# テスト

用意されたテストは、DrRacketからでもコマンドラインからでも実行できます。

DrRacketでテストを実行するには、テストファイルを開き、右上の「Run」ボタンをクリックするだけです。

コマンドラインからテストを実行するには、演習のディレクトリでテストを実行するだけです。たとえば、テストスイートが`hello-world-test.rkt`という名前なら、次のコマンドを実行します。

```
raco test hello-world-test.rkt
```

すると、次のように表示されます。

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
