# はじめに

Elmのような純粋関数型言語では、同じ引数で呼び出された関数は必ず同じ値を返さなければなりません。そのため、`rand : Int`という型シグネチャを持つ関数は`rand = 4`としか実装できず、これではランダムな整数を生成できるとは到底思えません。

では、Elmでランダムな値を生成するにはどうすればよいのでしょうか？　問題を2つに分けて考えます。まず、生成したい値を`Random.Generator a`で記述し、次に値を生成します。

値を生成する1つ目の方法は、`initialSeed : Int -> Seed`で`Random.Seed`を作成し、次に`step : Generator a -> Seed -> ( a, Seed )`を使うことです。`step`は値と新しいシードを返します。これらの関数はどちらも純粋なので、同じ引数で2回呼び出しても同じ値が生成されることに注意してください。

値を生成する2つ目の方法は、`generate : (a -> msg) -> Generator a -> Cmd msg`を使う方法ですが、これはElmアプリケーションの中でしか行えません。その場合、Elmランタイムは`step`のほかに、外部の純粋でないリソースを使ってシードを生成することがあります。

ここからは、ジェネレーターに焦点を当てます。

例を示すために、`initialSeed`と`step`を使って、ジェネレーターから複数の値を生成する関数`generate : Int -> Generator a -> List a`を定義したことにしましょう。

`Random`モジュールには、特定の範囲の整数と小数を生成するための基本的なジェネレーターが2つ用意されています。

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

これらの値は、タプルにまとめたり、値の配列にまとめたりできます。

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra`パッケージには、さまざまなデータ構造のためのジェネレーターがもっとたくさん用意されています。文字列、日付、辞書、配列、集合などです。

`Random.constant`を使うと、常に1つの値だけを返すジェネレーターを作れます。

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform`を使うと、与えられた要素の中から等しい確率でランダムに選べます。

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`が2つの引数（`Red`と`[Green, Blue]`）を取るのは、選べる値が少なくとも1つあることを保証するためです。1つの配列は空になり得るからです。

`Random.weighted`を使えば、確率を調整することもできます。

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

値の合計は100にする必要はありません。どのみち正規化されます。

`Random.map`を使うと、ジェネレーターの中身に手を加えられます。

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

`Random.map2`から`Random.map5`までを使えば、さらに多くのジェネレーターを組み合わせられます。

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

もっと複雑な用途には、`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`があります。これは、あるジェネレーターが生成した値を使って別のジェネレーターを作れます。

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

ジェネレーターを自己再帰的に定義すると便利なことがあります。そのような場合、コンパイラーがジェネレーターを無限に展開しないように、`Random.lazy`を使う必要があるかもしれません。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

この例は少し重たいので、順に分解してみましょう。

`Peano`は正の整数を表す型です。`Zero`は0、`Next(Zero)`は1、`Next(Next(Zero))`は2、といった具合です。`peano`は、ランダムな`Peano`の数を得るために定義します。

まず、`Random.lazy`はロジックに何も付け加えないことに注意してください。単に、コンパイラーが`peano`を無限に`peano`へ書き込むのを防ぐだけです。

`Random.uniform`を使って、ゼロ（確率50%）と、別の`Peano`の数に1を足したもの（確率50%）のどちらかを選びます。ただし、前の例とは違い、`Random.uniform`が選ぶのは値（`Zero`など）ではなく、ジェネレーター（`Random.constant Zero`など）です。`peano`自体を使いたいからです。つまり、`Random.uniform`は`Generator (Generator Peano)`型の値を返しますが、これは必要なものではありません。

ジェネレーターを「平坦化」するには、それを`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`にパイプします。ここで`b`は`Peano`であってほしいところです。`Generator a`は`Generator (Generator Peano)`なので、`a`は`Generator Peano`でなければならず、関数`(a -> Generator b)`は`(Generator Peano -> Generator Peano)`型でなければなりません。何も変更したくないので、`identity`が適切な選択です。

最後に、`peano`はどんな数を生成するのでしょうか？　50%の確率で0を生成し、50%の確率で自身をもう一度繰り返して1を足したものを生成します。つまり、0（50%）、1（25%）、2（12%）、3（6%）といった数になります。`peano`はいくらでも大きな数を生成できますが、確率は指数関数的に小さくなります。
