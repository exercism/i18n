# 説明

この演習では、お気に入りの料理本を見ながら最高のラザニアを作るためのコードを書きます。

タスクは3つあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンでの加熱時間を分単位で定義する

オーブンでの加熱時間が何分かを確認するために、`expectedMinutesInOven`を定義します。料理本によると、オーブンでの加熱時間は40分です。

```
> expectedMinutesInOven
  ⧩
  40
```

## 2. 準備時間を分単位で計算する

`preparationTimeInMinutes`関数を定義します。この関数は、ラザニアに重ねた層の数を入力として受け取り、ラザニアの準備にかかった時間を分で返します。1層あたり2分かかるものとします。

```
> preparationTimeInMinutes 3
  ⧩
  6
```

## 3. 経過時間を分単位で計算する

`elapsedTimeInMinutes`関数を定義します。この関数は2つの入力を受け取ります。1つ目はラザニアに重ねた層の数、2つ目はラザニアをオーブンに入れてからの時間（分）です。この関数は、ラザニアの調理に取り組んだ時間を分で返します。これは、準備にかかった時間（分）と、その時点でラザニアがオーブンに入っていた時間（分）の合計です。

```
> elapsedTimeInMinutes 3 20
  ⧩
  26
```
