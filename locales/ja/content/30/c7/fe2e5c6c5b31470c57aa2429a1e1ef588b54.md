# はじめに
C++に組み込みの数値型は、整数と浮動小数点数に分けられます。
整数は、`0`や`691`、`-2`のような小数部分を持たない数値です。
浮動小数点数は、`6.02214076`や`0.1`、`-1.616`のような小数点を持つ数値です。

## 整数
次の例では、4つの異なる変数の宣言と初期化を示します。

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

`int`変数に値を代入するときは、リテラルを直接使うことができます。
リテラルとは、`9241`のようなコードに直接書き込まれた数値です。
整数リテラルには、表現する基数に応じていくつかの種類があります。
10進数の整数リテラルが最も一般的で、`0`から`9`の数字を使います。
`0x`のような特別な接頭辞を付けると、他の基数を使うこともできます。
上の例では、数値`9421`を4つの表現と接頭辞で示しています。
どの変数も、同じ値に初期化されます。

さまざまな表現方法の詳細については、[小さなチュートリアル][cpp_numerical_bases]を見てみましょう。

読みやすくするために、アポストロフィで数字を区切ることができます。
`9'241`は、`0b0100'100'0001'1001`や`92'4'1`と同じです。

## 浮動小数点数

浮動小数点リテラルには2つの書き方があります。
直感的な`0.0024`のほかに、その科学的記数法である`2.4e-3`を使うこともできます。
最も一般的な浮動小数点型は`double`です。

## 算術演算

C++では、式を組み立てるために`+`、`-`、`*`、`/`、`(`、`)`、`%`を使うことができます。
2つの整数の間の演算の結果も、整数になります。
`5 / 2`は`2`を返します。
関わる型の一方が浮動小数点型であれば、結果も浮動小数点数になります。
`5.0 / 2`と`5 / 2.0`は`2.5`を返します。
`%`は余りを求める演算子で、整数の除算の余りを返します。`5%3`は`2`です。

## 代入演算子

代入演算子は、変数にリテラルを代入します。
常に右から左へ行われ、逆の向きになることはありません。

```cpp
int length = 5;
int width = 2;
length = width;
```

ここでは、整数値`5`が変数`length`に代入されます。
次に、整数値`2`が変数`width`に代入されます。
最後に、`width`の値が変数`length`にコピーされ、それまでの値`5`は失われます。
また、代入の操作の瞬間に`width`の値を`length`に代入しているだけだということも覚えておきましょう。
したがって、後で`width`の値が変わっても、`length`がとる値には影響しません。

代入演算子は、他の演算子（算術演算子やビット演算子）と組み合わせることができ、これらは`compound assignment`演算子`+=`、`-=`、`*=`、`/=`、`%=`として知られています。
これらの演算子は、変数に対して演算を行うことで、その変数の現在の値を変更します。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

変数`people`と`eggs`は`0`に初期化されます。
次に、変数`people`の現在の値`0`に整数値`2`を足し、その結果を`people`に代入し直します。
これで`people`は`2`になります。
その後、1人につき`3`個の卵を足し、合計で`6`個の卵になります。
次に、この`6`を変数`eggs`の現在の値`0`に足し、その結果を`eggs`に代入し直します。
これで`eggs`は`6`になります。
同等の式は、`people = people + 2`と`eggs = eggs + (3 * people)`になります。
