# 説明の補足

## 地雷原のフォーマット

地雷原はヌル終端文字列として表され、各行の末尾には改行文字が入ります。

例は、`"   \n * \n   \n"`のようになります。

## レジスタ

| レジスタ | 用途         | 型      | 説明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力         | アドレス | ヌル終端された入力文字列       |
| `$a1`    | 入力/出力    | アドレス | ヌル終端された出力文字列       |
| `$t0-9`  | 一時         | 任意     | 一時的な保存用                 |
