# 概要

オブジェクト初期化子は、コンストラクターに代わる書き方です。構文は、フィールド名=値のペアをカンマで区切って並べたもので、次のようになります。

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

コレクションも同じように初期化できます。ふつうは、次に示すようにカンマで区切ったリストを使います。

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

この方法（と構文）は、`IEnumerable`を実装していて`Add()`メソッドを持つクラスなら、どれでも使えます。

フィールドはどの順番で並べてもよく、まったく省略することもできます。

辞書では次の構文を使います。

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

初期化するフィールドは、呼び出し側からアクセスできなければなりません。ふつうは`public`か`internal`である必要があります。

言語の設計者や第一線で活躍する実践者たちの間には、不変性を推し進める強い流れがあるため、この方法で初期化したオブジェクトが可変であることは欠点と見なされています。次のバージョンであるC# 9では`init`句を導入する提案があり、これがその問題に対処するかもしれません。
