# はじめに

Elixirは動的型付け言語です。つまり、コンパイル時の型チェックは行われません。それでも、型仕様はドキュメントの一種として使えます。

型仕様は、関数定義の直前に`@spec`モジュール属性を使って追加できます。`@spec`の後には、関数名を書き、そのあとに、すべての引数の型をコンマで区切って括弧（`()`）の中に並べます。戻り値の型は、関数の引数と二重コロン`::`で区切ります。

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## 型

よく使われる型には次のようなものがあります。

- 真偽値：`boolean()`
- 文字列：`String.t()`
- 数値：`integer()`、`non_neg_integer()`、`pos_integer()`、`float()`
- 配列：`list()`
- 任意の型の値：`any()`

型によっては、パラメータを取ることもできます。たとえば、`list(integer)`は整数の配列です。

リテラル値も型として使えます。

型の和集合は、パイプ`|`を使って書けます。たとえば、`integer() | :error`は、整数か、アトムのリテラル`:error`のどちらかという意味です。

すべての型の一覧は、[公式ドキュメントの「Typespecs」の節][types]にあります。

## 引数に名前を付ける

型仕様の引数には名前を付けることもできます。同じ型の引数が複数あるときに区別するのに便利です。引数名を二重コロンで区切って、引数の型の前に書きます。

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## カスタム型

型仕様は、組み込みの型だけに限られません。カスタム型は、`@type`モジュール属性を使って定義できます。カスタム型の定義は、型の名前から始まり、その後に二重コロン、そして型そのものが続きます。

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

カスタム型は、定義したのと同じモジュールからでも、別のモジュールからでも使えます。
