# インストール

## tclshのインストール

必要なツールは、TCLのインタプリター`tclsh`だけです。

Windowsの場合、Tclを入手するのに最適なのは、Magicsplatが提供する[Tclインストーラー][magicsplat]です。

MacOSやUnix系のOSでは、`tclsh`はすでにインストールされています。通常、インストールされているバージョンは8.6.*何かしら*です。現行の安定版である9.1をインストールするには、次のようにします。
 - MacOSなら、[Homebrew][brew]を使います。
 - Linuxなら、お使いのパッケージマネージャーを確認します。
 - または、[ソースをダウンロード][download]して[ビルド][build]します。

Exercismのウェブインターフェースで演習を解く場合、テストランナー（2023年2月時点）はTclバージョン8.7a4を使用しています。

## 対話型tclshシェルの使い方

コードを書いているときに、コマンドを試してみるために[`tclsh`][tclsh]の対話セッションを起動するのはよくあることです。ただし、tclshが提供するのはごく基本的なREPLインタプリターで、コマンドライン編集やコマンド履歴はありません。より快適に使うために、readlineの機能を追加する`rlwrap`というプログラムがあります。

```bash
rlwrap tclsh
```

rlwrapをインストールするには:
 - MacOSなら、[Homebrew][brew]を使います。
 - Linuxなら、お使いのパッケージマネージャーを確認します。
 - または、[ソースをダウンロード][rlwrap-download]して[ビルド][rlwrap-build]します。

とても便利なので、いつも使いたくなるはずです。~/.bashrcに次を追加しましょう。

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## どのバージョンを使うべきか？

現在の安定版は9.1です。上で触れたとおり、バージョン8.6も依然として広く使われています。

インストールされている`tclsh`のバージョンは、次のコマンドを実行して確認できます。

```bash
echo 'puts [info patchlevel]' | tclsh
```
