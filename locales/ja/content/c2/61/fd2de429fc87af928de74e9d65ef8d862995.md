# テスト

まずは[テスト駆動開発の3つのルール][3-tdd-rules]に従って、最初のテストをコンパイルし、リンクし、通るようにしましょう。

同梱のmakefileを使うと、`test`タスクでテストを作成して実行できます。

```console
$ make test
```

コンパイラのエラーを解消するのに必要な関数だけを作成し、まずはテストを失敗させましょう。
次に、テストが通るだけのコードを書きます。
それができたら、次のテストに進みましょう。

テストを進めていく中で、読みやすさと表現力のために実装をリファクタリングする時間をとってから、次のテストに進みましょう。

低レベルのアルゴリズムや機能を自分で一から書くよりも、標準のC99の機能を使うようにしてみましょう。

## メモリリークのチェック

makefileには、メモリリークや配列への範囲外アクセスに関するよくある間違いをチェックするビルドも付属しています。
このチェックを実行するには、コマンドラインで次のようにします。

```console
$ make memcheck
```
