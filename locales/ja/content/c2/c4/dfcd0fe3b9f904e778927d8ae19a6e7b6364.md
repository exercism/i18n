# はじめに

Kotlinの[`string`][ref-string]は、Unicode文字の並びで、変更できないものです。

[`Immutable`][wiki-immutable]とは、文字列に対するどんな操作も新しい文字列を返さなければならないということです。元の文字列が変わることは決してありません。

[`Unicode`][wiki-unicode]のおかげで、世界中のほとんどの文字体系を表現できますが、Cのような古い言語とは違い、文字とバイトが1対1で対応しているわけではありません。

文字列は通常、二重引用符`" "`で囲みます。

一部の文字はエスケープが必要です。`\'`、`\\`のほか、`\t`（タブ）や`\n`（改行）といったおなじみの非表示文字がそれにあたります。

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

複数行の文字列は二重引用符3つで囲み、任意のテキストを含めることができます（エスケープは不要です）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

[trimIndent][trimIndent-doc]を使うと、各行に共通するインデントを取り除けます。文字列の整形に便利です。

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

別の方法として、[trimMargin][trimMargin-doc]では区切り文字を指定できます。すると、`String`の各行はその区切り文字の後ろから始まります。区切り文字のデフォルトは`|`ですが、引数で別の区切り文字を指定することもできます。例えば次のとおりです。

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

文字列は`+`で連結できますが、短くて単純な場合にとどめておくのがよいでしょう。ほかにも、もっとよい方法がいろいろあります。

## 文字列テンプレート

これは、ほかの言語で「補間」と呼ばれているものです。

文字列の中にドル記号`$`とそれに続く識別子がある場合、または式を囲む波括弧（`{expression}`）がある場合、それらはそれぞれ、その値または式の結果で置き換えられます。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

式の解析が曖昧になる場合は、式を波括弧`{ }`で囲む必要があります。

一般に、文字列の結合には`+`を使うよりも、文字列テンプレートを使うほうが効率的で慣用的です。

## 文字列の関数

Kotlinには、文字列を操作するための[`functions`][ref-string-functions]が_たくさん_用意されています。

ほとんどは`String`クラスのメンバーではなく[`extensions functions`][ref-extensions]ですが、使い方にはほとんど影響しません。

~~~~exercism/note
Kotlinのやや複雑な[ドキュメント][ref-string-functions]のページでは、デフォルトの表示だと拡張関数が隠れています。
`Members & Extensions`をクリックして、このセクションを展開してください。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

次の例は、利用できるもののほんの一部です。

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
