# インストール

Standard MLの処理系として*PolyML*を使います。

Windowsを使っている場合は、[https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases)からインストーラーをダウンロードできます。
Linux/OS X/Free BSDでの一般的な手順は、[https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme)にあります。

ソースからインストールしたい場合も、手順はとても簡単です。

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

たとえば`$HOME/.local`のような任意の場所にインストールしたい場合は、次のようにします。

```sh
$ ./configure --prefix=$HOME/.local
```

最後のステップです。

```sh
$ make compiler
$ make install
```

正しくインストールできたか確認しましょう。

```sh
$ poly
```

インタプリターが表示されれば、準備完了です！
表示されない場合は、おそらく`$HOME/.local/bin`（または`<you prefix>/bin`）を`$PATH`に追加する必要があるでしょう。
