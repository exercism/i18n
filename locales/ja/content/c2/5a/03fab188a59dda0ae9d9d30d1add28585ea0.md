# 説明

`accumulate`という操作を実装してください。この操作は、コレクションと、その各要素に対して行う操作を受け取り、入力コレクションの各要素にその操作を適用した結果を収めた新しいコレクションを返します。

次の数値のコレクションがあるとします。

- 1、2、3、4、5

そして、操作は次のとおりです。

- 数値を2乗する（`x => x * x`）

書いたコードで、2乗した値のコレクションを生成できるようにしてください。

- 1、4、9、16、25

期待される関数シグネチャは、テストスイートで確認してください。

## 制約

標準ライブラリが提供する`collect`、`map`、`fmap`、その他もろもろの機能には手を出さないでください！　代わりに、ほかの基本的な道具を使って、自分で解いてみてください。
