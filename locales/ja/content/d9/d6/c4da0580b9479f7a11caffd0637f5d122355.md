# ヒント

## 全般

- `unparse`は[`prettyprint`][prettyprint]にあります。スライス系は[`sequences`][sequences]に、複数入力を扱うクレイブ系は[`combinators`][combinators]にあります。

## 1. 値をクォートする

- 一言で言うと、`unparse`です。

## 2. フラグの枠組みを取り除く

- 先頭のマーカーは`1 tail-slice`で落とし、次に末尾のマーカーは`1 head-slice*`で落とします。

## 3. フラグを分割する

- `head-slice`と`tail-slice`は、どちらもスタックにフラグとヘッダーの長さの両方を必要とします。使うのは`[ head-slice ] [ tail-slice ] 2bi`です。

## 4. 2つの読み取り値から三角測量する

- 3つの異なるクォーテーションで、それぞれが同じ2つの読み取り値を取ります：`[ - ] [ + 2 / ] [ / ] 2tri`。

## 5. 3つの読み取り値をまとめる

- それぞれ3つの入力を受け取る3つのクォーテーション：`3tri`。合計を求めるクォーテーションは`[ + + ]`、積を求めるものは`[ * * ]`、最大値を求めるものは`[ max max ]`です。
