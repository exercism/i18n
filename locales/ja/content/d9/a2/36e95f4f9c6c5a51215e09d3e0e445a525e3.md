# はじめに

Goでは、`for`とインデックスを使って`slice`を繰り返し処理することもできますし、`range`を使うこともできます。`range`を使えば、`map`を繰り返し処理することもできます。

それぞれの繰り返しでは、インデックスかキーと、そのインデックスかキーにある要素のコピーの、2つの値が返されます。

## `slice`を繰り返し処理する

とても簡単です。`slice`の繰り返しは、期待どおりの順序で進みます。

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## `map`を繰り返し処理する

`map`を繰り返し処理すると、新たな問題が生じます。順序がランダムになるのです。

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
上の出力は正しくないように見えるかもしれません。`map`の宣言にある最初のキーと値のペア`9 10`が、最後ではなく最初に出力されると期待するのが自然だからです。
しかし、`map`は本質的に順序を持ちません。最初や最後のキーと値のペアというものはないのです。
そのため、`map`の要素を繰り返し処理するとき、どの要素がどの順序でたどられるかはランダムで、決まったパターンには従いません。
つまり、上の出力は起こりえますが、自分で実行したときに得られる結果とは異なるかもしれません。
詳しくは、[Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause)を参照してください。
~~~~

## キーや値を省略した繰り返し

Goでは、使われていない変数があるとビルド時にエラーになります。
最初の例のように、値だけが必要なこともあります。

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

`i`を`_`に置き換えると、その値を使わないことをコンパイラーに伝えられます。

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

インデックスだけを出力したい場合は、`x`を`_`に置き換えるか、宣言そのものを省略します。

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## 構造体以外の型

これまでに構造体型を定義する方法を見てきました。
構造体以外の型を定義することもでき、これは組み込み型の宣言の別名として使えます。また、構造体型と同じようにレシーバー関数を定義して拡張することもできます。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

配列や`map`で構成される、構造体以外の型を定義することもできます。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
