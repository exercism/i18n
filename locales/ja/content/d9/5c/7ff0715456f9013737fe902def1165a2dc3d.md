# はじめに

`Complex numbers`は、難しくありません。
もっとおだやかな名前を付けてあげればいいだけなのです。

複素数は、特に工学や科学の分野でとても役に立つため、Juliaでは整数や浮動小数点数と並ぶ標準の数値型として用意されています。

## 基本

Juliaの`complex`値は、基本的には2つの数値のペアです。多くの場合は浮動小数点数ですが、いつもそうとは限りません。
この2つは、残念ながら歴史的な理由から「実部」と「虚部」と呼ばれています。
ここでも、奇妙な名前にとらわれず、その根本的なシンプルさに目を向けるのが一番です。

2つの実数から複素数を作るには、虚部に接尾辞`im`を付けるだけです。

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> typeof(z)
ComplexF64 (alias for Complex{Float64})
julia> zi = 1 + 2im
1 + 2im
julia> typeof(zi)
Complex{Int64}
```

このように、対応する整数型や浮動小数点型から派生した、さまざまな`Complex`型があります。

実数の変数から複素数を作る場合、上記の書き方は使えません。
`a + bim`と書くと、パーサーが`bim`という（存在しない）変数名だと勘違いしてしまいます。

`b*im`と書くこともできますが、おすすめの方法は`complex()`関数を使うことです。これなら掛け算と足し算をせずに済みます。

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

複素数の各部分を個別に取り出すには、次のようにします。

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> real(z)
1.2
julia> imag(z)
3.4
```

まとめて取り出すこともできます。

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

どちらの部分も0になることがあり、数学者はそのような数を「完全に実数」あるいは「完全に虚数」と呼ぶことがあります。
しかしJuliaでは、それでも複素数のままです。

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im
julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})
julia> zi = 3.4im
0.0 + 3.4im
julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

「`i`（または`j`）は-1の平方根である」と聞いたことがあるかもしれません。

今のところ、これが意味するのは、虚部が_定義により_次の等式を満たすということだけです。

```julia-repl
julia> 1im * 1im == -1
true
```

とてもシンプルな考え方ですが、興味深い結果を生みます。

## 算術

浮動小数点数や整数で使う標準的な数学の`operators`と初等関数は、すべて複素数でも使えます。ほんの一例を挙げます。

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im
julia> z2 = 2 + 1.5im
2.0 + 1.5im
julia> z1 + z2  # addition
3.5 + 3.5im
julia> z1 * z2  # multiplication
0.0 + 6.25im
julia> z1 / z2  # division
0.96 + 0.28im
julia> z1^2  # exponentiation
-1.75 + 6.0im
julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## 関数

`real()`と`imag()`のほかにも、複素数に関係の深い関数がいくつかあります。

- `conj()`は、複素数の虚部の符号を反転させるだけです（_+から-へ、またはその逆_）。
    - 複素数の掛け算の仕組みのおかげで、これは思っている以上に役に立ちます。
- `abs(<complex number>)`は、虚部のない実数を必ず返します。
- `abs2(<complex number>)`は`abs(<complex number>)`の2乗を返します。`abs()`より計算が速く、計算で必要になることもよくあります。
- `angle(<complex number>)`は位相角をラジアンで返します。

```julia-repl
julia> z1
1.5 + 2.0im
julia> conj(z1)
1.5 - 2.0im
julia> abs(z1)
2.5
julia> abs2(z1)
6.25
julia> angle(z1)
0.9272952180016122
```
数学が気になる人向けに、少しだけ説明します。

- `z1`の`(real, imag)`という表現は、実質的には複素平面上の直交座標を使っています。
- 同じ複素数は、極座標を使った`(r, θ)`という表記でも表せます。
- ここで、`r`と`θ`はそれぞれ`abs(z1)`と`angle(z1)`で求まります。

いくつかの定数を使った例です。

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im
julia> real(euler)
-1.0
julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

極座標の`(r, θ)`表記はとても便利なので、より効率よく組み立てるための組み込み関数`cis`（`cos(x) + isin(x)`の略）と`cispi`（`cos(πx) + isin(πx)`の略）が用意されています。

極座標表記の便利さは、オイラーの美しい公式`ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`（ただし`|x + iy| = 1`）に表れています。
`|x + iy| = r`とすると、より一般的な極形式`r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`が得られます。
特に指数形式は簡潔で、扱いやすいことに注目してください。

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

上で近似等号を使ったのは、`cis`と`cispi`の方がよりきれいな数値を返せることがあるからです。特に`cispi`は、引数がπの任意の倍数（たとえばラジアン！）の場合に力を発揮します。

```julia-repl
julia> cis(π)
-1.0 + 0.0im
julia> cispi(1)
-1.0 + 0.0im
julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im
julia> cis(θ)
6.123233995736766e-17 + 1.0im
julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

ちなみに、このことから複素数は2次元での回転や半径方向の移動にとても役立ちます。

回転の場合、複素数`z = x + iy`は、単純な掛け算`z * ℯ^(iθ)`で原点を中心に角度`θ`だけ回転できます。
ここでの`x`と`y`は、実数の2次元直交平面上のいつもの座標にすぎません。正の角度なら*反時計回り*、負の角度なら*時計回り*の回転になります。

同様に簡単に、半径方向の移動`Δr`は、極形式の複素数の大きさ`r`に足すことで実現できます（例：`z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`）。
角度の部分は変わらず、大きさ`r`だけが変わることに注目してください。期待どおりですね。
