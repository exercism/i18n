# 指示

あなたは腕利きのミクソロジストとして、夜のにぎわいを楽しむ人たちのためにおいしい飲み物を作っています。でも、仕事を手伝ってくれるコードを少し書けば、もっと楽にできると思ったのです。

## 1. 注文にかかる時間を求める

飲み物の種類によって、準備にかかる時間は異なります。

- `"beer"`、`"soda"`、`"water"`はそれぞれ0.5分です。
- `"shot"`は1.0分、`"mixed drink"`は1.5分です。
- `"fancy drink"`は2.5分です。
- `"frozen drink"`は3.0分です。

関数`timeToPrepare(drinks:)`を実装してください。この関数は、用意する必要がある飲み物を表す文字列の配列を保持する引数`drinks`を取ります。関数は、配列内のすべての飲み物を用意するのにかかる合計時間を返すようにしてください。

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. ライムウェッジを補充する

シフトを始めるときにまずやるべきことの1つは、これからのシフトに備えて、ライムウェッジの小さな容器がいっぱいになっているか確認することです。ライムの大きさによって取れるウェッジの数は変わり、"small"のライムからは6個、"medium"のライムからは8個、"large"のライムからは10個のウェッジが取れます。

まだウェッジが足りなくて、切るライムもまだ残っている間は、配列から最初のライムを取り出し、必要な数からそのライムで取れるウェッジの数を引きます。必要な数に達するか、ライムがなくなるまでこれを続けます。

関数`makeWedges(needed:limes:)`を実装してください。この関数は、切る必要があるウェッジの数を保持する引数`needed`と、切るために用意されているライムの大きさを表す文字列の配列を保持する引数`limes`を取ります。関数は、切ったライムの数を返すようにしてください。

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. シフトを終える

おめでとうございます！　長い一日の仕事ももうすぐ終わり、まもなく家に帰って新しいアプリの開発に取りかかれます。でも、注文を次のシフトに引き継いで帰る前に、まだ続いている飲み物の注文をさばかなければなりません。

シフトに残り時間がある限り、配列の最初の注文を作り、その注文を配列から取り除きます。次に、その注文の準備にかかった時間を、関数`timeToPrepare(drinks:)`に従ってシフトの残り時間から引きます。

関数`finishShift(minutesLeft:remainingOrders:)`を実装してください。この関数は、シフトの残り時間（0より大きいことが保証されています）と、空でない飲み物の注文の配列を受け取ります。関数は、シフトが終わるまでに手をつけられなかった注文の配列を返すようにしてください。

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. 特定の注文を記録する

ビールとソーダを新鮮なまま保つには、それらの注文と、注文された時刻を記録する必要があります。

関数`orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`を実装してください。この関数は、注文と時刻のリストを受け取ると、ビールとソーダの最初と最後の注文時刻、それぞれの注文の合計数を含むオプショナルのタプルのペアを返し、それらの飲み物の注文が1つもなかった場合は`nil`を返します。他の飲み物を記録する必要はありません。

関数`orderTracker(orders:)`を実装してください。この関数はタプルの配列を受け取ります。各タプルは、注文された飲み物と、その注文が入った時刻を保持しています。関数は、ビールが最初に注文された時刻と最後に注文された時刻、ビールの注文の合計数、ソーダが最初に注文された時刻と最後に注文された時刻、ソーダの注文の合計数を保持するタプルを返すようにしてください。返す形式は次のタプルです：`(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
