# インストール

演習を進めるには[Vim](http://www.vim.org)が必要です:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [ソースから](#source)

## macOS

macOSには標準でVimが入っていますが、あまりにも古いバージョンです。

ソフトウェアのインストールには、[MacPorts](https://www.macports.org)か[Homebrew](https://brew.sh)を使っていることが多いでしょう。

Homebrewの場合:

```
$ brew update
$ brew install vim
```

MacPortsの場合:

```
$ sudo port install vim +huge
```

GUIが必要な場合は、代わりに[MacVim](https://macvim-dev.github.io/macvim)を検討してみてください。

## Ubuntu / Debian

GUIをサポートした本格的なVim（`gvim`）をインストールします:

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

[Chocolatey](https://chocolatey.org)を使う場合:

```
C:\> choco install vim
```

または、[こちら](http://www.vim.org/download.php#pc)から直接ダウンロードしてインストールしてください。

## ソースから

最新のVimを自分でコンパイルしたい場合は、[GitHubの公式リポジトリ](https://github.com/vim/vim)を見てみましょう。
