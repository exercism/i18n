# 概要

## インクルード

C++で他のファイルの内容を取り込むには、`include`ディレクティブを使います。これらのインクルードは、ファイルの先頭に書きます。コンパイル時には、ディレクティブのある行が、対応するファイルの内容に置き換えられます。インクルードしても、名前空間は元のファイルのまま保たれます。

## 標準ライブラリ

標準ライブラリには、よく使われる関数、アルゴリズム、データ構造が数多くそろっています。標準ライブラリは、`std`名前空間を使います。

その一例が、Cの数値演算ライブラリである`cmath`です。一般的な数学演算を数多く提供しています。

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
標準ライブラリは、二重引用符`"`ではなく、山括弧`<>`でインクルードします。この違いは、コンパイラーがそれぞれのファイルを探す場所にあります。山括弧を使う場合は、現在のプロジェクト内の検索が省略され、システムのインクルードディレクトリから直接探し始めます。ローカルのファイルをインクルードしたい場合は、二重引用符を使います: `#include "myfile"`
~~~~
