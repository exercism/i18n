# はじめに

*ジェネリックワード*は、引数のクラスによっていくつもの実装を持てる操作を宣言します。メソッドは`M:`で追加します。

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:`は、そのワードとスタック効果を宣言します。`M:`は特定のクラスに対するメソッドを定義します。Factorは実行時に、スタックの一番上にある引数のクラスに基づいてメソッドを選びます。

ジェネリックワードに、どのクラスにメソッドが定義されているかを尋ねることもできますし、あとからメソッドを追加したり削除したりもできます。継承のための特別な構文はありません。どのタプルクラスにも、自動的にメソッドを定義できます。
