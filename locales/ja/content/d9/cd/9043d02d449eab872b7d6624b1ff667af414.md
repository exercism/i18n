# ジェネリック型の紹介

**ジェネリック型**とは、型でパラメータ化されたジェネリッククラスまたはジェネリックインターフェースのことです。これにより、コンパイラーがそのクラスやインターフェースに対して型安全性を強制できるようになります。

次の、ジェネリックではない`Container`インターフェースを見てみましょう。

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

このインターフェースは`Object`型を受け取って返すので、プリミティブ型以外のどんな型でも扱えます。しかし、これには代償があります。あるコードが`Integer`を期待して`get`を呼び出しているのに、別のコードが`String`を追加しようと`set`を呼び出すと、実行時例外が発生してしまうからです。

**ジェネリッククラス**と**ジェネリックインターフェース**は、次のような形式で書きます。

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

クラス名やインターフェース名のあとに続く、山括弧（`<>`）で囲まれた型パラメータの部分が、型パラメータ（型変数とも呼ばれます）`T1`、`T2`、…、`Tn`を指定します。これらはクラスやインターフェースの本体の中で使うことができ、ジェネリックな型安全性を得られます。

これが`Container`のジェネリック版です。

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

作成するときは、そのインスタンスがどの型を保持するのかを宣言する必要があり、コンパイラーがその制約を強制します。

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
