# はじめに

ベクトルは1次元の配列です。
異なる型の要素を含めることができます。

## ベクトルの作成

ベクトルは`vector`関数で作成することも、そのリーダー構文`#()`を使うことでも作成できます。

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

配列でもあるので、`make-array`でも作成できます。

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## ベクトルの述語

オブジェクトがベクトルかどうかを確認するには、述語`vectorp`を使うだけです。

## 要素へのアクセス

ベクトルの要素にアクセスするには`aref`を使います。インデックスは0から始まります。

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
