# 概要

## `if`式

`jq`の**条件式**は`if A then B else C end`です。

`if-then-else`も、`jq`のほかの組み込みと同じように、ひとつのフィルターです。入力を受け取り、出力を生成します。

式`A`が「真」とみなされる値を生成すると、`if`フィルターは`B`を評価します。そうでなければ`C`を評価します。`if`フィルターへの入力は、`B`または`C`に渡されます。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`節は**省略できます**。次の2つの文は同じ意味です。

```jq
if A then B else . end
if A then B end
```
~~~~

## 入れ子の`if`文

`elif`を使うと、条件をさらに追加できます。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

`elif`節は必要なだけいくつでも使えます。

## 真とみなされる値

`jq`で「false」となる値は、`false`と`null`だけです。それ以外はすべて「true」になります。数値のゼロや、空の文字列・配列・オブジェクトでさえも「true」です。

## 真偽値演算子

**真偽値演算子**の`and`と`or`を使うと、複雑なクエリを組み立てられます。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

否定するには、`not`を使います。これは演算子ではなく**フィルター**です。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## 代替演算子

**代替演算子**を使うと、式がfalseまたはnullだった場合の「デフォルト」の値を指定できます。

```jq
A // B

# This is identical to
if A then A else B end
```

実際に確かめてみましょう。

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```

## ほかにもあるのでしょうか？

ほかの言語から来たプログラマーは、`cond`、`case`、`switch`、`when`、`unless`、三項演算子など、より多彩な条件分岐の命令を期待するかもしれません。上に挙げた演算子が、`jq`にあるすべてです。
