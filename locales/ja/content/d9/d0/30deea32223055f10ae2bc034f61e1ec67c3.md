# はじめに

## 真偽値

`Bool`型は、言語の基本的な構成要素の1つです。何かが真か偽かを表すための型で、それぞれ`True`と`False`という値を使います。

真偽値は、`&&`の「AND」演算子と`||`の「OR」演算子で組み合わせることができ、`not`関数で否定できます。

真偽値は、特定の条件が満たされたときだけ実行される分岐をコードに作るときにも、とても役立ちます。Elmでは、これは`if-then-else`式で行います。使い方は次のとおりです。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
