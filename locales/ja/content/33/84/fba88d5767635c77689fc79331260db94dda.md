# 説明

地元のクラブでは、シーズンの最終戦です。フィニッシュラインでリーダーボードを運営しています。レーサーは順番にゴールし、レーンにはラベルが必要で、公式の台帳には次のレースの前に注釈を付けなければなりません。

レーサーの名前は、ゴールした順に配列として渡されます。0番目の名前が優勝者、1番目が2位、という具合です。

## 1. ゼッケンを割り当てる

`assign-bibs`を定義して、レーサー名の配列を受け取り、`{ position name }`のペアの配列を返すようにします。`position`が先です。

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. レーンのラベル

`lane-labels`を定義して、レーサー名の配列を受け取り、`"Lane 0: Bolt"`のような文字列を返すようにします。

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. レーサーにタグを付ける

`tag-racers`を定義して、レーサー名の配列*と*タグ文字列を受け取り、`"<tag>/<index>: <name>"`という形式のラベルを返すようにします。どのラベルにも同じタグが埋め込まれます。

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. ゴールを記録する

`record-finishes`を定義して、レーサー名の配列と台帳（ベクター）を受け取り、レーサーごとに`"<index>: <name>"`という形式の文字列を台帳にその場で追加します。戻り値はありません。

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. ラップベル

`lap-bells`を定義して、数値`laps`を受け取り、`"ding "`を`laps`回繰り返した文字列を返すようにします。

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
