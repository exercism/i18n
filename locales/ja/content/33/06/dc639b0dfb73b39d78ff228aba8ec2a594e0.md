# 概要

F#の[`list`][lists]は、0個以上の値からなる不変のコレクションです。配列内の値は、すべて同じ型でなければなりません。配列は不変なので、一度作成されると、その値を変えることはできません。F#の配列には*先頭*（最初の要素）と*末尾*（最初の要素より後ろのすべて）があります。配列の末尾もまた、配列です。

配列は次のように定義できます。

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

配列に要素を追加する最も一般的な方法は、`::`（cons）演算子を使うことです。

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

配列は、`@`演算子または`List.append`を使って連結できます。

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

配列は、[`List`モジュール][list-module]で定義されている関数と演算子によって操作します。これらの関数の一部は、`list`インスタンスの[プロパティ][list-properties]としても利用できます。

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

どちらを使っても間違いということはありません。一般的に、`List`モジュールの関数は型推論とうまく働きますが、プロパティを使うとより簡潔なコードを書けます。

配列を変更しているように見える関数や演算子（要素の追加など）も、実際には新しい配列を返します。ただし、配列の実装では不要な割り当てやコピーが起こらないため、通常はパフォーマンスが問題になることはありません。

配列は単方向連結リストとして実装されているため、要素を先頭に追加する（`::`演算子を使う）のは非常に高速ですが、インデックスで要素にアクセスするのは比較的遅くなる可能性があります。

配列は、[*list*][list-pattern]パターンと[*cons*][cons-pattern]パターンを使ったパターンマッチで処理することもできます。

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

パターンマッチでは、値を*破棄*することもできます。特定のケースでその値を*気にしない*とき（つまり、その値を*使わない*とき）は、アンダースコア（`'_'`）を使ってそれを示せます。

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

単独の`'_'`は、パターンマッチでは常に*最後*に置きます。他のどのケースにも*当てはまらない*値はすべて、このケースで処理されます。
