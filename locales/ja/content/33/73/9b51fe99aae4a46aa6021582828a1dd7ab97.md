# 説明

ルシアンの恋人が帰宅途中なのに、ルシアンは記念日のディナーをまだ作っていません！

この演習では、ルシアンがお気に入りの料理本から絶品ラザニアを作るのを手伝うコードを書きます。

ラザニアを作るのにかかる時間に関して、4つのタスクがあります。

## 1. オーブンでの想定時間を分単位で定義する

ラザニアを何分オーブンに入れておくべきかを表す`expected_minutes_in_oven`定数を定義しましょう。料理本によると、オーブンでの想定時間は`40`分です。

## 2. オーブンでの残り時間を分単位で計算する

`remaining_minutes_in_oven`メソッドを実装しましょう。このメソッドは、ラザニアを実際にオーブンに入れておいた分数を_仮引数_として受け取り、前のタスクの**オーブンでの想定時間**をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを_戻り値_として返します。

```abap
remaining_minutes_in_oven( 30 ).
// => 10
```

## 3. 準備時間を分単位で計算する

`preparation_time_in_minutes`メソッドを実装しましょう。このメソッドは、ラザニアに重ねた層の数を_仮引数_として受け取り、各層の準備に2分かかると仮定して、ラザニアの準備に何分かかったかを_戻り値_として返します。

```abap
preparation_time_in_minutes( 2 ).
// => 4
```

## 4. 合計作業時間を分単位で計算する

`total_time_in_minutes`メソッドを実装しましょう。このメソッドは_2つの仮引数_を取ります。`numbernumber_of_layers`仮引数はラザニアに重ねた層の数で、`actual_minutes_in_oven`仮引数はラザニアをオーブンに入れておいた分数です。このメソッドは、ラザニアの調理に合計何分かかったかを_戻り値_として返します。これは、準備にかかった分数と、その時点でラザニアがオーブンに入っていた分数の合計です。

```abap
total_time_in_minutes( 
  numbernumber_of_layers = 3
  actual_minutes_in_oven = 20 ).
// => 26
```
