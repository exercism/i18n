# 説明

この演習では、Exercismで学びたいプログラミング言語の配列を管理するコードを書きます。

タスクは9つあり、そのすべてで配列を扱います。

## 1. 新しい配列を作成する

学びたい言語を管理するには、新しい配列を作成する必要があります。

新しい空の配列を返す`static`メソッド`Languages.NewList()`を実装してください。

```csharp
Languages.NewList()
// => empty list
```

## 2. 既存の配列を定義する

今、学びたい言語が書かれた紙があります。C#、Clojure、Elmです。

その配列を返す`static`メソッド`Languages.GetExistingLanguages()`を実装してください。

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. 配列に新しい言語を追加する

Exercismを見ていて面白い言語が見つかると、それを配列に追加したくなります。

配列の末尾に新しい言語を追加する`static`関数`Languages.AddLanguage()`を実装してください。

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. 配列内の言語を数える

言語を1つずつ数えるのは面倒です。

配列内の言語の数を数える`static`メソッド`Languages.CountLanguages()`を実装してください。

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. 言語が配列に含まれているか確認する

指定した言語が配列に含まれているかどうかを確認する`static`メソッド`Languages.HasLanguage()`を実装してください。

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. 配列を逆にする

あるとき、自分の配列が実は逆順になっていることに気づきます！

配列を逆にする`static`メソッド`Languages.ReverseList()`を実装してください。

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. 配列がわくわくするものか確認する

言語はどれも大好きですが、C#は心の中で特別な位置を占めています。そのため、次のいずれかの条件に当てはまると、言語の配列にわくわくします。

- 配列の最初がC#である。
- 配列の2番目の要素がC#で、かつ配列に含まれる言語が2つか3つである。

言語の配列がわくわくするものかどうかを確認する`static`メソッド`Languages.IsExciting()`を実装してください。

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.言語を削除する

指定した言語を配列から削除する`static`メソッド`Languages.RemoveLanguage()`を実装してください。

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. 配列内のすべての言語が重複していないか確認する

配列内で言語が重複しているかどうかを確認する`static`メソッド`Languages.IsUnique()`を実装してください。

このメソッドが呼ばれるとき、言語の配列（つまり仮引数）は空でないことが保証されています。また、配列が変更されてもかまいません。

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
