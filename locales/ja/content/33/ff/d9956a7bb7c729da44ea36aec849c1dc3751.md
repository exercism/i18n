# テスト

演習をダウンロードするには、例えば`hello-world`なら、ターミナルを開いて次のように実行します：

```bash
exercism download --track roc --exercise hello-world
```

次に、演習のディレクトリに移動して、コードを編集し、演習を解きます。例えば：

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

各演習にはテストスイートが付属しています。`roc test`コマンドを使うと、テストを実行できます。例えば：

```
roc test hello-world-test.roc
```

演習を解き終えると、失敗したテストが0件と表示されるはずです。例えば：

```
All (5) tests passed in 123.4 ms.
```

ただし、コードにエラーがある場合は、次のように表示されます：

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

これはコードを修正する助けになるはずです。コードが動くようになったら、`exercism submit`コマンドで提出できます（詳しくは演習のディレクトリにある`HELP.md`を参照してください）。
