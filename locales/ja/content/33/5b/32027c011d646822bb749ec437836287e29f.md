# Import

[特殊形式`import`][import]を使うと、外部のモジュールの関数やマクロを、モジュール名を書かずに使えるようになります。

外部のモジュールを丸ごとインポートすると、既存のローカル関数と衝突する可能性があります。これを避けるには、`:except`と`:only`という2つのオプションがあります。どちらもキーワードリストを引数に取ります。キーは関数名で、値はその関数のアリティです。

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

通常、インポートはモジュール定義の先頭に書きますが、どこにでも書くことができます。インポートにはレキシカルスコープがあるので、関数定義の内部で書いたインポートは、別の関数では使えません。

使われていないインポートは、コンパイラの警告の原因になります。

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
