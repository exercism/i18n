# 概要

0個以上の要素を保持できるデータ構造は、_コレクション_ と呼ばれます。
Rubyの**配列**は、オブジェクトが追加された順序を保つコレクションです。
配列にはどんなオブジェクトでも入れられます。
オブジェクトは、インデックスを使って配列に追加したり、配列から取り出したりできます。
Rubyの配列のインデックスは0から始まります。つまり、最初の要素のインデックスは常に0です。

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Rubyで配列を作る方法はいくつかあります。

- リテラルコンストラクター`[]`を使う方法（_最もよく使われる_）
- `Array.new`を明示的に呼び出す方法
- Kernelの`Array()`メソッドを呼び出す方法

`Array.new`メソッドは、2つの省略可能な引数に対応しています。配列の初期サイズと、デフォルトのオブジェクトです。

サイズとデフォルトのオブジェクトを指定すると、配列はデフォルトオブジェクトのコピー`size`個で埋められます。

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

配列のすべての要素が同じハッシュを保持しているので、1つを変更するとすべてに影響します。

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

複数のコピーが必要な場合は、ブロック版を使いましょう。ブロック版では、配列の要素を初期化する必要があるたびに、そのブロックの結果が使われます。

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Rubyの配列のもう1つの特徴は、[Enumerable][enumerable-module]モジュールをミックスインしていることです。このモジュールは、配列の要素を繰り返し処理したり、検索したり、並べ替えたり、絞り込んだりするための便利なメソッドをたくさん追加してくれます。
