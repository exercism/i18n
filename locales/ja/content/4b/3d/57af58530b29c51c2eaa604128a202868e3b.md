# 説明

空のバッファを初期化し、フィボナッチ数列の最初の5つの数値（要素）を並べていきます。

フィボナッチ数列は、次の要素がその前の2つの和になる数列です。この数列は1から始まるので、最初の2つの要素は1と1です。

## 1. `count`個のゼロからなるバッファを作成する

`count`個のゼロからなるバッファを作成する関数を書きます。

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. フィボナッチ数列の最初の5つの要素を並べる

フィボナッチ数列の最初の5つの数値を返す関数を作ります。
最初の5つの要素は`1, 1, 2, 3, 5`です。

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
