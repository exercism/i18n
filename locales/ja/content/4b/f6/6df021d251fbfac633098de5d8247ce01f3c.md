# 可変長引数

Swiftの[_可変長引数_][variadic-parameters]を使うと、同じ型の0個以上の値を、関数の1つの仮引数に渡すことができます。
これは、仮引数の型注釈に`...`を付けることで示します。

これらの値は、可変長引数の型と同じ型の要素を持つ配列に、自動的にまとめられます。

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

可変長引数を使うときには、Swiftに2つの制限があります。

1. Swiftでは、1つの関数に可変長引数を1つしか持てません。この制限は将来のSwiftのリリースで取り除かれることが決まっていますが、現時点ではまだ残っています。
2. 定義の中で可変長引数のあとに続く仮引数がある場合、可変長引数の直後の仮引数には、引数ラベルを_必ず_付ける必要があります。

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
