# はじめに

Clojureの数値には、次のようなものがあります。

- 整数：小数点以下の桁がない数値（いわゆる整数）です。例は`-6`、`0`、`1`、`25`、`976`、`500000`です。
- 浮動小数点数：小数点以下に0桁以上の桁がある数値です。例は`-2.4`、`0.1`、`3.14`、`16.984025`、`1024.0`です。

よく使われる数値型には`int`と`float`があります。`int`は32ビットの整数で、`float`は64ビットの浮動小数点数です。

算術は標準的な算術演算子を使って行います。数値は、標準的な数値比較演算子（`>`、`<`、`<=`、`>=`）と、等価演算子（`=`）、非等価演算子（`not=`）を使って比較できます。

この演習では、条件によって処理を切り替える必要があります。Clojureでこれを行う一般的な方法は、`cond`を使うことです。

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```

## 補足
正確な型に関係なく数値を比較したい場合には、`=`よりも`==`演算子のほうが適していることがあります。たとえば、次のとおりです。
```clojure
(== 5.0 5) ;; true as both numbers are equal when type is ignored
(= 5.0 5) ;; false as the types of numbers are also taken into account here i.e. float is different from int
```
詳しくは、[Equalityに関するClojureガイド][guide-equality]の、特に[Numbers][guide-numbers]のセクションで説明されています。
