# はじめに

## Juliaの真偽値

真か偽の値は、`Bool`型で表します。
`Bool`型が持つ値は、`true`と`false`の2つだけです。

```julia-repl
julia> true
true

julia> false
false
```

## 真偽値の演算子

Juliaには、真偽値の演算子が3つあります。

`&&`は、真偽値の「and」を表します。
`&&`の*両側*の式が`true`のとき、結果は`true`になります。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`は、真偽値の「or」を表します。
`||`の*どちらか*の式が`true`のとき、結果は`true`になります。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`は、真偽値の「not」を表します。
`true`と`false`を入れ替えます。

```julia-repl
julia> !true
false

julia> !false
true
```

より長く複雑な式では、意図を明確にするために括弧（`()`）を使うのがよいでしょう。

```julia-repl
julia> (true || false) && (false && true)
false
```
