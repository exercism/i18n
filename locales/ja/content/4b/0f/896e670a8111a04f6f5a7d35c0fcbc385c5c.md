## 例外メッセージ

ときには、[例外を送出する](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。その際は、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めましょう。そうすることでコードが読みやすくなり、デバッグもずっと楽になります。エラーの原因が特定の型になるとわかっている場合は、[組み込みのエラー型](https://docs.python.org/3/library/exceptions.html#base-classes)から適切なものを選んで送出してもかまいませんが、その場合も意味のあるメッセージを含めましょう。

この演習では、ゲームが終わったのにプレイヤーが続けてプレイしようとしたときに、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「スロー」する必要があります。テストに合格するのは、`exception`を`raise`し、かつメッセージを添えた場合だけです。

メッセージ付きで`ValueError`を送出するには、メッセージを`exception`型の引数として書きます：

```python
# when player tries to play, but the game is already over.
raise ValueError("The game has already ended.")
```
