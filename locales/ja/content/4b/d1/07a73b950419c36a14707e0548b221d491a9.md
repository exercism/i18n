# 概要

PHPには、算術演算を行うための演算子がいくつか用意されています。PHPの算術演算子は、数学における標準的な演算の順序に従います。PHPが提供する演算子は次のとおりです。

* 単項プラス（+）
* 単項マイナス（-）
* 加算（+）
* 減算（-）
* 乗算（*）
* 除算（/）
* 余り（%）
* 累乗（**）

それぞれがどのように使われるのか、見ていきましょう。

## 単項プラス（+）

単項プラス演算子（+）は1つの値に対して働きます（単項演算子）。変数の`float`または`int`の値になります。

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## 単項マイナス（-）

単項マイナス演算子は1つの値に対して働き（単項演算子）、数値の符号を反転した値を返します。

```php
$forward = 65;
$reverse = -$forward; // -65
```

## 加算（+）と減算（-）

加算演算子は、その両側にある2つの値を足します。一方、減算演算子は、左の値から右の値を引きます。

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## 除算（/）

除算演算子は、左の値を右の値で割った結果を返します。右の値が0の場合、`DivisionByZeroError`エラーが発生します。

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## 乗算（*）

乗算演算子は、左の値と右の値を掛け合わせた結果を返します。

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## 余り（%）

余り演算子は、左の値を右の値で割ったときの余りを返します。この演算子は、ある数が別の数を割り切れるかどうかを調べたり、値が偶数か奇数かを判定したりするのに、とても役立ちます。

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## 累乗（**）

累乗演算子は、左の値を右の値で累乗するために使います。PHP 5.6より前では、同じことを行うのに`pow`関数を使う必要がありました。

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

累乗演算子は、両辺に整数と小数を指定できます。そのため、平方根（あるいは他の累乗根）や、より複雑な指数の値を計算することもできます。

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## 演算の順序

PHPは数学の標準的な演算の順序に従います。つまり、演算を左から右へ順に行うのではなく、各演算子に優先順位があり、その優先順位に従って演算が解決されます。演算の順序は次のとおりです。

* 括弧（`()`）
* 累乗
* 乗算、除算
* 加算、減算

乗算と除算は互いに同じ優先順位です。同様に、加算と減算も互いに同じ優先順位です。

つまり、乗算は加算よりも優先順位が高いため、次の値は10ではなく17になります。

```php
$value = 2 + 3 * 5;
```

PHPには、変数に対して演算を行い、その結果をその変数自身に代入するときに、算術演算子と代入を組み合わせた便利な代入演算子もいくつか用意されています。これらについては、`Assignment Operators`のコンセプトで扱います。
