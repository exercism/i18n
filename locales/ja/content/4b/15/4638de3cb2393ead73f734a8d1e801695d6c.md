# 型変換の概要

Goでは、異なる型の間で明示的な変換が必要です。
たとえば、次のコードはコンパイラエラーになります。

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

型の間の変換（**型キャスト**とも呼ばれます）は、変換先の型の名前を持つ関数で行います。
値`v`は、`T(v)`を使って型`T`に変換されます。
たとえば、`int`を`float64`に変換するには、次のように書きます。

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

独自に定義した型でも、同じことが言えます。

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## プリミティブ型と文字列の間の変換

プリミティブ型（`int`など）と`string`の間で変換するための`strconv`パッケージがあります。

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

警告：標準のキャスト方法では、この動作にはなりません。
たとえば、次のとおりです。

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

ほかにも、よく使われる変換メソッドをいくつか紹介します。

| メソッド    | 用途                           |
| ----------- | ------------------------------ |
| ParseBool   | `string`を`bool`に変換する     |
| FormatBool  | `bool`を`string`に変換する     |
| ParseFloat  | `string`を`float`に変換する    |
| FormatFloat | `float`を`string`に変換する    |
| ParseInt    | `string`を`int`に変換する      |
| FormatInt   | `int`を`string`に変換する      |
