# インストール

## Windowsをお使いの方へ

[Windows Subsystem for Linux][wsl-link]をインストールしてから、次のセクションに進んでください。

## Linux/Macをお使いの方へ

### brewでインストールする

Chapelをインストールするもっとも簡単な方法です。
基本的な環境が整い、Exercismのトラックを進めるのに適しています。
さらに進んだ方は、ソースコードからChapelをビルドする方法（次のセクション）を選んでもよいでしょう。

0. まだの場合は、パッケージマネージャーの[brew][brew-link]をインストールします。
1. まず、`brew update`を実行してbrewを最新の状態にします。
2. `brew install chapel`を実行してChapelをインストールします。
3. `chpl --version`を実行して、インストールが成功したか確認します。

これで、chapelコンパイラー（`chpl`）、テストの実行に使うパッケージマネージャーの`mason`、そしてドキュメント生成ツールの`chpldoc`がインストールされます。`chpldoc`はExercismには必要ありませんが、Chapelで自分だけのライブラリーを作りたくなったとき（そのときは必ず来ます :)）に役立ちます。

### ソースコードからChapelをビルドする

さらに進んだ方は、Chapelをソースコードから自分でビルドしたくなるかもしれません。その場合は、次のようにします。

1. [前提条件][prereqs-link]をインストールします。
2. 最新のChapelリリースのアーカイブを[ダウンロード][download-link]して展開します。
3. まず、Chapelをインストールする場所を決めて、インストールと設定の準備を行います。
これは、用意されている`configure`スクリプトを実行すればできます。
単に

```
./configure
```

を実行すると、バイナリ、ライブラリー、共有ファイルが`/usr/local/`にインストールされます。この場所は`--prefix`オプションで変更できます。
たとえば、Chapelを`~/.chapel`にインストールしたい場合は、次のようにします。

```
./configure --prefix=~/.chapel
```

4. コンパイラーとツールをインストールするには、次を実行します。

```
make
make mason
make chpldoc
make install
```

5. `/dir/for/install/bin`フォルダーが`PATH`変数に含まれていることを確認します。

Chapelのさまざまなインストール方法やソースコードからの作業について詳しくは、ドキュメントの[Building Chapel][building-link]ページを参照してください。
