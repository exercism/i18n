# はじめに

## `true`と`false`

Rubyでは、真偽の状態を`true`と`false`で表します。

```ruby
happy = true
sad = false
```

## 等価と比較

Rubyでは、通常の比較演算子を使ってオブジェクト同士を比較できます。
- `==`を使うと、2つのオブジェクトが等しいかどうかを調べられます
- `>`を使うと、左側のオブジェクトが右側のオブジェクトより**大きい**かどうかを調べられます
- `<`を使うと、左側のオブジェクトが右側のオブジェクトより**小さい**かどうかを調べられます
- `>=`や`<=`を使うと、それぞれ「以上」と「以下」を判定できます

通常の演算子を使って、真偽値の論理演算もできます。
- `&&`や`and`を使うと、`x and y`がどちらも`true`かどうかを確認できます
- `||`や`or`を使うと、`x or y`が`true`かどうかを確認できます
- `!`や`not`を使うと、等しいかどうかを反転できます。たとえば`x != y`（xとyは等しくない）のように書きます

以下はその例です。
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
