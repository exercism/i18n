# はじめに

三項演算子を使うと、`if`の条件を、文のブロックではなく式の中で定義できます。これは関数型プログラミングの考え方に通じるもので、コードをより表現豊かに、エラーが起きにくくしてくれることがよくあります。

三項演算子は、3つの式を組み合わせます。まず条件、次に条件が`true`のときに評価されて返される式（`?`で始まる`if`の部分）、そして条件が`false`のときに評価されて返される式（`:`で始まる`else`の部分）です。

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
