# HTTPの10億ドルの疑問

## 問題

与えられた国々（国の数は`N`）の中で、純資産額の上位`x`人の億万長者を見つけるよう依頼されました。それを実装するために、国ごとの億万長者の詳細を返すAPIへのアクセスが与えられています。

APIへのアクセスを簡単にするには、[`ims/billionairehub`クライアント](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client)コネクターを使って、国ごとの億万長者の詳細を返すAPIに接続できます。

```ballerina
    billionairehub:Client cl = check new ({auth: {clientId, clientSecret}});

    // TODO Write your logic here
    return [];
}
```

## 制約

* 1 <= N <= 5
* 1 <= x <= 10

## 例1

入力

```
Countries: ["United States"]
Limit: 3
```

出力

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## 例2

入力

```
Countries: ["China", "India"]
Limit: 5
```

出力

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## テスト環境

* 億万長者APIに接続するためのクライアントIDとクライアントシークレットは、`tests/Config.toml`に用意されています。それらを使ってクライアントを初期化できます。
* `bal test`を使って、実装を実行してテストしましょう。

## ヒント

* `ims/billionairehub`パッケージの[クライアント](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client)を使って、国ごとの億万長者を取得するAPIを呼び出せます。具体的には、`getBillionaires("<country>")`リモートメソッドを使います。
* まず国ごとの最も裕福な人々を見つけ、それらを組み合わせて上位`x`人を見つけることができます。
* [クエリ式](https://ballerina.io/learn/by-example/query-expressions/)は、フィルタリングと並べ替えに便利です。
