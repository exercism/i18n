# 説明

[アームストロング数][armstrong-number]とは、それぞれの桁の数字を桁数乗したものの合計に等しい数のことです。

たとえば、次のようになります。

- 9はアームストロング数です。`9 = 9^1 = 9`だからです。
- 10はアームストロング数では*ありません*。`10 != 1^2 + 0^2 = 1`だからです。
- 153はアームストロング数です。`153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`だからです。
- 154はアームストロング数では*ありません*。`154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`だからです。

ある数がアームストロング数かどうかを判定するコードを書いてみましょう。

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
