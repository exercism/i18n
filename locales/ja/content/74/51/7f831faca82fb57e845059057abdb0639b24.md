# 説明の補足

## レジスタ

| レジスタ | 用途   | 型     | 説明                                    |
| -------- | ------ | ------ | --------------------------------------- |
| `$a0`    | 入力   | アドレス | バケットの容量を並べたワード配列              |
| `$a1`    | 入力   | 整数   | 開始バケット（1または2）                      |
| `$a2`    | 入力   | 整数   | 目標の量                                 |
| `$a3`    | 入出力 | アドレス | 最終的なバケットの中身を並べたワード配列       |
| `$v0`    | 出力   | 整数   | 必要な操作の数。不可能な場合は-1              |
| `$t0-9`  | 一時的 | 任意   | 一時的な保存に使います                       |
