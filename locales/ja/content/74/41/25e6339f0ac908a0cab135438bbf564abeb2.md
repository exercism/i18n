# 説明

この演習では、[囲碁のルール](https://matmoore.github.io/learngo/)を適用していきます。ルール自体はすでに書かれているので、あとはそれらを適用して`Game`を更新し、エラーやルール違反を処理するだけです。

ゲームは次のように表されます。

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

ゲームには4つのルールがあります。

- 1つの交点に置ける石は1つだけです（`oneStonePerPointRule`）
- 相手の石を取ることができます！（`captureRule`）
- 自分自身を取ってしまうような場所には石を置けません（`libertyRule`）
- 同じ交点を2度使うことはできません（`koRule`）

## 1. ルールを適用する

`applyRules`関数の中身を書いてください。この関数は、初期状態の`Game`とルールの集まりを受け取り、ルールを適用したあとの新しい`Game`を返します。

`oneStonePerPointRule`・`libertyRule`・`koRule`はいずれもルール違反をチェックし、エラーを返すことがあるため、戻り値の型は`Result String Game`です。これらのルールのいずれかが失敗した場合は、元のゲームを返しますが、`error`フィールドには該当するエラーを設定します。

`captureRule`は違反をチェックしないので失敗することはなく（ただし、変更された`Game`を返すことはあります）、戻り値の型は`Game`です。

すべてのルールを通過した場合は、ルールによる`Game`の変更をすべて保持し、プレイヤーを変更します。これを行うための`changePlayer`関数が用意されています。

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
