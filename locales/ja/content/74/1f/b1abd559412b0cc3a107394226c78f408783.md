# 概要

パースとは、テキストを意味のあるデータに変換する処理のことです。
その点、`String`パッケージの関数ではできることに限りがあり、正規表現も扱いにくいため、Elmでパースするときの定番の方法は`elm/parser`パッケージを使うことです。

プログラミング言語[LOLCODE][lolcode]（の一部）をパースするパーサーを書く例を、一緒に見ていきましょう。
次のコメント付きのプログラムを考えてみます。

```
HAI 1                 # program version 1
CAN HAS STDIO?        # import stdio
VISIBLE "HAI WORLD!"  # print "HAI WORLD!"
KTHXBYE               # end of program
```

まず、考えられるコマンドを表すElmの型を書きましょう。

```elm
type Command
    = Version Int
    | Import String
    | Print String
```

そうすると、このLOLCODEプログラムは`List Command`として表せます。
まずは`HAI 1`の行をパースするパーサーから始めましょう。

```elm
versionP : Parser Command
versionP =
    Parser.succeed Version
        |. Parser.keyword "HAI"
        |. Parser.spaces
        |= Parser.int
```

`versionP`は、_パーサーのパイプライン_を使って組み立てられています。
`(|.)`演算子は「文字列をパースするけれど結果は捨てる」、`(|=)`は「文字列をパースして結果を保持する」という意味です。
この例では、`Parser.keyword "HAI"`が`HAI`を消費しますが、その結果は無視されます。
`Parser.spaces`は`' '`、`'\n'`、`'\r'`の文字をいくつでも消費しますが、これも無視されます。
`Parser.int`は整数をパースし、その整数の値（たとえば1）が一番外側の`Parser.succeed Version`に渡されて、パーサーは`Version 1`という値を返して成功します。

パイプラインの中のどれか1つのパーサーが失敗すると、`Parser.DeadEnd`が返り、パーサー全体が失敗します。
パーサーは`Parser.run`で実行できます。

```elm
Parser.run versionP "HAI 1"
    --> Ok (Version 1)
Parser.run versionP "HAI 2"
    --> Ok (Version 2)
Parser.run versionP "BYE 2"
    --> Err [{ problem = ExpectingKeyword "HAI", col = 1, row = 1 }]
Parser.run versionP "HAI MOM"
    --> Err [{ problem = ExpectingInt, col = 5, row = 1 }]
```

次は`CAN HAS STDIO?`の行を、このようにパースしてみましょう。

```elm
importP : Parser Command
importP =
    Parser.succeed Import
        |. Parser.keyword "CAN HAS"
        |. Parser.spaces
        |= packageP
        |. Parser.symbol "?"
```

`importP`もパーサーのパイプラインですが、今回は最後が`Parser.symbol`になっていて、`?`のような記号をパースするのに向いています。
保持したい値（インポートするパッケージの名前）は、次のようにしてパースします。

```elm
packageP : Parser String
packageP =
    Parser.chompWhile Char.isAlphaNum
        |> Parser.getChompedString
        |> Parser.map String.toLower
```

パッケージ名が何になるかわからないので、`Parser.keyword`は使えません。そこで`Parser.chompWhile`を使います。これは、条件を満たす限り（ここでは英数字であること）1文字ずつ消費します。
こうして消費された文字は、`Parser.getChompedString`が集めて`Parser String`を返します。
ここではパッケージ名を正規化したいので、`Parser.map`を使ってパーサーの中の文字列を変更し、小文字にします。

```elm
Parser.run importP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS StDiO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS STDIO"
    -->  Err [{ problem = ExpectingSymbol "?", col = 14, row = 1 }]
```

続いて`VISIBLE "HAI WORLD!"`は、次のようにパースされます。

```elm
printP : Parser Command
printP =
    Parser.succeed Print
        |. Parser.keyword "VISIBLE"
        |. Parser.spaces
        |. Parser.symbol "\""
        |= stringP
        |. Parser.symbol "\""

stringP : Parser String
stringP =
    Parser.chompWhile (\c -> c /= '"')
        |> Parser.getChompedString

Parser.run printP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
```

これで、コマンドごとにパーサーができました。
もちろん、実際のプログラムではこれらのコマンドの順序は予測できないので、汎用的なコマンドのパーサーを作ります。

```elm
commandP : Parser Command
commandP =
    Parser.oneOf
        [ versionP
        , importP
        , printP
        ]
```

`Parser.oneOf`は、与えられた順にパーサーを1つずつ試します。
パーサーが失敗すると次のパーサーを試しますが、成功した場合はその結果を返し、残りのパーサーは試しません。
すべてのパーサーが失敗すると、`Parser.oneOf`も失敗します。

```elm
Parser.run commandP "HAI 2"
    --> Ok (Version 2)
Parser.run commandP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run commandP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
Parser.run commandP "O NOES"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 1 }
    --      ]
```

失敗した試行がそれぞれ`Parser.DeadEnd`を生成し、それが`Parser.oneOf`に集められている点に注目してください。

プログラム全体をパースするには、複数のコマンドを順番にパースする必要があります。

```elm
programP : Parser (List Command)
programP =
    Parser.sequence
        { start = ""
        , separator = "\n"
        , end = "KTHXBYE"
        , spaces = Parser.succeed ()
        , item = commandP
        , trailing = Parser.Optional
        }
```

`Parser.sequence`は、さまざまなオプションを指定できる自由度の高いパーサーです。
`start`、`separator`、`end`には、並びの中の項目を区切る文字列を渡します。Elmのリストをパースするなら`"["`、`","`、`"]"`を渡すことになります。
`spaces`には、項目と区切り文字の間に入るかもしれない空白を扱うパーサーを渡すことで、柔軟に対応できます。Elmのリストをパースするなら`Parser.spaces`を使いますが、今回は空白を一切受け付けないので、何も消費せずにすぐ成功する`Parser.succeed ()`を使います。
`item`には項目のパーサーを渡し、最後に`trailing`で、末尾の区切り文字を`Parser.Forbidden`、`Parser.Mandatory`、`Parser.Optional`のどれにするかを決められます。

```elm
Parser.run programP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run programP "KTHXBYE"
    --> Ok []
Parser.run programP "HAI 2\nCAN HAS STDIO?\n"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 3 }
    --      , { problem = Expecting "KTHXBYE", col = 1, row = 3 }
    --      ]
```

パーサーは成功すると、そこで文字列の消費をやめます。

```elm
Parser.run Parser.int "1"
    --> Ok 1
Parser.run Parser.int "1 BTW VISIBLE \"U SEE NOTHING\""
    --> Ok 1
```

そのため、文字列を最後までパースしたことを確認したいときは、`Parser.end`を使います。

```elm
fullProgramP : Parser (List Command)
fullProgramP =
    programP
        |. Parser.spaces
        |. Parser.end

Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE\nBTW VISIBLE \"U SEE NOTHING\""
    --> Err [{ problem = ExpectingEnd, col = 1, row = 4 }]
```

最後に、パースした内容によってパーサーを失敗させたいこともあります。
たとえば、`HAI`コマンドが2つ続けて出てくるプログラムを失敗させるパーサーが必要なら、次のように書けます。

```elm
singleVersionProgramP : Parser (List Command)
singleVersionProgramP =
    fullProgramP
        |> Parser.andThen
            (\commands ->
                case commands of
                    (Version _) :: (Version _) :: _ ->
                        Parser.problem "Multiple versions defined"

                    _ ->
                        Parser.succeed commands
            )
```

`Parser.andThen`はパーサーの内容を調べて、その値に応じて新しいパーサーを返すことができます。
ここでは、一方のケースでは`Parser.problem`を使って独自のメッセージでパーサーを失敗させ、もう一方では元の値をそのまま返しています。

```elm
Parser.run singleVersionProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run singleVersionProgramP "HAI 1\nHAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Err [{ problem = Problem "Multiple versions defined", col = 8, row = 4 }]
```
