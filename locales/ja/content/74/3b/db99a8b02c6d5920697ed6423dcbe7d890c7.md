# PaySwitch - 給与コンバーター

## 問題

**Insure Everyone**という会社は、従業員に外貨で給与を支払っています。しかし、法律の要件により、給与は現地通貨に換算しなければなりません。従業員は世界中にいます。
Insure Everyoneの人事部は、各従業員の給与をそれぞれの現地通貨に換算するプログラムを作るため、優秀なエンジニアの助けを求めています。Insure Everyoneは、外部APIが提供する為替レートを利用しています。

外部の為替レートAPIが与えられたとき、`source currency`、`salary`（ソース通貨での金額）、従業員の`local currency`を受け取り、現地通貨での給与を返す関数を書く必要があります。

## 制約

* 500 <= `salary` <= 10000
* `sourceCurrency`と`targetCurrency`は[ISO通貨コード（アルファベット）](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)です。テスト入力には無効な通貨コードが含まれることがあります。
* 返されるレートの精度は、小数点以下`5`桁まで測定されます。

## 例

### 例1

#### 入力：
* 給与: 1000
* ソース通貨: USD
* ターゲット通貨: GBP

#### 出力：

外部の為替レートAPIが次の為替レートのレスポンスを返したとします（省略）：

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

このとき、関数は`735.84000`を返す必要があります。

### 例2

#### 入力：

* 給与: 1000
* ソース通貨: GBP
* ターゲット通貨: USD

#### 出力：

外部の為替レートAPIが次の為替レートのレスポンスを返したとします（省略）：

```json
{
    "base": "GBP",
    "rates": {
        // omitted
        "USD": 1.35898,
        // omitted
    }
}
```

このとき、関数は`1358.9800`を返す必要があります。
