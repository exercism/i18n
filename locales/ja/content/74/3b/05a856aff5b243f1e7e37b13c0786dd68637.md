# スレッド

## Tcl固有のスレッド情報

スレッドを使った並列処理を実装します。入力をチャンクに分割し、スレッドで動くコードがそれらを非同期的に調べられるようにします。

Tclのスレッドについての参考資料をいくつか挙げます。

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf)、
  _Practical Programming in Tcl and Tk, 4th Ed._からの1章
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * 注：この章には「Tclのバイナリ配布物のほとんどはスレッドが有効になっていません」と書かれていますが、現在はそうではありません。Tclの配布物はスレッドをサポートした状態でビルドされるようになりました（参照：[TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md)）
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm)（Tclのドキュメントより）
