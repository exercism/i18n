# 指示

庭に何羽の鳥が訪れたかを記録するのが日課の、熱心なバードウォッチャーです。
ふだんはノートに正の字を書いて鳥を数えていますが、データを扱いやすくするために、ここ数週間の鳥の数をデジタル化しました。

## 1. これまでに数えた鳥の合計を求める

まずは全体像をつかむことから、データの分析を始めましょう。
記録を始めてから数えた鳥の合計を求めてください。

1日ごとの鳥の数を含む`int`のスライスを受け取る関数`TotalBirdCount`を実装します。
この関数は、数えた鳥の合計を返す必要があります。

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. 特定の週に訪れた鳥の数を計算する

鳥の数の全体像がつかめたので、次はより細かい分析をしてみたくなります。

1日ごとの鳥の数のスライスと週番号を受け取る関数`BirdsInWeek`を実装します。

この関数は、その週に数えた鳥の合計を返します。
週は常に完全に記録されているものとします。

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. 数え間違いを修正する

鳥を記録している間ずっと、庭の遠くの隅に隠れている鳥が1羽いたことに気づきました。

この鳥は、1日おきにいつも庭で過ごしていたことがわかりました。

その間の日にどこにいたのかは正確にはわかりませんが、庭にいなかったことは確かです。

バードウォッチャーとしての勘で、リストで記録を始めた最初の日には、この鳥が庭にいたこともわかっています。

この新しい情報をもとに、1日ごとに数えた鳥のスライスを引数として受け取り、数え間違いを修正したスライスを返す関数`FixBirdCountLog`を書いてください。

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
