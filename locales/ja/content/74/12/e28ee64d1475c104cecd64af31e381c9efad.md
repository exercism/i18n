# `for`ループ入門

[`for`ループ](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)は、ある条件を満たすまで複数の文を繰り返し実行するための仕組みです。
ループは4つの部分からなります。

```java
for (initialization; test; update) {
    body;
}
```

`initialization`はループの初期状態を設定するもので、ループの開始時にちょうど1回だけ実行されます。
通常は、`test`式と`update`式で使う変数を宣言して代入します。
たとえば、次のとおりです。

```java
int i = 1
```

`test`式は、ループを終了すべきかどうかを判定します。
評価結果が`true`なら、本体が実行され、続いて`update`式が実行されます。
`false`なら、本体も`update`式も実行されず、実行はループを閉じる波括弧（`}`）の後ろから再開します。
通常は、`initialization`で代入した変数を確認します。
たとえば、次のとおりです。

```java
i <= 10
```

ループの本体を実行したあと、`update`式が実行されます。
通常は、ループ変数を何らかの値だけ増やしたり減らしたりします。
たとえば、次のとおりです。

```java
i++
```

最初の4つの平方数を出力する`for`ループは、次のようになります。

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

出力は次のようになります。

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

コレクションのすべての要素を繰り返し処理する場合は、`for-each`ループのほうが適していますが、次のように`for`ループでも書けます。

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for`ループには、`for-each`ループに比べていくつかの利点があります。

- 好きなインデックスから開始したり、そこで終了したりできます。
- 好きな（真偽値の）終了条件を使えます。
- ループ変数の増やし方を工夫して、要素を飛ばすことができます。
- カウントダウンして、コレクションを後ろから前へ処理できます。
- コレクションを使わない場面でも`for`ループを使えます。
