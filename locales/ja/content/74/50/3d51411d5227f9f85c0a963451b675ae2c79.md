# 概要

0個以上の要素を保持できるデータ構造は、_コレクション_と呼ばれます。**配列**は、サイズ（長さ）が固定されていて、要素がすべて同じ型でなければならないコレクションです。要素は、インデックスを使って配列に代入したり、配列から取り出したりできます。C#の配列は0から始まるため、最初の要素のインデックスは常に0です。

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

配列は、配列の作成と値の設定を同時に行える省略記法でも定義できます。コンパイラーが配列の要素数を判断できるようになったため、長さは省略できます。

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

配列は、配列インスタンスの[メソッド][array-methods]や[プロパティ][array-properties]を呼び出すか、[`Array`クラス][array-class]で定義されている静的メソッドを使うことで操作できます。

## 繰り返し

配列もまた_コレクション_です。つまり、[`foreach`ループ][foreach-statement]を使えば、その_すべて_の値を繰り返し処理できます。

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

[`for`ループ][for-statement]を使って配列を繰り返し処理することもできます。

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

ただし、一般的には、次の理由から`for`ループよりも`foreach`ループが好まれます。

- `foreach`ループは、_すべて_の値を繰り返し処理することが保証されています。`for`ループでは、たとえばオフバイワンエラーによって要素を取りこぼしやすくなります。
- `foreach`ループはより_宣言的_です。コードは_何_をしたいのかを伝えますが、`for`ループは_どのように_したいのかを伝えることになります。
- `foreach`ループは間違いが起きにくいのに対し、`for`ループではオフバイワンエラーが起きやすくなります。
- `foreach`ループは、インデクサーを使った要素へのアクセスに対応していないものを含め、すべてのコレクション型で使えます。

`foreach`ループが_すべて_の値を繰り返し処理することを保証するため、コンパイラーは`foreach`ループの中でコレクションを更新することを許可しません。

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`ループには、`foreach`ループよりも優れている点がいくつかあります。

- 好きなインデックスから開始したり、終了したりできます。
- 任意の（真偽値の）終了条件を使えます。
- ループ変数の増分を工夫することで、要素をスキップできます。
- カウントダウンすることで、コレクションを後ろから前に処理できます。
- コレクションを扱わない場面でも`for`ループを使えます。
