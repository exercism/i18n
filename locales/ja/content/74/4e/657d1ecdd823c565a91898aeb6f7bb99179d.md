# 指示

この演習では、名作ゲーム『パックマン』のルールをC++の関数に翻訳していきます。

翻訳するルールは4つあり、いずれもゲームの状態に関係しています。

> 引数がどのようにして作られるかは気にしなくて大丈夫です。引数を組み合わせて、意図した結果を返すことだけに集中しましょう。

## 1. パックマンがゴーストを食べられるかどうかを定義しましょう

2つの引数（パックマンがパワーペレットの効果を発動中かどうか、パックマンがゴーストに触れているかどうか）を受け取り、パックマンがそのゴーストを食べられるかどうかを表す真偽値を返す`can_eat_ghost`関数を定義しましょう。この関数は、パックマンがパワーペレットの効果を発動中で、かつゴーストに触れているときだけ`true`を返すようにします。

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. パックマンが得点するかどうかを定義しましょう

2つの引数（パックマンがパワーペレットに触れているかどうか、パックマンがドットに触れているかどうか）を受け取り、パックマンが得点したかどうかを表す真偽値を返す`scored`関数を定義しましょう。この関数は、パックマンがパワーペレットかドットに触れているときに`true`を返すようにします。

```cpp
scored(true, true);
// => true
```

## 3. パックマンが負けるかどうかを定義しましょう

2つの引数（パックマンがパワーペレットの効果を発動中かどうか、パックマンがゴーストに触れているかどうか）を受け取り、パックマンが負けたかどうかを表す真偽値を返す`lost`関数を定義しましょう。この関数は、パックマンがゴーストに触れていて、パワーペレットの効果を発動中でないときに`true`を返すようにします。

```cpp
lost(false, true);
// => true
```

## 4. パックマンが勝つかどうかを定義しましょう

3つの引数（パックマンがすべてのドットを食べたかどうか、パックマンがパワーペレットの効果を発動中かどうか、パックマンがゴーストに触れているかどうか）を受け取り、パックマンが勝ったかどうかを表す真偽値を返す`won`関数を定義しましょう。この関数は、パックマンがすべてのドットを食べていて、かつ3で定義した引数に基づいて負けていないときに`true`を返すようにします。

```cpp
won(false, true, false);
// => false
```
