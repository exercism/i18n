# プレースホルダー

## bashで解くには

`bash`には、日時の文字列を**解析**する組み込みの方法がありません。
この演習では、外部のユーティリティを呼び出す必要があります。

* GNUの`date`コマンドの`-d`オプションは、[さまざまな形式][gnu-date]を解析できます。
* Macをお使いの場合は、[BSDの`date`コマンド][bsd-date]とその`-f`オプションを参照してください。
* Perlは広く利用可能で、その[`Time::Piece`モジュール][time-piece]を使ってタイムスタンプを解析できます。

bashは、外部ツールなしで日時を**フォーマット**できます。
整数の時刻の値（エポックからの秒数）があれば、[`printf`の`%()T`フォーマッター][bash-printf]で「strftime」形式のフォーマットを適用できます。

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
[time-piece]: https://perldoc.pl/Time::Piece
