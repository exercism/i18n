# 概要

Common Lispでは、関数は1つの値だけでなく、複数の値を返すことができます。
たとえば、ゼロに向かって切り下げる`floor`は2つの値を返します。1つ目は切り下げた値で、2つ目は余りです。

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
（複数の戻り値は、出力では別々の行に表示します。）

## 複数の値を返す

関数に複数の値を返させたいときは、`values`アクセサーを使います。

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

返したい値のリストがあるときは、`value-list`が使えます。

```lisp
(values-list '(a b c)) ; => a
                       ;    b
                       ;    c
```
## 複数の値を扱う

1つ目の値だけが必要なら、特別なことは何もする必要はありません。言語がうまく処理してくれます。

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

ただし、それ以外の値にアクセスしたい場合は、いくつかの関数を使う必要があります。

主なマクロは`multiple-value-list`と`multiple-value-bind`の2つです。
これらは、複数の値を返すものを包み込んで、すべての値を取り出すために使います。
1つ目は、すべての値のリストを作ります。
2つ目は、それぞれの値に変数を束縛できます。

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

`a`、`b`、`c`という変数は、`multiple-values-bind`の内側でのみスコープに入ることに注意してください。

もう1つ便利なマクロが`nth-value`です。これはリストに対する`nth`と同じように、複数の値の中から「n番目」の項目を返します。

```lisp
(nth-value 0 (values 1 2 3 )) ; => 1
(nth-value 1 (values 1 2 3 )) ; => 2
(nth-value 2 (values 1 2 3 )) ; => 3
```
