# インストール

## Mac

Homebrewを使う場合は、`brew install swi-prolog`でインストールします。
または、お使いのマシン用のソースを[SWI Prologのウェブサイト](http://www.swi-prolog.org/download/devel)からダウンロードしてください。

## Windows

お使いのマシン用のソースを[SWI Prologのウェブサイト](http://www.swi-prolog.org/download/devel)からダウンロードしてください。

## Linux

お使いのディストリビューション向けの手順については、[こちら](http://www.swi-prolog.org/build/unix.html)を参照してください。
