# 説明

この演習では、フリーランスがプロジェクトマネージャーとやり取りするのを手助けするコードを書きます。日額と月額をすばやく計算するためのいくつかのユーティリティを提供し、必要に応じて指定した割引を適用できるようにします。

まず、フリーランスとプロジェクトマネージャーの間でルールをいくつか決めておきます。

日額は時給の8倍です。
1か月の請求対象日数は22日です。
プロジェクトマネージャーがフリーランスに月単位での請求を選んだ場合、フリーランスは割引の適用を提案しています。これは、プロジェクトマネージャーがやりくりしなければならない予算があるときに役立ちます。

割引は、パーセンテージを表す小数として扱います。たとえば25.0（25%）です。

## 1. 時給から日額を計算する

時給から日額を計算する関数を実装しましょう。

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

返される日額は小数にします。

## 2. 割引後の価格を計算する

割引後の価格を計算する関数を実装しましょう。

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

返される値は常に小数で、いかなる丸めも行いません。

## 3. 時給と割引から月額を計算する

月額を計算し、割引を適用する関数を実装しましょう。

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

返される月額は、最も近い整数に切り上げます（天井関数を使います）。

## 4. 予算、時給、割引から作業日数を計算する

予算、時給、割引を受け取り、それで何日分の作業をまかなえるかを計算する関数を実装しましょう。

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

返される日数は、小数点以下1桁に切り下げます（床関数を使います）。
