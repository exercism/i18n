# 演習の補足

## レジスター

| レジスター | 用途     | 型   | 説明                             |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | 入力     | 整数 | 1..64の範囲のマス番号 |
| `$v0`    | 出力     | 整数 | 出力の下位32ビット |
| `$v1`    | 出力     | 整数 | 出力の上位32ビット |
| `$t0-9`  | 一時     | 任意 | 一時的な保存用 |
