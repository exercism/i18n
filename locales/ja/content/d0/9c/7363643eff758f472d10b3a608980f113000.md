# 説明

知り合いのErinは、複数のイベントのために何千枚ものチラシを印刷する必要があり、助けを求めています！　Erinから、ヘッダー、任意の日付、そしてアーティストのリスト（それぞれに_Unicodeアイコン_が対応します）を含むリーフレットのレイアウトを作ってほしいと頼まれました。目標は、クールな新しいリーフレットデザインを`print`して配布することです。成功するには、Pythonの文字列フォーマットのスキルを総動員する必要があります。

## 1. 先頭を大文字にしたヘッダーを持つクラスを作成する

`capitalize_header`関数は、イベント名を1つ受け取り、そのイベント名の先頭を大文字にしたものを返します。

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. 日付をフォーマットする

新しいメソッド`format_date`を作成します。このメソッドは、日、月、年を含むリストを1つ受け取ります。フォーマットされた日付を`<month_name> <date>, <year>`という形式で表示します。

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. Unicodeコードポイントをアイコンとしてレンダリングする

メソッド`display_icons`が呼び出されると、渡されたUnicodeコードポイントのリストが_アイコン_の`list`としてレンダリングされ、返されます。

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. 完成したリーフレットを表示する

ここで、これまでのすべての関数を使い、それらを`print_leaflet`関数にまとめます。この関数は、`event_name`、`icons`のリスト、`authors`のリスト、`event_date`のリストを受け取ります。

ポスターは以下のレイアウトに従う必要があります。

リーフレットは、長方形の形をした特定のレイアウトに従います。

- 最初と最後の行には、20個のアスタリスクが入ります。`"*"`
- 各セクションは、その上と下を空の行で区切られます。
- 空の行には、先頭に1つ、末尾に1つのアスタリスクだけが入ります。
- 最初のセクションはリーフレットのヘッダーで、このタイトルは先頭を大文字にします。
- 2番目のセクションは任意の日付です。日付が渡されなかった場合、このセクションは空の行になります。
- 3番目、つまり最後のセクションはアーティストのリストで、各アーティストには対応するアイコンが付きます。

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
