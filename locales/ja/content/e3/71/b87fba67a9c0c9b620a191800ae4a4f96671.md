# ヒント

## 概要

- Erlangのライブラリの使い方については、[公式のGetting Startedガイド][getting-started-erlang-libraries]を読んでください。特に、[文字列のフォーマット][getting-started-formatted-text-output]について書かれています。

## 1. ランダムな惑星を生成する

- 惑星クラスを表す文字のリストを持つ、用意されたモジュール属性を使いましょう。
- リストから要素をランダムに選ぶ[組み込み関数][enum-random]があります。

## 2. ランダムな宇宙船の登録番号を生成する

- 範囲から要素をランダムに選ぶ[組み込み関数][enum-random]があります。

## 3. ランダムな宇宙暦を生成する

- ランダムな小数を返すElixirの関数はありません。
- `0.0 <= x < 1.0`を満たすランダムな小数xを返す、[Erlangの組み込み関数][erl-rand-uniform]があります。
- `x`が`0.0 <= x < 1.0`の範囲にあり、別の範囲`a <= x < b`の数値が必要な場合は、範囲の幅（`b - a`）を掛けて、範囲の始まり（`a`）を足すことで、xの範囲をずらせます。つまり、`x * (b - a) + a`です。

## 4. 宇宙暦をフォーマットする

- 小数を指定した精度の文字列に一度にフォーマットできるElixirの関数はありません。
- フォーマット文字列とデータのリストを受け取り、charlistを返す[Erlangの組み込み関数][erl-io-lib-format]があります。
- charlistを文字列に変換する[組み込み関数][to-string]があります。
- その関数のフォーマット文字列には、制御シーケンスが含まれています。
- 制御シーケンスは`~`で始まり、`~F.P.PadModC`というパターンを持ちます。ここで、`F`は出力の幅、`P`は精度、`Pad`は埋め込み文字、`Mod`は制御シーケンスの修飾子、`C`は制御シーケンスの種類を表します。
- 小数を目的の精度でフォーマットするには、`~.PC`というパターンの制御シーケンスで十分です。
- 小数の制御シーケンスの種類は`f`です。
- 必要なフォーマット文字列は、まさに`~.1f`です。
