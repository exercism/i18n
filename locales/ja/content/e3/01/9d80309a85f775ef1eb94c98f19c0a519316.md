# 学習

Exercismでは演習とフィードバックを提供していますが、Common Lispを初めて学ぶ人にとっては、なかなか飛び込みにくいかもしれません。次のリソースが、始める助けになります。

* [A Road to Common Lisp][road-to-cl]は、ある人がCommon Lispにたどり着くまでの道のりと、その始め方についての考えをまとめたブログ記事です
* [Practical Common Lisp][practical-cl]は、Common Lispを学ぶための完結した書籍で、オンラインで無料で読めます（紙の本もあります）
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  さまざまな執筆者による
* [Awesome Common Lisp Learning][awesome-cl]

関連して、このExercism Common Lispトラック内の[重要なリソース][track-resources]も参照してください。
