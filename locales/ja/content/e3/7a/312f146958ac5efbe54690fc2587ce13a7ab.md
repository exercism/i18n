# 説明の補足

## 例外メッセージ

[例外を送出する](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要がある場合があります。そのときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。これにより、コードが読みやすくなり、デバッグがとても楽になります。エラーの原因がある型だとわかっている場合は、[組み込みのエラー型](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを送出する方法もありますが、その場合も意味のあるメッセージを含めるようにしましょう。

この演習では、無効な座標が与えられたときに、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「送出」する必要があります。テストに合格するには、`exception`を`raise`し、かつメッセージを含める必要があります。

メッセージ付きで`ValueError`を送出するには、そのメッセージを`exception`型の引数として書きます。

```python
# when the coordinates for the piece are invalid
raise ValueError('Invalid coordinate')
```
