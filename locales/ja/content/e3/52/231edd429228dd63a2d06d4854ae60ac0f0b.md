# インストール

## 対象バージョン

このトラックのテストには`alpine:3.24.1`のDockerイメージを使っており、2026年9月時点では`sqlite3 version 3.53.4`が使われています。
このトラックが提供するツールは、最新のUbuntu LTSリリースで動作するように努めています。
より新しいバージョンをインストールしている場合もありますが、一部の機能は私たちのテストランナーでは動作しない可能性があることに注意してください。
機能の違いは[SQLiteのバージョン履歴][version-history]で比較できます。

## Windows

WindowsにSQLiteをインストールするには、次の手順に従ってください。

1. [公式ダウンロードページ][sqlite-download]から、コンパイル済みのWindows用バイナリをダウンロードします。
2. ダウンロードしたZIPファイルを、好きなディレクトリに展開します。
   たとえば`C:\Program Files\sqlite3`です。
3. `sqlite3.exe`が含まれるディレクトリを、システムのPATH環境変数に追加します。
   手順はWindowsのバージョンごとに少し異なりますが、検索すればすぐに見つかるはずです。
   たとえば、[Windows 11の手順][windows-11-install]や[Windows 10の手順][windows-10-install]があります。

## macOS

macOSにはSQLiteが最初からインストールされています。
ただし、より新しいバージョンが必要な場合は、[Homebrew][homebrew]を使えます。

```bash
brew install sqlite
```

## Ubuntu / Debian

UbuntuおよびDebian系のシステムでは、aptを使ってSQLiteをインストールできます。

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

CentOS、Fedora、Red Hat系のシステムでは、yumまたはdnfを使ってSQLiteをインストールできます。

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Arch Linuxでは、pacmanを使ってSQLiteをインストールできます。

```bash
sudo pacman -S sqlite
```

## その他のインストール方法と古いバージョン

詳しい情報や別のインストール方法については、[SQLiteのダウンロードページ][sqlite-download]を参照してください。
`Build Product Names and Info`のセクションに、SQLiteの各バージョンの命名テンプレートがあるので、お好みの検索エンジンで目的のバージョンを検索できるはずです。
