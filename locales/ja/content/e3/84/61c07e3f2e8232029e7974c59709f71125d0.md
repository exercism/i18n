# はじめに

Javaは静的型付け言語です。つまり、変数の型はコンパイル時に決まっています。
値に名前を付けることを、変数の定義といいます。
変数を定義するときは、型を明示的に指定します。

```java
int explicitVar = 10;
```

変数の値の更新は、`=`演算子を使って行います。
ここでの`=`は、数学的な等号を表すものではありません。
単に、変数に値を代入するものです。
一度定義したら、変数の型を変更することはできません。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Javaは[オブジェクト指向言語][object-oriented-programming]であり、すべての関数を_クラス_の中で定義する必要があります。
クラスを定義するには、`class`キーワードを使います。

```java
class Calculator {
    // ...
}
```

クラスの中にある関数を、_メソッド_といいます。
メソッドは、0個以上の仮引数を持てます。
すべての仮引数には、型を明示的に指定する必要があり、仮引数に型推論はありません。
同様に、戻り値の型も明示する必要があります。
メソッドから値を返すには、`return`キーワードを使います。
ほかのクラスからメソッドを呼び出せるようにするには、`public`アクセス修飾子を付ける必要があります。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

メソッドを呼び出すには、そのクラス名とメソッド名を指定し、メソッドの仮引数それぞれに渡す値を指定します。

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Javaのスコープは、`{`と`}`の間に定義されます。

Javaでは2種類のコメントが使えます。
1行コメントは`//`で始まり、複数行コメントは`/*`と`*/`の間に書きます。

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
