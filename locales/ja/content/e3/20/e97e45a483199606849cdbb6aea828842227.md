# はじめに

Kotlinでは、クラスを使ってデータと振る舞いをカプセル化できます。
クラスは`class`キーワードで宣言します。
例えば：

```kotlin
class Car
```

クラスを呼び出すことで、そのインスタンスを作成できます。

```kotlin
val instance = Car()
```

## プロパティ

上の例では、`Car`クラスはプロパティなしで宣言されていました。
クラスのプロパティは、クラス本体の`{}`の間に宣言できます。可変プロパティには`var`を、不変プロパティには`val`を使います。
例えば：

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

別の方法として、プロパティを引数に取るコンストラクターで定義することもできます。

## コンストラクター

Kotlinには、プライマリーコンストラクターとセカンダリーコンストラクターという2種類のコンストラクターがあります。
プライマリーコンストラクターは、クラス宣言と同じ行で宣言します。
例えば：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

アノテーションも可視性修飾子もない場合は、`constructor`キーワードを省略できます。

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlinでは、プロパティだけを含む場合、クラス本体を省略して定義できます。波括弧`{}`は必要ありません：

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

クラスが持てるプライマリーコンストラクターは1つだけです。
セカンダリーコンストラクターは追加のコンストラクターで、クラス本体で`constructor`キーワードを使って宣言することで追加できます。
例えば：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

セカンダリーコンストラクターは、`this`を呼び出してプライマリーコンストラクターを呼び出す必要があります。

## 初期化ブロック

プライマリーコンストラクターはクラスのプロパティを設定します。
オブジェクトの作成時にもっと処理が必要な場合は、`init`ブロックを使って追加の操作を行えます。

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## 関数

関数はクラス本体で定義できます。
例えば：

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## 可視性

プロパティと関数は、`private`、`public`、`internal`、`protected`のいずれかになります。

- `private`はクラス内からのみアクセスできます。
- `protected`はクラス内のものに加え、サブクラスからもアクセスできます。
- `internal`は同じモジュール内のものからアクセスできます。
- `public`はそのクラスを利用する他のコンポーネントからアクセスできます。

例えば：

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
