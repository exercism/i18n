# 説明

近くに「Tech Palace」という家電店があります。
店のオーナーは最近、マーケティングメッセージを表示したり、入り口でお客さんがいわゆる会員カードをスキャンしたときに特別な挨拶を表示したりするために、大きなディスプレイを設置しました。
このディスプレイはたくさんの小さなLEDライトでできていて、複数行のテキストを表示できます。

オーナーは、新しいディスプレイに表示するテキストを生成するコードについて、助けを必要としています。

## 1. ウェルカムメッセージを作成する

会員カードをスキャンするほとんどのお客さんに対して、オーナーはディスプレイに`Welcome to the Tech Palace, `に続けてお客さんの名前を大文字で表示したいと考えています。

お客さんの名前を受け取り、目的のメッセージを文字列として返す関数`welcome`を実装してください。

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. 飾り枠を追加する

たくさん買ってくれる常連のお客さん向けに、オーナーはウェルカムメッセージの前後に星の行を足して、表示をもっと華やかにしたいと考えています。
ただ、星を何個並べるかはまだ決まっていないので、そこは設定できるようにしたいそうです。

ウェルカムメッセージと、1行あたりの星の数を引数として受け取る関数`add_border`を書いてください。
返すのは3行の文字列で、1行目は指定した数の星、2行目は渡されたままのウェルカムメッセージ、3行目はまた星の行です。

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. 古いマーケティングメッセージを整える

この新しいディスプレイを設置する前、店にはよく似たディスプレイがありましたが、そちらは設定を変えられない固定の行しか表示できませんでした。
オーナーは、古いマーケティングメッセージのいくつかを新しいディスプレイでも再利用したいと考えています。
ところが、そのデータには、複数のディスプレイを積み重ねたときにテキストの位置をそろえるために使われた、ありがたくない空白文字がすでに含まれています。
そこで、メッセージを再利用できるように整える必要があります。

古いマーケティングメッセージを受け取る関数`clean`を実装してください。
この関数はまず、テキストの先頭と末尾にある空白文字をすべて取り除いてから、それを返します。

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
