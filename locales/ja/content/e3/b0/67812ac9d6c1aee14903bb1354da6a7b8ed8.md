# 概要

Factorでデータを受け渡す唯一の方法は、*データスタック*です。ワードは入力を取り出し、出力を積みます。どのワード定義も、その約束事を記した*スタック効果*を宣言します。

```factor
: restow ( a b -- b a ) swap ;
: discard-top ( a b -- a ) drop ;
```

`( … -- … )`の中に書かれている名前は読み手のためのもので、コンパイラーが確認するのは入力と出力の*数*です。数が合わなければコンパイル時エラーになります。これは、こうした宣言のない動的型付け言語では実行時エラーになってしまう種類のバグを捕まえてくれます。

スタックは位置で意味が決まるので、次のワードを実行する前に、その先頭を絶えず並べ替える必要があります。`kernel`の**シャッフルワード**が、まさにその役割を果たします。

```
dup   ( x   -- x x   )    ! duplicate the top
drop  ( x   --       )    ! discard the top
swap  ( x y -- y x   )    ! flip the top two
over  ( x y -- x y x )    ! copy the second item onto the top
nip   ( x y -- y     )    ! discard the second item
rot   ( x y z -- y z x )  ! roll the third item up to the top
```

シャッフルワードの一族はさらに広がります。逆方向に回す`-rot`、1つ深い位置の要素に働く`d`付きのいとこ（`dupd`、`swapd`）、ペアに対して働く`2`付きのいとこ（`2dup`、`2drop`、`2nip`）、そして`pick`や`tuck`などです。これらは後の演習で必要になったときに紹介します。一度にあまり多くのシャッフルワードに手を伸ばすのは、たいてい、*ローカル*（名前の付いた値）を使ったほうが読みやすいというサインです。

慣習として、ワードの名前には`lowercase-kebab-case`を使います。述語は`?`で終わって真偽値を返し（`even?`、`empty?`）、セッターは`>>name`、ゲッターは`name>>`と書きます。また、あるワードとその破壊的版は同じ名前を共有することがよくあり、区別は文脈によってのみなされます。
