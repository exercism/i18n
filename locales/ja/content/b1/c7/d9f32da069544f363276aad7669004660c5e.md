# ヒント

## 共通

- 読み書きに使うワードはすべて[`io.files`][io.files]にあり、そこで受け取る`utf8`エンコーディングは[`io.encodings.utf8`][utf8]から来ています。

## 1. すべての観測値を読み取る

- `file-lines`は、改行を取り除いた行の配列を返します。

## 2. 最新の観測値を探す

- `file-lines`で行を読み取り、次に（`sequences`から）`last`を取得します。

## 3. 生のログを読み取る

- `file-contents`は、改行も含めて、ファイル全体を1つの文字列として返します。

## 4. 観測値を記録する

- ファイルを追記用に開き、クォーテーションの中で観測値を`print`します：`with-file-appender ( path encoding quot -- )`。観測値はクォーテーションの中で使われ、pathはその前に消費されるので、`::`ローカルを使うと本体が読みやすくなります：`:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`。

## 5. ログを書き直す

- `set-file-lines`は、シーケンスの各要素をそれぞれの行に書き込み、改行は自動で追加してくれます。

[io.files]: https://docs.factorcode.org/content/vocab-io.files.html
[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
