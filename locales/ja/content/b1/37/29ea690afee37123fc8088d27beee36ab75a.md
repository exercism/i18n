# ジェネリッククラス

早い段階から、`ARRAY{STR}`、`FMAP{STR,INT}`、`FSET{STR}`を使ってきました。波括弧の中には、いつも型が入っていました。今度は、波括弧を自分で持つクラスを書きます。

## 問題

遺失物取扱所には、1つの物をしまえて、誰が届け出たかを覚えておける箱が必要です。セーター用の箱は、次のようになります。

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

そして水筒用に同じクラスをもう一度、電話用にもう一度。1語だけが違う3つのコピーです。

## 型パラメータ

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

クラス名のあとに付く`{T}`が**型パラメータ**です。`T`は型そのものではありません。`T`は、そのクラスを使うときに渡される型の代わりを務めるものです。クラスの内部では、`T`はほかの型名とまったく同じように使えます。

## 使ってみる

波括弧の中に型を指定します。

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}`と`LOST_BOX{INT}`は、別々の型です。一方を他方の必要な場所に置けば、コンパイラーが検出するエラーになります。それは、2つのクラスを手で書き出した場合とまったく同じです。実際、起きていることはまさにそれで、Satherは実際に使われた型ごとに、このパターンから別々のクラスを組み立てます。

ですから、実行時にコストはかかりませんし、型の情報も失われません。`jumper.item`は本当に`STR`であって、確認したり変換したりしなければならない何かではありません。

## 型パラメータが複数の場合

クラスは、カンマで区切って複数のパラメータを取ることができます。すでに見た`FMAP{K,T}`がその例です。

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## 名前の付け方

慣習として、大文字1文字を使います。物には`T`、キーには`K`、要素には`E`です。ライブラリーでも全体を通してこの文字が使われています。
