# はじめに

## 整数

Gleamには、整数と小数という2種類の数値があります。

整数は、小数点以下のない数値です。

```gleam
let integer = 3
// -> 3
```

Gleamには、整数を扱うための演算子がいくつかあります。

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## 小数

小数は、小数点以下に1桁以上の数字がある数値です。

```gleam
let float = 3.45
// -> 3.45
```

小数にも、専用の演算子があります。

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## モジュール

### モジュール

Gleamのコードはモジュールにまとめられており、1つのファイルが1つのGleamモジュールになります。

これまでは、`pub fn`という書き方で関数を定義してきました。これは、ほかのモジュールからも使える公開された関数を定義します。`fn`で定義した関数は、それを定義したモジュールの中だけで使える非公開の関数で、ほかのモジュールからは使えません。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleamのモジュールには名前があり、その名前は`src`または`test`ディレクトリ内のファイルパスにもとづいて決まります。

たとえば、`src\geometry\rectangle.gleam`（Windowsの場合）または`src/geometry/rectangle.gleam`（UNIX系OSの場合）で定義されたモジュールは、`geometry/rectangle`という名前になります。

### ほかのモジュールから関数をインポートする

ほかのモジュールで定義された関数にアクセスするには、インポートを使います。
そのモジュールをインポートすると、そのモジュールが公開しているすべての関数が使えるようになります。
ただし、どのようにアクセスするかは、モジュールのインポートのしかたによって変わります。

修飾インポートが既定で、そのようなモジュール内の関数（たとえば`gleam/list`モジュールの`map`関数）にアクセスするには、モジュール名を前に付けます（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

既定では、モジュールを指す名前はモジュール名の最後の部分で、この場合は`int`ですが、`as`キーワードを使うと変更できます。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非修飾インポートを使うと、そのモジュールが公開している関数に、接頭辞を付けずに直接アクセスできます。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

修飾インポートのほうが、関数がどこから来たのかが読み手にわかりやすく、名前の衝突も避けられるので、好まれます。


### 標準ライブラリ

Gleamには、充実した、よく整備された標準ライブラリがあります。ドキュメントは[hexdocs.pm/gleam_stdlib][docs]でオンライン公開されています。このリンクはどこかに保存しておきましょう。これから何度も使います！

ほとんどの組み込みデータ型には、そのデータ型を扱う関数を提供する対応するモジュールがあります。たとえば、整数には`gleam/int`モジュール、文字列には`gleam/string`モジュール、配列には`gleam/list`モジュールなどがあります。

[docs]: https://hexdocs.pm/gleam_stdlib/
