# 説明

この演習では、自動車工場の組み立てラインを分析するコードを書きます。

## 1. 1時間あたりに生産される正常な車の数を計算する

1時間あたりに生産される車の数と成功率を入力として受け取り、1時間あたりに正常に生産される車の数を計算する関数を実装してください。成功率はパーセンテージで、`0`から`100`の範囲で指定します：

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**注：**戻り値は浮動小数点数にしてください。

## 2. 1分あたりに生産される正常な車の数を計算する

1時間あたりに生産される車の数と成功率を入力として受け取り、1分あたりに正常に生産される車の数を計算する関数を実装してください：

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**注：**戻り値は整数にしてください。

## 3. 生産コストを計算する

各車を個別に生産するには、成功するかどうかに関わらず、通常$10,000かかります。しかし、少し工夫すれば、10台まとめて$95,000で生産できます。たとえば、37台は次のように生産できます：
37 = 10台のグループ3つ + 個別の車7台

したがって、37台のコストは次のようになります：
3 \* 95,000 + 7 \* 10,000 = 355,000

成功するかどうかに関わらず、指定された台数の車を生産するコストを計算する関数を実装してください：

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**注：**戻り値は整数にしてください。
