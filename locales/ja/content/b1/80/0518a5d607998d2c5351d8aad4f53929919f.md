# 説明

Lispエイリアンのリリーは、あなたの助けのおかげで、たくさんのラザニアを作ることができました。そのお礼に、残りものを少し分けてあげたいと思っています。でもその前に、あなたが手伝ってくれた関数のひとつについて、いくつかフィードバックがあります。

この演習では、リリーのラザニア作りを手伝い、さらに残りものをあなたと分け合えるようにするために、関数をいくつか追加で書いていきます。

タスクは6つあります。3つは既存のラザニア作りの関数を改善するもの、残りの3つは残りものを分けるものです。

## 1. `preparation-time-in-minutes`を使いやすくする

リリーによると、`preparation-time-in-minutes`は、関数を使う前にすべての層を数えなければならないので、少し使いにくかったそうです。リリーは、層を（何層でも）入力として受け取り、層の数に応じて準備時間を計算する、そういうバージョンの関数を作れないかと考えています。念のため、1層を準備するには19分かかります。

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. 予想されるオーブン時間を変更できるようにする

リリーの親はいつもラザニアを337分焼いていましたが、リリーも、他のLispエイリアンはもっと長く、あるいは短く焼くのが好きだと認めています。

そこで、`remaining-minutes-in-oven`が`expected-minutes-in-oven`を使うのではなく、時間を長め・かなり長め・短め・かなり短めのどれにするかを指定する_省略可能な_入力を受け取れるようにするとよいでしょう。長め・短めは、既定の337分から100を足すか引くことを意味します。かなり長め・かなり短めは、200を足すか引きます。入力が指定されない場合、または入力が'normal'の場合は、既定値の337を返すようにします。

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. リリーがもうひとつの好みの調理スタイルを思い出す

その変更を終えた直後、リリーは、_とても短い_調理時間を好むLispエイリアンもいることを思い出します。実質的に、生で食べたいのです。そこで、前のタスクと同じ値に加えて、入力が`NIL`だった場合は0を返すようにします。

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. 残りものを分ける

ラザニア作りの関数の改善を手伝ってもらったおかげで、_たくさんのラザニア_があります！　リリーは、あなたの助けに報いるために、残りものを分け合いたいと思っています。3つの入力を受け取る関数を書く必要があります。残りものの総量、リリーが食器棚で見つけた残りもの用の容器の数、そしてあなたが見つけた容器の数です。残りもの用の容器を探すのにかかる時間は人によって違い、また残りものの正確な量は、あなたとリリーがそれぞれの食器棚を探している間に決まるかもしれません。そこで二人は、関数が入力の順序を問わずに受け取れるようにしようと決めます。そうすれば、それぞれの数値が決まった時点で書き留めておけるからです。3つの数値がそろったら、関数呼び出しの括弧（`()`）を閉じて評価するだけです。

関数は、余った残りものの量、つまり残りものの重さと、あなたとリリーが見つけた容器の合計数との差を返します。

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. 仮定を置く

それぞれの食器棚に何度か往復したあと、二人は、入力が指定されなかった場合に、あなたまたはリリーが…たとえば10個の容器を持っていると_仮定_してくれると助かると考えます。

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. 標準的な残りものの量

さらに良いのは、容器に入りきるだけの残りものがあると関数が_仮定_してくれることです。つまり、重さが指定されなければ、関数は`:just-split-it`を返します。_ただし_、重さが指定されていて、それが`nil`の場合は`:looks-like-someone-was-hungry`を返します。

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
