# 概要

Haxeの[文字列][strings]は、テキストをUnicode文字（英字、数字、句読点など）の並びとして表すイミュータブルなオブジェクトです。`string`インスタンスを定義するには、ダブルクォートを使います。

```haxe
var fruit:String = "Apple";
```

文字列を操作するには、その[メソッドやプロパティ][string-api]のいずれかを呼び出します。文字列の値は一度定義されると変わることはないため、文字列を操作するメソッドはすべて新しい文字列を返します。

文字列はダブルクォート（`"`）で区切ります。特別な文字の中には、バックスラッシュ（`\`）を使って[エスケープ][escaping]する必要があるものがあります。さらに、Haxeの文字列は複数行にわたって記述でき、長い文字列リテラルを簡単に組み立てられます。

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

文字列を連結するもっとも簡単な方法は、[`+`演算子][plus-operator]を使うことです。

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

より複雑な文字列の整形には、[文字列補間][interpolation]が好まれます。これは、文字列をシングルクォート（`'`）で囲み、ドル記号（`$`）で変数の補間を行うものです。`${expr}`を使えば、式全体を評価することもできます。ここで`expr`は、任意の有効なHaxeの式です。

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
