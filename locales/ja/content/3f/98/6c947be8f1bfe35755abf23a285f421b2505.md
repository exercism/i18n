# 説明

単語が与えられたら、その単語のスクラブルスコアを計算してください。

## 文字の点数

次の点数表を使います。

```text
Letter                           Value
A, E, I, O, U, L, N, R, S, T       1
D, G                               2
B, C, M, P                         3
F, H, V, W, Y                      4
K                                  5
J, X                               8
Q, Z                               10
```

## 例

"cabbage"は14点になります。

- Cは3点
- Aは2回、それぞれ1点
- Bは2回、それぞれ3点
- Gは2点
- Eは1点

これを合計すると、次のようになります。

- `3 + 2*1 + 2*3 + 2 + 1`
- = `3 + 2 + 6 + 3`
- = `5 + 9`
- = 14

## 拡張

- ダブルレターやトリプルレターをプレイできます。
- ダブルワードやトリプルワードをプレイできます。
