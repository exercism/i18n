# 指示の補足

## ヒント

この演習を完了するには、関数`slices`を実装する必要があります。この関数は*text*を受け取り、指定された長さの数字の部分列を返します。

この演習を解くのが初めてなら、用意されているシグネチャのまま進めることをおすすめします。

```haskell
slices :: Int -> String -> [[Int]]
```

その後、この問題に戻ってきて、ほかのデータ型やライブラリーを試してみるのもよいでしょう。

- `ByteString`（*bytestring*パッケージ）
- `Sequence`（*containers*パッケージ）
- `Text`（*text*パッケージ）
- `Vector`（*vector*パッケージ）

テストスイートは、意味の通るほとんどどんな型シグネチャでも受け入れるように意図的に設計されています。ですから、自分がいちばんよいと思うものを探してみてください。
