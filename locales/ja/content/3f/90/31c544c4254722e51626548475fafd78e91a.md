# はじめに

## クラス

Javaにおける主要なオブジェクト指向の構成要素は_クラス_です。クラスは、データ（_フィールド_）と振る舞い（_メソッド_）を組み合わせたものです。
クラスのフィールドとメソッドは、まとめて_メンバー_と呼ばれます。

メンバーへのアクセスはアクセス修飾子で制御できます。よく使われるのは次の2つです。

- `public`：どのコードからもアクセスできます（制限なし）。
- `private`：同じクラス内のコードからしかアクセスできません。

クラスは、そのクラスのインスタンスを作るためのテンプレートだと考えるとよいでしょう。
クラスのインスタンス（_オブジェクト_とも呼ばれます）を作るには、`new`キーワードを使います。

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

フィールドには型と名前（camelCaseで定義します）があり、クラス内のどこにでも定義できます（慣例として、クラス名はPascalCaseで書きます）。

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

フィールドには、任意で初期値を割り当てることができます。
フィールドに初期値を指定_しない_場合、そのフィールドは型のデフォルト値に設定されます。
インスタンスのフィールドの値には、ドット記法でアクセスしたり更新したりできます。

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

privateなフィールドは、通常、メソッドを呼び出した副作用として更新されます。
そのようなメソッドは通常、値を返しません。その場合、戻り値の型は`void`にします。

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
