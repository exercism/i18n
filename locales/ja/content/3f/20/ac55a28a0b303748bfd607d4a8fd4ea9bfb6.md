# はじめに

## 無名関数

Elixirでは、関数は第一級オブジェクトとして扱われます。つまり、次のようなことができます。

- 名前付き関数も無名関数も、変数に代入できます。
- 名前付き関数も無名関数も、データと同じように、引数や戻り値として受け渡すことができます。
- 無名関数は、動的に作成できます。

無名関数は、名前付き関数とは異なり、静的な参照を持ちません。変数に代入するか、その場で呼び出す場合にのみ利用できます。

無名関数は、次のような場面で使うことがあります。

- レキシカルスコープ（クロージャーとも呼ばれます）を使ってデータを隠す。
- 実行時に動的に関数を作成する。

無名関数は予約語`fn`で始まり、引数は`->`トークンで関数の本体と区切られ、`end`で終わります。名前付き関数と同じく、関数内の最後の式は、呼び出し元に_暗黙的に返され_ ます。

関数の参照を呼び出すには、参照を保持する変数と引数のリストの間に`.`を書く必要があります。

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

さらに、省略記法のキャプチャ構文を使うと、もっと簡潔に書くこともできます。

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## ビット操作

Elixirには、ビットを扱うための多くの関数が用意されており、それらは_Bitwise_モジュールにあります。

- `band/2`: ビット単位のAND
- `bsl/2`: ビット単位の左シフト
- `bsr/2`: ビット単位の右シフト
- `bxor/2`: ビット単位のXOR
- `bor/2`: ビット単位のOR
- `bnot/1`: ビット単位のNOT

ビット演算の関数を使う例を次に示します。

```elixir
Bitwise.bsl(1, 3)
# => 8
```

ビット演算の関数は、すべて整数に対してのみ動作します。

Elixirのバージョン1.9以前を使っている場合は、_Bitwise_モジュールを利用するために、モジュール定義の先頭で`require Bitwise`を呼び出す必要があります。
