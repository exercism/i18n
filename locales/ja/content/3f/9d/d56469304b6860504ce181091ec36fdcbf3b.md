# 説明

地元のピザ屋の店主から、いろいろなピザの調理時間の計算を手伝ってほしいと頼まれました。この演習では、その計算をするための関数をいくつか書いていきます。

タスクは3つあります。

## 1. 残りの焼き時間を分単位で計算する

ピザをオーブンに入れておくのに、あと何分必要かを数える`remainingMinutesInOven()`関数を定義して実装しましょう。

この関数は、ピザを焼き始めてから経過した分数を表す**省略可能な**入力を1つ受け取ります（デフォルト値があります）。入力が省略された場合は、ピザをオーブンに入れたばかりで、まだ**0（ゼロ）**分も経っていないものとします。

簡単にするために、どの種類のピザも、焼き上がるまでにオーブンでちょうど40分かかるとしましょう。

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. 準備時間を分単位で計算する

ピザを焼く前には、生地を準備して伸ばし、トッピングをのせる必要があります。

オーブンに入れる前にピザを準備するのに何分かかるかを数える`preparationTimeInMinutes()`関数を定義して実装しましょう。

この関数は、使うトッピングの種類の数を表す**必須の**入力（`numberOfIngredientTypes`）を1つ受け取ります。

生地を作って伸ばすのに5分、トッピングは**1種類**のせるごとに2分かかるとします。

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. 経過時間を分単位で計算する

ピザを準備して焼き、提供するまでに何分かかるかを数える`elapsedCookingTimeInMinutes()`関数を定義して実装しましょう。計算には、前のステップで作った関数を使います。

この関数は2つの入力を受け取ります。1つ目は**必須**で、トッピングの種類の数です。2つ目は**省略可能**で、提供までの時間（分）です（指定がなければ0とします）。

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
