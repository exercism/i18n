# 概要
C++に標準で用意されている数値型は、整数と浮動小数点に分けられます。
整数は、`0`や`691`、`-2`のような、小数部分を持たない数です。
浮動小数点数は、`6.02214076`や`0.1`、`-1.616`のように小数点を含む数です。

## 整数
次の例は、4つの異なる変数の宣言と初期化を示しています。

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

`int`の変数に値を代入するときは、リテラルをそのまま使うことができます。
リテラルとは、`9241`のようにコードに直接書き込まれた数値のことです。
整数リテラルは、数をどう表すかによって、基数ごとに異なる書き方があります。
10進数の整数リテラルが最も一般的で、`0`から`9`の数字を使います。
`0x`のような特別な接頭辞を付けると、別の基数を使うこともできます。
上の例では、数値`9421`を4通りの表現と接頭辞で表しています。
どの変数も、同じ値で初期化されます。

それぞれの表現方法について詳しく知りたいときは、[小さなチュートリアル][cpp_numerical_bases]を見てみましょう。

読みやすくするために、アポストロフィで数字を区切ることができます。
`9'241`は`0b0100'100'0001'1001`や`92'4'1`と同じです。

## 浮動小数点数

浮動小数点リテラルには2通りの書き方があります。
直感的な`0.0024`のほかに、その指数表記である`2.4e-3`も使えます。
最もよく使われる浮動小数点型は`double`です。

## 算術演算

C++では、式を組み立てるために`+`、`-`、`*`、`/`、`(`、`)`、`%`を使えます。
整数同士の演算結果も整数になります。
`5 / 2`は`2`を返します。
関わる型のどちらかが浮動小数点型であれば、結果も浮動小数点型になります。
`5.0 / 2`と`5 / 2.0`は`2.5`を返します。
`%`は余りを求める演算子で、整数の除算の余りを返します。`5%3`は`2`です。

## 代入演算子

代入演算子は、変数にリテラルを代入します。
代入は常に右から左へ行われ、逆向きに行われることはありません。

```cpp
int length = 5;
int width = 2;
length = width;
```

ここでは、整数値`5`が変数`length`に代入されます。
次に、整数値`2`が変数`width`に代入されます。
最後に、`width`の値が変数`length`にコピーされ、それまでの値`5`は失われます。
また、代入の瞬間に`width`の値が`length`に代入されるだけだという点にも注目してください。
そのため、あとで`width`の値が変わっても、`length`の値には影響しません。

代入演算子は、算術演算子やビット演算子と組み合わせることができ、これらは複合代入演算子（`compound assignment`）として知られています。`+=`、`-=`、`*=`、`/=`、`%=`があります。
これらの演算子は、変数の現在の値に演算を行って、その値を更新します。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

変数`people`と`eggs`は`0`で初期化されます。
次に、変数`people`の現在の値`0`に整数値`2`を加え、その結果を`people`に代入し直します。
これで`people`は`2`になります。
続いて、1人あたり`3`個の卵を加えると、合計で`6`個の卵になります。
この`6`を、変数`eggs`の現在の値`0`に加えて`eggs`に代入し直します。
`eggs`は`6`になります。
これと等価な式は、`people = people + 2`と`eggs = eggs + (3 * people)`です。

## キャスト

キャストとは、ある型から別の型への変換です。
`double`が必要な場面では、代わりに`int`を使うことができます。
上で見た`5.0 / 2`の例は、`2`が暗黙的に`2.0`へキャストされて処理されます。
`double`を`int`にキャストすると、情報が失われることがあります。
別の型Tへのキャストは、`static_cast<T>`を使って明示的に行うのがよい習慣です。
古いCスタイルの`(T)`によるキャストは、現代のC++では推奨されませんが、知っておくべきものです。

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## 精度と表現

C++の数値は、いくらでも大きくできるわけではありません。
たとえば`int`は32ビットで表現されます。
これは`2^32`個、およそ40億個の数を表せるだけの大きさです。
`0`を含めると、`int`の最大値と最小値は`-2^31`と`2^31 - 1`になります。

浮動小数点数は通常、10進数で15桁程度の精度で実装されますが、その表現はホストシステムによって異なります。
