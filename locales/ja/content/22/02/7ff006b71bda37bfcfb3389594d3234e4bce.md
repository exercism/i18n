# 概要

Gleamの配列は、0個以上の値をまとめた不変のコレクションです。配列に入る値は、すべて同じ型でなければなりません。配列は不変なので、一度作られた配列の値を後から変えることはできません。配列を変更しているように見える関数や演算子（要素の追加など）は、実際には新しい配列を返します。

配列は次のように定義できます:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

配列に要素を追加する最も一般的な方法は、スプレッド構文を使って先頭に付け加える方法です:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam標準ライブラリの[`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html)モジュールには、配列を扱うための便利な関数がたくさん用意されています。このモジュールはGleamのコードで非常によく使われるので、慣れておくとよいでしょう。

配列のパターンを使うと、`case`式で配列にマッチさせ、含まれている値を変数に代入できます:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

長さがちょうどの配列にマッチさせるだけでなく、スプレッド構文を使えば、ある長さ以上の配列にマッチさせることもできます:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

スプレッド構文は、残りの配列を変数に代入するのにも使えます:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

`case`式では、マッチさせる型が取りうるすべての値に対してパターンを用意する必要があるので、残りの値を処理するために最後に破棄パターン（`_`）を置くことがよくあります。
