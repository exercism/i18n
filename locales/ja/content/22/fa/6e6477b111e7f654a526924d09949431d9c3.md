# 概要

ファイルは、ディスク上に名前を持つストリームです。[`io.files`][io.files]ボキャブラリには、ファイルを扱う2つの方法があります。1つは、1回の呼び出しで全体を読み書きするファイル全体向けの便利なワード、もう1つは、少しずつ読み書きするためのストリームを開くもの（`with-…`コンビネータ）です。どちらも、`io-streams`の概念で扱ったメモリ上のストリームと同じ[ストリームプロトコル][stream-protocol]に基づいています。`<file-reader>`と`<string-reader>`は、どちらも同じワードに応答します。

ファイルを扱うワードはどれも、**エンコーディング**を取ります。エンコーディングとは、バイトと文字を相互に変換する仕組みです。テキストを扱うときは、ほとんどが`io.encodings.utf8`の[`utf8`][utf8]です。バイナリを扱うときは、`latin1`や`<byte-array>`エンコーディングを使います。

## ファイル全体の読み込み

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents`は、ファイル全体を1つの文字列として返します。`file-lines`は、行末の改行を取り除いたうえで、行を配列として返します。各行が1件のレコードになっている場合に便利です。

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## ファイル全体の書き込み

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

どちらもファイルを**置き換え**、ファイルが存在しなければ新しく作成します。`set-file-contents`は文字列をそのまま書き込み、`set-file-lines`はシーケンスの各要素を、改行を補いながら1行ずつ書き込みます。

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## スコープ付きストリーム

ファイルに追記したいときや、少しずつ読み書きしたいときは、`with-…`コンビネータでファイルを開き、クオテーションの中でカレントストリームのワードを使います。

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

`with-file-writer`は、まずファイルを切り詰めます。`with-file-appender`は、既存の内容をそのままにして、そのあとに書き込みます。どちらもデストラクタスコープです。クオテーションの実行が終わると、たとえ例外が発生した場合でもファイルハンドルは閉じられます。`boatswains-bilge`のコンビネータが提供するのと同じ保証を、ファイル向けに特化したものです。

## ファイル全体か、スコープ付きか

ファイルがメモリに収まるほど小さく、全体を一度に扱いたいときは、`file-contents`/`file-lines`/`set-file-contents`/`set-file-lines`の出番です。追記したいとき、`readln`で大きなファイルを1行ずつ読み進めたいとき、読み込みと書き込みを交互に行いたいときは、`with-…`で開くワードの出番です。ファイル全体をメモリに置くのが無駄だったり、そもそも適切でなかったりする場面では、こちらが向いています。
