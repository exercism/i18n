# はじめに

Pythonの`str`は、[Unicodeコードポイント][unicode code points]の[イミュータブルなシーケンス][text sequence]です。これには、文字、ダイアクリティカルマーク、位置決め文字、数値、通貨記号、絵文字、句読点、空白、改行文字などが含まれます。

文字列はすべての[共通シーケンス操作][common sequence operations]を実装しており、`for item in <string>`や`for index, item in enumerate(<string>)`という構文で繰り返し処理できます。

文字列は`<str> + <other str>`や`<str>.join(<iterable>)`で連結でき、`<str>.split(<separator>)`で分割できます。さらに、書式設定、組み立て、テンプレート化のためのさまざまなオプションも用意されています。

`str`はイミュータブルなので、メモリ上にある`str`オブジェクトの値は変わりません。文字列を変更しているように見えるメソッドは、新しいコピー、つまり新しい`str`のインスタンスを返します。

文字列がどんな情報を表しているのか（あるいは、_「コンピューターはどうやって0と1を文字に変換しているのでしょうか？」_）を詳しく知りたいときは、[このブログ記事がいつまでも役に立ちます][joel-on-text]。Pythonのドキュメントにも、非常に詳しい[Unicode HOWTO][unicode how-to]があり、`str`、`bytes`、`re`モジュールにおけるPythonのUnicode仕様のサポート、ロケールに関する考慮事項、エンコーディングと変換に関するよくある問題が説明されています。
