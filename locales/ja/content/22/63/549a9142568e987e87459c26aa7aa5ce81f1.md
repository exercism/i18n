# はじめに

Clojureの`vector`は、0個以上の値からなる、順序を持ちインデックスでアクセスできる不変のコレクションです。つまり、一度作成された`vector`は変更できません。`vector`を操作する関数は新しい`vector`を返し、元の`vector`はそのまま残ります。`vector`の値は、異なる型が混ざっていてもかまいません。`vector`は次のように定義できます。

```clojure
(def empty [])
(def single-value [5])
```

`vector`の要素は、インデックスを使って取り出せます。Clojureの`vector`は0から始まるため、最初の要素のインデックスは常に0です。

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

元の`vector`は変わりません。

```clojure
numbers
;;=> [2 3 5]
```

更新した値を覚えておくには、その値をそのまま渡していくか、`var`に保持する必要があります。

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
