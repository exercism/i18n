# はじめに

[パターンマッチング][pattern-matching]を使うと、表現力豊かな分岐コードが書け、[分割代入][destructuring]を使うと、値と変数をエレガントに結び付けられます。
どちらもElmプログラマーとしてぜひ身につけたい技術で、組み合わせて使うとコードの可読性が大きく向上します。

## シンプルなパターンマッチング

パターンマッチングとは、扱うデータの形に応じてコードを分岐させる書き方のことです。
そのため、データが取りうる複数の形を表すカスタム型の考え方と自然に噛み合います。
たとえば、`Blue`か`Red`のどちらかであると定義された`Color`カスタム型があれば、色をパターンマッチングして正しい文字列を返す`toString`関数を書くことができます。

```elm
type Color = Blue | Red

toString : Color -> String
toString color =
    case color of
        Blue -> "blue"
        Red -> "red"
```

パターンマッチングは、単純な列挙型ではないカスタム型にも使えます。
引数として`Maybe String`を受け取る`hello`関数を考えてみましょう。この`Maybe String`は、人の名前か、何も持たないかのどちらかを表します。
パターンマッチングでは、データに小文字の名前を付けてその変数に束縛し、マッチングの右辺で使えるようにできます。

```elm
hello : Maybe String -> String
hello maybeName =
    case maybeName of
        Nothing -> "Hello stranger!"
        -- here we bind 'name' to the data inside the 'Just'
        Just name -> "Hello " ++ name ++ "!"
```

パターンマッチングは網羅的でなければならず、そうでなければコンパイラーがコンパイルを拒否します。
しかし、データの一部やcase式の一部の分岐を気にしないこともあります。
そういうときは、束縛する変数名を探してすべてのケースを分岐させる代わりに、アンダースコアのワイルドカード`_`を使えます。

```elm
type Entity = Friend { name: String } | Stranger | Alien

hello : Entity -> String
hello entity =
    case entity of
        -- here we don't care about the data held by 'Friend'
        Friend _ -> "Hi!"
        -- mandatory because pattern matching must be exhaustive,
        -- but for all other cases, we answer the same thing
        _ -> "Hello stranger!"
```

## 高度なパターンマッチング

カスタム型だけでなく、`Char`、`String`、`Int`、`Floats`のようにリテラルを持つ型に対してもパターンマッチングできます。

```elm
howMany : Int -> String
howMany count =
    case count of
        0 -> "none!"
        1 -> "there is one!"
        2 -> "a couple!"
        _ -> "too many to count!"

greekLetter : String -> String
greekLetter letter =
    case letter of
        "a" -> "alpha"
        "b" -> "beta"
        _ -> "I don't remember"
```

複数の値を入れ子にせずマッチングさせたいときは、マッチングする値を[_アドホックタプル_][ad-hoc-tuples]にまとめるのがElmでよく使われるやり方です。次のようになります。

```elm
howManyGreekLetters : Int -> String -> String
howManyGreekLetters count letter =
    case ( count, letter ) of
        ( 0, _ ) -> "none!"
        ( 1, "a" ) -> "there is an alpha!"
        ( 1, "b" ) -> "there is a beta!"
        _ -> "at least two!"
```

関数型プログラマーにとってリストは大切なものですが、[リストもパターンマッチングできます][pattern-match-lists]。リストを組み立てるときと同じ構文、演算子`::`を使います。

```elm
head : List a -> Maybe a
head list =
    case list of
        [] -> Nothing
        x :: _ -> Just x
```

最後に、パターンマッチングは再帰的にも機能し、複雑で再帰的な型を深く掘り下げることができます。

```elm
type Activity = Work | Play Game
type Game = Boardgame String | VideoGame String

pickActivity : Activity -> Bool
pickActivity activity =
    case activity of
        -- The only thing we want is playing Catan
        Play (Boardgame "Catan") -> True
        _ -> False
```

## 分割代入

分割代入は、型の中のデータに変数を束縛できるという点で、パターンマッチングととてもよく似ています。
大きな違いは、取りうる形が1つだけのときにその仕組みを「分割代入」と呼び、形が複数あるときにパターンマッチングと呼ぶことです。
分割代入は`let`束縛や関数の引数でよく見られ、もちろんcase式の中でもパターンマッチングと混ざって使われます。

```elm
pairSum : ( Int, Int ) -> Int
pairSum pair =
    -- Destructuring of a pair in a 'let' binding
    let ( x, y ) = pair
    in x + y

-- Custom type containing a single variant
type Container = Box String

-- Destructuring of the container as function argument
-- to bind its content directly without the need of 'let' or 'case'.
unbox : Container -> String
unbox (Box str) =
    str

-- Destructuring combined with pattern matching
unboxMaybe : Maybe Container -> Maybe String
unboxMaybe maybeContainer =
    case maybeContainer of
        Nothing -> Nothing
        Just (Box "42") -> Just "The answer to the universe!"
        Just (Box str) -> Just str
```

分割代入は、バリアントが1つだけのカスタム型、タプル、そしてレコードにも使えて、レコードではとても便利です。
[レコードを分割代入する][records-pattern-matching]には、そのフィールドを好きな数だけ、1つ、2つ、…、あるいはすべて使えます。

```elm
type alias Circle =
    { radius : Float
    , center : ( Float, Float )
    }

perimeter : Circle -> Float
perimeter { radius } =
    2 * pi * radius
```

残念ながら、Elmの構文ではレコードを再帰的に分割代入できません。
先ほどの`Circle`の例では、円の中心の`x`` and `y の位置に一度にアクセスする方法はありません。
まず`center`にアクセスし、それからその`x`と`y`の位置を分割代入する必要があります。

```elm
left : Circle -> Float
left { radius, center } =
    let ( x, _ ) = center
    in x - radius
```

最後にもう1つコツを紹介します！
もの全体とその一部の両方に簡単にアクセスしたいことがあります。そんなときに役立つのが[`as`キーワード][as-keyword]です。
これを使うと、もの全体に別名を付けながら、その中身を分割代入することもできます。

```elm
-- Make the circle smaller if the radius is sufficiently big.
-- Otherwise, return the circle unchanged.
smaller : Float -> Circle -> Circle
smaller reduction ({ radius, center } as circle) =
    if reduction < radius then
        { radius = radius - reduction
        , center = center
        }
    else
        circle
```
