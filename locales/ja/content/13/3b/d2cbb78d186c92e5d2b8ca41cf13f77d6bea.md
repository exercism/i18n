# 説明

フレーズを頭字語に変換します。

IT業界の人たちは、TLA（3文字の頭字語）が大好きです！

Portable Network Graphicsのような長い名前を、その頭字語（PNG）に変換するプログラムを書いて、ちょっとした専門用語を生み出してみましょう。

句読点は次のように扱います。ハイフンは単語の区切りです（空白と同じ扱いです）。それ以外の句読点は、入力から取り除いてかまいません。

たとえば、次のとおりです。

| 入力                      | 出力 |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
