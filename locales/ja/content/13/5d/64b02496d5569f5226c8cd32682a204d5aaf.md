# 指示の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 入力     | アドレス | 因数を格納したワードの配列         |
| `$a1`    | 入力     | 整数 | 因数の個数             |
| `$a2`    | 入力     | 整数 | 上限                         |
| `$v0`    | 出力     | 整数 | 上限以内の倍数の合計 |
| `$t0-9`  | 一時的 | 任意     | 一時的な保存に使う    |
