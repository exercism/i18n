# はじめに

Gleamでは、エラー処理に例外を使いません。その代わり、成功するか失敗するかを表す汎用的な`Result`型を、関数が返します。

`Result`型は言語に組み込まれているので、自分で定義したりインポートしたりする必要はありません。ですが、もし自分で定義するとしたら、次のようになります。

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

関数が成功したときは`Ok`が返され、失敗したときは`Error`が返されます。

Gleamでは`Result`が非常によく登場するので、Gleamプログラマーはそれを扱いやすくするために[`gleam/result`モジュール](https://hexdocs.pm/gleam_stdlib/gleam/result.html)をよく利用します。

`result.map`関数は、`Result`が`Ok`ならその中に入っている値に関数を適用し、`Error`ならそのまま通すために使います。

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try`関数も似ていますが、こちらはコールバック関数が`Result`を返すことが期待されます。`Result`を返す複数の関数をつなげたいときに便利です。

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
