# 指示

ネットボールクラブでは、各ラウンドが終わるたびに順位表を計算する必要があります。

4つのタスクはすべて`NETBALL_LADDER`クラスに書きます。

## 1. 順位表のポイント

勝利は4ポイント、引き分けは2ポイントです。敗戦にはポイントがもらえません。

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. 得失点差

得点から失点を引いた値です。マイナスになることもあります。

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. プレーしたクォーター数

クォーターは15分です。与えられた時間（分）は、まるまる何クォーター分になるでしょうか？

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. クォーター内の経過分数

同じ時間（分）が与えられたとき、現在のクォーターが始まってから何分経過しているでしょうか？

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
