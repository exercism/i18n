# 指示

魔法使いと戦士のゲームというテーマの続きとして、そろそろ万能なサイコロを振るメソッドを追加しましょう。これは1から18までの数字が付いた、伝統的な18面サイコロです。プレイヤーは呪文の強さも生成します。

## 1. _魔法使いと戦士_のプレイヤーがサイコロを振れるようにしましょう

`Player`クラスに`RollDie()`メソッドを実装しましょう。

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. プレイヤーには強さが必要です。呪文の強さを生成する手段を用意しましょう

`Player`クラスに`GenerateSpellStrength()`メソッドを実装しましょう。呪文の強さは0.0以上、100.0未満です。

なお、2人の敵の強さを比べたときに引き分けになる可能性を減らすには、呪文の強さを実数（整数ではない）にする必要があります。

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
