# はじめに

## ビット操作

Javaには、`byte`、`short`、`int`、`long`、`char`のビットを操作するための演算子があります。

### シフト演算子

`<<`を使うとビットを左にシフトでき、`>>`を使うと右にシフトできます。

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

`<<`演算子は常に右側に0を挿入します。
ただし、`>>`は一番左のビットと同じビットを挿入します（数値が負なら1、正なら0）。

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

右にシフトするときに0を挿入したい場合は、代わりに`>>>`を使います。

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### ビット演算

#### ビット単位のAND

ビット単位のAND演算子（`&`）は、2つの値を受け取り、各ビットに対してANDを実行します。
1つ目の値の各ビットを、2つ目の値の同じ位置にあるビットと比較します。
両方が1であれば、結果のビットは1になります。
そうでなければ、結果のビットは0になります。

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### ビット単位のOR

ビット単位のOR演算子（`|`）は、2つの値を受け取り、各ビットに対してORを実行します。
1つ目の値の各ビットを、2つ目の値の同じ位置にあるビットと比較します。
どちらかのビットが1であれば、結果のビットは1になります。
そうでなければ0になります。

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### ビット単位のXOR

ビット単位のXOR演算子（`^`）は、2つの値に対してビット単位のXORを実行します。
ビット単位のAND演算子やビット単位のOR演算子と同様に、1つ目の値の各ビットを、2つ目の値の同じ位置にあるビットと比較します。
どちらか一方だけが1であれば、結果のビットは1になります。
そうでなければ0になります。

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### ビット単位のNOT（`~`）

最後に、ビット単位のNOT演算子（`~`）は各ビットを反転します。
これまでの演算子とは異なり、これは単項演算子であり、1つの値だけに作用します。

```java
~0b0110_0101;
// # => 0b1001_1010
```
