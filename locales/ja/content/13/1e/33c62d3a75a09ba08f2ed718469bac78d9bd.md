# インストール

C言語のトラックでは、次のソフトウェアがシステムにインストールされている必要があります。

* モダンなCコンパイラー
* Makeビルドツール

AppleのXcode IDEは、コンパイラーとネイティブビルドシステムを1つのIDE（統合開発環境）にまとめたものです。
Linux環境では、通常、コンパイラーとネイティブビルドシステムは別々のコマンドラインツールとして提供されます。

## Linux

Linuxでは、コンパイラーとしてgccまたはclangが、ネイティブビルドには`make`が必要になります。
Makeはほとんどのunixシステムにプリインストールされていますが、たいていはパッケージマネージャーからもインストールできます。
DebianやUbuntuベースのディストリビューションでは、必要なものが入っていない場合は、`sudo apt-get install build-essential`でまとめてインストールできます。

## MacOS

MacOSでは、[Homebrew][]を使って`brew install gcc`または`brew install llvm`でgccやclangをインストールできます。

## Windows

Windows 10では、[Windows Subsystem for Linux][]を使い、上記のLinux向けの手順に進むことをおすすめします。

それより前のバージョンのWindowsを使っている場合や、WSL Bashが使えない場合は、[MSYS][]や[mingw-w64][]を利用できます。

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
