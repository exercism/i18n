# 概要

ループには大きく分けて2つの種類があります。

1. 条件が満たされるまで繰り返す。
2. コレクションの要素を順に処理する。

どちらも[Juliaで可能です][loops]が、2つ目のほうがよく使われるかもしれません。

## `while`ループ

ループを何回回すかが事前にわからない、終わりの見えない問題のために、Juliaには`while`ループがあります。

基本の形はとてもシンプルです：

```julia
while condition
    do_something()
end
```

この場合、プログラムは`condition`が`true`でなくなるまでループを回り続けます。

ループを途中で抜ける方法が2つあります：

- `break`はループを終了させ、実行はループの`end`の次の行から続きます。
- `return x`は現在の関数の実行を停止し、戻り値`x`を呼び出し元に返します。

こうした方法があると、`while true ... end`で「無限」ループを作っておき、ループ本体の中で停止条件を見つけて`break`や`return`を起こす、という書き方が便利なことがあります。

## コレクションをループする

最も簡単な例は、範囲をループすることです。

何かを10回行いたい場合：

```julia
for n in 1:10
    do_something(n)
end
```

現在の繰り返しがある条件を満たさない場合、`continue`で即座に次の繰り返しへスキップできます：

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

短い形では、`if`ブロックを`is_useless(n) && continue`に置き換えることもできます。

他にも多くのコレクション型をループできます：配列の要素、文字列の文字、辞書のキーなどです。

必要なのは、コレクションが`iterable`であることです。これは後の概念で詳しく説明しますが、要点は、求められたときに次の項目を取り出す方法と、終わりに達してそれ以上項目がないことを示す方法を、コレクションが持っている必要があるということです。

これまでの例では、値がそのままループのインデックスにもなっている範囲`1:10`をループしていました。

より一般的には、値だけでなくインデックスが必要になることがあります。そのためには[`eachindex()`][eachindex]関数を使います。例えば`for i in eachindex(my_array) ... end`のように書きます。

## 内包表記

Juliaでは、明示的なループを書くことは、多くの伝統的な言語よりも少ない傾向があります。より簡潔に書ける方法がいろいろあるからです。

特に一般的なのは、他のコレクション（ベクトル、文字列、集合など、多くの可能性があります）の要素から新しいベクトルを組み立てたい場合です。

Pythonのリスト内包表記が好きな人なら、Juliaでも[同様の構文][comprehensions]が使えると知って喜ぶでしょう。

要は、ベクトルの中にごくコンパクトなループを組み込むということです。

最もシンプルな構文は`result = [f(x) for x in some_collection]`という形です。

伝統的なループで書くと、次のようになります：

```julia
result = []
for x in some_collection
    push!(result, f(x))
end
```

必要に応じて、コレクションの中で条件に合う要素だけを選ぶための条件を、末尾に追加できます：

```julia-repl
# multiples of 3
julia> [n^2 for n in 1:10 if n%3 == 0]
3-element Vector{Int64}:
  9
 36
 81

# letters beyond 'h' in the alphabet
julia> [uppercase(c) for c in "Julia" if c > 'h']
3-element Vector{Char}:
 'U': ASCII/Unicode U+0055 (category Lu: Letter, uppercase)
 'L': ASCII/Unicode U+004C (category Lu: Letter, uppercase)
 'I': ASCII/Unicode U+0049 (category Lu: Letter, uppercase)
```

構文はPythonと_似ています_が、_同一ではありません_。複数の変数や多次元配列ではいくつか違いがあるため、この話題は後の概念でより詳しく扱います。

## その他の方法

現代的で、ほとんどが関数型の言語であるJuliaには、（もちろん）コレクションを操作する方法がいろいろあります。明示的なループや、内包表記でまとめたループだけではありません。

後の概念では、ブロードキャストや高階関数といった代替手段を見ていきます。
