# はじめに

## ハッシュテーブル

Common Lispのハッシュテーブルは、関連するデータをまとめて保存しておくためのデータ構造です。
キー（どんなオブジェクトでもかまいません）を値（こちらもどんなオブジェクトでもかまいません）に対応付けます。
他の言語では、この概念をマップ、辞書、ハッシュなどと呼ぶことがあります。

### ハッシュテーブルの作成

ハッシュテーブルは`make-hash-table`関数で作成できます。

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

（ハッシュテーブルが表示される形式は処理系によって異なるため、REPLでは違って見えるかもしれません。）

### キーによる値の取得

ハッシュテーブルからキーで値を取得するには、`gethash`関数を使います。

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash`は[複数の値][concept-multiple-values]を返します。これについては別の概念で説明します。

### 値の挿入

ハッシュテーブルに値を挿入するには、`gethash`と組み合わせて`setf`を次のように使います。

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

これはハッシュテーブル`*hash-table*`にあるキー`:foo`の値を`:bar`に変更します。
そしてその値を返します。

`setf`の使い方については、別の概念で説明します。
