# 真偽値

Haskellには[`Bool`][bools]という型があります。
`True`と`False`を列挙した型です。

## 論理演算子

Haskellには3つの論理演算子（`not`・`||`・`&&`）があります。これらを組み合わせると、真偽値から、さまざまな結果を生み出す式を作れます。

### AND（`&&`）

Haskellの[AND演算子][and]は`&&`で表され、両方の値が`True`なら`True`を返し、それ以外なら`False`を返します。
AND演算子を使うときは、1つの真偽値を`&&`の右側に、もう1つを左側に置きます。

```haskell
True && True
-- -> True

True && False
-- -> False
```

### OR（`||`）

Haskellの[OR演算子][or]は`||`で表され、与えられた値のうち**少なくとも1つ**が`True`なら`True`を返します。
両方の値が`False`なら、`False`を返します。
OR演算子を使うときは、1つの真偽値を`||`の右側に、もう1つを左側に置きます。

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### NOT（`not`）

HaskellのNOT演算子は`not`で表され、与えられた真偽値が`False`なら`True`を返し、`True`なら`False`を返します。
NOT演算子を使うときは、演算子（`not`）の後ろに真偽値を1つ置きます。

```haskell
not True
-- -> False

not False
-- -> True
```

## 括弧（`()`）の使い方

真偽値を扱うときは、括弧を使って、どちらを先に評価するかを決められます。
括弧の使い方によって、結果は変わることがあります。
Haskellでは、括弧の中身が先に評価されます。

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

括弧の中身が先に評価されるため、次の例では、NOT演算子は括弧の中の式に適用されます。

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
括弧は、結果が変わる場合にだけ使いましょう。それ以外のときは省略してください。
~~~~
