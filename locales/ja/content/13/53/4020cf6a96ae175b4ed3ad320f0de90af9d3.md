# 変数入門

## 変数

_変数_は、データを入れておく場所です。
Bashが扱うデータには、文字列と配列の2種類があります。
配列については、あとで説明します。

変数への代入は、次のように書きます。

```bash
name="value"
```

~~~~exercism/note
**重要**：イコール記号の前後には_スペースを入れてはいけません_！

次の例のようにスペースがあると、

```bash
x = 10
```

bashは**コマンド**`x`を、**2つの引数**`=`と`10`で呼び出そうとします！
~~~~

変数は_パラメータ_と呼ばれることもあります。
このドキュメントでは、この2つの言葉を同じ意味で使います。

bashが使ったり設定したりする重要なパラメータには、次のようなものがあります。

* `PATH`：外部コマンドを探すために使う、コロンで区切られたディレクトリの一覧です。
* `IFS`：「内部フィールド区切り文字」です。
   これがどのように使われるかは、あとで見ていきます。
* `PWD`：現在の作業ディレクトリです。
   `pwd`コマンドの出力と同じ値になります。
* `RANDOM`：0から32767までの疑似乱数の整数です。
* `BASH_VERSION`：実行中のbashインスタンスのバージョン文字列です。

## 変数の名前

変数の名前は、_英大文字、英小文字、数字、アンダースコア_で構成されます。
数字で始めることはできません。

~~~~exercism/caution
**すべて大文字の変数名は避ける**のがベストプラクティスです。
シェルはこの書き方をシェル自身のパラメータに使っているので、特別な意味を持つシェルのパラメータをうっかり上書きしたくはないはずです。

## パラメータ展開

パラメータの値は、`$varname`という書き方で取り出せます。

```bash
x=10
echo "The value of x is $x"
```

変数名がまわりの文字列と紛れないようにするには、変数名を波括弧で囲みます。
たとえば、文字列`10x10`を出力するには次のようにします。

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

読みやすさや一貫性のために、ほとんどの場面で波括弧を使うことを勧めている[スタイルガイド][google-style-guide]もあります。

## 位置パラメータ

[コマンドと引数][cmds-args]のレッスンで見たように、コマンドは引数を取ることができます。
bashスクリプトも例外ではありません。
実行中のbashインスタンスに渡された引数は、_位置パラメータ_と呼ばれます。
これらは、次の特別なパラメータで取り出せます。

* `$1`：1番目の位置パラメータ
* `$2`...`$9`：それに続くパラメータ
* `${10}`...：2桁の数字には波括弧が必要です。
* `$0`：現在のスクリプトの名前。

シェル関数に渡す引数も位置パラメータで、まったく同じように扱います。
関数については、また別のレッスンで詳しく見ていきます。

### 特別な位置パラメータ

位置パラメータを扱うのに役立つ_特別なパラメータ_がいくつかあります。

* `$#`は、位置パラメータの_数_に展開されます。
* `"$@"`は、すべての位置パラメータを、それぞれ別々の単語として並べたリストに展開されます。
* `"$*"`は、すべての位置パラメータをある文字でつなげた、1つの文字列に展開されます。
  * つなげる文字には、`$IFS`変数の_最初の文字_が使われます。既定ではスペースです。

`"$@"`は、位置パラメータを安全にクォートしたまま別のコマンドへ渡す、もっとも安全な方法です。
位置パラメータをループで回すときにも、これを使います。

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

実際には、`"$*"`よりも`"$@"`のほうがよく使われます。

## コマンド置換

bashスクリプトでよく行う操作のひとつが、コマンドの出力を受け取って変数に保存することです。
これには_コマンド置換_を使います。

```bash
var=$(command)
```

たとえば、文字列を大文字にするには次のようにします。

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## パラメータ展開の詳細

bashには、外部コマンドを呼び出さなくても変数や文字列を操作できる、組み込みの機能がたくさんあります。

* テキストを大文字にする。
  前のセクションでは、私が`tr`を使ってテキストを大文字にする方法を紹介しました。
  これをbashで行うには、次のようにします。

  ```bash
  echo "${text^^}"
  ```

  同じように、`${text,,}`とすると値が小文字になります。

* 変数が空のときに既定値を渡す。

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* 検索と置換。

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

ほかにも、部分文字列を取り出す、文字列の長さを調べる、既定値を_代入する_、値の先頭や末尾からテキストを取り除くなど、おもしろいパラメータ展開がたくさんあります。
詳しくは[マニュアル][param-exp]を読んでみてください。
