# ヒント

## 全般

- Getting Startedガイドの[`alias`と`import`][getting-started]について読みましょう。
- elixirschool.comの[モジュールの合成][elixir-school-module-composition]について読みましょう。

## 1. コンパイルエラー`Race.__struct__/0 is undefined`を修正する

- [`alias`][alias]特殊形式を使うと、エイリアスを作成できます。

## 2. コンパイルエラー`Car.__struct__/0 is undefined`を修正する

- [`alias`][alias]特殊形式を使うと、エイリアスを作成できます。
- `alias`特殊形式は、`:as`オプションを受け付けます。

## 3. コンパイルエラー`undefined function puts/1`を修正する

- [`import`][import]特殊形式を使うと、関数をインポートできます。
- [`import`][import]特殊形式は、`:only`オプションを受け付けます。その値には、関数名をキー、関数のアリティを値とするキーワードリストを指定します。

## 4. コンパイルエラー`undefined function default_color/0`を修正する

- [`import`][import]特殊形式を使うと、関数をインポートできます。
- [`import`][import]特殊形式は、`:except`オプションを受け付けます。その値には、関数名をキー、関数のアリティを値とするキーワードリストを指定します。
