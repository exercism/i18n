# インストール

まず、必要に応じて[Erlang][1]のインストールページの手順に従い、Erlangがインストールされていることを確認してください。
[1]: /languages/erlang

## Mac OS X向けのHomebrew

Homebrewを最新の状態に更新してください：

```bash
$ brew update
```

LFEをインストールしてください：

```bash
$ brew install lfe
```

## ソースからのインストール

システムの「developer tools」または「essential build packages」、`git`、Erlangの`erl`をインストールしてください。

たとえば、Ubuntu 18.04では：

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

その後、次のコマンドでLFEをダウンロードしてビルドできます：

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

LFEをコンパイルしたら、``lfe``バイナリを実行してREPL（対話セッション）を起動できます：

```bash
$ ./bin/lfe
```
