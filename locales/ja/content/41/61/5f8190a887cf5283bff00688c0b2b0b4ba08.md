# 指示

スクエアコードと呼ばれる、秘密のメッセージを組み立てる古典的な方法を実装します。

英語のテキストが与えられたら、そのテキストを暗号化したものを出力します。

まず、入力を正規化します。英語のテキストから空白と句読点を取り除き、メッセージを小文字にします。

次に、正規化した文字を行に分割します。これらの行は、間に改行を挟んで表示すると、長方形を形作っているとみなせます。

たとえば、次の文を

```text
"If man was meant to stay on the ground, god would have given us roots."
```

正規化すると、次のようになります。

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

平文は長方形に整理します。長方形の大きさ（`r x c`）はメッセージの長さで決まり、`c`が列の数、`r`が行の数を表すとき、`c >= r`かつ`c - r <= 1`となるようにします。

正規化したテキストは54文字なので、`c = 8`、`r = 7`の長方形になります。

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

暗号化されたメッセージは、左から右へ列を上から下に読むことで得られます。

上のメッセージは、次のように暗号化されます。

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

暗号化したテキストは、完全な長方形（`(r X c)`）を埋めるかたまりに分けて出力します。`r`の長さのかたまりを`c`個、空白で区切って並べます。完全な長方形より`n`文字足りない場合は、最後の`n`個のかたまりをそれぞれ末尾の空白1つで埋めます。

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

これらを積み重ねると、暗号文を目で見て元のメッセージに戻せることに気づくでしょう。

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
