# 概要

Rubyには標準ライブラリ（しばしば「stdlib」と略されます）が付属しています。標準ライブラリは、日付、JSON、ネットワークなどを扱うためのクラスの集まりです。また、コードを扱いやすくする便利な機能も提供しています。

`OpenStruct`は標準ライブラリの一部で、`Hash`から簡単にオブジェクトを作ることができます。`Hash`のキーでアクセスする代わりに、`OpenStruct`ではメソッドを使って値の取得や設定ができます。

標準ライブラリやその他のライブラリのクラスを使うときは、`require`メソッドでそのクラスを読み込む必要があります。

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

これにはもう一つ嬉しい利点があります。ブロック構文を使うときに、省略記法を活用できるのです。ブロックが1つのメソッドを呼び出す場合は、ブロックを`&:`とメソッド名に置き換えられます。たとえば、次の2行は同じ意味です。

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
