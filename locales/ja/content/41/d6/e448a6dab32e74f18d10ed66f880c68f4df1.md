# 概要

Elixirの標準ライブラリには、日付と時刻を扱うための4つのモジュールがあり、それぞれが独自の構造体を持っています。

- [`Date`モジュール][date]。`Date`構造体は、[`~D`シジル][sigil-d]で作成できます。
    ```elixir
    ~D[2021-01-01]
    ```

- [`Time`モジュール][time]。`Time`構造体は、[`~T`シジル][sigil-t]で作成できます。
    ```elixir
    ~T[12:00:00]
    ```

- タイムゾーンのない日時のための[`NaiveDateTime`モジュール][naivedatetime]。`NaiveDateTime`構造体は、[`~N`シジル][sigil-n]で作成できます。
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- タイムゾーンのある日時のための[`DateTime`モジュール][datetime]。UTC以外のタイムゾーンでこのモジュールを使うには、外部の依存関係であるタイムゾーンデータベースが必要です。`DateTime`構造体は[`~U`シジル][sigil-u]で表現できますが、作成するときは`DateTime`の関数を使いましょう。
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## 比較

日付や時刻を互いに比較するには、対応するモジュールの`compare`または`diff`関数を探しましょう。`==`、`>`、`<`のような比較演算子は_動くように見えます_が、これらの構造体に対して正しい意味での比較はしてくれません。

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## ずらす

日付、時刻、日時は、対応するモジュールの`add/2`関数を使って、時間を前後にずらすことができます。

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## 変換

`NaiveDateTime`構造体は、[`NaiveDateTime.to_date/1`][naivedatetime-to-date]と[`NaiveDateTime.to_time/1`][naivedatetime-to-time]を使って、`Date`構造体と`Time`構造体に分解できます。逆の変換は[`NaiveDateTime.new!/2`][naivedatetime-new]で行えます。

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
