# インストール

[NodeJS LTS](https://nodejs.org/en)が必要です。

> 💡 このトラックは、古い安定版でも、「current」バージョンでも、おそらく動作します。
> ただし、[設計上](https://github.com/nodejs/release#release-schedule)、奇数バージョンは決して安定しません。
> NodeJSをインストールするときは、必ず偶数バージョンを選びましょう。

Node.JSの`corepack`を使って[Yarn 4+](https://yarnpkg.com/getting-started/install)をインストールします：

```shell
corepack enable yarn
```

## インストールの確認

インストールしたばかりのバイナリを使うには、通常、新しいターミナルを開く必要があります。

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_注：表示されるバージョンは、ここに載っているものとは異なるはずです。_

## 演習のインストール

**各演習**では、テストを実行するためにいくつかのツールが必要です。

それらは、各演習のディレクトリで次のコマンドを実行するとインストールできます：

```bash
$ corepack yarn install
```

お使いのエディターによっては、Plug'n'Playインストールで動作させるために、各演習に[Editor SDK](https://yarnpkg.com/getting-started/editor-sdks)をインストールする必要があります。
この記事を書いている時点では、次のエディターに対応しています：

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
