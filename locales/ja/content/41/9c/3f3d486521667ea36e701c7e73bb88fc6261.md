# はじめに

`Complex numbers`は難しくありません。
ただ、もっと気軽な名前をつけてあげればいいだけです。


複素数はとても役に立ちます。とくに工学や科学の分野では欠かせないため、Pythonには、整数（[`int`s][ints]）や浮動小数点数（[`float`s][floats]）と並んで、[`complex`][complex]が標準の数値型として用意されています。


Pythonの`complex`の値は、本質的には2つの浮動小数点数のペアです：

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

これらは「実部」と「虚部」と呼ばれます。
「`i`（または`j`）は-1の平方根だ」と聞いたことがあるかもしれません。
今のところ、これが意味するのは、虚部が_定義により_等式`1j * 1j == -1`を満たすということだけです。
単純な考え方ですが、そこからは面白い数学的な帰結が導かれます。

Pythonでは、「虚部」は`j`で表し（_数学の教科書で目にする`i`ではありません_）、`j`は数値の直後に置く必要があります。そうしないと、Pythonがそれを変数名とみなしてしまうからです：


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


複素数を作る方法には、よく使われるものが2つあります。

1) [`complex(real, imag)`][complex]コンストラクターは、2つの`float`の仮引数を取ります：

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    このコンストラクターは、文字列の入力も解析できます。
    ただし、文字列にスペースが含まれていると失敗するという、少し変わった制約があります。

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) 複素数は、`<real part> + <complex part>j`というリテラルとして指定できます。実部が0のときは、`<complex part>j`だけでもかまいません：


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    最終的な結果は、`complex()`コンストラクターを使った場合とまったく同じです。


## 算術

小数や整数で使う[`operators`][operators]のほとんどは、複素数でも使えます。

複素数では整数除算は_**できません**_。そのため、`//`演算子や`%`演算子、`divmod()`関数は、複素数型ではエラーになります。

複素数の掛け算と割り算の規則を説明することは、このコンセプトの範囲外です（_そして、そうした計算を「手作業で」行う機会は、めったにないでしょう_）。

このテーマを深く掘り下げたい場合は、複素数についての[数学][math-complex]や[電気工学][engineering-complex]の入門書が、こうした場面を扱っています。

Pythonの標準ライブラリには、実数を扱うための便利な機能が詰まった[`math`][math-module]モジュールがあり、複素数を扱うための同等のモジュールが[`cmath`][cmath]です。
