# 説明

この演習では、お気に入りの料理本を見ながら最高のラザニアを作れるように、コードを書いていきます。

タスクは5つあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンでの想定時間を分単位で定義する

`expectedMinutesInOven`関数を定義しましょう。この関数は引数を取らず、ラザニアをオーブンに入れておくべき時間が何分かを返します。料理本によると、オーブンでの想定時間は40分です。

```haskell
expectedMinutesInOven
-- -> 40
```

## 2. オーブンに残しておく時間を分単位で計算する

`remainingMinutesInOven`関数を定義しましょう。この関数は、ラザニアが実際にオーブンに入っていた時間（分）を引数として受け取り、前のタスクで定義したオーブンでの想定時間をもとに、ラザニアをオーブンにあと何分残しておく必要があるかを返します。

```haskell
remainingMinutesInOven 30
-- -> 10
```

## 3. 準備にかかる時間を分単位で計算する

`preparationTimeInMinutes`関数を定義しましょう。この関数は、ラザニアに重ねた層の数を引数として受け取り、ラザニアの準備に何分かかったかを返します。1層あたり2分かかるものとします。

```haskell
preparationTimeInMinutes 3
-- -> 6
```

## 4. 経過時間を分単位で計算する

`totalTimeInMinutes`関数を定義しましょう。この関数は2つの引数を取ります。1つ目はラザニアに重ねた層の数、2つ目はラザニアがオーブンに入っている時間（分）です。この関数は、ラザニアの調理に合計で何分かかったかを返します。これは、準備にかかった時間（分）と、その時点でラザニアがオーブンにいた時間（分）を足したものです。

```haskell
elapsedTimeInMinutes 3 20
-- -> 26
```

## 5. ラザニアができたことを知らせる通知を作成する

`alarm`関数を定義しましょう。この関数は引数を取らず、ラザニアが食べごろになったことを伝えるメッセージを返します。

```haskell
alarm
-- -> "Ding!"
```
