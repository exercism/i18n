# はじめに

Flags属性を使うと、判別共用体で定義した値をビット位置（つまりフラグ）として表せます。フラグとして扱えば、そうした値を組み合わせられるようになり、複数の真偽条件を1つの値で表すことができます。

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

フラグを立てるには、ビット単位のOR演算子（`|||`）を使います。フラグを下ろすには、ビット単位のAND演算子（`&&&`）とビット単位の否定演算子（`~~~`）を組み合わせます。
フラグが立っているかどうかはビット単位のAND演算子で確認できますが、`HasFlag()`メソッドを使うこともできます。

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

F#言語で使えるビット演算子の一覧は、[ビット演算子のまとめ][bitwise-operators]を参照してください。

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
