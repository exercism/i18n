# 配列

**配列**は、同じ型の値を順番に並べて保持します。

型は`ARRAY{T}`と書きます。ここで`T`は保持する値の型です。文字列の配列は`ARRAY{STR}`、整数の配列は`ARRAY{INT}`です。

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

2つの`|`記号の間にある値が**配列リテラル**です。Satherは、値の個数からサイズを判断します。

## 値の取り出し

角括弧（`[]`）の中に位置を書きます。

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

数え始めは**0**で、1ではありません。そのため、最初の値は`0`にあり、3つ並んだ値の最後は`2`にあります。

## いくつある？

`.size`は配列が保持している値の数を表します。

```sather
row.size    -- 3
```

数え始めが0なので、最後の位置は常に`.size - 1`です。

```sather
row[row.size - 1]     -- "Ben"
```

存在しない位置（`row[3]`や`row[-1]`）を要求するのは、Satherが気づいてくれない間違いです。そのため、値を目で数えるのではなく、`.size - 1`と書くのがよいでしょう。

## 配列を順にたどる

配列とループは一緒に使います。変数を0から順に増やしながら位置をたどり、その変数を使って各値にアクセスします。

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
