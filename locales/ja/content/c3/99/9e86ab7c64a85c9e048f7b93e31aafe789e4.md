# 説明

最初のN個の自然数について、和の2乗と2乗の和の差を求めます。

最初の10個の自然数の和の2乗は、(1 + 2 + ... + 10)² = 55² = 3025です。

最初の10個の自然数の2乗の和は、1² + 2² + ... + 10² = 385です。

したがって、最初の10個の自然数の和の2乗と、最初の10個の自然数の2乗の和の差は、3025 - 385 = 2640です。

この問題の効率的な解法を、基本原理から自分で見つけ出す必要はありません。調べることは認められていますし、むしろ推奨されます。問題に最適なアルゴリズムを見つけることは、ソフトウェアエンジニアリングにおける重要なスキルです。
