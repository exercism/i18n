# 説明

ある基数で桁の並びとして表された数を、別の基数に変換します。

一般的な基数変換を実装しましょう。基数**a**で桁の並びとして表された数が与えられたとき、それを基数**b**に変換します。

## 注意

- 変換は自分で実装してみましょう。
  変換を代わりにやってくれるものを使ってはいけません。

## [位取り記数法](https://en.wikipedia.org/wiki/Positional_notation)について

位取り記数法では、基数**b**の数は、**b**のべき乗の線形結合として理解できます。

数42は、*10進法では*、次のことを意味します：

(4 * 10^1) + (2 * 10^0)

数101010は、*2進法では*、次のことを意味します：

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

数1120は、*3進法では*、次のことを意味します：

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

*そうです。上の3つの数はまったく同じです。おめでとうございます！*
