# 説明

この演習では、お気に入りの料理本に載っている最高のラザニアを作るためのコードを書きます。

タスクは4つあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンに入れておくべき時間を分単位で定義する

`Lasagna`クラスに`EXPECTED_MINUTES_IN_OVEN`定数を定義します。この定数には、ラザニアをオーブンに入れておくべき時間（分）を格納します。
料理本によると、オーブンに入れておくべき時間は40分です。

```Crystal
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. オーブンでの残り時間を分単位で計算する

`Lasagna#remaining_minutes_in_oven`メソッドを定義します。このメソッドは、ラザニアを実際にオーブンに入れておいた時間（分）を引数として受け取り、前のタスクで定義したオーブンでの想定時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```Crystal
Lasagna.new.remaining_minutes_in_oven(30)
# => 10
```

## 3. 準備時間を分単位で計算する

`Lasagna#preparation_time_in_minutes`メソッドを定義します。このメソッドは、ラザニアに重ねた層の数を引数として受け取り、準備にかかった時間（分）を返します。層を1つ重ねるのに2分かかるものとします。

```Crystal
Lasagna.new.preparation_time_in_minutes(2)
# => 4
```

## 4. 合計の作業時間を分単位で計算する

`Lasagna#total_time_in_minutes`メソッドを定義します。このメソッドは、名前付きの引数を2つ受け取ります。`number_of_layers`引数はラザニアに重ねた層の数、`actual_minutes_in_oven`引数はラザニアをオーブンに入れておいた時間（分）です。
このメソッドは、ラザニアの調理にかかった合計時間（分）を返します。合計時間は、準備にかかった時間（分）と、その時点でラザニアをオーブンに入れておいた時間を足したものです。

```Crystal
number_of_layers = 3
actual_minutes_in_oven = 20
Lasagna.new.total_time_in_minutes(number_of_layers, actual_minutes_in_oven)
# => 26
```
