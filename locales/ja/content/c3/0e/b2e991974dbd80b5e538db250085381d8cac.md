# ヒント

## 1. 数字だけの予約日時を解析する

- 日時の解析には、lubridateに多くの[ヘルパー関数][ref-parse]が用意されています。

## 2. 予約がすでに過ぎているかどうかを確認する

- [現在時刻を取得する][ref-now]ときは、ローカルタイムゾーンではなく`UTC`を使うことを忘れないようにしましょう。

## 3. 予約が午後にあるかどうかを確認する

- 必要なのは、日時の`hour`の部分だけです。

## 4. 予約の曜日を確認する

- イントロダクションを確認してみましょう。lubridateでは、月曜日が1日目の_デフォルト_ではありません。

## 5. 予約を変更する

- 入力はタスク1と同じ形式です。
- 元の予約は何曜日ですか？
- 金曜日にたどり着くには、何日足す必要がありますか？（入力が金曜日の予約である場合は、今日ではありません）
- **警告**: Base Rの古い`ifelse()`関数は、日時とうまく組み合わせられません。
  この種のロジックが必要な場合は、dplyrライブラリの[`if_else()`][ref-if_else]がより信頼できる選択肢です（[`Switch`][concept-switch]のコンセプトで説明されています）。
