# 説明

1つの製造元が生産できるモーターには、2つの異なる種類があります。以降、これらのモーターをモーターAとモーターBと呼びます。どちらのモーターも、生産には配線、穴あけ、組み立ての3つの工程が必要です。それぞれの工程にかかる時間は、モーターの種類によって異なります。一般に、モーターAを1台作るには、配線に`t_a_1`時間、穴あけに`t_a_2`時間、組み立てに`t_a_3`時間かかります。一方、モーターBを1台作るには、配線に`t_b_1`時間、穴あけに`t_b_2`時間、組み立てに`t_b_3`時間かかります。各工程に割り当てられた合計時間（配線に`t_1`時間、穴あけに`t_2`時間、組み立てに`t_3`時間）と、それぞれのモーターの価格（`p_a`、`p_b`）が与えられたときに、利益が最大になるモーターAとモーターBの最適な生産量を計算する関数を実装してください。

この関数には、全部で4つの入力パラメーターがあります。それぞれ次のとおりです。

1. `a_hours`: (`t_a_1`、`t_a_2`、`t_a_3`)の3要素のタプル（単位は時間）
2. `b_hours`: (`t_b_1`、`t_b_2`、`t_b_3`)の3要素のタプル（単位は時間）
3. `total_hours`: (`t_1`、`t_2`、`t_3`)の3要素のタプル（単位は時間）
4. `prices`: (`p_a`、`p_b`)の2要素のタプル（単位はドル）

出力は、(`q_a`、`q_b`、`profit`)からなる1つの3要素のタプルです。その内容は次のとおりです。

1. `q_a`: 生産すべきモーターAの最適な数量
2. `q_b`: 生産すべきモーターBの最適な数量
3. `profit`: 利益が最大となる金額（単位はドル）

そのほか、重要な点がいくつかあります。`q_a`と`q_b`はモーターの端数を生産できないため、浮動小数点数にはできません。変数に対するZ3モデルの結果は、出力する前に`int`へ変換する必要があります。Z3モデルの結果が`IntNumRef`型の場合は、`as_long()`クラスメソッドを使って整数に変換できます。不正な入力によって問題が充足不可能な場合は、Pythonの組み込み例外である`ArithmeticError()`を発生させてください。
