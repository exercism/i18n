# テスト

## 要点

- 問題のディレクトリ（例：`~/Exercism/hello-world`）に移動します。
- ターミナルで`jconsole`のセッションを開始します。
- 解答ファイルを読み込みます（例：`load 'hello-world.ijs'`）。
- `load  'general/unittest'`と入力して、単体テストのフレームワークを読み込みます。
- `unittest 'test.ijs'`と入力して、解答をテストします。
<br></br>
- 別の方法として、次のように1行でテストを実行することもできます：`jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`。

## `jconsole`のセッション

このトラックのテストは、できるだけシンプルに使えるように作られています。
例えば`hamming.ijs`という演習に取り組んでいるとします。作業は次の流れで進めます。
`hamming.ijs`を編集して、解答を書きます。
まずは次のように入力して、対話的に組み立てていきましょう。

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

次に、Jコンソールの中から、次のように入力して再読み込みします。

```j
load 'hamming.ijs'
```

続いて、次のように入力して単体テストのフレームワークを読み込みます。

```j
load 'general/unittest'
```

テストを実行するには（解答を読み込んだあとに）次のように入力します。

```j
unittest 'test.ijs'
```

あとは結果を確認しましょう。

## コマンドライン

`-js`フラグを使うと、ターミナルで1行のコマンドとしてテストを実行できます。

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
ここで、それぞれの引数が、順番に実行されるコマンドを表しています。
