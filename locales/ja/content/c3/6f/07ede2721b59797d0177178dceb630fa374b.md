# インストール

## Clojure CLIのインストール
Clojureには、ClojureのREPLを起動したり、ClojureやJavaのライブラリを使ったり、Clojureのプログラムを起動したりできるコマンドラインツールが用意されています。

Javaをインストールする必要がある場合は、[Adoptium Temurin 17](https://adoptium.net/)をおすすめします。

### Linux
次の依存関係がインストールされていることを確認してください。`bash`、`curl`、`rlwrap`、`Java`。
Clojureは、次の2つの方法のどちらでもインストールできます。

1. LinuxBrew：[Homebrew](https://brew.sh/)が必要です。

```bash
brew install clojure/tools/clojure
```

2. スクリプトインストーラー

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Mac OS X向けのHomebrew
[clojure/tools](https://github.com/clojure/homebrew-tools)のtapから、brewでコマンドラインツールをインストールします。

```bash
brew install clojure/tools/clojure
```

#### Java

Javaはどのディストリビューションでも動作します。必要であれば、brewを使ってTemurinをインストールできます。

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

WindowsでのClojureは、最近大幅に改善されました。以前はWSL2の使用をおすすめしていました。WSL2はとてもよく動作しますが、現在はPowerShellインストーラーがあります。WindowsでのClojureは現在アルファ版の状態です。既知の問題については、[clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues)を参照してください。

Javaがインストールされ、`JAVA_HOME`環境変数が設定されていることを確認して、次を実行してください。

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

WindowsにClojureをインストールするもう1つの方法は、[Scoop](https://scoop.sh/)パッケージマネージャーを使うことです。scoopをインストールするには、PowerShellを開いて、次の2つのコマンドを順番に実行してください。

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

ScoopでClojureをインストールするには、まず2つの重要なbucketを追加する必要があります。

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

これで、次のコマンドを実行してJavaとClojureをインストールする準備ができました。

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

上記の手順が正常に完了すると、次のコマンドでClojureを実行できるようになります。

```sh
clj
```

## Leiningenのインストール（任意）

もはや必須ではありませんが、フル機能のプロジェクト管理ツール[Leiningen](https://leiningen.org/)は今もサポートしています。便利なテスト、ビルド、改良されたREPLなど、さまざまな役立つタスクを提供します。

1. [lein script](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein)または[lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat)（Windows）をダウンロードします
2. シェルが見つけられる場所の`$PATH`（例：`/usr/local/bin/`）に配置します
3. 実行可能に設定します（`sudo chmod a+x /usr/local/bin/lein`）
4. `lein`を実行します。
