# はじめに

## ジェネリック型

**ジェネリック型**とは、型でパラメーター化されたジェネリックなクラスまたはインターフェースのことです。
これにより、コンパイラーはそのクラスやインターフェースに対して型の安全性を強制できます。

次の、ジェネリックでない`Container`インターフェースを見てみましょう。

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Object型を受け取って返すので、プリミティブ型以外のあらゆる型で動作します。
しかし、これには代償が伴います。`Integer`を期待して`get`を呼び出すコードもあれば、`String`を追加しようと`set`を呼び出すコードもあり、その結果、実行時に例外が発生してしまうからです。

**ジェネリッククラス**と**ジェネリックインターフェース**は、次のような形式をとります。

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

クラス名やインターフェース名のうしろに続く、山括弧（`<>`）で囲まれた型パラメーターの部分では、型パラメーター（型変数とも呼ばれます）`T1`、`T2`、…、`Tn`を指定します。
これらをクラスやインターフェースの本体で使うと、ジェネリックな型安全性が得られます。

こちらが、`Container`のジェネリック版です。

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

作成する際には、どの型を保持するのかを宣言する必要があり、コンパイラーがその制約を強制します。

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```

## リスト

**リスト**は、Javaにおける順序付きのコレクションです。
配列とは違い、[`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html)はサイズを大きくして、いくつでも項目を格納できます。
標準的な実装の1つは`ArrayList`で、サイズ変更可能な配列を基盤としています。
もう1つの標準的な実装は`LinkedList`クラスで、双方向連結リストを基盤としています。

`List`は空の場合もあれば、いくつでも（重複も含めて）項目を保持できます。
`List`は**ジェネリックインターフェース**で、どんな型のオブジェクトを格納できるかを示すように型付けされています。
たとえば、次のようになります。

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`には、要素の追加・削除・取得・存在確認に役立つさまざまなメソッドがあります。

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
