# テスト

## テストの実行

1. 演習を取得します：

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. 演習のディレクトリに移動します：

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. テストを実行します：

    ```bash
    $ ./gradlew test
    ```

ほとんどの演習では、デフォルトで最初のテストだけが実行されます。  
ほかのテストには、スキップするための`@Ignore`が付いています。  
テストを1つ解いたら、次に進むためにその次のテストから`@Ignore`を外します。

これはテスト駆動開発（略してTDD）でよく使われる進め方です。  
一度に1つの問題だけに取り組めるようにするためのものです。
