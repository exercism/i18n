# はじめに

F#の`char`型は、テキストの、アドレス指定できる最小の構成要素を表す16ビットの値で、デフォルトでイミュータブルです。

`char`は、シングルクォートを使ったリテラルとして定義できます：

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

文字列は`char`の並びです。

個々の`char`は、0始まりのインデックスを使って文字列から取り出せます：

```fsharp
"Exercism"[4] //  =>  'c'
```

文字列を繰り返し処理すると、各ステップで`char`が返されます。

次の例では、話を簡単にするために高階関数と匿名関数を使っています。
これらはシラバスの後半で詳しく扱いますが、今は文字列中の文字をループで処理するための、簡潔な書き方だと考えてください。

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

上で見たように、`char`はその`int`値にキャストできます。
これは他の文字体系でも（*少なくともある程度は*）動作します：

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

文字を比較するときには、その基になっているInt16が使われます：

```fsharp
'A' < 'D'  // =>  true
```

また、`int`を`char`にキャストすることもできます：

```fsharp
char 77  // => 'M'
```

`System.Char`ライブラリには、大文字・小文字の変換など、.NET言語で期待されるメソッドがひと通りそろっています：

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
