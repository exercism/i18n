# はじめに

`Lambda`クラスは、Haxeで関数型スタイルのプログラミングを行うための、関数型メソッドを集めたものです。Iterable全体を一度に操作できるようにします。こうした書き方は、ループ処理よりも間違いが起きにくく読みやすいので、好まれることがよくあります。便利なように、ArrayクラスとListクラスには、`Lambda`クラスにあるよく使われるメソッドのいくつかが用意されています。

`Lambda`クラスには、次のような関数があります。

- `Lambda.array`と`Lambda.list`は、IterableをArrayまたはListに変換します。常に新しいインスタンスを返します。
- `Lambda.count`は、要素の数を数えます。IterableがArrayまたはListの場合は、そのlengthプロパティを使う方が速くなります。
- `Lambda.has`は、指定した要素がIterableに含まれているかどうかを判定します。
- `Lambda.indexOf`は、指定した要素のインデックスを調べます。
- `Lambda.find`は、指定した検索関数に一致する最初の要素を見つけます。
- `Lambda.concat`は、2つのIterableを結合し、新しいListを返します。
- `Lambda.filter`は、条件を満たす要素を見つけ、新しいListを返します。

いくつかの関数を使った例を次に示します。

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
