# プレースホルダー

## `jq`のヒント

この演習では、入力のオブジェクトを受け取り、それを新しいオブジェクトに変換します。
役に立つかもしれない組み込み関数を2つ紹介します。

- [`to_entries`][x_entries]
  - この関数はオブジェクトを入力として受け取ります
  - 出力は_配列_です。配列の各要素は`{"key": "K", "value": V}`というオブジェクトです
    - 各`K`は、入力オブジェクトのキーです
    - 各`V`は、`K`に対応する値です。
- [`from_entries`][x_entries]
  - 逆の操作です
  - `{"key": K, "value": V}`というオブジェクトの配列を受け取り、1つのオブジェクトを組み立てます

例を見てみましょう。

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

次のように出力されます。

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
