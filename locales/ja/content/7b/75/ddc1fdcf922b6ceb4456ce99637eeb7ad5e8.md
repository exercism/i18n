# タプル

[タプル][tuple]とは、要素を順番に並べた有限個のリストで、変更できない（イミュータブル）ものです。
タプルでは、すべての位置が固定の型を持つ必要があります。
そのため、コンパイラーは各位置にどんな型があるのかを把握しています。
タプルで使う型は位置ごとに異なっていてもかまいませんが、それらの型はコンパイル時に判明している必要があります。

## タプルの作成

タプルの値の型をコンパイル時に解釈できるかどうかによって、タプルの作成方法は変わります。
値がコンパイル時に判明しているなら、タプルのリテラル構文で作成できます。そうでなければ、明示的に宣言する必要があります。
また、値の型がタプルで指定した型と一致していること、値の個数が指定した型の個数と一致していることも重要です。
タプルのリテラル構文で定義する例を次に示します。

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

`Tuple`クラスを使ってタプルを作成することもできます。

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

あるいは、タプルを代入する変数の型を明示的に指定することもできます。

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

タプルの型を明示的に指定すると、ある位置が共用体型を持つように定義できるので便利です。
つまり、1つの位置に複数の型を持たせられます。

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## 変換

### 配列からタプルを作成する

`Tuple`クラスの`from`メソッドを使うと、配列からタプルを作成できます。
このとき、タプルの型を指定する必要があります。

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### 配列への変換

`to_a`メソッドを使うと、タプルを配列に変換できます。
変換後の配列の要素の型は、タプルの各フィールドの型の共用体になります。

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## 要素へのアクセス

配列と同じく、タプルのインデックスは0から始まります。つまり、最初の要素はインデックス0にあります。
ただし配列と違い、各要素の型は固定でコンパイル時に判明しているので、タプルにインデックスでアクセスするときは、その位置に固有の型が得られます。
タプルの要素にアクセスするには、`[]`演算子を使います。

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

配列から要素にアクセスする場合とのもう1つの違いは、インデックスを指定すると、そのインデックスがタプルの範囲内にあるかどうかをコンパイラーが確認してくれることです。
そのため、実行時エラーではなくコンパイル時エラーになります。

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

ただし、インデックスが変数に格納されていると、そのインデックスがタプルの範囲内にあるかどうかをコンパイル時に確認できず、代わりに実行時エラーになります。

## 部分タプル

`[]`演算子に範囲を渡すと、タプルの部分タプルを取得できます。
返ってくるのは、指定した範囲の要素を持つ新しいタプルです。
範囲はコンパイル時に指定する必要があります。そうでなければ、部分タプルの要素の型をコンパイラーが把握できません。
つまり、範囲は範囲リテラルでなければならず、変数に代入してはいけません。

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## タプルをいつ使うか

タプルは、値の型がコンパイル時に判明している固定個の値をまとめたいときに便利です。
タプルは変更できないため、配列よりもメモリーの使用量が少なく、処理も速いからです。
もう1つの用途は、メソッドから複数の値を返すことです。
タプルの各位置はそれぞれ異なる型を持てるので、値の型が異なる場合に特に役立ちます。

サイズが増減するデータ構造が必要な場合や、頻繁に変更する必要がある場合には、タプルを使うべきではありません。
