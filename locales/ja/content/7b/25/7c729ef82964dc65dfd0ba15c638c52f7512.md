# はじめに

カスタム型は、Gleamで新しいデータ型を定義する仕組みです。複数の_バリアント_を持ち、それぞれに名前があります。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

カスタム型のそれぞれのケースは、任意でデータを持てます。また、ケースごとに持てるデータの型は異なっていてもかまいません。バリアントがデータを持つ場合、それは_レコード_と呼ばれます。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

特定のケースの値を作るには、追加のデータを持たないケースなら名前をそのまま参照し（`Spring`）、データを持つケースなら関数として呼び出します（`SomeInt(2)`）。

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

カスタム型は、Gleamのあらゆるものと同様に_構造的等価性_を持ちます。つまり、同じバリアントで同じデータを持つ2つの値は等しいとみなされます。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

カスタム型のバリアントは、`case`式を使ってパターンマッチできます。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
