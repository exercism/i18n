# 説明の補足

## ヒント

'The Twelve Days of Christmas'の歌詞を出力する`recite`関数を実装する必要があります。型について不安があるときは、用意されているシグネチャを使ってもかまいませんが、それに創造性を縛られないようにしましょう。

この演習では、テキストデータを扱います。歴史的な理由から、Haskellの`String`型は、文字の配列である`[Char]`と同じ意味です。テキストデータをより効率的に扱うには、`Text`型を使えます。

この演習の任意の発展として、次のことができます。

- Haskellの[文字列型](https://haskell-lang.org/tutorial/string-types)について読む。
- package.yamlの依存関係のリストに`- text`を追加する。
- `Data.Text`を[次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)インポートする。

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- たとえば`recite :: Int -> Int -> [Text]`と書き、`Data.Text`のコンビネーターを`T.pack`のように参照する。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べる。
- TwelveDays.hs内の`String`をすべて`Text`に置き換える。つまり次のとおりです。

```haskell
recite :: Int -> Int -> [Text]
```

この部分は完全に任意です。
