# 指示

陛下は、[カルマル同盟][kalmar_union]の首都コペンハーゲンでディナーパーティーを開こうとしています。
一年で最大のパーティーで、すべての貴族が招待されています。
しかし、陛下を毒殺しようという陰謀があるという噂が、国中に広まっています。

そこで陛下は、毒見役であるあなたに、食べ物や飲み物に毒が盛られていないかを調べるよう命じました。
陛下が料理として出す予定なのは**Mushroom pasties**だけですが、飲み物はいろいろな種類があります。

## 1. 食べ物が正しいか確認する

陛下が注文したものと違う食べ物なら、毒が入っている可能性が高いです。
陛下の注文と違う食べ物は、捨てることになります。

`check_food?`メソッドを実装しましょう。このメソッドは、食べ物の名前を`String`として受け取る`food`という引数を取ります。
このメソッドは、`Mushroom pasties`ならその食べ物を返し、そうでなければ`nil`を返します。

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. 飲み物に毒が入っていないか確認する

飲み物に毒が入っている可能性もありますが、毒かどうかの見分けは少し難しいです。
名前に`i`という文字が含まれてい**ない**飲み物には毒が入っています。大文字か小文字かは問いません。
毒が入っている飲み物は、捨てることになります。

`check_drink?`メソッドを実装しましょう。このメソッドは、飲み物の名前を`String`として受け取る`drink`という引数を取ります。
このメソッドは、毒が入っていなければその飲み物を返し、そうでなければ`nil`を返します。

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. 飲み物を差し替える

陛下は、招待した客に食べ物に毒が入っているのではないかと心配させたくはありません。
そのため、飲み物に毒が入っている場合は、別の飲み物、つまり**Apple juice**に差し替えることになります。

`replace_drink`メソッドを実装しましょう。このメソッドは、飲み物の名前を`String`として受け取る`drink`という引数を取ります。
このメソッドは、毒が入っていなければその飲み物を返し、そうでなければ`"Apple juice"`を返します。

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
