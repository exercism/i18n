# is_を付けたdef

[comment]: # (2つのパラメーターが必要です:)
[comment]: # (- expected: 正しい名前)
[comment]: # (- actual: 生徒が使った誤った名前)

Elixirには固有の命名規則があり、その中には[真偽値を返す関数](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)の名前の付け方も含まれます。

> 真偽値を返す関数は、末尾にクエスチョンマークを付けて命名します。

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

ガードや、真偽値を返しかつガード内でも有効な一部の組み込み関数やマクロは別の規則に従い、`is_`を前に付けて命名します（`def is_integer`、`defguard is_foo`、`defmacro is_foo`）。この2つの規則を混ぜてはいけません。
