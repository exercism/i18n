# メンテナーのリポジトリ権限

トラックメンテナーとは、そのトラックのGitHubチームのメンバーである人のことです。トラックチームのメンバーになれるのは、招待された人だけです。

```exercism/note
トラックメンテナーになりたい場合は、[フォーラム](https://forum.exercism.org/c/exercism/building-exercism/125)でトピックを立ててください。
```

## メンテナンスカテゴリー

メンテナンスカテゴリーは5つあります。

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

トラックのメンテナンスカテゴリーは、3つの要素で決まります。

1. トラックがアクティブかどうか（つまり、学習者がウェブサイトでそのトラックに参加できるかどうか）
2. トラックメンテナーの人数
3. トラックメンテナーのうち、`cross-track-maintainers` GitHubチームにも所属している人の人数

メンテナンスカテゴリーを決めるには、この表を見て、トラックに当てはまる最初のカテゴリーを探します。

| カテゴリー            | アクティブか | メンテナーの人数          | クロストラックメンテナーの人数    |
| --------------------- | ------------ | ------------------------- | --------------------------------- |
| wip-track             | いいえ       | 問わない                  | 問わない                          |
| unmaintained          | はい         | 0                         | 0                                 |
| maintained-autonomous | はい         | 0より大きい               | メンテナーの人数と同じ            |
| maintained-solitary   | はい         | 1                         | 0                                 |
| maintained            | はい         | 1より大きい               | メンテナーの人数より少ない        |

## リポジトリの権限

メンテナンスカテゴリーは、トラックのGitHubリポジトリの権限を設定するために使われます。

| カテゴリー            | PRが必要 | PRの承認が必要 | クロストラックチームのレビュー |
| --------------------- | -------- | -------------- | ------------------------------ |
| wip-track             | いいえ   | いいえ         | いいえ                         |
| unmaintained          | はい     | はい           | はい                           |
| maintained-solitary   | はい     | はい           | はい                           |
| maintained-autonomous | はい     | いいえ         | いいえ                         |
| maintained            | はい     | いいえ         | いいえ                         |

```exercism/caution
メンテナーが`main`にプッシュできるのは、`wip-track`カテゴリーだけです。
```

```exercism/caution
ツールのリポジトリは、その内容が[CODEOWNERSファイル](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners)で保護されているため、常にPRの承認が必要です。
```
