# ヒント

## 全般

- 真偽値を扱うための演算子は3つあります。`not`、`&&`、`||`です。
- 1つの式の中で複数の演算子を組み合わせることができます。

## 1. パックマンがゴーストを食べられるかどうかを定義する

- 関数は`Bool`の値を戻す必要があります。
- 結果を出すために、真偽値演算子`&&`を使って引数を組み合わせることができます。

## 2. パックマンが得点するかどうかを定義する

- 関数は`Bool`の値を戻す必要があります。
- 結果を出すために、真偽値演算子`||`を使って引数を組み合わせることができます。

## 3. パックマンが負けるかどうかを定義する

- 関数は`Bool`の値を戻す必要があります。
- 結果を出すために、真偽値演算子`&&`と`not`を使って引数を組み合わせることができます。

## 4. パックマンが勝つかどうかを定義する

- 関数は`Bool`の値を戻す必要があります。
- 真偽値演算子`&&`と`not`を使って、引数と、すでに実装した関数の1つの戻り値を組み合わせることができます。
