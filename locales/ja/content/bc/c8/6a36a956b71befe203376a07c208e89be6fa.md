# はじめに

Unisonは、真と偽の値を`Boolean`型で表します。値は`true`と`false`の2つだけです。

```unison
trueVariable = true
falseVariable = false
```

真偽値の式は、and（`&&`）、or（`||`）、not（`not`）という演算子を使って評価できます。

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Unisonの真偽値の式では、短絡評価が行われます。`&&`の式で最初の引数が`false`なら、2つ目の引数を評価する必要はありません。同じように、`||`の式で最初の引数が`true`なら、その式はすぐに`true`を返します。

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
