# はかり

## ストーリー

この演習では、はかりをモデル化します。

重さはポンドまたはキログラムで設定・取得でき、負の値にはできません。

重さはSI単位または米国単位（ポンドとオンス）で表示できます。

重さには風袋調整を適用できます（たとえば、容器の重さを差し引くためなど）。はかりの精度には疑いがあるため、この値はどんな値でもかまいません（負の値や、表示される重さが負になる値でも構いません）。セキュリティ上の理由から、この値は取得できません。

次の点に注意してください。

```
display-weight = input-weight - tare-adjustment
```

換算率は次のとおりです。

- 1ポンドは16オンス
- 1ポンドは2.20462キログラム

たとえば：

- 60キログラムは132.2772ポンド
- 132.2772ポンドは132ポンド4オンス

## タスク

これらは、はかりの演習に合うタスクの例です。

- はかりに重さを設定できるようにする
- 負の入力の重さが拒否されるようにする
- 米国単位の重さを取得できるようにする
- はかりの単位をポンドに設定できるようにする
- はかりに風袋調整を適用できるようにする
