# 説明

英語からピッグ・ラテンに翻訳するプログラムを実装してください。

ピッグ・ラテンは、子どもたちが考え出した言葉遊びの言語で、わざとわかりにくく作られています。いくつかの簡単なルール（下記）に従いますが、速く話されると、子どもでない人（や、母語話者でない人）には理解するのがとても難しいものです。

- **ルール1**：単語が母音で始まる場合は、単語の末尾に"ay"の音を付けます。単語の先頭にある"xr"と"yt"は母音として発音されることに注意してください（例："xray" -> "xrayay"、"yttria" -> "yttriaay"）。
- **ルール2**：単語が子音で始まる場合は、その子音を単語の末尾に移動し、単語の末尾に"ay"の音を付けます。子音の音は複数の子音からできていることもあり、これを子音クラスターと呼びます（例："chair" -> "airchay"）。
- **ルール3**：単語が子音とそれに続く"qu"で始まる場合は、それらを単語の末尾に移動し、単語の末尾に"ay"の音を付けます（例："square" -> "aresquay"）。
- **ルール4**：単語の中で"y"が子音クラスターのあとに来る場合、または2文字の単語の2文字目である場合、"y"は母音として発音されます（例："rhythm" -> "ythmrhay"、"my" -> "ymay"）。

エッジケースに対応するためのルールがほかにもいくつかあり、地域ごとの変種もあります。

詳しくは<http://en.wikipedia.org/wiki/Pig_latin>を参照してください。
