# はじめに

## 無名関数

Gleamの関数は第一級の値です。つまり、関数はふつうの値と同じように、変数に代入したり、引数として渡したり、ほかの関数から返したりできます。

モジュールで定義した名前付きの関数は、その名前で参照できます。

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleamには無名関数もあり、これはほかの関数の中で定義します。

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

関数の型は、無名関数とよく似た構文で書きます。`Int`と`Float`を受け取って`Int`を返す関数の型は、次のように書きます。

```gleam
fn(Int, Float) -> Int
```

無名関数は、定義された時点でスコープにあった変数を参照できます。このような関数を_クロージャ_と呼びます。

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_関数キャプチャ_構文を使うと、1つの引数を関数に渡す無名関数を手軽に作れます。次の2つの式は同じ意味です。

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
