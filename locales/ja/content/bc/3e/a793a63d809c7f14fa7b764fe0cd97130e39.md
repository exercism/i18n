# 概要

Elixirには、整数と浮動小数点数という2種類の数値があります。

整数は、小数点を含まない数値です。

```elixir
integer = 3
# => 3
```

整数を扱うための便利な関数は、[`Integer`][integer]モジュールにあります。

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

大きな整数（浮動小数点数も同様）は、通常、3桁ごとにアンダースコアで区切ってグループ化して書きます。

```elixir
1_000_000
# => 1000000
```

Elixirでは[任意精度演算][arbitrary-precision-arithmetic]を使っているため、数値の最大サイズは、システムで利用できるメモリによってのみ制限されます。

Elixirは、[2進数、8進数、16進数の整数][integers-in-other-bases]を入力するための短縮記法にも対応しています。

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## 比較

整数と浮動小数点数は、同じ値であれば等しい（[`==`][kernel-equal]）とみなされます。ただし、型が異なるため、厳密に等しい（[`===`][kernel-strictly-equal]）と判定されることはありません。

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
