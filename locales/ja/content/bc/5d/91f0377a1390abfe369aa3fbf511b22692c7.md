# 文字列

**文字列**とは、テキストのことです。Satherで文字列を表す型は`STR`で、文字列は二重引用符で囲んで書きます。

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## 文字列の連結

`+`は2つの文字列を端から端までつなげます。

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

2つの文字列の間には何も入らないので、スペースが必要なら自分で書かなくてはなりません。省くと`"JeanSibelius"`になります。

## 長さはどれくらい？

`.size`は、文字列が何文字あるかを返します。これは整数なので、型は`INT`です。

```sather
"Sibelius".size      -- 8
```

`.size`のあとには括弧（`()`）がありません。引数を取らないルーチンと同じです。

## 一部を取り出す

`.head(n)`は最初の`n`文字です。`.tail(n)`は最後の`n`文字です。

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head`は前から数え、`tail`は後ろから数えます。どちらも元の文字列には手を付けず、新しい文字列を返します。
