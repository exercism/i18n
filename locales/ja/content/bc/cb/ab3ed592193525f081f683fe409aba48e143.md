# はじめに

`switch`式を使うと、ある値を複数のパターンのうちの1つに照合し、対応する値を返したり、対応する処理を行ったりできます。この対応関係は、`=>`という記号で表します。さらに、それぞれのパターンには、`when`キーワードで導入する任意のケースガードを付けられます。switchのその「アーム」が選ばれるには、ケースガードの式が`true`と評価される必要があります。ケース（_switchアーム_とも呼びます）は書かれた順に評価され、一致が見つかった時点で処理は打ち切られ、対応する値が返されます。

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
