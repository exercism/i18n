# 概要

浮動小数点数とは、小数点を含む小数または整数のことです（`3.14`、`-1.7`、`99.99`、`2048.0`など）。

Common Lispのfloat型は、それぞれ独自の特性と精度を持ついくつかのサブタイプに分かれています。short-float、single-float、double-float、long-floatです。

short-floatサブタイプは、通常4つの中で最もメモリ使用量が少なく、精度も最も低くなります。メモリ使用量が気になるものの、精度はそれほど重要でない場面に適しています。

single-floatサブタイプは、メモリ使用量と精度のバランスが取れています。汎用的な浮動小数点計算によく使われます。

double-floatサブタイプは、single-floatよりも高い精度を持ち、科学技術計算や数値シミュレーションなど、より正確な計算が求められる用途に適しています。

long-floatサブタイプは、4つの中で最も高い精度を持ちますが、ほかのサブタイプより多くのメモリを必要とすることがあります。非常に正確な計算が求められる特殊な用途で使われるのが一般的です。

これらのサブタイプのおかげで、Common Lispプログラマーは、アプリケーションの要件に合わせて適切な精度とメモリ使用量を選べます。

一般に、整数だけを扱う場合は、整数を使うのがおすすめです。浮動小数点数は計算を何度も重ねるうちに精度が落ちていきますが、整数にはその心配がありません。

## リファレンス

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
