# デバッグ

テストが失敗すると、何が問題だったのか、どの入力で起きたのかを説明するメッセージが表示されます。また、[コンソールへの出力][fmt-println]も表示されるので、これを手がかりにすることもできます。コンソールに出力するには、次のように書きます。

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

注意：ブラウザー内のエディターでデバッグするとき、例えば`fmt.Print`を使うと出力のあとに改行が追加されません。これが原因で`go test --json`にバグが発生し、テストの出力が乱れることがあります。
