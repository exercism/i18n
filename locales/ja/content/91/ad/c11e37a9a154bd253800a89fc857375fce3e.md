# 概要

`SYMBOL:`は値を*保持する*わけではありません。ただの名前です。値は名前空間の中にあり、その名前がキーとして値を指します。

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

スコープは2つあります。

- **グローバル**：`set-global`、`get-global`、`change-global`で読み書きします。値はプロセスの生存期間中ずっと残ります。
- **動的**：`set`、`get`、`change`で読み書きします。束縛は`with-variable`の形式が実行されている間だけ有効で、間に挟まるすべてのシグネチャを変えることなく、外側のコードが内側のコードから見える値を「注入」できます。

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:`と`SYMBOLS:`はボキャブラリーの読み込み時にシンボルを宣言するので、ファイルをまたいで共有できる参照になります。
