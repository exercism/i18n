# 説明

魔法使いの卵であるElyseは、修行を続けています。
彼女は手品を披露するために、いくつかのカードのデッキを渡されます。
少し簡単にするために、彼女は1から10のカードだけを使います。
どのカードも1枚ずつしかなく、デッキに重複はありません。

この演習では、JuliaのBaseライブラリのメソッドを使って、配列の中身を分析します。

## 1. カードが存在するか判定する

Elyseは、カードがデッキに入っているかどうか、つまりデッキに特定の数値が含まれているかどうかを判定したいと考えています。

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. カードの位置を探す

Elyseは、デッキの中でのカードの位置（インデックス）を知りたいと考えています。
カードがデッキにない場合は、`nothing`を返します。

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. 各カードが偶数かどうかを判定する

Elyseは、すべてのカードが偶数かどうか、つまりデッキの各数値が偶数かどうかを知りたいと考えています。

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. デッキに奇数のカードが含まれているか確認する

Elyseは、デッキに奇数があるかどうかを知りたいと考えています。

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. 最初の偶数のカードの位置を判定する

Elyseは、最初の偶数のカードの位置を知りたいと考えています。
デッキに偶数のカードがない場合は、`nothing`を返します。

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. デッキから最初の奇数のカードを取り出す

Elyseは、最初の奇数のカードの値を知りたいと考えています。
デッキに奇数のカードがない場合は、`nothing`を返します。

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
