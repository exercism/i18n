# 説明

チェスのファンなら、自分だけのチェスゲームを書いてみたいですよね。
すでにネット上にはたくさんのチェスの実装が公開されていますが、自分で作るものは世界に一つだけのものです！

まずは、駒を動かすための基本的な仕組みから実装していきます。

チェスは、8マス×8マスの盤の上で行います。
マスは、アルファベット1文字と数字1つで表します。

## 1. ランクとファイルの範囲を定義する

このゲームでは、盤面のランクを保持する必要があります。
ランクとは盤面の行のことで、1から8までの番号が付いています。

また、盤面のファイルも保持する必要があります。
ファイルとは盤面の列のことで、AからHまでのアルファベットで表します。

それぞれランクとファイルの範囲を保持する`Chess::RANKS`と`Chess::FILES`という定数を定義します。

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. マスが有効かどうかを確認する

このゲームでは、マスが有効かどうかを確認する必要があります。
マスは、そのランクとファイルが、それぞれランクとファイルの範囲内にあれば有効です。

`rank`というランクを表す整数と、`file`というファイルを表す文字を入力として受け取る`Chess.valid_square?`メソッドを定義します。
このメソッドは、ランクとファイルがそれぞれの範囲内にあれば`true`を、そうでなければ`false`を返します。

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. プレイヤーのニックネームを取得する

このゲームでは、プレイヤーのニックネームを取得する必要があります。
ニックネームは、プレイヤーの名の最初の2文字と、姓の最後の2文字を組み合わせたものです。
ニックネームは大文字にします。

プレイヤーの名を表す文字列`first_name`と、姓を表す文字列`last_name`を入力として受け取る`Chess.nickname`メソッドを定義します。
このメソッドは、プレイヤーのニックネームを大文字の文字列として返します。

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 移動のメッセージを作成する

このゲームでは、どのプレイヤーがどのマスに移動したかを伝えるメッセージを作成する必要があります。
メッセージには、プレイヤーのニックネームと、移動先のマスを使います。
また、マスのファイルとランクがファイルとランクの範囲内にあるかどうかを確認して、その移動が有効かどうかも判断する必要があります。

移動が有効な場合、メッセージは`"{nickname} moved to {square}"`とします。
移動が無効な場合、メッセージは`"{nickname} attempted to move to {square}, but that is not a valid square"`とします。

プレイヤーの名を表す文字列`first_name`、姓を表す文字列`last_name`、そして移動先のマスを表す文字列`square`を入力として受け取る`Chess.move_message`メソッドを定義します。
このメソッドは、その移動のメッセージを文字列として返します。

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
