# はじめに

## ビット演算

ビット演算を使うと、2進数の個々の桁を操作できます。

Elmでは、[Bitwiseモジュール](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)でいくつかのビット演算子が提供されています。

### 基本的な演算

数値の個々のビットを操作することを_マスキング_と呼びます。
_マスク_とは、特定のビットをある決まったパターンにした数値で、`and`や`or`、`xor`などのビット演算子を使って別の数値を操作するために使います。

#### and

`and`は、2つの数値の両方で`1`になっているビットだけを残して、それらを結合します。
これは、特定のビットがセットされているかどうかを調べるときに便利です。
たとえば、ある数値の4番目のビットが`1`にセットされているかを調べるには、`01000`（10進数の`8`）というマスクと`and`して、結果が0以外になるかを見ます。

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

#### or

`or`は、どちらか一方または両方の数値で`1`になっているビットを`1`にして、2つの数値を結合します。
これは、特定のビットを`1`にするときに便利です。
たとえば、`10101`の2番目のビットをセットするには、`00010`というマスクと`or`します。

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

#### 排他的論理和（xor）

`xor`は、片方の数値で`1`、もう片方で`0`になっているビットを`1`にして、2つの数値を結合します。
これは、ビットを反転させて反対の値にするときに便利です。

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

#### 補数

`complement`は、数値の各ビットを反転させます（`0`は`1`に、`1`は`0`になります）。

この結果、正の数は負の数に、負の数は正の数になります。
2進数では、負の数は一番左の位を`1`にして表すからです。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

#### ビットシフト

次の演算子は、ビットを指定した桁数だけ左または右に移動させます。これは実質的に、2の累乗を掛けたり割ったりすることと同じです。

`shiftLeftBy`はビットを左に移動させ、右側から`0`で埋めます。
たとえば、`21`を3桁左にシフトするには次のようにします。

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

これは`21 * 2^3 = 21 * 2 * 2 * 2 = 168`と同じです。

`shiftRightBy`はビットを右に移動させます。

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

2桁右にシフトすることは、整数を4で割ることと同じです。

この関数は、一番左のビットの値をそのまま複製することに注意してください。
そのため、負の数は負のままになります。

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

右にシフトして0で埋めたい場合は、`shiftRightZfBy`を使います。

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
