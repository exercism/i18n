# 説明

むかしむかし、格子窓のある奇妙な家に、風変わりなプログラマーが住んでいました。ある日、そのプログラマーはオンラインの求人サイトから、パーティーロボットを作る仕事を引き受けました。ロボットは、人々にあいさつをして、席へ案内するはずでした。最初のバージョンはとても機械的で、プログラマーに人づきあいの経験が足りないことがあらわれていました。そのうちのいくつかは、次のバージョンにもそのまま受け継がれてしまいました。

## 1. パーティーに来た新しいゲストを歓迎する

`Welcome`関数を実装して、与えられた名前を使った歓迎のメッセージを返すようにしましょう。

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. 今日が誕生日の新しいゲストを歓迎する

`HappyBirthday`関数を実装して、その人の名前と年齢を使った誕生日のメッセージを返すようにしましょう。残念ながら、このプログラマーは少し見栄っ張りなので、ロボットはゲスト全員の誕生日を知っていることを披露しなければなりません。

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. 道案内をする

`AssignTable`関数を実装して、道案内ができるようにしましょう。この関数は5つの入力を受け取ります。

- 迎える新しいゲストの名前（`string`）
- テーブル番号（`int`）
- 隣に座る人の名前（`string`）
- テーブルのある方向（`string`）
- テーブルまでの距離（`float64`）

正確な結果の形式は、下の例で確認できます。

ロボットは、テーブル番号を3桁の形式で伝えます。桁数が3桁に満たない場合は、先頭に0を補って3桁にします（例：3は003になります）。ロボットはテーブルまでの距離も伝えます。幸いなことに、その精度は1桁までに限られています。

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
