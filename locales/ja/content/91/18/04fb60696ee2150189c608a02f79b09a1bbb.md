# 指示

ここでのタスクは、GPSの座標を解析することです。
各座標は、半球を明示する[十進度形式](https://en.wikipedia.org/wiki/Decimal_degrees)の変種で書式化されています：

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

各構成要素に使える値は次のとおりです：

- `<LATITUDE_DEGREES>`：0..90の範囲（両端を含む）の浮動小数点数
- `<LATITUDE_HEMISPHERE>`：`N`または`S`
- `<LONGITUDE_DEGREES>`：0..180の範囲（両端を含む）の浮動小数点数
- `<LONGITUDE_HEMISPHERE>`：`E`または`W`

たとえば、`"48.8584 N, 2.2945 E"`は次のように解析されます：

- `<LATITUDE_DEGREES>`：48.8584
- `<LATITUDE_HEMISPHERE>`：N
- `<LONGITUDE_DEGREES>`：2.2945
- `<LONGITUDE_HEMISPHERE>`：E

11個のタスクに分けて、GPSの座標を少しずつ解析していきます。
ここでは、Prologの[確定節文法](https://en.wikipedia.org/wiki/Definite_clause_grammar)（DCG）サポートを使います。これは構造化されたテキストを解析するために設計されたものです。

````exercism/note
まずは始めやすいように、スタブファイルにはすでに次のように[`dcg/basics`ライブラリ](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl)が読み込まれています：

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. カンマを解析する

`comma`ルールを実装して、1つのカンマ（`","`）を解析できるようにします：

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. 空白を解析する

`space`ルールを実装して、1つの空白（`" "`）を解析できるようにします：

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. 改行以外のすべての空白文字に対応する

`space`ルールを変更して、改行を除く_すべての_空白文字を解析できるようにします：

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. 緯度の半球を解析する

緯度の半球は`"N"`か`"S"`のどちらかで、それぞれ`north`または`south`というアトムに解析されます。
`latitude_hemisphere`ルールを実装して、緯度の半球を解析できるようにします：

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. 経度の半球を解析する

経度の半球は`"E"`か`"W"`のどちらかで、それぞれ`east`または`west`というアトムに解析されます。
`longitude_hemisphere`ルールを実装して、経度の半球を解析できるようにします：

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. 度を解析する

緯度や経度の度は、浮動小数点数として定義されています。
`degrees`ルールを実装して、浮動小数点数を解析できるようにします：

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. 緯度の度を解析する

緯度の度は、ただの浮動小数点数ではなく、0..90の範囲（両端を含む）の浮動小数点数です。
`latitude_degrees`ルールを実装して、上記の範囲を使って緯度の度を解析できるようにします：

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. 経度の度を解析する

経度の度は、ただの浮動小数点数ではなく、0..180の範囲（両端を含む）の浮動小数点数です。
`longitude_degrees`ルールを実装して、上記の範囲を使って経度の度を解析できるようにします：

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. 緯度を解析する

緯度には、度と半球という2つの部分があり、それらは空白で区切られています。
`latitude`ルールを実装して、緯度を解析できるようにします：

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. 経度を解析する

緯度には、度と半球という2つの部分があり、それらは空白で区切られています。
`latitude`ルールを実装して、緯度を解析できるようにします：

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. 座標を解析する

座標には、緯度と経度という2つの部分があり、それらはカンマとそれに続く空白で区切られています。
`coordinate`ルールを実装して、緯度（度と半球）の両方を解析できるようにします：

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
