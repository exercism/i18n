# はじめに

これまでは、メソッドに渡す引数が、メソッドで宣言された仮引数に、その位置によって対応付けられることを見てきました。別の方法として、引数の位置ではなく、宣言された仮引数の識別子を指定して引数を対応付けるやり方があります。とくに、メソッドがたくさん引数を取る場合に役立ちます。

次のコードは、この構文を示しています。

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
