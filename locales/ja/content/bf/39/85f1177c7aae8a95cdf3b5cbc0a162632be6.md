# CLI

## セットアップ

Purescriptをインストールする最も簡単な方法は、Node.jsとNPMを使うことです。

Node.jsがまだインストールされていない場合は、[Node.jsのウェブサイト][nodejs-website]からダウンロードできます。Node.jsが使えるようになったら、ターミナルで次のコマンドを入力して、PureScriptコンパイラーとSpagoパッケージマネージャー兼ビルドツールをインストールしてください。

```shell
npm install -g purescript spago
```

詳しくは、[PureScriptリポジトリー][purescript-repository]を参照してください。

## 必要なもの

演習の依存関係をインストールします：

```shell
spago install
spago build
```

## テストに合格するには

次のコマンドでテストを実行します：

```shell
spago test
```

テストスイートでは、最初のテスト以外はすべてスキップされています。これは、演習を一歩ずつ解き進められるようにするためです。

1つのテストに合格したら、`xit`を`it`に変えることで、次のテストを有効にできます。

## 解答を提出する

スキップされているテストがなくなり、すべてに合格したら、次のコマンドで解答を提出できます：

```shell
exercism submit src/<NAME>.purs
```

## カスタムテストを書く

独自のカスタムテストを追加したい場合は、新しいファイル`test/Custom.purs`を作成し、解答と一緒にそのファイルも提出します：

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
