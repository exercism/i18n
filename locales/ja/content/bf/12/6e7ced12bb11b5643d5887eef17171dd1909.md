# 説明

マジシャンを目指すElyseは、基本をいくつか練習する必要があります。Elyseは、思い通りに操りたいカードの山を持っています。

少し簡単にするために、1から10のカードだけを使います。

カードの山は`queue`で表され、山の一番下がキューの先頭、山の一番上がキューの最後になります。

## 1. 山の一番上にカードを挿入する

`insert_top`関数を実装してください。この関数は、渡された新しいカードを山の一番上に追加した、山のコピーを返します。

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. 山の一番上のカードを取り除く

`remove_top_card`関数を実装してください。この関数は、一番上のカードを取り除いた山のコピーを返します。渡された山が空の場合は、元の山をそのまま返します。

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. 山の一番下にカードを挿入する

`insert_bottom`関数を実装してください。この関数は、渡された新しいカードを山の一番下に追加した、山のコピーを返します。

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. 山の一番下のカードを取り除く

`remove_bottom_card`関数を実装してください。この関数は、一番下のカードを取り除いた山のコピーを返します。渡された山が空の場合は、元の山をそのまま返します。

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. 山のサイズを確認する

`check_size_of_stack`関数を実装してください。この関数は、山のサイズが与えられた`stack_size`と同じかどうかを調べます。

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
