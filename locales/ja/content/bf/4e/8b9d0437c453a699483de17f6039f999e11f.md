# はじめに

Pythonでは、[`enum`][enum-docs]とは、一意の`literal`、つまり`constant`な値に結び付けられた名前の集まりです。
`Enums`は、`Enum`クラスを継承する、つまりサブクラス化することで定義します。
組み込みの`enum`型はモジュール`enum`で利用でき、クラス`Enum`は`from enum import Enum`を使ってインポートできます。


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

`enum`のメンバーの値には、`str`や`tuple`、`float`など、任意のデータ型を指定できることに注意してください。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

`enum`の中で2つのメンバーに同じ値を代入すると、後から代入されたメンバーは先のメンバーのエイリアスになります。1つの`enum`の異なるメンバーに同じ名前を使うことはできません。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

`enum`のメンバーを反復処理するには、標準の`for member in`構文を使います。

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

`Enum`のメンバーは、[`is`（_同一性演算子_）][identity-keyword]や`is not`を使って比較できます。`==`や`!=`（_等価演算子_）も同様に機能します。

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

ある値に対応する`enum`のメンバーにアクセスするには、`<EnumName>(<value>)`を使います。

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
