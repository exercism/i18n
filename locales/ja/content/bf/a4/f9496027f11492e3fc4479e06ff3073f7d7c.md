# はじめに

## コメント

Exercismのx86-64トラックでは、アセンブラーとして**NASM**（The Netwide Assembler）を使います。
NASMでは、コメントの先頭にセミコロン（`;`）を付けます。

コメントはプログラムのどこにでも書くことができ、`;`より後ろはすべてアセンブラーに無視されます。

## 定数

NASMでは、**equ**を使ってアセンブル時の定数を定義できます。
たとえば、次のように書くと`UNIVERSE`という名前の定数を値`42`で定義できます：

```x86asm
UNIVERSE equ 42
```

定数は定義されたときに一度だけ評価され、あとから再定義することは_できません_。

## 汎用レジスタ（GPRs）

アセンブリでは、変数の代わりに、値を保存するために通常レジスタを使います。
**CPUレジスタ**は、コンピューターのプロセッサー内部にある高速なメモリーの一部です。
ほとんどの計算は、CPUのレジスタで行われます。

レジスタのなかには、さまざまな計算に使われるものがあり、**汎用レジスタ（GPRs）**と呼ばれます。
その他のレジスタには、特別な用途や専用の用途があります。

x86-64には16個の64ビット汎用レジスタ（GPRs）があり、32ビット、16ビット、8ビットとしてもアクセスできます。
汎用レジスタは次のとおりです。ここで`rn`の`n`は8から15までの値をとります：`r8`、`r9`、`r10`、`r11`、`r12`、`r13`、`r14`、`r15`です。

| 64-bit | 32-bit | 16-bit | 8-bit |
| :----: | :----: | :----: | :---: |
|  rax   |  eax   |   ax   | ah/al |
|  rbx   |  ebx   |   bx   | bh/bl |
|  rcx   |  ecx   |   cx   | ch/cl |
|  rdx   |  edx   |   dx   | dh/dl |
|  rsi   |  esi   |   si   |  sil  |
|  rdi   |  edi   |   di   |  dil  |
|  rbp   |  ebp   |   bp   |  bpl  |
|  rsp   |  esp   |   sp   |  spl  |
|   rn   |  rnd   |  rnw   |  rnb  |

64ビット未満を使う場合、アクセスされるビットは通常レジスタの下位部分になります。
この規則の例外は`ah`、`bh`、`ch`、`dh`で、これらはレジスタの16ビット部分のうち上位8ビットにアクセスします。

`rax`レジスタでビットがどのようにアクセスされるかを示した図：

```
+--------+---------------------------------------+
| 64-bit |                  rax                  |
+--------+-------------------+-------------------+
| 32-bit |                   |        eax        |
+--------+-------------------+---------+---------+
| 16-bit |                             |    ax   |
+--------+-----------------------------+----+----+
| 8-bit  |                             | ah | al |
+--------+-----------------------------+----+----+
```

これらのレジスタのなかには、関数呼び出しをまたいで保存しなければならないものがあります：`rbp`、`rsp`、`rbx`、`r12`、`r13`、`r14`、`r15`です。
これらを保存しないと、エラーや未定義の動作を引き起こすことがあります。

それ以外のレジスタは保存する必要がなく、自由に使えます：`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10`、`r11`です。

~~~~exercism/caution
シラバスの後のほうで、レジスタを保存する方法を学びます。
今は、2つ目の種類のレジスタ、つまり`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10`、`r11`だけを使いましょう。
~~~~

## 命令

命令とは、CPUが実行できる計算の単位です。
命令は通常、次のような形をとります：

```x86asm
name destination, source
```

つまり、最初に命令の名前を書き、次に1つ以上の空白、続いて宛先オペランド、カンマ（`,`）、最後にソースオペランドを書きます。
ソースオペランドは通常、命令によって変更されません。変更されるのは宛先オペランドだけです。

特に断りのない限り、両方のオペランドのサイズは同じでなければなりません。
たとえば、ソースオペランドが16ビットなら、宛先オペランドも16ビットでなければなりません。

たとえば、レジスタに値を保存するには、`mov`命令を使います：

```x86asm
mov rax, rdx  ; rax = rdx
              ; mov is the name, rax is the destination operand and rdx is the source operand
```

上のコードは、ソースオペランドである`rdx`の64ビットすべての内容を、この命令の宛先オペランドである`rax`の64ビットすべてにコピーします。

ほとんどの命令では、定数の整数をソースオペランドとして使えます（ただし、宛先オペランドとしては使えません）：

```x86asm
mov rcx, 42 ; rcx = 42
            ; rcx is the destination operand and 42 is the source operand
```

32ビットレジスタに書き込むと上位ビットもクリアされるため、`mov eax, 42`は`mov rax, 42`と同じになることに注意してください。
これは16ビットレジスタと8ビットレジスタには当てはまりません。

加算、減算、乗算といった算術演算には、`add`、`sub`、`imul`命令を使います：

```x86asm
add rax, rsi ; rax = rax + rsi
imul rax, rdi ; rax = rax * rdi
sub rax, r8 ; rax = rax - r8
```

## 関数

命令は関数のなかにまとめられます。
すべての関数は、ソースファイルの**section .text**に配置されます。

関数の宣言は、次の要素で構成されます：

1. 関数の名前を付けたラベルと、それに続く`:`。
2. その関数を定義する命令。
3. 戻るための命令、`ret`。

このトラックではSystem V AMD64 ABIの呼び出し規約を使い、最初の6つの整数引数はレジスタで関数に渡されます。
引数は次の順序で渡されます：`rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9`です。

整数の値は、`rax`レジスタで関数から返されます。

関数を呼び出すには、`call`命令を使います。
関数は、同じソースファイルのどこからでも呼び出せます。
関数をほかのソースファイルから見えるようにするには、`global`ディレクティブを使う必要があります。

たとえば、次のように書くと`sum`関数を宣言できます：

```x86asm
section .text ; functions are placed here

global sum ; sum is visible to other source files

sum:
    ; first argument is passed in rdi
    ; second argument is passed in rsi
    ; return value is placed in rax

    mov rax, rdi ; rax is now equal to rdi
    add rax, rsi ; rax = rax + rsi

    ret ; function return
```

そして、次のように書くと`sum`関数を引数3と5で呼び出せます：

```x86asm
mov rdi, 3  ; First argument in rdi
mov rsi, 5  ; Second argument in rsi
call sum

; The rax register now contains the value 8 (3 + 5), after sum returns
```
