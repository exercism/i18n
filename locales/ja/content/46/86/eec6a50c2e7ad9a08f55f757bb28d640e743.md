# 概要

Swiftは、次の3つを主な目標として設計されたコンパイル型のマルチパラダイムプログラミング言語です：

- **安全性**：言語に組み込まれた機能が、コードが本番環境で実行される前にバグを見つけて防ぐ助けになります。
- **速度**：C系の言語に匹敵する最適化されたパフォーマンス。
- **表現力**：読み書きが楽しく簡単な、クリーンでモダンな構文。

Appleは2014年、iOSとmacOS開発のための従来の言語だったObjective-Cに代わるモダンな言語としてSwiftを発表しました。現在、Swiftはオープンソースで、Appleのプラットフォーム、Linux、Windowsで動作します。

## はじめに

### 変数

[変数][constants-variables]を定義すると、値を保存して名前を付けられます。変数を定義したあとは、その名前を使ってコード全体でその値を参照できます。変数は_ミュータブル_です。つまり、定義したあとで値を変更できます。

変数は`var`キーワードで定義します：

```swift
var variableName = 10
```

Swiftは静的型付け言語です。つまり、すべての値はコンパイル時に型が決まっています。[型注釈][type annotations]を使って明示的に型を宣言することもできますし、代入した値からSwiftコンパイラーに[型を推論][type-inferring]させることもできます：

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

変数の値は、代入演算子（`=`）を使って更新できます：

~~~~exercism/note
変数の型は、宣言したあとに変更することはできません。

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

型を指定すれば、初期値を与えずに変数を宣言することもできます。ただし、使う前に値を代入する必要があります：

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### 定数

[定数][constants-variables]も値に名前を結び付けますが、代入したあとに値を変更することはできません。定数は_イミュータブル_です。定数は`let`キーワードで定義します：

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### 算術演算子

Swiftには、基本的な計算のための標準的な[算術演算子][arithmetical-operators]が用意されています：

- 加算：`+`
- 減算：`-`
- 乗算：`*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### 関数

Swiftでは、[関数][functions]は特定の処理を行う自己完結したコードのまとまりです。関数は入力を受け取り、値を返すことができ、値として他の関数に渡すこともできます。関数は`func`キーワードで定義します。そのあとに関数名、括弧（`()`）で囲んだ仮引数リスト、そして省略可能な戻り値の型を書きます：

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swiftの関数は[引数ラベル][argument-labels]を使うので、コードが自然な文章のように読めます：

- **引数ラベル**は、関数を呼び出すときに使います。
- **仮引数名**は、関数の本体の中で値にアクセスするときに使います。

名前を1つだけ指定すると、Swiftはそれを引数ラベルと仮引数名の両方として使います：

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

関数を呼び出すときに引数ラベルを付けたくない場合は、仮引数名の前にアンダースコア（`_`）を書きます：

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

関数の仮引数はすべてデフォルトで定数（`let`）です。つまり、関数の本体の中では値を変更できません。

関数から値を返すには、`->`のあとに戻り値の型を指定し、`return`キーワードを使います：

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

関数が値を返さない場合、その戻り値の型は`Void`です（空のタプル`()`と同じです）。そのような関数では、`-> Void`という戻り値の型と`return`文の両方を省略できます。

### コメント

Swiftは2種類の[コメント][comments]をサポートしています：

- **1行コメント**は`//`で始まり、行の終わりまで続きます。
- **複数行コメント**は`/*`と`*/`の間に書きます。

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
