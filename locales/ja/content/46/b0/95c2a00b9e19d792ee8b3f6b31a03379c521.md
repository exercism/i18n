# 指示の補足

## C++実装に関する追加の注意

C++で並列処理を実現するには、いくつかの方法があります。
ExercismのオンラインランナーはC++17に対応しているため、[アルゴリズムライブラリ][algorithm]の実行ポリシーを利用できます。
もう1つの方法は、[スレッド][thread]を手動で管理することです。
ただし、スレッドの生成にはかなりコストがかかる点に注意してください（[スレッドプール][pool]を使うと助けになります）。

ローカルで作業するときは、もちろん好きなものを使えます。
ただし、非標準のライブラリを使った解答は、おそらくExercismのオンラインランナーでは動きません。

### ベンチマーク

ローカルで作業するときは、さまざまな実装でどれだけ速くなるかを知るために、任意でベンチマークを実行できます。
CMakeのフラグ`EXERCISM_INCLUDE_BENCHMARK`を有効にすると、ベンチマークが有効になります：
```
cmake -DEXERCISM_RUN_ALL_TESTS=1 -DEXERCISM_INCLUDE_BENCHMARK=1 .
```

### 並列アルゴリズムのコンパイラーサポート

GCCによるC++標準ライブラリ（`libstdc++`）の実装は、[TBB][tbb]に依存しています。
TBBが利用できない場合は、並列実行を指定しても、逐次版にフォールバックします。

Ubuntuでは、`libtbb-dev`パッケージをインストールする必要があります：
```
apt-get install libtbb-dev
```

macOSでは、[Homebrew][homebrew]を使ってTBBをインストールできます：
```
brew install tbb
```

Clangの`libc++`は、バージョン17の時点で、並列アルゴリズムを試験的に部分的にサポートしています。
有効にするには、コンパイラーフラグ`-fexperimental-library`を指定する必要があります。

Apple Clang 15以前は、並列アルゴリズムを_サポートしていません_。

LinuxとmacOSでは、この演習にはGCC（デフォルトの`libstdc++`と合わせて）を使うことをおすすめします。

MicrosoftのMSVCは、少なくともVS 2017 15.7以降、追加のライブラリをインストールすることなく並列アルゴリズムをサポートしています。
