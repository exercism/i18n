# はじめに

Pythonの辞書（`dict`）は、[ハッシュ可能][term-hashable]な_キー_を_値_に対応付けるデータ構造で、他のプログラミング言語ではサイズ変更可能な[ハッシュテーブル][hashtable-wikipedia]、ハッシュマップ、[連想配列][associative-array)として知られています。
辞書は、Pythonで唯一の組み込み[マッピング型][mapping-types-dict]です。


`Keys`はハッシュ可能でなければならず、辞書全体で一意でなければなりません。
キーの型には`numbers`、`str`、`tuples`（_イミュータブル_な値）などがあります。
`lists`、`dict`s、`set`sのような_ミュータブル_なデータ構造を含めることはできません。
Python 3.7以降、`dict`のキーの順序は、エントリを挿入した順序になることが保証されています。

`values`はどのようなデータ型やデータ構造でもかまいません。
値は_いくらでも_入れ子にできるので、リストのリストやサブ辞書、その他のカスタムあるいは複合的なデータ構造を含めることもできます。

`key`がわかっていれば、辞書は`value`を（平均して）一定の時間で取り出せます（_エントリの数には依存しません_）。
`list`や`array`の中から値を探す場合（_`index`の位置がわからない場合_）と比べると、`dict`はメモリをかなり多く使いますが、取り出しは非常に高速です。
辞書は、要素の集まりが大きく、頻繁にアクセスして更新する必要がある場面で特に役立ちます。


## 辞書の作成

辞書はさまざまな方法で作成できます。
最もわかりやすいのは、`dict()`コンストラクターを使う方法と、`dict`の_リテラル_を宣言する方法の2つです。

### `dict()`クラスのコンストラクター

`dict()`（_辞書クラスのコンストラクター_）は、`key`と`value`のペアの任意のイテラブルに対して使うことも、一連の`<name>=<value>`_引数_に対して使うこともできます。

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### 辞書リテラル

`dict`は、波括弧（`{}`）で`key : value`のペアを囲む_辞書リテラル_として直接書くこともできます。

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## 辞書の値にアクセスする

辞書のエントリには、角括弧（`[]`）に入れた_key_を使ってアクセスできます。
`key`が`dict`に存在しない場合は、`KeyError`がスローされます。

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

`.get(<key>, <default value>)`メソッドを使ってエントリにアクセスすると、`KeyError`を避けられます。

```python
>>> bear.get("color", 'not found')
'not found'
```

## 辞書の値を変更・追加する

エントリの`value`は、その_key_に代入することで変更できます。

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

新しい`key`:`value`のペアも、同じように_追加_できます。

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## 辞書のエントリを削除（pop）する

`.pop(<key>)`メソッドを使うと、辞書のエントリを削除できます。
`.pop()`は（`key`、`value`）のペアを削除し、`value`を返します。
`.get()`と同様、`.pop(<key>)`は2番目の引数（_`dict.pop(<key>, <default value>)`_）を受け付けます。この引数は、`key`が見つからない場合に返されます。
これにより、`KeyError`が発生するのを防げます。

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## 辞書をループする／繰り返し処理する

`for item in dict`や`while item`を使って辞書をループすると、デフォルトでは_keys_だけが繰り返されます。
同じループの中で、_角括弧_を使えば_values_にもアクセスできます。

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

`.items()`メソッドを使うこともできます。これは（`key`、`value`）のタプルを自動的に返します。

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

同様に、`.keys()`メソッドは`keys`を、`.values()`メソッドは`values`を返します。
