# はじめに

Kotlinの[`string`][ref-string]は、Unicode文字の不変なシーケンスです。

[`Immutable`][wiki-immutable]とは、文字列に対するどんな操作も新しい文字列を返さなければならない、ということです。元の文字列が変わることは決してありません。

[`Unicode`][wiki-unicode]であれば、世界中のほとんどの文字体系を表せますが、（Cのような古い言語とは違い）文字とバイトが1対1で対応しているわけではありません。

文字列は二重引用符`" "`で囲みます。

一部の文字はエスケープが必要です。`\\`のほか、`\t`（タブ）や`\n`（改行）のような、おなじみの非表示文字もエスケープします。

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

複数行の文字列は二重引用符3つで囲み、任意のテキストを含められます（エスケープは不要です）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

[trimIndent][trimIndent-doc]を使うと、各行に共通するインデントを取り除けます。
文字列を整形するのに便利です。

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

別の方法として、[trimMargin][trimMargin-doc]を使うと区切り文字を指定できます。
すると、`String`の各行はその区切り文字のあとから始まります。
区切り文字のデフォルトは`|`ですが、別の区切り文字を入力として渡すこともできます。
たとえば次のようになります。

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

文字列は`+`で連結できますが、短く単純な場合に限るのがよいでしょう。
ほかにも、多くの場合によりよい選択肢があります。

## 文字列テンプレート

これは、ほかの言語では「補間」と呼ばれているものです。

文字列の中にドル記号`$`のあとに識別子が続くか、式を囲む波括弧（`{expression}`）があると、それぞれその値、または式の結果に置き換えられます。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

式の前後に波括弧`{ }`が必要になるのは、そうしないと解析があいまいになる場合です。

一般に、文字列の結合には`+`を使うよりも、文字列テンプレートを使うほうが効率的で、より慣用的です。

## 文字列の関数

Kotlinには、文字列を操作するための[`functions`][ref-string-functions]が_たくさん_用意されています。

ほとんどは`String`クラスのメンバーではなく、[`extensions functions`][ref-extensions]です。ただし、使い方にほとんど違いはありません。

~~~~exercism/note
Kotlinのやや複雑な[ドキュメント][ref-string-functions]のページでは、デフォルトの表示だと拡張関数が隠れています。
`Members & Extensions`をクリックして、このセクションを展開してください。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

次の例は、利用できるもののほんの一部です。

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
