# Instructions

コミュニティ芸術センターのモザイクが先月設置し終わり、それを今ではMagpie Margが見つけてしまいました。たいていの日は、すぐ近くにある自分の**隠し場所**からもっとピカピカのタイルを取り出して、タイルを1枚か2枚と入れ替えたり、1枚はぎ取って1時間ほど姿を消したりしています。

こうした変更をいちいち記録するのが、ボランティアの仕事です。モザイク自体は**固定長の配列**で、タイルの位置ごとにスロットが1つあり、そこには色を表す文字列か、欠けていることを示す`f`が入ります。Magpie Margの隠し場所は、彼女が盗んできたばらばらのタイルを入れた**ベクター**です。

## 1. 新しい行を並べる

`fresh-mosaic`を定義して、長さ`n`を受け取り、`n`個の空スロット（それぞれ`f`）からなる配列を返すようにします。

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. タイルを置く

`place-tile`を定義して、行と位置と色を受け取り、指定した位置がその色になるように行をその場で更新します。このワードは何も返しません。

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. タイルを欠き取る

`chip-tile`を定義して、行と位置を受け取り、指定した位置が再び`f`になるように行をその場で更新します。

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. タイルの色を変える

`recolour-tile`を定義して、行と位置と引数を1つ取るクオーテーションを受け取り、その位置のタイルにクオーテーションを適用して、行をその場で更新します。

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Margが来る前にスナップショットを撮る

`snapshot-mosaic`を定義して、行を受け取り、元の行を後から変更しても影響を受けない独立したコピーを返すようにします。

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Margがタイルをポケットに入れる

`stash-tile`を定義して、Margの隠し場所（ベクター）と色を受け取り、隠し場所にその色を追加します。何も返しません。

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Margがタイルを返す

`return-tile`を定義して、Margの隠し場所を受け取り、最後にしまったタイル（一番上のもの）を取り出して返します。

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
