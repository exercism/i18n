# 説明

この演習では、高校時代の恋人同士がSNSで愛を告白できるように、二人のイニシャルをあしらったASCIIのハートを生成します。

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 名前の最初の文字を取得する

`first_letter`関数を実装しましょう。名前を受け取り、その最初の文字を返します。また、名前に含まれる不要な空白を取り除きます。

```gleam
first_letter("Jane")
// -> "J"
```

## 2. 最初の文字をイニシャルとして整形する

`initial`関数を実装しましょう。名前を受け取り、その最初の文字を大文字にし、ドットを付けて返します。前のステップで定義した`first_letter`を再利用しましょう。

```gleam
initial("Robert")
// -> "R."
```

## 3. フルネームを名と姓に分割する

`initials`関数を実装しましょう。スペースで区切られた名と姓からなるフルネームを受け取り、イニシャルを返します。前のステップで定義した`initial`を再利用しましょう。

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. イニシャルをハートの中に入れる

`pair`関数を実装しましょう。2つのフルネームを受け取り、ASCIIのハートの中にイニシャルを入れたものを返します。前のステップで定義した`initials`を再利用しましょう。

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
