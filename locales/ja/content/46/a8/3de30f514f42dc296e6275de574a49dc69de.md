# Cairoのモジュールとパス

Cairoでは、コードを整理するために**モジュール**を使います。

モジュールは、プロジェクトを構造化し、関数や構造体、トレイトなどの要素の可視性を制御するのに役立ちます。

## モジュールを定義する

モジュールは`mod`で定義し、入れ子にすることもできます。

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

関数や構造体、トレイトは、**デフォルトではプライベート**です。

モジュールの外からアクセスできるようにするには、`pub`を使います。

## パス：絶対パスと相対パス

別のモジュールにある要素を参照するには、次の2つの方法があります。

- **絶対パス**（`crate::`から始まる）：

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **相対パス**（現在のモジュールから始まる）：

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  `front_of_house`が同じモジュールにあれば、これで動作します。

## `use`でモジュールをスコープに持ち込む

毎回フルパスを書くのは面倒です。

`use`キーワードを使うと、短く参照できます。

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use`が適用されるのは、**それが書かれたスコープの中だけ**です。ほかの場所でも必要なら、もう一度書く必要があります。

### `use`の慣用的な書き方

- スコープに持ち込むのは**モジュール**で、関数ではありません。

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  次のようにはしません。

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- **トレイト、構造体、列挙型**については、フルパスを使います。

  ```rust
  use core::num::traits::BitSize;
  ```

### `as`による別名

必要に応じて、インポートに別名を付けられます。

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### 複数の要素をインポートする

複数の`use`文を書く代わりに、インポートをまとめられます。

```rust
use shapes::{Square, Circle, Triangle};
```

## `pub use`による再エクスポート

モジュールを別の構造で公開するには、`pub use`を使います。

```rust
pub use crate::front_of_house::hosting;
```

これで外部のコードは、`restaurant::front_of_house::hosting::add_to_waitlist()`の代わりに`restaurant::hosting::add_to_waitlist()`を使えます。

## Scarbで外部パッケージを使う

依存関係を追加するには、`Scarb.toml`を更新します。

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

依存関係を追加するには`scarb add <package>`を、削除するには`scarb rm <package>`を使います。

## グロブ演算子（`*`）

モジュールからすべてをインポートするには、次のように書きます。

```rust
use core::num::traits::*;
```

コードが読みにくくなることもあるので、慎重に使ってください。
