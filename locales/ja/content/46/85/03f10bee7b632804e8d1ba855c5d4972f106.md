# 説明

小さな島のフェリーの運航時刻表を管理しています。出航は日付として記録され、それらを扱うためのヘルパーがいくつか必要です。

## 1. 出航日を記録する

`make-date`を定義して、年、月、日を受け取り、対応するタイムスタンプを返すようにしましょう。

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. 曜日の名前を返す

`weekday-name`を定義して、出航のタイムスタンプを受け取り、それが当たる曜日の名前を返すようにしましょう。

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. うるう年

`leap?`を定義して、年を受け取り、それがうるう年かどうかを返すようにしましょう。

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. 1か月の日数

`month-length`を定義して、年と月を受け取り、その月の日数を返すようにしましょう（2月を忘れずに）。

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. 何日後

`add-days`を定義して、タイムスタンプと日数を受け取り、その日数だけ後のタイムスタンプを返すようにしましょう。

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
