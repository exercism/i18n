# はじめに

## キーワードリスト

キーワードリストは、キーと値のデータ構造です。

```elixir
[month: "April", year: 2018]
```

キーワードリストは`{key, value}`の[タプル][exercism-tuples]のリストで、同じものをそのままの形で書くこともできますが、短い構文のほうがよく使われます。

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

キーワードリストのキーは[アトム][exercism-atoms]である必要がありますが、値はどんなものでもかまいません。同じキーを複数回使うこともできます。キーワードリストのキーと値のペアには順序があります。

キーワードリストは、リストと同じやり方で扱うこともできますし、`Keyword`モジュールを使うこともできます。

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
