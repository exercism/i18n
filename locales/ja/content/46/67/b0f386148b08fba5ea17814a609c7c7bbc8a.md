# 説明の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 入力     | 整数 | カテゴリー：`0`=チョイス、`1`=1の目、`2`=2の目、`3`=3の目、`4`=4の目、`5`=5の目、`6`=6の目、`7`=リトルストレート、`8`=ビッグストレート、`9`=フルハウス、`10`=フォーオブアカインド、`11`=ヨット |
| `$a2`    | 入力     | アドレス | サイコロ（ワード配列）                                          |
| `$v0`    | 出力     | 整数 | 結果のスコア                                            |
| `$t0-9`  | 一時     | 任意     | 一時的な保存に使用                                 |
