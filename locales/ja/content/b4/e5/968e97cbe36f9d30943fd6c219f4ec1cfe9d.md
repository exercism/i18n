# 算術演算子について

## 演算子

Goでは、次の算術演算子を使うことができます。

| 演算子 | 例             |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

整数同士の除算では、余りは切り捨てられます（例：`5 / 2 == 2`）。

`+`演算子は、文字列の連結にも使えます：`"foo" + "bar" == "foobar"`。

## 異なる型同士の演算

Goでは、異なる数値型の間で算術演算を行うことはできません。

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

オペランドは同じ型である必要があり、明示的に型を変換しなければならないこともあります。

```go
x := float64(42)
n := 2.0
value := n * x 
```

## 複合代入

それぞれの演算子には、変数をその場で更新する複合代入の書き方があります。

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## インクリメントとデクリメント

変数の後に置くと、インクリメント（`++`）とデクリメント（`--`）の文は、その変数に格納されている数値を1だけ増やしたり減らしたりします。
変数の前に置くと、構文エラーになります。

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

これらは文なので、値を返しません。
