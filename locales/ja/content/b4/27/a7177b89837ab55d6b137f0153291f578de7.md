## 変数

変数とは、値またはコンテナを指す名前のことです。
変数名は、シジルと呼ばれる特殊文字で始まることも、その文字を付けずに始まることもあり、そのあとには識別子が続きます。
シジルのあとにトゥイギルが続くこともあります。

シジルの種類によって、保持するデータ構造の種類が変わります。

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

よく目にするトゥイギルは`^`と`:`で、コードブロックのシグネチャを短く書くためのものです。
`^`は位置仮引数用です。
`:`は名前付き仮引数用です。

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## コンテナ

コンテナがあるおかげで、変数を変更できます。

`constant`で宣言した変数と、シジルなしの変数（識別子の前に`\`を付けて宣言します）にはコンテナがなく、代わりに値を直接指します。

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## 型

変数は、型制約を付けて宣言できます。
型制約には型強制も指定できます。これは、目的の型に、受け入れる型を引数として渡す書き方です。

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

型制約を使うと、マルチディスパッチルーチンを活用できます。

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Rakuの型も、ただのオブジェクトの一種です。
`class`、`role`、`enum`を宣言するのは、独自の型オブジェクトを作る方法です。
たとえば、組み込み型の`Bool`はenumで作られています：`enum Bool <False True>`。

`subset`キーワードを使うと、ほかの型を基にした単純な型制約も作れます。
さらに、`where`節を使ってこの新しい型を制限できます。
`where`節は、シグネチャの中でも使えます。

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
