# 説明の補足

## ヒント

`label`と`ohms`という関数を実装する必要があります。`label`には用意されたシグネチャーをそのまま使ってもかまいませんが、それにとらわれて自由な発想を狭めないようにしましょう。

この演習ではテキストデータを扱います。歴史的な理由から、Haskellの`String`型は文字の配列`[Char]`と同じ意味です。テキストデータをより効率よく扱うには、`Text`型を使うこともできます。

この演習の任意の発展として、次のことができます。

- Haskellの[文字列型](https://haskell-lang.org/tutorial/string-types)について読んでみましょう。
- package.yamlの依存関係のリストに`- text`を追加します。
- `Data.Text`を[次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)インポートします。

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- これで、例えば`label :: Resistor -> Text`と書いたり、`Data.Text`のコンビネーターを例えば`T.pack`のように参照したりできます。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べてみましょう。

この部分は完全に任意です。
