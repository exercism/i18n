# はじめに

## プロパティ

C#のプロパティは、クラスのメンバーであり、そのクラス内のデータへのアクセスを提供します。呼び出し側は、データを設定したり取得（get）したりできます。プロパティは、自動実装にするか、バッキングフィールドを持つことができます。プロパティは、setアクセサーまたはgetアクセサー、あるいはその両方で構成されます。他の言語では、「mutator」がsetアクセサーに、「accessor」がgetアクセサーにほぼ相当しますが、構文の構成はまったく異なります。

プロパティを設定するときには、入力値を検証したり、整形したり、その他の方法で操作したりできます。実際、クラス内のコードからアクセスできるあらゆるプログラム的操作を実行できます。

同様に、プロパティを取得するときには、データを計算したり整形したりできます。ここでも、クラスで利用できるあらゆるプログラム的操作を実行できます。

プロパティは、他のクラスメンバーと同じようにアクセス修飾子（`public`、`private`など）を持ちますが、setアクセサーは、取得（get）アクセサーとは独立したアクセスレベルを持てますし、その逆も同様です。プロパティは必ずしも両方のアクセサーを持つ必要はなく、片方（getまたはset）だけでもかまいません。

プロパティを表す基本的な構文には、2つの形があります。

### フィールドまたは式を基にしたプロパティ：

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### 自動実装プロパティ

```
public int MyProperty { get; private set; } = 42;
```

初期化は省略できます。
