# 説明

船のパーサーとして、食料庫の在庫表を管理しています。在庫表はハッシュテーブルで、それぞれのキーが品物の名前、値が在庫数です。

## 1. 配列から在庫表を組み立てる

`create-inventory`を定義してください。品物名の配列を受け取り、重複しないそれぞれの名前とその個数を対応させたハッシュテーブルを返します。

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. 品物を追加する

`add-items`を定義してください。在庫表と品物の配列を受け取り、挙げられた品物ごとに個数を増やした新しい在庫表を返します。元の在庫表は変更しないでください。

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. 個数を減らす

`decrement-items`を定義してください。在庫表と品物の配列を受け取り、挙げられた品物ごとに個数を1つ減らした新しい在庫表を返します。個数が0を下回ることはなく、もともと在庫表にない品物は除きます（マイナスの項目は追加されません）。

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. 品物を完全に取り除く

`remove-item`を定義してください。在庫表と1つの品物を受け取り、その品物を取り除いた新しい在庫表を返します。その品物がなければ、変更していないコピーを返します。

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. 利用できる品物を一覧にする

`list-inventory`を定義してください。在庫表を受け取り、在庫数が0より大きい品物だけを含み、名前のアルファベット順に並べた`{ name quantity }`の組の配列を返します。

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
