# はじめに

AWKはとても小さな言語で、基本的なデータ型もわずかしかありません。
このレッスンでは、数値と文字列について見ていきます。

## 数値

AWKの数値は、倍精度浮動小数点数として実装されています。
整数、小数、倍精度浮動小数点数のあいだに区別はありません。

AWKは8進数の定数（`0`で始まるもの）と16進数の定数（`0x`または`0X`で始まるもの）を理解します。

### 数値演算

[標準の算術演算子][ops-arith]である`+`、`-`、`*`、`/`、`%`を使うことができます。
冪乗演算子は`^`です（POSIXで規定されています）が、`**`も使えます。
[組み込みの数値関数][funcs-numeric]もいくつかあり、三角関数、乱数生成、そして数値を_x_と0のあいだの最も近い整数に切り捨てる`int(x)`などがあります。

ビット演算の_演算子_はありません。
gawkでは、それらは関数として実装されています。
引数は負でない数値でなければなりません。

| 関数 | 演算 |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | 引数のビット単位のAND |
| `or(a, b [, ...])`  | 引数のビット単位のOR |
| `xor(a, b [, ...])` | 引数のビット単位のXOR |
| `lshift(v, count)`  | _v_の値を_count_ビット左にシフトしたもの |
| `rshift(v, count)`  | _v_の値を_count_ビット右にシフトしたもの |
| `compl(v, count)`   | _v_のビット単位の補数 |

## 文字列

AWKの文字列は文字の並びです。
文字列定数は、二重引用符で囲んで指定します。

~~~~exercism/caution
GNU awkでは文字列にUnicode文字を使えますが、ほかのawk実装では使えないことがあります。
`gawk`と、もうひとつの人気のAWKである`mawk`を比べてみましょう：

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### 文字列の操作

文字列の操作はただひとつ、連結だけです。
連結に特別な演算子はありません。
2つの文字列を並べて書くだけで連結されます：

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print`は関数ではなく**文**です。
`print`に括弧（`()`）は必要ありません。
~~~~

AWKには[文字列操作関数][funcs-string]が豊富に用意されています。
トラックを進めていくなかで、これらを詳しく紹介していきます。

## 数値と文字列の相互変換

数値と文字列を変換する明示的な演算子はありません。
AWKは、プログラムの文脈に応じてこれを暗黙的に行います。
そのおかげで、入力フィールドの値を扱うのはとても簡単です。AWKはたいてい、こちらが望むとおりに動いてくれます。

* `print x + y`は、`+`の数値演算のおかげで、`x`と`y`の変数の値を数値に変換します。
* `print x y`は、連結の操作によって、`x`と`y`の変数の値を文字列に変換します。

明示的に書きたい場合は、`0 + x`で_x_の数値としての表現が得られ、`"" x`で_x_の文字列表現が得られます。

### 文字列から数値へ

AWKが文字列を数値に変換する方法は、戸惑うこともあります。
簡単に考えるなら、AWKは文字列の先頭から「数値の文字」を読み進め、数値でない文字が見つかったところで止まる、というイメージです。
いくつかの例を見てみましょう：

* `"2.5"`は数値の`2.5`に変換されます。
* `"1e3"`は数値の`1000`に変換されます（科学的記数法）。
* `"456abc"`は数値の`456`に変換されます（`a`は「数字」ではないので、そこで変換が止まります）。
* `"abc789"`は数値の`0`に変換されます（文字列の**先頭**に数字がないためです）。

詳しくは[マニュアル][str-to-num]をご覧ください。

## 変数の型を調べる

[`typeof(var)`関数][func-typeof]は、型を文字列として返します。

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
と出力されます
```none
42 string
43 number
```
