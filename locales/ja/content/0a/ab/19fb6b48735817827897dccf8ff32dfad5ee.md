# ヒント

## 全般

- `*T`を使うと、ある型`T`へのポインターである変数を宣言できます。たとえば、`var i *int`は`int`へのポインターである変数`i`を宣言します。
- `&`演算子を使うと、変数のポインター（そのメモリ上のアドレス）を取得できます。たとえば、`mypointer := &anIntVariable`です。
- ポインターに`*`演算子を使うと、ポインターに格納されている値を取得できます。たとえば、`var i int = *aPointerToInt`です。
  これはポインターのデリファレンスと呼ばれます。
- ポインターをデリファレンスする前に、そのポインターが`nil`でないことを確認します。
  `nil`ポインターをデリファレンスしようとすると、実行時エラーになります。
- ポインターの仕組みに自信がないときは、[Tour of Go: Pointers][go-tour-pointers]や[Go by Example: Pointers][go-by-example-pointers]を読んでみてください。

## 1. 投票カウンターを作成する

- `int`へのポインター、つまり`*int`を作成する必要があります。
- 変数に`&`演算子を使うと、その変数へのポインターを作成できます。たとえば、`&myInt`です。
- 自分で定義した新しい変数へのポインターを作成することも、関数の引数の変数を使うこともできます。

## 2. カウンターから投票数を取得する

- ポインターに`*`演算子を使うと、デリファレンスしてその値を取得できます。たとえば、`*myPointer`です。
- `nil`ポインターをデリファレンスすると、実行時エラーになります。
  デリファレンスする前に、必ずポインターが`nil`でないことを確認してください。

## 3. カウンターの票をインクリメントする

- ポインター`var myPointer *int`があるとき、`*myPointer`に代入すると、`myPointer`が指す値を変更できます。
- ポインターの現在の値を取得するには、`*`演算子を使ってデリファレンスするか、前のタスクで作成した関数を呼び出します。

## 4. 選挙結果を作成する

- 関数の引数の値で`Name`と`Votes`フィールドを埋めた、新しい`ElectionResult`リテラルまたは変数を作成します。
- 変数名やリテラルの前に`&`演算子を使うと、変数やリテラルからポインターを作成できます。たとえば、`&myVariable`や`&ElectionResult{Name: "John", Votes: 1}`です。

## 5. 結果を発表する

- `ElectionResult`へのポインターを受け取っていても、ポインターでないかのように、ドット`.`記法でそのフィールドにアクセスできます！
- 構造体の`Name`と`Value`フィールドにアクセスして、メッセージを組み立てます。
- 構造体へのポインターからフィールドにアクセスする場合でも、デリファレンスする必要はありません。
  次の例のように、Goが自動的にポインターをデリファレンスしてくれます。

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. 票の再集計

- マップはすでにポインターのようなものだと考えられます。
  つまり、関数の中でマップに加えた変更は、関数の外からも見えます。
- `var m map[string]int`のキーの値をインクリメントするには、いくつかの方法があります。`m["mykey"] = m["mykey"] + 1`、`m["mykey"] += 1`、`m["mykey"]++`です。
