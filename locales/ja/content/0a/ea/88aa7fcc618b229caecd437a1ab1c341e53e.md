# 説明

小さな家具工房で見習いとして働いています。親方のタブレットではFactorが動いていて、裁断リストを管理しています。作業台に乗せられた板はどれも、最初の切断が行われる前に、いくつかの派生した値と一緒に測られます。

前任の見習いは、これまでのコードを`dup`や`over`、`swap`、`rot`が入り乱れた状態で残しました。ここでの仕事は、5つの小さなワードを*コンビネーター*を使って書き直すことです。

それぞれの板は、加工前の長さ（cm）だけをスタックに載せた状態で、作業の流れに入ってきます。

## 1. 挽き代を加える

のこぎりの刃は、切るたびに木を薄く削り取ります。これが*挽き代*です。工房では、これを吸収するために、板ごとに2%の長さを余分に見込んでいます。

`with-kerf`を定義して、長さを受け取り、その長さに2%の挽き代を加えた値を返すようにしましょう。

```factor
100 with-kerf .
! => 102
```

## 2. 挽き代と仕上げ代を計算する

切断のあとは仕上げです。やすりがけと鉋がけによって、元の長さのさらに5%が削り取られます。

`kerf-and-finish`を定義して、*両方*の余分を並べて返すようにしましょう（挽き代が下、仕上げ代が上）。

```factor
100 kerf-and-finish .s
! => 2
! => 5
```

## 3. 裁断カードを作る

親方が切る板にはどれも、小さなカードが貼られます。そこには、加工前の長さ、挽き代、仕上げ代という3つの数値が、この順に書かれています。

`cut-card`を定義して、この3つすべてを返すようにしましょう。

```factor
100 cut-card .s
! => 100
! => 2
! => 5
```

## 4. 1ピースあたりの長さ

工房には、等しい長さに分割する必要がある、まとまった*束*の材木も届きます。挽き代は束の長さに一度だけ加えられ、その結果が分割するピースの数で割られます。

`per-piece`を定義して、束の長さとピースの数を受け取り（ピースの数はスタックの一番上にあります）、1ピースあたりの長さを返すようにしましょう。

```factor
100 2 per-piece .
! => 51

100 4 per-piece .
! => 25+1/2
```

## 5. 2つの束を比べる

親方が材木置き場で2つの束のどちらかにしようかと迷っているとき、それぞれの挽き代を一目で比べたくなることがあります。

`compare-bolts`を定義して、スタックから2つの長さを取り出し、それぞれの挽き代を（同じ順序で）返すようにしましょう。

```factor
50 100 compare-bolts .s
! => 1
! => 2
```
