# はじめに

型パラメーターを使うと、どんな型の値でも入れられるようになります。このような型を_ジェネリック型_と呼びます。

たとえば、この`Box`型は`a`という型パラメーターを持っています（小文字で書きます）。

```gleam
pub type Box(a) {
  Box(a)
}
```

`a`という型パラメーターは、どんな型にでも当てはまるプレースホルダーです。そのため、`Box`は文字列でも整数でも、そのほかのどんな型でも使えます。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

型パラメーターは、カンマで区切ると複数持たせることができます。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## ジェネリック関数

型パラメーターは、関数の引数にも使えます。

この関数は`a`型の値を受け取り、`a`を受け取って`b`を返す関数を2回呼び出します。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
