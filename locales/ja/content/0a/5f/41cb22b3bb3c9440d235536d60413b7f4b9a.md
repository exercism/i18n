この演習の目標は、パスワードチェッカーの演習を改善することです。
与えられたパスワードは一度に複数のルールに違反することが多いため、役に立つパスワードチェッカーは、たまたま見つかった最初のルールだけではなく、違反しているすべてのルールをユーザーに伝えるべきです。
改善されたパスワードチェッカーは、与えられたパスワードが違反しているすべてのルールを一度に示すべきです。

このパスワードチェッカーのルールは、前のパスワードチェッカーの演習と同じです。

- 12文字以上であること
- 大文字を少なくとも1つ含むこと
- 小文字を少なくとも1つ含むこと
- 数字を少なくとも1つ含むこと
- 集合!@#$%^&\*の中に記号を少なくとも1つ含むこと

## 1. `PasswordError`判別共用体を変更し、個々の値をフラグとして扱えるようにする

この必須のステップが完了するまで、テストはコンパイルされないことに注意してください。

## 2. `checkPassword`関数を実装する

`checkPassword`関数は、与えられたパスワードを前述のルールに照らしてチェックします。
この関数は`Result`値を返す必要があります。パスワードがすべてのルールを満たす場合は`Ok`が返され、1つ以上のルールを満たさない場合は`Error`値が返されます。
与えられたパスワードが複数のルールを満たさない場合、`PasswordError`値は満たさなかったすべてのルールを表す必要があります。

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. ``getStatusPhrases`関数を実装する

`getStatusPhrases`関数は文字列の集合を返します。各文字列は、`checkPassword`から返された結果に含まれるエラーの1つに対応する、人間が読めるフレーズを含んでいます。

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
