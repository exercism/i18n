# 説明

郊外のクリケット場のグラウンドキーパーが、数字の計算を手伝ってほしいと思っています。境界線にはどれだけロープが必要なのか、打ったボールはどれだけ遠くへどの方向へ飛んだのか、そして野手が追いつくまでにボールはどれだけ転がるのか、というものです。

距離はすべてメートル、速さはすべてメートル毎秒です。フィールド上の位置はピッチの中央を基準に測ります。`x`はグラウンドをまっすぐ縦に進む向きの距離、`y`はそれを横切る向きの距離で、左が正、右が負です。

## 1. 境界線に必要なロープ

境界線はピッチの中央を囲む円です。半径を受け取り、必要なロープの長さを返す`boundary-length`を定義しましょう。長さは2 × π × 半径です。

```factor
70.0 boundary-length .
! => 439.822971502571
```

## 2. ピッチからどれだけ離れているか

野手の`x`と`y`を受け取り、ピッチの中央からどれだけ離れた場所に立っているかを返す`distance-from-pitch`を定義しましょう。x² + y²の平方根です。

```factor
30.0 40.0 distance-from-pitch .
! => 50.0
```

## 3. どちらの方向へ飛んだか

打球が落ちた地点の`x`と`y`を受け取り、その方向を**度**で返す`shot-angle`を定義しましょう。0がグラウンドをまっすぐ縦に進む向き、90が真横の左、-90が真横の右、180がキーパーを越えてまっすぐ後ろです。

```factor
50.0 50.0 shot-angle .
! => 45.0
```

## 4. どれだけ飛んだか

速さ`speed`で打たれ、**度**で表した`angle`の角度で上がったボールは、最初に着地するまでに speed² × sin(2 × angle) ÷ 9.8 メートル飛びます。速さと角度を受け取り、その距離を返す`carry`を定義しましょう。

```factor
30.0 45.0 carry .
! => 91.83673469387755
```

## 5. 芝の上で減速する

外野を転がるボールはスピードを失っていきます。`metres`メートル進んだあとの速さは、speed × e^(−0.02 × metres) です。最初の速さと転がったメートル数を受け取り、残っている速さを返す`speed-after`を定義しましょう。

```factor
30.0 50.0 speed-after .
! => 11.03638323514327
```

## 6. どこで追う価値がなくなるか

タスク5を逆にしてみましょう。ボールが転がり始める速さと、それより遅い`target`の速さを受け取り、targetまで落ちる前に何メートル転がるかを返す`metres-until`を定義しましょう。ln(speed ÷ target) ÷ 0.02 です。

```factor
30.0 15.0 metres-until .
! => 34.657359027997266
```
