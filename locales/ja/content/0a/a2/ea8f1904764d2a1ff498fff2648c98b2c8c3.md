# 指示の補足

この演習は、確定節文法（DGC）を使って実装してください。
DCGは、並び（配列）を解析するだけでなく、その並びを生成したり、補完したり、検査したりするのにも使えます。

## ライブラリー

スタブの実装ファイルには、次の行が含まれています。

```prolog
:- use_module(library(dcg/basics)).
```

これで`dcg/basics`ライブラリーを利用できるようになります。この演習を解くには十分なはずです。
