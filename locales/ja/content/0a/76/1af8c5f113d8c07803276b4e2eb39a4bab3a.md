# 関数アノテーションの順序

慣習として、`@doc`による関数アノテーションは`@spec`による関数アノテーションより前に置きます。また、`@spec`による関数アノテーションは関数の直前に置きます。関数に複数の節がある場合は、関数アノテーションは最初の節の前に置きます。

例：

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
