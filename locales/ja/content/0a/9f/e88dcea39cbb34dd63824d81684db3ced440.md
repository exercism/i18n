# はじめに

## 基本1

### 定数と関数

定数の値は`name = expression`のように定義します。Elmでは、定義を除くすべてが式です。

```elm
five = 5

six = 3 + 3
```

関数は`name parameters... = expression`のように定義し、仮引数はスペースだけで区切ります。

```elm
add number1 number2 = number1 + number2
```

関数の呼び出しも式であり、関数名を指定して、その関数の仮引数それぞれに対応する引数をスペースで区切って渡すことで行います。書き方は関数の定義と同じです。

```elm
five = add 2 3
```

括弧（`()`）を使うと、式を評価する順序を指定できます。

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### インデント／意味を持つ空白

Elmでは、コードの区切りを指定するために波括弧、括弧、セミコロンといった構文上の目印を使いません。代わりに空白とインデントを使います。

- モジュール、インポート、トップレベルの関数定義は、いちばん左の列から始める必要があります。
- 式を複数の行に分割する場合、その式の一部となっているコードは、その式の下で少なくとも1つのスペース分インデントする必要があります。
- まとまりとしてグループ化される式の部分は、同じ数のスペースでインデントします。

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### モジュール

Elmでは、各ファイルが1つのモジュールであり、他のどのコードよりも前に`module`文を書く必要があります。
モジュール名はファイル名と一致していなければならないので、モジュール`Calculator`はファイルCalculator.elmに置く必要があります。
モジュール内で定義されたものは、そのモジュールにプライベートなスコープを持ち、`exposing`に挙げられていない限り、このモジュールの外からはアクセスできません。

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### コメント

コメントとは、Elmファイルの中にあるテキストのうち、コードとして解釈されないものです。
主に、自分自身や他のプログラマーが読むためのものです。
1行コメントには、二重のダッシュを基にした軽量な構文があります。
複数行コメントも、開きと閉じの区切り文字のペア`{-`と`-}`を使えば可能です。

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
