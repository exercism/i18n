# 説明

この演習では、友人が開発している新しいRPGゲームのクエストのロジックを実装します。ゲームの主人公はアンナリン。勇敢な女の子で、獰猛で忠実な飼い犬を連れています。ところが不幸が訪れます。森で木の実を探しているときに親友が誘拐されてしまったのです。アンナリンは親友を見つけ出して助けようとします。このクエストに飼い犬を連れていくこともできます。

親友の足跡をしばらく追ったあと、アンナリンは親友が囚われている野営地を見つけます。誘拐犯は2人いました。強力な騎士と、狡猾な弓使いです。

誘拐犯を見つけたアンナリンは、次に挙げる行動のうちどれが取れるかを考えます。

- 速攻：騎士が眠っていれば速攻できます。鎧を着るのに時間がかかるため、騎士は無防備になります。
- スパイ：少なくとも1人が起きていれば、一行を偵察できます。そうでなければ、スパイは時間の無駄です。
- 囚人への合図：囚人が起きていて弓使いが眠っていれば、鳥の鳴き声で囚人に合図を送れます。弓使いは鳥の鳴き声による合図の訓練を受けているので、そのメッセージを傍受できてしまうからです。
- _囚人の解放_：アンナリンは囚人を解放するために、野営地に忍び込むことを試せます。
  これは危険な行為で、成功するのは次の2つの場合だけです。
  - 飼い犬を連れている場合、弓使いが眠っていれば囚人を救出できます。
    騎士は犬を恐れており、アンナリンと囚人が逃げるまでに弓使いが準備を整える時間はありません。
  - 飼い犬を連れていない場合、アンナリンと囚人はとても慎重に行動しなければなりません！
    囚人が起きていて、騎士と弓使いがどちらも眠っていれば、アンナリンは囚人を解放できます。しかし囚人が眠っていると救出できません。アンナリンが突然現れたことに囚人が驚いて、騎士と弓使いを起こしてしまうからです。

ここからは4つのタスクです。森で見つけた3人のキャラクターの状態と、アンナリンの飼い犬がいるかどうかに基づいて、上記の行動が可能かどうかを判断するロジックを実装します。

## 1. 『速攻』アクションが可能かどうかを確認する

`canExecuteFastAttack`という関数を実装します。この関数は、騎士が起きているかどうかを示す真偽値を受け取ります。この関数は、キャラクターの状態に基づいて『速攻』アクションが可能であれば`true`を返します。そうでなければ`false`を返します。

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. 『スパイ』アクションが可能かどうかを確認する

`canSpy`という関数を実装します。この関数は3つの真偽値を受け取ります。それぞれ騎士、弓使い、囚人が起きているかどうかを示します。この関数は、キャラクターの状態に基づいて『スパイ』アクションが可能であれば`true`を返します。そうでなければ`false`を返します。

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. 『囚人への合図』アクションが可能かどうかを確認する

`canSignalPrisoner`という関数を実装します。この関数は2つの真偽値を受け取ります。それぞれ弓使いと囚人が起きているかどうかを示します。この関数は、キャラクターの状態に基づいて『囚人への合図』アクションが可能であれば`true`を返します。そうでなければ`false`を返します。

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. 『囚人の解放』アクションが可能かどうかを確認する

`canFreePrisoner`という関数を実装します。この関数は4つの真偽値を受け取ります。最初の3つの仮引数は、それぞれ騎士、弓使い、囚人が起きているかどうかを示します。最後の仮引数は、アンナリンの飼い犬がいるかどうかを示します。この関数は、キャラクターの状態とアンナリンの飼い犬の有無に基づいて『囚人の解放』アクションが可能であれば`true`を返します。そうでなければ`false`を返します。

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
