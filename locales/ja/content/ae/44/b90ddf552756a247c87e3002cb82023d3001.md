# 配列

`ARRAY`は固定です。作られたときのサイズのままで、変わることはありません。要素を後から追加することも、削除することもできません。

探偵の手帳は、これとは違います。手がかりは一つずつ見つかり、見込みがなくなれば線を引いて消されていきます。そういうときに向いているのが、**配列**です。

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes.append("broken window");
   notes.size                   -- 2
```

`LIST{T}`は、配列と同じように型`T`の値を順番に保持し、指示に応じて伸び縮みします。

## その場で変わる

`append`は、呼び出された配列そのものを変更し、何も返しません。

```sather
   notes.append("muddy boots");        -- yes
   notes := notes.append("muddy boots");   -- no: append answers nothing
```

これは、変更のたびに代入し直す必要があった`FMAP`や`FSET`とは違います。`LIST`は`SCOREBOARD`と同じ、ごく普通のオブジェクトです。ルーチンに渡せば、そのルーチンが同じ配列を変更できます。

## 読み書き

角括弧を使い、0から数えるのは配列とまったく同じです。

```sather
   notes[0]                     -- "muddy boots"
   notes[1] := "smashed window";
   notes.size                   -- how many
   notes.is_empty               -- true when there are none
```

## 削除

`remove_index`は指定した位置の要素を取り除き、それより後ろの要素はひとつずつ前に詰まります。

```sather
   notes.remove_index(0);       -- the first clue is struck out
```

つまり、位置は固定ではありません。前の手がかりが削除されると、手がかりの位置は変わります。位置を記録しておく前には、この点に気をつけましょう。

## 順に見ていく

`elt!`は、配列と同じように使えます。

```sather
   loop
      #OUT + notes.elt! + "\n";
   end;
```

## 波括弧

`LIST{STR}`は文字列の配列、`LIST{INT}`は数値の配列です。これは、`lost-property`で書いたものとまったく同じジェネリッククラスです。そして今なら、ライブラリ自身のものも同じように読めるようになります。
