# はじめに

Haxeのイテレーターは、`for`ループを使って値を繰り返し処理するために使われます。イテレーターには2つの種類があります。

- `Iterator`：値を繰り返し処理するもの。
- `Iterable`データ：あるデータ型を繰り返し処理できるようにするもの。

どちらの概念も、`Iterator<T>`と`Iterable<T>`で表されます。

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

これらの型のどちらかと一致するクラスは、`for`ループで繰り返し処理できます。クラスが`hasNext`と`next`というメソッドを定義していればイテレーターとみなされ、そうではなく`iterator`メソッドを定義していればイテラブルな型とみなされます。
