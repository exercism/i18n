Haxeの真偽値は`Bool`型で表され、その値は`true`か`false`のどちらかです。

Haxeは3つの真偽値演算子をサポートしています。`!`（単項の否定）、`&&`（二項のAND）、`||`（二項のOR）です。

複合的な真偽値式（`&&`と`||`）では、_短絡評価_が行われます。式は左から右へ評価されますが、評価されるのは必要な範囲までです。これは、次のような場合に重要です。

```haxe
object != null && object.field == x
```

最初の真偽値チェックのおかげで、`object.field`にアクセスするのは`object`が`null`でないときだけになり、実行時エラーを防げます。

3つの真偽値演算子にはそれぞれ異なる[優先順位][precedence]があり、`!` → `&&` → `||`の順に評価されます。

式を括弧（`()`）で囲むと、この優先順位を上書きできます。括弧のほうが優先順位が高いからです。

```haxe
!true && false   // => false
!(true && false) // => true
```
