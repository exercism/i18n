# ループ入門

Bashには2つのループの書き方があります。

* 複数の項目からなる配列の_各項目について_、いくつかのコマンドを繰り返す
* ある条件が真（または偽）である_間_、いくつかのコマンドを繰り返す

## `for`ループ

配列の項目を1つずつ処理するには、`for`ループを使います。

```bash
for varname in words; do COMMANDS; done
```

`words`は、単語分割とファイル名展開（[クォートの概念][quoting]で学びました）によって展開されます。
それぞれの単語が順番に`varname`に代入され、COMMANDSが実行されます。

`for`ループが役立つ場面を、いくつか紹介します。

* 複数のファイルに対して、いくつかのコマンドを実行する。

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* スクリプトや関数に渡された引数それぞれに対して、コマンドを実行する。

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* コマンドの出力を空白文字で区切った単語ごとに、コマンドを実行する。

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    この書き方については、後ほど注意点を見ていきます。

### 算術`for`ループ

Bashには算術ループもあります。
ほかのプログラミング言語を使ったことがある人には、ある程度見覚えがあるでしょう。

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

Bashでは、二重括弧（`(( ))`）が算術コンテキストを表します（Bashの算術については、後の概念で詳しく見ていきます）。
先ほどの`seq`を使った例は、次のように書けます。

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### `for`を使うべきでない場合

[`for`で行を読み込んではいけません][bashfaq1]。

`cat`の出力を1行ずつ処理する、というアンチパターンをよく見かけます。

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

これには2つの誤りがあります。

1. コマンド置換がクォートされていないため、単語分割の影響を受けます。
   単語分割は、デフォルトでは改行だけでなく_空白文字_で分割します。
   この`for`ループは、ファイルの行ではなく**単語**を1つずつ処理しています。
2. コマンド置換がクォートされていないため、ファイル名展開の影響を受けます。
   ファイル内のすべての単語が、グロブパターンとして照合されます。

[クォートの概念][quoting]で学んだように、単語分割は`IFS`変数で制御でき、ファイル名展開は無効にできます。
しかし、これはどちらかというと壊れやすい方法です。
ファイルの行を1つずつ処理するのに、`for`は適した方法ではありません。
ファイルを読み込む慣用的な方法は、`while`ループを使うことです。

## `while`ループ

ある条件が真である_間_、一連のコマンドを繰り返すには、`while`を使います。

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

`if`と同様（[条件分岐の概念][conditionals]で学んだように）、CONDITION_COMMANDSに特別な構文はありません。
コマンドリストの終了ステータスが「真」か「偽」かを決めます。

## ループの制御

`break`コマンドは、ループから抜け出します。
制御は、ループの終端`done`の次のコマンドから再開します。

`continue`コマンドは、ループの次の繰り返しに進みます。

## ファイルの行を読み込む

すでに触れたとおり、ファイルを読み込む慣用的な方法は`while`ループです。

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* ファイルの内容は、`<`リダイレクトによってループへの入力として渡されます。
* `read`コマンドは、入力から1行すべてを読み込めたときに「真」を返します。
  入力を使い切ったとき、または最後の行が改行で終わっていないときは、`read`は「偽」を返します。
  * 最後の行が改行で終わっていない場合でも対応できる、_真に_ 慣用的な書き方は次のとおりです。

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* `-r`オプションは、`read`にバックスラッシュの並びを置換しないよう指示します。バックスラッシュはただの文字として扱われます。
* `IFS=`は、`read`コマンドが実行されている間だけ`IFS`に空文字列を代入します。
  これにより単語分割が一時的に無効になり、読み込んだ行の先頭や末尾の空白文字がそのまま保たれます。

## `until`

`until`構文は、ある条件が**偽**である間、一連のコマンドを繰り返します。
ループは、条件が真になる_まで_繰り返されます。

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

`until`を使うことはまれです。
よく使われるのは、「while not」ループです。

```bash
while ! CONDITION_COMANDS; do ...
```

## 無限ループ

ずっと繰り返し続けたいこともあります。
その方法は2つあります。

1. 常に成功の終了ステータスになる条件を指定した`while`ループ

    ```bash
    while true; do ...
    ```

2. 式を空にした算術`for`ループ

    ```bash
    for ((;;)); do ...
    ```

## do-while

do-whileという専用の構文はありませんが、同じ動作を実現できます。

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
