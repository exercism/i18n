# 指示

この演習では、在庫管理システムを扱います。

在庫はアイテム名で整理し、利用可能なアイテムの数を記録しておく必要があります。

在庫へのアイテムの追加を処理する必要があります。あるベクトルの中にアイテムが現れるたびに、在庫内のそのアイテムの数量を`1`増やします。また、要求されたときには数量を`1`減らして、在庫からアイテムを削除する処理も必要です。

最後に、ある在庫のすべてのキーと値のペアを`pair`の`vector`として返す関数を実装します。

~~~~exercism/note
この演習のテストは、ミューテーションの有無に依存しませんが、関数名は、これらの関数が入力を変更しないものであることを示しています。
入力を変更せずにイントロダクションで紹介した関数を使いたい場合は、`copy()`関数が役立ちます。
~~~~

## 1. ベクトルから在庫を作成する

アイテムの入力ベクトルから「在庫」を作成する`create_inventory(<input vector>)`関数を実装します。各アイテム名と、それに対応する数量を組にした`dict`を返します。

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. ベクトルから既存の辞書にアイテムを追加する

渡された在庫にアイテムのベクトルを追加する`add_items(<inventory dict>, <item vector>)`関数を実装します。

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. 在庫からアイテムを減らす

アイテムの`vector`を受け取る`decrement_items(<inventory dict>, <items vector>)`関数を実装します。関数は、そのアイテムが`vector`に現れるたびに、アイテムの個数から`1`を引きます。

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

在庫内のアイテムの個数は、0を下回らないようにします。入力の`vector`にアイテムが現れる回数が、在庫にある個数を超えた場合、そのアイテムの数量は0のままにします。個数が0になったあとは、それ以上その個数を減らす要求は無視します。

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. 在庫からエントリを完全に削除する

在庫からアイテムとその個数を完全に削除する`remove_item(<inventory dict>, <item>)`関数を実装します。

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

在庫にそのアイテムが見つからない場合、関数は元の在庫をそのまま返します。

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. 在庫の中身をすべて返す

在庫を受け取り、`(item, quantity)`のペアのベクトルを返す`list_inventory(<inventory dict>)`関数を実装します。

ベクトルには、_利用可能な_アイテム（_数量が0より大きいもの_）だけを含め、アイテムのアルファベット順に並べ替えます。

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
