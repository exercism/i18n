# 説明

ダンス一座は列を作って並びます。誰がどの場所に立っているかを把握しましょう。

5つのタスクはすべて`DANCE_FORMATION`クラスに書きます。

## 1. 列には何人いる？

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. 先頭は誰？

先頭に立つ人がリーダーです。

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. 最後尾は誰？

列がどれだけ長くても、しんがりは最後に立つ人です。

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. 開演時の並び

一座はいつも同じ順番で開演します。Mia、Ana、Benの順です。その列を返します。

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

このルーチンは引数を取りません。

## 5. ステップを数える

ダンサーはそれぞれ、こなすステップ数が決まっています。それを合計します。

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

空の列は0ステップです。
