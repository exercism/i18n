# はじめに

Elixirは、`true`と`false`という値を真偽値型で表します。値は`true`と`false`の2つだけです。これらの値は変数に束縛できます。

```elixir
true_variable = true
false_variable = false
```

`and/2`、`or/2`、`not/1`演算子を使うと、厳密な真偽値の式を評価できます。

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

真偽値を返す関数を書くときは、関数名の末尾を`?`にするのが慣習です。真偽値を保持する変数にも、同じ慣習を使えます。

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
