# 説明

この演習では、ログのエントリーを処理します。

それぞれのログ行は、次の形式の文字列です：`"[<LEVEL>]: <MESSAGE>"`。

ログレベルは3つあります。

- `INFO`
- `WARNING`
- `ERROR`

ここには3つのタスクがあり、どれも1行のログを受け取って、それを使って何かをするものです。解き方はたくさんあります。上の例からお気に入りのテクニックを選んで、どんなふうに書けるか試してみましょう。

## 1. ログ行からメッセージを取得する

`message`関数を実装して、ログ行のメッセージを返すようにしましょう。

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

先頭と末尾の空白は取り除きます。

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. ログ行からログレベルを取得する

`log_level`関数を実装して、ログ行のログレベルを返すようにしましょう。ログレベルは小文字で返します。

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. ログ行を整形し直す

`reformat`関数を実装して、ログ行を整形し直しましょう。メッセージを先に、そのあとにログレベルを括弧（`()`）に入れて並べます。

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
