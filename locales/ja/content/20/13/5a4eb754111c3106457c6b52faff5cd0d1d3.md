# はじめに

分岐させたい値がいくつか離散的にあるときは、`if`を連ねるよりも、[`combinators`][combinators]の`case`を使うほうがすっきりします。

## `case`

```
case ( obj assoc -- )
```

`case`はスタックの一番上から値を受け取り、節の*assoc*を取ります。各節は`{ value [ body ] }`の形です。入力と`=`で等しくなる値を持つ最初の節が選ばれ、その本体は、入力値が*すでに消費された*状態で実行されます。末尾に`[ body ]`だけを書いた項目はデフォルトになります。これが実行されるとき、入力は*まだスタックに残っています*。

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

等価判定は`=`で行われるので、`=`で等しいと判定されるものなら何でもキーとして使えます。数値、文字列、シンボルはいずれも使えます。

## 条件付き分岐のための`cond`

選択が等価判定ではなく*述語*に基づく場合（たとえば`x > 11`）、`cond`が適した道具です。`cond`は[Cars, Assemble!][cars-assemble]で登場しました。

## シンボル

`SYMBOL:`は、自分自身をスタックに積むワードを定義します。これは自己評価するタグの値です。`SYMBOLS:`を使うと、複数のシンボルを一度に定義できます。

```factor
SYMBOLS: yes no maybe ;
```

こうすると`yes`は値になり、`=`で比較でき、`case`のキーとして使えます。

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
