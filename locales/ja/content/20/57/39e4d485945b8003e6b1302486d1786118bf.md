# 概要

[`sequences`][sequences]ボキャブラリは、配列（`{ … }`）、ベクター（`V{ … }`）、文字列、範囲、スライスがすべて実装する単一の[プロトコル][sequence-protocol]を定義します。どれか1つでできることは、ほかのどれでもできます。

| ワード | スタック効果 |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (0-based)      |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (all but last n) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (last n)   |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (length when absent) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

配列は固定長なので、`prefix`/`suffix`/`append`/`prepend`の操作はすべて、元の配列を拡張するのではなく新しいシーケンスを返します。ベクターはサイズ変更可能で、`push`と`pop`はその場で動作しますが、新しいコピーが欲しいときは`clone`から始めるのが適切です。

## 変換

`>array`、`>string`、`>vector`（それぞれのボキャブラリにあります）は、任意のシーケンスを指定された具体的な型に変換します。呼び出し側が特定の表現を求めるときや、スライスなどの遅延シーケンスを実体化するときに使います。

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
