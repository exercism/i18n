# 説明

この演習では、ログ行を処理します。

それぞれのログ行は、`"[<LEVEL>]: <MESSAGE>"`という形式の文字列です。

ログレベルは次の3つです：

- `INFO`
- `WARNING`
- `ERROR`

タスクは3つあり、どのタスクもログ行を受け取って、それを使って何かを行うものです。

## 1. ログ行からメッセージを取得する

`message`関数を実装して、ログ行のメッセージを返しましょう：

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

先頭や末尾の空白は削除します：

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. ログ行からログレベルを取得する

`logLevel`関数を実装して、ログ行のログレベルを返しましょう。ログレベルは小文字で返します：

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. ログ行を整形し直す

`reformat`関数を実装して、ログ行を整形し直しましょう。メッセージを先に、ログレベルをそのあとに括弧（`()`）で囲んで置きます：

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
