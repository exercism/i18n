# 型変換の紹介

Goでは、異なる型の間で明示的に変換する必要があります。
型の間の変換（**型キャスト**とも呼ばれます）は、変換先の型の名前を持つ関数を使って行います。
たとえば、`int`を`float64`に変換するには、次のように書きます。

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## プリミティブ型と文字列の間の変換

プリミティブ型（`int`など）と`string`の間を変換するための`strconv`パッケージがあります。

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```
