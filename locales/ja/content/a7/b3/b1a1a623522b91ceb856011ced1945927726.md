# 概要

JavaScriptには、インクリメント演算子とデクリメント演算子があります。
これらは変数の値をその場で変更します。
`++`は数値に1を足し、`--`は数値から1を引きます。

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

上の例では、後置のインクリメント演算子とデクリメント演算子を使っています。
この場合、演算子は変数の後に置かれ、式の戻り値は、増減する_前_の変数の値になります。

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

演算子を変数の前に置く前置の形式もあります。
その場合、戻り値は増減した_後_の変数の値になります。

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
