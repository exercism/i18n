# Linuxハッカーのためのインストール（上級Linuxユーザー向け）

ここに載せる最適な手順はまだ検討中ですが、多くのLinuxエンジニアが、何をどこにインストールするかについて非常にこだわりを持っていることは承知しています（そしてありがたく思っています）。

_標準的なインストールに従いたい場合は、いったん戻って[通常のセットアップ](https://exercism.io/tracks/pharo-smalltalk/installation)に従ってください。_

以下の手順はまだ作業中で、ArchLinuxを前提としていますが、お使いのディストリビューションにも当てはまるかもしれません（当てはまらない場合は、改善点の洗い出しにご協力いただけると助かります。Pharo本体へのリクエストにもつながる可能性があります）。_注：これらの手順が確実に動作するかはまだ分かっていないため、改善に向けたご協力をいただければ幸いです。_

- お好みの場所にPharo VMをインストールします。AURなどに対応するものがあり、そこにpharo 7が載っていればそれを使えるかもしれません。そうでなければ、[https://files.pharo.org/vm/pharo-spur64/linux/]からダウンロードしてください（stable-timerのVMを選びます）。
- 次に、exercismディレクトリに置くPharo.imageファイルを展開する必要があります。これは[https://files.pharo.org/image/70/]から入手できます。最新の64ビットzipファイルを選んでください。
- では、VMとImageが動作するか確認するために、簡単なコマンドラインテストを試してみましょう：`pharo Pharo.image eval "100 factorial"`。すべて問題なければ、答えが返ってくるはずです。
- 次に、OSXのセクションで説明されている「load script」を試してみましょう。`libgit2`に言及したエラーが出るかもしれません。その場合は、それもインストールして再試行してください。`libcurl-gnutls`をインストールすると役立つという報告もあります（ただし、まだ確認されていません）。
- 一部のlibgit2の失敗については、開発版のpharoからバックポートできる可能性のある内部のloadModuleの変更があるという報告も受けています。この場合は、次のように、クラス`LGitLibrary`のメソッド`unixModuleName`を置き換える必要があります。
  1. `pharo-ui Pharo.image`と入力して、GUI付きのPharoを起動します。
  1. Ctrl-Spaceを押して、`unixModuleName`と入力します。
  1. `LGitLibrary >> unixModuleName`の項目を選び、Enterキーを押します。
  1. 開いたブラウザーで、`unixModuleName`のメソッドのソースを次の内容に置き換え（コピー＆ペーストします）、保存（Ctrl-S）して、最後に保存してpharoを終了します。
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

次に、前述のOSXのexercismの「load script」をもう一度試してみましょう。すべて正しく動作していれば、読み込みの進行状況バーが画面を横切って点滅し、続いてSystem Browserのウィンドウが表示されます。表示されない場合は、PharoのDiscord（上記のとおりです）にお越しください。

その後は、いったん戻って、残りの[始め方の手順](https://exercism.io/tracks/pharo-smalltalk/installation)に従ってください。
