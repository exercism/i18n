# はじめに

## 継承

継承は、オブジェクト指向プログラミング（OOP）の中心となる概念です。
継承はIS-A関係を表します。
英語で「継承」という言葉が持つ意味は、プログラミングでもそのまま当てはまります。つまり、親から機能を受け継ぐということです（プログラミングでは、機能といえば通常は関数と変数のことです）。

次のような`Animal`クラスを考えてみましょう。

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`は親クラスです。このクラスが持つ性質は、一般的なすべての動物に拡張できるからです。

`Lion`という動物を考えてみましょう。そのクラスは次のようになります。

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override`アノテーションは、サブクラスのメソッドがスーパークラスのメソッドをオーバーライドしていることを示すために使います。
必ず必要なものではありませんが、使うのがベストプラクティスです。
~~~~

では、次のように書くとどうなるでしょうか。

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

注：`Animal`クラスを`Lion`で初期化しています。
出力は次のようになります。

```java
Lion here!!
```

オブジェクト指向プログラミングでは、継承には多くの種類がありますが、Javaがサポートしているのはその一部だけです（マルチレベル継承と階層継承）。
詳しくは、[こちら][java-inheritance]をご覧ください。
