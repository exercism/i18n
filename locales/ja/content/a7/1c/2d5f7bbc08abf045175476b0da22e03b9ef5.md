# 説明

Lisp星人のルーシーは数値が好きで、その中には「素晴らしい」ものもあると思っています。

ルーシーは、数値をより素晴らしくする関数を書くのを手伝ってほしいと頼んできました。

ルーシーがどの数値を素晴らしいと考えるかは変わることもあるので、関数は柔軟である必要があります。

## 1. 素晴らしくする

数値の配列を、より素晴らしい数値の配列にするには、`make-magnificent-maybe`という関数を書く必要があります。この関数は、数値に適用する関数と、数値の配列を入力として受け取ります。
（与えられた関数に従って）より素晴らしい数値の配列に評価されるようにしましょう。

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. 最高のものだけ

（うまくいけば）数値をより素晴らしくしたあと、ルーシーは本当に素晴らしい数値だけを見たがっています。

1は*決して*素晴らしくないと確信しているので、それは取り除く必要があります。

しかしそれ以外については、ルーシーは気が変わることもあるので、ここでも数値が素晴らしいかどうかを教えてくれる関数を渡してくれます。

`only-the-best`という関数を書く必要があります。この関数は関数と数値の配列を入力として受け取り、最高の数値だけを返します（`1`と、与えられた関数が真になる数値は除きます）。

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
