# ヒント

## 全般

- `case`（[`combinators`][combinators]にあります）は同じ値にマッチさせるのに向いた道具です。`cond`はガード付きの述語に向いた道具です。
- シンボル（`yes`、`no`、`maybe`、`korean`、…）は、演習ファイル内の`SYMBOLS:`によってすでに宣言されています。

## 1. 料理を評価する

- `korean`と`turkish`をそれぞれの承認値に対応づける、2節からなる`case`です。

## 2. 映画のジャンルを評価する

- `romance`にマッチさせ、残りにはデフォルトとして`[ drop no ]`を置きます。
  デフォルトの分岐では、元の値が一番上にそのまま見えていることを忘れないでください。結果をプッシュする前に、それを`drop`しましょう。

## 3. 散歩を評価する

- `cond`（これも`combinators`にあります）を使います。それぞれのガードは`[ dup N > ]`です。
  本体では、承認値をプッシュする前にキロメートルを`drop`する必要があります。

## 4. アクティビティを評価する

- アクティビティは`{ tag value }`です。`first2`で両方をスタックにプッシュし、次に`swap`でタグを一番上にします。`case`がマッチさせる相手はこれです。
- `board-game`と`chill`の分岐では、(`f`)の値がまだスタックに残っています。承認値をプッシュする前に、それを`drop`します。
- `movie`、`restaurant`、`walk`の分岐では、該当する値がまだスタックに残っているので、タスク2・1・3のワードを直接呼び出せます。

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
