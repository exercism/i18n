# 説明

通常の数値を[序数](https://en.wikipedia.org/wiki/Ordinal_numeral)に変換する関数を書きましょう。0については、文字列の"0"をそのまま返します。

序数とは、リストの中での何かの位置を表す数です。この演習ではその意味で序数を使い、序数を英語でつづった名前を使います。

序数は次のようになります（少なくとも、その一つの表し方です）。

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

つまり、通常の数値を入力すると、それに対応する序数が得られます。

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
