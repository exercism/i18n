でも、少し整理されていません。Azaraの座標は、Ruiのものとは形式も並び順も違うようで、どの宝がどの場所に対応するのかを知るには、二つのリストを何度も見比べなければなりません。
そこで、F#を学び始めたばかりの二人が、宝探しの情報をうまく整理するために、小さなプログラム（というより、いくつかの関数）を書くのを手伝ってほしいと頼みに来ました。

## 1. 座標を取り出す

Azaraのリストから`(treasure, coordinate)`のペアを受け取り、抽出した地図上の座標だけを返す`getCooordinate()`関数を実装しましょう。

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. 座標を整形する

"2A"という形式の座標を受け取り、`(2, 'A')`という形式のタプルを返す`convertCoordinate()`関数を実装しましょう。

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. 座標を照合する

`(treasure, coordinate)`のペアと、`(location, coordinate, quadrant)`のレコードを受け取り、それぞれの座標を比較する`compareRecords()`関数を実装しましょう。
座標が「一致」すれば**`true`**を返し、一致しなければ**`false`**を返します。
正確に比較できるように、必要に応じて座標の形式を整えましょう。

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. 一致したレコードを組み合わせる

Azaraのリストの`(treasure, coordinate)`のペアと、Ruiのリストの`(location, coordinate, quadrant)`のレコードを受け取り、**座標が一致すれば**`(coordinate, location, quadrant, treasure)`を返す`createrecord()`関数を実装しましょう。
座標が_一致しなければ_、同じ形で`""`で埋めたタプルを返します。
正確に比較できるように、必要に応じて座標の形式を整えましょう。

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
