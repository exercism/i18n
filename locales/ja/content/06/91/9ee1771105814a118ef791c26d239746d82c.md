# 説明

この演習では、宝物をしまっておくための、汎用的な（そして魔法の！）`TreasureChest`を書いていきます。

## 1. `TreasureChest`型を定義する

2つのフィールドを持つパラメトリック型`TreasureChest{T}`を定義します。

- 宝物箱のパスワードを保存するために使う、`String`型の`password`フィールド。
- 宝物を保存するために使う、`T`型の`treasure`フィールド。
この値は汎用的なので、宝物は何でもかまいません。

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. `get_treasure()`関数を定義する

この関数は2つの引数を取ります。

- `String`（パスワードを試すため）
- `TreasureChest`型

この関数は、渡されたパスワードが`TreasureChest`の`password`と一致するかどうかを確認します。

- パスワードが一致すれば、宝物を返します。
- パスワードが一致しなければ、`nothing`を返します。

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. `multiply_treasure()`関数を定義する

この関数は2つの引数を取ります。

- 整数の乗数`n`。
- `TreasureChest{T}`型

この関数は、新しい`TreasureChest{Vector{T}}`を返します。その内容は次のとおりです。

- 元と同じパスワード
- 掛け算された宝物。長さ`n`の`Vector{T}`で、元の宝物が`n`回繰り返されています。

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
