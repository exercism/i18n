# はじめに

運に左右されるゲームには、ランダムさの源が必要です。Factorの[`random`][random]ボキャブラリーには、渡したものに合わせて姿を変える汎用的なワード`random`をはじめ、シャッフルやサンプリングのためのヘルパー、そしてテストのためにランダムさを*再現可能*にする仕組みが用意されています。

## ワードを`inline`にする

この演習のタスクには、*クオーテーション*（`[ … ]`のブロック）を引数として受け取り、それを実行するワードを定義するものがあります。それについてFactorには厳格なルールが1つあります。**引数として受け取ったクオーテーションを`call`するワードは、`inline`として宣言しなければなりません。**書き方としては、閉じる`;`のすぐ後ろに`inline`を置きます。

`inline`は、ワードの本体を一度だけ独立してコンパイルする代わりに、それぞれの呼び出し箇所にそのまま差し込むようコンパイラーに指示します。

- 呼び出し元のクオーテーションが直接織り込まれるので、**クオーテーションがスタックに残したものは、そのまま呼び出し元へ流れていきます**。たとえそのワード自身のスタック効果が出力を何も宣言していなくても、です。

`10`を積んでから、渡されたクオーテーションを実行する小さなワードを紹介します。

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

このワードのスタック効果`( quot -- )`には出力がありません。それでも、*異なる*効果を持つ2つのクオーテーションを渡して呼び出すと、結果はそれぞれ異なり、どちらも呼び出し元へ流れていきます。

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`：1つの要素

`random`（[`random`][random]内）は、引数に対して汎用的に働きます。

```
random ( obj -- elt )
```

- **整数**`n`を与えると、`[0, n)`の範囲のランダムな整数を返します。

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- **シーケンス**を与えると、ランダムな要素を1つ返します。

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

普通のサイコロを振るには、範囲を1つずらします。`6`の`random`は0から5を返すので、`6 random 1 +`とすれば1から6になります。

## 複数の値を取り出す

決まった回数だけランダムな値を取り出して集めるには、`replicate`（[`sequences`][sequences]内）でクオーテーションを繰り返します。

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`：その場でシャッフルする

`randomize`（[`random`][random]内）は、要素をランダムな順序に並べ替えたシーケンスを返します。

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

これは**その場で**シャッフルし、同じシーケンスを返します。元の順序を保ちたい場合は、先に`clone`してください。

## `sample`：重複しない複数の要素

`sample`（[`random`][random]内）は、シーケンスから*重複しない*`n`個の要素を取り出します。トランプを配るように、同じカードは二度出ません。

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

シーケンスが持っている数より多くの要素を求めると、エラーになります。

## 再現可能なランダムさ

既定では、`random`はシステムクロックを種にして初期化されたグローバルなジェネレーターから値を取り出すため、実行するたびに結果が変わります。テストのため、あるいは*再現*できるゲームが欲しいときはいつでも、固定の**シード**でジェネレーターを束縛します。

`<mersenne-twister>`（[`random.mersenne-twister`][mt]内）は、整数のシードからジェネレーターを組み立て、`with-random`（[`random`][random]内）は、そのジェネレーターを組み込んだ状態でクオーテーションを実行します。

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

クオーテーションの中のすべて、つまり`random`、`randomize`、`sample`は、シードで初期化されたジェネレーターから値を取り出すので、同じシードなら常に同じ結果が再現されます。

クオーテーションを引数として受け取り、それを`with-random`で実行するワードは、[ワードを`inline`にする](#marking-a-word-inline)のルールに当てはまります。`with-random`は結局そのクオーテーションを`call`することになるので、そのようなラッパーには`inline`を付ける必要があります。
