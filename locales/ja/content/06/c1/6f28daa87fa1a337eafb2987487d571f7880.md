# はじめに

条件式は、条件が**`true`**か**`false`**かによって、実行するコードを切り替えるために使います。条件式は次のように書きます。

```haxe
if (condition) {
  expressions
};
```

条件の結果は`Bool`型なので、結果が`true`のときに式が実行されます。

条件が実際には`false`のときに、別のコードを実行したいこともあります。そこで登場するのが`else`式です。`else`は、最初の条件が`false`のときに式を実行します。では、複数の可能性について条件を調べたいときはどうすればよいでしょうか？　そんなときは`else if (condition)`を使います。以下が完全な例です。

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
