# はじめに

`IEnumerable<T>`インターフェースを実装する型は、_列挙可能_と呼ばれます。組み込みのコレクション型はすべて、このインターフェースを実装しています。

列挙可能な型は、`foreach`ループを使って繰り返し処理できます。

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>`を実装するには、型は`IEnumerator<T> GetEnumerator()`という1つのメソッドを実装する必要があります。見てきたように、列挙可能な型は、コレクションの実際の繰り返し処理を`IEnumerator<T>`型に任せます。このインターフェースには、実装する必要がある1つのプロパティと3つのメソッドがあります。

- `public T Current { get; }`：現在の要素を取得します。
- `public bool MoveNext ();`：次の要素に移動し、次の要素への移動が成功した場合は`true`を、そうでない場合（これ以上要素がない場合）は`false`を返します。
- `public void Reset ();`：列挙子を初期状態（最初の要素の前）にリセットします。
