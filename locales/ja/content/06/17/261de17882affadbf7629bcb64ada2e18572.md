# Introduction

Swiftでは、`String`は人が読めるテキストを表す`Character`の値の、順序付きのコレクションです。Swiftの文字列は、Unicodeの文字や絵文字に完全に対応しています。

文字列リテラルを使うと、文字列を作成できます。テキストをダブルクォーテーション（`"`）で囲んでください。特殊な文字にはエスケープシーケンスを使います。たとえば、`\n`は改行を表し、`\"`は文字列リテラルの中でダブルクォーテーションをエスケープすることを表します。

空の文字列は、間に何も入れずにダブルクォーテーションを2つ並べて書きます（`""`）。

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
