# 指示の補足

## Pythonトラックでのこの演習の構成

この演習のテストでは、プログラムを`Garden`の[`class`][classes in python]として実装することが想定されています（_[concept:python/classes]()も参照してください_）。
Pythonのクラスに馴染みがない場合は、この[Real Pythonのチュートリアル][how-to-make-a-class]が、始めるにあたっての追加の資料として役立つでしょう。

`class`には、`plants`という[`method`][methods]を実装してください。このメソッドは、生徒の名前を引数に取り、その生徒に割り当てられた植物名の`list`を返します。


## コンストラクター

次のような庭をつくるとします。

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

これはテストでは`Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`として表されます。

この表現を扱えるようにするには、`class`に[`__init__()`][init]という[特殊メソッド][special-methods]を実装する必要があります。
`__init__()`や[_コンストラクター_][what-is-a-constructor]に馴染みがない場合は、Pythonのドキュメントにある[クラスとインスタンスのオブジェクト][class vs instance objects in python]に詳しい説明があります。


## デフォルト引数

テストによっては、生徒の`list`が`__init__()`の引数として渡されます。
その場合は、問題文に書かれている12人の生徒の名簿を上書きします。
次の2つの文はどちらも、`__init__()`メソッドで動作する必要があります。


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

1つの方法は、生徒の`list`を[デフォルト引数][default argument values]にすることです。Pythonのドキュメントでは、[関数定義][function definitions]の説明の中で`default parameters`について詳しく解説しています。
