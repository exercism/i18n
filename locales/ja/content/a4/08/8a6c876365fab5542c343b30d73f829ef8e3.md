# 列挙型

列挙型はCairoのデータ型で、コードの可読性と安全性を高めるために、あらかじめ決められたバリアントの集合を定義するために使います。
Cairoでは、`enum`のバリアントは、さまざまなデータ型（整数、構造体、タプル、他の列挙型など）を保持するように宣言できます。

以下のコード例は、列挙型をどのように定義できるかを示しています。

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

上で宣言した`Direction`列挙型は、`North`、`East`、`South`、`West`という4つのバリアントを持つ単純な列挙型です。
命名規則では、列挙型のバリアントにはパスカルケースを使います。
各バリアントは、`Direction`列挙型のそれぞれ異なる値を表します。
この列挙型の例では、それぞれのバリアントは関連する値を持たず、次の構文でインスタンス化できます。

```rust
let direction = Direction::North;
```

以下は同じ`Direction`列挙型ですが、各バリアントが関連する値を持ち、その値が方向の正確な角度を保持します。

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

この例から、`Direction`列挙型の各バリアントが`u128`の関連する値を持つことがわかります。
この種の列挙型は、次のようにインスタンス化できます。

```rust
let direction = Direction::North(10);
```

## カスタム型を使った複雑な列挙型の例

列挙型は、バリアントとして異なるデータ型を組み合わせて宣言できます。
以下の例では、`Action`は`Quit`、`Direction`、`SendMessage`、`ChangeAvatar`、`ProfileState`をバリアントとして集めた複雑な列挙型です。

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## 列挙型に対するトレイトの実装

Cairoでは、トレイトを定義し、カスタムの列挙型に実装できます。
これにより、列挙型に関連するメソッドや属性を定義できます。
以下はその例で、`Message`列挙型を定義し、それに対して`Processing`トレイトを実装しています。

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

次は、このトレイトを使って`Quit`メッセージを処理する方法です。

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

列挙型は多くの場面で役に立ちます。特に、上のトレイトの実装で使った`match`の流れと組み合わせると便利です。
`match`の流れについては、[The Cairo Book][match]でさらに詳しく学べます。

[match]: https://book.cairo-lang.org/ch06-02-the-match-control-flow-construct.html
