# Null

Nullは、`null`というただ1つの値だけを持つプリミティブな値型です。
Nullは、何もないことを表すためによく使われます。
偽として扱われますが、`false`やほかの偽とみなされる値とは別のものです。

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## null値の扱い

PHPでは、null値はよくあるエラーの原因になります。エラー状態の代わりに返されたり、何もないことを表すために返されたりすることが多いからです。
エラーの発生を防ぐには、値を操作する前にその値がnullでないことを確認する「nullチェック」がよく必要になります。

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

nullチェックを繰り返すと間違いが起きやすくなります。そこでPHPには、null値を扱うための演算子が2つ用意されています。nullセーフなアクセスを提供する`?->`演算子と、null合体演算子`??`です。

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
