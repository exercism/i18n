# 概要

## 型エイリアス

Gleamでは、型エイリアスを使うと、そのまま書くには面倒な既存の型に、便利な名前を付けられます。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type`を付けて書くと、そのエイリアスは定義したモジュールの外でも使えます。`pub`を省略すると、そのエイリアスは非公開になり、他のモジュールからは参照できません。
