# 概要

Elmは、信頼性の高いWebアプリケーションを作るための、楽しい言語です。親しみやすいエラーメッセージ、優れたパフォーマンス、小さなアセット、そして実行時の例外がないのが特徴です。

おそらくElmで最も有名で、最も広く模倣されているのがThe Elm Architectureです。これはWebアプリケーションを組み立てるためのシンプルなパターンで、ElmのWebアプリケーションはすべてこの形で書かれます。

中心となる考え方は、アプリケーションの状態を表す`Model`、そのモデルを`update`する方法、そしてモデルを`view`する方法を軸にコードを組み立てる、というものです。

`Model`にはアプリケーションの状態、つまりアプリケーションに必要なすべてのデータが入ります。型は何でもかまいませんが、役に立つアプリケーションでは通常は[レコード][record]です。テキストボックスと、そのテキストを逆にしたものを表示するテキストだけのシンプルなアプリケーションを想像すると、モデルは次のようになります。この例は[Elm Guide][elm-guide-text-fields]でも見ることができます。

```elm
type alias Model =
  { text : String
  }
```

`update`は、何か変化があったとき（たとえばユーザーがボタンをクリックしたとき）に`Msg`とともに呼ばれる関数です。`Msg`と現在の`Model`を受け取り、新しい`Model`を返します。`Msg`の型も何でもかまいませんが、通常は[カスタム型][custom-type]です。

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

すべてのカスタム型と同様に、`Msg`のバリアントには、必要に応じて任意の情報を含めることができます。上の例では、`TextChanged`というバリアントが`String`を含んでいます。

`view`は、ブラウザーでユーザーに表示するHTMLを返す関数です。現在の`Model`を受け取り、`Html Msg`（ElmがHTMLを表すために使う型）を返します。それぞれのHTML要素（たとえば`<div>`）には、`Html`パッケージの対応するElm関数（`Html.div`）があります。これらの関数はそれぞれ2つの入力を受け取ります。1つ目は属性のリスト（`Html.Attributes`パッケージと`Html.Events`パッケージのもの）で、2つ目は子要素のリスト（`Html`パッケージの関数）です。また、HTMLの文字列コンテンツを表す`text`関数もあります。これは文字列を1つ受け取るだけで、それ以外は`Html`パッケージの他のすべての関数や要素と同じように使います。

`view`関数では、ボタンのクリックやテキストボックスの編集といった特定のイベントによって`Msg`が生成されるように指定できます。Elm Runtimeはこの`Msg`を使って`update`関数を呼び出し、`Model`を変更して、更新されたHTMLを生成します。次のコードでは、これが`Html.Events.onInput TextChanged`で行われています。

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

`Html.Events.onInput`には、`Msg`を生成するために使う関数（`String -> Msg`）を渡す必要があります。イベントごとに渡せる情報が異なるため、期待される関数も変わります。たとえば、`Html.Events.onCheck`（チェックボックス用）は`Bool -> Msg`を、`Html.Events.onClick`は`Msg`だけを期待します。

Elmは純粋で関数的な言語であり、変更は起こりえません。そのため、変化するものすべてはElm Runtimeが扱います。さまざまな[HTML Elements][html-elements]、[Element Attributes][element-attributes]、[HTML Events][html-events]は、Elmのパッケージレジストリで確認できます。

Elmで書けるWebアプリケーションには4つの「レベル」があり、進むにつれてできることが増え、複雑になっていきます（とはいえ、Elmは言語もエコシステムも、楽しいくらいシンプルなままです）。これらはすべて[Browser package][browser-package]で定義されています。

- [sandbox][browser-sandbox]：ボタンやチェックボックスなど、ユーザー入力に反応します
- [element][browser-element]：HTTPとJavaScriptの相互運用を使って、外の世界とやり取りします
- [document][browser-document]：Webページの`<title>`と`<body>`を制御します
- [application][browser-application]：ルーティングやURLの変化を扱う、完全なシングルページアプリケーションを作ります

このコンセプトでは[sandbox][browser-sandbox]を使います。最もシンプルですし、sandboxなのでExercismのオンラインエディターでも比較的扱いやすいからです。Elmプログラムのエントリーモジュールは`Main`という名前にする必要があり、アプリケーションを生成する関数は`main`という名前にする必要があります。次のようになります。

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

`update`関数と`view`関数はすでに見ました。さらに[sandbox][browser-sandbox]では、`Model`の初期状態を返す`init`関数が必要です。
