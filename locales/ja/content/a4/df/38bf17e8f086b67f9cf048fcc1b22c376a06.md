# はじめに

特殊形式の`import`を使うと、外部モジュールの名前を書かずに、そのモジュールの関数を利用できます。

外部モジュールを丸ごとインポートすると、既存のローカル関数と衝突する可能性があります。これを避けるために、`:except`と`:only`という2つのオプションが用意されています。どちらもキーワードリストを受け取り、キーが関数名、値がその関数のアリティになります。

通常、インポートはモジュール定義の先頭に書きます。

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
