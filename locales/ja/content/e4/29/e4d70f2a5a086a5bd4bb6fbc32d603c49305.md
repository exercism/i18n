# はじめに

## 比較

JavaScriptでは、数値は次の関係演算子と等値演算子を使って比較できます。

| 比較             | 演算子  |
| ---------------------- | --------- |
| より大きい           | `a > b`   |
| 以上 | `a >= b`  |
| より小さい              | `a < b`   |
| 以下    | `a <= b`  |
| （厳密に）等しい        | `a === b` |
| （厳密に）等しくない    | `a !== b` |

比較の結果は常に真偽値、つまり`true`か`false`になります。

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

JavaScriptでは、上記の比較演算子は文字列の比較にも使えます。
その場合は、辞書順（辞書式順序）で比較されます。
すべての文字の正確な順序の一覧は[こちら][utf-16-list]にあります。

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 条件分岐

JavaScriptで条件に応じて処理を実行する一般的な方法が、`if`文です。
これは`if`キーワード、丸括弧（`()`）で囲まれた条件、波括弧（`{}`）で囲まれたブロックから構成されます。
ブロックが実行されるのは、条件が`true`と評価された場合だけです。

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

単独で使うことも、`else`キーワードと組み合わせて使うこともできます。

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

`else`文の中にさらに条件を入れ子にするには、`else if`を使います。

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```

[utf-16-list]: https://www.fileformat.info/info/charset/UTF-16/list.htm
