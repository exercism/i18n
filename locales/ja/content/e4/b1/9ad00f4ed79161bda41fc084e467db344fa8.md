# リソース

## モジュール

Perlには標準でコアモジュールが用意されており、その一覧は[perldoc](https://perldoc.perl.org/modules)で確認できます。通常、これらのモジュールはすぐに使えます（ディストリビューションによっては、コアモジュールを別途インストールする必要があります）。

[Awesome Perl](https://github.com/hachiojipm/awesome-perl)は、便利なモジュールを厳選してまとめたリストで、他のおすすめリストへのリンクも紹介されています。

Perlにはいくつかのモジュールインストーラーがあり、[CPAN](https://metacpan.org/)で公開されているさまざまなモジュールをインストールできます。

### App::cpm
とても高速でシンプルなモジュールインストーラーです。[CPAN](https://metacpan.org/pod/App::cpm::Tutorial)でチュートリアルが公開されています。

[インストールのドキュメント](https://exercism.org/tracks/perl5/installation)にある`local::lib`の手順に沿って進めていれば、すでにインストールされています。

`cpanfile`から必要なモジュールをインストールするには、`cpm install`を実行するだけです。推奨モジュールをインストールするには`--with-recommends`を、提案モジュールをインストールするには`--with-suggested`を使います。

特定のモジュールをローカルにインストールするには`cpm install Module::Name`を実行し、グローバルにインストールするには`cpm install -g Module::Name`を実行します。

### App::cpanminus
もっとも有名で、よく使われているモジュールインストーラーです。インストール手順は[CPAN](https://metacpan.org/pod/App::cpanminus)で確認できます。

`cpanfile`から必要なモジュールをインストールするには、`cpanm -L local --installdeps .`を実行します。
特定のモジュールをローカルにインストールするには`cpanm -L local Module::Name`を、グローバルにインストールするには`cpanm Module::Name`を実行します。

## コードスタイルとリント

Perlのコーディングについて、一般的な良い指針を探しているなら、Damian Conwayの[Perl Best Practices][PBP]がよい参考になります。

コードを綺麗に整えるには、モジュール[Perl::Tidy][PerlTidy]を使えます。

その後、付属の`perltidy`ユーティリティプログラムを使ってコードをフォーマットし直せます。

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy`には、あらゆる好みに対応できる*たくさん*の設定オプションがあります。それらは[こちら][perltidyDocs]にまとめられています。

[tidyview]という、さまざまなオプションを調整してその結果をすぐに確認できるビジュアルインターフェースもあります。

コーディング規約を強制したい場合は、[Perl::Critic][perlcritic]もあります。先ほど紹介した*Perl Best Practices*に書かれているルールが付属していますが、プラグインも豊富にあり、社内のコーディング規約に合わせてカスタマイズできます。

使い方：

    $ perlcritic some_script.pl

このツールには非常に多くの設定項目があります。詳しくは[ドキュメント][perlcriticdocs]をご覧ください。
