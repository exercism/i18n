# 説明

この演習では、看板会社が看板用のカスタムメッセージを作成するためのコードを書きます。

## 1. 行事の看板を作る

文字列を`occasion`仮引数として、誰かの名前を保持する文字列を`name`仮引数として受け取る関数`buildSign(occasion, name)`を実装します。2つの仮引数はテンプレート文字列に埋め込まれ、看板に表示するメッセージを出力します。

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. 誕生日の看板を作る

年齢を受け取り、その年齢に基づいて看板のメッセージの一部を決める関数`buildBirthdaySign(age)`を実装します。年齢が50以上なら、看板ではその人を_mature_と呼び、そうでなければ_young_と呼びます。期待される正確な出力は次のとおりです。

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. 卒業式の看板を作る

名前を文字列の仮引数として、年を数値の仮引数として受け取り、文字列補間を使って、メッセージの2行を改行で区切る看板用のフレーズを作る関数`graduationFor(name, year)`を実装します。

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. 看板の費用を計算する

看板の内容を保持する文字列と、通貨を表す文字列を受け取る関数`costOf(sign, currency)`を実装します。看板の基本料金は、指定された通貨で20です。さらに、文字ごとに2かかります。（空白も計算に含まれます。）戻り値には、看板を作成する費用が含まれ、小数点以下2桁で表記し、その後に通貨文字列を続けます。

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
