# 概要

Gleamでは、新しいデータ型を定義するのにカスタム型を使います。カスタム型には複数の_バリアント_を持たせることができ、それぞれに名前を付けられます。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

カスタム型の各バリアントは、データを任意で持つことができ、バリアントごとに持てるデータの型を変えられます。バリアントがデータを持つ場合、それは_レコード_と呼ばれます。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

特定のバリアントの値を作るには、追加のデータを持たないバリアント（`Spring`）ならその名前を参照し、データを持つバリアント（`SomeInt(2)`）なら関数として呼び出します。

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

カスタム型は、Gleamにあるすべてのものと同じく、_構造的等価性_を持ちます。つまり、同じバリアントで同じデータを持つ2つの値は等しいとみなされます。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

カスタム型のバリアントは、`case`式を使ってパターンマッチできます。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
