# 概要

`case`は、Factorの等価性に基づく多分岐スイッチです。選択が、*1つ*の値がいくつかの候補のどれかと等しいかどうかで決まるときに適した道具です。各分岐ごとに別々の判定が必要なときには向きません（そういうときは`cond`を使います）。

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

押さえておきたいポイントがいくつかあります。

- 等価性の判定には`=`を使います。`=`で扱えるものはすべてキーになれます。数値、文字列、文字、シンボル、タプルなどです。
- *マッチした*分岐では、入力値がスタックから取り除かれた状態になります。*デフォルト*の分岐では、入力値がスタックの一番上に残ったままです。
- デフォルトがなく、どの分岐にもマッチしない`case`は、エラーを投げます。

`case`は、可能なときはジャンプテーブルにコンパイルされるので、単なる`if`の連鎖の糖衣構文ではなく、高速でもあります。
