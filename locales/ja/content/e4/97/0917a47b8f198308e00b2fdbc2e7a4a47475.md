# 概要

Haxeには2つの数値型があります。整数と小数です。

- `Int`：整数を表します。
- `Float`：倍精度64ビットの浮動小数点数を表します。

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

`Float`が期待される場所では、どの`Int`も使うことができます（つまり、`Int`は`Float`に**代入可能**であり、**統一可能**です）。ただし、その逆は成り立ちません。`Float`を`Int`に代入すると精度が失われる可能性があるため、暗黙的に代入することはできません。

## 比較

数値は、同じ値であれば等しいとみなされます。

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

最後のケースについては、簡単な説明が[0.30000000000000004.com][0.30000000000000004.com]にあります。
