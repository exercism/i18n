# はじめに

Kotlinは、JetBrainsが開発した**静的型付け**のプログラミング言語です。つまり、変数の型はコンパイル時に決まります。

## 変数

他の静的型付けプログラミング言語と同じように、それぞれの変数の型はコンパイル時に決める必要があります。ただし、コンパイラーが文脈から型を推論できる場合は、型の宣言を省略できます。

Kotlinには、不変の変数（`val`）と可変の変数（`var`）があります。不変の変数は、最初の値が代入されたあとに値を変更することはできません。ほとんどの場面では、このタイプの変数を使うことになります。

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

可変の変数は、値を1回以上変更できます。

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Kotlinのセミコロンは省略できます。ただし、いくつかの特殊なケースを除きます。それについては後ほど説明します。

## 関数

Kotlinの関数は`fun`キーワードで定義し、_第一級市民_です（OOPとは関係ありません）。つまり、ファイルの中に直接宣言できるという意味です（いわゆる`top-level functions`です）。たとえばJavaでは、メソッドはクラスの中にしか定義できず、ファイルには定義できません。

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

関数は引数を受け取ることができます。各引数には名前と型があります。変数とは違い、引数の型は推論できません。関数の引数は0個でも、それ以上でもかまいません。

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Kotlinの関数は、値を返すこともあれば、返さないこともあります。

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

関数から値を返すには、`return`キーワードを使います。

```kotlin
fun getName(): String {
    return "Alice"
}
```

関数は、デフォルト値を持つ仮引数を定義できます。関数を呼び出すときにその仮引数を省略すると、この値が使われます。

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## コメント

1行コメントを書くには`//`を使います。

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

複数行コメントを書くには`/*`と`*/`を使います。

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
