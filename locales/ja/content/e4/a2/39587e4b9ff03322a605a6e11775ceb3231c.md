# はじめに

1000までの非負の整数をすべて手に入れたいとします。
それを1つずつ配列に入力しなければならないとしたら、ばかげていますよね。

そこで登場するのが、`range`型です。

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

`range`は非常によく使われます。入力を省くためだけでなく、関数の戻り値としても使われます。

`range`はベクトルでは_ありません_。
シーケンスを生成するための一連の指示にすぎません（「遅延」評価、つまり「イテレーター」です）。

`range`をベクトルとして使いたいときは、`collect()`関数で変換します。

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

ステップ幅も指定できます。この例では0.3です。

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

つまり、構文は`start:stepsize:stop`です。
整数の例で見たように、両端の値はどちらも_含まれます_。
ステップ幅が`stop - start`をちょうど割り切れない場合、最後の要素は`stop`を超えないようになります。

## 文字の範囲

`range`には数値以外のシーケンスも使えます。
最も単純な例はASCII文字です。

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

`Char`型については、別のコンセプトで詳しく扱います。
今は、シングルクォートで囲んだ1文字だと考えておきましょう。

## `range`のための関数と演算子

`range`の両端は`first()`と`last()`で確認できます。

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## ベクトルのインデックス指定についてもう少し

ベクトルのインデックス指定には、整数の`range`とベクトルの両方が使えます。

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
