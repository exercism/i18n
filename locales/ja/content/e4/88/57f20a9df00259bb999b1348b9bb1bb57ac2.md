# はじめに

Pythonでは、[タプル][tuple]は_順序_を持つ要素の_不変_なコレクションです。
ほとんどのコレクションと同様、`tuples`は任意の（または複数の）データ型を保持できます。他の`tuples`も含まれます。
タプルは[共通のシーケンス操作][common sequence operations]をすべてサポートしますが、[可変シーケンス操作][mutable sequence operations]は**サポートしていません**。

タプルの要素は、`for item in <tuple>`という構文を使って繰り返し処理できます。
要素のインデックスと値の両方が必要な場合は、`for index, item in enumerate(<tuple>)`を使います。
他のシーケンスと同じく、`tuples`内の要素には、左からの`0-based index`番号または右からの`-1-based index`番号を使った_ブラケット記法_でアクセスできます。
タプルは、スライス記法（_`<tuple>[<start>:<stop>:<step>]`_）を使って全体または一部をコピーすることもできます。


## タプルの作成

タプルは、`tuple(<iterable>)`クラスコンストラクターを使う方法と、`tuple`リテラル宣言を使う方法の、複数のやり方で作成できます。

### `tuple()`コンストラクターを空で使う場合と_イテラブル_を渡す場合：

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

文字列はイテラブルなので、`tuple()`コンストラクターの引数に1つの`str`を渡すと、意外な結果になることがあります：

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

単一のイテラブルは、要素が1つずつ追加されます：

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### タプルを_リテラル_として宣言する：

`tuple(<iterable>)`コンストラクターは引数として_イテラブル_（または何もなし）しか受け取らないため、要素が1つのタプルはリテラル方式で作るほうがずっと簡単です。

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

入れ子になったデータ構造も、他の`tuples`を含め、`tuple`の要素として含めることができます：

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## タプルの連結

タプルはプラス`+`演算子を使って連結できます。これは各`tuple`を展開し、新しく結合された`tuple`を作ります。

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## タプル内の要素へのアクセス

`tuple`内の要素には、左からの`0-based index`番号または右からの`-1-based index`番号を使った_ブラケット記法_でアクセスできます。

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## タプルの要素を繰り返し処理する

`tuple`内の要素は、`for item in <tuple>`構文を使ってループで_繰り返し処理_できます。
インデックスと値の両方が必要な場合は、`for index, item in enumerate(<tuple>)`を使います。

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## タプルに要素が含まれているか確認する

`in`演算子を使うと、`tuple`にある要素が含まれているかを確認できます。

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
