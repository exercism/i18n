# はじめに

配列はFactorの固定長のシーケンスです。要素は変更できますが、長さは変えられません。配列リテラル`{ … }`の書き方や、配列をスライスしたり集約したりする方法は、すでに知っているはずです。この演習では、スタック上の値から配列を組み立て、その中身を検索したり並べ替えたりするときに必要になる、小さな道具箱を扱います。

## スタックから組み立てる

`1array`、`2array`、`3array`、`4array`（[`arrays`][arrays]にあります）は、スタックの先頭から1つ、2つ、3つ、4つの値を取り出して、それらをひとまとめにします。

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## 連結する

`concat`（[`sequences`][sequences]にあります）は、要素がそれ自体シーケンスであるシーケンスを受け取り、1階層分だけ平坦にします。`join`は、それぞれの要素の間に区切り文字を挟んで同じことをします。

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## 逆順にする

`reverse`は、要素を逆の順序にした新しいシーケンスを返します。

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## 配列かどうかを調べる

`array?`（[`arrays`][arrays]にあります）は型を判定する述語です。`<array>`、`1array`/`2array`/...、配列リテラル`{ … }`で作られた値なら真を、それ以外のすべて（ベクター、文字列、その他のシーケンスなど）なら偽を返します。

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## 検索する

`index`は、入力の値と等しい最初の要素の位置を返します。その値がなければ`f`を返します。`member?`は真偽値だけを返します。どちらも**要素が先**で、**シーケンスが後**です。`members`（[`sets`][sets]にあります）は、シーケンスの*重複のない*要素（重複を取り除く操作です）を返し、`all-unique?`（これも`sets`にあります）は、そのシーケンスにすでに重複がないかどうかを調べます。

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
