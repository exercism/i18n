# `for`ループ

ループは、コードのブロックを何度も実行できるようにする、プログラミングの基本的な概念です。Swiftには、[`for-in`ループ][for-loops]と`while`ループの2種類のループがあります。この章では、`for-in`ループについて学びます。

`for`ループを使うと、値のシーケンスを繰り返し処理し、各要素を1つずつ取り出して、自分で選んだ変数に束縛できます。Swiftでは、範囲、配列、文字列など、さまざまなシーケンスを繰り返し処理できます（その他の型については、後ほど説明します）。シーケンスのすべての要素を処理し終えると、ループは終了します。

`for`ループは、`for`キーワード、変数名、`in`キーワード、そして繰り返し処理する値のシーケンスの順に書いて宣言します。`for-in`ループに与える変数は不変なので、ループの中でその値を変更することはできません。次は、数値の配列を繰り返し処理する`for-in`ループの例です。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number`変数は`for-in`ループの中で宣言され、ループのスコープ内でのみ利用できます。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 範囲を繰り返し処理する

`for-in`ループを使って、数値の範囲を繰り返し処理することもできます。これを使うと、コードのブロックを決まった回数だけ実行できます。たとえば、範囲`1...5`は1、2、3、4、5の数値を繰り返し処理するので、ループは5回実行されます。配列のようなデータ構造でインデックスを繰り返し処理したいときは、`0..<array.count`という範囲を使います。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 文字列を繰り返し処理する

`for-in`ループを使って、文字列を繰り返し処理することもできます。これを使うと、文字列の各文字を繰り返し処理できます。ここで注目したいのは、ループに与えられる型が`Character`であるという点です。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## `stride`

Swiftには、特定のステップ幅で範囲のシーケンスを作れる`stride`関数もあります。これは`for-in`ループで繰り返し処理できます。`stride`には[`stride(from:to:by:)`][stride-to]と[`stride(from:through:by:)`][stride-through]の2つがあり、前者は終端を含まず、後者は終端を含みます。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

`to`の仮引数は終端を含まないので、ループは`to`に指定した数値の手前まで繰り返し処理します。一方、`through`の仮引数は終端を含むので、この場合は`10`も含まれます。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
