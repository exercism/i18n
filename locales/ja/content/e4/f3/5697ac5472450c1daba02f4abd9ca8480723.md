# はじめに

それぞれの値が自分の位置によって決まる、`n`個の値の並びが必要なときは、Factorの`<iota>`と`map`が協力すれば、ループのカウンターを書かずにそれを実現できます。

## `<iota>` と `map`

`<iota>`（[`sequences`][sequences]にあります）は、非負の整数`n`を受け取り、整数`0, 1, …, n-1`からなる*仮想的な*シーケンスを返します。次に`map`がそのシーケンスを順にたどり、各要素にクオーテーションを適用します。

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

クオーテーションは整数を1つ、つまりインデックスを受け取り、その位置に対応する値をスタックに残します。

## インデックスの走査と、回数を指定した繰り返し

各インデックスを訪れることによる*副作用*だけが必要で、新しいシーケンスが要らないときは、`each-integer`（[`math`][math]にあります）がクオーテーションを`0, 1, …, n-1`に対して実行します。

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate`（[`sequences`][sequences]にあります）は、クオーテーションを`n`回呼び出して結果を集めます。インデックスは無視されるので、`n`個の独立した値を作るときに便利です。

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## 上下限を指定する範囲

インデックスの範囲が`0`から始まらない場合や、両端を含めたい場合は、[`ranges`][ranges]ボキャブラリーが括弧記法のリテラルを提供します。角括弧は端点を含み、丸括弧は端点を含みません。

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

よく使われる、引数を1つだけ取る省略記法を紹介します。

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>`がもっとも一般的な形です。`[a..b]`などの仲間は、範囲が`0`以外から始まるときや、上限を含める必要があるときに適した道具です。

## 下限が開いた範囲と、空になりうる範囲

角括弧は端点を*含み*、丸括弧は端点を*含みません*。同じ考え方を左側にも当てはめると、`(a..b]`と`(a..b)`になります。

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]`は、`n > 0`のとき`{ 1 … n }`、`n = 0`のとき`{ }`を返します。これは「`n`以下の正の整数すべて」を繰り返し処理するときに自然な形です。

## 降順の範囲

4つの括弧記法、`[a..b]`、`[a..b)`、`(a..b]`、`(a..b)`は、`a > b`のとき、空の結果に向かうのではなく*下向き*に数えます。

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## 位置に応じて文字列を組み立てる

`map`は、クオーテーションが返した形のまま結果を返します。クオーテーションが文字コードをスタックに残した場合は、`>string`（[`strings`][strings]にあります）がその結果を文字列に変えます。

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A`は整数`65`としてパースされます。ここでのクオーテーションはインデックスを2倍にしてその値を足すので、1つおきの大文字に行き着きます。インデックスにどんな計算を重ねるかによって、その位置に来る文字が決まります。

## 位置ごとに選び分ける

その位置の文字がインデックスに関する*条件*で決まるときは、クオーテーションの中で選び分けます。

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

最初の3つの位置では`i 3 <`が`t`と判定されるので`a`になり、残りは`b`になります。同じ形、`[ <test> [ <yes> ] [ <no> ] if ]`を使えば、`even?` / `odd?`（[`math`][math]にあります）による偶奇の判定や、`mod`と`zero?`を使った「k個おきの位置」の判定にも対応できます。
