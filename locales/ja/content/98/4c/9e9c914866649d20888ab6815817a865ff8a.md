# ロードマップ

このドキュメントでは、今後数か月の間にコントリビューターやメンテナーが主に取り組むことになるであろう主要なトピックの概要を紹介します。

## トピックの概要

- 既存のコンセプト演習を改善する
- 新しいコンセプト演習を作成する（下記のシラバス概要を参照）
- すべてのプラクティス演習について、`prerequisites`と`practices`のリストを定義する（[Issue 1396](https://github.com/exercism/go/issues/1396)を参照）
- 残っている[テストランナー](https://github.com/exercism/go-test-runner/)のバグを修正する
- [アナライザー](https://github.com/exercism/go-analyzer/)を修正して再び動くようにし（例：[Issue 16](https://github.com/exercism/go-analyzer/issues/16)を参照）、その他のバグも修正する
- [リプレゼンター](https://github.com/exercism/go-representer/)の安定した良いバージョンを完成させ、実際に公開する
- 演習のアプローチを改善・追加する
- [問題仕様](https://github.com/exercism/problem-specifications)とテストを同期する

## シラバスの概要

### すでにあるコンセプト

- `basics`
- `strings`と`strings-package`
- `numbers`（基本）と`arithmetic-operators`
- `floating-point-numbers`
- `booleans`
- `comments`
- `conditionals-if`と`comparison`
- `conditionals-switch`
- `structs`
- `type-definitions`
- `slices`
- `iteration`（`for`ループ）
- `functions`（複数の戻り値を含む）
- `maps`
- `range-iteration`
- `runes`
- `pointers`
- `methods`
- `interfaces`
- `errors`
- `zero-values`（nilを含む）
- `type-conversion`
- `type-assertion`
- `constants`
- `string-formatting`
- `packages`（import/export）
- `time`
- `variadic-functions`（`...`を導入）
- `randomness`
- `regular-expressions`
- `stringers`

### 今後追加される可能性のあるコンセプト

- `time-duration`
- `integer-types`
- `panic-recover`
- `error-wrapping`（errors.Is、errors.As）
- `bytes`
- `bitwise-operators`
- `goroutines`
- `waitgroups`
- `mutexes`
- `channels`と`select`
- `closures`/`anonymous-functions`/`higher-order-functions`
- `JSON`
- `defer`
- `Buffer`、`io.Reader`/`io.Writer`
- `typed-parameters`（ジェネリクス）
- `context`
- timeヘルパー（ticket、sleepなど）
- `reflection`
- `unsafe`
- `init`
- Functional Optionsパターン
- ファイルの埋め込み

コンセプト演習の範囲外になりそうな追加トピック：

- ツール類（go fmt、go vet、go docなど）
- テストとサンプルの書き方
- ベンチマーク
- プロファイリング
- go generate
- コンパイラオプション
