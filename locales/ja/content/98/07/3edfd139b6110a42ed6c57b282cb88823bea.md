# はじめに

ハッシュはPerlのデータ型のひとつで、文字列のキーとスカラー値のペアを順序なしで保持します。

ハッシュ変数は通常、リストを代入して初期化します。たとえば、`my %scores = (Alice => 10, Bob => 15, Charlie => 20);`のように書きます。

リストの要素は通常カンマで区切りますが、キーと値を区切るために「ファットコンマ」と呼ばれる`=>`をよく目にするでしょう。その動作はカンマとほぼ同じですが、左辺の要素を文字列として解釈してくれるという利点があります。

ハッシュは個々のキーに代入して初期化することもできます。たとえば、`$scores{Alice} = 10;`のようになります。

ハッシュの値には、添字でキーを指定してアクセスできます。たとえば、`$scores{Bob} # 15`のようになります。

ハッシュのキーは一意です。同じキーが複数与えられた場合、最後に与えられた値だけが保持されます。

## 関数

ハッシュを扱う関数には、ハッシュのそれぞれの部分をリストとして取得する[keys][keys]と[values][values]があります。[keys][keys]と[values][values]関数が返すリストは、[grep][grep]、[map][map]、[sort][sort]といったリストを扱う関数や、[for][for]ループで役立ちます。

その他のハッシュ関数には、キーがハッシュに存在するか（値が`undef`であっても）を確認する[exists][exists]や、ハッシュからキーを削除する[delete][delete]があります。

## シジルの違い

ハッシュの値を取得するとき、与えるシジルによって結果が変わります。変数名の末尾にある添字`{}`が、その名前のハッシュにアクセスしていることをPerlに伝えます。

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

許可されていますが、可読性のために、異なる変数型で同じ名前を共有しないことをおすすめします。
