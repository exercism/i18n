# 説明

この演習では、車両の購入の準備を手助けするコードを書いていきます。

ここには3つのタスクがあります。1つは運転免許が必要かどうかを判定するもの、1つは2台の車両から選ぶのを手助けするもの、もう1つは中古車の妥当な価格を見積もるものです。

## 1. 運転免許が必要かどうかを判定する

車両の種類によっては、運転するのに運転免許が必要です。
運転免許が必要なのは`"car"`と`"truck"`の2種類だけだと仮定し、それ以外は免許なしで運転できるものとします。

車両の種類を受け取り、その種類に免許が必要かどうかを示す真偽値を返す`needsLicense(kind)`関数を実装しましょう。

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. 購入候補の2台から選ぶ

購入できる車両の中から候補を検討します。
何とか2台まで絞り込めましたが、最終的な決断には助けが必要です。
そこで、2台の車両を引数として受け取り、[辞書順][lexicographical-order]で先に来る方を含む判断を返す`chooseVehicle(option1, option2)`関数を実装しましょう。

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 中古車の価格の見積もりを計算する

選ぶ車が決まったら、ディーラーで妥当な価格で買えるようにしたいところです。
中古車の購入を考えているので、価格は車両の年式によって変わります。
おおよその見積もりとして、車両が3年未満なら、新車だったときの定価の80%の価格だと仮定します。
10年以上なら50%です。
3年以上10年未満なら、定価の70%です。

このロジックを`if`、`else if`、`else`を使って適用する`calculateResellPrice(originalPrice, age)`関数を実装しましょう（練習したい場合は他の書き方でも構いません）。
定価と車両の年式を引数として受け取り、ディーラーでの見積もり価格を返します。

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
