# 補足説明

## ワード

`custom-set`タプルを定義し、`INSTANCE: custom-set set`で`set`ミックスインのインスタンスとして宣言します。

- `<custom-set> ( -- set )`は、空の集合を作ります。
- `>custom-set ( seq -- set )`は、シーケンスから集合を作り、重複は黙って捨てます。

次に、`custom-set`に対して、`members`、`in?`、`adjoin`、`set-like`の`M:`メソッド（`sets`のもの）を用意します。`INSTANCE:`宣言とこの4つのメソッドがあれば、`sets`ボキャブラリーの`null?`、`union`、`intersect`、`diff`、`subset?`、`set=`、`intersects?`は、プロトコルのデフォルト実装を通して、定義した集合でどれも機能します。テストはこれらのワードを直接呼び出します。

`adjoin ( elt set -- )`は破壊的です。`elt`がまだ含まれていなければ、`set`にその場で追加します。
