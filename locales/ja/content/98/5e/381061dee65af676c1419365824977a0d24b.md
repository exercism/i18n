# 説明

この演習では、2012年9月15日にニューヨークでオープンした美容サロンの予約スケジューラーを作ります。

## 1. 予約日時を解析する

`AppointmentScheduler.schedule()`メソッドを実装して、予約日時のテキスト表現を対応する`LocalDateTime`に解析しましょう。

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. 予約がすでに過ぎているかどうかを確認する

予約日時を受け取り、その予約が過去のものかどうかを確認する`AppointmentScheduler.hasPassed()`メソッドを実装しましょう。

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. 予約が午後かどうかを確認する

予約日時を受け取り、その予約が午後（12:00以降、18:00より前）かどうかを確認する`AppointmentScheduler.isAfternoonAppointment()`メソッドを実装しましょう。

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 予約の日時を説明する

予約日時を受け取り、その日時の説明を返す`AppointmentScheduler.getDescription()`メソッドを実装しましょう。

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. 記念日を返す

今年の記念日である9月15日を返す`AppointmentScheduler.getAnniversaryDate()`メソッドを実装しましょう。

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
