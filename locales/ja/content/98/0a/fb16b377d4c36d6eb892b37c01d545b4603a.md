# ヒント

## 全般

- 似た内容のわかりやすい実例が載っている[Elm Guide][elm-guide]を見てみましょう。

## 1. アプリケーションのModel型とMsg型を定義し、init関数を書く

- `Model`には、アプリケーションの状態、つまりアプリケーションに必要なすべてのデータが入ります。
- これは[レコード][record]である必要があります。
- このアプリケーションでは、テキストボックスに入力されたテキストを保存するための`String`が1つあれば十分です（テストでは、`content`という名前であることが求められます）。

- `Msg`型は、`update`関数に渡されるメッセージを定義するもので、モデルに特定の変化を起こすために使います。
- これは[カスタム型][custom-type]である必要があります。
- このアプリケーションに必要なモデルの変更は1つだけです。テキストボックスのテキストが変わったときに、モデルを更新するという変更です。

- `init`関数は、適切なデフォルト値を持つ`Model`を返すだけでかまいません（テストでは、空文字列が求められます）。

## 2. update関数を書く

- 役に立つアプリケーションなら、update関数は`case`文を使って`Msg`の入力にパターンマッチします。
- `case`文の各分岐では、`Msg`の入力から必要な情報を取り出し、更新された`Model`を返します。
- `Model`はレコードである必要があり、通常は[レコード更新構文][record-update-syntax]を使います。

## 3. view関数を書く

- `view`関数は、ルート要素として`div`を返します。
- 最初の子要素は`input`にします。現在のテキストを表す`value`属性と、該当する`Msg`のバリアントを持つ`onInput`属性/イベントを付けます。
- 2番目の子要素はもう1つの`div`で、その中に、テキストが回文かどうかを示す`text`の子要素を置きます。

## 4. main関数を書く

- main関数は、[`Browser.sandbox`][browser-sandbox]を呼び出すだけです。
- `Browser.sandbox`には、`init`、`update`、`view`の各関数を持つ[レコード][record]を渡す必要があります。
