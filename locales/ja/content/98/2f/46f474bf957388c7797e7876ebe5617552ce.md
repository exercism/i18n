# `while`ループと`until`ループ

ループは、与えられた条件に基づいてコードを繰り返し実行するための制御構造です。

## `while`ループ

`while`ループは、与えられた条件に基づいてコードを繰り返し実行するための制御構造です。`while`ループ内のコードは、条件が真と評価されるかぎり実行され続けます。`while`ループは、繰り返しの回数が事前にわからないときによく使われますが、ループが必要なあらゆる場面で使うことができます。

条件は、ループ内のコードが実行される前に評価されます。つまり、条件が偽であれば、ループ内のコードは一度も実行されません。

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

文字列を1文字ずつ処理したいときは、文字列の長さを使ってループを回すことができます。

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`ループ

`until`ループは`while`ループと同じように動作しますが、ループ内のコードは条件が真と評価されるまで実行され続けます。これは`if`と`unless`の違いと同じです。

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 無限ループ

`while`ループでよくある間違いは、決して終わらない「無限ループ」に陥ることです。無限ループは、条件が決して真または偽と評価されないことが原因で起こることがあります。これは多くの場合、プログラマーのミスによるものです。たとえば、ループ変数のインクリメントを忘れた場合などです。しかし、プログラムのロジックを実装するうえで、無限ループがもっともわかりやすい方法であることもあります。あるいは、永遠にループし続けることが欠かせない場合もあります。たとえば、HTTPサーバーは、やってくる接続を待ち、それを処理し、そして次の接続を待ちます。

## `break`

`break`キーワードを使うと、ループを途中で抜けることができます。特定の条件でループを途中で抜けたいときに便利です。

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next`キーワードを使うと、ループの次の繰り返しへスキップできます。ループの特定の繰り返しをスキップしたいときに便利です。

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## ループ中の型

ループの中では、変数の型が異なることがあります。次の例では、ループの前半で`a`が`Int32`にも`String`にもなりうるため、`a`の型は`Int32 | String`です。変数`a`が型`Int32 | String`になるのは、ループの前半だけです。ループが始まるときには`Int32`を保持しており、2回目の繰り返しでは`String`を保持するからです。この複数の型を扱う仕組みについては、のちほど詳しく説明します。ただし、ループの後半では`String`しか保持しないことが確実なので、ループの後半における`a`の型は`String`です。実行時に`Int32`と`String`を同時に保持することはありません。

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
