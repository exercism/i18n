# 文字列ビルダー

`STR`は決して変わりません。つまり、`+`で`STR`に付け足すことはできず、両方の中身を持つまったく新しい文字列を作ることになります。

1回なら問題ありません。しかしループの中ではそうはいきません。

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

ループが1回回るたびに、それまでに作った内容すべてが新しい文字列にコピーされ、古い文字列は捨てられます。10行なら10回のコピーで、しかも回を追うごとに長くなっていきます。100行なら100回です。作業量は行数の*2乗*で増えていき、無害に見えるループがプログラムの中で一番遅い部分になります。

## FSTR

`FSTR`は、*変更できる*文字列、すなわち**文字列ビルダー**です。`FSTR`に付け足すときは、たいていすでに確保してある領域に書き込むだけなので、100行を処理するループでも、100回のコピーではなく、およそ100行分の作業で済みます。

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

注目すべき点が3つあります。

**`#FSTR`は空の`FSTR`を作ります。** `#FSTR(100)`は、100文字分の領域をあらかじめ確保した`FSTR`を作ります。サイズがわかっているときは、こうしておく価値があります。

**結果は必ず代入し直す必要があります。** `script := script + ...`と書き、`script + ...`だけではいけません。たいていの場合、返ってくるのは渡したのと同じビルダーですが、領域が足りなくなると、より大きな新しいビルダーになります。戻り値を捨ててしまうと、古いビルダーに書き込み続けることになります。

**最後に`.str`を付けます。** `: STR`を返すと宣言したルーチンは`STR`を返さなければなりません。`.str`はビルダーから`STR`を作ります。

## 追加できるもの

`FSTR`に対する`+`は、文字列、文字、整数、真偽値を受け付けます。そのため、たいていは事前に変換する必要はありません。

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## 改行

文字列の中の`"\n"`は改行です。1文字ですが、2文字で書きます。

```sather
   script := script + "Enter" + "\n" + "Exit";
```
