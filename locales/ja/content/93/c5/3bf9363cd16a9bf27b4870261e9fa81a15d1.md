# 型のジャグリング

型のジャグリングは、型の強制変換とも呼ばれます。
型のジャグリングとは、演算を行うために、異なる型の2つの値が同じ型に強制変換されることです。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

式が評価されるとき、文字列の値は、`*`演算子の期待に合わせて暗黙的に`int`に変換されます。どちらの型に変換するかは、その演算の規則に従ってPHPが判断しますが、その規則は大きく異なります。

型の強制変換は、関数やメソッドを呼び出すときにも起こります。

```php
strlen(12321);
# => 5
```

## 型キャスト

暗黙的な強制変換に頼る代わりに、`C`言語スタイルの型キャストを使って、値を特定の型として明示的に評価させることができます。

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

これは、値を括弧（`(...)`）で指定した型に変換します。対象の型には、すべてのプリミティブ型を使用できます。`bool`、`int`、`float`、`string`、`array`、`object`です。

## 一時的な変換にすぎない

型のジャグリングやキャストは、変数に格納されている値の型を**変えません**。変換されるのは、演算への入力だけです。

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## 情報の欠落

値を別の型に強制変換すると、その過程で情報が失われることがあります。

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

キャストに頼ると、それが明示的であれ暗黙的であれ、より大きなシステムではエラーを引き起こす可能性があります。

## `array`と`object`への明示的な型キャスト

値は`array`型や`object`型にキャストすることもできます。配列でもオブジェクトでもない値を`array`にキャストすると、配列の中の1つの要素に変換されます。

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

`object`にキャストすると、その値は`scalar`という名前のpublicプロパティに設定されます。

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass`は、PHPに組み込まれている無名クラスの型です。
