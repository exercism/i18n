# 余り

余りを使った比較は、Crystalでも問題なく書けます。ただ、割り算の余りを比べるなら、[`divisible_by?`][divisible_by]メソッドを使うほうが読みやすくなります。
たとえば、次のとおりです。

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
