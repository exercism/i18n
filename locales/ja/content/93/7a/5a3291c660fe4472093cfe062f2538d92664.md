# はじめに

構造体は[マップ][exercism-maps]を基盤にした拡張で、コンパイル時のチェックとデフォルト値を提供します。構造体の名前は、それが定義されたモジュールと同じになります。構造体を定義するには、`defstruct`構文を使います。この構文は通常、モジュール定義の直後に置きます。`defstruct`は、アトムのリスト（デフォルト値が`nil`の場合）か、キーワードリスト（デフォルト値を指定する場合）のどちらかを受け取ります。デフォルト値を持たないフィールドは、デフォルト値を持つフィールドより前に書く必要があります。

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## フィールドへのアクセスと更新

構造体はマップを基に作られているので、値の取得や操作にはほとんどのマップ関数を使えます。ただし、構造体には_アクセスビヘイビア_が**実装されていません**。構造体のフィールドにアクセスするには、代わりに_静的アクセス演算子_の`.`を使うのがおすすめです。

- フィールドの値を取得・フェッチする:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- フィールドの値を更新する

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## パターンマッチング

構造体は、構造体名を付けても付けなくてもパターンマッチングで使えます。

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

パターンに構造体名を含めると、左辺と右辺が同じ型の構造体であることを保証できます。

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## フィールドの値の初期化を強制する

`@enforce_keys`モジュール属性にフィールドのキーのリストを指定すると、構造体の作成時に値が初期化されることを保証できます。キーがリストにない場合、その値は上の例のように`nil`になります。強制されたキーが初期化されないと、エラーが発生します。

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
