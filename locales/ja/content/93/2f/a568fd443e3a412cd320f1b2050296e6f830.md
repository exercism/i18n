# About

Perlは、Larry Wallが作ったプログラミング言語で、1987年に最初のバージョンが公開されました。

## パッケージとモジュール

パッケージはコードの集まりで、多くの場合、同じ名前で拡張子が`.pm`のモジュールファイルの中に入っています。
モジュールは、ふつうは`use`キーワードを使って、別のファイルに読み込むことができます。

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## 変数

スカラー変数（`$foo`）、配列変数（`@bar`）、ハッシュ変数（`%baz`）があります。
ここでは話を簡単にするため、スカラー変数だけを使います。
スカラーの値は、文字列、数値、真偽値、あるいは何かへの[リファレンス][perlreftut]のいずれかです。
値が存在しないことは`undef`で表します。


`my`と`our`というキーワードは、レキシカルスコープで変数を宣言します。たとえば`my $foo;`のように書きます。
`our`を使うと、その変数は同じ名前のパッケージ変数の別名にもなります。
ここでは扱いませんが、ほかにも変数を宣言する方法があります。

変数には`=`演算子で代入できます。たとえば`$foo = 1;`です。これは変数の宣言と同時に行うこともできます。たとえば`my $foo = 1;`のように書きます。

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## サブルーチン

`sub`キーワードは[サブルーチン][perlsub]を宣言します。
`return`キーワードはサブルーチンを終了し、指定した値を返します。何も指定しなければ空のリストを返します。
`return`を指定しない場合、返される値は、使われたサブルーチンのコンテキスト（スカラー、リスト、無効）とその最後の文によって決まります。

```perl
sub hello () {
    return 'Hello, World!';
}
```

最近のバージョンのPerlでは、[シグネチャ][perlsubsig]で仮引数を指定できます。
仮引数のリストには、スカラー変数、配列変数、ハッシュ変数を含められます。
仮引数のリストが空なら、そのサブルーチンは引数を1つも受け取りません。
古いバージョンのPerlでは、特殊変数`@_`から引数を取り出す必要がありましたが、ここでは扱いません。

## コメント

Perlのコメントは、文字列の一部ではない`#`で始まり、行の終わりまで続きます。
