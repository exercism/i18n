# 概要

[`grouping`][grouping]と[`splitting`][splitting]にある4つのワードで、「シーケンスをいくつかの部分に切り分ける」というほとんどすべての用途に対応できます。

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| ワード            | 効果                                                                  |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`（重ならない*n*個ずつのまとまり）                       |
| `clump`           | `( seq n -- clumps )`（重なり合う*n*個ずつの窓）                   |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`（quotが真のときに区切る）      |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`（*隣り合う*要素でquotが`f`のときに区切る） |

役に立つイメージは、次のとおりです。

- **`group`/`clump`**は大きさに注目します。*n*という入力が、それぞれの窓の大きさを決めます。
- **`split-when`**は*1つの要素*に注目します。述語が、その要素が区切りになるかどうかを判断します。
- **`monotonic-split`**は*ペア*に注目します。述語が、隣り合う2つの要素がまだ同じまとまりに属しているかどうかを判断します。

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
