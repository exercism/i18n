# 概要

C#のリストは、プリミティブ値や、構造体・クラスのインスタンスを集めたコレクションです。基底クラスライブラリでは[`List<T>`][lists-docs]として実装されており、ここで`T`はリストに入れる要素の型を表します。APIには、リストを作成・操作するための豊富なメソッドが用意されています。

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

コレクションの定義には、たいてい山括弧（`<>`）で囲んだプレースホルダーが含まれ、慣例的に`T`が使われます。これにより、コレクションを使う側が、どんな型の要素を格納するかを指定できます。

[concept:csharp/arrays]()と違って、リストはサイズを動的に変更できます。

## LINQ

`List<T>`に組み込みで用意されているAPIは豊富です（`ConvertAll`、`FindAll`、`Foreach`などのマッピングやフィルタリングも含まれます）。[ループ構文][for-each]もとても分かりやすく、このAPIに慣れておくことは間違いなく必要です。ただ、多くのタスクではLanguage Integrated Query（[LINQ][linq]）も利用できます。LINQはさらに強力で、広く使われており、ライブラリのコレクション、サードパーティのコレクション、自作のクラスに対して一貫したインターフェースを提供できるという利点があります。
