# ヒント

## 全般

- [`combinators`][combinators]の`cond`が、スピードを成功率に対応させるもっともすっきりした方法です。
- 算術のワードは[`math`][math]にあります。小数を整数に変換するヘルパーである`floor`と`>integer`は、それぞれ[`math.functions`][math.functions]と`math`にあります。

## 1. ラインが動いているかどうかを報告する

- [`math`][math]の`zero?`は、スピードが`0`かどうかを判定します。
- `if`は真偽値と2つのクオーテーション（`[ "stopped" ] [ "running" ]`）を受け取り、条件に合うほうを実行します。ここではテストがスピードを消費するので、どちらのクオーテーションにも`drop`は必要ありません。

## 2. 成功率を計算する

- `cond`の節は`{ [ predicate ] [ body ] }`と書きます。各述語はスピードを調べますが、スタックは元のままにしておく必要があります（`dup`…`<test>`とすればそうなります）。本体はたいてい`drop`で始まります。
- 順序が大切です。`0 4 <=`は`t`になるので、`zero?`を`4 <=`より先に確認します。
- 最後のエントリーは述語なしにして、スピード`10`のデフォルトとして使います。

## 3. 1時間あたりの生産率を計算する

- ファイルの先頭付近で、`base-speed`を`CONSTANT:`として定義します（`lasagna`の`expected-bake-time`と同じです）。
- `base-speed * speed * success-rate`を計算します。1つの方法は`kernel`の`bi`を使うことです。`bi`は同じ入力に対して2つのクオーテーションを実行し、両方の結果をスタックに残します。

## 4. 1分あたりに生産される正常な製品の数を計算する

- 1時間あたりの生産率を60で割ります。
- `floor`で小数部分を切り捨ててから、`>integer`でその小数の結果を整数に変換します。
