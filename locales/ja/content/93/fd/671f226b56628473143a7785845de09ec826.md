# 説明

この演習では、自動車工場の組み立てラインの生産を分析するコードを書きます。組み立てラインの速度は、`0`（停止）から`10`（最大）まで設定できます。

最も低い速度（`1`）では、1時間に`221`台の車が生産されます。生産台数は速度に比例して増えるので、速度を`4`にすると、1時間に`4 * 221 = 884`台の車を生産することになります。ただし、速度が上がるほど不良品が作られる可能性が高くなり、そうした車は廃棄しなければなりません。次の表は、速度が成功率にどう影響するかを示しています。

- `0`: 成功率0%。
- `1`から`4`: 成功率100%。
- `5`から`8`: 成功率90%。
- `9`: 成功率80%。
- `10`: 成功率77%。

課題は3つあります。

## 1. 成功率を計算する

生産速度に基づいて成功率を計算する、`successRate`関数を実装してください。

```fsharp
successRate 6
// => 0.9
```

## 2. 1時間あたりの生産台数を計算する

成功率を考慮して、組み立てラインの1時間あたりの生産台数を計算する、`productionRatePerHour`関数を実装してください。

```fsharp
productionRatePerHour 6
// => 1193.4
```

戻り値は`float`であることに注意してください。

## 3. 1分あたりに生産される良品の数を計算する

1分あたりに何台の良品が生産されるかを計算する、`workingItemsPerMinute`関数を実装してください。

```fsharp
workingItemsPerMinute 6
// => 19
```

戻り値は`int`であることに注意してください。
