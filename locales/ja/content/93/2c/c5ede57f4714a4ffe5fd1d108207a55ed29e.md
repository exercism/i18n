# はじめに

`null`値は、値が_存在しないこと_を表すために使われます。**null許容**型とは、変数が`null`値を取れるようにする型です。任意の型をnull許容にするには、その型を`Null<T>`で包みます。

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

ある値が現在`null`かどうかを確認するには、`if`式を使うだけです。

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
