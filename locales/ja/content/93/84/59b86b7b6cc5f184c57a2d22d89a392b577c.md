# 型アサーション入門

Goのインターフェースは、基底の型について曖昧さを生むことがあります。
型アサーションを使うと、インターフェース値が持つ基底の具象値を、次の構文で取り出せます：`interfaceVariable.(concreteType)`。

例えば、次のようになります：

```go
var input interface{} = 12
number := input.(int)
```

注意：インターフェース変数が具象型の値を持っていないと、これはパニックを引き起こします。

型アサーションの戻り値は2つあります。基底の値と、アサーションが成功したかどうかを示す真偽値です。この両方を利用すれば、インターフェース値が特定の具象型の値を持っているかどうかを確かめられます。
例えば、次のようになります：

```go
str, ok := input.(string) // no panic if input is not a string
```

`input`が`string`を持っていれば、`str`が基底の値になり、`ok`は`true`になります。
`input`が`string`を持っていなければ、`str`は`string`型のゼロ値（つまり`""`、空文字列）になり、`ok`は`false`になります。
どちらの場合もパニックは起きません。

## 型スイッチ

**型スイッチ**を使うと、複数の型アサーションを連続して行えます。
構文は型アサーション（`interfaceVariable.(concreteType)`）と同じですが、`concreteType`がキーワード`type`に置き換わります。
次に例を挙げます：

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
