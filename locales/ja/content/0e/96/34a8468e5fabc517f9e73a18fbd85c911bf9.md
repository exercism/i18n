# 概要

[`for`ループ][for-statement]を使うと、条件を満たすまでコードを繰り返し実行できます。

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`ループは、4つの部分から成り立っています。

1. 初期化子：ループに入る前に1度だけ実行されます。ふつうは、ループの中で使う変数を定義するために使います。
2. 条件式：各繰り返しの前に実行されます。これが`true`と評価される間、ループは実行され続けます。
3. 反復子：各繰り返しの後に実行されます。ふつうは、ループ変数を変更する（多くの場合、増やす／減らす）ために使います。
4. 本体：各繰り返しで実行されるコードです。

## `for`ループと`foreach`ループの違い

一般に、[concept:csharp/foreach-loops]()は次の理由から`for`ループよりも好ましいです。

- `foreach`ループは、_すべて_の値を確実に繰り返し処理します。`for`ループでは、たとえばオフバイワンエラーによって要素を見落としやすくなります。
- `foreach`ループはより_宣言的_です。コードは_何を_したいのかを伝え、`for`ループのように_どのように_したいのかを伝えるものではありません。
- `foreach`ループは間違いが起きにくいのに対し、`for`ループではオフバイワンエラーが起きやすくなります。
- `foreach`ループは、インデックスを使って要素にアクセスできないものを含め、すべてのコレクション型で使えます。

`foreach`ループが_すべて_の値を確実に処理できるようにするため、コンパイラーは`foreach`ループの中でコレクションを更新することを許可しません。

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`ループには、`foreach`ループにない利点もいくつかあります。

- 好きなインデックスから始めたり、そこで終えたりできます。
- 任意の（真偽値による）終了条件を使えます。
- ループ変数の増やし方を工夫して、要素を飛ばすことができます。
- カウントダウンして、コレクションを後ろから前へ処理できます。
- コレクションを扱わない場面でも`for`ループを使えます。
