# はじめに

C#のプロパティは、クラスのメンバーであり、そのクラス内のデータへのアクセスを提供します。
呼び出し側は、そのデータを設定したり取得（get）したりできます。プロパティは、自動実装にする
ことも、バッキングフィールドを持つこともできます。プロパティはsetアクセサーとgetアクセサーの
一方、または両方で構成されます。他の言語では、「ミューテーター」がsetアクセサーに、
「アクセサー」がgetアクセサーにほぼ相当しますが、構文の構成はまったく異なります。

プロパティを設定するときは、入力値を検証したり、書式を整えたり、その他の方法で加工したりでき、
実際、クラス内のコードから利用できるあらゆるプログラム的操作を実行できます。

同様に、プロパティを取得するときは、データを計算したり書式を整えたりでき、ここでもクラスで
利用できるあらゆるプログラム的操作を実行できます。

プロパティには、他のクラスメンバーと同じようにアクセス修飾子（`public`、`private`など）を
付けられます。ただし、setアクセサーは、取得（get）アクセサーとは独立したアクセスレベルを
持てますし、その逆も可能です。プロパティは両方のアクセサーを持つ必要はなく、どちらか一方
（getまたはset）だけでもかまいません。

プロパティを表す基本的な構文には、2つの形があります。

## フィールドまたは式でバッキングするプロパティ：

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## 自動実装プロパティ

```
public int MyProperty { get; private set; } = 42;
```

初期化は省略できます。
