# 型のジャグリング

型のジャグリングは、型の強制変換とも呼ばれます。
型のジャグリングとは、演算を行うために、型の異なる2つの値が同じ型に変換されることをいいます。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

これは暗黙的に行われることもあれば（上の例を参照）、`C`スタイルの型キャストを使って明示的に行うこともできます。

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

手動の型キャストで使用できる型は、`bool`、`int`、`float`、`string`、`array`、`object`です。
型キャストは、整数（`int`）を小数（`float`）に変換する場合や、その逆の場合によく使われます。
