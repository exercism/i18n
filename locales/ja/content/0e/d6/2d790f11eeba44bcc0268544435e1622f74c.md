# はじめに

`Map`は、**キー**と**値**のペアを保存するために使います。`Maps`の初期化は配列と同じように行いますが、マップリテラルの演算子`=>`を使います。キーと値の型を明示的に定義することもできますし、型を推論させることもできます。キーは一意でなければならず、そうでない場合はエラーが発生します。

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map`は`for`ループで繰り返し処理できます。繰り返す対象は、値とキーのどちらでもかまいません。

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
