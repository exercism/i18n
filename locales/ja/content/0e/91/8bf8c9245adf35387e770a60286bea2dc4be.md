# 概要

浮動小数点数とは、小数点以下の桁を0桁以上持つ数値のことです。
例としては、`4.0`、`0.1`、`3.14`、`-6.4`、`16.984025`、`1024.0`などがあります。
Rubyでは、浮動小数点数は[Float][Float]クラスによって実装されています。

浮動小数点数についての簡単な紹介は、[0.30000000000000004.com][0.30000000000000004.com]にあります。

[Float Toyのページ][evanw.github.io-float-toy]には、浮動小数点数のビットがどのように実際の浮動小数点値へ変換されるのかを、図を使ってわかりやすく説明したものがあります。

同じ処理を繰り返し実行するには、ループを使います。
この例では、条件が真とみなされる値（つまり`false`でも`nil`でもない値）に評価されている_間_、ループを続けるため、`while`ループが役立ちます。
Rubyには、`while`ループに似たループが用意されています。
それは`until`ループと呼ばれていて、その動作はもうお分かりでしょう。
真偽値の条件が`true`に評価される_まで_、ループを続けます。
言語によっては、あるコードを無限に実行させるために、`while true`のような構文が使われます。
Rubyでは、そのために`loop`ループがあります。
`loop`ループは単一の条件に依存しませんが、`return`や`break`キーワードを使えば終了させることができます。

前の演習の`#years_before_desired_balance`メソッドは、先ほど挙げた3つのループのどれを使っても書くことができました。

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

お気づきかもしれませんが、Rubyには他の言語にあるようなインクリメント演算子（`i++`）がありません。
代わりに、`i += 1`（これは`i = i + 1`と同じです）のような書き方を使うことができます。
