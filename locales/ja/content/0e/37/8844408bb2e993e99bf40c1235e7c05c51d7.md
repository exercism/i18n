# 参考資料

- [The Zig Programming Language Documentation][documentation]は、Zigが提供する言語機能の全体をよく見渡せる、優れた概説です。
- [The Zig Standard Library][std]は、Zigのコードがどのように書かれているかを学ぶのに良いリファレンスで、自分のコードに取り込める多くの関数が載っています。
- [Awesome Zig][awesome-zig]は、Zigのプロジェクトを厳選してまとめたリストです。
- irc.freenode.netの[#zig][irc]は、Zigの主要なIRCチャンネルです。
- [Stack Overflow][stack-overflow]では、すでに他の誰かが質問し、解決しているかもしれない問題について、コードスニペットや解答を見つけられます。
- [/r/Zig][reddit]は、Zigの主要なサブレディットです。
- [The Zig Programming Language Discord][discord-zig]は、主要な[Discord][discord]です。Zigコミュニティ全体とつながり、Zigに関するどんな問題でも素早く直接的な助けを得られる、絶好の場です。
- [The Zig SHOWTIME Newsletter][newsletter]では、新しいエピソードや重要なイベントのお知らせに加えて、興味深い新しいZigプロジェクトへのリンクも紹介しています。
