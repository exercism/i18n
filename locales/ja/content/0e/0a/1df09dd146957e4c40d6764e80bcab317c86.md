# はじめに

*タプル*は、いくつかの名前付きの値をひとつのオブジェクトにまとめたものです。他のプログラミング言語では、これをレコード、構造体、クラスなどと呼びます。それぞれのタプルクラスには決まった数の名前付きスロットがあり、Factorはそれらのゲッターとセッターを自動で生成します。

## タプルを定義する

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

各スロットは`{ name initial: default-value }`のように宣言します。`initial:`句を省略した場合のデフォルトは`f`です。

## タプルを生成する

最もシンプルなコンストラクターは`new`です。

```factor
point new .
! => T{ point }
```

`boa`（引数の順という意味）は、宣言した順にデータスタックからスロットを埋めていきます。

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

リテラル構文`T{ class { slot value } … }`を使うと、一部のスロットだけを設定したタプルを生成でき、出力も同じ形式になります。

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

スロットの値がデフォルトと一致する場合、プリンターはそれを省略します。

## スロットを読み取る

Factorは各スロットに対してゲッター`slot>>`を生成します。ゲッターは[`accessors`][accessors]にあります。

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## スロットを更新する

セッターは`>>slot`と書き、タプルをその場で*変更*します。

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

元のタプルを変更したくない場合は、先に`clone`します。

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot`は、現在の値を新しい値に対応づけるクオーテーションを受け取ります。

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x`も変更を加えるので、元のタプルを保ちたい場合は呼び出す前に`clone`します。
