# はじめに

`String`の個々の文字には、配列と同じように、角括弧（`[]`）を使ってアクセスできます。
ただし、文字列で使う[インデックス][string-indices]は整数ではなく、そのまま扱うことはできません。
代わりに、`startIndex`のように、すでにわかっている別のインデックスをもとに計算する必要があります。`startIndex`は、空でない文字列の先頭の文字の位置を指します。計算には、[`String`][string-docs]ライブラリと[`NSString`][nsstring-docs]ライブラリで用意されているメソッドを使います（`Foundation`モジュールをインポートすると、Swiftの文字列はNSStringのプロパティとメソッドをすべて使えるようになります）。

たとえば、次のような文字列があるとします。

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

"orange"の中の"g"を取り出したいときに`csv[21]`とは書けません。代わりに`String.Index`型の値を計算して、そのインデックスを渡す必要があります。
なお、これらのインデックスは、それ自体を人間が読んだり使ったりするためのものではありません。
人間が中身を知る必要がないため、_不透明なインデックス_と呼ばれます。

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

ただし、オフセットが有効なインデックスでない場合、つまり`startIndex`より前や`endIndex`より後のインデックスを返す場合には、エラーが発生してプログラムがクラッシュします。
これを防ぐには、上限となるインデックスを指定します。
こうするとオプショナルのインデックスが返り、それ以外の無効なインデックスに対してはnilを返します。

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

さらに、インデックスは文字列間で共有できません。
たとえば、上で計算した"orange"の中の"g"の`index`を使って、文字列`fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`にアクセスしようとすると、つまり`fam[index]`とすると、プログラムがクラッシュします。

こうなっている理由はいろいろありますが、突き詰めれば「Unicodeはやっかい」ということです。

一般的に、個々の文字にランダムアクセスしたいのであれば、`Array<Character>`のような別のデータ構造を使うことをおすすめします。

## 便利なメソッド

Swiftには、文字列の最初と最後の文字を取得する`first`メソッドと`last`メソッドがあります。
これらはオプショナルの文字を返すので、文字列が空の場合はnilを返します。

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

`prefix`メソッドと`suffix`メソッドを使うと、文字列の一部分を取り出せます。
これらのメソッドは整数を引数に取り、文字列の先頭または末尾からn文字分を含む部分文字列を返します。

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
