# 概要

Javaでは、[`null`リテラル][null-keyword]を使って、値が存在しないことを表します。

Javaの[プリミティブ型][primitive-data-types]はすべてデフォルト値を持っているため、`null`になることはありません。慣習として、`int`のように小文字で始まります。

[参照型][reference-data-types]はオブジェクトのメモリアドレスを持ち、`null`を値として持つことができます。こちらは一般的に`String`のように大文字で始まります。

プリミティブ型の変数に`null`を代入しようとすると、コンパイルエラーになります。その変数は常に、代入された型のデフォルト値を持っているからです。

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

参照型の変数に`null`を代入しても、参照型の変数は`null`を許容するため、コンパイルエラーにはなりません。

```java
//No error will occur as the String variable str is nullable
String str = null;
```

値が`null`である参照型の変数にアクセスするコードは、コンパイルは通りますが、実行時に`NullPointerException`がスローされます。

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

`null`であるのにオブジェクトが必要な参照型の変数にアクセスしようとすると、[`NullPointerException`がスローされます][null-pointer-exception]。

`null`の可能性がある値を安全に扱うには、その値を使う前に`null`かどうかを確認します。確認には、`==`や`!=`などの[等値演算子][equality-operators]を使います。

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
