# 説明

ニコマコス（西暦60〜120年）による正の整数の分類法に基づいて、ある数値が完全数、過剰数、不足数のどれにあたるかを判定してください。

ギリシャの数学者[ニコマコス][nicomachus]は、正の整数の分類法を考案しました。それぞれの数値は、その[アリコット和][aliquot-sum]に基づいて、[完全数](#perfect)・[過剰数](#abundant)・[不足数](#deficient)のいずれか1つにだけ分類されます。
_アリコット和_とは、ある数値の約数のうち、その数値自身を除いたものの和と定義されます。
例えば、`15`のアリコット和は`1 + 3 + 5 = 9`です。

## 完全数

数値がアリコット和と等しいとき、その数値は完全数です。
例えば、

- `6`は、`1 + 2 + 3 = 6`なので完全数です。
- `28`は、`1 + 2 + 4 + 7 + 14 = 28`なので完全数です。

## 過剰数

数値がアリコット和より小さいとき、その数値は過剰数です。
例えば、

- `12`は、`1 + 2 + 3 + 4 + 6 = 16`なので過剰数です。
- `24`は、`1 + 2 + 3 + 4 + 6 + 8 + 12 = 36`なので過剰数です。

## 不足数

数値がアリコット和より大きいとき、その数値は不足数です。
例えば、

- `8`は、`1 + 2 + 4 = 7`なので不足数です。
- 素数は不足数です。

## 課題

与えられた数値が[完全数](#perfect)かどうかを判定する方法を実装してください。
取り組んでいる言語によっては、与えられた数値が[過剰数](#abundant)か[不足数](#deficient)かどうかを判定する方法も実装する必要があるかもしれません。
