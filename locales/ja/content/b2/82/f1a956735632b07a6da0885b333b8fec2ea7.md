# 概要

Swiftでは、文字列を整数でインデックス指定することはできません（`string[3]`など）。
Swiftの文字列は長さの異なるUnicode文字で構成されているため、ある文字を見つけるには、それより前の文字を順にたどっていく必要があります。

特定の位置にある文字にアクセスするには、`String.Index`型のインデックスを計算する必要があります。
このインデックスが*不透明なインデックス*と呼ばれるのは、その内部構造が生の整数として直接操作されるのではなく、Swiftによって管理されているからです。

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
