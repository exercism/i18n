# はじめに

## letアサーション

Gleamで値のパターンマッチを行うときは、その型で取りうるすべての値にパターンが一致するようにしなければなりません。そうでないと、コードはコンパイルされません。

この関数は、リストが空の場合を処理していないため、コンパイルエラーになります。

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

Gleamのプログラムでは、ほとんどの場合、取りうるすべてのケースを処理したいと考えます。しかし、プロトタイプや簡単なスクリプトなどでは、正常系だけに注目し、それ以外のケースのコードは書きたくないこともあります。そこで登場するのが、Gleamの`let assert`です。

letアサーションを使うと、パターンをその型で取りうる値の一部にだけ一致させることができます。パターンが値に一致しない場合、プログラムはクラッシュします。`let assert`を使うと、上の関数は次のように書けます。

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleamのライブラリでは、プログラムをクラッシュさせる可能性があるため、letアサーションを決して使うべきではありません。代わりに`Result`型を使い、エラーの処理方法はアプリケーションのエンジニアに任せるべきです。
