# テスト

演習では、モックとテストのために[Pester][pester]フレームワークを使います。
テストはすべて、Pesterフレームワークの標準どおり、`[Exercise].tests.ps1`という名前のファイルにあります。
正しいディレクトリ、つまり`[Exercise].ps1`と`[Exercise].tests.ps1`があるディレクトリにいる必要があります。
PowerShellからは、次のように呼び出してテストを実行できます:

``` PowerShell
Invoke-Pester
```

これで、ディレクトリ内に見つかる`.tests.ps1`ファイルがすべて実行されます。

PowerShell以外のシェルを使っている場合は、次のように呼び出してテストを実行できます:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Visual Studio Codeでテストを実行する

Visual Studio Codeに[PowerShell拡張機能][extension]がインストールされていることを確認してください。

Visual Studio Codeでは、いくつかの方法でテストを実行できます:

- Debugメニューから`.Tests.ps1`スクリプトを実行する。キーボードショートカットは`F5`または`Shift + F5`です
- エディター上で、テストコードの`Describe`キーワードの上にある「Run Tests」リンクをクリックする
- Pesterフレームワークを実行するタスクを構成する

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
