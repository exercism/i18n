# 指示の補足

## 出力形式

生徒の植物を、カンマと空白で区切った、null終端の文字列として出力します。

## レジスタ

| レジスタ | 用途 | 型 | 説明 |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力 | アドレス | 庭の図 |
| `$a1`    | 入力 | アドレス | 生徒の名前 |
| `$a2`    | 入力/出力 | アドレス | null終端の出力文字列 |
| `$t0-9`  | 一時 | 任意 | 一時的な保存に使います |
