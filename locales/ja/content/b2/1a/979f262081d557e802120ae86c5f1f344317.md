# 説明

あなたはホテルのレストランのメートル・ドテルです。
今日用意されている席の数、予約の数、そして現在席を待っている「飛び込み」のお客様に応じて、ダイニングルームの席の割り当てを管理するのがあなたの仕事です。
この演習では、席は最初に見つかった空いている席から順に割り当てます。


この演習では、ダイニングルームの編成に関する6つの課題に取り組みます。


## 1. 今日の座席表を作る

今日ダイニングルームに用意する席の数を表すサイズ引数を受け取る`new_seating_chart(<size=22>)`関数を定義します。
`size`が指定されていない場合、この関数は22席の座席表を返します。
席の値には、お客様に割り当て可能であることを示すプレースホルダーとして`None`を設定します。


## 2. 予約を配置する

お客様の名前のリストを表す1つの引数を受け取る`arrange_reservations(<guest_names>)`関数を定義します。
これは、今日ダイニングルームに席を予約している人数を表します。


この関数は、既定のサイズ（22席）の座席表の`dict`を返し、予約リストに現れる順にお客様を席に割り当てます。
割り当てられていない席はすべて`None`にします。
お客様がいない場合は、すべての席が`None`のプレースホルダーになっている「空の」座席表を返します。


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. 「空いている」席をすべて見つける

1つの引数（_座席表の辞書_）を受け取り、現在待っているお客様が利用できる席番号の`list`を返す`find_all_available_seats(<seats>)`関数を定義します。
席が空の場合、辞書内ではその値が`None`になります。埋まっている席にはお客様の名前が入ります。


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. 現在の空席数

既存の予約の`dict`を1つの引数として受け取る`current_empty_seat_capacity(<seats>)`関数を定義します。
この関数は、空いている席の合計数を返します。

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. 待ってもらうべきか

2つの引数を受け取る`accommodate_waiting_guests(<seats>, <guests>)`関数を定義します。
1つ目の引数は座席表の`dict`です。
2つ目の引数は、予告なく「飛び込み」で来たお客様の`list`です。
まず、いくつ席が空いているかを調べ、現時点で予告なしに来たお客様をそもそも席に案内できるかどうかを判断する必要があります。

席が足りない場合は、座席表の`dict`を変更せずにそのまま返します。

席_が_空いている場合は、お客様を座席表の席に割り当て、更新した座席表を返します。
**ヒント:** 計算には、前に定義した関数を利用できます。


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. 席を空ける

2つの引数を受け取る`empty_seats(<seats>, <seat_numbers>)`関数を定義します。
1つ目の引数は座席表の辞書です。
2つ目の引数は、「空ける」、つまり席番号の値を`None`にする必要がある席番号のリストです。

「空ける」席の値を更新したあとの席の`dict`を返します。

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
