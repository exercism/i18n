# 説明

この演習では、電話番号を分析します。

実装する機能は2つあります。

ルーチンに渡される電話番号は、必ずNNN-NNN-NNNNの形式（たとえば212-515-9876）であり、nullになることはありません。

## 1. 電話番号を分析する

分析では、3つのデータを返します。

1. その番号がニューヨークの市外局番、つまり最初の3桁が212であるかどうかを示す値
2. 1から数えて5桁目から7桁目に、プレフィックスコードとして555を持つ偽の番号かどうかを示す値
3. 番号の最後の4桁

（静的）メソッド`PhoneNumber.Analyze()`を実装して、電話番号の情報を生成します。

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. 電話番号が偽のプレフィックスコード（555）を持つかどうかを検出する

タスク1で生成した電話番号の情報を使って、その電話番号が偽のものかどうかを検出する（静的）メソッド`PhoneNumber.IsFake()`を実装します。

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
