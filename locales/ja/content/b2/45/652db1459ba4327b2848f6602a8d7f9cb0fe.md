# はじめに

Pairs and Dictsのコンセプトでは、Juliaの辞書型の基本を扱いました。

`Dict`は重要でよく使われるコレクション型なので、それを操作する関数も数多く用意されています。

## 項目を取り出す

項目を取り出すもっとも簡単な方法は、キーを使うことです（多くの言語でも同じです）。
ただし、存在しないキーを指定すると`KeyError`になります。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

取り出す前にキーの存在を確認することもできます（`haskey(d, 4)`のような関数を使います）が、存在しないキーに対して既定値を返すようにしておくと便利なことがあります。

そのために、`get()`関数と、辞書を書き換える版である`get!()`があります。
この2つは、存在しないキーを`Dict`に追加するかどうかが異なります。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

以前のコンセプトで見たように、`delete!()`はキーを指定して項目を削除します。
これは、`pop!()`関数を使うと、値を取り出す処理と組み合わせられます。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 繰り返し

`Dict`を繰り返し処理すると、既定では`key => value`のペアが返されます。
それぞれの要素には、おなじみの`.first`と`.second`でアクセスできます。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

キーだけ、あるいは値だけを使いたいこともよくありますが、それは簡単です。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## マージ

2つの`Dict`を組み合わせると便利なことがありますが、複数の`Dict`に同じキーが存在する場合にどう扱うかをはっきりさせておく必要があります。

`merge()`と`merge!()`関数は、渡された任意の数の`Dict`を左から右へと組み合わせます。

すでに存在するキーの値はそのまま上書きされるので、もっとも右にある`Dict`が「勝ち」ます。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()`と`mergewith!()`関数では、第1引数に関数を渡して、キーが重複したときのマージ方法を定義できます。
足し算はわかりやすい例です。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

`mergewith`系の関数は、高階関数が活きる良い例であることに注目してください。
