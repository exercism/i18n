# 説明の補足

グリッドの各行は、1つのワードで表します。

例えば、次のようになります。

```
    0 1 0
    1 0 0
    1 1 0
```

これは、次のように表されます。

```
0x2
0x4
0x6
```

グリッドの列数は最大32です。

## レジスタ

| レジスタ | 用途     | 型      | 説明                        |
| -------- | -------- | ------- | --------------------------- |
| `$a0`    | 入力     | 整数    | 行数                        |
| `$a1`    | 入力     | 整数    | 列数                        |
| `$a2`    | 入力     | アドレス | 現在の世代のグリッド        |
| `$a3`    | 入力/出力 | アドレス | 次の世代のグリッド          |
| `$t0-9`  | 一時使用 | 任意    | 一時的な保存に使用          |
