# 指示

工場で働いていると、社員のバッジに印刷するメッセージを作る必要が出てきます。そこで、この関数をJavaScriptで実装することにしましょう。

バッジには、社員の`id`、社員の`name`、そしてその社員が働いている部署が必要です。

## 1. バッジに印刷するテキストを作成する

`printBadge`という名前の関数を実装して、バッジに印刷するテキストを返すようにしましょう。

社員の名前は必ず渡されますが、社員の`id`番号と部署名は`null`の場合があります。`id`番号が渡された場合は、角括弧で囲みます（例：`[20]`）。

オーナーのバッジには、`id`と`department`はありません。

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
