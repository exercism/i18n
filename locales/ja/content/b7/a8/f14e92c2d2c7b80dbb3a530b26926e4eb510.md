# 出力

Cairoでは、メッセージや値をコンソールに出力できます。それにより、プログラムのデバッグや、実行中に情報を伝えるのが簡単になります。

Cairoの出力の仕組みは、多様な場面で使えるうえにわかりやすく、さまざまな型のデータをフォーマットして出力するための手段が用意されています。

## 出力の基本

Cairoには、テキストをコンソールに出力するための主要なマクロが2つあります。

- **`println!`**: 新しい行に出力します。
- **`print!`**: 改行を加えず、インラインで出力します。

どちらのマクロも、第一引数に`ByteArray`を取ります。単純な文字列でも、値を埋め込むプレースホルダーを含むフォーマット文字列でもかまいません。

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

上の例では、

- `{}`のプレースホルダーが、`x`と`y`の値に置き換わります。
- `println!`を使うと、出力が改行で終わります。

## 文字列のフォーマット

フォーマットした文字列を、すぐに出力せずに作っておきたいこともあるでしょう。

そんなときは`format!`マクロが役立ちます。

`println!`と似た働きをしますが、コンソールに出力する代わりに`ByteArray`を返します。

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

この例では、

- `format!`が`s1`、`s2`、`s3`を1つの文字列にまとめ、ダッシュ（`-`）で区切ります。
- できあがった文字列は、あとで再利用したり出力したりできます。

## カスタムデータ型の出力

既定では、Cairoが出力できるのは整数や文字列のような基本的な型だけです。

構造体のようなカスタム型を出力しようとすると、その型が`Display`トレイトや`Debug`トレイトを実装していないかぎりエラーになります。

### カスタムフォーマットに`Display`を使う

`Display`トレイトを使うと、カスタム型をどのように出力するかを定義できます。

例を見てみましょう。

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

この例では、

- `fmt`関数が、`Point`構造体を出力可能な文字列に変換する方法を定義しています。
- `write!`マクロが、フォーマットされた文字列を`Formatter`に追加します。

### `Debug`を使ったデバッグ

デバッグのために、Cairoには`Debug`トレイトが用意されています。

ほとんどの型では自動で導出できるので、構造体の内部の詳細を手早く簡単に出力できます。

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

この例では、

- `#[derive(Debug)]`が、`Debug`トレイトの実装を自動で生成します。
- `{:?}`プレースホルダーは、フォーマットに`Debug`トレイトを使うよう`println!`に指示します。

## 16進数での出力

Cairoでは、`{:x}`プレースホルダーを使って整数を16進数で出力できます。

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

これは、低レベルのデータ表現を扱うときに特に役立ちます。
