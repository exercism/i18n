# はじめに

## デフォルト引数値

[デフォルト引数値][default-parameter-values]は、関数のどの仮引数に対しても指定できます。指定するには、仮引数リストの中で、その仮引数の型注釈のあとに値を代入します。デフォルト引数値が指定されていれば、関数を呼び出す側はその仮引数を省略でき、その場合はデフォルト値が使われます。

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## 可変長引数

[可変長引数][variadic-parameters]を使うと、1つの仮引数に対して、指定した型の値を0個以上受け取れるようになります。
可変長引数は、仮引数の型注釈のあとに3つのドット（`...`）を付けて定義します。

関数の本体では、Swiftはこれらの値を、指定した型の配列として利用できるようにします。

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
可変長引数のあとにさらに仮引数を続ける場合、可変長引数に続く最初の仮引数には、**必ず**明示的な引数ラベルを付けなければなりません。そうすることで、Swiftは可変長の引数リストがどこで終わるのかを判断できます。
~~~~


## in-out仮引数

関数の本体では、仮引数は変数ではなく定数として扱われます。仮引数の値を変更しようとすると、コンパイル時のエラーになります。
関数で仮引数の値を変更したい場合は、[_in-out仮引数_][in-out-parameters]を使って、この可変性を明示する必要があります。

in-out仮引数を使うには、次の3つの点を押さえておく必要があります。

1. 関数定義では、仮引数の型注釈で`:`と型名のあいだにキーワード`inout`を書いて、in-out仮引数であることを明示しなければなりません。
2. in-out仮引数に渡す値は、定数ではなく変数として宣言されている必要があります。同様に、リテラルを渡すこともできません。
3. 関数を呼び出すときは、変数名の前に`&`を付けて、変更可能であることを明示する必要があります。

こうすると、関数はin-out仮引数の内部コピーを作り、関数の本体で指示されたとおりにそれを変更し、関数が戻るときに、変更後の値を、渡された変数へコピーし直します。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
in-out仮引数については、ほかにもいくつか知っておきたいルールがあります。

1  in-out仮引数をもつ関数の内部では、in-out仮引数として渡された変数を参照することはできません。
2. 同じ関数の中で、同じ変数を複数のin-out仮引数として渡すことはできません。
   たとえば、`inoutFunc(&mutVar, &mutVar)`はコンパイラエラーになります。
~~~~

## 入れ子の関数

関数は、[ほかの関数の内部][nested-functions]で定義できます。
これはよく、ヘルパー関数を作るのに使われます。ヘルパー関数は、それを包む関数の中でしか役に立たないので、外側の名前空間を汚さずに済みます。

こうした関数は、通常の関数と同じように定義して呼び出しますが、それを包む関数の外からは見えません。

```swift
func makeNumber(_ number: Int) -> Int {
  func double(_ x: Int) -> Int { 2 * x }
  func add(_ x: Int) -> Int { x + 1 }

  return number.isMultiple(of: 2) ? add(double(number)) : double(number)
}

makeNumber(3)
// Returns 6
makeNumber(4)
// Returns 9
```
