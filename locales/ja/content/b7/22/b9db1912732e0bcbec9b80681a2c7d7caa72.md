# はじめに

## `for`ループ

`for`文は、コードのブロックを繰り返し実行します。
最初の行で、そのブロックを何回繰り返すかを制御します。

```go
for init; condition; post {
    // loop body
}
```

- **init**文は、最初の繰り返しの前に一度だけ実行されます。ループで使うカウンター変数を宣言して初期化するのが一般的です。
- **condition**は、各繰り返しの前に評価される真偽値の式です。これが`false`と評価されると、ループは止まります。
- **post**文は、各繰り返しが終わるたびに実行されます。カウンターの更新に使えます。

`init; condition; post`を括弧（`()`）で囲まないでください。
ただし、ループ本体を囲む波括弧（`{ }`）は常に必要です。

このループは、`i`を`1`で始め、`i`の現在の値を出力してから次の繰り返しに向けて値を増やし、`i`が`10`になった時点で止まります。

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
