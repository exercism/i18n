# 数値型

Crystalには、さまざまな用途に応じた多様な数値型があります。たとえば、ある型は別の型よりも高速ですが、扱える値の範囲は狭くなります。逆に、扱える値の範囲が広い型は、処理が遅くなります。

Crystalには、符号付き整数型と符号なし整数型の両方があります。符号付き整数型は正の値も負の値も扱えます。符号なし整数型は正の値しか扱えません。

## 符号付き整数型

Crystalの[符号付き整数型][int]は次のとおりです：

| 型       | サイズ（ビット） | 範囲                                                                                                        |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 to 127                                                                                                 |
| `Int16`  | 16          | -32_768 to 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 to 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 to 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 to 170_141_183_460_469_231_731_687_303_715_884_105_727 |

小さい型は、大きい型よりもメモリの使用量が少なく高速ですが、扱える値の範囲は狭くなります。

値が一定の範囲に収まるとわかっている場合は、メモリを節約しパフォーマンスを高めるために、できるだけ小さい型を使うのが最善です。

デフォルトの整数型は`Int32`です。特定の型の整数を宣言するには、`<number>_I <bit>`のように型名をサフィックスとして付けます。

```crystal
1_i8.class
# => Int8
```

`to_i<bit>`メソッドを使うと、異なる整数型の間で変換できます。`to_i`メソッドは、デフォルトの整数型である`Int32`に変換します。

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 符号なし整数型

Crystalの[符号なし整数][uint]型は次のとおりです：

`UInt8`、`UInt16`、`UInt32`、`UInt64`、`UInt128`

符号付き整数と符号なし整数の唯一の違いは、符号なし整数が正の値しか扱えないことです。特定の型の符号なし整数を宣言するには、`<number>_u<bit>`のように型名をサフィックスとして付けます。`to_u<bit>`メソッドを使うと、異なる符号なし整数型の間で変換できます。`to_u`メソッドは、デフォルトの符号なし整数型である`UInt32`に変換します。

```crystal
1_u8.to_u16.class
# => UInt16
```

## 浮動小数点型

Crystalの浮動小数点型は次のとおりです：

| 型        | サイズ（ビット） | 範囲                 |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 to 3.4E+38   |
| `Float64` | 64          | 2.3E-308 to 1.7E+308 |

[浮動小数点型][float]は2つあり、一方が他方よりも精度が高くなっています。

デフォルトの浮動小数点型は`Float64`です。

`to_f<bit>`メソッドを使うと、異なる浮動小数点型の間で変換できます。`to_f`メソッドは、デフォルトの浮動小数点型である`Float64`に変換します。

## 演算後の型

2つの数値の間で演算を行うと、結果はより精度の高いほうの数値の型になります。浮動小数点は整数よりも精度が高く、整数は符号なし整数よりも精度が高くなります。また、`Float64`は`Float32`よりも精度が高く、以下同様です。

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## さらに深く：符号なし整数と符号付き整数

~~~~exercism/advanced
内部では、符号なし整数と符号付き整数を分けているのは、符号付き整数が最初のビットを符号の格納に使う点です。符号は正か負のどちらかです。符号なし整数では、最初のビットも値の格納に使われます。そのため、符号付きの32ビット整数の最大値は2^31 - 1です。符号なしの32ビット整数の最大値は2^32 - 1です。

符号の有無についてもっと知りたい場合は、[Wikipedia](https://en.wikipedia.org/wiki/Signedness)で詳しく読むことができます。
~~~~
