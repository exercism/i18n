# 説明

この演習では、新しい乗り物を買う準備を助けるコードを書きます。

やることは3つあります。1つは、手が届く乗り物の価格を判断するため、1つは、運転免許が必要かどうかを判断するため、そしてもう1つは、登録料を計算するためのものです。

## 1. 与えられた乗り物の月々の支払いを払えるかどうかを計算する

町の乗り物販売店はどこも、5年間、金利0%のキャンペーンを行っていて、あなたはそれを利用したいと思っています。
検討している乗り物の名前、その価格、毎月の予算を受け取り、その乗り物を買えるかどうかを知らせる文字列を返す`canibuy(vehicle, price, monthly_budget)`関数を実装してください。月々の支払いが毎月の予算と10以内の差であれば、倹約を促す特別なメッセージを返します。

```julia-repl
julia> canibuy("1974 Ford Pinto", 516, 100)
"Yes! I'm getting a 1974 Ford Pinto."

julia> canibuy("2014 Bugatti Veyron", 562_500, 5000)
"Damn! No 2014 Bugatti Veryon for me."

julia> canibuy("2020 Gazelle Medeo", 3000, 50)
"I'll have to be frugal if I want a 2020 Gazelle Medeo."
```

~~~~exercism/note
Juliaの数値には、桁をまとめるために`_`を含めることができます。
たとえば、`562_500`は`562500`と同じです。
~~~~

## 2. 運転免許が必要かどうかを判断する

車を買うことにしたなら、運転免許が必要です。
自転車には免許は必要ありません。
乗り物の名前とその種類（`"car"`または`"bike"`のいずれか）を受け取り、免許が必要かどうかを返す`licence(vehicle, kind)`関数を実装してください。

```julia-repl
julia> licence("2014 Bugatti Veyron", "car")
"The 2014 Bugatti Veyron requires a licence to operate."

julia> licence("2020 Gazelle Medeo", "bike")
"The 2020 Gazelle Medeo requires no licence to operate."
```

## 3. 新しい乗り物の登録料を計算する

新しい乗り物の登録料は、次の計算式に基づきます。

- 自転車は登録する必要がありません。したがって、登録料は0€です。
- 10年以上前の車は、登録料は一律25€です。
- それより新しい車の場合は、次のとおりです。
  1. 基準額として、その車のメーカー標準小売価格（MSRP）か25&nbsp;000€の、どちらか大きいほうをとります。
  2. 車齢1年ごとに、基準額の10%を引きます。
  3. その値を100で割ります。これが支払う登録料です。

乗り物のMSRP、車齢（年数）、および乗り物の種類（`"car"`または`"bike"`のいずれか）を受け取り、上記の計算式に従ってその乗り物の登録料を返す`fee(msrp, age, kind)`関数を実装してください。

```julia-repl
julia> fee(562_500, 6, "car")
2250

julia> fee(25_000, 3, "car")
175

julia> fee(34_000, 30, "car")
25

julia> fee(3000, 0, "bike")
0
```
