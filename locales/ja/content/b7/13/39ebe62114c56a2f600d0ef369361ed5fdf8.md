# はじめに

## 数値と文字列

AWKはとても小さな言語で、基本的なデータ型もわずかしかありません。
このレッスンでは、数値と文字列について見ていきます。

### 数値

AWKの数値は、倍精度浮動小数点数として実装されています。
整数、小数、倍精度浮動小数点数の間に区別はありません。

AWKは8進数の定数（`0`で始まるもの）と16進数の定数（`0x`または`0X`で始まるもの）を理解します。

#### 数値の演算

標準的な算術演算子である`+`、`-`、`*`、`/`、`%`を使えます。
べき乗の演算子は`^`です。
組み込みの数値関数もいくつかあり、三角関数や乱数生成、数値を_x_と0の間で最も近い整数に切り捨てる`int(x)`などがあります。

### 文字列

AWKの文字列は、文字の並びです。
文字列の定数は、二重引用符で囲んで指定します。

#### 文字列の操作

文字列の操作は、連結の1つだけです。
連結には専用の演算子はありません。2つの文字列を並べるだけで、それらは連結されます。

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print`は**文**であって、関数ではありません。
`print`に括弧（`()`）は必要ありません。
~~~~

AWKには、文字列を操作するための関数が豊富に用意されています。
これらについては、トラックを進めていく中で詳しく紹介していきます。

### 数値と文字列の変換

数値と文字列を変換する明示的な演算子はありません。
AWKは、プログラムの文脈に応じてこれを暗黙的に行います。
そのため、入力フィールドの値を扱うのはとても簡単です。AWKはたいてい、こちらが望んだとおりに動いてくれます。

* `print x + y`は、`+`の数値演算のおかげで、`x`と`y`の変数の値を数値に変換します。
* `print x y`は、連結の操作によって、`x`と`y`の変数の値を文字列に変換します。

明示的に行いたい場合は、`0 + x`で_x_の数値としての表現が得られ、`"" x`で_x_の文字列としての表現が得られます。

#### 文字列から数値へ

AWKが文字列を数値に変換する方法は、戸惑うこともあるかもしれません。
簡単に言うと、AWKは文字列の先頭から「数値の文字」を読み進め、数値ではない文字が見つかったところで止まります。
いくつか例を挙げます。

* `"2.5"`は数値の`2.5`に変換されます。
* `"1e3"`は数値の`1000`に変換されます（指数表記）。
* `"456abc"`は数値の`456`に変換されます（`a`は数値ではないため、そこで変換が止まります）。
* `"abc789"`は数値の`0`に変換されます（文字列の**先頭**に数字がないためです）。
