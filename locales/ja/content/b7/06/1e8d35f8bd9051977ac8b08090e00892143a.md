# ゲッターとセッター

ゲッターとセッターは、オブジェクトのプロパティの値を読み書きするためのメソッドです。
Crystalにはマクロがあり、プロパティのゲッターとセッターを簡単に定義できます。
マクロはコンパイル時にコードを生成する仕組みで、これについては後ほどマクロのコンセプトで説明します。

Rubyでは、これらのメソッドは`attr_reader`、`attr_writer`、`attr_accessor`というメソッドを使って定義され、表面的にはCrystalの実装とよく似ています。
Crystalでは、これらは`getter`、`setter`、`property`というマクロとして定義されています。

## ゲッター

`getter`は、インスタンス変数の値を返すメソッドを定義するマクロです。
つまり、インスタンス変数にアクセスしたいときに、その前に`@`を書く必要がなくなります（メソッド内。ただし`initialize`は除く）。代わりに、`getter`マクロが定義したメソッドを呼び出せます。

`getter`マクロには、カンマで区切って複数のインスタンス変数を渡すことができます。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

このように、`getter`を使うと書くコードの量が減り、読みやすくなります。
また、RubyとCrystalは、Crystalでは`getter`マクロの引数として変数名とシンボルの両方を受け付けるという点で異なります。
シンボルについては、後ほどシンボルのコンセプトで説明します。

## セッター

`setter`は、インスタンス変数の値を設定するメソッドを定義するマクロです。
このマクロはそれほど頻繁には使われず、代わりに`property`マクロがよく使われます。
作成されるメソッドは`name_of_method=`のような形になります。`=`が付くことで、プロパティを設定できるようになります。

このメソッド定義は少し特殊で、メソッドが受け取る引数が`=`記号の後に来ます。
Crystalには、`+`メソッドなど、この構文を使う特殊なメソッドがほかにもいくつかあります。

`getter`マクロと同様に、`setter`を定義したあとでインスタンス変数の値を更新したいときは、`setter`マクロが定義したメソッドを呼び出せます。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## プロパティ

`property`は、インスタンス変数のゲッターとセッターの両方を定義するマクロです。

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
