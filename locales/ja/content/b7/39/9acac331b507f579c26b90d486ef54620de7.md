# はじめに

Haxeでは、例外は、コードの実行中に発生するエラーを安全に扱うための仕組みです。すべての例外には、エラーを説明するメッセージを含める必要があります。`throw`キーワードを使えば、例外をスローできます。

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

例外がスローされると、コードは、そのエラーを処理する担当の箇所を探します。見つからなければ、エラーメッセージを表示するとともに、プログラムの実行を停止します。

Haxeで例外を処理するには、`try-catch`ブロックを使います。このブロック文は、1つの`try`ブロックと1つ以上の`catch`ブロックで構成されます。`try`ブロックはコードの一部を実行してみます。一方、`catch`ブロックは、例外がスローされたときにそれをキャッチできるよう待ち構えていて、実行が止まらないようにします。`catch`ブロックが例外をキャッチすると、そのブロック内のすべてを実行します。

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch`ブロックの引数の型は省略します。
