# はじめに

[ペアと辞書][pairs-dicts]のコンセプトでは、Juliaの辞書型の基本を説明しました。

`Dict`は重要でよく使われるコレクション型なので、それを操作する関数もたくさんあります。

## 項目の取得

項目を取り出すもっとも簡単な方法は、多くの言語と同じで、キーを指定する方法です。
ただし、存在しないキーを指定すると`KeyError`になります。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

取り出す前にキーの有無を調べることもできます（`haskey(d, 4)`や`4 ∈ keys(d)`などを使います）が、存在しないキーに対して既定値をそのまま受け取れると便利なこともあります。

そのためにあるのが`get()`関数と、`Dict`を書き換える`get!()`です。
この2つは、存在しないキーを`Dict`に追加するかどうかが違います。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

以前のコンセプトで、`delete!()`を使うとキーを指定して項目を削除できることを説明しました。
これは、`pop!()`関数を使えば値を取り出す処理と組み合わせられます。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 繰り返し

`Dict`を繰り返し処理すると、既定では`key => value`のペアが得られます。
それぞれの要素には、いつもの`.first`と`.second`という名前でアクセスできます。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

キーだけ、または値だけを使いたいこともよくありますが、それも簡単です。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## マージ

2つの`Dict`を組み合わせると便利なことがありますが、複数の入力に同じキーがあるとき、それをどう扱うかをはっきりさせておく必要があります。

`merge()`と`merge!()`は、渡された任意の数の`Dict`を左から右へと組み合わせます。

すでにあるキーの値はそのまま上書きされるので、いちばん右の`Dict`が「勝ち」ます。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()`と`mergewith!()`では、第一引数に関数を渡して、重複したキーをどのようにマージするかを決められます。
足し算はその簡単な例です。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

2つのベクトルをつなげるのも、マージのときによく使われる操作です。
そのためにJuliaでは`vcat()`関数を使います。理由は[`Multi Dimensional Arrays`][multidim]のコンセプトで説明しています。

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

なお、`mergewith`系の関数は、[高階関数][hof]が活きているよい例です。

複数の[`Set`][sets]をまとめるときに使うマージ関数は`union`です。
