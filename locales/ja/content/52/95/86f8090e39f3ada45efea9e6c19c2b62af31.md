# 条件分岐

Rubyには、制御フロー式と呼ばれるものがあります。これはプログラムの実行の流れを制御するために使い、真または偽の値を受け取ります。
真または偽の値を作るために使える演算子もあり、これらは[比較演算子][comparison-operators]と呼ばれます。

コードを実行するかしないかを制御する、主な制御式が2つあります。これは、どの分岐が実行されるかを決めるもの、と言い換えてもいいでしょう。

その2つが、`if`と`unless`式です。

## 比較演算子

[比較演算子][comparison-operators]は、値を比較して`true`または`false`を返すために使います。
次の演算子は、同じ型の2つの値を比較する必要があります。
値の型が同じでない場合、コンパイラーがエラーを出します。
演算子の一覧と、`true`になる例を挙げます。

| メソッド | 説明           | 例 |
| ------ | --------------------- | ------- |
| <      | より小さい             | 4 < 5   |
| <=     | 以下    | 4 <= 4  |
| >      | より大きい          | 3 > 1   |
| >=     | 以上 | 2 >= 2  |

等しい・等しくないの演算子は、ここまでに挙げた演算子とは違い、どんな型の値でも比較できます。
`==`演算子は、2つの値が等しいかどうかを調べます。値の型の確認も含まれます。
`!=`も同じように動きますが、値が等しくない場合は`true`を、等しい場合は`false`を返します。
等しい・等しくないの演算子の一覧と、`true`になる例を挙げます。

| メソッド | 説明  | 例 |
| ------ | ------------ | ------- |
| ==     | 等しい        | 4 == 4  |
| !=     | 等しくない    | 5 != 4  |

## `if`文

[`if`][if]文は、与えられた条件が真か偽かを調べるために使います。
条件が真であれば、`if`文の中のコードが実行されます。
`if`文は`end`キーワードで終わります。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless`文

`unless`文は`if`文とよく似た動きをしますが、条件が偽の場合に`unless`文の中のコードを実行します。

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else`文

`else`文は、`if`文と組み合わせて使うことができます。
`else`文は、`if`の分岐が実行されなかった場合に実行されます。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## 「連鎖する`if`」文

`elsif`文は、`if`文と組み合わせて使うことができます。
`elsif`文は、`if`の分岐が実行されず、かつ`elsif`文の条件が真の場合に実行されます。
`elsif`文はつなげて書くことができ、最初に真になった条件が実行されます。
`if`文の最後に`else`文を置くこともでき、それまでのどの条件も真にならなかった場合に実行されます。

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
