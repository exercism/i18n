# 概要

`Option`型は、値が存在するかもしれないし、存在しないかもしれない場合を扱うための、F#言語の仕組みです。他の言語でそのような値を扱う際によく使われる`null`に代わる、型安全な方法を提供します。F#の標準ライブラリの多くの関数で使われているため、標準ライブラリを効果的に活用するには`Option`を理解することが欠かせません。

## `Option`型を使うメリット

* __コンパイル時の安全性__: 値の有無を型システムで明示することで、コンパイラーは「値がない」ケースを必ず処理させることができ、nullによって起こりうる多くのバグを防げます。

* __実行時の安全性__: F#は`null`の代わりに`None`で値の不在を表すため、`NullReferenceException`が発生することはありません。

* __明示的な処理を強制する__: 型システム上、`Some value`と`None`の両方のケースをコードで明示的に処理することが求められるため、コードはより堅牢で予測しやすくなります。

* __パターンマッチと組み合わせられる__: `Option`はF#のパターンマッチと自然に組み合わせることができ、値が存在する場合にそれを分解して扱ったり、存在しない場合に別の処理を行ったりする、すっきりとした安全な方法を提供します。

## 使い方

`Option`型はジェネリック型（基底となる型を持つ型）です。  
`Option`の値は、何らかの具体的な値を表す`Some value`か、値がないことを表す`None`のどちらかです。

次の関数は、`Option`の値を作成する方法を示しています。

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`は、`Option<T>`に相当する後置構文です。この2つの構文は同じように使えます。
ただし、F#スタイルガイドによれば、Option型には後置記法のほうが推奨されています（[F#スタイルガイドの型と型注釈の書式設定に関するセクション](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)を参照）。
~~~~

`Option`の典型的な使い道は、検索関数です。
たとえば、`List.tryFind`関数は、要素がリスト内にあれば`Some index`を返し（`index`はリスト内で探している値の位置です）、リスト内になければ`None`を返します。

## `Option`の値の中身を読む

`Option`の値を読み取る慣用的な方法は、次の例のようにパターンマッチを使うことです。

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## デフォルト値で`Option`をアンラップする

`Option`は、`Option.defaultValue`関数でデフォルト値を渡すことで「アンラップ」（含まれている型に変換）できます。
これは、値が`None`でないことを保証したいときに特に便利です。
たとえば、次のようになります。

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## `Option`モジュールのその他の関数

`Option`モジュールには、リスト、配列、シーケンスなどのコレクション型で利用できる関数に対応する関数も含まれています。たとえば、`Option.map`、`Option.iter`、`Option.forall`、`Option.count`などです。
これらの関数を使うと、`Option`を0個または1個の要素を持つコレクションのように扱うことができます。
