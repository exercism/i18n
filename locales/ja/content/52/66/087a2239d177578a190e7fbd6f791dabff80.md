# 説明

地域の芸術センターでボランティアをしていて、正面入口の上には長い陶器タイルのモザイクが設置されようとしています。デザインチームは、この作品を**行ごとに**設計しました。各行はタイルの色の配列で、モザイク全体は行の配列です。

ボランティアがタイルを切ったり、置いたり、並べ替えたりするなか、設計の一部を組み立て、組み合わせ、調べるための、小さくて再利用できるワードを書いていきます。

## 1. タイル1枚だけの行

`tile-strip`は色を1つ受け取り、その色だけを持つ1要素の行を返すように定義しましょう。

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. タイル3枚の行

`row-of-three`は色を3つスタックから取り、3要素の行を返すように定義しましょう。

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. 行をまとめてタイルの平坦な配列にする

デザインチームは、モザイクのすべての行について色の合計を確認する必要があります。`combine-rows`は行の配列を受け取り、すべてのタイルを順番どおりに並べた1つのシーケンスを返すように定義しましょう。

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. 行を鏡写しにする

左右対称のパネルでは、チームは反対側に複製を置く前に行を鏡写しにします。`mirror-row`は行を逆順にして返すように定義しましょう。

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. この色は行のどこにある？

`tile-position`は行と色を受け取り、その行でその色を持つ最初のタイルのインデックス（0始まり）を返すように定義しましょう。その色がなければ、`f`を返します。

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. この行にその色は含まれている？

`has-colour?`は行と色を受け取り、その色が行のどこかにあれば`t`を、なければ`f`を返すように定義しましょう。

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
