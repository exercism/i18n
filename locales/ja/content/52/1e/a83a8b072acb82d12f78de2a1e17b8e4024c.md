# テスト

テストは`exercism test`または`eutest`で実行します。デフォルトではすべてのテストが実行されます。

## テストをスキップする

まずは、`t_<exercise>.e`の中で最初のテスト以外をすべてコメントアウトしてみるのがよいでしょう。

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

テストを1つずつ順番に進めていき、今のテストが通ったら次のテストのコメントを外します。すべてのテストが通れば、その演習は完了です。
