# 説明の補足

# 入力

この演習の入力は次のとおりです。

- `target`: 文字列（例：`'stone'`）で、_左の引数_になります。
- `candidates`: ボックス化された文字列の配列（例：`'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`）で、_右の引数_になります。

動詞は次のように呼び出されます。

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## 出力

動詞は、`target`のアナグラムである文字列を収めたボックスの_配列_を返します。アナグラムがなければ、結果は`empty`になります。
