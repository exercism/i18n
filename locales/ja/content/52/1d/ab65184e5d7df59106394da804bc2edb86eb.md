# 説明

この演習では、フリーランサーがプロジェクトマネージャーとやり取りするのを手助けするコードを書きます。いくつかのユーティリティを用意して、日額と月額をすばやく計算できるようにしましょう。割引が指定される場合もあります。

まず、フリーランサーとプロジェクトマネージャーの間で、いくつかのルールを決めておきます。

- 日額は、時給の8倍です。
- 1か月の請求対象日数は22日です。

場合によっては、フリーランサーが日額に割引を適用することもあります（たとえば、いちばん忠诚の高い顧客や非営利の顧客に対して）。

割引は、割合を表す小数として扱います。たとえば`25.0`（25%）です。

## 1. 時給から日額を計算する

引数として時給を受け取り、日額を計算する`dailyRateFrom`という関数を実装します。
契約では、1日は8時間が請求対象と定められています。

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

返される日額は`Double`でなければなりません。

## 2. 時給と割引から月額を計算する

割引後の月額を計算する`monthlyRateFrom`関数を実装します。
引数は2つ、時給と割引率（パーセント）です。


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

返される月額は、最も近い整数に切り上げる（天井関数を使う）必要があります。

## 3. 予算、時給、割引から、まるまる働ける営業日数を計算する

予算、時給、割引を受け取り、それが丸1日分の仕事を何日まかなえるかを計算する`workdaysIn`関数を実装します。

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
返される日数は、次の整数に切り捨てる（床関数を使う）必要があります。
