# はじめに

ループは、ある処理を繰り返し実行するために使います。
よく使われるのは、`while loop`（回数が決まっていない繰り返し）と`for loop`（回数が決まっている、つまりカウントする繰り返し）の2種類です。
`for each`ループというものもあり、これは後の概念で登場します。

## 基本的な構文

`for loop`は、ヘッダーと、波括弧で囲まれたループ本体を含むコードブロックからできています。
ヘッダーは、セミコロン`;`で区切られた3つの要素からなります。init-statement、condition、そしてもう1つの式です。
それぞれは空でもかまいません。

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- **init**の要素は、ループが始まる前に1度だけ実行されるコードです。
- **condition**の要素は、真偽値に評価され、ループをいつ止めるかを制御する式でなければなりません。
この条件がtrueと評価されるかぎり、ループ内のコードが実行されます。
この式がfalseと評価された時点で、ループはそれ以上繰り返されません。
- **expression**の要素は、各繰り返しの最後に実行されるコードです。

`while loop`は、条件のチェックがtrueであるかぎり本体を実行します。
次のコードは、forループをwhileループに書き換える方法を示しています。

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## 補足: インクリメントとデクリメント

ループを扱っていると、カウンター変数に1を足したり1を引いたりすることがよくあります。
これがあまりに一般的なので、この操作には専用の演算子`++`と`--`があります。

これらには前置と後置の2つの形があります。
前置は文の中で使う前に変数を変化させ、後置は使った後に変化させます。
ほとんどの場面では、前置のほうを使いたくなるでしょう。

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## `for`ループの例

initの要素では通常カウンター変数を用意し、conditionではループを続けるか止めるかをチェックし、postの要素では通常、各繰り返しの最後にカウンターを増やします。

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

このループは`1`から`9`までの数値を合計します（`9`も含みます）。

## `break`と`continue`

ループ本体の中では、`break`キーワードを使ってループの実行を完全に止めることができます。

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

これに対して、`continue`キーワードは現在の繰り返しの実行だけを止め、次の繰り返しへ進みます。

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> 補足: `break`と`continue`の使用を最小限にするか、まったく避けたほうが、ループの流れを理解しやすくなることがほとんどです。
