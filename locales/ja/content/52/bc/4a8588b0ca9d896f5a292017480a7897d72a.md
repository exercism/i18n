# 説明

カードゲームのSpellbound Steelでは、warrior、mage、rogueといったキャラクターカードか、fireball、ice storm、lightning boltといった呪文カードのどちらかが入ったデッキを使います。ゲームには2人から4人が参加し、よりパワーレベルの高いカードを出して他のプレイヤーを倒すことが目標です。

カードのパワーレベルを計算したり、並べ替えたり、比べたりするいろいろなメソッドを作って、ゲームで優位に立ちましょう。

## 1. デッキからカードを探す

カードがデッキに入っているかどうか、わからないことがあります。そこで、探している種類のカードがデッキのどこにあるのか、最初の1枚の位置を教えてくれるメソッドがあると便利です。カードがデッキにないときは、それもわかるようにしたいところです。

`SpellboundSteel.find_card?`というメソッドを実装します。このメソッドは、`String`のカードの`Array`と、探す`String`のカードを入力として受け取ります。探しているカードと一致する、デッキの中で最初のカードのインデックスを返します。カードがデッキにない場合は、`nil`を返します。

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. カード名の各単語の先頭を大文字にする

カードを読みやすくするために、カード名の各単語の先頭の文字を大文字にしたいと考えます。そうすれば、カードをプレイするときにカード名がすぐに見分けられます。

`SpellboundSteel.capitalize_cards`というメソッドを実装します。このメソッドは、`String`のカードの`Array`を入力として受け取り、各単語の先頭を大文字にしたカードを返します。

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. すべてのカードのパワーレベルを計算する

ゲームでは、すべてのカードのパワーレベルを計算することが大切です。各カードのパワーレベルは、次の表のとおりです。

| カードの種類 | パワーレベル |
|----------------|-------------|
| Warrior        | 10          |
| Mage           | 20          |
| Rogue          | 30          |
| Fireball       | 15          |
| Ice Storm      | 25          |
| Lightning Bolt | 35          |

`SpellboundSteel.calculate_power_level`というメソッドを実装します。このメソッドは、`String`のカードの`Array`を入力として受け取り、すべてのカードのパワーレベルの合計を返します。

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. カードをデコードする

ゲームには、呪いのカードと呼ばれるものがあります。これは、プレイした本人しかデコードできない隠しカードです。カードをデコードするには、カード名の2文字おきに文字を取り除きます。すると、カードの名前がわかります。

`SpellboundSteel.decode_card`というメソッドを実装します。このメソッドは`String`のカードを入力として受け取り、デコードしたカードを返します。

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
