# はじめに

## ループ

ループは、ある処理を繰り返し実行するために使います。
よく使われるのは、`while loop`（回数が決まっていないループ）と`for loop`（回数が決まっている、カウントするループ）の2つです。
さらに、あとで別の概念で登場する`for each`ループというものもあります。

### 一般的な構文

`for loop`は、ヘッダーと、ループの本体を波括弧で囲んだブロックから成ります。
ヘッダーは、セミコロン`;`で区切られた3つの要素から成ります。初期化文、条件、そしてもう1つの式です。
これらはそれぞれ空でもかまいません。

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- **init_statement**の要素は、ループが始まる前に一度だけ実行されるコードです。
- **condition**の要素は、`boolean`と評価される式で、ループをいつ止めるかを制御します。
  この条件が`true`と評価されるかぎり、ループ内のコードが実行されます。
  この式が`false`と評価されるとすぐに、ループの繰り返しはそれ以上実行されません。
- **expression**の要素は、繰り返しのたびに最後に実行されるコードです。

`while loop`は、**condition**のチェックが`true`であるかぎり、本体を実行します。
次のコードは、`for`を`while loop`に書き換える方法を示しています。

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### 補足：インクリメントとデクリメント

ループを扱っていると、繰り返しの回数を数えるカウンター変数に1を足したり、1を引いたりすることがよくあります。
これはあまりに一般的なので、インクリメントとデクリメントには専用の演算子`++`と`--`が用意されています。

これらには**前置**と**後置**の形があります。
前置は、文の中で変数を使う前に値を変え、後置は使ったあとに変えます。
ほとんどの場面では、前置を使いたくなるはずです。

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### `for`ループの例

_init component_はふつうカウンター変数を用意し、_condition_はループを続けるか止めるかを判定し、_post component_はふつう繰り返しのたびに最後にカウンターをインクリメントします。

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

このループは、`1`から`9`までの数（`9`を含む）を合計します。

### `break`と`continue`

ループ本体の中では、`break`キーワードを使ってループの実行を完全に止めることができます。

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

対照的に、`continue`キーワードは現在の繰り返しの実行だけを止め、次の繰り返しへ進みます。

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
`break`と`continue`の使用を最小限にするか、まったく避けたほうが、ループのロジックはたいてい理解しやすくなります。
どちらのキーワードもコードの一部を飛ばすため、処理を追うのが難しくなりがちです。
~~~~
