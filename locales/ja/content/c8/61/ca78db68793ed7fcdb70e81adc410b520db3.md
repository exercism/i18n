# 概要

F#で数値を扱ううえで重要な点の1つは、整数（小数点以下の桁がない数値）と浮動小数点数（小数点以下の桁が0以上ある数値）の違いです。

F#で最もよく使われる数値型は、`int`（32ビット整数）と`float`（64ビット浮動小数点数）です。

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

整数でも浮動小数点数でも、`_`を_桁区切り_として使えます。大きな数値を書くときに役立ちます。

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

算術演算には、標準の[算術演算子][arithmetic-operators]（`+`、`-`、`*`など）を使います。数値の比較には、標準の[比較演算子][comparison-operators]（`<`、`>=`など）のほか、等値演算子（`=`）や不等演算子（`<>`）も使えます。

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

数値型の間で変換するには、組み込みの[変換演算子][conversion-operators]を使う必要があります。これらの演算子は、変換先の型の名前がそのまま演算子名になっています。

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

型の間で変換するときは、いつも注意してください。値が変換先の型で表せない場合、その値は_オーバーフロー_します。
