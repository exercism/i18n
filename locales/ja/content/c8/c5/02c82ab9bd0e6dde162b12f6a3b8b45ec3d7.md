# `if`、`elseif`、`else`

`if`、`elseif`、`else`を使った条件文は、プログラムの制御フローの基本的な要素です。
`if`文は式を評価し、それが`true`であれば、そのコードの分岐を実行します。

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

式が真偽値でない場合、その値が真とみなされるかどうかが判定されます。
PHPでは、次の値は`false`と等しいとみなされます。

- 真偽値の`false`
- 整数の`0`
- 小数の`0.0`と`-0.0`
- 空の配列`[]`
- 空文字列`""`または数値文字列`"0"`
- `null`

それ以外の値はすべて真とみなされます。

## 複数の条件に対応する

`if`文に続けて、`elseif`と`else`を使って複数の条件をつなげることができます。

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

真と評価された条件は、1つだけ実行されます。
そのため、複数の条件が真と評価される可能性がある場合、書く順番が重要になります。

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
