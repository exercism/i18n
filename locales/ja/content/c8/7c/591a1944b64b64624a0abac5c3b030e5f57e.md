# はじめに

ループには大きく分けて2つの種類があります。

1. 条件が満たされるまで繰り返すループ。
2. コレクションの中の要素を1つずつ処理するループ。

どちらもJuliaで書くことができますが、2つ目のほうがよく使われるかもしれません。

## `while`ループ

繰り返す回数があらかじめわからないような問題には、Juliaの`while`ループが使えます。

基本の形はとてもシンプルです。

```julia
while condition
    do_something()
end
```

この場合、`condition`が`true`でなくなるまで、プログラムはループを回り続けます。

ループから途中で抜ける方法は2つあります。

- `break`を使うとループを抜け、ループの`end`の次の行から実行が続きます。
- `return x`は現在の関数の実行を終了し、戻り値`x`を呼び出し元に返します。

こうした方法があると、`while true ... end`で「無限」ループを作り、ループ本体の中で停止条件を見つけて`break`や`return`を実行する、という書き方が便利なこともあります。

## コレクションをループする

一番わかりやすい例は、範囲をループすることです。

何かを10回行いたいときは、次のように書きます。

```julia
for n in 1:10
    do_something(n)
end
```

現在の繰り返しがある条件を満たさないときは、`continue`で次の繰り返しへすぐに進むことができます。

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

もっと短く書くなら、`if`ブロックを`is_useless(n) && continue`に置き換えることもできます。

ほかにもさまざまなコレクションをループできます。配列の要素、文字列の文字、辞書のキーなどです。

ここまでの例では範囲`1:10`をループしていて、値がそのままループのインデックスにもなっています。

より一般的には、値だけでなくインデックスが必要になることもあります。
そういうときは`eachindex()`関数を使います。たとえば`for i in eachindex(my_array) ... end`のように書きます。
