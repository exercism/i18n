# 基本

Satherのプログラムは、**ルーチン**を入れる**クラス**でできています。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## クラス

クラス名は大文字で書き、単語の間はアンダースコアでつなぎます。`GREETER`、`STAGE_DIRECTIONS`のように書きます。ファイル名は通常、これを小文字にしたものに合わせます。`stage_directions.sa`のようにします。

ルーチンはすべてクラスの中にあります。クラスの外にコードはありません。

## ルーチン

答えを返すルーチンは、コロンのあとにその答えの種類を宣言します。

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR`はテキストの型です。引数を取らないルーチンは、括弧（`()`）を使わずに書き、呼び出します。

ルーチンは引数を取ることができ、名前のあとの括弧の中に書きます。

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return`は答えを返し、その場でルーチンを終了させるので、そのあとにある行はスキップされます。

## 呼び出し

クラスの外からは、クラス名、`::`、ルーチン名の順に書きます。

```sather
GREETER::hello
```

同じクラスの中からなら、クラス名は省略できます。あるルーチンから別のルーチンを使うときは、この書き方が普通です。

```sather
   greeting_again : STR is
      return hello;
   end;
```

## コメント

2つのダッシュで、その行の終わりまでのコメントが始まります。

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

慣習として、クラスはその名前を書いたコメントで終わります。ルーチンもループもクラスも`end;`で閉じるので、このコメントは、この`end;`がどれに属するかを示しています。

```sather
end; -- class GREETER
```

## セミコロン

文はセミコロンで終わります。ルーチンの最後の文のあとのセミコロンは省略できますが、毎回書いておけば、考えなくてよいことが1つ減ります。
