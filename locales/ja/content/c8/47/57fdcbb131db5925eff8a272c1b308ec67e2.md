# 説明

友人のLi Meiは、おいしいミックスフルーツジュースを売るジュースバーを営んでいます。よく店に通っていると、Factorのコードで彼女の暮らしをもう少し楽にできることに気づきます。

## 1. ジュースを混ぜるのにかかる時間を求める

Li Meiは、メニューのジュースを注文したお客さんに、どれくらい待てばよいかを前もって伝えるのが好きです。ジュースを混ぜるのにかかる時間はそれぞれ違うので、彼女は正確な数字を覚えるのに苦労しています。

- `"Pure Strawberry Joy"`は`0.5`分かかります。
- `"Energizer"`と`"Green Garden"`はそれぞれ`1.5`分かかります。
- `"Tropical Island"`は`3`分かかります。
- `"All or Nothing"`は`5`分かかります。
- その他の飲み物（特別メニューなど）は`2.5`分かかります。

`time-to-mix-juice`を定義して、スタックからジュース名を取り出し、その飲み物を混ぜるのにかかる分数を返すようにします。

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. ライムウェッジの在庫を補充する

Li Meiの作品の多くには、材料として、あるいは飾りとしてライムウェッジが使われています。そのため、朝シフトが始まるときには、その日のためにライムウェッジの入れ物をいっぱいにしておく必要があります。

`wedges-from-lime`を定義して、ライムのサイズを受け取り、そこから取れるウェッジの数を返すようにします。`"small"`のライムからは`6`個、`"medium"`からは`8`個、`"large"`からは`10`個です。

次に`limes-to-cut`を定義します。これは必要なウェッジの数`needed`と、`limes`の配列（切る順に並んだライムのサイズ）を受け取ります。ライムを順番に1つずつ切り、必要な数のウェッジが取れたか、ライムがなくなった時点で止めます。切る必要があったライムの数を返します。

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. キューの各注文を混ぜる時間を一覧にする

Li Meiは、お客さんが待っている注文を混ぜるのにどれくらいかかるかを把握するのが好きです。

`order-times`を定義して、注文の配列を受け取り、各注文を混ぜる時間を同じ順番で並べた配列を返すようにします。

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. シフトを終える

Li Meiはいつも15時まで働きます。その後は従業員のDmitryが引き継ぎます。Li Meiのシフトが終わる時点で、注文されたのにまだ用意されていない飲み物が残っていることがよくあります。Dmitryはその残ったジュースを用意します。

引き継ぎを楽にするために、`remaining-orders`を定義します。これはLi Meiのシフトに残っている`time-left`分の時間と、`orders`の配列（注文されたのにまだ用意されていないジュース）を受け取ります。Dmitryが引き継ぐ必要のある注文、つまりLi Meiがシフト終了前に手をつける時間のない注文を返します。

`time-left`は常に`0`より大きいです。注文は配列に並んでいる順に用意します。Li Meiは一度ジュースに手をつけたら、少し長く働くことになっても必ず最後まで仕上げます。すべての注文に手をつける時間があれば、空の配列を返します。

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
