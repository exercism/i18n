# 文字列のメソッド

`String`には、文字列を操作するためのメソッドがいくつか用意されています。これらのメソッドは文字列自体に対して呼び出し、1つの文字列に複数の操作を行うために連結して使われることがよくあります。

以下は、特によく使われるメソッドの一部の一覧です。メソッドの完全な一覧については、[`String`のAPIドキュメント][string-api]を参照してください。

## String#upcase & String#downcase

[`upcase`][upcase]メソッドは、すべての文字を大文字に変換した新しい文字列を返します。

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase]メソッドは、すべての文字を小文字に変換した新しい文字列を返します。

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

Crystalには、文字列の一部を置き換えるためのメソッドがあります。これらは[`sub`][sub]（_substitution_、置換）と[`gsub`][gsub]（_global substitution_、全体置換）と呼ばれます。

これらのメソッドは、第1引数に文字列、文字、または正規表現を、第2引数に文字列または文字を取ることができます。第1引数は置き換えられる文字列の一部で、第2引数は置き換え後の値です。`Char`と正規表現については、後のコンセプトで説明します。

`sub`メソッドは、第1引数が最初に現れる箇所を第2引数で置き換えます。

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub`メソッドは`sub`と同じように動作しますが、第1引数が現れるすべての箇所を第2引数で置き換えます。

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

chompとstripを使うと、文字列から不要な文字を削除できます。

[`chomp`][chomp]メソッドは、デフォルトで文字列の末尾から`\r`、`\n`、または`\r\n`を削除します。このメソッドを引数付きで呼び出すと、指定した値を文字列の末尾から削除します。ただし、その値が文字列の末尾に存在する場合に限ります。

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

デフォルトでは、[`strip`][strip]メソッドは文字列の先頭と末尾からすべての空白を削除します。このメソッドを引数付きで呼び出すと、その引数を文字列の先頭と末尾から削除します。ただし、その値が文字列の先頭または末尾に存在する場合に限ります。

```crystal
" hello ".strip
# => "hello"
```

## String#index

[`index`][index]メソッドを使うと、文字列内での文字のインデックスを調べることができます。`index`メソッドは、引数に`String`、`Char`、または正規表現を取ります。省略可能な第2引数で、検索を開始するインデックスを指定できます。`index`メソッドは、引数が最初に現れる位置のインデックスを返します。

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

[`delete_at`][delete_at]メソッドを使うと、文字列から1文字を削除できます。`delete_at`メソッドは引数にインデックスを取り、そのインデックスにある文字を削除します。

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

[`insert`][insert]メソッドを使うと、特定のインデックスに文字列を挿入できます。`insert`メソッドは、第1引数にインデックスを、第2引数に文字列を取ります。`insert`メソッドは、第2引数をそのインデックスに挿入した新しい文字列を返します。

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
