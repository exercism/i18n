# 説明

この演習では、プログラミング言語の配列を操作するいくつかの関数を実装します。

## 1. 空の言語配列を返す関数を定義します

引数を取らず、空の配列を返す`language_list`関数を定義します。

```php
<?php

language_list();
// => []
```

## 2. 任意の数の言語から配列を作成できるように関数を変更します

`language_list`関数を変更して、言語（文字列）を可変長引数として受け取れるようにします。受け取った言語を要素に持つ配列を返します。

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. 配列に言語を追加する関数を定義します

2つの引数、言語の配列と新しい言語を取る`add_to_language_list`関数を定義します。

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. 言語の配列から要素を削除する関数を定義します

言語の配列から最初の言語を削除する`prune_language_list`関数を定義します。

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. 配列の最初の要素を取得する関数を定義します

1つの引数（_言語の配列_）を取る`current_language`関数を定義します。配列の最初の言語を返します。配列には必ず1つ以上の要素があるものとします。

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. 配列に含まれる言語の数を返す関数を定義します

1つの引数（_言語の配列_）を取る`language_list_length`関数を定義します。配列に含まれる言語の数を返します。

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
