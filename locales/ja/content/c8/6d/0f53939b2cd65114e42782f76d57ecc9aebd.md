# 説明

Joshは新しいロールプレイングゲームを作っています。いくつかの仕組みの実装を手伝ってあげましょう。

## 1. ユニオン型を定義する

`String`と`Missing`のユニオン型を`StringOrMissing`という名前で定義します。これは後のコードで使えます。
`Int64`と`Nothing`のユニオン型を`IntOrNothing`という名前で定義します。これも後のコードで使えます。

## 2. Player複合型を実装する

Player複合型には4つのフィールドがあり、それぞれに型注釈とデフォルト値が必要です。
- `name`は`StringOrMissing`型で、デフォルト値は`missing`です。
- `level`は`Int64`型で、デフォルト値は`0`です。
- `health`は`Int64`型で、デフォルト値は`100`です。
- `mana`は`IntOrNothing`型で、デフォルト値は`nothing`です。

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. 自己紹介をする

`introduce`関数を実装します。

ステルス状態のプレイヤーは名前を隠していることがあり、その場合は`"Mighty Magician"`として紹介されます。
それ以外の場合は、そのプレイヤーの名前を使って紹介します。

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. incrementメソッドを実装する

`increment`ヘルパー関数には2つのメソッドがあり、それぞれ関数シグネチャが異なります。
それぞれの引数には、シグネチャを明確にするための型注釈が必要です。

名前用の`increment`メソッドは、プレイヤーの`name`を受け取ります。
- 名前が`missing`の場合は、`"The Great"`という称号を返します。
- それ以外の場合は、名前に`" the Great"`という称号が付け加えられます。

この`increment`メソッドは新しい名前を返します。

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

マナ用の`increment`メソッドは、プレイヤーの`mana`を受け取ります。
- プレイヤーのマナが`missing`の場合は、`50`を返します。
- それ以外の場合は、マナを`100`増やします。

この`increment`メソッドは更新後のマナを返します。

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. title関数を実装する

ゲームの最高レベルは`42`です。このレベルに到達したプレイヤーの功績をたたえるため、その名前に称号が付けられます。`title!`関数は、プレイヤーの名前を次のように更新します。

- プレイヤーのレベルが42の場合は、`increment`関数を使って名前が更新されます。
- それ以外の場合は、名前は変わりません。

どちらの場合でも、`title!`関数はプレイヤーの名前を返します。

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. revive関数を実装する

`revive!`関数は、プレイヤーのキャラクターが本当に死んでいるか（体力が`0`になったか）を確認します。

プレイヤーが死んでいる場合：
- プレイヤーは体力`100`で復活します。
- プレイヤーのマナは、`increment`関数を使って増やします。

プレイヤーが生きている場合は、何も起こりません。

`revive!`関数はプレイヤーを返します。

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
