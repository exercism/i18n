# はじめに

ベクターは1次元の配列です。異なる型の要素を入れることもできます。

## ベクターの作成

ベクターは、`vector`関数を使うか、リーダー構文の`#()`を使うことで作成できます。

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## 要素へのアクセス

ベクターの要素にアクセスするには`aref`を使います。インデックスは0から始まります。

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
