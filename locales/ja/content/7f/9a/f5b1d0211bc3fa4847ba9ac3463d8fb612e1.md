# 説明

サーカスのショーとは、演目を並べた順番のことです。演目ごとに中身はまったく違いますが、ショーを組み立てる人には、どの演目からも同じ2つの情報が必要です。

1つのファイルに複数のクラスを書くのは、この演習が初めてです。スタブには抽象クラスが用意してあるので、その下に残りを書いていきましょう。

## 1. 3つの演目

3つのクラスを書きましょう。それぞれが`$ACT`です。

| クラス | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "`のあとに高さ、そのあとに`"m"` | 8 |

`JUGGLING`と`TUMBLING`は引数なしで作ります。`TRAPEZE`は高さをメートルで渡して作ります。

```sather
#JUGGLING
#TRAPEZE(4)
```

つまり`#TRAPEZE(4).name`は`"Trapeze at 4m"`になります。

## 2. ショー

`CIRCUS_ACTS`クラスを書きましょう。3つのルーチンを持ち、どれも演目の順番を`ARRAY{$ACT}`として受け取ります。

**`total_minutes`**：ショー全体の所要時間です。

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**：演目の名前を`", "`でつないだものです。

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**：ショーの中でいちばん時間がかかる演目の名前です。同じ長さのものが2つあるときは、先に出てくるほうが選ばれます。演目のないショーには最長の演目がないので、答えは`""`になります。

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

3つのルーチンはどれも、演目がどの種類なのかを尋ねてはいけません。
