# 説明の補足

## トラック固有の説明

関数は、積と、因数の配列のオフセットおよび長さを返すことになっています。
因数は、メモリ上にi32のペアとして書き込まれるだけです。

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

1桁の回文積のうち最大のものでは、次のようになります。

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
