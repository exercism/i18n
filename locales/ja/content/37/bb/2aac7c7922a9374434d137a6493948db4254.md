# はじめに

Factorの各ソースファイルは、`IN:`で*ボキャブラリー*を宣言し、使うボキャブラリーがあれば`USING:`でインポートします。

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

ディレクトリの構成は、ドットで区切られたボキャブラリー名に対応しています。

- ボキャブラリー`my-vocab`は`my-vocab/my-vocab.factor`にあります
- ボキャブラリー`my-vocab.helpers`は`my-vocab/helpers/helpers.factor`にあります

Factorのボキャブラリーローダーは、`USING:`宣言を推移的にたどります。読み込んだファイルが別のボキャブラリーをインポートしていれば、そのボキャブラリーも自動的に読み込まれます。

大きなルーチンを2つのボキャブラリーに分けることもよくあります。小さくて再利用できるワードをまとめたヘルパーのボキャブラリーと、それをインポートして結果を組み立てるメインのボキャブラリーです。
