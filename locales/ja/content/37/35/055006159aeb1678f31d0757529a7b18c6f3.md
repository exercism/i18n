# 概要

[タプル][tuple]は、情報をまとめるためによく使われます。配列とは異なり、サイズが固定されており、異なるデータ型を保持できます。タプルは括弧（`()`）を使って作成し、関数から複数の値を返すのによく使われます。

```haskell
tuple = (1, "abc", False)
```

これは、たとえば2D空間の座標を保存したいときに便利です。その場合、タプルは常に2つの要素、x座標とy座標を持つことがわかります。

```haskell
coordinate = (3, 4)
```

## 要素へのアクセス

短いタプルを扱うことがよくあります。その場合、`fst`関数と`snd`関数を使って要素にアクセスできます。

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
