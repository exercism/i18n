# 文字列

Crystalには、テキストを表すために使われる[`String`][strings]という型があります。Crystalの文字列はUnicode文字の並びです。文字列はイミュータブルで、一度作成すると変更できません。つまり、文字列を変更するたびに新しい文字列が作成され、元の文字列は変更されません。

文字列を定義するには、ダブルクォート`"`を使います。

```crystal
"Hello World"
```

## 連結

2つの文字列を連結するには、`+`演算子を使います。`+`演算子は、2つの文字列を組み合わせた新しい文字列を返します。

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## 文字列と数値の変換

`to_i`メソッドは文字列を整数に変換します。また、`to_f`メソッドを使うと小数を返せます。文字列を数値に変換できない場合は、`ArgumentError`が発生します。

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

整数や小数は、`to_s`メソッドを使って文字列に変換できます。

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## 補間

補間は、文字列を組み合わせたり、式を文字列に埋め込んだりする便利な方法です。文字列を補間するには、`#`文字のあとに波括弧`{}`を書き、その中に式を入れます。

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystalは、式の結果を自動的に文字列に変換します。

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## サイズ

文字列の文字数を知りたいときは、`size`メソッドを使います。これは文字列の長さを整数で返します。文字列のサイズは文字列に保存されたプロパティなので、メソッドを呼び出すたびにサイズを計算する必要がなく、とても高速です。

```crystal
"Hello World".size
# => 11
```

## インデックス

インデックスとは、文字列から特定の文字を取得したいときに使うものです。`String`から文字を取得するには、おなじみの角括弧（`[]`）による記法を使います。

~~~~exercism/note
`[]`はStringのインスタンスメソッドとして実装されており、インデックスがそのメソッドの引数になります。
~~~~

Crystalでは、文字列の最初の文字がインデックス0になります。

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

文字列の末尾から文字を取得するには、文字列の長さから1を引くと最後の文字のインデックスになり、最後から2番目の文字なら長さから2を引く、というようにします。これにはもっと簡単な方法があり、負のインデックスを使うだけです。最後の文字はインデックス-1、最後から2番目の文字はインデックス-2、というようになります。

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### 部分文字列のテスト

Crystalは、インデックスを使うことで、文字列に部分文字列が含まれているかを調べられます。同じ角括弧記法を使いますが、インデックスの代わりに部分文字列を指定します。部分文字列が文字列の中に見つかればその部分文字列が返され、見つからなければ`NilAssertionError`が発生します。

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

部分文字列が見つかったかどうかを`Bool`の値で知りたい場合は、`includes?`メソッドを使います。

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## エスケープ

一部の文字は文字列の中に直接書けません。そのような場合は、エスケープシーケンスを使います。たとえば、文字列の中でダブルクォートを使いたいときは、ダブルクォートをエスケープする必要があります。`\`文字を使ってエスケープシーケンスを書き、そのあとにエスケープしたい文字を続けます。

Crystalの特殊文字は次のとおりです。

| 値       | 説明                          |
| -------- | ----------------------------- |
| `\a`     | アラート                      |
| `\b`     | バックスペース                |
| `\e`     | エスケープ                    |
| `\f`     | フォームフィード              |
| `\n`     | ラインフィード（改行）        |
| `\r`     | キャリッジリターン            |
| `\t`     | 水平タブ                      |
| `\v`     | 垂直タブ                      |
| `\\`     | バックスラッシュ              |
| `\'`     | シングルクォート              |
| `\"`     | ダブルクォート                |
| `\377`   | 8進数のASCII文字              |
| `\xFF`   | 16進数のASCII文字             |
| `\uFFFF` | 16進数のUnicode文字           |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## 複数行の文字列

複数行の文字列を書くには、1行の文字列と同じ構文を使いますが、文字列に含めたい行ごとに改行します。

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode]は、さまざまな文字体系のテキストをエンコードし、表現し、処理するための標準です。Unicodeは、文字、句読点、記号、絵文字を含む10万文字以上をサポートしています。

Crystalは文字列にUnicodeを使っているので、たとえば文字列に絵文字を入れることができます。

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

ときには、たとえばエディターやシステムで使えない文字を使いたいことがあります。その場合は、Unicodeエスケープシーケンスを使ってその文字を書くことができます。

```crystal
"\u{1F310}"
# => "🌐"
```
