# 説明

こんにちは、Agent Double-Null0111。

引き受けるかどうかはさておき、今回のミッションは、UMBRA（United Minions Being Really Awful）の本部に潜入し、彼らの最新の、本当にひどい計画の設計図を回収するための、2つのツールを書くことです。
このミッションを遂行するには、3つのツールが必要になります。

## 1. ID番号を生成する

ミニオンはそれぞれ一意な識別子を持っています。この識別子は毎日変わり、持っている秘密の数と、眠る時間の数によって決まります。
日（`Int`）を受け取り、その日の識別子を生成する関数を作る必要があります。
識別子を生成する関数は、2つの仮引数を受け取ります。

1. 持っている秘密の数
2. ミニオンが眠る時間の数

識別子は次のように計算します。

1. 持っている秘密の数と、眠る時間の数を掛けます。
2. その結果に、日（`Int`で表します）を足します。

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. 回収した秘密の計画を秘密のパスワードで保護する

秘密の計画を手に入れたら、パスワードを知っている人だけがそれを取り出せるように、計画を保護する必要があります。
そのためには、関数`protectSecret(secret: String, password: String) : (String) -> String`を実装する必要があります。
この関数は、パスワードの候補となる文字列を入力として受け取る、別の関数を返します。
入力されたパスワードが正しければ、新しい関数は隠された秘密を返します。パスワードが間違っていれば、関数は "Sorry. No hidden secrets here." を返します。

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. 秘密のパスワードを見つける

UMBRAの基地にはたくさんの部屋があり、それぞれ警備員が守っています。警備員は、秘密のパスワードを尋ねてきます。
秘密のパスワードは、部屋の番号によって決まります。
残念ながら、パスワードを計算するアルゴリズムは、半分しか分かっていません。
残りの半分は、ミニオンの1人に聞けば分かります。

次のものを受け取ってパスワードを返す、`getPassword`関数を実装する必要があります。

1. 部屋の番号
2. ミニオンの関数。そして、秘密のパスワードを返します

秘密のパスワードは、分かっているほうのアルゴリズムを表す別の関数を渡して、ミニオンの関数を呼び出すと得られます。
分かっているほうのアルゴリズムは、次のとおりです。

1. 2つの数値を受け取り、それらを足します。
2. その結果に部屋のIDを掛けます。

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
