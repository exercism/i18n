# はじめに

Goには、変数の値に空やnull、undefinedといった概念はありません。
初期値を明示せずに宣言された変数は、それぞれの型のゼロ値になります。

真偽値や数値型、文字列などのプリミティブ型のゼロ値は、それぞれ`false`、`0`、`""`です。

ゼロを意味する識別子`nil`は、ポインター、関数、インターフェース、スライス、チャネル、マップなど、より複雑な型のゼロ値です。

次の表に、Goの各型のゼロ値をまとめます。

| 型      | ゼロ値 |
| --------- | ---------- |
| 真偽値   | `false`    |
| 数値   | `0`        |
| 文字列    | `""`       |
| ポインター   | `nil`      |
| 関数  | `nil`      |
| インターフェース | `nil`      |
| スライス     | `nil`      |
| チャネル     | `nil`      |
| マップ     | `nil`      |

上の表に構造体の型がないことにお気づきかもしれません。
これは、構造体の型のゼロ値がそのフィールドによって決まるためです。
構造体は、そのすべてのフィールドがそれぞれのゼロ値になると、ゼロ値になります。
