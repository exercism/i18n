# 説明の補足

## ツリーの表示

この演習には、ツリーを見やすい形式で出力するための定義済みクラスメソッドがいくつか用意されています。
主な目的は、デバッグを助け、より分かりやすくすることです。
クラスの残りの部分を正しく実装すれば、ツリーが自動的に出力されるはずです。

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
