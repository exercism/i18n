# はじめに

Elixirのすべてのエラーは、_例外ビヘイビア_を実装しています。_Accessビヘイビア_と同じように、_例外ビヘイビア_は、ビヘイビアというソフトウェア契約を満たすためにモジュールが実装しなければならないコールバック関数を定義します。エラーを定義すると、次のような性質を持ちます。

- モジュールの名前が、エラーの名前になります。
- モジュールがエラー構造体を定義します。
- 構造体は`:message`フィールドを持ちます。
- モジュールは`raise/1`と`raise/2`で使うことができ、意図したエラーを発生させられます。

_例外ビヘイビア_は、`message/1`と`exception/1`という2つのコールバックも指定します。実装していない場合は、デフォルトの実装が使われます。`message/1`は、`raise`で呼び出されると、エラー構造体を読みやすいメッセージに変換します。`exception/1`は、`raise/2`で呼び出されると、メッセージに追加のコンテキストを加えることができます。

## 例外を定義する

エラーモジュールから例外を定義するには、`defexception`マクロを使います。

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## 例外を使う

定義したエラーは、組み込みのエラーと同じように、`raise/1`または`raise/2`を使って発生させることができます。

- `raise/1`は、モジュール名を指定して特定のエラーを発生させます。引数が文字列の場合は、その文字列をメッセージとする`RuntimeError`を発生させます。
- `raise/2`は、モジュール名を指定して特定のエラーを発生させ、属性の引数を受け取ります。この引数は、適切なメッセージを持つエラーを取得するために使われます。
