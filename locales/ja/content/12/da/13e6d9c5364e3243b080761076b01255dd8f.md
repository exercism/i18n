# タプル型

タプルは、Cairoにおける汎用性が高く効率的な複合データ型で、型の異なる複数の値を1つにまとめることができます。
タプルは固定長です。一度宣言すると、そのサイズを変更することはできません。

## タプルの作成

タプルを作るには、括弧（`()`）の中に、値をカンマで区切って並べます。
タプルの各位置にはそれぞれ決まった型があり、その型は互いに異なっていてもかまいません。

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

タプルには、データ型の異なる複数の値を入れられます。他のタプルを入れることもできます。
たとえば、次のようになります。

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

ここでは、`nested_tup`変数は2つのタプルを含むタプルです。タプルが要素として他のタプルを持てることがわかります。

## タプルの分解

タプルの中の個々の値にアクセスするには、パターンマッチングを使ってタプルを分解します。
こうすると、タプルはその構成要素に分かれます。

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## 宣言と分解を同時に行う

タプルの宣言と分解は、同時に行うこともできます。

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## ユニット型`()`

ユニット型は、Cairoにおける特別な型で、値は`()`の1つだけです。
要素を持たないタプルで表されます。
ユニット型のサイズは常にゼロで、コンパイルされたコードには存在しないことが保証されています。

Cairoでは、すべての式が値を返します。式が何も返さないときは、暗黙的に`()`を返します。
これは、値を返す必要があるものの、返すべき意味のある値がない関数で役立ちます。

## 名前付きタプル型の宣言

名前付きタプルを使うと、タプルに対してより説明的な型エイリアスを作ることができ、コードの可読性が上がります。

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

この例では、`Point`は符号なし32ビット整数のペアを表す名前付きタプル型で、コードの表現力が高まります。
