# 概要

[concept:csharp/enumerables]()は、[`foreach`ループ][foreach-statement]を使って繰り返し処理できます：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

`foreach`ループは、3つの部分から成ります：

1. 宣言：繰り返し処理で取り出した値を受け取る変数を定義します。この変数は、ループの中だけで使えます。
2. 対象となるオブジェクト：繰り返し処理できるオブジェクトです。
3. ループ本体。

## `for`ループと`foreach`ループの比較

ただし、一般的には、次の理由から`foreach`ループのほうが`for`ループよりも好まれます：

- `foreach`ループは、_すべて_の値を確実に繰り返し処理します。`for`ループでは、たとえば1つずれるミスによって要素を見落としやすくなります。
- `foreach`ループはより_宣言的_で、コードは_何を_したいのかを伝えます。一方、`for`ループは_どのように_行うのかを伝えます。
- `foreach`ループは間違いが起きにくいのに対し、`for`ループでは1つずれるミスが起こりがちです。
- `foreach`ループは、インデックスを使って要素にアクセスできないものも含め、あらゆるコレクション型で使えます。

`foreach`ループが_すべて_の値を繰り返し処理することを保証するために、コンパイラーは`foreach`ループの中でコレクションを更新することを許可しません：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`ループには、`foreach`ループにない利点もいくつかあります：

- 好きなインデックスから始めたり、そこで止めたりできます。
- 任意の（真偽値の）終了条件を使えます。
- ループ変数の増分を工夫することで、要素を飛ばせます。
- カウントダウンすることで、コレクションを後ろから前に処理できます。
- コレクションを扱わない場面でも`for`ループを使えます。
