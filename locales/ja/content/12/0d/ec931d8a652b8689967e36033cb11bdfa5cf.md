# はじめに

ここでは、JSONの構文とデータ型について、すでに知っていることを前提に進めます。

jqは、入ってきたJSONデータを_単一の式_（_フィルターのパイプライン_として書きます）に通すことで、望みどおりに変換されたデータを得ます。

<!-- prettier-ignore -->
~~~~exercism/note
`jq`言語は、`jq`_プログラム_によって実装されています。
このプログラムには、入力をどのように読み込み、出力をどのように表示するかを制御するための、便利なコマンドラインオプションがいくつか用意されています。

以下の例では、次のものが出てきます。

- `-n`または`--null-input`

    通常、`jq`プログラムには読み込むファイルを渡すか、入力にデータを送ります。
    `--null-input`オプションを使うと、入力をまったく与えずにJSONデータを生成できます。

- `-c`または`--compact-output`

    `jq`は、デフォルトで出力を整形して表示します。
    データがきれいに整形されていると、人間が読むのにとても便利です。
    しかし、機械には必要ありません。`--compact-output`オプションは、整形のための空白を取り除き、生成されるJSONのサイズを最小限にします。

- `-f filename`または`--from-file filename`

    `jq`プログラムをコマンドラインで指定する代わりに、`filename`から読み込みます。
    `sed`と`awk`も、同じ目的で`-f`オプションを使います。
    これは、練習用の演習のテストスクリプトで使われているのを見ることになります。

このレッスンの残りでは、`jq`_言語_に焦点を当てます。
~~~~

## フィルターとパイプ

**フィルター**は**式**とも呼ばれます。

_フィルター_は入力を受け取り、出力を生成します。
unixシェルで作業するときと同じように、_フィルター_同士をパイプ`|`でつなぐと、ある_フィルター_の出力を別のフィルターの入力に接続できます。

## 恒等フィルター：`.`

これは最も単純な_フィルター_です。
入力をそのまま出力に渡すだけです。

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## 配列

ここでは、**配列**を扱うための簡単な導入を行います。
この話題については、後でもっと詳しく扱います。

_配列_の要素には括弧（`[]`）でアクセスし、インデックスは0から始まります。

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

_フィルター_は、式を`[`と`]`で囲むことで_配列_を作れます。

- あらかじめ要素が決まっている場合：

  ```sh
  jq -n '[1, 2, 3]'
  ```

- 要素のストリームを集める場合：たとえば、
  `range`は数値のストリームを出力する関数です。

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  `[]`を使うと、式の結果が配列にまとめられます。

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## カンマは演算子

_カンマ_は、_配列_の要素を区切るだけの構文ではありません。
**カンマ**は、ストリームを連結する**演算子**です。

たとえば`[1, 2, 3]`は、_配列_のコンストラクター`[]`を使って、3つの式`1`、`2`、`3`を連結した結果をまとめる_フィルター_です。

上の`range(10; 70; 15)`にあるセミコロンに気づきましたか？
`jq`言語では_カンマ_に特別な役割があるため、複数の引数を取る関数では、引数を区切るのにセミコロンを使います。

## オブジェクト

**オブジェクト**の簡単な導入です。

多くのプログラミング言語と同様に、_オブジェクト_のプロパティにはドットでアクセスします。

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
_オブジェクト_にも括弧を使えますが、その場合は文字列リテラルに引用符が必要です。
これは、スペースを含むキーを扱うための方法のひとつです。

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

_オブジェクト_は`{}`と`key: value`のペアで作れます。
「単純な」文字列である_キー_には、引用符は必要ありません。

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

出力は次のとおりです。

```none
{
  "question": 54,
  "answer": 42
}
```

_キー_を_式_として扱うには、括弧で囲む必要があります（以下も上と同じ出力になります）。

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## パイプライン

たとえば、次の内容を含む`file.json`があるとします。

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

key2の_配列_の長さを計算してみましょう。

```sh
$ jq '.key2 | length' file.json
3
```

`.key2`という式の出力を、`length`への入力として_パイプで渡して_います。`length`は当然ながら、_配列_の要素数を出力します。

## フィルターは入力を無視できる

この例では、入力のJSONデータは無視され、出力に影響しません。

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## フィルターはデータのストリームを出力できる

_フィルター_は複数の値を出力できます。
たとえば、`.[]`という_フィルター_は、_配列_の各要素をそれぞれ別の値として出力します。

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

このような_フィルター_を別のフィルターにパイプすると、2番目の_フィルター_が**_値ごとに_**実行されます。

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

これは、暗黙の繰り返しのようなものです。
このテクニックを一度理解すると、非常に強力な`jq`の_フィルター_がとても簡潔に書けることに気づくでしょう。

## 括弧

**括弧**は、演算の順序を強制するために、部分式をまとめるのに使います。他の言語と同じです。
`jq`では、括弧が必要になる場面が意外に思えることがあります。

たとえば、2つの要素を持つ_配列_を作りたいとします。9の平方根と、_e_を1乗したものです。
2つの式はそれぞれ`9 | sqrt`と`1 | exp`です。
出力は_配列_`[3, 2.7...]`になると予想します。

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

なぜ予想どおりにならなかったのでしょうか？　`jq`はこれを次のように解釈します。

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq`は2つの要素（`3`と`1`）のストリームを作り、それぞれが`exp`に渡されます。

`exp`が入力として数値を1つだけ受け取るようにする必要があります。
言い換えると、パイプがカンマより先に評価されるようにする必要があります。

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## 関数と演算子

深く掘り下げることはしませんが（関数は別の演習の話題です）、便利な組み込み関数をいくつか紹介します。

- `length`

  配列を入力として受け取り、その配列の要素数を出力します。

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  この演算子は、オペランドの型によって動作が変わります。
  数値なら足し算をし、
  文字列なら連結し、
  配列なら要素を追加し、
  オブジェクトならマージします。

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add`は、配列を受け取り、`+`のルールに従ってすべての要素を足し合わせた項目を返す関数です。
  `[1, 2, 3] | add`は`6`を出力します。

- `map`

  配列を入力として、フィルターを引数として受け取り、各要素にフィルターを適用した配列を出力します。

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  _何らかの_入力と、引数としてのフィルターを受け取ります。
  - 入力に適用したフィルターの結果が_true_の値になるなら、入力をそのまま出力します
  - そうでなければ、_何も_出力しません（`null`の値ではなく、本当に何も出力しません）

  たとえば、いくつかの数値から3で割り切れるものを選ぶには

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  `range`が数値の_ストリーム_を出力することを思い出してください。
  `select`は、それぞれの数値につき1回呼び出されます。
  式を「通過した」数値だけが出力されます。

  配列の要素を選びたいことは、よくあります。
  これにはいくつかの方法があります。

  入力`["Anne", "Bob", "Cathy", "Dave"]`に対して、長さが4の名前を選びます。
  - `map`と`select`を組み合わせる

    ```jq
    map(select(length == 4))
    ```

  - 配列を要素に分解し、そのストリームに対して`select`を行い、結果をまとめる

    ```jq
    [ .[] | select(length == 4) ]
    ```
