# 指示の補足

## レジスター

| レジスター | 用途   | 型     | 説明                     |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 入力         | 整数    | 上限                                |
| `$a1`    | 入出力       | アドレス | 素数の格納先の配列                    |
| `$v0`    | 出力         | 整数    | 素数の個数                          |
| `$t0-9`  | 一時         | 任意    | 一時的な保存に使う                    |
