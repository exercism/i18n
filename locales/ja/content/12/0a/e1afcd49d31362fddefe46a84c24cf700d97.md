# はじめに

Perlは、Larry Wallによって作られ、1987年に最初にリリースされたプログラミング言語です。

## パッケージとモジュール

パッケージとは、コードをまとめたもので、多くの場合、同じ名前で拡張子が`.pm`のモジュールファイルの中に含まれます。
そのモジュールは、ふつうは`use`キーワードを使って、別のファイルに読み込むことができます。

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## 変数

変数には、スカラー（`$foo`）、配列（`@bar`）、ハッシュ（`%baz`）があります。
話を簡単にするため、ここではスカラー変数だけを使います。
スカラー値は、文字列、数値、真偽値、あるいは何かへの[リファレンス][perlreftut]のいずれかです。
値が存在しない状態は`undef`です。


`my`と`our`というキーワードは、レキシカルスコープで変数を宣言します。たとえば`my $foo;`のように書きます。
`our`を使うと、その変数は同じ名前のパッケージ変数の別名にもなります。
変数を宣言する方法はほかにもありますが、ここでは扱いません。

`=`演算子を使うと変数に代入できます。たとえば`$foo = 1;`です。これは変数の宣言と同時に行うこともできます。たとえば`my $foo = 1;`のように書きます。

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## サブルーチン

`sub`キーワードは[サブルーチン][perlsub]を宣言します。
`return`キーワードはサブルーチンを終了し、指定した値を返します。何も指定しなければ空のリストを返します。
`return`を指定しない場合、戻り値は、そのサブルーチンが使われた文脈（スカラー・リスト・void）と、最後の文によって決まります。

```perl
sub hello () {
    return 'Hello, World!';
}
```

最近のPerlでは、[シグネチャ][perlsubsig]で仮引数を指定できます。
引数リストには、スカラー変数・配列変数・ハッシュ変数を書くことができます。
引数リストが空の場合、そのサブルーチンは引数を取りません。
古いバージョンのPerlでは、特殊変数`@_`から引数を取り出す必要がありましたが、ここでは扱いません。

## コメント

Perlのコメントは、文字列の一部ではない`#`で始まり、行の終わりで終わります。
