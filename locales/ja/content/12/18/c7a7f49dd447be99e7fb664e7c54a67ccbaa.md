# 条件分岐

**条件分岐**は、ある条件が成り立つかどうかによって、2つの処理のうちどちらを行うかを選びます。

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

これを読み解くと、まず`if`、次に`true`か`false`で答える質問、そして`then`です。`then`のあとの行は答えが`true`のときに実行され、`else`のあとの行は`false`のときに実行されます。`end;`は全体を閉じます。

## 3つ以上の分岐

`elsif`を使うと、質問をさらに追加できます。この質問は、その上の質問の答えが`false`だったときにだけ尋ねられます。

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

順番がものを言います。`9`というスコアは最初の質問で引っかかり、2番目の質問には決して到達しません。`9 >= 5`も`true`であるにもかかわらず、です。条件を間違った順番で書いてしまうのが、ここでつまずくよくある原因です。

綴りは`elsif`です。`elseif`でも`else if`でもありません。

## `else`を省略する

その場合に何もすることがないときは、`else`を省略できます。

```sather
   if late then
      apologise;
   end;
```

何かを返さなければならないルーチンでは、すべての経路が値を返す必要があります。そのため、この演習ではどの`if`にも`else`が付いています。
