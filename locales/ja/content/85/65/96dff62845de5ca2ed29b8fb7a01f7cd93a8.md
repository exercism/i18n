# 概要

## 背景

文字列は、引用符で囲まれたテキストのことです。

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

残念ながら、この用語は他の言語に慣れたプログラマーには戸惑いをもたらすかもしれません。

`type`は`character`ですが、Rでは1文字（他のいくつかの言語では`char`と呼ばれますが、Rでは_そうではありません_）と長い文字列を区別しません。
どちらも1つの要素であり、シングルクォート`' '`またはダブルクォート`" "`のどちらで囲んでも構いません。

スタイルガイドではダブルクォートの使用が推奨されています。ただし、文字列の中にダブルクォートをエスケープせずに使いたい場合は例外です。

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

したがって、`character vector`は文字列のベクトルであり、各文字列が1つの要素になります。

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

上の例では、`length(s[1])`は`length("some")`と等価です。つまり_ベクトルの要素数_であり、_文字列の長さ_ではありません。

上の例の`nchar()`のように、個々の文字列を操作することももちろん可能ですが、それには特定の関数が必要で、これについては以下で説明します。

### エスケープ

上で見たように、一部の句読点は、バックスラッシュ`\`を前に付けて「エスケープ」する必要があります。

この話題は言語間でかなり標準化されているため、経験豊富なプログラマーの多くにとって、そのリストは驚くようなものではないでしょう。

引用符（上記参照）に加えて、リストには改行`\n`、タブ`\t`、バックスラッシュ`\\`、そして`\U`や`\u`で始まるUnicode記号があります。

エスケープ文字をたくさん使わずに済むように、`r"( )"`の中で生の文字列（raw string）を定義できます。

```R
r"(raw "string")"
#> [1] "raw \"string\""
```

括弧`( )`を含む生の文字列には、他にも多くの[構文オプション][book-raw]があります。

### ロケール

現在サポートされているどのバージョンのRも文字列をUTF-8でエンコードするため、世界中のほとんどの言語を扱えます。

```R
"आधुनिक मानक हिन्दी"
#> [1] "आधुनिक मानक हिन्दी"
```

さらに、多くのR関数は[`locale`][wiki-locale]を認識しており、文字列の並べ替え、大文字・小文字への変換、日付や時刻などについて、地域の慣習に従おうとします。

このシラバスでは、主に米国英語の例を示します。これは一般的なデフォルトであることと、シラバスの著者がたまたま米国在住であることの両方が理由です。

ロケールは複雑な話題なので、ご自身の状況に合ったドキュメントを探してみてください。


## 文字列関数

base Rでもほとんどのことは_可能_ですが、多くのプログラマーは文字列操作のサポートが限られていて分かりにくいと感じています。

幸いなことに、`tidyverse`にはもっと直感的で柔軟、かつ一貫性のあるパッケージがあります。

### Base R

古いスタイルの文字列関数を使ったレガシーコードがまだたくさんあります。
これには、Exercism上のコミュニティの解答の多くも含まれます。

また、小さなタスクでは、大きなライブラリを読み込む代わりに組み込み関数を使うと便利なことがあります。
Rトラックのメンテナーは、[GitHubリポジトリ][gh-exercism-r]で演習を検証するための模範解答を書くときに、この方法を取ることが多いです。

そのため、古い方法についてもある程度知っておく価値はあります。

以下に示す関数は最もシンプルな形で紹介していますが、ほとんどには省略可能な引数もあります。
詳しくはドキュメントを参照してください。

#### [`nchar`][ref-nchar]

文字列の文字数を返します。

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

「文字」とは何かという（_複雑な！_）話題は、ここでの範囲を超えています。
上の例から、いくつかの点だけ押さえておきましょう。

- Rの文字列は内部的にはCで実装されていますが、`\0`で終端されていません（終端されていれば長さに1が加算されるはずです）。
- マルチバイトのUnicode文字は、期待するとおりに扱われます。"Hrōðgār"は7文字（「ルーン」または「コードポイント」とも呼ばれます）ですが、格納には10バイト必要です。

`nchar`に何を渡すかには注意してください。
`character`以外の値では、結果が予測できないことがありますが、最近のRのバージョンでは改善されています。

#### [`grep`][ref-grep]

文字列のベクトルの中からパターンを検索し、マッチした箇所のインデックスを返します。

```R
grep("Jav", c("Java", "Python", "Javascript"))
#> [1] 1 3
```

#### [`paste`][ref-paste]と[`paste0`][ref-paste]

任意の数の文字列を1つの文字列に結合します。

`paste`には任意で区切り文字を指定できます。デフォルトはスペースです。

`paste0(v)`は`paste(v, sep = "")`と等価です。

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### [`sprintf`][ref-sprintf]

文字列の組み立てをより細かく制御するために、RはC（および後発のいくつかの言語。Wikipediaには約30言語が[掲載されています][wiki-printf-ports]）から`sprintf`関数を取り入れています。

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### [`trimws`][ref-trimws]

先頭および末尾の空白は、`trimws()`で削除できます。

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

両端をまとめて削除したくない場合は、`which = "left"`（または"right"）パラメータがあります。

#### [`substr`][ref-substr]

1つの文字列を操作し、2つの位置（両端を含む）の間の部分文字列を返します。

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### [`strsplit`][ref-strsplit]

区切り文字列に基づいて、文字列をRのリストに分割します。
区切り文字は必須（デフォルトなし）ですが、空文字列にすることもできます。

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

リストについては、別の[概念][concept-lists]で扱います。
まだシラバスのその部分に到達していない場合は、今のところ、[`unlist()`][ref-unlist]関数が（この場合）リストをベクトルに変換するとだけ知っておいてください。

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

#### [`regexpr`][ref-grep]と[`regexpr`][ref-grep]

「regular expression（正規表現）」を略した名前で、これらの関数は文字列内でパターンの出現箇所を検索し、（場合によっては）役立つデータのリストを返します。
ここでは網羅性のために挙げているだけです。_もっと良い選択肢があります！_

`regexpr`は最初の出現箇所だけを返し、`gregexpr`はすべての出現箇所を返します（"g"は「global」検索の意味です）。

名前が示すとおり、パターンには[正規表現][wiki-regex]を使えます。これについては[後の概念][concept-regex]で扱います。

### Tidyverse

好意的に解釈すれば、古いスタイルの文字列関数はRが提供する最良のものとは言えません（_もっと辛口の見方もあります_）。

この状況を改善するため、[`stringr`][ref-stringr]ライブラリは2009年から開発が続けられており、今では[Tidyverse][ref-tidyverse]コレクションの中核を担っています。

`library(stringr)`または`library(tidyverse)`で名前空間に読み込めます。

主な特徴をいくつか挙げます。

- すべての関数名は`str_`という接頭辞を持ち、目的が分かりやすいようになっています。
- 引数の順序は一貫性があり、入力データが最初の引数になります。
- 入力は単一の文字列から複雑なデータ構造まで多岐にわたります。関数はそれに適応し、最も理にかなった処理を行おうとします。

すべてのTidyverseパッケージと同様に、`stringr`には充実したドキュメントがあり、通常はパッケージの作者によって書かれています。

- [リファレンスサイト][ref-stringr]
- [チートシート][cheat-stringr]
- 「R for Data Science」の[章][book-strings]

`stringr`には何十もの関数があり、多くの場合、さまざまな省略可能な引数を持っています。
最初は少し圧倒されるかもしれませんが、そんなときはドキュメントが頼りです。

何を入力したいのか（単一の文字列、ベクトル、それとももっと複雑なもの？）、そして何を出力したいのかを考えてみましょう。

正しい関数と正しい引数を見つけられれば、やりたいことを実現する簡単な方法がきっとあるはずです。

#### 余談：パイプの簡単な入門

関数をつなぐパイプ`|>`の使い方は、シラバスの他の部分でより詳しく説明します。

今のところ、次のことを知っておくと役立ちます。

- パイプの左側の結果は、右側の関数の最初の引数になります（ここで「右側」とは、省略可能な改行を無視したものを指します）。
- 残りの引数は、関数呼び出しに含めることができます。
- Rでは、パイプの先には関数の_名前_だけでなく、関数_呼び出し_を指定する必要があるため、常に括弧が必要です（_これは他の言語とは異なります_）。

以下の例で構文を説明します。
個々の関数については後で説明します。

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### 長さの管理

[`str_length`][ref-str_length]はコードポイントを数えます（`nchars`と似ています）。

他にも空白を操作する関数がいろいろあります。たとえば[`str_trim()`][ref-str_trim]や[`str_squish()`][ref-str_trim]です。
これは、どんなデータサイエンスプロジェクトでも、最初に行う重要なクリーニング作業になることが多いです。

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### 部分文字列を取り出す

[`str_sub(string, start, end)`][ref-str_sub]関数は`start`から`end`まで（両端を含む）の部分文字列を返し、[`str_sub_all()`][ref-str_sub]は複数の文字列を操作できます。

非常に柔軟に使えます。
`start`と`end`はそれぞれ、デフォルトで最初と最後の文字になります。
これらはインデックスのベクトルにすることもできます。
ベクトルのインデックスとは対照的に（これはありがたいことです）、負の値は文字列の末尾から逆向きに数えます。Python流です。

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"

# str_sub_all takes vector input, gives list output
str_sub_all(c(s, "ijklmnop"), c(1, 4, 6), c(2, 5, -1))
[[1]]
#> [1] "ab"  "de"  "fgh"

[[2]]
#> [1] "ij"  "lm"  "nop"
```

#### 文字列を結合する

[`str_flatten`][ref-str_flatten]は文字ベクトルを1つの文字列に変換します。
`collapse`引数は各要素の間に挿入され、デフォルトは`""`です。

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

[`str_c`][ref-str_c]は複数の文字ベクトルを1つの文字ベクトルに変換します。必要に応じてリサイクルされます。

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

[`str_glue`][ref-str_glue]は、Rにシンプルな文字列補間をもたらします。
波括弧`{ }`の中の式が評価され、そのテキスト表現に置き換えられます。

複数の式文字列を指定した場合は、`str_flatten`と同様に結合されます。
また、文字列の先頭や末尾の空白を任意で削除することもできます。

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

`str_glue`は柔軟（かつかなり複雑）ですが、その基盤となる[`glue`][ref-glue]ライブラリには、さらに幅広い可能性があります。

#### 文字列を分割する

Rの非常によくある用途は、乱雑なデータを分析しやすい一貫した形式に整えることです。
これを助けるために、テキストを部分文字列に分割する方法がいくつかあります。

[`str_split_1`][ref-str_split]は最もシンプルで、1つの文字列を、指定したパターン（デフォルトのパターンはありません）で分割した要素のベクトルに変換します。

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

[`str_split_i`][ref-str_split]は文字ベクトルとインデックス`n`を取り、各入力文字列の`n`番目の部分文字列のベクトルを返します。

```R
s2 <- c(s, "C Kotlin, F#")  #> [1] "R Julia Python" "C Kotlin, F#"
str_split_i(s2, " ", 2)  # 2nd element of each
#> [1] "Julia"   "Kotlin,"
```

[`str_split`][ref-str_split]は文字ベクトルを取り、ベクトルのリストを返します。
私たちのシラバスには[リストの概念][concept-lists]があり、その出力について説明しています。

```R
str_split(s2, " ")
[[1]]
#> [1] "R"      "Julia"  "Python"

[[2]]
#> [1] "C"       "Kotlin," "F#"     
```

[`str_split_fixed`][ref-str_split]もあり、こちらは行列を返します。
行列については、後の概念で扱います。

#### 文字列を比較する

文字列全体を比較するために、[`str_equal()`][ref-str_equal]は「等しい」のさまざまな定義を使えます。
最も単純には、デフォルトでは大文字と小文字を区別しますが、変更できます。
ロケールや[Unicode][wiki-unicode]によって、さらに多くの可能性が生まれます。

```R
str_equal("Odin", "odin")
#> [1] FALSE
str_equal("Odin", "odin", ignore_case = TRUE)
#> [1] TRUE
```

他にも[多くの関数][ref-string-matching]があり、[正規表現の概念][concept-regex]でより詳しく説明します。

#### 文字列を変換する

一部の言語（主にヨーロッパの言語）では、大文字と小文字を区別します。
これらを相互に変換するための`stringr`の[関数群][ref-str-case]が、ロケールに適した方法で用意されています。

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : 各単語の最初の文字を大文字に
- `str_to_sentence()` : 文の最初の文字を大文字に

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

パターンマッチングに基づく部分文字列の置換には、[`str_replace()`][ref-str_replace]がパターンの最初の出現箇所を変更し、[`str_replace_all()`][ref-str_replace]がすべての出現箇所を変更します。

文字のインデックスに基づく部分文字列の置換には、[str_sub()][ref-str_sub]の代入形式があります。

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```

#### その他

[`str_dup`][ref-str_dup]は複製を作り、[`str_unique`][ref-str_unique]は重複を削除します。

デフォルトでは`str_dup`に区切り文字はありませんが、指定することもできます。

```R
str_dup("xyz", 4, sep = ", ")
#> [1] "xyz, xyz, xyz, xyz"
```

`str_unique`は[`unique()`][ref-unique]を拡張したものです。
どちらもベクトルから重複する要素を削除しますが、`stringr`の関数は大文字と小文字の区別や、ロケール固有のさまざまなマッチングも扱えます。

```R
inp <- c("some", "strings", "Some", "Strings")
str_unique(inp)
#> [1] "some"    "strings" "Some"    "Strings"
str_unique(inp, ignore_case = TRUE)
#> [1] "some"    "strings"
```
