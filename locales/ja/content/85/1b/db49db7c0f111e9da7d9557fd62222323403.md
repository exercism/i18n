# 指示

DNAの鎖が与えられたら、そのRNAの相補鎖を返します（RNAの転写に従います）。

DNAの鎖もRNAの鎖も、ヌクレオチドが並んでできています。

DNAに含まれる4つのヌクレオチドは、アデニン（**A**）、シトシン（**C**）、グアニン（**G**）、チミン（**T**）です。

RNAに含まれる4つのヌクレオチドは、アデニン（**A**）、シトシン（**C**）、グアニン（**G**）、ウラシル（**U**）です。

DNAの鎖が与えられたとき、それぞれのヌクレオチドを相補的なヌクレオチドに置き換えると、転写されたRNAの鎖ができます。

- `G` -> `C`
- `C` -> `G`
- `T` -> `A`
- `A` -> `U`
