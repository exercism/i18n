二人には、出発地点に YOU ARE HERE と印を付けた白地図も渡されています。

しかし、少し困ったことがあります。Azaraの座標は、Ruiのものとは書式や並び順が違うようなのです。そのため、どの宝物がどの場所に対応するのかを知るには、二人は何度もリストを見比べなければなりません。
二人は駆け出しのJuliaプログラマーで、宝探しの情報をうまく整理するための小さなプログラム（実際にはいくつかの関数です）を書くのを手伝ってほしいと、助けを求めてきました。

## 1. 座標を取り出す

Azaraのリストから`(treasure, coordinate)`のペアを受け取り、そこから取り出した地図の座標だけを返す`get_cooordinate()`関数を実装してください。

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. 座標を整形する

"2A"という形式の座標を受け取り、`('2', 'A')`という形式のタプルを返す`convert_coordinate()`関数を実装してください。

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. 座標を照合する

`(treasure, coordinate)`のペアと`(location, coordinate, quadrant)`のレコードを受け取り、それぞれの座標を比較する`compare_records()`関数を実装してください。
座標が「一致」すれば**`true`**を、一致しなければ**`false`**を返します。
正確に比較するために、必要に応じて座標を整形し直してください。

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. 一致したレコードを組み合わせる

Azaraのリストから`(treasure, coordinate)`のペアを、Ruiのリストから`(location, coordinate, quadrant)`のレコードを受け取り、**座標が一致すれば**`(coordinate, location, quadrant, treasure)`を返す`create_record()`関数を実装してください。

座標が一致_しなければ_、空のタプルを返します。
正確に比較するために、必要に応じて座標を整形し直してください。

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
