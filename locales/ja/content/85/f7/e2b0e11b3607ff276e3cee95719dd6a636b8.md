# テスト

## テストの実行

テストを実行するには、次のコマンドを実行します：

```bash
dotnet test
```

## 演習を解く

演習を解くというのは、その演習のテストをすべて通すということです。デフォルトでは、テストを実行すると、最初の1つのテストだけが実行されます。これは意図的なもので、まずはその1つのテストを通すことに集中できます。それが通ったら、テストの`[<Fact>]`または`[<Theory>]`属性から`Skip = "Remove this Skip property to run this test"`を削除すると、次のテストを有効にできます。すべてのテストを有効にして、実装がそのすべてを通せば、演習を解けたことになります！

始めやすいように、各演習にはスタブの実装ファイルが用意されています。このファイルを、解答を組み立てる出発点として使えます。このファイルは、必要だと思えば自由に削除したり変更したりしてかまいません。

## パッケージを使う

ほとんどの演習は、外部パッケージを使わずに解けるはずです。ただし、外部パッケージを使いたい演習では、次のコマンドを実行するとプロジェクトに追加できます：

```bash
dotnet add package [package-name]
```
