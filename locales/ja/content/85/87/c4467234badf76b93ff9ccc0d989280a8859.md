# Introduction

*disposable*とは、OSのリソース（開いているファイル、ソケット、ハッシュテーブルを基にしたロックなど）を保持し、使い終わったら解放する必要があるもののことです。Factorの`destructors`ボキャブラリは、これらを小さなフレームワークで包み込み、例外によってスタックが巻き戻されるときでも後始末が行われるようにします。

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )`は、リソースを渡してクォーテーションを実行し、終了時にそのリソースを破棄します。複数のリソースを扱う場合は、`with-destructors`でスコープを開き、それぞれを`&dispose`（正常終了時とエラー時の*両方*で破棄）または`|dispose`（エラー時のみ破棄）に登録します。

クラスは、`disposable`を拡張し、`dispose*`というジェネリックを実装することで、このフレームワークに加わります。フレームワークは、オブジェクトごとにただ一度だけこれを呼び出します。呼び出し側が使う公開されたワードは`dispose`です。

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
