# 指示の補足

## レジスタ

| レジスタ | 用途         | 型      | 説明                                   |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | 入力         | アドレス | 1つ目の色を表すヌル終端文字列           |
| `$a1`    | 入力         | アドレス | 2つ目の色を表すヌル終端文字列           |
| `$a2`    | 入力         | アドレス | 3つ目の色を表すヌル終端文字列           |
| `$a3`    | 入力/出力    | アドレス | ヌル終端された出力文字列                 |
| `$t0-9`  | 一時         | 任意    | 一時的な保存に使用                       |
