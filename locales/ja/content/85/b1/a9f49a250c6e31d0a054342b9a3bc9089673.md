# 指示の補足

## ヒント

ユニットテストには単語の例が載っています。ユニットテストに出てくる特定の子音の組み合わせにとらわれず、子音をまとめる方法を考えてみましょう。

この演習では、テキストデータを扱います。歴史的な理由から、Haskellの`String`型は`[Char]`、つまり文字の配列と同じ意味を持ちます。テキストデータをより効率的に扱うには、`Text`型を使えます。

この演習の追加課題として、次のこともできます。

- Haskellの[文字列型](https://haskell-lang.org/tutorial/string-types)について読んでみる。
- package.yamlの依存関係のリストに`- text`を追加する。
- `Data.Text`を[次のように](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)インポートする。

      import qualified Data.Text as T
      import           Data.Text (Text)

- これで、たとえば`translate :: Text -> Text`と書いたり、`Data.Text`のコンビネーターを`T.isSuffixOf`のように参照したりできます。
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)のドキュメントを調べてみましょう。

この部分は完全に任意です。
