# 説明

研究施設の警備の受付を担当しています。スタッフは*バッジ*を身につけており、そのコードは厳密な形式に従っています。入退室ログには、そうしたコードが普通の文章に混ざった状態であふれていて、共有する前にログを整理しなければなりません。こうした作業には、正規表現がぴったりの道具です。

有効なバッジコードは、**大文字2文字、ハイフン、続いて数字4文字**です。たとえば`NS-1024`です。

## 1. バッジコードを確認する

`valid-badge?`を定義してください。バッジの文字列を受け取り、その文字列*全体*が有効なバッジコードであれば`t`を、そうでなければ`f`を返します。

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. ログの1行からすべてのコードを取り出す

`badge-codes`を定義してください。入退室ログの1行を受け取り、その中に登場するすべてのバッジコードを順番に並べたシーケンスを返します。

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. コードの中の数字を数える

`digit-count`を定義してください。文字列を受け取り、その中に数字がいくつ含まれるかを返します。

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. パスワードを伏せ字にする

ログの行には、`pass=`に続けてパスワード（空白以外の文字の並び）が記録されていることがあります。`redact`を定義してください。1行を受け取り、そのようなパスワードをすべて`pass=****`に置き換えた行を返します。

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
