# はじめに

## 数値

Javaの数値には、2つの種類があります。

- 整数：小数点以下の桁がない数値（整数）です。
  例としては、`-6`、`0`、`1`、`25`、`976`、`-500000`などがあります。
- 小数：小数点以下に0桁以上の数字がある数値です。
  例としては、`-20.4`、`0.1`、`2.72`、`16.984025`、`1024.0`などがあります。

Javaで最もよく使われる数値型は、`int`と`double`です。
`int`は32ビットの整数で、`double`は64ビットの小数です。

計算には、標準の算術演算子を使います。
数値の比較には、標準の比較演算子（例：`5 > 4`や`4 <= 5`）や、等値演算子（`==`）、不等値演算子（`!=`）を使います。

Javaの数値変換には、2つの種類があります。

1. 暗黙的な変換：データが失われることはなく、特別な構文も必要ありません。
2. 明示的な変換：データが失われる可能性があり、_キャスト_という形で追加の構文が必要です。

`int`は`double`よりも精度が低いため、`int`から`double`への変換は安全で、暗黙的な変換になります。
一方、`double`から`int`への変換ではデータが失われる可能性があるため、明示的な変換が必要です。

## `if`-`else`文

### _if-then_文

Javaで最も基本的な制御フローの文が、_if-then_文です。
この文は、特定の条件が`true`のときにだけ、あるコードのまとまりを実行するために使います。
_if-then_文は、`if`節を使って書きます。

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

上の例では、車に燃料が残っていない場合、`Car.drive`メソッドを呼び出しても何も起こりません。

### _if-then-else_文

_if-then-else_文は、`if`節の条件が`false`になったときの、もう1つの実行の道筋を用意します。
このもう1つの道筋は`if`節のあとに続き、`else`節を使って書きます。

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

上の例では、車に燃料が残っていない場合、`Car.drive`メソッドを呼び出すと、車を止める別のメソッドが呼び出されます。

_if-then-else_文では、`else if`節を使って複数の条件を扱うこともできます。

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

上の例では、燃料が`5`以下のときに車を走らせると、車は走りますが、燃料ランプが点灯します。
燃料が`0`になると、車は走るのを止めます。
