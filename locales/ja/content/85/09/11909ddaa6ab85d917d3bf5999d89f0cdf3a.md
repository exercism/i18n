# 概要

文字リストは`~c`シジルを使って作成します。

```elixir
~c"hello"
```

~~~~exercism/note
古いバージョンのElixirでは、文字リストはシングルクォートで囲んだ`'hello'`のように表されていました。
~~~~

文字リストとは、整数の配列のことです。それぞれの整数は、ある文字のUnicodeの値、すなわちコードポイントを表します。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## 文字リストは配列なのです

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

文字リストは配列なので、他の配列と同じように扱えます。再帰やパターンマッチを使ったり、[`List`][list]モジュールを使ったりできます。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

2つの配列は、[`++`][kernel-concat-list]で連結できます。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

最初の配列が長いほど連結は遅くなるので、長さのわからない配列に繰り返し要素を追加するのは避けましょう。

## 表示可能性

整数の配列に、表示可能な文字のコードポイントだけが含まれている場合、その配列は文字リストとして表示されます。`[]`構文で定義した場合でも同じです。

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

整数の配列に、表示できない文字のコードポイント（たとえば`0-6`、`14-26`、`28-31`）が1つでも含まれている場合、その配列は配列として表示されます。`~c""`構文で定義した場合でも同じです。

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

表示可能かどうかは、[`List.ascii_printable?`][list-ascii-printable]で確認できます。

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

これらは同じデータを表示する2つの異なる方法にすぎないことに注意してください。値そのものは厳密に等しいです。

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

[`IO.inspect`][io-inspect]で配列を表示するときは、[`:charlists`][inspect-opts]オプションを使って、配列をどのように表示するかを制御できます。

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## コードポイント

文字の前に`?`を付けると、その文字のコードポイントが得られます。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## 文字リストと文字列

同じ文字で構成された文字リストと文字列は、等しいとはみなされません。

```elixir
~c"hello" == "hello"
false
```

文字リストの各要素は[文字のUnicodeコードポイント][unicode-table]ですが、文字列ではコードポイントが[UTF-8][utf8]としてエンコードされます。

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

`ü`のコードポイントは`252`ですが、UTF-8では`195`と`188`としてエンコードされることに注目してください。

**実際のところ、文字リストが使われることはほとんどありません**。主な用途はErlangとの連携、特にバイナリを引数として受け取らない古いライブラリを使うときです。

Elixirを使うときは、**テキストの保存には文字列を使いましょう**。`String`モジュールには、テキストを処理するための関数が豊富に用意されており、文字リストにはそうした関数はありません。

文字リストは[`to_string`][kernel-to-string]で文字列に変換できます。

```elixir
to_string(~c"hello")
# => "hello"
```
