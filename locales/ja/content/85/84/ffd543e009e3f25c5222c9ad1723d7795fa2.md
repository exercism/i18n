# テストを実行する

テストスイートを実行するには、次のコマンドを実行します：

```bash
stack test
```

#### このようなエラーメッセージが表示されたら…

```
No .cabal file found in directory
```

または

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

おそらく古いバージョンのstackを使っているので、アップグレードする必要があります。次のコマンドを試してみましょう：

```bash
stack upgrade
```

その他のアップグレード方法については、[Stackのドキュメント](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade)を参照してください。

#### それ以外の場合に、このようなエラーメッセージが表示されたら…

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

メッセージの指示どおりに実行すれば、正しいバージョンのコンパイラーがダウンロードされ、インストールされます：

```bash
stack setup
```

# *GHCi*を実行する

GHCiで自分の解答をいろいろ試してみたいときは、次のコマンドを実行するだけです：

```bash
stack ghci
```
