# 説明

この演習では、フリーランスがクライアントと、いくつかのプロジェクトの料金についてやり取りするのを助けるコードを書きます。クライアントのための費用をすばやく計算する、いくつかのユーティリティ関数を書きます。

```exercism/note
`ratePerHour`変数と`dayRate`関数は、お金に関係しています。
単位は、時間の単位あたりの金額です。それぞれ時間と日に対応します。
```

## 1. 時給から日当を計算する

あるクライアントが、料金について尋ねるためにフリーランスに連絡してきます。
フリーランスは、**_1日8時間働いています_**と説明します。
しかし、フリーランスが知っているのは、そのプロジェクトの時給だけです。
時給から日当を見積もれるように手伝いましょう。

```javascript
dayRate(89);
// => 712
```

日当は、丸めたり「固定」の精度に変換したりする必要はありません。

## 2. 固定予算から稼働日数を計算する

別の日、プロジェクトマネージャーが、固定予算のプロジェクトをフリーランスに持ちかけます。
固定予算とフリーランスの時給をもとに、予算を使い切るまでに何日働けるかを計算できるように手伝いましょう。
結果は、最も近い整数に**切り捨て**る_必要があります_。

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. 大規模プロジェクトの割引料金を計算する

フリーランスのクライアントは、何ヶ月にもわたるプロジェクトでフリーランスを雇うことがよくあります。
そうした場合、フリーランスは、まる1ヶ月ごとに割引を提供することにし、残りの日数は日当で請求します。
ワークライフバランスがすばらしいおかげで、暦月ごとに22日しか働きません。つまり、**_どの月も請求対象の日数は22日です_**。
時給、プロジェクトに含まれる請求対象日数、月ごとの割引率が与えられたときに、そうしたプロジェクトの費用を見積もれるように手伝いましょう。
割引率は常に数値として渡され、`42%`は`0.42`になります。結果は、最も近い整数に**切り上げ**る_必要があります_。

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
