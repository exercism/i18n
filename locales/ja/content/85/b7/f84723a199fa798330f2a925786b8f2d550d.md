# 説明

この演習では、お気に入りの料理本のラザニアを上手に作れるように、コードを書いていきます。
タスクは4つあり、どれもラザニアを作るのにかかる時間に関するものです。

## 1. オーブンでの想定加熱時間を分単位で定義する

`expectedMinutesInOven`定数を定義します。この定数には、ラザニアをオーブンに入れておくべき分数を格納します。
料理本によると、オーブンでの想定加熱時間は40分です。

```swift
expectedMinutesInOven
// Returns 40
```

## 2. オーブンでの残り時間を分単位で計算する

`remainingMinutesInOven(elapsedMinutes:)`関数を定義します。この関数は、ラザニアがすでにオーブンに入っていた分数を保持する`elapsedMinutes`引数を取ります。
この関数は、前のタスクで求めたオーブンでの想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. 準備にかかる時間を分単位で計算する

`preparationTimeInMinutes(layers:)`関数を定義します。この関数は、ラザニアに重ねた層の数を保持する`layers`引数を取ります。
この関数は、1層につき2分かかるものとして、ラザニアの準備に何分かかったかを返します。

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. 合計の作業時間を分単位で計算する

`totalTimeInMinutes(layers:elapsedMinutes:)`関数を定義します。この関数は2つの引数を取ります。`layers`引数はラザニアに重ねた層の数で、`elapsedMinutes`引数はラザニアがオーブンに入っていた分数です。
この関数は、ラザニアの調理に費やした合計時間を分単位で返します。これは、準備にかかった分数と、その時点でラザニアがオーブンにいた分数を足したものです。

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
