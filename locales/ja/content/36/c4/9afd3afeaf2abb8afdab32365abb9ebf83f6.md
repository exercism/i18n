# イテレーター

イテレーターとは、名前が`!`で終わるルーチンで、`loop`の中でしか呼び出せません。ループを1周するたびに、次の値を生成します。値が尽きると、ループはその場で終わります。

```sather
   loop
      total := total + counts.elt!;
   end;
```

Satherに`for`文はありません。その代わりになるのがイテレーターであり、この言語の代名詞ともいえる機能です。

## 早いうちに知っておきたいもの

| イテレーター | 与えるもの |
| --- | --- |
| `a.elt!` | `a`の各要素を順番に |
| `a.ind!` | `a`の各位置: 0, 1, 2 … |
| `n.upto!(m)` | `n`, `n+1` … `m` |
| `n.downto!(m)` | `n`, `n-1` … `m` |
| `n.times!` | `n`回実行し、何も与えない |
| `n.up!` | `n`, `n+1`, … といつまでも終わらない |
| `s.elt!` | 文字列の各文字 |

`until!`、`while!`、`break!`もイテレーターです。だからこそ名前が`!`で終わり、ループの中でしか動きません。

## 呼び出しを書く場所

イテレーターの呼び出しは、式を書ける場所ならどこにでも書けます。条件の途中でも構いません。

```sather
   loop
      if counts.elt! > 10 then busy := busy + 1; end;
   end;
```

プログラムの中でイテレーターを書いた*場所*ごとに、それぞれ独立した位置が保たれます。1つのループ本体の中で`counts.elt!`を2回書くと、配列を2回、別々にたどることになります。これはほとんど望ましい結果にはなりません。

```sather
   loop
      #OUT + counts.elt! + " and " + counts.elt!;   -- two separate walks
   end;
```

代わりに、値を一度だけ取り出して変数に入れましょう。

## ループを終わらせる

ループは、その中の*どれか1つ*のイテレーターが尽きた時点で終わります。すべてが尽きるのを待つわけではありません。イテレーターが1つなら、これは当たり前に思えます。複数になると、誰もが引っかかるルールになり、次の演習のテーマになります。

## どれを選ぶか

値が欲しいときは`elt!`、位置が欲しいときは`ind!`を選びましょう。両方が同時に必要なとき、あるいは答えが値ではなく位置のときにだけ、`0 .. a.size - 1`ではなく`upto!`を使いましょう。
