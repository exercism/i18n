# 概要

ABAPにはいくつかの数値型があります。小規模な入門演習でよく使われるのは、整数値を表す`i`と、パック10進数を表す`p`です。

値が日数などの整数でなければならないときは`i`を使います。時給のように小数部を含められる値のときは小数型を使います。

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

パック10進数は、小数点以下の桁数を固定したい業務アプリケーションでよく使われます。ABAPには10進浮動小数点数（`decfloat16`と`decfloat34`）や2進浮動小数点数（`f`）もあります。2進浮動小数点数は科学技術計算で役立ちますが、多くの小数は正確に表現できないため、金額を扱うような例で標準的に使うには向いていません。
