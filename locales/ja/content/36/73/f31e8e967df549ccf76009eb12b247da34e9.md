# はじめに

Juliaは、ほとんどのプログラミング言語と同じように、さまざまなコレクション型を提供しています。

なかにはもともと順序を持つもの（`Vectors`や多次元の`Arrays`など）もあり、位置を指定して要素にアクセスできます。
順序を持たないコレクション（`Sets`、`Dicts`）では、キーや値を使って要素にアクセスします。

最も単純な場合として、`Ints`の`Vector`を昇順に並べ替えたいとしましょう。

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

簡単ですね！
`sort()`という関数は名前もわかりやすく、並べ替えられた`Vector`を返すように見えます。

_冗談です！_
シラバスのこの段階まで進むと、話し合うべきニュアンスがあることに、おそらく（そして正しく）気づいているはずです。

## 破壊的な関数と非破壊的な関数

`sort(v)`を実行したあと、`v`はどうなっているでしょうか？

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

元のベクトルは変わっていません。
`sort()`は***非破壊的***な関数で、入力の_コピー_を返します。

多くの場面でこれはよい設計です。振る舞いを簡単に理解できる[純粋関数][wiki-pure-func]になり、並列・分散コードでも扱いやすくなります。

一方で、10億個の文字列からなる配列を並べ替えたいとします。

並べ替えにはおそらく時間がかかるでしょう。
さらに、すべてをコピーし（_遅い！_）、そのコピーを保持するために十分なメモリを確保する（_数ギガバイト！_）必要があります。

よく似た次のコードと比べてみましょう。

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

今度は、入力の`Vector`がコピーなしでその場で並べ替えられ、元の順序は永久に失われます。

効率的なこともありますが、バグを生みやすく、予期しない副作用につながることもあり、あなたのコードを使うほかの人を混乱させることもあります。
_慎重に選びましょう！_

`sort!()`は「破壊的な関数」です。（_非常に強い_）慣習として、入力を変更する関数は、プログラマーへの警告として名前に`!`を付けます。

## 何を基準に並べ替える？

`Int64`の値を並べ替えるのは比較的簡単です。2が1より大きく3より小さいことは、幼い子どもでもわかります。

ほかの型はもっと複雑かもしれませんが、一般に`isless(x, y) == true`であれば`x < y`です。
Juliaはほとんどの標準的な型に対して`isless()`の実装を提供しています。

たとえば、Unicode文字の場合です（ヨーロッパの文字では、大文字は小文字より前に並びます）。

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

並べ替える前の要素に、任意の関数を適用することもできます。たとえば、符号を無視する`abs`や、大文字と小文字を区別せずに並べ替えるための`uppercase`です。

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

## インデックス配列で並べ替え

並べ替える要素が大きなオブジェクトの場合、位置のインデックスを扱うほうが簡単なことがあります。

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

`langs`はVectorなので、各インデックスは[範囲][concept-range]`1:length(langs)`内の整数です。
`sortperm()`の出力は、これらの整数の[順列][wiki-permutation]で、入力ベクトルの並べ替えに対応します。

## 部分的な並べ替え

プログラムで入力をすべて並べ替える必要はあるでしょうか？
最初のいくつか、あるいは最後のいくつかの要素だけが重要な場合、[部分的な並べ替え][wiki-partial-sort]を行うほうがずっと速いことがあります。

Juliaには`partialsort()`と`partialsort!()`という関数があり、指定した要素または要素の範囲が正しいことを保証しますが、入力の残りの部分については何も保証しません。

2番目の引数は整数か範囲で、並べ替えた入力のインデックスを表します。

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```
