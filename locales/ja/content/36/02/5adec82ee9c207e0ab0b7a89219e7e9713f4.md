# 指示の補足

## 出力形式

一連の動作を、`null`終端された文字列として出力します。区切りにはカンマとスペースを使います。

## レジスタ

| レジスタ | 用途     | 型      | 説明                          |
| -------- | -------- | ------- | ----------------------------- |
| `$a0`    | 入力     | 整数    | 1から31までの数値             |
| `$a1`    | 入力・出力 | アドレス | `null`終端された出力文字列    |
| `$t0-9`  | 一時的   | 任意    | 一時的な保存に使う            |
