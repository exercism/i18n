# 説明

この演習では、親友と一緒に「ウィザードとウォリアーズ」というロールプレイングゲームを遊びます。演じるのはゲームマスターで、プレイヤーにとってゲームの世界を生き生きとしたものにするのが役割です。そのために欠かせないのが、プレイヤーにゲームを説明することです。キャラクターの状態はどうなっているのか、訪れている町はどんな様子なのか、といったことです。

ゲームの一部をプレイヤーに説明する5つのタスクに取り組みます。

## 1. キャラクターを説明する

各キャラクターにはクラス、レベル、ヒットポイントがあり、次のように説明されます：`"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`

`Character`を唯一の入力として受け取り、その説明を返す`GameMaster.describe`メソッドを実装しましょう。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 目的地を説明する

各目的地には名前と住民の数があり、次のように説明されます：`"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`

`Destination`を唯一の入力として受け取り、その説明を返す`GameMaster.describe`メソッドを実装しましょう。

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 移動方法を説明する

キャラクターは、次の2つの方法のいずれかで目的地へ移動できます：

- 徒歩。次のように説明されます：`"You're traveling to your destination by walking."`
- 馬に乗って。次のように説明されます：`"You're traveling to your destination on horseback."`

`TravelMethod`を唯一の入力として受け取り、その説明を返す`GameMaster.describe`メソッドを実装しましょう。

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. 目的地へ移動するキャラクターを説明する

キャラクターが目的地へ移動しているときは、個々の説明を組み合わせて次のように説明されます：`"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`

`Character`、`Destination`、`TravelMethod`を入力として受け取り、その説明を返す`GameMaster.describe`メソッドを実装しましょう。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 移動方法を指定せずに目的地へ移動するキャラクターを説明する

ほとんどの場合、キャラクターは徒歩で目的地へ移動します。利便性のため、プレイヤーは移動方法の指定を省略できます。その場合、移動方法は徒歩とみなされます。`Character`と`Destination`を入力として受け取り、その説明を返す`GameMaster.describe`メソッドを実装しましょう。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
