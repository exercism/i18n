# 説明

この演習では、お気に入りの料理本のラザニアをすばらしい出来に仕上げるために、コードを書いていきます。

タスクは4つあり、どれもラザニアの調理にかかる時間に関するものです。

## 1. オーブンでの想定加熱時間を分で定義する

ラザニアをオーブンに入れておくべき分数を表す`OvenTime`定数を定義します。料理本によると、想定されるオーブンの加熱時間は40分です。

```go
OvenTime
// => 40
```

`RemainingOvenTime()`関数を定義します。この関数は、ラザニアを実際にオーブンに入れておいた分数を入力として受け取り、前のタスクで求めた想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```go
func RemainingOvenTime(actual int) int {
    // TODO
}

RemainingOvenTime(30)
// => 10
```

## 3. 準備時間を分で計算する

`PreparationTime`関数を定義します。この関数は、ラザニアに重ねた層の数を入力として受け取り、ラザニアの準備にかかった分数を返します。1層につき2分かかるものとします。

```go
func PreparationTime(numberOfLayers int) int {
    // TODO
}

PreparationTime(2)
// => 4
```

## 4. 経過した作業時間を分で計算する

`ElapsedTime`関数を定義します。この関数は2つの入力を受け取ります。1つ目はラザニアに重ねた層の数、2つ目はラザニアをオーブンに入れておいた分数です。
この関数は、ラザニアの調理に合計で何分かかったかを返します。これは、準備にかかった分数と、その時点でラザニアがオーブンにいた分数を足したものです。
