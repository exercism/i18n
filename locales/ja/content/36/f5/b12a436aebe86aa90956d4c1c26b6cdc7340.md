# 説明の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                             |
| -------- | --------- | ------- | --------------------------------------- |
| `$a0`    | 入力     | アドレス | nullで終端された3進数文字の文字列 |
| `$v0`    | 出力     | 整数 | 入力文字列の10進数の値           |
| `$t0-9`  | 一時 | 任意     | 一時的な保存に使います              |
