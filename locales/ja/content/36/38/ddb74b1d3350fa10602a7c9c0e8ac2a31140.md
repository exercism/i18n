# 説明

文字列で表された三進数（例えば'102012'）を、基本原理に立ち返って10進数に変換しましょう。

無効な三進数を表す文字列は、値0として扱います。

三進数では、0、1、2の3つの記号を使います。

三進数の一番右の位は1の位です。右から2番目の位は3の位、3番目の位は9の位、以降も同様です。

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

使っているプログラミング言語の標準ライブラリに変換用のメソッドが用意されていても、それは存在しないものとして、自分で実装してみましょう。
