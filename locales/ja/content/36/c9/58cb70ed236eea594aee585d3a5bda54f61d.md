# はじめに

## マッピング

マッピングとは、関数をシーケンスの各要素に適用して、新しいシーケンスを作ることです。

これは`mapcar`関数を使えば、配列に対して簡単に行えます。
引数を`2`倍する`double`という関数があるとしましょう。

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

最初の引数は呼び出す関数であることに注目してください。`#'`は関数を指定するための特別なクォート構文です。

`double`はまず最初の要素で呼び出され、次に2番目の要素で呼び出され、というふうに進みます。
結果は配列にまとめられ、それがこの式が評価される値になります。

## フィルタリング

フィルタリングとは、あるシーケンスから、特定の要素以外をすべてコピーして新しいシーケンスを作る処理です。
新しいシーケンスにどの要素を含めるかは、述語関数（真偽値に評価される関数）で決めることも、特定のオブジェクトとの等価性で決めることもできます。

### 述語による削除

`remove-if`は、述語関数とシーケンスを引数に取り、述語が偽の値に評価された要素だけからなるシーケンスを返す関数です。
言い換えると、述語が真に評価される要素をすべて「取り除き」ます。ただし、この関数は元のシーケンスを変更しないことに注意してください！
代わりに、該当する要素を取り除いた新しいシーケンスを返します。すべての値で述語が真だった場合は、空のシーケンスが返されます。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### 特定の要素を削除する

シーケンスから特定の要素を削除したい場合は、削除する要素とシーケンスを取る`remove`を使います。
シーケンスの中で、削除する要素と等しくない値がすべて返されます。
注意：等価性の判定には、デフォルトで`eql`という[汎用的な等価性の述語][concept-equality]が使われます。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

[concept-equality]: /tracks/common-lisp/concepts/equality
