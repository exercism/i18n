# はじめに

## 再帰

再帰関数は、自分自身を呼び出す関数です。

再帰関数には、少なくとも1つの_ベースケース_と、少なくとも1つの_再帰ケース_が必要です。

_ベースケース_は、関数を再び呼び出すことなく値を返します。_再帰ケース_は、いずれベースケースと一致するように入力を変えながら、関数を再び呼び出します。

多くの場合、それぞれのケースは別々の関数節に書きます。

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
