# はじめに

オブジェクトは、変数名の前に`@`を付けて作る_インスタンス変数_を設定することで、自分自身の状態を保持できます。

```ruby
@name = 2
```

オブジェクトは通常、`initialize`メソッドで初期状態を設定します。このメソッドは、クラスに対して`new`を呼び出したときに自動的に呼び出されます。

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

`initialize`メソッドは引数を受け取ることもでき、そうすればインスタンスごとに独自の状態で開始できます。

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

_インスタンス_変数は、外部からの読み書きができないものだと考えてください。インスタンス変数の取得と設定には、_インスタンス_メソッドを使うべきです。

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
