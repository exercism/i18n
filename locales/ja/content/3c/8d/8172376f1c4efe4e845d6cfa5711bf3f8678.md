# はじめに

メソッドは、特別な_レシーバー_引数を持つ関数です。
レシーバーは、`func`キーワードとメソッド名の間にある、専用の引数リストに現れます。

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

メソッドを定義できるのは、そのメソッドと同じパッケージで定義された型をレシーバーに持つ場合だけです。

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

構造体のメソッドは、ドット記法で呼び出すことができます。

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

`Person`インスタンス`p`に対してメソッド`Greetings()`を呼び出した方法に注目してください。
これは、オブジェクト指向プログラミング言語でメソッドを呼び出す方法とまったく同じです。

覚えておきましょう。メソッドは、レシーバー引数を持つ関数にすぎません。
メソッドは名前の衝突を避けるのに役立ちます。メソッドは特定のレシーバー型に結び付いているので、異なる型に同じメソッド名を付けることができます。

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

レシーバーには、値レシーバーとポインターレシーバーの2種類があります。

これまでに見てきたメソッドはすべて値レシーバーを持っています。つまり、メソッドに渡された値のコピーを受け取るので、メソッド内でレシーバーに加えた変更は呼び出し元には見えません。

レシーバーが指す値を変更するには、ポインターレシーバーを持つメソッドを宣言できます。
これは型名の前に`*`を付けることで行います。
たとえば`rect`型の場合、ポインターレシーバーは`*rect`として宣言します。
このような変更は、メソッドの呼び出し元からも見えます。

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
