# 説明

2進数を、文字列（例：'101010'）として表したものから、基本原理に基づいて10進数の値に変換しましょう。

2進数から10進数への変換を実装します。2進数の文字列が入力として与えられたら、プログラムは10進数の値を出力するようにしましょう。無効な入力にも対応する必要があります。

## 注意

- 変換は自分で実装しましょう。
  変換を代わりに行ってくれるものを使ってはいけません。

## 2進数（基数2）について

10進数は基数10の記数法です。

基数10で書かれた数値23は、10の累乗の線形結合として理解できます。

- 一番右の桁には10^0 = 1を掛けます
- その次の桁には10^1 = 10を掛けます
- ...
- *n*番目の桁には10^*(n-1)*を掛けます。
- これらの値はすべて足し合わせます。

つまり、`23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

2進数も同じ考え方ですが、10の累乗ではなく2の累乗を使います。

つまり、`101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`。
