# 説明

2人のバイオリニストがデュエットの練習をしています。それぞれのパートは、各小節の音符の数を並べた配列で、パートの長さがいつも同じとは限りません。

4つの課題はすべて`DUET_PRACTICE`クラスに書きます。

## 1. 2人は何小節を一緒に演奏する？

2人は、両方のパートに小節が残っている間だけ一緒に演奏します。

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. 一致する小節はいくつある？

両方のパートで音符の数が同じ小節を数えます。一致するのは、両方にある小節だけです。

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. 忙しいのはどちら？

1つ目のパートの音符が2つ目のパートより多い小節を数えます。

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. 小節に重みを付ける

後ろの小節ほど難しいので、小節はその位置の分だけ数えます。1つ目の小節は1回、2つ目は2回、3つ目は3回です。各小節の音符の数にその番号を掛けて、すべて足し合わせます。

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

つまり1×4 + 2×4 + 3×8です。小節の番号は0からではなく1から始まります。
