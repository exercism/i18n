# インストール

## どのバージョンを選ぶか

安定版でサポートが続いているPHPのリリースを使うことをおすすめします。
現在は、**PHP8.2、8.3、8.4**です。
現在のリリースとそのサポート期間の詳細は、[PHP公式ドキュメント](https://www.php.net/supported-versions.php)にあります。

## PHPをインストールする

LinuxやmacOSのほとんどのパッケージマネージャーは、ビルド済みのパッケージを提供しています。
PHPはソースからダウンロードしてビルドすることもできます。[php.net/downloads.php](https://php.net/downloads.php)や[windows.php.net/download](https://windows.php.net/download)から入手できます。

~~~~exercism/note
演習を解くのに、nginxやApache HTTPサーバーなどのWebサーバーは必要ありません。
~~~~

### Linux

ディストリビューションによって方法が異なります。
お使いのパッケージマネージャーに応じて、次のいずれかを実行できるはずです。

```shell
yum install php
```

または

```shell
apt-get install php
```

詳しい手順は、PHPマニュアルの[Unixシステムへのインストール](https://www.php.net/manual/en/install.unix.php)を参照してください。

### macOS

PHPはmacOSに同梱されていることが多いですが、古いバージョンのことがほとんどです。
PHPは[Homebrew](https://brew.sh/)でインストールすることをおすすめします。
Homebrewは[公式サイト](https://brew.sh/#install)の手順に従ってインストールできます。

インストールできたかを確認するには、次のコマンドを実行してみましょう。この記事を書いている時点では、Homebrewの`4.5.x`が表示されるはずです。

```shell
brew --version 
```

HomebrewでPHPをインストールします。

```shell
brew install php@8.4
```

これで、インストールされたPHPのバージョンが表示されるはずです。少なくとも`8.2.0`以上です。

```shell
php -v
```

詳しい手順は、マニュアルの[macOSへのインストール](https://www.php.net/manual/en/install.macosx.php)を参照してください。

### Windows

Windows用の公式PHPバイナリは、[windows.php.net/download](https://windows.php.net/download)からダウンロードできます。

[WAMP](https://www.wampserver.com/en/)（Windows、Apache、MySQL、PHP）や[XAMPP](https://www.apachefriends.org/de/index.html)といった、すぐに使えるパッケージもあります。

詳しい手順は、マニュアルの[Windowsシステムへのインストール](https://www.php.net/manual/en/install.windows.php)を参照してください。

### Docker

コンテナ化された環境を好む場合は、[Docker Hubの公式PHPイメージ](https://hub.docker.com/_/php)をダウンロードできます。
[Docker](https://docs.docker.com/engine/install/)も必要です。

### その他

別のOSを使いたい場合は、[php.net/manual/en/install](https://www.php.net/manual/en/install.php)の手順を参照してください。

## PHPUnitをインストールする

~~~~exercism/note
PHPUnit 12はまだサポートされていません！
~~~~

### PHP Archive（PHAR）を使う

Exercismの演習でPHPUnitを使う最も簡単な方法は、PHP Archive（PHAR）としてパッケージ化されたディストリビューションをダウンロードすることです。これがPHPUnitの推奨の使い方でもあります。
`exercism` CLIを置いた場所にPHARを置けば、どこからでもPHPUnitを実行できます。

PHPUnitのパッケージは、PHPアーカイブとして次のようにダウンロードできます。

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

次に、ダウンロードしたファイルに実行権限を与えます。

```shell
chmod +x phpunit.phar
```

そして、`exercism` CLIを置いたのと同じ場所に移動し、コマンド名を`phpunit`にします。

```shell
mv phpunit.phar ~/bin/phpunit
```

これで、どこからでも`phpunit`を実行できます。[PHPトラックのテストのドキュメント](https://exercism.org/docs/tracks/php/tests)にも書かれているとおりです。

```shell
phpunit --version
```

出力は次のようになります。

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

公式の[PHPUnitのインストール手順](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit)に従ってインストールすることもできます。

### Composerを使う

PHPUnitバージョン11は[Composer](https://getcomposer.org)でもインストールできます。

#### Composerをインストールする

お使いのOSの[インストール手順](https://getcomposer.org/doc/00-intro.md)に従って[Composer](https://getcomposer.org)をインストールします。使いやすさのため、グローバルにインストールすることをおすすめします。

#### PHPUnitをグローバルツールとして追加する

次のコマンドを使います。

```shell
composer global require phpunit/phpunit ^11.5
```

必ずバージョン11.5以降をインストールしてください。
