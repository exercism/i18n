# はじめに

Pythonの[比較演算子][comparisons]（_Pythonの関係演算子_とも呼ばれます）は、2つの[オペランド][operand]の_値_を調べ、`comparison`の条件が満たされるかどうかに応じて、真偽値の`True`または`False`を返します。

次の表は、Pythonでよく使われる比較演算子をまとめたものです。

| 演算子 | 演算 | 説明 |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | 「より大きい」             | `a > b`は、`a`の値が`b`より**厳密に**大きいとき`True`になります        |
| `<`      | 「より小さい」             | `a < b`は、`a`の値が`b`より**厳密に**小さいとき`True`になります           |
| `==`     | 「等しい」                 | `a == b`は、`a`の値が`b`と**厳密に**等しいとき`True`になります           |
| `>=`     | 「以上」                   | `a >= b`は、`a`の値が`b`より大きいか、`a`と`b`が等しいとき`True`になります                        |
| `<=`     | 「以下」                   | `a <= b`は、`a`の値が`b`より小さいか、`a`と`b`が等しいとき`True`になります                        |
| `!=`     | 「等しくない」             | `a != b`は、`a == b`が`False`のとき`True`になります                                 |
| `is`     | 「同一性」                 | `a is b`は、`a`と`b`が同じ_オブジェクト_である**_ときに限り_**`True`になります |
| `is not` | 「同一性の否定」         | `a is not b`は、`a`と`b`が同じ_オブジェクト_**ではない****_ときに限り_**`True`になります       |
| `in`     | 「包含の判定」         | `a in b`は、`a`が`b`のメンバー、部分集合、または要素であるとき`True`になります            |
| `not in` | 「包含の判定の否定」 | `a not in b`は、`a`が`b`のメンバー、部分集合、または要素でないとき`True`になります  |

これらはすべて同じ優先順位を持ちます（_[真偽値演算][boolean operations]より高く、算術演算やビット演算より低い_順位です）。

## 異なるデータ型どうしの比較

異なる型のオブジェクトは（数値型を除いて）、デフォルトでは等しいと判定されません。また、`class`の同一でないインスタンスも、その`class`がデフォルトの`object`の比較動作をカスタマイズする特別なメソッドを定義していない限り、等しいと判定され _**ません**_。

数値型は（ほとんどが）この型一致のルールの例外です。比較のために型を暗黙的に変換できる限り、`integer`は`float`と等しいと見なされる**ことがあります**（_[`octal`][octal]が[`hexadecimal`][hex]と等しい_場合も同様です）。

その他の数値型（[複素数][complex numbers]、[小数][decimal numbers]、[分数][rational numbers]）では、比較演算子はそれが「意味をなす」ところ（_暗黙の変換が結果を変えない場合_）で定義されていますが、比較のために元のオブジェクトを正確に変換できない場合は`TypeError`を送出します。

## オブジェクトの同一性の比較

演算子`is`と`is not`は、オブジェクトの_値_ではなく、オブジェクトの[_同一性_][object identity]を判定します。オブジェクトの同一性は、生成後は決して変わりません。また、[`id()`][id function]関数を使うと調べることができます。

`<apple> is <orange>`は、`id(<apple>)` == `id(<orange>)`である**_ときに限り_**`True`と評価されます。`<apple> is not <orange>`はその逆になります。

## メンバーシップの比較

演算子`in`と`not in`は、_メンバーシップ_を判定します。`<fish> in <soup>`は、`<fish>`が`<soup>`のメンバーであるとき（_`<fish>`が`<soup>`の部分集合であるか、`<soup>`に含まれる場合_）に`True`と評価され、それ以外の場合は`False`と評価されます。`<fish> not in <soup>`は、その否定、つまり_`<fish> in <soup>`の反対_を返します。

文字列型とバイト型の場合、`<name> in <fullname>`は、`<name>`が`<fullname>`の部分文字列である**_ときに限り_**`True`になります。
