# 概要

[`IEnumerable<T>`][IEnumerable]インターフェースを実装する型は、*列挙可能*であると呼ばれます。
組み込みのコレクション型はすべて、このインターフェースを実装しています。

列挙可能な型は、`foreach`ループを使って繰り返し処理できます。

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>`を実装するには、型は1つのメソッド`IEnumerator<T> GetEnumerator()`を実装する必要があります。
見てのとおり、列挙可能な型は、コレクションの実際の繰り返し処理を`IEnumerator<T>`型に委ねます。
このインターフェースには、実装する必要のある1つのプロパティと3つのメソッドがあります。

- `public T Current { get; }`: 現在の要素を取得します。
- `public bool MoveNext ();`: 次の要素に移動します。次の要素への移動が成功した場合は`true`を、そうでない場合（要素がもうない場合）は`false`を返します。
- `public void Reset ();`: 列挙子を初期状態（最初の要素の前）にリセットします。

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
