# はじめに

## パターンについてもっと詳しく

Fundamentalsの概念で学んだように、AWKのプログラムは**パターンとアクションの組**でできています。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### 「パターン」とは何でしょうか？

「パターン」とは、任意のAWKの式のことです。
式の結果が真とみなされるかどうかで、アクションを実行するかどうかが決まります。

### 空のパターン

パターンは省略できます。
この場合、アクションはすべてのレコードに対して実行されます。

passwdファイルに含まれるすべてのユーザー名を出力してみましょう。

```sh
awk -F: '{print $1}' /etc/passwd
```

### 正規表現

AWKでは、文字列を正規表現と比較して真偽値の結果を得ることができます。

特定のフィールドを照合するには、正規表現の照合演算子`~`を使います。
この演算子は、左側のオペランドに文字列を、右側のオペランドに正規表現を取ります。
正規表現リテラルは`/`で囲みます。

passwdファイルの中から、bashでログインするユーザーを探すには、次のようにします。

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~`は「正規表現が一致**しない**」演算子です。

現在のレコードに対して正規表現を照合するには、`$0 ~ /regex/`と書きます。
これはよく使われるので、省略記法があります。`$0`と`~`を省略して、単に`/regex/`と書けます。

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
そのAWKのワンライナーを、同等のgrepコマンドと比べてみましょう。

```sh
grep 'regex' data.txt
```

AWKは、簡潔さを犠牲にすることなく、プログラミング言語そのものを手に入れさせてくれます。
~~~~

GNU AWKの正規表現の方言については、この先の概念でより詳しく扱います。

### 式

AWKの式（算術式でも論理式でも、その他の式でも）は、パターンとして使えます。

UIDが1000以上のユーザーをすべて抽出するには、次のようにします。

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

AWKで偽となる値は数値のゼロと空文字列で、それ以外の数値や文字列はすべて真であることを思い出しましょう。
数値または文字列に評価される式であれば、どんなものでもパターンとして使えます。

### 関数

[組み込み][builtins]関数も[ユーザー定義][user-defined]関数も、式の中で、つまりパターンの中で使えます。
いくつか例を挙げます。

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### 定数のパターン

AWKでよく使われるイディオムに、次のようなものがあります。

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1`は真となるパターンで、対応するアクションがありません。
これは「現在のレコードを出力する」という意味です。
