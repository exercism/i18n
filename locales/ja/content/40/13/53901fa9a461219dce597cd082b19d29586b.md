# はじめに

Clojureの標準データ型はすべてイミュータブルなので、制御された変更を行える*参照型*が提供されています。その中で最もシンプルでよく使われるものがアトムです。

アトムは、初期値を取る`atom`関数で作成します：

```clojure
(def players (atom ()))
```

アトムの現在の値は、`deref`または`@`の省略記法でデリファレンスします：

```clojure
@players
;;=> ()
```

`players`アトムの現在の値は、`swap!`を使って変更できます。`swap!`は関数を適用して値を更新します：

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!`関数は、アトムの現在の値に関係なく、その値を置き換えます：

```clojure
(reset! players ())
```
