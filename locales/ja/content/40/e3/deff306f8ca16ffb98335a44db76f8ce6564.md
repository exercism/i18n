# はじめに

Factorでは、ほとんどのデータは*シーケンス*の中にあります。配列（`{ … }`）、ベクター（`V{ … }`）、文字列はどれも、[`sequences`][sequences]にある同じ[プロトコル][sequence-protocol]を共有しています。

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

集約を行う`sum`、`count`、`any?`、`all?`や、`empty?`や`member?`のような述語は、どのシーケンス型でも同じように使えます。元のシーケンスを変更せずに新しいシーケンスを作るには、`prefix`、`suffix`、`append`、`unclip`、`unclip-last`を使います。

`>array`、`>vector`、`>string`（[`arrays`][arrays]と、対応するボキャブラリーにあります）は、汎用的な操作から特定のシーケンス型に戻したいときに、シーケンス型の間で変換を行います。

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
