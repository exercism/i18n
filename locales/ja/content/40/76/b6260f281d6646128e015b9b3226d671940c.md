# テスト

テストを実行する前に、インストールの手順に従って、演習フォルダーが正しくセットアップされていることを確認しましょう。インストールの手順とは、`corepack yarn install`とEditor SDKのセットアップのことです。

テストは次のコマンドで実行します：

```bash
$ corepack yarn test
```

## スキップされるテスト

テストスイートでは、最初のテストを除いてすべてのテストがスキップされています。

ひとつのテストが通るようになったら、`xit`を`it`に変えると、次のテストを有効にできます。また、テストは`xdescribe`を使ってグループにまとめることもあります。これを`describe`に変えると、そのグループを有効にできます。最後に、演習によっては`it.skip`というオプショナルのテストがあることもあります。`.skip`を削除すると、そのオプショナルのテストを実行できます。
