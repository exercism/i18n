# 説明

この演習では、地元のゲームセンターで一番人気のゲームのハイスコアを記録しておく方法を実装します。

## 1. 新しいハイスコアのマップを定義する

新しいハイスコアのマップを作るには、`HighScore.new/0`関数を定義します。この関数は引数を取らず、新しい空のハイスコアのマップを返します。

```elixir
HighScore.new()
# => %{}
```

## 2. ハイスコアのマップにプレイヤーを追加する

ハイスコアのマップにプレイヤーを追加するには、`HighScore.add_player/3`を定義します。これは3つの引数を取る関数です。

- 1つ目の引数は、スコアのマップです。
- 2つ目の引数は、プレイヤーの名前を表す文字列です。
- 3つ目の引数は、整数のスコアです。この引数は省略可能で、デフォルト値0で実装します。

デフォルトの初期スコアは、モジュール属性に保存します。あとでもう一度必要になります。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. スコアのマップからプレイヤーを削除する

スコアのマップからプレイヤーを削除するには、`HighScore.remove_player/2`を定義します。これは2つの引数を取ります。

- 1つ目の引数は、スコアのマップです。
- 2つ目の引数は、プレイヤーの名前を表す文字列です。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. プレイヤーのスコアをリセットする

プレイヤーのスコアをリセットするには、`HighScore.reset_score/2`を定義します。これは2つの引数を取ります。

- 1つ目の引数は、スコアのマップです。
- 2つ目の引数は、スコアをリセットしたいプレイヤーの名前を表す文字列です。

この関数は、プレイヤーがスコアを持っていない場合でも動作する必要があります。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. プレイヤーのスコアを更新する

以前のスコアに加算してプレイヤーのスコアを更新するには、`HighScore.update_score/3`を定義します。これは3つの引数を取ります。

- 1つ目の引数は、スコアのマップです。
- 2つ目の引数は、スコアを更新したいプレイヤーの名前を表す文字列です。
- 3つ目の引数は、保存されているハイスコアに**加算**したいスコアです。

この関数は、プレイヤーが以前のスコアを持っていない場合でも動作する必要があります。その場合は、以前のスコアが0であるとみなします。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. プレイヤーの配列を取得する

プレイヤーの配列を取得するには、`HighScore.get_players/1`を定義します。これは1つの引数を取ります。

- 1つ目の引数は、スコアのマップです。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
