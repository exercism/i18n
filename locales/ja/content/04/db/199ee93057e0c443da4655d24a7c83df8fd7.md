# 概要

## 等価性

Elmの型は、[等価演算子][equality-operator]`(==)`を使って「同じであること」を確認できます。
不等価演算子は`(/=)`です（多くの言語の`!=`では**ありません**）。

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

比較する2つの値は、同じ型でなければなりません。
等価演算子は、リテラル、タプル、レコード、カスタム型に対して使えます。
この演算子は構造的な等価性を調べます。つまり、等しい値は、型注釈やメモリ上の位置に関係なく、同じ内容と同じ深い構造を持ちます。

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

関数を比較すると、実行時にプログラムがクラッシュしてしまいます。そのため、関数の比較は**決して**行わないでください。
この制約についての詳しい情報は[こちら][equality-operator]にあります。

## 比較

[比較演算子][comparison-operators]`(<)`、`(<=)`、`(>)`、`(>=)`と、関数`min`、`max`、`compare`は、`comparable`型に対して使えます。
`comparable`型は、比較できるすべての組み込み型をまとめた特別な型です。数値、文字、文字列、`comparable`なもののリスト、`comparable`なもののタプルが含まれます。
文字は、その[Unicodeコードポイント][unicode-codepoint]に基づいて比較されます。

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

シーケンスのような型（文字列、リスト、タプル）は、[辞書式順序][lexicographic-order]で比較されます。
簡単に言うと、シーケンスの要素は、より小さい要素が見つかるかシーケンスが終わるまで、順番にペアで比較されます。

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

レコードやカスタム型など、その他の型の値は直接比較できません。

`Set`や`Dict`のキーなど、いくつかの組み込み型は、その構造が内部的な順序に依存しているため、内容が`comparable`である必要があります。
つまり、カスタム型は`Set`に格納できないということです。ただし、コミュニティによる代替手段として、[`AnySet`][any-set]、[`AnyDict`][any-dict]、[`Sort`][sort]などがあります。

`comparable`な値のリストは`List.sort`で並べ替えられ、`comparable`な値に変換できる値のリストは`List.sortBy`で並べ替えられます。
階層的な並べ替え（あるプロパティで並べ替え、同点の場合は別のプロパティで決める）が必要な場合は、タプルとリストが辞書式順序で並べ替えられるため、`List.sortBy`でタプルやリストを使えます（他にも[代替手段][sort-by]があります）。


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

関数`compare`は2つの`comparable`な値を受け取り、`Order`を返します。
`Order`は、ある値が別の値より大きい（`GT`）、等しい（`EQ`）、小さい（`LT`）のどれであるかを1回の操作で判定する型です。

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

比較関数は任意の型に対して作成でき、たとえば`List.sortWith`で並べ替えるのに使えます。

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
