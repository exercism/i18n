# 数値

`INT`は整数を表します。このSatherでは、`INT`はちょうど32ビットなので、-2147483648から2147483647までを数えることができます。

```sather
   goals : INT is
      return 42;
   end;
```

## 入力

ルーチンは、括弧（`()`）の中に入力を受け取ります。入力にはそれぞれ型を指定します。

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

同じ型の入力は、宣言をまとめて書くこともできます。これが一般的な書き方です。

```sather
   total(first, second : INT) : INT is
```

## 算術

| 演算子 | 意味 |
| --- | --- |
| `+` | 足し算 |
| `-` | 引き算と、符号の反転 |
| `*` | 掛け算 |
| `/` | 割り算。余りは切り捨てます |
| `%` | その割り算の余り |

`INT`同士の`/`で小数になることはありません。

```sather
7 / 2      -- 3
7 % 2      -- 1
```

小数が必要なときは`FLTD`を使います。これは後で登場します。

普通の算数と同じように、掛け算と割り算は、足し算と引き算よりも優先されます。別の計算をしたいときは、括弧でまとめます。

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## `INT`で使える便利なルーチン

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

文字列を学んだあとに、`.str`を使うと、数値を文章の一部にできるようになります。
