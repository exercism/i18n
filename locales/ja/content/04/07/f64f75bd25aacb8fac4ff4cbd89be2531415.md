# 無視してください

## 入力

スクリプトは、覆面算のパズルを1つの文字列として標準入力（stdin）から受け取ります。パズルの文字列は、`WORD1 + WORD2 + ... == RESULT`という形式です。

例えば、次のようになります。

```text
SEND + MORE == MONEY
```

## 出力

パズルに解がある場合は、`LETTER=DIGIT`の組を空白で区切り、文字のアルファベット順に並べた1行を出力します。

上の例の場合、出力は次のようになります。

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

パズルに複数の正しい解がある場合は、そのうちのどれを出力してもかまいません。

パズルに解がない場合は、何も出力しません（空行を出力します）。
