# はじめに

## 比較演算子

Rには、ほかの多くの言語と同じ演算子がそろっています。

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 条件分岐

`if`-`else`の基本形は次のとおりです。

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

この場合、真偽値を囲む括弧（`()`）と、本体を囲む波括弧（`{}`）の両方が必要です。

シンプルな`if`文は、短く書くことができます。

```R
if (x == 0) return("success")
```
