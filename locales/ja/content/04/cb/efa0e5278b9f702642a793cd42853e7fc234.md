# 指示の補足

## 例外のカスタマイズと送出

コードの中で例外を[カスタマイズ](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)し、さらに[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)する必要があることもあります。そのようなときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。これによりコードが読みやすくなり、デバッグも格段にはかどります。

カスタム例外は、新しい例外クラスを作ることで定義できます（詳しくは[`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)を参照してください）。こうしたクラスは通常、[`Exception`](https://docs.python.org/3/library/exceptions.html#Exception)のサブクラスです。

エラーの原因が、ある例外型から派生したものだとわかっている場合もあります。そのようなときは、_Exception_クラスの下にある[`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを継承するという方法があります。エラーを送出するときも、意味のあるメッセージを含めるようにしましょう。

この演習では、2つの_カスタム例外_を作成する必要があります。1つは循環バッファが**満杯**のときに[送出](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)する、つまり「スロー」する例外で、もう1つは**空**のときの例外です。テストに合格するのは、適切な例外をカスタマイズし、その例外を`raise`し、適切なエラーメッセージを含めた場合だけです。

`built-in exception`をカスタマイズするには、その例外を継承した`class`を作成します。メッセージ付きでカスタム例外を送出するときは、そのメッセージを`exception`型の引数として書きます。

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
