# インストール

## Windows（推奨）

Windowsを使っていますか？

`Windows Key`を押して、`cmd`と入力し、`enter`を押します。

> オペレーティングシステムがWindowsであれば、Batchはすでにシステムにインストールされています。

別のオペレーティングシステムを使っている場合は、以下の手順に従ってBatchをインストールできます。

## Mac OS

1. Gatekeeperが署名のないパッケージをブロックしないように設定されている必要があります。
2. ターミナルアプリケーションを開きます。
3. 次のコマンドを実行してBatchをインストールします：

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. システムが64ビットの場合は、32ビットアーキテクチャを有効にします（まだ有効にしていない場合）：

```bash
sudo dpkg --add-architecture i386
```

2. WineHQリポジトリを追加します：

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. WineHQをインストールします：

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Wineリポジトリを有効にします：

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. WineHQをインストールします：

```bash
dnf install winehq-stable
```
