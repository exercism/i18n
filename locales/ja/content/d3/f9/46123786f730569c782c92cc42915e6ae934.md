# 説明

友達のためにクッキーを焼こうと準備しているうちに、レシピで使われているいくつかの分量を変換しなければならないことに気づきました。メートル法にしか慣れていないので、アメリカのお菓子作りでよく使われる分量をミリリットル（mL）に変換する方法を、自分のために考えておく必要があります。

解答には、次の変換表を使ってください。

| 変換する単位 | 体積 | ミリリットル（mL） |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| アメリカのカップ          | 1      | 240                 |
| アメリカの液量オンス  | 1      | 30                  |
| アメリカの小さじ     | 1      | 5                   |
| アメリカの大さじ   | 1      | 15                  |

プログラミングの腕を磨いているなら、表にあるどの単位から別の単位へも（同じ単位同士へも）変換しやすくするために、ミリリットルを中間の単位として使うのがよいでしょう。

## 1. 量のペアから数値部分を取り出す

`KitchenCalculator.get_volume/1`関数を実装しましょう。量のペアのタプルが与えられたら、その数値の部分だけを返します。

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. 量のペアをミリリットルに変換する

`KitchenCalculator.to_milliliter/1`関数を実装しましょう。量のペアのタプルが与えられたら、変換表を使ってその体積をミリリットルに変換します。

複数の関数節とパターンマッチングを使って、各単位の関数を作りましょう。それぞれの単位を表すアトムは`:cup`、`:fluid_ounce`、`:teaspoon`、`:tablespoon`、`:milliliter`です。変換結果はタプルに包んで返します。

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. ミリリットルの量のペアを別の単位に変換する

`KitchenCalculator.from_milliliter/2`関数を実装しましょう。量のペアのタプルと変換したい単位が与えられたら、変換表を使ってその体積を目的の単位に変換します。

複数の関数節とパターンマッチングを使って、各単位の関数を作りましょう。それぞれの単位を表すアトムは`:cup`、`:fluid_ounce`、`:teaspoon`、`:tablespoon`、`:milliliter`です。

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. どの単位からでも別の単位に変換する

`KitchenCalculator.convert/2`関数を実装しましょう。量のペアのタプルと変換したい単位が与えられたら、与えられた体積を目的の単位に変換します。

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
