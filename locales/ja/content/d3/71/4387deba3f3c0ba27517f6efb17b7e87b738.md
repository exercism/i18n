# はじめに

Pyretには、`true`と`false`という2つの異なる真偽値プリミティブがあります。
この2つの値は、命題や条件が成り立つかどうかを表します。

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyretには、真偽値を組み合わせる演算子`and`と`or`があります。

`and`演算子は、両側がともに`true`のときに`true`を返し、それ以外の組み合わせでは`false`を返します。

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

`or`演算子は、少なくとも片側が`true`なら`true`を返し、両側が`false`なら`false`を返します。

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()`は、`true`を`false`に、`false`を`true`に反転させる組み込み関数です。

```pyret
not(true) # false
not(false) # true
```
