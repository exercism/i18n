# はじめに

メソッドには、可変長引数の仮引数を持たせることができます。これを使うと、呼び出し側は通常の引数と同じように、0個以上の引数を指定できます。メソッドは、これらの引数を1つの配列として受け取ります。

仮引数を可変長引数にするには、仮引数の宣言に`params`キーワードを付けます。

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
