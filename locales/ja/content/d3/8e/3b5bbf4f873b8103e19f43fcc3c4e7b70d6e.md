# 説明

3進数を表す文字列（例：'102012'）を、基本原理に基づいて10進数に変換します。

無効な3進数を表す文字列は、値0として扱うようにします。

3進数では、0、1、2の3つの記号を使います。

3進数の最後の位は1の位です。最後から2番目は3の位、最後から3番目は9の位、というように続きます。

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

使っている言語の標準ライブラリに変換を行うメソッドがあっても、それは存在しないものとして、自分で実装してみましょう。
