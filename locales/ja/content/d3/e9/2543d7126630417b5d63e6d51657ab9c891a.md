# 説明

ベルリンの新しい空港が、ロボット研究所のエンジニアとして採用されました。
その空港には、ぎこちなく、どことなく人型に見えるロボットがいて、接客サービスの向上に役立てようとしています。

最初の仕事は、セルフチェックインカウンターでパスポートをスキャンした利用者に、その人の母語であいさつするようロボットをプログラムすることです。

ロボットは自分の能力に誇りを持っているので、必ず自分が話せる言語を先に言ってから、その人にあいさつします。
たとえば、ドイツのパスポートがスキャンされると、ロボットはこう言います。

```txt
I can speak German: Hallo Dietrich!
```

## 1. 抽象的なあいさつ機能を作る

自分も他のエンジニアも言語を簡単に追加できるように、コードを構成する必要があります。

まずは、2つの関数を持つ`Greeter` traitを定義します。

- `language_name`：ロボットが利用者へのあいさつに使う言語（`ByteArray`）を返す。
- `greet`：利用者の名前（`ByteArray`）を受け取り、その言語のあいさつメッセージ（`ByteArray`）を返す。

次に、利用者の名前と、`Greeter` traitを実装したものを受け取り、目的のあいさつ（`ByteArray`）を返す関数`say_hello`を実装します。
たとえば、`language_name`が`"German"`を返し、`greet`が`"Hallo {name}!"`を返すドイツ語の`Greeter`実装を考えてみましょう。

```rust
say_hello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. イタリア語を実装する

では、イタリアのパスポートをスキャンした人にも対応できるようにロボットを動かしましょう。

`Italian` structを作成し、タスク1の`Greeter` traitを満たすように2つの関数を実装します。
イタリア語では、`"Ciao {name}!"`のようにあいさつできます。

## 3. フランス語を実装する

今日の仕事を終える前に、フランス語であいさつする機能を追加しておくことになっています。

`French` structを作成し、`Greeter` traitを満たすように2つの関数を実装します。
フランス語では、`"Bonjour {name}!"`のようにあいさつできます。
