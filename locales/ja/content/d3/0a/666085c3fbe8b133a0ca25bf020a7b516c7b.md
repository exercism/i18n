# 概要

Luaの真偽値型には、伝統的な2つの真偽値、`true`と`false`があります。これらの値は変数に代入したり、論理演算子（`and`、`or`、`not`）で組み合わせたり、条件判定（たとえば制御構造の中）に使ったりできます。

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

条件判定と論理演算子は、真偽値の`false`と`nil`を偽、それ以外をすべて真として扱います。
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and`と`or`はどちらも*短絡評価*を行います。つまり、必要なときだけ2番目のオペランドを評価します。すべての演算は[演算子の優先順位](https://www.lua.org/manual/5.4/manual.html#3.4.8)に従って評価されます。`not`は`and`や`or`よりも先に評価されます。

`false`と`nil`だけが偽とみなされ、それ以外はすべて真とみなされることから、Luaでは次のような書き方がよく使われます。
```lua
x = x or y
```

これは次のコードと同じ意味です。
```lua
if not x then
  x = y
end
```

関数の中で、仮引数に値がない（`nil`である）ときにデフォルト値を代入するために、これを使うこともよくあります。
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
