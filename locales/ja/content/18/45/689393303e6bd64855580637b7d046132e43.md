# ローカルでのデバッグ

Bashトラックのテストを[Bats](https://github.com/bats-core/bats-core)で実行すると、BatsはSTDOUTとSTDERRの両方を取り込み、出力のアサーションに使います。

```exercism/caution
これはローカルの`bats`では動作しますが、Exercismのオンラインエディターでは**動作しません**。
```

テストの結果に影響を与えずにデバッグ用の出力を表示したいときは、ファイルディスクリプター（fd）3に書き出します。

```bash
echo 'debug message' >&3
```

Batsは、テスト実行中にfd 3へ書き出された出力を表示しますが、`assert_output`のようなアサーションにはその出力を含めません。

実行例：

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

これは、ローカルでテストを実行するときに役立ちます。
