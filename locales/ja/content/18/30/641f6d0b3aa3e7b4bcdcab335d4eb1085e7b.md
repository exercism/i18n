# 説明

[_可変長引数_][variadic-parameters]を使うと、1つの仮引数で、指定した型の0個以上の値を受け取れるようになります。
可変長引数は、仮引数の型注釈の後ろに3つのドット（`...`）を付けて定義します。

関数の本体では、これらの値は指定した型の配列として利用できます。

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
可変長引数のあとにさらに仮引数が続く場合、可変長引数の直後の仮引数には明示的な引数ラベルを**必ず**付けなければなりません。そうすることで、Swiftは可変長引数の並びがどこで終わるのかを判断できます。
~~~~
