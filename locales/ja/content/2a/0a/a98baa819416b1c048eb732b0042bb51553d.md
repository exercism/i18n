# はじめに

## 比較

Pythonは、次の基本的な比較演算子をサポートしています。

| 演算子 | 演算 | 説明 |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | 「より大きい」             | `a > b`は、`a`の値が`b`より**厳密に**大きい場合に`True`になります        |
| `<`      | 「より小さい」             | `a < b`は、`a`の値が`b`より**厳密に**小さい場合に`True`になります           |
| `==`     | 「等しい」                 | `a == b`は、`a`の値が`b`と**厳密に**等しい場合に`True`になります           |
| `>=`     | 「以上」 | `a >= b`は、`a > b`であるか、または値が`a == b`の場合に`True`になります                        |
| `<=`     | 「以下」    | `a <= b`は、`a < b`または`a == b`の場合に`True`になります                        |
| `!=`     | 「等しくない」                 | `a != b`は、`a == b`が`False`の場合に`True`になります                                 |
| `is`     | 「同一性」                 | `a is b`は、`a`と`b`が同じ_オブジェクト_である場合にのみ`True`になります |
| `is not` | 「同一性の否定」         | `a is not b`は、`a`と`b`が同じ_オブジェクト_で**ない**場合に`True`になります       |
| `in`     | 「包含テスト」         | `a in b`は、`a`が`b`のメンバー、部分集合、または要素である場合に`True`になります            |
| `not in` | 「包含テストの否定」 | `a not in b`は、`a`が`b`のメンバー、部分集合、または要素でない場合に`True`になります  |

これらの優先順位はすべて同じです（_これは[ブール演算][boolean operations]より高く、算術演算やビット演算より低くなっています_）。

## 異なるデータ型同士の比較

型が異なるオブジェクトは（_数値型を除いて_）、デフォルトでは決して等しいと比較されません。
`class`の非同一のインスタンスも、その`class`がデフォルトの`object`比較動作をカスタマイズする特別な[拡張比較][rich comparisons]メソッドを定義していない限り、_**等しい**_とは比較されません。
`rich comparisons`によるカスタマイズは、続く演習で扱います。
このトピックの（はるかに）詳しい説明は、Pythonのドキュメントの[値の比較][value comparisons]を参照してください。

数値型は（ほとんどが）この型一致の規則の例外です。
比較のために型を暗黙に変換できるのであれば、`integer`は`float`（_または[`octal`][octal]が[`hexadecimal`][hex]と等しい_）と等しいと見なされる**ことがあります**。

Python標準ライブラリにある他の数値型（[複素数][complex numbers]、[十進数][decimal numbers]、[分数][rational numbers]）では、比較演算子は「意味を成す」ところ（_暗黙の変換が結果を変えないところ_）で定義されていますが、比較のために元のオブジェクトを正確に変換できない場合は`TypeError`を送出します。
Pythonが_数値変換_に用いる規則の詳細は、Pythonのドキュメントの[算術変換][arithmetic conversions]を参照してください。

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

数値と`NaN`（_not a number_、非数）型との順序比較は、すべて`False`になります。
Pythonの`NaN`の定義による紛らわしい副作用として、`NaN`は`NaN`と決して等しいと比較されません。

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## 文字列の比較

数値と違い、文字列（`str`）は、それぞれのUnicodeコードポイント（_`str`内の各コードポイントを組み込み関数[`ord()`][ord]に渡した結果で、これは`int`を返します_）を使って、[_辞書式順序_][lexographic order]で比較されます。
両方の文字列のすべてのコードポイントが一致し、_**かつ同じ順序である**_場合、その2つの文字列は等しいと見なされます。
この比較は「ペアごと」に行われます。つまり、1文字目と1文字目、2文字目と2文字目、というように進みます。
Python 3.xでは、`str`と`bytes`を直接強制変換したり比較したりすることはできません。

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## 比較の連結

比較演算子は_自由に_連結できます。つまり、どのような組み合わせでも、どのような長さでも使えます。
式の評価は`left`から`right`へと行われることに注意してください。

例として、`x < y <= z`は`x < y` `and` `y <= z`と等価ですが、`y`が**一度だけ**評価されるという点が異なります。
どちらの場合も、`x < y`が`False`と判明した時点で、`z`は**まったく**評価され_ません_。
これは一般に`short-circuit evaluation`と呼ばれます。式の真偽値がすでに決まっていれば、評価は止まるのです。

`Short circuiting`は、さまざまなブール演算子や関数でサポートされており、Pythonでは比較の連結でもサポートされています。
`C`、`C++`、`C#`、`Java`など多くのプログラミング言語と違い、Pythonでは`a < b < c`のような連結式が、従来の[数学的な解釈][three way boolean comparison]と優先順位を持ちます。

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## オブジェクトの同一性の比較

演算子`is`と`is not`は、オブジェクトの_値_ではなく、オブジェクトの[_同一性_][object identity]を調べます。
オブジェクトの同一性は作成後に変わることはなく、[`id()`][id function]関数を使うと調べられます。

`<apple> is <orange>`は、_**`id(<apple>)` == `id(<orange>)`の場合にのみ**_`True`になります。
`<apple> is not <orange>`はその逆になります。

`None`と`NotImplemented`はシングルトンであるため、常に`is`と`is not`を使って項目と比較するべきです。
この慣習の詳細については、Pythonリファレンスの[値の比較][value comparisons none]と[PEP8][pep8 programming recommendations]を参照してください。

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## メンバーシップの比較

演算子`in`と`not in`は、_メンバーシップ_を調べます。
`<fish> in <soup>`は、`<fish>`が`<soup>`のメンバーである場合（_`<fish>`が`<soup>`の部分集合であるか、`<soup>`に含まれている場合_）に`True`になり、それ以外の場合は`False`になります。
`<fish> not in <soup>`は、その否定、つまり`<fish> in <soup>`の_反対_を返します。

文字列型とバイト型では、`<name> in <fullname>`は、_**`<name>`が`<fullname>`の部分文字列である場合にのみ**_`True`になります。

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
