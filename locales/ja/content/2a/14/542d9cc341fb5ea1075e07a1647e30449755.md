# はじめに

浮動小数点数は、小数点以下の桁を1桁以上持つ数値です。64ビットの倍精度浮動小数点形式を使います。

```elixir
float = 3.45
# => 3.45
```

## 数値の扱い

[`Integer`][integer-functions]モジュールと[`Float`][float-functions]モジュールには、これらの型を扱うための便利な関数が用意されています。基本的な算術演算子は、[`Kernel`][kernel-arithmetic-operators]モジュールで定義されています。

## 変換

整数と浮動小数点数は、1つの算術式の中で混ぜて使えます。式の中で浮動小数点数を使うと、結果も必ず浮動小数点数になります。

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

ただし、割り算では、整数だけを使った場合でも、結果は必ず浮動小数点数になります。

```elixir
6 / 2
# => 3.0
```

浮動小数点数を整数に変換するには、[`trunc/1`][trunc-1]で小数部分を切り捨てます。
