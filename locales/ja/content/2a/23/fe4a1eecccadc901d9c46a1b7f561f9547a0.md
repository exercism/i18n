# 概要

三項演算子を使うと、`if`条件を文のブロックではなく、式として書くことができます。これは関数型プログラミングの考え方に通じるもので、コードをより表現豊かに、そして間違いが起きにくくしてくれることがよくあります。

三項演算子は、3つの式を組み合わせたものです。まず条件、次にその条件が真のときに評価されて返される式（`?`で始まる`if`の部分）、そして条件が偽のときに評価されて返される式（`:`で始まる`else`の部分）が続きます。

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
