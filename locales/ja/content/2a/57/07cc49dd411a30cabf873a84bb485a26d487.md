# 可視性

クラスを使ってコードを整理するとき、プロパティ・メソッド・定数の可視性は、適切な抽象化と責務を後押しします。
プロパティ・メソッド・定数の可視性は、それらを宣言するときに`public`、`private`、`protected`のどのキーワードを使うかで決まります。
可視性は、常にクラスのプロパティ・メソッド・定数を外部から使う場合を基準に考えます。
つまり、プロパティが`public`で宣言されていれば、外部からの呼び出しで参照でき、使うこともできます。
`private`のプロパティ・メソッド・定数は、外部からの呼び出しでは参照も使用もできません。

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

`protected`のプロパティ・メソッド・定数は、そのクラス自身と、（継承した）子クラスからのみ参照できます。

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
