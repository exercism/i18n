# 説明

この演習では、`HashMap`とentry APIのメソッドを使って、簡単なアルゴリズムの問題を解きます。

雑誌の記事の単語を表す`&[&str]`と、送りたいメモの単語を表す`&[&str]`が与えられたとき、雑誌から単語を切り取って手紙に貼り付け、メモを組み立てられるでしょうか？

補足：

- これは実際に切り貼りするという意味です。雑誌には、メモに必要な数だけ同じ単語が含まれている必要があります。
- 大文字と小文字は区別されます。雑誌の単語を貼り合わせてメモを作るからといって、文法的に正しくない文でよいわけではありません。

まずは、次のスタブの関数シグネチャから始めます。

```rust
pub fn can_construct_note(magazine: &[&str], note: &[&str]) -> bool {
    todo!()
}
```

次の入力を与えると

```rust
let magazine = "two times three is not four".split_whitespace().collect::<Vec<&str>>();
let note = "two times two is four".split_whitespace().collect::<Vec<&str>>();
assert!(!can_construct_note(&magazine, &note));
```

この関数は`false`を返します。メモには`"two"`が2つ必要ですが、雑誌には`"two"`が1つしか含まれていないからです。

次の入力では成功します。

```rust
let magazine = "Astronomer Amy Mainzer spent hours chatting with Leonardo DiCaprio for Netflix's 'Don't Look Up'".split_whitespace().collect::<Vec<&str>>();
let note = "Amy Mainzer chatting with Leonardo DiCaprio"
    .split_whitespace()
    .collect::<Vec<&str>>();
assert!(can_construct_note(&magazine, &note));
```

この関数は`true`を返します。メモに必要な単語がすべて雑誌に含まれているからです。
