# 説明

8進数を文字列で表したもの（例：'1735263'）を、基本原理だけを使って10進数に変換します（つまり、変換に組み込みライブラリや外部ライブラリを使ってはいけません）。

8進数から10進数への変換を実装します。8進数の入力文字列が与えられたら、プログラムは10進数の出力を生成するようにします。

## 注意

- 変換は自分で実装します。
  変換を代わりにやってくれるものを使ってはいけません。
- 無効な入力は8進数の0として扱います。

## 8進数（基数8）について

10進数は、基数10の記数法です。

基数10で表記された数値233は、10の累乗の線形結合として捉えることができます：

- 一番右の桁には、10^0 = 1を掛けます。
- その次の数値には、10^1 = 10を掛けます。
- ...
- *n*番目の数値には、10^*(n-1)*を掛けます。
- これらの値をすべて足し合わせます。

つまり：

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

8進数も同様ですが、10の累乗ではなく8の累乗を使います。

つまり：

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
