# はじめに

`:`による定義は、自分自身を直接呼び出すことができます。Factorのコンパイラーは、再帰的なワードのスタック効果も、他のワードと同様に推論します。単純な再帰には特別な宣言は必要ありません。

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

この2つの部分は、再帰の*ベースケース*（ここでは、空のシーケンスの合計が`0`になります）と、*再帰ステップ*（要素を1つ外し、残りに対して再帰し、結果を組み合わせます）です。

`if-empty`と`unclip`は、シーケンスの再帰における定番の組み合わせです。`if-empty ( seq emptyquot nonemptyquot -- )`は、シーケンスに応じて2つのクォーテーションのうちの一方を実行します。`unclip`は最初の要素を外すので、再帰ステップはより単純な対象を扱えます。
