# 学習

Groovyを始めてみたい方も、演習を進めながらさらに学びたい方も、ぜひ参考にしてください。

Groovyを試すには、次の方法があります。

* [オンラインインタプリターが使えるブラウザ](https://www.jdoodle.com/execute-groovy-online)
* コマンドラインで`groovyConsole`と入力して使う[Groovy Console](http://groovy-lang.org/groovyconsole.html)
* コマンドラインで`groovysh`と入力して使う[Groovy Shell](http://groovy-lang.org/groovyconsole.html)

次の資料でGroovyの全体像をさっと眺めてみましょう。

* Tim Rowsの[Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/)は、Javaのエンジニアでなくても同じように役立ちます
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* SmartThingsの[Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html)
* JDrivenの[online Groovy Koans](http://www.groovy-koans.org/)をいくつか

さらに深く学ぶなら、次の資料があります。

* [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* Groovyの_決定版_ともいえる書籍、[Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition)
* Ken Kousenの[Making Java Groovy](https://www.manning.com/books/making-java-groovy)
