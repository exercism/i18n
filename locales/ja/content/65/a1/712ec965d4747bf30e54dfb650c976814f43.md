# `readonly`クラスとプロパティ

`readonly`クラスとプロパティを使うと、クラスは簡単にアクセスできる`public`プロパティを指定できますが、変更を防ぐことができます。
プロパティを`readonly`として宣言するには、型指定の前に`readonly`を付ける必要があります。
プロパティは一度だけ代入できますが、値を再代入したり変更しようとすると、`Error`が発生します。

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

`readonly`クラスはこの動作を基にしています。クラスを`readonly`として宣言すると、読み取り専用の宣言が各プロパティに適用されます。
さらに、動的プロパティの追加も防ぎます。

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
