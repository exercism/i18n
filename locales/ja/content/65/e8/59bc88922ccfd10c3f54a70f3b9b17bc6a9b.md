# はじめに

F#でオブジェクト指向プログラミングを行うには、クラスが中心的な役割を担います。

F#のクラスは、フィールドとメソッドからできています。クラスのフィールドとメソッドは、まとめて _メンバー_ と呼ばれます。

F#のクラスは、`type`キーワードを使って定義します。メソッドは`member`キーワードで定義し、常にpublicです。(privateな)フィールドを定義するには、`let`束縛を使います。

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

クラスは、オブジェクトを作るためのひな型です。クラスのインスタンスを作るには、クラス名を関数のように呼び出します。クラスのインスタンスは、_オブジェクト_ とも呼ばれます。

オブジェクトのメンバーには、ドット記法でアクセスできます。

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
