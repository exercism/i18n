# 概要

型定義では、新しい名前付きの型を作ります。この型は、たとえ基になる型が同じであっても、ほかのどの型とも異なる別個の型です。

## 型を定義する

型定義は、`type`キーワードで始まり、その後に新しい型の名前と、その基になる型を書きます。

```go
type File []bool
```

ここでの`File`は、チェスボードの縦1列を表します。ふつうAからHまでのラベルが付いています。
この列の各マスは、そこが埋まっているかどうかを表す真偽値で表現されます。
`File`を定義したので、ほかの定義の中で使えるようになりました。

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`は、ファイルの識別子を`File`の値に対応付けます。
それぞれの`File`は、1つのチェスファイルのマスを表す真偽値のスライスです。
これらの型定義がなければ、`board`は`map[string][]bool`になり、何を表しているのかが分かりにくくなってしまいます。

## 定義した型は別個の型

`Score`と`int`はどちらも整数の値を保持しますが、互いに変換するには明示的な変換が必要です。

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42`は型なしの定数なので、`Score`型の変数にそのまま代入できます。

定義した型にはメソッドを持たせることもできます。これについてはメソッドの概念で説明します。

## 構造体型

構造体の定義も、同じ`type`キーワードを使います。

```go
type Player struct {
    Name  string
    Score Score
}
```

構造体型については構造体の概念で説明します。

## 型エイリアス

型エイリアスは、新しい型を作るのではなく、既存の型に別の名前を付けるものです。
エイリアスと元の型は同一なので、その値は互いに置き換えて使うことができます。
エイリアスは、`type`キーワード、エイリアスの名前、等号（`=`）、そして既存の型を使って宣言します。

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
