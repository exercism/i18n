# 概要

[三項演算子][ternary-operators]を使うと、`if`条件を文のブロックではなく式として書けます。これは関数型プログラミングの考え方に通じるもので、コードをより表現豊かに、そしてエラーを起こしにくくできることがよくあります。

三項演算子は、3つの式を組み合わせます。1つ目は条件、2つ目は条件が`true`のときに評価されて返される式（`if`の部分で、`?`で始まります）、3つ目は条件が`false`のときに評価されて返される式（`else`の部分で、`:`で始まります）。

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
