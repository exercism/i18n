# インストール

## Linux

BashはGNUシェルなので、GNU/Linuxシステムならどれにも入っています。
BSDやその他のUNIX系OSでは、自分でインストールする必要があるでしょう。
BSDやAIX、あるいはbashが付属していないLinuxを使っている場合は、標準外のパッケージのインストールについて、お使いのOSの資料を参照してください。

お好きなグラフィカルインターフェースで「Terminal」という名前のアプリケーションを探してください。「Administrative/System Tools」のセクションにあるかもしれません。

使えるBashのバージョンを確認するには、コマンドラインまたはターミナルから次を実行します：

    echo $BASH_VERSION

シェルが`bash`なら、次のように表示されるはずです：

    4.4.19(1)-release

ほかに何もする必要はありません。今使っているシェルがbashなのですから、この時点でbashはすでにインストールされ、パスも通っています。

シェルがbashでなくても、わざわざ変える必要はありません。
bashシェルの中にいなくても、bashスクリプトを書いて実行できます。

インストールされているbashのバージョンを確認するには、次を実行します：

```plain
bash --version
```

次のように表示されます：

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

表示されない場合は、bashがインストールされていないのかもしれません。
お使いのディストリビューションのパッケージマネージャーでインストールしてください。

## Windows

Windows 10なら、[WSL](https://docs.microsoft.com/en-us/windows/wsl/about)をインストールできます。
これで、Windows上でネイティブに動作する完全な（といっても、GUI以外のコンポーネントですが）Linuxディストリビューションがインストールされます。

あるいは、次のものをインストールすることもできます：

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* [仮想マシン](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)内の完全なLinuxディストリビューション

## MacOS

Apple OSXの場合：

* Finderを開き、
* Applicationsフォルダーを開き、
* Utilitiesフォルダーを開き、
* 最後に`Terminal`アプリケーションを開きます。

MacOSにインストールされているbashはバージョン3.2で、とても古いことに注意してください。
これは、(i)新しいバージョンのbashがGPLv3でライセンスされていること、そして(ii)Appleがそのライセンス条件の順守を強制されたくないことによるものです。
さらに、AppleはbashがMacOSからなくなっていくことを示しています。デフォルトのログインシェルは最近[bashからzshに変更されました](https://support.apple.com/en-us/HT208050)。

Macで最新のbashを入手するには：

1. [Homebrew](https://brew.sh)をインストールします
1. ターミナルで`brew install bash`と入力します

これで最新のbashが（私の記憶では）`/usr/local/bin/bash`としてインストールされます（システムのデフォルトのbashを上書きしないためです。ほかのツールが/bin/bashに依存しているかもしれません）。

`bash`と入力したときにHomebrewのbashが起動するようにしたい場合は、~/.bash_profile（または~/.profile）ファイルを編集して、PATHの中で/usr/local/binを/binより*前*に置きます：

    PATH=/usr/local/bin:$PATH
