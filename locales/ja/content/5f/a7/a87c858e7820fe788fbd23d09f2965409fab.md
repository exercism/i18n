# テスト

## コードを書く

コードは`src/lib.cairo`に書きます。
演習には`src/lib.cairo`にスタブファイルが用意されていて、書く必要のあるコードのシグネチャを確認できます。

ほとんどの演習では、すべてのコードを`src/lib.cairo`に書くのがおすすめです。
解答を複数のファイルに分けたい場合は、The Cairo Bookの[モジュールの章][chapter-modules]を参照してください。

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## テストを実行する

テストを実行するには、まずテストしたい演習のディレクトリに作業ディレクトリを移動します。

```bash
cd path/to/exercise
```

そして、次のコマンドを実行します。

```bash
scarb cairo-test
```

デフォルトでは最初のテストだけが有効になっています。
次のテストに進む準備ができたら、そのテストからignoreフラグ（`#[ignore]`）を外します。

無視されたテストも含めてすべてのテストを実行するには、すべてのテストから`ignore`フラグを外すか、次のコマンドを実行するだけでもかまいません。

```bash
scarb cairo-test --include-ignored
```

テストに通るようにするために、できるだけ少ないコードを書いて構いません。
テストの失敗が、次に何を書けばよいかを教えてくれます。

Cairoはコンパイル時にすべてのコードをチェックするため、必要なコードを書くまでテストがコンパイルできないことがあります。
`ignore`されたテストもコンパイル時にチェックされます。
コンパイルできないテストは、各行の先頭に`//`を付けて[コメントアウト][comments]できます。
そして、そのテストに取り組む準備ができたら、コメントアウトを解除します。
Cairoには`panic!()`という特別なマクロもあり、これを未完成のコードパスに使うと、プログラムをコンパイルできるようになります。

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
