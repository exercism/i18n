# はじめに

## 文字

### 文字

Javaの`char`プリミティブ型は、1文字を16ビットで表す型です。
複数の`char`を組み合わせて`"word"`のような文字列にすることもできますし、`char`を1つずつ個別に扱うこともできます。
`char`リテラルはシングルクォートで囲みます（例：`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

### `String`の`char`を取得する

`String.toCharArray`メソッドは、文字列の`char`を配列として返します。
配列の回で説明したように、`for`ループを使って配列を順に処理できます。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### Characterクラス

`char`を調べたり操作したりするためのメソッドが、標準ライブラリにたくさん用意されています。
それらは`java.lang.Character`クラスの静的メソッドとして使うことができます。
いくつか例を見てみましょう。

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### `char`を`String`に追加する

`+`演算子を使うと、`char`を`String`に追加できます。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
2つの`char`をつないで`String`を作るときに、`+`を_使わない_ように注意してください！
この方法で2つの`char`を足し合わせると、`String`では_なく_、`int`になります！
例えば：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

これは、Javaが`char`を`int`に昇格させるためです（[Java Language Specification][jls-main]の[4.2 Primitive Types and Values ][jls-primitives]を参照してください）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

ただし、追加する文字が多いときは、代わりに`StringBuilder`を使うほうが効率的な場合があります。

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
