# はじめに

条件分岐は、条件が`true`か`false`かによって、実行するコードを変える文です。

`if`文は、条件が`true`のときにだけ、その本体を実行します。Goにはtruthyやfalsyという考え方がないため、条件には`bool`型を使う必要があります。`if mySlice { ... }`や`if 1 { ... }`のような式はコンパイルエラーになります。

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

さらに条件を調べたいときは`else if`を、どの条件にも当てはまらないときの受け皿としては`else`を使います。条件は上から順に評価され、条件が`true`になった最初の分岐だけが実行されます。

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`文には、短い初期化の文を書くこともできます。このように宣言した変数のスコープは、`if`/`else`の連鎖全体の中だけになります。

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
