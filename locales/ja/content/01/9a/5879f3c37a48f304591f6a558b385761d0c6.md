# はじめに

Elixirでは、ドキュメントは一級市民として扱われます。

コードをドキュメント化するためによく使われるモジュール属性が2つあります。モジュールを説明する`@moduledoc`と、その属性の直後にある関数を説明する`@doc`です。`@moduledoc`属性は通常モジュールの最初の行に書き、`@doc`属性は通常、関数定義の直前、その関数が型仕様を持つ場合は型仕様の直前に書きます。ドキュメントは一般に、ヒアドキュメント構文を使った複数行の文字列として書きます。

Elixirのドキュメントは[**Markdown**][markdown]で書きます。

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
