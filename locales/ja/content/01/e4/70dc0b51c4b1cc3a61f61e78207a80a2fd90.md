# はじめに

## 文字列

F#の`string`は、Unicode文字（英字、数字、句読点など）の並びとして、変更できないテキストを表すオブジェクトで、次のように定義します。

```fsharp
let fruit = "Apple"
```

文字列は、その文字列のメソッドを呼び出すか、`String`モジュールの関数を使うことで操作します。一度文字列を作成すると、その値を変えることはできません。文字列を変更するように見えるメソッドや関数は、実際には新しい文字列を返します。

文字列は、いくつかの方法で連結したり、書式を整えたりできます。
* 連結には`+`演算子を使えます。
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* テキストの書式設定には`sprintf`関数を使えます。書式テキストの中にプレースホルダー（`string`の場合は`%s`）を置き、値を引数として渡します。
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
