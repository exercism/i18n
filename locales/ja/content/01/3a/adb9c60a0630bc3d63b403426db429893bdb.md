# 概要

インターフェースは、クラスのシグネチャーだと考えることができます。というのも、クラスの公開フィールドを表しているからです。クラスは`implments`キーワードを使って`interface`を_実装_します。

その構文はクラスとよく似ていますが、メソッドが本体を持たないシグネチャーとして現れる点が異なります。

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

インターフェースから実装するフィールドは、**必ず**同じ可視性修飾子を使わなければなりません。たとえば、変数`a`がインターフェースで`public`なら、その実装でも`public`にする必要があります。
