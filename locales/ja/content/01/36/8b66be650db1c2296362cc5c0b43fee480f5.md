# Debug

失敗しているテストにメッセージを添えるには、[Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log)が使えます。次のように書きます。

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

テストが失敗すると、添えたログは`secondsInOneHour: 3600`になります。

注意点が1つあります。トップレベルの定数は、テストの実行が始まる前に一度だけ評価されます。そのため、テストはそのログメッセージを取得できません。たとえば、次のとおりです。

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

これはテスト中に何もログに出力しません。`secondsInOneHour`に対応するJavaScriptの変数が、すでに値3600として評価されているからです。
