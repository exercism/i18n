# 説明の補足

## 出力形式

歌詞をヌル終端文字列として出力します。

## レジスタ

| レジスタ | 用途      | 型     | 説明                    |
| -------- | --------- | ------ | ----------------------- |
| `$a0`    | 入力      | 整数   | 開始の節                |
| `$a1`    | 入力      | 整数   | 終了の節                |
| `$a2`    | 入力/出力 | アドレス | ヌル終端された出力文字列 |
| `$t0-9`  | 一時      | 任意   | 一時保存用              |
