# 関数

関数はCairoの基本です。

Cairoでは慣例として、関数名と変数名に**スネークケース**を使います。単語を小文字にして、アンダースコアで区切る書き方です。

例を見てみましょう。

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

関数は`fn`で定義し、そのあとに関数名、仮引数があればそのための括弧（`()`）、そして波括弧（`{}`）で囲まれた本体を続けます。

関数を呼び出すには、関数名のあとに括弧を書きます。

関数は、スコープ内にあれば、定義する順番は関係ありません。

## 仮引数

関数は**仮引数**を受け取ることができます。仮引数は、関数のシグネチャーで定義される変数です。

関数を呼び出すときは、**実引数**を渡します。実引数は、仮引数に渡される値です。

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

ここでは、`x`は`felt252`型の仮引数です。

`5`を渡して呼び出すと、この関数は「The value of x is: 5」と出力します。

仮引数が複数ある場合は、カンマで区切ります。

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

これは`The measurement is: 5h`と出力します。

## 文と式

Cairoの関数は、**文**と**式**から成り立っています。

- **文**は処理を実行しますが、値を返しません。
たとえば、`let x = 3;`は文です。
- **式**は評価されて値になります。
たとえば、`5 + 6`は`11`になります。

波括弧で囲まれたブロックも式であり、その最後の値が返されます。

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

ここでは、`y`に`4`が代入されます。

## 戻り値

関数は、`->`構文で戻り値の型を指定して、値を返すことができます。

既定では、関数は最後の式の値を返します。

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

これは`The value of x is: 5`と出力します。

もっと複雑な場合は次のようになります。

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

これは`The value of x is: 6`と出力します。

最後の式の末尾にセミコロンを付けないように注意してください。セミコロンを付けると式が文になり、関数は期待した値ではなく`()`（ユニット型）を返すようになります。
