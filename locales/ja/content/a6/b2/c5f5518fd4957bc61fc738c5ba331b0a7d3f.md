# はじめに

## 真と偽

Common Lispでは、`()`以外のすべての値が「真」とみなされます。`()`だけが「偽」です。
特別な定数シンボルとして`t`と`nil`があり、それぞれの値は真と偽です。

## 条件式

Common Lispにはいくつかの条件式があり、主な違いは扱える分岐の数です。

- `when`と`unless`では、分岐は1つだけです。

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

テスト式の後ろには、複数の式を書くこともできます。

- `if`は、おなじみのif-then-else構文を提供します。

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

then節とelse節はどちらも、1つの式しか書けないことに注意してください。

- `cond`を使うと、`if`式を入れ子にすることなく、複数の分岐を書けます。

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

テスト式の後ろに書ける式の数に制限はないことに注意してください。

- `case`は、おなじみの「switch」スタイルの構文を提供します。1つの値を複数の分岐と照らし合わせて調べます。

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

`cond`と同様、テスト式の後ろに書ける式の数に制限はないことに注意してください。
