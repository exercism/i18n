# はじめに

Haxeのプロパティは、クラスのメンバーであり、そのクラス内のデータへのアクセスを提供します。呼び出し側は、そのデータを設定したり取得（get）したりできます。プロパティは、setアクセサとgetアクセサのどちらか一方、または両方で構成されます。

プロパティは、他のクラスメンバーと同じようにアクセス修飾子（`public`、`private`など）を持ちますが、setアクセサはgetアクセサとは独立したアクセスレベルを持てますし、その逆も同様です。プロパティが両方のアクセサを持たなければならないわけではなく、片方（getまたはset）だけでもかまいません。

読み取りアクセスと書き込みアクセスは、次の例のように、構文にそのまま表れます。

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default`と`null`は、どちらも特別な**アクセス識別子**です。アクセス識別子は、フィールドを読み取るとき（1つ目の識別子）と、フィールドに書き込むとき（2つ目の識別子）の動作を設定します。指定できる値は次のとおりです。

- `default`：フィールドが`public`であれば、通常のフィールドアクセスを許可します。
- `null`：定義しているクラスの中からのみアクセスを許可します。
- `get/set`：アクセスは、アクセサメソッド（`get_x()`）の呼び出しとして生成されます。
- `dynamic`：`get/set`と同じですが、アクセサメソッドが存在するかどうかは確認できません。
- `never`：一切アクセスを許可しません。

完全な例を次に示します。

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
