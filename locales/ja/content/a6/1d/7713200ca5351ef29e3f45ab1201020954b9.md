# 繰り返し

プログラミングにおいて、[繰り返し][iteration]とは、コードのブロックを何度も繰り返す処理を指します。
これは`while`ループや`until`ループといった仕組みを使って行えます。
自分自身を呼び出す関数である再帰を使うことでも行えます。

しかし、最もよくあるのは、`Array`や`Range`、`String`のような要素のまとまりを繰り返し処理したい場合です。
Crystalの`Array`クラスと`Range`クラスはどちらも[`Enumerable`][enumerable]モジュールをインクルードしており、このモジュールは要素を繰り返し処理するためのメソッドを多数提供しています。
一方、`String`クラスは文字を繰り返し処理するための独自のメソッドを持っています。

また、Crystalには他の言語のような`for`文はありません。
その代わりに、繰り返し処理に使えるいくつかのメソッドがあります。

## 繰り返し処理

まとまりを繰り返し処理する最も一般的な方法は、[`each`][each]メソッドを使うことです。このメソッドは、まとまりの各要素をブロックに渡します。
これは`Range`を使えば簡単に行えます。
たとえば、1から3までループしたいときは、`each`メソッドを使ってその範囲を繰り返し処理できます。

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

さらに簡単に、決まった回数だけ繰り返したいだけであれば、`Int`クラスにある[`times`][times]メソッドを使えます。

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## `String`の繰り返し処理

`String`は文字の並びであり、`Enumerable`モジュールには属していません。そのため、文字を繰り返し処理するための独自のメソッドを持っています。
`String`を繰り返し処理する最も一般的な方法は、[`each_char`][each_char]メソッドを使うことです。このメソッドは`String`内の各文字をブロックに渡します。

~~~~exercism/note
`each_char`メソッドがブロックに渡すのは`Char`オブジェクトで、`String`オブジェクトではありません。
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String`を繰り返し処理するもう一つの方法は、[`each_line`][each_line]メソッドを使うことです。
このメソッドは、ファイルを1行ずつ読み込むときによく使われます。

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## `Enumerable`モジュールをインクルードしたオブジェクトの繰り返し処理

[`Enumerable`][enumerable]モジュールは、まとまりの要素を繰り返し処理するためのメソッドを多数提供しています。
`Enumerable`モジュールをインクルードするまとまりには`Array`、`Range`、`Hash`、`Set`などがあり、後者については今後の概念で扱います。

`Array`を繰り返し処理する最も一般的な方法は、[`each`][each]メソッドを使うことです。このメソッドは`Array`内の各要素をブロックに渡します。

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### map

[`map`][map]メソッドは`Array`を繰り返し処理するもう一つの方法で、各要素にブロックを適用した結果を含む新しい`Array`を返します。
`each`メソッドに似ていますが、変換された要素を持つ新しい`Array`を返します。
変換は、まとまりの各要素に関数を適用したいときに非常に便利で、よく使われる操作です。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if`のような制御フローを使えば、どの要素を変換するかを絞り込むこともできます。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## 省略記法

Crystalには、まとまりの各要素を繰り返し処理してメソッドを適用するための省略記法があります。
これは、1つのメソッドで変換するだけの単純なロジックを扱うときに便利です。
`&.`記法のあとにメソッド名を書くことで行えます。

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### インデックス付き

繰り返し処理している要素のインデックスを知りたいこともあります。その場合は[`each_with_index`][each_with_index]メソッドか[`map_with_index`][map_with_index]メソッドを使います。
これらのメソッドは各要素とそのインデックスをブロックに渡します。また、開始インデックスを指定するための省略可能な引数も受け取ります。

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

`String`オブジェクトには[`each_char_with_index`][each_char_with_index]メソッドも使えることに注意してください。

### sum

[`sum`][sum]メソッドはまとまりのすべての要素の合計を返します。合計する前に要素を変換するための省略可能なブロックも受け取ります。
合計の初期値を指定するための省略可能な引数も受け取ります。

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce]は、他の言語ではfoldとして知られているメソッドで、結合の仕方と初期値を使って、まとまりのすべての要素を1つにまとめます。
`reduce`メソッドにはブロックに渡されるアキュムレーターがあり、アキュムレーターは前回の繰り返しの結果です。
これは、まとまりのすべての要素を1つにまとめる再帰的な処理になります。

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce`は`sum`と似ているように思えるかもしれませんが、アキュムレーターの初期値と結合の仕方を指定できる分、`reduce`のほうが柔軟です。
`reduce`を使って`sum`や`count`などのメソッドを実装することもできます。
