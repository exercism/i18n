# 概要

Gleamは、Erlang仮想マシン（BEAM）でも、JavaScriptランタイムでも実行できます。これらのランタイムを使う言語はほかにもたくさんあり、そうした言語で書かれたコードをGleamから呼び出せると便利なことがよくあります。

Gleamの_外部関数_機能を使うと、他の言語で書かれた関数をGleamにインポートし、実行時のオーバーヘッドなしで呼び出せます。

GleamプロジェクトがErlang仮想マシン上で動いていて、Erlangの`lists`モジュールにある`reverse`関数を呼び出したい場合は、Gleamの関数ヘッドに`@external`属性を次のように追加します。

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

これは、通常のGleam関数と同じように呼び出せます。

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

このコードをJavaScriptランタイム向けにコンパイルしようとすると、JavaScript向けの実装がないため、エラーメッセージとともに失敗します。JavaScriptランタイム向けには、次のように別の実装を指定できます。

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

また、現在のコンパイル対象に対する外部実装がないときに使われるGleam実装を書くこともできます。

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
