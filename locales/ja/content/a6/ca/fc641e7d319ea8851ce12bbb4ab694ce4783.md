# はじめに

Common Lispのシンボルは、他の値、あるいは_キーワード_の場合はそれ自身を指すことができる特別な値です。
シンボルはLispによって評価されると、それが指す値に置き換えられます。

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

キーワードは先頭のコロン（`:`）で表されることに注意してください。

クォートとは、S式の前に`'`を付けることであり、Lispにその式を評価しないよう伝えます。
`defun`の例で`'foo`をクォートしたことで、Lispが`FOO`の指す先を探そうとして（見つからずに）失敗するのを避け、代わりに`FOO`という値そのものを返すようにしました。
プログラムのどこにも`FOO`が定義されていない場合は、次のようになります。

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

今のところは、関数からシンボルを返すための方法だとだけ考えておけば大丈夫です。ただ、クォートについてはまた後で取り上げ、その意味するところを今後の概念の演習でさらに掘り下げていきます。
