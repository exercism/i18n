# 概要

Rubyは動的型付け言語であり、強い型付けを持つ言語です。
動的言語では、変数やオブジェクトの型は実行時に決まります。つまり、その値や型は、最後の瞬間（インタプリターが解析するとき）まで変更できるということです。
では、強い型付けとはどういう意味でしょうか？
いったん変数やオブジェクトの型がわかれば、それを使って何ができるかについて、Rubyは厳格です。たとえば次のようになります。

```ruby
x = '2'
y = x + 'n'
# => '2n'
```

**しかし**

```ruby
x = '2'
y = x + 2
# => TypeError (no implicit conversion of Integer into String)
```

Rubyでは、すべてがオブジェクトであることを覚えておきましょう。
クラスでさえ、`Class`クラスのインスタンスです。

たとえば、次のとおりです。

```ruby
1.class
# => Integer

Integer.is_a?(Object)
# => true

Class.is_a?(Object)
# => true
```

つまり、次のようにクラスを定義することもできます。

```ruby
Car = Class.new do
  def run
    'running'
  end
end

Car.new.run
# => 'running'
```

最後に、`Integer`オブジェクトは1つ以上の（連続した）数字として定義できる値を保持しており、そのメソッドは多くの[数学演算子][integers-docs]をサポートしていることを覚えておきましょう。

[integers-docs]: https://docs.ruby-lang.org/en/master/Integer.html

~~~~exercism/note
ドキュメントでの説明では、インスタンスメソッドを`Class#method_name`のような構文で参照することがよくあります。一方、クラスやモジュールレベルのメソッドは`Class::method_name`として参照されます。
`::`は_スコープ解決演算子_と呼ばれ、参照しているクラスやモジュールレベルにある定数やメソッドを指します。
これはRubyのドキュメントや、メーリングリスト、その他のサポートの場で目にすることになります。
なお、この文章では、クラスやモジュールのメソッドを`ClassName.method_name`や`ModuleName.method_name`として参照しています。
~~~~
