# 説明

誰がどの料理を作り、誰がどの飲み物を持ってくるのかは正確にはわかりませんが、次のことはわかっています。

1. AishaはTagineを作ります。
2. EmmaはAmasiを持ってきます。
3. Frybreadを作る料理人はTonicを持ってきます。
4. MeiはLassiを持ってきます。
5. WinonaはPad Thaiを作りません。
6. Lassiを持ってくる料理人はBiryaniを作りません。

これらの手がかりをもとに、次のことを導き出しましょう。

- Aishaが持ってきた飲み物
- Emmaが作った料理
- Meiが作った料理
- Winonaが作った料理
- Winonaが持ってきた飲み物
