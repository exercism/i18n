# ヒント

ここにあるすべてのタスクでは、`print`コマンドが必要です。
```awk
{print "something", "something else"}
```

## 1. ユーザー名を一覧表示する

* フィールド区切り文字を定義するには、[`FS`変数][var-fs]を使います。

## 2. 行番号を出力する

* 行番号を取得するには、[組み込み変数`NR`][var-nr]を使います。

## 3. 無効なホームディレクトリを持つレコードを出力する

* ホームディレクトリは6番目のフィールドです。
* 与えられた`startsWith`関数を使います。
* [真偽値演算子][boolean-ops]を使います：`&&`、`||`、`!`。

## 4. bashを使う有効なユーザーの人数を出力する

* ログインシェルは最後のフィールドです。[`NF`変数][var-nf]を使うことができます。
