# はじめに

F#でコードを条件付きで実行する最も一般的な方法は、`if/elif/else`式を使うことです。

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

`if/elif/else`式で使われる条件は、`bool`型でなければなりません。F#には真と評価される値という概念はありません。
