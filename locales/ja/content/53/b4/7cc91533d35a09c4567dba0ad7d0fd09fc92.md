# 範囲

[範囲][range]は、2つの値の間の区間を表します。
範囲をサポートするもっとも一般的な型は`Integer`と`String`です。
これらは、コレクションを手早く作ったり、文字列を切り出したり、ある値が範囲に含まれているか確認したり、繰り返し処理を行ったりと、さまざまなことに使えます。
範囲は、範囲演算子`..`または`...`（それぞれ終端を含む場合と含まない場合）を使って作成します。

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

範囲演算子が2つあるのは、終端の値を含む範囲と含まない範囲を作れるようにするためです。これは、たとえば0から始まるインデックスを扱うときに便利です。

`Range`のイニシャライザーを使って範囲を作ることもできます。

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Rubyで範囲演算子`..`や`...`を使って範囲を作り、その範囲に対してメソッドを呼び出したいときは、範囲を括弧で囲む必要があります。
そうしないと、メソッドが範囲演算子の2番目の引数に対して呼び出されてしまうからです。

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## 部分文字列を取り出す

文字列を切り出したいときは、範囲演算子を使って部分文字列を取得できます。つまり、部分文字列の開始インデックスと終了インデックスで範囲を作ります。

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

負のインデックスを使うと、文字列の末尾から部分文字列を取得することもできます。

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 範囲のメソッド

範囲には、それを扱うためのメソッドがいくつか用意されています。たとえば、範囲内のすべての値の合計を求めたり、範囲にある値が含まれているかを確認したりできます。

| メソッド                | 説明                                                                    | 例                              |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | 範囲内のすべての値の合計を返します                                      | `(1..5).sum # => 15`            |
| [`size`][size]          | 範囲のサイズを返します                                                  | `(1..5).size # => 5`            |
| [`include?`][indlude]   | 範囲に指定した値が含まれていれば`true`、そうでなければ`false`を返します | `(1..5).include?(3) # => true`  |

## 終わりのない範囲と始まりのない範囲

範囲は、終わりがないものにも、始まりがないものにもできます。終わりのない範囲や始まりのない範囲では、開始値または終了値が`nil`になりますが、範囲を定義するときには`nil`を省略できます。

始まりのない範囲や終わりのない範囲は、たとえば文字列を先頭から、あるいは末尾まで切り出したいときに便利です。

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
コレクションに対して使わない場合、注意しないと、終わりのない範囲が終わりのない並びを引き起こすことがあります。
~~~~

## 文字列の範囲

文字列も範囲に使うことができ、2つの文字列の間にある文字列の区間を取得できます。特定の文字列を使うと、その振る舞いが少し意外なものになることがあるので、注意して使ってください。

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
