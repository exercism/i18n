# 説明の補足

## レジスター

| レジスター | 用途         | 型      | 説明                                |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 入力         | 整数    | 素因数分解する自然数                 |
| `$a1`    | 入力/出力    | アドレス | 素因数の格納先となる配列             |
| `$v0`    | 出力         | 整数    | 素因数の個数                         |
| `$t0-9`  | 一時的       | 任意    | 一時的な保存に使う                   |
