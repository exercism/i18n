# 余り

Crystalでは、余りを使った比較もまったく問題なく書けますが、割り算の余りを比較するなら[`divisible_by?`][divisible_by]メソッドを使うほうが読みやすくなります。
ある数が奇数か偶数かを調べたいときは、さらに[`odd?`][odd?]と[`even?`][even?]メソッドを使うのがおすすめです。

例えば、次のとおりです。

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```

[odd?]: https://crystal-lang.org/api/Int.html#odd%%3F%%3ABool-instance-method
