# 概要

シーケンスをたどるとき、要素だけでは足りないことがあります。位置も必要なのです。Factorの*インデックス付き*繰り返しワードを使えば、要素ごとのquotationに要素とインデックスの両方が渡され、インデックスはスタックの一番上に置かれます。`times`は、元になるシーケンスを使わずに回数を指定して繰り返すための関連ワードです。

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| ワード       | スタック効果                                                         |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`（ただし、後述の注意点があります）            |

`times`には注意すべき点があります。quotationのスタック効果は`( -- )`と記載されていますが、このワードは`inline`なので、`( str -- str )`のようにスタック効果のつり合いが取れたquotationも問題なく動作し、繰り返しの間でスタックが引き継がれます。こうすると、書き換え可能な状態を一切使わずに、回数を重ねて値を蓄積できます。

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

このやり方は`each-index`と`map-index`でも同じように使えます。宣言されている要素ごとのスタック効果は*最小限*を示すものであって、上限ではありません。
