# インストール

## .NET 10をインストールする

Visual Basicトラックでは.NET 10を使います。
手元で演習をビルドしてテストするには、お使いのオペレーティングシステム用の[.NET 10 SDK][install-sdk]をインストールします。
インストールするのはランタイムだけでなく、SDKです。

## インストールを確認する

新しいターミナルを開いて、次のコマンドを実行します。

```bash
dotnet --version
```

このコマンドは`10.0.0`以降を出力するはずです。

## エディターのサポート

演習を解くのに必要なのは、.NET SDKと、余計な機能のないテキストエディターだけです。
コード補完やデバッグといった、より高度な機能が欲しい場合は、次のエディターを検討してみましょう。

- Windows向けの[Visual Studio 2026][visual-studio]
- Windows、Linux、macOS向けの[Visual Studio Code][visual-studio-code]
- Windows、Linux、macOS向けの[JetBrains Rider][rider]

[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
