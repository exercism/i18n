# 概要

固定された定数値の集合を扱うときは、[列挙型][enumeration types]を使うことができます。`enum`を使うと、定数値を型安全に扱えるようになります。列挙型を定義するには、`enum`キーワードを使います。列挙型のメンバーは、列挙型名とドットを前に付けて参照します（例：`Status.Active`）。

各列挙型メンバーは、名前と`int`値の組み合わせです。最初のメンバーに明示的な値がない場合、その値は`0`に設定されます。列挙型メンバーに値が明示的に定義されていない場合、その値には前のメンバーの値に`1`を加えた値が自動的に割り当てられます。

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

列挙型はとても宣言的です。次の2つのメソッド呼び出しを比べてみましょう。

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

コードを読む人にとっては、2番目のバージョン（列挙型を使ったもの）のほうが理解しやすいでしょう。

## 数値型の列挙型

値の既定の数値型は`int`ですが、他の[整数数値型][integral numeric]を明示的に指定することで変更できます。

次の列挙型は、値に`byte`数値型を使います。

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## 列挙型メンバーへの変換

真偽値のようなものを表現したいときは、常に列挙型の使用を検討しましょう。前述の読みやすさの利点に加えて、列挙型には真偽値にはない利点があります。列挙型にはいつでも新しい値を追加できますが、真偽値は`true`か`false`しか取れません。そのため、列挙型を使うほうが将来性があります。

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

整数値を列挙型にキャストすることは_できます_が、その整数値がどの列挙型の値にも対応しない場合、予期しない結果になることがあります。

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## 列挙型のパース

名前をもとに文字列を列挙型メンバーに変換したいときは、[`Enum.Parse`][enum parse]を使うと便利です。

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

名前や値が列挙型に存在するかどうかを確認するには、[`Enum.TryParse`][enum tryparse]または[`Enum.IsDefined`][enum isdefined]を使います。どちらも、その列挙型メンバーが存在するかどうかを示す真偽値を返します。

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
