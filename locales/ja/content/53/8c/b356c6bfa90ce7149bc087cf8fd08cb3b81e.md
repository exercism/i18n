# インストール

## Clojure CLIのインストール

Clojureは、対話型REPL（Read-Eval-Print Loop）の実行、Clojureプログラムの実行、Clojure式の評価といったコマンドラインツールを提供しています。
演習では、Clojure CLIを使うことをおすすめします。[Clojure CLI](https://clojure.org/guides/deps_and_cli)をインストールするには、次の手順に従ってください。

### Windows
Windowsでのインストール手順は、[Clojure CLIのインストール](https://clojure.org/guides/getting_started#_installation_on_windows)を参照してください。

### Linux
ほとんどのプラットフォームでのインストール手順は、[Clojure CLIのインストール](https://clojure.org/guides/getting_started#_installation_on_linux)を参照してください。

### Mac OS XでのHomebrew
Homebrewを更新します。

``` bash
$ brew update
```

Clojure CLIをインストールします。
``` bash
$ brew install node clojure/tools/clojure
```

`Node`はnode環境に必要です。

## インストールの確認

正しくインストールされたかを確認するには、`clojure --help`を実行します。すべてうまくいっていれば、バージョンが表示されます。

```bash
$ clojure --help
Version: 1.10.1.547
...
```
