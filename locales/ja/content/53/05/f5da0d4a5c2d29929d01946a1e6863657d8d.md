# テスト

解答をテストするには、次のコマンドを実行するだけです：

```bash
make test
```

これは、テストファイル`<exercise-name>-test.ys`を実行します。このファイルには、解答を正しいものにするために通す必要のあるテストがすべて含まれています。
解答が何をする必要があるのかを正確に理解するために、テストファイルをよく読んでください。

> 注意：`make test`を初めて実行するときは、正しいバージョンの`ys` YAMLScriptインタプリターが正しい場所にインストールされていることも確認します。

ファイルを変更する前に`make test`を実行すると、すべてのテストが失敗します。
これは正しい、想定どおりの動作です。
通常の演習の進め方は、解答を少しずつ改善し、変更のたびに`make test`を実行して、すべてのテストが通るまで繰り返すというものです。

解答の特定の部分に集中していて、そのテストだけを実行したい場合は、そのテストに次のキーと値のペアを追加します：

```yaml
  ONLY: true
```

解答の別の部分に取り組んでいて、特定のテストをスキップしたい場合は、それらのテストに次のキーと値のペアを追加します：

```yaml
  SKIP: true
```


## テストの前提条件

YAMLScriptは現在、MacOSとLinuxで動作します。

お使いのコンピューターには、次のごく一般的なコマンドがインストールされている必要があります：

* `bash` - どのシェルでもテストを実行できますが、`bash`が利用できる必要があります。
* `make` - テストを実行するにはGNU `make`を使う必要があります。
  環境によっては、`make`とは別の名前になっているかもしれません。
  おそらく`gmake`です。
* `prove` - このプログラムは、通常のPerlのインストールに含まれています。
* `curl` - `ys`がまだインストールされていない場合に、インストールするために使われます。

これらのプログラムは、すでにすべてインストールされている可能性が非常に高いです。
