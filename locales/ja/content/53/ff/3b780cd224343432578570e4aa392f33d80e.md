# 概要

ほとんどのプログラミング言語と同じように、Gleamにも「副作用」があります。副作用とは、関数が値を返すだけでなく、世界の状態を読み取ったり変更したりできるということです。

Gleamの標準ライブラリにある`gleam/io`モジュールには、文字列をコンソールに出力する関数が用意されています。

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

他のパッケージが別のIO関数を提供していることもあります。たとえば`simplifile`は、ファイルの読み書きを行う関数を提供するパッケージです。

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
