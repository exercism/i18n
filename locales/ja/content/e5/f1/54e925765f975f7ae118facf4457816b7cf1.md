# はじめに

Juliaの`String`は、文字を順番に並べたものです。マニュアルにも書かれているとおりです。「もちろん、本当に厄介なのは『文字とは何か』と問い始めたときです」。

この複雑さの多くは`Chars`のコンセプト演習でより詳しく扱いますが、手短に言うと次のとおりです：

- Juliaの文字列はすべてUnicodeです。
- ASCIIでもある文字列（英語の大文字・小文字のAからZ、数字、そしていくつかの句読点）は、扱うのが_簡単_です。
- それ以外の世界のほとんどの文字体系も扱うことは_可能_ですが、より注意が必要です。

## 文字列リテラル

一般に、文字列は二重引用符`" "`で囲みます。
一重引用符`' '`は`Chars`にだけ使います。

三重の二重引用符`""" """`を使うこともできます。これを使うと、文字列の中の`"`をエスケープせずに使えます。
さらに重要なのは、複数行の文字列から余分なインデントが取り除かれることです。

```julia-repl
julia> """
       Multiline
       
       """
"Multiline\nString\n"
```

### 文字のエスケープ

C以降のほとんどの言語と同じく、Juliaはエスケープにバックスラッシュ`\`を使います：

1. 先ほどの例の改行`\n`のような、表示されない文字を入力するためです。
2. `\$`（後述）のように、そうしなければ特別な意味を持ってしまう文字を守るためです。

## インデックス

原則として、文字列はベクトルとまったく同じようにインデックスできます：

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

「Julia」のようなASCII文字列なら問題なく動きますが、それでは世界のほとんどの言語を無視することになります。

約15世紀前に古英語で書かれた『ベオウルフ』の文字を1つ考えてみましょう。

「Hrōðgār」は明らかに7文字ですが、そのすべてがASCIIというわけではありません。

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

このように文字列をインデックスしていくと、最初はうまくいきますが、どこかで破綻します：

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

問題は、この種のインデックスが_バイト_を数えていることです。非ASCIIの文字列では、バイトと文字は1対1の関係にはありません。
Unicode/UTF-8の文字を表現するには最大4バイト必要になることがあり、この点は`Chars`のコンセプト演習でさらに掘り下げます。

## 文字列の組み立て

### 連結

多くの言語では文字列の連結演算子として`+`を使いますが、Juliaは違います。
せめてエラーメッセージは役に立ちます。

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

`string()`関数は、任意の数の文字列を連結します。

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

`join()`関数も同じことができ、さらに文字列のベクトルを受け取って、指定した区切り文字（デフォルトは`""`）で連結します。

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

文字列はイミュータブルで、連結にはコピーが伴うことに注意してください。
そのため、ループの中で連結を繰り返すのは非効率で、断片をベクトルに集めておいて最後にまとめて`join`するほうがよいです。

### 繰り返し

簡単です：

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### 補間

多くの言語には、計算した値を文字列に埋め込む方法がありますが、最適な構文については驚くほど意見が分かれています。

Juliaでは、埋め込む値の前に`$`を付けます。

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

省略すると曖昧になる場合は括弧（`()`）が必要ですが、空白が続く単一の識別子なら省略できます。

文字列に$を含めるには、`\$`とエスケープします。

現時点では、補間で表示する小数点以下の桁数などの書式設定ができないという制限があることに注意してください。

### `@sprintf()`

文字列の組み立てをより細かく制御するために、JuliaはCから`sprintf`関数を取り入れています（後発の言語の多くも同様で、Wikipediaには約30言語が挙げられています）。

Juliaでは、これは`Printf`モジュール内の`macro`として実装されているため、`@`が頭に付きます。

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## 文字列の関数

話を簡単にするため、このセクションでは新しい文字列を返し、入力を変更しない関数に絞ります。
多くには、`!`を付けた名前の、入力をその場で変更する同等の関数があります。

### 長さ

文字列の長さはどれくらいでしょうか？
数え方によって変わることがあります。

単純なのはASCII文字列で、どの文字も1バイトを占めます。

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

`length()`関数は_文字_の数を返し、`sizeof()`関数は_バイト_の数を返します。

この違いは、他の文字集合では重要になります：

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### 分割

プログラミングでよくある操作は、長い文字列を、1文字以上の区切り文字列をもとに分割することです。

最も一般的には`split()`関数を使います。
区切り文字はデフォルトで（任意の）空白ですが、別のものも指定できます。

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

これらの例は文字列をより小さな_文字列_に分割しています。
文字列を_文字_に分けるのは別の操作です。

### 検索と置換

文字列に指定した部分文字列が含まれているかどうかを調べるにはどうすればよいでしょうか？
奇妙なことに、これを調べる関数は2つあります。`occursin()`と`contains()`は引数の順序だけが違います。

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

位置をより詳しく調べるには：

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

部分文字列の開始:終了のインデックスを得るには、いくつかの関数があります：

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

部分文字列を置換するには、`x => y`構文で変更を並べます。

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

Julia 1.7以降、`replace`関数は任意の数の変更を受け取ることができ、置換の間にどの文字も一度しか変更されないことが保証されています。

`x => y`構文は`pair`と呼ばれ、Juliaで重要な型です。これについては`Dicts and Pairs`のコンセプト演習で詳しく扱います。

### 空白

文字列の先頭や末尾の空白を取り除きたいことがよくあります。

そのための関数は`lstrip()`（左）、`rstrip()`（右）、`strip()`（両方）です。

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### 大文字・小文字の変換

これらの関数は名前を見ればほぼわかります：

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
