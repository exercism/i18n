# テスト

どの演習でも、次の一般的な手順が必要です。

まず、練習したい演習のディレクトリに移動します。ここでは`bob`の場合を見てみましょう。

```bash
$ cd </path/to/exercism>/lfe/bob
```

次にテストを実行します。`test`というmakeターゲットは`compile`に依存しているので、`make test`を実行すればソースが確実にコンパイルされてからテストの実行に進みます。


```bash
$ make test
```

おめでとうございます！　テストが失敗しています！！！

では、すべてのテストに通るようにするには何をすればよいのか、`README.md`を読んで確認しましょう。


テストが報告した最初のエラーを修正して、もう一度テストを実行します。

```bash
$ make test
```

そのまま続けて、ソースコードの次に失敗しているテストを修正し、すべてのテストが通るまでテストを実行します。

すべてのテストが通ったら、`src`ディレクトリにある自分のコードを最後にもう一度見直して、納得のいくものになっていることを確認し、レビューのために提出しましょう。

フィードバックを受け取り、解答を修正し、提出し、次の演習に挑戦します。LFEの悟りを開くまで、これを繰り返しましょう。
