# 説明

この演習では、友人が開発している新しいRPGゲームのクエストのロジックを実装します。ゲームの主人公はアナリン。勇敢な少女で、獰猛（どうもう）ですが忠実な飼い犬を連れています。ところが不幸が訪れます。森で木の実を探していた親友が誘拐されてしまったのです。アナリンは親友を見つけて助け出そうとします。このクエストに飼い犬を連れていくかどうかは自由です。

親友の跡をしばらく追ったあと、アナリンは親友が囚われている野営地を見つけます。誘拐犯は2人いることがわかります。強力な騎士と、ずる賢い弓兵です。

誘拐犯を見つけたアナリンは、次の行動のうちどれを実行できるかを考えます。

- 速攻：騎士が眠っていれば速攻できます。鎧を着るのに時間がかかるため、騎士は無防備になるからです。
- スパイ：グループのうち少なくとも1人が起きていれば、スパイできます。そうでなければ、スパイは時間の無駄です。
- 囚人への合図：囚人が起きていて弓兵が眠っていれば、鳥の鳴き声を使って囚人に合図できます。弓兵は鳥の合図の訓練を受けているため、メッセージを傍受されるおそれがあるからです。
- _囚人の解放_：アナリンは、囚人を解放するために野営地に忍び込むことを試せます。
  これは危険な行為で、次の2つの場合にしか成功しません。
  - アナリンが飼い犬を連れている場合、弓兵が眠っていれば囚人を救出できます。
    騎士は犬を恐れており、弓兵が準備を整える前に、アナリンと囚人は逃げ出すことができるからです。
  - アナリンが犬を連れていない場合は、アナリンと囚人はとても慎重に行動しなければなりません！
    囚人が起きていて、騎士と弓兵の両方が眠っていれば、アナリンは囚人を解放できます。しかし囚人が眠っていると救出できません。アナリンの突然の登場に囚人が驚き、騎士と弓兵を起こしてしまうからです。

タスクは4つあります。森で見つけた3人の状態と、アナリンの飼い犬がいるかどうかに基づいて、上記の各行動が可能かどうかを判定するロジックを実装します。

## 1. 速攻できるかどうかを確認する

騎士が起きているかどうかを示す真偽値を受け取る`canFastAttack()`メソッドを実装します。このメソッドは、騎士の状態に基づいて速攻できる場合に`true`を返し、そうでなければ`false`を返します。

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. グループをスパイできるかどうかを確認する

騎士、弓兵、囚人がそれぞれ起きているかどうかを示す3つの真偽値を受け取る`canSpy()`メソッドを実装します。このメソッドは、3人の状態に基づいてグループをスパイできる場合に`true`を返し、そうでなければ`false`を返します。

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. 囚人に合図できるかどうかを確認する

弓兵と囚人がそれぞれ起きているかどうかを示す2つの真偽値を受け取る`canSignalPrisoner()`メソッドを実装します。このメソッドは、2人の状態に基づいて囚人に合図できる場合に`true`を返し、そうでなければ`false`を返します。

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. 囚人を解放できるかどうかを確認する

4つの真偽値を受け取る`canFreePrisoner()`メソッドを実装します。最初の3つの入力は、騎士、弓兵、囚人がそれぞれ起きているかどうかを示します。最後の入力は、アナリンの飼い犬がいるかどうかを示します。このメソッドは、3人の状態とアナリンの飼い犬の有無に基づいて囚人を解放できる場合に`true`を返し、そうでなければ`false`を返します。

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
