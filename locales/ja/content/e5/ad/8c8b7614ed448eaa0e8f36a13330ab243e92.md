# テスト

テストは、次のコマンドで実行します。

```shell
npm run test
```

また、Jestを「watch」モードで実行することもできます。このモードでは、コードやテストモジュールを保存すると、テストが自動的に再実行されます。

```shell
npm run watch
```

## スキップされるテストを理解する

`skip`メソッドは、テストスイートにテストを実行しないよう指示します。この関数は、次の別名でも使えます：`it.skip(name, fn)`、`xit(name, fn)`、`xtest(name, fn)`

- なぜスキップされるのでしょうか？

利用者が一度に1つのテストに集中でき、解答を発展させながら1つずつ有効にしていけるようにするためです。

- どうすれば有効にできるのでしょうか？

`xtest`を`test`に変更します。

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
