# 指示の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                            |
| -------- | --------- | ------- | -------------------------------------- |
| `$a0`    | 入力     | アドレス | 2進数の文字からなるヌル終端文字列 |
| `$v0`    | 出力     | 整数 | 入力文字列の10進数の値          |
| `$t0-9`  | 一時利用 | 任意     | 一時的な保存に使われる             |
