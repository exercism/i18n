# はじめに

*正規表現*（regex）は、あるテキストがどんな形であるべきかを表す小さなパターンです。文字列を1文字ずつ自分で調べる代わりに、望む形を一度書いて、マッチングはFactorに任せます。Factorの正規表現ツールは、[`regexp`][regexp]というvocabularyにあります。

## パターンを書く

Factorでは、正規表現を`R/ `と`/`の間に書きます。

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

パターンの中のほとんどの文字は、それ自身を意味するだけです。`R/ cat/`は`cat`というテキストにマッチします。正規表現の力は、文字の*種類*や、その*個数*を表すいくつかの特別な記号から生まれます。

### 文字クラス：「集合の中から1文字」

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

クラスは*1文字*だけにマッチします。`[A-Z]`は`Q`にはマッチしますが、`QQ`にはマッチしません。

### 量指定子：「何回繰り返すか」

これらのどれかを断片の*後ろ*に置くと、それが何回繰り返せるかを指定できます。

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

つまり、`\d{4}`は4桁の数字が連続したものを意味し、`[A-Z]+`は1つ以上の大文字を意味します。これらを組み合わせると、`R/ [A-Z]+-\d+/`は「1つ以上の大文字、ダッシュ、そして1つ以上の数字」という形、つまり`SALE-2024`のようなテキストを表します。ここでの`-`は普通の文字です。`[ ]`の外側では、ダッシュはただのダッシュにマッチします（クラスの中、たとえば`[A-Z]`では、範囲を表します）。

## 文字列全体にマッチさせる

`matches?`は、「この文字列*全体*がパターンに当てはまるか？」に答えます。パターンは最初から最後まで、すべての文字を説明できなければなりません。

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

`SALE-2024`が`"GET SALE-2024"`の中にあるとしても、`matches?`はやはり`f`を返します。余分な文字も文字列の一部であり、パターンに当てはまらないからです。パターンが*どこか*に現れるかどうかだけを知りたいときは、`re-contains?`を使います。これは、`matches?`が`f`を返したまさにその場面で`t`を返します。

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## 長いテキストの中からマッチを見つける

`re-contains?`は、パターンがそこにあるか*どうか*しか教えてくれません。次に紹介するワードは、中を調べて*何が*マッチしたかを報告します。`all-matching-subseqs`はマッチしたすべての箇所を文字列のシーケンスとして返し、`count-matches`はその数を数えるだけです。

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## マッチを置き換える

`re-replace`は、すべてのマッチを置換テキストと入れ替え、新しい文字列を返します。

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

`regexp`vocabularyには、ほかにも知っておくとよいワードがあります。詳しくはリンクをたどってください。[`first-match`][first-match]（最初のマッチだけ）と、[`re-split`][re-split]（パターンにマッチする箇所で文字列を分割）です。
