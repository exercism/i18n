# ヒント

正規表現のスキルにかなり自信があるのでなければ、[Regex101][regex101]のようなオンラインプレイグラウンドで構文を試してみるとよいでしょう。

フレーバーをPCRE2に設定するのを忘れないでください。

各正規表現をあらかじめ`const`として定義しておくと、わかりやすさとパフォーマンスの面で役立つスタイルになります。

## 1. 有効なコマンドを確認する

- 文字列の先頭を表すアンカー文字は`^`です。
- 正規表現の検索から必要なのは、`true`/`false`だけです。
- 正規表現を使わずに解くこともできますが、コンセプト演習の趣旨に沿って解いてみてください。

## 2. 暗号化された絵文字を削除する

- 単純な[`replace()`][replace]を使います。

## 3. 有効な電話番号を確認する

- より長く、かなり繰り返しの多い正規表現が必要です。
- `n`回の連続は`{n}`という構文で指定できます。
- マッチに必要なのは、`true`/`false`だけです。

## 4. ウェブサイトのリンクを取得する

- ドットは`\.`でエスケープするのを忘れないようにしましょう。
- ドットより前の部分を[match][match]でキャプチャします。

## 5. ユーザーに挨拶する

- 名前付きキャプチャを使った`replace()`は、`r"(?<name>...) " => s"\g<name>... "`という形式です。
- ここでも`split()`で解けますが、正規表現の練習にはなります。
