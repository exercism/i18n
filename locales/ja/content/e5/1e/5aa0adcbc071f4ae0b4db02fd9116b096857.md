# 説明の補足

~~~~exercism/note

上の説明では、[_数学的な集合_][math-sets]について触れましたが、ピタゴラスの三つ組 {a, b, c} は_**必ず**_ a < b < c の順（_昇順_）で並んでいなければならないとも述べています。 

そのため、Pythonの[`set`型][python-sets]はこの演習には向いていません。`set`は本質的に_順序を持たない_からです。 
代わりに、[`list`][python-list]の`list`を返してください（_例えば`[[a, b, c]]`_）。 
三つ組自体はどのような順序で生成してもかまいません。外側の`list`の順序はテストでは無視されるからです。 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
