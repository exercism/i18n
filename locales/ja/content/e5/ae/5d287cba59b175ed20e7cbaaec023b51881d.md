# はじめに

## 一般的な構文

`for`ループは、同じ処理を繰り返し実行するためによく使われる文の1つです。Goでは、`for`キーワード、ヘッダー、そして波括弧で囲まれたループ本体を含むブロックからできています。ヘッダーは、セミコロン`;`で区切られた3つの要素、init・condition・postからなります。

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init**は、ループが始まる前に一度だけ実行されるコードです。
- **condition**は、真偽値に評価され、ループをいつ止めるかを制御する式でなければなりません。ループの中のコードは、この条件が`true`と評価されるかぎり実行されます。この式が`false`と評価された時点で、ループはそれ以上繰り返されません。
- **post**は、各繰り返しの最後に実行されるコードです。

**注意：** ほかの言語とは違い、ヘッダーの3つの要素を囲む括弧（`()`）はありません。むしろ、このような括弧を書くとコンパイルエラーになります。ただし、ループ本体を囲む波括弧（`{ }`）は常に必要です。

## `for`ループの例

ふつう、initではカウンター変数を用意し、conditionではループを続けるか止めるかを判定し、postでは繰り返しのたびに最後にカウンターをインクリメントします。

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

このループは`1`から`9`までの数値（`9`も含む）を出力します。ステップの指定は、上の例のように、インクリメントやデクリメントの文で行うことが多いです。
