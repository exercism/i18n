# 説明

2つの配列`A`と`B`が与えられたとき、次のどれに当てはまるかを判定してください。

- 配列`A`が配列`B`とequalである
- 配列`A`が配列`B`を含む（`A`は`B`のsuperlistである）
- 配列`A`が配列`B`に含まれる（`A`は`B`のsublistである）
- どれにも当てはまらない。つまり、配列`A`と`B`はunequalである

具体的には、2つの配列が同じ値と同じ順序を持っているとき、配列`A`は配列`B`とequalです。
`A`が`B`とequalな部分配列を含むとき、配列`A`は`B`のsuperlistです。
`B`が`A`とequalな部分配列を含むとき、配列`A`は`B`のsublistです。

例：

- `A = []`かつ`B = []`（どちらの配列も空）のとき、`A`と`B`はequalです
- `A = [1, 2, 3]`かつ`B = []`のとき、`A`は`B`のsuperlistです
- `A = []`かつ`B = [1, 2, 3]`のとき、`A`は`B`のsublistです
- `A = [1, 2, 3]`かつ`B = [1, 2, 3, 4, 5]`のとき、`A`は`B`のsublistです
- `A = [3, 4, 5]`かつ`B = [1, 2, 3, 4, 5]`のとき、`A`は`B`のsublistです
- `A = [3, 4]`かつ`B = [1, 2, 3, 4, 5]`のとき、`A`は`B`のsublistです
- `A = [1, 2, 3]`かつ`B = [1, 2, 3]`のとき、`A`と`B`はequalです
- `A = [1, 2, 3, 4, 5]`かつ`B = [2, 3, 4]`のとき、`A`は`B`のsuperlistです
- `A = [1, 2, 4]`かつ`B = [1, 2, 3, 4, 5]`のとき、`A`と`B`はunequalです
- `A = [1, 2, 3]`かつ`B = [1, 3, 2]`のとき、`A`と`B`はunequalです
