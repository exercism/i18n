# Entry API

Entry APIは、マップ構造の中身を操作するうえで、しばしばもっとも慣用的な方法です。ただし、Rustにしては珍しく、これはトレイトとして形式化されておらず、標準ライブラリのマップ型に実装された一連の型とメソッドにすぎません。

基本的に、`map.entry()`メソッドが提供するのは`enum`です：

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

その利便性は、この`enum`に実装されたさらなるメソッドから生まれます。たとえば、特定のキーに対応する値を取得し、必要に応じて変更したい場合で、その値の型のデフォルト値が適切であれば、次のように書くだけです：

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

カウンターのような用途では、これでとても楽ができます：

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

型のデフォルト値が用途に合わない場合は、`or_insert`で独自の定数のデフォルト値を渡すか、`or_insert_with`で計算した値を渡すことができます。

場合によっては、挿入が行われる可能性がある前に、既存の値に対して計算を行いたいことがあります。そうしたケースでは、`and_modify`を使います。ただし、この用途はややまれです。`and_modify`は、より一般的には、デリファレンスの必要性を避けるために使われます：

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

ときには、エントリーを直接`match`したいこともあります。それは次のように書けます：

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

詳しくは、[`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html)と[`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html)を参照してください。
