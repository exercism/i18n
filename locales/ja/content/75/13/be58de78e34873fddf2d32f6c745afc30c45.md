# はじめに

Factorの文字列は、文字のシーケンスです。`sequences`ボキャブラリのほとんどのワードがそのまま使えるほか、[`splitting`][splitting]や[`ascii`][ascii]などのボキャブラリにある、文字列を扱う専用のワードも使えます。

```factor
USING: ascii sequences splitting ;

"hello, world" .                  ! => "hello, world"
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
"WARNING" >lower .                ! => "warning"
"  spaced  " [ blank? ] trim .    ! => "spaced"
"warning" "(" ")" surround .      ! => "(warning)"
```

`split1`と`split`（[`splitting`][splitting]にあります）は文字列を切り分けます。`split1`は区切り文字が最初に現れる位置で、`split`は指定した文字のいずれかで切り分けます。`surround`と`glue`（[`sequences`][sequences]にあります）は文字列を組み立てます。`surround`は文字列を接頭辞と接尾辞で包み、`glue`は2つの文字列を区切り文字でつなぎます。[詳細](./about.md)ページには、文字列を扱う各ワードと、それが属するボキャブラリが並んでいます。

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[ascii]: https://docs.factorcode.org/content/vocab-ascii.html
