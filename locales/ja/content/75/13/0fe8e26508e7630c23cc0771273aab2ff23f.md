# ヒント

## 1. `Coord`型を定義する

- `Coord`は`struct`です。
- フィールドは`x`と`y`です。
- どちらも型は`UInt16`です。

## 2. `Plot`型を定義する

- `Plot`はキーワード`struct`です。
- フィールドは`bottom_left`と`top_right`です。
- どちらも型は`Coord`です。

## 3. 自分の請求がすでに登録されているか確認する

- その請求はすでに`register`の要素になっていますか？
- 必要なら[`Sets`][sets]の知識を復習しましょう。

## 4. 投機家は、角の座標で特定される区画を指定して請求を出すことができる

- 同じ請求がすでに登録されている場合は、自分の請求が失敗したことを示すために`false`を返します。
- 許可される場合は、自分の請求をregisterに追加します。[`push!()][push]関数が役立つかもしれません。
- `stake_claim!()`は値を変更する関数なので、`register`の変更は呼び出し元にも見えます。
- `claim.bottom_left.x`のように、ドット記法をつなげて書くこともできます。
- 成功したことを示すために`true`を返します。

## 5. 区画の長いほうの辺の長さを求める

- これらの長方形の区画の向きを思い出しましょう。`top_left`と`bottom_right`の座標は推測できます。
- 辺の長さの計算は簡単な算術です。
- [`max()`][max]と[`maximum()`][maximum]の違いに注意しましょう。`max`は比較する引数をいくつでも取れますが、`maximum`は1つのイテラブルを取ります。

```julia-repl
julia> max(1, 2, 3)
3

julia> v = [1, 2, 3];
julia> maximum(v)
3
```

## 6. 研究目的で、最も長い辺を持つ請求済みの区画を探す

- registerはSetで、順序はありませんがイテラブルです。
  - registerを順序のあるものに変換すると便利かもしれません。たとえば`collect()`を使います。
  - 区画の最も長い辺を計算する関数はすでに書いたので、それをコレクション全体に適用できます。
- `max`と`maximum`の違いについては、タスク5の注記を参照してください。
- 最大の長さを持つ区画を1つ以上見つけます。
- 結果を`Set{Plot}`として返します。
