# はじめに

`Option`は、関数の戻り値が有効かどうかを確認するために使う列挙型です。次のように定義されています。

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

これは`haxe.ds`パッケージの一部です。

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
