# 説明

Conda Airlinesは、プログラミングの世界で最大の航空会社で、1日に10,000便以上を運航しています！

現在、すべての座席を手作業で乗客に割り当てていますが、これを自動化する必要があります。

乗客の座席の割り当てを自動化するソフトウェアを作るよう依頼されました。
このソフトウェアには、メモリ効率と性能が求められます。

## 1. 座席の文字を生成する

Condaは、航空機の座席の文字を生成したいと考えています。
航空機は座席の列でできています。
各列には_4つの座席_があります。
各列の座席には、必ず`A`、`B`、`C`、`D`という名前が付いています。
列の最初の座席が`A`、2番目の座席が`B`、というようになります。
`D`の次は、また`A`から始まります。

生成する座席の文字の数を表す`int`を受け取る、`generate_seat_letters(<number>)`という関数を実装してください。
関数は、座席の文字の_イテラブル_を返すようにします。

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. 座席を生成する

Condaは、航空機の座席を指定された数だけ生成できるシステムを望んでいます。
各航空機の各列には_4つの座席_があります。
列は数字で表され、`1`から順に増えていきます。
座席は、`1A`、`1B`、`1C`、`1D`、`2A`、`2B`、`2C`、`2D`、`3A`、`3B`、`3C`、`3D`、…のように並びます。

例を示します。

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|      列      |  5  | 21  |
|  座席の文字   |  A  |  D  |
|    結果      | 5A  | 21D |

乗客の迷信から、多くの航空会社では、_13列目_の座席を設けていません。
Conda Airlinesもこの慣習に従っているため、_13列目_の座席は_生成しない_ようにしてください。

生成する座席の数を表す`int`を受け取る、`generate_seats(<number>)`という関数を実装してください。
関数は、生成した座席の_イテラブル_を返すようにします。

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. 乗客に座席を割り当てる

座席を生成する関数ができたので、それを使って乗客に座席を割り当てられます。

乗客の名前の`list`を受け取る、`assign_seats(<passengers>)`という関数を実装してください。
関数は、`passenger`を_キー_、`seat_number`を_値_とする_辞書_を返すようにします。

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. チケットコード

Conda Airlinesは、各チケットに固有のコードを持たせたいと考えています。
大手航空会社であるため、非常に多くの便があります。
つまり、同じ座席番号の便が複数存在します。
そこで、_12_文字の文字列で固有のチケットコードを生成するシステムを作ってほしいと考えています。

このコードは、`assigned_seat`に続けて`flight_id`を並べたものから始まります。
コードの残りの部分は`0s`で埋められます。

`seat_numbers`の`list`と、便番号を表す`string`を受け取る、`generate_codes(<seat_numbers>, <flight_id>)`という関数を実装してください。
関数は、`ticket_number`を生成する`generator`を返すようにします。

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
