# `match`式

`match`式は、値と条件を評価し、評価される式を返します。三項演算子と同じように、条件が一致しなければ、返される式は評価されません。条件が一致するかどうかは、同一性（厳密等価、つまり`===`）でチェックします。

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

等価（`==`）のチェックを行いたいときは、条件を次のように並べ替えます。

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

`match`式では、どの条件にも一致しなかった場合、`UnhandledMatchError`がスローされます。
