# 概要

Clojureは関数型言語なので、関数は第一級オブジェクトとして扱われます。つまり、関数はデータと同じように、他の関数に渡したり、他の関数から生成したりできます。Clojureには特に、既存の関数をもとに新しい関数を生み出す、豊富な高階関数が用意されています。ここでは、`partial`、`comp`、`memoize`、`juxt`という4つの重要な例を見ていきます。これらの関数を生成する関数は、より広い高階関数のカテゴリに属します。たとえば`map`、`reduce`、`apply`、`complement`などがあり、いずれも既存の関数を操作します。

## partial

一般に、既存の関数`my-function`が仮引数`p1, p2, ..., pN`を持つとき、その一部の仮引数`p1, p2, ..., pM`を定数`v1, v2, ..., vM`に固定できます。これは、次のように`partial`を適用することで行います: `(partial my-function v1 v2 ... vM)`。

結果は、`p1=v1, p2=v2, ..., pM=vM`と固定して元の関数`my-function`を適用する新しい関数です。この新しい関数は、`partial`を適用するときに値が指定されなかった残りの仮引数`pM+1, pM+2, ..., pN`を入力として受け取ります。

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

簡単な例として、渡された値に固定量の9を加える関数`inc-by-9`を定義してみましょう。この関数は次のように実装できます。

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

2つ目の例として、挨拶したい相手の名前と、最初と最後のテキストメッセージを使う関数`generic-greetings`があります。

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

そして`partial`を使って、常に特定の挨拶メッセージを使うようにします。

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp`を使うと、合成したい任意の数の関数を合成したものを作成できます。一般に、`N`個の関数`f1, f2, ..., fN`を合成するとは、それらの関数を順番に適用し、前の関数の出力を次の関数に渡すことを意味します。数学の記法では、次のように表されます。

```
f1 (f2 (... fN(x)))
```

Clojureでは、これは次のように書くのと同じです。

```clojure
(f1 (f2 (... (fN x))))
```

`comp`を使うと、この合成を行う新しい関数を作成できます。

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

例として、一連の数値を合計し、その結果を6倍したいとします。これは次のように書けます。

```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize`を使うと、特定の入力に対して以前計算した結果を再利用できます。同じ入力が与えられると、*メモ化された*関数は再計算せずに同じ結果を返します。これは、`clojure`の関数がデフォルトで*参照透過*である、つまり同じ入力に対して常に同じ出力を生成するという性質を利用しています。そのため、以前の計算を簡単に再利用できます。

この仕組みを確認するために、関数が出力を生成する前に2秒間スリープする、人工的なケースを使います。これにより、`memoize`を使う前後の*計算時間*を簡単に比較できます。

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt`は、渡された関数を左から右の順に適用する関数を生成します。結果は、各関数の個々の結果を要素とするベクトルです。

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

簡単な例として、xに2から5までの係数を順に掛けた積を計算する関数を生成します。

```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
