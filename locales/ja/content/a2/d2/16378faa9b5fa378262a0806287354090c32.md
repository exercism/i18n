# 概要

`Enum`は、列挙可能なデータを扱うためのアルゴリズムを集めた、とても便利なモジュールです。次のようなものがあります。

- 並べ替え（[`sort/2`][enum-sort/2]、[`sort_by/2`][enum-sort_by/2]）
- 絞り込み（[`filter/2`][enum-filter/2]）
- グループ化（[`group_by/3`][enum-group_by/3]）
- 数え上げ（[`count/2`][enum-count/2]）
- 検索（[`find/3`][enum-find/3]）
- 最小値・最大値の取得（[`min/3`][enum-min/3]、[`max/3`][enum-max/3]）
- 畳み込み（[`reduce/3`][enum-reduce/3]、[`reduce_while/3`][enum-reduce_while/3]）

ほかにもたくさんあります！　すべての一覧は[`Enum`モジュールのドキュメント][enum-functions]を参照してください。

## 列挙可能

一般に、_列挙可能_とは、繰り返し処理できるデータ、つまりコレクションのことです。Elixirでは、列挙可能とは、`Enumerable`[プロトコル][exercism-protocols]を実装したデータ型のことです。具体的には、次のとおりです。

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

まだすべてを知らなくても心配いりません。

自分で作ったデータ構造に`Enumerable`プロトコルを実装することもできます。

## Reduce

`Enum.reduce/2`を使うと、列挙可能なデータ全体を1つの値に_畳み込む_ことができます。そのために、_アキュムレーター_と呼ばれる特別な変数を使います。アキュムレーターは、繰り返しの間で畳み込みの中間状態を保持します。このことから、列挙可能なデータを扱ううえで最も強力な関数の1つになっています。ほかの多くの専門的な関数も、より汎用的な`reduce`で置き換えられます。たとえば…

最大値を求める場合：

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

マッピングもできます（ただし、あとで結果を逆順にする必要があります）。

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## マップのマッピング

- [`Map.new/2`][map-new]を使う場合：
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- [`Enum.into/3`][enum-into]を使う場合：
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- [`Enum.map/2`][enum-map]を使う場合：
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
