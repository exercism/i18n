# テスト

各演習にはテストファイルが含まれています。
テストは`bats`プログラムで実行します。
```bash
bats test-hello-world.bats
```

`bats`はインストールしておく必要があります。
お使いのシステムに`bats`をインストールする手順については、[Bashトラックのテスト][bash]ページをご覧ください。

### batsはbashで実装されています

batsファイルはbashスクリプトで、`bats`コマンドが認識する特別な関数をいくつか使っています。
次のようなテストが出てくるはずです。
```sh
gawk -f some-exercise.awk <<< "some,input,here"
```
この`<<<`構文は、bashの[Here String][here-string]です。
右側の文字列を、左側のプログラムの標準入力に送り込みます。
これは、次のコードと（[ほぼ][so]）同じです。
```sh
echo "some,input,here" | gawk -f some-exercise.awk
```

## assert関数のヘルプ

テストでは、[bats-assert][bats-assert]ライブラリの関数を使っています。
さまざまな`assert*`関数のヘルプは、そこで確認できます。

## スキップされるテスト

演習を解くというのは、その演習のテストをすべて通すことです。
デフォルトでは、テストを実行すると、最初の1つのテストだけが実行されます。
これは意図的なもので、その1つのテストを通すことに集中できるようになっています。
それが通ったら、次のテストを有効にできます。他のテストの前に付いている

    [[ $BATS_RUN_SKIPPED == true ]] || skip

という注釈をコメントアウトするか、削除してください。

## スキップを解除する

`skip`注釈が付いたテストも含めて、すべてのテストを実行するには、次のようにします。
```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

入力を省くためにラッパー関数を使うと便利です。`bash`では次のように書けます。
```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```
そうすれば、テストは次のコマンドだけで実行できます。
```bash
bats
```

## デバッグ出力

```exercism/caution
これはローカルの`bats`では動きますが、Exercismのオンラインエディターでは**動きません**。
```

テストを実行すると、`bats`は標準出力と標準エラー出力の両方を取り込み、期待される出力と比較します。
デバッグメッセージを標準出力や標準エラー出力に出力すると、それらも取り込まれた出力に含まれ、テストが失敗する原因になることがあります。

テスト結果に影響を与えずにデバッグ情報を出力するために、`bats`はこの目的でファイルディスクリプター**3**を用意しています。
`/dev/fd/3`に出力された内容はテストの実行中に表示されますが、アサーションに使われる取り込まれた出力には含まれません。

例:

```awk
BEGIN {
    # This debug message will not interfere with test output comparison
    print "a debug message" > "/dev/fd/3"

    # Normal program output (this is what your tests will see and compare)
    print "Hello, World!"
}
```

実行例:

```none
$ bats test-hello-world.bats
test-hello-world.bats
 ✓ Say Hi!
a debug message

1 test, 0 failures
```

これで、テストに影響を与えずに、役に立つデバッグ出力を確認できます。

コードのいくつかの場所で使う場合は、詳細を関数にまとめると読みやすくなるかもしれません。

```awk
BEGIN {
    debug("starting ...")
}

# do stuff here ...

END {
    debug("... finished")
}

function debug(msg) {print msg > "/dev/fd/3"}
```
