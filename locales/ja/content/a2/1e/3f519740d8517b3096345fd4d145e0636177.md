# はじめに

タプルは、任意の型のデータを決まった個数だけまとめておける、手軽な仕組みです。
タプルには固有の名前がありません。データ構造に名前を付けると、それは`struct`になります。
タプルのフィールドには名前がなく、アクセスするには分解するか、位置で指定します。

## 作成

タプルは、必ずタプル式で作成します。

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

タプルには、いくつでも要素を持たせることができます。

## 分解によるアクセス

タプルの要素には、分解によってアクセスできます。
つまり、タプルの各要素に変数名を割り当てて、タプルそのものを消費する、ということです。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
