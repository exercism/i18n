# 概要

PowerShellは、Microsoftが開発した動的で暗黙的に型付けされる（[厳密に型指定された][strong typed]変数もサポートしています）スクリプト言語で、主にタスクの自動化と構成管理に焦点を当てています。

PowerShellは、命令型、関数型、オブジェクト指向、さらにはパイプライン形式のプログラミングをサポートしています。

PowerShellは.NETプラットフォーム上に構築され、2006年に最初にリリースされました。
最新のWindows OSにはすべて標準で搭載されており、MacやLinuxにもインストールできます。


## 変数

PowerShellで変数を定義する方法には、よく使われるものが2つあります。

PowerShellの変数名は`$`で始まる必要があり、代入演算子`=`を使って変数名に値を結び付けます。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

値が特定の型であることを強制したい、あるいは必須にしたい場合は、変数の型を明示的に指定することもできます。
PowerShellは、可能であれば値をある型から別の型へ最大限変換しようとします。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### 定数

PowerShellの定数は、定義後に**変更**も**削除**もできない変数です。
ここで、変数を定義する2つ目の方法、つまりコマンドレット`New-Variable`を使う方法を紹介します。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## 関数

PowerShellの関数は、`function`キーワードを使って定義します。
各関数は、括弧（`()`）の中に0個以上の仮引数を取ることができ、そのあとに`{`で始まり`}`で終わる関数スコープが続きます。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShellの関数では、`FuncName $Arg`という構文で呼び出したあと、`return`キーワードを使って明示的に値を返すことができます。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## コメント

PowerShellの単一行コメントは`#`で始まり、行末で終わります。
PowerShellのコメントブロックは`<#`で始まり、`#>`で終わります。

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
