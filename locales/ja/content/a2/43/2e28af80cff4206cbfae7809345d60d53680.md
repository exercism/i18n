# 概要

プログラムやコードに問題があったり、予期しないことが起こったりしたときは、エラーを報告すると役に立ちます。

エラーはJavaScriptのオブジェクトです。

このオブジェクトの主なプロパティは`message`です。

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw`構文を使うと、エラーを投げることができます。

```javascript
throw new Error('Oops');
```

エラーが投げられると、その時点の実行は中断され、コールスタックの最初の`catch`ブロックから再開します。

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

JavaScriptの他のクラスと同様に、サブクラスは`extends`キーワードを使って`Error`を継承し、独自のエラーを作ることができます。
`instanceof`構文を使うと、catchしたエラーが`Error`の特定のサブクラスのインスタンスかどうかを確認できます。

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

## エラーの種類

`Error`オブジェクトのほかにも、組み込みのエラーオブジェクトがいくつかあります。詳しくは[こちら][error-types]で学べます。

## 独自のエラー

組み込みのエラータイプの1つを継承したクラスを作ることで、独自の[エラータイプ][custom-error-type]を定義することもできます。

```javascript
class MyCustomError extends Error {}
```

## エラー以外を投げる

`throw`構文は通常エラーオブジェクトを投げるために使いますが、JavaScriptは柔軟なので、`string`や`null`、その他のプリミティブ型も投げることができます。

## エラーのスタックトレース

JavaScriptの標準ではありませんが、ほとんどのJavaScript環境ではエラーオブジェクトに[`stack`][error-stack]プロパティが実装されており、投げられたエラーのスタックトレースを取得できます。
