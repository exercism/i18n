# はじめに

パースとは、テキストを意味のあるデータに変換する処理のことです。その点では`String`パッケージの関数には限界があり、正規表現も扱いにくいため、Elmでパースするなら`elm/parser`パッケージを使うのが定石です。

プログラミング言語[LOLCODE][lolcode]（の一部分）をパースするプログラムを書く例を、順を追って見てみましょう。まず、次のコメント付きのプログラムを考えます。

```
HAI 1                 # program version 1
CAN HAS STDIO?        # import stdio
VISIBLE "HAI WORLD!"  # print "HAI WORLD!"
KTHXBYE               # end of program
```

最初に、扱うコマンドを表すElmの型を書きましょう。

```elm
type Command
    = Version Int
    | Import String
    | Print String
```

こうすると、LOLCODEのプログラムは`List Command`として表せます。まずは`HAI 1`の行をパースするものから始めましょう。

```elm
versionP : Parser Command
versionP =
    Parser.succeed Version
        |. Parser.keyword "HAI"
        |. Parser.spaces
        |= Parser.int
```

`versionP`は、_パーサーのパイプライン_を使って組み立てます。`(|.)`演算子は「文字列をパースするけれど結果は捨てる」という意味で、`(|=)`は「文字列をパースして結果を残す」という意味です。この例では、`Parser.keyword "HAI"`が「HAI」を消費しますが、その結果は無視されます。`Parser.spaces`は' '、'\n'、'\r'という文字をいくつでも消費しますが、これも無視されます。`Parser.int`は整数をパースし、その値（例えば1）が一番上にある`Parser.succeed Version`に渡されて、パーサーは`Version 1`という値を返すことに成功します。

パイプラインの中のパーサーがどれか一つでも失敗すると、`Parser.DeadEnd`が返り、パイプライン全体が失敗します。パーサーは`Parser.run`で実行できます。

```elm
Parser.run versionP "HAI 1"
    --> Ok (Version 1)
Parser.run versionP "HAI 2"
    --> Ok (Version 2)
Parser.run versionP "BYE 2"
    --> Err [{ problem = ExpectingKeyword "HAI", col = 1, row = 1 }]
Parser.run versionP "HAI MOM"
    --> Err [{ problem = ExpectingInt, col = 5, row = 1 }]
```

それでは、「CAN HAS STDIO?」の行に取り組みましょう。

```elm
importP : Parser Command
importP =
    Parser.succeed Import
        |. Parser.keyword "CAN HAS"
        |. Parser.spaces
        |= packageP
        |. Parser.symbol "?"
```

`importP`もパーサーのパイプラインですが、今度は「?」のような記号のパースに適した`Parser.symbol`で終わります。残しておきたい値（インポートするパッケージの名前）は、こちらでパースします。

```elm
packageP : Parser String
packageP =
    Parser.chompWhile Char.isAlphaNum
        |> Parser.getChompedString
        |> Parser.map String.toLower
```

パッケージ名が何になるか分からないので`Parser.keyword`は使えません。そこで、条件（ここでは英数字であること）を満たす限り1文字ずつ消費する`Parser.chompWhile`を使います。消費された文字は`Parser.getChompedString`で集められ、`Parser String`が返ります。ここではパッケージ名を正規化したいので、`Parser.map`を使ってパーサーの中の文字列を小文字に変えます。

```elm
Parser.run importP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS StDiO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS STDIO"
    -->  Err [{ problem = ExpectingSymbol "?", col = 14, row = 1 }]
```

続いて、`VISIBLE "HAI WORLD!"`をパースするのはこちらです。

```elm
printP : Parser Command
printP =
    Parser.succeed Print
        |. Parser.keyword "VISIBLE"
        |. Parser.spaces
        |. Parser.symbol "\""
        |= stringP
        |. Parser.symbol "\""

stringP : Parser String
stringP =
    Parser.chompWhile (\c -> c /= '"')
        |> Parser.getChompedString

Parser.run printP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
```

これでコマンドごとのパーサーが揃いました。もちろん、一般的なプログラムではこれらのコマンドの順序は予測できないので、汎用のコマンドパーサーを作ります。

```elm
commandP : Parser Command
commandP =
    Parser.oneOf
        [ versionP
        , importP
        , printP
        ]
```

`Parser.oneOf`は、与えられた順番にパーサーを1つずつ試します。パーサーが失敗すると次のものが試され、成功すると残りのパーサーは試さずにその結果が返ります。すべてのパーサーが失敗すると、`Parser.oneOf`も失敗します。

```elm
Parser.run commandP "HAI 2"
    --> Ok (Version 2)
Parser.run commandP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run commandP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
Parser.run commandP "O NOES"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 1 }
    --      ]
```

失敗した試行がそれぞれ`Parser.DeadEnd`を生み、それが`Parser.oneOf`に集められることに注目してください。

プログラム全体をパースするには、複数のコマンドを順番にパースする必要があります。これを使います。

```elm
programP : Parser (List Command)
programP =
    Parser.sequence
        { start = ""
        , separator = "\n"
        , end = "KTHXBYE"
        , spaces = Parser.succeed ()
        , item = commandP
        , trailing = Parser.Optional
        }
```

`Parser.sequence`はとてもカスタマイズ性の高いパーサーで、たくさんのオプションがあります。`start`、`separator`、`end`は、並びの要素を区切る文字列を受け取ります。Elmのリストをパースするなら、"[", "," , "]"を使うでしょう。`spaces`は、要素と区切り文字の間に入りうる空白を扱うパーサーを受け取ることで柔軟性を持たせます。Elmのリストをパースするなら`Parser.spaces`を使いますが、今回は空白を受け付けないので、何も消費せずにすぐ成功する`Parser.succeed ()`を使います。`item`は要素のパーサーを受け取り、最後に`trailing`で、末尾の区切り文字を`Parser.Forbidden`、`Parser.Mandatory`、`Parser.Optional`のどれにするかを決められます。

```elm
Parser.run programP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run programP "KTHXBYE"
    --> Ok []
Parser.run programP "HAI 2\nCAN HAS STDIO?\n"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 3 }
    --      , { problem = Expecting "KTHXBYE", col = 1, row = 3 }
    --      ]
```

パーサーは成功すると、文字列の消費を止めます。

```elm
Parser.run Parser.int "1"
    --> Ok 1
Parser.run Parser.int "1 BTW VISIBLE \"U SEE NOTHING\""
    --> Ok 1
```

ですから、文字列をすべてパースしたことを確かめたいときは、`Parser.end`を使います。

```elm
fullProgramP : Parser (List Command)
fullProgramP =
    programP
        |. Parser.spaces
        |. Parser.end

Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE\nBTW VISIBLE \"U SEE NOTHING\""
    --> Err [{ problem = ExpectingEnd, col = 1, row = 4 }]
```

最後に、パースした内容によってパーサーを失敗させたいことがあります。例えば、「HAI」コマンドが2つ連続して始まるプログラムを失敗させたいなら、次のように書けます。

```elm
singleVersionProgramP : Parser (List Command)
singleVersionProgramP =
    fullProgramP
        |> Parser.andThen
            (\commands ->
                case commands of
                    (Version _) :: (Version _) :: _ ->
                        Parser.problem "Multiple versions defined"

                    _ ->
                        Parser.succeed commands
            )
```

`Parser.andThen`はパーサーの内容を調べて、その値に応じて新しいパーサーを返すことができます。ここでは、一方のケースでは`Parser.problem`を使って独自のメッセージでパーサーを失敗させ、もう一方では元の値を返しています。

```elm
Parser.run singleVersionProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run singleVersionProgramP "HAI 1\nHAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Err [{ problem = Problem "Multiple versions defined", col = 8, row = 4 }]
```
