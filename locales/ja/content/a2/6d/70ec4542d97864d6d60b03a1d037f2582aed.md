# はじめに

## 文字列

Elmでは、文字と文字列がテキストを表すための基本になります。文字列は文字のリストと考えることができ、`List`のほとんどの関数には`String`モジュールに対応するものがあります。

### 文字

`Char`型は、`'a'`のように一重引用符で囲んだ単一のUnicode文字を表します。 
`Char`モジュールには、文字の性質を調べる述語関数（`Char -> Bool`）が用意されています。たとえば`isUpper`、`isLower`、`isAlpha`、`isAlphaNum`です。
また、このモジュールには、文字を変換する関数として`toUpper`、`toLower`、`toLocaleUpper`、`toLocaleLower`が、数値のUnicode値（`Int`）との相互変換を行う関数として`toCode`と`fromCode`があります。

### 文字列

`String`型は、効率的な文字列操作のための組み込みの表現で、任意のUnicode文字の並びを表すことができます。たとえば"これはElmの文字列です。"のように。
複数行の文字列は二重引用符3つで表し、エスケープされていない引用符や改行を含めることができます。
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### 文字列の関数

`String`モジュールには、下の表にまとめたすべての関数が含まれています。
特によく使われる関数には、次のようなものがあります。

`cons : Char -> String -> String`は、文字列の先頭に文字を追加します。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String`は、2つの文字列を連結します。
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String`は、指定した区切り文字の位置で文字列を文字列のリストに分割します。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`は、文字列のリストを指定した区切り文字で連結します。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String`は、指定した部分文字列のすべての出現箇所を置き換えます。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int`は、文字列の文字数を返します。
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int`は、文字列を`Just Int`に変換しようとし、形式が正しくない文字列には`Nothing`を返します。
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool`は、2番目の文字列に1番目の文字列が含まれているかどうかを調べます。
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String`は、指定した関数を文字列内のすべての`Char`に適用します。
渡す関数は`Char`から`Char`への写像でなければならないことに注意してください。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
