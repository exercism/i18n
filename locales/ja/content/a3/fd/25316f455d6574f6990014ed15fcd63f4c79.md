# はじめに

Elixirのコードは、BEAM仮想マシン上で動作します。BEAMはErlang Run-Time Systemの一部です。Erlangに着想を得て、その実行環境を共有しているElixirは、Erlangのライブラリと高い相互運用性を備えています。つまり、Elixirのエンジニアは、自分のElixirコードの中からErlangのライブラリを利用できます。実際、Erlangのライブラリがすでに提供している機能を、Elixirのライブラリとしてわざわざ書くことは、Elixirコミュニティでは推奨されていません。

そのため、数学的な演算やタイマー機能といった一部の機能は、ElixirではErlangを通じてのみ利用できます。

Erlangの標準ライブラリは、特別な手順を踏むことなく、Elixirのコードからそのまま利用できます。

Erlangの関数は、Elixirの関数を呼び出すのと同じ方法で呼び出せますが、1つだけ小さな違いがあります。Erlangのモジュール名は`snake_case`のアトムです。たとえば、`math`モジュールのErlang関数`pi/0`を呼び出すには、次のように書きます。

```elixir
:math.pi()
# => 3.141592653589793
```

Elixirに相当するものがない、よく使われるErlangの関数には、次のようなものがあります。

- `:timer.sleep/1`は、プロセスを指定されたミリ秒数だけ停止させます。
- `:rand.uniform/0`は、`0.0 <= x < 1.0`の範囲でランダムな小数`x`を生成します。
- `:io_lib.format/2`は、制御シーケンスを使った、C言語スタイルの文字列フォーマットを提供します。この関数を使えば、たとえば2から36までの任意の基数で整数を表示したり、任意の精度で小数をフォーマットしたりできます。なお、この関数は、Erlangの多くの関数と同様に、文字リストを返します。
- `sin/1`、`cos/1`、`log2/1`、`log10/1`、`pow/2`などの数学関数を提供する`math`モジュール。

Erlangの標準ライブラリについて調べるには、[STDLIBリファレンスマニュアル][erl-stdlib-ref]を見てみましょう。

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
