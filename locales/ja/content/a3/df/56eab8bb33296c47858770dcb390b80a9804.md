# 概要

Elixirの[文字列][getting-started-strings]はダブルクォートで囲み、UTF-8でエンコードされています。

```elixir
"Hi!"
```

文字列は、[`<>/2`][kernel-concat]演算子を使って連結できます。

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixirの文字列は、`#{}`という構文を使った[補間][string-interpolation]に対応しています。

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

補間の中には、どんなElixirの式でも書けます。文字列を渡した場合は、その文字列がそのまま補間されます。それ以外の値を渡した場合は、Elixirがそれを文字列に変換しようとします。

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixirでは、`String`モジュールに文字列を扱うための関数がたくさん用意されています。文字列を思いどおりに処理する方法がわからないときは、ぜひ[`String`モジュールで利用できる関数][string-module-functions]を眺めてみてください。たいていは、必要なものが見つかります。

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

これらの関数を使うときは、文字列の最初の文字のインデックスが`0`であることを覚えておいてください。

文字列に入れるには[エスケープ][escape-characters]が必要な文字もあります。たとえば、改行、ダブルクォート、`#`などです。

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

改行の多いテキストを楽に扱いたいときは、代わりに[3つのダブルクォートによるヒアドキュメント構文][heredoc-syntax]を使いましょう。

```elixir
"""
1
2
3
"""
```

この構文は、コードのドキュメントを書くときによく使われます。

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
