# はじめに

## 文字列

Elixirの文字列はダブルクォートで囲み、UTF-8でエンコードされています。

```elixir
"Hi!"
```

文字列は`<>/2`演算子を使って連結できます。

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixirの文字列は、`#{}`という構文による式の埋め込みに対応しています。

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

文字列に改行文字を入れるには、`\n`というエスケープシーケンスを使います。

```elixir
"1\n2\n3\n"
```

改行の多いテキストを快適に扱いたいときは、代わりにダブルクォートを3つ重ねたヒアドキュメント構文を使いましょう。

```elixir
"""
1
2
3
"""
```

Elixirには、文字列を扱うための関数が`String`モジュールにたくさん用意されています。

## パイプ演算子

`|>`演算子はパイプ演算子と呼ばれます。前の関数呼び出しの戻り値を、次の関数呼び出しの最初の引数として渡す形で、関数呼び出しをつなげることができます。

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
