# はじめに

`for`ループを使うと、配列を繰り返し処理して、要素ごとに同じコードを実行できます。

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

上の例では、`fruit`は、配列`fruitList`の個々の要素の値を保持する変数です。コンパイラーは、`fruitList`を繰り返し処理できることを保証します。できない場合は、実行を停止します。

範囲演算子を使うと、数値を繰り返し処理できます。この演算子は2つの`Int`を取り、`min...max`と書きます。

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
