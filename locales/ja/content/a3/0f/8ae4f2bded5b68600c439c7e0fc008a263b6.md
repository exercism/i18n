# はじめに

## 構造体の型

構造体の型はすでに見てきました。おさらいすると、`struct`は「フィールド」と呼ばれる名前付きの要素の並びで、各フィールドは名前と型を持ちます。
フィールドの名前は、その構造体の中で一意でなければなりません。
構造体は、オブジェクト指向プログラミングの考え方でいう「クラス」にたとえることができます。

新しい構造体を作るには、`type`と`struct`というキーワードを使い、下の例のようにフィールドの名前と型を明示的に定義します。

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 構造体以外の型

組み込み型の宣言の別名として使える、構造体以外の型を定義することもできます。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

配列やマップからなる、構造体以外の型を定義することもできます。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
