# 2進数、8進数、16進数

2進数、8進数、16進数（_ヘックス_とも呼ばれます）は、それぞれ基数の異なる[記数法][numeral-systems]です。
2進数は基数2、8進数は基数8、16進数は基数16です。
Crystalでは、ふつうの整数は基数10です。
2進数、8進数、16進数は、どれも整数の表現方法です。
つまり、小数や分数を使わずに正の数と負の数（_ゼロを含む_）を表し、整数でできるすべての演算をサポートします。

## 2進数

[2進数][binary]は基数2の記数法で、0と1の数字だけを使います。
コンピューターのトランジスターやスイッチを流れる電気の「オフ」（0）と「オン」（1）の状態や、磁気記憶媒体の正負の電荷をよく表します。
2進数は、基数10で使われるすべての整数を表すことができます。

基数2のしくみの一部を抜き出すと次のようになりますが、これは無限に続き、128で止まるわけではありません。

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

では、数値の6を表したい場合、2進数では110になります。

| 位の値    | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| 2進数の数字 | 1   | 1   | 0   |

計算は`4 + 2 + 0 = 6`のようになります。

もう1つの例を見てみましょう。19です。

| 位の値    | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| 2進数の数字 | 1   | 0   | 0   | 1   | 1   |

2進数では10011になります。
計算は`16 + 0 + 0 + 2 + 1 = 19`のようになります。

## Crystalでの2進数

Crystalでは、`0b`プレフィックスを使って2進数のリテラルを表せます。
`0b10011`と書くと、Crystalはそれを2進数として解釈し、基数10に変換します。

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

2進数ではない数値に`0b`プレフィックスを付けて書くと、コンパイルエラーになります。

```crystal
0b10211
# => Error: unexpected token: "211"
```

### 2進数での演算

2進数は整数なので、整数でできるすべての演算を実行できます。

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### 2進数表現との相互変換

Crystalは2進数リテラルを自動的に`Int32`に変換します。
`Int32`を2進数表現に変換するには、[`<int>.to_s(base)`][to_s]メソッドを使い、base引数に2を指定します。
このメソッドは、2進数の文字列表現を返します。

```crystal
19.to_s(2)
# => "10011"
```

2進数の文字列表現を整数に変換するには、[`<int>.to_i(base)`][to_i]メソッドを使い、引数に基数（2）を渡します。

```crystal
"10011".to_i(2)
# => 19
```

間違った基数（_または無効な2進数表現_）を渡すと、`ArgumentError`が発生します。

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### 2進数のメソッド

整数に対して使えるメソッドの中には、その数値の2進数表現に関する情報を得られるものがあります。

[`<int>.bit_length`][bit_length]は、その数値を表すのに必要なビット数を返します。

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit]は、右端（_最下位ビット_）から数えて、指定したインデックスのビットを返します。

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## 8進数

[8進数][octal]は基数8の記数法です。
0、1、2、3、4、5、6、7の数字を使います。

Crystalでは、`0o`プレフィックスを使って8進数を表せます。
2進数の場合と同じく、Crystalは8進数表現を自動的に`Int32`に変換します。

```crystal
0o123
# => 83
```

8進数ではない数値に`0o`を付けると、コンパイルエラーになります。

### 8進数表現との相互変換

2進数の場合と同じく、[`<int>.to_s(base)`][to_s]メソッドを使って`Int32`を8進数表現に変換できます。
また、[`<int>.to_i(base)`][to_s]メソッドを使って8進数表現を`Int32`に変換できます。

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

2進数の場合と同じく、間違った基数を渡すと`ArgumentError`が発生します。

## 16進数

[16進数][hexadecimal]は基数16の記数法です。
0〜9の数字と、A、B、C、D、E、Fの文字を使います。
Aは10、Bは11、Cは12、Dは13、Eは14、Fは15です。

Crystalでは、`0x`プレフィックスを使って16進数を表せます。
2進数や8進数の場合と同じく、Crystalは16進数リテラルを自動的に`Int32`に変換します。

```crystal
#=> 0x123
291
```
 
16進数ではない数値に`0x`を付けると、コンパイルエラーになります。

### 16進数表現との相互変換

2進数の場合と同じく、[`<int>.to_s(base)`][to_i]メソッドを使って`Int32`を16進数表現に変換できます。
また、[`<int>.to_i(base)`][to_s]メソッドを使って16進数表現を`Int32`に変換できます。

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

2進数や8進数の場合と同じく、間違った基数を渡すと`ArgumentError`が発生します。

## 精度

数値を文字列表現に変換するとき、その数値の精度を指定できます。
これは、その数値を表すために使われる**最小**の桁数を意味します。
数値の桁数が精度より少ない場合、文字列表現の先頭にゼロが追加されます。
これは、[`<int>.to_s(<base>, precision: <value>)`][to_s]メソッドに`precision`引数を渡すことで行います。

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
