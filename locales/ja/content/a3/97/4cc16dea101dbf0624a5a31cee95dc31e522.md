# 概要

ディクショナリは、他の言語のマップや連想配列に相当するもので、キーと値のペアを保存します。ディクショナリのインデクサープロパティにキーを渡すと、対応する値を直接取得したり変更したりできます。

キーと値のペアは、追加したり削除したりすることもできます。また、キー、値、キーと値のペアを列挙できます。

値には、任意のC#型のオブジェクトを指定できます。プリミティブ型、構造体、そしてクラスも含まれます。

Dictionaryオブジェクトでは、キーに任意の型のオブジェクトを使えます。ただし、実行時に正しく動作させるには、キーが[GetHashCode][gethashcode]から返される適切なハッシュコードを持っている必要があります。

ディクショナリのインスタンスは、複数のスレッドから安全にアクセスすることはできません（スレッドセーフではありません）。マルチスレッドの状況では、[ConcurrentDictionary][concurrent-dictionary]を利用できます。

[HashSet][hashset]、[ConcurrentDictionary][concurrent-dictionary]、[SortedDictionary][sorted-dictionary]も参照してください。

Dictionaryには非ジェネリック版がありませんが、非ジェネリックのマップをサポートするクラスがいくつかライブラリに残っています。非ジェネリックのIDictionaryとHashtableは、見かけたときに分かるように、主に知っておく必要があります。これらを使うのは、古いコードベースを保守するとき以外にはほとんどないでしょう。

ディクショナリを[`IDictionary<TKey, TValue>`][idictionary]インターフェースを通して公開したり、アクセスしたりしたくなることもよくあります。

[インデクサープロパティ][indexer-properties]の性質上、プリミティブ値は次のようにその場で変更できることに注意してください。

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
