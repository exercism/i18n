# 概要

## 重要なポイント

- クラスの`.new`メソッドを呼び出してオブジェクトのインスタンスを作成すると、インスタンスの状態を初期化するために、`.initialize`メソッドにすべての引数が渡されます。
- インスタンス変数の名前には、先頭に`@`が付きます。
- インスタンス変数は、明示的に値を設定するまで、デフォルトでは`nil`です。
- インスタンス変数はデフォルトではプライベートなので、ゲッターとセッターを使って操作するのがよいでしょう。

```ruby
class Backpack
  initialize(owner)
    @owner = owner
  end

  def owner
    @owner
  end

  def owner=(new_owner)
    @owner = new_owner
  end
end
```

- 名前の末尾に`=`が付いたメソッドは、Rubyによってセッターとして認識されます。また、代入構文をシンタックスシュガーとして使えるようになり、たとえば`Backpack.new("Sven").owner = "Ayah"`のように書けます。
  `owner`と`=`の間にはスペースがありますが、実際のメソッド名は`owner=`であることに注目してください。
- ゲッターとセッターは、`attr_reader`、`attr_writer`、`attr_accessor`メソッドを使って作成できます。
  - `attr_reader`：指定したシンボルのゲッターを作成します
  - `attr_writer`：指定したシンボルのセッターを作成します
  - `attr_accessor`：指定したシンボルのゲッターとセッターを作成します

```ruby
class Backpack
  attr_accessor :owner

  initialize(owner)
    @owner = owner
  end
end
```

- インスタンス変数を直接使わずに、ゲッターとセッターを使うのはなぜでしょうか？
  - 前の例で`@ownar`のように打ち間違えると（これを「タイポ」と呼びます）、エラーは出ずにそのまま処理が進んでしまい、システムにバグを潜り込ませる可能性があります。
  - ゲッターとセッターを使うとこれが明示的になり、タイポをするとエラーが発生します
