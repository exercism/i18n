# 導入

## インポート

Swiftの標準ライブラリには豊富な機能が用意されていますが、外部のライブラリやフレームワークをインポートすると、さらに多くの機能を利用できます。
これらのモジュールには、Swiftプロジェクトが直接提供するもの（[Swift Argument Parser][argument-parser]など）、Appleのプラットフォームフレームワーク（[Foundation][apple-foundation]や[Network Framework][network-framework]など）、サードパーティのオープンソースライブラリ（[SwiftyBeaver][swifty-beaver]など）があります。

Foundationのようなコアモジュールは、Swiftで最も広く使われているライブラリの1つで、Swiftツールチェーンに含まれています。
サードパーティのライブラリは、インポートする前にプロジェクトの設定に追加しておく必要があります（たとえばSwift Package Managerを使います）。

モジュールのインポートは、`import`キーワードに続けてモジュール名を書くことで行います。
たとえば、プログラムに次のように書けばFoundationをインポートできます。

```swift
import Foundation
```

モジュールをインポートすると、その型、メソッド、関数を自分のコードから使えるようになります。
たとえばFoundationをインポートすると、`String`に`components(separatedBy:)`のような便利なユーティリティメソッドが追加されます。

慣習として、`import`文はSwiftファイルの先頭に置きます。そうすれば、コードを読む人に依存関係がすぐにわかります。

## 文字列のインデックス

`String`内の個々の文字には、配列で使うのと同じインデックスの書き方でアクセスできます。
ただし、文字列で使う[インデックス][string-indices]は_整数ではなく_、そのまま扱うことはできません。
代わりに、`startIndex`のような、何か別のわかっているインデックスを基準に計算する必要があります。`startIndex`は空でない文字列の最初の文字の位置を指します。計算には、[`String`][string-docs]と[`NSString`][nsstring-docs]のライブラリで使えるメソッドを使います（`Foundation`モジュールをインポートすると、Swiftの文字列はNSStringのすべてのプロパティとメソッドを利用できます）。

たとえば、次の文字列があるとします。

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

「orange」の中の「g」を取り出すのに`csv[21]`とは書けません。代わりに`String.Index`型の値を計算して、そのインデックスを渡す必要があります。
なお、これらのインデックスは、それ自体を人間が読んで理解するためのものではありません。
これらは_不透明なインデックス_と呼ばれるもので、中身を知る必要はありません。

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

ただし、オフセットが有効なインデックスでない場合、つまり`startIndex`より前や`endIndex`より後のインデックスを返すような場合は、エラーが発生してプログラムがクラッシュします。
この問題を防ぐには、制限となるインデックスを指定します。
これはオプショナルのインデックスを返し、そうでなければ無効になるインデックスに対してはnilを返します。

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

さらに、インデックスは文字列の間で共有できません。
たとえば、上で計算した「orange」の中の「g」の`index`を使って、文字列`fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`をインデックス指定する、つまり`fam[index]`とすると、プログラムがクラッシュします。

これにはいろいろな理由がありますが、突き詰めれば「Unicodeは厄介」ということに尽きます。

一般的に言えば、個々の文字にランダムアクセスする必要があるなら、`Array<Character>`のような別のデータ構造を使うほうがよいでしょう。

### 便利なメソッド

Swiftには、文字列の最初と最後の文字を取得する`first`と`last`というメソッドがあります。
これらのメソッドはオプショナルの文字を返すので、文字列が空の場合はnilを返します。

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

`prefix`と`suffix`メソッドを使うと、文字列の部分文字列を取得できます。
これらのメソッドは整数を引数に取り、文字列の最初または最後のn文字を含む部分文字列を返します。

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## 文字列のメソッド

テキストを扱うのは、プログラミングでよくある作業です。
Swiftには、Foundationフレームワークとあわせて、文字列を調べたり、変換したり、操作したりするための便利なメソッドやプロパティがたくさん用意されています。

## `components(separatedBy:)`で文字列を分割する

区切り文字を基準に文字列を部分文字列の配列に分割するには、`components(separatedBy:)`を使います（Foundationのインポートが必要です）。

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## `hasPrefix(_:)`と`hasSuffix(_:)`で先頭と末尾を調べる

文字列が特定の文字の並びで始まるか、または終わるかを調べるには、`hasPrefix(_:)`と`hasSuffix(_:)`を使います。

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## 大文字と小文字を変える

これらの標準のメソッドとプロパティを使うと、文字列の大文字・小文字を変換できます。

- `lowercased()`: 文字列の小文字のコピーを返します。
- `uppercased()`: 文字列の大文字のコピーを返します。
- `capitalized`: 各単語の最初の文字を大文字にしたコピーを返します（Foundation）。

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## `replacingOccurrences(of:with:)`で部分文字列を置き換える

対象の部分文字列をすべて別の文字列に置き換えるには、`replacingOccurrences(of:with:)`を使います（Foundation）。

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## `joined(separator:)`で文字列を連結する

`joined(separator:)`メソッドは、`[String]`のような文字列のコレクションに属します。
区切り文字を使って要素を1つの文字列に連結します。

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
