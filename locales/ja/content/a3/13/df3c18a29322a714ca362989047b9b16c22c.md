# 関数

JavaScriptでは、関数は_第一級オブジェクト_です。つまり、変数やプロパティに代入でき、他の関数に渡したり、関数から返したりできます。他の_オブジェクト_と同じように、プロパティやメソッドを持つこともできます。

## 入力：引数を渡す

JavaScriptの関数では、呼び出すときに引数を渡すことができます。引数は常に[値渡し](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7)です。つまり、関数の内部で仮引数に代入し直しても、関数の外では値は変わりません。ただし、渡されたオブジェクトの中身を変更できない、という意味ではありません。

> [!TIP]
> オブジェクトを渡すときは、そのオブジェクトへの参照が値として渡されます。そのため、オブジェクトを渡す場合だけ扱いが違うように_見えます_が、実際はそうではありません。

2つの引数を受け取って掛け算する関数の例は、次のとおりです。

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 出力：戻り値

JavaScriptでは、`return`キーワードのあとに式を書くことで、関数から1つの値を返せます。関数から何も返さない場合、戻り値は`undefined`です。

値を返す関数の例は、次のとおりです。

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 関数の定義

JavaScriptの関数には、4つの種類があります。

1. どんな値でも返すことができ、必ず最後まで実行される通常の関数
2. 常に`Promise`を返し、`await`演算子で一時停止と再開ができる非同期関数
3. 常に`Generator`オブジェクトを返し、`yield`演算子で一時停止と再開ができるジェネレーター関数
4. 常に`AsyncGenerator`オブジェクトを返し、`yield`と`await`の_両方_の演算子で一時停止と再開ができる非同期ジェネレーター関数

これら4つの種類それぞれに、定義する方法が3つあります。

1. 宣言を使う
2. 式を使う
3. コンストラクターを使う

最後に、_アロー関数とメソッド_を定義するための特別な構文もあります。
