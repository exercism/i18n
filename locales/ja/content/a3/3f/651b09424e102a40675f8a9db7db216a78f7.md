# 説明

この演習では、ある従業員の1か月の給与の総額を計算するためのルールを実装します。International Siderurgy Company（ISC）は、最終的な賃金に影響を与えるさまざまな要素を考慮しながら、従業員の給与を計算する支援を必要としています。

タスクは3つあり、実装には`if`/`else`文ではなく三項演算子を使います。

## 1. 給与の倍率を求める

`salaryMultiplier`メソッドを実装します。このメソッドは、従業員が仕事を休んだ日数に応じて給与の倍率を返します。従業員が5日以上休んだ場合は、15%のペナルティを適用します。

```java
int daysSkipped = 3;
salaryMultiplier(daysSkipped);
// => 1.0

daysSkipped = 7;
salaryMultiplier(daysSkipped);
// => 0.85
```

## 2. 販売した製品のボーナスを計算する

`bonusMultiplier`メソッドと`bonusForProductsSold`メソッドを実装します。ISCは販売した製品1つにつき10の貨幣単位を支払い、従業員が20個以上の製品を販売した場合は、倍率が13に上がります。`bonusMultiplier`はどの倍率を適用するかを決め、`bonusForProductSold`はボーナスの合計を貨幣単位で返します。

```java
int productsSold = 21;
bonusMultiplier(productsSold);
// => 13
bonusForProductsSold(productsSold);
// => 273

productsSold = 5;
bonusMultiplier(productsSold);
// => 10
bonusForProductsSold(productsSold);
// => 50
```

## 3. 従業員の最終的な給与を計算する

`finalSalary`メソッドを実装します。このメソッドは、基本給`1000.00`に給与の倍率を掛け、ボーナスを足した結果を返します。ただし、給与は`2000.00`を上限とします。

```java
int daysSkipped = 2;
int productsSold = 3;
finalSalary(daysSkipped, productsSold);
// => 1030.00

productsSold = 90;
finalSalary(daysSkipped, productsSold);
// => 2000.00
```
