# 説明

この演習では、名作ゲームのPac-ManにあるいくつかのルールをUnisonの関数に翻訳します。

翻訳するルールは4つあり、どれもゲームの状態に関係しています。

> 引数がどのように導き出されるのかは気にしなくて大丈夫です。引数を組み合わせて、意図した結果を返すことだけに集中しましょう。

## 1. Pac-Manがゴーストを食べられるかどうかを定義する

`pacmanRules.eatGhost`関数を定義します。この関数は2つの引数（_Pac-Manのパワーペレットが有効かどうか_と_Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manがゴーストを食べられるかどうかを示す真偽値を返します。この関数は、Pac-Manのパワーペレットが有効で、かつゴーストに触れているときだけ`true`を返すようにします。

```unison
pacmanRules.eatGhost: Boolean -> Boolean -> Boolean
pacmanRules.eatGhost powerPelletActive touchingGhost =
  todo "implement eatGhost"
```

## 2. Pac-Manが得点するかどうかを定義する

`pacmanRules.score`関数を定義します。この関数は2つの引数（_Pac-Manがパワーペレットに触れているかどうか_と_Pac-Manがドットに触れているかどうか_）を取り、Pac-Manが得点したかどうかを示す真偽値を返します。この関数は、Pac-Manがパワーペレットかドットに触れているときに`true`を返すようにします。

```haskell
pacmanRules.score: Boolean -> Boolean -> Boolean
pacmanRules.score powerPelletActive touchingDot =
  todo "implement score"
```

## 3. Pac-Manが負けるかどうかを定義する

`pacmanRules.lose`関数を定義します。この関数は2つの引数（_Pac-Manのパワーペレットが有効かどうか_と_Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manが負けるかどうかを示す真偽値を返します。この関数は、Pac-Manがゴーストに触れていて、パワーペレットが有効でないときに`true`を返すようにします。

```unison
pacmanRules.lose : Boolean -> Boolean -> Boolean
pacmanRules.lose powerPelletActive touchingGhost =
  todo "implement lose"
```

## 4. Pac-Manが勝つかどうかを定義する

`pacmanRules.win`関数を定義します。この関数は3つの引数（_Pac-Manがすべてのドットを食べたかどうか_、_Pac-Manのパワーペレットが有効かどうか_、_Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manが勝つかどうかを示す真偽値を返します。この関数は、Pac-Manがすべてのドットを食べていて、なおかつ3番目で定義した引数に基づいて負けていないときに`true`を返すようにします。

```unison
pacmanRules.win : Boolean -> Boolean -> Boolean -> Boolean
pacmanRules.win eatenAll powerPelletActive touchingGhost
  todo "implement Rules.win"
```
