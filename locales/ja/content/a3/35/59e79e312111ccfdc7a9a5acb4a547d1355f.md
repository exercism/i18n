# 説明

この演習では、ロールプレイングゲームの仕組みを実装します。
プレイヤーのキャラクターは、次の型で表されます。

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

このゲームのプレイヤーは、呪文を唱え始めるために、レベル10に到達してマナプールを解放する必要があります。
このゲームでは、復活と呪文を唱えるという2つの機能に取り組みます。

## 1. 自己紹介をしましょう

`introduce`関数の中身を書きましょう。
`Player`レコードの`Name`フィールドは`Option`であることに注意してください。
隠密のプレイヤーは、名前を`None`のままにして隠したいかもしれません。そのようなプレイヤーは`"Mighty Magician"`として紹介されます。
それ以外の場合は、自分の名前を使って自己紹介してください。

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. 復活の仕組みを実装しましょう

`revive`関数は、プレイヤーのキャラクターが本当に死んでいるかどうか（体力が0になっているかどうか）を確認する必要があります。
死んでいる場合は、体力が100の新しい`Player`インスタンスを返します。
そうでなければ、つまりプレイヤーのキャラクターが死んでいない場合、`revive`関数は`None`を返します。

プレイヤーのレベルが10以上の場合、マナも100にして復活させます。
プレイヤーのレベルが10未満の場合、マナは`None`にします。
`revive`関数はプレイヤーのレベルを維持する必要があります。

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

体力が1以上のプレイヤーに対して`revive`メソッドを呼び出すと、この関数は`None`を返します。

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. 呪文を唱える仕組みを実装しましょう

`castSpell`関数は、呪文のコストとなるマナの量を表す`int`と、`Player`を引数に取ります。
更新されたプレイヤーと、唱えた呪文が与えるダメージ量を返します。
呪文の詠唱に成功すると、呪文のマナコストの2倍のダメージを与えます。
しかし、プレイヤーのマナが足りない場合は何も起こらず、プレイヤーは変化せず、ダメージも与えられません。
プレイヤーがマナプールすら持っていない場合、呪文を唱えようとすると体力が呪文のマナコスト分減り、ダメージは与えられません。

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
