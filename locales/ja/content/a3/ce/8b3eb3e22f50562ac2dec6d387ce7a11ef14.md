# 説明

あなたは熱心なバードウォッチャーで、この7日間に庭へやって来た鳥の数を記録しています。

6つのタスクがあり、どれも庭に来た鳥の数を扱うものです。

## 1. 先週の記録を確認する

比較のために、先週の記録をいつも手元に残しています。先週の記録は0、2、5、3、7、8、4でした。先週の記録を入れたベクターを作成してください：

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. 今日来た鳥の数を確認する

`today`関数を実装して、今日庭に来た鳥の数を返してください。鳥の数は日ごとに並んでいて、最初の要素が最も古い日の数、最後の要素が今日の数です。

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. 今日の数を増やす

`inc-bird`関数を実装して、今日の数を増やしてください：

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. 鳥が一羽も来なかった日があるか確認する

`day-without-birds?`述語関数を実装して、庭に鳥が一羽も来なかった日があれば`true`を、そうでなければ`false`を返してください：

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. 週の最初から指定した日数分の鳥の数を計算する

`n-days-count`関数を実装して、週の最初から庭に来た鳥の数を返してください。ただし、数えるのは週の最初から指定された日数分だけにします。

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. 忙しい日が何日あったか計算する

日によっては、ほかの日より忙しいこともあります。忙しい日とは、庭に5羽以上の鳥が来た日のことです。
`busy-days`関数を実装して、忙しい日の数を返してください：

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. 変わった週かどうかを確認する

この1年で、同じ変わったパターンになる週があることに気づきました。それは、鳥の数が1羽と0羽を交互に繰り返すパターンです。`odd-week?`関数を実装して、今週の鳥の数のパターンがこの変わったパターンに一致すれば`true`を返してください：

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
