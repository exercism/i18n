# 説明

HTTPエンドポイントは、型チェックがあるとより安全に使えます。POSTリクエストにRecord型を加えると、毎回正しいデータが送られるようになります。

## 目標

- 用意されたコードを修正します。
- このレコードに必要な属性を追加して、2つのオペランドと1つの演算子を受け取れるようにします。
- パス'/calc'へのPOSTリクエストを受け取るHTTPリソース関数を追加します。
- この関数はCalculationレコード型をペイロードとして受け取り、汎用のJSONオブジェクトを返すようにします。

### 入力

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### 戻り値

```json
{ "expression": "4+10.2", "result": 14.2 }
```
