# 説明

完成したマインスイーパーの盤面に、地雷の数を書き加えます。

マインスイーパーは、マスの周囲（上下左右と斜め）に地雷がいくつあるかを示す数字のヒントを頼りに、地雷を見つけていく人気のゲームです。

この演習では、空いているマスの周囲にある地雷の数を数え、そのマスを数値に置き換えるコードを書きます。

盤面は、空白文字（' '）でできた長方形です。地雷はアスタリスク（'\*'）で表します。

周囲に地雷が1つもないマスは、空白のままにします。

## 例

たとえば、次のような5×4の盤面を受け取ることがあります（ここでは、画面上で見やすくするために、空いているマスを'·'で表しています）。

```
·*·*·
··*··
··*··
·····
```

これを、コードで次のように変換します。

```
1*3*1
13*31
·2*2·
·111·
```
