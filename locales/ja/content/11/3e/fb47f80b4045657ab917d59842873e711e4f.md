# はじめに

以前のコンセプトで、Juliaの型は階層を形成し、最上位に`Any`があることを見ました。

`Number`のような抽象型にはサブタイプがありますが、それ自体をインスタンス化することはできません。
変数を抽象型に設定すると、その変数の値は抽象型の任意のサブタイプであるように_制約_されます。
たとえば：

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

これにより、どの入力を有効にするかを制約するための、ある種の柔軟性が得られます。

しかし、変数に整数と文字列の両方の値を受け入れさせたい場合はどうでしょうか？
これらの型は階層の同じ枝にはありません。

型を`Any`に設定することも、デフォルトでそうなるようにすることもできますが、そうすると許可される型をまったく制御できなくなります。

よりよい方法として、`Union{ }`構文があります。波括弧の中に2つ以上の型を並べます。

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

別の例では、同じUnion型を関数シグネチャで使います。

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

ここでは型に名前を付けました。これは便利な略記になりますが、厳密には必要ありません。
関数`g(z::Union{Integer, String}) = z^3`も同じように動作します。

関数シグネチャについては、多重ディスパッチのコンセプトでさらに詳しく説明します。

## nothingとのUnion

他のいくつかの言語には、値を含むことも含まないこともある型があり、`Option`、`Nullable`、`Maybe`などの名前が付いています。

Juliaにはこのための専用の構文はありませんが、Union型は同じアイデアを一般化したものです。

`Nothingness`コンセプトで、Juliaには`nothing`や`missing`など、値がないことを表すさまざまな方法があることを見ました。
これらのどちらもUnion型に含めることができます。

たとえば、何らかの連結リストを定義するとき、これ以上ノードがない場合にリストを終端させる方法が必要です。
`Nothing`はシングルトン値`nothing`を持つ型で、このNode定義により、連鎖の終わりを知らせることができます。

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

同様に、`missing`は、特にベクトルなどのコレクションで、存在しない値のプレースホルダーとして使うことができます。
以下の例は非常に不自然ですが、実際のデータセットでは欠損値はよくあります。

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
