# 概要

`TUPLE:`は、名前付きのスロットを持つクラスを宣言します。Factorは、コンストラクターのワード（クラス名に`new`を付けたもの）、`boa`（引数の順番どおり）コンストラクター、リテラル構文`T{ class … }`、そしてスロットごとのアクセサワードを自動的に生成します。

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

[`accessors`][accessors]のアクセサシステムは、スロットごとに4種類のワードを提供します。`name>>`、`>>name`、`change-name`、そして変更用のペアである`[ … ] change-name`です。`>>name`と`change-name`はタプルを変更します。元のタプルをそのままにしておきたいときは、先に`clone`します。

タプルは、構造的な等価性によって`=`をサポートします。また、出力するときは、デフォルト値でないスロットの値が表示されます。

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
