# ヒント

## 全体

- `struct`は、フィールドと呼ばれる名前付きの要素を順に並べたもので、それぞれの要素が名前と型を持ちます。

## 1. ラジコンカーを作る

- 新しい[struct][struct]をインスタンス化し、`distance`以外のフィールドを埋めます。
- 新しく作成した`struct`の型を返す関数を作り、それに合わせてフィールドを更新します

## 2. レース用のトラックを作る

- 1つのフィールドを持つ新しい[struct][struct]を定義します
- 新しく作成した`struct`の型を返す関数を作り、それに合わせてフィールドを更新します

## 3. 車を走らせる

- 走った距離を記録するための新しいフィールドを追加します
- 車を走らせるのに十分なバッテリーがあるかどうかを確認する必要があります

## 4. ラジコンカーがレースを完走できるか確認する

- 車がちょうどレースを始めたところだと仮定します
- 現在のバッテリー残量で車が走れる最大距離を計算する必要があります
- 車を走らせられる回数は、`battery / batteryDrain`で計算できます。
- 車が進める最大距離は、車の速度と走れる回数を掛け合わせたものです。
- 車が走れる最大距離がわかったら、それをレース用トラックの距離と比較します

[struct]: https://tour.golang.org/moretypes/2
