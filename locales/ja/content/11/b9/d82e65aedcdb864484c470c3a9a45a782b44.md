# 指示

アンドリューは勤め先のエンジニアで、先ごろデータベース移行ツールのために軽量なSQLクエリ生成ユーティリティを作りました。最初の素朴な実装は、小さなデータの集合では完璧に動きました。しかし、大規模な本番移行のさなか、アプリケーションは過剰なメモリを消費し始め、高負荷の下で苦しむようになりました。アプリケーションをプロファイリングした結果、アンドリューは、ループの中で標準的な文字列連結を使うとGoがメモリを絶えず再確保してしまうことに気づきました。そこで今、アプリケーションがうまくスケールし、大量のテキストをメモリヒープを圧迫せずに扱えるようにするため、Goの`strings.Builder`を使ってこのユーティリティをリファクタリングする手助けが必要です。

## 1. SELECTクエリを生成する

`BuildSelectQuery`関数を実装してください。
テーブル名（`string`）とカラム名のスライス（`[]string`）を受け取ります。
セミコロンで終わる、完全な形のSQL `SELECT`文を返してください。
カラムのスライスが空、または`nil`のときは、すべてのカラムを選択する`*`ワイルドカードを使うようにフォールバックします。

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. バッチINSERT文を生成する

`BuildBatchInserts`関数を実装してください。
テーブル名（`string`）と、データベースの行を表す2次元スライス（`[][]ColumnValue`）を受け取ります。
行の各要素は、特定のカラム名とその文字列値を結びつけます。
この関数は、個々の`INSERT` SQL文字列からなるスライスを返す必要があります。
構造化されたスライス形式のおかげで、クエリの出力順序は予測可能で安定します。
入力の行のスライスが空の場合は、空の文字列スライスを返してください。
個々の行が空の場合は、その行をスキップしてください。
`VALUES`句の中の文字列値は、シングルクォート`'`で囲む必要があります。

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
