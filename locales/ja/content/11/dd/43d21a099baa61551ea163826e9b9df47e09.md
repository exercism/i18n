# 指示

プラハのヴルタヴァ川のほとりで小さな気象観測所を営んでいて、勤務のたびに気温の測定値をプレーンテキストのログに書き留めています。1行につき測定値が1つです。5つの小さなワードが、1回の勤務分の記録管理を担ってくれます。

それぞれのワードには、ログファイルへのパスが渡されます。

## 1. すべての測定値を読み取る

`read-readings`を定義して、ログの測定値すべてを、1行に1つずつ文字列の配列として返します。

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. 最新の測定値を探す

`latest-reading`を定義して、最新の測定値、つまりログの最後の行を返します。

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. 生のログを読み取る

`log-text`を定義して、ログファイル全体を、保存されているとおりそのまま1つの文字列として返します。

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. 測定値を記録する

`record-reading`を定義して、新しい測定値を独立した行としてログの末尾に追加します。それまでの測定値はそのまま残します。何も返しません。

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. ログを書き換える

`rewrite-log`を定義して、ログ全体を、1行に1つずつ並んだ測定値の新しい配列で置き換えます。

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
