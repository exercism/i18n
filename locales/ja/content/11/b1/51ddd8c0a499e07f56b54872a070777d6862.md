# 指示の補足

複素数の累乗を計算するには、指数関数とサイン関数、コサイン関数が必要ですが、これらはWebAssemblyでは利用できません。幸いなことに、[テイラー級数](https://en.wikipedia.org/wiki/Taylor_series)を使えばこれらを計算できます。期待される値と一致させるには、少なくとも`1/26!`の精度が必要です。

## 指数関数

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## サイン関数

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## コサイン関数

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
