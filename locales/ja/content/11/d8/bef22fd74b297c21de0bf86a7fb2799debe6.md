# 説明

ベーリング海峡を航行するカッターの船上で、当直士官を務めています。目に入るすべての流氷と岬の位置を、3つの情報源が報告してきます。

- **海図係**は方位で報告します。`north`、`east`、`south`、`west`のいずれかで、方角だけで距離はありません。
- **航海士**は、カッターが最後に測位した地点からの*極*座標で報告します。大きさは海里、方位は北から時計回りの度数です（つまり`0`が北、`90`が東、`180`が南、`270`が西です）。
- **マスト上の見張り員**は*相対*座標で報告します。前方への距離と、`ahead`、`starboard`、`behind`、`port`のいずれかです。相対方位は*船の現在の針路*を基準に測ります。船長は各当直の前に、ブリッジでその針路を告げます。

やることは、この3つを共通のデカルト座標`(x, y)`に変換し、海図に描けるようにすることです。方位は度数で表します。`(0, 1)`は北へ1海里、`(1, 0)`は東へ1海里です。

## 1. データモデルと、`cardinal`のデカルト座標

まず、演習全体で共有する部品を用意しましょう。

- 3つのタプルを定義します。`cardinal`（スロット1つ、`direction`）、`polar`（スロットは`magnitude`と`bearing`）、`relative`（スロットは`distance`と`bearing`）です。
- `SYMBOLS:`で方位のシンボルを宣言します。`north`、`east`、`south`、`west`、`ahead`、`starboard`、`behind`、`port`です。
- `SYMBOL:`で動的変数`heading`を宣言します（タスク3で使います）。
- `GENERIC: >cartesian ( direction -- x y )`と`GENERIC: flip ( direction -- direction' )`という2つのジェネリックワードを宣言します。これらのメソッドは次のタスク以降で追加します。

次に、`>cartesian`の`M: cardinal`メソッドを追加し、指定した方位の単位ベクトルを返すようにします。

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. `polar`のデカルト座標

`>cartesian`に`M: polar`メソッドを追加し、極座標形式を`(x, y)`に変換します。

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. `relative`のデカルト座標

`>cartesian`に`M: relative`メソッドを追加します。ここがポイントです。相対方位は船の*現在の針路*を基準に測りますが、それはタプルには含まれていません。`heading get`で`heading`変数（タスク1で宣言）を読み取り、方位のオフセット（`ahead = 0`、`starboard = 90`、`behind = 180`、`port = 270`）を足して、デカルト座標の点を求めます。呼び出し側は`with-variable`ブロックの中で`heading`を設定します。

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. 反転

`flip`ジェネリック（タスク1で宣言）のメソッドを追加し、反対の方位を返すようにします。

- `cardinal`の場合：north ↔ south、east ↔ west。
- `polar`の場合：方位に180°を足します（360で割った余り）。
- `relative`の場合：ahead ↔ behind、starboard ↔ port。

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. 方位の足し算

`add-bearings ( a b -- x y )`を定義します。これは両方の方位をデカルト座標に変換し、その和を返します。`cardinal`、`polar`、`relative`をどのように組み合わせても動きます。これこそ、`>cartesian`にジェネリックを使うことの見返りです。

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
