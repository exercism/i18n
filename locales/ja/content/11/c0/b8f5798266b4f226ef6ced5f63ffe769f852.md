# 概要

## 配列の繰り返し

`for`ループを使うと、配列を繰り返し処理し、要素ごとにコードを繰り返すことができます。

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

上の例では、`fruit`は配列`fruitList`の個々の要素の値を保持する変数です。コンパイラーは`fruitList`を繰り返し処理できるかどうかを確認し、できない場合は実行を停止します。

## 範囲の繰り返し

範囲演算子を使うと、数値を繰り返し処理できます。この演算子は2つの`Int`のオペランドを取り、`min...max`のように書きます。`min`は含まれ、`max`は含まれません（`min` <= i AND `max` > i）。

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## キーと値の繰り返し

キーと値のペアの集まりを繰り返し処理することもできます。構文の違いは、変数を1つだけ使う代わりに、キーの変数名、`=>`、値の変数名の順に書くことだけです。

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
