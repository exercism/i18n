# はじめに

C#の`enum`型は、固定された名前付き定数のセット（列挙型）を表します。主な目的は、数値定数を扱う際の型安全な方法を提供し、使用できる値をあらかじめ定義されたセットに限定することです。シンプルな`enum`は、次のように定義できます。

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

明示的に定義しなければ、`enum`のメンバーには自動的に0から始まる連番の整数値が割り当てられます。値を明示的に割り当てることもできます。

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
