# 指示の補足

## 例外メッセージ

ときには[例外を発生させる](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。そのときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。これによりコードが読みやすくなり、デバッグが格段に楽になります。エラーの原因がある型だとわかっている場合は、[組み込みのエラー型](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを発生させることもできますが、その場合も意味のあるメッセージを含めてください。

この演習では、採点ルールやプレイのルールに従っていないときにエラーを「投げる」ために、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使う必要があります。テストに合格するのは、`raise`で`exception`を発生させ、なおかつメッセージを添えたときだけです。

メッセージ付きで`ValueError`を発生させるには、`exception`型の引数としてメッセージを書きます。

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
