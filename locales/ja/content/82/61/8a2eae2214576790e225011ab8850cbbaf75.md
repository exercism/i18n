# ベクターをスタックとして使う

スタックは、一端からのアクセスに最適化された線形データ構造です。ちょうど、軸に刺さった紙の束のようなものです。新しい紙はいつも同じ端に追加され、紙は追加されたときと逆の順序で取り出されます。先に追加された紙が最後に取り出され、最後に追加された紙が最初に取り出されます。

Rustの`Vec`データ構造は、スタックとして使うのに適しています。[`push`メソッド](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push)は、ベクターの末尾に要素を追加します。[`pop`メソッド](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop)は、ベクターから最後の要素を取り除きます。`push`と`pop`はどちらも、償却`O(1)`時間しか必要としません。

## 例

この例では、簡単な[RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation)電卓のスタックとしてベクターを使います。完全なソースは[playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736)にあります。

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
