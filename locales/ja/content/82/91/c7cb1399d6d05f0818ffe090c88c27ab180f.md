# 概要

[内包表記][for]を使うと、_Enumerable_を簡単かつ宣言的に変換できます。これは、Elixirでenumerableを繰り返し処理するための_糖衣構文_です。

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

内包表記には3つの要素があります。

1. _ジェネレーター_:
   - [_Enumerable_][enumerable]プロトコルを実装した構造から列挙される値。
   - 列挙された値を分解するためのパターンマッチ式。
2. _フィルター_: 真偽値の条件で、新しい値を作るときにどの列挙値を使うかを選ぶために使います。
3. _コレクタブル_: [_Collectable_][collectable]プロトコルを実装した構造で、新しい値を集めるために使います。

内包表記には1行で書くものと複数行で書くものがあります。ジェネレーターを2つ以上使うと、生成される値の[直積][cartesian-product]が列挙されます。つまり、最初のジェネレーターが生成する各値は、2番目のジェネレーターが生成する各値と1回ずつ組み合わされます。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

doブロックの値は、_enumerable_から**生成される値ごとに**_collectable_へ挿入されます。

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

内包表記では、`<-`の左側でも、独立した行でも、パターンマッチを使えます。

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
