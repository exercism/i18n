# 指示の補足

## レジスター

| レジスター | 用途     | 型      | 説明                                                   |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | 入力      | アドレス | 1つ目の色を表すnull終端文字列                              |
| `$a1`    | 入力      | アドレス | 2つ目の色を表すnull終端文字列                              |
| `$a2`    | 入力      | アドレス | 3つ目の色を表すnull終端文字列（空の場合もあります）           |
| `$v0`    | 出力      | 整数    | 抵抗器の値                                              |
| `$t0-9`  | 一時的    | 任意    | 一時的に値を保存するため                                   |
