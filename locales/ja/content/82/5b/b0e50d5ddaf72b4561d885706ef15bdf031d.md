# はじめに

C#では、0個以上の要素を保持できるデータ構造は_コレクション_と呼ばれます。**配列**は、サイズ（長さ）が固定されたコレクションで、要素はすべて同じ型でなければなりません。要素は、インデックスを使って配列に代入したり、配列から取得したりできます。C#の配列は0から始まるため、最初の要素のインデックスは常に0です。

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

配列は、配列の作成と値の設定を同時に行える省略記法を使って定義することもできます。コンパイラーが配列の要素数を判断できるため、長さを省略できます。

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

配列は、配列インスタンスのメソッドやプロパティを呼び出すか、`Array`クラスで定義されている静的メソッドを使うことで操作できます。
