# 説明

2つの配列`A`と`B`が与えられたとき、次のどれに当てはまるかを判定します。

- 配列`A`が配列`B`と等しい。または
- 配列`A`が配列`B`を含んでいる（`A`は`B`のスーパーリスト）。または
- 配列`A`が配列`B`に含まれている（`A`は`B`のサブリスト）。または
- 上のどれにも当てはまらない。つまり、配列`A`と`B`は等しくない

具体的には、2つの配列が同じ順序で同じ値を持っていれば、配列`A`は配列`B`と等しいです。配列`A`が、`B`と等しい連続した値の部分列を含んでいれば、`A`は`B`のスーパーリストです。配列`B`が、`A`と等しい連続した値の部分列を含んでいれば、`A`は`B`のサブリストです。

例：

- `A = []`と`B = []`（どちらの配列も空）の場合、`A`と`B`は等しいです
- `A = [1, 2, 3]`と`B = []`の場合、`A`は`B`のスーパーリストです
- `A = []`と`B = [1, 2, 3]`の場合、`A`は`B`のサブリストです
- `A = [1, 2, 3]`と`B = [1, 2, 3, 4, 5]`の場合、`A`は`B`のサブリストです
- `A = [3, 4, 5]`と`B = [1, 2, 3, 4, 5]`の場合、`A`は`B`のサブリストです
- `A = [3, 4]`と`B = [1, 2, 3, 4, 5]`の場合、`A`は`B`のサブリストです
- `A = [1, 2, 3]`と`B = [1, 2, 3]`の場合、`A`と`B`は等しいです
- `A = [1, 2, 3, 4, 5]`と`B = [2, 3, 4]`の場合、`A`は`B`のスーパーリストです
- `A = [1, 2, 4]`と`B = [1, 2, 3, 4, 5]`の場合、`A`と`B`は等しくありません
- `A = [1, 2, 3]`と`B = [1, 3, 2]`の場合、`A`と`B`は等しくありません
