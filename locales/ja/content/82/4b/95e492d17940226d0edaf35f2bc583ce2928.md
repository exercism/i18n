# 説明

イベントオーガナイザーのMikaは、仕事で昇進しました。そして、新しい職務の一環として、イベントデータベースを担当することになりました。彼女はすぐに、多くのデータが扱いにくい形で保存されていることに気づきました。そこで、二人で協力して、一度きりのスクリプトでデータを整理することにしました。

スクリプトは一度しか実行しませんし、データの構造にも確信があるので、ここはGleamの_`let`アサーション_を使うのにぴったりの場面だと感じるでしょう。

## 1. エラーを取り出す

過去の各イベントには、開催中に発生した問題のリストがあります。これらは`Result`として保存されていますが、常に`Error`バリアントです。

`extract_error`関数を実装してください。この関数は、常に`Error`であると想定される`Result`を受け取り、含まれているエラーの値を返します。

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. チームの接頭辞を取り除く

チーム名には"Team "という接頭辞が付いていますが、これは不要です。チーム名から接頭辞を取り除く`remove_team_prefix`関数を実装してください。

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. 地域とチームを分割する

各イベントはチームによって運営され、各チームは地域に所属しています。データベースでは、これらはカンマで区切られた1つの文字列として保存されています。

`split_region_and_team`関数を実装して、文字列を2つの文字列のタプルに分割してください。1つは地域用、もう1つはチーム用です。チーム名から"Team "という接頭辞を取り除く必要があります。

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
