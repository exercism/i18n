# ヒント

## 全般

- `reduce`は、まずシーケンス、次にシード、そしてクォーテーションの順に受け取ります。クォーテーションが受け取るのは`( prev elt -- next )`で、最初が積み上げ中のアキュムレーター、次が次の要素です。
- 累積系のワード（`cum-sum`、`cum-product`、`cum-min`、`cum-max`）は[`math.statistics`][math.statistics]にあり、入力と同じ長さのシーケンスを返します。

## 1. リクエストのキューに従う

- `reduce`のシードは、開始残高です。
- クォーテーションは、リクエストを累積残高に加え、その後`0 max`で0を下限にします。こうして残高がマイナスになることはありません。
- 引数はスタックに`( opening requests )`の形で渡されますが、`reduce`が求めるのは`( seq init quot )`です。`swap`すれば整います。

## 2. 累積残高

- ワードは1つ、`cum-sum`だけです。

## 3. これまでの最小残高

- まず累積残高を計算し、その結果に累積の最小値を適用します。ワード2つをつなげるだけです。

## 4. 目標に達するまで半分にする

- `produce`がうってつけです。テストとステップを繰り返して、シーケンスを生成します。
- `produce`を通じて引き継がれる状態は、実行中の値と目標の*両方*です。`target`を下に、現在の値を上に置きます。述語は`2dup <`で両者を比較します（目標が実行中の値より小さい、つまり実行中の値はまだ目標を上回っている、という意味です）。
- クォーテーションの中では、`2 /i`で現在の値を2で割り、その結果を`dup`します。こうすると、実行中の状態を更新しつつ、新しい要素として出力されます。
- `produce`のあとは、残った状態（目標と最終的な値）を捨てる必要があります。`2nip`が下の2つの値を取り除き、生成されたシーケンスだけを残します。

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
