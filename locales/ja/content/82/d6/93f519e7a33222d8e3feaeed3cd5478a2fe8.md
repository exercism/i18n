# 指示の補足

## 実装

前提条件：

1. 0は、出力では常に[]ではなく[0]として表されます。
2. それ以外の場合、出力の先頭にゼロが付くことはありません。
3. 入力の先頭にゼロが付いていても受け付けます。
4. 入力の数字の並びが空の場合は、エラーではなく0とみなします。

問題となるケースでは、エラーを返して処理します。そのエラーのError()メソッドは、次のいずれかのメッセージを返します：

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
