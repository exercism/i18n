# はじめに

## メソッドのオーバーロード

*メソッドのオーバーロード*を使うと、同じクラスに同じ名前のメソッドを複数定義できます。オーバーロードしたメソッドどうしは、次のいずれかの点で異なっている必要があります。

- 仮引数の数
- 仮引数の型

戻り値の型に基づくメソッドのオーバーロードはありません。

コンパイラーは、仮引数の数とその型をもとに、どのオーバーロードされたメソッドを呼び出すかを自動的に推論します。

## 名前付き引数

これまでは、メソッドに渡す引数が、そのメソッドで宣言された仮引数に位置で対応づけられることを見てきました。別の方法として、特に多くの引数を取るルーチンを呼び出すときに、呼び出す側が仮引数の識別子を指定して引数を対応づけることができます。

次の例は、その構文を示しています。

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## 省略可能な仮引数

メソッドの仮引数は、既定値を代入することで省略可能にできます。省略可能な仮引数を持つメソッドを呼び出すとき、呼び出す側はその仮引数に値を渡す必要はありません。省略可能な仮引数に値が渡されなかった場合は、その既定値が使われます。

省略可能な仮引数は、仮引数リストの末尾に置く_必要があります_。その後ろに省略可能でない仮引数を置くことはできません。

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
