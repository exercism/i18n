# 説明

課題は、家系図の中の2人の人物の間の隔たりの次数を求めることです。
これは、ハリウッドの俳優は誰でも[ケビン・ベーコンから6次以内][six-bacons]にいる、というポップカルチャーの考え方に似ています。

- 入力として、すべての親の名前とその子どもが与えられます。
- それぞれの名前は一意で、子どもには親が1人または2人_いることもあります_。
- 隔たりの次数は、ある人から別の人へたどる接続の最短数として定義されます。
- 2人の人物がつながっていない場合は、「既知の関係がない」ことを表す値を返します。
  実際の実装については、テストケースを確認してください。

## 例

次のような家系図があるとします。

```text
      ┌──────────┐            ┌──────────┐     ┌───────────┐
      │  Helena  │            │  Erdős   ├─────┤  Shusaku  │
      └───┬───┬──┘            └─────┬────┘     └────┬──────┘
      ┌───┘   └───────┐             └───────┬───────┘
┌─────┴────┐     ┌────┴───┐           ┌─────┴────┐
│   Isla   ├─────┤ Tariq  │           │   Kevin  │
└────┬─────┘     └────┬───┘           └──────────┘
     │                │
┌────┴────┐      ┌────┴───┐
│   Uma   │      │ Morphy │
└─────────┘      └────────┘
```

TariqとUmaの隔たりの次数は2です（Tariq → Isla → Uma）。
IslaとKevinの間には知られた関係がありません。与えられたデータに接続がないためです。
UmaとIslaの隔たりの次数は1です。

~~~~exercism/note
IslaとTariqは兄弟で、隔たりの次数は1です。
同じように、この実装では、自分と父の兄弟との隔たりの次数は2であると報告されます。
~~~~
