# はじめに

## ランダム性

Elixirでは、列挙可能なデータ構造（配列や範囲など）からランダムな要素を選ぶには、`Enum.random`を使います。この関数は1つの要素を選び、どの要素も同じ確率で選ばれます。

Elixirには、ランダムな小数を選ぶための独自の関数はありません。そのためには、Erlangを直接使う必要があります。

## Erlangのライブラリ

ElixirのコードはBEAM仮想マシン上で動作します。BEAMはErlangランタイムシステムの一部です。Erlangに着想を得て、その実行環境を共有しているため、ElixirはErlangのライブラリとの優れた相互運用性を提供します。つまり、Elixirのエンジニアは自分のElixirコードの中からErlangのライブラリを使うことができます。実際のところ、Erlangのライブラリですでに提供されている機能のためにElixirのライブラリを書くことは、Elixirコミュニティでは推奨されていません。

その結果、数学的な操作やタイマー関数など、一部の機能はElixirではErlang経由でのみ利用できます。

Erlangの標準ライブラリは、特別な手順を必要とせず、Elixirのコードで利用できます。

Erlangの関数は、Elixirの関数を呼び出すのと同じように呼び出せますが、1つだけ小さな違いがあります。Erlangのモジュール名は`snake_case`のアトムです。たとえば、`math`モジュールからErlangの`pi/0`関数を呼び出すには、次のように書きます。

```elixir
:math.pi()
# => 3.141592653589793
```

Elixirに相当するものがない、よく使われるErlangの関数は次のとおりです。

- `:timer.sleep/1`は、指定されたミリ秒数のあいだプロセスを一時停止させます。
- `:rand.uniform/0`は、`0.0 <= x < 1.0`を満たすランダムな小数`x`を生成します。
- `:io_lib.format/2`は、C言語スタイルの文字列フォーマット（制御シーケンスを使用）を提供します。この関数を使えば、たとえば2から36までの任意の基数で整数を出力したり、希望する精度で小数をフォーマットしたりできます。この関数は、多くのErlang関数と同様、文字リストを返すことに注意してください。
- `math`モジュールは、`sin/1`、`cos/1`、`log2/1`、`log10/1`、`pow/2`などの数学関数を提供します。

Erlangの標準ライブラリについて調べるには、[STDLIBリファレンスマニュアル][erl-stdlib-ref]を見てみましょう。

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
