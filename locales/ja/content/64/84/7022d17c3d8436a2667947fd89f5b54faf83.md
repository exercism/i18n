# 抽象クラス

サーカスのショーは、演目のリストです。ジャグリング、空中ブランコ、軽業は、中身の異なる別々のものですが、上演順を組み立てる人にそれぞれから必要なのは、2つだけです。名前と、所要時間です。

**抽象クラス**が表すのは、そこまでです。それ以上はありません。

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

その名前は`$`で始まります。本体を持たないルーチンを並べます。シグネチャだけで、それぞれはセミコロンで終わります。ここから何かを作ることはできません。`create`も`new`もありません。

## 準拠

本物のクラスは、`<`のあとに`$ACT`と書くことで、`$ACT`になることを約束します。

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<`は「〜である」と読みます。そのクラスは、抽象クラスが並べたルーチンをすべて提供しなければなりません。引数も戻り値の型も同じでなければなりません。1つでも欠けるとコンパイルエラーになります。実行時になってから驚くことはありません。

クラスには、好きなものをいくらでも追加できます。`TRAPEZE`は、他のどの演目にもない高さを保持できます。抽象クラスはそれを知りませんし、気にもしません。

## 型を使う

`$ACT`は型なので、これを使ってさまざまなものを宣言できます。

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

この配列は、3つの異なるクラスのオブジェクトを同時に保持します。`ARRAY{JUGGLING}`にはできないことです。

## ディスパッチ

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!`は`$ACT`です。どの`minutes`が動くかは、その行が実行されるときに、オブジェクトが実際に何であるかによって決まります。ジャグリングなら`JUGGLING::minutes`、空中ブランコなら`TRAPEZE::minutes`です。この選び分けを**ディスパッチ**と呼びます。

足し算を行っているルーチンは、自分がどの種類の演目を扱っているかを一切尋ねません。4つ目の種類の演目を追加するには、新しいクラスを1つ書くだけで、他は何も変えずに済みます。こうする理由は、まさにそこにあります。
