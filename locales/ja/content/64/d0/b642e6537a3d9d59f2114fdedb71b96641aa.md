# 指示の補足

## 出力形式

タンパク質の配列は、各タンパク質のあとに改行文字を付けたヌル終端文字列として出力してください。

出力例は`"Methionine\nPhenylalanine\nSerine\n"`のようになります。

入力が無効な場合は、空の文字列を出力してください。

## レジスタ

| レジスタ | 用途        | 型      | 説明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 入力        | アドレス | ヌル終端の入力文字列  |
| `$a1`    | 入力/出力 | アドレス | ヌル終端の出力文字列 |
| `$t0-9`  | 一時        | 任意     | 一時保存に使用    |
