# 指示

課題は、会議が始まった時刻をもとに、納品日の記述を_実際の_納品日に変換することです。

納品日の記述には2つの種類があります。

1. 固定：あらかじめ決められた一連の単語です。
2. 可変：可変の部分を持ちますが、あらかじめ決められた一連のパターンに従う単語です。

## 固定の納品日の記述

固定の納品日の記述は3つあります。

- `"NOW"`
- `"ASAP"`（できるだけ早く）
- `"EOW"`（週の終わり）

次の表は、それぞれの変換方法を示しています。

| 記述    | 会議の開始時刻           | 納品日                     |
| ------- | ------------------------ | -------------------------- |
| `"NOW"` | -                        | 会議が始まってから2時間後  |
| `"ASAP"`| 13時より前               | 今日の17時                 |
| `"ASAP"`| 13時以降                 | 明日の13時                 |
| `"EOW"` | 月曜日、火曜日、水曜日   | 金曜日の17時               |
| `"EOW"` | 木曜日か金曜日           | 日曜日の20時               |

## 可変の納品日の記述

可変の納品日の記述には2つのパターンがあります。

- `"<N>M"`（N番目の月）
- `"Q<N>"`（N番目の四半期）

| 記述     | 会議の開始時刻                         | 納品日                                               |
| -------- | -------------------------------------- | ---------------------------------------------------- |
| `"<N>M"` | N番目の月より前                        | 今年のN番目の月の_最初の_平日の8時                   |
| `"<N>M"` | N番目の月以降                          | 来年のN番目の月の_最初の_平日の8時                   |
| `"Q<N>"` | N番目の四半期に入る前か、その四半期内  | 今年のN番目の四半期の_最後の_平日の8時               |
| `"Q<N>"` | N番目の四半期が終わったあと            | 来年のN番目の四半期の_最後の_平日の8時               |

~~~~exercism/note
平日とは、月曜日、火曜日、水曜日、木曜日、金曜日のことです。

1年は4つの四半期に分かれ、それぞれに3か月あります。
1. 1月・2月・3月
2. 4月・5月・6月
3. 7月・8月・9月
4. 10月・11月・12月
~~~~
