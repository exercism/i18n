# はじめに

`Complex numbers`は複雑ではありません。ただ、もっとおだやかな名前が必要なだけです。

複素数は、とくに工学や科学の分野でとても役に立つため、Rではinteger、double、logical、character、rawと並ぶ標準のアトミック型として用意されています。

## 基本

Rにおける`complex`は、1つの値です。ただし、使うときには2つの数値のペアとして考えることができます。これらは、残念な歴史的な事情から「実部」と「虚部」と呼ばれます。ここでも、奇妙な名前ではなく、その根底にあるシンプルさに目を向けるのがよいでしょう。

2つの実数から複素数を作るには、虚部に接尾辞`i`を付けるだけです。

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

実数の変数から複素数を作る場合、上記の書き方ではうまくいきません。`r + imi`と書くと、パーサーは`imi`を（存在しない）変数名だと誤解してしまいます。

虚部に`1i`を掛けるか、[`complex()`][ref-complex]関数を使います。

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

なぜ`j`ではなく`i`なのか、不思議に思うかもしれません。

多くのエンジニアは`j`を好みます。多くの科学者や数学者は、_虚数_を表す数学の記法`i`を好みますが、この記法は電気工学で_電流_を意味する`i`の使い方と衝突します。

Rは`i`を選び、Pythonは`j`を選び、Juliaは`im`を選んで論争を巧みにかわしました。[STEM][wiki-STEM]のプログラミング言語を行き来するときは、注意してください。

複素数の各部分に個別にアクセスするには、次のようにします。

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

どちらの部分も0になり得るので、数学者はその数を「完全に実」あるいは「完全に虚」と呼ぶことがあります。しかし、Rではそれでも複素数です。

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

「`i`（または`j`）は-1の平方根である」と聞いたことがあるかもしれません。

今のところ、これが意味するのは、虚部が_定義上_次の等式を満たすということだけです。

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

これはシンプルな考え方ですが、興味深い結果につながります。

## 演算

小数や整数で使うほとんどの演算子は、複素数でもそのまま使えます。

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

## 関数

ほとんどの数学関数は、複素数を入力として受け付けます。

`Re()`や`Im()`のほかにも、複素数に特に関係する関数がいくつかあります。

- `Conj()`は、複素数の虚部の符号を反転させるだけです（_+から-へ、またはその逆_）。
  - 複素数の積の仕組みのおかげで、これは思っている以上に役に立ちます。
- `abs(<complex number>)`は、虚部を持たない実数（その「大きさ」）を必ず返し、`Mod(<complex number>)`はその同義語です。
- `Arg(<complex number>)`は、位相角をラジアンで返します。

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
