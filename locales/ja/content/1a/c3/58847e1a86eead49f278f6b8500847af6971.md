# ヒント

## 全般

- `MACRO:`は[`macros`][macros]にあります。部品となるのは
  `kernel`（`dup`、`curry`）、`sequences`（`append`、`concat`、
  `<repetition>`、`map`）、そして`quotations`（`>quotation`）です。
- マクロの本体は、スタックに**1つのquotation**を残さなければなりません。
  本体がコードの配列を生成する場合は、最後に`>quotation`を書きます。
- 考え方が合っているか確かめるには、本体のワードをリスナーでリテラルに対して
  実行し、返ってくるquotationを見てみましょう。タスクの「コンパイル結果」の行に
  ある、まっすぐに並んだコードになっているはずです。

## 1. 2回繰り返す

- `[ A ]`を受け取り、`[ A A ]`を作りたいところです。コピーを作って
  繋げます：`dup append`。

## 2. N回の繰り返し

- `[ A ] n`を受け取り、`n`個のコピーを繋げたものを得たいところです。
- `<repetition>`がコピーを作りますが、その効果は
  `( length elt -- repetition )`です。カウントがスタックの一番上に来る
  必要があるので、先に`swap`します。
- その後、平坦にして変換します：`swap <repetition> concat >quotation`。

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. 多数を合成する

- すでにquotationの配列を受け取っているので、あとはそれを1つに平坦に
  するだけです。`concat >quotation`が本体のすべてです。

## 4. 展開された繰り返し

シーケンスとquotation、たとえば`{ 10 20 30 } [ + ]`を受け取り、
`[ 10 + 20 + 30 + ]`を得たいところです。3つの動きで組み立てていきます。

**1つの要素。** 要素をquotationに焼き込むのが、まさに`curry`の仕事です：

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**すべての要素。** それをシーケンスに対して`map`したいところですが、`map`が
マッピング用のquotationに渡す入力は1つ（要素）だけで、そのたびに`[ + ]`も手元に
必要です。そこで、`[ + ]`をマッピング用のquotationに、ここでも`curry`で先に
焼き込みます：

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry`は、「小さなquotation`[ curry ]`をプッシュし、そこに`[ + ]`を
curryする」という意味で、`[ [ + ] curry ]`になります。これを要素`e`に対して
mapすると`e [ + ] curry`が実行され、結果は`[ e + ]`になります。

**最後に繋げます。** 他のタスクと同じ締めくくりです：

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- 本体全体はこうなります：`[ curry ] curry map concat >quotation`。
