# 概要

Factorの[`calendar`][calendar]ボキャブラリーは、2つのタプルを中心に構成されています：

- `timestamp`：ある時点を表します（`year`、`month`、`day`、`hour`、`minute`、`second`、およびGMTオフセット）。
- `duration`：ある期間を表します（同じフィールドを量として使ったものです）。

## タイムスタンプ

`<date>`は真夜中のタイムスタンプを作り、`>date<`はそれを分解します：

```
<date> ( year month day -- timestamp )
>date< ( timestamp -- year month day )
```

```factor
USING: calendar ;

2024 7 14 <date> >date< .   ! => 14   (2024 and 7 below it)
```

よく使う問い合わせ：

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1   (0 = Sunday .. 6 = Saturday)
2024 1 8 <date> day-of-week day-names nth .   ! => "Monday"
2024 leap-year? .                      ! => t
2024 2 1 <date> days-in-month .        ! => 29
```

`day-names`（および`month-names`）は、[`calendar.english`][english]にあります。

## 期間と計算

`days`、`weeks`、`hours`、`minutes`のようなワードは`duration`を作り、`time+`と`time-`はタイムスタンプをその分だけずらします：

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .   ! => 29   (2024-02-29)
```

計算は月や年の境界をまたいで繰り上がり、同じ瞬間を指す2つのタイムスタンプは`=`で等しいと判定されます。

これら以外にも、`calendar`には時刻（`set-time`、`+hour`）、タイムゾーンの変換（`>gmt`、`>local-time`）、現在の時刻（`now`）、そして`calendar.format`を使った解析と書式設定があります。
