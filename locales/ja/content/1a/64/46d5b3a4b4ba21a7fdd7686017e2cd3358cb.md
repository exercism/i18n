# デバッグ

デバッグの助けとして、コンソールへの出力がすべてキャプチャされ、テスト結果ウィンドウに表示されるという性質を利用できます。
`@show`に値を渡すと、どんな値でも出力できます。

`@show`は式とその結果を表示し、その結果を返します。

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

[`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println)や、[`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout))に出力を書き込むその他のメソッドも使えます。
