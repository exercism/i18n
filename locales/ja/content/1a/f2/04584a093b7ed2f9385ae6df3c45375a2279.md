# 指示

この演習では、Exercismで学びたいプログラミング言語の配列を管理するコードを書きます。
タスクは6つあり、いずれも配列を扱います。

## 1. 新しい配列を作成する

学びたい言語を管理するには、新しい配列を作成する必要があります。
空の新しい配列を格納する`newList`定数を定義します。

```elm
newList
    --> []
```

## 2. 既存の配列を定義する

今、学びたい言語を書き出した紙が1枚あります。Elm、Clojure、Haskellです。
この配列を表す`existingList`定数を定義します。

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. 配列に新しい言語を追加する

Exercismを見て回って、もっと面白い言語を見つけたら、自分の配列に追加したくなります。
配列の先頭に新しい言語を追加する`addLanguage`関数を実装します。

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. 配列内の言語を数える

言語を手作業で数えるのは面倒です。
配列にある言語の数を数える`countLanguages`関数を実装します。

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. 配列を逆にする

しばらくして、自分の配列が実は逆順になっていることに気づきます！
配列を逆にする`reverseList`関数を実装します。

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. 配列がワクワクするものか確認する

どの言語も好きですが、Elmは心の中でも特別な存在です。
そのため、次のような言語の配列には、とてもワクワクします。

- 配列の最初の要素がElmである。
- または、配列の2番目の要素がElmで、配列に含まれる言語が3つ以下である。

言語の配列がワクワクするものかどうかを確かめる`excitingList`関数を実装します。

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
