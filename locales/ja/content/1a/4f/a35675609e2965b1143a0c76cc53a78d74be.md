# はじめに
## `switch`文

[`switch`文][switch]を使うと、1つの値を複数の候補と比較できます。
複数の`else-if`文を使うよりも、簡潔にコードを書けます。
`switch`文は`switch`キーワードから始まり、その後に比較する値を書きます。
次に、`case`キーワードの後に比較対象の値を書いて、各ケースを定義します。
どのケースにも一致しないときのデフォルトのケースは、`default`キーワードで定義します。
`else-if`文と同じように、`switch`文は最初に一致したケースに対応するコードブロックだけを実行します。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

次の例を見てみましょう。

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

これは、次のように書き換えられます。

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## `while`ループ

[`while`ループ][while-loops]は、ある条件が真である間、コードを実行し続ける制御フローの文です。
Swiftには、`while`ループと`repeat-while`ループの2種類があります。
`while`ループでは、ループ本体を実行する前に条件が評価されます。条件が偽なら、ループ本体は一度も実行されません。
Swiftの`while`ループは、次のような構造になっています。

```swift
while <#condition#> {
  <#code#>
}
```

このループは`count`が0より大きい間実行され、その結果、2、1、"Liftoff!"と出力します。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`ループ][while-loops]は`while`ループに似ていますが、条件はループ本体を実行した後に評価されます。
つまり、条件が偽であっても、ループ本体は必ず少なくとも1回は実行されます。
Swiftの`repeat-while`ループは、次のような構造になっています。

```swift
repeat {
  <#code#>
} while <#condition#>
```

この例では条件が偽なので、ループは1回だけ実行されます。
`repeat-while`ループなので、条件が評価される前にループ本体が1回実行されます。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 制御転送

Swiftには、ループの通常の制御フローを変えるための文がいくつかあります。
これらは制御転送文と呼ばれます。
`return`はすでに見てきました。このコンセプトでは、`continue`、`break`、ラベルなど、その他のものを紹介します。
`fallthrough`はこのコンセプトでは扱いませんが、[Swiftの書籍][fallthrough]で読むことができます。

### `continue`

ループの現在の繰り返しに残っている文を最後まで実行せず、早めに次の繰り返しへ進みたいことがあります。
こういうときは、`continue`キーワードを使います。
`continue`が実行されると、ループは次の繰り返しを実行できるかどうかの判定に移ります。つまり、`while`ループと`repeat-while`ループでは`while`の判定、`for-in`ループではシーケンスに次の要素があるかどうかの判定です。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### `break`

`break`は、ループから早めに抜けるために使います。
`break`が実行されると、ループはすぐに終了し、プログラムはループの次にある最初の文から続きます。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### ラベル

ループが入れ子になっているとき、`break`や`continue`を使っているループを含む外側のループを抜けたり再開したりするために、`break`や`continue`を使いたい場合があります。
そのような場合は、ラベルを使って、抜けたり再開したりするループを指定できます。
ループを始める`while`、`repeat`、`for`の前に、名前とコロンを書くと、そのループにラベルを付けられます。

このようにラベルを使うとどんな効果があるのか、次のループで見てみましょう。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
