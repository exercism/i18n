# 説明

この演習では、三目並べの状態を判定するプログラムを実装します。
_（このゲームは「noughts and crosses」や「Xs and Os」という名前で知られているかもしれません。）_

このゲームは3×3のマス目で行います。
プレイヤーは交代で、マス目に`X`と`O`を置いていきます。
ゲームは、どちらかのプレイヤーが縦・横・斜めのいずれかにマークを3つ並べて勝つか、すべてのマスが埋まったときに終わります。

この演習では、`X`から始まるものと仮定します。

与えられたゲームがどの状態にあるのかを判定するのが課題です。

考えられるゲームの状態は次の3つです。

- ゲームはまだ**ongoing**です。
- ゲームは**draw**で終わりました。
- ゲームは**win**で終わりました。

与えられた盤面が不正な場合は、適切なエラーを投げます。

盤面が次のいずれかの条件に当てはまる場合、その盤面は不正です。

- 正しい順番で手を打っても、その盤面には到達できません（`X`から始まることを思い出しましょう）。
- ゲームがすでに終わったあとにも、手が打たれています。

## 例

### 進行中のゲーム

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 引き分け

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 勝利

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 不正

#### 手番の順番が間違っている

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 勝利後もプレイを続けている

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
