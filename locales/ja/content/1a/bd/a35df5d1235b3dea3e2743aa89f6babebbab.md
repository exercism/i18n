# 説明

友人のLi Meiは、おいしいミックスフルーツジュースを売るジュースバーを営んでいます。Li Meiのお店によく通っていたところ、自分のプログラミングスキルを使って友人の仕事を楽にしてあげられることに気づきました。そこで、そのスキルを活かしてLi Meiの仕事を手伝うことにしました。

## 1. ジュースを混ぜるのにかかる時間を求める

Li Meiは、お客さんがメニューから注文したジュースを待つ時間を、あらかじめ伝えるのが好きです。ジュースを混ぜるのにかかる時間はそれぞれ違うので、正確な数字を覚えておくのは大変です。
`"Pure Strawberry Joy"`は0.5分、`"Energizer"`と`"Green Garden"`はそれぞれ1.5分、`"Tropical Island"`は3分、`"All or Nothing"`は5分かかります。
その他の飲み物（例えば、特別メニュー）については、準備に2.5分かかると考えてかまいません。

友人を助けるために、メニューにあるジュースを入力として受け取り、その飲み物を混ぜるのにかかる分数を返す関数`time_to_mix_juice`を書いてみましょう。

```julia-repl
julia> time_to_mix_juice("Tropical Island")
3

julia> time_to_mix_juice("Berries & Lime")
2.5
```

## 2. ライムのくし切りを補充する

Li Meiが作る飲み物の多くには、材料として、あるいは飾りとして、ライムのくし切りが入っています。
そのため、朝シフトが始まるときには、これから始まる1日のために、ライムのくし切りの容器がいっぱいになっているようにしておく必要があります。

Li Meiが切る必要のあるライムのくし切りの数と、手元にある丸ごとのライムの在庫を表す配列を受け取る関数`limes_to_cut`を実装しましょう。
`"small"`のライムからは6つのくし切り、`"medium"`のライムからは8つのくし切り、`"large"`のライムからは10のくし切りが取れます。
Li Meiはいつも、リストに現れる順番どおり、最初のライムから切っていきます。
必要な数のくし切りに達するか、ライムがなくなるまで切り続けます。

Li Meiは、あらかじめ何個のライムを切る必要があるのかを知りたいと思っています。
`limes_to_cut`関数は、切る必要のあるライムの数を返すようにします。

```julia-repl
julia> limes_to_cut(25, ["small", "small", "large", "medium", "small"])
4
```

## 3. 行列に並んだ注文それぞれを混ぜる時間を一覧にする

Li Meiは、お客さんが待っている注文を混ぜるのにどれくらい時間がかかるかを把握しておくのが好きです。

注文の行列を受け取り、混ぜる時間のベクトルを返す`order_times`関数を実装しましょう。

```julia-repl
julia> order_times(["Energizer", "Tropical Island"])
[1.5, 3.0]
```

## 4. シフトを終える

Li Meiはいつも15時まで働きます。
その後は、従業員のDmitryが引き継ぎます。
Li Meiのシフトが終わる時点で、注文はされたけれどまだ準備されていない飲み物が残っていることがよくあります。
Dmitryは、残っているジュースを準備します。

引き継ぎを楽にするために、Li Meiのシフトに残っている分数と、注文はされたけれどまだ準備されていないジュースの配列を受け取る関数`remaining_orders`を実装しましょう。
この関数は、Li Meiが勤務時間の終わりまでに準備を始められない注文を返すようにします。

シフトに残っている時間は、常に0より大きくなります。
準備するジュースの配列が空になることはありません。
さらに、注文は配列に現れる順番で準備されます。
Li Meiが何かジュースを混ぜ始めたら、少し長く働くことになっても、必ず最後まで作り終えます。
Dmitryが対応する必要のある注文が1つも残っていない場合は、空のベクトルを返すようにします。

```julia-repl
julia> remaining_orders(5, ["Energizer", "All or Nothing", "Green Garden"])
["Green Garden"]
```
