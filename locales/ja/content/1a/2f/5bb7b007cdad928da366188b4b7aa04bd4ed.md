# はじめに

Factorには`t`（true）と`f`（false）という2つの真偽値があります。「はい / いいえ」の答えが必要なところでは、ワードがこれらのどちらかをスタックに積みます。

真偽値の演算子は、[`kernel`][kernel]にあります。

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

`f`は、Factorで唯一*falsy*な値でもあります。それ以外の値（空の文字列、ゼロ、空の配列など）はすべて*truthy*として扱われます。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
