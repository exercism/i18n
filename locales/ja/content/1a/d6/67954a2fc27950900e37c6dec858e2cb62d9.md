# 概要

_クラス_のインスタンスを作るには、[`new`演算子][new]を使ってその[_コンストラクター_][constructors]を呼び出します。コンストラクターは特別な種類のメソッドで、新しく作られたインスタンスを初期化することを目的としています。[コンストラクターは通常のメソッドと同じような見た目][constructor-syntax]ですが、戻り値の型がなく、名前がクラス名と一致します。

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

通常のメソッドと同じように、コンストラクターも仮引数を持てます。コンストラクターの仮引数は、あとで使うために（privateな）[フィールド][fields]として保存しておくのが一般的です。そうでなければ、一度だけの計算に使われます。通常のメソッドに引数を渡すのと同じように、コンストラクターにも引数を渡せます。

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

コンストラクターの指定は省略できます。コンストラクターを指定しなければ、[仮引数を持たないコンストラクター][parameterless-constructors]がコンパイラーによって自動生成されます。

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

フィールドに初期値が割り当てられている場合、コンパイラーは、その割り当てを実際にはコンストラクターの中で行うコードを出力します。つまり、次の2つのクラス宣言は、機能の面では同じです。

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
