# はじめに

## 背景

文字列とは、引用符で囲まれたテキストのことです。
現在サポートされているどのバージョンのRも、文字列をUTF-8でエンコードするので、世界中のほとんどの言語を扱うことができます。

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

残念ながら、他の言語に慣れたプログラマーにとっては、この用語が混乱を招くかもしれません。

`type`は`character`ですが、Rは1文字（他のいくつかの言語では`char`と呼ばれますが、Rでは_そうではありません_）と長い文字列を区別しません。
どちらも1つの項目で、シングルクォート`' '`とダブルクォート`" "`のどちらで囲んでも同じように扱えます。

スタイルガイドでは、文字列の中でダブルクォートをエスケープせずに使いたい場合を除いて、ダブルクォートを使うことを勧めています。

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

つまり`character vector`は文字列のベクトルで、各文字列が1つの要素になります。

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

上の例では、`length(s[1])`は`length("some")`と等価です。これは_ベクトルの要素数_であり、_文字列の長さ_ではありません。

個々の文字列の操作ももちろん可能で、上の例の`nchar()`がそうですが、それには専用の関数が必要で、以下で説明します。

### 文字列関数

base Rでもほとんどのことは_可能_ですが、多くのプログラマーは、文字列操作のサポートがかなり限定的でわかりにくいと感じています。

幸いなことに、もっと直感的で柔軟、かつ一貫性のある`tidyverse`パッケージがあります。

### Base R

旧式の文字列関数を使ったレガシーコードは今もたくさんあります。
これにはExercismのコミュニティの解答のほとんどが含まれます。

さらに、小さなタスクでは、大きなライブラリを読み込む代わりに組み込み関数を使うと便利なことがあります。
Rトラックのメンテナーは、演習を検証するための模範解答を書くときに、この方法を取る傾向があります。

そのため、古い方法についてもある程度知っておく価値はあります。

#### `nchar`

文字列の文字数を返します。

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

「文字」とは何かという（_ややこしい！_）話題は、ここでの範囲を超えています。
上の例から、いくつかポイントだけ押さえておきましょう。

- 内部的にはCで実装されていますが、Rの文字列は`\0`で終端されません（終端があれば長さに1が加算されます）。
- マルチバイトのUnicode文字は、期待する（願う）とおりに扱われます。「Hrōðgār」は7文字（「ルーン」や「コードポイント」とも呼ばれます）ですが、保存には10バイト必要です。

#### `paste`と`paste0`

任意の数の文字列を1つの文字列に結合します。

`paste`には区切り文字を任意で指定できます。デフォルトはスペースです。

`paste0(v)`は`paste(v, sep = "")`と等価です。

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

文字列の組み立てをより細かく制御するために、RはCの`sprintf`関数をそのまま取り入れています（後発の言語も同様で、Wikipediaには約30の言語が[挙げられています][wiki-printf-ports]）。

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

先頭や末尾の空白は`trimws()`で取り除けます。

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

両端を削除したくないときは、`which = "left"`（または"right"）という引数があります。

#### `substr`

1つの文字列を操作し、2つの（両端を含む）位置の間の部分文字列を返します。

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

区切り文字列に基づいて、文字列をRのリストに分割します。
区切り文字は必須で（デフォルトはありません）、空文字列にすることもできます。

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

リストについては、別の[コンセプト][concept-lists]で扱います。
まだシラバスのその部分に到達していない場合は、今のところ、`unlist()`関数が（この場合）リストをベクトルに変換することだけ覚えておいてください。

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

好意的に言えば、旧式の文字列関数はRが提供する最良のものではない、と言えるでしょう（_もっと手厳しい見方もあります_）。

この状況を改善するため、`stringr`ライブラリは2009年から開発が続けられ、現在はTidyverseコレクションの中核を担っています。

`library(stringr)`または`library(tidyverse)`で名前空間に読み込みます。

主な特徴は次のとおりです。

- すべての関数名に`str_`という接頭辞が付き、目的がわかりやすいようになっています。
- 引数の順序は一貫性があり、入力データが最初の引数になります。
- 入力は、単一の文字列から複雑なデータ構造まで対応します。関数は状況に応じて、最も適切な処理を行おうとします。

他のすべてのTidyverseパッケージと同様に、`stringr`には優れたドキュメントがあり、通常はパッケージの作者によって書かれています。

- [リファレンスサイト][ref-stringr]
- [チートシート][cheat-stringr]
- 「R for Data Science」の[章][book-strings]

#### 寄り道：パイプの簡単な入門

関数をつなぐパイプ`|>`の使い方は、シラバスの別の場所で詳しく説明します。

今のところ、次のことを知っておくと役立ちます。

- パイプの左側の結果は、右側の関数の最初の引数になります（ここでいう「右側」は、任意の改行を無視します）。
- 残りの引数は、関数呼び出しに含めることができます。
- Rでは、_名前_だけでなく関数の_呼び出し_にパイプする必要があるため、常に括弧が必要です（_これは他のいくつかの言語とは異なります_）。

以下の例は構文を示しています。
個々の関数については後で説明します。

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### 長さを扱う

`str_length`はコードポイントを数えます（`nchars`と似ています）。

空白を操作する関数は他にもいろいろあり、`str_trim()`や`str_squish()`などがあります。
これは、どんなデータサイエンスプロジェクトでも、最初に行う重要なクレンジング作業になることがよくあります。

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### 部分文字列を取り出す

`str_sub(string, start, end)`関数は、`start`から`end`まで（両端を含む）の部分文字列を返し、`str_sub_all()`は複数の文字列を操作できます。

柔軟性はとても高いです。
`start`と`end`はそれぞれ、最初と最後の文字がデフォルトです。
これらはインデックスのベクトルにできます。
ベクトルのインデックスとはありがたいことに異なり、負の値はPython流に文字列の末尾から数えます。

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### 文字列を結合する

`str_flatten`は文字ベクトルを1つの文字列に変換します。
`collapse`引数は各要素の間に挿入され、デフォルトは`""`です。

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c`は複数の文字ベクトルを1つの文字ベクトルに変換します。必要に応じてリサイクルされます。

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue`は、シンプルな文字列補間をRにもたらします。
波括弧`{ }`の中の式が評価され、そのテキスト表現が埋め込まれます。

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### 文字列を分割する

Rの非常によくある用途は、乱雑なデータを分析しやすい一貫した形式に整えることです。
これを助けるために、テキストを部分文字列に分割する方法がいくつかあります。
そのほとんどは今回の範囲を超えています。

`str_split_1`が最もシンプルで、1つの文字列を、指定したパターンで分割した要素のベクトルに変換します（デフォルトのパターンはありません）。

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### 文字列を変換する

一部の言語（主にヨーロッパの言語）では、大文字と小文字を区別します。
これらを相互変換するための`stringr`関数がいくつかあり、ロケールに適した方法で変換します。

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : 各単語の最初の文字を大文字に
- `str_to_sentence()` : 文の最初の文字を大文字に

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

パターンマッチに基づく部分文字列の置換では、`str_replace()`はパターンの最初の出現を変更し、`str_replace_all()`はすべての出現を変更します。

文字のインデックスに基づく部分文字列の置換では、str_sub()の代入形式があります。

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
