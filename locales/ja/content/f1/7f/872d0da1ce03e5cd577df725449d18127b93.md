# インストラクションの補足

JavaScriptは本質的にシングルスレッドなので、並列なコード実行を扱うために他の言語が備えている言語機能の多くがありません。
実際のところ、「本当の」並列実行を実現する唯一の方法は、`Worker threads`（`Web Workers`とも呼ばれます）を使うことです。

並列に実行されているように見えるコード、たとえば`async functions`や`Promises`などは、ほとんどの場合、実際には並行して実行されているだけです。
現代のJavaScriptはそのような使い方に最適化されているため、多くの場合こちらの方が優れています。また、`Promise.all()`やその他の並行実行の手法を使って並列実行を「エミュレート」する（「ごまかす」）コードをよく目にするでしょう。

## 並行性と並列性

まずはそれぞれの簡単な定義を見て、両者の違いを確かめてみましょう。

- 並行性とは、2つ以上のタスクが同じ処理ユニットによって実行され、時間的な期間が重なり合いながら開始・実行・完了できることです。
- 並列性とは、2つ以上のタスクが別々の処理ユニットによって互いに独立して実行され、同時に開始・実行できることです。

念のため、同期実行の定義も挙げておきます。

- 同期実行とは、あるタスクを実行する前に、実行中の別のタスクが完了するのを待たなければならないことです。

## JavaScriptにおける並列性

JavaScriptはデフォルトではシングルスレッドですが、コードを並列に実行する方法はあります。

JavaScriptをブラウザで実行している場合（たとえばWebアプリなど）は、並列性を実現する方法は[Web Worker API][mdn-demo]を使うことです。
MDNの説明は次のとおりです。

> Web Workersを使うと、アプリケーションのメイン実行スレッドとは別のバックグラウンドスレッドでスクリプトの処理を実行できます。

一方、JavaScriptがExercismの実行環境であるNode.jsで動いている場合、同じ概念は[Worker threads][node]と呼ばれます。

~~~@exercism/caution

`Web Worker API`の簡単なデモを紹介します（[Medium][medium-demo]より）。

```js
// main.js
const myWorker = new Worker('worker.js');

myWorker.postMessage(5);

myWorker.onmessage = function (event) {
  console.log('Received result from worker:', event.data);
};
```

```js
// worker.js
onmessage = function (event) {
  console.log('Received number from main thread:', event.data);

  // Perform computation
  const result = event.data * 2;

  // Send result back to the main thread
  postMessage(result);
};
```

次は`Worker threads API`のデモです（[ドキュメント][node]より）。

```js
const {
  Worker,
  isMainThread,
  parentPort,
  workerData,
} = require('node:worker_threads');

if (isMainThread) {
  module.exports = function parseJSAsync(script) {
    return new Promise((resolve, reject) => {
      const worker = new Worker(__filename, {
        workerData: script,
      });
      worker.on('message', resolve);
      worker.on('error', reject);
      worker.on('exit', (code) => {
        if (code !== 0)
          reject(new Error(`Worker stopped with exit code ${code}`));
      });
    });
  };
} else {
  const { parse } = require('some-js-parsing-library');
  const script = workerData;
  parentPort.postMessage(parse(script));
}
```
