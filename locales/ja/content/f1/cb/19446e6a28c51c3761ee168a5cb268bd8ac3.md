# はじめに

多くのプログラミング言語とは異なり、JavaScriptには、（意味のある）値が存在しないことを表す2つの異なるものがあります。
それが`null`と`undefined`です。

## Null

プリミティブ値の`null`は、あらゆる型の変数に対して、意図的な「空の値」として使われます。

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

変数がnullかどうかは、[厳密等価演算子][mdn-strict-equality]`===`を使えば確認できます。

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> 値を代入されていない変数は、`undefined`という型になります。[^1]

つまり、`null`は空の値（ただし値ではあります）を表すのに対し、`undefined`は値がまったく存在しないことを表します。🤯

`undefined`は、さまざまな場面で登場します。

- 変数を値（初期値）なしで宣言すると、その変数は`undefined`になります。

  ```js
  let name;
  console.log(name); // => undefined
  ```

- オブジェクトに存在しないキーの値にアクセスしようとすると、`undefined`が返ります。

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- 関数が値を返さない場合、結果は`undefined`になります。

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- 関数に引数が渡されなかった場合、その引数にデフォルト値がなければ`undefined`になります。

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

変数がundefinedかどうかは、厳密等価演算子`===`を使って確認できます。

```javascript
let name;

name === undefined;
// => true
```

## オプショナルチェーン

オブジェクトの入れ子になった値を取り出そうとしたとき、親のキーが存在しないと、JavaScriptはエラーを投げます。
これを簡単に避けるために、2020年にオプショナルチェーンが言語仕様に追加されました。
オプショナルチェーン演算子`?.`を使うと、親が`null`または`undefined`でない場合にだけ、JavaScriptが入れ子のキーにアクセスしようとします。
それ以外の場合は`undefined`が返ります。

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Null合体

変数がnullまたはundefinedのときにだけ（そしてそのときにだけ）、デフォルト値を適用したい場面があります。
これに対応するために、2020年にNull合体演算子`??`が導入されました。
左辺のオペランドが`null`または`undefined`のときにだけ、右辺のオペランドを返します。
それ以外の場合は、左辺のオペランドが返されます。

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
