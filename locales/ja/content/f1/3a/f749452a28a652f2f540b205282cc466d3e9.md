# はじめに

## 比較

### 数値の比較

`jq`では、数値を次の比較演算子と等価演算子で比較できます。

| 比較             | 演算子 |
| ---------------------- | -------- |
| より大きい           | `a > b`  |
| 以上 | `a >= b` |
| より小さい              | `a < b`  |
| 以下    | `a <= b` |
| 等しい               | `a == b` |
| 等しくない           | `a != b` |

比較の結果は常に真偽値で、`true`か`false`のどちらかになります。

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### 文字列の比較

上記の比較演算子は、文字列の比較にも使えます。
その場合は、辞書式順序（辞書順）が適用されます。
順序は_Unicodeコードポイントの値_によって決まります。

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

数値が入っているように見えても型が文字列である2つの変数を比較するときは、注意が必要です。
辞書順のため、結果は数値型の値を比較した場合と同じにはなりません。

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### 「厳密な」等価性

`jq`の`==`演算子は、見た目が同じでも型が異なるものは等しくないという点で、JavaScriptの`===`に似ています。

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### 配列の比較

2つの配列は、対応するすべての要素が等しければ等しいとみなされます。

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### オブジェクトの比較

2つのオブジェクトは、同じキーと値のペアを持っていれば等しいとみなされます。

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## 条件分岐

### `if`式

`jq`の**条件式**は`if A then B else C end`です。

`if-then-else`は、他のすべての`jq`の組み込み関数と同じくフィルターです。入力を受け取り、出力を生成します。

式`A`が「真とみなされる」値を生成すると、`if`フィルターは`B`を評価します。
そうでなければ、`C`を評価します。
`if`フィルターへの入力は、`B`または`C`に渡されます。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`節は**省略可能**です。次の2つの文は等価です。

```jq
if A then B else . end
if A then B end
```
~~~~

### 入れ子の`if`文

`elif`を使うと、さらに条件を追加できます。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

`elif`節は必要なだけいくつでも使えます。

### 真偽の判定

`jq`で「偽」となる値は`false`と`null`だけです。
それ以外はすべて「真」になります。数値のゼロ、空の文字列・配列・オブジェクトでさえも「真」です。

### 真偽値演算子

**真偽値演算子**の`and`と`or`を使うと、複雑なクエリを組み立てられます。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

否定するには、`not`を使います。これは演算子ではなく**フィルター**です。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### 代替演算子

**代替演算子**を使うと、式が偽またはnullの場合の「デフォルト」値を指定できます。

```jq
A // B

# This is identical to
if A then A else B end
```

例を見てみましょう。

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
