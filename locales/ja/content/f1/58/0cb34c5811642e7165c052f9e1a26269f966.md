### はじめに

Javaトラックの最初の演習へようこそ！

このドキュメントは、この演習を解くための順を追ったガイドです。手順はWindows、macOS、Linuxのどれでも同じように使えます。

Javaの基本をすでに知っている人でも、このガイドを順にたどることは役に立ちます。コードのコンパイルとテストに使うツールGradleの出力を理解できるようになりますし、このトラックのすべての演習に共通するパターンもいくつか紹介します。

### 演習の構成

新しいJavaの演習を取得すると、次のものが届きます。

- __1つ以上のテストファイル__（必ずあります）。
これらは`src/test/java`ディレクトリにあり、解答がきちんと動いていると言えるために満たすべきテストを定義しています。
- __1つ以上のスターターファイル__（最初に用意されています）。
用意されている場合、これらは`src/main/java`ディレクトリにあり、今の問題を解くのに必要なクラスの骨組みを定義しています。

### 「Hello, World!」を解く

オンラインエディターで解答を書いてテストを実行することもできますが、手元の環境で問題を解いてテストを実行したい場合は、次のリンクを確認してください。

- [Javaのインストール][Installing Java]
- [ローカルでの作業][Working Locally]
- [Javaトラックでローカルにテストする][Testing locally on the java track]

### ステップ1：解答を修正する

ローカルで作業していても、オンラインエディターを使っていても、次のコードがあるはずです。

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

目標は、用意されたコードを書き換えて、`"Goodbye, Mars!"`ではなく`"Hello, World!"`というテキストを出力するようにすることです。

### ステップ2：テストを実行する

修正して解答を実装したら、もう一度テストを実行します。テストはオンラインエディターでも、自分のマシン上でも実行できます。

- オンラインエディターでテストを実行するには、「Run Tests」ボタンをクリックします。
- ローカルでテストを実行するには、[Javaトラックでのテスト][Testing locally on the java track]を確認してください。テストが失敗しても大丈夫です！　エラーメッセージが何を伝えているのかを見て、コードを直してもう一度テストします。テストが通ったら、次のステップに進みましょう。

### ステップ3：最初の解答を提出する

動く解答ができて見直しも済んだら、exercism.orgに提出する準備は完了です。解答はオンラインエディターからでも、[Exercism CLI][Working Locally]を使ってローカルからでも提出できます。

- 演習をローカルから提出するには、まだの場合はまず[exercism CLIをインストール][Working Locally]してから、解答のファイルを提出します。たとえば次のとおりです。

  ```sh
  exercism submit <file location>
  ```

- `<file location>`は`Greeter.java`ファイルの相対パスに置き換えます。たとえば`C:\exercism\java\hello-world`で作業しているなら、コマンドは次のようになります。

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- オンラインエディターから解答を提出したい場合は、「Submit」ボタンをクリックするだけです！

ローカルでの解答の提出について詳しくは、こちらをご覧ください。

- [ローカルで提出する][Working Locally]

### メンターになる

Exercismの核心は、コードの書き方について交わされる会話です。練習そのものももちろん楽しいですが、ほかの人の挑戦や自分の解答に触れることでフィードバックが得られます。そのフィードバックは、うまくできているところと、もっと改善できるところを教えてくれます。

提出された解答の中には、自分のものとほとんど同じものもあれば、まったく違うものもあります。どちらも見ると、勉強になるし面白いものです。

メンターは、自分が担当するトラックに提出された解答をレビューして、学習者ができるだけ多くを学べるように支えます。

メンタリングについてもっと知りたい場合は、[Exercismのドキュメント][Mentoring]を見てください。
