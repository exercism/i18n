# 指示

混み合った銀行では、待っているお客さんを、来た順ではなく*優先度*の順に応対します。お客さんは番号札を取るときに優先度の番号を受け取り、窓口係はいつも次にいちばん小さい番号のお客さんを応対します（`1`がいちばん急ぎです）。最小ヒープは、順番待ちの列にうってつけです。

## 1. キューを開く

`new-queue`を定義します。何も受け取らず、新しい空の優先度付きキューを返します。

```factor
new-queue
! => an empty priority queue
```

## 2. お客さんを追加する

`join-queue`を定義します。これはお客さんの名前、優先度の番号、キューを受け取ります。お客さんをキューに追加して、そのキューを返すので、お客さんを次々に追加できます。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. 次は誰？

`next-name`を定義します。キューを受け取り、次に応対すべきお客さん（いちばん小さい優先度の番号を持つお客さん）の名前を、そのお客さんを*取り除かずに*返します。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. 全員を応対する

`serve-all`を定義します。キューを受け取り、待っているすべてのお客さんの名前を、応対される順に返します。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
