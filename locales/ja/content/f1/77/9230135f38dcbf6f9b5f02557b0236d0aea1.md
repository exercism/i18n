# ヒント

## 1. セリフを言う2つの方法

- `.upper`と`.lower`は、1文字だけでなく文字列全体に働きます。
- `whisper`は、小文字にしたセリフの両端に`"..."`を連結します。

## 2. セリフを練習する

- 引数の型は`ROUT{STR}:STR`と書きます。波括弧の中が引数の型で、コロンのあとが答えです。
- 本体は1行です。`return part.call(line);`
- `rehearse`は`shout`や`whisper`に言及してはいけません。知らないことこそが、束縛されたルーチンを受け取る意味そのものなのです。

## 3. シーン全体

- `rehearsal-script`と同じように、ループと`FSTR`を使います。
- 各行で`part.call(...)`を呼び出し、最初の行を除くすべての行の前に`" "`を置きます。

## 4. ものを言う方法を返す

- 戻り値の型は`ROUT{STR}:STR`で、タスク2の引数の型とまったく同じです。
- クラスの中では`bind(shout(_))`と書きます。自分のクラスから呼び出すルーチンと同じで、クラス名は必要ありません。
- `return bind(...)`は構文エラーになります。`bind`は、まず代入の右辺に置く必要があります。

  ```sather
     part : ROUT{STR}:STR;
     if ... then part := bind(shout(_)); else ... end;
     return part;
  ```

- 2つの場合があるので、`if`を使うか、`else`付きの`case`を使います。

## 5. 引数を固定する

- `repeat`自体はごく普通のルーチンです。ループと`FSTR`、そして`1.upto!(times)`を使います。
- `doubler`は、数値をそのまま書き、セリフを穴として残して束縛します。`bind(repeat(2, _))`です。タスク4と同じく、変数に入れてそれを返します。
- 束縛されたルーチンの引数になるのは`_`だけです。だからこそ`bind(repeat(2, _))`の型は`ROUT{INT,STR}:STR`ではなく`ROUT{STR}:STR`なのです。
