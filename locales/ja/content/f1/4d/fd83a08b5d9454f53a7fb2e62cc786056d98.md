# ヒント

## 全般

- 基本方位を表す4つのシンボルと、相対方位を表す4つのシンボルは、1つの`SYMBOLS:`行で宣言します：
  `SYMBOLS: north east south west ahead starboard behind port ;`
- 各タプルは`TUPLE: <class> <slot1> <slot2> ;`で宣言します。
- `GENERIC:`行はワードを宣言します。それぞれの`M:`行が、1つのクラスにメソッドを追加します。メソッド本体で名前付きローカルを使いたい場合は`M::`を使います。

## 1. 基本方位用の`>cartesian`

- 4つの方向シンボルに対する小さな`case`で十分です。
- `{ north [ 0 1 ] }`の場合、本体は2つの値をプッシュするだけです。テストは、スタック上で`x`が`y`より下にあることを期待します。

## 2. 極座標用の`>cartesian`

- 度をラジアンに変換します：`bearing pi * 180 /`。
- `sin`と`cos`は`math.functions`にあります。
- `magnitude * sin(rad)`をプッシュしてから、`magnitude * cos(rad)`をプッシュします。

## 3. 相対方位用の`>cartesian`

- 動的変数を宣言します：`SYMBOL: heading`。
- メソッド内では`heading get`で読み取ります。
- `ahead/starboard/behind/port`を`case`で`0/90/180/270`のオフセットに対応させ、それから方位を足します。あとは、タスク2と同じ極座標変換です。補助ワード`: deg>cartesian ( magnitude bearing -- x y ) ... ;`をくくり出すことを検討してみましょう。

## 4. `flip`

- `cardinal`に対する`change-direction`と、`polar`または`relative`に対する`change-bearing`は、1つのスロットだけを変更した新しいタプルを作り、残りはそのままにします：
  `[ <transformation-quotation> ] change-bearing`。
- `polar`の回転には、`[ 180 + 360 mod ] change-bearing`を使います。

## 5. `add-bearings`

- 各入力に対して`>cartesian`を呼び出し、それからx成分とy成分を足します。ローカルを使うと読みやすくなります：
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
