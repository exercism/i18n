# トップレベルの定数として抽出しましょう

定数はトップレベルのスコープに抽出することを検討してみましょう。

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

外部から見えてアクセスできるのは、`export`された関数、クラス、定数だけです。
これらの定数は、他のコードに公開されることなく、同じファイル内に置くことができます。
また、定数を抽出すると、同じ定数を繰り返し使うときに関数内で毎回割り当てが起こるのを避けられるため、メモリを節約できます。
