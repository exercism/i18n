# 文字列メソッド

`str`は、[Unicodeコードポイント][unicode code points]の[イミュータブルなシーケンス][text sequence]です。
これには、文字、発音区別符号、位置指定文字、数字、通貨記号、絵文字、句読点、空白、改行などが含まれます。

文字列はすべての[共通シーケンス操作][common sequence operations]を実装しており、`for item in <str>`や`for index, item in enumerate(<str>)`という構文で繰り返し処理できます。
 個々のコードポイント（_長さ1の文字列_）は、左からの`0-based index`、または右からの`-1-based index`で参照できます。

  文字列は`<str> + <other str>`や`<str>.join(<iterable>)`で連結でき、`<str>.split(<separator>)`で分割できます。
   そのほかにも、さまざまな書式設定や組み立てのオプションがあります。

 文字列をさらに操作するために、Pythonには検索、クリーニング、変換、翻訳など、さまざまな操作のための豊富な[文字列メソッド][str-methods]が用意されています。

よく使われる`str`メソッドには、次のようなものがあります。

- `<str>.startswith(<substr>)`と`<str>.endswith(<substr>)`で接頭辞／接尾辞を確認する
- `<str>.title()`、`<str>.upper()`／`<str>.lower()`、`<str>.swapcase()`などのメソッドで文字列の大文字と小文字を変える
- `<str>.strip(<chars>)`、`<str>.lstrip(<chars>)`、`<str>.rstrip(<chars>)`を使って、文字列の先頭または末尾の文字を削除する
- `<str>.replace(<old>, <new>)`メソッドで部分文字列を置き換える

_イミュータブル_であるため、`str`オブジェクトのメモリ上の値は変わりません。文字列を変更しているように見えるメソッドは、その`str`オブジェクトの新しいコピー、つまり新しいインスタンスを返します。


[`<str>.endswith(<suffix>)`][str-endswith]は、文字列が`<suffix>`で終わっていれば`True`を、そうでなければ`False`を返します。

```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.title()`][str-title]は文字列を解析し、見つかった各「単語」の最初の「文字」を大文字にします。
Pythonでは、これは使用される[言語コーデック][codecs]や、その言語が単語や文字をどのように表現するかに大きく依存します。
また、言語や文字セットに応じた[ロケール][locale]のルールが適用されることもあります。


```python
>>> man_in_hat_th = 'ผู้ชายใส่หมวก'
>>> man_in_hat_ru = 'мужчина в шляпе'
>>> man_in_hat_ko = '모자를 쓴 남자'
>>> man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```


[`<str>.strip(<chars>)`][str-strip]は、先頭と末尾の`<chars>`を削除した`str`のコピーを返します。
`<chars>`で指定されたコードポイントは、接頭辞や接尾辞ではありません。コードポイントの**すべての組み合わせ**が、文字列の**両端**から削除されます。
 `<chars>`に何も指定しない場合は、空白のコードポイントのすべての組み合わせが削除されます。
 左側だけ、または右側だけを削除したい場合は、`<str>.lstrip(<chars>)`や`<str>.rstrip(<chars>)`を使えます。


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
 ```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace]は、`<substring>`のすべての出現箇所を`<replacement substring>`に置き換えた文字列のコピーを返します。


以下で使われている引用は、[Lewis Carroll][Lewis Carroll]の[The Hunting of the Snark][The Hunting of the Snark]によるものです。

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```

🌟**Python `3.9`で新しく追加されました**

Python `3.9`では、接頭辞と接尾辞の削除をずっと簡単にする2つの新しい文字列メソッドが導入されました。

[`<str>.removeprefix(<substring>)`][removeprefix]は、接頭辞を取り除いた文字列（`string[len(<substring>):]`）を返します。`<substring>`が存在しない場合は、元の文字列のコピーが返されます。

```python
# removing a prefix
>>> 'TestHook'.removeprefix('Test')
'Hook'
>>> 'bookkeeper'.removeprefix('book')
'keeper'
```

[`<str>.removesuffix(<substring>)`][removesuffix]は、接尾辞を取り除いた文字列（`string[:-len(substring)]`）を返します。`<substring>`が存在しない場合は、元の文字列のコピーが返されます。

```python
# removing a suffix
>>> 'TestHook'.removesuffix('Hook')
'Test'
>>> 'bookkeeper'.removesuffix('keeper')
'book'
```
