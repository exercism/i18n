# 説明

DNA研究所では、研究データを圧縮して保存容量を節約するためのさまざまな方法を検討してきました。ある同僚が、DNAデータをバイナリ表現に変換することを提案します。

| 核酸 | コード |
| ------------ | ------ |
| 空白         | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

そうすれば必要なデータ保存コストを半分にできる可能性がありますが、その代わりに人が読むにはわかりにくくなります。そこで、どれだけ節約できるかを確かめるために、データをエンコード・デコードするモジュールを書くことにします。

## 1. 核酸をバイナリ値にエンコードする

`encode_nucleotide/1`を実装して、核酸のコードポイントを受け取り、エンコードされたコードの整数値を返すようにします。

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. バイナリ値を核酸にデコードする

`decode_nucleotide/1`を実装して、エンコードされたコードの整数値を受け取り、核酸のコードポイントを返すようにします。

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. DNAの文字リストをエンコードする

`encode/1`を実装して、核酸と空白を表す文字リストを受け取り、エンコードされたデータのビット列を返すようにします。

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. DNAのビット列をデコードする

`decode/1`を実装して、核酸と空白を表すビット列を受け取り、デコードしたデータを文字リストとして返すようにします。

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
