# はじめに

多くのプログラミング言語には、さまざまな種類の数値を表すための専用の数値型がありますが、JavaScriptの数値型は2つだけです。

- `number`:倍精度64ビット浮動小数点形式（IEEE 754）の数値データ型です。例えば、`-6`、`-2.4`、`0`、`0.1`、`1`、`3.14`、`16.984025`、`25`、`976`、`1024.0`、`500000`などがあります。
- `bigint`:任意精度形式で_整数_を表せる数値データ型です。例えば、`-12n`、`0n`、`4n`、`9007199254740991n`などがあります。

[任意精度][ref-arbitrary-precision]が必要な場合や、非常に大きな数を扱う場合は、`bigint`型を使いましょう。そうでなければ、`number`型のほうが適しているでしょう。

## 丸め

`Math`という組み込みのグローバルオブジェクトには、さまざまな[丸め関数][ref-math-object-rounding]が用意されています。例えば、小数を最も近い整数に切り捨て（`floor`）たり、切り上げ（`ceil`）たりできます。

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

[ref-arbitrary-precision]: https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic
