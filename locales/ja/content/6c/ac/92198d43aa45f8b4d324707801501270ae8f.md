# 説明

この演習では、工場の従業員向けの名札を出力するコードを書きます。

## 1. 従業員の名札を出力する

従業員にはID、名前、部署名があります。従業員の名札のラベルは、次の形式です：`"[id] - name - DEPARTMENT"`。従業員の名札のラベルを返すように、（_static_）`Badge.Print()`メソッドを実装しましょう。

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

なお、ラベルでは部署名を大文字にします。

## 2. 新しい従業員の名札を出力する

コンピューターシステムの不具合により、新しい従業員が工場で働き始めるとき、まだIDを持っていないことがあります。名札は必須なので、その場合はIDの接頭辞がない一時的な名札が渡されます。まだIDを持っていない新しい従業員に対応できるように、（_static_）`Badge.Print()`メソッドを変更しましょう。

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. オーナーの名札を出力する

工場のオーナーも、いつでも名札を着けなければなりません。ただし、オーナーには部署がありません。この場合は、ラベルに部署名の代わりに`"OWNER"`と出力します。オーナーのラベルを出力するように、（_static_）`Badge.Print()`メソッドを変更しましょう。

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

オーナーが新しい従業員でもある場合があることに注意しましょう。

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
