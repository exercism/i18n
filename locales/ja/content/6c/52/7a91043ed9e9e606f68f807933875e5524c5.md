# はじめに

## 列挙型

C#の`enum`型は、名前付き定数の固定セット（列挙型）を表します。その主な目的は、数値定数を型安全に扱えるようにし、使用できる値をあらかじめ定義されたセットに限定することです。単純な列挙型は次のように定義できます：

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

明示的に定義しない場合、列挙型のメンバーには自動的に1ずつ増える整数値が割り当てられ、最初の値は0になります。値を明示的に割り当てることもできます：

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
