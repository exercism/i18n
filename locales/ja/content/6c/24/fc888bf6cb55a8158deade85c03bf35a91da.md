# はじめに

## 構造体とクラス

構造体とクラスは、Swiftプログラミングの主要な構成要素の2つです。どちらも、関連するデータと関数をまとめて、自己完結した機能の単位にするための仕組みです。そして、構造体やクラスを定義することは、Swiftの中で使う新しい型を定義することです。これまでに扱ってきた`Int`や`String`のような型を使うのと同じことです。

Swiftの構造体とクラスには、多くの共通点があります。いくつもの共通点のなかでも、どちらも値を_プロパティ_に保存でき、_メソッド_を通じて機能を提供できます。

それぞれに追加の機能もありますが、それはこの演習の範囲外です。

### 構造体とクラスの定義

構造体もクラスも、ほぼ同じ方法で定義します。まず適切なキーワードを書き、その後に定義する型の名前を続けます。そして構造体やクラスの本体を、波括弧の間に書きます。

本体には格納プロパティを書くことができます。格納プロパティは、通常の定数や変数と同じように定義し、同じように振る舞います。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### インスタンス

前述のとおり、構造体やクラスを定義することは、新しい_型_を定義することにすぎません。それはその型の値がどんな形になるかを示す設計図にすぎず、実際にその型の値を生成して使えるようにするものではありません。

その型の_インスタンス_を生成するには、型の名前を書き、その後に括弧（`()`）を続けます。

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

こうすると、これらの型の値が生成され、プロパティには定義で指定したデフォルト値が設定されます。GameCharacterの`name`プロパティのようなオプショナルの場合は、値を指定しない限り、プロパティはデフォルトでnilになります。これは、値をすぐに指定しない通常のオプショナル型を定義するときと同じです。

構造体では、Swiftが自動的に_メンバーワイズイニシャライザー_を提供します。これを使うと、括弧の中に構造体のプロパティの値を指定でき、それが定義内のデフォルト値を上書きします。

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### プロパティへのアクセス

構造体やクラスのプロパティには、_ドット記法_を使ってアクセスできます。値の名前の後にドット（`.`）とプロパティの名前を書きます。ある構造体やクラスのプロパティがさらに自分のプロパティを持っている場合は、このドット記法でそうした入れ子のプロパティにもアクセスできます。

この記法は、プロパティの値を取得するのにも、許可されている場合は変更するのにも使えます。

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### メソッド

構造体やクラスにデータを保存するプロパティと同様に、構造体やクラスに関数を保存する_メソッド_も定義できます。

メソッドは通常の関数と同じ方法で定義しますが、構造体やクラスの本体の内部に書く点だけが違います。構造体のプロパティの値を変更する関数には、先頭に`mutating`キーワードを付ける必要があります。さらに、メソッドから変更できるプロパティは、通常の変数と同じように、`let`ではなく`var`を使って定義しなければなりません。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

こうしたメソッドは、プロパティと同じようにドット記法で呼び出せます。

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

構造体やクラスのすべてのインスタンスには、`self`という暗黙のプロパティがあり、これはインスタンス自身を指します。
`self`の最も一般的な用途は、インスタンスプロパティと、同じ名前を持つ仮引数とを区別することです。

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swiftの型には、大文字で始まる`Self`キーワードもあり、これはインスタンス自身ではなく、そのインスタンスの*型*を指します。
