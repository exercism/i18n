# はじめに

Elixirの文字列はダブルクォートで囲み、UTF-8でエンコードされています。

```elixir
"Hi!"
```

文字列は`<>/2`演算子を使って連結できます。

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixirの文字列は、`#{}`という構文で補間できます。

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

文字列に改行文字を入れるには、`\n`というエスケープシーケンスを使います。

```elixir
"1\n2\n3\n"
```

改行の多いテキストを快適に扱いたいときは、代わりにダブルクォート3つのヒアドキュメント構文を使いましょう。

```elixir
"""
1
2
3
"""
```

Elixirは、文字列を扱うための多くの関数を`String`モジュールで提供しています。
