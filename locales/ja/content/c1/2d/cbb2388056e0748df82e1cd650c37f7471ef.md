# はじめに

## ランダム

Elmのような純粋関数型言語では、同じ引数で呼び出された関数は、常に同じ値を返さなければなりません。
そのため、型シグネチャが`rand : Int`である関数は`rand = 4`としか実装できません。これでは乱数を生成するには心もとない話です。

では、Elmでランダムな値はどうやって生成するのでしょうか？　問題を2つに分けます。まず、生成したい値を`Random.Generator a`で記述し、次に値を生成します。

値を生成する1つ目の方法は、`initialSeed : Int -> Seed`で`Random.Seed`を作り、次に`step : Generator a -> Seed -> ( a, Seed )`を使うことです。これは値と新しいシードを返します。
どちらの関数も純粋なので、同じ引数で2回呼び出すと、同じ値が生成されることに注意してください。

値を生成する2つ目の方法は、`generate : (a -> msg) -> Generator a -> Cmd msg`を使うことですが、これはElmアプリケーションの中でしか行えません。
その場合、Elmランタイムは`step`だけでなく、外部の純粋でないリソースも使ってシードを生成することがあります。

ここからは、ジェネレーターに焦点を当てます。

例を示すために、`initialSeed`と`step`を使って、ジェネレーターからいくつかの値を生成する関数`generate : Int -> Generator a -> List a`を定義したとしましょう。

`Random`モジュールには、特定の範囲の整数と小数を生成するための基本的なジェネレーターが2つ用意されています。

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

これらの値は、タプルにまとめたり、値の配列にまとめたりできます。

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra`パッケージには、文字列、日付、辞書、配列、集合など、さまざまなデータ構造のためのジェネレーターがたくさん用意されています。

`Random.constant`を使うと、常に1つの値だけを返すジェネレーターを作れます。

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform`を使うと、与えられた要素の中から等しい確率でランダムに選べます。

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`が2つの引数（`Red`と`[Green, Blue]`）を取るのは、選べる値が少なくとも1つあることを保証するためです。配列を1つだけ渡すと、空になっている可能性があるからです。

`Random.weighted`を使えば、確率を調整することもできます。

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

値の合計は100でなくてもかまいません。最終的には正規化されます。

`Random.map`を使うと、ジェネレーターの中の値に手を加えられます。

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

`Random.map2`から`Random.map5`までを使えば、より多くのジェネレーターを組み合わせることもできます。

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

もっと複雑な用途には、`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`があります。これは、あるジェネレーターが生成した値を使って別のジェネレーターを作れます。

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

ジェネレーターを自己再帰的に定義すると便利なことがあります。
そのような場合は、コンパイラーがジェネレーターを無限に展開しないように、`Random.lazy`を使う必要があるかもしれません。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

この例は少し重いので、分解してみましょう。

`Peano`は正の整数を表す型です。`Zero`が0、`Next(Zero)`が1、`Next(Next(Zero))`が2、というようになります。
`peano`は、ランダムな`Peano`の数値を得るために定義します。

まず、`Random.lazy`はロジックに何も付け加えず、コンパイラーが`peano`を`peano`の中に無限に書き込むのを防ぐだけであることに注意してください。

`Random.uniform`を使って、0（50%の確率）か、別の`Peano`の数値に1を足したもの（50%の確率）のどちらかを選びます。
ただし、前の例とは違い、`Random.uniform`は値（`Zero`など）から選ぶのではなく、ジェネレーター（`Random.constant Zero`など）から選びます。`peano`自身を使いたいからです。
これはつまり、`Random.uniform`が`Generator (Generator Peano)`型の値を返すということで、必要なものではありません。

ジェネレーターを「平坦化」するには、それを`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`にパイプします。ここでは`b`が`Peano`であってほしいところです。
`Generator a`は`Generator (Generator Peano)`なので、`a`は`Generator Peano`でなければならず、関数`(a -> Generator b)`は`(Generator Peano -> Generator Peano)`型でなければなりません。
何も変更したくないので、`identity`が適切な選択です。

最後に、`peano`はどんな数値を生成するのでしょうか？　50%の確率で0を、50%の確率で自分自身をもう1回繰り返して1を足したものを生成することがわかります。
つまり、数値は0（50%の確率）、1（25%の確率）、2（12%の確率）、3（6%の確率）…となります。
`peano`はいくらでも大きな数値を生成できますが、その確率は指数的に小さくなります。
