# 説明の補足

## ソートパッケージ

この演習では配列をソートする必要がありますが、標準ライブラリにはその機能が組み込まれていません。自分でソート用のライブラリを書くこともできますが、[sortsパッケージ](https://github.com/diku-dk/sorts)を使うほうがよいでしょう。

解答のディレクトリで次のコマンドを実行すると、このパッケージを解答で使えるようになります。

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

次に、[使いたいソートアルゴリズム](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts)をインポートします。

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
