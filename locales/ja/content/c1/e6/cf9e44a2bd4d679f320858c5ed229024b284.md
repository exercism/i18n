# 説明の補足

## 入力形式

入力のリストはそれぞれ、ヌル終端文字列として表され、各入力の末尾には改行文字が付きます。

例えば、`"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`のようになります。

## レジスター

| レジスター | 用途       | 型      | 説明                                                           |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | 入力         | アドレス | 各入力の後ろに改行が付いた、ヌル終端の入力文字列                |
| `$a1`    | 入力/出力    | アドレス | ヌル終端の出力文字列                                            |
| `$t0-9`  | 一時        | 任意     | 一時的な保存用                                                  |
