# はじめに

Common Lispでは、時刻は4つの方法で表現されます。ここではそのうち2つを取り上げます。

- ユニバーサル時間は絶対的な時刻であり、`1900-01-01T00:00:00Z`からの秒数を表す整数です（これはUTCの1900年1月1日0時のことです）。
- デコード時間は9つの値のタプルで、それらを合わせると特定の暦時刻を表します。値は秒、分、時、日、月、年、曜日、夏時間フラグ、タイムゾーンです。
（詳しくは後述します。）

## ユニバーサル時間

現在のユニバーサル時間を得るには、`get-universal-time`または`get-decoded-time`を使います。
前者は`1900-01-01T00:00Z`からの現在の秒数を返し、後者は同じデータをデコードされた形式で返します。

## デコード時間

`decode-universal-time`と`encode-universal-time`は、時刻を扱うための主要な関数です。
前者はユニバーサル時間を受け取り、デコード時間の値を[multiple-values][concept-multiple-values]として返し、後者はデコード時間の値を引数として受け取り、ユニバーサル時間を返します。

どちらも省略可能なタイムゾーンの引数を取ります。
タイムゾーンの形式については、後述します。

デコード時間は値の集まりです。

- *秒*：0から59までの整数
- *分*：0から59までの整数
- *時*：0から23までの整数
- *日*：1から31までの整数（上限は言うまでもなく月と年に依存します）
- *月*：1から12までの整数
- *年*：年を表す整数。
- *曜日*：0から6までの整数。0は月曜日、1は火曜日などを意味し、6は日曜日です。
- *夏時間フラグ*：真の値は夏時間が適用されていることを示します。
- *タイムゾーン*：UTCからのオフセットを表す、-24から24までの時間数。
値は有理数で、`1/3600`の倍数でなければなりません。

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
