# はじめに

リンケージとは、コード内のどこから識別子にアクセスできるかを表します。
ブロックスコープ、関数スコープ、関数プロトタイプスコープを持つ値には、リンケージがありません。
つまり、自分のスコープの外からアクセスすることはできません。
スコープについて詳しくは、[スコープの概念](../scope/introduction.md#Introduction)を参照してください。

## 外部リンケージ

ファイルスコープを持つ識別子は、デフォルトで外部リンケージを持ちます。
外部リンケージを持つ識別子は、プログラム内のどのファイルからでも呼び出すことができます。

## 内部リンケージ

ファイルスコープを持つ識別子は、`static`指定子を使うことで内部リンケージを持たせることができます。
内部リンケージを持つ識別子は、そのファイル内でのみ使うことができます。

例えば

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

静的リンケージは、静的記憶域期間と混同しないようにしましょう。
静的記憶域期間について詳しくは、[記憶域期間の概念](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type)を参照してください。
