# 手順

この演習では、ログ行を処理します。

各ログ行は`"[<LVL>]: <MESSAGE>"`という形式の文字列です。

ログレベルには次のものがあります：

- `TRC`（トレース）
- `DBG`（デバッグ）
- `INF`（情報）
- `WRN`（警告）
- `ERR`（エラー）
- `FTL`（致命的）

タスクは3つあります。

## 1. ログレベルを解析する

上記のログレベルに対応する6つの要素を持つ`LogLevel`列挙型を定義しましょう。

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

次に、ログ行を解析したログレベルを返す`LogLine.getLogLevel()`メソッドを実装しましょう：

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. 未知のログレベルに対応する

残念ながら、ときどき未知のログレベルを持つログ行があります。
こうしたログ行を問題なく処理できるようにするため、`LogLevel`列挙型に`UNKNOWN`要素を追加しましょう。これは、未知のログレベルを解析するときに返す必要があります：

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. ログ行を短い形式に変換する

ログ行のログレベルはかなり冗長です。
ログ行を保存するために必要なディスク容量を減らすため、`"[<ENCODED_LEVEL>]:<MESSAGE>"`という短い形式が考案されました。

エンコードされたログレベルは、ログレベルを数値に単純に対応付けたものです：

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

短縮されたログ行の形式を出力する`LogLine.getOutputForShortLog()`メソッドを実装しましょう：

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
