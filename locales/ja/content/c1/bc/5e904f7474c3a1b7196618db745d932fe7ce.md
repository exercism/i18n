# 詳細

## 関数の型

これまでに、関数シグネチャがどのように定義されるかを見てきました。関数名のあとに、仮引数のラベルとその型をカンマで区切って並べ、続けて`->`と、その関数が返す値の型を書きます。

このシグネチャから名前とラベルをすべて取り除くと、[関数の型][function-types]だけが残ります。

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

最初の2つの関数の型が同じ`(String, Int) -> String`であることに注目してください。2つの関数の動作は大きく異なるのに、です。どちらも`String`と`Int`を入力として受け取り、`String`を返します。そして、3つ目の関数の型からわかるように、この関数は何も返さないように見えても、実際には`Void`型の唯一の値である`()`を返します。`()`と`Void`は型名として互換性があるため、`printString`の型は`String) -> Void`と書くこともできます。

これらの型は、Swiftの他の型と同じように使えます。たとえば、変数や定数の宣言に使うことができます。また、Swiftでは関数は値なので、すでに存在する関数をこれらの定数や変数に代入できます。

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

他の変数や定数と同様に、代入する値は正しい型でなければなりません。

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## 関数の型を仮引数の型として使う

関数の型は他の型が使えるところならどこでも使えるので、[仮引数の型として使う][functions-as-parameters]こともでき、他の関数に渡してその関数の中で呼び出すことができます。

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## 関数の型を戻り値の型として使う

同様に、[関数の型は関数の戻り値の型として使う][functions-as-returns]こともできます。つまり、他の関数を作成して返す関数を書けるのです。このような関数を作るとき、返される関数は、その関数に渡された他の仮引数や、親関数の中で作られたローカル変数を使うことができます。

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## 値のキャプチャ

上の`makeAdder(base:)`関数で見たように、入れ子の関数は、それを囲む関数の仮引数や変数にアクセスできます。さらに、外側の関数が終了したあとも、これらの値へのアクセスを保ち続けることができます。この、アクセスを取得して保つ働きを[_キャプチャ_][capturing-values]と呼びます。

## 高階関数

関数を仮引数として受け取ったり、関数を返したりする関数を、高階関数と呼びます。Swiftには、さまざまなライブラリにたくさんの高階関数があります。たとえば、`Array`などのSwiftのコレクションで使える`sorted(by:)`メソッドがあります。これは、要素の型が`T`の配列に対して、`(T, T) -> Bool`型の関数を受け取ります。この関数は、2つの値のどちらが並べ替え後の配列で先に来るべきかを決めるもので、左側の値が先に来るべきなら`true`を、右側の値が先に来るべきなら`false`を返します。

もう一つの例は、コレクションの`contains(where:)`メソッドです。これは、要素の型が`T`のコレクションに対して、`(T) -> Bool`型の関数を受け取ります。この関数は、要素がある条件を満たすなら`true`を、そうでなければ`false`を返します。そして`contains(where:)`は、コレクションの中にその条件を満たす要素があれば`true`を返します。

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
