# はじめに

## パターンマッチング

`if/elif/else`式を使うと、条件に応じて処理を実行できます。F#には、条件に応じて処理を実行する、より強力な方法がもう1つあります。それがパターンマッチングです。パターンマッチングでは、1つ以上の_パターン_に対して値をテストできます。そのようなパターンの例として、_定数パターン_があります。これは、定数（例: `1`や`"hello"`）に対して値をマッチさせます。

F#では、パターンマッチングは`match`キーワードを使って行います。

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

これは他の言語の`switch`文と似ているように見えるかもしれませんが、他のパターンも合わせて使うと、パターンマッチングの真価が発揮されます。そのようなパターンの1つに、値をキャプチャできる_変数パターン_があります。

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

場合によっては、パターンに追加の条件を加えたいことがあります。これは_ガード_（節）として知られており、`when`キーワードを使って追加できます。

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

上記の例では、すべての可能な入力に一致するパターンがあるわけではありません。コンパイラーがこれを検出し、警告を出力します。これは_網羅性チェック_として知られています。警告を解決するには、すべてのケースを処理する必要があります。そのためには、_ワイルドカードパターン_を使います。これは、任意の値にマッチするパターンです。

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

パターンマッチングは、上から下へと各パターンに対して値をテストし、一致するパターンを見つけて、そのパターンに関連付けられた処理を実行します。パターンの順序は重要です！
