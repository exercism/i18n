# 詳細

[高階関数](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions)とは、次のいずれかに当てはまる関数のことです。

- 関数を引数として受け取る
- 関数を返す

関数の引数も、ただの普通の引数です。ただし、呼び出すことができるという点が違います。

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
