# はじめに

判別共用体型は、一定数の名前付きケースを表します。判別共用体の各値は、名前付きケースのうち、ちょうど1つに対応します。

判別共用体は、`type`キーワードを使って定義し、各ケースはパイプ文字（`|`）で区切ります。

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

判別共用体の各ケースには、任意でデータを関連付けることができ、ケースごとに異なる型のデータを持たせられます。どのケースにもデータが関連付けられていない場合、その判別共用体は、他の言語でよく_列挙型_（または_enum_）と呼ばれるものに似ています。

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

特定のケースの値を作るには、その名前（例: `Success`）を参照します。ケース名はただのコンストラクター関数なので、関連付けられたデータは通常の関数の引数として渡せます。別の判別共用体が同じ名前のケースを定義している場合は、その完全な名前（例: `Result.Success`）を使う必要があります。

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

判別共用体は_構造的等価性_を持ちます。つまり、同じケースで同じ（任意の）データを持つ2つの値は等価です。

判別共用体を扱うには`if/elif/else`式を使うこともできますが、推奨されるのは、_識別子パターン_を使ったパターンマッチングです。

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
