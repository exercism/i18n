# インストール

## Godot Engineのインストール

GDScriptトラックは、Windows、Linux、macOS、Androidで動作する[Godot Engine][godot-engine]を基盤にしています。
現時点では、[ローカルで作業する][working-locally]ためのテストランナーにはLinuxが必要です。
このトラックにはGodot 4.0以降が必要です。

インストールが完了したら、ターミナルで次のコマンドを実行すると、CLIが正しくインストールされたか確認できます。

```bash
godot --version
```

## Exercism GDScriptトラックのテストランナーのインストール

テストランナーを使うには、[Godotが正しくインストール][installation]されている必要があります。

Exercism向けのGDScriptスクリプトをビルドしてテストするために、GodotはCLIから「ヘッドレス」モードで実行されます。
現在、この手順にはLinuxとbashが必要です。

### ステップ1：テストランナー全体のインフラをインストールする

テストの準備として、[https://github.com/exercism/gdscript-test-runner][gdscript-test-runner]をクローンし、その中身を`/opt/test-runner/`に移動します。

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### ステップ2：演習1つ分のテストランナースクリプトをダウンロードする

`exercism`ツールをセットアップし、GDScriptの演習を少なくとも1つダウンロードしていれば、演習を収めるための`gdscript`フォルダーがワークスペースの下に作成されているはずです（`exercism configure`を実行すると確認できます）。
[テストランナー][test-local-gdscript-solution]をこのフォルダーに保存し、ファイルに実行権限を付けます。

## テストの実行

インストール手順が完了したら、任意の演習ディレクトリ（例：`~/exercism/gdscript/two-fer`）から、その演習に対するローカルの解答をテストするスクリプト（1つ上の`../`にあります）を実行できます。

```sh
../test-local-gdscript-solution.sh
```

## IDEを使う

[Visual Studio Code][vscode]のようなエディターでGDScriptのシンタックスハイライトを利用するには、[godot-tools][godot-tools]などの拡張機能をインストールし、さらにデバッグサーバーを起動しておく必要があります。
Godotは、プロジェクトをGodot自身のエディターで開いている間はこのデバッグサーバーを自動的に起動し、プロジェクトまたはGodot自体を閉じるまで実行し続けます。
