# 説明

近所にある地元の学校には、とても活発な生徒会があります。
生徒会は会長によって運営されており、2年ごとに新しい会長を選ぶ選挙が行われます。
今年の選挙では、票を数えるための新しいデジタルシステムが必要だということになりました。

学校では、この新しいシステムを作るために皆さんの助けが必要です。

## 1. 票を数えるカウンターを作成する

新しい投票システムにまず必要なものの1つが、票を数えるカウンターです。
このカウンターは、特定の候補者が獲得した票を把握しておくための仕組みです。

候補者の初期票数を受け取り、与えられた初期票数で初期化された`VoteCounter`構造体のスナップショットを返す`new_vote_counter`という関数を作成してください。

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. カウンターから票数を取得する

これで新しいカウンターを作れるようになりました。
ところが、新しいシステムにはカウンターから票数を取得する方法も必要になることに気づきます。

カウンター（`@VoteCounter`）を引数として受け取り、そのカウンターの票数を返す`vote_count`という関数を作成してください。

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. カウンターの票を増やす

いよいよ票を数えるときです！
ここで、カウンターの票を増やす方法が必要になります。

カウンター（`@VoteCounter`）と票数を引数として受け取り、その票数だけカウンターを増やす`increment_vote_count`という関数を作成してください。

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. 選挙結果を作成する

すべての票を数え終えたので、学校全体に向けて結果を発表する準備をしましょう。
そのためには、票のカウンターだけでは足りないことに気づきます。
票数を特定の候補者と結び付ける方法が必要です。

候補者の名前とその票数を受け取り、新しい選挙結果を返す`new_election_result`という関数を作成してください。

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

選挙結果の構造体はすでに用意されていて、次のように定義されています。

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. 結果を発表する

いよいよ新しい会長を学校に発表するときです！
会長は、学校にある小さなデジタル掲示板で発表されます。

メッセージには、新しい会長の名前とその獲得票数を、`<candidate_name> (<votes>)`の形式で表示します。
たとえば、こんなメッセージです：`"Peter (51)"`。

引数として`@ElectionResult`を受け取り、表示するメッセージを`ByteArray`で返す`display_result`という関数を作成してください。

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. 票の再集計

最終結果が正確かどうかを確かめるために、票が数え直されました。
数え直したところ、一部の候補者の票数が1票ずれていることが分かりました。

最終結果と、票数を減らす対象の候補者の名前を受け取る`decrement_votes_of_candidate`という関数を作成してください。
最終結果は`Felt252Dict<u32>`の形で渡され、キーは候補者の名前、値はその候補者の合計票数です。

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
