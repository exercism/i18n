# 指示の補足

## 例外メッセージ

ときに、[例外を送出する](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。そのときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。こうすると、コードが読みやすくなり、デバッグもぐっと楽になります。エラーの原因が特定の種類になるとわかっている場合は、[組み込みのエラータイプ](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを送出することもできますが、その場合も意味のあるメッセージを含めるようにしましょう。

この演習では、`say()`に入力する数値が範囲外の場合に、[raise文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使って`ValueError`を「スロー」することが求められています。テストが通るのは、`exception`を`raise`することと、それにメッセージを添えることの両方を満たしている場合だけです。

メッセージ付きで`ValueError`を送出するには、`exception`型の引数としてメッセージを書きます。

```python
# if the number is negative
raise ValueError("input out of range")

# if the number is larger than 999,999,999,999
raise ValueError("input out of range")
```
