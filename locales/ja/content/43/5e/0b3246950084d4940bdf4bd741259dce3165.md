# 説明

`accumulate`演算を実装しましょう。これは、コレクションと、そのコレクションの各要素に対して行う操作を受け取り、入力コレクションの各要素にその操作を適用した結果を含む新しいコレクションを返すものです。

次の数値のコレクションがあるとします。

- 1, 2, 3, 4, 5

操作は次のとおりです。

- 数値を2乗する（`x => x * x`）

このとき、コードは2乗した値のコレクションを生成できるはずです。

- 1, 4, 9, 16, 25

期待される関数のシグネチャは、テストスイートで確認してください。

## 制限事項

標準ライブラリが提供するcollect/map/fmapなどといった機能には手を出さないでください！　その代わりに、他の基本的な仕組みを使って自分で解きましょう。
