# 手順

この演習では、地元のゲームセンターで一番人気のゲームのハイスコアを記録する仕組みを実装します。

実装する関数は7つあり、いずれもハイスコアのデータが入った辞書を返したり、操作したりするためのものです。

## 1. 新しいハイスコアの辞書を定義する

`newScoreBoard()`という関数を作成してください。この関数は仮引数を取らず、新しいハイスコアの辞書を返します。辞書のキーには`String`型の値、値には`Int`型の値を使います。

## 2. ハイスコアの辞書にプレイヤーを追加する

ハイスコアの辞書にプレイヤーを追加するには、`addPlayer(_:_:_:)`を定義してください。これは3つの仮引数を取る関数です。

- 1つ目の仮引数は、スコアの辞書です。
    これは`in-out`仮引数にします。
- 2つ目の仮引数は、プレイヤーの名前を表す文字列です。
- 3つ目の仮引数は、スコアを表す整数です。
    この仮引数は省略可能なので、デフォルト値の0を設定して実装します。

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. スコアの辞書からプレイヤーを削除する

ハイスコアの辞書からプレイヤーを削除するには、`removePlayer(_:_:)`を定義してください。これは2つの仮引数を取ります。

- 1つ目の仮引数は、スコアの辞書です。
    これは`in-out`仮引数にします。
- 2つ目の仮引数は、プレイヤーの名前を表す文字列です。

この関数は、プレイヤーが辞書にいればそのプレイヤーを辞書から削除し、いなければ何もしません。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. プレイヤーのスコアをリセットする

プレイヤーのスコアをリセットするには、`resetPlayer(_:_:)`を定義してください。これは2つの仮引数を取ります。

- 1つ目の仮引数は、スコアの辞書です。
    これは`in-out`仮引数にします。
- 2つ目の仮引数は、スコアをリセットしたいプレイヤーの名前を表す文字列です。

この関数は、そのプレイヤーのスコアを0に設定します。
プレイヤーが辞書にいない場合は、何もしません。

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. プレイヤーのスコアを更新する

前回のスコアに加算してプレイヤーのスコアを更新するには、`updateScore`を定義してください。これは3つの仮引数を取ります。

- 1つ目の仮引数は、スコアの辞書です。これは`in-out`仮引数にします。
- 2つ目の仮引数は、スコアを更新したいプレイヤーの名前を表す文字列です。
- 3つ目の仮引数は、記録されているハイスコアに**加算**したいスコアです。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. プレイヤー名で並べた、スコア付きのプレイヤーのリストを取得する

`orderByPlayers`という関数を定義してください。これは1つの仮引数を取ります。

- 1つ目の仮引数は、スコアの辞書です。

この関数は、プレイヤーとそのハイスコアを組にした`(String, Int)`タプルの配列を返します。並び順は、プレイヤー名の昇順です。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. プレイヤーのスコアの降順で並べたプレイヤーのリストを取得する

プレイヤーをスコアの降順で並べたリストを取得するには、`orderByScores`を定義してください。これは1つの仮引数を取ります。

- 1つ目の仮引数は、スコアの辞書です。

この関数は、プレイヤーとそのハイスコアを組にした`(String, Int)`タプルの配列を返します。並び順は、プレイヤーのスコアの降順です。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
