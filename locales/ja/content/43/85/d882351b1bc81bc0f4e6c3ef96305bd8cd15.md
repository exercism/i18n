# はじめに

拡張メソッドを使うと、新しい派生型を作ったり、再コンパイルしたり、元の型をその他の方法で変更したりすることなく、既存の型にメソッドを追加できます。拡張メソッドは静的メソッドとして定義しますが、呼び出すときはインスタンスメソッドの構文を使います。最初の仮引数の前には`this`修飾子を付け、そのメソッドがどの型を対象に動作するのかを指定します。また、拡張メソッドは名前空間レベルでスコープに取り込まれます。

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
