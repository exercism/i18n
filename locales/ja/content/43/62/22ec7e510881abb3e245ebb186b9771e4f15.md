# 文字列

Crystalには、テキストを表すために使われる[`String`][strings]という型があります。
Crystalの文字列は、Unicode文字の並びです。
文字列はイミュータブルで、一度作成すると変更できません。
つまり、文字列を変更するたびに新しい文字列が作成され、元の文字列は変更されません。

文字列を定義するには、二重引用符`"`を使います。

```crystal
"Hello World"
```

## 連結

2つの文字列を連結するには、`+`演算子を使います。
`+`演算子は、2つの文字列を組み合わせた新しい文字列を返します。

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## 文字列と数値の変換

`to_i`メソッドは、文字列を整数に変換します。
あるいは、`to_f`メソッドを使うと、小数を返すこともできます。
文字列を数値に変換できない場合は、`ArgumentError`が発生します。

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

整数や小数は、`to_s`メソッドを使って文字列に変換できます。

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## 文字列補間

文字列補間を使うと、文字列を組み合わせたり、式を文字列に埋め込んだりできます。
文字列を補間するには、`#`に続けて波括弧（`{}`）を書き、その中に式を入れます。

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystalは、式の結果を自動的に文字列に変換します。

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## サイズ

文字列の文字数を知りたいときは、`size`メソッドを使います。このメソッドは、文字列の長さを整数で返します。
文字列のサイズは文字列に保存されたプロパティなので、メソッドを呼び出すたびに計算する必要がなく、非常に高速です。

```crystal
"Hello World".size
# => 11
```

## インデックス指定

インデックス指定とは、文字列から特定の文字を取り出すことです。
`String`から文字を取得するには、おなじみの角括弧（`[]`）を使います。

~~~~exercism/note
`[]`は`String`のインスタンスメソッドとして実装されており、インデックスがメソッドの引数になります。
~~~~

文字列の最初の文字は、インデックス0にあります。

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

文字列の末尾から文字を取得するには、文字列の長さから1を引くと最後の文字のインデックスになり、最後から2番目の文字なら長さから2を引く、というようにします。
これにはショートカットがあり、負のインデックスを使うだけです。最後の文字はインデックス-1、最後から2番目の文字はインデックス-2、というようになります。

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## エスケープ

文字列に直接書けない文字もあります。その場合はエスケープシーケンスを使います。
たとえば、文字列の中で二重引用符を使いたいときは、二重引用符をエスケープする必要があります。
`\`に続けてエスケープしたい文字を書くと、エスケープシーケンスになります。

Crystalの特殊文字は次のとおりです。

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | 警告                          |
| `\b`     | バックスペース                |
| `\e`     | エスケープ                    |
| `\f`     | 改ページ                      |
| `\n`     | ラインフィード（改行）        |
| `\r`     | キャリッジリターン            |
| `\t`     | 水平タブ                      |
| `\v`     | 垂直タブ                      |
| `\\`     | バックスラッシュ              |
| `\'`     | 一重引用符                    |
| `\"`     | 二重引用符                    |
| `\377`   | 8進数のASCII文字              |
| `\xFF`   | 16進数のASCII文字             |
| `\uFFFF` | 16進数のUnicode文字           |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## 複数行の文字列

複数行の文字列を書くには、1行の文字列と同じ構文を使い、文字列に含めたい行ごとに改行します。

```crystal
"Hello
World"
# => "Hello\nWorld"
```
