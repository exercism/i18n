# テスト

8thのバイナリにPATHが通っている場合は、次のコマンドを入力します。

```bash
8th -f test.8th
```

8thのバイナリにPATHが通っていない場合、Windowsでは次のように入力します。

```cmd
\path\to\8th -f test.8th
```

LinuxまたはmacOSの場合は次のとおりです。

```bash
/path/to/8th -f test.8th
```

## REPLでのテスト

`test-words.8th`を読み込んで8thを起動します。

```sh
8th -f test-words.8th
```

これでCLIセッションが開始され、解答ファイルにコードを書いたあと、それをREPLに読み込むことができます。
たとえば「word-count」の演習では、次のように入力します。

```8th
"word-count.8th" f:include
```

テストは次のようにして実行できます。
```sh
"word-count-tests.8th" f:include
```

または、そのファイルから1つのテストをコピーして貼り付けるか、自分でテストを入力することもできます。

## スキップされるテスト

演習を解くというのは、その演習のテストをすべて通すということです。
デフォルトでは、テストを実行したときに1つのテスト（最初のもの）だけが実行されます。
これは意図的なもので、まずその1つのテストを通すことに集中できます。
そのテストが通ったら、`SKIP-REST-OF-TESTS`というワードをそのテストの後に移動すると、次のテストを有効にできます。

## スキップを上書きする

`SKIP-REST-OF-TESTS`ワードより後のテストも含めてすべてのテストを実行するには、環境変数`RUN_ALL_TESTS`に`true`という値を設定します。
テストを実行している間だけこの設定を行う方法の1つを、macOSとLinuxの場合に示します。

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
