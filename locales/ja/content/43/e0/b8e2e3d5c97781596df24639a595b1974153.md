# 概要

整数は、小数点を含まない数です（`-6`、`0`、`25`、`1234`など）。

整数型は、`fixnum`と`bignum`という2つのサブタイプに分かれています。
* `fixnum`は、少なくとも16ビットの符号付き整数であると定義されていますが、実装によってはそれより大きいのが普通です。
* `bignum`は、`fixnum`より大きい整数を表す型です。

Common Lispでは、整数はいくらでも大きくも小さくもできるので、扱うときに「オーバーフロー」を心配する必要はありません。
他の言語では精度が失われたり、大きな数が一周してしまったりすることがありますが、Common Lispの整数の大きさは、使用できるメモリの量によってのみ制限されます。

```lisp
;; Big integers are no problem
(expt 2 200) ; => 1606938044258990275541962092341162602522202993782792835301376
```
