# プレースホルダー

## AWKの新しい概念

GNU awkのいくつかのおもしろい言語機能を復習したいときは、[`matrix`演習の説明][ex-matrix]を参照してください。

### 動的な関数呼び出し

awkの関数はファーストクラスオブジェクトではありません。ほかの言語のように、関数そのものを渡し合うことはできません。
しかし、変数に関数の_名前_（文字列）を保持しておき、特別な`@varname(args)`記法を使ってその関数を呼び出すことはできます。
例を見てみましょう。

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
これについては、[Indirect Function Calls][indirect]で説明されています。
これは`gawk`の拡張機能です。
