# Introduction

[可変長引数][variadic-parameters]を使うと、関数は1つの仮引数で、指定した型の0個以上の値を受け取ることができます。
可変長引数は、仮引数の型注釈に3つのドット（`...`）を付けて定義します。

関数の本体の中では、これらの値は、指定した型の配列として扱えます。

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
関数が可変長引数のあとに追加の仮引数を持つ場合、Swiftが可変長引数のリストの終わりを判断できるように、可変長引数の直後の仮引数には**必ず**明示的な引数ラベルを付ける必要があります。
~~~~
