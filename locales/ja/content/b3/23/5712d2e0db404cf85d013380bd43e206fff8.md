# はじめに

## 等価性

Elmの型は、等価演算子`(==)`を使って「同じであるか」を調べることができます。
等しくないことを調べる演算子は`(/=)`です（多くの言語の`!=`では*ありません*）。
等価演算子は、リテラル、タプル、レコード、カスタム型に対して使えます。

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

なお、関数は*決して*比較しないでください。比較すると、実行時にプログラムがクラッシュしてしまいます。

## 比較

比較演算子`(<)`、`(<=)`、`(>)`、`(>=)`と、関数`min`、`max`、`compare`は、`comparable`型に対して使えます。
`comparable`型は、比較できるすべての組み込み型をまとめた特別な型です。数値、文字、文字列、`comparable`なものの配列、`comparable`なもののタプルが含まれます。

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

レコードやカスタム型など、その他の型の値は直接比較できません。

`Set`や`Dict`のキーなど、一部の組み込み型は、内容が`comparable`である必要があります。これらの構造は内部的な順序に依存しているためです。

`comparable`な値の配列は`List.sort`で並べ替えることができ、`comparable`な値に変換できる値の配列は`List.sortBy`で並べ替えることができます。
階層的な並べ替え（あるプロパティで並べ替え、同じ値の場合は別のプロパティで順序を決める）が必要な場合は、タプルや配列を`List.sortBy`で使うこともできます。タプルと配列は辞書式順序で並べ替えられるためです。


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

関数`compare`は2つの`comparable`な値を受け取り、`Order`を返します。
`Order`は、ある値が別の値より大きい（`GT`）、等しい（`EQ`）、小さい（`LT`）かを1回の操作で判定する型です。

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

比較関数は任意の型に対して作ることができ、たとえば`List.sortWith`で並べ替えるのに使えます。

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
