# `for`ループ

ループはプログラミングの基本的な概念で、同じコードのブロックを何度も実行できるようにします。
Swiftには2種類のループがあります。[`for-in`ループ][for-loops]と`while`ループです。
この章では`for-in`ループについて学びます。

`for-in`ループを使うと、値のシーケンスを順に処理し、各要素を順番に取り出して、自分で決めた変数に束縛できます。
Swiftでは、範囲、配列、文字列など、さまざまなシーケンスを繰り返し処理できます（ほかの型については後ほど扱います）。
シーケンスのすべての要素を処理し終えると、ループは終了します。

`for-in`ループは、`for`キーワード、変数名、`in`キーワード、そして繰り返し処理する値のシーケンスの順に書いて宣言します。
`for-in`ループで与えられた変数は変更できません。つまり、ループの中でその値を変えることはできません。
数値の配列を繰り返し処理する`for-in`ループの例を示します。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number`変数は`for-in`ループの中で宣言され、ループのスコープ内でのみ利用できます。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 範囲の繰り返し

`for-in`ループを使えば、数値の範囲を繰り返し処理することもできます。
これを使うと、コードのブロックを決まった回数だけ実行できます。たとえば範囲`1...5`は数値1、2、3、4、5を繰り返し処理するので、ループは5回実行されます。
配列のようなデータ構造のインデックスを繰り返し処理したいときは、`0..<array.count`という範囲を使えます。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 文字列の繰り返し

`for-in`ループを使って文字列を繰り返し処理することもできます。
これを使うと、文字列の各文字を順に処理できます。ここで、ループの変数の型が`Character`であることに注目してください。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swiftには`stride`関数も用意されており、範囲を指定した間隔でたどるシーケンスを作れます。
これは`for-in`ループで繰り返し処理できます。
`stride`には[`stride(from:to:by:)`][stride-to]と[`stride(from:through:by:)`][stride-through]があります。前者は上限を含まず、後者は含みます。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

`to`は上限の値を含まないため、ループは`to`に指定した値の手前まで繰り返されます。一方`through`は上限を含むので、この場合は`10`も含まれます。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
