# 概要

**ワード**とは、Factorで関数を指す呼び名です。データスタックとシャッフルワードは`basics`で学びました。ここでは、入力を計算に使う自分だけのワードを定義します。

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

定義は、`:`、スタック効果、本体、そして`;`の順に書きます。`( … -- … )`の中に書かれた名前は読み手のためのもので、コンパイラーが確認するのは入力と出力の*数*です。数が食い違うとコンパイル時エラーになります。これは、こうした宣言を持たない動的型付け言語なら実行時エラーになってしまう類のバグを捕まえてくれます。

整数を計算するワード`+`、`-`、`*`は`math`ボキャブラリーにあり、どれもスタックの一番上から数値を2つ消費します。スタックの一番上が右側のオペランドになるので、`8 3 -`は`8 - 3`を計算します。

`CONSTANT:`は、固定の値に名前を付けます。その名前を呼び出すと、ほかのワードとまったく同じように値がスタックに積まれます。定数はファイルの先頭、それを使うワードより前に置きましょう。

ワードの本体からは、すでにスコープにあるワードをどれでも呼び出せます。同じファイルで先に定義したワード、読み込んだボキャブラリーのワード、そして宣言した定数です。小さくて目的を1つに絞ったワードを組み合わせていくのが、プログラムを組み立てる普通のやり方です。

慣習として、次のようになっています。

- ワードと定数には`lowercase-kebab-case`を使います。
- 述語は`?`で終わり、真偽値を返します（`even?`、`empty?`）。
- 入力を書き換えるワードは、書き換えない版と同じ名前になっていることが多く、両者を区別するのは文脈だけです。
