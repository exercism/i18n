# 静的シンタックスハイライト

静的シンタックスハイライトとは、ユーザーが変更_できない_コードに対するハイライトのことです。コードスニペットやイテレーションなどが含まれます。

```exercism/note
オンラインエディターでは、ユーザーがその場でコードを変更できるため、静的シンタックスハイライトを_使いません_。
オンラインエディターでのシンタックスハイライトの扱いについてもっと知りたい場合は、[動的シンタックスハイライトのドキュメント](/docs/building/tracks/new/syntax-highlighting/dynamic)を確認してください。
```

## 実装

静的シンタックスハイライトには、[highlightjsライブラリ](https://highlightjs.org/)を使用します。

自分の言語のサポートを追加する場合、3つの選択肢があります。

1. その言語がhighlightjsで_すぐに_サポートされている（つまり、[サポート対象の言語](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)として掲載されている）場合。
   その場合は、[トラックの設定](#configuring-track)のセクションに進みます。
2. 既存のhighlightjsプラグインを介してその言語がサポートされている場合。
   その場合は、[既存のプラグインの使用](#using-an-existing-plugin)のセクションに進みます。
3. その言語がサポートされて_いない_場合。
   ここでも3つの選択肢があります。
   1. [新しいプラグインの作成](#create-a-new-plugin)のセクションで説明するように、highlightjsプラグインを一から書きます。
   2. 自分の言語の構文が別の言語の構文に（よく）似ている場合（たとえば、Unisonの構文はHaskellに似ています）。その場合は、その言語のシンタックスハイライトを自分の言語に使うことを検討できます。
      詳しくは[トラックの設定](#configuring-track)のセクションを参照してください。
   3. 静的シンタックスハイライトを用意しない。

### トラックの設定

トラックの言語でhighlightjsのサポートを有効にするには、トラックの[config.jsonファイル](/docs/building/tracks/config-json)を変更する必要があります。`config.json`ファイルの中で、`online_editor.highlightjs_language`キーを、適切なhighlightjsの言語識別子（ドキュメントに記載されています）に追加または設定します。

#### 例

```json
{
  "online_editor": {
    "highlightjs_language": "csharp"
  }
}
```

### 既存のプラグインの使用

既存のプラグインを使用するには、そのプラグインが[NPM](https://www.npmjs.com/)で公開されている必要があります。プラグインがNPMで公開されていない場合は、次のいずれかを行います。

1. プラグインの作者に、NPMで公開する意思があるか尋ねます。
2. リポジトリをフォークして、自分で公開します。
3. Exercismがリポジトリをフォークして公開する、という方法もあります。
   その場合は、[フォーラム](https://forum.exercism.org/c/exercism/building-exercism/125)でトピックを立てて依頼してください。

次のステップは、[プラグインの有効化](#enable-plugin)です。

### プラグインの有効化

プラグイン（[NPM](https://www.npmjs.com/)で公開されている必要があります）を有効にするには、[フォーラム](https://forum.exercism.org/c/exercism/building-exercism/125)でトピックを立て、そのプラグインのサポートをウェブサイトに追加してほしいと依頼します。するとExercismが、プラグインをウェブサイトに追加するPull Requestを作成します。PRがマージされたら、[トラックの設定](#configuring-track)のセクションの手順に従って、highlightjsのサポートを有効にできます。

### 新しいプラグインの作成

プラグインを作成したい場合、ホスティングには2つの選択肢があります。

1. 自分の個人アカウントでリポジトリを作成し、自分で公開します。
2. Exercismにリポジトリを作成してもらい、公開してもらいます。
   その場合は、[フォーラム](https://forum.exercism.org/c/exercism/building-exercism/125)でトピックを立てて依頼してください。

リポジトリができたら、[言語のコントリビューション手順](https://highlightjs.readthedocs.io/en/latest/language-contribution.html)に従ってプラグインを実装します。

その後、プラグインを[NPM](https://www.npmjs.com/)で公開する必要があります。次のステップは、[プラグインの有効化](#enable-plugin)です。

### 別の言語を使う

自分の言語の構文が別の言語の構文に（よく）似ている場合は、その言語のシンタックスハイライトを自分の言語に使うことを検討できます。そうするには、トラックがその別の言語のhighlightjs言語識別子を使うように設定します。詳しくは[トラックの設定](#configuring-track)のセクションを参照してください。
