# 説明

この演習では、乗り物を買う準備を手伝うコードを書きます。

取り組むタスクは3つです。運転免許が必要かどうかを判断するタスク、2台の乗り物から1台を選ぶタスク、中古の乗り物の妥当な価格を見積もるタスクです。

## 1. 運転免許が必要かどうかを判断する

乗り物の中には、運転するのに運転免許が必要なものもあります。
`car`と`truck`の2種類だけに免許が必要で、それ以外は免許なしで運転できるものとします。

乗り物の種類を受け取り、その種類に免許が必要かどうかを真偽値で返す`needs_license(kind)`関数を実装します。

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. 購入候補の2台から1台を選ぶ

購入できる乗り物の選択肢を検討します。
なんとか2つまで絞り込めましたが、最終的な判断には助けが必要です。
そこで、2台の乗り物を引数に取り、辞書順で先に来るほうを答える`choose_vehicle(option1, option2)`関数を実装します。

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. 中古の乗り物の価格を見積もる

選び終えたら、次はディーラーで妥当な価格で買えるようにしたいところです。
中古の乗り物を買うのですから、価格は乗り物がどれくらい古いかによって変わります。
大まかに見積もるなら、乗り物が3年未満なら、新品だったときの価格の80%とします。
10年を超えると50%です。
3年以上10年以下なら、元の価格の70%です。

`calculate_resale_price(original_price, age)`関数を実装します。
元の価格と乗り物の年式を引数に取り、ディーラーでの見積価格を返します。

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
