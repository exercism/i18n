# 指示

この演習では、お気に入りの料理本に載っている絶品ラザニアを作るために、コードを書いていきます。

ラザニア作りにかかる時間に関する、5つのタスクがあります。

## 1. オーブンでの想定加熱時間を分単位で定義する

ラザニアをオーブンに入れておくべき時間を分で返す、イミュータブルな変数`expectedMinutesInOven`を定義します。
この変数はエクスポートする必要があります。
料理本によると、オーブンでの想定加熱時間は40分です。

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. オーブンでの残り時間を分単位で計算する

ラザニアを実際にオーブンに入れておいた時間を引数として受け取り、前のタスクで求めた想定加熱時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返す、`remainingMinutesInOven`プロシージャを実装します。

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. 下準備にかかる時間を分単位で計算する

ラザニアに重ねた層の数を引数として受け取り、1層あたり2分かかると仮定して、ラザニアの下準備に何分かかったかを返す、`preparationTimeInMinutes`プロシージャを実装します。

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. 合計の作業時間を分単位で計算する

`totalTimeInMinutes`プロシージャは2つの引数を取ります。`numberOfLayers`はラザニアに重ねた層の数、`actualMinutesInOven`はラザニアをオーブンに入れておいた分数です。
このプロシージャは、ラザニア作りに合計で何分かかったかを返します。これは、下準備にかかった分数と、その時点でラザニアをオーブンに入れておいた分数を足したものです。

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
