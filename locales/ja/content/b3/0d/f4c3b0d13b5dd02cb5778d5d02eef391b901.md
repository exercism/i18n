# `while`ループと`until`ループ

ループとは、与えられた条件に基づいてコードを繰り返し実行できるようにする制御構造です。

## `while`ループ

`while`ループは、与えられた条件に基づいてコードを繰り返し実行できるようにする制御構造です。
`while`ループ内のコードは、条件が真として評価される限り実行され続けます。
`while`ループは、繰り返しの回数が事前にわからない場合によく使われますが、ループが必要なあらゆる場面で使うことができます。

条件はループ内のコードが実行される前に評価されます。つまり、条件が偽であれば、ループ内のコードは一度も実行されません。

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

文字列を繰り返し処理したいときは、文字列の長さの分だけループを回すことができます。

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`ループ

`until`ループは`while`ループと同じように動作しますが、ループ内のコードは条件が真として評価されるまで実行され続ける点が異なります。
これは`if`と`unless`の違いと同じです。

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 無限ループ

`while`ループでよくある間違いは、決して終わらない「無限ループ」に入ってしまうことです。
無限ループは、条件が_決して_真または偽として評価されないことが原因で起こることがあります。
これは多くの場合、プログラマーのミスによるものです。たとえば、ループ変数をインクリメントし忘れるなどです。
しかし、プログラムのロジックを実装するうえで、無限ループがもっともわかりやすい方法であることもあります。
あるいは、永遠にループし続けることが不可欠な場合もあります。たとえば、HTTPサーバーは接続を待ち受け、それを処理し、そして次の接続を待ちます。

## `break`

`break`キーワードを使うと、ループを途中で抜けることができます。
特定の条件でループを途中で抜けたいときに便利です。

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next`キーワードを使うと、ループの次の繰り返しにスキップできます。
ループの特定の繰り返しをスキップしたいときに便利です。

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## ループ中の型

ループの中では、変数の型が変わることがあります。
次の例では、ループの前半で`a`が`Int32`にも`String`にもなりうるため、`a`の型は`Int32 | String`です。
変数`a`が型`Int32 | String`を持つのはループの前半だけです。ループが始まったときは`Int32`を保持し、2回目の繰り返しでは`String`を保持するからです。
この複数の型を扱う仕組みについては、後ほど詳しく説明します。
ただし、ループの後半では`String`しか保持されないことが確実なので、ループの後半における`a`の型は`String`です。
実行時には、`Int32`と`String`を同時に保持することはありません。

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```

# `return`

Crystalでは、メソッドの最後の式がその値を返します。
しかし、最後の式より前に値を返したいこともあります。
そのようなときは`return`キーワードを使います。`return`は、直後の式の値を返します。
`return`キーワードより後に書かれたコードは実行されません。

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
メソッドの最後の式が返すべき値である場合は、`return`キーワードは省略します。
~~~~
