# 概要

値のスコープとは、その値がプログラムのどこからアクセスできるかに関係します。

## スコープの4つの種類：ブロック、関数、関数プロトタイプ、ファイル

### ブロックスコープ

ブロックスコープを持つ値は、それが定義されたブロックの中からしかアクセスできません。
ブロックについてさらに詳しく知りたい場合は、[ブロックの概念](../blocks/introduction.md#Introduction)を参照してください。

### 関数スコープ

関数スコープは、`goto`文で使うラベルに適用される特別なスコープです。
同じ名前のラベルは、たとえ関数内の別々のブロックで定義されていても、同じ関数の中で2つとも使うことはできません。

### 関数プロトタイプスコープ

関数プロトタイプスコープも特別なスコープで、プロトタイプ（宣言とも呼ばれますが、すべての宣言がプロトタイプというわけではないことに注意してください）の中で名前を付けた仮引数にのみ適用されます。
関数宣言では、ふつう仮引数の名前は省略できます。
名前のスコープは、その宣言の中でだけ意味を持ちます。
次の例では、`len`という識別子が定義され、その後で関数宣言の中から参照されています。

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

宣言の中では、同じ変数を参照するときは名前を一致させる必要があることに注意してください。
もし`my_func`を`void my_func(int len, int numbers[length]);`と宣言すると、次のようなコンパイルエラーが生成されます。

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

関数定義では、関数宣言で使ったのと同じ名前を仮引数に使う必要はありません。
上の例では、宣言で`len`、定義で`length`を使っています。これは、`len`という識別子のスコープが関数宣言の中だけであることを示しています。

### ファイルスコープ

ファイルスコープを持つ値は、ファイル内のどこからでもアクセスできます。
そのような値は、関数の外で定義されます。
