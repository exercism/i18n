# はじめに

Haxeには正規表現のサポートが標準で備わっています。正規表現を使うと、文字列の形式を検証したり、文字列を変換したり、与えられたテキストから一定のデータを抜き出したりできます。

正規表現を作るには、`~/`と`/`の間に書きます。

```haxe
var r = ~/haxe/i;
```

別の方法として、`EReg()`のインスタンスを使うやり方もあります。

```haxe
var r = new EReg("haxe", "i");
```

ここでの`i`は、パターンの大文字と小文字を区別しないようにするフラグです。ほかにも次のようなフラグがあります。

- `g`: 全体置換。
- `m`: 複数行マッチング

`~/`と`/`の間には、正規表現のパターンを書きます。たとえば、AからZまでの文字を含む文字列を探したいとします。こういうときは、範囲を表すパターン`[A-Z]`を使えます。パターンにはほかにもいろいろなものがあります。

- `.`: 任意の1文字
- `*`: 0回以上の繰り返し
- `+`: 1回以上の繰り返し
- `[A-Z0-9]`: 文字の範囲
