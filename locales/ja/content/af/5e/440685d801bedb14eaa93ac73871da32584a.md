# 指示の補足

## 例外メッセージ

ときには、[例外を発生させる](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)必要があります。その際は、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしてください。これにより、コードが読みやすくなり、デバッグが格段にしやすくなります。エラーの原因がある特定の種類になると分かっている場合は、[組み込みのエラー型](https://docs.python.org/3/library/exceptions.html#base-classes)のいずれかを発生させることができますが、それでも意味のあるメッセージを含めるようにしてください。

この演習では、入力と出力の基数が異なる場合に`ValueError`を「スロー」するために、[`raise`文](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)を使う必要があります。`raise`で`exception`を発生させ、それとともに意味のあるメッセージを含めた場合にのみ、テストは通ります。

メッセージ付きで`ValueError`を発生させるには、`exception`型の引数としてメッセージを書きます。

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
