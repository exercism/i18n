# 概要

ある型が、_型パラメータ_を使ってどんな型の値でも入れられるようになっているとき、その型を_ジェネリック型_といいます。

たとえば、次の`Box`型には型パラメータ`a`があります（小文字で書きます）。

```gleam
pub type Box(a) {
  Box(a)
}
```

型パラメータ`a`は、どんな型にも当てはまるプレースホルダーなので、`Box`は文字列や整数など、どんな型にも使えます。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

型パラメータをカンマで区切れば、型に複数の型パラメータを持たせることもできます。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## ジェネリック関数

型パラメータは、関数の引数でも使うことができます。

この関数は型`a`の値を受け取り、`a`を受け取って`b`を返す関数を2回呼び出します。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
