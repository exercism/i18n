# 概要

文字クラスや量指定子だけでなく、正規表現はテキストの*構造*や*文脈*を表現することもできます。これらの機能も、同じ[`regexp`][regexp]ボキャブラリーに含まれていて、`R/ /`リテラルで書きます。

## グループ化と選択

丸括弧（`( )`）は、パターンの一部をグループ化します。すると、量指定子や`|`（「これまたはあれ」）がグループ全体に働きます。グループの後ろに`?`を付けると、そのグループは省略可能になります。

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## アンカー

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

*単語境界*（`\b`）とは、単語を構成する文字（英字、数字、アンダースコア）とそうでない文字とが接する位置のことです。文字列の端も含まれます。つまり、`\bcat\b`は`cat`が単独で存在するときだけマッチします。

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## 先読みと後読み

*先読み・後読み*は、ある位置の直前または直後にあるものを調べますが、その文字自体はマッチの一部にはしません。幅を持たないからです。

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## オプション

閉じの`/`の後に付けるオプション文字は、パターン全体の動作を変えます。`i`は大文字と小文字を区別しません。

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## マッチを変換する

`map-matches`はマッチするたびにクォーテーションを実行し、その結果を集めます。`each-match`も同じことをしますが、副作用のためだけに使います。どちらもクォーテーションに、マッチの`start`インデックス、`end`インデックス、そして文字列全体を渡すので、`subseq`でマッチしたテキストを取り出せます。

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Factorがサポートしていないこと

Factorの正規表現エンジンには、**キャプチャグループの取り出し**がありません（グループ`( )`はパターンを構造化しますが、それがマッチしたテキストを読み戻すことはできません）。**後方参照**（`\1`）も、**最短一致（非欲張り）**の量指定子（`*?`、`+?`）もありません。キャプチャグループの代わりに使える慣用的な手段が、先読み・後読みです。周りの文脈によって見分けながら、欲しい部分をマッチさせます。
