# はじめに

Gleamの不透明型はカスタム型の一種で、その型を定義したモジュールだけが、その型の値を作成したりパターンマッチしたりできます。決まった使い方だけを許す型を作りたいときに役立ちます。

不透明型は、`opaque`キーワードを使って定義します。

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

この`PositiveInt`型は、整数が必要だけれど、その値が0以上でなければならない場面で使います。通常のGleamの`Int`は負の値も取れるため、代わりに使うことはできません。

この型を定義したモジュールでは、内側の整数値を取り出す関数と、`PositiveInt`型を作るための関数を定義できます。後者は、値が正の数でなければエラーを返します。

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

このAPIがあれば、ほかのモジュールが負の値で`PositiveInt`を作ることはできません。そのため、`PositiveInt`を受け取る関数は、その値が正の数だと確信できます。
