# プレースホルダー

## Listの操作を実装する

この演習の目標は、Listのメソッドの一部を自分で実装することです。
データを保持するために、バックエンドでListオブジェクトを使うのが自然です。
Listのメソッド（`where`や`map`など）には手を出さないでください。

どうしても避けられない「プリミティブ」なList操作がいくつかあります。たとえば、次のようなものです。

* スライス：`list[from..to]`
* 追加：`list.add(item)`

## イテレータープロトコル

実装するListの操作は、どれもさまざまな方法で繰り返しを行うためのものです。
[イテレータープロトコル][iter]について読んでみましょう。
そうすると、次のように書けるようになります。

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
