# 概要

プロパティには、主に次の2つの種類があります。

1. `get`アクセサーと`set`アクセサーに本体がない自動実装プロパティです。明示的に初期化されることも、されないこともあります。たとえば、次のとおりです。
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. アクセサーが式を評価し、文を実行するプロパティです。コードは、バッキングフィールドを返したり代入したりするだけの、ごく簡単なものでかまいません。たとえば、次のとおりです。
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

プロパティとメソッドは、その振る舞いやできることがかなり重なっています。自動実装プロパティでなければ、クラスのスコープ内に書ける文や式を自由に含めることができます。よくあるのは、バッキングフィールドを包み込んでいると説明されるケースです。多くの場合、ある振る舞いをプロパティとして書くかメソッドとして書くかは明白ですが、どちらにするかは書き手の判断に委ねられることがよくあります。特に、アクセサーの中でどれだけのコードを実行するかは判断が分かれるところです。`set`アクセサーでの検証や、`get`アクセサーでの簡単な計算や書式設定は、よく見られます。

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

他のクラスメンバーと同じように、プロパティにもアクセスレベルを設定できます。多くの場合、プロパティはその本来の目的に沿って、`private`以外のアクセスレベルを持ちます。アクセサーの一方だけが、プロパティとは異なるアクセスレベルを持つこともあります。`TareWeight`の場合、やや人工的な『セキュリティ』上の制約のもとで、`public`なプロパティに`private`な`get`アクセサーを持たせる余地がありました。つまり、クラスの外部のコードからはプロパティの値を設定できますが、値を読み取る（`get`する）ことができるのはクラス内部のコードだけです。

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

`public`以外の`set`アクセサーもサポートされていますが、もっとよくあるのは、`set`アクセサーをまったく省略するケースです。これは、プロパティの値がクラスのコンストラクターで設定されるためでしょう。

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

この演習では、プロパティの基本的な使い方を扱いました。より発展的なトピックは、ほかの演習で扱っています。

- 式形式のプロパティ、`get`アクセサー、`set`アクセサー（式形式のメンバーで扱っています）
- インターフェースのプロパティ（インターフェースで扱っています）
- 抽象クラスのプロパティや抽象プロパティ（継承で扱っています）
- プロパティでの`readonly`キーワードの使用（不変性で扱っています）
- 静的プロパティ（静的メンバーで扱っています）
- インデクサー（インデクサーの演習で扱っています）
