# はじめに

この演習では、Rubyの基本的な構成要素を学びます。
扱う範囲は広いですが、難しく感じても心配しないでください。トラックを進めていく中で、それぞれの内容をずっと詳しく掘り下げていきます。

Rubyを理解するうえで重要なポイントの一つは、Rubyが[オブジェクト指向言語][object-oriented-programming]であるということ、そして**Rubyではすべてが[オブジェクト][object]である**ということです。数値も文字列も配列も、すべてオブジェクトです。

## 変数と定数

オブジェクトは、変数か定数を使って名前を付けて利用するのが一般的です。

変数は常に[スネークケース][snake-case]で書きます。
変数は、その寿命の中でさまざまなオブジェクトを参照できます。
たとえば、`my_first_variable`は`=`演算子を使って何度も定義し直すことができます。

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

一方、定数は一度だけ代入するものです。
大文字で始める必要があり、通常はすべて大文字で、単語をアンダースコアで区切って書きます。
たとえば、次のとおりです。

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## クラス

Rubyはクラスによって整理されています。
クラスは、`class`キーワードの後にクラス名を書いて定義します。
オブジェクトは通常、`.new`メソッドでクラスをインスタンス化して作ります。
たとえば、次のとおりです。

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## メソッド

機能の単位はメソッドにまとめられます。これは他の言語の_関数_に似ています。

メソッドは、位置引数やキーワード引数（`:`構文を使って定義・呼び出しします）を使って定義することも、引数をまったく持たないようにすることもできます。

メソッドは、最後に評価された文の結果を暗黙的に返すか、`return`キーワードを使って明示的にオブジェクトを返します。

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

メソッドは`.`構文を使って呼び出します。

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
