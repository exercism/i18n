# 概要

`Time`モジュールは、人間が読める形式の日付や時刻を表示するために使います。
`Time`でも時刻を操作することは技術的には可能ですが、その用途にはるかに適したElmのコミュニティパッケージがあります。たとえば、[`justinmimbs/date`][date]や[`CoderDennis/elm-time-format`][elm-time-format]などです。

## Posix

時刻は、不透明型`Posix`で表します。これはUnixエポック時間、つまり1970年1月1日のUTC午前0時から経過したミリ秒数を包んだものです。
`Posix`はタイムゾーンによって変化しない曖昧さのない値なので、時刻を保持するのに適した選択肢です。
Elmアプリケーションでは、`Posix`の時刻は通常、ブラウザーなどの外部ソースから提供されます。

次の関数を使うと、`Posix`をミリ秒の数値に変換したり、その逆を行ったりできます。

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## タイムゾーン

ふだんの生活では、`Posix`をそのまま読むことはほとんどなく、現地時刻のほうを使います。現地時刻は、地球上の自分の位置やその地域の夏時間の規則によって決まります。
Elmでは、この情報は不透明型`Zone`にエンコードされ、通常はブラウザーから提供されます。

常に使える特別な`Zone`があります。

```elm
utc : Zone
```

## 人間が読める時刻

`Posix`と`Zone`があれば、現地時刻をどんな細かさでも表示できるだけの情報がそろいます。
そのために使える関数を次に挙げます。

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

`Time`のカスタム型があと2つあることにお気づきでしょう。

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

これらのカスタム型を人間が読める値に変換するのは、利用者の側で行います。
