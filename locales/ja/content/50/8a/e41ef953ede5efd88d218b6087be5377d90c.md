# 概要

Javaは静的型付け言語です。つまり、コンパイル時にすべてのものに型があります。名前を付けて値を代入することを、変数を定義するといいます。

```java
int explicitVar = 10; // Explicitly typed
```

変数の値は、[`=`演算子][assignment]を使って代入したり更新したりできます。一度定義すると、変数の型を変更することはできません。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Javaはオブジェクト指向言語であり、すべての関数を _クラス_ の中で定義する必要があります。クラスは [`class`キーワード][classes]を使って定義します。クラスの中にある関数は _メソッド_ と呼ばれます。それぞれの[メソッド][methods]は、0個以上の仮引数を持てます。仮引数にはすべて明示的に型を付ける必要があり、仮引数の型推論はありません。同様に、戻り値の型も明示する必要があります。値は[`return`キーワード][return]を使って関数から返します。他のクラスからメソッドを呼び出せるようにするには、`public`アクセス修飾子を付ける必要があります。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

メソッドを呼び出すには、そのクラスとメソッド名を指定し、メソッドの仮引数それぞれに対応する引数を渡します。

```java
int sum = new Calculator().add(1, 2);
```

メソッドがクラスの _状態_ を一切使わない場合（この演習がその例です）、そのメソッドは `static` 修飾子を使って _静的_ にできます。同様に、クラスが静的メソッドしか持たない場合は、そのクラス自体も `static` 修飾子を使って静的クラスにできます。

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Javaのスコープは、`{`と`}`の文字の間に定義されます。

Javaは2種類の[コメント][comments]をサポートしています。1行コメントは`//`で始まり、複数行コメントは`/*`と`*/`の間に書きます。

整数値は、1つ以上の（連続した）数字として定義され、[既定の算術演算子][operators]をサポートしています。
