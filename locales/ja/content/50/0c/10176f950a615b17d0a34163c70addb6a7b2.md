# 概要

他のプログラミング言語と同じように、C++にも`switch`文があります。
`switch`文を使うと、長い`if ... else if`文を短く書けます。
switchを作るには、まず`switch`というキーワードのあとに整数を書きます。
次に、それぞれの条件を`case`キーワードで宣言します。
これまでの`case`の条件にどれも当てはまらないときに実行される`default`ケースも宣言できます。
各ケースは、`break`（または`return`）文で終わらせる必要があります。

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## フォールスルー

switch構文で重要なのは、`break`（または`return`）文で止められるまでコードが実行され続けるという点です。
そのため、予期しない動作になることがあります。

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

このように実行が続く仕組みが主に役立つのは、複数のラベルを付けた文を書きたいときです。
複数のswitchの結果に対して、同じコードを実行させることもできます。
たとえば予約アプリでは、グループの人数が2人と3人のときに呼び出す関数を同じにできます。

```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
ここまで見てきたように、C++のswitch文は他の言語と比べるとかなり限定的です。
多くの言語では、真偽値の式や正規表現に基づいて分岐できます。
C++のバージョンは、goto/switch構文を拡張したものだと考えるとよいでしょう。
ラベルにジャンプできるのはswitch文だけです。
その後はほかのラベルはすべて無視されるので、コードブロックから抜けるには`break`文を使う必要があります。
~~~~
