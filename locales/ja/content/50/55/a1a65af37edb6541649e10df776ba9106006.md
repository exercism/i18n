# テスト

テストを実行するには、次のコマンドを実行します。

```bash
make
```

## スキップされるテスト

演習を解くとは、そのテストをすべて通すことです。
デフォルトでは、テストを実行すると、最初の1つのテストだけが実行されます。
これは意図的なもので、まずはその1つのテストを通すことに集中できます。
そのテストが通ったら、`TEST_IGNORE()`の行を削除すると、次のテストを有効にできます。
すべてのテストを有効にして、実装がそれらをすべて通せば、演習は解けたことになります！

## デバッグ

デバッグを助けるために、`debug.mac`ファイルにさまざまなマクロが定義されています。
これらのマクロは、適切なサイズの引数を1つ以上渡して呼び出すことができます。
たとえば、次のとおりです。

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

これらのマクロを使うには、解答ファイルの先頭で`debug.mac`をインクルードする必要があります。

```x86asm
%include "debug.mac"
```
