# 概要

`var`の代わりに`final`キーワードを使って宣言した変数には、一度しか値を代入できません。

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

注意しておきたいのは、`final`が、配列やオブジェクトのような不変ではない型に対しては、意図した効果を発揮しないことがあるという点です。

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
