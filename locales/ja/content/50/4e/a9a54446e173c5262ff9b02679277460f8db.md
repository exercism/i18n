# 説明

この演習では、親友と一緒に「Wizard and Warriors」というロールプレイングゲームをします。ゲームマスターは、プレイヤーがゲームの世界を生き生きと感じられるようにする役割を担います。そのために欠かせないのが、ゲームの様子をプレイヤーに説明することです。たとえば、キャラクターがどんな状態なのか、訪れている町がどんなふうに見えるのか、といったことです。

ここでは、ゲームの一部をプレイヤーに説明する5つのタスクに取り組みます。

## 1. キャラクターを説明する

各キャラクターにはクラス、レベル、ヒットポイントがあり、次のように表されます：`"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`。`Character`だけを仮引数として受け取り、その説明を返す（静的）`GameMaster.Describe`メソッドを実装します。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 目的地を説明する

各目的地には名前と住民の数があり、次のように表されます：`"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`。`Destination`だけを仮引数として受け取り、その説明を返す（静的）`GameMaster.Describe`メソッドを実装します。

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 移動方法を説明する

キャラクターは、2つの方法のどちらかを使って目的地へ移動できます：

- 徒歩の場合：`"You're traveling to your destination by walking."`
- 馬に乗る場合：`"You're traveling to your destination on horseback."`

`TravelMethod`だけを仮引数として受け取り、その説明を返す（静的）`GameMaster.Describe`メソッドを実装します。

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. 目的地へ移動するキャラクターを説明する

キャラクターが目的地へ移動しているときは、個々の説明を組み合わせて次のように表されます：`"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`。`Character`、`Destination`、`TravelMethod`を仮引数として受け取り、その説明を返す（静的）`GameMaster.Describe`メソッドを実装します。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 移動方法を指定せずに目的地へ移動するキャラクターを説明する

ほとんどの場合、キャラクターは歩いて目的地へ移動します。そこで、プレイヤーは移動方法を省略できるようになっています。省略した場合は、歩いて移動したものとみなされます。`Character`と`Destination`を仮引数として受け取り、その説明を返す（静的）`GameMaster.Describe`メソッドを実装します。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
