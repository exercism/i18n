# 概要

ローカル変数は、スタックのコードを置き換えるものではありません。スタックのコードと並んで存在します。ローカル変数が役に立つのは、次のようなときです。

- 同じ入力を何度も参照するとき。
- 自然な演算の順序がスタックの順序と一致しないとき。
- ラムダに一度に複数の値を渡す高階のワードの中にいるとき（`assoc-map`の`( key value -- newkey newvalue )`）。

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]`は、クオテーションの中やリスナーでローカル変数の束縛を作ります。そうした場所では、`:>`>だけでは束縛先となる字句スコープがありません。

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

`:>`>の変更用の接尾辞を使うと、ローカル変数を再束縛できます。命令型の雰囲気のループで役立ちます。

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
