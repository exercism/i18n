# はじめに

[`Nothingness`][concept-nothingness]のコンセプトで見てきたように、Rには、存在しないデータ（`NULL`）、不明なデータ（`NA`）、数学的に無効なデータ（`NaN`、`Inf`）を表すさまざまな方法があります。
一般的にRは、これらを使ってその場で問題を知らせ、例外を発生させずに処理を続けようとします。

## `stop()`

なかには、プログラムの続行を許すには根本的すぎる問題もあります。
そのような場合は、`stop(msg)`を使ってプログラムを直ちに停止し、`Error`を発生させて`msg`を出力します。

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

他の言語の`assert`に似ていて、`stop()`の便利なラッパーです。
引数には、カンマで区切った任意の数の真偽値の条件を指定でき、それらがすべて`TRUE`のときだけプログラムが続行されます。

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()`と`message()`

これらは、致命的ではない状況に対する応答です。たとえば、次のような場合に使います。

- プログラムが少なくとも部分的には復帰できる問題を警告する。
- 長時間動くプログラムの進捗をユーザーに知らせる。

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

`suppressWarnings()`関数は、不要な出力でテストランナーを混乱させないために、Exercismの中でもときに役立ちます。
