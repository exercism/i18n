# 説明

ESA（Exercism宇宙機関）は、火星の衛星である[フォボス][phobos]への新しいミッションの計画を急ピッチで進めています。
このミッションの目標は、探査機をフォボスの表面に着陸させ、表面に関するデータを送り返すことです。
ESAは、探査機のナビゲーションコンピューターの開発への協力を求めています。
ナビゲーションコンピューターのメモリは限られているので、メモリの使用量はできるだけ抑える必要があります。
そのため、適切なデータ型を使う必要があります。

## 1. ナビゲーションの定数

ナビゲーションコンピューターが正しい計算を行うには、宇宙にあるいくつかの物体の間の距離を知る必要があります。距離はkmで表されます。

次の定数を定義しましょう。

- `NEPTUNE_DISTANCE`：値は`4_400_000_000`で、`Int64`として保存します
- `MARS_DISTANCE`：値は`227_940_000`で、`Int32`として保存します
- `ATMOSPHERE_DISTANCE`：値は`10_000`で、`Int16`として保存します

## 2. 正しい面積の計算

ナビゲーションコンピューターが正しい計算を行うには、宇宙にあるいくつかの物体の面積を知る必要があります。
面積が負になることは**ありません**。
エンジニアたちは、面積が負になったときにオーバーフローエラーが発生するようにプログラムを設計していました。
しかし、符号付き整数を符号なし整数に変更するのを忘れていました。

そこで、符号付き整数を符号なし整数に変換するプログラムが必要になりました。

`measurement`を引数として受け取り、面積を32ビットの符号なし整数として返す`Navigation#correct_area_analysis`メソッドを実装しましょう。

~~~~exercism/note
与えられる面積は、常に32ビットの符号なし整数に収まります。
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. 速度の計算

ナビゲーションコンピューターは、探査機の速度を知る必要があります。
速度はm/sで表されます。

速度を計算するには、移動した距離と、その距離を移動するのにかかった時間を知る必要があります。
そして、距離を時間で割ります。

速度は正確とは限らず、極端に大きな数値になることもありません。
そのため、`Float32`を使えます。

`distance`と`time`を引数として受け取り、速度を32ビットの`Float`として返す`Navigation#calculate_velocity`メソッドを実装しましょう。

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
