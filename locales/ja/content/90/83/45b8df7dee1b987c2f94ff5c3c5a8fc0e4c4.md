# 説明

この演習の目的は2つあります。

1. 「コールバックパターン」を使う関数を、`Promise`を返す関数に変える`promisify`関数を実装します。次の例を見てみましょう。

```javascript
function fetchProduct(productId, function(error, data) {
    if (error) {
        // Handle the error
    } else {
        // Make something with your data
    }
})

const fetchProductAsPromise = promisify(fetchProduct);

// Now you got a function `fetchProductAsPromise`
// that returns a promise
fetchProductAsPromise(productId)
    .then((data) => {})
    .catch((error) => {});
```

2. 次の組み込みの`Promise`メソッドを、それらを使わずに再実装します。

- `all`：プロミスの配列を受け取り、_すべて_が解決したときに解決し、_1つ_でも拒否されたときに拒否します。
- `allSettled`：プロミスの配列を受け取り、_すべて_が解決または拒否されたときに解決します。
- `race`：プロミスの配列を受け取り、_最初_に解決または拒否されたプロミスの値で解決または拒否します。
- `any`：プロミスの配列を受け取り、_1つ_が解決したときに解決し、_すべて_が拒否されたときに拒否します。
