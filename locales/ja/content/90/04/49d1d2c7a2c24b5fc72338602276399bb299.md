# 説明

この演習では、お気に入りの料理本のラザニアを作るためのコードを書いていきます。

課題は4つあり、どれもレシピの調理に関係しています。

## 1. 想定されるオーブン時間を分単位で定義します

`lasagna.oven_time`というテーブルのフィールドに、ラザニアをオーブンに入れておくべき時間を分単位で定義します。料理本によると、想定されるオーブン時間は40分です。

```lua
lasagna.oven_time
-- => 40
```

## 2. 残りのオーブン時間を分単位で計算します

`lasagna.remaining_oven_time`関数を定義します。この関数は、ラザニアが実際にオーブンに入っていた時間を分単位で入力として受け取り、前の課題で定義した想定オーブン時間をもとに、ラザニアがあと何分オーブンに入れておく必要があるかを返します。

```lua
lasagna.remaining_oven_time(30)
-- => 10
```

## 3. 準備時間を分単位で計算します

`lasagna.preparation_time`関数を定義します。この関数は、ラザニアに重ねた層の数を入力として受け取り、1層につき2分かけて準備すると仮定して、ラザニアの準備に何分かかったかを返します。

```lua
lasagna.preparation_time(2)
-- => 4
```

## 4. 経過した作業時間を分単位で計算します

`lasagna.elapsed_time`関数を定義します。この関数は2つの入力を受け取ります。1つ目は、ラザニアに重ねた層の数です。2つ目は、ラザニアがオーブンに入っていた時間を分単位で表したものです。この関数は、ラザニアの調理に合計で何分取り組んだかを返します。これは、準備にかかった時間と、その時点までラザニアがオーブンに入っていた時間を、それぞれ分単位で足したものです。

```lua
lasagna.elapsed_time(3, 20)
-- => 26
```
