# はじめに

## 基本

### 変数

Elixirは動的型付け言語です。つまり、変数の型がチェックされるのは実行時だけです。マッチ演算子の`=`を使うと、どんな型の値でも変数名に束縛できます。

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### モジュール

Elixirは[関数型プログラミング言語][functional-programming]であり、名前のある関数はすべて_モジュール_の中で定義する必要があります。モジュールを定義するには`defmodule`キーワードを使います。すべてのモジュールは実行時に他のすべてのモジュールから利用でき、プログラムの他の部分から見えるようにするための_アクセス修飾子_は必要ありません。_モジュール_は、他のプログラミング言語でいう_クラス_に似ています。

```elixir
defmodule Calculator do
  # ...
end
```

### 名前付き関数

_名前付き関数_はモジュールの中で定義する必要があります。_公開_の名前付き関数を定義するには`def`キーワードを使います。

関数は0個以上の引数を取ることができます。関数内の最後の式の値は、常に_暗黙的に返されます_。

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

関数を呼び出すには、そのモジュール名と関数名を指定し、関数の引数それぞれに値を渡します。

```elixir
sum = Calculator.add(1, 2)
# => 3
```

`def`の代わりに`defp`キーワードを使うと、_非公開_の関数を定義できます。非公開関数は、それを定義した同じモジュールの中からしか使えません。

定義されているのと同じモジュールの中で関数を呼び出すときは、モジュール名を省略できます。

短い関数は、1行の構文で書くこともできます（キーワード`do`の前後にあるカンマ`,`とコロン`:`に注目してください）。

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### 関数のアリティ

関数のことは、その_アリティ_で呼ぶことがよくあります。関数の_アリティ_とは、その関数が受け取る引数の数のことです。

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### 命名規則

モジュール名には`PascalCase`を使います。モジュール名は大文字の`A-Z`で始まる必要があり、文字`a-zA-Z`、数字`0-9`、アンダースコア`_`を含めることができます。

変数名と関数名には`snake_case`を使います。変数名または関数名は小文字の`a-z`かアンダースコア`_`で始まる必要があり、文字`a-zA-Z`、数字`0-9`、アンダースコア`_`を含めることができ、疑問符`?`や感嘆符`!`で終わることがあります。

### 標準ライブラリ

Elixirには、非常に充実していてドキュメントも整った標準ライブラリがあります。ドキュメントは[hexdocs.pm/elixir][docs]でオンラインで読めます。このリンクはどこかに保存しておきましょう。これから何度も使うことになります！

ほとんどの組み込みデータ型には、そのデータ型を扱う関数を提供する対応するモジュールがあります。たとえば、整数には`Integer`モジュール、文字列には`String`モジュール、リストには`List`モジュールなどがあります。

注目すべきモジュールの1つが`Kernel`モジュールです。これは、算術演算子や制御フローのマクロなど、標準ライブラリの残りの部分がその上に成り立っている基本的な機能を提供します。`Kernel`モジュールの関数は自動的にインポートされるので、`Kernel.`という接頭辞を付けずに使えます。

### コードのコメント

コメントは、ソースコードを読む他のエンジニアへのメモとして使えます。Elixirでは、1行コメントの前に`#`を付けます。
