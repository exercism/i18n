# 概要

`Map`は、**キー**と**値**のペアを保存するために使います。`Maps`は配列と同じように初期化しますが、マップリテラルの演算子`=>`を使います。キーと値の型を明示的に定義することもできますし、型を推論させることもできます。キーは一意でなければなりません。そうでなければ、エラーがスローされます。

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map`は`for`ループを使って繰り返し処理できます。値とキーのどちらに対しても繰り返し処理できます。

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

内部的には、`Map`は抽象型です。コンパイル時に、キーの型に応じて、いくつかの特化した型のいずれかに変換されます。

- `String`：`haxe.ds.StringMap`
- `Int`：`haxe.ds.IntMap`
- `EnumValue`：`haxe.ds.EnumValueMap`
- `{}`：`haxe.ds.ObjectMap`

`Map`型は実行時には存在せず、上記のオブジェクトのいずれかに置き換えられています。
