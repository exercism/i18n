# 学習

* [The Rust Programming Language](https://doc.rust-lang.org/book/)は、Rustを始めるときにも、Rustの特定の機能を深く掘り下げるときにも役立つ、優れたリソースです。
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/)では、Rustでよく書くことになるコードの例を紹介しています。
* [Into_rust()](http://intorust.com/)は「Rustを学ぶためのスクリーンキャスト」です。
* [Rustlings](https://github.com/carols10cents/rustlings)は「Rustのコードを読み書きすることに慣れるための小さな演習集」です。
* [Rust User Forum](http://users.rust-lang.org)では、あらゆるレベルの質問に答えてもらえます。
