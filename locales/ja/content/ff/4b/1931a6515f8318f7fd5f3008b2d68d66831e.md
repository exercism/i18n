# 説明

チェスの愛好家なら、自分だけのチェスを作ってみたいと思うでしょう。
インターネット上にはすでにたくさんのチェスの実装がありますが、自分で作るものは世界に一つだけです！

まずは、駒の基本的な動きの仕組みを実装するところから始めます。

チェスは、縦8マス、横8マスの盤の上で行われます。
各マスは、アルファベット1文字と数字で表されます。

## 1. ランクとファイルの範囲を定義する

ゲームでは、盤のランクを保持する必要があります。
ランクは盤の行にあたり、1から8までの数字で表されます。

盤のファイルも保持する必要があります。
ファイルは盤の列にあたり、AからHまでの文字で表されます。

ランクとファイルの範囲をそれぞれ保持する`Chess::RANKS`と`Chess::FILES`定数を定義しましょう。

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. マスが有効かどうかを判定する

ゲームでは、マスが有効かどうかを判定する必要があります。
ランクとファイルが、それぞれランクとファイルの範囲内にあれば、そのマスは有効です。

ランクを表す整数を保持する引数`rank`と、ファイルを表す文字を保持する引数`file`を取る`Chess.valid_square?`メソッドを定義しましょう。
このメソッドは、ランクとファイルがそれぞれの範囲内にあれば`true`を返し、そうでなければ`false`を返すようにします。

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. プレイヤーのニックネームを取得する

ゲームでは、プレイヤーのニックネームを取得する必要があります。
ニックネームは、プレイヤーの名の最初の2文字と、姓の最後の2文字を組み合わせたものです。
ニックネームは大文字にします。

プレイヤーの名を表す文字列を保持する引数`first_name`と、姓を表す文字列を保持する引数`last_name`を取る`Chess.nickname`メソッドを定義しましょう。
このメソッドは、プレイヤーのニックネームを大文字の文字列として返すようにします。

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 移動のメッセージを作成する

ゲームでは、どのプレイヤーがどのマスに移動したかを伝えるメッセージを作成する必要があります。
メッセージには、プレイヤーのニックネームと、移動先のマスを使います。
また、マスのファイルとランクがそれぞれの範囲内にあるかを調べて、移動が有効かどうかを判定する必要があります。

移動が有効であれば、メッセージは`"{nickname} moved to {square}"`とします。
移動が無効であれば、メッセージは`"{nickname} attempted to move to {square}, but that is not a valid square"`とします。

プレイヤーの名を表す文字列を保持する引数`first_name`、姓を表す文字列を保持する引数`last_name`、そして移動先のマスを表す文字列を保持する引数`square`を取る`Chess.move_message`メソッドを定義しましょう。
このメソッドは、移動のメッセージを文字列として返すようにします。

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
