# はじめに

## `switch`文

_if/else_文と同じように、`switch`文を使うと、条件によって実行するコードを切り替え、プログラムの流れを変えることができます。
違うのは、`switch`文が比較できるのは、プリミティブ型または文字列の式の値を、あらかじめ定義された定数と比べる場合だけという点です。

`switch`文を使うときには、役に立つキーワードがいくつかあります。

- `switch`：このキーワードを使うと、`switch`の構造を宣言できます。
  そのあとには、結果を変えるもとになる式または変数が続きます。
- `case`：このキーワードは、結果としてあり得る選択肢を宣言するために使います。
- `break`：`break`キーワードは、意図した流れの終わりで`switch`の実行を止めるのに役立ちます。
  これを忘れると、プログラムはそのまま続いてしまい、予想外の結果になることがあります。
- `default`：名前のとおり、式の結果がどの`case`にも当てはまらないときの、既定の結果として使います。

もっとも単純な形では、プリミティブ型または文字列の式を判定し、その値をもとに処理を決めます。
たとえば次のようになります。

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
