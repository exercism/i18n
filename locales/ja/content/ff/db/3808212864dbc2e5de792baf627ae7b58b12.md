# はじめに

## `nil`

[`nil`][nil-dictionary]は、英語で「何もない」や「ゼロ」を意味する言葉です。Elixirでは、`nil`は値が_存在しない_ことを表す特別な値です。

```elixir
# I do not have a favorite color
favorite_color = nil
```

ほかのプログラミング言語では、`null`や`none`という値が同じような役割を果たすことがあります。

## `if`

`cond`のほかに、Elixirには[`if/2`][getting-started-if]というマクロもあります。これは、条件を1つだけ調べたいときに役立ちます。

[`if/2`][kernel-if]は、条件と2つの選択肢を受け取ります。条件が_真とみなされる_場合は1つ目の選択肢を、_偽とみなされる_場合は2つ目の選択肢を返します。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

`if`式を1行で書くこともできます。条件のあとにカンマがあることに注目してください。

```elixir
if age > 16, do: "beer", else: "no beer"
```

この書き方は、ごく短い式には便利ですが、1行に収まらない式には使わないようにしましょう。

### _真とみなされる値_ と _偽とみなされる値_

Elixirでは、すべてのデータ型は、`if`式のような真偽値の文脈で出てくると、_真とみなされる値_か_偽とみなされる値_のどちらかに評価されます。`false`と`nil`**以外**のデータは、すべて_真とみなされる値_と見なされます。特に、空の文字列、整数の`0`、空のリストは、Elixirではすべて_真とみなされる値_です。
