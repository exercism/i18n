# ヒント

## 1. 新しいハイスコアボードを作成する

- 新しい`dict`を作成するには、[`dict.new`][new]と[`dict.from_list`][from_list]の関数を使います。

## 2. スコアボードにプレイヤーを追加する

- `dict`に新しいキーと値のペアを追加するには、[`dict.insert`][insert]関数を使います。

## 3. スコアボードからプレイヤーを削除する

- `dict`からキーと値のペアを削除するには、[`dict.delete`][delete]関数を使います。

## 4. プレイヤーのスコアを増やす

- `dict`のキーに対応する値を取得するには、[`dict.get`][get]関数を使います。
- `dict`の既存のキーと値のペアを上書きするには、[`dict.insert`][insert]関数を使います。

## 5. 月曜日のボーナスポイントを適用する

- `dict`のすべての値を変更するには、[`dict.map_values`][map_values]関数を使います。
