# 指示の補足

## 実装メモ

Treeオブジェクトには2つの属性があります。

- `String` label
- `List<Tree>` children

テストプログラムは、ビルダー関数`Tree.of`を繰り返し適用してツリーを作ります。たとえば、次の文は

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

次のツリーを構築します。

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

テスト用のツリーに重複した値はないと想定してかまいません。

---

メソッド`FromPov`と`PathTo`が、この演習の面白いところです。

メソッド`FromPov`は、文字列の引数`from`を受け取ります。これはツリー内のノードをその値で指定するものです。`from`の値を持つノードを根にしたツリーを返す必要があります。元のツリーを変更してそのまま返しても、新しいツリーを作って返してもかまいません。新しいツリーを返す場合は、元のツリーを消費したり破棄したりしても自由です。もちろん、変更せずにそのままにしておくのが望ましいですが。

メソッド`PathTo`は、2つの文字列の引数`from`と`to`を受け取ります。これらはツリー内の2つのノードをその値で指定するものです。1つ目のノードから2つ目のノードへの、ツリー内で最も短い経路を返す必要があります。

## 例外メッセージ

[例外をスローする](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)必要がある場合があります。スローするときは、エラーの原因を示す**意味のあるエラーメッセージ**を必ず含めてください。これによりコードが読みやすくなり、デバッグが格段に楽になります。

この演習では、[throwキーワード](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)を使って、`Tree()`クラスに方向を変えられないツリーが渡された場合や、`start node`と`end node`の間に経路が見つからない場合に、複数の`UnsupportedOperationException`を「スロー」する必要があります。テストは、`exception`を`throw`し、それにメッセージを添えた場合にのみ通ります。

メッセージ付きで`UnsupportedOperationException`をスローするには、メッセージを`exception`型の引数として書きます。

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
