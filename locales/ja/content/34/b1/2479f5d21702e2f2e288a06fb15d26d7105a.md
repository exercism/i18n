# はじめに

整数を対象としたビット演算子は、[`math.bitwise`][math.bitwise]にまとめられています。

```
bitand ( x y -- z )    ! AND
bitor  ( x y -- z )    ! OR
bitxor ( x y -- z )    ! XOR
bitnot ( x -- y )      ! NOT
shift  ( x n -- y )    ! left if n>0, right if n<0
```

```factor
USE: math.bitwise

12 10 bitand .    ! => 8
12 10 bitor .     ! => 14
1 4 shift .       ! => 16
16 -2 shift .     ! => 4
```

`even-parity?`と`odd-parity?`は、立っているビットの数が偶数か奇数かを返します。

```factor
USE: math.bitwise

5 even-parity? .    ! => t   (0b101 has two set bits)
5 odd-parity? .     ! => f
7 odd-parity? .     ! => t   (0b111 has three set bits)
```

1ビットだけを扱う補助ワードとして、`bit?`、`set-bit`、`clear-bit`もあります。

[math.bitwise]: https://docs.factorcode.org/content/vocab-math.bitwise.html
