# 説明

この演習では、自動車工場の組み立てラインの生産を分析するコードを書きます。
組み立てラインの速度は、`0`（停止）から`10`（最大）までの範囲です。

最低速度（`1`）では、1時間に`221`台の車が生産されます。
生産台数は速度に比例して増加します。
つまり、速度を`4`にすると、1時間に`4 * 221 = 884`台生産されるはずです。
ただし、速度が上がるほど、不良品が生産される可能性が高くなり、それらは廃棄しなければなりません。

課題は3つあります。

## 1. 成功率を計算する

与えられた速度に対して、製品がエラーなく作られる割合を計算する（_static_な）`AssemblyLine.SuccessRate()`メソッドを実装してください。
次の表は、速度が成功率にどう影響するかを示しています。

- `0`：成功率0%です。
- `1`から`4`まで：成功率100%です。
- `5`から`8`まで：成功率90%です。
- `9`：成功率80%です。
- `10`：成功率77%です。

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. 1時間あたりの生産台数を計算する

成功率を考慮して、組み立てラインの1時間あたりの生産台数を計算する（_static_な）`AssemblyLine.ProductionRatePerHour()`メソッドを実装してください。

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

戻り値は`double`であることに注意してください。

## 3. 1分あたりに生産される正常な車の数を計算する

1分あたりに何台の正常な車が生産されるかを計算する（_static_な）`AssemblyLine.WorkingItemsPerMinute()`メソッドを実装してください。

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

戻り値は`int`であることに注意してください。
