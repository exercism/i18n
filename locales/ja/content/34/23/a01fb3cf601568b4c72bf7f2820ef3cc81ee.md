# テスト

## テストの実行
Haxeのトラックでは、テストフレームワークの[Buddy](https://github.com/ciscoheat/buddy)を使います。
次のようにしてインストールできます。

```bash
haxelib install buddy
```

テストを実行するには、次のコマンドを実行します。

```bash
haxe test.hxml
```

テストファイルでは、各describeブロックが演習のテストのひとまとまりを表し、各テストは`it`または`xit`ブロックです。
`it`ブロックはテストを実行すると動きますが、`xit`ブロックは保留中のテストです。
解答を提出すると、Exercismのテストランナーがすべての`it`または`xit`ブロックを実行します。
ローカルで作業するときは、デフォルトでは最初のテストだけが実行されます。
他のテストを実行するには、対応する`xit`ブロックを`it`ブロックに変えて、`haxe test.hxml`をもう一度実行します。


また、演習によっては、haxelibで追加のライブラリをインストールする必要があります。
その場合は、演習の説明にその旨が書かれています。

## 演習を解く

演習を解くというのは、その演習のテストをすべて通すということです。
始めやすいように、各演習にはスタブの実装ファイルが用意されています。
このファイルを出発点にして、解答を作っていくことができます。
必要だと思うなら、このファイルを削除したり変更したりしてかまいません。
解答を目指して進めるときは、一度に1つのテストに集中してみましょう。
