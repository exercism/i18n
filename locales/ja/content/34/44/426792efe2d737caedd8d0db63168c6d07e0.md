# はじめに

## Nil

Gleamの`Nil`は、値が1つだけの型で、その値も`Nil`と呼ばれます。他の言語の`void`に似ていて、関数が返すのにより適した値がないときに使われます。

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Gleamの値は、他の言語のように「nil許容」や「null許容」ではありません。ある値が`Nil`になれるのは、その型が`Nil`のときだけで、他の型の値が`Nil`になることは決してありません。

## IO

ほとんどのプログラミング言語と同じように、Gleamには「副作用」があります。そのため関数は、値を返すだけでなく、世界の状態を読み取ったり変えたりできます。

Gleam標準ライブラリの`gleam/io`モジュールには、文字列をコンソールに出力するための関数が用意されています。

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

他のパッケージにも、別のIO関数が用意されていることがあります。たとえば`simplifile`は、ファイルの読み書きを行う関数を提供するパッケージです。

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
