# はじめに

Javaでは、真偽値は`boolean`型で表します。値は`true`か`false`のどちらかです。

Javaでは、3つの真偽値演算子を使うことができます。  

- `!`（NOT）：真偽値を否定します  
- `&&`（AND）：2つの真偽値を受け取り、どちらも`true`なら`true`になります  
- `||`（OR）：2つの真偽値の少なくとも一方が`true`なら`true`になります  

## 例

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
