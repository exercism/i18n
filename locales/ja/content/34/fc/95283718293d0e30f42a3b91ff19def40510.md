# 説明

以前に作った在庫管理システムの作業を続けていきます。`OpenStruct`とブロックの省略記法を知ったので、コードを少しリファクタリングすることにしました。アイテムをハッシュとして保存する代わりに、新たに身につけた知識を活かしていきます。

## 1. アイテムを取得できるようにする

在庫にあるアイテムのリストはこれまでどおり取得できるようにしたいところですが、今回はメソッドを呼び出せるオブジェクトとして扱えるようにします。

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. `item_names`をリファクタリングする

`item_names`を、ハッシュではなく新しく学んだブロックの省略記法を使うようにリファクタリングします。念のため、このメソッドは次の値を返す必要があります。

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. `total_stock`をリファクタリングする

`total_stock`を、ハッシュを参照するのではなく、OpenStructのメソッドを使うようにリファクタリングします。念のため、このメソッドは次の値を返す必要があります。

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
