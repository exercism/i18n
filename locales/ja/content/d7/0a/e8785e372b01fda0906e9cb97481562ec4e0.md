# 説明

Blorkemon™️のカードへの懐かしさはとどまるところを知らず、また集め始めてしまいましたね。友人たちも巻き込んでいます。

この演習では、`Card`のコレクションは`Set Card`で表します。というのも、存在するカードをすべて集めることが目標なら、重複したカードは重要ではないからです。

## 1. コレクションを始めよう

友人たちにもBlorkemon™️の熱狂に加わってほしいですよね。その一番の方法は、カードを1枚あげてコレクションのきっかけを作ることです。

`newCollection`を実装しましょう。これはカードをコレクションに変換します。

```elm
newCollection "Newthree"
    --> Set.fromList ["Newthree"]
```

## 2. コレクションを育てよう

コレクションができると、それは独りでに生き始め、育てていく必要があります。

`addCard`を実装しましょう。これは`Card`とコレクションを受け取り、2つの値を持つ`Tuple`を返します。1つは`Card`がすでにコレクションに入っていたかを示す`Bool`、もう1つはカードを追加したコレクションです。

```elm
addCard "Scientuna" (Set.fromList ["Newthree"])
    --> (False, Set.fromList ["Newthree", "Scientuna"])
```

## 3. 交換を始めよう

友人たちがまたBlorkemon™️に夢中になったので、カードを交換して自分のコレクションを育てられます。

すべての交換が価値があるわけでも、そもそもできるわけでもありません。持っていないカードは交換に出せませんし、すでに持っているカードと交換するべきでもありません。

`tradeCard`を実装しましょう。これは交換する2枚のカード（自分のものと相手のもの）と、現在のコレクションを受け取ります。戻り値は2つの値を持つ`Tuple`です。1つはその交換が可能で価値があるかを示す`Bool`、もう1つは交換した場合に最終的に手に入るコレクションです（実際には不可能であっても）。

```elm
tradeCard "Scientuna" "Newthree" (Set.fromList ["Scientuna"])
    --> (True, Set.fromList ["Newthree"])
```

## 4. それぞれ1枚しか存在しない

フリーマーケットで古いカードの隠し場所を見つけました。カードを並べ替えて重複を取り除き、そのリストと自分のコレクションを比べる必要があります。

`removeDuplicates`を実装しましょう。これはカードのリストを並べ替え、並べ替え済みで重複のないカードのリストを返します。

```elm
removeDuplicates ["Newthree", "Newthree", "Newthree", "Scientuna"]
    --> ["Newthree", "Scientuna"]
```

## 5. 相手が持っていないカード

自分のコレクションを誇りに思う時です。

`extraCards`を実装しましょう。これは自分のコレクションと他のコレクションを受け取り、他のコレクションが持っていないカードの数を返します。

```elm
extraCards (Set.fromList ["Scientuna"]) (Set.fromList ["Newthree", "Scientuna"])
    --> 0
```

## 6. みんなが持っているカード

Blorkemon™️好きの友人たちと集まって、どのカードが一番よくあるのか気になりました。

`boringCards`を実装しましょう。これはコレクションのリストを受け取り、すべてのコレクションが持っているカードを並べ替えたリストを返します。

```elm
boringCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> ["Scientuna"]
```

## 7. すべてのカード

あなたと友人たちは、合わせてBlorkemon™️のカードを全部持っているでしょうか？

`totalCards`を実装しましょう。これはコレクションのリストを受け取り、すべてのコレクションにある異なるカードの合計数を返します。

```elm
totalCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> 2
```

## 8. キラキラで勝負を決めよう

もうすぐ甥っ子が遊びに来ます。彼を驚かせたくなりました。子どもはキラキラしたものが好きですよね？　Blorkemon™️のカードはキラキラにできるんです！

`splitShinyCards`を実装しましょう。これはコレクションを受け取り、2つの並べ替え済みカードリストを持つ`Tuple`を返します。1つは`"Shiny"`で始まるすべてのカード、もう1つはそれ以外のカードです。

```elm
splitShinyCards (Set.fromList ["Newthree", "Scientuna", "Shiny Scientuna"])
    --> (["Shiny Scientuna"], ["Newthree", "Scientuna"])
```
