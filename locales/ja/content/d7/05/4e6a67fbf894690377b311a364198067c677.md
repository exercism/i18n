# はじめに

JSONの**オブジェクト**は、他の言語の用語で言えば「ハッシュ」「マップ」「辞書」にあたります。

JSONは_オブジェクト_を次のように定めています。

> オブジェクトは、**名前**/**値**のペアの順序を持たない集合です。
> オブジェクトは左波括弧`{`で始まり、右波括弧`}`で終わります。
> 各_名前_の後にはコロン`:`が続き、_名前_/_値_のペアはカンマ`,`で区切られます。

_名前_は**文字列でなければなりません**。_名前_のことを_キー_とも呼びます。

_値_はどんなJSONの型でもかまいません。次の例のように、同じオブジェクトの中でも_値_ごとに違う型にできます。

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

_最後_のキーと値のペアの後には、カンマを**付けてはいけません**。

## オブジェクトを作る

波括弧を使って、名前と値のペアをまとめます。名前は文字列でなければなりませんが、**識別子のような**名前（英数字とアンダースコアで構成され、数字で始まらないもの）であれば、引用符で囲む必要はありません。

```jq
{name: "Jane", age: 42}
```

_識別子のような_形でないキーを使ってもかまいません。その場合は引用符で囲むだけです。

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

名前が式の結果である場合、その式は**必ず**括弧（`()`）で囲まなければなりません。

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## インデックス

値は**ドット記法**でオブジェクトから取り出します。

```jq
{name: "Jane", age: 42} | .age    # => 42
```

キーを識別子として参照できない場合は、**ブラケット記法**を使います。

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## キーと値のペアを追加・変更する

配列に新しいキーと値のペアを追加したり、既存のキーの値を更新したりするには、`=`代入演算子を使い、左辺にインデックス式を置きます。

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+`演算子を使うと、オブジェクトを_マージ_できます。

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## キーを削除する

キーを削除するには、`del`関数を使います。更新されたオブジェクトが返ります。

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

`del`への入力は、オブジェクト内のキーに解決される**インデックス式**（ドット記法またはブラケット記法を使います）です。`jq`ではこれを**パス式**と呼びます。単に文字列を渡すだけでは不十分です。

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## キーの有無を調べる

- オブジェクトにキーがあるかどうかを調べるには、`has`関数を使います。

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- キーがオブジェクトの中にあるかどうかは、`in`で調べます。

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## すべてのキーを一覧にする

すべてのキーの一覧を出力するには、`keys`関数を使います。

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

`keys`はキーを_ソート_することに注意してください。元の順序でキーを取得するには、`keys_unsorted`を使います。

すべての_値_を一覧にするための同等の関数はありません。ただし、`.[]`フィルターはオブジェクトの値を_ストリーム_として出力し、そのストリームは`[...]`配列コンストラクターで取り込めます。

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## 繰り返し処理する

- `map_values(filter)`関数は、オブジェクト内の各_値_にフィルターを適用します。

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- オブジェクトを繰り返し処理するには、まずキーと値のオブジェクトの配列に変換する必要があります。それをしてくれるのが`to_entries`関数です。

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  ここまでくれば、`map`のような配列の繰り返し関数を使えます。

- `from_entries`関数はその逆で、キーと値のオブジェクトの配列をオブジェクトに変換します。

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- オブジェクト内の_各_キーと値のペアにフィルターを適用するには、`with_entries(filter)`関数を使います。

  たとえば、名前を年齢に対応付けるオブジェクトがあるとき、次のようにキーと値を入れ替えられます。

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  出力は次のようになります。

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)`は次と同じです。

  ```jq
  to_entries | map(filter) | from_entries
  ```
