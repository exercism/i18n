# はじめに

`LocalDate`や`LocalDateTime`のようなクラスは、時間の*一点*を表します。
`java.time`パッケージには、時間の*量*を表すクラスも2つあります。

- `java.time.Period`は、「2か月と5日」のような、年・月・日で表される時間の量です。
- `java.time.Duration`は、「1時間30分」のような、時・分・秒・ミリ秒・ナノ秒で表される時間の量です。

`Period`はカレンダーに従うため、日付や日時と組み合わせて使います。
`Duration`は正確な時間を測るので、時刻や日時には使えますが、日付には使えません。

```exercism/note
ほかの`java.time`のクラスと同じく、`Period`と`Duration`はイミュータブルです。
値を変更しているように見えるメソッドは、代わりに*新しい*インスタンスを返します。
```

## `Period`

`Period`は、静的ファクトリメソッドのいずれかを使って生成します。

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`の結果は、[ISO-8601][iso-8601-durations]の表記に従います。`P`（periodの頭文字）のあとに、年（`Y`）・月（`M`）・日（`D`）の数が続きます。

期間は、日付に足したり引いたりできます。

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

月によって長さが違うため、月を足すと存在しない日にあたることがあります。
その場合は、その月の最後の有効な日に調整されます。

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()`は、ある日付（その日を含む）から別の日付（その日を含まない）までの期間を返します。

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## `ChronoUnit`で単位ごとに数える

`Period`は、年・月・日をそれぞれ分けて保持します。
そのため`getDays()`は、期間のうち日の*部分*だけを返し、合計の日数ではありません。
2つの日付の間の、ある1つの単位の合計を数えるには、[`java.time.temporal.ChronoUnit`][chronounit-docs]の`between()`メソッドを使います。

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

2つ目の日付が1つ目より前の場合、結果は負の値になります。

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration`も、静的ファクトリメソッドを使って生成します。

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601の表記では、`T`が日付の部分と時刻の部分を区切ります。そのため、期間は`PT...`のように書きます。

期間は、日時に足したり引いたりできます。

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()`は、2つの日時の間の正確な時間を返します。

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

期間は、`toHours()`や`toMinutes()`、`toSeconds()`などのメソッドで単一の単位に変換できます。
これらは、その単位での*合計*を、切り捨てで返します。

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

時計のように期間を各部分に分けるには、代わりに`toXxxPart()`メソッドを使います。

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
