# はじめに

Cairoの型変換を使うと、データをある型から別の型へ変換できます。柔軟で安全なデータ操作ができるようになります。

## 基本

Cairoには、型変換のための仕組みがいくつか用意されています。

### 直接キャスト

互換性のある数値型であれば、直接キャストを使えます。

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### `Into`トレイト

`Into`トレイトを使うと、ある型から別の型へ変換できます。

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### `TryInto`トレイト

失敗する可能性のある変換には、`Option`を返す`TryInto`を使います。

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## 独自の型変換

自分で定義した型に`Into`を実装することもできます。

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## 安全性に関する注意点

- 変換が失敗する可能性があるとき（大きい型から小さい型への変換など）は、`TryInto`を使います
- 変換が必ず成功するときは、`Into`を使います
- `TryInto`が返す`Option::None`の場合は必ず処理しましょう
- 符号付き型と符号なし型の間で変換するときは、オーバーフローとアンダーフローに注意しましょう
