# はじめに

## 文字列の書式設定

C#/.NETで文字列を書式設定する主な仕組みは2つあります。`String.Format()`を使う方法と、文字列補間です。

### 複合書式設定

`String.Format()`は、固定テキストとプレースホルダー（ドキュメントでは書式項目と呼ばれます）からなる文字列（ドキュメントでは_複合書式_と呼ばれます）と、可変個の引数を受け取ります。戻り値は、各書式項目を対応する引数で解決し、解決された値を固定テキストと組み合わせます。

```csharp
string.Format("I had {0} bitcoins on {1}, the day I forgot my password.", 55.5, new DateTime(2010, 2, 25));
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

この仕組みは、技術的には_複合書式設定_として知られています。

### 文字列補間

補間文字列は`$`で始まり、波括弧で囲まれた実行時の式を含みます。書式項目の構文は次のとおりです：`$"{<interpolationExpression>}"`。これにより、引数を別のリストとして用意する必要がなくなります。結果は、`String.Format()`の仕組みと機能的に同等です。

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf} bitcoins on {thatDay}, the day I forgot my password."
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

### 書式項目

波括弧で囲まれたテキストは、複合書式の場合はプレースホルダー、文字列補間の場合は補間式であり、これらは_書式項目_として知られています。

書式項目は最大3つの部分から構成できます。1つ目は、上のサンプルコードにもある必須の式または引数プレースホルダーです。さらに、省略可能な配置（コンマ「,」で導入）と、省略可能な_書式文字列_（コロン「:」で導入）があります。

`{<interpolationExpression>[,<alignment>][:<formatString>]}`

_配置_は、テキストが配置される「フィールド」の長さを指定します。配置が正の場合は左に、負の場合は右にスペースで埋められます。

_書式文字列_は、出力テキストの形を指定します。たとえば、数値に桁区切り記号を含めるかどうか、`DateTime`オブジェクトの日付部分だけを出力するかどうかなどです。

次のコードは、`DateTime`オブジェクトの日付部分と、浮動小数点数を指数表記で表示する例です。

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf:E} bitcoins on {thatDay:d}, the day I forgot my password."
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings

string.Format(
    "I had {0:E} bitcoins on {1:d}, the day I forgot my password.",
    loadsOf, thatDay)
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings
```

数値と日付のどちらにも、標準書式とカスタム書式があります。_カスタム_と_標準_の間に重要な違いはありませんが、カスタム書式文字列を書式文字から組み立てられるという点だけが異なります。

### カルチャ

各スレッドには既定のカルチャ`Thread.CurrentThread.CurrentCulture`があり、これは`CultureInfo`のインスタンスにカプセル化されています。スレッドのカルチャは、英国の_DD/MM/YYYY_と米国の_MM/DD/YYYY_のように従来の日付書式が異なる場合など、地域ごとの違いに応じて日付や数値がどのように書式設定されるかを決定します。

`CultureInfo`は`IFormatProvider`インターフェースを実装しており、これは`String.Format()`の特定のオーバーロードに渡すことができます。これを使って、スレッドのカルチャを上書きできます。

## 逐語的文字列

逐語的文字列を使うと、複数行の文字列を扱えます。逐語的文字列は`@`で始めます。

```csharp
string str = @"
See no wretched
quotes everywhere
";
```
