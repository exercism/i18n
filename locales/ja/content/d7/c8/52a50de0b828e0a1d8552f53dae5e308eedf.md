# 指示

サラは新しいロールプレイングゲームに取り組んでいて、プレイヤーの仕組みについてあなたの助けを必要としています。

## 1. `player`タプルを定義する

4つのスロットとデフォルト値を持つタプルクラス`player`を定義します。

| スロット | デフォルト値 |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

定義できたら、プレイヤーをリテラルとして作ることができます。

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. プレイヤーを紹介する

プレイヤーの名前を返す`introduce`を定義します。ステルス状態のプレイヤーは名前を隠しており（`name`が`f`）、`"Mighty Magician"`として紹介される必要があります。

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. 倒れたプレイヤーを復活させる

`revive`を定義して、`health`を100、`mana`を100に設定した*新しい*プレイヤーを返します。ただし、プレイヤーの`health`が`0`の場合だけです。プレイヤーがまだ生きている場合は`f`を返します。

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. ダメージを受ける

`take-damage`を定義して、与えられた量だけ`health`が減った*新しい*プレイヤーを返します。`health`が`0`を下回ることはありません。

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
