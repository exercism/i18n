# アナライザーのタグ

アナライザーのタグは、解答が_どのように_解かれたのかを示すために使われます。

これらのタグは、次のことに使えます。

- 解答をアプローチと結びつける
- 解答をコンセプトと結びつける
- 特定のタグが付いた解答を検索する

## 形式

タグは、`<category>:<thing>`という形式の文字列です。

カテゴリーは4つあり、レベルが高い順に次のとおりです。

| カテゴリー  | 説明                                            | 具体性                                | 例                                    |
| ----------- | ----------------------------------------------- | ------------------------------------- | ------------------------------------- |
| `paradigm`  | [プログラミングパラダイム][programming-paradigms] | とても高レベルで、トラックに固有ではありません | `imperative`、`functional`            |
| `technique` | 使われているテクニック                          | 高レベルで、多くはトラックに固有ではありません | `recursion`、`immutability`           |
| `construct` | 言語の構成要素                                  | 多くはトラックに固有ではありません    | `bitwise-and`、`for-loop`             |
| `uses`      | 型やメソッドなど、言語に固有の使い方            | 低レベルで、トラックに固有です        | `DateTime.add_seconds`、`IEnumerable` |

タグの例をいくつか示します。

- `paradigm:functional`
- `technique:recursion`
- `construct:bitwise-and`
- `uses:DateTime.add_seconds`

## よく使われるタグ

トラックが解答に自由にタグを付けられるのはもちろんですが、できるだけ以下のよく使われるタグのリストを使うことをおすすめします。共通のタグを使うと、トラックをまたいだ解答のひも付けなど、便利なことができるようになります。

### パラダイム

| タグ                       | 説明                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| `paradigm:array`           | [配列プログラミング][array-programming]を使います。              |
| `paradigm:declarative`     | [宣言型プログラミング][declarative-programming]を使います。      |
| `paradigm:functional`      | [関数型プログラミング][functional-programming]を使います。       |
| `paradigm:generic`         | [ジェネリックプログラミング][generic-programming]を使います。    |
| `paradigm:imperative`      | [命令型プログラミング][imperative-programming]を使います。       |
| `paradigm:logic`           | [論理型プログラミング][logic-programming]を使います。            |
| `paradigm:meta`            | [メタプログラミング][metaprogramming]を使います。                |
| `paradigm:object-oriented` | [オブジェクト指向プログラミング][object-oriented-programming]を使います。 |
| `paradigm:procedural`      | [手続き型プログラミング][procedural-programming]を使います。     |
| `paradigm:reflective`      | [反射型プログラミング][reflective-programming]を使います。       |
| `paradigm:stack-oriented`  | [スタック指向プログラミング][stack-oriented-programming]を使います。 |
