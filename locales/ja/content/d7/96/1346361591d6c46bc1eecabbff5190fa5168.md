# はじめに

## 関数のエクスポート

関数のエクスポートについては最初の概念で扱いました。ここで簡単におさらいしておきましょう。

Elmでは、各ファイルが1つのモジュールであり、ほかのどのコードよりも前に`module`文を書く必要があります。

モジュール名はファイル名と一致していなければなりません。つまり、モジュール`Calculator`はCalculator.elmというファイルに、モジュール`Parser.Utils`はParser/Utils.elmというファイルに置く必要があります。

モジュール内で定義されたものは、そのモジュール内だけのスコープを持ち、`exposing`に挙げられていない限り、このモジュールの外からアクセスすることはできません。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## ほかのモジュールから関数をインポートする

ほかのモジュールで定義された関数にアクセスするには、インポートを使います。
そのモジュールをインポートすると、そのモジュールが公開しているすべての関数が利用できるようになります。
ただし、それらにどうアクセスするかは、モジュールのインポートのしかたによって変わります。

修飾インポートが既定で、そのようなモジュール内の関数（たとえば`List`モジュールの`map`関数）にアクセスするには、モジュール名を前に付けます（`List.map`）。

オープンインポートを使うと、そのモジュールが公開している関数に、接頭辞なしで直接アクセスできます。エクスポートで使ったものと対になる`exposing`キーワードを使って書きます。利用できるすべての関数を公開することも（`..`を使います）、特定の関数だけを公開することもできます（たとえば`map`）。

ほかのモジュールから型とそのコンストラクターをインポートすることもできますが、これは後の概念で扱います。

名前の衝突を避けてわかりやすくするため、修飾インポートが好まれます。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 型注釈

型注釈は`name : parameter types -> return type`のように定義し、引数の型も`->`で区切ります。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

括弧（`()`）を使うと、関数の引数を定義できます（引数自体も同じ構文で定義されるため、括弧が必要になります）。

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 数値

Elmで使える数値には2つの型があり、`Int`型と`Float`型で定義されています。
`Int`は正負の整数の集合に対応します。
`Float`は実数の集合に対応しますが、コンピューターの精度によって制限されます。
数値に対して定義された演算は、通常どちらか一方の型で機能し、両者を混ぜることはできません。
2つの型を相互に変換する関数もあり、たとえば`toFloat`は`Int`を`Float`に変換し、`round`、`floor`、`ceiling`、`truncate`は`Float`を`Int`に変換しますが、それぞれ意味が異なります。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 文字列の操作

コードで単語や文を表すために、Elmには組み込みの`String`型があります。
文字列リテラルは`"Hello World!"`のように二重引用符で囲んで書きます。
文字列の連結演算子`++`と等価演算子`==`は、はじめから使えます。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

そのほかの文字列関数のほとんどは`String`モジュールにあり、インポートする必要があります。

https://package.elm-lang.org/packages/elm/core/latest/String
