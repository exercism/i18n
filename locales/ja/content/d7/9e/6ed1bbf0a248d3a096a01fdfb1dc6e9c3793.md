# 説明

この演習では、1980年代の名作アーケードゲーム、[Pac-Man][Pac-Man]のルールをいくつか実装します。

実装するルールは4つあり、どれもゲームの状態に関するものです。

> _引数がどのように渡されるかは気にしなくてかまいません。引数を組み合わせて、意図した結果を返すことだけに集中しましょう。_

## 1. Pac-Manがゴーストを食べられるかどうかを定義する

`eat_ghost()`関数を定義します。この関数は2つの入力（_Pac-Manがパワーエサを食べている最中かどうか_ と _Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manがゴーストを食べられるかどうかを真偽値で返します。関数は、Pac-Manがパワーエサを食べている最中で、かつゴーストに触れているときだけ`True`を返すようにします。

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Pac-Manが得点したかどうかを定義する

`score()`関数を定義します。この関数は2つの入力（_Pac-Manがパワーエサに触れているかどうか_ と _Pac-Manがドットに触れているかどうか_）を取り、Pac-Manが得点したかどうかを真偽値で返します。関数は、Pac-Manがパワーエサかドットに触れているときに`True`を返すようにします。

```python
>>> score(True, True)
...
True
```

## 3. Pac-Manが負けるかどうかを定義する

`lose()`関数を定義します。この関数は2つの入力（_Pac-Manがパワーエサを食べている最中かどうか_ と _Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manが負けるかどうかを真偽値で返します。関数は、Pac-Manがゴーストに触れていて、パワーエサを食べている最中でないときに`True`を返すようにします。

```python
>>> lose(False, True)
...
True
```

## 4. Pac-Manが勝つかどうかを定義する

`win()`関数を定義します。この関数は3つの入力（_Pac-Manがすべてのドットを食べたかどうか_、_Pac-Manがパワーエサを食べている最中かどうか_、_Pac-Manがゴーストに触れているかどうか_）を取り、Pac-Manが勝つかどうかを真偽値で返します。関数は、Pac-Manがすべてのドットを食べていて、かつパート3で定義したルールで負けていないときに`True`を返すようにします。

```python
>>> win(False, True, False)
...
False
```
