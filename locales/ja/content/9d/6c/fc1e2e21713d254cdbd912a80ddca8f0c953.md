# 概要

[verbatim文字列][verbatim-strings]を使うと、複数行の文字列を書けます。先頭に@を付けます。文字列補間と組み合わせることもできます。開始引用符の前に「\$」を付けるだけです。

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
