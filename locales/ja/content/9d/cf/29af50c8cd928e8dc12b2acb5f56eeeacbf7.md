# 説明

この演習では、お気に入りの料理本に載っている最高のラザニアを作るために、コードを書いていきます。

ラザニアの調理にかかる時間に関わる、3つのタスクがあります。

## 1. オーブンでの想定時間を分単位で定義する

`expectedMinutesInOven`を定義して、ラザニアをオーブンに入れておくべき時間を分で計算できるようにします。料理本によると、オーブンでの想定時間は40分です。

```elm
expectedMinutesInOven
    --> 40
```

## 2. 下準備にかかる時間を分単位で計算する

`preparationTimeInMinutes`を定義します。これは、ラザニアの層の数を入力として受け取り、ラザニアの下準備にかかる時間を分で返します。1層あたり2分かかるものとします。

```elm
preparationTimeInMinutes 3
    --> 6
```

## 3. 経過時間を分単位で計算する

`elapsedTimeInMinutes`関数を定義します。この関数は2つの入力を受け取ります。1つ目の入力はラザニアの層の数で、2つ目の入力はラザニアをオーブンに入れてからの時間を分で表したものです。この関数は、ラザニアの調理に何分取り組んだかを返します。これは、下準備にかかった時間と、その時点でラザニアがオーブンにあった時間の合計です。

```elm
elapsedTimeInMinutes 3 20
    --> 26
```
