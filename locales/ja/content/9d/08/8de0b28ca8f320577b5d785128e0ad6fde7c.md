# はじめに

これまでのコンセプトで見たように、Juliaの型は階層をなし、その最上位にあるのが`Any`です。

`Number`のような抽象型にはサブタイプがありますが、抽象型そのものをインスタンス化することはできません。
変数の型に抽象型を指定すると、その変数の値は抽象型のサブタイプのいずれかに_制限_されます。
たとえば、次のようになります。

```julia-repl
julia> x::Number = 3
3
julia> typeof(x)  # one subtype of Number
Int64
julia> x = 4.2
4.2
julia> typeof(x) # another subtype of Number
Float64
julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

これで、どの入力を有効とするかを制約する、ある種の柔軟性が得られます。

しかし、変数に整数と文字列の両方の値を受け入れさせたい場合はどうでしょうか？　これらの型は階層の同じ枝にはありません。

型を`Any`に設定することも、デフォルトでそうなるようにすることもできますが、それでは許される型をまったく制御できなくなります。

よりよい方法として、`Union{ }`構文があります。これは波括弧の中に2つ以上の型を並べます。

```julia-repl
julia> y::Union{Integer, String} = 4
4
julia> typeof(y)
Int64
julia> y = "works"
"works"
julia> typeof(y)
String
julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

もう1つの例では、同じ型のUnionを関数のシグネチャに使っています。

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}
julia> f(z::IntOrString) = z^3
f (generic function with 1 method)
julia> f(2) # integers are cubed
8
julia> f("ab") # strings are repeated 3 times
"ababab"
```

ここでは型に名前を付けました。これは便利な省略記法になりますが、必ずしも必要ではありません。
関数`g(z::Union{Integer, String}) = z^3`も同じように動作します。

関数のシグネチャについては、多重ディスパッチのコンセプトで詳しく説明します。

## `nothing`を含むUnion

他のいくつかの言語には、値を含むことも含まないこともある型があり、`Option`、`Nullable`、`Maybe`などの名前が付いています。

Juliaにはこのための専用の構文はありませんが、型のUnionは同じ考え方を一般化したものです。

`Nothingness`のコンセプトで見たように、Juliaには値がないことを表す方法がいくつかあり、`nothing`や`missing`もその1つです。
これらのどちらも型のUnionに含めることができます。

たとえば、何らかの連結リストを定義するとき、これ以上ノードがなければリストを終端させる方法が必要です。
`Nothing`は単一の値`nothing`だけを持つ型で、次のNodeの定義では、これによって連鎖の終わりを示すことができます。

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

同様に、`missing`は、特にベクトルのようなコレクションで、値が存在しないことを示すプレースホルダーとして使えます。
次の例はかなり不自然ですが、実際のデータセットでは欠損値はよくあります。

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)
julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
