# 説明

この演習では、地元のゲームセンターで一番人気のゲームのハイスコアを記録する仕組みを実装します。

## 1. ハイスコアボードにプレイヤーを追加する

ハイスコアボードにプレイヤーを追加するには、次の引数を取る2つの`add_player!`メソッドを定義します：

- 第1引数はスコアの辞書です。
- 第2引数はプレイヤーの名前を表す文字列です。
- 第3引数はスコアを表す整数です。
  この引数は省略可能で、値が渡されなかった場合はスコアを0に設定します。

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. スコアボードからプレイヤーを削除する

ハイスコアボードからプレイヤーを削除するには、2つの引数を取る`remove_player!`を定義します：

- 第1引数はスコアの辞書です。
- 第2引数はプレイヤーの名前を表す文字列です。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. プレイヤーのスコアを更新する

前のスコアを置き換えてプレイヤーのスコアを更新するには、3つの引数を取る`update_score!`を定義します：

- 第1引数はスコアの辞書です。
- 第2引数は、スコアを更新したいプレイヤーの名前を表す文字列です。
- 第3引数は、保存されているハイスコアに設定したいスコアです。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. プレイヤーのスコアをリセットする

プレイヤーのスコアをリセットするには、2つの引数を取る`reset_score!`を定義します：

- 第1引数はスコアの辞書です。
- 第2引数は、スコアをリセットしたいプレイヤーの名前を表す文字列です。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. プレイヤーの配列を取得する

プレイヤーの配列を取得するには、1つの引数を取る`players`を定義します：

- 第1引数はスコアの辞書です。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
