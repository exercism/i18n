# 説明

この演習では、看板会社がオリジナルのメッセージ入り看板を作るのを手伝うコードを書きます。

## 1. 便利な文字列を用意する

看板を作るために使う、次の定数文字列を定義します。

- `birthday`: 値は"Birthday"です
- `valentine`: 値は"Valentine's Day"です
- `anniversary`: 文字列"Anniversary"を持ちます

## 2. 便利な文字を用意する

看板を作るために使う、次の定数文字を定義します。

- `space`: 値は" "（半角のスペース1つ）です
- `exclamation`: 値は"!"です

## 3. フレーズを組み合わせてメッセージを作る

関数`buildSign(for:name:)`を実装します。この関数は、引数`for`と引数`name`を取ります。`for`には、最初のタスクで定義した3つの文字列のうちの1つが入ります。`name`は文字列で、看板を贈る相手の名前が入ります。
連結を使って看板のメッセージを組み立てましょう。すでに定義した定数を再利用するのを忘れないでください。
関数は看板のメッセージを文字列として返します。

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. 卒業サインを作る

関数`graduationFor(name:year:)`を実装します。この関数は、引数`name`と引数`year`を取ります。`name`は文字列で、看板を贈る相手の名前が入ります。`year`は整数で、その人が卒業する年が入ります。
テンプレート文字列を使って看板のメッセージを組み立てましょう。
関数は看板のメッセージを文字列として返します。

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. サインの費用を計算する

関数`costOf(sign:)`を実装します。この関数は、引数`sign`を取ります。`sign`は文字列で、看板のメッセージが入ります。
看板の基本料金は、所定の通貨で20です。さらに、1文字ごとに2かかります（空白も計算に含まれます）。
関数は看板の費用を整数として返します。

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
