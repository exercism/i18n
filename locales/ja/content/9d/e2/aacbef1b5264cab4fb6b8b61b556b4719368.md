# テスト

ClojurescriptのREPLを使うと、コードを手軽に実行してすぐにフィードバックを得られます。テストの実行にも利用できます。

## Leiningen

Clojure CLIでREPLを開くには、演習のあるディレクトリに移動して、次を実行します。

``` bash
$ clojure -m cljs.main -re node
```

なお、Nodeがシステムにインストールされている必要があります。

演習に取り組む準備ができ、解答を書くファイル（`bob.cljs`など）を作成したら、ターミナルで`$ clojure -A:test`を実行するとテストを走らせることができます。

まず、テストの名前空間を`require`します。

``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

nsをテストの名前空間に変更します。

```clojure
=> (ns bob-test)
nil
```

次に、`bob-test`に対して`run-tests`を呼び出します。

``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Clojure CLIで演習のテストを実行するには、次のように呼び出すだけです。

``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
