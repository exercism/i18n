# 説明

この演習では、自動車工場での生産を分析するコードを書きます。

## 1. 1時間あたりに生産される正常な車の台数を計算する

車は生産ラインで生産されます。
生産ラインには決まった速度があり、その速度は変更することができます。
生産ラインの速度が速いほど、生産される車の台数も多くなります。
ただし、生産ラインの速度を変えると、正常に生産される車、つまり生産の過程でエラーがなかった車の台数も変わります。

1時間あたりに生産される車の台数と成功率を受け取り、1時間あたりに正常に生産される車の台数を計算する関数を実装してください。
成功率は`0`から`100`までのパーセントで与えられます。

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**注意:** 戻り値は`float64`にする必要があります。

## 2. 1分あたりに生産される正常な車の台数を計算する

1時間あたりに生産される車の台数と成功率を受け取り、1分あたりに何台の車が正常に生産されるかを計算する関数を実装してください。

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**注意:** 戻り値は`int`にする必要があります。

## 3. 生産コストを計算する

通常、車を1台ずつ生産するには、成功するかどうかに関わらず1台あたり10,000ドルかかります。
しかし、少し工夫すれば、10台の車をまとめて95,000ドルで生産できます。

たとえば、37台の車は次のように生産できます。
37 = 10台のまとまり3組 + 単体の車7台

つまり、37台の車のコストは次のとおりです。
3\*95,000+7\*10,000=355,000

成功するかどうかに関わらず、指定した台数の車を生産するコストを計算する`CalculateCost`関数を実装してください。

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**注意:** 戻り値は`uint`にする必要があります。
