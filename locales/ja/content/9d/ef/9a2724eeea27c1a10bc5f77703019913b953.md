# はじめに

## キャスト

キャストと型変換は、式をあるデータ型から別のデータ型に変える、異なる方法です。

式は、キャスト演算子`(<type>)`を使って別の型にキャストできます。

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

型に互換性がない場合は、`InvalidCastException`のインスタンスがスローされます。数値の場合は、受け取る側の型がキャストする値を表現できないことを意味します。クラスの場合は、どちらか一方の型がもう一方から派生している必要があります（これは構造体にもそのまま当てはまります）。

_キャスト_に代わる方法は、`is`演算子を使った_型変換_です。これは通常、参照型とnull許容型に適用されます。

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

オブジェクトの正確な型を調べる必要がある場合、`is`は少し寛容すぎるかもしれません。`is`は、あるクラスと、そのクラスから直接的または間接的に派生したすべてのクラスやインターフェースに対してtrueを返すからです。そのような場合は、`typeof`と`Object.GetType()`が解決策です。

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
