# はじめに

## JavaScriptの正規表現

[正規表現][mdn-regular-expressions]（Regex）とは、文字列の中の特定の要素を対象にして操作するために使える文字の並びです。これを使うと、次のことができます。

- 文字列の中からテキストを**検索**する
- 文字列の中の部分文字列を**置換**する
- 文字列から情報を**抽出**する

> 💡 JavaScriptの正規表現の仕様は、この言語のECMA-262標準の一部です。つまり、ブラウザーごとの互換性を気にする必要はありません。

## 正規表現の作り方

JavaScriptでは、正規表現はたいてい`/pattern/modifiers`という形式で書きます。

正規表現を作る方法には、次の2つがあります。

1. **正規表現リテラル**:

```javascript
const regex = /[a-z]/;
```

2. コンストラクター**RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

どちらの場合も、JavaScriptは正規表現からオブジェクトを作ります。基本的には、リテラルを使って不変のパターンを書くことをおすすめします。

`RegExp`コンストラクターは、正規表現が変わるときや、まだ正規表現が決まっていないとき（入力など）に使えます。

## 🏴‍☠️フラグ

正規表現には、[`flags`][mdn-flags]と呼ばれるオプションの特別な力があり、さらに多くの機能を使えるようになります。

よく使われるものには、次のようなものがあります。

- `/g` - グローバル検索
- `/i` - 大文字と小文字を区別しない
- `/m` - 複数行検索

簡単な例を見てみましょう。

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

`g`という文字を付けると、文字列の中にあるすべての一致を調べられます。この機能がなければ、JavaScriptは最初に見つかった`Home`だけを抽出します。

大文字と小文字を区別しない`/i`フラグを使うと、パターンを探すときに柔軟に対応できます。こうすれば、探しているものが`UPPERCASE`でも`lowercase`でも関係ありません。

`RegExp`コンストラクターを使う場合、フラグの付け方の構文が異なります。

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## よく使われる関数

正規表現をJavaScriptの組み込み関数と組み合わせると、文字列を操作したりデータを取り出したりする強力な方法が使えます。

ここでは、正規表現とともによく使われる関数をいくつか紹介します。

### `test`

[test()][mdn-regex-test]メソッドは、正規表現と指定した文字列が一致するかを検索します。`true`または`false`を返します。

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### `match`

[match()][mdn-regex-match]メソッドを使うと、見つかった一致があるかどうかによって内容が変わる、便利な配列が得られます。

このようにして、どんな文字列からでも情報を**検索**したり**抽出**したりできます。たとえば、次のとおりです。

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

グローバル検索フラグ`/g`があると、インデックスや入力などの役立つ情報とともに一致を1つだけ得る代わりに、配列に表示されるすべての出現箇所を返します。

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### `replace`

JavaScriptの[replace()][mdn-regex-replace]メソッドを使うと、指定した文字列の中から値を検索し、それを望みの新しい値に置き換えられます。

```javascript
string.replace(searchValue, newValue);
```

置換の対象を探すパターンには、単一の文字列か正規表現を使えます。

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

さらに、置換する部分に関数を適用して、それぞれの値にさらなる変更を加えることもできます。

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### `split`

JavaScriptの[split()][mdn-regex-split]メソッドは、正規表現を使って文字列を扱ったり操作したりする別の方法です。

この方法では、パターンを認識して文字列を分割するために正規表現を使います。たとえば`str.split(/[,.\s]/)`のように書きます。このパターンは`separator`として使われます。

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
