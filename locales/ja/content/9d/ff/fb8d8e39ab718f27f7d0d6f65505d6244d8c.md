# インストラクションの補足

出力は[行優先順](https://en.wikipedia.org/wiki/Row-_and_column-major_order)で並べる必要があります。つまり、最初の行の単語をすべて並べ、次に2番目の行の単語を並べる、というようにします。

## レジスタ

| レジスタ | 用途        | 型    | 説明                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 入力        | 整数 | サイズ                                |
| `$a1`    | 入力/出力 | アドレス | 行優先順の単語の行列 |
| `$v0`    | 出力       | 整数 | 行列内の単語数           |
| `$t0-9`  | 一時        | 任意     | 一時的な保存用               |
