# 概要

ビヘイビアを使うと、_ビヘイビアモジュール_の中でインターフェース（関数とマクロの集まり）を定義できます。これを後から別々の_コールバックモジュール_で実装できます。インターフェースを共有しているおかげで、これらのコールバックモジュールは互いに置き換えて使うことができます。

~~~~exercism/note
「behaviours」はイギリス英語のつづりであることに注意してください。
~~~~

## ビヘイビアを定義する

ビヘイビアを定義するには、新しいモジュールを作成し、必要なインターフェースに含まれる関数の一覧を指定します。各関数は、モジュール属性`@callback`を使って定義します。構文は[関数の型仕様][concept-typespecs]（`@spec`）とまったく同じです。指定するのは、関数名、引数の型の一覧、そして取りうる戻り値の型すべてです。

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer
end
```

## ビヘイビアを実装する

既存のビヘイビアを自分のモジュールに追加する（コールバックモジュールを作る）には、モジュール属性`@behaviour`を使います。値には、追加するビヘイビアモジュールの名前を指定します。

次に、そのビヘイビアモジュールが要求する関数（コールバック）をすべて定義します。Elixirに組み込みの`Access`や`GenServer`など、他の人が作ったビヘイビアを実装する場合は、そのビヘイビアのコールバックの一覧が[hexdocs.pm][hexdocs]のドキュメントに載っています。

コールバックモジュールは、自分のビヘイビアに含まれる関数だけを実装しなければならないわけではありません。1つのモジュールで複数のビヘイビアを実装することもできます。

どの関数がどのビヘイビア由来なのかを示すには、各関数の前にモジュール属性`@impl`を付けます。値には、そのコールバックを定義しているビヘイビアモジュールの名前を指定します。

```elixir
defmodule BookCollection do
  @behaviour Countable

  defstruct [:list, :owner]

  @impl Countable
  def count(collection) do
    Enum.count(collection.list)
  end

  def mark_as_read(collection, book) do
    # other function unrelated to the Countable behaviour
  end
end
```

## コールバックのデフォルト実装

ビヘイビアを定義するときは、コールバックのデフォルト実装を用意できます。この実装は、`__using__/1`マクロのquote式の中に定義します。ビヘイビアモジュールを使う側がデフォルト実装を上書きできるようにするには、関数の実装のあとで`defoverridable/1`マクロを呼びます。このマクロは、関数名をキー、関数のアリティを値とするキーワードリストを受け取ります。

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer

  defmacro __using__(_) do
    quote do
      @behaviour Countable
      def count(collection), do: Enum.count(collection)
      defoverridable count: 1
    end
  end
end
```

`__using__/1`の中で関数を定義するのは、コールバックのデフォルト実装を定義する以外の目的ではおすすめしません。ただし、別のモジュールで関数を定義して、それを`__using__/1`マクロの中でインポートすることはいつでもできます。
