# 手順の補足

## 帰納型を定義する

この演習では、戻り値が、自分で定義する[帰納型][inductive]の`Classification`であることを前提としています。

この型には[BEq][beq]インスタンス（真偽値による等値比較ができるようにするもの）と、[Repr][repr]インスタンス（その型の値を表示用に整形できるようにするもの）が必要です。

インスタンス宣言については、[こちらのページ][instance]を参照してください。Leanは多くのクラスに対してインスタンスを自動的に[生成][deriving]することができます。

## 部分型

`classify`関数の引数は、`Positive`という[部分型][subtype]です。

```
def Positive := { x : Nat // x > 0 }
```

部分型は、ある述語を満たす、特定の型の要素を表します。`Positive`は、`0`より大きい`Nat`の要素を表します。

部分型の要素はどれも、元になっている型の値と、その値が対応する述語を満たすという数学的な意味での証明との、2つの組になっていると考えることができます。

部分型は型のレベルで不変条件を強制するため、不正な形の値を作ることはできません。
