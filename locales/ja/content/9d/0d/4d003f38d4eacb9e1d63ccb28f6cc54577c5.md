# `while`ループと`until`ループ

ループとは、与えられた条件に基づいてコードを繰り返し実行できる制御構造です。

## `while`ループ

`while`ループは、与えられた条件に基づいてコードを繰り返し実行できる制御構造です。`while`ループの中のコードは、条件が真と評価される間、実行され続けます。`while`ループは、繰り返しの回数が事前にわからないときによく使われますが、ループが必要なあらゆる場面で使えます。

条件はループ内のコードが実行される前に評価されます。つまり、条件が偽であれば、ループ内のコードは一度も実行されません。

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

文字列を繰り返し処理したいときは、文字列の長さの分だけループを回せます。

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`ループ

`until`ループは`while`ループと同じように動きますが、ループ内のコードは条件が真と評価されるまで実行され続ける点が異なります。これは`if`と`unless`の違いと同じです。

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 無限ループ

`while`ループでよくある間違いは、決して終わらない「無限ループ」に入ってしまうことです。無限ループは、条件が_決して_真とも偽とも評価されないことによって起こることがあります。これは多くの場合、プログラマーのミスが原因です。たとえば、ループ変数のインクリメントを忘れる場合などです。しかしときには、無限ループがプログラムのロジックを実装する最も明確な方法であることもあります。あるいは、永久にループし続けることが不可欠な場合もあります。たとえば、HTTPサーバーは、やってくる接続を待ち、それを処理し、そして次の接続を待ちます。

## `break`

`break`キーワードを使うと、ループを途中で抜けられます。特定の条件でループを途中で抜けたいときに便利です。

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next`キーワードを使うと、ループの次の繰り返しにスキップできます。ループの特定の繰り返しをスキップしたいときに便利です。

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## ループ中の型

ループの中では、変数の型が変わることがあります。次の例では、`a`の型は`Int32 | String`です。ループの最初の部分では`Int32`にも`String`にもなりうるからです。変数`a`が`Int32 | String`という型になるのは、ループの最初の部分だけです。ループが始まるときには`Int32`を保持し、2回目の繰り返しでは`String`を保持するからです。この複数の型を持つ仕組みについては、後で詳しく説明します。しかし、ループの2番目の部分では`String`しか保持しないことが確実なので、ループの2番目の部分では`a`の型は`String`です。実行時には、`Int32`と`String`を同時に保持することは決してありません。

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```

## `while`を式として使う

`while`は式として使えます。つまり、変数の値として使えます。返される値は、`break`キーワードで与えた値です。ループ内の最後の式の値は返しません。

```crystal
a = while true
  break 1
end

p a
# => 1

i = 0
a = while i == 0
  i += 1
  1
end

p a
# => nil
```
