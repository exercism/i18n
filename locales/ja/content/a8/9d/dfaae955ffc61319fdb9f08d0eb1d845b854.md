# 説明

いま、注目を集めている新作ゲーム**Wings Quest**を開発しているところです。
このゲームでは、鳥になって飛び回り、種を集めます。
プレイヤーは、すべての種を拾い集めると勝利します。
プレイヤーがワシに触れてしまうと、集めた種をすべて失い、ゲームに負けます。
ただし、例外があります。プレイヤーがパワーアップを有効にしていると、ほかの鳥よりも高く飛ぶことができます。

このゲームで使われるルールをいくつか書くことが、この演習の目標です。

## 1. 鳥がボーナスポイントを獲得するかどうかを定義する

ゲームでは、鳥はパワーアップ中にワシに触れると、ボーナスポイントを獲得します。

関数`bonusPoints(powerUpActive:touchingEagle:)`を定義してください。この関数は2つの引数を取ります。`powerUpActive`は、鳥がパワーアップを有効にしているかどうかを保持し、`touchingEagle`は、鳥がワシに触れているかどうかを保持します。
この関数は、鳥がパワーアップを有効にしていて、かつワシに触れているときだけ`true`を返し、それ以外の場合は`false`を返します。

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. 鳥が得点するかどうかを定義する

ゲームでは、プレイヤーは種かパワーアップを拾うとポイントを獲得します。

関数`score(touchingPowerUp:touchingSeed:)`を定義してください。この関数は2つの引数を取ります。`touchingPowerUp`は、鳥がパワーアップに触れているかどうかを保持し、`touchingSeed`は、鳥が種に触れているかどうかを保持します。
この関数は、鳥がパワーアップか種に触れているときに`true`を返し、それ以外の場合は`false`を返します。

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. 鳥が負けるかどうかを定義する

関数`lose(powerUpActive:touchingEagle:)`を定義してください。この関数は2つの引数を取ります。`powerUpActive`は、鳥がパワーアップを有効にしているかどうかを保持し、`touchingEagle`は、鳥がワシに触れているかどうかを保持します。
この関数は、キャラクターがワシに触れていて、パワーアップを有効にしていないときに`true`を返し、それ以外の場合は`false`を返します。

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. 鳥が勝つかどうかを定義する

関数`win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`を定義してください。この関数は次の引数を取ります。

- `hasPickedUpAllSeeds`：鳥がすべての種を拾い集めたかどうか。
- `powerUpActive`：鳥がパワーアップを有効にしているかどうか。
- `touchingEagle`：鳥がワシに触れているかどうか。

この関数は、鳥がすべての種を集めていて、パート3で定義した引数に基づいて負けていないときに`true`を返し、それ以外の場合は`false`を返します。

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
