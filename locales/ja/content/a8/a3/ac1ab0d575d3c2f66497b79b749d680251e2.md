# はじめに

`for`ループは、何らかの処理を繰り返し実行するためによく使われる文のひとつです。
JavaScriptでは、`for`キーワード、丸括弧（`()`）で囲まれた_ヘッダー_、そして波括弧（`{}`）で囲まれたループの_本体_を含むコードブロックから構成されます。

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

初期化では通常カウンター変数を用意し、条件はループを続けるか止めるかを判定し、ステップは各繰り返しの最後にカウンターを増やします。
ヘッダーの各部分はセミコロンで区切られます。

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

ステップの定義には、上の例のように、JavaScriptのインクリメント演算子やデクリメント演算子を使うことがよくあります。
これらの演算子は、変数をその場で変更します。
`++`は数値に1を足し、`--`は数値から1を引きます。

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
