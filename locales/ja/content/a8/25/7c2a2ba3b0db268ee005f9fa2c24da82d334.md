# 説明

この演習では、フリーランサーがプロジェクトマネージャーとやり取りできるようにするコードを書きます。
課題は、日額と月額をすばやく計算するためのユーティリティをいくつか用意することです。割引が指定されていれば、それも適用できます。

まず、フリーランサーとプロジェクトマネージャーの間で、いくつかのルールを決めておきます。

- 日額は、時給の8倍です。
- 1か月は、請求可能な22日です。

フリーランサーが、日額に割引を適用することがあります（たとえば、最も熱心な顧客や非営利の顧客に対して）。

割引は、百分率を表す小数として扱います。たとえば`25.0`（25%）です。

~~~~exercism/note
これは、浮動小数点命令のサフィックスです。

| サフィックス | オペランドサイズ |
|--------|--------------|
| `ss`   | 32ビット       |
| `sd`   | 64ビット       |

このコンセプトで登場する命令をいくつか挙げます。

| 命令       | 説明                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | bをaにコピーします                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | 整数bを浮動小数点aに変換します                 |
| roundss/roundsd a, b, c | 浮動小数点bをcに従って丸め、aに格納します |
| cvtss2si/cvtsd2si a, b  | 浮動小数点bを整数aに変換します                 |
| comiss/comisd a, b      | aとbを比較します。`NaN`の場合は例外が発生します |
| ucomiss/ucomisd a, b    | aとbを比較します。`NaN`の場合は`PF`を設定します |

`roundss`と`roundsd`で使う丸め制御の数値は次のとおりです。

| 数値 | モード         |
|:-------|:-------------|
| 0      | 最近接      |
| 1      | 切り下げ（下方向） |
| 2      | 切り上げ（上方向）    |
| 3      | ゼロ方向への切り捨て     |
~~~~

## 1. 時給から日額を計算する

時給を64ビットの浮動小数点数として受け取り、日額を計算する`daily_rate`という関数を実装します。
契約では、1日は請求可能な8時間と定められています。

```c
daily_rate(60)
// => 480.0
```

戻り値の日額は、64ビットの浮動小数点数にします。

## 2. 割引後の価格を計算する

割引後の価格を計算する`apply_discount`関数を実装します。
元の価格と割引率（パーセント）の2つを入力として受け取ります。どちらも64ビットの浮動小数点数です。

```c
apply_discount(150.0, 10.0)
// => 135.0
```

戻り値は常に、64ビットの浮動小数点数にします。

## 3. 時給と割引から月額を計算する

割引後の月額を計算する`monthly_rate`関数を実装します。
時給と割引率（パーセント）の2つを入力として受け取ります。どちらも64ビットの浮動小数点数です。

```c
monthly_rate(77.0, 10.5)
// => 12130
```

戻り値の月額は、64ビット整数に切り上げます（天井関数）。

## 4. 予算・時給・割引から、働ける完全な日数を計算する

次の3つを入力として受け取る`days_in_budget`関数を実装します。

1. 予算（64ビットの符号なし整数）
2. 時給（64ビットの浮動小数点数）
3. 割引率（パーセント、64ビットの浮動小数点数）

この関数は、予算でまかなえる完全な労働日数を返します。

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

戻り値の日数は、32ビット整数に切り下げます（床関数）。
