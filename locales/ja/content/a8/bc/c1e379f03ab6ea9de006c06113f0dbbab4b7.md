# `rescue`を使わない

例外をフロー制御に使わないでください。
この演習は、`rescue`を使わずに解いてみましょう。

名前が`!`で終わる標準ライブラリの関数（エラーを発生させます）を使っている場合は、`!`の付かない同等の関数を探してみましょう（多くの場合、`{:ok, result}`や`{:error, message}`を返します）。

注意：この自動コメントが自分の解答に表示されている場合、ほかの自動コメントは正確でない可能性があります。
まずこの問題を直しましょう！

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
