# 説明

パレルモ港は、たくさんの船が行き来する忙しい港です。
長い間、現在港にいる船を把握するための手作業のシステムが使われてきました。
このシステムはとても間違いが起きやすく、港の責任者はコンピューター化されたシステムに置き換えることを決めました。

港の責任者から、新しいシステムの実装を任されました。
このシステムでは、船の識別子だけでなく、行き先の識別子も扱う必要があります。

## 1. 港の識別子を作成する

まず最初に、パレルモ港の識別子を作成します。
識別子は、港の名前の最初の4文字を大文字にしたものです。

`Port::IDENTIFIER`定数を、値が`:PALE`のシンボルとして定義します。

```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. 他の港の識別子を取得する

プログラムは他の港も扱う必要があるので、それらの識別子も作成します。
港はシステムの自動化を望んでおり、港ごとに命名規則が異なるため、識別子は港の名前から生成する必要があります。
識別子は、港の名前の最初の4文字を大文字にしたものです。

`Port.get_identifier`メソッドを、文字列を引数に取り、その港の識別子をシンボルとして返すように定義します。

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. 船がどのターミナルに停泊すべきか判断する

港には2つのターミナルがあり、システムは船がどのターミナルに停泊すべきかを判断する必要があります。
ターミナルは、船の識別子によって決まります。

識別子は2つの部分からできています。最初の部分は、その船がどの積荷を運んでいるかを表す3つの大文字で、その後に船を一意に識別する3つの数字が続きます。

船の識別子が**OIL**または**GAS**を運んでいる場合は、その船はターミナル**A**に停泊します。
それ以外の場合は、ターミナル**B**に停泊します。

`Port.get_terminal`メソッドを、船の識別子であるシンボルを引数に取るように定義します。
このメソッドは、ターミナルをシンボルとして返します。

```ruby
Port.get_terminal(:OIL123)
# => :A
```
