# 概要

[Pythonの比較のチュートリアル][python comparisons tutorial]と[Pythonの比較の例][python comparisons examples]は、この演習の内容をよくカバーする優れた入門資料です。

## 1. カードの値を計算する

- 等値比較演算子`==`を使うと、そのカードがエースかどうかを判定できます：`card == 'A'`。
- 包含演算子`in`を使うと、ある部分文字列が文字列に含まれているかどうかを判定できます：`'Q' in 'KJQ'`。
- [`int`コンストラクター][int constructor]を使うと、`int`の`str`を`int`に変換できます：`int('13')`。

## 2. どちらのカードの値が大きいか判定する

- `value_of_card`関数を定義したら、他の関数から呼び出せます。
- 値比較演算子`>`と`<`を使うと、特定のカードが与えられた値より_大きい_か_小さい_かどうかを判定できます：`3 < 12`。
- 等値比較演算子`==`を使うと、2つの値が互いに等しいかどうかを判定できます。

## 3. エースの値を計算する

- `value_of_card`関数を定義したら、他の関数から呼び出せます。
- ここでは、順序比較演算子`>`を使って適切な処理を選べます。

## 4. ブラックジャックを判定する

- 覚えておきましょう。カードのさまざまな組み合わせを処理するには、[`if`/`elif`/`else`構文][if syntax]が使えます。
- 比較演算子と真偽値演算子の_両方_を_自由に_つなげられます：`y < z < x`、または`(y or z) and (x or z)`
- すでに実装した`value_of_card`関数を再利用できます。

## 5. ペアを分割する

- すでに実装した`value_of_card`関数を再利用できます。
- `A`の場合（少なくとも1枚のカードがエースであるとき）は別に処理できます。

## 6. ダブルダウンする

- 手札が2枚のとき、11として数える`A`があると、ダブルダウンはできません。
- 最初のポイントを踏まえると、すでに実装した`value_of_card`関数を再利用_できるはず_です。
- 比較演算子を_自由に_つなげられます：`y < z < x`。
- [条件式][conditional expression]（_「三項演算子」とも呼ばれます_）を使うと、単純な`if`/`else`文を短く書けます：`13 if letter == 'M' else 3`。
