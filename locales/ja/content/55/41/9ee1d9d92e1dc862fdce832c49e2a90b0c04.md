# はじめに

## 入れ子の型

C#の型は、クラスや構造体のスコープの中で定義できます。外側の型が、一種の名前空間の役割を果たします。その型にアクセスするときは、外側の型からドット記法でたどります。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

内側の型にもアクセスレベルを設定できます。

外側の型のプライベートメンバーには、内側の型のメンバーからアクセスできますが、その逆はできません。
