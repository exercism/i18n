# ヘルプ

- [The Zig Programming Language Documentation][documentation]は、Zigが提供する言語機能の全体像をよくまとめたドキュメントです。
- [Zig Guide][zig-guide]は、Zigの言語機能を解説してくれる優れた入門ガイドです。
- [Ziglings][ziglings]は、とてもおすすめです。壊れた小さなプログラムを直しながらZigを学べます。
- [The Zig Programming Language Discord][discord-zig]は主要な[Discord][discord]です。Zigコミュニティ全体とつながり、Zigに関するあらゆる問題について素早く直接的な助けを得るのにうってつけの場です。
- irc.freenode.netの[#zig][irc]は、主要なZigのIRCチャンネルです。
- [/r/Zig][reddit]は、主要なZigのsubredditです。
- [Stack Overflow][stack-overflow]では、他の人がすでに質問し、解決しているかもしれない問題のコードスニペットや解答を見つけられます。
