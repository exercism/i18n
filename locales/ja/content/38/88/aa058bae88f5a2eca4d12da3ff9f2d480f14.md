# 概要

Swiftには、真偽値を表す組み込みの型[`Bool`][bools]が用意されています。真偽値とは、`true`と`false`です。

## 論理演算子

Swiftには、真偽値の式を組み合わせて評価するための3つの[論理演算子][logical-operators]（`!`、`&&`、`||`）が用意されています。

### 論理AND（`&&`）

[AND演算子][and]（`&&`）は、両方のオペランドが`true`のときだけ`true`を返します。
どちらかのオペランドが`false`なら、`false`を返します。
`&&`記号の両側には、式または真偽値を置きます。

```swift
true && true  // true
true && false // false
```

### 論理OR（`||`）

[OR演算子][or]（`||`）は、オペランドの**少なくとも1つ**が`true`なら`true`を返します。
両方のオペランドが`false`のときだけ`false`を返します。
`||`記号の両側には、式または真偽値を置きます。

```swift
true || true   // true
true || false  // true
false || false // false
```

### 論理NOT（`!`）

[NOT演算子][not]（`!`）は、真偽値を反転させます。
値が`false`なら`true`を返し、`true`なら`false`を返します。
`!`演算子は、値や式のすぐ前に置きます。

```swift
!true  // false
!false // true
```

## 括弧（`()`）を使う

[括弧][explicit-parentheses]を使うと、式をまとめて、評価の順序を制御できます。
Swiftでは、括弧の中の式が先に評価されます。

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

括弧でまとめると、NOT演算子が複雑な式にどう適用されるかも決まります。

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
評価の順序を明確にしたいときや、複雑な条件を読みやすくしたいときは、括弧を使いましょう。
デフォルトの優先順位で十分に明確なときは、不要な括弧を付けないようにしましょう。
~~~~
