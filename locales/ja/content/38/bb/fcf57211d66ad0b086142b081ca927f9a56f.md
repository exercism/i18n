# はじめに

## メソッドのオーバーロード

Javaでは、メソッドのオーバーロードを使うと、仮引数リストが異なれば、1つのクラスに同じ名前のメソッドを複数持たせることができます。これはコンパイル時のポリモーフィズム（静的ポリモーフィズム）に関係する仕組みです。似た処理を、異なる入力で行うメソッドを作るときに欠かせない考え方です。

### なぜオーバーロードするのでしょうか？

メソッドをオーバーロードすると、プログラムの可読性が高まります。仮引数が異なれば、別のメソッドに同じ名前を付けることができます。仮引数の数や型に応じて、対応するメソッドが呼び出されます。

### どうやってオーバーロードするのでしょうか？

メソッドのオーバーロードでカギになるのは、メソッドのシグネチャーです。シグネチャーが異なる2つのメソッドは、別のメソッドとみなされます。メソッドをオーバーロードする方法は2つあります。

1. **仮引数の数が違う場合**: メソッドには、同じ名前で仮引数の数だけが違うものを用意できます。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **仮引数の型が違う場合**: メソッドには、名前も仮引数の数も同じで、型だけが違うものを用意できます。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### 覚えておきたいポイント

- オーバーロードするメソッドは、引数リストを変えなければなりません。
- オーバーロードするメソッドは、戻り値の型も変えられますが、戻り値の型を変えただけではメソッドのオーバーロードにはなりません。
- メソッドは、同じクラス内でもサブクラス内でもオーバーロードできます。
