# はじめに

## エラー

プログラムやコードに何か問題があったり、予想外のことが起きたとき、それを報告するのにエラーは役立ちます。

エラーはJavaScriptのオブジェクトです。

このオブジェクトの主なプロパティは`message`です。

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw`構文を使うと、エラーを投げることができます。

```javascript
throw new Error('Oops');
```

エラーが投げられると、現在の実行は中断され、コールスタック内の最初のcatchブロックから再開されます。

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## 継承

継承は、クラス間に親子の関係を作る方法です。
子クラス（_サブクラス_とも呼ばれます）は、親クラス（_スーパークラス_とも呼ばれます）で定義された振る舞いとデータにアクセスできます。

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

子クラスの宣言にある`extends`キーワードは、[プロトタイプチェーン][prototype-chain]を通じて親クラスとの関係を確立します。

子のコンストラクターで作られたオブジェクトは、プロトタイプチェーンに親クラスのプロトタイプを持つため、親クラスで定義されたメソッドやデータにアクセスできます。

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

JavaScriptの他のクラスと同様に、サブクラスは`extends`キーワードを使って`Error`を継承し、カスタムエラーを作ることができます。
`instanceof`構文を使うと、捕まえたエラーが`Error`の特定のサブクラスのインスタンスかどうかを確認できます。

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
