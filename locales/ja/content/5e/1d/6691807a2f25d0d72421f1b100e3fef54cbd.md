# 説明

この演習では、サロンの世界に戻ってきます（`datetimes`演習で初めて登場しました）。これまでのいくつかのプロジェクトと同じように、担当している別のクライアントが大きな成功を収め、ニューヨークの拠点に加えてロンドンとパリにも店舗を出しました。

## 1. 管理者のために、UTC（協定世界時）の予約に対応する現地時刻を提供する

UTCの時刻を受け取り、現地時刻として返す静的メソッド`Appointment.ShowLocalTime()`を実装します。

```csharp
// For a student in NY
Appointment.ShowLocalTime(new DateTime(2030, 7, 25, 13, 45, 0));
// => {2030, 7, 25, 8, 45, 0}
```

## 2. ニューヨーク、ロンドン、パリで予約を登録する

サロンはそれぞれ自分で予約を受け付けます。入力する時刻は、そのサロンの所在地の現地時刻です。たとえば、ニューヨークのサロンである予約のために13時45分と入力した場合、ランチの直後にクライアントが来ることを想定しています。同じように、ロンドンのサロンで13時45分と入力した場合も、ランチの直後にクライアントが来ることを想定しています。

ニューヨーク、ロンドン、パリのタイムゾーンIDを知っておくと役に立ちます。

Mac（OSX）とLinuxでは、次のとおりです。

- ニューヨーク - America/New_York
- ロンドン - Europe/London
- パリ - Europe/Paris

Windowsでは、次のとおりです。

- ニューヨーク - Eastern Standard Time
- ロンドン - GMT Standard Time
- パリ - W. Europe Standard Time

所在地と時刻の文字列を受け取り、予約のUTC時刻を返す、静的メソッド`Appointment.Schedule()`のオーバーロードを実装します。

`Schedule()`の実装では、ビルドしたコードをLinux、Windows、Macのいずれでも実行できるようにする必要があります。オペレーティングシステムを意識する必要があるのは、これが最初の演習です。上で説明したタイムゾーンIDの違いに対応するために、コードの経路を分ける必要があります。

入力される日時の文字列は、有効であることが保証されています。

```csharp
Appointment.Schedule("7/25/2030 13:45:00", Location.Paris);
// => {2030, 7, 25, 11, 45, 0}
```

## 3. 予約前に、いくつかのタイミングでクライアントに通知を送る

予約の1日（early）、1時間45分（standard）、30分（late）前に通知を送る、静的メソッド`Appointment.GetAlertTime()`を実装します。

```csharp
Appointment.GetAlertTime(new DateTime(2030, 7, 25, 14, 45, 0), AlertLevel.Early);
// => {2030, 7, 24, 14, 45, 0}
```

## 4. サマータイムが最近切り替わった場合は、クライアントに注意を促すメッセージを送る

過去7日間にサマータイムが始まったか終わった場合に`true`を返す、静的メソッド`Appointment.HasDaylightSavingChanged()`を実装します。

```csharp
Appointment.HasDaylightSavingChanged(new DateTime(2020, 3, 30, 14, 45, 0), Location.London);
// => true
```

## 5. 現地の日時形式で予約を入力する

現地のスタッフにとって馴染みのある形式で予約を入力できるようにするために、サロンの所在地の既定の形式で日付と時刻を入力できる試験的なルーチンを作成するよう依頼されています。

所在地に適した形式の正しい日時文字列を受け取り、`DateTime`オブジェクトに変換する、`Appointment.NormalizeDateTime()`メソッドを実装します。日時をUTCに変換する処理は行いません。

不正な形式が入力された場合は、値が1/1/1の`DateTime`を返します。

```csharp
Appointment.NormalizeDateTime("25/11/2019 13:45:00", Location.London);
// => {2019, 11, 25, 13, 45, 0}
Appointment.NormalizeDateTime("25/11/2019 13:45:00", Location.NewYork);
// => {1, 1, 1, 0, 0, 0}
```
