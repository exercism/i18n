# 概要

[`switch`文][switch]は、1つの値を複数の候補パターンと照らし合わせて比較します。複数の`if-else`文を連ねるよりも、すっきりと読みやすいコードを書けるようになります。

`switch`文は、`switch`キーワードで始まり、そのあとに検査する値を書きます。それぞれの候補は、`case`キーワードで導入します。`default`キーワードは、明示したどのケースにも一致しなかったときに実行されるフォールバックのケースを定義します。`if-else`の連鎖と同じく、`switch`文が実行するのは、最初に一致したケースに対応するコードのブロックだけです。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

次の`if-else`の連鎖を見てみましょう。

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

これは、`switch`文を使うともっと明確に書けます。

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 値のバインディングと`where`節

`switch`のケースでは、一致した値を一時的な定数や変数にバインドして、そのケースの本体で使えます。また、ケースには`where`節を付け加えて、一致する前に追加の真偽値の条件を検査することもできます。

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
