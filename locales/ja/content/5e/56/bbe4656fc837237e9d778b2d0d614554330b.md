# 指示

[アームストロング数][armstrong-number]とは、それぞれの桁の数字を桁数だけ累乗し、その合計がもとの数と等しくなる数のことです。

例えば、次のようになります。

- 9はアームストロング数です。`9 = 9^1 = 9`だからです。
- 10は_アームストロング数ではありません_。`10 != 1^2 + 0^2 = 1`だからです。
- 153はアームストロング数です。`153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`だからです。
- 154は_アームストロング数ではありません_。`154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`だからです。

ある数がアームストロング数かどうかを判定するコードを書いてみましょう。

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
