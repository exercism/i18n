# 概要

[`fold`][fold]は、繰り返しの各要素に関数を適用し、その結果を新しい値に蓄積する[イテレーターを消費するアダプター][consuming iterator adaptor]です。

`fold`は繰り返しごとに2つの引数を取ります。1つ目は、アキュムレーターの初期値です。2つ目はクロージャーで、これも2つの引数、アキュムレーターと要素を受け取ります。クロージャーの戻り値が、次のアキュムレーターの値になります。イテレーターが空になると、アキュムレーターの最終的な値が返されます。

`fold`は、コレクションを1つの値に変換したいときに使えます。たとえば、すべての偶数の合計を求めたい場合は次のようになります。

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

`30`と出力されます。

`fold`でできることは、多くの場合、別の関数や複数の関数でも実現できます。先ほどの例なら、`(1..=10)`に対して[`filter`][filter]してから[`sum`][sum]するほうが簡潔で、同じ結果が得られます。次のようになります。

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

`fold`よりもよく使われる関数には、[`product`][product]や[`collect`][collect]があります。

アキュムレーターは、数値以外にも使えます。たとえば次のようになります。

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

`FeeFiFoFum`と出力されます。
