# Rustリファレンス

## 概念

Rustの概念演習では、基礎から言語の習得に至るまでの概念を教えます。以下で分類して一覧にまとめています。

Exercismの概念は、学習者に実用的な形で役立つように存在しており、その点で抽象的なアイデアとは異なります。このドキュメントでは、これらの概念がRustにおいて何を意味するのかを定義します。トラックのメンテナーが効果的なリファレンスを作成しやすいように、以下では視覚的なグルーピングを加えています。ただし、こうしたグルーピングは教育上の区分をなすものでは_ありません_。ですので、教えるときにこれらを参照しないでください。

チェックボックスは、その概念が演習のマッピング一覧ですでに教えられているかどうかを示します。

## 概念演習のマッピング

理想は、上に挙げた概念のそれぞれに対して、ちょうど1つの概念だけを教え、必要な知識をその前提条件だけに限定した概念演習を1つ用意することですが、それをそのまま実現するのは現実的ではありません。たとえば、プリミティブの知識を一切必要とせずに、関数とは何かを教える演習を設計するのは難しいでしょう。同じように、関数の知識が一切ない状態で、テストスイートを伴うプリミティブの演習を教えるのも難しいでしょう。

この表に並べた演習は、やがて上に挙げたすべての概念を網羅するDAG（有向非巡回グラフ）を形成するはずです。

| 演習                 | 前提条件                                | 教える内容                                                  | 物語                                                                        |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | 関数、テストスイート                                   | `&str`リテラル`"hello world"`を返します                                        |
| `compiled-calculator`    | `hello-world`                                | 整数、変数への代入                            | 一連の数学演算を行い、結果を暗黙的に返します                |
| `conditionals`           | `hello-world`                                | 条件分岐                                             | 3分岐の`if`/`else if`/`else`として構成するのが望ましいです。暗黙の戻り値です          |
| `slices`                 | `hello-world`、`compiled-calculator`         | スライス                                                   | 整数のスライスである引数からスライスを取り出します                        |
| `loops`                  | `slices`                                     | スライスに対する基本的なループ                               | 早期リターンを伴うのが理想的で、そのためイテレーターとして表すのは煩雑です           |
| `iterator-use`           | `slices`                                     | イテレーターの使用、`collect`                                |
| `integer-sizes`          | `compiled-calculator`                        | `i32`以外の整数、キャスティング                              | すべて符号付きのままです                                                                 |
| `unsigned-ints`          | `integer-sizes`                              | 符号なし整数                                            |
| `indexing`               | `integer-sizes`、`slices`                    | インデックスアクセス、`usize`                                        |
| `floats`                 | `compiled-calculator`                        | 浮動小数点数                                                   | おそらく同じcompiled calculator演習で、結果は整数以外になります             |
| `bools`                  | `compiled-calculator`                        | 真偽値、論理演算子                                 |
| `char`                   | `compiled-calculator`                        | `char`データ型                                          | ワイド文字の例をいくつか含めるのが望ましいです                                           |
| `str-use`                | `char`、`slices`                             | `&str`                                                   | 注：不変です！                                                                 |
| `string-use`             | `str-use`                                    | `String`                                                 | 注：所有権を持ち、可変です                                                             |
| `format-macro`           | `string-use`                                 | `format!`マクロ                                          |
| `str-vs-string`          | `str-use`、`string-use`                      | 結合、変換、コストなど                        |
| `generics-basics`        | `integer-sizes`、`floats`                    | 境界としての外部トレイトの使用、ジェネリクスの基礎          | おそらくcompiled-calculatorのままで、ジェネリックにするだけです                                 |
| `structs`                | `string-use`、`unsigned-ints`、`floats`      | データを管理するための構造体の作成と使用               | `Person`は名前、身長、所有する靴の数を持ちます                                   |
| `implicit-return`        | `compiled-calculator`                        | スコープ、式、暗黙の戻り値                     |
| `explicit-return`        | `implicit-return`、`conditionals`            | 明示的な`return`文                              |
| `methods`                | `structs`、`explicit-return`                 | `impl`ブロック、メソッド                                   |
| `tuples`                 | `structs`                                    | タプル                                                   | 匿名構造体として教えます。`.0`構文を教えます                                    |
| `tuple-structs`          | `tuples`、`structs`                          | タプル構造体（名前付きタプル）                             |
| `basic-enums`            | `unsigned-ints`                              | 基本的な列挙型（フィールドなし）、`match`                         |
| `enums`                  | `basic-enums`、`tuple-structs`               | 列挙型のバリアントに対するタプル構文                           |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | デフォルトで不変、明示的な可変性             |
| `let-expressions`        | `loops`、`option`、`result`                  | `if let`、`while let`                                    | 実装によって、`option`か`result`のどちらか一方にしか依存しないでしょう |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`、`PartialOrd`、`Debug`、`Display`、`Default` |
| `implementing-traits`    | `deriving-traits`                            | トレイトの手動実装                            | おそらく`Iterator`を実装します                                                    |
| `collection-conversions` | `vectors`、`hashsets`、`implementing-traits` | `FromIterator`、`IntoIterator`                           |
