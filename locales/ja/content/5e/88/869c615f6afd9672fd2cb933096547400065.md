# 説明

庭にやってくる鳥の数を毎日数えている、熱心なバードウォッチャーです。それぞれの日の数は、古い日を先頭とした配列に保存されています。

## 1. 今日の数

`today`を定義して、日ごとの数の配列をスタックから取り出し、今日の数を返します。

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. 今日の数を増やす

`increment-todays-count`を定義して、今日の数を1増やした新しい配列を返します。元の配列は変更しないようにしましょう。

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. 鳥が1羽もいなかった日はあったか？

`has-day-without-birds?`を定義して、少なくとも1日、鳥が0羽だった日があれば`t`を、そうでなければ`f`を返します。

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. 最初の数日間を合計する

`count-for-first-days`を定義して、数の配列と数値`n`を受け取り、最初の`n`個の数の合計を返します。

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. にぎやかな日を数える

にぎやかな日とは、鳥が5羽以上やってきた日のことです。`busy-days`を定義して、配列の中のにぎやかな日の数を返します。

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. 足りない日を埋める

`n`日間のうち観察しなかった日があるときは、足りない末尾の日を`0`で埋めます。`pad-missing-days`を定義して、数の配列と目標の長さ`n`を受け取り、長さが少なくとも`n`で、余分な部分が`0`である配列を返します。既存の数はそのまま保つ必要があり、入力の長さがすでに`n`以上であれば、そのまま返します。

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
