# はじめに

`when`は、例外をフィルタリングするときに使うキーワードです。`catch`文のあとに置き、その時点でスコープにある任意の値を使った真偽値の式を取ることができます。式が`true`と評価されれば、その`catch`文に対応するブロックが実行されます。評価されなければ、次の`catch`文があれば、そちらが調べられます。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
