# テストの実行

お使いのオペレーティングシステムを選んでください：

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. コマンドプロンプトを開きます。
2. 最初の演習を取得します：

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. 演習のディレクトリに移動します：

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. テストを実行します：

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _（最初はテストが失敗しても心配しないでください。どの演習もこうやって始めます。）_

5. 演習を解きます。`instructions.append.md`のガイドを見つけて、順に進めてください（[GitHubで見る][hello-world-tutorial]）。

うまくいきますように！　楽しんでください！

## Linux

1. ターミナルウィンドウで、最初の演習を取得します：

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. 演習のディレクトリに移動します：

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. テストを実行します：

   ```sh
   ./gradlew test
   ```

   _（最初はテストが失敗しても心配しないでください。どの演習もこうやって始めます。）_

   次のエラーが出たときは：

   ```sh
   ./gradlew: Permission denied
   ```

   ファイルに実行権限が付いていません。修正するには、次のコマンドを実行します：

   ```sh
   chmod +x ./gradlew
   ```

   これで、先ほどのコマンドを実行できるようになります。

4. 演習を解きます。`instructions.append.md`のガイドを見つけて、順に進めてください（[GitHubで見る][hello-world-tutorial]）。

うまくいきますように！　楽しんでください！
