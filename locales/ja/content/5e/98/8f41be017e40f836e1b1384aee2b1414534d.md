# MoonScriptトラックでのテスト

MoonScriptトラックでのテストは、[Luaトラックでのテスト][lua-tests]とまったく同じです。演習のディレクトリで、次のように入力します：

```console
$ busted
```

## 保留中のテスト

このトラックは、Exercismの[テスト駆動開発][tdd]という方法に沿っています。テストスイートはすべて用意されていますが、有効になっているのは最初のテストだけです。

テストを有効にするには、テストのコマンドを`pending`から`it`に変更します。

いつもすべてのテストを実行したいという方には、コマンドラインツールを使って一度にすべて変更する方法もあります。どこにでもインストールされているperlを使った例を挙げます：

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

オンラインエディターで作業しているときは、テストランナーが自動的にすべてのテストを実行します。

## LuaRocksを使う

Luaそのものは、とても小さな言語です。[LuaRocks][luarocks]は、Luaのモジュールのためのパッケージマネージャーです。

解答ではどのモジュールを使ってもかまいませんが、そのすべてがオンラインのテストランナーで使えるわけではありません。テストランナーで利用できるのは、次のとおりです：

**すでに`busted`の依存関係として利用できるもの**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**すでにMoonScriptの依存関係として利用できるもの**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**日時**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
