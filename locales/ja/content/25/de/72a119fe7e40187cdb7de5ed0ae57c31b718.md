# 説明の補足

## レジスタ

| レジスタ | 用途     | 型    | 説明                |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | 入力     | 整数 | x                          |
| `$a1`    | 入力     | 整数 | y                          |
| `$v0`    | 出力     | 整数 | 獲得ポイント              |
| `$t0-9`  | 一時的 | 任意     | 一時的な保存に使用 |
