# 説明

この演習では、地元のニュース局のための天気予報を生成します。

## 天気予報を生成する

まずは、いくつかのスタブ関数と、次の`enum`から始めます。

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

天気予報は、`"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`のように整形する必要があります。
正しい天気の状態を出力する関数を実装する必要があります。

たとえば、次のコードは雨の日の`get_weather_report`関数の期待される出力を示しています。

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

晴れの日の例はこちらです。

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
