# 指示

地元のバスケットボールチームのウェブサイトを保守するために、ウェブ開発チームと一緒に作業しています。ウェブ開発チームはElixirにあまり詳しくないため、迅速に開発を進められるよう、入れ子になったマップからデータを取り出す関数を求めています。

## 1. 入れ子になったマップ構造からデータを取り出す

2つの引数を取る`extract_from_path/2`関数を実装しましょう。

- `data`: バスケットボールチームに関するデータが入った入れ子のマップ構造。
- `path`: ピリオドで区切られたキーの文字列で、最後のキーに対応する値を取得するためのもの。

パスの途中で値またはキーが存在しない場合は、`nil`を返します。

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

この関数を実装するときは、_Access Behaviour_を使います。

入れ子のマップデータ構造を扱うために、`Map`や`Kernel`モジュールの関数を使わないでください。

## 2. 組み込み関数を使ってリファクタリングする

コードをレビューしてくれている同僚が、実装とよく似たことをする`Kernel`モジュールの関数を教えてくれます。

この`Kernel`モジュールの関数を使うように`get_in_path/2`を実装しましょう。

期待される引数は、パート1と同じです。

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
