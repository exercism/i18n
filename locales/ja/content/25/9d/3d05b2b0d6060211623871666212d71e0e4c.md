# 指示

庭にやってくる鳥の数を毎日数えています。データは整数の配列として保存され、**先頭が今日の数**です。

## 1. 今日の数

`today`を定義してください。スタックから日々の数の配列を取り出し、今日の数を返します。配列が空の場合は`f`を返します。

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. 今日の数を増やす

`increment-day-count`を定義してください。今日の数を1増やした新しい配列を返します。入力が空の場合は`{ 1 }`を返します。

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. 鳥が1羽も来なかった日はありましたか？

`has-day-without-birds?`を定義してください。0羽の鳥が記録された日が少なくとも1日あれば`t`を返し、そうでなければ`f`を返します。

`any?`などの高階のシーケンスワードではなく、**再帰を使ってください**。

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. 数え始めてからの鳥の合計

`total`を定義してください。すべての数の合計を返します。

`sum`ではなく、**再帰を使ってください**。

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. 忙しい日

忙しい日とは、鳥が5羽以上来た日のことです。`busy-days`を定義してください。忙しい日の数を返します。

`count`ではなく、**再帰を使ってください**。

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
