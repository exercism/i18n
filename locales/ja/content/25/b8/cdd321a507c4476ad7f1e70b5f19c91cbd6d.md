# はじめに

## 配列

PHPの配列は、順序付きのマップです。
マップとは、キーと値を対応付けるデータ構造です。
配列は柔軟で、線形の配列（`C`や`Java`のような）、リスト[ベクター]、ハッシュテーブル、辞書、コレクション、スタック、キューとして扱うことができます。

キーは省略できますが、指定する場合は`int`か`string`のどちらかでなければなりません。
キーを指定しない場合、PHPは`0`から始まる整数のキーを昇順に割り当てます。

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

配列には、あらゆる型の値を格納できます。
それぞれの値が異なる型でもかまいません。

### 配列を使う

配列はリテラルとして宣言する（上で書いたようにコードに直接書く）こともできますし、関数を使って作成・操作することもできます。
インデックス演算子を使って、値にアクセスしたり、代入したり、追加したりできます。

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## 可変長引数

関数の引数は、いくつでも受け取れるように指定できます。

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
