# テストを実行する

テストをコンパイルして実行するには、演習ディレクトリで次のとおり実行するだけです。
```bash
$ ponyc
$ ./exercise-name
```

（`exercise-name`は、演習ディレクトリの名前に置き換えてください）

コンパイルされたバイナリは、そのMainアクター内でテストを実行します。ですから、バイナリを実行して、テストが通ったかどうかを確認してみましょう。Ponyはコンパイル時にすべてのコードをチェックするので、必要なコードを書くまで、テストがコンパイルできないこともあります。コンパイルできないテストは、各行の先頭に`//`を付けてコメントアウトできます。その後、そのテストに取り組む準備ができたら、コメントアウトを解除できます。
