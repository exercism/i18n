# 説明

ITヘルプデスクの一員として、チケットシステムをもっと効率的に改善し、上司に統計を提供できるようにしたいと考えています。

チケットにはステータス（new、in progress...）と作成者（ユーザー名と従業員IDで識別されます）があり、IT社員に割り当てることができ、コメントの履歴を含んでいます。

ここでは、現在のチケットシステムを改善する4つのタスクを紹介します。

## 1. 空のコメントを検出する

空のコメントはインターフェースを煩雑にし、何の情報ももたらしません。それらを取り除きたいと考えています。

ユーザーとコメントのペアを受け取り、空のコメントに対して`True`を返すヘルパー関数`emptyComment`を定義しましょう。

関数の引数で分割代入を使って、ユーザーとコメントを直接取り出します。ユーザーはその情報が必要ないので無視します。

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. 作成者からのコメントの数を数える

上司は、チケットのプロセスにおけるユーザーの関与について統計を求めています。チケットの作成者が追加したコメントがいくつあるかを調べてほしいと考えています。

チケットを受け取り、チケットの作成者が追加したコメントの数を返す`numberOfCreatorComments`を定義しましょう。

関数の引数で分割代入を使って、`Ticket`型からレコードを取り出すと同時に、レコードから必要なフィールドも取り出します。次に、`let`束縛の中で`createdBy`を分解し、該当するコメントを数えられるようにします。数えるには`List`の関数を使い、無名関数の引数で分割代入を使ってユーザーとコメントのペアを分けます。

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. 開発チームに割り当てられたチケットを検出する

一部のチケットは、開発チームのAlice、Bob、Charlieにエスカレーションする必要があります。それらが進んでいるかを確かめるために、注意して見守ることが大切です。

チケットが開発チームのメンバーの誰かに割り当てられているかを確認するヘルパー関数`assignedToDevTeam`を定義しましょう。

関数の引数で分割代入を使って、`Ticket`型からレコードと必要なフィールドを取り出します。次に、1つの`case`文を使い、再帰的なパターンマッチでユーザー名を取り出し、リテラルパターンマッチで照合して、チケットがAlice、Bob、Charlieの誰かに割り当てられているかを確認します。

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. チケットをIT社員に割り当てる

ときには、たくさんのチケットを他のIT社員に再割り当てする必要があります。

そのための関数`assignTicketTo`を定義しましょう。この関数は、チケットを割り当てるユーザーとチケットという2つの引数を受け取ります。チケットのステータスが`New`なら、新しいユーザーに割り当て、ステータスを`InProgress`に変更します。それ以外のステータスでは、単純にチケットを新しいユーザーに再割り当てします。ただし、ステータスが`Archived`のチケットは一切変更しません。

関数の引数で分割代入を使って、`Ticket`型からレコードと必要なフィールドを取り出し、さらに`as`キーワードを使ってレコード全体をそのまま捕捉します。1つの`case`文を使ってステータスをパターンマッチし、`as`キーワードで捕捉した元のレコードを変更して作成した、適切なチケットを返します。

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
--        { status = InProgress
--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
