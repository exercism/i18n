# 概要

[タプル](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples)は、名前を持たないものの順序付けられた値をまとめた、_不変_のグループです。タプルには、どんなデータ型でも（複数のデータ型でも）入れることができます。他のタプルを入れることもできます。

タプルは、`(`と`)`の間にカンマで区切った値を並べて定義します：`(<element_1>, ... , <element_n>)`。

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

比較できるのは、長さと型が（同じ順序で）一致するタプルだけです。タプルは構造的等価性を持ちます。つまり、すべての値が等しい場合に_だけ_、2つのタプルは等しいとみなされます。

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

タプルから値を取り出すには、[3つの方法](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values)があります：

- `fst`関数と`snd`関数
- タプルの分解
- パターンマッチング

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
厳密には、タプルの値には`.Item1`、`.Item2`などのプロパティを使ってアクセスすることもできますが、これは推奨されておらず、コンパイラの警告が出ます。
~~~~

## タプルに関する重要なポイント

タプルについて知っておきたい重要なポイントをいくつか挙げます：

- タプル型のあるインスタンスは、1つのオブジェクトです。たとえば、C#の2要素の配列に似ています。関数に渡すときは、1つの引数として数えられます。唯一の例外は、複数の引数を持つF#以外のコードを呼び出す場合で、このときはタプルを渡すと、その値が自動的に対応する引数の値に展開されます。
- タプル型に明示的な名前を付けることはできません。タプル型の「名前」は、掛け合わされた型の組み合わせによって決まります。
- タプルを定義する決め手となる記号は、括弧（`()`）ではなくカンマです。括弧なしでタプルを定義することもできますが、ときに混乱を招くこともあります。F#では、カンマを見かけたら、それはおそらくタプルの一部です。
- タプルは、関数の引数としても、関数の戻り値としても使えます。
