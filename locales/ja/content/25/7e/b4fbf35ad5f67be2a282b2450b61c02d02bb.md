# 説明

Lispの宇宙人たちが初めて地球にやって来たとき、彼らは数えきれないほど奇妙で素晴らしいものに出会いましたが、特にお気に入りの発見のひとつが「ペット」でした。正直なところ、子犬や子猫を見て夢中にならない宇宙人がいるでしょうか？

Ludwigは、最近の地球への休暇を終えて、自分もペットを飼いたいと思うようになりました！　ただ、唯一の問題は？　選択肢が多すぎることです！Ludwigが次に抱きしめたくなる友だちを見つけて、お世話できるようにするプログラムを書いてあげませんか？

## 1. 相棒を選ぶ

Ludwigはペットを飼うと決めたものの、そこから先はまだ考えがまとまっていません。そこでまず最初のステップは、どんなペットを飼うかを決めることです！

Ludwigは、自分の性格を引き立ててくれる相棒を見つけたいと思っています。性格の特徴（キーワード）を受け取り、その特徴を持つペットの種類（文字列）を返す`pal-picker`という関数を、Ludwigに書いてあげませんか？

この場合は次のとおりです。

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

それ以外の、わからない性格の場合、関数は`"I don't know... A dragon?"`と評価されるようにしてください。

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. 自然のすみかで

Ludwigに新しい友だちができたので、住む場所が必要です！Ludwigがペットにちょうどいい大きさのベッドや水槽、おりを選ぶのを手伝えませんか？

ここでは、ペットの体重（キログラム、整数）から適切なすみかの大きさ（キーワード）を選ぶために、`habitat-fitter`という関数が必要です。

ペットの大きさごとに必要なすみかは次のとおりです。

- 40kg以上 -> `:massive`
- 20kg以上39kg以下 -> `:large`
- 10kg以上19kg以下 -> `:medium`
- 1kg以上9kg以下 -> `:small`
- 0kg以下 -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. さあ、ごはんにしましょう

地球のペットに共通する点がひとつあります。それは食べ物が必要だということです！しかし、この考えはLudwigには少しなじみがありません。エサ入れにエサを継ぎ足すのをつい忘れてしまうからです。

Ludwigには、エサ入れにエサを足す必要があるときに知らせてくれる、`feeding-time`というシンプルな関数があると助かります。この関数は満腹度の割合（整数）を受け取り、文字列の形でメッセージを返します。

エサの量が次の場合です。

- 20%より多い -> `"All is well."`
- 20%以下 -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. 行動規範

基本がすべて片づくと、Ludwigは「なでる」ことや「ボール遊び」をするなど、わくわくすることをいろいろ試すのを楽しみにしています。とはいえ、どのペットにもこうした活動が向いているわけではありません。

Ludwigは、`pet`と`play-fetch`という2つの関数を望んでいます。これらはペットの種類（文字列）を受け取り、その行動がふさわしくない場合は何も返さないか、`"Maybe not with this pet..."`のようなメッセージを返します。

ボール遊びをするのは`"Dog"`sだけで、なでることができるのは`"Fish"`以外のすべてのペットだと仮定します。

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
