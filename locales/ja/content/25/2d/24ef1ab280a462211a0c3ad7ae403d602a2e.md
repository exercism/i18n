# Introduction

## インスタンス変数

オブジェクトは、_インスタンス変数_を設定することで、自分自身の状態を保持できます。
これらの変数はオブジェクトの中に存在し、ふつうは内部の状態を保存するために使われます。

インスタンス変数は必ず`@`で始まります。
`@`で始まる変数に代入すると、新しいインスタンス変数を作ることができます。
たとえば、次のとおりです。

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

オブジェクトはふつう、初期状態を`initialize`メソッドで設定します。このメソッドは、クラスに対して`new`を呼び出すと自動的に呼び出されます。

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

`initialize`メソッドは引数を受け取ることもでき、そうすると各インスタンスを独自の状態で開始できます。

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

_インスタンス_変数は、外部からの読み書きに対して非公開とみなすのがよい習慣です。
代わりに、その値を取得・設定するメソッドを定義します。
たとえば、次のとおりです。

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary]は、「何もない」や「ゼロ」という意味の英単語です。
Rubyでは、`nil`はオブジェクトの_不在_を表すために使われます。
ほかのプログラミング言語では、`null`や`none`という値が同じような役割を果たすことがあります。

```ruby
# I do not have a favorite color
favorite_color = nil
```

Rubyでは、インスタンス変数は最初に現れたときにデフォルト値の`nil`を持ち、それ以外の値が与えられるまではそのままです。

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
