# 概要

Haxeは型付けが厳格な言語ですが、必要な場面ではその型の仕組みを回避することもできます。値に名前を付けて代入することを、変数の定義といいます。変数の定義には、型を明示的に指定する方法と、[`var`キーワード](var)を使ってHaxeコンパイラーに型を推論させる方法があります。したがって、次の2つの変数の定義は同じ意味になります。

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

変数の値を更新するには、`=`演算子を使います。

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

変数とは異なる型の値を代入しようとすると、コンパイラーはエラーを出します。

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Haxeでは、コードは通常、_関数_の中に書きます。関数は[_メソッド_](method)とも呼ばれます。関数は仮引数（引数）を受け取り、`return`キーワードを使って値を戻り値として返すことができます。関数を呼び出すときは、関数名のあとに括弧（`()`）を書きます。すべての関数には戻り値の型が必要です。

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Haxeのスコープは、`{`と`}`の間に定義されます。

Haxeには2種類のコメントがあります。1行コメントは`//`で始め、複数行コメントは`/*`と`*/`の間に書きます。
