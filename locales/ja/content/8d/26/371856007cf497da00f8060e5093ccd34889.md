# 手順

友達と一緒に、ペンと紙で遊ぶロールプレイングゲームを楽しんでいます。ただ、新しい人をグループに迎えるのはなかなか難しいことに気づきました。キャラクター作成でつまずいてしまい、どこから始めればよいかわからない人が多いのです。そこで、新しいプレイヤーを手助けするために、その流れを案内してくれる小さなプログラムを書くことにしました。

## 1. 新しいプレイヤーを歓迎する

`RPG.CharacterSheet.welcome/0`関数を実装しましょう。歓迎のメッセージを出力し、`:ok`を返します。

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. キャラクターの名前を尋ねる

`RPG.CharacterSheet.ask_name/0`関数を実装しましょう。質問を出力して答えを待ち、前後の空白を除いた答えを返します。

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. キャラクターのクラスを尋ねる

`RPG.CharacterSheet.ask_class/0`関数を実装しましょう。質問を出力して答えを待ち、前後の空白を除いた答えを返します。

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. キャラクターのレベルを尋ねる

`RPG.CharacterSheet.ask_level/0`関数を実装しましょう。質問を出力して答えを待ち、答えを整数として返します。

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. これまでのステップを1つにまとめる

`RPG.CharacterSheet.run/0`関数を実装しましょう。新しいプレイヤーを歓迎し、キャラクターの名前、クラス、レベルを尋ね、キャラクターシートをマップとして返します。また、"Your character"というラベルを付けてマップを出力します。

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
