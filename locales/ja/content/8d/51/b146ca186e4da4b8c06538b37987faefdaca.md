# はじめに

集合は、一意な値の集まりで、不変であり、順序も持ちません。集合の中の要素は、すべて同じ型でなければなりません。

`gleam/set`モジュールは`Set`型を定義し、集合を扱うための関数を提供します。

`set.to_list`と`set.from_list`を使うと、配列と集合を相互に変換できます。集合の中の要素の順序は保証されません。

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

`set.new`、`set.insert`、`set.delete`を使うと、集合を作成したり、要素を追加・削除したりできます。

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

`set.contains`と`set.size`を使うと、集合の中身を調べることができます。

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

集合は`set.union`と`set.intersect`で組み合わせることができます。

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

集合は絞り込むこともできます。

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
