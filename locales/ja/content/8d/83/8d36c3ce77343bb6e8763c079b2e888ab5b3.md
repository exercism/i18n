# 指示

熱心なバードウォッチャーで、毎日庭に何羽の鳥がやって来たかを記録しています。

バードウォッチングを一段と本格的にするために、データの記録と処理に役立ついくつかのツールを作ることにしました。

データは整数の配列として保存することにしました。
配列の最初の数値は今日庭にやって来た鳥の数で、2番目は昨日、以降も同様です。

```exercism/note
実際のアプリケーションでは、使える場面では常にコアモジュールを使うべきですが、ここでは再帰について学ぶために、この演習では`List`の関数を使わないでください。
```

## 1. 今日やって来た鳥の数を確認する

`today`関数を実装しましょう。
日ごとの鳥の数の配列を受け取り、今日の数を返します。
配列が空なら`Nothing`を返し、そうでなければ数が`Just`に包まれます。

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. 今日の数を増やす

`incrementDayCount`関数を実装しましょう。
日ごとの鳥の数の配列を受け取り、今日の数を1増やします。
配列が空の場合は`[1]`を返します。

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. 鳥が1羽も来なかった日があったかどうかを確認する

`hasDayWithoutBirds`関数を実装しましょう。
日ごとの鳥の数の配列を受け取ります。
庭に鳥が1羽も来なかった日が1日でもあれば`True`を返し、そうでなければ`False`を返します。

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. やって来た鳥の合計数を計算する

`total`関数を実装しましょう。
日ごとの鳥の数の配列を受け取り、データを記録し始めてから庭にやって来た鳥の合計数を返します。

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. 忙しい日の数を計算する

日によって忙しさは変わります。
忙しい日とは、庭に5羽以上の鳥がやって来た日のことです。

`busyDays`関数を実装しましょう。
日ごとの鳥の数の配列を受け取り、忙しい日の数を返します。

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
