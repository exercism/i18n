# ヘルプ

困ったときは、次のようなリソースで助けを求められます：

- [Futharkプロジェクトのメインサイト][main]では、[ドキュメント][docs]や[サンプル][examples]、[言語リファレンス][language-reference]などを公開しています。
- [Parallel Programming in Futhark][book]は、この言語の入門書として書かれた本です。
- [DiscordのExercismコミュニティ][exercism-discord]
- [Libera][libera]の`#futhark`チャンネル
- [futharkのGitterチャンネル][gitter]
- [/r/futhark/][reddit]は、APLのような言語のためのサブレディットです。

さらに、[StackOverflow][so]は、自分の問題や疑問がすでに回答されているかどうかを調べるのに適した場所です。
もし回答がなければ、いつでも[質問][ask-so]したり、ほかの人の質問に[回答][answer-so]したりできます。
