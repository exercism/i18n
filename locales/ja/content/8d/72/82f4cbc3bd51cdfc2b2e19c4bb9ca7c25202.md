# 説明

組織のネットワークのログイン手順を簡単にするためのシステムに取り組んでいます。ここでのタスクは、認証の部分に関するものです。このシステムでは、本人確認のために顔認証を使います。

どの場面でも、目の色のパラメータはnullでないことが保証されています。

## 1. 顔の特徴が一致することを確認する

2つの顔が一致するかを確認する`Authenticator.AreSameFace()`を実装します。

`FacialFeatures`クラスに等価性を判定するルーチンを追加します。

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. システム管理者を認証する

反対の声をよそに、システム管理者は、受け入れテストの間いつでも認証できるように、組み込みのIDを持たせると言って譲りません。

管理者のメールアドレスはadmin@exerc.ismです。目は緑色で、人中の幅は0.9です。

`Identity`クラスに等価性を判定するルーチンを追加します。

渡されたIDが管理者のものと一致するかを確認する`Authenticator.IsAdmin()`メソッドを実装します。

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. 新しいIDを登録する

`Authenticator.Register()`メソッドを実装します。このメソッドは、そのIDに対する`IsRegistered()`の呼び出しが`true`を返すように、認証器自身にIDを保存します。そうでなければ、`IsRegistered()`は`false`を返します。

同じIDを重複して登録しようとしていることを検出するために、そのIDがすでに登録済みであれば`Authenticator.Register()`は`false`を返し、そうでなければ`true`を返します。

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. 無効なIDが認証されるのを防ぐ

`Authenticator.IsRegistered()`メソッドを実装し、IDが1つも登録されていないときはfalseを返すようにします。

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. 認証の複数回の試行を検出するための診断を追加する

同じIDに対して`Authenticator.IsRegistered()`メソッドが短時間に何度も呼び出されるというバグが報告されています。まったく同じレコードが何度も送信されてしまう、いわゆる「バウンス」のような問題があるのではないかと考えられます。ここでのタスクは、実施されるテストを支えるために、診断用のルーチン`Authenticator.AreSameObject()`を追加することです。このルーチンは2つのオブジェクトを比較し、まったく同じインスタンスであれば`true`を、そうでなければ`false`を返します。

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
