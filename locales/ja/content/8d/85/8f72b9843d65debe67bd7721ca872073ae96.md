# 概要

ポインタが`int`などの基本的なデータ型を指すように作れるのと同じように、関数を指すポインタも作ることができます。関数ポインタを使うと、ある関数を別の関数に渡せます。別の関数に仮引数の値として渡される関数は、第一級関数と呼ばれます。1つ以上の関数を仮引数として受け取る関数、または関数を返す関数は、高階関数と呼ばれます。

次の例では、`is_even`と`is_odd`が第一級関数です。高階関数は`test_number`です。

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
`test_number`の最初の引数である`bool (*func) (int)`という関数シグネチャは、渡される関数のシグネチャと一致します。`is_even`も`is_odd`も、`int`の仮引数を取り、`bool`を返します。`(*func)`において、`func`は使用する関数の名前を表します。もし`(*fn)`を使うのであれば、次のように呼び出すことになります：`printf(text, number, fn(number)? "true": "false");`。関数ポインタの仮引数を満たすには、`test_number`を呼び出すときに、期待されるシグネチャを持つ関数の名前を渡します。このように、関数名はその名前の関数のアドレスを指していることがわかります。

間違ったシグネチャで関数ポインタを呼び出すと、未定義動作（UB）になります。コンパイラによっては、コンパイルが通らないこともあります。また、警告が出ても出なくてもコンパイルは通るものの、実行時にクラッシュすることもあります。
