# 説明

この演習では、ラジコンカーを動かして遊びます。このラジコンカーは、お金を貯めてやっと買えるようになったものです。

車のバッテリーは、最初は満充電（100%）です。リモコンで車を走らせるたびに、20メートル進み、バッテリーを1パーセント消費します。車のニックネームは、車が作成されるまでわかりません。

このラジコンカーには、2つの情報を表示するおしゃれなLEDディスプレイが付いています。

- これまでに走った合計距離。`"<METERS> meters"`のように表示されます。
- バッテリーの残量。`"Battery at <PERCENTAGE>%"`のように表示されます。

バッテリーが0%になると、車はもう走らせられなくなり、バッテリー表示は`"Battery empty"`になります。

## 1. 新品のラジコンカーを作成する

新品のラジコンカーの構造体を返す`RemoteControlCar.new/0`関数を実装しましょう。

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

ニックネームは構造体で必須の項目です。値は`new`関数の中で初期化し、構造体では初期化しないようにしてください。

## 2. ニックネームを指定して新品のラジコンカーを作成する

指定したニックネームを持つ新品のラジコンカーの構造体を返す`RemoteControlCar.new/1`関数を実装しましょう。

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. 走行距離を表示する

LEDディスプレイに表示されるのと同じ走行距離を返す`RemoteControlCar.display_distance/1`関数を実装しましょう。

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

この関数は、引数として`RemoteControlCar`構造体のみを受け取るようにしてください。

## 4. バッテリー残量を表示する

LEDディスプレイに表示されるのと同じバッテリー残量を返す`RemoteControlCar.display_battery/1`関数を実装しましょう。

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

この関数は、引数として`RemoteControlCar`構造体のみを受け取るようにしてください。バッテリーが0%になると、バッテリー表示は"Battery empty"になります。

## 5. 車を走らせると、バッテリーと走行距離が変わる

次の処理を行う`RemoteControlCar.drive/1`関数を実装しましょう。

- 走行距離を20メートル増やす
- バッテリーを1%消費する

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

この関数は、引数として`RemoteControlCar`構造体のみを受け取るようにしてください。

## 6. バッテリー切れの状態での走行を考慮する

バッテリーが切れている（0%）ときは、走行距離を増やさず、バッテリー残量も減らさないように`RemoteControlCar.drive/1`関数を更新しましょう。

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
