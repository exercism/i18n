# 説明

魔法使いになるため、Elyseは基本をいくつか練習する必要があります。彼女はトランプのデッキを持っていて、それを操作したいと思っています。

少しでも簡単にするために、彼女は1から10のカードだけを使います。

## 1. デッキからカードを取り出す

`getCard`関数を実装してください。この関数は、与えられたデッキの`index`の位置にあるカードを返します。`index`がデッキにない場合は、Nothingを返します。

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. デッキのカードを変更する

`setCard`関数を実装してください。この関数は、`index`の位置にあるカードを、与えられた新しいカードに変更したデッキを返します。
`index`がデッキにない場合は、元のデッキを返します。

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. デッキにカードを追加する

`addCard`関数を実装してください。この関数は、新しいカードを追加したデッキを返します。

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. デッキからカードを削除する

`removeCard`関数を実装してください。この関数は、`index`の位置にあるカードを削除したデッキを返します。
与えられた`index`がデッキの有効なインデックスでない場合は、元のデッキを返します。

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. デッキにある偶数のカードの枚数を数える

`evenCardCount`関数を実装してください。この関数は、デッキにある偶数のカードの枚数を数えます。

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
