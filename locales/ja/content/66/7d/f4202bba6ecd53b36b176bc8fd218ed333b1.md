# 指示

ネットボールの試合でスコアボードを担当することになりました。これまでと違って、スコアボードは起きたことを覚えておかなければなりません。

`SCOREBOARD`クラスには次のものが必要です。スタブにはクラスと、その2つの属性の宣言が用意されています。残りは自分で追加しましょう。

## 1. スコアボードを用意する

`create`はホームチームの名前とアウェイチームの名前を受け取り、どちらの得点も0のスコアボードを返します。

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. ゴールを決める

`home_goal`はホームの得点に1を加え、`away_goal`はアウェイの得点に1を加えます。どちらも何も返しません。

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. スコアボードを読み取る

`summary`は、スコアボードを掲示するときのように返します。つまり、ホームチーム、その得点、ダッシュ、アウェイの得点、そしてアウェイチーム、の順です。

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

空白は表示のとおりにし、ダッシュは1つの`-`にします。

## 4. どちらが勝っている？

`leader`はリードしているチームの名前を返し、得点が並んでいるときは`"Draw"`を返します。

```sather
board.leader
-- => "Vixens"
```

## 5. どのくらいリードしている？

`margin`は、2チームを分けるゴール数を返します。どちらがリードしていても、負の値になることはありません。

```sather
board.margin
-- => 1
```
