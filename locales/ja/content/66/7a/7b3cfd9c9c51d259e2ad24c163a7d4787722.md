# 指示

マジシャンの卵であるElyseは、基本の練習をする必要があります。Elyseには、操りたいカードの山があります。

少し簡単にするため、Elyseは1から10までのカードだけを使います。そうすると、カードの山は数値のベクトルで表せます。
あるカードの位置は、ベクトルのインデックスに対応します。

## 1. 山からカードを取り出す

カードを1枚選ぶには、渡された山からインデックス`position`のカードを返します。

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. 山の中のカードを交換する

手品の要領で、インデックス`position`のカードを、渡された交換用のカードと入れ替えます。
調整後の山を返します。

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. 山の一番上にカードを挿し込む

山の一番上に新しいカードを挿し込んで、カードを出現させます。
調整後の山を返します。

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. 山からカードを取り除く

山から、指定された`position`のカードを取り除いて、カードを消します。
調整後の山を返します。

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. 山の枚数を確認する

山の枚数が`stack_size`と同じかどうかを確認します。

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. 山の一番上のカードを取り除く

山の一番上のカードを取り除いて、カードを消します。
調整後の山を返します。

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. 山の一番下にカードを挿し込む

山の一番下に新しいカードを挿し込んで、カードを出現させます。
調整後の山を返します。

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. 山の一番下のカードを取り除く

山の一番下のカードを取り除いて、カードを消します。
調整後の山を返します。

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
