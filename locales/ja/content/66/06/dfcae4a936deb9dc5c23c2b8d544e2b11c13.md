# タプル

[タプル][tuple]は、要素の有限で順序付けられたリストであり、不変です。
タプルは、すべての位置が固定の型を持つことを要求します。
つまり、コンパイラーはそれぞれの位置にどの型があるのかを把握しています。
タプルで使われる型は位置ごとに異なっていてもかまいませんが、型はコンパイル時に判明していなければなりません。

## タプルの作成

タプルの値の型をコンパイル時に解釈できるかどうかに応じて、タプルはさまざまな方法で作成できます。
値がコンパイル時に判明している場合は、タプルのリテラル構文を使ってタプルを作成できます。そうでない場合は、明示的に宣言する必要があります。
また、値の型がタプルで指定した型と一致し、値の個数が指定した型の個数と一致していることも重要です。
タプルのリテラル構文で定義する例を次に示します。

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

`Tuple`クラスを使ってタプルを作成することもできます。

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

または、タプルに代入する変数の型を明示的に指定することもできます。

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

タプルの型を明示的に指定すると、ある位置がユニオン型を持つように定義できるため、便利なことがあります。
つまり、1つの位置が複数の型を持てるということです。

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## 変換

### 配列からタプルを作成する

`Tuple`クラスの`from`メソッドを使うと、配列からタプルを作成できます。
そのためには、タプルの型を指定する必要があります。

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### 配列への変換

`to_a`メソッドを使うと、タプルを配列に変換できます。
できあがる配列の要素の型は、タプルの各フィールドの型のユニオンになります。

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### タプル定義の省略記法

明示的なタプルの型を定義するための省略記法があります。
タプルのリテラルの中に型を書く方法です。

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## 要素へのアクセス

配列と同じように、タプルは0から始まるインデックスを持ち、最初の要素はインデックス0にあります。
ただし、配列と違って、各要素の型は固定されておりコンパイル時に判明しているため、タプルにインデックスを付けると、要素の型はその位置に固有のものになります。
タプルの要素にアクセスするには、`[]`演算子を使います。

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

配列から要素にアクセスする場合とのもう1つの違いは、インデックスを指定すると、コンパイラーがそのインデックスがタプルの範囲内にあるかどうかをチェックする点です。
つまり、実行時エラーではなくコンパイル時エラーになります。

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

ただし、インデックスが変数に格納されている場合、コンパイラーはコンパイル時にそのインデックスがタプルの範囲内にあるかどうかをチェックできないため、代わりに実行時エラーになります。

## サブタプル

`[]`演算子に範囲を渡すと、タプルのサブタプルを取得できます。
返ってくるのは、指定した範囲の要素を持つ新しいタプルです。
範囲はコンパイル時に与える必要があります。そうでないと、コンパイラーはサブタプルの要素の型を知ることができません。
つまり、範囲は範囲リテラルである必要があり、変数に代入してはいけません。

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## タプルをいつ使うか

タプルは、型がコンパイル時に判明している固定数の値をまとめたいときに便利です。
これは、タプルが不変であるため、配列よりも必要なメモリが少なく、高速だからです。
もう1つの用途は、メソッドから複数の値を返すことです。
タプルの各位置が異なる型を持てるため、値の型が異なる場合に特に役立ちます。

サイズが大きくなったり小さくなったりするデータ構造が必要な場合や、頻繁に変更する必要がある場合には、タプルを使うべきではありません。
