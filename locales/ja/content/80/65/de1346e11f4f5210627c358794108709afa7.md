# 概要

Goには、`fmt`（フォーマットパッケージ）という組み込みパッケージがあり、入出力の書式を操作するためのさまざまな関数を提供しています。
もっともよく使われる関数が`Sprintf`です。`Sprintf`は`%s`のような_動詞_を使って値を文字列に埋め込み、その文字列を返します。

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Goでは、浮動小数点数の値はSprintfの_動詞_を使うと便利に書式設定できます。`%g`（コンパクトな表現）、`%e`（指数）、`%f`（指数なし）の3つです。
どの_動詞_でも、フィールドの幅と数値の位置を制御できます。

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

利用できる_動詞_の一覧は、[フォーマットパッケージのドキュメント][fmt-docs]にあります。

`fmt`には、文字列を扱うためのほかの関数もあります。たとえば`Println`は受け取った引数をそのままコンソールに出力し、`Printf`は`Sprintf`と同じように入力を書式設定してから出力します。

[fmt-docs]: https://pkg.go.dev/fmt
