# 説明

Lispの宇宙人リリーは料理が大好きです。友達とピザパーティーを開きたいのですが、材料をできるだけ無駄なく使うために、始める前にそれぞれの材料がどれだけ必要になるかを正確に知りたいと思っています。

これを解決するために、リリーは計画の一部を自動化するプログラムを書き始めましたが、完成させるには助けが必要です。リリーが、配合の完璧なピザパーティーを開くのを手伝ってみませんか？

## 1. 生地の比率

まず最初に。どんなに素晴らしいピザも、おいしい生地から始まります。

リリーは、薄くてパリッとしていて、縁が少し厚めのピザが好きです。
中央部分に必要な生地は常に200gですが、縁は20cmごとに45gの生地が必要です。

ありがたいことに、リリーはピザの枚数（n）とその直径（d）から、生地のグラム数（g）を求める式を計算してくれました。

`g = n * (((45 * pi * d) / 20) + 200)`

リリーに必要なのは、次のような関数です。
* ピザの枚数（n）と、その直径（d）を受け取ります。
* そして、必要な生地の量を、最も近いグラム（g）に丸めて返します。

たとえば、直径30cmのピザを4枚作るには：

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. ソースをひと垂らし

リリーはソースを塗るときは几帳面ですが、ピザの大きさは一定しないことがあります。

直径（d）を求めるために、リリーは塗ったソースの量（s）を変数にした、次の式を使います。

`d = square-root of ((40 * s) / (3 * pi))`

リリーに必要なのは、塗ったソース1ミリリットルあたりからピザの直径（d）を計算する関数です。

たとえば、リリーがソースを250ml使ったとします：

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. チーズもお願いします

リリーの星では、チーズはどれも完璧な立方体で、大きさごとに売られています。
（何を期待していたんですか？　ここは何しろ宇宙の星ですから……）

ここでもまた、リリーは一辺の長さ（l）のチーズの立方体から作れる、ある直径（d）のピザの枚数（n）を求める式を計算してくれました。

`n = (2 * (l^3)) / (3* pi * (d^2))`

次のような関数を作ってください。
* チーズの立方体の一辺の長さ（l）と、ピザの直径（d）を受け取ります。
* そして、作れるピザの枚数（n）を、切り捨てて返します。

たとえば、25x25x25cmのチーズの立方体と、直径30cmのピザの場合：

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. 公平な分配

最後に、リリーはピザをそれぞれ8切れに分けて、友達の間で均等に配りたいと考えています。

次のような関数を作ってください。
* ピザの枚数と友達の人数を受け取り
* ピザが友達の間で均等に分けられるなら`T`を、そうでなければ`NIL`を返します。

たとえば：

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
