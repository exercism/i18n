# 概要

## メソッドの集まりとしてのインターフェース

もっとも単純な形では、**インターフェース型**はメソッドのシグネチャの集まりです。
次は、`Add`と`Value`という2つのメソッドを含むインターフェース定義の例です。

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

`increment`のような仮引数の名前はインターフェース定義から省略できますが、書いておくと読みやすくなることがよくあります。

Goのインターフェース名には、`Interface`や`I`という語は含めません。
その代わり、`Reader`や`Stringer`のように、`er`で終わることがよくあります。

## インターフェースの実装

インターフェースのメソッドを定義している型は、自動的に、暗黙的にそのインターフェースを「実装」します。
Goには`implements`というキーワードはありません。

次の型は、上で見た`Counter`インターフェースを実装しています。

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

インターフェースを実装するうえでは、メソッドが値レシーバーとポインターレシーバーのどちらを持つかは関係ありません。
（これらについて自信がなければ、[メソッドの概念][concept-methods]をもう一度見てみましょう。）

> インターフェース型の値は、それらのメソッドを実装する任意の値を保持できます。 [^1]

つまり`Stats`は、`Counter`インターフェースを期待するあらゆる場所で使えるようになりました。

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

もし関数のすべての仮引数と戻り値が具象型（つまり、インターフェースではない型）を使う必要があるとしたら、関数の再利用性は大きく制限されてしまいます。
仮引数にインターフェース型を使うと、その関数が役割を果たすために必要な振る舞いだけが定義されます。
これで、具象型がそのインターフェースを実装していれば、関数はさまざまな具象型の仮引数とともに使えます。
インターフェース型を戻り値として使う場合も、同じことが言えます。

インターフェースは暗黙的に実装されるので、型は複数のインターフェースを簡単に実装できます。
必要なメソッドがすべて定義されていればよいのです。

## インターフェースの組み合わせ

インターフェース定義には、他のインターフェースを含めることができます。
次は標準ライブラリからの例です。

```go
type ReadCloser interface {
	Reader
	Closer
}

// Based on these interfaces:

type Reader interface {
	Read(p []byte) (n int, err error)
}

type Closer interface {
	Close() error
}
```

`ReadCloser`を定義するために`Read`と`Close`のメソッドシグネチャを繰り返すのではなく、このインターフェース定義では`Reader`と`Closer`の既存の定義を利用しています。

## 空のインターフェース

Goにはとても特別なインターフェース型が1つあります。メソッドを1つも含まない**空のインターフェース**型です。
空のインターフェースは`interface{}`のように書きます。
Go 1.18以降では、`any`も使えます。
`any`はエイリアスとして定義されました。

空のインターフェースにはメソッドがないので、すべての型が暗黙的にこれを実装します。
これは、どんな値でも汎用的に受け取れる関数を定義するのに役立ちます。
その場合、関数の仮引数には空のインターフェース型を使います。

例えば、次のとおりです。

```go
func AnythingGoes(i interface{}) string {
    if i == 0 {
        return "zero"
    }
    if i == "" {
        return "empty string"
    }
    return "something else"
}
```
