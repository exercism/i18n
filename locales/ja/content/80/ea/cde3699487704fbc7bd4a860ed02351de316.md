# はじめに

`Rational numbers`は、整数の分子を整数の分母で割った分数です。

たとえば、`2//3`は、近似値である`Float64`の`0.6666...`ではなく、正確な分数として保存できます。

利点は、（*整数オーバーフロー*という極端な場合を除き）有理数が正確なまま保たれ、浮動小数点数ではしばしば避けられない丸め誤差を防げることです。

有理数はとてもシンプルな数値型で、みなさんが期待するとおりに動くことを目指しています。Juliaでは初期のバージョンから標準の型であるため、ほとんどの関数は整数や浮動小数点数と同じように有理数を入力として受け取ります。

## 有理数の作成

作成は、2つの整数の間に`//`を使うだけです。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

共通の因数は自動的に約分され、分数は「最小の項」に変換されます。つまり、その分数を正確に表す最小の整数になり、分母は非負になります。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## 有理数の算術演算

通常の`arithmetic operators`である`+ - * / ^ %`は有理数でも使え、基本的に他の数値型の場合と同じです。

整数や他の`Rational`を混ぜることができ、結果は`Rational`になります。式に`float`を含めると結果は`float`になり、その分だけ精度が失われる可能性があります。

`float`が必要な場合は、`float()`関数で有理数を変換するだけです。長い計算のあいだは有理数のまま精度を保ち、最後に浮動小数点数へ変換するのは、よくあるやり方です。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## その他の操作

Juliaでは、有理数もただの数値です。コンパイラーが通常は必要に応じて型を変換してくれます。

ただし、比較が期待どおりに機能するのは、有限の小数で表せる分数の場合だけである点に注意してください。

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

それ以外の場合は、比較のために`Rational`を`Float`にキャストする必要があります。

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

数学関数は有理数を入力として受け取りますが、浮動小数点数の結果を返すことがあります。

```julia-repl
julia> sqrt(9//16)
0.75
```
