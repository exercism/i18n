# Bashの花畑演習のヒント

この演習では、二次元配列が必要になりそうです。
Bashが提供するのは、一次元のインデックス[配列][array]と連想配列だけです。

多次元配列は、連想配列を使って再現できます。インデックスをカンマ区切りの文字列に変換し、それを配列のキーとして使います。

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
