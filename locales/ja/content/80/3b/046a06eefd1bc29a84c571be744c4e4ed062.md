# 指示の補足

## 実装上の注意

Cipherインターフェースの定義は`cipher.go`にあります。

実装はCipherインターフェースに準拠させてください。

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

`Encode`は、文字列内のA-Za-z以外の値はすべて無視することを想定しています。それらは出力には現れません。
出力は小文字に正規化されます。

暗号を取得するために使う関数は次のとおりです。

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

`NewShift`の引数は、1から25、または-1から-25の範囲でなければなりません。
0は使用できません。
無効な引数の場合、`NewShift`はnilを返します。

`NewVigenere`の引数は、小文字のa-zだけで構成されている必要があります。
すべてが文字'a'だけの値は使用できません。
無効な引数の場合、`NewVigenere`は`nil`を返します。
