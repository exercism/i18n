# 文字

`CHAR`は1文字を表し、シングルクォートで囲んで書きます。

```sather
   c : CHAR := 'M';
```

## 特殊な文字

直接入力できない文字もあり、そうした文字はバックスラッシュを使って書きます。

| 書き方 | 意味 |
| --- | --- |
| `'\n'` | 改行 |
| `'\t'` | タブ |
| `'\''` | シングルクォート |
| `'\\'` | バックスラッシュ |

## 文字への問い合わせ

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## 大文字と小文字

`.upper`と`.lower`は文字の大文字・小文字を変えるだけで、それ以外には何も手を加えません。そのため、まだ確認していない文字にそのまま使っても安全です。

## 数値

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int`と`.char`はちょうど逆の働きをします。番号について覚えておくと役に立つのは、`'a'`から`'z'`、`'A'`から`'Z'`、そして`'0'`から`'9'`がそれぞれ連続しているという点です。つまり、次のように書けます。

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## 折り返し

暗号のホイールは`z`を通り過ぎると`a`に戻ります。`%`はまさにそれを実現します。

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Satherの`%`は、右側が正の数であれば負の値を返しません。そのため、この式はホイールを前に回すときにも、逆に回すときにも使えます。

## 文字と文字列

`STR`はバイトが並んだもので、`CHAR`は1バイトです。英語のテキストでは1バイトが1文字にあたるので、`"Marlowe".size`は7、`"Marlowe"[0]`は`'M'`になります。アクセント記号の付いた文字や別の文字体系を含むテキストでは、1文字が複数のバイトを占めることがあり、そのどちらも当てはまりません。
