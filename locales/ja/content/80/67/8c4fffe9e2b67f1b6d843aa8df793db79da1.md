# はじめに

## Rの真偽値

真か偽かの値は、`logical`型で表します。
`logical`型がとる値は、`TRUE`と`FALSE`の2つだけです。

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 真偽値演算子

Rには5つの真偽値演算子がありますが、学習のこの段階では3つだけを扱います。
残りの2つは、ベクトルを扱うときに重要になります。ベクトルについては、後のいくつかのコンセプトで説明します。

`&&`は真偽値の「and」です。
`&&`の*両側*にある式がどちらも`TRUE`であれば、`TRUE`と評価されます。

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||`は真偽値の「or」です。
`||`の*どちらか*の側にある式が`TRUE`であれば、`TRUE`と評価されます。

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!`は真偽値の「not」です。
`TRUE`と`FALSE`の値を入れ替えます。

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

より長く複雑な式では、意図をはっきり伝えるために括弧（`()`）を使うのがよいでしょう。

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
