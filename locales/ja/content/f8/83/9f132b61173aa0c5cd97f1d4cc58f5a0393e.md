# はじめに

## ラベル付き引数

関数が多くの引数を取ると、どんな順番で渡せばよいかを覚えるのが難しいことがあります。読みやすさのために、Gleamでは引数に名前を付けてラベルを付けられます。

引数にラベルを付けるには、引数名の前にスペースで区切ってラベル名を指定します。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

ラベル付き引数を持つ関数を呼び出すときは、引数をどの順番で渡してもかまいません。次の`replace`の呼び出しは、どれも同じ意味になります。

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

ラベルはいつでも省略できます。関数にラベル付きの引数があっても、ラベルなしで呼び出すことができます。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
