# はじめに

いよいよ、C++の中心的なパラダイムのひとつであるオブジェクト指向プログラミング（OOP）に取り組むときがきました。OOPの中心にあるのは`classes`です。`classes`とは、関連する関数をひとそろい持ったユーザー定義のデータ型のことです。まずは基本から始め、より進んだトピックはシラバスのツリーをさらに下った先で扱います。

## メンバー

クラスは**メンバー変数**と**メンバー関数**を持つことができます。これらには**メンバー選択**演算子`.`でアクセスします。`classes`の外にある変数と同じように、メンバー変数は宣言時に値を代入して初期化しておくのが望ましいです。この値は、そのクラスから新しく作られるオブジェクトのデフォルト値になります。

## カプセル化と情報隠蔽

クラスには、メンバーへのアクセスを制限する仕組みがあります。基本となるのは`private`と`public`の2つです。`private`なメンバーはクラスの外からアクセスできません。`public`なメンバーは自由に呼び出せます。すべてのメンバーはデフォルトで`private`で、クラスの外から使えるようにするには明示的に指定する必要があります。

## 基本的な例

新しい`class`の定義は次の例のとおりです。定義のあとにある`;`に注目してください。

```cpp
class Wizard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

クラスの内側からは、すべての変数にアクセスできます。`cast_spell`関数の中の`damage`を見てみましょう。クラスの外からは`private`なメンバーを読み取ることも変更することもできません。

```cpp
Wizard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## コンストラクター

コンストラクターを使うと、オブジェクトの生成時にメンバー変数へ値を代入できます。名前は`class`と同じで、戻り値の型はありません。クラスは複数のコンストラクターを持てます。すべての変数をいつも設定する必要がない場合に便利です。

```cpp
class Wizard {
  public:
    Wizard(std::string new_name) {
      name = new_name;
    }
    Wizard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizard el{"Eleven"};       // deals  5 damage
Wizard vecna{"Vecna", 50}; // deals 50 damage
```

コンストラクターは奥が深く、多くのニュアンスがあります。`class`に対して`constructor`を明示的に定義しない場合、そのときに限り、コンパイラーがその役目を引き受けてくれます。これは上の最初の例で起きていました。_silverhand_オブジェクトは、引数を渡さずにデフォルトコンストラクターを呼び出すことで作られます。すべての変数は、クラスの定義に書かれた値に設定されます。もしその定義で値を何も与えていなければ、変数は未初期化のままになり、意図しない結果を招くかもしれません。

## 構造体

構造体は、この言語の原点であるCに由来し、C++そのものと同じくらい古くからあります。構造体は、ひとつ重要な例外を除けば、`classes`と実質的に同じものです。`class`では、デフォルトですべてが`private`です。これに対して構造体は、そう定義しない限り`public`です。慣習として、`struct`キーワードは**データだけの構造体**によく使われます。`class`キーワードは、特定の性質を保証する必要があるオブジェクトに好んで使われます。そのような不変条件の例として、`Wizard`という`class`の`damage`が負にならないことが挙げられます。`damage`変数は非公開で、damageを変更する関数はどれも、この不変条件が保たれるようにするはずです。
