# 説明

友人のLi Meiは、おいしいミックスジュースを売るジュースバーを営んでいます。あなたは彼女の店の常連で、友人の仕事をもっと楽にしてあげられることに気づきました。そこで、プログラミングのスキルを活かしてLi Meiの仕事を手伝うことにします。

## 1. ジュース1杯を作るのにかかる時間を求める

Li Meiは、お客さんが注文したメニューのジュースを待つ時間を、あらかじめ伝えるのが好きです。ただし、ジュースを混ぜるのにかかる時間は種類によって変わるため、正確な数字を覚えておくのは大変です。

| ID  | ドリンク                     | 時間 |
| --- | --------------------------- | ---- |
| 1   | ピュア・ストロベリー・ジョイ   | 1    |
| 2   | エナジャイザー               | 3    |
| 3   | グリーン・ガーデン           | 3    |
| 4   | トロピカル・アイランド        | 4    |
| 5   | オール・オア・ナッシング      | 5    |
| 6   | フィール・グッド             | 4    |
| 7   | 今日のおすすめ               | 7    |
| 8   | お客様のチョイス             | 10   |

ジュースのIDを32ビットの数値として受け取り、そのジュースを作るのにかかる時間も32ビットの数値として返す関数`time_to_make_juice`を書きましょう。

```c
time_to_make_juice(2);
// => 3
```

## 2. 注文されたすべてのジュースを作るのにかかる時間を求める

Li Meiは定期的に材料を補充する必要があるので、今ある注文をすべて準備するのにどれだけ時間がかかるかを前もって知っておきたいと思っています。

友人を助けるために、注文された各ジュースのIDの配列と、配列内のジュースの数を引数に取る関数`time_to_prepare`を書きましょう。この関数は、配列内のすべてのドリンクを準備するのにかかる合計時間を返します。

各ID、配列内のIDの数、戻り値はすべて32ビットの数値とみなしてかまいません。結果は常に32ビットの数値に収まります。

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. ライムのくし切りを補充する

Li Meiが作るドリンクの多くには、材料として、あるいは飾りとして、ライムのくし切りが使われています。そのため、朝シフトを始めるときには、これから始まる一日分のライムのくし切りが入った容器をいっぱいにしておく必要があります。

Li Meiが切る必要のあるライムのくし切りの数、手元にある丸ごとのライムの在庫を表す配列、その配列内のライムの数を引数に取る関数`limes_to_cut`を実装しましょう。

配列内では、それぞれのライムがその大きさを表す文字で表現されます。ライムの大きさによって、切り出せるくし切りの数は変わります。

| 大きさ | くし切りの数 |
| ------ | ----------- |
| 'S'    | 6           |
| 'M'    | 8           |
| 'L'    | 10          |

~~~~exercism/note
文字は8ビットの数値であり、他の8ビットの数値と同じように扱えます。

| 文字 | 値  |
| ---- | --- |
| 'S'  | 83  |
| 'M'  | 77  |
| 'L'  | 76  |

また、命令の中で直接使うこともでき、その値と等価です。

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

Li Meiは、配列に現れる順番で、最初の要素からライムを切っていきます。必要な数のくし切りに達するか、ライムがなくなるまで切り続けます。

Li Meiは、何個のライムを切る必要があるかを前もって知りたいと思っています。

必要なくし切りの数、配列内のライムの数、戻り値はすべて32ビットの数値とみなしてかまいません。結果は常に32ビットの数値に収まります。

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. シフトを終える

Li Meiはいつも15時まで働きます。その後は従業員のDmitryが引き継ぎます。Li Meiのシフトが終わる時点で、注文済みだがまだ準備できていないドリンクが残っていることがよくあります。そうした残りのジュースはDmitryが準備します。

引き継ぎをスムーズにするために、次のものを引数に取る関数`remaining_orders`を実装しましょう。

- Li Meiのシフトに残っている分数。
- 注文済みだがまだ準備されていない各ジュースのIDの配列。

この関数は、Li Meiが勤務時間の終わりまでに準備した注文の数を返します。

シフトに残っている時間は常に0より大きくなります。準備するジュースの配列が空になることはなく、シフトは必ず配列の最後に達する前に終わります。さらに、注文は配列に現れる順番で準備されます。Li Meiはあるジュースを混ぜ始めたら、少し長く働くことになっても必ず最後まで作り切ります。

残りの分数、配列内の各ID、戻り値はすべて32ビットの数値とみなしてかまいません。結果は常に32ビットの数値に収まります。

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
