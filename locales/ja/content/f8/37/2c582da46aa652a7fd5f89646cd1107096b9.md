# Luhnの概念

Luhnは、文字列と数値のチェックを組み合わせた検証アルゴリズムです。Rustの解答では、関数型のアプローチが好まれます。

## 一般

### プリミティブ

- `&str`と`char`
  - 与えられた入力の一部を正しく除外したり含めたりするには、個々の`char`と`&str`の違いを理解する必要があります。
- 整数
  - 必要な数値検証を行うには、整数の理解が重要です。
- 真偽値
  - 同一性の判定と最終的な比較に不可欠です。

### イテレーターの機能

- チェーン
  - ここでは、問題を順序立てて解くために、イテレーターのチェーンを理解することが重要です。
- `map`、`filter`、ターボフィッシュ、場合によっては`fold`
  - `map`と`filter`を組み合わせることで、このような検証問題の基礎となる設計パターンが得られます。`fold`を使った解答は、さらに簡潔になるという利点もあります。
  - 一部の解答では、チェーンされた式からどの型を作成しているのかをRustに伝えるために、ターボフィッシュが必要です。

## 解答例1

yorkの[解答](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## 解答例2

模範解答

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
