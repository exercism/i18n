# 概要

## 関数

Gleamでは、関数は`pub fn`構文で定義します。

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

この関数は2つの引数を受け取り、どちらも`Int`型です。そして、`Int`型の値を返します。Gleamには`return`キーワードはありません。関数内の最後の式の値が、常に_暗黙的に戻り値として返されます_。

引数の型注釈と戻り値の型は省略できます。また、Gleamは常にコード全体の型チェックを行います。通常、Gleamプログラマーは明確さのために関数に型注釈を付けますが、必要なければ省略してもかまいません。

```gleam
pub fn add(x, y) {
  x + y
}
```

関数は`function_name(argument1, argument2)`という構文で呼び出せます。

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## 変数

Gleamでは、変数は`let name = expression`という構文で定義します。

```gleam
pub fn main() {
  let count = 1
}
```

変数は型注釈を付けて宣言できます。関数の引数と同様、型注釈は省略可能ですが、ほとんどのGleamプログラマーは変数の型注釈を省略します。

```gleam
pub fn main() {
  let count: Int = 1
}
```

## 文字列リテラル

Gleamでは、文字列は二重引用符で書きます。

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## コードコメント

コメントを使うと、ソースコードを読む他のエンジニアにメモを残せます。Gleamのコメントは、`//`で始まる1行のコメントです。

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
