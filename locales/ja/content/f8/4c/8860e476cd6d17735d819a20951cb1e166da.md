# 概要

## Juliaの真偽値

真と偽の値は、`Bool`型で表されます。
値は`true`と`false`の2つだけです。

```julia-repl
julia> true
true

julia> false
false

julia> typeof(true)
Bool
```

ほかのいくつかの言語とは対照的に、Juliaには「truthiness」という考え方が意図的にありません。`true`か`false`に評価される式だけが`Bool`として扱われます。

具体的には、空の配列や文字列が`false`と解釈されることは*ありません*。
空の値を特別に扱いたいときは、`isempty()`のようなチェックが必要です。

## 真偽値の演算子

Juliaには3つの[真偽値演算子][boolean-operators]があります。

`&&`は真偽値の「and」です。
`&&`の*両側*の式がどちらも`true`のとき、`true`に評価されます。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`は真偽値の「or」です。
`||`の*どちらか*の側の式が`true`なら、`true`に評価されます。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`は真偽値の「not」です。
`true`と`false`の値を入れ替えます（反転させます）。

```julia-repl
julia> !true
false

julia> !false
true
```

似た演算子は、ほかの多くの言語を使ったことがある人には概念的になじみがあるでしょう。ただし、正確な書き方は言語によって異なることがあります。

## 演算子の優先順位

より複雑な式では、`&&`のほうが`||`より[優先順位][operator-precedence]が少し高いことを知っておくと役に立ちます*（算術式で`*`が`+`より先に適用されるのと同じです）*。

ただし、これに頼ると紛らわしく、間違いのもとになりかねません。
はっきりさせるために、括弧（`()`）を使って意図を明確にしましょう。

## 短絡評価

式`true || x`は`x`の値に依存するのでしょうか？　それとも、コンパイラーは`x`を無視できるのでしょうか？

Juliaは真偽値式を左から右へ評価し、結果が明確になった時点で止まります。

たとえば、`true || x`は`x`に関係なく`true`でなければならないので、`x`は評価されません。
同じように、`false && y`は`false`なので、`y`を評価する必要はありません。

逆に、`true && x`が`true`になるのは、`x`が`true`の*ときだけ*です。そのため、`x`を評価する必要があります。

同様に、演算子をいくつかつなげてみましょう。

```julia-repl
julia> true && false && something_else
false
```

`true && false`は必ず`false`になるので、`something_else`は重要ではなく、コンパイラーはそれを無視します。

この場合、`something_else`という変数は存在しませんでしたが、この文脈で書いてもエラーにはなりませんでした*（疑わしい場合はREPLで試してみてください）*。

このような短絡評価は、実行時の問題やエッジケースをとらえる近道として、Juliaプログラマーによく使われます。

```julia
all_ok || do_something()

is_problem && do_something_else()
```

たとえば、`do_something`は`all_ok`が`false`のときに`return`で関数を早く抜けることであったり、処理を続ける前に変数へ既定値を代入することであったりします。

これは真偽値の構文を少し乱用した使い方ですが、とても便利なことがあります。

## `Bool`の内部のしくみ

`Bool`が*算術*式の中に現れると、`true`は`1`、`false`は`0`と解釈されます。これは、それらが内部的にどのように格納されているかを反映しています。

低レベルな言語（Cなど）に慣れている方も、これを頻繁に使うのは*できれば*避けてください。
コードの読みやすさが下がり、デバッグが難しくなります。

数値を、いくつの要素が`true`かをすばやく数える方法として使っているのを見かけることもあるでしょう。

```julia-repl
julia> true + false + true
2
```
