# はじめに

JavaScriptは動的言語で、オブジェクト指向、命令型、宣言型（たとえば関数型プログラミング）といったスタイルをサポートしています。

## 変数

JavaScriptで名前に値を割り当てるには、主にいくつかの方法があります。変数を使う方法と、定数を使う方法です。
Exercismでは、変数は常に[camelCase][wiki-camel-case]で書き、定数は[SCREAMING_SNAKE_CASE][wiki-snake-case]で書きます。
従うべき公式のガイドがあるわけではなく、企業や組織によってスタイルガイドはそれぞれ異なります。
*変数の書き方は、好きなようにしてかまいません*。
演習で用意されているとおりに書くことの利点は、ウェブインターフェースやほとんどのIDEで変数と定数が区別してハイライトされることです。

JavaScriptでは、[`const`][mdn-const]、[`let`][mdn-let]、[`var`][mdn-var]のキーワードを使って変数を定義できます。

`let`や`var`を使うと、その変数の有効期間中に別の値を参照させることができます。
たとえば`myFirstVariable`は、代入演算子`=`を使って何度も定義し直すことができます。

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let`や`var`とは対照的に、`const`で定義した変数に代入できるのは一度だけです。
JavaScriptでは、これを使って定数を定義します。

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## 関数宣言

JavaScriptでは、機能のまとまりは*関数*にカプセル化されます。互いに関連する関数は、通常、同じファイルにまとめます。
関数には仮引数があり（そのため引数を受け取ることができます）、`return`キーワードを使って値を*返す*ことができます。
関数は`()`の構文で呼び出します。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

この例では、関数名は`add`です。
2つの仮引数`num1`と`num2`を持っています。
そして、式`num1 + num2`の結果を値として返します。

次に、関数`add`を2つの引数`1`と`3`で*呼び出し*ます。
関数の結果、つまり戻り値は`4`です。

## 他のファイルから使えるようにする

`function`や定数、変数を*他のファイル*から使えるようにするには、`export`キーワードを使って[エクスポート][mdn-export]する必要があります。
そうすると、別のファイルから`import`キーワードを使ってこれらを[インポート][mdn-import]できます。
これはモジュールシステムとも呼ばれます。

よい例が、すべてのテストの仕組みです。
各演習には、少なくとも1つのファイルがあります。たとえば`lasagna.js`で、これに*実装*が含まれています。
*実装*はそのファイルから`export`され、別のファイルからインポートできるようになります。
さらに、*テスト*が書かれた別のファイルが少なくとも1つあります。たとえば`lasagna.spec.js`です。
このファイルは、実装をテストするために、公開されている（つまり`export`された）ものを`import`します。

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
