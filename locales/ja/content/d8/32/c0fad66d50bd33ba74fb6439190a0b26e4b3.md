# 説明

この演習では、いろいろなタイプのファイターが互いに戦うロールプレイングゲームをプレイします。
ゲームには、ファイターのタイプごとに異なるルールがあります。
ここでは、WizardとWarriorという2つのタイプに注目します。

Warriorのルールは次のとおりです。

- Warriorは決して脆弱になりません。
- 攻撃する相手が脆弱でなければ、Warriorは`6`ポイントのダメージを与えます。
- 攻撃する相手が脆弱であれば、Warriorは`10`ポイントのダメージを与えます。

Wizardのルールは次のとおりです。

- Wizardは事前に呪文を準備できます。
- 事前に呪文を準備していないかぎり、Wizardは脆弱になります。
- 事前に呪文を準備していれば、Wizardは`12`ポイントのダメージを与えます。
- 事前に呪文を準備していなければ、Wizardは`3`ポイントのダメージを与えます。

## 1. Warriorクラスを作成する

`Warrior`という新しいクラスを作成します。
このクラスは、既存の`Fighter`クラスを継承するようにします。

## 2. Warriorを説明する

`Warrior`クラスを更新して、`toString()`メソッドがどんなタイプのファイターなのかを説明するようにします。
このメソッドは文字列`"Fighter is a Warrior"`を返すようにします。

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Warriorを脆弱でなくする

`Warrior`クラスを更新して、`isVulnerable()`メソッドが常に`false`を返すようにします。

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Warriorのダメージポイントを計算する

`Warrior`クラスを更新して、`getDamagePoints(Fighter)`メソッドが、上記のルールにしたがってWarriorが与えるダメージを計算するようにします。

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Wizardクラスを作成する

`Wizard`という新しいクラスをもう1つ作成します。
このクラスも、既存の`Fighter`クラスを継承するようにします。

## 6. Wizardを説明する

`Wizard`クラスを更新して、`toString()`メソッドがどんなタイプのファイターなのかを説明するようにします。
このメソッドは文字列`"Fighter is a Wizard"`を返すようにします。

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Wizardが呪文を準備できるようにし、準備していないときは脆弱にする

`Wizard`クラスを更新して、`prepareSpell()`というメソッドを追加します。
このクラスは、このメソッドが呼び出されたことを覚えておき、呪文が準備されているときだけ`isVulnerable()`メソッドが`false`を返すようにします。

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Wizardのダメージポイントを計算する

`Wizard`クラスを更新して、`getDamagePoints(Fighter)`メソッドが、上記のルールにしたがってWizardが与えるダメージを計算するようにします。

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
