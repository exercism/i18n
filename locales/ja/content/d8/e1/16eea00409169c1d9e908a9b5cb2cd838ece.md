# 手順

ネットワーク認証システムの作業を、もう少し進めることになりました。

開発中は管理者の識別情報をシステムにハードコードしていますが、それに加えて、上層部はシニアエンジニアにも同じ扱いをするよう求めています。

## 1. システム管理者の情報をシステムにハードコードして保存し、呼び出し元から使えるようにする

管理者の情報は次のとおりです。

| Email        | Eye Color | Philtrum Width | Name     | Address 1 | Address 2 |
| ------------ | --------- | -------------- | -------- | --------- | --------- |
| admin@ex.ism | green     | 0.9            | Chanakya | Mumbai    | India     |

`Authenticator.Admin`プロパティを実装して、システム管理者の識別情報を返すようにしましょう。名前と住所の各部分は、それぞれ`NameAndAddress`リストの別々の要素に入れます。

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. エンジニアたちの情報をシステムにハードコードして保存し、辞書形式で使えるようにする

エンジニアたちの情報は次のとおりです。

| Email         | Eye Color | Philtrum Width | Name     | Address 1 | Address 2 |
| ------------- | --------- | -------------- | -------- | --------- | --------- |
| bert@ex.ism   | blue      | 0.8            | Bertrand | Paris     | France    |
| anders@ex.ism | brown     | 0.85           | Anders   | Redmond   | USA       |

`Authenticator.Developers`プロパティを実装して、エンジニアたちの識別情報を返すようにしましょう。辞書のキーにはエンジニアの名前を使います。

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
