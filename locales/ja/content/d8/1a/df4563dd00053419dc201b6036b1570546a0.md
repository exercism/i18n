# はじめに

Common Lispには、いくつかの条件式が用意されています。主な違いは、対応できる分岐の数です。

- `when`と`unless`では、分岐を1つだけ書けます。

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

判定式のあとには、複数の式を並べることもできます。

- `if`は、定番のif-then-elseの構文を提供します。

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

then節とelse節には、それぞれ1つの式しか書けないことに注意してください。

- `cond`を使うと、`if`式を入れ子にすることなく、複数の分岐を書けます。

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

判定式のあとには、式をいくつでも書けることに注意してください。

- `case`は、定番の「switch」スタイルの構文を提供します。1つの値を、いくつかの分岐と照合します。

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

`cond`と同じく、判定式のあとには式をいくつでも書けることに注意してください。
