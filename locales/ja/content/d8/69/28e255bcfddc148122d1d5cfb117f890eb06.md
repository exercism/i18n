# 説明

ニュージーランドを歩きながら、コンパスで方位を測っています。方位は度数で表す整数で、値です。20度回っても、測った方位が変わるのではなく、別の方位が得られます。

`immutable class BEARING`を書きます。スタブには、クラスのヘッダーとその属性がすでに用意されています。

## 1. 方位を測る

`create`は度数を受け取り、方位を返します。度数は0から359までで、その範囲を外れた値は一周して戻ってきます。370は10、-10は350です。

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. 回す

`turned`は回す度数を受け取り、新しい方位を返します。負の数を渡すと逆方向に回ります。`turned`を呼び出したもとの方位は変わりません。

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. 比較する

`is_eq`は別の方位を受け取り、それらが同じかどうかを返します。これが定義されると、方位に対して`=`が使えるようになります。

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. 方位点に名前を付ける

`point`は、その方位が最も近い方位点を、`"N"`、`"NE"`、`"E"`、`"SE"`、`"S"`、`"SW"`、`"W"`、`"NW"`のいずれかとして返します。

各方位点は45度分を覆い、その正確な方位を中心としています。北は337.5から0を経て22.5まで、北東は22.5から67.5まで、といった具合です。ここでは方位は整数なので、方位22は`"N"`、23は`"NE"`になります。

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. 書き出す

`str`は度数と方位点を、`"90 degrees (E)"`のように返します。

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
