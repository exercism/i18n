# インストール

## Ubuntu（およびその他のほとんどのDebian系ディストリビューション）

ローカルでコードをビルドするには、gccとmakeが必要です。これらは次のコマンドでインストールできます。

```shell
sudo apt install gcc make
```

ARM64のハードウェアで実行していない場合は、次のコマンドで[QEMU][]エミュレーターとGCC ARM64クロスツールチェーンをインストールしてください。

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Debian系のディストリビューションで[Windows Subsystem for Linux][]を使い、上記のUbuntuの手順に従ってください。あるいは、Linuxの仮想マシンをセットアップする方法もあります。

## macOS

適切な仮想化ソリューション（例えば[Lima][]）を使えば、Linuxの仮想マシンを起動できます。

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
