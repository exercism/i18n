# Introduction

複数の要素をひとまとまりにし、そのまとまりを1つの単位として扱えると、便利なことがよくあります。Cairoでは、そのようなまとまりを構造体と呼び、まとまりの中の各要素を構造体のフィールドと呼びます。構造体は利用できるフィールドの全体を定義するもので、構造体の具体的な1つの実体はインスタンスと呼ばれます。

さらに、構造体にはメソッドを定義でき、メソッドはフィールドにアクセスできます。その場合、構造体自身は`self`と呼ばれます。メソッドが`ref self: SomeStruct`を使うと、フィールドを変更、つまり可変にできます。メソッドが`self: SomeStruct`や`self: @SomeStruct`を使う場合、フィールドは変更できません。つまり不変です。可変性を制御することで、借用チェッカーは、Cairoでは並行処理に関するある種のバグがそもそも発生しないようにできます。

この演習では、構造体に2種類のメソッドを実装します。1つは一般にゲッターと呼ばれるものです。ゲッターは、構造体のフィールドを外部に公開しますが、ほかの誰かがその値を変更することはできません。

もう1つの種類のメソッドも実装します。一般にセッターと呼ばれるものです。セッターはフィールドの値を変更します。セッターはCairoではあまり一般的ではありません。フィールドを自由に変更できるなら、単にそれを公開するほうが一般的です。ただし、フィールドの更新に副作用を持たせたい場合には便利です。

構造体は`struct`キーワードを使って定義し、そのあとに、その構造体が表す型の名前を先頭を大文字にして書きます：

```rust
struct Item {}
```

次に、追加の型を構造体の_フィールド_として構造体の本体に記述します。各フィールドはそれぞれの型を持ちます：

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

トレイトは、ある型が実装できるメソッドのまとまりを定義します（ここでは構造体に注目しますが、トレイトは列挙型にも実装できます）。これらのメソッドは、そのトレイトを実装している型のインスタンスに対して呼び出せます。トレイトは`trait`キーワードで定義し、トレイトの中には、その型に実装してほしいメソッドのシグネチャを書きます。

```rust
trait ImplTrait {
    // Define the method signature
    fn new() -> Item;
}
```

最後に、メソッドは構造体に対して`impl`ブロックの中で定義でき、このブロックが定義したトレイトを実装します：

```rust
impl ItemImpl of ImplTrait {
    // initializes and returns a new instance of our Item struct
    fn new() -> Item {
        Item {}
    }
}
```
