# 説明

あなたは、過去7日間に庭に何羽の鳥が訪れたかを記録している、熱心なバードウォッチャーです。

庭に訪れた鳥の数を扱う、5つのタスクに取り組みます。

## 1. 先週の記録を確認する

鳥の記録はJSON形式で保存します。
「main」配列には、週ごとの記録の配列が入ります。
各週の記録は7つの整数からなる配列で、1日につき1つの数値が入ります。
新しい週は、いつもmain配列の末尾に追加します。
先週の記録を返すフィルターを実装しましょう。

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. 昨日訪れた鳥の数を確認する

昨日庭に訪れた鳥の数を返すフィルターを実装しましょう。
鳥の記録は日付順に並んでいて、最初の要素が最も古い日の数、最後の要素が今日の数です。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. 訪れた鳥の合計数を計算する

今週庭に訪れた鳥の合計数を返すフィルターを実装しましょう。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. 忙しい日の数を計算する

日によっては、ほかの日より忙しいこともあります。
忙しい日とは、庭に5羽以上の鳥が訪れた日のことです。
今週の忙しい日の数を返すフィルターを実装しましょう。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. 鳥が1羽も訪れなかった日があるか確認する

今週、庭に鳥が1羽も訪れなかった日があれば`true`を、そうでなければ`false`を返すフィルターを実装しましょう。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
