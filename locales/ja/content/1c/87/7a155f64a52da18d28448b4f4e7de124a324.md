# 指示の補足

## ボーナス

`uüu`という文字列で関数をテストして、何が起こるか見てみましょう。
この文字列を正しく逆順にする関数を書いてみましょう。
ヒント：書記素クラスタ

ボーナスのテストを実行するには、最後のテストから無視フラグ（`#[ignore]`）を外して、次のコマンドでテストを実行します：

```bash
cargo test --features grapheme
```

ボーナスの課題には、外部ライブラリ（Rustの用語では`crate`）を使う必要があります。
そうしたライブラリを探すのにうってつけなのが、crateの公式リポジトリである[crates.io](https://crates.io/)です。
テストランナーがサポートしているcrateは限られている点に注意してください。
一覧は、[このファイル](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml)の`[dependencies]`セクションにあります。

プロジェクトで外部crateを使う方法については、[ドキュメントを確認してください](https://doc.rust-lang.org/cargo/guide/dependencies.html)。
