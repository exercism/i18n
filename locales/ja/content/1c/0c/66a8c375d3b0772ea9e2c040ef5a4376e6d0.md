# はじめに

Factorでは、ワードを次々と書いていくだけで組み合わせることができます。書いた順番が、そのままワードのつながり方になるのです。（プログラマーはこれを*関数合成*と呼びます。）ワードの本体も、それ自体がワードの並びです。それぞれがスタックから値を受け取り、結果を積みます。次のワードは、前のワードが終わったところから続けます。つまり、次のように定義すると

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

これはすでに、`cleanupname`、`first`、`1string`の合成そのものになっています。

この演習では、**クォーテーション**も紹介します。クォーテーションとは、その場で実行するのではなく、値として保存しておいて後から実行できるコードのかたまりです。

## クォーテーション

クォーテーションとは、角括弧で囲んだコードのかたまりです。書いた時点では実行されず、値としてスタックに置かれます。

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call`はクォーテーションを実行します。

```factor
3 [ 2 * ] call .    ! => 6
```

コードをデータとして渡したいときにクォーテーションを書きます。後から実行してもらうためだったり、*コンビネーター*に渡すためだったりします。コンビネーターとは、クォーテーションを入力として受け取るワードのことです。

## `compose`

`compose ( quot1 quot2 -- combined )`は、2つのクォーテーションを1つにつなぎ、書いた順番に実行します。

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

`:`と`;`で小さなワードを定義したほうが、たいてい`compose`より読みやすくなります。ただ、クォーテーションをその場で組み立てたいときには`compose`が便利です。部品がまだクォーテーションになっていない場合は、[`quotations`][quotations]の`>quotation ( seq -- quot )`を使うと、値やワードへの参照からなる並びを、呼び出せるクォーテーションに変えられます。

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## 1つのクォーテーションを2つの入力に適用する

`bi@ ( x y quot -- ... )`は、`x`に対してクォーテーションを実行し、次に`y`に対しても実行して、両方の結果をスタックに残します。

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

この演習の`couple`タスクは2つの名前を受け取ります。それぞれに`initial`を適用するには、`bi@`が自然な方法です。

## いくつかの文字列ワード

この演習では、小さな文字列ワードをいくつか使います。`sequences`、`ascii`、`strings`という3つのボキャブラリから取り出したものです。

- `replace ( seq old new -- new-seq )`（`splitting`内）は、部分文字列の置換です。
- `[ blank? ] trim`（`trim`は`sequences`、`blank?`は`ascii`）は、先頭と末尾の空白を取り除きます。
- `1string ( char -- str )`（`strings`内）は、1つの文字を文字列として包みます。
- `>upper ( str -- upper )`（`ascii`内）は、文字列を大文字にします。
- `append ( s1 s2 -- s )`（`sequences`内）は、2つの文字列を連結します。
- `prepend ( s1 s2 -- s )`（`sequences`内）は、`s2`の次に`s1`を連結します（`append`の入力を逆の順番にしたものです）。
- `glue ( s1 s2 sep -- s )`（`sequences`内）は、2つの文字列を、間に区切り文字をはさんで連結します。
- `surround ( seq pre post -- new )`（`sequences`内）は、文字列を接頭辞と接尾辞で包みます。

Unicode文字は、文字列の中で`\u{XXXX}`と書けます。ここで`XXXX`は16進数のコードポイントです。この演習には、ハートの`\u{2764}`（❤）が登場します。

## 書式付き出力

`append`、`glue`、`surround`だけでは表現しきれないときは、[`formatting`][formatting]が提供するprintf形式の`sprintf`を使います。

```
sprintf ( inputs... format-string -- str )
```

`%s`は文字列を、`%d`は整数を、`%f`は小数を埋め込みます。幅、精度、パディングの修飾子は省略可能で、`%`と型を表す文字の間に書きます。

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

数値と文字列の間で相互変換したいときは、[`math.parser`][math.parser]に`number>string`と`string>number`があります。

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
