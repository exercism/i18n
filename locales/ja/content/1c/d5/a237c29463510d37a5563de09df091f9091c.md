# 概要

ハードウェアのレベルまで下りていくと、トランジスターはオンかオフのどちらかしかありません。この2つの状態を、伝統的に`1`と`0`で表します。これが[`binary digits`][binary-digits]で、[`bits`][bits]と略されます。`bits`と`binary`についての知識は、低水準言語で働くシステムプログラマーにとって特に重要です。

しかし、コンピューティングの歴史のほとんどにおいて、プログラミングの優先事項は、この2進法の現実を_抽象化して隠す_、より洗練された方法を見つけることでした。Python（および他にも多くの[高水準プログラミング言語][high-level-language]）では、`int`、`float`、`string`などの定義された_型_を扱い、音声や動画のフォーマットにまで及びます。すべてを（最終的には）ビットに変換する処理は、Pythonの内部に任せています。

とはいえ、[ビット演算子][python-bitwise-operators]と[ビット演算][python-bitwise-operations]を使うことで、Pythonのような高水準言語であっても、速度とメモリ効率の面で大きな利点が得られることがあります。


## 2進数の入力と表示

当然のことながら、Pythonはユーザーと10進数でやり取りしますが、プログラマーはこの既定の動作を上書きできます。実際、Pythonは`binary`、`hexadecimal`、`octal`形式の`int`をそのまま受け入れ、それらの間で数学的な演算も問題なく行えます。詳しくは、[concept:python/binary-octal-hexadecimal]()のコンセプトを参照してください。

2進数は`0b`という接頭辞を付けて入力します。同じように、16進数には`0x`（_16進数は4ビットのまとまりを簡潔に表す方法です_）を、8進数には`oct`を使うことができます。

整数を2進数の文字列に変換する方法はいくつかあり、`0b`接頭辞を含むかどうか、また0で左詰めするかどうかが異なります。


```python
# Binary entry.
>>> 0b10111
23

# Converting an int display to binary string, with prefix.
>>> bin(23)  
'0b10111'

>>> number = 23

# Binary without prefix, padded to 8 digits.
>>> format(number, '08b')  
'00010111'

# Same format, but using an f-string.
>>> f"{number} in decimal is {number:08b} in binary and {number:x} in hex" 
'23 in decimal is 00010111 in binary and 17 in hex'
```


## [`Bitwise Logic`][python-bitwise-operations]

[concept:python/bools]()のコンセプトでは、真偽値（_`True`と`False`_）で使う_論理演算子_`and`、`or`、`not`について説明しました。ビットを扱うときも、同じ論理のルールが当てはまります。

ただし、論理演算子に対応するビット単位の演算子である`&`（_and_）、`|`（_or_）、`~`（_not_）、そして`^`（_[XOR][xor]_）は、2進表現の_各ビット_に対して適用され、`1`を`True`（「オン」）、`0`を`False`（「オフ」）として扱います。ビット単位の`&`を使った例を見ると、わかりやすいでしょう。


```python
>>> x = 0b01100110
>>> y = 0b00101010

>>> format(x & y, '08b')
'00100010'
```

入力した2つの数値の_**両方**_で`1`になっている位置だけが、出力でも`1`になります。

ビット単位の`&`は、アプリのユーザーが設定できる項目のように、`True`/`False`の値を詰め込んだ集合から個々のビットを取り出す方法としてよく使われます。これにより、個々のビットの値でプログラムのロジックを制御できます。


```python
>>> number = 0b0110
>>> number & 0b0001 > 0
False

>>> number & 0b0010 > 0
True
```


ビット単位の`|`（or）では、入力の_**どちらか**_に`1`があれば、出力に`1`が立ちます。


```python
>>> x = 0b01100110
>>> y = 0b00101010

>>> format(x | y, '08b')
'01101110'
```


ビット単位の排他的論理和（xor）を表す`^`演算子では、_**入力のどちらか一方にのみ**_`1`がある場合に`1`が立ちます。この記号は、[concept:python/sets]()のコンセプトで見覚えがあるかもしれません。そこでは`set`の_対称差_に使われ、これは[集合に適用したxor][symmetric-difference]と同じものです。xorの`^`が奇妙に思えるなら、これが暗号技術で[最もよく使われる演算][xor-cipher]であることを知っておくとよいでしょう。


```python
>>> x = 0b01100110
>>> y = 0b00101010

>>> format(x ^ y, '08b')
'01001100'
```


最後に、`~`演算子（_[チルダ][tilde]の文字_）があります。これはビット単位の`not`で、1つの入力を受け取り、_**すべてのビットを反転**_させます。期待した結果とは違うかもしれません。表現の中の`1`はそれぞれ`0`に変わり、その逆も同様です。詳しくは下のセクションを参照してください。


## 負の数と2進表現

10進表現では、数字の左に`+`または`-`の符号を付けて、正の数と負の数を区別します。しかし、この記号を2進のレベルで使うのはデジタル計算には効率が悪く、`+0`と`-0`が同じでないという問題も生じました。

現代のコンピューターは、`-`と`+`を使う代わりに、シリコンチップのレベルに至るまで、負の数の表現に[`two's complement`][twos-complement]を使っています。これは、すべてのビットを反転させ、左端のビット（「最上位ビット」、MSBとも呼ばれます）が`1`であれば、その数を_**負として解釈する**_という意味です。正の数では、MSBは`0`です。この表現には、ゼロの表し方が1つしかないという利点があり、プログラマーは`-0`と`+0`を管理する必要がありません。

この正負の数の表現方法は、Pythonにとってひとつの複雑さをもたらします。コア言語の内部には、`int32`や`int64`のような有限の整数という概念がないのです。「現代の」Pythonでは、`int`の大きさに制限はなく（_ハードウェアの容量によってのみ制限されます_）、負の数やビット反転した数は、正の数が無限に`0`を持つように、左側に（理論上）無限に`1`が並びます。

このため、`bitwise not`の役に立つ例を示すのは難しいです。

```python
>>> x = 0b01100110
>>> format(x, '08b')
'01100110'

# This is a negative binary (not twos-complement display).
>>> format(~x, '08b')
'-1100111'  

 # Decimal representation.
>>> x
102

# Using the Bitwise not, with an unintuitive result.
>>> ~x
-103
```

これは、固定長の整数を扱う言語で目にする`0b10011001`では**ありません**。

`~`演算子が期待どおりに機能するのは、_**符号なし**_のバイト型や整数型、または固定長の整数型だけです。これらの数値型は、[`NumPy`][numpy]、[`pandas`][pandas]、[`sympy`][sympy]などのサードパーティ製パッケージではサポートされていますが、コアPythonではサポートされていません。

実際には、Pythonプログラマーは`&`、`|`、`^`、そして後述するシフト演算子を、正の数に対してだけ使うことがよくあります。負の数に対するビット演算は、はるかに一般的ではありません。ひとつの手法は、負の値に[`2**32 (or 1 << 32)`][unsigned-int-python]を足して`int`を符号なしにするものですが、管理が難しくなります。もうひとつの戦略は、[`ctypes`][ctypes-module]モジュールでC言語スタイルの整数型を使うものですが、これも同じくらい扱いにくいです。


## [`Shift operators`][bitwise-shift-operators]

左シフト演算子`x << y`は、`x`のすべてのビットを`y`桁だけ左に移動させ、新しくできた隙間を0で埋めます。これは算術的には、数値を`(2**y)`倍するのと同じであることに注意してください。

右シフト演算子`x >> y`はその逆を行います。これは算術的には、整数除算`x // (2**y)`と同じです。

Pythonで負の数をシフトするときは、負の数とその落とし穴についての前のセクションを思い出してください。


```python
>>> x = 8
>>> format(x, '08b')
'00001000'

# A left bit shift. 
>>> x << 2  
32

>>> format(x << 2, '08b')
'00100000'

# A right bit shift. 
>>> format(x >> 2, '08b')
'00000010'
```
