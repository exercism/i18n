# 概要

[Nil][nil-dictionary]は、英語で「何もない」「ゼロ」という意味の言葉です。Elixirでは、`nil`は値の_不在_を表す特別な値です。

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil`はアトムですが、通常は`:nil`ではなく`nil`と書きます。真偽値の`true`と`false`もアトムです。

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

変数の値が`nil`かどうかは、[`==`][kernel-equal]やパターンマッチング、[`is_nil`ガード][kernel-is-nil]を使えば確認できます。

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
