# 指示の補足

## 待って、そんなの無理です！

Rocで、これらの配列の操作を組み込み関数を_一切_使わずに実装するのは、ほぼ不可能です。配列に要素を追加したり、先頭に要素を差し込んだりする方法が必要になるからです。
Haskellの`:`やPythonの`+=`のような演算子を使える言語もありますが、Rocでは[`List`の関数](https://www.roc-lang.org/builtins/main/#Builtin.List)を使う必要があります。

ですから、この演習では`List.append`を使ってもかまいません（ただし、それ以外の組み込み関数は使わないようにしましょう）。

多くの関数型プログラミング言語では、連結リストが主要なコレクション型として使われています。
連結リストでは、要素を先頭に追加したり、先頭の要素を取り出したりするのが効率的なので、そうした言語では配列の操作を`List.prepend`で実装することになります。
一方Rocでは、`List`は配列（連続したバイトのまとまり）です。
配列は、インデックスで要素に効率よくアクセスできる、新しい要素を効率よく追加できるなど、連結リストとは異なる性質を持っています。
そのため、Rocでは`List.append`をよく使い、`List.prepend`はほとんど使いません。

## 名前について

Rocでは、一般的な指示に挙げられているものとは少し違う名前を使います。

- `append`の代わりに`concat`
- `concatenate`の代わりに`join`
- `length`の代わりに`len`
- `foldl`の代わりに`fold`
- `foldr`の代わりに`fold_rev`

ただし、次の関数名はRocでも標準的です。
- `filter`
- `map`
- `reverse`

## ヒント

次のように書いてみましょう。

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

または

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
