# 指示の補足

## 実装

Cairoには浮動小数点数をネイティブにサポートする仕組みがないため、小数の値は整数を使って表現します。

この方法は、ブロックチェーン開発において計算の精度を保つために欠かせません。

この演習では、公転周期をマイクロ秒に変換することで**固定小数点演算**を使います。

たとえば、水星の公転周期`0.2408467`地球年は、`1,000,000`を掛けることで`240,846,700`マイクロ秒になります。

小数の精度を扱うために、テストケースでは、求められる年齢が**小数点以下2桁**で、整数として表されることを前提としています。

つまり、`31.69`年という年齢は、コードの中では`3169`として保存されます。

これを実現するには、割り算を行う前に100を掛けます。

例を見てみましょう。

```rust
let mercury_orbital_period = 240_846_700; // in microseconds
let age_microseconds = age_seconds * 1_000_000;
// multiplying with 100 to retain 2 decimal places
age_microseconds * 100 / mercury_orbital_period
```

この方法を使えば、必要な小数点以下2桁の精度を保ちながら、小数の値を正確に整数として表せます。これはテストに合格するために欠かせません。
