# 説明

日本人の友だち、クロコは、世界中にファンのいるストリーマーです。
クロコの配信スケジュールはかなり複雑で、配信は毎日違う時間に始まるように見えます。

彼は、視聴者それぞれの現地のタイムゾーンでスケジュールを表示する小さなアプリ、クロコの時計の開発を手伝ってほしいと頼んできました。
さらに追加の要望があります。アプリは時刻を、日本語とアメリカ英語の2つの言語で表示できる必要があるのです。

## 1. 日付を表示する

（有効な）現地の日付を表示する関数 `showLocalDate : Locale -> Int -> Month -> Int -> String` を定義しましょう。

`US`ロケールでは、書式は`Month/Day/Year`で、先頭にゼロは付けません。

`JP`ロケールでは、書式は`Year年Month月Day日`で、こちらも先頭にゼロは付けません。

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. 時刻を表示する

（有効な）現地の時刻を表示する関数 `showLocalTime : Locale -> Int -> Int -> String` を定義しましょう。

`US`ロケールでは、時は12時間表記で表示し、後ろに"PM"または"AM"を付けます。分は先頭にゼロを付けて表示します。

`JP`ロケールでは、時は24時間表記で「時」の前に、分は先頭のゼロなしで「分」の前に表示します。

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. タイムゾーンに対応する

特定のロケールで、タイムゾーンを基準とした日付と時刻を表示する関数 `showDateTime : Locale -> Zone -> Posix -> String` を定義しましょう。

最終的な結果の表示には`showLocalDate`と`showLocalTime`を使いましょう。

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
