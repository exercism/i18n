# 指示

この演習では、国際電話の国番号をハッシュマップで管理するコードを書きます。

マップのキーには整数（国番号）を、値には文字列（国名）を使います。

国番号を扱うタスクが11個あります。

## 1. 事前入力済みのハッシュマップを作成する

次の3つの国番号を含む、事前入力済みのハッシュマップがあります。コード1の"United States of America"、コード55の"Brazil"、コード91の"India"です。この事前入力済みのハッシュマップを格納する`countries`変数を定義してください。

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. マップに国を追加する

タスク1で作成したマップに、国番号44の"United Kingdom"を追加してください。

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. 国番号に対応する国名を取得する

国番号55の国名を取得してください。

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. 国名を更新する

"United States of America"の名前を"Les États-Unis"に変更してください。

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. マップに国が存在するか確認する

タスク1で作成したマップにBrazilのレコードが存在するか確認してください。

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. マップに存在しない国の名前を更新しようとする

マップに存在しない番号（たとえば999）の国の名前を変更してみてください。この場合、マップは変更されないはずです。

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. マップから国を削除する

マップからIndiaを削除してください。

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. 最も長い名前の国を見つける

マップの値を処理して、最も長い名前の国を見つけてください。

```clojure
(longest-name countries)
;;=> "United States of America"
```
