# はじめに

F#の`char`型は、テキストの最小のアドレス可能な構成要素を表す16ビットの値で、デフォルトで不変です。

`char`は、シングルクォートを使ってリテラルとして定義できます：

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

文字列は文字のシーケンスです。

個々の`char`は、文字列から（0から始まる）インデックスを使って取得できます：

```fsharp
"Exercism"[4] //  =>  'c'
```

文字列を繰り返し処理すると、各ステップで`char`が返されます。

次の例では、便宜上、高階関数と無名関数を使っています。
これらは後ほどシラバスで本格的に扱いますが、今は文字列内の文字をループする簡潔な方法です。

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

上に示したように、`char`はその`int`値にキャストできます。
これは他の文字体系でも（少なくとも一部の場合は）機能します：

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

文字を比較するときは、基になるInt16が使われます：

```fsharp
'A' < 'D'  // =>  true
```

また、`int`は`char`にキャストできます：

```fsharp
char 77  // => 'M'
```

`System.Char`ライブラリには、.NET言語で期待されるメソッドが一通り揃っており、大文字と小文字の変換などがあります：

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
