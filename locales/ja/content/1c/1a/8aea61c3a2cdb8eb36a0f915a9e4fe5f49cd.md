# 説明

ピタゴラスの三つ組とは、次の関係を満たす3つの自然数{a, b, c}の組のことです。

```text
a² + b² = c²
```

さらに、次の関係も満たします。

```text
a < b < c
```

例えば、次のようになります。

```text
3² + 4² = 5².
```

整数Nが入力として与えられたとき、`a + b + c = N`を満たすピタゴラスの三つ組をすべて見つけてください。

例えば、N = 1000の場合、`a + b + c = 1000`を満たすピタゴラスの三つ組はちょうど1つだけあります：`{200, 375, 425}`。
