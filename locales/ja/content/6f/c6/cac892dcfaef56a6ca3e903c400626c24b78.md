# ヒント

## 1. ハイスコアテーブルを作る

- ハイスコアテーブルは、ハッシュテーブルにする必要があります。
- ハッシュテーブルは`make-hash-table`で作成できます。

## 2. テーブルにプレイヤーを追加する

- ハッシュテーブルにキーと値のペアを追加するには、`(setf (gethash key table) value)`を使います。

## 3. プレイヤーのスコアを設定する

- プレイヤーのスコアを設定するのは、プレイヤーをテーブルに追加するのとほぼ同じです。
- ハッシュテーブルにキーと値のペアを追加するには、`(setf (gethash key table) value)`を使います。

## 4. テーブルからスコアを取得する

- ハッシュテーブルからキーに対応する値を取得するには、`gethash`を使います。
- `gethash`には省略可能な3番目の引数があり、キーが見つからなかったときに使う値を指定できます。

## 5. テーブルからプレイヤーを削除する

- テーブルからキーを削除するには、`remhash`を使います。
