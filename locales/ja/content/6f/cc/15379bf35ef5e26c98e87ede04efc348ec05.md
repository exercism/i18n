# はじめに

コレクションの定義には、たいてい山括弧（`<>`）で囲まれたプレースホルダーが含まれていて、慣例的に`T`が使われます。このようなコレクションを、ジェネリック型と呼びます。これにより、コレクションを使う側は、そのコレクションにどんな型の要素を格納するのかを指定できます。上のサンプルコードでは、文字列の配列をインスタンス化しています。

クラスや関数を**ジェネリック**にするには、`@:generic`属性を使います。これにより、コンパイラーはそのクラスや関数をジェネリックとして識別します。

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
