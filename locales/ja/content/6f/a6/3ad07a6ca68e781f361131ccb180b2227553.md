# はじめに

## 文字列

Javaの`String`は、Unicode文字（文字、数字、記号など）の並びとして、変更できないテキストを表すオブジェクトです。
`String`のインスタンスを定義するには、二重引用符を使います。

```java
String fruit = "Apple";
```

文字列は、その文字列のメソッドを呼び出すことで操作します。
一度文字列を作成すると、その値を変更することはできません。
文字列を変更するように見えるメソッドも、実際には新しい文字列を返します。
`String`クラスには、文字列を変換するための_静的_メソッドがいくつか用意されています。
