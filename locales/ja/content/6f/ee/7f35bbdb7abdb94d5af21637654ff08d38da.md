# はじめに

[`Set`][set]は、次のような性質を持つ要素の集まりです：

- 順序を持ちません。
- 要素は一意です。そのため、重複を追加しようとしても黙って無視されます。
- 数学の集合でよく使われる演算の多くをサポートします。

作成には`Set()`コンストラクターを使います。入力には任意のイテレーターを指定できます。

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

新しい要素は`push!()`で追加し（配列と同じです）、`delete!()`で削除します。

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## `Set`の演算

他のいくつかのコレクション型と同様に、要素が含まれているかどうかは`in`または`∈`演算子で確認します（記号を入力するには`\in`と入力してからTabキーを押します）。

```julia-repl
julia> 3 ∈ s1
true
```

2つの`Set`に対する次の演算がサポートされています（演算子記号へのショートカットは括弧（`()`）内に示します）。

- `union(A, B)`または`A ∪ B`（`\cup`）：AまたはB、あるいはその両方にあるすべての要素。
- `intersect(A, B)`または`A ∩ B`（`\cap`）：AとBの両方に共通するすべての要素。
- `setdiff(A, B)`（記号なし）：AにあってBにない要素。
- `symdiff(A, B)`（記号なし）：AまたはBのどちらか一方にだけある要素。
- `issubset(A, B)`または`A ⊆ B`（`\subseteq`）または`B ⊇ A`（`\supseteq`）：Aのすべての要素がBにも含まれる場合に`true`。
- `issetequal(A, B)`（記号なし）：AとBがまったく同じ要素を含む場合に`true`。
- `isdisjoint(A, B)`（記号なし）：AとBに共通する要素が1つもない場合（つまり共通部分が空の場合）に`true`。

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

これらの多くには、関数名に`!`を付けた破壊的なバージョンもあります。関数の完全な一覧は[マニュアル][set]を参照してください。
