# 説明

今日、世界のほとんどの人はアラビア数字（0〜9）を使っています。
しかし、2000年前にさかのぼってみると、当時のほとんどのヨーロッパ人は代わりにローマ数字を使っていたことがわかります。

ローマ数字を書くには、次のラテン文字を使います。それぞれに値があります：

| M    | D   | C   | L   | X   | V   | I   |
| ---- | --- | --- | --- | --- | --- | --- |
| 1000 | 500 | 100 | 50  | 10  | 5   | 1   |

ローマ数字はこれらの文字を並べたもので、その値は各文字の値の合計になります。
たとえば、`XVIII`の値は18です（`10 + 5 + 1 + 1 + 1 = 18`）。

ただし、話を少しややこしくするルールが1つあります。それは、**同じ文字を続けて3回より多く使うことはできない**というものです。
つまり、4のような数値を、一見自然に見える`IIII`で表すことはできません。
代わりに、そうした数値には、2つの文字の間で引き算をする方法を使います。
そこで、`4`は`1 + 1 + 1 + 1`ではなく、`5 - 1`と考えます。
そして、現代の考え方からすると少し戸惑いますが、小さい方の数を先に書きます。
これは次の場合にだけ当てはまります：4（`IV`）、9（`IX`）、40（`XL`）、90（`XC`）、400（`CD`）、900（`CM`）。

ローマ数字では順序が大切です！
文字（および上記の特別な組み合わせ）は、左から右へと値が小さくなる順に並べなければなりません。

例をいくつか見てみましょう。

```text
 105 => CV
---- => --
 100 => C
+  5 =>  V
```

```text
 106 => CVI
---- => --
 100 => C
+  5 =>  V
+  1 =>   I
```

```text
 104 => CIV
---- => ---
 100 => C
+  4 =>  IV
```

最後に、もう少し複雑な例です。

```text
 1996 => MCMXCVI
----- => -------
 1000 => M
+ 900 =>  CM
+  90 =>    XC
+   5 =>      V
+   1 =>       I
```
