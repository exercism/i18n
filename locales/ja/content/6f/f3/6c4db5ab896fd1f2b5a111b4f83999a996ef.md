# はじめに

## 真偽値

Javaの真偽値は`boolean`型で表し、その値は`true`か`false`のどちらかです。

Javaでは、3つの真偽値演算子を使うことができます。  

- `!`（NOT）：真偽値を反転させます  
- `&&`（AND）：2つの真偽値を受け取り、どちらも`true`であれば`true`を返します
- `||`（OR）：2つの真偽値のどちらかが`true`であれば`true`を返します

### 例

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
