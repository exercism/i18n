# インストール

## .NETのインストール

F#トラックは、Windows、Linux、macOSで動作する[.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet)プラットフォームの上に構築されています。.NETプロジェクトをビルドするには、.NETコマンドラインインターフェース（CLI）を使います。このCLIは.NET SDKの一部なので、[インストール手順](https://dotnet.microsoft.com/download)に従ってSDKをインストールしてください。なお、F#トラックにはSDKバージョン8.0以上が必要です。

インストールが完了したら、ターミナルで次のコマンドを実行すると、CLIが正しくインストールされたかどうかを確認できます。

```bash
dotnet --version
```

出力されたバージョンが`8.0.100`以上であれば、.NET SDKは正しくインストールされています。

## IDEを使う

より高機能な編集環境を求めるなら、IDEを使うのがよいでしょう。.NETプロジェクトのビルドに対応している、よく使われるIDEは次のとおりです。

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download)と[Ionide-fsharp拡張機能](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

なお、.NETプロジェクトの形式は以前のバージョンとは大きく異なるため、古いIDE（Visual Studio 2015など）は対応していません。
