# 説明

この課題では、図をもとに、幼稚園のクラスのどの子どもがどの植物を担当しているかを判定します。

クラスには12人の子どもがいます：

- Alice、Bob、Charlie、David、Eve、Fred、Ginny、Harriet、Ileana、Joseph、Kincaid、Larry

4種類の種が植えられています：

| 植物 | 図での表記 |
| ------ | ---------------- |
| Grass  | G                |
| Clover | C                |
| Radish | R                |
| Violet | V                |

それぞれの子どもには4つのカップが与えられ、各列に2つずつ置かれます：

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

先生は、子どもたちの名前のアルファベット順にカップを割り当てます。つまり、Aliceが最初で、Larryが最後になります。

次の図は、Aliceの植物を表す例です：

```text
[window][window][window]
VR......................
RG......................
```

窓に一番近い1列目には、violetとradishがあります。
2列目にはradishとgrassがあります。

プログラムには、窓に一番近い列から始めて、左から右へと植物が与えられます。これをもとに、どの植物がどの子どものものかを判定できるようにします。

たとえば、庭が次のようになっているとします：

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

このとき、Aliceの植物を尋ねられると、次のように返します：

- Violets, radishes, violets, radishes

一方、Bobの植物を尋ねると、次のようになります：

- Clover, grass, clover, clover
