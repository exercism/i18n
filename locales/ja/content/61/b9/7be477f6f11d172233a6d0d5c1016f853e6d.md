# Haskellの組み込み数値型

## 数値

Haskellの標準ライブラリは***Prelude***と呼ばれ、基本的な数値型のほとんどを定義しています。サイズが固定の整数（`Int`）、任意精度の整数（`Integer`）、単精度浮動小数点数（`Float`）、倍精度浮動小数点数（`Double`）です。
有理数や複素数などのその他の数値型は、追加のライブラリで定義されています。

`Integer`sは、マシンのメモリの限界まで、どんなに大きな数でも保持できます。一方、`Int`は32ビットまたは64ビットで表現できる正負の整数の集合に対応します（少なくとも-2^29から2^29までが保証されています）。

`Float`は実数の集合に対応し、コンピューターの精度によって制限されます。
数値に対して定義された演算は、通常はどちらか一方の型で機能し、両方で機能するわけではありません。

`Float`と`Integer`の間で変換する関数には、`Int`/`Integer`を`Float`に変換する`toFloat`や、`Float`を`Int`に変換する`ceiling`などがあります。

## 算術演算子

Haskellには、動作が異なり、受け取る引数の型も異なる、累乗の演算子が3つあります。

- `**` は2つの**浮動小数点数**を受け取り、対数を使って累乗を計算します。
- `^^` は**浮動小数点数**を受け取り、正または負の**整数**乗します。
- `^` は**任意の数値型**を受け取り、**正の整数**乗します。

整数型（`Int`または`Integer`）から他の数値型への変換は、`fromIntegral`関数を使って行います。
変換先の型は自動的に推論されます。
たとえば、次のとおりです。

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```

整数の除算は少し複雑です。
整数に対して通常の`/`演算子を使うと、エラーメッセージが表示されます（ただし、`4/3`という式は機能します。Haskellが、必要なところではリテラルの整数を親切に浮動小数点数に昇格してくれるからです）。
代わりに、整数の除算はいくつかの名前付き演算子を使って行います。

Haskellには演算子に関する便利な仕掛けがあります。2つの引数を取る関数であれば、名前をバッククォートで囲むことで、演算子のように使えます。
つまり、次の2行はまったく同じ意味です。

```haskell
 d = 7 `div` 3
 d = div 7 3
```

それを踏まえて、整数除算の演算子を紹介します。

- `quot`：2つの数の商を返します。
  除算の結果を0に向かって切り捨てたものです。
- `rem`：商の余りを返します。
- `div`：`quot`に似ていますが、負の無限大に向かって切り捨てられます。
- `mod`：2つの数の余りを返します。
  `rem`に似ていますが、`div`が負の数を返すときの規則が異なります。

2つの引数を取る関数を演算子に変換できるのと同様に、演算子を括弧（`()`）で囲むことで、2つの引数を取る関数に変換できます。
つまり、次の2行は同じ意味です。

```haskell
(+) 3 4
3 + 4
```
