# 説明

Maryはテレビシリーズ_スター・トレック：新世代_の大ファンです。
彼女はよく、友人たちと一緒に_宇宙船エンタープライズ_の乗組員になりきって遊ぶ、ペンと紙のロールプレイングゲームをします。
Maryが演じるキャラクターはピカード艦長なので、艦長日誌を付けることになります。
彼女はゲームの創造的な部分が大好きですが、その場でランダムなデータを作るのは苦手です。

艦長日誌によく登場するデータをランダムに生成する仕組みを作って、Maryを手伝いましょう。

~~~~exercism/note
この演習のスターター実装は、`java.util.Random`のインスタンスをコンストラクターの引数として受け取ります。
これにより、演習のテストでは、あらかじめ決められたシードを持つインスタンスを渡せるようになり、テスト結果が予測可能になります。

そのため、実装では、与えられた`java.util.Random`のインスタンスを使うことが求められます。
~~~~

## 1. ランダムな惑星を生成する

_宇宙船エンタープライズ_は、旅の途中でたくさんの惑星と出会います。
スタートレックの世界では、惑星はその性質によっていくつかのクラスに分けられています。
たとえば、地球はクラス`M`の惑星です。
惑星のクラスは、`D`、`H`、`J`、`K`、`L`、`M`、`N`、`R`、`T`、`Y`のいずれかです。

`randomPlanetClass()`メソッドを実装しましょう。
このメソッドは、惑星のクラスをランダムに1つ返します。

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. ランダムな宇宙船の登録番号を生成する

宇宙を飛び回っているのはエンタープライズ（登録番号`NCC-1701`）だけではありません！
別の宇宙船とランデブーしたとき、Maryはその宇宙船の登録番号を日誌に記録する必要があります。

登録番号は「NCC-」という接頭辞で始まり、そのあとに`1000`から`9999`までの数値（両端を含む）が続きます。

ランダムな宇宙船の登録番号を返す`randomShipRegistryNumber()`メソッドを実装しましょう。

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. ランダムな宇宙暦を生成する

日付のない日誌に、なんの意味があるでしょうか？

宇宙暦は小数です。
_宇宙船エンタープライズ_の冒険のうち、_新世代_のシーズン1の物語は、宇宙暦`41000.0`から`42000.0`の間に起こります。
「4」は24世紀を、「1」はシーズン1を表しています。

`41000.0`以上`42000.0`未満の小数を返す`randomStardate()`メソッドを実装しましょう。

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
