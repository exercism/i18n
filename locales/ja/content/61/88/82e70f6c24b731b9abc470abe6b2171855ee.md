# インストール

Ceylonをインストールするいちばん簡単な方法は、そもそも**インストールしない**ことです。
ほとんどの演習は、[Web IDE](http://try.ceylon-lang.org/)を使えば解けるはずです。

でも、コマンドライン版をインストールしたい場合は、[SDKMAN](http://sdkman.io/)を使うのがいちばん簡単です。まだSDKMANが入っていなければ、まずそれをインストールしてから、ターミナルで`sdk install ceylon`と入力するだけです。

OSXを使っている場合は、[Homebrewパッケージマネージャー](http://mxcl.github.com/homebrew/)からインストールすることもできます。

その他のプラットフォーム向けのインストール手順や、EclipseのプラグインであるCeylon IDEについては、[公式サイト](http://ceylon-lang.org/download/)で確認できます。
