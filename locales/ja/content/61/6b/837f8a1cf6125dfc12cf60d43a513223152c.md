# 概要

[構造体とクラスのメンバーの種類][expression-bodied-members]の多く（主な例外はフィールドです）は、式形式のメンバーの構文を使うことができます。メンバーを式で定義すると、従来のブロックや文を使うよりも、簡潔で読みやすいコードになることがよくあります。

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

式形式のメンバーには、複数の文からなるブロックを書くことはできません。ただ、関数型言語の経験がある方は、従来のメンバーでできることはこの式形式のメンバーでもすべて実現できるという点を頭に置いておいてください。ここでいう「式」とは、副作用を生み出す代入操作であったり、何でもできるメソッド呼び出しであったりします。

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
