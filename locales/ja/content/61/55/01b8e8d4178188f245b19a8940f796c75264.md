# Alias

[特殊形式の`alias`][alias]を使うと、外部のモジュールを参照するときの名前を短くしたり、変更したりできます。独自の名前は`:as`オプションで指定できます。

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

引数を指定せずに使うと、モジュール名が最後の部分だけに短縮されます。たとえば次のようになります。

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

複数の`alias`は、`{}`でまとめて指定できます。

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

通常、`alias`はモジュール定義の先頭に書きますが、どこにでも書くことができます。`alias`にはレキシカルスコープがあり、関数定義の中で追加した`alias`は、別の関数では使えません。

使われていない`alias`があると、コンパイラーが警告を出します。

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
