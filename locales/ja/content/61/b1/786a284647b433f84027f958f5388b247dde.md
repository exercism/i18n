# はじめに

_`enum`型_とは、変数が、あらかじめ定義された定数の集合のいずれかになることを可能にする特別なデータ型です。
その変数は、あらかじめ定義された値のいずれかでなければなりません。
よくある例としては、方角（`NORTH`、`SOUTH`、`EAST`、`WEST`という値）や曜日が挙げられます。

定数なので、`enum`型のフィールド名は大文字で書きます。

## `enum`型を定義する

Javaのプログラミング言語では、`enum`キーワードを使って`enum`型を定義します。
たとえば、曜日の`enum`型は次のように定義します。

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

決まった定数の集合を表す必要があるときは、いつでも`enum`型を使いましょう。
これには、太陽系の惑星のような自然な`enum`型や、コンパイル時にすべての値がわかっているデータの集合が含まれます。たとえば、メニューの選択肢やコマンドラインフラグなどです。

## `enum`型を使う

上で定義した`DayOfWeek`の`enum`を使う方法を、次のコードで見てみましょう。

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## メソッドとフィールドを追加する

Javaの`enum`型は、他の言語の対応するものよりもずっと強力です。
`enum`宣言は、_クラス_（_`enum`型_と呼ばれます）を定義します。
`enum`クラスの本体には、メソッドやその他のフィールドを含めることができます。

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating`型のメンバーに対して`getNumberOfStars`メソッドを呼び出します。

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
