# 説明

この演習では、[ブラックジャック][blackjack]のゲームの最初のターンをシミュレーションします。

## 1. 与えられたカードの値を計算する

2枚のカードが配られ、ディーラーの表向きのカードが1枚見えています。
カードはすべて、"ace"、"king"、"three"、"two"などの文字列で表されます。
各カードの値は次のとおりです。

| カード | 値 | カード | 値 |
| :---: | :---: | :-----: | :---: |
| ace | 11 | eight | 8 |
| two | 2 | nine | 9 |
| three | 3 | ten | 10 |
| four | 4 | jack | 10 |
| five | 5 | queen | 10 |
| six | 6 | king | 10 |
| seven | 7 | _other_ | 0 |

~~~~exercism/note
通常、エースは1または11の値を取ることができますが、ここでは簡単にするため、11の値しか取らないものとします。
~~~~

カードを文字列として引数に取る`Blackjack.parse_card`メソッドを実装してください。
このメソッドは、カードの値を整数で返します。

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. 値の範囲に名前を付ける

プレイヤーのスコアは、値の範囲に分類する必要があります。
プレイヤーのスコアは、プレイヤーの2枚のカードの値を合計して計算します。
使用する範囲は次のとおりです。

| 範囲 | 値 |
| :-------: | :------: |
| low | [4, 11] |
| mid | [12, 16] |
| high | [17, 20] |
| blackjack | [21] |

2枚のカードを文字列として引数に取る`Blackjack.card_range`メソッドを実装してください。
このメソッドは、2枚のカードが該当する値の範囲の名前を返します。

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. 最初のターンの判断ロジックを実装する

手持ちの2枚のカードとディーラーのカードに応じて、ゲームの最初のターンには戦略があり、次の選択肢があります。

- スタンド（S）
- ヒット（H）
- スプリット（P）
- 自動勝利（W）

まだ最適ではありませんが、友人のAlexが開発中の戦略に従います。その内容は次のとおりです。

- エースのペアを持っている場合は、必ずスプリットします。
- ブラックジャック（2枚のカードの合計が21になる場合）で、ディーラーがエース、絵札、または10を持っていなければ、自動的に勝ちです。
  ディーラーがこれらのいずれかを持っている場合は、スタンドして、もう1枚のカードが公開されるのを待ちます。
- カードの合計が[17, 20]の範囲にある場合は、必ずスタンドします。
- カードの合計が[12, 16]の範囲にある場合は、ディーラーが7以上でない限り必ずスタンドします。ディーラーが7以上の場合は、必ずヒットします。
- カードの合計が11以下の場合は、必ずヒットします。

3枚のカードを文字列として引数に取る`Blackjack.first_turn`メソッドを実装してください。
このメソッドは、取るべき判断を文字列で返します。

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
