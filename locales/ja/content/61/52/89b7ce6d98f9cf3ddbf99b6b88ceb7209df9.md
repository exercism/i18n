# はじめに

## 属性

[C#の`Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/)を使うと、宣言を装飾してメタデータを関連付けられます。関連付けられる対象は、クラス、メソッド、`enum`、フィールド、プロパティ、その他の[対応している宣言](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets)です。

属性を適用するには、宣言の前の行に`ClassAttribute`や`FieldAttribute`を追加します。

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

この宣言的なメタデータは、コードに追加の構造化された情報を関連付けるだけで、コードの動作を変えることはありません。しかし、そのメタデータはコードの他の部分で使われ、対象の振る舞いを変えたり、機能を追加・変更・削除したり、一部の機能を制限したりします。

[あらかじめ定義されている属性や予約された属性](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)はたくさんあります。たとえば、`Flags`、`Obsolete`、`Conditional`、`Experimental`などです。それぞれに固有の意味があり、C#のドキュメントで調べられます。なお、[`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)のような属性の完全な名前は`<Name>Attribute`という形になります（たとえば`FlagsAttribute`）。

## フラグ`enum`

C#の[`enum`型](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)は、名前付き定数の固定された集合（列挙）を表します。

通常、1つの`enum`メンバーは、こうした名前付き定数のうちちょうど1つしか参照できません。しかし、複数の定数を参照できると便利なこともあります。その場合は、`enum`に[`Flags`属性](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)を付けることで実現できます。

フラグ`enum`は、次のように定義できます（2進数の整数表記`0b`を使います）。

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

値が`0b00000011`である`PhoneFeatures`のインスタンスは、`Call`と`Text`の_両方_のフラグが設定されています。

デフォルトでは、`enum`メンバーの値には`int`型が使われます。`enum`の宣言で型を指定すれば、別の整数型を使うこともできます。

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
