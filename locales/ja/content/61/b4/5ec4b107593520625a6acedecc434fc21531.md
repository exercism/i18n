# 説明

この演習では、友達と数の当てっこゲームをします。
ルールは簡単です。`1`から`100`までの数を心の中でひそかに選び、友達がその数を当てようとします。
友達の助けになるように、その予想が選んだ数（`42`）にどれだけ近いかによって、返事を変えます。
入力として考えられるそれぞれの場合のルールは、次のとおりです：

- 予想が`42`のとき："Correct"
- 予想が`41`か`43`のとき："So close"
- 予想が`41`より小さいとき："Too low"
- 予想が`43`より大きいとき："Too high"

予想への返事を実装する、4つのタスクがあります。

## 1. 正解に返事をする

`reply`関数を実装して、正解に返事をしましょう：

```haskell
reply 42
-- -> "Correct"
```

## 2. 惜しい予想に返事をする

`reply`関数を変更して、惜しい予想にも返事をしましょう：

```haskell
reply 41
-- -> "So close"
```

## 3. 小さすぎる予想に返事をする

`reply`関数を変更して、小さすぎる予想にも返事をしましょう：

```haskell
reply 25
-- -> "Too low"
```

## 4. 大きすぎる予想に返事をする

`reply`関数を変更して、大きすぎる予想にも返事をしましょう：

```haskell
reply 88
-- -> "Too high"
```
