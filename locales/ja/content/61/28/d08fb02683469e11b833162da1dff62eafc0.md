# 説明

_Instruments of Texas_で働いているあなたは、C#で書かれた実験的な電卓の開発を任されています。まずは掛け算から始めて、いくつかの電卓の機能を検証するテストハーネスを作成します。掛け算の2つのオペランドがどちらも負の場合には、特に注意が必要になることがわかるでしょう。

`Calculator`クラスはすでに用意されています。変更しないでください。

## 1. ユーザー定義の例外`CalculationException`の定義を完成させる

`CalculationException`のコンストラクターの定義を完成させてください。このコンストラクターは、電卓がスローした例外と、その例外がスローされた時点で処理していたオペランドの両方を保存（ラップ）する必要があります。

## 2. 電卓のオーバーフロー状態を処理し、呼び出し元に詳細な情報を提供する

`CalculatorTestHarness.Multiply()`メソッドを実装してください。このメソッドは、コンストラクターに渡された`Calculator`インスタンスの`Calculator.Multiply()`メソッドを呼び出し、xとyの整数値を渡します。`Calculator.Multiply()`メソッドでオーバーフローが発生すると、`OverflowException`がスローされます。この例外は`CalculatorTestHarness.Multiply()`メソッドでキャッチして`CalculationException`でラップし、そのとき受け渡されているxとyの値を、その例外のオペランドとして保存してください。新しく作成した`CalculationException`オブジェクトをスローしてください。`Calculator.Multiply()`メソッドが成功した場合の戻り値は無視してかまいません。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. 有効な入力に対する掛け算の動作をテストする

2つの整数を引数に取り、`CalculatorTestHarness.Multiply()`メソッドを呼び出す`CalculatorTestHarness.TestMultiplication()`メソッドを実装してください。`"Multiply succeeded"`が返されます。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. 負の入力に対する掛け算の動作をテストする

`CalculatorTestHarness.TestMultiplication()`メソッドを変更して、2つの整数引数がどちらも負（0より小さい）の場合に`"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"`が返されるようにしてください。

`<INNER_EXCEPTION_MESSAGE>`プレースホルダーは、`CalculationException`の内部例外のメッセージで置き換えてください。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. 正の入力に対する掛け算の動作をテストする

`CalculatorTestHarness.TestMultiplication()`メソッドを変更して、少なくとも一方の整数引数が負でない場合に`"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"`が返されるようにしてください。

`<INNER_EXCEPTION_MESSAGE>`プレースホルダーは、`CalculationException`の内部例外のメッセージで置き換えてください。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
