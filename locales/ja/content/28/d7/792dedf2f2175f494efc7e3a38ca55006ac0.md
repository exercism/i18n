# はじめに

イニシャライザは、列挙型の値を用意するために使われる特別なメソッドです。その定義はメソッドの定義とよく似ていますが、`func`キーワードも戻り値の型もなく、名前は`init`でなければならず、さらにイニシャライザは列挙型の値を`self`に必ず代入しなければなりません。イニシャライザは、ドット記法で呼び出すか、列挙型の名前にイニシャライザの仮引数を渡して呼び出すかのいずれかです。

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
