# はじめに

Rubyでは、**配列**は順序付けされた、整数のインデックスを持つ、あらゆるオブジェクトのコレクションです。
配列のインデックスは`0`から始まります。
負のインデックスは、配列の末尾からの相対位置とみなされます。つまり、インデックス`-1`は配列の最後の要素を指し、`-2`は後ろから2番目の要素を指し、以下同様です。
Rubyの配列は[Enumerableモジュール][enumerable-module]をインクルードしており、これによりいくつかの走査メソッドと検索メソッド、そしてソートする機能が追加されます。

## 配列の作成

- Rubyの配列には、さまざまな型のオブジェクトを入れることができます。

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## 要素の代入

要素にはインデックスを使ってアクセスしたり、変更したりできます。
開始インデックスとサイズを指定すると、部分配列にアクセスできます。

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- 負のインデックスは、配列の末尾から逆方向に数えます。

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## 要素の参照

- 配列の要素は、#[]メソッドを使って取得できます。
- インデックスにある要素を返すか、開始インデックスからlength個の要素にわたる部分配列を返します。

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- 負のインデックスは配列の末尾から逆方向に数えます（-1は最後の要素です）。

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## 配列の情報を取得する

配列は常に自身の長さを把握しています。
配列に含まれる要素の数を調べるには、length、count、sizeを使います。

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## 配列への要素の追加

配列の末尾に要素を追加するには、`push`か`<<`を使います。

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## 配列からの要素の削除

popメソッドは、配列の最後の要素を取り除いて返します。

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
