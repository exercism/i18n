# 手順

この演習では、お気に入りの料理本を見ながら絶品ラザニアを作るためのコードを書いていきます。

4つのタスクがあり、どれもラザニアを作るのにかかる時間に関するものです。

## 1. 焼き時間の目安を定数に保存する

ラザニアをオーブンで何分焼けばよいかを返す`expected_bake_time`定数を定義します。

料理本によると、ラザニアはオーブンで合計60分焼く必要があります。

```julia-repl
julia> expected_bake_time
60
```

## 2. 準備にかかる時間を分単位で計算する

`preparation_time`関数を定義します。この関数は、ラザニアに重ねた層の数を入力として受け取り、ラザニアの準備に何分かかったかを返します。1層につき2分かけて準備するものとします。

```julia-repl
julia> preparation_time(4)
8
```

## 3. 残りの焼き時間を分単位で計算する

`remaining_time`関数を定義します。この関数は、ラザニアがすでにオーブンに入っていた実際の分数を入力として受け取り、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```julia-repl
julia> remaining_time(50)
10
```

## 4. 合計の作業時間を分単位で計算する

`total_working_time`関数を定義します。この関数は2つの入力を受け取ります。1つ目の入力は、ラザニアに重ねた層の数です。2つ目の入力は、ラザニアがオーブンに入っていた分数です。

この関数は、ラザニアの調理に合計で何分取り組んだかを返します。これは、準備にかかった分数と、その時点でラザニアがオーブンに入っていた分数を足したものです。

```julia-repl
julia> total_working_time(3, 20)
26
```
