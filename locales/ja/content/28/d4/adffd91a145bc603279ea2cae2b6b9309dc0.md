# 説明の補足

## 例外のメッセージ

[例外を発生させる][raising-exceptions]必要があることがあります。
そのときは、エラーの原因が何であるかを示す**意味のあるエラーメッセージ**を必ず含めるようにしましょう。
これによりコードが読みやすくなり、デバッグもぐっと楽になります。
エラーの原因がある特定の種類だとわかっている場合は、[組み込みのエラー型][error-base-classes]のいずれかを発生させることもできますが、その場合も意味のあるメッセージを含めるようにしましょう。


`Tic Tac Toe`の正常なゲームは、どちらかのプレイヤーが勝った時点で終わります。
両方のプレイヤーが勝利している状態にある場合、この演習では[raise文][raise]を使って、解答の中で`ValueError`を「投げる」ことが求められます。
また、あるプレイヤーが2手続けて打ったと判定された場合や、後手に割り当てられているのに最初の手を打ったと判定された場合にも、コードは`ValueError`を投げることが求められます。


メッセージ付きで`ValueError`を発生させるには、`exception`型の引数としてメッセージを書きます：

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

テストではエラーメッセージが完全に一致するかどうかが確認されるので、期待される結果をよく読んでください。

[raising-exceptions]: https://docs.python.org/3/tutorial/errors.html#raising-exceptions
[error-base-classes]: https://docs.python.org/3/library/exceptions.html#base-classes
[raise]: https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement
