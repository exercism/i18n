# 概要

Kotlinの真偽値は`Boolean`型で表され、その値は`true`か`false`のどちらかです。

Kotlinには、組み込みの[論理演算子][reference]が3つあります。`!`（否定、別名NOT）、`&&`（遅延評価の論理積、別名AND）、`||`（遅延評価の論理和、別名OR）です。`&&`と`||`は_短絡評価_を使います。これは、演算子の右側が必要なときにだけ評価されるという意味です。

```kotlin
true || false // => true
true && false // => false
```

3つの論理演算子には、それぞれ異なる[_演算子の優先順位_][precedence]があります。そのため、評価される順序は`!`が最初、次に`&&`、最後に`||`となります。このルールを「回避」したいときは、論理式を括弧（`()`）で囲むことができます。括弧の優先順位はさらに高いからです。

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
