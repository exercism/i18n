# 説明

待ち望んでいた日がついにやってきて、今ではアルプスにある美しい農場の、誇らしい持ち主です。

それでも、牛に餌をやるために朝早く起きるのは、相変わらず好きではありません。
そこで、優秀なエンジニアらしく、給餌機`FEED-M-ALL`を作ります。

プロジェクトを完成させるために最後に必要なのは、それぞれの牛が受け取るべき飼料の量を計算するコードです。
どの牛も同じ量を受け取ることが大切で、争いを避ける必要があります。
牛はとても敏感なのです。

幸いなことに、飼料の量を計算するための公式を自分で全部導き出す必要はありません。
インターネットで見つけた、謎めいた外部ライブラリを使います。
これを使えば、牛たちは最高に幸せになれるはずです。
そのライブラリは、次のインターフェースを満たす型を公開しています。
自分で書くコードでは、これに頼ることになります。

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

コードを書いていくうちに、エラー処理を改善して、より堅牢にし、後で農場の日々の暮らしで使うときにデバッグしやすくしていきます。

## 1. 食べ物を均等に分ける

まず最初に、牛1頭あたりの飼料の量を計算するために必要なコードを書くことに集中します。

`FodderCalculator`と、牛の頭数を表す整数を引数に取る関数`DivideFood`を実装します。
*このタスクでは、渡される牛の頭数は常に0より大きいものと仮定します。*
この関数は、牛1頭あたりの餌の量を`float64`として返すか、エラーが発生した場合はそのエラーを返す必要があります。

計算を行うには、まずすべての牛の飼料の合計量を取得する必要があります。
これは、`FodderAmount`メソッドを呼び出し、牛の頭数を渡すことで行います。
さらに、この量に掛け合わせる必要がある係数も必要です。
この係数は`FatteningFactor`メソッドを呼び出すことで取得します。
これら2つの値と牛の頭数があれば、牛1頭あたりの餌の量（`float64`として）を計算できます。
それが`DivideFood`関数から返されるべきものです。

呼び出したメソッドのいずれかがエラーを返した場合、実行を停止し、そのエラーを（そのまま）`DivideFood`関数から返す必要があります。

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. 牛の頭数を確認する

上の最初のタスクに取り組んでいるうちに、使っている外部ライブラリが思っていたほど高品質ではないことに気づきます。
たとえば、無効な入力を適切に処理できません。
この制限を回避するために、自分のコードで入力値のチェックを追加することにします。

`DivideFood`と同じシグネチャを持つ関数`ValidateInputAndDivideFood`を書きます。

- 渡された牛の頭数が0より大きい場合、関数は`DivideFood`を呼び出し、その呼び出しの結果を返す必要があります。
- 牛の頭数が0以下の場合、関数は`"invalid number of cows"`というメッセージのエラーを返す必要があります。

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. エラー処理を改善する

渡す前に牛の頭数を確認したのは良い判断でしたが、具体性のないエラーメッセージにはあまり満足していません。
そこで、`InvalidCowsError`というカスタムエラー型を作って、もっと良いものにすることにします。

カスタムエラーは、牛の頭数（`int`）とカスタムメッセージ（`string`）を保持し、`Error`メソッドはデータを次の形式でシリアライズする必要があります。

```txt
{number of cows} cows are invalid: {custom message}
```

カスタムエラーを手に入れたので、牛の頭数を整数で受け取り、エラー（またはnil）を返す関数`ValidateNumberOfCows`を実装します。

- 牛の頭数が0より小さい場合、関数はカスタムメッセージを`"there are no negative cows"`に設定した`InvalidCowsError`を返します。
- 牛の頭数が0の場合、関数はカスタムメッセージを`"no cows don't need food"`に設定した`InvalidCowsError`を返します。
- それ以外の場合、関数は検証が成功したことを示す`nil`を返します。

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

この検証関数を設定するという大変な作業を終えると、すでに夕方になっていることに気づき、山に沈む夕日を楽しむために机を離れます。
新しい検証関数を実際にコードに追加する作業は、また別の日に取っておくことにします。
