# ヒント

## 1. ランクとファイルの範囲を定義する

- ランクとファイルの[範囲][range]を保持する2つの[定数][constants]を定義する必要があります。
- ランクは1から8までの[整数][integers]の範囲にします。
- ファイルは'A'から'H'までの[文字][characters]の範囲にします。
- 定数は`Chess`[モジュール][module]の中で定義する必要があります。

## 2. マスが有効かどうかを確認する

- 値が範囲の中にあるかどうかを確認する必要があります。
- 値が範囲の中にあるかどうかを確認するために使える[メソッド][include]があります。

## 3. プレイヤーのニックネームを取得する

- [範囲演算子][range-operator]をインデックスとして使うと、部分文字列を取得できます。
- 文字列を大文字に変換するために使える[メソッド][upcase]があります。

## 4. 移動メッセージを作成する

- マスの文字列をインデックスして、ランクとファイルを取得できます。
- すでに定義したメソッドを使って、プレイヤーのニックネームを取得したり、移動が有効かどうかを確認したりできます。
