# はじめに

この演習は、[Cargo Shuffle][cargo-shuffle]で出会ったデータスタックとスタック効果の表記を土台にしています。ここでは、真偽値を組み合わせるワードを書いていきます。

## シャッフルワード

よく使うシャッフルワードは、[`kernel`][kernel]に入っています。

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## 真偽値

真偽値リテラルは`t`と`f`の2つです。`f`はFactorで唯一の偽の値で、`0`や空のコレクションを含め、それ以外はすべて真になります。

```factor
t .    ! => t
f .    ! => f
```

## 真偽値のワード

`kernel`ボキャブラリーにある、この3つの真偽値ワードです。

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

それぞれの出力にある`?`は、スタック効果で「真偽値」を表すときの慣習です。

以下のタスクの1つでは、`swap`が必要になります。
