# 概要

Goでは、文字列はイミュータブルです。
ループの中で`+`を使って文字列を連結すると、頻繁にメモリの割り当てが起こり、データが何度もコピーされます。
[`strings`パッケージ](https://pkg.go.dev/strings)には[`Builder`](https://pkg.go.dev/strings#Builder)があり、文字列を効率よく組み立てることでメモリのオーバーヘッドを最小限に抑えられます。

## 文字列を組み立てる

`strings.Builder`のゼロ値は、明示的に初期化したりメモリを割り当てたりしなくても、すぐに使えます。
新しいデータは、専用の書き込みメソッドを使って追加します。
どの書き込みメソッドも、Goの標準インターフェースを満たすためにエラー値を返しますが、常に`nil`になることが保証されているので、ふだんのコードではたいてい無視します。

よく使うメソッドは次のとおりです。

- `WriteString(s string) (int, error)`: バッファーに文字列を追加します。
- `WriteRune(r rune) (int, error)`: ルーンをUTF-8でエンコードしたものを追加します。
- `WriteByte(c byte) error`: 1バイトを追加します。

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## 取り出しとリセット

テキストを組み立て終えたら、`String()`メソッドを呼ぶことで、蓄積された内容をGoの標準的な文字列として取り出せます。
`String()`の呼び出しはとても低コストです。蓄積されたデータをコピーせず、内部のバイトスライスをそのまま文字列として返すからです。

同じビルダーのインスタンスを再利用して、新しい文字列を組み立てたいとき（たとえばループの中）は、`Reset()`メソッドを呼びます。
これで内部のバッファーが空になり、内部的に確保済みのメモリ容量はそのままに、次の文字列を新しく組み立てられます。

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
