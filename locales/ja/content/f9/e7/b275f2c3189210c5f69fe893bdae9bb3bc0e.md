# はじめに

_if/else_文と同じように、`switch`文を使うと、条件によってコードを実行し、プログラムの流れを変えることができます。
違いは、`switch`文が比較できるのは、プリミティブ型や文字列の式の値を、あらかじめ定義された定数の値とだけだという点です。

`switch`文を使うときには、いくつか役に立つキーワードがあります。

- `switch`: このキーワードで、`switch`の構造を宣言します。
  そのあとには、結果を変える式や変数を書きます。
- `case`: このキーワードは、結果としてありうる選択肢を宣言するために使います。
- `break`: 望む流れの終わりで`switch`の実行を止めるには、`break`キーワードがとても役に立ちます。
  忘れてしまうと、プログラムはそのまま続けて実行され、予期しない結果になることがあります。
- `default`: 名前のとおり、ほかのどの`case`も式の結果と一致しないときの、既定の結果として使います。

最も単純な形では、プリミティブ型や文字列の式を判定し、その値に基づいて処理を決めます。
例えば、次のようになります。

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
