# 概要

`null`という値は、値が_存在しない_ことを表すために使います。**null許容型**とは、変数が`null`という値を取れるようにする型のことです。どんな型でもnull許容型にするには、その型を`Null<T>`で包みます。

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

値がそのとき`null`かどうかを確認するには、`if`式を使うだけです。

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
