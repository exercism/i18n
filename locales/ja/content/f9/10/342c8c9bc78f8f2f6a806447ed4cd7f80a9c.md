# はじめに

「クォーテーション」は、`[ ]`という角括弧で囲まれたコードのことです。これは値なので、スタックに積んだり、別のワードに渡したり、配列にしまったりできます。

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

ほとんどの高階ワードは、2番目の引数としてクォーテーションを受け取ります。

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

クォーテーションの中身は、ふつうのFactorコードです。ほかで使っているのと同じ演算子とスタック効果を使います。

データからコードを組み立てるとき、たとえば断片をつなげたりトークンを操作に対応づけたりするときは、結果はシーケンスになります。`>quotation`に通すと呼び出せるようになります。

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
