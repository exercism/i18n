# ヒント

## 1. ピザの値段を計算する

- そのトッピングを追加していないピザの値段に、追加オプション1つ分の値段を足した金額を返す再帰関数を用意しましょう。
- `Maximum call stack size exceeded`エラーが出た場合は、ベースケースを書き忘れていないか確認しましょう。
- `Memory Allocation Error`が出る場合は、トッピングの入力配列を書き換えるのではなく、複製していないか確認しましょう。

## 2. 注文の合計金額を計算する

- `pizzaPrice`を使って、配列内の各ピザの値段を計算し、それを合計に足していきましょう。
- `Maximum call stack size exceeded`エラーが出て、しかも失敗するテストが1つではない場合は、ベースケースを書き忘れていないか確認しましょう。失敗するテストが1つだけなら、ループを使って実装してみましょう！
- `Memory Allocation Error`が出る場合は、入力配列を書き換えるのではなく、複製していないか確認しましょう。
