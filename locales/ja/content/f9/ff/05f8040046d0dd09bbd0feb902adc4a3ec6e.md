# 概要

真偽値の式とは、1つ以上の値に対する問いで、`true`または`false`で答えることができます。
真になる式は`1`を返し、偽になる式は`0`を返します。
また、数値にも真偽値があります。ゼロは`false`で、ゼロ以外は`true`です。

古いCのコードでは、真偽値に`int`型を直接使うか、プログラマーが`TRUE`や`FALSE`のような定数を定義して`1`と`0`を真偽値の表現に対応させていたかもしれません。

C99で`_Bool`型が追加されました。
`stdbool.h`ヘッダーファイルでは、`bool`、`true`、`false`という3つの新しい真偽値のシンボルが定義されています。
`true`は`1`に、`false`は`0`に、`bool`は`_Bool`に対応します。
これでプログラマーは、`int`を直接使ったり、独自の真偽値の対応を自分で作ったりする代わりに、`stdbool.h`をインクルードするだけで、コード内で自動的に真偽値のシンボルを使えるようになりました。

## 比較演算子

Cは6つの比較演算子、`==`（等しい）、`!=`（等しくない）、`>`（より大きい）、`<`（より小さい）、`>=`（以上）、`<=`（以下）に対応しています。
これらの演算子は値同士の関係を比較し、その結果を真偽値として評価します。

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 真偽値演算子

Cは3つの真偽値演算子、`||`（または）、`&&`（かつ）、`!`（否定）に対応しています。

`!`は1つのオペランドと一緒に使います。
オペランドの真偽値を反転させます。
たとえば、`0`は`false`ですが、`!0`は`true`です。

`||`と`&&`は2つのオペランドと一緒に使います。
右側のオペランドが評価されるのは、左側のオペランドだけでは式の結果が決まらないときだけです。
つまり、`||`が右側のオペランドを評価するのは、左側のオペランドが`false`に評価されるときだけです。
`&&`が右側のオペランドを評価するのは、左側のオペランドが`true`に評価されるときだけです。

## 短絡評価

すべてのオペランドを評価しないことを「短絡評価」と呼びます。
短絡評価は、特定の状況を簡潔かつ強力に扱う方法です。
たとえば、ポインターが`NULL`でないことを確認し、（`&&`で）`NULL`でなければそのポインターを逆参照する、というのはよく使われるイディオムです。こうすれば、`NULL`ポインターを逆参照するのを避けられます。
しかし、短絡評価はバグにつながることもあります。
プログラマーが、`||`や`&&`の右側のオペランドが常に評価されるとは限らないことを忘れてしまうことがあります。
右側のオペランドが、常に起きると期待している副作用を持つ式の場合、左側のオペランドの真偽値次第でバグになります。

## 真偽値の式を返す

真偽値の式の結果は、そのまま直接返すことができます。
たとえば、次の`if`文は

```c
if (count > 0)
    return true;
else
    return false;
end
```

次のように置き換えられます。

```c
return count > 0;
```
