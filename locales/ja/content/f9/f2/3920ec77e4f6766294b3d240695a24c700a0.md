Elixirには独自の命名規則があり、その中には[真偽値を返し、ガード節で有効なチェック](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)の名前の付け方も含まれます。

> ガード節で使える型チェックやその他の真偽値チェックには、`is_`の接頭辞を付けます。

こうしたチェックには、組み込み関数、マクロ、ガードなどがあります。

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
なお、ガード節では使えない真偽値を返す関数やマクロは別の規則に従い、末尾に`?`を付けます（`def foo?`、`defmacro foo?`）。2つの規則を混ぜてはいけません。
