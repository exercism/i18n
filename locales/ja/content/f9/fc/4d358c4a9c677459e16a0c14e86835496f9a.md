# 指示

この演習では、お気に入りの料理本をもとに、最高のラザニアを作るためのコードを書いていきます。

ラザニアの調理にかかる時間に関する、5つのタスクがあります。

## 1. オーブンでの焼き時間（分）を定義する

クラス`Lasagna`の`expectedCookTime`関数を実装してください。この関数は引数を取らず、ラザニアをオーブンに入れておくべき時間を分単位で返します。
料理本によると、オーブンでの焼き時間は40分です。

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. 残りの焼き時間（分）を計算する

クラス`Lasagna`の`remainingCookTime`関数を実装してください。この関数は、ラザニアをオーブンに入れておいた実際の時間を分単位で引数に取り、前のタスクで求めたオーブンでの焼き時間をもとに、ラザニアをあと何分オーブンに入れておく必要があるかを返します。

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. 下準備にかかる時間（分）を計算する

クラス`Lasagna`の`totalPreparationTime`関数を実装してください。この関数は、ラザニアに重ねた層の数を引数に取り、1層あたり2分かかるものとして、ラザニアの下準備にかかった時間を分単位で返します。

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. 合計の作業時間（分）を計算する

クラス`Lasagna`の`totalElapsedTime`関数を実装してください。この関数は2つの引数を取ります。1つ目の引数はラザニアに重ねた層の数で、2つ目の引数はラザニアをオーブンに入れておいた時間です。
この関数は、ラザニアの調理に合計で何分かかったかを返します。これは、下準備にかかった時間と、その時点でラザニアをオーブンに入れておいた時間の合計です。

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. ラザニアができたことを知らせる通知を作成する

クラス`Lasagna`の`alarm`関数を実装してください。この関数は引数を取らず、ラザニアが食べごろになったことを知らせるメッセージを返します。

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
