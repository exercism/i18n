# 附加說明

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                                                                               |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0`    | 輸入     | 整數 | 邊 a                                                                             |
| `$a1`    | 輸入     | 整數 | 邊 b                                                                             |
| `$a2`    | 輸入     | 整數 | 邊 c                                                                             |
| `$v0`    | 輸出     | 整數 | 三角形類型（`0` = 不等邊三角形，`1` = 等腰三角形，`2` = 等邊三角形，`3` = 無效） |
| `$t0-9`  | 暫時 | 任意     | 用於暫時儲存                                                         |
