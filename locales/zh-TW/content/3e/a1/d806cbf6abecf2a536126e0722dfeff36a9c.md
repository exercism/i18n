# 簡介

在 C# 中，`string`是一種物件，用來表示不可變的文字，也就是一連串的 Unicode 字元（字母、數字、標點符號等）。定義`string`實例時，會使用雙引號：

```csharp
string fruit = "Apple";
```

字串是透過呼叫它的方法來操作。字串一旦建立後，它的值就永遠不會改變。任何看似修改字串的方法，實際上都會回傳一個新的字串。

多個字串可以串接（相加）在一起，最簡單的方式就是使用`+`運算子。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

如果需要比單純串接更複雜的字串格式處理，建議使用字串插補。若要在字串中使用插補，請在字串前面加上錢字號（`$`），接著就能用大括號（`{}`）存取字串裡的任何變數。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
