# 說明

在這道練習中，你是個超級運動迷，而且剛剛發現自己對 NBA 籃球充滿熱情。由於剛接觸 NBA 籃球，你正深入研究 NBA 的歷史，追蹤球隊、教練以及他們的勝敗戰績，並互相比較。

由於你還沒有最愛的球隊，你也會開發一套演算法，判斷是否該支持某支特定的球隊。

你有七個任務，幫助你開發出自己專屬的「支持某支球隊」演算法。

## 1. 定義模型

定義`Coach`記錄，包含以下兩個欄位：

- `name`：教練的名字，型別為`String`。
- `former_player`：指出這位教練是否曾是球員，型別為`Bool`。

定義`Stats`記錄，包含以下兩個欄位：

- `wins`：勝場數，型別為`Int`。
- `losses`：敗場數，型別為`Int`。

定義`Team`記錄，包含以下三個欄位：

- `name`：球隊的名字，型別為`String`。
- `coach`：球隊的教練，型別為`Coach`。
- `stats`：球隊的統計資料，型別為`Stats`。

## 2. 建立球隊的教練

實作`create_coach`函式，接受教練的名字與他是否曾是球員作為參數，並回傳`Coach`記錄：

```gleam
create_coach("Larry Bird", True)
// -> Coach(name: "Larry Bird", former_player: True)
```

## 3. 建立球隊的統計資料

實作`create_stats`函式，接受勝場數與敗場數作為參數，並回傳`Stats`記錄：

```gleam
create_stats(58, 24)
// -> Stats(wins: 58, losses: 24)
```

## 4. 建立球隊

實作`create_team`函式，接受球隊的名字、教練與記錄作為參數，並回傳`Team`記錄：

```gleam
let coach = create_coach("Larry Bird", True)
let stats = create_stats(58, 24)
create_team("Indiana Pacers", coach, stats)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Larry Bird", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 5. 替換教練

NBA 球隊的老闆沒什麼耐性，你發現球隊戰績不佳時，教練往往會因此被換掉。實作`replace_coach`函式，接受球隊與新教練作為參數，並回傳換上新教練後的球隊：

```gleam
let coach = create_coach("Larry Bird", True)
let record = create_stats(58, 24)
let team = create_team("Indiana Pacers", coach, record)

let new_coach = create_coach("Isiah Thomas", True)
replace_coach(team, new_coach)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Isiah Thomas", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 6. 檢查是否為同一支球隊

在研究統計資料的過程中，你會持續記錄球隊及其戰績的清單。有時候你會出錯，清單上出現重複的項目。實作`is_same_team`函式，接受兩支球隊，若兩者為同一支球隊則回傳`True`，否則回傳`False`：

```gleam
let pacers_coach = create_coach("Larry Bird", True)
let pacers_stats = create_stats(58, 24)
let pacers_team = create_team("Indiana Pacers", pacers_coach, pacers_stats)

let lakers_coach = create_coach("Del Harris", False)
let lakers_stats = create_stats(61, 21)
let lakers_team = create_team("LA Lakers", lakers_coach, lakers_stats)

is_same_team(pacers_team, lakers_team)
// -> False
```

## 7. 檢查你是否該支持某支球隊

看過許多球隊和比賽之後，你想出了一套演算法。若下列其中一項為 True，你就支持那支球隊：

- 教練的名字是 "Gregg Popovich"
- 教練曾是球員
- 球隊的名字是 "Chicago Bulls"
- 球隊贏了 60 場以上的比賽
- 球隊的敗場數多於勝場數

實作`root_for_team`函式，接受一支球隊，若你應該支持該球隊則回傳`True`，否則回傳`False`：

```gleam
let spurs_coach = create_coach("Gregg Popovich", False)
let spurs_stats = create_stats(56, 26)
let spurs_team = create_team("San Antonio Spurs", spurs_coach, spurs_stats)
root_for_team(spurs_team)
// -> True
```
