# 操作說明

你的鎮上有幾間披薩切片店，你想寫一個網頁應用程式，讓你比較兩種不同的披薩配置，看看哪一家給你的切片比較大。

## 1. 撰寫一個計算切片大小的函式，對無效輸入回傳 nil

實作函式`sliceSize(diameter: Double?, slices: Int?) -> Double?`，它會接收披薩的直徑和每個披薩的切片數，並回傳單一切片的面積。
若直徑為負數，或切片數小於 1，請回傳`nil`，因為不存在直徑為負的披薩，也不可能把一個披薩切成少於 1 片。
若任一參數為`nil`，也請回傳`nil`。

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. 處理網頁應用程式的輸入，判斷較大的切片

你的網頁應用程式會傳四個字串給你的函式`biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`。
第一個和第二個字串分別是第一個披薩的直徑和切片數，第三個和第四個則分別是第二個披薩的直徑和切片數。

實作`biggestSlice`，讓它嘗試把每個披薩的直徑和切片數分別轉換成`Double`和`Int`。
如果這兩個值都能從字串取得，就用你的第一個函式試著計算面積，否則該切片的面積就是`nil`。
取得兩個切片的面積後，請用以下規則比較這兩個面積：

1. 如果切片 A 的面積是`Double`，而切片 B 的面積是`nil`，請回傳「Slice A is bigger」。若情況相反，則回傳「Slice B is bigger」。
2. 如果兩個面積都是`Double`，請根據哪個切片的面積較大，回傳「Slice A is bigger」或「Slice B is bigger」。
3. 如果兩個面積都是`nil`，或者兩者都是`Double`且相等，請回傳「Neither slice is bigger」。

~~~~exercism/note
即使輸入算出的切片面積為 0，該切片仍視為有效，且應該被視為比面積為`nil`的切片更大。
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
