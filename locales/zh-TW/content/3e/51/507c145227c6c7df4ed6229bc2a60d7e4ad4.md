## 簡介

指標是一種變數或常數，它的值是另一個變數或常數的位址。指標是 C 語言中一項強大、卻也可能帶來危險的功能。要理解指標，可能不太容易。

變數和常數會把值存放在某個記憶體位置中。那個記憶體位置就稱為該變數或常數的位址。

要取得變數的位址，我們會使用位址運算子，也就是`&`。
```c
int i = 5;
int *i_address = &i;
```

型別後面加上一個`*`，再加上識別碼，就是宣告指向該型別變數的指標的方式。`*`之所以稱為間接運算子，是因為它間接地指向指標所保存位址的那個值。

當我們像這樣建立一個陣列

```c
int my_ints[] = {1, 2};
```

`my_ints`的值其實就是它的位址，而這個位址恰好也與它第一個元素的位址相同。它第二個元素的位址，會是第一個元素的位址加上系統中一個`int`的大小。

這就是指標必須宣告為某種型別的原因。如果指標不知道它指向什麼型別，那麼在對它加上`1`時，它就不知道該前進多少個位元組。對指標加上`1`並不必然代表在位址上加一個位元組，而是代表加上 1 乘上該型別的長度（以位元組為單位）。
