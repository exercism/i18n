# 指令

見習魔術師 Elyse 繼續她的訓練。她會拿到好幾疊牌，需要用來表演魔術。
為了讓事情簡單一些，她只使用 1 到 10 的牌。

在這道練習中，請使用內建方法來分析陣列的內容。

## 1. 找出牌的位置

Elyse 想知道某張牌在牌堆中的位置（索引）。

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. 判斷某張牌是否存在

Elyse 想知道某張牌是否在牌堆中，換句話說，牌堆裡是否包含特定的`number`。

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. 判斷每張牌是否為偶數

Elyse 想知道每張牌是否都是偶數，換句話說，牌堆中的每個數字是否都是偶數`number`。

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. 檢查牌堆中是否有奇數值的牌

Elyse 想知道牌堆中是否有奇數。

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. 取得牌堆中的第一張奇數牌

Elyse 想知道第一張奇數牌的值。

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. 判斷第一張偶數牌的位置

Elyse 想知道第一張偶數牌的位置。

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
