# 簡介

在整個 Julia 學習路徑上，你都需要把自己的解法當作小型函式庫來看待，也就是說，你需要定義函式、型別等東西，之後再讓它們對測試套件執行。
基於這個原因，我們會把具名函式當作第一個概念來介紹。

Julia 是一門動態、強型別的程式語言。
它的程式設計風格以函式式為主，但比 Haskell 這類語言更有彈性。

## 變數與指定

你不需要事先宣告變數。
只要把值指定給合適的名稱就好：

```julia-repl
julia> myvar = 42  # an integer
42

julia> name = "Maria"  # strings are surrounded by double-quotes ""
"Maria"
```

## 常數

如果某個值需要在整個程式中都能取用，但不預期會改變，最好把它標記為常數。

在指定前加上`const`關鍵字，能讓編譯器產生比變數更有效率的程式碼。

常數也有助於保護你免於撰寫程式碼時的錯誤。
如果不小心嘗試修改`const`的值，會出現警告：

```julia-repl
julia> const answer = 42
42

julia> answer = 24
WARNING: redefinition of constant Main.answer. This may fail, cause incorrect answers, or produce other errors.
24
```

請注意，`const`只能在任何函式*外部*宣告。
通常會放在`*.jl`檔案的開頭附近，位於函式定義之前。

## 算術運算子

這些運算子和其他許多語言相同：

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division with floating-point result)
8 % 3  # 2 (remainder)
```

## 函式

在 Julia 中，定義具名函式有兩種常見方式：

1. 使用`function`關鍵字

    ```julia
    function muladd(x, y, z)
        x * y + z
    end
    ```

    為了可讀性，慣例上會縮排 4 個空格，但編譯器會忽略縮排。
    `end`關鍵字是不可或缺的。

    請注意，我們也可以寫成`return x * y + z`。
    不過，Julia 函式一律會回傳最後一個求值的運算式，所以`return`關鍵字是可有可無的。
    許多程式設計師偏好加上它，讓意圖更明確。

2. 使用「指定形式」

    ```julia
    muladd(x, y, z) = x * y + z
    ```

    這最常用來撰寫簡潔的單一運算式函式。

    在指定形式中，*絕對不會*使用`return`關鍵字。

這兩種形式是等價的，用法完全相同，所以挑你覺得比較好讀的就好。

呼叫函式時，要寫出函式名稱，並為函式的每個參數傳入引數：

```julia
# invoking a function
muladd(10, 5, 1)

# and of course you can invoke a function within the body of another function:
square_plus_one(x) = muladd(x, x, 1)
```

## 命名慣例

和許多語言一樣，Julia 要求名稱（變數、函式，以及許多其他東西的名稱）必須以字母開頭，後面可以接字母、數字和底線的任意組合。

依照慣例，變數、常數和函式的名稱使用*小寫*，並盡量把底線減到合理的少量。
