# 簡介

**詞**是 Factor 對函式的稱呼。這個概念延續`basics`的資料堆疊，要談的是定義自己的詞：做算術、為固定值命名，以及用其他詞組合成新的詞。

一個定義以`:`開頭，接著是堆疊效應，然後是本體，最後以`;`結束。編譯器會檢查本體是否符合宣告的效應：

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

整數算術詞`+`、`-`、`*`各自會彈出兩個數字並推入結果。它們位於`math`詞彙中，所以用到它們的檔案必須在`USING:`那一行加上`math`。堆疊頂端是右邊的運算元：

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:`為固定值命名。常數本身也是一個詞，呼叫它就會把值推入堆疊：

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

詞的本體可以呼叫任何已在作用域中的詞，包括你在同一個檔案裡先前定義的詞：

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

輸出結尾的`?`是代表「布林值」的慣例，而詞和常數都採用`lowercase-kebab-case`。
