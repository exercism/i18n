# 指令

在這個練習中，你將為一間美容沙龍開發預約排程系統。

你有三個任務，全都與預約日期有關。

## 1. 檢查預約是否已經過去

實作 `appointment_has_passed` 副程式，它接受一個日期字串，並檢查該預約是否發生在過去：

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

日期字串會以 ISO 8601 日期時間格式傳入：`YYYY-mm-ddTHH:MM:SS`

你需要實作私有的 `_parse_datetime` 副程式。
這裡建議了幾個模組：

- [Time::Piece][time-piece] 是 Perl 的核心模組。
- [DateTime::Tiny][datetime-tiny] 可從 CPAN 取得。

## 2. 檢查預約是否在下午

實作 `is_afternoon_appointment` 函式，它接受一個日期字串，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. 描述預約的時間與日期

實作 `describe_appointment` 函式，它接受一個日期字串，並回傳該日期與時間的描述：

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

請注意，小時的範圍是 0 到 12，而且不會有前導零或空格。

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
