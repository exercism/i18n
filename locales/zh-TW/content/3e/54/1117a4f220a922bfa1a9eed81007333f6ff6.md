# 測試

如果你是用 CLI 工具下載練習，應該會看到一個以該練習命名的 Uiua 檔案，以及一個`tests.ua`檔案。
這個檔案包含所有測試案例，和你上傳解答時線上執行的測試相同。
你可以自由新增額外的測試案例來做實驗喔。
不過，修改測試並不會影響線上測試的流程。

## 在本機測試

如要執行某個練習的測試，請在該練習的目錄中開啟終端機，然後執行`uiua test tests.ua`指令。

舉例來說，未經修改的`hello-world`練習，輸出可能長這樣：

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

`Error`這一行會顯示你程式碼的實際輸出。
行號則指出預期結果在`tests.ua`裡的位置。
解答正確時，會顯示：

```bash
$ uiua test tests.ua
Test passed
```
