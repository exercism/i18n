# 簡介

## 布林值

Java 中的布林值以 `boolean` 型別表示，其值可以是 `true` 或 `false`。

Java 支援三種布林運算子：  

- `!`（NOT）：將布林值反轉  
- `&&`（AND）：接受兩個布林值，若兩者皆為 `true`，就回傳 `true`
- `||`（OR）：兩個布林值中只要有一個是 `true`，就回傳 `true`

### 範例

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
