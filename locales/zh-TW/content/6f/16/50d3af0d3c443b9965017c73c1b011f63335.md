# 補充說明

這個練習要求你處理例外。[例外](https://docs.oracle.com/javase/tutorial/essential/exceptions/definition.html)是指程式執行期間發生、會打斷程式指令正常流程的事件。

在 Java 中，例外分成兩種類型：受檢例外與非受檢例外。

- [Java 中的受檢例外與非受檢例外](https://www.geeksforgeeks.org/checked-vs-unchecked-exceptions-in-java/)

- [非受檢例外：爭議](https://docs.oracle.com/javase/tutorial/essential/exceptions/runtime.html)

## 受檢例外

受檢例外是會在[編譯時期](https://en.wikipedia.org/wiki/Compile_time)接受檢查的例外。

### 實務上的影響

任何可能[拋出](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)受檢例外的方法，你都必須在它的[方法簽章](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html)中宣告，並且在呼叫任何可能拋出受檢例外的方法時處理或重新拋出它們。

這是因為受檢例外應該在執行時期處理，也就是說，它們是你能夠從中復原的錯誤。

### 使用時機範例

當方法無法回傳任何有效結果時，經常會用到它們；例如搜尋方法找不到它正在尋找的項目時。

這是回傳 null 或錯誤碼以外的另一種選擇。受檢例外比這些替代方案更好，因為它強制方法的使用者去考慮錯誤的情況。

## 非受檢例外

非受檢例外是不會在[編譯時期](https://en.wikipedia.org/wiki/Compile_time)接受檢查的例外。

### 實務上的影響

對於可能[拋出](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)非受檢例外的方法，你不必在它們的[方法簽章](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html)中宣告，也不必在呼叫任何可能拋出非受檢例外的方法時處理或重新拋出它們。

### 使用時機範例

非受檢例外通常是由程式中的瑕疵所造成，可以透過良好的程式撰寫習慣來避免。例如： ArrayIndexOutOfBoundsException 可以藉由確保陣列索引介於 0 和陣列的長度之間來避免。
