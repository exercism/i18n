# 安裝

## 安裝 .NET

F# 軌道是以 [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) 平台為基礎打造的，該平台可在 Windows、Linux 與 macOS 上執行。若要建置 .NET 專案，你可以使用 .NET 命令列介面（CLI）。這個 CLI 是 .NET SDK 的一部分，你可以依照[安裝指示](https://dotnet.microsoft.com/download)來安裝。注意：F# 軌道需要 8.0 以上版本的 SDK。

完成安裝後，你可以在終端機執行以下指令，確認 CLI 是否安裝成功：

```bash
dotnet --version
```

如果輸出是`8.0.100`或更高的版本，就代表 .NET SDK 安裝成功。

## 使用 IDE

如果你想要功能更完整的編輯體驗，大概會想使用 IDE。以下是支援建置 .NET 專案、最受歡迎的幾個 IDE：

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) 搭配 [Ionide-fsharp 擴充功能](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

注意：.NET 專案格式與早期版本有顯著差異，因此不支援較舊的 IDE（例如 Visual Studio 2015）。
