# 簡介

出自[手冊][man-types]

> jq 支援與 JSON 相同的一組資料型態，包括數字、字串、布林、陣列、物件（用 JSON 的說法，就是只能用字串當鍵的雜湊），以及 `null`。

我們把重點放在**數字**上。

## 數字與數值運算子

所有的數字，不論是不是整數，都是 IEEE754 雙精度浮點數。這讓我們只能精確到 53 位元。

數字可以搭配一般常見的運算子：

- 算術：`+`、`-`、`*`、`/`、`%`
- 比較：`==`、`!=`、`<`、`<=`、`>=`、`>`
- 標準的[數學函式][man-math]

  針對單一輸入的函式，用管線把值傳進函式

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  針對雙輸入的函式，這些函式會忽略輸入，並預期把值當成參數傳入（還記得嗎？參數之間是用分號分隔的）

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  函式引數的分隔符號是分號，不是逗號。

## 其他`jq`運算式

要解這道練習，你需要認識條件運算式。

### 條件運算式

`jq`使用[`if-then-else`運算式][if-then-else]來表示**條件運算式**。
它是一個*運算式*，所以要放在管線裡。

語法如下：`if CONDITION then TRUE_EXPR else FALSE_EXPR end`。

`else`子句可以省略。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

需要額外條件時，可以使用`elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
