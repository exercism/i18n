# 資源

除了[學習][learning]資源之外，這裡還有一些地方，可以在你學習 Odin 的過程中幫助你：

* [Odin playground][play]，直接在瀏覽器裡動手試試看。
* [odin-lang/Odin][gh] GitHub 儲存庫。
* Odin 的[社群][community]連結（論壇、Discord、Reddit 等）。
* Odin 創作者 gingerBill 撰寫的[文章][articles]。
  這些文章能讓你一窺這門語言的設計原則。
* [風格指南][style]。
* [Awesome Odin][awesome]，Odin 函式庫與資源的連結集合。
* 一系列關於 Odin 以及如何用它開發遊戲的[影片][vids]。
  作者是 Karl Zylinski，也就是《Understanding Odin》這本書的作者。
