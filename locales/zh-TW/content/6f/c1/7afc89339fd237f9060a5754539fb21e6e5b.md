# 安裝

## 系統需求

* 64 位元的 x86 CPU
* 新版的 C 編譯器
* Make 建置工具
* Netwide 組譯器（NASM）

請注意，這個 track 只支援 System V AMD64 ABI 的呼叫慣例。Windows 使用者需要安裝 Windows Subsystem for Linux（WSL），或設定一台 Linux 虛擬機器。

## Linux

使用系統的套件管理員安裝所需的軟體：

* Ubuntu、Debian：`$ sudo apt-get install gcc make nasm`
* Fedora：`$ sudo dnf install gcc make nasm`
* CentOS、RHEL：`$ sudo yum install gcc make nasm`
* Arch Linux：`$ sudo pacman -S gcc make nasm`
* OpenSUSE：`$ sudo zypper install gcc make nasm`

## macOS

安裝 Xcode Command Line Tools：

```bash
$ xcode-select --install
```

使用 [Homebrew](http://brew.sh/) 安裝 NASM：

```bash
$ brew install nasm
```

## Windows

若要安裝 WSL，請參閱 https://docs.microsoft.com/en-us/windows/wsl/install-win10。
