# 提示

## General

- 函式就只是記憶體位址，可以像任何記憶體位址一樣操作。
- 記憶體位址是 64 位元的整數值，透過平常的暫存器傳入與回傳。
- 可以`call`或`jmp`到儲存在暫存器或記憶體中的函式。

## 1. 記住一筆交易

- 函式就只是記憶體位址，可以像任何記憶體位址一樣操作。
- 記憶體位址是 64 位元的整數值，透過平常的暫存器傳入與回傳。
- `remember_transaction`應該把函式儲存在一個持久的記憶體位置。
- 在`apply_remembered`裡，要傳給已儲存函式的引數已經放在正確的暫存器（`rdi`）中。

## 2. 銀行的操作手冊

- 分派表就只是一個陣列，可以像任何陣列一樣索引。
- 分派表中的每個項目都是一個函式，而函式是 64 位元（8 位元組）的整數值。
- 在`select_transaction`裡，交易的引數原本放在`rdx`，需要在呼叫函式前搬到`rdi`。
- 對分派交易的呼叫位於尾端位置，所以你可以使用尾呼叫（`jmp`）。

## 3. 處理月結單

- 陣列中的每個項目都是一個函式，而函式是 64 位元（8 位元組）的整數值。
- 任何呼叫者儲存的暫存器都可能被外部函式覆寫，所以在呼叫這類函式前，你應該先保存任何必要的值。
  呼叫者儲存的暫存器有`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10`和`r11`。
- 被呼叫者儲存的暫存器，例如`rbx`、`rbp`、`r12`、`r13`、`r14`和`r15`，不會被呼叫的函式修改。
  不過，你需要在使用它們之前先保存原始值，並在回傳前還原該值。
- 在呼叫外部函式前，堆疊應該對齊到 16 位元組。
  進入函式時，`rsp`比 16 的倍數少 8。
- 對於空陣列，不會套用任何交易，函式應該回傳未改變的起始餘額。

## 4. 加上防護條件來處理

- 陣列中的每個項目都是一個函式，而函式是 64 位元（8 位元組）的整數值。
- 任何呼叫者儲存的暫存器都可能被外部函式覆寫，所以在呼叫這類函式前，你應該先保存任何必要的值。
- 被呼叫者儲存的暫存器，例如`rbx`、`rbp`、`r12`、`r13`、`r14`和`r15`，不會被呼叫的函式修改。
  不過，你需要在使用它們之前先保存原始值，並在回傳前還原該值。
- 在呼叫外部函式前，堆疊應該對齊到 16 位元組。
  進入函式時，`rsp`比 16 的倍數少 8。
- 防護函式會接收每筆交易的結果作為引數。
  這個值必須在呼叫防護函式前放進`rdi`。
- 防護函式對無效的結果回傳`0`，對有效的結果回傳非零值。
  有效的結果會更新累計餘額與已核准交易的數量。
- 函式回傳兩個 64 位元非負整數：最終餘額應放在`rax`，已核准交易的數量應放在`rdx`。
