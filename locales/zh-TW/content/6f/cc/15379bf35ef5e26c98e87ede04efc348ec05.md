# 簡介

集合的定義通常會在角括號中包含一個佔位符，依慣例通常是 T。這種集合就稱為泛型型別。這讓集合的使用者可以指定要在集合中儲存哪種型別的項目。在上述範例程式碼中，我們實例化了一個字串陣列。

讓類別或函式變成**泛型**的方式，是使用`@:generic`屬性。這會讓編譯器將該類別或函式辨識為泛型：

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
