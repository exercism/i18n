# 指示

你的任務是：給定一張圖，判斷幼兒園班級裡每個小朋友負責照顧哪些植物。

班上有 12 個小朋友：

- Alice、Bob、Charlie、David、Eve、Fred、Ginny、Harriet、Ileana、Joseph、Kincaid 和 Larry。

這裡種了 4 種不同的種子：

| 植物   | 圖中的編碼 |
| ------ | ---------- |
| 草     | G          |
| 三葉草 | C          |
| 蘿蔔   | R          |
| 紫羅蘭 | V          |

每個小朋友分到 4 個杯子，每一排 2 個：

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

老師會依照小朋友名字的字母順序分配杯子，所以 Alice 排在最前面，Larry 排在最後。

以下是 Alice 的植物範例圖：

```text
[window][window][window]
VR......................
RG......................
```

第一排最靠近窗戶，她有一株紫羅蘭和一株蘿蔔。第二排則有一株蘿蔔和一些草。

你的程式會收到植物的排列，從最靠近窗戶的那一排開始，由左到右讀取。根據這些資訊，它就能判斷哪些植物屬於哪個小朋友。

舉例來說，如果告訴它花園長這樣：

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

那麼問到 Alice 的植物時，它應該給出：

- Violets, radishes, violets, radishes

而問到 Bob 的植物時，則會得到：

- Clover, grass, clover, clover
