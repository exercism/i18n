# 簡介

[`Set`][set] 是一種項目集合，具有以下特性：

- 無序。
- 項目是唯一的，因此嘗試加入重複項目時會被默默忽略。
- 支援許多數學集合常見的運算。

用 `Set()`建構子來建立，並以任何疊代器作為參數。

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

用 `push!()`加入新元素（和陣列一樣），並用 `delete!()`移除元素。

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## 集合運算

和其他幾種集合型別一樣，用 `in` 或 `∈` 運算子來檢查成員資格（先輸入 `\in` 再按 tab 即可打出這個符號）。

```julia-repl
julia> 3 ∈ s1
true
```

以下支援這些針對成對 Set 的運算（括號中顯示的是運算子符號的快速鍵）。

- `union(A, B)` 或 `A ∪ B`（`\cup`）：A 或 B 或兩者中的所有項目。
- `intersect(A, B)` 或 `A ∩ B`（`\cap`）：A 和 B 共同擁有的所有項目。
- `setdiff(A, B)`（無符號）：在 A 但不在 B 的項目。
- `symdiff(A, B)`（無符號）：在 A 或 B 其中一個但不在兩者的項目。
- `issubset(A, B)` 或 `A ⊆ B`（`\subseteq`）或 `B ⊇ A`（`\supseteq`）：如果 A 中所有項目也都在 B 中，則為 `true`。
- `issetequal(A, B)`（無符號）：如果 A 和 B 含有完全相同的項目，則為 `true`。
- `isdisjoint(A, B)`（無符號）：如果 A 和 B 沒有共同項目（也就是交集為空），則為 `true`。

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

這些運算中有許多也有會直接修改原集合的版本，就是在函式名稱後加上 `!`。
完整的函式清單請參閱[手冊][set]。
