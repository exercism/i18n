# 指令補充

## 棋盤格式

棋盤以一個以 null 結尾的字串表示，每一列的結尾都有一個換行字元。

例如 `"X  \n XO\nOX \n"`

## 暫存器

| 暫存器  | 用途        | 型別    | 說明                                                             |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | 輸入        | 位址 | 以 null 結尾的輸入字串                                            |
| `$v0`    | 輸出       | 整數 | 遊戲狀態 (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | 暫存    | 任意     | 用於暫存資料                                                   |
