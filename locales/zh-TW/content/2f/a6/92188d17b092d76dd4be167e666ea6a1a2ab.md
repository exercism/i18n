# 簡介

C 是一種靜態型別的語言，意思是所有東西在編譯時就具有型別。為變數取名字並設定它的型別，這個過程稱為宣告變數。

宣告變數時必須明確指定它的型別。變數名稱必須以字母或底線開頭。有些名稱不能使用，因為它們被保留給[關鍵字][reserved-keywords]或[其他識別字][reserved-identifiers]。

設定或更新變數是透過變數賦值來完成。設定值就定義了該變數。定義變數也稱為初始化。

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

變數的值可以使用`=`簡單賦值運算子來指定和更新。一旦定義之後，變數的型別就永遠不會改變。

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C 是一種命令式程序語言。所有運算都是以一連串的敘述來進行，而這些敘述是某個函式或多個函式的一部分。

每個函式可以有零個或多個參數。定義函式時，所有參數和回傳值都必須明確標註型別。值透過`return`關鍵字從函式回傳。函式預設具有外部儲存類別，意思是它會在程式的整個生命週期內存在，並且可以在檔案外部被看見。若要避免這種情況，可以加上`static`關鍵字來指定內部可見性。

```c
static int add(int x, int y) {
  return x + y;
}
```

在上述範例中，變數`x`和`y`只能在函式內使用，也就是說，它們具有函式作用域。作用域指的是這樣的概念：與某個名稱（程式元素的名稱）相關聯的值，只能在定義它的程式碼「區域」內存取。C 中主要的程式碼區域有：

- 檔案
- 函式
- 程式區塊（例如迴圈和其他結構內）

呼叫函式時，需要指定函式名稱，並為每個函式參數傳入引數。

```c
int sum = add(1, 2);
```

C 支援兩種註解。單行註解以`//`開頭（從 C99 開始），多行註解則插入在`/*`和`*/`之間。
