# golint 未通過

有一個很棒的工具叫做[`golint`](https://github.com/golang/lint)，它會檢查程式碼裡常見的問題和風格問題。
對你的解法執行`golint`，例如：`golint two_fer.go`，它會提供一些有用的建議。

隨時用`golint`檢查程式碼是個好習慣喔。
在為正式環境撰寫 Go 軟體時，許多建置管線只要程式碼沒有通過`golint`，就會自動失敗。

如果你想從檢查工具獲得更多回饋，可以參考 [golangci-lint](https://github.com/golangci/golangci-lint) 這個專案，它讓你用一個指令就能執行許多檢查工具。
專案的設定檔可以依照專案的需求調整它的行為。

```
> golint
%{golint}
```
