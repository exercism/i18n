# 簡介

## 字串

C# 中的`string`是一個物件，用來表示不可變的文字，也就是一連串的 Unicode 字元（字母、數字、標點符號等等）。雙引號用來定義`string`實例：

```csharp
string fruit = "Apple";
```

### 方法

字串可以透過呼叫它的[內建方法][docs-string-methods]來操作。
例如，要移除字串中的空白，可以像這樣使用 [Trim 方法][tutorial-docs.microsoft.com-trim-white-space]：

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

字串一旦建立，它的值就永遠不會改變。
任何看似修改字串的方法，實際上都會回傳一個新的字串。

### 串接

多個字串可以串接（相加）在一起。最簡單的做法是使用`+`運算子。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### 格式化

只要字串格式化的需求比單純串接更複雜，就建議改用字串內插。要在字串中使用內插，請在字串前面加上錢字號（`$`）。接著就能用大括號（`{}`）存取字串中的任何變數。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
