# Test Runner

Test Runner 是一套軟體，用來針對學生的程式碼執行練習的測試。

Test Runner 為我們帶來兩項好處：

1. 它讓瀏覽器內寫程式成為可能，學生可以一邊反覆修改解法，一邊看到測試通過或失敗。
2. 它讓我們能提供資訊給導師，說明學生的程式碼是否「能運作」。

## 為 Test Runner 貢獻

每個程式語言都有自己的 Test Runner，而且是用該語言寫成的。
網站則扮演 Test Runner 與學生提交內容之間的協調者。

每個 Test Runner 都位於 Exercism GitHub 組織中一個名為 `<track_slug>-test-runner` 的儲存庫裡（例如 [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)）。
你可以[在這裡](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories)查看現有的 Test Runner。

如果你想協助現有的 Test Runner，請在它的儲存庫開一個 issue，問問有沒有什麼地方可以幫忙。
如果你想為目前還沒有 Test Runner 的語言建立一個，請依照[建立 Test Runner](/docs/building/tooling/test-runners/creating-from-scratch)的說明進行。
