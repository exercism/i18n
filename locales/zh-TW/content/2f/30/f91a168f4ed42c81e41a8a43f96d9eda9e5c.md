# 簡介

還記得基礎概念單元提過嗎？AWK 程式是由**模式與動作配對**組成的。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## 「模式」是什麼意思？

「模式」可以是任何 AWK 運算式。
運算式結果的真假，決定了動作是否會被執行。

## 空模式

模式可以省略。
在這種情況下，動作會對每一筆記錄執行。

我們可以印出 passwd 檔案裡所有的使用者名稱。

```sh
awk -F: '{print $1}' /etc/passwd
```

## 正規表達式

AWK 可以把字串和正規表達式相比對，取得布林結果。

用 `~` 這個正規表達式比對運算子來比對特定的欄位。
這個運算子的左運算元是字串，右運算元是正規表達式。
正規表達式的字面值會用 `/` 斜線包住。

要找出 passwd 檔案中以 bash 登入的使用者：

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` 是「正規表達式**不**相符」的運算子。

要比對目前這一筆記錄是否符合某個正規表達式，可以寫成 `$0 ~ /regex/`。
這種寫法太常見了，所以有簡寫：你可以省略 `$0` 和 `~`，直接寫 `/regex/`。

```sh
awk '/regex/' data.txt
```

## 運算式

AWK 的運算式（不論是算術、邏輯或其他）都可以當作模式使用。

要取出所有 UID 為 1000 以上的使用者：

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

回想一下，AWK 的 false 值是數字零和空字串，其他所有數字或字串都是 true。
任何可以算出數字或字串的運算式，都能當作模式使用。

## 函式

任何[內建][builtins]或[使用者自訂][user-defined]的函式都可以用在運算式裡，因此也能用在模式裡。
幾個例子：

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## 常數模式

AWK 常見的慣用寫法是：

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` 是一個結果為真、而且沒有對應動作的模式。
它的意思是「印出目前這一筆記錄」。
