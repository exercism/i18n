## 選擇性引數

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

等同於

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

在 REPL 的回應中，你可以看到第一個定義同時定義了兩個方法。
