# 簡介

關鍵字陣列是一種鍵值資料結構。

```elixir
[month: "April", year: 2018]
```

關鍵字陣列是`{key, value}`元組的陣列，也可以寫成這種形式，不過較短的語法更廣為使用。

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

關鍵字陣列中的鍵必須是原子，但值可以是任何東西。同一個鍵可以使用超過一次。關鍵字陣列中的鍵值對是有順序的。

你可以用處理陣列的相同方式來操作關鍵字陣列，也可以使用`Keyword`模組。
