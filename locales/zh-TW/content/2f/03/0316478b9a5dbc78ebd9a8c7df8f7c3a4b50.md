# 關於

- Pony 是靜態型別的。這表示你*必須*事先定義程式中資料的型別。如果你告訴 Pony 變數`x`是整數，就不能把字串指定給它。
- Pony 的型別系統正是 Pony 這些保證得以成立的原因。
  - 如果你的程式能編譯，它就不會當掉。
  - 永遠不會有未處理的例外。
  - Pony 根本沒有`null`這種東西，所以你的程式永遠不會試圖解引用`null`。
  - 永遠不會有資料競爭。
  - 永遠不會發生死鎖。
  - 你的程式碼永遠具備能力安全（可防範供應鏈攻擊）。
- Pony 不允許你做型別轉換。所有的型別變更都必須透過函式來完成，由函式建立新型別的新實例。
- Pony 的型別系統和大多數其他語言都不一樣，所以我們會把它拆成一小塊一小塊來介紹。

## Primitives

- Primitives 是 Pony 中最簡單的程式組織形式。
  - 你可以把它想成一個容器，或函式的命名空間。
  - 它沒有欄位（欄位是類別的事）。
  - 它用`primitive`這個關鍵字定義。

## 函式

- 函式用`fun`關鍵字定義。
  - 函式必須住在`primitive`裡（或`class`、`actor`，這些之後會再介紹）。
  - 函式可以有傳入的引數，也會有回傳值。這些都必須有型別。
  - 如果你定義了回傳型別，你的函式*就必須*回傳該型別的值。Pony 沒有 Null 這種概念。

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## 註解

註解可以用來留下筆記、提醒，或只是暫時把程式碼從原始碼中移除。就像你上面已經看到的，單行註解使用`//`。多行註解使用 C 風格的`/*`和`*/`。

## 變數

- 變數一律以小寫字母開頭。
  - 我們會用`var`來宣告。（`let`和`embed`之後會再介紹）。
  - 如果 Pony 能判斷變數的型別，它就會幫你處理。
  - 變數的型別會在編譯期檢查，而且永遠不會改變。
  - 剛開始學 Pony 時，我們建議明確寫出型別。

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
