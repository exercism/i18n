# 關於

C# 中主要的物件導向建構單元是_類別_，它是資料（[_欄位_][fields]）與行為（[_方法_][methods]）的組合。類別的欄位與方法稱為它的_成員_。

成員的存取可以透過存取修飾詞加以限制，最常見的兩種是：

- [`public`][public]：任何程式碼都能存取這個成員（沒有限制）。
- [`private`][private]：只有同一個類別內的程式碼能存取這個成員。

依照慣例，所有成員都應該明確指定存取修飾詞。如果沒有指定存取修飾詞，就會預設為 `private`。

上述把相關的資料與行為群組在一起，並限制成員的存取，這種做法稱為[封裝][encapsulation]，是物件導向的核心概念之一。

物件在某個時間點的所有欄位值組合，稱為該物件的[狀態][object-state]。

你可以把類別想成是建立該類別執行個體的範本。要[建立類別的執行個體][creating-objects]（也就是_物件_）時，需使用 [`new`關鍵字][new]：

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

[欄位][fields]具有型別，可以在類別中的任何位置定義。
公開欄位以 [PascalCase][pascal-case] 命名，私有欄位則以 [camelCase][camel-case] 命名，並在前面加上底線 `_`：

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

你可以選擇性地為欄位指定初始值。如果欄位_沒有_指定初始值，就會被設為其型別的[預設值][default-values]。執行個體的欄位值可以用點記法存取與更新。

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

私有欄位通常是呼叫方法時的副作用而一併更新。這類方法通常不會回傳任何值，此時回傳型別應該是 [`void`][void]：

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

請注意，在 C# 類別中使用公開欄位並不常見。通常會使用私有欄位，或是其他種類的成員，這些會在後續的練習中討論。

在類別內，[`this`關鍵字][this]會指向目前的類別。當參數與欄位同名時，這特別有用：

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

類別與方法的結構提供了一種自然的方式，來限制欄位、方法等程式元素的可見性，並避免惡名昭彰的[全域狀態問題][so-global-state-problem]。若要讓類別外的程式碼看見公開欄位、方法與其他成員，必須加上物件名稱來限定，也就是 `object.field` 或 `object.method()`（靜態成員則用類別名稱）。在方法內宣告的變數與參數，只有該方法內看得見。

這種做法要留意一點：如果欄位名稱與方法中某個變數或參數的名稱相同，方法內的程式碼就會忽略該欄位，這可能不是你想要的结果。一般來說，應該盡量避免這種情況，雖然它在建構函式中是很常見的模式。如果欄位與變數同名是合理的，就在方法內用 `this`關鍵字來限定欄位名稱。

這些[存取修飾詞][access-modifiers]可以用來進一步限制可見性。
