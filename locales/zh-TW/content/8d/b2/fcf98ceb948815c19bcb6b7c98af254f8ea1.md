# 指令

你的朋友 Linus 是一名火車駕駛員，負責在城市之間駕駛貨運列車。雖然他很會操作列車，卻不太擅長處理物流或電腦。他想請你發揮程式設計的專長，幫他整理列車的詳細資料，並修正路線資料中的錯誤。

~~~~exercism/note
這道練習用切片、索引和各種`Dict`方法就能輕鬆解決。不過，我們希望你練習用打包（也就是 slurping）、解包（也就是 splatting）和多重賦值來完成下面每一項任務。
~~~~

## 1. 建立包含所有車廂的向量

你的朋友一直記錄著每個車廂的識別碼（ID），但他永遠不確定系統在任何時間點需要處理多少個車廂。如果把這些資料打包成一個統一的`Vector`，物流程式的其他部分就會輕鬆許多。

請實作一個函式 `get_vector_of_wagons(args...)`，接受任意數量的車廂 ID。每個 ID 都是正整數。函式接著要以單一`Vector`的形式`return`這些 ID。

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. 修正車廂的向量

到這裡，你已經開始熟悉這些資料，以及物流程式如何使用它們。ID 系統一律把火車頭的 ID 指定為**1**，列車中其餘車廂則隨機分配一個大於**1**的 ID。

你的朋友把兩節新車廂接上列車，卻忘了更新系統！現在，列車`Vector`中的前兩節車廂必須移到最後面，否則整個順序都會亂掉。

更麻煩的是，你的朋友剛發現了第二個`Vector`，裡頭似乎包含遺漏的車廂 ID。他只記得，在新車廂移動之後，第二個`Vector`裡的 ID 應該直接放在指定火車頭的正後方。

如果你能幫 Linus 修正錯誤並整合資料，他會非常感激。

請實作一個函式 `fix_vector_of_wagons(each_wagons_id, missing_wagons)`，接受兩個包含車廂 ID 的`Vectors`。它要把第一個`Vector`的前兩個項目移到最後面，並把第二個`Vector`的值插入火車頭 ID（**1**）的後方（_也就是在它的右側_）。函式接著要`return`一個修改後的`Vector`。

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. 新增遺漏的停靠站

既然所有車廂資料都正確了，Linus 希望你更新系統的路線資訊。在一條運輸路線上，列車可能會在幾個不同的車站停靠，上下貨物。每一趟旅程的中途交貨點數量都可能不同。你的朋友希望你用任何遺漏或額外的送貨資訊來更新系統的路線`Dict`。

請實作一個函式 `add_missing_stops(route, stops...)`，接受一個路線`Dict`，後面接著數量不定的 `stop_number => city` Pair。你的函式接著要回傳更新後的路線`Dict`，其中多了一個`key`，內含依序排列所有新增停靠站的`Vector`。

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. 擴充路線資訊

Linus 一直在開發路線程式，並注意到某些路線缺少了一些重要細節。初始的路線資訊是以`Dict`建構的，你的朋友希望你把所有可能遺漏的內容都更新進那個`Dict`。系統中每條路線需要的細節都略有不同，所以 Linus 比較偏好通用的解法。

請實作一個名為 `extend_route_information(route; more_route_information...)` 的函式，它接受一個`Dict`，內含列車路線起點與終點的城市，再加上數量不定的關鍵字引數，包含列車速度、長度或溫度等路線細節。函式要回傳一個整合所有路線資訊的`Dict`。

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
