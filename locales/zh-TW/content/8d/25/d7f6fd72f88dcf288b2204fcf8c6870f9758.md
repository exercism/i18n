# 指令

在這道練習裡，你可以玩玩一台遙控車，你終於存夠錢把它買下來了。

遙控車一開始的電量都是滿的（100%）。每次你用遙控器駕駛這台車，它就會前進 20 公尺，並消耗 1% 的電量。這台車的暱稱要等到建立之後才會知道。

這台遙控車有個炫麗的 LED 顯示器，會顯示兩項資訊：

- 它總共行駛的距離，顯示為：`"<METERS> meters"`。
- 剩餘的電量，顯示為：`"Battery at <PERCENTAGE>%"`。

如果電量剩下 0%，你就不能再駕駛這台車，電池顯示器會顯示 `"Battery empty"`。

## 1. 建立一台全新的遙控車

實作`RemoteControlCar.new/0`函式，回傳一個全新的遙控車 struct：

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

struct 必須要有暱稱，請確保在`new`函式中初始化這個值，而不是在 struct 裡。

## 2. 建立一台帶有暱稱的全新遙控車

實作`RemoteControlCar.new/1`函式，回傳一個帶有指定暱稱的全新遙控車 struct：

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. 顯示距離

實作`RemoteControlCar.display_distance/1`函式，回傳 LED 顯示器上顯示的距離：

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

請確認這個函式只接受`RemoteControlCar` struct 作為引數。

## 4. 顯示電量百分比

實作`RemoteControlCar.display_battery/1`函式，回傳 LED 顯示器上顯示的電量百分比：

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

請確認這個函式只接受`RemoteControlCar` struct 作為引數。如果電量剩下 0%，電池顯示器會顯示 "Battery empty"。

## 5. 駕駛會改變電量與行駛距離

實作`RemoteControlCar.drive/1`函式，它會：

- 將行駛距離增加 20 公尺
- 消耗 1% 的電量

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

請確認這個函式只接受`RemoteControlCar` struct 作為引數。

## 6. 處理電池沒電時的駕駛行為

更新`RemoteControlCar.drive/1`函式，讓電池耗盡（0%）時，既不增加行駛距離，也不減少電量百分比：

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
