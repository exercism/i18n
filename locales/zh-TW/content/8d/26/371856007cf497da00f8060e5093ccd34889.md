# 指令

你和朋友們很喜歡玩桌上角色扮演遊戲，但你發現要讓新朋友加入你們的團並不容易。他們常常在建立角色時卡關，不知道該從哪裡開始。為了幫助新手，你決定寫一個小程式，引導他們完成整個流程。

## 1. 歡迎新玩家

實作`RPG.CharacterSheet.welcome/0`函式。它應該印出歡迎訊息，並回傳`:ok`。

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. 詢問角色的名字

實作`RPG.CharacterSheet.ask_name/0`函式。它應該印出一個問題，等待玩家輸入，並回傳去掉前後空白的答案。

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. 詢問角色的職業

實作`RPG.CharacterSheet.ask_class/0`函式。它應該印出一個問題，等待玩家輸入，並回傳去掉前後空白的答案。

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. 詢問角色的等級

實作`RPG.CharacterSheet.ask_level/0`函式。它應該印出一個問題，等待玩家輸入，並把答案以整數回傳。

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. 把前面的步驟組合成一個

實作`RPG.CharacterSheet.run/0`函式。它應該歡迎新玩家，依序詢問角色的名字、職業和等級，並把角色卡以 map 的形式回傳。它還應該印出這張 map，並加上「Your character」這個標籤。

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
