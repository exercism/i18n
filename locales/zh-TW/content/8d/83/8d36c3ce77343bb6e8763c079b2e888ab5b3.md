# 說明

你是個熱愛賞鳥的人，會記錄每天有多少鳥兒造訪你的花園。

你決定把賞鳥提升到新的層次，實作一些工具來幫助你追蹤和處理這些資料。

你選擇把資料存成一個整數的陣列。
陣列中的第一個數字是今天造訪你花園的鳥數，第二個是昨天的，依此類推。

```exercism/note
在真實世界的應用中，只要情況允許，你應該一律使用核心模組；不過為了學習遞迴，這個練習中請不要使用任何`List`的函式。
```

## 1. 檢查今天有多少鳥來訪

實作`today`函式。
它應該接收一個每日鳥數的陣列，並回傳今天的數量。
如果陣列是空的，它應該回傳`Nothing`；否則數量會被包在`Just`裡。

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. 將今天的數量加一

實作`incrementDayCount`函式。
它應該接收一個每日鳥數的陣列，並將今天的數量加 1。
如果陣列是空的，則回傳`[1]`。

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. 檢查是否有完全沒有鳥來訪的日子

實作`hasDayWithoutBirds`函式。
它應該接收一個每日鳥數的陣列。
如果至少有一天沒有任何鳥造訪花園，它應該回傳`True`，否則回傳`False`。

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. 計算來訪鳥隻的總數

實作`total`函式。
它應該接收一個每日鳥數的陣列，並回傳從你開始收集資料以來造訪花園的鳥隻總數。

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. 計算忙碌的日子有幾天

有些日子比其他日子忙碌。
忙碌的日子指的是有 5 隻以上鳥兒造訪花園的日子。

實作`busyDays`函式。
它應該接收一個每日鳥數的陣列，並回傳忙碌日子的數量。

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
