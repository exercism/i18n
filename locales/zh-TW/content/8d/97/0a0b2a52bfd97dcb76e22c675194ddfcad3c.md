# 提示

## 1. 建立新的居民

- 想了解如何建立 struct，可以回顧 [struct 概念](/tracks/go/concepts/structs)。

## 2. 驗證居民資料

- 字串的零值是`""`。
- map 的零值是`nil`。
- 想了解如何判斷 map 的鍵是否存在，可以回顧 [map 概念](/tracks/go/concepts/maps)。

## 3. 刪除居民資料

- 當居民的所有欄位都設為零值時，就視為已刪除。
- 想了解每種 Go 型別的零值，可以回顧 [零值概念](/tracks/go/concepts/zero-values)。

## 4. 計算居民人數

- 想了解如何使用 range 走訪 slice，可以回顧 [range 疊代概念](/tracks/go/concepts/range-iteration)。
