# 說明

將以字串表示的二進位數字（例如 '101010'），從基本原理著手轉換成對應的十進位值。

實作二進位到十進位的轉換。給定一個二進位輸入字串，你的程式應該產生十進位的輸出。程式也應該要能處理無效的輸入。

## 注意

- 自己實作這個轉換。不要使用其他工具替你執行轉換。

## 關於二進位（基底 2）

十進位是以 10 為基底的系統。

以十進位表示時，數字 23 可以理解為 10 的次方的線性組合：

- 最右邊的數字會乘以 10^0 = 1
- 下一個數字會乘以 10^1 = 10
- ...
- 第 _n_ 個數字會乘以 10^_(n-1)_。
- 所有這些值會相加。

所以：`23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

二進位也類似，但用的是 2 的次方，而不是 10 的次方。

所以：`101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`。
