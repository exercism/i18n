# 指令

給定一個主音（也就是起始音）和一組音程，請從主音開始，依照指定的音程模式產生音階。

西方音樂的音階是以半音階（12 個音）為基礎。這個音階可以用下列這組音高來表示：

A, A#, B, C, C#, D, D#, E, F, F#, G, G#

某個升音（以 # 表示）也可以寫成它上方那個音的降音（以 b 表示），所以半音階也能這樣寫：

A, Bb, B, C, Db, D, Eb, E, F, Gb, G, Ab

大調音階、小調音階以及各種調式，都是這十二個音所組成集合的子集。它們各有七個音，稱為全音階。這些音階裡要用升記號還是降記號來表示，取決於主音。以下列出各自對應的情況：

不使用升記號或降記號：
C 大調
a 小調

使用升記號：
G, D, A, E, B, F# 大調
e, b, f#, c#, g#, d# 小調

使用降記號：
F, Bb, Eb, Ab, Db, Gb 大調
d, g, c, f, bb, eb 小調

全音階，以及所有由半音階衍生出來的音階，都是以音程為基礎建構而成。音程是兩個音高之間的距離。

最簡單的音程出現在兩個相鄰的音之間，稱為「半音」，或「小二度」（有時以小寫的「m」表示）。兩個音之間如果還夾著一個音，這樣的音程稱為「全音」或「大二度」（以大寫的「M」表示）。全音階在相鄰音之間只會用到這兩種音程。

非全音階的音階則可能包含其他音程。所謂的「增二度」音程，以「A」表示，中間夾著兩個音（例如從 A 到 C，或從 Db 到 E），也就是「全音」加「半音」。還有更小和更大的音程，不過它們不會出現在這道練習中。
