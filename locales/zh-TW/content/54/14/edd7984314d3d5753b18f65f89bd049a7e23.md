# 簡介

Julia 裡的 `String` 是不可變的有限字元序列，採用 Unicode 的 UTF-8 編碼。

`String` 字面值就是用雙引號包住的一串字元：

```julia-repl
julia> "Christopher"
"Christopher"
```

字串可以用 `*` 運算子串接起來：

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
如果你好奇為什麼 Julia 用 `*` 而不是 `+` 來串接字串，可以看看 [Julia 手冊](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation)。
~~~~

有些特殊字元需要用反斜線開頭來跳脫：

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Julia 預設就內建了許多處理字串的實用函式：

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
