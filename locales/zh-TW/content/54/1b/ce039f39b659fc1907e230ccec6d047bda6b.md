# 關於

浮點數是在小數點後還帶有一或多個數字的數字。

```gleam
let float = 3.45
// -> 3.45
```

浮點數也有專屬於自己的一組運算子。

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

為了讓數字更清楚易讀，也可以在浮點數中加入底線。

```gleam
1_000_000.0 // One million
```

浮點數也可以使用科學記號：

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
