# 關於

在 Gleam 中，`case` 運算式可以依照條件執行程式碼。使用 case 運算式時，可以將值與一個或多個_模式_進行比對。_常值模式_就是其中一種，它會把值與常值（例如`1`或`"hello"`）進行比對。

case 運算式使用 `case` 關鍵字撰寫：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

雖然這看起來像是其他語言裡的 `switch` 敘述，但當你同時使用其他模式時，模式比對才會真正展現它的威力。_變數模式_就是其中一種，它可以將值指定給變數。在下面這個例子中，如果 `number` 不是 `0`，變數 `i` 就會被指定為 `number` 的值：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

有時候，你可能想為模式再加上一個額外的條件。這稱為_守衛_（子句），可以使用 `if` 關鍵字加入：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

基於效能考量，守衛中只允許使用基本的數學與布林運算子，其他函式不能用在守衛裡。

在上面的例子中，並非所有可能的輸入都有對應的模式。編譯器會偵測到這一點並產生錯誤。這稱為_窮舉檢查_。要解決這個警告，就必須處理所有的情況。為此，可以使用_捨棄模式_，它是一種能比對任何值的模式：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

case 運算式會由上而下依序將值與每個模式比對，直到找到相符的模式為止，並執行該模式對應的邏輯。模式的順序很重要！
