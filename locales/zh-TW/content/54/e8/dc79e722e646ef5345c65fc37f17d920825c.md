# 關於

Idris 是一套通用的純函式程式語言，支援[依賴型別](http://en.wikipedia.org/wiki/Dependent_type)。
依賴型別讓型別能以值為依據，也就是說，程式行為的某些面向可以直接在型別中精確描述。
它採用編譯式，並使用[及早求值](http://en.wikipedia.org/wiki/Eager_evaluation)。
它的特色受 Haskell 與 ML 影響，包括：

- 完整的依賴型別，並支援依賴模式比對
- 簡單的外部函式介面（可連接 C）
- 編譯器支援的互動式編輯：編譯器會利用型別協助你撰寫程式碼
- where 子句、with 規則、簡單的 case 運算式、模式比對的 let 與 lambda 綁定
- 具備投影與更新的依賴記錄
- 介面（類似 Haskell 的型別類別）
- 由型別驅動的多載解析
- do 記法與慣用括號
- 以縮排為準的語法
- 可擴充的語法
- 累積宇宙
- 完整性檢查
- [Hugs](http://www.haskell.org/hugs/) 風格的互動式環境
