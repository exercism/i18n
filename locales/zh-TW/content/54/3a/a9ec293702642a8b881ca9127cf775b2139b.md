# 學習

Pascal 程式語言歷史悠久，線上有許多文件也都是為初學者而寫的。這些教學大多是在談主控台程式，也就是把資訊印到螢幕上，或是讀取使用者的輸入。舉例來說，最常見的初學者教學之一，就是寫一個把 'Hello World' 印到螢幕上的程式：

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

從主控台或終端機執行時，這個程式會在螢幕上印出 'Hello World'。

在 Exercism，我們用自動化測試來確認你的解法是否正確，因此我們需要用的是**unit**，而不是**program**。最主要的差別在於，你必須從函式回傳一個值，而不是把某些東西印到終端機上：

```pascal
writeln('Hello World!');
```

變成

```pascal
result := 'Hello World!'
```

write/writeln 這兩個指令還是很有用，可以用來顯示資訊，或是取得某個指令、數學運算等結果的文字表示。
