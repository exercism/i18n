# 說明

身為一位西洋棋愛好者，你會想寫出自己的版本。沒錯，線上可能已經有很多現成的西洋棋實作，但你的版本會是獨一無二的！

不過，在盡情發揮想像力之前，得先處理好基本功。我們就從產生棋盤開始吧。

棋盤上的每個格子都由一組字母和數字來標示。這些方格組成的垂直行稱為直行，以 A 到 H 標示。水平方向的橫列則以 1 到 8 編號。

## 1. 定義橫列的範圍

實作`rank_range()`函式。它應該回傳一個整數範圍，從 1 到 8。

```julia-repl
julia> rank_range()
# output omitted
```

## 2. 定義直行的範圍

實作`file_range()`函式。
它應該回傳一個字元範圍，從大寫字母 A 到大寫字母 H。

```julia-repl
julia> file_range()
# output omitted
```

## 3. 把橫列的範圍轉換成橫列向量

實作`ranks()`函式。它應該回傳一個整數向量，從 1 到 8。
不要手動寫出這個向量，而是用`rank_range()`函式回傳的範圍來產生。

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. 把直行的範圍轉換成直行向量

實作`files`函式。它應該回傳一個字元向量，從 'A' 到 'H'。
不要手動寫出這個向量，而是用`file_range()`函式回傳的範圍來產生。

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
