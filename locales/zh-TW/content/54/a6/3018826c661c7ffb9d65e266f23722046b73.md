# Bash shell 中的算術入門

Bash 可以進行算術運算，但_只能處理整數_。
如果你需要做浮點數運算，就得呼叫外部程式（例如 [awk][awk] 或 [bc][bc]）。

各種算術運算子都列在手冊裡（依優先順序排列）：[Shell Arithmetic][arithmetic]。

此外，Bash 只會在特定地方進行算術運算（也就是所謂的算術「情境」）。

## 算術展開

算術展開看起來很像[命令替換][cmd-sub]，只是改用雙括號。

```bash
$(( expression ))
```

這個語法會展開成運算式求值後的結果。
常見的用法是把結果存進變數：

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
括號裡要放多少空白由你決定。
這取決於風格與可讀性。

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

你親切的作者喜歡加上空白，讓括號內的算術運算式更清楚可見。
~~~~

## 算術條件式

算術條件式是在雙括號內執行的，_不需_開頭的`$`：

```bash
(( expression ))
```

這不會展開成結果。
不過它會產生一個_結束狀態_。

* 如果運算式的結果**不為零**，結束狀態就是 0（成功）。
* 如果運算式的結果**為零**，結束狀態就是 1（失敗）。

~~~~exercism/note
在`((`裡，Bash 對 true/false 的判斷方式和 C 語言相同：零是假，非零是真。
**這和 Bash 判斷結束狀態的方式正好相反！**
~~~~

這個語法通常用在兩個地方：

1. 當作 [`if`條件式][conditional-if] 或 [`while`迴圈][looping-while] 的 COMMAND 部分。

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. 當作獨立命令，用來修改變數的值。

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   把算術這樣用、又搭配`set -e`時要小心。
   如果運算式求值結果為零，結束狀態就會變成非零，Bash 便會終止。

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   想更深入了解`++`運算子，可以看看這篇關於 [Postincrement vs Preincrement][incr] 的文章

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## 其他具有算術情境的地方

還有其他幾個地方也屬於算術情境：

* [算術 `for`迴圈][looping-for]。

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* 數字索引陣列的索引部分。

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  想進一步了解陣列，可以閱讀 [Arrays][arrays] 概念文件。

* `${var:offset:length}`展開中的偏移與長度部分。
* [`let`內建命令][let]。
  * 請注意，`(( expression ))`比`let "expresson"`更受推薦。
    和算術條件式不同，`let`運算式會受到檔名展開與單詞分割的影響，而且需要用引號包起來。
* 當變數具有「整數屬性」時的變數賦值。

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  作者認為`declare -i`的用途有限。
  它最大的好處是可以用「裸」算術（不必使用算術運算式語法）。
  這可能讓閱讀你程式碼的人感到困惑，因為算術運算式會在出乎意料的地方被求值。
  ~~~~

## 在算術運算式中使用變數

算術情境有一個特點可以提升可讀性。

```bash
height=10
width=20
area=$(( height * width ))
```

你注意到了嗎？算術運算式裡的變數少了`$`符號。
Bash 允許你這麼做。
這讓運算式好讀得多。

手冊上寫著：

> 在運算式中，shell 變數也可以直接用名稱引用，而不需要使用參數展開語法。

這對陣列元素也適用：

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

不過其他參數運算式就得使用它們的特殊語法。
例如，把字串長度加倍：

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

位置參數也一樣。
如果前兩個位置參數代表寬與高：

```bash
area=$(( $1 * $2 ))
```
