# 簡介

## 比較運算子

比較運算子和許多其他語言很像。

判斷相等性時，運算子有`==`（等於）和`!=`（不等於）。

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

大於和小於運算子的寫法也很常見。

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## 用`if`分支

這是`if`運算式的完整形式：

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 每個條件都必須用括號`()`包住。
- 條件的求值結果必須是布林值`true`或`false`。
  Kotlin 沒有某些語言那種「truthy」和「falsy」的概念。
- 如果只有單一運算式，大括號`{}`可以省略。
- `else if`和`else`都是可選的，而且可以有多個`else if`區塊。

`if`運算式也可以用來「挑選」值：

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 其他選擇？

Kotlin 刻意_不_支援 Java 裡的三元運算子`? :`，
而是偏好`if ... else`的簡潔寫法：

```Kotlin
return if (isOK) goodValue else badValue
```
