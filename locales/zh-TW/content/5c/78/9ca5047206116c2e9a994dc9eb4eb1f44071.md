# 說明附錄

## Subtype

這個練習定義了一個稱為 `Positive` 的 Subtype，代表所有大於 0 的自然數。
Subtype 可以想成是一對 `⟨x, h⟩`，其中 x 是值，h 是它有效性的證明。

Subtype 內的值（在這裡就是 x）可以透過 .val 取得，例如 `x.val`。
它的證明則可以透過 .property 取得，例如 `x.property`。
兩者也可以像平常一樣，透過模式比對取得。

要建構一個 Subtype 的值，就必須證明它的有效性，在這個例子中，也就是證明該數字大於 0。

Lean 中有許多引理與定理，可以作為這個證明的起點。
例如，`Nat.zero_lt_succ` 是一個引理，它斷言對任何自然數 `n` 而言：`0 < n + 1`。
