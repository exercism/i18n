# 說明

在這個練習中，你將為一個簡單的整數計算機建立錯誤處理。
為了讓事情單純一些，我們已經提供了計算加法、乘法和除法的方法。

目標是做出一個能正常運作的計算機，當傳入引數 `16`、`51` 和 `+` 時，它會回傳符合以下模式的字串：`16 + 51 = 67`。

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. 實作 `calculate` 方法以支援幾種基本運算

這個任務中主要要實作的方法是 `CalculatorConundrum.calculate()` 方法。
它接受三個引數。
前兩個引數 `operand1` 和 `operand2` 是要進行運算的整數。
第三個引數 `operation` 的型別是字串，而在這個練習中，必須實作以下運算：

- 使用 `+` 字串的加法
- 使用 `*` 字串的乘法
- 使用 `/` 字串的除法

## 2. 處理不合法的運算

更新 `CalculatorConundrum.calculate()` 方法，以處理不合法的運算：

- 當 `operation` 引數是 `null` 時，應該拋出 `IllegalArgumentException`，訊息為 `Operation cannot be null`。
- 當 `operation` 引數是 `""` 時，應該拋出 `IllegalArgumentException`，訊息為 `Operation cannot be empty`。
- 當 `operation` 引數是 `+`、`*` 或 `/` 以外的任何運算時，應該拋出 `IllegalOperationException`，訊息為 `Operation '{operation}' does not exist`。

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. 處理除以零時拋出的例外

在 Java 中，嘗試除以零會拋出 `ArithmeticException`。
更新 `CalculatorConundrum.calculate()` 方法來攔截這個例外，然後拋出 `IllegalOperationException`，訊息為 `Division by zero is not allowed`，並以攔截到的 `ArithmeticException` 作為它的原因。

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
