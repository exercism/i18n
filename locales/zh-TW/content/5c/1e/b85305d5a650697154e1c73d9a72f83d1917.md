# 說明

在這道練習裡，你會操作一台遙控車，這是你終於存夠錢買下的喔。

車子一開始的電量是滿的（100%）。
每次你用遙控器駕駛車子時，它會前進 20 公尺，並消耗 1% 的電量。
車子的暱稱要等到它被建立之後才會知道。

這台遙控車有一個酷炫的 LED 顯示器，會顯示兩項資訊：

- 它總共行駛的距離，顯示為：`"<METERS> meters"`。
- 剩餘的電量，顯示為：`"Battery at <PERCENTAGE>%"`。

如果電量為 0%，你就不能再駕駛這台車，電池顯示器會顯示`"Battery empty"`。

## 1. 建立一台全新的遙控車

實作`new_remote_control_car/0`函式，回傳一個全新的遙控車物件：

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. 建立一台帶有暱稱的全新遙控車

實作`new_remote_control_car/1`函式，回傳一個帶有指定暱稱的全新遙控車物件：

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. 顯示距離

實作`display_distance/0`函式，它會接收一個車子物件作為輸入，並輸出 LED 顯示器上顯示的距離字串：

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. 顯示電量百分比

實作`display_battery/0`函式，它會接收一個車子物件作為輸入，並輸出 LED 顯示器上顯示的電量百分比字串：

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

如果電量為 0%，電池顯示器會顯示 "Battery empty"。

## 5. 駕駛會改變電量與行駛距離

實作`drive/0`函式，它會：

- 接收一個車子物件作為輸入
- 將行駛的公尺數增加 20
- 消耗 1% 的電量
- 輸出修改後的車子物件

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. 處理電池沒電時駕駛的情況

更新`drive/0`函式，讓它在電池耗盡（0%）時，既不增加行駛距離，也不減少電量百分比：

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
