# 提示

## 一般

- 回傳字元的常式會宣告成`: CHAR`。回傳數字的常式是`: INT`，回傳是或否的常式則是`: BOOL`。

## 1. 它是字母嗎？

- `.is_alpha`會直接給出答案。回傳它就好，不需要`if`。

## 2. 大聲喊出來

- `.upper`本身就不會動到非字母的字元，所以沒有什麼要檢查的。

## 3. 它是什麼數字？

- `.int`。

## 4. 第一個字元

- 用方括號，而且第一個位置是`0`。

## 5. 轉動轉盤

- 分成三個步驟：先算出這個字母在字母表中的位置，移動它，再把結果轉回字母。
- 位置怎麼算：`c.int - 'a'.int`。對`'a'`來說就是 0。
- 繞回來則是`% 26`，它會讓結果保持在 0 到 25 之間。
- 轉回字母：加上`'a'.int`並使用`.char`。
- 寫`'a'.int`而不是`97`。這樣才看得出這個數字的用意。
