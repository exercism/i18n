## 格式

雖然 Common Lisp 不在意程式碼的縮排與排版，也不在意你用的是空格還是 Tab，但這對提交到 Exercism 的內容來說是很重要的一點。
Exercism.org 的程式碼編輯器無法妥善處理 Tab 與空格字元混用的情況，因此建議只使用空格，讓人工審閱者更容易閱讀你的程式碼。
請查閱你的編輯器設定，了解如何做到這一點。
以下是一些熱門的 Common Lisp 編輯器設定說明。

### VIM

使用下列指令來確保 VIM 只使用空格縮排：

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

（或寫成一行`:set tabstop=2 shiftwidth=2 expandtab`）。你可以把它加進`~/.vimrc`檔案，讓這個設定一直生效。

### Emacs

Emacs 非常適合用來編輯 Common Lisp，而且有許多強大的外掛套件可用。要用預設的 Emacs 搭配 exercism.org 運作良好，唯一要做的事就是對下列程式碼求值：

`(setq-default indent-tabs-mode nil)`

你可以把它放進`~/.emacs`（或`~/.emacs.d/init.el`），這樣每次啟動 Emacs 時都會套用這個設定。

推薦給 Emacs 與 Common Lisp 的一個外掛是 [SLIME][slime]，它與 REPL 緊密整合，讓反覆編寫與測試程式變得非常輕鬆。
