# 關於

[推導式][for]提供了一種能輕鬆且宣告式地轉換 _Enumerable_ 的機制。它們是 Elixir 中用來疊代 _Enumerable_ 的語法糖。

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

推導式由三個部分組成：

1. _產生器_：
   - 從實作 [_Enumerable_][enumerable] 協定的結構所列舉出的值。
   - 用來解構所列舉值的模式比對運算式。
2. _篩選器_：布林條件，用來選擇在建立新值時要使用哪些列舉出的值。
3. _收集目標_：實作 [_Collectable_][collectable] 協定的結構，用來收集新產生的值。

推導式有單行和多行兩種。當使用多個產生器時，所產生的值會以[笛卡兒積][cartesian-product]的方式列舉。也就是說，第一個產生器產生的每個值，都會與第二個產生器產生的每個值配對一次。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

do 區塊中的值，會**針對從 _Enumerable_ 產生的每個值**插入到收集目標之中。

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

推導式中可以進行模式比對，無論是在`<-`的左側，或是獨立寫成一行。

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
