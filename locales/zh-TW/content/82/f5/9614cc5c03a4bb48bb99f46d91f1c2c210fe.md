# 提示

## 一般

- `reduce`會先接收序列，再接收初始值，最後接收 quotation。quotation 會收到 `( prev elt -- next )`：先收到累計中的累加器，再收到下一個元素。
- 累計系列（`cum-sum`、`cum-product`、`cum-min`、`cum-max`）位於 [`math.statistics`][math.statistics]，會回傳一個與輸入長度相同的序列。

## 1. 遵守請求佇列

- `reduce`的初始值就是期初餘額。
- combiner 會把請求加到累計餘額上，再用 `0 max` 把下限設為零，讓餘額永遠不會變成負數。
- 引數在堆疊上以 `( opening requests )` 的順序出現，但 `reduce`要的是 `( seq init quot )`，只差一個`swap`。

## 2. 累計餘額

- 只要一個 word：`cum-sum`。

## 3. 目前為止的最低餘額

- 先算出累計餘額，再對該結果取累計最小值。兩個 word，串接起來。

## 4. 減半直到達到目標

- `produce`正是合適的工具：它會反覆測試與推進，藉此產生一個序列。
- 在 `produce`中流動的狀態*同時*是累計值與目標值。把 `target`放在底部，把目前的值放在頂端；判斷式會用 `2dup <`比較兩者（目標小於累計值，也就是說，目前仍高於目標）。
- 在 quotation 裡，用 `2 /i`把目前的值除以 2，再用 `dup`複製結果，讓它既能更新流動中的狀態，也會成為新產生的元素。
- `produce`之後，剩下的狀態（目標值加上最終值）需要被丟棄：`2nip`會剝掉底部的兩個值，只留下產生的序列。

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
