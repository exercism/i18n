# 簡介

模式比對是根據某個值是否對應到指定、甚至深層的模式來決定分支的過程。在 Haxe 中，**模式比對**是使用 `switch` 運算式和各個 `case` 運算式來完成的。

想想這個資料結構：

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- 模式一律由上而下進行比對。
- 最上面一個與輸入值相符的模式，會執行它所對應的運算式。
- `_` 模式可符合任何值，所以 `case _:` 等同於 `default:`

## 列舉比對

列舉可以自然地透過它們的建構子來比對：

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
