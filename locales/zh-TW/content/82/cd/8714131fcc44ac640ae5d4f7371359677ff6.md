# 關於

[C++](https://en.wikipedia.org/wiki/C%2B%2B)（讀作 cee plus plus）是一種通用程式語言，由 [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) 於 1979 年在貝爾實驗室開始開發。它非常受歡迎，尤其是在需要速度，以及/或需要取用某些低階功能的應用程式上。它被認為是中介層級的語言，因為它同時封裝了高階與低階語言的特性。

C++ 支援[程序式](https://en.wikipedia.org/wiki/Procedural_programming)、[物件導向](https://en.wikipedia.org/wiki/Object-oriented_programming)、[函式](https://en.wikipedia.org/wiki/Functional_programming)與[泛型](https://en.wikipedia.org/wiki/Generic_programming)程式設計。C++ 的編譯器幾乎每個平台都能取得，包括 Windows、Mac OS 和 Linux。

主要優點：
- **型別安全：**封裝必要的不安全操作
- **資源安全：**並非所有資源管理都是在管理記憶體
- **效能：**對幾乎所有系統的某些部分來說，這很重要
- **可預測性：**對硬性與軟性即時系統而言
- **可教學性：**程式的複雜度應與任務的複雜度成正比
- **可讀性：**對人與機器都是（「可分析性」）
- **直接對應硬體：**指令與基本資料型態的直接對應
- **零額外負擔的抽象化：**帶有建構子與解構子的類別、繼承、泛型程式設計、函式程式設計技巧

C++ 的標準由國際標準化組織（ISO）維護，而截至 2018 年 6 月，C++ 的現行版本是 C++17（這個名稱並非代表 C++ 的第 17 版，而是表示該標準於 2017 年獲得批准）。

C++ 最棒的地方在於，從資源非常有限的嵌入式處理器，到最大的大型主機超級電腦，以及介於兩者之間的每一台個人電腦，它都能執行。
