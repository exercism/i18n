# 關於

Scala 是一種能隨著你一起成長的程式語言：從小型腳本到大型跨平台應用程式都適用。

Scala 將物件導向與函式式程式設計結合在一門簡潔的高階語言中。Scala 的靜態型別有助於在複雜的應用程式中避免 bug，而它的 JVM、JavaScript 和 Native 執行環境，讓你輕鬆取用龐大的函式庫生態系統，打造高效能系統。

* 功能
    * JVM 互通性：Scala 執行於 JVM，因此 Java 與 Scala 的技術堆疊可以混用，達到無縫整合。
    * JS 與 Native 互通性：受惠於 [Scala.js](https://www.scala-js.org/) 和 [Scala Native](https://github.com/scala-native/scala-native)，Scala 可以在瀏覽器中執行，也可以在原生裝置上執行。
    * 型別推論：Scala 是靜態型別的語言。不過，Scala 提供了型別推論，減輕進階型別系統帶來的負擔。
    * 物件導向：就每個值都是物件這層意義來說，Scala 是純物件導向語言。物件的資料型態與行為由類別和特質所描述。類別抽象透過子類別化，以及具彈性的 mixin 組合機制來擴充，以避免多重繼承的問題。
    * 函式式：就每個函式都是值這層意義來說，Scala 也是一種函式式語言。Scala 提供輕量的語法來定義匿名函式，支援高階函式，允許函式巢狀定義，也支援柯里化。Scala 的 case 類別與內建的樣式比對支援，塑造了許多函式式程式設計語言所使用的代數型別。單例物件則提供了一個便利的方式，把不屬於任何類別的函式群組起來。
    * 並行與分散式：對集合使用資料平行操作，用 actor 處理並行與分散式，或用 future 進行非同步程式設計。
