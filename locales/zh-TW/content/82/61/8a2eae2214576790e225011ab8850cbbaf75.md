# 向量作為堆疊

堆疊是一種線性資料結構，專門針對從單一端點存取而最佳化。一個貼切的比喻是把紙張串在軸桿上：新的紙張總是從同一端加入，而紙張取出的順序與加入的順序相反。先加入的紙張最後取出，最後加入的紙張最先取出。

Rust 的`Vec`資料結構很適合作為堆疊使用。[`push`方法](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push)會將項目加入向量的尾端。[`pop`方法](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop)會移除向量中最後一個項目。`push`和`pop`都只需要攤銷`O(1)`時間。

## 範例

在這個範例中，我們把向量當作堆疊，用來實作一個簡單的 [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) 計算器。完整原始碼可以在 [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736) 上找到。

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
