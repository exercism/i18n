# 簡介

Clojure 所有的標準資料型態都是不可變的，因此它提供了*參考型別*，讓你能以受控的方式修改狀態。其中最簡單、也最常用的一種就叫做 Atom。

Atom 是用`atom`函式建立的，這個函式會接收一個初始值：

```clojure
(def players (atom ()))
```

要取得 Atom 目前的值，可以用`deref`或`@`簡寫來解引用：

```clojure
@players
;;=> ()
```

`players`這個 Atom 目前的值可以用`swap!`修改，它會套用一個函式來更新值：

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!`函式則會直接取代 Atom 的值，不管它目前的值是什麼：

```clojure
(reset! players ())
```
