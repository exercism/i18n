# 說明補充

## 這個練習在 Python track 上的結構

這個練習的測試預期你建立一個 Matrix [`class`][classes]（_另見 [concept:python/classes]()_）。
這和_使用_第三方函式庫（例如 [Numpy][numpy-matrix]）的 Matrix 物件不同，這種做法並不支援。
 _別擔心，這沒有你想像中那麼複雜！_
