# 簡介

Python 的[比較運算子][comparisons]（_也稱為 Python 關係運算子_）會查看兩個[運算元][operand]的_值_，並根據 `comparison` 條件是否成立，回傳布林值 `True` 或 `False`。

下表列出最常見的 Python 比較運算子：

| Operator | Operation                  | Description                                                               |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | 「大於」             | 若 `a` 的值**嚴格**大於 `b`，則 `a > b` 為 `True`        |
| `<`      | 「小於」                | 若 `a` 的值**嚴格**小於 `b`，則 `a < b` 為 `True`           |
| `==`     | 「等於」                | 若 `a` 的值**嚴格**等於 `b`，則 `a == b` 為 `True`           |
| `>=`     | 「大於或等於」 | 若 `a > b` 或 `a == b`，則 `a >= b` 為 `True`                        |
| `<=`     | 「小於或等於」    | 若 `a < b` 或 `a == b`，則 `a <= b` 為 `True`                        |
| `!=`     | 「不等於」             | 若 `a == b` 為 `False`，則 `a != b` 為 `True`                                 |
| `is`     | 「身分」                 | 若 `a` 與 `b` 是相同的_物件_，則 `a is b` 為 `True`（**_且唯有在此情況下_**） |
| `is not` | 「否定的身分」         | 若 `a` 與 `b`**不是**相同的_物件_，則 `a is not b` 為 `True`（**_且唯有在此情況下_**）       |
| `in`     | 「包含測試」         | 若 `a` 是 `b` 的成員、子集或元素，則 `a in b` 為 `True`            |
| `not in` | 「否定的包含測試」 | 若 `a` 不是 `b` 的成員、子集或元素，則 `a not in b` 為 `True`  |

它們的優先順序都相同（_高於[布林運算][boolean operations]，但低於算術或位元運算_）。

## 不同資料型態之間的比較

型別不同的物件（_數值型別除外_）預設永遠不會比較為相等。
同一個 `class` 的不同實例也**_不會_**比較為相等，除非 `class` 定義了可自訂預設 `object` 比較行為的特殊方法。

數值型別（大多）是這條型別相符規則的例外。
只要型別能為了比較而隱式轉換，`integer`**就**可以被視為等於 `float`（_或 [`octal`][octal] 等於 [`hexadecimal`][hex]）。

至於其他數值型別（[複數][complex numbers]、[十進位數][decimal numbers]、[分數][rational numbers]），比較運算子只在「說得通」的地方才有定義（_也就是隱式轉換不會改變結果的地方_），但若底層物件無法為了比較而精確轉換，就會拋出 `TypeError`。

## 比較物件身分

運算子 `is` 和 `is not` 測試的是物件[_身分_][object identity]，而不是物件的_值_。
物件建立之後，其身分永遠不會改變，而且可以透過 [`id()`][id function] 函式取得。

**_且唯有在_** `id(<apple>)` == `id(<orange>)` 時，`<apple> is <orange>` 才會求值為 `True`。
`<apple> is not <orange>` 則會得到相反的結果。

## 成員資格比較

運算子 `in` 和 `not in` 測試的是_成員資格_。
若 `<fish>` 是 `<soup>` 的成員（_也就是 `<fish>` 是 `<soup>` 的子集或包含於 `<soup>` 之中_），則 `<fish> in <soup>` 求值為 `True`，否則求值為 `False`。
`<fish> not in <soup>` 會回傳其否定，也就是 `<fish> in <soup>` 的_相反結果_。

對字串和位元組型別而言，**_且唯有在_** `<name>` 是 `<fullname>` 的子字串時，`<name> in <fullname>` 才會是 `True`。
