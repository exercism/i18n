# 測試

在嘗試執行測試之前，請先依照安裝步驟正確設定好作業資料夾，也就是 `corepack yarn install` 和 Editor SDK 的設定。

用以下指令執行測試：

```bash
$ corepack yarn test
```

## 跳過的測試

在測試套件中，除了第一個測試之外，其餘的測試都會被跳過。

當你讓一個測試通過之後，就可以把 `xit` 改成 `it` 來啟用下一個測試。
此外，測試也可以使用 `xdescribe` 來分組。
把它改成 `describe` 就能啟用整個群組。
最後，有些練習可能會有選用測試 `it.skip`。
移除 `.skip` 就能執行這個選用測試。
