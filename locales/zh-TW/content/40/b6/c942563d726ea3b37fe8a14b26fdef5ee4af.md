# 關於

Go 的愛好者（稱為 _gophers_）形容 Go 既有 Python 或 Ruby 這類動態語言的表達力，又有 C 或 C++ 這類編譯式語言的效能。

這門語言是開源的，最初由 Google 的工程師發起。它以 C 風格的語法撰寫，變數採用靜態型別，透過垃圾回收管理記憶體，並且編譯成獨立執行檔。

Go 以內建於語言核心的[並行程式設計功能](https://golang.org/doc/effective_go.html#concurrency)聞名，標準函式庫中也有網路套件（[例如網頁伺服器](https://pkg.go.dev/net/http)），編譯與執行速度都很快。它簡單、極簡且一致的語言設計帶來愉悅的體驗，而豐富又周全的工具則解決了[一致格式化](https://pkg.go.dev/cmd/gofmt)和[文件](https://pkg.go.dev/golang.org/x/tools/cmd/godoc)等傳統問題。

Go 的首頁是 [go.dev](https://go.dev/)，另外 [tour.go.dev](https://tour.go.dev/) 還有很棒的互動式教學喔。
