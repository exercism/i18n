# 說明

兩位小提琴手正在排練一首二重奏。每個聲部都是一個陣列，記錄每個小節裡的音符數量，而且各聲部的長度不一定相同。

這四個任務都放在`DUET_PRACTICE`類別裡。

## 1. 他們會一起演奏幾個小節？

只要兩個聲部都還有小節，他們就會一起演奏。

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. 有幾個小節相符？

數一數兩個聲部音符數量相同的小節。只有雙方都有的小節才可能相符。

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. 誰比較忙？

數一數第一個聲部音符比第二個聲部多的小節。

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. 為小節加權

越後面的小節越難，所以每個小節的分量等於它的位置：第一小節算一次，第二小節算兩次，第三小節算三次。把每個小節的音符數乘上它的編號，再全部加起來。

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

也就是 1×4 + 2×4 + 3×8。小節編號從 1 開始，不是從 0。
