# 安裝

## 該選哪個版本？

我們建議使用仍在積極維護中的穩定 PHP 版本。
目前是 **PHP 8.2、8.3 和 8.4**。
關於目前各版本及其支援時程的詳細資訊，請參閱[官方 PHP 文件](https://www.php.net/supported-versions.php)。

## 安裝 PHP

Linux 與 macOS 上大多數套件管理器都提供預先建置好的套件。
PHP 也可以從原始碼下載並自行建置，詳見 [php.net/downloads.php](https://php.net/downloads.php) 或 [windows.php.net/download](https://windows.php.net/download)。

~~~~exercism/note
完成這些練習並不需要 nginx 或 Apache HTTP server 這類網頁伺服器。
~~~~

### Linux

不同的發行版有不同的做法。
你應該可以執行

```shell
yum install php
```

或

```shell
apt-get install php
```

取決於你使用的套件管理器。

更多說明請參閱 PHP 手冊的[在 Unix 系統上安裝](https://www.php.net/manual/en/install.unix.php)。

### macOS

macOS 雖然通常內建 PHP，但版本往往已經過時。
我們建議透過 [Homebrew](https://brew.sh/) 安裝 PHP。
你可以依照[官方首頁](https://brew.sh/#install)的說明安裝 Homebrew。

確認安裝是否成功，請試試下列指令，在撰寫本文時它應該會輸出 Homebrew `4.5.x`。

```shell
brew --version 
```

透過 Homebrew 安裝 PHP

```shell
brew install php@8.4
```

這應該會顯示目前安裝的 PHP 版本，至少為 `8.2.0`。

```shell
php -v
```

更多說明請參閱手冊的[在 macOS 上安裝](https://www.php.net/manual/en/install.macosx.php)。

### Windows

Windows 的官方 PHP 二進位檔可從 [windows.php.net/download](https://windows.php.net/download) 下載。

也有預先整合好的套件，例如 [WAMP](https://www.wampserver.com/en/)（Windows、Apache、MySQL、PHP）和 [XAMPP](https://www.apachefriends.org/de/index.html)。

更多說明請參閱手冊的[在 Windows 系統上安裝](https://www.php.net/manual/en/install.windows.php)。

### Docker

如果你偏好容器化的做法，可以下載 [Docker Hub 的官方 PHP 映像檔](https://hub.docker.com/_/php)。
你也需要 [Docker](https://docs.docker.com/engine/install/)。

### 其他

如果你想使用其他作業系統，請參閱 [php.net/manual/en/install](https://www.php.net/manual/en/install.php) 的說明。

## 安裝 PHPUnit

目前尚不支援 PHPUnit 12！
~~~~

### 透過 PHP Archive（PHAR）

在 Exercism 練習中使用 PHPUnit 最簡單的方式，是下載以 PHP Archive（PHAR）封裝的發行版，這也是使用 PHPUnit 的建議做法。
把這個 PHAR 存放在你存放 `exercism` CLI 的位置，這樣無論你在哪裡都能執行 PHPUnit。

你可以下載打包成 PHP archive 的 PHPUnit 發行版：

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

接著讓下載的檔案變成可執行：

```shell
chmod +x phpunit.phar
```

然後把它移到你放置 `exercism` CLI 的相同位置，並將指令命名為 `phpunit`：

```shell
mv phpunit.phar ~/bin/phpunit
```

現在無論你在哪裡都能執行 `phpunit`，如 [PHP 軌道測試文件](https://exercism.org/docs/tracks/php/tests)所示：

```shell
phpunit --version
```

輸出應該像這樣：

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

你也可以依照官方的[安裝 PHPUnit 說明](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit)來安裝 PHPUnit。

### 透過 Composer

PHPUnit 11 版也可以透過 [Composer](https://getcomposer.org) 安裝。

#### 安裝 Composer

依照你的裝置作業系統[安裝說明](https://getcomposer.org/doc/00-intro.md)安裝 [Composer](https://getcomposer.org)。為了方便使用，我們建議全域安裝。

#### 將 PHPUnit 新增為全域工具

使用下列指令：

```shell
composer global require phpunit/phpunit ^11.5
```

請確認你安裝的是 11.5 或之後的版本。
