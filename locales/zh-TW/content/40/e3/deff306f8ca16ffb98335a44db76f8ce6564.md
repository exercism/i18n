# 介紹

Factor 裡大部分的資料都住在*序列*中。陣列（`{ … }`）、向量（`V{ … }`）和字串全都共用來自 [`sequences`][sequences] 的同一套[協定][sequence-protocol]。

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

聚合操作（`sum`、`count`、`any?`、`all?`），以及 `empty?`、`member?` 這類述詞，在每一種序列型別上都有相同的行為。在不改變既有資料的前提下建立新序列：`prefix`、`suffix`、`append`、`unclip`、`unclip-last`。

當你需要從泛型操作取回某個特定的具體型別時，`>array`、`>vector` 和 `>string`（位於 [`arrays`][arrays] 與對應的詞彙表中）可以在各種序列型別之間轉換。

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
