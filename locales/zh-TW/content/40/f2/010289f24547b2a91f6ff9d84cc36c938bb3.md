# 提示

## 一般

- [數字教學][numbers]。

## 1. 計算每秒的生產速率

- 可以使用[條件式][if-statement]來判斷成功率。
- Java 允許對兩種不同的數字型別進行乘法運算（例如`int`和`double`），並會自動回傳「較廣泛」的資料型態。
- 數字可以使用內建的[比較][comparison-operators]和[相等運算子][comparison-operators]來比較。

## 2. 計算每秒生產出的可用物品數量

- `int`可以自動轉換成`double`，但反過來卻行不通。原因是`int`的精確度比`double`低，因此必須進行四捨五入；此外，`int`能表示的數字範圍也比`double`小。如果要強制進行這種轉換，可以使用[轉型為`int`][cast-int]。
