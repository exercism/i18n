# 簡介

## 陣列

在 Common Lisp 中，如同其他語言，陣列是一組元素，透過整數索引來存取。
元素的型別可以不同。
陣列可以多維（不只是單純的一維）。

### 建立

`make-array`可以用來建立陣列。
它有很多選項，但較簡單的形式可以建立 N 維陣列，並將所有元素初始化為單一值，或將陣列初始化為另一個序列中的值（例如陣列）。
它的第一個引數是每個維度大小的陣列。

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

（請注意，N 維陣列的列印方式會顯示維度數。）

陣列也可以使用與其列印格式相同的格式來建立：

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### 存取元素

要存取向量的元素，請使用`aref`，索引從零開始。
提供的索引數量必須符合陣列的維度數。

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
