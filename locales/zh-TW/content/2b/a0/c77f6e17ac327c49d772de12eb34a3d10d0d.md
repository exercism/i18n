# 說明

在這道練習中，你會撰寫程式碼，替工廠員工印製名牌。
員工會有 ID、名字和部門名稱。
員工名牌標籤的格式如下：`"[id] - name - DEPARTMENT"`。

## 1. 印製員工的名牌

實作 `print_name_badge` 函式。它會接收 ID、名字和部門，並回傳名牌標籤，其中部門名稱要使用大寫。

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. 印製新進員工的名牌

由於電腦系統的古怪設計，新進員工剛開始在工廠上班時，有時還沒有 ID。
因為名牌是必備的，他們會拿到一張沒有 ID 前綴的臨時名牌。

擴充 `print_name_badge` 函式。當 id 缺少時，它應該印出不含 ID 的名牌。

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. 印製老闆的名牌

即使是工廠老闆，也必須隨時配戴名牌。
不過，老闆沒有部門，而且永遠都不會有：他們在所有部門之上。
在這種情況下，標籤應該印出 `"OWNER"`，而不是部門名稱。

擴充 `print_name_badge` 函式。當部門是 `NULL` 時，假設這張名牌屬於公司老闆。

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

請注意，老闆也有可能同時是新進員工。

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. 計算沒有 ID 的員工薪資總和

為了粗略衡量 ID 的發放狀況，你想看看沒有 ID 的員工薪資加總起來是多少。
數值很高，代表有很多人還在等，或是這個問題也影響到資深員工：這兩種情況都不妙。

實作 `salaries_no_id` 函式，它會接收一個 ID 向量和對應的薪資向量，並回傳還沒有 ID 的人的薪資總和。
兩個向量的長度相同。

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```
