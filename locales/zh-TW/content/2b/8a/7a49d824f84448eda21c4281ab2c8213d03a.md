# 指令

**複數**表示為 `z = a + b * i` 的形式，其中：

- `a`是**實部**（一個實數），

- `b`是**虛部**（同樣是一個實數），

- `i`是滿足`i^2 = -1`的**虛數單位**。

## 複數的運算

### 共軛

複數`z = a + b * i`的共軛為：

```text
zc = a - b * i
```

### 絕對值

`z`的絕對值（或模）定義為：

```text
|z| = sqrt(a^2 + b^2)
```

絕對值的平方，等於`z`與其共軛`zc`的乘積：

```text
|z|^2 = z * zc = a^2 + b^2
```

### 加法

兩個複數`z1 = a + b * i`與`z2 = c + d * i`的和，就是把各自的實部與虛部分別相加：

```text
z1 + z2 = (a + b * i) + (c + d * i)
        = (a + c) + (b + d) * i
```

### 減法

兩個複數的差，就是把對應的部分相減：

```text
z1 - z2 = (a + b * i) - (c + d * i)
        = (a - c) + (b - d) * i
```

### 乘法

兩個複數的乘積定義為：

```text
z1 * z2 = (a + b * i) * (c + d * i)
        = (a * c - b * d) + (b * c + a * d) * i
```

### 倒數

非零複數的倒數為：

```text
1 / z = 1 / (a + b * i)
      = a / (a^2 + b^2) - b / (a^2 + b^2) * i
```

### 除法

一個複數除以另一個複數的結果為：

```text
z1 / z2 = z1 * (1 / z2)
        = (a + b * i) / (c + d * i)
        = (a * c + b * d) / (c^2 + d^2) + (b * c - a * d) / (c^2 + d^2) * i
```

### 指數運算

將 _e_（自然對數的底數）取複數次方，可以用歐拉公式表示：

```text
e^(a + b * i) = e^a * e^(b * i)
              = e^a * (cos(b) + i * sin(b))
```
