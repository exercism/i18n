# 指示

在這個練習中，你將幫助高中情侶在社群媒體上表達愛意，用他們的姓名縮寫產生一個 ASCII 愛心：

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 取得名字的第一個字母

實作 `HighSchoolSweetheart::firstLetter` 函式。
它應該接受一個名字，並回傳它的第一個字母。
它應該清掉名字中任何多餘的空白。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->firstLetter("Jane");
# => "J"
```

## 2. 將第一個字母格式化為姓名縮寫

實作 `HighSchoolSweetheart::initial` 函式。
它應該接受一個名字，回傳它的第一個字母，轉成大寫並在後面加上一個點。
請務必重複使用你在上一個步驟中定義的 `HighSchoolSweetheart::first_letter`。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initial("jane");
# => "J."
```

## 3. 將全名拆分為名字與姓氏

實作 `HighSchoolSweetheart::initials` 函式。
它應該接受一個全名（由名字和姓氏組成，中間以空格分隔），並回傳姓名縮寫。
請務必重複使用你在上一個步驟中定義的 `HighSchoolSweetheart::initial`。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initials("Jane Doe");
# => "J. D."
```

## 4. 將姓名縮寫放進愛心裡

實作 `HighSchoolSweetheart::pair` 函式。
它應該接受兩個全名，並回傳放在 ASCII 愛心裡的姓名縮寫。
請務必重複使用你在上一個步驟中定義的 `HighSchoolSweetheart::initials`。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->pair("Blake Miller", "Riley Lewis")
# => """
#      ******       ******
#    **      **   **      **
#  **         ** **         **
# **            *            **
# **                         **
# **     B. M.  +  R. L.     **
#  **                       **
#    **                   **
#      **               **
#        **           **
#          **       **
#            **   **
#              ***
#               *
# """
```
