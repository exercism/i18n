# 說明

Elena 是報紙工廠新上任的品質經理，她請你寫一支小程式來監控生產室。

## 1. 定義自訂錯誤

使用`ERROR:`這個解析詞來定義錯誤元組類別`machine-error`。它不需要任何欄位。

```factor
machine-error   ! throws a fresh machine-error
```

## 2. 檢查濕度

定義`check-humidity`。它會從堆疊取出濕度讀數，並在讀數嚴格大於`70`時`throw`出字串`"humidity too high"`。否則它不回傳任何東西。

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. 檢查溫度

定義`check-temperature`。它會從堆疊取出溫度讀數，並在讀數嚴格大於`500`時`throw`出字串`"temperature too high"`。否則它不回傳任何東西。

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. 監控機器

定義`monitor`，讓它從堆疊取出濕度和溫度，並執行這兩項檢查。如果任何一項檢查拋出例外，`monitor`應該改為拋出一個全新的`machine-error`。如果兩項都通過，`monitor`不回傳任何東西。

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. 監控一批讀數

定義`monitor-batch`，讓它接收一個由`{ humidity temperature }`讀數組成的陣列，並回傳其中有多少筆會失敗（也就是有多少筆會讓`monitor`拋出）。

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
