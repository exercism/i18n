# 關於

Lua 使用兩種方式來表示數字：64 位元整數與雙精度浮點數。

~~~exercism/note
在 5.3 版之前，Lua 使用雙精度浮點格式來表示所有數字。
~~~

數字可以附帶小數部分，也可以附帶十進位指數。
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

帶有小數點或指數的數字會被視為浮點數，沒有的則視為整數，但兩者的型別都是 'number'。
```lua
type(1)         --> number
type(2.0)       --> number
```

如果想區分浮點數與整數，可以使用`math`模組的`type`函式。
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## 比較

數值相同的整數與浮點數在比較時會被視為相等：
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## 算術運算

Lua 支援常見的算術運算子：加法、減法、乘法、除法與負號運算。此外還支援向下取整除法、取餘數與次方運算。

### 加法、減法、乘法與負號運算

如果兩個運算元都是整數，運算結果就是整數。浮點數也是如此。
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

如果其中一個運算元是浮點數，其餘的整數也會被轉換成浮點數，運算結果就是浮點數。
```lua
1.0 + 2   --> 3.0
```

### 除法

除法一律以浮點數進行運算，結果也是浮點數。
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

除以零會得到`inf`或`-inf`。零除以零則會得到`-nan`。
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### 向下取整除法

如果需要整數結果，可以使用向下取整除法。向下取整除法一律將商往負無窮方向取整，確保所有運算元的結果都是整數。

~~~exercism/note
在 5.3 版之前，Lua 沒有用於向下取整除法的算術運算子。
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

向下取整除法遵循與加法、減法、乘法和負號運算子相同的規則。如果兩個運算元都是整數，結果就是整數，否則結果為浮點數。

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

使用向下取整除法除以零時，Lua 會拋出錯誤。
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### 取餘數

取餘數用於取得兩個運算元相除後的餘數。
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### 次方運算

與除法一樣，次方運算也是以浮點數進行，結果為浮點數。
```lua
10 ^ 2    --> 100.0
```

## 優先順序

所有運算都會依照[運算子優先順序](https://www.lua.org/manual/5.4/manual.html#3.4.8)來求值。可以使用括號來改變運算式的優先順序。

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## 取整

`math`模組提供三個取整函式：`floor`會「向下」取整（往負無窮方向），`ceil`會「向上」取整（往正無窮方向），`modf`則往零取整。

### `math.floor`

`floor`會往負無窮方向取整。
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil`會往正無窮方向取整。
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf`會往零取整。這個函式會回傳取整後的值，以及數字的小數部分，而小數部分一律是浮點數。
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## 轉換

如果想將整數轉換成浮點數，可以對它加上`0.0`。
```lua
1 + 0.0         --> 1.0
```

如果想將浮點數轉換成整數，可以將它與零做位元 OR 運算，或使用`math`模組的`tointeger`函式。
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

如果數字無法轉換成整數，OR 運算子會拋出錯誤，而`tointeger`函式會回傳`nil`。
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## 十六進位

與許多其他程式語言一樣，Lua 支援以`0x`開頭的十六進位數字，但與許多其他程式語言不同的是，Lua 也支援浮點十六進位數字。它們可以有小數部分與二進位指數，並以 'p' 或 'P' 開頭。
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
