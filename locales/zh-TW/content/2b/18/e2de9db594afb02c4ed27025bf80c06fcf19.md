# 安裝

要執行這些練習，你只需要安裝 [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) 和 [Java 8](https://java.com/en/download/)。CommandBox CLI 支援 Mac、Linux 和 Windows，安裝指南在這裡：

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

如果你是 Mac 上的 Homebrew 使用者，設定 CommandBox CLI 的方式如下：

```bash
brew install commandbox
```

安裝好 CLI 之後，就可以玩玩看 REPL 了：

```bash
box repl
```

你也可以直接執行 .cfm 頁面：

```bash
box exec myTest.cfm
```

甚至可以在硬碟上的任何目錄啟動網頁伺服器：

```bash
box server start
```

CommandBox 有一個互動式 shell，提供更強大的 Tab 鍵自動補齊，執行速度也更快。只要執行`box`這個執行檔、不帶任何參數，就能進入這個 shell。

```bash
box
```
