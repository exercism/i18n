# 說明

你的朋友已經受夠了花錢買照片編輯軟體，決定自己寫一套。你的朋友決定把這套新軟體叫做 Foto Fusionist。

Foto Fusionist 是一套能做好多事的照片編輯軟體，不過到目前為止你只實作了其中幾項。不過，你的朋友對目前的進展很滿意，並請你再實作幾項功能。

## 1. 將二進位表示法轉換成整數

第一個功能，你的朋友希望能把數字的二進位表示法轉換成整數。這麼做是因為軟體要能讀取某個色彩通道的二進位表示法，並把它轉換成整數。

請實作方法 `FotoFusionist.binary_to_int`，它接受一個型別為 `String` 的引數 `binary`。這個方法應該回傳該二進位數字的整數表示法。

```crystal
FotoFusionist.binary_to_int("10011")
# => 19
```

## 2. 從整數取得最低有效位

你的朋友想要的第二個功能，是能從整數取得[最低有效位][least-significant-bit]。最低有效位是最靠右邊的位元。它被叫做最低有效位，是因為它的值最小。

我們需要最低有效位，來判斷能否藉由減少用來表示色彩通道的位元數，來最佳化一張圖片。

請實作方法 `FotoFusionist.least_significant_bit`，它接受一個型別為 `Int32` 的引數 `number`。這個方法應該回傳該數字的最低有效位。

```crystal
FotoFusionist.least_significant_bit(0b10011)
# => 1

FotoFusionist.least_significant_bit(0b10010)
# => 0
```

## 3. 從色彩通道取得十六進位值

你的朋友想要的第三個功能，是能從色彩通道取得十六進位值。我們需要十六進位值，才能把色彩通道轉成十六進位表示法，而且給定的十六進位表示法必須由兩位數組成。

請實作方法 `FotoFusionist.hex_value`，它接受一個型別為 `Int32` 的引數 `number`。這個方法應該把該數字的十六進位值以 `String` 回傳。

```crystal
FotoFusionist.hex_value(19)
# => "13"
```

## 4. 從 RGB 取得十六進位值

你的朋友想要的第四個功能，是能從 RGB 色彩取得十六進位值。這是為了讓使用者能取得顏色的單一字串表示法。RGB 色彩是由三個色彩通道表示的顏色：紅色、綠色和藍色。每個色彩通道都由一個 0 到 255 之間的數字表示。

RGB 色彩的十六進位值，就是該顏色以十六進位表示的字串，其中紅色通道在最前面，接著是綠色通道，最後是藍色通道。

請實作方法 `FotoFusionist.hex_value_from_rgb`，它接受三個引數：型別為 `Int32` 的 `red`、`green` 和 `blue`。這個方法應該把該 RGB 色彩的十六進位值以 `String` 回傳。

```crystal
FotoFusionist.hex_value_from_rgb(255, 0, 0)
# => "ff0000"
```

[least-significant-bit]: https://en.wikipedia.org/wiki/Least_significant_bit
