# 說明

你在無板籃球比賽中負責操作計分板。和目前為止的一切不同，計分板必須記住發生過的事。

`SCOREBOARD`類別需要以下內容。這個程式骨架已提供類別和它的兩個屬性宣告；請補上其餘部分。

## 1. 設定計分板

`create`接受主隊名稱與客隊名稱，並回傳一個兩隊分數都是零的計分板。

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. 進一球

`home_goal`會將主隊分數加一，`away_goal`則會將客隊分數加一。兩者都不回傳任何值。

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. 讀取計分板

`summary`會以比賽紀錄的格式回傳計分板：主隊、主隊分數、一個連字號、客隊分數，然後是客隊。

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

空格必須完全如上所示，而連字號是單一個`-`。

## 4. 誰領先？

`leader`會回傳領先隊伍的名稱，當分數平手時則回傳`"Draw"`。

```sather
board.leader
-- => "Vixens"
```

## 5. 領先多少？

`margin`會回傳兩隊相差多少球。無論哪隊領先，它永遠不會是負數。

```sather
board.margin
-- => 1
```
