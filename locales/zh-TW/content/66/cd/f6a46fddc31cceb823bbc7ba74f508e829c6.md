# 關於

在 C# 中配置記憶體，最重要的一點是這件事是_自動_完成的，不需要手動配置記憶體。為了讓自動配置的記憶體在不再使用時也能被釋放，C# 使用了[垃圾回收器][docs.microsoft.com_garbage-collection-fundamentals]。

使用 C# 時會用到兩種不同的記憶體：

- 堆疊。
- 堆積。

堆疊的生命週期很短，可用的空間也有限。一旦超過堆疊允許的記憶體上限，就會擲回`StackOverflowException`。每個執行緒都有自己專屬的堆疊。由於方法回傳後堆疊會自動「回溯」，因此不需要垃圾回收器介入。這表示在堆疊上配置與釋放記憶體的速度都非常快。

堆積的生命週期很長，可用的記憶體也很多。配置物件時，記憶體配置器會在堆積上找到一些可用記憶體並加以配置。堆積由各個執行緒共用，也能用來共享資料。每隔一段時間，垃圾回收器會暫停執行（也就是所謂的「GC 暫停」），並檢查是否有不再使用的物件。如果有，這些物件的記憶體就會被釋放，之後可以再次配置使用。

## 什麼東西放在哪裡？

原則上，實值型別會配置在堆疊上，參考型別則配置在堆積上。不過也有一些例外，例如當實值型別是參考型別的一部分時（像是某個帶有`int`欄位的類別）。
