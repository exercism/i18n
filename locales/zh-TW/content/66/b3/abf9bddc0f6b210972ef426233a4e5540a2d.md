# 說明

身為見習魔術師的 Elyse，需要練習一些基本功。她有一副牌，想要好好地操作它們。

為了讓事情簡單一點，她只用 1 到 10 這幾張牌。

## 1. 從牌組中取出一張牌

實作 `getCard`函式，回傳指定牌組中位置為`index`的牌。如果`index`不在牌組中，就回傳 Nothing。

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. 更換牌組中的一張牌

實作 `setCard`函式，回傳將牌組中位置為`index`的牌更換成新牌之後的牌組。
如果`index`不在牌組中，就回傳原本的牌組。

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. 在牌組中新增一張牌

實作 `addCard`函式，回傳加入新牌之後的牌組。

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. 從牌組中移除一張牌

實作 `removeCard`函式，回傳將位置為`index`的牌移除之後的牌組。
如果給定的`index`不是牌組中的有效索引，就回傳原本的牌組。

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. 計算牌組中偶數牌的數量

實作 `evenCardCount`函式，計算牌組中有多少張偶數牌。

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
