# 簡介

每次呼叫函式時，記憶體中都會建立一個新的堆疊框架，用來儲存該函式的引數和區域變數，而當函式回傳時，這個堆疊框架就會被釋放。由於 Gleam 使用遞迴函式呼叫來取代迴圈語法，這些堆疊框架可能會佔用大量記憶體。

為了解決這個問題，Gleam 支援尾端呼叫最佳化。如果函式的最後一件事就是呼叫另一個函式，編譯器便能重複使用目前函式的堆疊框架。這代表函式可以無限次呼叫自己，而不會用到任何額外的記憶體。

未經最佳化的遞迴函式，通常可以透過*累加器*改寫成尾端呼叫最佳化的函式。

累加器是一個變數，會連同資料一起傳遞。它用來傳遞函式執行過程中的目前狀態，直到抵達基底情況為止。

累加器應該由函式的作者初始化，而不是由函式的使用者。為了做到這一點，要宣告兩個函式：一個公開函式，只接受必要的資料作為引數，並初始化累加器；以及一個私有函式，它也接受一個累加器。

```gleam
// Count the length of a list without tail call optimisation
pub fn count(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> {
      let amount = count(rest) // Non-tail recursive call
      amount + 1
    }
  }
}
```

```gleam
// Count the length of a list with tail call optimisation
pub fn count(list: List(String)) -> Int {
  count_elements(list, 0)
}

fn count_elements(list: List(String), accumulator: Int) -> Int {
  case list {
    [] -> accumulator
    [_, ..rest] -> {
      let accumulator = accumulator + 1
      count_elements(rest, accumulator) // Tail recursive call
    }
  }
}
```
