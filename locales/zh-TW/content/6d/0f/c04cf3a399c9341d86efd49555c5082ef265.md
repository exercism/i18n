# 簡介

## IO

處理輸入與輸出的函式由`IO`模組提供。

### 輸出

要把字串寫到標準輸出，請使用`IO.puts`。`IO.puts`一定會在字串結尾加上換行。如果不想要這種行為，請改用`IO.write`。這兩個函式成功時都會回傳原子`:ok`。

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`很適合用來輸出字串，但也就僅止於此。如果你需要一個除錯工具，讓你能把任何值寫到標準輸出，請改用`IO.inspect`。`IO.inspect`會原封不動地回傳傳入的值，因此可以放在程式碼的任何位置。它也接受許多選項，例如`:label`，讓你能把它和其他`IO.inspect`呼叫區分開來。

### 輸入

要從標準輸入讀取一行，請使用`IO.gets`。`IO.gets`接受 1 個引數，也就是一段會印出來當作輸入提示的字串。`IO.gets`不會在提示後面加上換行，需要的話請自己加上。

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
