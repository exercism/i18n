# 安裝

## 安裝 .NET

C# 課程建立在 [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) 平台之上，可在 Windows、Linux 和 macOS 上執行。
若要建置 .NET 專案，你可以使用 .NET 命令列介面（Command Line Interface，簡稱 CLI）。
這個 CLI 是 .NET SDK 的一部分，只要依照[安裝指示](https://dotnet.microsoft.com/download/dotnet/8.0)操作就能安裝。
注意：C# 課程需要 9.0 以上版本的 SDK。

安裝完成後，你可以在終端機執行下列指令，確認 CLI 是否安裝成功：

```bash
dotnet --version
```

如果輸出是大於或等於`9.0.100`的版本，就代表 .NET SDK 已安裝成功。

## 使用 IDE

如果你想要功能更完整的編輯體驗，不妨使用[整合開發環境（IDE）](https://en.wikipedia.org/wiki/Integrated_development_environment)。
以下是支援建置 .NET 專案、最受歡迎的幾款 IDE：

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) 搭配 [C# 擴充功能](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

注意：由於 .NET 的專案格式與舊版差異很大，較舊的 IDE（例如 Visual Studio 2015）並不支援。
