# 安裝

這個 track 的解答是用 32 位元 RISC-V 組合語言撰寫，並在模擬環境中執行，所以不需要 RISC-V 硬體。
每個練習都附有一份 Makefile，負責建置測試並執行測試。
要使用它，你需要三項工具：

- [Zig][zig]：透過`zig cc`提供 RISC-V 組譯器、C 編譯器和連結器。
- [Make][make]：負責執行建置。
- [QEMU][qemu] 的`qemu-riscv32`：負責執行建置出來的程式。

## macOS

使用任何合適的虛擬化解決方案（例如 [Lima][lima]）啟動一台 Linux 虛擬機，然後依照下方其中一個 Linux 發行版本的章節操作。

## Windows

使用 [Windows Subsystem for Linux][wsl]，並依照下方其中一個 Linux 發行版本的章節操作。
或者，你也可以架設一台 Linux 虛擬機。

## Debian / Ubuntu

安裝 Make 和 QEMU 的使用者模式模擬器：

```shell
sudo apt install make qemu-user
```

接著按照[直接下載][zig-install]的說明安裝 Zig 0.15.2 或更新版本。

## Fedora

用以下指令安裝這三項工具：

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

用以下指令安裝這三項工具：

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

用以下指令安裝這三項工具：

```shell
sudo zypper install zig make qemu-linux-user
```

## 檢查安裝

確認這三項工具都能找到：

```shell
zig version
make --version
qemu-riscv32 --version
```

接著用 Exercism CLI 下載一個練習，並執行它的測試：

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
