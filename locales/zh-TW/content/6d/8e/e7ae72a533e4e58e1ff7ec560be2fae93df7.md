# 資源

* [The Rust Programming Language](https://doc.rust-lang.org/book/) 是入門 Rust 以及深入探索特定功能的好資源。
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) 會用範例帶你認識在 Rust 中最常寫到的東西。
* 你可以用 [Rust API Documentation](http://doc.rust-lang.org/std/) 來發掘新的方法，並了解它們怎麼運作。
* 遇到問題時，可以用 [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) 搜尋看看有沒有人問過，也可以在上面提問與回答。
* [Rust User Forum](http://users.rust-lang.org) 是一般 Rust 討論的園地。
* [/r/rust](http://www.reddit.com/r/rust/) 是官方的 Rust Reddit 看板。
* [The Rust Programming Language](https://discord.gg/rust-lang) 在 [Discord](https://discordapp.com/) 上的官方伺服器，可以用來快速提問，以及討論這個語言。
