# 指示

你的公司一直在處理地圖資料，用來建立網頁。
經過一番討論後，決定開始使用 R 來動態執行一些計算。

請盡量直接處理向量點：不需要把它們拆解成獨立的`x`和`y`座標。

## 1. 縮放座標

實作`scale(point, s)`函式，它會接收一個任意維度數的點，並依照預先定義的`s`縮放。

```R
# A 2D example
s <- c(0.5, 0.8)
point <- c(10, 5)
scale(point, s)
#> [1] 5 4
```

## 2. 平移座標

實作`translate(point, ...)`函式，它會回傳一個新的點，每個座標都依照省略號中的值移動。

這個函式必須能處理任意維度的點，且省略號引數的數量要與該維度相符。

```R
point2d <- c(2, 3)

# supply dx, dy translations
translate(point2d, 0.5, 0.6)
#> [1] 2.5 3.6

point3d <- c(2, 3, 4)

# supply dx, dy, dz translations
translate(point3d, 0.5, 0.6, 0.7)
#> [1] 2.5 3.6 4.7
```

## 3. 轉換 2D 點

你的某些團隊成員對 R 比較不熟悉，所以你決定用函式閉包，為`{x, y}`座標對建立可重複使用的轉換。

實作`transform2d(dx, dy, s)`函式，它會回傳一個運用閉包的函式，對點執行可重複的 2D 平移與縮放。

縮放引數`s`應該是選用的，預設值為`1`。

回傳的函式應該接受一個 2D 點，然後：

1. 依照預先定義的`dx`和`dy`平移它
2. 依照`s`縮放它

```R
# scale all coordinates by the same amount (2) in this example
# your code needs to be able to handle a vector `s`

tf2d <- transform2d(0.5, 0.6, 2)
class(tf2d)
#> [1] "function"

tf2d(c(2, 3))
#> [1] 5.0 7.2

# Accept default for `s`
tf2d <- transform2d(0.5, 0.6)

tf2d(c(2, 3))
#> 2.5 3.6
```

運算的順序很重要：先平移再縮放會得到正確的結果，先縮放再平移則不會。
用技術性的說法，這些運算_不具交換律_。

## 4. 轉換 3D 點

地圖資料也可能包含高度，用來在螢幕上加入陰影與等高線。

實作`transform3d(dx, dy, dz, s)`函式，它會回傳一個函式。

縮放引數`s`應該是選用的，預設值為`1`。

回傳的函式應該接受一個 3D 點，依照預先定義的值平移它，然後再依照`s`縮放它。

```R
# using default `s`
tf3d <- transform3d(0.5, 0.6, 0.7)
point <- c(2, 3, 4)
tf3d(point)
#> [1] 2.5 3.6 4.7

# using vector `s`
tf3d <- transform3d(0.5, 0.6, 0.7, c(0.5, 0.6, 0.7))
tf3d(point)
#> [1] 1.25 2.16 3.29
```
