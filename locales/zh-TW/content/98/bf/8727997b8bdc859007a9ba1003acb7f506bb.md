# 指令

在這道練習中，你會寫一些程式碼，幫助你準備購買一輛車。

你有三個任務：判斷你是否需要駕照、在兩輛車之間做出選擇，以及估算一輛中古車的合理價格。

## 1. 判斷你是否需要駕照

有些種類的車輛需要駕照才能操作。
假設只有 `"car"` 和 `"truck"` 這兩種需要駕照，其他種類都可以在沒有駕照的情況下操作。

實作 `needsLicense(kind)` 函式，它接收車輛的種類，並回傳一個布林值，表示你是否需要這種車輛的駕照。

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. 在兩輛可能購買的車輛之間做選擇

你評估了手上所有可選的車輛。
你成功把選項縮小到兩個，但需要有人幫你做最後的決定。
為此，請實作 `chooseVehicle(option1, option2)` 函式，它接收兩輛車作為引數，並回傳一個決定，其中包含在[字典序][lexicographical-order]中排在前面的那個選項。

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 估算中古車的價格

既然你已經做出決定，你會想確保自己在車行拿到合理的價格。
由於你想買的是中古車，價格取決於車齡。
粗略估算的話，假設車輛不到 3 年，價格是全新時原價的 80%。
如果車齡至少 10 年，則是 50%。
如果車齡至少 3 年但不到 10 年，則是原價的 70%。

實作 `calculateResellPrice(originalPrice, age)` 函式，使用 `if`、`else if` 和 `else` 來套用這套邏輯（如果你想多練習，也有其他寫法）。
它接收原價和車齡作為引數，並回傳車行的估價。

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
