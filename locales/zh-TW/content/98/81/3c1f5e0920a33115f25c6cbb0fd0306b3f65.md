# 指令補充

## 詞

定義一個 `custom-set` 元組，並用 `INSTANCE: custom-set set` 宣告它是 `set` 混入的實例。

- `<custom-set> ( -- set )`，建立一個空集合。
- `>custom-set ( seq -- set )`，從序列建立一個集合，並默默捨棄重複的元素。

接著，為 `custom-set` 提供 `M:` 方法（來自 `sets`），涵蓋 `members`、`in?`、`adjoin` 和 `set-like`。有了 `INSTANCE:` 宣告和這四個方法之後，來自 `sets` 詞彙的 `null?`、`union`、`intersect`、`diff`、`subset?`、`set=` 和 `intersects?`，都會透過協定的預設實作在你的集合上運作；測試會直接呼叫這些詞。

`adjoin ( elt set -- )` 會就地修改集合：如果 `elt` 還沒出現在 `set` 裡，就把 `elt` 加入 `set`。
