# 字串建構器

一個`STR`永遠不會改變。所以`+`沒辦法直接把內容加到它身上，只能建立一個全新的字串，把兩邊的內容都放進去。

偶爾做一次沒問題，但放進迴圈裡就行不通了：

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

每一輪都會把目前累積的內容複製到新的字串，然後把舊的丟掉。10 行代表 10 份複本，而且一份比一份長。100 行就是 100 份。工作量會隨著行數的*平方*成長，一個看起來無害的迴圈，就成了拖慢整個程式的元凶。

## FSTR

`FSTR`是一種*可以*改變的字串，也就是**字串建構器**。對它加入內容時，通常只是寫進它已經有的空間，所以處理 100 行的迴圈大約只做 100 行份量的工作，而不是產生 100 份複本。

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

有三件事值得注意。

**`#FSTR`會建立一個空的建構器。**`#FSTR(100)`則會建立一個已經預留好 100 個字元空間的建構器，當你事先知道大小時，這麼做很值得。

**你必須把結果指定回去。**一定要寫成`script := script + ...`，絕不能單獨寫`script + ...`。通常回傳的會是原本那個建構器，但當空間用完時，它會是更大、全新的那一個；要是把回傳值丟掉，你就會繼續寫進舊的建構器裡。

**最後要加上`.str`。**一個宣告回傳`: STR`的函式必須交回一個`STR`，而`.str`就是用來從建構器產生一個`STR`。

## 可以加入什麼

`FSTR`上的`+`可以接受字串、字元、整數或布林值，所以通常不需要先做轉換：

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## 換行

字串裡的`"\n"`代表一個換行，也就是一個字元，卻用兩個字元寫成。

```sather
   script := script + "Enter" + "\n" + "Exit";
```
