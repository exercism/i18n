# 指示

在這道練習中，你將為一間位於紐約、於 2012 年 9 月 15 日開幕的美容沙龍開發預約排程系統。

## 1. 解析預約日期

實作`AppointmentScheduler.schedule()`方法，將預約日期的文字表示法解析成對應的`LocalDateTime`：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. 檢查預約是否已經過去

實作`AppointmentScheduler.hasPassed()`方法，它會接收一個預約日期，並檢查該預約是否發生在過去的某個時間點：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. 檢查預約是否在下午

實作`AppointmentScheduler.isAfternoonAppointment()`方法，它會接收一個預約日期，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 描述預約的時間與日期

實作`AppointmentScheduler.getDescription()`方法，它會接收一個預約日期，並回傳該日期與時間的描述：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. 回傳週年紀念日

實作`AppointmentScheduler.getAnniversaryDate()`方法，回傳今年的週年紀念日，也就是 9 月 15 日：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
