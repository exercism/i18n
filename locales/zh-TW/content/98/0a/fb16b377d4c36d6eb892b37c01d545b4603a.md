# 提示

## General

- 請參考 [Elm Guide][elm-guide]，裡面有一個很類似的完整範例。

## 1. 定義應用程式的`Model`與`Msg`型別，並撰寫`init`函式

- `Model`包含應用程式的狀態，也就是應用程式需要的所有資料。
- 它應該是一個[記錄][record]。
- 這個應用程式只需要一個`String`來儲存文字方塊裡的文字（測試要求它必須叫做`content`）。

- `Msg`型別定義要傳遞給`update`函式的訊息，用來觸發模型中特定的變更。
- 它應該是[自訂型別][custom-type]。
- 這個應用程式只需要一種模型變更，也就是當文字方塊裡的文字改變時更新模型。

- `init`函式應該直接回傳一個帶有合理預設值的`Model`（測試要求空字串）。

## 2. 撰寫 update 函式

- 在任何實用的應用程式中，update 函式都會用`case`敘述對`Msg`參數進行模式比對。
- 在 case 敘述的每個分支中，它會從`Msg`參數取出需要的資訊，並回傳更新後的`Model`。
- `Model`應該是記錄，而且通常會使用[記錄更新語法][record-update-syntax]。

## 3. 撰寫 view 函式

- view 函式應該為根元素回傳一個`div`。
- 第一個子元素應該是`input`，帶有儲存目前文字的`value`屬性，以及對應`Msg`變體的`onInput`屬性／事件。
- 第二個子元素應該是另一個`div`，裡面有一個`text`子元素，用來說明這段文字是不是迴文。

## 4. 撰寫 main 函式

- main 函式應該只要呼叫[`Browser.sandbox`][browser-sandbox]
- `Browser.sandbox`需要一個[記錄][record]引數，裡面包含`init`、`update`和`view`函式。
