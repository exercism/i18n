# 簡介

雜湊是 Perl 的一種資料型態，內含無序的字串鍵，每個鍵各自搭配一個純量值。

雜湊變數通常透過指定一個陣列來填入內容，例如`my %scores = (Alice => 10, Bob => 15, Charlie => 20);`。

陣列中的元素通常以逗號分隔，但你經常會看到所謂的「胖逗號」`=>`，用來分隔陣列裡的鍵與值。它的行為幾乎和逗號一模一樣，但額外的好處是會把左邊的元素解讀成字串。

雜湊也可以透過指定個別的鍵來填入內容，例如`$scores{Alice} = 10;`。

只要用下標指定鍵，就能存取雜湊中的值，例如`$scores{Bob} # 15`。

雜湊中的鍵是唯一的。如果同一個鍵被提供多次，只有最後提供的值會被保留。

## 函式

處理雜湊的函式包括 [keys][keys] 和 [values][values]，可分別取出雜湊中對應的部分並以陣列回傳。[keys][keys] 和 [values][values] 函式回傳的陣列，可以搭配 [grep][grep]、[map][map]、[sort][sort] 等陣列函式，以及 [for][for] 迴圈使用。

其他雜湊函式還包括 [exists][exists]，可用來檢查某個鍵是否存在於雜湊中（即使它的值是`undef`），以及 [delete][delete]，可用來從雜湊中移除某個鍵。

## 符號的差異

取得雜湊的值時，使用哪個符號會決定結果。變數名稱結尾的`{}`下標，就是告訴 Perl 你正在存取這個名稱的雜湊。

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

雖然這是允許的，但為了可讀性，建議不要讓不同型別的變數共用同一個名稱。
