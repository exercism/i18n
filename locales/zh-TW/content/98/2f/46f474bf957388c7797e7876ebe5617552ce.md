# `while`迴圈與`until`迴圈

迴圈是一種控制結構，能讓程式碼依據給定的條件重複執行。

## `while`迴圈

`while`迴圈是一種控制結構，能讓程式碼依據給定的條件重複執行。
只要條件求值為真，`while`迴圈裡的程式碼就會持續執行。
當事前不知道疊代的次數時，通常會使用 `while` 迴圈，不過任何需要迴圈的情況都能派上用場。

條件會在迴圈裡的程式碼執行之前先求值，也就是說，如果條件為假，迴圈裡的程式碼永遠不會被執行。

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

想疊代一個字串時，可以對字串的長度跑迴圈。

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`迴圈

`until`迴圈的運作方式和 `while` 迴圈相同，差別在於迴圈裡的程式碼會持續執行，直到條件求值為真為止。
這就如同 `if` 和 `unless` 之間的差異。

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 無限迴圈

`while` 迴圈常見的錯誤是進入一個「無限迴圈」，永遠跳不出來。
無限迴圈可能起因於條件_永遠_不會求值為真或為假。
這通常是開發者的疏失，例如忘記遞增迴圈變數。
但有時，無限迴圈是實作程式邏輯最清楚的方式。
又或者，永遠迴圈是必要的；例如 HTTP 伺服器會等待進來的連線、處理它，然後再等待下一個連線。

## `break`

`break`關鍵字可以用來提早跳出迴圈。
當你想在特定條件下提早跳出迴圈時，這很方便。

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next`關鍵字可以用來跳到迴圈的下一次疊代。
當你想跳過迴圈中特定的疊代時，這很方便。

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## 迴圈下的型別

變數的型別在迴圈中可能有所不同。
在下面的範例裡，`a`的型別是`Int32 | String`，因為它在迴圈的前半段可能是`Int32`或`String`。
變數`a`只會在迴圈的前半段帶有`Int32 | String`型別，因為迴圈開始時它存放的是`Int32`，而到了第二次疊代，它存放的是`String`。
這套多重型別系統之後會再詳細說明。
不過由於我們確定迴圈的後半段只會存放`String`，所以`a`在迴圈後半段的型別是`String`。
在執行期間，它永遠不會同時存放`Int32`和`String`。

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
