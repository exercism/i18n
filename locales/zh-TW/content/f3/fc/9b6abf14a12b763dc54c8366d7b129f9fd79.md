# 安裝 Delphi 與 DUnitX 測試框架 #
## Windows ###

有免費的 [Community Edition](https://www.embarcadero.com/products/delphi/starter) 版本可以使用。請依照產品隨附的安裝說明操作。

## 非 Windows 作業系統 ###

Delphi 只能在 Windows 作業系統上執行。你也可以在裝有 Windows 的虛擬機中執行 Delphi。

## 安裝 DUnitX 測試框架 ###
在安裝 Delphi XE8 及以上版本時，可以選擇一併安裝 DUnitX。不過，我建議按照下面的說明，直接從作者的 GitHub 儲存庫手動取得一份 DUnitX，因為那裡更新得更頻繁。

Delphi 安裝完成後，如果你發現自己的 Delphi 安裝中缺少這套測試框架，請依照以下步驟取得並安裝 DUnitX。

- DUnitX 是 [VSoftTechnologies](https://www.github.com/VSoftTechnologies) 的開源專案。DUnitX 的 GitHub 儲存庫在[這裡](https://github.com/VSoftTechnologies/DUnitX)。
- 最好先 fork 這個儲存庫，再 clone，或用其他方式把 fork 下載到你的本機。
- Vincent Parrett 在[這篇部落格文章](https://www.finalbuilder.com/resources/blogs/postid/702/dunitx-has-a-wizard)中，提供了如何把 DUnitX 安裝到 Delphi 的逐步說明。

## 為 DUnitX 設定 Delphi ###

如果你是因為自己的 Delphi 安裝沒有內含 DUnitX 而手動安裝的，請依照以下圖文步驟，對 Delphi 做必要的設定變更，讓它能找到你安裝的 DUnitX。

*注意：這裡假設你此時已經完成 Delphi 的安裝。*

- 啟動 Delphi。如果你的安裝是全新的，很可能會看到類似這樣的 `Welcome Page`。

[![Welcome Page](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/00delphiwelcomepageLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/00delphiwelcomepage.png)

- 在上方選單中找到並點選 `Tools`。
 
![Tools](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/01delphiclicktools.png)

- 點選 `Options`。

![Options](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/02delphiclickoptions.png)

- 在 Options 畫面左側找到並點選 `Environment Variables`。

[![Options Screen Environment Variables](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/03delphioptionsenvironmentvariablesLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/03delphioptionsenvironmentvariables.png)

- 點選 `User overrides` 群組中的 `New` 按鈕。

![點選 New](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/04delphioptionsenvironmentvariablesclicknew.png)

- 接著會出現一個 New User Variable 視窗，裡面有兩個欄位。在上方欄位的 Variable Name 中輸入 `DUNITX`。在下方欄位輸入你那份 DUnitX 的完整路徑，例如我的是 `C:\Program Files\Embarcadero\Studio\19.0\source\DUnitX`。*你可能沒有 19.0 這個資料夾，這取決於你安裝的 Delphi 版本。* 然後點選 `Ok` 按鈕關閉這個視窗。

![New User Variable](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/05delphinewuservariable.png)

- 在 Options 畫面左側找到並點選 `Library`。

[![Library](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/06delphioptionslibraryLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/06delphioptionslibrary.png)

- 點選 Directories 群組中 Library 路徑旁邊的 `...` 按鈕

[![...button](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/07delphiclicklibrarypathbuttonLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/07delphiclicklibrarypathbutton.png)

- 在 Directories 視窗中輸入你剛才建立的變數名稱。輸入內容應該像這樣 `$(DUNITX)`

![Directories](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/08delphidirectoriesinputvarnameclickadd.png)

- 點選 `Add` 按鈕，把這個新項目加入清單。

- 點選 `Ok` 按鈕儲存這項變更。


- 最後，點選 Options 視窗上的 `Ok` 按鈕，儲存所有變更。

現在 Delphi 就能找到屬於 DUnitX 測試框架程式庫的單元了。

*注意：這裡假設學員使用的是 Delphi XE 或更高的版本。*
