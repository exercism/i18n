# 關於

Rust 實作 [char][char type] 型別來表示單一字元。`char`字面值會放在單引號內，例如`'a'`。每個`char`大小為四個位元組，代表單一的 [Unicode 純量值][unicode scalar]。

不過，[`char`][character type]並非總是我們認知的字母。有些語言（例如印地語）會使用[變音符號][diacritics]，這些是附加在字元上、用來修飾該字元的特殊符號。雖然在 Rust 中，變音符號是獨立的`char`，但我們通常會把變音符號和它所修飾的字元一起視為一個字母。

字元與其變音符號的組合，稱為[字素叢集][grapheme cluster]。有一些外部的 crate 可以用來處理字素叢集，例如 [unicode-segmentation][unicode-segmentation]。

範例

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

會輸出

```rust
2
'u'
'\u{308}'
```

'\u{308}' 是另一種書寫`char`字面值的方式。`\u`表示這是 Unicode `char`，其中`{308}`是該字元或變音符號專屬的 Unicode 編號。
