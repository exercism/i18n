# 類別的 static 關鍵字

類別是 PHP 中組織程式碼的單位，通常代表某個事物、服務或程序的實例。使用`static`和`self`關鍵字，屬性和方法就可以參照類別本身而存在，供所有實例（或不需要任何實例）使用。

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## 限制

static 類別方法只能呼叫自己所屬類別中的其他 static 類別屬性或類別方法。
