# 介紹

## 陣列

我們使用的程式語言叫做 Lisp，這個名字是 _LIST Processing_ 的縮寫，所以你可能會猜想這門語言具備處理項目陣列的能力。沒錯，你說對了！

雖然 Common Lisp 有陣列以外的其他資料結構，但陣列依然被大量使用。

在 Common Lisp 中，陣列是一連串的項目。它也被稱為 **cons**（大多是基於歷史因素）。這些項目本身不一定要是相同的型別。例如，你可以有一個包含`1`、`two`、`"III"`的陣列。

### 建立陣列

你可以直接輸入像這樣帶引號的陣列：`'(1 two "III")`，這樣就會建立並求值一個陣列（它會求值成 `(1 two "III")`）。

還有兩個用來建立陣列的主要函式：`list` 和 `cons`。

`list` 接受零個或多個引數，並求值成一個用這些值建立起來的陣列：

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` 接受兩個項目，並建立一個陣列，把第一個項目當作它的 `car`（陣列的開頭），第二個項目當作它的 `cdr`（陣列的其餘部分）：

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

函式 `car` 和 `cdr` 可以用來存取陣列的 `car` 和 `cdr`。

（`first` 和 `rest` 是 `car` 和 `cdr` 的同義詞，運作方式完全相同。）

### 長度與隨機存取

陣列的長度可以用 `length` 取得。空陣列的長度是零。

任意項目都可以用 `nth` 存取（請注意，陣列的索引從 0 開始）。

要求超出陣列長度的索引，並_不_算錯誤。它會求值成 `nil`：

```lisp
(nth 23 '(short list)) ; => nil
```

還有幾個用來存取陣列開頭項目的輔助方法：`first`、`second`、`third`，一路到 `tenth`。很方便吧？

### 合併陣列

兩個或多個陣列可以用 `append` 合併：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

傳給 `append` 的每個引數都必須是陣列。
