# 說明

你正在為一台復古掌上型遊戲機的計分系統撰寫韌體。
這台機器的 CPU 效能不高，計分板螢幕則以固定頻率更新。
為了讓畫面保持流暢，不論玩家正在做什麼，計分常式都必須在可預測的週期數內執行完畢。

你有四個任務。

~~~~exercism/note
這些任務的程式碼應該不帶分支。
請使用 `cmovcc`、`setcc` 和算術運算，而不要使用條件跳躍。
~~~~

## 1. 加入獎勵分數而不讓顯示溢位

掌機 LCD 的計分區域可以顯示 6 位十進位數字。
它無法顯示任何大於 `999999` 的數字。
當獎勵分數會讓累計總分超過這個上限時，顯示的總分會維持在最大值，而不是繞回。

請定義一個函式 `add_bonus`，它接受目前的總分和要加入的獎勵分數，回傳限制在 `999999` 以內的新總分。
引數依序為：

1. `total`：目前的總分（永遠介於 `0` 和 `999999` 之間）
2. `bonus`：要加入的獎勵分數（永遠是非負數）

若兩者的和小於或等於 `999999`，回傳值就是 `total + bonus`；否則為 `999999`：

```c
add_bonus(500, 100);
// => 600
add_bonus(999990, 50);
// => 999999
add_bonus(999999, 0);
// => 999999
```

兩個引數和回傳值都是 64 位元有號整數。

~~~~exercism/note
你可以假設 `total + bonus` 不會讓 64 位元有號整數溢位。
~~~~

## 2. 比較兩個分數

掌機會在存檔中保存一份小型排行榜，記錄玩家最近的最佳分數。
每次遊玩結束後，新的分數會插入排行榜中正確的位置。
排序常式會詢問兩個分數中哪一個領先，並預期得到一個小整數作為答案。

請定義一個函式 `compare_scores`，它接受兩個分數，並回傳：

- 如果第一個分數_較高_，回傳 `+1`
- 如果第一個分數_較低_，回傳 `-1`
- 如果兩個分數_相等_，回傳 `0`

範例：

```c
compare_scores(500, 300);
// => 1
compare_scores(300, 500);
// => -1
compare_scores(500, 500);
// => 0
```

兩個引數和回傳值都是 64 位元有號整數。

## 3. 驗證原始分數

多人對戰結束後，掌機可以透過連接線與另一台主機連線，互相分享分數。
這條連接線容易受到電氣雜訊干擾，傳入的位元組偶爾會損毀，產生遠低於合法下限或遠高於合法上限的值。
驗證器會先把每個傳入的分數限制在合法範圍內，才讓系統其他部分看到它。

請定義一個函式 `validate_score`，它接受原始分數和合法範圍，回傳限制在 `[min, max]` 內的分數。
引數依序為：

1. `score`：透過連接線收到的原始分數
2. `min`：允許的最小分數
3. `max`：允許的最大分數

若 `score < min`，回傳值為 `min`；若 `score > max`，回傳值為 `max`；否則回傳 `score`。
你可以假設 `min <= max`。

範例：

```c
validate_score(450, 0, 500);
// => 450
validate_score(-50, 0, 1530);
// => 0
validate_score(1234567, 0, 2999);
// => 2999
```

所有引數和回傳值都是 64 位元有號整數。

## 4. 追蹤最高的兩個分數

每次遊玩結束時，掌機會掃描存檔中的最近遊玩紀錄，找出有史以來最高的兩個分數。
這份紀錄在記憶體中就是一個單純的 64 位元有號整數陣列。
掃描會走訪陣列一次，並持續保留兩個目前最大值：目前為止的最高分，以及第二高分。

請注意，這兩個數字都應該至少為 `0`。
任何負數都會被忽略。

這個函式的第一版是用層層串接的條件跳躍寫成的。
對每個候選值，程式碼會判斷它該落在哪裡（高於第一、介於第一和第二之間，或哪裡都不放），並據此調整目前的最大值，同時捨棄任何負的結果。

這樣做可行。
不過，由於輸入值是隨機的，每個條件跳躍都會導致大量的分支預測錯誤。
這就是你決定把主迴圈改寫成無分支的原因。

以下是將帶分支的部分註解掉的函式：

```x86asm
; rdi = output buffer for two elements, rsi = input array address, rdx = number of elements in array
top_two:
    xor r8d, r8d                   ; first  = 0
    xor r9d, r9d                   ; second = 0
    xor ecx, ecx                   ; index = 0
    test rdx, rdx
    jz .done

;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
;                       BRANCHY CODE TO REFACTOR
;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
;.loop:
;    mov rax, qword [rsi + 8*rcx]   ; candidate
;    inc rcx
;    cmp rax, r8
;    jle .check_second              ; candidate <= first, try second
;    mov r9, r8                     ; second = first
;    mov r8, rax                    ; first  = candidate
;    cmp rcx, rdx
;    jb .loop                       ; go to next iteration
;    jmp .done                      ; otherwise, we are done
;.check_second:
;    cmp rax, r9
;    jle .loop                      ; candidate <= second, go to next iteration
;    mov r9, rax                    ; second = candidate
;    cmp rcx, rdx
;    jb .loop                       ; go to next iteration
;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;

.done:
    mov qword [rdi], r8            ; save first
    mov qword [rdi + 8], r9        ; save second
    ret
```

請用無分支的實作取代被註解掉的部分。
新程式碼中唯一允許的跳躍，是跳回迴圈開頭以檢查陣列中下一個元素的那一個。

這個函式沒有回傳值，並接受與帶分支版本相同的引數：

1. `out`：輸出緩衝區，函式會把最高的兩個非負分數以遞減順序寫入其中，型別為 64 位元有號整數
2. `array`：64 位元有號整數的輸入陣列
3. `length`：陣列中的元素數量，型別為 64 位元無號整數

~~~~exercism/note
如果陣列中含有重複的值，而這些重複值正好是前兩高的分數，它們可以同時出現在兩個輸出位置中。
~~~~
