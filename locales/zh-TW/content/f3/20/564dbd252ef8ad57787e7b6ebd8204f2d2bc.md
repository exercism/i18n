# 指令

在這個練習中，你會處理一行行的日誌。

每一行日誌都是一個格式如下的字串："[<LEVEL>]: <MESSAGE>*"。

## 1. 從日誌行取得訊息

實作 `LogLevels.message()` 函式，回傳日誌行中的訊息，並移除前後的空白。

## 2. 從日誌行取得日誌層級

實作 `LogLevels.logLevel()` 函式，回傳日誌行中的日誌層級，並轉成小寫。

## 3. 重新格式化日誌行

實作 `LogLevels.reformat()` 方法，它接受一個日誌行和一個位置字串，並重新格式化為包含兩行的訊息。
第一行的格式為`<LEVEL>@<LOCATIOON>:`，其中：

* `<LEVEL>`是小寫的日誌層級（同第 2 點「從日誌行取得日誌層級」）。
* `<LOCATION>`是第二個參數傳入的位置。

第二行恰好包含兩個空格，後面接著日誌訊息（同第 1 點「從日誌行取得訊息」）：

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
