# 指令

Karl 想在 Exercism 網站上記錄他想學習的語言陣列。
Karl 需要能夠新增語言、移除舊語言，以及檢查某些語言是否在陣列中。
要是 Karl 想學 Java 或 Kotlin，那會非常令人興奮喔！

## 1. 定義一個函式來檢查語言陣列是否為空

Karl 需要知道他的語言陣列是否會變成空的，這樣他才能去找更多語言來學！
定義一個叫做`isEmpty`的方法，如果陣列中沒有語言，就回傳`true`。

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. 定義一個函式來把語言加入陣列

Karl 很期待學習 Kotlin 和 Python！
定義一個叫做`addLanguage`的方法，它會接收他想學習的語言並把它加入陣列，來幫 Karl 踏出第一步。

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. 定義一個函式來從陣列中移除語言

Karl 決定他現在不想學 Scala 了。
定義一個叫做`removeLanguage`的方法，它會接收他正在移除的語言並把它從陣列中移除，來幫 Karl 把它拿掉。

```java
languageList.removeLanguage("Scala");
```

## 4. 定義一個函式來回傳陣列中的第一個項目

Karl 想記住他加入陣列的第一個語言（而且還留在陣列裡的那個）。
定義一個叫做`firstLanguage`的方法，它會回傳陣列中的第一個語言。

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. 定義一個函式來回傳陣列中有多少個語言

Karl 需要知道他總共想學多少個語言。
定義一個叫做`count`的方法，它會回傳陣列中的語言數量，來幫 Karl 找出答案。

```java
int two = languageList.count(); // 2
```

## 6. 定義一個函式來判斷某個語言是否在陣列中

Karl 正在努力回想他到底想不想學 Python 或 Ruby。
定義一個叫做`containsLanguage`的方法，它會接收他詢問的語言，這樣 Karl 就能查個明白！

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. 定義一個函式來判斷這個陣列是否令人興奮

如果 Karl 想學 Java 或 Kotlin，那就非常令人興奮！
定義一個叫做`isExciting`的方法，如果 Karl 想學 Java 或 Kotlin 就回傳 true。

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
