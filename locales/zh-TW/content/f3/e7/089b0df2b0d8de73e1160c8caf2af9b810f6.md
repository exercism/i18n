# 指示

你的朋友剛傳了一則帶有重要秘密的訊息給你。
為了不讓其他人輕易讀取，這則訊息在加密時經過一連串的位元操作。
你需要撰寫方法來協助解密這則訊息。

## 1. 把位元移回去

解密訊息的第一步，是把位元往右移回去，以還原加密過程中的位移。
解密程序後續的步驟會假設左側會補入 0。

實作 `Secrets.shiftBack` 方法，它接受一個值和要位移的位數，並執行位移。

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. 設定一些位元

接下來，有些位元需要設為 1。

實作 `Secrets.setBits` 方法，它接受一個值和一個遮罩，並回傳把值中對應位元設為 1 的結果。
當遮罩中的位元是 1 時，值中對應的位元也應設為 1。
其他所有位元則保持不變。

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 翻轉特定的位元

加密過程中有些位元會被翻轉。
解密時需要把它們翻轉回來。

實作 `Secrets.flipBits` 方法，它接受一個值和一個遮罩。
遮罩指出值中哪些位元要翻轉。
如果遮罩中的位元是 1，值中對應的位元就會被翻轉。
其他所有位元則保持不變。

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 清除特定的位元

最後，還有某些位元解密後永遠是 0。

實作 `Secrets.clearBits` 方法，它接受一個值和一個遮罩。
當遮罩中的位元是 1 時，`value` 中對應的位元應設為 0。
其他所有位元則保持不變。

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
