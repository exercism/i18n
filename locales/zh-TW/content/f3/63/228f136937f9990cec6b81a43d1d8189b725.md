# 說明

在這個練習中，你將為一個簡單的整數計算機建立錯誤處理機制。
這個計算機應該支援加法、乘法和除法運算，並將結果以格式化字串回傳。
你還需要實作錯誤處理，來處理不合法的運算以及除以零的情況。

目標是做出一個能運作的計算機，並以下列格式回傳字串：

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. 實作計算機的運算

這個任務的主要函式是 `SimpleCalculator::calculate`，它接受三個引數：兩個整數，以及一個代表運算的 `ByteArray`。
請實作下列運算：

- **加法**，使用`+`符號
- **乘法**，使用`*`符號
- **除法**，使用`/`符號

## 2. 處理不合法的運算

如果運算符號不是`+`、`*`或`/`，計算機應該 panic 或回傳錯誤：

- 如果運算是空字串，請 panic 並帶上 `ByteArray` 錯誤訊息 `"Operation cannot be an empty string"`。
- 對於其他任何不合法的運算，請回傳 `Result::Err("Operation is out of range")`。

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. 處理除以零的錯誤

當嘗試除以`0`時，計算機應該 panic，並附上錯誤訊息，指出不允許除以零。
回傳值應該是 `felt252` 型別的值 `'Division by zero is not allowed'`。

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
