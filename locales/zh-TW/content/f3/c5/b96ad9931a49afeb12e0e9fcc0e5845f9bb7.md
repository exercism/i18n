# 指令

在這個練習中，你的任務是為一台加密裝置撰寫軟體，這台裝置會透過對資料進行轉換來運作。你需要一種方法，能靈活地將較簡單的函式組合起來，建立出複雜的函式。

每個任務都請回傳一個匿名函式，而且這個函式可以從呼叫端的作用域中被呼叫。

## 1. 建立一個加法器

實作`secret_add`。它應該回傳一個函式，該函式接受一個引數，並將傳入`secret_add`的引數與其相加。

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. 建立一個減法器

實作`secret_subtract`。它應該回傳一個函式，該函式接受一個引數，並從該引數中減去傳入`secret_subtract`的秘密值。

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. 建立一個乘法器

實作`secret_multiply`。它應該回傳一個函式，該函式接受一個引數，並將其乘以傳入`secret_multiply`的秘密值。

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. 建立一個除法器

實作`secret_divide`。它應該回傳一個函式，該函式接受一個引數，並將其除以傳入`secret_divide`的秘密值。

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. 建立一個函式組合器

實作`secret_combine`。它應該回傳一個函式，該函式接受一個引數，並依序將傳入`secret_combine`的兩個函式套用到該引數上。

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
