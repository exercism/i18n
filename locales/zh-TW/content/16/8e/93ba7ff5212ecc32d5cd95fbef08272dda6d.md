# 提示

## 一般


- [元組][tuples]是不可變的[序列型別][sequence types]，可以包含任何資料型態。
- 元組是[可迭代][iterable]的。如果你同時需要索引和值，可以使用 [`enumerate()`][enumerate]。
- 元素可以透過[括號表示法][bracket notation]存取，索引從左邊的 0 開始，或從右邊的 -1 開始。處理元組時，也可以使用其他[常見序列操作][common sequence operations]。

## 1. 取出座標

- 記住：元組可以透過 _索引_ 存取，使用 _括號_。索引從左邊的 0 開始。

## 2. 格式化座標

- 查看 [`class tuple`][class tuple] 以了解元組的更多細節。
- 查看 [`class str`][class str] 以了解字串的更多細節。

## 4. 合併符合的紀錄

- 記住，元組支援所有[常見序列操作][common sequence operations]。
- 你能在這裡重複使用你的 `compare_records()` 函式嗎？

## 5. 「清理」並為所有紀錄建立報告

- 記住：元組是 _不可變_ 的，但可以透過 _索引_ 搭配 _括號表示法_ 存取其內容。
- 除非有 _歧義_，否則元組不一定要使用括號。
- Python 有多種字串格式化的方法。[`str.format()`][str.format] 和 [`f-strings`][f-strings] 是兩種非常常見的方式。
- 透過 Python 的 [`format specification mini-language`][format specification mini-language]，可以使用多種文字格式化選項。
