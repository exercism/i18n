# 簡介

在 Go 中，`struct` 是一連串具名的元素，這些元素稱為_欄位_，每個欄位都有名稱和型別。
欄位名稱在 struct 內必須是唯一的。
struct 可以比擬為物件導向程式設計範式中的_類別_。

## 定義 struct

使用 `type` 和 `struct` 關鍵字可以建立新的 struct，並明確地定義每個欄位名稱和型別。
例如，這裡我們定義一個 `Shape` struct，它包含形狀的名稱和大小：

```go
type Shape struct {
    name string
    size int
}
```

struct 中的欄位名稱遵循 Go 的慣例：以小寫字母開頭的欄位，只有同一個套件中的程式碼能存取；以大寫字母開頭的欄位，則可以在其他套件中存取。

## 建立 struct 的實例

定義好 `struct` 之後，你需要建立新的實例，並以任意順序使用欄位名稱來定義各個欄位：

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

要讀取或修改實例的欄位，請使用 `.` 表示法：

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

沒有指定初始值的欄位，會擁有它們的零值。
例如：

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

只要依_順序_定義欄位，就可以不使用欄位名稱來建立 `struct` 的實例：

```go
s := Shape {
	"Oval",
	20,
}
```

不過，這種語法被視為_脆弱的程式碼_，因為當新增欄位時，特別是新增的欄位型別不同時，它就可能會壞掉。
在下列範例中，我們為 `Shape` 新增了一個額外的欄位：

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## 「New」函式

有時候，有幾個能幫助我們建立 struct 實例的函式會很方便。
依照慣例，這些函式通常叫做 `New`，或名稱以 `New` 開頭，但因為它們只是一般的函式，你可以任意命名。
它們或許會讓你想起其他語言中的建構子，但在 Go 中，它們就只是一般的函式。

在下列範例中，我們使用其中一個 `New` 函式來建立 `Shape` 的新實例，並自動為形狀的 `size` 設定預設值：

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

使用 `New` 函式有下列優點：

* 驗證傳入的值
* 處理預設值
* 由於 `New` 函式通常和它們所初始化的 struct 宣告在同一個套件中，因此它們甚至可以初始化 struct 的私有欄位
