# 提示

## 1. 判斷千層麵是否烤好了

- 使用 [`if` 敘述][mdn-if-else]，根據某個條件回傳結果。
- 這個任務最好先檢查那兩個特定條件。
- 請記得，缺少的參數會是`undefined`，而你可以用嚴格相等運算子`===`檢查變數是否為`undefined`。

## 2. 估算準備時間

- 使用預設參數來設定平均準備時間，以防呼叫函式時沒有提供這個參數。
- 重溫[陣列][concept-arrays]，了解如何判斷層數（`layers` 陣列的長度）。

## 3. 計算所需的麵條和醬汁份量

- 首先，建立兩個變數來追蹤麵條和醬汁的份量。
  用`let`定義它們，這樣之後就能在程式碼中更改值。
  另外，指定一個適當的初始值。
- 使用 [`for` 迴圈][concept-for-loops]來逐一走訪每一層。
- 如果在迴圈中遇到`'noodles'`或`'sauce'`層，就依此增加對應變數中儲存的份量。
- 使用[物件][concept-objects]回傳這兩個結果。

## 4. 加入祕密食材

- 重溫[陣列][concept-arrays]，了解如何從陣列中取出元素，以及如何在陣列尾端加入東西。
- 陣列`a`中最後一個元素的索引是`a.length - 1`。
- 這個函式不應該有`return`敘述。

## 5. 依比例調整食譜

- 首先，根據目標份數計算需要套用到所有份量的倍率。
- 確保引數不被修改的一種方法，是使用新的物件來儲存結果。
- 使用 [`for...in` 迴圈][mdn-for-in]走訪原始食譜中的所有項目，並依此填入物件。
