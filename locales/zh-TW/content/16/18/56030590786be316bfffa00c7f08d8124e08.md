# 指令補充

## 詞

定義兩個擴充 `disposable`（來自 `destructors`）的包裝元組，並在 `bytes` 與 `ops` 兩個整數計數器之外，一併存放底層的串流：

- `metered-input < disposable`，槽位為 `stream`、`bytes`、`ops`。
- `metered-output < disposable`，槽位為 `stream`、`bytes`、`ops`。

用 `new-disposable`（而不是 `new`）建構它們，讓包裝元組向解構子框架註冊。

- `<metered-input> ( stream -- m )`：包裝一個輸入串流。
- `<metered-output> ( stream -- m )`：包裝一個輸出串流。

將每個元組宣告為對應串流混入的實例：

```
INSTANCE: metered-input  input-stream
INSTANCE: metered-output output-stream
```

接著提供 `M:` 方法，在更新計數器的同時委派給底層串流：

- 對 `metered-input`：[`stream-read1`][stream-read1]、[`stream-read-unsafe`][stream-read-unsafe]、[`stream-element-type`][stream-element-type]（委派），以及 [`dispose*`][dispose*]。
- 對 `metered-output`：[`stream-write1`][stream-write1]、[`stream-write`][stream-write]、[`stream-flush`][stream-flush]（委派），以及 [`dispose*`][dispose*]。

每次成功的讀取或寫入，都應該把傳輸的位元組數加到 `bytes>>`，並將 `ops>>` 加一。讀取若遇到檔案結尾，仍算一次 op，但傳輸零個位元組。`dispose*` 應該直接傳遞給底層串流。
