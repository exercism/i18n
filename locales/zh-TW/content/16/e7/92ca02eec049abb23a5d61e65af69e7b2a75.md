# 簡介

Gleam 的標準函式庫中的`gleam/order`模組包含`Order`型別，這個型別用來比較值。

`Order`的定義如下：

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

這個型別有三個變體，分別用來表示一個值與另一個值之間的關係：

- `Gt`：這個值 _大於_ 另一個值。
- `Eq`：這個值 _等於_ 另一個值。
- `Lt`：這個值 _小於_ 另一個值。

如果某個資料型態可以比較大小，通常該模組會定義一個`compare`函式，回傳`Order`值。例如，`gleam/float`和`gleam/int`分別定義了處理浮點數與整數的`compare`函式。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

像是`list.sort`這樣的排序函式通常會接受一個回傳`Order`值的函式，讓呼叫端定義這個陣列應該如何排序。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
