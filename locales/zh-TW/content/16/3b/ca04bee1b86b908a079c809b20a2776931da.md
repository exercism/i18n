## 1. 用密碼保護取回的機密計畫

一旦拿到機密計畫，你就得好好保護它，讓只有知道密碼的人才能取回。

為了做到這一點，你需要實作`protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`這個函式。
這個函式會回傳另一個函式，它接受各種可能的密碼字串作為輸入。
如果輸入的密碼正確，新的函式就會回傳藏起來的機密；但如果密碼錯誤，這個函式會回傳 "Sorry. No hidden secrets here."。

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. 產生一組能打開他們保險箱的密碼組合

我們得知，UMBRA 所有保險箱的密碼組合，都是以所在房間的號碼為依據產生的。
密碼組合的產生方式，是對房間號碼反覆套用一個特別的函式。
所以密碼組合的第一個數字，來自把函式套用在房間號碼上；第二個數字，來自把函式套用在第一個數字上；第三個數字，則來自把函式套用在第二個數字上。

不過，UMBRA 會定期更換用來產生密碼組合的函式，所以你的工具需要同時接收房間號碼和對應的函式，才能產生密碼組合。

請實作`generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)`這個函式，來產生你需要的密碼組合。

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
