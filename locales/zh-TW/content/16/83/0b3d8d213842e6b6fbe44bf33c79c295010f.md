# 簡介

## Switch

[switch 敘述][switch] 會把一個值與多個可能的相符模式做比較。相較於串接多個`if-else`敘述，它提供了更簡潔、更好讀的替代寫法。

`switch`敘述以`switch`關鍵字開頭，後面接著要測試的值。每個可能的相符情況都用`case`關鍵字帶出。`default`關鍵字則定義備援情況，在所有明確列出的情況都不相符時執行。和`if-else`串接一樣，`switch`敘述只會執行第一個相符情況所對應的程式區塊。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

來看看下面這串`if-else`：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

用`switch`敘述可以寫得更清楚：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## While 迴圈

[while 迴圈][while-loops] 是一種控制流程敘述，讓程式碼在特定條件為真時持續執行。Swift 提供兩種 while 迴圈：while 迴圈和 repeat-while 迴圈。while 迴圈的條件會在迴圈主體執行前先求值；如果條件為假，迴圈主體就完全不會執行。Swift 裡的 while 迴圈結構如下：

```swift
while <#condition#> {
  <#code#>
}
```

這裡的迴圈會在 count 大於 0 時持續執行，因此會依序印出數字 2、1 和 "Liftoff!"。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[repeat-while 迴圈][while-loops] 和 while 迴圈類似，但條件是在迴圈主體執行後才求值。這代表迴圈主體至少會執行一次，即使條件為假也一樣。Swift 裡的 repeat-while 迴圈結構如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

這裡的迴圈只會執行一次，因為條件為假。由於它是 repeat-while 迴圈，迴圈主體會在條件求值前先執行一次。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 控制轉移

Swift 提供控制轉移敘述，用來改變迴圈和 switch 敘述的執行流程。除了`return`之外，Swift 還有`continue`、`break`、迴圈標籤和`fallthrough`。

### Continue

`continue`敘述會告訴迴圈停止執行目前這次疊代，立刻開始下一次疊代。在`while`或`repeat-while`迴圈中，它會直接跳到條件檢查；在`for-in`迴圈中，則會前進到序列中的下一個元素。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

### Break

`break`敘述會立刻整個離開迴圈或 switch 敘述，程式接著從迴圈或 switch 之後的第一行程式碼繼續執行。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

### 帶標籤的敘述

在巢狀迴圈中，你可能會希望`break`或`continue`影響外層迴圈，而不是最內層的那個。只要在迴圈前面加上名稱和冒號（`labelName:`），就能為迴圈加上標籤。接著你就可以把這個標籤交給`break`或`continue`：

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
