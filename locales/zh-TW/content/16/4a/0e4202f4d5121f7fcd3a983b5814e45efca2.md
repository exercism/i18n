# 介紹

許多程式需要（看似）隨機的值，來模擬真實世界的事件。

常見且熟悉的例子包括：
- 擲硬幣：從 `('Heads', 'Tails')` 中隨機取一個值。
- 擲骰子：從 1 到 6 中隨機取一個整數。
- 洗牌：將一副牌隨機排序。
- 在 3D 圖形模擬中生成樹木和灌木。

用電腦產生_真正_隨機的值，是[出乎意料地困難的技術挑戰][truly-random]，所以你會看到這類結果被稱為「偽隨機」。

實際上，像 Python 標準程式庫中的 [`random`][random]模組這樣設計良好的程式庫，不但快速、有彈性，對大多數的建模、模擬與遊戲應用來說，產生的結果也已經綽綽有餘。

在這篇簡短的介紹裡，我們會示範這個模組中最常用的四個函式。
我們鼓勵你多多探索完整的 [`random`][random]文件，因為裡頭有許多工具和選項。

在使用 `random`模組裡的工具之前，你必須先匯入它：

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

為了避免每次都打出模組名稱，你可以依名稱匯入特定的函式：

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` 與 `randint()`

如上方的第一個範例所示，`randrange()` 函式有三種形式：

1. `randrange(stop)` 會給出一個整數 `n`，滿足 `0 <= n < stop`
2. `randrange(start, stop)` 會給出一個整數 `n`，滿足 `start <= n < stop`
3. `randrange(start, stop, step)` 會給出一個整數 `n`，滿足 `start <= n < stop`，
    且 `n` 位於序列 `start, start + step, start + 2*step...` 之中

在最常見的 `step == 1` 情況下，`randint(a, b)` 可能更方便、也更好讀。
`randint()` 的結果_包含_上界，所以 `randint(a, b)` 等同於使用 `randrange(a, b+1)`。



## `choice()` 與 `choices()`

這兩個函式假設你的起點是某個[序列][sequence-types]或其他容器。
通常會是 `list`，或者在某些限制下是 `tuple` 或 `set`（_`tuple` 不可變，而 `set` 沒有順序_）。

`choice()` 函式會從給定的序列中隨機回傳一個成員，而 `choices()` 則會從給定的序列中隨機回傳指定數量（`k`）的成員。
在上面示範的範例中，我們假設硬幣是公平的、正反兩面機率相同，不過你也可以指定權重。

例如，如果袋子裡有 10 顆紅球和 15 顆綠球，而我們想隨機抽出一顆：


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
