# 指示

你的朋友 Johannes 很喜歡自己動手做（DIY）硬體。
他們剛做出了一台果汁機，Johannes 非常興奮。
Johannes 的目標是每天早上都能做出新鮮的果汁。

Johannes 果汁機有很多厲害的功能。
像是內建的測量系統，可以告訴你杯子裡有多少果汁。
它也有計時器，能告訴你機器已經運轉了多久。

Johannes 不太擅長寫程式，但他們想寫一個程式來控制這台機器。
因此他們請你來幫忙。

## 1. 除錯燈

這台機器有一個除錯燈，原理很簡單：只要機器有電，除錯燈就會亮。
只有在除錯燈亮著的時候，程式才會執行。

這個方法應該是一個名為`JuiceMaker`的類別方法。

定義類別方法`JuiceMaker.debug_light_on?`，讓它回傳`true`。

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. 初始化機器

當機器通電時，應該會建立一個`JuiceMaker`類別的實體。
這台機器應該要有一個初始化狀態。
初始化狀態應該包含以下資訊：

1. 機器是否在運轉。當機器開啟時，這應該一律是`false`。
2. 杯子裡的果汁量，這會是一個測量杯中果汁量的感測器。

定義初始化狀態，它會把杯子裡的果汁量當作參數，並建構這個初始化狀態。
初始化狀態應該包含一個設為`false`的實體變數`@running`，以及一個根據類別初始化時所給的引數而定的實體變數`@fluid`。

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. 開啟機器

這台機器可以開啟和關閉。
你需要定義一個方法來開啟機器。
當機器開啟時，運轉狀態應該設為`true`。

定義方法`JuiceMaker#start`，用來開啟機器。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. 機器狀態

這台機器需要能告訴你機器的狀態。
如果機器正在運轉，它應該回傳`true`；如果沒有運轉，則回傳`false`。

定義方法`JuiceMaker#running?`，讓它回傳機器的狀態。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. 加入果汁

這台機器可以把果汁加入杯子。
機器能夠知道加了多少果汁到杯子裡。
加入果汁之後，機器需要協助才能知道杯子裡有多少果汁。

定義方法`JuiceMaker#add_fluid`，它會把加入的果汁量當作參數，並更新杯子裡的果汁量。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. 關閉機器

這台機器可以開啟和關閉。
你需要定義一個方法來關閉機器。
這個方法只會在機器運轉時被呼叫。
當機器關閉時，運轉狀態應該設為`false`。
關閉之後，機器也需要協助才能判斷杯子裡有多少果汁。
這台機器每分鐘會用掉五個單位的果汁。

定義方法`JuiceMaker#stop`，它會把機器已運轉的分鐘數當作參數，並回傳機器關閉後杯子裡的果汁量。

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
