# 執行 Ceylon 測試

在執行測試之前，必須先透過[`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html)編譯你的程式碼。

我們使用[`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html)指令來執行測試。

[`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html)需要一個模組名稱，才知道要對哪個模組執行測試。
在 Ceylon 學習軌道中，每個練習就只有一個模組。

因此，你可以這樣執行測試：

```bash
ceylon compile && ceylon test $(basename source/*)
```
