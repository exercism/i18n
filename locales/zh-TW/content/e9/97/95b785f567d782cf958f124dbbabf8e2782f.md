# 測試

要執行這些測試，你需要 Minitest gem。開啟終端機視窗，執行下列指令來安裝 minitest：

```
gem install minitest
```


請在練習目錄下，用下列指令執行測試：

```
ruby <snake-case-exercise>_test.rb
```

請把`<snake-case-exercise>`替換成你練習名稱的 snake_case 形式。

## 彩色輸出

你可以`require 'minitest/pride'`，或是執行下列指令來取得彩色的輸出：

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
