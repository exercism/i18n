## 安裝

有些 Tcl 發行版預設不包含 Tcl 的 Thread 套件，可能需要另外安裝。
用以下指令確認
```bash
$ echo 'package require Thread' | tclsh
```
如果它_沒有輸出_任何內容，就表示 Thread 套件已經安裝好了喔。

視需要執行 `apt install tcl-thread`（或 `dnf install tcl-thread`）。
