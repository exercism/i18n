# 關於

閉包，也就是會記住自身環境中值的 quotation，是 Factor 打造可重複使用轉換的方式。`curry`和`compose`涵蓋了簡單的情況；其餘的就交給 fry quotation 吧。

```factor
3 [ + ] curry .      ! [ 3 + ]
[ 1 + ] [ 2 * ] compose .   ! [ 1 + 2 * ]
2 3 '[ _ _ + + ] .   ! [ 2 3 + + ]
```

| 工具      | 形式                                | 什麼時候用                     |
|-----------|--------------------------------------|--------------------------------|
| `curry`   | `value quot -- newquot`              | 只有一個被捕獲的值             |
| `2curry`  | `v1 v2 quot -- newquot`              | 兩個值，都放在最前面           |
| `compose` | `quot1 quot2 -- combined`            | 把兩個 quotation 頭尾串接起來  |
| `'[ _ ]`  | `… -- newquot`                       | 可以捕獲多個值，位置不限       |

Fry 是一種編譯期的改寫：`'[ _ + ]`會展開成對`[ + ]`呼叫`curry`。編譯器會處理背後的細節，你只要在被捕獲的值該出現的地方寫上底線就好。
