# 提示

## 1. 定義`Usd`、`Eur`和`Jpy`型別

- `Usd`、`Eur`和`Jpy`型別可以使用`pub type TypeName`語法定義，不需要建構子。

## 2. 定義`Money`型別。

- `Money`型別應該有一個代表貨幣的幽靈型別參數。

## 3. 定義`dollar`、`euro`和`yen`函式

- `dollar`、`euro`和`yen`函式的回傳型別標註應該要是`Money(currency)`，其中`currency`是`Money`型別適當的型別參數。

## 4. 定義`total`函式

- `total`函式的回傳型別標註應該使用與引數相同的型別參數。
