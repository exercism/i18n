# 資源

## 參考資料

- [RISC-V 參考卡][reference-card]列出了指令、擬指令與暫存器。
- [RISC-V 呼叫慣例][psabi]說明哪些暫存器用來存放函式的輸入與結果，以及函式必須保留哪些暫存器。
- [RISC-V 規格][isa-manual]精確描述了每個指令的作用。
- [GNU 組譯器手冊][gas-directives]說明了`.section`、`.string`、`.word`和`.global`等指示詞。

## 工具

- [Compiler Explorer][godbolt]會顯示編譯器為一段 C 程式碼產生的組合語言。
  這個連結會以 32 位元的 RISC-V 編譯器開啟，讓你可以比較自己的解法與編譯器會寫出的內容。

## 社群

- [RISC-V International][riscv-org]是負責維護 RISC-V 標準的組織。
- [r/RISCV][reddit]是分享 RISC-V 晶片、開發板與軟體消息的 Reddit 社群。
- [Stack Overflow][stack-overflow]有許多關於 RISC-V 組合語言的問答。
