# 聯合型別

Crystal 允許一個變數由多種型別組成。
這就叫做[聯合型別][union-type]。
在 Crystal 中，聯合型別經常由編譯器推斷出來。

~~~~exercism/note
聯合型別在執行階段仍然是單一型別，即使它由多種型別組成也一樣。
這表示如果一個聯合型別是由`String`和`Int32`組成，它不會在同一時間同時是兩者。
它會是`String`，不然就是`Int32`。
~~~~

宣告聯合型別的方式，是用直線符號（`|`）把型別隔開。
聯合型別通常會用括號包起來，但這並非必要。
最常見的聯合型別是`(T | Nil)`，其中`T`是某種型別；當方法可能回傳`Nil`時，就會出現這種型別。
這也表示這個變數是**nilable**。

```crystal
foo : String = "Hello"
foo = nil # Error: type must be String, not (String | Nil)

foo : (String | Nil) = "Hello"
foo = nil
```

它不限定只能有兩種型別，你想放幾種都可以。

```crystal
foo : (String | Int32 | Nil | Float64) = "Hello"
foo = 1
foo = nil
foo = 1.0
```

## `typeof` 與 `Object#class`

要取得變數的型別有兩種方式。
一種是使用[`typeof`][typeof]，另一種是使用[`Object#class`][Object#class]。
兩者的差別在於，`typeof`會在編譯階段回傳變數的型別，而`Object#class`會在執行階段回傳型別。
這表示如果你想確認某個變數是不是聯合型別，`Object#class`沒辦法告訴你，因為它只會在執行階段回傳型別，而那是單一型別。

```crystal
foo = 0 == 0 ? "a" : 1
typeof(foo) # => (String | Int32)
foo.class # => String
```

## 聯合型別的運算

由於聯合型別在執行階段是單一型別，所有標準運算都能套用在它上面。
不過在編譯程式碼時，編譯器必須知道它究竟是哪一種型別。
因此，當你想使用特定型別專屬的運算時，程式碼就必須寫成能確保它只會是其中一種型別的形式。

```crystal
foo : (String | Int32) = "Hello"
foo.downcase # Error: undefined method 'downcase' for (String | Int32)
```

Crystal 確實為聯合型別準備了一個特別的方法：`is_a?`方法，它接受一個型別作為引數，並回傳布林值。
`nil?`方法是`is_a?(Nil)`的簡寫。
把`is_a?`方法放進控制運算式中，會告訴編譯器它是哪一種型別，藉此保證它就是那個型別。
而對於 else 分支，則能保證它不是那個型別。

```crystal
foo : (String | Int32) = "Hello"
if foo.is_a?(String)
  typeof(foo)  # => String
  foo.downcase # => "hello"
end
```

`is_a?`的引數不限定只能放單一型別，也可以放聯合型別。
它也能搭配`&&`來處理多種型別。

~~~~exercism/note
`is_a?`方法用在控制運算式時，它的對象不能是實例變數或類別變數。
必須先把它們指定給區域變數才行。
~~~~

## as

把聯合型別變成單一型別的方法之一，是讓某個分支只有在型別符合特定型別時才能進入。
另一種做法是使用[`as`][as]方法。
它會透過執行階段的檢查，把聯合型別變成單一型別。
如果型別不是預期的型別，就會引發例外。

```crystal
foo : String | Int32 = "Hello"
foo.as(String).downcase # => "hello"

foo.as(Int32) # Error: can't cast String to Int32
```

~~~~exercism/caution
這種做法只適用於你確定型別就是預期的型別，或是你希望在型別不符時引發例外的情況。

在不當的設定下使用這種做法，可能會導致非預期的行為。
~~~~

## as?

[`as?`][as?]的運作方式和`as`非常類似，但當型別不是預期的型別時，它會回傳 nil 而不是引發例外。
這表示它會回傳預期型別與`Nil`組成的聯合型別。

```crystal
foo : (String | Int32) = "Hello"
foo.as?(String).downcase # => "hello"

foo.as?(Int32) # => nil
```

## 可為 nil 的簡寫

nilable 的意思是變數可以是某個型別或`Nil`。
它可以寫成`(T | Nil)`。
不過由於可為 nil 的型別相當常見，所以有個簡寫：`T?`。

```crystal
# This:
foo : (String | Nil) = "Hello"
foo = nil

# Is the same as:
foo : String? = "Hello"
foo = nil
```
