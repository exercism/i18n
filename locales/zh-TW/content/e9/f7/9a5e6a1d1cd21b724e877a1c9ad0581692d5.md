# 指令

你是貨輪上的無線電報員。訊號從一條充滿雜訊的線路傳來：船上的機械聲、天氣造成的靜電干擾，偶爾還有外語的雜談，全都和你真正想聽的摩斯碼交錯在一起。為了聽清楚訊息，你把線路接上一台*磁帶*裝置，它會濾掉其他所有東西，只留下有效的摩斯符號（`.`、`-`，以及分隔字母的空格）。

你的任務是把這條磁帶打造成 Factor 的自訂輸入串流。

## 1. 定義磁帶

定義一個`tape`元組，繼承`disposable`，並帶有一個`wire`槽位，用來存放底層的輸入串流。

```factor
TUPLE: tape < disposable wire ;
```

接著撰寫建構子`<tape> ( wire -- tape )`。請使用`new-disposable`（而不是`new`），讓解構子框架能註冊這條磁帶，並把底層串流存進`wire`槽位。

## 2. 加入 input-stream mixin

宣告`tape`是一個`input-stream`：

```factor
INSTANCE: tape input-stream
```

這樣一來，協定的預設組合子就會分派到你的類別。

## 3. 讀取一個摩斯符號

實作`M: tape stream-read1 ( tape -- elt/f )`。從底層的線路讀取位元組，直到遇到`CHAR: .`、`CHAR: -`或`CHAR: \s`（空格）其中之一。回傳那個位元組。如果線路回傳`f`（串流結束），也回傳`f`。這條磁帶就到此為止。

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. 委派元素型別

實作`M: tape stream-element-type ( tape -- type )`，把工作委派給線路：磁帶不會改變所讀取元素的種類。

## 5. 清理

實作`M: tape dispose* ( tape -- )`。框架對每一次`dispose`只會呼叫你的方法一次；你只要把底層的線路處置掉就好。

這 5 個部分就定位之後，磁帶就能像一般的輸入串流一樣運作：`with-input-stream`、`stream-read`，以及其他協定詞彙都會自動分派到你的方法。
