# 簡介

該來認識 C++ 的其中一個核心典範了：物件導向程式設計（OOP）。
OOP 的核心是`classes`，也就是由使用者自訂、各自帶有一組相關函式的資料型態。
我們會從基礎開始，之後再沿著課程大綱往下，涵蓋更進階的主題。

## 成員

類別可以擁有**成員變數**和**成員函式**。
它們是透過**成員選擇**運算子`.`存取的。
就像`classes`之外的變數一樣，最好在宣告成員變數時就給它一個初始值。
這個值之後就會成為用這個類別新建之物件的預設值。

## 封裝與資訊隱藏

類別可以選擇限制對其成員的存取。
兩種基本情況是`private`和`public`。
`private`成員無法從類別外部存取。
`public`成員則可以自由呼叫。
所有成員預設都是`private`，必須明確標記，才能在類別外部使用。

## 基本範例

下面這個範例展示了新`class`的定義。
請注意定義結尾的`;`。

```cpp
class Wizzard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

你可以從類別內部存取所有變數。
看看`cast_spell`函式裡的`damage`。
你無法從類別外部讀取或變更`private`成員：

```cpp
Wizzard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## 建構函式

建構函式讓你能在建立物件時就為成員變數指定值。
它們的名稱和`class`相同，而且沒有回傳型別。
一個類別可以有好幾個建構函式。
如果你不總是需要在建立物件時設定所有變數，這就很實用。

```cpp
class Wizzard {
  public:
    Wizzard(std::string new_name) {
      name = new_name;
    }
    Wizzard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizzard el{"Eleven"};       // deals  5 damage
Wizzard vecna{"Vecna", 50}; // deals 50 damage
```

建構函式是個大主題，有許多細微之處。
如果你沒有為`class`明確定義`constructor`，那麼（也只有在那時候）編譯器會幫你完成這件事。
上面第一個範例就是這種情況。
_silverhand_ 物件是透過呼叫預設建構函式建立的，過程中沒有傳入任何引數。
所有變數都會被設成類別定義中所指定的值。
如果你在定義中沒有給任何值，這些變數就可能處於未初始化的狀態，進而導致非預期的後果。

## 結構體

結構體來自這門語言最初的 C 根源，和 C++ 本身一樣歷史悠久。
它們實際上和`classes`是同一回事，只有一個重要的例外。
在`class`裡，所有東西預設都是`private`。
相對地，結構體除非另外定義，否則都是`public`。
依照慣例，`struct`關鍵字常用來表示**純資料結構**。
而對於需要確保某些性質的物件，則偏好使用`class`關鍵字。
這樣的不變量可以是：你的`Wizzard` `class`的`damage`不能變成負數。
`damage`變數是私有的，任何會變更 damage 的函式都會確保這個不變量得以維持。
