# 關於

[Vim](http://www.vim.org) 是一套問世數十年的文字編輯器，至今仍舊極受程式設計師，以及喜歡在終端機模擬器中工作的人歡迎。

在 Vim 裡，按鍵的作用並不總是相同。
這取決於你目前處於哪個模式。
你會不斷在模式之間切換：有導覽用的模式、插入用的模式、選取文字範圍用的模式、輸入指令用的模式，等等。
這聽起來很複雜，但你很快就會習慣。

和其他編輯器最大的不同，在於 Vim 的模式化介面。
使用 Vim 時，你不是在按複雜的快速鍵，而是在說一種語言。

例如，當你在普通模式按下`d`，就會啟動刪除動作。
接著你必須選擇要作用的範圍（或其他物件）。
例如`dw`會刪除到目前單字的結尾，`dd`則刪除目前這一行。
如果游標落在某組雙引號內的任何位置，你可以用`ci"`來修改這組引號。

由於你不需要同時按下好幾個鍵，而是依序按下單一按鍵，就能降低罹患[腕隧道症候群](https://en.wikipedia.org/wiki/Carpal_tunnel_syndrome)的風險。

為了方便起見，常用按鍵會安排在基準鍵列上或附近，這樣你就不必一直把手移來移去。

沒錯，一開始要學的東西很多，但一旦學會，你就能比使用大多數其他編輯器更快、更精準地編輯文字。
大家到現在還在使用 Vim，是有原因的！

Vim 內建了自己的腳本語言。
它的名稱是`Vimscript`、`Vim script`或`VimL`，取決於你問的是誰。
它是一門真正的程式語言，你也可以用它來設定 Vim。
設定檔叫做`vimrc`，內容其實只是一連串的 Vim 指令、函式和運算式。

這表示 Vim 的設定具有[圖靈完備](https://en.wikipedia.org/wiki/Turing_completeness)性。
你可以從小處著手，先加上幾行，再慢慢增加，最後寫出完整的外掛。
沒有什麼是你做不到的。

**額外補充**：這話聽聽就好，不過 Vim 和 Emacs 之間的[編輯器大戰](https://en.wikipedia.org/wiki/Editor_war)已經持續了好長一段時間。 :-)
