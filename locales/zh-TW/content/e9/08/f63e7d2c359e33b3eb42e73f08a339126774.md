# 關於

- binary 型別是 bitstring 型別的特化。
- binary 由位元組組成。
  - 位元組是 8 個位元。
  - 位元組可以表示從`0`到`255`的數字。
  - 處理位元組時，經常會用到十六進位整數值：`0x00`到`0xFF`。
- binary 字面值使用 [`<<>>` 特殊形式][special-form]定義。
  - 如果位元組使用大於`255`的整數，只會取用最後 8 個位元，除非你用 [`::`][type-operator]運算子指定要使用的[單位和／或大小][bin-size]。
- [`<>/2`][bin-concat]可以用來串接 bitstring、binary 和字串。

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

_null-byte_ 是`<<0>>`的另一個名稱。

## 字串是編碼過的 binary 資料

- 字串是以 [UTF-8][wiki-utf8] 格式編碼的 binary 資料。
  - 它們以 8 位元（一個位元組）為單位編碼，最多用 4 個位元組來表示超過 255 個字元。
  - [字串的長度][string-length]不一定和它的[位元組大小][byte-size]相同。

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## 對 binary 資料進行模式比對

- binary 可以[整段做模式比對，也可以用特殊形式][special-form]只比對其中一部分。
  - 在模式比對中，只有最後一部分可以有不固定的大小。

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

字串也可以這樣做：

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
