# 指令補充

## Assert

在這個練習中，我們假設由呼叫端負責，只以非零的輸入呼叫`classify`。
所以請讓`classify`函式斷言它的輸入不是零。
更多細節請參閱 [Zig 語言參考][zig-reference] 以及 [`std.debug.assert`][assert]的實作。

不過請注意，這個練習目前不會測試輸入為 0 的情況（因為`std.testing`[尚未支援預期 panic][proposal]）。

[zig-reference]: https://ziglang.org/documentation/0.16.0/#unreachable
[assert]: https://ziglang.org/documentation/0.16.0/std/#std.debug.assert
[proposal]: https://github.com/ziglang/zig/issues/1356
