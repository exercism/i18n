# 關於

Haxe 支援型別與欄位的執行期反射。想正確使用反射，就必須了解哪些操作受到支援、哪些不支援。由於反射帶有動態特性，這點未必能在編譯期就決定。

反射 API 由兩個類別組成：

- `Reflect`：輕量的 API，最適合用在匿名結構上，對類別的支援有限。
- `Type`：更強大的 API，適合用來處理類別與列舉。

可用的方法都詳列在 [Reflect][reflect] 與 [Type][type] 的 API 中。

以下範例使用的是 JavaScript 目標：

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
