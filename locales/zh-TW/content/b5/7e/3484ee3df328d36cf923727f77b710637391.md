# 提示

## 一般

- `accessors`會提供自動產生的`slot>>` getter、`>>slot` setter，以及`change-slot` updater。
- setter 與`change-slot`會*改動*元組本身。如果你想要非破壞性的更新，請先`clone`它。

## 1. 定義`player`元組

- slot 的語法是寫在`TUPLE: …  ;`裡的`{ name initial: value }`。
- 沒有`initial:`子句的 slot 會預設為`f`。

## 2. 介紹玩家

- `name>>`會讀取`name` slot。
- 來自[`kernel`][kernel]的`unless*`是「值為`f`時採用預設值」的慣用寫法。

## 3. 讓倒下的玩家復活

- `health>>`會讀取該 slot；來自[`math`][math]的`zero?`則用來檢查是否為零。
- 先用`clone`，再用`100 >>health`和`100 >>mana`來建立新的玩家。
- 如果是「還活著」的情況，就回傳`f`。

## 4. 承受傷害

- `change-health`接受一個 quotation：`( old-health -- new-health )`。
- 一個 fry quotation `'[ _ - 0 max ]`（`max`來自[`math.order`][math.order]）可以幫你「減去捕捉到的傷害，並將結果限制在零以上」。
- 別忘了在改動前先`clone`。

[math]: https://docs.factorcode.org/content/vocab-math.html
[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
