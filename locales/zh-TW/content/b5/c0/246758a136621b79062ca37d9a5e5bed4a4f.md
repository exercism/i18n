# 介紹

在 Common Lisp 中，函式的引數列表稱為[「lambda list」][lambda-list]。lambda list 可以包含不同類型的引數。這些不同的類型是以[「lambda list keywords」][lambda-list-keyword]來指定，它們全都以`&`開頭。最常使用的類型是選擇性引數、關鍵字引數與其餘引數。在一個 lambda list 中，某個 lambda list keyword 之後的每個參數都會是該類型。每個 lambda list keyword 在一個 lambda list 中只能使用一次。

lambda list 也會用在其他構造中，例如解構與巨集，這些之後會再討論。
