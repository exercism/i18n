# Instructions

你的任務是取得一份比賽的得分球員清單，並計算每位球員攻進了多少球。

`PlayerName`是`String`的型別別名，能讓程式碼更容易閱讀，也能區分這裡使用的`String`與其他用途的`String`。

## 1. 彙總得分球員

首先實作`updateGoalCountForPlayer`，為球員初始化或累加進球數。然後實作`aggregateScorers`函式，透過`updateGoalCountForPlayer`來計算每位球員攻進了多少球。這個函式接受一個`List PlayerName`（得分球員的名字，可能包含重複的球員名字），並回傳一個`Dict PlayerName Int`，內含清單中的所有球員，以及他們各自攻進了多少球。

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. 移除不重要的球員

實作`removeInsignificantPlayers`函式，過濾掉進球數少於門檻的球員。

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. 重設球員的進球數

實作`resetPlayerGoalCount`函式，把某位球員的進球數重設為零。

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. 格式化單一球員的進球數

實作`formatPlayer`函式，把單一球員的進球數格式化為字串。如果字典中沒有這位球員，就假設他的進球數為零。

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. 格式化所有球員的進球數

實作`formatPlayers`函式，把所有球員的進球數格式化為字串。球員應依名字排序。

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. 合併比賽

實作`combineGames`函式，計算每位球員在兩場比賽中總共攻進了多少球。

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
