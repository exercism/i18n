# 簡介

## 陣列

JSON 把**陣列**定義為：

> 陣列是有序的值的集合。
> 陣列以`[`左方括號開始，以`]`右方括號結束。
> 值與值之間以`,`逗號分隔。

陣列可以包含零個或多個_任何類型_的 JSON 值。
陣列元素不需要都是相同的型別。

### 建立陣列

用方括號把元素收集成陣列。

```jq
[1, 2, 3]
```

把_串流_用方括號包起來，就能把它的元素收集成陣列。

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### 大小

`length`函式會回傳陣列中元素的數量。

### 索引與切片

陣列的索引從 0 開始。

用方括號運算式從陣列取出元素：
`.[2]`取得第三個元素。

負的索引會從陣列尾端往回算：
`.[-1]`取得最後一個元素；`.[-2]`則是倒數第二個。

**切片**是陣列的子序列。
`.[10:15]`從索引 10 開始回傳 5 個元素；結束索引_不包含_在內。

還有幾個方便好用的函式：

- `first`取得第一個元素。
- `last`取得最後一個元素。
- `nth(n)`取得索引`n`的元素。

### 疊代

`jq`提供了許多函式，涵蓋常見的疊代功能：

- `map(expr)`會回傳一個新陣列，其中`expr`會依序套用到每個元素上。

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)`是一個函式，會把`expr`套用到_單一值_上；
  如果運算式的結果為 true，就回傳該值；
  如果結果為 false，就_什麼都不_回傳，不是`null`，而是真的什麼都沒有。

  要把它套用到陣列上，可以搭配`map`一起使用。

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  或者，把`select`套用到_串流_上，再收集結果。

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)`和`all(condition)`會回傳一個布林值，表示陣列中是否有任何元素或全部元素通過條件。

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
