# 說明

你負責學校話劇的道具表。道具是一份對應表，把道具的名稱對應到它的數量。

這三個任務都寫在`MISSING_PROPS`類別裡。

## 1. 我們有多少個？

回傳某種道具的數量。如果這種道具根本不在表上，就拋出字串 `"Unknown prop: "`，後面接上它的名稱。

```sather
MISSING_PROPS::count_of(props, "crown")
-- => 2

MISSING_PROPS::count_of(props, "sword")
-- raises "Unknown prop: sword"
```

注意「有零個」和「根本沒這種東西」之間的差別。列為零的道具是已知的，只是用完了。

## 2. 拿走一個

回傳拿走一個之後還剩多少個。如果這種道具列在表上，但已經一個都不剩，就拋出 `"Out of "`，後面接上它的名稱。

```sather
MISSING_PROPS::take_one(props, "crown")
-- => 1

MISSING_PROPS::take_one(props, "lantern")
-- raises "Out of lantern"
```

如果道具根本不在表上，仍然應該拋出 `"Unknown prop: ..."`，而且你不應該把這則訊息寫兩次。

## 3. 回報

無論發生什麼事，都改成回傳一則訊息，而不是拋出。

```sather
MISSING_PROPS::report(props, "crown")
-- => "Took crown, 1 left"

MISSING_PROPS::report(props, "lantern")
-- => "Out of lantern"

MISSING_PROPS::report(props, "sword")
-- => "Unknown prop: sword"
```

成功時，訊息是 `"Took "`、名稱、`", "`、還剩多少個，再加上 `" left"`。失敗時，訊息就正好是原本會拋出的內容。
