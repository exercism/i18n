# 提示

## 1. 重新命名欄位

- 記得，你需要修改`trees`資料集，只要呼叫`library(datasets)`就能取得。
- 你可能會（也可能不會）想把原本的`data.frame`轉成`tibble`。
- 如何變更欄位名稱，請參考簡介。

## 2. 新增 girth 與 weight 欄位

- 如何新增欄位，請參考簡介。
- 新的欄位可以用現有的欄位計算出來。
- 別忘了四捨五入到要求的精確度喔。

## 3. 果園的資料集副本

- 你需要搬移欄位並排序資料列（請參考簡介）。

## 4. 客戶的資料集副本

- 你需要取出部分的欄位。
- 副本中只應該包含 height 介於最小與最大值之間、*而且* weight 低於最大值的樹木。
