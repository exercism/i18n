# 指令

在這道練習中，你會幫一位朋友正在開發的電玩遊戲寫一些邏輯。
遊戲的主角是 Annalyn，一位勇敢的女孩，身邊有一隻兇猛又忠誠的寵物狗。
不幸的是，災難發生了：她最好的朋友在森林裡採莓果時被綁架了。
Annalyn 會試著找到並救出她的朋友，這趟冒險中也可以選擇帶上她的狗。

Annalyn 最後找到了囚禁她朋友的營地，發現綁匪有兩個：一位強大的騎士和一位狡猾的弓箭手。

玩家會看到接下來可以採取的行動選項。
四個可能的選項中，每個都需要你寫一個字詞，告訴遊戲是否要顯示該選項。

## 1. 檢查是否該顯示「快速攻擊」選項

如果騎士正在睡覺，Annalyn 就能趁他還沒完全清醒、穿上盔甲之前，迅速突襲營地。

實作一個名為`can-do-fast-attack`的字詞，它接受一個布林值，表示騎士是否醒著。
如果「快速攻擊」行動可用，就回傳`t`，否則回傳`f`：

```factor
t can-do-fast-attack .
! => f
```

## 2. 檢查是否該顯示「偵察」選項

只要這群人裡至少有一人醒著，就能對他們進行偵察。否則，偵察只是浪費時間。

實作一個名為`can-spy`的字詞，它接受三個布林值，分別表示騎士、弓箭手和囚犯是否醒著。
如果「偵察」行動可用，就回傳`t`，否則回傳`f`：

```factor
f t f can-spy .
! => t
```

## 3. 檢查是否該顯示「對囚犯打暗號」選項

如果囚犯醒著，而弓箭手正在睡覺，就可以用鳥叫聲向她打暗號。
如果弓箭手醒著，就不能安全地打暗號，因為弓箭手也受過鳥叫聲暗號的訓練。

實作一個名為`can-signal-prisoner`的字詞，它接受兩個布林值，分別表示弓箭手和囚犯是否醒著。
如果「對囚犯打暗號」行動可用，就回傳`t`，否則回傳`f`：

```factor
f t can-signal-prisoner .
! => t
```

## 4. 檢查是否該顯示「釋放囚犯」選項

Annalyn 可以試著潛入營地救出她的朋友。這件事風險很高，只有兩種方式能成功：

- 如果 Annalyn 帶著她的寵物狗，只要弓箭手在睡覺，她就能救出囚犯。
  騎士怕狗，而弓箭手也來不及準備，Annalyn 和她的朋友就能逃走。

- 如果 Annalyn 沒有帶狗，那她和囚犯就得非常小心翼翼！
  只要囚犯醒著，而且騎士和弓箭手都在睡覺，Annalyn 就能釋放囚犯。
  如果囚犯在睡覺，就無法救她：她會被 Annalyn 突然出現嚇到，然後吵醒騎士和弓箭手。

實作一個名為`can-free-prisoner`的字詞，它接受四個布林值。
參數依序表示弓箭手是否醒著、狗是否在場、囚犯是否醒著，以及騎士是否醒著。
如果「釋放囚犯」行動可用，就回傳`t`，否則回傳`f`：

```factor
f t t f can-free-prisoner .
! => t      (archer asleep, dog present, prisoner awake, knight asleep)

t t f f can-free-prisoner .
! => f      (archer is awake, so no rescue possible)
```
