# 指令

你在`classes`練習中開始的遙控車專案進行得很順利（恭喜！），而且因為最近談成了幾筆贊助案，預算裡有經費可以做一些強化。

其中一部分預算被用來提供一些遙測資料。

為了讓贊助商開心，車上安裝了一面看板，在車子繞行賽道時顯示贊助商的名稱。

你會注意到，這些新奇技術的導入大幅縮短了車子的電池續航力。

## 1. 讓遙控車能顯示贊助商名稱

實作`SetSponsors()`，讓它接收一個或多個贊助商名稱，並儲存在車子上。

請注意，`SetSponsors()`方法的引數保證不會是 null。

實作`DisplaySponsor()`來顯示所選的贊助商。傳入的第一個贊助商，其`sponsorNum`為 0，第二個為 1，依此類推。

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. 取得車子的遙測資料

實作`RemoteControlCar.GetTelemetryData()`方法。

`GetTelemetryData()`應該透過`out`參數提供電池百分比，以及以公尺為單位的行駛距離。

`GetTelemetryData()`應該在 serialNum 引數小於先前收到的值時回傳`false`。（這牽涉到多個遙測節點的問題。）在這種情況下，`serialNum`會被設為先前最高的`serialNum`，而電池百分比和行駛公尺數都會被設為`-1`。呼叫成功時，`serialNum`維持不變。

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. 新增功能，讓遙測系統能取得每公尺的電池用量

實作`TelemetryClient.GetBatteryUsagePerMeter()`方法。

這會呼叫`RemoteControlCar.GetTelemetryData()`。如果`GetTelemetryData()`回傳`false`，或者車子尚未行駛過，這個常式就應該回傳 "no data"。如果`GetTelemetryData()`回傳`true`，則應該回傳格式如下的訊息："usage-per-meter=BATTERY-USAGE-PER-METER"，其中計算方式是把（100 減去目前的電池百分比）除以目前為止行駛的公尺數。

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
