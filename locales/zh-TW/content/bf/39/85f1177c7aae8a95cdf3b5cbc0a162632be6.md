# CLI

## 設定

安裝 PureScript 最簡單的方式，就是透過 Node.js 和 NPM。

如果你的電腦還沒安裝 Node.js，可以從 [Node.js 網站][nodejs-website] 下載。等 Node.js 安裝好並能運作之後，在終端機輸入以下指令，即可安裝 PureScript 編譯器和 Spago 套件管理與建置工具。

```shell
npm install -g purescript spago
```

更多資訊請見 [PureScript 儲存庫][purescript-repository]。

## 需求

安裝練習的相依套件：

```shell
spago install
spago build
```

## 讓測試套件通過

用以下指令執行測試：

```shell
spago test
```

測試套件裡除了第一個測試之外，其餘的都被跳過了。這是為了鼓勵你一步一步解開練習。

當你讓某個測試通過後，只要把`xit`改成`it`，就能啟用下一個測試。

## 提交解答

當所有測試都不再被跳過，而且全部通過後，就可以用以下指令提交你的解答：

```shell
exercism submit src/<NAME>.purs
```

## 撰寫自訂測試

如果你想額外撰寫自訂測試，請建立一個新檔案`test/Custom.purs`，並在提交解答時連同這個新檔案一起提交：

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
