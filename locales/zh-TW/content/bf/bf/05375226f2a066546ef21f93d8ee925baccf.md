# 簡介

一個[`list`][list]是可變的項目集合，各項目依_序列_排列。
 就像大多數的集合類型（_請參見內建的[`tuple`][tuple]、[`dict`][dict]和[`set`][set]_），`list`可以儲存任何（或多種）資料型態的參照，包括其他的`list`。
 陣列可以透過[切片語法][slice notation]或使用`<list>.copy()`整份或部分複製。
 就像任何[序列][sequence type]一樣，`lists`中的元素可以從左邊以`0-based index`編號、或從右邊以`-1-based index`編號來引用。

陣列同時支援[一般][common sequence operations]與[可變][mutable sequence operations]的序列操作，例如`min(<list>)`/`max(<list>)`、`<list>.index()`、`<list>.append()`和`<list>.reverse()`。
 `list`中的元素可以使用`for item in <list>`這樣的構造來疊代。
 當同時需要元素的索引和值時，可以使用`for index, item in enumerate(<list>)`。

Python 也提供了許多實用的[list-methods][list-methods]來操作陣列。
 以下會介紹其中一些`list methods`。


請注意，當你用`list-method`操作`list`時，**你會改動這個陣列**物件。
 如果你不想改動原始的`list`，至少需要透過切片或`<list>.copy()`做一份`shallow copy`。


## 新增項目

如果要把項目加到現有陣列的最後或「右側」，請使用`<list>.append(<item>)`：

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

有別於_附加_，`<list>.insert()`讓你可以把項目加到陣列中_指定的索引_位置。
它接受 2 個參數：

1. 你想插入項目的`<index>`。
2. 要插入的`<item>`。

**注意**：如果給定的`index`是 0，項目會被加到`list`的開頭（「左側」）。
 如果提供的`index`大於`list`上最後一個`index`，項目會被加到最後的位置，等同於使用`<list>.append(<item>)`。


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


`<list>.extend(<item>)`可以用來把現有陣列與另一個可疊代物件（例如`set`、`tuple`、`str`或`list`）的元素合併。
  這個可疊代物件會被_拆解_，元素會依序附加（_在這種情況下使用`<list>.append(<item>)`會把整個可疊代物件當成**單一項目**加入。_）。


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## 移除項目

如果要從陣列中刪除項目，請使用`<list>.remove(<item>)`，並將要移除的項目作為引數傳入。
 如果該項目不在`list`中，`<list>.remove(<item>)`會拋出`ValueError`。


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


或者，使用`<list>.pop(<index>)`方法可以同時移除**並**`return`一個元素供你使用。


`<list>.pop(<index>)`接受一個選用參數：要移除並回傳的項目`index`。
 如果沒有指定（選用的）`index`引數，`list`的最後一個元素會被移除並回傳。
 如果指定的`index`大於最後一個項目的`index`，就會引發`IndexError`。


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

用`list.clear()`可以移除`list`中的所有元素。它不接受任何參數。

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## 反轉與重新排序

`<list>.reverse()`方法會**就地**反轉元素的順序。


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


陣列可以透過[`<list>.sort()`][sort]_**就地**_重新排序。
預設的排序順序是由左至右_遞增_。
Python 文件提供了[更多排序的技巧與方法][sorting how to]。

~~~~exercism/note
 從 2002 年到 2022 年，Python 在內部使用一種稱為 [`Timsort`][timsort] 的演算法來排列陣列，但從 `Python 3.11` 起改用 [`Powersort`][powersort]。

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

如果想要_遞減_的順序，請傳入`reverse=True`引數：

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

如果不希望改動原始陣列，可以使用內建的[`sorted(<iterable>)`][sorted]函式回傳排序後的**副本**。


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## 項目在陣列中出現的次數

元素在陣列中出現的次數可以用`list.count(<item>)`計算。
 它接受要計數的`item`作為引數，並回傳該元素在`list`中出現的總次數。


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## 找出項目的索引

`<list>.index(<item>)`會回傳傳入項目_第一次出現_的`index`編號。
 如果都沒有出現，就會引發`ValueError`。
 如果不需要項目的確切位置，內建的`in`運算子更適合用來檢查陣列是否包含某個值。


索引從左側開始由零算起，所以「第一個」項目的位置是`0`。
索引也可以從右側開始，以`-1`起算。


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

也可以提供`start`和`end`索引，把搜尋範圍縮小到`list`的特定區段：

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
