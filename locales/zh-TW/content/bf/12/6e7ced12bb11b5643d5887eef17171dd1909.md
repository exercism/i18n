# 指令

身為一位見習魔術師，Elyse 需要練習一些基本功。她有一疊卡片想要操作。

為了讓事情簡單一點，她只用 1 到 10 的卡片。

這疊卡片用一個`queue`表示，堆疊的底部在佇列的前端，堆疊的頂端在後端。

## 1. 在堆疊頂端插入一張卡片

實作函式`insert_top`，回傳堆疊的副本，並將提供的新卡片加到堆疊頂端。

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. 從堆疊頂端移除一張卡片

實作函式`remove_top_card`，回傳移除頂端卡片後的堆疊副本。如果給定的堆疊是空的，就回傳原本的堆疊，不做任何改變。

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. 在堆疊底部插入一張卡片

實作函式`insert_bottom`，回傳堆疊的副本，並將提供的新卡片加到堆疊底部。

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. 從堆疊底部移除一張卡片

實作函式`remove_bottom_card`，回傳移除底部卡片後的堆疊副本。如果給定的堆疊是空的，就回傳原本的堆疊，不做任何改變。

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. 檢查堆疊的大小

實作函式`check_size_of_stack`，檢查堆疊的大小是否等於給定的`stack_size`。

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
