# 簡介

## 註解

Exercism 的 x86-64 軌道使用 **NASM**（The Netwide Assembler）作為組譯器。
在 NASM 中，註解會以分號（`;`）開頭。

註解可以放在程式的任何地方，而緊接在`;`之後的所有內容都會被組譯器忽略。

## 常數

在 NASM 中，可以使用 **equ** 定義組譯時期的常數。
例如，以下定義了一個名為`UNIVERSE`、值為`42`的常數：

```x86asm
UNIVERSE equ 42
```

常數在定義時只會求值一次，之後再也_不能_重新定義。

## 通用暫存器（GPRs）

在組合語言中，我們通常不使用變數，而是使用暫存器來儲存值。
**CPU 暫存器**是位於電腦處理器內部的一小塊快速記憶體。
大多數的運算都在 CPU 的暫存器中進行。

有些暫存器用於各種不同的運算，稱為**通用暫存器（GPRs）**。
其他暫存器則有特殊或專門的用途。

在 x86-64 中，有 16 個 64 位元的通用暫存器（GPRs），也可以用 32 位元、16 位元或 8 位元的形式存取。
以下說明這些通用暫存器，其中`rn`裡的`n`範圍是 8 到 15：`r8`、`r9`、`r10`、`r11`、`r12`、`r13`、`r14`和`r15`。

| 64 位元 | 32 位元 | 16 位元 | 8 位元 |
| :----: | :----: | :----: | :---: |
|  rax   |  eax   |   ax   | ah/al |
|  rbx   |  ebx   |   bx   | bh/bl |
|  rcx   |  ecx   |   cx   | ch/cl |
|  rdx   |  edx   |   dx   | dh/dl |
|  rsi   |  esi   |   si   |  sil  |
|  rdi   |  edi   |   di   |  dil  |
|  rbp   |  ebp   |   bp   |  bpl  |
|  rsp   |  esp   |   sp   |  spl  |
|   rn   |  rnd   |  rnw   |  rnb  |

使用少於 64 位元時，存取的位元通常來自暫存器的低位部分。
這個規則的例外是`ah`、`bh`、`ch`和`dh`，它們存取的是暫存器 16 位元部分中的高 8 位元。

下圖說明`rax`暫存器的位元如何存取：

```
+--------+---------------------------------------+
| 64-bit |                  rax                  |
+--------+-------------------+-------------------+
| 32-bit |                   |        eax        |
+--------+-------------------+---------+---------+
| 16-bit |                             |    ax   |
+--------+-----------------------------+----+----+
| 8-bit  |                             | ah | al |
+--------+-----------------------------+----+----+
```

其中有些暫存器必須在函式呼叫之間保持不變：`rbp`、`rsp`、`rbx`、`r12`、`r13`、`r14`和`r15`。
若未能保持這些暫存器，可能會導致錯誤或未定義行為。

其他暫存器則不需要保持，可以自由使用：`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10`和`r11`。

~~~~exercism/caution
之後在課程大綱中，你會學到如何保持暫存器。
目前請只使用第二類暫存器：`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10`和`r11`。
~~~~

## 指令

指令是 CPU 可以執行的一項項運算。
它們通常具有以下形式：

```x86asm
name destination, source
```

也就是說，指令的名稱放在最前面，接著至少一個空白，然後是目的運算元、逗號（`,`），最後是來源運算元。
指令通常不會修改來源運算元，只會修改目的運算元。

除非另有說明，否則兩個運算元的大小必須相同。
例如，如果來源運算元是 16 位元，目的運算元也必須是 16 位元。

舉例來說，要把值儲存到暫存器中，可以使用`mov`指令：

```x86asm
mov rax, rdx  ; rax = rdx
              ; mov is the name, rax is the destination operand and rdx is the source operand
```

上面的程式片段會把來源運算元`rdx`全部 64 位元的內容，複製到該指令的目的運算元`rax`的全部 64 位元。

在大多數指令中，可以把常數整數當作來源運算元（但不能當作目的運算元）：

```x86asm
mov rcx, 42 ; rcx = 42
            ; rcx is the destination operand and 42 is the source operand
```

請注意，寫入 32 位元暫存器也會清除高位元，所以`mov eax, 42`等同於`mov rax, 42`。
但 16 位元和 8 位元暫存器並非如此。

對於加法、減法和乘法等算術運算，可以使用`add`、`sub`和`imul`指令：

```x86asm
add rax, rsi ; rax = rax + rsi
imul rax, rdi ; rax = rax * rdi
sub rax, r8 ; rax = rax - r8
```

## 函式

指令會組織成函式。
所有函式都放在原始檔的**section .text**中。

函式的宣告包含：

1. 一個標籤，以函式的名稱命名，後面接著`:`。
2. 定義該函式的指令。
3. 返回指令，`ret`。

這個軌道使用 System V AMD64 ABI 呼叫慣例，前六個整數引數會透過暫存器傳入函式。
傳入的順序如下：`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`。

整數值會透過`rax`暫存器從函式回傳。

要呼叫函式，我們使用`call`指令。
同一個原始檔中的任何位置都可以呼叫函式。
如果要讓其他原始檔也能看到某個函式，就必須使用`global`指示詞。

例如，以下宣告了一個函式`sum`：

```x86asm
section .text ; functions are placed here

global sum ; sum is visible to other source files

sum:
    ; first argument is passed in rdi
    ; second argument is passed in rsi
    ; return value is placed in rax

    mov rax, rdi ; rax is now equal to rdi
    add rax, rsi ; rax = rax + rsi

    ret ; function return
```

而以下則以引數 3 和 5 呼叫我們的`sum`函式：

```x86asm
mov rdi, 3  ; First argument in rdi
mov rsi, 5  ; Second argument in rsi
call sum

; The rax register now contains the value 8 (3 + 5), after sum returns
```
