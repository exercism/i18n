# 提示

## 一般

- 回呼函式是當作引數傳給呼叫端函式的函式。
- 回呼函式必須符合呼叫端函式的規格。

## 1. 以成功訊息通知

- 在你的函式中使用匯入的 API 函式`notify`。
- 傳一個物件給`notify`。這個物件應該有`message`屬性。想一想訊息的值應該是什麼。
- 注意 JSDoc 的型別提示：這個函式不應該回傳值。

## 2. 以錯誤訊息通知

- 在你的函式中使用匯入的 API 函式`notify`。
- 再傳另一個物件給`notify`。它應該有`message`屬性。訊息的值應該和上一題不同。
- 注意函式定義上方的註解 [JSDoc]：
  - 這個函式不應該回傳值。

## 3. 下單購買水果

- 使用已經匯入的`order`函式。
- 注意 JSDoc 的型別提示：這個函式應該接收 3 個引數，而且不回傳值。
- 重複使用先前建立的回呼函式，把它們當作 order 函式的引數。

## 4. 重構你的程式碼，讓函式更精簡

- 重複使用前面幾題的函式。
- 注意 JSDoc 的型別提示：這個函式應該接收 2 個引數，而且不回傳值。
- 把這些引數合併成一個物件，代表向水果商下單的查詢。
