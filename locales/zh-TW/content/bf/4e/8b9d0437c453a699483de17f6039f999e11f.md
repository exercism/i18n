# 簡介

在 Python 中，[`enum`][enum-docs]是一組名稱，每個名稱都綁定到唯一的`literal`或`constant`值。
`Enums`是透過繼承或子類別化`Enum`類別來定義的。
內建的`enum`型別位於`enum`模組中，而`Enum`類別可以用`from enum import Enum`匯入。


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

請注意，`enum`成員的值可以是任何資料型態，例如`str`、`tuple`、`float`等等。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

當你把相同的值指定給`enum`中的兩個成員時，後指定的成員會成為前一個成員的別名。同一個`enum`中不允許兩個不同的成員使用相同的名稱。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

疊代`enum`的成員可以使用標準的`for member in`語法：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

`Enum`成員可以用[`is`（_身分運算子_）][identity-keyword]或`is not`來比較。`==`或`!=`（_相等運算子_）的運作方式也相同：

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

若要取得某個值對應的`enum`成員，可以使用`<EnumName>(<value>)`：

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

[identity-keyword]: https://www.w3schools.com/python/ref_keyword_is.asp
