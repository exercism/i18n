# 簡介

`str` 類別提供了[許多實用的方法][str methods]，用來操作與組合字串。
這些方法涵蓋搜尋、清理、分割、轉換、翻譯，以及許多其他技巧。

字串是 [Unicode 碼位][unicode code points] 的 [序列][text sequence]：個別的「字元」或碼位（_長度為 1 的字串_）可以用從左邊算起的`0-based index`編號，或從右邊算起的`-1-based index`編號來取值。
字串支援所有[常見的序列操作][common sequence operations]。

可以用`for item in <str>`或`for index, item in enumerate(<str>)`語法來疊代。
也可以用`<str> + <other str>`或`<str>.join(<iterable>)`來串接。

字串是_不可變的_，意思是記憶體中`str`物件的值無法改變。
對`str`進行操作的函式或方法（_就是我們這裡正在學的這些_）會回傳該`str`物件的新`instance`，而不會修改原本的`str`。

以下是一些 Python 字串方法的精選範例。
完整的清單請參閱 Python 文件中的 [str 類別][str methods]。


[`<str>.title()`][str-title]會解析字串，並將找到的每個「單字」的第一個「字元」轉為大寫。
在 Python 中，這非常取決於所使用的[語言編解碼器][codecs]，以及該語言如何表示單字與字元。
特定語言或字元集也可能有[地區設定][locale]規則。


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith]在字串以`<suffix>`結尾時回傳`True`，否則回傳`False`。


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip]會回傳`str`的副本，並移除開頭與結尾的`<chars>`。
`<chars>`中指定的碼位並不是前綴或後綴，字串**兩端**的碼位**所有組合**都會被移除。
 如果沒有為`<chars>`指定任何內容，則會移除所有空白字元碼位的組合。


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace]會回傳字串的副本，並將所有出現的`<substring>`取代為`<replacement substring>`。

以下使用的引文出自 [Lewis Carroll][Lewis Carroll] 的 [The Hunting of the Snark][The Hunting of the Snark]

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
