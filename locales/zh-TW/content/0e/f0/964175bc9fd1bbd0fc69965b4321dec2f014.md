# 簡介

C# 中的屬性是類別的成員，提供存取該類別內資料的方式。呼叫端可以設定或取得（get）資料。屬性可以是自動實作的，也可以有支援欄位。屬性由 set 存取子及／或 get 存取子組成。

在其他語言中，「mutator」大致等同於 set 存取子，「accessor」大致等同於 get 存取子，不過語法的組成方式完全不同。

設定屬性時，可以對輸入值進行驗證、格式化或其他處理，事實上，只要是類別中的程式碼能存取的程式化操作，都可以執行。

同樣地，取得屬性時，資料可以經過計算或格式化，而且只要是類別可用的程式化操作，同樣都能執行。

屬性和其他類別成員一樣，可以擁有存取修飾詞（`public`、`private` 等），但 set 存取子可以擁有獨立於取得（get）存取子的存取層級，反之亦然。屬性不一定要同時具備兩個存取子，也可以只有其中一個（get 或 set）。

表達屬性的基本語法有兩種形式：

## 以欄位／運算式為基礎的屬性：

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## 自動實作屬性

```
public int MyProperty { get; private set; } = 42;
```

初始化是選用的。
