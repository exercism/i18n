# 資源

- [The Zig Programming Language Documentation][documentation] 完整介紹了 Zig 為使用者提供的所有語言功能。
- [The Zig Standard Library][std] 是學習 Zig 程式碼如何撰寫的實用參考，也展示了許多你可以匯入自己程式碼的函式。
- [Awesome Zig][awesome-zig] 是一份精選的 Zig 專案清單。
- irc.freenode.net 上的 [#zig][irc] 是主要的 Zig IRC 頻道。
- [Stack Overflow][stack-overflow] 可以用來尋找程式碼片段，以及別人可能已經問過、甚至已經解決的問題的解答。
- [/r/Zig][reddit] 是主要的 Zig Reddit 看板。
- [The Zig Programming Language Discord][discord-zig] 是主要的 [Discord][discord]。它提供了很棒的方式讓你認識廣大的 Zig 社群，並針對任何 Zig 相關問題快速取得直接協助。
- [The Zig SHOWTIME Newsletter][newsletter] 會發布新的集數、重要活動，以及有趣的新 Zig 專案連結。
