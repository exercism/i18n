# 介紹

`String`中的個別字元可以透過陣列所使用的下標方法來存取。
不過，字串所使用的[索引][string-indices]_並非_整數，無法直接拿來操作。
這些索引必須根據其他已知的索引計算而得，例如 `startIndex`，它指向非空字串中第一個字元的位置；計算時要使用 [`String`][string-docs] 與 [`NSString`][nsstring-docs] 程式庫所提供的方法（匯入 `Foundation` 模組後，Swift 中的字串就能取用 NSString 的所有屬性和方法）。

舉例來說，假設有下列字串：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

你無法寫出 `csv[21]` 來取得「orange」中的「g」，而是要計算一個 `String.Index` 型別的值，並改用這個索引。
請注意，這些索引本身並不是設計給人直接解讀的。
它們被稱為_不透明索引_，因為人類不需要知道它們內部裝了什麼。

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

不過請注意，如果偏移量不是有效的索引，也就是說，如果它算出的索引落在 `startIndex` 之前或 `endIndex` 之後，這個操作就會引發錯誤，讓程式崩潰。
為了避免這個問題，你可以指定一個限制索引。
這樣一來會回傳一個可選的索引，對於原本無效的索引則會回傳 nil。

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

此外，索引不能在不同字串之間共用。
舉例來說，用上面算出的「orange」中「g」的 `index` 來索引字串 `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`，也就是 `fam[index]`，會讓你的程式崩潰。

這一切背後有很多原因，但基本上都可以歸結為一句話：「Unicode 很棘手」。

一般來說，如果你需要隨機存取個別字元，你大概應該改用其他資料結構，例如 `Array<Character>`。

## 一些實用的方法

Swift 有 `first` 和 `last` 方法，可以取得字串的第一個和最後一個字元。
這些方法會回傳一個可選字元，所以如果字串是空的，它們會回傳 nil。

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

你也可以使用 `prefix` 和 `suffix` 方法來取得字串的子字串。
這些方法接受一個整數作為引數，並回傳包含字串前 n 個或後 n 個字元的子字串。

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
