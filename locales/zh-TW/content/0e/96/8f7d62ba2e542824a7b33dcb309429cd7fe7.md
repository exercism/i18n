# 測試

## 執行測試

要執行測試，請在練習目錄中執行下列指令：

```shell
make
```

這會組譯你的解法、編譯測試、將它們連結成一個 RISC-V 程式，並在`qemu-riscv32`下執行。
程式會為每個測試印出一行，顯示它是通過、失敗還是被忽略，最後再印出一份摘要。

## 完成練習

完成一個練習，就代表讓它所有的測試都通過。
預設情況下，執行測試時只會執行一個測試（也就是第一個）。
這是刻意的，這樣你就能專心先讓那一個測試通過。
一旦它通過了，你就可以移除`TEST_IGNORE();`這一行來啟用下一個測試。
當所有測試都已啟用，而你的實作也讓它們全部通過時，你就完成這個練習了喔！
