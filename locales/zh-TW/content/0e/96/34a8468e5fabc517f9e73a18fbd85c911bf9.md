# 關於

[`for`迴圈][for-statement]讓你可以反覆執行程式碼，直到符合某個條件為止。

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`迴圈由四個部分組成：

1. 初始化式：在進入迴圈前執行一次。通常用來定義迴圈內會用到的變數。
2. 條件：在每次迴圈疊代前執行。只要評估結果為 `true`，迴圈就會繼續執行。
3. 疊代器：在每次迴圈疊代後執行。通常用來修改（往往是遞增／遞減）迴圈變數。
4. 主體：每次迴圈疊代時實際執行的程式碼。

## for 迴圈與 foreach 迴圈

一般而言，[concept:csharp/foreach-loops]()比 `for` 迴圈更適合使用，原因如下：

- `foreach`迴圈保證會疊代過_所有_的值。使用 `for` 迴圈時，很容易漏掉元素，例如因為差一錯誤。
- `foreach`迴圈更具有_宣告式_風格：你的程式碼傳達的是你想讓它_做什麼_，而不是像 `for` 迴圈那樣傳達你想_怎麼做_。
- `foreach`迴圈萬無一失，而 `for` 迴圈則很容易發生差一錯誤。
- `foreach`迴圈適用於所有集合型別，包括那些不支援使用索引子存取元素的型別。

為了保證 `foreach` 迴圈會疊代過_所有_的值，編譯器不允許在 `foreach` 迴圈內更新集合：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`迴圈確實比 `foreach` 迴圈有一些優點：

- 你可以從想要的索引開始，或停在想要的索引。
- 你可以使用任何想要的（布林）結束條件。
- 你可以自訂迴圈變數的遞增方式來跳過某些元素。
- 你可以倒著計數，從後往前處理集合。
- 在不涉及集合的情境下，你也可以使用 `for` 迴圈。
