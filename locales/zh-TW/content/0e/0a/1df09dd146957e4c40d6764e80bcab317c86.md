# 簡介

*元組*會把幾個具名的值打包成一個物件，也就是其他語言所稱的記錄、結構或類別。每個元組類別都有一組固定的具名槽位，Factor 會自動為它們產生取值器和設定器。

## 定義元組

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

每個槽位都以`{ name initial: default-value }`的形式宣告。沒有`initial:`子句時，預設值是`f`。

## 建構元組

最簡單的建構子是`new`：

```factor
point new .
! => T{ point }
```

`boa`（依引數順序）會從資料堆疊依宣告順序填入槽位：

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

字面語法`T{ class { slot value } … }`讓你可以建構只設定部分槽位的元組，列印出來的樣子也相同：

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

當槽位的值與預設值相同時，列印程式會省略它。

## 讀取槽位

Factor 會為每個槽位產生一個取值器`slot>>`。取值器位於[`accessors`][accessors]裡：

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## 更新槽位

設定器寫成`>>slot`，而且會*就地修改*元組：

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

想保留原始值不動，就先`clone`：

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot`接受一個引述，把目前的值對應到新的值：

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x`同樣會就地修改，所以如果想保留原始值，請在呼叫它之前先`clone`。
