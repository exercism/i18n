# 型別戲法

型別戲法又稱為型別強制轉換。
型別戲法是指兩個不同型別的值，為了執行運算而被強制轉換成同一種型別。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

這種轉換可以隱含地發生（見上方範例），也可以明確地透過 `C` 風格的型別轉換來完成：

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

手動型別轉換允許的型別有：`bool`、`int`、`float`、`string`、`array`、`object`。
最常見的情況，是把整數（`int`）改成浮點數（`float`），或是反過來。
