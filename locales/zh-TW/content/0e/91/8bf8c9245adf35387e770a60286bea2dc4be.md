# 關於

浮點數是小數點後帶有零或多個位數的數字，例如`4.0`、`0.1`、`3.14`、`-6.4`、`16.984025`和`1024.0`。在 Ruby 中，浮點數是透過 [Float][Float] 類別實作的。

你可以在 [0.30000000000000004.com][0.30000000000000004.com] 找到浮點數的簡短介紹。

[Float Toy 頁面][evanw.github.io-float-toy] 用好看的圖解說明了浮點數的位元如何轉換成實際的浮點數值。

想要重複執行邏輯，可以使用迴圈。
在這個例子中，`while`迴圈很好用，因為只要條件評估為真值（也就是不是`false`或`nil`），它就會持續迴圈。
Ruby 也實作了一個類似`while`迴圈的迴圈，叫做`until`迴圈，你大概已經猜到它的作用了。
它會持續迴圈，直到布林條件評估為`true`。
在某些語言中，為了讓一段程式碼能無限次執行，會使用像`while true`這樣的結構。
在 Ruby 中，`loop`迴圈就是為了這個目的而存在。
雖然`loop`迴圈不依賴單一條件，但可以透過`return`或`break`關鍵字來中止它。

上一個練習中的`#years_before_desired_balance`方法，也可以用前面提到的三種迴圈中的任一種來撰寫：

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

你大概已經注意到了，Ruby 不像某些其他語言那樣有遞增運算子（`i++`）。不過，可以使用像`i += 1`（等同於`i = i + 1`）這樣的寫法。
