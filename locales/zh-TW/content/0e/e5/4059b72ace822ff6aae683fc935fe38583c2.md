# 關於

想像你有一個幾十萬行的程式碼庫。有人把開發者的字典傳進你正在開發的方法裡。也許你被指派要印出特權開發者的詳細資料。你決定把字典裡的眼睛顏色清空，以保護開發者的隱私。除非 `Authenticator.GetDevelopers()` 方法已經製作了字典的[深拷貝][so-deep-copy]，或者更好的做法是把它包在唯讀集合裡，否則你剛剛就把 authenticator 給毀了。

這遵循[防禦性複製][defensive-copying]的原則。只要避免把內部的可寫入狀態暴露給呼叫方，就能確保你正式的 API 不會被繞過。

[so-deep-copy]: https://stackoverflow.com/questions/78536/deep-cloning-objects
[defensive-copying]: https://www.informit.com/articles/article.aspx?p=31551&seqNum=2
