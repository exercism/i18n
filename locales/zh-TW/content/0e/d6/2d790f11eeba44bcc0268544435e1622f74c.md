# 簡介

`Map`用來儲存成對的**鍵**和**值**。`Maps`的初始化方式就跟陣列一樣，但要使用 map 常值運算子`=>`。你也可以明確定義鍵與值的型別，或讓型別自動推斷。鍵必須是唯一的，否則會拋出錯誤。

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map`可以用`for`迴圈疊代。你可以疊代值，也可以疊代鍵：

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
