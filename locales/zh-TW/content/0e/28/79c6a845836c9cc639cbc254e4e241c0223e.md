# 簡介

命名空間是一種將相關程式碼分組的方式，也能避免名稱衝突。除了最簡單的程式碼基底之外，幾乎所有的程式碼基底都會用到。

語法如下：

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

命名空間內含的型別若要在該命名空間的作用域之外使用，必須在型別名稱前面加上點號語法。另一種做法更為常見：在檔案最上方（或命名空間內）放置`using`指示詞，之後就能不加前置詞直接使用型別。在同一個命名空間裡，則不需要限定型別名稱。

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

你可以用`using MyAlias = MySpace;`這個語法為命名空間取別名，之後在任何可以使用該命名空間的地方，都能改用這個別名。
