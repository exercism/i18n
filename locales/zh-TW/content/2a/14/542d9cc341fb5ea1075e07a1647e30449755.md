# 簡介

浮點數是小數點後帶有一或多個位數的數字。它們使用 64 位元雙精度浮點數格式。

```elixir
float = 3.45
# => 3.45
```

## 處理數字

在 [`Integer`][integer-functions] 和 [`Float`][float-functions] 模組中，你可以找到一些處理這些型別的實用函式。基本的算術運算子則定義在 [`Kernel`][kernel-arithmetic-operators] 模組中。

## 轉換

整數和浮點數可以混用在同一個算術運算式中。在運算式中使用浮點數，就能確保結果也會是浮點數。

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

不過，做除法時，結果一律會是浮點數，即使只用到整數也一樣。

```elixir
6 / 2
# => 3.0
```

要把浮點數轉成整數，你可以用 [`trunc/1`][trunc-1] 捨去小數部分。
