# 簡介

## Charlists

Charlist 是使用`~c` Sigil 建立的。

```elixir
~c"hello"
```

~~~~exercism/note
請注意，在舊版 Elixir 中，charlist 是以單引號表示的，例如`'hello'`。
~~~~

雖然 charlist 和字串看起來很像，但這兩種資料型態其實大不相同。Charlist 就是由整數組成的陣列。這些整數代表某個字元的 Unicode 值，也就是所謂的碼點。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

你可以在字元前面加上`?`，取得它的碼點。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

因為 charlist 就是陣列，你可以像操作其他陣列一樣操作它，例如使用遞迴和模式匹配。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

你可以使用`++`串接兩個陣列。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

第一個陣列越長，串接的速度就越慢，所以要避免反覆在長度不固定的陣列後面附加元素。

## case

`case`是一種控制流程結構，讓我們可以把某個值與多個模式進行比較。`case`表達式中的子句會從上到下依序求值，直到找到符合的模式為止。

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
