# 提示

## 1. 將二進位表示法轉換成整數

- 有一個[內建方法][string-to_i]，可以將帶有二進位表示法的字串依指定的進位轉換成整數。

## 2. 從整數取得最低有效位元

- 有一個[內建方法][integer-bit]，可以依指定的索引從整數取得某個位元。
- 最低有效位元是最右邊的位元，
  位於索引 0。

## 3. 從色彩通道取得十六進位值

- 有一個[內建方法][integer-to_s]，可以將整數依指定的進位轉換成帶有十六進位表示法的字串。
- 這個方法可以接受一個選用引數，用來指定產生位數的精度。

## 4. 從 RGB 取得十六進位值

- 你可以使用前面已經定義好的方法，從色彩通道取得十六進位值。
