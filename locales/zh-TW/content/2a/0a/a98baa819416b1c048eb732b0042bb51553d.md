# 簡介

## 比較

Python 支援以下基本的比較運算子：

| 運算子 | 運算 | 說明 |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | 「大於」             | 若 `a` 的值**嚴格**大於 `b`，則 `a > b` 為 `True`        |
| `<`      | 「小於」                | 若 `a` 的值**嚴格**小於 `b`，則 `a < b` 為 `True`           |
| `==`     | 「等於」                 | 若 `a` 的值**嚴格**等於 `b`，則 `a == b` 為 `True`           |
| `>=`     | 「大於或等於」 | 若 `a > b` 或 `a == b`，則 `a >= b` 為 `True`                        |
| `<=`     | 「小於或等於」    | 若 `a < b` 或 `a == b`，則 `a <= b` 為 `True`                        |
| `!=`     | 「不等於」             | 若 `a == b` 為 `False`，則 `a != b` 為 `True`                                 |
| `is`     | 「同一性」                 | 若 `a` 和 `b` 是同一_物件_，則 `a is b` 為 `True`（_**且僅限於此情況**_）|
| `is not` | 「否定的同一性」         | 若 `a` 和 `b` **不是**同一_物件_，則 `a is not b` 為 `True`       |
| `in`     | 「包含測試」         | 若 `a` 是 `b` 的成員、子集合或元素，則 `a in b` 為 `True`            |
| `not in` | 「否定的包含測試」 | 若 `a` 不是 `b` 的成員、子集合或元素，則 `a not in b` 為 `True`  |

它們的優先順序都相同（_高於 [布林運算][boolean operations]，但低於算術或位元運算_）。

## 不同資料型態之間的比較

不同型態的物件（_數值型態除外_）預設永遠不會比較為相等。
`class` 的非同一實例也 _**不會**_ 比較為相等，除非該 `class` 定義了特殊的 [豐富比較][rich comparisons] 方法，來自訂 `object` 預設的比較行為。
透過 `rich comparisons` 進行自訂會在某個後續的練習中介紹。
關於這個主題的（更多）細節，請參閱 Python 文件中的 [值比較][value comparisons]。

數值型態（大多）是這個型態配對規則的例外。
只要型態可以隱含轉換以供比較，`integer` **可以**被視為等於 `float`（_或 [`octal`][octal] 等於 [`hexadecimal`][hex]_）。

對於 Python 標準函式庫中的其他數值型態（[複數][complex numbers]、[十進位數][decimal numbers]、[分數][rational numbers]），比較運算子只在「合理」的地方才有定義（_隱含轉換不會改變結果的地方_），但如果底層物件無法準確轉換以供比較，就會擲出 `TypeError`。
關於 Python 用於_數值轉換_的規則的詳細資訊，請參閱 Python 文件中的 [算術轉換][arithmetic conversions]。

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

任何數字與 `NaN`（_不是數字_）型態進行的有序比較結果都是 `False`。
Python `NaN` 定義的一個令人困惑的副作用是：`NaN` 永遠不會等於 `NaN`。

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## 比較字串

與數字不同，字串（`str`）是使用各自的 Unicode 碼點[_依字典序_][lexographic order]進行比較（_也就是將 `str` 中的每個碼點傳入內建函式 [`ord()`][ord] 所得到的結果，它會回傳一個 `int`_）。
如果兩個字串中的所有碼點都相符，且 _**順序相同**_，這兩個字串就被視為相等。
這種比較是以「成對」的方式進行：第一個對第一個、第二個對第二個，依此類推。
在 Python 3.x 中，`str` 和 `bytes` 無法直接強制轉換或比較。

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## 比較串接

比較運算子可以_任意_串接，意思是它們能以任何長度的任何組合來使用。
請注意，運算式的求值是由 `left` 到 `right` 進行。

舉例來說，`x < y <= z` 等於 `x < y` `and` `y <= z`，差別在於 `y` **只會被求值一次**。
在兩種情況下，當發現 `x < y` 為 `False` 時，`z` **完全**_不會_被求值。
這通常稱為 `short-circuit evaluation`：如果運算式的真值已經確定，求值就會停止。

`Short circuiting` 受到各種布林運算子、函式的支援，Python 中的比較串接也支援它。
與許多其他程式語言（包括 `C`、`C++`、`C#` 和 `Java`）不同，Python 中像 `a < b < c` 這樣的串接運算式具有傳統的[數學詮釋][three way boolean comparison]與優先順序。

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## 比較物件同一性

運算子 `is` 和 `is not` 測試的是物件的[_同一性_][object identity]，而非物件的_值_。
物件建立之後，其同一性永遠不會改變，可以透過 [`id()`][id function] 函式取得。

若 _**且僅限於**_ `id(<apple>)` == `id(<orange>)`，則 `<apple> is <orange>` 的求值結果為 `True`。
`<apple> is not <orange>` 則會得到相反的結果。

由於 `None` 和 `NotImplemented` 具有單例的地位，應該一律使用 `is` 和 `is not` 來與項目進行比較。
關於這個慣例的更多細節，請參閱 Python 參考文件中的[值比較][value comparisons none]和 [PEP8][pep8 programming recommendations]。

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## 成員資格比較

運算子 `in` 和 `not in` 測試的是_成員資格_。
若 `<fish>` 是 `<soup>` 的成員（_`<fish>` 是 `<soup>` 的子集合，或包含於 `<soup>` 之中_），則 `<fish> in <soup>` 的求值結果為 `True`，否則為 `False`。
`<fish> not in <soup>` 會回傳其否定，也就是 `<fish> in <soup>` 的_相反結果_。

對於字串和位元組型態，若 _**且僅限於**_ `<name>` 是 `<fullname>` 的子字串，則 `<name> in <fullname>` 為 `True`。

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
