# 補充說明

## Roc API

計算字母的數量，忽略大小寫與非字母的字元，並回傳一個把小寫字母對應到其數量的字典。
把字母視為 Unicode 純量值；不需要 Unicode 正規化。

使用[roc-parallel 平台](https://github.com/ageron/roc-parallel)的`pf.Parallel.map!(items, { workers, task })`，以純`task`函式平行處理給定的`items`，透過多個執行緒（由`workers`指定）同時進行。
所有項目處理完畢後，結果會依輸入順序回傳。
你只需要編輯`ParallelLetterFrequency.roc`。

## 執行測試

與大多數其他練習不同，這個練習使用具有作用的函式。
請用`roc --opt=speed parallel-letter-frequency-test.roc`執行測試，而不是`roc test`。
Roc 程式碼回傳的任何錯誤都會由平台以和平常不同的格式回報。

你也可以去看看[`bank-account`練習](https://exercism.org/tracks/roc/exercises/bank-account)，它探討了並行的另一個面向：安全地將更新套用到共享狀態。

<summary>顯示提示</summary>

[Unicode 函式庫](https://github.com/roc-lang/unicode)提供大小寫轉換和字母偵測。
看看`unicode.Case.to_lower`、`unicode.GeneralCategory.of_scalar`、`unicode.Scalar.iter`和`unicode.Scalar.to_str`。
如果你的純`task`回傳一個`Try`，`Parallel.map!`會把這些 task 的結果包在它自己的`Try`裡回傳；請同時處理平台錯誤與各個 task 的錯誤。
