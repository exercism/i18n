# CLI（命令列介面）

你可以在練習的目錄中開啟命令提示字元，然後執行 [`go test` 指令][docs-go-test]來執行測試。或者，大多數 IDE 也都內建執行測試的支援，包括 [Visual Studio Code][docs-run-unit-tests-visual-studio-code] 和 [JetBrains GoLand][docs-run-unit-tests-goland]。

一開始只會啟用第一個測試。這是為了鼓勵你一次一步地解開這道練習。當你讓第一個測試通過後，把下一個測試的`Skip`屬性移除，再努力讓那個測試通過。

等到所有測試都沒有被跳過，而且全部通過時，你就可以提交你的解答：在練習的目錄中開啟命令提示字元，然後執行 [`exercism submit` 指令][docs-exercism-cli]。

如果想進一步閱讀，這裡有一份 [Go 測試][testing-in-go]的入門介紹，包含如何自己撰寫測試。
