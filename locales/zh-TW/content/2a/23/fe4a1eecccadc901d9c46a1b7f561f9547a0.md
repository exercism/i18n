# 關於

三元運算子允許把 `if` 條件定義在運算式裡，而不是定義在敘述區塊中。這種寫法與函式程式設計的思路相呼應，而且往往能讓程式碼更有表達力、更不容易出錯。

三元運算子會結合 3 個運算式：一個條件，接著是條件為 true 時會求值並回傳的運算式（也就是`if`的部分，由`?`帶出），以及條件為 false 時會求值並回傳的運算式（也就是`else`的部分，由`:`帶出）。

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
