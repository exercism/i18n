# 說明

在這個練習中，你將撰寫程式碼，使用 `Map` 來管理一份國際撥號代碼的字典。

這份字典可以讓你透過國際撥號代碼（映射的鍵，型別為 `Integer`）查詢國家名稱（映射的值，型別為 `String`）。

## 1. 回傳映射中的撥號代碼

實作不接受任何參數的 `getCodes` 方法，回傳目前字典中各撥號代碼對應國家的映射。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. 在字典中新增項目

我們需要填充這份字典。
實作 `setDialingCode` 方法，它接受一個撥號代碼與對應的國家，並新增該撥號代碼與國家。
如果該撥號代碼已經在映射中，就用提供的代碼與國家更新映射。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. 查詢撥號代碼對應的國家

實作 `getCountry` 方法，它接受一個撥號代碼，並回傳該撥號代碼對應的國家名稱。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. 不允許重複

新增撥號代碼時，必須小心避免同一個代碼或國家被新增兩次。
發生這種情況時，可以假設第一筆項目才是正確的項目。
實作 `addNewDialingCode` 方法，它會為指定的撥號代碼與國家新增一筆項目。
不過，和 `setDialingCode` 不同，如果該撥號代碼或國家已經在映射中，它不會做任何事。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. 找出國家對應的撥號代碼

這種情況很少見，但還是可能出錯。
為了修正錯誤，我們需要知道該國家目前對應到哪個撥號代碼。
為了找出哪個撥號代碼需要修正，請實作 `findDialingCode` 方法，它接受一個國家，並回傳該國家的撥號代碼。
如果該國家_不在_映射中，請回傳 `null`。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. 更新國家的撥號代碼

現在我們知道哪個撥號代碼需要修正了，接著就來更新它。
實作 `updateCountryDialingCode` 方法，它接受該國家的新撥號代碼與國家名稱，並據此更新。
如果該國家_不在_映射中，則不做任何事（因為這個方法只用來協助修正錯誤）。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
