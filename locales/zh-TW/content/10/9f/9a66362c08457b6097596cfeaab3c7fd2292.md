# 簡介

遞迴函式是會呼叫自己的函式。

一個遞迴函式至少需要一個_基礎情況_，以及至少一個_遞迴情況_。

_基礎情況_會直接回傳值，不再呼叫函式本身。
_遞迴情況_會再次呼叫函式，並修改輸入，讓它最終能符合基礎情況。

在 Elm 中，遞迴函式通常會透過模式比對，搭配`case`運算式或多個函式子句來定義。

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## 用遞迴實現迴圈

由於不可變性，Elm 的迴圈寫法和命令式語言不同。
舉例來說，迴圈通常長這樣：

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

在 Elm 這類函式式語言中，無法修改變數。
因此，迴圈必須用遞迴來實作。

在 Elm 中，`for`迴圈的等效寫法會像這樣：

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

在實務上，要疊代 Elm 的陣列及其他資料結構時，通常會使用`List`模組裡的函式，例如`List.map`、`List.filter`和`List.foldl`。
這些函式在底層都是用遞迴實作的。
