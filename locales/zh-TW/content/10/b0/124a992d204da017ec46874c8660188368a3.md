# 簡介

在 Go 中，字串是不可變的。
在迴圈中使用 `+` 串接字串會造成頻繁的配置，並多次複製資料。
[`strings`套件](https://pkg.go.dev/strings)提供 [`Builder`](https://pkg.go.dev/strings#Builder)，能有效率地組裝字串，將記憶體額外開銷降到最低。

## 建構字串

`strings.Builder` 的零值立即可用，不需要任何明確的初始化或配置。
你可以使用特定的寫入方法，將新資料推入 builder 中。
每個寫入方法都會回傳一個錯誤值，以符合 Go 的標準介面，但保證它一定是 `nil`，日常程式碼通常會忽略它。

最常用的方法有：

- `WriteString(s string) (int, error)`：將字串附加到緩衝區。
- `WriteRune(r rune) (int, error)`：附加一個 rune 的 UTF-8 編碼。
- `WriteByte(c byte) error`：附加單一位元組。

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## 取得與重設

當你組裝完文字後，可以呼叫 `String()` 方法，將累積的內容取出為 Go 標準字串。
呼叫 `String()` 的成本非常低，因為它會直接將底層的位元組切片以字串形式回傳，不會複製累積的資料。

如果你需要重複使用同一個 builder 執行個體來組裝新的字串（例如在迴圈中），可以呼叫 `Reset()` 方法。
這會清空內部緩衝區，讓你重新開始建立下一個字串，同時在底層保留已配置的記憶體容量。

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
