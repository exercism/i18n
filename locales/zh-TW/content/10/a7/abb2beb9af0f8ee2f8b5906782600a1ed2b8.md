# 簡介

C# 是靜態型別的語言，這表示所有東西在編譯期就已經有型別。把值指定給一個名稱，就叫做定義變數。定義變數時，可以明確寫出它的型別，也可以讓 C# 編譯器根據指定的值推斷型別（也就是_型別推斷_）。因此，下面這兩種變數定義是等價的：

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

要更新變數的值，可以透過`=`運算子。變數一旦定義之後，型別就永遠不會改變。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# 是[物件導向語言][object-oriented-programming]，而且所有函式都必須定義在_類別_裡。`class`關鍵字用來定義類別。物件（或稱_執行個體_）則是使用`new`關鍵字建立。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

類別裡的函式稱為_方法_。每個方法可以有零個或多個參數。所有參數都必須明確標示型別，參數沒有型別推斷。同樣地，回傳型別也必須明確寫出。方法是使用`return`關鍵字回傳值。若要讓其他檔案的程式碼能呼叫某個方法，就必須加上`public`存取修飾詞。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

呼叫方法時，是在執行個體上使用點（`.`）語法，寫出要呼叫的方法名稱，並為方法的每個參數傳入引數。引數可以選擇性地指定對應的參數名稱。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

在 C# 中，作用域是以`{`和`}`這兩個字元定義的。

C# 支援兩種註解。單行註解前面要加上`//`，多行註解則是寫在`/*`和`*/`之間。

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
