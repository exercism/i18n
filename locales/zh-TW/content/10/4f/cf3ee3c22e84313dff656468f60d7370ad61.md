# Case

[Case][case] 是一種控制運算式，就像 if-else 一樣（在其他語言中常被稱為 switch）。
Case 可以串接多個 if-else-if 敘述，而且在提供流程控制的同時，通常也更容易閱讀。

一個 case 是以關鍵字`case`定義，後面可選擇性地接一個運算式。
接著，每個分支都用關鍵字`when`，後面接一個運算式，該運算式會與 case 運算式比較。
`when`關鍵字不應相對於`case`關鍵字縮排。
`when`關鍵字後面，是要在 case 運算式符合 when 運算式時執行的程式碼。
Case 允許選擇性地加上`else`敘述；當沒有其他分支符合時，就會執行這個敘述。

case 運算式會先求值，再與每個`when`運算式比較。
比較時使用的是 case 相等運算子（`===`）。

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## Case 相等運算子（`===`）

Case 相等運算子（`===`）和相等運算子（`==`）有點不同。
這個運算子會檢查右邊是不是左邊所描述集合中的一員。
這表示每個運算元放置的位置是有影響的。
實際運作的方式取決於左邊的型別，例如`Range`會檢查右邊是否在範圍內，而`Object`則會檢查右邊是不是`Object`的實例。

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## 搭配多個運算式的 Case

Case 可以在單一分支中比對多個運算式，每個可能的值以逗號分隔。
只要其中任何一個運算式符合，就會執行這段程式碼。
當你希望單一分支能有多個可能的值時，這就很有用。

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## 搭配範圍的 Case

Case 也可以檢查某個值是否落在範圍內。
做法是把範圍當作 when 運算式。

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## 沒有 case 運算式的 Case

當不需要 case 運算式時，可以將它省略。
這麼做會讓每個 when 運算式改為判斷真值。
它們的行為也就會像 if-else-if 敘述一樣。

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## 單行的 when

Ruby 允許單行的 case 敘述。
當你只有簡單的單行敘述時，就可以這麼寫。
單行 when 敘述的寫法是`when <expression> then <statement>`。
而在 else 敘述中使用時，寫法則是`else <statement>`。

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## 搭配型別的 Case

Case 可以搭配型別進行比對。
當你想根據變數的型別而有不同的行為時，這就很有用。

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
