# 關於

Factor 最初由 Slava Pestov 在 2002 年設計，當時是一種實作在 JVM 上、供遊戲引擎使用的腳本語言。從那時到現在，這個平台與生態系已經走了很長一段路，語言核心本身也是如此。Factor 的標準函式庫已經變得極為龐大，而它的實作，包括具備自我代管能力的原生程式碼最佳化編譯器，現在幾乎完全是用 Factor 寫成的。

Factor 能建立獨立的應用程式，甚至是圖形介面應用程式，而且它們在 Linux、Windows 和 Mac OS 上的行為完全一致。

Factor 是一門簡單卻強大、表達力豐富的堆疊導向高階語言，風格接近 Forth、Joy 和 Lisp。它提出了一種串接式（無引數、可組合）的資料流模型，同時具備極高的擴充性，以及一套衍生自 [CLOS](https://enwp.org/Common_Lisp_Object_System) 的物件系統。

同像性是 Factor 程式設計模型中很重要的一部分。所有的值，包括函式和 Factor 程式碼區塊，都放在同一個堆疊上，並且可以用同樣的方式操作。這是一個簡單卻強大的範式，能帶來有趣的問題解法，也帶來無限的擴充可能。

Factor 要求讀者具備一種不同於 C 或 Python 的思維方式。由於它的組合式程式設計模型，每個函式的輸出會成為下一個函式的輸入。函式可以把其他函式或字面 Factor 程式碼區塊當作輸入。這樣一來，它有點像（單向的）Unix 管線，卻又更先進、更不複雜。這需要一點時間習慣，不過我們鼓勵互動式開發與重構（re-**Factor**ing），用起來也會變得相當有趣喔。

Factor 程式語言是開放原始碼的，你可以在 [GitHub](https://github.com/factor/factor) 上看到它正活躍開發中。

如果你對 Factor 還有一點陌生，強烈建議你先讀過 Factor 文件的 [Factor cookbook](https://docs.factorcode.org/content/article-cookbook.html) 和 [Your first program](https://docs.factorcode.org/content/article-first-program.html) 這兩節，再繼續往下看吧。

## Factor 術語詞彙表

* **詞** 基本上就是一個函式，它從**堆疊**取出引數，並把值回傳到**堆疊**。所有詞都必須宣告堆疊效應。Factor 語法的每個元素都是**詞**，因此定義新語法非常容易。
* **詞彙庫** 一群按目錄或原始碼檔組織起來的**詞**，就像其他語言裡的模組或函式庫。
* **堆疊** 一個後進先出、存放著動態型別值參考的陣列，所有操作都透過它進行，也是函式之間傳遞資料的主要方式。這只是實作細節；Factor 大部分也可以用項重寫來實作。
* **程式** 一系列在執行時操作**堆疊**的**詞**。這為這個語言打下強大的基礎，讓許多抽象與範式得以建立在其上。
