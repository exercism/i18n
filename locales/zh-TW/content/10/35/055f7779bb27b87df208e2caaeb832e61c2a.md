# 指示

一位博物學家正在為住在破火山口周圍的龍建立目錄。牠們彼此共享一些特徵，每條龍都有名字、顏色和年齡，但各自又有獨特的專精之處。你會建立一棵小小的龍類別繼承樹，還要寫出一個能讓任何後代變老的詞。

## 1. 龍的家族

先一口氣定義好整棵元組類別的繼承樹（它們的建構子會在後續的任務中介紹）：

- `dragon`，帶有 `name`、`color`、`age`三個槽位。
- `fire-dragon`，`dragon`的子類別，新增一個 `flame-temp`槽位。
- `ice-dragon`，`dragon`的另一個子類別，新增一個 `chill-temp`槽位。
- `volcano-dragon`，`fire-dragon`的子類別，新增一個 `lava-volume`槽位。

接著幫 `dragon`定義一個 `<dragon>`建構子。

```factor
"Falkor" "white" 100 <dragon> name>> .   ! => "Falkor"
```

## 2. 噴火的龍

幫 `fire-dragon`定義一個 `<fire-dragon>`建構子。

```factor
"Smaug" "red" 500 1200 <fire-dragon> flame-temp>> .   ! => 1200
"Smaug" "red" 500 1200 <fire-dragon> dragon? .        ! => t
```

## 3. 噴冰的龍

幫 `ice-dragon`定義一個 `<ice-dragon>`建構子。

```factor
"Frosty" "blue" 200 -40 <ice-dragon> chill-temp>> .   ! => -40
"Frosty" "blue" 200 -40 <ice-dragon> fire-dragon? .   ! => f   (siblings)
```

## 4. 火山的居民

幫 `volcano-dragon`定義一個 `<volcano-dragon>`建構子。

```factor
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> dragon? .       ! => t
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> fire-dragon? .  ! => t
```

## 5. 讓任何龍變老

定義 `age-dragon`，把任何龍（或後代）的 `age` 槽位加一。它不會回傳任何東西。

```factor
"Falkor" "white" 100 <dragon> dup age-dragon age>> .   ! => 101
```

同一個詞應該能用在每一個後代身上，這正是共用存取器的意義所在。
