# 說明

Ellen 正在做一款遊戲，玩家必須在其中對抗外星人。
她剛學會物件導向程式設計（OOP），很期待能運用 `classes` 為她的程式帶來的好處。

很高興的是，你答應要幫忙，於是她把程式設計這些玩家必須對抗的外星人的任務交給了你。


## 1. 建立 Alien 類別

定義 Alien 類別，並替它加上一個建構式，接受兩個參數`<x_coordinate>`和`<y_coordinate>`，將它們存入 `x_coordinate` 和 `y_coordinate` 這兩個實例變數。
每個外星人一開始的生命值也都是 3，所以 `health` 變數也要一併初始化。

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

現在，每個外星人都應該能在內部追蹤自己的位置和生命值。

## 2. `hit`方法

Ellen 希望 Alien `class` 有一個 `hit` 方法，呼叫時會把外星人物件的生命值減少 1。
這樣一來，她只要呼叫`<alien>.hit()`就好，不必手動更改外星人的生命值。
`hit()`要讓生命值剛好降到零還是降到零以下，由你決定。

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. `is_alive`方法

你發現，生命值要是持續下降，總有一天會降到 0（甚至更低！）。
最好加上一個 `is_alive` 方法，讓 Ellen 可以快速呼叫，確認外星人是不是……呃……還活著。😉
`<alien>.is_alive()`應該要回傳布林值。

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. `teleport`方法

在 Ellen 的遊戲裡，外星人有瞬間移動的能力！
你需要寫一個 `teleport` 方法，接受新的 `x_coordinate` 和 `y_coordinate` 值，並據此改變外星人的座標。

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. `collision_detection`方法

顯然，如果外星人會被東西擊中，牠們就得能夠偵測到這種碰撞發生。
不過，碰撞偵測演算法可能很棘手，而你還不知道該怎麼實作。
Ellen 說她之後會處理，但她還是希望 `collision_detection` 方法先出現在類別裡，提醒之後要把這個功能做出來。
它需要接受某種變數（大概是另一個物件），但你知道的真的就只有這些。
你要確保把這個方法定義放進類別後，呼叫時不會產生任何錯誤：

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. 外星人計數器

Ellen 回來找你，又有新的需求。
她想追蹤整場遊戲期間總共建立了多少個外星人。
她說這跟計分系統有關。

例如：

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. 建立外星人陣列

Ellen 很喜歡你目前做出來的成果，但她還想再請你幫個忙。
她想要一個獨立（在 `Alien()` 類別之外）的函式，它會接收一串位置（以 `tuples` 表示），並建立一個由 `Alien()` 物件組成的 `list`。

例如：

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
