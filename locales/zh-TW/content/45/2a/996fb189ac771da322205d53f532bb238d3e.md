# 指令

[阿姆斯壯數](https://en.wikipedia.org/wiki/Narcissistic_number)是一種數字，它的值等於自身每個位數的數字各自取位數次方後的總和。

例如：

- 9 是阿姆斯壯數，因為 `9 = 9^1 = 9`
- 10 *不是*阿姆斯壯數，因為 `10 != 1^2 + 0^2 = 1`
- 153 是阿姆斯壯數，因為：`153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 *不是*阿姆斯壯數，因為：`154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

寫一些程式碼來判斷某個數字是不是阿姆斯壯數。
