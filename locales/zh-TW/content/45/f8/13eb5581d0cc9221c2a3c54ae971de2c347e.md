# 測試

## 設定

請依照 [JavaScript 的設定說明][docs-exercism-javascript]，安裝必要的相依套件。

## 需求

安裝練習所需的相依套件：

```shell
corepack pnpm install
```

如果`corepack`抱怨尚未啟用，你可以執行以下指令來啟用它：

```bash
corepack enable pnpm
```

## 讓測試套件通過

每個練習都附有測試套件，幫助你在提交前驗證自己的解答。
你可以在練習的目錄中開啟命令提示字元，然後執行：

```bash
corepack pnpm test
```

有些測試套件會跳過第一個以外的所有測試。

當你讓一個測試通過後，只要把`xtest`改成`test`，就能啟用下一個測試。

## 撰寫自訂測試

如果你想撰寫額外的自訂測試，請建立一個新檔案`custom.spec.js`，並將這個新檔案連同你的解答一起提交：

```shell
exercism submit numbers.js custom.spec.js
```

[docs-exercism-javascript]: https://exercism.org/docs/tracks/javascript/installation
