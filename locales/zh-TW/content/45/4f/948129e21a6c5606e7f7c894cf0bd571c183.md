# 簡介

JavaScript 有一個內建的`Date`物件，用來儲存日期與時間，並提供管理它們的方法。

<!-- prettier-ignore -->
~~~exercism/caution
它是以 Java 的`java.util.Date`類別為基礎，這個類別在 2010 年代初就被取代了，但為了向後相容，JavaScript 的`Date`依然保留至今。

由於一般來說處理日期本就很困難，加上時區處理既糟糕又往往付之闕如，因此存在許多函式庫，例如`moment.js`、`day.js`、`date-fns`和`luxon`。
這些在 Exercism 上都無法使用。

在自己的專案裡，不要使用像`moment.js`這種已棄用或無人維護的套件，請改用更現代的替代方案，例如`luxon`，或是尚未廣泛普及的 [Temporal][mdn-temporal]。
這個練習的重點是`Date`，它在 JavaScript 終結之前都會一直很重要。

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## 建立

`Date`物件是`Date`類別的實例。
建立它時，可以不傳任何引數給建構函式。
這樣會得到一個代表目前日期與時間的`Date`物件：

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Unix 時間戳記（數字）

如果傳入的是數字，它會被解讀為`timestamp`。
時間戳記是一個整數，代表自**1970 年 1 月 1 日 [UTC][defn-utc]+0**以來所經過的**毫秒**數。

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

你可能會以為`new Date(0)`會產生「最早」的日期物件，但 JavaScript 會把日期轉換成你所在的時區，這表示只有身處 [GMT／UTC+0][defn-gmt] 時區附近的人，才會真正得到 [Unix 紀元][defn-unix-epoch]的值。

### ISO 8601 時間戳記（字串）

你可以把代表日期的字串值傳給`Date`建構函式。
在各式實作之間**唯一**一致的格式，是國際公認且標準化的所謂 [ISO 8601 時間戳記字串][defn-iso8601]的[簡化版本][mdn-date-string-format]。

位於 [UTC][defn-gmt] 的某個時間點看起來像這樣：

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

其中各欄位對應的內容如下：

| 鍵   | 說明                                          | 預設值  |
| ---- | --------------------------------------------- | ------- |
| YYYY | 日曆年份，以 4 位數表示                       |         |
| MM   | 日曆月份，以 2 位數表示                       | 01      |
| DD   | 日曆日，以 2 位數表示                         | 01      |
| T    | 字面上的字母 T，用來分隔日期與時間            |         |
| HH   | 24 小時制的小時，2 位數                       | 00      |
| mm   | 分鐘，2 位數                                  | 00      |
| ss   | 秒，2 位數                                    | 00      |
| mss  | 毫秒，3 位數                                  | 000     |
| Z    | 字面上的字母 Z，或是位移量`+/-HH:mm`          |         |

字面上的字母`Z`代表 UTC（沒有時區，也沒有日光節約時間）。

由於大多數組成部分都有預設值，所以把結尾的部分省略是合法的：

```text
YYYY-MM-DD
```

預設時間為 00:00:00.000

如果時間戳記結尾不是`Z`，也沒有以`+HH:mm`或`-HH:mm`結尾（表示時區位移量），那麼基於歷史因素，以下規則適用：

> 當未提供時區位移量時，只有日期的形式會被解讀為 UTC 時間，而日期加時間的形式會被解讀為本地時間。
> 會被解讀為 UTC 時間，是因為一個歷史上的規格錯誤，它與 ISO 8601 不一致，卻因為網頁相容性而無法更改。
> 參見 [Broken Parser：一個網頁相容性的現實問題][ref-broken-parser]。

### 日期物件

既有的日期物件也可以當作建構函式的引數傳入。
這會複製既有的`Date`物件，得到日期與時間都相同的一份。

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### 分別提供日期與時間的各個組成值

傳入三個數字，即可建立代表日期的日期物件。
傳入 6 個數字，即可建立代表日期與時間的日期物件。

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

第二個值是`month`，一月從`0`開始，一直到十二月的`11`。

## `Date.parse()`

你可能會看到有人提到或引用日期解析函式`Date.parse`。
由於這個函式只有少數不變量（必然成立的事），其餘的實作並未規範（因此不標準），所以不應該使用它。

## 存取`Date`的組成部分

日期物件上有各種方法會回傳日期的組成部分：

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

這些方法各自都有對應的`set`版本（例如`setFullYear`），可以用來更新值。
任何溢出的值都會進位到下一個組成部分：

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

所有方法都有 UTC 版本，會忽略本地時區。

## 從日期轉換

日期物件有一個方法`getTime()`，會回傳以毫秒為單位的 UNIX 時間戳記，也就是自 1970 年 1 月 1 日 UTC 午夜起算的毫秒數。
此外，還有`toISOString()`方法，可以把日期物件轉換成 ISO 8601 時間戳記字串。

## 比較日期

大於（`>`）、大於等於（`>=`）以及小於（`<`）與小於等於（`<=`），都可以直接用在兩個日期之間，或日期與數字之間。
這之所以可行，是因為 JavaScript 會嘗試把日期強制轉型成原始型別。

<!-- prettier-ignore -->
~~~exercism/advanced
在兩個日期之間，或日期與數字之間進行比較時，JavaScript 會呼叫 [`[Symbol.toPrimitive]("number")`][mdn-to-primitive]，它在內部會呼叫 [`date.valueOf()`][mdn-date-value-of]。
後者等同於呼叫 [`date.getTime()`][mdn-date-get-time]。

如果你不想依賴這個行為，請先用`getTime()`轉成數字。

[mdn-to-primitive]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/Symbol.toPrimitive
[mdn-date-value-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf
[mdn-date-get-time]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime
~~~

日期不能用相等性（`==`和`===`）來比較，但`.getTime()`的結果可以。
