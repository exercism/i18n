# 簡介

## 套件

在 Go 中，應用程式是以套件來組織的。
套件是位於同一個資料夾中的原始碼檔案集合。
同一個資料夾中的所有原始碼檔案，開頭都必須有相同的套件名稱。
依照慣例，套件名稱會與它所在的資料夾相同。

```go
package greeting
```

Go 提供了內容豐富的標準函式庫套件，你可以使用`import`關鍵字在程式中使用它們。
標準函式庫套件是以其名稱匯入的。

```go
package greeting

import "fmt"
```

匯入套件之後，就可以用套件名稱來取用：

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go 透過宣告的方式來決定其他套件中的程式碼是否能呼叫某個項目。
若要讓函式、型別、變數、常數或結構欄位能從外部看見（稱為 _匯出_），名稱就必須以大寫字母開頭。

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## 字串格式化

Go 提供了一個內建套件`fmt`（格式化套件），它提供各種函式來處理輸入與輸出的格式。
最常用的函式是`Sprintf`，它使用像`%s`這樣的動詞將值內插到字串中，並回傳該字串。

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

在 Go 中，浮點數可以很方便地用 Sprintf 的動詞來格式化：`%g`（精簡表示法）、`%e`（指數）或`%f`（非指數）。
這三種動詞都可以控制欄位寬度與數值位置。

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

你可以在[格式化套件文件][fmt-docs]中找到完整的可用動詞清單。

`fmt`還包含其他處理字串的函式，例如`Println`會直接將接收到的引數印到主控台，而`Printf`則會先以與`Sprintf`相同的方式格式化輸入，再將它印出。

[fmt-docs]: https://pkg.go.dev/fmt
