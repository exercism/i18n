# 指令

在這個練習中，你會處理日誌行。

每一行日誌都是格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

日誌等級共有三種：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會拿到一行日誌，請你對它做些處理。

## 1. 從日誌行取得訊息

實作`message`函式，回傳日誌行的訊息：

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

開頭或結尾的空白都應該移除：

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. 從日誌行取得日誌等級

實作`log-level`函式，回傳日誌行的日誌等級，並以小寫回傳：

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. 重新格式化日誌行

實作`reformat`函式，重新格式化日誌行，把訊息放在前面，日誌等級則放在後面並加上括號：

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
