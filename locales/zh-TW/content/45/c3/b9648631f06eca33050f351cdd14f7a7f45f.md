# 指令

給定兩個陣列，判斷第一個陣列是否包含於第二個陣列中、第二個陣列是否包含於第一個陣列中、兩個陣列是否互相包含，或是以上皆非。

具體來說，如果從 B 的開頭移除 0 個或多個元素，並從 B 的結尾移除 0 個或多個元素後，得到的陣列與 A 完全相同，那麼陣列 A 就是陣列 B 的子陣列。

範例：

* A = [1, 2, 3]，B = [1, 2, 3, 4, 5]，A 是 B 的子陣列
* A = [3, 4, 5]，B = [1, 2, 3, 4, 5]，A 是 B 的子陣列
* A = [3, 4]，B = [1, 2, 3, 4, 5]，A 是 B 的子陣列
* A = [1, 2, 3]，B = [1, 2, 3]，A 等於 B
* A = [1, 2, 3, 4, 5]，B = [2, 3, 4]，A 是 B 的超陣列
* A = [1, 2, 4]，B = [1, 2, 3, 4, 5]，A 既不是 B 的超陣列，也不是 B 的子陣列，也不等於 B
