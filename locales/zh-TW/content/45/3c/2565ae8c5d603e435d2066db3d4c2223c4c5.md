# 提示

## 通則

你試過把邏輯拆成一個或多個輔助函式嗎？
這類歌曲稱為[累積歌曲][cumulative song]，所以特別適合「拆解」。
這麼做可以讓你的程式碼更容易理解，也更符合[單一職責原則][Single Responsibility Principle]。

## 做法

### 迴圈

想了解 Python 中有哪些迴圈寫法，請參閱[迴圈](https://exercism.org/tracks/python/concepts/loops)。

### 遞迴

想了解如何在 Python 中使用遞迴，可以從[Python 程式設計：遞迴][python-programming: recursion]、[Real Python：Python 遞迴][Real Python: python-recursion]或[Real Python：用遞迴思考][Real Python: python-thinking-recursively]開始。
