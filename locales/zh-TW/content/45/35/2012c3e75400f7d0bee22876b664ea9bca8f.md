# 型別宣告

PHP 是一種_動態型別_的語言，意思是變數可以包含任何型別的資訊。
PHP 允許對類別屬性、函式引數和函式回傳值進行_選擇性的_強型別宣告。
PHP 的強型別宣告會在執行階段提供型別斷言，不過，PHP 會盡可能嘗試將純量型別強制轉換成符合宣告的型別。
這個強制轉換行為可以透過在檔案最上方宣告`strict_types`來停用。

```php
<?php
declare(strict_types=1);
```

此外，函式也可以將回傳型別宣告為`void`，表示這個函式不會回傳任何值。

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## 聯合型別

如果函式引數、回傳值或類別屬性可以有多種型別，就可以宣告聯合型別。

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## 混合型別

在撰寫程式碼時，我們有時無法指定型別。
從 PHP 8.0 開始，提供了一個名為`mixed`的逃生型別。
`mixed`等同於`object|resource|array|string|float|int|bool|null`的聯合型別。
