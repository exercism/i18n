# 關於

在 Elixir 中，若要從可列舉的資料結構（例如陣列、範圍）中隨機挑選一個元素，我們會使用 [`Enum.random/1`][enum-random]。這個函式會挑出單一元素，而且每個元素被挑中的機率都相同。從範圍中隨機挑選單一值時，會以常數時間完成，不需要走訪整個範圍。

## 隨機整數與字母

- 隨機挑選一個整數
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- 隨機挑選一個字母，以字串表示
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- 隨機挑選一個字母，以 charlist 表示
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

若要從可列舉的資料結構中挑選多個元素，請使用 [`Enum.take_random/2`][enum-take-random]。若要將可列舉的資料結構以隨機順序排序，請使用 [`Enum.shuffle/1`][enum-shuffle]。

## 隨機浮點數

Elixir 本身沒有用來挑選隨機浮點數的函式。要做到這件事，我們得使用 Erlang 的 [`rand`][erl-rand] 模組，而 `Enum.random` 在底層用的也正是它。

- 隨機挑選一個浮點數（大於或等於 0.0 且小於 1.0）：

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- 隨機挑選一個浮點數（大於或等於`a`且小於`b`）：
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## 常態分布

上述所有函式在挑選隨機值時，每個可能的值被挑中的機率都相同。這就叫做*均勻分布*。`rand` 模組也提供 [`normal/0`][erl-rand-normal-0] 與 [`normal/2`][erl-rand-normal-2] 兩個函式，能挑選出符合[常態分布][normal-distribution]的隨機浮點數。

## 種子

重要的是要了解，這些「隨機」值其實是由*偽*隨機數字生成器所產生。PRNG 是一種演算法，給定一個稱為*種子*的初始值之後，就會產生一串看起來隨機、但其實一點也不隨機的數字。

這一點在除錯時可能很有用。你可以用 [`:rand.seed/2`][rand-seed-2] 重設種子，強制 Erlang（連帶 Elixir）的偽隨機數字生成器產生相同的數列。第一個引數是特定的 PRNG 演算法，第二個則是內含三個整數的元組，也就是種子。

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## 密碼學

`Enum.random` 和 Erlang 的 `rand` 模組所回傳的隨機值並非[密碼學上安全][cryptographically-secure-rng]。請不要用它們來產生密碼學金鑰、密碼或 nonce。這種用途請改用 Erlang 的 [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes]。
