# 測試

Factor 軌道使用**Factor 0.101**。每個練習都隨附一套`exercism-tools`詞彙庫，其中定義了`STOP-HERE`與`TASK:`這兩個解析用詞，以及一個測試執行器。在練習的目錄下執行：

```
factor -roots=. -run=exercism-tools <exercise>
```

例如，以`hello-world`練習為例：

```
factor -roots=. -run=exercism-tools hello-world
```

所有測試都通過時，執行器會以狀態 0 結束；只要有任何測試失敗，就會以非零狀態結束，並輸出診斷訊息。

## 略過的測試

解一道練習，就是讓它的所有測試都通過。
執行測試時，預設只會執行一個測試（第一個）。
這是刻意的設計，讓你專心先讓那一個測試通過。

這個機制靠的是測試檔裡的`STOP-HERE`這一行：在解析時，它會告訴 Factor 忽略它底下的所有內容，所以執行器只會看到它上面的測試。第一個測試通過之後，你有兩種方式可以啟用更多測試：

- **刪除`STOP-HERE`這一行**，一次啟用所有剩下的測試。
- **把`STOP-HERE`這一行往下移**，一次啟用一個測試，或一次啟用一個任務。

概念練習會把測試分組放在`TASK:`標記底下，所以把`STOP-HERE`移到下一個`TASK:`之前，是很自然的做法。

當所有測試都已啟用，而你的實作也讓它們全部通過時，你就解出這道練習了喔！
