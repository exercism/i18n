# 說明

身為準魔術師，Elyse 需要練習一些基本功。她有一疊卡片，想要加以操作。

為了方便一些，她只用 1 到 10 的卡片。

## 1. 建立含有特定卡片的切片

練習卡片時，Elyse 喜歡從整副牌中最喜歡的三張開始：2、6 和 9。請寫一個函式`FavoriteCards`，回傳一個依序包含這三張卡片的切片。

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. 從牌堆中取出一張卡片

從給定的牌堆中回傳位置`index`的卡片。

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

如果索引超出範圍（也就是負數，或是超出牌堆末端），我們想回傳`-1`：

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
在 Go 的慣例中，會回傳錯誤，而不是回傳「超出範圍」的值。這裡當預期是正整數時，「超出範圍」的值是`-1`。回傳錯誤時，通常會一併回傳 [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) 與錯誤。如何回傳錯誤並附上正確的回傳值，會在之後的練習中介紹。
~~~~

## 3. 替換牌堆中的一張卡片

將位置`index`的卡片替換成提供的新卡片，並回傳調整後的牌堆。請注意，這會修改傳入的切片，而這是預期的行為。

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

如果索引超出範圍（也就是負數，或是超出牌堆末端），我們想把新卡片加到牌堆末端：

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. 在牌堆頂端加入卡片

將`value`參數指定的卡片加到牌堆頂端。

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

如果沒有給`value`參數任何引數，結果就會等於原始的切片。

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. 從牌堆中移除一張卡片

從牌堆中移除位置`index`的卡片，並回傳牌堆。請注意，這可能會修改傳入的切片，這沒有問題。

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

如果索引超出範圍（也就是負數，或是超出牌堆末端），我們想讓牌堆保持不變：

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
