你被指派要撰寫一個服務，這個服務會接收事件。每個事件都有一個對應的日期，但你注意到有 3 種不同的格式被送到你服務的端點：

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

你可以看出它們之間有一些相似之處，於是決定撰寫一些可組合的正規表達式模式。

## 1. 從日期中比對出日、月和年

實作`day`、`month`和`year`，讓它們回傳一個字串模式；這個模式在執行時，會比對`"01/01/1970"`（`dd/mm/yyyy`）中的數字元件。日和月可能以`1`或`01`的形式出現（左側補零）。

不用擔心錯誤檢查。你可以假設傳進來的永遠是有效的數字元件。

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. 比對出一週中的星期名稱和一年中的月份名稱

實作`day-name`和`month-name`，讓它們分別回傳一個字串模式；這個模式在執行時，會比對任何具名的星期名稱，以及具名的月份名稱。

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. 擷取日、月和年

實作`capture-day`、`capture-month`、`capture-year`、`capture-day-name`、`capture-month-name`，讓它們回傳一個映射，把各元件對應到名稱：`"day"`、`"month"`、`"year"`、`"day-name"`、`"month-name"`。

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. 組合這些擷取結果，擷取完整的日期

實作`capture-numeric-date`、`capture-month-name-date`和`capture-day-month-name-date`，讓它們使用各自的日期格式，回傳一個包含第 3 部分各元件的映射。

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
