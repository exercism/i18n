# 簡介

F# 中的`list`是零個或多個值組成的不可變集合。陣列中的值必須全部具有相同的型別。由於陣列不可變，一旦建立之後，它的值就永遠不會改變。任何看起來會修改陣列的函式或運算子（例如新增元素），實際上都會回傳一個新的陣列。

陣列可以這樣定義：

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

要把元素加入陣列，最常見的方式是使用`::`（cons）運算子：

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

F# 的陣列有_頭部_（第一個元素）和_尾端_（第一個元素之後的所有元素）。陣列的尾端本身也是一個陣列。

操作陣列的方式有兩種：使用`List`模組中定義的函式與運算子，或是手動使用 _list_ 和 _cons_ 模式來做模式比對：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

在模式比對時，你也可以_捨棄_某個值；當你在某個情況中_不_在意某個值（也就是你不打算_使用_它）時，可以用底線（`'_'`）來表示：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

在模式比對時，單一的`'_'`一定要放在_最後_，任何_不_符合其他情況的值都會由這個情況處理。
