# 測試

## 執行測試

當你位於某個練習的目錄中時，應該會看到兩個子目錄：

* `Sources/<Exercise>`包含你對這個練習的解答
* `Tests/<Exercise>Tests`包含要為這個練習執行的測試

如果你在正確的目錄中（也就是包含 `Sources` 和 `Tests` 的那個目錄），就可以用 `swift test` 來執行該練習的測試：

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

當一個測試通過後，請在 `@Test` 敘述中移除 `.enabled(if: RUNALL)`，好啟用下一個測試；或者你也可以在 Linux 或 macOS 上把 `RUNALL` 環境變數設為 `true`，一次執行所有測試：

```bash
$ export RUNALL=true
```

或者，如果你在 Windows 上使用 PowerShell：

```powershell
set RUNALL=true
```

## 提交你的解答

要將解答上傳到 Exercism，你必須位於包含 `Sources` 和 `Tests` 目錄的那個目錄中。

```bash
$ exercism submit 
```
