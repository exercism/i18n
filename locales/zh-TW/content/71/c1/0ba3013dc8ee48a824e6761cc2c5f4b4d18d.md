# 同步到 GitHub

嗨，大家好！

過去幾個月，我們一直努力投入 [Coding Fundamentals](https://exercism.org/courses/coding-fundamentals) 和 [Front-End Fundamentals Bootcamp](https://exercism.org/courses/front-end-fundamentals) 這兩門課程，這段經歷對我們來說非常棒。現在它們都完成了，所以我們花了一些時間，為 Exercism 主站加入一些新功能！

今天，我們要在 Exercism 上推出**2 項新功能**：
1. 將你的解法同步到 GitHub。
2. 儲存並探索你的收藏。

## 將你的解法同步到 GitHub

擁有自己公開的解法備份，是大家長久以來一直要求的功能。
很多人手動把解法同步到 GitHub，甚至自己寫腳本處理，但現在這個功能已經**內建在 Exercism 裡**了！

一旦啟用這項功能，你的解法就會自動備份到 GitHub。你可以設定備份要透過 Pull Request 還是 commit 進行，還能把你所有的解法一次大量上傳！

一個月前，我們悄悄地向 Insiders 推出這項功能，現在已經有數萬筆解法備份到 GitHub 了。用過的人越多，大家就越喜歡它。有位 Insider 這麼說：

> 這個功能剛被提出來的時候，我並沒有特別的感覺，但現在它真的上線了，我很高興你們選擇把它做出來！我已經無法想像沒有它的 Exercism 了。
> 
> \- W8CYE 於 Discord

想開始使用的話，只要前往新的 [GitHub 同步器設定頁面](https://exercism.org/settings/github_syncer)，連接一個 repo 就行了！

## 收藏

今天我們也要推出 [Exercism 收藏](https://exercism.org/favorites)，讓你儲存和瀏覽自己在 Exercism 上找到的最佳解法。

收藏的設計，是為了讓你蒐集所有覺得有趣、深受啟發或令人驚豔的內容。你可以在瀏覽網站時替解法加星號，之後想深入研究時，隨時回來重看它們。

要新增收藏，只要在任何一個社群解法上點擊「Favorite」按鈕。你會看到文字變成「Favorited」，星星也會變成金色！
如果想移除收藏，再點一次就可以了。

<img src="https://assets.exercism.org/images/community/favorites-button.png" alt="社群解法頁面的螢幕截圖，畫面中顯示 Favorite 按鈕" style="width:100%; max-width:600px;" width="2182" height="980" />

你先前已經加過星號的解法，都已經自動移轉到你的收藏裡了。你可以透過 Learn 選單進入收藏，或直接點[這個連結](https://exercism.org/favorites)。
