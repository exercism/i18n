# 指令

在這道練習中，你將實作一款角色扮演遊戲的機制。
玩家的角色會以下列的型別表示：

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

遊戲中的玩家必須達到等級 10，才能解鎖魔力池，進而開始施展法術。
你在這款遊戲中要處理兩項功能：復活機制和施法機制。

## 1. 自我介紹

撰寫`introduce`函式的內容。
潛行的玩家可能會隱藏自己的名字，這時會以 `"Mighty Magician"` 來介紹自己。
否則，就用你自己的名字來介紹自己。

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. 實作復活機制

`revive`函式應該檢查玩家的角色是否確實已經死亡（生命值降到 0）。
如果確實死亡，就回傳一個生命值為 100 的新`Player`實例。
否則，如果玩家的角色還沒死亡，`revive`函式會回傳`Nothing`。

如果玩家的等級是 10 以上，復活時也應該一併回復 100 魔力。
如果玩家的等級低於 10，他們的魔力應該是`Nothing`。
`revive`函式應該保留玩家的等級。

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

如果在生命值為 1 以上的玩家身上呼叫`revive`方法，這個函式應該回傳`Nothing`。

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. 實作施法機制

`castSpell`函式會接受兩個引數：一個`Int`，表示法術消耗多少魔力，以及一個`Player`。
它會回傳更新後的玩家，以及這個法術造成的傷害量。
成功施展的法術會造成等同於該法術魔力消耗兩倍的傷害。
不過，如果玩家的魔力不足，什麼都不會發生，玩家維持不變，也不會造成任何傷害。
如果玩家甚至連魔力池都沒有，嘗試施展法術時必須讓玩家的生命值減少等同於該法術魔力消耗的量，而且不會造成任何傷害。

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
