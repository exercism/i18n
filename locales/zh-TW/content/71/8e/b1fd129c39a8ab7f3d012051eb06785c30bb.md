# 說明

你的社區協會請你實作一個簡單的登記應用程式，用來管理社區花園的登記作業。我們已經為你提供了`Plot`結構。

## 1. 開啟花園

實作`CommunityGarden.start/1`函式，它會接收一個選用的選項關鍵字清單，並將這些選項傳遞給 _agent 行程_。花園的初始狀態應初始化為代表一個空的花圃集合。它應回傳一個帶有花園 pid 的`:ok`元組。

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. 列出登記資料

實作`CommunityGarden.list_registrations/1`函式。它會接收社區花園的`pid`。它應回傳一份清單，列出已登記的花圃。

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> 到目前為止，我們還沒加入登記花圃的功能，所以這個清單應該是空的

## 3. 將花圃登記給某人

實作`CommunityGarden.register/2`函式。它會接收社區花園的`pid`以及要登記花圃的名字。成功時，它應回傳帶有花圃 id 與登記對象的`Plot`結構。

這些 id 應遞增且唯一。你可以在 agent 的狀態中保留一個 id 計數器。

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. 釋出花圃

實作`CommunityGarden.release/2`函式。它會接收要釋出花圃的`pid`與`id`。成功時它應回傳`:ok`。花圃釋出後，該 id 不會被重複使用，只會用來當作唯一識別碼。

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. 取得已登記的花圃

實作`CommunityGarden.get_registration/2`函式。它會接收要檢查花圃的`pid`與`id`。如果該花圃已登記，它應回傳該花圃；若未登記，則回傳`:not_found`。

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
