# 簡介

Gleam 中的字串是不可變的文字，前後以一對雙引號包住。字串支援 unicode 字元，也可以跨越多行。

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

字串可以使用 `<>` 運算子串接起來：

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

標準函式庫中的 [`gleam/string`][stdlib] 模組提供了處理字串的函式。

字串可以在 `case` 運算式中比對：

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

如果你想比對字串的開頭，並把剩下的部分指定給變數，可以使用 `<>` 運算子的模式：

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
