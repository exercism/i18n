# 簡介

_「日期和時間是我們教小孩子的东西，能有多難？」_

許多程式設計師都犯過這個錯誤，而隨之而來的經歷往往對他們的身心健康造成很不好的影響。

任何要用日期和時間做不算簡單的程式設計的人，至少都該準備好理解並減輕潛在的問題。

本文件會試著概述 Julia 如何處理日期和時間，但若想了解更進一步的細節，還是得查閱[手冊][Dates]。
另外還有一本 [Wikibook][Wikibook]，有些讀者可能會覺得它的說明更清楚，裡頭還有一張很有幫助的[圖][type-hierarchy]，說明型別階層。

## `Dates`模組

大部分基本功能都在`Dates`裡，這個模組隨預設安裝一起提供，但不屬於標準函式庫。

要使用這個模組，有兩種做法：

1. 加上`import Dates`，然後在所有函式呼叫前面加上`Dates.`
2. 加上`using Dates`，把整個模組帶進目前的命名空間（_除了少數有問題的名稱_）。

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

`Dates`模組既龐大又複雜，但它提供四大類功能：

- `Dates.Date`，包含日、月、年，但不含時刻。
- `Dates.Time`，包含時刻，但不含日期。
- `Dates.DateTime`，結合日期與時間。
- `Dates.Period`，處理時間或日期的間隔。

請注意，`DateTime`一般_不_包含時區資訊（Python 會稱之為「naive」日期時間）。
有個例外是`now()`，它會從你的系統時鐘取得本地時間，必要時還能轉換成 UTC。

最常見的需求大概有：

- 解析某種適當的輸入格式，以建構`Dates`型別。
- 從`Dates`型別取得所需的數字或字串格式。
- 對`Date`、`Time`或`DateTime`值套用偏移。
- 計算兩個這類值之間的間隔。
- 取得目前的日期（用`today()`）和／或時間（用`now()`）。

~~~~exercism/note
為了減少視覺上的干擾，本文件後續大部分的範例程式碼都假設已經`using Dates`，並避免在函式呼叫中加上模組名稱`Dates.`。
~~~~

### 日期與時間格式

日期和時間有許多種寫法，而且往往因文化而異。
「7/6/23」這種全數字日期既含糊又令人困惑，還曾在跨國組織裡造成許多代價高昂的錯誤（_作者說這句話，是因為有過慘痛的親身經歷_）。

國際標準定義在`ISO 8601`中，主要有兩大好處：

- 解析起來快速又明確。
- 排序很簡單，因為日期時間可以當成一般文字，依字母順序排序。

前面的範例裡，我們看到`Date.now()`回傳了`2025-06-21T16:03:04.161`。

這個格式由幾個部分組成：

- 日期部分是`YYYY-MM-DD`。
- 時間部分是`hh:mm:ss`。
- 小數點後可選擇加上毫秒（或更小的單位）。

其他字串格式會在後面的章節討論。

## 日期

`Dates.Date`是相對單純、只含日期的型別，不處理時間或時區。

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

有一些存取函式可以取得日期的各個部分，這些函式成對出現，以大小寫區分。

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### 查詢函式

有各式各樣的函式對日曆有些概念。
下一個範例只展示了其中幾個。

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## 時間

`Dates.Time`是基本的、只含時間的型別。
它不處理日期：時間到了午夜會自動繞回`Time(0, 0, 0)`。

完整的建構子格式是`Time(hour, min, sec, millisec, microsec)`，或對應的 ISO 8601 寫法。

所有參數都是選用的，預設為`0`。

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

和`Date`一樣，各個部分都可以用存取函式取得：

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## 日期時間

`Dates.DateTime`結合了`Date`和`Time`型別的大部分特性。

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

年、月、日參數預設為`1`，時間參數則全部預設為`0`。

要記清楚這些參數並不容易，所以輸入時用 ISO 格式可能會比較方便。

或者，也可以像上面的範例那樣，用一個`Date`和一個`Time`建構出`DateTime`。

## 期間

日期時間的每個組成部分都各有自己的`Period`型別，從`Year`一路到`Nanosecond`，用來表示一段時間間隔。
這些型別在做運算時特別好用。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

處理`Period`型別時，Julia 會試著聰明地應付月長這類日曆上的不規則，必要時進行捨入。

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## 字串表示法

我們前面提過 ISO 8601 標準，它是 Julia 在格式化或解析字串時預設的日期時間表示法。

當然，還有許多其他格式經常被使用，而且往往因文化而異。
為了處理這些格式，Julia 提供了`DateFormat`型別，可以用任意複雜度的格式字串建構出來。

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

上面的範例很簡單，只是一個歐洲常見的日／月／年格式日期。
這裡展示了兩種語法變化，但結果完全相同。

接著就能用`DateFormat`來解析任何合適的字串：

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

建立`DateFormat`有不小的額外負擔，所以只做一次這個步驟（就像這裡的`dtfmt`），在迴圈處理大量日期時間字串時對效能很有幫助。

格式可以比這複雜得多，詳情請參閱[手冊][dateformat]。

同一個`DateFormat`也可以用來把日期時間輸出成任何想要的字串格式，只要使用[`Dates.format()`][format]函式。

可惜`format`似乎有命名空間衝突（至少在 Julia 1.11.5 中是如此），所以即使已經`using Dates`，最好還是保留`Dates.`這個前綴。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

如同[文件][wiki-format]所述，`"e, u d"`會給出星期幾和月份的縮寫文字表示法。

文字表示法預設為英文。
也可以加入其他語言，不過目前這方面的支援還不太理想。
