# 提示

## 一般

- `<dlist>`在[`dlists`][dlists]裡；push/pop 這類詞彙則在[`deques`][deques]中。
- `MEMO:`在[`memoize`][memoize]裡。
- 區域變數（`::` 和 `:>`）能讓 BFS 的主體保持易讀；述詞看到的區域變數與主體相同。

## 1. 排空潮水佇列

- 先從`<dlist>`開始，用`[ push-back ] each`填入內容，接著以`until`迴圈（述詞為`[ deque-empty? ]`）排空它：將前端 pop 出來放進`V{ } clone`，最後再用`>array`轉成陣列。

## 2. 可抵達的海灣

- 模式如下：用`HS{ } clone`當作`visited`，用`<dlist>`當作`frontier`，把`start`標記為已造訪並推入`frontier`，然後持續迴圈直到`frontier`為空：pop 出前端，用`at`在圖表中查出它的鄰居，對每個還沒見過的鄰居，併入`visited`並 push-back 到`frontier`上。

## 3. 跳躍次數

- 做法和第 2 題相同，但佇列改為攜帶`{ cove distance }`配對。當你 pop 出的配對中，海灣等於目標時，就把距離記錄為答案並停止。使用可變的區域變數（`f :> answer!`），並以`frontier deque-empty? answer or`作為`until`迴圈結束的條件。

## 4. 黃金數量

- 只要一行宣告：`MEMO: gold-count ( cove -- n ) gold-distribution at 0 or ;`。`MEMO:`取代了開頭的`:`；其餘都是普通的詞彙定義。當鍵不存在時，`at`會回傳`f`；`0 or`則會以零代替。

## 5. 寶藏路線

- `coves-reachable`會回傳一個雜湊集合；`members`（在`sets`裡）會把它變成序列。用`[ [ gold-count ] keep 2array ] map`建立由`{ gold cove }`配對組成的陣列，接著`sort`這個陣列（它會依配對的第一個元素排序），再用`last second`取出黃金最多的那組配對中的海灣。
