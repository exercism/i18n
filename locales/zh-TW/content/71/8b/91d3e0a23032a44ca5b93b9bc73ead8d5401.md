# 說明

在這個練習中，你將管理一套庫存系統。

庫存應按物品名稱來組織，並追蹤可用物品的數量。

你需要處理將物品新增到庫存。每當某個物品出現在指定的陣列中，該物品在庫存中的數量就應該增加`1`。你還需要處理從庫存刪除物品，在被要求時將數量減少`1`。

最後，你需要實作一個函式，將指定庫存中的所有鍵值對以`tuples`組成的`list`回傳。

## 1. 根據陣列建立庫存

實作 `create_inventory(<input list>)` 函式，它會根據輸入的物品陣列建立一份「庫存」。它應該回傳一個`dict`，其中包含每個物品名稱及其對應的數量。

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. 將陣列中的物品新增到現有的字典

實作 `add_items(<inventory dict>, <item list>)` 函式，它會將一批物品新增到傳入的庫存中：

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. 從庫存中減少物品數量

實作 `decrement_items(<inventory dict>, <items list>)` 函式，它接收一個由物品組成的`list`。每當某個物品在該`list`中出現一次，你的函式就應該將該物品的計數減去`1`：

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

庫存中的物品計數不應低於 0。如果某個物品在輸入`list`中出現的次數超過可用的計數，該物品所列的數量應維持在 0。一旦計數降為 0，後續移除計數的要求就應被忽略。

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. 從庫存中完全移除某個項目

實作 `remove_item(<inventory dict>, <item>)` 函式，它會從庫存中完全移除某個物品及其計數：

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

如果在庫存中找不到該物品，函式應回傳原本的庫存，內容不變。

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. 回傳庫存的完整內容

實作 `list_inventory(<inventory dict>)` 函式，它接收一份庫存，並回傳由`(item, quantity)`元組組成的陣列。該陣列應只包含_可用_的物品（_數量高於 0_）：

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
