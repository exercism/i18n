# 簡介

## 基礎

Java 是靜態型別的語言，這代表變數的型別在編譯期就已經確定。
把值指定給一個名稱，就稱為定義變數。
定義變數時，必須明確指定它的型別。

```java
int explicitVar = 10;
```

更新變數的值是透過`=`運算子來完成。
在這裡，`=`並不代表數學上的相等。
它只是把值指定給變數而已。
變數一旦定義之後，型別就永遠不會改變。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java 是一種[物件導向語言][object-oriented-programming]，而且所有函式都必須定義在一個_類別_中。
`class`關鍵字就是用來定義類別。

```java
class Calculator {
    // ...
}
```

類別內的函式稱為_方法_。
每個方法可以有零個或多個參數。
所有參數都必須明確標註型別，參數沒有型別推斷。
同樣地，回傳型別也必須明確標示。
方法使用`return`關鍵字回傳值。
若要讓其他類別能呼叫某個方法，就必須加上 `public` 存取修飾子。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

呼叫方法時，需要指定它的類別與方法名稱，並為方法的每個參數傳入引數。

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Java 中的作用域定義在`{`與`}`字元之間。

Java 支援兩種註解。
單行註解以`//`開頭，多行註解則放在`/*`與`*/`之間。

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
