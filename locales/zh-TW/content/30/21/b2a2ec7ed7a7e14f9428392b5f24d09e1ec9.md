# 指令

在這個練習中，你會寫一些程式碼，幫助你依照最愛的食譜做出一道美味的千層麵。

這個練習有三個任務，全都和烹調千層麵所花的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義`expectedMinutesInOven`這個值，用來檢查千層麵應該在烤箱裡烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```
> expectedMinutesInOven
  ⧩
  40
```

## 2. 計算準備時間（分鐘）

定義`preparationTimeInMinutes`函式，它接受你加在千層麵裡的層數作為參數，並回傳你準備千層麵花了幾分鐘。假設每一層需要花 2 分鐘準備。

```
> preparationTimeInMinutes 3
  ⧩
  6
```

## 3. 計算經過的時間（分鐘）

定義`elapsedTimeInMinutes`函式，它接受兩個參數：第一個參數是你加在千層麵裡的層數，第二個參數是千層麵已經在烤箱裡待了幾分鐘。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間（分鐘）加上千層麵當下已經在烤箱裡待的時間（分鐘）。

```
> elapsedTimeInMinutes 3 20
  ⧩
  26
```
