# 簡介

在 Clojure 中，把值繫結到名稱的做法稱為 _var_。頂層（全域）var 類似其他語言裡的常數，但通常會被重新定義，以利於動態開發。

頂層 var 使用 `def` 定義：

```clojure
(def fingers 10)
```

`defn` 巨集可以用來定義接受零個或多個引數的函式。函式一律會回傳其主體中最後一個運算式的結果。

```clojure
(defn add [x y]
  (+ x y))
```

要呼叫一個函式，需要指定它的名稱，並為函式的每個參數傳入引數。

```clojure
(def five (add 2 3))
```

在 Clojure 中，函式和值都必須先定義才能使用。在定義之前就使用，會導致編譯錯誤。

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

在 Clojure 中，空白除了排版之外沒有任何意義。

Clojure 的函式和 var 是以命名空間來組織的。命名空間會把相關的功能群組在一起，並使用 `ns` 巨集定義：

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure 支援兩種註解。單行註解以 `;` 開頭，而 `comment` 形式則用來避免求值 `(comment` 與 `)` 之間的所有內容。
