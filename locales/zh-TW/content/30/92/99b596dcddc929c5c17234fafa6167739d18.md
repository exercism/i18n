# 說明

在這個練習中，你要為紐約一間於 2012 年 9 月 15 日開幕的美容沙龍製作預約排程系統。

這五個任務都會牽涉到預約日期。
時間採用 24 小時制（沒有 AM/PM）。

## 1. 解析全數字的預約日期

實作 `schedule_appointment()` 函式，把預約日期的文字表示法解析成對應的 `DateTime` 格式。

請注意，輸入採用美式的月/日/年順序。

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 檢查預約是否已經過了

實作 `has_passed()` 函式，它會接受一個預約日期，並檢查該預約是否已經過去了：

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 檢查預約是否在下午

實作 `is_afternoon_appointment()` 函式，它會接受一個預約日期，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 描述預約的時間與日期

實作 `description()` 函式，它會接受一個預約日期，並回傳該日期與時間的描述：

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. 回傳週年紀念日

實作 `anniversary_date()` 函式，它會回傳今年的週年紀念日，也就是 9 月 15 日：

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
