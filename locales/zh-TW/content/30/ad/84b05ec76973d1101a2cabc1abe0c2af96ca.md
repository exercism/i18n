# 簡介

在像 Elm 這樣的純函式語言中，用相同引數呼叫的函式必須永遠回傳相同的值。因此，型別簽章為`rand : Int`的函式只能實作成`rand = 4`，這對產生隨機整數來說可不是好兆頭。

那麼，我們要怎麼在 Elm 中產生隨機值呢？我們把問題拆成兩部分：首先，用`Random.Generator a`描述我們想產生的值，然後再產生這個值。

第一種產生值的方式，是先透過`initialSeed : Int -> Seed`建立`Random.Seed`，然後使用`step : Generator a -> Seed -> ( a, Seed )`，它會回傳一個值和一個新的種子。注意這兩個函式都是純的，所以用相同的引數呼叫兩次會產生相同的值。

第二種產生值的方式，是使用`generate : (a -> msg) -> Generator a -> Cmd msg`，但這只能在 Elm 應用程式裡進行。在這種情況下，Elm 執行環境除了使用`step`之外，也可能使用外部的非純資源來產生種子。

接下來，我們會把焦點放在產生器上。

為了示範範例，我們姑且假設自己用`initialSeed`和`step`定義了一個函式`generate : Int -> Generator a -> List a`，它能從一個產生器產生若干個值。

`Random`模組提供了兩個基本的產生器，用來在特定範圍內產生整數和浮點數：

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

這些值可以組合成元組，也可以組成由值構成的陣列：

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra`套件提供了更多產生器，涵蓋各種資料結構：字串、日期、字典、陣列、集合等等。

我們可以用`Random.constant`建立只會回傳單一值的產生器：

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

我們可以用`Random.uniform`從給定的元素中隨機挑選，每個元素的機率相同：

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`接受兩個引數（`Red`和`[Green, Blue]`），以確保至少有一個值可以挑選，因為單一陣列可能是空的。

我們也可以用`Random.weighted`調整機率：

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

這些值不一定要加總到 100，它們反正會重新正規化。

我們可以用`Random.map`觸及產生器的內部：

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

我們也可以使用`Random.map2`一路到`Random.map5`，來組合更多產生器：

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

對於更複雜的用途，我們有`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，它可以用某個產生器產生的值來建立另一個產生器：

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

有時候，以自我遞迴的方式定義產生器很有用。在這些情況下，你可能需要用`Random.lazy`來避免編譯器無限展開產生器。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

這個例子有點重，所以我們來拆解一下吧。

`Peano`是一種代表正整數的型別：`Zero`是 0，`Next(Zero)`是 1，`Next(Next(Zero))`是 2，依此類推。我們定義`peano`來取得隨機的`Peano`數字。

首先，注意`Random.lazy`並沒有為邏輯增加任何東西，它只是避免編譯器無限地把`peano`寫進`peano`裡。

我們用`Random.uniform`在零（機率 50%）和另一個`Peano`數字加一（機率 50%）之間做選擇。不過，和上一個例子不同，`Random.uniform`挑選的不是值（例如`Zero`），而是產生器（例如`Random.constant Zero`），因為我們想使用`peano`本身。這表示`Random.uniform`會回傳型別為`Generator (Generator Peano)`的值，而這不是我們需要的。

為了「flatten」這個產生器，我們將它用管線送入`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，其中我們希望`b`是`Peano`。由於`Generator a`就是`Generator (Generator Peano)`，`a`必定是`Generator Peano`，而函式`(a -> Generator b)`的型別必定是`(Generator Peano -> Generator Peano)`。我們不想修改任何東西，所以`identity`是正確的選擇。

最後，`peano`會產生什麼樣的數字呢？我們知道它有 50% 的時間會產生 0，另外 50% 的時間會產生自身的另一次疊代再加一。也就是說，產生的數字會是 0（50% 的時間）、1（25% 的時間）、2（12% 的時間）、3（6% 的時間）等等。`peano`可以產生任意大的數字，但機率會以指數遞減。
