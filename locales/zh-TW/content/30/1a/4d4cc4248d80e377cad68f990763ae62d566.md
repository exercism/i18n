# 關於

物件初始化器是建構函式的替代做法。它的語法是一組以逗號分隔的欄位 name=value 配對，如下所示：

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

集合也可以用這種方式初始化。一般來說，這會用逗號分隔的寫法來完成，如下所示：

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

這種做法（以及語法）適用於任何實作`IEnumerable`且具有`Add()`方法的類別。

欄位可以依任意順序排列，也可以完全省略。

字典的語法如下：

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

被初始化的欄位必須能被呼叫端存取。一般來說，這代表它們必須是`public`或`internal`。

語言設計者和頂尖實務工作者之間有一股強烈的趨勢在提倡不可變性，因此以這種方式初始化的物件具有可變性，被視為一項缺點。有人提議在即將推出的語言版本 C# 9 中引入`init`子句，或許能解決這個問題。
