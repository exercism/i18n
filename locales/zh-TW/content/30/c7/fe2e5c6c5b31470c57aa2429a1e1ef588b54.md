# 簡介
C++ 內建的數字型別可以分成整數與浮點數。
整數是完整的數字，像`0`、`691`或`-2`。
浮點數是帶有小數點的數字，例如`6.02214076`、`0.1`或`-1.616`。

## 整數
下面的範例展示了四個不同變數的宣告與初始化

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

當你把值指定給`int`變數時，可以直接使用字面值。
字面值就是像`9241`這樣寫死在程式裡的數字。
針對不同的進位表示法，有不同的整數字面值。
十進位整數字面值最常見，使用的是`0`到`9`的數字。
只要加上像`0x`這樣的特殊前綴，就能使用其他進位。
上面的範例展示了數字`9421`的四種表示法與前綴。
所有變數都初始化為相同的值。

想進一步了解各種進位表示法，可以參考[這篇小教學][cpp_numerical_bases]。

你可以用單引號分隔數字，讓它更容易閱讀。
`9'241`和`0b0100'100'0001'1001`或`92'4'1`是一樣的。

## 浮點數

浮點數字面值有兩種寫法。
除了直觀的`0.0024`之外，也可以使用它的科學記號`2.4e-3`。
最常見的浮點數型別是`double`。

## 算術

C++ 支援`+`、`-`、`*`、`/`、`(`、`)`和`%`來組成運算式。
兩個整數之間運算的結果也會是整數。
`5 / 2`會回傳`2`。
當參與運算的其中一個型別是浮點數時，結果也會是浮點數。
`5.0 / 2`和`5 / 2.0`會回傳`2.5`。
`%`是餘數運算子，會回傳整數除法後的餘數：`5%3`的結果是`2`。

## 指定運算子

指定運算子會把字面值指定給一個變數。
運算一律從右到左進行，不會反過來。

```cpp
int length = 5;
int width = 2;
length = width;
```

這裡把整數值`5`指定給變數`length`。
接著把整數值`2`指定給變數`width`。
最後`width`的值會複製到變數`length`，原本的值`5`就消失了。
另外要注意，我們只是在指定的當下把`width`的值指定給`length`。
所以如果之後`width`的值改變了，也不會影響`length`得到的值。

指定運算子可以和其他運算子（算術與位元）結合，稱為`compound assignment`運算子，也就是`+=`、`-=`、`*=`、`/=`、`%=`。
這些運算子會對變數目前的值做運算，藉此修改它。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

變數`people`和`eggs`都初始化為`0`。
接著，我們把整數值`2`加到變數`people`原本的值`0`上，再把結果指定回`people`。
現在`people`變成`2`了。
然後，我們為每個人加上`3`顆蛋，總共是`6`顆蛋。
現在把這個`6`加到變數`eggs`原本的值`0`，並指定回`eggs`。
`eggs`現在會是`6`。
等效的運算式會是`people = people + 2`和`eggs = eggs + (3 * people)`。
