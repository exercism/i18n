# 測試

你可以透過 DrRacket 執行提供的測試，也可以從命令列執行。

若要透過 DrRacket 執行測試，只要開啟測試檔案，然後點擊右上角的「Run」按鈕即可。

若要從命令列執行測試，只要在練習目錄中執行測試即可。例如，如果測試套件叫做`hello-world-test.rkt`，你可以執行以下指令：

```
raco test hello-world-test.rkt
```

這會顯示以下內容：

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
