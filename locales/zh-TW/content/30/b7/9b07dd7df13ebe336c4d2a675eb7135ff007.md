# 提示

## 1. 把遇到的空格換成底線

內建的`clojure.string`函式庫提供了[`replace`][str-replace]函式。

## 2. 把控制字元換成大寫字串 "CTRL"

你可以使用 Java `Character` 類別的[`isISOControl`][java-ctrl]方法。

## 3. 把 kebab-case 轉成 camelCase

試著用[`split`][str-split]依照連字號把字串拆開吧。
如果字串裡沒有連字號，就原樣回傳。你可以用[`includes?`][str-includes]來檢查。用[`upper-case`][str-upper-case]做出駝峰的大寫部分。最後再用[`join`][str-join]把它們串接起來。

## 4. 略過不是字母的字元

你可以用[`Character/isLetter`][java-isletter]作為述詞來過濾字元。

## 5. 略過希臘小寫字母

希臘小寫字母是 Unicode 碼位`\u03B1`到`\u03C9`，也就是整數值 945 到 969。
