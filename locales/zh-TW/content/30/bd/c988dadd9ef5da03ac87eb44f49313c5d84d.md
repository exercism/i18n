# 指令

你的任務是建立一個碼錶，精確記錄每一圈的時間。

碼錶會使用四個指令（start、stop、lap 和 reset）來記錄：

1. 目前這一圈的計時時間
2. 先前記錄的單圈時間

能使用哪些指令取決於碼錶目前處於哪個狀態：

1. Ready：初始狀態
2. Running：正在計時
3. Stopped：停止計時

| 指令 | 起始狀態 | 結束狀態 | 效果                                                     |
| ---- | --------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | 開始計時                                      |
| Start   | Stopped     | Running   | 恢復計時                                     |
| Stop    | Running     | Stopped   | 停止計時                                     |
| Lap     | Running     | Running   | 將目前的單圈加入先前的單圈，然後重置目前的單圈 |
| Reset   | Stopped     | Ready     | 重置目前的單圈並清除先前的單圈                |
