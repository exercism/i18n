# 關於

`assocs`是一種[協定][assoc-protocol]，而不是單一的資料型態。雜湊表（`H{ }`）、關聯串列（由`{ key value }`配對組成的序列）以及樹狀映射都實作了它，而且 `assocs` 上的大多數詞語在這些型態之間都可以互通。

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

完整的詞語範圍很廣，包括排序疊代、映射與篩選，但大多數練習層級的工作只會用到其中一小部分：

| 詞語        | 效果                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )`，可區分值為 f 與鍵不存在兩種情況 |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`，會修改內容            |
| `change-at` | `( key assoc quot -- )`，其中`quot`是`( old -- new )` |
| `inc-at`    | `( key assoc -- )`，即 `+1`，鍵不存在時插入 `1` |
| `delete-at` | `( key assoc -- )`，會修改內容                  |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys`與`sort-values`（位於`sorting`中）會依選定的欄位對 alist 排序。

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
