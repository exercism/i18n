# 補充說明

## 地雷區格式

地雷區會用一個以 null 結尾的字串來表示，每一列的結尾都帶有一個換行字元。

例如：`"   \n * \n   \n"`

## 暫存器

| 暫存器   | 用途     | 型別 | 說明                          |
| -------- | -------- | ---- | ----------------------------- |
| `$a0`    | 輸入     | 位址 | 以 null 結尾的輸入字串        |
| `$a1`    | 輸入/輸出 | 位址 | 以 null 結尾的輸出字串        |
| `$t0-9`  | 暫時性   | 任意 | 用於暫存                      |
