# 指令補充

## 提示

要完成這個練習，你需要實作 `score`函式，它接受一連串的保齡球*投球*，並回傳最終得分或對應的錯誤：

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

這些定義已經幫你準備好了，但函式本身要由你來定義。

請記住，測試套件預期投球的編號要從 0 開始。
