# 簡介

整數不只能看成數值，也能看成位元的排列模式。Factor 的[`math`][math]詞彙提供了針對這些位元排列的標準低階運算，而[`math.bitwise`][bitwise]詞彙則額外加入了一些處理固定寬度值的輔助工具。

## 位元位移

`shift ( m n -- m' )`會移位`m`的位元。*正*的`n`向左移位（每一步都乘以 2）；*負*的`n`向右移位（每一步都除以 2）：

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

對正整數來說，右移會從低位捨去位元並補上零。對*負*整數來說，Factor 的`shift`是算術移位，它會保留符號位元，概念上是從左側填入符號位元的複本。（Factor 的整數是任意精度，所以「左側」要延伸多遠都行。）

## 位元邏輯運算

四個基本的邏輯運算是：

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`bitnot`作用在`0b1011`上會得到`-12`，因為 Factor 的整數是任意精度：把`0b1011`的位元反轉，概念上是「全部都是 1，只有低的四位反轉成`0100`」，讀成帶號大數就是`-12`。

## 將值視為 N 個位元

來自`math.bitwise`的`bits ( x n -- y )`會把`x`遮罩到它的低`n`個位元。這就是 Factor 裡「把值重新解讀成 N 位元無號整數」的作法：

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

第二個例子對這個練習很重要。如果你從一個負的二補數 Int32 值開始，想將它「邏輯上」右移（從左側補零）`amount`個位元，Factor 的慣用寫法是：

```
( value -- shifted )
32 bits  amount neg  shift
```

先遮罩到 32 位元，切換成無號的解讀，再移位。因為遮罩後的值是非負的，`shift`只會從低位捨去位元並補上零。
