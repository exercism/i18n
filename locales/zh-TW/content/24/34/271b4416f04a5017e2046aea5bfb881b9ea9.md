# 說明

Larry 是個喜歡寫程式來玩遊戲的 Lisp 外星人。
今天他想寫幾個函式，幫自己完成一個很像井字遊戲的遊戲。

和井字遊戲一樣，這個遊戲是在一個 3x3 的棋盤上進行的。

## 1. 從零開始

首先，Larry 需要一個函式來建立空白的棋盤`make-empty-board`。
棋盤上的所有格子都應該是`NIL`。

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. 從現有的棋盤開始

接著，Larry 需要一個函式，用一個由列組成的陣列來建立棋盤。
例如：

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. 勝利條件

如果同一列上出現 3 個相同的符號，那麼那位玩家就贏了。
Larry 會需要一個函式`all-the-same-p`，它接收一個含有 3 個項目的陣列，如果所有項目都是相同的符號，就會得出`T`。
（可以用`eq`來判斷兩個符號是否相同。）

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. 取得一列

現在 Larry 需要一個方法，來取得某一列的元素。
函式`row`會接收一個棋盤和一個列號，並回傳該列中元素的陣列。

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. 取得一欄

最後，Larry 需要一個方法來取得某一欄的元素。
函式`column`會接收一個棋盤和一個欄號，並回傳該欄中元素的陣列。

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
