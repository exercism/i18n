# 簡介

動態記憶體是由函式庫函式實作的，程式設計師用這些函式在執行期間配置與釋放記憶體。
由於記憶體的配置與釋放都由程式設計師掌控，動態記憶體的安全性完全取決於程式設計師是否不會犯下人為錯誤。
因此，動態記憶體是程式設計 bug 的主要來源之一，也是駭客攻擊的主要目標。

## malloc

`malloc`是宣告於`stdlib.h`中的函式，用來配置動態記憶體。
如果配置成功，會回傳一個指標，指向所配置記憶體第一個位元組的位址。
如果配置失敗，則回傳`NULL`。
檢查`malloc`的結果是否為`NULL`，並在失敗時妥善處理，是明智的做法。
回傳的指標型別是`pointer-to-void`，大致上可以視為一種「通用」指標，能夠轉換成記憶體實際使用的特定型別。
`malloc`有一個參數，也就是所需記憶體的大小，以位元組為單位。
配置陣列所需的總大小，是每個元素的資料型態大小乘上元素的數量。
`sizeof`運算子通常用來取得每個元素資料型態的大小。
以下範例示範了這一點

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

要記得，`malloc`新配置的記憶體不會被初始化，可能含有垃圾值。
請注意，對`numbers`指標使用`sizeof`得到的並不是陣列元素的數量，也不是所配置的記憶體總量。
`malloc`回傳的指標大小，就是該系統上任何指標的大小。
範例程式是在 64 位元系統上執行的，所以指標大小是 8 位元組（8 位元組乘以每個位元組 8 位元 = 64 位元）。
指標型別從 pointer-to-void 隱式轉換成 pointer-to-int。
也可以像這樣明確轉換：`int * numbers = (int *) malloc(sizeof(int) * count);`。
如果這些值在被讀取之前一定會先寫入，那麼使用`malloc`可以是配置記憶體的有效方式。
但如果在初始化之前有可能先讀取這些值，那麼使用`malloc`就有風險。
比較安全的配置記憶體方式是使用`calloc`，它會把新配置的記憶體初始化為零。

請注意上面的範例中使用了`free(numbers)`。

## free

`free`是宣告於`stdlib.h`中的函式，用來釋放動態配置的記憶體。
動態配置的記憶體在被`free`釋放之前，會一直佔用著記憶體。
有些作業系統可能會在程式結束時自動釋放動態配置的記憶體，但最好不要依賴這個行為。
`free`有一個參數，是指向那塊動態配置記憶體的指標。
指標在釋放之後若沒有設為`NULL`，就稱為懸空指標。
懸空指標可能指向原本預期之外的其他記憶體。
因此，懸空指標可能導致資料損毀，以及任意程式碼的替換與執行。
指向已配置記憶體、卻未設為`NULL`而清除的指標，可能被用來駭入程式。
指標傳給`free`之後，最好將它設為`NULL`。

## calloc

`calloc`是宣告於`stdlib.h`中的函式，既能配置動態記憶體，也會把新配置的記憶體初始化為零。
如果配置成功，會回傳一個指標，指向所配置記憶體第一個位元組的位址。
如果配置失敗，則回傳`NULL`。
檢查`calloc`的結果是否為`NULL`，並在失敗時妥善處理，是明智的做法。
回傳的指標型別是`pointer-to-void`，大致上可以視為一種「通用」指標，能夠轉換成記憶體實際使用的特定型別。
`calloc`有兩個參數。
第一個參數是要配置多少個指定資料型態的數量。
第二個參數是要配置之指定資料型態的大小。

在以下範例中，所有的`printf`敘述應該都會顯示`0`，因為`calloc`保證會把新配置的值設為零。

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc`是宣告於`stdlib.h`中的函式，用來擴張或縮減已配置的記憶體。
如果重新配置成功，會回傳一個指標，指向重新配置後記憶體第一個位元組的位址。
如果重新配置失敗，則回傳`NULL`。
檢查`realloc`的結果是否為`NULL`，並在失敗時妥善處理，是明智的做法。
`realloc`有兩個參數。
第一個參數是指向要重新配置之現有記憶體的指標。
第二個參數是重新配置後記憶體的大小，以位元組為單位。
在記憶體擴張之前所設定的值會保留下來。
重要的是要記得，擴張記憶體時新增的記憶體不會被初始化為零，其值可能是任何內容。
另外，縮減記憶體時被移除的記憶體也不會被初始化，可能會保留原本的值。
以下範例示範了陣列的擴張與縮減

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
