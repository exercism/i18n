# 取值方法與設值方法

取值方法和設值方法讓我們可以讀取和寫入物件屬性的值。
Crystal 有巨集，因此能輕鬆地為屬性定義取值方法和設值方法。
巨集是一種在編譯期產生程式碼的方式，之後會在巨集概念中介紹。

在 Ruby 裡，這些方法是用`attr_reader`、`attr_writer`和`attr_accessor`方法定義的，表面上和 Crystal 的實作非常相似。
Crystal 則把它們定義為`getter`、`setter`和`property`巨集。

## 取值方法

`getter`是一個巨集，它會定義一個回傳實體變數值的方法。
這表示當你想存取實體變數時，不必再在它前面寫`@`（在方法裡，但不含`initialize`）；改為呼叫`getter`巨集所定義的方法即可。

`getter`巨集可以接受多個實體變數，只要用逗號分隔即可。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

如你所見，使用`getter`可以減少你要寫的程式碼，也讓程式更容易閱讀。
另外，Ruby 和 Crystal 有一點不同：Crystal 的`getter`巨集同時接受變數名稱和符號做為引數。
符號之後會在符號概念中介紹。

## 設值方法

`setter`是一個巨集，它會定義一個設定實體變數值的方法。
這個巨集並不常見，通常會改用`property`巨集。
它所建立的方法會長得像`name_of_method=`；當中的`=`就是讓屬性可以被設定的關鍵。

這種方法定義有點特別，因為方法接收的引數放在`=`之後。
Crystal 還有其他幾個特殊方法也使用這種語法，例如`+`方法。

和`getter`巨集一樣，定義好`setter`之後，當你想更新實體變數的值時，可以呼叫`setter`巨集所定義的方法。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## 屬性

屬性巨集會同時為實體變數定義取值方法和設值方法。

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
