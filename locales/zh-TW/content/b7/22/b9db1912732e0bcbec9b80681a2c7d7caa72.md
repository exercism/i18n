# 簡介

## `for`迴圈

`for`敘述會重複執行一個程式區塊。它的第一行決定這個區塊要重複幾次：

```go
for init; condition; post {
    // loop body
}
```

- **init** 敘述會在第一次疊代前執行一次。通常會在這裡宣告並初始化迴圈使用的計數器變數。
- **condition** 是一個布林運算式，會在每次疊代前求值。當它的求值結果為`false`時，迴圈就會停止。
- **post** 敘述會在每次疊代結束後執行，可以用來更新計數器。

不要在`init; condition; post`外面加上小括號。不過，包住迴圈主體的大括號`{ }`則一律不可省略。

這個迴圈會讓`i`從`1`開始，印出`i`目前的值，在下一次疊代前將它增加，並在`i`到達`10`時停止：

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
