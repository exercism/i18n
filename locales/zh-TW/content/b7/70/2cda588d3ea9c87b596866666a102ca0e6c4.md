# 數字型別

Crystal 有各種不同的數字型別，各有不同用途。
舉例來說，有些型別速度較快，但可表示的值的範圍比其他的小。
有些型別可表示的值的範圍更大，但速度較慢。

在 Crystal 中，整數型別分為有號與無號兩種。
有號整數可以是正數或負數。
無號整數只能是正數。

## 有號整數型別

以下是 Crystal 的[有號整數型別][int]：

| 型別     | 大小（位元） | 範圍                                                                                                        |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 到 127                                                                                                 |
| `Int16`  | 16          | -32_768 到 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 到 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 到 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 到 170_141_183_460_469_231_731_687_303_715_884_105_727 |

較小的型別佔用的記憶體較少，速度也比大型別快，但可表示的值的範圍較小。

如果你知道值會落在某個範圍內，最好使用盡可能小的型別，以節省記憶體並提升效能。

預設的整數型別是 `Int32`。
若要宣告特定型別的整數，可以在數字後加上型別名稱作為後綴，寫成 `<number>_I <bit>`。

```crystal
1_i8.class
# => Int8
```

你可以使用 `to_i<bit>` 方法在不同的整數型別之間轉換。
`to_i` 方法會轉換成預設的整數型別 `Int32`。

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 無號整數型別

以下是 Crystal 的[無號整數][uint]型別：

`UInt8`、`UInt16`、`UInt32`、`UInt64`、`UInt128`

有號與無號整數唯一的差別在於，無號整數只能是正數。
若要宣告特定型別的無號整數，可以在數字後加上型別名稱作為後綴，寫成 `<number>_u<bit>`。
你可以使用 `to_u<bit>` 方法在不同的無號整數型別之間轉換。
`to_u` 方法會轉換成預設的無號整數型別 `UInt32`。

```crystal
1_u8.to_u16.class
# => UInt16
```

## 浮點數型別

以下是 Crystal 的浮點數型別：

| 型別      | 大小（位元） | 範圍                 |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 到 3.4E+38   |
| `Float64` | 64          | 2.3E-308 到 1.7E+308 |

有兩種不同的[浮點數型別][float]，其中一種比另一種更精確。

預設的浮點數型別是 `Float64`。

你可以使用 `to_f<bit>` 方法在不同的浮點數型別之間轉換。
`to_f` 方法會轉換成預設的浮點數型別 `Float64`。

## 運算後的型別

當你對兩個數字進行運算時，結果的型別會是精確度最高的那個數字所屬的型別。
浮點數比整數更精確，整數又比無號整數更精確。
而 `Float64` 又比 `Float32` 更精確，依此類推。

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## 深入探索：無號整數與有號整數

~~~~exercism/advanced
在底層，無號與有號整數的差別在於，有號整數會用第一個位元來儲存正負號。
這個號代表正數或負數。
至於無號整數，第一個位元則用來儲存值。
因此，有號 32 位元整數的最大值是 2^31 - 1。
無號 32 位元整數的最大值則是 2^32 - 1。

如果你想進一步了解有號與無號，可以在 [Wikipedia](https://en.wikipedia.org/wiki/Signedness) 上閱讀更多相關內容。
~~~~
