# 簡介

[配對與字典][pairs-dicts] 概念介紹了 Julia 字典型態的基礎。

因為`Dict`是重要且常用的集合型態，所以也有許多函式可以用來操作它們。

## 取得條目

取得條目最簡單的方法就是透過鍵，就像許多程式語言一樣。不過，要求一個不存在的鍵會得到`KeyError`。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

我們可以在嘗試取出之前先檢查鍵是否存在（例如使用`haskey(d, 4)`或`4 ∈ keys(d)`），不過直接為缺少的鍵取得預設值也很有用。

為此，我們有`get()`函式，以及會修改字典的版本`get!()`。兩者的差別在於「缺少的」鍵是否會被加入`Dict`。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

在先前的概念中我們看到，`delete!()`會依鍵移除條目。這可以搭配`pop!()`函式，在移除的同時取出對應的值。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 疊代

對`Dict`疊代時，預設會產生`key => value`配對。可以用慣用的`.first`和`.second`命名方式取得其中的兩個部分。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

我們常常只想使用鍵，或只想使用值，這很簡單。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## 合併

合併兩個`Dict`很實用，但我們得先說清楚，對於同時出現在多個輸入裡的鍵，我們打算怎麼處理。

`merge()`和`merge!()`函式會把任意數量的`Dict`由左至右合併起來。

既有的鍵，其值會被直接覆寫，所以最右邊的`Dict`會「勝出」。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()`和`mergewith!()`函式讓我們可以把函式當作第一個引數傳入，用來定義重複的鍵該如何合併。加法就是個簡單的例子。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

合併時，串接兩個向量也是常見的操作。為此，Julia 使用`vcat()`函式，原因在 [`Multi Dimensional Arrays`][multidim] 概念中有說明。

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

請注意，`mergewith`系列函式是 [高階函式][hof] 實際運作的好例子。

若要合併多個 [`Set`s][sets]，對應的合併函式是`union`。
