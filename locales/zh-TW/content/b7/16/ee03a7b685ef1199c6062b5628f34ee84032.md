# 說明

在這個練習中，你會寫一些程式碼，幫助自己為購買新車做準備。

你有三個任務：一個幫助你判斷自己負擔得起哪輛車的價格，一個判斷你是否需要駕照，還有一個幫助你計算註冊費。

## 1. 計算你是否負擔得起某輛車的月付款

你鎮上的交通工具經銷商都在推出五年期、0% 利率的優惠活動，而你想好好把握。
請實作 `canibuy(vehicle, price, monthly_budget)` 函式，它接受你正在考慮的車輛名稱、它的價格，以及你的每月預算，並回傳一個字串，讓你知道自己是否負擔得起這輛車。如果月付款與你的每月預算相差在 10 以內，你要回傳一個特別提醒，要你節省一點：

```julia-repl
julia> canibuy("1974 Ford Pinto", 516, 100)
"Yes! I'm getting a 1974 Ford Pinto."

julia> canibuy("2014 Bugatti Veyron", 562_500, 5000)
"Damn! No 2014 Bugatti Veryon for me."

julia> canibuy("2020 Gazelle Medeo", 3000, 50)
"I'll have to be frugal if I want a 2020 Gazelle Medeo."
```

~~~~exercism/note
在 Julia 中，數字可以包含 `_` 來將位數分組。
例如 `562_500` 等同於 `562500`。
~~~~

## 2. 判斷你是否需要駕照

如果你決定買車，就需要駕照。
腳踏車則不需要駕照。
請實作 `licence(vehicle, kind)` 函式，它接受車輛名稱和車輛種類（`"car"` 或 `"bike"`），並回傳你是否需要駕照：

```julia-repl
julia> licence("2014 Bugatti Veyron", "car")
"The 2014 Bugatti Veyron requires a licence to operate."

julia> licence("2020 Gazelle Medeo", "bike")
"The 2020 Gazelle Medeo requires no licence to operate."
```

## 3. 計算新車的註冊費

新車的註冊費依下列公式計算：

- 腳踏車不需要註冊，因此費用為 0€。
- 車齡 10 年以上的汽車，費用一律為 25€。
- 較新的汽車：
  1. 先取一個基本價格，也就是車輛的製造商標準零售價（MSRP）或 25&nbsp;000€ 當中較高者。
  2. 每過一年，就從基本價格中扣除 10%。
  3. 將該數值除以 100。這就是你必須支付的註冊費。

請實作 `fee(msrp, age, kind)` 函式，它接受車輛的 MSRP、車齡（年）以及車輛種類（`"car"` 或 `"bike"`），並依上述公式回傳該車輛的註冊費。

```julia-repl
julia> fee(562_500, 6, "car")
2250

julia> fee(25_000, 3, "car")
175

julia> fee(34_000, 30, "car")
25

julia> fee(3000, 0, "bike")
0
```
