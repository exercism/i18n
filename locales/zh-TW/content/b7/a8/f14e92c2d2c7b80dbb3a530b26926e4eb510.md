# 印出

Cairo 的印出功能讓你能把訊息和值顯示到主控台，方便你除錯程式，或在執行期間傳達資訊。

印出系統既靈活又直觀，提供了各式工具來格式化和輸出各種型別的資料。

## 印出的基礎

Cairo 提供兩個主要的巨集，用來把文字印到主控台：

- **`println!`**：在新的一行印出輸出。
- **`print!`**：直接印出輸出，不加上換行。

這兩個巨集都以`ByteArray`作為主要引數，它可以是一段簡單的字串，也可以是帶有值佔位符的格式化字串。

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

在上述範例中：

- `{}`佔位符會被`x`和`y`的值取代。
- `println!`會確保輸出以換行結尾。

## 格式化字串

有時你可能需要先建立格式化字串，而不馬上印出。

`format!`巨集可以幫你做到這件事。

它的運作方式和`println!`類似，但會回傳`ByteArray`，而不是把輸出送到主控台。

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

在這個範例中：

- `format!`會把`s1`、`s2`和`s3`組合成單一字串，並用連字號（`-`）隔開。
- 產生的字串可以重複使用，或之後再印出。

## 印出自訂資料型別

預設情況下，Cairo 只能印出整數和字串這類基本型別。

如果你想印出像結構體這樣的自訂型別，就會遇到錯誤，除非該型別有實作`Display`或`Debug`特質。

### 使用`Display`自訂格式

`Display`特質讓你定義自訂型別該如何印出。

以下是一個範例：

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

在這個範例中：

- `fmt`函式定義了`Point`結構體如何轉換成可印出的字串。
- `write!`巨集會把格式化後的字串附加到`Formatter`。

### 用`Debug`除錯

為了除錯，Cairo 提供了`Debug`特質。

你可以為大多數型別自動衍生它，快速又輕鬆地印出結構體的內部細節。

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

在這個範例中：

- `#[derive(Debug)]`會自動產生`Debug`特質的實作。
- `{:?}`佔位符會告訴`println!`使用`Debug`特質來格式化。

## 以十六進位印出

Cairo 允許使用`{:x}`佔位符，以十六進位格式印出整數。

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

在處理低階資料表示法時，這特別好用。
