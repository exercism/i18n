# 簡介

## 數字與字串

AWK 是一門非常精簡的程式語言，只有少數幾種基本資料型態。
在這個單元裡，我們會一起看看數字和字串。

### 數字

AWK 的數字是以雙精度浮點數實作的。
整數、浮點數和雙精度浮點數之間沒有區別。

AWK 看得懂八進位數字常數（以`0`開頭）與十六進位數字常數（以`0x`或`0X`開頭）。

#### 數值運算

你可以使用標準的算術運算子 `+`、`-`、`*`、`/`、`%`。
指數運算子是 `^`。
AWK 也有一些內建的數值函式，包括三角函式、隨機數字產生，以及用來把數字截斷成 _x_ 與零之間最接近整數的 `int(x)`。

### 字串

AWK 的字串是由字元組成的序列。
使用雙引號來指定字串常數。

#### 字串運算

字串運算只有一種：串接。
串接沒有專屬的運算子；
只要把兩個字串並排放在一起，就會將它們串接起來：

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` 是**敘述**，不是函式。
`print` 不需要括號。
~~~~

AWK 有許多字串操作函式。
隨著我們在這門課程中繼續學習，會深入介紹它們。

### 數字與字串之間的轉換

沒有明確的運算子可以在數字與字串之間轉換。
AWK 會依照程式的上下文隱含地自動轉換。
這讓處理輸入欄位的值變得非常簡單：AWK 通常就是會照你想要的去做。

* `print x + y`會因為`+`這個數值運算，把`x`和`y`變數的值轉換成數字。
* `print x y`會因為串接運算，把`x`和`y`變數的值轉換成字串。

如果你想明確表達轉換，`0 + x`會給出 _x_ 的數字表示，而`"" x`會給出 _x_ 的字串表示。

#### 從字串轉換成數字

AWK 把字串轉換成數字的方式可能會讓人困惑。
一個簡單的理解方式是：AWK 會從字串開頭讀取「數字字元」，直到遇到「非數字」字元為止。
一些例子：

* `"2.5"`會轉換成數字`2.5`；
* `"1e3"`會轉換成數字`1000`（科學記號）；
* `"456abc"`會轉換成數字`456`（因為`a`不是「數字」，轉換就到此停止）。
* `"abc789"`會轉換成數字`0`（字串的**開頭**沒有數字）。
