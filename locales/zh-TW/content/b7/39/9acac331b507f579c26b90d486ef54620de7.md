# 簡介

在 Haxe 中，例外是一種安全處理執行程式碼時所發生錯誤的方式。所有例外都應該包含一段描述該錯誤的訊息。我們可以用`throw`關鍵字來拋出例外：

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

當例外被拋出時，程式碼會去尋找負責處理這個錯誤的部分。如果找不到，它就會顯示錯誤訊息，同時停止程式的執行。

在 Haxe 中，我們用`try-catch`區塊來處理例外。這個區塊敘述由一個`try`區塊和一個或多個`catch`區塊組成。`try`區塊會嘗試執行一段程式碼，而`catch`區塊則在一旁待命，一旦有例外被拋出就把它捕捉下來，讓執行不會中斷。當`catch`區塊捕捉到例外時，也會執行區塊內的所有內容：

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch`區塊的引數型別應該省略。
