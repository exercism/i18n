安裝
============

要使用 YAMLScript 撰寫程式，你需要安裝 YAMLScript 命令列翻譯員。
這是一個稱為`ys`的二進位執行檔。
它目前可在下列平台運作：

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> 注意：Windows 支援已在規劃中，但目前尚未提供。

發行版本[可在 GitHub 上取得](
http://github.com/yaml/yamlscript/releases)。


## 自動安裝

為了完成 Exercism YAMLScript 的練習，你會反覆修改你的解答程式，並執行`make test`，直到所有測試通過。

就是這麼簡單！

第一次執行`make test`時，它會嘗試把該練習所需的特定版本`ys`翻譯員安裝到`/path/to/exercism/yamlscript/.local/`目錄中。

如果你已經把該版本的`ys`安裝在`PATH`中的某處，它就會默默地把`ys`翻譯員複製到正確的位置。

如果沒有，它會提示你進行二進位發行版本安裝，這通常只需要幾秒鐘。

如果失敗了（很少見，但偶爾會發生），它會提示你從原始碼自動建置，這可能需要幾分鐘（但非常可靠，而且不需要任何互動）。

只有在第一次執行`make test`時才會遇到這個情況。
所有設定使用相同版本`ys`的練習都會共用同一份安裝。

> 注意：你也可以把`make install-ys`指令與`make
> test`分開使用。
> 它會執行與`make test`完全相同的安裝流程，只是之後不會執行測試。


想進一步了解如何安裝 YAMLScript，特別是在 Exercism 之外使用它，請參閱 [YAMLScript 安裝文件](
https://yamlscript.org/doc/install/)。
