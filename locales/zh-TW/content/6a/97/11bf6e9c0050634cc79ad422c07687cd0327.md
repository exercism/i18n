# 簡介

遞迴是一種讓函式重複執行程式碼的方式，作法是讓函式呼叫它自己。
它也是另一種迴圈／疊代的方法。和迴圈一樣，函式應該測試一個布林運算式，以判斷何時要結束。
和迴圈不同的是，永遠不會結束的遞迴不會無限地執行下去。
每次函式呼叫所使用的值，可能會放在堆疊上各自獨立的空間裡。
如果函式呼叫的數量佔用的空間超過堆疊所能容納的量，就會造成堆疊溢位錯誤。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

執行後會印出

```
The number is 1
The number is 2
After recursion
```

有些情況用遞迴來表達，可能會比用迴圈來表達更容易閱讀，也更容易理解。
