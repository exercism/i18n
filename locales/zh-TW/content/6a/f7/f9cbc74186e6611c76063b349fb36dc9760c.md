# 簡介

在 JavaScript 中，_樣板字串_ 可以把運算式嵌入字串裡，這種做法也稱為字串內插。
這項功能擴充了內建的 [`String`][string-reference] 全域物件。

在 JavaScript 中，只要用反引號把文字包起來，就能建立樣板字串。
樣板字串不僅能讓文字包含換行和其他特殊字元，還能嵌入變數和其他運算式。

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

在上面的範例中，是用反引號（<code>\`\`</code>）來表示樣板字串。`${...}` 是替換時使用的佔位符號。
任何非字串的型別都會被_隱含_轉換成字串。
這個主題會在[型別轉換][type-conversion-concept]概念裡說明。
各種運算式都能用在樣板字串中。

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

當你需要把字串排成多行時：

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

如果你想在一般字串裡表示換行，而不用樣板字串（也就是不用反引號），可以使用換行跳脫序列 `\n`：

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

有了這些替換功能，你還可以在過程中加入邏輯，來決定輸出的字串應該是什麼。
其中一種處理邏輯的做法是使用[三元運算子][ternary-operator]。
它提供和 `if/else` 條件判斷相同的功能，只是格式稍有不同。

要在樣板字串的語法裡加入邏輯：

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
