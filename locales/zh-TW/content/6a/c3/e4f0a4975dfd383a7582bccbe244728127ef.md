# 操作說明

使用原始文字或 JSON 呼叫 API 時，很容易出錯。在這個練習中，你會使用 Ballerina Records 來組織請求內容，確保能順利與外部的訂位端點溝通。

## 目標

- 修改提供的程式碼。
- 呼叫 Airline 訂位服務，為使用者預訂機票。帶著適當的請求內容對 airlineReservationService 送出 POST 請求，並取得回應
- 呼叫 Hotel 訂位服務，為使用者預訂飯店房間。帶著適當的請求內容對 hotelReservationService 送出 POST 請求，並取得回應
- 呼叫 Car rental 服務，為使用者租車。帶著適當的請求內容對 carRentalService 送出 POST 請求，並檢查回應
- 如果一切順利，回傳一個帶有 message 屬性的 body，其值為 "Congratulations! Your journey is ready!!"
