# 說明

在這個練習中，你會繼續研究遙控車。

實驗車已經開發出來了，而測試跑道需要調整，才能同時處理量產車和實驗車這兩種車款。這兩種車都已經打造完成，你需要想辦法讓它們都能在同一條測試跑道上運作。

此外，量產車也開始交出不錯的成績。車隊老闆希望透過公布量產車的排名，來維持競爭的氣氛。

## 1. 讓車輛能在同一條測試跑道上行駛

請在`IRemoteControlCar`介面中新增一個方法，公開這兩種車的`Drive()`實作。

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. 讓不同車款在測試跑道上行駛的距離能夠互相比較

請在`IRemoteControlCar`介面中新增一個屬性，公開這兩種車的`DistanceTravelled`屬性實作。

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. 讓量產車可以進行排名

請在`ProductionRemoteControlCar`類別中實作`IComparable<T>`介面。車輛的預設排序方式應為勝場數遞增。

請實作靜態的`TestTrack.GetRankedCars()`，回傳傳入的車輛，並依勝場數遞增排序。

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
