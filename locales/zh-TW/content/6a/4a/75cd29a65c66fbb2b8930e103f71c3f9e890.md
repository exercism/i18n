# 迴圈

Rust 中的迴圈可以重複執行一個程式區塊，直到你要求它停止，或符合某個條件為止。

最基本的迴圈會使用`loop`關鍵字：

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

上面的程式碼片段會產生無限迴圈。要離開迴圈，請使用 break 關鍵字：

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## 使用`for`和`while`的迴圈

除了`loop`關鍵字之外，你也可以用`for`和`while`來建立迴圈。

`for`迴圈用於疊代集合或迭代器的元素。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

範圍也是迭代器，因此用`for`迴圈逐一疊代它們非常方便：

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

`while`迴圈會不斷重複執行程式碼，直到符合某個條件為止。我們可以用`while`迴圈改寫前面的範例，如下所示：

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

想了解更多關於迴圈的資訊，請參閱 Rust 書中的 [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops)。
