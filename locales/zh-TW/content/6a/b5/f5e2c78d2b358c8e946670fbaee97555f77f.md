# 簡介

## 正規表達式

Elixir 的正規表達式遵循**PCRE**規範（**P**erl **C**ompatible **R**egular **E**xpressions），和其他熱門語言如 Java、JavaScript 或 Ruby 類似。

`Regex`模組提供了一些用來處理正規表達式的函式。`String`模組的某些函式也接受正規表達式作為引數。

~~~~exercism/note
這個練習假定你已經熟悉正規表達式的語法，包含字元類別、量詞、群組和擷取。

如果你需要複習正規表達式的知識，可以參考以下資源：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

### Sigils

建立正規表達式最常見的方式是使用 `~r` sigil。

```elixir
~r/test/
```

請注意，所有 Elixir sigil 都支援[不同種類的分隔符號][sigils]，不只`/`。

### 比對

`=~/2`運算子可以用來執行正規表達式比對，並回傳`boolean`結果。或者，`Regex`模組和`String`模組中也有`match?/2`函式。

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### 擷取

如果單純的布林檢查不夠，可以使用`Regex.run/3`函式取得所有擷取結果的陣列（若沒有比對成功則為`nil`）。回傳的陣列中，第一個元素一定是整個正規表達式的比對結果，後續的元素則是符合的群組。

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### 修飾符

正規表達式的行為可以藉由附加特殊旗標來調整。使用 sigil 建立正規表達式時，請把修飾符加在第二個分隔符號之後。

常見的修飾符有：
- `i`：讓比對不區分大小寫。
- `u`：啟用像`\p`這類 Unicode 特有的樣式，並讓`\w`、`\s`等字元類別也能比對 Unicode。

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
