# 簡介
C++ 內建的數字型別可分為整數與浮點數。
整數是不帶小數點的數字，例如`0`、`691`或`-2`。
浮點數是帶有小數點的數字，例如`6.02214076`、`0.1`或`-1.616`。

## 整數
以下範例展示了四個不同變數的宣告與初始化：

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

當你把值指定給`int`變數時，可以直接使用字面值。
字面值就是像`9241`這樣寫死在程式裡的數字。
不同的進位表示法各有不同的整數字面值。
十進位整數字面值最常見，使用`0`到`9`的數字。
只要加上特殊的前綴，例如`0x`，就能使用其他進位。
上面的範例用四種表示法與前綴來呈現數字`9241`。
所有變數都初始化為相同的值。

如果想進一步了解各種表示法系統，可以參考[這份小教學][cpp_numerical_bases]。

你可以用單引號分隔數字，讓程式碼更容易閱讀。
`9'241`與`0b0100'100'0001'1001`或`92'4'1`相同。

## 浮點數

浮點數字面值有兩種形式。
除了直覺的`0.0024`，也可以使用它的科學記號`2.4e-3`。
最常見的浮點數型別是`double`。

## 算術運算

C++ 支援`+`、`-`、`*`、`/`、`(`、`)`與`%`來組成運算式。
兩個整數運算的結果仍然是整數。
`5 / 2`會回傳`2`。
當其中一個運算型別是浮點數時，結果也會是浮點數。
`5.0 / 2`與`5 / 2.0`會回傳`2.5`。
`%`是餘數運算子，會回傳整數除法的餘數：`5%3`的結果是`2`。

## 賦值運算子

賦值運算子會把字面值指定給變數。
賦值一律由右至左進行，絕不會反過來。

```cpp
int length = 5;
int width = 2;
length = width;
```

這裡整數值`5`被指定給變數`length`。
接著整數值`2`被指定給變數`width`。
最後，`width`的值被複製到變數`length`，原本的值`5`就遺失了。
另外要注意，我們只在賦值運算發生的當下，把`width`的值指定給`length`。
因此，如果之後`width`的值改變了，也不會影響`length`取得的值。

賦值運算子可以與其他運算子（算術與位元運算）結合，這類運算子稱為`compound assignment`運算子：`+=`、`-=`、`*=`、`/=`、`%=`。
這些運算子會對變數執行運算，藉此修改變數目前的值。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

變數`people`與`eggs`都初始化為`0`。
接著，我們在變數`people`現有的值`0`加上整數值`2`，再把結果指定回`people`。
現在`people`變成`2`。
之後，我們為每個人加上`3`顆蛋，總共是`6`顆蛋。
現在把這個`6`加到變數`eggs`現有的值`0`上，再指定回`eggs`。
`eggs`現在會是`6`。
等效的運算式會是`people = people + 2`與`eggs = eggs + (3 * people)`。
