# 簡介

函式是一段有組織、可重複使用的程式碼區塊，用來執行某些動作。
在 JavaScript 中，定義函式的方式有很多種。
這裡我們會看_函式宣告_和_函式運算式_。
其他像是[箭頭函式][concept-arrow-functions]的做法，會在其他概念中介紹。

## 函式宣告

在 JavaScript 中，定義函式的標準方式是_函式宣告_，也稱為_函式定義_或_函式敘述_。

它由`function`關鍵字、函式的名稱，以及以括號括住、以逗號分隔的參數清單組成。
接著是包在大括號裡的函式主體（定義函式做什麼的敘述集合）。

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

在 JavaScript 中，呼叫（invoke）函式的做法，是寫出函式名稱，後面接著一對包含引數的括號。

```javascript
someName(arg1, arg2, arg3);
```

## 參數

在函式主體內使用參數時，要留意可能的副作用。

- [基本資料型態][mdn-primitives]的值是_不可變的_。
  函式主體內對引數所做的任何事，都不會影響到原始值。
- 對所有其他值（物件、陣列、函式）而言，重新賦值不會影響到原始值。
  不過，如果你修改了這樣的引數（例如在物件中新增一個鍵），也會一併修改到傳入的原始值。

在 JavaScript 中，函式宣告裡定義的所有參數預設都是選用的。
如果你提供的引數比參數少，缺少的引數在函式內會是`undefined`，請參閱 [Null 與 Undefined][concept-null-undefined]。
在許多情況下，指定一個比`undefined`更合適的預設值是很合理的做法。
要做到這點，可以在函式定義中直接指定預設參數。

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## `return` 敘述

`return`敘述會結束函式的執行，並指定一個要回傳給函式呼叫者的值。一個函式可以有多個`return`敘述。

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

一個沒有回傳任何值，或沒有`return`敘述的函式，其結果會是`undefined`。
JavaScript 中沒有隱含的`return`。

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

在 JavaScript 中，你只能回傳恰好一個值。
如果你想傳遞更多資訊，就必須先把它們組合成單一實體，通常是組合成[物件][concept-objects]或[陣列][concept-arrays]。

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## 函式運算式

函式宣告是一個獨立的敘述。
但有時候，把函式定義成另一個運算式的一部分會很方便，例如在賦值中、作為函式參數（[回呼][concept-callbacks]），或作為[物件][concept-objects]中的值。
這可以透過函式運算式來完成。
它的語法和函式宣告相同，只是可以省略函式名稱，建立一個_匿名函式_。

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
