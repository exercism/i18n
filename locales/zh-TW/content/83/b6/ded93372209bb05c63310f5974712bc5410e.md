# 補充說明

## 字詞

定義一個`school`元組來存放名冊，裡面要怎麼儲存學生由你決定，接著實作下面的字詞。

- `<school> ( -- school )`：建立一個空的學校。
- `add-student ( school name grade -- ? )`：把`name`加到`grade`。成功時回傳`t`，如果`name`已經加入過（不論是加到這個年級或其他年級），就回傳`f`，此時名冊保持不變。
- `roster ( school -- names )`：所有學生，先依年級排序，再依名字的字母順序排序。
- `grade ( school n -- names )`：年級`n`的學生，依名字的字母順序排序。
