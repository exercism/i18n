# 關於

[符號][symbols]是具名的識別碼，可以用來指向某個值。
符號是透過符號字面值建立的，做法是在名稱前面加上`:`字元，例如`:foo`。
符號也可以寫成加上引號的形式，例如`:"foo"`，這樣一來名稱中就能包含空格等字元。

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

符號在 Ruby 中許多地方都會用到，包括作為雜湊的鍵，以及代表方法名稱和變數名稱。

## 識別碼

符號和字串不同的地方在於，它們是識別碼，而不是代表資料或文字。
這表示同名的兩個符號永遠是同一個物件。

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## 修改符號

符號是不可變的，也就是說它們無法被修改。
這表示當你「修改」一個符號時，其實是建立了一個新的符號。
有幾個方法可以用來操作符號，它們全都會回傳新的符號。
所有的方法都可以在 [Symbol API][symbols-api] 裡找到。

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

符號不可變的好處是，它們比字串更節省記憶體，而且作為識別碼使用時也更安全。

## 轉換

符號可以轉換成字串，反之亦然。
當你想修改一個符號，或是想把符號當作字串使用時，這就很有用。
要把字串呈現為符號，可以使用`String#to_sym`方法；反過來則可以使用`Symbol#to_s`方法。
由於符號可用的方法有限，所以如果需要一個新的符號，先把符號轉成字串，以便對它使用字串的方法，可能會很有用。

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
