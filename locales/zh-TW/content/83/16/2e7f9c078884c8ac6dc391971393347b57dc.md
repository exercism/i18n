# 簡介

## 泛型

當一個型別能使用_型別參數_來容納任何型別的值時，它就是_泛型型別_。

例如，這個`Box`型別帶有型別參數`a`（以小寫字母書寫）。

```gleam
pub type Box(a) {
  Box(a)
}
```

型別參數`a`是任何型別的佔位符，所以`Box`可以搭配字串、整數或任何其他型別使用。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

一個型別可以有多個型別參數，只要用逗號分隔它們即可。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### 泛型函式

型別參數也可以用在函式的引數中。

這個函式接受一個型別為`a`的值，並將一個接受`a`、回傳`b`的函式呼叫兩次。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
