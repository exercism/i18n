# 簡介

## 套件與模組

### 匯入

模組通常會用`use`關鍵字載入。
這會載入模組，並呼叫它的`import`方法，匯入所有已匯出的符號。

套件`@EXPORT`陣列中的符號會預設被匯入。
套件`@EXPORT_OK`陣列中的符號則必須明確匯入。

### 匯出

符號必須先被匯出，才能被匯入。
[Exporter][Exporter] 模組隨 Perl 一起提供，是最方便的匯出方式之一。

定義模組：
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

使用模組：
```perl
use Foo ('bar');

bar();
```

### 核心模組

除了 [Exporter][Exporter] 之外，Perl 還提供各式各樣的[核心模組][perl-core-modules]可供使用。
這裡可能會遇到的一些練習中，實用的例子包括 [List::Util][List::Util]、[Time::Piece][Time::Piece] 和 [Math::BigRat][Math::BigRat]。

### CPAN

除了核心模組之外，[CPAN][metacpan] 還有數千個由 Perl 社群建立的額外模組可供安裝。
Perl 學習路徑使用 [cpanfile][test-runner-cpanfile] 安裝一組精選模組，這些模組可以搭配 Exercism 的 Perl 測試執行器使用。
