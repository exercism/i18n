不過事情有點雜亂：Aazra 的座標格式和排序方式似乎和 Rui 的不同，他們得在兩份陣列之間來回查看，才能弄清楚哪些寶物對應哪些地點。身為剛起步的 Gleamlin，他們來找你幫忙寫個小程式（其實是一組函式），好把尋寶資訊整理得更有條理。

## 1. 轉換位置

實作`place_location_to_treasure_location`函式，它接受一個地點位置（例如`#("C", 1)`），並轉換成寶物位置（例如`#(1, "C")`）。

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. 比較寶物與地點的位置

實作`treasure_location_matches_place_location`函式，它接受一個地點位置（例如`#("C", 1)`），如果和某個寶物位置（例如`#(1, "C")`）相符，就回傳`True`。

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. 計算地點的寶物數量

實作`count_place_treasures`函式，它接受一個地點（例如`#("Aqua Lagoon (Island of Mystery)", #("F", 1))`）和寶物陣列，並回傳在該地點能找到的寶物數量。

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. 特殊地點

實作`special_case_swap_possible`函式，它接受一個寶物（例如`#("Amethyst Octopus", #(1, "F"))`）、一個地點（例如`#("Seaside Cottages", #("C", 1))`）和一個想要的寶物（例如`#("Crystal Crab", #(6, "A"))`），並在下列組合時回傳`True`：

- Brass Spyglass 可以在 Abandoned Lighthouse 和任何其他寶物交換。
- Amethyst Octopus 可以在 Stormy Breakwater 和 Crystal Crab 或 Glass Starfish 交換。
- Vintage Pirate Hat 可以在 Harbor Managers Office 和 Model Ship in Large Bottle 或 Antique Glass Fishnet Float 交換。
