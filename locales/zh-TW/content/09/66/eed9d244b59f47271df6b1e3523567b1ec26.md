# 提示

## 一般

- 練習檔案中已經宣告了`plot`元組、`registrations`與`next-id`符號，以及`not-found`符號。
- 若要處理模組層級的狀態，請使用`set-global`、`get-global`和`change-global`。

## 1. 開啟花園並列出它的註冊項目

- `V{ } clone`是`registrations`正確的起始值（一定要用`clone`，這樣常值才不會在每次呼叫之間共用）。
- `1 next-id set-global`會設定計數器。
- 對`list-registrations`來說，單一個`registrations get-global`就夠了。

## 2. 註冊一塊花圃

- 先讀取`next-id`，再用`plot boa`根據`id`和`name`建立花圃。
- 用`next-id [ 1 + ] change-global`把計數器加一。
- `push`（位於[`sequences`][sequences]）會就地附加到向量尾端，非常適合用在`registrations get-global`上。

## 3. 釋放一塊花圃

- `:: release ( id -- )`讓`id`可以在篩選述詞內使用。
- `[ id>> id = ] reject`會保留每個`id`欄位*不*符合區域變數`id`的花圃。把它當作`change-global`的主體來使用。

## 4. 取得已註冊的花圃

- `find`會回傳`( index elt/f )`。`nip`會丟掉索引。
- `[ not-found ] unless*`會在什麼都沒找到時代入該符號。

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
