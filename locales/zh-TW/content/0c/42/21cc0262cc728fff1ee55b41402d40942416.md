# 簡介

在 Go 中，`struct` 是一連串具名元素，這些元素稱為_欄位_，每個欄位都有一個名稱和型別。同一個 struct 內的欄位名稱必須是唯一的。struct 可以和物件導向程式設計範式中的_類別_相提並論。

## 定義 struct

你可以使用 `type` 和 `struct` 這兩個關鍵字建立新的 struct，並明確地定義欄位的名稱和型別。例如，這裡我們定義了一個 `Shape` struct，用來存放形狀的名稱和大小：

```go
type Shape struct {
    name string
    size int
}
```

struct 中欄位的命名遵循 Go 的慣例：名稱以小寫字母開頭的欄位，只有同一個套件中的程式碼看得見；名稱以大寫字母開頭的欄位，則在其他套件中也看得見。

## 建立 struct 的實例

定義好 `struct` 之後，你需要建立新的實例，並以任意順序透過欄位名稱來指定欄位：

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

要讀取或修改實例的欄位，可以使用 `.` 標記法：

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

沒有指定初始值的欄位，會擁有自己的零值。例如：

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

只要_按照順序_定義欄位，你也可以不使用欄位名稱來建立 `struct` 的實例：

```go
s := Shape {
	"Oval",
	20,
}
```

不過，這種語法被認為是_脆弱的程式碼_，因為一旦新增欄位就可能出問題，尤其是當新欄位屬於不同的型別時。在下面的例子中，我們為 `Shape` 新增了一個額外的欄位：

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## 「New」函式

有時候，有一些能幫我們建立 struct 實例的函式會很方便。依照慣例，這些函式通常叫做 `New`，或是名稱以 `New` 開頭；但由於它們只是一般的函式，你要取什麼名字都可以。它們也許會讓你想起其他語言中的建構函式，但在 Go 裡，它們就只是一般的函式。

在下面的例子中，我們使用其中一個 `New` 函式來建立 `Shape` 的新實例，並自動為形狀的 `size` 設定預設值：

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

使用 `New` 函式有下列幾項好處：

* 驗證傳入的值
* 處理預設值
* 由於 `New` 函式通常和它們所初始化的 struct 宣告在同一個套件中，因此它們甚至可以初始化 struct 的私有欄位

想更深入了解這個型別，可以參考這些資源：[Go by Example: Structs][go-by-example-structs]、[A Tour of Go: Structs][tour-of-go-structs] 或 [Structures in Go (structs)][medium-structures-in-go]

## `new` 內建函式

建立 struct 新實例的另一種方式，是使用 `new` 內建函式：

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

在這個例子中，`new` 會建立 `Shape` struct 的實例，把所有值都初始化為其型別的零值，並回傳指向它的指標。

~~~~exercism/note
大多數時候，你不會看到有人用 `new` 內建函式來建立 struct 的新實例。請優先使用 struct 實字、自訂的 `New` 函式，或套件提供的任何其他能幫你建立 struct 的函式。把使用 `new` 內建函式建立 struct 新實例，當成最後的手段。
~~~~
