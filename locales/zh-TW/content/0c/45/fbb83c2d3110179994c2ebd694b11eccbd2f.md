# 簡介

Swift 提供控制轉移敘述，可用來改變迴圈和 switch 敘述的執行流程。除了`return`之外，Swift 還包含`continue`、`break`、迴圈標籤和`fallthrough`。

## Continue

`continue`敘述會告訴迴圈停止執行目前這次疊代，並立刻開始下一次疊代。在`while`或`repeat-while`迴圈中，它會直接跳到條件檢查。在`for-in`迴圈中，則會前進到序列中的下一個元素。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break`敘述會立刻結束整個迴圈或 switch 敘述。程式會從迴圈或 switch 後面的第一行程式碼繼續執行。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## 帶標籤的敘述

在巢狀迴圈中，你可能會希望`break`或`continue`作用在外層迴圈，而不是最內層的迴圈。只要在迴圈前面加上名稱和冒號（`labelName:`），就能為迴圈加上標籤。接著就可以把這個標籤傳給`break`或`continue`：

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
