# 簡介

JavaScript 有一個內建物件`Date`，用來儲存日期與時間，並提供管理它們的方法。

<!-- prettier-ignore -->
~~~exercism/caution
它的基礎是 Java 的`java.util.Date`類別，這個類別在 2010 年代初期就被取代，但基於向後相容，JavaScript 的`Date`仍然保留了下來。

由於日期本身就很難處理，加上時區處理既糟糕又常常付之闕如，因此出現了許多函式庫，例如`moment.js`、`day.js`、`date-fns`和`luxon`。
這些在 Exercism 上都無法使用。

在你自己的專案裡，不要使用像`moment.js`這種已棄用或不再維護的套件，改用更現代的替代方案，例如`luxon`，或是尚未普及的 [Temporal][mdn-temporal]。
這個練習的重點是`Date`，直到 JavaScript 走到盡頭之前，它都會一直很重要。

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## 建立

`Date`物件是`Date`類別的實例。
建立時可以不傳任何引數給建構函式。
這樣會產生一個代表目前日期與時間的`Date`物件：

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Unix 時間戳記（數字）

如果傳入的是數字，就會被解讀成`timestamp`。
時間戳記是一個整數，代表從**1970 年 1 月 1 日[UTC][defn-utc]+0**起所經過的**毫秒**數。

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

你可能會以為`new Date(0)`會產生「最早」的日期物件，但 JavaScript 會把日期轉換成你所在的時區，也就是說，只有身處 [GMT／UTC+0][defn-gmt] 時區附近的人，才會真正取得 [Unix 紀元][defn-unix-epoch] 的值。

### ISO 8601 時間戳記（字串）

你可以把代表日期的字串值傳給`Date`建構函式。
在各家實作之間，**唯一**一致的格式，就是國際公認且已標準化的所謂 [ISO 8601 時間戳記字串][defn-iso8601]的[簡化版本][mdn-date-string-format]。

以[UTC][defn-gmt]表示的某個時間點，看起來像這樣：

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

其中會進行以下替換：

| 鍵   | 說明                                        | 預設值 |
| ---- | ------------------------------------------- | ------- |
| YYYY | 日曆年，以 4 位數表示                        |         |
| MM   | 日曆月，以 2 位數表示                        | 01      |
| DD   | 日曆日，以 2 位數表示                        | 01      |
| T    | 字母 T 字面值，用來分隔日期與時間            | T       |
| HH   | 24 小時制的小時，2 位數                      | 00      |
| mm   | 分鐘，2 位數                                 | 00      |
| ss   | 秒，2 位數                                   | 00      |
| mss  | 毫秒，3 位數                                 | 000     |
| Z    | 字母 Z 字面值，或是位移量`+/-HH:mm`          |         |

字母`Z`字面值代表 UTC（沒有時區，也沒有日光節約時間）。

由於大多數組成部分都有預設值，所以省略結尾的部分是合法的：

```text
YYYY-MM-DD
```

預設時間為 00:00:00.000

如果時間戳記的結尾不是`Z`，也不是`+HH:mm`或`-HH:mm`（代表時區位移量），那麼基於歷史因素，適用以下規則：

> 未提供時區位移量時，只有日期的格式會被解讀為 UTC 時間，而同時包含日期與時間的格式則會被解讀為本地時間。
> 之所以解讀為 UTC 時間，是因為規格在歷史上出錯，與 ISO 8601 不一致，但基於網頁相容性而無法更動。
> 參見 [Broken Parser – A Web Reality Issue][ref-broken-parser]。

### 日期物件

既有的日期物件也可以當成建構函式的引數。
這會複製既有的`Date`物件，日期與時間都相同。

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### 個別提供日期與時間的組成值

傳入三個數字，就能建立代表日期的日期物件。
傳入六個數字，則能建立同時代表日期與時間的日期物件。

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

第二個值是`month`，從代表一月的`0`開始，到代表十二月的`11`為止。

## `Date.parse()`

你可能會看到有人提到或引用日期剖析函式`Date.parse`。
由於這個函式只有少數不變量（必然成立的事實），其餘的實作方式並未規定（因此也稱不上標準），所以不應該使用它。

## 存取`Date`的組成部分

日期物件上有許多方法會回傳日期的組成部分：

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

這些方法各自都有對應的`set`版本（例如`setFullYear`）可以更新值。
任何溢出的值都會進位到下一個組成部分：

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

所有方法都有 UTC 版本，會忽略本地時區。

## 從日期轉換

日期物件有一個`getTime()`方法，會回傳以毫秒為單位的 UNIX 時間戳記，也就是 1970 年 1 月 1 日 UTC 午夜起經過的毫秒數。
此外還有`toISOString()`方法，可以把日期物件轉換成 ISO 8601 時間戳記字串。

## 比較日期

大於（`>`）、大於等於（`>=`）、小於（`<`）和小於等於（`<=`）可以直接用在兩個日期之間，或日期與數字之間。
這麼做之所以可行，是因為 JavaScript 會嘗試把日期強制轉換成原始值。

<!-- prettier-ignore -->
~~~exercism/advanced
在比較兩個日期，或日期與數字時，JavaScript 會呼叫 [`[Symbol.toPrimitive]("number")`][mdn-to-primitive]，這在內部又會呼叫 [`date.valueOf()`][mdn-date-value-of]。
後者等同於呼叫 [`date.getTime()`][mdn-date-get-time]。

如果你不想依賴這種行為，請先用`getTime()`轉換成數字。

[mdn-to-primitive]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/Symbol.toPrimitive
[mdn-date-value-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf
[mdn-date-get-time]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime
~~~

日期無法用相等比較（`==`和`===`），但`.getTime()`的結果可以。
