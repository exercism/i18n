Raku 是一門極其豐富、靈活且強大的程式語言。
它的靈活性讓開發者能寫出富有表現力、貼合自身風格的程式碼。

Raku 是一門龐大的語言，有豐富的深度可以學習、探索與實驗。
這份課程大綱的目標是涵蓋基礎知識，讓你順利起步。

物件導向程式設計是 Raku 的核心，但它並不會強迫你採用物件導向的寫法。
由於它天生就是物件導向，這份課程大綱經常會提到[物件、類別與方法][object-orientation]。

## 變數

為了保持簡單，我們在基礎概念裡只會使用純量[變數][variables]。

純量變數是前面帶有`$`符號的[識別字][identifiers]。

純量變數幾乎可以存放任何東西，預設型別是 [`Any`][Any]。

你使用的大部分變數都需要先[宣告][variable-declarator]。
目前請先用[`my`][my]和[`constant`][constant]就好。

```raku
my $foo;
constant $BAR;
```

## 副程式

副程式要用[`sub`][sub-declarator]宣告詞來宣告。

`sub`宣告後面可以接一個選用的[識別字][identifiers]，接著是選用的[簽章][signatures]，然後是[區塊][blocks]。

副程式（以及其他東西）可以透過加上[`is export`][exporting]特性來匯出。

在識別字後面加上[後環綴 `( )`][postcircumfix-()]運算子，就可以呼叫副程式。

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## 運算子

Raku 有各式各樣的[運算子][operators]。
在基礎概念裡的練習中，我們會用到 Raku 的一些基本數學運算子，例如`+`和`-`。

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

如果你想的話，在 Raku 裡可以輕鬆定義自己的運算子喔。
大多數內建運算子也可以用副程式的形式使用。

## 套件與模組

Raku 裡有幾種[套件][package-declarator]。在基礎概念裡，我們只會用到`module`。

要把整個檔案宣告成`module`，就要在模組宣告前面加上`unit`。

```raku
unit module Foo;

sub bar () { ... }
```

## 註解

Raku 有[單行][single-line-comments]與[多行／內嵌][multi-line-comments]註解。

單行註解以`#`開頭，一直到該行結尾。

多行／內嵌註解以井號加上反引號，再接一個 Unicode 開放標點字元開頭。
結尾則是相對應的成對結束字元。

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## 風格慣例

Raku 的變數與副程式[識別字][identifiers]採用`kebab-case`風格。
常數採用`ALL-CAPS`。
套件名稱採用`PascalCase`。
