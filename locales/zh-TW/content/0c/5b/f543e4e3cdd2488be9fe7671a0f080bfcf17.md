# 關於

ClojureScript 是一個以 JavaScript 為目標的 Clojure 編譯器。它會產生 JavaScript 程式碼，並與 Google Closure 最佳化編譯器的進階編譯模式相容。

## 為什麼要用 Clojure？

Clojure 是一種支援互動式開發的動態通用程式語言。Clojure 是函式式程式設計語言，擁有豐富的不可變、持久性資料結構。身為 Lisp 的方言，它抱持著程式即資料的哲學，並具備強大的巨集系統。

## 為什麼要用 JavaScript？

瀏覽器與網頁應用程式的普及，讓 JavaScript 擁有其他語言都望塵莫及的獨家觸及範圍。正因為它如此重要，JavaScript 引擎也獲得了大量的研究與最佳化，使 JavaScript 在效能上足以與 JVM 等許多更成熟的平台一較高下。

## 為什麼要用 Google Closure？

Google 身為現今一些最複雜的用戶端伺服器網頁應用程式的提供者，對打造 Closure 函式庫與 Closure 編譯器投入了大量資源，兩者相輔相成，讓整程式最佳化得以實現，即使使用大量函式庫，產出的程式也能把載入時間降到最低。

## 機會

ClojureScript 結合了 JavaScript 平台的觸及範圍、Clojure 的靈活性與互動式開發，以及 Google Closure 的整程式最佳化，為網頁程式設計提供最強大的語言。
