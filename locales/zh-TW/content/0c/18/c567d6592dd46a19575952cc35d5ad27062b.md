# 指令

Tori 是一位氣候記者，她想寫一篇關於不同城市天氣的報導。她手上有這些城市的天氣資料，想依氣溫將它們排名，但有些溫度是華氏，有些是攝氏。她需要你幫忙把溫度換算成同一個單位，再進行排名。

## 1. 將華氏換算成攝氏

定義`fahrenheit_to_celsius`函式，它接收華氏溫度作為引數，並回傳攝氏溫度。

要將華氏換算成攝氏，請從華氏數值中減去 32，再將結果除以 1.8。

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. 比較兩個溫度

定義`compare_temperature`函式，它接收兩個溫度，並回傳一個`Order`值，指出第一個溫度是小於、等於，還是大於第二個溫度。

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. 依溫度排序城市

定義`sort_cities_by_temperature`函式，它接收一個城市陣列，並將它們從最冷排到最暖後回傳。

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
