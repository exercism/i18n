# 關於

除了`cond`之外，Elixir 還提供了巨集 [`if/2`][getting-started-if]，當你只需要檢查一個條件時，它特別好用。

[`if/2`][kernel-if]接受一個條件和兩個選項。如果條件為*真值*，它會回傳第一個選項；如果條件為*假值*，則回傳第二個選項。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

如果沒有提供第二個選項，就會回傳`nil`。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

也可以把`if`運算式寫在同一行。請注意條件後面的逗號。

```elixir
if age >= 16, do: "beer", else: "no beer"
```

這種語法適合非常短的運算式，但如果運算式放不進同一行，就應該避免使用。

## *真值*與*假值*

在 Elixir 中，所有資料型態在布林情境（例如`if`運算式）中出現時，都會求值為*真值*或*假值*。所有資料都會被視為*真值*，**除了**`false`和`nil`之外。特別是空字串、整數`0`和空陣列，在 Elixir 中都會被視為*真值*。如此一來，[Elixir 與 Ruby 相似，但和 JavaScript、Python 或 PHP 不同][falsy-various-langs]。

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and]、[`||/2`][kernel-or]和[`!/1`][kernel-not]是可用於任何值的*真值*布林運算子，正好與*嚴格*布林運算子[`and/2`][kernel-boolean-and]、[`or/2`][kernel-boolean-or]和[`not/1`][kernel-boolean-not]互補。

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
