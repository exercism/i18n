# 指示

你經營一間高級電影院。
想進場看電影的人，必須先購買年票，之後就能免費觀賞。

你的電影院會記錄每一筆入場紀錄。
你想用這份紀錄追蹤這個月有哪些會員使用了年票。
你也想了解顧客的年齡分布。
你發現可以用集合來達成這些目標。

## 集合

集合非常適合用來儲存這類資料。

集合是一種資料型態，用來儲存彼此相異、不重複的值，而且沒有特定的順序。
「相異、不重複」的意思是，一個元素要嘛在集合裡，要嘛不在集合裡；和陣列不同，同一個元素不能重複出現在集合中。
集合通常是無序的；如果你把集合裡的元素列出來，得到的順序可能和加入時的順序不同，甚至可能和上一次列出的順序也不一樣！

集合最基本的特性之一就是成員檢查：能夠確認某個元素是否在集合中。
幾乎所有使用集合的場合，都離不開成員檢查。

Go 並沒有內建的集合資料型態。
一般常見的做法是用`map[<type>]struct{}`或`map[<type>]bool`來代替集合；和集合類似，`map`可以加入相異、不重複的元素，也支援成員檢查。

## 1. 儲存參加者資訊的地方

為了追蹤出席狀況和年齡分布，你會用到集合。

你不會想為名字和年齡各寫一個集合；你可以改用泛型集合，一個就能同時處理兩者。
定義一個`Set`型別，底層是`map[T comparable]struct{}`，用來儲存參加者。
撰寫一個`NewSet[T comparable]()`函式，回傳空的`Set[T]`。

```go
names := NewSet[string]()
```

## 2. 追蹤參加者

現在你準備好記錄參加者的資訊了。

撰寫一個`Add[T]()`方法，把元素加入集合。

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. 檢查參加者

現在你有了參加者的集合，就能檢查特定會員和年齡層是否出現。
撰寫一個`Contains[T](element)`方法，回傳某位會員或某個年齡層是否在`Set`裡。

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. 比較參加者

又過了一個月，你手上有一份新的年齡分布`Set`。
你的行銷經理想知道這個月的新片是否改變了出現的年齡層。
撰寫一個`Equals[T](other)`方法，判斷兩個集合是否含有相同的元素。

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
