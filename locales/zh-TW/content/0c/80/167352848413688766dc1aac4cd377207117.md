# 關於

遞迴是一種透過函式呼叫自身，來重複執行程式碼的方式。
它是迴圈／疊代的另一種做法。和迴圈一樣，函式應該檢查一個布林運算式，以判斷何時結束。
和迴圈不同的是，永不結束的遞迴不會無限地執行下去。
每次函式呼叫所使用的值，可能會放在堆疊上各自的框架中。
如果函式呼叫的數量佔用的空間超過堆疊所能容納的，就會導致堆疊溢位錯誤。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

這會輸出

```
The number is 1
The number is 2
After recursion
```

有些情況用遞迴表達，會比用迴圈表達更容易閱讀，也更容易理解。


## Tail Call

尾呼叫指的是函式的最後一個敘述只呼叫自身，不做其他事。

尾呼叫是遞迴的一種特殊形式，能讓編譯器在編譯後的程式碼中，把遞迴最佳化成迴圈。
這麼一來就能兼得兩者的優點：既有遞迴的可讀性，又有迴圈的效能。
把遞迴編譯成迴圈，稱為`tail call elimination`或`tail call optimization.`

當尾呼叫被編譯成迴圈時，每次函式呼叫不會建立新的堆疊框架。
原先呼叫時的函式位址會接收更新後的值，因而節省堆疊空間並提升效能。

下面這個例子不是尾呼叫，因為函式會在自己呼叫自己的結果上加 1。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

這會輸出

```
The number is 1
The number is 2
j is 3 after recursion
```

要將它重構成尾呼叫，請把`j`變成`printIncrement`的參數

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

你可能會發現，尾呼叫比不是尾呼叫的遞迴呼叫更容易理解。
不過，編譯器通常不保證所有的尾呼叫都會被最佳化。
使用遞迴時，一定要確認疊代的次數不會多到讓堆疊溢位。
