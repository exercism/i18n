# 說明

你的朋友 Li Mei 經營一間果汁吧，賣的是美味的綜合果汁。
你是她店裡的常客，也發現自己可以讓朋友的生活輕鬆一點。
於是你決定用你的程式設計技能來幫 Li Mei 分擔工作。

## 1. 判斷調製一杯果汁需要多少時間

Li Mei 喜歡事先告訴客人，他們所點的菜單上的果汁要等多久。
她很難記住確切的數字，因為調製每種果汁所需的時間都不一樣。
`"Pure Strawberry Joy"`要 0.5 分鐘，`"Energizer"`和`"Green Garden"`各要 1.5 分鐘，`"Tropical Island"`要 3 分鐘，而`"All or Nothing"`要 5 分鐘。
其他所有飲料（例如特價品）都可以假設準備時間為 2.5 分鐘。

為了幫你的朋友，請寫一個函式`time_to_mix_juice`，它接收菜單上的果汁作為引數，並回傳調製這杯飲料需要的分鐘數。

```R
time_to_mix_juice("Tropical Island")
# => 3

time_to_mix_juice("Berries & Lime")
# => 2.5
```

## 2. 補充萊姆角的存量

Li Mei 的許多創作都會用到萊姆角，無論是當作材料，還是作為裝飾的一部分。
所以她早上開始上班時，都得確認裝萊姆角的盒子是滿的，足夠應付接下來的一天。

請實作函式`limes_to_cut`，它接收 Li Mei 需要切的萊姆角數量，以及一個代表她手邊整顆萊姆存量的陣列。
一顆`"small"`萊姆可以切出 6 個萊姆角，一顆`"medium"`萊姆可以切出 8 個，而`"large"`萊姆則可以切出 10 個。
她總是按照清單中的順序切萊姆，從第一項開始。
她會一直切下去，直到切出所需的萊姆角數量，或是萊姆用完為止。

Li Mei 想事先知道她需要切幾顆萊姆。
`limes_to_cut`函式應該回傳需要切的萊姆數量。

```R
limes_to_cut(25, c("small", "small", "large", "medium", "small"))
# => 4
```

## 3. 列出佇列中每筆訂單的調製時間

Li Mei 喜歡在螢幕上追蹤客人等候中的訂單各需要多少時間才能調製完成。

請實作`order_times`函式，它接收一個訂單佇列，並將製作每筆訂單所需的時間*印出*到 stdout。

```R
order_times(c("Energizer", "Tropical Island"))
# => 1.5 
# => 3
```

## 4. 收尾這班

Li Mei 總是工作到下午 3 點。
接著由她的員工 Dmitry 接手。
Li Mei 的班結束時，經常還有已經點好但還沒調製的飲料。
Dmitry 會接著調製剩下的果汁。

為了讓交接更順利，請實作函式`remaining_orders`，它接收 Li Mei 這班剩下的分鐘數，以及一個陣列，裡面是已經點好但還沒調製的果汁。
這個函式應該回傳 Li Mei 在下班前來不及開始調製的訂單。

這班剩下的時間一定會大於 0。
要調製的果汁陣列絕對不會是空的。
此外，訂單會按照它們在陣列中出現的順序來調製。
如果 Li Mei 開始調製某杯果汁，就算得多工作一下，她也一定會把它做完。
如果已經沒有剩下的訂單需要 Dmitry 處理，就應該回傳一個空向量。

```R
remaining_orders(5, c("Energizer", "All or Nothing", "Green Garden"))
# => c("Green Garden")
```
