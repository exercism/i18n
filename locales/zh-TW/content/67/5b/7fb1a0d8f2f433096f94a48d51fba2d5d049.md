# Debug

YS 有一個內建的 `DBG` 函式，在除錯你的解答程式碼時很好用。
它接受任意數量的引數，並將它們印到 stderr 的主控台。
它會回傳最後一個引數，所以你可以直接在程式碼中內嵌使用它。


你可以使用`.>`這個行內運算子，它是`.DBG()`的簡寫。

以下是一個範例程式碼檔案：

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

當你用`ys`執行這段程式碼時，會看到以下輸出：

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## 編譯

另一個找出問題的常見方法，是看看你的 YS 程式碼編譯成什麼樣的 Clojure 程式碼。

你可以用`-c`旗標執行`ys`命令列翻譯員來做到這一點。

以下是上面的`program.ys`檔案編譯後的樣子：

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

你可以清楚看到`.>`運算子如何編譯成`DBG`函式呼叫。
