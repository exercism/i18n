# 指令

學習 ABAP 內部資料表的基礎知識。

你的類別有一個名為`initial_data`的內部資料表。它有三個欄位：`GROUP`、`NUMBER`和`DESCRIPTION`。

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## 步驟 1

你的第一項任務，是完成`fill_itab`方法，並依照下列的值，把 6 筆記錄放進這個資料表：

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## 步驟 2

接著，實作`add_to_itab`方法，在內部資料表的末端新增一筆具有下列值的記錄：

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## 步驟 3

現在請在`sort_itab`方法中排序這個內部資料表，讓`GROUP`欄位依字母順序排列，`NUMBER`欄位則依遞減順序排列。

## 步驟 4

在`search_itab`方法中，搜尋排序後的資料表，並回傳`NUMBER`欄位值為 6 的那筆記錄的索引。
