# 簡介

Python 的字典（`dict`）是一種資料結構，用來將[可雜湊][term-hashable]的_鍵_對應至_值_；在其他程式語言裡，它被稱為可調整大小的[雜湊表][hashtable-wikipedia]、雜湊映射或[關聯陣列][associative-array]。字典是 Python 唯一內建的[映射型別][mapping-types-dict]。


`keys`必須是可雜湊的，而且在同一個字典中必須唯一。
鍵的型別可以是`number`、`str`或`tuple`（由_不可變_的值組成）。
鍵不能包含_可變_的資料結構，例如`list`、`dict`或`set`。
從 Python 3.7 起，`dict`的鍵順序保證就是項目插入的順序。

`values`可以是任何資料型態或結構。
值也可以_任意_巢狀，因此能包含陣列的陣列、子字典，以及其他自訂或複合的資料結構。

給定一個`key`，字典可以在（平均）常數時間內取出對應的`value`（_與項目數量無關_）。
與在`list`或`array`中搜尋某個值（_在不知道`index`位置的情況下_）相比，`dict`會用掉明顯更多的記憶體，但取用速度非常快。

當項目集合龐大，且必須經常存取和更新時，字典特別有用。
