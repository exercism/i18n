# 關於

Elm 是純函式語言，所以沒有敘述，只有運算式，而且函式永遠是單一運算式。

這鼓勵我們寫出小而簡單的函式，一般來說是件好事，但有時候函式無可避免地會比較複雜，我們就需要一種方式，確保這些函式仍然能寫得優雅。

`let`運算式正是為此而生。它分成兩個部分：`let`區段，你可以在這裡建立任意數量的定義；接著是`in`區段，它是一個可以使用這些定義的單一運算式。

以電腦科學的角度來說，`let`會建立一個作用域，其範圍只限於`in`裡的運算式。

`let`運算式在幾種情況下特別好用：

- 簡化運算式
- 為中間運算式的結果命名
- 當運算式愈來愈大時，把它拆成更小的部分

在`let`運算式裡，大多數的事情都能做，包括解構，不過以下幾項不行：

- Custom Types
- Type Alias
- 名稱遮蔽（你不能重新定義，或重複使用已經在作用域裡的名稱）

## 簡化運算式

這個運算式把 3 個數字的立方相加，但可讀性不高，而且很容易在不同數字上寫出不一致的計算。

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

我們可以在`let`運算式裡定義一個`cube`函式，讓計算更簡單、更具表達力，也更安全。這個函式可以有型別註解，但在慣用的 Elm 程式碼裡，這相當少見。

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## 為中間運算式的結果命名

這段程式碼定義了 sideArea 和 topArea，讓計算更簡單、也更具表達力。

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## 拆分大型運算式

這段程式碼會為 [Game of Life](https://playgameoflife.com/)（一個常見的程式設計範例練習）建立初始樣式。

不需要完全理解它的運作原理，但應該很明顯：如果不使用`let`，把它寫成單一運算式會非常龐大。

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
