# 關於

我們可以用 [Bitwise 模組][bitwise-hexdocs] 裡的函式，對整數執行[位元二元運算][bitwise-wiki]。

- [`band/2`][bitwise-and]：位元 AND
- [`bsl/2`][bitwise-shift-left]：位元左移（SHIFT LEFT）
- [`bsr/2`][bitwise-shift-right]：位元右移（SHIFT RIGHT）
- [`bxor/2`][bitwise-xor]：位元 XOR
- [`bor/2`][bitwise-or]：位元 OR
- [`bnot/1`][bitwise-not]：位元 NOT

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
