# 提示

## 一般

- 每個任務都需要一個變數來計算圈數，其中兩個還需要第二個變數來累計總和。
- 第`n`圈的長度是`90 + 10 * n`公尺。驗算一下：第 1 圈是 100 公尺。

## 1. 總共跑了多遠？

- 讓`total`從 0 開始，`lap`從 1 開始。
- 在迴圈開頭用`until!(lap > laps)`結束迴圈，這樣零圈時迴圈主體一次都不會執行，總和也會維持在 0。
- 把這一圈的長度加到總和裡，然後把`lap`加 1。忘了後者，就是迴圈永遠跑不完的原因。

## 2. 要跑幾圈才能達到某個距離？

- 同樣是累計總和，但這次要問的是總和，而不是圈數：`until!(total >= metres)`。
- 把它放在迴圈開頭。這樣一來，問 0 公尺時就會直接得到 0 圈，不會跑任何一圈。
- 迴圈結束時，圈數計數器的值就是答案。

## 3. 第幾圈開始變長？

- 這裡不需要累加任何東西，所以不需要累計總和。
- 檢查目前這一圈的長度，當它超過所問的距離時，就用`break!`跳出來。
- 迴圈結束時`lap`裡的值就是答案。
