# 關於

Elm 是一門令人愉快的語言，很適合用來打造可靠的網頁應用程式。
它有親切的錯誤訊息、出色的效能、小巧的檔案，而且沒有執行階段例外。

Elm 最出名、也最廣為仿效的部分，大概就是 The Elm Architecture 了。它是一個用來組織網頁應用程式的簡單模式，所有 Elm 網頁應用程式都是照著它寫的。

核心概念是：你的程式碼是圍繞著應用程式狀態的`Model`、一個`update`模型的方式，以及一個`view`模型的方式來建構的。

`Model`包含應用程式的狀態，也就是應用程式需要的所有資料。
它可以是任何型態，但在任何實用的應用程式裡，它通常是[記錄][record]。
想像一個簡單的應用程式，裡面有一個文字方塊，以及一段顯示該文字反向結果的文字，這個模型大概會長得像下面這樣。
你也可以在 [Elm 指南][elm-guide-text-fields] 上看到這個範例。

```elm
type alias Model =
  { text : String
  }
```

`update`是一個函式，當有變動時（例如使用者點擊按鈕），它會被呼叫並收到一個`Msg`。
它接收`Msg`和目前的`Model`，並回傳一個新的`Model`。
`Msg`可以是任何型態，但它通常是一個[自訂型態][custom-type]。

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

和所有自訂型態一樣，`Msg`的變體可以依需求攜帶任意數量的資訊。
在上面的例子中，`TextChanged`這個變體包含一個`String`。

`view`是一個回傳 HTML 的函式，用來在瀏覽器中顯示給使用者看。
它接收目前的`Model`，並回傳一個`Html Msg`（Elm 用來表示 HTML 的型態）。
每個 HTML 元素（例如`<div>`）在`Html`套件裡都有一個對應的 Elm 函式（`Html.div`）。
這些函式每個都接收兩個參數，第一個是屬性的陣列（來自`Html.Attributes`和`Html.Events`套件），第二個是子元素的陣列（來自`Html`套件的函式）。
另外還有一個`text`函式，代表 HTML 的字串內容，它只接收一個字串參數，除此之外的用法和`Html`套件裡其他所有函式 / 元素都一樣。

`view`函式可以指定某些事件（例如點擊按鈕，或在文字方塊裡編輯文字）會產生一個`Msg`，Elm Runtime 會用它來呼叫`update`函式、修改`Model`，並產生更新後的 HTML。
在下面的程式碼裡，這是靠`Html.Events.onInput TextChanged`做到的。

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

`Html.Events.onInput`預期會收到一個函式（`String -> Msg`），並用它來建立`Msg`。
不同的事件能提供的資訊不同，因此預期的函式也不同，舉例來說，`Html.Events.onCheck`（給核取方塊用）預期`Bool -> Msg`，而`Html.Events.onClick`只預期一個`Msg`。

Elm 語言是純的、也是函式式的，不可能發生變異，所以所有會變動的東西都交由 Elm Runtime 處理。
你可以在 Elm 套件註冊表上看到所有不同的 [HTML 元素][html-elements]、[元素屬性][element-attributes] 和 [HTML 事件][html-events]。

用 Elm 可以寫 4 種「等級」的網頁應用程式，一級比一級強大、也一級比一級複雜（不過 Elm 仍然是一門簡單到令人愉快的語言，生態系也是）。
這些都定義在 [Browser 套件][browser-package] 裡：

- [sandbox][browser-sandbox]，回應使用者的輸入，例如按鈕和核取方塊
- [element][browser-element]，透過 HTTP 和 JavaScript 互通與外界溝通
- [document][browser-document]，控制網頁的`<title>`和`<body>`
- [application][browser-application]，建立完整的單頁應用程式，處理路由 / URL 變化

本概念使用的是 [sandbox][browser-sandbox]，因為它最簡單（而且因為它是沙箱，要搭配 Exercism 線上編輯器使用也相對容易）。
Elm 程式的入口模組必須叫做`Main`，而建立應用程式的函式必須叫做`main`，如下所示。

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

我們已經看過`update`和`view`這兩個函式，而 [sandbox][browser-sandbox] 還額外需要一個`init`函式，用來回傳`Model`的初始狀態。
