# 列舉

列舉是 Cairo 的資料型態，用來定義一組預先定義好的變體，目的是讓程式碼更好讀、更安全。
在 Cairo 中，`enum` 的變體可以宣告成容納不同的資料型態（整數、結構、元組、其他列舉等）。

下方的程式碼片段示範列舉可以怎麼定義：

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

上面宣告的 `Direction` 列舉是個簡單的列舉，含有四個變體：`North`、`East`、`South` 和 `West`。
命名慣例是用 PascalCase 來命名列舉的變體。
每個變體都代表 `Direction` 列舉型別的一個不同值。
在這個列舉範例中，每個變體都沒有關聯值，可以用以下語法建立實例：

```rust
let direction = Direction::North;
```

下面是同一個 `Direction` 列舉，但它的變體帶有 關聯值，用來儲存方向的確切度數：

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

從這個範例可以明顯看出，`Direction` 列舉的每個變體都有一個 `u128` 的關聯值。
這種列舉可以這樣建立實例：

```rust
let direction = Direction::North(10);
```

## 使用自訂型別的複雜列舉範例

列舉的變體可以混合使用不同的資料型態來宣告。
在下面的範例中，`Action` 是個複雜的列舉，以 `Quit`、`Direction`、`SendMessage`、`ChangeAvatar` 和 `ProfileState` 這幾個變體組成。

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## 列舉的特徵實作

在 Cairo 中，可以為自訂列舉定義並實作特徵。
這讓你能定義與列舉相關的方法和屬性。
下面是個例子，我們定義一個 `Message` 列舉，並為它實作 `Processing` 特徵：

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

以下說明如何用這個特徵來處理 `Quit` 訊息：

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

在許多情況下，列舉都很好用，尤其是在搭配 `match` 流程使用時，就像上面特徵實作裡的用法一樣。
想更深入了解 `match` 流程，請參閱 [The Cairo Book][match]。
