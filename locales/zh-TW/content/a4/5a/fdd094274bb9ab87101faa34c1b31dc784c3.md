# Null

Null 是原始型別，只有一個值：`null`。
Null 通常用來表示什麼都沒有。
Null 被視為「假值」，但與 `false` 和其他假值不同。

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## 處理 null 值

在 PHP 中，null 值常是錯誤的常見來源，因為它們經常被回傳，用來代替錯誤狀態或表示什麼都沒有。
要避免錯誤發生，通常得先「檢查 null」，確認值不是 null 之後再對它進行操作。

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

一再檢查 null 很容易出錯，因此 PHP 提供了兩個處理 null 值的運算子：null 安全存取運算子 `?->`，以及 null 合併運算子 `??`。

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
