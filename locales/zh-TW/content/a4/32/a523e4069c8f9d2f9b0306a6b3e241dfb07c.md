# 關於

## 型別別名

在 Gleam 中，型別別名可以為既有的型別取一個方便的名稱，不然原本寫起來會很麻煩。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

使用`pub type`定義的話，這個別名就能在定義它的模組之外使用。如果省略`pub`，別名就會是私有的，無法在其他模組中引用。
