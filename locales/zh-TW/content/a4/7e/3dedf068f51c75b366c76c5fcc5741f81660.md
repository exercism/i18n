# 關於

[方法多載][method-overloading]是 Java 中的一個重要概念，它讓一個類別可以有多個同名的方法，只要每個方法的參數列表不同即可。
這項功能是 Java 物件導向程式設計的基礎，提供了一種用不同型別或數量的輸入執行相似操作的方式。
方法多載提升了程式碼的可讀性與組織性，讓功能相似的方法可以共用同一個名稱。
要注意的是，多載是由方法的簽章決定，而簽章包含方法名稱與參數列表。

## 重點

- **簽章很重要**：回傳型別不屬於方法簽章的一部分，所以只改變方法的回傳型別並不構成多載。
- **參數不同**：多載的方法在參數的數量或型別上必須不同。
- **用途**：多載經常用來讓方法能以更直覺的方式搭配不同型別的輸入使用。

## 方法多載的範例

假設有一個可以將數字相加的`Calculator`類別。
多載讓不同型別的加法操作得以實現：

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## 最佳實務

- **清晰**：使用多載方法時，應該讓程式碼更直覺。
  - 多載方法的行為應該彼此相關且一致。
- **避免模糊地帶**：確保每個多載方法都有明確的用途，而且參數列表的差異足夠明顯，以免造成混淆。
- **文件**：為多載方法的每個版本撰寫適當的文件。
  - 清楚的文件能幫助其他開發者了解每個方法版本的用途與用法。
- **一致的回傳型別**：雖然多載方法的回傳型別可以不同，但通常最好盡可能保持一致，以免造成混淆。
- **節制多載**：避免過度使用方法多載。
  - 過度的多載會讓程式碼更難閱讀與維護。

## 結論

方法多載是 Java 中一項強大的功能，只要使用得當，就能大幅提升程式碼的可讀性與彈性。
它讓方法用途更廣，也更能適應不同的情境，使你的 Java 程式更加模組化、更容易維護。
