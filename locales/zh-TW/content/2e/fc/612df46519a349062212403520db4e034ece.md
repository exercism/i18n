# 簡介

## 說明

除了像`number`和`string`這類原始資料型態之外，JavaScript 還有一種重要的資料型態：`object`。
物件是鍵值對的集合。
因此，它們可以當作其他語言中常說的映射或字典來使用。

在其他語言中，映射裡的所有值通常必須是相同的資料型態。
在 JavaScript 中，只有鍵的型別受到限制：它必須是字串。
同一個物件裡的值可以有不同型別。
它們可以是像數字這樣的原始型別，也可以是陣列、其他物件，甚至是函式。
這讓物件非常有彈性，因此也是 JavaScript 中[物件導向程式設計][oop]（OOP）的核心要素。

接下來，我們會聚焦在物件作為集合或映射的用途。物件的其他用法會在其他概念中介紹，例如[類別][concept-classes]。

## 建立物件

你可以用大括號建立物件。
也可以直接放入一些項目。
做法是先寫鍵，接著是冒號和值。

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

在 JavaScript 中，最後一個項目後面的尾逗號是可有可無的。

你可能會納悶，既然鍵應該是字串，為什麼沒有用引號包起來。
這是一種簡寫語法。
如果鍵符合 JavaScript [識別碼][mdn-identifier]的命名規則，就可以省略引號。
如果鍵的名稱含有特殊字元，就必須使用一般的字串寫法。

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## 取得值

要取得某個鍵對應的值有兩種方式：點記法和方括號表示法。

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

使用點記法這種簡寫方式，和省略引號有一樣的限制。
只有在鍵符合識別碼命名規則時才能使用。
換句話說，如果你的鍵不是只由字母組成的單一詞彙，就必須使用方括號表示法。

## 新增或修改值

你可以用賦值運算子`=`來新增或修改值。
同樣地，可以使用點記法和方括號表示法。

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## 刪除項目

你可以用 `delete` 關鍵字從物件中刪除鍵值對。

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## 檢查鍵是否存在

你可以用 `hasOwnProperty` 方法檢查物件中是否存在某個鍵。

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## 用迴圈走訪物件

有一種特別的 `for...in` 迴圈可以疊代物件所有的鍵。

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

為了避免難以察覺的錯誤，你應該一律假設 `for...in` 迴圈會以任意順序走訪這些鍵。
另外要注意，`for...in` 的疊代會包含[繼承的鍵][concept-inheritance]。
