# 關於

在 Rust 中，疊代器是任何有實作 [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) trait 的值。
疊代器的值可以透過在疊代器上呼叫 `next` 方法來手動推進。

```rust
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // many built-in methods implemented
}
```

Rust 的許多 [`collections`](https://doc.rust-lang.org/std/collections/index.html) 都實作了
[`IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html)，
它能從集合的值產生一個 `Iterator`。

```rust
trait IntoIterator where Self::IntoIter: Iterator<Item=Self::Item> {
    type Item;
    type IntoIter: Iterator;
    fn into_iter(self) -> Self::IntoIter;
}
```

請注意，雖然 `IntoIterator::into_iter` 會消耗它的 `self` 型別，但那個型別不一定是自有值。
因此，[`Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-2)、
[`&'a Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator) 和
[`&'a mut Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-1) 都有 `IntoIterator` 的實作。
這些針對不同所有權程度的實作提供了實用的彈性。

理解 `traits` 對這個概念來說不是必要的，我們之後會有完整的練習讓你精通 `traits`。
現在只要記住：

- 任何實作 `IntoIterator` 的型別都稱為 _可疊代_，因為它能被轉換成疊代器。
- 任何實作 `Iterator` 的型別就是疊代器，它會_產生_值，並且可以被_疊代_。
- 你可以透過呼叫任何實作 `IntoIterator` 的型別的 `into_iter` 方法，從中取得疊代器。
- 每一個疊代器都[實作了 `IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html#impl-IntoIterator-25)，並且會產生它自己。
- `for` 迴圈總是作用在疊代器上，並對它們的範圍引數隱式呼叫 `IntoIterator`。

## `into_iter` 與 for 迴圈

你大概對向量上的 for 迴圈很熟悉：

```rust
// lor is a `Vec`, which implements `IntoIterator`
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
for people in &lor {
    println!("{people}");
}
```

從根本上來說，`for` 迴圈只是呼叫其引數的 `into_iter` 方法，
然後不斷呼叫 `next()` 直到不再產生項目為止的簡寫。換句話說，前面的迴圈可以解糖為：

```rust
{
    let mut iterator = (&lor).into_iter();
    while let Some(people) = iterator.next() {
        println!("{people}");
    }
}
```

## `iter` 與 `iter_mut` 方法

大多數 Rust 集合型別都提供 `iter` 和 `iter_mut` 方法。
對於型別為 `T` 的集合，這兩個方法按慣例會執行以下操作：

- `iter` 回傳的疊代器會產生不可變借用的 `&T`。
- `iter_mut` 回傳的疊代器會產生可變借用的 `&mut T`。

```rust
let mut v = vec![1, 2, 3];

// Using `iter` method
let mut iterator = v.iter();
assert_eq!(iterator.next(), Some(&1));
assert_eq!(iterator.next(), Some(&2));
assert_eq!(iterator.next(), Some(&3));
assert_eq!(iterator.next(), None);

// Using `iter_mut` method
for value in v.iter_mut() {
     *value *= *value;
}
println!("{v:?}");
// => [1, 4, 9]
```

## `iter`、`iter_mut` 與 `into_iter` 的差異

如果 `iter`、`iter_mut` 和 `into_iter` 都會產生疊代器，它們之間有什麼差異？

- `iter` 回傳的疊代器慣例上會產生不可變借用的 `&T`。
- `iter_mut` 回傳的疊代器慣例上會產生可變借用的 `&mut T`。
- `into_iter` 回傳的疊代器可能會產生 `T`、`&T` 或 `&mut T`，取決於它的情境。

`into_iter` 呼叫時的情境是什麼？
它的 `self` 型別。
回想一下，`Vec`、`&'a Vec` 和 `&'a mut Vec` 都有 `IntoIterator` 的實作。
因此：

- `(&v).into_iter()` 等同於 `v.iter()` => 回傳 `&T`
- `(&mut v).into_iter()` 等同於 `v.iter_mut()` => 回傳 `&mut T`
- `v.into_iter()` => 回傳 `T` 並移動這些值

這在 for 迴圈中最為明顯：

- `for num in &v {...}` => 繫結 `&T`
- `for num in &mut v {...}` => 繫結 `&mut T`
- `for num in v {...}` => 繫結 `T` 並移動這些值

撰寫 `v.iter()` 通常會比 `(&v).into_iter()` 更清楚。
因此，基於使用上的便利性，我們會偏好 `iter` 和 `iter_mut` 而不選 `into_iter`。

## 使用疊代器的內建方法

疊代器提供許多內建方法，例如 `map`、`filter`、`collect`。
這些方法有時會與閉包搭配使用。

`map` 使用閉包來轉換疊代器的值。
`take` 將（可能是無限的）疊代器截斷為在最多指定數量的項目後就終止的疊代器。

```rust
for even_number in (0..).into_iter().map(|x| x * 2).take(4) {
    let odd_number = even_number + 1;
    println!("{even_number} => {odd_number}");
}
// 0 => 1
// 2 => 3
// 4 => 5
// 6 => 7
```

`filter` 將疊代器轉換為只回傳閉包評估為 `true` 的那些值的疊代器。
`count` 會消耗疊代器，回傳產生的項目數量。

```rust
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
let short_people = ["Dwarves", "Hobbits"];
let num_tall_people = lor.iter().filter(|people| !short_people.contains(people)).count();
assert_eq!(num_tall_people, 5);
```

`flat_map` 透過提供的閉包將每個項目轉換為新的疊代器來轉換疊代器，
然後將所有產生的新疊代器串接起來攤平。
`collect` 會產生新的集合，
只要該集合型別有實作 [`FromIterator`](https://doc.rust-lang.org/std/iter/trait.FromIterator.html)。

```rust
let words = ["alpha", "beta", "gamma"];
// chars() returns an iterator
let merged: String = words.iter()
                          .flat_map(|s| s.chars())
                          .collect();
assert_eq!(merged, "alphabetagamma");
```

[`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html) 提供了_許多_這類實用的疊代器轉換；
值得閱讀文件並熟悉它們。

## 惰性

重要的是要知道 Rust 的疊代器是惰性的：
在我們消耗疊代器之前，它們不會產生任何值。
如果你撰寫並執行以下程式碼：

```rust
(0..5).map(|x| x * x);
```

你會得到以下編譯器錯誤：

```rust
 --> src/main.rs:2:5
  |
2 |     (0..5).map(|x| x * x);
  |     ^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: `#[warn(unused_must_use)]` on by default
  = note: iterators are lazy and do nothing unless consumed
```

這是因為 `map` 是回傳另一個疊代器的配接器方法。

要消耗疊代器，可以使用 `for` 迴圈，或使用會產生本身不是疊代器的某個值的疊代器方法。

例如，`collect` 是消費者方法（它的函式簽章不回傳疊代器，而是回傳泛型型別）：

```rust
//         Iterator   Adaptor        Consumer
//                |      |               |
let v: Vec<_> = (0..5).map(|x| x * x).collect();
```
