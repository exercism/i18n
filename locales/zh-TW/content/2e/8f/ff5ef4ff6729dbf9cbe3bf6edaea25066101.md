# 關於

[Emacs Lisp](https://www.gnu.org/software/emacs/manual/) 是 Emacs 的核心語言。Emacs 是極具代表性的文字編輯器，也是自由軟體運動的起點。
Emacs 由超過一百萬行的 Emacs Lisp 組成，而在 Emacs 裡執行的所有應用程式（各種程式語言的整合開發環境、遊戲、規劃工具等）都是用 Emacs Lisp 寫成的。
使用者的偏好設定同樣是一串串 Emacs Lisp 運算式。

認識 Emacs Lisp，是踏入 Lisp 的第一步。Lisp 是至今仍在使用、第二古老的程式語言（2018 年剛滿 60 歲），也仍影響著許多其他程式語言。

[引述 Emacs 創作者的話](https://www.gnu.org/gnu/rms-lisp.html)：
「Multics Emacs 非常成功，撰寫新的編輯指令實在太方便，連他辦公室的秘書都開始學著使用。他們用了一本別人寫的手冊，手冊示範了如何擴充 Emacs，卻沒說這是在寫程式。所以那些原本認為自己不會寫程式的秘書並沒有被嚇跑。他們讀了手冊，發現自己也能做出有用的東西，於是學會了寫程式。」
