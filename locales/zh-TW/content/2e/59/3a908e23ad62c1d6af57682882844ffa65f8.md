# 簡介

雖然`readonly`修飾詞可以防止欄位中的值或參考遭到覆寫，但它對參考型別的成員並沒有任何保護作用。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

若要確保參考型別的所有成員都受到保護，可以把欄位設為`readonly`，並定義不含`set`存取子的自動屬性。

基底類別庫（Base Class Library，BCL）針對需要防止集合成員被更新的情況，提供了一些集合的唯讀版本。這些版本以包裝的形式提供：

- `ReadOnlyDictionary<T>`會以唯讀方式公開`Dictionary<T>`。
- `ReadOnlyCollection<T>`會以唯讀方式公開`List<T>`。
