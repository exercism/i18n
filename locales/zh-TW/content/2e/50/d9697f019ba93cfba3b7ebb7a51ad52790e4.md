# 簡介

在 F# 中，把值指定給一個名稱稱為_繫結_。繫結是不可變的，因此它們類似於其他程式語言中的常數。由於 F# 是靜態型別的語言，每個繫結在編譯期都帶有型別。

繫結是使用`let`關鍵字定義的。對大多數繫結來說，指定型別是選用的，因為 F# 的_型別推斷_通常可以根據繫結的值推斷出型別。一個繫結看起來像這樣：

```fsharp
// Automatically inferred type
let fingers = 10
```

函式也是一般的繫結，只是帶有一或多個參數。函式會自動回傳它的最後一個運算式。型別推斷對大多數函式也適用，它會分析函式被呼叫時傳入什麼值，以及函式回傳什麼值。

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

呼叫函式時，要指定函式的名稱，並為函式的每個參數傳入引數。

```fsharp
let five = add 2 3
```

如果繫結的型別無法推斷，編譯器會回報錯誤。要修正這個問題，請為繫結加上明確的型別標註。

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F# 中的繫結只能在定義_之後_使用。在繫結定義之前就使用它，會導致編譯錯誤。

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# 使用有意義的空白來定義作用域。這表示作用域是相對於宣告繫結的那一行，用空格縮排程式碼來定義的。預設慣例是使用 4 個空格縮排：

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F# 的繫結（其中也包含函式）通常會組織在模組裡。模組會把相關的功能集結在一起，並使用`module`關鍵字定義。模組定義必須放在它的繫結之前：

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# 支援兩種註解。單行註解以`//`開頭，多行註解則插入在`(*`和`*)`之間。
