# 說明補充

## 例外訊息

有時我們需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。當你這麼做時，應該一律附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓程式碼更好讀，對除錯也有很大的幫助。如果你知道錯誤來源會是某種類型，可以選擇引發其中一種[內建錯誤類型](https://docs.python.org/3/library/exceptions.html#base-classes)，但還是應該附上有意義的訊息。

這道練習要求你在 `board()` 函式收到格式錯誤的輸入時，使用 [`raise` 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「拋出」`ValueError`。只有同時 `raise` 這個 `exception` 並附上訊息，測試才會通過。

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception` 型別的引數：

```python
# when the board receives malformed input
raise ValueError("The board is invalid with current input.")
```
