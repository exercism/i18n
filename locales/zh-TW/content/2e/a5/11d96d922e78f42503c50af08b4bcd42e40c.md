# 說明

在這個練習中，你將撰寫程式碼，追蹤你在 Exercism 上想學習的程式語言陣列。

這個練習有六個任務，全都和處理陣列有關。

## 1. 建立新的陣列

為了追蹤你想學習的程式語言，你需要建立一個新的陣列。定義`new_list`函式，回傳一個全新的空陣列。

```gleam
new_list()
// -> []
```

## 2. 定義既有的陣列

目前你有一張紙，上面寫著你想學習的程式語言：Gleam、Go 和 TypeScript。定義`existing_list`函式來回傳這個陣列。

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. 在陣列中加入新的程式語言

當你在 Exercism 上探索，發現更多有趣的程式語言時，你會想把它們加進你的陣列。實作`add_language`函式，把新的程式語言加到陣列的最前面。

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. 計算陣列中的程式語言數量

一個一個數程式語言很不方便。實作`count_languages`函式，計算陣列中有多少個程式語言。

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. 反轉陣列

某個時刻，你會發現你的陣列其實是反過來的！實作`reverse_list`函式來反轉你的陣列。

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. 檢查陣列是否令人興奮

雖然你喜歡所有的程式語言，但 Gleam 在你心中有個特別的位置。因此，如果符合以下條件，你就會對一串程式語言感到非常興奮：

- 陣列中的第一個是 Gleam。
- 陣列中的第二個項目是 Gleam，且該陣列包含兩個或三個程式語言。

實作`exciting_list`函式，檢查一串程式語言是否令人興奮：

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
