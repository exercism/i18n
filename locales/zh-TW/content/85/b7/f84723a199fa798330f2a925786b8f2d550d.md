# 說明

在這個練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出美味的千層麵。
這個練習共有四個任務，全都和烹煮千層麵所花的時間有關。

## 1. 定義千層麵在烤箱裡的預期時間（分鐘）

定義`expectedMinutesInOven`常數，用來儲存千層麵應該待在烤箱裡幾分鐘。
根據食譜，預期的烤箱時間是 40 分鐘：

```swift
expectedMinutesInOven
// Returns 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remainingMinutesInOven(elapsedMinutes:)`函式，它接受`elapsedMinutes`引數，這個引數存放千層麵已經在烤箱裡待了幾分鐘。
這個函式應該根據前一個任務算出的預期烤箱時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. 計算準備時間（分鐘）

定義`preparationTimeInMinutes(layers:)`函式，它接受`layers`引數，這個引數存放你加到千層麵裡的層數。
這個函式應該回傳你準備千層麵花了幾分鐘，假設每準備一層要花 2 分鐘。

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. 計算總工作時間（分鐘）

定義`totalTimeInMinutes(layers:elapsedMinutes:)`函式，它接受兩個引數：`layers`參數是你加到千層麵裡的層數，`elapsedMinutes`參數則是千層麵已經在烤箱裡待了幾分鐘。
這個函式應該回傳你烹煮千層麵總共花了幾分鐘，也就是準備時間（分鐘）加上千層麵目前待在烤箱裡的時間（分鐘）。

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
