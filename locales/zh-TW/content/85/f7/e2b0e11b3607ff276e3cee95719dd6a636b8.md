# 測試

## 執行測試

要執行測試，請執行以下指令：

```bash
dotnet test
```

## 解出練習

解出一個練習，代表讓它的所有測試都通過。預設情況下，當你執行測試時，只會執行一個測試（第一個）。這是刻意的，這樣你就能專注在讓那一個測試通過。一旦它通過了，你就可以從測試的`[<Fact>]`或`[<Theory>]`屬性中移除`Skip = "Remove this Skip property to run this test"`，來啟用下一個測試。當所有測試都啟用，而你的實作讓它們全部通過時，你就解出這個練習了！

為了幫助你起步，每個練習都會附上一份雛形實作檔。你可以用這個檔案作為建立解答的起點。如果你覺得移除或修改這個檔案是對的，儘管去做吧。

## 使用套件

大部分練習應該都不需要用到任何外部套件就能解出。不過，如果你真的想在某個練習裡使用外部套件，可以執行以下指令把它加到你的專案中：

```bash
dotnet add package [package-name]
```
