不過情況有點雜亂：Azara 的座標格式和排序方式似乎和 Rui 的不一樣，他們得不斷在兩份清單之間來回查看，才能弄清楚哪些寶物對應哪些地點。
身為剛開始學 Julia 的程式設計者，他們來找你幫忙寫個小程式（其實是一組函式），好把尋寶資訊整理得更有條理。

## 1. 擷取座標

實作`get_cooordinate()`函式，它會接收 Azara 清單中的一組`(treasure, coordinate)`配對，並只回傳擷取出的地圖座標。

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. 格式化座標

實作`convert_coordinate()`函式，它會接收格式為 "2A" 的座標，並回傳格式為`('2', 'A')`的元組。

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. 比對座標

實作`compare_records()`函式，它會接收一組`(treasure, coordinate)`配對和一筆`(location, coordinate, quadrant)`記錄，並比較兩者的座標。
如果座標「相符」就回傳**`true`**，不相符就回傳**`false`**。
為了精確比較，請視需要重新格式化座標。

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. 合併相符的記錄

實作`create_record()`函式，它會接收 Azara 清單中的一組`(treasure, coordinate)`配對和 Rui 清單中的一筆`(location, coordinate, quadrant)`記錄，並在**座標相符**時回傳`(coordinate, location, quadrant, treasure)`。

如果座標_不_相符，就回傳空的元組。
為了精確比較，請視需要重新格式化座標。

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
