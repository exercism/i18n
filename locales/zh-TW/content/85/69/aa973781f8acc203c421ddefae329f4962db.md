# 簡介

## 數字

Java 中有兩種不同的數字型別：

- 整數：小數點後沒有任何位數的數字（整數）。
  例如`-6`、`0`、`1`、`25`、`976`和`-500000`。
- 浮點數：小數點後有零或多位數字的數字。
  例如`-20.4`、`0.1`、`2.72`、`16.984025`和`1024.0`。

Java 中最常見的兩種數值型別是`int`和`double`。
`int`是 32 位元的整數，而`double`是 64 位元的浮點數。

算術運算使用標準的算術運算子來進行。
數字可以使用標準的數值比較運算子（例如`5 > 4`和`4 <= 5`），以及相等（`==`）與不相等（`!=`）運算子來比較。

Java 有兩種數值轉換：

1. 隱式轉換：不會遺失任何資料，也不需要額外的語法。
2. 顯式轉換：可能會遺失資料，且需要以_轉型_形式提供的額外語法。

由於`int`的精確度低於`double`，所以從`int`轉換成`double`是安全的，因此屬於隱式轉換。
然而，從`double`轉換成`int`可能會遺失資料，所以需要顯式轉換。

## If-Else 敘述

### _if-then_ 敘述

Java 中最基本的控制流程敘述是 _if-then_ 敘述。
這個敘述只會在特定條件為`true`時執行某一段程式碼。
_if-then_ 敘述是用`if`子句定義的：

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

在上面的例子中，如果車子沒油了，呼叫`Car.drive`方法不會有任何作用。

### _if-then-else_ 敘述

_if-then-else_ 敘述提供另一條執行路徑，用於`if`子句中的條件結果為`false`時。
這條替代的執行路徑接在`if`子句之後，並使用`else`子句定義：

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

在上面的例子中，如果車子沒油了，呼叫`Car.drive`方法會呼叫另一個方法來停下車子。

_if-then-else_ 敘述也可以透過`else if`子句支援多個條件：

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

在上面的例子中，當燃料小於或等於`5`時開車，車子會繼續行駛，但會亮起燃料燈。
當燃料降到`0`時，車子就會停下來。
