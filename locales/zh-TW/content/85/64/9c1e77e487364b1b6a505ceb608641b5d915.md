# 說明

在這個練習中，你將撰寫程式碼，幫助一位自由工作者與客戶溝通某些專案的價格。
你將撰寫幾個工具函式，快速計算客戶所需的費用。

```exercism/note
`ratePerHour`變數和`dayRate`函式都與金錢有關。
它們的測量單位是每單位時間的金額：分別為小時和天。
```

## 1. 根據每小時費率計算日費率

一位客戶聯絡這位自由工作者，詢問他們的費率。
這位自由工作者說明他們**_每天工作 8 小時。_**
然而，這位自由工作者只知道他們在這個專案上的每小時費率。
請幫他們根據每小時費率估算日費率。

```javascript
dayRate(89);
// => 712
```

日費率不需要取整，也不需要改成「固定」精度。

## 2. 根據固定預算計算工作天數

另一天，一位專案經理向這位自由工作者提議，以固定預算承接一個專案。
請根據固定預算和這位自由工作者的每小時費率，幫他們計算在預算用完之前可以工作幾天。
結果_必須_**無條件捨去**到最接近的整數。

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. 計算大型專案的折扣費率

這位自由工作者的客戶經常雇用他們進行橫跨數個月的專案。
在這些情況下，這位自由工作者決定為每個完整月份提供折扣，其餘天數則按日費率計費。
由於你的工作與生活平衡絕佳，每個日曆月只工作 22 天，所以**_每個月有 22 個可計費天數。_**
請根據每小時費率、專案包含的可計費天數以及每月折扣費率，幫他們估算這類專案的成本。
折扣一律以數字傳入，其中`42%`會變成`0.42`。結果_必須_**無條件進位**到最接近的整數。

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
