# 簡介

*disposable* 是指任何持有作業系統資源的東西，例如已開啟的檔案、通訊端，或以雜湊表實作的鎖；用完之後就必須把它釋放。Factor 的[`destructors`][destructors]詞彙把這些資源包進一個小型框架，因此即使例外讓堆疊回溯，清理工作依然會發生。

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` 會帶著這個資源執行引述，並在離開時將它處置。如果要處理多個資源，可以用 `with-destructors` 開啟一個作用域，並用 `&dispose`（正常離開時處置，*發生錯誤時也*處置）或 `|dispose`（只在發生錯誤時處置）逐一註冊。

類別只要擴充 `disposable` 並實作 `dispose*` 這個泛型詞，就能加入這個框架；框架對每個物件只會呼叫它一次。呼叫者所使用的公開詞是 `dispose`。

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
