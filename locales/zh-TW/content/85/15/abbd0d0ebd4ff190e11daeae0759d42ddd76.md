# 指令補充

## 暫存器

| 暫存器   | 用途         | 型態    | 說明                                   |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | 輸入         | 位址    | 第一個顏色，以 null 結尾的字串         |
| `$a1`    | 輸入         | 位址    | 第二個顏色，以 null 結尾的字串         |
| `$a2`    | 輸入         | 位址    | 第三個顏色，以 null 結尾的字串         |
| `$a3`    | 輸入/輸出    | 位址    | 以 null 結尾的輸出字串                 |
| `$t0-9`  | 暫時         | 任意    | 用於暫時儲存                           |
