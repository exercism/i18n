# 指令

你在研究站負責安全櫃檯。員工身上配戴*識別證*，識別證上的代碼有嚴格的格式；存取日誌裡到處都是混雜在一般文字中的這類代碼，而日誌必須先清理過才能分享出去。正規表示式正是處理這些工作的好工具。

有效的識別證代碼是**兩個大寫字母、一個連字號，接著四個數字**，例如`NS-1024`。

## 1. 檢查識別證代碼

定義`valid-badge?`，它接受一個識別證字串，當*整串*字串是有效的識別證代碼時回傳`t`，否則回傳`f`。

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. 從一行日誌中取出每個代碼

定義`badge-codes`，它接受存取日誌中的一行，並依序回傳其中出現的所有識別證代碼所組成的序列。

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. 計算代碼中的數字個數

定義`digit-count`，它接受一個字串，回傳其中包含多少個數字。

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. 遮蔽密碼

日誌列有時會把密碼記錄成`pass=`後面接著密碼本身（任何一串非空白字元）。定義`redact`，它接受一行文字，回傳將每個這類密碼都替換成`pass=****`的結果。

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
