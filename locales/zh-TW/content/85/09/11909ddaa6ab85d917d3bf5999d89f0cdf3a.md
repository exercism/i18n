# 關於

字元陣列是使用`~c` Sigil 建立的。

```elixir
~c"hello"
```

~~~~exercism/note
請注意，在較舊版本的 Elixir 中，字元陣列是以單引號`'hello'`表示的。
~~~~

字元陣列是由整數組成的陣列。這些整數代表某個字元的 Unicode 值，也就是所謂的碼位。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## 字元陣列_就是_陣列

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

因為字元陣列就是陣列，你可以像處理其他陣列一樣使用它們：透過遞迴與模式比對，或是使用[`List`][list]模組。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

你可以使用[`++`][kernel-concat-list]把兩個陣列串接起來。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

第一個陣列越長，串接就越慢，所以請避免反覆在任意長度的陣列尾端附加元素。

## 可列印性

如果一個整數陣列裡的整數全都是可列印字元的碼位，它就會以字元陣列的形式顯示，即使它是用`[]`語法定義的也一樣。

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

如果一個整數陣列裡只要包含一個不可列印字元的碼位（例如`0-6`、`14-26`、`28-31`），它就會以陣列的形式顯示，即使它是用`~c""`語法定義的也一樣。

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

可以用[`List.ascii_printable?`][list-ascii-printable]來檢查可列印性。

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

請記住，那只是_顯示_同一份資料的兩種不同方式，這些值是完全相等的。

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

使用[`IO.inspect`][io-inspect]列印陣列時，你可以用[`:charlists`][inspect-opts]選項來控制陣列的列印方式。

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## 碼位

在字元前面加上`?`，就能取得它的碼位。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## 字元陣列與字串

由相同字元組成的字元陣列和字串，並不被視為相等。

```elixir
~c"hello" == "hello"
false
```

字元陣列裡的每個值都是[字元的 Unicode 碼位][unicode-table]，而在字串裡，這些碼位則以 [UTF-8][utf8] 編碼。

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

注意`ü`這個碼位為`252`的字元，在 UTF-8 中是如何被編碼成`195`和`188`的。

**實際上，字元陣列很少被使用**。它主要的用途是與 Erlang 介接，尤其是在使用不接受 binary 作為引數的舊程式庫時。

使用 Elixir 時，**請用字串來儲存文字**。`String`模組提供許多處理文字的函式，這些函式並不適用於字元陣列。

字元陣列可以用[`to_string`][kernel-to-string]轉換成字串。

```elixir
to_string(~c"hello")
# => "hello"
```
