# 簡介

## Struct 型別

我們已經看過 struct 型別了；簡單回顧一下，`struct` 是由具名元素組成的序列，這些元素稱為_欄位_，每個欄位都有自己的名稱和型別。欄位的名稱在 struct 內必須是唯一的。Struct 可以對比物件導向程式設計範式中的_類別_。

你可以使用`type`和`struct`關鍵字建立新的 struct，然後像下面範例這樣，明確地定義各欄位的名稱和型別。

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 非 struct 型別

你也可以定義非 struct 型別，把它當作內建型別宣告的別名。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

你也可以定義由陣列和 map 組成的非 struct 型別。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
