# 關於

Elixir 的[字串][getting-started-strings]以雙引號包住，並採用 UTF-8 編碼：

```elixir
"Hi!"
```

字串可以用 [`<>/2`][kernel-concat]運算子連接起來：

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir 的字串支援使用`#{}`語法的[字串內插][string-interpolation]：

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

內插裡頭可以放任何合法的 Elixir 運算式。如果放進去的是一個字串，就會直接把它內插進去；如果放進去的是其他任何值，Elixir 會試著把它轉成字串。

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir 在`String`模組裡提供了許多處理字串的函式。如果你不確定該怎麼用自己需要的方式來處理字串，記得去瀏覽一下 [`String`模組中提供的函式][string-module-functions]，你很可能就會找到需要的東西。

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

使用其中一些函式時，請記得字串中第一個字元的索引是`0`。

有些字元必須[跳脫][escape-characters]才能放進字串裡，例如換行、雙引號，或是`#`字元：

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

如果要輕鬆處理含有大量換行的文字，改用[三重雙引號 heredoc 語法][heredoc-syntax]會更順手喔：

```elixir
"""
1
2
3
"""
```

你經常會看到這種語法被用來為程式碼撰寫文件：

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
