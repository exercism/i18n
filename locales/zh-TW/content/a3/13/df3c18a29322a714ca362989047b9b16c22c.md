# 函式

在 JavaScript 裡，函式是_一級物件_，這代表它們可以被指定給變數和屬性、傳遞給其他函式，也能從函式中回傳。它們和任何其他_物件_一樣，可以擁有屬性和方法。

## 輸入：傳遞引數

JavaScript 函式讓你在呼叫時傳入引數。引數一律[以傳值方式傳遞](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7)。換句話說，如果函式在內部重新指定了一個參數，函式外的值不會跟著改變。但這並不代表傳入的物件不能被修改。

> [!TIP]
> 傳入物件時，傳入的是指向該物件之參考的「值」。這讓人_覺得_傳入物件的處理方式不太一樣，但其實並不是這樣。

以下是一個接受兩個引數並將它們相乘的函式範例：

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 輸出：回傳值

JavaScript 可以使用 `return` 關鍵字，後面接著一段運算式，從函式回傳單一的值。當函式沒有回傳任何東西時，回傳的值會是 `undefined`。

以下是會回傳值的函式範例：

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 定義函式

JavaScript 中有四種不同形式的函式：

1. 一般函式：可以回傳任何東西，而且一定會執行到結束；
2. 非同步函式：一律回傳 `Promise`，而且可以透過 `await` 運算子暫停與恢復；
3. 產生器函式：一律回傳 `Generator` 物件，而且可以透過 `yield` 運算子暫停與恢復；
4. 非同步產生器函式：一律回傳 `AsyncGenerator` 物件，而且可以同時透過 `yield` 和 `await` 兩個運算子暫停與恢復。

這四種形式的函式，各自有三種定義方式：

1. 使用宣告
2. 使用運算式
3. 使用建構子

最後，還有一些特殊語法用來定義_箭頭函式和方法_。
