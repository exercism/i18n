# 說明

在這道練習裡，你需要把經典遊戲 Pac-Man 的幾條規則翻譯成 Unison 函式。

一共有四條規則要翻譯，全都跟遊戲狀態有關。

> 別擔心引數是怎麼來的，只要專注在組合這些引數、回傳預期的結果就好。

## 1. 定義 Pac-Man 是否吃掉幽靈

定義`pacmanRules.eatGhost`函式，它接受兩個引數（_Pac-Man 是否有能量球作用中_ 和 _Pac-Man 是否碰到幽靈_），並回傳一個布林值，表示 Pac-Man 是否能吃掉幽靈。這個函式應該只在 Pac-Man 有能量球作用中且碰到幽靈時回傳 true。

```unison
pacmanRules.eatGhost: Boolean -> Boolean -> Boolean

```


## 4. 定義 Pac-Man 是否獲勝

定義`pacmanRules.win`函式，它接受三個引數（_Pac-Man 是否已經吃掉所有豆子_、_Pac-Man 是否有能量球作用中_，以及 _Pac-Man 是否碰到幽靈_），並回傳一個布林值，表示 Pac-Man 是否獲勝。如果 Pac-Man 已經吃掉所有豆子，而且根據第 3 部分定義的引數判斷並沒有輸掉，這個函式就應該回傳 true。
