# 說明

在這個練習中，你將實作一款角色扮演遊戲的機制。
玩家的角色由以下型別表示：

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

遊戲中的玩家必須達到 10 級，才能解鎖法力池，進而開始施放咒語。
你將在這款遊戲中實作兩項功能：復活機制和施放咒語的機制。

## 1. 自我介紹

撰寫 `introduce` 函式的內容。
請注意，`Player` 記錄的 `Name` 欄位是 `Option`。
善於潛行的玩家可能會想把名字設為 `None` 來隱藏身分，這類玩家的自我介紹會是 `"Mighty Magician"`。
否則，就用你自己的名字來自我介紹即可。

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. 實作復活機制

`revive` 函式應該檢查玩家的角色是否確實已經死亡（生命值降到 0）。
如果是，它應該回傳一個生命值為 100 的新 `Player` 實例。
否則，如果玩家的角色還沒死，`revive` 函式會回傳 `None`。

如果玩家的等級在 10 以上，復活後也應該擁有 100 點法力。
如果玩家的等級低於 10，其法力應該是 `None`。
`revive` 函式應該保留玩家的等級。

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

如果對生命值為 1 以上的玩家呼叫 `revive` 方法，函式應該回傳 `None`。

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. 實作施放咒語機制

`castSpell` 函式接受的引數包括一個表示咒語法力消耗量的 `int`，以及一個 `Player`。
它會回傳更新後的玩家，以及所施放咒語造成的傷害量。
成功施放咒語造成的傷害，等於該咒語法力消耗量的兩倍。
不過，如果玩家的法力不足，什麼都不會發生：玩家維持不變，也不會造成任何傷害。
如果玩家甚至沒有法力池，嘗試施放咒語時必須依咒語的法力消耗量扣減其生命值，且不會造成傷害。

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
