# 簡介

Elixir 程式碼是在 BEAM 虛擬機上執行的。BEAM 是 Erlang Run-Time System 的一部分。Elixir 受到 Erlang 啟發，又和它共用執行環境，因此能與 Erlang 函式庫有很好的互通性。這表示 Elixir 開發者可以在自己的 Elixir 程式碼裡使用 Erlang 函式庫。事實上，對於 Erlang 函式庫已經提供的功能，Elixir 社群並不鼓勵再用 Elixir 另外寫一份函式庫。

因此，某些功能（例如數學運算或計時器函式）在 Elixir 中只能透過 Erlang 取得。

Erlang 的標準函式庫可以直接在我們的 Elixir 程式碼中使用，不需要任何額外的步驟。

呼叫 Erlang 函式的方式和呼叫 Elixir 函式一樣，只有一個小小的差別：Erlang 的模組名稱是 `snake_case` 的原子。舉例來說，如果要從 `math` 模組呼叫 Erlang 的 `pi/0` 函式，可以這樣寫：

```elixir
:math.pi()
# => 3.141592653589793
```

最常用、而且在 Elixir 裡沒有對應版本的 Erlang 函式有：

- `:timer.sleep/1`：暫停一個行程，時間為指定的毫秒數。
- `:rand.uniform/0`：產生一個隨機浮點數`x`，其中`0.0 <= x < 1.0`。
- `:io_lib.format/2`：提供 C 風格的格式化字串功能（使用控制序列）。用這個函式，我們可以把整數以 2 到 36 之間的任意進位印出，或是把浮點數格式化成想要的精確度。要注意的是，這個函式和許多 Erlang 函式一樣，會回傳一個 charlist。
- `math` 模組：提供各種數學函式，例如 `sin/1`、`cos/1`、`log2/1`、`log10/1`、`pow/2` 等等。

想認識 Erlang 的標準函式庫，可以看看 [STDLIB 參考手冊][erl-stdlib-ref]。

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
