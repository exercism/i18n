# 簡介

## 匯入

Swift 的 Standard Library 提供豐富的功能，而你可以透過匯入外部函式庫和框架，使用更多額外的功能。
這些模組可能直接來自 Swift 專案（例如 [Swift Argument Parser][argument-parser]）、來自 Apple 平台框架（例如 [Foundation][apple-foundation] 和 [Network Framework][network-framework]），或來自第三方開源函式庫（例如 [SwiftyBeaver][swifty-beaver]）。

像 Foundation 這類核心模組，也就是 Swift 中最廣泛使用的函式庫之一，會隨 Swift 工具鏈一起提供。
第三方函式庫必須先加入專案設定（例如使用 Swift Package Manager），才能匯入。

匯入模組的方式是寫下`import`關鍵字，後面接著模組名稱。
所以只要在程式裡加入以下內容，就能匯入 Foundation。

```swift
import Foundation
```

匯入模組後，你的程式碼就能使用它的型別、方法和函式。
例如，匯入 Foundation 會為`String`增加像`components(separatedBy:)`這樣實用的工具方法。

按照慣例，`import`敘述會放在 Swift 檔案的開頭，讓任何閱讀程式碼的人都能馬上看到相依項目。

## 字串索引

`String`中的個別字元可以像陣列一樣，使用下標取值的方式來存取。
不過，字串使用的[索引][string-indices]並_不是_整數，無法直接操作。
而是必須根據其他已知的索引計算出來，例如`startIndex`，它指向非空字串中第一個字元的位置，而且要用 [`String`][string-docs] 和 [`NSString`][nsstring-docs] 函式庫提供的方法（匯入`Foundation`模組後，Swift 的字串就能使用所有 NSString 的屬性和方法）。

例如，假設有下列字串：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

你無法寫`csv[21]`來取得「orange」裡的「g」，必須改為計算一個`String.Index`型別的值，並以該索引取代。
注意，這些索引本身並不是設計給人直接閱讀的。
它們就是所謂的_不透明索引_，因為人類不需要知道裡面是什麼。

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

不過要注意，如果偏移量不是有效的索引，也就是說，如果算出來的索引在`startIndex`之前或`endIndex`之後，這個操作就會引發錯誤，導致程式崩潰。
為了避免這個問題，你可以指定一個限制索引。
這會回傳一個可選的索引，對於原本無效的索引則會回傳 nil。

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

此外，索引不能在不同字串之間共用。
例如，用上面算出的「orange」中「g」的`index`去索引字串`fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`，也就是`fam[index]`，會讓程式崩潰。

這一切背後有很多原因，但基本上都歸結為一句話：「Unicode 很棘手」。

一般來說，如果你需要隨機存取個別字元，你大概應該改用其他資料結構，例如`Array<Character>`。

### 一些實用的方法

Swift 有`first`和`last`兩個方法，可以取得字串的第一個和最後一個字元。
這些方法會回傳可選的字元，所以如果字串是空的，就會回傳 nil。

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

你也可以用`prefix`和`suffix`方法取得字串的子字串。
這些方法接受一個整數作為引數，並回傳包含字串前 n 個或後 n 個字元的子字串。

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## 字串方法

處理文字是程式設計中常見的工作。
Swift 與 Foundation 框架提供了許多方便的方法和屬性，用來檢視、轉換和操作字串。

## 使用`components(separatedBy:)`分割字串

要根據分隔符號把字串分割成子字串陣列，請使用`components(separatedBy:)`（需要匯入 Foundation）：

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## 使用`hasPrefix(_:)`和`hasSuffix(_:)`檢查前綴和後綴

要檢查字串是否以特定的字元序列開頭或結尾，請使用`hasPrefix(_:)`和`hasSuffix(_:)`：

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## 改變大小寫

你可以用這些標準方法和屬性來轉換字串的大小寫：

- `lowercased()`：回傳字串的小寫副本。
- `uppercased()`：回傳字串的大寫副本。
- `capitalized`：回傳每個單字首字母大寫的副本（來自 Foundation）。

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## 使用`replacingOccurrences(of:with:)`取代子字串

要用另一個字串取代目標子字串的所有出現處，請使用`replacingOccurrences(of:with:)`（來自 Foundation）：

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## 使用`joined(separator:)`連接字串

`joined(separator:)`方法屬於字串的集合，例如`[String]`。
它會用分隔符號把元素連接成單一字串：

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
