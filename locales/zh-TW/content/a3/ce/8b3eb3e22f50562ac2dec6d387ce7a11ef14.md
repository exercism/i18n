# 說明

你是個熱衷的賞鳥者，會記錄過去七天裡有多少隻鳥飛進你的花園。

你有六個任務，全都和飛進花園的鳥的數量有關。

## 1. 檢查上週的紀錄是多少

為了方便比較，你總會把上週的紀錄放在手邊，那些數字是：0、2、5、3、7、8 和 4。建立一個包含上週紀錄的向量：

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. 檢查今天有多少隻鳥來訪

實作`today`函式，回傳今天有多少隻鳥飛進你的花園。鳥的數量依日期排序，第一個元素是最早那天的數量，最後一個元素則是今天的數量。

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. 增加今天的數量

實作`inc-bird`函式來增加今天的數量：

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. 檢查是否有一天沒有鳥來訪

實作`day-without-birds?`這個述詞函式；如果有一天沒有任何鳥飛進花園，就回傳`true`，否則回傳`false`：

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. 計算前幾天來訪鳥數的總和

實作`n-days-count`函式，回傳從這週開始飛進花園的鳥的數量，但只計算從這週開始算起指定的天數。

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. 計算忙碌的天數

有些日子比其他日子忙。只要一天有五隻以上的鳥飛進你的花園，就算忙碌的一天。
實作`busy-days`函式，回傳忙碌的天數：

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. 檢查是否為奇數週

過去一年來，你發現有些星期會呈現相同又奇特的模式，數量會在一和零之間交替。實作`odd-week?`函式，如果這週的鳥數模式符合這個奇數模式，就回傳`true`：

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
