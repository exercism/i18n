# 關於

字典就像其他語言中的對應結構（例如 map 或關聯式陣列）一樣，會儲存鍵／值對，只要把鍵傳給字典的索引子屬性，就能直接取得或變更對應的值。

此外，鍵／值對可以加入字典，也可以從字典中移除。鍵、值以及鍵／值對都可以列舉。

值的型別可以是任何 C# 型別，包括基本型別、結構 _和_ 類別。

Dictionary 物件允許鍵是任何型別的物件。不過，為了確保執行時的行為正確，鍵必須具有適當的雜湊碼，也就是 [GetHashCode][gethashcode] 所傳回的值。

一個字典執行個體無法被多個執行緒安全地存取（非執行緒安全）。多執行緒的情況可以使用 [ConcurrentDictionary][concurrent-dictionary]。

另請參閱 [HashSet][hashset]、[ConcurrentDictionary][concurrent-dictionary]、[SortedDictionary][sorted-dictionary]。

雖然 Dictionary 沒有非泛型版本，但程式庫中仍保留了一些類別，用來支援非泛型的 map。你需要認識非泛型的 IDictionary 和 Hashtable，主要是為了在看到它們時能認得出來。除了維護舊的程式碼基底之外，你不太可能需要用到它們。

你通常會想透過它的 [`IDictionary<TKey, TValue>`][idictionary] 介面來公開及存取字典。

請注意，由於[索引子屬性][indexer-properties]的特性，基本型別的值可以直接就地修改，例如：

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
