# 二進位、八進位與十六進位

二進位、八進位和十六進位（_也稱為 hex_）是基數不同的[進位系統][numeral-systems]。
二進位的基數是 2，八進位是 8，十六進位是 16。
在 Crystal 中，一般的整數採用基數 10。
二進位、八進位和十六進位都是整數的表示法。
這表示它們可以表示正數和負數（_包括零_），不帶分數或小數，並且支援我們對整數能做的所有運算。

## 二進位

[二進位][binary]是基數為 2 的進位系統，只使用數字 0 和 1。
它通常用來表示電腦中電流通過電晶體和開關時的 0（「關」）與 1（「開」）狀態，以及磁性儲存媒體中的正負電荷。
二進位可以表示基數 10 中使用到的所有整數。

基數 2 系統的一小部分看起來像這樣，不過它會無限延伸，不會停在 128：

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

所以如果我們想表示數字 6，用二進位表示會是：110

| 位值     | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| 二進位數字 | 1   | 1   | 0   |

而運算會是：`4 + 2 + 0 = 6`

另一個例子：19

| 位值     | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| 二進位數字 | 1   | 0   | 0   | 1   | 1   |

這個二進位數字會是：10011
而運算會是：`16 + 0 + 0 + 2 + 1 = 19`

## Crystal 中的二進位

在 Crystal 中，我們可以使用`0b`前綴來表示二進位字面值。
如果我們寫`0b10011`，Crystal 會將它解讀為二進位數字，並轉換成基數 10。

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

如果你寫了一個帶有`0b`前綴、卻不屬於二進位系統的數字，就會拋出編譯錯誤。

```crystal
0b10211
# => Error: unexpected token: "211"
```

### 二進位數字的運算

由於二進位數字就是整數，我們可以對它們執行所有能用於整數的運算。

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### 二進位表示法的轉換

Crystal 會自動將二進位字面值轉換成`Int32`。
若要將`Int32`轉換成二進位表示法，請使用[`<int>.to_s(base)`][to_s]方法，並將 base 引數設為 2。
這個方法會回傳該二進位數字的字串表示法：

```crystal
19.to_s(2)
# => "10011"
```

若要將二進位的字串表示法轉換成整數，我們可以使用[`<int>.to_i(base)`][to_i]方法，並將基數（2）作為引數傳入：

```crystal
"10011".to_i(2)
# => 19
```

給錯基數（_或無效的二進位表示法_）會拋出`ArgumentError`：

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### 二進位方法

有些方法可以用在整數上，取得該數字二進位表示法的相關資訊。

[`<int>.bit_length`][bit_length]會回傳表示該數字所需的位元數：

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit]會回傳指定索引位置的位元，從右邊（_最低有效位元_）開始算起：

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## 八進位

[八進位][octal]是基數為 8 的進位系統。
它使用數字 0、1、2、3、4、5、6 和 7。

在 Crystal 中，我們可以使用`0o`前綴來表示八進位數字。
和二進位一樣，Crystal 會自動將八進位表示法轉換成`Int32`。

```crystal
0o123
# => 83
```

在不是八進位系統的數字前加上`0o`前綴，會拋出編譯錯誤。

### 八進位表示法的轉換

和二進位一樣，我們可以使用[`<int>.to_s(base)`][to_s]方法，將`Int32`轉換成八進位表示法。
也可以使用[`<int>.to_i(base)`][to_s]方法，將八進位表示法轉換成`Int32`。

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

和二進位一樣，給錯基數會拋出`ArgumentError`。

## 十六進位

[十六進位][hexadecimal]是基數為 16 的進位系統。
它使用數字 0 到 9，以及字母 A、B、C、D、E 和 F。
A 是 10，B 是 11，C 是 12，D 是 13，E 是 14，F 是 15。

我們可以在 Crystal 中使用`0x`前綴來表示十六進位數字。
和二進位、八進位一樣，Crystal 會自動將十六進位字面值轉換成`Int32`。

```crystal
#=> 0x123
291
```
 
在非十六進位的數字前加上`0x`前綴，會拋出編譯錯誤。

###  十六進位表示法的轉換

和二進位一樣，我們可以使用[`<int>.to_s(base)`][to_i]方法，將`Int32`轉換成十六進位表示法。
也可以使用[`<int>.to_i(base)`][to_s]方法，將十六進位表示法轉換成`Int32`。

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

和二進位、八進位一樣，給錯基數會拋出`ArgumentError`。

## 精確度

將數字轉換成字串表示法時，我們可以指定該數字的精確度。
意思是用來表示該數字的**最少**位數。
如果該數字的位數少於精確度，字串表示法前面會補上零。
這是透過將`precision`引數傳給[`<int>.to_s(<base>, precision: <value>)`][to_s]方法來完成。

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
