# 簡介

## 字串

Elixir 的字串以雙引號包住，並以 UTF-8 編碼：

```elixir
"Hi!"
```

字串可以用`<>/2`運算子串接：

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir 的字串支援以`#{}`語法進行插值：

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

若要在字串中放入換行字元，請使用`\n`跳脫序列：

```elixir
"1\n2\n3\n"
```

如果想輕鬆處理含有大量換行的文字，改用三個雙引號的 heredoc 語法會更方便：

```elixir
"""
1
2
3
"""
```

Elixir 在`String`模組中提供了許多處理字串的函式。

## 管線運算子

`|>`運算子稱為管線運算子。它可以把函式呼叫串接起來，讓前一個函式呼叫的回傳值作為下一個函式呼叫的第一個引數傳入。

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
