# 簡介

`for`迴圈可以讓你疊代一個陣列，並為每個元素重複執行同一段程式碼：

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

在上面的範例中，`fruit`是用來存放陣列`fruitList`中個別元素值的變數。編譯器會確保`fruitList`可以被疊代，否則就會停止執行。

你可以使用範圍運算子來疊代數字。這個運算子接受兩個`Int`運算元，寫成`min...max`：

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
