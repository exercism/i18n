# 操作說明

在這個練習中，你會模擬一個以視窗為基礎的電腦系統。
你會建立一些視窗，它們可以移動、調整大小，並顯示自己的內容。

## 1. 定義 Size struct

定義一個名為 `Size` 的 struct，其中有兩個 `Int` 屬性 `width` 和 `height`，分別儲存視窗目前的寬度和高度。
初始的寬度和高度應分別為 80 和 60。
加入一個方法 `resize(newWidth:newHeight:)`，它接受新的寬度和高度參數，並變更這些屬性以反映新的大小。

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. 定義 Position struct

定義一個名為 `Position` 的 struct，其中有兩個 `Int` 屬性 `x` 和 `y`，分別儲存視窗左上角目前的水準和垂直位置。
x 和 y 的初始值都應該是 0。位置 (0, 0) 是螢幕的左上角，`x` 值在你往右移動時會變大，`y` 值在你往下移動時會變大。

加入一個方法 `moveTo(newX:newY:)`，它接受新的 x 和 y 參數，並變更這些屬性以反映新的位置。

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. 定義 Window 類別

定義一個視窗類別，它有下列屬性：

- `title`：`String`，初始值為「New Window」
- `screenSize`：`Size`，常數值，`width` = 800、`height` = 600
- `size`：`Size`，初始值為 `Size` struct 的預設值
- `position`：`Position`，初始值為 `Position` struct 的預設值
- `contents`：`String?`，初始值為 `nil`

你也應該為這個類別定義一個空的初始化器。

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. 新增調整視窗大小的方法

- `resize(to:)`：`(Size) -> ()`，這個方法以 `Size` struct 作為輸入，並嘗試將視窗調整為指定的大小。不過，新的大小不能超過特定界限。
- 允許的最小高度或寬度為 1。
  要求的高度或寬度若小於 1，會被裁切為 1。
- 最大高度和寬度取決於視窗目前的位置，視窗的邊緣不能超出螢幕的邊緣。
  超過這些界限的值會被裁切為它們能取的最大大小。
  例如，如果視窗的位置在 `x` = 400、`y` = 300，而要求調整為 `height` = 400、`width` = 300，那麼視窗會被調整為 `height` = 300、`width` = 300，因為螢幕在 `y` 方向上不夠大，無法完全容納這個要求。

## 5. 新增移動視窗的方法

- `move(to:)`：`(Position) -> ()`，這和 `resize(to:)` 類似，不過這個方法調整的是視窗的_位置_，而不是大小。和 `resize` 一樣，新的位置不能超過特定限制。
- `x` 和 `y` 的最小位置都是 0。
- 任一方向的最大位置取決於視窗目前的大小；邊緣不能超出螢幕的邊緣。
  超過這些界限的值會被裁切為它們能取的最大大小。例如，如果視窗的大小在 `x` = 250、`y` = 100，而要求移動到 `x` = 600、`y` = 200，那麼視窗會被移動到 `x` = 550、`y` = 200，因為螢幕在 `x` 方向上不夠大，無法完全容納這個要求。

## 6. 新增更新視窗文字與顯示視窗資訊的方法

- `update(title:)`：`(String) -> ()`，這個方法會將 `title` 屬性設為傳入字串的值。
- `update(text:)`：`(String?) -> ()`，這個方法會將 `contents` 屬性設為傳入的可選字串的值。
- `display()`：`() -> String`，這個方法會回傳一個描述視窗目前狀態的字串。例如，如果視窗的 `title` 是「My First Window」，位置：x = 10、y = 100；大小：width = 200、height = 150；內容：「I 😍 my window」，它就應該回傳字串：`"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"`。如果 `contents` 是 nil，最後一行應為「[This window intentionally left blank]」

## 7. 為 Window 類別建立初始化器

視窗系統應該要有初始化器，讓視窗可以用自訂的輸入來建立。
為 `Window` 類別建立**另一個**初始化器。
這個初始化器應該接受下列參數：`title`、`contents`，以及兩個可選參數 `size` 和 `position`。
`size` 和 `position` 參數應預設為 `Size` 和 `Position` struct 的預設值。

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
