# 簡介

Java 中最主要的物件導向建構單元是_類別_，它結合了資料（_欄位_）與行為（_方法_）。
一個類別的欄位與方法合稱為它的_成員_。

成員的存取權限可以透過存取修飾子來控制，最常見的兩種是：

- `public`：任何程式碼都能存取這個成員（沒有限制）。
- `private`：只有同一個類別中的程式碼才能存取這個成員。

你可以把類別想成是用來建立該類別實例的範本。
要建立類別的實例（又稱為_物件_），會使用`new`關鍵字：

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

欄位有型別與名稱（以 camelCase 命名），而且可以定義在類別中的任何位置（依慣例會以 PascalCase 命名）：

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

你可以選擇性地為欄位指定初始值。
如果欄位_沒有_指定初始值，就會被設為該型別的預設值。
實例的欄位值可以用點記法來存取和更新。

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

私有欄位通常是透過呼叫方法時的附帶效果來更新。
這類方法通常不會回傳任何值，此時回傳型別應該設為`void`：

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
