# 關於

在 Go 裡，我們可以使用相等和排序運算子來比較值。
這類運算子一共有 6 個：

| 比較        | 運算子  |
| ------------------| --------- |
| 相等             | `==`      |
| 不相等         | `!=`      |
| 小於              | `<`       |
| 小於或相等     | `<=`      |
| 大於           | `>`       |
| 大於或相等  | `>=`      |

比較的結果一律是布林值：

```go
a := 3

a != 4 // true
a > 5  // false
```

## 相等運算子

相等運算子 `==` 和 `!=` 分別檢查一個值是否等於另一個值。
在 Go 中，大多數的型態都能使用相等運算子。
以下是一些常見的例子：

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## 排序運算子

排序運算子會檢查一個值是否大於（`>`）、大於或等於（`>=`）、小於（`<`）、小於或等於（`<=`）另一個值。
這種比較適用於數字、位元組、rune 和字串。
比較字串時，會依照字典順序（也稱為字典序）。

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
