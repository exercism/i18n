# 關於

在程式設計中，處理文字是常見的工作。
Swift 與 Foundation 框架提供了許多方便的方法和屬性，可以用來檢視、轉換及操作字串。

## 使用`components(separatedBy:)`分割字串

如果想依照分隔符號把字串拆成由子字串組成的陣列，可以使用`components(separatedBy:)`（需要先匯入 Foundation）：

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## 使用`hasPrefix(_:)`和`hasSuffix(_:)`檢查字首與字尾

如果要檢查字串是否以特定的字元序列開頭或結尾，可以使用`hasPrefix(_:)`和`hasSuffix(_:)`：

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## 改變大小寫

你可以使用下列標準方法和屬性來轉換字串的大小寫：

- `lowercased()`：回傳字串的小寫副本。
- `uppercased()`：回傳字串的大寫副本。
- `capitalized`：回傳每個單字首字母皆為大寫的副本（來自 Foundation）。

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## 使用`replacingOccurrences(of:with:)`取代子字串

如果想用另一個字串取代目標子字串的所有出現處，可以使用`replacingOccurrences(of:with:)`（來自 Foundation）：

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## 使用`joined(separator:)`串接字串

`joined(separator:)`方法屬於字串的集合，例如`[String]`。
它會使用分隔符號將元素串接成單一字串：

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
