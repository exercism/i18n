# 安裝


## 取得 GHCup

安裝 Haskell 工具最推薦的方式是透過 [GHCup][ghcup]。

有了 GHCup，你就可以管理已安裝的編譯器、專案與套件管理工具，以及語言伺服器。


## 安裝 Stack

做 Exercism 練習時，你只需要 Stack。

要安裝 Stack，請執行 GHCup 的安裝指令或安裝腳本。
依預設選項進行即可，但請指定你也要一併安裝 Stack。

不小心跳過了 Stack 的安裝嗎？
別擔心，之後執行`ghcup install stack`就行了。

GHCup 會安裝

- **編譯器**（GHC：Glasgow Haskell Compiler）

  嚴格來說，做 Exercism 並不需要它，但當你想在練習目錄之外玩玩 [GHCi][ghc-guide-ghci] 時，它就很方便。

- **Cabal**

  專案與套件管理工具。
  做 Exercism 不需要它。

- **Stack**

  你會用來做 Exercism 的專案與套件管理工具。
  它會確保每個專案（練習）都有正確的編譯器與函式庫。

想確認安裝是否成功，可以執行下列任一個指令

- `ghcup list`：成功的話會列出一長串工具版本，並將 Stack 標示為已安裝
- `stack --version`：成功的話會顯示類似`Version 2.7.5, Git revision ...`的內容


## 取得正確的 GHC 版本

需要時，Stack 會自動下載並安裝 GHC。
你可以在終端機中執行下列指令來開始安裝並驗證：

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

如果輸出類似

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

就表示 GHC 安裝正確。


## 設定編輯器來搭配 Haskell

Haskell 的支援是由 Haskell Language Server（HLS）提供的。
語言支援並非必要，但強烈建議使用。


### Visual Studio Code（推薦）

只要安裝 [Visual Studio Code 的 Haskell 擴充套件][vscode-haskell]就行了。
它會透過 GHCup 自動安裝 HLS，裝好之後就一切就緒了。

**注意**：剛下載的練習，HLS 可能會啟動失敗。
遇到這種情況，請執行`stack test`，然後重新啟動語言伺服器。


### 其他編輯器

請參閱 [HLS 的編輯器設定說明文件][hls-editor-config]。
你可能需要手動安裝 HLS。
若要手動安裝，請執行`ghcup install hls`。
