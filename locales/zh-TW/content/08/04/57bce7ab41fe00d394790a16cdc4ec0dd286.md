# 指令補充

## 例外訊息

有時候，你需要[拋出例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓你的程式碼更好讀，對除錯也很有幫助。如果你確定錯誤來源屬於某個特定型別，可以選擇拋出其中一種[內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但還是要附上有意義的訊息。

這個練習要求你在下列情況使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)「拋出」`ValueError`：輸入缺少適當的分隔符號、並非全為大寫、沒有形成帶有節點的樹，或根本沒有形成樹。只有同時 `raise` 這個 `exception` 並附上訊息，測試才會通過。

要拋出帶有訊息的 `ValueError`，請把訊息寫成 `exception` 型別的引數：

```python
# if the tree properties as given do not have proper delimiters.
raise ValueError("properties without delimiter")

# if the tree properties as given are not all in uppercase.
raise ValueError("property must be in uppercase")

# if the input does not form a tree, or is empty.
raise ValueError("tree missing")

# if the input is a tree without any nodes.
raise ValueError("tree with no nodes")
```
