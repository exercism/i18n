# 說明

你的朋友剛傳了一則訊息給你，裡頭藏著重要的秘密。他不想讓別人輕易讀到，所以在加密時做了一連串的位元操作。你需要寫出幾個函式，幫忙把這則訊息解密。

## 1. 把位元移回去

解密的第一步，是把加密過程中的位移反向還原，將位元往右移回去。後續的解密步驟會假設左側補進來的是 0。

實作`shiftBack`函式，讓它接受一個值和要位移的位數，並執行位移。

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. 設定一些位元

接著，有些位元需要設成 1。

實作`setBits`函式，讓它接受一個值和一個遮罩，回傳把值當中對應的位元設為 1 之後的結果。遮罩中為 1 的位元，值當中對應的位元也應該設成 1，其他位元則保持不變。

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 翻轉特定的位元

加密的過程中，有些位元被翻轉了。解密時得把它們翻轉回來。

實作`flipBits`函式，讓它接受一個值和遮罩。遮罩指出值當中哪些位元要翻轉：如果遮罩中的位元是 1，就把值當中對應的位元翻轉，其他位元則保持不變。

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 清除特定的位元

最後，還有一些位元解密後一定是 0。

實作`clearBits`函式，讓它接受一個值和遮罩。遮罩中為 1 的位元，`value`當中對應的位元應該設成 0，其他位元則保持不變。

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
