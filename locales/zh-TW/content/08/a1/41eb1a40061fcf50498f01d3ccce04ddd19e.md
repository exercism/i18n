# 簡介

Cairo 中的控制流程讓你根據條件與重複來控制程式的執行路徑。

## 條件式執行

使用`if`運算式，根據條件來執行程式碼：

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if`是運算式，因此可以回傳值：

```rust
let result = if condition { 5 } else { 10 };
```

## 迴圈

使用`loop`重複執行程式碼。
迴圈會一直執行下去，除非你把它停下來；當條件成立時，用`break`離開迴圈吧。

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

迴圈可以透過`break`回傳值：

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

使用`continue`跳到下一次疊代：

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
