# 關於

[concept:csharp/enumerables]() 可以使用 [`foreach` 迴圈][foreach-statement] 疊代：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

`foreach` 迴圈包含三個部分：

1. 宣告：定義用來存放疊代值的變數。這個變數（只能）在迴圈內使用。
2. 可疊代的物件：可以被疊代的物件。
3. 迴圈主體。

## for 與 foreach 迴圈

不過一般來說，`foreach` 迴圈會比 `for` 迴圈更適合，原因如下：

- `foreach` 迴圈保證會疊代過_所有_值。使用 `for` 迴圈時，很容易漏掉元素，例如因為差一錯誤。
- `foreach` 迴圈更具_宣告性_，你的程式碼傳達的是你希望它_做什麼_，而 `for` 迴圈傳達的則是你希望_怎麼做_。
- `foreach` 迴圈萬無一失，而使用 `for` 迴圈時很容易發生差一錯誤。
- `foreach` 迴圈適用於所有集合型別，包括不支援使用索引子存取元素的集合。

為了保證 `foreach` 迴圈會疊代過_所有_值，編譯器不允許在 `foreach` 迴圈內更新集合：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

相較於 `foreach` 迴圈，`for` 迴圈確實有一些優勢：

- 可以從你想要的索引開始或停止。
- 可以使用任何你想要的（布林）終止條件。
- 可以透過自訂迴圈變數的遞增方式來跳過元素。
- 可以透過倒數從後往前處理集合。
- 可以在不涉及集合的情境中使用 `for` 迴圈。
