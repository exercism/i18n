# 條件式

**條件式**會根據某件事是否成立，在兩種做法之間做出選擇。

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

讀法是這樣：先是`if`，接著是一個答案為`true`或`false`的問題，然後是`then`。`then`後面的幾行程式會在答案為 true 時執行，`else`後面的幾行則在答案為 false 時執行。`end;`會結束整段結構。

## 不只兩種選擇

`elsif`會再加上一個問題，只有在它上面的問題結果為 false 時才會問到。

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

順序很重要。分數是`9`時會被第一個問題接住，永遠到不了第二個，即使`9 >= 5`也成立。把判斷寫錯順序，通常就是出錯的原因。

它的拼法是`elsif`，不是`elseif`，也不是`else if`。

## 省略 else

在那種情況下沒什麼事要做的時候，可以省略`else`。

```sather
   if late then
      apologise;
   end;
```

必須回傳東西的常式，每一條路徑都得回傳，所以在這個練習裡，每個`if`都會保留它的`else`。
