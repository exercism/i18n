# 簡介

我們假設你已經熟悉 JSON 的語法和資料型態。

jq 的運作方式，是讓傳入的 JSON 資料通過_單一運算式_（以一連串過濾器構成的_管線_寫成），以得到想要的轉換後資料。

<!-- prettier-ignore -->
~~~~exercism/note
`jq`語言是由`jq`這支_程式_所實作的。
這個程式提供了幾個方便的命令列選項，用來控制輸入如何被取用，以及輸出如何呈現。

在下面的範例中，你會看到：

- `-n`或`--null-input`

    一般來說，`jq`程式會拿到一個要讀取的檔案，或者你把資料送進它的輸入。
    `--null-input`選項讓你在沒有任何輸入的情況下產生 JSON 資料。

- `-c`或`--compact-output`

    `jq`預設會把輸出排版得很漂亮。
    資料排版整齊時，對人類閱讀非常有用。
    不過機器並不需要：`--compact-output`選項會移除排版用的空白，把產生的 JSON 大小縮到最小。

- `-f filename`或`--from-file filename`

    從`filename`讀取`jq`程式，而不是在命令列上直接提供。
    `sed`和`awk`也都為了同樣的目的使用`-f`選項。
    你會在練習題的測試腳本裡看到這種用法。

本單元剩下的部分會聚焦在`jq`這門_語言_上。
~~~~

## 過濾器與管線

**過濾器**也稱為**運算式**。

_過濾器_接受一個輸入並產生一個輸出。
就像你在 Unix shell 裡的作業方式，你可以用管線`|`把_過濾器_連接起來，讓一個_過濾器_的輸出接到另一個_過濾器_的輸入。

## 恆等過濾器：`.`

這是最簡單的_過濾器_。
它只是把輸入原封不動地送到輸出。

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## 陣列

這裡會快速介紹如何處理**陣列**。
我們之後會更深入地探討這個主題。

_陣列_的元素用中括號存取，而且索引從 0 開始。

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

_過濾器_可以用`[`和`]`把運算式包起來，藉此建立_陣列_

- 搭配已知的元素清單：

  ```sh
  jq -n '[1, 2, 3]'
  ```

- 收集一串元素：例如 `range` 這個函式會輸出數字串流

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  用`[]`可以把運算式的結果收集成一個陣列

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## 逗號是運算子

_逗號_不只是分隔_陣列_元素的語法。
**逗號**是一個**運算子**，用來連接串流。

例如`[1, 2, 3]`是一個_過濾器_，它用_陣列_建構子`[]`把三個運算式`1`、`2`和`3`連接後的結果收集起來。

你注意到上面`range(10; 70; 15)`裡的分號了嗎？
因為_逗號_在`jq`語言裡有特定的用途，所以接受多個引數的函式會用分號來分隔引數。

## 物件

快速介紹**物件**。

和許多程式語言類似，用點號來存取_物件_的屬性

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
_物件_也可以用中括號存取，但這樣一來字串字面值就需要加引號。
這是處理含有空白的鍵的其中一種方法。

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

你可以用`{}`和`key: value`配對來建構_物件_。
如果_鍵_是「簡單」的字串，就不需要加引號。

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

輸出

```none
{
  "question": 54,
  "answer": 42
}
```

若要把_鍵_當成_運算式_，就必須用括號把它包起來（下面這段也會輸出和上面相同的結果）。

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## 管線

例如，假設有一個`file.json`，內容是

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

我們來算算 key2 這個_陣列_的長度：

```sh
$ jq '.key2 | length' file.json
3
```

我們把`.key2`運算式的輸出_經由管線_送到`length`，它一如預期地會輸出_陣列_裡元素的數量。

## 過濾器可以忽略它的輸入

在這個範例中，輸入的 JSON 資料會被忽略，對輸出沒有任何影響：

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## 過濾器可以輸出資料串流

一個_過濾器_可以輸出多個值。
例如，`.[]`這個_過濾器_會把_陣列_的每個元素當成獨立的值輸出：

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

把這樣的_過濾器_用管線送進另一個時，第二個_過濾器_會**_針對每個值_**各執行一次：

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

這就像是隱式疊代。
一旦你懂了這個技巧，就會發現功能強大的`jq`_過濾器_可以寫得非常精簡。

## 括號

**括號**用來把子運算式分組，以強制運算的順序，就像其他語言一樣。
在`jq`裡，需要用括號的地方有時會讓人覺得有點意外。

例如，假設我們想建立一個有 2 個元素的_陣列_：9 的平方根，以及 _e_ 的 1 次方。
這兩個個別的運算式是`9 | sqrt`和`1 | exp`。
我們預期輸出會是_陣列_`[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

為什麼我們沒得到預期的結果？`jq`會把它解讀成這樣：

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq`建立了一個包含兩個元素（`3`和`1`）的串流，這兩個元素會分別被送給`exp`。

我們需要確保`exp`只接收一個數字作為輸入。
換句話說，我們要強制管線先被求值，再處理逗號。

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## 函式與運算子

這裡不深入探討（函式會是另一個練習的主題），以下是一些實用的內建函式：

- `length`

  以陣列作為輸入時，輸出陣列中元素的數量。

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  這個運算子的行為取決於運算元的型別：
  它可以把數字相加，
  把字串串接，
  在陣列後面附加內容，
  合併物件。

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add`是一個函式，它接受一個陣列，並依照`+`的規則把所有元素加總後回傳一個結果。
  `[1, 2, 3] | add`會輸出`6`。

- `map`

  以陣列作為輸入、以一個過濾器作為引數時，輸出把該過濾器套用到每個元素後所得到的陣列

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  給定_某個_輸入以及一個過濾器作為引數時：
  - 如果把過濾器套用到該引數後得到_true_值，就原封不動地輸出輸入
  - 否則就什麼都不_輸出_（不是`null`值，而是真的沒有輸出）

  例如，給定一些數字，選出能被 3 整除的那些

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  還記得`range`會輸出數字的_串流_。
  `select`會針對每個數字各被呼叫一次。
  只有「通過」這個運算式的數字才會被輸出。

  你經常需要選出陣列裡的元素。
  有幾種做法。

  以`["Anne", "Bob", "Cathy", "Dave"]`作為輸入，選出長度為 4 的名字。
  - 把`map`和`select`一起使用

    ```jq
    map(select(length == 4))
    ```

  - 把陣列展開成一個個元素，對這個串流做`select`，再收集結果

    ```jq
    [ .[] | select(length == 4) ]
    ```
