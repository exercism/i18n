# 關於

在 Common Lisp 中，參數列表（例如定義函式時所用的那個）也稱為 [lambda list][lambda-list]。
Lambda list 也用來定義巨集和解構。

Lambda list 可以包含 [lambda list keywords][lambda-list-keyword]，例如 `&rest`、`&optional`、`&key` 等等。

雖然多種類型的參數可以和其他類型的參數（選擇性參數與關鍵字參數）組合使用，但這麼做可能會有問題，應該謹慎處理。
請參閱 Practical Common Lisp 裡[「混合不同的參數類型」][pcl-function]一節。
