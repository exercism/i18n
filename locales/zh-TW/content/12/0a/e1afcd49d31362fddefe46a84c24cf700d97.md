# 簡介

Perl 是由 Larry Wall 創造的程式語言，於 1987 年首次發布。

## 套件與模組

套件是一組程式碼的集合，通常放在同名且副檔名為`.pm`的模組檔案裡。
接著就能把這個模組匯入另一個檔案，通常使用`use`關鍵字。

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## 變數

變數有純量（`$foo`）、陣列（`@bar`）和雜湊（`%baz`）三種。
為了簡單起見，這裡只會用到純量變數。
純量值可以是下列幾種：字串、數字、布林，或是指向某個東西的[參照][perlreftut]。
沒有值的情況就是`undef`。


`my`和`our`這兩個關鍵字會在語彙作用域中宣告變數，例如`my $foo;`。
使用`our`時，這個變數也會同時成為同名套件變數的別名。
還有其他宣告變數的方式，這裡不談。

你可以用`=`運算子指定變數的值，例如`$foo = 1;`，也可以在宣告變數的同時指定，例如`my $foo = 1;`。

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## 副程式

`sub`關鍵字用來宣告[副程式][perlsub]。
`return`關鍵字會結束副程式，並給出指定的值；如果沒有指定任何值，就回傳空陣列。
如果沒有明確寫出`return`，回傳值會由呼叫這個副程式時的情境（純量、陣列或 void）以及它的最後一個敘述決定。

```perl
sub hello () {
    return 'Hello, World!';
}
```

較新版本的 Perl 可以在[簽名][perlsubsig]中指定正式參數。
參數列表可以包含純量、陣列或雜湊變數。
空的參數列表代表這個副程式不接受任何引數。
較舊版本的 Perl 則需要從特殊變數`@_`取得引數，這裡不談。

## 註解

Perl 的註解以`#`開頭，這個`#`不屬於字串，註解一直到該行結尾為止。
