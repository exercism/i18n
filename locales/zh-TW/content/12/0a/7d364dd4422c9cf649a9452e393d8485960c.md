# 指令補充

## 暫存器

| 暫存器 | 用途         | 型別    | 說明                                |
| ------ | ------------ | ------- | ----------------------------------- |
| `$a0`  | 輸入         | 整數    | 上限                                |
| `$a1`  | 輸入/輸出    | 位址    | 質數的目的地陣列                    |
| `$v0`  | 輸出         | 整數    | 質數的數量                          |
| `$t0-9`| 暫時         | 任意    | 用於暫存                            |
