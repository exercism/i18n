# 簡介

在 Elixir 中，所有的錯誤都實作了 _Exception Behaviour_。就像 _Access Behaviour_ 一樣，_Exception Behaviour_ 定義了模組必須實作的回呼函式，以履行這個 behaviour 的軟體契約。錯誤一旦定義完成，就會具備以下特性：

- 模組的名稱定義了錯誤的名稱。
- 模組會定義一個錯誤結構體。
- 這個結構體會有一個`:message`欄位。
- 這個模組可以搭配`raise/1`和`raise/2`使用，以引發預期的錯誤。

_Exception Behaviour_ 也指定了兩個回呼：`message/1`和`exception/1`。如果沒有實作，就會採用預設的實作。當搭配`raise`呼叫時，`message/1`會把錯誤結構體轉換成可讀的訊息；而`exception/1`則允許在搭配`raise/2`呼叫時，在訊息中加入額外的資訊。

## 定義例外

要從錯誤模組定義例外，我們會使用`defexception`巨集：

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## 使用例外

定義好的錯誤可以像內建錯誤一樣，搭配`raise/1`或`raise/2`來使用。

- `raise/1`會依模組名稱引發特定的錯誤；如果引數是字串，則會引發一個`RuntimeError`，並以該字串作為訊息。
- `raise/2`會依模組名稱引發特定的錯誤，並接受一個屬性引數，用來取得帶有適當訊息的錯誤。
