# 元組型別

元組是 Cairo 中一種多用途且高效的複合資料型態，讓你能將多個不同型別的值組成單一實體。
元組的長度固定，意思是宣告之後，大小就無法改變。

## 建立元組

若要建立元組，你會在括號內寫下以逗號分隔的值列表。
元組中的每個位置都有特定的型別，而這些型別可以彼此不同。

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

元組可以存放多個不同資料型態的值，包括其他元組。
例如：

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

這裡的`nested_tup`變數是一個包含兩個元組的元組，說明元組可以將其他元組作為元素。

## 解構元組

若要存取元組中的個別值，你可以使用模式比對來解構元組。
這會將元組拆解成它的組成部分。

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## 同時宣告與解構

你也可以同時宣告並解構一個元組。

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## 單元型別`()`

單元型別是 Cairo 中的特殊型別，只有一個值：`()`。
它由一個沒有元素的元組表示。
單元型別的大小永遠為零，而且保證不會存在於編譯後的程式碼中。

在 Cairo 中，每個運算式都會回傳一個值；而當運算式沒有回傳任何東西時，它會隱式回傳`()`。
這對於需要回傳值、但沒有有意義的值可回傳的函式來說很有用。

## 具名元組型別宣告

具名元組可讓你為元組建立更具描述性的型別別名，提升程式碼可讀性。

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

在這個例子中，`Point`是具名元組型別，代表一對無號 32 位元整數，讓程式碼更具表達力。
