# 指令

你受雇於一家正在開發聊天機器人的公司，擔任正規表達式專家。

這個專案還在非常初階的開發階段，因此你的任務是運用正規表達式，提升聊天機器人理解與產生自然語言的能力。

## 檢查指令是否有效

聊天機器人不只聰明，還是個忠實的助手。

使用者想向聊天機器人提問，必須在指令的第一個位置說出「**Chatbot**」這個詞。

這個關鍵字是大寫還是小寫都無所謂，重要的是它出現的位置。

實作`isValidCommand()`函式，協助聊天機器人辨識使用者何時在下指令。

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## 移除加密的 emoji

聊天機器人很難理解人類如何用 emoji 表達情緒。

聊天機器人收到使用者的訊息時，每個 emoji 都會表示成「_emoji_」後面接著它的 _id_ 編號。

實作`removeEmoji()`方法，接收一個字串，並移除整則訊息中所有 emoji 的加密。

不含 emoji 文字的行，應該原封不動地回傳。

只要移除 emoji 字串就好，不要試著調整空白。

針對這個挑戰，請使用建構函式語法來建立正規表達式。

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## 檢查電話號碼是否有效

考量到使用者會從行動應用程式下載聊天機器人的功能，他們在對話過程中需要輸入手機號碼。

問題在於，聊天機器人只能讀取並驗證特定格式的號碼。

如果號碼有效（符合**正規表達式**指定的字元序列），聊天機器人會回覆一則訊息，感謝使用者並確認號碼。如果號碼無效，函式會告知使用者這個電話號碼不正確。

預期的格式是：(+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## 取得網站連結

聊天機器人是非常好奇的軟體。雖然它能在網路上搜尋特定主題，但它喜歡詢問使用者有沒有很酷的網站或 URL，好去找到相關資訊。

對話範例：

- **聊天機器人**：嘿 username，我想學怎麼用 JavaScript 寫程式，你知道有什麼很酷的網站可以讓我學習嗎？
- **使用者**：我從 [exercism.org](http://exercism.org) 學到很多。

實作`getURL()`函式，它能回傳一個只包含各個網站連結的陣列。要寫出能辨識任何 URL 的正規表達式會非常複雜，但聊天機器人只需要讀取簡單的 URL。在這個練習中，URL 就是任何以`"."`分隔的字詞序列。

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## 向使用者打招呼

為了儲存所有與它對話過的人員資料，聊天機器人能從使用者的個人檔案中，以下面這種格式取得全名：**「smith, john」**。

這麼一來，我們希望聊天機器人非常有禮貌，並留下良好的印象。

撰寫`niceToMeetYou()`函式，它接收一個包含使用者全名的字串，並回傳字串**「Nice to meet you, John Smith」**。

為了學習的目的，請使用正規表達式中的**取代方法**來實作這個函式。

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
