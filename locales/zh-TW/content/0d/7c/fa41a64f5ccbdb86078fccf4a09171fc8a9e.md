# 關於

任何值都可能是錯誤。`throw`（在 `kernel` 中）會發出訊號；目前這個詞的堆疊效應會遭到捨棄，控制權則回溯到最接近的外層`recover`。

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` 是一個解析詞，能一次定義錯誤的 tuple 類別*和*建構詞：

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

這樣一來，每個自訂錯誤都有專屬的類別、友善的拋出建構詞，以及一個類別述詞（`name?`），可以用來比對捕捉到的錯誤：

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

若要做 finally 式的清理，請見`continuations`裡的`cleanup`。若需要可重新啟動的條件，請見`condition`。
