# 簡介

## 基礎

我們假設你已經熟悉 JSON 的語法和資料型態。

jq 的運作方式，是把傳入的 JSON 資料通過_單一運算式_（寫成_過濾器管線_），以得到想要的轉換後資料。

<!-- prettier-ignore -->
~~~~exercism/note
`jq`語言是由`jq`_程式_實作的。
這個程式提供了幾個方便的命令列選項，用來控制輸入如何被取用，以及輸出如何呈現。

在下面的範例中，你會看到：

- `-n`或`--null-input`

    一般來說，`jq`程式會讀取指定的檔案，或者你把資料送到它的輸入。
    `--null-input`選項讓你可以在沒有任何輸入的情況下產生 JSON 資料。

- `-c`或`--compact-output`

    預設情況下，`jq`會把輸出的排版印得很漂亮。
    資料排版得漂亮時，對人類來說閱讀起來極為方便。
    不過機器並不需要這些：`--compact-output`選項會移除排版用的空白，把產生的 JSON 縮到最小。

- `-f filename`或`--from-file filename`

    從`filename`讀取`jq`程式，而不是在命令列上直接提供。
    `sed`和`awk`也都為了同樣的目的使用`-f`選項。
    你會在練習題的測試指令碼中看到這種用法。

這堂課接下來的內容會聚焦在`jq`_語言_本身。
~~~~

### 過濾器與管線

**過濾器**也稱為**運算式**。

一個_過濾器_接受輸入並產生輸出。
就像你在 unix shell 裡工作的方式一樣，你可以用管線`|`串接_過濾器_，把一個_過濾器_的輸出接到另一個的輸入。

### 恆等過濾器：`.`

這是最簡單的_過濾器_。
它只是把輸入直接傳到輸出。

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### 陣列

這裡會快速介紹如何處理**陣列**。
我們之後會更詳細地探討這個主題。

_陣列_元素用方括號存取，索引從 0 開始。

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

一個_過濾器_可以把運算式包在`[`和`]`裡來建構_陣列_

- 搭配一份已知的元素清單：

  ```sh
  jq -n '[1, 2, 3]'
  ```

- 收集一串元素：舉例來說，`range`是一個會輸出數字串流的函式

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  用`[]`會把運算式的結果收集成一個陣列

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### 逗號是運算子

_逗號_不只是分隔_陣列_元素的語法。
**逗號**是一個串接資料流的**運算子**。

舉例來說，`[1, 2, 3]`是一個_過濾器_，它用_陣列_建構子`[]`來收集串接三個運算式`1`、`2`和`3`的結果。

你注意到上面`range(10; 70; 15)`裡的分號了嗎？
因為_逗號_在`jq`語言中有特定的用途，所以接受多個引數的函式會用分號來分隔引數。

### 物件

快速介紹**物件**。

和許多程式語言類似，用點來存取_物件_的屬性

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
方括號也可以用於_物件_，但這麼一來，字串常值就需要加上引號。
這是處理含有空格的鍵的其中一種做法。

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

你可以用`{}`和`key: value`配對來建構_物件_。
「簡單」的字串不需要用引號把_鍵_括起來。

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

輸出

```none
{
  "question": 54,
  "answer": 42
}
```

若要把_鍵_當成_運算式_處理，你必須用括號把它包起來（下面這段也會輸出和上面相同的結果）。

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### 管線

舉例來說，假設`file.json`的內容是

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

讓我們來算算 key2 _陣列_的長度：

```sh
$ jq '.key2 | length' file.json
3
```

我們把`.key2`運算式的輸出_用管線接到_`length`的輸入，毫不意外地，它會輸出_陣列_中的元素個數。

### 過濾器可以忽略它的輸入

在這個範例中，輸入的 JSON 資料會被忽略，對輸出沒有任何影響：

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### 過濾器可以輸出資料流

一個_過濾器_可以輸出多個值。
舉例來說，`.[]`這個_過濾器_會把_陣列_的每個元素當成獨立的值輸出：

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

把這樣的_過濾器_用管線接到另一個過濾器時，第二個_過濾器_會**_針對每個值_**各執行一次：

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

這就像是隱含的疊代。
一旦你懂了這個技巧，就會發現非常強大的`jq`_過濾器_可以寫得非常簡潔。

### 括號

**括號**用來把子運算式群組在一起，以強制運算的順序，就像其他語言一樣。
在`jq`中，需要用到它們的時機有時會讓人覺得有點意外。

舉例來說，假設我們想建構一個有 2 個元素的_陣列_：9 的平方根，以及_e_的 1 次方。
這兩個獨立的運算式是`9 | sqrt`和`1 | exp`。
我們預期輸出會是_陣列_`[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

為什麼我們沒有得到預期的結果？
`jq`把它解讀成這樣：

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq`會建立一個有兩個元素（`3`和`1`）的資料流，兩者都分別被送給`exp`。

我們必須確保`exp`只會收到一個數字當作輸入。
換句話說，我們必須強制管線在逗號之前先被求值。

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### 函式與運算子

這裡不深入探討（函式會是另一個練習的主題），以下是一些實用的內建函式：

- `length`

  以陣列為輸入時，輸出陣列中的元素個數。

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  這個運算子的行為取決於運算元的型態：
  它會相加數字、
  串接字串、
  附加陣列、
  合併物件。

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add`是一個函式，它接受一個陣列，並依照`+`的規則把所有元素加總後回傳一個結果。
  `[1, 2, 3] | add`會輸出`6`。

- `map`

  以陣列為輸入、以過濾器為引數時，輸出一個把該過濾器套用到每個元素後所得的陣列

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  給定_某個_輸入和一個過濾器作為引數：
  - 如果套用到該引數的過濾器產生_true_值，就原封不動地輸出輸入
  - 否則輸出_空無_（不是`null`值，是真的沒有任何輸出）

  舉例來說，給定一些數字，挑出其中能被 3 整除的

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  回想一下，`range`會輸出一個數字的_資料流_。
  `select`會針對每個數字各被呼叫一次。
  只有「通過」該運算式的數字才會被輸出。

  你經常需要挑選陣列中的元素。
  這裡有幾種做法。

  以`["Anne", "Bob", "Cathy", "Dave"]`為輸入時，挑出長度為 4 的名字。
  - 把`map`和`select`一起使用

    ```jq
    map(select(length == 4))
    ```

  - 把陣列拆解成個別元素，對該資料流使用`select`，再收集結果

    ```jq
    [ .[] | select(length == 4) ]
    ```
