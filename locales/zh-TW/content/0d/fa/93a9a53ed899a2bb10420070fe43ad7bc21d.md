# 簡介

## 陣列

在 C# 中，可以容納零個或多個元素的資料結構稱為_集合_。**陣列**是一種集合，它的大小與長度固定，而且所有元素都必須是相同的型別。你可以使用索引將元素指定給陣列，或從陣列中取出元素。C# 的陣列以零為起始索引，也就是說，第一個元素的索引一律是零：

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

陣列也可以用簡寫語法來定義，同時建立陣列並設定它的值。由於編譯器現在能判斷陣列會有幾個元素，所以可以省略長度：

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

你可以呼叫陣列執行個體的方法或屬性來操作陣列，也可以使用`Array`類別中定義的靜態方法。

## `for`迴圈

`for`迴圈可以讓你重複執行某段程式碼，直到條件成立為止。

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`迴圈由四個部分組成：

1. 初始化運算式：在進入迴圈前執行一次。通常用來定義迴圈內會用到的變數。
2. 條件：在每次疊代前執行。只要這個運算式的結果是`true`，迴圈就會繼續執行。
3. 迭代器：在每次疊代後執行。通常用來修改（通常是遞增或遞減）迴圈變數。
4. 主體：每次疊代時實際執行的程式碼。

## `foreach`迴圈

陣列同時也是一種_集合_，這表示除了用索引存取值之外，你還可以用`foreach`迴圈走訪它的_所有_值：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
