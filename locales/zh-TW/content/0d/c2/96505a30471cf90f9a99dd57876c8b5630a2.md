# 說明

在準備烤餅乾給朋友吃的時候，你發現食譜裡有些計量單位必須換算。由於你只熟悉公制，得想個辦法把常見的美制烘焙計量換算成毫升（mL），這樣自己用起來才方便。

你的解法請參考這份換算表：

| 要換算的單位 | 體積 | 毫升（mL） |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| 美制杯          | 1      | 240                 |
| 美制液量盎司    | 1      | 30                  |
| 美制茶匙        | 1      | 5                   |
| 美制湯匙        | 1      | 15                  |

身為一個正在受訓的優秀程式設計師，你決定用毫升當作中間單位，方便把表上的任何單位換算成其他任何單位（甚至是它自己）。

## 1. 取得體積配對中的數值部分

實作 `KitchenCalculator.get_volume` 方法。
給定一個體積配對元組，它應該只回傳數值部分。

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. 把體積配對換算成毫升

實作 `KitchenCalculator.to_milliliter` 方法。
給定一個體積配對元組，它應該依照換算表把體積換算成毫升。

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. 把毫升體積配對換算成其他單位

實作 `KitchenCalculator.from_milliliter` 方法。
給定一個體積配對元組和想要的單位，它應該依照換算表把體積換算成該單位。

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. 把任何單位換算成任何單位

實作 `KitchenCalculator.convert` 方法。
給定一個體積配對元組和想要的單位，它應該把給定的體積換算成想要的單位。

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
