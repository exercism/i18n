# 關於

Elm 中的[自訂型別][custom-types]代表了固定數量的具名案例。每個值都恰好對應其中一個具名案例。在其他語言或情境中，這些被稱為_和型_、_辨別聯合_、_標記聯合_和_代數資料型態_。

辨別聯合的每個案例都可以選擇性地帶有關聯資料，而且不同的案例可以帶有不同的資料型態。如果沒有任何案例帶有關聯資料，這個辨別聯合就類似其他語言通常所稱的_列舉_（或 _enum_）。

自訂型別使用`type`關鍵字定義，所需的語法非常少。它們是 Elm 程式設計中最重要的技巧之一，用來讓程式碼中可能出現的值與現實生活中合法的值完全吻合，如此一來就沒有無效資料存在的空間，也讓[不可能出現的狀態無法在程式碼中表示][impossible-states]。

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

要為特定案例建立值，可以在該案例定義於同一個模組時，或是透過`import SeasonModule exposing (Season(..))`這種語法匯入時，直接引用它的名稱（`Spring`）；也可以在透過`import SeasonModule exposing (Season)`這種語法匯入時，引用它的完整限定名稱（`Season.Spring`）。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

自訂型別和 Elm 中的所有東西一樣，都具有_結構相等性_，這代表同一個案例、且帶有相同（選用）資料的兩個值，彼此是等價的。

處理自訂型別的首選方式是使用[模式比對][pattern-matching]：

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
