# 簡介

函式可以為一個或多個引數宣告預設值。來看看下面這個函式：

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

編譯時，Elixir 會建立 `number/0`（沒有引數）與 `number/1`（一個引數）這兩個函式定義。

如果一個以上的引數帶有預設值，這些預設值會由左至右套用到函式，補上缺少的引數。

如果函式有多個子句，預設引數應定義在函式標頭（沒有主體的函式）中，並放在函式子句之前：

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
