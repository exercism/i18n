# 說明

根據尼科馬庫斯（西元 60 - 120 年）對正整數的分類法，判斷一個數字是 perfect、abundant 還是 deficient。

古希臘數學家[尼科馬庫斯][nicomachus]根據正整數的[真因數和][aliquot-sum]，設計了一套分類法，讓每個數都能唯一歸入**perfect**、**abundant**或**deficient**其中一類。
真因數和定義為一個數的所有因數之和，但不包含該數本身。
例如，15 的真因數和是 (1 + 3 + 5) = 9。

- **Perfect**：真因數和 = 該數
  - 6 屬於 perfect，因為 (1 + 2 + 3) = 6
  - 28 屬於 perfect，因為 (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**：真因數和 > 該數
  - 12 屬於 abundant，因為 (1 + 2 + 3 + 4 + 6) = 16
  - 24 屬於 abundant，因為 (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**：真因數和 < 該數
  - 8 屬於 deficient，因為 (1 + 2 + 4) = 7
  - 質數也都是 deficient

請實作一個方法，判斷給定的數字是否為**perfect**。
視你所屬的語言軌道而定，你可能還需要實作一個方法，判斷給定的數字是否為**abundant**或**deficient**。
