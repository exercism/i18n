# 資源

* Libera Chat 上的 [#haskell](https://web.libera.chat/?channel=#haskell) IRC 頻道，其目標是「鼓勵學習和討論 Haskell、函式程式設計，以及一般程式設計」。想進一步了解這個 IRC 頻道，可以參考 [Haskell Wiki 上的頻道頁面](https://wiki.haskell.org/IRC_channel)。
* [Hoogle](https://www.haskell.org/hoogle/) 是一套 Haskell API 搜尋引擎。即使你只知道函式的名稱，也能查詢這個函式的作用。更有趣的是，它還支援用型別簽名來搜尋：如果你想知道哪些函式具有 [(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b]) 這個型別簽名，Hoogle 可以幫你找出來！
* [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell) 可以用來搜尋你的問題，看看是否已經有人回答過。你也可以在上面提問、回答問題喔。
* [/r/haskell](https://www.reddit.com/r/haskell) 是 Haskell 的 subreddit。
* [Haskell 社群頁面](https://www.haskell.org/community/) 連結到許多 Haskell 開發者聚集與交流的社群；你可以從這裡選擇自己偏好的交流方式。
