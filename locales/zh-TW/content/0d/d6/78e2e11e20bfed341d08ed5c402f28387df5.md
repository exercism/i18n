# 指示

舞台監督想把排練腳本打出來，而其中好幾個部分是把東西重複或接在一起做出來的。

這四個任務都要放在`REHEARSAL_SCRIPT`類別裡。

## 1. 重複提示

給定一個提示和一個數字，回傳把該提示重複那麼多次、中間不夾任何東西的結果。

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

重複零次會得到空字串。

## 2. 演員名單的首字母

給定演員名單，回傳每個名字的第一個字母，並接在一起。

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. 為台詞編號

給定一場戲的台詞，從 1 開始編號，每一句各自獨立一行。

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

各行之間有一個換行，最後一行之後則沒有。沒有台詞的場景就是空字串。

## 4. 大喊一句台詞

回傳一句台詞，並把每個字母都變成大寫。

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
