# 說明

如果你遇到困難，以下是一些可以尋求協助的資源：

- [Uiua 專案的主要網站][main] 提供[說明文件][docs]、範例、教學與社群資源。
- [Exercism Discord 社群][exercism-discord]
- [Uiua Discord 社群][discord] 是個非常熱心且活躍的社群。
- [入門教學][tutorial] 能提供整體概觀，並附有小型練習帶你認識 Uiua。
- [Uiua Pad][pad] 可以視覺化地逐步執行小型程式碼片段。
- [/r/apljk/][apl-reddit] 是一個專門討論 APL 這類語言的 subreddit。

此外，[StackOverflow][so] 是搜尋你的問題或疑問是否已經有人回答過的好地方。
如果沒有，你也可以隨時[發問][ask-so]，或是[回答][answer-so]別人的問題。
