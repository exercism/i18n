# 提示

## 一般

- `n <iota>`會產生一個由整數`0, 1, …, n-1`組成的虛擬序列。
- `map`（在[`sequences`][sequences]中）會對每個元素執行你的 quotation，並收集結果。
- `>string`（在[`strings`][strings]中）會把字元碼組成的序列轉成字串。

## 1. 字母旗布

- `CHAR: a`會解析成整數`97`。加上索引`i`就能得到第`i`個小寫字母的編碼。

## 2. 計數旗布

- `mod`（在[`math`][math]中）會回傳整數除法的餘數。
- 數字字元的編碼是連續的（`CHAR: 0`、`CHAR: 1`、……），所以`CHAR: 0 +`可以把`0..9`範圍內的整數轉成對應的數字字元。

## 3. 條紋旗布

- `even?`（在[`math`][math]中）對偶數是`t`，否則為`f`。
- 在`map`的 quotation 裡，`if`會根據測試結果挑選兩個字元常值的其中一個。

## 4. 標記旗布

- `5 mod zero?`只在位置`0`、`5`、`10`、……時是`t`。

## 5. 山谷旗布

- `-5 5 [a..b)`（在[`ranges`][ranges]中）是半開區間`-5, -4, …, 4`。
- `abs`（在[`math`][math]中）會把負整數變成它的正數對應值，非負整數則保持不變。
