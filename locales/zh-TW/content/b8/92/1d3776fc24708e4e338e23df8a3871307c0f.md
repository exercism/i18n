# 簡介

## True 與 False

在 Ruby 中，True 和 False 這兩種邏輯狀態分別以`true`和`false`表示。
它們可以單獨作為字面值使用，也可以是邏輯方法或比較方法的結果。

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ 與 _falsey_

在`if`敘述或其他布林情境中對物件求值時，除了`false`和`nil`之外，所有物件都會被視為 _truthy_。

## 控制流程

_truthy_ 與 _falsey_ 的求值在控制流程中很有用。
和程序式語言一樣，Ruby 有`if`...`else`結構，但更常見的是把`if`當作「守衛」敘述使用，來修飾運算式的求值。

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby 提供了`unless`，讓程式碼讀起來更順暢。
例如，比起`eat_desert if not too_full`，我們也可以寫成`eat_desert unless too_full`。

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
