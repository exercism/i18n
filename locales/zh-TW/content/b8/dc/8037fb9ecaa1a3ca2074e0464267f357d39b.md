# 帶有狀態的類別

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr、readonly attr、private attr

| 寫法 | 可從外部讀取 | 可從外部變更 |
| --- | --- | --- |
| `attr x : INT` | 可以 | 可以 |
| `readonly attr x : INT` | 可以 | 不行 |
| `private attr x : INT` | 不行 | 不行 |

`readonly` 是你預設應該選用的那個。它讓任何人都能看到分數，並要求改變分數必須經由 `home_goal`，而關於計分的規則就住在那裡。

## create 與 new

`new` 會產生這個類別的一個物件，其中每個屬性都是空的。它只能在類別內部使用。

`create` 是一個名字約定好的一般方法：`#C(args)` 就完全等同於 `C::create(args)`。一個類別可以有好幾個，靠引數來區分彼此；而一個都沒有這類方法的類別，就是無法用 `#` 建立。

## SAME

`SAME` 代表它被寫在其中的那個類別。在 `create` 裡它是回傳型別；它也能用在引數的位置，而它正是讓繼承而來的方法談論的是繼承的那個類別、而不是原本那個類別的原因。

## 沒有回傳型別的方法

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

沒有 `:`，也沒有型別。這樣的方法是以敘述的形式被呼叫，不能出現在運算式裡。它表示這次呼叫的重點，就在於它所造成的改變。

## self

在方法內部，`self` 就是它被呼叫時所在的那個物件。它很少真的要寫出來，因為單獨寫出一個屬性名稱或方法名稱時，意思本來就是 `self` 的。當這個物件必須被傳遞出去或回傳時，就需要寫出它：

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`、`new`、`void`、`result`、`value` 和 `out` 都是 Sather 已經佔用的字，都不能拿來當作你自己取的名稱。

## 參照，而非值

物件是經由參照存取的。同一個計分板的兩個名稱，看到的是同一個分數：

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class` 則是之後取得另一種行為的方法。
