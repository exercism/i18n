# 簡介

## 數字

F# 中有兩種不同的數值型別：

- 整數：小數點後沒有任何位數的數字（即整數）。例如 `-6`、`0`、`1`、`25`、`976` 和 `500000`。
- 浮點數：小數點後有零個或多個位數的數字。例如 `-2.4`、`0.1`、`3.14`、`16.984025` 和 `1024.0`。

F# 中最常見的兩種數值型別是 `int` 和 `float`。`int` 是 32 位元整數，`float` 則是 64 位元浮點數。

算術運算使用標準的算術運算子來進行。數字可以使用標準的數值比較運算子，以及等於（`=`）與不等於（`<>`）運算子來比較。

數值型別之間的轉換是透過內建的轉換運算子來完成。這些轉換運算子以其要轉換成的型別來命名。F# _不_支援數值型別之間的自動轉換。

## 條件

在 F# 中，要以條件方式執行程式碼，最常見的做法是使用 `if/elif/else` 運算式：

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

`if/elif/else` 運算式中使用的條件必須是 `bool` 型別。F# 沒有 _truthy_ 值的概念。
