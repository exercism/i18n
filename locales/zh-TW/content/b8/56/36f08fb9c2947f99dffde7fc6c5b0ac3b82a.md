# 簡介

C# 和許多靜態型別語言一樣，提供了多種代表整數的型別，每一種都有自己的值範圍。在範圍最小的一端，`sbyte`型別的最小值為 -128，最大值為 127。和所有整數型別一樣，這些值可以透過`<type>.MinValue`和`<type>.MaxValue`取得。在範圍最大的一端，`long`型別的最小值為 -9,223,372,036,854,775,808，最大值為 9,223,372,036,854,775,807。介於兩者之間的是`short`和`int`型別。

這些範圍取決於系統為該型別配置的儲存寬度。例如，`byte`使用 8 位元，`long`使用 64 位元。

上述每個型別都有一個無號的對應型別：`sbyte`/`byte`、`short`/`ushort`、`int`/`uint`和`long`/`ulong`。在所有情況下，值的範圍一律從 0 到有號最大值的負值乘以 2 再加 1。

| 型別   | 寬度   | 最小值                     | 最大值                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 位元 | -128                       | +127                        |
| short  | 16 位元 | -32_768                    | +32_767                     |
| int    | 32 位元 | -2_147_483_648             | +2_147_483_647              |
| long   | 64 位元 | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 位元 | 0                          | +255                        |
| ushort | 16 位元 | 0                          | +65_535                     |
| uint   | 32 位元 | 0                          | +4_294_967_295              |
| ulong  | 64 位元 | 0                          | +18_446_744_073_709_551_615 |

某種型別的變數（或運算式）可以輕鬆轉換成另一種型別。例如，在指定運算中，如果要指定的值（lhs）的型別能確保該值落在被指定型別（rhs）的範圍內，就可以直接指定：

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

另一方面，如果來源型別的範圍不是被指定型別值範圍的子集合，那麼即使某個值確實落在被指定型別的範圍內，仍需要使用`()`進行轉型：

```csharp
short s = 42;
uint ui = (uint)s;
```
