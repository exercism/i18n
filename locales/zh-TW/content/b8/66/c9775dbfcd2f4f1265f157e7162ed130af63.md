# 條件式

Crystal 有所謂的控制運算式，用來控制程式的執行方式，它們會接受真值或假值。
有一類運算子可以用來產生真值或假值，這些稱為[相等與比較運算子][equality-and-comparison]。

控制哪些程式碼會執行、哪些不會的控制運算式主要有兩種，也就是決定會執行哪個分支。

這兩種是：`if`和`unless`運算式。

## 比較運算子

比較運算子用來比較值並回傳 `true` 或 `false`。這類運算子要求兩個型別相同的值才能比較。如果兩個值的型別不同，編譯器會拋出錯誤。
以下是比較運算子清單，以及它們產生 `true` 時的範例：

| 方法 | 說明           | 範例 |
| ------ | --------------------- | ------- |
| <      | 小於             | 4 < 5   |
| <=     | 小於或等於    | 4 <= 4  |
| >      | 大於          | 3 > 1   |
| >=     | 大於或等於 | 2 >= 2  |

## 相等運算子

相等運算子和比較運算子類似，但用來檢查兩個值是否相等。

`==`運算子會檢查兩個值是否相等，包括值的型別。如果兩個值相同，就回傳 `true`，否則回傳 `false`。
`==`運算子可以拿任何型別的值和任何其他型別的值比較。
`!=`的運作方式相同，但值不相等時回傳 `true`，相等時回傳 `false`。

## `if`敘述

[`if`][if]敘述用來檢查給定的條件是真值還是假值。如果條件為真值，`if`敘述裡的程式碼就會執行。`if`敘述以 `end`關鍵字結尾。

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## `unless`敘述

[`unless`][unless]敘述的運作方式和 `if`敘述非常相似，但如果條件為假值，它就會執行 `unless`敘述裡的程式碼。

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## `else`敘述

`else`敘述可以和 `if`、`unless`敘述搭配使用。如果 `if`分支或 `unless`分支沒有執行，就會執行 `else`敘述。

~~~~exercism/warning
即使 `else`分支可以和 `unless,`搭配使用，也不建議這麼做，因為會降低可讀性。
建議改用帶有 else 分支的 `if !condition`。
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## 「串接式 if」敘述

`elsif`敘述可以和 if 敘述搭配使用。如果 if 分支沒有執行，而且 `elsif`敘述的條件為真值，就會執行 `elsif`敘述。
`elsif`敘述可以串接在一起，第一個為真值的條件會被執行。
if 敘述最後也可以有一個 else 敘述，如果前面的敘述都沒成立，就會執行它。

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## 型別與條件式

當變數被指定成不同型別時，變數會同時帶有這兩種型別。這是因為編譯器不知道哪個分支會被執行。這種多重指定也稱為 union，會在之後的概念中介紹。以下範例可以看到這種情況：

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```

## 三元運算子

Crystal 有三元運算子，也就是單行的 if-else 敘述：`condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```
