# 關於

有時候你不需要為了建立帶有狀態的物件而付出額外負擔。
在這種情況下，可以使用`module`。

`module`與類別非常相似（事實上，`Module`是`Classes`在物件階層中的父類別），主要差別在於我們用的是類別方法，而不是實體方法。
類別方法以`self.`開頭，並且直接對模組呼叫。

例如：

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
