# 發展藍圖

這份文件概述了接下來幾個月裡，貢獻者與維護者可能會專注的主要主題。

## 主題總覽

- 改善現有的概念練習（請見[追蹤議題](https://github.com/exercism/javascript/issues/1415)）
- 建立更多概念練習（請見下方的課程大綱總覽）
- 為所有實作練習定義 `prerequisites` 與 `practices` 清單（請見[追蹤議題](https://github.com/exercism/javascript/issues/960)）
- 改善[測試執行器](https://github.com/exercism/javascript-test-runner/)
  - 修正 bug
  - 當變數定義在測試案例之外時，提供更友善的輸出
  - 將測試與任務連結起來
- 為所有現有的概念練習加上[分析器](https://github.com/exercism/javascript-analyzer/)註解
- 改善／更新／校對各種文件（貢獻指南、如何實作概念練習、docs、exercises/shared、reference 資料夾）

## 課程大綱總覽

### 已存在或已建立議題的概念

- `basics`
- `strings`（包含字串方法）
- `numbers`
- `booleans`
- `conditionals`（if/else）與`comparison`
- `for-loops`與`increment-decrement`
- `while-loops`
- `conditionals-switch`
- `objects`（作為鍵值集合）
- `null-undefined`
- `functions`
- `type-conversion`（包含 truthy/falsy）
- `template-strings`
- `conditionals-ternary`
- `callbacks`
- `arrow-functions`
- `classes`與`prototypes`
- `inheritance`
- `errors`
- `arrays`（包含用 push、pop 等進行陣列操作）
- `array-loops`
- `array-analysis`
- `array-transformation`
- `array-destructering`
- `rest-and-spread`
- `promises`
- `recursion`
- `closures`
- `sets`
- `randomness`
- `regular-expressions`
- `dates`
- `async-await`
- `type-checking`

### 未來可能加入的概念

- `maps`（可加入 Sets 練習，WeakSet/WeakMap 或許能作為第一次疊代先放進 about）
- `JSON`
- `math`
- getter/setter、旗標、描述器
- `proxy`
- `variables`（深入探討 const/let/var）
- `immutability`（包含 freeze，可與變數概念合併）
- `object-helpers`（例如 Object.assign）
- 字元與碼點
- this 與作用域（包含 call/bind）
- 迭代器與「列舉器」
- 產生器/yield
- 非同步產生器與迭代器
- 位元運算子
- 模組、匯入、匯出、動態匯入
- 鴨子型別
- 國際化 API
- `bigint`
- `symbol`
- JSDoc 註解
- 非同步、事件迴圈
- setTimeout/setInterval
- 事件
- 有時「萬物皆物件」（函式、陣列與原始型別跟物件的關係，例如裝箱型別）
