# 範圍

[範圍][range] 代表兩個值之間的區間。
最常支援範圍的型別是 `Int`、`Char` 和 `String`。
範圍可以用在許多地方，例如快速建立集合、切片字串、檢查某個值是否在範圍內，以及疊代。
範圍是用範圍運算子 `..` 或 `...` 建立的（分別包含與不包含結尾值）。

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

會有兩個範圍運算子，是為了建立包含或不包含結尾值的範圍，這在例如處理從零開始的索引時很方便。

範圍也可以用 `Range` 初始化器建立。

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Crystal 中使用範圍運算子 `..` 或 `...` 建立範圍，並且想對該範圍呼叫方法時，需要用括號把範圍包起來。
這是因為不這麼做的話，方法會被當成範圍運算子的第二個引數來呼叫。

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 取得子字串

想要切片字串時，可以使用範圍運算子來取得子字串。
也就是建立一個帶有子字串起始與結束索引的範圍。

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

你也可以用負索引從字串尾端取得子字串。

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 範圍方法

範圍確實有一組可以用來操作它們的方法。
例如，這些方法可以用來取得範圍中所有值的總和，或檢查範圍是否包含某個值。

| Method                  | Description                                                             | Example                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | 回傳範圍中所有值的總和                                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | 回傳範圍的大小                                                          | `(1..5).size # => 5`            |
| [`includes?`][indludes] | 如果範圍包含給定的值就回傳 `true`，否則回傳 `false`                     | `(1..5).includes?(3) # => true` |

## 無盡與無始範圍

範圍可以是無盡的，也可以是無始的。
無盡或無始範圍的起始值或結束值為 `nil`，但定義範圍時可以省略 `nil`。

當你想例如從字串開頭切片，或一路切到結尾時，使用無始和無盡範圍很方便。

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
如果沒有用在集合上，又沒有小心使用，無盡範圍可能會產生無盡的序列。
~~~~

## Char 範圍

字元可以用在範圍中，讓你取得兩個字元之間的字元區間。
例如，當你想取得字母表時就很方便。

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## 字串範圍

字串也可以用在範圍中，讓你取得兩個字串之間的字串區間。
但當字串範圍中使用多個字元時，它的行為和 `Char` 稍有不同。
在處理更複雜的字串範圍時，它的行為可能會讓人困惑，所以要小心。

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
