# 簡介

## Julia 中的布林值

真或假的值由 `Bool`型別表示。
它只包含兩個值：`true`和`false`。

```julia-repl
julia> true
true

julia> false
false
```

## 布林運算子

Julia 有三個布林運算子。

`&&`是布林的「且」。
如果 `&&`*兩側*的運算式都是 `true`，結果就是 `true`。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`是布林的「或」。
只要 `||`*任一側*的運算式是 `true`，結果就是 `true`。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`是布林的「非」。
它會把 `true`和 `false`互換。

```julia-repl
julia> !true
false

julia> !false
true
```

運算式越長、越複雜時，最好用括號讓你的意圖更清楚。

```julia-repl
julia> (true || false) && (false && true)
false
```
