# 關於

[Range][range] 代表兩個值之間的區間。
Range 常與 `Int`、`String`和`Character` 等型別搭配使用，用來疊代序列、切割集合，或檢查某個值是否落在邊界內。

Swift 提供兩種主要的 Range 運算子：

- **閉合 Range 運算子（`...`）**：同時包含起始值和結束值（`1...5` 包含 1、2、3、4 和 5）。
- **半開 Range 運算子（`..<`）**：包含起始值，但不包含結束值（`1..<5` 包含 1、2、3 和 4）。

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
直接在 Range 字面值上呼叫方法時，請把 Range 運算式用括號包起來，讓編譯器先求出 Range：

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## 將 Range 轉換成陣列

你可以使用 `Array(_:)` 初始化器，把一段數字的 Range 轉換成 `Array`：

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 用 Range 切割陣列

你也可以用 Range 取出陣列中的子區段：

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Range 的屬性和方法

Range 常見的操作包括：

| 成員                  | 說明                                                | 範例                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 回傳 Range 中的元素數量                | `(1...5).count` 回傳 `5`          |
| [`contains(_:)`][contains] | 若 Range 包含指定的值，就回傳 `true` | `(1...5).contains(3)` 回傳 `true` |

## 單邊 Range

Swift 也支援單邊（部分）Range，也就是省略起始值或結束值：

- `array[2...]`：從索引 2 到集合結尾。
- `array[...2]`：從集合開頭到索引 2（含）。
- `array[..<2]`：從集合開頭到索引 2（不含）。

## 字串與字元 Range

Range 也可以建立在遵循 `Comparable` 的字元或字串之間：

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
