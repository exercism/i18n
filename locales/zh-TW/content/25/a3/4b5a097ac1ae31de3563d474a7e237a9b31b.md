## 執行測試

1. 前往你的 PHP 練習目錄根目錄，也就是 `<EXERCISM_WORKSPACE>/php`。
   想知道 Exercism 工作區在哪裡，請執行

   ```shell
   exercism workspace
   ```

2. 如果還沒安裝 [PHPUnit]，請先安裝。
3. 用以下指令執行測試：

   ```shell
   phpunit test_file.php
   ```

   例如，要執行 Hello World 練習的測試，你可以執行：

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
