# 指令

當 Lisp 外星人初次來到地球時，他們遇見了無數稀奇古怪又美妙的事物，但他們最喜歡的發現之一，就是「寵物」。老實說，有哪個外星人不會對小狗或小貓心動呢？

Ludwig 在最近一趟地球假期之後，決定要養一隻屬於自己的寵物！唯一的問題是什麼？選擇實在太多了！或許你可以寫個程式，幫 Ludwig 找到並照顧他們下一個可以抱在懷裡的夥伴？

## 1. 挑選夥伴

雖然 Ludwig 很確定要養寵物，但這也是他們目前唯一想清楚的事。那麼，第一步就是決定要養哪一種寵物！

Ludwig 想找一個性格能與自己互補的夥伴。你能幫 Ludwig 寫一個叫做 `pal-picker` 的函式嗎？這個函式接受某個性格特質（一個關鍵字），並回傳具有該特質的寵物類型（一個字串）。

在這個情況下：

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

至於其他未知的性格，你的函式應該求值為：`"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. 在牠們的天然棲息地

既然 Ludwig 有了新朋友，他們就需要一個住的地方！你能幫 Ludwig 為他們的寵物挑選合適尺寸的床／水缸／籠子嗎？

在這裡，Ludwig 需要一個叫做 `habitat-fitter` 的函式，用來根據寵物以公斤計的體重（一個整數），選擇合適的棲息地大小（一個關鍵字）。

各種體型的寵物所需的棲息地是：

- 大於或等於 40kg -> `:massive`
- 20kg 到 39kg（含）-> `:large`
- 10kg 到 19kg（含）-> `:medium`
- 1kg 到 9kg（含）-> `:small`
- 小於或等於 0kg -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. 現在，開飯囉

所有地球寵物都有一個共同點：牠們都需要食物！不過這個概念對 Ludwig 來說有點陌生，因為他們常常忘記幫寵物的食盆補充食物。

Ludwig 需要一個簡單的函式 `feeding-time`，在食盆需要補充時提醒他們。這個函式會接受飽足百分比（一個整數），並以字串的形式回傳一則訊息。

如果食物量是：

- 高於 20% -> `"All is well."`
- 20% 或以下 -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. 行為準則

基本事項都安排妥當後，Ludwig 很期待嘗試各種有趣的事，像是「摸摸」和玩「你丟我撿」。話雖如此，並不是每種寵物都適合這些活動。

Ludwig 想要一對函式，也就是 `pet` 和 `play-fetch`，它們接受寵物類型（一個字串）；當動作不合適時，就什麼都不回傳，或回傳類似這樣的訊息：`"Maybe not with this pet..."`。

假設只有 `"Dog"`s 會玩你丟我撿，而且除了 `"Fish"` 之外所有寵物都可以摸摸。

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
