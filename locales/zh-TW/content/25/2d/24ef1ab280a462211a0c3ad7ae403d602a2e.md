# 介紹

## 實體變數

物件可以透過設定_實體變數_來保存自己的狀態。
這些變數存在於物件內部，通常用來儲存一些內部狀態。

實體變數一律以`@`開頭。
只要設定一個以`@`開頭的變數，就能建立新的實體變數。
例如：

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

物件通常會在`initialize`方法中設定初始狀態，當你對類別呼叫`new`時，這個方法會自動被呼叫。

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

`initialize`方法也可以接受引數，讓每個實體都能以自訂的狀態開始：

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

把_實體_變數視為對外部的讀取與寫入保持私有，是很好的做法。
我們改為定義方法來取得和設定它們的值。
例如：

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] 是英文單字，意思是「沒有」或「零」。
在 Ruby 中，`nil`用來表示物件的_不存在_。
在其他程式語言中，`null`或`none`值可能扮演類似的角色。

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby 在第一次遇到實體變數時，會給它預設值`nil`，直到它被賦予其他值為止。

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
