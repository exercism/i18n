# 說明

你正在記錄每天有多少鳥來拜訪你的花園。這些資料以整數陣列儲存，**今天的數量排在最前面**。

## 1. 今天的數量

定義`today`，讓它從堆疊取出每日數量的陣列，並回傳今天的數量；如果陣列是空的，就回傳`f`。

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. 增加今天的數量

定義`increment-day-count`，回傳一個新的陣列，其中今天的數量加一。如果輸入是空的，就回傳`{ 1 }`。

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. 有沒有哪一天沒有鳥？

定義`has-day-without-birds?`，如果至少有一天記錄到零隻鳥，就回傳`t`，否則回傳`f`。

**使用遞迴**，不要用`any?`或其他高階序列詞彙。

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. 開始記錄以來的鳥類總數

定義`total`，回傳所有數量的總和。

**使用遞迴**，不要用`sum`。

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. 忙碌的日子

忙碌的一天是指有五隻或更多鳥的一天。定義`busy-days`，回傳忙碌日子的數量。

**使用遞迴**，不要用`count`。

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
