# 引號簡介

剛開始寫 bash 的程式設計師會一聽再聽到的建議：

> 把變數加上引號！

為什麼呢？

當你展開變數（例如`$name`）時，幾乎總是希望把變數的_值_當成單一字串（或數字）。
你不會希望這個值意外被當成兩個或多個分開的字串處理。

## 引號

引號是確保一段文字被視為單一詞彙的主要機制。
引號主要有兩種。

### 雙引號

雙引號內允許參數展開、算術展開與命令替換。

```bash
echo "This is bash version $BASH_VERSION"
```

你可以在雙引號字串中加入字面上的雙引號，只要在它前面加上反斜線。

```bash
echo "She said \"Let me teach you about bash.\""
```

### 單引號

單引號內_不會_進行任何展開。

```bash
echo 'This is bash version $BASH_VERSION'
# ...^..................................^
# prints exactly: This is bash version $BASH_VERSION
```

在單引號字串中_無法_嵌入單引號。

## 引號的重要性

到底為什麼`echo $name`會有問題？

當 shell 解析一行程式碼時，會依序進行[幾種展開][expansions]。
最後的幾個展開中有兩個是_詞分割_與_檔名展開_。

### 詞分割

任何參數展開、命令替換或算術展開的結果，只要_不是發生在雙引號內_，都符合進行「詞分割」的條件。
shell 會取用展開後的結果，並依照`$IFS`值中出現的任何字元序列來分割它。
預設情況下，這包含空格、定位字元與換行。

我們可以用 shell 迴圈實際看看：

```bash
sentence="The quick brown fox jumps."
i=0
for word in "$sentence"; do echo "$((++i)) $word"; done
# ..........^.........^
```
輸出
```none
1 The quick brown fox jumps.
```

但不加引號時：

```bash
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
輸出
```none
1 The
2 quick
3 brown
4 fox
5 jumps.
```

換個`$IFS`值來看看：

```bash
csv="first,second,third"
IFS=","
for word in $csv; do echo "$word"; done
```
輸出
```none
first
second
third
```

#### 停用詞分割

停用詞分割的一個技巧，是把`$IFS`設成空字串

```bash
sentence="The quick brown fox jumps."
IFS=    # or explicitly, IFS=""
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
輸出
```none
1 The quick brown fox jumps.
```

不過，除非你也停用檔名展開，否則不建議讓變數不加引號。
我們會在下面看到怎麼做。

### 檔名展開

「glob」樣式用來表示精簡的模式，以比對一組檔案。
例如，你可以用`*.md`比對某個目錄中所有的 Markdown 檔案。
[glob 樣式][glob] 自 Unix 發明以來就存在了。

glob 的萬用字元有：

* `*`比對零個或多個任意字元，
* `?`比對恰好一個任意字元，
* `[...]`比對方括號內所列字元集合中的恰好一個字元。

   ~~~~exercism/advanced
   <details><summary>

   點這裡顯示。
   </summary>

    * `[abc]`比對恰好一個字元，該字元是`a`、`b`或`c`。
        * 若要在運算式中包含字面上的右括號，把它放在左括號後的第一個字元（可有可無的`^`之後）
            * `[][]`是一個字元集合，會比對右括號或左括號。
            * 或是用反斜線跳脫：`[[\]]`
    * `[x-y]`比對恰好一個字元，該字元落在從`x`到`y`的_範圍_內
        * 若要在字元集合中包含字面上的連字號，它必須是左括號後的第一個字元（可有可無的`^`之後），或是右括號前的最後一個字元。
            * `[-xy]`或`[xy-]`都各自比對恰好一個字元，該字元是`-`、`x`或`y`
            * 或是用反斜線跳脫：`[x\-y]`
        * 可以指定多個範圍，例如`[0-9A-Fa-f]`比對一個十六進位數字
    * `[^abc]`比對恰好一個字元，該字元**不是**`a`、`b`或`c`，
    * `[^x-y]`比對恰好一個字元，該字元**不是**落在從`x`到`y`的範圍內
    * `[[:character_class:]]`比對一個字元，該字元屬於名為「character_class」的類別
        * 可用的字元類別有：
            * `lower`：小寫字母
            * `upper`：大寫字母
            * `alpha`：字母
            * `digit`：數字
            * `alnum`：字母與數字
            * `space`：空白字元
            * `blank`：水平空白字元（空格與定位字元）
            * `xdigit`：十六進位數字
            * `word`：識別字中允許的字元（字母、數字、底線）
            * `punct`：標點符號
            * `cntrl`：控制字元
            * `graph`：「可見」字元
            * `print`：可見字元加上空格
        * 它們可以組合：
            * `[[:alpha:]]`類別由`[[:lower:][:upper:]]`組成
            * `[[:alnum:]]`類別由`[[:alpha:][:digit:]]`組成
            * `[[:word:]]`類別由`[[:alnum:]_]`組成
            * 底線（八進位 137）同時屬於`[[:word:]]`和`[[:punct:]]`
            * `[[:graph:]]`類別由`[[:alnum:][:punct:]]`組成
            * `[[:print:]]`類別由`[[:graph:] ]`組成，也就是只有空格（八進位 040），不含其他任何空白字元。

#### 疊代檔案清單

你可以用`for`迴圈疊代檔案清單

```bash
for file in *.csv; do
    do_something_with "$file"
done
```

請注意變數`"$file"`有加上引號。
glob 樣式可能會傳回名稱中含有空格的檔案。
我們需要把變數加上引號，這樣`do_something_with`命令才會收到恰好一個引數，也就是檔案名稱。

#### Glob 樣式不是正規表達式

Glob 樣式**不是**正規表達式。

* 比對恰好一個字元
   * 正規表達式`.`
   * glob`?`
* 比對零個或多個字元
   * 正規表達式`.*`
   * glob`*`
        * glob 樣式`.*`的意思是「比對一個檔案名稱，其第一個字元是字面上的點，後面接著零個或多個任意字元」。
* 比對一個或多個字元
   * 正規表達式`.+`
   * glob`?*`
* 正規表達式的字元集合與 glob 的字元集合行為相同。

#### 引號與檔名展開

有些時候你會想抑制檔名展開。
處理使用者輸入就是其中一種情況。
看看這段程式碼

```bash
read -p "Enter something: " user_input
echo $user_input
```

如果使用者輸入星號（`*`），會輸出什麼？
目前目錄中的檔案清單。
這大概不是你想要的結果。

另一個例子是把樣式當作引數傳給預期收到樣式的程式。
`tr`程式經常用於文字操作。要把變數的值轉成小寫，可以這樣做

```bash
var="My Puppet"
echo "$var" | tr '[:upper:]' '[:lower:]'
```
輸出
```none
my puppet
```

常見的錯誤是忘了把`tr`的引數加上引號：`tr [:upper:] [:lower:]`

~~~~exercism/caution
這為什麼會出問題？
沒有加上引號的 glob 樣式會被展開成相符的檔案清單。
假設使用你腳本的人，目前的目錄裡有 `p`、`u`、`w` 這幾個檔案：

```bash
touch p u w
var="My Puppet"
echo "$var" | tr [:upper:] [:lower:]
```

這會導致錯誤！

未加引號的`[:upper:]`樣式會比對`:`、`u`、`p`、`e`或`r`中的任一個。
未加引號的`[:lower:]`樣式會比對`:`、`l`、`o`、`w`、`e`或`r`中的任一個。
Bash 會為第一個樣式比對到檔案`p`和`u`，為第二個樣式比對到檔案`w`，於是`tr`被這樣呼叫

```bash
echo "$var" | tr p u w
```

而這對`tr`來說是錯誤的引數數量。
~~~~

#### 停用檔名展開

你可以用[`set`][set]命令來停用檔名展開。

```bash
echo *      # prints a list of files
set -f      # disable filename expansion
echo *      # prints a literal asterisk
set +f      # enable filename expansion
```

#### 控制檔名展開

內建的[`shopt`][shopt]命令有幾個設定可以控制檔名展開的運作方式。
其中幾個有趣的設定是：

* `shopt -s nocaseglob`：執行不區分大小寫的比對
* `shopt -s extglob`：啟用擴充樣式
* `shopt -s nullglob`：如果沒有檔案相符，就把樣式替換成空無。
   預設行為是讓樣式以字面上的字串保留下來。
