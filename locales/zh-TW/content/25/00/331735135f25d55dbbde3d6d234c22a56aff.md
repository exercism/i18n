# 關於

關於 C# 字串，最需要記住的一點是：它們是不可變的物件，用來表示由 Unicode 字元（字母、數字、標點符號等）組成的文字序列。使用雙引號來定義一個`string`執行個體：

```csharp
string fruit = "Apple";
```

要操作字串，可以呼叫它的其中一個[方法][methods]或[屬性][properties]。由於字串值一旦定義之後就永遠不會改變，所有字串操作方法都會回傳一個新的字串。

字串以雙引號（`"`）字元作為分隔。有些特殊字元需要使用反斜線（`\`）字元來[跳脫][escaping]。字串也可以在前面加上 at（`@`）符號，讓它成為[逐字字串][verbatim]，會忽略任何跳脫字元。

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

如果你只需要字串的一部分，可以使用[`Substring()`方法][substring]來只取出那一部分：

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

[`IndexOf`()方法][indexof]可以用來找出某個`string`在另一個`string`中第一次出現的索引，如果找不到指定的值，就會回傳`-1`：

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

最後，有[許多串連字串的方法][concatenation]。最簡單的方式是使用[`+`運算子][plus-operator]。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

如果需要比單純串連更複雜的字串格式化，建議改用[字串插值][interpolation]。要在字串中啟用插值，請在字串前面加上錢號（`$`）符號。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
