# 指令補充

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | 輸入     | 整數 | x                          |
| `$a1`    | 輸入     | 整數 | y                          |
| `$v0`    | 輸出    | 整數 | 得分              |
| `$t0-9`  | 暫存 | 任意     | 用於暫存資料 |
