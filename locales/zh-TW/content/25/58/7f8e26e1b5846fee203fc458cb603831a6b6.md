# 說明

你正與一個網站開發團隊合作，維護一支當地籃球隊的網站。這個團隊對 Elixir 比較不熟悉，因此希望有一個函式能從一連串巢狀的 map 中擷取資料，讓開發更快速。

## 1. 從巢狀的 map 結構中擷取資料

實作`extract_from_path/2`函式，它接受兩個引數：

- `data`：一個巢狀的 map 結構，裡面是這支籃球隊的資料。
- `path`：一個以句點分隔鍵的字串，用來取得最後一個鍵所對應的值。

如果路徑中任何一個環節的值或鍵不存在，就應該回傳 `nil`。

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

實作這個函式時，請使用 _Access Behaviour_。

處理巢狀 map 資料結構時，請不要使用任何 `Map` 或 `Kernel` 模組函式。

## 2. 使用內建的函式重構

審查你程式的同事告訴你，`Kernel` 模組裡有一個函式和你目前的實作非常相似。

請實作 `get_in_path/2`，改用這個 `Kernel` 模組函式。

它預期的引數和第 1 部分相同。

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
