# 提示

## 一般

- `delivery_date()`的輸入是兩個`String`引數，輸出則是`String`。
- 所有日期字串都採用 [ISO 8601][iso] 格式，這也是 Julia 預設的字串表示法。
- `Dates`模組的實用文件包括：
  - Exercism 的[學習路徑][dates-times]。
  - [Julia 手冊][Dates]。
  - [Wikibook][Wikibook]。
- 最基本來說，你需要熟悉 [DateTime][datetime] 建構子，以及如何加減 [Periods][period]。
- 實用的函式包括 [`dayofweek()`][dayofweek]，以及（可選）[`lastdayofmonth()`][lastdayofmonth] 或 [`lastdayofquarter()`][lastdayofquarter]。
- 若要從字串中取出整數，[`parse()`][parse] 函式會很重要。
- 如果你的解法會用到高階函式，[`tonext()`][tonext] 和 [`toprev()`][toprev] 這兩個函式可能很有用。
