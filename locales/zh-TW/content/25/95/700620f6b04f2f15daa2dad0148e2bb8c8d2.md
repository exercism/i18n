# 簡介

## 切片

Go 的切片類似於其他語言的陣列。
切片可以存放多個特定型別（或介面）的元素。

Go 的切片是以陣列為基礎。
陣列的大小是固定的。
相對地，切片則是動態調整大小、具彈性的陣列元素檢視。

切片的寫法類似`[]T`，其中`T`是切片中元素的型別：

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

你可以使用方括號語法，取得或設定指定以 0 為起算索引的元素：

```go
withData[1] = 5
x := withData[1] // x is now 5
```

你可以從現有的切片取得一段元素範圍，建立新的切片。
同樣是使用方括號語法，但要同時指定起始索引（含）與結束索引（不含）。
如果沒有指定起始索引，預設為 0。
如果沒有指定結束索引，預設為切片的長度。

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

你可以使用`append`函式將元素加入切片。
下面我們把`4`和`2`加入`a`切片。

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append`總是會回傳一個新的切片；當我們只是想把元素加入現有的切片時，通常會像上面那樣，把它重新指定回我們當作第一個引數傳入的切片變數。

`append`也可以用來合併兩個切片：

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## 可變參數函式

一般來說，Go 的函式只接受固定數量的引數。
不過，在 Go 中也可以撰寫可變參數函式。

可變參數函式是指能接受數量不定之引數的函式。

如果函式定義中最後一個參數的型別前面加上省略符號`...`，那麼這個函式就能針對該參數接受任意數量的引數。

```go
func find(a int, b ...int) {
    // ...
}
```

在上面的函式中，參數`b`是可變參數，我們可以傳入 0 個或多個引數給`b`。

```go
find(5, 6)
find(5, 6, 7)
find(5)
```

~~~~exercism/caution
可變參數必須是函式的最後一個參數。
~~~~

可變參數函式的運作方式，是把數量不定的引數轉換成一個型別為該可變參數型別的切片。

以下是可變參數函式實作的範例。

```go
func find(num int, nums ...int) {
    fmt.Printf("type of nums is %T\n", nums)

    for i, v := range nums {
        if v == num {
            fmt.Println(num, "found at index", i, "in", nums)
            return
        }
    }

    fmt.Println(num, "not found in ", nums)
}

func main() {
    find(89, 90, 91, 95)
    // =>
    // type of nums is []int
    // 89 not found in  [90 91 95]

    find(45, 56, 67, 45, 90, 109)
    // =>
    // type of nums is []int
    // 45 found at index 2 in [56 67 45 90 109]

    find(87)
    // =>
    // type of nums is []int
    // 87 not found in  []
}
```

在上面程式中的`find(89, 90, 91, 95)`這一行，傳給 find 函式的數量不定引數是`90`、`91`和`95`。
`find`函式預期`num`之後有一個可變的 int 參數。
因此，編譯器會把這三個引數轉換成型別為`int`的切片`[]int{90, 91, 95}`，然後以`nums`傳給 find 函式。

有時候你已經有一個切片，想把它傳給可變參數函式。
這可以透過在切片後面加上`...`來達成。
這會告訴編譯器在可變參數函式中直接使用該切片。
在這種情況下，前面提到建立切片的步驟會直接省略。

```go
list := []int{1, 2, 3}
find(1, list...) // "find" defined as shown above
```
