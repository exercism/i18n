# 關於

[元組](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples)是一組_不可變_、未命名但有序的值。
元組可以容納任何（或多個）資料型態，也包括其他元組。

元組定義為`(`和`)`字元之間、以逗號分隔的值：`(<element_1>, ... , <element_n>)`。

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

只有長度相同、型別相同（且順序相同）的元組才能互相比較。
元組具有結構相等性，這表示唯有當所有值都相等時，它們才算相等。

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

你可以用[三種方式從元組中擷取值](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values)：

- `fst`和`snd`函式
- 元組解構
- 模式比對

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
嚴格來說，你可以用元組的`.Item1`、`.Item2`、……等屬性來存取它的值，但並不建議這麼做，而且會產生編譯器警告。
~~~~

## 元組的重點

關於元組，有幾個重點值得了解：

- 某個特定元組型別的執行個體是單一物件，就像 C# 中含兩個元素的陣列那樣。搭配函式使用時，它們算作單一參數。唯一的例外是用多個參數呼叫非 F# 程式碼時，在這種情況下你會傳入一個元組，而它的值會自動擷取到對應的參數值。
- 元組型別無法取明確的名稱。元組型別的「名稱」取決於相乘在一起的型別組合。
- 定義元組的關鍵符號是逗號，而不是括號。你可以不用括號來定義元組，雖然有時會讓人混淆。在 F# 中，如果你看到逗號，它很可能就是元組的一部分。
- 元組可以作為函式的引數，也可以作為函式的回傳值。
