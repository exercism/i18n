# 指令

你是 IT 服務台的一員，你想要改善工單系統，讓它更有效率，並為你的主管提供統計資料。

一張工單有狀態（new、in progress……）、建立者（以使用者名稱和員工 ID 辨識），可以被指派給 IT 員工，並包含留言的歷史紀錄。

以下四個任務可以改善你目前的工單系統。

## 1. 偵測空白留言

空白留言會讓介面顯得雜亂，又無法提供任何資訊，所以你想把它們過濾掉。

定義一個輔助函式`emptyComment`，它接收一組使用者與留言的配對，並對空白留言回傳`True`。

在函式的引數中直接使用解構，取出使用者和留言。你不需要那位使用者的資訊，所以可以忽略它。

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. 計算建立者的留言數量

你的主管想要掌握使用者在工單流程中的參與情況統計。
她要你查看工單建立者新增了多少留言。

定義`numberOfCreatorComments`，它接收一張工單，並回傳工單建立者新增的留言數量。

在函式的引數中使用解構，從`Ticket`型別取出記錄，同時取出你需要的欄位。
接著，在`let`綁定中解構`createdBy`，這樣就能計算相關的留言。
使用`List`的函式來計數，並在匿名函式的引數中使用解構，以分開使用者與留言的配對。

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. 偵測指派給 Dev Team 的工單

有些工單必須呈報給 Dev Team 的 Alice、Bob 或 Charlie。
密切留意這些工單、確保它們持續有進展，是很重要的。

定義一個輔助函式`assignedToDevTeam`，用來檢查工單是否指派給 Dev Team 的其中一位成員。

在函式的引數中使用解構，從`Ticket`型別取出記錄，以及你需要的欄位。
接著，用單一的`case`敘述檢查工單是否指派給 Alice、Bob 或 Charlie：使用遞迴模式比對取出他們的使用者名稱，並使用字面值模式比對來比對它們。

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. 將工單指派給 IT 員工

有時候一批工單需要重新指派給其他 IT 員工。

定義一個函式`assignTicketTo`來幫你完成這件事。這個函式接收兩個引數：要指派工單的目標使用者，以及一張工單。
如果工單的狀態是`New`，就把它指派給新的使用者，並將狀態改為`InProgress`。
至於其他狀態，只要把工單重新指派給新的使用者即可，但狀態為`Archived`的工單完全不能修改。

在函式的引數中使用解構，從`Ticket`型別取出記錄以及你需要的欄位，並使用`as`關鍵字將整個記錄原樣捕捉下來。
用單一的`case`敘述對狀態進行模式比對，並回傳適當的工單，該工單是由你以`as`關鍵字捕捉的原始記錄修改而來。

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
--        { status = InProgress
--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
