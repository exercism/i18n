# 指令

Elyse 是個準魔術師，她正繼續她的訓練。
她會拿到好幾副撲克牌，用來表演她的魔術。
為了讓事情簡單一點，她只用 1 到 10 的牌。
每張牌她都只有一張，牌組裡不會有重複的牌。

在這個練習中，請使用 Julia Base 函式庫中的方法來分析陣列的內容。

## 1. 判斷某張牌是否存在

Elyse 想知道某張牌是否在牌組裡，換句話說，牌組是否包含某個特定的數字。

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. 找出某張牌的位置

Elyse 想知道某張牌在牌組中的位置（索引）。
如果這張牌不在牌組裡，就回傳`nothing`。

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. 判斷每張牌是否為偶數

Elyse 想知道是否每張牌都是偶數，換句話說，牌組中的每個數字是否都是偶數。

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. 檢查牌組中是否含有奇數牌

Elyse 想知道牌組裡是否有奇數。

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. 判斷第一張偶數牌的位置

Elyse 想知道第一張偶數牌的位置。
如果牌組裡沒有偶數牌，就回傳`nothing`。

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. 從牌組中取得第一張奇數牌

Elyse 想知道第一張奇數牌的值。
如果牌組裡沒有奇數牌，就回傳`nothing`。

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
