# 關於

浮點數是包含小數點的小數或整數（像是`3.14`、`-1.7`、`99.99`、`2048.0`）。

Common Lisp 的 float 型別細分成幾種子型別，每一種都有自己的特性與精確度：short-float、single-float、double-float 和 long-float。

short-float 子型別通常佔用的記憶體最少，在四種子型別中精確度也最低。它適合用在記憶體用量是考量點，但可以接受較低精確度的情況。

single-float 子型別在記憶體用量與精確度之間取得平衡。它經常用於一般用途的浮點數運算。

double-float 子型別的精確度比 single-float 更高，適合需要更精確計算的應用，例如科學運算與數值模擬。

long-float 子型別在四種子型別中精確度最高，但相較於其他子型別，可能需要更多記憶體。它通常用於需要極高精確度計算的特殊應用。

這些子型別讓 Common Lisp 程式設計師能依照自己應用程式的需求，選擇合適的精確度與記憶體用量。

一般來說，如果你處理的都只是整數，應該優先使用整數，因為在大量運算之後，整數不會像浮點數那樣有精確度流失的問題。

## 參考資料

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
