# 關於

`SYMBOL:`並不*儲存*值，它只是一個名稱。值存在於命名空間中，而名稱則是用來取用它的鍵。

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

兩種作用域：

- **全域**：透過`set-global`、`get-global`、`change-global`寫入與讀取。值會持續存在於整個行程的生命週期內。
- **動態**：透過`set`、`get`、`change`寫入與讀取。綁定只在`with-variable`表單的執行期間存在，讓外層程式碼能「注入」內層程式碼看見的值，而不必改動中間每一層的函式簽章。

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:`和`SYMBOLS:`會在 vocabulary 載入時宣告符號，讓它們成為可跨檔案共用的參照。
