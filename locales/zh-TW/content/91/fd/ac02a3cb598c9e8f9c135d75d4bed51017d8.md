# 簡介


PowerShell 有[`bool`][booleans]型別，可以用來表示 true 和 false 這兩種值。
這個型別只有兩個值：`True` 和 `False`。
你可以用 `$` 前綴把這些值綁定到變數：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

我們可以用`-and`、`-or`和`-not`這類[邏輯運算子][logical-operators]來組合並求值布林運算式。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```
