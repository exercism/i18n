# Instructions

身為西洋棋愛好者，你想寫出自己版本的這款遊戲。
沒錯，網路上或許早已有許多現成的西洋棋實作，但你的版本會獨一無二！

你先從實作棋子的基本移動系統開始。

這場西洋棋會在寬八格、長八格的棋盤上進行。
棋盤上的每個格子都用一個字母和一個數字來標示。

## 1. 定義行與列的範圍

遊戲需要儲存棋盤上的行。
行是棋盤上橫向的排列，編號從 1 到 8。

遊戲也需要儲存棋盤上的列。
列是棋盤上縱向的排列，以字母 A 到 H 來標示。

定義 `Chess::RANKS` 和 `Chess::FILES` 這兩個常數，分別儲存行與列的範圍。

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. 檢查格子是否有效

遊戲需要檢查某個格子是否有效。
當格子的行和列都落在行與列的範圍內時，這個格子就是有效的。

定義 `Chess.valid_square?` 方法，它接受引數 `rank`（存放該行的整數）和 `file`（存放該列的字元）。
如果行和列都落在行與列的範圍內，這個方法應該回傳 `true`，否則回傳 `false`。

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. 取得玩家的暱稱

遊戲需要取得玩家的暱稱。
暱稱是玩家名字的前兩個字元，加上姓氏的最後兩個字元。
暱稱應該全部轉成大寫。

定義 `Chess.nickname` 方法，它接受引數 `first_name`（存放玩家名字的字串）和 `last_name`（存放玩家姓氏的字串）。
這個方法應該以全大寫的字串回傳玩家的暱稱。

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 建立移動訊息

遊戲需要為每一步移動建立訊息，說明是哪位玩家移動到哪個格子。
訊息應該使用玩家的暱稱，以及他們移動到的格子。
遊戲也必須判斷這步移動是否有效，檢查這個格子的列和行是否落在列與行的範圍內。

如果移動有效，訊息應該是：`"{nickname} moved to {square}"`
如果移動無效，訊息應該是：`"{nickname} attempted to move to {square}, but that is not a valid square"`

定義 `Chess.move_message` 方法，它接受引數 `first_name`（存放玩家名字的字串）、`last_name`（存放玩家姓氏的字串），以及 `square`（存放玩家移動到的格子的字串）。
這個方法應該以字串回傳這步移動的訊息。

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
