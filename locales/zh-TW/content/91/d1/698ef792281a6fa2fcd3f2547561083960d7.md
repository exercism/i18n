# 簡介

## 位元運算

位元運算讓我們可以操作二進位數字裡的個別位元。

Elm 在它的 [Bitwise 模組](https://package.elm-lang.org/packages/elm/core/latest/Bitwise) 中提供了幾個位元運算子。

### 基本運算

修改數字中的個別位元稱為_遮罩_。
_遮罩_是一個數字，其中特定的位元以特定方式設定，讓我們能用 `and`、`or` 和 `xor` 等位元運算子來操作另一個數字。

#### and

`and` 會把兩個數字合併，只保留在兩個數字中都是 `1` 的位元。
這在檢查某個位元是否被設定時很有用。
舉例來說，要檢查某個數字的第 4 個位元是否設為 `1`，可以把它和遮罩 `01000`（十進位的 `8`）做 `and`，然後看看結果是不是非零：

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

#### or

`or` 會把兩個數字合併，只要某個位元在其中一個或兩個數字中是 `1`，就把結果的該位元設為 `1`。
這在把某個特定位元設為 `1` 時很有用。
舉例來說，要把 `10101` 的第 2 個位元設為 `1`，可以把它和遮罩 `00010` 做 `or`：

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

#### 互斥或（xor）

`xor` 會把兩個數字合併，如果某個位元在一個數字中是 `1`、在另一個數字中是 `0`，就把結果的該位元設為 `1`。
這在把某個位元翻轉成相反值時很有用：

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

#### 補數

`complement` 會反轉數字中的每個位元（`0` 變成 `1`，`1` 變成 `0`）。

要注意，這會讓正數變成負數，負數變成正數。
這是因為二進位中的負數是以最左邊的位元為 `1` 來表示。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

#### 位移

以下運算子會把位元向左或向右移動指定的位置數量，效果等同於乘以或除以 2 的次方。

`shiftLeftBy` 會把位元向左移，並從右側補 `0`。
舉例來說，把 `21` 向左移 3 個位置：

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

這等同於 `21 * 2^3 = 21 * 2 * 2 * 2 = 168`。

`shiftRightBy`：把位元向右移：

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

向右移 2 個位置等同於整數除以 4。

要注意，這個函式會複製最左邊位元的值。
因此，負數會維持負數：

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

如果你想向右移位並補零，可以使用 `shiftRightZfBy`：

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
