# 說明

從前有一位古怪的程式設計師，住在一棟裝了鐵窗的奇怪房子裡。
有一天，他在一個線上求職網站上接了一份工作，要打造一台派對機器人。
這台機器人應該要向人們打招呼，並帶他們到座位上。
第一版非常技術取向，顯露出這位程式設計師不太會與人互動。
其中有些部分也延續到了下一版。

## 1. 歡迎派對的新賓客

實作`Welcome`函式，用給定的名字回傳一則歡迎訊息：

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. 歡迎今天生日的新賓客參加派對

實作`HappyBirthday`函式，用給定的名字和年齡回傳一則生日訊息。
可惜這位程式設計師有點愛現，所以機器人得展示它知道每一位賓客的生日。

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. 指引方向

實作`AssignTable`函式來指引方向。
它應該接受 5 個參數。

- 要迎接的新賓客名字（`string`）
- 桌號（`int`）
- 同桌賓客的名字（`string`）
- 桌子所在的方向（`string`）
- 到桌子的距離（`float64`）

確切的結果格式可以參考下面的範例。

機器人會以 3 位數的格式提供桌號。
如果數字不足 3 位數，就會在前面補上零，補足成 3 位數（例如 3 會變成 003）。
機器人還會說出桌子的距離。
幸好精確度只限於 1 位小數。

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
