# 說明

你在遊樂園工作，收到了一份規格書，要設計一套管理入場與遊樂設施的系統。你的任務是為入場者（造訪樂園的人）建立模型。

## 1. 建立新的入場者

實作`Attendee`類別的`Attendee#initialize`方法，它應該接受一個身高（單位是公分），並將它存成實例變數。

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. 入場者有多高

實作`Attendee`類別的`Attendee#height`取值方法，它應該回傳該實例的高度。

```ruby
Attendee.new(106).height
# => 106
```

## 3. 搭乘通行證的 id 是什麼

不是所有入場者都買了搭乘通行證，但我們需要知道他們有沒有通行證。為`Attendee`類別實作`Attendee#pass_id`取值方法，它應該回傳該實例的`pass_id`，如果入場者沒有通行證則回傳`nil`。

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. 讓人們可以購買通行證

實作`Attendee#issue_pass!`來改變實例的狀態，並把通行證 id 的實例變數設為傳入的引數。它應該回傳通行證 id。

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. 撤銷通行證

有些遊客會做出不安全的行為而違反規定，所以樂園希望能撤銷通行證。實作`Attendee#revoke_pass!`來改變實例的狀態，並把通行證 id 設為`nil`。

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
