# 補充說明

## 在 Prolog 中處理日期

Prolog 內建的日期支援[相當基本][built-in-dates-support]。雖然只用 Prolog 內建的功能就能解這道練習，但透過 [date_time 套件][date-time-package]來處理日期會輕鬆許多。

### 安裝 date_time 套件

如果你的 Swipl 版本還算新，可以執行以下指令來安裝套件：

```bash
swipl pack install date_time
```

如果這樣行不通，可以執行：

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
如果你使用的是線上編輯器，就不需要手動安裝任何東西。
~~~~

### 使用 date_time 套件

在解答檔案最上方加入以下程式碼，即可使用`date_time`套件：

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
提示：[date_time 套件的原始碼][date-time-package-source]有完整的文件說明，會是很大的幫助！

~~~~
