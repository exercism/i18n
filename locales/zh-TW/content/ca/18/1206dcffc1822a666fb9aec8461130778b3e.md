# 關於

Haxe 內建支援正規表達式。你可以用它們來驗證字串的格式、轉換字串，或從指定的文字中擷取符合規則的資料。

要建立正規表達式，在`~/`和`/`之間輸入：

```haxe
var r = ~/haxe/i;
```

另一種做法是使用`EReg()`實例：

```haxe
var r = new EReg("haxe", "i");
```

這裡的`i`是一個旗標，讓模式不分大小寫。還有其他旗標，包括：

- `g`：全域取代。
- `m`：多行比對

在`~/`和`/`之間，你輸入的是正規表達式的模式。舉例來說，你想找出含有 A 到 Z 字母的字串。這裡可以使用範圍模式`[A-Z]`。模式有很多種，包括：

- `.`：任何字元
- `*`：重複零次或多次
- `+`：重複一次或多次
- `[A-Z0-9]`：字元範圍
