# 關於

條件運算式會根據某個條件是否為 **true** 或 **false**，來決定是否執行程式碼。這些運算式的寫法如下：

```haxe
if (condition) {
  expressions
};
```

條件的輸出屬於 `Bool` 型別，因此當輸出為 `true` 時，就會執行這些運算式。

有時候，當條件實際上是 `false` 時，我們會想執行另一段程式碼，這時就輪到 `else` 運算式上場了。當最初的條件為 `false` 時，`else` 會執行其中的運算式。但要是我們想針對多種可能的情況檢查條件呢？這時就會使用 `else if (condition)`。以下是一個完整的範例：

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
