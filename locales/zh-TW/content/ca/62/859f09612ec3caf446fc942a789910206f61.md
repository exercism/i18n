# 執行測試

SWI Prolog 可以互動方式執行，也可以直接在命令列執行。

## 命令列

你可以用下列指令從命令列執行測試：

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

請把`<exercise>`替換成你正在實作的練習名稱。

## 互動模式

如果想以互動方式執行 Prolog，請先執行：

```bash
swipl
```

Prolog 主控台啟動後，載入你的實作並用下列方式執行測試：

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

請把`<exercise>`替換成你正在實作的練習名稱。

### 重新載入變更

載入上述檔案後，只要執行下列指令，就能套用你做過的任何變更：

```
?- make.
```

## 跳過的測試

當你初次開始一個練習時，只會執行第一個測試。其餘的測試都透過在`test`目標中加上`condition(pending)`而被跳過。
第一個測試通過後，把`condition(pending)`裡的`pending`改成`true`，就能取消跳過下一個測試。
對每個測試重複這個步驟，直到所有測試都能執行並通過。

### 命令列

在指令最後加上`-- --all`引數，就能一併執行所有待執行的測試：

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
