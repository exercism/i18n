# 簡介

Go 的函式和方法可以回傳多個值：

```go
func GetCard() (Card, error) { ... }
```

每個回傳值都必須依序指定，並以逗號分隔：

```go
card, err := GetCard()
```

指定語句中的每個位置都會宣告一個變數。
如果有任何已宣告的變數沒有被使用，Go 就不會編譯通過。
空白識別碼`_`可以代替變數名稱，藉此略過該回傳值：

```go
card, _ := GetCard()
```

`error`是內建的介面。
`nil`錯誤代表沒有發生任何錯誤；任何非 nil 的值都代表出了問題。
依照慣例，可能失敗的函式應該把 `error` 當作最後一個回傳值。
呼叫端在使用其他回傳值之前，必須先檢查它：

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
