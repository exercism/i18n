# 關於

C 是一種靜態型別語言，這代表所有東西在編譯時期都有型別。為[變數][variable]命名並設定它的型別，這個過程稱為宣告變數。

宣告變數時，必須明確指定它的型別。變數名稱[必須遵守一些規則][name-rules]，例如開頭必須是字母或底線。有些名稱不能使用，因為它們被保留[給關鍵字][reserved-keywords]或[其他識別碼][reserved-identifiers]。

設定或更新變數是透過變數賦值來完成。設定變數的值即為定義該變數。定義變數也稱為初始化。

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

變數的值可以使用 [`=` 簡單賦值運算子][assignment-operator]來指定與更新。變數一旦定義之後，它的型別就永遠不會改變。

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C 是一種[命令式][imperative]的[程序式][procedural]語言。所有運算都是由一連串的[敘述][statements]所組成，而這些敘述屬於某個[函式][function]或多個函式。

每個函式可以有零個或多個[參數][parameters]。定義函式時，所有參數以及回傳值都必須明確標註型別。函式使用 [`return` 關鍵字][return-keyword]回傳值。函式預設具有外部的[儲存類別][storage_class]，代表它會在程式執行期間一直存在，而且可以從檔案外部看見。若要避免這種情況，可以加上 `static` 關鍵字來指定內部的可見性。

```c
static int add(int x, int y) {
  return x + y;
}
```

在上面的例子中，變數 `x` 和 `y` 只能在該函式內使用，也就是說，它們具有函式作用域。[作用域][scope]指的是，與某個名稱（程式元素的名稱）相關聯的值，只能在定義它的程式「區域」內存取。C 中主要的程式區域有：

- 檔案
- 函式
- 區塊（例如迴圈及其他結構之內）

呼叫函式時，要指定函式名稱，並為每個函式參數傳入對應的引數。

```c
int sum = add(1, 2);
```

C 支援兩種[註解][comments]。單行註解以 `//` 開頭（自 C99 起），多行註解則插入在 `/*` 與 `*/` 之間。
