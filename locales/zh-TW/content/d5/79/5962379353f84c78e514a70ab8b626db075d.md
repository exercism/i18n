# 簡介

## 正規表達式

**正規表達式**（regex）是一連串的字元，用來描述文字中的搜尋模式。

學習正規表達式的語法已超出本主題的範圍。
我們會把重點放在`jq`提供的篩選器，看看如何運用正規表達式。

### 正規表達式的實作版本

不同的工具會實作不同版本的正規表達式。
`jq`內建 [Oniguruma][oniguruma] 正規表達式函式庫，它大致上與 Perl v5.8 的正規表達式相容。

`jq`所使用的具體語法可以在 [Oniguruma 的 GitHub 存放庫][onig-syntax] 找到。

<!-- prettier-ignore -->
~~~~exercism/caution
`jq`沒有針對正規表達式的特殊語法。
它們就是單純以字串表示。
這代表正規表達式中的任何反斜線，都必須在字串中跳脫。

例如，數字字元類別（`\d`）必須寫成 `"\\d"`。
~~~~

<!-- prettier-ignore-end -->

### 正規表達式函式

`jq`中的正規表達式僅限於[一組篩選器][jq-regex-funcs]。

#### 簡單比對

當你需要知道某個字串是否符合某個模式時，請使用`test`篩選器。

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

這個篩選器會輸出_布林值_的結果。

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

#### 相符結果的相關資訊

當你需要擷取真正符合模式的子字串時，請使用`match`篩選器。

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

這個篩選器會輸出：

- 如果沒有相符結果，則不輸出任何東西，或者
- 如果有相符結果，則輸出一個包含各種屬性的物件。

這個範例使用反向參照語法`\1`，尋找兩個相同且連續的母音。

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match`篩選器會為_每個_相符結果回傳一個物件。
這個範例展示了`"g"`旗標的實際運作，用來找出所有的母音。

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

#### 擷取的子字串

與`match`篩選器類似，`capture`篩選器在找到相符結果時會回傳一個物件。

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

回傳的物件是**具名擷取**的對應。

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

#### 只取子字串

`scan`篩選器類似於帶有`"g"`旗標的`match`。

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan`會輸出子字串的_串流_。

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

使用`[...]`陣列建構子來收集這些子字串。

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

#### 切割字串

如果你知道字串中想要**保留**的部分，請使用`match`或`scan`。
如果你知道想要**捨棄**的部分，請使用`split`。

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
**只接收一個引數**的`split`篩選器會把引數視為**固定字串**。

如果要讓`split`使用正規表達式，你**必須**提供第二個引數；使用空字串也沒關係。
~~~~

<!-- prettier-ignore-end -->

以下範例會依任意空白切割字串。

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

#### 取代

`sub`與`gsub`篩選器可以轉換輸入字串，將輸入中相符的部分取代為取代字串。

如果只想取代第一個相符結果，請使用`sub`。
如果要取代所有相符結果，請使用`gsub`。

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

取代的文字可以參照相符的子字串；請使用具名擷取與[字串插值][jq-interp]。

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

### 旗標

在上述所有篩選器中，FLAGS 是一個由零個或多個支援旗標組成的字串。

- `g`：全域搜尋（找出所有相符結果，不只第一個）
- `i`：忽略大小寫的搜尋
- `m`：多行模式（'.' 會符合換行）
- `n`：忽略空相符
- `p`：同時啟用 s 與 m 模式
- `s`：單行模式（'^' -> '\A', '$' -> '\Z'）
- `l`：找出可能的最長相符結果
- `x`：擴充的正規表達式格式（忽略空白與註解）

例如

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
