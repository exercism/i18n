# 簡介

位元運算讓我們可以操作二進位數字中個別的位元。

Elm 在它的 [Bitwise 模組](https://package.elm-lang.org/packages/elm/core/latest/Bitwise) 中提供了幾個位元運算子。

## 基本運算

修改數字中個別的位元稱為_遮罩_。
_遮罩_是一個數字，其中特定的位元以特定方式設定，用來透過位元運算子（例如`and`、`or`和`xor`）操作另一個數字。

### and

`and`會只保留兩個數字中同為`1`的位元，藉此合併這兩個數字。
這在檢查某個位元是否被設定時很有用。
例如，要檢查某個數字的第 4 個位元是否設為`1`，就將它與遮罩`01000`（十進位的`8`）做`and`運算，再看看結果是否不為零：

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or`會將兩個數字合併，只要某個位元在其中任一個或兩個數字中為`1`，就把它設為`1`。
這在把特定位元設為`1`時很有用。
例如，要設定`10101`中的第 2 個位元，就將它與遮罩`00010`做`or`運算：

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### 互斥或（xor）

`xor`會將兩個數字合併，當某個位元在其中一個數字為`1`、在另一個數字為`0`時，就把它設為`1`。
這在把位元翻轉成相反值時很有用：

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### 補數

`complement`會將數字中的每個位元反相（`0`變成`1`，`1`變成`0`）。

請注意，這會使正數變成負數，負數變成正數。
這是因為二進位中的負數是以最左邊的位置為`1`來表示。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### 位元位移

以下運算子會將位元向左或向右移動指定的位置數量，效果等同於乘以或除以 2 的次方。

`shiftLeftBy`會將位元向左移動，並從右側補入`0`。
例如，要將`21`向左移 3 位：

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

這等同於`21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`：將位元向右移動：

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

向右移 2 位等同於對 4 做整數除法。

請注意，這個函式會複製最左邊位元的值。
所以，負數會維持負數：

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

如果你想向右移位並補入零，請使用`shiftRightZfBy`：

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
