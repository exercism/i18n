# 在命令列上測試

使用以下指令執行測試：

```bash
scarb cairo-test
```

除了第一個測試之外，其餘的測試都已被忽略。當第一個測試通過之後，打開位於`tests`目錄中的測試原始檔，移除下一個測試的`#[ignore]`旗標，再讓測試通過一次。每個獨立的測試都是上方帶有`#[test]`旗標的函式。就這樣持續下去，直到所有測試都通過為止。

如果你想在不編輯測試原始檔的情況下執行*所有*測試，請使用：

```bash
scarb cairo-test --include-ignored
```

如果你想執行某個特定測試，不論它是否被忽略，例如`some_test`，可以使用：

```bash
scarb cairo-test -f some_test
```

想進一步了解 Cairo 的測試，請參閱線上的[測試文件][cairo-tests]。

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
