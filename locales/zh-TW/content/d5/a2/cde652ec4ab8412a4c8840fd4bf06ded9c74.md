# 指示

把以某個進位制表示、由一串數字組成的數，轉換成任何其他進位制。

實作通用的進位制轉換。
給定一個以進位制**a**表示、由一串數字組成的數，將它轉換成進位制**b**。

## 注意

- 試著自己實作這個轉換吧。
  不要用其他現成的東西替你完成轉換。

## 關於[位值記數法][positional-notation]

在位值記數法中，進位制**b**的數可以理解為**b**的次方的線性組合。

數字 42，*以十進位表示*，意思是：

`(4 * 10^1) + (2 * 10^0)`

數字 101010，*以二進位表示*，意思是：

`(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)`

數字 1120，*以三進位表示*，意思是：

`(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)`

我想你懂了吧！

*沒錯。上面這三個數字完全是同一個數。恭喜！*
