# 指令

在這道練習中，你會為紐約一間在 2012 年 9 月 15 日開幕的美容沙龍製作一套預約排程系統。

你有四個任務，全都會牽涉到預約日期。日期和時間會採用下列三種格式的其中一種：

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
測試會自動將 culture 設定為`en-US`，你不需要自行設定或指定 culture。
~~~~

## 1. 解析預約日期

實作`schedule`函式，將預約日期的文字表示法解析成對應的`DateTime`格式：

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 檢查預約是否已經過去

實作`hasPassed`函式，它會接收預約日期，並檢查該預約是否發生在過去的某個時間點：

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 檢查預約是否在下午

實作`isAfternoonAppointment`函式，它會接收預約日期，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 描述預約的時間和日期

實作`description`函式，它會接收預約日期，並回傳該日期和時間的描述：

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 回傳週年紀念日

實作`anniversaryDate`函式，它會回傳今年的週年紀念日，也就是 9 月 15 日：

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
