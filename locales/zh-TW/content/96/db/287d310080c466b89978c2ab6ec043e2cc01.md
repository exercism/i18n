# 提示

## 一般

- [整數值][integers]可以定義為一個或多個連續的數字。
- [映射值][maps]會儲存鍵值資料。

## 1. 給定一個棋盤和一個直行，計算有多少個格子被佔據

- 你可以疊代一個[映射][maps]
- 檢查值是否為 true。
  如果是，就遞增。
  這是為了計算棋子數量。
- 你必須從函式[明確地回傳整數][return]。

## 2. 給定一個棋盤和一個橫列，計算有多少個格子被佔據

- 你首先需要檢查橫列是否在範圍內。
- 逐一走訪棋盤。
- 如果格子被佔據，就加一。

## 3. 計算給定的棋盤上有多少個格子

- 這有很多種解法喔。
- 這應該回傳棋盤上設定了多少個格子。

## 4. 計算給定的棋盤上有多少個格子被佔據

- 取得棋盤上所有直行的 CountInFile。
