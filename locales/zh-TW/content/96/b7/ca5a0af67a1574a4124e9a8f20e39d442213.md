# 測試

每道練習都會有一個測試檔案。
由於 Exercism 提倡[測試驅動開發][tdd]，測試*就是*需求本身。
記得閱讀測試，了解你的程式碼會如何被呼叫，以及預期會得到什麼輸出。

執行測試套件：

```bash
tclsh exercise.test
```

## 略過的測試

解完一道練習，代表要讓它所有的測試都通過。預設情況下，執行測試時只會跑一個測試（也就是第一個）。這是刻意的設計，讓你專注在讓那一個測試通過就好。一旦它通過了，只要把下一個測試前面的`skip`指令註解掉或移除，就能啟用那個測試。

或者，不管測試是不是處於「略過」狀態，想要全部執行：

```bash
RUN_ALL=1 tclsh exercise.test
```

[tdd]: https://exercism.org/docs/using/solving-exercises/tdd
