# 簡介

## 變數

Elixir 是動態型別的語言，意思是變數的型別只會在執行期檢查。我們可以用匹配運算子`=`，把任何型別的值綁定到變數名稱上：

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## 模組

Elixir 是一種[函式程式設計語言][functional-programming]，所有具名函式都必須定義在_模組_裡。我們用`defmodule`關鍵字來定義模組。所有模組在執行期都能被其他模組取用，不需要_存取修飾子_就能讓程式的其他部分看見。_模組_相當於其他程式語言裡的_類別_。

```elixir
defmodule Calculator do
  # ...
end
```

## 具名函式

_具名函式_必須定義在模組裡。我們用`def`關鍵字來定義_公開_的具名函式。

每個函式可以有 0 個或多個引數。函式中最後一個運算式的值，一律會被_隱式回傳_。

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

呼叫函式時，要指明模組與函式名稱，並為函式的每個引數傳入對應的值。

```elixir
sum = Calculator.add(1, 2)
# => 3
```

我們也可以用`defp`關鍵字取代`def`，來定義_私有_函式。私有函式只能在定義它的同一個模組內使用。

如果在定義函式的同一個模組內呼叫它，可以省略模組名稱。

你也可以用單行語法來寫簡短的函式（注意`do`關鍵字前後的逗號`,`和冒號`:`）。

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## 函式的引數個數

我們經常會用_引數個數_來稱呼函式。函式的_引數個數_，就是它接受的引數數量。

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## 命名慣例

模組名稱應使用`PascalCase`。模組名稱必須以大寫字母`A-Z`開頭，可以包含字母`a-zA-Z`、數字`0-9`和底線`_`。

變數與函式名稱應使用`snake_case`。變數或函式名稱必須以小寫字母`a-z`或底線`_`開頭，可以包含字母`a-zA-Z`、數字`0-9`和底線`_`，而且可能以問號`?`或驚嘆號`!`結尾。

## 標準函式庫

Elixir 有非常豐富、文件齊全的標準函式庫。文件可以在線上查閱：[hexdocs.pm/elixir][docs]。把這個連結存起來，你之後會很常用到！

大多數內建的資料型態都有對應的模組，提供操作該資料型態的函式。例如整數有`Integer`模組，字串有`String`模組，陣列有`List`模組，以此類推。

值得一提的模組是`Kernel`模組。它提供了標準函式庫其餘部分所賴以建立的基礎能力，例如算術運算子、控制流程巨集，還有更多。`Kernel`模組的函式會自動匯入，所以使用時不必加上`Kernel.`前綴。
