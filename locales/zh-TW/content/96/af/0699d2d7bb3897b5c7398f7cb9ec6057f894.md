# 關於

當你要為只可能有一組特定狀態的資料建立模型時，例如一星期中的每一天、指南針的方向，或控制器上的按鈕，像`Int`或`String`這類基本型別有很大的缺點。
使用整數或字串時，你的程式碼必須不斷檢查無效的值（例如`999`這種狀態碼，或`"leftt"`這種拼字錯誤），而人類讀者也無法輕易看出這些數字代表什麼。

Swift 用[_列舉_][enumerations]（常簡稱為 *enum*）來解決這個問題。
列舉為一群相關的具名值定義了一個共同的型別。因為編譯器事先就知道所有可能的 `case`，所以能在編譯時期檢查你的程式碼是否正確且完整。
列舉也可以擁有方法、初始化器和計算屬性。

## 定義列舉

使用`enum`關鍵字來定義列舉，後面接型別名稱，並在大括號內列出各個 `case`。
依照 Swift 的慣例，型別名稱使用`UpperCamelCase`，而每個 `case` 使用`lowerCamelCase`：

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

你也可以把多個 `case` 定義在同一行，用逗號分隔：

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

要取用某個列舉 `case` 時，寫出列舉的型別名稱、一個點（`.`），再加上 `case` 名稱。一旦型別已知，或編譯器可以推斷出來，就可以省略型別名稱，改用更簡短的點語法：

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## 列舉與`switch`敘述

列舉可以和 [`switch` 敘述][enums-and-switches]完美搭配。
因為 Swift 的`switch`必須窮盡所有情況，編譯器會確保你處理了每一個可能的 `case`：

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

如果你漏掉任何一個 `case`，又沒有提供`default`子句，編譯器就會回報錯誤：

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

把所有的 `case` 明確列出來，通常比使用`default`更好。這樣一來，未來如果新增了一個 `case`，編譯器會立刻提醒你更新每一個處理該列舉的`switch`敘述。

## 方法與初始化器

列舉可以像類別和結構體一樣，定義方法和自訂初始化器。在列舉方法內，`self`代表目前的 `case` 值：

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## 原始值

列舉的 `case` 可以預先填入預設值，這些值稱為[_原始值_][raw-values]。
同一個列舉中所有的原始值都必須是相同的型別（例如`Int`、`String`或`Character`）：

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

你可以用`init(rawValue:)`從原始值初始化列舉。因為可能傳入無效的原始值，這個初始化器會回傳一個可選值：

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift 可以為`String`和`Int`列舉自動指定原始值：

- 對`String`列舉來說，每個 `case` 的原始值預設就是該 `case` 的名稱。
- 對`Int`列舉來說，原始值從`0`開始，每次遞增 1，除非另有指定。

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## 關聯值

列舉的 `case` 也可以各自附帶儲存不同型別的自訂值，這些值稱為[_關聯值_][associated-values]：

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

一個列舉可以使用原始值或關聯值，但不能同時使用兩者。

## 遞迴列舉

[遞迴列舉][recursive-enumerations]是指某個列舉的一個或多個 `case`，以該列舉的另一個實例作為關聯值。
要啟用遞迴，請用`indirect`關鍵字標記該 `case`（或整個列舉）：

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
