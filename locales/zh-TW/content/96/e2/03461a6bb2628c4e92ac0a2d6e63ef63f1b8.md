# 說明補充

## 關於 Stream 能力

`Stream`是一種 Unison 能力，用來發出值。

如果你的函式在被呼叫時，需要順帶產生一些值，就可以使用`Stream`能力喔。例如，下面這個函式會回傳陣列的最後一個值，但每看到一個元素就會發出目前的累計總和：

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

我們可以用能力處理器，把 Stream 具體化成陣列，連同產生它的函式回傳值一起取出：

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
