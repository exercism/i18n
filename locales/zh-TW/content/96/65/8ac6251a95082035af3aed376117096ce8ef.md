# 說明

在這個練習中，你會寫一些程式碼，幫助你為購買車輛做準備。

你有三個任務：判斷你是否需要駕照、幫你在兩輛車之間做選擇，以及估算中古車可接受的價格。

## 1. 判斷你是否需要駕駛執照

有些種類的車輛需要駕駛執照才能駕駛。
假設只有`"car"`和`"truck"`需要駕照，其他種類都可以無須駕照駕駛。

實作`NeedsLicense(kind)`函式，它接受車輛種類，並回傳一個布林值，指出該種類的車輛是否需要駕照。

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. 在兩輛可能購買的車輛之間做選擇

你評估了手邊可選的車輛。
你成功把選項縮小到兩輛，但需要有人幫你做最後決定。
為此，請實作`ChooseVehicle(option1, option2)`函式，它接受兩輛車作為引數，並回傳一個決定，其中包含依字典序排在最前面的那個選項。

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 估算中古車的價格

既然你已經做出決定，你會想確保自己在經銷商那裡拿到合理的價格。
由於你有意購買中古車，價格取決於車齡。
粗略估算的話，假設車輛車齡未滿 3 年，價格是全新時原價的 80%。
如果車齡至少 10 年，價格是 50%。
如果車齡至少 3 年但未滿 10 年，價格是原價的 70%。

實作`CalculateResellPrice(originalPrice, age)`函式，使用`if`、`else if`和`else`來套用這套邏輯（如果你想多練習，也有其他寫法）。
它接受原價和車齡作為引數，並回傳在經銷商的預估價格。

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**注意**回傳值是`float64`。
