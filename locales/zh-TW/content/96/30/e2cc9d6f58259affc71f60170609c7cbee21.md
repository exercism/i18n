# 說明

身為西洋棋愛好者，你應該會想寫一套自己的西洋棋。沒錯，線上或許已經有很多現成的實作，但你的版本會獨一無二！

不過在盡情發揮想像力之前，得先處理基本的部分。我們先從產生棋盤開始吧。

棋盤上的每個方格都由一組字母與數字標示。垂直的方格行稱為直行（英文：_files_），標示為 A 到 H；水平的方格列稱為橫列（英文：_ranks_），編號為 1 到 8。

## 1. 定義橫列的範圍

實作`rank_range/0`函式。它應該回傳從 1 到 8 的整數範圍。

```elixir
Chessboard.rank_range()
```

## 2. 定義直行的範圍

實作`file_range/0`函式。它應該回傳從大寫字母 A 的碼位到大寫字母 H 的碼位的整數範圍。

```elixir
Chessboard.file_range()
```

## 3. 將橫列的範圍轉換成橫列的陣列

實作`ranks/0`函式。它應該回傳從 1 到 8 的整數陣列。不要手動寫出這個陣列，請用`rank_range/0`函式回傳的範圍來產生。

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. 將直行的範圍轉換成直行的陣列

實作`files/0`函式。它應該回傳從 "A" 到 "H" 的字母（字串）陣列。不要手動寫出這個陣列，請用`file_range/0`函式回傳的範圍來產生。

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
