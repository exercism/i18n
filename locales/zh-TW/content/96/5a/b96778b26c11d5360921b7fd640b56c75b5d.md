# 說明

水手長每天都會在甲板上舉行值更簡報：固定的問候、值班船員的點名，最後以解散作結。你要把這份簡報拆成幾個具名的小片段，再將它們組合起來。

這次練習你會編輯**兩個檔案**：

- `bosuns-briefing/helpers/helpers.factor`，可重複使用的小片段。Vocabulary：`bosuns-briefing.helpers`。
- `bosuns-briefing/bosuns-briefing.factor`，負責組合這些小片段的主要檔案。Vocabulary：`bosuns-briefing`。

## 1. 問候

在 `helpers.factor` 中，定義 `greeting`，讓它回傳固定的開場字串 `"All hands, attention!"`。

```factor
greeting .
! => "All hands, attention!"
```

## 2. 船員列

在 `helpers.factor` 中，定義 `crew-line`，讓它接受一個名字字串，並回傳在該名字前面加上 `"  - "` 的字串（兩個空格、一個連字號、一個空格）。

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. 收尾

在 `helpers.factor` 中，定義 `closing`，讓它回傳固定的解散字串 `"Carry on."`。

```factor
closing .
! => "Carry on."
```

## 4. 名冊

在 `bosuns-briefing.factor` 中，定義 `roster`，讓它接受一個船員名字的陣列，並回傳單一的多行字串，其中每個名字都交由 `crew-line` 格式化，再以換行串接起來。

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. 簡報

在 `bosuns-briefing.factor` 中，定義 `briefing`，讓它接受一個船員名字的陣列，並以單一字串回傳完整的簡報：第一行是問候，接下來幾行是名冊，最後一行是收尾。請使用這些小片段和 `roster`。

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
