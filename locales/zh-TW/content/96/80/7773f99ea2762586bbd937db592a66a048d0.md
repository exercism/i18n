# 簡介

## 常數與函式

Haskell 程式由定義與運算式組成。

常數值以`name = expression`定義。

```haskell
five = 5

six = 3 + 3
```

函式以`name parameters... = expression`定義，其中的參數僅以空格分隔。

```haskell
add number1 number2 = number1 + number2
```

呼叫函式本身也是一種運算式，做法是指定函式的名稱，並為函式的每個參數傳入引數，以空格分隔，就和定義函式一樣。

```haskell
five = add 2 3
```

括號可以用來指定運算式的求值順序。

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 縮排／有意義的空白

Haskell 使用空白與縮排來界定程式碼的範圍。
***屬於某個運算式的程式碼，其縮排必須比該運算式的起始位置更往內。***

- 模組、import 與最上層的函式定義必須從最左欄開始。
- 如果一個運算式被拆成多行，屬於該運算式的程式碼必須縮排在該運算式之下，並至少留一個空格。
- 運算式中歸為同一組的部分，應該以相同數量的空格縮排。

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## 模組

模組會匯出函式。
這表示你可以使用模組在匯出敘述中提供的函式。
模組也可以定義僅供內部使用的函式。
預設情況下，沒有明確匯出的函式無法從模組外部使用。

在模組開頭，我們會指定模組名稱。
如果有一個名為 Calculator.hs 的檔案，就應該把模組命名為 Calculator。
接著，我們指定它要匯出的函式，然後就可以開始撰寫函式了。
所以我們會從這個開始。

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## 註解

註解是 Haskell 檔案中不會被解讀為程式碼的一段文字。
它主要是給你和其他程式設計師閱讀的。
單行註解有一種輕量的語法，是以雙破折號為基礎。
多行註解則可以用 `{-` 與 `-}` 這對開頭與結尾的定界符來撰寫。

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
