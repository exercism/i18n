# 說明

在這道練習中，你會寫一些程式碼，幫助你依照最愛的食譜烤出美味的千層麵。

你有四項任務，全都和烤千層麵所花費的時間有關。

## 1. 定義預期的烘烤時間（分鐘）

定義`expected-time`變數，用來確認千層麵應該在烤箱裡烤幾分鐘。根據這本食譜，預期的烘烤時間是 40 分鐘：

```clojure
expected-time
;;=> 40
```

## 2. 計算剩餘的烘烤時間（分鐘）

定義`remaining-time`函式，它接受千層麵已經在烤箱中烘烤的實際分鐘數作為引數，並根據上一項任務算出的預期烘烤時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```clojure
(remaining-time 30)
;;=> 10
```

## 3. 計算準備時間（分鐘）

定義`prep-time`函式，它接受你加到千層麵裡的層數作為引數，並回傳你準備千層麵花了幾分鐘，假設每一層要花 2 分鐘準備。

```clojure
(prep-time 2)
;;=> 4
```

## 4. 計算總工作時間（分鐘）

定義`total-time`函式，它接受兩個引數：第一個引數是你加到千層麵裡的層數，第二個引數是千層麵已經在烤箱中烘烤的分鐘數。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間加上千層麵目前在烤箱中烘烤的時間。

```clojure
(total-time 3 20)
;;=> 26
```
