# 簡介

`Result` 型別是 Elm 語言中處理錯誤回報的解決方案，也是讓人能從錯誤中復原的推手。它和 `Maybe` 型別有點相似，不過 Maybe 雖然可以由可能失敗的函式回傳，卻不會告訴你失敗的原因。Result 則包含了關於失敗原因的這層脈絡。

`Result` 型別的定義如下：

```elm
type Result error value
  = Ok value
  | Err error
```

這在 Elm 的術語中稱為「自訂型別」定義。
`OK value` 和 `Error error` 裡的 `error` 和 `value` 代表一個型別變數，意思是它可以是任何型別，例如 `Int`、`Bool` 或 `String`。
因此，`Result String Int` 是一個預期包含 `Int` 的變數，而如果發生錯誤，錯誤會以 `String` 表示。
有一個 [Result 模組](https://package.elm-lang.org/packages/elm/core/latest/Result)，裡面有許多處理 result 的實用輔助函式。
