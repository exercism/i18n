# 簡介

字面值是直接寫在程式碼中的固定值。
它們不需要在執行階段進行任何運算。
它們有各種形式，能有效率地表示不同型別的資料。
最常見的字面值屬於數值性質，但也有用於日期、時間和字串型別的字面值運算子。
之後的概念會說明如何使用使用者自訂的字面值運算子。

## 數值字面值

數值字面值包含十進位、八進位、十六進位和二進位表示法。
這些基礎知識已在[數字概念][numbers-concept]中介紹過。

像是`23`、`0x50f7ba11`和`0xba5eba11`這類表示法，編譯器都會理解為`int`。
一般的`int`型別是有號的，而且（[視編譯器和系統而定][in-depth-integers]）範圍通常是`-2'147'483'648`到`2'147'483'647`。
大多數情況下這樣就很夠用，你不需要擔心特定的型別。

有些使用情境需要更大的範圍，或是程式極小的記憶體佔用量。
為了明確表達，可以直接用數值字面值指定特定的整數型別。

當不需要負數、但想要更大的範圍時，會使用`u`或`U`後綴來表示_無號_整數。
若需要更大的範圍，可以使用`L`甚至`LL`來表示 long 和 long long 型別。

~~~~exercism/caution
允許使用小寫的`l`，但它很容易和數字`1`搞混，因此不建議這麼做。
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

浮點數在編譯時通常會推導為`double`。
這是個很好的預設情況，而需要使用更窄的`float`型別的情境，比上面無號整數的例子少見。

~~~~exercism/advanced
[C++23 標準][cpp23-literals]為`f128`或`F16`這類字面值帶來了更細緻的控制。
有些編譯器允許使用自家的字面值。
GCC 允許把`d`當作字面值使用，但標準並未預見這種用法，而且可能會妨礙跨平台相容性。

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## 字元與字串字面值

其他概念已經用過單引號的字元字面值，例如`'}'`或`'@'`。

在 C++ 中，`char`僅限於前 128 個 [ASCII 字元編碼][ascii-code]。
若要使用多個 ASCII 字元、像`‰`這種擴充 ASCII 字元，甚至像`麗`和`ẞ`這樣的 Unicode 字元，就需要其他型別。
先前的概念用_雙引號_介紹了字串字面值：`"一体どういう意味ですか。C++です"`。
這個日文句子的實際型別是`const char (&)[46]`，也就是 C 風格字串。

字串字面值預設並不會啟用。
若要使用 _string_ 字面值`""s`或 _string-view_ 字面值`""sv`，使用者必須透過相關的命名空間來指明：

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_string_view_ 可以看成是對 const 字串的參考。

[ascii-code]: https://www.ascii-code.com/
