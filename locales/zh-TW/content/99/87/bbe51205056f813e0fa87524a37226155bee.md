# 安裝 Kotlin

除了 Exercism CLI 和你慣用的文字編輯器之外，還需要以下工具，才能在 Exercism 上用 Kotlin 練習：

* **Java 開發套件**（JDK）：Kotlin 會編譯成 Java 位元組碼，所以你需要安裝 JDK，它同時包含 Java 執行環境*和*開發工具（其中最重要的是 Java 編譯器）；以及
* **Gradle**：一套專為 JVM 專案設計的建置工具，並且支援 Kotlin。

選擇你的作業系統：

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

……或者……

* 如果你不想使用套件管理員，也可以[手動安裝](#h-install-manually)。

另外，你也可以使用 [Java IDE](#h-java-ides)。

----

## Windows

請以系統管理員身分開啟命令提示字元。（如果你需要協助開啟系統管理員提示字元，請參考[在 Windows 8+ 開啟提升權限的提示字元](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/)（或 [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)）。

1. 如果你還沒安裝 Chocolatey，現在就安裝：

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  安裝 JDK：

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

建議你關閉系統管理員命令提示字元，另外開啟一個新的命令提示字元。做 Exercism 的練習並不需要系統管理員權限。

現在，你可以開始踏上 Exercism 的 Kotlin 賽道了！

要開始的話，請參考「[執行測試](https://exercism.org/docs/tracks/kotlin/tests)」。

## macOS

以下是使用最常見方式，也就是 Homebrew，來安裝的說明。如果你不想這樣做，也可以[在 macOS 上不使用 Homebrew 安裝](#h-installing-on-macos-without-homebrew)。

### 安裝

1. 如果你還沒安裝 [Homebrew](http://brew.sh)，現在就安裝：

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. 加入 [Homebrew Cask](https://caskroom.github.io/)，這樣就能安裝 JDK 這類預先建置好的二進位檔。

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  安裝 JDK：

       ```
        $ brew install --cask adoptopenjdk11
       ```

現在，你可以開始踏上 Exercism 的 Kotlin 賽道了！

要開始的話，請參考「[執行測試](https://exercism.org/docs/tracks/kotlin/tests)」。

## Linux

以下是使用你所用發行版的套件管理員來安裝的說明。如果你不想這樣做，也可以[在 Linux 上不使用套件管理員安裝](#h-installing-on-linux-without-a-package-manager)。

* [Debian](#h-debian)
* [其他 Linux 發行版](#h-other-linux-distributions)

### Debian

如果你使用的是 Debian 或其衍生發行版（例如 Ubuntu 或 Linux Mint），請使用 APT：

*（已驗證於：Ubuntu 14、16 和 18）*

1. 安裝 JDK：

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


現在，你可以開始踏上 Exercism 的 Kotlin 賽道了！

要開始的話，請參考「[執行測試](https://exercism.org/docs/tracks/kotlin/tests)」。

----

### 其他 Linux 發行版

安裝 JDK 11 的方法有很多，其中最簡單的方式之一是使用 SDKMAN，
它可以讓你輕鬆安裝 OpenJDK 11。請依照下列步驟：

1. 安裝 SDKMAN：
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    （如果這樣做沒用，請參考這裡的說明：https://sdkman.io/install ）
1. 安裝 OpenJDK 11：
    ```
    $ sdk install java 11.0.2-open
    ``` 

現在，你可以開始踏上 Exercism 的 Kotlin 賽道了！

要開始的話，請參考「[執行測試](https://exercism.org/docs/tracks/kotlin/tests)」。

### 在 Windows 上手動安裝

*注意：這些說明是為熟悉 Windows 的使用者準備的。如果你還不知道怎麼設定環境變數，或是不太有把握管理目錄結構，我們強烈建議你使用上面[以 Chocolatey 為基礎的安裝方式](#h-windows)。*

1. 安裝 JDK：
   1. 從 [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) 下載「**OpenJDK 11 (LTS)**」（選擇「**Install JDK**」）。
   -  執行安裝程式，全部使用預設值。

現在，你可以開始踏上 Exercism 的 Kotlin 賽道了！

要開始的話，請參考「[執行測試](https://exercism.org/docs/tracks/kotlin/tests)」。

## Java IDE

市面上有許多 Java IDE，其中最受歡迎的三種是：

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/)（下載「Community」版本）
  - 這個 IDE 由 Kotlin 的開發團隊打造，對這個語言的支援最好。
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/)（下載「Java SE」組合包）

另外還有[其他選擇](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs)。
