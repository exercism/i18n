# 關於

JavaScript 是一種程式語言，能讓網頁具備動態效果。它是一種直譯式語言，也就是說，它不需要經過編譯：翻譯員（例如網頁瀏覽器）會剖析程式碼，並將它轉換成使用者電腦可以執行的程式碼，非常適合用來打造能在_任何電腦_上的任何瀏覽器運行的動態網站！

JavaScript 不只用於瀏覽器。像 [Node.js][web-nodejs] 和 [Deno][web-deno] 這類 JavaScript 執行環境，讓你能在網頁伺服器上撰寫、啟動並處理請求。
其他框架，例如 [Electron][web-electron]，則使用 JavaScript 為 Windows、Linux 和 macOS 撰寫_跨平台應用程式_。
行動應用程式開發也是可行的，可以運用 [React Native][web-react-native]、[Ionic][web-ionic] 及各種其他工具，而 [Expo][web-expo] 現在更讓你一次就能同時鎖定 Android、iOS 與網頁。

ECMAScript 是定義 JavaScript 的[標準][web-ecma]。

> 「ECMAScript 已成為全球最廣泛使用的通用程式語言之一。
> 它最為人所知的身分是內嵌於網頁瀏覽器中的語言，但同時也被廣泛應用於伺服器與嵌入式應用。」
> 出自：[ECMA International Language Specification][web-ecma-2019]

從 2015 年的第 6 版（一般稱為 ES2015 或 ES6）開始，標準每年都會發布新版本。
第 6 版是一次重大更新，相較於 ES5 帶來許多強化，其中包括樣板字串、更具表達力的箭頭函式語法，以及定義類別時更簡潔的語法。

但由於新的語法和功能_每年_都會加入 JavaScript，[目前的瀏覽器][web-compat-browsers] 和 [最新的 Node.js][web-compat-node] 往往無法完整支援這些變更。
這並不表示我們不能用。
像 [Babel][web-babel] 這類工具為大多數功能提供了[轉譯][wiki-transpilation]，讓我們可以像身處未來一樣地_撰寫_程式。

**注意**：本學習軌道透過 Babel 與 [@babel/preset-env][web-babel-preset-env] 外掛支援最新的 ECMAScript 語法；每當該外掛更新時，就會啟用新的實驗性功能，並與規格的發布保持同步。它會自動配合_你本機的 Node.js_ 安裝環境。這表示你不必擔心哪些功能受到支援、哪些沒有。
