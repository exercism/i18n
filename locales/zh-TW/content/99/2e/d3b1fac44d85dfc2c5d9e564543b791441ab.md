# 說明附錄

## 暫存器

| 暫存器 | 用途        | 型別    | 說明                         |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | 輸入         | 整數    | N，三角形三邊長的和          |
| `$a1`    | 輸入/輸出    | 位址    | a 的值                       |
| `$a2`    | 輸入/輸出    | 位址    | b 的值                       |
| `$a3`    | 輸入/輸出    | 位址    | c 的值                       |
| `$v0`    | 輸出         | 整數    | 三元組的數量                 |
| `$t0-9`  | 暫時         | 任意    | 供暫時儲存使用               |
