# 使用字串插值

[comment]: # (當解法沒有使用字串插值時，就會顯示這個警告)

使用[字串插值](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20)把`name`參數插入輸出字串中。

- 在 Exercism 的 Elixir track 中，為了兼顧可讀性，建議盡可能使用字串插值，而不是字串串接。

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [任何 Elixir 運算式](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30)都可以寫進字串插值的語法裡

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
