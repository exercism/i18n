# 說明

注意：這項練習是`need-for-speed`練習的延續。

在這項練習中，你將要組織各種遙控車之間的比賽。
每輛車都有自己的速度和電池耗電特性。

車輛一開始的電池是滿的（100%）。
每次你使用遙控器駕駛車輛時，車輛會前進相當於其速度的公尺數，並依其電池耗電量減少剩餘的電池百分比。

如果車輛的電池低於其電池耗電百分比，就無法再駕駛該車輛。

這台遙控車有一個花俏的 LED 顯示器，會顯示兩項資訊：

- 已行駛的總距離，顯示為：`"Driven <METERS> meters"`。
- 剩餘的電池電量，顯示為：`"Battery at <PERCENTAGE>%"`。

每條賽道都有自己的距離。
車輛的測試方式是檢查它們是否能在不耗盡電池的情況下完成賽道。

## 1. 駕駛車輛

在`Car`上實作`Drive`方法，根據車輛的速度更新已行駛的公尺數，並依照電池耗電量減少電池電量：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

注意：如果駕駛車輛會導致電池電量低於 0，就不應該嘗試駕駛。

## 2. 顯示已行駛的距離

在`Car`上實作`DisplayDistance`方法，以`string`形式回傳 LED 顯示器上顯示的距離：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. 顯示電池百分比

在`Car`上實作`DisplayBattery`方法，以`string`形式回傳 LED 顯示器上顯示的電池百分比：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. 檢查遙控車是否能完成比賽

為了完成比賽，車輛必須能夠行駛賽道的距離。
這表示在越過終點線之前不能耗盡電池。
實作`CanFinish`方法，該方法接受`trackDistance int`作為參數，如果車輛能完成比賽則回傳`true`；否則回傳`false`：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
