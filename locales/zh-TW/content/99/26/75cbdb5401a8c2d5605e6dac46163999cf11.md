# 在本機解練習

在自己的電腦上解練習，讓你可以用熟悉的環境寫程式。

## 安裝 CLI

若要在自己的電腦上解練習，你需要先依照[這份說明](https://exercism.org/cli-walkthrough)安裝並設定 Exercism 命令列介面。

### 設定

你需要讓 CLI 知道你是誰，我們才能正確下載內容。
你可以在[設定頁面](/settings/api_cli)找到你的權杖。
接著你可以用下列指令設定 CLI，並將`<your-api-token>`替換成設定頁面上的值：

```
exercism configure --token=<your-api-token>
```

## 下載練習

安裝完成後，你可以用下列指令透過 CLI 把練習下載到自己的電腦（請將`<exercise-slug>`和`<track-slug>`替換成對應的值）：

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

你不必記住這個指令的結構，因為練習頁面上會列出該練習對應的指令。

下載指令執行完畢後，練習的檔案就會下載到你的電腦。

## 解練習

每個練習的目標，都是寫出能通過所有測試的實作。
這樣的實作稱為_解答_。

為了幫助你，每個練習都包含下列檔案：

- README.md：說明對你的期待是什麼
- HELP.md：如何執行測試，以及卡住時如何求助的資訊
- HINTS.md（選用）：幫助你解練習的提示
- 測試檔案：包含用來驗證你的解答是否正確的測試
- 起始檔案：提供一個起點，幫助你開始建構實作

依照 track 的不同，可能還有其他檔案是該 track 的工具在執行測試時所需的。

## 提交你的解答

當你的解答通過所有測試後，就可以用下列指令提交解答：

```
exercism submit <implementation_file_paths>
```

這個指令會把你的解答上傳到 Exercism 網站，並印出解答頁面的網址。

同樣地，你不必記住這個指令，練習的`HELP.md`檔案裡會列出正確的指令。

你也可以提交尚未完成的解答，這樣你就能：

- 看看其他人怎麼完成這個練習
- 向導師尋求協助

## 其他 CLI 功能

### 查看所有指令

執行 help 子指令，就能取得所有可用指令的完整清單。

```bash
exercism help
```

### 疑難排解

確認你使用的是最新版本。

查看你目前的版本：

```bash
exercism version
```

對照最新發行版本確認一下，如果你的版本不是最新的，就進行升級。

升級後，再確認一次版本。如果版本沒有改變，請確認你執行的是升級後的執行檔。

```bash
which exercism
```

如果還是遇到問題，請在 GitHub 的 exercism/cli 開啟 issue，並附上 troubleshoot 指令的輸出。

```bash
exercism troubleshoot
```

你可以在[我們的 issue 追蹤器](https://github.com/exercism/exercism/issues)開啟 issue，社群會盡量協助你。**在開啟任何 issue 之前，請先確認你已經完成[互動導覽](https://exercism.org/cli-walkthrough)。**
