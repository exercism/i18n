# 說明

你的朋友 Linus 是位火車頭駕駛員，開著貨運列車往返於城市之間。
雖然他們很擅長處理列車的事，卻不太擅長處理物流或電腦。
他們想請你運用程式設計的專長，幫忙整理列車的細節，並修正路線資料中的錯誤。

~~~~exercism/note
這道練習用切片、索引和各種 `dict` 方法就能輕鬆解決。
不過，我們希望你在解決以下每個任務的過程中，練習打包、解包和多重指派。
~~~~

## 1. 建立所有車廂的陣列

你的朋友一直在記錄每個車廂的識別碼（ID），但他們永遠不確定系統在任何時刻需要處理多少個車廂。如果把這些資料打包成單一的 `list`，對物流程式的其餘部分來說會方便得多。

實作一個 `get_list_of_wagons()` 函式，接受任意數量的車廂 ID。
每個 ID 都會是正整數。
這個函式接著應該把傳入的 ID 以單一 `list` 的形式 `return`。

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. 修正車廂陣列

到了這裡，你已經開始對這些資料，以及它在物流程式中的用法有些感覺了。
ID 系統一律把火車頭的 ID 指派為 **1**，列車中其餘的車廂則隨機指派一個大於 **1** 的 ID。

你的朋友剛把兩節新車廂連上列車，卻忘了更新系統！
現在，列車 `list` 中的前兩個車廂必須移到最後，否則一切順序都會亂掉。

更麻煩的是，你的朋友剛剛又發現了第二個 `list`，裡面似乎包含了遺漏的車廂 ID。
他們只記得，新的車廂移好之後，第二個 `list` 裡的 ID 應該直接接在指定的火車頭後面。

Linus 會非常感謝你幫他們修正錯誤並整合資料。

實作一個 `fix_list_of_wagons()` 函式，接受兩個包含車廂 ID 的 `lists`。
它應該把第一個 `list` 的前兩個項目移到最後，並把第二個 `list` 中的值插入火車頭 ID（**1**）後方（也就是它的右側）。
這個函式接著應該 `return` 一個經過修改的 `list`。

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 新增缺少的停靠站

現在所有車廂資料都正確了，Linus 希望你更新系統的路線資訊。
沿著運輸路線，列車可能會在幾個不同的車站停靠，以裝卸貨物。
每趟旅程的中途交貨點數量都可能不同。
你的朋友希望你用任何缺少或額外的交貨資訊，更新系統的路線 `dict`。

實作一個 `add_missing_stops()` 函式，接受一個路線 `dict`，後面接著數量不固定的關鍵字引數。
這些引數的形式可以是包含一個或多個停靠站的 `dict`，也可以是任意數量的 `stop_number=city` 關鍵字配對。
你的函式接著應該回傳更新後的路線 `dict`，其中多了一個 `key`，存放依序加入的所有停靠站 `list`。

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. 擴充路線資訊

Linus 一直在開發路線程式，並注意到某些路線缺少了一些重要細節。
最初的路線資訊是以 `dict` 建構的，你的朋友希望你用任何可能缺少的內容更新那個 `dict`。
系統中的每條路線都需要稍微不同的細節，所以 Linus 真的很希望有個通用的解決方案。

實作一個名為 `extend_route_information()` 的函式，接受兩個 `dicts`。
第一個 `dict` 包含列車路線往返的起點與終點城市。

第二個 `dict` 包含其他路線細節，例如列車速度、長度或溫度。
這個函式應該回傳一個整合了所有路線資訊的 `dict`。

~~~~exercism/note
第二個 `dict` 可以包含與範例所示不同或更多的屬性。
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. 整理車廂停放場

Linus 在勘查車廂停放場時，注意到車廂沒有按照正確的順序存放。
除了 ID 之外，每個車廂還有對應其載運貨物種類的顏色。
車廂在停放場中以網格存放，網格裡的每一欄都是相同顏色的車廂。

然而，物流系統顯示要存放進停放場的車廂 `lists`，其_列_卻按顏色分組。
但要讓存放網格正常運作，每一_列_應該有三種不同的顏色，這樣_欄_才能按顏色對齊。
你的朋友希望你整理停放場的車廂 `lists`，讓車廂能正確存放。

實作一個名為 `fix_wagon_depot()` 的函式，接受一個包含三個項目的 `list`。
每個 `list` 項目都是一個子陣列（或「列」），內含三個 `tuples`。
每個 `tuple` 都是一組 `(<wagon ID>, <wagon color>)` 配對。

你的函式應該回傳一個 `list`，其中三個「列」`lists` 已重新排序，讓車廂交換到正確的位置。

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
