# 簡介

**閉包**是 [Clojure 裡的一種程式設計模式][clojure-guide-closures]，它允許外部[詞法作用域][wiki-lexical-scope]的變數在函式內部使用。Clojure 對閉包的支援是透明的，而且常常在不知道它們是什麼的情況下就用到它們。

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## 用閉包保存狀態並傳遞值

使用 atom 可以保留一些狀態：

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

每一次呼叫 `increment`，它的計數器就會增加一次：

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
