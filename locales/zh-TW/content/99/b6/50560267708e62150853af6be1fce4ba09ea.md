# 安裝

請從[官方發行頁面][official-releases]取得適合你平台的`full`執行檔。
目前這個 track 以 Arturo 0.10.0 的 Arizona Bark 版本為目標。

~~~~exercism/caution
Homebrew 是 macOS 與 Linux 平台上很受歡迎的第三方軟體安裝方式。
不過，它為 Arturo 提供的安裝方式指向`mini`版本，與這個 track 不相容。
~~~~

如果需要更多安裝 Arturo 的協助，請參考[官方 Arturo Discord][discord]。

## 執行 Arturo 程式碼

到這裡，你就可以開始寫 Arturo 程式碼了！
想進入 Arturo REPL，請在命令列執行`arturo`吧。
想執行 Arturo 腳本，請在命令列執行`arturo <file>`。

[official-releases]: https://arturo-lang.io/#download
[discord]: https://discord.gg/YdVK2CB
