# 關於

.NET 基底類別庫提供了 [`Regex`][regex]類別來處理正規表達式。

請參閱這篇[文章][regex-comparison]，了解 C# 與其他正規表達式變體的比較。

## 擷取群組

需要考量的其中一個面向是擷取群組，它會回傳文字中符合正規表達式樣式各部分的內容。擷取群組的用法需要花點時間熟悉。請參閱這份[文件][capture]。

請注意，這裡牽涉到一層階層結構，其中包含了擷取群組 `(?<capture-name>pattern)`：

- 會回傳一組零個或多個比對（文字中每找到一個比對就有一個）。
- 每個比對包含若干個擷取群組
- 每個群組包含若干個擷取

此外：

- `Match` 衍生自 `Group`
- `Group` 衍生自 `Capture`

注意事項：

- 最安全的做法是使用具名擷取。
- 擷取群組在 `Groups` 集合中出現的順序，通常與它們在文字中出現的順序相同。
- `Groups[0]`似乎對應到整個比對。
- `Groups[<capture name>].Value` 幾乎肯定就是你感興趣的部分。個別的擷取（`Caputures[0]` 除外）如果存在，似乎是為了診斷用途而設計的。

## 正規表達式選項

請熟悉 [`RegexOptions`][regex-options]。

除了常見的 `IgnoreCase` 選項之外，還有 `MultiLine`，它適合一次處理多行文字，以及 `IgnorePatternWhitespace`，它搭配逐字字串、字串內插和註解時可以非常有表現力，如下所示：

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

另一個值得注意的選項是 `RegexOptions.Compiled`，用於[已編譯][regex-compilation]的正規表達式。
