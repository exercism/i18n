# 指令補充

## 提示

帶有*回傳型別*的函式只能回傳該*型別*的資料和`null`。
不過，呼叫函式的一方只預期會拿到一種資料型態。

例如：
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
為了更清楚表達這個函式也可能回傳`null`或其他資料型態，請使用`dynamic`。
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
