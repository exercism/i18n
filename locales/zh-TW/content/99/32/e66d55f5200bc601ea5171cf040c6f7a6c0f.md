# 簡介

在`Promise`類別出現之前，處理非同步程式碼只有一種方式：_回呼模式_。

回呼函式是一種函式，它會當作引數傳給另一個函式，並在另一個函式完成某個動作後被呼叫。這類回呼函式常見的模式，是把「錯誤」當作第一個參數（見下方範例）。

```javascript
function callback(error, arg2, arg3) {}
```

這跟非同步程式碼有什麼關係？

長久以來，回呼的用途是讓我們能在非同步工作完成後做一些事，而且不會阻塞整個程式。

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

在上面的範例中，`fetchProduct`函式（它是一個非同步函式）會接收一個回呼函式作為第二個引數，用來決定產品資料取得之後要做什麼。
