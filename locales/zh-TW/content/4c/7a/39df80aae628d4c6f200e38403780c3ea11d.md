# 說明

你剛開始在一間攀岩館的櫃檯工作。
會員會購買為期數個月的會員資格，並在每次來訪時簽到與簽退。
經理請你寫一個輔助方法，回答會員最常問的問題。

## 1. 計算會員資格何時結束

從指定日期開始的會員資格，會在指定月數後同一個月份的同一天結束。
如果結束的月份沒有這一天，會員資格就會改在該月的最後一天結束。

實作 `FrontDesk.membershipEnd()` 方法，這個方法接受會員資格的開始日期與月數，並回傳結束日期：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. 顯示會員資格持續多久

健身房會在會員卡上以年、月、天印出會員資格的長度。

實作 `FrontDesk.membershipLength()` 方法，這個方法接受會員資格的開始日期與結束日期，並以 `Period` 回傳會員資格的長度：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. 計算會員資格的剩餘天數

會員經常問自己的會員資格還剩幾天到期。

實作 `FrontDesk.daysLeft()` 方法，這個方法接受今天的日期與會員資格的結束日期，並回傳從今天到結束日期的總天數。
如果結束日期是今天或已經過了，就沒有剩餘天數，因此方法回傳 `0`：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. 測量一次來訪

健身房 24 小時營業，旋轉閘門會記錄會員簽到與簽退的日期和時間。

實作 `FrontDesk.visitDuration()` 方法，這個方法接受一次來訪的簽到與簽退日期時間，並以 `Duration` 回傳這次來訪持續多久：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. 在收據上列印一次來訪

收據會以小時和分鐘顯示一次來訪的長度，例如 `1h 35m`。
分鐘一律寫成兩位數，任何秒數都會省略，而小時不局限於一天以內。

實作 `FrontDesk.formatVisit()` 方法，這個方法接受一次來訪的持續時間，並以此格式回傳：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
