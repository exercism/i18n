# 安裝

Racket 發行版可以從 https://download.racket-lang.org 下載。

我們提供下列平台的安裝程式：

* Windows
* Linux
* macOS

指引教材請參閱 Racket 的 [Getting Started](http://docs.racket-lang.org/getting-started/) 頁面。

[Racket Guide](https://docs.racket-lang.org/guide/intro.html) 會帶你認識如何與 Racket 互動。

使用 DrRacket IDE 的指引請見 [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html)。

Racket 命令列工具以及其他編輯器用法的入門介紹，請見 [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html)。


## 關於 Linux 安裝程式：

Linux 版本相當通用，在大多數發行版上都能運作，包括比較老舊的發行版。

下載安裝程式檔案後，用以下指令執行：
```
sh racket-8.10-x86_64-linux-cs.sh
```

如果要安裝到需要管理員權限的位置，你可能需要在指令最前面加上`sudo`。

**警告：你的發行版套件管理器可能也提供 Racket，不過版本可能比最新的 Racket 還舊。**
雖然你之後也可以選擇改用套件管理器，但身為學習者，如果能使用 https://download.racket-lang.org 上提供的最新版本，體驗會好得多。


## 關於 macOS 安裝程式：

如果你的電腦使用 M1 或 M2 系列處理器，請在下載前於平台下拉式選單中選擇**Apple Silicon**。
