# 不要使用巢狀 if 敘述

試著改寫 if 敘述來避免過深的巢狀結構吧，因為巢狀結構會讓程式碼變得比較難懂。請看下面這兩段程式碼：

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

再和下面這段程式碼比較：

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

第二個範例有著很明確的結構：所有處理錯誤的路徑都放在縮排的程式區塊裡，而「happy path」則永遠靠最左邊對齊。這樣一來，程式碼讀起來非常輕鬆，因為你可以很快看出最常見、不會出錯的那條執行路徑。
