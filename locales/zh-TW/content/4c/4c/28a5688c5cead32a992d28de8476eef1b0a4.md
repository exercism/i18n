# 安裝

安裝 Zig 的方式有很多種，而且隨著這門語言日趨成熟，安裝方式也持續增加。
幸運的是，所有熱門的安裝方法都列在 [Zig 安裝頁面][install-zig] 上。

## Zig 版本

Exercism 使用 Zig 0.17.0（2026 年 10 月 1 日發布）。

練習或許能與其他 Zig 版本相容，但這並不保證。
Zig 尚未推出 1.0 版，破壞性變更屢見不鮮。

## 其他工具

### Zig fmt：產生格式良好的程式碼

完成任何練習時，你的解法可以使用各種程式碼風格。
不過，在解練習之外，例如開發應用程式或函式庫時，讓程式碼保持一致、易讀通常是個好主意。
當其他人想協助你的專案，而必須閱讀你的程式碼時，這點尤其重要。

為了解決這個問題，Zig 編譯器內建了一個輕量的[檢查工具][linters]，能方便地幫你格式化程式碼。
這個程式碼格式化工具旨在遵循 [Zig 文件][documentation] 已建立的[風格指南][style-guide]。

想了解 Zig 原生格式化工具的功能，請使用以下指令：

```bash
zig fmt --help
```

### Zig Zen：寫程式的準則

有時候，一點指引就能在完成任何任務時帶來很大的幫助，寫程式也不例外。
幸好 Zig 編譯器內建了一個有趣的指令，能提醒我們寫出優良 Zig 程式碼的一些目標。

想看看這些智慧箴言，可以使用以下指令：

```bash
zig zen
```

### Zig Language Server：全方位的 Zig 編輯器支援

這款第三方軟體提供編輯器自動完成功能，以及增強的 Zig 程式碼導覽功能，能幫助你更快學會這門語言。

最新說明請參閱 [ZLS 安裝指南][install-zls]。
