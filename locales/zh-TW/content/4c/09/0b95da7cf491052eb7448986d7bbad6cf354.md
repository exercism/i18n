# 說明

一個派對機器人正在為盛大的慶典串起旗串。每一串旗串都是一列由`n`面小旗子排成的橫列，而每面旗子的字元取決於它在這列中的位置，從左邊開始以`0`起算。幫機器人組出下面這些圖案吧。

## 1. 字母旗串

定義 `alphabet-bunting`，讓它從堆疊取出一個非負整數`n`，並回傳由字母表中前`n`個小寫字母組成的字串。

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

你可以假設`n`最多是`26`。

## 2. 數字旗串

定義 `counting-bunting`，讓它接收`n`並回傳由`n`個數字組成的字串，其中位置`i`的旗子顯示`i mod 10`。

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. 條紋旗串

定義 `stripe-bunting`，讓它在兩個字元之間交替：偶數位置是`*`，奇數位置是`-`。

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. 標記旗串

每第五面旗子是一個特別的標記。定義 `marker-bunting`，讓位置`0`、`5`、`10`、……是`|`，其餘是`.`。

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. 山谷旗串

機器人掛起一串固定大小、有 10 面旗子的旗串，釘在中央的掛鉤上。從位置`-5`最左邊的旗子開始數，一路數到`5`（但不含`5`），每面旗子的字元就是它到中央的距離，以數字表示。

定義 `valley-bunting`（不需任何輸入），讓它回傳那個固定的字串。

```factor
valley-bunting .
! => "5432101234"
```
