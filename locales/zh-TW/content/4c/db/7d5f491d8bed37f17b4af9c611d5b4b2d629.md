# 簡介

## 集合

集合是不可變、無序的，其中的值都獨一無二。集合中的所有元素都必須是相同的型別。

`gleam/set` 模組定義了 `Set` 型別，並提供各種處理集合的函式。

你可以用 `set.to_list` 和 `set.from_list` 把陣列和集合互相轉換。集合中元素的順序並沒有保證。

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

你可以用 `set.new`、`set.insert` 和 `set.delete` 建立集合並填入元素。

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

你可以用 `set.contains` 和 `set.size` 這兩個函式查詢集合的內容。

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

集合可以用 `set.union` 和 `set.intersection` 來結合。

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

你也可以篩選集合。

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
