# 簡介

有時在走訪序列時，你需要的不只是元素本身，還有它的*位置*。在[`sequences`][sequences]裡的 `*-index` 家族會把兩者都交給處理個別元素的 quotation。`times` 則是單純計次疊代的好搭檔，當你只需要計數、不需要序列時特別好用。

## `each-index`與`map-index`：索引在 quotation 裡

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

quotation 收到的元素在下面，`index` 則在堆疊的**最上層**：

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index`會執行 quotation 以產生副作用，不回傳任何東西。`map-index`則會把每個元素的結果收集成一個新的序列，型別與輸入相同。

## `times`：計次疊代

`times`（位於 [`math`][math]）會執行它的 quotation `n` 次。

```
times ( n quot: ( -- ) -- )
```

文件上列出的 `( -- )` 形式是*最低要求*：因為 `times` 是 `inline`，所以像 `( str -- str )` 這種堆疊效果平衡的 quotation 也能正常運作，堆疊會在各次疊代之間傳遞下去。這樣一來，不必使用任何可變狀態，就能做出計次累加器：

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

每次疊代的主體都會看到目前的字串，在後面附加內容，再把新的字串留在堆疊上，供下一次疊代使用。當你想讓累加器一路傳下去時，同樣的技巧也適用於 `each-index` 和 `map-index`。

[math]: https://docs.factorcode.org/content/vocab-math.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
