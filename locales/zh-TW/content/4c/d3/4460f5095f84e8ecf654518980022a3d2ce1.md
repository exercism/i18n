# 簡介

許多程式都需要（偽）隨機值，來模擬真實世界的事件。

常見且熟悉的例子包括：

- 擲硬幣：從 ('H', 'T') 中隨機取一個值。
- 擲骰子：1 到 6 之間的隨機整數。
- 洗牌：將卡片陣列隨機排序。
- 在 3-D 圖形模擬中產生樹木和灌木。

用電腦產生真正隨機的值，是一件[出乎意料地困難的技術挑戰][why-randomness-is-hard]，這也是為什麼會有「偽隨機」產生器。

## 產生隨機數字

在 JavaScript 中，你可以使用[`Math.random()`][Math.random]函式來產生偽隨機數字。
它會回傳一個偽隨機浮點數，介於 0（包含）與 1（不包含）之間。

若要取得介於 _min_（包含）與 _max_（不包含）之間的隨機數字，你可以使用像這樣的函式：

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## 產生隨機整數

若要產生隨機整數，你可以使用`Math.floor()`或`Math.ceil()`，把隨機產生的數字轉成整數。
