# 關於

[Conses][hyper-conses] 是 Common Lisp 裡的基本資料型態。每個 cons 都由頭（head）和尾（tail）組成，基於[歷史原因][history]，這兩部分分別稱為`car`和`cdr`。
cons 的頭和尾可以是任何資料型態，沒有限制。

Cons 是用 [`cons`][hyper-cons] 函式建立的，這個函式接受兩個物件，並求值為一個 cons（有時也稱為「cons cell」）。

cons 的各個部分可以用 [`car`][hyper-car] 和 [`cdr`][hyper-cdr] 函式存取。

## 參考

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
