# 給維護者

## 用來建立 Fortran 測試的輔助腳本：create_fortran_test.py

建立練習測試的一個簡單方法，就是使用`bin/create\_fortran\_test.py`這個腳本。

用這個腳本建立初始的 <exercise>\_test.f90 檔案，你可以把它當成測試的範本。
一般來說，你得把產生出來的檔案裡的「response」函式換成正確的函式呼叫。

另外請注意，Fortran 在處理`\n`和`\t`這類特殊字元時會有問題，所以要特別小心。

### 先備條件

- 可正常運作的 CMake 與 Fortran 編譯器
- Python3.x（要讓它也能用 Python2 或許可行，但我沒有花心力讓它向下相容）
- 最新版的 https://github.com/exercism/problem-specifications.git
- git

### 建立新測試的工作流

- 從`exercism/problem-specifications`拉取最新的變更，例如 git clone git@github.com:exercism/problem-specifications.git
- 建立新分支來建立新的練習，例如 git checkout -b exercise-bob
- 針對你想建立的範例執行這個腳本
- 把`config/CMakeLists.txt`複製到練習目錄（你可以用`bin/update-cmake-files`來做這件事）
- 實作出能正常運作的練習
- 修正可能有問題的測試（例如 exercise/bob 的「Test 20」與「Test 24」）
- 確認`ctest`指令能順利驗證、沒有錯誤
- 把你的解答複製到 .meta/example.f90，並把實際的實作從練習檔案中移除，例如 bob.f90
- 更新 .docs 與 .meta 目錄
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - 把「# Description」換成「# Instructions」
  - 手動填寫 .meta/tests.toml（在自動化的做法出現之前）
  - 手動填寫 .meta/config.json（在自動化的做法出現之前）
    - 使用 ../problem-specifications/exercises/bob/metadata.yml
- 為你的變更開啟一個 pull request

以 bob 為例：

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### 修改`CMakeLists.txt`

修改 cmake 檔案時，請更新`config/`裡的主要版本，並用`bin/update-cmake-files`把它複製到所有練習目錄。

## 解答

當你完成解答後，把解答複製到「.meta」目錄，命名為「example.f90」。

也許你想留下一份能幫助學生的函式或副程式骨架實作，並把以練習命名的檔案留在練習目錄中。
