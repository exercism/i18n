# 說明

在這個練習中，你將為一家電影院的網站建立各種規則。

## 1. 檢查電影觀眾是否符合敬老優惠資格

電影院提供「老人年金」優惠。
年滿 60 歲的觀眾票價是 10.00。
未滿 60 歲的人則須付全額 15.00。

請使用三元運算子撰寫`Moviegoer#ticket_price`方法。

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. 檢查電影觀眾是否可以觀看恐怖片

電影院有一套簡化的年齡驗證系統。
年滿 18 歲就能觀看恐怖片。
未滿 18 歲則不能。

實作`Moviegoer#watch_scary_movie?`方法。
它應該回傳這個人是否被允許觀看這部電影。

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. 檢查電影觀眾是否能獲得免費爆米花

電影院有電影俱樂部方案。
會員觀看任何電影都能獲得免費爆米花。

實作`Moviegoer.claim_free_popcorn!`方法。
如果觀眾是電影俱樂部會員，就應該獲得免費爆米花。
如果觀眾不是會員，這個方法應該拋出程式碼最上方定義的`UnsupportedOperation`例外。

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
在這個練習中，你需要在特定的作用域內定義`UnsupportedOperation`例外。
~~~~
