# 補充說明

這是個很適合拿來實驗非標準字串常值和超程式設計的練習。

這篇[部落格文章](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html)有非標準字串常值的簡短介紹。[手冊](https://docs.julialang.org/en/v1/manual/metaprogramming/)裡則有詳細的超程式設計指南。

你可以加入以下描述的功能，來擴充你的解法喔。

加分題 A 只需要部落格文章中提到的基礎知識。加分題 B 則需要更多 Julia 超程式設計的知識。

## 加分題 A
實作一個字串常值，作用等同於對字串套用`ROT13`：
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## 加分題 B
實作字串常值`R<i>`，其中`i = 0, ..., 26`，用來依`i`的值位移字串：
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
