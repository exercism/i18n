# 簡介

_「日期和時間是我們教小孩子的東西。這能有多難？」_

許多程式設計師都犯過這個錯誤，而隨之而來的經驗往往對他們的健康和幸福造成不良影響。

任何用日期和時間做有點複雜的程式設計的人，至少應該準備好理解並減輕潛在的問題。

本文件將試著概略說明 Julia 如何處理日期和時間，但若要瞭解更多細節，仍需查閱[手冊][Dates]。
另外還有一本 [Wikibook][Wikibook]，有些讀者可能會覺得它的解說更清楚，其中還包含一張實用的型別階層[圖解][type-hierarchy]。

## `Dates`模組

大部分基本功能都在`Dates`裡，這個模組包含在預設安裝中，但不屬於標準函式庫的一部分。

要使用這個模組，有兩種做法：

1. 加上`import Dates`，然後在所有函式呼叫前面加上`Dates.`
2. 加上`using Dates`，這會把整個模組帶進目前的命名空間（_少數有問題的名稱除外_）。

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

`Dates`模組龐大又複雜，但它提供四大類功能：

- `Dates.Date`，包含日、月、年，但不含時刻。
- `Dates.Time`，包含時刻，但不含日期。
- `Dates.DateTime`，結合日期與時間。
- `Dates.Period`，處理時間與日期的間隔。

請注意，`DateTime`通常_不_包含時區資訊（Python 會稱之為「naive」datetime）。
其中一個例外是`now()`，它會從你的系統時鐘取得本地時間，必要時還能轉換成 UTC。

或許最常見的需求是：

- 解析某個合適的輸入格式，以建構`Dates`型別。
- 從`Dates`型別取得所需的數字或字串格式。
- 對`Date`、`Time`或`DateTime`值套用位移。
- 計算兩個這類值之間的間隔。
- 取得目前日期（用`today()`）和／或時間（用`now()`）。

~~~~exercism/note
為了減少視覺上的干擾，本文件後續大部分的範例程式碼都假設使用了`using Dates`，並且在函式呼叫中省略模組名稱`Dates.`。
~~~~

### 日期與時間格式

日期和時間有很多種寫法，而且往往因文化而異。
像「7/6/23」這種全數字的日期既模糊又令人困惑，還在跨國組織裡造成過許多代價高昂的錯誤（_作者這麼說，是因為有慘痛的親身經歷_）。

國際標準定義在`ISO 8601`中，主要有兩項優點：

- 解析快速且沒有歧義。
- 排序很容易，因為日期時間可以當成一般文字，按字母順序排序。

前面的範例中，我們看到`Date.now()`回傳`2025-06-21T16:03:04.161`。

它由幾個部分組成：

- 日期部分是`YYYY-MM-DD`。
- 時間部分是`hh:mm:ss`。
- 小數點後則可選擇加上毫秒（或更小的單位）。

其他字串格式會在後面的章節討論。

## 日期

`Dates.Date`是相對簡單、只包含日期的型別，不理解時間或時區。

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

日期各部分的存取函式都有，而且成對出現，以大小寫區分。

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### 查詢函式

有各種對曆法有一定理解的函式。
下面的範例只展示了其中幾個。

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## 時間

`Dates.Time`是基本的、只包含時間的型別。
它不理解日期：時間會在午夜自動回到`Time(0, 0, 0)`。

完整的建構子格式是`Time(hour, min, sec, millisec, microsec)`，或等效的 ISO 8601 格式。

所有參數都是選用的，預設值為`0`。

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

和`Date`一樣，各部分都可以用存取函式取得：

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## 日期時間

`Dates.DateTime`結合了`Date`和`Time`型別的大部分功能。

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

年、月、日參數的預設值是`1`，時間參數則全部預設為`0`。

要記清所有這些參數可能很不容易，所以輸入時用 ISO 格式或許更好。

或者，也可以用`Date`和`Time`建構出`DateTime`，就像上面的範例那樣。

## 期間

日期與時間的每個組成部分都有自己的`Period`型別，從`Year`到`Nanosecond`，代表一段時間間隔。
這些型別在算術運算上特別有用。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

處理`Period`型別時，Julia 會盡量聰明地應對月份長度之類的曆法不規則情形，必要時進行進位。

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## 字串表示法

我們前面提過 ISO 8601 標準，它是 Julia 在格式化或解析字串時預設的日期時間表示法。

顯然，還有許多其他格式被頻繁使用，而且往往因文化而異。
為了處理這些格式，Julia 提供了`DateFormat`型別，它可以從任意複雜度的格式字串建構出來。

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

上面的範例非常簡單，只是歐洲常見的日／月／年格式日期。
語法上展示了兩種寫法，但結果完全相同。

接著就能用`DateFormat`來解析任何合適的字串：

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

建立`DateFormat`有相當大的額外負擔，所以只做一次這一步（就像這裡的`dtfmt`），在對大量日期時間字串迴圈時對效能有幫助。

格式可以比這複雜得多，詳情請查閱[手冊][dateformat]。

同一個`DateFormat`也可以用來把日期時間輸出成任何想要的字串格式，只要使用 [`Dates.format()`][format]函式。

可惜的是，`format`似乎有命名空間衝突（至少在 Julia 1.11.5 是如此），所以即使已經`using Dates`，最好還是加上`Dates.`前置字串。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

如[文件][wiki-format]所述，`"e, u d"`會給出星期和月份的縮寫文字表示。

文字表示預設為英文。
也可以加入其他語言，不過目前對這方面的支援還不夠理想。
