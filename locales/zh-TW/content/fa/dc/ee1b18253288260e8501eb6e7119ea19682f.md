# 說明

在這次練習中，我們來試著解決一個經典問題吧。

Bob 是個小偷。經過幾個月的縝密計畫，他終於成功破解了一棟高級公寓的保全系統。

他面前擺著許多物品，每件物品都有自己的價值（v）和重量（w）。Bob 當然想讓取得的總價值最大化；如果做得到，他會很樂意把所有東西都帶走。但令他崩潰的是，他發現自己帶的背包只能承受有限的重量（W）。

給定一個有特定承載上限（W）的背包，請幫 Bob 算出他能從屋裡的物品中取得的最大價值。注意，每種物品 Bob 只能拿一件。

所有給定的價值都是嚴格的正數。物品會以物品陣列表示，每件物品都有重量和價值。

例如：

```none
Items: [
  { "weight": 5, "value": 10 },
  { "weight": 4, "value": 40 },
  { "weight": 6, "value": 30 },
  { "weight": 4, "value": 50 }
]

Knapsack Limit: 10
```

在上面這個例子中，第一件物品的重量是 5、價值是 10，第二件物品的重量是 4、價值是 40，依此類推。

在這個例子裡，Bob 應該拿走第二件和第四件物品，才能讓價值最大化，在这个情況下是 90。他沒辦法拿到超過 90，因為背包的重量上限是 10。
