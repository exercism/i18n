# 提示

## 一般

- 每個任務都是在迴圈裡組出文字，所以都會從`#FSTR`開始，並以`.str`結束。
- 把每一次`+`的結果都指定回原本的字串變數：`script := script + ...`。

## 1. 重複一句提詞

- `1.upto!(times)` 會讓迴圈執行正確的次數。它產生的值用不到，所以可以直接指定給一個永遠不會用到的變數，或者改用 `times.times!`，它完全不會產生任何值。
- 次數為零時不需要特別處理：迴圈就是不會執行。

## 2. 演員名字的首字母

- `names.elt!` 會取出每一個名字；`[0]` 則取出它的第一個字元。
- `FSTR` 可以直接接受 `CHAR`，所以不需要先把它轉成字串。

## 3. 替每一行編號

- 在一個迴圈裡用兩個疊代器，就像上一個練習那樣：用 `1.up!` 取得編號，用 `lines.elt!` 取得文字。
- 換行要放在每一行之前，第一行除外。最簡單的方法就是檢查編號：`if number > 1 then ... end`。
- `FSTR` 可以直接接受數字，所以 `script + number + ". "` 不需要轉換就能運作。

## 4. 大聲喊出一行台詞

- `line.elt!` 會一次一個字元地走訪字串。
- `.upper` 不會動到任何不是字母的字元，所以空格不需要特別處理。
