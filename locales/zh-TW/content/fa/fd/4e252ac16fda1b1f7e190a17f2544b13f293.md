# 操作說明

某些「其他」開發者一直在開發遙控車專案 [exercise:csharp/remote-control-competition]()。你被找來清理這些程式碼。

## 1. 分離車子本身與遙測系統的關注點

重構`RemoteControlCar`類別，把遙測方法和屬性拆分出來，改由`Telemetry`屬性存取。

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. 避免其他程式碼對 Telemetry 型別產生過多的相依性

確保`Telemetry`實例無法在車子的作用域之外建立。

## 3. 避免其他程式碼相依於 Speed 結構

確保`Speed`結構無法在`RemoteControlCar`類別的作用域之外使用。

## 4. 避免其他程式碼相依於 SpeedUnits 列舉

確保`SpeedUnits`列舉無法在`RemoteControlCar`類別的作用域之外使用。
