# 簡介

## 字串

在 Common Lisp 中，字串是[字元][concept-characters]的[向量][concept-vectors]。它們的寫法是把字元用雙引號包起來（例如「Hello World!」）。

`stringp` 述詞只有在給定的值是字串時，才會回傳 true。

字串可以用 `subseq` 函式拆成子字串，這個函式接受一個字串、一個起始索引，以及選用的結束索引。索引從 0 開始。

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

字串可以用 `string=` 比較是否相等。如果需要忽略字元的大小寫，則可以使用 `string-equal`。

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

字串的大寫、小寫與首字母大寫等操作，可以分別用 `string-upcase`、`string-downcase` 和 `string-capitalize` 來完成。

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
