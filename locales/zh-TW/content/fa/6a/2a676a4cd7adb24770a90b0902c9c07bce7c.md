# 安裝

安裝 PureScript 最簡單的方式是透過 Node.js 和 NPM。

如果你的電腦上還沒安裝 Node.js，可以從 [Node.js 網站](https://nodejs.org/) 下載。等 Node.js 安裝好、可以執行之後，在終端機輸入這個指令，安裝 PureScript 編譯器和 Spago 建置工具：

    npm install --global purescript spago

更多資訊可以在 [PureScript 儲存庫](https://github.com/purescript/purescript/blob/master/INSTALL.md) 找到。
