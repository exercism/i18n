# 說明

Lisp 外星人 Lilly 回來了，這次要做更多料理！他們這次要製作 Lisp 外星千層麵，這道菜跟人類的千層麵其實沒差多少。

Lilly 會需要一些函式，來協助算出千層麵的烹調時間。而且每個函式都要有完善的說明文件，這樣 Lilly 才不會忘記每個函式的用途。

你能幫 Lilly 寫幾個函式，協助他們掌握千層麵的烹調時間嗎？

## 1. 定義烤箱的預期時間（分鐘）

定義`expected-time-in-oven`函式，它不接受任何參數，並回傳千層麵應該待在烤箱裡幾分鐘。依照 Lisp 外星人的傳統（就像 Lilly 的親代單位以前做菜那樣），預期的烤箱時間為 337 分鐘：

```lisp
(expected-time-in-oven) ;; => 337
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remaining-minutes-in-oven`函式，它接受千層麵已經待在烤箱裡的實際分鐘數作為參數，並根據上一個任務算出的預期烤箱時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```lisp
(remaining-minutes-in-oven 100) ;; => 237
```

## 3. 計算準備時間（分鐘）

定義`preparation-time-in-minutes`函式，它接受 Lilly 加進千層麵的層數作為參數，並回傳 Lilly 花了幾分鐘準備千層麵，假設每一層需要 19 分鐘準備。

```lisp
(preparation-time-in-minutes 3) ;; => 57
```

## 4. 計算經過的時間（分鐘）

定義`elapsed-time-in-minutes`函式，它接受兩個參數：第一個參數是 Lilly 加進千層麵的層數，第二個參數是千層麵已經待在烤箱裡的分鐘數。這個函式應該回傳 Lilly 總共花了幾分鐘烹調千層麵，也就是準備時間的分鐘數，加上千層麵當下已經待在烤箱裡的分鐘數。

```lisp
(elapsed-time-in-minutes 3 100) ;; => 157
```
