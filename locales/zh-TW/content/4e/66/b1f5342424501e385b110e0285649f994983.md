# 指令

你正在維護一座訊號站的程式碼產生工具組。
每個巨集都是一個*模板*，也就是一個小範本，編譯器會用它來在每個呼叫端印製出特製化的程式碼。

你只需要寫這 4 個巨集。測試檔定義了一些小小的包裝詞，用來*呼叫*你的巨集（巨集只能透過它產生出來的程式碼來觀察），接著檢查這些包裝詞的執行結果。包裝詞請保持原樣。

每個任務中，巨集主體會從堆疊上收到呼叫端的字面輸入，並且必須留下**一個引號**。「編譯成」那幾行顯示你的引號應該產生出來的直線式程式碼。

## 1. 執行兩次

`twice`接受一個字面引號，並回傳一個會把原本的引號連續執行兩次的引號。

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. 重複 N 次

`repeat-quot`接受一個字面引號和一個字面次數`n`，並回傳一個會把原本的引號連續執行`n`次的引號。`n = 0`會回傳空引號`[ ]`。

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. 組合多個

`compose-many`接受一個由引號組成的字面陣列，並回傳一個會依序執行每一個引號的單一引號。空陣列會回傳空引號。

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. 展開的疊代

`each-literal`接受一個字面序列和一個引號。它會回傳一個引號，這個引號會針對序列中的每個元素，推入該元素，然後執行那個引號。這是發生在編譯期的疊代，所以產生出來的程式碼是直線式的。

這是四個之中結構性最強的一個：序列的長度*和*它的元素值都會形塑產生出來的程式碼。提示會帶你一步一步把它建構出來。

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```
