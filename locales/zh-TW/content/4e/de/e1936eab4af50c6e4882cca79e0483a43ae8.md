# 關於

在 Java 中，布林值以`boolean`型別表示，其值可以是`true`或`false`。

Java 支援三種[布林運算子][operators]：

- `!`（NOT）：對布林值取反
- `&&`（AND）：接受兩個布林值，若兩者皆為 true，結果即為 true
- `||`（OR）：若兩個布林值中有任一個為 true，結果即為 true

`&&`和`||`運算子使用_短路求值_，意思是運算子右側只有在需要時才會被求值。

這些運算子也稱為條件運算子或邏輯運算子。
在文件中，`!`有時被歸類為位元運算，但它具有慣用的 _NOT_ 語意。

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

這三個布林運算子各有不同的[_運算子優先順序_][precedence]。
因此，它們的求值順序如下：先`not`，接著`&&`，最後`||`。
如果你想「跳脫」這些規則，可以把布林運算式用括號（`()`）括起來，因為括號的運算子優先順序更高。

```java
!true && false   // => false
!(true && false) // => true
```
