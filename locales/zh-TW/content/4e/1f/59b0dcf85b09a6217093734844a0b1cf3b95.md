# 說明

你的任務是解析 Smart Game Format（SGF）字串，並回傳一個代表這盤遊戲的樹狀資料結構。

SGF 字串代表一棵由節點組成的樹。整棵樹會包在小括號`()`裡。樹中的每個節點以分號`;`表示，後面接著一連串的屬性。一個屬性由大寫的識別字（例如`AB`）組成，後面接著一或多個以方括號`[]`包住的值。

例如，字串`(;FF[4]C[root])`代表一棵只有一個根節點的樹。這個節點有兩個屬性：
- 屬性`FF`，值為`4`
- 屬性`C`，值為`root`

**變化（樹與分支）**
SGF 透過巢狀的樹來支援遊戲變化。一棵樹可以有多棵子樹，這些子樹同樣包在小括號裡。
例如，`(;A[B](;C[D])(;E[F]))`代表一個帶有屬性`A`的根節點，它有兩個子分支：
1. 屬性為`C`、值為`D`的節點
2. 屬性為`E`、值為`F`的節點

**格式與跳脫**
方括號內的值可以包含跳脫字元。反斜線`\`後面接任何字元，代表的就是那個字元本身（例如`\]`應該解析成字面上的`]`）。此外，如果換行前面有反斜線，這個換行就代表續行，應該從值中移除。值裡其他的換行則應該保留。

**錯誤處理**
遇到無效的 SGF 字串時，你必須拋出錯誤。以下是無效 SGF 的幾個例子：
- 樹不是以小括號`()`開頭。
- 節點不是以分號`;`開頭。
- 屬性識別字並非全部由大寫字母組成。
- 缺少方括號，或小括號沒有成對。

### 資料結構

你的解析函式應該回傳這棵樹的表示方式。常見的做法是把每棵樹表示成一個帶有兩個欄位的物件：
- `properties`：一個物件（或 Map），鍵是屬性識別字（字串），值是字串陣列（因為一個屬性可以有多個值）。
- `children`：一個包含子樹的陣列。


範例：

輸入：`(;FF[4]C[root])`
輸出：`{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

輸入：`(;A[B](;C[D])(;E[F]))`
輸出：`{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
