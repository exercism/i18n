# 簡介

## 變數與賦值

R 是動態型別的語言，所以一般來說不需要指定變數的型別。建議使用的賦值運算子是`<-`。

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

使用`=`取代`<-`通常可行，但並非總是如此，而且這被視為不良風格，不建議這麼做。
如果是在 RStudio 裡作業，可以用鍵盤快速鍵`Alt-minus`輸入。

運算子大多與一般慣例相同，但請注意`%/%`和`%%`：

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

在 R 中，`#`代表單行註解的開頭。
多行註解則沒有另外的語法。

## 函式

定義函式的方式如下：

```R
squareit <- function(x) {
    x * x
}
```

函式可以有零個或多個引數，並以逗號分隔。
即使沒有任何參數，`function()`後面仍需加上小括號`()`。

函式的引數可以指定預設值，但這些引數必須排在所有沒有預設值的引數之後，而且要用`=`而非`<-`來指定預設值。
來看一個沒什麼意義的範例：

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

單行的函式主體其實不一定要加大括號`{ }`，但加上去會被視為良好的風格。

R 會自動回傳函式最後的值，就像上面的範例一樣。

`return()`可以用在函式主體的任何地方，讓回傳值更明確。

呼叫函式的方式和許多其他語言相同：

```R
squareit(3)
#> [1] 9
```
