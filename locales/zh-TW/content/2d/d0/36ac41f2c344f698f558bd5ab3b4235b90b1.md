# 說明

你正在協助一項鳥類調查。每天都會有人坐在賞鳥亭裡，數著飛過的鳥，而當天的數量會以陣列的形式傳回來。

這五個任務都放在`BIRD_SURVEY`類別裡。

## 1. 總數

把每一天的數量加總起來。

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

如果調查完全沒有任何一天，總數就是零。

## 2. 最好的一天

回傳最大的數量。如果沒有任何一天，答案就是零。

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. 繁忙的日子

有多少天的數量高於某個數字？

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

「高於」就是嚴格高於：數量正好等於 2 不算在內。

## 4. 要檢查的賞鳥亭

調查的第一天你檢查一個賞鳥亭，第二天檢查兩個，以此類推。這樣總共要檢查幾個賞鳥亭？

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

也就是 1 + 2 + 3 + 4。

## 5. 第一個繁忙的日子

第一天數量高於某個數字的是哪一天？天數從零開始編號，就跟陣列的位置一樣。如果沒有任何一天那麼繁忙，答案就是`-1`。

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
