# 簡介

## 基本概念

我們會將這門 _語言_ 稱為**AWK**，並將解讀 AWK 程式的 _執行檔_ 稱為**`awk`**或**`gawk`**。

### 模式與動作

一個 AWK 程式是由**模式-動作配對**組成。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**模式**可以是對輸入進行比對的正規表示式，也可以是任何能產生 true/false 值的運算式。

**動作**則是一個或多個 AWK 指令。外層的大括號是必要的。

如果模式的結果為 _true_，就會執行對應的動作。

### 記錄與欄位

AWK 會將輸入解析成一連串的**記錄**，再把每筆記錄分割成零個或多個**欄位**。

預設行為是：

- 以換行作為「記錄分隔符」將輸入分割成記錄，因此每一 _行_ 就是一筆記錄。
- 以空白作為「欄位分隔符」將記錄分割成欄位，因此每一 _詞_ 就是一個欄位。

### 模式與動作（續）

模式可以省略，此時動作會_對每一筆輸入記錄_執行。

動作也可以省略，此時預設動作是印出目前的記錄。

#### 特殊模式

有兩種特殊模式經常會用到。

- `BEGIN`會在讀取任何輸入之前執行對應的動作。
- `END`會在讀取完所有輸入之後執行對應的動作。

### 欄位變數

你可以用`$1`、`$2`、`$3`等方式取用欄位。

目前的記錄是`$0`。

以下是一些其他常用的內建變數。

#### 控制輸入解析的內建變數

- `RS`是輸入記錄分隔符。如前所述，它的預設值是換行。
- `FS`是輸入欄位分隔符。

這些變數通常會在`BEGIN`動作區塊中設定。

#### 傳遞資訊的內建變數

這些變數會在程式執行期間由 AWK 自動設定。

- `NF`會儲存目前記錄的欄位數量。
  - 想取得最後一個欄位的值，可以使用`$NF`。
- `NR`會儲存目前的記錄編號。
  - 在處理多個輸入檔案時，`NR`會保存到目前為止已處理的記錄總數。
- `FNR`會儲存目前輸入檔案中目前的記錄編號。
  - 為了說明 NR 與 FNR 的差異，以下是常見的 AWK 慣用寫法。
    ```awk
    NR == FNR {action}
    ```
    意思是「如果累計的記錄編號等於目前檔案的記錄編號」。這只有在_第一個輸入檔案_的記錄中才可能成立。

### 真值判斷

AWK 使用的真值概念和 C 相同。

- 數字`0`為 false。
- 其他任何數字都為 true。

由於 AWK 是文字處理語言，真值也會延伸到字串。

- 空字串`""`為 false。
- 任何非空字串都為 true。

### 註解

註解以`#`字元開頭，延伸到該行結尾。

### 範例

在類 Unix 系統中，`/etc/passwd`包含了使用者的資訊。每位使用者各佔一行，欄位之間以冒號分隔。

如要列出使用者名稱：

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

請注意，`{print $1}`動作沒有模式，因此會對每一筆記錄執行。

如果只想輸出使用 bash 作為登入 shell 的使用者，可以這樣寫：

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
