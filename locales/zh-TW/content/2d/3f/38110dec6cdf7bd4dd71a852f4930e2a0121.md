# 關於

Swift 提供控制轉移敘述，用來改變迴圈和 switch 敘述的執行流程。除了`return`之外，Swift 還有`continue`、`break`、迴圈標籤和`fallthrough`。

## Continue

`continue`敘述會告訴迴圈停止執行目前的疊代，立刻開始下一次疊代。在`while`或`repeat-while`迴圈中，它會直接跳到條件檢查；在`for-in`迴圈中，則會前進到序列中的下一個元素。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break`敘述會立刻結束整個迴圈或 switch 敘述。程式會從迴圈或 switch 後面的第一行程式碼繼續執行。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## 標籤敘述

在巢狀迴圈中，你可能會想讓`break`或`continue`影響外層迴圈，而不是最內層的迴圈。只要在迴圈前面加上名稱和冒號（`labelName:`），就能為迴圈加上標籤。接著就能把這個標籤交給`break`或`continue`：

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

在 Swift 中，`switch`敘述預設不會繼續執行下一個 case，執行會在符合的 case 結束時自動停止。如果你明確希望執行繼續進入下一個 case，而不檢查它的模式，請使用`fallthrough`關鍵字：

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
