# 說明

你正在開發一款目標為低功耗嵌入式系統的遊戲，需要撰寫幾個便利函式，供遊戲的其他部分使用。

## 1. 計算除法的商與餘數

商是除法的輸出。

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

範例：

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. 從疊代器中挑選位於偶數位置的項目

你的老闆保證，這對啟用螢幕緩衝區最佳化會有幫助。

疊代器是會公開 [`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html) 所定義之方法的項目。那份文件相當詳盡，因為疊代器提供了許多方法；以下是最相關的幾個特性：

- 疊代器是任意長度的項目串流
- 疊代器有 [`enumerate`方法](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate)，會為每個值回傳一個元組`(i, val)`
- 疊代器有 [`filter`方法](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter)，會用閉包判斷是否要產出疊代器中的某個元素
- 疊代器有 [`map`方法](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map)，會用閉包修改疊代器中的元素

由於你的函式可以執行在任何種類的疊代器上，因此它使用`impl`來表示這是 trait 實例，而不是單純的項目。同樣地，`<Item=T>`語法只是表示疊代器產生什麼種類的項目並不重要；你的函式可以產生任何疊代器的偶數元素。

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

範例：

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. 計算某個位置與原點之間的曼哈頓距離

為了方便對應，你有一個元組結構`Position`：

```rust
struct Position(i16, i16);
```

你需要為`Position`實作一個`manhattan`方法，回傳該位置與原點（`Position(0, 0)`）之間的[曼哈頓距離](https://en.wikipedia.org/wiki/Taxicab_geometry)。

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

範例：

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
