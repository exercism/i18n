# 沒有具名匯出

找不到[`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)。少了它，測試不會通過。

確認`%{export.name}`存在，並在它前面加上`export`：
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
