# 關於基礎

Kotlin 是靜態型別語言，設計上能與 Java 完全互通。

Kotlin 與 Java 不同之處在於：

- 語法更清爽、更簡潔；
- 納入許多函數式語言的特色；
- 對可為 null 的值提供廣泛支援。

## 變數

因為 Kotlin 是靜態型別語言，所以必須在編譯期_知道_每個值的型別。

不過，Kotlin 的[型別推論][inference]非常強大，因此通常不需要_指定_型別。

宣告變數的方式有兩種。

1. `val`會建立不可變的變數，而嘗試變更它會產生編譯期錯誤。

```kotlin
val x = 42  // => 42
x = 43      // => 'val' cannot be reasssigned
```

2. `var`會建立可變的變數。

```Kotlin
var x = 42  // => 42
x = 43      // => 43
```

因為不可變的變數能消除常見的一類 bug，所以只要有可能，就鼓勵使用`val`。

此外，即使是`var`也不能改變型別：

```kotlin
var x = 42
x = "foobar" // => Type mismatch: inferred type is String but Int was expected
```

為了減少視覺干擾，本課程大綱大多會省略明確的型別。
儘管如此，至少建議在下列情況指定型別：

- 公開 API
- 函式簽章
- 需要文件說明的地方

有些公司和組織會要求嚴格的型別安全，不允許型別推論；有些則會將型別推論限制在「簡單」型別，或完全採用型別推論。

```kotlin
val x: Int = 42  // => 42
```

一般來說，變數和函式的名稱應使用`camelCase`，而不是`snake_case`

## 函式

使用`fun`關鍵字宣告函式。
與 Java 不同，函式不一定要屬於某個類別。

```Kotlin
fun hello(): String {
    return "Hello, World!"
}

fun add(x: Int, y: Int): Int {
    return x + y
}
```

有幾點要注意：

- 函式名稱後面必須有括號`()`，即使函式不接受任何引數。
- 函式引數必須指定型別：沒有型別推論（與變數相反）。
- 函式主體會用大括號`{ }`包住（不過請見下文）。
- 如果要回傳值，就必須使用`return`關鍵字。
- 行尾的分號`;`可加可不加，通常會省略。
- 算術運算子`+`、`-`、`*`、`/`與大多數主流語言類似。

不過，對於這些非常簡單的「單一運算式」函式，有簡寫語法：

```Kotlin
// return type is usually omitted for single-expression functions
fun add(x: Int, y: Int) = x + y  
```

函式可以有帶預設值的參數。
如果呼叫函式時省略這些參數，就會使用這些預設值：

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

Exercism 中的函式通常會回傳值（因為測試執行器的結構方式）。
若要更廣泛地使用 Kotlin，知道不回傳值的函式可以省略回傳型別和 return 關鍵字，可能會很有用。

這時會說它的回傳型別是`Unit`：相當於 Java 和其他幾種語言中的`void`。

## 註解

單行註解以`//`開頭，該行其餘部分會被忽略。

多行註解以`/*`開頭，並以`*/`結尾

```Kotlin
fun hello(): String {
    /*
     * Failing to run this program on a new installation 
     * is considered bad luck
    */
    return "Hello, World!" // the compiler pixies are now happy
}
```

這與 Java 相同。
