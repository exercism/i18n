# 偏好頂層常數

考慮把`GIGASECOND`這個數字提取成一個常數：

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

只有被`export`的函式、類別和常數，才能從外部看見與存取。通常來說，替[魔術數字](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29)取個名字是合理的做法，也能提升可維護性。這些常數可以放在同一個檔案裡，而不會暴露給其他程式碼。
