# 說明

在這道練習中，你將為一個簡單的計算機建構錯誤處理。

目標是做出一個能正常運作的計算機：當傳入引數`16`、`51`和`+`時，它會回傳符合下列模式的字串：`16 + 51 = 67`。

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. 處理`calculate`方法中可能拋出錯誤的程式碼

這個任務要實作的主要方法是類別方法`SimpleCalculator.calculate()`。它會接受三個引數。
前兩個引數是要進行運算的數字。
第三個引數的型別是字串，而在這道練習中，你需要實作下列運算：

- 使用`+`字串的加法
- 使用`*`字串的乘法
- 使用`/`字串的除法

## 2. 處理不合法的運算

請更新`SimpleCalculator.calculate()`方法，讓它在遇到未知的運算符號時拋出`UnsupportedOperation`例外。

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
在這道練習中，你應該在特定的作用域內定義`UnsupportedOperation`例外。
~~~~

## 3. 處理無效的引數

請更新`SimpleCalculator.calculate()`方法，讓它在引數型別無效時拋出`ArgumentError`例外。

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. 處理除以零的例外

請更新`SimpleCalculator.calculate()`，讓它能處理`ZeroDivisionError`例外。
負責處理的程式碼應該回傳內容為`Division by zero is not allowed.`的字串。
其他任何例外都不應由`SimpleCalculator.calculate()`方法處理。

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
