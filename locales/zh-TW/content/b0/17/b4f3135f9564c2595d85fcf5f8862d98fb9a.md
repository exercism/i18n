# 關於

Go 包含基本的數值型別，這些型別可以表示整數或浮點數值的集合。
型別會因你需要的值大小，以及應用程式執行所在電腦的架構而有所不同（例如 32 位元與 64 位元）。

這個概念會著重於兩種數值型別：

- `int`：例如`0`、`255`、`2147483647`。
  一種有號整數，大小至少為 32 位元（值範圍：-2147483648 到 2147483647）。
  但這會取決於系統架構。
  大多數現代電腦都是 64 位元，因此`int`的大小會是 64 位元（值範圍：-9223372036854775808 到 9223372036854775807）。

- `float64`：例如`0.0`、`3.14`。
  包含所有 64 位元浮點數的集合。

- [Go 內建型別宣告][go-builtins]
- [Digital Ocean：了解 Go 的資料型態][do-understanding-types]
- [Arden Labs：了解 Go 中的型別][arden-understanding-types]

Go 支援標準的算術運算子：`+`、`-`、`*`、`/` 和 `%`（取餘數，而非取模）。

在 Go 中，在不同型別之間賦值需要明確轉換。
例如，要將`int`轉換成`float64`，你需要執行以下動作：

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

如需更多有關型別轉換的資訊，請參閱 [A Tour of Go：型別轉換][type-conversion]
