# 關於

每個 struct 或類別的實例，都有一個名為`self`的隱含屬性，指向實例本身。
`self`最常見的用途，是區分同名的實例屬性和參數：

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift 型別也提供了大寫的`Self`關鍵字，它指的是實例的*型別*，而不是實例本身。
