# 說明

在這個練習中，你會寫一些程式碼，幫助你準備購買車輛。

你有三個任務：判斷自己是否需要取得駕照、幫助自己在兩輛車之間做選擇，以及估算一輛中古車的合理價格。

## 1. 判斷自己是否需要駕照

有些種類的車輛需要駕照才能駕駛。
假設只有`'car'`和`'truck'`這兩種類型需要駕照，其他種類都可以在沒有駕照的情況下駕駛。

實作`needsLicense(kind)`函式，它接收車輛的種類，並回傳一個布林值，表示這個種類的車輛是否需要駕照。

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. 在兩輛可能購買的車輛之間做選擇

你評估了手邊可選的車輛。
你成功把範圍縮小到兩個選項，但你需要有人幫你做最後的決定。
為此，請實作`chooseVehicle(option1, option2)`函式，它接收兩輛車作為引數，並回傳一個決定，其中包含在字典順序中排在前面的那個選項。

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. 估算中古車的價格

既然你已經做出決定，你會想確保自己在經銷商那裡拿到合理的價格。
由於你想買的是中古車，價格取決於車齡。
粗略估算的話，假設車齡不到 3 年，價格是全新時原價的 80%。
如果車齡超過 10 年，價格是 50%。
如果車齡至少 3 年但不超過 10 年，價格是原價的 70%。

實作`calculateResellPrice(originalPrice, age)`函式，使用`if`、`else if`和`else`套用這套邏輯（如果你想練習，還有其他做法）。
它接收原價和車齡作為引數，並回傳經銷商估算的價格。

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
