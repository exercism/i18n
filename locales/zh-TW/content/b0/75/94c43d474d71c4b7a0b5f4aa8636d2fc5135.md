# 簡介

## while 迴圈

只要符合特定條件，你就可以用 while 迴圈重複執行程式碼。
它的寫法是以`while`關鍵字開頭，後面接著用括號包住的條件，以及用大括號包住迴圈_主體_的程式區塊。

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript 也有 do-while 迴圈。它的條件是在迴圈主體執行完之後才檢查，因此當條件取決於迴圈主體中運算出來的結果時，就非常實用。

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

在迴圈主體裡，你可以使用`break`關鍵字來完全停止迴圈的執行。相對地，`continue`關鍵字只會停止目前這次疊代，然後繼續執行下一次。善用`continue`，通常就能避免把迴圈主體的一大段程式碼包進 if 敘述裡。

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## switch 敘述

除了 if 敘述之外，JavaScript 也有 switch 敘述，可以依照條件執行不同的邏輯。當單一變數需要與多個不同的值比較時，就會用到它。比較的方式是檢查嚴格相等（`===`），請參閱[比較的概念][concept-comparison]。以某個變數`x`來說，JavaScript 的 switch 敘述語法如下。

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default`分支是選用的，當其他選項都不符合這個變數時，可以用它來執行一些程式碼。

上面這些`break`敘述之所以必要，是因為在 JavaScript 中，所有分支預設都會「fallthrough」。也就是說，如果沒有`break`敘述，即使`x`不符合後面那些選項，第一個符合的選項底下所有分支的程式碼還是會被執行。這種「預設 fallthrough」的行為，是在 JavaScript 中使用`switch`時常見的陷阱。在函式內，也可以用`return`取代`break`來避免這個問題。
