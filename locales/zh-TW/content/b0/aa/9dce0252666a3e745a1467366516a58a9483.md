# 指令補充

## 例外訊息

有時我們會需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做的時候，最好一律附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓程式碼更好讀，對除錯也有很大的幫助。如果你已經知道錯誤來源屬於某個特定型別，可以選擇[引發其中一種內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但還是要附上有意義的訊息。

這個練習要求你使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在 `largest_product()`函式收到無效輸入時「拋出」`ValueError`。你必須同時`raise`這個`exception`並附上訊息，測試才會通過。歡迎直接沿用你在`series`練習中寫的程式碼！

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception` 型別的引數：

```python
# span of numbers is longer than number series
raise ValueError("span must not exceed string length")

# span of number is negative
raise ValueError("span must not be negative")

# series includes non-number input
raise ValueError("digits input must only contain digits")
```
