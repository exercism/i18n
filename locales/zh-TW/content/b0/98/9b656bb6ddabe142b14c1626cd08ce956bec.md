# 簡介

Julia 中的 `String`是一段有序的字元序列。正如手冊所指出的：「當然，真正的麻煩在於追問字元究竟是什麼。」

這些複雜之處大多會在 `Chars`概念裡更詳細地說明，這裡先簡單帶過：

- Julia 中所有的字串都是 Unicode。
- 恰好也是 ASCII 的字串（英文大小寫字母 A 到 Z、數字，以及少數標點符號）_很容易_處理。
- 世界上大多數其他的書寫系統也_可以_處理，但需要更小心。

## 字串常值

一般來說，字串會用雙引號 `" "` 包住。
單引號 `' '` 只用於 `Chars`。

也可以使用三重雙引號 `""" """`，這樣就能在字串裡直接使用 `"`，不必跳脫。
更重要的是，多行字串中多餘的縮排會被去除。

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### 跳脫字元

就像從 C 開始的大多數語言一樣，Julia 用反斜線 `\` 來跳脫：

1. 輸入不可列印的字元，例如前一個例子中的換行 `\n`。
2. 保護原本具有特殊意義的字元，例如 `\$`（見下文）。

## 索引

原則上，字串可以像向量一樣索引：

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

對 "Julia" 這樣的 ASCII 字串來說，這顯然可行，但這樣一來就忽略了世界上大多數的語言。

來看看《貝奧武夫》裡的一個字元，那是以大約 15 個世紀前的古英語寫成的。

"Hrōðgār" 顯然有 7 個字元，但不是全部都是 ASCII。

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

這樣對字串做索引一開始很順利，但到了某個點就會出問題：

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

問題在於，這樣的索引方式計算的是_位元組_，而對非 ASCII 字串來說，位元組和字元並不是一對一的關係。
一個 Unicode/UTF-8 字元最多可能需要 4 個位元組來表示，`Chars`概念會進一步探討這一點。

## 建立字串

### 串接

許多語言用 `+` 當作字串串接運算子，但 Julia 不是這樣。
至少錯誤訊息還算有幫助。

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

`string()`函式可以串接任意數量的字串。

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

`join()`函式也能做到同樣的事，而且還能接收一個字串向量，用指定的分隔符號把它們串接起來（預設為 `""`）。

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

請注意，字串是不可變的，而串接會牽涉到複製。
因此，在迴圈裡反覆串接效率很差，比較好的做法是把片段收集到一個向量裡，最後再全部串接起來。

### 重複

很簡單：

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### 內插

許多語言都有把計算出來的值插入字串的方法，只是對於該用什麼語法最好，大家的分歧非常之大。

在 Julia 中，要內插的值前面會加上 `$`。

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

如果省略括號會造成歧義，就必須加上括號；但若是單一識別碼後面接著空白，則可加可不加。

若要在字串裡加入 $，請將它跳脫成 `\$`。

要注意一個限制：目前的內插不支援格式化，例如指定要顯示幾位小數。

### `@sprintf()`

為了更精細地控制字串的組合，Julia 沿用了 C 的 `sprintf` 函式（之後幾個語言也是如此；維基百科上列了大約 30 種）。

在 Julia 中，這是以 `Printf`模組裡的 `macro`實作的，因此有 `@` 前綴。

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## 字串函式

為了簡單起見，本節將聚焦在會回傳新字串、而不改變輸入的函式。
許多這類函式都有一個以 `!` 為後綴的對應版本，會原地修改輸入。

### 長度

一個字串有多長？
有時候，這取決於你怎麼數。

最簡單的情況是 ASCII 字串，每個字元佔 1 個位元組。

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

`length()`函式回傳的是_字元_數，`sizeof()`函式回傳的則是_位元組_數。

碰上其他字元集時，這個區別就變得重要了：

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### 分割

程式設計中常見的操作，是拿一個長字串，依照一個或多個字元組成的分隔字串，把它切成好幾段。

最一般的情況，我們用 `split()`函式。
分隔符號預設為（任何）空白，但也可以指定其他的。

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

這些例子把字串切成更小的_字串_。
把字串切成_字元_則是另一回事。

### 尋找與取代

字串裡是否包含某個指定的子字串？
奇怪的是，有兩個函式可以測試這件事：`occursin()`和 `contains()`只差在引數的順序。

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

如果想更精確地指定位置：

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

要取得子字串的起始:結束索引，我們有幾個函式：

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

要取代子字串，請用 `x => y` 語法列出各項變更。

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

從 Julia 1.7 起，`replace`函式可以接受任意數量的變更，並保證在取代過程中每個字元最多只會被改動一次。

`x => y` 這種語法叫做 `pair`，是 Julia 中很重要的型別，`Dicts and Pairs`概念裡有更詳細的介紹。

### 空白

我們經常需要移除字串開頭與結尾的空白。

用來做這件事的函式有 `lstrip()`（左）、`rstrip()`（右）、`strip()`（兩邊）。

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### 改變大小寫

這些函式的名稱相當望文生義：

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
