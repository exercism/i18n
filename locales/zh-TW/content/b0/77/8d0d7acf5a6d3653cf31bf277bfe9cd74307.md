# Bash 踩地雷練習的提示

這個練習似乎需要用到二維陣列。
Bash 只提供一維的索引式或關聯式[陣列][array]。

多維陣列可以使用關聯式陣列來模擬：將索引編碼成以逗號分隔的字串，當作陣列的鍵。

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
