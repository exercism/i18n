# 簡介

## 例外

Java 程式語言使用_例外_來處理錯誤和其他異常事件。

### 什麼是例外

例外是在程式執行期間發生、會打斷指令正常流程的事件。
在 Java 中，例外是明確地被拋出的，而拋出例外的動作稱為_拋出例外_。
處理例外的動作則稱為_捕捉例外_。

在 Java 中，所有例外都是`Exception`類別的子類別，而`Exception`本身又是`Throwable`的子類別。

Java 將例外區分為 2 種：

1. 受檢例外
2. 未受檢例外

#### 受檢例外

_受檢例外_是應用程式應該預期，並能從中復原的異常狀況。
受檢例外的一個例子是`FileNotFoundException`，當方法試圖讀取不存在的檔案時就會發生。

這類例外會在編譯期受到檢查：拋出受檢例外的方法必須在方法簽章中註明，而呼叫可能拋出受檢例外的方法的程式碼則必須處理它，否則程式碼無法編譯。

所有受檢例外都是`Exception`的子類別，且不繼承`RuntimeException`。

#### 未受檢例外

_未受檢例外_是應用程式通常無法預期、也無法從中復原的異常狀況。
未受檢例外的一個例子是`NullPointerException`，當方法預期收到非 null 的值，卻收到`null`時就會發生。

這類例外不會在編譯期受到檢查：拋出未受檢例外的方法不必在方法簽章中註明，而呼叫可能拋出未受檢例外的方法的程式碼也不一定要處理它。

所有未受檢例外都繼承自`RuntimeException`，而`RuntimeException`本身則是`Exception`的延伸。

### 拋出例外

Java 中的方法可以使用`throw`敘述來拋出例外。

#### 拋出受檢例外

從方法拋出受檢例外時，必須使用`throws`關鍵字在方法簽章中註明，如下方範例所示。
這會強制呼叫端的程式碼預期例外可能被拋出，並據此處理。

```java
public class InsufficientBalanceException extends Exception {

}

public class BankAccount {
  public void withdraw(double amount) throws InsufficientBalanceException {
    if (balance < amount) {
      throw new InsufficientBalanceException();
    }

    // rest of the method implementation
  }
}
```

#### 拋出未受檢例外

從方法拋出未受檢例外時，不一定要在方法簽章中註明，雖然 Java 也支援這樣做。

```java
public class BankAccount {
  public void withdraw(double amount) {
    if (amount < 0) {
      throw new IllegalArgumentException("Cannot withdraw a negative amount");
    }

    // rest of the method implementation
  }
}
```

### 處理例外

在 Java 中，處理例外是透過`try`、`catch`和`finally`關鍵字來完成。

- 可能拋出例外的程式敘述應該包在`try`區塊中。
- `try`區塊後面接著一個或多個`catch`區塊，用來捕捉`try`區塊中拋出的例外。
- `catch`區塊後面可以選擇性地加上`finally`區塊，它會在`try`區塊之後一律執行，無論是否拋出例外。

以下範例示範這些關鍵字如何運作：

```java
public class ATM {
  public void withdraw(BankAccount bankAccount, double amount) {
    try {
      System.out.println("Withdrawing " + amount);
      bankAccount.withdraw(amount);
      System.out.println("Withdrawal succeeded");
    } catch (InsufficientBalanceException) {
      System.out.println("Withdrawal failed: insufficient balance");
    } catch (RuntimeException e) {
      System.out.println("Withdrawal failed: " + e.getMessage());
    } finally {
      System.out.println("Current balance: " + bankAccount.getBalance());
    }
  }
}
```

在這個範例中，沒有拋出例外時會印出以下內容：

```text
Withdrawing 10.0
Withdrawal succeeded
Current balance: 5.0
```

不過，如果`bankAccount.withdraw(amount)`敘述拋出`InsufficientBalanceException`，就會印出以下內容：

```text
Withdrawing 10.0
Withdrawal failed: insufficient balance
Current balance: 5.0
```

或者，如果`bankAccount.withdraw(amount)`拋出未受檢例外，就會印出以下內容：

```text
Withdrawing -10.0
Withdrawal failed: Cannot withdraw a negative amount
Current balance: 5.0
```

### 錯誤

Java 另外還有一個稱為_錯誤_的獨立類別，指的是應用程式外部的嚴重問題。
錯誤的一個例子是`OutOfMemoryError`，當應用程式試圖使用超過系統可用記憶體時就會發生。

和未受檢例外一樣，錯誤不會在編譯期受到檢查。
差別在於，它們代表系統層級的問題，通常是由 Java 虛擬機器或環境拋出，而不是應用程式。
應用程式通常不應該嘗試捕捉或處理它們。

Java 中的所有錯誤都繼承自`Error`類別。
