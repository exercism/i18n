# 簡介

AWK 是一門非常小的語言，只有少數幾種基本資料型態。
在這個單元裡，我們會介紹數字與字串。

## 數字

AWK 的數字是以雙精度浮點數實作的。
整數、浮點數與雙精度浮點數之間並沒有區別。

AWK 看得懂八進位常數（以`0`開頭）和十六進位常數（以`0x`或`0X`開頭）。

### 數值運算

你可以使用標準的算術運算子`+`、`-`、`*`、`/`、`%`。
指數運算子是`^`。
還有一些內建的數值函式，包括三角函式、亂數產生，以及`int(x)`，用來把數字截斷成 _x_ 與零之間最接近的整數。

## 字串

AWK 的字串是字元序列。
使用雙引號來指定字串常數。

### 字串運算

字串運算只有一種：串接。
串接沒有專用的運算子；
只要把兩個字串並排放在一起，就會將它們串接起來：

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` 是**敘述**，不是函式。
`print` 不需要括號。
~~~~

AWK 有豐富的字串處理函式。
隨著我們在這條學習路徑上繼續前進，之後會更深入地認識它們。

## 數字與字串之間的轉換

沒有明確的運算子可以在數字與字串之間轉換。
AWK 會根據程式的上下文隱式地完成這件事。
這讓處理輸入欄位的值變得非常簡單：AWK 通常就是照著你想要的方式去做。

* `print x + y` 會因為`+`這個數值運算，把`x`和`y`變數的值轉換成數字。
* `print x y` 會因為串接運算，把`x`和`y`變數的值轉換成字串。

如果你想明確一點，`0 + x`會給出 _x_ 的數字表示，而`"" x`會給出 _x_ 的字串表示。

### 從字串轉成數字

AWK 把字串轉換成數字的方式可能會讓人困惑。
有個簡單的理解方式：AWK 會從字串開頭開始讀取「數字字元」，直到遇到「非數字」字元為止。
幾個例子：

* `"2.5"`會轉換成數字`2.5`；
* `"1e3"`會轉換成數字`1000`（科學記號）；
* `"456abc"`會轉換成數字`456`（因為`a`不是「數字」，轉換就停在這裡）。
* `"abc789"`會轉換成數字`0`（字串的**開頭**沒有任何數字）。
