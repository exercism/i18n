# 指令

你在開發一款屬於自己的角色扮演遊戲。在你的遊戲裡，有_角色_和_物品_。你可以對物品做的眾多動作之一，就是讓角色把它吃掉。

不是所有物品都能吃，也不是所有能吃的物品都會對角色產生同樣的效果。有些物品被吃掉後會變成另一種物品（例如你吃掉一顆蘋果，就只剩下蘋果核）。

為了保有這樣的彈性，你決定建立一個`Edible`協定，讓部分物品可以實作它。

## 1. 定義可食性

建立`RPG.Edible`協定。這個協定只有一個函式：`eat`。`eat`函式接受一個物品和一個角色，並回傳一個副產品和一個角色。

## 2. 讓麵包可以吃

為`RPG.LoafOfBread`物品實作`RPG.Edible`協定。一條麵包被吃掉時，會給角色 5 點生命值，而且沒有副產品。

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. 讓魔力藥水可以吃

為`RPG.ManaPotion`物品實作`RPG.Edible`協定。魔力藥水被吃掉時，會給角色等同於藥水強度的魔力點數，並產生一個空瓶。

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. 讓毒藥可以吃

為`RPG.Poison`物品實作`RPG.Edible`協定。毒藥被吃掉時，會奪走角色所有的生命值，並產生一個空瓶。

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
