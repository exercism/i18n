## 暫存器

| Register | Usage     | Type    | Description                |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | 輸入      | 整數    | 輸入的數字                 |
| `$v0`    | 輸出      | 整數    | 蛋的數量                   |
| `$t0-9`  | 暫存      | 任意    | 用於暫存資料               |
