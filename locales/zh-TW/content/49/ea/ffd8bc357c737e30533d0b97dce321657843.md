# 簡介

你的朋友 Eliud 從奶奶 Tigist 那裡繼承了一座農場。
她的奶奶是一位發明家，總是把東西做得過度複雜。
雞舍裡有一個數字顯示器，上面顯示一個編碼過的數字，代表所有可能撿到的蛋的位置。

Eliud 請你寫一個程式，顯示雞舍裡實際的蛋的數量。

位置資訊的編碼方式計算如下：

1. 掃描每個可能下蛋的位置，有蛋就記下`1`，空的位置就記下`0`。
2. 把這個數字從二進位轉成十進位。
3. 把結果顯示在顯示器上。

範例 1：

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

範例 2：

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
