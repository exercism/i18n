# 關於

Factor 把隨機性集中在[`random`][random]詞彙裡的單一個泛用 word 上：

```
random ( obj -- elt )
```

它會根據引數決定行為：

- **整數**`n`會產生`[0, n)`範圍內的隨機整數；
- **sequence**會產生一個隨機元素；
- assocs、hash-sets，以及`uniform-distribution`元組也都支援。

另外還有兩個以它為基礎的 sequence 輔助工具：

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize`會就地修改並回傳 sequence，所以如果需要保留原本的順序，請先`clone`。

## 隨機性從何而來

`random`會讀取`random-generator`動態變數所持有的產生器。預設是以系統時鐘作為種子的 Mersenne Twister，因此每個行程都不一樣。你可以在 quotation 的動態範圍內安裝不同的產生器：

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

因為`with-random`只是在 quotation 的動態範圍內綁定`random-generator`，所以包裝它的 word 應該標記為`inline`，這樣 quotation 才能把結果留在堆疊上讓呼叫方取用。

除此之外，`random`還提供`random-bits`、`random-unit`、`uniform-random`和`normal-random`來處理其他分佈，另外還有`system-random-generator`和`secure-random-generator`，用於不可重現與密碼學相關的需求。
