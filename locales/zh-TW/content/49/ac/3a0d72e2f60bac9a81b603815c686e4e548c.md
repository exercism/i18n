# 簡介

## 函式

你可以在`jq`中定義自己的**自訂函式**，來封裝你需要的任何邏輯。
_函式_的行為就像內建函式一樣：它們接收一個輸入，並輸出零個、一個或多個輸出。

### 定義函式

你可以用以下語法定義一個`jq`_函式_：

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- 以`def`關鍵字開頭，
- 函式主體前有一個冒號，
- 主體由單一運算式組成，
- 以分號結尾，
- 和`jq`語法的其他部分一樣，你可以自由使用空白來提升可讀性。

### 函式要放在哪裡

_函式_必須先定義才能使用：下面這樣會出錯：

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

這表示你必須把_函式_放在`jq`程式碼的最前面，也就是「主要」運算式之前。

#### 巢狀函式

_函式_可以巢狀：

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

在這裡，`B`_函式_只在`A`的主體內可見。

### 作用域

一個_函式_會為變數和巢狀函式引入新的**作用域**。

### 引數

_函式_的**引數**是用_分號_分隔，不是逗號。
例如，一個接收一個數字，接著加上一個數字再乘上一個數字的_函式_：

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

#### 引數是_運算式_

函式的_引數_是篩選器，不是值。
從這個角度來看，它們的行為就像其他語言所說的回呼一樣：

以`add_mul`函式為例：

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

這裡發生了什麼事？

- `adder`引數拿到的是_運算式_`. + 5`
  - 當函式執行`. + adder`時，就會變成`. + . + 5`
  - 因為`. == 10`，結果會是 25
- 同樣地，`multiplier`引數是運算式`. - 2`
  - 結果會是 8
  - 然後結果就是`25 * 8 == 200`

#### 引數當作值

有時你會想把_引數_「具體化」成一個變數：

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

這有個簡寫：

```jq
def my_func($arg):
    other stuff ...
;
```

注意，這只是「語法糖」：沒有`$`的`arg`名稱，在_函式_裡仍然在作用域內。

### 參數數量

_函式_有**參數數量**，也就是它們接收的_引數_個數。

_函式_可以用同一個名稱搭配不同的_參數數量_。
內建的[`range`][man-range]函式就是個例子：`range/1`、`range/2`和`range/3`都可以並存。

這在定義透過引數攜帶狀態的遞迴函式時很有用。
例如`map`_可以_這樣實作：

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

### 遞迴

`jq`會進行尾呼叫最佳化，但只限於參數數量為 0 的函式。

### 模組

`jq`模組是一個只包含函式的檔案。
模組會用[`include`][man-include]或[`import`][man-import]指令引入到`jq`程式中。
