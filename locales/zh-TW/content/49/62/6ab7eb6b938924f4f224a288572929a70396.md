# 說明

在這個練習中，你將會模擬一台秤重機。

## 1. 建立秤重機的初始狀態

初始化時，秤重機應該採用出廠設定，而出廠設定會依機器銷售的地區而有所不同。
因此，這台機器應該要能在初始化時指定精確度，以及是否使用公制。

請實作 `WeighingMachine#initialize` 方法，它接受兩個引數：`precision`（型別為 `Int32`）和 `metric`（型別為 `Bool`）。
`metric` 引數為 `true` 時，表示機器應該使用公制，否則應該使用英制。
這個 `initialize` 方法也應該將實例變數 `@weight` 設為 `0.0`。

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. 讓秤重機具備精確度

為了滿足不同的需求，我們讓每台秤重機都能自訂精確度（小數分隔符後面的位數）。

請實作 `WeighingMachine#precision` 取值方法，回傳秤重機的精確度。

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. 讓秤重機可以設定重量

請實作 `WeighingMachine#weight` 屬性，讓重量可以被取得*和*設定：

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. 讓機器可以在公制和英制單位之間切換

請實作 `WeighingMachine#metric=` 屬性，讓單位可以被設定。
它應該接受布林值。

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
