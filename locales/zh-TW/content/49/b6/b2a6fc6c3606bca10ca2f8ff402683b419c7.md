# 說明

在這個練習中，你會和朋友一起玩猜數字遊戲。規則很簡單：你偷偷在`1`到`100`之間選一個數字，朋友則試著猜出你選的是哪個數字。為了幫助朋友，你會根據猜測和你選的數字（`42`）有多接近，給出不同的回應。以下是各種回應的規則：

- 如果猜的是`42`：「Correct」
- 如果猜的是`41`或`43`：「So close」
- 如果猜的數字小於`41`：「Too low」
- 如果猜的數字大於`43`：「Too high」

你有四個任務，要分別實作這些猜測對應的回應。

## 1. 回應正確的猜測

實作`reply`函式，讓它能回應正確的猜測：

```gleam
reply(42)
// -> "Correct"
```

## 2. 回應接近的猜測

修改`reply`函式，讓它能回應很接近的猜測：

```gleam
reply(41)
// -> "So close"
```

## 3. 回應太低的猜測

修改`reply`函式，讓它能回應太低的猜測：

```gleam
reply(25)
// -> "Too low"
```

## 4. 回應太高的猜測

修改`reply`函式，讓它能回應太高的猜測：

```gleam
reply(88)
// -> "Too high"
```
