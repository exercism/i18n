# 輸入輸出參數

在函式的主體內，參數會被視為常數，而不是變數；若試圖修改參數的值，會引發編譯期錯誤。
如果函式想要修改某個參數的值，就必須使用[_輸入輸出參數_][in-out-parameters]，讓這種可變性明確表達出來。

使用輸入輸出參數時，程式設計師必須確認三件事：

1. 函式定義必須在參數的型別標註中，於`:`和型別名稱之間寫上關鍵字`inout`，明確標示出輸入輸出參數。
2. 傳入輸入輸出參數的值必須宣告為變數，不能是常數。同樣地，它也不能是字面值。
3. 呼叫函式時，變數名稱前面必須加上`&`，明確標示它可被修改。

完成這些步驟後，函式會為輸入輸出參數建立一份內部副本，依函式主體中的指示修改它，並在函式回傳時，把修改後的值複製回傳入的那個變數。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
關於輸入輸出參數，還有幾條額外的規則需要留意。

1  在含有輸入輸出參數的函式內，你不能參照以輸入輸出參數傳入的那個變數。
2. 同一個變數不能在同一函式中作為多個輸入輸出參數傳入。
   例如，`inoutFunc(&mutVar, &mutVar)`會引發編譯器錯誤。
~~~~
