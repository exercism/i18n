# 指令

從前有一位性格古怪的程式設計師，住在一棟裝了鐵窗的奇特房子裡。
有一天，他在一個線上求職看板上接下了一份工作，要打造一個派對機器人。這個
機器人應該要問候人們，並引導他們入座。第一版非常技術導向，也顯露出這位
程式設計師缺乏與人互動的能力。其中有些特點也被帶到了下一版。

## 1. 歡迎新賓客來到派對

實作 `welcome` 方法，使用給定的名字回傳一段歡迎訊息：

```crystal
PartyRobot.welcome("Christiane")
# => Welcome to my party, Christiane!
```

## 2. 歡迎今天生日的新賓客來到派對

實作 `happy_birthday` 方法，使用這個人的名字和年齡回傳一段生日訊息。
可惜這位程式設計師有點愛現，所以機器人得展現它對每位賓客生日的了解。

```crystal
PartyRobot.happy_birthday("Frank", 58)
# => Happy birthday Frank! You are now 58 years old!
```

## 3. 指引方向

實作 `assign_table` 函式來指引方向。
它應該接受 5 個參數。

- 要問候的新賓客名字（`String`）
- 桌號（`Int`）
- 同桌賓客的名字（`String`）
- 找到這張桌子的方向（`String`）
- 到這張桌子的距離（`Float64`）

確切的結果格式可以參考下面的範例。

同桌賓客的名字應該縮寫成名字的第一個和最後一個字母。
Frank 變成 Fk，Christian 變成 Cn，以此類推。

機器人會提供桌號。
機器人也會提到這張桌子的距離。
幸好，精度只限於 1 位數。

```crystal
PartyRobot.assign_table("Christiane", "on the left", 27, 23.7834298, "Frank")
# =>
# Welcome to my party, Christiane!
# You have been assigned to table 27. Your table is on the left, exactly 23.8 meters from here.
# You will be sitting next to Fk.
```
