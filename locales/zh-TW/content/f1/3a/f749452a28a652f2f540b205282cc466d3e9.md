# 簡介

## 比較

### 比較數字

在`jq`中，數字可以用下列的關係運算子和相等運算子來比較。

| 比較             | 運算子 |
| ---------------------- | -------- |
| 大於           | `a > b`  |
| 大於或等於 | `a >= b` |
| 小於              | `a < b`  |
| 小於或等於    | `a <= b` |
| 等於               | `a == b` |
| 不等於               | `a != b` |

比較的結果一律是布林值，也就是`true`或`false`。

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### 比較字串

上述的比較運算子也可以用來比較字串。
這種情況下，會套用字典（詞典）順序。
排序的依據是_Unicode 碼點的值_。

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

比較兩個看似含有數字值、型別卻是字串的變數時，你需要特別小心。
由於採用字典順序，結果不會和比較型別為數字的值相同。

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### 「嚴格」相等

`jq`的`==`運算子就像 JavaScript 的`===`，也就是說，外表「看起來」一樣、但型別不同的東西並不相等。

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### 比較陣列

若兩個陣列中所有對應的元素都相等，這兩個陣列就相等。

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### 比較物件

若兩個物件擁有相同的鍵值對，這兩個物件就相等。

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## 條件判斷

### `if`運算式

`jq`的**條件運算式**是`if A then B else C end`。

`if-then-else`和所有`jq`內建功能一樣是個篩選器：它接收輸入，並產生輸出。

若運算式`A`產生「為真」的值，`if`篩選器就會求值`B`。
否則它會求值`C`。
傳入`if`篩選器的輸入會傳遞給`B`或`C`。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`子句是**非必要**的；以下兩個敘述等價。

```jq
if A then B else . end
if A then B end
```
~~~~

### 巢狀`if`敘述

可以用`elif`加入更多條件。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

你可以依需要加入任意多個`elif`子句。

### 真值性

`jq`中唯一的「假」值是`false`和`null`。
其他一切都是「真」，連數字零，以及空字串、空陣列和空物件也是。

### 布林運算子

你可以用**布林運算子**`and`和`or`建立複雜的查詢。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

若要取反，請使用`not`。它是**篩選器**，不是運算子。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### 替代運算子

**替代運算子**讓你在運算式為 false 或 null 時，指定一個「預設」值。

```jq
A // B

# This is identical to
if A then A else B end
```

舉例說明：

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
