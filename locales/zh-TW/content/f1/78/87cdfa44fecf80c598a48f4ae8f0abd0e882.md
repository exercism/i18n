# Unison 基礎

## 詞項與函式

詞項與函式是撰寫 Unison 程式的基本單位。

我們把靜態的值稱為「詞項」。它的定義方式是 `name = expression`，前面可以選擇性加上形式為 `name : MyType` 的型別簽章。Unison 支援型別推論，所以在簡單的定義中，你可能會看到型別簽章被省略。

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

Unison 函式的形式像 `myFunctionName argument1 argument2 = myImplementation`，以函式名稱開頭，後面接著以空格分隔的引數。

```
getMax a b = Nat.max a b
```

函式也可以選擇性加上型別簽章。最右邊的型別永遠是這個函式最終的回傳型別，每個引數之間則以函式箭頭 `->` 分隔。

```
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

要呼叫一個函式，就寫出它的名稱，後面接著只以空格分隔的引數。

```
maximum = getMax 1 10
```

呼叫函式時，Unison 會試著把緊接在右邊的東西當成引數，這未必總能產生你想要的函式求值順序。

假設我們想從下面這個運算式取得值 `1`。

```
shouldBe1 = getMax 1 10 - 10
```

依照目前的寫法，`shouldBe1` 會求值為 `0`，因為隱含的函式應用順序是 `getMax 1 10`，也就是 `10`，接著再算 `10 - 10`，得到 `0`。

你可以用括號重新分組這個運算式，得到你想要的運算順序。

```
shouldBe1 = getMax 1 (10 - 10)
```

## 多行函式

Unison 的多行函式使用縮排或 `let` 區塊來界定程式碼的邊界，也就是所謂的「語彙作用域」。

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

縮排層級相同的所有內容都共用同一個作用域，這就是為什麼我們能在最後一行引用變數 `newBeginning`。

## 命名空間與 `use` 敘述

命名空間是我們用來分組和組織 Unison 函式的方式。你可以把它們想成類似「目錄」的東西。它們提供結構與邏輯上的分組。

你可以用 `use` 敘述把某個命名空間裡的函式帶入作用域。

假設你正在寫一個會用到 Unison `List` 值的函式。你知道自己會需要像 `List.map` 和 `List.flatMap` 這樣的函式，其中 `List` 是命名空間，而 `map` 和 `flatMap` 是函式。為了避免重複，你可能會選擇在自己的函式中把 `List` 命名空間裡的所有東西都帶入語彙作用域，像這樣：

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

`use List` 這一行釐清了對 `map` 和 `flatMap` 的引用。你可以閱讀更多關於 [`use` 敘述][use-statements] 的說明。

## Unison 的標準函式庫

Unison 的標準函式庫叫做 `base`。如果你照著快速入門指南做，並且在本機建立了程式碼庫，標準函式庫應該已經自動下載好了。你可以在 [Unison Share][unison-share-base] 線上瀏覽標準函式庫的文件。

## 註解與說明文件字面值

註解在 Unison 中算是個有點特別的功能。撰寫 Unison 程式碼時，你可以在副檔名為 `.u` 的檔案裡，用以下語法建立不會被解讀的文字：

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

_不過_，Unison 程式碼是以抽象語法樹的雜湊值儲存，而不是檔案系統上的文字檔案。因此，那些用來「裝飾」檔案中某個 Unison 函式或詞項的文字註解，其實沒辦法被保存下來，也無法重新呈現給其他人看。如果你想為 Unison 詞項加上一些資訊，而且希望這些資訊能被保存下來、讓其他人閱讀和理解，你可以使用說明文件字面值。

說明文件在 Unison 程式語言中是一級值。這表示 `Doc` 元素可以被指定給值、以值的形式傳入函式，或作為函式的值回傳。說明文件字面值元素以雙大括號開啟和結束。以下是我們可能把 `Doc` 元素當成註解使用的方式。

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
