# 提示

## 1. 兩種說出一句台詞的方式

- `.upper`和`.lower`可以作用在整個字串上，不限於單一字元。
- `whisper`會在被轉成小寫的那行台詞前後接上`"..."`。

## 2. 排練一句台詞

- 引數型態寫成`ROUT{STR}:STR`，也就是把引數型態放在大括號裡，冒號後面則是答案。
- 主體只有一行：`return part.call(line);`
- `rehearse`不能提到`shout`或`whisper`。不知道正是取用綁定常式的重點。

## 3. 整場戲

- 一個迴圈和一個`FSTR`，就像`rehearsal-script`裡那樣。
- 對每一行呼叫`part.call(...)`，並在除了第一行以外的每一行前面加上`" "`。

## 4. 回傳一種說話的方式

- 回傳型態是`ROUT{STR}:STR`，就和任務 2 的引數型態一模一樣。
- 在類別裡使用`bind(shout(_))`，不需要類別名稱，就像任何從自己類別中呼叫的常式一樣。
- `return bind(...)`無法通過語法解析。`bind`必須先放在賦值的右邊：

  ```sather
     part : ROUT{STR}:STR;
     if ... then part := bind(shout(_)); else ... end;
     return part;
  ```

- 有兩種情況，所以要用`if`，或是帶`else`的`case`。

## 5. 固定一個引數

- `repeat`本身就是個普通的常式：一個迴圈、一個`FSTR`，以及`1.upto!(times)`。
- `doubler`會把它綁定起來，數字直接寫死，台詞則留成一個洞：`bind(repeat(2, _))`。和任務 4 一樣，把它放進變數再回傳那個變數。
- 只有`_`會成為綁定常式的引數，這就是為什麼`bind(repeat(2, _))`的型態是`ROUT{STR}:STR`，而不是`ROUT{INT,STR}:STR`。
