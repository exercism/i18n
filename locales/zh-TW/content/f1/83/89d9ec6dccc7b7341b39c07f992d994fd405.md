# 指令

一家繁忙的銀行依照*優先順序*服務等待的顧客，而不是依照他們抵達的順序。每位顧客在取號時會拿到一個優先順序號碼，而櫃員總是接著服務號碼最小的那位（`1` 最為急迫）。最小堆積就是最完美的等候隊伍。

## 1. 開啟佇列

定義 `new-queue`，不接受任何引數，並回傳一個全新的空優先佇列。

```factor
new-queue
! => an empty priority queue
```

## 2. 加入顧客

定義 `join-queue`，接受顧客名稱、優先順序號碼和一個佇列。它會把顧客加入佇列並回傳該佇列，因此可以一個接一個地加入顧客。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. 下一位是誰？

定義 `next-name`，接受一個佇列，回傳下一個應該被服務的顧客名稱，也就是優先順序號碼最小的那位，而且*不會*將這位顧客移除。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. 服務所有人

定義 `serve-all`，接受一個佇列，回傳所有等待中顧客的名稱，並依照他們會被服務的順序排列。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
