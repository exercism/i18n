# 指令

從前從前，有一座熱鬧繁華的城市，叫做 Cyberspace。
Cyberspace 是一座數位大都會，每天有數百萬名居民登入和登出。
為了追蹤所有這些使用者，Cyberspace 有一個特別的檔案，叫做 /etc/passwd。

/etc/passwd 檔案就像是這座城市的電話簿。
它列出了系統上每一個擁有帳號的使用者，以及每位使用者的一些重要資訊：

| n   | 欄位 |
| --- | --- |
| 1   | 使用者名稱 |
| 2   | 密碼（「x」表示基於安全考量，實際密碼儲存在別的地方）|
| 3   | UID，唯一的使用者數值 ID |
| 4   | GID，唯一的群組數值 ID（通常與 UID 相同）|
| 5   | 使用者資訊（通常是使用者的全名，但也可以包含其他資訊）|
| 6   | 家目錄 |
| 7   | 登入 shell |

這些欄位以冒號字元分隔。
以下是一個典型的條目：

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

這個檔案由一群系統管理員管理，他們負責建立新帳號、更新現有帳號，以及移除舊帳號。
系統管理員是 Cyberspace 的守門人，確保只有獲得授權的使用者才能存取系統。

有一天，團隊新聘了一位叫做 Alex 的系統管理員。
Alex 對接下這份工作感到很興奮，也很快就摸透了 /etc/passwd 檔案的來龍去脈。
他們學會了如何把新使用者加入系統、如何更新使用者資訊，以及如何移除舊使用者。

當 Alex 在處理 /etc/passwd 檔案時，他們注意到了一些奇怪的事。
有些使用者的家目錄很奇怪，或者不太尋常。
有些使用者的家目錄被設成 /dev/null，另一些使用者的家目錄則被設成根本不存在的奇怪路徑。

Alex 意識到這些使用者不是真人，而是駭客建立的假帳號。
駭客找到了利用系統漏洞的方法，並建立了這些假帳號來取得 Cyberspace 的存取權。

Alex 知道自己必須採取行動。
他們使用 awk 分析 /etc/passwd 檔案，並寫了一個指令碼來找出所有假帳號。
接著他們與團隊其他成員合作，移除這些帳號，並修補當初讓駭客得以建立這些帳號的漏洞。

多虧 Alex 使用了 awk，團隊才能找出並移除這些假帳號，讓 Cyberspace 成為對所有人來說更安全的地方。
系統管理員持續管理 /etc/passwd 檔案，讓它保持最新且安全，並確保只有獲得授權的使用者才能存取系統。

現在，輪到你來當像 Alex 一樣的系統管理員了。

## 1. 列出使用者名稱

寫一個 awk 程式，印出 passwd 檔案中每一行以冒號分隔的第一個欄位。

## 2. 印出行號

寫一個 awk 指令，印出輸入檔案中每一筆紀錄的行號。
只印出行號，不要印出其他資訊。

## 3. 印出家目錄無效的紀錄。

在 Cyberspace 中，「有效」的家目錄會以`/home`或`/root`開頭。
印出輸入檔案中家目錄**無效**的紀錄。

## 4. 印出使用 bash 的有效使用者

印出家目錄有效**且**登入 shell 是`bash`的紀錄。
