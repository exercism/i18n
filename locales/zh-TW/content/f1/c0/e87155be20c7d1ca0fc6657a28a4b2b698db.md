# 關於

[Java](https://go.java/index.html) 是最受歡迎的程式語言之一，這要歸功於它的多功能性與相容性。
它被廣泛用於軟體開發、行動應用程式，以及開發更大型的系統。

Java 誕生於 1995 年，目前由 [Oracle](https://www.oracle.com/index.html) 維護。
儘管它不像市面上一些新興語言那麼年輕，Java 依然非常受歡迎。
它的設計目標是快速、安全、可靠、對初學者友善，而且高度可攜。
這種可攜性之所以存在，是因為 Java 是在跨平台相容的 [Java 虛擬機器（JVM）](https://en.wikipedia.org/wiki/Java_virtual_machine) 上執行的。
Android 應用程式同樣是用 Java 開發的，因為 [Android 作業系統](<https://en.wikipedia.org/wiki/Android_(operating_system)>) 執行在 Java 語言環境上。

Java 社群非常龐大！
舉例來說，GitHub 上就有超過 150 萬個 Java 專案。
另外值得一提的是，Java 在 [StackOverflow](https://stackoverflow.com/questions/tagged/java) 上是第二大的社群！
這一點很重要，因為程式語言的社群越大，你越可能獲得更多支援。

Java 也內建了一套強大且設計良好的 [API（應用程式介面）](https://docs.oracle.com/en/java/javase/11/docs/api/index.html)，可用於各種用途，例如資料庫連線、網路、I/O、XML 解析、工具程式等等。

從筆記型電腦到資料中心，從遊戲主機到科學超級電腦，從手機到網際網路，[Java 無所不在](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)！
