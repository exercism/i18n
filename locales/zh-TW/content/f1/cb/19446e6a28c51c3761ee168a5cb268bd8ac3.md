# 簡介

和許多其他程式語言不同，JavaScript 裡有兩個不同的實體用來表示「沒有（有意義的）值」。
它們是`null`和`undefined`。

## Null

原始型別的值`null`用來當作任何型別變數刻意設定的「空值」。

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

你可以使用[嚴格相等運算子][mdn-strict-equality]`===`來檢查變數是否為 null。

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> 尚未被指定值的變數，其型別為`undefined`。[^1]

這表示`null`代表的是一個空值（但仍然是一個值），而`undefined`代表的是完全沒有值。🤯

`undefined`會出現在不同的情境中。

- 如果變數在宣告時沒有給值（初始化），它就是`undefined`。

  ```js
  let name;
  console.log(name); // => undefined
  ```

- 如果你試著存取物件中不存在的鍵，會得到`undefined`。

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- 如果函式沒有回傳值，結果就是`undefined`。

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- 如果呼叫函式時沒有傳入引數，該引數就是`undefined`，除非這個引數有預設值。

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

你可以使用嚴格相等運算子`===`來檢查變數是否為 undefined。

```javascript
let name;

name === undefined;
// => true
```

## 選擇性串接

如果你想取得物件中巢狀的值，但上層的鍵不存在，JavaScript 會拋出錯誤。
為了輕鬆避免這種情況，2020 年時，語言規格中加入了選擇性串接。
使用選擇性串接運算子`?.`，你可以確保只有在上層不是`null`或`undefined`時，JavaScript 才會試著存取巢狀的鍵。
否則會回傳`undefined`。

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## 空值合併

有些情況下，你會想在變數是 null 或 undefined 時套用預設值（而且只有在這種時候）。
為了解決這個問題，2020 年時導入了空值合併運算子`??`。
只有當左側運算元是`null`或`undefined`時，它才會回傳右側運算元。
否則會回傳左側運算元。

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
