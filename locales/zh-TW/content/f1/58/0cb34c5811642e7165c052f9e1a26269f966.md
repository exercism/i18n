### 簡介

歡迎來到 Java 賽道的第一個練習！

這份文件會一步步帶你解決這個練習。
這些說明在 Windows、macOS 和 Linux 上都能適用。

即使你已經熟悉 Java 的基礎，跟著這份指南走一遍還是很有幫助，因為它能幫你了解我們用來編譯與測試程式的工具 Gradle 所產生的輸出，也會介紹這個賽道中所有練習共通的幾種模式。

### 練習結構

當你取得一個新的 Java 練習時，會收到：

- __一個或多個測試檔案__（一定有）。
這些檔案位於`src/test/java`目錄中，定義了一組測試，我們的解答必須先通過這些測試，才能確定它真的能正常運作。
- __一個或多個起始檔案__（初次取得時會提供）。
如果有提供，這些檔案位於`src/main/java`目錄中，裡面定義了你解決目前問題所需的類別骨架。

### 解決「Hello, World!」

你可以使用我們的線上編輯器來撰寫解答並執行測試；如果你想在本機解題並執行測試，請參考下列連結：

- [安裝 Java][Installing Java]
- [在本機工作][Working Locally]
- [在 Java 賽道本機測試][Testing locally on the java track]

### 步驟 1：修正解答

無論你是在本機工作，還是使用線上編輯器，都應該會看到下面這段程式碼：

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

目標是修改提供的程式碼，讓它產生`"Hello, World!"`這段文字，而不是`"Goodbye, Mars!"`。

### 步驟 2：執行測試

修正並完成解答之後，再執行一次測試。
你可以使用線上編輯器執行測試，也可以在自己的電腦上本機執行：

- 若要在線上編輯器中執行測試，請點擊「Run Tests」按鈕。
- 若要在本機執行測試，請參考[在 Java 賽道測試][Testing locally on the java track]如果測試失敗也沒關係！看看錯誤訊息在告訴你什麼，修改程式碼後再測一次，等到測試通過，就可以前往下一步了。

### 步驟 3：提交你的第一個疊代

現在你已經有一份能正常運作、也檢查過的解答，可以把它提交到 exercism.org 了。
你可以使用線上編輯器提交解答，也可以在本機透過 [Exercism CLI][Working Locally] 提交：

- 若要在本機提交練習，請先[安裝 exercism CLI][Working Locally]（如果還沒安裝的話），然後提交你解答的檔案，例如：

  ```sh
  exercism submit <file location>
  ```

- 把`<file location>`替換成你的`Greeter.java`檔案所在的相對位置；舉例來說，如果你的工作目錄是`C:\exercism\java\hello-world`，那麼指令就是

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- 如果你想用線上編輯器提交解答，只要點擊「Submit」按鈕就行了！

想更深入了解如何在本機提交解答：

- [在本機提交][Working Locally]

### 成為導師

Exercism 的核心，就是那些關於程式設計實務的對話。
自己埋頭練習固然有趣，但只有和他人交流，無論是討論別人的嘗試還是你自己的，才能得到回饋。
這些回饋可以指出你做得好的地方，以及你可能需要改進的地方。

有些提交的內容會和你的幾乎一模一樣，有些則完全不同。
看看這兩種類型，都很有啟發性，也很有趣。

導師會審閱他們所選賽道中提交的解答，盡可能幫助使用者學到最多。

想進一步了解引導的相關內容，請參閱 [Exercism 文件][Mentoring]。
