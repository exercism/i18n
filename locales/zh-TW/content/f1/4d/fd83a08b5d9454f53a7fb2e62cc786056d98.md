# 提示

## 一般

- 用一行`SYMBOLS:`宣告四個基本方位符號和四個相對方位符號：`SYMBOLS: north east south west ahead starboard behind port ;`
- 每個元組都用`TUPLE: <class> <slot1> <slot2> ;`宣告。
- 一行`GENERIC:`會宣告這個詞；每一行`M:`則為一個類別新增一個方法。如果你想在方法主體裡使用具名區域變數，就用`M::`。

## 1. `>cartesian` 用於基本方位

- 用一個簡單的`case`處理四個方位符號就夠了。
- `{ north [ 0 1 ] }`，主體只是把兩個值推入堆疊；測試預期`x`在堆疊上位於`y`的下方。

## 2. `>cartesian` 用於極座標

- 把度數轉成弧度：`bearing pi * 180 /`。
- `sin`和`cos`都在`math.functions`裡。
- 先推入`magnitude * sin(rad)`，再推入`magnitude * cos(rad)`。

## 3. `>cartesian` 用於相對方位

- 宣告一個動態變數：`SYMBOL: heading`。
- 在方法中用`heading get`讀取它。
- 用`case`把`ahead/starboard/behind/port`對應到`0/90/180/270`的偏移量，然後加上 heading。接下來就和任務 2 一樣是極座標轉換，可以考慮抽出一個輔助詞：`: deg>cartesian ( magnitude bearing -- x y ) ... ;`。

## 4. `flip`

- 對`cardinal`呼叫`change-direction`，對`polar`或`relative`呼叫`change-bearing`，都會建立一個只改了一個槽位的新元組，其餘的保持不變：`[ <transformation-quotation> ] change-bearing`。
- 至於`polar`的旋轉：`[ 180 + 360 mod ] change-bearing`。

## 5. `add-bearings`

- 對每個輸入呼叫`>cartesian`，然後把 x 分量相加、把 y 分量相加。使用區域變數可以讓這段更好讀：
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
