# 關於

如果想依照條件執行程式碼，可以使用[`if/elif/else` 運算式][conditional-expression]。`if/elif/else` 運算式中使用的條件必須是`bool`型別。F# 沒有 _truthy_ 值這樣的概念。

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

由於 `if/elif/else` 是運算式，因此可以將它綁定到一個名稱，或是從函式中回傳。

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

所有分支都必須回傳相同的型別。如果沒有這麼做，就會產生編譯器錯誤：

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

只有在回傳的運算式型別為[`unit`][unit-type]時，`else` 和 `elif` 分支才是選用的。

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

`if/else` 運算式也可以寫成一行。不過這只適用於簡單的 `if` 運算式。

```fsharp
let y = if x > 5 then 10 else 20
```
