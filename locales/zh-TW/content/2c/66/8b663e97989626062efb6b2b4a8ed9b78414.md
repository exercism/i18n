# 說明

你正在開發一套系統，協助某個足球俱樂部網站的工作人員報導比賽。資料會從各種來源接收，經過清理後匯入單一串流。

## 1. 根據球衣號碼輸出球員的描述

這支球隊只踢 4-3-3 陣型，也從未同意 1965 年那項允許替補的規則變更，更別說擴編球員名單了。

球員的描述如下：

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

請實作靜態方法`FootballMatchReports.onField()`，根據球衣號碼輸出球員的描述。

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. 若球衣號碼不在官方名單中，就輸出 "invalid"

請修改`FootballMatchReports.onField()`方法，讓它在處理 1-11 範圍之外的球衣號碼時回傳 'invalid'。

```java
FootballMatchReports.onField(13);
// => "invalid"
```
