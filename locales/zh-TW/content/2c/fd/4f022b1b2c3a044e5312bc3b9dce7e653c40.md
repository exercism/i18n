# 任務

任務是一些 GitHub issue，我們希望有人能一起協助處理，範圍從校對文字到建立概念練習都有。
這些任務會顯示在網站上，並連到 GitHub 上對應的 issue。
每個任務都會標上一或多個屬性，這些屬性取自該 issue 的標籤。
使用者接著就能依照這些屬性來篩選任務。

## 標籤

一個 issue 必須被標上一或多個任務專用標籤，才會被視為任務。
因此維護者可以選擇只讓部分 issue 顯示為任務。

每個任務標籤的格式為：`x:<type>/<value>`，目前支援五種任務類型：

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Action 標籤

`x:action/<value>` 標籤描述貢獻者在處理這個 issue 時，會從事哪一類工作。

| 標籤                 | 說明                     |
| -------------------- | ------------------------ |
| `x:action/create`    | 從零開始打造某個東西     |
| `x:action/fix`       | 修正問題                 |
| `x:action/improve`   | 改善現有功能或內容       |
| `x:action/proofread` | 校對文字                 |
| `x:action/sync`      | 將內容與最新版本同步     |

### Knowledge 標籤

`x:knowledge/<value>` 標籤描述貢獻者需要具備多少 Exercism 相關知識。

| 標籤                       | 說明                           |
| -------------------------- | ------------------------------ |
| `x:knowledge/none`         | 不需要任何 Exercism 相關知識   |
| `x:knowledge/elementary`   | 需要少量 Exercism 相關知識     |
| `x:knowledge/intermediate` | 需要相當多的 Exercism 相關知識 |
| `x:knowledge/advanced`     | 需要全面的 Exercism 相關知識   |

### Module 標籤

`x:module/<value>` 標籤指出貢獻者會參與 Exercism 的哪個部分。

| 標籤                         | 說明                 |
| ---------------------------- | -------------------- |
| `x:module/analyzer`          | 分析器相關工作       |
| `x:module/concept`           | 概念相關工作         |
| `x:module/concept-exercise`  | 概念練習相關工作     |
| `x:module/generator`         | 練習產生器相關工作   |
| `x:module/practice-exercise` | 練習題相關工作       |
| `x:module/representer`       | 表示器相關工作       |
| `x:module/test-runner`       | 測試執行器相關工作   |

### Size 標籤

`x:size/<value>` 標籤描述貢獻者預期要投入多少工作量。

| 標籤             | 說明           |
| ---------------- | -------------- |
| `x:size/tiny`    | 極少的工作量   |
| `x:size/small`   | 少量工作       |
| `x:size/medium`  | 中等工作量     |
| `x:size/large`   | 大量工作       |
| `x:size/massive` | 極大量的工作   |

### Type 標籤

`x:type/<value>` 標籤描述貢獻者會從事哪一類工作。

| 標籤             | 說明                                                                                                                                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | 持續整合相關工作（例如 GitHub Actions 工作流）                                                                                                                                                              |
| `x:type/coding`  | 撰寫不屬於學員導向內容的程式碼。這通常是與正式環境工具（例如測試執行器）、內部工具（產生器），或 Exercism 維護的程式庫有關的任務。                                                                          |
| `x:type/content` | 內容相關工作（例如練習、概念）                                                                                                                                                                              |
| `x:type/docker`  | Dockerfile 相關工作                                                                                                                                                                                         |
| `x:type/docs`    | 文件相關工作                                                                                                                                                                                                |

## 已認領與未認領的標籤

如果已經有人在處理某個任務，而想把它藏起來，可以在該 issue 加上 `x:status/claimed` 標籤。
