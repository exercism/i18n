# 提示

## 1. 產生座位字母

- 回傳值的_型別_應該是`generator`。
- 你可以準備一串從`A`到`D`的字母，然後讓它們循環。
- 使用`yield`回傳下一個字母。

## 2. 產生座位

- 回傳值的_型別_應該是`generator`。
- 應該跳過第`13`排，所以從`12`到`14`。
- 請記住，回傳的值應該由小到大排序。`1A, 1B, 2A, ...`
- 在這裡，重複使用或呼叫你已經定義好的函式可能是個好做法。

## 3. 將座位分配給乘客

- 請確認你的座位號碼中沒有包含任何空格。
- 在這裡，重複使用或呼叫你已經定義好的函式可能是個好做法。

## 4. 票券代碼

- 你可以使用`len()`取得字串的長度。
- 你可以使用`"<string>" * <int>`來重複字串。
