# 安裝

我們提供了[預先編譯好的 Uiua 二進位檔][releases]，所以不需要自己編譯。
最新的安裝說明請見[官方安裝指南][install-guide]，內容也涵蓋 IDE 整合與字型的設定。

```exercism/note
目前我們的線上測試執行器使用的是`0.18.1`版。
由於 Uiua 的開發步調很快，這個版本隨時可能變動，所以如果你無法重現網站上的測試結果，請把這點放在心上。
```

下載到你想要的位置之後，你需要把 Uiua 加入系統的 PATH。

- **macOS：** 用 Finder 開啟`Applications > Utilities > Terminal`。輸入`export PATH="/path/to/uiua:$PATH"`，就能從任何位置執行 Uiua。

- **Windows：** 從開始選單開啟「Edit Environment Variables」。在「Path」中，加入你的 Uiua 資料夾。

- **Linux：** 開啟終端機，並把`export PATH="/path/to/uiua:$PATH"`加到`~/.bashrc`或`~/.profile`，方便之後取用。
