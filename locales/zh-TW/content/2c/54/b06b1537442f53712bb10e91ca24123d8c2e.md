# 說明

在這個練習中，你需要實作經典遊戲 Pac-Man 的幾個規則。

你有四個規則要實作，全都和遊戲狀態有關。

## 1. 定義 Pac-Man 是否會吃掉幽靈

實作一個函式，接收 Pac-Man 是否有作用中的能量球，以及 Pac-Man 是否正接觸幽靈，並回傳布林值，表示 Pac-Man 是否能吃掉幽靈。只有在 Pac-Man 有作用中的能量球且正接觸幽靈時，這個函式才應該回傳`true`。

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. 定義 Pac-Man 是否得分

實作一個函式，接收 Pac-Man 是否正接觸能量球，以及 Pac-Man 是否正接觸豆子，並回傳布林值，表示 Pac-Man 是否得分。如果 Pac-Man 正接觸能量球或豆子，這個函式應該回傳`true`。

```lua
rules.score(true, true)
-- => true
```

## 3. 定義 Pac-Man 是否輸掉

實作一個函式，接收 Pac-Man 是否有作用中的能量球，以及 Pac-Man 是否正接觸幽靈，並回傳布林值，表示 Pac-Man 是否輸掉。如果 Pac-Man 正接觸幽靈，且沒有作用中的能量球，這個函式應該回傳`true`。

```lua
rules.lose(false, true)
-- => true
```

## 4. 定義 Pac-Man 是否獲勝

實作一個函式，接收 Pac-Man 是否已經吃掉所有豆子、Pac-Man 是否有作用中的能量球，以及 Pac-Man 是否正接觸幽靈，並回傳布林值，表示 Pac-Man 是否獲勝。如果 Pac-Man 已經吃掉所有豆子，且根據第 3 部分定義的引數判斷並沒有輸掉，這個函式應該回傳`true`。

```lua
rules.win(false, true, false)
-- => false
```
