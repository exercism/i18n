# 關於

## 布林值

PowerShell 有[`bool`][booleans]型別，用來表示 true 和 false 值。這個型別只有兩個值：`True`和`False`。你可以用`$`前綴把這些值繫結到變數：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

我們可以用[邏輯運算子][logical-operators]，例如`-and`、`-or`、`-not`，來組合並評估布林運算式。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## 轉換與真值性

PowerShell 可以把任何型別隱含地視為布林值。不過你也可以使用布林型別加速器`[bool]`來進行明確轉換。

以下是 PowerShell 把其他型別轉換成布林值時使用的一些通用規則：

$false:
- 空字串，例如`''`或`""`
- Null 值，例如`$null`
- 值為零（0）的數值型別

$true:
- 非空字串
- 任何其他非集合型別的執行個體

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

關於從集合型別轉換布林值的深入規則，請閱讀[這裡][collection-conversion]。
