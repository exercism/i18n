# 補充指示

## 例外訊息

有時候，你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓你的程式碼更容易閱讀，也對除錯大有幫助。如果已知錯誤來源會是某種型別，你可以選擇引發[內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)之一，但仍應附上有意義的訊息。

這個練習要求你在`convert()`函式收到不是有效 OCR 數字的字串時，使用[raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「拋出」`ValueError`。只有同時`raise`該`exception`並附上訊息時，測試才會通過。

若要引發帶有訊息的`ValueError`，請把訊息寫成`exception`型別的引數：

```python
# when the rows aren't multiples of 4
raise ValueError("Number of input lines is not a multiple of four")

# when the columns aren't multiples of 3
raise ValueError("Number of input columns is not a multiple of three")
```
