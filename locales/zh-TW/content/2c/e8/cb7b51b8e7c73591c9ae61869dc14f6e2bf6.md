# 簡介

Julia 鼓勵程式設計師盡可能把程式碼放進可經 JIT 編譯的函式裡；而建立許多小型函式，在設計上本來就有良好的效能。

這樣一來，往往會留下許多小而簡單的函式；要完成較複雜的工作時，就得把它們組合起來。

其中一個顯而易見的做法是巢狀呼叫函式。下面這個例子非常刻意，但足以說明重點。

```julia-repl
julia> first.(titlecase.(reverse.(["my", "test", "strings"])))
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

這種做法的缺點是，巢狀層級一深，可讀性就迅速下降。

我們需要更簡單、更有彈性的做法。

## 合成

這是數學家鍾愛的技巧，而 Julia 也沿用了數學的語法。

任意數量的函式都能用`∘`運算子合成在一起（[`composed`][comp]，輸入方式為先輸入`\circ`再按 Tab）。結果可以當作單一個函式使用。

```julia-repl
julia> compfunc = first ∘ titlecase ∘ reverse
first ∘ titlecase ∘ reverse
julia> compfunc.(["my", "test", "strings"])
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
# alternative syntax, giving the same result
julia> (first ∘ titlecase ∘ reverse).(["my", "test", "strings"])
```

有幾點值得注意：

- 起始的函式排列順序和巢狀寫法相同，執行時則是由右至左。
- 合成時使用廣播並不簡單，但可以在呼叫合成後的函式時套用廣播。

## 管線

另一種做法不妨想成是_程式設計師_的取向，而不是_數學家_的取向。

`Pipelines`長久以來被用在 Unix shell 腳本裡，近年也在主流程式語言中流行起來（F# 有時被認為是率先採用這種做法的先驅）。

基本概念是先有一份資料，接著讓它通過一連串函式，最後得到結果。

管線運算子寫成`|>`（F# 和近期版本的 R 也是如此），不過 Julia 另外還有廣播版本`.|>`。

```julia-repl
julia> ["my", "test", "strings"] .|> reverse .|> titlecase .|> first
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

現在執行順序嚴格地由左至右，每個函式的輸出會順著箭頭的方向流動，成為下一個函式的輸入。

## 限制、變通做法與其他選項

用來示範合成與管線的函式全都只接受_單一_引數，這絕非巧合。

有些純函式語言會把_第一個_引數送進函式，但允許同時帶入其他引數。

相對地，Julia 在管線中只接受函式_名稱_（或等效的東西），不能附帶其他引數。

這麼做有重要的技術理由（與`currying`並非這門語言設計的標準環節有關）。
不瞭解 currying 的_眾多_讀者，只要接受這個限制並非粗心大意造成的疏漏，而且未來版本的 Julia 也不太可能改變就好。

### 變通做法

我們需要只接受單一引數、又能完成所需工作的函式。幸好，在 Julia 裡定義新函式很簡單。

最簡單的做法是使用[`anonymous function`][anonymous-function]。舉例來說，如果我們有一個輸入字串，想用底線把它切開：

```julia-repl
julia> "my_test_strings" |> (s -> split(s, '_'))
3-element Vector{SubString{String}}:
 "my"
 "test"
 "strings"
```

接著就能像先前一樣，把這個向量送進其他函式。

在這個情況下，把匿名函式用括號括起來並非必要，但一般來說，這是減少歧義的實用做法。

同樣地，我們也可以在程式中較早的位置建立具名函式，需要時再重複使用。
