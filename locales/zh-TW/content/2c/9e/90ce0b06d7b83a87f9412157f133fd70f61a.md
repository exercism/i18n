# `case`敘述

當一個值要和一系列可能的值比較時，一串`elsif`會反覆表達同樣的內容：

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case`只要寫一次：

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

值放在`case`後面。每個`when`提供一個用來比較的值，第一個符合的就會執行。

## 一個`when`裡可以放多個值

一個`when`可以列出多個值，用逗號分隔：

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

這適用於整數、字元和字串，也就是任何能用`=`比較的東西。

## `else`不是可有可無的

**一個沒有符合任何項目、又沒有`else`的`case`，是一種錯誤；一旦發生，程式就會停止。**

這和`if`不同：在`if`裡省略`else`只代表什麼都不會發生。這也和大多數程式語言不同，在那些語言裡，沒有符合項目的`case`會默默什麼都不做。

所以每個`case`都需要一個`else`，即使你很確定`when`的部分已經涵蓋了所有可能的值。之後新增了第四個 zone，`case`卻沒有跟著更新，程式就會在第一個用到它的乘客身上停下來。

## 只有一個`when`會執行

當某個`when`符合時，它`then`後面的敘述會執行，這個`case`就結束了，程式會從`end`之後繼續進行。它下面的`when`部分根本不會被查看，所以你不需要寫任何東西來阻止下一個也跟著執行。
