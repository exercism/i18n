# 說明

在這份練習中，你會撰寫程式碼，處理一份你打算在 Exercism 平台上練習的程式語言陣列。

這個練習有六個任務。

## 1. 建立新陣列

在新增語言之前，你需要先建立一個新的陣列。定義一個會回傳空陣列的函式。

```clojure
(new-list)
;; => ()
```

## 2. 新增語言到陣列中

當你探索 Exercism 並找到想學習的語言時，你需要能把它們加進陣列。定義一個函式，將新的語言新增到陣列開頭。

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. 檢查最後新增的語言

你會想快速檢查自己剛才新增了哪個語言。定義一個函式，回傳陣列中的第一個語言。

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. 從陣列中移除第一個語言

有時候你會改變心意，不想用剛才新增的語言。定義一個函式，從陣列中移除第一個語言。

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. 計算陣列中的語言數量

一個一個數語言很不方便。定義一個函式來計算陣列中的語言數量。

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. 整合全部功能

定義一個`learning-list`函式，並在其中使用前面定義過的幾個函式。

- 建立一個空陣列
- 新增 2 個程式語言到陣列中。

  - "Clojure"
  - "Lisp"

- 從陣列中移除 "Lisp"，因為你今年可能沒那麼多時間，而且它和 Clojure 相當類似。
- 再新增 2 個程式語言到陣列中。

  - "Java"
  - "JavaScript"

- 回傳語言的總數。提示：結果應該是 3。

```clojure
(learning-list)
;; => 3
```
