# 關於

Nim 是一門通用程式語言，由 Andreas Rumpf 設計與開發，並於 2008 年首次問世。
它的設計目標是高效、表達力強且優雅。
Nim 是靜態型別的編譯式語言，卻能讓你寫出優雅且執行效率高的程式碼。
Nim 讓你能把程式碼編譯成 C、C++、JavaScript 或 Objective-C，藉此針對許多不同的平台。
Nim 的語法和 Python 相似，也承襲了 Python 的許多特色，但同時從 C、C++、C#、Lisp、Ada、Go、Oberon 等許多語言汲取靈感。

由於 Nim 是通用程式語言，它可以用在各種場合，但真正填補空缺的領域是遊戲開發與系統程式設計，其中也包含嵌入式系統。

Nim 帶給你許多在 Python 及其他語言裡看得到的便利，例如容易閱讀的語法、讓你在專案中使用新函式庫的套件管理系統，以及除錯時對使用者友善的錯誤追蹤訊息。

Nim 帶給你 C 的速度與可攜性，同時具備高效能的垃圾回收器與優雅的語法，讓這門語言對新手非常平易近人。
Nim 也把掌控權交給你，讓你能更換垃圾回收器，或將它完全關閉，自己管理記憶體。
使用 Nim，你擁有多樣的程式設計範式與抽象層可以選擇。
