# 測試

用以下指令執行測試：

```shell
corepack pnpm test
```

請確保你的程式碼遵循最佳實踐和程式碼風格，和其他使用者一樣，使用 ESLint，這是一個能對你的程式碼進行靜態分析的工具。有時候，這類工具能幫你省下一些時間，及早找出 JavaScript 程式碼中的錯字或愚蠢的錯誤：

```shell
corepack pnpm lint
```

你也可以用「watch」模式執行 Jest，這樣當你儲存程式碼或測試模組的變更時，它會自動重新執行你的測試：

```shell
corepack pnpm watch
```

## 了解略過的測試

略過方法會指示測試套件不要執行某個測試，這個函式也可以透過以下別名使用：`it.skip(name, fn)`、`xit(name, fn)` 或 `xtest(name, fn)`

- 為什麼要略過它們？

為了讓使用者能一次專注在一個測試上，並隨著解法的演進逐一啟用它們。

- 如何啟用它們？

把 `xtest` 改成 `test`。

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## 建立你的第一個 JavaScript 2015 模組

一般來說，這個學習軌道上的測試會把你的實作當作 JavaScript 模組匯入來載入它：`import { Bob } from './bob.js';`。
你只需要從被引用的檔案`bob.js`匯出你的實作：

```javascript
export function hey(message) {}
```

你可以在 [Babel 文件](https://babeljs.io/docs/learn-es2015/#modules) 中找到更多關於模組的資訊。
為了讓你更容易上手，目錄中有一個_骨架_JavaScript 檔案。
