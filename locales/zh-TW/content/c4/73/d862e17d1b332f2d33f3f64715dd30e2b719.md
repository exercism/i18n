# 關於

當型別無法隱含轉型時，就必須使用明確的轉型[運算子][cast-operator]。
轉型運算子其實就是放在要轉型的值前面、用括號包住的目標型別：

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

使用明確轉型可能會有危險。最常見的兩種錯誤是：

- 轉型成不相容的型別。這會在執行階段擲回例外。
- 轉型成寬度不足的數值。以整數來說，這可能導致正負號衝突，或是擲回溢位例外。

注意：型別為`int`的運算式可以明確轉型成`char`。這可能產生無效的`char`。

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
