# 關於

Gleam 不使用例外來處理錯誤，而是由可能成功或失敗的函式回傳通用的 `Result` 型別。

`Result` 型別是語言內建的，因此不需要定義或匯入，但如果你自己定義，會長這樣：

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

當函式成功時會回傳 `Ok` 變體，失敗時則回傳 `Error` 變體。

Result 在 Gleam 中非常常見，Gleam 開發者通常會使用 [`gleam/result` 模組](https://hexdocs.pm/gleam_stdlib/gleam/result.html) 來讓操作這些值更輕鬆。

`result.map` 函式可以用來對 result 內的值呼叫函式（如果它是 `Ok`），或原樣傳遞 `Error`。

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try` 函式類似，但回呼函式預期要回傳一個 result。這在串接多個會回傳 result 的函式時很有用。

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
