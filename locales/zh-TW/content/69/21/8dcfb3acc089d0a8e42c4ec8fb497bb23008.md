# 簡介

## 命名空間

組織程式碼的一個重要方法是使用命名空間。兩個函式可能發生命名衝突，這時可以把它們放進不同的命名空間來解決。命名空間可以巢狀，這有助於組織龐大的程式碼庫。要存取命名空間，可以使用作用域解析運算子`::`。

下面這個範例展示了兩個不同的`foo`函式。只要加上各自的命名空間前綴，就能把它們放在一起使用。

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
