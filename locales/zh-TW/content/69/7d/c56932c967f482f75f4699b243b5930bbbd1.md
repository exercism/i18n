# 控制流程

`if`運算式和迴圈以下列方式控制 Cairo 中的執行流程：
`

- **`if`運算式**會根據條件是否評估為`true`來決定是否執行某段程式碼。
- **迴圈**（例如`loop`、`while`和`for`）會在指定條件持續成立時重複執行程式碼，直到觸發中斷條件為止。

這些結構是在 Cairo 中實作邏輯與疊代的基礎。

## `if`運算式

Cairo 的`if`運算式讓你根據條件邏輯來控制執行流程。它的結構會依照布林條件的評估結果是`true`還是`false`，來決定要執行哪些程式碼。

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

這個範例示範了 Cairo 中一個簡單的`if`區塊。只有在條件`temperature > 25`評估為`true`時，才會印出訊息`"It's hot outside!"`。如果條件為`false`，就不會執行任何程式碼，程式會繼續往下執行。

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

執行這段程式碼會在主控台印出`"The number is less than 10."`。

### 用`else if`處理多個條件

你可以把`if`和`else`組合成`else if`運算式，來處理多個條件。

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

執行這段程式碼會在主控台印出`"Grade: B"`。

### 在`let`敘述中使用`if`

Cairo 的`if`運算式可以放在`let`敘述的右邊，把結果指定給變數。

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## 迴圈

迴圈是一種基本結構，能重複執行程式碼區塊，讓工作有效率且受控地執行。迴圈可以逐一走訪序列，或根據條件重複執行程式碼。Cairo 提供三種主要的迴圈形式：

- **loop**：基本的迴圈，會無限執行，除非你用`break`敘述明確將它停下。
- **while**：只要指定條件維持`true`就會繼續執行，當條件變成`false`時停止。
- **for**：逐一走訪集合（例如陣列）中的元素，為每個元素執行程式碼。

### 用`loop`重複執行程式碼

`loop`關鍵字會告訴 Cairo 不斷重複執行某個程式碼區塊，直到你明確要求它停止。

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

執行這段程式碼會在程式的 gas 用完、或我們手動將它停止之前，於主控台不斷印出`"again!"`。

> 注意：Cairo 內建 gas 計量器，避免我們執行含有無限迴圈的程式。
> gas 計量器是一種機制，用來限制一個程式可以完成的計算量。
> gas 是一種計量單位，用來表示一道指令的運算成本。
> 當 gas 計量器用完時，程式就會停止。

若要跳出迴圈，請在迴圈中放置`break`關鍵字，告訴程式何時停止執行。

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

`continue`關鍵字會告訴程式進入迴圈的下一次疊代，並略過這次疊代中剩下的程式碼。

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

執行這個程式時，當`i`等於`5`，不會印出`i`的值。

#### 從`loop`回傳值

你可以使用`break`關鍵字，後面接著想回傳的值，從`loop`回傳一個值。這樣就能離開`loop`，並把結果交給程式其餘的部分。

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### 用`while`做條件式迴圈

`while`會在條件為`true`時執行程式碼，並在條件變成`false`時結束。

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### 用`for`走訪集合

`for`會逐一走訪集合中的每個項目，為每個項目執行程式碼。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
