# 簡介

## 元組

在 Elixir 中，元組是一種組織資料的資料結構，可以存放任意型別、固定數量的項目，但每個元素都沒有明確的名稱。在 Elixir 中，元組常用於記憶體讀取密集的操作，因為讀取元素是常數時間的操作。當元素需要動態新增或移除時，通常不會使用元組，因為它不會修改既有的元組，而是建立一個新的元組，這需要事先配置記憶體。

實際上，在 Elixir 中是用大括號建立元組。元組中的元素可以用`elem/2`函式個別存取，索引從 0 開始：

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### 以元組表示群組資訊

實際上，元組經常被用來表示群組化的資訊。

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## 模式比對

在斷言式、慣用的 Elixir 程式碼中，模式比對的使用非常普遍。你可能還記得，`=/2`被描述為比對運算子，而不是指定運算子。使用比對運算子時，如果左側的模式與右側相符，左側的任何變數都會被綁定，並回傳右側的值。如果沒有比對成功，就會引發`MatchError`。

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

記住，比對是從右側往左側進行。

在上一個範例中，如果模式比對裡不需要某個變數，我們可以用`_`來捨棄它。任何以`_`開頭的變數都不會被執行環境追蹤。

### 具名函式中的模式比對

在建立多個函式子句時，模式比對也是很有用的工具。模式比對可以用在函式的引數上，藉此決定要呼叫哪個函式子句，從檔案最上方開始往下，直到第一個比對成功為止。變數可以在函式標頭中綁定，並在函式主體中使用。

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
