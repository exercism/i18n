# 安裝

你需要 Node Package Manager (npm) 才能安裝 Reason。請依照[這裡](https://www.npmjs.com/get-npm)的指示。

安裝 npm 之後，請用以下指令安裝 Reason：
```
npm install -g bs-platform
```

Reason 能與多種編輯器整合，請參閱[這裡](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)。

一些命令列工具（包括讓你在 shell 中對 Reason 運算式求值的 REPL）可以在[這裡](https://github.com/reasonml/reason-cli)找到。
