# 關於 `for` 迴圈

[`for` 迴圈](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) 提供了一種機制，可以重複執行一組敘述，直到符合某個條件為止。
迴圈由四個部分組成：

```java
for (initialization; test; update) {
    body;
}
```

`initialization` 會設定迴圈的初始狀態，並且在迴圈開始時只執行一次。
通常它會宣告並指定一個變數，供 test 運算式與 update 敘述使用。
例如：

```java
int i = 1
```

`test` 運算式會測試迴圈是否應該結束。
如果它的求值結果是 true，就會執行迴圈主體，接著執行 update 運算式。
如果是 false，則迴圈主體與 update 敘述都不會被執行，程式會從迴圈的右大括號之後繼續執行。
通常它會檢查在 initialization 區塊中指定的變數。
例如：

```java
i <= 10
```

執行完迴圈主體之後，就會執行 `update` 運算式。
通常它會將迴圈變數增加或減少某個值。
例如：

```java
i++
```

一個印出前四個平方數的 `for` 迴圈會長這樣：

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

如果要疊代集合中的每個元素，建議使用 `for-each` 迴圈，不過也可以用 `for` 迴圈這樣寫：

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

相較於 `for-each` 迴圈，`for` 迴圈確實有一些優點：

- 你可以從想要的索引開始，也可以在想要的索引停止。
- 你可以使用任何想要的（布林）結束條件。
- 你可以自訂迴圈變數的遞增方式來跳過某些元素。
- 你可以用倒數的方式，從後往前處理集合。
- 你可以在不涉及集合的情境中使用 `for` 迴圈。
