# 簡介

Julia 是一門通用程式語言，可以用來完成大多數的程式設計任務。
不過在實務上，主要的使用場景多半集中在工程與科學領域。
快速、多元且精密的數值計算是這門語言設計上的核心。

## 整數

整數是一種沒有小數點的「整」數字。

在[基礎][basics]概念中，我們看過可以把整數值指定給變數，而不需要指定型別。

為了方便閱讀，可以用底線當作數字分隔符。
編譯器會忽略它們。

```julia-repl
julia> x = 3
3

julia> typeof(x)
Int64

julia> large_number = 1_234_567_890
1234567890
```


## 浮點數

浮點數有小數點，小數點後面還有小數部分，這應該不令人意外。

```julia-repl
julia> f = 3.45
3.45

julia> typeof(f)
Float64
```

當然，也支援科學記號。

```julia-repl
julia> avogadro = 6.02e23
6.02e23
```

最大值和最小值可能會讓你嚇一跳：

```julia-repl
julia> typemax(Float64)
Inf

julia> typemin(Float64)
-Inf
```

無限大是有效的值！

## 算術運算子

如同基礎概念中討論過的，算術運算子大致上就和我們小時候學的標準算術一樣。
請注意，指數運算用的是`^`，而_不是_`**`（兩者在其他語言中都很常見）。

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division)
8 % 3  # 2 (remainder)
2 ^ 3  # 8 (exponentiation)
```

不過，有幾個 Julia 特有的細節值得討論。

### 乘法

```julia-repl
julia> x = 4.2
4.2

julia> 2 * x
8.4

julia> 2x
8.4

julia> 2.4x
10.08
```

這可能有點出人意料。

永遠都可以像大多數其他電腦語言一樣，把`*`當作中綴運算子來使用。

不過，Julia 的設計者相信，程式碼應該盡可能看起來像數學算式。

由於變數名稱必須以字母開頭，因此把數字（整數或浮點數）放在名稱前面時，會被視為隱含的乘法。

例如，如果我們想求球體的表面積，除了寫`4 * pi * r * r`，也可以這麼做：

```julia-repl
julia> surface(r) = 4π * r^2
surface (generic function with 1 method)

julia> surface(3)
113.09733552923255
```

雖然 π 是內建的常數，但它同時也是一個（希臘）字母。
因此，剖析器仍然需要一個明確的`*`，才能把`π`和`r`分開。

### 除法

用`/`當中綴運算子時，結果一定是浮點數，即使輸入的是整數也一樣。

至於整數除法，還有更多選擇。

```julia-repl
julia> 10 / 3  # floating-point division
3.3333333333333335

julia> div(10, 3)  # integer division
3

julia> 10 ÷ 3  # synonym for div()
3

julia> 10 // 3  # rational number (fraction)
10//3
```

`div()`函式用於整數除法，結果會朝零取整：正數時向下取整，負數時向上取整。

我們也可以用中綴運算子`÷`作為同義寫法，同樣是為了讓它看起來更數學一些。
如果你用的編輯器看得懂 Julia，可以輸入`\div`再按`<Tab>`鍵。

`//`運算子超出本概念的範圍。
目前我們只要知道，`//`的結果是一個「有理數」，大多數人稱之為_分數_。

## 數值型別的轉換

這通常會自動發生：

```julia-repl
julia> x = 2 + 3.5
5.5

julia> typeof(x)
Float64
```

我們把`Int64`和`Float64`相加，得到`Float64`的結果。

事實上，在相加之前，整數已經悄悄地被轉換成`Float64`。

**浮點數轉整數**的轉換無可避免地比較複雜。
小數點後面的部分你想怎麼處理？

- `round()`函式會四捨五入到最接近的整數；遇到像 4.5 這種正好在中間的情況時，會捨入到最接近的_偶數_。
- `floor()`向下取整，`ceil()`向上取整，`trunc()`朝零取整。
- 如果直接嘗試轉型，例如用`Int32()`，會失敗並出現`InexactError`。

不過，這些函式預設回傳的並不是你可能想要的整數型別。
你可以指定想要的輸出型別。

```julia-repl
julia> round(4.5)
4.0

julia> ceil(Int, 4.3)
5
```

也可以用`digits`關鍵字，把數字捨入到指定的小數位數。

```julia-repl
julia> round(π, digits=10)
3.1415926536
```

## 除以零

這應該只會丟出錯誤吧？
事實上，情況沒有那麼單純。

用`÷`或`//`做整數除法，一如預期會產生錯誤。

用`/`做浮點數除法時，採取的可能算是工程取向，而不是標準的資訊科學取向：

```julia-repl
julia> 2 / 0
Inf

julia> 0 / 0
NaN
```

如同前面幾節討論過的，無限大在 Julia 中是有效的浮點數，以`Inf`表示。

當分子也是零的時候，結果在數學上是未定義的。
這時 Julia 會把它當成「非數值」，以`NaN`表示。
