## 安裝 Z3

### 下載 Python（若尚未安裝）

最新版本的 Python 可以從[這裡](https://python.org)下載。

* 安裝時，請務必勾選將 Python 加入 PATH 的核取方塊。

### 下載 Visual Studio（若尚未安裝）

最新版本的 Visual Studio 可以從[這裡](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)下載。

* 安裝時，請選取**Python Development**工作負載。
* 勾選右側所有選用的 Python 開發套件核取方塊。

安裝完成後，開啟 Visual Studio 並設定你的初始偏好設定。

### 安裝 Git 指令

Git 安裝說明可以在[這裡](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)找到。

* 你需要[將 Git 加入你的系統變數](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)。

### 複製 Z3

前往 [Z3 GitHub 儲存庫](https://github.com/Z3Prover/z3)查看專案。

在電腦上開啟終端機，並前往你想複製 Z3 儲存庫的位置（例如：C:\Z3）。

在該位置執行：

```bash
git clone https://github.com/z3Prover/z3.git
```

### 在 Windows 上使用 Visual Studio Command Prompt 建置 Z3

透過開始功能表開啟**Developer Command Prompt for VS 2019**。

前往你複製 Z3 儲存庫的資料夾（例如：C:\Z3）。

若要建置 32 位元版本，請執行：

```bash
python scripts/mk_make.py
```

若要建置 64 位元版本，請執行：

```bash
python scripts/mk_make.py -x
```

然後執行：

```bash
cd build
pip install z3-solver
```



你現在應該可以開啟 Visual Studio，並使用其 Python 繫結來執行 Z3。


若要測試，可以執行：
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

最後兩行應該會產生`sat`和`[y = 4, x = 2]`。
