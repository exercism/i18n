# 說明

在這個練習中，你會寫一些程式碼來幫助 Larry the Lisp Alien 解析並格式化日誌字串。這些日誌字串來自各種系統，需要經過處理，才能將它們的訊息顯示在資訊豐富的監控顯示器上。

日誌字串的格式為`"[<level>]: <message>"`。層級會是下列其中一個值：`info`、`warn`或`ohno`。

## 1. 擷取訊息

定義一個函式`log-message`，它會接受一個日誌字串，並求值為其中包含的訊息。

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. 判斷嚴重程度

日誌字串的層級會決定其嚴重程度。

- 層級為`info`表示嚴重程度為`:everything-ok`
- 層級為`warn`表示嚴重程度為`:getting-worried`
- 層級為`ohno`表示嚴重程度為`:run-for-cover`

定義一個函式`log-severity`，它會接受一個日誌字串，並求值為正確的嚴重程度。

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. 處理現實的變化無常

不幸的是，日誌字串有時並不總是格式正確。具體來說，日誌層級可能不會如上所述全部是小寫。請修改`log-severity`來處理這種情況。

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. 根據日誌嚴重程度重新格式化日誌訊息

視嚴重程度而定，訊息應該以不同方式修改：

- 嚴重程度為`:everything-ok`時，訊息應改成全部小寫。
- 嚴重程度為`:getting-worried`時，訊息應改成每個單字首字母大寫。
- 嚴重程度為`:run-for-cover`時，訊息應改成全部大寫。

定義一個函式`log-format`，它會接受一則日誌訊息，並求值為格式正確的訊息。

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
