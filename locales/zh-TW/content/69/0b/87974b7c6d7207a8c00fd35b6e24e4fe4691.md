# 說明補充

## 詞彙

- `<bst> ( data-seq -- tree )`，依序插入 `data-seq` 的每個元素來建立一棵樹。
- `sorted-data ( tree -- seq )`，以遞增順序回傳樹中的元素（中序走訪）。

## 元組階層

二元搜尋樹裡的節點，不是*空的*，就是*帶有資料和兩棵子樹*。可以用一個小小的繼承階層來表示：

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst`是抽象的父類別；`leaf`是空樹的情況；`branch`帶有一個值和兩個 `bst` 子節點（每個子節點本身不是 `leaf` 就是 `branch`）。

## 排序

用 `before=?`（來自 `math.order`）來比較資料，它對字串和數字都能運作。測試用的就是 `"1"`、`"2"`、`"3"` 這類字串資料。
