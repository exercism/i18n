# 說明

在這個練習中，你會處理日誌行。

每一行日誌都是格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

日誌等級有三種：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會拿到一行日誌，並請你對它做點處理。

## 1. 從日誌行取得訊息

實作`message`函式，回傳日誌行裡的訊息：

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

開頭或結尾的空白都應該移除：

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. 從日誌行取得日誌等級

實作`log_level`函式，回傳日誌行的日誌等級，而且要以小寫回傳：

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. 重新格式化日誌行

實作`reformat`函式，重新格式化日誌行，把訊息放在前面，接著用括號把日誌等級放在後面：

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
