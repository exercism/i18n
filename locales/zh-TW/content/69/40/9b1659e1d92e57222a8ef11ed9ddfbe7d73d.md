# 簡介

和屬性一樣，屬性會在你的 struct 和類別中儲存資料，你也可以定義_方法_，讓它們把函式存在你的 struct 或類別裡。

定義方法和定義一般函式的方式相同，差別只在於方法定義在 struct 或類別的主體內。注意，如果某個函式會改變 struct 中屬性的值，它就必須加上`mutating`關鍵字。此外，如果某個屬性可以被方法改變，這個屬性就必須用`var`定義，而不是`let`，就跟一般的變數一樣。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

這些方法可以像屬性一樣，用點記法呼叫。

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
