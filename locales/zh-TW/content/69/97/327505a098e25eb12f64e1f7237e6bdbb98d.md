# 指令

在這道練習中，你會處理日誌報告中的每一行。
每一行日誌都是格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

日誌共有三種等級：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會拿到一行日誌，並要你對它做點處理。

## 1. 從日誌行取得訊息

實作`log_line::message`方法，回傳日誌行的訊息：

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. 從日誌行取得日誌等級

實作`log_line::log_level`方法，回傳日誌行的日誌等級，而且要以大寫回傳：

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. 重新格式化日誌行

實作`log_line::reformat`方法，重新格式化日誌行，把訊息放在前面，並在後面用括號標註日誌等級：

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
