# 關於

## 繼承

Java 以繼承作為核心功能，並藉由繼承實現抽象等許多 OOP 原則。

一個類別可以使用`extends`關鍵字繼承另一個類別，也可以使用`implements`關鍵字來實作介面。

## 存取修飾子

存取修飾子用來規範類別的成員變數和方法，決定它們能否從其他類別（或程式碼中的任何位置）存取。

共有四種存取修飾子：

- `private`
- `public`
- `protected`
- 預設（不需要關鍵字）

你可以[在這篇文章中][access-modifiers]進一步了解它們。

## 繼承與組合

這兩個概念非常相似，經常被人混淆。

- 繼承代表子類別與父類別之間具有 IS-A 關係。

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

在這裡，`Dog` IS-A `Animal`

- 組合代表 HAS-A 關係。

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

在這裡，`Car` HAS-A `Engine`
