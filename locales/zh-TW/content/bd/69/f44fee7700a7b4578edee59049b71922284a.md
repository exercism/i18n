# 指令

在這個練習中，你將幫助高中情侶在社群媒體上公開示愛，用他們名字的首字母產生一個帶有 unicode 愛心的訊息：

```
❤ J.  +  M. ❤
```

## 1. 清理名字

實作 `cleanupname` 方法。
它應該接受一個名字，移除其中所有的 `-` 字元，並以空格取代。
同時也應該移除名字開頭和結尾的空白。

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. 取得名字的第一個字母

實作 `firstletter` 方法。
它應該接受一個名字，並以字串的形式回傳它的第一個字母。
記得重複使用你在前一步定義的 `cleanupname`，並將它與其他函式組合起來。

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. 將第一個字母格式化為縮寫

實作 `initial` 方法。
它應該接受一個名字，回傳它的第一個字母，轉為大寫，後面加上一個句點。
記得重複使用你在前一步定義的 `firstletter`。

```julia-repl
initial("Robert")
"R."
```

## 4. 把縮寫放進愛心裡

實作 `couple` 方法。
它應該接受兩個名字，回傳兩人的縮寫，並在兩側加上 emoji 愛心。
記得重複使用你在前一步定義的 `initial`。

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
