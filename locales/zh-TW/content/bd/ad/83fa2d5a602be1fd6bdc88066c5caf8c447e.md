# 簡介

## 資源生命週期

`[concept:csharp/resource-cleanup]()`使用`IDispose`介面來表示：某個物件的資源或其他程式狀態在該物件不再需要時必須被釋放或重設（而且光靠垃圾回收器無法達成這點，也無法提供所需的控制程度），而`IDisposable.Dispose()`方法正是這類清理作業最自然的所在。

還有一種結構，也就是`using`區塊，從呼叫端的角度來看，它能將所有的資源生命週期管理集中到單一敘述裡。

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

在上述範例中，與`file`相關的檔案系統資源會在離開`using`區塊時釋放回作業系統。

要讓這個模式運作，`using`敘述中的變數必須是實作`IDisposable`介面的參考型別，並且必須在其`Dispose()`方法中釋放資源、重設程式狀態。

C# 8 為這個模式帶來了一項改良。`using`敘述可以放在區塊的開頭。

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java 開發者或許會認出，這與 Java 7 引進的*自動資源管理*機制相當類似。
