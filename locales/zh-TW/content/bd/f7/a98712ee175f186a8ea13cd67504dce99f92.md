# 簡介

## 命名空間

命名空間是一種把相關程式碼分組、避免名稱衝突的方式，除了最簡單的程式碼庫之外，幾乎所有程式碼庫都會用到。

語法如下：

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

在命名空間外部參照命名空間內含的型別時，要在型別名稱前面加上以點分隔的語法。或者，更常見的做法是，在檔案頂端（或命名空間內）加上 `using` 指示詞，這樣就能直接使用型別，不必加上前置詞。在同一個命名空間內，則不需要限定型別名稱。

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

你可以用 `using MyAlias = MySpace;` 這樣的語法為命名空間取別名，之後在任何可以使用該命名空間的地方，都能改用這個別名。
