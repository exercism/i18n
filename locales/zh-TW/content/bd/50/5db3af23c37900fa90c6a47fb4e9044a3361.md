# 說明補充

## 打造你自己的 DSL

在這個練習中，你可以完全自由地設計你理想中的圖形 DSL。

測試只要求你建立幾個特定的圖形，至於要怎麼建立，完全由你決定。

想讓樂趣加倍的話，你還可以試著實作一個`to_dot`函式，把你的圖形轉換成 DOT 格式！

## 圖形的表示法

在`Graph.roc`中定義你的 DSL，再用它建立程式骨架所要求的圖形。每個`EdgeId`中的兩個節點 ID 必須依字母順序排列。

| 定義 | 要建立的圖形 |
| --- | --- |
| `empty_graph` | 空圖形 |
| `graph_with_one_node` | 一個節點 |
| `graph_with_one_node_with_attribute` | 一個帶有屬性的節點 |
| `graph_with_one_edge` | 一條邊 |
| `graph_with_one_attribute` | 一個圖形屬性 |
| `graph_with_nodes_edges_and_attributes` | 節點、邊和屬性 |
| `multiple_edges_on_one_line` | 在同一行表示的多條邊 |
| `only_1_edge_between_nodes` | 每對節點之間只有一條邊 |
