# 簡介

_字串_ 是 JavaScript 用來儲存文字資料的資料型態。

## 建立字串

建立字串的方式，就是把文字用單引號或雙引號包起來。在 Exercism 上，我們使用單引號。

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## 字串是字元的陣列

字串可以視為一個字元陣列，其中第一個字元的索引是`0`。你可以用方括號搭配想取得的字母索引，來存取字串中的單一字元。

```javascript
'cat'[1];
// => 'a'
```

你可以透過 `length` 屬性取得字串中的字元數。

```javascript
'cat'.length;
// => 3
```

## 串接與方法

串接字串最簡單的方式，就是使用加法運算子 `+`。

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

字串提供了許多輔助方法，完整清單請見 [MDN 的字串方法文件][mdn-string-methods]。以下列出一些常用的輔助方法。

- [`toUpperCase`][mdn-to-upper-case]與[`toLowerCase`][mdn-to-lower-case]：改變所有字元的大小寫
- [`trim`][mdn-trim]：移除開頭與結尾的空白
- [`includes`][mdn-includes]、[`startsWith`][mdn-starts-with]與[`endsWith`][mdn-ends-with]：判斷另一個字串是否屬於給定的字串
- [`slice`][mdn-slice]：取出字串中的某一段

在 JavaScript 中，字串是不可變的。因此所謂的「修改」，例如透過上面某些方法，實際上都會改為建立一個新的字串。
