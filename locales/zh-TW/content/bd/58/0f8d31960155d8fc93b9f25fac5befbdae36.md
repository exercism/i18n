# 簡介

## 開始使用

### 變數

你可以透過定義[變數][constants-variables]來儲存值並為它命名。
定義變數之後，你可以在整份程式碼中用它的名稱取用該值。
變數是_可變的_，也就是說它們的值在定義之後可以改變。

使用`var`關鍵字來定義變數：

```swift
var variableName = 10
```

Swift 是靜態型別語言，這表示每個值在編譯時期都有已知的型別。
你可以用[型別註解][type annotations]明確宣告型別，也可以讓 Swift 編譯器從指定的值[推斷型別][type-inferring]：

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

你可以使用賦值運算子（`=`）更新變數的值：

~~~~exercism/note
變數的型別在宣告之後就無法改變。

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

你可以指定型別來宣告一個沒有初始值的變數，但在使用它之前必須先賦予值：

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### 常數

[常數][constants-variables]同樣將名稱與值關聯起來，但它們的值在賦值之後就不能改變。
它們是_不可變的_。
使用`let`關鍵字來定義常數：

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### 算術運算子

Swift 提供了標準的[算術運算子][arithmetical-operators]來做基本的數學運算：

- 加法：`+`
- 減法：`-`
- 乘法：`*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### 函式

在 Swift 中，[函式][functions]是執行特定工作的獨立程式碼區塊。
函式可以接受輸入、回傳值，也能像值一樣傳遞給其他函式。
使用`func`關鍵字定義函式，後面接著函式名稱、括號中的參數列表，以及選用的回傳型別：

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift 函式使用[引數標籤][argument-labels]，讓程式碼讀起來像自然的句子：

- **引數標籤**是在呼叫函式時使用。
- **參數名稱**則是在函式主體內用來取用該值。

如果你只指定一個名稱，Swift 會將它同時用作引數標籤和參數名稱：

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

如果你在呼叫函式時不想要引數標籤，可以在參數名稱前加上底線（`_`）：

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

所有函式參數預設都是常數（`let`），這表示它們的值無法在函式主體內修改。

若要從函式回傳值，請在`->`之後指定回傳型別，並使用`return`關鍵字：

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

當函式不回傳值時，它的回傳型別是`Void`（等同於空元組`()`）。
在這種函式中，你可以同時省略`-> Void`回傳型別和`return`敘述。

### 註解

Swift 支援兩種形式的[註解][comments]：

- **單行註解**以`//`開頭，一直延伸到該行結尾。
- **多行註解**則包在`/*`和`*/`之間。

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
