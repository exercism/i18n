# 簡介

`Tuple`在許多方面和`Vector`（一維`array`）很像。不過，兩者之間還是有幾個重要的差異。

- 元組使用小括號`( )`而不是方括號`[ ]`來書寫，不過在意義明確的情況下，小括號可以省略。
- 元組不要求同質：每個元素的型別都是各自獨立儲存的。
- 元組是不可變的。

不可變性能讓編譯器進行更多最佳化，也讓元組的效能比向量更好，所以在不需要可變性的情況下，應該優先選用元組。

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

另外還有`Tuple()`建構子，可以把任何可迭代的集合轉換成元組。很方便的是，它會把字串視為由字元組成的可迭代集合。

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

對任何元組來說，都可以透過索引存取元素，也可以對它執行迴圈。

任何純數值的元組也能用在`sum()`之類的數學函式裡，就跟陣列一模一樣。

## 解構

元組可以透過多重賦值解構成個別元素。對於不需要的元素，可以用底線`_`當作虛擬變數。

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

寫過 Python 的人對這種多重賦值的語法一定很熟悉。

## 具名元組

`Tuple`只包含值。`NamedTuple`則會把每個值和一個名稱配成對。

之後就可以用「點」記法存取個別的欄位：

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

名稱在內部是以`Symbol`儲存的（一種不可變的型別，前面會加上冒號`:`），所以還有另一種語法可以用：

```julia-repl
julia> nt[:b]
7.3
```

要分別取得名稱（也稱為「鍵」）或值都很容易：

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

請注意，對具名元組進行疊代只會產生_值_，而_名稱_會被忽略。

元組（無論是否具名）是把結構化資料傳入函式、從函式傳出的常見做法。在這種用途下，不可變性很有好處，既能確保資料安全，也能讓編譯器進行更積極的最佳化。
