# 執行測試

如要執行某個練習的測試，請在該練習目錄中執行`<exercise>.test`指令碼：

```bash
tclsh <exercise>.test
```

對大多數練習來說，除了第一個測試之外，其餘測試都會顯示「skipped」。
這讓你（開發者）可以進行測試驅動開發：只寫出足以逐一通過每個測試的程式碼就好。
如要覆寫略過測試的指令，請在執行測試套件之前，先將`RUN_ALL`環境變數設為有效的 Tcl true 值 \[1\]：

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]：Tcl 的 true/false 值記載於 C 函式庫函式 [Tcl_GetBoolean][bool] 的手冊頁中。

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
