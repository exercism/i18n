# 安裝 Swift

Swift 可在 macOS、Linux 和 Windows 上使用。
安裝流程會依你使用的作業系統而有所不同。
關於 Linux 支援，有一點要特別注意：Swift 只在下列發行版上獲得（官方）支援：
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

如果你使用的是其他 Linux 發行版，就得自己想辦法安裝 Swift。

## Xcode（macOS）

Swift 隨 Xcode 一起提供，Xcode 是 Apple 專為 macOS 和 iOS 開發打造的 IDE。
在這個 Exercism 軌道上，你需要安裝 Xcode 16.0 或更新的版本。
Xcode 可在 [Mac App Store][xcode] 免費取得。
Xcode 的其他版本（包括最新的 beta 版）可在 [Apple 開發者中心][apple-developer-center]取得。

## macOS 與 Linux

在 macOS 和 Linux 上，有一套名為 [swiftly][swiftly] 的 Swift 安裝管理工具。
它是一種命令列工具，讓你能在系統上安裝並管理多個 Swift 版本。
在 macOS 上安裝 swiftly 的指令可以在[這裡][swiftly-macos]找到，Linux 的安裝指令則在[這裡][swiftly-linux]。

macOS 的另一種安裝方式是 [Homebrew][homebrew]。
在 Linux 上，你可以用官方 [Swift 網站][tarball]提供的 tarball 來安裝。

## Windows

在 Windows 上安裝 Swift，建議使用 [WinGet 安裝程式][winget-windows]。
你也可以改用 Scoop 套件管理器安裝 Swift，或手動安裝。
所有選項請參閱[在 Windows 上安裝 Swift][swift-windows] 頁面。
