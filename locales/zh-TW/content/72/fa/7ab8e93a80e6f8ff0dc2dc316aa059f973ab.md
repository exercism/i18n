# 指示補充

## 提示

要完成這個練習，你需要實作`anagramsFor`函式：接收一個*單字*和一組*單字*，回傳其中是所給*單字*字母重組的那些單字。

你必須依照這些字母重組在候選單字中出現的順序回傳它們。

如果這是你第一次解這個練習，建議你先沿用提供的函式簽章：

```haskell
anagramsFor :: String -> [String] -> [String]
```

之後，不妨再回來看看這個問題，玩玩其他資料型態和函式庫：

- `Text`，來自 *text* 套件。
- `Sequence` 和 `Set`，來自 *containers* 套件。
- `MultiSet`，來自 *multiset* 套件

測試套件刻意設計成能接受幾乎任何合理的型別簽章，所以鼓勵你找出自己認為最好的那個。
