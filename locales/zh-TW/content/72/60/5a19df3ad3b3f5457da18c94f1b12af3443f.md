# 說明

在這個練習中，你會寫一些程式碼，幫助你做好購買車輛的準備。

你有三個任務：判斷自己是否負擔得起某輛車的月付金、判斷你需要哪一種駕照，以及估算中古車的合理價格。

## 1. 計算你是否負擔得起某輛車的月付金

你鎮上的汽車經銷商都在舉辦五年期、零利率的促銷活動，而你想好好把握。但你不確定自己是否負擔得起想買的那輛車的月付金。

月付金就是車輛的總價除以五年期間的月數。

請實作 `canIBuy(vehicle:price:monthlyBudget:)` 函式，它接受下列引數：
- `vehicle`：你想購買的車輛名稱。
- `price`：你想購買的車輛價格。
- `monthlyBudget`：你每月負擔得起的金額。

這個函式應根據下列條件回傳對應的訊息：
- 如果車輛的月付金小於或等於每月預算，回傳訊息 `"Yes! I'm getting a <vehicle>"`。
- 如果車輛的月付金超出你的每月預算，但幅度在 10% 以內（含 10%），回傳訊息 `"I'll have to be frugal if I want a <vehicle>"`。
- 如果車輛的月付金超出你的每月預算超過 10%，回傳訊息 `"Darn! No <vehicle> for me"`。

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. 判斷你需要哪一種駕照

你決定要買一輛中古車，而你需要判斷自己需要哪一種駕照才能駕駛它。

請實作 `licenseType(numberOfWheels:)` 函式，它接受引數 `numberOfWheels`，也就是你想購買的車輛的輪子數量。

這個函式應根據下列條件回傳對應的訊息：
- 如果輪子數量是 2 或 3，回傳訊息 `"You will need a motorcycle license for your vehicle"`。
- 如果輪子數量是 4 或 6，回傳訊息 `"You will need an automobile license for your vehicle"`。
- 如果輪子數量是 18，回傳訊息 `"You will need a commercial trucking license for your vehicle"`。
- 如果是其他任何數量，回傳訊息 `"We do not issue licenses for those types of vehicles"`。

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. 估算中古車的價格

既然你已經做了決定，你會想確保自己在經銷商那裡拿到合理的價格。由於你買的是中古車，價格取決於車齡。粗略估算的話，假設車輛車齡不到 3 年，價格是全新時原價的 80%。如果車齡至少 10 年，價格是 50%。如果車齡至少 3 年但不超過 10 年，價格是原價的 70%。

請實作 `calculateResellPrice(originalPrice:yearsOld:)` 函式，它接受引數 `originalPrice`（車輛的原價）與 `yearsOld`（車輛的車齡，以年為單位）。這個函式應回傳車輛的轉售價格。

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
