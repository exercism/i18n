# 測試

要使用 CLI 執行練習的測試，請在練習的目錄下執行下列指令：

```bash
clojure -M:test
```

## REPL

要使用 REPL 執行練習的測試，請在練習的目錄下執行下列指令：

```bash
$ clojure -m cljs.main -re node
```

接著`require`練習的測試命名空間以及 Clojure 的測試命名空間）：

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

將 ns 改成測試命名空間：

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

接著呼叫`run-tests`：

```clojure
=> (cljs.test/run-tests)
```
