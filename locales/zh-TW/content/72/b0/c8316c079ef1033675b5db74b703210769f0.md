# 指令

在這道練習中，你會處理儲蓄帳戶。
每年，你的儲蓄帳戶餘額會根據它的利率更新。
銀行給你的利率取決於你帳戶裡的金額（也就是餘額）：

- 餘額小於`0`美元時為 3.213%（餘額會變得更負）。
- 餘額大於或等於`0`美元，且小於`1000`美元時為 0.5%。
- 餘額大於或等於`1000`美元，且小於`5000`美元時為 1.621%。
- 餘額大於或等於`5000`美元時為 2.475%。

你有四項任務，每一項都會處理你的餘額和它的利率。

## 1. 計算利率

實作`InterestRate()`函式，根據指定的餘額計算利率：

```go
InterestRate(200.75)
// => 0.5
```

注意，回傳的值是`float32`。

## 2. 計算利息

實作`Interest()`函式，根據指定的餘額計算利息：

```go
Interest(200.75)
// => 1.003750
```

注意，回傳的值是`float64`。

## 3. 計算年度餘額更新

實作`AnnualBalanceUpdate()`函式，將利率納入考量，計算年度餘額更新：

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

注意，回傳的值是`float64`。

## 4. 計算達到目標餘額所需的年數

實作`YearsBeforeDesiredBalance()`函式，計算達到目標餘額所需的最少年數，並考量到每年利息都會加到餘額上。
這表示一年後的餘額是：起始餘額 + 起始餘額的利息。
兩年後的餘額是：一年後的餘額 + 一年後餘額的利息。
依此類推，直到當年的餘額大於或等於目標餘額。

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

注意，回傳的值是`int`。
