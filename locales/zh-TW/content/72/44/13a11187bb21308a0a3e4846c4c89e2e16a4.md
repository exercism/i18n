# 簡介

在 Python 中，`None`經常用來表示某個值不存在的情況，它是用來定義`null`（空）變數、物件或引數的佔位符。

如果你在其他程式語言中聽過或用過`NULL`或`nil`型別，那麼 Python 中`None`的這種用法對你來說應該很熟悉。`None`可以幫你宣告還沒有值的變數或函式引數，之後再視需要重新指定成特定的值。

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

`None`用在條件判斷中時會評估為`False`，因此很適合用來驗證一個值是「存在」還是「不存在」，也就是_任何_值；當函式或流程可能回傳錯誤物件或訊息時，經常會用到這種模式。

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
