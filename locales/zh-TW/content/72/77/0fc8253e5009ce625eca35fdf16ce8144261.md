# 說明

你在海濱木板路的遊樂場裡經營各種機率遊戲。客人擲骰子、夾娃娃機夾取獎品，牌桌則需要洗牌、發牌，全都由隨機性驅動。打烊時，你還想要一個「重播」功能，好讓有爭議的遊戲能從同一個種子重新跑一次。

## 1. 擲骰子

定義`roll-die`，讓它接受骰子的面數，並回傳`1`到`sides`（含）範圍內的點數。

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. 取得獎品

定義`pick-prize`，讓它接受一串獎品，並隨機回傳其中一個。

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. 洗牌

定義`shuffle-deck`，讓它接受一副牌（一個序列），並回傳牌被隨機排列後的結果。

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. 發一手牌

定義`deal-hand`，讓它接受一副牌和一個數量`n`，並從牌組中回傳`n`張*互不相同*的牌。

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. 以種子重播

定義`play-seeded`，讓它接受一個種子和一個 quotation，並用一個以該整數為種子的產生器來執行這個 quotation，如此一來同一個種子永遠會重現相同的結果。quotation 的結果應該回傳給呼叫方。

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
