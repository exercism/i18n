# 提示

## 1. 檢查是否能使出「快速攻擊」

- 邏輯 NOT 運算子（`!`）可以放在運算式前面，把它的值反轉。
- 想認識邏輯運算子，可以看看[這篇 MDN 文章](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_Operators#Logical_NOT_!)

## 2. 檢查是否能進行「間諜」行動

- 邏輯運算式會由左至右求值，並會檢查是否可能「短路」。
- 想全面了解由左至右的運作方式，可以參考[這篇文章](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)！

## 3. 檢查是否能進行「向囚犯打信號」行動

- 邏輯運算子依優先順序排列（由高到低）：`!`、`&&`、`||`。
- 想了解運算子優先順序，可以看看[這篇 MDN 文章](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Precedence_And_Associativity)

## 4. 檢查是否能進行「釋放囚犯」行動

- `()` 是優先順序最高的運算子。用它來把邏輯運算式分組。
