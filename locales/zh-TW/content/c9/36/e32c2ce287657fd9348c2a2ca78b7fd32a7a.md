# 簡介

在 R 中，`vector`是同一種`type`的值的集合：`numeric`、`character`等等。如果輸入的型別不一致，R 會悄悄把它們全部強制轉換成同一種型別，通常是`character`，這可能導致出乎意料的結果。

```R
v <- c(2, 5.4, "txt")
v
#> [1] "2"   "5.4" "txt"
typeof(v)
#> [1] "character"
```

## 建立向量

如果你已經握有所有的值，可以使用`c()`（是「concatenate」或「combine」的縮寫）：

```R
x <- 10
v <- c(4, 7, x)
```

`c()`函式非常有彈性，輸入可以包含其他向量和範圍。`c()`能接受任意數量和種類的輸入，並將它們攤平成單一向量。

## 範圍、序列、重複

如果要一段連續的值（遞增或遞減），可以使用`:`記法：

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

`seq()`函式提供更精細的控制：

```R
# specify step size
seq(2, 11, by = 3) # c(2, 5, 8, 11)

# specify number of values, evenly-spaced
seq(2.5, 4, length.out = 5) # c(2.500, 2.875, 3.250, 3.625, 4.000) 
```

有些範圍已經預先定義成內建常數：

```R
letters  # LETTERS is the UPPERCASE equivalent
#> [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q" "r" "s" "t" "u" "v" "w" "x" "y" "z"

month.name
#> [1] "January"   "February"  "March"     "April"     "May"       "June"      "July"      "August"   
#> [9] "September" "October"   "November"  "December" 

month.abb
#> [1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

## 算術運算

運算會自動沿著向量逐一元素套用。
其他語言常見的迴圈、陣列推導式和遞迴在這裡並不需要，而且（*基於效能考量*）通常應該避免使用。

```R
2 + 1:3 # c(3, 4, 5)
2 * 1:3 # c(2, 4, 6)
12 / 1:3 # c(12  6  4)
2 ^ (1:3) # c(2, 4, 8) : exponentiation, precedence order here needs ()
```

成對的向量也能逐一元素運算：

```R
v <- 1:3
w <- 5:7

v + w
#> [1]  6  8 10

v * w
#> [1]  5 12 21

v ^ w
#> [1]    1   64 2187
```

## 存取向量元素

如同許多語言，我們可以用方括號中的索引來存取元素：

```R
v <- 4:7
v[2]
#> [1] 5
v[2:4]
#> [1] 5 6 7
```

但請注意：***R 預設採用從 1 開始的索引***。

這在科學語言中很常見（Fortran、Matlab、Julia），但和 C 及其眾多後繼語言從 0 開始的索引不同。

範圍不只能像上面的例子那樣使用，也能用在極具彈性的`c()`函式中：

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`（就像 R 中大多數的東西）可以被視為可變的，用同樣彈性的語法就能寫入單一或多個元素：

```R
v <- 1:10
v[2] <- 42
v[4:6] <- c(11, 12, 13)
v
#> [1]  1 42  3 11 12 13  7  8  9 10
```

## 負索引

熟悉其他語言的程式設計師可能會猜到，`v[-1]`是存取向量最後一個元素的方法。
*錯了！*
要達到這個目的，請使用`tail(v, n=1)`。

負索引其實是***移除***元素的方法，會回傳一個更短的向量：

```R
v <- c(2, 4, 6)
v[-2]
#> [1] 2 6  # second element gone
```

## 向量的條件判斷

對向量套用比較，會回傳一個長度相同的布林向量。
這在`all()`和`any()`這類函式中非常方便：

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

對於更複雜的邏輯運算式，務必使用`&`和`|`運算子，它們能作用在向量上。
雙字元的`&&`和`||`只適合用來比較單一值。

```R
v %% 2 == 0 & v > 5
#> [1] FALSE FALSE  TRUE
```
