# 推薦的學習資源

歡迎學習 ColdFusion（CFML）！CFML 是一種動態、型別寬鬆的 JVM 指令碼語言。它有兩種不同的檔案類型。`.cfm` 檔案（ColdFusion markup）完全是程序式的，使用標籤式語法來產生 HTML 樣板。如果你要建立網站，這些檔案會用來當作檢視：

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

另一種檔案類型是 `.cfc`（ColdFusion Component），它是你宣告類別的方式。元件用於商業邏輯、模型與控制器。這些檔案通常使用指令碼語法，讀起來和 JavaScript 很像。

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
