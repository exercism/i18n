# 說明

你的朋友 Chandler 打算走訪世界各地充滿異國風情的國家。可惜的是，Chandler 的數學不太好。他很擔心旅途中被貨幣兌換處坑錢，所以希望你能幫他做一個貨幣計算器。以下是他對這個應用程式的需求：

## 1. 估算兌換後的價值

建立`exchange_money()`函式，接受 2 個參數：

1. `budget`：你打算兌換的金額。
2. `exchange_rate`：等於一單位外幣的本國貨幣金額。

這個函式應該回傳兌換後貨幣的價值。

**注意：** 如果你的貨幣是 USD，而你想用`1.20`的匯率把 USD 兌換成 EUR，那麼`1.20 USD == 1 EUR`。

```julia
julia> exchange_money(127.5, 1.2)
106.25
```

## 2. 計算兌換後剩下的金額

建立`get_change()`函式，接受 2 個參數：

1. `budget`：兌換前的金額。
2. `exchanging_value`：從預算中*取出*用來兌換的金額。

這個函式應該回傳預算中*剩下*的金額。

```julia
julia> get_change(127.5, 120)
7.5
```

## 3. 計算紙鈔的價值

建立`get_value_of_bills()`函式，接受 2 個參數：

1. `denomination`：單張紙鈔的價值。
2. `number_of_bills`：紙鈔的總張數。

這間兌換亭只以特定面額單位的現金進行交易。
你收到的總額必須能被一張「紙鈔」（也就是一個單位）的價值整除，除不盡的部分會留下零頭或餘數。
你的函式應該只回傳兌換亭會還給你的紙鈔總價值（_不包含零頭_）。
可惜的是，剩下的零頭就當作額外的好處，留給兌換亭。

```julia
julia> get_value_of_bills(5, 128)
640
```

## 4. 計算紙鈔的張數

建立`get_number_of_bills()`函式，接受`amount`和`denomination`。

這個函式應該回傳在給定的_amount_內你能拿到多少張_紙鈔_。
換句話說：起始金額能放進幾張_完整的紙鈔_？
記住，你只能拿到_完整的紙鈔_，不能拿到紙鈔的一小部分，所以記得要正確地相除。
實際上，你就是把金額_向下_取整到最接近的整張紙鈔（面額）。

```julia
julia> get_number_of_bills(127.5, 5)
25
```

## 5. 計算換成紙鈔後的剩餘金額

建立`get_leftover_of_bills()`函式，接受`amount`和`denomination`。

這個函式應該回傳在給定的紙鈔面額下，起始_amount_中無法換回的_剩餘金額_。
確切知道兌換亭能留下多少錢非常重要。

```julia
julia> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 計算兌換後的價值

建立`exchangeable_value()`函式，接受`budget`、`exchange_rate`、`spread`和`denomination`。

參數`spread`是作為兌換手續費*收取的百分比*，以整數表示。
它需要除以 100 轉換成小數。
如果`1.00 EUR == 1.20 USD`，而*spread*是`10`，那麼實際的總匯率會是：`1.00 EUR == 1.32 USD`，因為 1.20 的 10% 是 0.12，而這筆額外費用會加到匯率上。

這個函式應該在計算*匯率*加上*spread*之後，回傳新貨幣的最大價值。
記住，貨幣的*denomination*是整數，不能分割。

**注意：** 回傳值應該是整數型別。

```julia
julia> exchangeable_value(127.25, 1.20, 10, 20)
80

julia> exchangeable_value(127.25, 1.20, 10, 5)
95
```
