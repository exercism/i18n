# 指令補充

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                                             |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | 輸入     | 整數 | 要檢查的年份                                     |
| `$v0`    | 輸出     | 布林 | 輸入是否為閏年（`0` = `false`，`1` = `true`）      |
| `$t0-9`  | 暫存 | 任意     | 用於暫存資料                                     |
