# 燃料轉換 JSON

## 問題描述

ABC Corp 的每位員工都能獲得無上限的燃料津貼。員工每次為車輛加油時，都必須提交一筆紀錄。這些紀錄會附加到同一個 JSON 檔案中，並在月底統一處理。

身為數位營運團隊的一員，你的任務是讀取這個 JSON 檔案，並將結果寫入另一個 JSON 檔案。輸出檔案應包含每位員工的一筆資料，並帶有下列詳細資訊：

- 員工編號
- 加油次數
- 燃料總費用
- 總加侖數
- 累計總英里數

你會收到兩個 `string` 引數。

1. 輸入 JSON 檔案的路徑。
1. 輸出 JSON 檔案的路徑。

輸入的 JSON 檔案包含一個 JSON 物件陣列。每個 JSON 物件的形式如下。


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

你的任務是將 JSON 輸入轉換成下列 JSON 格式，並將內容寫入指定的路徑。輸出檔案應包含每位員工的一筆資料，並依 `employeeId` 由小到大排序。

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## 限制條件

- 輸入 JSON 檔案中的加油紀錄數量 `n`：0 <= n <= 1000
- 公司員工人數：97
- 油價以每加侖計算
- 沒有缺漏的加油紀錄

## 提示

- 使用[`ballerina/io`模組](https://lib.ballerina.io/ballerina/io/latest)來讀取及寫入 JSON 檔案。
- 將 JSON 值轉換成應用程式專屬的型別，就能以型別安全的方式處理資料。相關資訊請參閱 Ballerina By Examples（BBE）中的[轉換成使用者自訂型別的範例](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type)。

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [解構紀錄](https://ballerina.io/learn/by-example/destructure-records-using-query)有助於減少程式碼的冗長程度。

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- 若函式只有單一運算式，請使用運算式主體函式。例如，只有 return 敘述的函式。

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
