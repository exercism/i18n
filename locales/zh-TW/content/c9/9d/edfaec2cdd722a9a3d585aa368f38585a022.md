# 關於

Common Lisp 對大多數運算都使用標準的算術運算子，但它在採用「前綴表示法」這點上有些獨特，有別於大家較熟悉的中綴表示法。

用圖示說明更清楚：

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前綴表示法雖然會把 `2 + 2` 這類運算變成有點陌生的`(+ 2 2)`形式，卻讓一次對多個數字進行運算變得容易許多。

## 只有單一引數的算術運算子

有個小小的特別之處：`-` 和 `/` 運算子只套用在一個數字上時，具有特殊的意義：

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## 比較數字

最後，你可能會發現用 `=`（相等）、`/=`（不相等）和 `>=`（大於或等於）這類函式來比較不同的數字很有用。

這些比較為真時（例如`(= 1 1)`），它們會回傳 `T`；不為真時（例如`(> 0 1)`），則回傳 `NIL`。

## 數值述詞

這個語言也內建了一些實用的述詞，例如 `zerop`、`evenp` 和 `oddp`，用來檢查顯而易見的條件。

## 參考資料

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
