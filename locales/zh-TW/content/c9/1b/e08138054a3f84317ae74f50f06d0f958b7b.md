# 測試

## 執行測試

如要執行測試，請執行以下指令：

```bash
dotnet test
```

如要在每次原始碼檔案變更時自動執行測試，請執行以下指令：

```bash
dotnet watch test
```

## 解題

解完一道練習，代表讓它所有的測試都通過。預設情況下，執行測試時只會執行一個測試（第一個）。這是刻意的設計，讓你專注在讓那一個測試通過就好。一旦它通過了，你就可以從測試的 `[Fact]` 或 `[Theory]` 屬性中移除 `Skip = "Remove this Skip property to run this test"`，來啟用下一個測試。當所有測試都已啟用，而你的實作讓它們全部通過時，你就解完這道練習了！

為了幫你踏出第一步，每道練習都會附上一個實作範本檔案。你可以把這個檔案當作建構解答的起點。如果你覺得移除或修改這個檔案是對的，就放心去做吧。

## 使用套件

大多數練習應該都不需要用到任何外部套件就能解出來。不過，對於你真的想使用外部套件的練習，你可以執行以下指令，把它加到你的專案中：

```bash
dotnet add package [package-name]
```
