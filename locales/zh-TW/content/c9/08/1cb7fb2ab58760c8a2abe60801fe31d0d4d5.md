# 簡介

`for` 迴圈是最常用來重複執行某段邏輯的敘述之一。
在 JavaScript 中，它由`for`關鍵字、包在括號裡的_標頭_，以及包在大括號裡、包含迴圈_主體_的程式區塊組成。

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

初始化通常會設定一個計數器變數，條件則用來檢查迴圈該繼續還是停止，而遞增會在每次重複結束時把計數器加一。
標頭的各個部分之間以分號分隔。

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
