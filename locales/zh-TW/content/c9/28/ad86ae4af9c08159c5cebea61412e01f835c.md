## 匯入

模組通常會用`use`關鍵字載入。
這會同時載入模組並呼叫它的`import`方法，匯入所有已匯出的符號。

套件`@EXPORT`陣列中的符號預設會自動匯入。
套件`@EXPORT_OK`陣列中的符號則必須明確匯入。

在 Perl `v5.37`之前，模組的結尾必須是 true 值（通常是`1`），用來表示模組已成功載入。
使用[`module_true`][module_true]功能時，就不需要這麼做。

## 匯出

符號必須先匯出，才能被匯入。
[Exporter][Exporter] 模組隨 Perl 一同提供，是匯出時最方便的選擇之一。

定義模組：
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

使用模組：
```perl
use Foo ('bar');

bar();
```

## Pragma

Pragma 是一種模組，會影響 Perl 行為的某個層面。

一般常建議使用[`strict`][strict]與[`warnings`][warnings]這兩個 pragma，分別用來限制不安全的建構和標示潛在問題。
`strict` pragma 會隨 `use v5.12` 或更高的版本一起啟用。
`warnings` pragma 會隨 `use v5.35` 或更高的版本一起啟用。

[`feature`][feature]這個 pragma 讓你啟用較新和實驗性的 Perl 功能。
當`use`關鍵字後面接上特定的 Perl 版本時，就會啟用該版本對應的功能組合。

## 核心模組

除了 [Exporter][Exporter] 之外，Perl 還提供各式各樣的[核心模組][perl-core-modules]可以使用。
有些核心模組對你在這裡可能會遇到的練習特別實用，例如 [List::Util][List::Util]、[Time::Piece][Time::Piece] 和 [Math::BigRat][Math::BigRat]。

## CPAN

除了核心模組之外，[CPAN][metacpan] 還有數千個由 Perl 社群建立、可供安裝的額外模組。
Perl 課程使用 [cpanfile][test-runner-cpanfile] 安裝一些精選模組，這些模組可以在 Exercism 的 Perl 測試執行器中使用。
