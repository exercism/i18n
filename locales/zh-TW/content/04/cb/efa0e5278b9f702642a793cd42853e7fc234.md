# 指令補充說明

## 自訂與引發例外

有時候，你的程式碼必須同時[自訂](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)例外，並用[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)引發例外。這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。這能讓程式碼更容易閱讀，對除錯也有很大的幫助。

自訂例外可以透過新的例外類別來建立（詳情請見 [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)），這些類別通常是 [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) 的子類別。

如果你已經知道錯誤來源會是某種例外的衍生型別，可以選擇繼承 _Exception_ 類別底下的其中一種 [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)。引發錯誤時，你仍然應該附上有意義的訊息。

這個練習要求你建立兩個_自訂例外_。一個是在你的環狀緩衝區**已滿**時要[引發](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)／「拋出」的例外，另一個則用在它**已空**時。只有在你的自訂例外恰當、以`raise`引發這些例外，並且附上恰當的錯誤訊息時，測試才會通過。

要自訂 `built-in exception`，請建立一個繼承該例外的`class`。以訊息引發自訂例外時，請把訊息寫成`exception`型別的引數：

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
