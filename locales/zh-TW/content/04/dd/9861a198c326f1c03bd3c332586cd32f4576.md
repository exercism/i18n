# 數字

`INT`存放整數。在 Sather 中，它正好是 32 位元，因此範圍從 -2147483648 到 2147483647。

```sather
   goals : INT is
      return 42;
   end;
```

## 引數

常式會在括號中接受引數，每個引數都有自己的型別：

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

型別相同的引數可以共用宣告，這也是常見的寫法：

```sather
   total(first, second : INT) : INT is
```

## 算術

| 運算子 | 意義 |
| --- | --- |
| `+` | 相加 |
| `-` | 相減，以及取負值 |
| `*` | 相乘 |
| `/` | 相除，並捨去餘數 |
| `%` | 該相除運算的餘數 |

兩個`INT`之間的`/`永遠不會產生分數：

```sather
7 / 2      -- 3
7 % 2      -- 1
```

如果你想要分數，就需要`FLTD`，它後面才會介紹到。

乘法和除法的優先順序比加法和減法高，就跟一般的算術一樣。需要不同的分組方式時，就用括號：

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## `INT`的實用常式

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str`能讓數字成為句子的一部分，等你學過字串之後就會用到。
