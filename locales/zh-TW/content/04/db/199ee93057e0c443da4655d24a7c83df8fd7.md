# 關於

## 相等

Elm 的型別可以用[相等運算子][equality-operator]`(==)`檢查是否「相同」。
不等運算子則是 `(/=)`（*不是*許多語言所用的`!=`）。

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

被比較的兩個值必須屬於相同的型別。
相等運算子可用於字面值、元組、記錄與自訂型別。
這個運算子檢查的是結構相等，這表示相等的值具有相同的內容與深層結構，與型別標註或記憶體中的位置無關。

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

請注意，*絕對不要*比較函式，因為這會讓程式在執行時崩潰。
關於這項限制的更多資訊請看[這裡][equality-operator]。

## 比較

[比較運算子][comparison-operators]`(<)`、`(<=)`、`(>)`、`(>=)`以及函式`min`、`max`、`compare`可用於`comparable`型別。
`comparable`型別是一種特殊的型別，它集合了所有可以比較的內建型別：數字、字元、字串、可比較項目的陣列，以及可比較項目的元組。
字元是依據其[Unicode 碼位][unicode-codepoint]來比較的。

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

類似序列的型別（字串、陣列與元組）會依[字典序][lexicographic-order]比較。
簡單來說，序列的元素會依序兩兩比較，直到找到較小的元素，或其中一個序列結束為止。

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

其他型別的值，例如記錄或自訂型別，無法直接比較。

有些內建型別要求其內容必須是`comparable`，例如`Set`或`Dict`的鍵，因為它們的結構依賴內部的排序。
這表示自訂型別可能無法存放在`Set`中，不過社群有一些替代方案：[`AnySet`][any-set]、[`AnyDict`][any-dict]、[`Sort`][sort]等等。

由`comparable`值組成的陣列可以用`List.sort`排序，而可以對應到可比較值的值所組成的陣列，則可以用`List.sortBy`排序。
如果你需要階層式排序（先依某個屬性排序，遇到相同值時再依另一個屬性決定順序），可以把元組或陣列搭配`List.sortBy`使用（還有其他[替代方案][sort-by]），因為元組與陣列都是依字典序排序的。


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

函式`compare`接受兩個`comparable`值，並回傳一個`Order`。
`Order`是一種型別，能在單一操作中判斷某個值大於（`GT`）、等於（`EQ`）或小於（`LT`）另一個值。

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

比較函式可以為任意型別建構，並且能用在例如搭配`List.sortWith`進行排序：

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
