# 別理我

## 輸入

你的腳本會透過標準輸入（stdin）收到單一字串，也就是這個字母算術謎題。謎題字串的格式如下：`WORD1 + WORD2 + ... == RESULT`。

例如：

```text
SEND + MORE == MONEY
```

## 輸出

如果謎題有解，請輸出一行，由以空格分隔的 `LETTER=DIGIT` 配對組成，並依字母順序排序。

以上面的例子來說，輸出應該是：

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

如果謎題有多組有效解，輸出其中任何一組都可以。

如果謎題無解，就不要輸出任何內容（一行空行）。
