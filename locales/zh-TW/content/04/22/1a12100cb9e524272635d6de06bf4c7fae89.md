# 說明

你是沿海貨輪上的水手長。艙底是船體最底層的隔艙，會收集廢水；每到一班，艙底設備都得打開、運轉，然後收納歸位。無論抽水過程中發生什麼事，設備*一定*得回到收納狀態。

測試會提供`<test-pump>`讓你取得新的幫浦。每個幫浦都有一個`opened>>`槽位，開啟時讀值為`t`，處置後則為`f`。

## 1. 排空艙底

定義`drain-bilge`來釋放單一幫浦。對同一個幫浦呼叫`drain-bilge`兩次應該不會有任何問題，框架會替你處理。

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. 抽水程序

定義`pump-out`，讓它接受一個幫浦和一個引述，把幫浦推入堆疊供引述使用，然後在之後釋放幫浦，*即使引述拋出例外也一樣*。

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. 整班流程

定義`shift-routine`，讓它接受兩個幫浦和一個引述。開啟一個解構子作用域，把*兩個*幫浦都註冊為無條件釋放，然後呼叫引述。不論引述正常結束還是拋出例外，兩個幫浦最後都會被釋放。

引述會從堆疊接收這兩個幫浦作為輸入。

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. 有風險的抽水

有時候幫浦是借來的，只有在出錯時你才想丟棄它，否則下一班值班人員需要它保持開啟。定義`risky-pump-out`，讓它接受一個幫浦和一個引述，把幫浦註冊為**僅在失敗時**釋放，並帶著堆疊上的幫浦呼叫引述。

如果引述成功，幫浦會保持開啟。如果引述拋出例外，幫浦會被釋放，例外則會繼續向外傳播。

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. 自訂可處置物件：閥

用一個全新的可處置物件，也就是`valve`，來補齊工具組。元組已經替你宣告好了：

```factor
TUPLE: valve < disposable is-open ;
```

- 定義`<valve> ( -- valve )`，透過`new-disposable`建構一個全新的閥，並把`is-open`設為`t`。
- 實作`M: valve dispose*`，把`is-open`切換成`f`。

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
