# 簡介

## 比較運算子

R 有一組運算子，和許多其他程式語言相同：

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 分支

if-else 的基本形式是：

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

在這種情況下，布林值前後的括號`()`和主體前後的大括號`{}`都是必需的。

簡單的`if`敘述可以縮短成：

```R
if (x == 0) return("success")
```
