# 說明

在這個練習中，你要實作一種方法，用來追蹤你當地電動遊樂場裡最熱門遊戲的高分。

## 1. 定義新的高分映射

要建立新的高分映射，請定義 `HighScore.new/0` 函式，這個函式不接受任何引數，並回傳一個新的空高分映射。

```elixir
HighScore.new()
# => %{}
```

## 2. 將玩家加入高分映射

要將玩家加入高分映射，請定義 `HighScore.add_player/3`，這是一個接受 3 個引數的函式：

- 第一個引數是分數映射。
- 第二個引數是玩家的名字，型態為字串。
- 第三個引數是分數，型態為整數。這個引數是選用的，請把第三個引數的預設值設為 0。

請把預設的初始分數存在模組屬性裡，之後還會用到。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. 從分數映射中移除玩家

要從高分映射中移除玩家，請定義 `HighScore.remove_player/2`，它接受 2 個引數：

- 第一個引數是分數映射。
- 第二個引數是玩家的名字，型態為字串。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. 重設玩家的分數

要重設玩家的分數，請定義 `HighScore.reset_score/2`，它接受 2 個引數：

- 第一個引數是分數映射。
- 第二個引數是玩家的名字，型態為字串，也就是你想重設分數的玩家。

如果玩家還沒有分數，這個函式也應該能正常運作。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. 更新玩家的分數

要透過在先前分數上加分來更新玩家的分數，請定義 `HighScore.update_score/3`，它接受 3 個引數：

- 第一個引數是分數映射。
- 第二個引數是玩家的名字，型態為字串，也就是你想更新分數的玩家。
- 第三個引數是你想**加到**已儲存高分上的分數。

如果玩家先前沒有分數，這個函式也應該能正常運作，請假設先前的分數是 0。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. 取得玩家陣列

要取得玩家陣列，請定義 `HighScore.get_players/1`，它接受 1 個引數：

- 第一個引數是分數映射。

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
