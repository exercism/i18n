# 簡介

## 不透明型別

Gleam 中的不透明型別是一種自訂型別，只有定義該型別的模組才能建構或模式配對這種型別的值。當你希望某個型別只能以特定方式使用時，這就很有用。

不透明型別是用`opaque`關鍵字定義的。

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

這個`PositiveInt`型別適合用在需要整數、而且該整數必須大於或等於零的情境。一般的 Gleam `Int`無法勝任，因為它也可以是負數。

定義這個型別的模組可以定義一個函式來取得內部的整數值，也可以定義一個建立`PositiveInt`型別的函式，後者在傳入的值不是正數時會回傳錯誤。

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

有了這組 API，其他模組就無法建構出帶有負數值的`PositiveInt`，因此任何接受`PositiveInt`的函式都能確定這個值是正數。
