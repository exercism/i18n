# 未使用預設引數

這個解法在定義函式時沒有使用[預設引數][default argument]。
Python 的[預設引數][default arguments in python]可以協助避免函式被呼叫時沒有帶入預期的引數，或是沒有引數可傳入的情況。
`Default arguments`也能協助避免函式內不必要的條件式程式碼或檢查。

這個解法可以改用`default argument`，搭配 [str.format][str.format] 或 [f-strings][f-strings]（_也就是「格式化字串字面值」或「內插字串」_）。

Real Python 的 [String Formatting in Python][string formatting in python] 是學習 Python 各種字串格式化選項的好起點。
