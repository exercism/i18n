# 簡介

物件可以透過設定*實例變數*來保存自己的狀態，實例變數的建立方式是在變數名稱前面加上`@`。

```ruby
@name = 2
```

物件通常會在`initialize`方法中設定初始狀態，這個方法會在對類別呼叫`new`時自動被呼叫。

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

`initialize`方法也可以接受引數，讓每個實例都能以自訂的狀態開始：

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

把*實例*變數視為對外部的讀取和寫入而言是私有的。取得和設定實例變數時，應該使用*實例*方法：

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
