# 提示

## 一般

- 閱讀官方[入門指南][getting-started-processes]中關於行程的說明。
- 閱讀[這篇部落格文章][mullen-processes]，了解 Elixir 的行程。

## 1. 啟動機器

- 機器應該在新的行程中執行。有一個[內建函式可以啟動新的行程][kernel-spawn-1]。
- 啟動新行程時，使用 0 引數的匿名函式。這個函式還不需要做任何事。

## 2. 回報機器狀態

- 你會需要一個新的具名函式。你可以把它命名為`loop`之類的。
- 這個新函式應該接受一個引數：狀態。
- 前一步的 0 引數匿名函式可以呼叫這個新的具名函式，並傳入初始狀態。
- 這個新的具名函式需要回應訊息。
- 有一個[內建函式會等待訊息送達行程的信箱][kernel-receive]。
- 有一個[內建函式可以把訊息傳送給另一個行程][kernel-send]。
- 使用遞迴來等待多個訊息。

## 3. 發放號碼

- 這個步驟在概念上和前一個步驟相同。唯一的差別是需要更新機器的狀態。

## 4. 停止機器

- 這個步驟不需要傳送任何訊息作為回應。
- 如果行程沒有更多程式碼要執行，它就會結束。
- 當你需要在 Elixir 中建立一個「空的」程式碼區塊時，可以把`nil`當作該程式碼區塊中唯一的運算式。
- 這是遞迴函式的基礎情況。

## 5. 忽略非預期的訊息

- 這個步驟不需要傳送任何訊息作為回應。
- 你可以用`_`來比對所有不符合前述模式的訊息。
