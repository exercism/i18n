# 簡介

方法是一種帶有特殊_接收者_引數的函式。
接收者會出現在自己的引數清單中，介於`func`關鍵字和方法名稱之間。

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

只有當接收者的型別和方法定義在同一個套件裡時，你才能定義這個方法。

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

定義在結構體上的方法可以用點記法呼叫。

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

注意我們在`Person`實例`p`上呼叫`Greetings()`方法的方式。
這和你在物件導向程式語言中呼叫方法的方式完全一樣。

記住：方法就只是帶有接收者引數的函式。
方法有助於避免命名衝突，因為方法會綁定到特定的接收者型別，所以你可以在不同的型別上使用相同的方法名稱。

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

接收者分為兩種：值接收者和指標接收者。

到目前為止我們看過的方法都使用值接收者，這表示它們收到的會是傳入方法的值的副本，也就是說，在方法內對接收者所做的任何修改，都不會被呼叫端看見。

你可以宣告使用指標接收者的方法，藉此修改接收者所指向的值。
做法是在型別名稱前面加上`*`。
例如以`rect`型別來說，指標接收者會宣告成`*rect`。
這類修改同樣會被方法的呼叫端看見。

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
