# 簡介

## 基礎

在 F# 中，把值指定給一個名稱稱為_繫結_。繫結是不可變的，這讓它們很像其他語言裡的常數。由於 F# 是靜態型別語言，每個繫結在編譯時期就有一個型別。

繫結是用`let`關鍵字定義的。大多數繫結不需要指定型別，因為 F# 的_型別推論_通常可以根據它們的值推斷出型別。一個繫結長這樣：

```fsharp
// Automatically inferred type
let fingers = 10
```

函式也是普通的繫結，只是帶有一或多個參數。函式會自動回傳它的最後一個運算式。型別推論對大多數函式也適用，它會分析函式被呼叫時傳入什麼值，以及函式回傳什麼值。

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

要呼叫一個函式，就是指定它的名稱，並為函式的每一個參數傳入引數。

```fsharp
let five = add 2 3
```

如果繫結的型別無法被推斷，編譯器會回報錯誤。要修正這個問題，請為繫結加上明確的型別註解。

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F# 裡的繫結只能在定義_之後_使用。在繫結被定義之前使用它，會導致編譯錯誤。

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# 使用有意義的空白來定義作用域。這表示作用域是由程式碼以空格縮排所定義，相對於宣告繫結的那一行。預設慣例是使用四個空格縮排：

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F# 的繫結（包含函式）通常會組織在模組裡。模組會把相關的功能群組在一起，並使用`module`關鍵字定義。模組定義必須出現在它的繫結之前：

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# 支援兩種註解。單行註解前面會加上`//`，多行註解則插在`(*`與`*)`之間。
