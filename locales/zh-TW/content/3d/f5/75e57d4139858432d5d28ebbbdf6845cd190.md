# 簡介

Haxe 支援型別與欄位的執行階段反射。為了正確使用反射，必須先了解哪些操作受到支援、哪些不受支援。由於反射具有動態特性，這點無法總是在編譯階段就確定。

反射 API 由兩個類別組成：

- `Reflect`：輕量的 API，最適合用在匿名結構上，對類別的支援有限。
- `Type`：更強大的 API，可用來處理類別與列舉。

在下面的範例中，我們使用的是 JavaScript 目標：

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
