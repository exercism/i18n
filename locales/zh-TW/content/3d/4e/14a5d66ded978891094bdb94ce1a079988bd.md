# 測試

## clojure.test

Babashka 內建 clojure.test。當你準備好要進行某個練習，並且已建立用來存放解答的檔案（例如`bob.clj`）之後，就可以使用`clojure.test/run-tests`來執行測試，[做法如這裡所述](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests)。


The REPL 讓你輕鬆執行程式碼並立即獲得回饋，也可以用來執行測試。建議使用`rlwrap`來啟用行編輯，並用上下方向鍵瀏覽指令歷史。要測試練習，請切換到它的目錄，並開啟 socket REPL，將`src`和`test`目錄加入 classpath：
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

首先，使用`require`載入測試命名空間：
``` clojure
=> (require 'bob-test)
nil
```

然後對`bob-test`呼叫`run-tests`：
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

要建立測試執行器腳本：

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
