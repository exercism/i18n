# 簡介


## 布林值

PowerShell 有 [`bool`][booleans] 型別，用來表示 true 與 false 這兩種值。
這個型別只有兩個值：`True` 和 `False`。
你可以用前綴 `$` 把這些值繫結到變數：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

我們可以使用 `-and`、`-or` 和 `-not` 這類[邏輯運算子][logical-operators]來組合並求值布林運算式。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## 註解式說明

PowerShell 的 [`Comment-based help`][comment-based help] 能為以註解撰寫的函式和指令碼提供詳細資訊。
它使用特殊的說明註解關鍵字來指定要說明的主題，例如 `.SYNOPSIS`、`.EXAMPLE` 或 `.NOTES`。

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

你可以使用 `Get-Help` 這個 cmdlet 來顯示註解式說明的資訊。

```powershell
> Get-Help -Name "ExampleFunction"
```
