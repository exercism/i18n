# 說明

偵探的筆記本會隨著案件進行而寫滿，也會隨著調查方向被排除而再次清空。

五個任務全都放在`CASE_NOTES`類別中。

## 1. 開啟案件

回傳一本全新的空筆記本。

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. 寫下一條線索

把一條線索加到筆記本的最後面。這不會回傳任何東西，而是會改變傳入的筆記本。

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. 有多少條線索？

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. 排除一條線索

將某個位置的線索從筆記本中取出。它後面的所有線索都會向前移動。這同樣不會回傳任何東西。

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. 回顧案件

回傳筆記本中的每一條線索，並以`"; "`串接。空的筆記本會讀取為空字串。

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
