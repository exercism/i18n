# 指令

你是個熱衷的賞鳥者，會記錄過去七天有多少鳥造訪你的花園。

你有 5 個任務，全都和造訪你花園的鳥的數量有關。

## 1. 查看上週的計數

為了方便比較，你總是隨身保留一份上週的計數副本，分別是：0、2、5、3、7、8 和 4。實作 `BirdCount.last_week` 方法，回傳上週的計數：

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 查看昨天有多少鳥造訪

實作 `BirdCount#yesterday` 方法，回傳昨天有多少鳥造訪你的花園。鳥的計數是按日期排序的，第一個元素是最早那天的計數，最後一個元素則是今天的計數。

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. 計算造訪鳥隻的總數

實作 `BirdCount#total` 方法，回傳造訪你花園的鳥的總數：

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. 計算忙碌的天數

有些日子比其他日子更忙碌。忙碌的一天，是指有 5 隻以上的鳥造訪你的花園的那一天。
實作 `BirdCount#busy_days` 方法，回傳忙碌的天數：

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. 查看是否有完全沒有鳥造訪的一天

實作 `BirdCount#day_without_birds?` 方法，如果有一天沒有任何鳥造訪花園，就回傳 `true`；否則回傳 `false`：

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
