# 關於

[Python][python docs] 是一門[動態且強型別][dynamic typing in python]的[物件導向][object oriented programming]程式語言。它同時採用[鴨子型別][duck typing]與[漸進式型別][gradual typing]（透過[型別提示][type hints]）。它支援多種程式設計範式，包括指令式（_物件導向、程序式_）與宣告式（_函式式、並行_）等風格。但別被騙了：雖然跨範式的程式設計完全受到支援，[在 Python 裡，一切皆為物件][everythings an object]。


Python 由 Guido van Rossum 創作，並於 1991 年首次發布。[Python 軟體基金會][psf]負責管理並指導 Python 與 CPython 開發的資源，並透過 [Python 增強提案（PEP）][peps]接收社群[成員][psf membership]對語言變更的提案。對[剛踏上這段旅程][python for beginners]的程式設計師來說，它被公認是一門強健的語言，社群氛圍友善，各種程度與興趣的學習者都能找到豐富的資源。


Python 非常重視程式碼的可讀性，而且（_與 Haskell 類似_）使用[顯著縮排][significant indentation]來表示函式、方法與類別的定義。你可以在命令列、互動式翻譯員工作階段、[JupyterLab][jupyter]（Jupyter Notebook），或各式各樣的[程式碼編輯器與 IDE][editors for python] 中撰寫與執行程式碼。

[Python 的應用非常廣泛][python is used extensively]，涵蓋科學運算、金融、遊戲、網路、網際網路開發，以及串接其他程式的管線。


[Python 之禪（PEP 20）][the zen of python]與[什麼是 Pythonic？][what is pythonic]進一步闡述了這門語言的哲學與觀點。


這個 track 目前的測試與工具支援 `Python 3.10 - 3.13.7`（_測試_）與 [`Python 3.13.7`][313-new-features]（_工具_）。強烈建議學生至少升級到 `Python 3.10`，因為這個 track 所用的一些功能在較早的版本中可能不受支援。話說回來，大多數練習在 `Python 3.6+` 甚至更早的版本上都能運作。但未列在[現行 Python 版本][active-python-releases]中的版本，我們不保證支援。當某項功能只在特定版本中提供時，我們會盡量註明。
