# 資料庫付款批次

## 問題陳述

你必須將一批付款資料插入`Payment`資料表。你的任務是從提供的輸入 JSON 檔案讀取付款資料，並使用 JDBC Client 的`batchExecute`操作，將付款資料插入`Payment`資料表。範例輸入檔為`payments.json`。

輸入 JSON 檔案的內容以下列 JSON schema 為基礎。

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

你需要在不對資料庫發出額外查詢的情況下，回傳批次中已插入付款資料的自動產生付款 ID 作為輸出。

你可以假設`payments.json`檔案中提供的`employee_id`是有效的，且已存在於`Employee`資料表中。

## 資料庫詳細資訊

本問題請使用提供的 H2 資料庫。

> 範例資料庫檔案為`gofigure.mv.db`，資料庫名稱為`gofigure`。它位於`db`資料夾中。

下列資料表已存在於範例 H2 資料庫中，並含有一些範例資料。欄位名稱與資料型態如下。

**資料表名稱**：`Employee`

| **欄位：**      | 型態 |
| -----------       | ----------- |
| `employee_id`     | 整數，自動遞增主鍵       |
| `name`            | 字串        |
| `city`            | 字串        |
| `department`      | 字串        |
| `age`             | 整數        |

**資料表名稱**：`Payment`

| **欄位：**      | 型態 |
| -----------       | ----------- |
| `payment_id`      | 整數，自動遞增主鍵       |
| `date`            | 日期        |
| `amount`          | 小數        |
| `employee_id`     | 整數        |
| `reason`          | 字串        |

* 資料庫檔案為`gofigure.mv.db`。請將 JDBC URL 設為`jdbc:h2:file:/path/to/db/file`
* 使用者名稱：`root`
* 密碼：`root`

## 限制

* 使用`db`資料夾中提供的 H2 資料庫檔案來驗證查詢與 Ballerina 範例
* 使用 maven dependency params 的方式，在 Ballerina.toml 中將 H2 資料庫驅動程式新增為平台相依性
* 你需要在不對資料庫發出額外查詢的情況下，找出自動產生的付款 ID。

## 測試環境

* 你可以使用`bal test`執行測試，它會對提供的範例資料庫執行測試。

## 範例

### 範例 1

**輸入：** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

範例`payments.json`檔案資料：

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**輸出：**`[1,2,3]`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模組來操作資料庫
* 請參閱 [前置需求](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 一節，了解將 JDBC 驅動程式新增為相依性的步驟
* 使用 [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) 讀取 JSON 輸入檔案
* 將 JSON 值轉換為應用程式特定型別，以便以型別安全的方式處理資料。請參閱 [轉換為使用者定義型別](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) 範例
* 使用 [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) 與 [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) 遠端方法來操作資料庫
* 請參閱 [批次執行](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) 範例
