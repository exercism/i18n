# 簡介

使用`while`迴圈，只要某個條件成立，就能重複執行程式碼。
它的寫法是先寫`while`關鍵字，接著是包在括號裡的條件，最後是包在大括號裡、包含迴圈_主體_的程式區塊。

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript 也有 do-while 迴圈。
這種迴圈會先執行迴圈主體，再檢查條件。
當條件的判斷取決於主體程式碼的執行結果時，這就很實用。

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

在迴圈主體裡，你可以使用`break`關鍵字來完全停止迴圈的執行。
相對地，`continue`關鍵字只會停止目前這次疊代的執行，然後繼續下一次疊代。
有了`continue`，你通常可以避免把迴圈主體的一大部分包進`if`敘述裡。

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
