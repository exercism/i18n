# 簡介

陣列與列表包含一組有序的純量集合。
除了使用參照之外（這會在另一個概念中介紹），這表示陣列與列表永遠是平坦的，也就是說，它們無法包含其他陣列或列表。

在大多數情況下，列表會用括號 `()` 包起來，其中的元素以逗號 `,` 分隔。

陣列變數通常是透過把列表指定給它來填入，例如 `my @names = ('Alice', 'Bob', 'Charlie');`。

陣列或列表的元素可以透過下標指定索引來存取，例如 `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`。

Perl 的索引從 `0` 開始。
負索引會從陣列或列表的尾端開始往回數，例如 `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`。

## 函式

Perl 實作了許多可用來操作陣列與列表的函式，其中最實用的幾個是 [grep][grep]（用於產生一份經過篩選、符合條件的元素新列表）、[map][map]（用於把元素轉換成一份新的值列表），以及 [sort][sort]（用於產生一份重新排序後的新元素列表）。

用來操作陣列的函式則包括 [push][push]（把元素加到尾端）、[pop][pop]（移除最後一個元素）、[shift][shift]（移除第一個元素）、[unshift][unshift]（把元素加到開頭），以及 [splice][splice]（用於更複雜的修改）。

用 [for(each)][perlsynforeach] 敘述來疊代陣列與列表，也是你會經常遇到的情況。

## 符號變化

存取陣列的元素時，所使用的符號會決定結果。
變數名稱末尾的下標 `[]` 就是告訴 Perl，你正在存取該名稱的陣列。

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

雖然這是允許的，但為了可讀性，建議不要讓不同型別的變數共用同一個名稱。

## 陣列與列表的差異

陣列與列表有許多相似之處，在很多地方可以互換使用，但它們並不是同一個東西。
列表是一組固定且不可變的純量集合。
陣列則是一組可變的純量集合，其內容與陣列本身的大小都可以改變。

在某些情境下，它們的行為不同。
陣列用在純量情境時，會給你陣列的大小。
列表用在純量情境時，會給你列表中的最後一個元素，並且可能會出現一些警告，說其餘的內容被用在空情境中。

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
