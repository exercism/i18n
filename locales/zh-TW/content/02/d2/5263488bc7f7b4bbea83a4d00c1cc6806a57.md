# 關於

[switch 敘述][switch]讓你將一個值與多個可能的相符值進行比較。相較於使用多個`else-if`敘述，它能讓你寫出更精簡的程式碼。`switch`敘述以`switch`關鍵字開頭，後面接著要比較的值。接著，你可以用`case`關鍵字定義各種情況，後面接著要比對的值。當沒有任何情況相符時，則用`default`關鍵字定義預設情況。和`else-if`敘述一樣，`switch`敘述只會執行第一個相符情況所對應的程式區塊。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

看看下面這個例子：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

這段程式也可以改寫成：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 綁定與 `where`敘述

在`switch`敘述中被比對的值，也可以綁定到名稱上，並在情況的主體中使用這些名稱。這些名稱也可以用於`where`子句，`where`子句是額外的布林運算式，必須求值為`true`，情況才會相符。

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
