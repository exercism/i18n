# 提示

## 1. 建立包含所有車廂的向量

- 用經典的 for/while 迴圈搭配`push!`把元素加進`Vector`就能運作。
- 不然，用[`collect()`][collect]函式可以更簡潔。
- 或者，在向量建構子裡使用展開也行：

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. 修正車廂的向量

- 把前面的車廂和火車頭跟其他部分拆開會很有用，這樣才能用正確的順序重新組裝。
- 使用展開的多重賦值可能會幫上忙（請參考介紹）。

## 3. 新增缺少的停靠站

- 記住，這個函式不會改動輸入！請建立一個新的`Dict`。
- 只需要停靠站名稱，不需要站號，所以每一組都必須拆開。
- 組裝名稱向量有許多種方式：
  -  用 for/while 迴圈搭配`push!()`把元素加到`Vector`。
  -  陣列[推導式][comprehensions]
  -  用[`map()`][map]把函式套用到向量上。
  -  也可以對[匿名][anonymous]函式使用[廣播][broadcasting]：

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. 擴充路線資訊

- 把剩下的引數收集起來之後，`more_route_information`會是一個`Pairs()`集合。
- [`merge()`][merge]函式可以合併兩個以上的`Dict`，也能接受`Pairs()`集合。要把`Pairs()`集合明確轉換成`Dict`雖然可行，但沒有必要。
