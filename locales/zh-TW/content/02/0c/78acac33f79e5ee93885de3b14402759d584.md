# 位元操作

Crystal 提供了位元運算子，可以在二進位層級操作 [`Int`][ints]。

## 位移運算子

Crystal 提供了[位移運算子][shift]，可以將位元向左（`<<`）或向右（`>>`）位移。

### 左移（`<<`）

左移運算子（`<<`）會將位元向左位移。
要位移的值放在左邊，要位移的位數放在右邊。

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

如果數字是負數，就會改為向右位移。

```crystal
0b0010 << -1
# => 0b0001
```

### 右移（`>>`）

右移運算子（`>>`）會將位元向右位移。
和左移運算子一樣，要位移的值放在左邊，要位移的位數放在右邊。

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

同樣地，如果數字是負數，運算子就會改為向左位移。

```crystal
0b0100 >> -1
# => 0b1000
```

## 二元運算子

Crystal 有 3 個[二元運算子][binary]（`&`、`|`、`^`），以及一個用來執行位元運算的 `~` 運算子。

### 位元 AND（`&`）

二元 AND 運算子（`&`）會對兩個值執行位元 AND 運算。
它會把第一個值的每個位元，和第二個值中相同位置的位元做比較。
如果兩個位元都是 1，結果位元就會設為 1，否則設為 0。

```crystal
0b0011 & 0b1010
# => 0b0010
```

### 位元 OR（`|`）

二元 OR 運算子（`|`）會對兩個值執行位元 OR 運算。
它同樣會比較第一個值的每個位元，和第二個值中相同位置的位元。
只要其中一個位元是 1，結果位元就會設為 1，否則設為 0。

```crystal
0b0011 | 0b1010
# => 0b1011
```

### 位元 XOR（`^`）

二元 XOR 運算子（`^`）會執行位元 XOR 運算。
和位元 AND、位元 OR 運算子一樣，它會把第一個值的每個位元，和第二個值中相同位置的位元做比較。
如果兩者中_只有一個_是 1，結果位元就是 1，否則就是 0。

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### 位元 NOT（`~`）

最後，位元 NOT 運算子（`~`）會翻轉值的每個位元。
和其他二元運算子不同，這是一元運算子，只對右邊的值運作。

```crystal
~0b1110_0010
# => 0b0001_1101
```
