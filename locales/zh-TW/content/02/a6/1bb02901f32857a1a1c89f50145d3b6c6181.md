# 提示

## 一般

- 在元組名稱後面加上 _.n_，就能存取元組中個別的元素，其中 _n_ 是元素的索引，從 0 開始。

## 1. 取得玩具的名稱

- 你可以使用`.n`語法來存取玩具的名稱。

## 2. 新增玩具到資料庫

- 你可以使用元組語法`(name1: value1, name2: value2, ...)`來建立新的元組。

## 3. 更新玩具的數量

- 你可以使用 [`for` 迴圈][for-loop]，對裝有元組的陣列進行疊代，並更新玩具的數量。
- 你可以使用先前實作的函式來取得玩具的名稱。
- 你可以使用[條件式][conditional-statement]來確認玩具的名稱是否與你想更新的那個相符。
- 你可以使用`.n`語法來更新玩具的數量，例如：`toys.price = 3`。

## 4. 為玩具新增分類鍵

- 你可以使用 [`for` 迴圈][for-loop]，對裝有元組的陣列進行疊代，並為玩具新增分類鍵。
- 元組是不可變的，所以你需要建立一個加入分類鍵的新元組。

[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
