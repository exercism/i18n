# 關於

[TypeScript](https://www.typescriptlang.org/)（TS）是 JavaScript（JS）的超集合，由 Microsoft 所創造，起因是在 JS 中開發大規模應用程式時所遭遇的種種挫折。在大型 JS 專案裡，要掌握自己的物件有哪些屬性、自己的函式接受哪些引數（以及這些引數必須是什麼型別），往往會變得十分困難。同樣地，由於無法智慧地檢視 JS 程式碼，當你引入一個套件（例如從`npm`安裝的套件）時，就必須持續維護相關文件，才能知道有哪些方法可用、它們接受哪些引數。TS 解決了這些問題。它目前是一個託管在 Github 上的開源專案，支援任何瀏覽器上的工具，也支援 Node，適用於任何主機、任何作業系統。TS 會編譯成可讀、符合標準的 JavaScript。

除了介面（自訂型別）以及修改某些 ECMAScript 功能（例如類別）的語法之外，TS 也為 JS 加上了一套彈性的型別系統。型別是選用的，而且很有彈性（例如，你可以指定某個引數是字串或數字）。型別讓大多數程式碼編輯器提供的工具得以運作，改善開發體驗，例如程式碼補全與方法偵測，無論是在你自己的程式碼或你使用的套件裡都能派上用場。它支援許多即將到來的 ECMAScript 功能（例如 async/await）。TS 可以用物件導向或函式導向的風格撰寫。它與所有現有的 JS 套件相容。TS 會轉譯成乾淨、易讀的 JS。

到[練習場](https://www.typescriptlang.org/play)試試看吧，並透過 [TypeScript 部落格](https://devblogs.microsoft.com/typescript/)和 [Twitter 帳號](https://twitter.com/typescript)掌握最新消息。
