# 簡介

## 數字

Lua 的數字有兩種表示方式：64 位元整數與雙精度浮點數。它支援常見的算術運算子：加法、減法、乘法、除法與取負值。此外，它還支援向下取整除法、取餘數與次方運算。

| 運算子 | 範例               |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
