# 說明

在**Chrono Realms**裡，Time Keepers 要處理的不只是時間軸形成的樹，還有 **Chrono Chain**，也就是一連串相連的 **TimeNode**，每個節點代表時間中的某個特定時刻。
**Chrono Chain** 是由連續時刻構成的直線路徑，每個 **TimeNode** 都連向下一個節點。
當你需要穿梭於一連串特定事件時，**Chrono Chain** 就很好用，因為它讓 Time Keepers 能沿著單一時間軸前進。

不過，為了處理這些可能很長的 **Chrono Chain**，Time Keepers 會使用**智慧指標（Box<T>）**，安全地管理和走訪這些時刻串列，避免不必要的記憶體複製或溢位。
每個 **TimeNode** 都持有指向下一個節點的參考，形成遞迴結構。

身為學徒，你的任務就是用智慧指標把 **Chrono Chain** 實作成遞迴的串列結構。

在這道練習中，你會：

1. 建立一個遞迴的 `ChronoChain` 列舉，用來表示一串時刻。
2. 使用 `Box<T>` 智慧指標來儲存遞迴的節點。
3. 實作一個函式，從 `u32` 值的陣列建立 `ChronoChain`。
4. 實作一個函式，走訪 `ChronoChain` 並加總串列中儲存的值。

## 1. 定義遞迴的 `ChronoChain` 列舉

建立一個有兩個變體的遞迴列舉 `ChronoChain`：

- `End`：代表串列的結尾。
- `Link`：包含一個 `u32` 值，以及指向鏈中下一個節點的裝箱參考。

## 2. 建立 ChronoChain 的函式

撰寫一個函式 `ChronoChain::build`，接受 `u32` 值的陣列並回傳 `ChronoChain`，用智慧指標把這些值依序串接起來。

## 3. 實作加總函式

撰寫一個函式 `ChronoChain::sum`，遞迴走訪 `ChronoChain`，加總所有節點的值。

## 範例用法

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
