# 閏年的概念

我比較喜歡第一個範例解法，因為它簡潔的風格符合我所看過的慣用 Rust 寫法。它也避開了標準解法中額外引入的閉包概念。

## 萃取出的概念

### 一般

- 布林邏輯
  - 布林值
- 運算式
  - Rust 函式會隱含地回傳運算式
- 算術
  - 取模

### 型別

- 無號整數：`u64`
- 布林值：`bool`

## 範例練習 1

["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09) 的解法

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## 範例練習 2

[標準解法](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
