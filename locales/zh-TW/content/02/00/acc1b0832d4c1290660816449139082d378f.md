# Introduction

在 Elixir 中，元組是一種用來組織資料的資料結構，可保存固定數量、型別不拘的項目，但每個元素沒有明確的名稱。在 Elixir 中，元組常用於記憶體讀取密集的操作，因為讀取元素是常數時間的操作。當元素可能需要動態新增或移除時，通常不會使用元組，因為它不會修改現有的元組，而是建立新的元組，這需要事先配置記憶體。

在實務上，Elixir 使用大括號建立元組。元組中的元素可以透過`elem/2`函式，使用以 0 為基礎的索引個別存取：

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## 元組作為分組資訊

實務上，元組常用來表示分組資訊。

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
