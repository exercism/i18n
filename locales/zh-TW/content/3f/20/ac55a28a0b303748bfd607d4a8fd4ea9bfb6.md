# 簡介

## 匿名函式

在 Elixir 中，函式是一級公民。這代表：

- 具名函式和匿名函式都可以賦值給變數。
- 具名函式和匿名函式可以像資料一樣傳遞，作為引數和回傳值。
- 匿名函式可以動態建立。

與具名函式不同，匿名函式沒有可靜態參照的名稱，只有在賦值給變數或立即呼叫時才能使用。

我們可能會用匿名函式來：

- 利用詞法作用域（也稱為閉包）隱藏資料。
- 在執行階段動態建立函式。

匿名函式以保留字 `fn` 開頭，引數和函式主體之間以 `->` 符號分隔，並以 `end` 結束。和具名函式一樣，函式中最後一個運算式會_隱式回傳_給呼叫它的函式。

若要呼叫函式參照，必須在參照變數和引數列表之間使用 `.`：

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

你還可以使用簡寫的擷取語法，讓這段程式碼更簡潔：

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## 位元操作

Elixir 在 _Bitwise 模組_中提供了許多處理位元的函式。

- `band/2`：位元 AND
- `bsl/2`：位元左移
- `bsr/2`：位元右移
- `bxor/2`：位元 XOR
- `bor/2`：位元 OR
- `bnot/1`：位元 NOT

以下是使用位元函式的範例：

```elixir
Bitwise.bsl(1, 3)
# => 8
```

所有位元函式都只能處理整數。

如果你執行的是 Elixir 1.9 或更早的版本，需要在模組定義的開頭呼叫 `require Bitwise`，才能使用 _Bitwise_ 模組。
