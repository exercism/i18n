# 簡介

## 參數

這個練習會討論 C# 中方法參數的一些細節，以及它們的使用方式。

參數會將資訊從發出呼叫的方法傳遞給被呼叫的方法。

- 參數的行為可以透過使用`ref`和`out`等修飾詞來修改。

- 帶有`out`修飾詞的參數會將值從被呼叫的方法回傳給呼叫端。這個參數可以在未初始化的情況下傳遞給被呼叫的方法，而且無論如何，在被呼叫的方法內，它會被視為在進入方法時尚未初始化。要理解參數修飾詞的行為與規則，最容易的方式是透過範例（見下方）和編譯器訊息。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out`參數必須在被呼叫的方法內指定值。

- 帶有`ref`修飾詞的參數會將值傳入被呼叫的方法。當方法回傳時，呼叫端會看到被呼叫的方法對該參數所做的任何更新。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`參數必須是變數，因為被呼叫的方法會直接操作呼叫端所看到的參數。
- `out`和`ref`修飾詞在被呼叫的方法簽章與呼叫位置都必須同時出現。
