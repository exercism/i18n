# 說明補充

## 提示

要完成這個練習，你需要實作`slices`函式，它會接收一段*文字*，並回傳指定長度的數字子序列：

如果這是你第一次解這個練習，建議你先沿用提供的簽章：

```haskell
slices :: Int -> String -> [[Int]]
```

之後，不妨再回來看看這個問題，試試其他的資料型態和函式庫：

- `ByteString`，來自 *bytestring* 套件。
- `Sequence`，來自 *containers* 套件。
- `Text`，來自 *text* 套件。
- `Vector`，來自 *vector* 套件。

測試套件刻意設計成能接受幾乎任何合理的型別簽章，所以鼓勵你找出你認為最好的那一種。
