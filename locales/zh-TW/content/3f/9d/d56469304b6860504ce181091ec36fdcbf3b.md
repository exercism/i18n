# 指示

你家附近那家披薩店的老闆娘請你幫她計算不同披薩的烹調時間。在這個練習中，你會寫幾個函式來做這些計算。

你有三個任務。

## 1. 計算剩餘的烘烤時間（分鐘）

定義並實作`remainingMinutesInOven()`函式，計算披薩還需要在烤箱裡烤幾分鐘。

這個函式要接受一個**選用**參數（帶有預設值），代表披薩開始烘烤後已經過了幾分鐘。如果沒有傳入這個參數，就假設你才剛把披薩放進烤箱，已經過了**0（零）**分鐘。

為了簡單起見，我們假設所有種類的披薩都正好需要烤 40 分鐘才會好。

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. 計算準備時間（分鐘）

烘烤披薩之前，你需要準備麵團、把它桿開，再放上配料。

定義並實作`preparationTimeInMinutes()`函式，計算披薩放進烤箱前需要多少分鐘準備。

這個函式要接受一個**必填**參數（`numberOfIngredientTypes`），代表會用到幾種配料食材。

假設製作麵團並把它桿開需要 5 分鐘，而每**一種**配料則需要 2 分鐘。

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. 計算總共花費的時間（分鐘）

定義並實作`elapsedCookingTimeInMinutes()`函式，計算從準備、烘烤到上桌，披薩總共需要幾分鐘。計算時請使用前面步驟寫好的函式。

這個函式要接受兩個參數。第一個是**必填**的配料食材種類數量。第二個是**選用**的上桌時間（分鐘），如果沒有提供就當作是 0。

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
