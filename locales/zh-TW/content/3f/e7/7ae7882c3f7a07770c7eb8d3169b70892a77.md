# 簡介

Julia 鼓勵程式設計師盡可能把程式碼放進可以 JIT 編譯的函式裡，而且依照設計，建立許多小型函式本來就有很好的效能。

這樣一來，往往會留下許多小而簡單的函式，需要把它們組合起來，才能完成不簡單的任務。

一個顯而易見的做法是巢狀呼叫函式。
下面這個例子非常刻意，但足以說明重點。

```julia-repl
julia> first.(titlecase.(reverse.(["my", "test", "strings"])))
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

這種做法的缺點是，隨著巢狀層級越來越深，可讀性會迅速下降。

我們需要一個更簡單、更有彈性的做法。

## 合成

這是數學家鍾愛的技巧，而 Julia 沿用了數學的語法。

任意數量的函式都可以用`∘`運算子[`composed`][comp]在一起（輸入`\circ`後再按 Tab）。
結果可以當成單一個函式來用。

```julia-repl
julia> compfunc = first ∘ titlecase ∘ reverse
first ∘ titlecase ∘ reverse
julia> compfunc.(["my", "test", "strings"])
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
# alternative syntax, giving the same result
julia> (first ∘ titlecase ∘ reverse).(["my", "test", "strings"])
```

有幾點值得注意：

- 起始的函式出現的順序和巢狀時相同，執行時則是從右到左。
- 合成時不容易使用廣播，但可以在呼叫合成後的函式時套用。

## 管道

另一種做法可以想成是_程式設計師_的路線，而不是_數學家_的。

[`Pipelines`][comp]長久以來一直用在 Unix shell 指令碼中，近年也在主流程式語言裡流行起來（F# 有時被認為是率先採用它們的推手）。

基本概念是先有一份資料，然後讓它經過一連串函式，最後得到結果。

管道運算子是`|>`（和 F# 及近期的 R 版本一樣），不過 Julia 也提供了廣播版本`.|>`。

```julia-repl
julia> ["my", "test", "strings"] .|> reverse .|> titlecase .|> first
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

執行的方向現在嚴格由左到右，每個函式的輸出會順著箭頭的方向流動，成為下一個函式的輸入。

## 限制、變通做法和其他選項

用來示範合成與管道的函式全都只接受_單一_引數，這絕非巧合。

有些純函式語言會把_第一個_引數送進函式，同時允許附帶其他引數。

相較之下，Julia 在管道裡只接受函式_名稱_（或同等的東西），不能附帶任何額外的引數。

這背後有重要的技術原因（和[`currying`][currying]並非語言設計的標準一環有關）。
對柯里化毫無概念的_眾多_人，只要接受這項限制並非粗心大意造成的疏漏，而且未來幾版的 Julia 也不太可能改變就行了。

### 變通做法

我們需要只接受單一引數、又能完成各種所需工作的函式。
幸運的是，在 Julia 裡定義新函式很容易。

最簡單的方式是使用[`anonymous function`][anonymous-function]。
舉例來說，如果我們有一個輸入字串，想用底線把它切開：

```julia-repl
julia> "my_test_strings" |> (s -> split(s, '_'))
3-element Vector{SubString{String}}:
 "my"
 "test"
 "strings"
```

接著就能像之前一樣，把那個向量送進其他函式。

在這個例子裡，把匿名函式用括號包起來是可有可無的，但一般來說，這麼做有助於減少歧義。

同樣地，我們也可以在程式較早的地方建立一個具名函式，需要時再重複使用。
