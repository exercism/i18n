# 關於

Python 有三種不同的內建數字型別：整數（[`int`][int]）、浮點數（[`float`][float]）與複數（[`complex`][complex]）。
分數（[`fractions.Fraction`][fractions]）與十進位數（[`decimal.Decimal`][decimals]）也可以從標準函式庫匯入使用。

整數，包括十六進位（[_`hex()`_][hex]）、八進位（[_`oct()`_][oct]）與二進位（[_`bin()`_][bin]）數字，只要**不帶**小數點，也同樣算作`ints`：

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

含有小數點的數字（不論有沒有小數部分）會被視為`floats`：

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## 算術

Python 完整支援這些不同數字型別之間的算術運算。當這些數字與二元算術運算子（`+`、`-`、`*`、`/`、`//`與`%`）一起使用時，Python 會把範圍較窄的數字轉換成與較寬的數字相符的型別。

所有數字（複數除外）都支援所有[算術運算][arithmetic-operations]，並依照[運算子優先順序][operator precedence]求值。
複數在數學函式（`+`與`-`以外的）方面的支援，可以在 [cmath][cmath] 模組中找到。

### 加法與減法

加法與減法運算子的行為和一般數學相同。
如果運算元中有一個或多個是`float`，其餘的`int`也會被轉換成`float`：

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### 乘法

和加法與減法一樣，乘法也會把範圍較窄的數字轉換成與較寬的數字相符的型別：

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### 除法

除法一律回傳`float`，即使結果是整數也一樣：

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### 向下取整除法

如果需要`int`的結果，你可以用向下取整除法把結果截斷。
向下取整除法是使用`//`運算子來執行：

```python
>>> 6//5
1

>>> 6//2
3
```

### 取餘數

取餘數運算子（`%`）會回傳兩個運算元相除後的餘數：

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 left over
>>> 5 % 3
2
```

5 % 3 的另一種看法：

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## 次方運算

次方運算是使用`**`運算子來執行：

```python
>>> 2 ** 3
8

>>> 4 ** 0.5
2
```

## 型別轉換

你可以使用內建函式`int()`和`float()`，把數字從`int`轉成`floats`，或從`floats`轉成`int`：

```python
>>> int(3.45)
3

>>> float(3)
3.0
```

## 四捨五入

Python 提供了一個內建函式 [`round(<number>, <decimal_places>)`][round]，可以把浮點數四捨五入到指定的小數位數。
如果沒有指定小數位數，數字會四捨五入到最接近的整數，並回傳`int`：

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## 優先順序與括號

Python 允許你使用括號把運算式分組。
當你想覆寫預設的運算順序時，這就很有用。

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python 依照 [PEMDAS][pemdas] 規則決定運算子優先順序。
這表示`()`內的計算優先順序最高，接著是`**`，然後是`*`、`/`、`//`、`%`、`+`與`-`：

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 256, then 2 + 768
>>> 2 + 3 * 4 ** 4
770
```

## 精度與表示法

Python 的整數具有[任意精度][arbitrary-precision]，位數只受限於主機系統可用的記憶體。

浮點數通常是用 C 的`double`來實作（_15 位小數的精確度_），但表示方式會因主機系統而異。
複數則有`real`和`imaginary`兩個部分，兩者都由浮點數表示。

如果你想更深入了解各種程式語言中浮點數運算的問題與限制，可以看看 [0.30000000000000004.com][0.30000000000000004.com] 和 [The Python Tutorial][floating point math]。
