# 簡介

在 Rust 中，任何實作 [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) trait 的型別都可以當作疊代器。
Rust 內建的 [`collections`](https://doc.rust-lang.org/std/collections/index.html)可以透過`iter`、`iter_mut`和`into_iter`方法轉換成疊代器。
疊代器有各式各樣[強大的方法](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods)，例如`collect`、`map`、`filter`和`fold`，讓你對資料進行操作。

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
