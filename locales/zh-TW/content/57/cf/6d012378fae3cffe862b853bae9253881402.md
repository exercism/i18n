# 安裝 Java

除了 Exercism CLI 和你最愛的文字編輯器之外，用 Java 練習 Exercism 的練習題還需要 **Java Development Kit**（JDK）。JDK 同時包含 Java 執行環境_以及_開發工具（其中最重要的就是 Java 編譯器）。

現在 JDK 有許多不同的發行版，其中有些是開放原始碼的。在 Exercism，我們推薦使用 [Eclipse Temurin by Adoptium][adoptium]。

## 支援的 Java 版本

Exercism 的 Java 軌道支援 Java 25 LTS 及更早的版本。

## 安裝 Eclipse Temurin

要在你的系統上安裝 Eclipse Temurin，請前往他們很棒的[安裝說明][adoptium-installation-guide]。這裡可以找到用你慣用的套件管理器安裝 JDK 的說明，也提供了各大作業系統可下載的安裝程式連結。

## Java IDE

Java 有許多免費的 IDE 可以用。以下是一些熱門的選擇：

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code 的 Java 擴充功能][vscode-java]

## 接下來

你現在已經準備好開始使用 Exercism 的 Java 軌道了！

要開始的話，請參閱「[執行測試][exercism-java-tests-docs]」。
