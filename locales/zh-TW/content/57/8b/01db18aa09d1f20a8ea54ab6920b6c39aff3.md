# 說明

Lamont 是一個 Lisp 外星人，想要寫自己的電動遊戲。他們請你幫忙的其中一項任務，就是記錄高分表。

## 1. 建立高分表

請定義一個函式`make-high-score-table`，它不接受任何引數，並且會求值為一個新的空雜湊表：

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. 把玩家加入表中

要把玩家加入表中，請定義一個函式`add-player`，它接受兩個引數：
- 高分表
- 玩家的名稱，以關鍵字表示

把玩家的初始分數設為零。

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. 設定玩家的分數

要設定某位玩家的分數，請定義一個函式`set-score`，它接受三個引數：
- 高分表
- 玩家的名稱，以關鍵字表示
- 玩家的分數，以整數表示

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. 從表中取得分數

要從表中取得某位玩家的分數，請定義一個函式`get-score`，它接受兩個引數：
- 高分表
- 玩家的名稱，以關鍵字表示

這個函式應該求值為該玩家所儲存的分數。
如果該玩家沒有儲存任何分數，或是該玩家尚未加入表中，則求值為`0`。

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. 從表中移除玩家

要從高分表中移除玩家，請定義一個函式`remove-player`，它接受兩個引數：
- 高分表
- 玩家的名稱，以關鍵字表示

這個函式應該妥善處理玩家尚未加入表中的情況。
很明顯地，玩家被移除之後，若從表中取得他們的分數，結果會是零。

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
