# 說明補充

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                 |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | 輸入     | 位址 | 書籍字詞的陣列         |
| `$a1`    | 輸入     | 整數 | 書籍數量             |
| `$v0`    | 輸出    | 整數 | 價格，以美分為單位             |
| `$t0-9`  | 暫存 | 任意     | 用於暫時儲存  |
