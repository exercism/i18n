# 指令

在這個練習中，你會處理儲蓄帳戶。
每年，你的儲蓄帳戶餘額都會根據利率更新。
銀行給你的利率取決於你帳戶裡的金額（也就是餘額）：

- 餘額小於`0`美元：3.213%（餘額會變得更負）。
- 餘額大於或等於`0`美元且小於`1000`美元：0.5%。
- 餘額大於或等於`1000`美元且小於`5000`美元：1.621%。
- 餘額大於或等於`5000`美元：2.475%。

這個練習共有四個任務，每個任務都會運用到餘額和它的利率。

## 1. 計算利率

實作`interest_rate`函式，根據指定的餘額計算利率：

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. 計算利息

實作`yearly_interest`函式，根據指定的餘額計算利息：

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. 計算年度餘額更新

實作`annual_balance_update`函式，計算年度餘額更新，並將利率納入考量：

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. 計算達到目標餘額所需的年數

實作`years_until_desired_balance`函式，計算達到目標餘額所需的最少年數，並考量到每年都會把利息加進餘額中。
這代表一年後的餘額是：起始餘額 + 起始餘額的利息。
第二年後的餘額是一年後的餘額 + 一年後餘額的利息。
依此類推，直到當年的餘額大於或等於目標餘額為止。

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

注意，回傳的值是`int`。
