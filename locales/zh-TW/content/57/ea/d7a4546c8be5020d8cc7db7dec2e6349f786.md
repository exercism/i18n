# 簡介

`OpenStruct`讓你輕鬆地從 `Hash` 建立物件。不必透過 `Hash` 的鍵來存取，`OpenStruct`讓我們改用方法來存取和設定值。

```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

這個做法還有一個好處：使用區塊語法時，我們可以利用一個捷徑。當區塊只呼叫單一方法時，你可以用`&:`加上方法名稱來取代整個區塊。例如下面這兩行是同義的：

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## 標準函式庫

你在先前練習中看過的所有類別，都屬於 Ruby 的核心函式庫。

OpenStruct 是 Ruby 標準函式庫（常簡稱為「stdlib」）的一部分，這是一組用來處理日期、JSON、網路等項目的類別。它也提供一些實用的功能，讓你的程式碼更容易處理。

當你使用的類別不是來自核心函式庫時（例如放在其他檔案裡你自己的程式碼、來自 stdlib 的類別，或外部相依性），就必須先用`require`方法將它們匯入，才能使用。例如：

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
