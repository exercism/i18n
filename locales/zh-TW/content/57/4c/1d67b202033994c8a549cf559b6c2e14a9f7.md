# 指令補充

## 暫存器

| 暫存器 | 用途     | 型態    | 說明                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | 輸入     | 位址 | 以 null 結尾的輸入字串                      |
| `$v0`    | 輸出     | 布林值 | 輸入是否為等字母詞（`0` = `false`，`1` = `true`） |
| `$t0-9`  | 暫時 | 任意     | 用於暫存資料                        |
