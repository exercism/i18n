# 簡介

## Enum

`Enum`是一個非常實用的模組，提供了一組處理可列舉資料的演算法。它提供排序、篩選、分組、計數、搜尋、尋找最小/最大值等功能。

一般而言，_可列舉_是指任何可以被疊代的資料，也就是集合。在 Elixir 中，可列舉是指任何實作了`Enumerable`[協定][exercism-protocols]的資料型態。其中最常見的是[陣列][exercism-lists]和[映射][exercism-maps]。

許多`Enum`函式會接受函式作為引數。

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

最常見的`Enum`函式是`map`和`reduce`。

### `map/2`

`Enum.map/2`讓你可以把可列舉中的每個元素替換成另一個元素。`Enum.map/2`的第二個引數是一個函式，它接受原始元素並回傳取代它的新元素。

### `reduce/3`

`Enum.reduce/3`讓你可以把整個可列舉_縮減_成單一值。為了做到這件事，會使用一個稱為_累加器_的特殊變數。累加器會在每次疊代之間攜帶縮減過程的中間狀態。

`Enum.reduce/3`的第二個引數是累加器的初始值。第三個引數是一個函式，它接受一個元素和一個累加器，並回傳累加器的新值。

### 處理映射

當把映射和`Enum`函式一起使用時，映射會自動轉換成由 2 個`{key, value}`元組組成的陣列。

若要把它轉換回映射，請使用`Enum.into/2`。`Enum.into/2`是一個把可列舉轉換成可收集的函式，可收集是指任何實作了`Collectable`協定的資料結構。可以把它想成`Enum.reduce/3`的相反。

`Enum`也有`Enum.into/3`。`Enum.into/3`是`Enum.into/2`的變化版本，它接受一個轉換函式，在把可列舉轉換成可收集的過程中套用。

#### 對映射套用映射

除了使用`Enum.into/3`或`Enum.map/2`加上`Enum.into/2`來對映射套用轉換（映射）之外，我們也可以使用專門的`Map.new/2`函式。它的運作方式和`Enum.into/3`完全一樣，接受一個可列舉和一個轉換函式，但它一定回傳一個新的映射，而不是讓我們選擇可收集。
