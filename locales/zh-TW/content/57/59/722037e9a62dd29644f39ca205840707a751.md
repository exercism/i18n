# 映射與集合

陣列以編號的位置存放值。有時候，有用的標籤並不是數字。

## 映射

**映射**會把每個**鍵**和一項**目標**配成一對。用鍵去查，映射就會給你當初歸在那個鍵底下的東西。

`FMAP{K,T}`是從型別`K`的鍵對應到型別`T`的目標的映射。把動物名稱和牠的棲地配成對的 guide，就是`FMAP{STR,STR}`。

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## 一定要把答案指定回去

再看一次中間那一行。`insert`會回傳一個多了那組配對的映射，而這個答案必須保留下來：

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

這和`FSTR`的規則一樣，原因也一樣。答案通常就是進去的那個映射本身，只是就地被改過；偶爾，當映射沒有空間了，答案會是一個更大的映射。既然你分不出是哪一種，**請使用答案，並且不要再使用舊的名字。**`insert`之前留下來的名字可能已經過時，甚至可能根本不再描述一個可用的映射。

這也代表，把映射交給一個常式之後，它並不會因此就免於被改動。如果原本的映射必須保留下來，請看概念頁面上的`copy`。

## 鍵在不在？

`has_ind`會問某個鍵在不在映射裡。這個名字是「has index」的縮寫，index 就是這些映射對鍵的稱呼。

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

查一個不存在的鍵**不會**抱怨。`get`會回傳該型別的空值：`INT`得到零，`STR`則得到 void，而 void 之後會在其他地方出錯。所以要先看，再取：

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## 集合

**集合**存放的值不重複、也沒有順序。`FSET{T}`是型別`T`的值的集合。

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

同一樣東西插入兩次，只會留下一份。集合就是為了這個：收集東西，同時不去記每樣東西出現了幾次。

對集合呼叫`insert`會回傳之後要繼續用的集合，和映射完全一樣，所以每次都要把它指定回去。

## 有多少個

`.size`在兩者上都能用：映射裡有多少組配對，集合裡有多少個值。
