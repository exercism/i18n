# 指令

Boris 是個超級鐵道模型迷，決定要發行電子報，和全世界分享他的熱情。他會先寄出電子報的第一期給同樣熱愛這項嗜好的朋友和熟人，這些人的電子郵件地址存放在一個文字檔裡。

提示：檔案相關操作請使用 [simplifile](https://hexdocs.pm/simplifile/simplifile.html) 模組。

## 1. 從檔案讀取電子郵件地址

實作`read_emails`函式。它接受一個文字檔的路徑字串，該檔案包含以換行分隔的電子郵件地址，並回傳檔案中所有電子郵件地址的陣列。

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. 建立用來寫入的日誌檔

寄送電子郵件這件事，可能因為許多難以預期的原因而失敗，例如電子郵件地址打錯字，或是暫時的網路問題。為了確保你能重試寄信給所有朋友，又不會重複寄送，你需要記錄已經收到電子郵件的地址。為此，你會需要一個日誌檔。

實作`create_log_file`函式。它接受一個檔案路徑，並在該位置建立一個新的空檔案。

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. 記錄已寄出的電子郵件

實作`log_sent_email`函式。它接受日誌檔的路徑，以及一個包含電子郵件地址的字串。它會把該電子郵件地址寫入檔案，並在後面加上一個換行。

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. 寄送電子報

現在你已經有了寄信流程的所有積木，接下來需要把它們組合成單一個函式。

實作`send_newsletter`函式。它接受電子郵件地址檔案的路徑、日誌檔的路徑，以及一個會寄送電子郵件到指定地址的匿名函式。

它應該從給定的檔案讀取所有電子郵件地址，並嘗試寄送電子郵件給每一個地址。如果負責寄信的匿名函式回傳`Ok`值，就把該電子郵件地址寫入日誌檔。務必在寄出電子郵件後立刻這麼做。

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
