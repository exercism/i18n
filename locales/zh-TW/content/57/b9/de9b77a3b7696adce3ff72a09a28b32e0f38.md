# 補充說明

## 輸出格式

把菱形輸出成以 null 結尾的字串，每一列結尾都要有一個換行字元。

輸出結果會像這樣：`"  A  \n B B \nC   C\n B B \n  A  \n"`

## 暫存器

| 暫存器  | 用途         | 型別    | 說明                          |
| ------- | ------------ | ------- | ----------------------------- |
| `$a0`   | 輸入         | 位元組  | 字母                          |
| `$a1`   | 輸入/輸出    | 位址    | 以 null 結尾的結果字串        |
| `$t0-9` | 暫時性       | 任意    | 用於暫時儲存                  |
