# 簡介

`GENERIC:` 宣告會建立一個詞，它的行為取決於其中一個引數的*類別*。具體的行為則來自以 `M:` 定義的*方法*。

```factor
GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area
    side>> dup * ;
M: circle area
    radius>> dup * pi * ;
```

當 `area` 被呼叫時，Factor 會檢查堆疊頂端，找出類別相符且最特定的方法，然後執行它。使用區域變數時，你可以改用 `M::`：

```factor
TUPLE: rectangle width height ;

M:: rectangle area ( r -- n )
    r width>> r height>> * ;

T{ rectangle { width 3 } { height 4 } } area .   ! => 12
```

泛型讓你日後可以加入新的表示方式，而不必修改呼叫端的程式碼：`area` 原本就已經能用在 `square` 和 `circle` 上，而 `rectangle` 方法也會在每個呼叫 `area` 的地方自動被採用。

## 什麼時候適合使用泛型

在下列情況下，就該使用 `GENERIC:`：

- 同一個操作對不同的輸入有*真正不同*的實作。
- 你預期未來的程式碼會加入新的型別。
- 你希望型別系統強制每個類別各自定義。

如果變化只是少數幾個標籤的列舉，用 `case` 會更簡單。

## 用 `INSTANCE:` 加入 mixin

*mixin* 是一種*開放*的泛型類別，任何人都能把新的類別註冊為成員。Factor 內建的許多協定（sequence、set、stream 等）都以 mixin 的形式提供，因此自訂的 tuple 只要宣告自己是實例，就能採用該協定的預設方法：

```factor
MIXIN: shape
M: shape area                   ! a default area for any shape
    drop 0 ;

TUPLE: my-shape ;
INSTANCE: my-shape shape         ! my-shape is now a `shape`

T{ my-shape } area .   ! => 0
```

在 `INSTANCE:` 之後，每個預設方法 `M: shape …` 都會自動對 `my-shape` 進行分派，任何要求 `shape` 的程式碼也都能接受 `my-shape`。`M:` 用來為泛型加入方法；`INSTANCE:` 則用來讓類別加入 mixin。

## `TYPED::`：為一般詞的輸入加上檢查

`GENERIC:`/`M:` 會依引數的類別來選擇方法。有時你並不想分派，只想要*一個*詞，堅持它的輸入必須是特定類別。`TYPED::`（位於 `typed` 詞彙表中）就是 `::`，只是在每個輸入名稱後面寫上類別：

```factor
TYPED:: triple ( n: integer -- m )
    n 3 * ;

14 triple .   ! => 42
```

`n: integer` 的讀法就像你已經用過的區域變數，只是把類別寫在冒號後面。這裡沒有分派，只有一個定義、一種行為，但每個引數現在都會依其類別接受檢查：像 `"x" triple` 這樣不符的用法會被拒絕（*expected input value of type integer but got string*），而不是默默地通過。

輸出也可以用同樣的方式標註。`yes?` 同時標註了它的輸入和結果：

```factor
TYPED:: yes? ( word: string -- answer: boolean )
    word "yes" = ;

"yes" yes? .   ! => t
"no" yes? .    ! => f
```

## 數學函式與常數

這個練習也會用到幾個來自 `math.constants` 和 `math.functions` 的詞，你會在這裡第一次遇見它們：

- `pi`：來自 `math.constants` 的常數 π。
- `sin ( x -- y )`、`cos ( x -- y )`：以弧度表示之角度的正弦與餘弦。
- `e^ ( x -- y )`：`e` 的 `x` 次方。（若要使用任意底數，請用 `^`。）

```factor
pi 2 / sin   ! → 1.0
0 cos        ! → 1.0
1 e^         ! → 2.718281828459045
```
