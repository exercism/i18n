# 說明

你的任務是依照下列規則，把英文翻譯成 Pig Latin：

- **規則 1**：如果單字以母音開頭，就在單字結尾加上 "ay" 的音（例如 "apple" -> "appleay"）。
  請注意，單字開頭的 "xr" 和 "yt" 會發出母音（例如 "xray" -> "xrayay"、"yttria" -> "yttriaay"）。
- **規則 2**：如果單字以子音開頭，就把它移到單字結尾，然後在結尾加上 "ay" 的音（例如 "pig" -> "igpay"）。
  子音可以由好幾個子音組成，例如 "chair" 裡的 "ch" 或 "stand" 裡的 "st"（例如 "chair" -> "airchay"）。
- **規則 3**：如果單字以子音開頭，後面接著 "qu"，就把它們移到單字結尾，然後在結尾加上 "ay" 的音（例如 "square" -> "aresquay"）。
- **規則 4**：如果單字在子音串後面出現 "y"，或者 "y" 是雙字母單字裡的第二個字母，那它就會發出母音（例如 "rhythm" -> "ythmrhay"、"my" -> "ymay"）。
