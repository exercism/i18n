# 關於

用 `final` 關鍵字而不是 `var` 宣告的變數，只能指定一次值。

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

值得注意的是，對於像陣列或物件這類並非不可變的型別，`final` 可能不會產生預期的效果：

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
