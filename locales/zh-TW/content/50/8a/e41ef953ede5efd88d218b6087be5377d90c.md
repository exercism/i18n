# 關於

Java 是一種靜態型別的語言，這代表所有東西在編譯時期就已經有型別。把值指定給一個名稱，就稱為定義變數。

```java
int explicitVar = 10; // Explicitly typed
```

變數的值可以用[`=`運算子][assignment]來指定和更新。變數一旦定義之後，它的型別就永遠不會改變。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java 是物件導向的語言，所有的函式都必須定義在_類別_裡，而類別是用[`class`關鍵字][classes]定義的。類別裡的函式稱為_方法_。每個[方法][methods]可以有零個或多個參數。所有參數都必須明確標註型別，參數沒有型別推斷。同樣地，回傳型別也必須明確寫出來。函式使用[`return`關鍵字][return]回傳值。若要讓其他類別能呼叫某個方法，就必須加上`public`存取修飾子。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

呼叫方法時，要指定它的類別和方法名稱，並為方法的每個參數傳入引數。

```java
int sum = new Calculator().add(1, 2);
```

如果某個方法沒有用到任何類別的_狀態_（這道練習就是這種情況），就可以用`static`修飾子把它設為_static_。同樣地，如果一個類別只有靜態方法，它本身也可以用`static`修飾子設為靜態。

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Java 的作用域定義在`{`和`}`這兩個字元之間。

Java 支援兩種[註解][comments]。單行註解前面要加上`//`，多行註解則寫在`/*`和`*/`之間。

整數值是由一個或多個（連續的）數字組成，並支援[預設的數學運算子][operators]。
