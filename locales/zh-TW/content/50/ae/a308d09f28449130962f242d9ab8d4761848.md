# 關於

區域變數不會取代堆疊程式碼，而是與它並存。遇到下列情況時，就派得上用場：

- 同一個輸入被引用超過一次。
- 運算的自然順序與堆疊順序不一致。
- 你身處一個高階詞之中，它會一次把多個值交給 lambda（`assoc-map`的`( key value -- newkey newvalue )`）。

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]`會在引述或監聽器中引入區域綁定，否則`:>`就沒有詞法作用域可以綁定：

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

`:>`的變更後綴讓你可以重新綁定區域變數，這在感覺很命令式的迴圈中很實用：

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
