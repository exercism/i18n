# 說明

在這個練習中，你會和最要好的朋友一起玩一款名為「巫師與戰士」的角色扮演遊戲。你是遊戲主持人，負責讓遊戲世界在玩家眼前活起來。其中一個關鍵環節，就是把遊戲的種種描述給玩家聽：角色的狀態是什麼、他們造訪的城鎮長什麼樣子，等等。

你有 5 個任務，要把遊戲的各個部分描述給玩家聽喔。

## 1. 描述角色

每個角色都有職業、等級和生命值，描述方式為：`"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`。請實作（靜態）`GameMaster.Describe`方法，讓它接受一個`Character`作為唯一參數，並回傳該角色的描述。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 描述目的地

每個目的地都有名稱和居民數量，描述方式為：`"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`。請實作（靜態）`GameMaster.Describe`方法，讓它接受一個`Destination`作為唯一參數，並回傳該目的地的描述。

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 描述移動方式

角色可以用下列兩種方式的其中一種前往目的地：

- 步行，描述方式為：`"You're traveling to your destination by walking."`
- 騎馬，描述方式為：`"You're traveling to your destination on horseback."`

請實作（靜態）`GameMaster.Describe`方法，讓它接受一個`TravelMethod`作為唯一參數，並回傳其描述。

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. 描述角色前往目的地

當角色前往某個目的地時，描述會由各段個別描述組合而成：`"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`。請實作（靜態）`GameMaster.Describe`方法，讓它接受`Character`、`Destination`和`TravelMethod`作為參數，並回傳其描述。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 描述角色前往目的地但不指定移動方式

在大多數情況下，角色都是步行前往目的地。為了方便起見，玩家可以省略不提移動方式，此時會假設移動方式為步行。請實作（靜態）`GameMaster.Describe`方法，讓它接受`Character`和`Destination`作為參數，並回傳其描述。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
