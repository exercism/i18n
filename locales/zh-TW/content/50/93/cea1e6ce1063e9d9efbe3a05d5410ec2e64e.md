# 關於

「Racket（舊名 PLT Scheme）是一門通用、多範型的程式語言，屬於 Lisp/Scheme 家族。它的設計目標之一，是成為建立、設計與實作語言的平台。這門語言應用於各種場景，例如腳本撰寫、通用程式設計、資訊科學教育與研究。」 - [維基百科][wikipedia racket page]

你可以透過幾本不同的書來學習 Racket 的基礎。可以先看看 [*How to Design Programs*][htdp]，用稍微不那麼嚴謹但很有趣的 [*Realm of Racket*][realm] 自己做遊戲，或是用 [*Racket Programming the Fun Way*][the fun way] 探索 Racket 豐富多樣的函式庫。

看看[官方語言網站][racket homepage]和 [Github 儲存庫][racket github]。你可以在 [Twitter][racket twitter]、[郵件清單][racket listserv]、[Discord][racket discord] 和 [Slack][racket slack] 上找到這個社群。
