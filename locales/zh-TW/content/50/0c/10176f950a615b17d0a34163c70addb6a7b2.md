# 關於

和其他語言一樣，C++ 也提供了 `switch`敘述。
`switch`敘述是撰寫冗長的 `if ... else if` 敘述時更簡短的方式。
要建立一個 switch，我們先使用關鍵字 `switch`，後面接著一個整數。
接著用 `case` 關鍵字宣告每一個條件。
我們也可以宣告一個 `default` 分支，當前面沒有任何 `case` 條件相符時就會執行。
每個分支都應該以 `break`（或 `return`）敘述結尾。

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## 貫穿

switch 結構有一件重要的事：程式碼會繼續執行，直到被 `break`（或 `return`）敘述中止為止。
這可能會導致非預期的行為。

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

這種繼續執行的特性，主要用途是讓同一個敘述帶有多個標籤。
多個 switch 的結果可以對應到同一段要執行的程式碼。
這樣一來（例如在訂房應用程式中），人數為 2 和 3 時所呼叫的函式就可以是同一個：
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
如你所見，與其他語言相比，C++ 的 `switch`敘述非常受限。
許多語言可以根據布林運算式，甚至正規表示式來做 switch。
你可以把 C++ 版本想成一種擴充的 goto/switch 結構。
只有 `switch`敘述能跳至標籤。
之後其他所有標籤都會被忽略，你必須使用 `break` 敘述才能跳出程式區塊。
~~~~
