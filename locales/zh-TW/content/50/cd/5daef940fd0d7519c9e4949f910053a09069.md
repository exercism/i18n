# 內部連結

透過 Exercism 的 Markdown 解析器渲染出來的連結，會被檢查是否為內部連結；如果是，就可能加上提示框。

某個概念的提示框可能長得像這樣：

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## 使用方式

要讓連結以這種方式裝飾，並沒有特殊的語法。
我們會改為檢查連結的 href 是否符合下列兩種形式之一：

- URL，例如 https://exercism.org/tracks/ruby/concepts/basics
- 絕對路徑，例如 /tracks/ruby/concepts/basics

我們目前不支援相對 URL（例如以 `./` 或 `../` 開頭的），因為 Markdown 解析器並不知道它所渲染文件的脈絡、它渲染時所在的脈絡，也不知道 git 儲存庫的結構。

## 替代方案

除了使用一般連結，你也可以改成渲染 Widget。
這種元件通常放在文件最後，用來推薦延伸閱讀，或是推薦能從中學到東西的好練習。

詳情請參閱 [Widget 的說明文件](/docs/building/markdown/widgets)。
