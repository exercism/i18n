# 關於

Swift 的標準函式庫雖然提供了豐富的功能，但你可以透過匯入外部的函式庫和框架，使用更多額外的功能。
這些模組可能直接來自 Swift 專案（例如 [Swift Argument Parser][argument-parser]）、來自 Apple 平台的框架（例如 [Foundation][apple-foundation] 和 [Network Framework][network-framework]），或是來自第三方的開源函式庫（例如 [SwiftyBeaver][swifty-beaver]）。

像 Foundation 這類核心模組（它是 Swift 中使用最廣泛的函式庫之一）已隨 Swift 工具鏈一併提供。
第三方函式庫則必須先加入專案設定（例如使用 Swift Package Manager），才能被匯入。

要匯入模組，請寫下 `import` 關鍵字，後面接著模組名稱：

```swift
import Foundation
```

匯入模組後，你的程式碼就能使用它提供的型別、方法和函式。
舉例來說，匯入 Foundation 會為 `String` 擴充一些實用的方法，例如 `components(separatedBy:)`。

依照慣例，`import` 敘述會放在 Swift 檔案的開頭，這樣任何閱讀程式碼的人都能立刻看出相依性。

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
