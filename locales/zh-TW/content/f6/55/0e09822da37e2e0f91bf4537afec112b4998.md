# 範例

## MoonScript 專屬說明

在這個練習中，你會需要用到 Lua 內建的 [`os.date`][lua-os-date] 和 [`os.time`][lua-os-time] 函式。

- `os.time(tbl)` 會把包含「日期時間規格」的 table 轉換成整數值。它的引數是一個 table，裡面包含 "year"、"month" 和 "day" 這些鍵，另外還可以有 "hour"、"min"、"sec" 和 "isdst"。

- `os.date(format, time)` 會把整數時間值轉換成格式化後的字串。格式字串的說明請參考 [`strftime(3)`][strftime] 的 man page。

[lua-os-date]: https://www.lua.org/manual/5.4/manual.html#pdf-os.date
[lua-os-time]: https://www.lua.org/manual/5.4/manual.html#pdf-os.time
[strftime]: https://manpage.me/index.cgi?apropos=0&q=strftime&sektion=3&manpath=Debian+8.1.0&arch=default&format=html
