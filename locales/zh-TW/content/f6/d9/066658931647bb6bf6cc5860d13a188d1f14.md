# 指令

在這個練習中，你是個超級運動迷，而且你最近剛愛上 NBA 籃球。因為剛接觸 NBA 籃球，你正深入鑽研 NBA 的歷史，追蹤各支球隊、教練和他們的勝敗戰績，並互相比較。

由於你還沒有最喜歡的球隊，你也會開發一套演算法，判斷是否該支持某支球隊。

你有 7 個任務，幫助你開發專屬於你的*支持球隊*演算法。

## 1. 定義模型

定義`Coach`記錄，包含以下 2 個欄位：

- `Name`：教練的名字，型別為`string`。
- `FormerPlayer`：指出這位教練是否為前球員，型別為`bool`。

定義`Stats`記錄，包含以下 2 個欄位：

- `Wins`：勝場數，型別為`int`。
- `Losses`：敗場數，型別為`int`。

定義`Team`記錄，包含以下 3 個欄位：

- `Name`：球隊的名字，型別為`string`。
- `Coach`：球隊的教練，型別為`Coach`。
- `Stats`：球隊的戰績，型別為`Stats`。

## 2. 建立球隊的教練

實作`createCoach`函式，接受教練的名字和是否為前球員的狀態作為參數，並回傳它的`Coach`記錄：

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. 建立球隊的戰績

實作`createStats`函式，接受勝場數和敗場數作為參數，並回傳它的`Stats`記錄：

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. 建立球隊

實作`createTeam`函式，接受球隊名字、教練和記錄作為參數，並回傳它的`Team`記錄：

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. 替換教練

NBA 球隊老闆們沒什麼耐心，你發現球隊戰績不佳時，教練往往會被換掉。實作`replaceCoach`函式，接受球隊和它的新教練作為參數，並回傳換上新教練之後的球隊：

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. 檢查是否為同一支球隊

在深入鑽研戰績的過程中，你會整理一份份球隊和它們戰績的清單。有時候你會弄錯，清單上就會出現重複的項目。實作`isSameTeam`函式，接受兩支球隊，如果它們是同一支球隊就回傳`true`；否則回傳`false`：

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. 檢查你是否該支持某支球隊

看過許多球隊和比賽之後，你想出了一套演算法。只要符合下列其中一項，你就支持那支球隊：

- 教練的名字是 "Gregg Popovich"
- 教練是前球員
- 球隊的名字是 "Chicago Bulls"
- 球隊贏了 60 場以上的比賽
- 球隊的敗場數比勝場數多

實作`rootForTeam`函式，接受一支球隊，如果你應該支持該球隊就回傳`true`；否則`return` false：

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
