# 提示

## 一般

- `Vector`的索引從`1`開始。
- 牌組中不會有重複的牌。

## 1. 判斷某張牌是否存在

- Base 中有一個方法 [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in)，可用來判斷某個集合是否含有某個值。

## 2. 找出某張牌的位置

- Base 中有一個方法 [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any})，可用來找出集合中第一個符合給定述詞的元素的位置。
- 在接收述詞函式的方法中，可以使用`==(x)`作為述詞，找出等於`x`的元素。

## 3. 判斷每張牌是否為偶數

- Base 中有一個方法 [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any})，若集合中所有元素都符合給定述詞，便會回傳`true`。
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) 是一個述詞函式。

## 4. 檢查牌組是否含有奇數值的牌

- Base 中有一個方法 [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any})，若集合中有任何元素符合給定述詞，便會回傳`true`。
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) 是一個述詞函式。

## 5. 找出第一張偶數牌的位置

- Base 中有一個方法 [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any})，可用來找出集合中第一個符合給定述詞的元素的位置。
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) 是一個述詞函式。

## 6. 從牌組中取得第一張奇數牌

- 你可以用`v[n]`取得向量`v`中的第`n`個值。
- Base 中有一個方法 [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any})，可用來找出集合中第一個符合給定述詞的元素的位置。
- 如果給定集合中沒有任何元素符合傳給`findfirst`的述詞，`findfirst`會回傳`nothing`。
- 複習一下`nothing`在 Julia 中的運作方式：[concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- 複習一下 Julia 中條件式的運作方式：[concept:julia/conditionals](../../../../concepts/conditionals/about.md)
