# 簡介

## 數字

許多程式語言都有特定的數字型別，用來表示不同種類的數字，但 JavaScript 只有兩種：

- `number`：一種數字資料型態，採用雙精度 64 位元浮點數格式（IEEE 754）。
  例如 `-6`、`-2.4`、`0`、`0.1`、`1`、`3.14`、`16.984025`、`25`、`976`、`1024.0` 和 `500000`。
- `bigint`：一種數字資料型態，能用任意精度格式表示_整數_。
  例如 `-12n`、`0n`、`4n` 和 `9007199254740991n`。

如果你需要任意精度，或是要處理極大的數字，就用 `bigint` 型別。
否則，`number` 型別通常是比較好的選擇。

### 數值捨入

JavaScript 有一個內建的全域物件`Math`，它提供各種[數值捨入函式][ref-math-object-rounding]。
例如，你可以把小數向下取整（`floor`）或向上取整（`ceil`），得到最接近的整數。

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## 算術運算子

JavaScript 提供 6 種不同的運算子，用來對數字執行基本的算術運算。

- `+`：加法運算子，用來求數字之和。
- `-`：減法運算子，用來求兩個數字的差。
- `*`：乘法運算子，用來求兩個數字的乘積。
- `/`：除法運算子，用來把兩個數字相除。

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`：餘數運算子，用來求相除之後的餘數。

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`：指數運算子，用來把數字提升到某個次方。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### 運算順序

當一行裡用到多個運算子時，JavaScript 會依照[這份優先順序表][mdn-operator-precedence]所顯示的優先順序來計算。
簡單來說，在我們這個情境裡，JavaScript 用的是小學數學課學過的 PEDMAS 規則（括號、指數、除法／乘法、加法／減法）。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### 簡寫賦值運算子

簡寫賦值運算子是一種更簡短的寫法，用來對變數做算術運算，並把新的值賦予同一個變數。
例如，想想兩個變數`x`和`y`。
那麼，`x += y`就等同於`x = x + y`。
通常，這裡用的會是數字，而不是變數`y`。
其他 5 種運算也可以用類似的寫法。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
