# 簡介

## 整數

C# 和許多靜態型別語言一樣，提供了多種代表整數的型別，每種型別各有自己的值範圍。在範圍最小的一端，`sbyte`型別的最小值是 -128，最大值是 127。就像所有整數型別一樣，這些值可以透過`<type>.MinValue`和`<type>.MaxValue`取得。在範圍最大的一端，`long`型別的最小值是 -9,223,372,036,854,775,808，最大值是 9,223,372,036,854,775,807。介於兩者之間的是`short`和`int`型別。

這些範圍取決於系統為該型別配置的儲存寬度。例如，`byte`使用 8 個位元，`long`則使用 64 個位元。

上述每種型別都有一個對應的不帶正負號版本：`sbyte`/`byte`、`short`/`ushort`、`int`/`uint`和`long`/`ulong`。在所有情況下，值的範圍都是從 0 到負的帶正負號最大值乘以 2 再加 1。

| 型別   | 寬度   | 最小值                     | 最大值                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 位元  | -128                       | +127                        |
| short  | 16 位元 | -32_768                    | +32_767                     |
| int    | 32 位元 | -2_147_483_648             | +2_147_483_647              |
| long   | 64 位元 | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 位元  | 0                          | +255                        |
| ushort | 16 位元 | 0                          | +65_535                     |
| uint   | 32 位元 | 0                          | +4_294_967_295              |
| ulong  | 64 位元 | 0                          | +18_446_744_073_709_551_615 |

一個型別的變數（或運算式）可以輕鬆轉換成另一個型別。舉例來說，在指定運算中，如果被指定的值的型別（lhs）能確保該值落在被指定目標的型別範圍內（rhs），那就只需要一個簡單的指定：

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

另一方面，如果來源型別的範圍不是目標型別值範圍的子集，即使該特定值落在目標型別的範圍內，仍然需要進行轉型，也就是`()`運算：

```csharp
short s = 42;
uint ui = (uint)s;
```
