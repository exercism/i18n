# 簡介

在 Elm 中，字元和字串是文字表示的基礎。
字串可以想成是字元的陣列，而大多數`List`函式在`String`模組中都有對應的版本。

## 字元

`Char`型別以單引號表示單一的 Unicode 字元，例如`'a'`。
`Char`模組提供述詞函式（`Char -> Bool`）來測試字元的性質：`isUpper`、`isLower`、`isAlpha`和`isAlphaNum`。
這個模組也提供轉換字元的函式：`toUpper`、`toLower`、`toLocaleUpper`和`toLocaleLower`，以及用`toCode`和`fromCode`在字元與其 Unicode 數值（`Int`）之間互相轉換。

## 字串

`String`型別提供了內建的表示法，能有效率地操作字串，並可表示任何 Unicode 字元序列，例如 "this is an Elm string."。
多行字串以三個雙引號表示，可以包含未跳脫的引號和換行。
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## 字串函式

`String`模組包含下表摘要的所有函式。
以下是一些最常用的函式：

`cons : Char -> String -> String`會在字串的開頭加入一個字元。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String`會串接兩個字串。
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String`會依指定的分隔符號把字串拆成字串的陣列。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`會用指定的分隔符號把字串的陣列串接起來。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String`會取代指定子字串的所有出現處。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int`會回傳字串中的字元數。
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int`會嘗試把字串轉成`Just Int`，若字串格式不正確則回傳`Nothing`。
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool`會檢查第二個字串是否包含第一個字串。
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String`會把指定的函式套用到字串中的每個`Char`。
請注意，提供的函式必須是`Char`到`Char`的對應。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
