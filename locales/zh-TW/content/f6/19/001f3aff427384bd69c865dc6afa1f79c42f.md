# 指示

學校話劇裡的每個角色都有一名替角：一個能在需要時上場、把這個角色該做的事做好的人，而舞台監督不會知道他是誰。

五個任務全部放進 `UNDERSTUDY` 類別。前兩個是一般的常式，後面的任務會把她們綁定起來。

## 1. 兩種說台詞的方式

寫一個`shout`，回傳大寫的台詞；再寫一個`whisper`，回傳小寫、而且前後各加上`"..."`的台詞。

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. 排練一句台詞

`rehearse`接受一句台詞和一種說它的方式，並回傳結果。它的第二個引數型別是`ROUT{STR}:STR`。

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. 整場戲

`run_scene`接受一個台詞陣列和一種說它們的方式，回傳把它們全部用那種方式說出來、並以`" "`連接起來的結果。

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

空的場景就是空字串。

## 4. 交還一種說台詞的方式

`understudy_for`接受一個風格名稱，也就是`"shout"`或任何其他東西，並回傳一個`ROUT{STR}:STR`。`"shout"`會得到大喊的那個常式，其他任何東西則會得到低語的那個常式。

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. 固定一個引數

寫一個`repeat`，接受一個次數和一句台詞，回傳把台詞重複那麼多次、中間什麼都沒有的結果：

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

接著寫一個`doubler`，它不接受任何引數，回傳一個`ROUT{STR}:STR`，會把傳進來的東西重複兩次。做法是把次數先填好，再綁定`repeat`。

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
