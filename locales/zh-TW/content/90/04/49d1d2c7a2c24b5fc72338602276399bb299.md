# 說明

在這份說明中，你會寫一些程式碼，幫助你照著最愛的食譜做千層麵。

你有四項任務，全都和烹調這道食譜有關。

## 1. 定義預期的烤箱時間（分鐘）

定義 `lasagna.oven_time` 這個表格欄位，表示千層麵應該待在烤箱裡幾分鐘。根據這本食譜，預期的烤箱時間是 40 分鐘：

```lua
lasagna.oven_time
-- => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義 `lasagna.remaining_oven_time` 函式，它接受千層麵已經待在烤箱裡的分鐘數作為引數，並根據上一項任務的預期烤箱時間，回傳千層麵還需要待在烤箱裡幾分鐘。

```lua
lasagna.remaining_oven_time(30)
-- => 10
```

## 3. 計算準備時間（分鐘）

定義 `lasagna.preparation_time` 函式，它接受你加進千層麵的層數作為引數，並回傳你花多少分鐘準備千層麵，假設每一層要花你 2 分鐘準備。

```lua
lasagna.preparation_time(2)
-- => 4
```

## 4. 計算經過的作業時間（分鐘）

定義 `lasagna.elapsed_time` 函式，它接受兩個引數：第一個引數是你加進千層麵的層數，第二個引數是千層麵已經待在烤箱裡的分鐘數。這個函式應該回傳你總共花了幾分鐘烹調千層麵，也就是準備時間的分鐘數，加上千層麵目前為止待在烤箱裡的分鐘數。

```lua
lasagna.elapsed_time(3, 20)
-- => 26
```
