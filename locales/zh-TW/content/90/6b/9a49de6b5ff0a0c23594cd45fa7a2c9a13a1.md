# 說明

ESA（Exercism 太空總署）正全力規劃一趟前往火星衛星[火衛一][phobos]的新任務。
這項任務的目標是讓探測器降落在火衛一表面，並回傳關於該表面的資料。
ESA 請你協助打造探測器的導航電腦。
導航電腦的記憶體有限，所以我們得盡可能降低記憶體用量。
因此，我們需要選用合適的資料型態。

## 1. 導航常數

導航電腦需要知道太空中某些物體之間的距離，才能進行正確的計算，距離以公里為單位。

定義下列常數：

- `NEPTUNE_DISTANCE`，值為 `4_400_000_000`，應以 `Int64` 儲存
- `MARS_DISTANCE`，值為 `227_940_000`，應以 `Int32` 儲存
- `ATMOSPHERE_DISTANCE`，值為 `10_000`，應以 `Int16` 儲存

## 2. 修正面積分析

導航電腦需要知道太空中某些物體的面積，才能進行正確的計算。
面積**不可能**是負值。
工程師原本規劃讓程式在面積為負值時產生溢位錯誤。
不過，工程師忘了把有號整數改成無號整數。

因此，工程師希望有一個能把有號整數轉換成無號整數的程式。

請實作 `Navigation#correct_area_analysis` 方法，它接受 `measurement` 作為引數，並以 32 位元的無號整數回傳面積。

~~~~exercism/note
給定的面積一定可以用 32 位元的無號整數表示。
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. 計算速度

導航電腦需要知道探測器的速度。
速度以 m/s 為單位。

要計算速度，我們需要知道移動的距離，以及移動這段距離所花的時間。
接著，把距離除以時間。

速度不必很精確，也永遠不會是很大的數字。
因此，我們可以使用 `Float32`。

請實作 `Navigation#calculate_velocity` 方法，它接受 `distance` 和 `time` 作為引數，並以 32 位元的`Float`回傳速度。

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
