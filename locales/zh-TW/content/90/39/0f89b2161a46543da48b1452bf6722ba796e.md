# Unison 基礎

## 詞項與函式

詞項與函式是撰寫 Unison 程式時的基本單位。

所謂「詞項」就是我們對靜態值的稱呼。它的定義方式是 `name = expression`，前面可以選擇性加上形式為 `name : MyType` 的型別簽章。Unison 支援型別推論，所以在簡單的定義中，你可能會看到型別簽章被省略。

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

Unison 函式的形式類似 `myFunctionName argument1 argument2 = myImplementation`，開頭是函式名稱，後面接著以空格分隔的引數。

```
getMax a b = Nat.max a b
```

函式可以選擇性加上型別簽章。最右邊的型別一律是函式最終的回傳型別，而每個引數之間以函式箭頭 `->` 分隔。

```
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

要呼叫函式，就寫出函式名稱，後面接著只以空格分隔的引數。

```
maximum = getMax 1 10

> maximum
  ⧩
  10
```

呼叫函式時，Unison 會試著把緊接在右邊的內容當成它的引數，這不一定會產生你想要的函式求值順序。

假設我們想從下面的運算式取得值 `1`

```
shouldBe1 = getMax 1 10 - 10

> shouldBe1
  ⧩
  0
```

依照現在的寫法，`shouldBe1` 會求值為 `0`，因為隱含的函式套用順序是 `getMax 1 10`，其結果是 `10`，接著再算 `10 - 10`，得到 `0`。

你可以用括號重新分組運算式，讓運算順序符合你的需求。

```
shouldBe1 = getMax 1 (10 - 10)

shouldBe1
  ⧩
  1
```

## 監看運算式

Unison 提供了一種快速求值程式碼的方式，稱為「監看運算式」。監看運算式以 `>` 符號開頭，後面接著要求值的運算式。監看運算式可以寫在任何副檔名為 `.u` 的檔案中。儲存檔案後，你應該會在 Unison Codebase Manager（UCM）主控台中看到該運算式的求值結果。在本文件中，我們會盡可能示範如何用監看運算式求值，並顯示其預期輸出。

```
> helloThere
  ⧩
  "Hello, World!"
```

## 多行函式

Unison 的多行函式使用縮排或 `let` 區塊來界定程式碼範圍，也就是所謂的「詞法作用域」。

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

同一層縮排的所有內容共用同一個作用域，這就是為什麼我們可以在最後一行引用變數 `newBeginning`。

## 命名空間與 `use` 敘述

命名空間是我們用來分組和組織 Unison 函式的方式。你可以把它們想成類似「目錄」的東西。它們提供結構與邏輯上的分組。

你可以用 `use` 敘述把命名空間中的函式帶入作用域。

假設你正在撰寫一個會用到 Unison `List` 值的函式。你知道自己會需要像 `List.map` 和 `List.flatMap` 這樣的函式，其中 `List` 是命名空間，而 `map` 和 `flatMap` 是函式。為了避免重複，你可以在函式中像這樣把 `List` 命名空間的所有內容帶入詞法作用域：

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

`use List` 這一行消除了 `map` 和 `flatMap` 引用的歧義。你可以[在這裡][use-statements]進一步了解 `use` 敘述。

## Unison 的標準函式庫

Unison 的標準函式庫叫做 `base`。如果你按照快速入門指南操作，並在本機建立了程式碼庫，標準函式庫應該已經自動下載好了。你可以在線上瀏覽標準函式庫文件：[Unison Share][unison-share-base]。

## 註解與說明文件字面值

在 Unison 中，註解算是個有點特別的功能。撰寫 Unison 程式碼時，你可以在副檔名為 `.u` 的檔案中用下列語法建立不會被解讀的文字：

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

_不過_，由於 Unison 程式碼是以其抽象語法樹的雜湊值儲存，而不是以檔案系統上文字形式的檔案儲存，那些用來「裝飾」檔案中某個 Unison 函式或詞項的文字註解，其實無法被保存下來並重新呈現以供分享。如果你想以一種能保存下來、讓其他人閱讀理解的方式，為你的 Unison 詞項加入資訊，可以使用說明文件字面值。

在 Unison 程式語言中，說明文件是一等值。這表示 `Doc` 元素可以被指定給值、以值的形式傳入函式，或作為函式的值回傳。說明文件字面值元素以雙大括號開啟和關閉。以下是我們可以用 `Doc` 元素當作註解的方式。

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
