# 簡介

## 基礎

### 變數

Elixir 是動態型別的語言，也就是說，變數的型別只會在執行時檢查。使用匹配運算子`=`，我們可以把任意型別的值綁定到一個變數名稱上：

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### 模組

Elixir 是[函式程式設計語言][functional-programming]，所有具名函式都必須定義在_模組_中。`defmodule`關鍵字用來定義模組。在執行時，所有模組都可以被其他模組取用，不需要_存取修飾子_就能讓程式的其他部分看見它們。_模組_概念上類似於其他程式語言中的_類別_。

```elixir
defmodule Calculator do
  # ...
end
```

### 具名函式

_具名函式_必須定義在模組中。`def`關鍵字用來定義_公開_的具名函式。

每個函式可以有零個或多個引數。函式中最後一個運算式的值總是會_被隱式回傳_。

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

呼叫函式時，要指定它的模組和函式名稱，並為函式的每個參數傳入引數。

```elixir
sum = Calculator.add(1, 2)
# => 3
```

也可以用`defp`關鍵字取代`def`來定義_私有_函式。私有函式只能在定義它們的同一個模組內使用。

當在定義函式的同一個模組內呼叫它時，可以省略模組名稱。

你也可以用單行語法撰寫簡短的函式（注意關鍵字`do`前後的逗號`,`和冒號`:`）。

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### 函式的引數個數

我們常會用_引數個數_來指稱函式。函式的_引數個數_就是它接受的引數數量。

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### 命名慣例

模組名稱應該使用`PascalCase`。模組名稱必須以大寫字母`A-Z`開頭，可以包含字母`a-zA-Z`、數字`0-9`和底線`_`。

變數和函式名稱應該使用`snake_case`。變數或函式名稱必須以小寫字母`a-z`或底線`_`開頭，可以包含字母`a-zA-Z`、數字`0-9`和底線`_`，而且結尾可以是問號`?`或驚嘆號`!`。

### 標準函式庫

Elixir 擁有非常豐富且文件完整的標準函式庫。文件可以在 [hexdocs.pm/elixir][docs] 線上查閱。把這個連結存起來，你會很常用到它喔！

大多數內建的資料型態都有對應的模組，提供處理該型別的函式。例如整數有`Integer`模組，字串有`String`模組，陣列有`List`模組等等。

值得一提的模組是`Kernel`模組。它是標準函式庫其餘部分的建構基礎，提供算術運算子、控制流程巨集等基本能力。`Kernel`模組的函式會自動匯入，所以你可以不加`Kernel.`前綴直接使用。
