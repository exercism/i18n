# 關於

Haxe 中的[字串][strings]是不可變的物件，用來把文字表示成一連串 Unicode 字元（字母、數字、標點符號等）。要用雙引號來定義`string`實例：

```haxe
var fruit:String = "Apple";
```

操作字串的方式，是呼叫它的其中一個[方法或屬性][string-api]。由於字串的值一旦定義後就永遠不會改變，所有字串操作方法都會回傳一個新的字串。

字串是由雙引號（`"`）字元所界定。有些特殊字元需要使用反斜線（`\`）字元來[跳脫][escaping]。此外，Haxe 字串可以跨多行，能輕鬆建構出長字串常值：

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

串接字串最簡單的方式，就是使用 [`+` 運算子][plus-operator]。

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

若要進行更複雜的字串格式化，建議使用[字串內插][interpolation]。做法是用單引號（`'`）把字串包起來，並用錢號（`$`）觸發變數內插。也可以用`${expr}`來求值整個運算式，其中`expr`可以是任何合法的 Haxe 運算式：

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
