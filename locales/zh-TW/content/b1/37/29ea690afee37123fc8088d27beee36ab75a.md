# 泛型類別

你很早就開始使用`ARRAY{STR}`、`FMAP{STR,INT}`和`FSET{STR}`了。大括號裡裝的一直都是某種型別。現在，換你寫一個自帶大括號的類別吧。

## 問題

失物招領處需要一個箱子，用來裝一樣東西，並記住是誰把它送來的。一個裝毛衣的箱子：

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

接著為水瓶再寫一次同樣的類別，再為手機寫一次。三份副本只差一個字。

## 型別參數

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

類別名稱後面的`{T}`是**型別參數**。`T`本身不是型別，而是一個佔位符，代表使用這個類別時實際提供的型別。在類別內部，`T`的用法和任何型別名稱完全一樣。

## 使用方式

在大括號裡提供型別：

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}`和`LOST_BOX{INT}`是兩個不同的型別。把其中一個用在需要另一個的地方，就是編譯器會抓到的錯誤，情形就跟你親手把那兩個類別完整寫出來一樣。而實際上發生的也正是如此：Sather 會為每個真正用到的型別，從這個範本建構出一個獨立的類別。

所以這麼做在執行時期沒有任何額外成本，也不會損失型別資訊：`jumper.item`真的就是一個`STR`，而不是某個還得檢查或轉換的東西。

## 不只一個

一個類別可以接受好幾個參數，以逗號分隔。`FMAP{K,T}`就是你已經知道的例子。

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## 命名

依照慣例使用單一的大寫字母：`T`代表一個東西，`K`代表一個鍵，`E`代表一個元素。函式庫從頭到尾都這樣用。
