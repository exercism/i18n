# 說明

在這份練習中，你會撰寫程式碼來分析汽車工廠的組裝線。

## 1. 計算每小時生產的可用汽車數量

實作一個函式，接收每小時生產的汽車數量和成功率，並計算每小時成功製造的汽車數量。成功率以百分比表示，範圍從 `0` 到 `100`：

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**注意：** 回傳值應該是浮點數。

## 2. 計算每分鐘生產的可用汽車數量

實作一個函式，接收每小時生產的汽車數量和成功率，並計算每分鐘成功製造多少輛汽車：

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**注意：** 回傳值應該是整數。

## 3. 計算生產成本

每輛車單獨生產的成本通常是 $10.000，無論成功與否。但只要稍微規劃一下，10 輛車一起生產只要 $95.000。舉例來說，37 輛車可以這樣生產：
37 = 3 x 十輛一組 + 7 輛個別生產

所以 37 輛車的成本是：
3 \* 95,.000 + 7 \* 10.000 = 355.000

實作一個函式，計算生產一定數量汽車的成本，無論這些車是否成功製造：

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**注意：** 回傳值應該是整數。
