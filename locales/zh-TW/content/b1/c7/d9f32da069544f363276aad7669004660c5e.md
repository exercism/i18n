# 提示

## 一般

- 所有與讀取、寫入相關的字詞都位於 [`io.files`][io.files]；它們所接受的 `utf8` 編碼則來自 [`io.encodings.utf8`][utf8]。

## 1. 讀取每一筆讀數

- `file-lines` 會回傳一個陣列，其中的每一行都已移除換行符號。

## 2. 找出最新的讀數

- 用 `file-lines` 讀取所有行，再取 `last` 那一項（來自 `sequences`）。

## 3. 讀取原始日誌

- `file-contents` 會把整個檔案以單一字串回傳，換行符號也一併包含在內。

## 4. 記錄一筆讀數

- 以附加模式開啟檔案，並在 quotation 內用 `print` 印出讀數：
  `with-file-appender ( path encoding quot -- )`。讀數是在 quotation 內使用的，而 path 則會先被消耗掉，因此用 `::` 區域變數可以讓主體保持易讀：
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`。

## 5. 改寫日誌

- `set-file-lines` 會把序列中的每個元素各寫成一行，並自動幫你加上換行符號。

[io.files]: https://docs.factorcode.org/content/vocab-io.files.html
[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
