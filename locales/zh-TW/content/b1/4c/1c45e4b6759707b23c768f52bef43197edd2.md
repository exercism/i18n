# 操作說明

在這道練習中，你會做一點資料工程，預先處理一些成績資料。
有一所學校，學生多得不得了（太多了嗎？），校方想對學生拿到的成績做些資料分析，而且希望做得有效率，因此重點是盡量精簡並整理這些資料。

評分等級通常是 0 到 10，所以每個成績只佔 8 位元的資料型態最有效率。
- 有些教授用實數（因為他們對精確度很挑剔），你需要把這些數值轉成`UInt8`資料型態。
- 有些教授則用帶負數的整數（用來懲罰特別不受教的學生），遇到這種情況，你需要把這些數值轉成`Int8`資料型態。

等你實作出轉換成績的函式之後，還要再寫一個函式來處理存放成績的集合，把成績降級，並以遞減順序回傳。
- 有些教授用遞增排序的`Vector`來存放成績，因為他們對自己的資料很講究。
- 有些教授則用未排序的`Set`來存放成績，因為他們比較懶一點。

這兩個函式中，你都需要處理無效的輸入，方法是丟出 MethodError。

~~~~exercism/note
例外處理會在之後的概念單元中介紹，所以在這道練習裡，你可以使用以下語法：
```julia
throw(MethodError(f, args))
```
其中`f`是函式，`args`是傳入該函式的引數所組成的元組。
以`demote(n)`函式為例，`f`是`demote`，而`args`是`(n,)`：
```julia
throw(MethodError(demote, (n,)))
```
~~~~

## 1. 將成績降級

實作`demote(n)`方法。
- 輸入為`Float64`時，應該四捨五入到最接近的整數，並回傳`UInt8`資料型態。
- 輸入為任意的`Integer`時，應該以`Int8`資料型態回傳同一個整數。
- 其他所有輸入都應該丟出 MethodError。

```julia-repl
julia> demote(4.2)::UInt8
5

julia> demote(4)::Int8
4

julia> demote("hi")
MethodError: no method matching demote(::String)     #output truncated
```

## 2. 預先處理資料

實作`preprocess(coll)`方法。
- 輸入為`Vector`時，應該將所有數字降級，並反轉該向量。
- 輸入為`Set`時，應該將所有數字降級，並回傳依遞減順序排序的向量。
- 其他所有輸入都應該丟出 MethodError。

```julia-repl
julia> preprocess([1, 2, 3])
3-element Vector{Int8}:
 3
 2
 1

julia> preprocess(Set([2.2, 5.8, 3.4]))
3-element Vector{UInt8}:
 6
 4
 3

julia> preprocess(42)
MethodError: no method matching preprocess(::Int64)     #output truncated
```
