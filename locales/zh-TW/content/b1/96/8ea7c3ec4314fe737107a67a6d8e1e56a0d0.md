# 簡介

這個練習延續你在[後院賞鳥者][backyard-birdwatcher]看過的內容，接著介紹會接收 *quotation*（寫在`[ ]`括號裡的一段程式碼）來驅動操作的高階詞。

## 把 quotation 當成值

quotation 就只是一段字面上的程式碼。你可以把它當作資料傳給另一個詞：

```factor
{ 1 2 3 4 5 } [ 2 > ] count .   ! => 3
```

這裡的`[ 2 > ]`就是一個 quotation，它接收一個數字，並留下一個布林值。`count`會對每個元素執行它，並統計結果為真的數量。

## 篩選與排除

```
find      ( seq quot    -- i/f elt/f ) ! first match: index and element, or f f
find-last ( seq quot    -- i/f elt/f ) ! same, but searches from the end
filter    ( seq quot    -- newseq )    ! keep elements where quot is truthy
reject    ( seq quot    -- newseq )    ! drop them instead
without   ( seq exclude -- newseq )    ! drop every element that's in `exclude`
sift      ( seq         -- newseq )    ! drop every `f`, keep the rest
```

```factor
{ 1 2 3 4 5 } [ 3 > ] find .s
! => 3            (index)
! => 4            (element)
{ 1 2 3 4 5 } [ 3 > ] find-last .s
! => 4            (index)
! => 5            (element)
{ 1 2 3 4 5 } [ even? ] filter .    ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .    ! => { 1 3 5 }
"hello world" " ld" without .       ! => "heowor"
{ 1 f 2 f 3 } sift .                ! => { 1 2 3 }
```

`without`會把它的第二個引數視為一個集合：只要`seq`裡的元素和`exclude`裡*任一個*元素`=`，就會被丟棄。`sift`是`reject`不使用 quotation 的特例：它會保留除了`f`以外的每個元素，很適合用來清掉前一次`map`留下的空缺。

### 保留測試的結果

`find`會交回符合的*元素*。當測試本身就會*算出*你真正想要的值時，`map-find`能幫你省下第二趟巡訪：它會對每個元素執行 quotation，並回傳第一個不是`f`的結果**以及**產生這個結果的元素。

```
map-find ( seq quot: ( elt -- result/f ) -- result elt )
```

```factor
USING: kernel math sequences ;

! First multiple of 3, paired with that multiple divided by 3.
{ 11 13 15 17 } [ dup 3 mod 0 = [ 3 /i ] [ drop f ] if ] map-find .s
! => 5            (result: 15/3)
! => 15           (element)
```

對於不符合條件的元素，quotation 會回傳`f`；對於符合的那一個，則回傳你想保留的結果。如果沒有任何元素符合，`map-find`會留下`f f`，就和`find`一樣。

### 依欄位篩選記錄

當元素是*元組*時，述詞通常會透過自動產生的讀取器`slot>>`取出某個欄位，再依它來測試：

```factor
USING: accessors sequences ;

TUPLE: customer name vip? ;

{
    T{ customer { name "Alice" } { vip? t } }
    T{ customer { name "Bob"   } { vip? f } }
    T{ customer { name "Carol" } { vip? t } }
}
[ vip?>> ] filter [ name>> ] map .
! => { "Alice" "Carol" }
```

## 用`with`帶入固定值

有時候述詞需要一個每次呼叫都相同的值，可能是閾值、除數或目標字串。`with`（位於[`kernel`][kernel]）會把那個固定值嵌進 quotation 裡，將接收兩個引數的 quotation`( value elt -- ? )`變成`filter`、`count`、`map`和`each`所期望的單一引數 quotation：

```
with ( value seq quot -- seq curry )
```

每個處理元素的呼叫都會在堆疊上看到`( value elt )`，固定值在前，目前的元素在後：

```factor
USING: kernel sequences ;

! Count elements greater than 5 — value=5 is threaded in
5 { 2 7 4 9 1 8 } [ < ] with count .   ! => 3
```

## 映射與疊代

`map`（位於[`sequences`][sequences]）會把 quotation 套用到每個元素，並回傳結果組成的陣列。`each`做同樣的走訪，但會捨棄結果，適合用在 quotation 純粹為了副作用而執行的時候。`2map`會同步走訪*兩個*序列，並合併對應的元素；`2each`和`2reduce`分別是它「只取副作用」和「摺疊」的親戚；`zip`則是「把元素兩兩配對但不合併」的簡寫：

```
map     ( seq       quot           -- newseq )
map-as  ( seq       quot exemplar  -- newseq )
each    ( seq       quot           -- )
2map    ( seq1 seq2 quot           -- newseq )
2each   ( seq1 seq2 quot           -- )
2reduce ( seq1 seq2 identity quot  -- result )
zip     ( seq1 seq2                -- pairs )
```

`2reduce`會一次把累加器串過兩個序列，它的 quotation 接收`( accumulator elt1 elt2 -- accumulator' )`。這裡它累加出一個內積：每一對相乘，再把所有乘積加總（`1*10 + 2*20 + 3*30`）：

```factor
{ 1 2 3 } { 10 20 30 } 0 [ * + ] 2reduce .   ! => 140
```

`map-as`是`map`的親戚，會強制指定輸出序列的型別。傳入一個空的`{ }`或`V{ }`作為樣本，就能覆寫預設沿用輸入型別的行為（否則把字串映射成非字元時，Factor 試著把結果塞回字串就會出錯）。

```factor
USING: formatting math sequences ;

{ 1 2 3 } [ sq ] map .                         ! => { 1 4 9 }
{ 1 2 3 } [ . ] each                           ! prints 1, then 2, then 3
{ 1 2 3 } { 10 20 30 } [ + ] 2map .            ! => { 11 22 33 }
{ "x" "y" } { 1 2 } [ "%s%d" sprintf ] 2map .  ! => { "x1" "y2" }
{ 1 2 3 } { 10 20 30 } [ + . ] 2each           ! prints 11, then 22, then 33
{ "a" "b" "c" } { 1 2 3 } zip .                ! => { { "a" 1 } { "b" 2 } { "c" 3 } }
```

兩種處理雙序列的形式都會在較短的輸入長度處停下來。`zip`等同於`[ 2array ] 2map`，是保留配對，而不是把配對合併掉。

## 排序

`sort`會以自然順序回傳排序後的複本；`sort-by`（位於[`sorting`][sorting]）則依從每個元素取出的鍵來排序：

```
sort    ( seq      -- sortedseq )
sort-by ( seq quot -- sortedseq )
```

```factor
{ 3 1 4 1 5 9 2 6 } sort .
! => { 1 1 2 3 4 5 6 9 }

{ -3 5 -1 4 } [ abs ] sort-by .
! => { -1 -3 4 5 }
```

## 彙總

`map-sum`（位於[`sequences`][sequences]）會把 quotation 映射過整個序列，並在同一趟裡把結果加總：

```
map-sum ( seq quot -- n )
```

```factor
{ 1 2 3 4 } [ sq ] map-sum .   ! => 30
```

## 最小值與最大值

`minimum`和`maximum`會直接回傳序列中最小或最大的元素。`minimum-by`和`maximum-by`（都在[`sequences`][sequences]裡）則回傳取出鍵之後最小或最大的那個元素：

```
minimum     ( seq      -- elt )
maximum     ( seq      -- elt )
minimum-by  ( seq quot -- elt )
maximum-by  ( seq quot -- elt )
```

```factor
{ 3 1 4 1 5 9 2 6 } minimum .       ! => 1
{ 3 1 4 1 5 9 2 6 } maximum .       ! => 9

{ -3 5 -1 4 } [ abs ] minimum-by .
! => -1
```

## 撰寫自己的高階詞

當*你的*詞接收 quotation 作為執行期引數，並把它轉交給`map`、`filter`、`each`等詞時，請用`; inline`來宣告你的詞。這會告訴編譯器在每個呼叫點把你的詞內嵌，因為在呼叫點上 quotation 是已知的字面值。少了它，編譯器就沒辦法知道該 quotation 的堆疊效應。

```factor
USING: math sequences ;

: tax-on ( inventory quot -- total )
    map-sum ; inline

{ { "shirt" 20 } { "hat" 15 } } [ second 1/10 * ] tax-on .
! => 3+1/2
```

只用字面 quotation 組成的詞不需要`inline`，只有會把*傳入的* quotation 轉送出去的詞才需要。

如果這樣的`inline`詞會呼叫*自己*，也就是一個遞迴組合子，那就改用`; inline recursive`來宣告。少了這個額外的詞，編譯器會停下來，並顯示 *"The inline recursive word ... must be declared recursive"*，正好告訴你該補上什麼。

## 取出第二個元素

對一個有兩個元素的陣列，`second`會回傳它的第二個元素，`first`則回傳第一個。兩者都在[`sequences`][sequences]裡。

## 數字轉字串

`number>string ( n -- str )`（位於[`math.parser`][math.parser]）會把數字轉成它的十進位字串形式：

```factor
42 number>string .     ! => "42"
3.5 number>string .    ! => "3.5"
```
