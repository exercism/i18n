# 提示

## 一般

- 不用擔心引數是怎麼產生的，只要專注在組合這些引數，回傳預期的結果就好。
- Unison 有[特定的運算子優先順序規則][operator-precedence]，如果需要以不同順序套用函式，記得使用括號。

## 1. 定義 Pac-Man 是否能吃掉幽靈

- 你需要定義一個帶有 2 個引數的函式。第一個引數是[布林][boolean]值，代表 Pac-Man 是否有作用中的能量球。第二個引數是[布林][boolean]值，代表 Pac-Man 是否碰到幽靈。
- 這個函式必須回傳一個[布林][boolean]值。
- 你可以使用[布林][boolean]運算子`&&`來組合這些引數以得到結果。

## 2. 定義 Pac-Man 是否得分

- 你需要定義一個帶有 2 個引數的函式。第一個引數是[布林][boolean]值，代表 Pac-Man 是否碰到能量球。第二個引數是[布林][boolean]值，代表 Pac-Man 是否碰到豆子。
- 這個函式必須回傳一個[布林][boolean]值。
- 你可以使用[布林][boolean]運算子`||`來組合這些引數以得到結果。

## 3. 定義 Pac-Man 是否落敗

- 你需要定義一個帶有 2 個引數的函式。第一個引數是[布林][boolean]值，代表 Pac-Man 是否有作用中的能量球。第二個引數是[布林][boolean]值，代表 Pac-Man 是否碰到幽靈。
- 這個函式必須回傳一個[布林][boolean]值。
- 你可以使用[布林][boolean]運算子`&&`和`not`來組合這些引數以得到結果。

## 4. 定義 Pac-Man 是否獲勝

- 你需要定義一個帶有 3 個引數的函式。第二個引數是[布林][boolean]值，代表 Pac-Man 是否吃掉了所有豆子。第一個引數是[布林][boolean]值，代表 Pac-Man 是否有作用中的能量球。第二個引數是[布林][boolean]值，代表 Pac-Man 是否碰到幽靈。
- 這個函式必須回傳一個[布林][boolean]值。
- 你可以使用[布林][boolean]運算子`&&`和`not`來組合引數與被呼叫函式的結果。

[boolean]: https://elixir-lang.org/getting-started/basic-types.html#booleans
[operator-precedence]: https://www.unison-lang.org/learn/fundamentals/values-and-functions/function-application-operators/
