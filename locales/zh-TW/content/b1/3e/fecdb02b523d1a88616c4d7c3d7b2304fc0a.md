# 簡介

處理二進位資料在任何程式語言中都是重要的概念，而 Elixir 提供了優雅的語法來撰寫、匹配與建構二進位資料。

在 Elixir 中，二進位資料被稱作位元字串型別。二進位資料_型別_（不要與一般所說的二進位資料混為一談）是位元字串的一種特定形式，我們會在之後的練習中討論。

位元字串字面值是用位元字串的特殊形式 `<<>>` 定義的。定義位元字串字面值時，是以區段為單位來定義的。每個區段都有一個值和型別，兩者以 `::` 運算子分隔。型別會指定要用多少位元來編碼這個值。型別可以完全省略，此時會預設為 8 位元的整數值。

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

把型別寫成 `::1` 是 `::size(1)` 的簡寫。如果位元大小來自變數，就得使用較長的語法。

## 二進位

撰寫二進位整數字面值時，我們可以在字面值前面加上 `0b`，直接用二進位表示法來寫。要注意的是，在測試結果中印出或在 iex 中使用時，它們仍然會以十進位數字顯示。

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## 截斷

如果區段的值超出該區段型別的容量，就會從左邊被截斷。

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## 前置與附加

你可以用特殊形式在現有的位元字串前面加入，也可以在後面附加。如果現有的位元字串大小未知，就必須對它使用 `::bitstring` 型別。

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## 串接

我們可以用特殊形式串接存在變數中的位元字串。串接兩個大小未知的位元字串時，必須使用 `::bitstring` 型別。

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## 模式匹配

也可以用模式匹配從這個特殊形式取得值。你必須知道每個想捕捉的片段有多少位元，只有一個例外：`::bitstring` 型別可以用來對大小未知的位元字串進行模式匹配，但這只能用在最後一個片段。

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## 檢視位元字串

~~~~exercism/note
位元字串被印出時（無論是測試執行器或 iex），格式可能與建立它們時所用的格式不同。這在學習位元字串時經常造成混淆。
~~~~

預設情況下，位元字串會以 8 位元（一個位元組）的片段顯示，即使你建立它們時用的是不同大小的片段。

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

如果你建立的位元字串代表可列印的 UTF-8 編碼字串，它就會以字串的形式顯示。

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
