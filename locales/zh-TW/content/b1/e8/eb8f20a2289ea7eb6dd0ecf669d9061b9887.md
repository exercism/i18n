# Python 的字典方法

Python 的 `dict` 類別提供了許多實用的[方法][dict-methods]，其中一些已經在字典的概念練習中介紹過了。

這個概念還會談到另外幾個：

- `<dict>.setdefault()` 會自動新增鍵，而不會擲回 KeyError。
- `<dict>.fromkeys(<iterable>, <default value>)` 可以從任意數量的可迭代物件建立新的 `dict`。
- `<dict>.keys()`、`<dict>.values()` 和 `<dict>.items()` 提供方便的迭代器。
- `sorted(<dict>.items())` 可以輕鬆重新排序 `dict` 中的項目。
- `<dict_one>.update(<dict_two>)` 會用另一個 `dict` 中重疊的值來更新某個 `dict`。
- `<dict> | <other_dict>` 和 `<dict> |= <other_dict>` 透過運算子合併或更新兩個 `dict`。
- `reversed(<dict>.keys())`、`reversed(<dict>.values())` 或 `reversed(<dict>.items())` 會產生_反轉_後的檢視。
- `<dict>.popitem()` 會移除並回傳一組 `key`、`value` 配對。

[dict-methods]: https://docs.python.org/3/library/stdtypes.html#dict
