# 說明補充

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                                 |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | 輸入     | 位址 | 以 null 結尾的十六進位字元字串 |
| `$v0`    | 輸出     | 整數 | 輸入字串的十進位值               |
| `$t0-9`  | 暫時 | 任意     | 用於暫時存放                  |
