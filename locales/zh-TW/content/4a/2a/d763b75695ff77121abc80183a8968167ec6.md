# 指令

你受聘到一家正在開發 Chatbot 的公司，擔任正規表示式專家。

這項開發還處於非常初期的階段。
你的任務是運用正規表示式，提升 Chatbot 理解與產生自然語言的能力。

## 1. 檢查有效指令

Chatbot 不只聰明，還是個忠心的助手。
使用者必須把「**Chatbot**」這個詞放在指令的第一個位置，才能向 Chatbot 提問。
關鍵字是大寫還是小寫都沒關係。
重要的是這個詞出現的位置。

實作 `is_valid_command` 函式，協助 Chatbot 辨識使用者是否正在下指令。

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. 移除加密的表情符號

Chatbot 很難理解人類如何用表情符號表達情緒。
Chatbot 收到使用者訊息時，每個表情符號都會以字串「emoji」加上一個 _id 編號_ 來表示。

實作 `remove_emoji` 方法，它接受一個字串，並移除訊息中所有的表情符號。

不含表情符號的行應原樣回傳。
只要移除表情符號字串就好。
不要調整空白。

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. 檢查有效的電話號碼

在與 Chatbot 互動的某個時刻，使用者會提供電話號碼。
Chatbot 只能撥打特定格式的號碼。

實作 `check_phone_number` 函式。

如果號碼有效，Chatbot 會回覆一則訊息，感謝使用者並確認號碼。
如果號碼無效，Chatbot 會告知使用者該電話號碼無效。

預期的格式是 `(+NN) NNN-NNN-NNN`，其中 N 是數字。

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. 取得網站連結

Chatbot 是一套非常好奇的軟體。
雖然它能上網搜尋特定主題，但它喜歡詢問使用者有哪些很酷的網站可以造訪，以找到相關資訊。

對話範例：

> **Chatbot**：嘿，使用者，我想學怎麼用 JavaScript 寫程式。你知道有什麼很酷的網站可以讓我學習嗎？

> **使用者**：我從 exercism.org 學到很多，那裡有很多很棒的資源。

實作 `get_domains` 函式，它會回傳網站網域的陣列。

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. 向使用者打招呼

有禮貌的 Chatbot 會用名字稱呼使用者。
當使用者自我介紹時，我們的 Chatbot 會偵測他們的名字，並以親切的問候回應。

撰寫 `nice_to_meet_you` 函式。

如果輸入字串包含「My name is Someone.」，請擷取名字並回傳字串「Nice to meet you, Someone.」。

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. 非常簡單的 CSV 解析

抵擋不住「功能蔓延」的誘惑，我們要在 Chatbot 裡加一個 CSV 解析函式。

實作 `parse_csv` 函式，它接受一個字串，並回傳解析出的欄位陣列。
欄位分隔符號應該是「逗號加上選擇性的空白」。

我們不用擔心 CSV 格式的任何邊界情況（例如欄位中含有逗號）。

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
