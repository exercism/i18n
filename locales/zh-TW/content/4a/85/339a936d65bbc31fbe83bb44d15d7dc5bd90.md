# 學習

## 從零開始學 Python
Python 是（_正如 [Wikipedia 所述][wikipython]_）一門*通用且高階的程式語言*。
 你可以用它寫出各式各樣的軟體，從電子遊戲、HTTP 伺服器到命令列工具，還有其他琳瑯滿目的東西。
 它特別擅長把不同的系統和程式「黏」在一起。


我們認為最好的學習方式，就是透過大大小小的程式專案來_玩_、來_練習_，或者從像 Exercism 這裡的小題目著手！
