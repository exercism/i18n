# 提示

## 一般

- 想認識`Enum`模組，可以閱讀[官方入門指南][getting-started-enum]，或到 [elixirschool.com][elixir-school-enum] 看看。
- 翻閱文件，查看完整的 [`Enum`模組函式清單][enum-functions]。

## 1. 依價格排序商品

- 有一個[內建函式][enum-sort-by]，可以使用排序函式來排序可列舉結構。

## 2. 找出所有缺少價格的商品

- 有一個[內建函式][enum-filter]可以篩選可列舉結構。

## 3. 更新商品名稱

- 有一個[內建函式][enum-map]可以轉換可列舉結構中的每個元素。
- 有一個[內建函式][string-replace]可以將某個字串的所有出現位置取代成另一個字串。

## 4. 增加商品的數量

- Map 實作了可列舉協定。
- `Enum`函式會把 map 轉換成 `{key, value}` 元組的陣列。
- 有兩個不同的函式可以使用轉換函式，把 `{key, value}` 元組的陣列變回 map。其中[一個一律回傳新的 map][map-new]，而[另一個則讓你自行選擇收集目標][enum-into]。

## 5. 計算商品的總數量

- Map 實作了可列舉協定。
- `Enum`函式會把 map 轉換成 `{key, value}` 元組的陣列。
- 有一個[內建函式][enum-reduce]可以將可列舉結構縮減成單一值。
