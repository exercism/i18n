# 問題解決策略

如同這裡第一篇文章所說的，**_問題解決是一項後設技能_**。
我們發現，程式語言的語法或結構，往往不是解題過程中最困難的部分，真正困難的是想清楚_該寫什麼程式_，或是_該從哪裡開始_。
發展出一套策略和系統，把問題拆解成可以寫成程式的步驟，是一項**很棒**、值得培養的技能。
以下是一些來自社群的文章、影片和書籍，可以幫助你培養這項超級技能。

- Free Code Camp 提供了一篇不錯的總覽文章：[How to Think Like a Programmer - Lessons in Problem-Solving][free-code-camp-think-like-a-programmer]。
- fast.ai 創辦人 Jeremy Howard 寫了一篇不錯的摘要：[G. Polya's Problem Solving Techniques][g-polya-how-to-solve-it-summary]。
- [G. Polya's How To Solve It][g-polya-how-to-solve-it]（完整版）最初寫於 1945 年，原本是為了解決複雜數學問題而寫的指引；時至今日，它對於一般問題解決而言，依然是_絕佳_的建議。
- Kurtis Pykes 為 Towards Data Science 撰寫了一篇不錯的[問題解決實作教學][Kurtis Pykes: Hands-on Tutorial - How to Improve Your Problem-Solving Skills as A Programmer]。
- 前面提到的 Free Code Camp 文章中，也介紹了 V. Anton Spraul 的 [Think Like a Programmer: An Introduction to Creative Problem Solving][v-anton-spraul-think-like-a-programmer]，這本書以更現代、更聚焦程式設計的方式，重新詮釋了 Polya 為數學所歸納出的同一套通用方法。
- [Felienne Hermans][felienne-hermans] 則更關注人們_如何_學習程式設計這門技藝，以及這件事如何對應到一般的學習。
  她寫了 [The Programmer's Brian][programmers-brain-free-online] 一書，書中提供了各種策略，幫助你更懂得閱讀程式碼、更清晰地思考程式碼、寫出更好的程式碼，並成為更好的程式碼協作者。
  - 你可以從[這裡][programmers-brain-manning]訂購她的實體書。
  - 她還有兩支談論同一主題、很有意思的影片：[How to Teach Programming (and other things)?][felienne-hermans-how-to-teach-programming] 和 [Programming is Writing is Programming ][felienne-hermans-programming-is-writing-is-programming]。
- [Algorithmic Thinking (Daniel Zingaro)][daniel-zingaro-algorithmic-thinking]（由 No Starch Press 出版）和 [How to think like a programmer (Paul Vickers)][paul-vickers-how-to-think-like-a-programmer] 同樣探討了寫程式時的問題解決。
- [Computational Thinking: A beginner's guide to problem-solving and programming (Karl Beecher)][beecher-computational-thinking] 和 [Computational Thinking for the Modern Problem-Solver (Riley and Hunt)][riley-and-hunt-computational-thinking] 也提供了思考問題、把問題拆解成程式解法的策略。
- [From Computing to Computational Thinking (Paul S. Wang)][wang-computational-thinking] 稍微更一般化、更偏學術一些，但它所提供的問題解決策略與架構，可以運用在寫程式以外的更多地方，而且不需要具備程式設計的基礎知識。

其中有些書也可以透過 Association of Computing Machinery (ACM) 的圖書館借閱。
