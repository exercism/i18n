# 簡介

## 差別聯合

差別聯合型別代表固定數量的具名案例。差別聯合的每個值都恰好對應其中一個具名案例。

差別聯合使用`type`關鍵字定義，各案例之間以管道（`|`）字元分隔：

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

差別聯合的每個案例都可以選擇性地帶有關聯資料，而且不同的案例可以帶有不同型態的資料。如果所有案例都沒有關聯資料，這個差別聯合就類似於其他語言通常所說的_列舉_。

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

建立特定案例的值，可以藉由參照它的名稱來完成（例如`Success`）。由於案例名稱就只是建構函式，關聯資料可以像一般函式引數一樣傳入。如果另一個差別聯合定義了同名的案例，你就必須使用它的完整名稱（例如`Result.Success`）。

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

差別聯合具有_結構相等性_，也就是說，同一個案例且帶有相同（選用）資料的兩個值彼此等價。

雖然你可以使用`if/elif/else`運算式來處理差別聯合，但建議的處理方式是透過模式比對，並使用_識別碼模式_：

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
