# 關於

Go 中的 [`Time`][time]是一種描述時間點的型別。
你可以透過它的方法存取、比較和操作日期與時間資訊，不過 `time` 套件本身也提供了一些函式。
當前的日期和時間可以透過[`time.Now`][now]函式取得。

[`time.Parse`][parse]函式會將字串解析成 `Time` 型別的值。
Go 有一套特殊的方式來定義你期望的解析版面。
你需要用這個特殊時間戳的值，寫出一個版面的範例：
`Mon Jan 2 15:04:05 -0700 MST 2006`。

例如：

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

[`Time.Format()`][format]方法會回傳時間的字串表示。
就和`Parse`函式一樣，目標版面同樣是透過一個使用特殊時間戳值的範例來定義。

例如：

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## 版面選項

若要自訂版面，請組合使用這些選項。
Go 也提供了預先定義的日期與時間戳[格式常數][const]。

| 時間        | 選項                                        |
| ----------- | ---------------------------------------------- |
| 年        | 2006 ; 06                                      |
| 月        | Jan ; January ; 01 ; 1                         |
| 日         | 02 ; 2 ; \_2（表示前面補 0）                 |
| 星期     | Mon ; Monday                                   |
| 小時        | 15（24 小時制）; 3 ; 03（AM 或 PM） |
| 分鐘      | 04 ; 4                                         |
| 秒      | 05 ; 5                                         |
| AM/PM 標記  | PM                                             |
| 一年中的第幾天 | 002 ; \_\_2                                    |

`time.Time` 型別有各種方法可以取得特定的時間，例如小時：[`Time.Hour()`][hour]、月份：[`Time.Month()`][month]。
想進一步了解運作方式，可以參考[官方文件][time]。

[`time`][time]還包含另一個型別，也就是[`Duration`][duration]，用來表示經過的時間，此外也支援地區/時區、計時器，以及其他會在另一個概念中介紹的相關功能。
