# 說明

舞團會排成一排排，而你要記住誰站在哪裡。

這 5 個任務都寫在 `DANCE_FORMATION`類別裡。

## 1. 這一排有幾個人？

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. 誰帶頭？

帶頭的人就是排在最前面的那位。

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. 誰在最後面？

殿後的人就是排在最後面的那位，不論這排有多長。

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. 開場隊形

舞團開場時總是按照同樣的順序出場：Mia、Ana、Ben。請回傳這一排。

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

這個常式不需要任何引數。

## 5. 數一數舞步

每位舞者都有指定的舞步數要做，把它們加起來。

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

空的一排是零步。
