# 說明

在這個練習中，你會處理日誌項目。

每一行日誌都是一個格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

有三種不同的日誌層級：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會接收一行日誌，並要求你對它做些處理。
解決這些任務的方法有很多，從上面的範例中選擇你最喜歡的技巧，看看你能想出什麼吧。

## 1. 從日誌行取得訊息

實作`message`函式，回傳日誌行的訊息：

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

任何開頭或結尾的空白都應移除：

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. 從日誌行取得日誌層級

實作`log_level`函式，回傳日誌行的日誌層級，且應以小寫回傳：

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. 重新格式化日誌行

實作`reformat`函式，重新格式化日誌行，將訊息放在最前面，並在後面以括號加上日誌層級：

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
