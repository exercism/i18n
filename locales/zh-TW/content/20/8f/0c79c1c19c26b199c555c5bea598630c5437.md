# 建構函式屬性提升

在宣告許多屬性的類別裡，如果把類別、屬性，以及用來設定屬性的建構函式分開宣告，就會產生許多重複的程式碼。
使用建構函式屬性提升，可以減少重複的情形。

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
