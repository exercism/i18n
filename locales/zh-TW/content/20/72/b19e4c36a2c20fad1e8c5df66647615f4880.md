# 簡介

有些迴圈無法寫成「對序列中的每個元素做這件事」，你必須持續進行，直到某個條件改變。Factor 的`while`組合子就是為此而生：述詞程式區塊會說「要繼續嗎？」，body 程式區塊做一步的工作，而`while`會重複直到述詞給出`f`。

## `while`和`until`

```
while ( pred body -- )
until ( pred body -- )
```

`pred`和`body`都是對資料堆疊進行操作的程式區塊。`while`會在`pred`留下真值時持續迴圈；`until`則相反：它會持續迴圈，*直到*`pred`變成真（也就是在`pred`留下`f`時繼續）。

單一狀態可以在述詞和 body 之間透過堆疊流動：

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

追蹤：述詞`dup 0 >`會查看目前的計數器；body `dup . 1 -`會印出它並將它減一；當計數器到達`0`時迴圈停止。最後的`drop`會把最後那個`0`從堆疊丟棄。

## `while*`：保留述詞的值

```
while* ( pred body -- )
```

`while`只在意它的述詞是否留下真值，在執行 body 之前會把值本身丟掉。`while*`則會*把那個值交給 body*。當測試和 body 想要同一個剛計算出來的值時就使用它：查找、比對、解析後的記號。

這裡每個名稱都指向鏈中的下一個名稱。述詞會查找目前的名稱；只要還有下一個名稱，`while*`就會把它傳給 body，body 會印出它並從那裡繼續：

```factor
USING: assocs kernel locals prettyprint ;

:: print-chain ( start links -- )
    start [ links at ] [ dup . ] while* ;

"a" H{ { "a" "b" } { "b" "c" } } print-chain
! prints "b" then "c"
```

`links at`會回傳下一個名稱，或是在某個名稱沒有對應項目時回傳`f`。當它回傳名稱時，`while*`會把該名稱交給`dup .`，後者會印出它並將它留作下一次查找的鍵。第一個`f`會停止迴圈，`while*`會丟棄它，所以不會留下任何東西。

## 用區域變數處理多個狀態值

當迴圈帶有多個值時，比如剩餘的陣列和累計總和，堆疊操作就會變得雜亂。最簡潔的模式是用`::`宣告*區域變數*：

```
:: word ( inputs -- outputs ) ... ;
```

在 body 內，`:> name!`會新增可變的區域變數；讀取用`name`，寫入用`name!`（它會從堆疊取用新值並指定給它）。

```factor
USING: kernel locals math sequences ;

! Walk a sequence from the front, summing as we go
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0   :> running!
    [ rest empty? ] [
        rest unclip [ rest! ] dip
        running + running!
    ] until
    running ;
```

這裡的兩個區域變數（`rest`和`running`）涵蓋了整個迴圈的狀態：述詞會檢查它們，body 會更新它們，最後再回傳最終值。

`unclip ( seq -- rest first )`會剝離序列的第一個元素，當迴圈想每次疊代消耗陣列中的一個元素時很方便。`[ rest! ] dip`形式會把`rest`更新為剩餘的尾端，同時把剛彈出的元素留在堆疊上讓 body 使用。
