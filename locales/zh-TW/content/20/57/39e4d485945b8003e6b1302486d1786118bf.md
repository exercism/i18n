# 關於

[`sequences`][sequences]詞彙定義了一個[協定][sequence-protocol]，陣列（`{ … }`）、向量（`V{ … }`）、字串、範圍和切片都實作它。你能對其中一種做的事，也能對其他任何一種做。

| 詞          | 效果                              |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )`（索引從 0 開始） |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )`（除了最後 n 個以外的元素） |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )`（最後 n 個） |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )`（不存在時回傳長度） |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

陣列是固定長度的，所以 `prefix`/`suffix`/`append`/`prepend` 這些操作都會回傳新的序列，不會直接擴充原本的陣列。向量則可以調整大小，`push`和`pop`會直接在原地運作；不過如果你想要的是一份全新的副本，`clone` 才是正確的起點。

## 轉換

`>array`、`>string`和`>vector`（分別位於各自的詞彙中）會把任何序列轉換成指定的具體型別。當呼叫端需要特定的表示法時，或在你要具體化切片或其他惰性序列時，就可以派出它們。

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
