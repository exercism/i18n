# 簡介

當你有好幾個各自獨立、需要分別處理的可能值時，使用`case`（在[`combinators`][combinators]中）會比一連串的`if`更簡潔。

## `case`

```
case ( obj assoc -- )
```

`case`會從堆疊頂端取走值，以及一組子句構成的 *assoc*。每個子句的形式是`{ value [ body ] }`。第一個值與輸入相等的子句會勝出，比較所用的運算子就是`=`；它的 body 執行時，輸入值已經被取用掉了。最後一項若只有`[ body ]`就是預設情況，它執行時輸入值仍在堆疊上。

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

相等的判定靠的是`=`，所以任何能以`=`比較為相等的東西都能當作鍵，數字、字串和符號皆可。

## 用`cond`處理條件分支

當選擇取決於述詞而不是相等比較時（例如`x > 11`），`cond`就是合適的工具。你在 [Cars, Assemble!][cars-assemble] 裡已經見過`cond`了。

## 符號

`SYMBOL:`會宣告一個把自己推上堆疊的詞，也就是一個能自我求值的標籤值。`SYMBOLS:`則能一次宣告好幾個：

```factor
SYMBOLS: yes no maybe ;
```

現在`yes`是一個值，可以用`=`比較，也能拿來當作 case 的鍵：

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
