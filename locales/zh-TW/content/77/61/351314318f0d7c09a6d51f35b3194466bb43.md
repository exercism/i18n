# 說明

在這道練習中，你要幫妹妹校訂她的學校報告。老師希望報告有正確的標點、文法，以及出色的用字遣詞。

你有四項任務，要清理並修改字串。

## 1. 將報告標題改成大寫

一篇好的報告需要格式正確的標題。
實作函式`capitalize_title(<title>)`，它接受標題`str`作為參數，並將每個單字的第一個字母改成大寫。
這個函式應該回傳標題格式的`str`。


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. 檢查每個句子是否以句號結尾

你想確保報告的標點完美無誤。
實作函式`check_sentence_ending()`，它接受`sentence`作為參數。這個函式應該回傳`bool`。


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. 清理多餘的空格

為了讓報告看起來專業，必須移除多餘的空格。
實作函式`clean_up_spacing()`，它接受`sentence`作為參數。
這個函式應該移除句子開頭和結尾多餘的空白，並回傳更新後的新句子`str`。


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. 用同義詞取代單字

為了讓報告_更上一層樓_，你可以把一些形容詞換成同義詞。
撰寫函式`replace_word_choice()`，它接受`sentence`、`old_word`和`new_word`作為參數。
這個函式應該把所有出現的`old_word`都取代成`new_word`，並回傳含有更新後句子的新`str`。


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
