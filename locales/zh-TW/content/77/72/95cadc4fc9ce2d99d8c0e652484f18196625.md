# 說明

你的朋友 Chandler 打算前往世界各地充滿異國風情的國家旅行。可惜 Chandler 的數學不太好。他很擔心在旅途中被換匯業者坑騙喔，所以想請你幫他做一個匯率計算機。

## 1. 估算兌換後的價值

定義`exchange-money`，它接受`budget`和`exchange-rate`，並回傳兌換後貨幣的價值。

**注意：**如果你的貨幣是 USD，而你想以`1.20`的匯率把 USD 兌換成 EUR，那麼`1.20 USD == 1 EUR`。

```factor
127.5 1.2 exchange-money .
! => 106.25
```

## 2. 計算兌換後剩下的金額

定義`get-change`，它接受`budget`（兌換前）和`exchanging-value`（從預算中取出、要用來兌換的金額）。回傳剩下的金額。

```factor
127.5 120 get-change .
! => 7.5
```

## 3. 計算鈔票的價值

定義`value-of-bills`，它接受`denomination`（單張鈔票的面額）和`number-of-bills`。回傳這些鈔票的總價值。

```factor
5 128 value-of-bills .
! => 640
```

## 4. 計算鈔票的張數

定義`number-of-bills`，它接受`amount`和`denomination`。回傳該金額可以換成幾張指定面額的*整張鈔票*。無條件捨去，因為不足一張的鈔票並不存在。

```factor
127.5 5 number-of-bills .
! => 25
```

## 5. 計算兌換成鈔票後的餘額

定義`leftover-of-bills`，它接受`amount`和`denomination`。回傳無法換成整張鈔票的剩餘金額。

```factor
127.5 20 leftover-of-bills .
! => 7.5
```

## 6. 計算兌換後的價值

定義`exchangeable-value`，它接受`denomination`、`budget`、`spread`和`exchange-rate`。

`spread`是以整數表示的*百分比*，作為兌換手續費。它需要以分數的形式加到匯率上。如果`1.00 EUR == 1.20 USD`，而`spread`是`10`，總匯率就是`1.00 EUR == 1.32 USD`（1.20 的 10% 是 0.12，加到 1.20 上）。

回傳套用匯率加上 spread 之後，新貨幣的最大價值，並以指定`denomination`的整張鈔票為單位無條件捨去。回傳值是整數。

```factor
20 127.25 10 1.20 exchangeable-value .
! => 80

5 127.25 10 1.20 exchangeable-value .
! => 95
```

## 7. 安全計算剩餘金額

和`get-change`類似，但如果 Chandler 不小心輸入了比預算還大的兌換金額，就回傳`0`，而不是負數。定義`safe-change`，它接受`budget`和`exchanging-value`。

```factor
127.5 120 safe-change .
! => 7.5

50 100 safe-change .
! => 0
```

## 8. 以預算為上限

Chandler 正在為了買紀念品討價還價。定義`cap-spend`，它接受`budget`和`price`，並回傳兩者中較小的那個，也就是他實際上最多能付的金額。

```factor
100 30 cap-spend .
! => 30

20 30 cap-spend .
! => 20
```
