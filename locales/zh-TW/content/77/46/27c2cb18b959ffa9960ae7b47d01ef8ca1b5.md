# 提示

## 一般

- 測試應用程式裡提供了[`roc-random`套件](https://github.com/kili-ilo/roc-random)，可以使用別名`random`。
  stub 會匯入`random.Random`。

- `Random.Generator(a)`描述的是一個型別為`a`的值要怎麼產生。

- 用`Random.list`把多次抽樣組合起來，再用`Random.map`轉換它們的結果。

- `Random.step(state, generator)`會回傳`{ value, state }`；在各個模擬群組之間傳遞更新後的狀態，這樣才不會重複抽到同樣的樣本。
