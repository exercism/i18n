# 指令

給定一個主音（也就是起始音）和一組音程，請依照指定的音程模式，產生以主音為起始的音階。

西方音樂中的音階建立在半音階（12 個音）之上。這個音階可以表示成下列這組音高：

A, A#, B, C, C#, D, D#, E, F, F#, G, G#

某個升音（以 # 標示）也可以表示成它上方那個音的降音（以 b 標示），所以半音階也可以這樣寫：

A, Bb, B, C, Db, D, Eb, E, F, Gb, G, Ab

大調音階、小調音階和調式都是這十二個音高集合的子集。它們各有七個音高，稱為全音階。這些音階中的音要用升記號還是降記號來寫，取決於主音。以下是哪些屬於哪一類：

無升記號或降記號：
C 大調
a 小調

使用升記號：
G、D、A、E、B、F# 大調
e、b、f#、c#、g#、d# 小調

使用降記號：
F、Bb、Eb、Ab、Db、Gb 大調
d、g、c、f、bb、eb 小調

全音階以及所有其他由半音階衍生出來的音階，都是建立在音程之上。音程是兩個音高之間的距離。

最簡單的音程是兩個相鄰音之間的音程，稱為「半音」或「小二度」（有時寫成小寫的「m」）。兩個音之間還夾著一個音的音程，則稱為「全音」或「大二度」（寫成大寫的「M」）。全音階在相鄰音之間只用這兩種音程來構成。

非全音階的音階可以包含其他音程。增一度音程寫成「A」，中間夾著兩個音（例如從 A 到 C，或從 Db 到 E）。還有更小和更大的音程，但這些不會出現在這個練習裡。
