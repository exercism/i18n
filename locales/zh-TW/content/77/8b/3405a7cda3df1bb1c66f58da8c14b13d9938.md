# 推薦學習資源

## 部落格

- 微軟的 [CommandLine 部落格](https://devblogs.microsoft.com/commandline/) 是學習 Windows 命令列最新功能的絕佳資源。

## 社群媒體

- 你可以用 [StackOverflow](https://stackoverflow.com/questions/tagged/batch-file) 搜尋你的問題，看看是否已經有人回答過。你也可以在上面提問和回答問題。
- [/r/Batch](https://www.reddit.com/r/Batch/) 是 Batch 的 Reddit 看板。

## 影片

- [Batch Tutorials by John Hammond](https://www.youtube.com/playlist?list=PL69BE3BF7D0BB69C4) 的解說對初學者來說很清楚。
- [Batch-Man](https://www.youtube.com/@batch-man/videos) 頻道也定期創作內容，並示範各種技巧。
