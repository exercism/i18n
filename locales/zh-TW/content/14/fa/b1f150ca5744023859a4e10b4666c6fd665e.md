# 提示

## 一般

- [Python 字典教學][dict-tutorial] 是不錯的起點。
- Python 官方文件中的 [Mapping Types - dicts][dict docs] 也很有幫助。

## 1. 根據陣列建立庫存

- 你需要 [for 迴圈][for-loop] 來疊代項目陣列，接著在字典中插入缺少的項目，並使用字典存取子增加該項目的計數。
- 你可以使用[`dict.setdefault`][dict setdefault]來確保在增加項目計數之前先設好值。
- 這個函式應該[回傳][return-keyword]一個字典。

## 2. 將陣列中的項目加入既有的字典

- 你需要 [for 迴圈][for-loop] 來疊代項目陣列，接著在項目尚未存在於字典中時插入該項目，並透過字典存取子[遞增][increment]項目計數。
- 你可以使用[`dict.setdefault`][dict setdefault]來確保在遞增項目計數之前先設好值。
- `create_inventory` 函式可以傳入空字典作為參數，來使用 `add_items` 函式。
- 這個函式應該[回傳][return-keyword]一個字典。

## 3. 從庫存中遞減項目

- 你需要 [for 迴圈][for-loop] 來疊代項目陣列，如果項目數量不是`0`，就[遞減][decrement]目前的項目數量。
- 你可以使用`key in dict`這項檢查，如果鍵存在就會回傳 `True`，藉此確保在遞減項目數量之前，該值已經在字典裡。
- 這個函式應該[回傳][return-keyword]一個字典。

## 4. 從庫存中完全移除某個項目

- 如果項目在字典裡，就[移除它][dict-pop]。
- 如果項目不在字典裡，就什麼都不做。
- 這個函式應該[回傳][return-keyword]一個字典。

## 5. 回傳庫存內容

- 你需要在庫存上使用 [for 迴圈][for-loop]，如果項目數量大於`0`，就把`tuple`附加到`list`。
- 你可以使用[`dict.items()`][dict items]同時疊代項目和值，`items()`會回傳一個`tuple`，你可以視需要直接使用或解構它。
- 這個函式應該[回傳][return-keyword]一個[元組][tuples]的[陣列][list]。
