# 指令

Izzy 是一位熱衷賞鳥的鳥類觀察者，她會記錄每天有多少鳥來訪她的花園。

她請你幫忙，把她的賞鳥體驗提升到新的層次，並實作幾個工具，幫助她追蹤和處理這些資料。

你選擇把資料儲存成整數的陣列。陣列中的第一個數字是今天來訪花園的鳥隻數量，第二個是昨天的，依此類推。

## 1. 檢查今天有多少鳥來訪

實作 `today` 函式。它會接收每日鳥隻數量的陣列，並回傳今天的數量。如果陣列是空的，應該回傳 `0`。

```gleam
today([2, 5, 1])
// -> 2
```

## 2. 增加今天的計數

實作 `increment_day_count` 函式。它會接收每日鳥隻數量的陣列，並把今天的數量加 1。如果陣列是空的，回傳 `[1]`。

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. 檢查是否有沒有鳥來訪的日子

實作 `has_day_without_birds` 函式。它會接收每日鳥隻數量的陣列。如果至少有一天沒有鳥來訪花園，應該回傳 `True`，否則回傳 `False`。如果陣列是空的，這代表_目前為止_還沒有任何鳥隻紀錄，此時回傳 `False`。

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. 計算來訪鳥隻的總數

實作 `total` 函式。它會接收每日鳥隻數量的陣列，並回傳從你開始收集資料以來造訪花園的鳥隻總數。

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. 計算忙碌的天數

有些日子比其他日子忙碌。所謂忙碌的日子，是指有 5 隻以上的鳥來訪你的花園。

實作 `busy_days` 函式。它會接收每日鳥隻數量的陣列，並回傳忙碌日子的數量。

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
