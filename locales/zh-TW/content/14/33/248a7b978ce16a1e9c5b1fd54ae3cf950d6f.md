# 安裝

這個 track 使用 ReScript 12，並且需要 [Node.js][nodejs] 22 以上版本。
許多系統已經預先安裝了它，或者你可能之前為了其他 track 安裝過。

開啟終端機並執行：

```sh
node -v
```

如果沒有安裝 Node，或是列出的版本較舊，請依照你的平台，按照 [Node.js 官方安裝][nodejs-install]的指示進行安裝。

## 安裝相依套件

每個 ReScript 練習都是獨立的 npm 專案。
用 [Exercism CLI][exercism-cli] 下載練習後，安裝專案相依套件（包含 ReScript），就可以開始了：

```sh
cd /path/to/exercise
npm install
```

## 編輯器支援

ReScript 專案維護了一份[官方與社群支援的編輯器外掛清單][rescript-plugins]。
