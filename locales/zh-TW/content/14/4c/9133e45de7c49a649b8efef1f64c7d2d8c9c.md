# 說明

根據 Nicomachus（西元 60 至 120 年）針對正整數的分類法，判斷一個數字是 perfect、abundant 還是 deficient。

希臘數學家 [Nicomachus](https://en.wikipedia.org/wiki/Nicomachus) 為正整數設計了一套分類法，根據[真因數和](https://en.wikipedia.org/wiki/Aliquot_sum)，把每個數字唯一歸入 **perfect**、**abundant** 或 **deficient** 這三類之一。真因數和的定義，是把一個數的所有因數相加，但不包含這個數本身。例如，15 的真因數和是 (1 + 3 + 5) = 9。

- **Perfect**：真因數和 = 該數
  - 6 是 perfect 數，因為 (1 + 2 + 3) = 6
  - 28 是 perfect 數，因為 (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**：真因數和 > 該數
  - 12 是 abundant 數，因為 (1 + 2 + 3 + 4 + 6) = 16
  - 24 是 abundant 數，因為 (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**：真因數和 < 該數
  - 8 是 deficient 數，因為 (1 + 2 + 4) = 7
  - 質數都是 deficient

請實作一個能判斷給定數字是否為 **perfect** 的方法。依你所使用的程式語言而定，你可能還需要實作一個能判斷給定數字是否為 **abundant** 或 **deficient** 的方法。
