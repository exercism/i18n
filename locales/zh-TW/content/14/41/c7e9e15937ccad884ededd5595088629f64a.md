# 指令

密碼轉盤是兩個疊在一起的圓盤，轉動時會帶動整個字母表：把它設定到 3，每個字母就會變成往後數 3 個位置的字母，`z` 則會繞回來變成 `a`。偵探們已經用了好幾個世紀。現在換你來打造一個。

這 5 個任務都放在`CIPHER_WHEEL`類別裡。

## 1. 它是字母嗎？

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. 大聲喊出來

回傳字元的大寫。任何不是字母的內容都會原樣回傳。

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. 它的數字是多少？

回傳代表某個字元的數字。

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. 第一個字元

回傳字串的第一個字元。

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. 轉動轉盤

給定一個小寫字母和一個位置數，回傳字母表中往後數那麼多位置的字母。超過 `z` 就會繞回來變成 `a`。

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

用負數的位置數也能往回轉。

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

你可以假設傳入的字元是小寫字母。
