# 簡介

## 陣列

陣列是 Elixir 語言內建的資料結構。它們被視為一種基本型別，以方括號表示。陣列可以是空的，也可以存放任意數量的項目，項目可以是任何型別。例如：

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir 將陣列實作成連結陣列，其中每個節點儲存 2 個值：第一個項目，以及包含其餘所有項目的另一個陣列。陣列中的第一個項目稱為_頭_，其餘項目組成的陣列則稱為_尾_。我們可以在程式碼中使用這種表示法：

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

我們可以使用 _`[head | tail]`_ 表示法將元素加到陣列的前面：

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

`Kernel`模組中有幾個處理陣列的函式，另外還有完整的`List`模組。

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
