# 關於

字串代表文字資料。
在 Swift 中，[`String`][strings-and-characters]是一組有序的`Character`值集合，其中每個字元都代表一個 Unicode 字元。

你可以使用字串常值建立字串，字串常值就是一連串以雙引號（`"`）包住的字元。
若要多行字串，請使用三個雙引號（`"""`）：

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift 字串能與 Foundation 框架的 [`NSString`][nsstring-docs] 類別無縫互通，讓你能運用豐富的文字處理功能。

## 字元

`Character`代表單一擴充字素叢集（extended grapheme cluster），也就是由一個或多個 [Unicode 純量值][unicode-scalar-values]所組成人類可讀的字元。
Unicode 純量值是一個 21 位元的碼點，範圍從 `U+0000` 到 `U+D7FF`（含），或從 `U+E000` 到 `U+10FFFF`（含）。

```swift
let aChar: Character = "A"
```

## 型別推論

當你寫下字串常值時，Swift 會自動將它的型別推論為`String`。
若要把單一字元儲存為`Character`，你必須提供明確的型別註解：

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## 串接

你可以使用加法運算子（`+`）把字串串接起來：

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

如果不先把字元轉換成字串，就無法直接用`+`把`Character`串接到`String`。
不過，你可以使用 [`append(_:)`][append] 方法，直接把字串或字元附加到可變字串：

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## 字串插值

[字串插值][string-interpolation]讓你能在字串常值中嵌入常數、變數、常值和運算式，藉此建構字串。
把每個運算式放進括號裡，並在括號前加上反斜線（`\(` ... `)`）：

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## 字串與字元的屬性

字串和字元都提供幾個屬性，讓你檢視它們的內容。

### 字串屬性

常見的字串屬性包括：

| 屬性  | 說明                                    | 範例                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | 若字串沒有任何字元就回傳 `true` | `"Hello".isEmpty` 的結果是 `false` |
| `count`   | 回傳字串中的字元數 | `"Hello".count` 的結果是 `5`       |

完整的屬性清單請參閱 [Apple 的 String 文件][string-docs]。

### 字元屬性

常見的字元屬性包括：

| 屬性       | 說明                                   | 範例                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | 若字元是小寫就回傳 `true`  | `"a".isLowercase` 的結果是 `true` |
| `isUppercase`  | 若字元是大寫就回傳 `true`  | `"A".isUppercase` 的結果是 `true` |
| `isNumber`     | 若字元是數字就回傳 `true`    | `"1".isNumber` 的結果是 `true`    |
| `isWhitespace` | 若字元是空白就回傳 `true` | `" ".isWhitespace` 的結果是 `true`|

完整的屬性清單請參閱 [Apple 的 Character 文件][character-docs]。

## 型別轉換

你可以使用`String(_:)`初始化器把其他型別轉換成字串，它支援`Int`、`Double`和`Character`等標準型別：

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## 特殊字元

Swift 字串常值支援多種用於特殊字元的[跳脫序列][special-characters]：

| 序列   | 說明                   |
| ---------- | ----------------------------- |
| `\0`       | 空字元                |
| `\\`       | 反斜線                     |
| `\t`       | 水平定位字元                |
| `\n`       | 換行字元           |
| `\r`       | 回車字元               |
| `\'`       | 單引號         |
| `\"`       | 雙引號         |
| `\u{n}`    | 任意 Unicode 純量（十六進位） |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
