# 提示

## 一般

- 閱讀 Apple 的《A Tour of Swift》中關於 [optional][optionals] 和 [條件式][conditionals] 的內容。

## 1. 撰寫一個計算切片大小的函式，在輸入無效時回傳 nil。

- 圓的面積是 _pi_ \* _r_<sup>2</sup>，其中 _r_ 是直徑的一半。
- 你可以使用型別轉換，把 `Int` 轉成 `Double`。
- 如果任一參數無效，可以使用 guard 風格的條件式提早結束。

## 2. 處理來自網頁應用程式的輸入，判斷比較大的那一片切片。

- 可以使用 optional binding 來判斷某個 optional 是否有值，並在有的話取出該值。
- 如果你不需要進一步處理就知道回傳值應該是什麼，可以提早結束函式。
- 你不能直接把 `nil` 和非 nil 的值相比較。
- 你可以使用 `switch` 敘述和 optional 模式來比較 optional 值。

[conditionals]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
