# 燃料補助

## 問題陳述

ABC Corp 的每位員工都能獲得無限的燃料補助。員工每次為車輛加油時，都必須提交一筆紀錄。這些紀錄會附加到同一個 CSV 檔案，並在月底時統一處理。

身為數位營運團隊的一員，你的任務是讀取這個 CSV 檔案，並將結果寫入另一個 CSV 檔案。輸出檔案應為每位員工包含一筆資料，內容如下：

- 員工編號
- 加油次數
- 燃料總費用
- 總加侖數
- 累計總里程

你會收到兩個`string`引數。

1. 輸入 CSV 檔案路徑
1. 輸出 CSV 檔案路徑

輸入 CSV 檔案有`n`行，每一行的格式如下。

| 欄位名稱      | Ballerina 型別 |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

輸出檔案應為每位員工包含一筆資料，並依`employee_id`遞增排序。每一行的格式如下：

| 欄位名稱      | Ballerina 型別 |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## 限制

- 輸入 CSV 檔案的行數`n`：2 <= n <= 1000
- 公司員工數：97
- 油價以每加侖計
- 沒有遺漏的加油紀錄

## 範例 1

- 輸入：`example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- 輸出：`example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```

## 提示

- 使用 [`ballerina/io` 模組](https://lib.ballerina.io/ballerina/io/latest)來讀寫 csv 檔案
- 輸入與輸出檔案不會／不應包含標頭
- [Ballerina 表格語法](https://ballerina.io/learn/by-example/table)
