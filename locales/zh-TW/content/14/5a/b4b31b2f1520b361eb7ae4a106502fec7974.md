# 簡介

在 Haxe 中，`class` 是最主要的資料結構，它封裝了資料（欄位）與行為（方法）。欄位和方法也合稱為類別的成員。

成員的存取可以透過存取修飾子來限制，這些修飾子包括：

- `public`：成員可以從任何地方存取。
- `private`：成員只能由同一個類別存取。

類別可以想成是建立實例的範本。要建立實例，只要使用 `new` 關鍵字：

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

要定義欄位，請先寫存取修飾子，接著寫變數名稱與型別：

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

定義欄位時，你也可以設定初始值。如果欄位沒有指定初始值，它的值會是 `null`。你可以使用點記法存取欄位：

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
