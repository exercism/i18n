# 簡介

`MACRO:`宣告就像`:`，但它的主體會在*編譯期*執行，而且必須回傳一個 quotation。編譯器會用回傳的 quotation 取代巨集呼叫。因為主體就是普通的 Factor 程式碼，所以建立結果 quotation 只是在操作由 word 組成的序列。

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

巨集的輸入是*呼叫位置的字面值*。如果你傳入非字面值，編譯器就會拒絕特化，因為巨集主體需要在編譯期拿到這個值，而不是在執行期。

和它關係密切的是`<< … >>`解析期求值區塊，它會在編譯期執行任意的 Factor 程式碼，但不受回傳 quotation 這項約定的限制。兩者都屬於 Factor 的[`macros`][macros]機制。

[macros]: https://docs.factorcode.org/content/vocab-macros.html
