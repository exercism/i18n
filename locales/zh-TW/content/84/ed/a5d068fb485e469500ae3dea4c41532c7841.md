# 補充說明

## 輸入格式

每個骨牌都儲存為單一位元組，左半部放在高位[半位元組][nibble]，右半部放在低位[半位元組][nibble]。例如，骨牌`[2|1]`、`[2|3]`和`[1|3]`會表示為位元組`0x21 0x23 0x13`。

## 暫存器

| 暫存器   | 用途     | 型別   | 說明                                        |
| -------- | -------- | ------ | ------------------------------------------- |
| `$a0`    | 輸入     | 位址   | 骨牌位元組的陣列                            |
| `$a1`    | 輸入     | 整數   | 骨牌的數量                                  |
| `$v0`    | 輸出     | 布林值 | 骨牌能否串連（`0` = `false`，`1` = `true`） |
| `$t0-9`  | 暫時     | 任意   | 用於暫存資料                                |


[nibble]: https://en.wikipedia.org/wiki/Nibble
