# 提示

## 一般

- 你需要的字串詞彙位於[`splitting`][splitting]和[`sequences`][sequences]；`blank?`則在`ascii`裡。過程中記得更新你的`USING:`那一行。

## 1. 清理名字

- `replace ( seq old new -- new-seq )`會做子字串的取代。
- `[ blank? ] trim`會去除開頭與結尾的空白。

## 2. 取得名字的第一個字母

- 呼叫`cleanupname`之後，用`first`取出第一個字元，再用`1string`把它包成只有一個字元的字串。

## 3. 把第一個字母格式化為縮寫

- 用`>upper`（在`ascii`裡）把字母轉成大寫，然後在結尾`append`一個`"."`。

## 4. 把縮寫放進愛心裡

- `bi@ ( x y quot -- ... )`是用單一次組合子呼叫，把`initial`套用到兩個名字上的自然做法：`[ initial ] bi@`。
- 執行`bi@`之後，堆疊上會有兩個縮寫。用`glue`以分隔符號將它們接起來，再用`surround`以愛心的前置與後置字串把結果包起來。
- 在 Factor 字串常值裡，愛心字元是`\u{2764}`。

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
