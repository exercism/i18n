# 二進位、八進位、十六進位

二進位、八進位與十六進位（也稱為 hex）是不同的[數字系統][numeral-systems]，各有不同的基數。
二進位是基數 2，八進位是基數 8，十六進位則是基數 16。
在 python 中，一般的整數是基數 10。
二進位、八進位與十六進位的字面值都算是 `int` 的子型別，Python 會自動在它們之間轉換。
這表示它們只能表示沒有小數或分數部分的零、正數與負數。
二進位、八進位與十六進位數字支援所有整數運算。
不過，除法（和整數一樣）會回傳 `float`。

[numeral-systems]: https://en.wikipedia.org/wiki/Numeral_system
