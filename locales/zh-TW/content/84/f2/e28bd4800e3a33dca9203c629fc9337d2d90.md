# 提示

## 一般

- 每個任務都是把一個值拿去和一個固定陣列比對，這正是`case`的用途。
- 每個`case`都需要一個`else`，即使上面的分支看起來已經很完整。少了`else`，比對不到任何分支的值會讓程式中止。

## 1. 某個區域的車資

- 三個`when`分支和一個`else`。`else`涵蓋所有不屬於任何區域的數字。
- 第 0 區和未知的區域都免費，但兩者是不同的情況；分成兩個分支來寫，才說得出你真正要表達的意思。

## 2. 是哪一種票？

- `'c'`和`'s'`的結果相同，所以共用一個分支：`when 'c', 's' then`。
- 單引號：這裡的引數是`CHAR`，不是`STR`。

## 3. 是哪一種日子？

- 兩個分支，一個列出兩天，另一個列出五天。
- 字串用`=`比較的方式和數字一樣，所以不必改寫就能放進`case`裡。

## 4. 每日上限

- 你已經有一個能把日子轉成日子類型的函式。呼叫它，然後對結果做`case`。
- 這樣寫，日子的清單就只會出現一次。在這裡重複列出，就是這個任務設計來抓出的錯誤。
