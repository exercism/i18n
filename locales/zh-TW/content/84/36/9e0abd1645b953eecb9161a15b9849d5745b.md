# 基礎

## 開始入門

### 變數

要宣告一個[變數][variables]，請使用`=`賦值運算子。
在 Crystal 中，變數應採用 [snake_case][snake-case] 格式。

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### 常數

[常數][constants]使用相同的`=`賦值運算子宣告，但要使用全大寫字母，也就是 SCREAMING_SNAKE_CASE。

```crystal
NUMBER = 1
puts NUMBER # => 1
```

將值指定給已經定義過的常數會導致編譯期錯誤。

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### 型別

Crystal 是編譯式語言，意思是每個變數或方法引數在編譯期都會被賦予一個型別。
編譯器能夠推斷變數或方法引數的型別。
不過，在某些情況下，必須明確指定型別。
需要設定型別的情況會在後續的概念中說明。

### 方法

[方法][methods]是一種將一組指令群組起來以便重複使用的方式。
在 Crystal 中，方法通常定義於類別、模組或結構裡。
不過，方法也可以定義在類別、模組或結構之外。
方法使用`def`關鍵字宣告，後面接著方法名稱。
在 Crystal 中，方法應以 snake_case 撰寫。
當方法沒有任何引數時，可以省略括號。
要宣告方法的結束，你必須使用`end`關鍵字。

```crystal
def hello
  puts "Hello World!"
end
```

對變數或方法引數的型別使用不存在的方法，會導致編譯期錯誤。

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### 引數

方法可以帶有[引數][arguments]。
引數是傳遞給方法的資料。
為了讓方法能接受引數，你必須指定引數的名稱。
在 Crystal 中，引數應以 snake_case 撰寫。
一個方法可以有多個引數，但引數之間必須以逗號分隔。

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

方法也可以有多個引數。
在這種情況下，引數之間必須以逗號分隔。

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### 呼叫方法

呼叫屬於類別、模組或結構的方法時，你必須使用點運算子（`.`）。
格式應為：`<ClassName>.<method_name>`。
當方法不屬於類別、模組或結構時，你只要寫出它的名稱即可呼叫。
方法一律隱式回傳最後一個運算式的值。

當方法有引數時，在方法呼叫與定義中指定引數時可以使用括號，如下所示：`<method_name>(<argument_1>, <argument_2>, ...)`。
當方法沒有引數時，應省略括號。

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

呼叫帶有多個引數的方法時，引數之間應以逗號分隔。
引數的順序必須與方法引數的順序相同。

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

以錯誤的引數數量呼叫方法會導致編譯期錯誤。

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### 加法、減法與乘法

在 Crystal 中，你可以使用`+`運算子將兩個數字相加。
你也可以使用`-`運算子將兩個數字相減。
還可以使用`*`運算子將兩個數字相乘。

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### 註解

在 Crystal 中，[註解][comments]是以`#`字元撰寫，後面接著一個空格，然後才是註解內容。
註解用來為程式碼留下說明。
編譯器不會執行註解。

```crystal
# This is a comment
```
