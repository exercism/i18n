# 指令

在這個練習中，你要幫助高中情侶在社群媒體上表達愛意，用他們的姓名縮寫產生一個 ASCII 愛心：

```
❤ J.  +  M. ❤
```

## 1. 清理名字

實作`HighSchoolSweetheart.clean_up_name`方法。
它應該接收一個名字，移除其中所有的`-`字元並以空格取代。
它還應該移除名字開頭和結尾的任何空白。

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. 取得名字的第一個字母

實作`HighSchoolSweetheart.first_letter`方法。
它應該接收一個名字並回傳它的第一個字母。
記得重複使用你在前一步定義的`HighSchoolSweetheart.clean_up_name`。

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. 將第一個字母格式化為姓名縮寫

實作`HighSchoolSweetheart.initial`方法。
它應該接收一個名字，回傳它的第一個字母，轉成大寫，後面加上一個句點。
記得重複使用你在前一步定義的`HighSchoolSweetheart.first_letter`。

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. 把姓名縮寫放進愛心裡

實作`HighSchoolSweetheart.pair`方法。
它應該接收兩個名字，回傳前後帶有愛心表情符號的姓名縮寫。
記得重複使用你在前一步定義的`HighSchoolSweetheart.initial`。

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
