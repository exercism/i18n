# 指令補充

Julia Base 中複數的實作可以在這裡找到：https://github.com/JuliaLang/julia/blob/master/base/complex.jl。

---

## 加分題 A
你可以取消註解 `# enable_realcomplex_tests = true`，來練習實數與複數之間運算的加分題，這行程式位於 `complex-numbers.jl` 這個 stub 檔或 `runtests.jl` 中。

## 加分題 B
你可以取消註解 `# enable_syntaxsugar_tests = true`，來練習實數與複數之間的加分題，這行程式位於 `complex-numbers.jl` 這個 stub 檔或 `runtests.jl` 中。
接著，仿照 `im` 實作 `jm`，讓 `1 + 1jm == ComplexNumber(1, 1)` 成立。
