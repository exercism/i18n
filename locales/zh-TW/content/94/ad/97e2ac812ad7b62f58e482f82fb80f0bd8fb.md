# 簡介

在`Types`概念中，我們學到了：

- 型別在 Julia 中會形成一個階層。
- 每個型別都有一個超型別。
- `Any`位於階層的最頂端，而且它自己就是自己的超型別。
- 型別_可能_會有子型別，而那些有子型別的型別稱為`abstract types`。
- 沒有子型別的型別（樹狀結構上的葉節點）稱為`concrete types`。
- 無法再分割的型別，例如`Char`或`Int64`，稱為`primitive types`。

只有`primitive`型別會以最單純的形式遵循抽象與具體的模式。`Vector`是一種集合，可以拆分為擁有各自型別的元素。

```julia-repl
julia> isprimitivetype(Int)
true

julia> isprimitivetype(Vector)
false
```

_什麼東西的集合？_

每個向量（或集合）都是元素的集合，這些元素具有某種統一的型別；這個型別可以用大括號`{ }`中的_參數_來指定，也可以省略，讓型別推論來決定。

```julia-repl
julia> v = [1, 2, 3]
3-element Vector{Int64}:
 1
 2
 3

julia> v8 = Vector{Int8}([2, 4, 6])
3-element Vector{Int8}:
 2
 4
 6
```

這些`parametric types`是`generic programming`的一種形式，許多現代語言也有大致對應的東西，只是細節上差異不少。

## 參數化複合型別

有時我們會想建立一個彈性（泛用）到足以處理不同欄位型別的複合型別。

這可以透過在定義中放入一個虛設型別來達成，這個型別通常稱為`T`。

```julia-repl
julia> struct Point{T}
               x::T
               y::T
       end

# high definition version

julia> real_point = Point(7.3, 4.2)
Point{Float64}(7.3, 4.2)

julia> typeof(real_point)
Point{Float64}

# low definition version

julia> int8point = Point{Int8}(17, 23)
Point{Int8}(17, 23)

julia> typeof(int8point)
Point{Int8}

julia> Point(Int8(17), Int8(23))
Point{Int8}(17, 23)
```

當然，這個做法也適用於欄位中的集合：

```julia-repl
julia> struct Record{T}
           data::Vector{T}
           comment::String
       end

julia> rec = Record{Float64}([1.3, 5.2], "some data")
Record{Float64}([1.3, 5.2], "some data")

julia> rec.data
2-element Vector{Float64}:
 1.3
 5.2

julia> rec2 = Record{Int32}([3, 5], "more data")
Record{Int32}(Int32[3, 5], "more data")

julia> rec2.data
2-element Vector{Int32}:
 3
 5
```
