# 簡介

在 Python 中，`str`是一種[不可變序列][text sequence]，由 [Unicode 碼點][unicode code points]組成。
這些碼點可能包含字母、變音符號、定位字元、數字、貨幣符號、表情符號、標點符號、各種空白、換行，以及更多其他內容。

字串實作了所有[常見序列操作][common sequence operations]，可以用`for item in <str>`或`for index, item in enumerate(<str>)`語法疊代。
可以用`<str> + <other str>`或`<str>.join(<iterable>)`串接，用`<str>.split(<separator>)`分割，並提供多種格式化與組合的選項。

為了進一步處理字串，Python 提供了一組豐富的[字串方法][str-methods]，可以協助搜尋、清理、轉換、翻譯，以及許多其他操作。

`str`是_不可變_的，因此`str`物件在記憶體中的值不會改變；那些看似會修改字串的方法，其實會回傳該`str`物件的新副本或新實例。
