# 資料庫：大額支出

## 問題陳述

ABC Corp 需要你找出付款金額大於指定金額（例如`3000.00`）的員工姓名與部門。

建立一個名為`HighPayment`的記錄來回傳所需的資料。該記錄的定義如下。

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

使用 JDBC client 的`query`操作，從資料庫取得所需的資料。

> 注意：請依`payment_id`遞增排序結果。

## 資料庫詳細資訊

本題請使用提供的 H2 資料庫。

> 範例資料庫檔案為`gofigure.mv.db`，資料庫名稱為`gofigure`，位於`db`資料夾內。

範例 H2 資料庫中已經有下列資料表，並包含一些範例資料。欄位名稱與資料型態如下。

**資料表名稱**：`Employee`

| **欄位：**      | 型別 |
| -----------       | ----------- |
| `employee_id`     | 整數，自動遞增主鍵       |
| `name`            | 字串        |
| `city`            | 字串        |
| `department`      | 字串        |
| `age`             | 整數        |

**資料表名稱**：`Payment`

| **欄位：**      | 型別 |
| -----------       | ----------- |
| `payment_id`      | 整數，自動遞增主鍵       |
| `date`            | 日期        |
| `amount`          | 小數        |
| `employee_id`     | 整數        |
| `reason`          | 字串        |

* 資料庫檔案為`gofigure.mv.db`。JDBC URL 請使用`jdbc:h2:file:/path/to/db/file`
* 使用者名稱：`root`
* 密碼：`root`

## 限制條件

* 使用`db`資料夾中提供的 H2 資料庫檔案來驗證查詢與 Ballerina 範例
* 使用 maven dependency params 方式，在 Ballerina.toml 中將 H2 資料庫驅動程式新增為平台相依性

## 測試環境

* 你可以用`bal test`執行測試，測試會對提供的範例資料庫執行。

## 範例

### 範例 1

**輸入：** dbFilePath：`“/Path/to/file/gofigure”`，amount：`3000`

**輸出：** `[{"name":"Anita Bath","department":"Marketing", "amount":3400, "reason": "Stationary"}, {"name":"Amanda Hug","department":"Engineering", "amount":4400, "reason": "Travel expenses"}]`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模組來操作資料庫
* 參考[先決條件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)一節，了解將 JDBC 驅動程式新增為相依性的步驟
* 使用 [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) 遠端方法從資料庫查詢資料
* 參考[簡單查詢](https://ballerina.io/learn/by-example/mysql-query-operation)範例
* 使用 Ballerina 的 [stream](https://ballerina.io/learn/by-example/stream-type) 型別來存取資料
* 使用 SQL join 從資料庫找出所需的資料集
