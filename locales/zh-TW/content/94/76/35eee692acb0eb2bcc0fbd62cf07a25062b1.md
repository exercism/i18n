# 說明

你是聖誕老人物流部門的一名精靈，老闆交給你兩項任務，要升級系統的軟體。

## 1. 取得玩具的名稱

系統需要能夠從資料庫中取得玩具的名稱。
資料庫是由`(name: String, quantity: Int)`型別的元組所組成。

請實作`getName(_:)`函式，它接收一個引數，該引數存放`(name: String, quantity: Int)`型別的元組。

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. 將新玩具加入資料庫

玩具市場瞬息萬變，熱門的商品變化得非常快。
因此，我們需要一個能建立新玩具的函式。

請實作`createToy(name:amount:)`函式，它接收引數`name`（存放玩具的名稱）與`amount`（存放玩具的數量）。

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. 更新玩具的數量

聖誕老人工作坊裡的精靈不斷製作出更多玩具，而聖誕老人需要掌握每種玩具的數量。
為此，系統必須能夠更新資料庫中玩具的數量。

請實作`updateQuantity(_:toy:Amount:)`函式，它接收以下引數：
- `toys`：存放`(name: String, quantity: Int)`型別的元組陣列。
- `toy`：要更新的玩具名稱。
- `amount`：玩具的新數量。

你可以假設該玩具已經在資料庫中，不需要再檢查。

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. 為玩具加上分類鍵

聖誕老人希望能將資料庫中的玩具分類。
這樣一來，在需要送貨時就能輕鬆找到玩具，也能對資料庫中的玩具進行排序。

然而，系統最初建置時忘了加上分類鍵。
現在系統需要能夠為資料庫中的玩具加上分類鍵。

請實作`addCategory(_:category:)`函式，它接收以下引數：
- `toys`：存放`(name: String, quantity: Int)`型別的元組陣列。
- `category`：要加到玩具上的分類鍵。

你可以假設該玩具已經在資料庫中，不需要再檢查。
你也可以假設該玩具還沒有任何分類鍵。

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
