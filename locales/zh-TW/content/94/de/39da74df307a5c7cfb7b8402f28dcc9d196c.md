# 指令

在這道練習中，你將為一位朋友正在開發的新 RPG 遊戲實作任務邏輯。

遊戲的主角是 Annalyn，一個勇敢的女孩，身邊帶著一隻凶猛又忠誠的寵物狗。不幸的是，災難降臨了：她最好的朋友在森林裡採集莓果時被綁架了。

Annalyn 將試著找到並救出她最好的朋友，這次冒險中她可以選擇帶上她的狗。

沿著好朋友留下的蹤跡走了一段時間後，她找到了囚禁她好友的營地。原來綁匪有兩個人：一位強壯的騎士和一位狡猾的弓箭手。

找到綁匪後，Annalyn 思考自己可以採取下列哪些行動：

- _快速攻擊_：如果騎士正在睡覺，就可以發動快速攻擊，因為他需要花點時間穿上盔甲，這段期間他會很脆弱。
- _偵查_：只要至少有一個人醒著，就可以對這群人進行偵查。否則偵查只是浪費時間。
- _對囚犯打信號_：如果囚犯醒著而弓箭手正在睡覺，就可以用鳥叫聲向囚犯打信號，因為弓箭手受過鳥叫信號的訓練，可能會攔截訊息。
- _釋放囚犯_：Annalyn 可以試著潛入營地解救囚犯。
  這是有風險的行動，只有在兩種情況下才會成功：
  - 如果 Annalyn 帶著她的寵物狗，只要弓箭手在睡覺，她就能救出囚犯。
    騎士怕狗，而弓箭手在 Annalyn 和囚犯逃脫前來不及做好準備。
  - 如果 Annalyn 沒有帶狗，她和囚犯就必須非常小心翼翼地行動！
    如果囚犯醒著，而騎士和弓箭手都在睡覺，Annalyn 就能釋放囚犯；但如果囚犯正在睡覺，就沒辦法救他：囚犯會被 Annalyn 突然出現嚇到，因而吵醒騎士和弓箭手。

你有四項任務：根據森林中這三個角色的狀態，以及 Annalyn 的寵物狗是否在場，實作判斷上述行動是否可行的邏輯。

## 1. 檢查是否可以發動快速攻擊

實作 `canFastAttack()` 方法，它接受一個布林值，表示騎士是否醒著。這個方法會根據騎士的狀態，在可以發動快速攻擊時回傳 `true`，否則回傳 `false`：

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. 檢查是否可以偵查這群人

實作 `canSpy()` 方法，它接受三個布林值，分別表示騎士、弓箭手和囚犯是否醒著。這個方法會根據這三個角色的狀態，在可以偵查這群人時回傳 `true`，否則回傳 `false`：

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. 檢查是否可以對囚犯打信號

實作 `canSignalPrisoner()` 方法，它接受兩個布林值，分別表示弓箭手和囚犯是否醒著。這個方法會根據這兩個角色的狀態，在可以對囚犯打信號時回傳 `true`，否則回傳 `false`：

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. 檢查是否可以釋放囚犯

實作 `canFreePrisoner()` 方法，它接受四個布林值。前三個參數分別表示騎士、弓箭手和囚犯是否醒著。最後一個參數表示 Annalyn 的寵物狗是否在場。這個方法會根據這三個角色的狀態以及 Annalyn 的寵物狗是否在場，在可以釋放囚犯時回傳 `true`，否則回傳 `false`：

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
