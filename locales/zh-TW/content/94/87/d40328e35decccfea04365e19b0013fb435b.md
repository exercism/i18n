# 精確數字

你已經認識的數字型別當中，有兩種做出了取捨。

`INT` 正好是 32 位元，所以能容納的數字大約從負 20 億到 20 億，再大就不行了。一旦超出這個範圍，它會默默繞回，不會報錯，只會給你一個錯誤的答案。

`FLTD` 能容納小數，但只是近似值。`0.1d + 0.2d` 非常接近 `0.3`，但不是剛好等於。

如果需要處理這類要求精確的工作，函式庫裡各有一種型別可用。

## INTI：任意大小的整數

`INTI` 可以容納任意大小的整數，唯一的限制是記憶體。

```sather
   #INTI(2).pow(100)
   -- 1267650600228229401496703205376
```

`INT` 裝不下這個數字。`FLTD` 可以裝下接近它的值，但會丟掉最後二十位數字。

可以從 `INT` 建立，或在數字太大、一開始就沒辦法寫成 `INT` 時，從字串建立：

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
```

接下來 `+`、`-`、`*`、`/` 和比較都照常運作，而 `.str` 會給出每一位數字。

計算一個舞團能有幾種排列方式，是想要這種型別的典型理由。十二位舞者有 479001600 種排法，`INT` 裝得下；十三位有 6227020800 種，就裝不下了。

```sather
   #INTI(20).factorial
   -- 2432902008176640000
```

## RAT：精確的分數

`RAT` 以一個整數除以另一個整數來表示，並保持這樣。

```sather
   #RAT(1, 3)          -- 1/3, exactly
   #RAT(1, 2) + #RAT(1, 3)
   -- 5/6
```

因為沒有任何東西會被轉換成小數，所以不會發生捨入。

```sather
   #RAT(1, 10) + #RAT(2, 10) = #RAT(3, 10)      -- true
   0.1d + 0.2d = 0.3d                            -- not to be relied on
```

`RAT` 會自我約分：`#RAT(2, 4)` 是 `1/2`，印出來也是 `1/2`。約分後剛好是整數的，會印成整數：`#RAT(6, 3)` 印出 `2`。

## 代價

兩者都比內建型別慢，而且都會配置記憶體。`INT` 和 `FLTD` 是單一機器指令；`INTI` 和 `RAT` 則是在軟體中做算術的物件。

在精確度正是重點的地方使用它們，其他地方就用一般的型別。
