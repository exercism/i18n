# 說明

Elena 是報紙工廠的新任品質經理。
她才剛到公司，便決定檢視工廠裡的一些流程，看看有什麼可以改進的地方。

她發現技術人員做了許多手動的品質檢查。

她看到這是導入自動化的好機會，於是請你這位自由接案的開發者設計一套軟體，來監控部分機器。

## 1. 監控房間的濕度

你的第一項任務，是寫一套軟體來監控生產室的濕度。
公司的軟體已經連接了一個感測器，會定期回傳房間的濕度百分比。

你需要在軟體中實作一個函式，當濕度百分比過高時會拋出錯誤。
這個函式應該命名為`check_humidity_level`，並以濕度百分比作為參數。

如果百分比超過 70%，你應該以錯誤中止執行（訊息內容不重要）。
否則，發出一則包含「humidity test passed」的訊息，並回傳`TRUE`來確認測量結果正常。

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. 偵測過熱

Elena 對你的第一項任務非常滿意，請你負責監控機器的溫度。
你和技術人員 Greg 聊天時得知，如果機器的溫度超過 500°C，技術人員就會開始擔心過熱。

機器上裝有一個感測器，用來測量內部溫度。
你要知道，這個感測器非常敏感，而且經常損壞。
這種情況下，技術人員就必須更換它。

你的工作是實作一個函式`report_overheating`，以溫度作為參數，並在感測器損壞或機器開始過熱時拋出錯誤。

由於之後必須根據不同的錯誤做出不同反應，你需要一套機制來區分這兩種錯誤。

- 如果感測器損壞，溫度會是`NULL`。
  這種情況下，你應該以錯誤訊息中止執行，訊息字串中要包含「Sensor Broken」。
- 當感測器正常運作時，如果溫度超過 600°C，你應該以包含該溫度的訊息中止執行。
- 如果溫度超過 500°C 但未達 600°C，你應該發出包含該溫度的警告，並回傳`FALSE`。
- 否則一切正常，發出訊息`"temperature check passed: t °C"`，其中`t`是溫度，並回傳`TRUE`。

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. 監控機器

現在你的機器已經能偵測錯誤，你也有自訂的機器錯誤，接著你要加入一個包裝函式，用來回報整體運作情況。
除了回傳前面幾個函式的日誌，這個包裝函式還需要依據發生的失敗類型加入日誌。

- 檢查濕度與溫度。
- 如果有問題，就讓`check_humidity_level()`和`report_overheating()`輸出各自的日誌。
- 如果一切正常，加入一則包含「All OK」的訊息。

實作一個函式`monitor_the_machine()`，以濕度與溫度作為引數。

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
