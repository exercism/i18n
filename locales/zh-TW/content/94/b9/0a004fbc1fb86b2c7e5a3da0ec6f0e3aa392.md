# 簡介

在 Cairo 中，布林值是由預先宣告的布林型別`bool`表示，其值可以是`true`或`false`。

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo 支援三種邏輯運算子，能將運算式求值為布林值，並回傳`true`或`false`。

| 運算子    | 意義                                 |
| ----------- | --------------------------------------------- |
| `&&`（且）  | 若兩個敘述皆為 true，則為 true。       |
| `\|\|`（或） | 若至少一個敘述為 true，則為 true。 |
| `!`（非）   | 只有當敘述為 false 時，才為 true。    |
