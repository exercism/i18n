# 說明

在這個練習中，你將建立一台磅秤的模型，並以公斤作為單位。

這個練習共有 6 個任務，每個任務都需要你實作一或多個屬性：

## 1. 讓磅秤具有精度

為了滿足不同的需求，我們讓每台磅秤都能自訂精度（小數分隔符號後面的位數）。
實作`WeighingMachine`類別，讓它有一個唯讀的`Precision`屬性，其值為建構子的`precision`引數：

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. 讓磅秤可以設定重量

實作`WeighingMachine.Weight`屬性，讓重量可以被取得*和*設定：

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. 確保負數的輸入重量會被拒絕

很顯然地，重量不可能是負數。
為`WeighingMachine.Weight`屬性加上驗證，在嘗試將它設為負數重量時擲回`ArgumentOutOfRangeException`：

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. 讓磅秤可以套用皮重調整

皮重調整可以是任何值（甚至是負數，或是會讓顯示重量變成負數的值）。
實作`WeighingMachine.TareAdjustment`屬性，讓皮重調整可以被設定：

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. 確保磅秤有預設的皮重調整

經過一番徹底測試後，發現因為製造上的問題，所有磅秤都會將重量高估`5`。
將`WeighingMachine.TareAdjustment`屬性的預設值改為`5`。

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. 讓重量可以被取得

實作`WeighingMachine.DisplayWeight`屬性，它應該回傳一個字串，顯示經過皮重調整後的重量，並套用正確的精度，再加上單位。
請注意：
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
