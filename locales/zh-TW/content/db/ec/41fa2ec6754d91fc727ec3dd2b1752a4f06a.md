# 型別宣告

PHP 的型別宣告會在執行時期，為函式引數、回傳值與類別屬性提供型別斷言。
在函式上，可以加上 `void` 回傳型別，表示這個函式不會回傳任何值。
宣告的型別也會做為執行時期的斷言，確認函式回傳的回應型別合理。

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## 聯合型別

如果某個函式引數、回傳值或類別屬性可以有多種型別，就可以宣告聯合型別。

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## 混合型別

在撰寫程式碼時，我們可能沒辦法指定型別。
從 PHP 8.0 開始，提供了一個名為 `mixed` 的逃生出口型別。
`mixed` 等同於 `object|resource|array|string|float|int|bool|null` 的聯合型別。
