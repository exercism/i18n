# 說明

在這個練習中，你的任務是為一台加密裝置撰寫軟體，這台裝置的運作方式是對資料進行轉換。你需要一種方法，能透過組合較簡單的函式，靈活地建立複雜的函式。

每個任務都要回傳一個匿名函式，且該函式可以從呼叫端的作用域中呼叫。

所有函式都應接受整數引數。在 Elixir 中，整數也很適合用來執行位元運算。

## 1. 建立加法器

實作 `Secrets.secret_add/1`。它應該回傳一個函式，該函式接受一個引數，並將傳入 `secret_add` 的引數加到這個引數上。

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. 建立減法器

實作 `Secrets.secret_subtract/1`。它應該回傳一個函式，該函式接受一個引數，並從該引數中減去傳入 `secret_subtract` 的秘密。

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. 建立乘法器

實作 `Secrets.secret_multiply/1`。它應該回傳一個函式，該函式接受一個引數，並將它乘以傳入 `secret_multiply` 的秘密。

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. 建立除法器

實作 `Secrets.secret_divide/1`。它應該回傳一個函式，該函式接受一個引數，並將它除以傳入 `secret_divide` 的秘密。

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

請使用整數除法，讓輸出能與其他函式預期的輸入相容。

## 5. 建立「and」運算器

實作 `Secrets.secret_and/1`。它應該回傳一個函式，該函式接受一個引數，並對它和傳入 `secret_and` 的秘密執行位元 _and_ 運算。

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. 建立「xor」運算器

實作 `Secrets.secret_xor/1`。它應該回傳一個函式，該函式接受一個引數，並對它和傳入 `secret_xor` 的秘密執行位元 _xor_ 運算。

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. 建立函式組合器

實作 `Secrets.secret_combine/2`。它應該回傳一個函式，該函式接受一個引數，並依序將傳入 `secret_combine` 的兩個函式套用到它上面。

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
