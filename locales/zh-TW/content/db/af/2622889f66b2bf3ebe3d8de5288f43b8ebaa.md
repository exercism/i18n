# 說明

為了那高得令人咋舌的日薪，你被吸引回到了 Hyperia（這裡通貨膨脹嚴重）。

中央銀行正在考慮引進美元作為第二種貨幣，因此所有會計系統都必須調整，才能處理多種貨幣。

你被要求實作貨幣金額物件。

## 1. 讓貨幣金額可以進行相等性測試

請修改 `CurrencyAmount` 結構，讓它能處理相等性。如果兩個貨幣金額結構的貨幣不同（「USD」或「HD」），就應該擲回 `ArgumentException` 的執行個體。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. 比較貨幣金額

請修改 `CurrencyAmount` 結構，讓它能處理比較（僅限`>`和`<`）。如果兩個貨幣金額結構的貨幣不同（「USD」或「HD」），就應該擲回 `ArgumentException` 的執行個體。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. 加減貨幣金額

請修改 `CurrencyAmount` 結構，讓它能處理算術加法與減法（僅限`+`和`-`）。如果兩個貨幣金額結構的貨幣不同（「USD」或「HD」），就應該擲回 `ArgumentException` 的執行個體。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. 乘除貨幣金額

請修改 `CurrencyAmount` 結構，讓它能處理算術乘法與除法（僅限`*`和`/`）。

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. 將貨幣金額轉換成 double

請修改 `CurrencyAmount` 結構，讓執行個體可以明確轉型成 `double`。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. 將貨幣金額轉換成 decimal

請修改 `CurrencyAmount` 結構，讓執行個體可以隱式轉換成 `decimal`。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
