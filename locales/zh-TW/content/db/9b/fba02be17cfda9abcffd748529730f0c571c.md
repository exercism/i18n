# 補充說明

## 字詞

定義一個`stopwatch`元組，以及一個建構子`<stopwatch> ( -- stopwatch )`，它會回傳一個新的碼錶，狀態為`"ready"`，沒有經過時間，也沒有任何先前的分段。

請提供以下這些能對碼錶操作的字詞：

- `state ( stopwatch -- str )`：`"ready"`、`"running"`或`"stopped"`。
- `current-lap ( stopwatch -- str )`：目前分段的經過時間，格式為`"HH:MM:SS"`字串。
- `total ( stopwatch -- str )`：目前分段與所有先前分段的經過時間總和，格式為`"HH:MM:SS"`字串。
- `previous-laps ( stopwatch -- seq )`：先前已記錄分段所組成的陣列，每個分段都是`"HH:MM:SS"`字串。
- `start ( stopwatch -- )`、`stop ( stopwatch -- )`、`reset ( stopwatch -- )`與`lap ( stopwatch -- )`：上方表格中的四個指令。若在狀態不允許的情況下呼叫其中一個指令，應該要`throw`一個錯誤。

時間會透過以下方式推進：

- `advance-time ( str stopwatch -- )`：將`"HH:MM:SS"`的時間長度加到目前分段。這只有在碼錶處於計時狀態時才會生效。
