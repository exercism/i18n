# 學習

## 從零開始學 C++

C++ 是一門語法廣泛且富有表達力的語言，支援多種不同的程式設計風格：程序式、物件導向、函式式與泛型，也能在同一個程式裡把這些風格全部混在一起。這個語言軌道嘗試以難度漸增的方式來引入題目。不過，語言語法裡的各個元素，最好用一系列練習以外的形式來介紹。

一般而言，exercism 假設你已經熟悉某個軌道中語言的語法與運作機制。然而，認識一門語言的語法，只是精通這門語言的第一步。Exercism 讓你練習解題，並與解過同一道題目的其他程式設計師交流討論。正是透過這樣的共同討論，我們才能累積專業知識與洞見，成為更好的程式設計師。

如果你是剛接觸 C++ 語言的新手，應該先花點時間學會這門語言的基礎。以下幾個資源能幫你順利起步喔：

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

[Coliru](http://coliru.stacked-crooked.com/) 是一個連結到 C++ 編譯器的簡單網頁表單介面，讓你能試跑小型程式。有時候，相較於在自己的整合開發環境裡建置專案，這是做個快速實驗更容易的方法。

## C++ 的測試驅動開發

Exercism 假設你熟悉測試驅動開發的概念。每個練習都附有一系列已經為你寫好的測試。你一次通過一個測試來完成練習，逐步寫出實作以滿足這些測試。

如果你剛接觸測試驅動開發，強烈建議你先做過 [C++ Now! 2014](http://cppnow.org/) 的 [Test-Driven Development in C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven) 工作坊。那個工作坊所用的工具，和 exercism 上 C++ 語言軌道所用的工具相同。
