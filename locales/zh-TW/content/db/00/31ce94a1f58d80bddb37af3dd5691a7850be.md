# 簡介

在 Rust 中，布林值由`bool`型別表示，其值可以是`true`或`false`。

Rust 支援 6 個比較運算子：`==`（等於）、`!=`（不等於）、`>`（大於）、`<`（小於）、`>=`（大於或等於）、`<=`（小於或等於）。它們可以用來將非布林值之間的關係求值為一個布林值。

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

與某些其他語言不同，`0`不是`false`，非零的值也不是`true`。

Rust 支援 2 個布林運算子：`||`（或）、`&&`（且）。只有在左側運算元還無法決定運算式的結果時，才會對它們求值。也就是說，`||`只有在左側運算元求值為`false`時，才會對右側運算元求值；而`&&`則只有在左側運算元求值為`true`時，才會對右側運算元求值。
