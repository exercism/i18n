# 簡介

## 型別別名

### 型別別名

在 Gleam 中，你可以用型別別名為現有的型別取一個方便的名稱，否則這些型別寫起來會很麻煩。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

使用`pub type`撰寫時，這個別名可以在定義它的模組之外使用。如果省略`pub`，別名就是私有的，無法在其他模組中參照。

## 字典

Gleam 中的字典是用來以鍵值對儲存資料的資料結構。在其他語言中，這類結構也可能被稱為關聯式陣列、雜湊或字典。

字典的鍵和值可以是任何型別，而且字典不保證存取或回傳項目時的順序。

### 操作字典

字典是透過`gleam/dict`模組中的函式來建立和操作的。

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
