# 提示

## 1. 介紹你自己

`introduce` 函式必須「拆開」`player.Name` 中所包含的值。
可以考慮使用 [`Options.defaultValue` 函式][defaultvalue]，在它是 `Some` 時把 `player.Name` 轉換成「包裝」的值，在它是 `None` 時轉換成所需的預設值。

## 2. 實作 revive 機制

`revive` 函式必須回傳 `Some <player>` 或 `None`，其中 `<player>` 是一個 `Player` 記錄，可能帶有幾個修改過的欄位。

## 3. 實作施法機制

可以考慮使用 match 運算式來同時涵蓋 `Some` 和 `None` 兩種情況，如下例所示：

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
