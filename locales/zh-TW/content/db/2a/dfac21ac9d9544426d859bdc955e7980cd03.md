# 說明

Josh 正在開發一款全新的角色扮演遊戲，需要你幫忙實作其中一些機制。

## 1. 自我介紹

實作`introduce`函式。

匿蹤的玩家可能隱藏自己的名字，此時會以`"Mighty Magician"`介紹他們。否則，就直接使用玩家的名字來介紹他們。

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. 實作 revive 機制

`revive`函式應該檢查玩家的角色是否確實已死亡（生命值已降到 0）。如果已死亡，應該回傳一個生命值為 100 的新`Player`實例。否則，如果玩家的角色尚未死亡，`revive`函式會回傳`None`。

如果玩家的等級為 10 或以上，也應該以 100 魔力復活。如果玩家的等級低於 10，其魔力應保持不變。`revive`函式應保留玩家的等級。

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

如果對生命值為 1 或以上的玩家呼叫`revive`方法，則該函式應回傳`None`。

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. 實作施法機制

`cast_spell`函式接受一個`Int`和一個`Player`作為引數；`Int`表示該咒語消耗多少魔力。它會回傳更新後的玩家，以及施放該咒語所造成的傷害量。成功施放咒語造成的傷害等於該咒語魔力消耗的兩倍。然而，如果玩家的魔力不足，則不會發生任何事，玩家保持不變，且不會造成任何傷害。如果玩家甚至沒有魔力池，嘗試施放該咒語時必須使其生命值減少該咒語的魔力消耗，且不會造成傷害。請注意，玩家的生命值不能低於零（0）。

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
