# 測試

測試可以用幾種方式執行。

## 在 Emacs 中互動式執行

1. 開啟測試檔，`M-x eval-buffer RET`
2. 以互動方式逐一執行，使用 `M-x ert RET test-name RET`
3. 以互動方式一次全部執行，使用 `M-x ert RET t RET`
   注意，這會執行目前載入 Emacs 中的所有測試！
4. 只要做了任何變更，測試前都要重新執行 `M-x eval-buffer RET`

如果只想執行目前緩衝區裡的測試，可以把下面這段加進你的 `.emacs` 或 `init.el`：

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

重新啟動 Emacs 之後：

1. 開啟測試檔
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## 從終端機執行

若要以批次模式從終端機執行所有測試，請執行 `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`

上面這個指令有點冗長，所以如果你想的話：

1. 在你的 `$PATH` 上建立一個名為 `ert-run` 的檔案（可能在 `~/bin` 裡）
2. 檔案內容應該如下：
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. 用 `chmod +x ert-run` 讓檔案變成可執行

你應該可以直接呼叫 `ert-run *-test.el`，以批次模式執行測試。

## 其他選項

其他選項可以在文件中找到，`C-h i m ert RET`。
