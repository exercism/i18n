# 簡介

## 陣列

Cairo 核心函式庫實作了`Array`型別。

它和其他程式語言常見的陣列型別很像，但有幾個關鍵差異：

- 元素只能有效率地加到`Array`型別的尾端，也只能有效率地從前端移除。
- 無法用陣列索引手動設定項目。

你可以用`ArrayTrait::new`函式建立陣列，也可以用`array!`巨集：

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

元素可以用`ArrayTrait::append`函式加入陣列：

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

元素可以用`ArrayTrait::pop_front`函式從陣列移除：

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo 也引進了`Span`型別，它的作用像是`Array`的「快照」。

每個`Array`都可以用`ToSpanTrait::span`函式轉換成`Span`：

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

把陣列轉換成`Span`非常有效率，因為`Span`只是一種資料結構，讓 Cairo 能「檢視」陣列的某個區段，不會以任何方式修改它。

透過把陣列轉換成`Span`，Cairo 允許你執行更多操作，比直接對`Array`允許的還多，例如從 span 的前端移除項目。

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

請注意，我們必須用`mut`關鍵字把`one_to_four_span`設成可變，才能呼叫`pop_back`；它會縮短 span 所「檢視」的陣列區段，藉此修改這個 span。
