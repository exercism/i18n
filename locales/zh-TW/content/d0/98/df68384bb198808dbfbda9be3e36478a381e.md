# 提示

## 一般

- [The Cairo Book：型別轉換][tcb-conversions]
- [The Cairo Book：自訂型別轉換][tcb-ctc]

## 1. 將有號整數轉換成無號整數

- 檢查有號值是否為負值，如果是，就回傳`Option::None`
- 檢查有號值是否超過`u16::MAX`（65535），如果是，就回傳`Option::None`
- 對於合法的值，使用`.try_into()`轉型，或直接轉換
- 記住，`u16`可以存放從 0 到 65535 的數值

## 2. 將無號整數轉換成有號整數

- 由於`u16::MAX`（65535）可以輕鬆放進`i32`，這個轉換一定會成功
- 使用`.into()`把`u16`安全地轉換成`i32`

## 3. 自訂型別轉換

- 用以下語法實作`Into`特徵：`impl IntoImplName of Into<SourceType, TargetType>`
- 在`into`方法中，建立目標型別的新實例
- 把`Essence`的`potency`欄位對應到`Elixir`的`strength`欄位
- 實作這個特徵之後，就可以在`Essence`實例上使用`.into()`

## 4. 使用 Into 特徵

- 實作`Into`特徵之後，對`Essence`參數呼叫`.into()`
- 編譯器會自動使用你實作的這個特徵
- 回傳型別標註可以幫助 Cairo 判斷該用哪一種轉換
