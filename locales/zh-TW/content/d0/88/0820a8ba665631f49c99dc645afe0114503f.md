# 指令

在這個練習中，你會撰寫程式碼，協助自由工作者與專案經理溝通，提供一些工具，以便快速計算每日與每月費率，並可選擇套用指定的折扣。

我們先在自由工作者與專案經理之間訂下幾條規則：

每日費率是每小時費率的 8 倍。
一個月有 22 個可計費工作日。
如果專案經理選擇讓自由工作者按月請款，自由工作者願意套用折扣；當專案經理有特定預算要控制時，這會很方便。

折扣以代表百分比的小數來表示，例如 25.0（25%）。

## 1. 根據每小時費率計算每日費率

實作一個函式，根據每小時費率計算每日費率：

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

回傳的每日費率應為浮點數。

## 2. 計算折扣後價格

實作一個函式，計算折扣後的價格。

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

回傳值一律應為浮點數，且不做任何四捨五入。

## 3. 根據每小時費率與折扣計算每月費率

實作一個函式，計算每月費率並套用折扣：

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

回傳的每月費率應向上取整（取天花板值），到最接近的整數。

## 4. 根據預算、每小時費率與折扣計算可工作天數

實作一個函式，接受預算、每小時費率和折扣，並計算這樣能涵蓋多少天的工作。

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

回傳的天數應向下取整（取地板值），到小數點後一位。
