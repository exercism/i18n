# 說明附錄

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                      |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | 輸入     | 整數 | 範圍 1..64 的平方數 |
| `$v0`    | 輸出    | 整數 | 輸出的低 32 位元            |
| `$v1`    | 輸出    | 整數 | 輸出的高 32 位元           |
| `$t0-9`  | 暫存 | 任意     | 用於暫存            |
