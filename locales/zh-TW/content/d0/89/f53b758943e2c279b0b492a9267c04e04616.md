# Match 運算式

一個 match 運算式會對一個值和一個條件求值，並回傳一個待求值的運算式。就像三元運算子一樣，如果條件不符，要回傳的運算式就不會被求值。要比對條件時，會進行身分檢查（嚴格相等或 `===`）。

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

若要進行相等（`==`）檢查，可以調整條件的寫法：

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

在 match 運算式中，如果沒有任何條件相符，就會拋出 `UnhandledMatchError`。
