# 提示

## 一般

- `cmovcc`系列指令不接受立即值。
  使用它們之前，必須先把常數載入暫存器。
- `setcc`系列指令只能處理 8 位元運算元。
  設定好適當的值之後，通常需要對它們做符號延伸或零延伸。

## 1. 加上獎勵分數而不讓顯示溢位

- 上限值是`999999`。
  任何超過這個值的總和都會變成`999999`。
- 比較之後接著一個`cmovcc`，就能在條件成立時把某個值替換成另一個值。
- `cmovcc`系列指令不接受立即值。
  使用它們之前，必須先把常數載入暫存器。

## 2. 比較兩個分數

- 一次比較之後可以接著多個`setcc`或`cmovcc`，依照相同或不同的旗標來設定或搬移多個值。
- `setcc`系列指令只能處理 8 位元運算元。
- 帶號的 8 位元運算元可以用`movsx`做符號延伸成 64 位元。

## 3. 驗證原始分數

- 一次比較之後可以接著多個`setcc`或`cmovcc`，依照相同或不同的旗標來設定或搬移多個值。
- 帶號比較的條件後綴是`l`（代表 lesser，即小於）與`g`（代表 greater，即大於）。

## 4. 追蹤最高的兩個分數

- 最高值有兩個。
  新的候選值要和這兩個值都比較過。
- 一次比較之後可以接著多個`setcc`或`cmovcc`，依照相同或不同的旗標來設定或搬移多個值。
- 帶號比較的條件後綴是`l`（代表 lesser，即小於）與`g`（代表 greater，即大於）。
