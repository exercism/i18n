# 佔位符

## 如何用 bash 解題

`bash`沒有任何內建的方式可以**解析**日期時間字串。
這個練習需要你呼叫外部工具。

* GNU `date`指令的`-d`選項可以解析[各式各樣的格式][gnu-date]。
* Mac 使用者的話，請參考 [BSD `date`指令][bsd-date]及其`-f`選項。
* Perl 十分普及，而且可以用它[`Time::Piece`模組][time-piece]來解析時間戳記。

bash 也能**格式化**日期，不需要任何外部工具。
給定一個整數時間值（自 epoch 起算的秒數），[`printf`的`%()T`格式器][bash-printf]就能套用「strftime」樣式的格式化。

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
[time-piece]: https://perldoc.pl/Time::Piece
