## 1. 建立帶有首字大寫標題的類別

`capitalize_header`函式應該接收一個活動名稱，並回傳該活動名稱首字大寫後的版本。

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. 格式化日期

建立一個新方法`format_date`，它接收一個包含日期、月份與年份的陣列，並以`<month_name> <date>, <year>`的格式顯示日期。

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. 將 unicode 碼點呈現為圖示

呼叫`display_icons`方法時，傳入的 unicode 碼點陣列應該被轉換成 _圖示_，並以`list`回傳。

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```
