# 操作說明

你附近的一間學校有個非常活躍的學生會。學生會由一位會長管理，每 2 年會舉辦一次選舉，選出新任會長。

今年的選舉決定要採用一套新的數位系統來計算選票。學校需要你幫忙打造這套新系統。

## 1. 從`ElectionResult`取得票數

新系統需要一個能從計數器取得票數的方法。

選舉結果的 struct 已經替你建立好了，定義如下：

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

由於`struct`中的所有成員都是公開的，你不需要撰寫`constructor`來初始化`ElectionResult`物件。
你可以改用`initializer list`：

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

建立一個函式`vote_count`，它會接受一個`ElectionResult`的參考作為引數，並回傳該`ElectionResult`中的票數。

```cpp
vote_count(hamilton);
// => 1804
```

## 2. 增加`ElectionResult`的票數

終於要來處理選票了！
現在你需要一個方法，用來增加`ElectionResult`中的票數。

建立一個`void`函式`increment_vote_count`，它會接受一個`ElectionResult`的參考和一個票數作為引數，並將該`ElectionResult`增加該票數。

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. 計票與會長職位

學校已經交出選票，現在該來確認贏家了。

建立一個函式`determine_result`，它會接收一份最終計票結果的參考，並回傳新任會長`ElectionResult`的參考。
它也應該在贏家的名字前面加上「President」。
最終計票結果是以指向`std::vector<ElectionResult>`的`reference`形式提供，這是一個 vector，內含所有參選候選人的`ElectionResults`。

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

為了簡單起見，你可以假設以下幾點：
- 這個`vector`至少有一個元素。
- 第一名不會有平手的情況。
