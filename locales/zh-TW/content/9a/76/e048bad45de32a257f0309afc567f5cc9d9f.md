# 關於

Bash 是一門你會愛上的語言！

你日常的許多電腦工作，都可以用它產生的簡潔指令碼完成。你很快就會發現，雖然大多數事情都能透過圖形使用者介面完成，但使用這個強大的語言，其實可能快得多！指令翻譯員通常會在文字視窗中執行，使用者可以在那裡輸入指令（操作也可能來自某些檔案，也就是所謂的 Bash 指令碼）。

更正式地說，Bash（**B**ourne-**a**gain **sh**ell 的縮寫，取 Bourne shell 與「born-again」一詞的雙關）是一種 Unix 指令翻譯員。它比幾種其他殼層提供了許多改良（Bash 在指令歷史、工作控制和命令列編輯方面有一些實用的功能）。

想理解 Bash，有一個很好的方法：

> 雖然大多數使用者把殼層想成互動式的指令翻譯員，但它其實是一門程式語言，其中每個敘述都會執行一個指令。由於它必須同時滿足指令執行的互動層面與程式設計層面，它是一門奇特的語言，受歷史形塑的程度不亞於設計。Brian Kernighan 與 Rob Pike

_cite: Kernighan, Brian W.; Pike, Rob (1984). The UNIX Programming Environment. Englewood Cliffs: Prentice-Hall. ISBN 0-13-937699-2._

雖然 Bash 最早是在數十年前由自由軟體基金會的 Brian Fox 寫成並發行，但時至今日，全世界每天仍在使用它！從自動化到把專案串接起來，這門語言依然和以往一樣多才多藝。這門語言歷史悠久還有另一個好處：圍繞它的豐富文件。如果你卡住了，不確定該怎麼完成某個練習，最好的起點就是內建的說明，可以用 `info bash` 或 `man bash` 取得。

這個 track 的用意，是幫助你在這門美妙的指令碼語言中累積一些經驗。

**祝你 Bash 愉快**
