# 關於

只要為方法參數指定預設值，就能讓它變成選擇性參數。當參數是選擇性的時候，呼叫端不需要為該參數提供引數，此時就會使用預設值。選擇性參數_必須_放在參數清單的最後面，後面不能接著非選擇性參數。如果方法有多個選擇性參數，你可以使用具名引數只指定其中幾個。

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

選擇性參數的值只能是下列其中一種：

- 常數運算式（例如`"hi"`、`2`、`DayOfWeek.Friday`、`null`等）
- 實值型別的 `new` 運算式
- 實值型別的 `default` 運算式
