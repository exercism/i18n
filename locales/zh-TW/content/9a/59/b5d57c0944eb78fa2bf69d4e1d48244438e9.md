# 說明

你是個熱衷賞鳥的人，會持續記錄過去 7 天有多少鳥造訪你的花園。

你有 6 項任務，全都和造訪你花園的鳥的數量有關。

## 1. 檢查上週的數量

為了方便比較，你總會在身邊留一份上週的數量紀錄，分別是：0、2、5、3、7、8 和 4。定義一個包含上週數量的`lastWeek`繫結：

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. 檢查昨天有多少鳥造訪

實作`yesterday`函式，回傳昨天有多少鳥造訪你的花園。鳥的數量紀錄依日期排序，第一個元素是最早那天的數量，最後一個元素則是今天的數量。

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. 計算造訪鳥類的總數

實作`total`函式，回傳造訪你花園的鳥的總數：

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. 檢查是否有哪天沒有鳥造訪

實作`dayWithoutBirds`函式，如果有一天沒有任何鳥造訪花園就回傳`true`；否則回傳`false`：

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. 增加今天的數量

實作`incrementTodaysCount`函式，將今天的數量加一，並回傳更新後的數量：

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. 檢查不尋常的一週

過去這一年來，你發現有些星期會出現相同的不尋常模式：
- 每個星期中的偶數日都沒有鳥出現
- 每個星期中的偶數日剛好有 10 隻鳥出現
- 每個星期中的奇數日剛好有 5 隻鳥出現

實作`unusualWeek`函式，如果這週的鳥類數量模式符合其中一種不尋常的模式，就回傳`true`：

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

（請注意，日期的奇偶性是從 1 開始計算，而不是從 0 開始，陣列中的第一個元素對應的是奇數日）
