# 簡介

`Option`型別是 F# 語言用來處理可能不存在或存在的值的機制。
它提供型別安全的做法，取代其他語言常用來處理這類值的`null`。
許多 F# 標準函式庫的函式都會用到它，因此要有效運用 F# 標準函式庫，理解它是必要的。

## 用法

`Option`型別是泛型型別（具有底層型別）。  
`Option`的值只有兩種：`Some value`，代表某個特定的值；或`None`，代表沒有值。

下面的函式示範如何建立`Option`值：

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`是`Option<T>`的後置寫法；這兩種語法形式可以互換使用。
不過，根據 F# 風格指南，Option 型別偏好使用後置寫法（參見 [F# 風格指南中關於型別與型別標註格式化的章節](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)）。
~~~~

## 讀取 Option 值的內容

讀取`Option`值的慣用做法是模式比對，如下面範例所示：

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## 以預設值解包 Option

只要用`Option.defaultValue`函式提供預設值，就能把`Option`「解包」（轉換成它內含的型別）。
當你想確保值不是`None`時，這特別有用。
例如：

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
