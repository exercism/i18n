# 關於

預設情況下，變數只存在於定義它的那個作用域裡。如果定義在函式或類別之外的檔案中，它就只限於該檔案的作用域；如果定義在函式或類別裡，就只限於該函式或類別的作用域。

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## 全域作用域

在變數賦值前加上`global`關鍵字，就會建立一個全域作用域的變數。這種做法通常不建議使用，因為它會產生[緊密耦合的程式碼](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>)。

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## 靜態作用域

在變數賦值或宣告前加上`static`關鍵字，會保留變數的作用域，但它的值會在多次執行之間被保留下來。

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

在這個例子中，`$count`變數_只在第一次呼叫函式時_初始化為 0。之後每次呼叫，值都會延續到下一次呼叫。因此，函式每次被呼叫時，都會回傳一個遞增的整數值。
