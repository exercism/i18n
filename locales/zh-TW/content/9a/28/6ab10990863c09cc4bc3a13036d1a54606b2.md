# 關於

Elm 形容自己是「一門打造可靠網頁應用程式的愉悅語言」。它的目標是做出效能優異、而且不會發生執行期例外的網頁應用程式。

具體來說，它是一門會編譯成 JavaScript 的函式程式語言。它的語法和特色源自 ML 語言家族，例如 Haskell，但[特別強調易學與簡潔][blog-syntax]。

你可以到官方網站 [elm-lang.org][elm-lang] 了解更多。剛接觸的人可以先從 Elm 指南開始，網址是 [guide.elm-lang.org][guide]。
