# 關於

## `for`迴圈

`for`敘述會重複執行一段程式碼。
它的第一行控制這段程式碼要重複幾次：

```go
for init; condition; post {
    // loop body
}
```

- **init**敘述會在第一次疊代前執行一次。通常會在這裡宣告並初始化迴圈要用的計數器變數。
- **condition**是每次疊代前求值的布林運算式。當它的求值結果為`false`時，迴圈就會停止。
- **post**敘述會在每次疊代結束後執行，可以用來更新計數器。

不要在`init; condition; post`外面加上小括號。
不過，包住迴圈主體的大括號`{ }`則一律必須寫。

這個迴圈會讓`i`從`1`開始，印出`i`目前的值，並在進入下一次疊代前把它加一，直到`i`達到`10`時停止：

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## 其他迴圈形式

### 只有條件的迴圈

init 和 post 敘述可以省略。
只有 condition 的`for`敘述，作用等同於其他語言裡的`while`迴圈。
Go 並沒有`while`關鍵字。

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### 無限迴圈

`for`敘述也可以不寫 condition：

```go
for {
    // loop body
}
```

這個迴圈不會自己結束。
必須明確地離開迴圈，例如使用`break`或`return`。

## 控制迴圈

### `break`與`continue`

在這個迴圈裡，`break`會直接跳出迴圈：

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue`則會跳過目前迴圈主體剩下的部分，直接開始下一次疊代：

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### 帶標籤的`break`與`continue`

在巢狀迴圈中，沒有標籤的`break`或`continue`只會作用在最內層的迴圈。
只要在某一層迴圈的正上方一行放一個識別字，後面加上冒號，就能為這層迴圈加上標籤。
接著把該迴圈的標籤寫在`break`或`continue`後面，動作就會轉向那個迴圈：

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
