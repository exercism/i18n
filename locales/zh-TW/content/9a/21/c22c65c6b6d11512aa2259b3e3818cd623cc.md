# 指令補充

## 提示

這個練習會處理文字資料。基於歷史因素，Haskell 的`String`型別等同於`[Char]`，也就是一個字元的陣列。為了更有效率地處理文字資料，可以使用`Text`型別。

作為這個練習的選用延伸，你可以

- 閱讀 Haskell 中關於[字串型別](https://haskell-lang.org/tutorial/string-types)的說明。
- 在 package.yaml 的相依套件清單中加入`- text`。
- 用[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)匯入`Data.Text`：

        import qualified Data.Text as T
        import           Data.Text (Text)

- 你現在可以寫出例如`abbreviate :: Text -> Text`，並以例如`T.filter`取用`Data.Text`的組合子。
- 查閱[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文件。

這個部分完全是選用的。
