# 關於

PHP 提供了許多用來執行算術運算的運算子。PHP 的算術運算子遵循標準的數學運算順序。PHP 提供的運算子有：

* 恆等（+）
* 負號（-）
* 加法（+）
* 減法（-）
* 乘法（*）
* 除法（/）
* 取模（%）
* 次方（**）

我們來看看每一個運算子，以及它們可以怎麼用：

## 恆等運算子（+）

恆等運算子（+）作用在單一值上（一元運算子），會求出變數的`float`或`int`值。

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## 負號運算子（-）

負號運算子作用在單一值上（一元運算子），並回傳該數值的相反數。

```php
$forward = 65;
$reverse = -$forward; // -65
```

## 加法（+）與減法（-）

加法運算子會把它兩側的兩個值相加，而減法運算子則會從左邊的值減去右邊的值。

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## 除法（/）

除法運算子會給出左邊的值除以右邊的值的結果。如果右邊的值是 0，就會引發`DivisionByZeroError`錯誤。

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## 乘法（*）

乘法運算子會回傳把左邊和右邊的兩個值相乘的結果。

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## 取模（%）

取模運算子會回傳左邊的值除以右邊的值之後的餘數。這個運算子很適合用來判斷某個數是否能整除另一個數、判斷一個值是奇數還是偶數，還有更多用途。

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## 次方（**）

次方運算子用來把左邊的值取右邊的值的次方。在 PHP 5.6 之前，你需要用`pow`函式才能做到同樣的事。

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

次方運算子兩邊都支援整數和浮點數，所以你可以用它來計算平方根（或其他次方根），或是更複雜的指數值。

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## 運算順序

PHP 遵循標準的數學運算順序。也就是說，運算並不是單純由左到右執行，每個運算子都有自己的優先順序，運算會依照優先順序來處理。運算順序是：

* 括號
* 次方
* 乘法、除法
* 加法、減法

乘法和除法的優先順序相同。同樣地，加法和減法的優先順序也相同。

這表示下面這個值會是 17 而不是 10，因為乘法的優先順序高於加法：

```php
$value = 2 + 3 * 5;
```

當你對某個變數進行運算，並把結果指定回同一個變數時，PHP 也提供了許多方便的賦值運算子，把算術運算子和賦值結合在一起。這些內容會在`Assignment Operators`概念中說明。
