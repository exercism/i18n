# 簡介

## Julia 的布林值

真或假的值由`Bool`型別表示。
它只包含兩個值：`true`和`false`。

```julia-repl
julia> true
true

julia> false
false
```

## 布林運算子

Julia 有三個布林運算子。

`&&`是布林的「and」。
如果`&&`兩側的運算式*都*是`true`，它的結果就會是`true`。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`是布林的「or」。
只要`||`兩側其中一邊的運算式是`true`，它的結果就會是`true`。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`是布林的「not」。
它會把`true`和`false`的值互換。

```julia-repl
julia> !true
false

julia> !false
true
```

運算式比較長、比較複雜時，最好用括號把意圖表達清楚。

```julia-repl
julia> (true || false) && (false && true)
false
```
