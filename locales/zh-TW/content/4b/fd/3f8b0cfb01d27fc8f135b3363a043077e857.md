# 簡介

## True 與 False

在 Ruby 中，true 和 false 這兩種邏輯狀態是分別用`true`和`false`來表示的。

```ruby
happy = true
sad = false
```

## 相等與比較

Ruby 讓你使用一般的相等符號來比較物件：
- 用`==`看看兩個物件是否相等。
- 用`>`看看左邊的物件是否**大於**右邊的物件。
- 用`<`看看左邊的物件是否**小於**右邊的物件。
- 用`>=`或`<=`分別測試「大於或等於」和「小於或等於」。

你也可以使用一般的運算子來做布林邏輯運算：
- 用`&&`或`and`檢查`x and y`是否為 true。
- 用`||`或`or`檢查`x or y`是否為 true。
- 用`!`或`not`來反轉相等性，例如`x != y`（x 不等於 y）。

以下是一些範例：
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
