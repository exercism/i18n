# 說明

Elyse 非常期待在即將到來的拉斯維加斯之旅中玩幾局撲克（以及其他紙牌遊戲）。她非常熱衷於「自我追蹤」，因此想寫幾個小函式來幫她處理追蹤的工作，並請你幫忙一起想想該怎麼做。

## 1. 追蹤撲克牌局

Elyse 特別喜歡撲克，她想記錄自己玩了幾局，以及_玩了哪些牌局_。每一局都有專屬的編號，而每張牌桌都會顯示目前正在進行的牌局編號。Elyse 選了一張牌桌坐下，開始玩她的第一局。她打算玩三局。

實作一個函式`rounds`，它接受目前的牌局編號，並回傳一個`list`，內容包含該局以及_接下來兩局_的編號：

```clojure
(rounds 27)
;;=> (27 28 29)
```

## 2. 把所有牌局記在同一個地方

Elyse 在第一張牌桌玩了幾局，然後休息一下，又到第二張牌桌玩了幾局……結果每張牌桌各得到一份不同的陣列！她想把這兩份陣列合併起來，這樣就能把所有撲克牌局記錄在同一個地方。

實作一個函式`concat-rounds`，它接受兩個陣列，並回傳一個`list`，內容是第一個`list`裡的所有牌局，接著是第二個`list`裡的所有牌局：

```clojure
(concat-rounds '(27 28 29) '(35 36))
;;=> (27 28 29 35 36)
```

## 3. 找出之前的牌局

聊到之前的幾局撲克時，另一位玩家提到其中兩局的過程非常相似。Elyse 不確定自己到底有沒有玩過那幾局。

實作一個函式`contains-round?`，它接受兩個引數：一個是玩過的牌局陣列，另一個是牌局編號。如果該局在玩過的牌局陣列中，函式會回傳`true`，不在的話回傳`false`：

```clojure
(contains-round? '(27 28 29 35 36) 29)
;;=> true

(contains-round? '(27 28 29 35 36) 30)
;;=> false
```

## 4. 計算牌值的平均值

Elyse 想試試一款叫做 Black Joe 的新遊戲。它類似 21 點，目標是讓手上的牌加總達到某個目標點數，不過在 Black Joe 裡，目標是讓牌值的_平均值_等於 7。要算出平均值，可以把所有牌值加總，再除以手牌的張數。

實作一個函式`card-average`，它會回傳一手 Black Joe 牌的平均值。

```clojure
(card-average '(5 6 7))
;;=> 6.0
```

## 5. 其他的平均值算法

在 Black Joe 裡，速度很重要。Elyse 想試著找出更快的平均算法。

她想到兩種能算出_近似平均值_的方法：

- 取手牌中_第一張_和_最後一張_牌值的平均。
- 使用手牌的中位數（也就是中間那張牌）。

實作函式`approx-average?`，它的參數`hand`是一個包含手牌所有牌值的陣列。

如果上述兩種策略中，_其中一種_`or`_兩種都_算出的數字_正好等於實際的平均值_，就回傳`true`。

注意：_所有手牌的張數都是奇數，這樣比較容易找出中位數。_

```clojure
(approx-average? '(1 2 3))
;;=> true

(approx-average? '(2 3 4 8 8))
;;=> true

(approx-average? '(1 2 3 5 9))
;;=> false
```

## 6. 更多求平均值的方法

平均值實驗的結果讓 Elyse 很感興趣，她想知道取_偶數_位置牌值的平均，和取_奇數_位置牌值的平均，結果會不會一樣。該是再寫一個測試函式的時候了！

實作一個函式`average-even-odd?`，它會回傳布林值，指出偶數索引位置牌值的平均是否和奇數索引位置牌值的平均相同。

```clojure
(average-even-odd? '(1 2 3))
;;=> true

(average-even-odd? '(1 2 3 4))
;;=> false
```

## 7. 獎勵局規則

在 Black Joe 裡，每第 11 手牌都是獎勵手牌，並附帶一條獎勵規則：如果你抽到的最後一張牌是傑克（11），它的值就要加倍。

實作一個函式`maybe-double-last`，它接受一手牌，並檢查最後一張牌是不是傑克（11）。如果最後一張牌**是**傑克（11），就把它的值加倍，再回傳這手牌。

```clojure
(maybe-double-last '(5 9 11))
;;=> '(5 9 22)

(maybe-double-last '(5 9 10))
;;=> '(5 9 10)
```
