# 安裝

## Windows 使用者

請安裝 [Windows Subsystem for Linux][wsl-link]，然後參閱下一節。

## Linux/Mac 使用者

### 使用 brew 安裝

這是安裝 Chapel 最簡單的方式。
它會給你一套基本可用的安裝環境，足以用來完成 Exercism 的 track。
進階使用者則可能想從原始碼自行建置 Chapel（見下一節）。

0. 如果你還沒安裝，請先安裝 [brew][brew-link] 套件管理器。
1. 首先，執行`brew update`確認 brew 是最新版本。
2. 執行`brew install chapel`安裝 Chapel。
3. 執行`chpl --version`，確認安裝成功。

這會安裝 Chapel 編譯器（`chpl`）、我們之後用來執行測試的套件管理器`mason`，以及文件產生工具`chpldoc`。`chpldoc` 對 Exercism 來說用不到，不過如果你（總有一天 :)）想用 Chapel 開發自己的函式庫，有它會很方便。

### 從原始碼建置 Chapel

進階使用者可能想自行從原始碼建置 Chapel，做法如下：

1. 安裝[必備條件][prereqs-link]
2. [下載][download-link]最新版 Chapel 的壓縮檔並解開。
3. 首先，你需要先準備好安裝 Chapel 的位置並完成設定。
這可以透過執行隨附的`configure`腳本完成。
只要執行

```
./configure
```

就會把執行檔、函式庫與共用檔案安裝到`/usr/local/`，你可以用`--prefix`選項改變這個位置。
例如，如果你想讓 Chapel 安裝到`~/.chapel`，可以這樣做

```
./configure --prefix=~/.chapel
```

4. 要安裝編譯器與工具，請執行

```
make
make mason
make chpldoc
make install
```

5. 確認`/dir/for/install/bin`資料夾已加入你的`PATH`變數。

想了解更多安裝 Chapel 以及從原始碼建置的不同方式，請參閱文件中的 [從原始碼建置 Chapel][building-link] 頁面。
