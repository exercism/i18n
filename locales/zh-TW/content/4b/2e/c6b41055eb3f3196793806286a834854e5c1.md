# 暫停社群貢獻

有些儲存庫沒有足夠的資源，無法分類或審查非維護者使用者提出的議題或提取要求。
暫停社群解決方案
如果儲存庫啟用了這個工作流，當作者_不是_ Exercism 的 GitHub 組織成員時，它就會自動在剛開啟的議題或提取要求上留言。
留言會建議使用者先在 Exercism 論壇上開一個主題。

## 啟用工作流

請將 [.github/workflows/pause-community-contributions.yml 檔案](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) 加入你的儲存庫。

## 停用工作流

從你的儲存庫移除這個工作流檔案。

## 來源

這個工作流定義在`.github/workflows/pause-community-contributions.yml`檔案中。
