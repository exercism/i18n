# 關於

能夠存放零個或多個元素的資料結構，稱為_集合_。
Ruby 中的**陣列**是一種集合，它會維持物件加入時的順序。
陣列可以存放任何物件。
可以透過索引把物件加入陣列，或從陣列中取出物件。
Ruby 的陣列索引從 0 開始，也就是說，第一個元素的索引一律是 0：

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

在 Ruby 中，建立陣列的方式有好幾種：

- 使用字面值建構子`[]`_（最常見）_
- 明確呼叫`Array.new`
- 呼叫 Kernel 的`Array()`方法

`Array.new`方法支援兩個選用引數：陣列的初始大小，以及預設物件。

當提供了大小與預設值時，陣列會以預設物件的`size`個複本填入。

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

由於所有陣列元素存放的都是同一個雜湊，改變其中一個就會連帶影響全部。

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

如果你要的是多個不同的複本，就應該使用區塊版本：每次需要初始化陣列中的某個元素時，都採用該區塊的執行結果：

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ruby 陣列的另一個特點，是它們混入了 [Enumerable][enumerable-module] 模組，因而多了許多方便的方法，可以用來疊代、搜尋、排序、篩選陣列中的元素等等。

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
