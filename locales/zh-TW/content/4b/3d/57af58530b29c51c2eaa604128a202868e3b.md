# 說明

你要初始化空白的緩衝區，並列出費波那契數列的前五個數字（也就是元素）。

費波那契數列是一組數字，其中每一個元素都是前兩個元素的總和。這個數列從 1 開始，所以前兩個元素是 1 和 1。

## 1. 建立一個包含 `count` 個 0 的緩衝區

建立一個函式，用來建立包含 `count` 個 0 的緩衝區。

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. 列出費波那契數列的前五個元素

建立一個函式，回傳費波那契數列的前五個數字。
它的前五個元素是 `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
