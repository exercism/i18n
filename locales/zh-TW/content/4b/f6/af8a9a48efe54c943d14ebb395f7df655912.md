# 簡介

Clojure 中的數字包括：

- 整數：小數點後沒有任何數字的數字（整數）。例如`-6`、`0`、`1`、`25`、`976`和`500000`。
- 浮點數：小數點後有零個或多個數字的數字。例如`-2.4`、`0.1`、`3.14`、`16.984025`和`1024.0`。

常見的數字型別有`int`和`float`。`int`是 32 位元整數，`float`則是 64 位元浮點數。

算術運算使用標準的算術運算子。數字可以使用標準的數值比較運算子（`>`、`<`、`<=`、`>=`）、相等運算子（`=`）與不相等運算子（`not=`）來比較。

在這個練習中，你必須依照條件執行邏輯。在 Clojure 中，常見的做法是使用`cond`：

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```

## 備註

當數字需要在不考慮確切型別的情況下進行比較時，`==`運算子在某些情況下可能比`=`更合適。例如：

```clojure
(== 5.0 5) ;; true as both numbers are equal when type is ignored
(= 5.0 5) ;; false as the types of numbers are also taken into account here i.e. float is different from int
```
