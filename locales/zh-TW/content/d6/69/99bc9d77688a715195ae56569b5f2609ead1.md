# 測試

在嘗試執行測試之前，請先依照安裝步驟正確設定作業資料夾，也就是 `corepack yarn install` 和 Editor SDK 的設定。

用以下指令執行測試：

```bash
$ corepack yarn test
```

請確保你的程式碼遵循最佳實務，和其他使用者一樣，使用 eslint 這套能對你的程式碼進行靜態分析的工具。這類工具能幫你省下一些時間，找出程式碼裡的錯字或愚蠢的錯誤：

```bash
$ corepack yarn lint
```

或者一次做完這兩件事：

```bash
$ corepack yarn test && corepack yarn lint
```

Exercism 上的 TypeScript 賽道不會強制規定程式碼的_風格_，所以你可以自由選擇要不要加分號、要用定位字元還是空格，以及介於兩者之間的任何做法。

## 建立你的第一個模組

通常，這個賽道上的測試會把你的實作當作模組載入：`import Bob from './bob';`。要讓它順利運作，你必須從測試尋找你的模組時所看的檔案 `bob.ts` 匯出你的實作：

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

我們在每個練習中都提供了程式骨架，並已經幫你把這個 `export` 放在裡面了。
