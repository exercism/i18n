# 簡介

*引號*是指 `[ ]`方括號中的程式碼，在 Factor 裡，它本身就是一個值，就像數字或字串一樣。你可以把它存進變數、放進陣列、傳給另一個函式，之後再*呼叫*它。

## `call`

`call`（位於[`kernel`][kernel]中）會執行引號：

```factor
3 4 [ + ] call .
! => 7
```

當你在 Factor 無法推斷堆疊效應的情境下`call`一個引號時，就必須明確宣告該效應：

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

這會編譯出一段執行時期的檢查，確認這個引號確實具有所宣告的效應。

## 序列中的引號

因為引號是值，所以陣列裡可以混合存放數字和引號：

```factor
{ 3 4 [ + ] }
```

如此一來，「程式」就成了一般的序列，而`each`也就成了執行它的自然方式：

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## 裁切序列的尾端

`head*`會回傳除了最後`n`個元素以外的所有元素；`last2`則回傳最後兩個：

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

搭配`suffix`，這就是在堆疊上寫出「消耗最上面兩個、推入一個結果」這種操作所需的全部工具。
