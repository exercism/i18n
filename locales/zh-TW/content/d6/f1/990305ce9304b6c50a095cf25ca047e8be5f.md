# 指示補充

## 其他指示

你會拿到一張名為「isogram」的資料表。
第一欄「phrase」包含一些文字。
你需要判斷這個詞組是否為字母不重複的詞組。
把第二欄「is_isogram」更新成整數值：

* 如果這個詞組是字母不重複的詞組，填 1，
* 如果不是，填 0。

~~~~exercism/note
SQLite 的比較運算會以 0/1 數字的形式回傳布林值

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
