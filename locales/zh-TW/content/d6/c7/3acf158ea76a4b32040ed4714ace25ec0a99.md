# 指令補充

## 詞

定義一個`linked-list-node`元組。

定義一個`linked-list`元組，並提供一個`M: linked-list length`方法（來自`sequences`），讓測試可以直接在你的連結串列上呼叫`length`。

- `<linked-list> ( -- linked-list )`：建構一個空的連結串列。
- `>linked-list ( seq -- linked-list )`：依序把`seq`的每個元素推入一個全新的連結串列。
- `linked-list>array ( linked-list -- array )`：回傳所有值，最上面的元素排在最前面。
- `list-push ( linked-list value -- linked-list )`：把一個值推入頂端。
- `list-pop ( linked-list -- linked-list value )`：移除並回傳最上面的值。
- `list-peek ( linked-list -- value )`：回傳最上面的值，但不移除它。
- `list-reverse ( linked-list -- linked-list )`：回傳一個元素順序相反的連結串列。

當連結串列為空時，從`list-pop`和`list-peek`拋出`list-empty`錯誤類別。
