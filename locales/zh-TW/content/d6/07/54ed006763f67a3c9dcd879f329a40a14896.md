# 布林值

Crystal 有一種型別叫做 [`Bool`][bools]。
它代表 `true` 和 `false` 這兩個值。

## 邏輯運算子

Crystal 有三個邏輯運算子（`!`、`||`、`&&`），它們可以組合布林值，並構成會得出不同值的運算式。

### 且（`&&`）

Crystal 中的[且運算子][and]以 `&&` 表示，如果兩個值都是 `true`，就回傳 `true`；否則回傳 `false`。
使用且運算子時，其中一個布林值放在 `&&` 右邊，另一個放在左邊。

```crystal
true && true
# => true

true && false
# => false
```

### 或（`||`）

Crystal 中的[或運算子][or]以 `||` 表示，只要給定的值中**至少有一個**是 `true`，就回傳 `true`。
如果兩個值都是 `false`，則回傳 `false`。
使用或運算子時，其中一個布林值應該放在 `||` 右邊，另一個放在左邊。

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### 非（`!`）

Crystal 中的非運算子以 `!` 表示，如果給定的布林值是 `false`，就回傳 `true`；如果給定的是 `true`，則回傳 `false`。
使用非運算子時，布林值應該放在運算子（`!`）後面。

```crystal
!true
# => false

!false
# => true
```

## 使用括號（`()`）

處理布林值時，你可以用括號決定要先計算哪些布林值。
括號的使用方式不同，結果也可能不同。
在 Crystal 中，括號內的內容會先被計算。

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

由於括號內的內容會先被計算，所以在下面的範例中，非運算子會套用到括號內的運算式。

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
只有在括號會影響結果時才該使用括號，否則就應該省略。
~~~~
