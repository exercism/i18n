# 指令

你正在為錄音室裡一台小型混音控台撰寫數位核心。

聲音會以取樣的形式源源不絕地送進來。
每個取樣都是一個數字，描述喇叭單體在某個瞬間的位置。
混音控台一次會處理一整個取樣區塊，對每個取樣套用相同的運算。

你有 5 個任務，每個任務都對記憶體中的一個取樣區塊進行操作。
你會透過記憶體位址接收運算元，並透過結果位址寫回答案。

~~~~exercism/note
這個練習的運算應該使用 SIMD 指令完成，而不是純量運算。
~~~~

## 1. 混合兩條音軌

錄音室有時會把不同樂器錄在不同的音軌上。
若要透過同一組喇叭播放，你必須把這 2 條音軌相加成一條。

實作`mix_tracks`函式，它會逐個取樣把兩條音軌相加。
每條音軌都是一個包含 8 個帶正負號 16 位元取樣的區塊。
相加結果若超出帶正負號 16 位元的範圍，必須進行飽和處理，而不是溢位環繞。

這個函式的引數依序如下：

- `result`：用來寫入 8 個混合後取樣的緩衝區的 16 位元組對齊記憶體位址。
- `track_a`：第一條音軌的 16 位元組對齊記憶體位址，內含 8 個帶正負號的 16 位元取樣。
- `track_b`：第二條音軌的 16 位元組對齊記憶體位址，內含 8 個帶正負號的 16 位元取樣。

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

這個函式沒有回傳值。

## 2. 移除漏音

當 2 支麥克風同時錄音時，每一支都會隱約收到另一個音源的微弱複本。
這個不想要的複本稱為_漏音_。
一旦量測出這個漏音，就必須把它減掉，才能清理這條音軌。

實作`remove_bleed`函式，它會逐個取樣把漏音區塊從音軌區塊中減掉。
每個區塊都是 8 個帶正負號的 16 位元取樣，而且相減時必須進行飽和處理。

這個函式的引數依序如下：

- `result`：寫入 8 個清理後取樣的記憶體位址（不保證對齊）。
- `track`：錄下來的音軌的 16 位元組對齊記憶體位址，內含 8 個帶正負號的 16 位元取樣。
- `bleed`：要移除的漏音的記憶體位址，內含 8 個帶正負號的 16 位元取樣（不保證對齊）。

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

這個函式沒有回傳值。

## 3. 合併音量表

每個聲道上頭都有一個音量表，那是一條小小的光條，亮度顯示該聲道有多大聲。
面板上有一個主音量表，它的亮度應該等於兩個聲道加起來的亮度。
你要把這 2 個音量表區塊相加來驅動它。

注意，亮的音量表會維持在最亮，而不會繞回全暗，所以相加時要進行飽和處理。

實作`combine_meters`函式，它會逐個取樣把兩個音量表區塊相加。
這個函式的引數依序如下：

- `result`：寫入 16 個合併後數值的 16 位元組對齊記憶體位址。
- `meter_a`：第一個聲道音量表區塊的 16 位元組對齊記憶體位址，內含 16 個緊密排列的無正負號 8 位元數值。
- `meter_b`：第二個聲道音量表區塊的 16 位元組對齊記憶體位址，內含 16 個緊密排列的無正負號 8 位元數值。

每個區塊是 16 個無正負號的 8 位元數值。
相加時要飽和在無正負號的範圍內。

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

這個函式沒有回傳值。

## 4. 套用淡出

歌曲不該突然中斷，而是要一路淡出到結束。
你手上有一個_增益係數_區塊，每個取樣對應一個係數，這些係數會一路遞減。

每個係數都是一個以`65536`為分母的分數。
例如，某個取樣的值是`16384`，它實際上代表`16384 / 65536`，也就是`1 / 4`。
最大的可用數值是`32767`，只比二分之一小一點。

由於`65536`是`2^16`，把取樣乘上它的係數，再保留乘積的_高半部_，就會得到`sample * gain / 65536`。

實作`apply_fade`函式，它會依係數縮放每個取樣。
這個函式的引數依序如下：

- `result`：寫入所有縮放後取樣的 16 位元組對齊記憶體位址。
- `track`：音軌的 16 位元組對齊記憶體位址，內含`n`個帶正負號的 16 位元取樣。
- `gains`：增益係數的 16 位元組對齊記憶體位址，內含`n`個帶正負號的 16 位元數值，每個數值的範圍是`0`到`32767`。
- `n`：取樣的數量，永遠不為零且是`8`的倍數，型別為 64 位元無正負號整數。

注意，`track`是一個陣列，內含`n`個帶正負號的 16 位元取樣，其中`n`永遠不為零，且一定是`8`的倍數。
對每個取樣來說，縮放後的結果是帶正負號乘積`sample * gain`的_高_16 位元。

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
保留高半部時，捨入方向是朝負無窮大。
這就是為什麼`20000 * 32767`縮放後會得到`9999`，而`-20000 * 32767`會縮放成`-10000`，而不是`-9999`。
~~~~

這個函式沒有回傳值。

## 5. 衰減音軌

鼓手錄得太大聲了。
為了把整條音軌壓下來，你要把每個取樣除以一個常數。

實作`attenuate_track`函式。
這個函式的引數依序如下：

- `result`：寫入結果的 16 位元組對齊記憶體位址，結果為 32 位元帶正負號整數。
- `samples`：取樣的 16 位元組對齊記憶體位址，內含`n`個帶正負號的 16 位元數值。
- `divisor`：16 位元組對齊的記憶體位址，內含除數的 4 份相同複本，內容為 32 位元整數。
- `n`：取樣的數量，永遠不為零且是`4`的倍數，型別為 64 位元無正負號整數。

注意，`samples`是一個陣列，內含`n`個帶正負號的 16 位元取樣，其中`n`永遠不為零，且一定是`4`的倍數。

除數會以同一個 32 位元整數的`4`份複本提供，事先複製好，讓它能一次填滿全部 4 個資料通道。

整數 SIMD 沒有緊密排列的除法，所以這項工作會改用緊密排列的浮點數來做，再轉回緊密排列的 32 位元整數，存入`result`。
轉換回來時要朝零截斷，所以商為`2.3`時會變成`2`，商為`-2.3`時會變成`-2`。

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

這個函式沒有回傳值。
