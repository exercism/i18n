# 簡介

[`function`][function]是一種把程式碼分門別類的方式，讓程式中的一處或多處可以用名稱呼叫它。函式用來執行特定且重複性的工作。

更正式地說：函式是任何可以套用[`function call`][calls]運算的 Python 物件。函式可以用來在某些運算之後[`return`][return]一個或多個值，也可以用來產生一個或多個[`side effects`][side effects]。如果函式沒有指定回傳值，它仍然會回傳`None`。

以下是帶有副作用的函式範例：

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

在上面這個範例中，[`def`][def]關鍵字用來表示函式定義的開頭。`hello`是這個函式的名稱。空括號代表沒有傳入任何值給這個函式。函式的主體是單一的`print("Hello")`敘述。`print`本身也是個函式。`print`函式括號中的`"Hello"`稱為[`argument`][arguments]。`print`函式會用這個引數來得知要印出什麼。請注意，函式的主體有縮排。縮排很重要，因為 Python 靠它來判斷那段程式碼區塊在哪裡結束。函式主體的結尾，會落在程式的結尾，或是下一行_沒有_縮排的程式碼之前。由於`hello()`沒有指定`return`值，它會執行自己的副作用（也就是呼叫`print()`），然後回傳`None`。最後，我們用函式名稱加上括號來呼叫它，這會告訴 Python 翻譯員這個名稱是_可呼叫的_。

以下是帶有回傳值的函式範例：

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

這個函式的主體已經從_呼叫_`print`改成_回傳_`string` "Hello"。結果程式仍然會印出`"Hello"`，但副作用發生在_呼叫端程式碼_，而不是在`hello`函式裡。如果呼叫`hello`函式時把括號省略掉（例如`print(hello)`），`print`就會輸出類似這樣的內容：

```
<function hello at 0x0000026E18E93E20>
```

重要的是，即使函式不接受任何引數（_也就是沒有參數_），還是必須加上空括號才能正確_呼叫_它。這點和 Ruby 之類的語言不同，那些語言在呼叫沒有任何引數的函式時，並不需要加上空括號。

函式可以定義零個或多個[`parameters`][parameters]。參數定義了函式接受哪些引數。

以下是一個接受引數的函式範例：

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

這個參數定義為`name`。`"Bob"`是程式傳給`hello`函式的引數。函式會_回傳_`string` "Hello, Bob"。

如果有人呼叫`hello`時沒有傳入引數，會發生什麼事？程式會拋出錯誤：

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

如果我們不希望程式在沒有引數時出錯（_但又要允許呼叫端不提供引數_），可以定義[預設引數][default arguments]。預設引數定義了呼叫函式時，若缺少該引數要採用什麼值。

以下是帶有預設引數的函式範例：

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

`name`參數的預設引數是`"you"`，所以如果沒有傳入`name`引數，程式就會輸出`Hello, you`。

想進一步了解函式引數，請參閱[函式引數][function arguments]概念。
