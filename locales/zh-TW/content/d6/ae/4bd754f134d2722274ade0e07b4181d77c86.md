# 關於

Java 的 `char` 基本型別是單一 Unicode 字元的 16 位元表示法。

~~~~exercism/note
`char` 型別是以[最初的 Unicode 規格][unicode-specification]為基礎，該規格使用 16 位元來表示字元。
這足以涵蓋大多數常見的字母，並涵蓋 0x0000 到 0xFFFF 範圍內的字元。
該規格後來已將可能的字元範圍擴展到 0x01FFFF。

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

多個 `char` 可以組成一個字串，例如 `"word"`，而 `char` 也可以個別處理。
`char` 字面值以單引號包住（例如 `'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

## 取得 `String` 的 `char`

`String.toCharArray` 方法會以陣列的形式回傳 String 的字元。
如[陣列][concept-arrays]所述，你可以使用 `for` 迴圈來疊代該陣列。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## [Character][docs-character] 類別

有許多內建的方法可以檢查及操作 `char`。
這些方法可以在 [`java.lang.Character`][docs-character] 類別中找到，形式為靜態方法。
以下是一些範例：

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Character 類別中有一些方法具有多載，因此可以接受 `char` 或 `int`。
例如，`isDigit` 有一個接受 [`char`][is-digit-char] 的多載，另一個則接受 [`int`][is-digit-int]。
如前所述，`char` 型別只能表示 0x0000 到 0xFFFF 範圍內的字元。
然而 `int` 可以表示所有字元，因此才有多載的 `int` 版本。

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## 將 `char` 加入 `String`

`+` 運算子可以用來把 `char` 加入 `String`。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
小心 _不要_ 用 `+` 把兩個 `char` 連接成一個 `String`！
這樣相加兩個 `char` 會得到 `int`，_不是_ `String`！
例如：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

這是因為 Java 會將 `char` 提升為 `int`（參見 [Java 語言規格][jls-main]的[4.2 基本型別與值][jls-primitives]）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

不過，當要加入的字元很多時，改用 [`StringBuilder`][docs-stringBuilder] 可能更有效率：

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
