# 說明

在這個練習中，你將撰寫程式碼，幫助一位自由工作者與專案經理溝通。
你的任務是提供幾個工具函式，用來快速計算日費率與月費率，並可選擇套用指定的折扣。

我們先在自由工作者與專案經理之間訂下一些規則：

- 日費率是時薪的 8 倍。
- 一個月有 22 個可計費天數。

有時候，自由工作者會想在日費率上套用折扣（例如給最忠實的客戶或非營利組織客戶）。

折扣以代表百分比的分數來表示，例如 `25.0`（25%）。

## 1. 根據時薪計算日費率

實作一個名為 `daily_rate` 的函式，根據作為參數傳入的時薪計算日費率。
契約定義中，一天有 8 個可計費小時。

```cpp
daily_rate(60)
// => 480.0
```

回傳的日費率型別應為 `double`。

## 2. 計算折扣後的價格

實作一個 `apply_discount` 函式，計算折扣後的價格。
它應接受 2 個參數：原始價格與折扣百分比。

```cpp
apply_discount(150, 10)
// => 135.0
```

回傳值一律應為 `double` 型別，且不得以任何方式四捨五入。

## 3. 根據時薪與折扣計算月費率

實作一個 `monthly_rate` 函式，計算折扣後的月費率。
它應有 2 個參數：時薪與折扣百分比。

```cpp
monthly_rate(77, 10.5)
// => 12130
```

回傳的月費率應向上取整（取天花板值），取到最接近的整數。

## 4. 根據預算、時薪與折扣計算完整工作天數

實作一個 `days_in_budget` 函式，接受預算、時薪與折扣，並計算這樣能涵蓋多少個完整的工作天。

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

回傳的天數應向下取整（取地板值），取到最接近的整數。
