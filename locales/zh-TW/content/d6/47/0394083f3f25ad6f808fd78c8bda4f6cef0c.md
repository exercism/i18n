# 關於匿名函式與閉包

PHP 允許在其他函式內部宣告函式。這些函式不需要命名，但可以指定給變數，甚至直接傳入另一個需要函式參數的函式。

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

上面定義並傳入 array_filter 的函式就是匿名函式。`array_filter` 會用它來判斷陣列中某個值是否會出現在 `array_filter` 的結果中。如果該函式對某個值回傳 `true`，這個值就會被包含在結果陣列裡。

匿名函式也可以用來從函式內部參照函式外部作用域中的變數。這就是所謂函式的作用域對函式中使用的變數「閉合」，因此有了「閉包」這個名稱。在某些語言中，所有作用域內的變數都會自動允許在閉包內使用。就 PHP 而言，代表目前物件的`$this`會自動允許在閉包內使用。其他所有變數都必須用`use`關鍵字明確參照。

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

在上面的 `makeAdderFunction` 函式中，傳入的`$number`值會在內部定義的匿名函式中被「閉合」，這個匿名函式接著會被回傳。之後每當執行該函式時，它都知道當初傳入的`$number`值。如果你用另一個數字再次呼叫這個函式，會回傳一個完全不同的函式。它不會改變第一次呼叫所回傳的值或功能。
如果你需要閉合多個變數，可以用逗號分隔，把它們加進`use`關鍵字中。

PHP 也有一種較簡短的函式語法，稱為`arrow functions`。它們必須相當簡單。基本形式如下：

```php
fn(arguments) => expression
```

在這種函式風格中，你不需要使用`use`。它會自動閉合並捕捉父作用域中的任何值。這些箭頭函式中的運算式會自動被回傳，不需要使用`return`關鍵字。這讓我們能把上面的 `onlyOdds` 函式改寫成這樣：

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

上面的 `makeAdderFunction` 可以改寫成這樣：

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**注意：** 如果函式無法寫成運算式，就無法使用較短的箭頭函式語法。

變數是以傳值方式傳入匿名函式與閉包，並在其中使用。這表示如果你在函式內改變變數的值，不會影響函式外該變數的值。如果你需要修改該值，可以用傳參考的方式傳入。

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

在上面的例子中，`array_walk` 會疊代陣列中的每個元素，把每個值送給呼叫中宣告的函式。它會在`$total`中累計總和，其中加進去的每個值都是該數字的絕對值。它也會記錄一共有多少個數字。這兩個值在閉包中都是以傳參考方式使用，由`use`區段中每個變數前面的`&`表示。這表示當 `array_walk` 完成時，變數的變更仍然會保留，因此函式可以回傳陣列中所有數字絕對值的平均。

匿名函式與閉包能提供一種方便的方式，用來定義可能只在單一情境中用得到的函式，或是定義一個依據一組參數回傳動態函式的函式，而這些參數是在與函式實際使用時不同的時間點得知的。
