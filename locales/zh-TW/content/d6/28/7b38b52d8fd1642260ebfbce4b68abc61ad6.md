# 提示

## 一般

- 這個練習會用到文字資料和陣列。Unison 的`Text`值可以拆解成`Char`的陣列，再組回`Text`。UCM 支援「依型別搜尋」工具，對尋找相關函式可能很有幫助。
- 試著在 UCM 命令列輸入`find : Text -> [Char]`，看看會出現什麼。冒號`:`代表我們是依型別搜尋，而不是依名稱。[在這裡進一步了解`find`指令。](https://www.unison-lang.org/learn/ucm-commands/#find)
- 你也可以在 [Unison share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest) 線上瀏覽`Text`型別和`List`型別的函式。
