# 簡介

在 Gleam 中，`Iterator`和陣列很像，它是有序的值集合，其中所有值都屬於相同型態。它和陣列的不同之處在於它是惰性的，意思是它不會一次把所有值都存進記憶體，而是需要時才計算。

當處理非常巨大、甚至無限大的序列時，這就很實用，因為它讓我們在沒有足夠的可用記憶體一次存放全部值時，仍然可以處理它們。

`gleam/iterator`模組定義了`Iterator`型態，以及用來操作疊代器的函式。

許多用於陣列的函式也適用於疊代器，例如`map`、`filter`和`take`。這些函式會回傳疊代器，所以直到疊代器被消耗之前，它們實際上不會執行任何工作。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold`函式可以從一個被反覆呼叫、用來產生序列中下一個值的函式建立疊代器。

這裡用`unfold`函式建立一個會產生費氏數列的疊代器：

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

這裡的序列是無限的，所以在把值收集到陣列之前，會先用`take`函式讓它變成有限。如果對無限疊代器呼叫`to_list`，程式會一直執行，直到記憶體用盡並崩潰。
