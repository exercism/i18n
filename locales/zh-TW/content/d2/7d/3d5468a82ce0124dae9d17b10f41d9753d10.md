# 簡介

## 模組

Gleam 程式碼以模組來組織，每個檔案就是一個 Gleam 模組。

到目前為止，我們都是用 `pub fn` 語法來撰寫函式，這會定義一個可供其他模組公開使用的函式。用 `fn` 定義的函式則是其所屬模組的私有函式，其他模組無法使用。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 模組有名稱，名稱取決於它們在 `src` 或 `test` 目錄中的檔案路徑。

例如，定義在 `src\geometry\rectangle.gleam`（Windows 上）或 `src/geometry/rectangle.gleam`（類 UNIX 作業系統上）的模組，名稱會是 `geometry/rectangle`。

## 從其他模組匯入函式

要存取定義在其他模組中的函式，必須透過匯入。
匯入某個模組時，該模組所公開的所有函式都會變成可以存取。
但存取方式會依模組的匯入方式而有所不同。

限定匯入是預設方式，存取這類模組中的函式（例如 `gleam/list` 模組裡的 `map` 函式）時，要在前面加上模組名稱（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

預設用來指涉模組的名稱是模組名稱的最後一部分，在這裡就是 `int`，不過這可以用 `as` 關鍵字來改變。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非限定匯入讓你可以直接存取該模組中公開的函式，而不需要加上前置詞。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

限定匯入較為建議，因為它能讓讀者更清楚函式的來源，也能避免名稱衝突。


## 標準函式庫

Gleam 有豐富且文件齊全的標準函式庫。文件可在 [hexdocs.pm/gleam_stdlib][docs] 線上取得。把這個連結存起來，你會很常用到！

大多數內建資料型態都有對應的模組，提供處理該資料型態的函式，例如整數有 `gleam/int` 模組、字串有 `gleam/string` 模組、陣列有 `gleam/list` 模組等等。

[docs]: https://hexdocs.pm/gleam_stdlib/
