# 廚房計算機

## 故事

這個故事用來引導學習者探索某個程式語言中的[元組][type-tuple]。

基本前提是，廚房裡的食材經常以冷僻的單位計量，而且需要根據用量或手邊可用的工具進行不同的換算。元組用來為測量結果中的數值部分提供[鴨子型別][concept-duck-typing]。

因此，這裡會探討如何使用浮點數進行基本的數值換算。

### 換算

| 原單位             | 目標單位 |
| ------------------ | -------- |
| 1 mL               | 1mL      |
| 1 cup              | 240mL    |
| 1 fluid ounce (US) | 29.57mL  |
| 1 teaspoon         | 5 mL     |
| 1 tablespoon       | 15 mL    |

## 任務

這份教材應該引導學生了解如何使用：

- 元組
- 將元組作為分組資訊
- 透過元素索引取得元組中的值
- 使用模式配對取得元組中的值
- 建立新的元組
