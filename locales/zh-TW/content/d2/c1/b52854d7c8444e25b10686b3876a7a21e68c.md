# 簡介

## 整數

整數是屬於集合`{..., -2, -1, 0, 1, 2, ...}`的完整數字。整數的最大值和最小值取決於 PHP 所執行的系統。在大多數現代系統上，整數通常是 64 位元的值，也就是說它可以表示`-9_223_372_036_854_775_808`到`9_223_372_036_854_775_807`（含頭尾）。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

你可以使用進位前綴，以 10 進位以外的進位來書寫整數字面值：

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> 摘自 PHP 的[說明文件][syntax]

## 浮點數

在 PHP 中，浮點數用來表示實數的一部分。它們由一個或多個數字組成，並以小數分隔符隔開。

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### 常見陷阱

並非所有數字和算術運算都能用浮點數來完成。用浮點數來表示金額可能導致捨入誤差。

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## 算術運算子

PHP 提供了多種運算子來執行算術運算。PHP 的算術運算子遵循標準的數學運算順序。PHP 提供的運算子有：

* 正號（+）
* 負號（-）
* 加法（+）
* 減法（-）
* 乘法（*）
* 除法（/）
* 取模（%）
* 次方（**）

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
