# 指令

在這項練習中，你將寫一些程式碼，幫助你依照最愛的食譜烤出完美的千層麵。

你有 5 個任務，全都和烤千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義`expected_minutes_in_oven`函式，它不接受任何引數，並回傳千層麵應該在烤箱中待幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```gleam
expected_minutes_in_oven()
// -> 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remaining_minutes_in_oven`函式，它接受千層麵已經在烤箱中的實際分鐘數作為引數，並根據前一個任務中預期的烤箱時間，回傳千層麵還需要在烤箱中待幾分鐘。

```gleam
remaining_minutes_in_oven(30)
// -> 10
```

## 3. 計算準備時間（分鐘）

定義`preparation_time_in_minutes`函式，它接受你加到千層麵中的層數作為引數，並回傳你準備千層麵所花的分鐘數，假設每一層需要 2 分鐘準備。

```gleam
preparation_time_in_minutes(2)
// -> 4
```

## 4. 計算總工作時間（分鐘）

定義`total_time_in_minutes`函式，它接受兩個引數：第一個引數是你加到千層麵中的層數，第二個引數是千層麵已經在烤箱中的分鐘數。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間的分鐘數，加上千層麵目前在烤箱中待的分鐘數。

```gleam
total_time_in_minutes(3, 10)
// -> 16
```

## 5. 建立千層麵烤好的通知

定義`alarm`函式，它不接受任何引數，並回傳一則表示千層麵可以吃了的訊息。

```gleam
alarm()
// -> "Ding!"
```
