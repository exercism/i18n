# 提示

## 一般

- 觀看 Jeroen Engels 的[精彩演講][phantom-builder-pattern]，主題是幻影建造者模式。

## 1. 為寶箱提供一個佔位符

- `Chest`和`TreasureChest`可以相同，兩者都是單一變體，只是加上了幻影型別。
- 佔位符`Chest todo`沒有足夠的型別引數，因為缺少了幻影型別。
- 幻影型別應該是記錄，這樣才能擴充。
- 起始型別是不受約束的`Chest treasure {}`，最終型別則是經過完整驗證的`Chest treasure { conditions | securePassword : (), uniqueTreasure : () }`。
- 要從起始型別變成另一個，`secureChest`和`uniqueTreasures`會分別加上`securePassword : ()`和`uniqueTreasure : ()`這兩個條件。

## 2. 選取安全的寶箱

- 你可以對函式引數中的`Chest`進行模式比對。
- 你可以使用[`String.length`][string-length]函式來驗證密碼。
- `securePassword : ()`條件是從型別簽章加上去的，不是從函式主體。
- 你不能把未受約束的`Chest`放進`Just`裡，然後期望型別會改變。你需要用`Chest`建構子建立一個新值。

## 3. 選取獨特的寶藏

- 沒有現成的`List.unique`函式可用，你應該自己建立一個。
- 一個可行的做法是使用`List.filterMap`，搭配一個型別類似`secureChest`的輔助函式。
- `uniqueTreasure : ()`條件是從型別簽章加上去的，不是從函式主體。
- 你不能把未受約束的`Chest`放進`Just`裡，然後期望型別會改變。你需要用`Chest`建構子建立一個新值。

## 4. 享受最終成品

- `makeTreasureChest`應該使用`TreasureChest`型別建構子。
