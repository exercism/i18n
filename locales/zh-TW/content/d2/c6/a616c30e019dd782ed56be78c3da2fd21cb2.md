# 三元運算子

三元運算子提供了另一種語法，可以執行 `if..else..` 比較並回傳值。

## 語法

PHP 提供了 `if` 敘述，讓你能根據條件的真假來決定要評估哪個動作。

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

或者，三元運算子也能表示同樣的操作：

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

這種比較語法很短，寫成 `(condition) ? (evaluate if true) : (evaluate if false);`。

## 優點

使用三元運算子最明顯的好處就是簡潔，相較於 `if..else..` 敘述，條件運算式寫起來短得多，不過它還有其他幾個好處：

- 它是一個運算式，可以放在另一個運算式裡面使用
- 它讓每個分支可以惰性求值。

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  在這個例子裡，如果不需要精確答案，就不會呼叫那個耗時的計算。

## 缺點

三元運算子有幾個缺點，因此使用前值得多想一下：

- 三元運算子可能比較難閱讀，因為它靠的是解讀符號，而不是使用關鍵字。
- 三元運算子可能在不經意間導致 bug，因為 PHP 的三元運算子是左結合的，這和多數現代語言（例如 C、Java、JavaScript）相反。
- 在 `true` 或 `false` 分支中被求值的運算式必須回傳一個值。

## 更精簡的寫法

三元語法還能再縮短成 `(condition) ?: (evaluate if falsey)`。
其中一種用法，就是在運算式裡提供備援值：

```php
$fruit = null;
eat($fruit ?: 'apple');
```

這有時也稱為 _Elvis 運算子_（`?:`）
