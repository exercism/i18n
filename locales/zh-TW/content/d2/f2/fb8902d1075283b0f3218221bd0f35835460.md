# 關於

Gleam 有一級函式，意思是函式就是一般的值，可以指定給變數、作為引數傳入，也可以從其他函式回傳。

在模組中定義的具名函式，可以透過它的名稱來引用。

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam 也有匿名函式，這類函式定義在其他函式裡面。

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

函式的型別寫法和匿名函式類似。一個接受`Int`和`Float`並回傳`Int`的函式，型別寫起來像這樣：

```gleam
fn(Int, Float) -> Int
```

匿名函式可以引用定義當下作用域內的變數，這讓它們成為_閉包_。

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_函式擷取_語法提供了一種方便的簡寫，用來建立把單一引數傳給某個函式的匿名函式。下面這兩個運算式是等價的：

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
