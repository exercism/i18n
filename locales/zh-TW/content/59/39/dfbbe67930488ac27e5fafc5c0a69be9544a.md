# 提示

## 一般

- 建立結構體實例時，先宣告結構體名稱，後面接著以大括號括住的欄位值。
- 你可以用`@T`來宣告某個型別`T`的快照，例如`let i: @u32 = @1;`會宣告一個變數`i`，它是`u32`值`1`的快照；
- 你可以用`*`（desnap）運算子從快照中取出值，例如`let int = *an_int_snapshot;`。
- 你可以用`mut`關鍵字把值宣告為可變的，例如`let mut i = 1;`。

## 1. 建立計票器

- 你需要建立一個指向`VoteCounter`結構體的指標，也就是`@VoteCounter`。
- 建立結構體實例時，可以直接指定`value`參數。

## 2. 從計票器取得票數

- 你可以對快照使用`*`運算子將它 desnap 並取得它的值，例如`*my_snapshot`。

## 3. 增加計票器的票數

- 你不能直接修改`@VoteCounter`快照，而是要回傳一個票數已增加的新`VoteCounter`實例。
- 你可以用`*`運算子將底層的計票器值 desnap，或是呼叫你在前一個任務建立的那個函式。

## 4. 建立選舉結果

- 建立一個新的`ElectionResult`結構體或變數，並用函式引數中的值填入`name`和`vote_counter`欄位。
- 你可以在變數名稱或結構體宣告前面加上`@`運算子來建立`VoteCounter`快照，或是呼叫你在前面某個任務建立的`new_vote_counter`函式。

## 5. 公布結果

- 雖然你收到的是`ElectionResult`的快照，但你仍然可以用點號`.`存取它的欄位，就像它不是快照一樣！
- 透過存取結構體上的`name`和`vote_counter`欄位來組成訊息。
- 當你要 desnap 巢狀快照時，需要套用與待 desnap 快照數量相同的`*`運算子：

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. 重新計票

- 由於[字典的實作方式][dictionaries underneath]，字典必須是可變的才能修改和讀取，這表示你在函式內對字典所做的變更，在函式外也看得見。
- 若要增加`let mut m: Felt252Dict<u32>`中某個鍵的值，你應該合併使用它的`get`和`insert`函式：`m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
