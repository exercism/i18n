# 迴圈

```sather
   loop
      ...
   end;
```

Sather 只有一種迴圈敘述。它沒有`while`，也沒有`for`；這兩者都是用`loop`加上某個能結束它的東西拼出來的。

## 變數

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=`會宣告變數，並從給定的值推得型別。當某個變數必須先存在、之後才有值時，改用型別來宣告它：

```sather
   total : INT;
   total := 0;
```

沒有指定值的變數，若是`INT`就從零開始，若是`BOOL`就從`false`開始，若是字串或物件則為 void。

## 結束迴圈

| 寫法 | 結束迴圈的時機 |
| --- | --- |
| `until!(q)` | `q`為 true 時 |
| `while!(q)` | `q`為 false 時 |
| `break!` | 立刻結束 |

這三種可以出現在迴圈主體的任何位置，同一個迴圈也可以搭配使用多種。

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## 驚嘆號

`until!`、`while!`和`break!`都以`!`結尾，因為它們是**疊代器**，也就是只能出現在迴圈裡、而且能結束迴圈的東西。在迴圈外寫下其中一個，會是錯誤，而不是警告。之後的練習會用到函式庫裡其他的疊代器，最後甚至會自己寫出新的疊代器。

## 無窮迴圈

一個沒有東西能結束它的迴圈會永遠執行下去。偶爾這正是我們想要的，但更常見的情況是，判斷條件所問的那個值始終沒有改變。如果程式卡住不動，首先要檢查的，就是迴圈裡是否有東西正讓它一步步走向結束。
