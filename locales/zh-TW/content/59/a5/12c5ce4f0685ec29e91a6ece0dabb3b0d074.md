# 簡介

[switch 敘述][switch]會把一個值和多個可能的相符模式做比較，是取代串接多個 `if-else` 敘述時更簡潔、也更好讀的另一種寫法。

`switch`敘述以`switch`關鍵字開頭，後面接著要測試的值。每個可能的相符情況都用`case`關鍵字帶出。`default`關鍵字則定義備援情況，當沒有任何明確的情況相符時就會執行。和`if-else`串接一樣，`switch`敘述只會執行第一個相符情況所對應的程式區塊。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

來看看下面這串`if-else`：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

改用`switch`敘述可以寫得更清楚：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
