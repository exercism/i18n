# 說明

在這道練習中，你會玩一款叫做「Wizard and Warriors」的角色扮演遊戲，可以選擇扮演巫師或戰士。

戰士和巫師各有不同的規則來決定他們造成的傷害點數。

戰士的規則如下：

- 若攻擊的目標並非處於易受傷狀態，造成 6 點傷害
- 若攻擊的目標處於易受傷狀態，造成 10 點傷害

巫師的規則如下：

- 若巫師事先準備了法術，造成 12 點傷害
- 若巫師沒有事先準備法術，造成 3 點傷害

一般來說，角色永遠不會處於易受傷狀態。不過，巫師如果沒有準備法術，就_會_處於易受傷狀態。

你有六個任務要處理戰士和巫師角色。

## 1. 描述角色

覆寫`Character`類別上的`ToString()`方法，回傳角色的描述，格式為`"Character is a <CHARACTER_TYPE>"`。

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. 讓角色預設不易受傷

確保`Character.Vulnerable()`方法永遠回傳`false`。

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. 讓巫師可以準備法術

實作`Wizard.PrepareSpell()`方法，讓巫師能事先準備法術。

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. 讓巫師在未準備法術時處於易受傷狀態

確保巫師沒有準備法術時，`Vulnerable()`方法回傳`true`；否則回傳`false`。

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. 計算巫師的傷害點數

實作`Wizard.DamagePoints()`方法，回傳造成的傷害點數：已準備法術時為 12 點傷害，未準備時為 3 點傷害。

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. 計算戰士的傷害點數

實作`Warrior.DamagePoints()`方法，回傳造成的傷害點數：目標處於易受傷狀態時為 10 點傷害，否則為 6 點傷害。

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
