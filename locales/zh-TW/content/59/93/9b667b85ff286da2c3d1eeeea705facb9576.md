# 關於

[記錄][records]是一種資料結構，將相關的資訊加上標籤分組在一起。它們類似於 JavaScript 或 Java 的物件，或 C 或 Rust 的 struct，但有一些關鍵差異。

## 建立記錄

記錄是以大括號[建立][create]的，其中各個元素以逗號分隔。

```elm
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

記錄的型別也用類似的語法定義，只是等號`=`換成了冒號`:`。

```elm
firefly : { name : String, creator : String, episodes : Int }
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

一直重複寫這些型別定義很麻煩，所以用[型別別名][record-types]來共用定義是常見的做法。

```elm
type alias TvSeries =
    { name : String
    , creator : String
    , episodes : Int
    }

firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

型別別名也會自動為這個記錄提供一個建構函式。這有時會讓人覺得意外，因為 Elm 的函式必須以小寫字母開頭，但型別建構函式正是其中一個例外。

```elm
firefly : TvSeries
firefly = TvSeries "Firefly" "Joss Whedon" 14
```

## 存取記錄的欄位

[存取記錄實例的欄位值][access]的主要方式，是使用`firefly.creator`這樣的點記法。Elm 編譯器也支援以點號`.`開頭的特別存取函式，例如`.creator`，它們可以用在任何具有同名欄位的記錄上。這是「函式必須以小寫字母開頭」這條規則的第二個例外。事實上，使用者定義的函式必須以小寫字母開頭，但我們剛才看到的這兩個例子是編譯器產生的，而不是程式設計師寫的。

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

firefly.name
    --> "Firefly"

.creator firefly
    --> "Joss Whedon"
```

記錄也可以在綁定中被_解構_，使用的是[記錄模式比對][pattern-matching]。解構可以用在任何具有相關名稱欄位的記錄上。

```elm
episodesCount : TvSeries -> Int
episodesCount { episodes } =
    episodes

complicatedCopy : TvSeries -> TvSeries
complicatedCopy show =
    let
        { name, creator } = show
    in
    { name = name
    , creator = creator
    , episodes = episodesCount show
    }
```

## 更新記錄

就像 Elm 裡的一切，記錄是不可變的，所以一旦定義了記錄，它的欄位值就永遠不會改變。有[一種特別的語法可以建立現有記錄的副本，同時改變一個或多個欄位][update]。這種語法使用豎線符號`|`來區分原始記錄和即將改變的欄位，例如`{ oldRecord | field1 = newValue }`。

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

updatedFirefly : TvSeries
updatedFirefly =
    { firefly | creator = "J Whedon", episodes = 15 }
```

## 比較記錄

Elm 使用[結構相等性][equality]，意思是同一個記錄的兩個實例若有相同的值，就會被視為相等。

```elm
firefly1 = TvSeries "Firefly" "Joss Whedon" 14
firefly2 = TvSeries "Firefly" "Joss Whedon" 14

firefly1 == firefly2
    --> True
```

## 可擴充記錄

Elm 也支援[結構型別][structural-typing]，意思是如果某個函式需要具有 x 和 y 欄位的記錄，它就能用在任何具有這些欄位的記錄上，例如 2D 點、3D 點、太空船等等。這類型別定義中帶有豎線`|`，例如`{ a | x : Float, y : Float }`，在 Elm 的術語中稱為「可擴充記錄」。要留意型別定義中的豎線`|`（這是可擴充記錄的定義，例如`{ a | x : Int }`）和實際記錄實例中的豎線`|`（代表我們正在更新該記錄的某些欄位）之間的差別。

```elm
point2d = { x = 1, y = 2 }
point3d = { x = 3, y = 4, z = 7 }

.x point2d --> 1
.x point3d --> 3

length : { a | x : Float, y : Float } -> Float
length vector =
    sqrt (vector.x * vector.x + vector.y * vector.y)

length point2d --> 2.236068
length point3d --> 5

translateX : { a | x : Float } -> { a | x : Float }
translateX vector =
    { vector | x = vector.x + 1 }

translateX point2d --> { x = 2, y = 2 }
translateX point3d --> { x = 4, y = 4, z = 7 }
```
