# 說明

Lisp 外星人 Leslie 需要去買點東西。有一份購物清單是很重要的，要能往裡面加東西，也要能從裡面拿掉東西。

當然，單純的紙筆對 Lisp 外星人來說是不夠的。「List」幾乎就是「Lisp」這個字的全部了！一定得寫些函式來幫忙記錄要買的東西。

你能幫 Leslie 記錄這份購物清單嗎？

## 1. 建立新清單

首先，Leslie 需要建立一個空的清單。一個叫做`new-list`的函式正好適合這件事。

```lisp
(new-list) ; => ()
```

喔不……Leslie 心裡已經有幾樣想買的東西了，所以他們需要一個函式，接受三個項目（還好 Leslie 只會建立包含三個項目的清單，不多也不少！），並用這些東西建立一份新的購物清單。寫一個`list-of-things`函式，接受三個項目並回傳包含它們的清單。

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. 把東西加進清單。

去商店之前，Leslie 會先翻翻儲藏室，看看自己需要什麼。幫他們寫一個`add-to-list`函式，把項目加到清單的開頭。

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. 清單上的下一樣（幾樣）東西是什麼？

購物時，Leslie 想知道接下來要找什麼。他們也喜歡先偷看清單，看看第二個、第三個，甚至是第 23 個項目（他們的幸運數字）。

- `first-thing`會求值為清單上的第一樣東西
- `second-thing`會求值為第二樣東西
- `third-thing`會求值為第三樣東西
- `twenty-third-thing`會求值為第二十三樣東西

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. 從清單移除東西

Leslie 想找出清單上的第一個項目，並把它從架上拿下來。幫他們寫一個`remove-first-item`函式，它會求值為輸入清單中除了第一個項目以外的所有項目。

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. 用較小的清單拼出較大的清單

Leslie 發現自己不小心做了兩份購物清單，而不是一份！寫一個`list-append`函式，回傳一個清單，其中包含第一個清單的元素，後面接著第二個清單的元素。

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. 還要多久？

Leslie 開始擔心這趟購物會花上好一陣子。這份清單上到底有幾樣東西？寫一個`just-how-long`函式，告訴他們清單有多長。

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
