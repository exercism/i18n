# 給維護者

## 產生測試：`bin/generate_tests.py`

測試檔案是從 [exercism/problem-specifications](https://github.com/exercism/problem-specifications) 中的標準資料產生，使用的是儲存在每個練習`.meta/template.j2`的 Jinja 範本。

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

這個腳本會從 configlet 的快取（`~/.cache/exercism/configlet/problem-specifications`，由`bin/configlet sync`填入）讀取 problem-specifications，或從名為`problem-specifications`的上層目錄讀取。
只會產生`.meta/tests.toml`中收錄的案例。

Fortran 字串常值不能包含`\n`和`\t`這類跳脫序列。
`escape_quote_whitespace`範本篩選器會把這些改寫成`" // NEWLINE // "`、`" // TAB // "`與`" // CARRIAGE_RETURN // "`，因此範本必須宣告這些常數（請見`exercises/practice/bob/.meta/template.j2`）。

### 先備條件

- 可正常運作的 CMake 與 Fortran 編譯器
- Python 3.12+（需安裝`jinja2`）
- git

### 新增練習的工作流

以`bob`為例：

- 建立新分支，例如`git checkout -b exercise-bob`
- 執行`bin/add-exercise bob`（需要`jq`和`curl`）。這會：
  - 取得 configlet 並執行`configlet create`，這會把練習加入`config.json`，並從 problem-specifications 同步它的文件、中繼資料與`tests.toml`
  - 用`bin/reorder-exercises`排序`config.json`
  - 把`exercises/shared/CMakeLists.txt`複製到練習目錄
  - 寫入一份預留的解答、一份預留的`.meta/example.f90`，以及一份初始的`.meta/template.j2`（取自`exercises/shared/template.j2`）

  除非你傳入`-a <username>`，否則它會詢問你的 GitHub 使用者名稱；除非你傳入`-d <difficulty>`，否則難度會設為 1。

- 編輯`.meta/template.j2`，讓每個案例以正確的輸入呼叫正確的函式，然後產生測試：

  ```bash
  bin/generate_tests.py bob
  ```

- 在`.meta/example.f90`寫入可正常運作的解答。把學生檔案（例如`bob.f90`）替換成測試所呼叫的函式或副程式骨架，幫助學生起步。
- 確認所有測試都通過，並從儲存庫根目錄執行完整建置：

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- 執行`bin/reorder-exercises`與`bin/configlet lint`
- 如果一切順利，就為你的變更開啟一個 pull request。

### 修改`CMakeLists.txt`

修改 cmake 檔案時，請更新`exercises/shared/`裡的主要副本，並用`bin/update-cmake-files`將它複製到所有練習目錄。
