# 關於

C# 是一種靜態型別的語言，意思是所有東西在編譯期都有型別。為[變數][variable]命名就叫做定義變數。變數定義好之後，設定或更新它的值則稱為變數賦值。定義變數時，可以明確指定它的型別，也可以使用[`var`關鍵字][var]，讓 C# 編譯器根據指定的值推斷型別。使用`var`的做法稱為_型別推斷_。

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

變數的值可以使用[`=`運算子][assignment]來指定和更新。變數一旦定義，它的型別就永遠不會改變。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# 是物件導向語言，所有[函式][function]都必須定義在_類別_中，而類別是用[`class`關鍵字][classes]定義的。物件（或_執行個體_）則是用`new`關鍵字建立的。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

類別內的函式稱為_方法_。每個[方法][methods]可以有零個或多個參數。所有參數都必須明確標註型別，參數沒有型別推斷。同樣地，回傳型別也必須明確標示。方法是使用[`return`關鍵字][return]回傳值的。若要讓其他檔案的程式碼可以呼叫某個方法，就必須加上`public`存取修飾詞。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

方法是在執行個體上使用點（`.`）語法來呼叫的，要指定呼叫的方法名稱，並為方法的每個參數傳入引數。引數可以選擇性地指定對應的參數名稱。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

如果要呼叫的方法和呼叫它的方法定義在同一個類別裡，可以省略類別名稱。

如果某個方法沒有用到任何物件_狀態_，就可以用`static`修飾詞把它變成_靜態_方法。靜態方法同樣是用點（`.`）語法呼叫，但呼叫的對象是類別本身，而不是類別的執行個體。

如果一個類別只有靜態方法，這個類別也可以用`static`修飾詞設為靜態。這表達了這個類別的用途。

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

C# 中的作用域定義在`{`和`}`字元之間。

C# 支援兩種[註解][comments]。單行註解前面要加`//`，多行註解則放在`/*`和`*/`之間。

整數值定義為一個或多個（連續的）數字，並支援[預設的數學運算子][operators]。

變數名稱[必須遵循一些規則][identifier-names]，例如開頭必須是字母或底線，而且[應該遵循 C# 的命名慣例][naming-guidelines]。如果變數名稱和保留的 [C# 關鍵字][csharp-keywords] 衝突，就必須用`@`來脫逸。不建議使用這種寫法，但在特殊情況下還是會遇到，例如：`var @this`、`var @class`或`var @var`。

有幾個概念對 C# 這類 C 語言家族的語言來說非常基本，幾乎在任何非平凡的程式碼中都會自然出現。這些概念就是[可變性][mutation]和[作用域][scope]。可變性是指變數的值可以在程式執行期間改變。作用域是指與某個名稱（程式元素的名稱）相關聯的值，只能在定義它的程式碼「區域」記憶體內存取。C# 中主要的程式碼區域是_類別/結構_和_函式_（通常是方法），但也可能包含迴圈和其他結構的主體。
