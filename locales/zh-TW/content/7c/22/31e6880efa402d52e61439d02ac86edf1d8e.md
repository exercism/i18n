# 建構子屬性提升

在宣告許多屬性的類別中，分別宣告類別、它的屬性，以及用來設定這些屬性的建構子，會造成重複。
使用建構子屬性提升可以減少重複的量。

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
