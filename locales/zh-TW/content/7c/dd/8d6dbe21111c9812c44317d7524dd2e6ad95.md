# 關於

## 可選型別

Swift 使用[_可選型別_][optionals]，讓開發者能夠表示某個值可能不存在。可選型別是一種型別，它可以持有一個值，也可以是[`nil`][nil]，後者代表值不存在。使用可選型別時，程式必須先確認值確實存在，解開之後才能使用。

任何型別只要在型別名稱後面加上`?`，就能變成可選型別。因此可選整數的型別是`Int?`，可選字串的型別是`String?`。定義可選型別的常數或變數，以及為它們指定值的方式，都和非可選型別完全相同。

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

只要把特殊的值`nil`指定給可選型別的變數，就表示該變數沒有值。`nil`可以用在所有可選型別上，但指定給 2 種不同可選型別的`nil`並不屬於同一種型別，不能互換，甚至不能比較。

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

另外要注意，雖然`nil`可以指定給任何可選型別，卻不能指定給非可選型別（即使那個型別實際上並不是`nil`）。而預期接收非可選型別的方法，也不能在沒有先解開的情況下傳入可選型別。

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## 使用可選型別

可選型別和它的基底型別是不同的型別，因此兩者的用法並不相同。例如：`Int("123") + 1`會產生編譯器錯誤「Value of optional type 'Int?' must be unwrapped to a value of type 'Int'」。這是因為`Int("123")`回傳的是可選的`Int?`型別，而不是`Int`型別；若字串無法轉換成整數，結果就會是`nil`。若要從轉換結果中取得`Int`，就必須先將它「解開」。

在 Swift 中，最常見的做法是使用`if-let`和`guard-let`這兩種[_可選綁定_][optional-binding]的語法結構。它會檢查是否為`nil`：如果值存在，就讓程式走其中一條路徑，並把解開後的值綁定到指定的名稱；如果發現是`nil`，就走另一條路徑。

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

值得注意的是，`safeNum`變數的型別是`Int`，而不是`Int?`。在下面的範例中，`num`的型別是`Int?`，而`safeNum`的型別是`Int`。

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

這種_可選綁定_很重要，因為它會把可選型別從值上解開（也就是「移除」），讓這個值能以非可選值的方式使用。如果只是用條件判斷檢查值是否為`nil`，這個值仍然會是可選型別：

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

在需要提早回傳的情況下，也可以使用`guard-let`這種做法：

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## 比較可選型別

請注意，即使 2 個可選值的基底型別可以用標準的比較運算子比較，可選值本身卻不能比較，只能檢查它們是否相等。2 個可選值若都是`nil`，或是它們所包裝的值在各自的基底型別中相等，則兩者相等。

不過，我們可以撰寫程式碼，對 2 個可選值進行自訂的比較。下面的範例是一個`switch`敘述，只有在 2 個可選值都不是`nil`，且第一個值小於第二個值時，才會回傳`true`。它使用_可選模式_`varName?`來達成這件事；這個模式只會比對非`nil`的可選值，並把可選值內部的值綁定到名稱`varName`。

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
