# 關於

靜態擴充讓你在不修改原始碼的情況下，為既有的型別加上看似擴充的功能。這是透過 `using` 敘述達成的。靜態擴充可以是很強大的工具，讓你不必實際改動型別就能擴增它們。

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
