# 關於

[Symbol][symbols] 是具名的識別碼，可以用來參照某個值。Symbol 是透過 Symbol 字面值建立的，做法是在名稱前面加上一個 `:` 字元，例如 `:foo`。Symbol 也可以用引號包起來書寫，例如 `:"foo"`，這樣一來，名稱裡就能包含空白等字元。

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Symbol 在這門語言的許多地方都會用到，包括作為具名元組的鍵，以及用來表示方法和變數的名稱。

## Crystal 中的 Symbol

Crystal 的 Symbol 和 Ruby 的差別很大。在 Crystal 中，Symbol 是一種常數，因此是在編譯時期就指定完成。這表示 Symbol 無法動態建立，而在 Ruby 中是可以的。

Crystal 的 Symbol 以 `Int32` 表示，因此非常有效率。

## 轉換

Symbol 可以轉換成字串，反之則不行。這是因為 Symbol 是在編譯時期建立，而字串則是在執行時期建立。

```crystal
:foo.to_s # => "foo"
```
