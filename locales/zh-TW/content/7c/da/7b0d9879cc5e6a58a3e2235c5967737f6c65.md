# 簡介

方法參數可以透過指派預設值來變成選擇性參數。當呼叫帶有選擇性參數的方法時，呼叫者不需要為它們傳入值。如果沒有為選擇性參數傳入值，就會使用它的預設值。

選擇性參數必須位於參數列表的最後；它們後面不能接著非選擇性參數。

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

選擇性參數可以透過在變數名稱前使用`?`運算子來設為`null`：

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
