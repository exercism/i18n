# 測試

每個練習都包含一個測試檔。
使用`bats`程式執行測試。

```bash
bats hello_world.bats
```

如果你在本機執行測試時需要輸出除錯訊息，請參閱[在本機除錯][debugging]。

你需要先安裝`bats`。
請參閱 [Bash 軌道的測試][tests] 頁面，了解如何在你的系統上安裝`bats`。

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## 略過的測試

解完一個練習，代表要讓它所有的測試都通過。
預設情況下，執行測試時只會執行一個測試（第一個）。
這是刻意的設計，讓你可以只專注在讓那一個測試通過。
一旦它通過了，你可以把下一則標註註解掉或刪除，來啟用下一個測試：

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## 覆寫略過設定

若要執行所有測試，包括帶有`skip`標註的測試，可以執行：

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

用包裝函式來省點打字會很方便：

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

這樣一來，只要執行：

```bash
bats
```
