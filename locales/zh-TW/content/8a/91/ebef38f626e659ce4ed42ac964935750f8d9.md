# 簡介

這個練習會延續[莉亞的美味千層麵][lasagna]裡的整數運算。在這裡，你會接觸浮點數，並學會針對不同的情況挑選正確的除法詞。

## 整數與浮點數

Factor 會區分整數（`1`、`42`、`1_000_000`）與浮點數（`1.0`、`3.14`、`6.02e23`）。如果同一個計算中混用了整數與浮點數，結果就會是浮點數：

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

你可以在數字裡加上底線來分組，例如`1_000_000`，而 Factor 會直接忽略它們。

## 除法詞

Factor 有各自獨立的除法詞，它們都位於[`math`][math]詞彙中。

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` 對兩個整數會產生`ratio`（Factor 的精確有理數型別），如果其中一個輸入是浮點數，就會產生`float`。`/f` 即使對兩個整數也會強制產生浮點數結果。`/i` 一律向零截斷。

## 檢查

來自[`math`][math]、[`math.functions`][math.functions]和[`math.primes`][math.primes]的數字述詞：

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## 浮點數轉整數

[`math.functions`][math.functions]詞彙中的`floor`、`ceiling`和`round`都會回傳浮點數（`3.0`，而不是`3`）。若要取得真正的整數，請串接`>integer`：

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## 次方與絕對值

`sq`、`^`和`abs`（位於[`math.functions`][math.functions]）會計算平方、任意次方與絕對值：

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## 最小與最大

`min ( x y -- z )`和`max ( x y -- z )`（位於[`math.order`][math.order]）會回傳兩個數字中較小或較大的那一個：

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

最常見的用法是*夾限*：用`max`把值固定在下限（例如`0 max`會讓值保持非負），或用`min`把它固定在上限。

## 順序述詞

`math.order`也提供`before?`、`after?`、`before=?`、`after=?`，這些比較述詞可用於任何可排序的型別，例如數字、字串和字元：

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

當值可能是字串時，請改用這些述詞，而不要用`<`/`<=`，因為算術運算子不會對字串分派。
