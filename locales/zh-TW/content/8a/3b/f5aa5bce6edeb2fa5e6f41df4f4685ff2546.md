# Exercism 的 Rust 學習軌道有哪些內容不在範圍內？

這份文件要說明的是：在 Rust 語言、社群與生態系的範圍內，Exercism 的 Rust 學習軌道能教什麼、不能教什麼。

如果某個練習已在 _design.md_ 的「Out of scope」底下說明過，這裡就不該再重複，除非你認為該主題在其他地方沒有得到足夠的重視。

## 網頁介面的限制

使用網頁介面的學生，能做的事僅限於網頁介面與測試執行器所允許的範圍，因此網頁介面的能力實際上就是 Rust 學習軌道的外圍限制。

學生可以：

- 編輯單一的 `.rs` 檔案
- 接收 `stdout` 的輸出（例如來自 `dbg!`）

值得注意的是，這表示他們不能編輯 Cargo.toml，因此任何依賴外部 crate 的練習，都必須事先把所有相依項目列在 Cargo.toml 裡。

## Exercism 不教什麼

Exercism 的目標是讓你精通一門程式語言，而不是傳授軟體設計或資訊科學這類更抽象的技能。因此，任何與 Rust 程式語言關係不大的主題，都不在 Rust 學習軌道的範圍內。

## 不在範圍內的主題範例

以下是一些被排除在外的主题：

### Cargo

- 編輯 Cargo.toml
- CLI 指令，例如 `new`、`update`、`bench`

### 框架

- Amethyst
- Yew、Iced、Sauron 等

### 互通性

- CFFI
- `asm!`

### 一般來說：

- 檔案處理
- 網路
