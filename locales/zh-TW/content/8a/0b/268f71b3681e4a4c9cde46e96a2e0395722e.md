# 關於

Dart 結合了物件導向程式設計與靜態型別，同時保有 JavaScript 這類動態語言的靈活性。
Dart 的設計目標是簡化常見的程式設計工作，因此在軟體開發社群中迅速竄紅，尤其是因為它與跨平台開發的熱門框架 [Flutter](https://flutter.dev) 緊密整合。

## Dart 的關鍵概念

- **簡單且熟悉：** 對熟悉 Java、JavaScript 或 C# 等語言的開發者來說，Dart 很容易上手。
  它的語法簡潔一致，相當平易近人。
- **現代的物件導向語言：** Dart 融入了現代物件導向原則，對類別、繼承與介面提供完善支援。
- **強型別兼具靈活性：** Dart 雖然是靜態型別語言，卻提供靈活的型別推論與動態功能，讓開發者同時享有兩者的優點。
- **非同步程式設計輕鬆上手：** Dart 的`async`和`await`關鍵字簡化了並行處理。
  以**isolates**（輕量、類似執行緒的結構）為核心的事件驅動模型，讓你能有效率地進行非同步執行，不必處理複雜的執行緒作業。
- **完整的工具與函式庫：** Dart 提供豐富的內建函式庫，生態系更有 [Pub.dev](https://pub.dev) 加持；這個套件管理器提供各式各樣的開源函式庫與工具。
- **跨平台開發：** Dart 是 [Flutter](https://flutter.dev) 的動力來源，而 Flutter 是最受歡迎的框架之一，讓你能用同一份程式碼基底，打造行動裝置、網頁與桌面平台的高效能跨平台應用程式。
- **網頁支援：** Dart 程式碼可以轉譯成 JavaScript，因此用戶端與伺服器端的網頁開發都適用。
  像 [AngularDart](https://github.com/angulardart-community)（前身為 [https://github.com/angulardart](https://github.com/angulardart)）這類框架，就是專為 Dart 網頁應用程式量身打造。
- **伺服器端能力：** Dart 不只適合前端開發；你也可以搭配 [Shelf](https://pub.dev/packages/shelf) 等框架，建構可擴充的伺服器端應用程式。
- **高效能：** Dart 程式碼在行動裝置與桌面應用程式上會編譯成原生機器碼，在網頁上則編譯成最佳化的 JavaScript，在各平台上都能展現高效能。

## Dart 的多元應用

- **行動應用程式：** Dart 最廣為人知的用途是透過 Flutter 開發行動應用程式，讓 iOS 與 Android 之間能共用一致的使用者介面與商業邏輯。
- **網頁開發：** Dart 可以編譯成 JavaScript 來建構現代網頁應用程式，無論是使用原生 Dart 框架，或是 Flutter 的網頁版本都沒問題。
- **桌面應用程式開發：** 透過 Flutter，Dart 現在也支援為 Windows、macOS 與 Linux 建立原生應用程式，真正實現跨平台能力。
- **後端服務：** 拜簡潔的語法與效能最佳化之賜，Dart 在後端服務的應用日益增加，能處理 RESTful API、微服務等各種工作。
- **Firebase 與雲端整合：** Dart 透過官方函式庫，對 Firebase 與其他雲端服務的整合提供強大支援，是開發雲端應用程式的熱門選擇。

## 近期增強功能

- **空值安全：** Dart 推出了**健全的空值安全**，確保不可為空值的型別在開發期間正確使用，有助於消除空值參照錯誤。
- **更快的編譯速度：** Dart 在改善編譯流程方面大有進展，同時提供**提前編譯（AOT）**與**即時編譯（JIT）**兩種方式，確保開發週期快速、正式版本建置最佳化。
- **桌面與嵌入式裝置：** Flutter 拓展到桌面與嵌入式平台後，Dart 的應用範圍比以往更廣，開發者能為行動裝置與網頁以外的各種裝置打造應用程式。

Dart 不斷成長的生態系、強大的開發者支援，以及跨平台能力，讓它成為現代應用程式開發的熱門選擇。
