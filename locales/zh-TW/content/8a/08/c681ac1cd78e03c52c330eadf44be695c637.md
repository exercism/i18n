# 提示

## 一般

- 測試會同時從多個執行緒呼叫你的函式。
  你應該使用原子指令，確保不會遺失任何更新。
- `lock`前綴可讓讀取-修改-寫入指令具原子性。
  搭配記憶體運算元的`xchg`一律具原子性，不需要前綴。
- 這些共享的值全都是 64 位元。

## 1. 計算入場人數

- 應該把團體人數加到計數中。
- 你可以用`lock`前綴讓某些指令具原子性。

## 2. 更換膠捲

- 可以使用`xchg`指令交換兩個運算元。
  搭配記憶體運算元時，它會自動具原子性。
- 這個函式會回傳先前掛上的膠捲的識別碼。

## 3. 賣出一張票

- `xadd`指令會把來源運算元加到目的運算元，並在更新前回傳舊的值。
  你需要以原子方式把目前的計數加一，並回傳更新後的值，而不是舊的值。
- 你可以用`lock`前綴讓某些指令具原子性。
- 就算兩道指令都具原子性，值也可能在它們之間改變。
  讀取計數器和寫入計數器應該在同一道原子指令中完成。
- 回傳的值是遞增_之後_的計數。

## 4. 填滿首映場

- 如果計數已經達到最大容量，就不能更新，而且函式應該回傳`0`。
- 如果計數還沒達到最大容量，就應該加`1`，並回傳這個新的計數。
- 可以用`cmpxchg`確保計數仍然是先前讀取時的值，然後才更新它。
  這個指令會比較它的第一個運算元和`rax`。
  如果第一個運算元等於`rax`，它的值會被第二個運算元取代，並設定`ZF`。
  否則，它的值會存到`rax`，並清除`ZF`。

## 5. 留意售票亭

- 這個函式依序有三個部分：佔用售票亭、執行任務、重新開放售票亭。
- 佔用售票亭是一種測試並設定。
  同一道指令應該取得旗標的舊值，同時把它設為`1`。
  舊值為`0`表示售票亭本來沒人，現在屬於你；而`1`表示裡面已經有別人了。
- 就算兩道指令都具原子性，值也可能在它們之間改變。
  讀取旗標和寫入旗標應該在同一道原子指令中完成。
- 當售票亭被佔用時，執行`pause`，然後再次嘗試交換。
- 當售票亭沒人時，你應該執行任務。
- 任務是一個外部函式。
  呼叫它之前，堆疊應該對齊到 16 位元組，而且任何由呼叫者負責保存的暫存器都可能被它覆寫。
  執行完任務之後你還會需要旗標的記憶體位置，所以要把這個值存到安全的地方。
- 執行完任務之後，應該把`0`存入旗標來重新開放售票亭。
