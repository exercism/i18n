# 關於

Factor 的條件式都以**quotation**作為分支：也就是寫在方括號 `[ ... ]` 裡的程式碼，它會以值的形式被推入堆疊，而不是立刻執行，要等到條件式選中它時才會執行。（**quotation**本身會在後面的練習裡完整介紹。）

最基本的三個在`kernel`裡：

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

另外兩個加星號的變體，會把布林值當成在為真時值得使用的值，也就是典型的「值或`f`」組合：

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

分支超過兩個時，可以用`combinators`裡的`cond`：它會逐一走訪由`{ predicate body }`配對組成的陣列，然後執行第一個成立的述詞的主體。慣用的寫法會在每個述詞裡使用`dup`，讓輸入值保留下來；而主體開頭會先`drop`，在推入結果之前把輸入值丟掉：

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

最後一項如果沒有述詞，就是預設分支。
