# 說明

在這個練習中，你會撰寫程式碼來分析汽車工廠裝配線的產量。裝配線的速度可以從 `0`（關閉）到 `10`（最高）。

以最低速度（`1`）運作時，每小時會生產 `221` 輛車。產量會隨速度呈線性成長。所以當速度設為 `4` 時，每小時應該生產 `4 * 221 = 884` 輛車。然而，速度越高，越可能生產出瑕疵車，這些車就得被丟棄。下表顯示速度如何影響成功率：

- `0`：成功率 0%。
- `1` 到 `4`：成功率 100%。
- `5` 到 `8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

你有兩項任務。

## 1. 計算每小時的生產率

實作 `production-rate` 函式，計算裝配線每小時的生產率，並將成功率納入考量：

```clojure
(production-rate 6)
;;=> 1193.4
```

注意，回傳的值是 `float`。

## 2. 計算每分鐘生產的正常品數量

實作 `working-items` 函式，計算每分鐘可生產多少能正常運作的車輛：

```clojure
(working-items 6)
;;=> 19
```

注意，回傳的值是 `int`。
