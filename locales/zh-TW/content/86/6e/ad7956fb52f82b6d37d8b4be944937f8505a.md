# 關於

在 Common Lisp 中，時間有 3 種表示方式

- 通用時間是一種絕對時間，一個整數，代表自`1900-01-01T00:00:00Z`起經過的秒數（也就是 UTC 的 1900 年 1 月 1 日午夜）。
- 解碼時間是由 9 個值組成的元組，它們共同代表特定的日曆時間：秒、分、時、日、月、年、星期、日光節約時間旗標、時區。
（詳細討論見下文。）
- 內部時間是正整數，單位為實作定義的「內部時間單位」，可用於測量執行時間。

## 通用時間

若要取得目前的通用時間，可以使用`get-universal-time`或`get-decoded-time`。
前者回傳自`1900-01-01T00:00Z`起目前的秒數，後者則以解碼格式回傳相同資料。

請注意，由於這個數字是正整數，因此無法編碼 1900 年之前的日期。

## 解碼時間

`decode-universal-time`和`encode-universal-time`是處理時間的主要函式。
前者接受通用時間，並以 [multiple-values][concept-multiple-values] 的形式回傳解碼時間值；後者接受解碼時間值作為引數，並回傳通用時間。

兩者都接受一個可選的時區引數。
時區的格式請見下文。

解碼時間是一組值：

- *秒*：介於 0 到 59 之間的整數
- *分*：介於 0 到 59 之間的整數
- *時*：介於 0 到 23 之間的整數
- *日*：介於 1 到 31 之間的整數（上限顯然取決於月份和年份）
- *月*：介於 1 到 12 之間的整數
- *年*：表示年份的整數。
- *星期*：介於 0 到 6 之間的整數。0 代表星期一，1 代表星期二，依此類推……6 代表星期日。
- *日光節約時間旗標*：true 值表示目前處於日光節約時間。
- *時區*：介於 -24 到 24 之間的小時數，表示與 UTC 的偏移量。
這個數字是有理數，且必須是`1/3600`的倍數。

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

請注意，未提供時區參數時，會出現一些有趣的行為。
詳情請參閱[`decode-universal-time`][hyperspec-decode-universal-time]和[`encode-universal-time`][hyperspec-encode-universal-time]的文件。

## 內部時間

內部時間是正整數，單位為「內部時間單位」。兩個內部時間的差值可用於測量執行期間的時間。

- `get-internal-real-time`會回傳目前的「真實」或「時鐘」時間。
- `get-internal-run-time`非常取決於實作，可能包含、也可能不包含例如分頁或垃圾回收所花費的時間。

變數`internal-time-units-per-second`含有一個值，代表目前執行中的 Lisp 環境每秒的「內部時間單位」數。
