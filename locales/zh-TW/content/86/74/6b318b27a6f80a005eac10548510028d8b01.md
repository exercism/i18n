# 說明

在這個練習中，你會為一間位於紐約的美容沙龍製作預約排程系統，這間沙龍於 2012 年 9 月 15 日開幕。

你有四項任務，這些任務都會涉及預約日期。日期和時間會使用下列三種格式之一：

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

測試會自動將文化特性設定為 `en-US`，你不需要自行設定或指定文化特性。

## 1. 解析預約日期

實作（_static_）`Appointment.Schedule()`方法，將預約日期的文字表示法解析成對應的 `DateTime` 格式：

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 檢查預約是否已經過去

實作（_static_）`Appointment.HasPassed()`方法，它會接受一個預約日期，並檢查該預約是否發生在過去的某個時間點：

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 檢查預約是否在下午

實作（_static_）`Appointment.IsAfternoonAppointment()`方法，它會接受一個預約日期，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 描述預約的時間和日期

實作（_static_）`Appointment.Description()`方法，它會接受一個預約日期，並回傳該日期和時間的描述：

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 回傳週年紀念日

實作（_static_）`Appointment.AnniversaryDate()`方法，它會回傳今年的週年紀念日，也就是 9 月 15 日：

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
