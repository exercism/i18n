# 簡介

## 比較運算子

[比較運算子][comparison-operators]會比較兩個相同型別的值，並回傳一個 `Bool` 值（`true` 或 `false`）。
如果你試著比較不同型別的值，編譯器會產生錯誤。

Swift 中標準的比較運算子有：

| 運算子 | 說明       | 範例            |
| -------- | ------------------------ | --------------- |
| `==`     | 等於                 | `1 == 1`（true） |
| `!=`     | 不等於                 | `1 != 2`（true） |
| `<`      | 小於                | `4 < 5`（true） |
| `<=`     | 小於或等於    | `4 <= 4`（true） |
| `>`      | 大於               | `3 > 1`（true） |
| `>=`     | 大於或等於 | `2 >= 2`（true） |

## `if` 與 `else` 敘述

[條件式][conditional-statement]會根據條件評估為 `true` 或 `false` 來執行程式碼。
最常見的條件式是 [`if` 敘述][if]，它只在條件為 `true` 時執行一段程式區塊。
使用 `if` 關鍵字撰寫 `if` 敘述，後面接著條件，以及以大括號括住的程式區塊：

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

你可以將 `if` 搭配 `else` 子句，在條件為 `false` 時執行替代的程式碼：

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

若要依序測試多個條件，可以用 `else if` 將敘述串接起來。
`if` 敘述不需要 `else` 分支，但你可以加上一個，用來處理所有條件都不符合的情況：

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if` 運算式

在現代 Swift 中，`if` 敘述也可以當作運算式使用，產生一個值。
每個分支都會評估出一個值，讓你能輕鬆地有條件地指定結果：

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## 三元運算子

[三元條件運算子][ternary-operator]是 `if-else` 運算式的簡潔寫法。
它會評估一個條件，並根據該條件為 `true` 或 `false` 回傳兩個值其中之一。

這個運算子由三個部分組成：`condition ? trueExpression : falseExpression`。
如果 `condition` 評估為 `true`，就會評估並回傳 `trueExpression`；否則會評估並回傳 `falseExpression`。

三元運算子很適合簡單、單行的選擇：

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

上面的範例等同於以下寫法的精簡版：

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
