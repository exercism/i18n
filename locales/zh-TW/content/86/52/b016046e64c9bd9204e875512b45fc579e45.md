# 說明

你在「Booking Up For Beauty」練習中幫忙的紐約美容院經營得有聲有色，許多客戶也成了常客。
常客不再每次分別預約，而是有固定的安排：「每隔一個星期二」、「每月的最後一個星期五」等等。
老闆請你寫一個小工具，算出這些安排背後的日期，以及美容院每月例行公事的日期。

## 1. 找出常客的固定預約

實作 `SalonCalendar.standingAppointment()` 方法，它接受年、月、出現次數（`1` 代表第一次，`2` 代表第二次，依此類推）以及星期幾。
它會回傳該月內這個星期幾第幾次出現的日期：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. 找出常客每月最後一次的預約

有些常客偏好當月最後一次出現的那一天。
實作 `SalonCalendar.lastAppointment()` 方法，它接受年、月與星期幾，並回傳該月內這個星期幾最後一次出現的日期：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. 找出臨時客人的下一個可預約日

櫃檯的客人問：「下一個星期六是什麼時候？」
如果他們發問當天就是星期六，指的就是當天。
實作 `SalonCalendar.nextAvailable()` 方法，它接受一個日期與星期幾，並回傳在給定日期當天或之後、第一個落在該星期幾的日期：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. 找出結帳日

美容院在每個月的最後一天結帳。
不過週末不營業，所以當月最後一天落在星期六或星期日時，會提前在前一個星期五結帳。
實作 `SalonCalendar.bookkeepingDay()` 方法，它接受年與月，並回傳該月的結帳日：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. 把週末規則重複用在發薪日

員工在每月 15 日支薪，週末規則相同：15 日落在星期六或星期日時，發薪日就是前一個星期五。
與其把規則再寫一次，不如把它變成可以重複使用的調整器。

實作 `SalonCalendar.precedingWorkday()` 方法，它會回傳一個 `TemporalAdjuster`，讓平日維持不變，並把星期六或星期日往回移到前一個星期五。
接著用這個調整器實作 `SalonCalendar.payday()` 方法，它接受年與月：

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

也很歡迎你回頭把這個調整器用在 `bookkeepingDay()` 裡喔。
