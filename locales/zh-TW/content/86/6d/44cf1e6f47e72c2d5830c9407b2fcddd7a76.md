# 提示

## 一般

- 手邊有一份列出 Lisp 所有數值運算的清單，可能會很有幫助。
- 你可以在[這裡](http://www.lispworks.com/documentation/HyperSpec/Body/12_aa.htm)找到完整清單

## 1. 麵團比例

- Common Lisp 有個[內建常數](http://www.lispworks.com/documentation/HyperSpec/Body/v_pi.htm)可用來表示 π（圓周率）
- 說到四捨五入，CL 規格提供了[一些函式](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm)

## 2. 少許醬汁

- 有個[內建運算子](http://www.lispworks.com/documentation/HyperSpec/Body/f_sqrt_.htm)可以幫你算出數字的平方根

## 3. 來點起司吧

- 要計算數字的平方或立方，可以使用[內建的指數函式](http://www.lispworks.com/documentation/HyperSpec/Body/f_exp_e.htm)
- 你可以看看[這頁四捨五入的相關運算](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm)，並研究一下`round`的其他替代做法。

## 4. 公平分配

- 這個部分會用到一個你可能還沒見過的函式：[取模函式](https://en.wikipedia.org/wiki/Modulo_operation)（`mod`）。這個函式會給你兩個數字相除的餘數。
- 若想把`mod`的結果與另一個數字做比較，可以參考[這頁比較運算子](http://www.lispworks.com/documentation/HyperSpec/Body/f_eq_sle.htm)。
