# 簡介

Factor 裡大部分的資料都住在*序列*中。陣列、向量和字串都是序列，並共用一組來自[`sequences`][sequences]詞彙表的共通詞。

## 陣列字面值

陣列字面值使用`{ }`，元素之間以空白分隔：

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

陣列是固定長度的，所以像`suffix`和`remove-nth`這種會改變元素數量的詞，會回傳一個*新*序列，而不是把原本的序列變大。

## 長度與索引

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth`是邊界安全的版本：不需要先檢查長度，就能探測某個位置。

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## 切片

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

如果`n`大於序列長度，兩者都會拋出錯誤。如果`n`太大，`index-or-length`會把它縮小到序列的長度，這樣後續的切片就不會超出尾端：

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

帶星號的版本`head*`和`tail*`則是從尾端開始算：`head*`會丟掉最後`n`個元素，`tail*`則保留最後`n`個元素：

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

如果要取得兩個索引之間的任意切片，`subseq`會接受*起始*索引（含）和*結束*索引（不含）：

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

當你手上同時有*起始位置和長度*時，把它們相加就能得到結束位置：

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

（這就是索引範圍`[2, 5)`，也就是從位置 2 開始的三個字元。）

反過來的問題，也就是*子序列出現在哪裡*，可以由`subseq-index`回答：它會回傳第一個相符項目的起始索引，找不到時則回傳`f`：

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## 填充

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

兩者都會把`seq`加長，直到長度至少為`n`。如果`seq`已經有這麼長，就會原樣回傳。

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## 同樣的詞也能用在字串上

字串就是字元的序列，所以上面介紹的一切也都能用在字串上，只是結果會是另一個字串，而不是陣列：

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## 聚合

`sum`和`product`（位於[`sequences`][sequences]）會把數值序列的元素相加或相乘：

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count`會對序列執行述詞，並回傳有多少個元素讓它成立：

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## 針對整個序列的述詞

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## 建立新序列

`suffix`會把元素加到序列的尾端；`prefix`則把元素加到前端。`unclip`會剝掉第一個元素，`unclip-last`會剝掉最後一個：

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

把`unclip-last`和`suffix`組合起來，就能以非破壞性的方式更新最後一個元素（`unclip`加上`prefix`對第一個元素也有同樣的效果）：

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## 在序列型別之間轉換

`>array`、`>vector`和`>string`（位於[`arrays`][arrays]和對應的詞彙表）會強制把序列轉成特定的具體型別。當某個運算回傳的是切片或泛型序列，而你需要的是一個陣列（或字串）時，這就很有用。

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
