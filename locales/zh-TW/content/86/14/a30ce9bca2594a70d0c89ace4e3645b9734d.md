# 補充說明

## 提示

你需要實作`rotate`函式，它會接受一個`Int`和一個`String`，然後用旋轉密碼將它編碼。
如果對型別不太確定，可以使用提供的簽章，但別讓它限制你的創意。

這個練習處理的是文字資料。基於歷史因素，Haskell 的`String`型別等同於`[Char]`，也就是字元的陣列。若要更有效率地處理文字資料，可以使用`Text`型別。

作為這個練習的選用延伸，你可以

- 閱讀 Haskell 中關於[字串型別](https://haskell-lang.org/tutorial/string-types)的內容。
- 在 package.yaml 的相依性清單中加入`- text`。
- 用[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)匯入`Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 使用`Text`型別，例如`rotate :: Int -> Text -> Text`，並以例如`T.pack`的方式取用`Data.Text`的組合子。
- 查閱[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文件。
- 把 RotationalCipher.hs 中所有出現的`String`都換成`Text`，也就是：

```haskell
rotate :: Int -> Text -> Text
```

這個部分完全是選用的喔。
