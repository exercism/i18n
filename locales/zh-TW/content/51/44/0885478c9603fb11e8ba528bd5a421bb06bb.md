# 關於

在 Clojure 中，將值綁定到名稱稱為 [_var_][vars]。頂層（全域）var 類似於其他語言中的常數，但通常會重新定義以促進動態開發。

頂層 var 是使用[`def`][def]定義的：

```clojure
(def fingers 10)
```

你可以使用核心函式來對值進行算術運算，這些函式用於[數字運算][operators]。

`defn`巨集可以用來定義一個接受零個或多個引數的[函式][functions]。函式總是回傳其主體中最後一個運算式的結果。

```clojure
(defn add [x y]
  (+ x y))
```

呼叫函式的方式是指定其名稱，並為函式的每個參數傳入引數。

```clojure
(def five (add 2 3))
```

在 Clojure 中，函式和值只能在定義_之後_使用。在定義之前使用會導致編譯錯誤。

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

在 Clojure 中，空白除了用於排版之外沒有其他意義。

Clojure 的函式和 var 組織在命名空間中。命名空間會將相關功能分組，並使用`ns`巨集來定義：

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure 支援兩種註解。單行註解以`;`開頭，而`comment`形式用於防止評估`(comment`和`)`之間的所有內容。
