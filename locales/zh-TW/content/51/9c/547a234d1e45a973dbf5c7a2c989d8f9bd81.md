# 說明

在這個練習裡，你會動手玩一台遙控車，那是你終於存夠錢才買下的。

遙控車一開始的電量是滿的（100%）。每次你用遙控器駕駛這台車，它就會前進 20 公尺，並消耗掉百分之一的電量。

這台遙控車有個炫麗的 LED 顯示器，會顯示兩項資訊：

- 總共行駛的距離，顯示為：`"Driven <METERS> meters"`。
- 剩餘的電量，顯示為：`"Battery at <PERCENTAGE>%"`。

如果電量降到 0%，你就不能再駕駛這台車，而電量顯示器會顯示 `"Battery empty"`。

你有六個任務，每個任務都會操作遙控車的實例。

## 1. 買一台全新的遙控車

實作（*static*）`RemoteControlCar.Buy()`方法，回傳一台全新的遙控車實例：

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. 顯示行駛的距離

實作`RemoteControlCar.DistanceDisplay()`方法，回傳 LED 顯示器上顯示的距離：

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. 顯示電量百分比

實作`RemoteControlCar.BatteryDisplay()`方法，回傳 LED 顯示器上顯示的電量百分比：

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. 駕駛時更新行駛的公尺數

實作`RemoteControlCar.Drive()`方法，更新行駛的公尺數：

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. 駕駛時更新電量百分比

更新`RemoteControlCar.Drive()`方法，讓它更新電量百分比：

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. 電量耗盡時避免繼續駕駛

更新`RemoteControlCar.Drive()`方法，讓它在電量耗盡（0%）時既不增加行駛距離，也不減少電量百分比：

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
