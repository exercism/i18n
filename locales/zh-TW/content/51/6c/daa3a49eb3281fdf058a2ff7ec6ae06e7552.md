# 簡介

## Pairs

`Pair`就只是兩個項目結合在一起。
而這兩個項目則被取了個很有想像力的名字：`first`和`second`。

你可以用`=>`運算子或`Pair()`建構子來建立它們。

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Dicts

由 Pair 構成的`Vector`就像其他任何陣列一樣：有序、型別一致，而且在記憶體中連續存放。

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

`Dict`表面上很相似，但它的儲存方式能讓你用鍵快速取用資料，即使項目數量變得很大也沒問題。

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

在其他語言裡，和`Dict`很像的東西可能叫做 dictionary（Python）、Hash（Ruby）或 HashMap（Java）。

至於 Pair，無論是單獨存在或放在 Vector 裡，對每個元件的型別都沒有太多限制。

要在`Dict`裡生效，這個`Pair`必須是`key => value`配對，而且`key`必須是「可雜湊的」。
最重要的是，這表示`key`必須是_不可變的_，所以`Char`、`Int`、`String`、`Symbol`和`Tuple`都沒問題，但`Vector`不行。

### 修改 Dict

你可以用新的鍵新增項目，也可以用既有的鍵覆寫項目。

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

要移除項目，可以用`delete!()`函式，它會在鍵存在時修改 Dict，否則就默默不做任何事。

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### 檢查鍵或值是否存在

做法不只一種。
要檢查鍵是否存在，可以用`haskey()`函式：

```julia-repl
julia> haskey(pd, 'b')
true
```

或者，你也可以改為搜尋鍵或值：

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
