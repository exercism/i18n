# 關於

當你需要*修改* Factor 的序列時，會遇到兩種形式：

- **陣列**（`{ … }`）的長度固定。你可以用 `set-nth` / `change-nth` 改變每個位置*上*的內容，但無法增加或縮短它的長度。
- **向量**（`V{ … }`）的長度可變。`push` 會把元素加到末端，`pop` 則移除並回傳最後一個元素。

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| 字詞            | 作用                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`，由 `n` 個 `elt` 複製而成的陣列 |
| `<vector>`      | `( n -- vector )`，容量為 `n` 的空向量 |
| `V{ }`          | 空向量的字面值                           |
| `set-nth`       | `( elt n seq -- )`，指定索引 `n` 的元素 |
| `change-nth`    | `( i seq quot -- )`，把 `quot` 套用到索引 `i` 的元素 |
| `push`          | `( elt seq -- )`，附加到向量末端          |
| `suffix!`       | `( seq elt -- seq )`，就地附加，並回傳該向量 |
| `pop`           | `( seq -- elt )`，移除並回傳最後一個元素      |
| `pop*`          | `( seq -- )`，移除最後一個元素並捨棄            |
| `clone`         | `( obj -- copy )`，全新且獨立的副本     |
| `new-sequence`  | `( n exemplar -- newseq )`，與 `exemplar` 同類別的新序列 |
| `new-resizable` | `( n exemplar -- newseq )`，可調整大小的新變體 |

當你修改呼叫者傳入的序列時，這個變更對呼叫者是可見的，因為你們持有的是同一個物件。如果你不想這樣，請先 `clone`，取得一份獨立的副本。
