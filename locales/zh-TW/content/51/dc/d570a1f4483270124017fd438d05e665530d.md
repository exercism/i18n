# 簡介

Charlist 是使用 `~c` sigil 建立的。

```elixir
~c"hello"
```

~~~~exercism/note
請注意，在較舊版本的 Elixir 中，charlist 是以單引號寫成`'hello'`的。
~~~~

雖然 charlist 和字串看起來非常相似，但這兩種資料型態其實截然不同。charlist 是整數組成的陣列，而這些整數代表某個字元的 Unicode 值，也就是所謂的碼點。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

在字元前面加上`?`，就能取得它的碼點。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

因為 charlist 就是陣列，你可以像操作其他陣列一樣操作它們，例如使用遞迴和模式配對。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

你可以使用`++`串接兩個陣列。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

第一個陣列越長，串接的速度就越慢，所以請避免不斷地把元素附加到長度不固定的陣列上。
