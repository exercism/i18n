# 簡介

迴圈是一種重複執行一批敘述的方式。每一次執行這批敘述，就稱為一次疊代。

## `while` 迴圈

`while` 迴圈會在迴圈開頭的布林運算式為真時，執行一批敘述。當布林運算式為假時，迴圈就會停止執行，程式流程繼續往下走到迴圈後面的下一行程式碼。

如果布林運算式從一開始就求值為假，`while` 迴圈就完全不會執行，執行流程也會直接前進到迴圈後面的下一行程式碼。

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

迴圈一定要有結束的條件，這點很重要；否則就會變成無限迴圈，讓程式完全無法繼續進行。
如果把上面程式碼中`i`的`++`移除，就會變成無限迴圈。

## `do` 迴圈

`do` 迴圈會在迴圈的底部才測試布林運算式。
`do` 迴圈至少一定會執行一次，如下例所示

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

改寫成 `while` 迴圈的話，就會冗長許多

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` 迴圈

迴圈常常會更新某個變數，並在變數達到特定值時結束。
`for` 迴圈可以在同一行的小括號裡，一次完成一個或多個變數的初始化、更新與測試。
第一段用來初始化變數，第二段用來測試變數，第三段則用來更新變數的值。

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

這比等效的`while`迴圈寫法更簡潔，而且仍然很好讀。
