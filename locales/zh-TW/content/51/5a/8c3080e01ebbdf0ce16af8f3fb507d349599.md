# 簡介

`Agent`模組提供了一種抽象機制，用來啟動[行程與 _receive-send_ 迴圈][exercism-processes]。接下來，我們會把透過`Agent`模組啟動的行程稱為「代理行程」。我們可能會選擇用一個代理行程來代表集中式的共享狀態。

要啟動一個代理行程，`Agent`提供了`start/2`函式。啟動代理行程時，你提供給`start`的函式會回傳該行程的初始狀態：

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

就像`Map`或`List`一樣，`Agent`也提供了許多操作代理行程的函式。

依照慣例，我們會把所有與`Agent`相關的功能整理並封裝到一個模組裡，用來代表正在建模的領域。

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
