# 說明

在這個練習中，你會撰寫程式碼來印出工廠員工的名牌。

## 1. 印出員工的名牌

員工有 ID、姓名和部門名稱。
員工名牌標籤的格式如下：`"[id] - name - DEPARTMENT"`。
實作`printBadge()`方法，回傳員工的名牌標籤：

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
請注意，標籤上的部門名稱應該以大寫呈現。
~~~~

## 2. 印出新員工的名牌

由於電腦系統的某個小問題，新員工到工廠上班時偶爾還沒有 ID。
由於一定要佩戴名牌，他們會拿到一張沒有 ID 前綴的臨時名牌。
修改`printBadge()`方法，讓還沒有 ID 的新員工也能使用：

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. 印出老闆的名牌

即使是工廠老闆，也必須隨時佩戴名牌。
不過，老闆並沒有所屬部門。
在這種情況下，標籤應該印出`"OWNER"`，而不是部門名稱。
修改`printBadge()`方法，為老闆印出標籤：

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
請注意，老闆也可能同時是新員工：

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
