# 指令

你的任務是解開一道二進位謎題。
每一道二進位謎題都恰好只有 _一個_ 解，只要套用以下規則就能找出來：

1. 每一格都必須填入 0 或 1。
2. 相同的數字不能有兩個以上相鄰。因此，如果相鄰的兩格填入相同的數字，這兩個數字旁邊的格子就必須填入另一個數字。
3. 每一列和每一欄都必須包含數量相同的 0 和 1。
4. 每一列和每一欄都是獨一無二的。

你會拿到一道尚未完成的謎題，它是以 0 和 1 組成的列來表示，未知的值則以佔位符（`_`）代替。
你的目標是定義這道二進位謎題的規則，讓測試能自行推算出佔位符的值（這部分不用你自己來做喔）。
你的實作必須使用 Prolog 的[有限領域約束邏輯程式設計（CLP(FD)）](https://www.swi-prolog.org/man/clpfd.html)，它非常適合這類任務。

````exercism/note
為了幫你踏出第一步，起始檔案已經透過以下方式引入 [`clpfd`函式庫](https://www.swi-prolog.org/man/clpfd.html)：

```prolog
:- use_module(library(clpfd)).
```
````
