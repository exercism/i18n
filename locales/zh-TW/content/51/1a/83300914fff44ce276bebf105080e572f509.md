# match 基礎

`match`運算式可以輕鬆地把一個值與一連串模式做比對，再根據比對到的模式執行程式碼。一個模式可以由字面值、變數名稱、萬用字元，以及許多其他東西組成。

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

如果要執行多行程式碼，就要用大括號`{}`把`match`的分支包起來：

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

`match`運算式還能把符合模式的值綁定起來。這麼一來，就可以取出列舉變體的關聯值。

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

這裡把`Color`列舉的`Red`變體擴充成帶有一個關聯的列舉。透過`match`運算式，我們可以取出它的關聯值，也就是`state`。這只是個變數名稱，之後可以在該分支的程式碼裡使用。

## 比對`Option`列舉型別

內建的`Option`列舉也可以用`match`運算式來處理。

我們來設計一個函式，它接受一個`Option<u8>`參數。如果傳入的參數裡有值，就把這個值加一；否則函式應該回傳`None`值，不做任何動作。

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> 注意：`{:?}`是一種特殊的格式化語法，可以印出傳給`println!`巨集的參數的除錯形式。
> 你可以在[The Cairo Book][debugging]裡找到更多相關資訊。

使用`match`控制流程的一個好處是它具有窮盡性：每個分支的模式必須涵蓋_所有_可能的情況。看看前面例子中沒有處理`None`情況的版本：

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## 用`_`萬用字元捕捉所有情況

使用列舉時，我們也可以針對少數幾個特定的值採取特別的處理，而對其他所有的值執行同一個預設動作：只要在`match`運算式的最後一個分支加上以`_`為模式的新分支就行了。`_`模式是一種特殊的模式，它會比對任何值，但不會把值綁定起來。

`is_red`函式接受一個參數，如果顏色是`Red`就回傳`true`，其他顏色則回傳`false`：

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## 用`|`運算子做模式比對

Cairo 的`match`控制流程結構允許用`|`（_或_）運算子把一個值與多個模式做比對，這能讓程式碼更簡潔。

例如，以`Color`列舉來說，我們想寫一個函式，顏色是`Red`或`Green`時回傳`true`，其他顏色則回傳`false`：

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## 用`felt252`和整數變數做模式比對

`felt252`和整數變數可以和一組值做比對，不過有一些限制：

- 只支援能放進單一`felt252`的整數（也就是不支援`u256`）。
- 0 必須是第一個分支。
- 每個分支必須和其他分支連續相接，形成一段連續的區間。

我們來實作一個六面骰的擲骰遊戲。擲出骰子後，會得到一個 0 到 5 之間的數字。擲出 0、1 或 2 就算贏；擲出 3 可以再擲一次；其他數字則算輸：

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## 比對元組

元組也可以和一組模式做比對。這些模式的寫法和元組很像。

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

在最後一個`match`分支裡，要用`(_, _)`還是只用`_`萬用字元來比對任何日期和顏色的組合都可以，因為它們在功能上是相同的。
