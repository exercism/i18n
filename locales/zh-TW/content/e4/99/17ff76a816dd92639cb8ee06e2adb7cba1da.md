# 簡介

陣列是 Factor 的固定長度序列：你可以修改元素，但不能改變長度。你已經知道怎麼寫陣列字面值（`{ … }`），也知道如何切片與聚合。本練習會介紹一組小工具，當你從堆疊上的值建立陣列，之後要查詢或重新排列內容時，就會派上用場。

## 從堆疊建立

`1array`、`2array`、`3array` 和 `4array`（位於 [`arrays`][arrays]）會從堆疊頂端取走 1、2、3 或 4 個值，將它們打包起來：

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## 串接

`concat`（位於 [`sequences`][sequences]）接受一個序列，其元素本身也是序列，並將它們扁平化一層。`join` 做的是同樣的事，只是在每一對之間插入分隔符號：

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## 反轉

`reverse` 會回傳一個新序列，其中的元素順序相反：

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## 它是陣列嗎？

`array?`（位於 [`arrays`][arrays]）是型別述詞。對任何由 `<array>`、`1array`/`2array`/...，或陣列字面值 `{ … }` 建立的值，它都是 true；對其他所有東西（包括向量、字串和其他序列）則是 false：

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## 查詢

`index` 會回傳第一個等於輸入值的元素位置，如果不存在則回傳 `f`。`member?` 只回傳布林值。兩者都接受**元素在前**、**序列在後**。`members`（位於 [`sets`][sets]）會回傳序列中*唯一*的元素，也就是去重運算；`all-unique?`（同樣位於 `sets`）則測試序列是否已經沒有重複：

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
