# 簡介

Kotlin 是 JetBrains 開發的**靜態型別**程式語言。這代表變數的型別在編譯期就已經決定。

## 變數

與其他靜態型別程式語言類似，每個變數的型別都應該在編譯期定義。當編譯器能從上下文推斷出型別時，你可以省略明確的型別宣告。

Kotlin 有不可變（`val`）與可變（`var`）變數。不可變變數在指定初始值之後，值就無法再改變。大多數時候你都會使用這種變數。

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

可變變數的值則可以改變一次或多次：

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Kotlin 中的分號是選用的，除了少數之後才會介紹的特殊情況。

## 函式

Kotlin 的函式以`fun`關鍵字定義，而且是_一級公民_（與物件導向程式設計無關）。這代表你可以直接在檔案中宣告它們（也就是所謂的`top-level functions`），例如在 Java 中，方法只能定義在類別裡，不能定義在檔案中：

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

函式可以接收引數。每個引數都有一個名稱和一個型別。與變數不同，引數的型別無法推斷。函式可以有零個或多個引數：

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Kotlin 函式可能回傳值，也可能不回傳值：

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

若要從函式回傳值，會使用`return`關鍵字：

```kotlin
fun getName(): String {
    return "Alice"
}
```

函式可以有帶預設值的參數。當呼叫函式時省略這些參數，就會使用預設值：

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## 註解

使用`//`定義單行註解：

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

或使用`/*`和`*/`定義多行註解：

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
