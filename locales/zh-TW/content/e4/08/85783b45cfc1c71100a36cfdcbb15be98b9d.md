# 關於

自訂型別是 Gleam 中定義新資料型態的方式。一個自訂型別可以有多個_變體_，每個變體都有自己的名稱。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

自訂型別的每個情況都可以選擇性地攜帶一些資料，而不同情況可以攜帶不同型別的資料。當變體帶有資料時，就稱為_記錄_。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

要為特定情況建立值時，如果該情況不帶額外資料（`Spring`），可以直接使用它的名稱；如果帶有額外資料，則像呼叫函式一樣呼叫它（`SomeInt(2)`）。

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

自訂型別和 Gleam 裡的一切一樣，都具有_結構相等_的特性，也就是說，相同變體且資料相同的兩個值，彼此等價。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

自訂型別的變體可以用 `case` 運算式進行模式比對。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
