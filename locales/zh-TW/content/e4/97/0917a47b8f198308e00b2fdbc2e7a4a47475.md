# 關於

Haxe 有兩種數字型態，分別是整數與浮點數：

- `Int`：代表整數。
- `Float`：代表雙精度的 64 位元浮點數。

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

雖然每個 `Int` 都能用在需要 `Float` 的地方（也就是說，`Int` **可以賦值給** `Float`，或**可以與** `Float` **統一**），但反過來則不然：把 `Float` 指定給 `Int` 可能會遺失精度，因此不允許隱式進行。

## 比較

兩個數字只要有相同的值，就視為相等。

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

至於最後一個例子，請參考 [0.30000000000000004.com][0.30000000000000004.com] 的簡短說明。
