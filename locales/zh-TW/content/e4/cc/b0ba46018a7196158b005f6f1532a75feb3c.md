# 說明

在這個練習中，你會撰寫程式碼，協助一家招牌公司為他們的招牌製作客製化訊息。

## 1. 製作場合招牌

實作`buildSign(occasion, name)`函式，它接受一個字串作為`occasion`參數，以及一個存放某人名字的字串作為`name`參數。
這兩個參數會嵌入樣板字串中，用來輸出招牌上的訊息。

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. 製作生日招牌

實作`buildBirthdaySign(age)`函式，它接受一個年齡，並根據年齡決定招牌上訊息的一部分。
如果年齡是 50 或以上，招牌會稱呼使用者為 _mature_，否則會稱呼他們為 _young_。
預期的確切輸出如下：

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. 製作畢業招牌

實作`graduationFor(name, year)`函式，它接受名字作為字串參數、年份作為數字參數，並使用字串插值產生招牌上的詞句，其中以換行分隔訊息中的兩行。

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. 計算招牌的成本

實作`costOf(sign, currency)`函式，它接受一個存放招牌內容的字串，以及一個代表貨幣的字串。
招牌的基本價格是所給貨幣的 20。此外，每個字母要價 2。（空白也會計入計算。）
回傳的詞句包含製作招牌的成本，寫成小數點後兩位，後面接著貨幣字串。

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
