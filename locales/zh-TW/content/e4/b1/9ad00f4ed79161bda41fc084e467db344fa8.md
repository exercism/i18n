# 資源

## 模組

Perl 內建了一組核心模組，你可以在 [perldoc](https://perldoc.perl.org/modules) 上找到它們的清單。通常你馬上就能使用其中任何一個模組（有些發行版可能需要另行安裝核心模組）。

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) 是一份精選的實用模組清單，也指向其他一些推薦清單。

Perl 有幾種模組安裝工具，讓你能安裝 [CPAN](https://metacpan.org/) 上各式各樣的模組。

### App::cpm
非常快速又直覺的模組安裝工具。在 [CPAN](https://metacpan.org/pod/App::cpm::Tutorial) 上有教學。

如果你照著[安裝文件](https://exercism.org/tracks/perl5/installation)裡的`local::lib`說明做，就已經裝好它了。

只要執行`cpm install`，就能從`cpanfile`安裝所需的模組；加上`--with-recommends`或`--with-suggested`，則可分別安裝推薦或建議的模組。

執行`cpm install Module::Name`可以把特定模組安裝到本機，執行`cpm install -g Module::Name`則會安裝到全域。

### App::cpanminus
最知名、最常用的模組安裝工具。安裝說明可以在 [CPAN](https://metacpan.org/pod/App::cpanminus) 上找到。

執行`cpanm -L local --installdeps .`可以從`cpanfile`安裝所需的模組。執行`cpanm -L local Module::Name`可以把特定模組安裝到本機，執行`cpanm Module::Name`則會安裝到全域。

## 程式碼風格與 Lint 檢查

如果你在找 Perl 程式設計的通則，Damian Conway 的[Perl Best Practices][PBP]是很好的參考。

想美化程式碼，可以使用 [Perl::Tidy][PerlTidy] 模組。

接著就能用附帶的`perltidy`工具程式重新格式化你的程式碼。

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy`有*一大堆*組態選項，能迎合各種口味。它們的文件在[這裡][perltidyDocs]。

另外還有 [tidyview]，這是個視覺化介面，讓你調整各種選項並立刻看到結果。

如果你想強制落實程式碼規範，還有 [Perl::Critic][perlcritic]。它內建前面提過的*Perl Best Practices*一書所述的規則，不過外掛很多，也能自訂來符合任何公司內部的程式碼規範。

用法：

    $ perlcritic some_script.pl

這個工具有非常多組態調整，完整內容請看它的[文件][perlcriticdocs]。
