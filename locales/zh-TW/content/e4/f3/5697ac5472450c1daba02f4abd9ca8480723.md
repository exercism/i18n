# 簡介

當你需要一排`n`個值，而每個值都取決於它的位置時，Factor 的`<iota>`和`map`會合作完成這件事，不必自己寫一個迴圈計數器。

## `<iota>`和`map`

`<iota>`（位於 [`sequences`][sequences] 中）接受一個非負整數`n`，並回傳整數`0, 1, …, n-1`的*虛擬*序列。接著`map`會走訪它，把你的 quotation 套用到每個元素：

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

quotation 會接收一個整數，也就是索引，並把該位置的值留在堆疊上。

## 依次數疊代與重複

當你只需要走訪每個索引的*副作用*，而不是一個新的序列時，`each-integer`（位於 [`math`][math] 中）會在`0, 1, …, n-1`上執行 quotation：

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate`（位於 [`sequences`][sequences] 中）會呼叫 quotation `n` 次並收集結果、忽略索引，很適合用來建立`n`個獨立的值：

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## 有界範圍

當索引範圍不是從`0`開始，或你希望兩端都包含在內時，[`ranges`][ranges] 詞彙提供了括號表示法的字面值。方括號包含端點；圓括號則排除它。

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

幾個常見的單引數簡寫：

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>`是最常見的形式；當範圍不是從`0`開始，或需要包含上界時，`[a..b]`之類的寫法就是正確的工具。

## 開放的下界與可能為空的範圍

方括號*包含*端點；圓括號*排除*它。同樣的技巧用在左邊就得到`(a..b]`和`(a..b)`：

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]`在`n > 0`時會得到`{ 1 … n }`，在`n = 0`時得到`{ }`，這正是疊代「每個小於等於`n`的正整數」時自然的形式。

## 遞減範圍

四種括號形式，`[a..b]`、`[a..b)`、`(a..b]`、`(a..b)`，在`a > b`時都往*下*數，而不是朝空的結果前進：

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## 依位置建立字串

`map`會產生其 quotation 回傳的任何形狀。如果 quotation 在堆疊上留下一個字元碼，`>string`（位於 [`strings`][strings] 中）會把結果轉成字串：

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A`會解析成整數`65`。這裡的 quotation 把索引加倍再加上那個基數，剛好落在每隔一個的大寫字母上。你在索引上疊加的任何運算，都會決定最後出現在那個位置的字元。

## 依位置選擇

當字元取決於關於索引的*條件*時，把選擇的動作放在 quotation 裡面：

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

前三個位置把`i 3 <`測為`t`，所以得到`a`；其餘的得到`b`。同樣的形式，`[ <test> [ <yes> ] [ <no> ] if ]`，可以涵蓋用`even?` / `odd?`（位於 [`math`][math] 中）做的奇偶測試，以及用`mod`和`zero?`做的「每隔 k 個位置」測試。
