# 關於

`case` 是 Factor 中以相等性為基礎的多分支切換工具。當選擇取決於某個*單一*值是否等於幾個選項中的其中一個時，它就是合適的工具；但如果每個分支需要的是不同的條件判斷，就不適合（那種情況請改用 `cond`）。

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

有幾點值得弄清楚：

- 相等比較用的是`=`。任何能用`=`比較的東西都能當作鍵：數字、字串、字元、符號，甚至是元組。
- *配對成功*的分支看到的堆疊*不包含*輸入值；*預設*分支則會看到它還留在堆疊頂端。
- `case` 若沒有預設分支，又沒有符合的子句，就會拋出錯誤。

`case` 在可行的情況下會編譯成跳躍表，所以它不只是`if`串連的語法糖，執行速度也很快。
