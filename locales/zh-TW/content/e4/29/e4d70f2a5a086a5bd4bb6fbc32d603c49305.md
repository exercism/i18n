# 簡介

## 比較

在 JavaScript 中，你可以使用下列的關係運算子和相等運算子來比較數字。

| 比較             | 運算子  |
| ---------------------- | --------- |
| 大於           | `a > b`   |
| 大於或等於 | `a >= b`  |
| 小於              | `a < b`   |
| 小於或等於    | `a <= b`  |
| （嚴格）等於        | `a === b` |
| 不等於（嚴格）    | `a !== b` |

比較的結果永遠是布林值：`true`或`false`。

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

在 JavaScript 中，上面的比較運算子也可以用來比較字串。
這種情況下，會採用字典（詞典）順序。
你可以在[這裡][utf-16-list]找到列出所有字元確切順序的清單。

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 條件判斷

在 JavaScript 中，常見的條件執行邏輯方式是使用`if`敘述。
它由`if`關鍵字、以括號包住的條件，以及以大括號包住的程式區塊組成。
只有當條件的評估結果為`true`時，程式區塊才會執行。

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

它可以單獨使用，也可以和`else`關鍵字搭配使用。

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

若要在`else`敘述中巢狀加入另一個條件，可以使用`else if`。

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
