# `for` 迴圈

迴圈是程式設計裡的基本概念，讓你能重複執行同一段程式區塊。
在 Swift 中，迴圈有兩種：[`for-in` 迴圈][for-loops] 和 `while` 迴圈。
本章會帶你認識 `for-in` 迴圈。

`for` 迴圈讓你逐一疊代一串值，每次取出一個元素，並將它綁定到你自己取名的變數。
Swift 讓你疊代各種不同的序列，例如範圍、陣列和字串（還有更多型別會在後面介紹）。
當序列中的每個元素都疊代過之後，迴圈就會結束。

`for` 迴圈是用 `for` 關鍵字宣告的，後面接著一個變數名稱、`in` 關鍵字，以及要疊代的序列。
`for-in` 迴圈裡指定的變數是不可變的，也就是說你沒辦法在迴圈內改變它的值。
以下是一個 `for-in` 迴圈疊代數字陣列的範例：

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` 變數是在 `for-in` 迴圈裡宣告的，只有在該迴圈的作用域內才能使用。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 疊代範圍

你也可以用 `for-in` 迴圈疊代一段數字範圍。
這讓你能把一段程式區塊執行指定的次數，例如範圍 `1...5` 會疊代數字 1、2、3、4、5，所以迴圈會執行 5 次。
有時候你會想疊代陣列這類資料結構的索引，這時可以使用 `0..<array.count` 範圍。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 疊代字串

你也可以用 `for-in` 迴圈疊代一個字串。
這讓你能逐一疊代字串中的每個字元，特別注意迴圈裡取出的型別是 `Character`。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift 也提供了 `stride` 函式，讓你能建立一個以指定間距跨過某段範圍的序列。
接著就能用 `for-in` 迴圈疊代它。
`stride` 有兩種定義：[`stride(from:to:by:)`][stride-to] 和 [`stride(from:through:by:)`][stride-through]，前者不包含結束值，後者包含結束值。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

注意 `to` 參數不包含結束值，所以迴圈會疊代到 `to` 參數之前的那個數字為止；而 `through` 參數則包含結束值，所以在這個例子中也會包含 `10`。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
