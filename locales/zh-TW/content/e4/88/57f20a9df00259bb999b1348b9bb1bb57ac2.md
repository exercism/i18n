# 介紹

在 Python 中，[元組][tuple] 是一種_不可變_、依_序列_排列的項目集合。
和大多數集合一樣，`tuples`可以存放任何（或多種）資料型態，包括其他的`tuples`。
元組支援所有[常見序列操作][common sequence operations]，但**不**支援[可變序列操作][mutable sequence operations]。

可以使用`for item in <tuple>`語法疊代元組中的元素。
如果同時需要元素的索引和值，可以使用`for index, item in enumerate(<tuple>)`。
和任何序列一樣，可以使用_方括號標記法_存取`tuples`內的元素，索引從左邊算起是`0-based index`，從右邊算起則是`-1-based index`。
也可以使用切片標記法（_`<tuple>[<start>:<stop>:<step>]`_）複製整個元組或其中的一部分。


## 元組的建立

元組可以用多種方式建立，可以使用`tuple(<iterable>)`類別建構子，也可以使用`tuple`字面值宣告。

### 使用空的`tuple()`建構子，或搭配_可迭代物件_使用：

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

字串是可迭代的，所以把單一個`str`當成引數傳給`tuple()`建構子，可能會出現令人意外的結果：

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

單一可迭代物件的元素會一個一個被加入：

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### 將元組宣告為_字面值_：

由於`tuple(<iterable>)`建構子只接受_可迭代物件_（或什麼都不接受）當作引數，所以用字面值的方式建立只有一個元素的元組要容易得多。

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

巢狀資料結構可以作為`tuple`元素，包括其他的`tuples`：

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## 元組的串接

元組可以使用加號`+`運算子串接，運算子會展開每個`tuple`，建立一個新的、合併後的`tuple`。

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## 存取元組內的元素

可以使用_方括號標記法_存取`tuple`內的元素，索引從左邊算起是`0-based index`，從右邊算起則是`-1-based index`。

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## 疊代元組的元素

可以使用`for item in <tuple>`語法，在迴圈中_疊代_`tuple`內的元素。
如果同時需要索引和值，可以使用`for index, item in enumerate(<tuple>)`。

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## 檢查元素是否在元組中

可以使用`in`運算子檢查某個元素是否在`tuple`中。

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
