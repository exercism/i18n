本練習的目標是改良密碼檢查器練習。

由於同一個密碼可能同時違反多條規則，一個好用的密碼檢查器應該把所有違反的規則都告訴使用者，而不是只回報最先發現的那一條。改良後的密碼檢查器應該一次指出某個密碼違反的所有規則。

這個密碼檢查器的規則和先前的密碼檢查器練習相同：

- 長度必須至少 12 個字元
- 必須至少包含一個大寫字母
- 必須至少包含一個小寫字母
- 必須至少包含一個數字
- 必須至少包含一個符號，而且該符號要落在`!@#$%^&\*`這個集合內

## 1. 修改`PasswordError`差別聯集，讓個別的值可以被當作旗標看待

請注意，在完成這個關鍵步驟之前，測試都無法編譯。

## 2. 實作`checkPassword`函式

`checkPassword`函式會依據上述規則檢查傳入的密碼。這個函式應該回傳`Result`值：當密碼符合所有規則時回傳`Ok`，當密碼違反一條以上的規則時回傳`Error`。如果傳入的密碼違反多條規則，`PasswordError`值應該代表所有違反的規則。

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. 實作 ``getStatusPhrases` 函式

`getStatusPhrases`函式會回傳一組字串，每個字串各包含一句人類可讀的短語，分別對應`checkPassword`回傳結果中的其中一個錯誤。

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
