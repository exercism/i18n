# 簡介

Lua 的布林型別有兩個傳統的布林值：`true`和`false`。這些值可以指定給變數，也能用邏輯運算子（`and`、`or`、`not`）組合，並用在條件判斷中（例如控制結構）。

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

條件判斷和邏輯運算子會把布林值 `false`和`nil`都視為假，其他任何值則視為真。
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and`和`or`都採用*短路求值*，也就是只在必要時才會計算第二個運算元。所有運算都依[運算子優先順序](https://www.lua.org/manual/5.4/manual.html#3.4.8)來求值，其中`not`會比`and`和`or`先求值。
