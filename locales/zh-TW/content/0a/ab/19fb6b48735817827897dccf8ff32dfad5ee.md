# 提示

## 一般

- 你可以用`*T`來宣告指向某個型別`T`的指標變數，例如`var i *int`會宣告一個指向`int`的指標變數`i`
- 你可以用`&`運算子取得指向某個變數的指標（也就是它的記憶體位址），例如`mypointer := &anIntVariable`。
- 你可以對指標使用`*`運算子，取得存在指標裡的值，例如`var i int = *aPointerToInt`。
  這個動作稱為對指標解參考。
- 在解參考指標之前，請先確認它不是`nil`。
  試圖解參考`nil`指標會導致執行階段錯誤。
- 如果你不確定指標是怎麼運作的，可以讀讀[Tour of Go: Pointers][go-tour-pointers]或[Go by Example: Pointers][go-by-example-pointers]

## 1. 建立投票計數器

- 你需要建立一個指向`int`的指標，也就是`*int`。
- 你可以對變數使用`&`運算子，建立指向它的指標，例如`&myInt`
- 你可以建立一個指向自己定義的新變數的指標，也可以直接使用函式引數的變數

## 2. 從計數器取得票數

- 你可以對指標使用`*`運算子來解參考，並取得它的值，例如`*myPointer`
- 解參考`nil`指標會導致執行階段錯誤。
  解參考之前，務必先確認指標不是`nil`。

## 3. 增加計數器的票數

- 如果你有一個指標`var myPointer *int`，可以對`*myPointer`指定值，來改變`myPointer`所指到的值
- 要取得指標目前的值，你需要用`*`運算子解參考它，或是呼叫你在上一個任務建立的函式。

## 4. 建立選舉結果

- 建立一個新的`ElectionResult`字面值或變數，並用函式引數中的值填入`Name`和`Votes`欄位。
- 你可以在變數名稱或字面值前面加上`&`運算子，從變數或字面值建立指標，例如`&myVariable`或`&ElectionResult{Name: "John", Votes: 1}`

## 5. 公布選舉結果

- 雖然你收到的是指向`ElectionResult`的指標，但你仍然可以用點號`.`存取它的欄位，就好像它不是指標一樣！
- 透過存取結構上的`Name`和`Value`欄位來組出訊息。
- 即使你是從指向結構的指標存取欄位，也不需要做任何解參考。
  Go 會自動幫你解參考指標，就像下面這個例子：

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. 重新計票

- 你可以把 map 想成它本身就是指標。
  這表示你在函式內對 map 所做的變更，在函式外也看得見。
- 要增加`var m map[string]int`中某個鍵的值，你有幾種做法：`m["mykey"] = m["mykey"] + 1`、`m["mykey"] += 1`或`m["mykey"]++`。
