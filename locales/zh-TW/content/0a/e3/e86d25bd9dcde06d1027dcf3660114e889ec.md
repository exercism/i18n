# 指示

在這道練習中，你將為朋友正在開發的一款新 RPG 遊戲實作任務邏輯。遊戲的主角是 Annalyn，一個勇敢的女孩，身邊帶著一隻凶猛又忠誠的寵物狗。不幸的是，災難降臨了：她最好的朋友在森林裡尋找莓果時被綁架了。Annalyn 會試著找到並救出她最好的朋友，這趟任務中她可以選擇是否帶著她的狗同行。

循著好朋友的蹤跡走了一段時間後，她找到了囚禁她好朋友的營地。原來綁匪有兩個人：一名强大的騎士和一名狡猾的弓箭手。

找到綁匪之後，Annalyn 思考自己能採取下列哪些行動：

- 快速攻擊：如果騎士正在睡覺，就能發動快速攻擊，因為他需要時間穿上盔甲，所以會處於脆弱狀態。
- 刺探：只要這群人裡至少有一個是清醒的，就能對他們進行刺探。否則刺探只是浪費時間。
- 對囚犯打暗號：如果囚犯是清醒的，而弓箭手正在睡覺，就能用鳥叫聲向囚犯打暗號，因為弓箭手受過鳥叫暗號的訓練，可能會攔截訊息。
- _釋放囚犯_：Annalyn 可以試著潛入營地釋放囚犯。
  這件事風險很高，只有兩種方式可能成功：
  - 如果 Annalyn 帶著她的寵物狗，那麼只要弓箭手在睡覺，她就能救出囚犯。
    騎士怕狗，而弓箭手來不及準備，Annalyn 和囚犯就能趁機逃走。
  - 如果 Annalyn 沒帶狗，那她和囚犯就得非常小心翼翼！
    只要囚犯是清醒的，而且騎士和弓箭手都在睡覺，Annalyn 就能釋放囚犯；但如果囚犯在睡覺，就救不了他：囚犯會被 Annalyn 突然出現嚇到，進而吵醒騎士和弓箭手。

你有四項任務：根據森林裡這三個角色的狀態，以及 Annalyn 的寵物狗是否在場，實作判斷上述行動是否可行的邏輯。

## 1. 檢查「快速攻擊」行動是否可行

實作一個名為`canExecuteFastAttack`的函式，它接受一個布林值，表示騎士是否清醒。這個函式會根據角色的狀態，在「快速攻擊」行動可行時回傳`true`，否則回傳`false`：

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. 檢查「刺探」行動是否可行

實作一個名為`canSpy`的函式，它接受三個布林值，分別表示騎士、弓箭手和囚犯是否清醒。這個函式會根據角色的狀態，在「刺探」行動可行時回傳`true`，否則回傳`false`：

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. 檢查「對囚犯打暗號」行動是否可行

實作一個名為`canSignalPrisoner`的函式，它接受兩個布林值，分別表示弓箭手和囚犯是否清醒。這個函式會根據角色的狀態，在「對囚犯打暗號」行動可行時回傳`true`，否則回傳`false`：

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. 檢查「釋放囚犯」行動是否可行

實作一個名為`canFreePrisoner`的函式，它接受四個布林值。前三個參數分別表示騎士、弓箭手和囚犯是否清醒，最後一個參數表示 Annalyn 的寵物狗是否在場。這個函式會根據角色的狀態以及 Annalyn 的寵物狗是否在場，在「釋放囚犯」行動可行時回傳`true`，否則回傳`false`：

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
