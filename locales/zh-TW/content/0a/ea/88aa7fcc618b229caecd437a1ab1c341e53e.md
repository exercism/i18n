# 操作說明

你在小型家具工坊裡當學徒。師傅的平板電腦跑的是 Factor，負責記錄裁切清單。每塊放上工作檯的木板，都會在下第一刀之前先量出幾個衍生數值。

前一位學徒把收銀機的程式碼留下一團亂，滿是`dup`、`over`、`swap`和`rot`。你的任務是用*組合子*改寫五個小詞。

每塊木板進入工作流時，堆疊上只有它的原始長度（公分）。

## 1. 加上鋸路預留量

鋸片每次切割都會從木頭上削去一條細細的木料，這就是*鋸路*。工坊會為每塊木板多留 2% 的長度來吸收這道損耗。

定義`with-kerf`，讓它接收一個長度，回傳該長度加上 2% 的鋸路預留量。

```factor
100 with-kerf .
! => 102
```

## 2. 計算鋸路與修整預留量

切割之後接著是修整，也就是打磨與刨平，這道工序會再削去原始長度的 5%。

定義`kerf-and-finish`，讓它把*兩種*預留量並排回傳（鋸路在下，修整在上）。

```factor
100 kerf-and-finish .s
! => 2
! => 5
```

## 3. 製作切割卡

師傅每切一塊木板，都會在木板上貼一張小卡片，上面列出原始長度、鋸路預留量和修整預留量，也就是三個數字，依這個順序排列。

定義`cut-card`，讓它回傳這三個數字。

```factor
100 cut-card .s
! => 100
! => 2
! => 5
```

## 4. 每段長度

工坊也會收到整捆的*木材*，需要均分成等長的小段。鋸路預留量只加在木材的長度上一次，接著把結果除以段數。

定義`per-piece`，讓它接收木材的長度和段數（段數會放在堆疊最上層），然後回傳每段的長度。

```factor
100 2 per-piece .
! => 51

100 4 per-piece .
! => 25+1/2
```

## 5. 比較兩捆木材

有時師傅在木材行要從兩捆木材中挑一捆，想一眼就比較出兩者的鋸路預留量。

定義`compare-bolts`，讓它從堆疊取出兩個長度，並回傳各自的鋸路預留量（順序相同）。

```factor
50 100 compare-bolts .s
! => 1
! => 2
```
