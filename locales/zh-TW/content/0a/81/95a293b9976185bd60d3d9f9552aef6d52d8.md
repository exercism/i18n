# 說明

郊區板球場的場地管理員想找人幫忙算些數字：邊界需要多少繩子、一記擊球飛了多遠又飛向何方，以及球在野手追到之前會滾多遠。

所有距離都以公尺計，所有速度都以公尺每秒計。球場上的位置從球場中央量起：`x`是沿著球場正前方的公尺數，`y`是橫越球場的公尺數，左側為正、右側為負。

## 1. 邊界用的繩子

邊界是繞著球場中央的一個圓。定義`boundary-length`，接收半徑並回傳所需的繩長，也就是 2 × π × 半徑。

```factor
70.0 boundary-length .
! => 439.822971502571
```

## 2. 離球場中央多遠？

定義`distance-from-pitch`，接收野手的`x`和`y`，回傳他們站的位置離球場中央多遠：x² + y² 的平方根。

```factor
30.0 40.0 distance-from-pitch .
! => 50.0
```

## 3. 球往哪個方向飛？

定義`shot-angle`，接收擊球落點的`x`和`y`，回傳它的方向，單位是**度**：0 是沿著球場正前方，90 是左側正橫向，-90 是右側正橫向，180 則是往後直直飛過捕手。

```factor
50.0 50.0 shot-angle .
! => 45.0
```

## 4. 球飛了多遠？

以`speed`擊出、並以`angle`**度**仰角上升的球，在第一次落地前會飛 speed² × sin(2 × angle) ÷ 9.8 公尺。定義`carry`，接收速度和角度，回傳這段距離。

```factor
30.0 45.0 carry .
! => 91.83673469387755
```

## 5. 在草地上減速

球沿著外野滾動時會損失速度：滾了`metres`之後，速度變成 speed × e^(−0.02 × metres)。定義`speed-after`，接收起始速度和滾過的公尺數，回傳剩下來的速度。

```factor
30.0 50.0 speed-after .
! => 11.03638323514327
```

## 6. 滾到哪裡就不值得追了？

把第 5 題反過來想。定義`metres-until`，接收球開始滾動時的速度和較慢的`target`速度，回傳它在降到目標速度之前滾了多少公尺：ln(speed ÷ target) ÷ 0.02。

```factor
30.0 15.0 metres-until .
! => 34.657359027997266
```
