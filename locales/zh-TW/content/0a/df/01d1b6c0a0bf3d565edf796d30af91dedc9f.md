# 指令

你正在另一個團隊所提供的資料庫上，實作一套 ORM（物件關聯對映）系統。

這個資料庫一次只能處理一個交易。

在這個階段，不需要記錄日誌或其他錯誤處理。

注意，在內部，資料庫會經歷多個狀態：Closed、TransactionStarted、DataWritten、Invalid、Closed。你可以放心，每個練習開始時資料庫都處於`Closed`狀態。

這個資料庫有以下幾個實例方法：

- `Database.BeginTransaction()`會在資料庫上開始一個交易。如果在資料庫不是`Closed`狀態時呼叫，就會擲回例外。如果成功，資料庫的內部狀態會變成`TransactionStarted`。
- `Database.Write(string data)`會在交易內將資料寫入資料庫。如果收到錯誤的資料，就會擲回例外。如果在尚未呼叫`BeginTransaction()`的情況下嘗試呼叫這個方法，也會造成例外擲回。如果成功，資料庫的內部狀態會變成`DataWritten`。
- `Database.EndTransaction()`會將交易提交到資料庫。如果無法結束交易，或是之前沒有呼叫`Database.BeginTransaction()`，就可能擲回例外。
- 呼叫`Database.Dispose()`會在交易期間擲回例外時清理資料庫。這會將資料庫的狀態變成`Closed`。

可以使用`database.DbState`存取資料庫的狀態。

資料庫的狀態可以設為下列其中一種：

- TransactionStarted
- DataWritten
- Invalid
- Closed

## 1. 開始一個交易

實作`Orm.Begin()`來在資料庫上開始一個交易。如果資料庫一開始的內部狀態不是`State.Closed`，就會擲回`InvalidOperationException`。

```csharp
var orm = new Orm(new Database());
orm.Begin();
// => database has an internal state of State.TransactionStarted
```

## 2. 將一些資料寫入資料庫

實作`Orm.Write()`來將一些資料寫入資料庫。如果資料庫一開始的內部狀態不是`State.TransactionStarted`，或是寫入了錯誤的資料，就會擲回`InvalidOperationException`。如果寫入失敗，`Orm`必須清理資料庫。

```csharp
var orm = new Orm(new Database());
orm.Begin();
orm.Write("some data");
// => database has an internal state of State.DataWritten
orm.Write("bad write");
// => database has an internal state of State.Closed
```

## 3. 將先前寫入的資料提交到資料庫

實作`Orm.Commit()`來提交資料。如果提交失敗，就清理資料庫。如果資料庫一開始的內部狀態不是`State.DataWritten`，就會擲回`InvalidOperationException`。

```csharp
var orm = new Orm(new Database());
orm.Begin();
orm.Write("some data");
orm.Commit();
// => database has an internal state of State.Closed
orm.Begin();
orm.Write("bad commit");
orm.Commit();
// => database has an internal state of State.Closed
```

## 4. 確保 ORM 在交易進行到一半就必須結束時，資料庫能被正確地清理。

在`Orm`類別上實作`IDisposable`介面。這個呼叫保證會成功。

```csharp
var db = new Database();
var orm = new Orm(db);
orm.Begin();
orm.Write("some data");
orm.Dispose();
// => database has an internal state of State.Closed
```
