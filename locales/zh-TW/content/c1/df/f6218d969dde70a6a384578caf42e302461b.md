# 說明

在這個練習中，你會處理日誌行。

每一行日誌都是格式如下的字串：`"[<LVL>]: <MESSAGE>"`。

以下是不同的日誌等級：

- `TRC`（追蹤）
- `DBG`（除錯）
- `INF`（資訊）
- `WRN`（警告）
- `ERR`（錯誤）
- `FTL`（致命）

你有 3 個任務。

## 1. 解析日誌等級

定義一個`LogLevel`列舉，其中包含 6 個元素，分別對應上述的日誌等級。

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

接著，實作`LogLine.getLogLevel()`方法，回傳一行日誌解析後的日誌等級：

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. 支援未知的日誌等級

可惜的是，偶爾某些日誌行會有未知的日誌等級。
為了優雅地處理這些日誌行，請在`LogLevel`列舉中加入一個`UNKNOWN`元素，在解析到未知的日誌等級時應該回傳它：

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. 將日誌行轉換成簡短格式

日誌行的日誌等級相當冗長。
為了減少儲存日誌行所需的磁碟空間，我們發展出一種簡短格式：`"[<ENCODED_LEVEL>]:<MESSAGE>"`。

編碼後的日誌等級，就是將日誌等級簡單對應到一個數字：

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

實作`LogLine.getOutputForShortLog()`方法，用來輸出縮短後的日誌行格式：

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
