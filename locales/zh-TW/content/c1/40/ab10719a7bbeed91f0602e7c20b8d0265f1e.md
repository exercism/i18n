# 簡介

## 模式比對

可以使用`if/elif/else`運算式來有條件地執行邏輯。F# 還提供了另一種更強大的方式，可以有條件地執行邏輯：模式比對。使用模式比對時，可以將一個值與一或多個_模式_進行比對。這類模式的一個例子是_常數模式_，它會將值與常數（例如`1`或`"hello"`）進行比對。

在 F# 中，模式比對是透過`match`關鍵字來完成：

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

雖然這看起來像其他語言中的`switch`敘述，但當同時使用其他模式時，模式比對才開始展現威力。其中一種模式是_變數模式_，它讓你可以擷取一個值：

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

在某些情況下，你可能會想為模式加上額外的條件。這稱為_防護子句_，可以使用`when`關鍵字來加入：

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

在上述例子中，並非所有可能的輸入都會有符合的模式。編譯器會偵測到這點並輸出警告。這稱為_窮盡檢查_。為了解決這個警告，你必須處理所有情況。為此，可以使用_萬用字元模式_，它是一種能比對任何值的模式：

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

模式比對會由上而下將值與每個模式進行比對，直到找到符合的模式，並執行與該模式相關的邏輯。模式的順序很重要！
