# 簡介

差別聯合型別代表固定數量的具名案例。差別聯合的每個值都恰好對應其中一個具名案例。

差別聯合使用`type`關鍵字定義，案例之間以管線字元（`|`）分隔：

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

差別聯合的每個案例都可以選擇性地附帶資料，而且不同的案例可以有不同的資料型態。如果沒有任何案例附帶資料，這個差別聯合就類似於其他語言通常所稱的_列舉_（或 _enum_）。

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

要建立特定案例的值，只要指出它的名稱即可（例如`Success`）。由於案例名稱本身就是建構函式，附帶的資料可以像一般的函式引數一樣傳入。如果另一個差別聯合已經定義了同名的案例，你就需要使用它的完整名稱（例如`Result.Success`）。

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

差別聯合具有_結構相等性_，意思是同一個案例、且帶有相同（選用）資料的兩個值會是等值的。

雖然可以使用`if/elif/else`運算式來處理差別聯合，但建議的處理方式是透過模式比對，使用_識別碼模式_：

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
