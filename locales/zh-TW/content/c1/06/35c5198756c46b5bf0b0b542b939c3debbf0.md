# 說明補充

## 排序套件

這個練習要求你排序一個陣列，但標準函式庫並沒有內建這項功能。你可以自己寫一套排序函式庫，但更好的選擇是使用 [sorts 套件](https://github.com/diku-dk/sorts)。

只要在解答目錄中執行下列指令，就能在你的解答裡使用這個套件：

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

接著，用下列語法匯入你需要的[排序演算法](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts)：

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
