# 簡介

在 Common Lisp 中，時間有四種表示方式，這裡會談到其中兩種。

- 通用時間是一種絕對時間，是一個整數，代表自`1900-01-01T00:00:00Z`起經過的秒數（也就是 1900 年 1 月 1 日 UTC 的午夜）。
- 解碼時間是由 9 個值組成的元組，這些值共同代表某個特定的日曆時間：秒、分、時、日、月、年、星期、日光節約時間旗標、時區。
（詳細討論見下文。）

## 通用時間

想取得目前的通用時間，可以使用`get-universal-time`或`get-decoded-time`。
前者回傳自`1900-01-01T00:00Z`起算的目前秒數，後者則以解碼格式回傳同樣的資料。

## 解碼時間

`decode-universal-time`與`encode-universal-time`是處理時間的主要函式。
前者接受一個通用時間，並以[multiple-values][concept-multiple-values]的形式回傳一個解碼時間值；後者接受各個解碼時間值作為引數，回傳一個通用時間。

兩者都接受一個選用的時區引數。
時區的格式請見下文。

解碼時間是一組值：

- *秒*：介於 0 與 59 之間的整數
- *分*：介於 0 與 59 之間的整數
- *時*：介於 0 與 23 之間的整數
- *日*：介於 1 與 31 之間的整數（上限當然取決於月份與年份）
- *月*：介於 1 與 12 之間的整數
- *年*：代表年份的整數。
- *星期*：介於 0 與 6 之間的整數。0 代表星期一，1 代表星期二，依此類推……6 代表星期日。
- *日光節約時間旗標*：值為 true 時表示日光節約時間正在生效。
- *時區*：介於 -24 與 24 之間、代表與 UTC 時差的時數。
這個數字是有理數，且必須是`1/3600`的倍數

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
