# 關於

## 函式型別

我們之前看過函式簽章是如何定義的：先是一個函式名稱，接著是以逗號分隔的參數標籤清單及其型別，然後是 `->`，以及該函式回傳值的型別。

如果把這個簽章中的所有名稱和標籤都移除，剩下的就是[函式的型別][function-types]。

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

請注意，前兩個函式的型別相同，都是 `(String, Int) -> String`，儘管它們的運作方式大不相同。兩者都接受一個 `String` 和一個 `Int` 作為輸入，並回傳一個 `String`。而從第三個函式的型別可以看出，雖然這個函式看起來沒有回傳任何東西，它實際上回傳了 `()`，也就是型別 `Void` 唯一的值。注意 `()` 和 `Void` 作為型別名稱是可以互換的，所以 `printString` 的型別也可以寫成 `String) -> Void`。

這些型別可以像 Swift 中任何其他型別一樣使用，例如，可以用在變數或常數的宣告中。而且因為在 Swift 中函式就是值，所以既有的函式可以指定給這些常數或變數：

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

和其他變數或常數一樣，你指定給它的值必須是正確的型別：

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## 作為參數型別的函式型別

因為函式型別可以用在任何其他型別可以使用的地方，所以[它們也可以作為參數型別][functions-as-parameters]，傳入其他函式，並在那些函式中被呼叫。

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## 作為回傳型別的函式型別

同樣地，[函式型別也可以作為函式的回傳型別][functions-as-returns]。換句話說，你可以撰寫會建立並回傳其他函式的函式。在建立這些函式時，被回傳的函式可以使用傳入該函式的其他參數，或是父函式內建立的區域變數。

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## 捕獲值

如同上面 `makeAdder(base:)` 函式所示，巢狀函式可以存取外層函式的參數和變數。此外，在外層函式結束之後，它們仍然能保有對這些值的存取。這種取得並保有存取權的動作稱為[_捕獲_][capturing-values]。

## 高階函式

接受函式作為參數，或是回傳函式的函式，稱為高階函式。Swift 在它的各個函式庫中有許多高階函式。例如，Swift 集合（例如 `Array`）上可用的 `sorted(by:)` 方法：對於元素型別為 `T` 的陣列，它接受一個型別為 `(T, T) -> Bool` 的函式，這個函式會決定在排序後的陣列中兩個值哪個應該排在前面，如果左邊的值應該排在前面就回傳 `true`，如果右邊的值應該排在前面就回傳 `false`。

另一個例子是集合上的 `contains(where:)` 方法：對於元素型別為 `T` 的集合，它接受一個型別為 `(T) -> Bool` 的函式，如果元素符合某個性質就回傳 `true`，否則回傳 `false`。接著，如果集合中有某個元素符合這個性質，`contains(where:)` 就會回傳 `true`。

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
