# 指令補充

## 輸入格式

每個輸入清單都以 null 結尾的字串表示，而每個輸入的結尾都有一個換行字元。

例如：`"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## 暫存器

| 暫存器   | 用途         | 型別    | 說明                                                           |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | 輸入         | 位址    | 以 null 結尾的輸入字串，每個輸入後面都有一個換行               |
| `$a1`    | 輸入/輸出    | 位址    | 以 null 結尾的輸出字串                                         |
| `$t0-9`  | 暫時         | 任意    | 用於暫時存放資料                                               |
