# 簡介

連結性描述的是程式碼中可從何處存取某個識別字。
具有區塊、函式或函式原型作用域的值沒有連結性。
這表示無法從它們的作用域之外存取它們。
若想進一步了解作用域，請參閱[作用域概念](../scope/introduction.md#Introduction)。

## 外部連結性

具有檔案作用域的識別字預設為外部連結性。
具有外部連結性的識別字可以從程式中的任何檔案呼叫。

## 內部連結性

只要使用`static`修飾詞，就能讓具有檔案作用域的識別字擁有內部連結性。
具有內部連結性的識別字只能在所屬的檔案內使用。

例如

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

靜態連結性不應與靜態儲存期混淆。
若想進一步了解靜態儲存期，請參閱[儲存期概念](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type)。
