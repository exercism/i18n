# 說明

Lisp 外星人莉莉熱愛烹飪。她想和朋友們辦一場披薩派對，但為了充分利用食材，她希望在開始之前就精確知道每種食材需要多少。

為了解決這個問題，莉莉已經草擬了一個程式來自動處理部分規劃，但需要你幫忙完成。
你願意幫莉莉辦一場比例完美的披薩派對嗎？

## 1. 麵團比例

首先，每一塊美味的披薩都從好吃的麵團開始！

莉莉喜歡薄脆、餅皮較厚的披薩。
中間部分固定需要 200 克的麵團，而每 20 公分的餅皮則需要 45 克麵團。

幸好，莉莉已經推導出從披薩數量（n）和直徑（d）計算麵團克數（g）的公式：

`g = n * (((45 * pi * d) / 20) + 200)`

莉莉需要一個函式，它能：
* 接受披薩數量（n）和直徑（d）
* 並回傳所需的麵團克數（g），取最接近的公克。

例如，要做 4 個直徑 30 公分的披薩：

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. 加點醬料

莉莉塗抹醬料時非常講究，但她做的披薩大小並不總是固定。

為了算出直徑（d），她使用以下公式，其中已塗抹的醬料量（s）是變數：

`d = square-root of ((40 * s) / (3 * pi))`

莉莉需要一個函式，能從每毫升已塗抹的醬料（s）計算出披薩直徑（d）。

例如，假設莉莉用了 250 毫升的醬料：

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. 來點起司吧

在莉莉的星球上，所有起司都是完美的立方體，並依大小販售。
（不然你以為呢？這可是外星星球⋯）

莉莉再次推導出公式，用邊長（l）的起司立方體，算出能做出多少個直徑（d）的披薩（n）：

`n = (2 * (l^3)) / (3* pi * (d^2))`

建立一個函式，它能：
* 接受起司立方體的邊長（l）和披薩的直徑（d），
* 並回傳能做出的披薩數量（n），採無條件捨去。

例如，給定一個 25x25x25 公分的起司立方體，以及直徑 30 公分的披薩：

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. 公平分配

最後，莉莉希望每塊披薩都能切成 8 片，並平均分配給她的朋友們。

建立一個函式，它能：
* 接受披薩數量和朋友數量
* 並在披薩能平均分配給朋友時回傳 `T`，否則回傳 `NIL`。

例如：

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
