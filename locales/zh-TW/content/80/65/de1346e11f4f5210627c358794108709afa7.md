# 簡介

Go 有個內建套件叫 `fmt`（格式套件），提供各式各樣的函式來調整輸入與輸出的格式。
最常用的函式是 `Sprintf`，它會用像 `%s`這樣的_動詞_把值插入字串裡，然後回傳那個字串。

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

在 Go 裡，浮點數可以用 Sprintf 的動詞漂亮地格式化：`%g`（精簡表示法）、`%e`（指數）或 `%f`（非指數）。
這三種動詞都能控制欄位的寬度與數值位置。

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

所有可用動詞的完整清單可以在[格式套件說明文件][fmt-docs]裡找到。

`fmt`還包含其他處理字串的函式，例如 `Println`會直接把收到的引數印到主控台，而 `Printf`則會先用和 `Sprintf`相同的方式格式化輸入，再把它印出來。

[fmt-docs]: https://pkg.go.dev/fmt
