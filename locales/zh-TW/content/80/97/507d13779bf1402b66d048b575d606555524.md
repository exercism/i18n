# 提示

為了幫助你建立概念：這個練習使用複數來表示格線上的交叉點。複數可以想成由兩個數字組成的數對，因此也可以重新想像成二維的 x-y 平面，其中 x 軸代表實軸，y 軸代表虛軸。

## 1. 簡單的複數

- 這是一個簡單的包裝函式。
- 關於如何使用變數建立複數，請參閱「簡介」。
- 請注意，如果你沒有使用關鍵字引數，`complex()`的位置引數可能和你想的不一樣。

## 2. 取得駕駛方向

- 這個函式只需要一個數學運算。
- 運算的順序很重要（也就是說，它不對稱）。

## 3. 取得曼哈頓距離

- 記住，這是計程車沿著格線行進時經過的交叉點總數（不含起點交叉點）。
- 你的`driver_directions`函式可能會有幫助。
- 其他可能有幫助的函式是 [`Re()`和`Im()`][complex-ref]。

## 4. 取得「直線距離」

- 這是兩個交叉點之間的直線距離。
- 你可以把它想成是轉一個彎的曼哈頓距離路徑所形成的斜邊。
- 這也稱為[歐幾里得距離][euclid-ref]，或 L2 範數。
- 你的`driver_directions`函式可能會有幫助。
- 關於另一個可以用來求出大小的複數函式，請參閱「簡介」。

## 5. 取得烏鴉方向

- 你的`driver_directions`函式可能會有幫助。
- 這個函式會把駕駛方向的南北向對調。
- 這會把感知到的位置沿著「x 軸」翻轉。
- 關於另一個可以選用的函式，請參閱「簡介」。

[complex-ref]: https://www.rdocumentation.org/packages/base/versions/3.5.3/topics/complex
[euclid-ref]: https://en.wikipedia.org/wiki/Euclidean_distance
