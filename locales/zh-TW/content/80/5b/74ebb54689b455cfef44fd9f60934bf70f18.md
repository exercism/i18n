# 字元

`CHAR`是一個字元，寫在單引號之間。

```sather
   c : CHAR := 'M';
```

## 特殊字元

有些字元無法直接輸入，要用反斜線來寫：

| 寫法 | 意思 |
| --- | --- |
| `'\n'` | 換行 |
| `'\t'` | 定位字元 |
| `'\''` | 單引號 |
| `'\\'` | 反斜線 |

## 問題

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## 大小寫

`.upper`和`.lower`只會改變字母的大小寫，其他一律不動，所以即使你還沒檢查過某個字元，也可以放心套用。

## 數字

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int`和`.char`正好相反。關於編號方式，有幾個實用的事實：`'a'`到`'z'`是連續的，`'A'`到`'Z'`是連續的，`'0'`到`'9'`也是連續的，所以：

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## 繞回開頭

密碼轉盤轉過`z`之後會回到`a`。`%`做的正是這件事：

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Sather 的`%`在右邊是正數時永遠不會得出負數，所以往前轉或往後轉都沒問題。

## 字元與字串

`STR`是一列位元組，而`CHAR`是一個位元組。對英文文字來說，一個位元組就是一個字母，所以`"Marlowe".size`是 7，而`"Marlowe"[0]`是`'M'`。至於帶有重音或其他文字系統的文字，一個字母可能佔用好幾個位元組，上面那兩種說法就都不成立了。
