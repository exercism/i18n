# 簡介

`Rational numbers`是分子和分母都是整數的分數。

例如，我們可以把`2//3`儲存成精確的分數，而不是`Float64`的近似值`0.6666...`。

好處是（除了*整數溢位*這種極端情況之外），有理數會保持精確，避免浮點數經常難以避免的捨入誤差。

有理數是很單純的數值型別，運作方式也大致符合你的預期。
由於有理數從早期版本開始就是 Julia 的標準型別，大多數函式都會像接受整數和浮點數那樣，接受它作為輸入。

## 建立有理數

建立的方法很簡單，只要在兩個整數之間使用`//`就行了。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

公因數會自動約掉，把分數化成「最簡形式」：也就是能精確表示該分數的最小整數，而且分母為非負數。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## 有理數的算術運算

常見的`arithmetic operators` `+ - * / ^ %`可以用在有理數上，基本上和其他數值型別一樣。

整數和其他`Rational`也能參與運算，並得到`Rational`的結果。
運算式中若包含`float`，結果就會是`float`，因此可能會有精度損失。

如果想要`float`，只要用`float()`函式把有理數轉換過去就行了。
在冗長的計算中先用有理數保持精度，最後再轉成浮點數，這是很常見的做法。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## 其他運算

在 Julia 中，有理數就只是數字。
編譯器通常會視需要自動轉換型別。

不過要注意，比較運算只適用於具有有限小數表示法的分數：

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

否則的話，`Rational`應該先轉型成`Float`再進行比較：

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

數學函式可以接受有理數作為輸入，但結果可能是浮點數：

```julia-repl
julia> sqrt(9//16)
0.75
```
