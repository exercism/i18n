# 簡介

## R 中的布林值

真或假的值在 R 中由 `logical` 型別表示。
它只有兩個值：`TRUE` 和 `FALSE`。

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 布林運算子

R 裡有五個布林運算子，但在這個課程大綱階段只會用到其中三個。
另外兩個在處理向量時才會派上用場，之後會有幾個概念分別介紹到。

`&&` 是布林的「且」運算。
當 `&&` *兩側*的運算式都是 `TRUE` 時，它就會求值為 `TRUE`。

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` 是布林的「或」運算。
只要 `||` *任一側*的運算式是 `TRUE`，它就會求值為 `TRUE`。

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` 是布林的「非」運算。
它會交換 `TRUE` 和 `FALSE` 這兩個值。

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

遇到更長、更複雜的運算式時，最好用括號清楚表達你的意圖。

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
