# 指令補充

## 實作注意事項

Cipher 介面的定義位於 `cipher.go`。

你的實作應該符合 Cipher 介面。

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

預期 `Encode` 會忽略字串中所有不是 A-Za-z 的值，它們不會出現在輸出中。
輸出也會被正規化為小寫。

用來取得 Cipher 的函式如下：

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

`NewShift` 的引數必須介於 1 到 25 或 -1 到 -25 之間。
不允許 0。
引數無效時，`NewShift` 會回傳 nil。

`NewVigenere` 的引數只能由小寫字母 a-z 組成。
全部由字母 'a' 組成的值不允許。
引數無效時，`NewVigenere` 會回傳 `nil`。
