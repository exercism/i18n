# 安裝

這個軌道全程採用 [Wren Console][wren-console]，為 Wren 提供本機的執行環境。也就是說，我們假設你在電腦上執行 Wren 時，都會使用 [Wren Console][wren-console]。請不要把這和官方的 Wren <abbr title="命令列介面">CLI</abbr> 搞混。在理想情況下，你可以使用那個執行環境，但它目前[有](https://github.com/wren-lang/wren-cli/pull/74)[幾個](https://github.com/wren-lang/wren/pull/1006)[不同](https://github.com/wren-lang/wren-cli/issues/108)[問題](https://github.com/wren-lang/wren-cli/pull/105)，讓它成為用 Exercism 學習 Wren 時不太理想的選擇。

Wren Console 是從 Wren CLI 分支出來的，它解決了這些問題，並加入一些功能，讓你的學習體驗更順暢。別擔心，你在這裡學到的 Wren 語言知識和概念，未來無論你想在哪裡使用 Wren 都適用。

## 安裝概觀

- 安裝 Git，以取得 `git` 指令
- 安裝 [Wren Console][wren-console]，以取得 `wrenc` 指令

### 安裝 Git

你需要安裝 `git` 執行檔，並讓它位於你的 PATH 中。Wren Package 就是這樣安裝套件的（例如你測試練習時需要的測試套件等等）。

- **Windows**：官方 [Git 下載](https://git-scm.com/download/win) 是不錯的起點。
- **Linux**：你慣用的套件管理器應該就能幫上忙。
- **Mac**：所有近期版本的 Mac OS 都直接內建 `git`。

你可以用 `git --version` 確認 Git 是否已安裝：

```
$ git --version
git version 2.31.1
```

如果版本不完全相同也不用擔心，這通常沒那麼重要。


### 安裝 Wren Console

#### Windows

你大概會想從 GitHub [下載最新版本][releases]。接著你需要解壓縮，並把 `wrenc` 執行檔複製到你的 PATH 中。

也可以使用 Visual Studio [從原始碼建置][build-from-source]。

#### Linux

你可以從 GitHub [下載最新版本][releases]，或[從原始碼建置][build-from-source]。

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

並確認它可以在你的 `PATH` 中使用。

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

最簡單的安裝方式是使用 Exercism 的 [Homebrew][homebrew] tap 和 formula：

```
brew tap exercism/wren
brew install wren-console
```

或者你也可以從 GitHub [下載最新版本][releases]，並依照 Linux 的說明手動安裝。如果你熟悉這類操作，從原始碼建置也相當簡單。

### 測試安裝

當你確信執行檔已經正確安裝後，最好測試一下一切是否正常運作。

1. 開啟一個_終端機_（`Terminal`、`cmd`、`Powershell`、`bash`……）
2. 執行 `wrenc -v`

你應該會看到 `wrenc` 和 Wren 的版本都列出來：

```
wrenc v0.3.1 (wren v0.4.0)
```

**注意**：請務必開啟一個_新_的終端機視窗。安裝完成後，已開啟的終端機視窗可能沒有更新。這表示那些已開啟的終端機不知道有新程式被安裝了。

> _**協助**_：`'wrenc' is not recognised`
>
> 你可能沒有把 `wrenc` 放到 PATH 中……在 macOS 和 Linux 上，你可以把下面這行加進 `~/.bash_profile` 或 `~/.zshrc`，來修改你的 PATH：
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **不確定這些內容是否正確。**
> 在 Windows 上，開啟開始功能表並搜尋「environment variables」。你需要編輯 `PATH` 項目，並在這裡_加入_ `wrenc` 執行檔的路徑。這些通常位於 `C:\Program Files\nodejs`。如果你用 `File Explorer` 瀏覽到這裡，應該會找到 `node.exe`、`npm.bat` 和 `npx.bat`。
>
> 關閉所有已開啟的終端機，然後開啟一個新的。

## 練習需求

請依照[這些說明][cli-walkthrough]，為你的作業系統下載 `exercism` CLI。

CLI 設定並配置完成後，下載第一個練習 `hello-world`：

```bash
$ exercism download --exercise=hello-world --track=wren
```

每個練習接著需要一些 Wren 套件才能執行測試。你可以在練習目錄中執行這個指令來安裝它們：

```bash
$ wrenc package.wren install
```
