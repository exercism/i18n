# 關於

Swift 中的[閉包][closures]是自成一體的程式碼區塊，可以接收參數來觸發運算並回傳值。
閉包也會從環境中捕獲值，並在運算中使用這些值。
由於它們自成一體，因此可以在程式中像其他值一樣傳遞，或指定給常數與變數。

閉包聽起來可能很像 Swift 函式；確實如此，而且有充分的理由。
Swift 中的函式是閉包的特例，它們必須有名稱，而且定義時使用的語法略有不同。

雖然 Swift 中的函式在技術上也是閉包，但當人們在 Swift 裡提到「閉包」時，他們指的是[閉包表達式][closure-expressions]。
閉包表達式的寫法是先寫參數列表，接著是回傳型別與關鍵字`in`，再接著閉包的主體，全部包在一對大括號中：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

這定義了一個型別為`(Double, Double) -> Double`的閉包表達式，而且可以像執行這種型別的函式一樣，將它套用到適當型別的參數上來執行：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

由於每次想執行閉包時，都要寫出完整的閉包表達式並不太方便，因此可以像 Swift 中的任何其他值一樣，將閉包指定給名稱。
之後就能把名稱套用到參數上來呼叫它們：

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

如上所示，閉包和一般函式一樣，如果閉包的主體是單一表達式，就可以省略`return`關鍵字。

最常見的情況是，閉包會與高階函式一起使用，可能是作為參數傳入，或是作為結果回傳：

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## 推論閉包型別

當回傳型別或參數型別可以[從情境推論][inferring-closure-types]時，就可以從閉包表達式中省略。
此外，如果可以省略參數型別，參數名稱外面的括號也可以省略：

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- 在第一個範例中，型別可以從常數`mean`的型別標註推論出來。
- 在第二個範例中，編譯器從`makeAdder`的定義得知`base`是整數，而且回傳的函式必須是`(Int) -> Int`型別。由此，它可以驗證如果`x`是`Int`，那麼閉包就會是`(Int) -> Int`型別，因此我們可以省略閉包中的型別簽章，因為`(Int) -> Int`是這個閉包唯一可能擁有的有效簽章。
- 第三個範例類似，但編譯器需要從使用該方法的陣列取得一些型別資訊。它知道`sorted(by:)`方法接受的參數是一個閉包，該閉包有兩個參數，型別與被排序集合的元素相同，並會回傳`Bool`，因此編譯器可以推論閉包的回傳型別一定是`Bool`。而且由於該方法是用在 String 陣列上，它可以判定參數`s1`和`s2`的型別都必須是`String`。

## 閉包的限制

如前所述，Swift 中的函式和閉包非常相似，但有一些重要差異：

- 閉包不能使用外部引數標籤。沒有辦法定義它們，而且呼叫閉包時嘗試使用參數名稱會導致錯誤：

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- 閉包中的參數不能有預設參數值。
- 閉包中的參數可以是可變參數，但它們必須有名稱和型別標註。
