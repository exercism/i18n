# 說明

就像幾乎所有有工作的人一樣，Lisp 外星人 Layla 有時也需要製作報表，讓其他人知道一些資訊。他問你能不能幫他把他手上這些報表要用的資料格式化。

## 1. 格式化每季的值

Layla 首先需要的是一個函式：`format-quarter-value`，它接受兩個參數：季度和值，並將它格式化，以便放進報表。它的求值結果應該是一個字串。

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. 兩季報表

Layla 謝謝你寫了 `format-quarter-value` 這個函式，並說在*下一個*需要的函式裡，它會非常有用。

下一份報表需要印出 2 個季度的季度與值，分成兩行。

此外，輸出必須送到作為第一個引數提供的那個串流。

例如：`(format-two-quarters t "last" 3.14 "this" 0)` 會在標準輸出上產生下列內容：

```

The value last quarter: 3.14
The value this quarter: 0

```

注意它前後的空行。

## 3. 人類可讀與 Lisp 外星人可讀

Layla 忘了告訴你，Lisp 外星人喜歡用可以直接當成 Lisp 資料讀取的方式來看值。所以他們需要一個新函式，它的輸出要能被讀成 Lisp 資料（一樣要送到指定的串流）：

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
