# 提示

## 1. 估算準備時間

- 使用 [`len()` 內建函式][len-builtin] 取得 layers 切片的長度，也就是層數。

## 2. 計算所需的麵條與醬汁份量

- 首先，建立兩個變數來記錄麵條和醬汁的份量。
- 使用 `for` 迴圈逐一走訪每一層。
- 如果在迴圈中遇到 `'noodles'` 或 `'sauce'` 這一層，就把對應變數裡儲存的份量增加。

## 3. 加入祕密食材

- 重新複習[切片][concept-slices]，了解如何從切片取出元素，以及如何取代切片中的元素。
- 切片 `a` 中最後一個元素的索引是 `len(a) - 1`。

## 4. 依比例調整食譜

- 首先建立一個與輸入切片大小相同的新切片
- 使用 [`for` 迴圈][for-loop] 走訪輸入切片並產生輸出切片
