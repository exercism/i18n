# 說明

建立仿射密碼的實作，這是一種源自中東的古老加密系統。

仿射密碼是單表替換密碼的一種。
每個字元都會先對應到它的數值，再以數學函式加密，然後轉換成與新數值相對應的字母。
雖然所有單表密碼都很弱，但仿射密碼比 Atbash 密碼強得多，因為它的金鑰多得多。

## 加密

加密函式為：

```text
E(x) = (ai + b) mod m
```

其中：

- `i` 是字母的索引，從 `0` 到字母表長度減 1
- `m` 是字母表的長度。
  對羅馬字母表來說，`m` 是 `26`。
- `a` 和 `b` 是構成加密金鑰的整數

值 `a` 和 `m` 必須_互質_（或稱_互素_），自動解密才能成功，也就是說它們唯一的公因數是 `1`（更多資訊請見[關於互質整數的維基百科條目][coprime-integers]）。
如果 `a` 與 `m` 不互質，你的程式應該指出這是一項錯誤。
否則，它應該用提供的金鑰加密或解密。

在本練習中，數字是有效的輸入，但不會被加密。
空格與標點字元則排除在外。
密文會以固定長度分組寫出，各組之間以空格分隔，傳統的組大小是 `5` 個字母。
這麼做是為了讓人更難根據詞的邊界猜到加密後的文字。

## 解密

解密函式為：

```text
D(y) = (a^-1)(y - b) mod m
```

其中：

- `y` 是加密後字母的數值，也就是 `y = E(x)`
- 要注意的是，`a^-1` 是 `a mod m` 的模反元素（MMI）
- 模反元素只有在 `a` 與 `m` 互質時才存在。

`a` 的 MMI 是滿足以下條件的 `x`：`ax` 除以 `m` 後的餘數為 `1`：

```text
ax mod m = 1
```

關於如何求出模反元素以及它的意義，更多資訊請見[相關的維基百科條目][mmi]。

## 一般範例

- 以金鑰 `a = 5`、`b = 7` 加密 `"test"` 會得到 `"ybty"`
- 以金鑰 `a = 5`、`b = 7` 解密 `"ybty"` 會得到 `"test"`
- 以錯誤的金鑰 `a = 11`、`b = 7` 解密 `"ybty"` 會得到 `"lqul"`
- 以金鑰 `a = 19`、`b = 13` 解密 `"kqlfd jzvgy tpaet icdhm rtwly kqlon ubstx"` 會得到 `"thequickbrownfoxjumpsoverthelazydog"`
- 以金鑰 `a = 18`、`b = 13` 加密 `"test"` 會發生錯誤，因為 `18` 和 `26` 不互質

## 求模反元素（MMI）的範例

求 `a = 15` 的 MMI：

- `(15 * x) mod 26 = 1`
- `(15 * 7) mod 26 = 1`，即 `105 mod 26 = 1`
- `7` 是 `15 mod 26` 的 MMI
