# 關於

[Red](https://www.red-lang.org) 的各種特色，大多源自它是以 [Rebol](http://www.rebol.com) 為基礎所創造出來的，而 Red 的開發一開始是作為開源社群的替代方案。在此同時，Rebol 的開發已經停擺，Red 則不斷演進。

## Rebol 的傳承

就像 Rebol 一樣，Red 是一門**通用**程式語言。你可以用它打造任何你想要的應用程式。為了盡可能讓開發者感到熟悉，它實作了**多種典範**：*命令式*、*函式式*、*物件*、*符號*以及*反應式*。雖然整條工具鏈只有 1.5 MB 的下載大小，它卻為所有主要作業系統（Windows、Linux、macOS）提供**圖形使用者介面**的實作，而且不依賴任何外部函式庫。

Red 致力於做到**盡可能簡單**。它的設計方式是做出最實用的取捨，並選擇合理的預設值，讓你完成每一項任務時不會被琳瑯滿目的選擇淹沒。它著重於人類的**可讀性**，因此語法糖被減到最低，程式也盡量寫得像自然語言的句子。因此，Red 和 Rebol 都[極具表達力](https://redmonk.com/dberkholz/2013/03/25/programming-languages-ranked-by-expressiveness/)。

Red 一個不尋常的特點是它的**同像性**，所以 Red 程式可以像任何 Red 資料結構一樣被操作。因此，Red 和 Rebol 同時也是一種資料格式。有趣的是，[JSON 的靈感來自 Rebol](http://www.rebol.com/article/0522.html)。

## Red

與 Rebol 相比，Red 有大幅的改進。它能用任何一個支援的平台**編譯**成該平台的單一執行檔。所以，你可以在 Linux 上編譯 Windows 程式，或在 Windows 上編譯 macOS 程式。另外還有一個 **REPL 主控台**，有命令列和圖形兩種版本，讓你可以一行一行輸入 Red 指令，即時操作資料。

讓 Red 與眾不同的另一個地方是它的方言 Red/System，這讓 Red 成為一門**全端**語言，可以開發像 C 那樣的低階程式碼。

## 使命

* 讓寫程式重新變得**有趣**
* 對抗軟體的複雜度

## 開發

Red 是開源的，開發工作託管在 [GitHub 儲存庫](https://github.com/red/red)。目前專案處於 **alpha 階段**，所以要有心理準備，功能和行為隨時可能改變甚至出錯。
