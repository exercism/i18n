# 指令

在這個練習中，你會為朋友正在開發的一款電玩遊戲寫一些邏輯。遊戲的主角是 Annalyn，一個勇敢的女孩，身邊帶著一隻凶猛又忠誠的寵物狗。不幸的是，災難降臨了：她最好的朋友在森林裡尋找莓果時遭到綁架。Annalyn 會試著找到並救出她的朋友，這趟冒險中她可以選擇帶上她的狗。

Annalyn 最後找到了囚禁她朋友的營地，結果發現綁匪有兩個人：一名強大的騎士和一名狡猾的弓箭手。

玩家會看到接下來可以採取哪些行動的幾個選項。四個可能的選項中，你需要各寫一個函式，告訴遊戲是否應該顯示該選項。

## 1. 檢查是否應顯示「快速攻擊」選項

如果騎士正在睡覺，Annalyn 就能趁他還沒完全清醒、穿好盔甲之前，快速突襲營地。

實作一個名為`can_do_fast_attack`的函式，它接受一個布林值，表示騎士是否醒著。這個函式會依據角色的狀態，在「快速攻擊」行動可用時回傳`true`，否則回傳`false`：

```julia-repl
julia> knight_awake = true

julia> can_do_fast_attack(knight_awake)
false
```

## 2. 檢查是否應顯示「偵察」選項

只要他們之中至少有一個人醒著，就可以對這群人進行偵察。否則，偵察只是浪費時間。

實作一個名為`can_spy`的函式，它接受三個布林值，分別表示騎士、弓箭手和囚犯是否醒著。這個函式會依據角色的狀態，在「偵察」行動可用時回傳`true`，否則回傳`false`：

```julia-repl
# Output suppressed from the next 3 lines
julia> knight_awake = false
julia> archer_awake = true
julia> prisoner_awake = false

julia> can_spy(knight_awake, archer_awake, prisoner_awake)
true
```

## 3. 檢查是否應顯示「對囚犯打信號」選項

如果囚犯醒著，而且弓箭手正在睡覺，就可以用鳥叫聲向她打信號。如果弓箭手醒著，就沒辦法安全地打信號，因為弓箭手也受過鳥叫聲信號的訓練。

實作一個名為`can_signal_prisoner`的函式，它接受兩個布林值，分別表示弓箭手和囚犯是否醒著。這個函式會依據角色的狀態，在「對囚犯打信號」行動可用時回傳`true`，否則回傳`false`：

```julia-repl
julia> archer_awake = false
julia> prisoner_awake = true

julia> can_signal_prisoner(archer_awake, prisoner_awake)
true
```

## 4. 檢查是否應顯示「釋放囚犯」選項

Annalyn 可以試著潛入營地救出她的朋友。這件事風險很高，只有兩種情況能成功：

- 如果 Annalyn 帶著她的寵物狗，只要弓箭手在睡覺，她就能救出囚犯。
  騎士怕狗，而弓箭手也來不及在 Annalyn 和她的朋友逃脫之前做好準備。

- 如果 Annalyn 沒帶狗，她和囚犯就得非常小心才行！
  如果她醒著，而且騎士和弓箭手都在睡覺，Annalyn 就能救出囚犯；但如果囚犯在睡覺，就救不了她：她會被 Annalyn 突然出現嚇到，然後驚醒騎士和弓箭手。

實作一個名為`can_free_prisoner`的函式，它接受四個布林值。前三個參數分別表示騎士、弓箭手和囚犯是否醒著。最後一個參數表示 Annalyn 的寵物狗是否在場。這個函式會依據角色的狀態，在「釋放囚犯」行動可用時回傳`true`，否則回傳`false`：

```julia-repl
julia> knight_awake = false
julia> archer_awake = true
julia> prisoner_awake = false
julia> dog_present = false

julia> can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present)
false
```
