# 關於

在 Go 1.18 中，Go 新增了對**泛型**的支援。
泛型讓你撰寫能處理不同型別的函式與資料結構，而不必重複程式碼。

## 為什麼需要泛型？

在 Go 裡，函式與型別通常只處理特定的型別，例如 `int` 或 `string`。
在泛型出現之前，要支援多種型別有兩種做法。
第一種是撰寫多個名稱不同的函式，例如 `SumInts` 和 `SumFloats`。
這種做法會產生難以維護的重複程式碼。
第二種是使用空介面 `any`（`interface{}`）。
然而，空介面會移除編譯期的型別檢查，並且必須在執行階段進行型別斷言。
泛型在避免重複程式碼的同時提供型別安全，解決了這個問題。

## 泛型函式

在函式名稱後面加上方括號 `[...]` 中的**型別參數**，就能定義泛型函式。
以下是一個回傳反轉切片的泛型函式範例：

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

在這個範例中，`T` 是型別參數。
你可以把 `T` 想成真實型別的佔位符。
方括號內的 `any` 關鍵字是**型別限制**。
這個限制告訴編譯器 `T` 允許哪些型別。
在這裡，`any` 表示 `T` 可以是任何型別。

### 呼叫泛型函式

在方括號中傳入實際的型別，就能呼叫泛型函式。
這個實際的型別稱為**型別引數**。

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

大多數情況下，Go 編譯器可以從函式的引數自動判斷型別。
這個特性稱為**型別推斷**。
有了型別推斷，你就不需要在方括號裡寫出型別引數。

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

在這個範例中，編譯器看到 `words` 是字串切片，因此推斷 `T` 是 `string`。

## 型別限制

每個型別參數都必須有型別限制。
型別限制指定了哪些型別可以作為型別引數。
型別限制也決定了你能對該型別的值執行哪些操作。

### `any` 限制

`any` 限制允許任何型別。
在 Go 裡，`any` 是空介面 `interface{}` 的別名。
因為 `any` 允許所有型別，函式只能執行適用於所有 Go 型別的操作。
例如，如果你有兩個存放切片的 `any` 值，它們無法用 `==` 比較，因為切片不能用 `==` 比較。

### `comparable` 限制

Go 提供了一個內建的限制 `comparable`。
`comparable` 限制允許任何支援 `==` 和 `!=` 運算子的型別。
可比較的型別包括布林、數字、字串、指標、通道，以及由可比較型別組成的結構體或陣列。

以下是一個檢查切片是否包含特定元素的函式範例：

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

因為 `T` 使用了 `comparable` 限制，所以 `elem == target` 是合法的。
如果你把 `comparable` 換成 `any`，編譯器就會回報錯誤。

### 使用介面型別集合的自訂限制

從 Go 1.18 開始，介面除了方法之外，還能定義型別集合。
你可以用直立線字元 `|` 在介面中列出允許的型別。

```go
type Number interface {
    int | int64 | float64
}
```

現在你可以把 `Number` 當成函式的限制：

```go
func Double[T Number](value T) T {
    return value * 2
}
```

因為 `Number` 中的所有型別都支援 `*` 運算子，Go 允許函式內使用 `value * 2`。

### 基礎型別近似 `~`

有時你會以基本型別為基礎建立自訂的型別定義：

```go
type MyInt int
```

上面定義的 `Number` 限制只允許 `int`、`int64` 和 `float64` 這幾個確切的型別。
如果你把 `MyInt` 的值傳給 `Double`，編譯器會產生錯誤，因為 `MyInt` 不符合 `int`。
若要允許任何基礎型別為 `int` 的型別，請在型別前加上波浪號 `~`：

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

現在你就可以用 `MyInt` 型別的值來使用 `Double`。

### `cmp.Ordered` 限制

標準函式庫在 [`cmp` 套件][doc-cmp] 中提供了 `cmp.Ordered` 限制。
`cmp.Ordered` 限制允許任何支援 `<`、`<=`、`>` 和 `>=` 比較運算子的型別。

## 泛型型別

你也可以用型別參數定義泛型型別，例如結構體。
以下是一個泛型 `Stack` 資料結構的範例：

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

宣告泛型型別的變數時，必須在方括號中提供型別引數：

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

型別推斷只適用於泛型函式。
建立泛型型別的值時，你必須一律指定型別引數。

## 什麼時候該用泛型

泛型是強大的功能，但你不必每個問題都用它。

在這些情況下使用泛型：
- 你正在建立能處理任何元素型別的資料結構，例如樹、鏈結串列或快取。
- 你正在撰寫可處理任何型別切片或映射的工具函式，例如篩選、排序或搜尋。
- 你需要對多個型別使用完全相同的實作，並且想要編譯期的型別安全。

在這些情況下改用介面：
- 你關心的是行為與方法，而不是底層的資料型別。
  例如，如果你想從各種型別的來源（檔案、網路、TTY）讀取並處理資料，你會選擇 `func Process(src io.Reader)` 而不是 `func Process[T](src T)`。
- 不同型別需要不同的方法實作才能完成工作。
