# 指令

小提琴是靠耳朵對照參考音來調音的。各條弦的音高相差很遠，而且涉及的數字並不是整數。

這五個任務都放在`TUNING_THE_STRINGS`類別裡。

## 1. 升高一個八度

高一個八度的音，頻率是兩倍。

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. 降低一個八度

低一個八度，頻率則是一半。

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. 取兩者的中點

給定兩個頻率，回傳正中間的那個頻率。

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. 差了多少？

當兩個音很接近但不完全相同時，頻率每相差一個週期，你每秒就會聽到一次拍音。請回傳這兩個頻率相差多少。無論哪個音比較高，答案永遠不會是負數。

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. 分配練習時間

給定一個分鐘數和一個演奏者人數，每人可以分到幾分鐘？分鐘數和人數都是整數，但答案不一定會是整數。

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
