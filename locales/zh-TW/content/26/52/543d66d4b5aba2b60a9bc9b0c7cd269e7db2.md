# 簡介

方法是一種帶有特殊_接收者_引數的函式。接收者會出現在自己的引數清單中，位於`func`關鍵字與方法名稱之間。

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

只有當接收者的型別與方法定義在同一個套件時，你才能定義這個方法。

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

接收者分為兩種：值接收者和指標接收者。

使用值接收者的方法，會對傳入值的複本進行操作，這表示在方法內對接收者所做的任何修改，都不會被呼叫端看見。

你可以宣告使用指標接收者的方法，以便修改接收者所指向的值。做法是在型別名稱前面加上`*`。例如對`rect`型別來說，指標接收者會宣告成`*rect`。這類修改同樣會被方法的呼叫端看見。

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
