# 關於

方法參數可以藉由指定預設值，讓它成為選用參數。呼叫帶有選用參數的方法時，呼叫端不必傳入它們的值。如果沒有傳值給某個選用參數，就會使用它的預設值。

選用參數必須放在參數列表的最後面；它們後面不能再接非選用參數。

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

在變數名稱前面加上`?`運算子，就能把選用參數設為`null`：

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
