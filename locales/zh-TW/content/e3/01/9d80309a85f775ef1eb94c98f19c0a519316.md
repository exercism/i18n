# 學習

Exercism 提供練習與回饋，但對第一次學習 Common Lisp 的人來說，可能不太容易上手。
以下資源可以幫助你起步：

* [A Road to Common Lisp][road-to-cl]，一篇部落格文章，講述某個人學習 Common Lisp 的歷程，以及他對如何入門的看法
* [Practical Common Lisp][practical-cl]，學習 Common Lisp 的完整書籍，可免費在線上閱讀（也有實體書）
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]，
  由多位貢獻者共同撰寫
* [Awesome Common Lisp Learning][awesome-cl]

另外，在這個 Exercism Common Lisp track 中，也可以參考[重要資源][track-resources]。
