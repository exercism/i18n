# 簡介

## 協定

協定是 Elixir 中用來實現多型的機制，讓行為可以根據資料型態而有所不同。

協定使用`defprotocol`定義，其中包含 1 個或多個函式標頭。

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

協定可以用`defimpl`來實作。

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

協定可以為任何現有的 Elixir 資料型態或結構體實作。

呼叫協定的函式時，會根據第一個引數的型別自動選擇合適的實作。
