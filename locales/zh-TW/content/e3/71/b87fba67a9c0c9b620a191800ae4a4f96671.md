# 提示

## 一般

- 閱讀[官方 Getting Started 指南][getting-started-erlang-libraries]中關於使用 Erlang 函式庫的內容，特別是[格式化字串][getting-started-formatted-text-output]的部分。

## 1. 產生隨機的行星

- 使用題目提供的模組屬性，裡面是代表行星等級的字母陣列。
- 有一個[內建函式][enum-random]可以從陣列中隨機挑選一個元素。

## 2. 產生隨機的星艦註冊編號

- 有一個[內建函式][enum-random]可以從範圍中隨機挑選一個元素。

## 3. 產生隨機的星曆

- Elixir 沒有會回傳隨機浮點數的函式。
- 有一個 [Erlang 內建函式][erl-rand-uniform]會回傳一個隨機浮點數 x，其中`0.0 <= x < 1.0`。
- 如果`x`落在`0.0 <= x < 1.0`這個範圍內，但你需要的數字屬於另一個範圍`a <= x < b`，你可以把 x 的範圍平移：將它乘以範圍的寬度（`b - a`），再加上範圍的起點（`a`）。也就是：`x * (b - a) + a`。

## 4. 格式化星曆

- Elixir 沒有函式可以一步就把浮點數格式化為指定精度的字串。
- 有一個 [Erlang 內建函式][erl-io-lib-format]，它接受一個格式字串和一份資料陣列，並回傳一個字元清單。
- 有一個[內建函式][to-string]可以把字元清單轉換成字串。
- 這個函式的格式字串包含控制序列。
- 控制序列以`~`開頭，格式為`~F.P.PadModC`，其中`F`代表輸出的寬度，`P`代表精度，`Pad`代表填充字元，`Mod`代表控制序列修飾詞，`C`則是控制序列的型別。
- 想以指定精度格式化浮點數，只要使用格式為`~.PC`的控制序列就夠了。
- 浮點數的控制序列型別是`f`。
- 你需要的確切格式字串是`~.1f`。
