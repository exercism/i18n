# 安裝

## 目標版本

這個 track 的測試使用`alpine:3.24.1` Docker 映像，而截至 2026 年 9 月，這個映像使用的版本是`sqlite3 version 3.53.4`。
我們會盡量確保這個 track 提供的工具能在最新的 Ubuntu LTS 版本上運作。
你可能安裝了更新的版本，但請注意，有些功能在我們的測試執行器上可能無法運作。
各版本的功能可以在[SQLite 版本歷史][version-history]上比較。

## Windows

若要在 Windows 上安裝 SQLite，請依照下列步驟：

1. 從[官方下載頁面][sqlite-download]下載預先編譯好的 Windows 二進位檔。
2. 將下載的 ZIP 檔解壓縮到你選擇的目錄，例如 `C:\Program Files\sqlite3`。
3. 將包含`sqlite3.exe`的目錄加入系統的 PATH 環境變數。
   每個 Windows 版本的作法略有不同，不過這些資訊應該不難搜尋。
   例如[Windows 11][windows-11-install]和[Windows 10][windows-10-install]的說明。

## macOS

macOS 已預先安裝 SQLite。
不過如果你需要更新的版本，可以使用[Homebrew][homebrew]：

```bash
brew install sqlite
```

## Ubuntu / Debian

在 Ubuntu 和以 Debian 為基礎的系統上，你可以使用 apt 安裝 SQLite：

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

在 CentOS、Fedora 和以 Red Hat 為基礎的系統上，你可以使用 yum 或 dnf 安裝 SQLite：

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

在 Arch Linux 上，你可以使用 pacman 安裝 SQLite：

```bash
sudo pacman -S sqlite
```

## 其他安裝方式與較舊版本

更多資訊和其他安裝方式請參閱[SQLite 下載頁面][sqlite-download]。
`Build Product Names and Info`區段列出了不同 SQLite 版本的命名範本，所以你應該可以用自己慣用的搜尋引擎找到想要的版本。
