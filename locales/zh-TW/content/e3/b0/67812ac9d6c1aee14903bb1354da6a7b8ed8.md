# 關於

Factor 唯一的資料傳遞慣例是*資料堆疊*：詞會彈出它們的輸入，再推入它們的輸出。每個詞的定義都會宣告一份*堆疊效應*，用來記錄這項約定。

```factor
: restow ( a b -- b a ) swap ;
: discard-top ( a b -- a ) drop ;
```

`( … -- … )`裡的名稱是為了方便讀者；編譯器真正檢查的是輸入與輸出的*數量*。數量不符會造成編譯期錯誤，這能攔下一類 bug，這類 bug 在沒有這種宣告的動態型別語言中會變成執行期錯誤。

因為堆疊是有位置的，你經常需要在下一個詞執行之前，先重新排列堆疊頂端。`kernel`的**重排詞**正是做這件事：

```
dup   ( x   -- x x   )    ! duplicate the top
drop  ( x   --       )    ! discard the top
swap  ( x y -- y x   )    ! flip the top two
over  ( x y -- x y x )    ! copy the second item onto the top
nip   ( x y -- y     )    ! discard the second item
rot   ( x y z -- y z x )  ! roll the third item up to the top
```

完整的重排詞家族還延伸到 `-rot`（往另一個方向轉）、加了 `d` 後綴而作用位置深一層的近親（`dupd`、`swapd`）、加了 `2` 前綴而作用於成對項目的近親（`2dup`、`2drop`、`2nip`），以及 `pick` 和 `tuck` 等等。這些詞會在後續練習需要時才介紹；一次動用太多重排詞，通常代表改用*區域變數*（具名的值）會更好讀。

依照慣例，詞採用 `lowercase-kebab-case`，述詞以 `?` 結尾並產生布林值（`even?`、`empty?`），設值詞寫成 `>>name`，取值詞寫成 `name>>`；一個詞和它會修改狀態的版本常常共用同一個名稱，只靠上下文來區分。
