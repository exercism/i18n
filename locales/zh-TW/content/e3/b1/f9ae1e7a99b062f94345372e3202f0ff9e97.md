# 指令

附近有一間叫做「Tech Palace」的電器行。
店主最近安裝了一面大型顯示器，用來播放行銷訊息，並在顧客於入口掃描所謂的會員卡時顯示特別的問候語。
這面顯示器由許多小小的 LED 燈組成，可以顯示多行文字。

店主需要你幫忙寫出用來產生這面新顯示器文字內容的程式碼。

## 1. 建立歡迎訊息

對大多數掃描會員卡的顧客，店主希望在顯示器上看到 `Welcome to the Tech Palace, `，後面接著以大寫字母顯示的顧客姓名。

實作函式`welcome`，它接受顧客的姓名，並以字串回傳想要的訊息。

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. 加上花俏的邊框

對於在店裡大量消費的忠實顧客，店主希望讓歡迎訊息看起來更花俏，在歡迎訊息前後各加上一行星號。
他們還不確定每行應該要有幾顆星號，所以希望這個數量可以調整。

撰寫函式`add_border`，接受一則歡迎訊息和每行的星號數量作為引數。
它應該回傳一個由 3 行組成的字串：一行包含指定數量的星號，接著是原本傳入的歡迎訊息，然後再一行星號。

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. 清理舊的行銷訊息

在安裝這面新顯示器之前，店裡有一面類似的顯示器，只能顯示無法調整的固定文字行。
店主想在新顯示器上重複使用一些舊的行銷訊息。
不過，這些資料裡已經包含了一些惱人的空白字元，那是當初為了讓文字在好幾面堆疊在一起的顯示器上對齊而留下的。
你的任務是清理這些訊息，讓它們可以重複使用。

實作函式`clean`，它接受舊的行銷訊息。
這個函式應該先移除文字中開頭和結尾的所有空白字元，然後回傳它。

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
