# 當個優秀的 Exercism 社群成員

我們希望 Exercism 是個值得花時間待著的好地方，無論你是誰。
為了確保 Exercism 真的是這樣，我們非常重視當個好的社群成員。

這在我們的[行為準則](https://exercism.org/code-of-conduct)裡有正式規範，但其實可以用一句話總結：**保持善意。**

在為 Exercism 貢獻的過程中，有幾個原則值得放在心上。
無論你是在引導別人、學習、在聊天空間裡閒聊，還是在 GitHub 上幫忙打造東西，只要遵循這些想法，你就會發現 Exercism 是個極其有趣又收穫滿滿的地方：

- 預設對方出於善意
- 犯錯是件很棒的事
- 你不知道自己不知道什麼
- 建設性地表達不同意
- 謹慎選擇用詞

## 預設對方出於善意

參與 Exercism 的絕大多數人，都是因為他們_想要幫助別人_。
他們可能對科技業充滿熱情，也許對教育有興趣，但最重要的是，他們想待在一個能與他人一起打造正面事物的空間裡。

這表示大多數的討論，都發生在兩個希望彼此好、也希望 Exercism 好的人之間。

有時候，當意見不合時，我們很容易就認定對方在刁難、沒在聽，或是不懂你的意思。
我們也很容易想像對方一副自鳴得意的樣子，一邊自我膨脹，一邊用他那些「錯誤」的意見惹火你。
但實際上，對方更可能是在努力傳達他覺得重要的事，只是還沒找到能讓別人聽懂的說法或方式。

當我們退一步，預設每個參與的人都在**努力**保持善意、努力做對的事、努力說清楚，我們就更容易放下自己的自尊，**主動**去聽聽對方的觀點。

這就帶我們來到……

## 犯錯是件很棒的事

發現自己某件事想錯了，是_你能遇到最棒的事_，因為你現在比之前**錯得少**了。
如果你在意思考是否科學、在意追求知識、在意把事情做對，那麼發現自己錯了就是最令人興奮的事。

所以當你在 Exercism 上加入一場討論時，把它當成一個機會，不是用來證明你是對的，而是用來發現自己可能哪裡錯了。這麼做之後，你可能會比以前更接近正確。

Adam Grant 為這個主題[寫了一整本書](https://www.adamgrant.net/book/think-again/)。
書中他引用了 [Ray Dalio](https://en.wikipedia.org/wiki/Ray_Dalio) 的話：「如果你回顧自己時，不會想著『哇，我一年前怎麼那麼笨』，那表示你過去一年大概沒學到什麼。」

## 你不知道自己不知道什麼

Exercism 建立在一個信念上：**我們不知道自己不知道什麼**。
整個平台的運作，就是靠導師指出那些你不知道自己有的知識缺口。
而當雙方都願意接納新資訊時，那會是超棒的體驗（很多時候，反而是_導師_在看到學生寫出的新程式碼和策略時，才發現自己原來也不知道某件事！）

在以學生身分參與引導時，要記住這種感覺並不難，但這種開放的心態在 Exercism 的其他每個地方同樣重要。
當你覺得網站上某個東西很爛時，先問問自己有哪些事是你可能_不_知道的。一個從你的角度看很荒謬的決定，可能代表你的知識有缺口，但也同樣可能代表那個決定**真的**很荒謬。

想看看這個原則的實際例子，可以讀讀我們關於[柴斯特頓的柵欄](/docs/community/being-a-good-community-member/chestertons-fence)的文章。

## 建設性地表達不同意

要打造成功的產品和成功的社群，很大一部分在於讓人們帶來不同的意見和觀點，並以找出共同真相為目標去討論它們。有時甚至需要對公認的真相抱持異議，才能抵達更好的真相。
因此，彼此意見不同是 Exercism 不可或缺的一環。
而能以建設性的方式表達歧見，是一項技能，而且很難精通。

以下幾個指引，談的是如何在我們的社群裡_有建設性地_表達不同意：

### 1. 先問問自己是否真的需要介入

你發現了一個問題，覺得應該讓某個人知道。
首先要問自己的是：真的需要嗎？
告訴別人某件事有錯，會_讓事情變得更好_嗎？
你是在製造雜訊，還是在提供訊號？

大多數時候，告訴別人他錯了是件好事。
你幫他補上知識缺口，也讓 Exercism 變得更好。
但有時那不值得花力氣、也不值得製造雜訊，糾正別人只會讓他對自己感覺更糟。
所以在跳進去之前，先確認這麼做對其他貢獻者來說是對的事。

### 2. 不要跟著一起批

這點和第一點密切相關：我們天生有種群體本能，一看到有人表達常見的（或相反的）意見，就覺得非得留言不可。
在 GitHub 上你很常看到這種情況：每個留言底下都有人加 👍 和 👎 表情符號，或是用「我也是！」的留言洗版。
很多人一看到公開的意見衝突，就覺得必須去「聲援」自己認同的那一方。

如果你要說的不是新的東西，或不是有用的東西，就問問自己到底_需不需要_開口。

- 那個 👎 只是讓對方覺得自己很糟嗎？
- 它只會讓對方更固守立場、變得防衛嗎？
- 加一個 👍 會讓另一個人覺得自己是對的、自我膨脹，反而更難去同理相反的觀點嗎？
- 加一句「我這邊也壞了！」的留言，是給維護者一個_有用_的資訊，還是只是增加壓力和急迫感？

每個情況都不一樣，但按下去或打字之前，先想一想。

### 3. 不要針對個人

所以你陷入了一場意見衝突。
**太好了！** 🎉
現在，_讓它有意義_。

記住，你不是在反對一個人，你是在反對他在某件事上**目前**的觀點。
要給他空間改變那個觀點，而且_不會_讓他覺得改變就是丟臉。
讓他有能力看見你觀點的價值，同時不讓他覺得自己很笨。
**不要針對個人。**

一個明顯的警訊，是你需要引用對方說過的話，來指出他哪裡說錯或自相矛盾。
人會自相矛盾，往往是**思考正在演進**的跡象。
這不能證明他_錯了_，只證明他讓自己的腦袋自由發揮。  
他們正在探索不同的路徑，用不同的方式把事情拼湊起來。
鼓勵這種事！

另外，記得做你自己。
你_不需要_特別指出你同意 X，或是 Y 顯然是對的。
重點不在人身上，而在_找出最好的解法_。
多給訊號，別製造雜訊。

### 4. 接受決定

很多時候，意見衝突不會得出所有人都同意的結論。
事實上，在 Exercism 幾乎每件事都是某種折衷。
所以你幾乎總是會對結果有那麼一點不滿意。

要當個好的社群成員，關鍵就在於接受並擁抱這些決定，即使你不同意它們。

決定必須涵蓋很多觀點，最終也會包含很多取捨。
對某個語言 track 來說是好事，對另一個 track 可能就差一點。
某個架構或組織方向，可能讓你比別人多做一些事。
牽涉整個網站或整個社群的考量，可能被認為比你那個 track 專屬的考量更重要。

如果你覺得自己不懂某個決定為什麼會做成，隨時可以問。
但一旦決定被解釋清楚了，即使你不喜歡，接受它就是你的責任。
如果每個人都努力這麼做，那麼下次有個決定**真的**如你所願、卻犧牲了別人的愉悅時，你不會感受到他們的內疚或不滿，也能把精力放在更有生產力的事情上。

也請相信，這些決定都是出於_**善意**_：每個人都在努力為社群、平台和我們的學生做出最好的選擇。

## 謹慎選擇用詞

在 Exercism 裡，實踐善意的方式有很多，但最有力的一種，是去思考你的話語會如何影響別人。

在一個充滿不同背景的人、跨越文化的空間裡，大家抱持不同的信念、價值體系和母語，能把話說清楚就是一種超能力。
你很容易知道自己的話_想表達_什麼，卻很難知道別人_怎麼理解你的話_。

想更深入了解這件事為什麼這麼重要，可以讀讀[我們使用的詞語](/docs/community/being-a-good-community-member/the-words-that-we-use)。
