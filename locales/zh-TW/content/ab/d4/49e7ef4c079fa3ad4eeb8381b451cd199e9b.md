# 指示

身為見習魔術師，Elyse 需要練習一些基本功。
她有一疊卡片，想要操作它們。

為了方便起見，她只用 1 到 10 的卡片，所以她的堆疊可以用一個數字向量來表示。
某張卡片的位置對應到向量中的索引。

## 1. 從堆疊取出一張卡片

要挑一張卡片，就從給定的堆疊中回傳索引`position`的卡片。

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. 替換堆疊中的一張卡片

施展一點手法，把索引`position`的卡片替換成提供的替代卡片。
回傳調整後的堆疊。

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. 在堆疊頂端插入一張卡片

在堆疊頂端插入一張新卡片，讓它憑空出現。
回傳調整後的堆疊。

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. 從堆疊移除一張卡片

從堆疊中移除指定`position`的卡片，讓它消失。
回傳調整後的堆疊。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. 移除堆疊頂端的卡片

移除堆疊頂端的卡片，讓它消失。
回傳調整後的堆疊。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. 在堆疊底部插入一張卡片

在堆疊底部插入一張新卡片，讓它憑空出現。
回傳調整後的堆疊。

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. 移除堆疊底部的卡片

移除堆疊底部的卡片，讓它消失。
回傳調整後的堆疊。

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. 檢查堆疊的大小

檢查堆疊的大小是否等於`stack_size`。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
