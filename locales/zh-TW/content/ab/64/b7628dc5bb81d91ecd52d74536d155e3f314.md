# 簡介

在 JavaScript 中，`Array`類別內建了許多強大的方法，可以用來轉換陣列。有了這些方法，要把一個陣列轉換成另一個陣列，比用簡單的`for`迴圈或其他直接操作的方式輕鬆得多。

有些方法是[_純_][pure-function-definition]的，這表示它們不會修改原始陣列，而是回傳一個新的陣列。不過，其他方法會直接操作被呼叫的陣列，而且**不會**回傳修改後的陣列。

以下介紹幾個最常用來轉換陣列的方法。完整的方法清單可以在 [MDN 文件][array-methods] 中找到。

### map（純）

依照以引數傳入的函式轉換每個元素，藉此建立一個新的陣列。這些回呼函式通常會寫成[箭頭函式][concept-arrow-functions]。

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

值得一提的是，產生的陣列長度一律與原始陣列相同。

### filter（純）

給定一個過濾函式（元素應該保留時回傳 true，應該移除時回傳 false），將目前的陣列過濾成一個新的陣列。

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce（純）

使用一個接收 _累加器_ 與目前陣列元素作為參數的函式，將陣列化簡為單一的值。這個函式說明目前元素該如何合併到累加器中，並回傳下一次疊代要使用的累加器。

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

反轉陣列中的元素。

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

這個方法會修改它所被呼叫的陣列。

### slice（純）

給定起始與結束索引，從它所被呼叫的陣列建立一個子陣列。

結束索引所指的元素不會被包含在內。此外，所有參數都是選用的：起始索引預設為`0`，結束索引則預設為陣列長度。

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

移除、取代或新增陣列中的元素。

它接受下列參數：

- 開始修改陣列的元素索引
- 要刪除的元素數量
- 要插入陣列的元素（選用）

`splice`會回傳被移除的元素。

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

預設情況下，`sort`會先將陣列的元素轉成字串，再套用字串比較來排序（請參閱[比較概念][concept-comparison]）。排序是 _原地_ 進行的，這表示原始陣列會被修改。`sort`也會回傳那個修改後的陣列，如果你想把其他方法串接在後面，這會很方便。

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

想自訂排序行為的話，可以把一個比較函式當作引數傳入。比較函式本身會以兩個引數被呼叫，這兩個引數是陣列中的兩個元素。它接著必須回傳下列其中一項：

- 若第一個引數應排在第二個之前，則回傳負數
- 若第一個引數應排在第二個之後，則回傳正數
- 若元素的順序應維持不變，則回傳`0`

舉例來說，可以使用下列的比較函式來排序數字。

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
