## 各月份

首先登場的是 Functional February，我們會一起探索函式式語言！我們剛做好這個月的主題介紹影片，我自己超期待深入鑽研。函式式語言非常有趣又好玩，能教你很多東西。函式式語言有很多，如果你不知道從哪裡開始，我們特別推薦你試試 Elixir、F# 或 Gleam。

接著是 Mechanical March，我們會看看比較偏系統程式設計的語言，例如 C++、Go 或 Nim。這類語言通常會編譯成機器碼，可能會有記憶體管理需要你傷腦筋，或是讓你思考程式碼是怎麼被執行的。它們能讓你稍微靠近電腦內部運作的樣子。

Analytical April 我們聚焦在比較偏科學應用的語言。這裡最主要的兩個是 Python 和 Julia，不過我們也有一條很棒的 R 軌道。當然，Python 這類語言可以歸在很多類別，但我們認為現在大多數非初學者學它，是著眼於它作為資料科學技術的價值，所以就把它放在這個月！

五月會很有趣，我們把它叫做 Mindshifting May！我們要介紹一些做法很不一樣的語言。我們最喜歡的例子是 Prolog，它是一種相當獨特的程式設計方式，不過我們也會看看 Rust、TCL，以及 Unison，這是一個非常新的語言，對分散式程式設計採取了不同的做法，讓我們既期待又好奇。

到了六月，我們採用北半球的命名方式，把這個月叫做 Summer of Sexps。我們會探索以運算式為基礎的語言，特別聚焦在 Common Lisp 和 Clojure，這是 Exercism 上兩個很棒的軌道！如果你從沒試過 Lisp，這會是對你來說非常有趣的一個月。你不但不會再害怕那些括號，反而會開始欣賞它們！

進入七月，我們要走復古路線，迎接 Jurassic July。我們會探索古老的語言，也就是那些為我們今日所知的程式設計奠定基礎的語言。想想 Fortran、COBOL、VB 和 C。如果你算是程式設計的新手，看到以前的寫程式方式可能會讓你又好奇又震驚！

八月這個月會包含大家都很熟悉的語言，因為我們要聚焦在打造網站和 App。我們會看看 JavaScript、Kotlin 和 Swift 這類語言，也會看一些比較少人用的，例如 Dart。我們也會認識像 ABAP 這種用於非常特定用途的語言。

Slimline September 聚焦在那些只要打很少的字就能做很多事的語言，也就是大家可能拿來玩 code golf 的那種語言！想想 Perl、AWK、JQ 和 Bash。這些語言第一次用可能會覺得有點深奧，但只要你願意花心力去學，它們是超級強大的生產力工具，對你的腦袋來說也很有探索的樂趣！

第 10 個月是 Object Oriented October。我們會探索非常著重物件導向程式設計的語言，像是 Ruby 和 C#，以及比較少人知道的 Crystal 和 Pharo。如果你一直想深入探索 OOP，這個月就是為你準備的！

我們最後一個主題月份是 Nibbly November，這個月專門獻給最低階的語言，你會在其中操作位元和位元組。我們聚焦兩種語言：x86-assembly，這個語言很可能支撐著你現在用來觀看影片的硬體；以及 WebAssembly，它是新崛起的角色，能讓你用網頁瀏覽器執行任何程式語言。這不會是輕鬆的一個月，但完成後的成就感可能是最棒的！

最後我們來到 December Diversions。這些是我們沒辦法塞進其他任何地方的語言！像是 Groovy、Lua 和 Wren。你可以把這個月當作自由選項，任你挑選喜歡的語言，風風光光地為這一年收尾！
