# 指令附錄

## 本練習的專屬指令

如果想來點不一樣的，也可以試試看使用 `unfold` 函式的解法。你應該已經熟悉 `foldLeft/Right`：把整個集合「map」成另一樣東西（通常不是集合）。`unfold` 則是相反的操作：把某樣東西（通常不是集合）「map」成一個集合。所以 `unfold` 可說是函式式程式設計標準工具組中順理成章的一員。

這個練習可以看作是 `unfold` 的一個例子：把一個 `Int`「map」成一個 `String`（當然，它隱含就是一個 `Seq[Char]`）。

Scala 的集合從 2.13 版開始就提供了這個操作，例如 [`List.unfold`][list] 和 `Iterator.unfold`。它接收一個起始狀態，以及一個會回傳下一個元素和下一個狀態的函式；若回傳 `None` 就停止：

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
