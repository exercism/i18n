# 關於

C# 中的布林值是以`bool`型別表示，其值可以為`true`或`false`。

C# 支援 4 種[布林運算子][operators]：`!`（NOT）、`&&`（AND）、`||`（OR）和`^`（XOR）。`&&`和`||`運算子使用_短路求值_，這表示運算子的右側只會在需要時才求值。

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

這 3 個布林運算子各有不同的[_運算子優先順序_][precedence]。因此，它們的求值順序如下：先`not`，再`&&`，然後`^`，最後`||`。如果你想「避開」這些規則，可以將布林運算式用括號（`()`）括起來，因為括號具有更高的運算子優先順序。

```csharp
!true && false   // => false
!(true && false) // => true
```
