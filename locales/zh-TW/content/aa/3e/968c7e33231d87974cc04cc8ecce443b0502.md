# 指令附加說明

## 暫存器

| 暫存器  | 用途     | 型態    | 說明                                                      |
| -------- | --------- | ------- | --------------------------------------------------------- |
| `$a0`    | 輸入     | 位址 | 以 null 結尾的輸入字串                              |
| `$v0`    | 輸出     | 布林 | 輸入字串的括號是否匹配（`0` = `false`，`1` = `true`） |
| `$t0-9`  | 暫存 | 任意     | 用於暫存                                |
