# 關於

ABAP 支援數值常用的算術運算子：

- `+`將值相加。
- `-`將值相減。
- `*`將值相乘。
- `/`將值相除。
- `MOD`回傳整數除法的餘數。

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

乘法與除法會先於加法與減法進行運算。當計算需要明確分組時，請使用括號。

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
