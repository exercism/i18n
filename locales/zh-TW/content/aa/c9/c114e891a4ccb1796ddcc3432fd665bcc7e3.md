# 建立 Analyzer

首先，感謝你有興趣建立 Analyzer！

以下是開始的步驟：

1. 先查看[我們的儲存庫清單，確認是否已有現成的 `...-analyzer`](https://github.com/search?q=org%3Aexercism+analyzer&type=repositories)。
2. 瀏覽[這個目錄的內容](/docs/building/tooling/analyzers)，確認你對建立 Analyzer 這件事已經有足夠的了解。
3. 在 [Exercism 論壇][building-exercism] 發一篇新主題，告訴我們你想為哪個程式語言建立 Analyzer。
4. 等到有人為你建立好 Analyzer 的儲存庫之後，可以參考 [Analyzer 介面](/docs/building/tooling/analyzers/interface)與[最佳實務](/docs/building/tooling/best-practices)文件，協助你進行實作。

我們有一群非常友善、樂於相助的社群，在你完成這項工作的過程中，他們會很樂意幫助你！
如果卡住了，請在 [Exercism 論壇][building-exercism] 發一篇新主題，或視需要到 [exercism/exercism][exercism-repo] 建立新的 issue 🙂
