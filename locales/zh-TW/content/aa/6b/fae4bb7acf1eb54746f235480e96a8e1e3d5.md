# 關於

條件式是一種敘述，會根據條件的結果是`true`還是`false`，執行不同的程式碼。

[`if`敘述][if_statement]只會在條件為`true`時執行它的內容。
Go 沒有 truthy 或 falsy 值的概念，所以條件必須是`bool`型別。
像`if mySlice { ... }`或`if 1 { ... }`這類運算式會造成編譯錯誤。

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

用`else if`檢查更多條件，如果都不符合，再用`else`作為備援。
條件會由上而下依序判斷，只有第一個條件為 true 的分支會執行。

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

一般來說，Go 偏好針對例外情況提早回傳，並避免使用`else`。

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

`if`敘述也可以包含一段簡短的初始化敘述。
這常用來在呼叫之後立刻檢查錯誤：

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

在初始化敘述中宣告的變數，作用域只涵蓋整個`if`/`else`鏈。
特別值得一提的是，Go 沒有三元運算子，這是刻意的設計選擇，讓程式碼更容易掃視閱讀。

想了解更多，請參考 [Go by Example: If/Else][go_by_example_if]。
