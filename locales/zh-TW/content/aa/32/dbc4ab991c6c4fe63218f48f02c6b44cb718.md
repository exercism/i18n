# 關於

`awk`是一門由翻譯員執行的程式語言，專門設計來處理文字，通常用來擷取資料與產生報表。
它是大多數類 Unix 作業系統的標準功能，並有[POSIX 規範][posix]。

`awk`的程式設計範式可以說是「資料驅動」：
`awk`程式會讀取一行行的文字（或其他文字單位），然後尋找*模式*的相符結果。
一旦比對成功，就會執行指定的*動作*。

`awk`程式大致長這樣：
```awk
pattern1 {action1}
pattern2 {action2}
...
```

*模式*可以是正規表示式，也可以是其他評估結果為 true/false 的運算式。
*模式*可以省略，此時會對每一筆文字記錄執行*動作*。
*動作*也可以省略，此時預設動作是印出目前的記錄。

`awk`是使用者工具箱裡的絕佳幫手。
它非常適合寫成簡短的「單行」程式，直接從命令列輸入。
一個`awk`程式就能取代大多數由`grep`、`sed`、`tr`、`cut`組成的管線。

## 實作

`awk`在 1977 年由 Alfred Aho、Peter Weinberger 與 Brian Kernighan 發明（這門語言的名稱正是取自他們三人的姓氏）。
這個實作後來被稱為「old awk」。
1985 年推出了改良版本，稱為「BWK awk」、「new awk」，或「the one-true-awk」。
macOS 以及部分 \*BSD 發行版隨附的就是這個版本。

另一個常見的實作是`mawk`，它以位元組碼翻譯員為基礎。
`mawk`的速度非常快。
在許多 Linux 發行版上，`mawk`是預設隨附的`/usr/bin/awk`。

### GNU awk

這條學習軌道會採用`gawk`，也就是 GNU 的 awk 實作。
`gawk`或許沒有`mawk`那樣的極致速度，但功能非常豐富、說明文件完善，還有一些方便的命令列選項。

### Shebang

視平台而定，只要在檔案開頭加上一行 [shebang][shebang]，就能執行 awk 指令碼。
在大多數系統上，下面這兩種 shebang 應該有一種能用。
不過，由於沒有哪一種 shebang 能適用於所有系統，我們選擇省略 shebang。

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
