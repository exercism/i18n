# 測試

下載練習時，會一併取得以下這些用來建置與測試解答的檔案：

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

檔名會因練習而異。
把你的解答寫在第一個`.vb`檔案裡。
第二個以`Tests.vb`結尾的檔案是 [xUnit 測試套件][xunit]。
一般來說，你只會為了取消略過後續的測試才編輯這個檔案。
最後兩個檔案你都不需要編輯。
`.vbproj`檔案包含專案的建置設定與直接的套件參考。
產生的`packages.lock.json`檔案則記錄了解析後的直接與間接套件版本。

~~~exercism/note
測試描述了通過的解答必須滿足的行為。
它們能協助釐清指示沒有涵蓋的細節。
~~~

## 執行測試

在練習目錄中開啟終端機，然後執行：

```bash
dotnet test
```

這個指令會還原專案的相依性、建置專案，並執行它的測試。
你也可以使用`dotnet watch test`，在每次原始碼檔案變更時重新執行測試。

## 略過的測試

練習一開始只會啟用第一個測試，讓你一次一步解完其餘的測試。
打開以`Tests.vb`結尾的檔案，就能找到這些測試。
每個測試都是一個以 xUnit 的`<Fact>`屬性標記的`Sub`副程式。
只要測試的`<Fact>`屬性帶有`Skip`引數，該測試就會被略過：

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

如要啟用該測試，只要移除`Skip`引數即可：

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

新啟用的測試通過後，就對下一個被略過的測試重複同樣的步驟。
當所有測試都已啟用並通過時，你就完成了！
