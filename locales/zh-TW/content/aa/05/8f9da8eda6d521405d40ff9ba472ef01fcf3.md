# 在命令列上測試

用以下指令執行測試：

```bash
$ cargo test
```

除了第一個測試之外，其餘的測試預設都會被忽略。在你讓第一個測試通過之後，打開位於`tests`目錄中的測試原始碼檔案，移除下一個測試的`#[ignore]`標記，然後再讓測試通過一次。每個獨立的測試都是一個函式，上方帶有`#[test]`標記。持續這個過程，直到所有測試都通過為止。

如果你想在不編輯測試原始碼檔案的情況下，只執行_被忽略的_測試，請使用：

```bash
$ cargo test -- --ignored
```

如果你使用的是 Rust 1.51 或之後的版本，可以用以下指令執行_所有_測試：

```bash
$ cargo test -- --include-ignored
```

想執行特定的測試，例如`some_test`，可以使用：

```bash
$ cargo test some_test
```

如果該特定測試被忽略了，請使用：

```bash
$ cargo test some_test -- --ignored
```

想進一步了解 Rust 測試，請參閱線上的[測試說明文件][rust-tests]。

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
