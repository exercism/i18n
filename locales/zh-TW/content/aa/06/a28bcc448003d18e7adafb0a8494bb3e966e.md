# 測試在本機通過，線上卻失敗？

有時候，你的測試在本機電腦上可以通過，線上卻不行。

這通常有幾個原因：

## 你還沒有取消略過所有測試

許多 Exercism 練習都會略過部分測試。
這樣設計的目的，是讓你依序解開每一個測試，每解完一個就取消略過下一個。
等到你完成整個練習時，所有測試都應該已經取消略過並通過，你也會得到一份完整可用的解答。
請查看[你正在學習的路徑](/docs/tracks)的說明文件，了解該語言的略過機制細節。

我們在線上執行測試時，會先取消略過所有測試。
如果你在本機沒有全部取消略過，我們就可能會發現一些你沒考慮到的邊界案例，測試也就會失敗。

## 我們和你使用的版本不同

Exercism 的測試執行器使用特定的語言版本。
那不一定是最新版本的語言，因為每當有新版本發布時，我們都必須手動更新測試執行器。

如果測試在線上失敗，請查看輸出內容（點擊「Failed」字樣），並試著找出可能出錯的地方。
如果你判斷問題出在版本不符，請到 GitHub 上相關的測試執行器儲存庫開一個 issue。
那類儲存庫的命名通常遵循`https://github.com/exercism/$SLUG-test-runner`這個模式（例如`https://github.com/exercism/ruby-test-runner`）。
