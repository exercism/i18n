# 簡介

在 Elixir 中，我們可以定義模組屬性，並將它們當作常數用在函式裡。

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

當用來定義模組常數時，模組屬性的值可以是任何能在編譯期求值的運算式。編譯完成後就無法再存取模組屬性，因為它們在編譯期間就會被展開，這點與 C 這類語言中定義的巨集類似。
