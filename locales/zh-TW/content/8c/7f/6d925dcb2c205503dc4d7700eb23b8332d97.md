# 簡介

`call`（在 [`kernel`][kernel] 中）會執行一個 quotation。當 quotation 的堆疊效應無法推斷時（通常是因為這個 quotation 來自其他地方），就要在 `call` 上明確宣告效應：

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

因為 quotation 是值，陣列可以混合裝著數字和 quotation，讓「程式」就只是另一種序列：

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
