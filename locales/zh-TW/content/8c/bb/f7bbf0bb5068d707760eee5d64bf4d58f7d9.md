# 安裝

## 安裝 R 執行環境
前往 [CRAN 首頁](https://cran.r-project.org/)。在那裡你可以找到 Linux、Mac OSX 和 Windows 的下載連結。下載並執行適合你的作業系統的安裝程式。

## 安裝 RStudio IDE（推薦）
RStudio 是熱門的跨平台整合開發環境（IDE），可用來撰寫 R 程式（也支援 Python、JavaScript 和 Markdown 等其他語言）。使用 RStudio 會讓你更容易撰寫程式碼解答和執行測試。

下載並安裝[目前的 RStudio 穩定版](https://www.rstudio.com/products/rstudio/download/)。或者，你也可以取得即將發布版本的[預覽版](https://www.rstudio.com/products/rstudio/download/preview/)。

## 安裝 Visual Studio Code 的 R 擴充功能（替代方案）
Visual Studio Code 的 R 擴充功能支援更豐富的語法突顯、程式碼自動補完、程式碼檢查、格式化、與 R 終端機互動、檢視資料、圖表、工作區變數與說明頁面，以及管理套件和處理 R Markdown 文件。

下載並安裝[最新版的 R 擴充功能](https://code.visualstudio.com/docs/languages/r)

## 安裝用來執行測試的 R 套件
用來執行規格測試的測試執行器，是 Hadley Wickham 的 [`testthat`](https://github.com/hadley/testthat) 套件，這是許多 R 套件作者常用的選擇。

要安裝這個套件，請在 RStudio 主控台（或你使用 R 的任何地方）輸入以下內容。

```{R}
install.packages("testthat")
```

雖然解 Exercism 的練習時，你不太可能*需要*安裝額外的套件，但你可能會想引入像是 [`tidyverse`](https://github.com/tidyverse/tidyverse) 這類符合你程式設計風格的通用工具套件。要安裝並載入像 `tidyverse` 這樣的套件：

```{R}
install.packages("tidyverse")
library(tidyverse)
```
