# 陣列方法

陣列是常見的資料結構。
因此，有一系列方法可以用來處理陣列。
其中包含排序、反轉、插入等許多操作。

有些方法是破壞性的，這表示它們會修改原始陣列。
其他方法則是非破壞性的，也就是說它們會回傳一個新陣列，不會修改原本的陣列。

以下是處理陣列時最常用到的幾個方法：

## insert

當你要在陣列中插入元素時，可以使用 [`insert`][insert]方法，它接受一個索引和一個元素作為引數。
元素會被插入到指定的索引位置，陣列其餘的部分則會向右移動。
如果索引超出範圍，就會引發`IndexError`。

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

當你想從陣列中刪除特定的元素時，可以使用 [`delete`][delete]方法，它接受一個元素作為引數。
這個方法會回傳被移除的元素。
如果元素不存在於陣列中，則會回傳`nil`。

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first 與 last

當你想取得陣列的第一個或最後一個元素時，可以使用 [`first`][first]和 [`last`][last]方法。
這些方法接受一個選用引數，用來指定要回傳多少個元素。
相較於使用索引`0`或`-1`，或使用範圍，這樣可以提升可讀性。
如果陣列是空的，就會引發`Enumerable::EmptyError`。

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

當你想反轉陣列時，可以使用 [`reverse`][reverse]方法，它會回傳一個元素順序相反的新陣列。
要注意的是，`reverse`會回傳新陣列，並不會修改原本的陣列。
如果你想修改原本的陣列，可以在方法名稱結尾加上`!`。

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat（`+`）

當你想把物件加入陣列時，`<<`這個附加方法很好用。
不過，當要合併兩個陣列時，可以使用 [`+`][concat]運算子，它會回傳一個包含兩個陣列元素的新陣列。

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

如果你把一個陣列附加到另一個陣列，該陣列會以單一元素的形式加入。

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

當你要檢查陣列是否為空時，可以使用 [`empty?`][empty?]方法，如果陣列是空的就回傳`true`，否則回傳`false`。
相較於用`0`來檢查陣列長度，這樣可以提升可讀性。

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

當你想取得陣列中某個元素的索引時，可以使用 [`index`][index]方法，它接受一個元素作為引數。
如果元素不存在於陣列中，則會回傳`nil`。

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

當你想知道陣列中有多少個元素時，可以使用 [`size`][size]方法。

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

當你想計算某個元素在陣列中出現的次數時，可以使用 [`count`][count]方法。

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

當你想排序陣列時，可以使用 [`sort`][sort]方法，它會回傳一個元素已排序的新陣列。
和`reverse`一樣，這個方法會回傳新陣列，並不會修改原本的陣列。

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
