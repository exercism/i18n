# 說明

如果你想要用 Raspberry Pi 打造一些東西，你很可能會用到_電阻_。在這道練習中，你需要知道關於電阻的兩件事：

- 每個電阻都有一個電阻值。
- 電阻很小。小到如果你把電阻值印在上面，會很難辨識。

為了解決這個問題，製造商會在電阻上印上以顏色編碼的色帶，用來表示它們的電阻值。每個色帶都有一個位置和一個數值。

電阻的前 2 個色帶採用簡單的編碼方式：每種顏色對應到一個數字。

第三個色帶是乘數。

在這道練習中，你將建立一個實用的程式，讓你不必記住各個色帶的數值。

關於電阻顏色編碼的更多資訊，可以參考[維基百科的電子色碼條目][e-color-code]。

## 1. 定義具名向量

顏色的編碼方式如下：

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

建立具名向量 `resistor_bands`，其中顏色為名稱，數字為值。

## 2. 回傳某個色帶對應的值

首先，你需要能夠找出任一顏色色帶的單一數值。

定義一個函式 `band_value(band)`，它接收一個代表色帶顏色的`字串`。這個函式會回傳該顏色對應的值。

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. 回傳兩個色帶組合後的值

電阻上的前兩個色帶會組合成一個數字。如果前兩個色帶的數字分別是 `m` 和 `n`，它們會組合成數字 `mn`。

定義一個函式 `two_band_value(bands)`，它接收一個裝有兩個色帶顏色的`vector`，其中每個元素都是`string`。這個函式會回傳這兩種顏色組合後對應的值。

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. 回傳三個色帶組合後的歐姆值

最後，你需要讓前兩個色帶搭配第三個色帶，求出完整的歐姆值。為此，你需要找出雙色帶值和乘數。乘數可以想成是在雙色帶值後面加上幾個零。

定義一個函式 `ohms(bands)`，它接收一個裝有三個色帶顏色的`vector`，其中每個元素都是`string`。這個函式會回傳這三種顏色組合後對應的歐姆值。

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
