## 基礎 2

### 匯出函式

匯出函式在第一個概念中介紹過了，這裡快速複習一下。

Elm 中的每個檔案都是一個模組，而且必須在所有其他程式碼之前包含一個`module`敘述。

模組名稱必須與檔案名稱相符，所以模組`Calculator`必須放在 Calculator.elm 檔案中，而模組`Parser.Utils`則需要放在 Parser/Utils.elm 檔案中。

模組內定義的任何東西都是該模組私有的，無法從這個模組外部存取，除非列在`exposing`中。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### 從其他模組匯入函式

要存取定義在其他模組中的函式，需要透過匯入來完成。
匯入該模組時，所有由它匯出的函式都會變成可存取的。
但存取它們的方式會依匯入模組的方式而有所不同。

限定匯入是預設方式，要存取這類模組中的函式（例如`List`模組中的`map`函式），需要在前面加上模組名稱（`List.map`）。

開放匯入則可以直接存取該模組中匯出的函式，不需要加上前綴。它們是透過`exposing`關鍵字完成的，就像是匯出時所用關鍵字的鏡像。你可以匯出所有可用的函式（使用`..`），或是特定的函式（例如`map`）。

你也可以從其他模組匯入型別及其建構子，這會是之後的概念。

建議優先使用限定匯入，以幫助維持清晰並避免名稱衝突。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### 型別註解

型別註解是用`name : parameter types -> return type`定義的，參數型別之間也用`->`分隔。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

括號可以用來定義函式參數（參數本身也是用相同的語法定義，所以才需要括號）。

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### 數字

Elm 中有兩種可用的數字型別，分別由`Int`和`Float`型別定義。
`Int`對應到正整數與負整數的集合。
`Float`對應到實數的集合，受限於電腦的精確度。
定義在數字上的運算通常只適用於其中一種型別，不能混用。
有些函式可以在兩者之間轉換，例如`toFloat`會將`Int`轉成`Float`，而`round`、`floor`、`ceiling`或`truncate`則會以不同的語意將`Float`轉成`Int`。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### 字串操作

若要在程式碼中描述單字和句子，Elm 有原生的`String`型別。
字串常值寫在雙引號之間，例如`"Hello World!"`。
預設可以使用字串串接運算子`++`和相等運算子`==`。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

大多數其他的字串函式都在`String`模組中，需要先匯入。

https://package.elm-lang.org/packages/elm/core/latest/String
