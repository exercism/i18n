# https://www.php.net/manual/en/language.basic-syntax.phptags.php"範圍解析運算子

範圍解析運算子（`::`）讓我們可以參照類別，以存取它的名稱常數、靜態屬性或靜態方法。

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## 搭配範圍解析運算子使用`self`與`static`

物件可能需要參照自己的範圍。為了做到這點，`self`關鍵字讓類別可以參照自己的範圍。使用`self`關鍵字能將類別與自己的名稱解耦，讓程式碼隨時間更容易維護。

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

不過，`self`在詞法上會綁定到它所出現的類別。

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

評估`MyOtherClass::getMyValue`仍然會得到`1`，而不是`99`。為了解決這個問題，請將`static`關鍵字搭配範圍解析運算子使用，把參照「延遲綁定」到目前的子系類別。

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## 搭配範圍解析運算子使用`parent`

有時會需要特別參照父範圍中可用的常數、屬性或方法：

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

在物件導向程式設計中，最常見的情況是用`parent`在建立物件時呼叫父類別的建構函式：

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 注意事項

### 常數、屬性與方法的可見性

範圍解析運算子仍然遵循`public`、`private`與`protected`這些可見性修飾詞所制定的規則。
