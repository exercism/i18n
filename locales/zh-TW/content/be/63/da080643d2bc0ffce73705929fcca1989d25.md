# 關於

`List`和[`Array`][array]非常相似。不過，有些重大差異你可別錯過喔：

1. List 不能使用方括號來索引，也就是`[0]`。
2. List 無法初始化。
3. 沒有 List 推導式。
4. List 可以在疊代時自由修改元素。

`List`是`haxe.ds`套件裡的成員，所以每次想使用 List 時，都需要匯入這個套件：

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
