# 指令

在這個練習中，你會用到儲蓄帳戶。每年，儲蓄帳戶的餘額會根據利率更新。銀行提供的利率取決於帳戶裡的金額（也就是餘額）：

- 餘額非負且小於`1000`美元：0.5%。
- 餘額為正、大於等於`1000`美元且小於`5000`美元：1.621%。
- 餘額為正且大於等於`5000`美元：2.475%。
- 餘額為負（會產生負利息）：3.213%。

你有三個任務，每個任務都會處理餘額和它的利率。

## 1. 計算利率

實作 `SavingsAccount.interest_rate` 方法，根據指定的餘額計算利率：

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

注意，回傳的值是 `Float` 的實例。

## 2. 計算年度餘額更新

實作 `SavingsAccount.annual_balance_update` 方法，將利率納入考量，計算年度餘額更新：

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

注意，回傳的值是 `Float` 的實例。

## 3. 計算達到期望餘額所需的年數

實作 `SavingsAccount.years_before_desired_balance` 方法，計算達到期望餘額所需的最少年數：

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

注意，回傳的值是 `Integer` 的實例。
