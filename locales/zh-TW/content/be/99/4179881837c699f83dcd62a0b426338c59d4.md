# 安裝

只要下載 Scarb 就能安裝 Cairo。Scarb 把 Cairo 編譯器和 Cairo 語言伺服器打包成一個容易安裝的套件，讓你馬上就能開始寫 Cairo 程式碼。Scarb 同時也是 Cairo 的套件管理器。

想取得適合你所用平台的建議安裝指示，請前往 [Cairo 官方網站](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/)。

依作業系統分類：

- Linux/MacOS
    1. 安裝 [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. 安裝 [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. 在新的終端機工作階段中執行`scarb --version`，確認安裝成功
- Windows
    1. 安裝 [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. 在新的終端機工作階段中執行`scarb --version`，確認安裝成功

裝好工具鏈並不代表一切！IDE 支援能大幅提升生產力，這也是大多數開發者已經習以為常的事。
如果你使用 Visual Studio Code，我們建議你安裝 [Cairo 擴充功能](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1)，它提供語法突顯、程式碼自動完成，以及其他實用的功能喔！
