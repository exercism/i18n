# 簡介

在 Haxe 中，抽象型別是一種在執行階段會是另一種型別的型別。它是一項編譯階段特性，能在具體型別「之上」定義型別，以修改或擴充其行為：

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

這裡我們使用`abstract`關鍵字宣告`AbstractInt`型別。它的語法與`class`非常相似。就像類別一樣，抽象型別也可以擁有方法。它們也能像類別一樣被實例化與使用：

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
