# 提示

## 1. `weigh-crate`

- `sequences`裡的某個單字就能做到喔。

## 2. `weigh-all`

- `parallel-map`（位於[`concurrency.combinators`][combinators]）的形狀和`map`一樣：傳入一段引述，把一個板條箱轉換成一個重量。

## 3. `<crane>`

- `crane`這個 tuple（欄位有`lock`和`tonnage`）已經在練習檔案中宣告好了。
- 鎖的欄位使用`<lock>`（位於[`concurrency.locks`][locks]），起始噸位則用`0`。`boa`會依欄位順序，從堆疊上的值建構出一個 tuple。

## 4. `hoist-crate`

- `with-lock ( lock quot -- )`會在持有鎖的情況下執行引述。這段引述需要讀取起重機的噸位、加上`weight`，再把結果存回去。`change-tonnage`（由`TUPLE:`自動產生）正好用一個字就能完成這段讀取、修改、寫回的步驟。
- 區域變數能讓這段程式碼更好讀：`:: hoist-crate ( weight crane -- )`讓你能在鎖的區塊內引用`weight`和`crane`。

## 5. `crane-tonnage`

- 讀取時也需要鎖，這樣一來，當你觀察時，進行中的寫入就不會只完成一半。

## 6. `load-cargo`

- 為每個板條箱建立一個`<promise>`，並`spawn`一個執行緒，讓它秤出板條箱的重量、把它吊起，然後`fulfill`這個 promise。被 fulfill 的值可以是任何東西，例如一個哨兵值，因為這個 promise 只用來表示工作已完成。
- 在 spawn 的同時，把這些 promise 收集成一個序列（區域變數能讓這件事寫得簡潔俐落；搭配 lambda 的`map`也很好用）。
- 所有執行緒都 spawn 完之後，走訪這個 promise 序列，逐一呼叫`?promise`。`?promise`會阻塞，直到該執行緒完成，因此當最後一個回傳時，每一次吊掛都已經完成了。
