# 說明

在這個練習中，你要寫一些程式碼，幫你依照最愛的食譜做出美味的千層麵。

你有四個任務，全都和烹煮千層麵所花的時間有關。

~~~~exercism/note
你可以使用型別推斷，也就是不指定任何型別；也可以明確指定型別。如果選擇後者，請使用`int`作為型別。
~~~~

## 1. 定義預期的烤箱時間（分鐘）

定義`expectedMinutesInOven`繫結，用來確認千層麵應該在烤箱裡烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```fsharp
expectedMinutesInOven
// => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remainingMinutesInOven`函式，它接受千層麵已經在烤箱裡的實際分鐘數作為參數，並根據上一個任務算出的預期烤箱時間，回傳千層麵還需要留在烤箱裡幾分鐘。

```fsharp
remainingMinutesInOven 30
// => 10
```

## 3. 計算準備時間（分鐘）

定義`preparationTimeInMinutes`函式，它接受你加進千層麵的層數作為參數，並回傳你花了幾分鐘準備千層麵，假設每一層要花 2 分鐘準備。

```fsharp
preparationTimeInMinutes 2
// => 4
```

## 4. 計算經過的時間（分鐘）

定義`elapsedTimeInMinutes`函式，它接受兩個參數：第一個參數是你加進千層麵的層數，第二個參數是千層麵已經在烤箱裡的分鐘數。這個函式應該回傳你花了多少分鐘烹煮千層麵，也就是準備時間（分鐘）加上千層麵目前為止待在烤箱裡的分鐘數。

```fsharp
elapsedTimeInMinutes 3 20
// => 26
```
