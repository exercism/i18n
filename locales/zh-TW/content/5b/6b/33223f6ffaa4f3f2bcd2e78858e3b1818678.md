# 簡介

PowerShell 是 Microsoft 推出的動態、隱含型別的指令碼語言（_但也支援[強型別][strong typed]變數_），主要用於工作自動化與設定管理。

PowerShell 支援指令式、函式式、物件導向，甚至管線風格的程式設計。

PowerShell 建構於 .NET 平台上，並於 2006 年首次發布。
現今所有 Windows 作業系統預設都包含它，也可以在 Mac 和 Linux 上安裝。


## 變數

在 PowerShell 中，定義變數有兩種常見的方式。

PowerShell 中的變數名稱必須以 `$` 開頭，並使用賦值運算子 `=` 把變數名稱綁定到某個值。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

你也可以明確指定變數的型別，如果你想要強制要求值必須是某種型別的話。
PowerShell 會盡可能嘗試把值從一種型別轉換成另一種。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### 常數

PowerShell 中的常數是一種變數，定義之後既不能**更改**，也不能**移除**。
這就帶出定義變數的第二種方式：使用 `New-Variable` 這個 cmdlet。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

想了解更詳細、更進階的新增變數方式，請參閱 [New-Variable][New-Variable]。


## 函式

PowerShell 中的[函式][functions]使用 `function` 關鍵字定義。
每個函式可以在 `()` 括號中帶有零個或多個正式參數，接著是以 `{` 開頭、以 `}` 結束的函式範圍。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell 中的函式可以在使用 `FuncName $Arg` 語法呼叫之後，透過 `return` 關鍵字明確地回傳值。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

如何撰寫詳細的函式定義，以及函式如何隱含地回傳值，這些進階內容會在 `Functions` 概念模組中介紹。


## 註解

PowerShell 中的單行註解以 `#` 開頭，到行尾為止。
PowerShell 中的註解區塊以 `<#` 開頭，以 `#>` 結束。
用註解區塊建立 Comment-Based Help 的進階示範，會在 `Functions` 概念模組中介紹。

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
