# 指令

在這個練習中，你會模擬一套以視窗為基礎的電腦系統。
你會建立一些可以移動和調整大小的視窗。

## 1. 定義程式視窗的屬性

使用提供的類別骨架，為 `y`、`x`、`height` 和 `width` 值定義屬性。

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. 定義程式視窗的初始值

為 `ProgramWindow` 定義一個建構函式。
它不應該接受任何引數，但在建構函式執行期間，要設定其屬性的預設值。
它應該將 `y` 和 `x` 的初始值設為 `0`。
它應該將 `height` 和 `width` 的初始值設為 `600x800` 的螢幕尺寸。

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. 定義調整視窗大小的函式

在`Size.php`中定義一個新的 Size 類別。
它應該接受建構函式的引數，用來設定 `height` 和 `width` 屬性。
此外，`ProgramWindow` 還需要一個調整大小的函式，它會接收 `Size` 物件實例並更新自身的屬性。

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. 定義移動視窗的函式

在`Position.php`中定義一個新的 Position 類別。
它應該接受建構函式的引數，用來設定 `y` 和 `x` 屬性。
此外，`ProgramWindow` 還需要一個移動的函式，它會接收 `Position` 物件實例並更新自身的屬性。

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
