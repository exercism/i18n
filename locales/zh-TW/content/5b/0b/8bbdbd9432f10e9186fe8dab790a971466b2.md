# 指示

柏林的新機場為了他們的機器人實驗室招募了開發者，而你即將在那裡開始上班。
他們有一些笨重、外型有點像人形的機器人，他們正試著用這些機器人來改善客戶服務。

你上班後的第一項任務，就是寫一支程式，讓機器人在旅客於自助報到櫃檯掃描護照之後，能用旅客的母語問候他們。

這台機器人對自己的能力很自豪，所以它總是會先說自己會說哪種語言，然後再問候對方。
舉例來說，如果有人掃描的是德國護照，機器人就會說：

```txt
I can speak German: Hallo Dietrich!
```

## 1. 建立抽象的問候功能

你不需要自己撰寫各種語言的程式碼，所以你得先把機器人的程式碼結構設計好，讓其他開發者之後能輕鬆加入更多語言。

第一步，定義一個介面 `Greeter`，裡面有兩個方法。

- `LanguageName`：回傳機器人應該用來問候訪客的語言名稱（`string`）。
- `Greet`：接受訪客的名字（`string`），並回傳帶有特定語言問候訊息的`string`。

接著，實作一個函式 `SayHello`，它接受訪客的名字，以及任何實作了 `Greeter` 介面的東西作為引數，並回傳想要的問候字串。
舉例來說，想像一個德文的 `Greeter` 實作，它的 `LanguageName` 會回傳 `"German"`，而 `Greet` 會回傳 `"Hallo {name}!"`：

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. 實作義大利文

現在，你的任務是讓機器人也能為掃描義大利護照的人服務。

為此，建立一個 struct `Italian`，並實作兩個方法，讓這個 struct 能滿足你在任務 1 建立的 `Greeter` 介面。
用義大利文問候別人時，可以說 `"Ciao {name}!"`。

## 3. 實作葡萄牙文

在你收工之前，還得完成用葡萄牙文問候別人的功能。

為此，建立一個 struct `Portuguese`，並同樣實作讓這個 struct 能滿足 `Greeter` 介面所需的兩個方法。
用葡萄牙文問候別人時，可以說 `"Olá {name}!"`。
