# 簡介

Factor 是一種*串接式*語言：每個詞都會從共用的**資料堆疊**讀取輸入，再把輸出推回堆疊上。要傳遞值，沒有其他方法。

寫下一個字面值會把它推入堆疊頂端；程式碼由左至右讀取：

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

*堆疊效果*宣告記錄了一個詞的合約：

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` 表示這個詞會取出兩個值，並以相反的順序留下兩個值。名稱只是說明，編譯器只會檢查輸入與輸出的*數量*，而堆疊頂端對應的是最右邊的名稱。

日常使用的`kernel`**重排詞**會重新排列堆疊頂端的值：

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

詞用`:`定義，並以`;`結尾；編譯器會拒絕本體與宣告效果不符的定義。
