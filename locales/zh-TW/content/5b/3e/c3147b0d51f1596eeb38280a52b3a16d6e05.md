# 提示

## 一般

- 閱讀官方指南中關於[模式比對][pattern-matching]的內容吧。
- 來看看這份關於[解構][destructuring]的速查表吧。
- 記錄的模式比對在[這裡][records-pattern-matching]有更詳細的說明。

## 1. 偵測空留言

- 如果引數是配對，你可以直接在函式引數中使用`(a, b)`。
- 你可以用萬用字元`_`取代收到但用不到的值。
- 要檢查字串是否為空，請參閱[`String`文件][string-docs]。

## 2. 計算建立者的留言數量

- 你可以在函式引數中直接解構只有單一變體的自訂型別`type Box = Box AB`，像這樣：`(Box ab)`。
- 你可以用`{ a }`來對記錄`{a : A, b : B}`的欄位`a`做模式比對。
- 對於帶有記錄的自訂型別，你可以同時使用上述兩種技巧。
- 你無法直接從記錄`{ ab : (A, B) }`中對配對`ab`做模式比對。你必須先對`{ ab }`做模式比對，然後在`let`綁定中使用`( a, b) = ab`。
- 要找出陣列中符合條件的元素數量，請使用[`List`函式][list-docs]。
- 你可以直接在匿名函式的引數中解構配對。

## 3. 偵測指派給開發團隊的工單

- 就像任務 2 一樣，你可以在函式引數中比對「裝箱」記錄的相關欄位。
- 你可以使用遞迴模式比對來比對像`Just (Box "42")`這樣的巢狀值。
- 你可以在`case`敘述中使用萬用字元`_`來比對任何東西。

## 4. 將工單指派給 IT 員工

- 就像任務 2 和任務 3 一樣，你可以在函式引數中比對「裝箱」記錄的相關欄位。
- 此外，你可以使用`as`關鍵字來模式比對欄位，同時綁定整個記錄：`(Box ({ a } as ab))`。
- 你可以用`case`敘述對自訂型別的值做模式比對。
- 使用型別建構子`Ticket`來回傳工單。
- 使用[記錄更新語法][record-update]來修改記錄。
