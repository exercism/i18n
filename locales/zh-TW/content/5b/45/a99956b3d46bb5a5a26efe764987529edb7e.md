# 簡介

Factor 用[`calendar`][calendar]詞彙來為日期和時間建立模型。時間上的某個點是 `timestamp`，一段時間的長度則是 `duration`。

## 建立日期

`<date>`（位於 [`calendar`][calendar] 中）會建立一個代表指定日期午夜的 `timestamp`：

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` 則會把 timestamp 拆解回它的各個部分：

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## 檢視日期

`day-of-week` 會以整數回傳星期幾，`0` 代表星期日，`6` 代表星期六。`day-names`（位於 [`calendar.english`][english] 中）是對應的名稱清單，所以 `day-names nth` 能把這個數字變成一個詞：

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` 接受一個年份（或一個 timestamp），而 `days-in-month` 則回傳某個 timestamp 所屬月份的長度，且已經把閏年考量進去：

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## 日期運算

`days`、`weeks`、`hours` 這類詞會建立一個 `duration`，而 `time+` 會把 timestamp 平移一個 duration：

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

運算會正確地跨越月份與年份的界線進位，而兩個指向同一瞬間的 timestamp 用 `=` 比較時會相等。

## 時刻

`<timestamp>` 會建立完整的 timestamp，精確到秒。它的最後一個引數是與 UTC 的時差；`instant`（一個長度為零的 `duration`）會讓 timestamp 維持在 UTC：

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` 是 `>date<` 的對應詞，會把 timestamp 拆成時、分、秒：

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` 和 `minutes` 建立 `duration` 的方式就跟 `days`、`weeks`、`hours` 一樣，所以其中任何一個都可以交給 `time+`：

```
seconds ( x -- duration )
minutes ( x -- duration )
```

timestamp 的各個欄位可以用存取子 `year>>`、`month>>`、`day>>`、`hour>>`、`minute>>` 和 `second>>` 讀取：

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
