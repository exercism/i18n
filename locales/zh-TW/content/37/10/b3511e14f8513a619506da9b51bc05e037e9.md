# 簡介

Go 沒有空、null 或 undefined 這類變數值概念。
沒有明確初始值的變數，會預設為其型別對應的零值。

布林、數值型別和字串等基本型別的零值，分別是 `false`、`0` 和 `""`。

識別字 `nil` 代表零，是較複雜型別的零值，例如指標、函式、介面、切片、通道和映射。

下表列出 Go 各型別的零值。

| 型別 | 零值 |
| --------- | ---------- |
| 布林 | `false` |
| 數值 | `0` |
| 字串 | `""` |
| 指標 | `nil` |
| 函式 | `nil` |
| 介面 | `nil` |
| 切片 | `nil` |
| 通道 | `nil` |
| 映射 | `nil` |

你可能注意到上表沒有列出結構型別。
這是因為結構型別的零值取決於它的欄位。
當結構的所有欄位都設為各自的零值時，這個結構也就會被設為它的零值。
