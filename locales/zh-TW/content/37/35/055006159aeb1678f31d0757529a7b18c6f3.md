# 關於

[元組][tuple]經常用來將資訊分組。元組和陣列不同，它的大小固定，而且可以存放不同的資料型態。
元組使用括號`()`建立，也常用來從函式回傳多個值。

```haskell
tuple = (1, "abc", False)
```

舉例來說，當你想在二維空間中儲存一個座標時，這就很實用，因為你知道這個元組永遠會有兩個元素：x 和 y 座標。

```haskell
coordinate = (3, 4)
```

## 存取元素

你經常會處理短小的元組，這時可以用`fst`和`snd`函式來存取元素。

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
