# 關於

在 Haxe 中，抽象型別是一種在執行時期會變成另一種型別的型別。它是一種編譯時期的功能，用來在具體型別「之上」定義型別，以修改或擴充這些型別的行為：

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

這裡我們用`abstract`關鍵字宣告了`AbstractInt`型別。它的語法和`class`極為相似。而且就跟類別一樣，抽象型別也可以有方法。它們也能像類別一樣被實例化並使用：

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

如前所述，抽象型別是編譯時期的功能。把上面的範例編譯成 JavaScript 後會得到以下結果：

```javascript
var a = 12;
console.log(a)
```

抽象型別`AbstractInt`會完全從輸出中消失。這是因為`Abstract`的建構子被[行內化][inline]了，這點我們之後會再看到。

[inline]: https://haxe.org/manual/class-field-inline.html
