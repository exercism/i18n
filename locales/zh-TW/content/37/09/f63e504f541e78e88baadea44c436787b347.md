# 字串

Crystal 有一種稱為 [`String`][strings] 的型別，用來表示文字。
Crystal 的字串是 Unicode 字元序列。
字串是不可變的，一旦建立就無法修改。
這表示每次修改字串時都會建立一個新的字串，因此原始字串不會被修改。

要定義字串，請使用雙引號 `"`。

```crystal
"Hello World"
```

## 串接

要串接兩個字串，請使用 `+` 運算子。
`+` 運算子會回傳一個結合這兩個字串的新字串。

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## 字串與數字之間的轉換

`to_i`方法會把字串轉換成整數。
或者，你也可以用 `to_f`方法回傳浮點數。
如果字串無法轉換成數字，就會引發 `ArgumentError`。

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

整數或浮點數可以用 `to_s`方法轉換成字串。

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## 內插

內插是結合字串並在字串中嵌入運算式的便利方式。
要內插字串，你可以使用 `#` 字元，後面接著大括號 `{}`，並把運算式放在大括號內。

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal 會自動把運算式的結果轉換成字串。

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## 長度

當你需要知道字串中有多少個字元時，可以使用 `size`方法，它會以整數回傳字串的長度。
字串的長度是字串本身儲存的屬性，所以不必在每次呼叫方法時重新計算，執行速度非常快。

```crystal
"Hello World".size
# => 11
```

## 索引

索引是指從字串中取得特定的字元。
要從 `String` 取得字元，你可以使用熟悉的括號表示法。

~~~~exercism/note
`[]` 是以 `String` 的實體方法實作的，其中索引就是該方法的引數。
~~~~

字串中的第一個字元位於索引 0。

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

要從字串尾端取得字元，你可以用字串長度減一取得最後一個字元的索引，用字串長度減二取得倒數第二個字元，依此類推。
這件事有更簡便的做法，就是直接使用負索引：最後一個字元位於索引 -1，倒數第二個字元位於索引 -2，依此類推。

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### 子字串測試

Crystal 支援用索引檢查字串是否包含某個子字串。
同樣的括號表示法就能做到，只是括號內放的不是索引，而是子字串。
如果字串中含有這個子字串，就會回傳該子字串，否則會引發 `NilAssertionError`。

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

如果你想用 `Bool` 值表示是否找到子字串，可以使用 `includes?`方法。

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## 跳脫

有些字元無法直接寫在字串裡，這時你就必須使用跳脫序列。
例如，如果你想在字串中使用雙引號，就必須跳脫雙引號。
你可以使用 `\` 字元來撰寫跳脫序列，後面接著你想跳脫的字元。

以下是 Crystal 中的特殊字元：

| 值       | 說明                          |
| -------- | ----------------------------- |
| `\a`     | 警示                          |
| `\b`     | 退格                          |
| `\e`     | 跳脫                          |
| `\f`     | 換頁                          |
| `\n`     | 換行                          |
| `\r`     | 回車                          |
| `\t`     | 水平定位點                    |
| `\v`     | 垂直定位點                    |
| `\\`     | 反斜線                        |
| `\'`     | 單引號                        |
| `\"`     | 雙引號                        |
| `\377`   | 八進位 ASCII 字元             |
| `\xFF`   | 十六進位 ASCII 字元           |
| `\uFFFF` | 十六進位 unicode 字元         |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## 多行字串

要撰寫多行字串，你使用的語法和單行字串相同，只是字串中每一行都要換行。

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] 是一種用於編碼、表示和處理不同書寫系統文字的標準。
Unicode 支援超過 100,000 個字元，包括字母、標點符號、符號和表情符號。

由於 Crystal 使用 Unicode 來處理字串，因此你可以，比如說，在字串中放入表情符號。

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

有時你想使用某個字元，但你的編輯器或系統中剛好沒有這個字元。
在這種情況下，你可以使用 Unicode 跳脫序列來寫出該字元。

```crystal
"\u{1F310}"
# => "🌐"
```
