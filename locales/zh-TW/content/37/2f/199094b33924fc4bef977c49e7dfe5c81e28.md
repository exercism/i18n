# 說明

你好，特務 Double-Null0111。

你的任務，如果你願意接受的話，是寫出一組工具，幫你潛入 UMBRA（United Minions Being Really Awful）總部，取回他們最新邪惡計畫的藍圖。
你需要三樣工具才能完成這項任務。

## 1. 產生一組 id 號碼

每個小嘍囉都有一個專屬識別碼，這個識別碼每天都會改變，取決於他們掌握的祕密數量，以及他們睡眠的小時數。
你需要寫一個函式，接受日期（型別為`Int`），並為當天產生一個識別碼產生函式。
這個識別碼產生函式接受兩個參數：

1. 掌握的祕密數量
2. 小嘍囉睡眠的小時數

識別碼的計算方式如下：

1. 把掌握的祕密數量乘以他們睡眠的小時數
2. 再把日期（以`Int`表示）加到結果上

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. 用密碼保護取回的祕密計畫

拿到祕密計畫之後，你需要保護它，讓只有知道密碼的人才能取回。
為此，你需要實作函式`protectSecret(secret: String, password: String) : (String) -> String`。
這個函式會回傳另一個函式，它接受可能的密碼字串作為輸入。
如果輸入的密碼正確，新的函式會回傳藏起來的祕密；但如果密碼錯誤，函式會回傳 "Sorry. No hidden secrets here."

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. 找出密碼

UMBRA 基地有好幾個房間，每個房間都由一名警衛看守，他會向你詢問密碼。
密碼取決於房間的號碼。
可惜的是，我們只知道推算密碼的演算法的一半。
另一半可以透過詢問其中一個小嘍囉得知。

請實作`getPassword`函式，它接受以下項目並回傳密碼：

1. 房間號碼
2. 小嘍囉的函式，然後回傳密碼

密碼的取得方式，是呼叫小嘍囉的函式，並傳入另一個代表我們已知那部分演算法的函式。
我們負責的那部分演算法：

1. 接受兩個數字並將它們相加
2. 把結果乘以房間 id

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
