# 指示補充

## 列印樹狀結構

這個練習提供了一些預先定義好的類別方法，協助你以美觀的格式列印出這棵樹。主要目的是幫助除錯，並讓內容更加清楚。只要你正確地實作類別的其他部分，它就應該能幫你印出這棵樹。

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
