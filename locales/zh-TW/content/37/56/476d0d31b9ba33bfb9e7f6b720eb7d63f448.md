# 簡介

在程式設計中，妥善處理錯誤非常重要，這樣才能確保遇到預期外的狀況時，程式不會崩潰或出現無法預期的行為。
Cairo 提供兩種主要的錯誤處理機制：

1. 使用 `panic` 的**無法復原的錯誤**，會立刻停止程式。
2. 使用 `Result` 的**可復原的錯誤**，讓程式能夠處理並回應錯誤。

## 無法復原的錯誤：`panic`

有時程式會遇到嚴重到無法繼續執行的錯誤。
在這種情況下，Cairo 會使用 `panic` 函式立刻停止執行。
當錯誤讓程式無法以合理的方式繼續執行時，這就很有幫助，例如嘗試存取超出範圍的索引。
`panic` 函式接受一個 `ByteArray` 訊息，用來描述錯誤的原因。

例如，在 Cairo 中：

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

這個範例示範了強制觸發的 panic，會帶著訊息立刻停止程式。

### `assert!` 巨集

`assert!` 巨集是強制檢查程式碼中特定條件的好用工具。
如果 `assert!` 中的條件結果為 `false`，程式就會 panic，並附上 `ByteArray` 錯誤訊息。
這經常用來在開發期間驗證假設，並確保值符合特定條件。

例如：

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

如果 `x` 不大於零，程式就會 panic，並顯示訊息 `"x must be greater than zero"`。`assert!` 有助於檢查不變量和前置條件，而不必手動撰寫錯誤處理程式碼。

## 可復原的錯誤：`Result`

並非所有錯誤都需要停止程式。
有些錯誤可以妥善處理，讓程式繼續執行。
Cairo 的 `Result` 列舉代表這些可復原的錯誤，它有兩個變體：

- `Result::Ok` 代表成功。
- `Result::Err` 代表錯誤。

使用 `Result`，函式可以回傳成功值或錯誤，讓呼叫它的函式決定接下來該怎麼做。

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

在這個範例中，如果 `b` 是零，就會回傳錯誤；否則會回傳相除的結果。
