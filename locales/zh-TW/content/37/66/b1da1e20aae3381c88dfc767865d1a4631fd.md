# 指令補充

## Track 專屬指令

這些函式應該回傳乘積，以及因數陣列的偏移量和長度。
因數只是以 i32 成對寫入記憶體：

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

以最大的一位數迴文乘積為例，結果會像這樣：

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
