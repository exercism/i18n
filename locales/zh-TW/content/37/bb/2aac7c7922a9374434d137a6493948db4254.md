# 簡介

每個 Factor 原始檔都會用 `IN:` 宣告一個*詞彙*，並用 `USING:` 匯入它所用到的其他詞彙。

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

目錄結構會依照帶點的詞彙名稱來安排：

- 詞彙 `my-vocab` 位於 `my-vocab/my-vocab.factor`
- 詞彙 `my-vocab.helpers` 位於 `my-vocab/helpers/helpers.factor`

Factor 的詞彙載入器會沿著 `USING:` 宣告逐層追蹤：當你載入的檔案匯入了另一個詞彙時，那個詞彙也會自動被載入喔。

你經常會把一個大型的常式拆分成兩個詞彙：一個放著小型、可重複使用詞的輔助詞彙，以及一個匯入它們並組合出結果的主要詞彙。
