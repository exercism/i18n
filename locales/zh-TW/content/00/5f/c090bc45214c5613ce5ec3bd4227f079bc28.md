# 指令

在 _Instruments of Texas_ 工作時，你的任務是開發一個以 Elixir 撰寫的實驗性逆波蘭表示法 [RPN] 計算機。你的團隊遇到了某些操作會引發錯誤、導致行程崩潰的問題。你的任務是撰寫一個函式來包裝操作函式，讓錯誤能用更優雅、更符合 Elixir 慣用寫法的方式處理。

## 1. 警告團隊

實作函式`calculate!/2`，以堆疊作為唯一的引數來呼叫操作函式。這個操作函式定義在別處，但你知道它可能順利完成，也可能引發錯誤。

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> 函式名稱以`!`結尾，是在警告程式設計師這個函式可能會引發錯誤

## 2. 包裝錯誤

在做更多研究時，你注意到許多函式會用原子和元組來表示成功或失敗。請用這個策略來實作`calculate/2`。

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. 傳遞訊息

有些錯誤含有重要資訊，你的同事必須知道這些資訊，才能確保系統正確運作。實作`calculate_verbose/2`來傳遞錯誤訊息。這個錯誤是一個 struct，其中帶有`:message`欄位。

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
