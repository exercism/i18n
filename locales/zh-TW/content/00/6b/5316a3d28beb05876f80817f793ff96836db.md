# 關於

Elixir 中的函式可以動態分派。

所有模組名稱都是原子。所有 Elixir 模組名稱在編譯時都會自動加上`Elixir.`前綴。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir 可以在執行階段解析要呼叫的函式，並利用模組名稱進行查詢。如果模組名稱綁定到變數，查詢就能動態進行。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
