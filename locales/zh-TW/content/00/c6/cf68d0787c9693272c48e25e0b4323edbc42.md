# 簡介

元組是一種輕量的方式，能把一組型別各異、數量固定的資料聚集在一起。元組沒有特定的名稱；為資料結構命名後，它就變成了 `struct`。元組的欄位沒有名稱，而是透過解構或依位置來存取。

## 語法

### 建立

元組一律使用元組運算式建立：

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

元組可以有任意數量的元素。

### 以解構存取

我們可以透過解構來存取元組的元素。這只是把變數名稱指定給元組中的個別元素，並在過程中消耗掉整個元組。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 依位置存取

也可以透過數字位置索引來存取元組的元素。索引一如往常，從 0 開始。

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## 元組結構體

你之後也會需要處理元組結構體。和一般結構體一樣，它們是具名型別；但和一般結構體不同的是，它們的欄位是匿名的。它們的語法和一般的元組語法非常相似。解構與依位置存取兩者都可以使用。

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### 欄位可見性

匿名元組的所有欄位一律都是公開的。不過，元組結構體的每個欄位各自擁有可見性，預設為私有，就和標準結構體的欄位一樣。你可以用 `pub` 修飾詞把欄位設為公開，就和標準結構體一樣。

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
