# 介紹

Go 中的`string`是不可變的位元組序列，這些位元組不一定要代表字元。

字串常值定義在雙引號之間：

```go
const name = "Jane"
```

字串可以用`+`運算子串接起來：

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

有些特殊字元需要用前置的反斜線跳脫，例如字串中的`\t`代表定位字元，`\n`代表換行。

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings`套件裡有許多處理字串的實用函式。
想進一步了解字串相關的函式，可以參考 [strings 套件文件](https://pkg.go.dev/strings)。
以下是一些例子：

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
