# Introduction

有時候，你需要把一個序列看成一系列*片段*，而不是逐一處理每個元素。[`grouping`][grouping]、[`splitting`][splitting] 和 [`splitting.monotonic`][splitting.monotonic] 這幾個詞彙表提供了四種做法。

## `group`：大小為 *n* 的不重疊區塊

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

如果序列長度不是 *n* 的倍數，最後一組的長度會小於 *n*。

## `clump`：大小為 *n* 的重疊滑動視窗

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

如果序列長度小於 *n*，結果會是空的。

## `split-when`：在述詞成立的地方切開

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

每個元素都會各自呼叫一次述詞；結果為真的元素就是*切點*，不會被保留在結果中。

## `monotonic-split`：在相鄰配對檢查不成立的地方切斷連續片段

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

述詞會套用在*相鄰配對*上。只要它回傳真值，這一段就會繼續；當它回傳 `f` 時，就會開始新的一段。用 `[ = ]` 會得到元素相等的連續片段；用 `[ <= ]` 會得到非遞減的連續片段；依此類推。

## 什麼時候該用哪一個

- **`group`/`clump`**：你知道自己想要的*大小*。
- **`split-when`**：你知道*中斷元素*長什麼樣子。
- **`monotonic-split`**：你知道是什麼讓兩個相鄰元素*仍然屬於同一段*。
