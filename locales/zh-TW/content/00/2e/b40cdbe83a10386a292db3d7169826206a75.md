# 簡介

Common Lisp 有個印表機的概念，涵蓋了所有用來寫出 Lisp 資料文字表示法的函式。其中一個就是 `format`，它讓程式設計師能依照自己的需求格式化資料。

`format` 的能力，乃至整個 Lisp 印表機的能力，是個很大的主題；這裡只會介紹 `format` 用法的基礎。

## FORMAT 函式

`format` 這個函式至少接受兩個引數：一個要輸出到的串流，以及一個控制字串，定義要輸出什麼、以及如何輸出。

串流本身就是一個獨立的概念，會在別處介紹。不過現在你只需要知道，輸出是送到串流上，而這個引數有兩個特殊的值：`t`和`nil`。`t`代表輸出到標準輸出（其實就是變數`*standard-output*`所綁定的那個串流），而`nil`代表建立一個字串並回傳它。

要注意的是，除了後面那種把串流指定為`nil`的情況之外，`format`一律會求值為`nil`。這是很常見的單純做字串插值或字串建構的方式。

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## 格式指示詞

控制字串裡可以包含「格式指示詞」，用來指示`format`要輸出什麼，以及如何解讀傳給`format`的其他參數。某種程度上，控制字串就是一個程式，`format`會解讀並執行它。所有指示詞都以`~`開頭，後面接著一個字元（_例如_`~A`、`~D`、`~&`）。字元的大小寫沒有差別。

大多數格式指示詞只是把`format`的某個引數插進輸出裡。這稱為「消耗」該引數。有些指示詞不會消耗引數，有些則會消耗超過一個。甚至有個指示詞可以讓你在引數清單中跳來跳去，或略過某些引數。

## 基本格式化

一個用途非常廣泛的格式指示詞是`~A`。它會輸出資料的「人類可讀」版本。

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

另一個好用的格式指示詞是`~S`。它會輸出資料的「機器可讀」版本。如果你想讓產生的輸出能被當成 Lisp 資料解讀，這會非常有用。對很多東西來說，它看起來和`~A`一樣，但要注意，以字串為例，輸出會包含引號（夾在另一個字串裡時會被跳脫），這樣這個值就能再被讀回來當作字串參數。

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

另外兩個非常好用的指示詞是`~%`和`~&`。前者會輸出一個換行字元，後者則會輸出一個「全新的一行」。差別在於，`~%`總是輸出一個換行，而`~&`則是在目前不在行首時才輸出。這兩個都不會消耗引數。

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

最後，`~~`是個簡單的指示詞，會輸出一個字面上的`~`。
