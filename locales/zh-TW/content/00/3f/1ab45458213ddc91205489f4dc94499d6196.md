# 簡介

`Tuple`在很多方面和`Vector`（一維`array`）十分相似。不過，兩者之間有幾個重要的差異。

- 元組寫在小括號`( )`中，而不是方括號`[ ]`，不過在意義明確的情況下，小括號可以省略。
- 元組不一定要是同質的：每個元素的型別都是獨立儲存的。
- 元組是不可變的。

不可變性能讓編譯器進行更多最佳化，也讓元組的效能比向量更好，因此在不需要可變性的情況下，應該優先使用元組。

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

另外還有`Tuple()`建構子，可以把任何可疊代的集合轉換成元組。很實用的一點是，它會把字串視為由字元組成的可疊代集合。

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

對任何元組來說，都可以透過索引存取元素，或是以迴圈逐一走訪。

任何純數值的元組也能像陣列一樣，用在`sum()`這類數學函式中。

## 解構

使用多重賦值，就能把元組解構成一個個元素。如果有些元素用不到，可以用底線`_`當作佔位變數。

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

寫過 Python 的人對這種多重賦值語法一定很熟悉。

## 具名元組

`Tuple`只包含值。`NamedTuple`則會把每個值和一個名字配成對。

接著就能用「點」標記法存取個別欄位：

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

名字在內部是以`Symbol`儲存的（一種不可變型別，而且名字前面會加上冒號`:`），所以還有另一種語法可以使用：

```julia-repl
julia> nt[:b]
7.3
```

要分別取得名字（也稱為「鍵」）或值也很容易：

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

注意，對具名元組做疊代時只會產生_值_，_名字_會被忽略。

元組（無論是否具名）都是在函式之間傳遞結構化資料的常見方式。在這種用途下，不可變性很有好處，既能確保資料安全，也能讓編譯器進行更積極的最佳化。
