# 說明

馬戲團裡的每一副吊帶都有以公斤計算的額定負載，數字還沒確認之前，誰都不能上場。

`SAFETY_HARNESS`類別需要具備以下內容。程式骨架已經給你類別和它的屬性，其餘請自己補上。下面每個常式都帶有一份契約，提示會告訴你是哪一種。

## 1. 架設吊帶

`create`接受這副吊帶的額定負載，並回傳一副吊帶。額定值為零或更低，根本算不上是吊帶，所以那是`pre`。

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. 還剩多少餘裕？

`spare_capacity`接受吊帶上的負載，回傳它還能再承受多少。負載不得為負，也不得超過上限，這兩點都是`pre`。答案永遠不會是負數，這是`post`。

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. 有多滿？

`percent_used`接受負載，並回傳它佔上限的百分比，小數無條件捨去。負載不得為負數，答案也永遠不會是負數。

```sather
harness.percent_used(60)
-- => 50
```

## 4. 它安全嗎？

`is_safe`接受負載，並回答它是否在上限之內。任何負載都可以拿來問，包括莫名其妙的數字，所以對負載不設`pre`，但要寫一個`post`，說明只有在負載位於上限之內時，答案才為 true。

```sather
harness.is_safe(200)
-- => false
```
