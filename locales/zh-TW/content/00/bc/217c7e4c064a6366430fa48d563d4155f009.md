# 簡介

在 JavaScript 中，要依照條件執行程式邏輯，常見的做法是使用 `if`敘述。
它由 `if`關鍵字、以括號包住的條件，以及以大括號包住的程式區塊組成。
只有當條件的結果為`true`時，程式區塊才會被執行。

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

它可以單獨使用，也可以搭配 `else`關鍵字。

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

若要在 `else`敘述中巢狀另一個條件，可以使用 `else if`。

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
