# 基礎

Sather 程式是由**類別**組成的。類別是一個有名字的箱子，裡面裝著常式。**常式**是一段有名字的工作，會產生一個結果。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

從上往下讀：

- `class GREETER is` 打開這個箱子，並為它命名。類別名稱以大寫書寫。
- `hello : STR is` 開始一個名為 `hello` 的常式，它會產生一個 `STR`，也就是一段文字，稱為字串。`: STR` 則是對回傳結果種類的承諾。
- `return "Hello!";` 把結果交回去。文字寫在雙引號之間。
- `end;` 關閉這個常式，第二個 `end;` 則關閉這個類別。

一行中 `--` 之後的所有內容都是**註解**。Sather 會忽略它，它是寫給人看的。

```sather
-- This line is for the reader, not the computer.
```

如果想從其他地方使用某個常式，請寫出類別名稱、兩個冒號，再加上常式名稱：

```sather
GREETER::hello        -- this is "Hello!"
```

在同一個類別裡，你可以省略類別名稱：

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

不接受引數的常式在呼叫時不加括號，也就是 `hello`，而不是 `hello()`。
