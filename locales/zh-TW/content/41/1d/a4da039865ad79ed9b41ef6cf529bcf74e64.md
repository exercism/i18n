# 安裝

首先，請依照 [Erlang][1] 安裝頁面上的說明，確認你已經安裝好 Erlang。
[1]: /languages/erlang

## Mac OS X 的 Homebrew

將你的 Homebrew 更新到最新版本：

```bash
$ brew update
```

安裝 LFE：

```bash
$ brew install lfe
```

## 從原始碼安裝
安裝你系統的「開發者工具」或「必備建置套件」、`git`，以及 Erlang 的 `erl`。

例如，在 Ubuntu 18.04 上：

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

接著，你就可以用下列指令下載並建置 LFE：

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

編譯好 LFE 之後，只要執行 ``lfe`` 這個執行檔，就能啟動 REPL（互動式工作階段）：

```bash
$ ./bin/lfe
```
