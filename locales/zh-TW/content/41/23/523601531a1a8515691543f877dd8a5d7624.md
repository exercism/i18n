# 安裝

你需要 [NodeJS LTS](https://nodejs.org/en)。

> 💡 這個軌道可能也能搭配較舊的穩定版本，以及「current」版本運作。
> 不過，[按照設計](https://github.com/nodejs/release#release-schedule)，奇數版本永遠不穩定。
> 請務必安裝偶數版本的 NodeJS。

請使用 Node.JS`corepack`來安裝 [Yarn 4+](https://yarnpkg.com/getting-started/install)：

```shell
corepack enable yarn
```

## 檢查安裝

一般來說，你需要開啟一個新的終端機，才能使用剛安裝好的執行檔。

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_注意：你的版本可能會與這裡不同。_

## 練習安裝

**每個練習**都需要一些工具才能執行測試：

你可以在每個練習目錄中執行以下指令來安裝這些工具：

```bash
$ corepack yarn install
```

視你使用的編輯器而定，為了搭配 Plug'n'Play 安裝方式運作，你需要在每個練習中安裝 [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks)。
在撰寫本文時，支援以下編輯器：

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
