# 指令

在這個練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出一份超棒的千層麵。

你有五個任務，都跟烹調千層麵所花費的時間有關。

## 1. 定義千層麵預期的烤箱時間（分鐘）

定義`expectedMinutesInOven`函式，這個函式不接受任何引數，並回傳千層麵應該在烤箱裡烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```haskell
expectedMinutesInOven
-- -> 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remainingMinutesInOven`函式，它接受千層麵已經在烤箱裡待了幾分鐘作為引數，並根據上一個任務算出的預期烤箱時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```haskell
remainingMinutesInOven 30
-- -> 10
```

## 3. 計算準備時間（分鐘）

定義`preparationTimeInMinutes`函式，它接受你加進千層麵的層數作為引數，並回傳你準備千層麵花了幾分鐘，假設每一層需要 2 分鐘準備。

```haskell
preparationTimeInMinutes 3
-- -> 6
```

## 4. 計算經過的時間（分鐘）

定義`totalTimeInMinutes`函式，它接受兩個引數：第一個引數是你加進千層麵的層數，第二個引數是千層麵已經在烤箱裡待了幾分鐘。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間加上千層麵目前待在烤箱裡的時間。

```haskell
elapsedTimeInMinutes 3 20
-- -> 26
```

## 5. 建立千層麵烤好的通知

定義`alarm`函式，這個函式不接受任何引數，並回傳一則訊息，表示千層麵已經可以吃了。

```haskell
alarm
-- -> "Ding!"
```
