# 提示

## 一般

- 在入門指南中閱讀[`alias`和`import`][getting-started]的相關說明。
- 在 elixirschool.com 上閱讀[模組組合][elixir-school-module-composition]的相關說明。

## 1. 修正編譯錯誤 `Race.__struct__/0 is undefined`

- 可以使用[`alias`][alias]特殊形式來建立別名。

## 2. 修正編譯錯誤 `Car.__struct__/0 is undefined`

- 可以使用[`alias`][alias]特殊形式來建立別名。
- `alias`特殊形式接受`:as`選項。

## 3. 修正編譯錯誤 `undefined function puts/1`

- 可以使用[`import`][import]特殊形式來匯入函式。
- [`import`][import]特殊形式接受`:only`選項。它的值應該是一個關鍵字列表，以函式名稱作為鍵，並以函式的元數作為值。

## 4. 修正編譯錯誤 `undefined function default_color/0`

- 可以使用[`import`][import]特殊形式來匯入函式。
- [`import`][import]特殊形式接受`:except`選項。它的值應該是一個關鍵字列表，以函式名稱作為鍵，並以函式的元數作為值。
