# 結構體

結構體會把一組固定且異質的資料收集成單一單位。Rust 中的結構體有以下特性：

- 每個結構體型別都有特定的名稱。
- 結構體的每個成員都稱為**欄位**。
- 結構體的每個欄位都有特定的名稱。
- 可見性是依照欄位來追蹤的：每個欄位都可以各自是公開、私有或其他狀態[^1]。

# 結構體概覽

結構體使用`struct`關鍵字定義，後面接著這個結構體所描述型別的名稱。
名稱後面可以接著大括號（標準結構體）、小括號（元組結構體）或分號（單元結構體）。

```rust
struct Item {}
```

接著把其他型別以該結構體的_欄位_形式帶進結構體主體，每個欄位都有自己的型別：

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

最後，可以在`impl`區塊裡為結構體定義方法：

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# 結構體的種類

結構體有三種：具名欄位的結構體（標準結構體）、元組結構體，以及單元結構體。

結構體和**元組**非常相似。事實上，結構體和元組唯一的差別在於「什麼是匿名的」。大致的形式如下：

- 結構體有名稱，欄位也有名稱：

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  透過名稱存取欄位：

  ```rust
  let bar = foo.bar;
  ```

- 元組結構體有名稱，但欄位是匿名的：

  ```rust
  Foo(Bar, Bat)
  ```

  透過解構或數值索引存取欄位：

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- 元組本身匿名，欄位也是匿名的：

  ```rust
  (Bar, Bat)
  ```

  和元組結構體一樣，透過解構或數值索引存取欄位。

- 匿名結構體，顧名思義是匿名的，但擁有具名欄位。你可能在其他語言看過它們，例如 Go 或 Java。Rust 沒有這種東西；一般認為改用元組才是慣用做法。

# 零大小型別

結構體可以有任意多或任意少的欄位，全看需求而定。這意味著結構體可以合法地擁有零個欄位。沒有欄位的結構體稱為**零大小型別**，編譯器會對它做一些特殊處理：零大小型別（通常縮寫為**ZSTs**）永遠不會佔用堆疊或堆積空間，即使你預期它會。舉例來說，如果`T`是 ZST，`Box<T>`就不會配置任何堆積記憶體。

寫一個 ZST 時，你可以使用標準結構體或元組結構體的語法：

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

ZST 也有一種簡寫：

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

一般來說，寫 ZST 時建議使用簡寫，因為你不能混用：宣告 ZST[^2] 時用了哪種風格，實例化時就必須用同一種風格。

談完 ZST 的語法之後，我們來聊聊為什麼你會想要這種東西吧。ZST 不能儲存任何資料，但它非常適合用來實作特徵。

[^1]: [這些文件](https://doc.rust-lang.org/reference/visibility-and-privacy.html)說明了一些較少使用的可見性選項。
[^2]: 這是一條通則的具體例子：宣告任何結構體型別時用了哪種風格，實例化時就必須用同一種風格。
