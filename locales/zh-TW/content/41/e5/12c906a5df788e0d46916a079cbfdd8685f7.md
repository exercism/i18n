# 關於

Ruby 內建了標準函式庫（常簡稱為「stdlib」），這是一組用來處理日期、json、網路等工作的類別。它還提供了一些實用的功能，讓你的程式碼更好用。

`OpenStruct`是標準函式庫的一部分，可以讓你輕鬆地從`Hash`建立物件。與其用`Hash`的鍵來存取，`OpenStruct`讓你改用方法來存取和設定值。

使用標準函式庫或其他函式庫的類別時，你需要用`require`方法來引入該類別。

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

額外的好處是，使用區塊語法時還能利用一種簡寫。當區塊只呼叫單一方法時，你可以用`&:`加上方法名稱來取代區塊。例如下面這兩行程式碼的意思相同：

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
