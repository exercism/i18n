# 指令

實作這個經典的加密訊息方法，稱為方塊密碼。

給定一段英文文字，輸出這段文字的編碼版本。

首先，輸入會先被正規化：移除英文文字中的空格與標點符號，並將訊息轉為小寫。

接著，把正規化後的字元切成列。這些列在加上換行符號列印出來後，可以視為構成一個矩形。

舉例來說，這個句子

```text
"If man was meant to stay on the ground, god would have given us roots."
```

正規化後會變成：

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

明文應該排列成一個矩形。矩形的大小（`r x c`）取決於訊息的長度，並滿足 `c >= r` 且 `c - r <= 1`，其中 `c` 是欄數，`r` 是列數。

我們正規化後的文字長度是 54 個字元，因此矩形為 `c = 8`、`r = 7`：

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

編碼訊息是從左到右、由上往下讀取每一欄所得到的。

上面的訊息編碼後為：

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

輸出編碼文字時要分段，使其填滿完整的矩形 `(r X c)`，共有 `c` 段，每段長度為 `r`，並以空格分隔。若片語比完整矩形少了 `n` 個字元，就在最後 `n` 段各補上一個尾隨空格。

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

注意，如果把這些疊起來，就能用視覺方式將密文解碼回原始訊息：

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
