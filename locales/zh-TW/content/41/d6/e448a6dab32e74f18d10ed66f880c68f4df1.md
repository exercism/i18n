# 關於

Elixir 的標準函式庫提供了 4 個處理日期與時間的模組，每個模組都有自己的 struct。

- [`Date`模組][date]。`Date` struct 可以用 [`~D` sigil][sigil-d] 建立。
    ```elixir
    ~D[2021-01-01]
    ```

- [`Time`模組][time]。`Time` struct 可以用 [`~T` sigil][sigil-t] 建立。
    ```elixir
    ~T[12:00:00]
    ```

- [`NaiveDateTime`模組][naivedatetime] 用於沒有時區的日期時間。`NaiveDateTime` struct 可以用 [`~N` sigil][sigil-n] 建立。
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- [`DateTime`模組][datetime] 用於帶有時區的日期時間。要用這個模組處理 UTC 以外的時區，需要一個外部相依套件，也就是時區資料庫。`DateTime` struct 可以用 [`~U` sigil][sigil-u] 表示，但應該改用`DateTime`的函式來建立。
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## 比較

要比較兩個日期或時間時，請在對應的模組中尋找 `compare` 或 `diff` 函式。`==`、`>`、`<` 這類比較運算子_看似_可以用，但它們不會為這些 struct 做出正確的語意比較。

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## 位移

日期、時間和日期時間都可以用對應模組的 `add/2` 函式，在時間軸上向前或向後位移。

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## 轉換

`NaiveDateTime` struct 可以用 [`NaiveDateTime.to_date/1`][naivedatetime-to-date] 和 [`NaiveDateTime.to_time/1`][naivedatetime-to-time] 拆解成 `Date` struct 和 `Time` struct。反過來則可以用 [`NaiveDateTime.new!/2`][naivedatetime-new] 做到。

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
