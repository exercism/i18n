# 簡介

`Complex numbers`其實並不複雜。
它們只是需要一個不那麼嚇人的名字。


它們非常實用，尤其是在工程與科學領域，因此 Python 把 [`complex`][complex] 列為標準的數值型別，與整數（[`int`s][ints]）和浮點數（[`float`s][floats]）並列。


Python 中的`complex`值基本上就是一對浮點數：

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

這兩個部分分別叫做「實部」和「虛部」。
你可能聽過「`i`（或 `j`）是 -1 的平方根」這種說法。
就目前來說，這只表示虛部_依定義_滿足等式 `1j * 1j == -1`。
這是個簡單的想法，卻會帶來有趣的數學結果。

在 Python 中，虛部是以`j`標示的（_而不是數學教科書裡會看到的`i`_），而且
`j`必須緊接在數字之後，以免 Python 把它當成變數名稱：


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


建立複數有兩種常見的做法。

1) [`complex(real, imag)`][complex]建構子接受兩個`float`參數：

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    建構子也能解析字串輸入。
    只是有個奇怪的限制：字串裡只要有空格就會失敗。

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) 複數也可以寫成`<real part> + <complex part>j`這樣的字面值，如果實部是零，也可以只寫`<complex part>j`：


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    結果和用`complex()`建構子完全一樣。


## 算術

大部分用在浮點數和整數上的[`operators`][operators]，也能用在複數上。

複數無法進行整數除法，因此`//`和`%`運算子以及`divmod()`函式用在複數型別上都會失敗。

說明複數乘除的規則超出了這個概念的範圍（_而且你不太常需要「手動」執行這些運算_）。

如果你想深入這個主題，任何關於複數的[數學][math-complex]或[電機工程][engineering-complex]入門教材都會涵蓋這些情境。

Python 標準函式庫有個[`math`][math-module]模組，裡面滿是處理實數的實用功能，而[`cmath`][cmath]模組則是它處理複數的對應版本。
