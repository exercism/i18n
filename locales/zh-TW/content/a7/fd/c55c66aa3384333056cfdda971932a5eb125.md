# 提示

## 一般

- `case`（在`combinators`裡）適合用來比對相同的值；`cond`則適合處理帶守衛的述詞。
- 這些符號（`yes`、`no`、`maybe`、`korean`等）已經在練習檔案中透過`SYMBOLS:`宣告好了。

## 1. 為料理評分

- 用一個有 2 個子句的`case`，把`korean`和`turkish`對應到各自的認可值。

## 2. 為電影類型評分

- 比對`romance`，其餘的用`[ drop no ]`作為預設分支。記得預設分支會看到堆疊最上方的原始值，所以在推入結果之前要先移除它。

## 3. 為散步評分

- 使用`cond`（同樣在`combinators`裡），每個守衛都是`[ dup N > ]`。主體需要在推入認可值之前先移除公里數。

## 4. 為活動評分

- 活動是`{ tag value }`。用`first2`把兩者都推入堆疊，再用`swap`讓標籤位於最上方，這正是`case`要比對的對象。
- `board-game`和`chill`的分支會看到（`f`）值還在堆疊上；在推入認可值之前先把它`drop`掉。
- `movie`、`restaurant`和`walk`的分支會看到對應的值還在堆疊上，所以可以直接呼叫你在第 2、1、3 題寫的詞。
