# 簡介

## 繼承

繼承是 OOP（物件導向程式設計）的核心概念。
它代表的是一種 IS-A 關係。
它在程式設計裡的意思，就跟在英文裡一樣，都是從父類別繼承特性（在程式設計裡，這些特性通常就是函式與變數）。

請看下面這個`Animal`類別：

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`是一個父類別，因為這個類別所擁有的屬性可以延伸給一般的所有動物。

再看一個叫做`Lion`的動物，它的類別長這樣：

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override`註解用來指出子類別中的某個方法正在覆寫父類別的方法。
它不是絕對必要，但使用它是最佳做法。
~~~~

現在，當我們這樣寫：

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

注意：這裡是用`Lion`來初始化`Animal`類別。
輸出結果會像這樣：

```java
Lion here!!
```

根據 OOP，繼承有很多種類型，但 Java 只支援其中幾種（多層繼承與階層繼承）。
想進一步了解的話，請閱讀[這篇][java-inheritance]。
