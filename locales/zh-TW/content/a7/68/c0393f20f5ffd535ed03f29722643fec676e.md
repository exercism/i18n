# Linux 進階使用者安裝指南（僅限進階 Linux 使用）

這裡的安裝說明我們還在調整中，不過我們知道（也很感謝），許多 Linux 開發者對於要安裝什麼、東西該放在哪裡，都相當有自己的想法。

_如果你還是想採用標準安裝，只要返回並依照[一般安裝設定](https://exercism.io/tracks/pharo-smalltalk/installation)操作就好。_

以下說明還非常初步，內容以 ArchLinux 為基礎，但或許也適用於你的發行版（如果幫不上忙，也請幫我們找出可以改進的地方，甚至向 Pharo 上游提出請求）。_注意：目前還不確定這些說明是否能穩定運作，所以很歡迎大家協助改進。_

- 把 Pharo VM 安裝到你偏好的位置。如果 AUR 或類似的套件庫裡有列出 Pharo 7，你也許可以直接使用；或者也可以從這裡下載：[https://files.pharo.org/vm/pharo-spur64/linux/]（請挑選 stable-timer 的 VM）
- 接著你需要解壓縮一個 Pharo.image 檔，放到你的 exercism 目錄裡。你可以從這裡取得：[https://files.pharo.org/image/70/]，並選擇最新的 64 位元 zip 檔。
- 現在用一個簡單的命令列測試，確認 VM 和 Image 是否能正常運作：`pharo Pharo.image eval "100 factorial"`。如果一切正常，你應該會得到一個答案。
- 接著試試 OSX 那一節提到的「load script」。你可能會遇到提到`libgit2`的錯誤，如果是這樣，你也需要安裝它再試一次。我們也收到回報說安裝`libcurl-gnutls`有幫助（但這還沒被證實）。
- 我們也收到回報指出，某些 libgit2 的失敗情形，可能與開發版 Pharo 內部對 loadModule 所做的調整有關，我們或許會把它移植回來。這種情況下，你需要把`LGitLibrary`類別裡的`unixModuleName`方法替換成下面這樣：
  1. 輸入`pharo-ui Pharo.image`，啟動有完整圖形介面的 Pharo
  1. 按 Ctrl-Space，然後輸入`unixModuleName`
  1. 選取`LGitLibrary >> unixModuleName`這一項，然後按 Enter
  1. 在接下來出現的瀏覽器視窗中，把`unixModuleName`的方法原始碼換成下面這段（複製貼上），按儲存（ctrl-s），最後儲存並離開 Pharo。
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

現在重新執行前面提過的 OSX exercism「load script」。如果一切運作正常，你應該會看到載入進度條在畫面上閃過，接著會出現一個 System Browser 視窗。如果沒有，請前往 Pharo Discord（如前面所述）。

現在你可以返回，繼續依照其餘的[入門說明](https://exercism.io/tracks/pharo-smalltalk/installation)操作。
