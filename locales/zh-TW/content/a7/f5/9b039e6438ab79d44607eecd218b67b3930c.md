# 表示法

[表示器][representer] 會套用以下正規化：

- [所有註解和文件都會被移除][remove-comments-and-docs]
- [模組和函式中的 import 會被排序][sort-imports-order]
- [程式碼會以`mix format`格式化][format-code]
- [識別字會被正規化為佔位符值][normalize-identifiers]
- [map 和 struct 中的鍵會被排序][sort-keys-in-maps-and-structs]
