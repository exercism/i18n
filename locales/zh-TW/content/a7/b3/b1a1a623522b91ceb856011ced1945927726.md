# 關於

JavaScript 有遞增與遞減運算子。
它們會直接修改變數本身。
`++` 會把數字加一，`--` 會把數字減一。

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

上面的範例展示的是後綴遞增／遞減運算子。
此時運算子放在變數之後，而這個運算式的回傳值是變數在增加／減少_之前_的值。

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

另外還有前綴寫法，也就是把運算子放在變數前面。
這時回傳值就是變數在增加／減少_之後_的值。

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
