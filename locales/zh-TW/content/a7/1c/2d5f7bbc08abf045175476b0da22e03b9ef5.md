# 說明

Lisp 外星人 Lucy 喜歡數字，他們覺得其中有些數字很「了不起」。

他們想請你幫忙寫一些函式，讓數字變得更了不起。

Lucy 對「數字怎樣才算了不起」的看法會改變，所以這些函式必須保持彈性。

## 1. 讓數字變得了不起

想把一個數字陣列變成更了不起的數字陣列，你需要寫一個函式 `make-magnificent-maybe`，它接受一個要套用到數字上的函式，以及一個數字陣列。
它應該求值為一個數字陣列，裡面的數字都更了不起（依據你提供的函式而定）。

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. 只留下最棒的

在（希望有）把數字變得更了不起之後，Lucy 只想看看真正了不起的數字。

他們很確定 1 *永遠不*了不起，所以你得把 1 拿掉。

除此之外，Lucy 有時會改變心意，所以他們同樣會給你一個函式，用來判斷某個數字了不起還是不了不起。

你需要寫一個函式 `only-the-best`，它接受一個函式和一個數字陣列，只回傳最棒的數字（不包括 `1`，也不包括函式求值為 true 的數字）。

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
