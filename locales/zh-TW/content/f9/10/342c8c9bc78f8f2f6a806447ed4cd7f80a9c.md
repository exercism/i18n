# 簡介

「quotation」是一段放在`[ ]`方括號裡的程式碼。它是一個值：你可以把它推上堆疊、傳給另一個 word，或存進陣列裡。

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

大多數高階 word 都會把 quotation 當作第二個引數：

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

quotation 的主體就只是一般的 Factor 程式碼，跟你在其他地方使用的運算子和堆疊效應一模一樣。

當你從資料建構程式碼時，例如串接片段、把 token 對應到運算，得到的結果會是一個序列，把它傳給`>quotation`，就能讓它變成可呼叫的：

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
