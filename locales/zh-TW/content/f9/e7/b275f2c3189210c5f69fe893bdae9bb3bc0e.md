# 簡介

和 _if/else_ 敘述一樣，`switch` 敘述讓你藉由有條件地執行程式碼，來改變程式的流程。
差別在於，`switch` 敘述只能拿基本型別或字串運算式的值，去和預先定義好的常數值比較。

使用 `switch` 敘述時，有幾個關鍵字很有用。

- `switch`：這個關鍵字讓你宣告 switch 的結構。
  後面接著會改變結果的運算式或變數。
- `case`：用這個關鍵字來宣告結果的各種可能。
- `break`：`break` 關鍵字非常有用，可以在想要的流程結束時停止執行 switch。
  如果忘了它，程式會繼續執行，可能導致非預期的結果。
- `default`：顧名思義，當沒有其他 case 符合運算式的結果時，就用它作為預設結果。

最簡單的用法，是拿基本型別或字串運算式來測試，並根據它的值做出決定。
例如：

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
