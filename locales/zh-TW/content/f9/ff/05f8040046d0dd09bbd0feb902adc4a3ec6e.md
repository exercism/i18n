# 關於

布林運算式是對一個或多個值提出的問題，答案可以是 `true` 或 `false`。
運算式為真時會回傳 `1`；為假時則回傳 `0`。
此外，數字本身也有真／假值。零是 `false`；非零是 `true`。

早期的 C 程式碼若不是直接使用 `int` 型別來表示布林值，就是程式設計師自行定義像 `TRUE` 和 `FALSE` 這樣的常數，把 `1` 和 `0` 對應成布林的表示方式。

到了 C99 版本，新增了 `_Bool` 型別。
`stdbool.h` 標頭檔定義了三個新的布林符號：`bool`；`true` 和 `false`。
`true` 對應到 `1`；`false` 對應到 `0`；而 `bool` 對應到 `_Bool`。
所以現在，程式設計師不必再直接使用 `int` 或自行打造布林對應，只要引入 `stdbool.h`，就能在程式中自動取得布林符號。

## 比較運算子

C 支援六種比較運算子：`==`（等於）、`!=`（不等於）、`>`（大於）、`<`（小於）、`>=`（大於或等於）、`<=`（小於或等於）。
這些運算子會比較值之間的關係，並得出布林值。

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 布林運算子

C 支援三種布林運算子：`||`（或）、`&&`（且）和 `!`（非）。

`!` 只用於一個運算元。
它會反轉運算元的布林值。
例如，`0` 是 `false`，但 `!0` 是 `true`。

`||` 和 `&&` 則用於兩個運算元。
只有當左邊的運算元還不足以決定整個運算式的結果時，才會求值右邊的運算元。
也就是說，`||` 只有在左邊的運算元求值為 `false` 時，才會求值右邊的運算元。
`&&` 只有在左邊的運算元求值為 `true` 時，才會求值右邊的運算元。


## 短路

不求值所有運算元，這種做法稱為「短路」。
短路是處理某些情況時簡潔又有力的方式。
例如，常見的慣用寫法是先檢查某個指標不是 `NULL`，並且（&&）在它不是 `NULL` 的情況下才對它解參考，如此便能避免對 `NULL` 指標解參考。
不過，短路也可能導致 bug。
有時程式設計師會忘記，`||` 或 `&&` 右邊的運算元不一定每次都會被求值。
如果右邊的運算元是一個帶有副作用、而且預期一定會發生的運算式，那麼它會不會成為 bug，就取決於左邊運算元的布林值。


## 回傳布林運算式

布林運算式的結果可以直接回傳。
例如，這個 `if` 敘述

```c
if (count > 0)
    return true;
else
    return false;
end
```

可以改寫成

```c
return count > 0;
```
