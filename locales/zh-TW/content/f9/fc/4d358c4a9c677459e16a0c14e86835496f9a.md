# 指示

在這個練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出一份美味的千層麵。

你有五個任務，全都和烹調千層麵所花的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

在 `Lasagna` 類別中實作 `expectedCookTime` 函式，它不接受任何引數，並回傳千層麵應該待在烤箱裡幾分鐘。
根據食譜，預期的烤箱時間是 40 分鐘：

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

在 `Lasagna` 類別中實作 `remainingCookTime` 函式，它接受千層麵實際已經待在烤箱裡的分鐘數作為引數，並根據上一個任務算出的預期烤箱時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. 計算準備時間（分鐘）

在 `Lasagna` 類別中實作 `totalPreparationTime` 函式，它接受你加在千層麵裡的層數作為引數，並回傳你準備千層麵花了幾分鐘，假設每一層要花你 2 分鐘準備。

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. 計算總工作時間（分鐘）

在 `Lasagna` 類別中實作 `totalElapsedTime` 函式，它接受兩個引數：第一個引數是你加在千層麵裡的層數，第二個引數是千層麵已經待在烤箱裡的分鐘數。
這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間的分鐘數，加上千層麵當下已經待在烤箱裡的分鐘數。

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. 建立通知，表示千層麵已經好了

在 `Lasagna` 類別中實作 `alarm` 函式，它不接受任何引數，並回傳一則訊息，表示千層麵可以吃了。

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
