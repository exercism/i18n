# 簡介

這道練習以你在 [Cargo Shuffle][cargo-shuffle] 中看過的資料堆疊與堆疊效應標記法為基礎。在這裡，你將撰寫能組合布林值的詞。

## 重排詞

最常見的重排詞都放在 [`kernel`][kernel] 詞彙裡：

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## 布林

布林字面值有兩個：`t` 和 `f`。`f` 是 Factor 中唯一為假的值，其他一切，包括 `0` 和空的集合，都為真。

```factor
t .    ! => t
f .    ! => f
```

## 布林詞

以下是來自 `kernel` 詞彙的三個布林詞：

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

每個輸出中的 `?` 是堆疊效應的慣例，代表「布林值」。
