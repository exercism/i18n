# 簡介

## 比較運算子

R 有一組運算子，和其他許多程式語言相同：

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 分支

if-else 的基本形式是

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

在這個情況下，布林值周圍的小括號 `()` 和敘述周圍的大括號 `{}` 都是必需的。
簡單的`if`敘述可以縮短：

```R
if (x == 0) return("success")
```
