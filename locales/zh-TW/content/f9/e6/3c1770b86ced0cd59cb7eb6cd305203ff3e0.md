# 指示

你期盼已久的日子終於到來，現在你是阿爾卑斯山上美麗農場的驕傲主人。

你依然不喜歡一大早起床餵牛。
因為你是個優秀的工程師，所以你打造了一台餵食器，叫做`FEED-M-ALL`。

完成這個專案的最後一件事，就是寫出一段程式碼，計算每頭牛應該分到多少飼料。
每頭牛分到的量必須相同，你得避免衝突。
牛可是很敏感的。

幸運的是，你不需要自己推導出所有計算飼料份量的公式。
你用了一個在網路上找到的神祕外部函式庫。
據說它能讓牛群過得最開心。
這個函式庫提供了一個型別，實作了以下介面。
你在自己寫的程式碼裡會用到它。

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

在你寫程式的過程中，會逐步改善錯誤處理，讓它更強健，之後在日常農場生活中使用時也更容易除錯。

## 1. 平均分配食物

首先，你專注於寫出計算每頭牛飼料份量所需的程式碼。

實作一個函式 `DivideFood`，接受一個 `FodderCalculator` 和一個整數的牛隻數量作為引數。
*在這項任務中，假設傳入的牛隻數量永遠大於零。*
這個函式應該回傳每頭牛的食物份量，型別為 `float64`，若發生錯誤則回傳該錯誤。

要進行計算，你得先取得所有牛的飼料總量。
作法是呼叫 `FodderAmount` 方法並傳入牛隻數量。
此外，你還需要一個用來乘上這個總量的係數。
你可以透過呼叫 `FatteningFactor` 方法取得這個係數。
有了這兩個值和牛隻數量，你就能算出每頭牛的食物份量（型別為 `float64`）。
這就是 `DivideFood` 函式應該回傳的內容。

如果你呼叫的其中一個方法回傳錯誤，執行就應該停止，並將該錯誤原樣從 `DivideFood` 函式回傳。

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. 檢查牛隻數量

在做上面的第一項任務時，你發現自己用的外部函式庫品質不如預期。
例如，它無法妥善處理無效的輸入。
你想在自己的程式碼裡加入輸入值的檢查，來繞過這個限制。

寫一個函式 `ValidateInputAndDivideFood`，簽章與上面的 `DivideFood` 相同。

- 如果傳入的牛隻數量大於 0，函式應該呼叫 `DivideFood` 並回傳該呼叫的結果。
- 如果牛隻數量是 0 或更少，函式應該回傳一則訊息為 `"invalid number of cows"` 的錯誤。

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. 改善錯誤處理

在傳遞之前先檢查牛隻數量是個好做法，但你對這個不夠具體的錯誤訊息不太滿意。
你決定做得更好，建立一個名為 `InvalidCowsError` 的自訂錯誤型別。

這個自訂錯誤應該保存牛隻數量（`int`）和自訂訊息（`string`），而 `Error` 方法應該將資料序列化成以下格式：

```txt
{number of cows} cows are invalid: {custom message}
```

有了自訂錯誤之後，實作一個函式 `ValidateNumberOfCows`，接受牛隻數量（整數）並回傳一個錯誤（或 nil）。

- 如果牛隻數量小於 0，函式回傳一個 `InvalidCowsError`，自訂訊息設為 `"there are no negative cows"`。
- 如果牛隻數量是 0，函式回傳一個 `InvalidCowsError`，自訂訊息設為 `"no cows don't need food"`。
- 否則，函式回傳 `nil`，表示驗證成功。

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

在辛苦建立這個驗證函式之後，你發現已經傍晚了，於是離開書桌去欣賞山巒上的夕陽。
你把實際將新的驗證函式加進程式碼這件事，留到改天再說。
