# 關於

`null`值用來表示值的_不存在_。**可為`null`**的型別，就是允許變數取值為`null`的型別。若要讓任何型別都可為`null`，我們會用`Null<T>`將它包住：

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

若要檢查某個值目前是否為`null`，只要使用`if`運算式就行了：

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
