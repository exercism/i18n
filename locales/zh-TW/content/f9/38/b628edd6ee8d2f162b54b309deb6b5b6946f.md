# 提示

## 1. 計算披薩的價格

- 建立一個遞迴函式，回傳不含該額外配料的披薩價格，再加上那項配料的價格。
- 如果出現 `Maximum call stack size exceeded` 錯誤，檢查一下是不是漏掉了基底情況。
- 如果出現 `Memory Allocation Error`，檢查是不是複製了輸入的配料陣列，而不是直接修改它。

## 2. 計算一筆訂單的總價

- 使用 `pizzaPrice` 計算陣列中每個披薩的價格，並加到總和裡。
- 如果出現 `Maximum call stack size exceeded` 錯誤，而且有超過一個測試失敗，檢查一下是不是漏掉了基底情況。如果只有一個測試失敗，試著用迴圈來實作吧！
- 如果出現 `Memory Allocation Error`，檢查是不是複製了輸入的陣列，而不是直接修改它。
