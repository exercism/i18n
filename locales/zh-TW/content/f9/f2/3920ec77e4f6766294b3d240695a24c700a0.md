# defguard 搭配問號

[comment]: # (- actual：學生使用的錯誤名稱)

Elixir 有特定的命名慣例，其中包含如何命名[會回傳布林值且在 guard clause 中有效的檢查](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)：

> 型別檢查以及其他允許在 guard clause 中使用的布林檢查，命名時會加上`is_`前置字元。

這類檢查包含一些內建函式、一些巨集和 guard。

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
請注意，回傳布林值但在 guard clause 中無效的函式和巨集，遵循另一種慣例，名稱會以`?`結尾（`def foo?`、`defmacro foo?`）。這兩種慣例不能混用。
