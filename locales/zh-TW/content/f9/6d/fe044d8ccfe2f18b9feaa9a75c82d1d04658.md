# 關於

[SQLite][sqlite] 是一個開放原始碼、輕量、無伺服器且自成一體的[關聯式資料庫][relational-database]管理系統。
它以簡單、易用和零設定需求著稱。
SQLite 可以嵌入應用程式之中，是應用程式、嵌入式系統與中小規模專案的理想選擇。

SQLite 由 [D. Richard Hipp][hipp] 所創建，遵循 [ACID][acid] 特性，目的是促成可靠的交易。
由於資源佔用極小、效能出色，它被廣泛應用於各行各業。

SQLite 採用直觀的 SQL 語法來定義資料庫並與之互動。
資料表、索引和查詢都使用標準 SQL 敘述建立，為開發者提供熟悉且富表達力的資料庫管理方式。
資料庫引擎自成一體，不需要獨立的伺服器行程。
這樣的簡單性結合強大的功能，讓 SQLite 成為重視易用性與效率的專案的絕佳選擇。
