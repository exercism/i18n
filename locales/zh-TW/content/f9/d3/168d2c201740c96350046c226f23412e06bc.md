# 關於

在 Go 中，字串是不可變的。
在迴圈裡用`+`串接字串，會造成頻繁的記憶體配置，並多次複製資料。
[`strings`套件](https://pkg.go.dev/strings)提供了[`Builder`](https://pkg.go.dev/strings#Builder)，能有效率地組裝字串，把記憶體開銷降到最低。

## 建立字串

`strings.Builder`的零值可以直接使用，不需要任何明確的初始化或記憶體配置。
你可以使用特定的寫入方法，把新資料寫進`Builder`。
每個寫入方法都會回傳一個錯誤值，以符合 Go 的標準介面，但這個值保證永遠是`nil`，日常程式碼通常會忽略它。

最常用的方法有：

- `WriteString(s string) (int, error)`：將字串附加到緩衝區。
- `WriteRune(r rune) (int, error)`：附加某個 rune 的 UTF-8 編碼。
- `WriteByte(c byte) error`：附加單一位元組。

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## 取出內容與重設

組裝好文字之後，只要呼叫`String()`方法，就能把累積的內容取出成一般的 Go 字串。
呼叫`String()`的成本非常低，因為它會直接把底層的位元組切片當成字串回傳，不會複製累積的資料。

如果你需要重複使用同一個`Builder`實例來組裝新的字串（例如在迴圈裡），可以呼叫`Reset()`方法。
這會清空內部的緩衝區，讓你從頭開始建立下一個字串，同時在底層保留已經配置好的記憶體容量。

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
