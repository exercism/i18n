# 簡介

許多程式需要（偽）隨機值來模擬真實世界的事件。

常見、熟悉的例子包括：

- 擲硬幣：從 ('H', 'T') 中隨機取值。
- 擲骰子：從 1 到 6 的隨機整數。
- 洗牌：將一份卡片清單隨機排序。
- 在 3D 圖形模擬中生成樹木與灌木。

用電腦產生真正隨機的值，是一件[出乎意料地困難的技術挑戰][why-randomness-is-hard]，這也是為什麼還有所謂的「偽隨機」產生器。

## 產生隨機數

在 JavaScript 中，你可以使用[`Math.random()`][Math.random]函式來產生偽隨機數。
它會回傳一個介於 0（含）與 1（不含）之間的偽隨機浮點數。

如果想取得介於 _min_（含）與 _max_（不含）之間的隨機數，可以寫一個像這樣的函式：

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## 產生隨機整數

要產生隨機整數，你可以用`Math.floor()`或`Math.ceil()`，把隨機產生的數字轉成整數。
