# Instructions

你已經在市公所工作了好一陣子，也開發出一套能加快日常工作的工具，例如填寫表單。

現在有位新同事要加入你們，而你發現自己的工具可能不夠淺顯易懂。你們辦公室裡有許多奇怪的慣例，例如表單一律用大寫字母填寫，還有避免讓欄位留空。

你決定撰寫一些文件，讓新同事能更快上手，直接開始使用你的工具。

## 1. 為表單工具的用途撰寫文件

為 `Form` 模組撰寫說明其用途的文件。內容應該是：

```
A collection of loosely related functions helpful for filling out various forms at the city office.
```

## 2. 為以空值填寫欄位撰寫文件

為 `Form.blanks/1` 函式撰寫文件和型別規格。文件內容應該是：

```
Generates a string of a given length.

This string can be used to fill out a form field that is supposed to have no value.
Such fields cannot be left empty because a malicious third party could fill them out with false data.
```

型別規格應該說明這個函式接受一個引數（非負整數），並回傳一個字串。

## 3. 為將值分割成由大寫字母組成的陣列撰寫文件

為 `Form.letters/1` 函式撰寫文件和型別規格。文件內容應該是：

```
Splits the string into a list of uppercase letters.

This is needed for form fields that don't offer a single input for the whole string,
but instead require splitting the string into a predefined number of single-letter inputs.
```

型別規格應該說明這個函式接受一個引數（字串），並回傳一個由字串組成的陣列。

## 4. 為檢查值是否符合欄位長度上限撰寫文件

為 `Form.check_length/2` 函式撰寫文件和型別規格。文件內容應該是：

```
Checks if the value has no more than the maximum allowed number of letters.

This is needed to check that the values of fields do not exceed the maximum allowed length.
It also tells you by how much the value exceeds the maximum.
```

型別規格應該說明這個函式接受兩個引數，一個字串和一個非負整數，並回傳兩種可能的值之一。它會回傳 `:ok` 原子，或是回傳一個二元組，其中第一個元素是 `:error` 原子，第二個是正整數。

## 5. 為不同的地址格式撰寫文件

不知道是什麼原因，市公所的內部系統用了兩種不同的方式來表示地址：一種是映射，另一種是元組。

用定義三個自訂的公開型別來記錄這件事：
- `address_map`：帶有 `:street`、`:postal_code` 和 `:city` 鍵的映射。每個鍵都存放一個字串型別的值。
- `address_tuple`：帶有三個值的元組：`street`、`postal_code` 和 `city`。每個值的型別都是字串。在型別規格中為這些值命名，以區分它們。
- `address`：可以是 `address_map`，也可以是 `address_tuple`。

## 6. 為地址的格式化撰寫文件

為 `Form.format_address/1` 函式撰寫文件和型別規格。文件內容應該是：

```
Formats the address as an uppercase multiline string.
```

型別規格應該說明這個函式接受一個引數（地址），並回傳一個字串。
