# 指示補充

## 實作

物品由 [記錄](https://lfe.gitbooks.io/reference-guide/content/16.html) 表示，定義於`item.lfe`。
使用`item-weight`取得重量，使用`item-value`取得值。

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
