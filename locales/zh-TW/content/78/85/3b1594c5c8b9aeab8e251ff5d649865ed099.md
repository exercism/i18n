# 說明補充

## Callable

在 PHP 中，有個概念叫做 [callable](https://www.php.net/manual/en/language.types.callable.php)。

它可以有多種形式，不過我們會把重點放在[匿名函式](https://www.php.net/manual/en/functions.anonymous.php)。

我們可以把匿名函式存進變數，再用參數呼叫它：

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
