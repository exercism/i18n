# 求助

如果你遇到困難需要協助，可以參考下列資源：

- [The Emacs Wiki](http://emacswiki.org/) 非常寶貴，值得你花很多時間在這裡。
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) 是 GNU Emacs 的官方手冊。
- IRC：在 [Libera.Chat](https://libera.chat/) 上有 `#emacs`、`#org-mode` 以及其他許多 Emacs 套件的頻道，也有許多熱心的人在線上。而且有了 Emacs，連上 IRC 就只差`M-x erc`這個指令。
- Matrix：在 [Matrix](https://matrix.org/) 上有 [emacs](https://matrix.to/#/#emacs:matrix.org)、[org-mode](https://matrix.to/#/#org-mode:matrix.org) 以及其他 Emacs 套件的聊天室。你可以[加入 Emacs 的 Matrix 空間](https://matrix.to/#/#emacs-space:matrix.org)，了解有哪些頻道可以參加。想在 Emacs 裡面連上 Matrix，可以使用 [Ement.el](https://github.com/alphapapa/ement.el) 套件。
- 你可以用 [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) 和 [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) 搜尋你的問題，看看是不是已經有人問過。你也可以在上面發問和回答問題。
