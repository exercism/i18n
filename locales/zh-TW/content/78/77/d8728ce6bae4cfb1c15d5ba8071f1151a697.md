# 說明

在這個練習中，你將撰寫程式碼，記錄你想在 Exercism 上學習的程式語言陣列。

一共有六個任務，全都會涉及處理陣列。

## 1. 建立新陣列

為了記錄你想學習的程式語言，你需要建立一個新的陣列。定義 `newList` 繫結，讓它包含一個全新的空陣列。

```fsharp
newList
// => []
```

## 2. 定義既有的陣列

目前你手上有張紙，上面列出你想學習的程式語言：F#、Clojure 和 Haskell。定義 `existingList` 繫結來代表這個陣列。

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. 在陣列中新增一個程式語言

當你在 Exercism 上探索、發現更多有趣的程式語言時，你會想把它們加進陣列裡。實作 `addLanguage` 函式，把新的程式語言加到陣列開頭。

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. 計算陣列中的程式語言數量

一個一個數程式語言很不方便。實作 `countLanguages` 函式，計算陣列裡有多少個程式語言。

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. 反轉陣列

某個時刻，你發現你的陣列其實是反著排的！實作 `reverseList` 函式來反轉你的陣列。

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. 檢查陣列是否令人興奮

雖然你熱愛所有程式語言，但 F# 在你心中有個特別的位置。因此，只要符合以下情況，你就會對一個程式語言的陣列感到非常興奮：

- 陣列中的第一個是 F#。
- 陣列中的第二個項目是 F#，而且陣列裡只有兩個或三個程式語言。

實作 `excitingList` 函式，檢查一個程式語言的陣列是否令人興奮：

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
