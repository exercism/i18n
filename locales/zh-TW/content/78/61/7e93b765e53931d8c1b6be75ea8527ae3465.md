# 簡介

## 數字

C# 裡有兩種不同的數字：

- 整數：小數點後沒有位數的數字（也就是沒有小數部分的數）。例如 `-6`、`0`、`1`、`25`、`976` 和 `500000`。
- 浮點數：小數點後有零個或多個位數的數字。例如 `-2.4`、`0.1`、`3.14`、`16.984025` 和 `1024.0`。

C# 中最常見的兩種數值型別是 `int` 和 `double`。`int` 是 32 位元的整數，`double` 則是 64 位元的浮點數。

算術運算使用標準的算術運算子來完成。數字可以用標準的數值比較運算子，以及相等（`==`）與不相等（`!=`）運算子來比較。

C# 有兩種數值轉換：

1. 隱式轉換：不會遺失任何資料，也不需要額外的語法。
2. 顯式轉換：可能會遺失資料，而且需要額外的語法，也就是所謂的轉型。

由於 `int` 的精確度比 `double` 低，從 `int` 轉換成 `double` 是安全的，因此屬於隱式轉換。不過，從 `double` 轉換成 `int` 可能會遺失資料，所以需要顯式轉換。

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## `if` 敘述

在這個練習中，你必須依條件執行邏輯。在 C# 裡，最常見的做法是使用 `if/else` 敘述：

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if` 敘述的條件必須是 `bool` 型別。C# 沒有 _truthy_ 值的概念。
