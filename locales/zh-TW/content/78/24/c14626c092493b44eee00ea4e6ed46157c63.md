# 簡介

我們使用的語言 Lisp 這個名字代表 _LIST Processing_，你可能會以為這個語言內建處理項目列表的功能，而你猜得沒錯！

雖然 Common Lisp 還有列表以外的資料結構，列表仍然被大量使用。

Common Lisp 中的列表是一連串的項目。它也被稱為**cons**（大多是基於歷史原因）。
項目本身不必是相同的型別。
例如，你可以有一個包含`1`、`two`、`"III"`的列表。

## 建立列表

你可以直接輸入像這樣加上引號的列表：`'(1 two "III")`，這會建立一個列表並對它求值（它會求值為`(1 two "III")`）。

建立列表還有兩個主要的函式：`list`和`cons`。

`list`接受零個或多個引數，並求值為以這些值建立的列表：

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`接受兩個項目，並建立一個列表，其中第一個項目是它的`car`（列表的頭部），第二個項目是它的`cdr`（列表的其餘部分）：

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

`car`和`cdr`這兩個函式可以用來存取列表的`car`和`cdr`。

（`first`和`rest`是`car`和`cdr`的同義詞，運作方式完全相同。）

## 長度與隨機存取

列表的長度可以用`length`取得。
空列表的長度為零。

任意項目都可以用`nth`存取（注意，列表的索引從 0 開始）。

要求一個比列表長度更大的索引並_不_算錯誤。
它會改為求值為`nil`：

```lisp
(nth 23 '(short list)) ; => nil
```

也有幾個輔助方法可以存取列表開頭的項目：`first`、`second`、`third`，一路到`tenth`。很方便吧？

## 合併列表

兩個或多個列表可以用`append`合併：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

傳給`append`的每個引數都必須是列表。
