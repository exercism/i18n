# 安裝

要開始做這些練習，你需要安裝以下軟體：

1. [`OPAM`，OCaml 套件管理工具](https://opam.ocaml.org/)

   請參考 [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)，
   了解如何為你的作業系統安裝並設定 `OPAM`。

2. OCaml 編譯器

   查看可用的版本列表：

   ```bash
   opam switch
   ```

   如果你已經有 OCaml 5.1 的 switch，可以執行 `opam switch <switch-name>` 載入它，或執行以下指令建立新的 switch：

   ```bash
   opam switch create exercism 5.4.0
   ```

   這裡的 `exercism` 名稱是選填的，不過為你的 switch 命名是個好習慣。

3. 安裝擴充標準函式庫和測試函式庫

   執行以下指令，安裝這個 track 所需的相依套件：

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   有些練習只會用到 OCaml 標準函式庫，有些則會用到 Jane Street 的擴充函式庫 Base 與 Core_kernel。
   測試函式庫叫做 OUnit，部分練習還會額外使用 QCheck 函式庫來做基於屬性的測試。
   執行上面的指令就會安裝這些函式庫。

4. 安裝並使用互動式 shell（選填）

   [設定與使用 `utop`](https://dev.realworldocaml.org/install.html) 的摘要：

   ```bash
   opam install utop
   ```

   在你的家目錄建立一個名為 `.ocamlinit` 的新檔案，並在裡面加入以下幾行：

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. 在 VS Code 中安裝工具（選填）

   如果你使用 VS Code：
   - 從[這裡](https://github.com/ocaml/ocaml-lsp)安裝 OCaml 語言伺服器。
   - 從[這裡](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform)安裝 OCaml VS Code 擴充功能，或搜尋由 Ocaml Labs 推出的 `OCaml Platform`。
