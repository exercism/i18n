# 簡介

## 抽象語法樹

抽象語法樹（AST），也稱為_引用運算式_，是一種把程式碼表示成資料的方式。

抽象語法樹裡的每個節點，都是一個由三個元素組成的元組。

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

第一個元素是原子，代表運算。第二個元素是關鍵字陣列，也就是中介資料。第三個元素是引數的陣列，裡面包含其他節點。整數、原子和字串等字面值，在抽象語法樹中會直接以本身來表示，而不是用由三個元素組成的元組。

### 將程式碼轉換成抽象語法樹

把 Elixir 程式碼轉換成抽象語法樹，以及把抽象語法樹轉回程式碼，都屬於標準函式庫的一部分。你可以在`Code`模組（例如把含有程式碼的字串轉換成抽象語法樹）和`Macro`模組（例如走訪抽象語法樹，或把它轉換成字串）裡，找到處理抽象語法樹的函式。

請注意，標準函式庫中所有的函式都用「quoted」這個名稱來表示抽象語法樹（是_引用運算式_的簡稱）。

把程式碼轉換成抽象語法樹的特殊形式叫做`quote`。它接受一個程式區塊，並回傳該區塊的抽象語法樹。

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

### 使用情境

能把程式碼表示成抽象語法樹，是 Elixir 元程式設計的核心。_巨集_是一種撰寫能產生 Elixir 程式碼的 Elixir 程式碼的方式，它的運作方式就是把抽象語法樹當作輸出回傳。

抽象語法樹的另一個使用情境是靜態程式碼分析，例如 Exercism 自己的工具 Analyzer，你或許已經認識它了，它就是那個會在你的解答上留言的小機器人。
