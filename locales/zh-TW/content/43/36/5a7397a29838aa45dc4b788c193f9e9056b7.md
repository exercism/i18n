# 說明補充

## 例外訊息

有時你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，你應該一律加上**有意義的錯誤訊息**，指出錯誤的來源。這能讓程式碼更容易閱讀，也對除錯很有幫助。如果你知道錯誤來源屬於某種特定型別，可以選擇引發其中一種[內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然應該加上有意義的訊息。

這個練習要求你在 `say()` 的數字輸入超出範圍時，使用 [`raise` 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)「拋出」`ValueError`。只有當你同時 `raise` 這個 `exception` 並附上訊息時，測試才會通過。

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception` 型別的引數：

```python
# if the number is negative
raise ValueError("input out of range")

# if the number is larger than 999,999,999,999
raise ValueError("input out of range")
```
