# 安裝

## 安裝 Godot Engine

GDScript track 建構在 [Godot Engine][godot-engine] 之上，可在 Windows、Linux、macOS 與 Android 上執行。
目前，[在本機練習][working-locally]用的測試執行器需要 Linux。
這個 track 需要 Godot 4.0 或以上的版本。

安裝完成後，你可以在終端機執行以下指令，確認 CLI 是否安裝成功喔：

```bash
godot --version
```

## 安裝 Exercism GDScript track 測試執行器

你必須先正確[安裝 Godot][installation]，才能使用測試執行器。

為了建構並測試 Exercism 的 GDScript 腳本，Godot 會透過 CLI 以「headless」模式執行。
這些指示目前需要 Linux 與 bash。

### 步驟 1：安裝整體的測試執行器基礎架構

為了設定測試環境，請複製 [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] 並將其內容移到`/opt/test-runner/`：

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 步驟 2：下載單一練習的測試執行器腳本

假設你已經設定好`exercism`工具，並下載了至少一個 GDScript 練習，它應該已經在你的工作區底下建立了一個`gdscript`資料夾（執行`exercism configure`即可看到），用來存放這些練習。
請將[測試執行器][test-local-gdscript-solution]儲存在這個資料夾，並將該檔案標記為可執行。

## 執行測試

完成安裝步驟後，你應該可以從任何練習目錄（例如`~/exercism/gdscript/two-fer`）開始，執行腳本（位於上一層，也就是`../`）來測試你在該練習的本機解答：

```sh
../test-local-gdscript-solution.sh
```

[gdscript-test-runner]: https://github.com/exercism/gdscript-test-runner
[test-local-gdscript-solution]: https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test-local-gdscript-solution.sh

## 使用 IDE

要在像 [Visual Studio Code][vscode] 這樣的編輯器中使用 GDScript 語法醒目提示，你需要安裝 [godot-tools][godot-tools] 這類擴充功能，並讓除錯伺服器保持運作。
每當專案在 Godot 自己的編輯器中開啟時，Godot 就會自動啟動這個除錯伺服器，並持續運作，直到專案或 Godot 本身關閉為止。
