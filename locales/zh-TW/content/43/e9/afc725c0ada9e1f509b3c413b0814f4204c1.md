# 簡介

[可變參數][variadic-parameters]讓函式能針對單一參數，接受零個或多個指定型別的值。
只要在參數的型別標註後面加上三個點（`...`），就能定義可變參數。

在函式主體內，Swift 會將這些值以指定型別的陣列形式提供使用：

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
如果函式在可變參數後面還有其他參數，那麼緊接在可變參數後的第一個參數**必須**要有明確的引數標籤，Swift 才知道可變引數清單在哪裡結束。
~~~~
