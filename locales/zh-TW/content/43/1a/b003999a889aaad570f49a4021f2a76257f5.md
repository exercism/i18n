# 測試

如果你的 PATH 裡有 8th 執行檔，請輸入這個指令：

```bash
8th -f test.8th
```

如果 PATH 裡找不到 8th 執行檔，在 Windows 上請輸入

```cmd
\path\to\8th -f test.8th
```

Linux 或 macOS：

```bash
/path/to/8th -f test.8th
```

## 在 REPL 中測試

啟動 8th，並載入 test-words.8th：

```sh
8th -f test-words.8th
```

這會開啟一個 CLI 工作階段，等你在解答檔案裡寫好一些程式碼之後，就可以把它載入 REPL。
例如，在「word-count」這個練習裡，你可以輸入：

```8th
"word-count.8th" f:include
```

接著就能用以下指令執行測試
```sh
"word-count-tests.8th" f:include
```

或者你也可以從那個檔案複製貼上單一測試，或自己輸入一個。

## 略過的測試

完成一個練習，代表要讓它所有的測試都通過。
預設情況下，執行測試時只會跑一個測試（也就是第一個）。
這是刻意設計的，讓你專注在讓那一個測試通過就好。
一旦它通過了，你就可以把`SKIP-REST-OF-TESTS`這個詞移到它後面，來啟用下一個測試。

## 覆寫略過設定

如果想執行所有測試，包括`SKIP-REST-OF-TESTS`這個詞之後的測試，你可以把環境變數`RUN_ALL_TESTS`設成`true`。
只想在執行測試期間設定這個變數的一個方法是（macOS 和 Linux）：

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
