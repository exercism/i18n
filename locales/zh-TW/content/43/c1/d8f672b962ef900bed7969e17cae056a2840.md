# 簡介

## 日期與時間

在 Common Lisp 中，時間有四種表示方式，這裡會介紹其中兩種。

- 通用時間是一種絕對時間，是一個整數，代表自`1900-01-01T00:00:00Z`（也就是 UTC 時間 1900 年 1 月 1 日的午夜）起算的秒數。
- 解碼時間是由 9 個值組成的元組，這些值共同代表某個特定的日曆時間：秒、分、時、日、月、年、星期、日光節約時間旗標、時區。
（詳見下文。）

### 通用時間

要取得目前的通用時間，可以使用`get-universal-time`或`get-decoded-time`。
前者回傳自`1900-01-01T00:00Z`起算的目前秒數，後者則以解碼格式回傳同樣的資料。

### 解碼時間

`decode-universal-time`和`encode-universal-time`是處理時間的主要函式。
前者接受一個通用時間，並以[多重值][concept-multiple-values]的形式回傳解碼時間值；後者接受解碼時間的各個值作為引數，回傳一個通用時間。

兩者都接受一個選用的時區引數。
時區的格式請見下文。

解碼時間是一組值：

- *秒*：0 到 59 之間的整數
- *分*：0 到 59 之間的整數
- *時*：0 到 23 之間的整數
- *日*：1 到 31 之間的整數（上限當然取決於月份和年份）
- *月*：1 到 12 之間的整數
- *年*：代表年份的整數。
- *星期*：0 到 6 之間的整數。0 代表星期一，1 代表星期二，依此類推……6 代表星期日。
- *日光節約時間旗標*：值為 true 表示日光節約時間正在實施。
- *時區*：介於 -24 與 24 之間的數字，代表與 UTC 的時差。
這個數字是有理數，且必須是`1/3600`的倍數

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```

## 多重值

在 Common Lisp 中，函式不只可以回傳一個值，還可以回傳多個值。
例如`floor`會朝零的方向向下取整，並回傳兩個值：第一個是取整後的值，第二個是餘數。

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
（我們會把回傳的多個值顯示在輸出的不同行。）

### 回傳多個值

想讓函式回傳多個值，就要使用`values`存取器：

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

### 處理多個值

如果你只在意第一個值，那就不需要做任何特別的事，語言本身會處理好：

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

不過，如果你想取得其他那些值，就會需要用到幾個函式。
主要的兩個巨集是`multiple-value-list`和`multiple-value-bind`。
它們用來包住會回傳多個值的東西，並捕捉所有的值。
第一個會建立一個包含所有值的清單。
第二個則讓你將變數綁定到各個值上。

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

另一個實用的函式是`nth-value`
