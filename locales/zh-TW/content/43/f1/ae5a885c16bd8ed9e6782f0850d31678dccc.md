# 指令說明

在這個練習中，你要實作一種記錄高分的方式，用來追蹤你當地遊樂場裡最熱門遊戲的高分。

你要實作 7 個函式，全都和回傳及操作高分資料的字典有關。

## 1. 定義一個新的高分字典

建立一個不接受任何參數的函式`newScoreBoard()`，它會回傳一個新的高分字典，這個字典的鍵是型別為`String`的值，而值則是型別為`Int`的值。

## 2. 將玩家加入高分字典

若要將玩家加入高分字典，請定義`addPlayer(_:_:_:)`，這是一個接收 3 個參數的函式：

- 第一個參數是分數的字典。
    這應該是一個輸入輸出參數。
- 第二個參數是玩家名稱，以字串表示。
- 第三個參數是分數，以整數表示。
    這個參數是選用的，請把第三個參數的預設值設為 0。

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. 從分數字典中移除玩家

若要從高分字典中移除玩家，請定義`removePlayer(_:_:)`，它接收 2 個參數：

- 第一個參數是分數的字典。
    這應該是一個輸入輸出參數。
- 第二個參數是玩家名稱，以字串表示。

如果玩家在字典裡，這個函式應該將他從字典中移除；否則就什麼都不做。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. 重設玩家的分數

若要重設玩家的分數，請定義`resetPlayer(_:_:)`，它接收 2 個參數：

- 第一個參數是分數的字典。
    這應該是一個輸入輸出參數。
- 第二個參數是玩家名稱，以字串表示，也就是你想重設分數的玩家。

這個函式會將該玩家的分數設為 0。
如果玩家不在字典裡，就什麼都不做。

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. 更新玩家的分數

若要透過加上先前的分數來更新玩家分數，請定義`updateScore`，它接收 3 個參數：

- 第一個參數是分數的字典。這應該是一個輸入輸出參數。
- 第二個參數是玩家名稱，以字串表示，也就是你想更新分數的玩家。
- 第三個參數是你想**加到**已儲存高分上的分數。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. 取得依玩家名稱排序的玩家與分數清單

定義函式`orderByPlayers`，它接收 1 個參數：

- 第一個參數是分數的字典。

這個函式會回傳一個由`(String, Int)`元組組成的陣列，內容是玩家和他們的高分，並依玩家名稱遞增排序。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. 取得依玩家分數遞減排序的玩家清單

若要取得依分數遞減排序的玩家清單，請定義`orderByScores`，它接收 1 個參數：

- 第一個參數是分數的字典。

這個函式會回傳一個由`(String, Int)`元組組成的陣列，內容是玩家和他們的高分，並依玩家分數遞減排序。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
