# 關於

整數是不含小數點的完整數字（例如 `-6`、`0`、`25`、`1234` 等等）。

整數型別分為兩個子型別：`fixnum` 和 `bignum`。
* `fixnum` 的定義是至少有 16 位元的有號整數，但依實作不同，實際上可能更大。
* `bignum` 則是一種型別，包含任何比 `fixnum` 更大的整數。

在 Common Lisp 中，整數可以任意大或任意小，所以使用時不必擔心「溢位」。
其他語言可能會遺失精確度，或是大型數字會溢位，但在 Common Lisp 中，整數的大小只受限於可用記憶體的多寡。

```lisp
;; Big integers are no problem
(expt 2 200) ; => 1606938044258990275541962092341162602522202993782792835301376
```
