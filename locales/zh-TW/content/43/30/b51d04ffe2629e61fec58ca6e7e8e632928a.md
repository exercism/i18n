# 說明

你附近有一所學校，他們的學生會非常活躍。
學生會由會長管理，每 2 年會舉辦一次選舉，選出新的會長。
今年的選舉決定需要一套新的數位計票系統。

學校需要你幫忙打造這套新系統。

## 1. 建立計票器

新的投票系統首先需要的東西之一，就是計票器。
計票器可以用來追蹤某位候選人目前的票數。

建立一個函式 `new_vote_counter`，它接受某位候選人的初始票數，並回傳一個以該初始票數初始化的 `VoteCounter` struct 快照。

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. 從計票器取得票數

現在你已經有辦法建立新的計票器了！
但你發現，新系統還需要能從計票器取得票數的方法。

建立一個函式 `vote_count`，它會接受一個計票器（`@VoteCounter`）作為引數，並回傳該計票器中的票數。

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. 增加計票器的票數

終於可以開始計票了！
現在你需要能增加計票器票數的方法。

建立一個函式 `increment_vote_count`，它會接受一個計票器（`@VoteCounter`）和一個票數作為引數，並將該計票器的票數增加那麼多。

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. 建立選舉結果

所有票都計完後，該準備向全校公布結果了。
你發現，只有計票器是不夠的。
需要有辦法把票數和特定的候選人關聯起來。

建立一個函式 `new_election_result`，它會接收候選人的名字和票數，並回傳一個新的選舉結果。

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

選舉結果的 struct 已經幫你建立好了，定義如下：

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. 公布結果

該向學校公布新的會長了！
新會長會在學校的數位公布欄上公布。

訊息應該顯示新會長的名字和得票數，格式如下：`<candidate_name> (<votes>)`。
以下是這種訊息的範例：`"Peter (51)"`。

建立一個函式 `display_result`，它會接收一個 `@ElectionResult` 作為引數，並回傳含有要顯示訊息內容的 `ByteArray`。

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. 重新計票

為了確認最終結果是否準確，票數重新計算了一次。
重新計票時發現，有些候選人的票數差了一票。

建立一個函式 `decrement_votes_of_candidate`，它會接收最終結果，以及要減少票數的候選人名字。
最終結果以 `Felt252Dict<u32>` 的形式提供，其中鍵是候選人的名字，值是他們的總票數。

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
