# 智慧指標

Cairo 中的智慧指標是強大的工具，能安全又有效率地管理記憶體。

智慧指標是一種資料結構，行為就像一般的指標，但多了安全機制，可以避免常見的記憶體管理問題，例如解參考空指標或存取未初始化的記憶體。

## 什麼是智慧指標？

一般而言，指標是一個儲存記憶體位址的變數，通常指向存放在該位址的值。

不過，原始指標可能很危險：如果指標沒有指向有效的記憶體，或是被錯誤地解參考，就可能導致程式當機或出現無法預期的行為。

智慧指標透過對記憶體管理施加嚴格的規則來解決這個問題，確保記憶體的存取既安全又受控。

Cairo 和 Rust 等許多現代語言一樣，使用智慧指標來防止不安全的記憶體存取。

Cairo 的智慧指標不僅儲存記憶體位址，還會追蹤所有權並確保記憶體安全。

## Cairo 中的智慧指標型別

Cairo 提供多種智慧指標型別，包括`Box<T>`和`Nullable<T>`，各自有不同的用途。

我們來仔細看看這些型別的運作方式，以及你可能在什麼時候用到它們。

### `Box<T>`

`Box<T>`型別是 Cairo 最主要的智慧指標。

它讓你可以把資料存放在一個特殊的記憶體區段，稱為「boxed segment」。`Box<T>`是指向這個區段的指標；當你建立一個 box 時，就是在這個區段中為資料配置空間。

在下列情況，box 特別適合：

- 你需要儲存某個型別的值，而該型別的大小無法在編譯期決定。
- 你有大量資料，而且想在轉移所有權時不要複製這些資料。

使用 box，就能更有效率地儲存大型資料結構。

把`Box<T>`傳給函式時，只會傳遞指標，不需要複製整份資料，因此能提升效能，對大型結構尤其明顯。

### `Nullable<T>`

`Nullable<T>`是 Cairo 另一種重要的智慧指標。

它可以用來指向型別`T`的有效值，或者在沒有值時是`null`。

當你需要儲存不一定存在的值時，這個型別就很有用，例如字典可以包含選用的元素。

在 Cairo 中，`Nullable<T>`通常用在字典裡，處理無法套用預設值的情況。

它讓你可以有條件地儲存值，更容易安全地處理資料不存在的情形。

## 智慧指標與記憶體安全

使用智慧指標的主要優點之一，就是有助於確保記憶體安全。

透過管理所有權與存取規則，Cairo 能避免常見的問題，例如解參考空指標或懸空指標。

智慧指標會追蹤資料何時不再需要，並在資料離開作用域時自動釋放記憶體，降低記憶體洩漏的風險。

### 範例：用`Box<T>`處理遞迴型別

許多程式語言都有一個常見的難題：如何處理遞迴型別。

遞迴型別指的是會包含自身參照的型別。

如果沒有妥善的記憶體管理，定義遞迴型別可能會引發無限遞迴之類的問題。

在 Cairo 中，`Box<T>`讓你能安全地定義遞迴型別。

舉例來說，你可以用`Box<T>`實作二元樹，其中每個節點都包含指向另一個節點的參照。

把參照存放在 box 中，Cairo 就能確保記憶體用量是有限的，編譯器也能決定這個結構所需的記憶體大小。

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### 智慧指標的效能優勢

智慧指標也能提升程式的效能。

使用`Box<T>`時，傳遞的只是指向資料的指標，而不是複製整份資料結構。

處理大型資料集時尤其有用，因為它能大幅減少記憶體操作的額外負擔。

在下面的範例中，資料透過`Box<T>`以參照方式傳遞，避免複製整份結構的成本：

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

在這個範例中，`pass_pointer`接收的是`Box<Cart>`而不是`Cart`，減少了函式呼叫過程中複製的記憶體量。
