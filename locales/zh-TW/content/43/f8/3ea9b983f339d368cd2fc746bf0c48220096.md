### 動態函式呼叫

awk 的函式不是一級物件：它們無法像某些其他語言允許的那樣被傳來傳去。
不過，變數可以存放函式的_名稱_（一個字串），並用特殊的`@varname(args)`標記法來呼叫該函式。
例如：

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
這在[間接函式呼叫][indirect]中有說明。
這是`gawk`的擴充功能。
