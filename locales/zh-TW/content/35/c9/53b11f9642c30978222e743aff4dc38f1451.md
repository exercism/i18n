# 指令

你的任務是將 RNA 序列轉譯成蛋白質。

RNA 鏈由三個核苷酸組成的序列構成，這些序列稱為**密碼子**。
每個密碼子會轉譯成一個**胺基酸**。
這些胺基酸結合在一起後，就會形成蛋白質。

在現實世界中，總共有 64 個密碼子，對應到 20 種胺基酸。
不過在這道練習裡，你只會用到這 64 個當中的少數幾個。
它們列在下表中：

| 密碼子             | 胺基酸        |
| ------------------ | ------------- |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

舉例來說，RNA 字串「AUGUUUUCU」有三個密碼子：「AUG」、「UUU」和「UCU」。
它們分別對應到 Methionine、Phenylalanine 和 Serine。

## 「STOP」密碼子

從上表可以注意到，有三個**「STOP」密碼子**。
如果你遇到其中任何一個密碼子，就忽略序列剩下的部分，因為蛋白質已經完成了。

舉例來說，「AUGUUUUCUUAAAUG」包含一個 STOP 密碼子（「UAA」）。
一旦處理到那個位置，我們就會停下來。
因此我們只考慮它前面的部分（也就是「AUGUUUUCU」），而不理會它之後的任何密碼子（也就是「AUG」）。

想進一步了解，請參閱[維基百科上的蛋白質轉譯][protein-translation]。
