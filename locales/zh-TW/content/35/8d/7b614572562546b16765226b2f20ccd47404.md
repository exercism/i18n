# 使用型別規格

[comment]: # (當解法沒有型別規格時，就會顯示這個警告)

加入[型別規格](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs)（`@spec`），說明函式輸入與輸出之間的契約。

- Elixir 是動態型別語言，型別檢查只會在執行階段發生。使用型別規格可以讓 linter 與靜態分析工具（例如以 Erlang 的[`Dialyzer`](http://erlang.org/doc/man/dialyzer.html)為基礎的[`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html)）評估程式碼是否有非預期的行為。
- 你可以在[語言文件](https://hexdocs.pm/elixir/typespecs.html#content)中找到所有內建型別的[完整清單](https://hexdocs.pm/elixir/typespecs.html#basic-types)。
- 型別可以加或不加括號來指定，`atom()`與`atom`
  - Exercism 的 Elixir 風格是不加括號。

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
