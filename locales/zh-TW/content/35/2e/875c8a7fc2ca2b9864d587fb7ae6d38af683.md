# 簡介

若要在同一個專案中的不同 Elixir 模組之間共用程式碼，你需要以完整名稱來參照外部的模組。但如果那個名稱太長或太容易混淆呢？

特殊形式`alias`可以讓你縮短或變更參照外部模組時所用的名稱。未帶任何引數使用時，它會把模組名稱縮減到只剩最後一個區段，例如`MyApp.Logger.Settings`會變成`Settings`。可以使用`:as`選項指定自訂名稱。

別名通常會加在模組定義的開頭。

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```
