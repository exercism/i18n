# 三元運算子

三元運算子提供了另一種語法，用來執行 `if..else..` 比較並回傳一個值。

## 語法

PHP 提供了 `if` 敘述，可以根據條件的「真假」來決定要執行的動作。

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

另一種方式是，三元運算子也能表示同樣的操作：

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

這種比較的語法很簡短，寫成`(condition) ? (evaluate if true) : (evaluate if false);`。
