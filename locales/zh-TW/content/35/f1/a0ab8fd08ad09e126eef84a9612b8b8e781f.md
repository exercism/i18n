# 介紹

## 陣列推導式

推導式提供了一種能以宣告式輕鬆轉換 _Enumerable_ 的機制。

要宣告一個最簡單的推導式，可以使用 `for` 關鍵字，後面接著一個 _產生器_，以及一個會根據列舉值建立新值的 _do 區塊_。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

推導式也可以有 _篩選條件_。沒有通過篩選條件的值，會從最終的陣列中被移除：

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

我們可以跨越多行，宣告更複雜的推導式：

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

使用多個產生器可以建立 _笛卡兒積_。也就是說，第一個產生器產生的每個值，都會和第二個產生器產生的每個值配對一次：

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
