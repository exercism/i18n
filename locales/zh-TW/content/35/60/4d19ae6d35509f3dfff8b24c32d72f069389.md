# 簡介

當一個 quotation 需要*記住*來自周遭環境的值時（其他語言稱之為*閉包*），Factor 會用上兩項工具：`curry`這個詞，以及`'[ ]`的 *fry* 語法。

## `curry`：捕捉一個值

`curry`（位於[`kernel`][kernel]）接受一個值與一個 quotation，並回傳一個已把該值內嵌進去的新 quotation：

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

想捕捉兩個值，就連續套用兩次`curry`：

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`：串接兩個 quotation

`compose`（位於[`kernel`][kernel]）把兩個 quotation 黏在一起：

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Fry quotation：捕捉多個值

當需要捕捉的值超過一兩個時，一連串的`curry`呼叫就會變得難以閱讀。*fry* 使用`'[ … ]`，搭配一個或多個`_`佔位符；每個`_`都會依序由一個從資料堆疊取出的值取代：

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

`curry`與 fry 都會在建構出閉包的那一刻，就從堆疊上*消耗*掉它們的值。上面那一行不會在堆疊上留下任何東西，而且可以直接取代`[ + + ] curry curry`。

佔位符會由左至右，依序填入堆疊中由下而上的值：`2 3 '[ _ _ ]`的結果是`[ 2 3 ]`，而不是`[ 3 2 ]`。

fry 還能*深入*巢狀 quotation，讓你可以把捕捉到的值放在你希望它們出現的確切位置：

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

`_`位於內層`[ … ]`裡，但 fry 依然會把它填上。

## 帶有宣告效果的`call`

當你終於要執行一個儲存起來的 quotation 時，在`call`上宣告它的堆疊效果，編譯器就能對它做型別檢查：

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## 向量運算

[`math.vectors`][math.vectors]詞彙庫會逐元素結合兩個長度相同的序列。`v+`和`v*`會將它們相加或相乘；`vmax`和`vmin`則會保留每個分量中較大或較小的那個。每個運算都會回傳一個長度為 2 的陣列：

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
