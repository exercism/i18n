# 指令

在這個練習中，你要幫高中情侶在社群媒體上公開告白。

## 1. 顯示以愛心分隔的情侶名字

請實作靜態方法`HighSchoolSweethearts.DisplaySingleLine()`，接收兩個名字，並將它們以愛心分隔後顯示。
格式化後的字串寬度應為 61 個字元，並讓愛心位於字串正中央。

所有名字都保證能輕鬆容納在這行的寬度內。

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. 用 ascii 藝術愛心顯示這對情侶的姓名縮寫

實作靜態方法`HighSchoolSweethearts.DisplayBanner()`，它會顯示兩組以加號分隔的姓名縮寫。

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. 用依地區設定調整的宣告，讓德國交換學生感到賓至如歸。

實作靜態方法`HighSchoolSweethearts.DisplayGermanExchangeStudents()`，顯示我們德國交換學生的交往開始日期與交往時間長度。

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
