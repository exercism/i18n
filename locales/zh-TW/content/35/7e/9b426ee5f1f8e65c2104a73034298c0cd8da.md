# Babashka 文字編輯器整合

## nREPL

### Emacs: [CIDER](https://cider.mx/)

這是這一切的開端，而它的 [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) 生態系支撐著許多其他外掛。

1. 為你的平台安裝 [Emacs](https://www.gnu.org/software/emacs/download.html)。

2. 選擇一套現成的 Emacs 發行版（[Prelude](https://prelude.emacsredux.com/)、[Spacemacs](https://www.spacemacs.org/) 和 [Doom Emacs](https://github.com/hlissner/doom-emacs) 都很棒），或把下面這段加進你的`init.el`：

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

以下摘要自 [CIDER 文件](https://docs.cider.mx/cider/platforms/babashka.html)：

從專案目錄啟動 nREPL 伺服器：

```bash
$ bb --nrepl-server
```

用`C-x C-f`建立或開啟任何 Clojure 檔案（`.clj`），再用`C-c C-x c j`（cider-connect-clj）連上它。

[基本的 CIDER 按鍵綁定](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference)：

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` or `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` or `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. 安裝 [VSCode](https://code.visualstudio.com/)。

2. 安裝 [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva)。

目前 Calva 會把你的原始碼理解成位在某個資料夾（也就是一個 Clojure 專案）的脈絡裡。想建立這樣一個專案，用 [clj-new](https://github.com/seancorfield/clj-new) 是個不錯的方式：

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. 從專案目錄啟動 nREPL 伺服器：

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

在 VSCode 中開啟專案資料夾（Ctrl+K Ctrl+O），或從另一個終端機開啟：

```bash
$ cd bbtest
bbtest$ code .
```

4. 在 VSCode 中執行 Calva 指令`Connect to a running REPL`（ctrl+alt+c ctrl+alt+c）。出現提示時選擇`Generic`專案，並輸入`localhost:1667`。

REPL 指令：

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. 從[這裡](https://www.jetbrains.com/idea/download/index.html)下載 IntelliJ。
2. 依照[使用者指南](https://cursive-ide.com/userguide/)安裝 Cursive，並[設定相依項目](https://cursive-ide.com/userguide/deps.html)。
3. 更多資訊請參閱 [Cursive：使用 Babashka](https://cursive-ide.com/userguide/babashka.html)。

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. 安裝 [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. 安裝`chlorine`套件

3. 啟動 socket REPL：

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. 開啟 Atom 的 command palette（ctrl+shift+p），執行`Connect Clojure Socket REPL`指令，並使用`localhost`和`1666`

5. 透過`Edit`選單 -> `Keymap...`編輯 keymap.cson 中的按鍵綁定：

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

若使用 Emacs，請把下面這段加進你的`init.el`來安裝 [inf-clojure](https://github.com/clojure-emacs/inf-clojure)：

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

依照上面的方式啟動 socket REPL，然後在 Emacs 中執行`M-x inf-clojure-connect`（C-c M-c）。

用 C-c C-e 求值 form。若想取得 inf-clojure-mode（也就是 REPL）和 inf-clojure-minor-mode 中所有可用指令的清單，你可以呼叫 C-h f RET inf-clojure-mode 和 C-h f RET inf-clojure-minor-mode，或直接瀏覽它們的選單。

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

下載 [Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage)，並把它設為`vim`的別名。

* 安裝 [vim-plug](https://github.com/junegunn/vim-plug)：

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

建立`~/.config/nvim/init.vim`：

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

開啟 Neovim，執行指令`:PlugInstall`。

把`iced`指令加入 $PATH：

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* 啟動 socket REPL 伺服器、開啟原始碼檔案，然後執行`:IcedConnectSocketRepl 1666`。

預設的 REPL 指令（預設的`<Leader>`是`\`）：

- `<Leader>ei`：求值內層元素
- `<Leader>ee`：求值外層陣列
- `<Leader>et`：求值外層頂層陣列
