# 簡介

這個練習會討論方法參數的一些細節，以及它們在 C# 裡的用法。

參數會把資訊從呼叫端的方法傳遞給被呼叫的方法。

- 參數的行為可以透過 `ref`、`out` 這類修飾詞來調整。

- 帶有 `out` 修飾詞的參數會把值從被呼叫的方法傳回給呼叫端。這個參數可以不經初始化就傳給被呼叫的方法，而且無論如何，在被呼叫的方法裡，它一律被視為進入時尚未初始化。想了解參數修飾詞的行為與規則，最快的方式就是看範例（見下方）和編譯器訊息。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out` 參數必須在被呼叫的方法內被指定。

- 帶有 `ref` 修飾詞的參數會把值傳入被呼叫的方法。當方法回傳時，呼叫端會在该參數中看到被呼叫的方法所做的任何更新。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` 參數必須是變數，因為被呼叫的方法會直接操作呼叫端所看到的那個參數。
- `out` 和 `ref` 修飾詞在被呼叫的方法簽章和呼叫端都必須寫出來。
