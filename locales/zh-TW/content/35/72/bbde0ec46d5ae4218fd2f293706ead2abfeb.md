# 迴圈

一個**迴圈**會把同樣的事情反覆做很多次。

```sather
   loop
      ...
   end;
```

單獨一個迴圈永遠不會停下來，所以裡面必須有東西讓它結束。

## 找個地方來計數

迴圈幾乎總是需要一個會隨著進行而改變的值。那就是**變數**，而`::=`可以建立一個：

```sather
   total ::= 0;
```

這個變數叫做`total`，初始值是`0`，Sather 會從`0`推斷出它存放的是一個`INT`。之後，用`:=`就能放入新的值：

```sather
   total := total + 5;
```

從右往左讀：取出`total`現在的值，加上 5，再把結果放回`total`。

這樣建立的變數會一直存在到常式結束為止。

## until!

`until!`接受一個問題。每繞一圈就會問一次，當答案為 true 時，迴圈就當場停下來。

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

`n`會依序數 1、2、3……，而當`n`第一次超過`last`時，迴圈就會結束。少了`n := n + 1`，這個問題的答案就永遠不會改變，迴圈也會一直跑下去。

`until!`不一定要放在第一行。把它放在讓問題合理的位置：放在最前面，迴圈可能一次都不執行；放在最後面，則至少會執行一次。

`!`是名稱的一部分。Sather 用這種方式標記某些東西；這個標記的意義之後會再說明。

## break!

`break!`會立刻結束迴圈，不需要附帶任何問題。當停止的原因是在工作進行到一半才冒出來時，它就很好用。

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

`until!`和`break!`只有在`loop`裡面才有意義。兩者都不能單獨使用。
