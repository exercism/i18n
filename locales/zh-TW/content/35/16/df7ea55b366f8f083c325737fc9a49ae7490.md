# 關於

回想一下，`jq`支援和 JSON 相同的資料型態。
JSON 把**字串**描述為：

> 字串是由零個或多個 Unicode 字元組成的序列，以雙引號包住，並使用反斜線跳脫。

## 跳脫序列

在字串中，使用反斜線字元來嵌入「特殊」字元：

- `\"` 字面上的雙引號，
- `\\` 字面上的反斜線，
- 空白字元 `\n`、`\t`、`\r`、`\f`、`\b`
- Unicode 字元 `\uAAAA`，其中 `A` 是十六進位數字

## 字串長度

想知道字元的數量，可以使用[`length`][length]函式。

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

想知道實際的_位元組_數量，可以使用[`utf8bytelength`][utf8bytelength]函式。

```sh
$ jq -cn --args  '$ARGS.positional[] | utf8bytelength' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
27
```

## 子字串

可以使用 [**slice** 標記法][slice]來取出子字串。
語法是`.[i:j]`。
回傳的子字串長度為`j - i`，內容是從索引`i`（含）到索引`j`（不含）的字元。
任一個索引都可以是負數，此時會從字串尾端往回數。
任一個索引也可以省略，此時代表字串的開頭或結尾。
索引從 0 開始。

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## 串接

使用[`+`][+]來連接字串：

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

當拿到的是字串陣列時，使用[`add`][add]：

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## 分割與合併

分割可以使用[`split/1`][split/1]函式或[`/`][/]運算子：

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

[`split/1`][split/1]的反向操作是[`join/1`][join/1]。

我們經常需要把字串轉成字元陣列。
有兩種做法：

1. 用空字串分割

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. 用[`explode`][explode]拆成_碼點_陣列

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   [`implode`][implode]是[`explode`][explode]的反向操作。

## 找出子字串的索引

使用[`index/1`][index/1]函式；索引從 0 開始。

```jq
"hello" | index("el")'   # => 1
```

如果字串裡沒有這個子字串，結果會是`null`

```jq
"hello" | index("elk")   # => null
```

其他實用的函式還有[`rindex/1`][index/1]和[`indices`][indices]。

## 字串內插

在字串中，`\(expression)`這個序列會把該運算式的_結果_[嵌入字串][interpolate]：

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## 大小寫轉換

使用[`ascii_downcase`][ascii_downcase]和[`ascii_upcase`][ascii_downcase]函式來改變字串的大小寫。

## 把字串轉成數字

使用[`tonumber`][tonumber]函式從字串建立數字。

如果字串無法轉成數字，就會拋出錯誤，因此可能需要用到[`try-catch`][try-catch]。

```jq
$ jq -cn --args '$ARGS.positional[] | [., tonumber]' 42 3.14 oops 1e6 0xbeef
["42",42]
["3.14",3.14]
jq: error (at <unknown>): Invalid numeric literal at EOF at line 1, column 4 (while parsing 'oops')

$ echo $?
5

$ jq -cn --args '$ARGS.positional[] | try [., tonumber] catch "not a number"' 42 3.14 oops 1e6 0xbeef
["42",42]
["3.14",3.14]
"not a number"
["1e6",1000000]
"not a number"
```

請注意，[JSON 數字][json-numbers]並不包含某些語言支援的十六進位或八進位變化。

## 其他函式

這些函式的詳細資訊請查閱[手冊][manual]：

- 重複字串：`*`
- 測試是否包含：`contains/1`、`inside/1`、`indices/1`、`index/1`、`rindex/1`、`startswith/1`、`endswith/1`
- 修剪：`lsrimstr/1`、`rtrimstr/1`
- 格式化函式：`@text`、`@json`、`@html`、`@uri`、`@csv`、`@tsv`、`@sh`、`@base64`、`@base64d`
