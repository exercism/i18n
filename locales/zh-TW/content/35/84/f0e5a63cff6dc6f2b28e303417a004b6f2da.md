# 說明

在這個練習中，今天是情人節，你和你的另一半打算一起做些開心的事。你的另一半有很多點子，現在要請你幫這些點子評分，好從中挑出要進行的活動。

你的另一半提出了這些點子：

- 玩桌遊
- 放鬆一下
- 看電影
- 去餐廳

你有六項任務，幫助你選出情人節這天的活動。

## 1. 定義核准

針對另一半提出的每個點子，你要用三種選項之一來回應：yes、no 或 maybe。

定義 `Approval` 自訂型別，以下列三種情況來表示這些選項：`Yes`、`No` 和 `Maybe`。

## 2. 定義料理

你的另一半挑了兩間可能的餐廳：一間是韓式料理，另一間是土耳其料理。

定義 `Cuisine` 自訂型別，以下列兩種情況來表示這些料理：`Korean` 和 `Turkish`。

## 3. 定義電影類型

可以選的電影多到數不清，所以為了縮小範圍，你的另一半也列出了電影類型。

定義 `Genre` 自訂型別，用情況來表示下列類型：`Crime`、`Horror`、`Romance` 和 `Thriller`。

## 4. 定義活動

如前所述，你的另一半提出了五種不同的活動：玩桌遊、放鬆一下、看電影和去餐廳。

定義 `Activity` 自訂型別來表示這些活動類型：

- `BoardGame`：沒有附帶資料。
- `Chill`：沒有附帶資料。
- `Movie`：附帶 `Genre` 資料。
- `Restaurant`：附帶 `Cuisine` 資料。

## 5. 為活動評分

終於，你可以開始為另一半的點子評分了。對於另一半的點子，你的感覺是：

- 玩桌遊：no。
- 放鬆一下：no。
- 看電影：如果是浪漫電影就是 yes，否則就是 no。
- 去餐廳：如果是韓式料理就是 yes，如果是土耳其料理就是 maybe。

實作一個名為 `rateActivity` 的函式，它接受一個 `Activity` 值，並根據上述的感覺回傳對應的 `Approval`：

```elm
rateActivity (Restaurant Turkish)
-- => Maybe
```
