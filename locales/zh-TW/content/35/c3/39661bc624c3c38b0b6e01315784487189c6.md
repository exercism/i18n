# 說明

在這個練習中，你會寫一些程式碼，幫助你為購買車輛做好準備。

你要完成三個任務：判斷自己是否需要取得駕照、在兩輛車之間做出選擇，以及估算一輛中古車的合理價格。

## 1. 判斷你是否需要駕照

有些種類的車輛需要有駕照才能操作。
假設只有`"car"`和`"truck"`這兩種需要駕照，其他種類都可以在沒有駕照的情況下操作。

實作`needs_license`函式，它接收車輛的種類，並回傳一個布林值，指出你需要駕照才能操作這種車輛。

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. 在兩輛可能購買的車之間做出選擇

你已經評估過手邊可選的車輛。
你成功把選擇縮小到兩個，但還需要有人幫你做最後的決定。
實作`choose_vehicle`函式，它接收一個包含兩輛車的陣列，並回傳一個決定，也就是在字典順序中排在前面的那個選項。

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. 估算一輛中古車的價格

既然你已經做出決定，你會想確保自己在車商那裡拿到合理的價格。
因為你想買的是中古車，價格取決於車齡。
粗略估計的話，假設車齡不到 3 年，價格是全新時原價的 80%。
如果車齡超過 10 年，價格是 50%。
如果車齡至少 3 年但不超過 10 年，價格是原價的 70%。

實作`resell_price`函式，用`if`、`elif`和`else`套用這套邏輯。
它接收一個物件，裡面包含原價和車齡，並回傳車商的估計價格。

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
