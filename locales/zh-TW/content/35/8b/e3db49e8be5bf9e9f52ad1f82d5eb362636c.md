# 關於

Factor 的字元是*整數*，也就是 Unicode 碼位，因此直接用數值的 `<`、`>`、`=` 就能進行區分大小寫的排序。而[`unicode`][unicode]詞彙則在此之上加入了能感知 Unicode 的述詞，以及單一字元的大小寫轉換。

## 述詞

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## 大小寫轉換

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

字串層級的 `>upper`、`>lower` 和 `>title` 會把這些轉換套用到字串的每個字元上。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
