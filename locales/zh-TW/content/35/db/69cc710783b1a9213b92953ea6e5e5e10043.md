# 未使用 gofmt

對解答執行`gofmt`，這有助於將 Go 的程式碼排版。

在 Go 社群中，程式碼排版非常重要。
大多數 IDE 都可以設定成每次儲存時自動排版程式碼。例如：

- Visual Studio Code 有[很棒的 Go 支援](https://code.visualstudio.com/docs/languages/go)
- Vim 也有[很棒的 Go 擴充套件](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) 是專為 Go 打造的完整 IDE

手動執行`gofmt`：

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
