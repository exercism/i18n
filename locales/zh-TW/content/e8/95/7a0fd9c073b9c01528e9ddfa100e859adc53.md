# 簡介

## Agent

`Agent` 模組提供了一層抽象，用來建立[行程與 _receive-send_ 迴圈][exercism-processes]。接下來，我們把透過 `Agent` 模組啟動的行程稱為 _「agent 行程」_。我們可以選擇用一個 _agent 行程_ 來代表集中共享的狀態。

要啟動一個 _agent 行程_，`Agent` 提供了 `start/2` 函式。呼叫 `start` 啟動 _agent 行程_ 時所傳入的函式，會回傳該行程的初始狀態：

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

就像 `Map` 或 `List` 一樣，`Agent` 也提供了許多處理 _agent 行程_ 的函式。

依照慣例，我們會把與 `Agent` 相關的所有功能整理並封裝到一個模組裡，用來表示所建模的領域。

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
