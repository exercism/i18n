# 簡介

## Try/Rescue/Else/After

在錯誤發生時，`try..rescue` 是捕捉錯誤的強大結構。捕捉錯誤讓函式能在必要時回傳明確的值。`try..rescue` 結構還提供了兩個我們可以運用的額外功能：

- `else` 區塊
  - 當 try 區塊成功時，結果會與這個區塊進行比對。
- `after` 區塊
  - 不論 try 區塊成功或引發例外，只要程式在當下仍在執行，`after` 區塊中的程式碼就一定會被執行。
  - `after` 區塊的結果不會回傳到呼叫端的作用域。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## 動態分派

Elixir 在決定要呼叫哪個函式時，會使用模組的名稱來進行查找。如果模組的名稱被綁定到變數上，查找就可以動態進行。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

在內部，模組的名稱就是一個原子。所有 Elixir 的模組原子都會自動加上 `Elixir.` 前綴。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
