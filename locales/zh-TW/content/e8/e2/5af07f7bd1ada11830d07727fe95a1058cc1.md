# 指令

在這個練習中，你需要實作一些函式，來操作程式語言的陣列。

## 1. 定義一個回傳空語言陣列的函式

定義`new/0`函式，它不接受任何引數，並回傳一個空陣列。

```elixir
LanguageList.new()
# => []
```

## 2. 定義一個將語言加入陣列的函式

定義`add/2`函式，它接受 2 個引數（一個_語言陣列_，以及一個代表_語言_的字串常值）。它應該回傳把新語言加在給定陣列最前面所得到的陣列。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. 定義一個從陣列移除語言的函式

定義`remove/1`函式，它接受 1 個引數（一個_語言陣列_）。它應該回傳移除第一個項目後的陣列。假設陣列永遠至少會有一個項目。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. 定義一個回傳陣列中第一個項目的函式

定義`first/1`函式，它接受 1 個引數（一個_語言陣列_）。它應該回傳陣列中的第一個語言。假設陣列永遠至少會有一個項目。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. 定義一個回傳陣列中語言數量的函式

定義`count/1`函式，它接受 1 個引數（一個_語言陣列_）。它應該回傳陣列中的語言數量。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. 定義一個判斷陣列是否包含函式語言的函式

定義`functional_list?/1`函式，它接受 1 個引數（一個_語言陣列_）。它應該回傳一個布林值。如果_"Elixir"_是陣列中的其中一個語言，它應該回傳 true。

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
