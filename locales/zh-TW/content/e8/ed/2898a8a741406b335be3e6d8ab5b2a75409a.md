# 簡介

Factor 的條件式會在**quotations**之間做選擇，也就是以方括號`[ ... ]`寫成的程式碼片段。寫下`[ ... ]`會把程式碼當成值推入堆疊，而不是執行它；接著條件式會決定要執行哪一個 quotation。（我們會在之後的練習中完整介紹 quotations。）

`if`（在[`kernel`][kernel]中）是 Factor 的基本條件式。它接受一個布林值和兩個 quotation，若布林值為真就執行第一個，否則執行第二個。

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when`只在布林值為真時執行它的 quotation，`unless`則只在布林值為假時執行。若需要多重分支，可以使用`cond`（在[`combinators`][combinators]中）：

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
