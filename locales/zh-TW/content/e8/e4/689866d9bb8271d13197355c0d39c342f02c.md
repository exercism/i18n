# 簡介

有時需要讓某個狀態在多個詞之間共用，而不必每次都在它們的堆疊效應中層層傳遞。Factor 的*動態變數*（以`SYMBOL:`宣告）讓每個詞都能存取儲存在命名空間中的值。

## `SYMBOL:`與`SYMBOLS:`

`SYMBOL: name`會宣告一個變數，`SYMBOLS: a b c ;`則一次宣告多個：

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## 設定與取得

`set-global`和`get-global`（在[`namespaces`][namespaces]中）會操作全域命名空間：

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

若要處理模組層級的狀態，帶`-global`字尾的版本正是你要的。

## 用`with-variable`建立作用域綁定

動態變數還支援第二種*具作用域*的版本。`set`、`get`、`change`（不帶`-global`字尾）會讀寫*目前*的動態作用域，而`with-variable`（在[`namespaces`][namespaces]中）會在一段程式區塊執行期間建立全新的作用域：

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

在`quot`執行期間，變數會綁定到`value`；一旦`quot`回傳，這個綁定就消失。這讓外層的呼叫者能「注入」一個值，供內層程式碼讀取，而不必在每個堆疊簽章中層層傳遞。

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

這個練習從頭到尾都使用全域版本，不過當你閱讀別人寫的程式碼時，能認出`set`、`get`、`change`這組對應的家族會很有幫助喔。

## 可變向量

由於動態變數持有的是參考，你可以把一個*可變的*集合放在裡面，並就地更新：

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }`是向量常值。儲存`V{ }`常值之前，一定要先`clone`，因為常值會在呼叫之間共用。

## `find`：第一個相符的元素

`find`（在[`sequences`][sequences]中）會回傳第一個讓述詞為真的元素，以及它的索引：

```
find ( seq quot -- index elt/f )
```

如果沒有任何項目符合，兩個值都會是`f`。用`nip`丟掉索引，再搭配`unless*`，就是標準的「缺少時採用預設值」組合。

## `reject`：捨棄相符的項目

`reject`（同樣在[`sequences`][sequences]中）和`filter`相反：它會回傳*未通過*述詞的元素。
