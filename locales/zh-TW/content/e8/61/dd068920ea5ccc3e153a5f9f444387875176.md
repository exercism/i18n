# 關於

[`while`迴圈][while-loops]是一種控制流程敘述，用來讓程式碼在某個條件為真時持續執行。
Swift 提供兩種迴圈：`while`迴圈和`repeat-while`迴圈。
`while`迴圈的條件會在迴圈主體執行之前先求值；如果條件為假，迴圈主體就完全不會執行。
Swift 的`while`迴圈結構如下：

```swift
while <#condition#> {
  <#code#>
}
```

這裡只要`count`大於 0，迴圈就會一直執行，因此會依序印出 2、1 和 "Liftoff!"。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`迴圈][while-loops]與`while`迴圈類似，但它的條件是在迴圈主體執行之後才求值。
這表示迴圈主體至少一定會執行一次，即使條件為假也一樣。
Swift 的`repeat-while`迴圈結構如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

這裡的迴圈只會執行一次，因為條件為假。
由於這是`repeat-while`迴圈，迴圈主體會先執行一次，之後才會對條件求值。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 可選綁定迴圈

Swift 中`while`迴圈的一種常見變體是可選綁定`while`迴圈。
只要某個會產生可選值的函式回傳的不是`nil`，這類迴圈就會一直重複。
接著那個（非可選的）值會綁定到你自己選擇的名稱上，並可在迴圈主體中使用。

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
