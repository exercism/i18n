# 簡介

## 條件判斷 If

### 邏輯運算子

Java 支援三種邏輯運算子：`&&`（AND）、`||`（OR）和 `!`（NOT）。

### `if` 敘述

任何條件運算的底層型別都是 `boolean` 型別，它的值可以是 `true` 或 `false`。條件判斷常用來控制流程，檢查各種不同的條件。如果要檢查特定的情況，可以使用 `if` 敘述；當條件為 `true` 時，它就會執行當中的程式碼，像這樣：

```java
int val;

if(val == 9) {
    // conditional code
}
```

當情況不只一種時，可以用 `else if` 和 `else` 敘述把多個 `if` 敘述串連起來。

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### `switch` 敘述

Java 也提供了 `switch` 敘述，用來處理有多個選項的情況。

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
