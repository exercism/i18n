# 學習

Bash 是功能非常強大的 Unix shell 與命令指令稿語言，但學習曲線確實相當陡峭。

* Bash 的 [man page](https://manpage.me/index.cgi?apropos=0&q=bash&sektion=1&manpath=Debian+7.8.0&arch=default&format=html)
  是一份寫得很好、資訊豐富的文件。不過它非常「密集」，
  需要一讀再讀。

* 更多指南、資訊與範例可以參考：
    * [Greg's Wiki](http://mywiki.wooledge.org/BashGuide)，
    * [Bash Hackers Wiki](https://web.archive.org/web/20230323071638/https://wiki.bash-hackers.org/)，
    * Stack Overflow 上的 [bash 標籤資訊頁](https://stackoverflow.com/tags/bash/info)，
    * 以及比 man page 更深入的 [GNU Bash Manual](http://gnu.org/s/bash/manual)，
      它是 bash 資訊的_權威_來源。

* [shellcheck.net](https://www.shellcheck.net/) 提供網頁介面
  （某些發行版也有執行檔），可以檢查 shell 指令稿中的錯誤或
  常見問題，並提供如何正確修正的說明。
