# 關於

在 Rust 中，布林值由`bool`型別表示，它的值可以是`true`，也可以是`false`。

Rust 支援一種[布林否定運算子][negation operators]：`!`（否定）。

Rust 支援六種[比較運算子][comparison operators]：`==`（等於）、`!=`（不等於）、`>`（大於）、`<`（小於）、`>=`（大於或等於）、`<=`（小於或等於）。它們可以用來判斷非布林值之間的關係，並得出一個布林值。

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

和某些其他語言不同，`0`不是`false`，非零的值也不是`true`。

Rust 支援三種[邏輯二元運算子][logical binary operators]：`&`（邏輯且）、`|`（邏輯或）、`^`（邏輯互斥或）。

Rust 支援兩種[布林運算子][lazy boolean operators]：`||`（或）、`&&`（且）。它們和`|`、`&`不同的地方在於：只有當左側運算元還無法決定整個運算式的結果時，右側運算元才會被求值。也就是說，`||`只在左側運算元求值為`false`時才會計算右側運算元，而`&&`則只在左側運算元求值為`true`時才會。

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
