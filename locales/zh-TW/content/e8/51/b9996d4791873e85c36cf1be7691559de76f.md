# 餘數

在數學中，**餘數**是做完某個計算後「剩下」的數量。例如 `5 / 3` 的餘數是 `2`。

許多程式語言會用百分比符號（`%`）當作運算子來計算餘數。例如：
```javascript
5 % 3 == 2
```

餘數通常可以對整數和浮點數計算。例如：
```javascript
5.3 % 3 == 2.3
```

處理負數時，結果的正負號一律和被除數相同（也就是左邊那個被除的數）。例如：
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

有些語言（例如 Python）用 `%` 運算子計算的是模數，而不是餘數。
它們對負數的處理方式不同。
想了解更多，可以參考[在維基百科上](https://en.wikipedia.org/wiki/Modulo)的說明。
