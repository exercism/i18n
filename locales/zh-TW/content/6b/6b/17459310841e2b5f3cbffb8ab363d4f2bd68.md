# 說明

在 _Instruments of Texas_，RPN 計算機的開發進展順利。你的團隊現在希望能將方程式的字串版本寫入 _IO_ 資源。

## 1. 開啟檔案

你的團隊尚未決定要將方程式寫入哪種類型的裝置，所以你建議採用 _動態分派_ 的方式，將資源注入函式，而不是把它寫死在裡面。實作`write/3`函式，使用資源與檔名開啟 _IO 裝置_。

你可以假設`resource`永遠是一個原子，代表一個具有`open/1`函式的模組，且該函式會回傳`{:ok, io_device}`。

當函式成功時，回傳包含方程式的 ok 元組。

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. 嘗試寫入 IO 裝置

現在你已經開啟了 IO 裝置，請嘗試使用`IO.write/2`寫入。

擴充`write/3`函式來執行這個動作。寫入動作的嘗試可能會引發錯誤，請攔截錯誤並回傳錯誤元組：

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. 關閉 IO 裝置

永遠嘗試釋放你已開啟的資源是個好習慣，即使使用該資源的函式引發錯誤也一樣。擴充`write/3`函式，呼叫資源的關閉函式來關閉 _IO 裝置_。

你可以假設`resource`永遠是一個原子，代表一個具有`close/1`函式的模組，且該函式接受一個 _IO 裝置_。
