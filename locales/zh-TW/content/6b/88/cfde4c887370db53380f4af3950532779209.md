# 簡介

Unison 以`Boolean`型別表示 true 和 false 這兩種值。總共只有兩個值：`true`和`false`。

```unison
trueVariable = true
falseVariable = false
```

我們可以使用 and、or 和 not 運算子來計算布林運算式，它們分別以`&&`、`||`和`not`表示。

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
