# 指示

在這個練習中，你將寫一些程式碼來協助 Betty's Bike Shop，這是一間販售自行車與零件的線上商店。你有三個任務，目標是在網站上正確顯示自行車與零件的價格。

## 1. 匯出`penceToPounds`函式

你的同事已經寫好了這個模組的骨架，也就是尚未定義的`penceToPounds`和`poundsToString`兩個函式。
不過，他們忘了匯出`penceToPounds`函式，所以它目前無法被其他模組或測試套件看見。

請把`penceToPounds`加入已匯出函式的清單中。

## 2. 把便士轉換成英鎊

目前，價格是以整數的便士儲存的（這間自行車店位於英國）。
在網站上，我們想以英鎊顯示價格，其中 1.00 英鎊等於 100 便士。
你的第二個任務是實作`penceToPounds`函式，它接受`Int`型別的便士數量，並把它轉換成等值的英鎊，型別為`Float`。
你也應該為這個函式定義型別註解。

```elm
penceToPounds 106
    --> 1.06
```

## 3. 將價格格式化，以便在網站上顯示

由於 Betty's Bike Shop 的自行車是以英鎊販售，價格應該以符號「£」顯示。
因此你的第三個任務是實作`poundsToString`函式，它接受`Float`型別的英鎊金額，並回傳加上英鎊符號後所顯示的價格，型別為`String`。
`String`模組裡的`String.fromFloat`函式會對你很有幫助。
使用之前，你應該先匯入`String`模組。
你也應該為`poundsToString`定義型別註解。

```elm
poundsToString 1.06
    --> "£1.06"
```
