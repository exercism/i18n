# 說明

在這道練習中，你會實作一部分的輔助函式，用來協助開發者清理 SqueakyClean 名稱。

在這 4 個任務中，你會逐步建構出`clean`方法。
有效的 SqueakyClean 名稱由零個或多個字母和底線組成。

無論哪種情況，輸入字串都保證不是 null。請注意，`clean`方法應該將空字串視為有效。

## 1. 將遇到的所有空格取代為底線

實作（_static_）`SqueakyClean.clean()`方法，將任何空格取代為底線。這也適用於開頭與結尾的空格。

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. 將 kebab-case 轉換成 camelCase

修改（_static_）`SqueakyClean.clean()`方法，將 kebab-case 轉換成 camelCase。

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. 將 leetspeak 轉換成一般文字

修改（_static_）`SqueakyClean.clean()`方法，將 [leetspeak][leet-speak] 轉換成一般文字。

為了簡單起見，我們只會將`4`、`3`、`0`、`1`和`7`分別取代為`a`、`e`、`o`、`l`和`t`。

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. 省略任何不是字母的字元

修改（_static_）`SqueakyClean.clean()`方法，省略任何不是字母的字元。

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
