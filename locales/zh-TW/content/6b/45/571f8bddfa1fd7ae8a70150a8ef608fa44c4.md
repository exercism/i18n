# 介紹

儲存類別修飾詞關係到變數在記憶體中如何儲存。它們和值的儲存持續期間（也稱為生命週期）息息相關。

## auto：函式或區塊作用域變數的預設儲存類別

由於在區塊或函式中定義的變數預設就是`auto`，因此通常不會特別寫出這個詞。
`auto`變數的生命週期，從進入它的區塊時開始，到離開區塊時結束。
進入區塊時，系統會為`auto`變數配置記憶體，_但不會給它預設值_。

## static：別與靜態連結類型混淆的儲存修飾詞

如果變數定義在區塊或函式之外，並標記為`static`，這個`static`指的是它的連結，意思是它只能在該檔案內存取。
如果變數定義在函式內，或函式內的區塊中，並標記為`static`，它就具有`static`儲存持續期間。
`static`變數的值會在函式或區塊的多次呼叫之間保留下來。

## extern：如何存取另一個編譯單元中的變數

一個編譯單元由一個原始碼檔案，以及它`#include`的任何其他檔案所組成。
雖然具有檔案作用域的變數可以宣告並初始化為`extern`，但`extern`關鍵字通常是用來取用既有的變數，而不是定義新的變數。
`extern`所取用的變數必須具有檔案作用域。
位於檔案作用域的變數一律具有`static`儲存持續期間。
被 include 的檔案中的變數必須具有外部連結，include 它的檔案才能存取。

## register：如何可能加快變數的存取

標記為`register`的變數，表達了程式設計師希望把值放進暫存器以便快速存取的意願。
`register`變數和`auto`變數很像，都必須位於函式或區塊作用域中。
由於這個值打算放進暫存器而不是記憶體，編譯器應該不允許存取該變數的位址，因為暫存器的位址無法取得。
不過，記憶體位址本身可以放進暫存器。
`register`基本上只是一種提示，因為這個值實際上不一定會被放進暫存器。

## typedef：其實稱不上是儲存類別修飾詞

`typedef`之所以被描述為儲存類別修飾詞，純粹是出於語法上的理由。
這是因為儲存類別修飾詞不能和另一個儲存類別修飾詞一起使用。
所以，`typedef auto int i = 42;`和`static auto int i = 42;`一樣不合法。
