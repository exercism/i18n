# 指令

你的團隊正在開發一個氣象應用程式。
他們定義了一組 API，內含各種代表氣象資料的型別與常數，請見`meteorology.go`檔案。

你的任務是為所有型別加上合適的 `String` 方法，讓它們實作 `Stringer` 介面。

## 1. 為 `TemperatureUnit` 型別實作 `Stringer` 介面

經過一番討論，團隊決定溫度的單位採用 `Celsius` 或 `Fahrenheit`。
值應如下方範例所示格式化。

請為 `TemperatureUnit` 型別加上 `String` 方法，讓它實作 `Stringer` 介面。
若溫度單位是 Celsius，這個方法必須回傳字串 `"°C"`；若是 Fahrenheit，則必須回傳 `"°F"`。

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. 為 `Temperature` 型別實作 `Stringer` 介面

溫度值由一個整數和一個溫度單位組成。
它們應如下方範例所示格式化。

為了做到這點，請為 `Temperature` 型別加上 `String` 方法，讓它實作 `Stringer` 介面。
這個方法應回傳一個字串，內容是溫度的數值和溫度單位，兩者以空格分隔：`<temperature> <unit>`：

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. 為 `SpeedUnit` 型別實作 `Stringer` 介面

經過冗長的討論，團隊決定風速的單位採用 `KmPerHour` 或 `MilesPerHour`。
值應如下方範例所示格式化。

為了做到這點，請為 `SpeedUnit` 型別加上 `String` 方法，讓它實作 `Stringer` 介面。
若速度單位是每小時公里，這個方法必須回傳字串 `"km/h"`；若是每小時英里，則必須回傳 `"mph"`：

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. 為 `Speed` 型別實作 `Stringer` 介面

風速值由一個整數和一個速度單位組成。
它們應如下方範例所示格式化。

為了做到這點，請為 `Speed` 型別加上 `String` 方法，讓它實作 `Stringer` 介面。
這個方法應回傳一個字串，內容是速度的數值和速度單位，兩者以空格分隔：`<speed> <unit>`：

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. 為 `MeteorologyData` 型別實作 `Stringer` 介面

氣象資料包含地點、溫度、風向、風速和濕度。
它們應如下方範例所示格式化：

為了做到這點，請為 `MeteorologyData` 型別加上 `String` 方法，讓它實作 `Stringer` 介面。
這個方法應以下列格式回傳氣象資料：

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
