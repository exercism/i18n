# 關於

在 Gleam 中，`Iterator`和陣列類似，都是一種有序的值集合，且所有值都屬於相同型別。它和陣列不同的地方在於它是惰性的，意思是它不會一次將所有值儲存在記憶體中，而是需要時才計算出來。

這在處理非常龐大、甚至無限大的序列時很有用，因為當我們沒有足夠的可用記憶體一次儲存全部內容時，仍然可以處理它們。

`gleam/iterator`模組定義了`Iterator`型別，以及用來操作疊代器的函式。

許多適用於陣列的函式也同樣適用於疊代器，例如`map`、`filter`和`take`。這些函式會回傳疊代器，所以除非疊代器被消耗，否則這些函式不會實際執行任何工作。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold`函式可以用來從一個會被重複呼叫的函式建立疊代器，以產生序列中的下一個值。

這裡使用`unfold`函式建立一個會產生費氏數列的疊代器：

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

這裡的序列是無限的，所以在將值收集成陣列之前，會先使用`take`函式讓它變成有限的。如果對無限疊代器呼叫`to_list`，程式會一直執行，直到記憶體耗盡並當機。
