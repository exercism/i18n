# 測試

如果你用 CLI 工具下載了練習，應該會看到一個以該練習命名的 Futhark 檔案，以及一個`test.fut`檔案。
這個檔案包含所有測試案例，這些案例與你上傳解法時測試執行器所執行的一致。
歡迎自行新增額外的測試案例來做實驗。
不過，修改測試並不會影響線上測試執行器的流程。

## 本機測試

如要執行某個練習的測試，請在該練習的目錄中開啟終端機，然後執行`futhark test test.fut`（或`exercism test`）指令。

## 延伸資源

如果想進一步了解如何用 Futhark 測試，請參閱[`futhark test`][test-command]的文件。
