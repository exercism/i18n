# 說明補充

## 提示

你需要實作 `decode` 和 `encode` 這兩個函式，它們會用仿射密碼來解碼與編碼 `String`。
如果你不確定型別，可以使用提供的簽名，但別讓它限制你的創意。

這個練習處理的是文字資料。
基於歷史因素，Haskell 的 `String` 型別等同於 `[Char]`，也就是字元的陣列。
若要更有效率地處理文字資料，可以使用 `Text` 型別。

作為這個練習的選用延伸，你可以

- 在 package.yaml 的相依套件清單中加入 `- text`。
- 用[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)匯入 `Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 使用 `Text` 型別，例如 `decode :: Text -> Text`，並以例如 `T.pack` 的方式來取用 `Data.Text` 的組合子。
- 查閱[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的說明文件。
- 把 Affine.hs 中所有 `String` 都換成 `Text`，也就是：

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

這部分完全是選用的喔。
