# 關於

F# 中的布林值由`bool`型別表示，其值可以是`true`或`false`。

F# 支援三種[布林運算子][operators]：`not`（否定）、`&&`（且）和`||`（或）。`&&`和`||`運算子採用_短路求值_，這表示運算子右側只會在需要時才求值。

```fsharp
true || false // => true
true && false // => false
```

這三個布林運算子各有不同的[_運算子優先順序_][precedence]。因此，它們的求值順序如下：`not`最先，`&&`第二，最後是`||`。如果你想「跳脫」這些規則，可以用括號（`()`）把布林運算式包起來，因為括號的運算子優先順序更高。

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
