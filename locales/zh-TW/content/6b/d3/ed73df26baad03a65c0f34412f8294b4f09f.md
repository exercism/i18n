# 說明

在這個練習中，你會寫一些程式碼，幫助自由工作者與專案經理溝通：提供幾個小工具，讓他們能快速算出每日費率和每月費率，並可選擇套用指定的折扣。

我們先為自由工作者和專案經理之間訂下幾個規則：

- 每日費率是每小時費率的 8 倍。
- 一個月有 22 個可計費工作天。

有時候，自由工作者會願意在每日費率上給折扣，例如給最忠實的客戶，或是給非營利組織的客戶。

折扣會以代表百分比的小數來表示，例如`25.0`就代表 25%。

## 1. 根據每小時費率計算每日費率

實作一個函式，根據每小時費率計算每日費率：

```haskell
dailyRate 60
-- -> 480.0
```

回傳的每日費率應該是雙精度浮點數。

## 2. 計算折扣後的價格

實作一個函式，計算套用折扣後的價格。

```haskell
applyDiscount 150 10
-- -> 135.0
```

回傳值一律要是雙精度浮點數，不能做任何四捨五入。

## 3. 根據每小時費率和折扣計算每月費率

實作一個函式，計算每月費率並套用折扣：

```haskell
monthlyRate 77 10.5
-- -> 12130
```

回傳的每月費率應該向上取整（取天花板值）到最接近的整數。

## 4. 根據預算、每小時費率和折扣計算工作天數

實作一個函式，接收預算、每小時費率和折扣，算出這些預算能支應多少天的工作。

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

回傳的工作天數應該向下取整（取地板值）到小數點後一位。
