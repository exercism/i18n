# 關於

Tcl 讀作「tickle」，是 Tool Command Language 的縮寫，它是一門動態的開放原始碼程式語言。

它的設計目標是既簡單又強大。它的語法簡單到只用 [12 條規則][rules] 就能完整描述，但它仍然是一門功能完整的程式語言。

Tcl 把一切都視為*指令*，連變數賦值、程序定義與流程控制也不例外。因此，它既像 shell 指令碼，也像 Lisp。

Tcl 支援多種程式設計典範，包括物件導向、命令式與函式風格。Tcl 最常見的用途，是在 C 應用程式中嵌入指令碼執行環境，以及用 Tk GUI 工具組製作 GUI 原型。
