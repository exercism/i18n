# 關於

## 模組

Gleam 程式碼是以模組為單位來組織的，每個檔案就是一個 Gleam 模組。

到目前為止，我們都是用`pub fn`語法來寫函式，這種語法定義的函式會公開給其他模組使用。用`fn`定義的函式則是私有的，只限於定義它的模組內部使用，其他模組無法取用。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 模組都有名稱，名稱取決於它位於`src`或`test`目錄下的檔案路徑。

舉例來說，定義在`src\geometry\rectangle.gleam`（Windows 上）或`src/geometry/rectangle.gleam`（類 Unix 作業系統上）的模組，名稱會是`geometry/rectangle`。

## 從其他模組匯入函式

要取用定義在其他模組裡的函式，必須透過匯入。匯入某個模組時，該模組對外公開的所有函式都會變得可以取用。不過取用方式會依匯入模組的方式而有所不同。

限定匯入是預設做法，取用這類模組中的函式（例如`gleam/list`模組裡的`map`函式）時，是在模組名稱前面加上前綴（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

預設用來指稱模組的名稱，是模組名稱的最後一段，在這裡就是`int`，不過可以用`as`關鍵字來改變。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非限定匯入則可以直接取用該模組公開的函式，不需要加上前綴。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

會偏好使用限定匯入，因為它能讓讀者更清楚函式是從哪裡來的，也能避免名稱衝突。
