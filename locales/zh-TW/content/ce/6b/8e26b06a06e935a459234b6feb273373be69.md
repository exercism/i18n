# 關於

在 Ruby 中處理數字時，一個關鍵面向就是區分整數（小數點後沒有數字的數字）與浮點數（小數點後有零個或多個數字的數字）。
它們分別透過 [`Integer`][integer-ruby] 與 [`Float`][float-ruby] 類別來實作。

```ruby
a = 1
b = 1.0
a.class
#=> Integer
b.class
#=> Float
```

- 算術運算使用基本的[算術運算子][arithmetic-operators]（`+`、`-`、`*`、`/`）來完成。
  數字則可使用標準的[比較運算子][comparison-operators]來比較。
- 兩個 `Integer` 實例之間的基本算術運算，結果一律會是 `Integer` 實例。
- 兩個 `Float` 實例之間的基本算術運算，結果會是 `Float` 實例。
- `Integer` 實例與 `Float` 實例之間的基本算術運算，結果會是 `Float` 實例。
- `Float` 與 `Integer` 類別都有方法可以把值從一種轉換成另一種。
  整數精確到完整的單位，而浮點數的精確度則可細到整數的分數部分。
  這表示把浮點數轉換成整數時，可能會遺失精確度。

```ruby
4.9.to_i
#=> 4

5.to_f
#=> 5.0

7 - 3.0
#=> 4.0

2 == 4
#=> false

1.0 == 1
#=> true
```

可以使用 `if` 敘述來依條件執行程式碼：

```ruby
x = 5

if x == 5
  # Execute logic if x equals 5
elsif x > 7
  # Execute logic if x greater than 7
else
  # Execute logic in all other cases
end
```

有時候你想在某個條件不是 true 時執行一段（或多段）敘述，針對這種情況，Ruby 提供了 `unless` 關鍵字：

```ruby
x = 4
unless x == 5
  # Execute logic if x does not equal 5
else
  # Execute logic if x == 5
end
```

如果你想根據變數的值執行不同的程式碼，Ruby 的 `case` 敘述可能就能派上用場：

```ruby
y = 5
case y
when 3
  # Execute logic if y equals 3
when 5
  # Execute logic if y equals 5
else
  # Execute logic in all other cases
end
```

同樣的問題有時可以用不同種類的條件敘述來解決，有時其中一種可能比另一種更適合這個問題。
使用這三種條件敘述的任何一種時，不妨先停下來想一想，也考慮一下另外兩種選項。
