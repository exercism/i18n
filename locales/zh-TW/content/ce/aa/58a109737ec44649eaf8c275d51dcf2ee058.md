# 關於高階函式

在 Kotlin 中，函式是一等公民。
這代表它們可以儲存在變數中、作為引數傳遞，甚至由其他函式回傳。
舉例來說，把函式指定給變數`addOne`：

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

函式也可以回傳另一個函式：

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

指定之後，就能透過這個變數呼叫該函式，就像呼叫其他函式一樣：
```kotlin
addOne(3)
// => 4
```

## 宣告函式型別

變數或參數的型別可以用`(parameter types) -> return type`這種語法宣告。
例如，宣告一個變數：

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

而函式參數則可以這樣宣告：

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Lambda 運算式

Lambda 運算式是定義函式的簡短寫法。
它們的寫法是`{ parameters -> body }`。
這種運算式會回傳主體中最後一個敘述的最後一個值。
例如：

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

當資訊足夠時，Kotlin 可以推斷型別。
例如，上面的範例也可以寫成：

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## 單一參數 Lambda 中的`it`

當運算式只有一個參數時，可以省略這個參數。
Kotlin 會在主體中提供一個名為`it`的參數。
例如：

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## 傳遞尾隨 Lambda

當函式的最後一個引數是 Lambda 時，Lambda 運算式會直接寫在括號_之後_。
例如：

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
