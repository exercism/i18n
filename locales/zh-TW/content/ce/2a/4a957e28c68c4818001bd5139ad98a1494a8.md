# 布林

`bool` 型別（英文：_boolean_ 的縮寫）只有兩個值：`true` 和 `false`。在程式碼中，`true` 和 `false` 這兩個字面值不分大小寫。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

布林值經常在邏輯運算式中作為運算子的結果，接著用於控制結構。

## 邏輯運算子

以下是幾個邏輯運算子：

- `!$a`：如果 `$a` 不是 `true`，就回傳 `true`
- `$a && $b`：如果 `$a` 和 `$b` 都是 `true`，就回傳 `true`
- `$a || $b`：如果 `$a` 或 `$b` 其中一個是 `true`，就回傳 `true`

~~~~exercism/caution
還有 `and` 和 `or` 這兩個運算子，它們分別與 `&&` 和 `||` 互補。
它們的行為和 `&&`、`||` 並不相同，可能會產生非預期的結果，因此不建議使用。
~~~~
