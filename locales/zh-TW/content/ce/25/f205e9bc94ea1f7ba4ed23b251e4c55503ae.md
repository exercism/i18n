# 指示

寫一個函式，把一般數字轉換成羅馬數字。

羅馬人很聰明。他們征服了歐洲大部分地區，統治了數百年。他們發明了混凝土、筆直的道路，甚至還有比基尼。不過，有一件事他們始終沒發現，那就是數字零。這讓他們在記錄與標註自己豐功偉業的漫長歷史時，稍微棘手了些，但他們想出的數字系統至今仍在使用。舉例來說，BBC 就用羅馬數字來標註節目年份。

羅馬人用字母來書寫數字，也就是 I、V、X、L、C、D、M。（注意這些字母有很多直線，因此很容易刻進石板。）

```text
 1  => I
10  => X
 7  => VII
```

你不需要能夠轉換大約 3000 以上的數字。（羅馬人自己通常也不會用到更大的數字。）

維基百科寫道：現代羅馬數字……的寫法是把每個位數分開表示，從最左邊的位數開始，並略過任何值為零的位數。

想實際看看這個規則，可以拿 1990 當例子。

在羅馬數字中，1990 是 MCMXC：

1000=M
900=CM
90=XC

2008 寫成 MMVIII：

2000=MM
8=VIII
