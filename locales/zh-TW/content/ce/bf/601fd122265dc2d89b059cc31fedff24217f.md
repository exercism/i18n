# 簡介

Haxe 裡的`String`是一個物件，用來表示不可變的文字，也就是一連串的 Unicode 字元（字母、數字、標點符號等）。定義`String`實例時要使用雙引號：

```haxe
var fruit:String = "Apple";
```

操作字串的方式，就是呼叫這個字串的方法。字串一旦建立完成，它的值就永遠不會改變。任何看起來像是在修改字串的方法，實際上都會回傳一個新的字串。

多個字串可以串接（相加）在一起，最簡單的做法就是使用`+`運算子。

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

如果需要比單純串接更複雜的字串格式化，建議改用字串插值。想在字串裡使用插值，請用單引號（`'`）把字串包起來，接著就能用錢字號（`$`）來觸發插值：

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
