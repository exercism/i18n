# Exercism API

## 說明

大多數 Exercism 語言軌道都使用`exercism`命令列工具來取得和提交練習，這個工具會透過 REST API 與`exercism.io`互動。Pharo Smalltalk 語言軌道則改用同一套 REST API，直接把練習帶進、帶出 Pharo 映像檔，不需要任何中介工具。本文件詳細說明 Exercism API，並聚焦在 Pharo Smalltalk 語言軌道如何使用它，主要讀者是 Pharo Smalltalk 工具鏈的維護者。

## 標頭

所有端點都要求請求中的標頭必須設為下列值：

```
Authorization: Bearer <token>
```

`<token>`的值是使用者的 CLI 驗證權杖，可在`https://exercism.io/my/settings`取得。

## 取得練習

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

在上面的 URL 中，`<slug>`是練習的名稱，例如`hello-world`；`<language>`則是語言軌道，例如`pharo-smalltalk`。

### 回應

#### 200

請求成功時，回應會包含一份 JSON 內容。JSON 裡會有該練習的資訊，以及可下載練習檔案的下載網址。

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

語言軌道名稱不明確，或是提交的練習檔案沒有變更。

#### 403

解答尚未為該使用者解鎖，或者使用者尚未加入該語言軌道。

#### 404

找不到該語言軌道或練習。

## 提交練習

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### 回應

#### 201

提交成功。

#### 400

提交的檔案太大（超過 1 MB），或是解答重複。

#### 403

該使用者無法存取這份解答。解答的使用者 ID 與目前使用者的 ID 不符。

#### 404

找不到該解答 ID。
