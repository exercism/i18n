練習順序與主題的真正依據是 [config.json](config.json)，但這個檔案記錄了我們在該檔案中排定練習順序的理由。

## 我們的做法

我們是為正在學 Rust 的學生安排練習順序的。考量到這群讀者，我們在新增練習時遵循兩項規則。

- 一個練習應該只引入一個新概念
- 練習應該從 Rust 基礎循序漸進到進階的 Rust 概念

### 一次一個新概念

如果某個練習的解法需要學生同時用到`Result`和`HashMap`，那麼這兩個概念至少要有一個由更早的練習先引入。

如果 track 裡有幾個練習都依賴同一個概念，就把它們排在一起，以加深學習效果。

### 循序學習 Rust

#### 前期練習

前期練習應該著重於 Rust 的語法，以及許多程式語言都有的概念：條件判斷、迴圈、高階函式。

#### 中期練習

排在 track 中段的練習應該引入較不常見的概念，例如`Result`、`Option`和 Trait，或是`while let`這樣的語法。

走過 track 的中段之後，學生應該已經熟悉各種廣泛的 Rust 概念。

#### 後期練習

排在 track 後段的練習應該做到以下兩件事之一：

1. 引入進階概念：生命週期、並行、不安全性
2. 要求一個複雜的解法，整合學生至今學到的所有知識
