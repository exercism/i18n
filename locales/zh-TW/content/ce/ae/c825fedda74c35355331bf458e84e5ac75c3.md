# 簡介

短小的詞用堆疊來回操作還行。但當一個詞有好幾個輸入，而你需要以名稱取用它們時，Factor 提供了 *locals*，也就是具名綁定：可用 `::`（用於詞定義）或 `[| | ]`（用於行內 lambda）引入，兩者都來自 [`locals`][locals]。

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

在 quotation 內，`[| inputs | body ]` 是帶有具名輸入的 lambda：

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
