# 使用守衛

[comment]: # (當解法完全沒有使用守衛時，就會觸發這個錯誤)

使用[守衛](https://hexdocs.pm/elixir/master/guards.html)來防止`two_fer/1`在收到非二進位輸入時執行程式碼。

> 記住，在 Elixir 中，[字串](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)被視為[二進位資料](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)。

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> 這個守衛可以在`iex`中測試看看

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
