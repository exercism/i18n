# 提示

## 1. 調製一杯果汁

- `cond`（在 [`combinators`][combinators] 中）是根據一連串相等性測試來挑選值最簡潔的方式。

## 2. 補充萊姆角的存量

- 帶有兩份狀態（還需要多少萊姆角，以及手邊還剩多少萊姆）的 `while` 迴圈，是最自然的做法。用 `::` 和 `:> name!` 宣告這些狀態，能讓主體保持易讀。
- `unclip ( seq -- rest first )` 會取下第一顆萊姆，準備餵給 `wedges-from-lime`。

## 3. 列出佇列中每筆訂單的調製時間

- [`sequences`][sequences] 中的一個詞就能搞定全部工作。

## 4. 完成值班

- 結構和第 2 項任務相同：由兩份狀態（值班剩餘的分鐘數，以及還在等待的訂單）驅動的 `while` 迴圈。任一個用盡時就停止。
