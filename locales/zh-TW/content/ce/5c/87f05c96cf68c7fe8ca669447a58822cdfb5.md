# 簡介

Factor 的錯誤系統由三個部分組成：`throw`（位於 [`kernel`][kernel]）會拋出錯誤，`recover`（位於 [`continuations`][continuations]）會捕捉錯誤，而 `ERROR:` 則定義一個元組型別的錯誤類別。

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` 會執行 *try* quotation；如果它拋出錯誤，錯誤就會被推入堆疊，接著執行 *recovery* quotation。

`ERROR:` 會同時宣告類別，以及一個會拋出全新實例的建構子詞：

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
