# 測試

我們使用 stdlib 的 [PonyTest](https://stdlib.ponylang.io/pony_test--index/) 來撰寫測試，以檢驗你的解法。要檢驗你的解法，請編譯並執行你的程式碼。

舉例來說，你在「Hello World」的工作階段可能會像這樣：

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
