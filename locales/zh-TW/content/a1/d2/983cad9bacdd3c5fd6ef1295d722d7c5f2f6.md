# 簡介

## 定義變數

定義變數的意思是將值指定給一個名稱。在 Scala 中有兩種變數：val 和 var。

`val`是不可變的，所以它的值在第一次指定之後就無法再改變：

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

相對地，`var`可以重新指定為相同型別的新值：

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala 是靜態型別的語言，這表示所有東西在編譯期都有型別。變數可以透過明確指定型別來定義，也可以讓 Scala 編譯器根據指定的值推論它的型別（稱為型別推論）。因此，以下兩個變數定義是等價的：

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

一旦定義之後，變數的型別就永遠不會改變。

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## 在類別中定義方法

Scala 是_物件導向語言_，要求所有方法都必須定義在_類別_裡。`class`關鍵字用來定義類別。

```scala
class Calculator {
  // ...
}
```

在類別裡，方法可以用關鍵字`def`開頭，後面接著名稱來定義。每個方法可以有零個或多個參數，以逗號分隔並列在括號內。所有參數都必須明確標註型別，參數沒有型別推論。在參數列表之後，會以另一個冒號分隔來定義方法的回傳型別。

方法定義後面接著一個`=`符號，用來開始方法主體。在以下範例中，方法主體包含兩個敘述，並以花括號包住。

方法會回傳最後一個運算式的值，在這個例子裡，`add`方法回傳變數`sum`的值：

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

有幾個可以做的改進，能用來縮短那個方法以提升可讀性：

- 由於變數`sum`只被存取一次以回傳值，因此可以省略
- 只包含一個敘述的方法不需要花括號
- 方法的回傳型別可以像變數型別一樣被推論

這樣就得到以下功能相同的一行方法：

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## 實例化類別與呼叫方法

呼叫方法的方式是先建立類別的實例，接著在該實例上帶著引數呼叫方法：

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## 註解

Scala 支援兩種註解：單行註解與多行註解：

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
