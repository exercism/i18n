# 測試

## 執行測試

用以下指令執行測試規格：

```bash
$ gradle test
```

## 啟用更多測試

當你的程式碼通過所有已啟用的測試後，只要移除下一個你有興趣的測試前面的`@Ignore`，就能再啟用一個測試。你可以直接刪除`@Ignore`那一行，或在該行開頭加上兩個斜線，把它註解掉。

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
