# 測試

## 執行測試

完成[安裝步驟][test-installation-steps]後，你應該就能從任何練習目錄（例如 `~/exercism/gdscript/two-fer`）開始，執行上一層（`../`）的腳本，測試你在本機對該練習的解法：

```sh
../test-local-gdscript-solution.sh
```

## 解決練習

解決一個練習，代表讓它的所有測試都通過。

為了幫你起步，每個練習都會附上一個與它同名的 GDScript 檔案（例如 `exercism/gdscript/two-fer/two_fer.gd`）。
你可以把這個檔案當作建立解法的起點，視需要自由修改，不過測試要求函式名稱必須與原本提供的一致。

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
