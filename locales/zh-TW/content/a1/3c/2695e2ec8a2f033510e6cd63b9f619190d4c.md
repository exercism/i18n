# 補充說明

## 輸入範例

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

這表示你的輸入是：
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## 處理無效的輸入

如果有任何輸入值無效，你的動詞應該回傳一個`empty`（例如 `0$0` 或 `''`）。

### 範例

- 如果*輸入基數*小於 2：
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- 如果*輸出基數*小於 2：
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- 如果*位數*中包含大於或等於輸入基數的值：
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
