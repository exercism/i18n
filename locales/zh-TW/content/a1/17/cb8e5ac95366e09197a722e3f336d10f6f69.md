# 說明

你要幫助高中情侶用他們的姓名縮寫產生一個 unicode 愛心，好讓他們在社群媒體上表達愛意：

```
❤ J.  +  M. ❤
```

## 1. 清理姓名

定義`cleanupname`，從堆疊取出一個姓名。將每個`-`取代為空格，然後移除開頭與結尾的空白。

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. 取得姓名的第一個字母

定義`firstletter`，接受一個姓名。沿用上一個任務的`cleanupname`，然後取得結果的第一個字元，並以單一字元的字串回傳。

```factor
"Jane" firstletter .
! => "J"
```

## 3. 將第一個字母格式化為縮寫

定義`initial`，接受一個姓名。沿用上一個任務的`firstletter`，將它轉為大寫，然後在後面加上`.`。

```factor
"Robert" initial .
! => "R."
```

## 4. 將縮寫放進愛心裡

定義`couple`，從堆疊取出兩個姓名。對每個姓名沿用上一個任務的`initial`，然後組合出結果：

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
