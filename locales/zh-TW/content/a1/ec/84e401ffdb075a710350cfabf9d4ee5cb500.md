# 簡介

Gleam 標準函式庫在 `gleam/queue` 模組中實作了 `Queue` 型別。它和 `List` 型別類似，但有幾個關鍵差異：

- `Queue` 型別沒有字面語法可以用來建構佇列，或對它們做模式匹配。
- 元素可以有效率地從 `Queue` 型別的前後兩端加入和移除，而 `List` 型別只能有效率地從前端加入和移除元素。

大多數時候你會想用 `List` 型別，但當你需要從集合的尾端加入和移除元素時，`Queue` 型別是不錯的選擇。

可以使用 `queue.new` 和 `queue.from_list` 這兩個函式建立佇列：

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

可以使用 `queue.push_front` 和 `queue.push_back` 這兩個函式把元素加入佇列：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

可以使用 `queue.pop_front` 和 `queue.pop_back` 這兩個函式把元素從佇列移除：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

可以使用 `queue.to_list` 函式把佇列轉成列表：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## 佇列相等性

由於佇列的實作方式，含有相同元素且順序相同的兩個佇列，用 `==` 運算子比較時仍可能不相等，因為這個運算子是依結構比較值。例如：

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

如果你需要比較兩個佇列是否相等，可以使用 `queue.is_logically_equal` 函式。

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
