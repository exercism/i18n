# 關於

Swift 中的 `guard` 敘述用於從函式、迴圈或方法提前退出，也就是當必要條件沒有滿足時：

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

在上面的範例中，`guard` 會評估緊接在其後的布林運算式。
如果條件為`true`，執行就會繼續進行`guard`敘述之後的程式碼。
如果條件為`false`，就會執行`else`區塊裡的程式碼。

與`if`敘述不同：

- `guard` 敘述**必須**包含`else`子句。
- `else`子句**必須**轉移控制權以離開所在的作用域（例如使用`return`、`continue`、`break`，或拋出錯誤）。

`guard` 經常用來乾淨地驗證前置條件。
例如，來看看 sinc 函式（$\text{sinc}(x) = \frac{\sin(x)}{x}$，並將 $\text{sinc}(0)$ 定義為 1，以避免除以零的問題）：

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
