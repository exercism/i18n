# 關於

[D](https://dlang.org) 是一門系統程式語言，具有類似 C 的語法與靜態型別。它結合了效率、控制力與建模能力，同時兼顧安全性與程式設計師的生產力。這門語言最初由 [Walter Bright](https://en.wikipedia.org/wiki/Walter_Bright) 與 [Andrei Alexandrescu](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) 從 D 第 2 版開始開發。

D 是數十年來為各種不同語言實作編譯器所累積經驗的結晶，並擁有大量[獨特功能](http://dlang.org/overview.html)：

- 高階結構，帶來強大的建模能力
- 高效能的編譯式語言
- 靜態型別
- C++ 的演進（沒有那些錯誤）
- 直接與作業系統的 API 及硬體介面
- 極快的編譯速度
- 允許記憶體安全的程式設計（SafeD）
- 可維護、易於理解的程式碼。
- 學習曲線短（語法類似 C，也類似 Java 等）
- 與 C 應用程式二進位介面相容
- 多範式（命令式、結構化、物件導向、泛型、純函式程式設計，甚至組合語言）
- 內建錯誤預防機制（契約、單元測試）

[D Language Foundation](https://dlang.org/foundation.html) 是致力於開發與推廣 D 語言的組織。
