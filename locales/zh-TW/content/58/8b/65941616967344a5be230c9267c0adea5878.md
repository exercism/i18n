# 指令

Ozan 正在打造一張完美的混音帶：先決定*哪些*歌曲能入選，再敲定它們的*播放順序*。你將在`mixtape-maker`詞彙中，打造他這些選擇背後的組合數學工具喔。

## 1. 計算組合

定義`count-combinations`，回傳從`n`中選出`k`個項目的方法數，不計順序。

```factor
5 2 count-combinations .
! => 10
```

## 2. 計算排列

定義`count-permutations`，回傳從`n`中選出`k`個項目的方法數，且順序有別。

```factor
5 2 count-permutations .
! => 20
```

## 3. 列出組合

定義`list-combinations`，回傳一個序列中所有由`k`個元素組成的組合。

```factor
{ 1 2 3 } 2 list-combinations .
! => { { 1 2 } { 1 3 } { 2 3 } }
```

## 4. 列出排列

定義`list-permutations`，回傳一個序列的每一種排列順序。

```factor
{ 1 2 } list-permutations .
! => { { 1 2 } { 2 1 } }
```

## 5. 總和為目標值的組合

定義`combinations-summing-to`，只回傳序列中元素加總等於`target`的那些`k`組合。

```factor
{ 1 2 3 4 } 2 5 combinations-summing-to .
! => { { 1 4 } { 2 3 } }
```
