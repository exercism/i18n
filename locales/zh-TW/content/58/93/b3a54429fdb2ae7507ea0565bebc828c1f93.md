# 關於

[Guards][guards] 是 [模式比對][exercism-pattern-matching] 的補充。我們會在之後的概念中介紹模式比對。Guards 讓我們能根據輸入的值，為一個函式提供不同的實作。它們能進行更複雜的檢查。

guard 敘述的寫法是先寫一個豎線`|`，後面接著布林運算式，最後加上等號`=`和函式主體。同一個函式可以有多個 guard 敘述。guard 敘述會由上往下求值，第一個求值為`True`的敘述會被執行。guard 敘述可以包含一個`otherwise`敘述，用來承接所有不符合前面 guard 敘述的值。

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

我們也可以定義自己的函式，並在 guard 敘述裡使用它。

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
