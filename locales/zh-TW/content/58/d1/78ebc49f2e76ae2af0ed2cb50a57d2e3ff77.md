# 簡介

*不相交集*（一種並查集結構）會把一群值分割成互不重疊的群組，並且能快速回答一個問題：這兩個值是否在同一個群組裡？它位於[`disjoint-sets`][disjoint-sets]詞彙中。

## 建立不相交集

`<disjoint-set>`會建立一個空的結構。值，也就是*原子*，可以用`add-atom`一次加入一個，也可以用`add-atoms`從一個序列加入。每個原子一開始都自成一組。

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

不相交集是*可變的*：`add-atom`、`add-atoms`和`equate`會就地修改它，而不是回傳一個新的。當你希望不相交集在這些詞消耗掉之後回到堆疊上時，`keep`就很方便。

## 合併群組

`equate`會把包含其原子的兩個群組聯集起來。聯集具有遞移性：把兩個原子`equate`起來，再把其中一個與第三個`equate`，三個原子最後都會落在同一個群組裡。

```
equate ( atom1 atom2 disjoint-set -- )
```

## 代表

每個群組都有一個標準成員，也就是它的*代表*。`representative`會回傳它；兩個原子屬於同一個群組，若且唯若它們的代表相等。

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

群組挑選哪個原子當代表是內部細節，永遠不要依賴某個特定原子被選中，只需要依賴同一個群組中的兩個原子代表相同。
