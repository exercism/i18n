# 字串

`String` 資料型態是一串以 UTF-8 編碼的線性字元序列，很適合用來儲存文字資料。

## 建立字串

你可以使用 `String::new()` 或 `String::from()` 這兩個關聯函式來建立字串。許多型別都有 `to_string` 方法可以產生字串，例如從數字產生。

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### `format!` 巨集

由於從一堆較小的資料型態組出一個大字串是很常見的操作，Rust 也提供了簡寫，讓你不用理會呼叫 `to_string` 的細節，那就是 `format!` 巨集。舉例來說，我們可以把上面組出複合字串的寫法簡化如下：

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## 字串切片

字串和字串切片關係密切。字串切片是不可變的參照，指向一塊大小已知的記憶體區域，裡面是一串以 UTF-8 編碼的線性字元。任何字串都可以透過解參考（`&`）運算子借用，強制轉型成字串切片。要把字串切片轉成字串，`to_string()` 方法或 `String::from` 都很合適。

在 Rust 程式碼中，字串字面值用雙引號包起來。這些字串字面值一律是字串切片，因為它們指向程式執行檔裡一塊不可變的記憶體區域。

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## 修改字串

要把單一字元串接到字串後面，請用 `push` 方法。要把字串切片串接到字串後面，請用 `push_str` 方法或 `+` 運算子。

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## 存取字串中的字元

由於 Rust 的字串是以 UTF-8 編碼，個別字元的大小並不全都一樣。因此 `String` 資料型態並不提供索引運算子（`[]`）。要存取字串中的所有字元或某個特定字元，可以使用 `chars()` 方法。它會依序疊代字串中的每個字元。

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
