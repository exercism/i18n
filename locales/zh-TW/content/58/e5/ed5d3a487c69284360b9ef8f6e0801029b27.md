你也可以在 Markdown 文件中自行呈現這些小工具，例如放在文件結尾，推薦延伸閱讀或值得一試的練習。

**注意：**你也可以在行內文字使用一般連結，網站會自動為它們加上工具提示。詳見[內部連結說明文件](/docs/building/markdown/internal-linking)，以了解更多細節。

## 使用方法

只要能用 Markdown 的地方，就可以使用小工具，例如說明文件、解題方法和學生與導師的討論。

它們使用以下格式呈現：

```md
[<type>:<id>]()
```

`<type>`和`<id>`這兩部分是可變的，取決於實際使用的小工具。

連結參照（也就是`()`裡的內容）會被網站忽略。為了方便維護，你可以把它們指向任何你想要的內容。

## 練習小工具

連結格式：`[exercise:<track-slug>/<exercise-slug>]()`

### 範例

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## 概念小工具

連結格式：`[concept:<track-slug>/<concept-slug>]()`

### 範例

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## 解題方法小工具

連結格式：`[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### 範例

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## 文章小工具

連結格式：`[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### 範例

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
