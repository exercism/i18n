# 指令

馬戲團表演是由一連串節目組成的演出順序。每個節目的內容截然不同，但負責安排整場表演的人，需要從每個節目身上取得同樣的兩樣東西。

這是第一個要你在同一個檔案裡寫好幾個類別的練習。起始程式碼已經提供抽象類別，請在它底下寫出其餘的類別。

## 1. 三個節目

寫三個類別，每一個都是一種`$ACT`。

| 類別 | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "`再接上高度再接上`"m"` | 8 |

`JUGGLING`和`TUMBLING`建立時不需要引數。`TRAPEZE`建立時要傳入以公尺為單位的高度：

```sather
#JUGGLING
#TRAPEZE(4)
```

所以`#TRAPEZE(4).name`是`"Trapeze at 4m"`。

## 2. 整場表演

寫一個`CIRCUS_ACTS`類別，裡面有三個常式，每個都接收演出順序作為`ARRAY{$ACT}`。

**`total_minutes`**：整場表演總共花多久時間。

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**：所有節目的名稱，以`", "`串接起來。

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**：時間最長的節目名稱。如果兩個節目時間相同，較早出現的勝出。空的表演沒有最長的節目，所以答案是`""`。

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

這三個常式都不能詢問傳入的節目是哪一種類型。
