# 簡介

元組可以擴充其他元組。`TUPLE: child < parent slots ;`會宣告一個類別，它的實例同時也是`parent`的實例：它們除了自己的槽位之外，還會一併取得父類別的槽位，而父類別的存取子在它們身上也同樣有效，就好像那些存取子原本就定義在子類別上一樣。

```factor
USING: accessors ;

TUPLE: animal name age ;
TUPLE: dog < animal breed ;

"Rex" 4 "labrador" dog boa .
! => T{ dog { name "Rex" } { age 4 } { breed "labrador" } }

"Rex" 4 "labrador" dog boa name>> .   ! => "Rex"   (inherited accessor)
```

## `boa`的槽位順序

`boa`建構子接受槽位的順序是*宣告順序，父類別優先*。對上面的`dog`來說：

```
dog boa ( name age breed -- dog )
```

一個加上`weeks`的孫類別`puppy < dog `則會是：

```
puppy boa ( name age breed weeks -- puppy )
```

## 述詞階層

每個`TUPLE:`宣告都會產生一個述詞（`name?`）。
有了繼承之後，這些述詞會形成巢狀，每個後代都滿足祖先的述詞：

```factor
"Rex" 4 "labrador" dog boa
dup dog? .        ! => t
dup animal? .     ! => t
```

反過來並不成立：不是`dog`的`animal`無法通過`dog?`。

## 後續提醒

泛型方法（`M:`，會在[`generics`][generics]中介紹）也會沿著階層往上分派：定義在`animal`上的方法會對每個後代生效，除非有更具體的覆寫取得優先權。你在緊接著這個練習之後的`boatswains-bilge`裡馬上就會看到。
