# 簡介

錯誤在所難免。在 Elixir 中，雖然大家常說「let it crash」，但有時候我們仍需要救援函式呼叫，讓它回到已知的良好狀態，以履行軟體契約。在某些語言裡，錯誤被當成控制流程的一種手法，但在 Elixir 中並不鼓勵這種模式。我們通常光看名稱就能認出哪些函式可能會引發錯誤：會引發錯誤的函式，名稱結尾會加上`!`。這和回傳`{:ok, value}`或`:error`的函式形成對比。看看這些函式庫的例子：

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
