# 說明

實作遊程編碼與解碼。

遊程編碼（RLE）是一種簡單的資料壓縮形式，其中每個遊程（連續的資料元素）會以單一資料值和次數來表示。

例如，我們可以用 13 個字元來表示原本的 53 個字元。

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

遊程編碼可以從壓縮後的資料完美重建原始資料，因此它是一種無損資料壓縮。

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

為了簡化，你可以假設未編碼的字串只會包含字母 A 到 Z（大寫或小寫皆可）以及空白字元。這樣一來，要編碼的資料永遠不會包含任何數字，而要解碼的資料中的數字一律代表後續字元的次數。
