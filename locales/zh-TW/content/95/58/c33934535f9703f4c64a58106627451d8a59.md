# 指令補充

## 這個練習在 Python 中的結構

這個練習最適合用 Python 的 `%`（[取餘數][modulo]）運算子來解，它會回傳正整數除法所得的餘數。
它有一個等效的方法，就是 [operator 模組][operator-mod] 裡的 `operator.mod()`。


Python 在 [math 模組][math-module] 中也另外提供了幾個「餘數」方法。
[`math.fmod()`][fmod]的行為和 `%` 類似，但處理的是浮點數。
[`math.remainder()`][remainder]針對相除的餘數實作了「最接近零的步進」演算法。
雖然我們鼓勵你熟悉這些方法，但兩者的結果都不會與 `%` 完全一致，因此不建議在這個練習中使用。

內建函式[`divmod()`][divmod]在搭配兩個正整數使用時，也能得到與 `%` 相符的餘數，但它回傳的是一個需要拆解的 `tuple`。
