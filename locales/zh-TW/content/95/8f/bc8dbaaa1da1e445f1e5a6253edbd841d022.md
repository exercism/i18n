# 關於

集合的定義通常會在尖括號中加入一個佔位符號，依慣例通常是 T。這樣的集合稱為泛型。這讓使用集合的人可以指定要儲存在集合中的項目型別。在上面的範例程式碼中，我們建立了一個字串陣列。

只要使用`@:generic`標記，就能讓類別或函式變成**泛型**。這會讓編譯器將該類別或函式視為泛型：

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
