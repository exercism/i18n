# Nil

Crystal 有一種型別叫做[`Nil`][nil]，它只能有一個值：`nil`。它用來表示「沒有值」，類似於其他語言中的`null`或`None`。

Nil 值可以從各種方法回傳，例如[`String#[]?`][string-index]，當索引超出範圍時，它會回傳`nil`。

```crystal
"foo"[10]? # => nil
```

Crystal 有項機制叫做**空參考檢查**，意思是所有型別預設都不可為 nil。這表示除非你明確把變數宣告成`Nil`型別，否則不能把`nil`指定給變數。因此編譯器會自動檢查空參考。

## 假值

處理`nil`值有幾種做法。`nil`是[假值][truthy-falsey]，`false`也是。這表示在敘述，以及其他預期假值或真值的地方，`nil`都會被當成`false`看待。

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

這表示如果一個可為 nil 的變數值為`nil`，就不會進入真值分支。

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## 檢查是否為 nil

Crystal 有個方法可以檢查某個值是否為`nil`，叫做[`nil?`][nil?]，所有物件都可以使用。

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

直接把值用在 if 敘述裡時，情況會有點不同，因為在前面的例子裡，`false`和`nil`都會被當成假值。這裡只有`nil`會被當成假值，因為如果它的值是`false`，那它就不會是`nil`，因此會是真值。

## or 運算子

處理`nil`值最簡單的方法，就是從一開始就確保它們不會變成`nil`。or 運算子（[`||`][or]）經常用來處理`Bools`，但只要理解正確，它也能用來處理`nil`值。or 運算子會檢查第一個值是否為真值，如果不是，就採用第二個值。如此一來，如果值是`nil`，就會是假值，因此會採用第二個值。

```crystal
"foo"[10]? || "bar" # => "bar"
```
