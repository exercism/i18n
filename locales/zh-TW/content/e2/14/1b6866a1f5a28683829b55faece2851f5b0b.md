# 關於

雜湊是 Perl 的一種資料型態，其中包含由字串鍵與純量值配對而成的無序集合。

雜湊變數通常是透過指定一個陣列給它來填入內容，例如`my %scores = (Alice => 10, Bob => 15, Charlie => 20);`。

陣列通常以逗號分隔，但你常會看到用所謂的「胖逗號」`=>`來分隔陣列中的鍵與值。
它的行為和逗號幾乎相同，但額外的好處是會把左邊的元素視為字串。

雜湊也可以透過指定個別的鍵來填入內容，例如`$scores{Alice} = 10;`。

只要透過下標指定鍵，就能取得雜湊的值，例如`$scores{Bob} # 15`。

雜湊中的鍵是唯一的。
同一個鍵如果出現多次，只會保留最後一次指定的值。

## 函式

處理雜湊的函式包括 [keys][keys] 和 [values][values]，可將雜湊的這兩個部分分別取回成陣列。
[keys][keys] 和 [values][values] 函式回傳的陣列，對於 [grep][grep]、[map][map]、[sort][sort] 這類陣列函式，以及 [for][for] 迴圈，都很有用。

其他雜湊函式還包括 [exists][exists]，用來檢查某個鍵是否存在於雜湊中（即使它的值是`undef`），以及 [delete][delete]，用來從雜湊中移除某個鍵。

## 變數符號的差異

取得雜湊的值時，所使用的變數符號會決定結果。
變數名稱結尾的下標`{}`，就是在告訴 Perl 你正在存取該名稱的雜湊。

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

雖然這是被允許的，但為了可讀性，建議不要讓不同型別的變數共用同一個名稱。
