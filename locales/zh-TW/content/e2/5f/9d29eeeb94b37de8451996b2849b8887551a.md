# 除錯

執行每個測試時，你的 Red 腳本所產生的所有輸出都會顯示在主控台。你可以用`print`印出任何想印的東西，例如詞的值：

```red
print ["x =" x]
```

此外，`probe`函式也非常好用喔。它被求值時，會先求值自己的輸入，以反映其型別的方式印出結果，然後回傳它。所以在大多數情況下它是「透明」的，你可以把它放進運算式裡：

```red
x: 10
y: probe x + 5
```

有時候，名為`type?`的函式（沒錯，它的名字裡真的有一個問號！）可以用來檢查值的型別：

```red
print ["x type:" type? x]
```

還有一些更進階的除錯技巧，[列在 Red 的 Wiki 上](https://github.com/red/red/wiki/%5BDOC%5D-Debugging)。
