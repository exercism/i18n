# 指令

在這個練習中，你是個超級運動迷，而且最近剛愛上 NBA 籃球。
由於才剛接觸 NBA 籃球，你正深入研究 NBA 的歷史，追蹤各支球隊、教練、他們的勝敗紀錄，並互相比較。

因為你還沒有支持的球隊，你也會開發一套演算法，判斷是否該為某支球隊加油。
你有七個任務，幫助你開發出專屬於你的「為球隊加油」演算法。

## 1. 定義模型

定義 `Coach` 型別別名，用來表示一筆記錄，包含以下兩個欄位，順序如下：

- `name`：教練的名字，型別為`String`。
- `formerPlayer`：表示該教練是否曾是球員，型別為`Bool`。

定義 `Stats` 型別別名，用來表示一筆記錄，包含以下兩個欄位，順序如下：

- `wins`：勝場數，型別為`Int`。
- `losses`：敗場數，型別為`Int`。

定義 `Team` 型別別名，用來表示一筆記錄，包含以下三個欄位，順序如下：

- `name`：球隊的名字，型別為`String`。
- `coach`：球隊的教練，型別為`Coach`。
- `stats`：球隊的戰績，型別為`Stats`。

## 2. 建立球隊

你想與某些第三方程式碼介接，那些程式碼也有球隊的概念，但它們呼叫你的程式碼時，參數順序不同。請新增一個`createTeam`函式，型別簽章如下：`String -> Stats -> Coach -> Team`。

## 3. 更換教練

NBA 的老闆們沒什麼耐性，你發現球隊戰績不佳往往會導致教練被換掉。
實作`replaceCoach`函式，它接收新教練和球隊作為參數，並回傳換上新教練的球隊：

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. 檢查你是否該為某支球隊加油

未來你打算想出一套複雜的演算法來判斷是否該為某支球隊加油，但第一次嘗試時，你決定只要球隊的勝場數多於敗場數，你就該為它加油。

你希望這個函式能在其他情境中重複使用，所以在型別簽章中使用可擴充的記錄，以接受任何具有相關欄位的記錄。
為了讓函式盡可能簡潔，你想用模式比對從函式參數中取出`stats`。
實作`rootForTeam`函式，它接收一支球隊，如果你該為這支球隊加油就回傳`True`，否則回傳`False`。

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
