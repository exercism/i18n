# 指令補充

## 輸出格式

每個國籍都以單一字母表示。（`E` = `Englishman`，`J` = `Japanese`，`N` = `Norwegian`，`S` = `Spaniard`，`U` = `Ukrainian`）

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                  |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | 輸出    | 位元組    | 喝水者的國籍 |
| `$v1`    | 輸出    | 位元組    | 斑馬擁有者的國籍   |
| `$t0-9`  | 暫存 | 任意     | 用於暫存        |
