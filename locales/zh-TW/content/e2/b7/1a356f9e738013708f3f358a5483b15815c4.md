# 提示

## 一般

- Go 的切片索引從 0 開始。
  切片的第一個索引是`0`。
- 內建的[`append`][append-builtin]函式是[`variadic`][variadic-gobyexample]
- 你可以使用三個點記號，把一個切片的元素附加到另一個切片：

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. 建立含有特定卡片的切片

- 若要建立預先填入某些資料的切片，請使用切片字面值表示法：`s := []T{x1, x2, ..., xn}`。

## 2. 從牌堆中取出卡片

- 要取得切片中的第`n`個項目，[請使用索引][go-slices]。
- 若要檢查某個項目是否存在於切片中，可以使用條件式，並把索引與[切片的長度][len-builtin]相比較。

## 3. 替換牌堆中的卡片

- 若要設定切片中的第`n`個項目，[請使用索引][go-slices]並指定一個新的值給它。
- 若要在切片末端新增一個項目，請使用`append`函式。

## 4. 將卡片加到牌堆頂端

- 若要在切片前端新增項目，可以把原始切片的元素附加到`value`引數切片。

## 5. 從牌堆中移除卡片

- 移除切片中某個項目的做法，是把`index`之後的部分附加到它前面的部分。
