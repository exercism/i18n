# 簡介

[結構][structs-and-classes]（一般常稱為*struct*）是 Swift 程式主要的建構組塊之一。
結構讓你可以建立自訂型別，把相關的屬性（資料）和方法（行為）群組在一起。
事實上，Swift 的標準型別，包括`Int`、`Double`、`Bool`、`String`、`Array`和`Dictionary`，都是以結構實作的。

## 定義結構

使用`struct`關鍵字來定義結構，後面接著型別名稱，以及一對大括號，裡面是它的定義。
依照 Swift 的慣例，結構名稱使用`UpperCamelCase`：

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## 建立實例

結構的定義是一份藍圖。
要建立結構的*實例*，寫出型別名稱並在後面加上括號，即可呼叫它的初始化器：

```swift
var someStats = CharacterStats()
```

這樣會建立一個實例，並以定義中的預設屬性值填入。

Swift 也會為結構自動產生**逐一成員初始化器**，讓你可以依名稱初始化屬性：

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## 存取與修改屬性

你可以使用*點記法*來存取和修改實例的屬性：

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

因為結構是值型別，要修改實例的屬性，實例本身就必須以`var`宣告。
如果實例是以`let`宣告的，它的所有屬性都會變成不可變。
