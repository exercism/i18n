# 指示補充

## 詞

定義一個`cmplx`元組，其槽為`real`與`imaginary`。槽存取子`real>>`與`imaginary>>`會隨元組定義自動產生，測試就是用它們來讀取各分量。

- `<cmplx> ( real imag -- cmplx )`，建立一個複數。
- `>cmplx ( pair -- cmplx )`，從`{ real imaginary }`建立一個`cmplx`。
- `cmplx>pair ( cmplx -- pair )`，回傳`{ real imaginary }`。
- `c+ ( a b -- c )`、`c- ( a b -- c )`、`c* ( a b -- c )`、`c/ ( a b -- c )`，對兩個複數做算術運算。
- `c-abs ( a -- |a| )`，取絕對值（實數）。
- `c-conj ( a -- a* )`，取共軛複數。
- `c-exp ( z -- e^z )`，複數指數。

Factor 的`MATH:`泛型（`+`、`-`、`*`、`/`）只會對內建的數學階層進行分派，因此這個練習採用專屬的詞名稱，而不是在這些泛型上定義方法。

混合實數與複數的算術測試並未納入，這裡的每個運算都是在兩個`cmplx`值之間進行。
