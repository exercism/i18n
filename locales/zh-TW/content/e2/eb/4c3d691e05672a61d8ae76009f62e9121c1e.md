# 介紹

## 型別轉換

型別轉換有時也稱為型別強制轉換。
型別轉換是指將兩個不同型別的值強制轉換成同一型別，以便執行運算。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

這可以是隱式進行的（見上例），也可以使用`C`風格的型別轉型明確進行：

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

手動型別轉型允許的型別有：`bool`、`int`、`float`、`string`、`array`、`object`。
最常見的情況是，型別轉型用來把整數（`int`）轉成浮點數（`float`），或反過來。
