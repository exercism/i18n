# 提示

## 一般

## 1. 實作`new()`方法

- `new()`方法會接收我們用來建立`User`實例的引數。它應該回傳一個帶有指定 name、age 和 weight 的`User`實例。

- 更多定義與建立結構體實例的範例，請見[這裡](https://doc.rust-lang.org/book/ch05-01-defining-structs.html)。

## 2. 實作 getter 方法

- `name()`、`age()`和`weight()`這三個方法都是 getter。換句話說，它們負責回傳結構體實例上對應的欄位。

- 請注意，`User`結構體上的`name`欄位是`String`，但`name`方法回傳的卻是`&str`。我們要怎麼讓`&str`和`String`彼此配合呢？

- 在 Rust 裡，除非你明確想讓函式或方法提早回傳，否則不需要使用`return`敘述。一般來說，把想讓函式或方法回傳的結果後面的分號省略，改用_隱式_回傳會更符合慣例。使用顯式回傳並不是_錯_的，但能在適當的時候善用隱式回傳會更簡潔。

```rust
fn foo() -> i32 {
    1
}
```

- 更多在結構體上定義方法的範例，請見[這裡](https://doc.rust-lang.org/book/ch05-03-method-syntax.html)。

## 3. 實作 setter 方法

- `set_age()`和`set_weight()`是 setter，負責用傳入的引數更新結構體實例上對應的欄位。

- 正如這些方法的簽章所表明的，setter 方法不應該回傳任何值。
