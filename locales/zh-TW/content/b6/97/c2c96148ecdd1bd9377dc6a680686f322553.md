# 同步標籤工作流

同步標籤工作流會將儲存庫的 [GitHub 標籤](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) 與`.github/labels.yml`檔案的內容同步。
每當`.github/labels.yml`檔案變更時，同步標籤工作流就會自動更新儲存庫的標籤。

## 自訂標籤

定義在`.github/labels.yml`中的標籤有兩種形式：

- 共用標籤：這些是_所有_ Exercism 儲存庫都會使用的標籤，定義在 [org-wide-files 儲存庫](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- 軌道專屬標籤：這些標籤定義在`.appends/.github/labels.yml`檔案中

若要新增軌道專屬的標籤，你需要把它們加到`.appends/.github/labels.yml`檔案中（請參考[這個範例](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)）。
把變更合併到`main`之後，系統就會自動開啟一個 pull request 來修改`.github/labels.yml`檔案。
合併該 PR 之後，標籤就會自動更新（請見上述說明）。

```exercism/caution
絕對不要手動編輯`.github/labels.yml`檔案，因為那些變更會在下次同步標籤時被覆寫。
```

## 來源

這個工作流定義在`.github/workflows/sync-labels.yml`檔案中。
