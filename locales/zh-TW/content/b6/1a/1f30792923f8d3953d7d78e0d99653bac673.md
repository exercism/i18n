# 指示

鎮上新開了一間詩社，你正考慮要不要去參加。
因為過去曾經發生過一些事，這間詩社有一套非常嚴格的入場規定，你得先摸清楚才能進門喔。

詩社有兩扇門，一扇前門、一扇後門，兩邊都有人看守。
想進去的話，你得先想出當天的密碼。

密碼一律以一首詩為基礎，可以透過兩個步驟推導出來。

1. 守衛會一次唸一行詩，你要針對那一行回應對應的字母。
2. 接著守衛會把你回答過的所有字母一次告訴你，而你要用特定的格式把它們寫在一張紙上。

流程的細節取決於你想進的是哪一扇門。

## 1. 取得句子的第一個字母

為了得出前門密碼的字母，你要回應守衛唸給你的那行詩的第一個字母。

為了讓密碼好看一點，詩社成員喜歡用_藏頭詩_。
也就是說，每個句子的第一個字母會拼成一個單字。
以下是他們最喜歡的作家之一 Michael Lockwood 的作品。

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

所以當守衛唸**Stands so high**時，你要回答**S**；當守衛唸**Huge hooves too**時，你要回答**H**。

請實作函式`frontDoorResponse`，它接受一行詩作為引數，並回傳那一行的第一個字母。

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. 將單字首字母大寫

既然你已經收集到所有正確的字母，接下來只要把單字正確地改成首字母大寫，就能得到前門的密碼。

請實作函式`frontDoorPassword`，它接受一個字串（你在第 1 項任務中找到的字母組合），並回傳首字母正確大寫的結果。

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. 取得句子的最後一個字母

為了得出後門密碼的字母，你要回應守衛唸給你的那行詩的最後一個字母。

詩社成員真的很聰明。
前面提到的那首詩同時也是_藏尾詩_，意思是每個句子的最後一個字母也會拼成一個單字：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

當守衛唸**Stands so high**時，你要回答**h**；當守衛唸**Huge hooves too**時，你要回答**o**。

要注意的是，守衛有時會在一行的開頭或結尾加入風格上的停頓（也就是空白字元）。
你需要忽略這些停頓，才能得出正確的字母。

請實作函式`backDoorResponse`，它接受一行詩作為引數，並回傳那一行中最後一個不是空白字元的字母。

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. 要有禮貌

想從後門進入詩社，你得格外有禮貌。
所以這次推導密碼時，除了要把單字正確地改成首字母大寫，還要在結尾加上`', please'`。

請實作函式`backDoorPassword`，它接受一個字串（你在第 3 項任務中找到的字母組合），並回傳加上禮貌用語後的大寫密碼。

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
