# 指令

## 1. 概述

[逆波蘭表示法](https://en.wikipedia.org/wiki/Reverse_Polish_notation)（RPN）是一種撰寫數學運算式的方式。
與傳統的中序表示法不同，RPN 的運算子會*跟在*運算元後面。
舉例來說，你不會寫成：

```
2 + 2
```

而是寫成：

```
2 2 +
```

逆波蘭表示法最大的好處，就是它比中序表示法容易解析得多。
在複雜的運算式中，RPN 不需要考慮運算優先順序，也不需要括號。
例如：

```
(4 + 8) / (7 - 5)
```

可以寫成

```
4 8 + 7 5 - /
```

這兩種寫法的運算式求值結果都是 6。

## 2. 範例

我們來手動計算這個複雜的運算式吧。
如同簡介中所學到的，計算 RPN 需要用到堆疊。
這個堆疊用來存放運算子要處理的數值。
我們讓計算機從空堆疊開始，然後一次計算一個元素。

首先，我們遇到一個`4`，
所以把它推入剛建立好的堆疊。

```
4
```

接著，我們遇到一個`8`。
我們也把它推入堆疊。

```
4 8
```

現在，我們遇到一個`+`。
我們把最上面的兩個值（4 和 8）彈出，
將它們相加，
再把相加的結果推回堆疊。

```
12
```

我們對`7`、`5`和`-`做類似的事：

```
12 7
12 7 5
12 2
```

現在我們遇到一個`/`。
雖然我們上一個遇到的運算子是`-`，
但堆疊上還有兩個元素。
我們把這兩個元素彈出，
將它們相除，
再把結果推回堆疊。

```
6
```

最後，因為堆疊上剛好只剩一個元素，
我們可以說這個運算式的計算結果是 6。

## 3. 目標

你的目標是寫一個計算機，計算一連串以逆波蘭表示法排列的輸入，並回傳堆疊上最後的元素。

如果最後堆疊上不是剛好只有一個元素，請回傳`None`。

如果某個運算子的運算元太少（例如輸入`2 +`），請回傳`None`。

以下提供了一個列舉和一個待實作的函式作為起點。

```rust
#[derive(Debug)]
pub enum CalculatorInput {
    Add,
    Subtract,
    Multiply,
    Divide,
    Value(i32),
}

pub fn evaluate(inputs: &[CalculatorInput]) -> Option<i32> {
    todo!(
        "Given the inputs: {inputs:?}, evaluate them as though they were a Reverse Polish notation expression"
    );
}
```
