# 簡介

## 基礎

C# 是靜態型別的語言，這表示所有東西在編譯時期都有型別。將值指定給一個名稱，就叫做定義變數。定義變數時，可以明確指定它的型別，也可以讓 C# 編譯器根據指定的值推斷它的型別（這叫做_型別推斷_）。因此，下面這兩種變數定義方式是等價的：

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

更新變數的值要透過`=`運算子。變數一旦定義之後，它的型別就永遠不會改變。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# 是[物件導向語言][object-oriented-programming]，而且所有函式都必須定義在_類別_裡面。定義類別用的是`class`關鍵字。物件（或_實例_）則是使用`new`關鍵字建立的。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

類別裡的函式就叫做_方法_。每個方法可以有 0 個或多個參數。所有參數都必須明確標註型別，參數沒有型別推斷。同樣地，回傳型別也必須明確寫出來。方法是使用`return`關鍵字來回傳值。如果要讓其他檔案的程式碼能呼叫某個方法，就必須加上`public`存取修飾詞。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

方法是在實例上使用點（`.`）語法來呼叫的，要指定呼叫的方法名稱，並為方法的每個參數傳入引數。引數可以選擇性地指定對應的參數名稱。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C# 的作用域定義在`{`和`}`字元之間。

C# 支援兩種註解。單行註解前面要加`//`，多行註解則放在`/*`和`*/`之間。
