# 安裝 Factor

Factor 軌道使用 **Factor 0.101**。較早的版本不受支援。

你可以安裝[穩定版](#stable)或[每日版](#nightly)的建置，也可以[從原始碼建置](#build-from-source)。

執行`factor -e='vm-version print'`來驗證你的安裝，它應該會印出`0.101`或更高的版本。

---
### 穩定版

<https://factorcode.org#stable-release>在「Stable release」區段提供穩定版二進位檔。

---
### 每日版

<https://factorcode.org#development-release>在「Development release」區段提供每日版二進位檔。這些二進位檔是由 git 建置而成，但只會顯示通過的建置。

---
### 從原始碼建置

如果你想要最新開發中的版本，連每日版都嫌太舊，那你會需要現代的 C++ 編譯器（GCC >=4.8 或 Clang >=3.5）、`make`和`curl`。

滿足這些簡單的需求後，你就可以：

1. 下載`build` shell 指令碼：[**這裡**給 Unix-like 系統／POSIX shell](https://raw.githubusercontent.com/factor/factor/master/build.sh)，或[**這裡**給 Windows](https://raw.githubusercontent.com/factor/factor/master/build.cmd)。把它放到你要安裝 Factor 的目錄底下。系統會建立一個名為`factor`的目錄，裡面包含整份程式碼庫。

2. 用`./build.sh install`執行它，在 Windows 上則是`.\build.cmd install`。<sub>這會複製 Factor 的 `git` 儲存庫、建置它，並從 <https://factorcode.org> 下載 Factor VM 映像檔。這個過程可能需要 2 到 20 分鐘，時間長短取決於你的網路連線和處理器時脈。</sub>

3. 現在你可以執行在 `factor` 子目錄裡產生的`factor`或`factor.exe`二進位檔。試試`factor --help`取得說明。你也可以從命令列取得文件，或在 GUI Listener 中按下 <kbd>F1</kbd>，這會開啟說明瀏覽器。

4. 之後，請使用 `factor` 子目錄裡的`build.sh`（Windows 上為`build.cmd`）從 git 拉取更新並就地重新建置，必要時下載新的 VM 映像檔。

現在的檔案結構可能長這樣：

```
.
├── build.sh                   <- delete if you like
└── factor
    ├── basis
    ├── boot.unix-x86.64.image
    ├── build.cmd              <- use these from now on
    ├── build.sh               <-
    ├── core
    ├── extra
    ├── factor
    ├── Factor.app
    ├── factor.image
    ├── GNUmakefile
    ├── libfactor.a
    ├── libfactor-ffi-test.so
    ├── LICENSE.txt
    ├── misc
    ├── Nmakefile
    ├── README.md
    ├── unmaintained
    ├── vm
    └── work
```

你不再需要最上層的`build`指令碼，之後請改用下載下來的那個。

---

### 手動從原始碼建置（不建議）

複製[儲存庫](https://github.com/factor/factor)，然後在該資料夾中使用`make`。

如果`make`失敗，並出現找不到目標的錯誤，試試`make factor`；或者，如果你看得懂 Makefile，就在`GNUmakefile`裡找出你平台對應的 make 目標。

如果*那*也失敗了，就到 [factor/factor](https://github.com/factor/factor) 開一個 issue，附上錯誤訊息。親切的開發者們會很樂意幫忙。
