# 說明

在這個練習中，今天是情人節，你正在規劃要和伴侶一起做什麼。你的伴侶有很多想法，並請你為這些想法評分，好找出最棒的活動。

以下是你的伴侶提出的想法：

- 玩桌遊
- 放鬆一下
- 看電影
- 去餐廳吃飯
- 散步

你有六個任務，幫助你選出情人節的活動。

## 1. 定義認可

你的伴侶提出的每個想法，你都要用三種選項之一來回應：yes、no 或 maybe。

定義 `Approval` 代數資料型態，以下列三種案例來表示這些選項：`Yes`、`No` 或 `Maybe`。

## 2. 定義料理

你的伴侶選了兩間可能的餐廳：一間是韓國料理，另一間是土耳其料理。

定義 `Cuisine` 代數資料型態，以下列兩種案例來表示這兩間餐廳：`Korean` 或 `Turkish`。

## 3. 定義電影類型

可以選擇的電影非常多，所以為了縮小範圍，你的伴侶也列出了自己偏好的類型。

定義 `Genre` 代數資料型態，以下列幾個類型案例來表示：`Crime`、`Horror`、`Romance` 或 `Thriller`。

## 4. 定義活動

如前所述，你的伴侶想出了五種可能的活動：玩桌遊、放鬆一下、看電影、去餐廳吃飯和散步。

定義 `Activity` 代數資料型態來表示這些活動類型：

- `BoardGame`：沒有附帶資料。
- `Chill`：沒有附帶資料。
- `Movie`：以 `Genre` 作為附帶資料。
- `Restaurant`：以 `Cuisine` 作為附帶資料。
- `Walk`：以 `Int` 作為附帶資料，代表要步行的公里數。

## 5. 為活動評分

最後，你準備好要為伴侶的想法評分了。
以下是你看待伴侶想法的感受：

- 玩桌遊：no。
- 放鬆一下：no。
- 看電影：如果是浪漫愛情片，就是 yes；否則為 no。
- 去餐廳吃飯：如果是韓國料理，就是 yes；如果是土耳其料理，就是 maybe。
- 散步：如果走不到 3 公里，就是 yes；如果介於 3 到 5 公里（含），就是 maybe；否則為 no。

實作一個名為 `rateActivity` 的函式，接受一個 `Activity` 值，並依據上述感受回傳 `Approval`。
例如：

```haskell
rateActivity (Restaurant Turkish)
-- -> Maybe
```
