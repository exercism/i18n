# 關於

在像 Elm 這樣的純函式語言中，只要傳入相同的引數，函式就一定得回傳相同的值。
因此，型別簽章為`rand : Int`的函式只能實作成(`rand = 4`)[xkcd-random]，這對產生隨機整數來說可不是什麼好兆頭。

那我們在 Elm 裡要怎麼產生隨機值呢？
我們把問題拆成兩半：先用`Random.Generator a`描述我們想產生的值，然後再產生出值。

第一種產生值的方法，是透過`initialSeed : Int -> Seed`建立一個`Random.Seed`。
`Seed`是一種不透明型別，裡面包含一個整數，並且知道如何用看起來很隨機的方式（稱為偽隨機）轉換那個整數。
有了`Seed`之後，你就能用一個`Generator a`來產生值。
`Generator a`也是一種不透明型別，它知道如何用種子裡的整數，建立一個型別為`a`的偽隨機值，以及一個內含更新後整數的新種子。

要產生值，我們可以用`step : Generator a -> Seed -> ( a, Seed )`，它會回傳一個值，以及一個可以用來繼續產生更多值的新種子。

我們就用這些函式，從一個產生器裡取出`n`個隨機值吧：

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

注意，這些函式全都是純的，所以用相同的引數呼叫兩次，會產生相同的值。

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

第二種產生值的方法，是使用`Random.generate : (a -> msg) -> Generator a -> Cmd msg`，但這只能在 Elm 應用程式裡面做。
這種情況下，Elm 執行環境除了`step`之外，還可能動用外部的不純資源來產生種子，於是呼叫同一個函式兩次會得到不同的結果。

接下來，我們把焦點放在產生器上。

`Random`模組提供了兩個基本的產生器，可以在特定範圍內建立整數與浮點數：

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

這些值可以組合成元組，或是組合成值的陣列：

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

(`elm-community/random-extra`)[random-extra]套件提供了更多產生器，可用於各種資料結構：字串、日期、字典、陣列、集合等等。

我們可以用`Random.constant`建立只會回傳單一值的產生器：

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

我們可以用`Random.uniform`，以相同的機率從給定的元素中隨機挑選：

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`接受兩個引數（`Red`和`[Green, Blue]`），以確保至少有一個值可以挑，因為單一陣列有可能是空的。

我們也可以用`Random.weighted`調整機率：

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

這些值不必加起來等於 100，反正它們最後會被重新正規化。

我們可以用`Random.map`深入產生器的內部：

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

我們也可以用`Random.map2`一路到`Random.map5`，把更多產生器組合起來：

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

如果用途更複雜，我們還有`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，它可以用某個產生器產生的值來建立另一個產生器：

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

有時候，以自我遞迴的方式定義產生器是很有用的。
在那些情況下，你可能需要用`Random.lazy`，避免編譯器無限展開產生器。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

這個例子有點沉重，我們把它拆解一下吧。

`Peano`是一種代表正整數的型別：`Zero`是 0，`Next(Zero)`是 1，`Next(Next(Zero))`是 2，依此類推。
我們定義`peano`，讓它能給出一個隨機的`Peano`數字。

首先要注意，`Random.lazy`並沒有為邏輯加上任何東西，它只是避免編譯器把`peano`無限地寫進`peano`裡。

我們用`Random.uniform`在零（有 50% 的機率）和另一個`Peano`數字加一（有 50% 的機率）之間做選擇。
不過，和前一個例子不同的是，`Random.uniform`並不是從值（例如`Zero`）裡挑選，而是從產生器（例如`Random.constant Zero`）裡挑選，因為我們想用`peano`本身。
這代表`Random.uniform`會回傳型別為`Generator (Generator Peano)`的值，而這不是我們要的。

為了把產生器「攤平」，我們用管線把它送進`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，其中我們希望`b`是`Peano`。
因為`Generator a`是`Generator (Generator Peano)`，`a`就必須是`Generator Peano`，而函式`(a -> Generator b)`的型別必須是`(Generator Peano -> Generator Peano)`。
我們不想修改任何東西，所以`identity`正是正確的選擇。

最後，`peano`會產生什麼樣的數字呢？
我們知道它有 50% 的時間會產生 0，另外 50% 的時間會產生它自身的另一次疊代再加一。
這表示產生的數字會是 0（50% 的時間）、1（25% 的時間）、2（12% 的時間）、3（6% 的時間）等等。
`peano`可以產生任意大的數字，但機率會以指數的方式遞減。
