# 補充說明

在 Python 軌道上，這個練習會請你建立一個 `SpaceAge` _類別_（_[concept:python/classes]()_），其中包含太陽系所有行星對應的方法。
方法應遵循`on_<planet name>`的命名慣例。

每個方法都應該 `return` 在該行星上的年齡（以年為單位，四捨五入到小數點後第二位）：

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
