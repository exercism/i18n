# 簡介

在 Java 中，方法多載是一項功能，讓類別可以擁有多個名稱相同的方法，只要它們的參數列表不同即可。
它與編譯時期（或靜態）多型有關。
這個概念對於建立執行類似工作、但輸入不同的方法來說非常重要。

## 為什麼要使用方法多載？

方法多載能提升程式的可讀性。
不同的方法可以取相同的名稱，但使用不同的參數。
會根據參數的數量或參數的型態，呼叫對應的方法。

## 如何多載方法？

方法多載的關鍵在於方法的簽章。
如果兩個方法具有不同的簽章，就會被視為不同的方法。
多載方法的方式有兩種：

1. **參數數量不同**：方法可以有相同名稱，但參數數量不同。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **參數型態不同**：方法可以有相同名稱和相同的參數數量，但參數的型態不同。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## 重點提醒

- 多載的方法必須改變引數列表。
- 多載的方法也可以改變回傳型態，但僅僅改變回傳型態並不構成方法多載。
- 方法可以在同一個類別或子類別中多載。

在這個概念中，我們會探討 Java 中方法多載的各種範例與細節。
