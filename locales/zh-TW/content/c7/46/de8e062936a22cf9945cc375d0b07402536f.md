## 編輯器

### 免費／開源

- [VS Code](https://code.visualstudio.com)

  VS Code 是開源的程式碼編輯器。你可以[在這裡](https://code.visualstudio.com/docs/languages/typescript)找到如何設定 TypeScript 的資訊。VS Code 是 TypeScript 的熱門編輯器，因為微軟同時維護 VS Code 和 TypeScript，所以它和這個語言搭配得很好；VS Code 不需要任何額外設定就能支援 TS。事實上，VS Code 就是用 TypeScript 寫成的！

  VS Code 與 TS 常見的問題是編輯器和專案版本不同，這可能讓 VS Code 顯示令人困惑的錯誤訊息。處理這個錯誤的說明在[這裡](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### 需付費授權

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text 是熱門的程式碼編輯器，透過可安裝的外掛支援大多數語言。它可以免費試用，但會不時提示你購買授權，目前價格為 70 美元。

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm 是功能完整的 JavaScript/TypeScript IDE（整合開發環境）。它不需要額外設定就能支援 TypeScript，並整合了測試、除錯和程式碼分析。它可以免費試用 30 天，之後第一年的年度授權價格為 129 美元。
