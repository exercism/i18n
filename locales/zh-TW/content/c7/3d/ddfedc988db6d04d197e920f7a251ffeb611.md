在 Raku 中，程式區塊的使用非常普遍。它是函式的基礎，但同時也常出現在`grep`和`map`這類工具裡，用於`if`、`for`、`while`和`given`敘述的區塊，甚至連陣列索引也不例外。

## 常式

`Subs`和`Methods`是 Raku 中`Routines`的兩種型別。

常式可以隨時使用`return`關鍵字帶著回傳值結束，這是建立函式時很實用的工具。
如果沒有指定`return`，常式的最後一個敘述就會是它隱含的回傳值。

常式可以在程式區塊之前，用小括號包住一個`Signature`。

`Routine`是`Block`的子類別。

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

方法會留到另一個與類別和物件相關的概念中介紹。

## 區塊

`Block`是一種可重複使用的程式物件，通常用來建立 lambda。

區塊的最後一個敘述就是它隱含的回傳值。

區塊可以在程式區塊之前，加上以`->`開頭的`Signature`。

`Block`是`Code`的子類別，而`Code`是 Raku 中所有程式物件的最基底類別。

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## 簽章

`Signature`由零個或多個`Parameters`組成，以逗號分隔。

在簽章的最後，可以用[回傳型別箭頭][signatures-return-type-arrow]`-->`指定回傳型別。

簽章可以用來指定`Block`會接受的引數。

這個概念會讓簽章保持簡單，只使用位置參數搭配帶純量符號的變數，以及一個回傳型別。
這些會在其他概念中進一步擴充。

## 多重分派

Raku 允許使用`multi`關鍵字，撰寫多個名稱相同但簽章不同的常式。
這個功能稱為[多重分派][multi-dispatch]。
當常式被以名稱呼叫時，執行環境會決定正確的候選者並呼叫它。

這會在談到型別的概念中有更詳細的說明。

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

當`Whatever`星號`*`與大多數運算子搭配使用時，就會建立一個`WhateverCode`物件。
這讓你可以用更簡單的語法建立區塊。

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
