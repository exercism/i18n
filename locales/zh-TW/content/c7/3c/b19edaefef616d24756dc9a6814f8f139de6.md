## 元組

[元組][tuple] 常用來把相關的資訊群組在一起，它和陣列不同的地方在於大小固定，而且可以存放不同的資料型態。
元組使用括號`()`建立，經常用來從函式回傳多個值。

```haskell
tuple = (1, "abc", False)
```

舉例來說，當你想把二維空間中的座標存起來時，這就很好用，因為你知道這個元組永遠會有 2 個元素，也就是 x 座標和 y 座標。

```haskell
coordinate = (3, 4)
```

### 存取元素

你經常會處理長度很短的元組，這時可以用`fst`和`snd`函式來存取裡面的元素。

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## 模式比對

撰寫 Haskell 函式時，我們可以運用[斷言式風格][assertive-style]搭配[模式比對][pattern-match-doc]：
模式比對是 Haskell 非常強大的功能，它讓你比對資料建構子，並把變數綁定到裡面的值。
顧名思義，我們做的事就是把值拿來和模式比對，如果值符合模式，就能把變數綁定到模式裡的值。
模式比對主要由這幾個概念組成：辨識值、綁定變數，以及拆解值。

來看看這個函式吧：

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

這裡有個`lucky`函式，它接受一個`Int`並回傳`String`。
我們為這個函式定義了 2 個模式，一個比對數字`7`，另一個比對其他任何數字；名稱可以任意取（只要符合 Haskell 的命名慣例），不過這裡我們用了`x`。
如果數字是`7`，函式會回傳`"Lucky number seven!"`，否則會回傳`"Sorry, you're out of luck, pal!"`。
這裡要特別注意的是，模式是由上往下依序檢查，所以如果把模式的順序對調，這個函式就會永遠回傳`"Lucky number seven!"`。

### 陣列模式

一個很常見的模式是比對陣列，也就是取出陣列的頭和尾。
這是因為陣列本質上就是一種連結串列。
以下是回傳陣列頭與尾的函式範例：

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

這裡有 2 個模式，一個比對空陣列，另一個比對至少有 1 個元素的陣列。
這是因為如果陣列是空的，我們必須處理這種情況，否則就會產生執行階段錯誤。
如果陣列不是空的，我們可以把陣列的頭比對到`x`，把陣列的尾比對到`xs`。
這是用`:`（cons）運算子做到的，這個運算子用來把元素加到陣列最前面。
但在模式比對中，它讓我們把陣列拆解成頭和尾，某種程度上算是反過來做。

`xs`是陣列尾部的慣用名稱，它凸顯了這是一個陣列；不過如果你處理的是巢狀陣列，可以用`xss`來凸顯它是「陣列的陣列」。

### 元組模式

和陣列一樣，我們也可以比對元組。
以下是接受元組並回傳第一個和第二個元素的函式範例：

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

這裡的模式比對一個有 2 個元素的元組，第一個元素綁定到`x`，第二個元素綁定到`y`。

### 萬用字元模式

有時候我們不在意某個變數的值，只想讓模式比對成功。
這時就輪到萬用字元模式出場，它以底線`_`表示。

以下是回傳陣列第一個元素的函式範例：

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

這裡我們表示不需要陣列的尾，所以用萬用字元模式把它忽略掉。

### 型別模式

我們也可以比對型別，做法是使用該型別的建構子。
我們同樣能從型別中取出值，就像剛剛對元組做的一樣。

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

第一個模式比對`Guest`建構子，第二個模式比對`User`建構子，並把裡面的值綁定到`name`。
