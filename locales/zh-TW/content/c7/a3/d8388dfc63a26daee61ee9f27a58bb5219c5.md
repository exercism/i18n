# 關於

[映射][maps]是一種用來保存鍵值對的資料結構。

- 鍵可以是任何型態，但必須是唯一的。
- 值可以是任何型態，不需要是唯一的。
- 映射不保證內容的順序，即使表面上看似如此。
  - 會有這種錯覺，是因為它們底層的實作方式：
    - 數量少的時候（<=32 個項目），是以有序的[關鍵字陣列][keyword-list]實作。
    - 數量較多時（>32 個項目），則是以[雜湊陣列映射樹][hamt]實作 &#91;[1][stackoverflow]&#93;。
- 映射可以用字面形式宣告：

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- 映射也可以使用 [Map 模組][map-module] 提供的[`Map.new`][map-new]來建立。如果你已經有一個可列舉的集合想轉成陣列，就可以用這種方式：

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- 映射中的值可以用許多不同的方式存取：

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- 標準函式庫中的 [Map 模組][map-module] 有許多處理映射的實用函式。

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- 映射實作了[`Enumerable`][enumerable]協定，因此可以使用 [Enum 模組][enum] 的函式。
- [匿名函式][anon-fn]或[捕獲的函式參考][captured-fn]經常會作為 [Map][map-module] 和 [Enum 模組][enum] 函式的引數

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
