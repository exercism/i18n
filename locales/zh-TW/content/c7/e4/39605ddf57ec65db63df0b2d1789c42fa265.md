# 指示

你要寫一些程式碼，幫你照著最愛的食譜做千層麵。

你有五個任務，全都和做這道食譜有關。

## 1. 定義預期的烤箱時間（分鐘）

把`$EXPECTED-MINUTES-IN-OVEN`常數設為千層麵應該待在烤箱裡的分鐘數。根據食譜書，預期的烤箱時間是 40 分鐘：

```raku
$EXPECTED-MINUTES-IN-OVEN
# => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

修改`remaining-minutes-in-oven`副程式，它會接收千層麵實際已待在烤箱中的分鐘數作為引數，並根據上一個任務中預期的烤箱時間，回傳千層麵還需要待在烤箱裡多少分鐘。

```raku
remaining-minutes-in-oven(30)
# => 10
```

## 3. 計算準備時間（分鐘）

修改`preparation-time-in-minutes`副程式，它會接收你加在千層麵裡的層數作為引數，回傳你準備千層麵花了多少分鐘，假設每一層要花你 2 分鐘準備。

```raku
preparation-time-in-minutes(2)
# => 4
```

## 4. 計算總工作時間（分鐘）

修改`total-time-in-minutes`副程式，它會接收兩個引數：第一個引數是你加在千層麵裡的層數，第二個引數是千層麵已待在烤箱中的分鐘數。
這個副程式應該回傳你總共花多少分鐘做這份千層麵，也就是準備時間（分鐘）加上千層麵目前已經待在烤箱裡的時間（分鐘）之總和。

```raku
total-time-in-minutes(3, 20)
# => 26
```

## 5. 建立千層麵烤好的通知

修改`oven-alarm`副程式，它不接收任何引數，回傳一則表示千層麵已經可以吃了的訊息。

```raku
oven-alarm()
# => 'Ding!'
```
