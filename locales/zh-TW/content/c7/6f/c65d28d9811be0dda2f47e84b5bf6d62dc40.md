# 簡介

[concept:csharp/resource-cleanup]() 使用`IDispose`介面來表示某個物件的資源或其他程式狀態，在該物件不再需要時必須被釋放或重設（而且光靠垃圾回收器無法達成這件事，也無法提供所需的控制程度），而`IDisposable.Dispose()`方法正是這類清理作業的適當位置。

還有另一種建構方式，也就是`using`區塊，它從呼叫端的角度來看，能把所有資源生命週期管理都收攏到單一敘述中。

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

在上面的範例中，與`file`相關的檔案系統資源會在離開`using`區塊時釋放回作業系統。

要讓這個模式成立，using 敘述中的變數必須是實作`IDisposable`介面的參考型別，而且必須在其`Dispose()`方法中釋放資源、重設程式狀態。

C# 8 為這個模式帶來了一項改良。using 敘述可以放在區塊的開頭。

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java 開發者可能會認出，這相當於 Java 7 引入的_自動資源管理_機制。
