# 簡介

Factor 的錯誤系統由三個部分組成：`throw`用來拋出錯誤，`recover`用來處理錯誤，而`ERROR:`則用來定義你自己的錯誤類型。

## `throw`

`throw`（位於 [`kernel`][kernel] 中）會拋出錯誤。它的引數可以是*任何*值，例如字串、數字或元組，而這個值之後就會成為你可以檢查的錯誤：

```factor
! DOCTEST: SKIP
"file not found" throw
```

`throw`不會回傳；目前這個詞剩下的部分會被略過。

## `recover`

`recover`（位於 [`continuations`][continuations] 中）是 Factor 的 try/catch。它接受一個*try*引述和一個*recovery*引述：

```
recover ( try recovery -- )
```

如果`try`在沒有拋出錯誤的情況下結束，`recovery`就會被忽略。如果`try`拋出錯誤，錯誤會被推入堆疊，然後執行`recovery`：

```factor
[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"

[ "ok" ] [ drop "never runs" ] recover .
! => "ok"
```

`when`（位於 [`kernel`][kernel] 中）是它的自然搭檔：只有在堆疊頂端為真值時，它才會執行引述：

```factor
: check-positive ( n -- )
    0 < [ "negative!" throw ] when ;
```

## `ERROR:`

`ERROR:`會定義一個元組類別*以及*一個詞，這個詞會建立全新的實例並將它拋出：

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

沒有 slot 的錯誤只要寫成`ERROR: name ;`就行，呼叫`name`會拋出一個空實例。用`ERROR:`定義的元組帶有一個類別述詞`name?`，你可以用它來測試攔截到的錯誤是否屬於該型別。

## 讀回 slot

攔截到的錯誤就只是一個元組，因此每個由`ERROR:`定義的 slot，都和其他元組一樣帶有自動產生的`slot>>`讀取器。

```factor
! DOCTEST: SKIP
{
    T{ not-found { path "/a" } }
    T{ not-found { path "/b" } }
}
[ path>> ] map .   ! => { "/a" "/b" }
```
