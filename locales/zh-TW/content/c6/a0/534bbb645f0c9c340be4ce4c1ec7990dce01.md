# 說明

你任職的公司即將推出全新的智慧型手機，名叫**Smarty 5**，它具備全新的相機系統、全新的外型設計，以及一顆革命性的全新處理器，搭配一套名為**smartyOS**的全新作業系統。

這顆新處理器有能力處理比以往更安全的密碼，公司決定要好好善用這點。
他們請你為這支手機實作一套密碼鎖系統，讓使用者可以設定密碼，之後再檢查某個密碼是否正確。

~~~~exercism/caution
這個練習中實作的密碼系統並不安全，僅供教學用途。
它**不該**用於任何真實世界的應用程式。
~~~~

## 1. 設定密碼

這支手機允許使用者使用多種不同類型的密碼，從簡單的數字密碼，到更安全的英數字密碼，甚至還能使用儲存指紋的密碼。

這些不同類型的密碼各自使用不同的資料型態：數字密碼使用`Int32`，英數字密碼使用`String`，指紋密碼則使用`Float64`。

請實作`PasswordLock`類別，並加上一個初始化方法，它接受這三種密碼中的任一種作為引數，並將其存到名為`@password`的實例變數中。

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. 加密密碼

公司決定要將密碼加密，讓它不會以明文儲存，因此請你實作一個加密密碼的方法。

每種密碼類型都有自己獨特的加密方式：

- `Int32`密碼：將密碼除以二，並四捨五入到最接近的整數。
- `String`密碼：將密碼反轉。
- `Float64`密碼：將密碼乘以四。

請實作一個名為`encrypt`的實例方法，它不接受任何引數，並會修改`@password`實例變數，將它加密。

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. 檢查密碼是否正確

公司也請你實作一個方法，用來檢查某個密碼是否正確。

他們希望這個方法在密碼錯誤時回傳`nil`，在密碼正確時回傳`"Unlocked"`。

請實作一個名為`unlock?`的實例方法，接受要檢查的密碼作為引數。
密碼錯誤時，這個方法應回傳`nil`；密碼正確時則回傳`"Unlocked"`。

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
