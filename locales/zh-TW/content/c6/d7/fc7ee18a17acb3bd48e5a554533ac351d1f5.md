# 提示

## 1. 估算準備時間

- 使用向量的 [`size()`][size-func] 判斷層數（也就是 layers 切片的長度）。

## 2. 計算所需的麵條與醬料用量

- 首先，建立一個`amount`物件來追蹤麵條和醬料的用量。
- 使用 [`for` 迴圈][for-loop] 疊代每一層。
- 如果迴圈中遇到`"noodles"`或`"sauce"`層，就依此增加`amount`物件裡記錄的用量。

## 3. 加入祕密食材

- 回頭複習[向量][concept-vector]，了解如何從向量取出元素，以及如何取代向量中的元素。
- 向量`a`中最後一個元素的索引是`a.size() - 1`，或者你也可以直接用`a.back()`喔。

## 4. 調整食譜份量

- 先建立一個和輸入切片大小相同的新切片
- 使用 [`for` 迴圈][for-loop] 疊代輸入切片並產生輸出切片

## 5. 解鎖家族的祕密

- 你可以重複使用任務 3 寫的程式碼。
- 這個任務需要用到[函式多載][function overloading]。
