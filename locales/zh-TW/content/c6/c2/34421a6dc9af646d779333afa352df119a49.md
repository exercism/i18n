# 字串型別

Cairo 沒有原生的字串資料型態。
不過，有兩種方式可以表示字串型別：使用單一`felt252`的短字串，以及使用`ByteArray`的任意長度字串。

## 短字串

短字串以單引號構成，字串中的每個字元都會依照 [ASCII 標準][ascii-table] 編碼成一個位元組。

舉例來說，作為 ASCII 字串，`'abc'` 會是：

- `'a'` 等同於 `0x61`
- `'b'` 等同於 `0x62`
- `'c'` 等同於 `0x63`
- `'abc'` 等同於 `0x616263`

在 Cairo 中，短字串型別由 `felt252` 資料型態來存放。
由於 `felt252` 包含 251 個位元，短字串最多只能有 31 個字元（31 \* 8 = 248 位元，這是能塞進 251 位元中、8 的最大倍數）。

短字串宣告的範例：

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

ByteArray 結構是在 Cairo 2.4.0 中引入的。
ByteArray 字串以雙引號撰寫，如下所示：

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

技術上來說，這次更新也引入了 `bytes31` 型別，它可容納 31 個位元組，並且能塞進一個 felt 中。
`ByteArray` 結構基本上是用 `bytes31` 的陣列來表示長字串，這些 `bytes31` 存放「完整字詞」（也就是填滿整個 felt 的字詞），另外再用一個 felt 欄位存放「不完整的字詞」（其中的位元組數量另外記錄在長度欄位中）。

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```

[ascii-table]: https://www.asciitable.com/
