# 指令補充說明

## 實作說明

測試程式會透過反覆呼叫可變參數的`New`函式來建立樹。
例如，以下敘述

```go
tree := New("a",New("b"),New("c",New("d")))
```

會建構出以下的樹：

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

你可以假設測試用的樹不會有重複的值。

測試程式會使用`Value`和`Children`方法來拆解樹。

在開始這個練習有趣的部分之前，基本的樹建構與拆解必須先能運作，因此這部分會在前 3 個測試中分開測試。

---

`FromPov`和`PathTo`方法是這個練習有趣的部分。

`FromPov`方法接受一個字串引數`from`，它透過節點的值來指定樹中的某個節點。
它應該回傳一棵樹，其根節點的值為`from`。
你可以修改原始的樹並回傳它，或是建立一棵新的樹再回傳。
如果你回傳新的樹，你可以任意取用或銷毀原始的樹。
當然，能讓它保持不變是比較好的。

`PathTo`方法接受 2 個字串引數`from`和`to`，它們透過節點的值來指定樹中的 2 個節點。
它應該回傳樹中從第一個節點到第二個節點的最短路徑。
