# 簡介

在 JavaScript 中，*樣板字串*（英文：_template strings_）可以讓你在字串裡嵌入運算式，這種做法也稱為字串插值。
這項功能擴充了內建[`String`][string-reference]全域物件的功能。

在 JavaScript 裡，只要用反引號把文字包起來，就能建立樣板字串。
樣板字串除了能讓文字包含換行和其他特殊字元，還能嵌入變數和其他運算式。

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

在上面的例子中，反引號（<code>\`\`</code>）是用來表示樣板字串。`${...}` 是取代時使用的佔位符。
任何非字串的型別都會被*隱式*轉換成字串。
這個主題會在[型別轉換][type-conversion-concept]的概念裡介紹。
各種型別的運算式都可以用在樣板字串中。

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

當你需要把字串排成多行時：

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

有了這些取代功能，你還可以在過程中加入邏輯，來決定輸出的字串應該是什麼。

其中一個例子是嵌入[三元運算子][ternary-operator]。
這個運算子是撰寫 `if/else` 敘述的簡短形式。
語法是 `condition ? consequent-expression : alternative-expression`。
如果條件的值為 truthy，就會回傳冒號左側的運算元。
否則，三元運算式的結果就是冒號右側的運算元。

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
