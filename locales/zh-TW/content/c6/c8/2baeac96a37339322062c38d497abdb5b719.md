# 提示

## 1. 取得第一張卡片

- [這篇文章][mdn-destructuring]對陣列解構有不錯的概述。你可以在「Basic Array Destructuring」一節裡找到基本變數賦值的範例。

## 2. 取得第二張卡片

- 你可以使用佔位符來忽略陣列中的一個或多個值。
- 你可以在 [MDN][mdn-destructuring-ignore-value] 上找到範例。

## 3. 交換兩張卡片

- 可以在單一個解構運算式中交換兩個值。
- 你可以在 [MDN][mdn-destructuring-swapping] 上找到範例。

## 4. 移動三張卡片

- 可以在單一個解構運算式中改變三個值的位置。
- 這和交換兩個值一樣，只是變成三個（或更多）。

## 5. 挑選具名的牌堆

- 物件也可以像陣列一樣解構。
- 你可以在 [MDN][mdn-object-destructuring-basic-assignment] 上找到範例。

## 6. 交換具名的牌堆

- 從物件取出屬性時，可以使用特定的語法重新命名。
- 你可以在 [MDN][mdn-object-destructuring-object-rename] 上找到範例。
