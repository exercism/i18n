# 指令補充

## 例外訊息

有時我們需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做的時候，你應該一律附上**有意義的錯誤訊息**，指出錯誤的來源。這會讓你的程式碼更好讀，對除錯也有很大的幫助喔。如果你知道錯誤來源會是某種特定型別，可以選擇引發其中一種[內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

考拉茲猜想只關心**嚴格的正整數**，所以這個練習期望你在解法中使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，並在給定的值是零或負整數時「拋出」`ValueError`。只有當你同時`raise`這個`exception`並附上訊息時，測試才會通過。

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception` 型別的引數：

```python
# example when argument is zero or a negative integer
raise ValueError("Only positive integers are allowed")
```
