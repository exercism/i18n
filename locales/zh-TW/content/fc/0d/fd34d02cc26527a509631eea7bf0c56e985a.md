# 字元

**字元**是單一的字母、數字、空格或符號。Sather 用來表示字元的型別是 `CHAR`，字元寫在單引號之間。

```sather
   initial : CHAR is
      return 'M';
   end;
```

單引號代表單一字元，雙引號代表字串。`'M'`和`"M"`是不同的型別，不能互換。

## 從字串取出字元

字串是一排字元，用方括號可以依位置取出其中一個，位置從 0 開始算起，就和陣列一樣。

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## 判斷字元的性質

| 呼叫 | 回答 |
| --- | --- |
| `c.is_alpha` | 是字母嗎？ |
| `c.is_digit` | 是 `0`到`9`的其中一個嗎？ |
| `c.is_upper` | 是大寫字母嗎？ |
| `c.is_lower` | 是小寫字母嗎？ |

每個都會回傳`true`或`false`。

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## 轉換大小寫

`.upper`會取得字母的大寫，`.lower`則取得小寫。不是字母的字元會原樣回傳。

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## 字元與數字

每個字元都有對應的數字。`.int`會取得這個數字，`.char`則能把數字轉回字元。

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

確切的數字通常不太重要。重要的是字母`a`到`z`依序排列、彼此相鄰，所以 `'c'.int - 'a'.int` 是 2，也就是`c`在字母表中的位置差。這正是密碼轉盤能夠運作的原理。
