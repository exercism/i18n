# 簡介

在 Swift 中，`guard`敘述用於從函式提前回傳。當後續處理要繼續進行所需的必要條件沒有滿足時，就會用到它。例如：

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

在這裡，`guard`會檢查緊接在`guard`關鍵字後面的布林運算式是否評估為 true。如果是，處理就會繼續執行 guard 敘述後面的程式碼（這裡是`let root = myValue.squareRoot()`。否則，它會執行 else 子句中的程式碼。和`if`敘述不同，`guard`敘述_必須_要有 else 子句；而和 if-else 的 else 子句不同，guard 的 else 子句_必須_離開 guard 敘述的作用域。也就是說，它必須使用控制轉移敘述，例如`return`、`continue`、`break`，或是拋出錯誤或結束程式。
