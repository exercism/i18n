# 說明

舞蹈團表演的每一段舞碼，都以同一套暖身操為基礎，然後各自走出自己的風格。

程式碼骨架已經提供了 `WARM_UP`。請在它下面再寫三個類別。

## 1. 爵士舞碼

`JAZZ_ROUTINE` 原封不動地沿用 `WARM_UP` 的所有內容，沒有新增任何東西。

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. 踢踏舞碼

`TAP_ROUTINE` 沿用 `WARM_UP` 的 `counts`，但用自己的方式描述自己。請把 `describe` 排除在 include 之外，另外寫一個新的。

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. 壓軸

`FINALE` 以 `warm_up_counts` 這個名稱沿用 `WARM_UP` 的 `counts`，並把 `describe` 排除在外。接著它有自己的 `counts`，是暖身操的兩倍，還有自己的 `describe`。

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

注意這裡點出了什麼：`FINALE::counts` 並不是 `WARM_UP::counts`，而兩者在同一個類別裡以不同的名稱存在。
