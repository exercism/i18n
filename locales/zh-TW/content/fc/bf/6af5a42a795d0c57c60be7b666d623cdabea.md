# Char

`Char`是 Crystal 中的一種資料型態，代表一個 32 位元的 [Unicode][unicode] 碼位。
它的大小讓它在記憶體使用上很有效率，也賦予它一些字串沒有的特殊屬性。
建立時使用單引號（`'`），且裡面只能放一個 Unicode 碼位。

```crystal
'a' # => 'a'
'a'.class # => Char
```

在 Crystal 中處理字串時，經常會用到 Char，因為 String 類別中有不少方法會回傳 Char，或接受 Char 作為引數。
例如，[`String#[]`][index]方法會回傳一個 Char，而[`String#chars`][chars]方法則會回傳一組 Char 的集合。

## 遞增與遞減

由於 Char 是一個 32 位元的 Unicode 碼位，因此支援遞增與遞減。這表示如果你有`'a'`，只要加一就能得到`'b'`。

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

另外還有[`Char#succ`][succ]方法，會回傳 Unicode 表中下一個字元，以及[`Char#pred`][pred]方法，會回傳 Unicode 表中前一個字元。

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 串接

由於 Char 僅用來代表一個 32 位元的 Unicode 碼位，所以兩個 Char 無法串接在一起。
因此，Char 只能與字串串接。

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 屬性方法

Crystal 提供了一些方法來取得字元的相關資訊，例如它是不是數字或字母，或是它屬於大寫還是小寫。
以下是部分方法的清單，完整的清單請參閱 [Char API][char-api]：

| Method                           | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | 若 Char 是數字則回傳 `true`                          |
| [`Char#letter?`][letter]         | 若 Char 是字母則回傳 `true`                          |
| [`Char#lowercase?`][lowercase]   | 若 Char 是小寫則回傳 `true`                          |
| [`Char#uppercase?`][uppercase]   | 若 Char 是大寫則回傳 `true`                          |
| [`Char#ascii?`][ascii]           | 若 Char 是 ASCII 字元則回傳 `true`                   |
| [`Char#whitespace?`][whitespace] | 若 Char 是空白字元則回傳 `true`                      |

## 轉換

### 在碼位與 Char 之間轉換

由於 Char 代表一個 32 位元的 Unicode 碼位，因此可以在 Char 與碼位（Int）之間互相轉換。
這可以透過[`Char#ord`][ord]方法做到，它會回傳該 Char 的碼位；或是使用[`Int#chr`][chr]方法，它會回傳該碼位對應的 Char。

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 在不同型別之間轉換

與其他資料型態一樣，Char 也有一些可在不同型別之間轉換的方法。
最常用的是`Char#to_s`方法，會把 Char 轉成字串。不過，還有`Char#to_i`方法，會把 Char 轉成整數，以及`Char#to_f`方法，會把 Char 轉成浮點數。

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
