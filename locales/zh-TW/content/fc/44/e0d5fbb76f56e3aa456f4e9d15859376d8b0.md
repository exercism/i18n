# 關於

[Groovy](http://www.groovy-lang.org/) 是 Apache 基金會推出的功能強大、可選型別的動態語言，同時也具備靜態型別與靜態編譯的能力。

Groovy 的目標是透過簡潔、易學的語法來提升開發者的生產力。
它讓撰寫腳本、編寫領域特定語言、執行期與編譯期的超程式設計，以及函式程式設計都變得容易。

它可以存取完整的 Java 函式庫生態系，並能與 Java 應用程式完美整合。

它既能當作簡單的腳本語言使用，也能加入複雜的 Java 框架之中。
許多技術背後都是靠它驅動，例如：
* Gradle、
* Spock、
* Ratpack、
* Grails、
* 以及 Jenkins 中的腳本。

而且，它還很有趣喔。
