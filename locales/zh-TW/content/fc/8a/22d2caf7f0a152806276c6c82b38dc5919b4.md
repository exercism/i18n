# 說明

Red 內建了說明系統，可以在 Red 的主控台裡使用，每個內建函式都有文件記載。只要輸入`help`，再照著指示做就可以了。

Red 的[官方文件](https://github.com/red/docs/blob/master/en/SUMMARY.adoc)還在陸續編寫中，所以可能還需要搭配其他教材補充。

* [Red By Example](https://www.red-by-example.org/) 頁面介紹了許多函式。
* 另外，還有一份非常詳盡但非官方的 [Red Language Specification](https://github.com/meijeru/red.specs-public/blob/master/specs.adoc) 可以參考。
* 想快速尋求協助，最好的去處是 [Red's Gitter Help channel](https://gitter.im/red/help)，在那裡可以跟友善的社群一起聊聊。
