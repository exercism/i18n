# 簡介

## 基礎

### 函式

在 Gleam 中，函式是用`pub fn`語法定義的。

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

這個函式接受兩個引數，兩者的型別都是 `Int`，並回傳型別為 `Int` 的值。Gleam 中沒有 `return` 關鍵字，函式中最後一個運算式的值一律會_隱式回傳_。

引數的型別標註與回傳型別都是選用的，而 Gleam 一律會對你的程式碼進行完整的型別檢查。通常 Gleam 程式設計師為了清楚起見，會為函式加上型別標註，不過你想省略也沒問題。

```gleam
pub fn add(x, y) {
  x + y
}
```

可以用`function_name(argument1, argument2)`語法來呼叫函式。

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### 變數

在 Gleam 中，變數是用`let name = expression`語法定義的。

```gleam
pub fn main() {
  let count = 1
}
```

變數可以加上型別標註來宣告。就像函式引數一樣，這些標註是選用的，不過大多數 Gleam 程式設計師為了簡潔，會省略變數的型別標註。

```gleam
pub fn main() {
  let count: Int = 1
}
```

### 字串常值

在 Gleam 中，字串是用雙引號撰寫的。

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### 程式碼註解

註解可以用來留下筆記，給其他閱讀原始碼的開發者參考。Gleam 的註解是單行形式，前面會加上`//`。

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
