# 提示

**請記住**：這個練習的測試不在意是否會改動輸入，但函式名稱暗示這些函式應該不會改動輸入。
如果你想使用簡介中介紹的函式，同時又不改動輸入，`copy()`這個函式會很有幫助。

## 1. 依據向量建立庫存

- 開始之前，先看一下任務 2 可能會有幫助。

## 2. 將向量中的項目加入現有的字典

- 最簡單的做法是對輸入向量逐一迴圈處理每個項目。
- [`haskey(dict, key)`][haskey] 函式會很有用。

## 3. 減少庫存中的項目數量

- 這段程式碼和任務 2 相當類似，只是符號相反。
- 記得不要讓項目數量降到零以下喔。
- `if...else`邏輯可以做到，但 [`max()`][max] 函式能寫出簡潔又道地的程式碼。

## 4. 從庫存中完全移除一個項目

- Julia 正好有一個函式可以做這件事：請閱讀簡介。

## 5. 回傳庫存的全部內容

- 記得移除數量為零的項目。
- 初學者可能會覺得，對項目進行迴圈，並在合適時呼叫 [`push!()`][push]，是最簡單的做法。
- Python 風格的陣列推導式會簡潔得多，而且在最後加上 `if`子句也是允許的。
- 雖然需要用到後面概念的知識，但熟悉函式式程式設計的學生可能會想研究 [`filter()`][filter] 函式。
- 必須提供排序過的陣列，而 [`sort()`][sort] 預設會依配對的第一個元素來排序。
