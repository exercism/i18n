## 簡介

我們練習的解法差異大得驚人。
在大多數學習軌道中，最基礎的「正式」練習是 `TwoFer`。
典型的解法看起來像這樣（這是 Ruby，但大多數程式語言都很類似）：

```ruby
module TwoFer
  def self.two_fer(name='you')
    "One for #{name}, one for me."
  end
end
```

不過，在最近 500 個通過測試的解法中，有超過 350 個是獨一無二的 😲
而且即使你把空白和變數名稱這類東西標準化，還是會有超過一半是真正獨特的解法。

這讓「探索大家怎麼解題」變得超級有趣。
但這也完全不切實際。Exercism 上有數百萬個解法，要全部讀完，真的得花上一輩子的時間。

不過！我們的團隊設計了這些練習，也引導過數十萬人完成它們，所以很清楚大家會採用哪些不同的做法。
因此我們新增了 Dig Deeper 分頁，用來突顯一個練習各種慣用（或非慣用，但很有趣）的解法。

## 一個例子

我們來看一個例子，實際感受一下吧。
在 C# 裡，反轉一個字串有各種不同的做法。

你可以使用 `Array.Reverse()` 方法：
```csharp
var chars = input.ToCharArray();
Array.Reverse(chars);
return new string(chars);
```

或者用更簡短的 LINQ 做法：
```csharp
return new string(input.Reverse().ToArray());
```

或者使用 `StringBuilder`：
```
var chars = new StringBuilder();
for (var i = input.Length - 1; i >= 0; i--)
{
    chars.Append(input[i]);
}
return chars.ToString();
```

甚至用稍微不那麼慣用（但效能更好！）的 `Span<T>`：

```csharp
Span<char> chars = stackalloc[input.Length];
for (var i = 0; i < input.Length; i++)
{
    chars[input.Length - 1 - i] = input[i];
}
return new string(chars);
```

我們把每一種都稱為一個 Approach，每一種都有自己獨立的文章來解說。
這個練習的 Dig Deeper 頁面會把它們集結在一起，還附上一篇探討效能取捨的文章。
