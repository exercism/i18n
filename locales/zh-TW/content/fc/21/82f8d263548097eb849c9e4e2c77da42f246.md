# 說明

我們正在籌組一個起司俱樂部，將使用機器學習，根據顧客的歷史紀錄與口味，為熱愛起司的顧客挑選新的起司。

新成員必須填寫一份初始問卷，讓我們能先蒐集一些基本資料。
透過這份問卷，我們發現有一小群情感強烈的顧客，他們的評價缺乏細膩度。
由於這可能會無可挽回地讓更細緻的演算法產生偏差，因此我們另外設置了一套演算法來處理他們的需求。
請你提供一些輔助函式，來整理他們的資料。

~~~~exercism/note
雖然解決以下任務可能有不同的方法，但每個任務都能用不超過兩個高階函式來解決。
~~~~

## 1. 分類顧客

評分系統以五顆星為基準，也就是單純由整數`1:5`組成。
情感強烈的顧客只會給出`1`或`5`的評分，而我們想知道某位顧客是否表現出這種行為。

實作`all_15()`，它接收一個評分向量，若所有評分都是`1`或`5`就回傳`true`，否則回傳 false。

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. 為顧客命名

我們需要把顧客的姓名（或 ID）和他們的評分關聯起來。

實作`name_customers()`，它接收一個姓名向量和一個評分陣列，並將它們「配對」成一個陣列的陣列。

內層陣列元素的名稱應該要是`name`和`rating`。

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. 區分情感強烈的顧客

我們需要把情感較強烈的顧客和其他人區分開來。

實作`emphatics()`，它接收顧客與評分。
回傳一個陣列，只保留那些只用`1`或`5`星評分的顧客。

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. 把評分改成二進位

由於情感強烈的顧客只使用`1`和`5`的評分，若能將這些評分改成`0`和`1`，在運算上會更方便。

實作`to_binary()`，它接收一個情感強烈評分的向量。
回傳二進位評分，其中`1`已改成`0`，而`5`已改成`1`。

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. 計算一段時間以來的平均評分

隨著你越來越了解顧客的口味，你會想持續改善對所有個別顧客（不只是情感強烈的顧客）的推薦。

實作`satisfactions()`，它接收一個評分向量。
回傳一個到此為止的累積平均評分向量。
將結果四捨五入到小數點後 2 位。

希望這些數字能持續成長，讓顧客開心！

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
