# 說明

在這個練習中，你將管理一套庫存系統。

庫存應以物品名稱來組織，並記錄可用物品的數量。

你需要處理將物品加入庫存。
每當某個物品出現在指定的向量中，該物品在庫存中的數量就應該增加`1`。
當收到請求時，你還需要處理從庫存刪除物品，將數量減少`1`。

最後，你需要實作一個函式，將指定庫存中的所有鍵值對以`pair`的`vector`形式回傳。

~~~~exercism/note
這個練習的測試不在乎是否會修改內容，但函式名稱暗示這些函式應該不進行修改。
如果你想使用簡介中的函式，同時又不修改輸入，函式`copy()`會很有幫助。
~~~~

## 1. 根據向量建立庫存

實作`create_inventory(<input vector>)`函式，從輸入的物品向量建立一個「庫存」。
它應該回傳一個`dict`，內含每個物品名稱及其對應的數量。

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. 將向量中的物品加入現有字典

實作`add_items(<inventory dict>, <item vector>)`函式，將物品向量加入傳入的庫存：

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. 從庫存中遞減物品

實作`decrement_items(<inventory dict>, <items vector>)`函式，它接收一個物品的`vector`。
每當某個物品在`vector`中出現一次，你的函式就應該將該物品的數量減去`1`：

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

庫存中的物品數量不應低於 0。
如果某個物品在輸入`vector`中出現的次數超過可用數量，該物品所列出的數量應維持在 0。
一旦數量降到 0，之後額外的移除請求都應忽略。

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. 從庫存中完全移除某個項目

實作`remove_item(<inventory dict>, <item>)`函式，將某個物品及其數量從庫存中完全移除：

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

如果在庫存中找不到該物品，函式應回傳未經變更的原始庫存。

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. 回傳庫存的全部內容

實作`list_inventory(<inventory dict>)`函式，它接收一個庫存，並回傳由`(item, quantity)`配對組成的向量。

這個向量應只包含_可用_的物品（_數量高於 0_），並依物品名稱的字母順序排序：

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
