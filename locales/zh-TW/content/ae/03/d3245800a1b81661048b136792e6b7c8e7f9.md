Haxe 中的[布林][booleans]由 `Bool` 型別表示，它的值可以是 `true` 或 `false`。

Haxe 支援三種[布林運算子][operators]：`!`（一元 NOT）、`&&`（二元 AND）與 `||`（二元 OR）

複合布林運算式（`&&` 與 `||`）採用*短路*求值：運算式由左至右求值，但只求到必要的地方為止。這在下列這類情況下格外重要：

```haxe
object != null && object.field == x
```

第一個布林檢查確保只有在 `object` 不是 `null` 時才會存取 `object.field`，避免發生執行階段錯誤。

這三個布林運算子的[優先順序][precedence]不同，求值順序為：`!` -> `&&` -> `||`。

把運算式用括號 `()` 包起來，就能覆寫這些優先順序規則，因為括號的優先順序更高。

```haxe
!true && false   // => false
!(true && false) // => true
```
