# 簡介

在 Haxe 中，疊代器用來透過`for`迴圈疊代某個值。疊代器分成兩種：

- `Iterator`，用來疊代某個值。
- `Iterable`資料，讓你能疊代某種資料型態。

這兩個概念分別由`Iterator<T>`和`Iterable<T>`表示：

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

任何能與上述其中一種型別統一的類別，都可以用`for`迴圈來疊代。如果一個類別定義了`hasNext`和`next`方法，它就會被視為疊代器；否則，如果它定義了`iterator`方法，就會被視為可疊代的型別。
