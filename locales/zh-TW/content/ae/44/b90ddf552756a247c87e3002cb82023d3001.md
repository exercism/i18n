# 清單

`ARRAY`是固定的。它在建立時就決定好大小，之後也維持不變：不能對它附加元素，也不能從中移除元素。

偵探的筆記本就不是這樣。線索一次只出現一條，一旦被排除就會被劃掉。這種情況你需要的是**清單**。

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes.append("broken window");
   notes.size                   -- 2
```

`LIST{T}`會依序存放型別為`T`的值，就像陣列一樣，並能依你的要求增長或縮減。

## 就地改變

`append`會改變被呼叫的那個清單，而且不回傳任何東西：

```sather
   notes.append("muddy boots");        -- yes
   notes := notes.append("muddy boots");   -- no: append answers nothing
```

這和`FMAP`與`FSET`不同，在那裡每個變更都必須指定回去。`LIST`是一般的物件，就像`SCOREBOARD`一樣：把它交給一個常式，那個常式就能改變你的清單。

## 讀取與寫入

方括號，從 0 開始計數，就和陣列完全一樣：

```sather
   notes[0]                     -- "muddy boots"
   notes[1] := "smashed window";
   notes.size                   -- how many
   notes.is_empty               -- true when there are none
```

## 移除

`remove_index`會移除某個位置，它後面的所有元素都會往前移一位：

```sather
   notes.remove_index(0);       -- the first clue is struck out
```

所以位置並不是永久的。當較前面的線索被移除時，某條線索的位置就會改變，所以在儲存位置之前，這點值得記住。

## 走訪清單

`elt!`可以用，就和在陣列上一樣：

```sather
   loop
      #OUT + notes.elt! + "\n";
   end;
```

## 大括號

`LIST{STR}`是字串的清單，`LIST{INT}`是數字的清單。它是一個泛型類別，就和你在`lost-property`中寫的那一個一樣。而現在，你也可以用同樣的方式讀懂程式庫自己的泛型類別。
