# 簡介

C++ 的條件式和其他語言的條件式很類似。
任何條件運算的底層型別都是`bool`型別，它的值可以是`true`或`false`。
條件式經常被用來做為流程控制機制，檢查各種不同的條件。

`if`敘述可以在底層條件為`true`時執行它的程式碼，像這樣：

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

當情況不只一種時，可以用`else if`和`else`敘述把多個`if`敘述串接起來。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

從 C++17 起，`if`敘述也可以包含一段簡短的初始化敘述，用來為這個`if`敘述初始化一個或多個變數。
例如：

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：在初始化中建立的變數，在`if`敘述結束之後就無法存取。
