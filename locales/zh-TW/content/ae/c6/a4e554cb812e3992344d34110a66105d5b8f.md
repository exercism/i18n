# 迴圈入門

Bash 有兩種迴圈形式：

* _針對一串項目中的每個項目_重複執行某些指令，
* _在某個條件為真（或假）時_重複執行某些指令。

## `for`迴圈

若要疊代一串項目，我們會使用`for`迴圈。

```bash
for varname in words; do COMMANDS; done
```

`words`會經過單字分割與檔名展開（我們在[引號概念][quoting]中學過這兩個概念）。
每個單字會依序被指定給`varname`，然後執行 COMMANDS。

以下是一些例子，說明`for`迴圈在什麼情況下很有用：

* 對一群檔案執行一些指令。

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* 對指令稿或函式的每個參數執行一些指令。

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* 對某個指令輸出中每個以空白分隔的單字執行一些指令。

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    我們之後會看到一些關於這種寫法的警告。

### 算術`for`迴圈

Bash 確實有算術迴圈。
這對學過其他程式語言的人來說會有點眼熟。

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

在 Bash 中，雙小括號代表算術環境（我們會在之後的概念中看到更多 Bash 算術的內容）。
上面使用`seq`的例子可以改寫成這樣：

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### 何時不該使用`for`

[別用`for`逐行讀取][bashfaq1]。

這是個你常會看到的反模式：疊代`cat`的輸出。

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

這麼做有兩個錯誤。

1. 指令替換沒有加上引號，因此會受到單字分割影響。
   單字分割預設會依_空白_分割，而不只是換行。
   這個`for`迴圈疊代的是檔案中的**單字**，而不是行。
2. 指令替換沒有加上引號，因此會受到檔名展開影響。
   檔案中的每個單字都會被當作 glob 模式來比對。

如同我們在[引號概念][quoting]中學到的，可以用`IFS`變數控制單字分割，也可以關閉檔名展開。
但這往往是個脆弱的解法。
`for`不是疊代檔案各行內容的正確方法。
讀取檔案的慣用做法是使用`while`迴圈。

## `while`迴圈

使用`while`重複執行一連串指令，_只要_某個條件為真。

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

如同`if`（我們在[條件式概念][conditionals]中學過，CONDITION_COMMANDS 並沒有特殊語法。
指令清單的結束狀態會決定「真」或「假」。

## 控制迴圈

`break`指令會跳出迴圈。
控制權會從迴圈的`done`結束符號之後的指令繼續執行。

`continue`指令會跳到迴圈的下一次疊代。

## 讀取檔案中的行

如前所述，`while`迴圈是讀取檔案的慣用做法。

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* 檔案內容會透過`<`重導向作為迴圈的輸入。
* `read`指令若能從輸入讀取完整的一行，就會回傳「真」。
  當輸入被讀取完畢，或者最後一行結尾沒有換行時，read 會回傳「假」。
  * 要讀取檔案中的行，即使最後一行結尾沒有換行也能處理，_真正_慣用的做法是

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* `-r`選項告訴`read`不要替換反斜線序列：反斜線就只是一般的字元。
* `IFS=`只在`read`指令執行期間，把空字串指定給 IFS。
  這會暫時關閉單字分割，讓讀入的那一行文字中開頭或結尾的空白都能保留下來。

## Until

`until`建構會在某個條件為**假**時重複執行一連串指令。
迴圈會重複執行，_直到_條件變成真。

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

很少會用到`until`。
更常見的是使用「while not」迴圈。

```bash
while ! CONDITION_COMANDS; do ...
```

## 無限迴圈

有時候你會想讓迴圈一直執行下去。
這裡有兩種做法：

1. 條件永遠為成功結束狀態的`while`迴圈

    ```bash
    while true; do ...
    ```

2. 表示式為空的算術`for`迴圈

    ```bash
    for ((;;)); do ...
    ```

## Do-While

沒有明確的 do-while 建構，但你可以達到同樣的效果：

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
