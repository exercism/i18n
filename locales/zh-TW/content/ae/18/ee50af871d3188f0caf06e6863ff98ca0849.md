# 簡介

## 布林值

`bool`型別（boolean 的縮寫）只有兩個值：`true`和`false`。
`true`和`false`這兩個字面值在程式碼中不分大小寫。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

布林值經常在邏輯運算式中作為運算子的結果，然後用在控制結構裡。

### 邏輯運算子

邏輯運算子有以下幾種：

- `!$a`：如果`$a`不是`true`，就回傳`true`
- `$a && $b`：如果`$a`和`$b`都是`true`，就回傳`true`
- `$a || $b`：如果`$a`或`$b`其中一個是`true`，就回傳`true`

~~~~exercism/caution
另外還有`and`和`or`運算子，它們分別和`&&`、`||`互補。
它們的行為和`&&`、`||`不同，可能會產生非預期的結果，因此不建議使用。
~~~~
