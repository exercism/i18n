# 關於

[V](https://vlang.io/) 是一門用來打造可維護程式的簡單語言。它的語法類似 Go，效能卻和 C 一樣快。

V 目前仍在 beta 開發階段，但已經非常強大。

V 內建許多安全機制，無論你怎麼使用它，都能讓程式碼順利執行：邊界檢查、沒有未定義的值、變數預設為不可變、Option/Result 型別與強制錯誤檢查，以及沒有 null。

V 以 V 自己寫成，能在不到一秒內完成自我編譯，也能零成本呼叫 C 程式碼。它同時內建格式化、程式碼效能分析、測試與文件產生功能。

官方網站是 [vlang.io](https://vlang.io/)，所有文件都在[這份 markdown 檔案](https://github.com/vlang/v/blob/master/doc/docs.md)裡。
