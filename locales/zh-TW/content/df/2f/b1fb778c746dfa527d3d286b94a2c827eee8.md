# 指令

你是個熱愛賞鳥的人，會記錄過去七天內有多少鳥造訪你的花園。

你有六項任務，全都和造訪你花園的鳥的數量有關。

## 1. 查看上週的數量

為了方便比較，你總是會把上週的數量副本放在手邊，分別是：0、2、5、3、7、8 和 4。實作`BirdWatcher.getLastWeek()`方法，回傳上週的數量：

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 查看今天有多少鳥造訪

實作`BirdWatcher.getToday()`方法，回傳今天有多少鳥造訪你的花園。鳥的數量是依日期排序的，第一個元素是最早那天的數量，最後一個元素則是今天的數量。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. 增加今天的數量

實作`BirdWatcher.incrementTodaysCount()`方法，將今天的數量加一：

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. 查看是否有哪一天沒有鳥造訪

實作`BirdWatcher.hasDayWithoutBirds()`方法，如果有某一天沒有任何鳥造訪花園，就回傳`true`；否則回傳`false`：

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. 計算前幾天造訪的鳥的數量

實作`BirdWatcher.getCountForFirstDays()`方法，回傳從這週開始以來造訪你花園的鳥的數量，但將計算範圍限制在從這週開頭算起的指定天數內。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. 計算忙碌的天數

有些日子比其他日子更忙碌。所謂忙碌的一天，是指有五隻或更多鳥造訪你的花園。
實作`BirdWatcher.getBusyDays()`方法，回傳忙碌的天數：

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
