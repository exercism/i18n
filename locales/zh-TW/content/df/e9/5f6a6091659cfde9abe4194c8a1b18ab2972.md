# 簡介

字元和字串是 Elm 中文字表示的基礎。
字串可以想成是字元的陣列，`List`模組中大多數的函式在`String`模組裡都有對應的版本。

## 字元

`Char`型別代表以單引號表示的單一 Unicode 字元，例如`'a'`。
`Char`模組提供了述詞函式（`Char -> Bool`），用來測試字元的各種性質：`isUpper`、`isLower`、`isAlpha`和`isAlphaNum`。
這個模組也提供轉換字元的函式：`toUpper`、`toLower`、`toLocaleUpper`、`toLocaleLower`，以及透過`toCode`和`fromCode`在字元與其數值 Unicode 值（`Int`）之間互相轉換。

## 字串

`String`型別提供了內建的表示方式，能有效率地處理字串，並可表示任何 Unicode 字元序列。
字串以雙引號表示：`"this is a string"`。
多行字串以三個雙引號表示，其中可以包含未跳脫的引號和換行。

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## 字串操作

`reverse : String -> String`會反轉字串。
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String`會把字串重複 n 次。
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String`會取代所有出現的指定子字串。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String`會串接兩個字串。
也可以使用`++`運算子來達成。
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String`會把字串的陣列串接成單一字串。
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String`會在指定的分隔符號處把字串拆成字串的陣列。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`會用指定的分隔符號把字串的陣列串接起來。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String`會以空白區塊為單位，把字串拆成多個字串。
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String`會依換行把字串拆成一行一行。
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String`會在字串開頭加上一個字元。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )`會把非空字串拆成頭部和尾部。
這讓你比照陣列的方式對字串做模式比對。
空字串會回傳`Nothing`。
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## 取得子字串

`slice : Int -> Int -> String -> String`會依給定的起始和結束索引取出子字串。
負數索引會從尾端開始倒數。
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String`和`right : Int -> String -> String`會分別從字串的左側或右側取出 n 個字元。

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String`和`dropRight : Int -> String -> String`會分別從字串的左側或右側丟掉 n 個字元。
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## 檢查字串性質

`length : String -> Int`會回傳字串中的字元數。
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool`會判斷字串是否為空。
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool`會檢查第二個字串是否包含第一個字串。
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool`和`endsWith : String -> String -> Bool`會檢查第二個字串是否以指定的子字串開頭或結尾。
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int`會取得某個子字串在另一個字串中所有起始索引的陣列。
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## 轉換字串
`toInt : String -> Maybe Int`會嘗試把字串轉換成`Just Int`，格式不正確的字串則回傳`Nothing`。
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String`會把整數轉換成字串。
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float`會嘗試把字串轉換成浮點數，格式不正確的字串則會失敗。
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String`會把浮點數轉換成字串。
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char`和`fromList : List Char -> String`會分別把字串轉換成字元的陣列，以及把字元的陣列轉換回字串。
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String`會把字元轉換成字串。
```elm
fromChar 'a' 
    --> "a"
```

## 格式化字串

`toUpper : String -> String`和`toLower : String -> String`會分別把字串轉成全大寫或全小寫。
這在需要忽略大小寫的比較時很好用。
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String`會用提供的`Char`在字串兩側補齊，直到達到指定的長度。
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
同樣地，`padLeft`和`padRight`會從字串的其中一側補齊，直到達到指定的長度。

`trim : String -> String`會移除字串兩側的空白。
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft`和`trimRight`會移除字串其中一側的空白。

## 高階函式

`map : (Char -> Char) -> String -> String`會用給定的函式轉換字串中的每個字元。
注意，提供的函式必須是從`Char`對應到`Char`的轉換。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String`只會保留通過測試的字元。
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b`會從左側開始縮減字串。
套用這個函式時，第一個參數是第一個字元，第二個參數是提供的初始值。
函式的結果型別必須和提供的初始值相同，並依序套用到每個字元上。
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr`的做法相同，但從字串的右側開始。

`any : (Char -> Bool) -> String -> Bool`會判斷是否有任何字元對提供的述詞回傳`True`。
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool`會判斷字串中是否所有字元都對提供的述詞回傳`True`。
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
