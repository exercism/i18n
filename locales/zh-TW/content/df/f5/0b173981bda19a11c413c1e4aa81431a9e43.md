# 簡介

## 數字

Python 內建了三種不同的數字型態：`ints`、`floats` 和 `complex`。不過，這個練習只會用到 `ints` 和 `floats`。

### ints

`ints` 是整數，例如 `1234`、`-10`、`20201278`。

Python 的整數具有[任意精度][arbitrary-precision]，位數只受限於主機系統的可用記憶體。

### floats

`floats` 是含有小數點的數字，例如 `0.0`、`3.14`、`-9.01`。

浮點數在 Python 中通常是用 C 的 `double` 實作（_精確度為 15 位小數_），但實際的表示方式會依主機系統和其他實作細節而有所不同。在處理浮點數時，這可能會帶來一些意想不到的結果，不過對大多數情況來說已經「夠好了」。

## 算術

Python 完整支援 `ints` 和 `floats` 之間的算術運算。與二元算術運算子（`+`、`-`、`*`、`/`、`//` 和 `%`）搭配使用時，Python 會把較窄的數字轉換成較寬一方的型態。

Python 認為 `ints` 比 `floats` 窄，所以在運算式中使用浮點數，結果也一定是浮點數。不過進行除法時，即使只用整數，結果也一定是浮點數。

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

如果需要整數結果，可以用 `//` 截去小數部分。

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

要把浮點數轉成整數，可以使用 `int()`；要把整數轉成浮點數，可以使用 `float()`。

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
