# 關於

Common Lisp 的 Printer 是將資料輸出到串流的機制。這套機制中一個常用的函式是`format`。

`format`接受兩個必填參數：要寫入的串流，以及一個控制字串。控制字串的內容會決定後面其他的引數要怎麼使用。

第一個參數有兩個特殊值：`t`和`nil`。`t`表示應該使用綁定到`*standard-output*`的串流，`nil`則表示應該建立一個字串並回傳它。除非串流參數是`nil`，否則`format`的求值結果是`nil`。

控制字串可以包含格式指令，格式指令由`~`加上一個字元組成（字元的大小寫不重要）。格式指令會決定是否消耗引數，以及引數要如何格式化到串流上。

幾個重要的基本格式指令如下：

* `~A` - 以*美觀*、適合「人類閱讀」的方式格式化。
* `~S` - 以*標準*形式格式化，讓結果「機器可讀」。
* `~%` - 輸出一個換行。
* `~&` - 若不在行首，就輸出一個換行。
* `~~` - 輸出一個波浪號。

範例：

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
