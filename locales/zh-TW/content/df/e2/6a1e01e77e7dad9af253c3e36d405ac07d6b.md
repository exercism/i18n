# 關於

[結構體與類別][structs-and-classes]是在 Swift 中建立自訂型別的主要基本元件。
兩者都讓你能把相關的屬性（資料）與方法（行為）組織成可重複使用的單位。
Swift 中大多數的核心型別，包括`Int`、`Double`、`String`，以及`Array`和`Dictionary`這類集合型別，都是以結構體實作的。

各型別的詳細說明請參閱：

- [concept:swift/structs]()
- [concept:swift/classes]()

## 如何在結構體與類別之間做選擇

結構體和類別都能讓你定義自訂型別，但兩者在記憶體中的傳遞方式有根本上的差異：

- **結構體是值型別**：當你指定或傳遞結構體時，Swift 會為它的資料建立一份獨立的副本。
對其中一份副本所做的修改，不會影響到其他副本。
- **類別是參考型別**：當你指定或傳遞類別實例時，Swift 共用的是現有實例的參考。
透過其中一個參考所做的修改，會立即影響所有指向同一個實例的其他參考。

Swift 重視安全性與可預測的行為，因此對大多數自訂型別來說，結構體是預設的建議做法。
使用值型別能確保在程式的某個部分修改資料時，不會在其他地方產生非預期的副作用。

一般來說：

- **使用結構體**來建立模型，當資料代表的是獨立的值時（例如座標、形狀、幾何尺寸或格式化後的紀錄）。
- **使用類別**來建立模型，當實體具有各自獨特的身分或共用的生命週期需求時（例如 UI 控制項、資料庫連線或檔案控制代碼）。
