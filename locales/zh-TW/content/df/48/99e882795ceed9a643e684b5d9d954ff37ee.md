# 提示

## 1. 檢查是否能發動快速攻擊

我們需要檢查騎士是否清醒，並且把代表其狀態的布林值_反轉_。這可以用 [`not`][not] 函式來完成。

## 2. 檢查是否能偵查這群人

我們希望只要傳入的任一個述詞為 `true`，函式就回傳 `true`。這可以用 [`or`][or] 函式來做到。

## 3. 檢查是否能向囚犯打暗號

我們希望只有在傳入的所有述詞都是 `true` 時，才回傳 `true`。這可以用 [`and`][and] 函式來完成。

## 4. 檢查是否能救出囚犯

我們需要結合三個基本的邏輯運算子：[`and`][and]、[`or`][or] 和 [`not`][not]。

[not]: https://clojuredocs.org/clojure.core/not
[or]: https://clojuredocs.org/clojure.core/or
[and]: https://clojuredocs.org/clojure.core/and
