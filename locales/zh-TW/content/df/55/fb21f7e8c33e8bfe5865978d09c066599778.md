# 關於

組合子把堆疊重排的模式變成具名、可組合的詞。寫了足夠多的 Factor 之後，你就不再想著「我需要先`dup`，再執行 F，最後保留原本的值」，而是直接寫`[ F ] keep`。

| 模式 | 堆疊重排 | 組合子 |
|------|----------|--------|
| 套用 F，保留輸入 | `dup F swap` | `[ F ] keep` |
| 一個輸入套用兩個函式 | `dup F swap G` | `[ F ] [ G ] bi` |
| 一個輸入套用三個函式 | 很複雜 | `[ F ] [ G ] [ H ] tri` |
| 一個輸入套用多個函式 | 非常複雜 | `{ Fs … } cleave` |
| 對堆疊頂端*下方*的值進行操作 | `swap F swap` | `[ F ] dip` |
| 對兩個值做相同的運算 | `swap F swap F` | `[ F ] bi@` |
| 對兩個值做不同的運算 | `swap F swap G` | `[ F ] [ G ] bi*` |

以`2`開頭的系列（`2bi`、`2dip`、`2tri`、`2dup`、`2drop`、`2nip`、`2swap`）會在每個運算需要*兩個*輸入時做同樣的事；`3dup`和`4dup`則把複製的慣用手法延伸到堆疊頂端的三個或四個值。

除了 cleave/dip/bi 系列之外，[`kernel`][kernel]也提供了能乾淨地傳遞 `f` 的控制流程變體：

| 詞 | 效果 |
|----|------|
| `if*` | 真分支看得到該值；假分支看不到 |
| `?last` | 序列的最後一個元素，若為空則為 `f` |
| `pop*` | `pop` 的丟棄變體（會修改向量） |
| `dupd` | 複製堆疊中*倒數第二*的值 |
| `pick` | 把*倒數第三*的值複製到頂端 |
| `swapd` | 交換堆疊中倒數第二與倒數第三的值 |
| `rotd` | 旋轉四層堆疊中最底下的三個值 |
| `tuck` | 把頂端的值複製到倒數第二之下 |
| `with` | 把固定值內嵌到 quotation 中，供 HOS 使用 |
| `while` | 在述詞成立時持續迴圈 |
| `until` | 持續迴圈直到述詞成立 |

挑選合適的組合子本身就是一門功夫。一般原則是：當一個定義的主體裡連續出現多個堆疊重排詞時，通常就有某個組合子能更貼切地表達意圖。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
