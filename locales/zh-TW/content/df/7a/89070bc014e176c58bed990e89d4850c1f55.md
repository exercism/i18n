# 說明

你是一位老師。
到了學年末，你已經為每位學生產生了一個數字成績。
現在你需要把它換算成等第成績，並統計每個等第各有幾位學生達到。

## 1. 將數字成績換算成等第成績

`letter_grade`函式會接收數字成績作為輸入，並輸出對應的等第。
請使用以下範圍：

| 等第 |      成績 |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

範例：

```jq
75 | letter_grade   # => "C"
```

## 2. 統計每個等第的學生人數

`count_letter_grades`函式會接收一個物件，將學生姓名對應到他們的成績。
輸出會是一個物件，將每個等第對應到該等第的學生人數。

範例：

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

這題有幾種不同的解法。
請使用`reduce`篩選器來練習。
