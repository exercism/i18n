# 簡介

幾乎每個 Factor 程式都是一連串的詞，在*資料堆疊*上消耗並產生值。當輸入和輸出恰好對齊時，程式碼讀起來從左到右，乾淨俐落。當它們對不上時，你就得動用*重排詞*，程式碼很快變得雜亂。

這個練習會帶你認識 Factor 的標準解法：組合子。

## 重排詞

最常見的重排詞位於 [`kernel`][kernel]：

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

你應該已經用過`dup`和`swap`了。`over`會複製從頂端數來的*第二個*元素，當同一筆輸入需要同時餵給兩個運算時很方便：

```factor
! Sum a number with twice itself: x + 2*x
: triple ( x -- 3x ) dup 2 * + ;
```

只用一次還沒問題。但串在一起時，一連串的`dup`、`swap`、`over`、`rot`很快就變得難以閱讀。

## `keep`：保留輸入

`keep`（位於 [`kernel`][kernel]）會對堆疊頂端的值呼叫一個 quotation，但把原始值留在結果上方：

```
keep ( x quot: ( x -- y ) -- y x )
```

```factor
5 [ 2 * ] keep .s
! => 10
! => 5
```

這樣就取代了「先`dup`，接著做點什麼，再重排」的模式：任何你會寫`dup something swap`的地方，都可以直接改成`[ something ] keep`。

## `bi`：一個輸入套用兩個函式

`bi`（位於 [`kernel`][kernel]）會把*兩個* quotation 套用到同一個值，並把兩個結果都留在堆疊上：

```
bi ( x q1 q2 -- r1 r2 )
```

```factor
4 [ sq ] [ neg ] bi .s
! => 16
! => -4
```

沒有`bi`的話，你得寫`dup sq swap neg`，兩個運算還算好讀，三個就頭痛了。

## `tri` 和 `cleave`：一個輸入套用多個函式

`tri`把`bi`擴充成三個 quotation：

```
tri ( x q1 q2 q3 -- r1 r2 r3 )
```

`cleave`（位於 [`combinators`][combinators]）則把同樣的概念用在任意數量 quotation 的*陣列*上：

```factor
4 { [ ] [ sq ] [ neg ] } cleave .s
! => 4
! => 16
! => -4
```

空的 quotation `[ ]`扮演恆等的角色，當切牌中的某個位置應該就是輸入本身時，這很實用。

## `dip` 和 `2dip`：在底下運算

`dip`（位於 [`kernel`][kernel]）會對堆疊頂端*底下*的值呼叫 quotation，並保持頂端不變。`2dip`做法相同，但會保護頂端的*兩個*值：

```
dip  ( x   quot -- x   )
2dip ( x y quot -- x y )
```

```factor
9 10 11 [ + ] dip .s
! => 19      (9 + 10)
! => 11      (the protected top, restored)

9 10 11 12 [ + ] 2dip .s
! => 19      (9 + 10)
! => 11      (the protected y, originally 11)
! => 12      (the protected x, originally 12)
```

這裡`dip`把`11`藏起來，執行`9 10 +`，再把`11`放回頂端。`2dip`則把`11 12`藏起來，在底下執行`9 10 +`，然後還原`11 12`。

當自然的引數順序會把「直通」的值留在堆疊頂端時，`dip`就是正確的工具。用它來取代`swap … swap`這種夾心寫法。

## `bi@`：對兩個值做相同運算

`bi@`（位於 [`kernel`][kernel]）會把一個 quotation 套用到兩個堆疊值：

```
bi@ ( x y quot -- r1 r2 )
```

```factor
3 4 [ sq ] bi@ .s
! => 9
! => 16
```

## `bi*`：對兩個值做不同運算

`bi*`（位於 [`kernel`][kernel]）會把*不同*的 quotation 套用到兩個堆疊值：第一個 quotation 套用到下面那個值，第二個套用到頂端：

```
bi* ( x y q1 q2 -- r1 r2 )
```

```factor
3 4 [ sq ] [ neg ] bi* .s
! => 9
! => -4
```

兩個值要用相同處理方式時就用`bi@`，各自需要不同處理時就用`bi*`。

## `tri*`：對三個值做不同運算

`tri*`（位於 [`combinators`][combinators]）把`bi*`擴充到三個值和三個 quotation，並依序把每個 quotation 套用到一個值：

```
tri* ( x y z q1 q2 q3 -- r1 r2 r3 )
```

```factor
1 2 3 [ sq ] [ neg ] [ 10 * ] tri* .s
! => 1
! => -2
! => 30
```
