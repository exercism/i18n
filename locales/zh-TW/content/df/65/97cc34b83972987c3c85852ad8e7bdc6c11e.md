# 指令補充

## WebAssembly 專屬注意事項

WebAssembly 匯出函式 `convert` 的函式簽章如下：

```wasm
(func (export "convert")
    (param $arrOffset i32)
    (param $arrLength i32)
    (param $inputBase i32)
    (param $outputBase i32)
    (result i32 i32 i32)
)
```

前兩個參數 `$arrOffset` 和 `$arrLength` 分別表示一個 32 位元有號整數陣列的起始位移與長度。長度參數的單位是陣列元素的個數，而非位元組。在呼叫這個函式之前，呼叫端會把這個陣列寫入從位移 `$arrOffset` 開始的 WebAssembly 線性記憶體。WebAssembly 線性記憶體一律以小端序表示。

因此，呼叫端會把陣列 `[1,2]` 編碼成以下這八個位元組的序列。

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| ---- arr[0] ----- | ---- arr[1] ----- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```

參數 `$inputBase` 和 `$outputBase` 與線性記憶體無關。

結果型別是 `(i32 i32 i32)`。前兩個值是你的輸出在線性記憶體中的 `offset` 與 `length`。如果你想這麼做，也可以覆寫用於輸入的線性記憶體位址。第三個回傳值是用於錯誤處理的 i32 狀態碼。

如果第三個回傳值表示錯誤狀態，單元測試就不會讀取前兩個回傳值。
