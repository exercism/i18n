# 準備上線

在你準備好要上線自己的 track 之前，請確認下列工作都已完成。

## 申請 track 圖示

為了替網站設計圖示，請在 [exercism/website-icons](https://github.com/exercism/website-icons/issues) 儲存庫中開一個新的 issue，回答下列問題：

- 這個語言有官方標誌嗎？如果有：
  - 請附上一個範例的連結
  - 請列出姓名標示要求，以及使用該標誌所授予的權利
- 這個語言有非官方標誌嗎？如果有：
  - 請說明大家使用這個非官方標誌的方式
  - 請附上一個範例的連結
  - 請列出該標誌的姓名標示要求

## 新增 track 文件

請新增下列 track 文件：

- `docs/ABOUT.md`：這個語言的簡短介紹。
- `docs/INSTALLATION.md`：說明學生需要安裝什麼，才能在自己的本機系統上透過 CLI 進行這個 track。
- `docs/LEARNING.md`：學習資源的連結。
- `docs/RESOURCES.md`：實用資源的連結。
- `docs/TESTS.md`：說明所有與在 track 中執行測試相關的事項。

這些文件能幫助學生開始使用這個 track，也能讓他們認識這個 track 與它的語言。
更多資訊請參閱[文件說明](/docs/building/tracks/docs)。

## 新增練習文件

請新增下列練習文件：

- `exercises/shared/.docs/help.md`：包含這個 track 專屬的取得協助說明
- `exercises/shared/.docs/tests.md`：包含這個 track 專屬的執行測試說明

## 新增程式碼片段

請在`docs/SNIPPET.txt`檔案中新增一段程式碼片段。
這段片段能讓人一眼看出這個語言的語法長什麼樣子。
更多資訊請參閱[文件說明](/docs/building/tracks/docs)。

## 更新中繼資料

track 的中繼資料定義在 [config.json 檔案](/docs/building/tracks/config-json)中。
下列屬性應該更新：

- `language`：這個 track 的語言（例如`"C#"`）。長度必須 <= 255
- `slug`：這個 track 的語言，以小寫的 kebab-case 字串表示（例如`"csharp"`）。長度必須 <= 255
- `blurb`：這個語言的簡短描述。長度必須 <= 400
- `online_editor`：描述線上編輯器所用設定的物件：
  - `indent_style`：可以是`"space"`或`"tab"`
  - `indent_size`：縮排大小，為整數（例如`4`）
  - `highlightjs_language`：Highlight.js 的語言識別碼（請參閱[完整的識別碼清單](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)）。如果 Highlight.js 不支援這個語言，可以省略這個欄位。
- `key_features`：這個語言的主要特色，簡潔描述它最重要的特點。更多資訊請參閱[主要特色說明](/docs/building/tracks/config-json#h-key-features)。
- `tags`：定義這個 track 適用的標籤，讓它能在網站上被搜尋到。更多資訊與支援的標籤清單，請參閱[標籤說明](/docs/building/tracks/config-json#h-tags)。
