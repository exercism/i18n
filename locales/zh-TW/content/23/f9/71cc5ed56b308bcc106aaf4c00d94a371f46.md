# 指令

你有個朋友開了一間老字號的批發店，叫做 **Gross Store**。
這個名字來自店裡商品販售的數量單位：它們全都是以[籮][gross-unit]計算。
你的朋友請你幫他的店做一套銷售時點情報系統（POS）。
**首先，你想先為它打造一個雛型。**
**在你的雛型中，系統只會記錄數量。**
你的朋友給了你一份單位對照表，方便你使用：

| 單位               | 數值 |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 在程式中儲存測量單位

為了使用這些測量單位，你需要先在程式中把它們存起來。

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. 建立新的顧客帳單

你需要實作一個函式，為顧客建立一張新的（空白）帳單。

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. 在顧客帳單中加入商品

要做到這點，你需要：

- 如果傳入的`unit`不在`units` map 中，回傳`false`。
- 否則將商品加入顧客的`bill`，以商品名稱為索引，然後回傳`true`。
- 如果該商品已經在帳單中，就依照傳入的`unit`所對應的數量增加它的數量。

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> 請注意，回傳值的型別是`bool`。

## 4. 從顧客帳單中移除商品

要做到這點，你需要：

- 如果帳單中**沒有**這項商品，回傳`false`。
- 如果傳入的`unit`不在`units` map 中，回傳`false`。
- 如果新的數量會小於 0，回傳`false`。
- 如果新的數量是 0，就從`bill`中完全移除這項商品，然後回傳`true`。
- 否則，減少這項商品的數量並回傳`true`。

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> 請注意，回傳值的型別是`bool`。

## 5. 回傳顧客帳單中特定商品的數量

要做到這點，你需要：

- 如果`item`不在帳單中，回傳`0`和`false`。
- 否則，回傳帳單中該商品的數量和`true`。

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> 請注意，回傳值的型別是`int`和`bool`。

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
