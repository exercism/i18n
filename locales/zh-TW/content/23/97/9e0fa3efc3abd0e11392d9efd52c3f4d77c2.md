# 說明

身為一位初露頭角的魔術師，Elyse 需要用各種不同的方式分析她的牌堆。為了簡單起見，她只使用數值 1 到 10 的牌。

## 1. 判斷牌堆裡有幾張特定類型的牌

Elyse 想知道她的牌堆裡有幾張特定類型的牌。

撰寫一個函式 `cardTypeCheck`，它接受兩個參數：一個牌的陣列（Elyse 的牌堆），以及要計算的牌的類型。

<!--prettier-ignore -->
~~~exercism/note
這個函式應該使用 `forEach`，並回傳牌堆中指定類型的牌的數量。
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. 判斷有幾張奇數或偶數的牌

為了另一個把戲，Elyse 需要知道她的牌堆裡有幾張奇數或偶數的牌。

實作一個函式 `determineOddEvenCards`，它接受兩個參數：一個牌的陣列（Elyse 的牌堆），以及一個布林值（true 等同於「偶數」，false 等同於「奇數」）。

這個函式應該回傳一個數字：牌堆裡奇數或偶數牌的數量（取決於第二個引數的值）。

<!--prettier-ignore -->
~~~exercism/note
為了練習，這次在函式實作裡使用 `for...of` 迴圈。
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
