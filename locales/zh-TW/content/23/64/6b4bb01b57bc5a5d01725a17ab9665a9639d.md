# 關於

[C# `Attribute`][attribute-concept] 提供了一種裝飾宣告的方式，讓你可以把中繼資料關聯到類別、方法、列舉、欄位、屬性，或任何[其他支援的][attribute-targets]宣告。

你可以在宣告前面用方括號 `[]` 把[一個 attribute][attribute] 包起來，即可將它套用到該宣告上。下面的範例同時用到了 `ClassAttribute` 和 `FieldAttribute`：

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

這種宣告式的中繼資料只是把額外的結構化資訊關聯到程式碼上，並不會改變它的行為；不過程式碼的其他部分會利用這些中繼資料，來改變目標的行為，或是新增、變更、移除、限制目標的某些功能。

現成的預先定義 attribute 有很多，例如：`Flags`、`Obsolete`、`Conditional`。請注意，[`Flags` attribute][flags-attribute] 的完整名稱是 `FlagsAttribute`，但使用時可以省略「Attribute」後綴。

以下是四個經常使用的預先定義 attribute：

- `[Flags]`：預先定義於 System 命名空間。表示這個列舉同時支援位元運算和`Enum.HasFlag()`方法，此外`ToString`也會顯示所有的旗標：[參見範例][flags-example]。
- `[Obsolete]`：預先定義於 System 命名空間。可以加上說明程式碼為何過時的訊息，也能用來顯示編譯器警告或錯誤。
- `[Conditional]`：預先定義於 System.Diagnostics 命名空間。可以基於除錯（診斷）的目的，在編譯時期移除某些方法呼叫。
- `[CallerMemberName]`：預先定義於 System.Runtime.CompilerServices 命名空間。可以讓方法取得呼叫端的相關資訊。
