`jq`是一套用來解析與轉換 JSON 資料的工具。
`jq`就像處理 JSON 資料的`sed`。你可以用它來切割、過濾、映射與轉換結構化資料，就像`sed`、`awk`、`grep`等工具讓你輕鬆操作文字一樣。

`jq`是一種動態型別的函式程式語言。
所有的值都是不可變的。

`jq`程式是由一連串的「過濾器」管線組成：每個過濾器接收單一項目作為輸入，對它作用，然後輸出零個或多個轉換後的元素。
「過濾器」也可以稱為「運算式」。

一個運算式的輸出可以用`|`運算子傳遞給另一個運算式。
`expressionA | expressionB`會先將`expressionA`套用到某個輸入，然後針對`expressionA`的每個輸出重複執行`expressionB`。

運算式的輸入可以用`.`明確表示。
一個把輸入加上`1`的運算式寫起來像這樣：`. + 1`（或`1 + .`）。

## `jq`（程式）與`jq`（語言）的差異

`jq`是一套程式，你可以在各種作業系統上以套件形式安裝，也可以從原始碼自行建置（它是用 C 寫成的）。
它提供了幾個實用的[命令列選項][cli-options]，而且速度相當快。

`jq`程式也實作了一門_語言_，讓你能對輸入資料進行任意複雜的操作。

這個 Exercism 學習軌道會聚焦在這門語言上。
你會在測試中看到`jq`程式的使用方式。

## JSON

摘自 [json.org][json]：

> JSON（JavaScript Object Notation）是一種輕量級的資料交換格式。
> 它易於人類閱讀與撰寫。
> 它易於機器解析與產生。
> 它的基礎是 JavaScript 程式語言標準 ECMA-262 第三版（1999 年 12 月）的一個子集。
> JSON 是一種完全獨立於語言的文字格式，但使用了 C 語言家族的程式設計師所熟悉的慣例，包括 C、C++、C#、Java、JavaScript、Perl、Python 等。
> 這些特性讓 JSON 成為理想的資料交換語言。

這個學習軌道談的是`jq`，不是 JSON。
我們假設你已經熟悉 [JSON 的語法與資料型態][wiki-json]。
