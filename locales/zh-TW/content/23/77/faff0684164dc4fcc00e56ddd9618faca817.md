# 簡介

## 預設參數值

你可以為函式的任何參數提供[預設參數值][default-parameter-values]，做法是在參數列表中，於該參數的型別註記之後指定一個值。指定了預設參數值之後，函式的呼叫者在呼叫函式時可以省略該參數，此時會改用預設值。

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## 可變參數

Swift 中的[_可變參數_][variadic-parameters]允許把零個或多個同型別的值，傳入函式中的單一參數。只要在參數的型別註記後面加上 `...` 就能表示。

這些值會自動組成一個陣列，其元素的型別與可變參數的型別相同。

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

請注意，使用可變參數時，Swift 有一項限制。如果函式定義中還有參數排在可變參數之後，那麼緊接在可變參數後面的第一個參數_必須_有引數標籤。

## 輸入輸出參數

在函式主體中，參數會被視為常數而非變數；若試圖修改參數的值，會引發編譯期錯誤。如果函式想要修改某個參數的值，就必須使用[_輸入輸出參數_][in-out-parameters]，明確表達這樣的可變性。

使用輸入輸出參數時，程式設計者必須確認三件事：

1. 函式定義必須明確標示輸入輸出參數，做法是在參數的型別註記中，把關鍵字 `inout` 寫在 `:` 和型別名稱之間。
2. 傳入輸入輸出參數的值必須宣告為變數，而不是常數。同樣地，它也不能是字面值。
3. 在呼叫函式時，變數名稱前面必須加上 `&`，明確標示它可被修改。

完成這些步驟後，函式會為輸入輸出參數建立內部副本，依函式主體中的指示修改它，然後在函式回傳時，把修改後的值複製回當初傳入的變數。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
關於輸入輸出參數，還有幾項額外的規則需要注意。

1. 在含有輸入輸出參數的函式內，你不能參照當初作為輸入輸出參數傳入的那個變數。
2. 同一個變數不能在同一個函式中作為多個輸入輸出參數傳入。
   例如，`inoutFunc(&mutVar, &mutVar)` 會引發編譯器錯誤。
~~~~

## 巢狀函式

在 Swift 中，你可以[在其他函式裡定義函式][nested-functions]。這類函式稱為**巢狀函式**。

巢狀函式常被用來當作私有的小幫手，為外層函式執行特定工作，而不會弄亂外層的作用域：

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

巢狀函式的行為和一般函式相同，但它的可見範圍僅限於外層函式的主體。
