# 唯讀類別與屬性

唯讀類別和屬性讓類別能宣告公開屬性以便取用，同時防止修改。若要將某個屬性宣告為唯讀，必須在型別規格前面加上`readonly`。屬性只允許被賦值一次，之後任何重新賦值或修改值的嘗試都會導致錯誤。

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

唯讀類別以此行為為基礎：只要宣告為`readonly`，就會把唯讀宣告套用到每一個屬性上。此外，它也會防止新增動態屬性。

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
