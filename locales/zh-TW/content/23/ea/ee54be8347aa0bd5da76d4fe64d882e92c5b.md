# 簡介

[陣列][arrays-concept]有內建方法可以分析陣列的內容。
這些方法大多會接受一個回傳 true 或 false 的函式作為引數。
這樣的函式稱為[`predicate`][predicate_in_programming]。

這些內建方法是要用來_取代`for`迴圈_或內建的`forEach`方法：

使用 for 迴圈進行分析的範例：

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

使用內建方法進行分析的範例：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

以下列出一些其他可用來分析陣列的實用內建方法。完整的陣列方法清單請參閱 [MDN][mdn-array-methods]。

## `includes`

> includes() 方法會判斷陣列中的項目是否包含某個特定的值，並視情況回傳 true 或 false。[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> every() 方法會測試陣列中的所有元素是否都通過由所提供函式實作的測試。它會回傳布林值。[^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> some() 方法會測試陣列中是否至少有一個元素通過由所提供函式實作的測試。[^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> find() 方法會回傳所提供陣列中第一個滿足所提供測試函式的元素值。如果沒有值滿足該測試函式，則會回傳 undefined。[^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> findIndex() 方法會回傳陣列中第一個滿足所提供測試函式的元素索引。否則，它會回傳 -1，表示沒有元素通過測試。[^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
