# 提示

## 1. 建立衣物單品

- 有些函式可以搭配推導式語法來建構。
- `Dict`正是這樣的函式，請複習簡介中的**生成器表達式**。
- 索引`i`的分類會對應到索引`i`的品質（[eachindex()][index] 可能很有用）。

## 2. 建議組合

- 有一種簡潔的語法可以從推導式建立多維陣列。
- 複習簡介中的**多變數、多維輸出**。
- 請確認疊代器的順序（`tops` / `bottoms`）是正確的。

## 3. 加總穿搭價格

- 你需要取得兩件衣物的價格，並將它們相加。
- 請確認輸出陣列的形狀與輸入陣列的形狀相同。
- 複習簡介中的**單一變數**。

## 4. 篩除衝突的穿搭

- 你需要比較兩件衣物的`base_color`，並捨棄`base_color`相同的穿搭。
- 當輸入是`Matrix`時，請確認輸出採用最有效率的順序（也就是直行優先）。
- 複習簡介中的**單一變數**。

[index]: https://docs.julialang.org/en/v1/base/arrays/#Base.eachindex
