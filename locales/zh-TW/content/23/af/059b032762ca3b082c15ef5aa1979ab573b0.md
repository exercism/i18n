# 簡介

繼承是 OOP（物件導向程式設計）中的核心概念。它代表一種 IS-A 關係。它在程式設計裡的意義就跟在英文裡一樣，指的是從父類別繼承各種特性（在程式設計中，這些特性通常就是函式與變數）。

先來看看`Animal`這個類別：

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`是父類別，因為這個類別具備的特性可以延伸到所有動物。

假設有一隻動物叫做`Lion`，牠的類別如下：

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override`標註用來表示子類別中的某個方法覆寫了父類別的方法。
它不是絕對必要，但使用它是個好習慣。
~~~~

現在，只要我們這樣寫：

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

注意：這裡是用`Lion`來初始化`Animal`類別。
輸出結果如下：

```java
Lion here!!
```

根據 OOP，繼承有很多種類型，但 Java 只支援其中一部分（多層繼承與階層式繼承）。
想進一步了解，請閱讀[這篇說明][java-inheritance]。
