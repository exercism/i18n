# 簡介

## 布林

Gleam 用`Bool`型別來表示 true 和 false。這個型別只有兩個值：`True`和`False`。這些值可以綁定到變數上：

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`和`!`運算子可以用來操作布林值：

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`和`||`運算子採用短路求值，這代表運算子右側的運算式只會在需要時才求值。

每個運算子的優先順序都不同，其中`!`會比`&&`和`||`先求值。你也可以用大括號讓運算式的某一部分先求值，再處理其他部分：

```gleam
!True && False   // -> False
!{True && False} // -> True
```
