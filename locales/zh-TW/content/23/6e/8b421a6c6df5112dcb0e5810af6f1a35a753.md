# 關於

[`Rational numbers`][rational]是由整數分子除以整數分母所組成的分數。

例如，我們可以將`2//3`儲存為精確的分數，而不是近似的`Float64`值`0.6666...`

優點是（除了[整數溢位][integer-overflow]這種極端情況之外），有理數會保持精確，避免浮點數經常難以避免的捨入誤差。

更多細節請參閱 Julia 的[手冊頁面][julia-rational]。

有理數是相當簡單的數值型別，運作方式大致符合你的預期。
由於它們從早期版本開始就是 Julia 的標準型別，大多數函式會像對待整數和浮點數一樣，接受它們作為輸入。

## 建立有理數

建立方式就和在兩個整數之間使用`//`一樣簡單。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

公因數會自動約除，將分數轉換成[「最簡分數」][lowest-terms]：能精確表示該分數的最小整數，且分母為非負數。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

無限大的結果可以接受，但不能是[`NaN`][NaN]。

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## 有理數的算術運算

常見的[`arithmetic operators`][operators]`+ - * / ^ %`可用於有理數，基本上與其他數值型別相同。

整數和其他`Rational`可以加入運算，並得到`Rational`結果。
在運算式中加入`float`會得到`float`輸出，因此可能損失精度。

如果需要`float`，只要使用`float()`函式將有理數轉換即可。
在長時間的計算中使用有理數來保持精度，最後再轉換成浮點數，是很常見的做法。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

有理數和[複數][complex]也可以合併運算。
複數會在[另一個概念][complex-concept]中討論。

## 其他運算

在 Julia 中，有理數就只是數字。
編譯器通常會視需要轉換型別。

不過請注意，比較只適用於具有有限小數表示的分數：

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

但在其他情況下，`Rational`應該轉型成`Float`再進行比較：

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

數學函式接受有理數作為輸入，但可能產生浮點數結果：

```julia-repl
julia> sqrt(9//16)
0.75
```
