# 資料庫付款稽核

## 問題陳述

ABC Corp 需要你將 SQL 資料庫中的所有資料載入 [Ballerina 表格](https://ballerina.io/learn/by-example/table-syntax/)，以便後續處理。接著，你需要查詢載入後的 Ballerina 表格，找出付款金額大於指定金額（例如 3000.00）的員工姓名。

**步驟 1：**

建立一個包含下列欄位的 Ballerina 表格。

`payment_id` - 整數

`amount` - 浮點數

`employee_name` - 字串

**步驟 2：**

將 H2 資料庫中對應的完整資料集載入，以填充上述的 Ballerina 表格。使用 `payment_id` 作為該表格的主鍵。

**步驟 3**

使用 Ballerina 查詢運算式查詢 Ballerina 表格，找出付款金額大於指定金額的員工姓名。將結果依員工姓名遞增排序。回傳前，請先移除結果中重複的姓名。

> 注意：實作解法時必須使用 Ballerina 表格。

## 資料庫詳細資料

本題請使用提供的 H2 資料庫。

> 範例資料庫檔案是 `gofigure.mv.db`，資料庫名稱是 `gofigure`。它位於`db`資料夾中。

範例 H2 資料庫中已經有以下資料表，並附帶一些範例資料。欄位名稱與資料型態如下。

**資料表名稱**：`Employee`

| **欄位：**      | 型態 |
| -----------       | ----------- |
| `employee_id`     | 整數，自動遞增主鍵       |
| `name`            | 字串        |
| `city`            | 字串        |
| `department`      | 字串        |
| `age`             | 整數        |

**資料表名稱**：`Payment`

| **欄位：**      | 型態 |
| -----------       | ----------- |
| `payment_id`      | 整數，自動遞增主鍵       |
| `date`            | 日期        |
| `amount`          | 浮點數        |
| `employee_id`     | 整數        |
| `reason`          | 字串        |

* 資料庫檔案是 `gofigure.mv.db`。JDBC URL 請使用 `jdbc:h2:file:/path/to/db/file`。
* 使用者名稱：`root`
* 密碼：`root`

## 限制條件

* 使用`db`資料夾中提供的 H2 資料庫檔案來驗證查詢以及 Ballerina 範例
* 使用 maven dependency params 這種方式，將 H2 資料庫驅動程式新增為 Ballerina.toml 中的平台相依性

## 測試環境

* 你可以用`bal test`執行測試，它會針對提供的範例資料庫執行測試。

**輸入：** dbFilePath：`“/Path/to/file/gofigure”`，amount：`3000`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模組來操作資料庫
* 請參閱 [先決條件](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 一節，了解將 JDBC 驅動程式新增為相依性的步驟
* 使用 [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) 遠端方法從資料庫查詢資料
* 請參閱 [簡單查詢](https://ballerina.io/learn/by-example/mysql-query-operation) 範例
* 請參閱 [表格語法](https://ballerina.io/learn/by-example/table) 範例
* 使用 [查詢表格](https://ballerina.io/learn/by-example/querying-tables) 從 Ballerina 表格找出所需的資料
