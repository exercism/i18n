# 測試

## 命令列

你可以使用以下指令從命令列執行測試：

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

把`<exercise>`替換成你正在實作的練習名稱。

## 互動模式

要以互動方式執行 prolog，請先執行：

```bash
swipl
```

prolog 主控台啟動後，載入你的實作，然後用以下指令執行測試：

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

把`<exercise>`替換成你正在實作的練習名稱。

### 重新載入變更

載入上述檔案後，只要執行以下指令，就能套用你做過的任何變更：

```
?- make.
```

## 略過的測試

剛開始一個練習時，只會執行第一個測試。其餘的測試都透過在`test`目標中加入`condition(pending)`而略過。第一個測試通過後，把`condition(pending)`裡的`pending`改成`true`，就能取消略過下一個測試。對每個測試重複這個步驟，直到全部都能執行並通過為止。

### 命令列

在指令最後加上`-- --all`引數，就能一併執行所有待處理的測試：

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
