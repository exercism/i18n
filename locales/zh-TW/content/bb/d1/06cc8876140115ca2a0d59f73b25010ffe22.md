# 指令

在這項練習中，你將撰寫一些程式碼，幫助你依照最愛的食譜做出一份美味的千層麵。

這項練習有四個任務，全都和烹調千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義`Lasagna::EXPECTED_MINUTES_IN_OVEN`常數，它會回傳千層麵應該在烤箱裡烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```ruby
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`Lasagna#remaining_minutes_in_oven`方法，它接受千層麵實際已待在烤箱中的分鐘數作為參數，並根據前一個任務中預期的烤箱時間，回傳千層麵還需要待在烤箱裡幾分鐘。

```ruby
lasagna = Lasagna.new
lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. 計算準備時間（分鐘）

定義`Lasagna#preparation_time_in_minutes`方法，它接受你加進千層麵的層數作為參數，並回傳你準備千層麵花了幾分鐘，假設每一層需要花你 2 分鐘準備。

```ruby
lasagna = Lasagna.new
lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. 計算總共花費的時間（分鐘）

定義`Lasagna#total_time_in_minutes`方法，它接受兩個具名參數：`number_of_layers`參數是你加進千層麵的層數，而`actual_minutes_in_oven`參數是千層麵待在烤箱中的分鐘數。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間（分鐘）與千層麵當下已待在烤箱中的分鐘數之和。

```ruby
lasagna = Lasagna.new
lasagna.total_time_in_minutes(number_of_layers: 3, actual_minutes_in_oven: 20)
# => 26
```
