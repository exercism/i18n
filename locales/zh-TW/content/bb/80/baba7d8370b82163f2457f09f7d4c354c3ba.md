# 介紹

## 字元

Java 的`char`基本型別是以 16 位元表示單一字元。
多個`char`可以組成一個字串，例如`"word"`，而`char`也可以各自獨立處理。
`char`字面值前後會加上單引號（例如`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

## 取得`String`的`char`

`String.toCharArray`方法會把`String`的`char`以陣列的形式回傳。
如陣列一章所述，你可以用`for`迴圈來疊代這個陣列。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Character 類別

內建的函式庫有許多方法可以檢查和操作`char`。
這些都是`java.lang.Character`類別的靜態方法。
以下是一些例子：

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## 將`char`加到`String`

`+`運算子可以用來把`char`加到`String`上。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
小心_不要_用`+`把兩個`char`串接成一個`String`！
這樣把兩個`char`相加會得到一個`int`，_不是_一個`String`！
例如：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

這是因為 Java 會把`char`提升成`int`（請參閱 [Java Language Specification][jls-main] 的 [4.2 基本型別與值][jls-primitives]）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

不過，如果要相加的字元很多，改用`StringBuilder`會更有效率：

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
