# 指示

你的設計團隊正把部分的版面配置工作，從 CSS transform 轉移到 Factor。為了讓團隊其他成員滿意，你會建立一些小型、可重複使用的轉換，把它們寫成 quotation，這些 quotation 接收一個 2D 點並回傳一個 2D 點。

一個點就是由兩個元素組成的陣列`{ x y }`。

## 1. 平移座標

定義`translate-2d`，讓它從堆疊取出兩個值`dx`和`dy`，並回傳一個能將點平移`(dx, dy)`的 quotation。

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. 縮放座標

用同樣的方式定義`scale-2d`，回傳一個能將點按`(sx, sy)`縮放的 quotation。

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. 組合兩個轉換

定義`compose-transformations`，讓它接收兩個轉換 quotation `f`和`g`，並回傳一個單一 quotation，先套用`f`，再套用`g`。

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. 套用轉換

定義`apply-transformation`，讓它從堆疊取出一個點和一個轉換 quotation，並回傳轉換後的點。

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. 一次轉換多個點

定義`transform-points`，讓它接收一個由點組成的陣列和一個轉換 quotation，並回傳轉換後的點所組成的陣列。

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
