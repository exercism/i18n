# 指令

撰寫一個函式，將一般的數字轉換成羅馬數字。

羅馬人是一群聰明的傢伙。
他們征服了歐洲大部分地區，並統治了數百年。
他們發明了混凝土、筆直的道路，甚至還有比基尼。
不過，有一件事他們從未發現，那就是數字零。
這讓撰寫與標註他們豐功偉業的詳細歷史變得稍微困難了些，但他們想出的數字系統至今仍在使用。
舉例來說，BBC 至今仍用羅馬數字來標註他們節目的年份。

羅馬人用字母來書寫數字，分別是 I、V、X、L、C、D、M。
（注意這些字母有很多直線，因此很容易刻進石板裡）。

```text
 1  => I
10  => X
 7  => VII
```

這套記法能表示的最大數字是 3,999。
（羅馬人自己通常也不會用到更大的數字）

維基百科說：現代的羅馬數字……寫法是從最左邊的位數開始，將每個位數分開表示，並跳過任何值為零的位數。

想看看實際的例子，可以參考 1990。

用羅馬數字表示，1990 是 MCMXC：

1000=M
900=CM
90=XC

2008 寫成 MMVIII：

2000=MM
8=VIII

想了解更多，請參閱[維基百科上的羅馬數字][roman-numerals]。
