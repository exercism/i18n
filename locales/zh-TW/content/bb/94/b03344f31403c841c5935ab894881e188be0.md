# 關於


現在該來認識 C++ 的核心範式之一：物件導向程式設計（OOP）。
OOP 的核心是`classes`，也就是帶有自己一組相關函式的使用者自訂資料型態。
我們會從基礎開始，之後在課程大綱較後面的部分會談到更進階的主題。

## 成員

類別可以有**成員變數**和**成員函式**。
我們透過**成員選取**運算子`.`來存取它們。
就像`classes`外面的變數一樣，成員變數最好在宣告時就給它一個初始值。
這個值會成為從這個類別建立的新物件之預設值。

## 封裝與資訊隱藏

類別可以限制成員的存取權限。
最基本的兩種情況是`private`和`public`。
`private`成員無法從類別外部存取。
`public`成員則可以自由呼叫。
所有成員預設都是`private`，必須明確標記，才能在類別外部使用。

## 基本範例

以下範例是一個新`class`的定義。
請注意定義結尾的`;`。

```cpp
class Wizzard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

你可以從類別內部存取所有變數。
看看`cast_spell`函式裡的`damage`吧。
不過在類別外部，你無法讀取或修改`private`成員：

```cpp
Wizzard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## 建構函式

建構函式可以在建立物件時把值指定給成員變數。
它和`class`同名，而且沒有回傳型別。
一個類別可以有好幾個建構函式。
如果你不一定需要設定所有變數，這就很方便。

```cpp
class Wizzard {
  public:
    Wizzard(std::string new_name) {
      name = new_name;
    }
    Wizzard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizzard el{"Eleven"};       // deals  5 damage
Wizzard vecna{"Vecna", 50}; // deals 50 damage
```

建構函式是個大主題，有許多細節。
如果你沒有為你的`class`明確定義`constructor`，那麼（也只有在那時）編譯器才會幫你完成這件事。
上面第一個範例就是這種情況。
_silverhand_ 物件是透過呼叫預設建構函式建立的，沒有傳入任何引數。
所有變數都會被設成類別定義中所指定的值。
如果你在定義中沒有給任何值，這些變數可能沒有被初始化，可能導致意想不到的後果。

## 結構

結構源自這門語言最初的 C 根源，和 C++ 本身一樣古老。
它們實質上和`classes`是同一回事，只有一個重要的例外。
預設情況下，`class`裡的所有東西都是`private`。
相對地，結構則是`public`，除非另外定義。
依照慣例，`struct`關鍵字通常用於**只存放資料的結構**。
需要確保某些性質的物件，則偏好使用`class`關鍵字。
這樣的不變量可能是：你的`Wizzard` `class`的`damage`不能變成負數。
`damage`變數是私有的，任何會改變 damage 的函式都會確保這個不變量得以維持。
