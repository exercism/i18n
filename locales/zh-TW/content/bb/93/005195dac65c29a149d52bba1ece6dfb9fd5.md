# 帶有狀態的類別

到目前為止，每個類別都只是一箱常式。每個常式接收引數、算出答案，然後就把一切忘光。

類別其實可以反過來**記住**東西。計分板就必須如此：現在的分數取決於比賽開始以來的每一次得分。

## 屬性

`attr`讓類別有東西可以記住。

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

每個`attr`會變成兩個常式：一個讀取值，一個修改值：

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

同一型別的屬性可以共用一個宣告，就像引數一樣：

```sather
   attr home_score, away_score : INT;
```

## 物件

帶有屬性的類別，是製作**物件**的藍圖。每個物件都有自己的一份屬性，所以兩個計分板會各自保留自己的分數。

`new`會製作一個物件。它會放在名為`create`的常式裡，由這個常式把物件填好再交回來：

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME`的意思是「這個類別」。在那裡寫`SCOREBOARD`意思也一樣，但如果類別改名了，`SAME`還是能繼續運作。

## 建立物件

`#`會呼叫`create`：

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

從`rehearsal-script`開始，你就一直在用`#`，而`#FSTR`正是同樣的做法。

## 會改變物件的常式

在類別內部，屬性直接用名稱取用，前面不必加物件。它指的是這個常式被呼叫時所屬的物件。

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal`沒有宣告回傳型別，因為它不回傳任何東西，而是改變物件。把它當作敘述來呼叫：

```sather
   board.home_goal;
```

## 屬性一開始是空的

沒有設定過的屬性，`INT`會是 0，`BOOL`會是`false`，字串或物件則是 void。所以新的計分板會顯示 0 比 0，完全不需要特別指定。
