# 提示

## 一般

- 手邊有一份 PHP 的[算術運算][arithmetic-operations]清單，可能會很有幫助。

## 1. 麵團比例

- 你可以用加法和乘法的基本算術運算子來解這個任務。

## 2. 加點醬料

- 要確保罐數是整數，你需要無條件進位。
- PHP 提供了[數值函式][numeric-functions]，可以幫上忙。

## 3. 來點起司吧

- 你可以用[指數運算子][arithmetic-operations]來計算數字的立方。
- 要確保披薩數量是整數，你需要無條件捨去。
- PHP 提供了[數值函式][numeric-functions]，可以幫上忙。
- PHP 有[內建常數][pi-constant]可以用來表示圓周率（π）。

## 4. 公平分配

- 用[取餘數運算子][arithmetic-operations]（`%`）來取得除法後的餘數。

[arithmetic-operations]: https://www.php.net/manual/en/language.operators.arithmetic.php
[pi-constant]: https://www.php.net/manual/en/function.pi.php
[numeric-functions]: https://www.php.net/manual/en/ref.math.php
