# 關於

常見的數學函式都放在 [`math.functions`][math.functions] 裡，常數放在 [`math.constants`][math.constants]，另外還有幾個只能處理浮點數的詞放在 [`math.libm`][math.libm]。每個詞都從堆疊上取得輸入：

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .            ! => 3.0
1.0 1.0 fatan2 .    ! => 0.7853981633974483
```

## 常數

| 詞 | 值 |
| --- | --- |
| `pi` | π，3.14159… |
| `e` | *e*，2.71828… |

## 根與次方

| 詞 | 堆疊效果 | 結果 |
| --- | --- | --- |
| `sqrt` | `( x -- y )` | `x`的平方根 |
| `sq` | `( x -- y )` | `x * x` |
| `^` | `( x y -- z )` | `x`的`y`次方，`y`不一定要是整數 |

## 三角函式

| 詞 | 堆疊效果 | 結果 |
| --- | --- | --- |
| `sin` `cos` `tan` | `( x -- y )` | 對弧度制角度`x`求正弦、餘弦或正切 |
| `asin` `acos` `atan` | `( x -- y )` | 正弦、餘弦或正切值為`x`的那個角度，以弧度表示 |
| `fatan2` | `( y x -- z )` | 從`x`軸正方向到點（`x`，`y`）的角度，以弧度表示 |
| `deg>rad` | `( x -- y )` | 把度換算成弧度 |
| `rad>deg` | `( x -- y )` | 把弧度換算成度 |

所有角度都以**弧度**表示：轉一整圈是 2π，不是 360。在程式的邊界處換算，中間的計算一律用弧度。

要找出方向時，`fatan2`（來自 `math.libm`）比 `atan` 好用。`1 1 / atan` 分不出 (1, 1) 和 (−1, −1)，因為兩者相除都得到`1`；而且`x`為零時它就失效了。`fatan2`會同時看兩個數的正負號，回答範圍從 −π 到 π：

```factor
1 1 / atan rad>deg .          ! => 45.0
-1 -1 / atan rad>deg .        ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
```

## 指數與對數

| 詞 | 堆疊效果 | 結果 |
| --- | --- | --- |
| `e^` | `( x -- y )` | *e*的`x`次方 |
| `log` | `( x -- y )` | 自然對數：要得到`x`，*e*必須乘上的次方 |
| `10^` | `( x -- y )` | 10 的`x`次方 |
| `log10` | `( x -- y )` | 以 10 為底的對數 |
| `log2` | `( x -- y )` | 以 2 為底的對數 |

`e^`和`log`互為反運算，`10^`和`log10`也是。

如果某個量每一步都縮小同一個比例，它會遵循`start * e^(-rate * t)`。從`start`掉到`level`所需的時間是`log(start / level) / rate`。

## 沒有實數答案的時候

這些詞遇到棘手的輸入時，都不會拋出錯誤。負數的平方根或對數會得到**複數**結果，印出來時外圍會帶著一對`C{ ... }`，而不是單純的數字：

```factor
-1 sqrt .     ! => C{ 0.0 1.0 }
-1.0 log .    ! => C{ 0.0 3.141592653589793 }
0.0 log .     ! => -1/0.
```

`-1/0.`是負無限大。有可能出現不合法的引數時，就在呼叫前先檢查一下。等到三次計算之後才發現複數或無限大，就很難追回源頭了。

## 這裡的取整同樣只是近似

這些詞給的是最接近的浮點數，而不是精確值，所以比較結果時要容許誤差，用`~ ( x y epsilon -- ? )`，千萬別用`=`：

```factor
pi 6 / sin .             ! => 0.49999999999999994
pi 6 / sin 0.5 = .       ! => f
pi 6 / sin 0.5 1e-9 ~ .  ! => t
```
