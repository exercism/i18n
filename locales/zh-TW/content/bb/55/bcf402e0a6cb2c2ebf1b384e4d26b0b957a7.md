# 操作說明

這個練習談的是日誌檔案的解析。

在最近一次安全審查之後，你被要求清理組織封存的日誌檔案。

傳入這些方法的所有字串都保證不是 null，而且前後沒有多餘的空格。

## 1. 辨識混亂的日誌行

你需要大致了解，你的封存檔中有多少日誌行不符合現行標準。你認為只要做個簡單的測試，就能判斷一行日誌是否有效。一行日誌要算有效，開頭必須是下列其中一個字串：

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

實作`LogParser.IsValidLine()`方法，若字串無效就回傳`false`，否則回傳`true`。

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. 分割日誌行

有個新團隊加入了組織，結果你發現他們的日誌檔案用了奇怪的分隔符號來區隔「欄位」。他們不用像冒號 ":" 這種合理的東西，而是用 "<--->" 或 "<=>" 這類字串（因為比較漂亮）。事實上，任何字串都行，只要第一個字元是 "<"、最後一個字元是 ">"，中間是 "^"、"\*"、"=" 和 "-" 的任意組合。

實作`LogParser.SplitLogLine()`方法，它接收一行日誌，回傳一個字串陣列，其中每個字串各包含一個欄位。

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. 計算含有引號密碼的行數

團隊需要知道出現在引號文字裡的密碼，才能人工檢查。

實作`LogParser.CountQuotedPasswords()`方法，藉此大致了解這項人工處理的規模。

找出哪些日誌行中，字面字串 "password"（大小寫任意組合）被引號包住。你要考慮到 "password" 前後的引號內可能還有其他內容。

傳入這個常式的行，可能符合、也可能不符合任務 1 的定義。無論有效與否，我們都以相同方式處理。

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. 移除日誌中的殘留文字

你發現日誌的上游處理程序會把 "end-of-line" 這段文字連同緊接在後的數字行號（中間沒有空格）散落到整份日誌中。

實作`LogParser.RemoveEndOfLineText()`方法，接收一個字串、移除其中的 end-of-line 文字，並回傳「乾淨」的字串。

不含 end-of-line 文字的行應原樣回傳。

只要移除 end-of-line 字串就好，不要試著調整空白。

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. 列出密碼極度薄弱的行，好讓有罪的人受到懲罰

在把密碼從檔案中清除之前，我們需要列出所有密碼以 "password" 開頭的情況。

實作`LogParser.ListLinesWithPasswords()`方法，印出有問題的密碼，後面接著完整的那一行。

含有引號密碼的行已經被移除了，而你處理這些行時，不管它們是否符合任務 1 的定義。

含有問題密碼的行，回傳時要在前面加上 "<password>: "。

不含問題密碼的行，回傳時要在前面加上 "--------: "。

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
