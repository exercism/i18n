# 指示

在這個練習中，你會對遙控車再多做一些研究。

一款實驗車已經開發完成，測試跑道也需要調整，才能同時容納量產車和實驗車。
這兩種車都已經打造完成，你需要想辦法讓它們都能在測試跑道上運行。

此外，量產車也開始取得一些成績。
團隊老大很希望透過公布量產車的排名，來維持競爭的氣氛。

## 1. 實作介面

請為`RemoteControlCar`介面新增兩個方法：

- `drive()`，不回傳任何值，以及
- `getDistanceTravelled()`，回傳一個 `int`。

接著讓`ProductionRemoteControlCar`和`ExperimentalRemoteControlCar`實作`RemoteControlCar`介面。
這包括實作介面要求的所有方法。

## 2. 行駛

每次呼叫`.drive()`時，車子都應該行駛一段特定距離：

- 一輛`ProductionRemoteControlCar`行駛 10 個單位，
- 一輛`ExperimentalRemoteControlCar`行駛 20 個單位。

`.getDistanceTravelled()`方法應該回傳車子至今累積行駛的單位數。

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. 競速

實作`TestTrack.race(RemoteControlCar car)`方法，讓每輛`car`都能`drive()`。

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. 讓量產車可以排序

請在`ProductionRemoteControlCar`類別中實作`Comparable<T>`介面。
車子的預設排序順序應該是勝利次數的遞減順序。

實作靜態方法`TestTrack.getRankedCars()`，回傳傳入的車子，並依勝利次數遞減排序。

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
