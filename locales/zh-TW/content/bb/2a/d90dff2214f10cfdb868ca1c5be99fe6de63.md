# 關於

C# 型別可以定義在類別或結構的範圍內。外層型別提供了一種類似命名空間的作用。存取型別時，要透過外層型別並使用點號語法。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## 存取層級

存取層級可以套用到內部型別。例如，如果某個類別是 `private`，就無法從外層型別的範圍外看見它，當然也無法在該範圍外看見或使用它的執行個體。

外層類別的 private 成員都在內部類別所有成員的範圍內，但只有內部類別的非 private 成員才在外層類別成員的範圍內。若要存取外層類別的成員，就必須把外層類別的執行個體提供給內部類別。

下列範例說明了這一點：

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## 防止獨立建立執行個體

有一種模式可以避免可建立執行個體的型別在外層型別之外被建立：你公開一個 public 介面，但把實作的類別保持為 private。

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## 給 Java 開發者的說明

C# 的巢狀類別介於 Java 的靜態巢狀類別和內部類別之間。在 C# 中，外層類別的 private 成員都在巢狀類別成員的範圍內，但沒有特殊語法可以建立巢狀類別並將它連結到外層類別的執行個體。你必須使用上述範例所示模式的某種變化。

C# 確實有靜態巢狀類別，但那些只是具有靜態行為的封閉類別。
