# 說明補充

## 設定

請依照 TypeScript 的安裝說明，安裝必要的相依套件：

[https://exercism.org/docs/tracks/typescript/installation](https://exercism.org/docs/tracks/typescript/installation)

## 需求

安裝練習的相依套件：

```bash
$ yarn install
```

## 讓測試套件通過

用以下指令執行測試：

```bash
$ yarn test
```

在許多測試套件中，除了第一個測試以外，其他測試都會被跳過。

當你讓一個測試通過後，只要把 `xit` 改成 `it`，就能取消跳過下一個測試。

## 教學

本節會一步步帶你解這個練習。

這個練習有兩個檔案：

- hello-world.ts
- hello-world.test.ts

第一個檔案是你撰寫程式碼的地方，
第二個則是定義測試的地方。

測試會檢查你的程式碼是否做對的事情。
你不需要從零開始寫出整個測試套件，
但了解測試長什麼樣子、以及它在做什麼，會很有幫助。

打開測試檔 hello-world.test.ts，
裡面只有一個測試：

```typescript
it('says hello world', () => {
  expect(hello()).toEqual('Hello, World!')
})
```

現在用命令列執行以下指令來跑測試：

```bash
$ yarn test
```

測試失敗了，這很合理，因為你還沒寫任何程式碼。

失敗訊息看起來像這樣：

```
    × says hello world (5ms)

  ● Hello World › says hello world

    expect(received).toEqual(expected) // deep equality

    Expected: "Hello, World!"
    Received: "Goodbye, Mars!"

      4 |
      5 |   it('says hello world', () => {
    > 6 |     expect(hello()).toEqual('Hello, World!')
        |                     ^
      7 |   })
      8 |
      9 | })

      at Object.it (hello-world.test.ts:6:32)
```

這些就是 `hello-world.test.ts` 檔中可能有問題的程式碼行：

第 6 行：

```typescript
    expect(hello()).toEqual('Hello, World!')
                    ^
```

所以問題出在 `hello()` 這個函式呼叫。
可以看到測試預期輸出是 `'Hello, World!'`，但實際得到的卻是 `"Goodbye, Mars!"`。

現在來看看 `hello-worlds.ts` 檔裡的這個函式：

```typescript
export function hello(): string {
  return 'Goodbye, Mars!'
}
```

可以看到這個函式回傳了錯誤的字串，這就是失敗的原因。我們把回傳值改掉來修正它：

```typescript
export function hello(): string {
  return 'Hello, World!'
}
```

再執行一次測試：

```bash
 PASS  ./hello-world.test.ts
  Hello World
    √ says hello world (4ms)
```

這樣就通過了！
