# 提示

 ## 1. 定義預期的烤箱時間（分鐘）

- 定義一個[常數][constants]，用來存放食譜中指定的[`number`][numbers]值。

## 2. 計算剩餘的烤箱時間（分鐘）

- 設定方法的值來[回傳數字][return]。
- 使用[減法的數學運算子][operators]來相減。

## 3. 計算備料時間（分鐘）

- 設定方法的值來[回傳數字][return]。
- 使用[乘法的數學運算子][operators]來相乘。
- 使用額外提供的常數，代表每一層所需的時間（分鐘）。

## 4. 計算總工作時間（分鐘）

- 設定方法的值來[回傳數字][return]。
- [呼叫][invocation]先前實作過的其他方法之一。
- 使用[加法的數學運算子][operators]來相加。
