# 說明補充

## 關於 `smallest` 與 `largest` 實作的注意事項：

這兩個函式都必須接收兩個關鍵字引數：
- `max_factor`：int
- `min_factor`：int，預設 0

它們的回傳值必須是 `tuple -- (value, factors)`，其中 `value` 是迴文本身，而 `factors` 是一個 `iterable`，內含這個迴文的兩個因數，順序不拘。


## 例外訊息

有時候，我們必須[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，你應該一律附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓你的程式碼更容易閱讀，也對除錯有極大的幫助。如果你知道錯誤來源會是某個特定型態，可以選擇引發其中一種[內建錯誤型態](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然應該附上有意義的訊息。

這個練習要求你在 `largest()` 或 `smallest()` 函式收到一對不在正確範圍內的因數時，使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「throw」一個 `ValueError`。唯有你同時 `raise` 這個 `exception` 並附上訊息，測試才會通過。

若要帶著訊息引發 `ValueError`，請把訊息寫成 `exception` 型態的引數：

```python
# if the max_factor is less than the min_factor
raise ValueError("min must be <= max")
```
