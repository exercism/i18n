# 簡介

Java 裡的數字有兩種不同的型別：

- 整數：小數點後沒有任何位數的數字（也就是不帶小數部分的數）。例如`-6`、`0`、`1`、`25`、`976`和`-500000`。
- 浮點數：小數點後有零或多位數的數字。例如`-20.4`、`0.1`、`2.72`、`16.984025`和`1024.0`。

Java 中最常見的兩種數值型別是`int`和`double`。
`int`是 32 位元整數，`double`則是 64 位元的浮點數。

算術運算使用標準的算術運算子。
數字可以使用標準的數值比較運算子（例如`5 > 4`和`4 <= 5`），以及相等（`==`）和不等（`!=`）運算子來比較。

Java 有兩種數值轉換：

1. 隱式轉換：不會遺失任何資料，也不需要額外的語法。
2. 顯式轉換：可能會遺失資料，因此需要_轉型_這種額外的語法。

由於`int`的精確度比`double`低，從`int`轉換成`double`是安全的，所以屬於隱式轉換。
不過，從`double`轉換成`int`可能會遺失資料，因此需要顯式轉換。
