# 簡介

回想一下，`jq`程式是一組_運算式的管線_。
**變數賦值**遵循這個規則：_變數賦值_是一種長得像這樣的運算式：

```jq
... | expr as $varname | ...
```

## 過濾器的輸出就是輸入

和_恆等運算式_`.`一樣，_變數賦值_的輸出和它的輸入相同。
設定變數的值是一個副作用。

以下範例顯示，賦值之後的`.`和最初的輸入相同：

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## 變數作用域

變數的作用域是「詞法」的，也就是說，變數在管線剩下的部分都還在作用域內。
在函式中定義的變數（函式我們之後會再談到）對該函式而言是「區域」的。

## 變數名稱

變數必須以`$`開頭。
變數名稱其餘的部分是**識別字**：以字母或底線開頭，後面接著字母、數字或底線。

## 解構賦值

手冊上說：

> 只要提供一個_符合輸入結構_的模式，就能用單一個`as`運算式宣告多個變數（這稱為「解構」）。

範例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

把變數名稱對應到_物件的鍵_，可以省下一些功夫：

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## 常數

就像上面的範例所示，變數很方便用來存放常數。
與其讓「魔法數字」出現在程式碼裡，不如給常數一個名字。

## 通常不需要變數

省略變數往往讓程式更好讀。

想想看，要計算一個數字陣列的平均值

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

和下面這樣比起來

```jq
[2, 4, 8, 7] | add / length
```

這突顯了`jq`最強大的面向之一：過濾器的輸入會提供給_每一個_子運算式：

- 輸入陣列`[2,4,8,7]`會被傳給`add`（它把`+`運算子套用到所有元素，藉此加總這些數字）
- _同時_，`[2,4,8,7]`也會被傳給`length`
- 當這些子運算式完成後，它們的結果會被相除，回傳輸入陣列中這些數字的不均值。
