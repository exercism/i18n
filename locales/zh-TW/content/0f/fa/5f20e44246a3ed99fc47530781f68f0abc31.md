# 簡介

`if/elif/else`運算式可以用來依條件執行邏輯。F# 還有另一種更強大的方式可以依條件執行邏輯：模式比對。有了模式比對，就可以把一個值拿來和一或多個_模式_比對。這類模式的例子之一是_常數模式_，它會把值拿來和常數比對（例如`1`或`"hello"`）。

在 F# 中，模式比對是透過`match`關鍵字完成的：

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

雖然這看起來像是其他語言裡的`switch`敘述，但模式比對真正發揮作用的時候，是同時使用其他模式的時候。其中一種模式是_變數模式_，它讓你可以捕捉值：

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

有時候，你可能會想為模式加上額外的條件。這稱為_防護子句_，可以使用`when`關鍵字加入：

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

在上面的例子中，並非所有可能的輸入都會有相符的模式。編譯器會偵測到這點並發出警告。這稱為_完整性檢查_。為了解決這個警告，必須處理所有情況。為此，可以使用_萬用字元模式_，這是一種能符合任何值的模式：

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

模式比對會由上而下把值與每個模式逐一比對，直到找到相符的模式，並執行該模式對應的邏輯。模式的順序很重要！
