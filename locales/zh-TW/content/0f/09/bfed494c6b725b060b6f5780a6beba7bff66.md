# 管線與指令清單簡介

我們已經看過如何撰寫簡單的指令，也就是指令後面接著引數。
現在我們要看看如何把簡單的指令組合起來，做出更複雜的指令。

## 輸入與輸出

開始之前，先快速介紹一下輸入與輸出。

行程有「標準 I/O 通道」。

* 行程可以在「stdin」上消耗_輸入_。
* 行程可以在「stdout」上送出_輸出_。
* 行程可以在「stderr」上送出_錯誤輸出_。

`tr`指令就是這個概念最純粹的例子。
它做的事就是從輸入讀取文字、進行字元轉換，然後把結果文字印到輸出。

我們之後會在課程大綱中看到更多關於操作「stdio」通道的內容。

## 管線

這是殼層程式設計的「殺手級特色」之一。
管線讓你能對一串文字流進行精巧的轉換。

想產生排序好的使用者清單：

```bash
cat /etc/passwd | cut -d : -f 1 | sort
```

管線符號（`|`）會把一個指令的輸出連接到另一個指令的輸入。
`cut`讀取 `cat`的輸出，而 `sort`讀取 `cut`的輸出。

~~~~exercism/advanced
* 預設情況下，管線中的每個指令都會在各自獨立的子殼層中執行。
  （子殼層是子行程，也就是目前執行中的殼層的複本。）

* 執行管線會有效能成本。
  如果你發現自己寫出由類似指令組成的長管線，可以考慮把它們合併成單一指令。
  舉例來說，使用多個 `grep`、`cut`、`sed`、`awk` 和 `tr` 的管線，通常可以合併成單一 `awk`指令來提升效率。

* 管線的結束狀態就是管線中最後一個指令的結束狀態。
  這表示如果前面某個指令失敗，但最後一個指令成功，整條管線的結束狀態就是零。

  有一個殼層設定可以改變這個行為；
  如果啟用「pipefail」設定（使用 `set -o pipefail`），管線的結束狀態會是：
  * 如果所有指令都成功就是零，否則
  * 管線中各指令_**最後一個**非零的結束狀態_。
~~~~

## 指令清單

指令清單是由 `;`（或換行）、`&&` 或 `||` 分隔的一連串管線。

* `A; B` 是一個指令清單，其中 `B` 會在 `A` 完成後執行。
* `A && B`，其中 `B` 只在 `A` 成功（以狀態零結束）時執行。
* `A || B`，其中 `B` 只在 `A` 失敗（以非零狀態結束）時執行。

指令清單的結束狀態，就是最後執行的那個指令的結束狀態。

`&&` 和 `||` 運算子可以串接起來，讓下一個指令根據前面指令的狀態決定是否執行。
例如

```bash
A && B && C && D || E
```

* 如果 A 成功，就執行 B，
* 如果 A 和 B 都成功，就執行 C，
* 如果 A、B、C 都成功，就執行 D，
* 如果 A、B、C、D 中**任何一個**失敗，就執行 E。

~~~~exercism/caution
這些邏輯運算子要謹慎使用。
它們很容易讓程式碼變得難以閱讀，或讓邏輯變得難以理解。

例如，你可能會以為下面這兩個是一樣的：

```bash
if A; then B; else C; fi
```

```bash
A && B || C
```

差別在於：C 什麼時候會執行？

* 在第一段程式碼（`if` 敘述）中，C 只在 A 失敗時執行。
* 在第二段程式碼中，C 會在 A 失敗時執行，_或在 A 成功但 B 失敗時執行_！
~~~~

### 指令清單的用途

這裡有幾個例子，說明指令清單如何簡化程式碼。

#### 從檔案讀取成塊的多行

假設你有一個內含三角形資料的資料檔，每個三角形用三行分別存放三個邊。

```bash
$ cat triangle.dat
3
4
5
9
12
14
```

你可以使用 `while` 迴圈，條件是三個分開的 `read` 指令：

```bash
while read a && read b && read c; do
    if is_pythagorean "$a" "$b" "$c"; then
        echo "$a:$b:$c is pythagorean"
    else
        echo "$a:$b:$c is not pythagorean"
    fi
done < triangle.dat
```

假設 `is_pythagorean` 是一個判斷三個邊是否符合畢氏定理的指令，輸出會是：

```none
3:4:5 is pythagorean
9:12:14 is not pythagorean
```

#### 斷言

許多程式語言都有斷言機制，當某個條件不成立時會拋出例外。

```
assert(user == "Administrator", "wrong user");
```

我們可以在 Bash 中用 OR 運算子模擬這個功能：

```bash
die () { # a little convenience function
    echo "$*" >&2
    exit 1
}

[[ $user == "Administrator" ]] || die "wrong user"
[[ $password == "secret!" ]]   || die "incorrect password"
```

## 風格考量

冗長的指令清單很快就會變得難以閱讀。
大量使用換行能幫上很大的忙。

看看這個例子：當兩個條件都成立時，就把某個單字加入陣列。

```bash
[[ "$word" != "$topic" ]] && [[ "$key" == "$(sorted "$topic")" ]] && anagrams+=("$candidate")
```

Bash 允許你在管線符號或邏輯運算子後面加上換行。

```bash
[[ "$word" != "$topic" ]] &&
[[ "$key" == "$(sorted "$topic")" ]] &&
anagrams+=("$candidate")
```

不過，運算子放在行尾很容易被忽略。
使用_行接續_可以讓你把運算子放在最前面，這樣就更能看出清單還沒結束：

```bash
[[ "$word" != "$topic" ]] \
&& [[ "$key" == "$(sorted "$topic")" ]] \
&& anagrams+=("$candidate")
```

~~~~exercism/note
_行接續_是由「反斜線」和「換行」這兩個字元組成的序列（`\` + `\n`）。
當 Bash 看到這個序列時，會直接把它從程式碼中移除，讓目前這一行_接續_到下一行。
小心不要在反斜線和換行之間留下任何空格。
~~~~

再舉一個例子

```bash
printf "%s\n" "${numbers[@]}" | bc --mathlib | sort --general-numeric-sort
```

或是

```bash
printf "%s\n" "${numbers[@]}" \
| bc --mathlib \
| sort --general-numeric-sort
```
