# 補充說明

## 輸入格式

`board`參數代表遊戲棋盤，格式為由字串組成的陣列。

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

字串中的每個字元各代表一格。
每一格可接受的值如下：

- ` `：空白，代表一個空白格
- `B`：由黑棋玩家佔據的格
- `W`：由白棋玩家佔據的格

## 輸出格式

`getTerritory`函式預期會回傳一個帶有 2 個屬性的物件：

- `owner`：領土的擁有者（`NONE`、`BLACK`或`WHITE`）
- `territory`：座標陣列，代表領土中的每一格。

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

`getTerritories`函式預期會回傳一個帶有 3 個屬性的物件：

- `territoryBlack`：座標陣列，代表 `BLACK`玩家擁有的領土
- `territoryWhite`：座標陣列，代表 `WHITE`玩家擁有的領土
- `territoryNone`：座標陣列，代表不屬於這兩個玩家任何一方的領土

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
