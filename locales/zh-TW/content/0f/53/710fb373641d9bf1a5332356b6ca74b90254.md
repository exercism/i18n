# 指示

接下來，你要寫一些程式碼，幫助你照著最愛的食譜做出千層麵。

一共有五個任務，全都和烹調這份食譜的過程有關。

## 1. 定義預期的烘烤時間（分鐘）

定義一個 `ExpectedBakeTime` 常數，回傳千層麵應該在烤箱裡烘烤幾分鐘。
根據你的食譜，千層麵應該要在烤箱裡烤 40 分鐘：

```powershell
> $ExpectedBakeTime
> 40
```

## 2. 計算剩餘的烘烤時間（分鐘）

實作 `RemainingTime` 函式，它接受千層麵實際已經在烤箱裡的時間（分鐘）作為引數，並根據 `ExpectedBakeTime` 回傳千層麵還需要烤幾分鐘。

```powershell
> RemainingTime -Minutes 30
> 10
```

## 3. 計算準備時間（分鐘）

實作 `PreparationTime` 函式，它接受你想在千層麵裡加幾層作為引數，並回傳製作這些層需要花多少分鐘。
假設每一層需要 2 分鐘準備。

```powershell
> PreparationTime -Layers 2
> 4
```

## 4. 計算總共花費的烹調時間（準備 + 烘烤，分鐘）

實作 `ElapsedTime` 函式，它有兩個參數：`Layers`（_加入千層麵的層數_）和 `Minutes`（_千層麵已經在烤箱裡烘烤的分鐘數_）。
這個函式應該回傳你總共烹調了多少分鐘，也就是你的準備時間加上千層麵已經在烤箱裡烘烤的時間。

```powershell
> ElapsedTime -Layers 3 -Minutes 20
> 26
```

## 5. 建立通知，告知千層麵已經好了

定義 `Notification` 函式，它不接受任何引數，並回傳一則訊息，表示千層麵已經可以吃了。

```powershell
> Notification
> "Lasagna's ready!"
```
