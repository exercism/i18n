# 安裝

## 我裝的是哪一種 awk？

Exercism 的 AWK track 使用`gawk`，也就是 GNU 的 AWK。
你的系統可能已經裝了；要確認的話，執行這個指令
```sh
awk --version
```

如果它回傳：

* 類似 `GNU Awk 5.1.0 ...` 的東西
    - 你已經有 GNU awk 了，可以直接繼續做練習。

* 類似 `awk version 20200816` 的東西
    - 這是 `nawk`，也稱為 BWK awk（取名自 Brian Kernighan），或者叫做「one true awk」。
    - MacOS 和 BSD 系統內建的就是這個。
    - 安裝方式請見下方。

* 出現 `awk: not an option: --version` 這個錯誤
    - 你裝的大概是 `mawk`。
    - 用 `awk -W version` 確認，它可能回傳 `mawk 1.3.4 20200120`。
    - mawk 是個非常好又快速的 awk 實作，但它少了某些我們在 track 裡會用到的 gawk 專屬功能。
    - 安裝方式請見下方。

* 出現 `awk: unrecognized option: version` 這個錯誤，後面接著 `BusyBox v1.35.0 ...`
    - 你可能用的是 Alpine Linux。
    - 安裝方式請見下方。

* 出現「command not found」錯誤
    - 那要不是你的 PATH 設定亂了，就是你根本沒安裝 awk。
    - 安裝方式請見下方。

### Linux

這取決於你的發行版用哪個套件管理員。通常是：
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
你可能需要用`sudo`來執行對應的指令。

### MacOS

[Homebrew][brew] 是你的好朋友。點進連結安裝它，然後執行：
```sh
brew install gawk
```

### Windows

使用 [WSL][wsl] 的話，請參考上面的 Linux 安裝說明。
使用 cygwin 的話，請安裝 `gawk` 套件。

### 從原始碼編譯

想挑戰的人，可以參考[`gawk` 手冊裡的安裝說明][build]。
