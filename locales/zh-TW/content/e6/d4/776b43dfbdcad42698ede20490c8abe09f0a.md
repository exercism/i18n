# 說明補充

## 整數最大值

根據 [PHP 文件][php-int]，整數有一個最大值：

> `int`的大小取決於平台，不過最大值通常大約是 20 億（也就是 32 位元的有號整數）。
> 64 位元平台的常見最大值大約是 9E18。
> PHP 不支援無號的`int`。

換句話說，PHP 無法把`2^63`或更大的數字表示成整數。
這個練習的部分測試需要 64 位元整數（`2^64`），這已經超出 PHP 的整數大小限制。

當數字太大時，[PHP 會自動][php-int-to-float]把`int`轉成`float`：

> 如果 PHP 遇到超出`int`型別範圍的數字，會改為將它解讀成`float`。
> 此外，運算結果若超出`int`型別的範圍，也會改為回傳`float`。

但`float`型別[精確度有限][php-float-precision]。
而國王討厭不精確。
所以國王決定，要你把計算結果用能表示整數值的字串來呈現，而不是把答案表示成`int`或`float`。
而且他要的是整數運算，不是最後才偷懶地轉換一下。

你有辦法避開那些超過這個語言直接允許範圍的數字來解這題嗎？
另外，也請不要使用`gmp`或`bc`這類其他的 PHP 函式庫喔。

[php-int]: https://www.php.net/manual/en/language.types.integer.php
[php-int-to-float]: https://www.php.net/manual/en/language.types.integer.php
[php-float-precision]: https://php.net/manual/en/language.types.float.php
