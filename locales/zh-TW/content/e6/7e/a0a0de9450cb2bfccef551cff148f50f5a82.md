# 提示

在 2D 旋轉中使用複數，可以讓程式碼更簡潔，數值運算也更精確。

## 1. 用笛卡兒座標建立複數

- 內建的 [`complex(x, y)`][complex] 方法比直接指定`x + im*y`更有效率。
- 可以回頭看看簡介複習一下。

## 2. 用極座標建立複數

- 有幾種等效的做法（例如`exp`、`cis`、`cispi`）。
- 可以回頭看看簡介和指示，進一步複習。

## 3. 進行 2D 向量旋轉

- [歐拉公式][euler]在這裡很好用，你可以使用自己的`euler`函式。
- 有些方法可以取得複數的[實部][real]和[虛部][imaginary]，或是兩者一起！

## 4. 進行徑向位移

- 你的`euler`函式可能派得上用場，也可能不用……
- 內建的 [`angle`][angle] 方法可以快速從複數求出輻角。
- [`abs`][abs] 方法可以用來求出複數的量值。

## 5. 找出想要的歌曲

- 這是一個好機會，可以把你的`rotate`和`rdisplace`函式組合起來。
