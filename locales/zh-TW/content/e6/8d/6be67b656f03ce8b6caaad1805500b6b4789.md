# 提示

## 一般

- `TUPLE:`和`boa`都宣告在`kernel`相關的 vocab 裡，宣告類別時不需要特別的 USING。存取器的詞彙則來自[`accessors`][accessors]。

## 1. 基底類別

- `TUPLE: dragon name color age ;`會依序宣告這個類別和它的三個欄位。`<dragon>`只有一行：`dragon boa`。

## 2. 噴火的龍

- `<`父類別語法會繼承父類別的欄位：`TUPLE: fire-dragon < dragon flame-temp ;`。`boa`建構子的參數會先接收父類別的欄位。

## 3. 吐冰的龍

- 結構和第 2 個任務相同，只是多了一個不同的欄位。同層的子類別彼此不會互相影響，`fire-dragon`和`ice-dragon`都直接繼承`dragon`。

## 4. 住在火山的龍

- 讓它繼承`fire-dragon`（而不是直接繼承`dragon`），這樣`volcano-dragon`就會同時繼承`dragon`的欄位和`fire-dragon`的`flame-temp`。`boa`建構子會接收五個值：name、color、age、flame-temp、lava-volume。

## 5. 讓任何龍變老

- `change-age`是會修改資料的存取器，`( tuple quot -- tuple )`會把 quotation 套用到目前的 age，然後寫回去。`[ 1 + ] change-age drop`會遞增，並丟棄回傳的 tuple。由於每個子孫類別都繼承了這個欄位，同一個詞彙對每一種龍都適用。

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
