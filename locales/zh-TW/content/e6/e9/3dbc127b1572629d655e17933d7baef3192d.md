# 關於

CoffeeScript 是一門會轉譯成 JavaScript 的程式語言，用來製作動態網站（不論是在網頁瀏覽器還是伺服器端）。
轉譯器會在程式執行前，把 CoffeeScript 程式碼轉換成 JavaScript，在保有相容性與 JavaScript 相同效能的同時，還提供許多新功能！

CoffeeScript 的誕生，是為了提供一種更簡化的 JavaScript 撰寫方式，它融合了 Ruby 與 Python 的特色。
其中一項差異，是用縮排與箭頭取代 JavaScript 冗長的函式程式碼，並引入函式語言中實用的功能，包括模式比對。

CoffeeScript 是眾多可轉譯成 JavaScript 的新語言之一，例如 TypeScript 和 Flow。這個社群正在成長，而這類語言也非常受歡迎。
