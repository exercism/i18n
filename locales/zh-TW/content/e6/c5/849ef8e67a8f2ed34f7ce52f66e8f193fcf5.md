# 安裝

## 快速開始

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

預設會安裝到`/usr/local/bin`。若要改變這個位置，請提供目錄名稱：

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

我們透過 brew 提供 Linux 和 macOS 的執行檔。

安裝：

    brew install borkdude/brew/babashka

升級：

    brew upgrade babashka

## Arch（Linux）

`babashka` 在 [Arch 使用者軟體倉庫](https://aur.archlinux.org) 中[可以取得](https://aur.archlinux.org/packages/babashka-bin/)。你可以使用慣用的 [AUR](https://aur.archlinux.org) 輔助工具來安裝，例如
[yay](https://github.com/Jguer/yay)、[yaourt](https://github.com/archlinuxfr/yaourt)、[apacman](https://github.com/oshazard/apacman) 和 [pacaur](https://github.com/rmarquis/pacaur)。以下是以 `yay` 為例：

    yay -S babashka-bin

## Windows

在 Windows 上，你可以使用 [scoop](https://scoop.sh/) 和
[scoop-clojure](https://github.com/littleli/scoop-clojure) bucket 來安裝。

## 下載

你也可以從
[Github](https://github.com/borkdude/babashka/releases) 下載執行檔。Linux 有提供一個靜態執行檔，可以在 Alpine 上使用。
