# 介紹

當 quotation 需要從周遭環境*記住*數值時，Factor 提供兩種工具：來自 [`kernel`][kernel] 的 `curry`/`compose`，以及來自 [`fry`][fry] 的 fry 語法 `'[ … ]`。

`curry` 會把一個值嵌進 quotation 的開頭：

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` 則把兩個 quotation 黏在一起：

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

如果需要捕捉的値超過一兩個，fry 會更簡潔。每個 `_` 佔位符會依序填入一個從堆疊取出的值：

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry 也能深入巢狀的 quotation。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
