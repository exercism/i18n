# 說明

學校話劇的試鏡已經結束，導演需要把選角結果記錄下來。

四個任務都要寫在`CASTING_CALL`類別裡。

## 1. 判定結果

每位表演者都以十分為滿分來評分。八分以上就會入選；五到七分會進入複選；低於五分則會被致謝。

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. 屬於哪一組？

未滿 13 歲的表演者是 Juniors。13 到 15 歲是 Middles。16 歲以上則是 Seniors。

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. 什麼時候回來

Juniors 在四點回來複選，Middles 在五點，其他人則在六點。

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

這個引數是組別名稱，拼法要和任務 2 一模一樣。

## 4. 表單上要寫什麼

得分八分以上、而且會唱歌的人是 `"Lead"`。八分以上但不會唱歌則是 `"Speaking part"`。其他所有人都是 `"Chorus"`。

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
