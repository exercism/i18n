# 關於

[元組][tuple]是一種 _不可變_ 的集合，其中的項目依 _順序_ 排列。


和大多數集合一樣（請見內建的[`list`][list]、[`dict`][dict]和[`set`][set]），`tuples`可以存放任何一種（或多種）資料型態，包括其他的`tuples`。
元組的元素可以用`for item in <tuple>`這樣的結構來疊代。
如果需要同時取得元素的索引和值，可以使用`for index, item in enumerate(<tuple>)`。


和任何[序列][sequence]一樣，`tuples`中的元素可以透過 _括號標記_ 存取，使用從左邊數起的`0-based index`，或從右邊數起的`-1-based index`。
元組可以透過 _切片標記_ 或`<tuple>.copy()`整體或部分複製，並支援所有[常見序列操作][common sequence operations]。
由於 _不可變_，`tuples`**不**支援[可變序列操作][mutable sequence operations]。


和其他集合型別相比，元組佔用的記憶體空間非常少，而且使用索引存取時的時間是固定的（_O(1)_）。
不過，元組一旦建立就無法調整大小、排序或修改，所以當資料需要頻繁變更或更新時，彈性就比較差。
如果需要頻繁更新或擴充，`list`、`collections.deque`或`array.array`可能是更適合的資料結構。

<br>

## 建立元組

元組可以用多種方式建立：使用`tuple`類別建構子，或使用`(<element_1>, <element_2>)`（_`tuple`字面值_）宣告。

### 使用空的`tuple()`建構子，或搭配 _可疊代物件_：

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

字串是可疊代的，所以把單一`str`當作引數傳給`tuple()`建構子，可能會出現意想不到的結果：

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

其他可疊代物件的元素也會被逐一加入：

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

`dict`預設疊代的是 **鍵**。
如果想讓從字典建立的元組同時包含鍵和值，可以使用`<dict>.items()`，它會回傳一個 (`key`, `value`) `tuples` 的疊代器。

```python
>>> source_data = {"fish": "gold", "monkey": "brown"}

>>> multiple_elements_dict_1 = tuple(source_data)
('fish', 'monkey')

>>> multiple_elements_dict_2 = tuple(source_data.items())
(('fish', 'gold'), ('monkey', 'brown'))
```

#### 以 _字面值_ 宣告元組：

因為`tuple()`建構子只接受 _可疊代物件_（或什麼都不接受）當作引數，所以用字面值的方式建立單元素元組要簡單得多。

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

一般來說，建立`tuple`字面值時**不**需要括號，只需要逗號。
不過，在大多數情況下，使用`(<element_1>, <element_2>)`被認為可讀性更高。
在容易產生歧義的情況下也需要括號，例如空元組、單元素元組，或是函式以元組作為引數時。

```python
>>> elements_separated_with_commas = "Parrot", "Bird", 334782
("Parrot", "Bird", 334782)

>>> elements_with_commas_and_parentheses = ("Triangle", 60, 60, 60)
("Triangle", 60, 60, 60)
```

其他的資料結構也可以作為`tuple`的元素，包括其他的`tuples`。

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

元組可以用加號`+`運算子串接，它會把每個`tuple`拆解開來，建立一個新的合併`tuple`。

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## 存取資料

元組內的元素（就像其他序列型別`str`和`list`一樣）可以透過 _括號標記_ 存取。
索引可以是從**`left`** --> **`right`**（_從零開始_），或從**`right`** --> **`left`**（_從 -1 開始_）。
元組也可以透過 _切片標記_ 或`<tuple>.copy()`整體或部分複製。

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa

#age is at index 3 or index -1
>>> student_age_1 = student_info[3]
8

>>> student_age_2 = student_info[-1]
8
```

## 疊代元素

元組內的元素可以用`for item in <tuple>`語法在迴圈中 _疊代_。
如果需要同時取得索引和值，可以使用`for index, item in enumerate(<tuple>)`。

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)
>>> for item in student_info:
...   print(item)
...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) + ".")
...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```


## 元組作為同質性資訊

元組經常被當作 _記錄_ 使用，裡面包含的資料在 _組織上_ 或 _概念上_ 是同質的，並被視為單一的資訊單位，即使個別元素的資料型態是 _異質的_。

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)
```

當需要同質、不可變的資料序列時，也會用到元組，例如用於[`hashability`][hashability]、存放到`set`中，或在字典中建立鍵。

請注意，雖然`tuples`在大多數情況下是 _不可變的_，但因為它們可以包含 _任何_ 資料結構或物件，所以只要其中任何元素是 _可變型別_，元組就可能 _變成可變的_。
在`tuple`中使用可變的資料型態，會讓外層的`tuple`**無法雜湊**。

```python
>>> cmyk_color_map = {
        (.69, .3, .48, .1) : ("Teal 700", (59, 178, 146), 0x3BB292),
        (0, .5, 1, 0) : ("Pantone 151", (247, 127, 1), 0xF77F01),
        (.37, .89, 0, .44) : ("Pantone 267", (89, 16, 142), 0x59108E),
        (0, 1, .46, .45) : ("Pantone 228", (140, 0, 76), 0x8C004C)
    }

>>> unique_rgb_colors = {
        (59, 178, 146),
        (247, 127, 1),
        (89, 16, 142),
        (140, 0, 76),
        (76, 0, 140)
     }

>>> teal_700 = hash((59, 178, 146))

>>> teal_700 = hash(("Pantone 228", [(140, 0, 76), 0x8C004C]))
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'
```

## 擴充元組與相關資料型態

元組經常被當作 _記錄_ 使用，但其中的資料只能透過 _位置_／_索引_ 存取。
[`collections`][collections]模組中的[`namedtuple()`][namedtuple]類別擴充了基本元組的功能，讓元素可以透過 _名稱_ 存取。
此外，使用者也可以改用[`dataclass`][dataclass]來提供類似的具名屬性功能，不過各有其[優缺點][dataclass pros and cons]。
