# 簡介

[範圍][range]代表兩個值之間的區間。
範圍常和`Int`、`String`、`Character`這類型別搭配使用，用來疊代序列、切割集合，或檢查某個值是否落在範圍內。

Swift 提供了兩種主要的範圍運算子：

- **封閉範圍運算子（`...`）**：包含起始值和結束值（`1...5`包含 1、2、3、4 和 5）。
- **半開範圍運算子（`..<`）**：包含起始值，但不包含結束值（`1..<5`包含 1、2、3 和 4）。

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
當你直接在範圍字面值上呼叫方法時，請用括號把範圍運算式包起來，讓編譯器先對範圍求值：

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## 將範圍轉換成陣列

你可以使用`Array(_:)`初始化器，把數字範圍轉換成`Array`：

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 用範圍切割陣列

你可以用範圍切割出陣列的子區段：

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## 範圍的屬性和方法

範圍常見的操作包括：

| 成員                    | 說明                                                       | 範例                                 |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 回傳範圍中的元素數量                                       | `(1...5).count`回傳`5`               |
| [`contains(_:)`][contains] | 如果範圍包含指定的值，就回傳`true`                       | `(1...5).contains(3)`回傳`true`      |

## 單邊範圍

Swift 也支援單邊（部分）範圍，你可以省略起始值或結束值：

- `array[2...]`：從索引 2 到集合結尾。
- `array[...2]`：從集合開頭到索引 2（含索引 2）。
- `array[..<2]`：從集合開頭到索引 2 之前（不含索引 2）。

## 字串和字元範圍

也可以在遵循`Comparable`的字元或字串之間建立範圍：

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
