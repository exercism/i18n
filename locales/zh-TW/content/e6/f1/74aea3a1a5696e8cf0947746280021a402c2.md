# 說明

在這份練習中，你要為朋友正在開發的一款新 RPG 遊戲實作任務邏輯。

遊戲的主角是 Annalyn，一個勇敢的女孩，身邊帶著一隻凶猛又忠誠的寵物狗。不幸的是，災難降臨了：她最好的朋友在森林裡尋找莓果時遭到綁架。

Annalyn 會試著找到並救出她最好的朋友，這趟任務中她可以選擇帶不帶狗同行。

循著好朋友的蹤跡走了一段時間後，她找到了囚禁好朋友的營地。原來綁匪有兩個人：一位驍勇的騎士和一名狡猾的弓箭手。

找到綁匪後，Annalyn 開始思考自己可以採取下列哪些行動：

- _快速攻擊_：如果騎士正在睡覺，就可以發動快速攻擊，因為他需要時間穿上盔甲，這段期間他會很脆弱。
- _刺探_：只要這群人之中至少有一人醒著，就可以刺探他們。否則刺探只是浪費時間。
- _向囚犯打暗號_：如果囚犯醒著而弓箭手在睡覺，就可以用鳥叫聲向囚犯打暗號，因為弓箭手受過鳥叫聲暗號的訓練，可能會攔截訊息。
- _釋放囚犯_：Annalyn 可以試著潛入營地釋放囚犯。
  這件事風險很高，只有兩種情況之一能成功：
  - 如果 Annalyn 帶著寵物狗，只要弓箭手在睡覺，她就能救出囚犯。
    騎士怕狗，而弓箭手來不及準備，Annalyn 和囚犯就能趁機逃走。
  - 如果 Annalyn 沒有帶狗，她跟囚犯就得非常小心！
    只要囚犯醒著，而且騎士和弓箭手都在睡覺，Annalyn 就能釋放囚犯；但如果囚犯在睡覺，就沒辦法救他：囚犯會被突然出現的 Annalyn 嚇到，進而吵醒騎士和弓箭手。

你有四項任務：根據森林裡這三個角色的狀態，以及 Annalyn 的寵物狗在不在身邊，實作判斷上述行動是否可行的邏輯。

## 1. 檢查是否能發動快速攻擊

實作`can_fast_attack()`方法，它接受一個布林值，表示騎士是否醒著。這個方法會根據騎士的狀態，在可以發動快速攻擊時回傳`TRUE`，否則回傳`FALSE`：

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. 檢查是否能刺探這群人

實作`can_spy()`方法，它接受三個布林值，分別表示騎士、弓箭手和囚犯是否醒著。這個方法會根據這三個角色的狀態，在可以刺探這群人時回傳`TRUE`，否則回傳`FALSE`：

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. 檢查是否能向囚犯打暗號

實作`can_signal_prisoner()`方法，它接受兩個布林值，分別表示弓箭手和囚犯是否醒著。這個方法會根據這兩個角色的狀態，在可以向囚犯打暗號時回傳`TRUE`，否則回傳`FALSE`：

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. 檢查是否能釋放囚犯

實作`can_free_prisoner()`方法，它接受四個布林值。前三個參數分別表示騎士、弓箭手和囚犯是否醒著。最後一個參數表示 Annalyn 的寵物狗是否在場。這個方法會根據這三個角色的狀態以及 Annalyn 的寵物狗是否在場，在可以釋放囚犯時回傳`TRUE`，否則回傳`FALSE`：

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
