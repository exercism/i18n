# 元組

元組是一種輕量的方式，可以把固定數量、型別不拘的資料群組在一起。元組沒有特定的名稱；一旦為資料結構取了名字，它就變成`struct`。元組的欄位沒有名稱，只能透過解構或位置來存取。

## 語法

元組是一串以括號包住的欄位：

- `()` 是`unit type`，是一種[特殊情況](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _運算式_ **,)** 是單一元素的元組運算式
- **(** _型別_ **,)** 是單一元素的元組型別
- **(** _運算式_ **,** ... **)** 是一般的元組運算式
- **(** _型別_ **,** ... **)** 是一般的元組型別

### 建立

元組一律用元組運算式建立：

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

元組可以有任意數量的元素。

### 透過解構存取

可以透過解構來存取元組的元素。這只是把變數名稱指定給元組中的個別元素，並將元組消耗掉。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 透過位置存取

也可以透過數值位置索引來存取元組的元素。索引一如往常，從 0 開始。

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## 元組結構體

你也會需要處理元組結構體。和一般結構體一樣，它們是具名型別；但和一般結構體不同的是，它們的欄位是匿名的。它們的語法和一般元組語法非常相似。解構和位置存取兩種方式都可以使用。

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### 欄位可見性

匿名元組的所有欄位一律是公開的。不過，元組結構體的欄位各自有可見性，預設為私有，就和標準結構體的欄位一樣。你可以用`pub`修飾符讓欄位變成公開，就像標準結構體一樣。

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
