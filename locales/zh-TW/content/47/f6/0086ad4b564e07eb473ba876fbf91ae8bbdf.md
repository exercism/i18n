# 簡介

我們在[基礎][concept-basics]概念中已經介紹過函式，當時有這樣的例子：

```R
squareit <- function(x) {
    x * x
}

squareit(3)
#> [1] 9

# shorter form
squareit_short <- function(x) x ^ 2
```

仔細看看`squareit`的定義，可以辨認出幾個部分：

- 這個函式接受一個形式引數`x`。
- 有一個函式主體，通常包在大括號`{ }`裡。
- 函式物件一旦建立，就會被賦值給變數`squareit`。

函式在 R 中是一級物件，就和數字、字串沒什麼兩樣。
因此，`squareit <- function...`是一種賦值，語法上就跟`x <- 42`一模一樣。

## 引數

R 不像 Python、Julia 等其他腳本語言那樣，明確區分位置引數與關鍵字引數。

函式呼叫可以用位置或名稱來傳值。
後者對於引數眾多、順序又難記的複雜函式很有用。

```R
f <- function(x, y) x / y

# call positionally
f(4, 2)
#> [1] 2

# call by name
f(y = 2, x = 4)
#> [1] 2
```

### 選用引數

引數的預設值可以在函式定義中指定，但必須放在所有沒有預設值的引數之後。

接著就可以選擇要採用預設值，還是覆寫它。

```R
g <- function(x, y = 2) x / y

# default y value
g(6)
#> [1] 3

# explicit y value
g(6, 3)
#> [1] 2
```

### 額外引數

如果想接受任意數量的額外引數，可以在定義中使用`...`（省略符號）。
函式呼叫中任何額外的值都能轉成向量，不過請繼續往下讀，看看這些「點引數」（*在其他幾種語言中稱為「varargs」*）的另一種用法。

```R
var_f <- function(x, y, ...) {
  print(c(...))
}

var_f(2, 3, "opt1", "opt2")
#> [1] "opt1" "opt2"
```

## 函式環境

先前我們說過，形式引數和函式主體都是函式的組成部分。

其實還有第三個組成部分：定義函式時所在的*環境*。

這可以用巢狀函式來說明：

```R
outer_func <- function(x) {
  inner_func <- function(y) {
    x * y
  }
  
  inner_func(3)
}

outer_func(5)
#> [1] 15
```

函式呼叫把`x = 5`傳給外層函式，這個值在外層函式主體內可以取用。

內層函式是外層函式主體的*一部分*，因此能存取`x`的值。
換句話說，`x = 5`位於內層函式的*環境*之中。

技術上，這稱為[閉包][wiki-closure]。

環境在點引數上格外重要，因為用這種方式提供的任何值，都可以傳遞到函式主體裡的函式呼叫中。
外層函式不需要知道、也不必在意這些點引數代表什麼意思。

```R
f_var <- function(x, ...) {
  sum(x, ...)
}

x <- c(1, 2, NA, 6)

# for sum(), na.rm defaults to FALSE
f_var(x)
#> [1] NA

# pass through the na.rm value
f_var(x, na.rm = TRUE)
#> [1] 9
```

這項技巧被 Tidyverse 的函式庫大量使用，例如[`stringr`][ref-stringr]。
許多`stringr`函式都只是`stringi`與 base R 底層函式的易用包裝。

提供給`str_*()`函式的額外引數，就只是原樣傳遞給那些底層函式。

## 函式作為回傳值

外層函式可以定義一個內層函式（具名的，或如下所述的匿名函式），並把它當成回傳值。

被回傳的函式會包含定義它時所在的環境。

```R
times_y <- function(x) {
  # anonymous function - see next section
  \(y) x * y
}

f <- times_y(3)
class(f)
#> [1] "function"

f(4)
#> [1] 12
```

## 匿名函式

定義函式時，我們通常會把產生的函式物件綁定到某個變數：

```R
x <- 2

# function definition captures x from the environment
doubleit_short <- function(y) x * y
```

這樣之後在腳本中就能輕鬆使用這個函式，不過這種綁定並非必要。
簡短、只用一次的函式，在當下的情境中可能很有用。
沒有名稱綁定時，就稱為*匿名函式*。

匿名函式的使用實在太普遍，因此（*從 R v4.1.0 起*）有了一種定義它們的簡寫語法：把`function`這個字換成反斜線`\`。

前一節談回傳值時，就用過這樣的例子。

## 修改時複製

R 允許對向量的個別元素賦值。
如果把向量當成函式引數傳入，在函式主體中修改它再回傳，就會得到一個修改過的向量。

但原來的向量怎麼了？

```R
f <- function(vec) {
  vec[1] <- 42
  vec
}

vals <- c(1, 3, 4)

# f() returns a modified vector
f(vals)
#> [1] 42  3  4  

# the original vector is unchanged.
vals
#> [1] 1 3 4
```

R 是為資料科學設計的語言。
蒐集這些資料可能耗費大量時間與心力，也可能付出令人咋舌的金錢：*重要的是別讓資料損毀！*

一般原則（少數例外除外）是*修改時複製*。
如果某個物件（例如向量）被以可能導致後續問題的方式修改，R 會回傳一份*修改過的副本*，並保留原始物件不動。

複製大型資料結構在運算上可能很昂貴，但與資料損毀相比，這通常是兩害相權取其輕的做法。
