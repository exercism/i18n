# 安裝

elm 目前的版本是 0.19.1。
安裝說明會隨著語言的發展而改變。
最新的安裝說明請前往
[elm 指南的安裝說明][elm-install]。

[elm-install]: https://guide.elm-lang.org/install/elm.html

## 其他工具

**elm-test**

用來從命令列執行測試的工具叫做 elm-test。
目前 elm-test 需要 Node.js 和 npm，所以如果你還沒安裝，
請先[安裝 Node.js 和 npm][npm-install]。
安裝好 npm 之後，就可以用以下指令安裝 elm-test：

```shell
npm install --global elm-test@latest-0.19.1
```

更多資訊請見 elm-test 的 [npm 首頁][elm-test]。

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

大多數 elm 開發者都用 elm-format 來格式化 elm 程式碼。
它是一個零設定的程式碼格式化工具。
如果你還不習慣自動格式化工具，一開始可能會覺得有點挫折，
但一旦習慣了，就會開始想，以前沒有它到底是怎麼寫程式的。
它也可以用 npm 安裝：

```shell
npm install --global elm-format@latest-0.19.1
```

更多資訊請見 [GitHub 上的 elm-format 首頁][elm-format]。

[elm-format]: https://github.com/avh4/elm-format

**文字編輯器**

Elm 至少在 [IntelliJ][intellij] 有不錯的支援，
另外還有相容於 [elm 語言伺服器][els] 的文字編輯器，
例如 VS Code、Sublime Text 或 Vim。

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## npm 的權限錯誤

你在安裝 elm-test 或 elm-format 時，
可能會遇到 npm 的 EACCESS 權限錯誤。
如果是這樣，請依照 npm 網站上的說明處理。
[在全域安裝套件時解決 EACCES 權限錯誤][eaccess]。

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
