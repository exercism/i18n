# 提示

## 一般

- 指令 [cmp][cmp] 和 [test][test] 可用來根據某些受測條件設定旗標。
- 指令 [jmp][jmp] 和 [jcc][jcc] 可用來根據先前設定的旗標進行分支。
- 當你呼叫一個函式時，被呼叫的函式可能會修改你正在使用的暫存器。

## 1. 計算一張牌的值

- 指令 [cmp][cmp] 和 [test][test] 可用來根據某些受測條件設定旗標。
- 指令 [jmp][jmp] 和 [jcc][jcc] 可用來根據先前設定的旗標進行分支。
- 當你呼叫一個函式時，被呼叫的函式可能會修改你正在使用的暫存器。
- 你可以使用`cmp`來比較兩張牌，並設定適當的旗標。
- 如果一個數字等於另一個數字，你可以使用`je`或`jz`來分支。
- 如果一個數字小於另一個數字，你可以使用`jl`來分支。

## 2. 判斷哪張牌的值較高

- 指令 [cmp][cmp] 和 [test][test] 可用來根據某些受測條件設定旗標。
- 指令 [jmp][jmp] 和 [jcc][jcc] 可用來根據先前設定的旗標進行分支。
- 當你呼叫一個函式時，被呼叫的函式可能會修改你正在使用的暫存器。
- 一旦你定義了`value_of_card`函式，就可以從其他函式呼叫它。
- 你可以使用`cmp`來比較兩張牌，並設定適當的旗標。
- 你可以使用`jg`在一個數字大於另一個數字時分支，並使用`jl`在它較小時分支。
- 如果兩張牌的值相同，則在`rdx`中回傳第二張牌。否則，`rdx`應設為 0。

## 3. 計算一張 A 的值

- 指令 [cmp][cmp] 和 [test][test] 可用來根據某些受測條件設定旗標。

- 當你呼叫一個函式時，被呼叫的函式可能會修改你正在使用的暫存器。
- 一旦你定義了`value_of_card`函式，就可以從其他函式呼叫它。
- 你可以使用`add`來將兩個數字相加。
- 你可以使用`sub`來從第一個數字減去第二個數字。
- 你可以使用`cmp`來比較兩張牌，並設定適當的旗標。
