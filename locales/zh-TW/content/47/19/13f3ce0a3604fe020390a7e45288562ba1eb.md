# 幫助

## 安裝 Rust

關於 Rust 的安裝與學習資源，請參閱 [Exercism 的幫助頁面][help-page]。

## 提交解答

一般來說，你應該提交所有用來實作解答的檔案（大多數情況下是`src/lib.rs`）。如果你使用了任何外部 crate，請考慮一併提交`Cargo.toml`檔案。這會讓審查流程更快、更清楚。

## 意見回饋、問題、Pull Request

前往[論壇](https://forum.exercism.org/c/programming/rust/)發文，提供你對某個練習的意見回饋，或是表達想協助實作新練習的意願。Rust 學習軌道團隊的成員都很樂意幫忙喔！

GitHub 上的[學習軌道儲存庫][github]是所有 Rust 練習的所在地。

如果你想更了解 Exercism，可以看看[貢獻指南]。

## 提交未完成的解答

你可以提交未完成的解答，這樣就能看看其他人是怎麼完成這個練習的。
