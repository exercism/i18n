# 指令補充

## 提示

這道練習處理的是文字資料。基於歷史因素，Haskell 的`String`型態與`[Char]`同義，也就是一個字元的陣列。若要更有效率地處理文字資料，可以使用`Text`型態。

作為這道練習的選用延伸，你可以

- 閱讀 Haskell 的[字串型態](https://haskell-lang.org/tutorial/string-types)。
- 在 package.yaml 的相依套件清單中加入`- text`。
- 以[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)匯入`Data.Text`：

        import qualified Data.Text as T
        import           Data.Text (Text)

- 現在你可以寫出例如`isIsogram :: Text -> Bool`，並用`T.toLower`之類的方式取用`Data.Text`的組合子。
- 查閱[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的說明文件。

這個部分完全是選用的喔。
