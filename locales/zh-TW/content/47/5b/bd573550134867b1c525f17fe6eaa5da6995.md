# 指令補充

## 提示

你需要實作這個函式

```haskell
value :: (Color, Color) -> Int
```

它只接受兩個顏色，並產生該電阻器電阻的數值部分。

**加分題：性質測試**

這個練習是寫一些[性質測試](https://en.wikipedia.org/wiki/Property_testing)的好機會。如果你之前沒寫過，這裡有一些資源：

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing)。
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

我們在測試檔中提供了一個 QuickCheck 性質測試的範例。

可以測試的性質範例：

- 對所有`x`不是`Black`的`(x, y)`，`value (x, y) >= 10`皆成立

- 對`value (x, y)`呼叫`show`，會產生把對`value (y, x)`呼叫`show`的結果`reverse`後的字串。

- 所有顏色都有獨一無二的名稱。（對任意兩個顏色而言，如果顏色不同，名稱也就不同。）
