# 關於

在 Go 裡，`map`是一種內建的資料型態，代表雜湊表。在其他程式語言裡，你可能以`dict`、關聯式陣列或鍵值儲存的形式認識 map。如果你對這個概念不熟悉，可以把`map`想像成一本字典：每個單字是`key`，而解釋就是 map 的`element`。

> 開始之前，我想先請你參考 [Go 規格書的 map 章節][gospec-map] 和 [Go 部落格的 map 文章][goblog-map]，進一步深入了解`map`。

在語法上，`map`看起來像這樣：

```go
map[KeyType]ElementType
```

_`KeyType`必須是任何[可比較的型別][gospec-comparable]，而`ElementType`可以是 Go 中任何有效的型別，這表示你可以存放從基本的變數到 slice 的任何東西。_

請務必記得，Go 裡的`map`是**無序**的。如果你試著走訪`map`並印出元素，可能會驚訝地發現元素是以隨機順序印出來的（有興趣的話不妨試試看）。

同樣重要的是要知道，每個鍵都是唯一的，這表示重複指定同一個鍵，會覆寫對應鍵的值。

`map`是參考型別，這表示當你把它四處傳遞時，Go 不會複製整份 map。相反地，Go 會複製 map 的指標，這讓把 map 傳給函式或變數的成本很低。未初始化的 map，其值為`nil`。

你可以像下面這樣定義 map（我們也稱它為**nil map**）：

```go
  var foo map[string]int
```

要初始化 map，你可以這樣做：

```go
  // With map literal
  foo := map[string]int{}
```

或是

```go
  // or with make function
  foo := make(map[string]int)
```

> nil map 和已初始化的 map 不同，對 nil map 寫入會造成執行階段錯誤
>
> ```txt
> panic: assignment to entry in nil map
> ```
>
> 因此，在使用 map 之前先初始化它很重要

以下是一些你可以對 map 進行的操作

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

如果你試著取得 map 中不存在的鍵所對應的值，它會回傳該值型別的零值。這可能會讓你困惑，尤其當你的`ElementType`的預設值（例如 int 的 0）本身就是一個有效值時。要檢查某個鍵是否存在於你的 map 中，你可以使用

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```

如同前面看到的，要偵測`map`是否已初始化很簡單，只要把它和`nil`比較就好，但其他 map 又該怎麼辦呢？由於`map`不是可比較的型別，我們不能用`==`運算子，不過`reflect`套件有個東西可以救我們，它叫做`DeepEqual`，我們可以這樣用

```go
import "reflect"

// ....

equal := reflect.DeepEqual(map[string]int{}, map[string]int{})
fmt.Println(equal)
// Output: true
```

_但等等，如果 map 不是可比較的型別，為什麼我們能用`nil`跟它比較呢？這是因為規格書為此開了個例外，請參考[可比較性規格][gospec-comparable]_

最後一點，如果你試著從多個 goroutine 寫入`map`，會觸發競態偵測器，請參考 [Go 文件][godoc-race-detector] 和 [The Go Blog][goblog-race-detector]。或者，你可以使用`sync.Map`、`atomic`或`mutex`來繞過這個問題。
