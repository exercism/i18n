# 指令

排出一條骨牌鏈吧。

給定一組骨牌，請計算出一種排列順序，讓它們形成正確的骨牌鏈（一張骨牌其中一面的點數，要和相鄰骨牌鄰接那一面的點數相同），而且沒有相鄰骨牌的那兩面（也就是第一張和最後一張骨牌）點數也要彼此相同。

例如給定骨牌 `[2|1]`、`[2|3]` 和 `[1|3]`，你應該算出類似 `[1|2] [2|3] [3|1]` 或 `[3|2] [2|1] [1|3]` 或 `[1|3] [3|2] [2|1]` 等等的結果，其中第一個和最後一個數字相同。

對於骨牌 `[1|2]`、`[4|1]` 和 `[2|3]`，排出來的鏈並不合法：`[4|1] [1|2] [2|3]` 的第一個和最後一個數字不同。4 != 3

有些測試案例可能會在鏈的解法中使用重複的骨牌，請假設當時使用了多組骨牌。
