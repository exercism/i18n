# 關於

Ruby 是一門動態的開放原始碼程式語言，講究簡潔與生產力。它的語法優雅，讀起來自然，寫起來也輕鬆。

Ruby 誕生的初衷，是打造一門精心追求平衡的語言。它的創造者 [Yukihiro “Matz” Matsumoto](https://en.wikipedia.org/wiki/Yukihiro_Matsumoto) 融合了他最喜愛的幾門語言（Perl、Smalltalk、Eiffel、Ada 和 Lisp）的部分特色，催生出一門全新的語言，在函式式程式設計與指令式程式設計之間取得平衡。

他經常說，他「試著讓 Ruby 變得自然，而不只是簡單」，這樣的想法正呼應了人生。

循著這個理念，他補充說道：「Ruby 外表看似簡單，內在卻十分複雜，就像我們的人體一樣。」

你可以[在 Ruby 的網站上](https://www.ruby-lang.org/en/about/)進一步認識這門語言。
