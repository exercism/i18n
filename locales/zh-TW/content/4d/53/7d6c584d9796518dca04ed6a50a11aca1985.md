# 安裝

## Ubuntu（以及其他大多數 Debian 系發行版）

若要在本機建置程式碼，你需要 gcc 和 make，可以透過以下指令安裝

```shell
sudo apt install gcc make
```

如果你不是在 ARM64 硬體上執行，請使用以下指令安裝 [QEMU][] 模擬器與 GCC ARM64 交叉工具鏈

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

使用 [Windows Subsystem for Linux][]，搭配 Debian 系發行版，並依照上面的 Ubuntu 說明操作。
或者，也可以設定一台 Linux 虛擬機。

## macOS

可以使用任何合適的虛擬化解決方案（例如 [Lima][]）啟動 Linux 虛擬機。

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
