# 提示

## 1. 取得標題的第一個字母

- 有一個[方法][index]可以取得`String`在指定索引上的`Char`。

## 2. 取得作者姓名的首字母

- 你可以用已經實作好的方法來取得`String`的第一個字母。
- 想將多個值組合成`String`時，可以使用[字串插值][string-interpolation]。

## 3. 解密字母

- 有一個[方法][uppercase]可以檢查`Char`是不是大寫。
- 有一個[方法][ord]可以取得`Char`的碼位。

## 4. 解密文字

- 你可以使用[迴圈][while]來重複執行程式碼。
