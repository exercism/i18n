# Exercism 搬到 exercism.org 了

## Exercism 在 exercism.org 有新家了！

過去 8 年來，Exercism 一直住在 exercism.io，我們覺得是時候換個環境了！

如果你有興趣，以下是我們做這個決定的一些原因。

首先，我們覺得`.org`網域更能代表 Exercism 的本質。
大多數新專案一開始都是先找一個還空著的網域，而`.io`正好很合適，因為它常讓人聯想到 I/O。
但隨著我們成長、演進，成為更大的平台，我們已經有好一陣子覺得，是時候換一個看起來更「正式」的網域了。
我們擁有`exercism.com`、`exercism.net`以及其他幾個網域，但我們覺得`exercism.org`最能代表我們非營利的使命，也最能給人良好的第一印象。
由於我們也希望能向社群和組織募款，我們覺得比較專業的`.org`也更能帶來信任感，尤其我們的名字有時會給人一點突兀的第一印象……

其次，使用`io`網域的安全性，比使用幾個最初的頂級網域稍微低一些。
2017 年的時候，[io 的權威名稱伺服器遭到入侵](https://thehackerblog.com/the-io-error-taking-control-of-all-io-domains-with-a-targeted-registration/)，對方用的手法相當簡單。雖然出錯在所難免，事情也很快就被修正，但這種事不太會發生在`.org`網域上。
我們也偶爾遇到 DNS 解析的問題，有些人會沒辦法連上網站。
我們一直無法確切找出原因，但我們最合理的理解是，偶爾出問題的是`.io`這一層，而不是 AWS 這一層。

另外，關於`io`這個頂級網域未來的所有權，以及可能帶來的後果，也有一些疑問。這些疑問源自`.io`頂級網域的起源，以及誰從中受益。
如果你想進一步了解，[這篇文章](https://gigaom.com/2014/06/30/the-dark-side-of-io-how-the-u-k-is-making-web-domain-profits-from-a-shady-cold-war-land-deal/)整理了部分資訊。

綜合以上，我們覺得搬到`.org`對我們來說是正確的一步。
這件事我們已經規劃了幾年，也覺得趁著推出 v3 的變動，正是付諸實行的好時機。
如果你討厭以上所有理由，覺得我們背叛了初衷、毫無原則、向現實低頭，那很抱歉壞了你的心情。
至於其他人，希望大家會喜歡我們的新家！
