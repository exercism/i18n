# 簡介

除了 `if` 敘述之外，JavaScript 也有 `switch` 敘述，可以依照條件來決定要執行哪些邏輯。
當你需要把單一個變數和多個不同的值做比較時，就會用到它。
比較的方式是檢查嚴格相等（`===`），詳見「比較」概念。
對某個變數 `x` 來說，JavaScript 的 `switch` 敘述語法如下。

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default` 分支是選用的；當你想要在其他選項都不符合變數時執行一些程式碼，就會用到它。

上面這些 `break` 敘述是必要的，因為在 JavaScript 裡，所有 `case` 預設都會「穿透」。
這代表如果沒有 `break` 敘述，第一個符合的選項底下所有 `case` 裡的程式碼都會被執行，即使 `x` 並不符合那些選項。
這種「預設穿透」的行為，是在 JavaScript 裡使用 `switch` 時常見的陷阱。
在函式裡，也可以改用 `return` 來取代 `break`，避免這個問題。
