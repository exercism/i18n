# 指令補充

## 例外訊息

有時候，你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做的時候，一定要附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。這能讓你的程式碼更好讀，也對除錯大有幫助。如果你知道錯誤來源會是某一種類型，可以選擇引發其中一種[內建錯誤類型](https://docs.python.org/3/library/exceptions.html#base-classes)，但還是要附上有意義的訊息。

這個練習要求你使用[`raise`敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在傳入的引數不是有效的二進位字面值時「拋出」`ValueError`。只有當你同時`raise`這個`exception`並附上訊息時，測試才會通過。

若要帶著訊息引發`ValueError`，請把訊息寫成`exception`型別的引數：

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
