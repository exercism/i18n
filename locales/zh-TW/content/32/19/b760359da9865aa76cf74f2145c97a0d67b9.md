# 簡介

R 裡的`list`是有序的項目集合，和`vectors`有以下幾點不同：

- 項目可以是不同的型態（例如把`numeric`和`character`混在一起）。
- 項目可以是複雜的結構（例如 vector、其他 list 等）。
- 存取元素時，語法會有些不同。

和其他程式語言類比並不精確。
R 的`list`有點像 Python 的字典，但`list`是有序的，而且可以用數字索引來存取。
它有點像 C 的`struct`，差別在於`list`可以在執行時輕易擴充。

## 建立 list

替元素命名（常稱為「標籤」）在 list 裡比在 vector 裡更常見：

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

不過標籤是選用的；沒有標籤時，R 就會直接用索引編號：

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## 存取 list 元素

有三種做法，各自適合不同的情境。

### 1. 使用`$tag`表示法

如果事先就知道標籤名稱，這是最常見的做法。

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. 使用`[[tag]]`表示法

這樣做的好處是，標籤名稱可以在執行時才決定。
注意這裡用的是雙重方括號。

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 使用位置索引

不論 list 有沒有標籤，這種方式都適用。
同樣地，這裡的括號是雙重的。

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 新增與刪除元素

很簡單：指定給某個元素時，若它已存在就會修改，若是新的就會插入。

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

要刪除的話，把`NULL`指定給不要的元素即可。

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
