# 關於

撰寫 Haskell 函式時，我們可以使用[模式匹配][pattern-matching]。
模式匹配是 Haskell 非常強大的功能，它允許你比對資料建構子，並將變數綁定到其中的值。
顧名思義，我們做的就是將值與模式比對；如果值符合模式，就可以將變數綁定到模式內的值。
模式匹配主要由這些概念組成：辨識值、綁定變數，以及拆解值。

~~~~exercism/note
在 Elixir 等語言中，模式匹配與 Haskell 的模式匹配有點不同。
例如 Elixir 允許在模式中出現多個相同的綁定名稱，而 Haskell 則不允許。
~~~~


以這個函式為例：

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

這裡有一個函式`lucky`，它接受一個`Int`並回傳一個`String`。
我們為這個函式定義了兩個模式：一個比對數字`7`，另一個比對任何其他數字。名稱可以是任何東西（只要符合 Haskell 的命名慣例），但這裡我們使用`x`。
如果數字是`7`，函式會回傳`"Lucky number seven!"`，否則會回傳`"Sorry, you're out of luck, pal!"`。
這裡要注意的是，模式會從上到下檢查，所以如果我們交換模式的順序，函式就會總是回傳`"Lucky number seven!"`。

## 陣列模式

一個很常見的模式是比對陣列，也就是取出陣列的頭和尾。
這是因為陣列本質上是鏈結串列。
以下是一個回傳陣列頭和尾的函式範例：

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

這裡有兩個模式：一個比對空陣列，另一個比對至少有一個元素的陣列。
這是因為如果陣列是空的，我們需要為這種情況準備一個模式，否則會發生執行時錯誤。
如果陣列不是空的，我們可以將陣列的頭比對到`x`，並將陣列的尾比對到`xs`。
這是使用`:`（cons）運算子完成的，它用來將元素加到陣列前面。
但在模式匹配中，它讓我們能將陣列拆解成頭和尾，可以說是在做相反的事。

`xs`是陣列尾端的常見名稱，它強調這是一個陣列；但如果你要處理巢狀陣列，可以使用`xss`來強調這是陣列的陣列。

## 元組模式

和陣列一樣，我們也可以比對元組。
以下是一個接受元組並回傳第一個和第二個元素的函式範例：

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

這裡有一個模式比對包含兩個元素的元組，第一個元素綁定到`x`，第二個元素綁定到`y`。

## 萬用字元模式

有時我們不在乎變數的值，只想比對模式。
這就是萬用字元模式派上用場的地方，它以底線`_`表示。

以下是一個回傳陣列第一個元素的函式範例：

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

這裡我們表示不需要陣列的尾端，所以使用萬用字元模式來忽略它。

## 型別模式

我們也可以比對型別，這是透過使用該型別的建構子來完成的。
我們也可以從型別中取出值，就像我們對元組所做的那樣。

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

在第一個模式中，我們比對`Guest`建構子；在第二個模式中，我們比對`User`建構子，並將裡面的值綁定到`name`。
