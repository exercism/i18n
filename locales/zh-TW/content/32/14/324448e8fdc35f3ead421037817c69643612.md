# 說明

在和朋友規劃遊戲之夜時，大家決定重溫童年最愛的遊戲。你的德國朋友提議玩 _Mensch ärgere Dich nicht_（_Man, Don't Get Angry_），這款遊戲在許多歐洲國家都很經典（類似英文圈的 _Ludo_ 或北美的 _Parcheesi_）。

為了準備這場遊戲，你決定用 Elixir 實作擲骰子的函式。

在 _Mensch ärgere Dich nicht_ 中，玩家擲一顆六面骰來決定下一步。如果運氣好擲出 6，就可以再擲一次並再走一步。

## 1. 擲一次六面骰

實作 `d6/0` 函式，每次呼叫時隨機選出 1 到 6 之間的一個整數。

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. 只要一直擲出 6 就一直擲下去

實作 `roll/0` 函式。它應該回傳一個骰子點數的串流。擲骰結果要遵循遊戲規則：如果擲出 6，就可以再擲一次；否則就停止擲骰。請使用上一步定義的 `d6/0` 函式。

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. 允許使用作弊骰子

為了讓你更容易測試程式碼，請允許使用作弊骰子。

擴充 `roll/0` 函式。它應該接受一個選用引數，也就是一個函式。如果傳入這個引數，就用它來擲骰；否則就退回使用 `MenschAergereDichNicht.d6/0`。

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
