# 簡介

有時候，你不需要承擔建立帶有狀態物件的額外開銷。
在這些情況下，可以使用`module`。

模組和類別非常相似（事實上，在物件階層中，`Module`是`Class`的祖先），主要差別在於，我們不用實例方法，而是用類別方法。
類別方法以`self.`開頭，並且可以直接在模組上呼叫。

例如：

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
