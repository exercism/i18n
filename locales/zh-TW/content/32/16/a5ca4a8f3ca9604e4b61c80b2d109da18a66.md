# 提示

## 一般

- 契約寫在回傳型別之後、`is`之前：

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- 契約裡可以使用引數和物件的屬性，所以`limit`也取用得到。
- 測試建置時沒有加上`-chk`，所以契約寫錯也不會讓測試失敗。契約是寫給讀者看的。

## 1. 架好安全吊帶

- 在`create`上寫`pre kg > 0`。
- 主體就是一般的`new`，設定屬性後把它回傳。

## 2. 還剩多少餘裕？

- 兩個條件用`and`連接：`pre load >= 0 and load <= limit`。
- `post result >= 0`。這點由`pre`推導而來，也正是它值得寫下來的原因：它記錄了為什麼這個答案可以被信任。

## 3. 現在有多滿？

- `pre load >= 0`和`post result >= 0`。
- `load * 100 / limit`，順序就是這樣。先做除法會把結果全部捨去，在`tuning-the-strings`裡也一樣。

## 4. 安全嗎？

- 完全沒有`pre`：重點就在於任何負載都可能被拿來問。
- `post`把這個問題重新說了一遍：`post result = (load <= limit)`。這裡要加括號，因為`=`被用來表示兩件不同的事。
