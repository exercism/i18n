# 關於

元組（tuple）通常用來非正式地將資訊分組。Elixir 中一個常見的模式，是把函式的回傳值和狀態分組在一起。

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- 元組字面值以大括號`{}`包住。
- 元組可以存放任何資料型態，內容保存在連續的記憶體中，並在建立元組時配置。
- 元組允許常數時間的讀取。
- 操作元組時，並不會修改既有的元組，而是建立一個新的。
- 元組的效能特性讓它很適合把相關的資訊存放在一起，但不適合存放需要疊代、或可能增長縮短的項目集合。如果是後者的情況，[使用陣列會更合適][getting-started-lists-or-tuples]。
- [`Kernel`][kernel-module]和[`Tuple`][tuple-module]模組提供了實用的函式來操作元組。
