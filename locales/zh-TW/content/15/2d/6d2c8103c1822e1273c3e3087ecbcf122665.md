# Representer 正規化

[JavaScript representer][github-javascript-representer] 會套用以下的正規化：

## 移除註解

所有註解都會被移除。
以下範例彼此等價：

### 含有註解的範例

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### 不含註解的範例

```javascript
function hello() {
  return 'hi there';
}
```

## 正規化空白

產生 representation 時，程式碼的*順序*很重要，但它在檔案中的實際位置不重要。
也就是說，空白會被正規化。
以下範例彼此等價：

### 使用兩個空格縮排的範例

```javascript
function hello() {
  return 'hello world';
}
```

### 使用四個空格縮排的範例

```javascript
function hello() {
  return 'hello world';
}
```

### 縮排方式特殊的範例

```javascript
function hello() {
  return 'hello world';
}
```

## 正規化識別字

識別字會被正規化成預留位置的值。

### 之前

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### 之後

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
