# 指令

在這個練習中，你會撰寫程式碼，透過國際電話區號字典來記錄各國的國際電話區號。

這個字典以整數作為鍵（電話區號），並以字串（國名）作為值。

這個練習共有 9 個任務，都會用到`DialingCodes`這個靜態類別。

## 1. 建立新的字典

實作（靜態）方法`DialingCodes.GetEmptyDictionary()`，它會回傳一個空字典。

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. 建立預先填入資料的字典

有一個預先填入資料的字典，內含以下 3 個電話區號：代碼為 1 的「United States of America」、代碼為 55 的「Brazil」，以及代碼為 91 的「India」。實作（靜態）方法`DialingCodes.GetExistingDictionary()`，回傳這個預先填入資料的字典：

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. 將國家加入空字典

實作（靜態）方法`DialingCodes.AddCountryToEmptyDictionary()`，它會建立一個字典，並在其中加入一個電話區號和對應的國名。

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. 將國家加入現有的字典

實作（靜態）方法`DialingCodes.AddCountryToExistingDictionary()`，它會將一個電話區號和對應的國名加入非空的字典中。

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. 取得與電話區號相符的國名

實作（靜態）方法`DialingCodes.GetCountryNameFromDictionary()`，它會接收一個電話區號，並回傳對應的國名。如果字典中不包含該電話區號，則回傳空字串。

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. 檢查字典中是否存在某個國家

實作（靜態）方法`DialingCodes.CheckCodeExists()`，檢查某個電話區號是否存在於字典中。

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. 更新國名

實作（靜態）方法`DialingCodes.UpdateDictionary()`，它會接收一個電話區號，並將字典中對應的國名替換為以參數傳入的國名。如果字典中不存在該電話區號，則字典保持不變。

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. 從字典中移除國家

實作（靜態）方法`DialingCodes.RemoveCountryFromDictionary()`，它會接收一個電話區號，並從字典中移除對應的紀錄（電話區號 + 國名）。

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. 找出名稱最長的國家

實作（靜態）方法`DialingCodes.FindLongestCountryName()`，它會回傳字典中所儲存名稱最長的國家名稱。

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
