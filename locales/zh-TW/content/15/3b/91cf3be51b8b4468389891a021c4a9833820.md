# 簡介

Python 內建三種不同型別的數字：整數（[`int`][int]）、浮點數（[`float`][float]）與複數（[`complex`][complex]）。
分數（[`fractions.Fraction`][fractions]）與 Decimals（[`decimal.Decimal`][decimals]）也可以從標準函式庫匯入使用。

整數，包括十六進位（[_`hex()`_][hex]）、八進位（[_`oct()`_][oct]）與二進位（[_`bin()`_][bin]）數字，只要**沒有**小數位，同樣會被視為`ints`：

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

含有小數點的數字（不論是否帶有小數部分）會被視為`floats`：

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## 算術

Python 完整支援這些不同數字型別之間的算術運算，並且在使用二元算術運算子（`+`、`-`、`*`、`/`、`//`與`%`）時，會把較窄的數字轉換成較寬的對應型別。

### 加法與減法

加法和減法運算子的行為與一般數學相同。
如果其中一個或多個運算元是`float`，其餘的`int`也會一併轉換成`float`：

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### 乘法

與加法和減法一樣，乘法會把較窄的數字轉換成較寬的對應型別：

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### 除法

除法一律回傳`float`，即使結果是整數也一樣：

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### 向下取整除法

如果你需要`int`的結果，可以使用向下取整除法來截去結果的小數部分。
向下取整除法是使用`//`運算子來完成的：

```python
>>> 6//5
1

>>> 6//2
3
```

### 取餘數

取餘數運算子（`%`）會回傳兩個運算元相除後的餘數：

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

換個角度來看 5 % 3：

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## 四捨五入

Python 有一個內建函式[`round(number, <decimal_places>)`][round]，可以將浮點數四捨五入到指定的小數位數。
如果沒有指定小數位數，數字會四捨五入到最接近的整數，並回傳`int`：

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## 優先順序與括號

Python 允許你使用括號將運算式分組。
當你想覆寫預設的運算順序時，這就很有用。

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python 遵循 [PEMDAS][pemdas] 規則來決定運算子的優先順序。
這表示`()`內的運算有最高的優先順序，其次是`**`，再來是`*`、`/`、`//`、`%`、`+`與`-`：

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## 精確度與表示方式

Python 中的整數具有[任意精度][arbitrary-precision]，其位數只受限於主機系統可用的記憶體。

浮點數通常是用 C 的`double`來實作（_精確度為 15 位小數_），但表示方式會因主機系統而異。
複數則有`real`和`imaginary`兩個部分，兩者都以浮點數表示。

如果想更深入了解各種程式語言中浮點數運算的問題與限制，可以看看 [0.30000000000000004.com][0.30000000000000004.com] 以及 [The Python Tutorial][floating point math]。
