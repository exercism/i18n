# 介紹

列舉是指逐一走訪一個集合（`Array`、`Hash` 等），並對其中的每個物件執行某些動作。

列舉是 Ruby 裡的重要概念，可以用來排序（`sort_by`）、分組（`group_by`）、映射（`map`）、縮減（`reduce`），還有很多其他用途。
走訪集合時，你最常看到的慣用寫法就是列舉，而不是使用迴圈。

一個簡單的列舉範例，使用 `map` 和 `with_index`，看起來像這樣：

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
