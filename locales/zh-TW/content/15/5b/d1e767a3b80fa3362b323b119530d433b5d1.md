# 簡介

回想一下，在基礎概念中，AWK 程式是由**模式-動作配對**組成的。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## 我們說的「模式」是什麼意思？

「模式」可以是任何 AWK 運算式。
運算式結果的真值性會決定動作是否執行。

## 空模式

模式可以省略。
在這種情況下，動作會對每一筆記錄執行。

我們可以印出 passwd 檔案中的所有使用者名稱。

```sh
awk -F: '{print $1}' /etc/passwd
```

## 正規表達式

AWK 可以將字串與正規表達式比較，以取得布林結果。

使用`~`這個正規表達式比對運算子來比對特定欄位。
這個運算子以字串作為左運算元，以正規表達式作為右運算元。
正規表達式字面值會用`/`斜線包住。

若要找出 passwd 檔案中使用 bash 登入的使用者：

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~`是「正規表達式**不**比對」運算子。

若要將正規表達式與目前記錄比對，可以寫成`$0 ~ /regex/`。
這種用法非常常見，所以有簡寫：你可以省略`$0`和`~`，直接寫`/regex/`

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
將那個 AWK 一行指令與對應的 grep 指令比較一下

```sh

```

AWK 給你完整的程式語言，又不用犧牲簡潔性。

## 運算式

AWK 運算式（算術、邏輯或其他）可以當作模式使用。

若要取出所有 UID 為 1000 以上的使用者：

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

回想一下，AWK 的 false 值是數字零和空字串，其他所有數字或字串都是 true。
任何求值結果為數字或字串的運算式都可以當作模式。

## 函式

任何[內建][builtins]或[使用者定義][user-defined]的函式都可以用在運算式中，因此也能用在模式裡。
幾個例子：

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## 常數模式

常見的 AWK 慣用語法是：

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1`是一個沒有對應動作的真值模式。
這代表「印出目前記錄」。
