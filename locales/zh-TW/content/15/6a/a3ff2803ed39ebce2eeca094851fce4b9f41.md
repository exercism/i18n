# 簡介

[`fractions`][fractions] 模組讓我們能建立並處理[`rational numbers`][rational]：分子和分母都是整數的分數。
舉例來說，我們可以把 `2/3`儲存成精確的分數，而不是近似的 `float`值`0.6666...`。

和 `int`、`float`、`complex` 不同，分數沒有字面值表示法。
不過，分數的建構子相當有彈性。

最明顯的是，它可以接受兩個整數作為引數。
公因數會自動約掉，把分數轉成「最簡形式」（_能精確表示該分數的最小整數_）：

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

分數建構子也能解析字串表示法：

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

分數也可以搭配 `float`參數運作，但由於小數值在內部是以二進位近似表示，這麼做可能會碰到問題。
想更了解這個表示法的問題，請參考 [0.30000000000000004][0.30000000000000004] 網站，以及 Python 文件中的[浮點數運算：問題與限制][fp-issues]。

如果想在用浮點數搭配分數時得到更可靠的結果，可以使用 `<fraction>.limit_denominator()`方法。


## 分數的算術運算

常見的[`arithmetic operators`][operators] `+ - * / **`也能用在分數上，就像其他數值型別一樣。

整數和其他 `Fraction`都可以放進運算式裡，並得到 `Fraction`結果。
在運算式中加入 `float`會得到 `float`輸出，因此可能損失精度：

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

許多 Python 的標準數值函式，也能給出和處理 `int`、`float` 型別時一樣的預期結果：

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
