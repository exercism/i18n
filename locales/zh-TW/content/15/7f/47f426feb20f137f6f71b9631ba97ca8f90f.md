# 提示

## 一般

- 要存取和定義實例變數，你可以寫`@`，後面接著變數的名稱。

## 1. 初始化`TaskHandler`

- 要建立`Proc`，請使用`-> (args) { block }`語法。
- 當`Proc`定義在實例變數上時，必須明確標註型別。
  做法是在變數名稱後面加上`: Proc(<arg_type>, <return_type>)`。
  或是使用`-> (arg_1 : <arg_type>) : <return_type> { block }`語法。
- 這個`Proc`應該比較引數是否大於或等於 0。

## 2. 更新任務條件邏輯

- 這個方法應該接受一個區塊作為引數，並將它指定給`@task_condition_logic`實例變數。

## 3. 執行下一個任務

- 要執行`Proc`，你可以使用`call`方法，它會接受傳給該 `Proc` 的引數。
