# 關於

有時候，當一個函式接受許多引數時，很難記住它們應該以什麼順序傳入。為了提升可讀性，Gleam 允許為引數加上名稱標籤。

若要為引數加上標籤，請把標籤名稱放在引數名稱前面，兩者以空格分隔。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

呼叫帶有標籤引數的函式時，引數可以用任意順序傳入。以下這些`replace`呼叫都是等價的：

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

標籤一律可以省略。即使函式有標籤引數，仍然可以在不使用標籤的情況下呼叫。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

定義帶有標籤引數的函式時，第一個標籤引數之後的所有引數也都必須加上標籤。

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
