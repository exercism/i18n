# 補充說明

## 測試

測試會同時執行某些操作。
你應該盡量確保對 Account 的操作能讓它維持在一致的狀態。
例如：多個 goroutine 可能同時存款和提款，而兩筆同時發生的提款不應該讓餘額變成負數。

在本機開發時，你可以測試自己的程式碼是否能正確處理並行操作，且不會產生資料競爭，只要在執行測試時加上`-race`旗標即可。

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
