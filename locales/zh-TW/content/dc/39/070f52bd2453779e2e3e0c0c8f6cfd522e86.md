# 簡介

在 Go 1.18 中，Go 加入了對**泛型**的支援。
泛型讓你撰寫能處理不同型別的函式與資料結構，而不必重複程式碼。

## 為什麼需要泛型？

在 Go 裡，函式與型別通常只處理特定的型別，例如 `int` 或 `string`。
在泛型出現之前，要支援多種型別有兩種做法。
第一種是撰寫多個不同名稱的函式，例如 `SumInts` 和 `SumFloats`。
這種做法會產生重複的程式碼，難以維護。
第二種是使用空介面 `any`（`interface{}`）。
不過，空介面會失去編譯期的型別檢查，而且必須在執行時期做型別斷言。
泛型同時提供型別安全並避免重複的程式碼，正好解決這個問題。

## 泛型函式

定義泛型函式的方式，是在函式名稱後面用方括號 `[...]` 加上**型別參數**。
以下是個泛型函式的範例，它會回傳反轉後的切片：

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

在這個範例中，`T` 是一個型別參數。
你可以把 `T` 想成真正型別的佔位符。
方括號裡的 `any` 關鍵字是一種**型別約束**。
約束告訴編譯器 `T` 允許哪些型別。
在這裡，`any` 表示 `T` 可以是任何型別。

### 呼叫泛型函式

呼叫泛型函式時，可以把實際的型別放在方括號裡傳入。
這個實際的型別稱為**型別引數**。

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

大多數情況下，Go 編譯器會從函式的引數自動判斷型別。
這個特性稱為**型別推斷**。
有了型別推斷，你就不必在方括號裡寫出型別引數。

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

在這個範例中，編譯器看出 `words` 是字串切片，因此推斷 `T` 是 `string`。

## 型別約束

每個型別參數都必須有約束。
約束指定了哪些型別可以當作型別引數。
約束也決定你能對該型別的值執行哪些運算。

### `any`約束

`any`約束允許任何型別。
在 Go 裡，`any` 是空介面 `interface{}` 的別名。
因為 `any` 允許所有型別，所以函式只能執行對所有 Go 型別都有效的運算。
例如，兩個存放切片的 `any` 值不能用 `==` 比較，因為切片無法用 `==` 比較。

### `comparable`約束

Go 內建了一個名為 `comparable` 的約束。
`comparable`約束允許任何支援 `==` 和 `!=` 運算子的型別。
可比較的型別包括布林、數字、字串、指標、通道，以及由可比較型別組成的結構體或陣列。

以下範例的函式會檢查切片中是否包含某個特定項目：

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

因為 `T` 使用了 `comparable` 約束，所以 `elem == target` 是合法的。
如果把 `comparable` 換成 `any`，編譯器就會回報錯誤。

### 使用介面型別集合的自訂約束

從 Go 1.18 開始，介面除了方法之外，還可以定義型別的集合。
你可以用直線符號 `|` 在介面中列出允許的型別。

```go
type Number interface {
    int | int64 | float64
}
```

現在你可以把 `Number` 當作函式的約束：

```go
func Double[T Number](value T) T {
    return value * 2
}
```

因為 `Number` 裡的所有型別都支援 `*` 運算子，所以 Go 允許在函式裡使用 `value * 2`。

### 底層型別近似`~`

有時你會以基本型別為基礎，建立自訂的型別定義：

```go
type MyInt int
```

上面定義的 `Number`約束只允許 `int`、`int64` 和 `float64` 這幾個確切的型別。
如果把 `MyInt` 的值傳給 `Double`，編譯器會產生錯誤，因為 `MyInt` 並不符合 `int`。
若要允許底層型別為 `int` 的任何型別，請在型別前加上波浪號 `~`：

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

現在你就可以把 `MyInt` 型別的值交給 `Double` 使用。

### `cmp.Ordered`約束

標準函式庫在 [`cmp`套件][doc-cmp] 中提供了 `cmp.Ordered`約束。
`cmp.Ordered`約束允許任何支援 `<`、`<=`、`>`和 `>=`比較運算子的型別。

## 泛型型別

型別參數也可以用來定義泛型型別，例如結構體。
以下是泛型 `Stack` 資料結構的範例：

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

宣告泛型型別的變數時，必須在方括號中提供型別引數：

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

型別推斷只適用於泛型函式。
建立泛型型別的值時，一定要明確指定型別引數。

## 什麼時候該用泛型

泛型是很強大的功能，但不是每個問題都非得用它。

以下情況適合使用泛型：
- 你要建立能處理任何元素型別的資料結構，例如樹、鏈結串列或快取。
- 你要撰寫能處理任意型別切片或映射的工具函式，例如篩選、排序或搜尋。
- 你需要對多種型別使用完全相同的實作，同時想要編譯期的型別安全。

以下情況則適合改用介面：
- 你在意的是行為與方法，而不是底層的資料型態。
  例如，若要從各種不同型別的來源（檔案、網路、TTY）讀取並處理資料，你會選用 `func Process(src io.Reader)`，而不是 `func Process[T](src T)`。
- 不同型別需要不同的方法實作才能完成工作。
