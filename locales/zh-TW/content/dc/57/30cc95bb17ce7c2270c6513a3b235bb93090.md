# 簡介

## 泛型

集合的定義通常會用角括號包住一個預留位置，依慣例通常是`T`。這樣的集合就叫做泛型。如此一來，集合的使用者就能指定要在集合裡存放哪種型別的項目。在下面的範例程式碼中，我們正在具現化一個字串陣列。

## 陣列

C# 裡的陣列是由基本型別的值，或是結構和類別的執行個體所構成的集合。它們在基底類別庫中是以`List<T>`實作的，其中`T`是陣列中項目的型別。API 提供了一組豐富的方法，可以用來建立和操作陣列。

項目可以加入陣列，也可以從陣列中移除。它們會視需要成長和縮減。

```csharp
var listOfStrings = new List<string>();
```
