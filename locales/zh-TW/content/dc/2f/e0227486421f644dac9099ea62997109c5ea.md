# 簡介

JSON 將**陣列**定義為：

> 陣列是一組有序的值。
> 陣列以`[`左方括號開始，以`]`右方括號結束。
> 值之間以`,`逗號分隔。

陣列可以包含零個或多個 _任何種類_ 的 JSON 值。
陣列元素不需要全部都是相同的型別。

## 建立陣列

使用方括號把元素收集成一個陣列。

```jq
[1, 2, 3]
```

把 _資料流_ 包在方括號裡，就能把它的元素收集成一個陣列。

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## 大小

`length`函式會回傳陣列中的元素個數。

## 索引與切片

陣列的索引從 0 開始。

用方括號運算式從陣列取出元素：
`.[2]`會取得第三個元素。

負索引會從陣列尾端往回數：
`.[-1]`會取得最後一個元素；`.[-2]`則是倒數第二個。

**切片**是陣列的子序列。
`.[10:15]`會回傳從索引 10 開始的 5 個元素；結尾索引 _不包含在內_。

還有幾個方便好用的函式：

- `first`會取得第一個元素。
- `last`會取得最後一個元素。
- `nth(n)`會取得索引`n`的元素。

## 疊代

`jq`提供了許多函式，涵蓋常見的疊代功能：

- `map(expr)`會回傳一個新陣列，其中`expr`會依序套用到每個元素。

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)`是一個函式，會把`expr`套用到 _單一值_ 上；
  如果運算式的結果為 true，就回傳該值；
  如果結果為 false，則 _什麼都不回傳_，不是`null`，而是真的什麼都沒有。

  要把它套用到陣列上，請搭配`map`一起使用。

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  或者，把`select`套用到 _資料流_ 上，再收集結果。

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)`和`all(condition)`會回傳一個布林值，表示陣列中是否有任何元素、或是全部元素都通過該條件。

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
