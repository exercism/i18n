# 安裝

有別於許多其他程式語言，Pyret 不需要你全域安裝這個語言。相反的，Pyret 的開發者將他們的編譯器以 [npm 套件][pyret-npm]的形式提供。你會在每個練習中使用`npm`安裝 Pyret：更多細節會放在[測試][tests]頁面。

你需要安裝 Node.js，它是一個 JavaScript 執行環境。在 [Node.js 下載][download]頁面上，記得選擇`npm`作為套件管理器。

~~~~exercism/note
目前 pyret-npm 套件只相容於 Linux 和 MacOS。Windows 使用者需要使用 WSL 或虛擬機器來安裝 pyret-npm。
~~~~
