# 簡介

## 標記引數

有時候，一個函式接受很多引數時，很難記住它們該以什麼順序傳入。為了提升可讀性，Gleam 允許用名稱來標記引數。

要標記一個引數，請把標籤名稱寫在引數名稱前面，並用一個空格隔開。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

呼叫帶有標記引數的函式時，引數可以用任何順序傳入。底下這幾種`replace`的呼叫方式都是等價的：

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

標籤永遠是選用的。即使函式有標記引數，呼叫時仍然可以不寫標籤。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
