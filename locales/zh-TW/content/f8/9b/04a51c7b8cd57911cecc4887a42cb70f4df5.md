# 關於

C# 有 3 種浮點數型別：`double`、`float`和`decimal`。最常使用的型別是`double`，而`decimal`通常用於處理貨幣資料。`double`寫成`2.45`或`2.45d`，`float`寫成`2.45f`，而`decimal`寫成`2.45m`。

每種浮點數型別都有自己的[精確度、近似範圍與大小][docs-microsoft.com-characteristics-of-the-floating-point-types]。

浮點數型別之間的某些轉換是[自動（隱式）][docs-microsoft.com-implicit-numeric-conversion]，但其他則是[手動（明確）][docs-microsoft.com-explicit-numeric-conversion]。

```csharp
decimal account = 125m * (decimal)1.2f;
```

檢查浮點數型別的值是否相等時，請務必小心，因為看似代表相同值的值實際上可能不同。更多資訊請參閱[這篇文章][docs.microsoft.com_precision-in-comparisons]。

你可以在 [0.30000000000000004.com][0.30000000000000004.com] 找到浮點數的簡短介紹。[Float Toy 頁面][evanw.github.io-float-toy]有很棒的圖解說明，解釋浮點數的位元如何轉換成實際的浮點值。
