# 說明

身為準魔術師的 Elyse，需要練習一些基本功。她有一個牌堆，想要好好操作一番。

為了方便一些，她只用編號 1 到 10 的卡片，所以她的牌堆可以用一個數字向量來表示。每張卡片的位置對應到向量中的索引。

## 1. 從牌堆取出一張卡片

若要取出一張卡片，請回傳給定牌堆中索引`position`的卡片。

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. 替換牌堆中的一張卡片

施展一點手法，把索引`position`的卡片換成所提供的替代卡片。回傳調整後的牌堆。

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. 在牌堆頂端插入一張卡片

在牌堆頂端插入一張新卡片，讓它出現。回傳調整後的牌堆。

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. 從牌堆移除一張卡片

從牌堆移除給定`position`的卡片，讓它消失。回傳調整後的牌堆。

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. 檢查牌堆大小

檢查牌堆的大小是否等於`stack_size`。

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. 從牌堆移除最上面的卡片

移除牌堆最上面的卡片，讓它消失。回傳調整後的牌堆。

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. 在牌堆底部插入一張卡片

在牌堆底部插入一張新卡片，讓它出現。回傳調整後的牌堆。

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. 從牌堆底部移除一張卡片

移除牌堆底部的卡片，讓它消失。回傳調整後的牌堆。

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
