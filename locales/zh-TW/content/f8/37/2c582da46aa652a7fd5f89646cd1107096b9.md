# Luhn 的概念

Luhn 是一種驗證演算法，結合了文字與數字斷言。Rust 解法偏好函式風格。

## 一般

### 基本型別

- `&str`和`char`
  - 學生必須掌握個別`char`與`&str`的區別，才能正確排除或納入輸入內容的部分。
- 整數
  - 理解整數對於執行必要的數字驗證很重要。
- 布林值
  - 對於真值斷言與最終比較不可或缺。

### 迭代器特性

- 鏈式呼叫
  - 在這裡，理解迭代器鏈式呼叫很重要，才能以依序的方式解決問題。
- `map`、`filter`、turbofish，可能還有`fold`
  - 結合`map`和`filter`能為這類驗證問題提供基礎的設計模式。`fold`解法也更為簡潔。
  - 有些解法需要使用 turbofish，來告訴 Rust 你從鏈式運算式建立的是什麼型別。

## 範例解法 1

york 的[解法](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## 範例解法 2

標準解法

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
