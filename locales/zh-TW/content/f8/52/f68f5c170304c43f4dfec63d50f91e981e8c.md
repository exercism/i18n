# 簡介

JavaScript 是一種動態語言，支援物件導向、指令式，以及宣告式（例如函式程式設計）等各種風格。

## 變數

在 JavaScript 中，有幾種主要的方式可以把值指定給名稱：使用變數或常數。
在 Exercism，變數一律以 [camelCase][wiki-camel-case] 撰寫；常數則以 [SCREAMING_SNAKE_CASE][wiki-snake-case] 撰寫。
這件事沒有官方指南可循，各家公司和組織也有各自的風格指南。
_你可以自由選擇要用什麼方式撰寫變數_。
按照練習題準備的方式來寫變數，好處是它們在網頁介面和大多數 IDE 中會以不同的方式標示。

JavaScript 中的變數可以用 [`const`][mdn-const]、[`let`][mdn-let] 或 [`var`][mdn-var] 關鍵字來定義。

使用 `let` 或 `var` 時，一個變數在其生命週期內可以參照不同的值。
例如，`myFirstVariable` 可以用賦值運算子 `=` 定義並重新定義許多次：

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

與 `let` 和 `var` 相反，用 `const` 定義的變數只能被指定一次。
在 JavaScript 中，這用來定義常數。

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## 函式宣告

在 JavaScript 中，功能單位會封裝在_函式_裡；如果幾個函式屬於同一組，通常會把它們放在同一個檔案中。
這些函式有參數（因此可以接受引數），並且可以用 `return` 關鍵字_回傳_一個值。
函式透過 `()` 語法來呼叫。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

在這個例子中，函式名稱是 `add`。
它有兩個參數：`num1` 和 `num2`。
它會回傳一個值：運算式 `num1 + num2` 的結果

接著，函式 `add` 會用兩個引數_呼叫_：`1` 和 `3`。
函式的結果，也就是回傳值，是 `4`。

```exercism/note
💡 在 JavaScript 中，宣告函式有_許多_不同的方式。
其中有些方式看起來和用 `function` 關鍵字不一樣。
這個學習軌道會試著逐步介紹它們，但如果你已經認識它們，也歡迎使用任何一種。
大多數情況下，用哪一種都不會更好或更差。
```

## 對其他檔案公開

要讓一個 `function`、常數或變數能在_其他檔案_中使用，必須用 `export` 關鍵字將它們[匯出][mdn-export]。
接著，另一個檔案可以用 `import` 關鍵字[匯入][mdn-import]它們。
這也稱為模組系統。

所有測試的運作方式就是一個很好的例子。
每個練習至少有一個檔案，例如 `lasagna.js`，其中包含_實作_。
_實作_會從該檔案被 `export` 出去，讓它可以在另一個檔案中被匯入。
此外，至少還有一個其他檔案，例如 `lasagna.spec.js`，其中包含_測試_。
這個檔案會 `import` 公開的（也就是被 `export` 的）實體，以便測試實作：

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
