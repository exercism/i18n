# 指令

瑪莉是電視影集 _Star Trek: The Next Generation_ 的忠實粉絲。她經常玩紙筆角色扮演遊戲，在遊戲中她和朋友們會假扮成 _Starship Enterprise_ 的船員。瑪莉的角色是 Captain Picard，這表示她必須寫艦長日誌。她很喜歡遊戲中發揮創意的部分，但不喜歡臨時憑空生出隨機資料。

幫瑪莉建立隨機產生器，用來產生艦長日誌中常見的資料吧。

## 1. 產生隨機的行星

_Starship Enterprise_ 在航行途中會遇到許多行星。在 Star Trek 宇宙中，行星會依其特性分成不同等級。例如，地球是 M 級行星。所有可能的行星等級有：D、H、J、K、L、M、N、R、T 和 Y。

實作`random_planet_class/0`函式，它應該隨機回傳其中一個行星等級。

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. 產生隨機的星艦註冊編號

Enterprise（註冊編號 NCC-1701）可不是唯一在宇宙中飛行的星艦喔！當它與另一艘星艦會合時，瑪莉需要記錄那艘星艦的註冊編號。

註冊編號以「NCC-」為開頭，後面接著 1000 到 9999（含）之間的數字。

實作`random_ship_registry_number/0`函式，回傳隨機的星艦註冊編號。

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. 產生隨機的星曆

如果日誌不記錄日期，那還有什麼用呢？

星曆是浮點數。_Starship Enterprise_ 在 _The Next Generation_ 第一季的冒險，發生在星曆 41000.0 到 42000.0 之間。「4」代表第 24 世紀，「1」代表第一季。

實作`random_stardate/0`函式，回傳介於 41000.0（含）與 42000.0（不含）之間的浮點數。

實作時應該使用 Erlang 函式。

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. 格式化星曆

在艦長日誌中，星曆通常會四捨五入到小數點後一位。

實作`format_stardate/1`函式，它會接收一個浮點數，並回傳將該數字四捨五入到小數點後一位的字串。

實作時應該使用 Erlang 函式。

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
