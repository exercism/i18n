# 關於

函式可以為一個或多個引數宣告[預設值][default-arguments]。

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- 編譯上述範例時，Elixir 會為 `number/0`（沒有引數）與 `number/1`（一個引數）建立函式定義。
- 如果有多個引數帶有預設值，這些預設值會由左至右套用到函式上，補足缺少的引數。
- 如果函式有多個子句，就必須為預設引數撰寫[函式標頭][function-header]。
- 任何運算式都可以作為預設值。
- 匿名函式不能有預設引數。

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
