# Char

`Char` 是 Crystal 中的一種資料型態，代表一個 32 位元的 [Unicode][unicode] 碼位。
它的大小讓它在記憶體上很有效率，也帶來一些字串沒有的特性。
Char 使用單引號（`'`）建立，而且裡面只能放一個 Unicode 碼位。

```crystal
'a' # => 'a'
'a'.class # => Char
```

在 Crystal 中處理字串時，經常會用到 Char，因為 String 類別裡有不少方法會回傳 Char，或把 Char 當作引數。
例如，[`String#[]`][index] 方法會回傳一個 Char，而 [`String#chars`][chars] 方法則會回傳一組 Char。

## 遞增與遞減

因為 Char 是一個 32 位元的 Unicode 碼位，所以支援遞增和遞減；也就是說，如果你有`'a'`，加一就能得到`'b'`。

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

另外還有個名為 [`Char#succ`][succ] 的方法，會回傳 Unicode 表中的下一個字元；以及 [`Char#pred`][pred]，會回傳 Unicode 表中的前一個字元。

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 串接

由於 Char 只用來表示一個 32 位元的 Unicode 碼位，所以兩個 Char 不能串接在一起。
因此，Char 只能和字串串接。

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 屬性方法

Crystal 有幾個方法可以取得字元的相關資訊，例如它是不是數字、是不是字母，或是不是大寫、小寫。
以下是其中一些方法的清單，完整清單請見 [Char API][char-api]：

| 方法                             | 說明                                                 |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | 如果這個 Char 是數字，回傳`true`                     |
| [`Char#letter?`][letter]         | 如果這個 Char 是字母，回傳`true`                     |
| [`Char#lowercase?`][lowercase]   | 如果這個 Char 是小寫，回傳`true`                     |
| [`Char#uppercase?`][uppercase]   | 如果這個 Char 是大寫，回傳`true`                     |
| [`Char#ascii?`][ascii]           | 如果這個 Char 是 ASCII 字元，回傳`true`              |
| [`Char#whitespace?`][whitespace] | 如果這個 Char 是空白字元，回傳`true`                 |

## 轉換

### 在碼位與 Char 之間轉換

由於 Char 是一個 32 位元的 Unicode 碼位，你可以在 Char 和碼位（Int）之間轉換。
這可以用 [`Char#ord`][ord] 方法做到，它會回傳該 Char 的碼位；也可以用 [`Int#chr`][chr] 方法，它會回傳該碼位對應的 Char。

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 在型別之間轉換

和其他資料型態一樣，Char 也有幾個可以在型別之間轉換的方法。
最常見的是 `Char#to_s` 方法，會把 Char 轉成字串。此外還有 `Char#to_i` 方法，會把 Char 轉成 Int；以及 `Char#to_f` 方法，會把 Char 轉成 Float。

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## 跳脫

和字串一樣，有些字元無法直接寫出來，必須使用跳脫序列才能寫。
你可以用 `\` 字元寫出跳脫序列，後面接著你想跳脫的字元。

以下是 Crystal 中的特殊字元：

| 值       | 說明                          |
| -------- | ----------------------------- |
| `\a`     | 警鈴                          |
| `\b`     | 退格                          |
| `\e`     | 跳脫                          |
| `\f`     | 換頁                          |
| `\n`     | 換行                          |
| `\r`     | 歸位                          |
| `\t`     | 水平定位字元                  |
| `\v`     | 垂直定位字元                  |
| `\\`     | 反斜線                        |
| `\'`     | 單引號                        |
| `\"`     | 雙引號                        |
| `\377`   | 八進位 ASCII 字元             |
| `\xFF`   | 十六進位 ASCII 字元           |
| `\uFFFF` | 十六進位 Unicode 字元         |
