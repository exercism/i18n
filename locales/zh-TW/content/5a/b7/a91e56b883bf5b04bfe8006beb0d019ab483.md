# 簡介

## R 中的布林值

真或假的值由`logical`型別表示。
它只包含兩個值：`TRUE`和`FALSE`。

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 布林運算子

R 裡有 5 個布林運算子，但在課程大綱的這個階段，只有 3 個會用到。
另外 2 個在處理向量時會很重要，之後的幾個概念裡會再介紹到。

`&&`是布林運算的「且」。
如果`&&`*兩側*的運算式都是`TRUE`，它就會求值為`TRUE`。

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||`是布林運算的「或」。
如果`||`*任一側*的運算式是`TRUE`，它就會求值為`TRUE`。

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!`是布林運算的「非」。
它會把`TRUE`和`FALSE`的值互換。

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

運算式比較長、比較複雜時，最好用括號把你的意圖表達清楚。

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
