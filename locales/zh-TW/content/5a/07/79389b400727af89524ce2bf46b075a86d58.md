# 關於

除了`if`敘述之外，還有`switch`敘述可以依照條件執行不同的邏輯。當單一變數需要和多個不同的值比較時，就會用到它。對某個變數 x 來說，Haxe 的 switch 敘述語法如下。

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

當其他分支都不符合時，就會執行`default`分支。
