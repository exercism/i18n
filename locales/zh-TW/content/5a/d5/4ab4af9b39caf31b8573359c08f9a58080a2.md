# 指令

你的任務是找出完美的桌位安排。
你需要透過宣告_事實_（永遠為真的事物）和_規則_（有條件為真的事物）來完成。

## 1. 列出愛聊天的人

定義 `chatty` 事實來代表愛聊天的人。
`chatty` 事實接受單一引數：愛聊天的人的小寫名字。

```prolog
chatty(gustavo).
true.
```

## 2. 列出誰喜歡誰

定義 `likes` 事實來代表誰喜歡誰。
`likes` 事實接受兩個引數：

1. 喜歡對方的人的小寫名字
2. 被喜歡的人的小寫名字

```prolog
likes(esteban, malena).
true.
```

## 3. 互相喜歡的人能組成好的一對

定義 `pairing` 規則：當兩個人互相喜歡時為真。
pairing 規則接受兩個引數：

1. 第一個人的小寫名字
2. 第二個人的小寫名字

```prolog
pairing(malena, esteban).
true.
```

## 4. 愛聊天的人可以和任何人配對

定義 `pairing` 規則：當被配對的兩個人中（至少）有一個愛聊天時為真。

```prolog
pairing(valeria, jaime).
true.
```

## 5. 檢查座位安排

定義 `seating` 規則：當五組配對都是好的配對時為真。

pairing 規則接受五個引數：

1. 第一個人的小寫名字
2. 第二個人的小寫名字
3. 第三個人的小寫名字
4. 第四個人的小寫名字
5. 第五個人的小寫名字

使用剛才定義的事實和規則來檢查座位安排。

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
