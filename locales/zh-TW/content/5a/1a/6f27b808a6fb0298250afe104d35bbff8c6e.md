# 複製 ABAP 軌道

## 前置需求

1. ABAP 系統版本 7.4 或以上
2. abapGit v1.115.0 或以上
3. 可實作 ABAP 套件、程式與類別的權限

## 安裝 abapGit

整條 ABAP 軌道與所有練習都實作在一個 abapGit 儲存庫裡。要把軌道複製到自己的系統，你必須先安裝 abapGit。

1. 前往 [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. 下載`zabapgit_standalone.prog.abap`檔案
3. 在自己的系統中建立程式`zabapgit_standalone`
4. 將`zabapgit_standalone.prog.abap`裡的原始碼上傳到程式`zabapgit_standalone`
5. 啟用這個程式

## 安裝 Exercism ABAP 軌道

### 線上儲存庫

如果你的系統能連上網際網路，也可以存取 GitHub.com，請用這個方法（建議做法）。

1. 執行 abapGit

![abapGit 線上儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. 在「Repository Overview」中選擇「New Online」
3. 輸入以下值
- URL：`https://github.com/exercism/abap`
- Package：`$exer`
- Display Name：`Exercism - ABAP Track`

注意：如果套件名稱太長，例如`$exercism`，匯入儲存庫時就會發生錯誤。請照上面所說，讓名稱保持簡短。

![abapGit 線上儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. 選擇「Create Online Repository」。你應該會看到一份物件清單，狀態都是「A」：

![abapGit 線上儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. 選擇「Pull」，把所有物件複製到你的系統。完成後，你應該會看到所有物件的狀態都是空白的

![abapGit 線上儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### 離線儲存庫

如果你的系統*沒有*連上網際網路，請用這個方法。

1. 前往 [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. 下載儲存庫的 ZIP 檔案

![abapGit 離線儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. 執行 abapGit
4. 在「Repository Overview」中選擇「New Offline」
5. 輸入以下值
- Repository Name：`Exercism - ABAP Track`
- Package：`$exer`

![abapGit 離線儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. 選擇「Create Offline Repository」

![abapGit 離線儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. 選擇「Import ZIP」，然後挑選剛才下載的 ZIP 檔案。你應該會看到一份物件清單，狀態都是「A」：

![abapGit 離線儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. 選擇「Pull ZIP」，把所有物件複製到你的系統。完成後，你應該會看到所有物件的狀態都是空白的

![abapGit 離線儲存庫](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## 解除安裝 Exercism ABAP 軌道

你可以用以下方式把系統中的所有物件移除：

1. 執行 abapGit
2. 前往`Execism - ABAP Track`儲存庫
3. 選擇「Advanced > Uninstall」
4. 確認刪除所有物件與該儲存庫

## 疑難排解

- 如果遇到連線問題，請檢查 [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- 如果出現錯誤`Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`，請改用短一點的套件名稱，例如`$exer`。
- 有些檔案在提取到你的 ABAP 系統後會顯示差異。與檔案結尾字元或位元組順序標記有關的差異可以忽略。
