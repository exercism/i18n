# 指令

在這個練習中，你將會撰寫程式碼，分析汽車工廠裡一條組裝線的生產狀況。組裝線的速度範圍可以從`0`（關閉）到`10`（最高）。

在最低速度（`1`）下，每小時會生產`221`輛車。產量會隨速度呈線性增加。所以當速度設為`4`時，每小時應該會生產`4 * 221 = 884`輛車。不過，速度越高，就越可能生產出瑕疵車，而這些車之後必須被丟棄。下表顯示速度如何影響成功率：

- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

你有兩項任務。

## 1. 計算每小時的產量

實作`CarsAssemble.productionRatePerHour()`方法，計算組裝線每小時的產量，並將組裝線目前的速度與成功率納入考量：

```Java
CarsAssemble.productionRatePerHour(6)
// => 1193.4
```

請注意，回傳的值是`double`。

## 2. 計算每分鐘生產的正常運作車輛數量

實作`CarsAssemble.workingItemsPerMinute()`方法，計算每分鐘生產多少輛正常運作的車：

```Java
CarsAssemble.workingItemsPerMinute(6)
// => 19
```

請注意，回傳的值是`int`。
