# 簡介

區塊是一組敘述與宣告，被群組成一个語法單位。
區塊通常定義在大括號內，但並非總是如此。
區塊可以巢狀在函式裡，也可以巢狀在其他區塊裡。

函式的行為有點像區塊。
定義在函式裡的變數，其識別字在函式外看不見，就像定義在區塊裡的變數，其識別字在區塊外也看不見一樣。
兩個函式裡的兩個變數可以同名，因為這兩個函式看不進彼此的內部；同樣地，兩個區塊裡的兩個變數也可以同名，因為這兩個區塊也看不進彼此的內部。
但函式和區塊並不完全相同。
函式不能巢狀在另一個函式裡，但區塊可以巢狀在另一個區塊裡。

在下面的範例中，`number`定義在`main`函式裡。
`flag`定義在`if`區塊裡，而這個區塊巢狀在`main`函式中。
定義在區塊裡的變數只在该區塊內有效。
因此，嘗試編譯這段程式碼會導致編譯錯誤。

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

這個錯誤訊息可能會讓人困惑，因為`flag`在函式中確實有被使用過。
然而，`flag`定義在函式內部的某個區塊裡。
內層區塊可以「看見」外層函式中的變數`number`，但外層函式看不見定義在內層區塊裡的`flag`變數。
一旦執行離開這個區塊，`flag`變數就會自動被銷毀，程式再也無法使用它。
`main`函式本身是在最後一個`printf`敘述中才第一次看見`flag`這個識別字。
如果把最後一個`printf`敘述移除，程式就能順利編譯，執行時會印出`1`。
這是因為`flag`變數在包含第一個`printf`敘述的區塊裡是有效的。

從`C99`開始，單行的`if`、`for`、`while`和`do`敘述也算是一種區塊。
在下面的範例中，雖然`i`不是定義在大括號內，但它只存在於`for`敘述所定義的區塊裡，外層的`main`函式看不見它。

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

如果把最後一個`printf`敘述移除，程式就能順利編譯，執行時會印出`0 2 4 6 8 10 `。
有些語言，例如 Go 和 Rust，明確規定單行的條件式和迴圈敘述就構成一個區塊。
它們要求這類單行敘述仍然要用大括號括起來。
