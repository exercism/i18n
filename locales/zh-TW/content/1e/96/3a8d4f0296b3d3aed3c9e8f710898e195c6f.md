# 指令

在這個練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出一份超棒的千層麵。

你有三個任務，都跟烹調千層麵所花費的時間有關。

## 1. 定義千層麵預期的烤箱時間（分鐘）

定義`expectedMinutesInOven`常數，用來確認千層麵應該在烤箱裡烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```Haskell
expectedMinutesInOven
    --> 40
```

## 2. 計算準備時間（分鐘）

定義`preparationTimeInMinutes`函式，它接受你加進千層麵的層數作為參數，並回傳你準備千層麵花了幾分鐘，假設每一層需要 2 分鐘準備。

```Haskell
preparationTimeInMinutes 3
    --> 6
```

## 3. 計算經過的時間（分鐘）

定義`elapsedTimeInMinutes`函式，它接受兩個參數：第一個參數是你加進千層麵的層數，第二個參數是千層麵已經在烤箱裡待了幾分鐘。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間加上千層麵目前待在烤箱裡的時間。

```Haskell
elapsedTimeInMinutes 3 20
    --> 26
```
