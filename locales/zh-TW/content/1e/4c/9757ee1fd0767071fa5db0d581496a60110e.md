# 關於

Swift 提供三種主要的迴圈結構：

- **`while` 迴圈**：只要指定的條件維持為 `true`，就重複執行程式區塊。條件會在執行迴圈本體之前先評估。
- **`repeat-while` 迴圈**：和 `while` 迴圈類似，但條件是在執行迴圈本體之後才評估。這保證迴圈本體至少會執行一次。
- **`for-in` 迴圈**：對序列或集合（例如範圍、陣列或字串）中的每個元素執行一次程式區塊。
