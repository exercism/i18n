# 提示

## 一般

- 所有清理用的詞彙都放在[`destructors`][destructors]裡。
- `:>`和`::`（區域變數）能讓多幫浦的主體保持易讀，如果你會用到它們，記得把`locals`加進`USING:`喔。

## 1. 排出艙底污水

- 一個詞彙：`dispose`。

## 2. 抽水常式

- 一個詞彙：`with-disposal`。在結尾的`;`後面加上`inline`，讓編譯器能看穿傳入的引述：`: pump-out ( pump quot -- ) with-disposal ; inline`。

## 3. 整個班次的常式

- 用`with-destructors`開啟作用域。在裡面用`&dispose`註冊每個幫浦，然後`call`這個引述。使用區域變數時：`[ pump-a &dispose pump-b &dispose quot call ] with-destructors`。

## 4. 有風險的抽水

- 和第 3 個任務形狀相同，但對單一幫浦改用`|dispose`（僅在失敗時）。

## 5. 自訂的可處置物件：閥門

- `TUPLE: valve < disposable is-open ;`：`<`會擴充`disposable`，因此會繼承框架的機制。
- `<valve>`使用`new-disposable`（而不是單純的`new`），這樣新的閥門才會註冊到框架中。
- `M: valve dispose*`就是你的清理掛鉤。在堆疊上不留下任何東西很重要：`>>is-open`會把元組留在最頂端，所以記得用`drop`收尾。

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
