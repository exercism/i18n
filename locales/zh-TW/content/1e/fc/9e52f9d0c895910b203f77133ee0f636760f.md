# 簡介

R 沒有獨立的[集合][wiki-set]型別，而是用各種函式對向量執行類似的操作。

[`%in%`][ref-match]運算子用來測試集合成員資格。這個中置運算子與函式`is.element()`同義。

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

相關的函式包括：

- [`unique()`][ref-unique]：移除重複的值。
- [`union()`][ref-sets]：合併集合（數學上記作 `A ∪ B`）。
- [`intersect()`][ref-sets]：找出兩個集合共有的元素（`A ∩ B`）。
- [`setdiff()`][ref-sets]：從一個集合減去另一個集合（`A - B`）。
- [`setequal`][ref-sets]：測試兩個集合是否相等，忽略重複的值與順序。

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

在每個情況下，函式都會回傳一份複本，且不會更動原本的引數。

## 雜湊表

上面介紹的向量操作屬於 base R 的一部分。這些操作在處理小問題時很好用，但面對大型集合時就會變慢。

各種第三方套件實作了[雜湊表][wiki-hash]，以在某些情境下提升效能。

舉例來說，[`hashtable`][ref-hashtable]套件提供了 `hashmap` 與 `hashset` 的實作，在處理大量資料時能有更好的擴展性。

和大多數外部套件一樣，Exercism 裡無法使用它，但值得在解決真實世界的問題時研究看看。
