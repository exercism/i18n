# 簡介

## 溢位

當某個運算（例如算術運算或型別轉換）產生的值大於接收型別的容量時，就會發生算術溢位。

型別為`int`和`long`的運算式，以及它們對應的無號版本，在這種情況下都會悄悄地回繞。

整數運算的行為可以透過`checked`關鍵字來改變。當`checked`區塊內發生溢位時，會擲回`OverflowException`的執行個體。

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

型別為`float`和`double`的運算式會取用無限大這個特殊值。

型別為`decimal`的運算式則會擲回`OverflowException`的執行個體。
