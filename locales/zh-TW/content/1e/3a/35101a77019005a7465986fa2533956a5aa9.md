# 說明補充

## 用於 `.to_string()` 的 Rust trait

你還需要為 `Clock` struct 實作 `.to_string()`。我們會用它來顯示 `Clock` 的狀態。你可以直接實作，也可以使用 [Display trait][display-trait]。

若是如此，不妨改為替 `Clock` 實作 [Display trait][display-trait] 吧。

trait 讓我們能以一致的方式，為各種型別實作功能。

如果想多學一點，可以想想如何為 `Clock` 型別實作 `String::from`。你不必真的去實作它，它與 `Display` 是重複的，而當目標型別是 `String` 時，`Display` 通常是更好的選擇。不過，讓自己的工具箱裡多幾個型別轉換的 trait 也很有用喔。

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
