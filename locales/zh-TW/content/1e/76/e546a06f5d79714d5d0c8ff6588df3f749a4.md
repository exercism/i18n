# 指令補充

## 例外訊息

有時候，你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓程式碼更好讀，對除錯也有很大的幫助。如果你已知錯誤來源屬於某種類型，可以選擇引發其中一種[內建錯誤類型](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習要求你在傳入 `slice()` 函式的 series 和／或 length 參數為空或超出範圍時，使用 [raise 陳述式](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)「拋出」`ValueError`。只有同時 `raise` 例外並附上訊息，測試才會通過。

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception` 類型的引數：

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
