# 指示

你受 Isaac's Asteroid Exploration Co. 的產權申請部門指派，要改善他們土地申請系統的效能。

每當有小行星準備好可供開發，投機客就會受邀前來圈選一塊土地。
小行星的土地會劃分成互不重疊的長方形地塊。
每塊地塊的尺寸不一，但各邊都與座標軸平行。
投機客只要指定座標，就能圈選其中一塊地塊。

你的目標是開發一套高效能的系統，來處理這股搶地熱潮。這股熱潮過去曾導致網站當機。

測量單位是 100 公尺，但在這些任務中可以忽略。

## 1. 定義一個點

定義一個 `struct` 來存放 `x` 和 `y` 座標。
這些都是相當小的非負整數，所以請使用 `UInt16` 型別。

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. 定義一個地塊

由於所有地塊都必須是長方形，且邊只能是水平或垂直，因此只要兩個相對的角就能定義一個地塊。

實作 `Plot` struct，並讓它的建構函式接收兩個 Coord struct。

`Plot` 應該是關鍵字 struct，欄位為 `bottom_left` 和 `top_right`。

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. 檢查你的申請是否已經登記過了

這些申請競爭激烈，所以在你的申請被允許之前，會先和登記冊中既有的申請比對。

實作 `is_claim_staked()` 函式，判斷某筆申請是否已經被圈選過。

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. 投機客指定由角落座標標示的地塊，就能圈選自己的申請

實作 `stake_claim!()` 這個會變更狀態的函式，讓申請能夠被登記。

如果同一筆申請已經被圈選過，就回傳 `false`。

如果這是筆新申請，就把它加入登記冊並回傳 `true`。

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. 找出地塊較長邊的長度

實作 `get_longest_side()` 函式，取得某筆申請較長的那條邊（水平或垂直）。

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. 為了研究用途，找出邊最長的那塊申請地塊

實作 `get_claim_with_longest_side()` 函式，檢查所有已登記的申請，並回傳邊最長的那筆申請。

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

以 `Set` 回傳 Plot；如果邊最長的地塊只有一個，就回傳一個元素，如果並列，就回傳多個。
