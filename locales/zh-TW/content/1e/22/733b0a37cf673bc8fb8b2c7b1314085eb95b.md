# 關於

## 位元運算

位元運算讓我們可以操作二進位數字中的個別位數。
這些運算是計算的基礎，提供有效率的方式來執行低階工作，例如控制記憶體中的特定位元、最佳化數學運算、加密、通訊，以及資料的編碼與解碼。

### 了解 Elm 中的 32 位元整數

在 Elm 中，整數會以[二補數](https://en.wikipedia.org/wiki/Two%27s_complement)表示法儲存成 32 位元有號整數，也就是用 32 個二進位位數（_位元_）來儲存每個整數值。
這個位元上限會影響 Elm 能直接表示的整數範圍：

正數範圍：0 到 2<sup>31</sup> - 1（或 0 到 2,147,483,647）
負數範圍：-2<sup>31</sup> 到 -1（或 -2,147,483,648 到 -1）。

例如，整數`5`以二進位表示為`00000000000000000000000000000101`，不過我們通常會省略開頭的零，直接寫成`101`。

### 位元運算

Elm 在其 [Bitwise 模組](https://package.elm-lang.org/packages/elm/core/latest/Bitwise) 中提供了幾個位元運算子。

## 基本運算

修改數字中的個別位元稱為_遮罩_。
_遮罩_是一個數字，其中特定的位元以特定方式設定，用來透過`and`、`or`和`xor`等位元運算子操作另一個數字。

### and

`and`會結合兩個數字，只保留兩者中都是`1`的位元。
這在檢查某個位元是否被設定時很有用。
例如，要檢查某個數字的第 4 個位元是否設為`1`，將它與遮罩`01000`（十進位的`8`）做`and`運算，然後看看結果是否不為零：

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or`會結合兩個數字，只要某個位元在其中任一個或兩個數字中是`1`，就把它設為`1`。
這在把特定位元設為`1`時很有用。
例如，要設定`10101`中的第 2 個位元，將它與遮罩`00010`做`or`運算：

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### 互斥或（xor）

`xor`會結合兩個數字，只要某個位元在一個數字中是`1`、在另一個數字中是`0`，就把它設為`1`。
這在把位元翻轉成相反值時很有用：

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### 補數

`complement`會反轉數字中的每個位元（`0`變成`1`，`1`變成`0`）。

請注意，這會讓正數變成負數，負數變成正數。
這是因為負數在二進位中會以最左邊的位置為`1`來表示。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### 位元移位

以下運算子會把位元向左或向右移動指定的位置數，效果等同於乘以或除以 2 的次方。

`shiftLeftBy`會把位元向左移動，並從右側補`0`。
例如，把`21`向左移 3 個位置：

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

這等同於`21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`：把位元向右移動：

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

向右移 2 個位置等同於整數除以 4。

請注意，這個函式會複製最左邊位元的值。
所以，負數會保持為負數：

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

如果你想向右移位並補零，請使用`shiftRightZfBy`：

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
