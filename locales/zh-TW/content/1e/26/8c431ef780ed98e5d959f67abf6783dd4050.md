# 提示

## 一般

- 你需要讓函式[對其他檔案可見][global]。
- [NASM 文件][interfacing]說明了函式的引數如何傳遞，以及回傳值如何取得。

## 1. 定義預期的烤箱時間（分鐘）

- 你需要讓函式[對其他檔案可見][global]。
- [NASM 文件][interfacing]說明了函式的引數如何傳遞，以及回傳值如何取得。
- 有一道[指令][mov]可以將值存入暫存器。
- 你可以使用`equ`定義組譯時期的常數。

## 2. 計算剩餘的烤箱時間（分鐘）

- 你需要讓函式[對其他檔案可見][global]。
- [NASM 文件][interfacing]說明了函式的引數如何傳遞，以及回傳值如何取得。
- 你可以[呼叫][call]先前定義過的其他函式。
- 有一道[指令][sub]可以將數值相減。

## 3. 計算準備時間（分鐘）

- 你需要讓函式[對其他檔案可見][global]。
- [NASM 文件][interfacing]說明了函式的引數如何傳遞，以及回傳值如何取得。
- 有一道[指令][imul]可以將數值相乘。

## 4. 計算經過的時間（分鐘）

- 你需要讓函式[對其他檔案可見][global]。
- [NASM 文件][interfacing]說明了函式的引數如何傳遞，以及回傳值如何取得。
- 你可以[呼叫][call]先前定義過的其他函式。
- 有一道[指令][add]可以將數值相加。
