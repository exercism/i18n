# 簡介

當 Elixir 解析要呼叫的函式時，會使用模組的名稱來查詢。如果模組的名稱綁定到變數，這個查詢就能動態進行。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

在內部，模組的名稱是一個原子。所有 Elixir 的模組原子都會自動加上`Elixir.`前綴。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
