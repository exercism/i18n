# 說明補充

## 暫存器

| 暫存器 | 用途         | 型別    | 說明                                         |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | 輸入         | 位址    | 以 null 結尾的名稱字串，或空指標             |
| `$a1`    | 輸入/輸出    | 位址    | 以 null 結尾的結果字串                       |
| `$t0-9`  | 暫存         | 任意    | 用於暫時儲存                                 |
