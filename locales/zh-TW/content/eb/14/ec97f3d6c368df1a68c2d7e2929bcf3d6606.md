# 說明

在這個練習中，你會寫一些程式碼，幫助你依照最愛的食譜烤出美味的千層麵。

一共有四個任務，全都和烤千層麵所花費的時間有關。

## 1. 定義千層麵預期需要的烤箱時間（分鐘）

定義`Lasagna.expectedMinutesInOven()`方法，這個方法不接受任何參數，並回傳千層麵應該在烤箱中烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`Lasagna.remainingMinutesInOven()`方法，這個方法接受千層麵已經在烤箱中的實際分鐘數作為參數，並根據上一個任務中預期的烤箱時間，回傳千層麵還需要在烤箱中待幾分鐘。

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. 計算準備時間（分鐘）

定義`Lasagna.preparationTimeInMinutes()`方法，這個方法接受你加在千層麵中的層數作為參數，並回傳你花了幾分鐘準備千層麵，假設每一層需要花 2 分鐘準備。

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. 計算經過的時間（分鐘）

定義`Lasagna.elapsedTimeInMinutes()`方法，這個方法接受兩個參數：第一個參數是你加在千層麵中的層數，第二個參數是千層麵已經在烤箱中的分鐘數。這個函式應該回傳你花了幾分鐘烹調千層麵，也就是準備時間的分鐘數，加上當下千層麵已經在烤箱中度過的分鐘數，兩者的總和。

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
