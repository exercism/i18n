# 簡介

Gleam 用`Bool`型別來表示 true 和 false 這兩種值。這種型別只有兩個值：`True`和`False`。這兩個值可以綁定到變數上：

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`和`!`運算子可以用來操作布林值：

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`和`||`運算子採用短路求值，也就是說，運算子右邊的運算式只有在需要時才會被求值。

每個運算子的優先順序都不同，`!`會比`&&`和`||`先求值。你也可以用大括號，讓運算式的某個部分比其他部分先求值喔：

```gleam
!True && False   // -> False
!{True && False} // -> True
```
