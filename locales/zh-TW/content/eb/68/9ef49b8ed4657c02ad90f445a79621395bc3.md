# 關於

Factor 裡大部分的疊代都是用組合子（`each`、`map`、`reduce`）來表達，不過明確的遞迴仍然有它的用武之地：當遞迴的結構不是陣列形式時、當基本情況不那麼單純時，或是當你要自己實作組合子的時候。

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

有幾件事值得注意：

- 單純的`:`定義就能遞迴，不需要特殊語法。編譯器會跨越遞迴呼叫推斷堆疊效應。
- `loop ( quot -- )`可以讓你疊代一段會回傳布林的 quotation，只要結果為真就繼續執行。
- 尾呼叫會編譯成跳躍指令，所以遞迴再深的詞也不會把堆疊撐爆。

`unclip` / `if-empty`這一組是序列遞迴的標準形式；`cond`則是多情況分派的標準形式。
