# 測試

要測試你的解答，只要**執行測試腳本**就好。你可以在 Red Console 裡使用`do`函式並搭配測試腳本的路徑，像這樣：

```red
do %exercism/red/hello-world/hello-world-test.red
```

或者直接在系統終端機裡，把它當作引數傳給 Red 執行檔：

```shell
red exercism/red/hello-world/hello-world-test.red
```

一開始，測試檔案裡只會啟用第一個測試。這是為了鼓勵你一次只解決一個練習。等到第一個測試通過之後，把測試檔案開頭`test-init`函式的第二個*引數*改一改，再執行一次。這個值代表啟用的測試數量，所以把它從`1`改成`2`，就會啟用第二個測試。你也可以移除`test-init`函式的`\limit` refinement 和第二個引數，這樣就會執行所有測試，不會略過任何一個喔。
