# 關於

Java 8 推出的`java.time`套件內含數個用來處理日期與時間的類別。

## `LocalDate`

[`java.time.LocalDate`][localdate-docs]類別代表 [ISO-8601 曆法][iso-8601] 中沒有時區的日期，例如`2007-12-03`：

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

日期可以和其他的日期相比較：

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

`LocalDate`實例有 getter 可以取得其中各個時間部分：

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getYear();
// => 2007

date.getMonthValue();
// => 12

date.getDayOfMonth();
// => 3
```

`LocalDate`實例也有方法可以為它加上時間單位。

```exercism/note
這些方法會回傳一個_新的_`LocalDate`實例，不會更新現有的實例，因為`LocalDate`類別是不可變的。
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06

date.plusMonths(1);
// => 2008-01-03

date.plusYears(1);
// => 2008-12-03
```

## `LocalDateTime`

[`java.time.LocalDateTime`][localdatetime-docs]類別代表 [ISO-8601 曆法][iso-8601] 中沒有時區的日期時間，例如`2007-12-03T10:15:30`：

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);

datetime.getYear();
// => 2007

datetime.getMonthValue();
// => 12

datetime.getDayOfMonth();
// => 3

datetime.getHours();
// => 10

datetime.getMinutes();
// => 15

datetime.getSeconds();
// => 30
```

和`LocalDate`類別一樣，`LocalDateTime`實例也有相同的方法可以和其他`LocalDateTime`相比較，以及為它加上時間單位。

此外，也可以把`LocalDate`實例轉換成`LocalDateTime`：

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## 格式化日期時間

`LocalDate`和`LocalDateTime`在與`String`互相轉換時，都採用 [ISO-8601][iso-8601] 標準標記法。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

如果想用不同的格式，像這樣從`String`解析出`LocalDate`或`LocalDateTime`是行不通的。
要改用自訂格式來格式化日期，則應該使用[`java.time.format.DateTimeFormatter`][datetimeformatter-docs]：

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", formatter);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

建立自訂格式時也可以指定[地區設定][locale]，以便針對不同地區格式化與解析：

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```
