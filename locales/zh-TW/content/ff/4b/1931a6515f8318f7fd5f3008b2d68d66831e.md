# 說明

身為一位西洋棋愛好者，你會想寫出屬於自己的版本。沒錯，網路上或許已經有許多現成的西洋棋實作，但你的版本可是獨一無二的喔！

你先從實作棋子的基本移動系統開始。

這盤西洋棋會在一個寬 8 格、長 8 格的棋盤上進行。每個格子都由一個字母和一個數字來標示。

## 1. 定義橫列與縱列的範圍

遊戲需要儲存棋盤的橫列。橫列是棋盤上橫向的列，編號從 1 到 8。

遊戲也需要儲存棋盤的縱列。縱列是棋盤上縱向的行，以字母 A 到 H 標示。

定義`Chess::RANKS`和`Chess::FILES`這兩個常數，分別儲存橫列與縱列的範圍。

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. 檢查格子是否合法

遊戲需要檢查某個格子是否合法。只要格子的橫列與縱列都落在橫列與縱列的範圍內，這個格子就是合法的。

定義`Chess.valid_square?`方法，它接受引數`rank`（存有橫列的整數）與`file`（存有縱列的字元）。若橫列與縱列都在橫列與縱列的範圍內，這個方法應該回傳`true`，否則回傳`false`。

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. 取得玩家的暱稱

遊戲需要取得玩家的暱稱。暱稱由玩家名字的前 2 個字元和姓氏的後 2 個字元組成。暱稱應該全部轉為大寫。

定義`Chess.nickname`方法，它接受引數`first_name`（存有玩家名字的字串）與`last_name`（存有玩家姓氏的字串）。這個方法應該以大寫字串回傳玩家的暱稱。

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 建立移動訊息

遊戲需要為每一步移動建立訊息，說明是哪位玩家移動到哪個格子。訊息應該使用玩家的暱稱，以及玩家移動到的格子。遊戲還需要判斷這步移動是否合法，方式是檢查格子的縱列與橫列是否落在縱列與橫列的範圍內。

如果移動合法，訊息應該是：`"{nickname} moved to {square}"`
如果移動不合法，訊息應該是：`"{nickname} attempted to move to {square}, but that is not a valid square"`

定義`Chess.move_message`方法，它接受引數`first_name`（存有玩家名字的字串）、`last_name`（存有玩家姓氏的字串），以及`square`（存有玩家移動到的格子的字串）。這個方法應該以字串回傳這步移動的訊息。

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
