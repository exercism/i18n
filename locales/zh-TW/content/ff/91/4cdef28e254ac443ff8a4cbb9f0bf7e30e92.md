# 學習

* [The Rust Programming Language](https://doc.rust-lang.org/book/)是入門 Rust、也是深入探索 Rust 特定功能的絕佳資源。
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/)用範例帶你認識撰寫 Rust 時最常見的各種用法。
* [Into_rust()](http://intorust.com/)「學習 Rust 的螢幕錄影教學。」
* [Rustlings](https://github.com/carols10cents/rustlings)「讓你習慣閱讀和撰寫 Rust 程式碼的小型練習。」
* [Rust User Forum](http://users.rust-lang.org)能解答各種程度的問題。
