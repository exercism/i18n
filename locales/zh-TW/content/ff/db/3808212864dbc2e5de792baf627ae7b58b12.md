# 簡介

## Nil

[Nil][nil-dictionary] 是英文單字，意思是「nothing」或「zero」。在 Elixir 中，`nil` 是一個特殊的值，代表值的_缺失_。

```elixir
# I do not have a favorite color
favorite_color = nil
```

在其他程式語言中，`null` 或 `none` 這類值可能扮演類似的角色。

## If

除了`cond`之外，Elixir 也提供了巨集 [`if/2`][getting-started-if]，當你只需要檢查一個條件時，它會很有用。

[`if/2`][kernel-if] 接受一個條件和兩個選項。若條件為 _truthy_，它會回傳第一個選項；若條件為 _falsy_，則回傳第二個選項。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

也可以把`if`運算式寫在單行上。請注意條件後面的逗號。

```elixir
if age > 16, do: "beer", else: "no beer"
```

這種語法對非常短的運算式很有幫助，但如果運算式無法放在單行上，就應該避免使用。

### _Truthy_ 與 _falsy_

在 Elixir 中，所有資料型態在布林脈絡下（例如`if`運算式）都會得出 _truthy_ 或 _falsy_ 的值。除了`false`和`nil`以外，所有資料都視為 _truthy_。特別是空字串、整數`0`和空陣列，在 Elixir 裡都視為 _truthy_。
