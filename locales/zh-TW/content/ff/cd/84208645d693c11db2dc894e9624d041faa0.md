# 關於

`Map`用來儲存成對的**鍵**和**值**。`Map`的初始化方式跟陣列一樣，但要使用 map 常值運算子`=>`。你也可以明確定義鍵與值的型別，或交由型別推論決定。鍵必須是唯一的，否則會拋出錯誤。

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map`可以使用`for`迴圈來疊代。你可以選擇疊代其中的值，也可以疊代其中的鍵：

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

在底層，`Map`是一種抽象型別。編譯時，它會依據鍵的型別轉換成幾種特化型別之一：

- `String`：`haxe.ds.StringMap`
- `Int`：`haxe.ds.IntMap`
- `EnumValue`：`haxe.ds.EnumValueMap`
- `{}`：`haxe.ds.ObjectMap`

`Maps`型別在執行階段並不存在，而是被上述其中一種物件取代。
