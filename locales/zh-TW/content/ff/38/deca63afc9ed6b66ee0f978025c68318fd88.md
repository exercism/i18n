# 關於

## 數字

Swift 提供兩大類數字：整數和浮點數。

- [整數][integers]代表沒有小數部分的數，例如`0`、`1`、`-1`、`42`、`-273`。
- [浮點數][floatingpoint]代表帶有小數部分的數，例如`0.0`、`3.14`、`-1.36969e-10`。

你可以在數值字面值中加入底線來提升可讀性：`1_000_000`和`1000000`完全相同。
浮點數字面值可以寫成十進位或指數標記法。

大多數情況下，你會用[`Int`][int]來表示整數，用[`Double`][double]來表示浮點數：

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## 算術運算子

Swift 提供標準的[算術運算子][arithmetic-operators]來進行數值計算：

| 運算子 | 說明 | 範例 |
| ------ | ---- | ---- |
| `+` | 加法 | `4 + 6`的結果是`10` |
| `-` | 減法 | `15 - 10`的結果是`5` |
| `*` | 乘法 | `2 * 3`的結果是`6` |

~~~~exercism/caution
Swift 是型別安全的，不允許在算術運算中混用不同的數值型別。
你不能直接把`Int`和`Double`相加或相乘，必須先將其中一個型別轉換成另一個。
~~~~

### 除法

`/`運算子負責執行除法。
當兩個運算元都是整數時，整數除法會截去小數餘數：

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

非零的浮點數除以零會得到`inf`或`-inf`。
`0.0`除以`0.0`會產生`nan`（Not a Number，非數值）。
相對地，整數除以零會造成編譯期或執行期錯誤：

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### 餘數運算子

[餘數運算子][remainder-operator]（`%`）會計算兩個整數相除後剩下的餘數：

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
在 Swift 中，`%`是真正的*餘數*運算子，而不是取模運算子。
結果的正負號一律跟著第一個運算元（被除數），與第二個運算元的正負號無關：

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## 浮點數的捨入

你可以用`rounded()`方法來對浮點數取整。
預設情況下，`rounded()`會捨入到最接近的整數。
你也可以指定特定的[捨入規則][rounding-rule]，例如`.up`或`.down`：

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## 型別推論

當你宣告數值常數或變數而沒有加上型別標註時，Swift 會推論它的型別：

- 整數預設為`Int`。
- 帶有小數點的數字預設為`Double`。

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## 型別轉換

若要在不同型別的值之間進行運算，請用`Double(_:)`或`Int(_:)`這類的型別初始化器來轉換其中一個值：

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
