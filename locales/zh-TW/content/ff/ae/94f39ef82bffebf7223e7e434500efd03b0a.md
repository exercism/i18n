# 關於

[`repeat-while` 迴圈][repeat-loops]和 `while` 迴圈類似，但有一個關鍵差異：條件檢查是在迴圈主體執行*之後*才進行，而不是在之前。
因此，`repeat-while` 迴圈保證至少會執行一次它的程式區塊。

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
