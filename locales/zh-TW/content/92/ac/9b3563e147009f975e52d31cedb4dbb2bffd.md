# 關於

在撰寫 Elixir 函式時，我們可以利用[斷言風格][assertive-style]，搭配[模式比對][pattern-match-doc]：

```elixir
def read_file() do
  {:ok, contents} = File.read("hello.txt")
  contents
end
```

- 模式比對是明確地透過比對運算子[`=/2`][match-op]進行的。

  - 當運算子左側資料的_形狀_與右側相符時，比對就會成功。
  - 比對成功時，左側的變數會綁定到右側的值。
  - 使用底線符號`_`，可以讓我們忽略那些位置上的值。

    ```elixir
    {:ok, number, _} = {:ok, 5, [4.5, 6.3]}
    number
    # => 5 is bound to this variable
    ```

  - [固定運算子`^`][getting-started-pin-operator]可以用來避免變數被重新綁定，改為針對它現有的值進行模式比對。

    ```elixir
    number = 10
    {:ok, ^number, _} = {:ok, 5, [4.5, 6.3]}
    # => ** (MatchError) no match of right hand side value: {:ok, 5, [4.5, 6.3]}
    ```

- 模式比對也可以出現在函式子句的標頭，因此只有符合模式的引數才會呼叫該函式。
- 變數可以在函式子句的模式比對中被綁定。

  ```elixir
  defmodule Example do
    def named_function(:a = atom_variable) do
      {atom_variable, 1}
    end
  end

  Example.named_function(:a)
  # => {:a, 1}
  # The first function clause matches, so it is invoked

  Example.named_function(:b)
  # => ** (FunctionClauseError) no function clause matching in Example.named_function/1
  ```
