# 說明

鎮上新開了一間詩社，你正考慮參加。
因為過去發生過一些狀況，這間詩社有著一套非常特別的入場規定，你得在嘗試進門之前先摸清楚。

詩社有兩扇門，兩扇都有人把守。
為了進場，你得先推理出當天的密碼：

## 1. 將字串拆分成個別的行

你首先要做的，是把這首詩拆成個別的行。
警衛會朗誦一首詩，而你得把它拆成一行一行。

實作`splitOnNewlines`函式，它接受一個字串，並以換行字元為分隔符號，將它拆成字串陣列。
這個函式應該回傳一個字串陣列，其中每個字串都是這首詩的其中一行。

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. 前門

1. 警衛會朗誦一首詩
2. 你得把這首詩拆成個別的行。
3. 你得取出每一行的第一個字母。
   - 如果該行是空的，你應該改用`_`代替。
4. 你得把這些字母組合起來，它們會形成一個單字。

舉例來說，他們最喜歡的作家之一是 Michael Lockwood，他寫了下面這首_藏頭詩_，意思是每個句子的第一個字母會組成一個單字：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

當警衛朗誦這首詩時，你會把它拆成個別的行，並以每一行的第一個字母作答，也就是`["S", "H", "I", "R", "E"]`。

接著，警衛會把你回覆的字母陣列所組成的單字交給你，要你把它變成首字母大寫的形式。
最後你回傳的密碼是`"SHIRE"`，就能進去了。

實作`frontDoorPassword`函式，它接受一個代表這首詩的字串。
這個函式應該回傳你會告訴警衛的密碼。

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. 後門

在詩社的後方，你會遇到最有名的詩人，那裡就像是貴賓區。
因為這不是人人都能進的，後門的流程稍微複雜一點。

1. 警衛會朗誦一首詩。
2. 你得把這首詩拆成一行一行。
3. 你得取出每一行的最後一個字母。
   - 行尾有時會有空白，所以你需要把它們去掉。
4. 你得把這些字母組合起來，然後在這些字母組成的單字後面加上`", please"`。

舉例來說，前面提到的那首詩同時也是_藏尾詩_，意思是每個句子的最後一個字母會組成一個單字：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

當警衛朗誦這首詩時，你會把它拆成個別的行、去掉行尾的空白，並以每一行的第一個字母作答，也就是`["h", "o", "r", "s", "e"]`。

接著，警衛會把你回覆的字母陣列所組成的單字交給你，要你把它變成首字母大寫的形式，並在後面加上`", please"`。
最後你回傳的密碼是`"horse, please"`，就能進去了。

實作`backDoorPassword`函式，它接受一個代表這首詩的字串。
這個函式應該回傳你會告訴警衛的密碼。

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. 密室

詩社的後室裡還有另一扇門，通往只有最頂尖的詩人才能進入的密室。

1. 警衛會朗誦一首詩。
2. 你得把這首詩拆成一行一行。
3. 你得取出第 i<sup>th</sup> 行的第 i<sup>th</sup> 個字母。
4. 你得把這些字母組合起來，然後在這些字母組成的單字後面加上`"!"`。
5. 你得把這個單字變成全大寫的形式。

舉例來說，前面提到的那首詩經過修改後，就符合這個模式：

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

當警衛朗誦這首詩時，你會把它拆成個別的行、去掉行尾的空白，並以每一行的第 i<sup>th</sup> 個字母作答，也就是 ["S", "u", "p", "e", "r"]。

接著，警衛會把你回覆的字母陣列所組成的單字交給你，要你把它變成全大寫的形式，並在後面加上`"!"`。
最後你回傳的密碼是`SUPER!`，就能進去了。

實作`secretRoomPassword`函式，它接受一個代表這首詩的字串。
這個函式應該回傳你會告訴警衛的密碼。

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
