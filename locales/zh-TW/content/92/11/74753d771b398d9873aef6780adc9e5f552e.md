# 簡介

## 集合

[`Set`][set-docs]是一種無序的集合，和`List`不同，它保證不會包含任何重複的值。

`Set`介面的泛型型別參數，代表`Set`中所含元素的型別：

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

請注意，`Set.of()`方法建立的是一個[_不可修改_][unmodifiable-set-docs]的`Set`實例。
試著對這個實例呼叫`add`和`remove`之類的方法，會在執行時產生例外。

若要建立可修改的`Set`，你需要實例化一個實作`Set`介面的類別。
最常使用的內建類別，就是實作這個介面的[`HashSet`][hashset-docs]類別。

```java
Set<Integer> ints = new HashSet<>();
```

`Set`介面繼承自[`Collection`][collection-docs]和[`Iterable`][iterable-docs]介面，因此和其他種類的集合共用許多方法。
不過，它和`Collection`介面有一個明顯的差異：像是`add`和`remove`這類方法會回傳`boolean`（而不是`void`），用來指出呼叫該方法時，項目是否包含在集合中：

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
