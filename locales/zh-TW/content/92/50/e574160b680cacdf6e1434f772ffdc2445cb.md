# 說明

在這道練習中，你需要把經典遊戲 Pac-Man 的幾條規則翻譯成 Gleam 函式。

你要翻譯四條規則，全都和遊戲狀態有關。

> 別擔心這些引數是怎麼來的，只要專注在把引數組合起來，回傳預期的結果就好。

## 1. 定義 Pac-Man 是否會吃掉鬼

定義 `eat_ghost` 函式，它接受兩個引數（_Pac-Man 是否有能量球生效_、以及 _Pac-Man 是否碰到鬼_），並回傳 Pac-Man 是否能吃掉鬼的布林值。只有當 Pac-Man 有能量球生效且碰到鬼時，這個函式才應該回傳`True`。

```gleam
eat_ghost(False, True)
// -> False
```

## 2. 定義 Pac-Man 是否得分

定義 `score` 函式，它接受兩個引數（_Pac-Man 是否碰到能量球_、以及 _Pac-Man 是否碰到豆子_），並回傳 Pac-Man 是否得分的布林值。只要 Pac-Man 碰到能量球或豆子，這個函式就應該回傳`True`。

```gleam
score(True, True)
// -> True
```

## 3. 定義 Pac-Man 是否輸掉

定義 `lose` 函式，它接受兩個引數（_Pac-Man 是否有能量球生效_、以及 _Pac-Man 是否碰到鬼_），並回傳 Pac-Man 是否輸掉的布林值。如果 Pac-Man 碰到鬼而且沒有能量球生效，這個函式就應該回傳`True`。

```gleam
lose(False, True)
// -> True
```

## 4. 定義 Pac-Man 是否獲勝

定義 `win` 函式，它接受三個引數（_Pac-Man 是否吃光了所有豆子_、_Pac-Man 是否有能量球生效_、以及 _Pac-Man 是否碰到鬼_），並回傳 Pac-Man 是否獲勝的布林值。如果 Pac-Man 吃光了所有豆子，而且根據第 3 部分定義的引數判斷並沒有輸掉，這個函式就應該回傳`True`。

```gleam
win(False, True, False)
// -> False
```
