# 指令補充

## 起始程式碼

`src/TreeBuilding.hs`已經包含一份可運作、能通過所有測試的解法。它速度慢、也不容易閱讀；你的任務是在不破壞測試的前提下讓它更好。

`buildTree`在這些記錄無法構成有效的樹時會回傳`Nothing`。

## 改變表示法

測試從不直接使用`Tree`的建構子。它們改用下面這個函式來建立預期的樹：

```haskell
node :: Int -> [Tree] -> Tree
```

其中`node i children`是 id 為`i`、並帶有指定子節點的節點，子節點依 id 由小到大排列。

這表示你可以自由改變`Tree`的表示方式，例如改成：

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

只要`Tree`仍然有`Eq`和`Show`實例，而且`node`的意義不變即可。如果你使用了`containers`這類程式庫，記得把它加到`package.yaml`的`dependencies`中。
