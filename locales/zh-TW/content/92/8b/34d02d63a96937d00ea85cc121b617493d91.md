# 補充說明

## 例外訊息

有時候，你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，你應該一律附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。這能讓你的程式碼更好讀，對除錯也有很大的幫助。如果你知道錯誤來源會是某種特定類型，可以選擇引發其中一種[內建的錯誤類型](https://docs.python.org/3/library/exceptions.html#base-classes)，但還是應該附上有意義的訊息。

這個練習要求你使用[raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「拋出」`ValueError`，前提是 `preorder`和`inorder`這兩個引數的長度不符、元素不符，或是元素不唯一。只有在同時 `raise` `exception` 並附上訊息時，測試才會通過。

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception`型別的引數：

```python
# if preorder and inorder are not the same length
raise ValueError("traversals must have the same length")

# if preorder and inorder do not share the same elements
raise ValueError("traversals must have the same elements")
    
# if element repeat (are not unique)    
raise ValueError("traversals must contain unique items")
```
