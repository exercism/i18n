# 指示

在這個練習中，你將使用 Cairo 的控制流程結構，協助管理一間小烘焙坊的日常營運。

## 1. 計算訂單總額

實作`calculate_total`，根據糕點種類和數量計算一筆訂單的費用：

- Croissant：每個 3 枚硬幣
- Muffin：每個 2 枚硬幣
- Cookie：每個 1 枚硬幣

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. 套用大量訂購折扣

實作`apply_discount`，根據訂單總額套用折扣。
先將折扣百分比套用到總額，再無條件捨去，取最接近的整數硬幣（floor）。

- 訂單 ≥ 20 枚硬幣：折扣 10%
- 訂單 ≥ 10 枚硬幣：折扣 5%
- 訂單 < 10 枚硬幣：沒有折扣

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. 建立烘焙排程

實作`baking_schedule`，建立每日的烘焙計畫。
烘焙坊每小時以 5 筆訂單為一批進行烘焙：

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

使用適當的控制流程結構（`if`/`else`、`loop`）來有效率地解決每個問題。
