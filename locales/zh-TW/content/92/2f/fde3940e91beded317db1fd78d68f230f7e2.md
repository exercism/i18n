# 操作說明

你正待在海邊的無線電站，監聽頻道上的通訊：訊息從線路傳來，你把它們記錄下來，再把回覆送回去。五個小詞，就能應付一個班次的工作量。

測試會傳入`<string-reader>`輸入（進來的流量）給你，並用`<string-writer>`處理送出的部分，不過這裡的每個詞，換成真正的`<file-reader>`或 socket 也一樣能運作。

## 1. 全部聽完

定義`hear-out`，將輸入串流讀取殆盡，收成單一個字串。

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. 數一數訊息

定義`count-messages`，從輸入串流讀取每一行，並回傳總共有幾行。

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. 把最後一通呼叫複誦回去

定義`echo-back`，讀取每一行，並回傳**最後一行，且轉成大寫**，也就是無線電裡標準的「你剛才說的是 X」回覆。

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. 廣播一則訊息

定義`broadcast`，把訊息寫入指定的寫入器，並清空串流的緩衝區，讓它立刻送出去。不會回傳任何值。

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. 擷取引述的輸出

定義`capture`，以全新的 string-writer 作為環境輸出串流來執行一段引述，並回傳這段引述印出的內容。這段引述不接受任何引數，它就像平常一樣寫入環境串流。

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
