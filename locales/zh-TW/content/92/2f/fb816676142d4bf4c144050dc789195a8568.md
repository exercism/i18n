# 布林型別

在 Cairo 中，布林型別對邏輯運算和條件敘述來說是不可或缺的。Cairo 的布林值大小為一個`felt252`，既能有效利用空間，又保有 true/false 邏輯的簡潔。

Cairo 的布林型別使用關鍵字`bool`來表示。這讓你能在語言中宣告並操作布林變數。舉例來說，看看下面這個例子：

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

這個例子宣告了兩個布林變數。變數`t`被指定為`true`，並隱含宣告為布林型別；變數`f`則明確標註`bool`型別，並被指定為`false`。

有一點很重要：在 Cairo 中宣告布林變數時，一定要用`true`或`false`字面值當作值。也就是說，像`0`或`1`這樣的整數字面值，不能拿來代替`false`或`true`。嚴格執行這條規則能確保型別安全，並避免智慧合約開發中可能出現的邏輯錯誤。

## Cairo 中的布林運算子

- `||`（邏輯 OR）：只要運算元中至少有一個是`true`，就回傳`true`。
- `&&`（邏輯 AND）：兩個運算元都是`true`時，回傳`true`。
- `!`（邏輯 NOT）：回傳與運算元相反的布林值。

## 範例程式碼

下面的程式碼片段示範如何在 Cairo 中使用布林型別。它展示了布林變數的宣告、布林運算式的指定，以及用斷言驗證布林邏輯是否正確：

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
