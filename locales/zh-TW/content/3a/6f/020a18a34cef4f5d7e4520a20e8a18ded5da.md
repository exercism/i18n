# 簡介

C++ 中的布林值以 `bool` 型別表示。
`bool` 只會是 `true` 或 `false`。

## 邏輯運算子

C++ 支援三種布林運算子：`!`（NOT）、`&&`（AND）和 `||`（OR）。
你也可以使用替代寫法 `not`、`and` 和 `or`。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 優先順序

這三種布林運算子各有不同的*優先順序*。
因此，它們的求值順序如下：先 `!`，再 `&&`，最後是 `||`。
如果你想強制使用不同的順序，可以把布林運算式用括號（也就是 `()`）包起來，因為括號的優先順序更高。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 轉換

如果你在預期會用到數字的地方使用 `true` 或 `false`，它們會分別被轉換成 `1` 和 `0`。
如果你在布林運算中使用數字，除了 `0` 以外的所有值都會被視為 `true`，即使是負數也一樣。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
