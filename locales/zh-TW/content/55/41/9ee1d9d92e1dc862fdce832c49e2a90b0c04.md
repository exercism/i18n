# 簡介

## 巢狀型別

C# 型別可以定義在類別或結構的範圍內。外層型別提供了一種類似命名空間的作用。要存取內部型別時，必須透過外層型別並使用點語法。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

你可以為內部型別設定存取層級。

外層型別的私有成員對內部型別的成員是可見的，但反之則不然。
