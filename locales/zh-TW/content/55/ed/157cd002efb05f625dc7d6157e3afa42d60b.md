# 說明

巴勒莫港是個繁忙的港口，許多船隻來來往往。長久以來，這裡一直用人工方式記錄目前停泊在港內的船隻。這套系統非常容易出錯，於是港務主管決定改用電腦化的系統來取代它。

港務主管聘請你來實作這套新系統。這套系統除了要處理船隻的識別碼，還要處理目的地的識別碼。

## 1. 建立港口的識別碼

你首先要做的，是建立巴勒莫港的識別碼。識別碼是港口名稱的前四個字母，並以大寫表示。

將 `Port::IDENTIFIER` 常數定義為符號，其值為 `:PALE`。
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. 取得其他港口的識別碼

程式還必須處理其他港口，所以你也得為它們建立識別碼。港口希望這套系統能自動化，而由於各港口的命名慣例不同，識別碼應該由港口名稱產生。識別碼是港口名稱的前四個字母，並以大寫表示。

定義 `Port.get_identifier` 方法，讓它接受一個字串作為引數，並以符號形式回傳該港口的識別碼。

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. 判斷船隻應該停靠哪個碼頭

港口有兩個碼頭，系統需要判斷船隻應該停靠在哪一個。碼頭是由船隻的識別碼決定的。

識別碼由兩個部分組成：第一部分是三個大寫字母，代表船隻載運的貨物；接著是三個數字，也就是這艘船唯一的識別碼。

如果船隻的識別碼顯示它載運的是 **OIL**或**GAS**，船隻就應該停靠在碼頭**A**。否則，船隻應該停靠在碼頭**B**。

定義 `Port.get_terminal` 方法，讓它接受一個符號作為引數，也就是船隻的識別碼。這個方法應該以符號回傳碼頭。

```ruby
Port.get_terminal(:OIL123)
# => :A
```
