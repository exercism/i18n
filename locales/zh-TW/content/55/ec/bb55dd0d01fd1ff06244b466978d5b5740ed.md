# 提示

## 一般

- `disposable`位於`destructors`；串流協定的泛型位於`io`；`<string-reader>`（測試會用到）位於`io.streams.string`。
- `TUPLE: x < y ...`這種宣告會讓`x`繼承`y`的插槽。`disposable`會加上`disposed`旗標，並在透過`new-disposable`建構時，把元組註冊到解構子框架。

## 1. 定義紙帶

- 建構子：`tape new-disposable swap >>wire ;`。`swap`是為了讓線最後落在剛建好的紙帶下方，好讓`>>wire`取用。

## 2. 加入 input-stream mixin

- 在頂層寫一行，放在`TUPLE:`宣告之後。

## 3. 讀取一個摩斯符號

- 最簡單的形式是一個小迴圈：讀取一個位元組，檢查它，如果是摩斯符號或`f`就回傳，否則讀下一個。
- 字元常值寫成`CHAR: .`。空白則是`CHAR: \s`。
- 對小陣列用`member?`行得通：`B{ CHAR: . CHAR: - CHAR: \s } member?`。
- 最簡單的控制結構：用`while`迴圈讀到取得摩斯符號或`f`為止，最後再搭配一個`dup`，把結果交給呼叫方。

## 4. 委派元素型別

- 一行的方法：`wire>> stream-element-type`。

## 5. 清理

- 同樣的形式：`wire>> dispose`。
- 不要自己呼叫`dispose*`，而是對線呼叫`dispose`。框架的職責就是確保你的`dispose*`只執行一次。
