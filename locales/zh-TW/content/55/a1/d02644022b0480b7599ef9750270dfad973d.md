# 一般

[Python 比較教學][python comparisons tutorial] 和 [Python 比較範例][python comparisons examples] 是涵蓋這份練習內容的絕佳入門。

## 1. 計算一張牌的值

- 你可以使用相等比較運算子`==`來判斷一張牌是否為 A 牌：`card == 'A'`。
- 你可以使用包含運算子`in`來判斷子字串是否包含在字串中：`'Q' in 'KJQ'`。
- 你可以使用 [`int` 建構函式][int constructor] 將`int`的`str`轉成`int`：`int('13')`。

## 2. 判斷哪張牌的值較大

- 一旦定義好`value_of_card`函式，就可以從其他函式呼叫它。
- 你可以使用值比較運算子`>`和`<`來判斷特定牌是否_大於_或_小於_某個值：`3 < 12`。
- 你可以使用相等比較運算子`==`來判斷兩個值是否相等。

## 3. 計算 A 牌的值

- 一旦定義好`value_of_card`函式，就可以從其他函式呼叫它。
- 你可以在這裡使用順序比較運算子`>`來決定該採取什麼做法。

## 4. 判斷是否為 Blackjack

- 記住，你可以使用 [`if`/`elif`/`else`語法][if syntax] 來處理不同的牌組合。
- 比較運算子和布林運算子都能_任意_串接：`y < z < x` 或 `(y or z) and (x or z)`
- 你可以重複使用已經實作的`value_of_card`函式。

## 5. 分牌

- 你可以重複使用已經實作的`value_of_card`函式。
- 你可以另外處理`A`的情況（當手牌中至少有一張是 A 時）。

## 6. 加倍下注

- 當手上有兩張牌時，`A`以 11 點計算就永遠不能加倍下注。
- 根據第一點，你_應該_可以重複使用已經實作的`value_of_card`函式。
- 你可以_任意_串接比較運算子：`y < z < x`。
- 你可以使用 [條件運算式][conditional expression]（_有時也稱為「三元運算子」_）來簡化簡單的`if`/`else`敘述：`13 if letter == 'M' else 3`。
