# 介紹

最有用的序列詞會把一個 *quotation* 當作輸入之一，並用它來驅動運算：

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum`（也在`sequences`裡）會把 quotation 套用到整個序列上，並在一次遍歷中把結果加總。同樣的模式也用來驅動 `sort-by`（在 [`sorting`][sorting] 中），以及 `minimum-by` / `maximum-by`（在 `sequences` 中）。

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
