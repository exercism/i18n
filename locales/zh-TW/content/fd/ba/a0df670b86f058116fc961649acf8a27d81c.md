# 指令

在這道練習中，你會處理一行行的日誌喔。

每一行日誌都是一個格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

一共有三種不同的日誌層級：

- `INFO`
- `WARNING`
- `ERROR`

你將有三個任務，每個任務都會拿到一行日誌，並請你對它做點處理。

## 1. 從日誌行取得訊息

實作 `message()` 函式，回傳日誌行的訊息：

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

開頭或結尾的空白都應該移除：

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. 從日誌行取得日誌層級

實作 `logLevel()` 函式，回傳日誌行的日誌層級，回傳時請使用小寫：

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. 重新格式化日誌行

實作 `reformat()` 函式，重新格式化日誌行，把訊息放在最前面，層級則用括號放在後面：

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
