# 簡介

Swift 提供了一組敘述，可以用來改變迴圈正常的控制流程，這些敘述稱為控制轉移敘述。
你已經看過 `return`，這個單元會介紹其他幾個，包括 `continue`、`break` 和標籤。
這個單元不會涵蓋 `fallthrough`，但你可以在 [Swift 書籍][fallthrough] 中讀到相關內容。

## Continue

有時候，我們需要提早跳到迴圈的下一次疊代，而不執行目前這次疊代中剩下的敘述。
這時可以使用 `continue` 關鍵字。
執行 `continue` 時，迴圈會跳到下一次檢查，判斷能不能執行下一次疊代，也就是 while 和 repeat-while 迴圈中的 `while`，或是 for-in 迴圈中檢查序列裡是否還有下一個元素。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break 用來提早離開迴圈。
執行 `break` 時，迴圈會立刻結束，程式會從迴圈後的第一個敘述繼續執行。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## 標籤

當迴圈形成巢狀結構時，有時我們會想用 `break` 或 `continue` 來離開或重新開始外層的迴圈，也就是包住使用 `break` 或 `continue` 的那個迴圈的外層迴圈。
在這種情況下，可以使用標籤來指定要離開或重新開始的迴圈。
只要在開始迴圈的 `while`、`repeat` 或 `for` 前面加上一個名稱和冒號，就能為迴圈加上標籤。

想了解這樣使用標籤的效果，請看下面的迴圈。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
