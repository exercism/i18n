# 簡介

在 Go 中，常數是簡單、不變的值，會用`const`關鍵字指定給一個名稱：

```go
const myWebsite = "Exercism"
```

這類常數沒有型別，但當需要型別時（例如將它們傳給方法時），會根據語法取得預設型別。
具型別的常數可以透過明確加上型別來建立：

```go
const myWebsite string = "Exercism"
```

Go 不像某些其他語言有列舉，但有一個預先宣告的識別字`iota`，可用來建立列舉常數。
區塊中的常數會隱含地重複：

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
