# 說明

在這道練習中，你會撰寫程式碼來分析汽車工廠組裝線的生產情形。組裝線的速度可以從`0`（關閉）到`10`（最大）。

在最低速度（`1`）下，每小時會生產`221`輛車。產量會隨速度呈線性成長，所以當速度設為`4`時，每小時應該生產`4 * 221 = 884`輛車。不過，速度越快，就越可能生產出有瑕疵的車輛，這些車之後必須被丟棄。

這道練習共有三個任務喔。

## 1. 計算成功率

實作`success_rate()`方法，計算在指定速度下，產品能被正確製造出來的比率。以下列出速度對成功率的影響：

- `0`：成功率 0%。
- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

```R
success_rate(10)
# => 0.77
```

## 2. 計算每小時的生產速率

實作`production_rate_per_hour()`方法，計算組裝線每小時的生產速率，並把成功率納入考量：

```R
production_rate_per_hour(6)
# => 1193.4
```

注意，回傳的值是`double`。

## 3. 計算每分鐘生產的可用車輛數量

實作`working_items_per_minute()`方法，計算每分鐘能生產多少輛可用的車：

```R
working_items_per_minute(6)
# => 19
```

注意，回傳的值是整數：未完成的項目不會計入。
