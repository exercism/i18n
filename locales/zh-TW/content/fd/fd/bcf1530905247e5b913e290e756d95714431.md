# 簡介

*堆積*是一種集合，它總是知道自己的最小項目，並讓你快速移除它，也就是*優先佇列*的自然實作。堆積位於[`heaps`][heaps]詞彙中。

`<min-heap>`會建立一個空堆積，其中最小的鍵會最先出來；`<max-heap>`則是相反版本。每個項目都是一個儲存在*鍵*底下的*值*，而鍵就是優先順序：

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

堆積是*可變的*，`heap-push`會就地修改它。`heap-peek`會回傳前端的值和鍵，但不移除它們；`heap-pop`會移除並回傳它們；而`heap-pop-all`會清空堆積，將其變成一個關聯陣列，內含依優先順序排列的`{ key value }`配對：

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
