# 指示

你在 [exercise:csharp/developer-privileges]() 中最後看到的身分驗證系統需要一些關注。你的任務是整理這些程式碼。這樣的重構專案不僅能讓未來的維護者輕鬆一些，還能揭露並修正一些安全性漏洞。

## 1. 將適當的欄位與屬性設為 const

這是一項重構任務。對你認為適合的`Authenticator`或`Identity`成員加上`const`修飾詞。

## 2. 將適當的欄位設為 readonly

這是一項重構任務。對你認為適合的`Authenticator`類別或`Identity`結構的欄位加上`readonly`修飾詞。

## 3. 確保類別在建立之後就無法變更

對`Authenticator`類別或`Identity`結構上任何適合的屬性，移除`set`存取子或將其設為`private`。

## 4. 確保管理員不會被竄改

目前管理員身分欄位是透過呼叫`Admin`回傳的。這並不理想，因為呼叫端可以修改這個欄位。請想辦法防止呼叫端修改`Authenticator`物件上的管理員詳細資料。

## 5. 確保開發者不會被竄改

目前包含寫死之具特殊權限開發者身分的字典，是透過呼叫`GetDevelopers()`回傳的。這並不理想，因為呼叫端可以修改這個字典。請想辦法防止呼叫端修改`Authenticator`物件上的開發者詳細資料。
