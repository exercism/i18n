# 簡介

在 Common Lisp 中，要定義全域函式會使用 `defun`運算式。
這個運算式的第一個引數是參數列表（空列表代表這個函式沒有參數）。
接著是選用的說明字串（見下文），然後是零個或多個組成函式「主體」的運算式。

函式可以有零個或多個參數。

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

呼叫函式的方式，是求值一個運算式，並把代表該函式的符號放在運算式的第一個位置，其餘的項目則是傳入該函式的引數（如果有的話）。

函式求值後得到的值，就是函式主體中最後一個被求值的運算式的值。
每個函式都會求值出一個值。

```lisp
(add-nums 2 2) ;; => 4
```

函式也可以選擇性地帶有一個說明字串（也稱為「docstring」）。
如果有的話，它會放在參數列表之後、函式主體之前。
說明字串可以透過`documentation`取得。

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
