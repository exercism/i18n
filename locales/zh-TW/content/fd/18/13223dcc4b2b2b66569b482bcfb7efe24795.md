# 指令補充

## 自訂與拋出例外

有時候，你會需要在程式碼中同時[自訂](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)和[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)例外。這麼做的時候，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓程式碼更好讀，對除錯也有很大的幫助。

自訂例外可以透過建立新的例外類別來達成（詳見 [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)），這些類別通常是 [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) 的子類別。

如果你知道錯誤來源會是某種例外型別的衍生，可以選擇繼承 _Exception_ 類別底下的其中一種[`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)。拋出錯誤時，仍然要附上有意義的訊息。

這個練習要求你建立一個 _自訂例外_，在堆疊內容不足時[拋出](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)／「擲出」。只有在你自訂了適當的例外、`raise`這個例外，並附上適當的錯誤訊息時，測試才會通過。


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

此外，這個練習還要求你拋出幾個帶有錯誤訊息的 `built-in exceptions`。
若要拋出帶有訊息的 `built-in exception`，請把訊息寫成 `exception` 型別的引數：

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
