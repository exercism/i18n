# 說明

你在市政府辦公室工作了一段時間，也開發出一套能加快日常工作的工具，例如填寫表單。

現在，有位新同事要加入你的行列，而你發現自己的工具可能不是那麼一看就懂。
你們辦公室裡有很多奇怪的規矩，例如表單一律用大寫字母填寫，而且不能留下空白欄位。

第一步，你決定加上 PHP 型別宣告，讓新同事能更快上手，開始使用你的工具。

## 1. 宣告 Address 類別的型別

為 `Address`類別中已宣告的每個屬性加上屬性型別宣告。
每個類別屬性都應該宣告為字串。

## 2. 宣告用空白值填寫表單所需的型別

為 `Form`類別中的 `blanks`方法加上參數型別宣告和回傳型別宣告。
這個方法會接受一個整數長度，並回傳代表空白列的字串。

## 3. 在把值拆成個別字母時宣告型別

為 `Form`類別中的 `letters`方法加上參數型別宣告和回傳型別宣告。
這個方法會接受一個代表詞語的字串，並回傳由字母組成的陣列。

## 4. 在檢查值能否放入表單時宣告型別

為 `Form`類別中的 `checkLength`方法加上參數型別宣告和回傳型別宣告。
這個方法會接受一個字串詞語和一個整數最大長度，並回傳 true 或 false 的值。

## 5. 在格式化表單中的地址時宣告型別

為 `Form`類別中的 `formatAddress`方法加上參數型別宣告（使用先前更新過的 `Address`類別）以及回傳型別宣告。
這個方法會接受一個 `Address`，並回傳格式化後的字串。
