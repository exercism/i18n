# 簡介

在 Elixir 中，函式被視為一級公民。這代表：

- 具名函式和匿名函式都可以指定給變數。
- 具名函式和匿名函式可以像資料一樣到處傳遞，作為引數和回傳值。
- 匿名函式可以動態建立。

與具名函式不同，匿名函式沒有可用的靜態參考，只有在被指定給變數或立即呼叫時才能使用。

我們可能會用匿名函式來：

- 使用詞法作用域（也稱為閉包）隱藏資料。
- 在執行階段動態建立函式。

匿名函式以保留字`fn`開頭，引數與函式主體之間以`->`符號分隔，並以`end`結束。和具名函式一樣，函式中的最後一個運算式會_隱式回傳_給呼叫它的函式。

若要呼叫函式參考，你必須在參考變數和引數列表之間加上`.`：

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

你還可以使用簡寫的捕獲語法，讓寫法更精簡：

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
