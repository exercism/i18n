# 說明

在這個練習中，你將撰寫程式碼來分析汽車工廠裝配線的生產情況。裝配線的速度範圍可以從`0`（關閉）到`10`（最高）。

在最低速度（`1`）時，每小時生產`221`輛車。產量會隨速度呈線性成長，所以速度設為`4`時，每小時應該生產`4 * 221 = 884`輛車。不過，速度越高，產生瑕疵車的機率也越高，這些車之後必須被丟棄。下表顯示速度如何影響成功率：

- `1` 到 `4`：成功率 100%。
- `5` 到 `8`：成功率 90%。
- `9` 和 `10`：成功率 77%。

你有兩個任務。

## 1. 計算每小時的生產率

實作一個方法來計算裝配線每小時的生產率，並將成功率納入考量：

```rust
assembly_line::production_rate_per_hour(6)
// Returns: 1193.4
```

請注意，回傳的值是`f64`。

## 2. 計算每分鐘生產的可用成品數量

實作一個方法來計算每分鐘能生產多少輛可正常運作的車：

```rust
assembly_line::working_items_per_minute(6)
// Returns: 19
```

請注意，回傳的值是`u32`。
