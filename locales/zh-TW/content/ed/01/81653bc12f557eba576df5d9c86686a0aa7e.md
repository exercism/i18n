# 指令

你正在灌木叢中標出一條步道。距離和觀察記錄都是以序列的形式出現，所以兩者都是疊代器。

這四個都會放進`BUSH_WALK`類別。它們每一個都是疊代器，所以每個名稱都以`!`結尾。

## 1. 標記

`markers!`接受以公尺為單位的間距和一個數量，並產生每個標記與起點之間的距離。

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

數量為零時什麼都不產生。

## 2. 直到步道結束

`until_end!`接受步道沿途的觀察記錄，並一次產生一個，遇到`"end"`時停止。`"end"`本身不會被產生。

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

如果沒有`"end"`，就會產生全部。

## 3. 只有鳥類

`birds!`接受觀察記錄，只產生以大寫字母開頭的那些，這也是這份調查記錄鳥類的方式。

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. 編號

`numbered!`接受觀察記錄，並在每一項前面加上它的位置，從一開始計算。

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
