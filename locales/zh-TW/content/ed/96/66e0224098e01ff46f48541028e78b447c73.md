# 關於

[Clojure](http://clojure.org) 是一門以 Java Virtual Machine（JVM）為目標的動態程式語言。
Clojure 的設計目標是成為通用程式語言，它兼具腳本語言平易近人的特性，以及支援多執行緒程式設計的穩健基礎架構。

Clojure 主要是一門函式式程式語言，並提供豐富的不可變、持久化[資料結構](http://clojure.org/data_structures)。

Clojure 是開放原始碼專案，關於如何為這個語言[貢獻的資訊請見這裡](http://clojure.org/contributing)。

Clojure 的創造者 Rich Hickey 希望打造一門現代 Lisp，用於函式式程式設計，能與成熟的 Java 平台緊密共生，並且以並行處理為設計核心；Clojure 於焉誕生。

以下是兩段能體現 Clojure 目標的引文：

* _良好的設計不在於訂出宏大的計畫，而在於把事情拆解開來。_
* _程式設計不在於打字……而在於思考。_
