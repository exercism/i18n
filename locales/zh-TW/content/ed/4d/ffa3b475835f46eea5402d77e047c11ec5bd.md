# 指令

你的弦樂團即將舉行一場演奏會，而總得有人來寫節目單。

這五個任務都放在`PROGRAMME_NOTES`類別裡。

## 1. 寫出樂曲名稱和作曲者

先放樂曲名稱，接著是` by `，然後是作曲者。

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. 測量一行有多長

負責印刷的人需要知道一行有多長。

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. 開頭幾個字母

給定一個標題和一個數字，回傳從開頭算起的這麼多個字母。

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. 結尾幾個字母

同樣的做法，但從結尾開始算。

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. 縮短過長的標題

放不下的標題會截斷成前六個字母，後面再加上三個句點。

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
