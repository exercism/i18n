# 關於

[switch 敘述][switch]讓你可以把一個值和多個可能的相符值做比較，寫出來的程式碼比使用多個 `else-if` 敘述更精簡。`switch`敘述以`switch`關鍵字開頭，後面接著要比較的值。接著你可以用`case`關鍵字定義各種情況，並在後面加上要比較的目標值。當沒有任何情況相符時，就用`default`關鍵字定義預設情況。和`else-if`敘述一樣，`switch`敘述只會執行第一個相符情況所對應的程式區塊。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

來看看下面這個例子：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

也可以改寫成這樣：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
