# 指令

在這個練習中，你會寫一個泛型的（也可以說是有魔法！）TreasureChest，用來存放一些寶藏。

## 1. 定義 TreasureChest 型別

定義一個有兩個欄位的`TreasureChest{T}`參數化型別。

- 型別為`String`的`password`欄位，用來存放寶箱的密碼。
- 型別為`T`的`treasure`欄位，用來存放寶藏。
這個值是泛型的，所以寶藏可以是任何東西。

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. 定義 get_treasure() 函式

這個函式應該接受兩個引數。

- 一個`String`（用來嘗試密碼）
- 一個`TreasureChest`型別

這個函式應該把提供的密碼嘗試與`TreasureChest`裡的`password`比對。

- 如果密碼相符，就回傳寶藏。
- 如果密碼不符，就回傳`nothing`。

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. 定義 multiply_treasure() 函式

這個函式應該接受兩個引數。

- 一個整數乘數`n`。
- 一個`TreasureChest{T}`型別。

這個函式應該回傳一個新的`TreasureChest{Vector{T}}`，其中包含
- 與原本相同的密碼
- 乘倍後的寶藏，是長度為`n`的`Vector{T}`，也就是原本的寶藏重複`n`次。

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
