# 簡介

所有 Common Lisp 程式碼都是由 S-Expression（Symbolic Expression，符號運算式）組成，簡稱 sexpr。每個 sexpr 不是 atom 就是 cons。S-Expression 在求值時會自動回傳一個值，這個值會取代原本的運算式。當你撰寫自己的函式時（使用`defun`），`defun`主體中最後一個值會自動被回傳：

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
