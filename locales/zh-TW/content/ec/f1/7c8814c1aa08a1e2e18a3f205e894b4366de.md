# Break, Continue

當使用迴圈或疊代的控制結構時，`break`和`continue`關鍵字可以協助控制程式的流程。
`break`關鍵字會跳出迴圈的脈絡，進入外層作用域，藉此終止迴圈。
`continue`關鍵字則會略過目前這輪疊代的其餘部分，並在下一次疊代開始時重新回到迴圈的脈絡。
雖然不常見，但關鍵字後面也可以帶上數字，用來控制要跳出多少層脈絡，或略過多少層直接進入下一次疊代。

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

在前面的範例中，`continue`會執行五次（5），但到了第六次（6）疊代時會執行`break`，讓程式碼離開迴圈。
