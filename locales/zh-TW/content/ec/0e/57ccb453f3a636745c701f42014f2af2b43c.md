# 提示

## 1. 從牌組中取出一張牌

- `Vector`的索引從`1`開始。
- 你可以用`v[n]`取得向量`v`中的第`n`個值。

## 2. 交換牌組中的一張牌

- `Vector`是可變的，你可以隨時改變它的內容。
- 這個方法接受一個 [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) 作為引數。
- 你可以使用`p.first`和`p.second`來存取配對`p`的欄位。

## 3. 在牌組最上方插入一張牌

- Base 中有一個方法 [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!)，可以把新值加到集合的尾端。

## 4. 從牌組中移除一張牌

- Base 中有一個方法 [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!)，可以依指定的索引從`Vector`中刪除元素。

## 5. 移除牌組最上方的一張牌

- Base 中有一個方法 [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!)，可以移除集合尾端的元素。

## 6. 在牌組最下方插入一張牌

- Base 中有一個方法 [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!)，可以把新值插入集合的開頭。

## 7. 移除牌組最下方的一張牌

- Base 中有一個方法 [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!)，可以移除集合開頭的元素。

## 8. 檢查牌組的大小

- Base 中有一個方法 [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length)，可以取得集合的長度。
