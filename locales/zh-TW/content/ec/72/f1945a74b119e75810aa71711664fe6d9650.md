# 關於

**Delphi**是以 Object Pascal 為基礎的程式語言，可用於開發桌上型電腦、行動裝置、網頁與主控台軟體。
在 1995 年正式問世之前，Delphi 是這款當時尚未命名的產品在初期開發階段所使用的[代號](https://edn.embarcadero.com/article/20396)。

Delphi 最初由 [Borland](https://en.wikipedia.org/wiki/Borland) 開發，由 Anders Heilsberg 領軍，是 Windows 平台上 [Turbo Pascal](https://en.wikipedia.org/wiki/Turbo_Pascal) 的後繼產品，也是一套 [快速應用程式開發（RAD）](https://en.wikipedia.org/wiki/Rapid_application_development)工具。
Delphi 為既有的語言加入了完整的物件導向支援，此後這個語言不斷成長，支援許多其他現代語言特性，包括：
  
- **泛型**  
- **匿名方法（閉包）**  
- **動態建構（屬性）**  
- **抽象方法**  
- **內建字串型態**  
- **原生 COM 支援**  
- **RTTI**  

如同它的前身 Turbo Pascal，Delphi 的核心是原生碼編譯器。
Turbo Pascal 在撰寫程式的速度與程式的執行速度之間、在語法的清晰度與表達能力之間，取得了理想的平衡，這些原則在今日的 Delphi 依然成立。
較新版本的 Delphi 能為許多不同的平台編譯原生碼：

- **Windows（x86 與 x64）**  
- **OS X（僅支援 32 位元）**  
- **iOS（32 與 64 位元）**  
- **Android**  
- **Linux（僅支援 64 位元）**  

2006 年，Borland 的開發工具部門從 Borland 移轉到一家名為 [CodeGear](https://en.wikipedia.org/wiki/CodeGear) 的全資子公司，該公司於 2008 年被賣給 [Embarcadero Technologies](https://en.wikipedia.org/wiki/Embarcadero_Technologies)。
2015 年，Embarcadero 被 Idera 收購，但 Embarcadero 這個品牌名稱仍保留給開發工具部門使用。
