# 簡介

字典是一種元素的集合，其中每個元素都由一個鍵和一個值組成；只要把某個鍵傳給字典的方法，就會回傳與其關聯的值。它和其他語言中的映射或關聯式陣列所扮演的角色相同。

可以像這樣建立字典：

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

或

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

請注意，鍵和值的型別是字典定義的一部分。

建構完成後，可以使用內建方法`Add`和`Remove`來新增或移除字典中的項目。

要取得或更新字典中的值，可以透過鍵來索引字典：

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

你可以用以下方法測試字典中是否存在某個值：

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

對字典進行列舉時，會列舉它的鍵/值組。字典也有屬性，可讓你列舉它的鍵或值。
