# 簡介

## 映射

Elixir 中的映射是用來以鍵值對儲存資料的資料結構。在其他語言中，它們也可能被稱為關聯式陣列（PHP）、雜湊（Perl 5、Raku）或字典（Python）。

鍵和值可以是任何資料型態，但如果鍵是原子，我們就可以使用簡寫語法。存取或回傳映射時，並不保證其中項目的順序。

### 字面值形式

一個空的映射只要用 `%{}` 就能宣告。如果想在映射字面值中加入項目，有兩種形式可以用：

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

雖然沒有標準格式，但請選擇一致的方式來表示鍵值對字面值。

### Map 模組的函式

在 Elixir 中，_Map 模組_ 提供了許多處理映射的函式。有些 _Map 模組_ 的函式需要傳入一個 _匿名_ 函式，來協助轉換映射。

## 模組屬性作為常數

在 Elixir 中，我們可以定義模組屬性，並在函式中把它們當作常數使用。

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

用來定義模組常數時，模組屬性可以是任何能在編譯時期求值的運算式。編譯過後就無法再存取模組屬性，因為它們在編譯期間就會被展開，這與 C 這類語言中定義的巨集類似。
