# 指令補充

## 輸出格式

輸出的年齡以百分之一年為單位。

例如，100 × 1,000,000,000 ÷ 31,557,600 ≈ 3,169，所以年齡為 1,000,000,000 秒的人，就是`3169`個百分之一地球年。

## 暫存器

| 暫存器   | 用途     | 型別   | 說明                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 輸入     | 整數   | 行星（`0` = 水星，`1` = 金星，`2` = 地球，`3` = 火星，`4` = 木星，`5` = 土星，`6` = 天王星，`7` = 海王星） |
| `$a1`    | 輸入     | 整數   | 秒數                          |
| `$v0`    | 輸出     | 整數   | 年齡，以百分之一年為單位      |
| `$t0-9`  | 暫時     | 任意   | 用於暫存                      |
