# 浮點數

`INT` 只能存整數，兩個整數相除會把餘數丟掉：

```sather
7 / 2        -- 3, not 3.5
```

當小數部分有意義時，型別就要用 `FLTD`，也就是**浮點數**，可以儲存整數與整數之間的值。

## 寫出一個浮點數

浮點數字面值有小數點，結尾還帶著一個`d`。

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

這個`d`不能省略。`440.0`單獨出現時是另一種型別，精確度較低；`d`要求的則是這個課程從頭到尾都在用的那一種。

要寫`2.0d`，不是`2d`，小數點也不能省。

## 算術運算

`+`、`-`、`*` 和 `/` 都可以用，而且 `/` 現在會保留小數部分：

```sather
7.0d / 2.0d      -- 3.5
```

兩邊都必須是 `FLTD`。Sather 不會偷偷把兩種型別混在一起，所以`7 / 2.0d`會直接報錯，不會給你一個意外的結果。

## 從整數轉換

`.fltd`可以把`INT`變成`FLTD`：

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)`的結果是`3.5`。注意轉換要放在哪裡：`(7 / 2).fltd`會是`3.0`，因為相除時就已經把那一半丟掉了。要在相除**之前**轉換，不是之後。

## 相差多少？

`.abs`會去掉負號，用來問兩個值相差多少，而不必在意哪一個比較大：

```sather
(440.0d - 442.0d).abs      -- 2.0
```
