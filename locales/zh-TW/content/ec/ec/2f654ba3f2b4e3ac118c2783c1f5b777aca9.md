# 關於

## 結構體

我們已經看過結構體了。簡單回顧一下，`struct`是一連串具名的元素，這些元素稱為_欄位_，每個欄位都有名稱和型別。
在同一個結構體內，欄位名稱必須是唯一的。
`Structs`可以對應到物件導向程式設計典範中的_類別_。

你可以使用`type`和`struct`關鍵字來建立新的結構體，然後如下方範例所示，明確定義各個欄位的名稱與型別。

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 非結構體型別

你也可以定義非結構體型別，用來當作內建型別宣告的別名。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

你也可以定義由陣列和映射組成的非結構體型別。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
