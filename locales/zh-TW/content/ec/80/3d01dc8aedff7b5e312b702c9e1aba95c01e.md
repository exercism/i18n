# 表示法

[Python representer][representer] 會處理學生的解答，並將其正規化成更「通用」的形式：

- 使用 [Python AST 模組][python-ast]將程式碼轉換成 AST。
- 最終的 AST 樹會轉換成不含空白與縮排的字串，並輸出為 `representation.txt`。
- 為了方便疑難排解，`representation.out` 會包含起始 AST、編輯後的 AST，以及套用正規化後的程式碼表示。

- 移除項目：
    - 型別提示（_包含 dataclasses 中的型別提示，請見下方的正規化_）
    - `print()` 敘述
    - `if __name__ == __main__` 區塊
    - 註解
    - 文件字串

- 取代項目：
    - 使用者自訂的名稱會替換成佔位符（_包含函式名稱、參數，以及 lambda 中的變數_）

- 正規化：
  - 字串引號 `'` 會改成 `"`（_雙引號_），除非需要跳脫，否則維持不變。
  - 數字字面值會移除所有底線，並依位數計算科學記號：
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - 移除文件字串後主體為空的函式和類別，會將 `pass` 指定為其主體。
  - 有型別提示但未賦值的資料類別資料成員，會將這些資料成員的值指定為 `None`。詳細說明請見 normalizer.py 第 153 行開始的文件字串。
