# 簡介

## 相等

Common Lisp 有許多不同的相等述詞。
這點和其他程式語言不同，那些語言可能只有一、兩個（例如`==`和`===`）。
Common Lisp 中有些述詞是特定型別專用的，有些則是通用的。
這裡要介紹的是後者。

通用的相等述詞共有四個，它們的差別在於對「相等」的認定有多嚴格。
由最嚴格到最寬鬆依序是：`eq`、`eql`、`equal`和`equalp`。

以下是簡單的定義（省略了一些細節）：

- `eq`：將相等定義為兩個物件完全相同。
  _例如_：

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`：將相等定義為兩個型別與值都相同的數字、兩個相同的字元，其他情況則是在它們`eq`時才算相等。
  _例如_：

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`：將相等定義為：如果兩個串列的每個元素也`equal`，這兩個串列就`equal`；如果兩個字串的每個元素都`eql`，這兩個字串就`equal`；如果兩個陣列`eq`，這兩個陣列就`equal`；其他一切只要`eql`就`equal`。
  _例如_：

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`：將相等定義為：字串和字元以忽略大小寫的方式比較；數字比較時會做某種型別轉換；串列和陣列在每個元素也`equalp`時就`equalp`；結構在型別相同且所有欄位都`equalp`時就`equalp`；雜湊表則在鍵和值都`equalp`時就`equalp`。
  _例如_：

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
