# 提示

## 1. 給出成功次數與試驗次數的比值

- 以成功次數為分子、試驗次數為分母，建立`Rational`數字。
- 可以使用迴圈、推導式或向量運算來建立新的陣列。

## 2. 找出成功次數與試驗次數對應的實際機率

- 以成功次數為分子、試驗次數為分母，建立`Float`數字。
- 可以使用迴圈、推導式或向量運算來建立新的陣列。

## 3. 檢查這些機率的平均值

- 平均值是將所有資料加總，再除以事件的數量求得。
- 使用你的`rationalize`和`probabilities`函式。
- 如果使用浮點數和有理數時出現不一致，請回傳有理數。
- 比較時可能需要用到`float()`函式（請參閱簡介）。
- 可以使用迴圈或向量運算。

## 4. 檢查獨立機率

- 獨立事件的機率可以相乘，得出這些事件同時發生的總機率。
- 使用你的`rationalize`和`probabilities`函式。
- 如果使用浮點數和有理數時出現不一致，請回傳有理數。
- 比較時可能需要用到`float()`函式（請參閱簡介）。
- 可以使用迴圈或向量運算。
