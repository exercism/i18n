# 提示

## 1. 將語言新增到`@Languages`陣列

- 你想要修改`@Languages`陣列，在末端新增一個語言。

## 2. 從`@Languages`陣列移除語言

- 你想要修改`@Languages`陣列，移除最後一個語言。

## 3. 取得`@Languages`陣列中的第一個語言

- 你想要`return` `@Languages`陣列的第一個元素。

## 4. 取得`@Languages`陣列中的最後一個語言

- 你想要`return` `@Languages`陣列的最後一個元素。

## 5. 取得`@Languages`陣列中的一部分語言

- 你想要取得`@Languages`陣列的一部分。
- 記得索引從 0 開始。元素`1`的索引是`0`。

## 6. 檢查`@Languages`陣列中是否存在某個語言

- 如果指定的語言可以在`@Languages`陣列中找到，你想要回傳 true（例如`1`）或 false（例如`0`）的值。
