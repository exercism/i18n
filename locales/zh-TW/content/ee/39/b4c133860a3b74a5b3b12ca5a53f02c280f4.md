# 指令

Lucian 的女朋友正在回家的路上，而他還沒煮好他們的週年晚餐！

在這個練習中，你要寫一些程式碼，幫 Lucian 依照他最愛的食譜做出一道精緻的千層麵。

這個練習有四個任務，都和烹調千層麵所花的時間有關。

## 1. 定義預期的烤箱時間（以分鐘為單位）

定義`EXPECTED_MINUTES_IN_OVEN`常數，代表千層麵應該待在烤箱裡幾分鐘。這個常數必須被匯出。根據食譜，預期的烤箱時間是`40`分鐘。

## 2. 計算剩餘的烤箱時間（以分鐘為單位）

實作`remainingMinutesInOven`函式，它接受千層麵已經待在烤箱裡的分鐘數作為_參數_，並根據前一個任務中的**預期的烤箱時間（以分鐘為單位）**，_回傳_千層麵還需要在烤箱裡待幾分鐘。

```javascript
remainingMinutesInOven(30)
// => 10
```

## 3. 計算備料時間（以分鐘為單位）

實作`preparationTimeInMinutes`函式，它接受你加在千層麵裡的層數作為_參數_，並_回傳_你花了幾分鐘準備千層麵，假設每一層需要花 2 分鐘準備。

```javascript
preparationTimeInMinutes(2)
// => 4
```

## 4. 計算總工作時間（以分鐘為單位）

實作`totalTimeInMinutes`函式，它接受_兩個參數_：`numberOfLayers`參數是你加在千層麵裡的層數，`actualMinutesInOven`參數則是千層麵已經待在烤箱裡的分鐘數。這個函式應該_回傳_你總共花了幾分鐘烹調千層麵，也就是備料時間的分鐘數，加上千層麵目前待在烤箱裡的分鐘數的總和。

```javascript
totalTimeInMinutes(3, 20)
// => 26
```
