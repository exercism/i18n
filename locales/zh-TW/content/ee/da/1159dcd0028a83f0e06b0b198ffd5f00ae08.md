# 學習

如果你是 SQLite 新手，想學習 SQL 語法和資料庫管理的基礎，這裡有一些專為初學者挑選的優質資源：

- **YouTube 上的 SQL 入門**：不妨看看 [What is SQL?][sql-youtube]，這是 Danielle Thé 為初學者製作的 4 分鐘影片。

- **SQLite Tutorials**：[SQLite Tutorials][sqlite-tutorial] 提供了對初學者友善的 SQLite 入門介紹，涵蓋資料庫建立、查詢與資料操作等基本概念。

- **SQLZoo**：在 [SQLZoo][sqlzoo] 上透過互動式練習和教學來磨練你的 SQL 技能，其中也包含適合初學者的 SQLite 相關內容。

這些資源能為學習 SQLite 與 SQL 語法打下基礎，幫助初學者理解資料庫概念，並透過操作 SQLite 資料庫累積實作經驗。

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
