# 數字型別

Crystal 有各式各樣的數字型別，各有不同用途。舉例來說，有些型別速度較快，但可容納的值的範圍比其他的小。有些型別可容納的值的範圍較大，但速度較慢。

在 Crystal 中，帶號整數型別和無號整數型別都有。帶號整數型別可以是正數或負數。無號整數型別只能是正數。

## 帶號整數型別

以下是 Crystal 中的[帶號整數型別][int]：

| Type     | Size (bits) | Range                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 到 127                                                                                                 |
| `Int16`  | 16          | -32_768 到 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 到 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 到 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 到 170_141_183_460_469_231_731_687_303_715_884_105_727 |

較小的型別使用的記憶體較少，速度也比大型別快，但可容納的值的範圍較小。

當你知道值會落在某個範圍內時，最好使用盡可能小的型別，以節省記憶體並提升效能。

預設的整數型別是`Int32`。若要宣告特定型別的整數，可以把型別名稱當作後綴，加上`<number>_I <bit>`。

```crystal
1_i8.class
# => Int8
```

你可以使用`to_i<bit>`方法在不同的整數型別之間轉換。`to_i`方法會轉換成預設的整數型別`Int32`。

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 無號整數型別

以下是 Crystal 中的[無號整數][uint]型別：

`UInt8`、`UInt16`、`UInt32`、`UInt64`、`UInt128`

帶號整數與無號整數唯一的差別在於，無號整數只能是正數。若要宣告特定型別的無號整數，可以把型別名稱當作後綴，加上`<number>_u<bit>`。你可以使用`to_u<bit>`方法在不同的無號整數型別之間轉換。`to_u`方法會轉換成預設的無號整數型別`UInt32`。

```crystal
1_u8.to_u16.class
# => UInt16
```

## 浮點數型別

以下是 Crystal 中的浮點數型別：

| Type      | Size (bits) | Range                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 到 3.4E+38   |
| `Float64` | 64          | 2.3E-308 到 1.7E+308 |

這裡有兩種不同的[浮點數型別][float]，其中一種比另一種更精確。

預設的浮點數型別是`Float64`。

你可以使用`to_f<bit>`方法在不同的浮點數型別之間轉換。`to_f`方法會轉換成預設的浮點數型別`Float64`。

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
