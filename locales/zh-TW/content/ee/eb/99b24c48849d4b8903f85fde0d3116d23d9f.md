# 關於

在先前的概念中曾提過，區域標籤和函式其實都只是可執行程式碼區段（例如 `section .text`）裡的位址。

事實上，函式可以像任何記憶體位址一樣被操作，也就是說，可以載入暫存器、四處傳遞，也能存進記憶體。
也可以用 `call` 或 `jmp`，把執行流程轉移到存放在暫存器或記憶體中的函式：

```x86asm
section .text
sum_op:
    lea rax, [rdi + rsi] ; loads the sum rdi + rsi into rax
    ret

apply_sum:
    lea rax, [rel sum_op]
    jmp rax              ; tail call
```

像值一樣四處傳遞的函式位址，就稱為 [thunk][thunk]。
thunk 是組合語言中[高階程式設計][higher-order]的基本要素：也就是操作其他程式碼的程式碼。

## 程式碼即資料

函式位址也可以存進記憶體，之後再取出來使用：

```x86asm
section .bss
    cached_fn resq 1

section .text
save_op:
    mov qword [rel cached_fn], rdi
    ret

apply_op:
    ; arguments are already set up according to the ABI
    jmp qword [rel cached_fn] ; tail call
```

`save_op`會把它收到的函式位址寫進 `cached_fn`。
這個值在 `save_op`回傳之後仍然存在，所以之後任何一次對 `apply_op`的呼叫，都會尾跳到最後存入的那個位址。
如此一來，就能在執行期間改變 `apply_op`所呼叫的函式。

## 分派表

把函式位址存進陣列，就能依照某個索引（可能取決於執行期間的條件）挑選不同的函式。
這就稱為[分派表][dispatch-table]：

```x86asm
section .data
    dispatch_table dq add_op, sub_op, mul_op

section .text
dispatch:
    ; this function takes two arguments in rdi and rsi, and an index in rdx
    ; it then applies the function corresponding to the index in rdx to the arguments
    lea rax, [rel dispatch_table]
    jmp qword [rax + 8*rdx]  ; tail-call the function address for the index
```

## 有狀態的 thunk

如果一個 thunk 在多次呼叫之間會讀取或更新某塊持續存在的記憶體，它的行為就可能因為先前發生過的事而有所不同。
它的結果可能不單單取決於它的引數。

舉例來說，一個 _計數器_ 接收一個函式，用目前的計數值呼叫它，並在每次呼叫後把計數值加一：

```x86asm
section .data
    count dq 0

section .text
tick:
    mov rax, rdi               ; saves the function address
    mov rdi, [rel count]       ; loads the current count as the function's argument
    inc qword [rel count]      ; advances the count
    jmp rax                    ; tail-calls the function
```

`tick`會以目前的計數值作為引數，呼叫給定的函式，然後把計數值加一。
所以第一次呼叫 `tick(square)`會呼叫 `square(0)`，下一次呼叫 `tick(square)`會呼叫 `square(1)`，再下一次是 `square(2)`，依此類推。

另一個例子是 _延遲計算_：

```x86asm
section .bss
    captured_fn resq 1
    argument resq 1

section .text
delay:
    mov qword [rel captured_fn], rdi ; saves the function
    mov qword [rel argument], rsi    ; saves the argument
    lea rax, [rel invoke]            ; returns the `invoke` function
    ret

invoke:
    mov rdi, qword [rel argument]    ; loads the saved argument into `rdi`
    jmp qword [rel captured_fn]      ; tail-calls the saved function
```

`delay`會接收一個函式和一個值，把它們存起來，然後回傳 `invoke`。
呼叫 `invoke`時，它會用存下來的引數執行被捕捉的函式。

高階語言中常見的許多模式，例如回呼、虛擬方法、生成器、柯里化、函式合成等等，都建立在 thunk 與持續狀態的搭配之上。
