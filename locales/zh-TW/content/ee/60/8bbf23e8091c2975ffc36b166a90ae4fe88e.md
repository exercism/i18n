# 簡介

Elixir 透過程式碼中的 _Behaviours_ 來提供共通的泛用介面，同時讓每個實作它的模組能有各自專屬的實作。其中一個常見的例子就是 _Access Behaviour_。

_Access Behaviour_ 為以鍵為基礎的資料結構提供了一套共通的取值介面。它已經為映射和關鍵字清單實作好了，不過我們先來看看它在映射上的用法，感受一下。_Access Behaviour_ 規定：當你手上有一個映射時，可以在它後面接上 _方括號_，再用鍵取出該鍵對應的值。

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

如果資料結構裡沒有這個鍵，就會回傳`nil`。這可能導致非預期的行為，因為它不會拋出錯誤。要注意的是，`nil`本身就實作了 Access Behaviour，因此不管傳入什麼鍵都一律回傳`nil`。
