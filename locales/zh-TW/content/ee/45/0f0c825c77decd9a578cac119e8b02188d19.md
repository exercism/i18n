# 簡介

在[`Vectors`][vectors]概念中，我們提過「陣列是 Julia 語言的核心」，而向量是一維陣列。

因此，我們可以合理期待這個語言提供了許多靈活又強大的方式，讓我們能_對向量做事_，無論那到底是什麼意思。

## 接受向量輸入的函式

有些非常簡單的函式會接受向量輸入，並回傳純量輸出。

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## 算術運算

假設你有一個數值向量，想把每個值都減去 0.5。

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

這樣會失敗，那改成減去另一個向量呢？

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

成功了，但隨著向量愈來愈長，這做法相當繁瑣，也很耗記憶體。

幸好，Julia 有一個「神奇」的點，可以非常簡單地解決這個問題：你需要的就只是`v .- 0.5`。

下一節會說明原因。

## 廣播

所以，`v - 0.5`會失敗，但`v .- 0.5`會成功，我們需要理解這個點到底在做什麼。

它有兩個效果，兩者結合起來就能得到我們想要的結果。

### 1. 逐元素套用

首先，在任何中綴運算子前面加上一個點，代表「把這個運算分別套用到每個元素」。

同樣地，在函式名稱後面加上一個點，會把它「向量化」，即使這個函式原本是為純量輸入而寫的。

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. 單一元素擴展

我們在前面的例子看到，可以對長度相同的向量做減法，不過請理解，`.-`是比`-`更安全的運算子，因為它讓逐元素的意圖更明確。

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

那長度不同的向量呢？

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

一般來說，長度不同就是錯誤，_除非_其中一個的長度是 1（技術上來說，是「單一元素」維度）。

像`[0.5,]`或單純的`0.5`這類單一元素，會透過重複自動擴展到所需要的長度。
這正是`broadcasting`的核心。

### 原地廣播

如果在意記憶體用量，原地操作是減少記憶體配置的常見做法。

不過，上面例子中的廣播運算會建立新的`Vector`，而不是修改原本的那個。

若要原地修改原本的`Vector`，這個修改就必須用廣播來進行。

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## 索引

透過索引編號來選取向量中的元素，已經在先前的概念中介紹過了。

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### 邏輯索引

也可以選取滿足某個邏輯運算式的元素（技術上來說，就是「述詞」）。
這通常需要用到廣播。

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

遇到更複雜的運算式時，這些點往往會愈來愈多（但它們很小，也很容易打）。

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

提醒一下，這裡的「向量」其實可以是任何適當的有序可迭代物件，例如範圍：

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
