# `for` 迴圈

迴圈是程式設計中的基本概念，讓你能重複執行一段程式碼。
在 Swift 中有兩種迴圈：[`for-in` 迴圈][for-loops] 和 `while` 迴圈。
本章會帶你認識 `for-in` 迴圈。

`for` 迴圈讓你能疊代一個值的序列，依序取出每個元素，並將它綁定到你自己指定的變數。
Swift 可以疊代各種序列，例如範圍、陣列和字串（還有更多型別，之後會再介紹）。
當序列中的每個元素都疊代過後，迴圈就會結束。

`for` 迴圈使用 `for` 關鍵字宣告，後面接一個變數名稱、`in` 關鍵字，以及要疊代的值的序列。
`for-in` 迴圈中的這個變數是不可變的，也就是說你無法在迴圈內改變它的值。
以下是 `for-in` 迴圈疊代數字陣列的範例：

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` 變數是在 `for-in` 迴圈中宣告的，只能在該迴圈的作用域內使用。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 疊代範圍

你也可以用 `for-in` 迴圈疊代一段數字範圍。
這讓你能把一段程式碼執行特定的次數，例如範圍`1...5`會疊代數字 1、2、3、4 和 5，因此迴圈會執行 5 次。
有時你會想疊代陣列這類資料結構中的索引，這時就可以改用`0..<array.count`範圍。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 疊代字串

你也可以用 `for-in` 迴圈疊代字串。
這讓你能逐一疊代字串中的每個字元，特別注意迴圈中取得的型別是 `Character`。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## 未使用的變數

如果你不需要迴圈中變數的值，可以用底線符號`_`來忽略它。

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift 也提供 `stride` 函式，讓你能建立一段具有特定步長的範圍序列，接著就能用 `for-in` 迴圈疊代。
`stride` 有兩種定義：[`stride(from:to:by:)`][stride-to] 和 [`stride(from:through:by:)`][stride-through]，前者不包含結束值，後者則包含結束值。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

注意 `to` 參數不包含結束值，所以迴圈會疊代到 `to` 參數前一個數字為止；而 `through` 參數則包含結束值，因此在這個例子中還會包含`10`。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
