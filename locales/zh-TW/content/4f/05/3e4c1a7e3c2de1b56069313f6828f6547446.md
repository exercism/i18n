雖然在 Haxe 中手動串接字串是可行的，但 Haxe 支援[字串插補][string-interpolation]，提供更簡短、更方便的語法：

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

如上所示，插補字串是用單引號（`'`）包住的，這點和一般的[字串][strings]不同，而且裡面可以包含以錢字號（`$`）標示的特殊識別碼，用來觸發插補。

只要使用 `${expr}`，就能加入完整的運算式，其中 `expr` 可以是任何有效的 Haxe 運算式：

```haxe
trace('the next number is ${x + 1}');
```

如果實際上想要一個錢字號，可以用 `$$` 來抑制插補：

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

最後請注意，字串插補是編譯期的功能，不會影響執行時效能。在內部，Haxe 編譯器會產生等同於手動串接的程式碼。

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
