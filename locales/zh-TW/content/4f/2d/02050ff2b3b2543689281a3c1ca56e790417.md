# 提示

## 1. 三段表演

- 類別標頭會在`<`後面寫出抽象類別的名稱：`class JUGGLING < $ACT is`。
- 每一個都必須定義`name`和`minutes`，而且要與抽象類別宣告的完全一致。漏掉其中一個就會產生編譯錯誤，並在訊息中指出是哪個常式。
- 每一個也都需要一個`create`，否則`#JUGGLING`就沒有東西可以呼叫。對其中兩個來說，`create : SAME is return new; end;`就是全部了。
- `TRAPEZE`需要一個存放高度的屬性，以及一個接受該高度的`create`。
- `+`會把數字接到字串上，所以`"Trapeze at " + height + "m"`不需要做任何轉換。

## 2. 演出

- 引數的型別是`ARRAY{$ACT}`，正因如此，同一個陣列才能裝下這三種表演。
- `acts.elt!`會取得一個`$ACT`。對它呼叫`.minutes`就會自己執行正確的那一個，這就是分派，也是這個練習的重點。不需要檢查任何東西，也不用寫`typecase`。
- `billing`會在迴圈中建立字串，所以要使用`FSTR`，而`", "`要放在每個名字前面，第一個除外。
- `longest`會保留目前為止最好的一段表演。把最佳分鐘數的起始值設為`-1`，第一段表演就一定勝過它，這樣空演出也能處理，不必寫特例：名字會維持`""`。
