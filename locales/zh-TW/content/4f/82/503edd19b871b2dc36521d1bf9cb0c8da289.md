# 簡介

Python 有兩種迴圈結構。
`while`迴圈用於_不確定_（無法計數）的疊代，`for`迴圈則用於_確定_（可計數）的疊代。
關鍵字`break`、`continue`和`else`可以協助自訂迴圈的行為。
`range(<length of sequence>)`與`enumerate(<iterable>)`這兩個函式則有助於迴圈的計數與索引。


`while`迴圈不用事先指定要執行多少次，只要`loop`運算式（或「測試」）的求值結果為`True`，就會一直執行下去。
當迴圈運算式的求值結果為`False`時，迴圈就會終止。

```python
while expression:
    set_of_statements
```

`for`迴圈會逐一走訪任何序列中的值，當沒有更多值可以回傳時就會結束。
當沒有資料結構或其他可迭代物件可以走訪時，`range(<length of sequence>)`函式可以提供`loop`計數器或序列。

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
