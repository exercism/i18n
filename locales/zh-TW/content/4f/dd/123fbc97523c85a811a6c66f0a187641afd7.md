# 說明附錄

## 關於 Unicode 的 Tcl 注意事項

在 8.1 版中，Tcl 字串就能夠流暢地處理 Unicode 字元。
在當時，這可是相當劃時代的創舉。
然而，隨著 Unicode 字元不斷增加，Tcl 處理它們的能力也逐漸落後。

Tcl 的內部實作只能處理 16 位元的 Unicode 字元，僅涵蓋前 65,526 個字元。
[這個 Tcl wiki 頁面][tcl-unicode]，特別是其中關於「AndroWish」語言的討論，說明了背後的原因。

Tcl 9.0 是第一個能夠[處理完整 Unicode 字元集][tip-497]的版本。
因此，這個練習只有使用 Tcl 9.0 版才能（輕鬆地）完成。

[tcl-unicode]: https://wiki.tcl-lang.org/page/Unicode+and+UTF-8
[tip-497]: https://core.tcl-lang.org/tips/doc/trunk/tip/497.md
