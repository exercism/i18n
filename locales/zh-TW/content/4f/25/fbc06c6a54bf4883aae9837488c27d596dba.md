# 執行測試

在終端機中，先切換到練習的基底目錄，然後用以下指令執行測試：

```bash
$ gleam test
```

這會執行`test`子資料夾裡的測試檔案，也就是以`_test.gleam`結尾的檔案。

## 測試函式

這些測試使用[自訂測試框架](https://github.com/exercism/gleam-test-runner/tree/main/runner)。在`test`目錄中，任何名稱以`_test`結尾的公開函式，都會被測試框架視為一項測試。

例如：

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
