# 簡介

## Result

Gleam 不用例外來處理錯誤，而是由可能成功或失敗的函式回傳通用的 `Result` 型別。

`Result` 型別是語言內建的，所以你不需要定義或匯入它；不過如果你想自己定義，它會長這樣：

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

函式成功時會回傳 `Ok` 變體，失敗時則回傳 `Error` 變體。

Result 在 Gleam 裡非常常見，Gleam 程式設計師通常會使用 [`gleam/result` 模組](https://hexdocs.pm/gleam_stdlib/gleam/result.html)，讓處理起來更輕鬆。

`result.map` 函式可以在結果是 `Ok` 時，對裡面的值呼叫函式；如果結果是 `Error`，則原封不動地傳遞下去。

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try` 函式很類似，但它預期的回呼函式要回傳一個 Result。這在串接多個會回傳 Result 的函式時很方便。

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
