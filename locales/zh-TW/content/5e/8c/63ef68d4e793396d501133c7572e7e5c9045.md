# 簡介

在 Kotlin 中，類別可以用來封裝資料與行為。類別是使用`class`關鍵字宣告的。例如：

```kotlin
class Car
```

呼叫類別就能建立它的實例。

```kotlin
val instance = Car()
```

## 屬性

在上面的範例中，`Car`類別並沒有宣告任何屬性。類別屬性可以在類別主體中、`{}`之間宣告，可變的屬性用`var`，不可變的屬性用`val`。例如：

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

或者，也可以在建構函式中定義屬性，由建構函式接收這些屬性。

## 建構函式

Kotlin 有兩種建構函式：主建構函式和次要建構函式。主建構函式宣告在類別宣告的同一行。例如：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

如果沒有註解，也沒有可見性修飾子，就可以省略`constructor`關鍵字：

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin 允許在類別只包含屬性時，定義類別而不加主體，也就是不需要大括號`{}`：

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

一個類別只能有一個主建構函式。次要建構函式則是額外的建構函式，只要在類別主體中用`constructor`關鍵字宣告，就能加入。例如：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

次要建構函式必須呼叫`this`來叫用主建構函式。

## 初始化區塊

主建構函式會設定類別的屬性。如果建立物件時還需要做更多事，可以使用`init`區塊執行額外的動作。

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## 函式

函式可以定義在類別主體中。例如：

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## 可見性

屬性和函式可以是`private`、`public`、`internal`或`protected`。

- `private`只能在類別內部存取
- `protected`可以由類別內部的東西存取，也可以由任何子類別存取
- `internal`可以由同一個模組內的東西存取
- `public`可以由使用該類別的其他元件存取

例如：

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
