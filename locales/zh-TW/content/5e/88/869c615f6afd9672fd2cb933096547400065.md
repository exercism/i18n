# 指令

你是個熱衷的賞鳥者，每天都會記錄造訪花園的鳥的數量。這些數量儲存在一個陣列中，最舊的一天排在最前面。

## 1. 今天的數量

定義`today`，從堆疊取出每日數量的陣列，並回傳今天的數量。

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. 將今天的數量加一

定義`increment-todays-count`，回傳一個新的陣列，其中今天的數量加一。原始的陣列不應該被修改。

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. 有沒有哪一天沒有鳥？

定義`has-day-without-birds?`，如果至少有一天記錄到零隻鳥，就回傳`t`，否則回傳`f`。

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. 計算前幾天的總和

定義`count-for-first-days`，接收一個數量陣列和一個數字`n`，並回傳前`n`筆數量的總和。

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. 計算忙碌的天數

忙碌的一天是指有五隻或更多鳥的一天。定義`busy-days`，回傳陣列中忙碌天數的數量。

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. 補齊缺少的天數

如果你沒有在連續`n`天的每一天都觀察，就把尾端缺少的天數補上`0`。定義`pad-missing-days`，接收一個數量陣列和目標長度`n`，並回傳一個長度至少為`n`的陣列，其中多出來的元素是`0`。現有的數量必須保持不變；如果輸入的長度已經至少為`n`，就原樣回傳。

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
