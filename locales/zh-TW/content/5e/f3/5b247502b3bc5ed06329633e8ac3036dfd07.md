# 關於

[switch 敘述][switch]會將一個值與多個可能的相符模式進行比較。相較於串接多個`if-else`敘述，它提供更簡潔、更好讀的寫法。

`switch`敘述以`switch`關鍵字開頭，後面接著要測試的值。每個可能的相符情況都會用`case`關鍵字帶出。`default`關鍵字則定義備用情況，當沒有任何明確的情況相符時就會執行。和`if-else`串接一樣，`switch`敘述只會執行第一個相符情況所對應的程式區塊。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

看看下面這串`if-else`敘述：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

這段程式改用`switch`敘述可以寫得更清楚：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 值的綁定與`where`子句

`switch`的情況可以將相符的值綁定到暫時的常數或變數，供該情況的主體使用。情況也可以加入`where`子句，在相符之前檢查額外的布林條件：

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
