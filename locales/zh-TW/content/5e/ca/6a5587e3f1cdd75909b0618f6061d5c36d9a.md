# 執行測試

選擇你的作業系統：

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. 開啟 Command Prompt。
2. 取得第一個練習：

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. 切換到 exercism 目錄：

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. 執行測試：

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _（一開始測試失敗不用擔心，每個練習都是這樣開始的。）_

5. 解開這個練習。找到並跟著`instructions.append.md`指南操作（[在 GitHub 上查看][hello-world-tutorial]）。

祝你好運！玩得開心！

## macOS

1. 在終端機視窗中，取得第一個練習：

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. 切換到練習目錄：

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. 執行測試：

   ```sh
   ./gradlew test
   ```

   _（一開始測試失敗不用擔心，每個練習都是這樣開始的。）_

4. 解開這個練習。找到並跟著`instructions.append.md`指南操作（[在 GitHub 上查看][hello-world-tutorial]）。

祝你好運！玩得開心！

## Linux

1. 在終端機視窗中，取得第一個練習：

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. 切換到練習目錄：

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. 執行測試：

   ```sh
   ./gradlew test
   ```

   _（一開始測試失敗不用擔心，每個練習都是這樣開始的。）_

   如果你遇到以下錯誤：

   ```sh
   ./gradlew: Permission denied
   ```

   那表示這個檔案少了執行權限。要修正這個問題，請執行：

   ```sh
   chmod +x ./gradlew
   ```

   現在你應該就能執行先前的指令了。

4. 解開這個練習。找到並跟著`instructions.append.md`指南操作（[在 GitHub 上查看][hello-world-tutorial]）。

祝你好運！玩得開心！
