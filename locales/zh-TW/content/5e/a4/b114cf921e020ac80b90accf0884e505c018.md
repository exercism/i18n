# Rust 參考文件

## 概念

Rust 的概念練習涵蓋從基礎到精通語言的各種概念。以下將它們分類列出。

Exercism 的概念是為了以實用的方式服務學習者，因此與抽象的觀念有所不同。本文件定義這些概念在 Rust 中的含義。我們在下方加入了視覺分組，協助軌道維護者建立一份實用的參考文件。這些分組_並不_構成教學上的區分，因此教學時請不要引用它們。

核取方塊標示這些概念是否已納入練習對應清單中教授。

## 概念練習對應

理想上，上述每個概念都會有一份專屬的概念練習，只教一個概念，而且只需要它的先備知識，但這做起來並不完全實際。舉例來說，很難設計出一份練習來講解什麼是函式，卻完全不要求任何原始型別的知識；同樣地，要在有測試套件的情況下講解原始型別，也不可能完全不涉及函式的知識。

這張表中的練習應該構成一張有向無環圖（DAG），最終涵蓋上述所有概念。

| 練習                     | 先備知識                                     | 教授內容                                                 | 敘述                                                                             |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | 函式、測試套件                                           | 回傳 `&str` 字面值 `"hello world"`                                               |
| `compiled-calculator`    | `hello-world`                                | 整數、變數賦值                                           | 執行一連串數學運算，並隱式回傳結果                                              |
| `conditionals`           | `hello-world`                                | 條件式                                                   | 應以三分支的 `if` / `else if` / `else` 結構撰寫；隱式回傳                        |
| `slices`                 | `hello-world`, `compiled-calculator`         | 切片                                                     | 從一個整數切片的參數中取出一個切片                                              |
| `loops`                  | `slices`                                     | 對切片進行基本迴圈                                       | 最好能提早回傳，讓它難以用疊代器表達                                            |
| `iterator-use`           | `slices`                                     | 疊代器使用、`collect`                                    |
| `integer-sizes`          | `compiled-calculator`                        | 非 `i32` 的整數、型別轉換                                | 仍然全部是有號整數                                                              |
| `unsigned-ints`          | `integer-sizes`                              | 無號整數                                                 |
| `indexing`               | `integer-sizes`, `slices`                    | 索引、`usize`                                            |
| `floats`                 | `compiled-calculator`                        | 浮點數                                                   | 大概與編譯計算機是同一份練習，只是結果不是整數                                  |
| `bools`                  | `compiled-calculator`                        | 布林、布林運算子                                         |
| `char`                   | `compiled-calculator`                        | `char` 資料型態                                          | 應包含一些寬字元的範例                                                          |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | 注意：不可變！                                                                  |
| `string-use`             | `str-use`                                    | `String`                                                 | 注意：具所有權、可變                                                           |
| `format-macro`           | `string-use`                                 | `format!` 巨集                                           |
| `str-vs-string`          | `str-use`, `string-use`                      | 合併、轉換、成本等                                      |
| `generics-basics`        | `integer-sizes`, `floats`                    | 將外部特徵用作界限、泛型基礎                             | 大概仍是編譯計算機，只是改用泛型                                                |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | 建立並使用結構體來管理資料                               | `Person` 有姓名、身高，以及擁有鞋子的數量                                       |
| `implicit-return`        | `compiled-calculator`                        | 作用域、運算式、隱式回傳                                 |
| `explicit-return`        | `implicit-return`, `conditionals`            | 明確的 `return` 敘述                                     |
| `methods`                | `structs`, `explicit-return`                 | `impl` 區塊、方法                                        |
| `tuples`                 | `structs`                                    | 元組                                                     | 以匿名結構體的方式教授；教授 `.0` 語法                                          |
| `tuple-structs`          | `tuples`, `structs`                          | 元組結構體（具名元組）                                   |
| `basic-enums`            | `unsigned-ints`                              | 基本列舉（無欄位）、`match`                              |
| `enums`                  | `basic-enums`, `tuple-structs`               | 列舉變體的元組語法                                       |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | 預設不可變；明確的可變性                                 |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`、`while let`                                    | 依照實作方式，大概只會相依於 `option` 或 `result` 的其中一個                    |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | 手動實作特徵                                             | 大概會實作 `Iterator`                                                           |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
