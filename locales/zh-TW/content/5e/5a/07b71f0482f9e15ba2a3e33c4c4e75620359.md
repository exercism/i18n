# 介紹

`when` 是篩選例外時使用的關鍵字。它放在 catch 敘述之後，可以接受一個布林運算式，其中包含當下作用域內的任何值。如果運算式評估為 true，就會執行該 `catch` 敘述對應的程式區塊。否則，會繼續檢查下一個 `catch` 敘述（如果有的話）。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
