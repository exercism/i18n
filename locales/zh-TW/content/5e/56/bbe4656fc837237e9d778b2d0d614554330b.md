# 說明

[阿姆斯壯數][armstrong-number] 是一種數字：把它的每個位數各自取位數次方後加總，結果會等於它本身。

例如：

- 9 是阿姆斯壯數，因為 `9 = 9^1 = 9`
- 10 _不是_ 阿姆斯壯數，因為 `10 != 1^2 + 0^2 = 1`
- 153 是阿姆斯壯數，因為：`153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 _不是_ 阿姆斯壯數，因為：`154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

寫一段程式碼，判斷一個數字是不是阿姆斯壯數。

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
