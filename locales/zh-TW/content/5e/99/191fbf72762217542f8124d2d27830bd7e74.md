# 指令

你被一間為烏龜製作拼布被的公司聘為助理生產工程師。

訂單整天陸續進來，內容是一組顧客名稱或編號，以及訂購數量。
這些訂單會在早上、當天生產開始之前處理完畢。

只要當天的訂單全部完成，你就可以領全薪下班回家，所以大家都有動機盡可能縮短工作日。
由於每張訂單都由單一機器處理，先把最大的訂單排進去，就能把啟動工作的額外負擔推給較小的訂單，進而縮短整體生產時間。
因此，你決定提供一些排序函式來協助加快排程，讓你可以早點回家替烏龜織件毛衣。

## 1. 排序數量！

如前所述，數量陣列需要由大到小排序。
由於這些陣列可能很大，排序應該以*原地*方式進行。
為了正確追蹤所有資料，你還需要能依照數量來排序顧客陣列，因此會需要一組數量的排序排列。

請撰寫一個函式`sortquantity!(qty)`，它接受一個由`Integer`數量組成的`Vector`。
這個函式會以原地方式將輸入的`qty`由大到小排序，並回傳代表這個排序結果的排序排列。

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. 排序顧客

如上所述，你需要依照固定的順序追蹤顧客。

請撰寫一個函式`sortcustomer(cust, srtperm)`，它接受一個顧客的`Vector` `cust` 和一個排序排列的`Vector` `srtperm`。
這個函式會回傳一個新的陣列，其中的顧客依照這個排序排列所指定的順序排列。

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. 生產排程！

現在你可以把所有東西組合起來，幫那些烏龜保暖了！
你已經能正確排序數量和顧客，但還需要能還原出貨時的原始順序。
這可以透過反向排序排列來完成。

請撰寫一個函式`production_schedule!(cust, qty)`，它接受一個顧客的`Vector`和一個數量的`Vector`。
這個函式會以原地方式將數量由大到小排序。
它會回傳一個新的顧客`Vector`，排序與數量相同，以及一個*反向*排序排列，可用來把已排序的向量還原成原始順序。

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
