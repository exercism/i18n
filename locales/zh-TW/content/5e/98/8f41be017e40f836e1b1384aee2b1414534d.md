# MoonScript 軌道的測試

MoonScript 軌道的測試方式和 [Lua 軌道的測試][lua-tests] 完全一樣。
在練習目錄中輸入：

```console
$ busted
```

## 待處理的測試

這個軌道遵循 Exercism 的[測試驅動開發][tdd]方法論。
你會拿到一份完整的測試套件，但只有第一個測試是「啟用」狀態。

如要啟用這些測試，請把測試的指令從 `pending` 改成 `it`。

如果你喜歡每次都執行所有測試，可以用命令列工具一次全部改掉。
以下是用 perl 寫的範例（perl 幾乎到處都裝好了）：

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

當你在線上編輯器裡作業時，測試執行器會自動執行所有測試。

## 使用 LuaRocks

Lua 本身是一個非常小的語言。
[LuaRocks][luarocks] 是 Lua 模組的套件管理器。

你可以在自己的解法中自由使用任何模組，但不是所有模組都能在線上測試執行器中使用。
測試執行器提供以下這些：

**已可作為`busted`的相依套件使用**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**已可作為 MoonScript 的相依套件使用**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**日期時間**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
