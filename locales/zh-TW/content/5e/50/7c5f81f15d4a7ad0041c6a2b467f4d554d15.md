# 關於

[`fold`][fold]是一種[消耗性疊代器轉接器][consuming iterator adaptor]，它會把函式套用到疊代過程中的每個元素，並將結果累積成一個新值。

`fold`的每一次疊代都會接受兩個引數。第一個是累加器的初始值，第二個是閉包，這個閉包本身也接受兩個引數：累加器和一個項目。閉包的回傳值會成為累加器的下一個值。等到疊代器耗盡後，就會回傳累加器的最終值。

`fold`可以用在想要把一個集合轉換成單一值的時候。舉例來說，如果想要求出所有偶數的總和

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

印出`30`。

用`fold`能做到的事，通常也能用另一個或多個函式完成。以上面的例子來說，改成對`(1..=10)`使用[`filter`][filter]，再用[`sum`][sum]加總，不但更精簡，算出來的結果也一樣，像這樣

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

其他比`fold`更常用的函式還有[`product`][product]和[`collect`][collect]。

累加器也可以用來處理數字以外的值。例如

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

印出`FeeFiFoFum`
