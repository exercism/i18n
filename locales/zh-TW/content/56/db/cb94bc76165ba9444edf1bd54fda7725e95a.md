# 說明

你的朋友剛傳來一則訊息，裡頭有個重要的秘密。
他不想讓別人輕易讀懂，所以把訊息經過一連串的位元操作加密了。
你需要撰寫幾個函式來協助解密這則訊息。

## 1. 將位元移回

解密訊息的第一步，是把加密時位移過的位元往右移回來。
解密過程後續的步驟會假設左側補進的是 `0`。

實作 `shiftBack` 函式，它接收要位移的位數和一個值，並執行位移。

```elm
shiftBack 2 42 --> 10
```

## 2. 設定一些位元

接下來，有些位元需要設成 `1`。

實作 `setBits` 函式，它接收一個遮罩和一個值，並把值中的位元設為 `1`。
當遮罩中的某個位元是 `1` 時，值中對應的位元也應該設為 `1`。
其他所有位元則保持不變。

```elm
setBits 66 212 --> 64
```

## 3. 翻轉特定的位元

加密過程中有些位元被翻轉了。
要解密訊息，就得把它們翻轉回來。

實作 `flipBits` 函式，它接收一個遮罩和一個值。
遮罩指出值中哪些位元要翻轉。
如果遮罩中的位元是 `1`，就把值中對應的位元翻轉。
其他所有位元則保持不變。

```elm
flipBits 23 157 --> 138
```

## 4. 清除特定的位元

另外還有一些位元，解密後一定是 0。

實作 `clearBits` 函式，它接收遮罩和值。
當遮罩中的位元是 1 時，`value` 中對應的位元應該設為 0。
其他所有位元則保持不變。

```elm
clearBits 2 15 --> 13
```

## 5. 解密訊息

現在你已經有需要的所有函式，可以解碼朋友傳來的訊息了。
實作 `decrypt` 函式，依序執行下列操作：

1. 用你朋友出生的年份（1996）設定位元
2. 用你們初次見面的年份（2009）翻轉結果
3. 依照你們一起修的課堂數（5）把位元移回
4. 清除第一個和第五個位元。

```elm
decrypt 380182 --> 11840
```

請用你在前面幾個任務中實作的函式來完成 `decrypt`。
