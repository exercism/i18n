# 關於

[陣列][list]是 Haskell 中一種用來存放一組值的基本資料型態。
陣列是_不可變的_，也就是無法修改。
任何會改變陣列的操作都會回傳一個新的陣列。
Prelude 中有幾個方法可以讓你操作陣列。

Haskell 的陣列是以[連結串列][linked-list-wiki]實作，而不是以連續記憶體位址的陣列實作。
因此，存取陣列中的元素需要線性時間，實際所需時間取決於陣列的長度。

陣列可以用字面形式、頭尾記法（使用`cons`運算子`:`），或兩者的組合來表示：

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

頭尾記法可以用來把項目附加到陣列上。

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

在疊代過程中把元素附加到陣列被視為一種反模式。附加一個元素需要走訪整個陣列，並把元素加到最後面；因此，如果每一次疊代都要附加一個新元素，就必須在每次疊代時走訪整個陣列。

我們可以先把元素前置到反轉後的陣列，再反轉整個結果，以達到相同的效果。前置是很快的操作，只需要常數時間。

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Prelude 中有幾個常見的陣列函式：

- [`head`][head]回傳陣列的_頭_，也就是陣列中的_第一個_項目。
- [`tail`][tail]回傳陣列的_尾_，也就是原陣列_減去_第一個項目。
- [`length`][length]回傳陣列中的項目數量。
- [`elem`][elem]回傳一個布林值，指出該項目是否為陣列中的元素。

此外還有[`Data.List`模組][list]。

## 陣列型別

在 Haskell 中，陣列是**同質的**。
這表示陣列中所有元素都具有相同的型別。
當你試著把不同型別的元素放進同一個陣列時，就會得到型別錯誤。

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

陣列的型別標註是`[a]`，其中 a 是陣列所存放的型別，例如`String`或`Int`。

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
