# 指令補充

## `Print`不會為字串值加上引號

這個練習會涉及操作數字分數。
#[a: 1]` and `#[a: "1"]` are not the same:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

一種常見的除錯做法是用`print`印出值。
不過，輸出不會在字串前後加上引號。
因此，像`"1"`這樣的數字字串在印出時，看起來會和整數`1`一樣。

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
在這個練習的測試輸出中，你可能會看到像`:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`這樣的結果。
被比較的這兩個字典在印出時看起來一樣。
不過，第一個字典的值是數字字串，第二個字典的值是整數，所以它們並不相同。
除錯時，可以用`inspect`來檢查你的字典內容。

## `Express`會為字串值加上引號

`express`會把值轉換成 Arturo 程式碼，並回傳代表該程式碼的字串。
在那個結果中，任何字串值都會加上引號。
因此，`express "1"`會回傳`"1"`，而不是`1`。

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
