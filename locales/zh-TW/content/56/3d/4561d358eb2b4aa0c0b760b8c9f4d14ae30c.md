# 學習

如果你想學習 Typescript，不妨參考以下這些資源。

- [TS 教學](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)

TypeScript 是 JS 的超集合。
TypeScript 提供 JavaScript 的所有功能，並在這些功能之上再加一層：TypeScript 的型別系統。

- [Exploring ES6](https://leanpub.com/exploring-es6) 這本書，作者是 Axel Rauschmayer
- [ES6 Katas](https://jskatas.org/#bundle-es6-katas) 網站
- [Babel 編譯器](https://github.com/babel/babel)
