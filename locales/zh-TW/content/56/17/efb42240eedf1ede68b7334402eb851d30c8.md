# 說明

在這份練習中，你將套用[圍棋的規則](https://matmoore.github.io/learngo/)。規則本身已經寫好了，你只需要套用它們來更新 Game，並處理任何錯誤或違反規則的情況。

遊戲的表示方式如下：

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

這個遊戲有 4 條規則：

- 每個交叉點上只能有一顆棋子。
- 對手的棋子可以被吃掉。
- 你不能把棋子下在會讓自己的棋子被吃掉的位置。
- 你不能重複使用同一個交叉點。

## 1. 套用規則

請撰寫 `apply_rules` 函式的內容，它會接收一個初始的 `Game` 和一組規則，並在套用規則後回傳新的 `Game`。

其中三條規則會檢查是否違反規則，並可能回傳錯誤，因此回傳型別是 `Result(Game, String)`。如果這些規則中有任何一條失敗，就應該回傳原始的遊戲，但要把 `error` 欄位更新成相關的錯誤。

另一條規則不會檢查違規，因此不會失敗（不過它可以回傳變更後的 `Game`），所以回傳型別是 `Game`。

如果所有規則都通過，就應該保留規則對 `Game` 所做的所有變更，並切換玩家。

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
