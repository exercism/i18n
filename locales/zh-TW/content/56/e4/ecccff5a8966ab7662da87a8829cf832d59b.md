# 簡介

布林運算式是針對一個或多個值所提出的問題，答案可以是 `true` 或 `false`。
結果為 true 的運算式會回傳 `1`；結果為 false 的運算式則回傳 `0`。
此外，數字本身也有真假值。零是 `false`，非零是 `true`。

舊版的 C 程式碼可能直接使用 `int` 型別來表示布林值，也可能由程式設計師自行定義 `TRUE` 和 `FALSE` 這類常數，把 `1` 和 `0` 對應成布林表示法。

到了 C99 版本，新增了 `_Bool` 型別。
標頭檔 `stdbool.h` 定義了三個新的布林符號：`bool`、`true` 和 `false`。
`true` 對應到 `1`，`false` 對應到 `0`，而 `bool` 則對應到 `_Bool`。
所以現在，程式設計師不必直接使用 `int`，也不用自己打造布林對應，只要引入 `stdbool.h`，就能在程式碼中自動取得布林符號。

## 比較運算子

C 支援六個比較運算子：`==`（等於）、`!=`（不等於）、`>`（大於）、`<`（小於）、`>=`（大於或等於）、`<=`（小於或等於）。
這些運算子會比較值之間的關係，並將其化為布林值。

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 布林運算子

C 支援三個布林運算子：`||`（或）、`&&`（且）和 `!`（非）。

`!` 只用於一個運算元，會反轉該運算元的布林值。
例如 `0` 是 `false`，但 `!0` 是 `true`。

`||` 和 `&&` 則用於兩個運算元。
只有在左邊的運算元還無法決定運算式的結果時，才會評估右邊的運算元。
也就是說，`||` 只在左邊的運算元評估為 `false` 時，才會評估右邊的運算元。
`&&` 只在左邊的運算元評估為 `true` 時，才會評估右邊的運算元。
