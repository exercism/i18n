# 關於

正規表示式（regex）是 Elixir 中處理字串的強大工具。Elixir 的正規表示式遵循**PCRE**規範（**P**erl **C**ompatible **R**egular **E**xpressions）。代表正規表示式意義的字串模式會先經過編譯，再用來比對整個字串或字串的一部分。

在 Elixir 中，建立正規表示式最常見的方式是使用 [`~r` sigil][sigils-regex]。Sigil 為 Elixir 中常見的工作提供了_語法糖_的捷徑。在這個例子中，`~r`是使用 [`Regex.compile!/2`][regex-compile] 的捷徑。

```elixir
Regex.compile!("test") == ~r/test/
# => true
```

[`=~/2`][regex-match-operator] 運算子可用來對字串執行正規表示式比對，並回傳`boolean`結果。

```elixir
"this is a test" =~ ~r/test/
# => true
```

## 正規表示式語法回顧

- 正規表示式模式中的某些字元具有特殊意義，若要按字面使用該字元，必須以`\`跳脫，例如`~r/\?/`。
- _字元類別_（例如`\d`、`\w`）讓模式能比對某一範圍的字元
- _交替_（`|`）讓模式能比對其中一種模式
- _量詞_（`{N, M}`、`*`、`?`）讓模式能比對指定次數的重複模式
- _群組_（`()`）讓模式中的各部分能作為一個單位運作

## 擷取

正規表示式也很適合用來取出字串的一部分，這稱為_擷取_。若要_擷取_字串的某個部分，請為想擷取的部分建立一個群組（`()`），然後使用 [`Regex.run`][regex-run]。

```elixir
Regex.run(~r/Weight: (\d*)g/, "Weight: 150g")
# => ["Weight: 150g", "150"]
```

擷取群組會編號（從 1 開始），也可以在使用正規表示式取代字串部分內容時用於結果中：

```elixir
Regex.replace(~r/Weight: (\d*)g/, "Weight: 150g", "Gewicht: \\1g")
# => "Gewicht: 150g"
```

在左括號後面加上`?<name>`也能為擷取命名。使用 [`Regex.named_captures/3`][regex-named-captures] 取得含有具名擷取的映射。

```elixir
Regex.named_captures(~r/Weight: (?<weight>\d*)g/, "Weight: 150g")
# => %{"weight" => "150"}
```

## 修飾詞

正規表示式的行為可以在結尾加上特殊旗標來調整，例如`~r/test/i`。

- `caseless` `i`：忽略大小寫
  ```elixir
  "A" =~ ~r/a/
  # => false
  "A" =~ ~r/a/i
  # => true
  ```
- `unicode` `u`：啟用像`\p`這類 Unicode 專屬模式，並讓`\w`等字元類別也能比對 Unicode
  ```elixir
  "ö" =~ ~r/^\w$/
  # => false
  "ö" =~ ~r/^\w$/u
  # => true
  ```
- [還有更多：`dotall`、`multiline`、`extended`、`firstline`、`ungreedy`][regex-modifiers]

## 動態建立正規表示式

因為`~r` sigil 是`"pattern" |> Regex.escape() |> Regex.compile!()`的捷徑，你也可以使用字串內插來動態建立正規表示式模式：

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```

## 正規表示式與`String`模組

雖然正規表示式很強大，但使用它們並不總是明智：

- 它們必須先編譯才能使用，這會耗費運算時間與記憶體。
- 它們可能比直接使用字串函式來得慢。

根據經驗法則，只要情況允許，最好使用 [`String`模組的函式][string-functions]。

```elixir
# Don't use regular expressions to check a suffix:
if "YELLING!" =~ ~r/!$/, do: "Whoa, chill out!"

# Use a string function:
if String.ends_with?("YELLING!", "!"), do: "Whoa, chill out!"
```
