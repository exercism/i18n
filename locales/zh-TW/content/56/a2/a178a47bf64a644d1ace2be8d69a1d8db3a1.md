# 關於

在 Haxe 中，例外是處理執行程式碼時所發生錯誤的安全方式。所有例外都應該包含一段描述錯誤的訊息。我們可以使用`throw`關鍵字來_拋出_例外：

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

當例外被拋出時，程式碼會尋找一段被指派來處理該錯誤的程式碼。如果找不到，就會顯示錯誤訊息，同時停止程式的執行。

若要在 Haxe 中處理例外，我們會使用`try-catch`區塊。這個區塊敘述由一個`try`區塊和一或多個`catch`區塊組成。`try`區塊會_嘗試_執行一段程式碼，而`catch`區塊則在一旁待命，以便在例外被拋出時_捕捉_它，讓執行不會中斷。當`catch`區塊捕捉到例外時，也會執行區塊內的所有內容：

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch`區塊引數的型別應該省略。

有一點很重要：例外應該用在真正發生例外狀況、需要特別處理的錯誤時。不應該把它用於程式的控制流程，因為那被視為不良設計，往往會導致效能與可維護性不佳。
