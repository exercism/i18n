# Instructions

你的朋友 Li Mei 經營一間果汁吧，賣的是美味的綜合果汁。
你是她店裡的常客，有天發現自己其實可以讓朋友的生活輕鬆一點。
你決定運用你的程式設計技能，幫 Li Mei 分擔一些工作。

## 1. 判斷調製一杯果汁需要多久

Li Mei 喜歡事先告訴客人，他們從菜單上點的那杯果汁要等多久。
她很不容易記住確切的數字，因為每種果汁調製的時間都不一樣。
`'Pure Strawberry Joy'`需要 0.5 分鐘，`'Energizer'`和`'Green Garden'`各需要 1.5 分鐘，`'Tropical Island'`需要 3 分鐘，`'All or Nothing'`需要 5 分鐘。
至於其他飲品（例如特惠品），可以假設準備時間是 2.5 分鐘。

為了幫你的朋友，請寫一個函式`timeToMixJuice`，它接受菜單上的一杯果汁作為引數，回傳調製這杯飲品所需的分鐘數。

```javascript
timeToMixJuice('Tropical Island');
// => 3

timeToMixJuice('Berries & Lime');
// => 2.5
```

## 2. 補充萊姆角的存量

Li Mei 的許多飲品都會用到萊姆角，無論是當作材料，還是作為裝飾的一部分。
所以早上開始上班時，她得先確定裝萊姆角的容器是滿的，才能應付接下來的一天。

請實作函式`limesToCut`，它接受 Li Mei 需要切的萊姆角數量，以及一個代表她手邊整顆萊姆存量的陣列。
一顆`'small'`萊姆可以切出 6 個萊姆角，一顆`'medium'`萊姆可以切出 8 個，而`'large'`萊姆則可以切出 10 個。
她總是按照萊姆在陣列中出現的順序來切，從第一項開始。
她會一直切，直到切出所需的萊姆角數量，或是萊姆用完為止。

Li Mei 想事先知道她總共需要切幾顆萊姆。
`limesToCut`函式應該回傳需要切的萊姆數量。

```javascript
limesToCut(25, ['small', 'small', 'large', 'medium', 'small']);
// => 4
```

## 3. 完成收班

Li Mei 總是工作到下午 3 點。
之後由她的員工 Dmitry 接手。
Li Mei 的班結束時，常常還有已經點好、卻還沒調製的飲品。
Dmitry 接著會把剩下的果汁調製好。

為了讓交接更順利，請實作函式`remainingOrders`，它接受 Li Mei 班表剩餘的分鐘數，以及一個已經點好、但還沒調製的果汁陣列。
這個函式應該回傳 Li Mei 在下班前無法開始調製的訂單。

班表剩餘的時間永遠大於 0。
要調製的果汁陣列永遠不會是空的。
此外，訂單會按照它們在陣列中出現的順序來調製。
只要 Li Mei 開始調製某杯果汁，她就一定會把它做完，即使得多工作一會兒。
如果沒有剩下任何需要 Dmitry 處理的訂單，就應該回傳一個空陣列。

```javascript
remainingOrders(5, ['Energizer', 'All or Nothing', 'Green Garden']);
// => ['Green Garden']
```
