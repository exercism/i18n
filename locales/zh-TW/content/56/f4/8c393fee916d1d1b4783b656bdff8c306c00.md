# 指示

在這道練習中，你將撰寫程式碼，替工廠員工印出名牌。員工有 ID、名字和部門名稱。員工名牌標籤的格式如下：`"[id] - name - DEPARTMENT"`。

## 1. 印出員工的名牌

實作`NameBadge.print/3`函式。這個函式會接收 ID、名字和部門，並回傳名牌標籤，其中部門名稱以大寫表示。

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. 印出新進員工的名牌

由於電腦系統的一個古怪設計，新進員工剛開始在工廠工作時，偶爾還沒有 ID。因為名牌是必須佩戴的，他們會拿到一個沒有 ID 前綴的臨時名牌。

擴充`NameBadge.print/3`函式。當 ID 缺少時，印出的名牌就不包含 ID。

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. 印出老闆的名牌

就算是工廠老闆，也必須隨時佩戴名牌。不過，老闆沒有部門。在這種情況下，標籤應該印出`"OWNER"`，而不是部門名稱。

擴充`NameBadge.print/3`函式。當部門缺少時，假設這個名牌是屬於公司老闆的。

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

注意，老闆也可能同時是新進員工。

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
