# 關於

關於 Ruby 字串，最重要的一點是要記住：字串是物件，你可以對它們呼叫方法。
你可以在 [Ruby 文件][ruby-doc.org-string] 中找到所有方法。

另外也值得知道的是，字串可以用單引號（`'`）或雙引號（`"`）來建立。
單引號字串不會處理 ASCII 跳脫序列（\n、\t 等），也不會進行[字串插值][ruby-for-beginners.rubymonstas.org-interpolation]，而雙引號字串兩者都會處理。

你也可以使用 [heredoc 語法][ruby-heredoc]，或是 `%q`和`%Q`輔助寫法來建立字串。

[ruby-doc.org-string]: https://docs.ruby-lang.org/en/master/String.html
