# 簡介

在 Factor 裡，組合詞的方式就是把詞一個接一個寫下來。你書寫它們的順序，本身就是它們結合的方式。程式設計師稱這種做法為函式組合（英文：*function composition*）。一個詞的主體本身就是一連串的詞：每個詞會從堆疊消耗一些值並推入它的結果，而下一個詞則接著前一個詞停下的地方繼續。因此，定義

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

本身就已經是`cleanupname`、`first`和`1string`的組合。

這個練習也會介紹**引號**：一段可以儲存為值、稍後再執行的程式碼，而不是當場就執行它。

## 引號

引號是一段用方括號包起來的程式碼。寫下來的時候它不會執行，而是以值的形態待在堆疊上：

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call`會執行引號：

```factor
3 [ 2 * ] call .    ! => 6
```

當你需要把程式碼當成資料傳遞時，就會寫下引號：可能是要稍後執行，也可能是要傳給組合子，也就是一個以引號作為輸入的詞。

## `compose`

`compose ( quot1 quot2 -- combined )`會把兩個引號黏合成一個，並依書寫的順序執行它們：

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

你通常會發現，用`:`...`;`定義一個小詞，會比使用`compose`更好讀；但當你需要臨時組出引號時，`compose`就很方便。

當手上的積木本身還不是引號時，`>quotation ( seq -- quot )`（來自[`quotations`][quotations]）可以把一串值和詞的參照變成可呼叫的引號：

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## 將同一個引號套用到兩個輸入

`bi@ ( x y quot -- ... )`會對`x`執行一次引號，再對`y`執行一次，並把兩個結果都留在堆疊上：

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

這個練習的`couple`任務會接收兩個名字；`bi@`是將`initial`分別套用到每個名字上最自然的方式。

## 幾個字串相關的詞

這個練習需要幾個處理字串的小詞，分別來自三個詞彙庫：[`sequences`][sequences]、[`ascii`][ascii]和[`strings`][strings]：

- `replace ( seq old new -- new-seq )`（在`splitting`中）：替換子字串。
- `[ blank? ] trim`（`trim`在`sequences`，`blank?`在`ascii`）：移除前後的空白。
- `1string ( char -- str )`（在`strings`中）：把單一字元包成字串。
- `>upper ( str -- upper )`（在`ascii`中）：把字串轉成大寫。
- `append ( s1 s2 -- s )`（在`sequences`中）：串接兩個字串。
- `prepend ( s1 s2 -- s )`（在`sequences`中）：先接上`s2`再接上`s1`（也就是把`append`的輸入順序對調）。
- `glue ( s1 s2 sep -- s )`（在`sequences`中）：用分隔符號把兩個字串接起來。
- `surround ( seq pre post -- new )`（在`sequences`中）：在字串前後加上前綴和後綴。

Unicode 字元可以在字串裡寫成`\u{XXXX}`，其中`XXXX`是十六進位的碼位。這個練習裡會用到愛心符號`\u{2764}`（❤）。

## 格式化輸出

當`append`/`glue`/`surround`的表達力不夠時，[`formatting`][formatting]提供了 printf 風格的`sprintf`：

```
sprintf ( inputs... format-string -- str )
```

`%s`會代入字串，`%d`代入整數，`%f`代入浮點數；選擇性的寬度、精確度和填充修飾詞則放在`%`和型別字母之間：

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

若要在數字和字串之間來回轉換，[`math.parser`][math.parser]提供了`number>string`和`string>number`：

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
