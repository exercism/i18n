# 說明

在這個練習中，你會撰寫程式碼，透過一個國際撥號代碼雜湊映射來追蹤國際撥號代碼。

這個映射以整數作為鍵（也就是撥號代碼），並以字串（國家名稱）作為值。

這個練習有 11 個與撥號代碼相關的任務。

## 1. 建立預先填入資料的雜湊映射

有一個預先填入資料的雜湊映射，其中包含以下 3 個撥號代碼：「United States of America」的代碼是 1，「Brazil」的代碼是 55，「India」的代碼是 91。定義 `countries`變數來儲存這個預先填入資料的雜湊映射：

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. 將國家加入映射

將代碼為 44 的「United Kingdom」加入任務 1 建立的映射：

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. 取得對應某個國家代碼的國家名稱

取得撥號代碼為 55 的國家名稱

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. 更新國家名稱

將「United States of America」的名稱改為「Les États-Unis」：

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. 檢查映射中是否存在某個國家

檢查任務 1 建立的映射中是否有 Brazil 的記錄

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. 嘗試更新不在映射中的國家名稱

試著更改一個代碼不在映射中的國家名稱，例如 999。這應該不會對映射造成任何改變：

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. 從映射中移除國家

從映射中移除 India：

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. 找出名稱最長的國家

處理映射中的值，找出名稱最長的那一個：

```clojure
(longest-name countries)
;;=> "United States of America"
```
