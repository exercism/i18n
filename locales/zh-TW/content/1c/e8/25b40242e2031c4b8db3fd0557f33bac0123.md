# 關於

_「日期和時間是我們教小小孩的東西。這能有多難？」_

許多程式設計師都犯過這個錯誤，而隨後的經歷往往對他們的健康和幸福造成很不好的影響。

任何用日期和時間做非簡單程式設計的人，至少應該準備好理解並減輕潛在的問題。

本文會試著概述 Julia 如何處理日期和時間，但想深入了解細節，還是得查閱[手冊][Dates]。
另外也有一本 [Wikibook][Wikibook]，有些讀者可能會覺得它的說明更清楚，其中還包含一張很有幫助的型別階層[圖示][type-hierarchy]。

## `Dates`模組

大部分的基本功能都在`Dates`裡，這個模組包含在預設安裝中，但不屬於標準函式庫。

要使用這個模組，有兩種做法：

1. 加入`import Dates`，然後在所有函式呼叫前面加上`Dates.`
2. 加入`using Dates`，這會把整個模組帶進目前的命名空間（_除了少數有問題的名稱_）。

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

`Dates`模組又大又複雜，但它提供四大類功能：

- `Dates.Date`，包含日、月、年，但不含時刻。
- `Dates.Time`，包含時刻，精確到奈秒，但不含日期。
- `Dates.DateTime`，結合日期和時刻，精確到毫秒。
- `Dates.Period`，處理時間與日期的區間。

請注意，`DateTime`通常_不_包含時區資訊（Python 會把這稱為「naive」datetime）。
唯一的例外是`now()`，它會從你的系統時鐘取得本地時間，需要時還能轉換成 UTC。

其他時區運算則需要`TimeZones.jl`套件，它不屬於預設安裝的一部分。
截至 2025 年 6 月，Exercism 內還無法使用這個功能，但未來可能會加入。

最常見的需求大概是：

- 解析某種合適的輸入格式，以建構`Dates`型別。
- 從`Dates`型別取得所需的數字或字串格式。
- 對`Date`、`Time`或`DateTime`值套用一個偏移量。
- 計算兩個這類值之間的區間。
- 取得目前的日期（用`today()`）和／或時間（用`now()`）。

~~~~exercism/note
為了減少視覺上的干擾，本文後續大部分的範例程式碼都假設已使用`using Dates`，並避免在函式呼叫中包含模組名稱`Dates.`。
~~~~

### 日期與時間格式

日期和時間有許多種寫法，而且往往因文化而異。
像「7/6/23」這種全數字的日期既模糊又令人困惑，還曾在跨國組織裡造成許多代價高昂的錯誤（_作者是從慘痛的親身經驗說出這句話的_）。

國際標準定義在[`ISO 8601`][ISO8601]中，它有兩個主要優點：

- 解析快速且沒有歧義。
- 排序很容易，因為日期時間可以當作一般文字，按字母順序排序。

在前面的範例中，我們看到`Date.now()`回傳了`2025-06-21T16:03:04.161`。

它由幾個部分組成：

- 日期部分是`YYYY-MM-DD`。
- 時間部分是`hh:mm:ss`。
- 小數點後面可選擇加上毫秒（或更小的單位）。

其他字串格式會在後面的章節討論。

## 日期

`Dates.Date`是相對簡單的純日期型別，不涉及時間或時區。

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

有各種存取函式可以取得日期的個別部分，而且它們成對出現，以大小寫區分。

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month

# various compound methods are also available, returning a tuple
julia> monthday(date1)
(6, 23)
```

### 查詢函式

有各種[查詢函式][query-func]對曆法有一定程度的理解。
下一個範例只展示了其中幾個。

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## 時間

`Dates.Time`是基本的純時間型別。
它不涉及日期：時間在午夜會自動回到`Time(0, 0, 0)`。

完整的建構子格式是`Time(hour, min, sec, millisec, microsec)`，或是對應的 ISO 8601 寫法。

所有參數都是選用的，預設值為`0`。

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time(14, 57, 25, 142, 32)`
14:57:25.142032

julia> Time("14:57:25.142")
14:57:25.142
```

和`Date`一樣，個別部分可以透過存取函式取得：

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## 日期時間

`Dates.DateTime`結合了`Date`和`Time`型別的大部分功能。

它是這三個型別中最有彈性的，不過時間解析度只到毫秒（`Time`可以解析到奈秒）。

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

年和日的參數預設為`1`，時間相關的參數則全部預設為`0`。

要把這些參數全部記清楚可能不太容易，所以 ISO 格式或許更可取。

或者，也可以像上面的範例那樣，用`Date`和`Time`來建構`DateTime`。

## 期間

每個日期／時間元件都有自己的[`Period`][period]型別，從`Year`一路到`Nanosecond`，代表一段時間區間。
這些型別在做算術運算時特別有用。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

另外還有[`CompoundPeriod`][compound-period]型別，可以結合多個`Period`型別。
奇怪的是，這個型別目前需要加上模組名稱，才能避免命名空間錯誤（_這感覺像是個 bug_）。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> offset = Dates.CompoundPeriod(Year(21), Second(-61))
21 years, -61 seconds

julia> dt1 + offset
2046-06-23T14:56:24.142
```

減去日期／時間時，得到的期間會以天（對日期而言）或奈秒（對時間而言）為單位。
把它們[`canonicalize`][canonicalize]成`CompoundPeriod`可能會很有幫助。

```julia-repl
julia> diff = Time(23, 14, 00) - Time(1, 23, 52)
78608000000000 nanoseconds

julia> canonicalize(diff)
21 hours, 50 minutes, 8 seconds

julia> typeof(canonicalize(diff))
Dates.CompoundPeriod
```

處理`Period`型別時，Julia 會試著聰明地應對月份長度之類曆法上的不規則，必要時進行捨入。

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## [捨入][rounding]

`floor`、`ceil`和`round`這些函式應該在整數／浮點數中見過，但它們也能用於日期和時間。
用第二個引數指定要捨入到的`Period`。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> floor(dt1, Minute(15))
2025-06-23T14:45:00

julia> ceil(dt1, Minute(30))
2025-06-23T15:00:00

julia> ceil(dt1, Month(1))
2025-07-01T00:00:00
```

## 字串表示法

我們前面提過 ISO 8601 標準，它是 Julia 在格式化或解析字串時預設的日期／時間表示法。

顯然，還有許多其他格式經常被使用，而且往往因文化而異。
為了處理這些格式，Julia 提供了`DateFormat`型別，可以用任意複雜度的格式字串來建構。

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

上面的範例非常簡單，只是一個歐洲常見的日／月／年格式日期。
範例展示了兩種語法變體，但結果完全相同。

接著就能用`DateFormat`來解析任何合適的字串：

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

建立`DateFormat`會有相當大的額外負擔，所以像這裡用`dtfmt`一樣只做一次，在對大量日期／時間字串迴圈時有助於效能。

格式可以比這複雜得多，詳情請參閱[手冊][dateformat]。

熟悉其他程式語言的人可能會注意到，它和已有數十年歷史的`strptime`和`strftime`函式有相似之處。
Julia 版本承襲了這份傳統，但力求更簡潔、更有彈性。

同一個`DateFormat`也可以用來把日期／時間輸出成任何想要的字串格式，只要使用[`Dates.format()`][format]函式。

可惜的是，`format`似乎有命名空間衝突（至少在 Julia 1.11.5 中是如此），所以即使已經`using Dates`，最好還是加上`Dates.`前綴。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

如[文件][wiki-format]所述，`"e, u d"`會給出星期幾和月份的縮寫文字表示法。

文字表示法預設為英文。
也可以加入其他語言，不過目前對這方面的支援還不夠理想。
