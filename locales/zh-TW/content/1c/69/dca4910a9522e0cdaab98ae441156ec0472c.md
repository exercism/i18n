# 簡介

F# 的 `char` 型別是一個 16 位元的值，用來表示文字中最小、可定址的組成單位，且預設不可變。

`char`可以用單引號定義成常值：

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

字串是字元的序列。

可以透過（從零開始的）索引從字串中取出單一的 `char`：

```fsharp
"Exercism"[4] //  =>  'c'
```

對字串進行疊代時，每一步都會回傳一個 `char`。

為了方便起見，下一個範例使用了高階函式和匿名函式。
這些之後會在課程大綱中妥善介紹，不過現在，它們是對字串中的字元撰寫迴圈的一種簡潔方式。

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

如上所示，`char`可以轉型成它的 `int` 值。
這對其他書寫系統也同樣適用（*至少在某些情況下*）：

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

比較字元時，使用的是底層的 Int16：

```fsharp
'A' < 'D'  // =>  true
```

此外，`int` 也可以轉型成 `char`：

```fsharp
char 77  // => 'M'
```

`System.Char` 程式庫包含了 .NET 語言應有的一整套方法，例如大小寫轉換：

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
