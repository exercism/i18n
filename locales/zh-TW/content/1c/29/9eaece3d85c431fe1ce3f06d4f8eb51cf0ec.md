# 指令補充

## 實作

在 Cairo 中，由於原生不支援浮點數，我們會用整數來表示小數值。

這種做法在區塊鏈開發中不可或缺，能讓計算維持精確。

在本練習裡，我們把公轉週期換算成微秒，藉此使用**定點運算**。

舉例來說，水星 `0.2408467` 地球年的公轉週期，乘以 `1,000,000` 後就變成 `240,846,700` 微秒。

為了顧及小數精度，測試案例假設算出的年齡有**兩位小數**，並以整數表示。

也就是說，`31.69` 年的年齡在程式碼裡會存成 `3169`。

為了做到這點，我們在進行除法之前會先乘以 100。

以下是一個例子：

```rust
let mercury_orbital_period = 240_846_700; // in microseconds
let age_microseconds = age_seconds * 1_000_000;
// multiplying with 100 to retain 2 decimal places
age_microseconds * 100 / mercury_orbital_period
```

透過這種做法，你就能把小數值準確地以整數表示，同時維持所需的兩位小數精度，這對測試能否通過至關重要。
