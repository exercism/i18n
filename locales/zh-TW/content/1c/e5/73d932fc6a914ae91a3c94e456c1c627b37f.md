# 說明

你的日本朋友 Kuroko 是一位在國際上很受歡迎的實況主。
Kuroko 的直播行程相當複雜，每天的直播似乎都在不同的時間開始。

他請你幫忙做一個小型應用程式，用來依照觀眾所在地的時區顯示他的行程：Kuroko's Clock。
他還有一個額外的要求：這個應用程式要能用兩種不同的語言顯示時間：日文和美國英文。

## 1. 來談談日期

定義一個函式 `showLocalDate : Locale -> Int -> Month -> Int -> String`，用來顯示（有效的）當地日期。

在 `US` 地區設定中，格式為 `Month/Day/Year`，不補前導零。

在 `JP` 地區設定中，格式為 `Year年Month月Day日`，同樣不補前導零。

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. 開播時間到了

定義一個函式 `showLocalTime : Locale -> Int -> Int -> String`，用來顯示（有效的）當地時間。

在 `US` 地區設定中，小時會以 12 小時制顯示，並加上「PM」或「AM」，分鐘則會補前導零。

在 `JP` 地區設定中，小時會以 24 小時制顯示在「時」之前，分鐘則不補前導零，顯示在「分」之前。

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. 進入時區

定義一個函式 `showDateTime : Locale -> Zone -> Posix -> String`，用來依照特定地區設定，顯示相對於某個時區的日期和時間。

使用 `showLocalDate` 和 `showLocalTime` 來顯示最終結果。

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
