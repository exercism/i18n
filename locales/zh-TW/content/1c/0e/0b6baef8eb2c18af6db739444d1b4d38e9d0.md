# 關於

[Nil][nil-dictionary] 是一個英文單字，意思是「沒有」或「零」。在 Elixir 中，`nil`是一個特殊的值，代表值的_不存在_。

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil`是一個原子，但通常寫成`nil`，而不是`:nil`。布林值`true`和`false`也是原子。

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

你可以用 [`==`][kernel-equal]、模式配對，或 [`is_nil`警衛][kernel-is-nil] 來檢查變數的值是不是`nil`。

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
