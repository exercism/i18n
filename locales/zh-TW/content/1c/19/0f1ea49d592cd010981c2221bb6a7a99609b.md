# 簡介

大多數程式都會相依於一些函式庫。手動管理這些相依項目可能會很麻煩。幸運的是，Rust 生態系標準配備就有`cargo`！`cargo` 可以幫專案管理相依項目。

在 Rust 裡，你常會看到外部套件被稱為「crate」。crate 是 Rust 的編譯單元。一個 crate 可以編譯成執行檔，也可以編譯成函式庫。

大多數情況下，新增外部相依項目就跟在`Cargo.toml`檔案裡加一行一樣簡單。

這個練習已經幫你加好了 [`enum-iterator`](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) 和 [`int-enum`](https://docs.rs/int-enum/0.5.0/int_enum/) 這兩個相依項目。
