# 指令補充

## 加分題

用這個字串測試你的函式：`uüu`，看看會發生什麼事。
試著寫一個能正確反轉這個字串的函式吧。
提示：字素叢集

若要執行加分題的測試，請從最後一個測試移除忽略旗標（`#[ignore]`），然後用下列指令執行測試：

```bash
cargo test --features grapheme
```

加分題會需要用到外部函式庫（在 Rust 的用語裡稱為 `crate`）。
要找這些函式庫，[crates.io](https://crates.io/) 是個不錯的地方，它是 crate 的官方儲存庫。
請記得，我們的測試執行器只支援有限數量的 crate。
完整的清單在[這個檔案](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml)的`[dependencies]`區段中。

[查看說明文件](https://doc.rust-lang.org/cargo/guide/dependencies.html)，了解如何在專案中使用外部的 crate。
