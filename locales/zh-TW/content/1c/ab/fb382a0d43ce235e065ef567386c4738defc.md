# 指令補充

## 等等，這不可能吧！

在 Roc 裡，完全不使用*任何*內建函式來實作這些陣列操作幾乎是不可能的，因為你總得有辦法在陣列尾端附加元素，或在開頭插入元素。
在其他語言裡，你可能會用像 Haskell 的`:`或 Python 的`+=`這類運算子，但在 Roc 裡，你必須使用 [`List`函式](https://www.roc-lang.org/builtins/main/#Builtin.List)。

所以在這道練習中，你可以使用`List.append`（但請避免使用其他任何內建函式）。

許多函式程式語言會用連結串列當作主要的集合型別。
在連結串列開頭插入元素、或從開頭取出第一個元素都很有效率，所以在那些語言裡，你會用`List.prepend`來實作陣列操作。
不過在 Roc 裡，`List`是陣列（連續的一塊位元組）。
陣列和連結串列的特性不同，例如陣列可以有效地用索引存取元素，也可以在尾端附加新元素。
因此，在 Roc 裡我們很常使用`List.append`，很少使用`List.prepend`。

## 命名

Roc 使用的名稱和一般指令中列出的名稱略有不同：

- `concat` 而非 `append`
- `join` 而非 `concatenate`
- `len` 而非 `length`
- `fold` 而非 `foldl`
- `fold_rev` 而非 `foldr`

不過，以下這些函式名稱在 Roc 中是標準的：

- `filter`
- `map`
- `reverse`

## 提示

試著用用看：

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

或者

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
