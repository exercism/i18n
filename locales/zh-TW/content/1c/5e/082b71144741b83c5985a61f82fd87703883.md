# 簡介

**遞迴函式**是會呼叫自身的函式。

一個_遞迴函式_至少需要有一個_基本情況_，以及至少一個_遞迴情況_。

**基本情況**會回傳一個值，而不會再次呼叫函式。
**遞迴情況**會再次呼叫函式，並修改輸入，讓它在某個時間點符合基本情況。

以下是一個計算陣列元素數量的範例。

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

一個_遞迴函式_可以有許多_基本情況_和/或許多_遞迴情況_。
例如，[費波那契數列][wiki-fibonacci]就是一個具有兩個_基本情況_的遞迴數列。

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

計算某個給定值`x`在陣列中出現的次數，會有兩個_遞迴情況_。

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

在實務上，對陣列和其他可列舉的資料結構進行疊代時，最常使用內建函式，例如`map`和`reduce`，或是[使用資料流][map-implementation]，例如`[.[] | select(...)]`。
在底層，有些內建函式是[使用遞迴實作][walk-implementation]的。
