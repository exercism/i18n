# 說明

你是個熱愛賞鳥的人，會記錄過去七天有多少鳥飛進你的花園。

你有五個任務，全都和造訪你花園的鳥的數量有關。

## 1. 查看上週的數量

你以 JSON 格式儲存鳥的數量。
一個「main」陣列會儲存每週數量的陣列。
每週的數量是一個由七個整數組成的陣列，每個數字對應一週中的一天。
你總是將新的週資料附加到 main 陣列的末端。
實作這個篩選器，讓它回傳上週的數量。

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. 查看昨天有多少鳥來訪

實作篩選器，回傳昨天有多少鳥造訪你的花園。
鳥的數量依日期排序，第一個元素是最早那天的數量，最後一個元素則是今天的數量。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. 計算來訪鳥隻的總數

實作篩選器，回傳這週造訪你花園的鳥的總數。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. 計算忙碌的天數

有些日子比其他日子更忙。
所謂忙碌的一天，是指有五隻或更多鳥造訪你花園的一天。
實作篩選器，回傳這週忙碌的天數。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. 查看是否有沒有任何鳥來訪的一天

實作篩選器：如果這週有任何一天沒有鳥造訪花園，就回傳`true`；否則回傳`false`。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
