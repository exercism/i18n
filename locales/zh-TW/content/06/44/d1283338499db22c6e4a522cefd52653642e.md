# 簡介

機率遊戲需要隨機性的來源。Factor 的[`random`][random]詞彙表提供一個泛用詞`random`，它會配合你交給它的任何東西，另外還有用於洗牌與取樣的輔助詞，以及讓隨機性能在測試中*可重現*的方法。

## 將詞標記為`inline`

這個練習有些任務會定義一個詞，它接受一個 *quotation*（一個 `[ … ]` 區塊）作為引數並執行它。Factor 對此有一條鐵律：**一個會`call`它作為引數收到的 quotation 的詞，必須宣告為`inline`**，寫法是把`inline`直接放在結尾的`;`之後。

`inline`會告訴編譯器，把該詞的本體拼接進每一個呼叫位置，而不是將它獨立編譯一次。

- 呼叫端的 quotation 會直接被縫合進來，因此**無論 quotation 在堆疊上留下什麼，都會流回呼叫端**，即使這個詞本身的堆疊效應並未宣告任何輸出。

這裡有一個小詞，它會推入`10`，然後執行交給它的 quotation：

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

它的堆疊效應`( quot -- )`並未指名任何輸出，然而用兩個*不同*效應的 quotation 呼叫它，會產生不同的結果，而且全都流回呼叫端：

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`：單一元素

`random`（在[`random`][random]中）對它的引數是泛型的：

```
random ( obj -- elt )
```

- 給定一個**整數**`n`，它會回傳一個落在`[0, n)`範圍內的隨機整數：

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- 給定一個**序列**，它會回傳一個隨機元素：

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

要擲出一般的骰子，可以把範圍往上挪一位：對`6`取`random`會得到 0 到 5，所以`6 random 1 +`會得到 1 到 6。

## 抽取多個值

要收集固定數量的隨機抽取結果，可以用`replicate`（在[`sequences`][sequences]中）重複執行一個 quotation：

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`：就地洗牌

`randomize`（在[`random`][random]中）會回傳把元素以隨機順序排列的序列：

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

它是**就地**洗牌，並回傳同一個序列，所以如果你需要保留原本的順序，請先`clone`。

## `sample`：多個相異元素

`sample`（在[`random`][random]中）會從序列中抽取`n`個*相異*元素，就像發一手牌，絕不會拿到同一張牌兩次：

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

要求的元素數量超過序列所擁有的數量時，會產生錯誤。

## 可重現的隨機性

預設情況下，`random`會從以系統時鐘作為種子的全域產生器抽取，所以每次執行都不同。若要用於測試，或任何你想要能*重播*的遊戲的時候，就用固定的**種子**綁定一個產生器。

`<mersenne-twister>`（在[`random.mersenne-twister`][mt]中）會用整數種子建立一個產生器，而`with-random`（在[`random`][random]中）會安裝該產生器並執行一個 quotation：

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

quotation 內的所有東西（`random`、`randomize`、`sample`）都會從設定好種子的產生器抽取，所以同樣的種子永遠會重現同樣的結果。

一個接受 quotation 作為引數、並透過`with-random`執行它的詞，屬於[將詞標記為`inline`](#marking-a-word-inline)這條規則的範圍：`with-random`最後會`call`那個 quotation，所以這樣的包裝詞必須標記為`inline`。
