# 簡介

條件運算式用來根據條件是**true**還是**false**來執行程式碼。這些運算式的寫法如下：

```haxe
if (condition) {
  expressions
};
```

條件的輸出是`Bool`型別，因此當輸出為`true`時，就會執行這些運算式。

有時候，當條件的結果其實是`false`時，我們會希望執行另一段程式碼。這時候就輪到`else`運算式登場了。當最初的條件為`false`時，`else`會執行其中的運算式。但如果我們想檢查多種可能的情況呢？這時就可以使用`else if (condition)`。以下是完整的範例：

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
