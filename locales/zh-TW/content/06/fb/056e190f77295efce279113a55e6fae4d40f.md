# 說明補充

## 這個練習在 Python 學習軌道上的結構

這個練習的測試預期你的程式要以 Garden `class` 的形式實作（另請參閱 [concept:python/classes]()）。
如果你不熟悉 Python 的類別，這個 [Real Python 教學][how-to-make-a-class]會是不錯的入門起點喔。

你的`class`應該實作一個名為`plants`的[`method`][methods]，它會接收學生的名字作為引數，並回傳屬於該學生的植物名稱`list`。


## 建構子

建立範例花園：

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

在測試中，這會表示成 `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`。

為了讓這種表示方式能夠運作，你的`class`需要實作一個[`__init__()`][init] [特殊方法][special-methods]。
如果你不熟悉`__init__()`或[_建構子_][what-is-a-constructor]，Python 文件中的[類別與實例物件][class vs instance objects in python]有更詳細的說明。


## 預設參數

在某些測試中，會把學生的`list`當作引數傳給`__init__()`。
這應該會覆寫題目敘述中提供的 12 位學生名冊。
下面這兩段敘述都必須能在你的`__init__()`方法中運作：


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

其中一種做法是把學生的`list`設為[預設引數][default argument values]；Python 文件在說明[函式定義][function definitions]時，也深入介紹了`default parameters`。
