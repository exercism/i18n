# If、Elseif、Else

使用`if`、`elseif`和`else`的條件式，是程式流程控制的基本組成部分。
`if`敘述會評估一個運算式，如果結果為`true`，就會執行對應的程式分支。

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

如果運算式不是布林值，評估時會判斷該值的「真值性」或「非假值性」。
在 PHP 中，下列這些值會被視為等於 false：

- 布林值`false`
- 整數`0`
- 浮點數`0.0`和`-0.0`
- 空陣列`[]`
- 空字串`""`或數字字串`"0"`
- `null`

其他所有的值都會被視為 true。

## 處理多個條件

在`if`敘述之後，你可以用`elseif`和`else`串接多個條件。

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

只有一個評估為 true 的條件式會被執行。
所以如果多個條件都可能評估為 true，它們的撰寫順序就很重要。

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
