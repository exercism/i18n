他們還拿到空白地圖，上頭標著「你在這裡」的起點。

不過情況有點混亂：Azara 的座標格式和排序方式似乎和 Rui 的不同，他們得在兩份清單之間來回查看，才能弄清楚哪些寶藏對應哪些地點。
身為剛入門的 F# 愛好者，他們來找你幫忙寫一個小程式（其實就是幾個函式），好把尋寶資訊整理得更有條理。

## 1. 擷取座標

實作`getCooordinate()`函式，它會接收 Azara 清單中的一個`(treasure, coordinate)`配對，並只回傳擷取出的地圖座標。

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. 格式化座標

實作`convertCoordinate()`函式，它會接收格式為「2A」的座標，並回傳格式為`(2, 'A')`的元組。

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. 比對座標

實作`compareRecords()`函式，它會接收一個`(treasure, coordinate)`配對和一個`(location, coordinate, quadrant)`記錄，並比較兩者的座標。
如果座標「相符」，回傳 **`true`**；如果不同，則回傳 **`false`**。
視需要重新格式化座標，以便準確比較。

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. 合併相符的記錄

實作`createrecord()`函式，它會接收 Azara 清單中的一個`(treasure, coordinate)`配對和 Rui 清單中的一個`(location, coordinate, quadrant)`記錄，並且**在座標相符時**回傳`(coordinate, location, quadrant, treasure)`。
如果座標_不_相符，則回傳形狀相同、但內容填滿`""`的元組。
視需要重新格式化座標，以便準確比較。

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
