# 指令

撰寫一個函式，把一般數字轉換成[序數](https://en.wikipedia.org/wiki/Ordinal_numeral)。針對零（0），只要回傳字串 "0"。

序數是描述某個東西在陣列中位置的數字。序數就是在這個脈絡下使用，而且用的是以英文拼寫出來的序數名稱。

序數的形式如下（至少是其中一種）：

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

所以輸入一個一般數字，就會得到對應的序數：

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
