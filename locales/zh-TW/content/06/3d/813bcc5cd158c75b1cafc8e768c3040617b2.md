# 說明

你突然感受到一陣懷舊之情，強烈地想翻出你那些舊的 Blorkemon™️ 卡。Blorkemon™️ 卡是一款很棒的經典老派卡牌交換遊戲。每張`Card`上都畫著一隻 Blorkemon™️ 怪物，還有一個攻擊威力等級，運氣好的話，這張卡甚至可能還是閃亮的。

## 1. 比較威力等級

每張 Blorkemon™️ 卡看起來都比下一張更強大，但你最好還是確認一下。

實作`isMorePowerful`函式。如果它第一個引數的卡威力嚴格高於另一張，就回傳`True`，否則回傳`False`。

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. 找出最高威力

手握滿滿的 Blorkemon™️ 卡，你應該能準備出最具毀滅性的攻擊。

實作`maxPower`函式，它會回傳兩張卡中最高的威力等級。

```elm
maxPower newthree scientuna
    --> 120
```

## 3. 將卡片排序

你好像記得每種 Blorkemon™️ 至少都有一張卡，但距離你上次確認已經過了好一陣子，你應該把卡片排序，好跟 Pulpapedia 上的官方清單比對一下。

實作`sortByMonsterName`函式，它應該接收一個`Cards`陣列，並回傳依怪物名稱排序的陣列。

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. 最酷的卡片優先

Blorkemon™️ 是有史以來最酷的東西。你可不是隨口說說，你有一套科學方法可以證明。

實作`sortByCoolness`函式，它會將卡片陣列排序，把最酷的排在最前面。一張卡的酷炫度首先取決於它的閃亮度：所有閃亮卡都比其他卡酷得多。第二個因素則是威力等級，越高越好。

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. 閃亮威力

閃亮不只是好看而已，在威力相當的 Blorkemon™️ 對戰中，閃亮的那一方永遠會勝出。這就叫做閃亮威力。

實作`compareShinyPower`函式，它將這個特性化為程式碼。兩張卡的`Order`在威力等級不同時由威力等級決定，但如果威力相同，閃亮的卡會更勝一籌。

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. 下注吧

在 Blorkemon™️ 卡的對戰中，什麼事都可能發生，但威力更高的卡仍有較高的勝算。

實作`expectedWinner`函式，它會回傳最被看好會獲勝的怪物名稱，判斷依據是`compareShinyPower`的排序結果。這個函式應該回傳預期贏家的怪物名稱，如果兩個對手擁有相同的閃亮威力，則回傳 "too close to call"。

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
