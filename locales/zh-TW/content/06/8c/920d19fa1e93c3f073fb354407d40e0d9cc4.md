# 簡介

實作 `IEnumerable<T>` 介面的型別，稱為可列舉型別。所有內建的集合型別都實作了這個介面。

可列舉型別可以用`foreach`迴圈來疊代：

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

型別必須實作一個方法，才能實作`IEnumerable<T>`：`IEnumerator<T> GetEnumerator()`。如你所見，可列舉型別會把實際疊代集合的工作交給`IEnumerator<T>`型別。這個介面有一個屬性和三個方法要實作：

- `public T Current { get; }`：取得目前的元素。
- `public bool MoveNext ();`：移到下一個元素，成功移到下一個元素就回傳`true`，否則回傳`false`（沒有更多元素了）。
- `public void Reset ();`：把列舉程式重設回初始狀態（第一個元素之前）。
