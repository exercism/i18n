# 簡介

**正規表達式**（regex）是一連串的字元，用來描述文字中的搜尋模式。

學習正規表達式的語法超出本主題的範圍。
我們會聚焦在 `jq`提供、用來運用正規表達式的運算式上。

## 正規表達式的風格

不同的工具實作的正規表達式版本各不相同。
`jq`內建 [Oniguruma][oniguruma] 正規表達式函式庫，大致上相容於 Perl v5.8 的正規表達式。

`jq`使用的特定語法可以[在 Oniguruma 的 GitHub 儲存庫中找到][onig-syntax]。

<!-- prettier-ignore -->
~~~~exercism/caution
`jq`沒有針對正規表達式的特殊語法。
它們只是以字串表示。
這表示正規表達式裡的任何反斜線，都需要在字串中跳脫。

舉例來說，數字字元類別（`\d`）必須寫成 `"\\d"`。
~~~~

## 正規表達式函式

`jq`中的正規表達式僅限於[一組篩選器][jq-regex-funcs]。

### 簡單比對

當你需要知道某個字串是否符合某個模式時，請使用`test`篩選器。

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

這個篩選器會輸出_布林_結果。

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### 關於比對結果的資訊

當你需要擷取出真正符合模式的子字串時，請使用`match`篩選器。

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

這個篩選器會輸出：

- 如果沒有比對結果，就什麼都不輸出，或者
- 如果有比對結果，就輸出一個包含各種屬性的物件。

這個範例使用反向引用語法 `\1`，尋找兩個連續且相同的母音。

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match`篩選器會為_每一個_比對結果回傳一個物件。
這個範例示範`"g"`旗標的運作方式，用來找出所有母音。

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### 擷取的子字串

和`match`篩選器類似，`capture`篩選器會在比對成功時回傳一個物件。

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

回傳的物件是**具名擷取**的對應表。

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### 只要子字串

`scan`篩選器類似加上`"g"`旗標的`match`。

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan`會輸出子字串的_串流_。

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

使用`[...]`陣列建構子來擷取這些子字串。

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### 拆分字串

如果你知道字串中想要**保留**的部分，請使用`match`或`scan`。
如果你知道想要**丟棄**的部分，請使用`split`。

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
**單參數**的`split`篩選器會把它的引數視為**固定字串**。

若要在`split`中使用正規表達式，你**必須**提供第二個引數；用空字串也可以。
~~~~

<!-- prettier-ignore-end -->

以下範例會依任意空白拆分字串。

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### 替換

`sub`和`gsub`篩選器可以轉換輸入字串，把輸入中比對到的部分替換成替換字串。

如果只想替換第一個比對結果，請使用`sub`。
如果想替換所有比對結果，請使用`gsub`。

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

替換文字可以引用比對到的子字串；使用具名擷取與[字串插值][jq-interp]。

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## 旗標

在上述所有篩選器中，FLAGS 是由零個或多個支援的旗標組成的字串。

- `g`：全域搜尋（找出所有比對結果，而不只是第一個）
- `i`：忽略大小寫的搜尋
- `m`：多行模式（「.」會比對換行符號）
- `n`：忽略空比對
- `p`：同時啟用 s 和 m 模式
- `s`：單行模式（「^」對應「\A」，「$」對應「\Z」）
- `l`：找出盡可能最長的比對結果
- `x`：延伸正規表達式格式（忽略空白與註解）

例如

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
