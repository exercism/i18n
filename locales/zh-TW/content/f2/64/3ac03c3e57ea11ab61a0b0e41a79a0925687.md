# 簡介

轉型和型別轉換，是把運算式從一種資料型態變成另一種資料型態的兩種不同做法。

運算式可以用轉型運算子`(<type>)`轉型成另一種型別。

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

如果型別不相容，就會擲回`InvalidCastException`。就數字而言，這表示接收端的型別無法表示轉型後的值。就類別而言，其中一個型別必須衍生自另一個（這點對結構也同樣適用）。

除了轉型之外，另一種做法是使用`is`運算子的型別轉換。這通常用於參考型別和可為 Null 的型別。

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

如果你需要偵測物件確切的型別，那麼`is`可能有點太寬鬆了，因為對某個類別，以及它直接或間接衍生的任何類別和介面，`is`都會傳回 true。這種情況下，解法就是`typeof`和`Object.GetType()`。

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
