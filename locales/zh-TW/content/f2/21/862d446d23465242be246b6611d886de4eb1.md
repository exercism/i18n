# 簡介

Kotlin 的`when`是一種條件運算式，用來從多個選項中選擇。
它類似 Java 中的`switch`，而且比一連串的`if` ... `else if` ... `else`更有彈性。

和`if`一樣，`when`也可以當作會產生值的運算式使用。

## 比對值

在括號中給`when`一個要拿來比對的值。
每個分支會比對這個值，直到找到符合的分支：

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 每個分支寫成`pattern -> result`。
- 分支會從上到下逐一嘗試，直到找到符合的分支。
  只有第一個符合的分支會執行。
- 對於上方未列出的任何值，使用`else`（類似一連串`if`中最終的`else`）。

這類似[模式比對][pattern-matching]。
`pattern`可以是要比對的值，也可以使用`is`依型別比對：

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

或使用`in`檢查它是否包含在範圍、集合、字串，或任何其他具有`contains`方法的物件中：

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
你也可以透過定義`contains`[運算子擴充函式][kotlin-operator-overloading]，將`in`用於其他物件。
例如，將它與[Regex][kotlin-regex]搭配使用：

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

}
```

## 防護條件

在比對值時，可以在模式後面加上`if`，放入額外條件。
這些條件稱為防護條件。

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

甚至也可以使用`else if`。

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 比對條件

或者，也可以省略值，並在每個分支上放置布林條件：

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

同樣地，分支會從上到下檢查，只有第一個條件為`true`的分支會執行。

## 將`when`當作運算式使用

當`when`用於取得結果時（例如指定給變數、從函式回傳等），必須涵蓋所有可能的情況。

- 使用值來比對時，除非所有可能的值都已處理（例如`Boolean`或`enum`的所有值），否則要加上`else`。
- 比對條件時，必須有`else`分支，因為編譯器無法知道你的條件是否涵蓋所有情況。

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
