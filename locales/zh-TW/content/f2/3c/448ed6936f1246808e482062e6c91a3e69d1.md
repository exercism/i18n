# 忽略

## 額外的 jq 命令列選項

你會注意到測試裡`jq`多了幾個選項。

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

這些選項是什麼呢？

- `-s`

  這是「slurp」模式。
  它不會把輸入當成一串 JSON 物件來處理，
  而是把整份輸入全部吸進一個陣列裡。

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  你或許已經看過 `-r`，用來輸出「原始」字串（不含引號）。
  這個選項剛好相反。
  每一行輸入都會被視為一個字串。

  來看兩個例子：

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

把這兩個選項放在一起時，你得到的_不會_是字串陣列，
而是整份輸入成為單一字串，包含行尾的換行符號。

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

如何處理這個情況，正是這道練習的挑戰之一。
