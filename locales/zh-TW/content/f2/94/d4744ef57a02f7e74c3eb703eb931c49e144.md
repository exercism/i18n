# 說明

在這個練習中，你將會實作[二十一點][blackjack]的某些規則，例如遊戲的進行方式與計分方式。

**注意**：在這個練習中，_`A`_代表么點，_`J`_代表傑克，_`Q`_代表皇后，而_`K`_代表國王。
鬼牌會被移除。
這裡假設使用的是一副[標準的法式 52 張撲克牌][standard_deck]，但在大多數玩法中，會將數副牌一起洗勻後再玩。

## 1. 計算一張牌的值

在二十一點中，么點究竟值 1 分還是 11 分，由每位玩家自行決定（_之後會再詳細說明_）。
人頭牌（`J`、`Q`、`K`）計為 10 分，其餘的牌則依其「點數」（_數值_）計分。

定義`value_of_card(<card>)`函式，參數為`card`。
這個函式應該回傳傳入的牌面字串所代表的_數值_。
由於么點可以有多個值（1 **或** 11），這個函式目前會先把么點牌的值固定為 1。
稍後你將會實作一個函式，在已知現有手牌的情況下判斷么點牌的值。

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. 判斷哪張牌的值較高

定義`higher_card(<card_one>, <card_two>)`函式，參數為`card_one`和`card_two`。
就計分而言，`J`、`Q`或`K`的值為 10。
這個函式應該回傳哪張牌在計分上具有較高的值。
如果兩張牌的值相同，就回傳兩張。
只要在`return`敘述中使用逗號，就能回傳兩張牌：

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

么點可以有多個值，所以在這個任務中，我們會把`A`牌的值固定為 1。

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. 計算么點的值

正如前面提到的，么點的值可能是 1 **或** 11 分。
玩家會盡可能讓分數接近 21，但不要_超過_ 21（也就是「爆牌」）。

定義`value_of_ace(<card_one>, <card_two>)`函式，參數為`card_one`和`card_two`，代表在拿到么點牌_之前_，手中已有的兩張牌。
你的函式必須判斷接下來這張么點牌的值會是 1 還是 11，並回傳該值。
記住：加上么點後的這手牌，其值要盡可能地高，但_不能_超過 21。

**提示**：如果手牌中已經有么點，那麼接下來這張么點的值就是 1。

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. 判斷是否為「天生二十一」或「二十一點」手牌

如果玩家拿到的前兩張牌是一張么點（`A`）和一張十點的牌（10、`K`、`Q`或`J`），那麼這名玩家的分數就是 21。
這就稱為**二十一點**手牌。

定義`is_blackjack(<card_one>, <card_two>)`函式，參數為`card_one`和`card_two`，代表一對牌。
判斷這兩張牌是否構成**二十一點**，如果是就回傳布林值`True`，否則回傳`False`。

**注意**：分數的_計算_可以用很多種方式完成。
但如果可以的話，我們希望你檢查手牌中（_或某個特定位置_）**_是否_**有么點與一張十點的牌，而不是把整手牌的值_加總_起來。

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. 拆分對子

如果一手牌的前兩張牌值相同（_例如兩張 6，或一張`Q`和一張`K`_），玩家可以選擇把它們當成兩手獨立的牌來處理。
這就稱為「拆分對子」。

定義`can_split_pairs(<card_one>, <card_two>)`函式，參數為`card_one`和`card_two`，代表一對牌。
判斷這手兩張牌是否可以拆分成兩手。
如果這手牌可以拆分，就回傳布林值`True`，否則回傳`False`。

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. 加倍下注

當一開始拿到的兩張牌加起來為 9、10 或 11 點時，玩家可以再下一筆與原本賭注相同的賭注。
這就稱為「加倍下注」。

定義`can_double_down(<card_one>, <card_two>)`函式，參數為`card_one`和`card_two`，代表一對牌。
判斷這手兩張牌是否可以「加倍下注」，可以就回傳布林值`True`，否則回傳`False`。

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
