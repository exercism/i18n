# 說明

給定以秒為單位的年齡，計算某個人在太陽系某顆行星上的年齡會是多少。

一個地球年等於 365.25 個地球日，也就是 31,557,600 秒。如果有人告訴你某人的年齡是 1,000,000,000 秒，換算後會是 31.69 地球年。

至於其他行星，你必須考量它們以地球年為單位的公轉週期：

| 行星    | 以地球年為單位的公轉週期 |
| ------- | ----------------------------- |
| Mercury | 0.2408467                     |
| Venus   | 0.61519726                    |
| Earth   | 1.0                           |
| Mars    | 1.8808158                     |
| Jupiter | 11.862615                     |
| Saturn  | 29.447498                     |
| Uranus  | 84.016846                     |
| Neptune | 164.79132                     |

~~~~exercism/note
地球繞太陽完整公轉一圈的實際長度比較接近 365.256 天（1 恆星年）。
格里曆平均每年有 365.2425 天。
雖然 365.25 並不百分之百精確，但這是本練習採用的數值。
關於更多計算一年的方式，請參閱[維基百科上的「年」][year]。
