# 說明

在這個練習中，你會負責籌辦各種遙控車之間的比賽。每輛車都有自己的速度和耗電特性。

車子一開始的電池都是滿的（100%）。
每次你用遙控器駕駛車子時，車子會移動相當於自身速度的距離（單位為公尺），剩餘的電池百分比則會依耗電量下降。

如果車子的電池低於耗電百分比，就無法再駕駛這輛車。

每條賽道都有自己的距離。測試車子的方式，是檢查它能不能在電池耗盡前跑完整條賽道。

## 1. 建立一輛遙控車

定義一個`Car`結構體，其中包含下列`int`型別的欄位：

- battery
- batteryDrain
- speed
- distance

定義一個函式`NewCar`，讓你能建立遙控車。這個函式接受兩個參數：車子的速度（單位為公尺）和耗電百分比，兩者的型別都是`int`，並回傳一個`Car`實例：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. 建立一條賽道

定義另一個名為`Track`的結構體型別，其中的`distance`欄位型別為整數。
定義一個函式`NewTrack`，讓你能建立賽道。這個函式只有一個參數，就是賽道的距離（單位為公尺），型別為`int`：

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. 駕駛車子

實作`Drive`函式，它會根據車子的速度更新已行駛的公尺數，並依耗電量減少電池電量。
如果電池不足以再行駛一次，車子就不會移動：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. 檢查遙控車能否完成比賽

要完成一場比賽，車子必須能行駛完整條賽道的距離，也就是在越過終點線之前，電池不能先耗盡。
實作`CanFinish`函式，它會接受一個`Car`實例和一個`Track`實例作為參數，並在車子能完成比賽時回傳`true`，否則回傳`false`。

假設你現在位於比賽的起跑線，正要發動車子的引擎來參加比賽。
請注意，開始比賽時，車子的電池不一定處於滿電狀態：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
