# 說明

你是個熱衷賞鳥的人，會記錄有多少鳥兒造訪過你的花園。
平常你會用筆記本畫記來計算鳥的數量，但為了更妥善地處理資料，你已經把過去幾週的鳥數數位化了。

## 1. 判斷你目前為止總共數了幾隻鳥

我們先從高階的角度來分析資料吧。
看看你從開始記錄以來總共數了幾隻鳥。

實作一個函式 `totalBirdCount`，它接受一個裝有每日鳥數的 `Int`陣列。
它應該回傳你總共數到的鳥數。

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. 計算某一週造訪的鳥數

現在你對自己的鳥數數字有了整體的感覺，想來做更細緻的分析。

實作一個函式 `birdsInWeek`，它接受每日鳥數的陣列以及週次。

它會回傳你在那一週總共數到的鳥數。
你可以假設每一週都是完整記錄的。

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. 修正計數錯誤

你發現，在你一直努力記錄鳥兒的這段時間裡，有一隻鳥始終躲在花園遠處的角落。

你弄清楚這隻鳥每隔一天就會待在你的花園裡。

你不確定牠在那兩天之間到底在哪裡，但肯定不在你的花園裡。

你的賞鳥直覺也告訴你，這隻鳥在你清單中記錄的第一天就在你的花園裡。

根據這個新資訊，寫一個函式 `fixBirdCountLog`，它接受每日鳥數的陣列作為引數，並在修正計數錯誤後回傳該陣列。

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
