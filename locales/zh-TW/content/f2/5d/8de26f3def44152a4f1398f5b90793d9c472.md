# 簡介

代數資料型態（ADT）代表固定數量的具名情況。
ADT 的每個值都恰好對應到其中一個具名情況。

ADT 使用`data`關鍵字定義，各個情況之間以直立線（`|`）字元分隔。
如果所有情況都沒有附帶資料，這種 ADT 就類似其他語言通常所稱的列舉（或 enum）。

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

ADT 的每個情況都可以選擇性地附帶資料，而且不同的情況可以有不同的資料型態。
當情況附帶資料時，就必須有建構子。

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

要為某個特定情況建立值，只要引用它的名稱即可（例如`NInt 22`）。
由於情況名稱本身只是建構子函式，附帶的資料可以像一般函式引數一樣傳入。

ADT 具有結構相等性，意思是同一個情況且附帶的（選用）資料也相同的兩個值，彼此是相等的。

雖然可以用`if/else`運算式來處理 ADT，但建議的做法是使用`case`敘述進行模式匹配：

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
