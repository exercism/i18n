# 簡介

當迴圈的疊代次數無法事先得知，也就是「一直執行到某個述詞不再為真」時，Factor 會使用來自 [`kernel`][kernel] 的`while`組合子：

```
while ( pred body -- )
```

`pred`和`body`都是操作資料堆疊的 quotation。`while`會呼叫`pred`；如果堆疊最上方留下為真的值，`while`就會執行`body`並重複；否則就停止。從一次疊代流向下一次疊代的狀態，會保存在兩次呼叫之間的堆疊上（當狀態不只一個時，就存在具名的區域變數裡）。

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until`則是對稱的形式：它會持續執行，*直到*述詞變成真為止。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
