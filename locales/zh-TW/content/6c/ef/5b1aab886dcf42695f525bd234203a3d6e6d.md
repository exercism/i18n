# 簡介

許多程式語言都有特定的數字型別來表示不同種類的數字，但 JavaScript 只有兩種：

- `number`：一種採用雙精度 64 位元浮點格式（IEEE 754）的數字資料型態。例如`-6`、`-2.4`、`0`、`0.1`、`1`、`3.14`、`16.984025`、`25`、`976`、`1024.0`和`500000`。
- `bigint`：一種能以任意精度格式表示_整數_的數字資料型態。例如`-12n`、`0n`、`4n`和`9007199254740991n`。

如果你需要[任意精度][ref-arbitrary-precision]，或要處理極大的數字，請使用`bigint`型別。否則，`number`型別通常是比較好的選擇。

## 捨入

有一個內建的全域物件叫做`Math`，它提供各種[捨入函式][ref-math-object-rounding]。例如，你可以把小數向下捨入到最接近的整數（`floor`），或向上捨入（`ceil`）。

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
