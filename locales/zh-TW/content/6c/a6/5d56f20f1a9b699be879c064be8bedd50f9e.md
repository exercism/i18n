# 說明

在你的 DNA 研究實驗室裡，你一直在嘗試各種壓縮研究資料的方法，好節省儲存空間。一位隊友建議把 DNA 資料轉成二進位表示法：

| 核酸 | 編碼   |
| ------------ | ------ |
| 空格 | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

你思索著這件事：這有可能讓所需的資料儲存成本減半，但代價是犧牲了人類可讀性。於是你決定寫一個模組來編碼與解碼資料，好評估自己究竟省下了多少。

## 1. 將核酸編碼成二進位值

實作 `encode_nucleotide/1`，讓它接受核酸的碼點，並回傳編碼後代碼的整數值。

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. 將二進位值解碼回核酸

實作 `decode_nucleotide/1`，讓它接受編碼後代碼的整數值，並回傳核酸的碼點。

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. 編碼 DNA 字元列表

實作 `encode/1`，讓它接受代表核酸與空隙的字元列表，並回傳編碼後資料的位元字串。

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. 解碼 DNA 位元字串

實作 `decode/1`，讓它接受代表核酸與空隙的位元字串，並以字元列表回傳解碼後的資料。

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
