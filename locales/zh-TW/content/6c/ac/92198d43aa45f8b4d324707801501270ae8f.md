# 說明

在這個練習中，你將撰寫程式碼，為工廠員工列印名牌。

## 1. 列印員工的名牌

員工有 ID、姓名和部門名稱。員工名牌標籤的格式如下：`"[id] - name - DEPARTMENT"`。請實作（_static_）`Badge.Print()` 方法，回傳員工的名牌標籤：

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

請注意，部門名稱在標籤上要轉為大寫。

## 2. 列印新員工的名牌

由於電腦系統的小毛病，新員工開始在工廠工作時，偶爾還沒有 ID。因為名牌是必需的，他們會拿到一張沒有 ID 前綴的臨時名牌。請修改（_static_）`Badge.Print()` 方法，讓它支援還沒有 ID 的新員工：

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. 列印老闆的名牌

即使是工廠老闆，也必須隨時佩戴名牌。不過，老闆沒有部門。在這種情況下，標籤應該列印 `"OWNER"`，而不是部門名稱。請修改（_static_）`Badge.Print()` 方法，為老闆列印標籤：

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

請注意，老闆也可能同時是新員工：

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
