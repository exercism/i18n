# 範圍

[範圍][range]代表兩個值之間的區間。
最常支援範圍的型別是`Integer`和`String`。
它們可以用在許多地方，例如快速建立集合、切分字串、檢查某個值是否在範圍內，以及疊代。
建立範圍時使用範圍運算子`..`或`...`（分別代表包含與不包含結尾值）。

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

之所以有兩個範圍運算子，是為了讓你能建立包含或不包含結尾值的範圍。這在處理從零開始的索引時會很有用。

範圍也可以用`Range`建構子`new`來建立。

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Ruby 中用範圍運算子`..`或`...`建立範圍，並想對這個範圍呼叫方法時，需要把範圍用括號包起來。
否則，方法會被呼叫在範圍運算子的第二個引數上。

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## 取得子字串

想切分字串時，可以用範圍運算子取得子字串。
也就是建立一個包含子字串開始與結束索引的範圍。

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

你也可以使用負索引，從字串尾端取得子字串。

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 範圍方法

範圍有一些方法可以用來操作它們。
例如，這些方法可以用來取得範圍中所有值的總和，或檢查範圍是否包含某個值。

| Method                  | Description                                                             | Example                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | 回傳範圍中所有值的總和                          | `(1..5).sum # => 15`            |
| [`size`][size]          | 回傳範圍的大小                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | 如果範圍包含給定的值就回傳`true`，否則回傳`false` | `(1..5).include?(3) # => true` |

## 無限範圍與無起始範圍

範圍可以是無限的，也可以是沒有起始值的。
無限範圍或無起始範圍的起始值或結束值會是`nil`，但定義範圍時可以省略`nil`。

使用無起始與無限範圍很實用，例如你想從字串開頭或結尾切分字串時。

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
如果沒有搭配集合使用，無限範圍可能會造成無盡的序列，使用時請小心。
~~~~

## 字串範圍

字串也可以用在範圍中，讓你取得兩個字串之間的字串區間。
使用某些字串時，它的行為可能會有點出乎意料，所以請小心使用。

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
