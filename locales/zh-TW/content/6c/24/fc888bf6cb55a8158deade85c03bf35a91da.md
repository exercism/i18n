# 簡介

## 結構體與類別

結構體與類別是 Swift 程式設計的兩大基本積木。兩者都能把相關的資料與函式組成自成一體的功能單位。而當你定義一個結構體或類別時，你就是在定義一個新的型別，供 Swift 使用，就像你已經用過的`Int`和`String`這類型別一樣。

Swift 中的結構體與類別有許多相似之處。除了其他相似點之外，兩者都能把值存在_屬性_裡，並透過_方法_提供功能。

它們各自還提供一些額外的功能，但那超出了本練習的範圍。

### 定義結構體與類別

結構體與類別的定義方式大致相同。它們都以對應的關鍵字開頭，接著是正在定義的型別名稱，然後是結構體或類別的主體，放在大括號之間。

主體可以包含儲存屬性，這些屬性的定義與行為就跟一般的常數或變數沒兩樣。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### 實例

如上所述，定義一個結構體或類別只是在定義一個新的_型別_。它只是該型別的值會長什麼樣子的藍圖，並不會真的替你建立任何該型別的值供你使用。

要建立該型別的_實例_，你需要寫出型別名稱，後面接著一對括號。

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

這會建立這些型別的值，其中各屬性會填入定義中提供的預設值。請注意，在像 GameCharacter 的`name`屬性這樣的選用情況下，除非提供值，否則該屬性會預設為 nil，就像定義一般選用型別時若沒有立即提供值一樣。

對於結構體，Swift 會自動提供所謂的_逐成員初始化器_，讓你可以在括號內提供結構體屬性的值，這些值會覆寫定義中的預設值。

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### 存取屬性

結構體與類別的屬性可以用_點標記法_存取，也就是在值的名稱後面加上一個點（`.`）以及屬性名稱。如果結構體或類別的某個屬性本身也有屬性，也可以用這個點標記法存取這些巢狀屬性。

這種標記法既可以用來取得屬性的值，也可以在允許的情況下用來修改它。

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### 方法

屬性會在結構體與類別中儲存資料，同樣地，你也可以定義_方法_，在結構體或類別中存放函式。

方法的定義方式和一般函式相同，只是寫在結構體或類別的主體內。請注意，如果某個函式會改變結構體中某個屬性的值，它的前面必須加上`mutating`關鍵字。此外，如果某個屬性可能被方法改變，該屬性就必須用`var`而非`let`來定義，就像一般的變數一樣。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

這些方法可以用點標記法呼叫，就跟屬性一樣。

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

結構體或類別的每個實例都有一個隱含的屬性，名為`self`，它指向實例本身。
`self`最常見的用途，是區分同名的實例屬性與參數：

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift 型別也提供一個首字母大寫的`Self`關鍵字，它指的是實例的*型別*，而不是實例本身。
