# 說明

你的任務是把英文翻譯成豬拉丁。這套翻譯由四條規則定義，這些規則會檢視一個字開頭的母音與子音模式。這些規則會看每個字使用母音和子音的方式：

- 母音：字母 `a`、`e`、`i`、`o` 和 `u`
- 子音：英文字母中其餘的 21 個字母

## 規則 1

如果一個字開頭是母音，或以 `"xr"` 或 `"yt"` 開頭，就在字尾加上 `"ay"` 的音。

例如：

- `"apple"` -> `"appleay"`（開頭是母音）
- `"xray"` -> `"xrayay"`（開頭是 `"xr"`）
- `"yttria"` -> `"yttriaay"`（開頭是 `"yt"`）

## 規則 2

如果一個字開頭是一個或多個子音，就先把那些子音移到字尾，然後在字尾加上 `"ay"` 的音。

例如：

- `"pig"` -> `"igp"` -> `"igpay"`（開頭是單一子音）
- `"chair"` -> `"airch"` -> `"airchay"`（開頭是多個子音）
- `"thrush"` -> `"ushthr"` -> `"ushthray"`（開頭是多個子音）

## 規則 3

如果一個字開頭是零個或多個子音，後面接著 `"qu"`，就先把那些子音（如果有的話）和 `"qu"` 的部分移到字尾，然後在字尾加上 `"ay"` 的音。

例如：

- `"quick"` -> `"ickqu"` -> `"ay"`（開頭是 `"qu"`，前面沒有子音）
- `"square"` -> `"aresqu"` -> `"aresquay"`（開頭是一個子音後面接著 `"qu`"）

## 規則 4

如果一個字開頭是一個或多個子音，後面接著 `"y"`，就先把 `"y"`前面的子音移到字尾，然後在字尾加上 `"ay"` 的音。

一些例子：

- `"my"` -> `"ym"` -> `"ymay"`（開頭是單一子音後面接著 `"y"`）
- `"rhythm"` -> `"ythmrh"` -> `"ythmrhay"`（開頭是多個子音後面接著 `"y"`）
