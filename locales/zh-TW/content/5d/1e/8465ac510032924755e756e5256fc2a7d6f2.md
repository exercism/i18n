# 簡介

PHP 中的協變與逆變這兩個概念很重要，因為 PHP 在繼承類別或介面時，會強制執行這些規則。

協變會保留兩個型別之間的關係，而逆變則會反轉這個關係。簡單來說，這表示在繼承類別、覆寫函式時，你可以讓方法的參數使用更寬鬆或更具體的型別，也可以讓方法回傳更寬鬆或更具體的型別。

## 範例

看看下面這個類別：

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

如果我們繼承這個類別，就可以允許比原本宣告更多的參數型別，但不能回傳原本回傳型別以外的東西。

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

下面這個繼承而來的類別不合法，因為不允許回傳額外或更寬鬆的型別：

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
