# 簡介

Ruby 是一種動態的[物件導向語言][object-oriented-programming]。
Ruby 裡的一切都是[物件][object]。

在 Ruby 中，把物件指定給名稱的方式主要有兩種：使用變數或常數。
變數一律以 snake case 撰寫。
一個變數在其生命週期內可以指向不同的物件。
舉例來說，`my_first_variable`可以用`=`運算子定義與重新定義許多次：

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

不過，常數的設計是只能被指定一次。
常數必須以英文大寫字母開頭，而且通常全部以大寫字母書寫，單字之間用底線分隔。

例如：

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby 以類別來組織。
類別使用`class`關鍵字定義，後面接著類別的名稱。
物件通常是使用`.new`方法將類別實例化而建立。

例如：

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

功能的單位被封裝在方法裡，這點類似於其他語言的_函式_。
方法可以選擇性地定義位置引數，以及／或是使用`:`語法定義與呼叫的關鍵字引數。
方法會隱式回傳最後一個被求值敘述的結果，也可以透過`return`關鍵字顯式地回傳物件。
方法使用`.`語法來呼叫。

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
