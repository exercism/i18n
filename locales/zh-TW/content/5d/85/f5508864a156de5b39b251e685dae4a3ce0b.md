# 簡介

只要替方法的參數指定預設值，就能讓它成為選擇性參數。呼叫帶有選擇性參數的方法時，呼叫方不需要為這些參數傳入值。如果沒有傳入值，就會使用該選擇性參數的預設值。

選擇性參數_必須_位於參數列表的最後；它們後面不能接非選擇性參數。

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
