# 簡介

## 時間

`Time`模組用來顯示人類可讀的日期與時間。
雖然技術上確實可以用`Time`來操作時間，但 Elm 社群有一些更適合這項任務的套件，例如 [`justinmimbs/date`][date]或[`CoderDennis/elm-time-format`][elm-time-format]。

### Posix

時間由不透明型別`Posix`表示，它包裝了 Unix 紀元時間，也就是自 1970 年 1 月 1 日午夜 UTC 起經過的毫秒數。
`Posix`是不會因時區而異、不具歧義的值，因此很適合用來記錄時間。
在 Elm 應用程式中，`Posix`時間通常由外部來源提供，例如瀏覽器。

可以透過下列函式把`Posix`轉換成毫秒數，反之亦然：

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### 時區

在日常生活中，我們人類通常不會直接讀取`Posix`，而是偏好本地時間，這取決於我們在地球上的位置，以及當地的日光節約時間規則。
在 Elm 中，這些資訊會編碼在不透明型別`Zone`中，通常由瀏覽器提供。

有一個永遠都能存取的特殊`Zone`：

```elm
utc : Zone
```

### 人類可讀的時間

有了`Posix`和`Zone`，我們就有足夠的資訊，用任何詳細程度來顯示本地時間。
以下是可以達成這件事的函式清單：

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

你應該已經注意到另外兩個`Time`自訂型別：

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

把這些自訂型別轉換成人類可讀的值，就交給使用者自行處理。
