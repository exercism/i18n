# 簡介

有時候，當一個函式接受許多引數時，很難記住它們應該以什麼順序傳入。為了提升可讀性，Gleam 允許你為引數標上名稱標籤。

要為引數標上標籤，請把標籤名稱寫在引數名稱前面，並用一個空格隔開。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

呼叫帶有標籤引數的函式時，引數可以用任何順序傳入。下面這幾個`replace`的呼叫都是等效的：

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

標籤一律是選用的。即使函式帶有標籤引數，仍然可以不加標籤就呼叫它。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
