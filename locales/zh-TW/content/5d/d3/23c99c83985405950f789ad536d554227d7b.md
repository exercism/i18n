# 介紹

在 SQL 中，`SELECT` 敘述可以讓你從資料庫擷取資料。
`SELECT` 敘述的結果是一個結果集。
結果集包含以列和欄位排列的值。
每個欄位都是資料的某個特定屬性。
每一列都包含每個欄位的一個值。

你可以這樣想：一組欄位代表一個資料結構，每個欄位代表該資料結構中的一個欄位，而每一列則代表該資料結構的一個實例。

使用 `SELECT` 敘述，你可以指定想擷取的資料。
你也可以選擇轉換、篩選，或修改輸出資料的形狀。

## 基礎

基本的 `SELECT` 敘述結構如下：

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM` 和 `WHERE` 子句可以省略。
例如，像 `SELECT "Hello, world.";` 這樣的敘述完全有效。

另外請注意，換行並非必要；只要有任何空白，就能分隔 `SELECT` 敘述中的各個子句（也就是各個部分）。
~~~~

緊接在 `SELECT` 關鍵字後面的是你希望在結果中出現的欄位清單。
`FROM` 子句指出資料來源，通常是資料庫中的資料表。
`WHERE` 子句會依照一或多個條件篩選輸出資料。

## 使用 WHERE 子句篩選資料

`WHERE` 子句讓你篩選 `SELECT` 敘述所擷取的資料。
例如，如果我們只想要 Appliances 這個分類的資料，可以這樣寫：

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

結果：
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

或者，我們只想要 weight 介於 2.0 和 6.0 之間的資料：

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

結果：
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
