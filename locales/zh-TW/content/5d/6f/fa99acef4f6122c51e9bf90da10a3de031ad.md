# 執行測試

## 下載練習

使用 [Exercism CLI][cli] 下載你想做的練習吧。

```sh
exercism download --track=dart --exercise=hello-world
```

接著切換到練習所在的目錄。

```sh
cd /path/to/exercism/dart/hello-world
```

## 安裝相依套件

執行測試之前，先下載練習的相依套件。

```sh
dart pub get
```

## 執行測試

```sh
dart test
```

## 看懂測試結果

## 逐一完成測試

大多數練習都包含多個測試，預設情況下除了第一個之外，其餘都會被略過。

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

如果想一次完成一個測試，就隨著進度把每個測試的 `skip: true`改成 `skip: false`。
或者，你也可以不修改檔案，直接一次執行所有測試。

```sh
dart test --run-skipped
```

提交時，線上測試執行器會執行所有測試，包括被略過的測試。

## 處理錯誤「Could not find a command named frontend_server.dart.snapshot」

假設你有一個已經解完並提交的練習，隔了一段時間後又回來看它。
當你測試它時，可能會遇到這個錯誤：

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

[解決方法][solution]是刪除 `pubspec.lock` 檔案，然後再次執行 dart 指令。
