# 關於

## 選擇性

Swift 使用[_選擇性_][optionals]，讓程式設計師能夠表示某個值可能不存在。
選擇性是一種型別，它要嘛存放一個值，要嘛是[`nil`][nil]，而`nil`代表值不存在。
使用選擇性時，程式必須先檢查值是否存在，再將它展開後才能使用。

只要在型別名稱末端加上`?`，任何型別都能變成選擇性。
因此，選擇性整數的型別會是`Int?`，選擇性字串的型別則會是`String?`。
定義選擇性型別的常數或變數，以及指定值給它們的方式，都和非選擇性型別的值相同。

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

你可以把特殊值`nil`指定給選擇性型別的變數，藉此表示值不存在。
`nil`可以搭配所有選擇性型別使用，但指定給兩個不同選擇性型別的`nil`並不屬於相同型別，兩者不能互換，甚至不能比較。

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

另外要注意，雖然`nil`可以指定給任何選擇性型別，卻不能指定給非選擇性型別（即使該型別實際上並不存放`nil`）。
而預期接收非選擇性型別的方法，若沒有先展開，也無法接受傳入的選擇性型別。

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## 使用選擇性

因為選擇性型別和它的基底型別並不相同，兩者的使用方式也不同。
例如：`Int("123") + 1`會產生編譯器錯誤「Value of optional type 'Int?' must be unwrapped to a value of type 'Int'」。
這是因為`Int("123")`回傳的是選擇性型別`Int?`，而不是`Int`型別；如果字串無法轉換成整數，結果就會是`nil`。
若要取出轉換結果中的`Int`，必須先將它「展開」。

在 Swift 中，最常見的做法是使用`if-let`和`guard-let`這兩個結構來進行[_選擇性綁定_][optional-binding]：它會檢查值是否為`nil`。如果值存在，就走其中一條程式路徑，並把展開後的值綁定到提供的名稱；如果發現是`nil`，就走另一條程式路徑。

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

值得注意的是，變數`safeNum`的型別是`Int`，而不是`Int?`。
在下面的例子中，`num`的型別是`Int?`，而`safeNum`的型別是`Int`。

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

這個_選擇性綁定_很重要，因為它會把值外面的選擇性型別展開（或「移除」），讓這個值可以當成非選擇性值來使用。
如果你只是用條件檢查判斷值是否為`nil`，這個值仍然是選擇性型別：

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

如果希望提早回傳，也可以使用`guard-let`：

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## 比較選擇性

請注意，即使兩個選擇性的基底型別可以用標準比較運算子比較，選擇性本身仍然無法比較。
它們只能檢查是否相等。
如果兩個選擇性都是`nil`，或是它們包裝的值在各自的基底型別下相等，這兩個選擇性就相等。

不過，你可以撰寫程式碼，對兩個選擇性值進行自訂比較。
下面的例子是一個`switch`敘述，只有在兩個選擇性值都不是 nil，且第一個值小於第二個值時，才會回傳`true`。
為了做到這點，它使用了_選擇性模式_`varName?`，這個模式只會比對非 nil 的選擇性，並把選擇性裡面的值綁定到名稱`varName`。

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```

## Nil 合併

還有一種展開的選擇：當遇到`nil`時，可以使用[備用值][fallback]。
做法是使用_nil 合併運算子_`??`。假設`x`是`Int?`，如果你寫下`let y = x ?? 0`，Swift 會檢查 x 是否為`nil`。
如果 x 不是`nil`，它會展開`x`，並把展開後的值指定給`y`；如果`x`_是_`nil`，則會把 0 指定給`y`。

由於`x ?? y`只是`x != nil ? x! : y`的簡寫，因此如果 x 不是 nil，運算式`y`根本就不會被求值。

最後要注意的是，nil 合併運算子具有右結合性，這可能會讓不熟悉的人得到意想不到的結果。

```swift
let k = 42 ?? 0 + 1    // returns 42
let j = nil ?? 0 + 1   // returns 1
```

你可以進一步閱讀 [Swift 導覽：Nil 合併運算子][nil-coalescing]，了解 nil 合併運算子。
