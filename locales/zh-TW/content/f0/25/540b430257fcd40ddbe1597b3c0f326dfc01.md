# 關於

Elm 中的[`List`][lists]是不可變的集合，可以包含零個或多個同型別的值。
由於陣列不可變，一旦建立之後，它的值就永遠不會改變。
Elm 的陣列有_頭部_（第一個元素）和_尾部_（第一個元素之後的所有內容）。
陣列的尾部本身也是一個陣列。

陣列的型別註解可以這樣定義：

```elm
List String --> a list of String
List Int --> a list of Int
```

陣列可以這樣定義：

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

要將元素加入陣列，最常見的方式是透過`::`（cons）運算子：

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

陣列可以用`++`運算子或`List.append`附加：

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

陣列是透過[`List`模組][list-module]中定義的函式和運算子來操作的。

```elm
List.length [ 7, 8 ] --> 2
```

任何看似會修改陣列的函式或運算子（例如加入元素），實際上都會回傳一個新的陣列。
不過效能通常不是問題，因為陣列的實作方式避免了不必要的配置與複製。

陣列也可以用[模式比對][list-destructuring]來處理。

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
