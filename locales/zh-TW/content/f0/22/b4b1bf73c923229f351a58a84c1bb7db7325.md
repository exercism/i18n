# 執行測試

在終端機中，先切換到練習的基礎目錄，然後用以下指令執行測試：

```bash
$ mix test
```

這會執行`test`子資料夾裡的測試檔案，也就是以`_test.exs`結尾的檔案。

說明文件：

* [`mix test`：Elixir 的測試執行工具](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit`：Elixir 的單元測試函式庫](https://hexdocs.pm/ex_unit/ExUnit.html)

## 待處理的測試

在練習的測試套件中，除了第一個測試之外，其餘測試都被標記為略過。

當你讓一個測試通過後，只要用`#`符號把對應的`@tag :pending`註解掉，就能取消略過下一個測試。

例如：

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

如果你想一次執行所有測試，可以在`mix test`指令加上`--include`旗標，把所有被略過的測試一併納入：

```bash
$ mix test --include pending
```

或者，你也可以把`test/test_helper.exs`檔案裡的`ExUnit.configure`那一行註解掉，來啟用所有測試。

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## 實用的`mix test`選項

* `test/<FILE>.exs:LINENUM`：只執行單一測試，也就是`<FILE>.exs`裡定義位於第`LINENUM`行的那個測試
* `--failed`：只執行上次執行時失敗的測試
* `--max-failures`：當測試失敗數達到這個數量時，測試套件就會停止評估測試
* `--seed 0`：關閉隨機排序，讓同一個檔案裡的測試一律按照定義時的順序執行
