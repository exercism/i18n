## 數字與數值運算子

所有**數字**，不論是否為整數，都是 IEEE754 雙精度浮點數。
`jq`的實作使用 C 的 `double` 型別。
這讓我們最多只有 53 位元的精確度。

數字可以使用常見的運算子：

- 算術：`+`、`-`、`*`、`/`、`%`
- 比較：`==`、`!=`、`<`、`<=`、`>=`、`>`
- 標準[數學函式][man-math]

  對於單一輸入的函式，用管線把值送入函式

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  對於雙輸入的函式，這些函式會忽略輸入，並預期以參數的形式接收輸入

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  函式引數的分隔符號是分號，不是逗號。

~~~~exercism/caution
「這讓我們最多只有 53 位元的精確度」這句話是什麼意思？

來看一個示範：

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

看起來沒問題。那如果把指數再調大呢？

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

這兩個數字不應該相等。
這就是「精確度流失」的樣貌。
這表示`jq`無法處理任意大的數字。
~~~~

## 條件運算式

`jq`使用 [`if-then-else` 運算式][if-then-else]來處理**條件運算式**。
它是一個_運算式_，所以放在管線中。

語法為：`if CONDTITION then TRUE_EXPR else FALSE_EXPR end`。

`else`子句是選用的。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

要加入更多條件時使用`elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
