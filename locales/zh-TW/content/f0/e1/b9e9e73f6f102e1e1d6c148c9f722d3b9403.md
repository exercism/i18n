# 說明

在準備烤餅乾給朋友吃的時候，你發現自己得轉換食譜裡用到的某些計量單位。你只熟悉公制，所以得想個辦法，把常見的美式烘焙計量換算成毫升（mL），讓自己輕鬆一點。

請在解法中使用這張換算表：

| 要換算的單位 | 容積 | 毫升（mL） |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| 美制杯          | 1      | 240                 |
| 美制液量盎司    | 1      | 30                  |
| 美制茶匙        | 1      | 5                   |
| 美制湯匙        | 1      | 15                  |

身為一位才華洋溢、正在學習的程式設計師，你決定用毫升當作過渡單位，方便把表上任何一個單位換算成其他任何單位（甚至換算成自己）。

## 1. 取得容積配對中的數值部分

實作 `getVolume` 函式。給定一個容積配對元組，它應該只回傳數值部分。

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. 把容積配對換算成毫升

實作 `toMilliliter` 函式。給定一個容積配對元組，它應該使用換算表把容積換算成毫升。

使用多個函式子句與模式配對，為每個單位建立對應的函式。用來表示各單位的 atom 有：`Cup`、`FluidOunce`、`Teaspoon`、`Tablespoon`、`Milliliter`。
把換算結果用元組包住後回傳。

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. 把毫升容積配對換算成其他單位

實作 `fromMilliliter` 函式。給定一個容積配對元組與目標單位，它應該使用換算表把容積換算成目標單位。

使用多個函式子句與模式配對，為每個單位建立對應的函式。用來表示各單位的 atom 有：`Cup`、`FluidOunce`、`Teaspoon`、`Tablespoon`、`Milliliter`。

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. 從任何單位換算成任何單位

實作 `convert` 函式。給定一個容積配對元組與目標單位，它應該把給定的容積換算成目標單位。

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
