# 提示

## 一般

- 大多數雙運算元或三運算元的指令，都要求所有運算元的大小必須相同。

## 1. 追蹤不同的貨幣

- 大多數雙運算元或三運算元的指令，都要求所有運算元的大小必須相同。
- 你可以將相關的字串保存在 .rodata 區段或 .data 區段，再依照列舉值將它們分派出去。
- 列舉會隱式轉換成整數，通常是 32 位元大小。

## 2. 檢查匯率

- 大多數雙運算元或三運算元的指令，都要求所有運算元的大小必須相同。
- 每個列舉元素的值，就是 `value_in_US_dollars` 所參照的 C 陣列中的索引。
- 在 C 中，索引從位移 0 開始，而且是對應元素本身，與元素佔多少位元組無關，所以舉例來說，索引`2`永遠指向第三個元素。
- 每個`double`佔用 8 位元組的空間。
- 匯率可以用外幣的美元價值除以本國貨幣的美元價值來計算。

## 3. 計算紙鈔的價值

- 大多數雙運算元或三運算元的指令，都要求所有運算元的大小必須相同。
- 紙鈔的價值可以將`denomination`和`number_of_bills`相乘得出。
- `unsigned long long`是無號的 64 位元整數。
- `unsigned short`是無號的 16 位元整數。
- `uint64_t`是無號的 64 位元整數。

## 4. 計算紙鈔的數量

- 大多數雙運算元或三運算元的指令，都要求所有運算元的大小必須相同。
- 你需要先將`amount`向下取整，再把它轉換成整數。
- `float`是 32 位元的浮點數。
- 你可以使用 [roundss][round]，並以`1`作為第三個運算元，將 32 位元的浮點值向下取整。
- `unsigned int`是無號的 32 位元整數。

## 5. 計算兌換後的價值

- 大多數雙運算元或三運算元的指令，都要求所有運算元的大小必須相同。
- 你需要先將`spread`轉換成浮點值，再除以`100`以取得百分比。
- 取得百分比後，你應該將它乘以`exchange_rate`，以得到價差_費用_。
- _實際匯率_是匯率加上價差費用的總和。
- 你應該將預算除以實際匯率，以算出可兌換的最大金額。
- 你可以重複使用先前實作的`get_number_of_bills`函式，來取得你將會用到的紙鈔數量。
- `uint32_t`是無號的 32 位元整數。

[round]: https://www.felixcloutier.com/x86/roundss
