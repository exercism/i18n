# 回傳

在 Crystal 中，方法裡的最後一個運算式會回傳它的值。
不過，有時候你需要在最後一個運算式之前回傳值。
這時你可以使用`return`關鍵字，它會回傳後面運算式的值。
寫在`return`關鍵字之後的程式碼不會被執行。

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
當方法的最後一個運算式就是要回傳的值時，應該省略`return`關鍵字。
~~~~
