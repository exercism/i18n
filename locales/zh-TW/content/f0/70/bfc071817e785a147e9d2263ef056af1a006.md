# 分析器

Exercism 的分析器會自動評估學生的提交內容，並提供導師般的評論。

## 參與分析器開發

每個語言都有專屬的分析器，並以該語言撰寫。
網站則扮演分析器與學生提交內容之間的協調者。

每個分析器都放在 Exercism GitHub 組織裡，儲存庫名稱是`<track_slug>-analyzer`（例如 [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer)）。
你可以在這裡查看現有的分析器。

如果你想協助現有的分析器，請在它的儲存庫開一個 issue，詢問是否有你能幫上忙的地方。
如果你想為目前還沒有分析器的語言建立一個分析器，請依照[從零開始建立分析器](/docs/building/tooling/analyzers/creating-from-scratch)的說明進行。
