# 除錯

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] 是一個會回傳值的運算式。
Pyret 在給定的程式區塊裡只允許一個運算式，除非外層區塊標記了`block`。
在第二個例子中，在函式宣告加上`block`，就能在回傳之前先印出 42。

## `spy` 陳述式

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

`spy` 陳述式可以帶一個選用的標籤、一個或多個變數，並回報每個變數及其值。
因為它不是運算式，所以可以在區塊裡使用`spy`陳述式，外層區塊不需要標記`block`。

[spy]: https://pyret.org/docs/latest/s_spies.html
