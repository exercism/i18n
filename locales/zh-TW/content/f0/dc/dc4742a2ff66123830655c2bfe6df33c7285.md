# 簡介

在 Factor 中，你可以用`: name ( stack-effect ) body ;`定義一個新的詞。主體是一連串的詞；呼叫你的新詞時，會依序執行它們。

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

當一個常式愈來愈大時，你可以，也應該，*拆解*它：把一群詞抽成更小的具名詞，每個詞只負責一件事。這個語言就是以此命名的。

## 詞彙

每個`.factor`檔案都用`IN:`宣告一個詞彙。一個詞彙裡的詞可以呼叫另一個詞彙裡的詞，只要在`USING:`中列出那個詞彙即可。

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

目錄結構會跟著以點分隔的詞彙名稱走：詞彙`my-vocab`位於`my-vocab/my-vocab.factor`；詞彙`my-vocab.helpers`位於`my-vocab/helpers/helpers.factor`。Factor 的載入器會依`USING:`宣告遞移載入，視需要載入每個詞彙。
