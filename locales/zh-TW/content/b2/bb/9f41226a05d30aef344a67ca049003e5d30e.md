# 幫助

如果你遇到困難需要協助，可以使用下列資源：

- [/r/javascript](https://www.reddit.com/r/javascript) 是 JavaScript 的 subreddit。
- [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) 可以用來搜尋你的問題，看看是否已經有人問過。你也可以在上面提問和回答問題。
- [Github issue tracker](https://github.com/exercism/javascript/issues) 是我們追蹤 Exercism 上 JavaScript 練習開發與維護狀況的地方。如果上面的連結都幫不上忙，歡迎在這裡提出 issue。
