# 測試

這些練習都使用 [Pester][pester] 框架來進行模擬與測試。
所有測試都會放在名為`[Exercise].tests.ps1`的檔案中，這是 Pester 框架的標準做法。
如果你位於正確的目錄中（也就是包含`[Exercise].ps1`和`[Exercise].tests.ps1`的那個目錄）。
你可以在 PowerShell 中呼叫以下指令來執行測試：

``` PowerShell
Invoke-Pester
```

這會執行它在目錄中找到的所有`.tests.ps1`檔案。

如果你使用 PowerShell 以外的 shell，可以呼叫以下指令來執行測試：

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## 在 Visual Studio Code 中執行測試

你必須確認已在 Visual Studio Code 中安裝 [PowerShell 擴充功能][extension]。

在 Visual Studio Code 中，有幾種方式可以執行測試：

- 從「Debug」選單執行`.Tests.ps1`指令碼。鍵盤快速鍵為：`F5` 或 `Shift + F5`
- 在編輯器內，點擊測試程式碼中`Describe`關鍵字上方的「Run Tests」連結
- 設定 Task 來執行 Pester 框架

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
