# 指令

在工廠工作時，你需要製作印在員工識別證上的訊息。你決定用 JavaScript 來實作這個函式。

一張識別證需要員工的`id`、員工的`name`，以及他們所屬的部門。

## 1. 建立識別證文字

實作一個名為`printBadge`的函式，回傳要印在識別證上的文字。

員工的姓名一定會提供，但員工的`id`編號和部門名稱可能是`null`。員工的`id`編號若有提供，應該放在方括號中（例如`[20]`）。

老闆的識別證不應該有`id`或`department`。

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
