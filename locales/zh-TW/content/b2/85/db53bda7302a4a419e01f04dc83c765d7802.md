# 說明

在這個練習中，我們會模擬一場 [Blackjack][blackjack] 遊戲的第一回合。

## 1. 計算任何一張牌的值。

你會拿到兩張牌，並且能看見莊家攤開的那張牌。
所有牌都用字串表示，例如「ace」、「king」、「three」、「two」等。每張牌的值如下：

| 牌 | 值 | 牌 | 值 |
| :---: | :---: | :-----: | :---: |
| ace | 11 | eight | 8 |
| two | 2 | nine | 9 |
| three | 3 | ten | 10 |
| four | 4 | jack | 10 |
| five | 5 | queen | 10 |
| six | 6 | king | 10 |
| seven | 7 | _其他_ | 0 |

~~~~exercism/note
一般來說，ace 可以算作 1 或 11，但為了簡化，我們假設它只能算作 11。
~~~~

實作`Blackjack.parse_card`方法，它接收一張以字串表示的牌作為引數。
這個方法應該把牌的值以整數回傳。

```ruby
Blackjack.parse_card("ace")
# => 11
```

## 2. 為各種數值範圍命名。

玩家分數必須歸類到不同的數值範圍。
玩家分數的計算方式，是把兩張玩家牌的值相加。使用的範圍如下：

| 範圍 | 值 |
| :-------: | :------: |
| low | [4, 11] |
| mid | [12, 16] |
| high | [17, 20] |
| blackjack | [21] |

實作`Blackjack.card_range`方法，它接收兩張以字串表示的牌作為引數。
這個方法應該回傳這兩張牌所屬範圍的名稱。

```ruby
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. 實作第一回合的決策邏輯。

根據你的兩張牌和莊家的牌，遊戲的第一回合有一套策略，你有以下選擇：

- 停牌（S）
- 要牌（H）
- 分牌（P）
- 自動獲勝（W）

雖然這個策略還不是最佳解，但你要採用你朋友 Alex 一直在開發的策略，內容如下：

- 如果你拿到一對 ace，一定要分牌。
- 如果你拿到 Blackjack（兩張牌加起來的值為 21），而且莊家沒有 ace、人頭牌或 ten，你就自動獲勝。
  如果莊家確實有其中任何一張牌，你就必須停牌，等待另一張牌揭曉。
- 如果你兩張牌的值加起來落在 [17, 20] 這個範圍，就一定要停牌。
- 如果你兩張牌的值加起來落在 [12, 16] 這個範圍，就一定要停牌，除非莊家有 7 或更大的牌，這時你就一定要要牌。
- 如果你兩張牌的值加起來是 11 或更低，就一定要要牌。

實作`Blackjack.first_turn`方法，它接收三張以字串表示的牌作為引數。
這個方法應該把你該採取的決定以字串回傳。

```ruby
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
