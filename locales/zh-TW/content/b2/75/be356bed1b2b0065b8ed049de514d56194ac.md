# 說明補充

## 輸出格式

將學生的植物輸出成以 null 結尾的字串，並以逗號和空格作為分隔符號。

## 暫存器

| 暫存器   | 用途         | 型別    | 說明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 輸入         | 位址    | 花園配置圖                    |
| `$a1`    | 輸入         | 位址    | 學生的名字                    |
| `$a2`    | 輸入／輸出   | 位址    | 以 null 結尾的輸出字串        |
| `$t0-9`  | 臨時         | 任意    | 用於臨時儲存                  |
