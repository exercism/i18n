# 關於

在 Java 中，`null`字面值用來表示沒有值。

Java 中的[基本資料型態][primitive-data-types]都有預設值，因此永遠不會是`null`。
依照慣例，它們以小寫字母開頭，例如`int`。

[參考型別][reference-data-types]包含物件的記憶體位址，因此可以有`null`值。
它們通常以大寫字母開頭，例如`String`。

試著把`null`值指定給基本型別的變數，會造成編譯時期錯誤，因為這種變數永遠帶有被指定型別的預設值。

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

把`null`值指定給參考變數不會造成編譯時期錯誤，因為參考變數可以為`null`。

```java
//No error will occur as the String variable str is nullable
String str = null;
```

存取值為`null`的參考變數雖然可以順利編譯，但會在執行時期拋出`NullPointerException`。

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

當你試著存取一個值為 null、卻需要物件的參考變數時，就會[拋出`NullPointerException`][null-pointer-exception]。

為了安全地處理可為`null`的值，在操作它們之前應該先檢查它們是否為`null`，這可以透過`==`或`!=`這類[相等運算子][equality-operators]來完成：

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
