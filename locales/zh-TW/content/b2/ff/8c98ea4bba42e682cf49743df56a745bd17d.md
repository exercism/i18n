# 簡介

在課程大綱的其他部分，我們看過各種特性不同的資料型態。

- 原子向量是一維的，且型態同質。
- 串列是一維的，但元素可以是異質型態。
- 矩陣與陣列是多維的，且同質。

這個概念要來看如何儲存多維、異質的資料。
實務上，_大多數_真實世界的資料都是這樣，所以我們現在要觸及 R（大致上）在實務中如何被使用的核心。

## 資料框的種類

幾十年來，R 陸續加入了多種資料型態來處理表格式資料。

這份課程大綱主要聚焦在 tibble，但了解其他替代方案也很有用。

### `data.frame`

在 Base R 中，`data.frame` 是等長`vectors`組成的`list`。
可以把它想成一張長方形的資料表，其中每一欄都是同質的，但每一列可以（而且通常真的會）包含不同型態的資料。

以下用一個例子說明：

```R
# create the column vectors
languages <- c("Fortran", "R", "Python", "Julia")
created <- c(1957, 1993, 1991, 2012)
has.syllabus <- c(FALSE, TRUE, TRUE, TRUE)

# join columns to create the dataframe
df <- data.frame(languages, created, has.syllabus)
df
#>   languages created has.syllabus
#> 1   Fortran    1957        FALSE
#> 2         R    1993         TRUE
#> 3    Python    1991         TRUE
#> 4     Julia    2012         TRUE
 ```

這裡有一欄字串、一欄數字，還有一欄布林值。
當資料量放大時，這是用來表示許多真實世界資料集合的直覺方式。

### `tibble`

`data.frame` 的設計已經很_老_了。

累積數十年的經驗，加上 R 使用方式的轉變，促成了重新設計，在 Tidyverse 中打造出現代化的替代方案：tibble。

與 Base R 相比，tibble 有以下特點：

- 不同的預設值，以減少常見問題。
- 在輸入時較不願意強制轉換資料型態。
- 更多、更清楚的錯誤訊息。
- 不同、通常也更好的顯示格式。

簡單來說，`tibble` 的目標是「_做得更少、抱怨更多_」，也有人形容它是「_懶散又暴躁_」。

這兩種型態通常可以互換：任何接受`data.frame`的函式也會接受`tibble`，反之亦然。

兩種型態之間的轉換很簡單，用`as_tibble(df)`和`as.data.frame(tbl)`即可。

開發新東西時，使用 tibble 大概能幫你寫出更強健的程式碼。
不過，在 R 的世界裡，舊有的程式碼和資料非常大量，所以`data.frame`大概還會風行很久。

```R
# column vectors are same as for data.frame
library(tibble)
tbl <- tibble(languages, created, has.syllabus)
tbl
  # A tibble: 4 × 3
#>   languages created has.syllabus
#>   <chr>       <dbl> <lgl>       
#> 1 Fortran      1957 FALSE       
#> 2 R            1993 TRUE        
#> 3 Python       1991 TRUE        
#> 4 Julia        2012 TRUE      
```

注意預設的列印格式：帶有維度的那行註解會自動印出，欄的型態也會一併顯示。

## 操作 tibble

tibble 是 Tidyverse 的核心部分，可以用`library(tibble)`或`library(tidyverse)`載入。

### 建立 tibble

最簡單的方式是用`tibble()`函式把欄向量組合起來，就跟`data.frame()`一樣。
前面小節已經示範過例子。

如果逐列輸入值比較方便，對應的函式是`tribble()`。

實務上，建立 tibble 的方法有幾十種，因為許多 Tidyverse 函式的預設輸出格式就是 tibble。

## 操控 tibble

函式程式設計概念談過用`purrr`套件來操控向量與串列（一維資料結構）。

對於資料框（無論是傳統的還是 tibble），對應要使用的套件是`dplyr`。

### 子集選取

資料框（包括 tibble）可以視為一堆欄向量組成的串列，所以用串列索引就能取出指定的欄。

```R
tbl
# A tibble: 4 × 3
#>   languages created has.syllabus
#>   <chr>       <dbl> <lgl>       
#> 1 Fortran      1957 FALSE       
#> 2 R            1993 TRUE        
#> 3 Python       1991 TRUE        
#> 4 Julia        2012 TRUE    

tbl$created
#> [1] 1957 1993 1991 2012
```

資料框也可以用矩陣式的索引方式來取值。

```R
tbl[c(2, 4), 1:2]
  # A tibble: 2 × 2
#>   languages created
#>   <chr>       <dbl>
#> 1 R            1993
#> 2 Julia        2012
```

在搭配 Tidyverse 生態系的現代 R 中，`dplyr`的函式通常更有彈性也更方便，接下來這個概念會以它們為重點。

### 逐欄操作

用`pull()`搭配欄名或順序編號（負數表示從右邊數起）可以取得單一欄。

```R
tbl |> pull(created)
#> [1] 1957 1993 1991 2012
```

結果和`tbl$created`相同，但用的是方便串接管線的函式。

要取得多欄，適合的函式是`select()`，它的用途非常廣。
依照欄名或型態的特性來取得（或捨棄）欄。

```R
# Range with position and/or name
tbl |> select(1:created)
  # A tibble: 4 × 2
#>   languages created
#>   <chr>       <dbl>
#> 1 Fortran      1957
#> 2 R            1993
#> 3 Python       1991
#> 4 Julia        2012      

# Use type of column
tbl |> select(where(is.numeric))
  # A tibble: 4 × 1
#>   created
#>     <dbl>
#> 1    1957
#> 2    1993
#> 3    1991
#> 4    2012
```

可以同時使用多個條件，搭配布林運算子`&`、`|`和`!`（也就是且、或、非）。

拿我們那個語言玩具資料框來玩這麼強大的功能，好像有點誇張。
還好`dplyr`內建了`starwars`這個 tibble，讓我們有更大的資料可以練習喔。

```R
# pick a subset of columns
starwars |> 
  select(name | ends_with("color")) |> 
  head(5)
  # A tibble: 5 × 4
#>   name           hair_color skin_color  eye_color
#>   <chr>          <chr>      <chr>       <chr>    
#> 1 Luke Skywalker blond      fair        blue     
#> 2 C-3PO          NA         gold        yellow   
#> 3 R2-D2          NA         white, blue red      
#> 4 Darth Vader    none       white       yellow   
#> 5 Leia Organa    brown      light       brown    
```

### 逐列操作

用`filter()`取得符合某些條件的列，或用`filter_out()`排除它們。

```R
starwars |> 
  select(name:mass) |> 
  filter(between(height, 150, 165) & !is.na(mass))
  # A tibble: 4 × 3
#>   name               height  mass
#>   <chr>               <int> <dbl>
#> 1 Leia Organa           150    49
#> 2 Beru Whitesun Lars    165    75
#> 3 Nien Nunb             160    68
#> 4 Ben Quadinaros        163    65
```

篩選條件可以任意複雜，但永遠是根據列的_內容_。

如果知道列的_編號_，可以用各種`slice()`系列的函式。

```R
starwars |> 
  select(name | homeworld) |> 
  slice(20:25)
  # A tibble: 6 × 2
#>   name             homeworld
#>   <chr>            <chr>    
#> 1 Palpatine        Naboo    
#> 2 Boba Fett        Kamino   
#> 3 IG-88            NA       
#> 4 Bossk            Trandosha
#> 5 Lando Calrissian Socorro  
#> 6 Lobot            Bespin   
```

## 修改 tibble

先提醒一點：_修改時複製_的預設行為意味著原本的 tibble 通常維持不變。

大多數修改都是逐欄進行的。

欄名可以用`rename(newname = oldname)`更改，或用`rename_with()`套用函式。
注意`rename()`裡的語法。
欄`oldname`的_內容_會_綁定_到名稱`newname`，這也是參數順序的由來。

欄的順序可以用`relocate()`改變。
指定的欄預設會移到最左邊的位置，但可以用`.before`或`.after`引數做更精細的定位。

```R
sw <- starwars |> select(name:species) |> slice(1:4)
sw
  # A tibble: 4 × 11
#>   name           height  mass hair_color skin_color  eye_color birth_year sex   gender    homeworld species
#>   <chr>           <int> <dbl> <chr>      <chr>       <chr>          <dbl> <chr> <chr>     <chr>     <chr>  
#> 1 Luke Skywalker    172    77 blond      fair        blue            19   male  masculine Tatooine  Human  
#> 2 C-3PO             167    75 NA         gold        yellow         112   none  masculine Tatooine  Droid  
#> 3 R2-D2              96    32 NA         white, blue red             33   none  masculine Naboo     Droid  
#> 4 Darth Vader       202   136 none       white       yellow          41.9 male  masculine Tatooine  Human  

sw |> relocate(c(species, homeworld), .after = name)
  # A tibble: 4 × 11
#>   name           species homeworld height  mass hair_color skin_color  eye_color birth_year sex   gender   
#>   <chr>          <chr>   <chr>      <int> <dbl> <chr>      <chr>       <chr>          <dbl> <chr> <chr>    
#> 1 Luke Skywalker Human   Tatooine     172    77 blond      fair        blue            19   male  masculine
#> 2 C-3PO          Droid   Tatooine     167    75 NA         gold        yellow         112   none  masculine
#> 3 R2-D2          Droid   Naboo         96    32 NA         white, blue red             33   none  masculine
#> 4 Darth Vader    Human   Tatooine     202   136 none       white       yellow          41.9 male  masculine
```

如果需要更大的變動，`mutate()`可以讓你：

- 建立由現有欄計算而來的新欄。
- 用同名的新欄取代現有的欄。
- 把某欄的值設為`NULL`來刪除該欄。

顯然，`mutate()`很強大，也可能讓人困惑，同時也是讓人非常感謝有修改時複製機制的原因。

沒什麼明顯的理由需要在意星際大戰角色的身體質量指數，但以防萬一囉：

```R
starwars |> 
  select(c(name, species, height, mass)) |> 
  mutate(BMI = mass / (height / 100)^2) |> 
  head(4)
  # A tibble: 4 × 5
#>   name           species height  mass   BMI
#>   <chr>          <chr>    <int> <dbl> <dbl>
#> 1 Luke Skywalker Human      172    77  26.0
#> 2 C-3PO          Droid      167    75  26.9
#> 3 R2-D2          Droid       96    32  34.7
#> 4 Darth Vader    Human      202   136  33.3
```

**逐列操作**在修改單一 tibble 時比較少見（合併多個 tibble 會在後面的概念討論）。

有一個例外：`arrange()`會依照一欄或多欄的值來排序資料列。

```R
tbl
#>       A tibble: 4 × 3
#>   languages created has.syllabus
#>   <chr>       <dbl> <lgl>       
#> 1 Fortran      1957 FALSE       
#> 2 R            1993 TRUE        
#> 3 Python       1991 TRUE        
#> 4 Julia        2012 TRUE  

tbl |> arrange(languages)
#>       A tibble: 4 × 3
#>   languages created has.syllabus
#>   <chr>       <dbl> <lgl>       
#> 1 Fortran      1957 FALSE       
#> 2 Julia        2012 TRUE        
#> 3 Python       1991 TRUE        
#> 4 R            1993 TRUE     
```
