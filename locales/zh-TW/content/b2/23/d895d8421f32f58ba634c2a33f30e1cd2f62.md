# 指令補充

網格的每一列都以一個字組表示。

例如，

```
    0 1 0
    1 0 0
    1 1 0
```

表示為

```
0x2
0x4
0x6
```

網格最多有 32 行。

## 暫存器

| 暫存器   | 用途         | 型別    | 說明                        |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | 輸入         | 整數    | 列的數量                    |
| `$a1`    | 輸入         | 整數    | 行的數量                    |
| `$a2`    | 輸入         | 位址    | 目前世代的網格              |
| `$a3`    | 輸入／輸出   | 位址    | 下一代的網格                |
| `$t0-9`  | 暫存         | 任意    | 用於暫時儲存                |
