# 指令

這個練習要你分析電話號碼。

你要實作 2 個功能。

傳遞給這些常式的電話號碼保證為 NNN-NNN-NNNN 格式，例如 212-515-9876，且不為 null。

## 1. 分析電話號碼

你的分析應該回傳 3 筆資料：

1. 號碼的區號是否為紐約，也就是前 3 個數字是否為 212
2. 號碼是否為假號碼，也就是第 5 到第 7 位數字（從 1 開始算）是否為前綴碼 555
3. 號碼的後 4 位數字。

實作（靜態）方法`PhoneNumber.Analyze()`來產生電話號碼資訊。

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. 偵測電話號碼是否有假的前綴碼（555）

使用第 1 項任務產生的電話號碼資訊，實作（靜態）方法`PhoneNumber.IsFake()`來判斷這個電話號碼是否為假號碼。

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
