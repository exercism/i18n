# 簡介

「Pairs and Dicts」概念討論了 Julia 字典型別的基本用法。

由於`Dict`是重要且常用的集合型別，Julia 也提供了許多操作它們的函式。

## 取得項目

取得項目最簡單的方式是透過鍵（就像許多語言一樣）。
不過，查詢不存在的鍵會引發`KeyError`。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

我們可以先檢查鍵是否存在，再嘗試取得它（例如使用`haskey(d, 4)`），不過直接為缺少的鍵取得預設值也很有用。

為此，我們有`get()`函式，以及會修改字典的版本`get!()`。
兩者的差別在於，缺少的鍵是否會被加入`Dict`。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

在先前的概念中我們看到，`delete!()`可以依鍵移除項目。
這可以搭配取得值的動作，改用`pop!()`函式來完成。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 疊代

對`Dict`進行疊代時，預設會產生`key => value`配對。
這些組成部分可以用常見的`.first`和`.second`名稱來存取。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

我們經常只想使用鍵或只想使用值，這很簡單。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## 合併

合併兩個`Dict`可能很有用，但我們必須清楚，對於同時出現在多個輸入中的鍵，我們打算怎麼處理。

`merge()`和`merge!()`函式會以由左至右的方式合併任意數量的`Dict`。

既有的鍵，其值會被直接覆寫，因此最右邊的`Dict`「勝出」。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()`和`mergewith!()`函式讓我們可以把函式作為第一個引數傳入，用來定義重複的鍵該如何合併。
加法就是一個簡單的例子。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

請注意，`mergewith`系列函式正是高階函式的絕佳範例。
