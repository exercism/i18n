# 關於

在 Swift 中，你不能使用整數（例如 `string[3]`）來為字串取索引。
因為 Swift 字串是由長度可變的 Unicode 字元組成，所以若要找到某個字元，就必須逐一走訪前面的字元。

若要存取特定位置的字元，你必須計算出一個型別為 `String.Index` 的索引。
這些索引稱為*不透明索引*，因為它們的內部結構是由 Swift 管理，而不是直接當成原始整數來操作：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
