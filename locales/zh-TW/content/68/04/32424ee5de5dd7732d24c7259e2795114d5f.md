# 指令補充

## x86-64 Assembly 專屬說明

這個練習中的函式會接受一個陣列，裡面包含一個或多個數字，每個數字代表一個「遊戲分數」。

在 x86-64 assembly 中，陣列裡的元素是透過相對於基底指標的位元組偏移量來存取的。

這個基底指標會依照 [System V AMD64 ABI Calling Convention](https://www.uclibc.org/docs/psABI-x86_64.pdf) 透過暫存器傳入。

前 3 個引數會依照這個順序透過 rdi、rsi、rdx 傳入。

由於玩家的遊戲分數是以 32 位元整數表示，每個佔 4 位元組，因此可以從下列位置讀取：

| `rsi`   |
|---|
| `dword [rsi]` |
| `dword [rsi + 4]` |
| ... |
| `dword [rsi + 4*scores_count - 4]` |

`personal_top_three()` 應該將玩家的最高分寫入緩衝區，該緩衝區同樣透過暫存器傳入，並以相同方式存取。

| `rdi`   |
|---|
| `dword [rdi]` |
| `dword [rdi + 4]` |
| ... |

依照慣例，整數值會透過 rax 暫存器回傳。
