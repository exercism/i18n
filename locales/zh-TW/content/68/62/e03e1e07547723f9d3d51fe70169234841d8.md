# 關於

`call`是通用的「立刻執行這個 quotation」基本操作。當編譯器能看到 quotation 的字面形式時，就能推斷出堆疊效應；但當 quotation 來自變數、陣列或參數時，就必須自行宣告堆疊效應：

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

宣告`call( a b -- c )`會編譯成執行期檢查，確認 quotation 是否真的具有宣告的堆疊效應。一旦不符，你會得到清楚的錯誤，而不是損毀的堆疊狀態。

把 quotation 當成資料處理（將它們推入、放進陣列、從詞中回傳），正是讓串接式程式碼如此精簡的原因之一。一個「程式」可以只是一串單純的序列，而用`each`搭配`call`就足以解讀它。
