# 關於

[concept:csharp/resource-cleanup]() 使用`IDispose`介面，向類別的呼叫方發出訊號，表示當該物件不再需要時，有資源或程式狀態需要及時釋放或重設。在這個練習中，我們介紹了一些語法糖，也就是`using`關鍵字，讓程式碼更精簡，也比較不會遺漏重要的呼叫。

`using`可以視為在某些使用情境下取代了[`try/finally`][try-finally]。

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

這個語法可以用更精簡、更不容易出錯的寫法取代：

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

請注意，多個資源可以依照單行區塊的標準規則方便地合併：

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

在 C# 8 中引入了以下這種變化，`using`敘述出現在區塊開頭：

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

這讓你能在同一個區塊中擁有多個可處置的物件，也能更自然地處理[`try/catch`][try-catch]：

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

關於`using`關鍵字可以怎麼使用，以及可以用在哪些型別的執行個體上，這些規則都詳細說明在[這裡][using-statement]。

## 給 Java 開發者的說明

Java 開發者可能會認出這是 Java 7 中引入的[_自動資源管理_][automatic-resource-management]機制的類似機制。兩者非常相似。Java 的語法重新利用了`try`，它的優點是比 C# 的`using`更自然地整合`catch`區塊。

## 版本

請注意，比較彈性的`using`版本，也就是沒有自己語法區塊的版本，是在 C# 8 中引入的，所以你可能需要確認你正在處理的程式碼基底使用的是 C# 8 或之後的版本。
