# 指令補充

## 輸入/輸出格式

每一組單字都以一個以 null 結尾的字串表示，每個單字的結尾都有一個換行字元。

你必須依照候選單字中列出的順序回傳這些重組字。

舉例來說，`"tones\nnotes\nSeton\n"`

## 暫存器

| 暫存器  | 用途          | 型態    | 說明                                                          |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | 輸入          | 位址     | 以 null 結尾的目標字串，不含換行                                 |
| `$a1`    | 輸入          | 位址     | 以 null 結尾的候選字串，每個單字後面都有換行                     |
| `$a2`    | 輸入/輸出     | 位址     | 以 null 結尾的輸出字串，每個單字後面都有換行                     |
| `$t0-9`  | 暫時          | 任意     | 用於暫存                                                        |
