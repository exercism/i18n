# 操作說明

你的朋友 Linus 是一位在城市之間駕駛貨運列車的火車駕駛。雖然他很擅長處理列車，卻不太擅長處理物流或電腦。他想請你幫忙寫程式，整理列車的細節並修正路線資料中的錯誤。

~~~~exercism/note
這個練習用切片、索引以及各種`hash`方法就能輕鬆解決。
不過，我們希望你透過解下列每項任務，練習打包、解包與多重賦值。
~~~~

## 1. 建立所有車廂的陣列

你的朋友一直都有記錄每個車廂識別碼（ID），但他永遠不確定系統在任何時刻需要處理多少個車廂。如果把這些資料打包成一個統一的**陣列**，物流程式的其餘部分就會輕鬆許多。

實作一個方法`generate_list_of_wagons()`，它接受任意數量的車廂 ID。每個 ID 都會是正整數。這個方法應該將給定的 ID 以單一**陣列**的形式`return`。

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. 修正車廂的陣列

到這裡，你已經開始熟悉這些資料，以及它們在物流程式中的用法。這個 ID 系統一律把火車頭的 ID 指定為**1**，列車中其餘的車廂則會被指定一個隨機挑選、大於**1**的 ID。

你的朋友必須把兩節新車廂接上列車，卻忘了更新系統！現在，列車**陣列**中的前兩個車廂必須移到最後面，否則一切就會順序錯亂。

更麻煩的是，你的朋友剛剛發現了第二個**陣列**，裡面似乎包含遺漏的車廂 ID。他只記得，一旦搬移了新的車廂，這個第二個**陣列**中的 ID 就應該直接放在指定的火車頭後面。

如果你能修正他的錯誤並合併這些資料，Linus 會非常感激你。

實作一個方法`fix_list_of_wagons()`，它接受兩個含有車廂 ID 的**陣列**。它應該把第一個**陣列**的前兩個項目移到最後面，並將第二個**陣列**中的值插入到火車頭 ID（**1**）的後面（_右側_）。這個方法應該`return`一個經過修改的**陣列**。

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 新增缺少的停靠站

現在所有車廂資料都正確了，Linus 希望你更新系統的路線資訊。在一條運輸路線上，列車可能會在幾個不同的車站停靠，以裝載或卸下貨物。每趟旅程的中途交貨點數量可能各不相同。你的朋友希望你用任何缺少或額外的交貨資訊，來更新系統的路線**雜湊**。

實作一個方法`add_missing_stops()`，它接受一個路線**雜湊**，後面接著數量不定的關鍵字引數。這些引數的形式可以是一個含有一或多個停靠站的**雜湊**，也可以是任意數量的`stop_<number>: "city"`關鍵字配對。你的方法應該回傳更新後的路線**雜湊**，並多出一個**鍵**，這個**鍵**的值是依序包含所有新增停靠站的**陣列**。

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
停靠站一律會以正確的順序傳入，所以你不需要擔心排序的問題。
~~~~

## 4. 擴充路線資訊

Linus 一直在開發路線程式，並注意到某些路線缺少了一些重要細節。初始的路線資訊是以**雜湊**建構而成，你的朋友希望你用任何可能缺少的內容來更新那個**雜湊**。系統中的每條路線需要的細節都略有不同，所以 Linus 真的很希望有個通用的解決方案。

實作一個名為`extend_route_information()`的方法，它接受兩個**雜湊**。第一個**雜湊**包含列車路線往返的起點與目的地城市。

第二個**雜湊**包含其他路線細節，例如列車速度、長度或溫度。這個方法應該回傳一個包含所有路線資訊的合併**雜湊**。

~~~~exercism/note
第二個**雜湊**可以包含與範例所示不同或更多的屬性。
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
