# 關於

Elixir 程式碼在 [BEAM 虛擬機器][beam] 上執行。BEAM 是 [Erlang][erlang] 執行階段系統的一部分。Elixir 受到 Erlang 啟發，又與它共用執行環境，因此和 Erlang 函式庫之間有良好的互通性。也就是說，Elixir 開發者可以在自己的 Elixir 程式碼裡使用 Erlang 函式庫。事實上，針對 Erlang 函式庫已經提供的功能另外撰寫 Elixir 函式庫，在 Elixir 社群裡是不被鼓勵的。

因此，某些功能（例如數學運算或計時器函式）在 Elixir 中只能透過 Erlang 使用。

Elixir 與 Erlang 之間如此緊密的關係，意味著若想成為熟練的 Elixir 開發者，你可能會想花點時間學習 Erlang 的基本語法。

## 使用方式

在我們的 Elixir 程式碼裡可以直接使用 Erlang 的標準函式庫，不需要任何額外的步驟。

呼叫 Erlang 函式的方式和呼叫 Elixir 函式一樣，只有一個小小的差別。Erlang 的模組名稱是`snake_case`的 atom。舉例來說，若要從`math`模組呼叫 Erlang 的`pi/0`函式，可以這樣寫：

```elixir
:math.pi()
# => 3.141592653589793
```

## 最常使用的 Erlang 模組

最常使用的 Erlang 模組提供了 Elixir 標準函式庫所缺少的功能。它們包括：

- `timer`模組，提供[`sleep/1`][erl-timer-sleep]、[`send_after/2`][erl-timer-send-after]和[`send_interval/2`][erl-timer-send-interval]等函式。
- `rand`模組，提供[`uniform/0`][erl-rand-uniform]、[`normal/0`][erl-rand-normal]和[`seed/2`][erl-rand-seed-2]等函式。
- [`:io_lib.format/2`][erl-io-lib-format]，提供 C 風格的字串格式化（使用控制序列）。
- `math`模組，提供[`sin/1`][erl-math-sin]、[`cos/1`][erl-math-cos]、[`log2/1`][erl-math-log2]、[`log10/1`][erl-math-log10]和[`pow/2`][erl-math-pow]等數學函式。
- [`queue`][erl-queue]模組，提供佇列資料結構。
- [`crypto`][erl-crypto]模組，提供密碼學相關的函式。
- [`zip`][erl-zip]模組，提供處理 zip 壓縮檔的函式。
- [`calendar`][erl-calendar]模組，提供處理日期與時間的函式，例如[`iso_week_number/1`][erl-calendar-iso-week-number]。若要把 `Date`、`Time` 或 `NaiveDateTime` 結構傳給某個 Erlang 函式，就必須先用對應模組的`to_erl`函式將它轉換成 Erlang 的格式。

想探索 Erlang 的標準函式庫，可以參考 [STDLIB 參考手冊][erl-stdlib-ref]。

Elixir 與 Erlang 函式庫的互通性並不限於 Erlang 的標準函式庫。任何 Erlang 函式庫都可以在 Elixir 的程式碼中使用。
