# 關於

Julia 的創造者想要魚與熊掌兼得。正如他們在部落格文章「Why We Created Julia」中所說的，他們想要 C 的速度、Ruby 的動態特性，以及 Matlab 為人熟知的數學表示法。他們想要的是把最愛語言裡最喜歡的東西都湊在一起：像 Perl 那樣的字串處理，像 shell 那樣把東西黏合起來，功能強大卻不會複雜到難以理解。

Julia 有一套強大、清楚又直覺的動態[型別系統](http://docs.julialang.org/en/v1/manual/types/)。它既能讓你寫動態程式碼，也能在需要更多表達能力來簡化程式或提升效能時指定型別。這門語言支援[多重分派](https://youtu.be/kc9HwsxE1OY?t=66)，也就是根據每個引數的型別來決定要呼叫哪個方法。這讓你既能為特定型別撰寫專屬的方法，又能提供通用的備用版本，在數學程式碼裡特別好用，因為在那裡往往很難說某個運算為什麼該專屬於某個特定的引數。

Julia 的[超程式設計](http://docs.julialang.org/en/v1/manual/metaprogramming/)很容易。程式碼在 Julia 裡本身就能以資料結構表示，所以程式可以像 Lisp 一樣轉換並產生自己的程式碼。[Julia 的基礎與標準函式庫](https://github.com/julialang/julia)有很大一部分也是用 Julia 寫的，要理解並修改它，不需要懂另一種語言。如果你需要用到的函式庫是用別的語言寫的，例如 [C、Fortran](http://docs.julialang.org/en/v1/manual/calling-c-and-fortran-code/) 或 [Python](https://github.com/JuliaPy/PyCall.jl)，你可以用簡單的介面直接從你的程式碼中呼叫它們。

儘管問世不久，Julia 在現實世界裡已經被運用在各種領域，包括但不限於金融、資料科學與科學計算。你可以在 [Julia Blog Aggregator](https://www.juliabloggers.com/) 上找到許多展示應用，在 [juliacomputing.com](https://juliacomputing.com/case-studies/) 上看到商業使用的案例研究，也可以在[這裡](https://julialang.org/research/)找到關於這門語言及其研究應用的出版品清單。
