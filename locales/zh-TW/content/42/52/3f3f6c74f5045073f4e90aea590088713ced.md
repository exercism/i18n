# 說明

Chaitana 擁有一座非常受歡迎的主題樂園。
她在景觀優美的園區正中央只有一項遊樂設施：世界最巨大的雲霄飛車(TM)。
雖然只有這一項設施，世界各地的人還是遠道而來，為了有機會搭乘 Chaitana 的超級雲霄飛車，甘願排上好幾個小時。

這項設施有兩條佇列，各自以`array`表示：

1. 一般佇列
2. 快速通關佇列（_又稱 Fast-track_），在這裡人們額外付費以優先入場。

有人請你寫一些程式碼，以便更好地管理樂園裡的遊客。
你必須盡快實作下列函式，免得遊客（還有你老闆 Chaitana！）開始不耐煩。

## 1. 將人員加入佇列

定義 `ColossalCoaster.add_to_queue` 方法，它接受 4 個引數 `<express_queue>, <normal_queue>, <ticket_type>, <person_name>`，並回傳已加入該人員姓名的對應佇列。

1. `<ticket_type>` 是 `Int32`，其中 1 代表 express_queue，0 代表 normal_queue。
2. `<person_name>` 是要加入對應佇列的人員姓名（型別為 `String`）。

```crystal
express_queue = ["Tony", "Bruce"]
normal_queue = ["RobotGuy", "WW"]
ColossalCoaster.add_to_queue(express_queue, normal_queue, 1, "RichieRich")
# => ["Tony", "Bruce", "RichieRich"]
```

## 2. 我的朋友在哪裡？

有一個人比較晚到樂園，想加入朋友們正在排的佇列。
但他不知道朋友站在哪裡，而且手機也收不到訊號，沒辦法打電話給他們。

定義 `ColossalCoaster.find_my_friend` 方法，它接受 2 個引數 `queue` 和 `friend_name`，並回傳該人員姓名在佇列中的位置。

1. `<queue>` 是正在排隊的人所組成的 `array`。
2. `<friend_name>` 是你要找出其索引（在佇列中的位置）的朋友姓名。

```crystal
ColossalCoaster.find_my_friend(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve")
# => 1
```

## 3. 我可以加入他們嗎？

既然已經找到朋友了（在上述的任務 #2），這位晚到的人想在朋友排隊的位置加入他們。
定義 `ColossalCoaster.add_with_friends` 方法，它接受 3 個引數 `queue`、`friend_name` 和 `person_name`。

1. `<queue>` 是正在排隊的人所組成的 `array`。
2. `<friend_name>` 是要插入其位置的朋友姓名。
2. `<person_name>` 是要插入該索引位置的人員姓名。

回傳已加入這位晚到者姓名的佇列。

```crystal
ColossalCoaster.add_with_friends(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve", "Bucky")
# => ["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. 佇列裡的討厭鬼

你剛從佇列那邊聽說，有個很討厭的人又推人、又大叫，還到處鬧事。
你得把這個壞傢伙趕出去，因為他行為太差！

定義 `ColossalCoaster.remove_from_queue` 方法，它接受 2 個引數 `queue` 和 `person_name`。

1. `<queue>` 是正在排隊的人所組成的 `array`。
2. `<person_name>` 是要被趕出去的人員姓名。

回傳已移除那位討厭鬼姓名的佇列。

```crystal
ColossalCoaster.remove_from_queue(["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], "Eltran")
# => ["Natasha", "Steve", "Wanda", "Rocket"]
```

## 5. 排序佇列

為了管理上的需求，你需要把指定佇列中的所有姓名依字母順序排列。

定義 `ColossalCoaster.sorted_queue` 方法，它接受 1 個引數 `queue`（也就是正在排隊的人所組成的 `array`）。
這個方法應該回傳`array`排序後的副本。

```crystal
ColossalCoaster.sorted_queue(["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
# => ['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
