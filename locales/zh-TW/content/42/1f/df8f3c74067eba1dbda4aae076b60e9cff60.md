# 疊代器

用計數器逐一走過陣列，在真正開始做事之前，得先寫四行記錄性質的程式碼：

```sather
   i ::= 0;
   loop
      until!(i >= counts.size);
      total := total + counts[i];
      i := i + 1;
   end;
```

計數器、結束條件和遞增步驟，都和把數字加總這件事無關。**疊代器**把這三件事全都包辦了。

```sather
   loop
      total := total + counts.elt!;
   end;
```

`elt!`每繞一圈就交出一個元素，沒有元素時就結束迴圈。不用計數器，沒有容易出錯的地方，也不可能跑出陣列的範圍。

## 驚嘆號

`!`是疊代器的標記。你已經見過三個了，`until!`、`while!` 和 `break!`，它們都遵守同一條規則：**疊代器只能在迴圈裡呼叫。** 在迴圈外寫 `counts.elt!` 會造成錯誤。

在迴圈裡呼叫疊代器時，每繞一圈它就會被要求給出一個值。當它沒有值可給時，迴圈會立刻結束，不管這個呼叫出現在迴圈主體的哪個位置。

## 先從兩個開始

`elt!`會依序給出陣列或字串的元素。

```sather
   loop
      #OUT + names.elt! + "\n";
   end;
```

`upto!`負責計數。`1.upto!(5)`會給出 1、2、3、4、5，然後結束迴圈。

```sather
   loop
      total := total + 1.upto!(5);
   end;
```

兩者都是剛好以 `!` 結尾的普通常式，所以都用點號來呼叫，作用在陣列或數字上。

## 保留結果

迴圈會自己結束，所以在裡面算出的任何結果，都必須存放在**迴圈外**宣告的變數裡，否則迴圈一結束，它就會消失。

```sather
   total ::= 0;             -- outside
   loop
      total := total + counts.elt!;
   end;
   return total;
```
