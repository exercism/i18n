# 簡介

## 預設參數值

你可以為函式的任何參數提供[預設參數值][default-parameter-values]，方法是在參數列表中，緊接在該參數的型別註解之後為這個參數指派一個值。當指定了預設參數值之後，函式的呼叫者在呼叫函式時就可以省略該參數，此時會改用預設值。

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## 可變參數

[可變參數][variadic-parameters]讓函式可以針對單一參數接受零個或多個指定型別的值。
只要在參數的型別註解後面加上三個點（`...`），就能定義一個可變參數。

在函式主體中，Swift 會把這些值以指定型別的陣列形式提供使用：

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
如果函式在可變參數之後還有其他參數，那麼緊接在可變參數後面的第一個參數**必須**有明確的引數標籤，Swift 才知道可變引數列表在哪裡結束。
~~~~


## 輸入輸出參數

在函式主體中，參數會被視為常數，而不是變數；嘗試修改參數的值會引發編譯期錯誤。
如果函式想要修改某個參數的值，就必須使用[_輸入輸出參數_][in-out-parameters]，明確表達這種可變性。

要使用輸入輸出參數，程式設計師必須確認三件事：

1. 函式定義必須明確標記輸入輸出參數，方法是在參數的型別註解中，把關鍵字 `inout` 寫在 `:` 和型別名稱之間。
2. 傳入輸入輸出參數的值必須宣告為變數，而不能是常數。同樣地，它也不能是字面量。
3. 在呼叫函式時，變數名稱前面必須加上 `&`，明確標記它是可修改的。

完成這些之後，函式會為輸入輸出參數建立一份內部副本，依照函式主體中的指示修改它，然後在函式回傳時，把修改過的值複製回傳入的那個變數。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
關於輸入輸出參數，還有幾條額外的規則需要注意。

1  在含有輸入輸出參數的函式中，你不能引用作為輸入輸出參數傳入的那個變數。
2. 同一個變數不能在同一個函式中作為多個輸入輸出參數傳入。
   例如，`inoutFunc(&mutVar, &mutVar)` 會引發編譯器錯誤。
~~~~

## 巢狀函式

在 Swift 中，你可以[在其他函式裡面定義函式][nested-functions]。
這些函式稱為**巢狀函式**。

巢狀函式通常用來當作私有的輔助函式，負責執行外層函式需要的特定工作，同時又不會弄亂外層作用域：

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

巢狀函式的行為和一般函式一樣，但只有在外層函式的主體中才能看見。
