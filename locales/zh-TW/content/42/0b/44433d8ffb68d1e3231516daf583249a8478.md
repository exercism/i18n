# 關於

常值是直接寫在程式碼裡的固定值。
它們在執行期間不需要任何運算。
它們有各種形式，能有效率地表示不同型別的資料。
最常見的常值屬於數值性質，不過日期、時間和字串型別也有對應的常值運算子。
之後的概念會說明如何使用自訂的常值運算子。

## 數值常值

數值常值包含十進位、八進位、十六進位和二進位等表示法。
這些基礎已經在[數字概念][numbers-concept]中涵蓋過了。

像`23`、`0x50f7ba11`和`0xba5eba11`這些表示法，編譯器都會理解成`int`。
一般的`int`型別帶正負號，而且（[依編譯器和系統而定][in-depth-integers]）範圍通常是`-2'147'483'648`到`2'147'483'647`。
大多數情況下這樣就夠了，你不需要擔心具體的型別。

有些使用情境需要更大的範圍，或要求程式的記憶體佔用極小。
想要明確一點的話，可以直接在數值常值上指定具體的整數型別。

當不需要負數、但想要更大的範圍時，會在後面加上`u`或`U`後綴，代表_無號_整數。
需要更大的範圍時，可以用`L`甚至`LL`，分別代表 long 和 long long 型別。

~~~~exercism/caution
小寫的`l`是可以使用的，但它很容易和數字`1`搞混，因此不建議這麼寫。
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

浮點數在編譯時通常會解析成`double`。
這是很好的預設做法，需要使用較窄的`float`型別的情境，比上面無號整數的例子少見。

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## 字元與字串常值

其他概念已經用過單引號的字元常值，例如`'}'`或`'@'`。

在 C++ 裡，`char`只能表示前 128 個 [ascii 字元編碼][ascii-code]。
如果想使用多個 ascii 字元，或像`‰`這樣的擴充 ascii 字元，甚至像`麗`和`ẞ`這樣的 unicode 字元，就需要其他型別。
先前的概念介紹過用_雙引號_寫成的字串常值：`"一体どういう意味ですか。C++です"`。
這個日文句子的實際型別是`const char (&)[46]`，也就是 C 風格字串。

字串常值並不是預設就能直接使用的。
要使用_字串_常值`""s`或_字串檢視_常值`""sv`，使用者必須透過相關的命名空間來指明：

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_string_view_可以看成是對 const 字串的參考。
