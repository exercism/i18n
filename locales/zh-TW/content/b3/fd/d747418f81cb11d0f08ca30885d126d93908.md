## 這個練習在 Python 中的結構

我們額外新增了一個星期描述詞（`fifth`），用來表示一個月中的第五個星期幾，如果有的話。  
如果一個月中沒有第五個星期幾，你應該拋出一個例外。

## 自訂與拋出例外

有時候，你會需要在程式碼中同時[自訂](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)和[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)例外。這麼做的時候，一定要加上**有意義的錯誤訊息**，指出錯誤的來源。這能讓你的程式碼更好讀，也對除錯很有幫助。

自訂例外可以透過新的例外類別來建立（詳情請見 [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)），這些類別通常是 [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) 的子類別。

如果你知道錯誤來源會是某種例外型別的衍生，可以選擇繼承 _Exception_ 類別底下的其中一個 [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)。拋出錯誤時，仍然要附上有意義的訊息。

這個練習要求你建立一個_自訂例外_，在你的 `meetup()` 函式收到無效的星期名稱與數字組合時[拋出](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)這個例外。只有當你自訂了適當的例外、`raise` 這些例外，並附上適當的錯誤訊息時，測試才會通過。

要自訂 `built-in exception`，請建立一個繼承自該例外的 `class`。要以訊息拋出自訂例外時，請把訊息寫成 `exception` 型別的引數：

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
