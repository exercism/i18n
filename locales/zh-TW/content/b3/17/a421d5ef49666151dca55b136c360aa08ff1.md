# 關於

Gleam 用`Bool`型別來表示 true 和 false 這兩種值。它只有兩個值：`True`和`False`。這些值可以綁定到變數上：

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`和`!`這幾個運算子可以用來操作布林值：

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`和`||`運算子採用短路求值，也就是說，只有需要的時候才會對運算子右邊的運算式求值。

這些運算子各有不同的優先順序，其中`!`會比`&&`和`||`先求值。你也可以用大括號讓運算式裡的某個部分先求值：

```gleam
!True && False   // -> False
!{True && False} // -> True
```
