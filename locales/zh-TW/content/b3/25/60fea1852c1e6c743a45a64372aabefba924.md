# 說明

在這個練習中，你會寫一些程式碼，幫助你依照最愛的食譜書做出美味的千層麵。

你有五個任務，全都和烹煮千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義`expectedMinutesInOven`這個不可變變數，它會回傳千層麵應該待在烤箱裡幾分鐘。
這個變數必須匯出。
根據食譜書，預期的烤箱時間是 40 分鐘：

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. 計算剩餘的烤箱時間（分鐘）

實作`remainingMinutesInOven`程序，它接受千層麵實際已經待在烤箱裡的分鐘數作為參數，並根據上一個任務的預期烤箱時間，回傳千層麵還需要待在烤箱裡幾分鐘。

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. 計算準備時間（分鐘）

實作`preparationTimeInMinutes`程序，它接受你加在千層麵裡的層數作為參數，並回傳你準備千層麵花了幾分鐘，假設每一層需要花 2 分鐘準備。

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. 計算總工作時間（分鐘）

實作`totalTimeInMinutes`程序，它接受兩個參數：`numberOfLayers`參數是你加在千層麵裡的層數，而`actualMinutesInOven`參數是千層麵已經待在烤箱裡的分鐘數。
這個程序應該回傳你烹煮千層麵總共花了幾分鐘，也就是準備時間（分鐘）和千層麵目前已經待在烤箱裡的分鐘數的總和。

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```

proc totalTimeInMinutes*(numberOfLayers, actualMinutesInOven: int): int =
