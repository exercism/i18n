# 簡介

*堆積*是一種集合，它隨時都知道自己最小的項目，並讓你快速取出該項目。它是*優先佇列*的天然工具，優先佇列是一種等待隊伍，下一個被服務的是最重要的項目，而不是等最久的那個。堆積位於 [`heaps`][heaps] 詞彙中。

## 建立堆積

`<min-heap>` 會建立一個空堆積，其中*最小*的鍵會最先出來；`<max-heap>` 則是它的鏡像。

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
```

## 加入項目

每個項目都以一個*值*搭配一個*鍵*的形式儲存，鍵就是 Factor 用來排序的優先順序。`heap-push` 可以加入一個項目：

```
heap-push ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push   ! value "alice", priority 5
"bob"   2 pick heap-push   ! value "bob",   priority 2
```

堆積是*可變的*：`heap-push` 會直接就地修改它，而不是回傳一個新的堆積。在 `heap-push` 消耗掉堆積之後，`keep` 很方便用來把堆積放回堆疊上。

## 查看並移除最前面的項目

`heap-peek` 會回傳最前面的項目，也就是鍵最小的值，而且*不會*將它移除。`heap-pop` 會回傳該項目，*並*將它移除。`heap-empty?` 會回報是否還有剩下項目，讓你知道什麼時候該停止取出。`heap-pop-all` 會一次移除所有項目，並依優先順序回傳一份由 `{ key value }` 配對組成的關聯串列。

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-empty?  ( heap -- ? )
heap-pop-all ( heap -- alist )
```

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-empty? .        ! => f      (two items waiting)
dup heap-peek drop .     ! => "bob"  (smallest key, still in the heap)
dup heap-pop drop .      ! => "bob"  (smallest key, now removed)
heap-pop-all .           ! => { { 5 "alice" } }
```

`heap-pop` 和 `heap-empty?` 是一次處理一個項目的基礎元件，先查看或取出最前面的項目，對它採取動作，然後在 `heap-empty?` 回傳 `t` 之後停下來。下面的任務會用 `heap-pop-all` 一口氣清空整個佇列，不過只要持續取出直到堆積變空，也會得到相同的順序。

`heap-pop-all` 產生的配對是一份*關聯串列*：`values`（位於 `assocs` 中）只保留值，捨棄鍵。
