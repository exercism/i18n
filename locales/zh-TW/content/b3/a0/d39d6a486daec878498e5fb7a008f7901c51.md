# 關於

值的作用域，指的是程式中可以存取該值的位置。

## 作用域的四種類型：區塊、函式、函式原型、檔案

### 區塊作用域

具有區塊作用域的值，只能從定義它的區塊內部存取。
關於區塊的更多說明，請參閱[區塊概念](../blocks/introduction.md#Introduction)。

### 函式作用域

函式作用域是一種特殊的作用域，適用於搭配`goto`敘述使用的標籤。
同一個函式中不能有兩個同名的標籤，即使這些標籤定義在函式內不同的區塊中也不行。

### 函式原型作用域

函式原型作用域是另一種特殊的作用域，只適用於在原型中命名的參數（原型也稱為宣告，請留意並非所有宣告都是原型）。
在函式宣告中，參數名稱通常是選用的。
名稱的作用域只在該宣告中才有意義。
在下面的例子中，`len`識別字會先被定義，之後才在函式宣告中引用。

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

請注意，在一個宣告中引用同一個變數時，名稱必須一致。
如果`my_func`宣告成`void my_func(int len, int numbers[length]);`，就會產生類似以下的編譯錯誤

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

函式定義中的參數名稱，不必和函式宣告中使用的名稱相同。
在上面的例子中，宣告使用了`len`，定義則使用了`length`，這說明了`len`識別字的作用域僅限於函式宣告內。

### 檔案作用域

具有檔案作用域的值，可以從檔案中的任何位置存取。
這類值都定義在函式之外。
