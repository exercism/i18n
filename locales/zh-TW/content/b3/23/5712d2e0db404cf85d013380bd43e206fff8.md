# 簡介

## 相等性

Elm 的型別可以用相等運算子`(==)`來檢查是否「相同」。
不相等運算子則是`(/=)`，*不是*許多程式語言裡的`!=`。
相等運算子可以用於字面值、元組、記錄和自訂型別。

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

請注意，*千萬不要*比較函式，因為這麼做會讓程式在執行時當機。

## 比較

比較運算子`(<)`、`(<=)`、`(>)`、`(>=)`以及函式`min`、`max`、`compare`可以用於`comparable`型別。
`comparable`型別是一種特殊的型別，它把所有可以比較的內建型別集合在一起：數字、字元、字串、由可比較項目組成的陣列，以及由可比較項目組成的元組。

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

其他型別的值，例如記錄或自訂型別，則無法直接比較。

有些內建型別要求其內容必須是`comparable`，例如`Set`或`Dict`的鍵，因為它們的結構依賴內部的排序。

由`comparable`值組成的陣列可以用`List.sort`排序，而能夠對應到可比較值的陣列則可以用`List.sortBy`排序。
如果你需要多層排序（先依某個屬性排序，再用另一個屬性決定先後），也可以把元組或陣列搭配`List.sortBy`使用，因為元組和陣列是依照字典順序排序的。


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

函式`compare`接受兩個`comparable`值，並回傳一個`Order`。
`Order`是一種型別，它能在單一運算中判斷某個值是否大於（`GT`）、等於（`EQ`）或小於（`LT`）另一個值。

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

我們可以為任意型別建立比較函式，並用它們來排序，例如搭配`List.sortWith`：

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
