# 說明

重構一個 Markdown 解析器。

markdown 練習是一個重構練習。
這裡有一段程式碼，會解析含有 [Markdown 語法][markdown] 的字串，並回傳該字串對應的 HTML。
雖然這段程式碼寫得令人一頭霧水、難以看懂，但它竟然還是能正常運作，所有測試也都通過了！
你的挑戰是重寫這段程式碼，讓它更容易閱讀與維護，同時確保所有測試依然全部通過。

如果你在重構時用註解記下自己做了哪些改動，讓審閱的人能看得出來，那會很有幫助，不過這並非絕對必要。
最重要的是讓程式碼變得更好！

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
