# 說明

在這道練習中，你會寫一些程式碼，幫助自己準備買車。

你有三個任務：一個是判斷你是否需要駕照，一個是幫你在兩輛車之間做選擇，還有一個是估算中古車的合理價格。

## 1. 判斷你是否需要駕照

某些種類的車輛需要駕照才能駕駛。
假設只有`car`和`truck`這兩種需要駕照，其他種類都可以無照駕駛。

實作`needs_license(kind)`函式，它接受車輛的種類，並回傳一個布林值，表示該種類的車輛是否需要駕照。

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. 在兩輛想買的車之間做選擇

你評估了手邊可選的車輛。
你成功把選項縮小到兩個，但需要有人幫你做最後的決定。
為此，請實作`choose_vehicle(option1, option2)`函式，它接受兩輛車作為引數，並回傳一個決定，也就是依字典順序排在最前面的那個選項。

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. 估算中古車的價格

既然你已經做出決定，你想確保自己在經銷商那裡拿到合理的價格。
由於你想買的是中古車，價格取決於車齡。
粗略估算的話，假設車輛不到 3 年，價格是全新時原價的 80%。
如果超過 10 年，則是 50%。
如果車輛至少 3 年但未超過 10 年，價格是原價的 70%。

實作`calculate_resale_price(original_price, age)`函式。
它接受原價和車齡作為引數，並回傳經銷商那裡的預估價格。

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
