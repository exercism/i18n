# 關於

**詞**是 Factor 對函式的稱呼。你在`basics`中已經見過資料堆疊和堆疊重排的詞；接下來，換你來定義自己的詞，用它們的輸入來計算吧。

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

一個定義由`:`、堆疊效應、本體，最後是`;`組成。`( … -- … )`裡的名稱是給讀者看的；編譯器檢查的是輸入和輸出的*數量*。數量對不上就是編譯期錯誤，這能攔下一類 bug；這類 bug 在沒有這種宣告的動態型別語言裡，會變成執行期錯誤。

整數運算的詞`+`、`-`、`*`來自`math`詞彙，每個都會從堆疊頂端取用兩個數字。堆疊頂端是右邊的運算元，所以`8 3 -`算出來的就是`8 - 3`。

`CONSTANT:`會為一個固定不變的值定義名稱；呼叫這個名稱就會把值推入堆疊，和其他任何詞沒有兩樣。把常數放在檔案最前面，也就是放在任何會用到它們的詞之前。

一個詞的本體可以呼叫任何已經在作用域中的詞：同一個檔案裡較早的定義、從匯入的詞彙引進的詞，以及你自己宣告的常數。把小而單一用途的詞組合起來，是建立程式最自然的方式喔。

依照慣例：

- 詞和常數使用`lowercase-kebab-case`。
- 述詞以`?`結尾，並產生布林值（`even?`、`empty?`）。
- 會修改輸入的詞，往往和不修改的版本共用同一個名稱，只能靠上下文分辨。
