# 關於

我們會用 **AWK** 來指稱這門_語言_，並用 **`awk`** 或 **`gawk`** 來指稱解讀 AWK 程式的_執行檔_。

## 模式與動作

一個 AWK 程式由一組組**模式與動作的配對**組成

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**模式**可以是對輸入進行比對的正規表示式。也可以是任何結果為 true 或 false 的運算式。

**動作**是一道或多道 AWK 指令。外面的大括號是必要的。

如果模式的結果為 _true_，就會執行對應的動作。

## 紀錄與欄位

AWK 會把輸入解析成一連串的**紀錄**。每筆紀錄會再切割成零個或多個**欄位**。

預設行為是：

- 以換行字元作為「紀錄分隔符」，把輸入切成紀錄，因此每一_行_就是一筆紀錄。
- 以空白字元作為「欄位分隔符」，把紀錄切成欄位，因此每一個_字詞_就是一個欄位。

## 模式與動作（續）

模式可以省略，此時動作會_對每一筆輸入紀錄_執行。

動作也可以省略，此時預設動作是印出目前的紀錄。

### 特殊模式

有兩個經常使用的特殊模式。

- `BEGIN`會在讀取任何輸入之前執行對應的動作。
- `END`會在讀完所有輸入之後執行對應的動作。

## 欄位變數

你可以用`$1`、`$2`、`$3`等來取用欄位。

目前的紀錄是`$0`。

~~~~exercism/caution
說得精確一點，這些其實不算是嚴格的「變數」。`$`可以視為一種_運算子_，用來取得指定欄位編號的值。我們會在後續的概念中更深入探討。
~~~~

以下是其他一些常用的內建變數。

### 控制輸入解析的內建變數

- `RS`是輸入的紀錄分隔符。如前所述，它的預設值是換行字元。
- `FS`是輸入的欄位分隔符。

這些變數通常會設定在`BEGIN`動作區塊裡。

### 傳達資訊的內建變數

這些變數會在程式執行期間由 AWK 自動設定。

- `NF`儲存目前紀錄的欄位數量。
  - 想取得最後一個欄位的值，可以使用`$NF`。
- `NR`儲存目前的紀錄編號。
  - 處理多個輸入檔案時，`NR`會保存到目前為止已處理的紀錄總數。
- `FNR`儲存目前輸入檔案中目前的紀錄編號。
  - 為了說明 NR 和 FNR 的差異，這裡有個常見的 AWK 慣用寫法。
    ```awk
    NR == FNR {action}
    ```
    它的意思是「如果累計的紀錄編號等於目前檔案的紀錄編號」。這只有在_第一個輸入檔_的紀錄中才可能成立。

## 真假值

AWK 的真假值判定概念和 C 一樣：

- 數字`0`為假。
- 其他任何數字都為真。

由於 AWK 是文字處理語言，真假值的概念也延伸到字串。

- 空字串`""`為假。
- 任何非空字串都為真。

~~~~exercism/note

## 如何把輸入提供給`awk`

`awk`可以從檔案或標準輸入讀取輸入。以下這些做法都可以用。

```sh
awk '/regex/ {print $1}' file1 file2 ...

awk '/regex/ {print $1}' < file

some_command_here | awk '/regex/ {print $1}'
```

## 範例

在類 Unix 系統上，`/etc/passwd`存放使用者的相關資訊。每個使用者各佔一行，欄位之間以冒號分隔。

如要列出使用者名稱：

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

注意`{print $1}`這個動作沒有模式，所以每一筆紀錄都會執行它。

如果只想輸出以 bash 作為登入 shell 的使用者，可以這樣寫：

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```

### 更多範例

以下是一些 awk 程式，能和常見的 Unix 指令產生相同結果。

- 顯示檔案

    ```sh
    cat file.txt

    awk '1' file.txt
    ```

- 在檔案中搜尋模式

    ```sh
    grep 'foo.*bar' file.txt

    awk '/foo.*bar/' file.txt
    ```

- 只顯示檔案開頭的幾行

    ```sh
    head -n 20 file.txt

    awk '
        1
        NR == 20 {exit}
    ' file.txt
    ```

- 取代檔案中的文字

    ```sh
    sed 's/foo/bar/' file.txt

    awk '{sub(/foo/, "bar")};1' file.txt
    # or more readably
    awk '
        {
            sub(/foo/, "bar")
            print
        }
    ' file.txt
    ```
