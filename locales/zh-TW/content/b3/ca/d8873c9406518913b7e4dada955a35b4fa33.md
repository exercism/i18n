# 簡介

在 Common Lisp 中，就像其他語言一樣，陣列是一組元素，透過整數索引來存取。
元素可以是不同的型別。
陣列可以是多維的（不只是單純的一維）。

## 建立

`make-array`可以用來建立陣列。
它有很多選項，但比較簡單的用法就能建立 N 維陣列，把所有元素都初始化成同一個值，或是以另一個序列（例如陣列）中的值來初始化這個陣列。
它的第一個引數列出每個維度的大小。

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

（注意多維陣列印出時會帶上維度的數量。）

也可以用陣列印出時的相同格式來建立陣列：

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## 存取元素

要存取向量的元素，可以使用`aref`，索引從 0 開始。
提供的索引數量必須和陣列的秩一致。

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
