# 簡介

在 Gleam 中，撰寫並使用高階函式是很常見的事，也就是把其他函式當作引數的函式。有時候，一次使用許多高階函式會讓程式碼變得很難閱讀，出現一層又一層的縮排。

舉例來說，下面這個函式呼叫了幾個回傳`Result(Int, Nil)`的函式，並且在四個都成功時把它們的值加總起來。

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam 的 `use` 運算式讓我們可以寫出沒有這些縮排的程式碼，通常也讓程式碼更容易閱讀。

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

一個 `use` 運算式會收集區塊中後面所有的敘述，並把它當作回呼函式，作為最後一個引數傳給該函式呼叫。`use` 關鍵字和`<-`符號之間的變數，就是會傳給回呼函式的引數名稱。

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

回呼函式可以接受任意數量的引數，也可以完全沒有引數。

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

要建立一個能用 `use` 運算式呼叫的函式，並沒有什麼特別的要求，只要把回呼函式當作最後一個引數即可。

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam 的 `use` 運算式是非常強大的功能，可以運用在很多問題上，但過度使用時會讓程式碼難以閱讀。一般來說，比較建議使用一般的函式呼叫語法，只有在 `use` 運算式能讓程式碼更容易閱讀時才使用它。
