# 提示

## 1. 定義 `GbTree` 外部型別

- 外部型別可以使用`pub type TypeName(a, b, c)`語法來定義。

## 2. 定義 `new_gb_tree` 函式

- 外部函式可以使用`@external(erlang, "module", "function")`語法來定義。
- 這個函式應該使用`gb_trees:empty/0`。

## 3. 定義 `insert` 函式

- 查看`gb_trees:insert/3`的說明文件，確認引數的正確順序。
- 外部函式可以是私有函式，由`insert`函式呼叫，以改變引數的順序。
- 這個函式應該使用`gb_trees:insert/3`。

## 4. 定義 `delete` 函式

- 查看`gb_trees:delete_any/2`的說明文件，確認引數的正確順序。
- 外部函式可以是私有函式，由`delete`函式呼叫，以改變引數的順序。
- 這個函式應該使用`gb_trees:delete_any/2`。
- 如果找不到鍵，`gb_trees:delete/2`函式會崩潰，所以不應該使用它。
