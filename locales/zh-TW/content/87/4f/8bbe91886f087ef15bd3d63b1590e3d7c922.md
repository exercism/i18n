# 關於字串

Kotlin 中的[`string`][ref-string]是不可變的 Unicode 字元序列。

[`Immutable`][wiki-immutable]的意思是，對字串的任何操作都必須回傳新的字串：原始字串永遠不會改變。

[`Unicode`][wiki-unicode]代表世界上大多數的書寫系統都能被表示出來，但（和 C 這類較舊的語言不同）字元和位元組之間並沒有 1:1 的對應關係。
這部分會在後面的[`Chars`][concept-chars]概念中進一步討論。

字串會用雙引號`" "`包住。

有些字元需要跳脫：`\\`，以及一些常見的非列印字元，例如`\t`（定位字元）和`\n`（換行）。

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

多行字串則用 3 個雙引號包住，可以包含任意文字（不需要跳脫）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

用 [trimIndent][trimIndent-doc] 可以移除各行共同的縮排。
這在格式化字串時很好用：

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

或者，你也可以用 [trimMargin][trimMargin-doc] 自行指定分隔符號。
這樣`String`裡的每一行就會從分隔符號之後開始。
分隔符號預設是`|`，但你也可以用參數指定不同的分隔符號。
例如：

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

字串可以用`+`串接，但最好只用在簡短、單純的情況。
還有其他做法，而且往往更好。

## 字串模板

[`Templates`][ref-templates]指的是其他語言所說的「內插」。

如果字串裡有緊接著識別字的錢字號`$`，或是有以大括號（`{expression}`）包住的運算式，這些都會分別被替換成識別字的值或運算式的結果。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## 字串格式化

只有在 JVM 平台上，`String.format()`才能提供比字串模板更精確的格式化，它的[語法][web-formats]和（_非常古老！_）[`printf`][wiki-printf]函式類似。

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## 字串函式

Kotlin 提供了_許多_[`functions`][ref-string-functions]來操作字串。

這些大多是[`extensions functions`][ref-extensions]，而不是`String`類別的成員，不過這對我們怎麼使用它們幾乎沒有影響。

~~~~exercism/note
Kotlin 相當複雜的[說明文件][ref-string-functions]頁面，在預設檢視下會把擴充函式藏起來。
在撰寫這份文件時，最有價值的內容藏在名為`Members & Extensions`的分頁裡。
點擊它就能展開這個區段，看到`String`類別上所有可用的成員和擴充函式。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

以下範例只列出可用功能中的一小部分：

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## 建立字串

有時候，很長的字串需要分階段慢慢建立起來，例如在迴圈裡面。

用`+`串接字串很快就會變得不優雅，效能也不好：不可變性代表需要_大量_的複製。

Kotlin 有各種更有效率的方式可以組合多個字串：

- 字串模板，前面已經介紹過。
- [`joinToString()][ref-jointostring]，這會在之後的[陣列][concept-lists]概念中介紹。
- Java 的[`StringBuilder`][ref-stringbuilder]，不過它不太被認為是道地的 Kotlin 寫法。
- Kotlin 的[`buildString()`][ref-buildstring]，它把`StringBuilder`包裝成更簡潔、更道地的語法。
這會把建立字串的邏輯當作 lambda 引數傳入，之後的概念會再討論。

基本上，`StringBuilder`是一種類似陣列的結構，有很多方便的方法。
以下是其中一小部分：

- [`append()`][ref-sb-append]：加到最後面。
- [`insert()`][ref-sb-insert]：加到指定的位置。
- [`deleteAt()`][ref-sb-deleteat]和[`deleteRange()`][ref-sb-deleterange]：從指定的位置移除。
- `toString()`：最後轉換成一般的字串，用單一且高效的操作把全部內容串接起來。

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

以下是`buildString()`的範例，用到了之後概念才會提到的語法：

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
