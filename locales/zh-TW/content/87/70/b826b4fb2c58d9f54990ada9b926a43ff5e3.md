# 說明

安特衛普編組場又是一個繁忙的夜晚。你是值班的調度員：進站貨車要重新編組為出發列車，車鉤要逐一檢查，路線要在分歧點拆開，相同的貨物則要合併起來以便計費。

每一節*車廂*都是一個字串，說明它載運什麼：`"coal"`、`"timber"`、`"crates"` 等等。

## 1. 將車廂連接成列車

定義 `couple`，讓它接受一個車廂陣列和一個長度 `n`，並回傳每組 `n` 節車廂、彼此不重疊的列車。如果車廂總數無法整除，最後一組列車可以短一點。

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. 查看車鉤

定義 `peek-couplings`，讓它接受一個車廂陣列，並回傳每一組相鄰的車廂配對，這樣檢查員就能逐一檢查每個車鉤。

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. 在分歧點拆開列車

定義 `split-at-junctions`，讓它接受一個車廂陣列和一個 `junctions` 陣列（用來標記中斷點的車廂），並回傳分歧車廂之間的各段。分歧車廂本身不會被保留下來。

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. 合併相同的貨物

定義 `coalesce-cargo`，讓它接受一個車廂陣列，並把載運相同貨物的*連續*車廂歸成一段段。

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
