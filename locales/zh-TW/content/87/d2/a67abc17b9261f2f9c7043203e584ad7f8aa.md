# 指令補充

完成這個練習的方式有很多，不過這個練習是特別為想練習撰寫自己的 [ability handlers][ability-handler-docs] 的人量身打造的。

請寫一個 `Zipper` ability，讓你能在二元樹資料結構中移動。

`Zipper` ability 本身已經為你定義好了，但你需要自己實作處理常式，讓它能在我們指定的二元樹資料結構中移動。

給定以下的二元樹，如果我們依序呼叫 `Zipper.right`、`Zipper.right`、`Zipper.up`，然後再呼叫 `Zipper.left`，應該會停在值為 `5` 的節點上。

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

就這個練習而言，如果你對一棵沒有左分支或右分支的二元樹呼叫 `left` 或 `right`，可以直接回傳目前所在節點的值。
