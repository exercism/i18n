# 說明補充

## 字詞

定義一個`rat` tuple，裡面有`numerator`和`denominator`兩個欄位。
`<rat>`應該把引數約分成最簡分數，並把正負號放在分子上（所以分母永遠是正的）。

- `<rat> ( numerator denominator -- rat )`，建立一個約分後的有理數。
- `>rat ( pair -- rat )`，從`{ numerator denominator }`建立一個`rat`。
- `rat>pair ( rat -- pair )`，回傳`{ numerator denominator }`。
- `r+ ( a b -- c )`、`r- ( a b -- c )`、`r* ( a b -- c )`、`r/ ( a b -- c )`，兩個有理數之間的算術運算。
- `r-abs ( a -- |a| )`，取絕對值。
- `r^ ( a n -- a^n )`，將有理數取整數次方（允許負指數）。
- `real^r ( x a -- y )`，將實數取有理數次方，並回傳浮點數。

Factor 的`MATH:`泛型詞（`+`、`-`、`*`、`/`）只會依內建的數學階層分派，所以這個練習採用專屬的字詞名稱，而不是在這些泛型詞上定義方法。
