# 指令

在這個練習中，你會處理日誌行。

每一行日誌都是一個格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

日誌層級有三種：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會取一行日誌，並要你對它做點處理。

## 1. 從日誌行取得訊息

實作（_static_）`LogLine.Message()`方法，回傳日誌行的訊息：

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

開頭或結尾的空白都應該移除：

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. 從日誌行取得日誌層級

實作（_static_）`LogLine.LogLevel()`方法，回傳日誌行的日誌層級，且應該以小寫回傳：

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. 重新格式化日誌行

實作（_static_）`LogLine.Reformat()`方法，重新格式化日誌行，把訊息放在前面，並在後面用括號附上日誌層級：

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
