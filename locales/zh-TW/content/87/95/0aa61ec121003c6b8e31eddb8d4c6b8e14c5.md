# 簡介

## 繼承

在 C# 中，可以透過*繼承*來定義*類別*階層，讓衍生類別（`Car`）繼承父類別（`Vehicle`）的行為和資料。如果沒有指定父類別，類別會繼承`object`類別。

父類別可以透過三種方式提供功能給衍生類別：

- 定義一般方法。
- 定義`virtual`方法，它就像一般方法，但衍生類別*可以*改變它。
- 定義`abstract`方法，這是一種沒有實作的方法，衍生類別*必須*實作它。含有`abstract`方法的類別也必須標記為`abstract`。抽象類別無法具現化。

`protected`存取修飾詞允許在衍生類別中存取父類別的成員，但會阻擋其他類別存取。

衍生類別可以透過`base`關鍵字存取父類別的成員。

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

衍生類別的建構函式在執行自己的建構函式邏輯*之前*，會自動呼叫父類別的建構函式。可以使用`base`關鍵字將引數傳遞給父類別的建構函式：

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

當一個基底類別衍生出多個類別時，這兩個（或更多）類別通常會以不同方式實作基底類別的某個方法。這是一個非常重要的原則，稱為多型。舉例來說，下面這個改編自上例的範例展示了使用`Vehicle`的程式碼如何根據具現化的載具型別來改變行為。

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
