# 簡介

這可能是個*很大*的主題！
真的可以為它寫出一本厚書，而且確實有幾個人這麼做了（在 Amazon 搜尋「unicode book」就能看到一些例子）。

## 簡短的歷史

在幾十年前，電腦處理字元簡單得多，當時的程式設計師認為英文是唯一重要的語言。
所以：26 個字母、大小寫、10 個數字、幾個標點符號，再加上一個讓鈴響起的編碼（0x07），全部塞進 7 個位元就夠了：也就是 [ASCII][wiki-ascii] 字元集。

很自然地，有人開始問那 à、ä 和 Ł 怎麼辦，接著又有人問起 ऄ、ஹ 和 ญ，而年輕人想要 emoji 😱。
這該怎麼辦？

長話短說，許多聰明又有耐心的人必須花好幾年待在委員會裡，訂出 [Unicode][web-unicode] 字元集以及 [UTF-8][wiki-utf-8] 之類編碼的細節，而大量軟體得要進行*非常*複雜的改寫。
此外，還引入了許多新的 bug。

為了不讓*所有東西*都壞掉，Unicode/UTF-8 的設計確保前 127 個編碼與 ASCII 完全相同（*連那個鈴也是*）。

## Kotlin 裡的字元

大約 2005 年之後才設計出來的語言，有個很大的優勢：那時已經有了一套相當穩定的 Unicode 標準。

Kotlin（2011 年首次發布）可以理所當然地假設使用者會使用各種（人類）語言，而且需要用 Unicode 來表達它們。

字元常值是寫在單引號裡的，和寫在雙引號裡的字串不同。
對來自 C/C++ 世界的人來說這大概很明顯，但對 Python 和 JavaScript 程式設計師來說可能很容易搞混。

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

在`Char`和`Int`之間轉換很簡單：

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

編譯器允許對`Char`做*某些*形式的整數運算：

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char`的幾個函式

一如往常，這裡有太多[函式][ref-char-lib]可以討論了，以下只挑選了幾個。

- 對適用的字母系統，用[`uppercase()`][ref-uppercase]和[`lowercase()`][ref-lowercase]改變大小寫。
- 用[`isUpperCase()`][ref-isuppercase]和[`isLowerCase()`][ref-islowercase]測試大小寫。
- 用以下函式測試字元類型：
    - [`isLetter()`][ref-isletter]，涵蓋許多字母系統
    - [`isDigit()`][ref-isdigit]，範圍是 0..9
    - `isLetterOrDigit()`，結合前兩者
    - [`isWhitespace()`][ref-iswhitespace]，任何空白字元

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Char 陣列與字串的互相轉換

要從字串轉成 Char 陣列，可以用`toList()`。

要從 Char 陣列轉成字串，則有[`joinToString()`][ref-jointostring]函式，它會接受一個分隔符號當作引數（通常用空字串）。

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

請注意，`joinToString()`是作用在 List 或 Array 上。
要把單一個`Char`*轉型*成只有一個字元的字串，請用`toString()`。

```kotlin
'a'.toString() // => "a"
```

要檢查某個字元是否出現在`String`或`Char`陣列中，我們有`in`，它對應到[`contains()`][ref-contains]函式。

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
