# 說明

你對 Blorkemon™️ 卡片的懷舊之情絲毫沒有減退的跡象，甚至又開始收集起來，還拉著朋友一起加入。

在這個練習中，卡片收藏以`Set(String)`表示，因為當你的目標是蒐集所有現有的卡片時，重複的卡片並不重要。

## 1. 開始收藏

你真的很希望朋友們也加入你的 Blorkemon™️ 狂熱，而最好的方式就是送他們 1 張卡片，幫他們的收藏起個頭。

實作`new_collection`，把一張卡片轉換成一個收藏。

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. 擴充收藏

有了收藏之後，它便有了自己的生命，必須持續成長。

實作`add_card`，它接收一張卡片和一個收藏，並回傳一個帶有 2 個值的元組：一個`Bool`，表示這張卡片是否已經在收藏裡，以及加入該卡片後的收藏。

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. 開始交易

既然朋友們又為 Blorkemon™️ 瘋狂了，你就可以藉由交易卡片來擴充自己的收藏。

不是每筆交易都值得做，有些甚至根本做不成。
你不能交易自己沒有的卡片，也不該拿一張卡片去換自己已經有的卡片。

實作`trade_card`，它接收 2 張要交易的卡片（你的和對方的）以及你目前的收藏。
回傳值是一個帶有 2 個值的元組：一個`Bool`，說明這筆交易是否可行又值得，以及假如你真的完成交易後會得到的收藏（即使實際上根本不可能）。

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. 大家都有的卡片

你和熱愛 Blorkemon™️ 的朋友們聚在一起，想著哪些卡片最常見。

實作`boring_cards`，它接收一個收藏的陣列，回傳一個排序過的卡片陣列，這些卡片是所有收藏都有的。

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. 所有的卡片

你和朋友們加起來，擁有全部的 Blorkemon™️ 卡片嗎？

實作`total_cards`，它接收一個收藏的陣列，回傳所有收藏中不同卡片的總數。

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. 閃卡無敵

你的侄子快要來拜訪你了，你想讓他印象深刻。
小孩子都喜歡閃亮亮的東西，對吧？
Blorkemon™️ 卡片也能有閃亮版本喔！

實作`shiny_cards`，它接收一個收藏，回傳一個集合，裡面包含所有以`"Shiny "`開頭的卡片。

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
