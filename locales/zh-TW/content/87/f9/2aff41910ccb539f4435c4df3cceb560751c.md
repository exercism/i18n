# 簡介

`Integer`可以存放任意大的數字，只受限於你機器的記憶體，而`Int`則對應到可用 32 或 64 位元表示的正負整數集合（至少保證能表示 -2^29 到 2^29）。

`Float`對應到實數的集合，但其精度受電腦限制。
定義在數字上的運算通常只適用於其中一種型別，無法同時適用於兩者。

在`Float`和`Integer`之間轉換的函式，其中包括`toFloat`（將`Int`/`Integer`轉換成`Float`）和`ceiling`（將`Float`轉換成`Int`）等。

從整數型別（`Int`或`Integer`）轉換成任何其他數值型別時，是使用函式`fromIntegral`來完成。
目標型別會自動推論。
例如：

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
