# 簡介

`List`和`Array`非常相似。不過，其中有幾個重要差異是你不能錯過的：

1. `List`不能用方括號索引，也就是`[0]`。
2. `List`無法初始化。
3. 沒有列表推導式。
4. `List`可以在疊代的過程中自由修改元素。

`List`是`haxe.ds`套件的成員，所以每當你想使用`List`時，都需要先匯入它所在的套件：

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
