# 說明

在這個練習中，你會處理日誌列。

每一則日誌列都是格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

日誌層級有三種：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會拿到一則日誌列，並要你對它做些處理。

## 1. 從日誌列取得訊息

實作（_static_）`LogLevels.message()`方法，回傳日誌列的訊息：

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

開頭或結尾的空白都應該移除：

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. 從日誌列取得日誌層級

實作（_static_）`LogLevels.logLevel()`方法，回傳日誌列的日誌層級，且應以小寫回傳：

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. 重新格式化日誌列

實作（_static_）`LogLevels.reformat()`方法，重新格式化日誌列，把訊息放在前面，並將日誌層級以括號放在其後：

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
