# 指示

延續你在遊樂園的工作，這次要請你撰寫一些工具方法，用來檢查遊客是否能搭乘某項遊樂設施。

## 1. 檢查遊客是否持有搭乘證

實作 `Attendee#has_pass?` 方法，根據遊客是否持有搭乘證，回傳布林值（`true`/`false`）。

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. 檢查遊客是否適合搭乘遊樂設施

實作 `Attendee#fits_ride?` 方法，根據遊客的身高判斷他們是否適合搭乘某項遊樂設施。
遊樂設施要求的最低身高會以引數傳入。
遊客的身高必須大於或等於遊樂設施要求的最低身高。

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. 檢查遊客是否可以搭乘遊樂設施

實作 `Attendee#allowed_to_ride?` 方法，判斷遊客是否可以搭乘某項遊樂設施。遊樂設施要求的最低身高會以引數傳入。遊客必須持有搭乘證，並且符合該遊樂設施的身高限制。

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
