# 自訂迭代器

從 `bird-survey` 開始，你就一直在用迭代器。現在換你自己來寫一個吧。

## yield

迭代器看起來就像常式，但有兩點不同：名稱以 `!` 結尾，而且用 `yield` 交出值，而不是 `return`。

```sather
   markers!(count : INT) : INT is
      loop
         yield 100 * 1.upto!(count);
      end;
   end;
```

`yield` 會把一個值交給呼叫這個迭代器的迴圈，然後**等待**。等那個迴圈再繞回來時，迭代器會從 `yield` 之後繼續，一切就跟它離開時一模一樣：它的變數、它自己的迴圈、它所在的位置。

這就是迭代器的本質：一個能夠中途暫停、之後再繼續的常式。

```sather
   loop
      #OUT + TRAIL::markers!(3) + " ";      -- 100 200 300
   end;
```

## 結束

迭代器結束的方式有兩種。

**跑完。**當迭代器自己的迴圈跑完，或常式走到盡頭，它就結束了，而呼叫它的那個迴圈也會立刻結束。

**`quit`。**`quit` 會當場結束迭代器，不再交出任何值。

```sather
   named!(names : ARRAY{STR}) : STR is
      loop
         name ::= names.elt!;
         if name = "" then quit; end;
         yield name;
      end;
   end;
```

它會一路交出名字，直到遇到空字串就停下來。`quit` 對迭代器而言，就像 `return` 對常式一樣，差別在於它不帶任何值：已經沒有東西可以交了。

## once

標上 `once` 的引數只會在迴圈開始時計算一次，而不是每一輪都算：

```sather
   markers!(once count : INT) : INT is
```

只要某個東西在每一輪之間不會改變，就適合用 `once`，而大多數引數都是這樣。函式庫自己的迭代器也是這麼做的：`upto!(once i : SAME)`。

## 不交出值的迭代器

迭代器不一定要交出值。`times!` 就是一個例子：

```sather
   steps!(once count : INT) is
      loop
         ignored ::= 1.upto!(count);
         yield;
      end;
   end;
```

單獨一個 `yield` 什麼都不交，只是讓迴圈繼續繞一圈。

## 位置記在哪裡

程式裡每個呼叫迭代器的*位置*，都會保有自己的進度，這也是為什麼在同一個迴圈本體裡呼叫同一個迭代器兩次，就會把它走過兩遍。現在你可以明白原因了：那兩次呼叫是兩個各自暫停的常式。
