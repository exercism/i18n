# 簡介

Factor 的 I/O 建立在*串流*之上，也就是你能從中讀取位元組或字元、或把位元組或字元寫入其中的物件。[`io`][io]詞彙提供同一個[協定][stream-protocol]的兩種檢視方式。

## 兩種檢視方式

**顯式串流**詞會把串流當作引數傳入。它們一律以 `stream-` 開頭：

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

**環境串流**詞會從*目前綁定*的串流讀取，或寫入該串流，也就是全程式共用的動態變數 `input-stream` 或 `output-stream`。它們的名稱都很短：

```
read1 read readln write write1 print flush
```

日常程式碼大多使用環境形式。當你手上有一個特定的串流，又不想替換掉環境串流時，就會改用顯式形式。

## 記憶體內串流

在這道練習中，你會用到來自[`io.streams.string`][io.streams.string]的字串串流：

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

`<string-reader>` 會把字串常值當成檔案來讀取；`<string-writer>` 則會收集所有寫入其中的內容，讓你之後能再讀回來。兩者都實作與檔案串流相同的協定，因此這些知識可以直接套用到 `<file-reader>` / `<file-writer>`。

## 用 `with-…` 界定作用域

若要把某個顯式串流綁定成 quotation 的環境串流，並在之後釋放它，可以使用 `with-…` combinator：

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer]是「收集這段 quotation 印出的內容」的便利形式，它會建立 writer、以該 writer 作為環境輸出執行 quotation，並回傳捕捉到的字串：

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

所有 `with-…` combinator 都是 destructor combinator（與 [`boatswains-bilge`][boatswains-bilge] 的 `with-disposal` 和 `with-destructors` 屬於同一家族），即使 quotation 拋出例外，串流在離開時仍會被釋放。
