# 指令

在這道練習中，你會為一間在 2012 年 9 月 15 日開幕的美容沙龍製作預約排程系統。

這五個任務都與預約日期有關。

## 1. 解析預約日期

實作`Schedule`函式，將預約日期的文字表示解析成對應的`time.Time`格式：

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. 檢查預約是否已經過去

實作`HasPassed`函式，它會接收一個預約日期，並檢查該預約是否已成為過去：

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. 檢查預約是否在下午

實作`IsAfternoonAppointment`函式，它會接收一個預約日期，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. 描述預約的時間和日期

實作`Description`函式，它會接收一個預約日期，並回傳該日期與時間的描述：

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. 回傳沙龍開幕的週年紀念日

實作`AnniversaryDate`函式，回傳沙龍開幕日在當前年度的週年紀念日，時間以 UTC 為準。

假設目前年份是 2020 年：

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**注意：**回傳值是 `time.Time`，一天當中的時間不重要。
