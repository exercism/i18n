# 結構體

結構體是自訂的資料型態，讓你能為多個相關的值命名，並把它們打包在一起。
它們和元組很相似，但更有彈性，還能為每一筆資料命名，讓你的程式碼更清楚。
Cairo 的結構體有這些特性：

- 每個結構體型別都有特定的名稱。
- 結構體裡的每個成員稱為**欄位**。
- 結構體的每個欄位都有特定的名稱。
- 可見性是以欄位為單位來管理的：每個欄位都可以各自設定為公開或私有。

## 定義與建立結構體

要定義結構體，使用`struct`關鍵字，後面接上名稱，再用大括號列出各個欄位及其名稱與型別：

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

要建立`struct`的實例，請指定`struct`名稱，並用大括號以鍵值對來設定欄位。
注意，建立實例時，欄位的順序可以任意排列：

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## 操作結構體實例

用點記法來存取或修改`struct`實例的欄位。
注意，要修改欄位，這個實例必須是可變的：

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

如同任何運算式，我們可以把`struct`的新實例建立成函式主體中的最後一個運算式，藉此隱式回傳這個新實例：

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## 欄位初始化簡寫

在上一個例子中，把`email`和`username`這兩個函式參數取成和`struct`欄位相同的名稱很合理，但將它們指定給結構體欄位時還得重複寫一次，就有點繁瑣了。
幸好，有個方便的簡寫，可以用同名的變數來初始化結構體欄位：

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## 用結構體更新語法從其他實例建立實例

用結構體更新語法可以從既有的實例建立新實例，只改動部分欄位，其餘的則保持不變。
這是透過`..`運算子達成的。

不使用更新語法：

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

使用更新語法：

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

`..user1`語法會把`user1`剩下的欄位複製到`user2`。
注意，這會把資料從`user1`移動到`user2`，所以如果`user1`含有不可複製的型別，之後就無法再使用它。
