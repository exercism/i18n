# 簡介

[math/rand][mathrand] 套件支援產生偽隨機數字。

以下是產生介於`0`和`99`之間隨機整數的方法：

```go
n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

函式`rand.Float64`會回傳介於`0.0`和`1.0`之間的隨機浮點數：

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

此外，也支援將切片（或其他資料結構）洗牌：

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## 種子

`math/rand`套件產生的數字序列並不是真正的隨機。
只要給定特定的「種子」值，結果就完全固定不變。

在 Go 1.20 之後的版本中，種子會自動隨機選取，因此每次執行程式時，都會看到不同的隨機數字序列。

在較早的 Go 版本中，種子預設為`1`。
因此，若想讓程式每次執行時產生不同的序列，就必須在取得任何隨機數字之前，手動為隨機數字產生器設定種子，例如使用目前的時間。

```go
rand.Seed(time.Now().UnixNano())
```

[mathrand]: https://pkg.go.dev/math/rand
