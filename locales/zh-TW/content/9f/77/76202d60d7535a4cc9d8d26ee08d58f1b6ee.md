# 關於

`Lambda` 類別集結了一組函式方法，讓我們能以函式風格來撰寫 Haxe 程式。它讓我們能一次操作整個 Iterable。這通常比寫迴圈更好，因為比較不容易出錯，也更容易閱讀。為了方便起見，Array 和 List 類別也包含了一些 `Lambda` 類別中常用的方法。

`Lambda` 類別中部分函式包括：

- `Lambda.array`、`Lambda.list`：把 Iterable 轉換成 Array 或 List。它一律會回傳新的實例。
- `Lambda.count`：計算元素的數量。如果 Iterable 是 Array 或 List，改用它的 length 屬性會更快。
- `Lambda.has`：判斷指定的元素是否在 Iterable 裡。
- `Lambda.indexOf`：找出指定元素的索引。
- `Lambda.find`：找出符合指定搜尋函式的第一個元素。
- `Lambda.concat`：合併兩個 Iterable，回傳一個新的 List。
- `Lambda.filter`：找出符合條件的元素，回傳一個新的 List。

以下範例示範其中幾個函式：

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
