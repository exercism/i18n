# 關於

[F#](https://try.fsharp.org/) 是一門強型別的函式語言，屬於微軟 .NET 語言體系的一員。

雖然 F# 很適合處理資料科學問題，但它也能優雅地處理幾乎所有你交給它的問題。

由於 F# 是在 .NET 執行階段上執行的，你可以取用整個 .NET 生態系，包括 [nuget.org](https://www.nuget.org/) 上的所有套件。

因為 F# 也允許你撰寫物件導向程式碼，與現有 .NET 程式碼的整合又更加簡單。

F# 的首頁是 [fsharp.org](http://fsharp.org/)，而 [F# for fun and profit](http://fsharpforfunandprofit.com/) 網站則是很棒的 F# 入門資源。
