# 說明

你正在幫一位朋友，把他從花園各個角落收集到的讀數整理成一份報告。
可惜的是，你朋友把資料存成了一種奇怪的格式。
每一筆讀數都是一組以逗號分隔的欄位。
不過，他把兩位數拆成兩個欄位來儲存。

| 欄位編號 | 意義 |
| --- | --- |
| 1 | 識別碼 |
| 2 | 位置 |
| 3 | 第一筆讀數的十位數 |
| 4 | 第一筆讀數的個位數 |
| 5 | 第二筆讀數的十位數 |
| 6 | 第二筆讀數的個位數 |

以`101,house,4,2,5,4`這樣的輸入列為例：
- 第一筆讀數是`42`，
- 第二筆讀數是`54`。

## 任務 1：產生報告

你的任務是算出兩筆讀數的平均值，並以下列格式輸出每一列的結果：

```none
#<id>, <label> = <average>
```

由於 42 和 54 的平均值是 48，範例列的輸出應該會是：

```none
#101, house = 48
```
