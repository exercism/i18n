# 測試

每個範例都需要執行下列的一般步驟。

首先，切換目錄到你想練習的練習，在這個例子中是`bob`。

```bash
$ cd </path/to/exercism>/lfe/bob
```

接著執行測試。`test`這個 make 目標相依於`compile`，所以執行`make test`會確保你的原始碼先完成編譯，然後繼續執行測試。


```bash
$ make test
```

恭喜！你的測試失敗了！！！

現在請閱讀`README.md`，了解你需要做什麼才能讓所有測試通過。


修正測試回報的第一個錯誤，然後再次執行測試。

```bash
$ make test
```

繼續修正原始碼中下一個失敗的測試，並持續執行測試，直到所有測試都通過。

當所有測試都通過後，最後再看一遍`src`目錄中的程式碼，確認你對自己的程式碼感到滿意，然後提交審閱。

取得回饋、修改解法、提交、嘗試下一個練習，如此反覆，直到達到 LFE 的開悟境界。
