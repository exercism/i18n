# 簡介

*正規表示式*（regex）是一種小巧的模式，用來描述某段文字應該長什麼樣子。你不必自己逐字元檢查字串，只要把你想要的樣子寫一次，再交給 Factor 去比對就好。Factor 的正規表示式工具都放在 [`regexp`][regexp] 詞彙裡。

## 撰寫模式

在 Factor 裡，正規表示式寫在 `R/ ` 和 `/` 之間：

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

模式裡大多數字元就只代表它們自己，`R/ cat/` 比對到的就是 `cat` 這段文字。真正強大的地方，在於幾個特殊的符號，它們代表的是字元的*種類*，或是字元*重複的次數*。

### 字元類別：從一組字元中取一個

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

一個類別只比對*一個*字元。`[A-Z]` 比對得到 `Q`，但比對不到 `QQ`。

### 量詞：重複幾次

把下面其中一個放在某個符號*後面*，用來表示它可以重複幾次：

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

所以 `\d{4}` 代表連續 4 個數字，`[A-Z]+` 代表一個以上的大寫字母。把它們組合起來，`R/ [A-Z]+-\d+/` 描述的就是「一個以上的大寫字母、一個連字號，接著一個以上的數字」，像是 `SALE-2024` 這樣的文字。這裡的 `-` 是一般字元：在 `[ ]` 外面，連字號就只比對連字號（在類別裡面，例如 `[A-Z]`，它代表一個範圍）。

## 比對整段字串

`matches?` 回答的是「這*整段*字串完全符合這個模式嗎？」這個模式必須涵蓋從頭到尾每一個字元：

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

即使 `SALE-2024` 就藏在 `"GET SALE-2024"` 裡面，`matches?` 還是會回傳 `f`：多出來的字元也是字串的一部分，並不符合這個模式。如果你只在意這個模式*有沒有出現在某處*，就改用 `re-contains?`，`matches?` 回傳 `f` 的情況，它正好會回傳 `t`：

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## 在較長的文字裡找出比對結果

`re-contains?` 只告訴你模式*在不在*裡面。接下來這幾個詞會往裡面找，並回報*比對到什麼*：`all-matching-subseqs` 會以字串序列的形式，回傳模式比對到的每一個位置，而 `count-matches` 只是把它們數出來：

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## 取代比對到的內容

`re-replace` 會把每一個比對結果換成一段取代文字，並回傳新的字串：

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

`regexp` 詞彙裡還有幾個值得認識的詞，細節請點連結查看：[`first-match`][first-match]（只取第一個比對結果）和 [`re-split`][re-split]（在模式比對到的每個地方分割字串）。
