# 提示

## 一般

- 你需要定義[函式][functions]，並使用[算術運算子][arithmetics]。

## 1. 將預期的烘焙時間存入常數

- 定義一個 [const][const] 來儲存這個值。

## 2. 計算以分鐘為單位的準備時間

- 使用 [`times`算術運算子][arithmetics]將引數乘以 `2`。

## 3. 計算剩餘的烤箱時間（分鐘）

- 使用 [`minus`算術運算子][arithmetics]從 `60` 減去引數。

## 4. 計算總工作時間（分鐘）

- 重複使用第一步定義的 `preparation_time` 函式。
- 使用 [`plus`算術運算子][arithmetics]將 `preparation_time` 的回傳值加到引數上。

[functions]: https://docs.julialang.org/en/v1/manual/functions/
