# 學習 Batch

## 網站

- [官方 Batch 檔案說明文件](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-xp/bb490869(v=technet.10)?redirectedfrom=MSDN) 是瀏覽範例、認識這門語言的好地方。
- [SS64 指令說明文件](https://ss64.com/nt/) 大概是 Batch 指令最完整的說明文件，從基礎到進階的範例都找得到。
- [Rob van der Woude's Scripting Pages](https://www.robvanderwoude.com/) 是 Batch 腳本領域非常實用的資源，裡面有大量範例與解說；這個網站最有趣的地方，是它分享了一些真正獨特工具的程式碼，並用容易理解的方式把每個細節都解釋清楚。（這個網站一開始可能讓人有點摸不著頭緒，但很值得一看喔。）
- [DosTips 論壇](https://www.dostips.com/forum/) 是發問、尋求 Batch 腳本協助的好地方。
- [Batch-Man](https://batch-man.com/) 分享了許多實用的工具和腳本，解說方式也非常淺顯易懂；每個腳本都有部落格式的詳細說明、GitHub 儲存庫、大量範例，還有 YouTube 影片。

## 影片

- [John Hammond 的 Batch 教學](https://www.youtube.com/playlist?list=PL69BE3BF7D0BB69C4) 對初學者來說解說得很清楚。
- [Batch-Man](https://www.youtube.com/@batch-man/videos) 頻道也定期製作內容，示範各種技巧。
