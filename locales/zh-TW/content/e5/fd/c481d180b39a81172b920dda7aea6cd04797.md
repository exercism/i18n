# 說明

在這個練習中，你將為一款朋友正在開發的新 RPG 遊戲實作任務邏輯。遊戲的主角是 Annalyn，一個勇敢的女孩，身邊帶著一隻凶猛又忠誠的寵物狗。不幸的是，災難降臨了：她最好的朋友在森林裡尋找莓果時被綁架了。Annalyn 將試著找到並釋放她最好的朋友，在這趟旅程中，她可以選擇帶上她的狗。

在沿著好友的蹤跡追尋一段時間後，她找到了囚禁她好友的營地。原來綁匪有兩個：一位強大的騎士和一名狡猾的弓箭手。

找到綁匪後，Annalyn 思考她可以採取下列哪些行動：

- 快速攻擊：如果騎士正在睡覺，就可以發動快速攻擊，因為他需要時間穿上盔甲，所以會很脆弱。
- 刺探：只要他們之中至少有一個人醒著，就可以對這群人進行刺探。否則，刺探只是浪費時間。
- 向囚犯打暗號：如果囚犯醒著而弓箭手在睡覺，就可以用鳥叫聲向囚犯打暗號，因為弓箭手受過鳥鳴暗號的訓練，可能會攔截訊息。
- _釋放囚犯_：Annalyn 可以試著潛入營地來釋放囚犯。
  這是件冒險的事，只會在兩種情況下成功：
  - 如果 Annalyn 帶著她的寵物狗，她可以在弓箭手睡著時救出囚犯。
    騎士怕狗，而弓箭手在 Annalyn 和囚犯逃脫之前，來不及做好準備。
  - 如果 Annalyn 沒有帶狗，那麼她和囚犯就必須非常小心翼翼！
    Annalyn 可以在囚犯醒著、騎士和弓箭手都睡著時釋放囚犯；但如果囚犯在睡覺，就無法救出他：囚犯會被 Annalyn 突然出現嚇到，反而驚醒騎士和弓箭手。

你有四項任務：根據森林裡這三個角色的狀態，以及 Annalyn 的寵物狗是否在場，實作判斷上述行動是否可行的邏輯。

## 1. 檢查是否能發動快速攻擊

實作 `canFastAttack()` 方法，它接受一個布林值，表示騎士是否醒著。如果根據騎士的狀態可以發動快速攻擊，這個方法會回傳 `true`；否則回傳 `false`：

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. 檢查是否能刺探這群人

實作 `canSpy()` 方法，它接受三個布林值，分別表示騎士、弓箭手和囚犯是否醒著。如果根據這三個角色的狀態可以刺探這群人，這個方法會回傳 `true`；否則回傳 `false`：

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. 檢查是否能向囚犯打暗號

實作 `canSignalPrisoner()` 方法，它接受兩個布林值，分別表示弓箭手和囚犯是否醒著。如果根據這兩個角色的狀態可以向囚犯打暗號，這個方法會回傳 `true`；否則回傳 `false`：

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. 檢查是否能釋放囚犯

實作 `canFreePrisoner()` 方法，它接受四個布林值。前三個參數分別表示騎士、弓箭手和囚犯是否醒著，最後一個參數表示 Annalyn 的寵物狗是否在場。如果根據這三個角色的狀態以及 Annalyn 的寵物狗是否在場可以釋放囚犯，這個方法會回傳 `true`；否則回傳 `false`：

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
