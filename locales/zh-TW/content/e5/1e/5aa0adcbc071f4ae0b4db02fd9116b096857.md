# 指令補充

~~~~exercism/note

上面的說明提到了[_數學集合_][math-sets]，但也提到畢氏三元組 {a, b, c} _**必須**_ 按照 a < b < c 的順序排列（_遞增順序_）。

這使得 Python 的`set`型別不適合這個練習，因為它本質上是_無序_的。
你應該改為回傳一個由`list`組成的[`list`][python-list]（_例如 `[[a, b, c]]`_）。
你可以用任何你喜歡的順序產生這些三元組，因為外層`list`的順序在測試中會被忽略。

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
