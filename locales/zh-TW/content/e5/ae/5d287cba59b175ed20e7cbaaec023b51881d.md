# 簡介

## 一般語法

`for`迴圈是最常用來重複執行某段邏輯的敘述之一。在 Go 中，它由`for`關鍵字、標頭，以及一個用大括號包住迴圈主體的程式區塊組成。標頭則由 3 個以分號`;`分隔的部分組成：init、condition 和 post。

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init** 部分是一些只在迴圈開始前執行一次的程式碼。
- **condition** 部分必須是某個求值結果為布林值的運算式，用來控制迴圈何時該停止。
  只要這個條件的求值結果為 true，迴圈內的程式碼就會持續執行。
  一旦這個運算式的求值結果為 false，迴圈就不會再執行任何疊代。
- **post** 部分是一些會在每次疊代結束時執行的程式碼。

**注意：** 與其他語言不同，標頭的三個部分外面並沒有用小括號`()`包住。事實上，加上這樣的小括號會造成編譯錯誤。不過，包住迴圈主體的大括號`{ }`則一律不可省略。

## `for`迴圈：範例

init 部分通常會設定一個計數器變數，condition 部分則檢查迴圈應該繼續還是停止，而 post 部分通常會在每次重複結束時把計數器加一。

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

這個迴圈會印出從`1`到`9`的數字（包含`9`）。
