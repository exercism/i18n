# 提示

除非你對自己的正規表達式技巧非常有信心，否則在 [Regex101][regex101] 這類線上測試工具中釐清語法，可能會很有幫助。

記得把 flavor 設定為 PCRE2。

事先把每個正規表達式定義成`const`，是不錯的風格（能提升清晰度與效能）。

## 1. 檢查指令是否有效

- 字串開頭的錨點字元是`^`。
- 你只需要從正規表達式的搜尋結果取得 true/false 就好。
- 這題不用正規表達式也能解，但請盡量維持概念練習的精神。

## 2. 移除加密的表情符號

- 用一個簡單的 [`replace()`][replace] 就能解決喔。

## 3. 檢查電話號碼是否有效

- 需要一個比較長、但相當重複的正規表達式。
- 連續出現`n`次可以用`{n}`語法來指定。
- 我們只需要比對結果的 true/false。

## 4. 取得網站連結

- 記得用`\.`把點跳脫。
- 用 [match][match] 擷取點之前的部分。

## 5. 向使用者打招呼

- 帶有具名擷取的`replace()`格式是`r"(?<name>...) " => s"\g<name>... "`
- 同樣地，用`split()`也能完成任務，但練習一下正規表達式還是很有幫助。
