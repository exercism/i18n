# 測試

用以下指令執行測試：

```shell
npm run test
```

你也可以讓 Jest 以「watch」模式執行，這樣當你儲存程式碼或測試模組的變更時，測試就會自動重新執行：

```shell
npm run watch
```

## 了解略過的測試

skip 方法會指示測試套件不要執行某個測試，這個方法也可以透過下列別名使用：`it.skip(name, fn)`、`xit(name, fn)` 或 `xtest(name, fn)`

- 為什麼要略過它們？

讓使用者能一次專注在一個測試上，隨著解法逐步成形，再一個一個啟用。

- 如何啟用它們？

把 `xtest` 改成 `test`。

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
