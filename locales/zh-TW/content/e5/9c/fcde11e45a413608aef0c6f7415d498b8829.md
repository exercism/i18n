# 關於

在 Go 裡，函式是一級值。
這代表凡是能對其他值做的事，你都能對函式做：把函式指定給變數、把它們當作引數傳給其他函式，甚至從其他函式回傳函式。

下面我們建立兩個函式，`engGreeting` 和 `espGreeting`，並將它們指定給變數`greeting`：

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

函式值讓我們不只可以用資料來參數化函式，還可以用行為來參數化。
在下面的例子中，我們透過`greetingFunc`參數把行為傳給`dialog`函式：

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

未初始化的函式型別變數，其值是`nil`。
因此，呼叫值為`nil`的函式會引發 panic。

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

函式值可以和`nil`比較。
這有助於避免程式發生不必要的 panic。

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## 函式型別

函式值之所以可行，要歸功於 Go 的函式型別。
函式型別代表所有具有相同參數型別序列與相同結果型別序列的函式所形成的集合。
使用者自訂型別可以宣告在函式型別之上。
舉例來說，前面例子中的`dialog`函式可以改寫如下：

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## 匿名函式

多虧有一級函式的支援，我們還有一個強大的工具：匿名函式。
匿名函式在使用的地方就地定義，`func`關鍵字後面不接名稱。
這類函式可以存取外層函式中的變數。

例如：

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

呼叫`fib`會宣告變數`n1`和`n2`，並回傳一個匿名函式；這個匿名函式每次被呼叫時，都會改變這些變數的值。
匿名函式第 N 次被呼叫時，會回傳費氏數列從 0 開始的第 N 個數字。內部的匿名函式可以存取外層函式`fib`的區域變數（`n1`和`n2`）。
這是讓函式值在多次呼叫之間保有狀態的好方法。
我們說這個匿名函式是變數`n1`和`n2`的閉包。
[閉包][closure]在程式設計中被廣泛使用，你也可能看過其他語言支援它。

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
