# 介紹

## 類別

C# 中最主要的物件導向建構單位是_類別_，它是資料（_欄位_）與行為（_方法_）的組合。類別的欄位與方法合稱為它的_成員_。

成員的存取權限可以透過存取修飾詞來限制，最常見的兩種是：

- `public`：任何程式碼都能存取這個成員（沒有限制）。
- `private`：只有同一個類別內的程式碼可以存取這個成員。

你可以把類別想成建立該類別執行個體的範本。要建立類別的執行個體（也稱為_物件_），會使用 `new`關鍵字：

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

欄位有型別，而且可以定義在類別中的任何位置。
公開欄位以 PascalCase 命名，私有欄位則以 camelCase 命名，並在前面加上底線`_`：

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

你可以選擇性地為欄位指定初始值。如果欄位_沒有_指定初始值，它會被設為該型別的預設值。執行個體的欄位值可以用點記法存取和更新。

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

私有欄位通常會在呼叫方法時，作為副作用而被更新。這類方法通常不會回傳任何值，此時回傳型別應該是 `void`：

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
