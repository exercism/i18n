# 簡介

許多程式語言都有類似 `null` 或 `none` 的方式，用來表示不存在的值。由於 R 是為了處理大量（而且常常雜亂）的資料而設計，它有好幾種表示「什麼都沒有」的形式。

整體的目標是：在遇到缺失或可疑的值時把它們標記出來，然後繼續執行，而不會拋出例外。

## NULL

如果一個值真的不存在，就會用 `NULL` 來表示。這大概最接近 C 或 Python 的做法。

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

在許多情況下，`NULL` 值會被直接忽略：

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

如果某個值確實存在，但我們不知道它是什麼，就會使用 `NA`。舉例來說，在計算一條道路上往來的車輛時，人工觀測員可能會請病假，自動感測器也可能故障，但車流仍然持續不斷。

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

所以 `NA` 是一個佔位符，提醒人們必須決定該如何處理這個值。

## 空向量

或許令人意外的是，R 並沒有檢查空向量的標準方法，不過有些第三方套件會實作自己的函式，例如 `is.empty()`。

就連產生一個空向量都不是那麼直觀。我們在前面某個段落看過，不帶任何引數的 `c()` 會回傳 `NULL`，而不是向量。

```R
is.vector(c())
#> [1] FALSE
```

像 `logical()` 或 `integer()` 這類函式會接受一個指定所需長度的引數，而這個長度可以是零。

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

我們也可以先產生一個向量，再移除其中每個元素，如[向量概念][concept-vectors]所述。這樣會得到一個長度為 0、型別適當的向量。

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
