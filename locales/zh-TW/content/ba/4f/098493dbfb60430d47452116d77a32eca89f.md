# 簡介

在 Python 中，[`if`][if statement]、`elif`（_是 'else and if' 的縮寫_）和 `else` 敘述可以用來[控制程式的執行流程][control flow tools]，並讓程式做出判斷。
和許多其他程式語言不同，Python 3.9 及更早的版本並沒有提供正式的 case-switch 敘述，而是改用多個 `elif` 敘述來達到類似的效果。

Python 3.10 則導入了另一種 case-switch 敘述，稱為`pattern matching`，這部分會在其他概念中另外介紹。

條件敘述使用的運算式，必須得出`True`或`False`，無論是直接回傳`bool`，或是評估「truthy」或「falsy」的結果。


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

`if` 搭配一個非必要的 `else` 程式區塊時，會在原本的 `if` 條件評估為 `False` 時執行 `else` 區塊：

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` 則可以用來做多個判斷與分支。

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

把[布林運算][boolean operations]和[比較][comparisons]與條件敘述結合起來，就能進行更複雜的判斷：

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
