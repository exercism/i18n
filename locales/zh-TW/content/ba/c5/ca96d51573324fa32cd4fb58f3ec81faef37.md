# 簡介

## 格式化：基礎

Common Lisp 有一個稱為 The Printer 的概念，其中包含了所有用來撰寫 Lisp 資料文字表示法的函式。其中一個這樣的函式是 `format`，它讓程式設計師能依照自己的需求格式化資料。

`format` 以及廣義上 Lisp Printer 的能力是個很大的主題；這裡只會介紹 `format` 用法的基礎。

### FORMAT 函式

函式`format`至少接受兩個引數：要輸出到的串流，以及定義要輸出什麼、如何輸出的控制字串。

串流本身是個獨立的概念，會在別處介紹。但目前你只需要知道，輸出是寫入串流，而這個引數有兩個特殊值：`t`和`nil`。`t`表示輸出到標準輸出（實際上是變數`*standard-output*`所綁定的串流），而`nil`表示建立一個字串並回傳它。

請注意，`format`一律會求值為`nil`，只有在後者、也就是把`nil`指定為串流的情況下例外。這是進行單純字串內插或字串建構的常見做法。

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

### 格式指示詞

控制字串可以包含「格式指示詞」，用來指示`format`要輸出什麼，以及如何解讀傳給`format`的其他參數。某種程度上，控制字串就是一支程式，`format`會解讀並執行它。所有指示詞都以`~`開頭，後面接著一個字元（_例如_`~A`、`~D`、`~&`）。字元的大小寫沒有差別。

大多數格式指示詞只是把傳給`format`的引數內插到輸出中。這稱為「消耗」該引數。有些指示詞不會消耗引數，有些則消耗超過一個。甚至有一個指示詞能讓你在引數列表中跳來跳去，或略過某些引數。

### 基本格式化

一個用途非常廣泛的格式指示詞是`~A`。它會輸出資料的「人類可讀」版本。

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

另一個實用的格式指示詞是`~S`。它會輸出資料的「機器可讀」版本。如果你想讓產生的輸出能被當作 Lisp 資料解讀，這會非常有用。對許多東西而言，它的結果看起來和`~A`一樣，但要注意，以字串為例，輸出會包含引號（被包含在另一個字串中時會加上跳脫），這樣這個值之後就能被讀回成字串參數。

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

另外兩個非常實用的指示詞是`~%`和`~&`。前者輸出一個換行字元，後者則輸出一個「新行」。差別在於`~%`一律輸出換行，而`~&`只有在目前不在行首時才會輸出一個換行。這兩者都不會消耗引數。

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

最後，`~~`是一個簡單的指示詞，會輸出一個字面上的`~`。
