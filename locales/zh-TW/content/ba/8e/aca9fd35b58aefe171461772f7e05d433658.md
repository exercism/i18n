# 執行測試

要執行某個練習的測試，請`cd`到該資料夾，然後執行下列指令：

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

這些測試使用一個叫做 TestBox 的函式庫，它支援 xUnit 與 BDD 兩種測試風格。所有測試套件都會以[BDD 風格](https://testbox.ortusbooks.com/content/primers/bdd/specs.html)撰寫，用閉包來定義測試規格。你不需要擔心安裝 TestBox 的問題，CLI 測試執行器會幫你處理好。你只要在第一次執行它的時候有網路連線就好。你可以在這裡了解更多：

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
