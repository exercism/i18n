# 提示

## 1. 為員工印出識別證

- 可以使用[字串插值][string-interpolation]來簡潔地格式化識別證。
- 有一個[內建方法可以將字串轉換成大寫][toupper]。

## 2. 為新進員工印出識別證

- 使用 ID 之前，你應該先檢查它是不是`null`。
- [這個教學會詳細說明如何使用可為 null 的實值型別][nullable-types-tutorial]。

## 3. 為擁有者印出識別證

- 使用部門之前，你應該先檢查它是不是`null`。
- [這個教學會詳細說明如何使用可為 null 的參考型別][nullable-reference-types-tutorial]。
- 可以使用 [null 條件運算子][null-conditional-operator]來簡化在可為 null 的值上呼叫成員。
- 在可為 null 的值是`null`時，可以使用 [null 聯合運算子][null-coalescing-operator]來簡化回傳另一個值。
