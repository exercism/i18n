# 指令

你正在為學校的戲劇演出呼叫提示。舞台監督希望把標準台詞寫下來，這樣任何人都可以操作控制台。

你有四項任務，全都在`STAGE_DIRECTIONS`類別中。

## 1. 宣布開始

回傳開場的台詞。

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. 宣布中場休息

回傳中場休息時說出的台詞。

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. 宣布結束

回傳閉幕的台詞。

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. 呼叫最後的提示

最後的提示和閉幕的台詞相同。與其再寫一次文字，不如呼叫你已經寫好的函式。

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
