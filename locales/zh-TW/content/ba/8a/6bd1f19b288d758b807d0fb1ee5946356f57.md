# 安裝

Exercism 讓你可以直接在瀏覽器裡寫程式和測試你的 ABAP 程式碼。不需要額外安裝。不過，如果你比較想在自己的系統上寫程式和測試，可以取得一套 ABAP 試用系統。

當然，你的雇主可能正在使用 SAP。請向你的資訊部門確認你能否取得 ABAP 開發沙箱，以及該如何取得。

## 該選擇哪個版本？

我們鼓勵使用目前仍在支援中的 ABAP 平台版本。目前是**ABAP 7.5 以上**。關於目前各版本的詳細資訊與時程，請參閱 [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise)。

## 要安裝什麼？

我們建議使用最新的 [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial)。它是以 ABAP 7.58 為基礎。你可以將 SAP ABAP 系統安裝成 Docker 映像檔，或安裝在 SAP Cloud Appliance Library 代管的環境中。此外，你需要依你的本機作業系統，安裝 Windows 版或 Java 版的 SAP GUI。你可以從[這裡](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui)下載 SAP GUI。

如需更多詳細資訊，請參閱這篇 [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183) 部落格文章。
