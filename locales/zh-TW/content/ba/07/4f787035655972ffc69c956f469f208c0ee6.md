# 簡介

回想一下，`jq` 程式是_由運算式串成的管線_。
**變數賦值**遵循這個規則：_變數賦值_是一種長得像這樣的運算式：

```jq
... | expr as $varname | ...
```

## 篩選器輸出的是輸入

就像_恆等運算式_`.`一樣，_變數賦值_的輸出和它的輸入相同。設定變數的值則是一種副作用。

這個範例顯示，賦值之後的 `.` 和最初的輸入相同：

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## 變數的作用域

變數的作用域是「詞法」的，也就是說，變數在管線剩下的部分都在作用域內。定義在函式裡的變數（我們之後會談到函式）是該函式的「區域」變數。

## 變數名稱

變數必須以`$`開頭。變數名稱的其餘部分是**識別字**：以字母或底線開頭，後面接著字母、數字或底線。

## 解構賦值

手冊上寫道：

> 只要提供一個_符合輸入結構_的模式，就可以用單一個 `as` 運算式宣告多個變數（這稱為「解構」）。

範例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

讓變數名稱和_物件鍵_相符可以提供一個捷徑：

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## 常數

如上面的範例所示，變數很方便用來儲存常數。與其讓「魔術數字」出現在程式碼裡，不如給常數取個名字。

## 通常不需要變數

省略變數往往能讓程式更好讀。

想想看計算一個數字陣列平均值的做法：

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

相較於

```jq
[2, 4, 8, 7] | add / length
```

這凸顯了 `jq` 最強大的特點之一：篩選器的輸入會提供給_每一個_子運算式：

- 輸入陣列`[2,4,8,7]`會傳給`add`（它會把`+`運算子套用到所有元素上，藉此將數字加總）
- _同時_，`[2,4,8,7]`也會傳給`length`
- 這些子運算式完成後，它們的結果會被相除，回傳輸入陣列中這些數字的平均值。

## 學習練習會用到的 `jq` 運算子

### 替代運算子：`//`

運算式`a // b`在`a`為 false 或 null 時輸出`b`，否則輸出`a`。在設定變數的情境下，這非常方便用來提供預設值：

```jq
(.input.theAnswer // 42) as $answer | ...
```

### 算術運算子

- `+`、`-`、`*`是一般數字的加法、減法和乘法運算子。
