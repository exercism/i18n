# 提示

## 1. 建立新的陣列

- Common Lisp 有一個[名稱相當貼切的函式][hyper-list]，可以用來建立 _LIST_。

## 2. 把東西加入陣列

- 要把某個東西加到陣列的最前面，慣用的做法是用 *CONS* 建構出一個新的陣列，把該元素當作`car`，把原來的陣列當作`cdr`。在 Hyperspec 裡可以找到一個[頁面][hyper-cons]，說明這個函式。

## 3. 陣列上的下一個（些）元素是什麼？

- Common Lisp 有個通用函式可以[從陣列中的任何索引][hyper-nth]取得元素。
- 它也有[幾個輔助函式][hyper-first-tenth]，可以用來存取索引值小於 11 的元素。
- 陣列的索引從 0 開始。

## 4. 從陣列移除元素

- 要移除陣列中的第一個元素，慣用的做法是用一個能把`cdr`和`car`分開的函式。在 Hyperspec 裡可以找到一個[頁面][hyper-rest]，說明其中一個能做到這件事的函式。

## 5. 用較小的陣列組成更大的陣列

- Common Lisp 有一個[專門把一個陣列加到另一個陣列前面的函式][hyper-append]。

## 6. 還有多長？

- Common Lisp 有一個[名稱顯而易見][hyper-length]的函式，可以取得陣列的長度。
