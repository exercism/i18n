# 提示

## 1. `assign-bibs`

- 使用`map-index`。這個引號的堆疊頂端是`index`，下面則是`name`。要產生`{ position name }`配對，在呼叫`2array`之前，你得先把它們的順序對調過來。

## 2. `lane-labels`

- 使用`map-index`。
- `sprintf`會由下往上讀取它的引數：最左邊的`%`佔位符對應最底下的引數，最右邊的則對應最上面的。
- 在`"Lane %d: %s"`裡，你會希望`index`（數字）餵給`%d`，`name`（字串）餵給`%s`。請據此在引號內重新排列堆疊的順序。

## 3. `tag-racers`

- `tag`引數必須讓每一次逐元素的呼叫都能取得。`curry`（或`fry`）可以把它先綁進去。
- 在引號內，你會有 3 個值要餵給`sprintf`：標籤、索引和名稱。`spin`會反轉堆疊最上面的 3 個值，這正是你要的做法。

## 4. `record-finishes`

- 帳本必須讓每一次逐元素的呼叫都能取得。`fry`（`'[ … _ … ]`）是最自然的做法：其中的`_`會變成帳本。
- 用`sprintf`組出每位選手的字串，再把它`push`到帳本上。
- `each-index`不會回傳任何值；結果就是它所造成的變更。

## 5. `lap-bells`

- `times`是`inline`，所以它的引號可以具有非`( -- )`的效果。用一個效果為`( str -- str )`的引號，在每次疊代之間傳遞不斷累積的字串。
- 一開始先在堆疊上放一個空字串`""`。
