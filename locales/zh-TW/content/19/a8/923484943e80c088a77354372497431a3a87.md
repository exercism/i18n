# 介紹

## 位元陣列

處理二進位資料可能不太容易，所以 Gleam 提供了 `BitArray` 型別以及搭配的語法，讓你能建構二進位資料，也能對它進行模式匹配。

位元陣列的字面值是用 `<<>>` 語法定義的。定義位元陣列字面值時，它是由一個個區段組成。每個區段都有一個值和一個標註，兩者以 `:` 分隔。標註用來指定編碼這個值會用到多少位元，也可以整個省略，此時預設為 8 位元的整數值。

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

把型別指定為 `:1` 是 `:size(1)` 的簡寫。如果位元大小來自變數，就得使用較長的語法。

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### 二進位

撰寫二進位整數字面值時，我們可以直接用二進位表示法來寫，只要在字面值前面加上 `0b` 就好。請注意，它們在測試或你的程式中被印出時，會以十進位數字顯示。

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### 截斷

如果區段的值超出該區段型別的容量，就會從左邊被截斷。

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### 在前端與尾端加入

你可以用位元陣列語法，在現有的位元陣列前端或尾端加入資料。針對現有的位元陣列，必須使用 `:bits` 標註。

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### 串接

我們可以用位元陣列語法，串接存在變數裡的位元陣列。串接兩個大小不定的位元陣列時，必須使用 `:bits` 標註。

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### 模式匹配

也可以透過模式匹配，從位元陣列中取出值。你必須知道每個想捕捉的區段有多少位元，只有一個例外：`:bits` 標註可以用來對大小未知的位元陣列進行模式匹配，但它只能用在最後一個區段。

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### 檢視位元陣列

~~~~exercism/note
位元陣列印出來的格式，可能和建立它們時所用的格式不同。這是學習位元陣列時經常讓人困惑的地方。
~~~~

預設情況下，位元陣列會以 8 位元（一個位元組）為區段來顯示，即使你建立時用的是不同大小的區段也一樣。

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

如果你建立的位元陣列代表的是一個可列印的 UTF-8 編碼字串，有些函式（例如 `io.debug`）可能會把它顯示成字串。這是因為 Gleam 內部表示字串的方式有這麼一個實作細節。

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
