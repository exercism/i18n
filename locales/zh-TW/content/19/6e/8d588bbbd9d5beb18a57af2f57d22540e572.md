# 指令補充

## 暫存器

| 暫存器   | 用途     | 型別 | 說明                         |
| -------- | -------- | ---- | ---------------------------- |
| `$a0`    | 輸入     | 位址 | 第一個字串，以 null 結尾     |
| `$a1`    | 輸入     | 位址 | 第二個字串，以 null 結尾     |
| `$v0`    | 輸出     | 整數 | 漢明距離                     |
| `$t0-9`  | 暫存     | 任意 | 用於暫存                     |
