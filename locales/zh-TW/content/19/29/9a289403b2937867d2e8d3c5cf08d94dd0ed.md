# 簡介

[Zen of Python][zen-of-python] 主張「在 Python 裡，做一件事應該有一種*顯而易見*的方法」。

對 Python 3.6 以上版本來說，[**字面字串插值**][string-interpolation]（[**`f-string`**][f-string]）通常就是顯而易見且首選的字串格式化方式：

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

然而，考量到 Python 悠久的歷史與各種不同的使用情境，Python 還有**另外三種**常見的字串格式化方式，這應該不會太令人意外：

1. [`str.format()`][str-format] 用途廣泛、功能強大，而且同時相容於 [`gnu gettext`][gettext] 和大多數版本的 Python。
2. 如果你需要的是簡單、安全，和/或大量的國際化，可以使用 [`string.Template()`][string-template] 來降低處理輸入時的風險，也適合用來包裝翻譯字串。
3. `%` 運算子在新程式碼中通常被視為已淘汰，不過它在現代 Python 中仍然可用。
  它主要應該用於與較舊的程式碼庫相容。
  `%` 格式化在顯示非 ASCII 和 Unicode 字元時可能會有問題，而且比其他方法更容易出錯、功能也更少。
  如果你打算使用它，請查閱你所使用的 Python 發行版，以了解支援細節。

如果你想更進一步，[格式化全解析][all-about-formatting] 和 [Python 字串格式化的最佳實務][formatting-best-practices] 都是不錯的起點。
