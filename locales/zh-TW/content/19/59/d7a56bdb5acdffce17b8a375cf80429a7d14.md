# 簡介

只要某個欄位的值在編譯期就知道，而且在程式執行期間不會改變，就可以（通常也應該）套用`const`修飾詞。

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

只要某個欄位無法宣告為`const`，而它的值在程式執行期間不會改變，並且是在宣告時透過內嵌初始設定式設定，或是在具現化時（由建構函式，或由建構函式所呼叫的方法）設定，就可以（通常也應該）套用`readonly`修飾詞。

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
