# 關於

在 Swift 中，`String`是有序的`Character`值集合，用來表示人類可讀的文字。Swift 字串完整支援 Unicode 字元和表情符號。

你可以用字串字面值建立字串，只要把文字包在雙引號（`"`）裡。特殊字元會使用跳脫序列，例如`\n`代表換行字元，而`\"`則代表字串字面值裡跳脫過的雙引號。

空字串寫成中間沒有任何內容的一對雙引號（`""`）。

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
