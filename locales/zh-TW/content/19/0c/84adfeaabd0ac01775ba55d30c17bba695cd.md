# 說明補充

## 暫存器

| 暫存器 | 用途     | 型別    | 說明                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 輸入     | 位址 | 陣列一的元素                                         |
| `$a1`    | 輸入     | 整數 | 陣列一的大小，以字組為單位                                |
| `$a2`    | 輸入     | 位址 | 陣列二的元素                                         |
| `$a3`    | 輸入     | 整數 | 陣列二的大小，以字組為單位                                |
| `$v0`    | 輸出    | 整數 | `0` = equal、`1` = unequal、`2` = sublist、`3` = superlist |
| `$t0-9`  | 暫存 | 任意     | 用於暫存資料                                 |
