# 說明

在這道練習中，你會處理日誌行。

每一行日誌都是一個格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

一共有三種不同的日誌等級：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會取用一行日誌，並要求你對它做點處理。
解決這些任務的方法有很多種，你可以從上面的範例中挑選自己喜歡的幾種，然後看看能想出什麼吧！

## 1. 從日誌行取得訊息

實作 `LogLineParser#message` 方法，回傳日誌行的訊息：

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

開頭或結尾的空白都應該被移除：

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. 從日誌行取得日誌等級

實作 `LogLineParser#log_level` 方法，回傳日誌行的日誌等級，而且要以小寫回傳：

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. 重新格式化日誌行

實作 `LogLineParser#reformat` 方法，重新格式化日誌行，把訊息放在前面，並將日誌等級接在後面、用括號括起來：

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
