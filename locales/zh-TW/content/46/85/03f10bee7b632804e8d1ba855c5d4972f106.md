# 說明

你負責維護一座小島渡輪的航行時刻表。航班以日期記錄，而你需要幾個小工具來處理這些日期。

## 1. 記錄航行日期

定義`make-date`，接收年、月、日，回傳對應的時間戳記。

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. 為星期命名

定義`weekday-name`，接收某次航班的時間戳記，回傳它落在星期幾的名稱。

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. 閏年

定義`leap?`，接收一個年份，回傳它是否為閏年。

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. 一個月有幾天

定義`month-length`，接收年和月，回傳該月的天數（別忘了二月）。

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. 幾天之後

定義`add-days`，接收一個時間戳記和天數，回傳那麼多天之後的時間戳記。

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
