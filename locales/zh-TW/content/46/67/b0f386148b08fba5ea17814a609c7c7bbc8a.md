# 說明補充

## 暫存器

| 暫存器 | 用途 | 型別 | 說明 |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 輸入     | 整數 | 類別：`0` = choice，`1` = ones，`2` = twos，`3` = threes，`4` = fours，`5` = fives，`6` = sixes，`7` = little_straight，`8` = big_straight，`9` = full_house，`10` = four_of_a_kind，`11` = yacht |
| `$a2`    | 輸入     | 位址 | 骰子（字組陣列）                                          |
| `$v0`    | 輸出     | 整數 | 最終分數                                            |
| `$t0-9`  | 暫存 | 任意     | 用於暫存資料                                 |
