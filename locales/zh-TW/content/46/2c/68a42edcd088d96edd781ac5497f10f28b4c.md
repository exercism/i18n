# 指令

在這個練習中，你會幫助高中情侶在社群媒體上公開示愛，用他們的縮寫產生一個 ASCII 愛心：

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 取得名字的第一個字母

實作`first_letter`函式。它應該接收一個名字並回傳它的第一個字母。它應該清除名字中任何多餘的空白。

```gleam
first_letter("Jane")
// -> "J"
```

## 2. 將第一個字母格式化為縮寫

實作`initial`函式。它應該接收一個名字，回傳大寫的第一個字母，後面接著一個點。記得重複使用你在前一步定義的`first_letter`。

```gleam
initial("Robert")
// -> "R."
```

## 3. 將全名拆分成名字與姓氏

實作`initials`函式。它應該接收一個全名，全名由以空格分隔的名字和姓氏組成，並回傳縮寫。記得重複使用你在前一步定義的`initial`。

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. 將縮寫放進愛心裡

實作`pair`函式。它應該接收兩個全名，並回傳放在 ASCII 愛心內的縮寫。記得重複使用你在前一步定義的`initials`。

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
