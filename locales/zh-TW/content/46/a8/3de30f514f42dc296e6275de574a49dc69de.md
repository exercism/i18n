# Cairo 中的模組與路徑

Cairo 使用**模組**來組織程式碼。

模組有助於組織專案結構，並控制函式、struct 和 trait 這類項目的可見性。

## 定義模組

模組使用`mod`定義，而且可以巢狀：

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

函式、struct 和 trait **預設都是私有的**。

使用`pub`讓它們能在所屬模組之外被存取。

## 路徑：絕對路徑與相對路徑

若要參照另一個模組中的項目，可以使用：

- **絕對路徑**（從`crate::`開始）：

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **相對路徑**（從目前模組開始）：

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  如果`front_of_house`就在同一個模組裡，這樣寫就沒問題。

## 使用`use`將模組帶入作用域

一再寫出完整路徑很麻煩。

`use`關鍵字可以讓你用更簡短的方式參照：

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use`**只在它出現的作用域內**生效；如果其他地方也需要，就必須重複撰寫。

### `use`的慣用寫法

- 把**模組**帶入作用域，而不是函式：

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  而不是這樣寫：

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- **trait、struct 和 enum**則使用完整路徑：

  ```rust
  use core::num::traits::BitSize;
  ```

### 使用`as`設定別名

必要時可以重新命名匯入的項目：

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### 匯入多個項目

與其寫多個`use`敘述，不如把匯入的項目群組起來：

```rust
use shapes::{Square, Circle, Triangle};
```

## 使用`pub use`重新匯出

若想以不同的結構公開某個模組，可以使用`pub use`：

```rust
pub use crate::front_of_house::hosting;
```

現在外部的程式碼可以使用`restaurant::hosting::add_to_waitlist()`，而不必寫成`restaurant::front_of_house::hosting::add_to_waitlist()`。

## 透過 Scarb 使用外部套件

要新增相依性，請更新`Scarb.toml`：

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

使用`scarb add <package>`新增相依性，並使用`scarb rm <package>`移除相依性。

## 萬用字元運算子（`*`）

若要從模組匯入所有項目：

```rust
use core::num::traits::*;
```

使用時要小心，因為這可能會讓程式碼更難閱讀。
