# 簡介

Python 中的字典（`dict`）是一種資料結構，會將[可雜湊的][term-hashable]_鍵_對應到_值_，在其他程式語言中稱為可調整大小的[雜湊表][hashtable-wikipedia]、hashmap 或[關聯陣列][associative-array]。字典是 Python 唯一內建的[對應型別][mapping-types-dict]。


`Keys`在字典中必須是可雜湊且唯一的。鍵的型別可以是`numbers`、`str`或`tuples`（由_不可變_的值組成）。它們不能包含_可變_的資料結構，例如`lists`、`dict`或`set`。從 Python 3.7 開始，`dict`的鍵順序保證與項目插入的順序一致。

`values`可以是任何資料型態或結構。
值也可以_任意_巢狀，因此可以包含陣列的陣列、子字典，以及其他自訂或複合的資料結構。

給定一個`key`，字典可以（平均而言）在常數時間內取回`value`（_與項目數量無關_）。
相較於在`list`或`array`中搜尋一個值（_在不知道`index`位置的情況下_），`dict`會使用明顯更多的記憶體，但取用速度非常快。
當項目集合很大，且必須頻繁存取和更新時，字典特別有用。


## 建立字典

字典可以用許多方式建立。
最直接的兩種是使用`dict()`建構子，或宣告`dict`_實字_。

### `dict()`類別建構子

`dict()`（_字典類別的建構子_）可以搭配任何由`key`、`value`配對組成的可迭代物件，或搭配一連串`<name>=<value>`_引數_使用：

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### 字典實字

`dict`也可以直接用_字典實字_輸入，使用大括號（`{}`）包住`key : value`配對：

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## 存取字典中的值

你可以使用放在方括號（`[]`）中的_鍵_來存取字典中的項目。如果`key`不存在於`dict`中，就會擲回`KeyError`：

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

透過`.get(<key>, <default value>)`方法存取項目可以避免`KeyError`：

```python
>>> bear.get("color", 'not found')
'not found'
```

## 變更或新增字典的值

你可以透過指定其_鍵_來變更項目的`value`：

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

新的`key`:`value`配對可以用同樣的方式_新增_：

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## 移除（pop）字典項目

你可以使用`.pop(<key>)`方法刪除字典項目。`.pop()`會移除（`key`、`value`）配對並回傳`value`供使用。和`.get()`一樣，`.pop(<key>)`接受第二個引數（_`dict.pop(<key>, <default value>)`_），如果找不到該`key`就會回傳它。這可以避免引發`KeyError`：

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## 對字典進行迴圈／疊代

使用`for item in dict`或`while item`對字典進行迴圈時，預設只會疊代_鍵_。你可以在同一個迴圈中使用_方括號_存取_值_：

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

你也可以使用`.items()`方法，它會自動回傳（`key`、`value`）元組：

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

同樣地，`.keys()`方法會回傳`keys`，而`.values()`方法會回傳`values`。
