# 指令

社區藝術中心的馬賽克拼貼上個月才剛安裝完成，現在 Magpie Marg 發現了它。大多數的日子裡，她會從附近的**收藏**裡拿更閃亮的磁磚來換掉一兩塊，或者拔走一塊磁磚，然後消失一個小時。

你是負責記錄每一項變動的志工。馬賽克本身是一個**固定大小的陣列**，每個磁磚位置各有一個格位，裡面存放顏色字串，或是代表「缺失」的`f`。Magpie Marg 的收藏則是一個**vector**，裡面是她偷來的零散磁磚。

## 1. 排出新的一列

定義`fresh-mosaic`，它接收一個長度`n`，並回傳一個包含`n`個空的格位（每個都是`f`）的陣列。

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. 放置一塊磁磚

定義`place-tile`，它接收一個列、一個位置和一個顏色，並就地更新該列，讓指定的位置存放這個顏色。這個詞不會回傳任何值。

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. 挖下一塊磁磚

定義`chip-tile`，它接收一個列和一個位置，並就地更新該列，讓指定的位置再次變成`f`。

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. 為磁磚重新上色

定義`recolour-tile`，它接收一個列、一個位置和一個單一引數的 quotation，並把這個 quotation 套用到該位置的磁磚上，就地更新該列。

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. 在 Marg 抵達前先快照

定義`snapshot-mosaic`，它接收一個列，並回傳一份獨立的副本，之後對原始列的更動都不會影響到它。

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg 把磁磚收進口袋

定義`stash-tile`，它接收 Marg 的收藏（一個**vector**）和一個顏色，並把這個顏色附加到收藏裡。不回傳任何值。

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg 歸還一塊磁磚

定義`return-tile`，它接收 Marg 的收藏，移除並回傳最近收進去的磁磚（也就是最上面的那一塊）。

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
