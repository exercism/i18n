# 關於

Swift 是一門編譯式的多範式程式語言，設計時以三個主要目標為核心：

- **安全**：內建的語言特性有助於在程式碼於正式環境執行前，就先捕捉並預防 bug。
- **速度**：經過最佳化的效能，可與 C 系列語言相比。
- **表達力**：簡潔、現代的語法，讀寫起來都輕鬆愉快。

Apple 在 2014 年推出 Swift，作為 Objective-C 的現代替代方案，後者是當時 iOS 與 macOS 開發所用的語言。
時至今日，Swift 已是開放原始碼專案，可在 Apple 平台、Linux 和 Windows 上執行。

## 開始入門

### 變數

你可以定義一個[變數][constants-variables]，藉此儲存值並賦予它名稱。
定義變數之後，你就能在整個程式碼中用它的名稱來取用該值。
變數是可變的，這表示它們的值在定義之後還能改變。

用 `var` 關鍵字定義變數：

```swift
var variableName = 10
```

Swift 是靜態型別的語言，這表示每個值在編譯時期都已經有已知的型別。
你可以用[型別標註][type annotations]明確宣告型別，也可以讓 Swift 編譯器從指定的值[推斷型別][type-inferring]：

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

你可以用賦值運算子（`=`）更新變數的值：

~~~~exercism/note
變數的型別在宣告之後就無法改變。

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

你可以只指定型別來宣告一個沒有初始值的變數，但在使用它之前必須先指定值：

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### 常數

[常數][constants-variables]同樣是把名稱和值關聯起來，但它的值在賦值之後就無法改變。
它們是不可變的。
用 `let` 關鍵字定義常數：

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### 算術運算子

Swift 提供標準的[算術運算子][arithmetical-operators]來做基本數學運算：

- 加法：`+`
- 減法：`-`
- 乘法：`*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### 函式

在 Swift 中，[函式][functions]是獨立、自成一體的程式碼區塊，用來執行特定工作。
函式可以接受輸入、回傳值，也可以像值一樣傳遞給其他函式。
用 `func` 關鍵字定義函式，後面接著函式名稱、一組以括號包住的參數列表，以及選用的回傳型別：

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift 函式採用[引數標籤][argument-labels]，讓程式碼讀起來像自然的句子：

- **引數標籤**是在呼叫函式時使用的。
- **參數名稱**則是在函式主體內部用來取用該值的。

如果你只寫一個名稱，Swift 會同時把它當作引數標籤和參數名稱：

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

如果你在呼叫函式時不想使用引數標籤，就在參數名稱前面寫一個底線（`_`）：

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

所有函式參數預設都是常數（`let`），這表示它們的值無法在函式主體內修改。

若要從函式回傳值，就在 `->` 後面指定回傳型別，並使用 `return` 關鍵字：

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

當函式不回傳值時，它的回傳型別是 `Void`（等同於空元組 `()`）。
在這種函式中，`-> Void` 回傳型別和 `return` 敘述都可以省略。

### 註解

Swift 支援兩種形式的[註解][comments]：

- **單行註解**以 `//` 開頭，延伸到該行結尾。
- **多行註解**則包在 `/*` 和 `*/` 之間。

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
