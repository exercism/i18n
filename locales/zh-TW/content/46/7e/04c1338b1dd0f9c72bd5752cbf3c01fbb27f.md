# 簡介

## 關鍵字陣列

關鍵字陣列是鍵值資料結構。

```elixir
[month: "April", year: 2018]
```

關鍵字陣列是由`{key, value}`[元組][exercism-tuples]組成的陣列，也可以寫成那樣，但較短的語法更常被使用。

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

關鍵字陣列中的鍵必須是[原子][exercism-atoms]，但值可以是任何東西。每個鍵可以使用多次。關鍵字陣列中的鍵值對是有序的。

你可以用處理陣列的相同方式來處理關鍵字陣列，或者使用`Keyword`模組。

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
