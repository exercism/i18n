# 簡介

Kotlin 中的[`string`][ref-string]是不可變的 Unicode 字元序列。

[`Immutable`][wiki-immutable]是指對字串的任何操作都必須回傳一個新的字串：原始字串永遠不會改變。

[`Unicode`][wiki-unicode]是指世界上大多數的書寫系統都能表示出來，但（和 C 這類較舊的語言不同）字元和位元組之間並沒有 1:1 的對應關係。

字串前後以雙引號`" "`包住。

有些字元需要跳脫：`\\`，以及一些常見的非列印字元，例如`\t`（定位字元）和`\n`（換行）。

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

多行字串則以 3 個雙引號包住，並可以包含任意文字（不需要跳脫）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

用 [trimIndent][trimIndent-doc] 移除各行共同的縮排。這在格式化字串時很方便：

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

或者，也可以改用 [trimMargin][trimMargin-doc] 來指定分隔符號。這樣一來，`String`中的每一行就會從分隔符號之後開始。分隔符號預設為`|`，但你也可以把它當成參數，指定不同的分隔符號。例如：

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

字串可以用`+`串接，但最好只用在簡短單純的情況。還有其他做法，而且往往更好。

## 字串範本

這指的是其他語言所稱的「插值」。

如果字串中包含錢字號`$`後面接著識別字，或是包含以大括號（`{expression}`）包住某個運算式，這些都會分別被替換成對應的值或運算式的結果。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

當剖析結果可能產生歧義時，就必須用大括號`{ }`把運算式包起來。

一般來說，比起用`+`組合字串，使用字串範本更有效率，也更道地。

## 字串函式

Kotlin 提供了*許多*[`functions`][ref-string-functions]來操作字串。

這些大多是[`extensions functions`][ref-extensions]，而不是`String`類別的成員，不過這對我們使用它們的方式影響不大。

~~~~exercism/note
Kotlin 相當複雜的[說明文件][ref-string-functions]頁面，在預設檢視下會把擴充函式藏起來。記得點一下`Members & Extensions`來展開這個區塊。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

以下範例只示範了其中一小部分可用的函式：

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
