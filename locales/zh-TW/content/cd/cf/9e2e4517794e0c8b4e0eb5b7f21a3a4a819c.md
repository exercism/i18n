# 簡介

Gleam 的正規表達式遵循 **PCRE** 規範（**P**erl **C**ompatible **R**egular **E**xpressions，也就是與 Perl 相容的正規表達式），和其他熱門語言如 Java、JavaScript 或 Ruby 類似。

`gleam/regex`模組提供處理正規表達式用的函式。

~~~~exercism/note
這個練習假設你已經知道正規表達式的語法，包括字元類別、量詞、群組和擷取。

如果你需要複習正規表達式的相關知識，可以參考下列資源：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

建立正規表達式最常見的方式，是使用 `regex.from_string` 函式。

```gleam
let assert Ok(re) = regex.from_string("test")
```

如果正規表達式的語法無效，`regex.from_string` 函式會產生 `Error`，所以這裡使用了 let 斷言，確保正規表達式是有效的。

`regex.check` 函式可以用來檢查正規表達式是否符合某個字串。

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## 擷取

如果你想用正規表達式擷取子字串，可以使用 `regex.scan` 函式來回傳符合結果的陣列。

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## 修飾符

只要改用 `regex.compile` 函式建立正規表達式，並傳入選項，就能改變它的行為。

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
