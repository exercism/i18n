# 說明

我們每個人都會從親生父母身上繼承一套稱為 DNA 的化學指令，這些指令影響著我們身體的構造。所有已知的生命都依賴 DNA！

> 注意：你不需要了解任何關於核苷酸或 DNA 的知識，就能完成這個練習。

DNA 是由其他化學物質組成的長鏈，其中最重要的是四種核苷酸：腺嘌呤、胞嘧啶、鳥嘌呤和胸腺嘧啶。單一條 DNA 鏈可以包含數十億個這四種核苷酸，而它們出現的順序非常重要！
我們把一小段 DNA 裡這些核苷酸的順序稱為「DNA 序列」。

我們把 DNA 序列表示成這四種核苷酸的有序集合，常見的做法是用一串字元來表示，例如用 "ATTACG" 代表由 6 個核苷酸組成的 DNA 序列。
其中 'A' 代表腺嘌呤、'C' 代表胞嘧啶、'G' 代表鳥嘌呤，'T' 代表胸腺嘧啶。

給定一個代表 DNA 序列的字串，請計算每種核苷酸各出現多少次。
如果字串中含有不是 A、C、G 或 T 的字元，那它就是無效的，你應該發出錯誤。

例如：

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
