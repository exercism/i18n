# 提示

## 1. 使用正規表達式擷取產生卡片所需的資訊

- `\p{L}`會符合任何語言的任何字母。
- 你可以使用以下運算式來擷取這些資訊：
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
