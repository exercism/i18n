# 關於

C# 中的`DateTime`是不可變的物件，同時包含日期_與_時間的資訊。日期與時間資訊可以透過它內建的[屬性][properties]取得。

要操作`DateTime`，可以呼叫它的其中一個[方法][methods]。由於`DateTime`值一旦定義就永遠不會改變，所有看似會修改`DateTime`的方法，實際上都會回傳一個新的`DateTime`。

比較`DateTime`實例時，可以使用預設的比較運算子（`<`、`>`等）。目前的日期（以及時間）可以透過`DateTime.Now`屬性取得。

C# 中日期有一個很重要的特性：它們會因文化而異。因此，任何處理`string`的`DateTime`方法都會取決於目前的文化。這包括將`string`解析成`DateTime`的[`DateTime.Parse()`方法][parse]，以及`DateTime`類別中將`DateTime`轉換成`string`的[`ToString()`方法][to-string]。
