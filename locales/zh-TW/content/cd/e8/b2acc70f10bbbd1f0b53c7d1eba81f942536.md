# Instructions

在這個練習中，你需要實作 [Pac-Man][Pac-Man]這款 1980 年代經典街機遊戲的一些規則。

總共有六個任務，其中四個是與遊戲狀態有關的規則。

> _不用擔心函式中的引數是怎麼產生的，只要專注在組合這些引數，回傳預期的結果就好。_


## 0. 定義能量狀態

定義一個名為 `PowerOn` 的變數，用它的值來表示能量確實是開啟的。

```powershell
> $PowerOn
True
```

## 1. 定義 Pac-Man 是否吃掉幽靈

定義`EatGhost`函式，它接受兩個參數（_Pac-Man 是否有能量丸生效_ 和 _Pac-Man 是否碰到幽靈_），並回傳一個布林值，表示 Pac-Man 是否能吃掉幽靈。
只有在 Pac-Man 有能量丸生效且碰到幽靈時，這個函式才應該回傳 `True`。

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. 定義 Pac-Man 是否得分

定義`Score`函式，它接受兩個參數（_Pac-Man 是否碰到能量丸_ 和 _Pac-Man 是否碰到豆子_），並回傳一個布林值，表示 Pac-Man 是否得分。
只要 Pac-Man 碰到能量丸或豆子，這個函式就應該回傳 `True`。

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. 定義 Pac-Man 是否輸掉

定義`Lose`函式，它接受兩個參數（_Pac-Man 是否有能量丸生效_ 和 _Pac-Man 是否碰到幽靈_），並回傳一個布林值，表示 Pac-Man 是否輸掉。
如果 Pac-Man 碰到幽靈，而且沒有能量丸生效，這個函式就應該回傳 `True`。

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. 定義 Pac-Man 是否獲勝

定義`Win`函式，它接受三個參數（_Pac-Man 是否已經吃掉所有豆子_、_Pac-Man 是否有能量丸生效_，以及 _Pac-Man 是否碰到幽靈_），並回傳一個布林值，表示 Pac-Man 是否獲勝。
如果 Pac-Man 已經吃掉所有豆子，而且根據第 3 點中定義的參數判斷並沒有輸掉，這個函式就應該回傳 `True`。

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. 為獲勝條件撰寫 Synopsis

回到上一個函式，在註解區塊中加上`Synopsis`區段，簡短描述要如何贏得遊戲。
描述的長度至少要有十個字元。

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
