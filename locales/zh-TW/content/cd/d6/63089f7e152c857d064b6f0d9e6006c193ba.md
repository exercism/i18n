# 除錯

測試失敗時，會顯示一則訊息，說明哪裡出了問題，以及是哪個輸入造成的。
你也可以利用一點：任何印到「標準輸出」的內容同樣會顯示出來。
你可以用`println!`把內容寫到標準輸出：

```rust
println!("Debug message");
```

用大括號`{}`就能印出變數或運算式的值：

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

要注意的是，不是所有型別都能這樣印出來，只有能明確呈現給使用者的型別才可以。
舉例來說，向量（也就是陣列）就沒辦法這樣印，因為我們並不清楚向量該怎麼呈現給使用者！
至於這些其他型別，你可以用`{:?}`告訴`println!`巨集改用_除錯格式_。
這種表示法只有開發者才會看到。
來看個例子：

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

還有個方便的`dbg!`巨集，可以直接在行內替大型運算式除錯，不必把它拆成一堆獨立的變數宣告。

假設我們有下面這個運算式：

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

現在我們想知道呼叫`collect`之後回傳了什麼。
我們可以這樣寫：

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

但這也太麻煩了！
我們不想只為了除錯，就把精心寫好的運算式改掉。
讓我們歡迎`dbg!`登場：

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

這些空白只是為了讓程式碼更清楚。
你可以把任何運算式包進`dbg!()`，它就會用除錯格式把那個值印出來。
之後你還能繼續把這個值用在更大的運算式裡，就像`dbg!`從沒出現過一樣。

祝你除錯愉快！
