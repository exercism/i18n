# 簡介

Kotlin 的`when`是一種條件運算式，用來從多個選項中做選擇。它類似 Java 的`switch`，而且比一連串的`if` ... `else if` ... `else`更有彈性。

和`if`一樣，`when`也可以當成運算式使用，產生一個值。

## 比對值

在括號中給`when`一個要比對的值。每個分支會依序比對這個值，直到有一個分支符合為止：

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 每個分支都寫成`pattern -> result`。
- 分支會由上往下逐一嘗試，直到找到符合的項目。只有第一個符合的分支會執行。
- 對於上面沒有列出的值，使用`else`（類似一連串`if`中最後的`else`）。

這類似[模式比對][pattern-matching]。`pattern`可以是單純要比對的值，也可以使用`is`依型別比對：

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

或者使用`in`檢查它是否包含在某個範圍、集合、字串，或其他任何具有`contains`方法的東西裡：

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## 守衛條件

比對值的時候，可以在 pattern 後面加上`if`，放入額外的條件。這些條件稱為守衛條件。

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

甚至連`else if`也可以使用。

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 比對條件

另一種做法是省略要比對的值，在每個分支上放置布林條件：

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

同樣地，分支會由上往下檢查，只有第一個條件為`true`的分支會執行。

## 將`when`當成運算式使用

當`when`的結果會被使用時（指定給變數、從函式回傳等等），就必須涵蓋所有可能的情況。

- 以值進行比對時，除非所有可能的值都已處理（例如`Boolean`或`enum`的所有值），否則要加上`else`。
- 以條件進行比對時，`else`分支是必要的，因為編譯器無法知道你寫的條件是否涵蓋了每一種情況。

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
