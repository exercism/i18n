# 提示

## 一般

- `<disjoint-set>`、`add-atoms`、`equate`和`representative`都放在[`disjoint-sets`][disjoint-sets]這個詞彙裡。
- 這些字詞會把 disjoint set 當作它們的*最後一個*引數，而且其中大多數會消耗掉它，不會回傳它。`keep`會執行一個字詞，接著把那個最後引數的副本留在堆疊上。

## 1. 建立俱樂部

- `<disjoint-set>`會建立一個空的結構；`add-atoms`則會一次註冊整個序列。
- `add-atoms`會消耗掉 disjoint set。用`[ add-atoms ] keep`來加入這些詩人，同時仍然回傳俱樂部。

## 2. 記錄一次協作

- `equate`會合併兩個原子所屬的群組：`poet1 poet2 club equate`。
- 它不會回傳任何東西，所以`[ equate ] keep`會把俱樂部留在堆疊上等著回傳。

## 3. 找出詩人的圈子

- `representative`已經具備你需要的形狀：輸入一位詩人和一個俱樂部，輸出該圈子的代表。

## 4. 是否同屬一個圈子？

- 當`representative`對兩位詩人都回傳相同的值時，就表示這兩位詩人同屬一個圈子。
- 在俱樂部裡查出每位詩人的代表，然後用`=`比較這兩者。`[ representative ] curry`會建立一個 quotation，用來在這個特定的俱樂部裡查出某位詩人的代表，而`bi@`則會將它套用到這兩位詩人身上。

[disjoint-sets]: https://docs.factorcode.org/content/vocab-disjoint-sets.html
