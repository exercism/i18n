# 提示

## 一般

- 不用擔心特定的數字型態，目前先用`Int32`和`Float64`就好。
- Int32 和 Float64 是 Crystal 的預設數字型態，所以不需要特別指定。

## 1. 將溫度從攝氏轉換成克氏

- 你可以使用算術運算子（`+`）來把數字相加。

## 2. 將溫度四捨五入

- 你可以使用`round`方法把數字四捨五入到指定的小數位數。
- round 方法接受一個引數 `places`，用來指定要四捨五入到第幾位小數。

## 3. 將溫度從攝氏轉換成華氏

- 你可以使用算術運算子（`*`）來把數字相乘。
- 你可以使用括號（`()`）將運算分組。

## 4. 取得缺少的感測器數量

- 你可以使用算術運算子（`-`）來把數字相減。
- 你可以使用算術運算子（`%`）來取得相除後的餘數。
