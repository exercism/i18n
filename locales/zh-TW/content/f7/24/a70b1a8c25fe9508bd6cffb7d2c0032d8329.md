# 簡介

## JavaScript 中的正規表達式

[正規表達式][mdn-regular-expressions]（或稱 Regex）是一串字元，我們可以用它來鎖定並操作字串中的特定內容。因此，我們可以：

- **搜尋**字串中的文字
- **取代**字串中的子字串
- **擷取**字串中的資訊

> 💡 JavaScript 的正規表達式風格是 ECMA-262 語言標準的一部分，這代表你不必擔心各家瀏覽器的相容性問題。

## 如何建立正規表達式

在 JavaScript 中，正規表達式大多寫成`/pattern/modifiers`的格式。

我們有兩種建立正規表達式的方式：

1. **正規表達式字面量**：

```javascript
const regex = /[a-z]/;
```

2. **RegExp**建構函式：

```javascript
const regex = new RegExp('[a-z]');
```

這兩種情況下，JavaScript 都會根據正規表達式建立一個物件。建議預設使用不可變的模式，也就是字面量的寫法。

當正規表達式會變動，或是我們還不知道它會長什麼樣子時（例如來自輸入的內容），就可以使用 RegExp 建構函式。

## 🏴‍☠️ 旗標

正規表達式有一些選用的超能力，稱為[`flags`][mdn-flags]，可以啟用額外的功能。

以下是幾個常見的：

- `/g` - 全域搜尋
- `/i` - 忽略大小寫
- `/m` - 多行搜尋

來看一個簡單的例子：

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

`g`這個字元讓我們能找出字串中所有可能的符合項目。如果沒有這個功能，JavaScript 只會擷取出第一個符合的`Home`。

忽略大小寫的旗標`/i`讓我們在尋找模式時更有彈性。這樣一來，我們要找的是`UPPERCASE`還是`lowercase`就都不影響了。

使用`RegExp`建構函式時，加入旗標的語法不太一樣。

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## 最常用的函式

當正規表達式搭配 JavaScript 現有的內建函式使用時，我們就有一些強大的方式來操作字串並從中取得資料。

以下是幾個最常與正規表達式搭配使用的函式。

### Test

[test()][mdn-regex-test]] 方法會搜尋正規表達式與指定字串之間是否有符合的結果。回傳 true 或 false。

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

使用 [match()][mdn-regex-match] 方法，我們會得到一個實用的陣列，其內容取決於是否找到符合的結果。

這樣一來，我們既能**搜尋**，也能**擷取**任何字串中的資訊。例如：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

當加上全域搜尋旗標`/g`時，這個方法不會只回傳單一符合項目以及索引或輸入等實用資訊，而是會回傳所有出現的結果並放在陣列中：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScript 的 [replace()][mdn-regex-replace] 方法讓我們可以在指定的字串中搜尋某個值，並將它取代成想要的新值。

```javascript
string.replace(searchValue, newValue);
```

用來搜尋與取代的模式可以是一個單純的字串，或是一個正規表達式。

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

此外，我們還可以在取代的位置套用一個函式，對每個值做額外的處理。

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

JavaScript 的 [split()][mdn-regex-split] 方法代表了另一種使用正規表達式來操作字串的方式。

這樣一來，我們就能用正規表達式辨識某個模式，藉此切分指定的字串，例如`str.split(/[,.\s]/)`。這個模式會用來當作`separator`。

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
