# 說明

你正在經營一間線上時尚精品店。庫存中的每件商品都是一個包含兩個元素的陣列 `{ name price }`，而整份庫存就是一個由商品組成的陣列。

缺少的價格會記錄成 `f`。

## 1. 依價格排序庫存

定義 `sort-by-price`，回傳一個新的陣列，其中的商品依價格由小到大排序。

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. 找出沒有設定價格的商品

定義 `with-missing-price`，回傳一個只包含價格為 `f` 的商品的陣列。

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. 計算昂貴商品的數量

定義 `expensive-items`，接收一份庫存和一個價格門檻，並回傳價格嚴格高於門檻的商品有幾件。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. 找出最便宜的商品

定義 `cheapest-item`，回傳價格最低的商品。沒有價格（`f`）的商品不會出現在輸入中。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. 加總所有價格

定義 `total-price`，回傳所有價格的總和。沒有價格（`f`）的商品不會出現在輸入中。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. 將商品格式化為價格標籤

定義 `format-price-tag`，回傳格式為 `"name: $price"` 的商品字串。沒有價格（`f`）的商品不會出現在這裡。

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
