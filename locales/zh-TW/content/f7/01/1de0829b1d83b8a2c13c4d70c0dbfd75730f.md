# 簡介

## 遞迴

某個事物能夠以自身來定義，這種能力稱為遞迴。在 F# 中，遞迴最常見於遞迴函式，也就是會呼叫自身的函式。

遞迴函式至少需要有一個_基本情況_，以及至少一個_遞迴情況_。_基本情況_會回傳一個值，而不會再次呼叫函式。_遞迴情況_則會再次呼叫函式，並修改輸入，讓它終究能符合基本情況。

遞迴函式的定義方式和一般函式相同，只是要加上`rec`修飾詞。少了這個修飾詞，函式就_無法_呼叫自身，任何嘗試這麼做都會導致編譯錯誤。因此，必須明確選擇使用遞迴。

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# 也透過差別聯合型別支援遞迴型別。遞迴的差別聯合型別，其資料中會有一個或多個情況參照到這個差別聯合型別本身。和遞迴函式一樣，遞迴型別也必須有一個基本情況。和遞迴函式不同的是，遞迴型別不使用`rec`關鍵字。

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
