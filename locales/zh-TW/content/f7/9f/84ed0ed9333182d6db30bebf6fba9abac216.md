# 簡介

有時候，某個狀態需要在多個 word 之間共用，而不必每次都得透過它們的堆疊效應來傳遞。Factor 的*動態變數*（以`SYMBOL:`宣告）讓每個 word 都能存取儲存在命名空間中的值。

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global`和`get-global`會操作全域命名空間。`set`和`get`會操作*目前*的動態作用域；當你想要作用域內的綁定，而不是整個行程共用的綁定時，通常會用在`with-variable`區塊裡。

`SYMBOLS: a b c ;`會一次宣告多個符號。
