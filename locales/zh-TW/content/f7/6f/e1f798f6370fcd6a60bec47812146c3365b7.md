# 測試

要執行測試，請依照下列步驟：

- 進到題目目錄（例如`~/Exercism/hello-world`）。
- 在終端機中啟動`jconsole`工作階段（例如輸入`jconsole`或`ijconsole`）。
- 載入你的解答檔案（例如`load 'hello-world.ijs'`）
- 輸入`load  'general/unittest'`載入單元測試框架
- 輸入`unittest 'test.ijs'`測試你的解答。
<br></br>
- 或者，也可以用像這樣的一行指令來執行測試：`jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`。

## 略過的測試

一開始只會啟用最初的那個測試。
這種做法鼓勵你一步一步地解這道練習。
每個測試在其定義上方都有一個名詞，名稱以_'\_ignore'_結尾。
要執行該測試，請把它的值改成 0。

### 範例：

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
