# 關於

[Elixir](https://elixir-lang.org/) 於 2012 年首次發布，它擴展了 Erlang 早已穩固的種種特性，同時讓初學者更容易上手、閱讀、測試與撰寫。

Elixir 的創造者 José Valim [在他 2012 年的研討會演講中](https://vimeo.com/53221562)說明了他如何打造這門語言，讓應用程式能夠：

  1. 分散式
  2. 容錯
  3. 軟即時
  4. 熱程式碼替換（可以在不停止伺服器的情況下引入新的程式碼）

Elixir 實際上會編譯成[位元組碼](https://en.wikipedia.org/wiki/Bytecode)，然後在 [BEAM Erlang 虛擬機](https://codesync.global/media/robert-virding-co-creator-of-erlang-explains-the-beam/)上執行。

呼叫 Erlang 沒有所謂的「轉換成本」，也就是說你可以把 Erlang 程式碼直接放在 Elixir 程式碼旁邊執行。

作為一門函式語言，Elixir 裡的一切都是運算式。

Elixir 擁有「一級文件」的特性，意思是註解可以附加在函式上，讓取用更加容易。

正規表達式同樣享有一級待遇，省去了在字串裡頭彆扭的跳脫處理。

Elixir 的非同步通訊實作讓程式碼得以保持輕量，同時又能承載高流量的並行處理。

程式設計師用 Elixir 在單一伺服器節點上*並行*處理成千上萬個請求和回應。

它已被成功用於需要快速消費並提供大量 API 的微服務。

[Phoenix 框架](https://www.phoenixframework.org/)能協助組織 Elixir 的網頁應用程式。
