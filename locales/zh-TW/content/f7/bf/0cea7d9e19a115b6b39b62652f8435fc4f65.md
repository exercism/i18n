# 簡介

## 自訂型別

Elm 的[自訂型別][custom-types]代表固定數量的具名情況，每個值恰好對應其中一種具名情況。

自訂型別使用 `type` 關鍵字定義，需要的語法非常少。它是 Elm 程式設計中最重要的技巧之一，用來讓程式碼中可能的值與現實生活中有效的值完全一致，這麼一來就沒有無效資料的容身之處，也讓[不可能的狀態無法在程式碼中表示出來][impossible-states]。

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

自訂型別的每個情況都可以選擇性地附加資料，不同情況也可以帶有不同型別的資料。如果所有情況都沒有附加資料，這種可辨識聯合就很像其他語言通常所稱的_列舉_（或 _enum_）。

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

要為某個特定情況建立值，可以引用它的名稱（`Spring`），前提是它定義在同一個模組中，或是用 `import SeasonModule exposing (Season(..))` 這種風格的語法匯入；也可以引用它的完整限定名稱（`Season.Spring`），前提是用 `import SeasonModule exposing (Season)` 這種風格的語法匯入。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

自訂型別和 Elm 中的所有東西一樣，具有_結構相等_，也就是說，同一情況且（選填）資料相同的兩個值彼此等價。

處理自訂型別時，最推薦的做法是使用[模式比對][pattern-matching]：

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
