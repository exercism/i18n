# 介紹

C# 的`enum`型別代表一組固定的具名常數（即列舉）。

一般來說，一個`enum`成員只能對應到其中一個具名常數。不過，有時候我們會需要同時對應多個常數。這時候，可以用 [`Flags`屬性](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)來標註`enum`。

旗標列舉可以這樣定義（這裡使用二進位整數標記`0b`）：

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

一個值為`0b00000011`的`PhoneFeatures`實例，會同時設定`Call`_和_`Text`旗標。

預設情況下，列舉成員的值會使用`int`型別。你可以在列舉宣告中指定型別，改用其他整數型別：

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
