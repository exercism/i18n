# 關於

[可變參數][variadic-parameters]讓函式的單一參數可以接受 0 個或多個指定型別的值。
只要在參數的型別標註後面加上三個點（`...`），就能定義一個可變參數。

在函式主體裡，Swift 會把這些值整理成一個指定型別的陣列：

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
如果函式在可變參數之後還有其他參數，那麼緊接在可變參數後面的第一個參數就**必須**要有明確的引數標籤，Swift 才知道可變引數清單在哪裡結束。
~~~~
