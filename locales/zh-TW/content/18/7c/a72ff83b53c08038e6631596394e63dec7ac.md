# 說明

在這個練習中，你會寫一些程式碼，幫助自己照著最愛的食譜書烤出超美味的千層麵。

你有四個任務，全都和烹調千層麵所花的時間有關。

## 1. 定義預期的烤箱時間（以分鐘為單位）

定義`expected_minutes_in_oven`綁定，用來確認千層麵應該在烤箱中烤幾分鐘。根據食譜書，預期的烤箱時間是 40 分鐘：

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. 計算剩餘的烤箱時間（以分鐘為單位）

定義`remaining_minutes_in_oven`函式，它接受千層麵已經在烤箱中實際烤過的分鐘數作為參數，並根據上一個任務算出的預期烤箱時間，回傳千層麵還需要在烤箱中待幾分鐘。

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. 計算準備時間（以分鐘為單位）

定義`preparation_time_in_minutes`函式，它接受你加到千層麵裡的層數作為參數，並回傳你準備千層麵所花的分鐘數，假設每一層需要 2 分鐘來準備。

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. 計算經過的時間（以分鐘為單位）

定義`elapsed_time_in_minutes`函式，它接受兩個參數：第一個參數是你加到千層麵裡的層數，第二個參數是千層麵已經在烤箱中的分鐘數。這個函式應該回傳你烹調千層麵所花的分鐘數，也就是準備時間（分鐘）加上千層麵目前在烤箱中已經待的分鐘數。

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
