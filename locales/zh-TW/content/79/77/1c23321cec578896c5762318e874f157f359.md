# 簡介

## 比較數字

在 JavaScript 中，可以使用下列的關係與相等運算子來比較數字。

| 比較 | 運算子 |
| ---------------------- | --------- |
| 大於 | `a > b` |
| 大於或等於 | `a >= b` |
| 小於 | `a < b` |
| 小於或等於 | `a <= b` |
| （嚴格）等於 | `a === b` |
| 不（嚴格）等於 | `a !== b` |

比較的結果一定是布林值，所以不是`true`就是`false`。

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## 比較字串

在 JavaScript 中，上述的比較運算子也可以用來比較字串。
在這種情況下，會套用字典（字典編排）順序。
你可以在[這裡][utf-16-list]找到所有字元確切順序的清單。

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 嚴格相等

你可能會想，為什麼 JavaScript 用 3 個等號來檢查相等性。
`===`代表的是*嚴格相等*的檢查，這表示不會執行型別轉換，而且不同型別的值永遠不相等。

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

在 JavaScript 中，建議使用`===`和`!==`來檢查相等性。

另外還有`==`和`!=`，它們代表檢查*寬鬆相等*。
你應該避免使用它們，因為它們會在比較之前套用隱含的型別轉換。
這些情況下的結果很難預測，有時甚至不是你預期的樣子。

```javascript
0 == false;
// => true
```
