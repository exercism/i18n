# 簡介

R 中的`vector`是一組具有相同`mode`的值：`numeric`、`character`等等。如果輸入混合型別的資料，R 會悄悄地把它們全部強制轉換成共同的型別，通常是 character，這可能導致意料之外的結果。

## 建立向量

如果你已經有全部的值，可以使用`c()`（「concatenate」或「combine」的縮寫）：

```R
x <- 10
v <- c(4, 7, x)
```

`c()`函式非常有彈性，輸入可以包含其他向量和範圍。`c()`可以接受任意數量和種類的輸入，並將它們攤平成單一向量。

## 範圍

對於一段連續的值（遞增或遞減），你可以使用`:`標記法

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

## 存取向量元素

和許多語言一樣，我們可以用括號中的索引來存取：

```R
> v <- 4:7
> v[2]
[1] 5
> v[2:4]
[1] 5 6 7
```

但要小心：***R 預設使用從 1 開始的索引***。

這在科學計算語言（Fortran、Matlab、Julia）中很常見，但和 C 及其眾多後繼語言的從 0 開始索引不同。

範圍可以用在上面的範例中，也可以用在極具彈性的`c()`函式中：

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`（就像 R 中的大多數東西）可以視為可變的，用類似的彈性語法寫入單一或多個元素：

```R
> v <- 1:10
> v[2] <- 42
> v[4:6] <- c(11, 12, 13)
> v
 [1]  1 42  3 11 12 13  7  8  9 10
```

## 負索引

熟悉其他語言的程式設計師可能會猜`v[-1]`是存取向量最後一個元素的方法。
錯了！

負索引其實是一種***移除***元素的方法，會回傳一個較短的向量：

```R
> v <- c(2, 4, 6)
> v[-2]
[1] 2 6  # second element gone
```
