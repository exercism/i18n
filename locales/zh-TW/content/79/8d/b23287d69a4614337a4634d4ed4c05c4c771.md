# 提示

## 一般

- 也許你想建立一個以標籤與記錄清單為基礎的 DSL，像這樣：

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- 或者，你比較喜歡以函式呼叫鏈為基礎的 DSL，像這樣：

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  又或者你完全有不同的計畫？
  放手去做吧！

- 話雖如此，一個清楚、簡潔、又不會太令人意外的 DSL 通常比較好（例如 `minus` 函式是用來做減法，而不是用來在兩個節點之間建立邊，像 `node("a") - node("b")` 那樣）。
