# 關於

在 Common Lisp 裡，假值是由空陣列（`()`）或符號`nil`來表示。這些值可以加上引號，也可以不加引號。

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Lisp 中所有其他的值都代表真。另外還有一個特殊的常數符號`t`，它永遠等於`t`（因此永遠為真）。

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
