## 1. 撰寫用來翻轉兩條電線的閉包

每枚臭彈上都有三條顏色不同的電線。
撰寫一個閉包，接受一個 `(String, String, String)` 元組，並回傳把前兩個元素順序對調後的元組。
將這個閉包指定給名稱`flip`。

請注意，型別必須是 `ChangeClosure`（或可傳送的型別），型別定義已經寫在 stub 檔案裡。
否則程式碼將無法編譯。

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. 撰寫用來旋轉電線的閉包

撰寫一個閉包，接受一個 `(String, String, String)` 元組，並回傳把電線順序向左旋轉後的元組。
將這個閉包指定給名稱`rotate`。

請注意，型別必須是 `ChangeClosure`（或可傳送的型別），型別定義已經寫在 stub 檔案裡。

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. 實作電線洗牌產生器

為了找出剪斷臭彈電線的順序，你需要實作一個函式，根據臭彈的 ID 號碼產生正確的洗牌函式。

實作這個函式：

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

它接受一個翻轉兩條電線的閉包，以及一個旋轉三條電線的閉包，並回傳一個閉包。
這個回傳的閉包會接受臭彈的 ID 號碼和三條電線的順序，然後計算出電線需要剪斷的順序。
ID 號碼由八個位元組成，每個位元會決定要翻轉還是旋轉電線。

從最右邊的位元開始，針對 ID 號碼中的每個位元，如果該位元是 0，就把 `flipper` 閉包套用到電線元組上；如果是 1，就套用 `rotator` 閉包，得到電線的新狀態。
當 ID 的八個位元都套用完對應的閉包後，電線的最終狀態就是它們需要被剪斷的順序。

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
