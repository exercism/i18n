# 說明

在這個練習中，你要籌辦各種遙控車之間的比賽。每輛車都有自己的特性，並在整個錦標賽賽季中於許多不同的賽道上奔馳。

~~~~exercism/note
這個練習中的函式是在 C 原始檔中依提供的簽章所宣告的。你的 x86-64-assembly 程式碼必須遵循這些規格。
~~~~

## 1. 建立遙控車

你已經定義了一個 struct `car_t` 來表示一輛遙控車：

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

在 x86-64 組合語言中定義函式 `new_car`，就能建立一輛遙控車。
欄位 `battery` 的起始值一律是 `100.0`。

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. 建立新賽道

賽道以 struct `track_t` 表示：

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t` 用來記錄賽道的各種不同路面：

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

在 x86-64 組合語言中定義函式 `new_track`，就能建立新賽道。

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. 建立賽事

每場比賽最多有 6 輛車參加，在賽道上跑完指定的圈數。
比賽以 struct `race_t` 表示：

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

在 x86-64 組合語言中定義函式 `new_race`。
比賽一開始，還沒有任何確認參賽的車輛：

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. 確認車輛參賽

當車主要求讓車輛參加比賽時，只有在名單還沒額滿的情況下，參賽資格才會被確認。

在 x86-64 組合語言中定義函式 `add_participant`。
如果比賽還有一個參賽名額，就把這輛車加入名單、更新計數器，並確認它的參賽資格。
否則，賽事主辦單位必須告知車主，這輛車這次無法參賽。

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. 建立錦標賽

你用 struct `tournament_t` 記錄這個賽季預定的比賽：

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

在 x86-assembly 中定義函式 `add_race`，把一場比賽加入錦標賽的陣列，同時更新它的計數器。
你可以假設 `races` 陣列一定有足夠的空間容納新的比賽。

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
