# 字串

**字串**是一段文字。Sather 為它準備的型別是 `STR`，字串則寫在雙引號之間。

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## 串接字串

`+`會把兩個字串首尾相接。

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

它不會在兩者之間自動加入任何東西，所以空格必須自己寫出來。省略的話就會得到`"JeanSibelius"`。

## 字串有多長？

`.size`是字串裡有幾個字元。這是一個整數，所以型別是 `INT`。

```sather
"Sibelius".size      -- 8
```

`.size`後面沒有括號，就跟不接受引數的常式一樣。

## 取出其中一部分

`.head(n)`是前`n`個字元，`.tail(n)`是後`n`個。

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head`從前面數起，`tail`從後面數起。兩者都不會動到原本的字串，而是回傳一個新的字串。
