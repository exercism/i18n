# 提示

## 一般

- 有三個布林運算子可以處理布林值：`not`、`&&`和`||`。
- 單一運算式裡可以組合多個運算子。

## 1. 定義 pac-man 是否能吃掉幽靈

- 函式必須回傳一個`Bool`值。
- 你可以使用布林運算子`&&`來組合引數，以產生結果。

## 2. 定義 pac-man 是否得分

- 函式必須回傳一個`Bool`值。
- 你可以使用布林運算子`||`來組合引數，以產生結果。

## 3. 定義 pac-man 是否輸了

- 函式必須回傳一個`Bool`值。
- 你可以使用布林運算子`&&`和`not`來組合引數，以產生結果。

## 4. 定義 pac-man 是否獲勝

- 函式必須回傳一個`Bool`值。
- 你可以使用布林運算子`&&`和`not`來組合引數，以及其中一個先前實作的函式所回傳的結果。
