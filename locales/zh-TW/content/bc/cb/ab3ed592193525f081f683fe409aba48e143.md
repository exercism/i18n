# 簡介

`switch`運算式可以將某個值與一組模式中的其中一個案例比對，並回傳對應的值或執行對應的動作。這種對應關係以`=>`符號表示。此外，每個模式都能搭配一個選擇性的案例防護，並以`when`關鍵字開頭。必須讓該案例防護運算式評估為 true，`switch`的這個「分支」才會被選中。這些案例（又稱 _`switch`分支_）會依照文字順序評估，一旦找到相符的項目，就會立刻中止流程並回傳對應的值。

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
