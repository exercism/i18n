# 關於

在 Elixir 裡有兩種不同的數字：整數和浮點數。

整數就是不包含小數的數字。

```elixir
integer = 3
# => 3
```

有幾個處理整數的實用函式可以在 [`Integer`][integer] 模組裡找到。

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

大整數（浮點數也一樣）通常會每三位數字分成一組，並用底線分隔。

```elixir
1_000_000
# => 1000000
```

Elixir 中數字的最大大小只受限於系統可用的記憶體，因為 Elixir 使用[任意精度運算][arbitrary-precision-arithmetic]。

Elixir 也支援用捷徑標記來輸入[二進位、八進位與十六進位整數][integers-in-other-bases]。

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## 比較

如果整數和浮點數的值相同，就可以視為相等（[`==`][kernel-equal]）。不過，由於它們是不同的型別，所以永遠不會嚴格相等（[`===`][kernel-strictly-equal]）。

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
