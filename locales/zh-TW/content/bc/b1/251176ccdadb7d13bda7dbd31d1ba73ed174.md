# 說明

實作一個能將英文轉換成豬拉丁的程式。

豬拉丁是一種虛構的兒童語言，故意設計得令人混淆。它只遵循幾條簡單的規則（如下），但一旦說得快，非小孩（以及非母語人士）就很難聽懂。

- **規則 1**：如果一個字開頭是母音，就在字尾加上 "ay" 的音。請注意，字首的 "xr" 和 "yt" 會發出母音（例如 "xray" -> "xrayay"、"yttria" -> "yttriaay"）。
- **規則 2**：如果一個字開頭是子音，就把這個子音移到字尾，然後在字尾加上 "ay" 的音。子音可以由多個子音組成，也就是子音串（例如 "chair" -> "airchay"）。
- **規則 3**：如果一個字以子音加上 "qu" 開頭，就把這個子音和 "qu" 一起移到字尾，然後在字尾加上 "ay" 的音（例如 "square" -> "aresquay"）。
- **規則 4**：如果一個字在子音串之後有 "y"，或者 "y" 是兩個字母組成的字中的第二個字母，那麼 "y" 會發出母音（例如 "rhythm" -> "ythmrhay"、"my" -> "ymay"）。

針對邊界情況還有一些其他規則，也有地區性的變體。

詳情請見 <http://en.wikipedia.org/wiki/Pig_latin>。
