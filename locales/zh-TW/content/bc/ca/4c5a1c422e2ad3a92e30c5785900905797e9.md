# 維護者儲存庫權限

軌道維護者是軌道 GitHub 團隊的成員。成為軌道團隊成員是_僅限邀請_的。

```exercism/note
如果你想成為軌道維護者，請在[論壇](https://forum.exercism.org/c/exercism/building-exercism/125)上開一個主題。
```

## 維護類別

維護類別共有五種：

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

軌道的維護類別由三個變數決定：

1. 軌道是否開放中（也就是學生能否在網站上加入該軌道）
2. 軌道維護者的人數
3. 同時屬於 `cross-track-maintainers` GitHub 團隊的軌道維護者人數

要判斷維護類別，請從下表找出第一個符合該軌道的類別：

| 類別                  | 開放中？ | 維護者人數 | 跨軌道維護者人數          |
| --------------------- | -------- | ---------- | ------------------------- |
| wip-track             | 否       | 任意       | 任意                      |
| unmaintained          | 是       | 0          | 0                         |
| maintained-autonomous | 是       | > 0        | = 維護者人數              |
| maintained-solitary   | 是       | 1          | 0                         |
| maintained            | 是       | > 1        | < 維護者人數              |

## 儲存庫權限

維護類別會用來設定軌道 GitHub 儲存庫的權限。

| 類別                  | 需要 PR | 需要 PR 核准 | 跨軌道團隊審查 |
| --------------------- | ------- | ------------ | -------------- |
| wip-track             | 否      | 否           | 否             |
| unmaintained          | 是      | 是           | 是             |
| maintained-solitary   | 是      | 是           | 是             |
| maintained-autonomous | 是      | 否           | 否             |
| maintained            | 是      | 否           | 否             |

```exercism/caution
`wip-track`類別是唯一允許維護者推送到 `main` 的類別。
```

```exercism/caution
工具儲存庫_一律_需要 PR 核准，因為其內容受到 [CODEOWNERS 檔案](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners)保護。
```
