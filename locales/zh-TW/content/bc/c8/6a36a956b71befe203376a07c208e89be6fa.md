# 簡介

Unison 用`Boolean`型別來表示 true 和 false 這兩種值。只有兩個值：`true`和`false`。

```unison
trueVariable = true
falseVariable = false
```

我們可以使用 and（以`&&`表示）、or（以`||`表示）和 not（以`not`表示）運算子來計算布林運算式。

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Unison 的布林運算式支援短路：如果`&&`運算式的第一個引數是`false`，就沒有必要繼續計算第二個引數。
同樣地，如果`||`運算式的第一個引數是`true`，這個運算式就會立刻回傳`true`。

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
