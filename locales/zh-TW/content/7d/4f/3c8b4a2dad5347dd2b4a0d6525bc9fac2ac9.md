# 介紹

例外是錯誤處理的一種形式。
它們之所以被稱為例外，是因為通常會在處理意料之外的事件時出現。

在程式碼的任何地方，我們都可以「raise」一個例外。
我們透過 `raise`方法做到這件事，並傳入一個物件，通常是 Exception 物件，不過也可以直接使用基本的字串。
例如，你會看到練習的程式骨架中，我們使用內建的 `RuntimeError`來告訴 Ruby 某個方法尚未實作。
你也可以使用 `raise(ExceptionObject, params)`這種簡寫語法。
如果省略了例外類別，預設會使用 `RuntimeError`。
例如：

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

當 Ruby 看到這個情況時，會把錯誤往上拋到程式的最上層，然後結束程式。
例如，如果你試著把某個數除以零，就會看到類似這樣的結果：
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
