# 簡介

## 運算子多載

主要的算術與比較運算子都能經過調整，讓你自己定義的類別和結構也能使用。這就是所謂的_運算子多載_。

大多數運算子的形式如下：

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

轉型運算子的形式如下：

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

運算子的行為與靜態方法相同。運算子符號會取代方法識別項，而且它們也有參數和回傳型別。參數和回傳型別的型別規則符合你的直覺，而你可以仰賴編譯器提供詳細指引。
