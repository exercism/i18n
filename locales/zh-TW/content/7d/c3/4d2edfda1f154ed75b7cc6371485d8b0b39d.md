# 指令

將 RNA 序列轉譯為蛋白質。

RNA 可以拆解成由三個核苷酸組成的序列，稱為密碼子，然後像這樣轉譯成多肽：

RNA：`"AUGUUUUCU"` => 轉譯為

密碼子：`"AUG", "UUU", "UCU"`
=> 會變成具有以下序列的多肽 =>

蛋白質：`"Methionine", "Phenylalanine", "Serine"`

總共有 64 個密碼子，對應到 20 種胺基酸。不過，在這個練習中，並不是所有的密碼子序列和對應的胺基酸都很重要。
只要程式能處理一個密碼子，就應該能處理所有的密碼子。
不過，也歡迎你自行擴充測試套件中的清單，把它們全部納入。

另外還有三個終止密碼子（也稱為 'STOP' 密碼子）。如果核糖體遇到其中任何一個，所有的轉譯就會結束，蛋白質也隨之終止。

之後出現的所有密碼子都會被忽略，就像這樣：

RNA：`"AUGUUUUCUUAAAUG"` =>

密碼子：`"AUG", "UUU", "UCU", "UAA", "AUG"` =>

蛋白質：`"Methionine", "Phenylalanine", "Serine"`

請注意，終止密碼子 `"UAA"` 會結束轉譯，最後的 Methionine 不會被轉譯進蛋白質序列中。

以下是這個練習所需的密碼子及對應的胺基酸。

| 密碼子             | 蛋白質        |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

想更了解蛋白質轉譯，請參閱[維基百科上的蛋白質轉譯][protein-translation]。
