# 關於

quotation 是以 `[ ]` 寫成的，是 Factor 中對應匿名函式或程式區塊的寫法。它是一種一級值，可以推入堆疊、儲存，或到處傳遞，而且只有在某個東西*呼叫*它時才會執行。

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

quotation 是由一連串的詞組成，只要某段行為需要延後或參數化，Factor 就會用到它們：

- `if`、`when`、`unless`、`cond` 的分支
- `filter`、`count`、`any?`、`all?` 的述詞
- `map`、`each`、`reduce` 的轉換
- `times`、`while`、`loop` 的主體

通常可以推斷出一個 quotation 的堆疊效果。推斷不出來時（通常是因為它被儲存起來、之後才 `call`），請明確宣告它的效果：`call( a b -- c )`。

## 組合 quotation

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` 會把兩個 quotation 首尾相接成一個新的 quotation，先執行第一個，再執行第二個。`curry` 則會在開頭加上一個固定值，回傳的 quotation 會先推入那個值，再呼叫原本的 quotation。兩者產生的都是一般的 quotation，你可以 `call`、儲存，或傳給組合子。

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
