# 關於

Clojure 中有幾個基本的[流程控制](https://clojure.org/guides/learn/flow)結構。`if`是最重要的條件運算式，它由一個條件、一個「then」和一個選用的「else」組成。`if`只會求值條件所選中的那個分支。

```clojure
(if (even? 2) "even" "odd")
```

`cond`是一系列的測試和運算式。每個測試會依序求值，而第一個為真的測試，其對應的運算式會被求值並回傳。

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
