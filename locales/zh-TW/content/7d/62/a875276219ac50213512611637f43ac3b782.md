# 簡介

在 Exercism 上，你解完的每道練習都會附上一份範例解答。
在 Julia 軌道上，這些解答通常會包含[文件字串](https://en.wikipedia.org/wiki/Docstring)。
解完這道練習後，你會了解文件字串的結構、如何撰寫，以及如何透過 REPL 存取文件字串。

~~~~exercism/note
在 Julia 軌道上解練習時，如果你不想，並不需要為函式撰寫文件字串。
~~~~

## 語法

任何緊接在任何一種 Julia 物件（例如函式或型別）前面的字串，都會被解讀成記錄該物件的文件字串。
例如：

```julia
"Tell a joke."
joke() = ...
```

Julia 的文件字串使用 [Markdown](https://en.wikipedia.org/wiki/Markdown) 格式化。
這讓你能在文件字串裡使用縮排、程式區塊或粗體文字等功能。

~~~~exercism/note
你可以在 [Markdown 標準函式庫的文件](https://docs.julialang.org/en/v1/stdlib/Markdown/)裡找到支援的 Markdown 功能清單。
~~~~

比較複雜的文件字串可能長這樣：

````julia
"""
    mean(x, y)

Compute the mean value of `x` and `y`.
"""
mean(x, y) = (x + y) / 2
````

Julia 手冊裡有幾項應該遵循的慣例：

> - 一律在文件最上方顯示函式的簽章，並縮排四個空格，讓它以 Julia 程式碼的形式呈現。
> - 在簡化的簽章區塊之後，加入一句單行說明，描述這個函式的作用或這個物件代表什麼。
>    如有需要，可在空一行之後用第二段提供更多細節。
>    為函式撰寫文件時，這句單行說明應使用祈使語氣（「做這個」、「回傳那個」），而不是第三人稱（不要寫成「回傳長度……」）。
>    句子結尾要加上句號。
> - 不要重複自己。
>    既然函式名稱已經由簽章給出，就不需要以「`mean`這個函式……」開頭：直接講重點。
> - 用反引號標示程式碼與方程式。
> - 將開頭與結尾的 `"""` 字元各自獨立成行。

~~~~exercism/note
上面這份清單只涵蓋你在 Exercism 情境中可能需要的或會遇到的慣例。
你可以在 [Julia 手冊](https://docs.julialang.org/en/v1/manual/documentation/)裡找到完整、未刪節的清單。
關於為更進階的 Julia 概念撰寫文件的更多慣例，會在之後的練習中介紹該概念時一併說明。
~~~~

## 存取文件字串

你可以在 REPL 中輸入`?`再加上函式或物件的名稱來搜尋文件字串，例如

```julia-repl
help?> println
search: println printstyled print sprint isprint

  println([io::IO], xs...)


  Print (using print) xs followed by a newline. If io is not supplied, prints to stdout.

  Examples
  ==========

  julia> println("Hello, world")
  Hello, world

  julia> io = IOBuffer();

  julia> println(io, "Hello, world")

  julia> String(take!(io))
  "Hello, world\n"
```

這也可以用來做基本搜尋，例如當你不確定某個函式的確切拼法時：

```julia-repl
help?> printline
search:

Couldn't find printline
Perhaps you meant println, pipeline, @inline or print
  No documentation found.

  Binding printline does not exist.
```
