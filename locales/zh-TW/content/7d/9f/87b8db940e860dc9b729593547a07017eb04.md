# 一般

- API 文件：[package regexp][package-regexp]
- 正規表達式語法：[regexp/syntax][regexp-syntax]
- 網站 [regex101.com][regex101] 提供了線上的正規表達式測試工具。
- 建議將正規表達式寫成以反引號包住的[原始字串常值][raw-string-literals]。

## 1. 辨識亂碼的日誌行

- 函式 [regexp.MatchString][fun-re-match-string] 或方法 [MatchString][method-match-string] 在這裡可能很有用。
- 在正規表達式中，`^` 這個字元會比對行或字串的開頭。

## 2. 分割日誌行

- 方法 [Split][regexp-split] 在這裡可能很有用。

## 3. 計算引號文字中包含 `password` 的行數

- 只要在正規表達式前面加上 `(?i)`，就能讓運算式的比對區分大小寫。
  這會設定 `i` 旗標。
  詳見[這篇教學][yourbasic-i-flag]。

## 4. 移除日誌中的雜訊

- 方法 [ReplaceAllString][replace-all-string] 在這裡可能很有用。

## 5. 為日誌行加上使用者名稱標記

- 方法 [FindStringSubmatch][find-string-submatch] 在這裡可能很有用。
