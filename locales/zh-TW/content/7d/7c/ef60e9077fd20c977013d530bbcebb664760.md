# 說明

請先確認你已經讀過 Exercism 網站上 [C 語言專屬文件][c-track]。這份文件涵蓋了設定這些練習所需開發環境的基本資訊。

## 資源

如果遇到問題，可以透過下列資源尋求協助：

- [StackOverflow][] 可以用來搜尋你的問題，看看是否已經有人問過。你也可以在上面提問和回答問題。
- [CPPReference][] 可以用來查詢 C 的概念、運算子、型別、標準函式庫函式等資訊。
- [TutorialsPoint][] 的 C 程式設計部分有和 CPPReference 類似的內容。
- K&R 的 [The C Programming][K&R] 一書是這門語言的原始出處，至今仍然很實用。

[c-track]: https://exercism.org/docs/tracks/c
[stackoverflow]: http://stackoverflow.com/questions/tagged/c
[cppreference]: https://en.cppreference.com/w/c
[tutorialspoint]: https://www.tutorialspoint.com/cprogramming/
[K&R]: https://www.amazon.com/Programming-Language-2nd-Brian-Kernighan/dp/0131103628/
