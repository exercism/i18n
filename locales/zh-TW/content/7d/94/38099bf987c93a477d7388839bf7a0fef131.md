# 指令

在這個練習中，你需要實作一些方法來操作程式語言的陣列。

## 1. 定義一個回傳空語言陣列的方法

定義`LanguageList.list`方法，它不接受任何引數，並回傳型別為`Array(String)`的空陣列。

```crystal
LanguageList.list()
# => []
```

## 2. 定義一個將語言加入陣列的方法

定義`LanguageList.add`方法，它接受 2 個引數（一個_語言陣列_和一個_語言_的字串字面值）。
這個方法應該回傳把新語言加到陣列末端後的陣列。

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. 定義一個從陣列移除語言的方法

定義`LanguageList.remove`方法，它接受 1 個引數（一個_語言陣列_）。
這個方法應該回傳移除最後一個項目後的陣列。
假設陣列至少會有一個項目。

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. 定義一個回傳陣列中第 n 個項目的方法

定義`LanguageList.at`函式，它接受 2 個引數（一個_語言陣列_和一個索引）。
這個方法應該回傳陣列中索引為 n 的語言。
假設該索引位置上一定有一個語言。

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. 定義一個剖析語言字串的方法

定義`LanguageList.parse`方法，它接受 1 個引數（一個以逗號分隔的語言字串字面值）。
這個方法應該回傳一個語言陣列。

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
