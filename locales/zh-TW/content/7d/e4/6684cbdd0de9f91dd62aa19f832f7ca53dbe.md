# 簡介

## 數字

摘自[使用手冊][man-types]

> jq 支援和 JSON 相同的一組資料型態：數字、字串、布林值、陣列、物件（用 JSON 的說法，就是只有字串鍵的雜湊），以及「null」。

我們把焦點放在**數字**上。

### 數字與數值運算子

所有數字，不論是不是整數，都是 IEEE754 雙精度浮點數。
這讓我們只有 53 位元的精度。

數字可以搭配一般常用的運算子：

- 算術：`+`、`-`、`*`、`/`、`%`
- 比較：`==`、`!=`、`<`、`<=`、`>=`、`>`
- 標準[數學函式][man-math]

  只有一個輸入的函式，可以用管線把值傳進函式

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  需要兩個輸入的函式會忽略輸入，改以參數接收這兩個輸入（回想一下，參數之間是以分號分隔）

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  分號是函式引數的分隔符，不是逗號。

### 其他`jq`運算式

要解這道練習，你需要認識條件運算式。

#### 條件運算式

`jq`使用[`if-then-else`運算式][if-then-else]來處理**條件運算式**。
作為一個_運算式_，它會被放在管線裡。

語法是：`if CONDITION then TRUE_EXPR else FALSE_EXPR end`。

`else`子句是選用的。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

其他條件用`elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
