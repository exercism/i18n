# 關於

方法可以擁有可變參數，讓呼叫端可以像一般參數一樣指定零個或多個引數。方法會以單一陣列接收這些引數。

若要讓參數成為可變參數，請在參數宣告中加入[`params`關鍵字](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params)：

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
