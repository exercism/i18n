# 指令

你的公司接下了從使用者輸入產生 CSV 紀錄的工作。

我們需要一個依照 [RFC 4180](https://tools.ietf.org/html/rfc4180) 所定義標準的 CSV 紀錄建立器。

雖然有正式的規格書存在，你的公司只需要實作以下功能：
- 建立新的紀錄建立器
- 將個別欄位加入紀錄
- 以基本跳脫處理序列化紀錄

基本的跳脫處理是指：

- 包含換行、雙引號與逗號的欄位，必須用雙引號包起來。

- 如果欄位是用雙引號包起來的，那麼欄位中出現的雙引號，必須在它前面再加上一個雙引號來跳脫。


## 1. 建立一個新的建立器

你需要實作`new`方法來建立新的建立器。

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. 將個別欄位加入紀錄

你需要實作`add`方法，將欄位附加到你的紀錄建立器。
`add`接受不可變的字串切片`&str`作為引數。

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. 以基本跳脫處理序列化紀錄

你需要實作`build`方法。
`build`會消耗建立器並回傳一筆 CSV 紀錄。
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
