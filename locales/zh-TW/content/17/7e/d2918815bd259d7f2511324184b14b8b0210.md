## Roc API

使用不可變的`React`值。每個操作都會回傳一個更新後的反應器；後續操作請沿用這個值。儲存格以`cell_id`識別，回呼則以`callback_id`識別。這兩個識別碼都是註冊時提供的字串。註冊與移除回呼時，都要提供這兩個識別碼來指定儲存格及其回呼。

計算函式會接收一串儲存格的值，順序與其`inputs`儲存格識別碼清單相同。成功時回傳`Ok(value)`，失敗時回傳`Err(message)`，並附上描述失敗原因的字串，例如輸入數量不正確或除以零。新增計算儲存格時，它依賴的儲存格必須已經存在。`add_compute`和`set_value`都會以`ComputeFailed({ cell_id, message })`回報計算錯誤。如果更新期間有計算失敗，就不會回傳更新後的反應器，也不會執行任何回呼；原本的反應器仍然可以使用。

回呼是型別為`React.CellValue, React.CallbackLog -> React.CallbackLog`的純函式。每個回呼會收到儲存格的新值和目前的日誌，然後回傳更新後的日誌。`set_value`接受一個包含`cell_id`、`value`和初始`log`的記錄，並回傳更新後的反應器以及最終的日誌。把每個回呼回傳的日誌傳給下一個回呼；回呼的執行順序並未指定。

`React.CallbackLog`是`Dict(Str, List(I64))`的別名：它會記錄每個回呼識別碼所收到的值。測試會為每次輸入更新傳入空的日誌，以檢查回呼恰好執行一次，或完全沒有執行。

註冊回呼並不會呼叫它。同一個回呼可以移除多次，而且不得影響其他回呼。一次更新中的所有回呼都必須看到最終且穩定的儲存格值。
