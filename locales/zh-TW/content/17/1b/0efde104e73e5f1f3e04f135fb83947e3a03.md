# 簡介

介面（interface）是一種型別，其中的成員定義了一組相關的功能。它讓類別的使用方式與實作保持距離，因而允許有多種不同的實作，或支援某些泛型行為，例如格式化、比較或轉換。

介面的語法和類別相似，差別在於方法只以簽章的形式出現，不提供主體。

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

介面定義的所有操作，都必須由實作該介面的類別實作。

介面通常包含實例方法。

Java 類別庫中除了上面示範的 `Cloneable` 之外，另一個介面的例子是 `Comparable<T>`。當集合需要預設的泛型排序順序時，就可以實作 `Comparable<T>` 介面。
