# 簡介

遞迴是一種在函式裡重複執行程式碼的方式，作法是讓函式呼叫自己。也可以把它看成另一種迴圈或疊代的做法。和迴圈一樣，我們會用布林運算式或`True`/`False`的判斷，來決定何時停止遞迴的執行。_不同於_迴圈的是，在 Python 中，沒有終止條件的遞迴無法無限執行下去。每次函式呼叫所使用的值，都會放在 Python 翻譯員堆疊上各自的堆疊框裡。如果函式呼叫的總數佔用的空間超過堆疊能容納的範圍，就會產生錯誤。

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

輸出結果會是

```
The step is 1
The step is 2
After recursion
```

有些情況用遞迴表達，會比用迴圈表達更容易閱讀，也更容易理解。
