# 簡介

`switch()` 函式可以簡潔地取代一長串 `if` ... `else if` 的比較。
切換所依據的變數最常見的是字串，若是字串，選擇器中的引號就可以省略。

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

請注意，只有在值留白時，選項才會往下「貫穿」，就像上面範例中的 `M`。
不需要像某些其他語言那樣加入 `break` 敘述。

切換 `character` 型別時，最後一個值是預設值，就像這裡這樣。
使用整數型別時，則無法指定預設值。

## `dplyr` 中的函式

base R 中的 `switch` 相當有限：它只能對單一輸入做完全相符的比對。
這在 1993 年 R 初次發布時看似合理，但以現代用途來說需要改進。

~~~~exercism/note
正如 [`Conditionals`][concept-conditionals] 概念中所提到的，`tidyverse` 套件集合的設計目的，是在不影響向後相容性的前提下，補充（有時取代）base R 的功能。

只要在程式碼最上方加入 `library(dplyr)`（載入單一套件）或 `library(tidyverse)`（載入整個集合），就能將 `dplyr` 套件引入作用域。

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

`dplyr` 套件提供了兩個與 `switch` 相關的額外函式。

### `recode_values` 與 `replace_values` 函式

這兩個相關的函式可以將舊值對應到新值，做法類似向量化的 switch。

兩者主要的差別在於，`recode_values()` 會建立一個全新的向量，而 `replace_values()` 則允許對現有向量做局部更新。

比對仍然必須完全相符，但是：

- 左邊的選項可以是向量，只要其中任何一個元素相符，輸入就算相符。
- 左邊的選項與右邊的結果以波浪號 `~` 連結，而不是 `=`。
- 在所有情況下都可以指定預設值。

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when` 函式

`case_when` 將 `case_match` 的語法再推進一步，允許在 `~` 左邊使用任何邏輯運算式。

輸入向量（下面範例中的 `x`）不是以引數提供，只需要事先定義好即可。

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()` 函式也是 `dplyr` 的一部分。
