# 說明

你正在開發一套健康監測系統。為此，你需要追蹤使用者的健康統計資料。

你會從`impl`區塊中一些尚未實作的函式開始，另外還有以下的 struct 定義：

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

你的目標是實作`impl`區塊中`User` `struct`裡那些尚未實作的方法。

例如，`new`方法應該回傳一個`User`實例，並帶有指定的名稱、年齡和體重值。

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

`weight`方法應該回傳`User`的體重。

```rust
bob.weight();
// Returns: 155.2
```

`set_age`方法應該設定`User`的年齡。

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
