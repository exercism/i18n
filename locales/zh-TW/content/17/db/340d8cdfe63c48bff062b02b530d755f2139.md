# 關於

Common Lisp 為程式設計師提供了數種不同的條件式，可以依它們支援的「分支」數量來分類。

此外，和許多其他的程式語言不同，Common Lisp 中的所有條件式都是_運算式_，而不是敘述。
這表示所有 Lisp 條件式都會求出某個值，因此可以直接當成具體的參數來使用。

舉例來說：

```lisp
;; Doubles x when it's even
(* x (if (evenp x) 2 1))
```

## 單一分支條件式

`when`和`unless`這兩個條件式，只有在提供的測試結果分別為 true 或 false 時，才會對某段程式碼求值；否則會求值成`nil`。

測試運算式後面可以放多個運算式。

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

## 雙分支條件式

`if`條件式在測試為 true 時，會對主體的第一個運算式求值，否則對第二個求值。

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

請注意，then 和 else 這兩個子句都只能包含單一運算式。

## 多分支條件式

Lisp 的「超級條件式」是`cond`，它可以有無限多個分支。
每個分支都有一組測試條件和主體運算式，並由一對額外的括號包住。
如果所有測試都求值為 false，就會回傳`nil`。

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

請注意，測試運算式後面的運算式數量沒有限制。 


如果你只是想用一個值去比對多個分支，可以使用更簡潔的`case`運算式。
如果沒有任何情況相符，就會回傳`nil`。
`t`和`otherwise`都可以用來當作涵蓋所有情況的分支：

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

請注意，和`cond`一樣，測試運算式後面的運算式數量沒有限制。

## 隱形條件式

Common Lisp 中的布林運算`and`和`or`是會短路的巨集，可以用來減少某些條件運算式的重複。

`and`巨集只要遇到一個 false 值，就會立刻回傳`nil`；否則會回傳`and`中最後一個 true 值：

```lisp
(and 42 "Magic" :cool) ; => :COOL
(and () "Magic" :cool) ; => NIL
```

`or`巨集會回傳它遇到的第一個 true 值，如果沒有任何 true 值，則回傳`nil`：

```lisp
(or () 42 nil)  ; => 42
(or () NIL nil) ; => NIL
```

## 我累壞了……

如前面提到的，當`case`敘述中沒有任何一個分支相符，而且沒有`otherwise`子句時，就會回傳`nil`。
不過，有時候無法符合任何分支的情況應該被視為錯誤，這正是`ecase`（代表**窮盡**比對）派上用場的地方。

它的用法和`case`完全相同，但當沒有任何相符時，會發出錯誤，而不是回傳`nil`。

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => NIL

(ecase 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => ERROR: ELDER-BEAST fell through ECASE expression. Wanted one of (CAT BIRD DOG).
```
