# 簡介

你可以使用 `java.util.Random` 類別的實例在 Java 中產生隨機數字。

## 隨機整數

你可以使用`nextInt()`方法產生隨機整數。
這會產生一個介於`Integer.MIN_VALUE`到`Integer.MAX_VALUE`範圍內的值。

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

如果要限制產生值的範圍，可以使用`nextInt(int)`。
這會產生一個從`0`（包含）到指定上界（不包含）之間的值。

例如，這會產生一個從`0`到`9`的隨機數字。

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

而這會產生一個從`10`到`19`的隨機數字。

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## 隨機浮點數

你可以使用`nextDouble()`方法產生隨機浮點數。
這會產生一個介於`0.0`到`1.0`範圍內的值。

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

而這會產生一個從`100.0`到`200.0`的隨機數字。

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
