# 類別

類別是 PHP 中組織程式碼的單位。
代表某個項目行為的程式碼，或是代表某個流程行為的程式碼，都可以群組在一起成為一個類別。
依照慣例，指派給類別的函式稱為 `methods`。

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

類別會用 `new` 關鍵字來實例化，這會為類別實例配置記憶體，並呼叫該類別的建構函式。
實例化後的類別可以指派給變數。
若要呼叫類別實例的方法，可以使用 `->` 存取運算子。

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

實例化的類別可以使用特殊的 `$this` 變數來參照自己的實例。
類別也可以擁有屬性，這些屬性的作用就像綁定在類別物件實例上的變數。
這些屬性可以從內部或外部參照。

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
