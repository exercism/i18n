# 說明

你是海岸巡邏艦上的訊號兵。今天要在晨間值班開始前，把側背包裡需要的五個小詞準備好。

## 1. 把值加上引號

航海日誌會以 *Factor 原始形式* 記錄每一筆觀測，也就是解析器之後讀回來的同一段文字。定義`quote-value`，把任何值轉成它的原始形式字串。

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. 剝除旗標外框

進來的訊號旗兩端各有一個標記字元框住。定義`flag-body`，回傳兩個標記*之間*的所有內容：去掉第一個字元，去掉最後一個字元。

請回傳切片（一種檢視），不要複製。

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. 切分旗標

每個旗標都帶有一段簡短的前綴代碼，後面接著資料內容。定義`split-flag`，接收一個旗標和一個標頭長度，並回傳標頭切片與主體切片*兩者*。

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. 用兩個讀數進行三角定位

連續兩個訊號讀數可以推導出三項測量值：兩者的*差值*`a - b`、*中點*`(a + b) / 2`，以及*比值*`a / b`。每一項測量都會用到這兩個讀數。

定義`triangulate`，從一對讀數回傳這三項結果。

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. 彙總三個讀數

連續三個讀數會彙總成它們的**總和**、**乘積**與**最大值**。每一項統計都會用到這三個讀數。

定義`triangle-stats`，回傳這三項結果。

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
