# 指令

在這個練習中，你在一個提供外送的披薩店工作。

你們提供三種披薩：

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

顧客也可以用少許額外費用加選兩種額外的選項：

1. 額外醬料：\$1
1. 額外配料：\$2

當顧客下訂單時，如果他們只訂一到兩個披薩，就會加收一筆額外費用：

- 1 個披薩：\$3
- 2 個披薩：\$2

你有三個任務，每個任務都會處理披薩和它們的價格。

## 1. 定義披薩的型別和選項

定義 `Pizza` 自訂型別，用來表示不同種類的披薩和選項：

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

`ExtraSauce`和`ExtraToppings`應該包住`Pizza`型別。

## 2. 計算披薩的價格

實作`pizza_price`函式來計算披薩的價格：

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. 計算訂單的價格

實作`order_price`函式來計算披薩訂單的價格：

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
