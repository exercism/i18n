# 執行測試

安裝好`sbt`之後，就可以用下列指令在命令列執行測試：

```bash
$ sbt test
```

請注意，如果每次都執行`sbt test`，速度會很慢，因為每呼叫一次就會重新初始化一次`sbt`。

`sbt`的運作方式像一個 shell，啟動之後你就可以在裡面執行各種指令。

舉例來說，每當原始碼檔案有變動時，你可以用`sbt`重新執行測試：
```bash
$ sbt
>~ test
```

請注意，除了第一個測試以外，其他測試都已停用，方便你先從它開始著手。
要繼續完成其他測試，只要把每個測試案例開頭的`pending`關鍵字刪掉就可以了。

想進一步了解`sbt`，請參考[這裡](https://www.scala-sbt.org/)。


測試也可以在下列 IDE 中執行

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA 搭配 Scala 外掛](https://www.jetbrains.com/idea/)
