# 簡介

許多程式語言都有 `null` 或 `none` 之類的方式來表示不存在的值。由於 Julia 在設計上要處理大量（而且往往雜亂）的資料，它提供了多種表示「空無」的形式。

整體目標是：在遇到缺失或可疑的值時把它標記出來，然後繼續執行，而不是引發例外。

## `nothing`

如果某個值真的不存在，就會用 `nothing` 來表示。這大概最接近 C（`NULL`）或 Python（`None`）的做法。

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

所以 `nothing` 是型別 `Nothing` 的單例值，而且我們可以對它進行測試。

`nothing` 一個常見的用途，是當作只為了副作用（列印、網路設定等等）而使用的函式之回傳（非）值。

## `missing`

有些情況下，某個值理論上存在，但我們不知道它是什麼，這時就會用 `missing`。舉例來說，在統計道路上的車輛時，人工觀測員可能需要休息，自動感測器也可能故障，但車流仍然持續不斷。

因此 `missing` 是一種佔位符，提醒人們必須決定該怎麼處理資料中的這段落差。

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

很少其他程式語言內建這項功能，但 R 的 `NA` 或 SQL 的 `NULL` 是相當接近的類似物。

如果資料中含有 `missing` 值，運算式通常預設會回傳 `missing`。如果你想忽略這些值，可以用 `skipmissing()` 函式明確表達這個意思：

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

由於 `skipmissing` 會建立疊代器，如果你需要向量，請用 `collect()` 包住它。

有時候，把 `missing` 值替換成某個預設值會很有用。`@coalesce()` 巨集正好適合這個用途，它會回傳第一個不是 `missing` 的值（如果沒有其他值，就回傳 `missing`）。

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

`NaN` 是「Not a Number」的縮寫，用來標記原本預期會是數字、卻發生運算問題的情況。

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

只要資料中含有 NaN，任何計算的結果都會是 `NaN`。

目前沒有專門移除 `NaN` 值的函式，但標準的 `filter()` 函式可以簡單做到這件事。只有符合給定條件（也就是條件為 `true`）的值，才會被複製到結果陣列中：

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
