# 關於

Gleam 標準函式庫中的`gleam/order`模組包含了`Order`型別，用來比較值。

`Order`的定義看起來像這樣：

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

這個型別有三個變體，分別用來表示某個值與另一個值之間的關係：

- `Gt`：這個值比另一個值_大_。
- `Eq`：這個值與另一個值_相等_。
- `Lt`：這個值比另一個值_小_。

如果某個資料型態可以比較大小，模組通常會定義一個回傳`Order`值的`compare`函式。例如，`gleam/float`和`gleam/int`分別定義了可處理浮點數與整數的`compare`函式。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

排序函式（例如`list.sort`）通常會接收一個回傳`Order`值的函式，讓呼叫者自行決定該如何排序這個陣列。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
