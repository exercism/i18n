# 簡介

陣列是 Elixir 語言的內建型別。它們被視為一種基本型別，以方括號表示。陣列可以是空的，也可以存放任意數量、任意型別的項目。例如：

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir 將陣列實作成連結串列，其中每個節點儲存兩個值：第一個項目，以及一個包含其餘所有項目的陣列。陣列中的第一個項目稱為_頭部_，其餘項目的陣列則稱為_尾部_。我們可以在程式中使用這種表示法：

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

我們可以使用 _`[head | tail]`_表示法，把元素加到陣列的最前面：

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

`Kernel`模組中有幾個處理陣列的函式，另外還有整個`List`模組。

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
