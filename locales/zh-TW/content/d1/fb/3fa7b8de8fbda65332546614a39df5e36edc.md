# 指令補充

## 提示

你需要實作`responseFor`函式，它會針對給定的輸入回傳 Bob 的回應。如果你不確定型別，可以使用提供的簽章，但別讓它限制你的創意：

```haskell
responseFor :: String -> String
```

想解開這個練習，你可以先閱讀：

- [守衛][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

這個練習處理的是文字資料。基於歷史因素，Haskell 的`String`型別等同於`[Char]`，也就是字元的陣列。若要更有效率地處理文字資料，可以使用`Text`型別。

作為這個練習的選用延伸，你可以

- 閱讀 Haskell 中的[字串型別](https://haskell-lang.org/tutorial/string-types)。
- 在 package.yaml 的相依套件清單中加上`- text`。
- 用[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)匯入`Data.Text`：

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- 現在你可以寫出例如`responseFor :: Text -> Text`，並以例如`T.isSuffixOf`取用`Data.Text`的組合子。
- 查閱[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的說明文件，
- 接著你可以在 Bob.hs 中把所有`String`取代為`Text`：

    ```haskell
    responseFor :: Text -> Text
    ```

這部分完全是選用的。
