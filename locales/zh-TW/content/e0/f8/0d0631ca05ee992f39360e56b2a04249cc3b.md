# 範例

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

以點開頭的行是_指示詞_：這些是給組譯器的指令，而不是給處理器的。
`.equ` 把數字 16 命名為`FRAME_SIZE`。
`.text` 表示接下來的是程式碼。
`.global` 讓標籤`is_triple`可以被這個檔案之外的程式碼看見，這樣其他程式碼就能呼叫它。
你可能也會看到`.globl`，它的意思完全相同。

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` 會檢查 `a² + b² = c²` 是否成立，成立就回傳 1，否則回傳 0。
例如，`(6, 8, 10)` 會得到 1，因為 `36 + 64 = 100`。
標籤`is_triple`標出了函式的起始位置。
呼叫它時，`a`、`b` 和 `c` 分別放在暫存器 `a0`、`a1` 和 `a2` 裡。

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

暫存器 `ra` 存著_返回位址_，也就是結束時要回到呼叫者中的哪個位置。
每次 `call` 都會覆寫 `ra`，所以我們先把它存到_堆疊_上。
堆疊往位址較小的方向成長，所以從堆疊指標`sp`減去 16，就能為我們保留 16 個位元組。
（`sp` 必須永遠是 16 的倍數。）
我們也儲存了 `b` 和 `c`，因為我們呼叫的函式可以改動 `a` 系列暫存器的值。

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` 已經在 `a0` 裡了，也就是 `square` 預期收到輸入的地方。
`call` 會把 `ra` 設成下一道指令，然後跳到 `square`，而 `square` 會把結果放在 `a0` 裡回傳。

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

我們從堆疊把 `b` 載回來，將它平方，再加到 `a * a`。

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

當 `a² + b² = c²` 成立時，這個差值恰好為零。
`seqz`（「等於零則設定」）會把這個結果變成 1 或 0。

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

我們還原 `ra`，並交還那 16 個位元組的堆疊空間。
接著 `ret` 會跳到 `ra` 裡的位址，回到呼叫者。

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` 沒有呼叫其他函式，所以 `ra` 保持不變，也沒有東西需要儲存。
它沒有標上 `.global`，因為只有 `is_triple` 會用到它。
