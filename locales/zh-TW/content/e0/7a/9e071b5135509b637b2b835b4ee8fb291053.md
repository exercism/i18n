# 使用說明

在這個練習中，你將檢查網路論壇上使用者帳號的權限。這個論壇支援三種不同的權限：

- 閱讀
- 撰寫
- 刪除

論壇上有三種帳號類型，每種都有不同的預設權限：

- 訪客：可以閱讀文章。
- 使用者：可以閱讀及撰寫文章。
- 版主：可以閱讀、撰寫及刪除文章，擁有所有權限。

有時候個別權限可以被調整，例如可以讓訪客帳號額外獲得撰寫文章的權限；又或者撤銷某個帳號的所有權限，該帳號就會變成不具備任何權限。

## 1. 取得帳號類型的預設權限

首先，定義一個`AccountType`列舉來代表三種帳號類型：`Guest`、`User`與`Moderator`。

接著，定義一個`Permission`列舉來代表三種權限類型：`Read`、`Write`、`Delete`，以及另外兩個：`All`代表擁有所有權限，`None`代表不具備任何權限。

然後實作（_static_）`Permissions.Default()`方法，回傳特定帳號類型的預設權限：

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. 授予權限

實作（_static_）`Permissions.Grant()`方法，用來授予（新增）一項權限：

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. 撤銷權限

實作（_static_）`Permissions.Revoke()`方法，用來撤銷（移除）一項權限：

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. 檢查權限

實作（_static_）`Permissions.Check()`方法，接收目前帳號的權限，並檢查該帳號是否被授權擁有指定的權限：

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
