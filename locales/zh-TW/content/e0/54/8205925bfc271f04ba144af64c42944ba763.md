# 括號的注意事項

Tcl 是一門[非常簡單的語言](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm)，但它的翻譯員解析程式碼的方式有幾個很棘手的邊界情況。

## 大括號

大括號在 Tcl 裡只是把一段文字括起來的方式，那段文字可以被解讀成程式碼或資料。在大括號內可以出現巢狀的大括號，但巢狀的大括號必須成對平衡。Tcl 的 man page 這樣寫道：

> 大括號可以在單字內巢狀：每多一個左大括號，就必須多一個右大括號（不過，如果單字內的左大括號或右大括號是_以反斜線跳脫_的，那麼在尋找對應的右大括號時就不會把它計入）。

那裡的用字相當精確：如果你想留下沒有配對的左大括號或右大括號字元，就必須用反斜線將它跳脫。所以不要這樣寫：
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
你必須這樣寫
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

這在 Tcl 解析註解的方式上可能會有問題，而這種方式和大多數語言不同。更多討論請見 [Tcl wiki](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments)。

## 方括號

同樣地，由於 Tcl 用方括號來做[命令替換](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11)，即使是在雙引號字串內，你也得小心跳脫左方括號。

## 小括號

除了[關聯式陣列變數](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12)之外，小括號只是一般的字元。
