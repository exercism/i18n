## 一般

- Python 官方文件的[控制流程工具][control flow tools]和 Real Python 的[條件判斷][real python conditionals]教學，都是很好的起點。
- Python 官方文件的[布林運算][boolean operations]是複習`bools`的好地方，Real Python 的[布林值][python booleans]教學也是。
- Python 官方文件的[比較][comparisons]和[比較範例][python comparisons examples]可以幫你好好複習比較。

## 1. 檢查臨界狀態

- 比較運算子（[複習比較][comparisons review]）和布林運算（[concept:python/bools]()）可以組合起來，並搭配條件判斷使用。
- 條件運算式的結果必須是`True`或`False`。
- 當所有條件判斷都回傳`False`時，可以用`else`執行對應的程式區塊。

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. 判斷功率輸出範圍

- 比較運算子可以組合起來，並搭配條件判斷使用。
- 決策「分支」可以使用任意數量的`elif`敘述。
- 每個「分支」可以有各自的`return`，不過 lint 工具可能會認為這是「不好的寫法」。
- 如果 lint 工具提出警告，可以考慮把某個分支的輸出指定給一個共用的變數，再`return`該變數。

## 3. 失效安全機制
