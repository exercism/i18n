# 簡介

在 Java 中，`null`常值用來表示沒有值。

Java 的基本型別都有預設值，因此永遠不會是`null`。依照慣例，它們會以小寫字母開頭，例如`int`。

參考型別則會儲存物件所在的記憶體位址，本身的值可以是`null`。它們通常以大寫字母開頭，例如`String`。

嘗試把`null`指定給基本型別的變數，會導致編譯時期錯誤，因為這類變數永遠存放著所指定型別的基本值。

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

把`null`指定給參考型別的變數則不會產生編譯時期錯誤，因為參考型別的變數可以為`null`。

```java
//No error will occur as the String variable str is nullable
String str = null;
```
