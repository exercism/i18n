# 簡介

## 介面是一組方法

最簡單的形式下，**介面型別**是一組方法簽章。
以下是介面定義的範例，其中包含 `Add` 和 `Value` 兩個方法：

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

介面定義中的參數名稱（例如 `increment`）可以省略，但保留它們通常能提升可讀性。

Go 的介面名稱不含 `Interface` 或 `I` 這個字。
它們通常以 `er` 結尾，例如 `Reader`、`Stringer`。

## 實作介面

任何定義了介面方法的型別，都會自動隱含地「實作」該介面。
Go 裡沒有 `implements` 關鍵字。

以下型別實作了上面看到的 `Counter` 介面。

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

對實作介面來說，方法用的是值接收器還是指標接收器都無所謂。
（如果你對這些概念不太確定，可以複習[方法][concept-methods]的概念。）

> 介面型別的值可以存放任何實作了這些方法的值。[^1]

這表示 `Stats` 現在可以用在所有需要 `Counter` 介面的地方。

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

因為介面是隱含實作的，一個型別可以輕鬆實作多個介面。
它只需要定義所有必要的方法就好。

## 空介面

Go 有一個非常特別的介面型別：**空介面**，它不包含任何方法。
空介面寫成這樣：`interface{}`。
`any` 是 `interface{}` 的別名，而且更常被使用。

由於空介面沒有任何方法，每個型別都會隱含地實作它。
這在定義能泛型地接受任何值的函式時很有幫助。
這種情況下，函式的參數會使用空介面型別。
