# 提示

## 一般

- 前六個整數引數會透過`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`傳遞給函式。
- 記憶體中的位址是 64 位元（8 位元組）的值。

## 1. 為每個物品建立一筆項目

- 前六個整數引數會透過`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`傳遞給函式。
- 記憶體中的位址是 64 位元（8 位元組）的值。
- 第六個之後的所有整數引數都會透過堆疊傳遞，第一個位於`rsp + 8`。
- 額外引數的數量等於分類的數量，而這個數量會透過`r9`傳遞。
- 你可以用迴圈逐一加入額外引數，也可以搭配使用[movsq][movs]和[rep][rep]。

## 2. 為每月的物品清單保留空間

- 前六個整數引數會透過`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`傳遞給函式。
- 記憶體中的位址是 64 位元（8 位元組）的值。
- 在呼叫配置函式之後，你需要知道陣列的大小，才能將它的位元組清零。
- 當你呼叫外部函式時，它可能會修改任何_呼叫端儲存的暫存器_中的值。
- 你可以使用[push][push]或直接操作`rsp`來將暫存器的值保存在堆疊中。
- 任何對`rsp`的修改，包括使用`push`，都必須在函式回傳前還原，無論是使用[pop][pop]還是直接變更`rsp`。

## 3. 在每月清單中插入一筆物品

- 前六個整數引數會透過`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`傳遞給函式。
- 記憶體中的位址是 64 位元（8 位元組）的值。
- 無法放入暫存器的值會透過堆疊傳遞給函式。
- 每個物品的項目佔用 120 位元組的空間，遠大於暫存器的最大大小（8 位元組）。
- 透過堆疊傳遞的引數可以在從`rsp + 8`開始的位址中找到。
- 你可以用迴圈將值加入目的記憶體位置，也可以搭配使用[movsb][movs]和[rep][rep]。

## 4. 印出物品

- 前六個整數引數會透過`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`傳遞給函式。
- 記憶體中的位址是 64 位元（8 位元組）的值。
- 開頭字串是選用的，你可以改以`0`呼叫列印函式。
- 如果將開頭字串傳遞給列印函式，它的長度最多只能有 50 個 ASCII 字元，且已包含 NUL 結束字元（值為`0`）。
- 每當你呼叫函式時，都必須在堆疊上為第六個之後的任何引數保留空間。
- System V ABI 規定，在呼叫函式之前，堆疊應該對齊 16 位元組，這對外部函式尤其重要。
- 清單中每個物品的項目佔用 120 位元組的空間。
