# 布林

Haskell 有一個型別稱為[`Bool`][bools]，它是`True`與`False`的列舉。

## 邏輯運算子

Haskell 有三個邏輯運算子（`not`、`||`、`&&`），它們可以組合布林值，形成會產生不同值的運算式。

### 且（`&&`）

Haskell 中的[_且_運算子][and]以`&&`表示，如果兩個值都是`True`，就回傳`True`；否則回傳`False`。
使用_且_運算子時，會把一個布林值放在`&&`的右邊，另一個放在左邊。

```haskell
True && True
-- -> True

True && False
-- -> False
```

### 或（`||`）

Haskell 中的[_或_運算子][or]以`||`表示，只要給定的值中**至少有一個**是`True`，就回傳`True`。
如果兩個值都是`False`，就回傳`False`。
使用_或_運算子時，應該把一個布林值放在`||`的右邊，另一個放在左邊。

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### 非（`not`）

Haskell 中的_非_運算子以`not`表示：如果給定的布林值是`False`，就回傳`True`；如果提供的是`True`，則回傳`False`。
使用_非_運算子時，應該把一個布林值放在運算子（`not`）後面。

```haskell
not True
-- -> False

not False
-- -> True
```

## 使用括號（`()`）

處理布林值時，你可以用括號決定要先求值哪個布林值。
使用括號的方式不同，結果也會不一樣。
在 Haskell 中，括號內的內容會先被求值。

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

由於括號內的內容會先被求值，在下面這個例子裡，_非_運算子會套用到括號內的運算式。

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
只有當括號會影響結果時，才應該使用括號；否則就該省略。
~~~~
