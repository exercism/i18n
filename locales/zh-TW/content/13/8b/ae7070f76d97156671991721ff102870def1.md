# 函式庫

Exercism 的目標，是教導學習者掌握程式語言的語法、慣用語，以及標準函式庫的[流暢度](/docs/using/product/fluency)。這裡*刻意不*提及外部（非內建）函式庫，因為那屬於*熟練度*的範疇。因此，除了少數例外，練習必須能在不使用函式庫的情況下解出。

## 支援函式庫的理由

軌道仍可能想支援函式庫的理由有幾個：

1. 這種語言的標準函式庫（非常）精簡。Rust 就是這類語言的例子。
2. 函式庫能額外提供測試功能。例如，有個函式庫新增了對基於屬性的測試的支援。
3. 這個練習只能靠函式庫才能解出。這類練習的例子是 [lens-person 練習](https://exercism.org/exercises/lens-person)，在大多數語言中，它只能靠函式庫才能解出。

## 在測試執行器中支援函式庫

由於測試執行器在執行時無法連上網際網路，因此不可能在執行時下載函式庫。這個問題的**唯一**解法，就是在建置時安裝／下載函式庫，因為那時你*確實*能連上網際網路。實務上，這表示你需要在 Dockerfile 裡安裝／下載函式庫。

舉例來說，[Prolog 測試執行器的 Dockerfile](https://github.com/exercism/prolog-test-runner/blob/ed7447a7518ede6ee3405e649f50aaec828e318b/Dockerfile) 會安裝`date_time`函式庫：

```dockerfile
RUN swipl pack install date_time -y
```

## 說明文件

如果你的軌道支援函式庫，應該在[軌道文件](/docs/building/tracks/docs)中加以說明。另外也請在[`exercises/shared/.docs/help.md`文件](/docs/building/tracks/shared-files#file-help-md)中，用它的完整網址連結到本文件。
