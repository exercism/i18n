# 安裝

C 語言學習軌道要求你的系統上安裝了以下軟體：

* 現代的 C 編譯器
* Make 建置工具

Apple 的 Xcode IDE 把編譯器和原生建置系統整合進單一的 IDE（整合開發環境）。
Linux 環境通常則是把編譯器和原生建置系統各自以獨立的命令列工具提供。

## Linux

Linux 使用者需要 gcc 或 clang 作為編譯器，原生建置則需要`make`。
Make 在大多數 unix 系統上都已預先安裝，不過通常可以透過你的套件管理器取得。
在以 Debian 和 Ubuntu 為基礎的發行版上，若尚未安裝，可以用 `sudo apt-get install build-essential` 安裝所有需要的東西。

## MacOS

MacOS 使用者可以用 [Homebrew][]，透過 `brew install gcc` 或 `brew install llvm` 安裝 gcc 或 clang。

## Windows

建議 Windows 10 使用者使用 [Windows Subsystem for Linux][]，並依照上面 Linux 的說明繼續操作。

如果你使用的是較早版本的 Windows，或無法使用 WSL Bash，可以考慮改用 [MSYS][] 或 [mingw-w64][]。

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
