# 提示

## 一般

- 這篇[文章][time-overview]是 .NET 上日期、時間與時區的總覽。
- `DateTime` 結構的說明文件在[這裡][date-time]。

## 1. 為管理員提供 UTC（Universal Coordinated Time）預約時間的本地時間對應值

找一個適合的 `DateTime` 成員，把 UTC 轉換成本地時間。

## 2. 在紐約、倫敦與巴黎安排預約

使用 [`TimeZoneInfo`][time-zone-info] 類別，並從任務說明中挑選適當的時區 id。要記得，Windows 和 OSX/Linux 的 id 不一樣。

方法[`RuntimeInformation.IsOSPlatform()`]是讓程式碼路徑能針對不同作業系統運作的關鍵。

## 3. 在預約前以固定間隔向客戶發送提醒

其中一種做法是使用 [`TimeSpan`][time-span] 對時間做運算。

## 4. 如果日光節約時間最近有變更，我們會發送訊息提醒客戶。

`TimeZoneInfo` 有適合的方法可以處理這種情況。

## 5. 使用本地日期時間格式輸入預約

看看`DateTime.Parse()`和[`CultureInfo`][culture-info]。
