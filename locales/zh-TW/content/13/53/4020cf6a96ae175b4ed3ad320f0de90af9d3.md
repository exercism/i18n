# 變數簡介

## 變數

_變數_是存放資料的地方。
Bash 有兩種資料：字串和陣列。
我們之後會再談到陣列。

你可以像這樣指定變數：

```bash
name="value"
```

~~~~exercism/note
**重要**，等號兩邊_不能有空格_！

等號兩邊有空格時，就像這個例子：

```bash
x = 10
```

bash 會用`=`和`10`這**兩個引數**去呼叫**命令**`x`！
~~~~

變數也可以稱為_參數_。
這份文件會交替使用這兩個詞。

bash 會使用或設定的幾個重要參數包括：

* `PATH`：以冒號分隔的目錄清單，用來尋找外部命令。
* `IFS`：「內部欄位分隔符」。
   我們會在下面看到它的用途。
* `PWD`：你目前的工作目錄。
   它的值會和 `pwd` 命令的輸出相同。
* `RANDOM`：介於 0 和 32767 之間的偽隨機整數。
* `BASH_VERSION`：正在執行的 bash 實例的版本字串。

## 變數名稱

變數名稱由_大寫字母、小寫字母、數字和底線_組成。
開頭不能是數字。

~~~~exercism/caution
最佳做法是**避免使用全大寫的變數名稱**。
shell 會把這個慣例用在它的參數上，而你不會想不小心覆蓋掉具有特殊意義的 shell 參數。

## 參數展開

你可以用 `$varname` 這種語法取得參數的值。

```bash
x=10
echo "The value of x is $x"
```

為了避免變數名稱和周圍的文字混淆，你可以用大括號把變數名稱包起來。
例如要印出字串 `10x10`

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

有些[風格指南][google-style-guide]建議在大多數情況下使用大括號，以提升可讀性和一致性。

## 位置參數

就像我們在[命令與引數][cmds-args]這個單元討論過的，命令可以接受引數。
Bash 腳本也不例外。
傳給目前這個 bash 實例的引數稱為_位置參數_。
你可以用這些特殊參數取得它們：

* `$1`：第一個位置參數
* `$2` ... `$9`：後續的參數
* `${10}` ...：兩位數以上需要用大括號。
* `$0`：目前腳本的名稱。

傳給 shell 函式的引數也是位置參數，處理方式完全相同。
我們之後的單元會再深入了解函式。

### 特殊位置參數

有幾個_特殊參數_可以幫助你處理位置參數。

* `$#` 會展開成位置參數的_數量_。
* `"$@"` 會展開成所有位置參數的清單，每個參數各自成為一個獨立的詞。
* `"$*"` 會展開成單一字串，把所有位置參數用某個字元連接起來。
  * 用來連接的字元是 `$IFS` 變數的_第一個字元_，預設是空格。

`"$@"` 是把位置參數傳給另一個命令時最安全的做法，可以確保它們被安全地加上引號。
它也是你用來逐一走訪位置參數的方式：

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

實務上，`"$@"` 比 `"$*"` 更常被使用。

## 命令替換

你在 bash 腳本裡很常做的一件事，就是捕捉某個命令的輸出並存進變數。
要做到這件事，你會用到_命令替換_。

```bash
var=$(command)
```

例如，要把字串轉成大寫，你可以這樣做：

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## 參數展開的更多用法

Bash 內建許多工具可以操作變數和字串，讓你不需要呼叫外部命令。

* 將文字轉成大寫。
  在前一節我示範了如何用 `tr` 把一些文字轉成大寫。
  要在 bash 裡做到這件事：

  ```bash
  echo "${text^^}"
  ```

  同樣地，`${text,,}` 會把值轉成小寫。

* 當變數是空的時，提供一個預設值。

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* 搜尋並取代。

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

還有許多其他有趣的參數展開：擷取子字串、取得字串長度、_指派_預設值、從值的開頭或結尾移除文字等等。
你可以在[手冊][param-exp]裡讀到相關說明。
