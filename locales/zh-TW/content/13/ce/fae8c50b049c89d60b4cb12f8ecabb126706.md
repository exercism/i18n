# 指令

在啟動雷射陣列之前，你必須預測水晶被擊中的確切順序，並以它們的樣本 ID 辨識。

## 範例測試案例

看看這個水晶陣列的配置：

```json
{
  "start": { "x": 0, "y": 0, "angle": 0 },
  "prisms": [
    { "id": 1, "x": 10, "y": 10, "angle": -90 },
    { "id": 2, "x": 10, "y": 0, "angle": 90 },
    { "id": 3, "x": 30, "y": 10, "angle": 45 },
    { "id": 4, "x": 20, "y": 0, "angle": 0 }
  ]
}
```

## 發生了什麼事

雷射從原點`(0, 0)`出發，以 0° 的角度水平向右發射。
以下是光束路徑的逐步說明：

**步驟 1**：光束沿著 x 軸（y = 0）前進，並在位置`(10, 0)`首次遇到**水晶 #2**。
這顆水晶的折射角度是 90°，也就是讓光束垂直於目前的路徑轉向。
光束原本以 0° 前進，現在被轉向 90°（正上方）。

**步驟 2**：光束現在從位置`(10, 0)`垂直向上前進，並在位置`(10, 10)`擊中**水晶 #1**。
這顆水晶的折射角度是 -90°，會讓光束相對於目前的方向轉 -90°。
光束原本以 90° 前進，所以折射後變成 0°（90° + (-90°) = 0°），再次水平向右前進。

**步驟 3**：光束從位置`(10, 10)`水平前進，並在位置`(30, 10)`遇到**水晶 #3**。
這顆水晶讓光束折射 45°，把方向改變成 45°。
光束繼續前進，進入陣列之外的空間。
