# 簡介

## 位元操作

Java 提供了運算子，可以操作`byte`、`short`、`int`、`long`或`char`的位元。

### 移位運算子

使用`<<`將位元向左移位，使用`>>`向右移位。

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

`<<`運算子一律在右側插入 0。不過，`>>`會插入與最左邊位元相同的位元（若為負數則為 1，若為正數則為 0）。

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

向右移位時若想插入 0，請改用`>>>`。

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### 位元運算

#### 位元 AND

位元 AND（`&`）運算子接受兩個值，並對每個位元執行 AND。它會比較第一個值的每個位元，以及第二個值中相同位置的位元。如果兩者都是 1，結果的位元就是 1。否則，結果的位元就是 0。

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### 位元 OR

位元 OR（`|`）運算子接受兩個值，並對每個位元執行 OR。它會比較第一個值的每個位元，以及第二個值中相同位置的位元。如果其中任一個位元是 1，結果的位元就是 1。否則就是 0。

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### 位元 XOR

位元 XOR 運算子（`^`）會對兩個值執行位元 XOR。和位元 AND、位元 OR 運算子一樣，它會比較第一個值的每個位元，以及第二個值中相同位置的位元。如果只有其中一個是 1，結果的位元就是 1。否則就是 0。

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### 位元 NOT（`~`）

最後，位元 NOT 運算子（`~`）會翻轉每個位元。和先前的運算子不同，這是一元運算子，只作用於一個值。

```java
~0b0110_0101;
// # => 0b1001_1010
```
