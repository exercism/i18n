# 說明

你的籃網球俱樂部每輪比賽後都需要算出排名表。

這四個任務都要寫在 `NETBALL_LADDER` 類別裡。

## 1. 排名積分

勝場可得 4 分，平手可得 2 分，輸球則沒有分數。

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. 得失分差

得分減去失分。結果可能是負數。

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. 完整節數

一節是 15 分鐘。給定一個分鐘數，這樣是幾個完整的節？

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. 本節已進行的分鐘數

給定同樣的分鐘數，目前這一節已經進行了幾分鐘？

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
