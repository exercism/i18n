# 操作說明補充

## 暫存器

| 暫存器  | 用途     | 型別    | 說明                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 輸入     | 位址 | 因數字組的陣列         |
| `$a1`    | 輸入     | 整數 | 因數的數量             |
| `$a2`    | 輸入     | 整數 | 上限                         |
| `$v0`    | 輸出     | 整數 | 上限內所有倍數的總和 |
| `$t0-9`  | 暫時性 | 任意   | 用於暫時儲存    |
