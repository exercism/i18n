# 指令

延續巫師與戰士遊戲的主題，現在該來加入一個通用的擲骰方法了。這會是傳統的 18 面骰子，數字從 1 到 18。玩家也會產生法術強度。

## 1. 讓 _巫師與戰士_ 的玩家可以擲骰子。

在`Player`類別上實作一個`RollDie()`方法。

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. 玩家需要自己的強度。提供產生法術強度的方法

在玩家類別上實作一個`GenerateSpellStrength()`方法。法術強度介於 0.0 到 100.0 之間，但不包含 100.0。

請注意，法術強度必須是實數（不是整數），這樣在比較兩個對手的強度時，就能降低出現平手的可能性。

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
