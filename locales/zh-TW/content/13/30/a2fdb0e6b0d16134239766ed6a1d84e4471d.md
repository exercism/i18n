# 簡介

Gleam 不用例外來處理錯誤，而是由可能成功或失敗的函式回傳泛型的`Result`型別。

`Result`型別是語言內建的，所以你不需要定義或匯入它，但如果你自己動手定義，它會長得像這樣：

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

函式成功時會回傳`Ok`變體，函式失敗時則回傳`Error`變體。

`Result`在 Gleam 裡非常常見，Gleam 開發者也常會使用 [`gleam/result` 模組](https://hexdocs.pm/gleam_stdlib/gleam/result.html) 來讓處理它們更輕鬆。

`result.map`函式可以在結果裡的值是`Ok`時，對該值呼叫一個函式；如果是`Error`，就原樣傳遞下去。

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try`函式很類似，但它預期回呼函式會回傳一個結果。這在串接多個會回傳結果的函式時很有用。

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
