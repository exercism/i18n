# 指令

將一段詞組轉換成它的縮寫。

科技人最愛用他們的 TLA（三個字母的縮寫）！

寫個程式來產生一些行話吧：把像是 Portable Network Graphics 這樣的長名稱轉換成它的縮寫（PNG）。

標點符號的處理方式如下：連字號是詞語的分隔符號（就像空白一樣）；其他所有標點符號都可以從輸入中移除。

例如：

| 輸入                      | 輸出   |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
