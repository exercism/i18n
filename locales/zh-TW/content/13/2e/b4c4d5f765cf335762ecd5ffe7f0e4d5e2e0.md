# 說明

## 執行測試

Factor 學習路徑使用 **Factor 0.101**。在[安裝](https://exercism.org/docs/tracks/factor/installation)完成後，請在這個練習的目錄下執行：

```
factor -roots=. -run=exercism-tools <exercise>
```

例如，以 `hello-world` 來說：

```
factor -roots=. -run=exercism-tools hello-world
```

每個練習都隨附一個小型的`exercism-tools`詞彙，由它來驅動測試執行。當所有測試都通過時，執行器會以狀態 0 結束；如果有任何測試失敗，則會以非零狀態結束，並附上診斷輸出。

### 略過的測試

預設情況下，只會執行第一個測試。這個機制來自測試檔案中的`STOP-HERE`這一行：在解析時，它會告訴 Factor 的詞法分析器忽略它底下的所有內容，因此執行器只會看到上方的測試。當你的第一個測試通過後，你可以用兩種方式啟用更多測試：

- **刪除`STOP-HERE`這一行**，一次啟用所有剩下的測試。
- **把`STOP-HERE`這一行往下移**，就能一次啟用一個測試，或一次啟用一個任務。概念練習會把測試分組放在`TASK:`標記底下，把`STOP-HERE`移到下一個`TASK:`之前，就是很自然的一步。

當所有測試都通過時，你就完成了這個練習。

## 提交你的解答

在練習的目錄下：

```
exercism submit <exercise>/<exercise>.factor
```

例如：

```
exercism submit hello-world/hello-world.factor
```

如果練習的`.meta/config.json`列出多個解答檔案（有些概念練習會把解答拆到輔助的子詞彙裡），請把你編輯過的每個檔案都傳給`exercism submit`。

## 提交未完成的解答

即使測試沒有全部通過，你還是可以提交解答，這樣你就能看看其他人是怎麼解這個練習的，也可以就你目前完成的內容請導師給回饋。

## 取得更多協助

- [Exercism 論壇上的 Factor 分類](https://forum.exercism.org/c/programming/factor/)是詢問這條學習路徑相關問題、取得回饋的最佳地方。
- [Exercism Discord](https://exercism.org/r/discord)上有一般協助和個別學習路徑的頻道。
- Factor 的官方文件可以搜尋，而且內容非常完整。兩個不錯的切入點：
  - [The Factor handbook](https://docs.factorcode.org/content/article-handbook.html)，偏向參考書風格，依詞彙編排。
  - [The Factor cookbook](https://docs.factorcode.org/content/article-cookbook.html)，依主題提供簡短的慣用範例。
- Andrea Ferretti 的 [Factor tutorial](https://andreaferretti.github.io/factor-tutorial/)是快速又親切的入門，帶你認識這門程式語言和開發環境。
