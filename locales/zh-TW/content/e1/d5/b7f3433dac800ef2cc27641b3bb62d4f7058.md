# 簡介

命名空間是組織程式碼的一種重要方法。
兩個函式可能會發生命名衝突，只要把它們放進不同的命名空間就能解決。
命名空間可以巢狀，這有助於組織大型的程式碼庫。
要存取命名空間，可以使用作用域解析運算子`::`。

下面的範例展示了兩個不同的`foo`函式。
只要在它們前面加上各自的命名空間，就能一起使用。

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
