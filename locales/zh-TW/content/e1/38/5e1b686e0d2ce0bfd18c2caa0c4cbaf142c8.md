# 關於

## 一般語法

`for`迴圈是重複執行某些邏輯最常用的敘述之一。
在 Go 裡，它由 `for` 關鍵字、一個標頭，以及一個用大括號包住迴圈主體（body）的程式區塊組成。
標頭由 3 個以分號`;`分隔的部分組成：init、condition 和 post。

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init**部分只會在迴圈開始前執行一次。
- **condition**部分必須是某個求值結果為布林值的運算式，用來控制迴圈何時該停止。
  只要這個條件的求值結果為 true，迴圈內的程式碼就會持續執行。
  一旦這個運算式的求值結果為 false，迴圈就不會再疊代。
- **post**部分會在每次疊代結束時執行。

**注意：**與其他語言不同，標頭的三個部分外面並沒有小括號`()`。
事實上，加上這種括號會造成編譯錯誤。
不過，包住迴圈主體的大括號`{ }`則一律必須寫。

## `for`迴圈：範例

init 部分通常會設定一個計數器變數，condition 會檢查迴圈應該繼續還是停止，post 部分則通常在每次重複結束時把計數器加一。

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

這個迴圈會印出從`1`到`9`的數字（包含`9`）。
定義每次的遞增量通常是用遞增或遞減敘述來完成，就像上面的範例那樣。

## 標頭中可省略的部分

標頭中的 init 和 post 部分可以省略：

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

像上面那樣在`for`迴圈中省略 init 和 post 部分，就等於在 Go 裡建立了 while 迴圈。
Go 並沒有`while`關鍵字。
這體現了 Go 的一個原則：概念應該彼此正交。
既然已經有一個概念可以達成 while 迴圈的行為，也就是`for`迴圈，就不必再加入`while`這個額外的概念。

## `break`與`continue`

在迴圈主體裡，你可以用`break`關鍵字完全停止迴圈的執行：

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

相對地，`continue`關鍵字只會停止目前這次疊代的執行，並繼續進行下一次疊代：

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## 無限的`for`迴圈

迴圈標頭中的 condition 部分同樣可以省略。
事實上，你可以寫一個完全沒有標頭的迴圈：

```go
for {
  // Endless loop...
}
```

這個迴圈只有在程式結束，或主體中有`break`時才會停止。

## 標籤與`goto`

當我們使用`break`時，Go 會停止執行最內層的迴圈。
同樣地，當我們使用`continue`時，Go 會執行最內層迴圈的下一次疊代。

不過，這並不總是我們想要的。
我們可以把標籤與`break`和`continue`搭配使用，精確指定要從哪一個迴圈離開，或要繼續哪一個迴圈。

在這個範例中，我們建立了一個標籤`OuterLoop`，指向最外層的迴圈。
在最內層的迴圈裡，若要表示想從最外層迴圈離開，就使用`break`，後面接上最外層迴圈的標籤名稱：

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

把標籤與`continue`搭配使用也可以，這樣一來，Go 會繼續執行標籤所指迴圈的下一次疊代。

Go 也有`goto`關鍵字，運作方式類似，可以讓我們從某段程式碼跳到另一段有標籤的程式碼。

**警告：**雖然 Go 允許跳到標有標籤的程式碼，但使用這項語言功能很容易讓程式碼變得非常難讀。
因此，通常不建議使用標籤。
