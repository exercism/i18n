# 關於

[`while` 迴圈][while-loops] 是一種控制流程敘述，讓程式碼可以在某個條件為 true 時執行。
Swift 提供兩種迴圈：`while` 迴圈和 `repeat-while` 迴圈。
`while` 迴圈的條件會在迴圈主體執行之前先求值；如果條件為 false，迴圈主體就完全不會執行。
Swift 的 `while` 迴圈結構如下：

```swift
while <#condition#> {
  <#code#>
}
```

這裡只要 count 大於 0，迴圈就會持續執行，並依序印出數字 2、1 和「Liftoff!」。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while` 迴圈][while-loops] 和 `while` 迴圈類似，但條件是在迴圈主體執行之後才求值。
這表示即使條件為 false，迴圈主體也至少會執行一次。
Swift 的 `repeat-while` 迴圈結構如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

這裡的迴圈只會執行一次，因為條件為 false。
由於它是 `repeat-while` 迴圈，迴圈主體會先執行一次，然後才對條件求值。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
