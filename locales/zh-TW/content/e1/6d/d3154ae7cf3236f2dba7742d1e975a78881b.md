# 測試

前往包含對應 `${slug}_test.sql` 檔案的目錄，其中 `${slug}` 是練習名稱，以連字號取代空格並全部使用小寫（例如 `Hello World` 練習的 `hello-world_test.sql`）。

```bash
sqlite3 -bail < ${slug}_test.sql
```

你可以使用 `SELECT` 敘述來除錯。
如果測試失敗，輸出會轉送到 `user_output.md`，並顯示在網頁編輯器中。

你可以在 [sqlite 軌道的測試說明文件](https://exercism.org/docs/tracks/sqlite/tests) 找到更多資訊。
