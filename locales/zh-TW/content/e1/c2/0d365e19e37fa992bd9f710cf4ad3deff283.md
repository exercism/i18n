# 簡介

TypeScript 是帶有型別語法的 JavaScript，這讓它成為一門強型別的程式語言，支援物件導向、指令式與宣告式（例如函式式程式設計）等風格，讓你在任何規模下都能享有更好的工具支援。

因為[不學 JavaScript 就無法學會 TypeScript][handbook-js-or-ts]，所以這個 Track 有些內容著重在教 JavaScript 的概念，有些概念則只聚焦在 TypeScript 特有的功能。

## （重新）賦值

在 TypeScript 中，要把值指定給名稱，主要有幾種方式：使用變數或常數。
在 Exercism 上，變數一律以 [camelCase][wiki-camel-case] 撰寫；常數則以 [SCREAMING_SNAKE_CASE][wiki-snake-case] 撰寫。
這並沒有官方指南可遵循，各家公司和組織也都有各自的風格指南。
_你可以隨心所欲地撰寫變數_。
依照練習的撰寫方式來寫，好處是在網頁介面和多數 IDE 中會以不同的樣式標示。

在 TypeScript 中，可以使用 [`const`][mdn-const]、[`let`][mdn-let] 或 [`var`][mdn-var] 關鍵字來定義變數。

使用 `let` 或 `var` 時，變數在其生命週期內可以指向不同的值。
舉例來說，使用賦值運算子 `=`，`myFirstVariable` 可以被定義和重新定義許多次：

```typescript
let myFirstVariable = 1
myFirstVariable = 0
myFirstVariable = 42
```

和 `let`、`var` 不同，用 `const` 定義的變數只能被指定一次。
在 TypeScript 中，這用來定義常數。

```typescript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

由於 TypeScript 能靜態偵測到這種情況，TypeScript 編譯器也會產生錯誤：

```typescript
// ^? Cannot assign to 'MY_FIRST_CONSTANT' because it is a constant.(2588)
```

這表示你不需要執行程式就能偵測到 `TypeError`。

## 型別推論

先不深入探討[型別推論][handbook-type-inference]這個主題，但你要知道，被指定值的變數通常會有推論出的型別，即使沒有型別註解也一樣。

```typescript
const MY_FIRST_CONSTANT = 10
// ^? const MY_FIRST_CONSTANT: number
```

這個型別接著會在整份程式碼中被強制套用。
這也意味著，雖然下面這段程式碼是合法的 JavaScript：

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
```

但在使用 TypeScript 時就會報錯：

```typescript
let myFirstVariable = 1
myFirstVariable = 'Some string'
// ^? Type 'string' is not assignable to type 'number'.(2322)
```

這項功能確保了型別安全，即使沒有使用型別註解也一樣。

## 函式宣告

在 TypeScript 中，功能單位會封裝在_函式_裡；如果幾個函式屬於同一組，通常會把它們放在同一個檔案中。
這些函式可以接受參數（引數），並且可以用 `return` 關鍵字_回傳_一個值。
函式透過 `()` 語法來呼叫。

```typescript
function add(num1: number, num2: number): number {
  return num1 + num2
}

add(1, 3)
// => 4
```

函式參數通常應該標上型別，作法是使用冒號（`:`），後面接著型別。
函式回傳值則可以在參數列表結束後標上型別，同樣使用冒號（`:`），後面接著型別。

## 型別註解

如 `add` 的函式宣告所示，這些參數有明確的型別註解 `: number`。
變數宣告、類別屬性、函式宣告等等都支援型別註解。

明確的型別註解和推論出的型別，都會由型別檢查器強制套用。

```typescript
add('foo', 3)
// ^? Argument of type 'string' is not assignable to parameter of type 'number'.(2345)
```

## 開放給其他檔案

若想讓某個 `function`、常數或變數能在_其他檔案_中使用，就必須用 `export` 關鍵字將它們[匯出][mdn-export]。
接著，另一個檔案可以用 `import` 關鍵字來[匯入][mdn-import]它們。
這也稱為模組系統。
所有測試的運作方式就是一個很好的例子。
每個練習至少有一個檔案，例如 `lasagna.ts`，裡面包含_實作_。
此外，至少還會有另一個檔案，例如 `lasagna.test.ts`，裡面包含_測試_。
這個檔案會_匯入_公開（也就是匯出的）實體，以便測試實作：

```typescript
// file.ts
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.test.ts
import { MY_VALUE, add } from './file.js'

add(MY_VALUE, 5)
// => 15
```
