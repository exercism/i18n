# 說明

在這個練習中，你會撰寫程式碼，協助一家招牌公司為他們的招牌建立自訂訊息。

## 1. 建立場合招牌

實作方法 `build_sign( )`，它接受一個字串作為 `occasion` 參數，以及一個存放某人名字的字串作為 `name` 參數。這兩個參數會被嵌入字串範本中，用來輸出招牌上的訊息。

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. 建立生日招牌

實作方法 `build_birthday_sign( )`，它接受一個年齡，並根據年齡決定招牌上的部分訊息。如果年齡為 50 以上，招牌上會包含 _mature_ 這個字，否則招牌上會包含 _young_ 這個字。

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. 建立畢業招牌

實作方法 `graduation_for( )`，它接受一個字串參數作為名字，以及一個數字參數作為年份，並使用字串範本建立招牌的短語，並以換行符號分隔訊息中的兩行。

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. 計算招牌的費用

實作函式 `cost_of( sign currency )`，它接受一個包含招牌內容的字串，以及一個代表貨幣的字串。
招牌的基本價格為 20，並以指定的貨幣計價。此外，每個字母的費用為 2。（計算時會包含空白字元。）
回傳的短語會包含製作招牌的費用，以小數點後兩位數字表示，後面接著貨幣字串。

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
