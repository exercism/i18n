# 學習

Cairo 是第一個圖靈完備、能為一般運算建立可證明程式的語言。它是類似 Rust 的高階語言。和 Rust 一樣，它的目標是讓開發者能輕鬆寫出有效率又安全的程式碼。

我們認為最好的學習方式就是動手玩、動手練習，無論是打造自己的程式專案，還是解像 Exercism 這裡這樣的小題目都可以喔！

以下是幾個能幫助你快速展開 Cairo 之旅的資源：

- [Cairo Programming Language](https://www.cairo-lang.org/) 介紹 Cairo 語言，並列出許多學習與使用 Cairo 的相關資源。
- [The Cairo Book](https://book.cairo-lang.org/) 是學習 Cairo 的絕佳資源，也能帶你深入探索 Cairo 的各種特定功能。
- [Cairo Documentation](https://docs.cairo-lang.org/) 說明這門語言的各種建構與語意。
- [Cairo by Example](https://cairo-by-example.com/) 用範例展示你在 Cairo 中最常寫到的各種內容。
- [Node Guardians](https://nodeguardians.io/campaigns?f=3%3D2)「一個以奇幻為主題、給智慧合約開發者使用的學習平台。」
- [Cairo Community Forum](https://community.cairo-lang.org/) 解答各種程度的問題。
