# 說明

在馬戲團裡，安全檢查通過之前，沒有人可以上高空鞦韆。
你把這些檢查寫下來，這樣同樣的規則就能套用在每個人身上。

五個任務都寫在 `SAFETY_CHECK` 類別裡。

## 1. 墊子準備好了嗎？

只有當墊子既鋪好又乾淨時，才算準備好。

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. 下方有可以接住的東西嗎？

下方必須有墊子，或有安全網。兩者其一即可，兩者都有也沒問題。

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. 還有誰需要安全簡報？

任何還沒接受安全簡報的人，都需要安全簡報。

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. 這位表演者年齡夠大了嗎？

高空鞦韆是給 13 歲以上的表演者。

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. 全部組合起來

當表演者年齡夠大、接受過安全簡報，而且墊子也準備好時，就獲准上高空鞦韆。

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

這四個引數分別是年齡、是否接受過安全簡報、墊子是否鋪好，以及墊子是否乾淨。
