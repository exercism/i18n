# 簡介

元組是有序的值的容器。和所有 Gleam 資料型態一樣，元組是不可變的。元組的每個元素都可以是不同的型別，甚至可以是其他元組。

元組的定義方式，是把以逗號分隔的值放在`#(`和`)`之間：`#(1, 2.0, "Three")`。

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

長度相同、型別也相同（且順序相同）的元組，可以比較是否相等。

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

有三種方式可以從元組中取出裡面的值：

- 使用索引。
- 使用`let`進行模式配對。
- 使用`case`進行模式配對。

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
