# 說明

在這個練習中，你會寫一個好用的小程式，讓你不用再死記色環代表的數值。這個程式會接收 1、4 或 5 種顏色作為輸入，並以歐姆為單位輸出正確的數值。色環的編碼方式如下：

| 顏色 | 數值 |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

在 [`Resistor Color Trio`][resistor-color-trio-exercise] 中，你解碼了前三個色環。例如：orange-orange-brown 會轉換成主數值 `330`。在這個練習裡，你需要在其中加入_容差_。容差是指數值可以高於或低於主數值的最大幅度。例如，如果最後一個色環是 green，最大容差就是 `±0.5%`。

容差色環會是下列其中一個數值：

| 顏色 | 容差 |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

四環電阻的結構如下：

| 色環 1 | 色環 2 | 色環 3 | 色環 4 |
| ------- | ------- | ---------- | --------- |
| 數值 1 | 數值 2 | 乘數 | 容差 |

範例：

- orange-orange-brown-green 會是 `330` 歐姆，容差為 `±0.5%`。
- orange-orange-red-grey 會是 `3300` 歐姆，容差為 `±0.05%`。

四環電阻和五環電阻的差別，在於五環電阻多了一個色環，用來表示更精確的數值。

| 色環 1 | 色環 2 | 色環 3 | 色環 4 | 色環 5 |
| ------- | ------- | ------- | ---------- | --------- |
| 數值 1 | 數值 2 | 數值 3 | 乘數 | 容差 |

範例：

- orange-orange-orange-black-green 會是 `333` 歐姆，容差為 `±0.5%`。
- orange-red-orange-blue-violet 會是 `323 million` 歐姆，容差為 `±0.1%`。

另外也有一環電阻。一環電阻只有 black 一種顏色，數值為 0。

你的程式要把電阻色環的輸入`list`轉換成這樣的標籤：

"... ohms ±...%"

所以當輸入的`list`是`["orange", "orange", "black", "green"]`時，應該回傳：

"33 ohms ±0.5%"

當歐姆數到達好幾千時，我們會說「kiloohms」。這就像 1000 公尺說成「kilometer」、1000 公克說成「kilograms」一樣。

所以當輸入的`list`是`["orange", "orange", "orange", "grey"]`時，應該回傳：

"33 kiloohms ±0.05%"

當歐姆數到達好幾百萬時，我們會說「megaohms」。

所以當輸入的`list`是`["orange", "orange", "blue", "red"]`時，應該回傳：

"33 megaohms ±2%"
