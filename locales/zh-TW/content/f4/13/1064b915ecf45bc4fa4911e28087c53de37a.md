# 簡介

*元組*是 Factor 的紀錄、結構、類別型別。每個元組類別都有一組固定的具名槽位，Factor 會自動為它們產生取值函式與設值函式。

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa`（「依引數順序」）會依宣告順序，從堆疊填入各個槽位。`new`會建立實例，每個槽位都設為宣告的`initial:`值（若沒有則為`f`）。

每個槽位的取值函式是`slot>>`，設值函式是`>>slot`。設值函式會*修改*原物件，所以如果需要非破壞性的更新，請先用`clone`：

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

槽位預設值使用`{ name initial: value }`；沒有指定`initial:`時，預設值為`f`。
