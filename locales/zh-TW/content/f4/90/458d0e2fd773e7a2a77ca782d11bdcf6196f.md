# 指令

Lucian 的女友正在回家的路上，而他還沒煮好他們的週年紀念晚餐！

在這個練習中，你將寫一些程式碼，幫助 Lucian 依照他最愛的食譜書做出精緻的千層麵。

你有四項任務，全都和烹煮千層麵所花費的時間有關。

## 1. 定義預期的烘烤時間（分鐘）

定義`ovenTime()`函式，它不接受任何引數，並回傳千層麵應該待在烤箱裡幾分鐘。
根據食譜書，預期的烘烤時間是 40 分鐘：

```cpp
ovenTime();
// => 40
```

## 2. 計算剩餘的烘烤時間（分鐘）

定義`remainingOvenTime(int actualMinutesInOven)`函式，它接受千層麵已經待在烤箱裡的實際分鐘數作為引數，並根據上一項任務預期的烘烤時間（分鐘），回傳千層麵還需要在烤箱裡待幾分鐘。

```cpp
remainingOvenTime(30);
// => 10
```

## 3. 計算準備時間（分鐘）

定義`preparationTime(int numberOfLayers)`函式，它接受你加到千層麵裡的層數作為引數，並回傳你準備千層麵花了幾分鐘，假設每一層需要花 2 分鐘準備。

```cpp
preparationTime(2);
// => 4
```

## 4. 計算經過時間（分鐘）

定義`elapsedTime(int numberOfLayers, int actualMinutesInOven)`函式，它接受兩個引數：第一個引數是你加到千層麵裡的層數，第二個引數是千層麵已經待在烤箱裡的分鐘數。這個函式應該回傳你烹煮千層麵總共花了幾分鐘，也就是準備時間（分鐘）加上千層麵目前為止待在烤箱裡的分鐘數。

```cpp
elapsedTime(3, 20);
// => 26
```
