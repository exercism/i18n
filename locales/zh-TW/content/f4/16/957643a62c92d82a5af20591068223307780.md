# 學習 Visual Basic

## 網站

Visual Basic 這些年來演進了很多，許多第三方教學提到的仍是過時的工具或功能。
[Visual Basic 官方文件](https://learn.microsoft.com/en-us/dotnet/visual-basic/) 是最新、最可靠的資源，很適合做為你學習旅程的起點。

## .NET 生態系

Visual Basic 執行在 .NET 執行階段上，與 C# 和 F# 共用許多核心功能。
因此，了解 .NET 的運作方式，能讓你成為更強的 VB 開發者。

- [什麼是 .NET？](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [.NET 詞彙表](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [通用型別系統（CTS）](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
