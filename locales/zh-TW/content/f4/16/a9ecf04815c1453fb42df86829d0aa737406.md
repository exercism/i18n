# 補充說明

## 輸出格式

輸出一個以 null 結尾的字串，並以逗號和空格作為分隔符號。

一個範例輸出會是 `"491, 914, 142"`

如果輸入無效，就輸出空字串。

## 暫存器

| Register | Usage        | Type    | Description                    |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | 輸入          | 位址     | 以 null 結尾的數列字串           |
| `$a1`    | 輸入          | 整數     | 切片長度                        |
| `$a2`    | 輸入／輸出    | 位址     | 以 null 結尾的輸出字串           |
| `$t0-9`  | 暫時性        | 任意     | 用於暫時儲存                     |
