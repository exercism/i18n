# 尋求協助

如果你遇到問題，以下是一些可以幫助你的資源：

- [The PSF](https://www.python.org) 提供 Python 的下載、文件與社群資源。
- [Python Community Forums](https://discuss.python.org/) 提供協助、PEP 討論，以及 Python 核心提交者等更多內容。
- [The Exercism Community on Discord](https://exercism.org/r/discord)
- [The Exercism Community Discussion Forums](https://forum.exercsim.org)
- [Python Community on Discord](https://pythondiscord.com/) 是個非常熱心且活躍的社群。
- [/r/learnpython/](https://www.reddit.com/r/learnpython/) 是專為 Python 學習者設計的 subreddit。
- [#python on Libera.chat](https://www.python.org/community/irc/) 這裡是這個語言的核心開發者交流、完成工作的地方。
- [Free Code Camp Community Forums](https://forum.freecodecamp.org/)
- [Pythontutor](http://pythontutor.com/) 可以用視覺化的方式逐步檢視簡短的程式碼片段。

此外，[StackOverflow](http://stackoverflow.com/questions/tagged/python) 也是個搜尋你的問題、看看是否已經有人回答過的好地方。
如果沒有，你隨時可以[發問](https://stackoverflow.com/help/how-to-ask)或[回答](https://stackoverflow.com/help/how-to-answer)其他人的問題。
