# 資源

## 一般資源

- [vim-galore](https://github.com/mhinz/vim-galore) 是一份涵蓋 Vim 大小事的超大型指南。
- [Why, oh WHY, do those #?@! nutheads use vi?](http://www.viemu.com/a-why-vi-vim.html) 說明了關於 vi 與 Vim 的常見誤解。
- [Your problem with Vim is that you don't grok vi](http://stackoverflow.com/a/1220118) 是不可多得的珍寶。三不五時就讀一下吧。
