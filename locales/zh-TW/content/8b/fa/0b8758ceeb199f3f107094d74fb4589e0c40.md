# 表示

[Java representer][github-java-representer] 會進行下列正規化：

- 移除所有註解
- 移除所有 import 宣告
- 將識別字正規化為預留位置的值

套用上述正規化之後，產生的表示會依照 [Google Java Style][google-java-style] 格式化，以消除程式碼格式上任何剩餘的差異。

## 提交之前

請檢查下列幾點：

- 你不會重複分析器已經給過的回饋。
- 你檢查提交對話框裡的「examples」分頁，確認這些回饋對所有分頁都說得通。
- 你確認自己沒有提到空白或註解。
- 你確認自己不提到解法中出現的函式名稱或變數名稱，而是使用提供的對應（或省略名稱）。
  只有練習測試用到的識別字才可以安全地提到，因為它們對每個人來說都一樣。
