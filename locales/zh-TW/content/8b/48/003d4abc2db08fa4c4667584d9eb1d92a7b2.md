# 介紹

二進位數字最終直接對應到 CPU 或 RAM 裡的電晶體，以及每一個電晶體是「開」還是「關」。

低階操作，也就是俗稱的「bit-twiddling」，在系統程式語言中格外重要。

像 Julia 這類高階語言通常會把這些細節抽象掉。
不過，基礎語言本身就提供了一整套位元層級的操作。

***注意：*** 若想在 REPL 中看到人類可讀的二進位輸出，下面幾乎所有範例都得用`bitstring()`函式包起來。
這樣在視覺上很干擾，所以大部分出現這個函式的地方都已經被刪掉了。

## 位移運算

整數型別，無論是有號還是無號，都可以表示成一串 1 和 0。

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

位移就是把所有位元往左或往右移動指定的位置數。
使用`UInt`型別時，有些位元會從一端掉出去，另一端則補上 0：

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

每左移一次就把值乘以二，每右移一次就把值除以二（可能會截斷）。
用十進位表示會更明顯：

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

這種位移比「正規」的算術快得多，讓這個技巧在低階程式設計中非常受歡迎。

遇到有號整數時，我們得再小心一點。

左移相對單純：

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

因此，對正的有號整數做左移，跟對無號整數做左移是一樣的。

負數以[二補數][2complement]形式儲存，也就是最左邊的位元是 1。
左移沒問題，但右移時，最左邊的位元要補什麼呢？

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

`>>`運算子執行的是算術位移，會保留符號位元。

`>>>`運算子執行的是邏輯位移，會補 0，就當成這個數字是無號的一樣。

## 位元邏輯

我們在前一個概念中看過，`&&`（and）、`||`（or）和`!`（not）這些運算子是用在布林值上的。

另外也有對應的運算子`&`（位元 and）、`|`（位元 or）和`~`（波浪號，位元 not），用來比較兩個整數裡的位元。

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

這裡的`xor()`就是互斥或（exclusive-or），以函式的形式使用。

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
