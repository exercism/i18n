# 簡介

ABAP 支援一套物件導向程式設計模型，它是以 ABAP Objects 的類別與介面為基礎的。

## （重新）賦值

在 ABAP 中，將值指定給名稱有幾種主要方式：使用變數或常數。在 Exercism 上，變數一律以 [snake-case][wiki-snake-case] 撰寫。這並沒有官方指南可循，各家公司和組織也各有自己的風格指南。_你可以任意選擇自己喜歡的方式來撰寫變數。_ 照著練習準備的方式來寫變數，好處是它們在網頁介面和大多數 IDE 中會以不同方式標示出來。

在 ABAP 中，變數可以使用[`constant`][constant]或[`data`][data]關鍵字來定義。

使用`data`定義的變數，在其生命週期內可以參照不同的值。例如，`my_first_variable`可以透過[賦值運算子`=`][assignment]一再定義與重新定義：

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

與`data`不同，使用`constant`定義的變數只能指定一次。在 ABAP 中，這用來定義常數。

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## 類別與方法宣告

在 ABAP 中，功能單元會封裝在_方法_裡，如果幾個方法屬於同一組，通常會把它們放在同一個[類別][classes]中。這些方法可以接收參數（引數），並且可以在方法定義中使用`returning`關鍵字來_回傳_一個值。方法使用`( )`語法來呼叫。

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 在 ABAP 中，宣告類別與方法的方式_非常多_。這個 track 會試著循序漸進地介紹這些方式，但如果你已經知道它們，也可以自由選用其中任何一種。在多數情況下，用哪一種並沒有優劣之分。
