# 介紹

## 疊代器

Gleam 中的`Iterator`和陣列很像，都是一種有序的值集合，而且其中所有值的型別都相同。它和陣列不同的地方在於它是惰性的，也就是說，它不會一次把所有值都存進記憶體，而是需要用到時才計算出來。

當你處理非常龐大、甚至無限長的序列時，這就很有用，因為它讓我們在沒有足夠的可用記憶體一次儲存全部值時，仍然能處理這些序列。

`gleam/iterator`模組定義了`Iterator`型別，以及各種用來處理疊代器的函式。

許多用於陣列的函式在疊代器上也有，例如`map`、`filter`和`take`。這些函式會回傳疊代器，所以在疊代器被消耗之前，它們其實不會做任何事。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold`函式可以用一個會被反覆呼叫的函式來建立疊代器，每次呼叫都會產生序列中的下一個值。

這裡用`unfold`函式建立了一個會產生費氏數列的疊代器：

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

這裡的序列是無限的，所以在把值收集成陣列之前，會先用`take`函式讓它變成有限的。如果對無限的疊代器呼叫`to_list`，程式會一直執行，直到記憶體用盡而當機。
