# 簡介

Gleam 裡有 2 種不同的數字：整數和浮點數。

整數是沒有小數部分的數字。

```gleam
let integer = 3
// -> 3
```

為了方便閱讀，也可以在整數中加上底線。

```gleam
1_000_000 // One million
```

Gleam 有幾個可以搭配整數使用的運算子。

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
