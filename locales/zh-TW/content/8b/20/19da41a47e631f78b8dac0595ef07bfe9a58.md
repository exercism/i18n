# SQLite 專用指示

**result**欄位應該包含以 JSON 編碼的物件，每個單字是鍵，次數是整數。

舉例來說，看看上面那句：`"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
這段輸入的**result**應該會是：

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## 資料表結構

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
