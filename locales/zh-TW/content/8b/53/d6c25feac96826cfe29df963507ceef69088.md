# 簡介

## 列舉

_列舉型別_ 是一種特殊的資料型態，能讓變數的值取自一組預先定義的常數。
這個變數必須等於其中一個為它預先定義好的值。
常見的例子包括羅盤方位（`NORTH`、`SOUTH`、`EAST` 和 `WEST` 等值）以及一週中的每一天。

因為它們是常數，列舉型別的欄位名稱會使用大寫字母。

### 定義列舉型別

在 Java 程式語言中，你可以使用`enum`關鍵字來定義列舉型別。
例如，你可以這樣定義一個代表一週中各天的列舉型別：

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

當你需要表示一組固定的常數時，就應該使用列舉型別。
這包括自然的列舉型別，例如太陽系中的行星，以及在編譯時就知道所有可能值的資料集，例如選單上的選項、命令列旗標等等。

### 使用列舉型別

以下程式碼示範如何使用上面定義的`DayOfWeek`列舉：

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### 新增方法與欄位

Java 的列舉型別遠比其它語言中的同類功能強大得多。
`enum` 宣告會定義一個_類別_（稱為_列舉型別_）。
列舉類別的主體可以包含方法和其他欄位：

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

在`Rating`列舉型別的成員上呼叫`getNumberOfStars`方法：

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
