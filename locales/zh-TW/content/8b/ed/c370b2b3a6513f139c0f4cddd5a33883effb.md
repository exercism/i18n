# 提示

## 一般

- [`Map` API 文件][map-docs] 中列出了 `Map` 介面上可用的方法。

## 1. 回傳 map 中的代碼

- 你需要以[某種方式][declaring-members]定義一個 `Map`，讓你能在類別方法中使用它。

## 2. 在字典中新增項目

- Map 有[方法][map-put-docs]可以新增和更新某個鍵的值。

## 3. 查詢某個撥號代碼對應的國家

- Map 有[方法][map-get-docs]可以取得某個鍵的值。

## 4. 不允許重複

- 有方法可以檢查 map 是否包含某個[鍵][map-contains-key-docs]或某個[值][map-contains-value-docs]。

## 5. 找出某個國家的撥號代碼

- 有[方法][map-entry-set-docs]可以取得 map 中項目的可迭代集合，讓你逐一走訪鍵值對。

## 6. 更新國家的撥號代碼

- 別忘了，該國家先前的撥號代碼仍然會留在 map 裡。
- 有[方法][map-remove-docs]可以從 map 中移除項目。
