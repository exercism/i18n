# 簡介

## 外部函式

Gleam 可以執行在 Erlang 虛擬機器（BEAM）上，也可以執行在 JavaScript 執行環境上。還有許多其他語言也使用這些執行環境，因此我們常常會需要從 Gleam 呼叫用這些語言撰寫的程式碼。

Gleam 的_外部函式_功能可以讓其他語言的函式被匯入 Gleam，呼叫時不會產生額外的執行期負擔。

如果你的 Gleam 專案執行在 Erlang 虛擬機器上，而你想呼叫 Erlang `lists` 模組裡的 `reverse` 函式，只要在 Gleam 函式標頭加上 `@external` 屬性就行了，像這樣：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

接著就能像一般 Gleam 函式一樣呼叫它：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

如果你試著把這段程式碼編譯到 JavaScript 執行環境，就會因為沒有 JavaScript 的實作而失敗，並出現錯誤訊息。你也可以像這樣為 JavaScript 執行環境指定另一份實作：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

當目前的編譯目標沒有對應的外部實作時，也可以自己寫一份 Gleam 實作來使用：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## 外部型別

外部型別可以用來指向其他語言（例如 Erlang 或 JavaScript）所定義的資料型態。

要定義外部型別，只要宣告一個型別，但不提供任何建構子即可。之後就能像其他型別一樣使用它。

```gleam
pub type OrderedDictionary(element)
```
