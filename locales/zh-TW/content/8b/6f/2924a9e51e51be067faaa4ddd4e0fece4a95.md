# 簡介

## 遞迴

遞迴函式就是會呼叫自己的函式。

一個遞迴函式至少需要 1 個_基本情況_和至少 1 個_遞迴情況_。

_基本情況_會回傳一個值，不再呼叫函式。
_遞迴情況_會再次呼叫函式，並修改輸入，讓它在某個時間點符合基本情況。

在 Elm 中，遞迴函式通常會用 `case` 運算式，或多個函式子句的模式比對來定義。

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### 透過遞迴實作迴圈

由於不可變性，Elm 的迴圈寫法和指令式語言不同。
例如，迴圈通常長這樣：

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

在像 Elm 這樣的函式語言中，沒有辦法改變變數。
因此，迴圈必須用遞迴來實作。

Elm 中相當於 `for` 迴圈的寫法會像這樣：

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

實際上，在 Elm 中疊代陣列和其他資料結構時，最常使用 `List` 模組裡的函式，例如 `List.map`、`List.filter` 和 `List.foldl`。
在底層，這些函式都是用遞迴實作的。
