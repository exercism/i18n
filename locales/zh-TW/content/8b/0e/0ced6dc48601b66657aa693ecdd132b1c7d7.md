# 說明

你正在開發一款備受好評的新遊戲 **Crystal Hunter**。在遊戲中，你是一個四處移動並收集水晶的角色。玩家撿起所有水晶就能獲勝。如果玩家碰到強盜，就會失去所有水晶，遊戲也隨之結束。這條規則有個例外：玩家可以擁有使用中的強化道具，讓自己對強盜隱形。

你的目標是撰寫一些遊戲中會用到的規則。

## 1. 定義角色是否獲得額外分數

在遊戲中，角色若在擁有強化道具時碰到強盜，就會獲得額外分數。

定義 `Rules#bonus_points?` 方法，它接受兩個引數（_角色是否有使用中的強化道具_ 以及 _角色是否碰到強盜_），並回傳一個布林值，指出角色是否會獲得額外分數。這個方法只有在角色擁有使用中的強化道具且碰到強盜時才應回傳 `true`，否則回傳 `false`。

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. 定義角色是否得分

玩家在遊戲中撿起水晶或強化道具時會得分。

定義 `Rules#score?` 方法，它接受兩個引數（_角色是否碰到強化道具_ 以及 _角色是否碰到水晶_），並回傳一個布林值，指出角色是否得分。這個方法在角色碰到強化道具或水晶時應回傳 `true`，否則回傳 `false`。

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. 定義角色是否落敗

定義 `Rules#lose?` 方法，它接受兩個引數（_角色是否有使用中的強化道具_ 以及 _角色是否碰到強盜_），並回傳一個布林值，指出角色是否落敗。這個方法在角色碰到強盜且沒有使用中的強化道具時應回傳 `true`，否則回傳 `false`。

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. 定義角色是否獲勝

定義 `Rules#win?` 方法，它接受三個引數（_角色是否已撿起所有水晶_、_角色是否有使用中的強化道具_，以及 _角色是否碰到強盜_），並回傳一個布林值，指出角色是否獲勝。如果角色已收集所有水晶，且根據第 3 部分定義的引數判斷並未落敗，這個方法應回傳 `true`，否則回傳 `false`。

```crystal
Rules.new.win?(false, true, false)
# => false
```
