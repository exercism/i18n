# Debug

當測試失敗時，畫面會顯示一則訊息，說明哪裡出了問題，以及是哪一筆輸入。你也可以善用一點：任何[主控台輸出][programiz.com-basic-input-output]同樣會顯示出來。你可以用下列方式寫入主控台：

```csharp
Console.WriteLine("Debug message");
```
