# 操作說明

你正在為一台號碼牌機撰寫嵌入式系統。這是個非常簡單的機型。它可以發出連續的號碼，並回報最後發出的號碼是多少。

## 1. 啟動機器

實作 `start/0` 函式。它應該建立一個新的行程，並回傳該行程的 PID。這個新行程還不需要做任何事。

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

請注意，每次執行這段程式碼時，PID 可能都不一樣。

## 2. 回報機器狀態

修改這台機器，讓新建立的行程準備好接收訊息（啟動一個`receive`迴圈），初始狀態為 `0`。它應該要能接收 `{:report_state, sender_pid}` 訊息。收到這些訊息時，它應該把目前的狀態（最後發出的號碼牌號碼）傳送給 `sender_pid`，然後繼續等待更多訊息。

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. 發放號碼

修改這台機器，讓它能接收 `{:take_a_number, sender_pid}` 訊息。它應該把狀態增加 1，將新的狀態傳送給 `sender_pid`，然後繼續等待更多訊息。

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. 停止機器

修改這台機器，讓它能接收 `:stop` 訊息。它應該停止等待更多訊息。

## 5. 忽略非預期的訊息

修改這台機器，讓它在收到非預期的訊息時忽略它，並繼續等待更多訊息。
