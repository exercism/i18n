# 說明

你的任務是建立一個密碼檢查器。
密碼檢查器會驗證使用者提出的密碼，確保它符合控管該資源存取權的組織所定義的一組要求。

這道練習的密碼要求如下：
* 必須至少有 12 個字元
* 必須至少有一個大寫字母
* 必須至少有一個小寫字母
* 必須至少有一個數字
* 必須至少有一個符號，且該符號屬於這組字元：!@#$%^&*

你的解法必須使用`Result`來封裝成功或失敗的狀態。
成功時，`Result`必須以字串呈現通過驗證的密碼。
失敗時，`Result`必須指出違反了哪一條規則。

~~~~exercism/note
在這道練習裡，密碼檢查器會很陽春，只會指出單一條規則被違反的情況。
之後的練習會探討更貼近現實的密碼檢查器，它能夠同時指出多條被違反的規則。
~~~~

## 1. 實作`checkPassword`函式

`checkPassword`函式會依據上述規則檢查指定的密碼。失敗時，它會將其中一個`PasswordRule`值封裝進結果值中，藉此指出違反了哪一條規則。

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. 實作``getStatusMessage`函式

`getStatusMessage`函式會回傳一個字串，內容是讓人看得懂的訊息，說明`checkPassword`回傳的結果代表什麼意思。

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
