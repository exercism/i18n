# 測試


我們使用 [pytest][pytest: Getting Started Guide] 作為網站的測試執行器。
如果你想在自己的開發機上執行 Python 軌道的測試，就需要安裝 `pytest`。
你也應該安裝下列 `pytest` 外掛：

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

更多資訊可以在我們網站上的 [Python 測試指南][Python track tests page] 找到。


### 執行測試

若要執行隨附的測試，請在終端機中使用 `cd` 切換到練習所在的資料夾（_請把下方的 `<exercise-folder-location>` 換成你的路徑_）。
測試檔案通常以 `_test.py` 結尾，而且與解答上傳後在網站上執行的測試相同。

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

接著，在終端機中執行 `pytest` 指令，並把 `<exercise_test.py>` 換成測試檔案的名稱：

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### 常用選項
- `-o`：覆寫預設的 `pytest.ini`（_你可以用它來避免標記警告_）
- `-v`：啟用詳細輸出。
- `-x`：第一次失敗時就停止執行測試。
- `--ff`：先執行前一次測試失敗的項目，再執行其他測試案例。

其他選項請使用 `python3 -m pytest -h` 或 `py -m pytest -h`。


### 修正警告

如果你在呼叫 `pytest` 時沒有加上 `pytest -o markers=task`，使用我們新語法的測試可能會出現 `PytestUnknownMarkWarning`：

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

若不想每執行一次測試就輸入一次 `pytest -o markers=task`，你可以使用 `pytest.ini` 設定檔。
我們已經準備好一個，可以從 Python 軌道目錄的最上層下載：[pytest.ini][pytest.ini]。

你也可以自己建立 `pytest.ini` 檔案，內容如下：

```ini
[pytest]
markers =
    task: A concept exercise task.
```

把 `pytest.ini` 檔案放在 Python 軌道練習的_根目錄_或_工作目錄_中，就會註冊這些標記並停止警告。
關於 pytest 標記的更多資訊，可以在 `pytest` 文件中的 [使用屬性標記測試函式][pytest: marking test functions with attributes] 以及 `pytest` 文件中的 [使用自訂標記][pytest: working with custom markers] 找到。

關於自訂 pytest 設定的資訊，可以在 `pytest` 文件中的 [設定檔格式][pytest: configuration file formats] 找到。
