# 簡介

篩選是指從一個序列產生另一個序列，做法是複製原始序列中除了某些元素以外的所有元素。
新序列要包含哪些項目，可以交由述詞函式（一個會求出布林值的函式）來決定，也可以透過與特定物件比較是否相等來決定。

## 用述詞移除元素

`remove-if` 是一個函式，它接受一個述詞函式和一個序列作為引數，並回傳一個序列，其中只包含述詞結果為 false 的那些元素。
換句話說，它會「移除」序列中所有讓述詞求出 true 的元素。不過請注意，這個函式不會修改原始序列！
它會回傳一個少了這些元素的新序列。如果述詞對所有值都為 true，就會回傳一個空序列。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 移除特定項目

如果想從序列中移除某個特定項目，可以使用 `remove`，它接受要移除的項目和一個序列。
序列中所有不等於要移除的項目的值都會被回傳。
注意：相等性預設是用 `eql` 這個[通用相等述詞][concept-equality]來檢查。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
