# 關於

為了展開 C++ 之旅，我們從變數、函式呼叫和註解開始。

## 註解

註解有兩種：單行與多行。
同一行中`//`之後的所有內容都會被編譯器忽略。
多行註解也稱為 C 風格註解。
它們以`/*`和`*/`包圍。
夾在這兩者之間的任何內容也會被忽略。

## 變數

C++ 是一種具型別的語言。
所有型別都必須在編譯時期就已知，而且通常需要明確寫出來。
變數的型別無法改變。
一個名為`years`的整數變數可以這樣宣告：

```cpp
int years;
```

在宣告變數時就初始化是良好的做法。
C++ 提供不同的機制來達成這件事。
使用大括號的版本更符合現代 C++，不過等號版本也很常見。

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ 確實允許使用未初始化的變數。
在變數被刻意設定之前，它的值是未定義的，可能包含任何內容。
為了避免「先使用後設定」的錯誤和未定義行為，建議**一律初始化**。
未定義行為可能在你最意想不到的時刻讓程式當掉，即使先前一直運作得好好的。
再怎麼強調都不為過：務必盡一切代價避免未定義行為。
~~~~

## 算術運算

像`*`、`+`或`-`這類算術運算子可以是一個運算式的一部分，例如`3 * 2`或`tomatoes + potatoes`。

## 更新變數

只要型別不變，你可以重新指定變數的值：

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## 函式

函式有名稱、回傳型別，以及（可能為空的）參數列表。
一個名為`always_fortyseven`、總是回傳 47 的函式會像這樣：

```cpp
int always_fortyseven() {
    return 47;
}
```

接著是`vip_fee`，它有一個參數：
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

或是`total_fee`，這是一個有三個參數、並呼叫了另一個函式的函式。

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

C++ 的函式不會像某些其他語言那樣回傳最後一個敘述的值。
程式碼必須要有`return`關鍵字才能編譯。

### 空白

空白用來排版原始碼，包括空格、定位點和換行。
由於編譯器會忽略不必要的空白，你可以用它來組織程式碼。
聰明地運用空白可以提升程式碼的可讀性。
有不同的排版標準，但這些都只是慣例，編譯器不會強制要求。

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
