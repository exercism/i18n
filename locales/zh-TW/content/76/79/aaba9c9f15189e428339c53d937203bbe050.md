# 簡介

JavaScript 是一種動態語言，支援物件導向、指令式，以及宣告式（例如函數式程式設計）等風格。

## （重新）賦值

在 JavaScript 中，將值賦予名稱有幾種主要方式：使用變數或常數。在 Exercism 上，變數一律以 [camelCase][wiki-camel-case] 撰寫；常數則以 [SCREAMING_SNAKE_CASE][wiki-snake-case] 撰寫。這方面沒有官方指南可遵循，各家公司和組織也各有不同的風格指南。_你可以用任何自己喜歡的方式撰寫變數_。按照練習的準備方式來撰寫變數，好處是它們在網頁介面和大多數 IDE 中會以不同的方式標示。

JavaScript 中的變數可以使用 [`const`][mdn-const]、[`let`][mdn-let]或[`var`][mdn-var]關鍵字來定義。

使用`let`或`var`時，變數在其生命週期內可以指向不同的值。例如，`myFirstVariable`可以用賦值運算子`=`定義並重新定義許多次：

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

與`let`和`var`不同，以`const`定義的變數只能賦值一次。在 JavaScript 中，這項特性用來定義常數。

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 在之後的概念練習中，會探討並說明_常數_賦值／綁定與_常數_值之間的差異。

## 函式宣告

在 JavaScript 中，功能單位會封裝在_函式_裡，若多個函式屬於同一組，通常會把它們放在同一個檔案中。這些函式可以接收參數（引數），並使用`return`關鍵字_回傳_一個值。函式透過`()`語法來呼叫。

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 在 JavaScript 中，宣告函式的方式有_很多_種。這些其他方式看起來和使用`function`關鍵字不同。這個 track 會試著循序漸進地介紹它們，但如果你已經知道這些方式，歡迎自由使用其中任何一種。在大多數情況下，用哪一種並沒有好壞之分。

## 對其他檔案公開

若要讓`function`、常數或變數能在_其他檔案_中使用，必須使用`export`關鍵字將它們[匯出][mdn-export]。接著另一個檔案可以使用`import`關鍵字[匯入][mdn-import]它們。這也稱為模組系統。所有測試的運作方式就是一個很好的例子。每個練習至少有一個檔案，例如`lasagna.js`，其中包含_實作_。此外，至少還會有另一個檔案，例如`lasagna.spec.js`，其中包含_測試_。這個檔案會_匯入_公開（也就是已匯出）的實體，以便測試實作：

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
