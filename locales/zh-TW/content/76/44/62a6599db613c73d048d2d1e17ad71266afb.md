# 關於

`reduce`是 Factor 通用的摺疊運算：它會逐一走訪序列，讓累加器貫穿一個二元 quotation；這個 quotation 接收目前的累加器和下一個元素，並產生新的累加器。

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

自訂的初始值讓 `reduce` 能表達 `sum` 或 `product` 做不到的摺疊。例如，找出序列中的最大值，並在每個元素都比不過它時，改用一個預設值：

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

初始值 `0` 也參與比較，因此全為負數的序列仍然會得到 `0`，而不是它最小的值。

## `produce`：展開運算

`reduce`的對偶運算是 `produce`（位於 [`sequences`][sequences]）：`reduce`會*消耗*序列，`produce`則會*產生*序列。述詞 quotation 會檢查目前的狀態；只要它回傳真，主體 quotation 就會產生下一個元素。

```
produce ( pred quot -- seq )
```

`reduce`與`produce`搭配使用時，就構成 Factor 的摺疊與展開組合。

## 累積歸約

[`math.statistics`][math.statistics]中的累積系列會回傳與輸入長度相同的序列，其中每個元素都是從開頭到該位置（含）為止的歸約結果：

| word          | 累計運算 |
|---------------|-------------------|
| `cum-sum`     | 累計總和      |
| `cum-product` | 累計乘積    |
| `cum-min`     | 累計最小值    |
| `cum-max`     | 累計最大值    |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

當你想觀察某個量在整個序列中*如何*變化，而不只是看它的最終值時，累積歸約就很有用。把它們串接起來也很有用：一個累積運算的輸出本身就是一個序列，可以直接餵進另一個運算。

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
