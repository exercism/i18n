# 提示

## 一般

- 整數值可以定義為一個或多個連續的數字。

## 1. 定義預期的烤箱時間（分鐘）

- 你需要定義一個[方法][methods]，而且不接受任何引數。
- 你需要回傳一個整數值（請參閱[內建型別][built-in types]）。

## 2. 計算剩餘的烤箱時間（分鐘）

- 你需要定義一個帶有單一參數的[方法][methods]。
- 方法的參數是整數。
- 你需要回傳一個整數值（請參閱[內建型別][built-in types]）。
- 你可以使用`-`運算子來減去數值。

## 3. 計算準備時間（分鐘）

- 你需要定義一個帶有單一參數的[方法][methods]。
- 方法的參數是整數。
- 你需要回傳一個整數值（請參閱[內建型別][built-in types]）。
- 你可以使用`*`運算子來相乘數值。

## 4. 計算經過的時間（分鐘）

- 你需要定義一個帶有兩個參數的[方法][methods]。
- 方法的參數型別都是整數。
- 你需要回傳一個整數值（請參閱[內建型別][built-in types]）。
- 你可以[呼叫][invocation]之前定義過的其他方法之一。
- 你可以使用`+`運算子來相加數值。

[methods]: https://docs.scala-lang.org/overviews/scala-book/methods-first-look.html
[built-in types]: https://docs.scala-lang.org/overviews/scala-book/built-in-types.html
[invocation]: https://docs.scala-lang.org/style/method-invocation.html
