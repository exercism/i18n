# General

- 別忘了公開測試所需的所有函式

## 1. Define the Password opaque type, using the "Parse, don't validate" pattern

- Elm 指南有一節在介紹[自訂型別][custom-types]。
- `Password`自訂型別只有一個變體。
- 在 Elm 的慣例中，當自訂型別只有一個變體時，變體和型別會取相同的名稱（在這個例子中，兩者都叫做`Password`）
- 如果你想複習一下，Elm 指南有一節在介紹[Maybe][maybe]。
