# 型別斷言簡介

Go 的介面可能會讓底層型別變得不明確。
型別斷言讓我們可以用以下語法，取出介面值底層的具體值：`interfaceVariable.(concreteType)`。

例如：

```go
var input interface{} = 12
number := input.(int)
```

注意：如果介面變數沒有持有該具體型別的值，這會引發 panic。

我們可以利用型別斷言的兩個回傳值，來測試介面值是否持有特定的具體型別：底層值，以及一個回報斷言是否成功的布林值。
例如：

```go
str, ok := input.(string) // no panic if input is not a string
```

如果`input`持有`string`，`str`就會是底層值，而`ok`會是 true。
如果`input`沒有持有`string`，`str`就會是`string`型別的零值（也就是`""`，空字串），而`ok`會是 false。
無論是哪一種情況，都不會發生 panic。

## 型別切換

**型別切換**可以依序執行多個型別斷言。
它的語法和型別斷言相同（`interfaceVariable.(concreteType)`），但`concreteType`會換成關鍵字`type`。
來看一個例子：

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
