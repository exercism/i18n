# 型別轉換

型別轉換有時也稱為型別強制轉換。
型別轉換是指兩個不同型別的值為了執行某個運算，而被強制轉換成相同的型別。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

當這個運算式被求值時，字串值會被隱式轉換成`int`，以符合`*`運算子的預期。
至於該強制轉換成哪一種型別，則由 PHP 依照該運算的規則來決定，而這些規則的差異相當大。

呼叫函式和方法時也會發生型別強制轉換：

```php
strlen(12321);
# => 5
```

## 型別轉型

除了依賴隱式強制轉換之外，我們也可以使用`C`風格的型別轉型，明確地強制某個值以特定型別來求值：

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

這會把值轉換成括號`(...)`中指定的型別。
所有基本型別都可以作為目標型別：`bool`、`int`、`float`、`string`、`array`、`object`。

## 僅限暫時轉換

型別轉換或型別轉型**並不會改變**儲存在變數中的值的型別。
只有運算的輸入會被轉換。

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## 資訊遺失

當值被強制轉換成另一種型別時，過程中可能會遺失部分資訊：

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

無論是顯式還是隱式地依賴型別轉型，都可能在較大的系統中產生錯誤。

## 顯式轉型成`array`和`object`

值也可以轉型成`array`和`object`型別。
如果一個不是陣列或物件的值被轉型成`array`，它會被轉換成陣列中的單一項目：

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

當轉型成`object`時，值會被設定成名為`scalar`的公開屬性：

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass`是 PHP 內建匿名類別的型別。
