# 簡介

結構是建構在[映射][exercism-maps]之上的擴充，可提供編譯期檢查與預設值。結構會以其定義所在的模組命名。要定義結構，請使用`defstruct`建構。這個建構通常緊接在模組定義之後。`defstruct`可接受原子清單（用於`nil`預設值）或關鍵字清單（用於指定的預設值）。沒有預設值的欄位必須排在具有預設值的欄位之前。

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## 存取欄位與更新

由於結構建構在映射之上，我們可以使用大多數的映射函式來取得及操作值。結構並**未**實作 _Access Behaviour_。建議改用 _靜態存取運算子_`.`來存取結構欄位。

- 取得/提取欄位值：

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- 更新欄位值

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## 模式配對

結構可以在模式配對中使用，無論是否包含結構名稱。

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

將結構名稱包含在模式中，可以確保左側和右側都是相同型別的結構。

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## 強制初始化欄位值

我們可以使用`@enforce_keys`模組屬性搭配欄位鍵清單，以確保在建立結構時初始化這些值。若某個鍵未被列出，其值會如上述範例所示為`nil`。若強制的鍵未被初始化，就會引發錯誤。

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
