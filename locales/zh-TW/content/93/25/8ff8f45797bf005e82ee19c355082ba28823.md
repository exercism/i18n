# 關於

來自[`grouping`][grouping]和[`splitting`][splitting]的 4 個詞，幾乎能滿足所有「把序列切成片段」的需求：

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| 詞                | 效果                                                                     |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`，互不重疊、大小為 *n* 的區塊                        |
| `clump`           | `( seq n -- clumps )`，互相重疊、大小為 *n* 的視窗                        |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`，當 quot 為真時斷開               |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`，當*相鄰*的 quot 為 `f` 時斷開    |

一個實用的心智模型：

- **`group` / `clump`** 看的是大小；參數 *n* 決定每個視窗有多大。
- **`split-when`** 看的是*單一元素*；判斷函式決定每個元素是不是一個「斷點」。
- **`monotonic-split`** 看的是*成對元素*；判斷函式決定兩個相鄰元素是否仍屬於同一段。
