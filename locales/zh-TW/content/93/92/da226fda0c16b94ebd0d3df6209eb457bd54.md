# 關於

C# 中的陣列是基本型別的值，或結構與類別的執行個體的集合。它們在基底類別庫中以 [`List<T>`][lists-docs] 的形式實作，其中`T`是陣列中項目的型別。API 提供了一組豐富的方法，可用來建立及操作陣列。

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

集合的定義通常會在角括號中放一個預留位置，依慣例通常命名為`T`。如此一來，集合的使用者就能指定要在集合中存放哪種型別的項目。

和 [concept:csharp/arrays]() 不同，陣列可以動態調整大小。

## LINQ

雖然`List<T>`內建的 API 很豐富（包含`ConvertAll`、`FindAll`和`Foreach`等對應與篩選功能），它的[迴圈語法][for-each]也非常清楚，而且你確實需要熟悉這套 API，但語言整合查詢（[LINQ][linq]）可用於許多工作，功能更強大、使用也更廣泛，還有一項優點：能在程式庫集合、第三方集合和你自己的類別之間提供一致的介面。
