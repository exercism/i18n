# 指示

在這道練習中，你會寫程式碼來分析汽車工廠裡組裝線的生產情況。組裝線的速度範圍可以從`0`（關閉）到`10`（最高）。

在最低速度（`1`）時，每小時會生產`221`輛車。產量會隨速度呈線性成長，所以當速度設為`4`時，每小時應該生產`4 * 221 = 884`輛車。不過，速度越高，越可能生產出瑕疵車，這些車之後必須丟棄。下表說明速度如何影響成功率：

- `0`：成功率 0%。
- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

你有三個任務。

## 1. 計算成功率

實作`successRate`函式，根據生產速度計算成功率：

```fsharp
successRate 6
// => 0.9
```

## 2. 計算每小時的產量

實作`productionRatePerHour`函式，計算組裝線每小時的產量，並把成功率納入考量：

```fsharp
productionRatePerHour 6
// => 1193.4
```

請注意，回傳的值是`float`。

## 3. 計算每分鐘生產的正常車輛數量

實作`workingItemsPerMinute`函式，計算每分鐘能生產多少正常運作的車輛：

```fsharp
workingItemsPerMinute 6
// => 19
```

請注意，回傳的值是`int`。
