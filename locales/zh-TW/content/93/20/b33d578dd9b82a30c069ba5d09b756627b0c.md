# 安裝

如要在你的系統上安裝 Julia，請依照 [Julia 語言下載頁面](https://julialang.org/downloads/) 上的說明操作。

~~~~exercism/caution
不建議透過作業系統的套件管理工具來安裝 Julia。那些套件並非官方維護，可能會造成問題。
~~~~

如果想在本機安裝，有大量編輯器／IDE 的外掛可以使用。[VS Code 擴充套件](https://github.com/julia-vscode/julia-vscode) 是最受歡迎的一個。其他編輯器的整合功能，可以在 GitHub 上的 [JuliaEditorSupport](https://github.com/JuliaEditorSupport) 組織中找到。

如果你偏好互動性更高的環境，可以搭配 [IJulia](https://github.com/JuliaLang/IJulia.jl) 使用 Jupyter 筆記本，或是用 [Pluto.jl](https://github.com/fonsp/Pluto.jl) 在 Julia 裡撰寫簡單的響應式筆記本。

如果想在不需要本機安裝的情況下開始使用 Julia，最簡單的方法是 [Nextjournal](https://nextjournal.com/)，這是一個以筆記本為基礎的線上 IDE。你可以直接從瀏覽器開啟、登入，然後就能開始解練習了。如果你只是想要一個線上 REPL，可以使用 [Repl.it](https://repl.it/languages/julia)。
