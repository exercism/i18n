# 提示

## 1. 為員工印出識別證

- 你可以用[字串模板][string-template]來建立描述用的字串。
- 有[可以將字串轉成大寫的內建方法][to-upper-case]。

## 2. 為新進員工印出識別證

- 使用 ID 之前，你應該先檢查它是不是 `null`。
- 你可以用[相等運算子][kotlin-operators]來檢查某個值是不是 `null`。

## 3. 為擁有者印出識別證

- 當變數是 `null` 時，你可以用 [Elvis 運算子][elvis-operator]，改用替代值。
