# 不可變類別

`SCOREBOARD` 是會變動的東西。同一個計分板有兩個名字，兩者看到的是同一個分數，因為只有一塊板子，而兩個名字都指向它。

方位不是這樣。`350 degrees` 不會變成別的東西，它就是它自己。數字如此，字串也是如此，而你自己寫的類別也可以如此。

## immutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

兩個字就改變了一切。不可變類別的物件是一個**值**，不是被指向的東西：

- 被指定或傳遞時會複製，所以別人改不了你的；
- 它永遠不會是 void；
- 而且它的屬性不能被指定。

## 用產生另一個來改變

既然不允許 `degrees := 90`，`attr` 提供的是別的東西：一個常式，接收新值，並回傳一個把它改掉的**新物件**。

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

原本的物件完全沒被動到。這就是整套慣用法，`create` 也是這樣寫的：

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

這裡沒有 `new`。不可變物件永遠存在，所以 `b : SAME` 本身就已經是一個，每個屬性都停在它的空值。

因此，一個「改變」方位的常式會回傳一個新的方位：

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## 比較

值是依它們所持有的內容來比較，而不是依它們是哪個物件，但你得說明怎麼比。寫 `is_eq`，`=` 就會用它：

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

少了它，兩個方位上的 `=` 會無法編譯。

## 該選哪一種

當某個東西沒有身分，而且它沒有任何部分能合理地改變時，就用不可變類別：方位、點、日期、長度。當某個東西是特定的一個東西，而事情會發生在它身上時，就用一般類別：計分板、測試骨架、檔案。

判斷的標準是：「相同」指的是「相等」，還是「就是同一個」。
