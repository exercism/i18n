# 簡介

`null` 值用來表示值的_不存在_。**可為 null 的型別**是一種允許變數取`null`值的型別。只要用 `Null<T>` 把型別包起來，就能讓任何型別變成可為 null：

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

要檢查某個值目前是不是`null`，用 `if` 運算式就可以了：

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
