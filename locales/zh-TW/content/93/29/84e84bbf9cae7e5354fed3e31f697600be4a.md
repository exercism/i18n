# 簡介

## 陣列

在 F# 中，`list`是不可變的集合，包含零個或多個值。陣列中的值都必須具有相同的型別。由於陣列不可變，一旦建立陣列，其值就永遠不會改變。任何看似會修改陣列的函式或運算子（例如加入元素），實際上都會回傳新的陣列。

陣列可以如下定義：

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

將元素加入陣列最常見的方式，是使用 `::`（cons）運算子：

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

F# 陣列有一個 _頭部_（第一個元素）和一個 _尾部_（第一個元素之後的所有內容）。陣列的尾部本身也是陣列。

陣列可以透過 `List` 模組中定義的函式和運算子來操作，也可以使用 _list_ 和 _cons_ 模式手動進行模式比對：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

你也可以在模式比對時 _捨棄_ 某個值；當你在特定情況中 _不在意_ 某個值（也就是你不打算 _使用_ 它）時，可以使用底線（`'_'`）來表示這點：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

在模式比對時，單獨的 `'_'`應該總是最後出現；任何不符合其他情況的值，都會由這個情況處理。
