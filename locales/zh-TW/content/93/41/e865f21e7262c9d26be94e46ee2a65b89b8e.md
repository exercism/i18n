# 測試

只要切換到練習目錄，然後執行`odin test .`，就能在 exercism 專案目錄中執行 Odin 練習。

```sh
cd "$(exercism workspace)"/odin/leap
odin test .
```

## 啟用語言檢查

在測試的同時，Odin 可以「vet」你的程式碼：它可以找出未使用的匯入和變數等問題。

用以下指令執行測試：

```sh
odin test . -vet
```

想檢查更多項目，就加上`-strict-style`選項。

## 測試驅動開發（TDD）

`odin test`會執行每一個帶有`@(test)`屬性的程序。

在測試套件中，你會發現每個測試程序都有這個屬性。
這表示當你啟動測試時，每個測試程序都會執行。

Exercism 一般提倡[測試驅動開發][tdd]，做法如下：

- 一開始，除了第一個測試以外，其餘測試都設定成跳過；
- 你只要寫剛好能通過第一個測試的程式碼；
- 接著啟用下一個測試，並寫剛好能讓它通過的程式碼；
- 重複這個流程，直到你的程式碼通過所有測試。

我們（維護者）一直找不到優雅的方法，用程式的方式只執行其中一部分測試。
測試檔就是變得太大、太難以駕馭了。
想用 TDD 開發的話，你可以直接編輯測試檔，把還沒準備好執行的測試註解掉，然後隨著你寫出解法，一個一個把它們取消註解。
