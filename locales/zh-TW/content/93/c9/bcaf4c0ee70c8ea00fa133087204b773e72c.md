# 提示

## 一般

- 用 [`combinators`][combinators] 裡的 `cond` 來把速度對應到成功率，是最簡潔的做法。
- 算術相關的字詞都在 [`math`][math] 裡；浮點數轉整數的輔助函式 `floor` 和 `>integer` 則分別位於 [`math.functions`][math.functions] 和 `math`。

## 1. 回報產線是否正在運轉

- `zero?`（位於 [`math`][math]）可以測試速度是否為 `0`。
- `if` 接受一個布林值和兩段引文，也就是 `[ "stopped" ] [ "running" ]`，然後執行符合的那一段。在這裡，速度會被測試消耗掉，所以兩段引文都不需要 `drop`。

## 2. 計算成功率

- 一個 `cond` 子句的形式是 `{ [ predicate ] [ body ] }`。每個判斷式會檢查速度，但應該讓堆疊保持原樣（用 `dup` … `<test>` 就能做到）。主體通常以 `drop` 開頭。
- 順序很重要：要先檢查 `zero?` 再檢查 `4 <=`，因為 `0 4 <=` 的結果是 `t`。
- 用一個不含判斷式的最後條目，作為速度 `10` 的預設值。

## 3. 計算每小時生產率

- 在檔案開頭附近用 `CONSTANT:` 定義 `base-speed`（就像 `lasagna` 裡的 `expected-bake-time` 一樣）。
- 計算 `base-speed * speed * success-rate`。其中一個做法是使用 `kernel` 裡的 `bi`：它會對同一個輸入執行兩段引文，並把兩個結果都留在堆疊上。

## 4. 計算每分鐘生產的可用成品數量

- 把每小時的生產率除以 60。
- 用 `floor` 去掉小數部分，再用 `>integer` 把浮點數結果轉成整數。
