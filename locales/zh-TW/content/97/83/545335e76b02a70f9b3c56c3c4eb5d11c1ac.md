# 指示

在這道練習中，你會寫一些程式碼，幫助自己準備買一輛車。

你有三個任務：判斷自己需不需要駕照、在兩輛車之間做選擇，以及估算一輛二手車的合理價格。

## 1. 判斷你是否需要駕照

有些車輛種類需要駕照才能操作。
假設只有`"car"`和`"truck"`這兩種需要駕照，其他種類都可以在沒有駕照的情況下操作。

實作`needs_license(kind)`函式，它接收車輛種類作為字串，並回傳一個布林值，指出你是否需要那種車輛的駕照。

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. 在兩輛可能購買的車之間做選擇

你先評估手邊可選的車輛。
你成功把選項縮小到兩輛，但還需要幫忙做出最後決定。
為此，請實作`choose_vehicle(option1, option2)`函式，它接受兩輛車作為引數，並回傳一個決定，其中包含依字典序排在最前面的選項。

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

回傳的字串應該遵循「<CHOSEN_VEHICLE> is clearly the better choice.」的形式，其中`<CHOSEN_VEHICLE>`是從傳入的引數中選出的那個選項。

## 3. 估算一輛二手車的價格

既然做完了決定，你會想確保自己在車商那裡拿到合理的價格。
由於你想買的是二手車，價格取決於車齡。
粗略估算的話，假設車齡未滿 3 年，價格是全新時原價的 80%。
如果車齡至少 10 年，價格是 50%。
如果車齡至少 3 年但未滿 10 年，價格是原價的 70%。

實作`calculate_resell_price(original_price, age)`函式，用`if`、`else if`和`else`套用這套邏輯（如果你想練習，也有其他寫法）。
它接受原價和車齡作為引數，並回傳車商估算的價格。

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> 注意：回傳值的型別是`double`。
