# 說明

在這個練習中，你會安排各種不同類型遙控車之間的比賽。每台車都有自己的速度和電池耗損特性。

車子一開始的電池都是滿的（100%）。每次你用遙控器駕駛車子時，車子會前進相當於其速度的距離（以公尺計），並依電池耗損量減少剩餘的電池百分比。

如果車子的電池低於其電池耗損百分比，就無法再駕駛這台車。

每條賽道都有自己的長度。車輛的測試方式是檢查它們能否在電池耗盡前跑完全程。

## 1. 建立一台遙控車

定義一個`car`陣列，包含下列元素：

- speed
- battery_drain
- battery
- distance_traveled

定義一個函式`new_car`，接受車速（以公尺計）和電池耗損百分比作為兩個參數，並回傳一個`car`陣列，就可以建立一台遙控車。

新車的電池為 100%，行駛距離為零。

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. 建立一條賽道

定義另一個名為`track`的陣列，只有一個元素`track_length`。
定義一個函式`new_track`，接受賽道距離（以公尺計），就可以建立一條賽道：

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. 檢查電池是否耗盡

實作`battery_drained()`函式，用來指出電池是否已耗盡。
當電池不足以再移動一次時，即視為耗盡。

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. 駕駛車子

實作`drive`函式，根據車速更新已行駛的公尺數，並依電池耗損量減少電池。
如果電池不足以再行駛一次，車子就不會移動。

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. 檢查遙控車是否能完成比賽

要完成比賽，車子必須能行駛完賽道的長度。這表示它不能在越過終點線之前耗盡電池。

實作`can_finish`函式，接受一個`car`和一個`track`作為參數，如果車子能完成比賽就回傳`TRUE`；否則回傳`FALSE`。

假設你現在位於比賽的起跑線，正為比賽發動車子的引擎。請考慮到車子在開始比賽時，電池未必是滿的。

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. 儲存車子在滿電狀態下是否能完成某條賽道

你已經建立了幾條長度不同的賽道，需要儲存你的車子在滿電狀態下是否能完成這些賽道。

實作`store_track`函式，接受一台車、一條賽道和一個賽道名稱，並回傳帶有額外元素的更新後車子。
這個元素的名稱應該是賽道的`name`，其值則是一個子陣列，包含`track_length`以及車子是否能`complete`它。

引數中提供的車子可能不是滿電的，所以在使用前，務必重設電池和已行駛的距離。

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
