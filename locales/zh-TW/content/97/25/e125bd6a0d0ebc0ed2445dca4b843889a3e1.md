# 關於

每一支你執行過的程式，無論是遊戲、網頁瀏覽器還是手機應用程式，最後都會變成一長串微小的指令，由處理器一次執行一個。
組合語言，就是讓你親自寫下這些指令的方式。
你不必使用變數、陣列和`for`迴圈，而是直接使用處理器自己的積木：少數幾個暫存器、記憶體位址，以及從一個指令跳往另一個指令的跳躍。

RISC-V（讀作「risk five」）是一種處理器設計，2010 年起源於加州大學柏克萊分校。
有別於大多數處理器設計，它是開放標準：打造 RISC-V 晶片不必付費，也不必取得許可，而且任何人都能免費閱讀它的規格書。
RISC-V 晶片可見於微控制器、單板電腦、儲存裝置等各種地方。

RISC-V 是很適合入門的第一個組合語言，因為它的設計宗旨就是簡單。
它的指令只遵循少數幾種固定模式，而它的 32 個暫存器各有清楚且一致的角色，所以需要記的東西比大多數筆記型電腦裡的處理器少得多。
也正因為這份簡單，現在有許多大學用 RISC-V 來教電腦的運作原理。

這裡先小嚐一口，看一個把兩個數字相加的函式吧：

```riscvasm
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

在這條學習軌道上，你寫的是 32 位元的 RISC-V 組合語言。
你不需要任何 RISC-V 硬體：你的程式會在模擬器上測試，而模擬器會假裝自己是一顆 RISC-V 處理器。
你可以在線上編輯器裡做練習，也可以在自己電腦上用免費工具來做。

學組合語言需要耐心，但很值得喔。
一旦你看過迴圈或函式呼叫在處理器眼中是什麼樣子，其他每一種程式語言都會變得稍微好懂一些。
