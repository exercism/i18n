# 學習 PowerShell

開始學習 PowerShell 的好方法，是從 PowerShell 網站的[學習專區][learning section]挑選一項學習資源。
這裡有大量資訊，以及各種 PowerShell 主題的連結。

PowerShell 也有一套非常完整、能自我說明的說明系統。
你可以使用`Get-Help` Cmdlet 來探索 PowerShell 提供的許多功能。
在 PowerShell 中，試試看：

```PowerShell
Get-Help about
```

你會看到大約 3 頁可供探索的主題。
另外還有兩個非常有用的函式：

- Get-Command
- Get-Member

想知道這些能做什麼嗎？
當然，試試`Get-Help Get-Command`和`Get-Help Get-Member`。

## PowerShell 的動詞與名詞

PowerShell 的 Cmdlet 命名遵循相當嚴格的「動詞-名詞」規則。
剛開始，這對經驗豐富的程式設計師來說可能會有些突兀。
雖然你可以隨意命名你的函式，但熟悉並採用標準動詞，將能提升你的 PowerShell 程式設計。

若要查看所有已核准的動詞清單，只要執行：

```PowerShell
Get-Verb
```
