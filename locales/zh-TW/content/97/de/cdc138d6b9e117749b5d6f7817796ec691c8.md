# 簡介

除了字元類別和量詞之外，正規表達式還能描述*結構*和*情境*。這些功能同樣存在於[`regexp`][regexp]詞彙，以及相同的`R/ /`字面值之中。

括號`( )`會把模式的一部分群組起來，讓量詞或`|`（「這個或那個」）套用到整個群組；群組後面加上`?`，就會讓它變成選用：

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

錨點會把模式固定在某個位置上：`^`（開頭）、`$`（結尾），以及`\b`（單字邊界）。

*環視*會比對某個位置周遭的內容，而不會消耗它：

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

在結尾的`/`後面加上選項字母，會改變整個模式；`i`則會讓它變成不分大小寫：

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor 用環視來取代捕獲群組：它沒有捕獲群組擷取、反向參照，也沒有惰性量詞。

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
