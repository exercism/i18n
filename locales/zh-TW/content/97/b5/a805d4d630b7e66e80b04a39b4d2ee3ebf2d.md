# 介紹

## 浮點數

浮點數是帶有小數點後零或多個位數的數字。例如`-2.4`、`0.1`、`3.14`、`16.984025`和`1024.0`。

不同的浮點數型別可以儲存不同數量的小數點後位數，這就是所謂的精確度。

C# 有三種浮點數型別：

- `float`：4 位元組（約 6 到 9 位精確度）。寫作`2.45f`。
- `double`：8 位元組（約 15 到 17 位精確度）。這是最常見的型別。寫作`2.45`或`2.45d`。
- `decimal`：16 位元組（28 到 29 位精確度）。通常在處理貨幣資料時使用，因為它的精確度能降低捨入誤差的機率。寫作`2.45m`。

如你所見，每種型別可以儲存不同數量的位數。舉例來說，試著把 PI 存進`float`，只會儲存前 6 位小數（最後儲存的那一位會四捨五入）。

## `while`迴圈

在這個練習中，你可能會想使用迴圈。在 C# 中有幾種寫迴圈的方式，不過在這裡`while`迴圈最合適：

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## `do`/`while`迴圈

如果迴圈中的程式碼至少要執行一次，可以使用`do`/`while`迴圈：

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
