# 操作說明補充

## Arturo 專屬資訊

在這個練習中，你需要使用帶有自訂單位的[物理量]來回傳年齡，該單位代表該行星上一年的長度。
在 Arturo 中，一個量值由數值量和相關的[測量單位][unit-of-measurement]組成。

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Arturo 內建的 `yr 單位會轉換成 31556952 秒。
因此，你需要以先前在操作說明中提到的秒數為基準，定義並使用自己的年度單位。
~~~~

量值可以[轉換][convert]成另一個相容的單位。
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
由於浮點數的精確度限制，Arturo 有時會將純量儲存為有理數。
你可以改用 [`to`函式][to]，以近似浮點數的形式取得該數值。

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo 也允許我們 [specify] 自己的量值單位。

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
