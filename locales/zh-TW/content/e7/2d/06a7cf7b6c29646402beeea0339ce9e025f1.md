# 沒有具名匯出

找不到名為`%{export.name}`的 [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)。少了它，測試就不會通過。

請確認`%{export.name}`存在，並在它前面加上`export`：
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
