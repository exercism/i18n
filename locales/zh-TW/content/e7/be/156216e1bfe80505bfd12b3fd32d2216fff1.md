# 說明

在這個練習中，你要再多寫一些程式碼，幫你做出最愛食譜書裡的完美千層麵。

你有 5 個任務，全都跟烹調千層麵所花費的時間有關。

## 1. 允許更改預期的烤箱時間

你想寫一個改良版的`remainingMinutesInOven`函式，它接收千層麵已經在烤箱裡的經過分鐘數作為參數，並根據上一個任務中預期的烤箱時間（以分鐘計），回傳千層麵還得在烤箱裡待幾分鐘。

先前，你依賴的是來自`remainingMinutesInOven`函式外部的常數值`expectedMinutesInOven`。

這對你來說既有點太雜亂，也不夠有彈性，因為它不讓你能更改預期的烤箱時間。

為了整理一下，請定義`remainingMinutesInOven`函式，它接收千層麵已經在烤箱裡的經過分鐘數作為參數，同時也接收一個預設值為 40 的`expectedMinutesInOven`參數。

你的函式應該根據上一個任務中預期的烤箱時間（以分鐘計），回傳千層麵還得在烤箱裡待幾分鐘。

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. 允許不同數量的層數

你先前寫過一個`preparationTimeInMinutes`函式，它接收你加到千層麵裡的層數作為參數，並回傳你花了幾分鐘準備千層麵，假設每一層要花你 2 分鐘準備。

不過，你對這個函式不太滿意，因為在呼叫它之前，你得自己先數千層麵裡有幾層，誰有那麼多時間啊？

為了讓自己輕鬆一點，請寫一個函式`preparationTimeInMinutes`，它接收一個可變的`String`參數`layers`，你可以在裡面列出千層麵的不同層。

這個函式接著會計算千層麵裡的層數，並回傳所需的準備時間。

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. 計算麵條和醬汁的用量

在開始組裝千層麵之前，你想確認自己有足夠的醬汁和麵條，能做出夢想中的千層麵。

千層麵裡的每一層麵條，你需要 3 片麵條。

千層麵裡的每一層醬汁，你需要 0.2 公升的醬汁。

請定義函式`quantities`，它接收一個可變的`String`參數`layers`，你可以在裡面列出千層麵的不同層。

這個函式接著會算出製作這道餐點所需的麵條和醬汁數量。結果應該以`(noodles: Int, sauce: Double)`型別的元組回傳。

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. 原地將公升轉換成液體盎司

不幸的是，你手邊的醬汁，容量標示的是液體盎司，而不是公升。

為了幫你判斷手邊的醬汁是否足夠，請寫一個函式`toOz`，它接收一個 in-out 元組參數`(noodles: Int, sauce: Double)`，並把醬汁的量轉換成液體盎司。

注意，每公升有 33.814 液體盎司。

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. 判斷最適合搭配的葡萄酒

最後，你想知道該用哪種葡萄酒來搭配你的千層麵。

你聽說，如果千層麵裡的莫札瑞拉起司、瑞可塔起司和白醬比肉和醬汁多，就該搭配白酒，否則就搭配紅酒。

請寫一個函式`redWine`，它接收一個可變的`String`參數`layers`，你可以在裡面列出千層麵的不同層。

這個函式會用 5 個巢狀函式，判斷千層麵裡莫札瑞拉起司、瑞可塔起司、白醬、醬汁和肉的層數，並比較這些層數，判斷是否該搭配紅酒，若是就回傳`true`，否則回傳`false`。

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
