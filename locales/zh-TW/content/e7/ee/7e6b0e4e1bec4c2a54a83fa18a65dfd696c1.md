# 簡介

Julia 中有三種主要的條件敘述：

- `if` 運算式
- 三元運算子
- 短路求值

## `if` 運算式

Julia 的 `if` 運算式與其他語言中的類似：

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

如果 `if` 後面的布林運算式求值為 `true`，就會執行第一個程式區塊，並跳過第二個程式區塊。
如果 `if` 後面的布林運算式求值為 `false`，就會跳過第一個程式區塊，並執行第二個程式區塊。
程式會從 `end` 關鍵字後面的第一行程式碼繼續執行。

~~~~exercism/note
在 Julia 中，`end` 關鍵字代表所有區塊運算式的結尾。
這個語法並非 `if` 運算式或函式定義專屬。
~~~~

如果第二個程式區塊本身就是另一個 `if` 運算式，可以用 `elseif` 避免在區塊中巢狀 `if` 運算式：

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

如果 `if` 運算式只需要在其中一種情況下執行程式碼，就不需要寫出 `else` 分支。

## 三元運算子

簡單的 `if-else` 敘述也可以用三元運算子 `a ? b : c` 來寫。
如果 `a` 為 true，就會對 `b` 求值。
否則對 `c` 求值。

舉例來說，下面這個函式

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

也可以寫成

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

如果想根據條件把不同的值指定給變數，這個用法特別有用。
如果 `a` 為 `true`，`x = a ? b : c` 會把 `b` 指定給 `x`，否則把 `c` 指定給 `x`。
例如：

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## 短路求值

如果用 `&&` 和 `||` 運算子把多個布林運算式串在一起，Julia 只會對判斷整串運算式值所需的必要運算式求值。

舉例來說，考慮運算式串 `n > 0 && k > 10`。
如果 `n` 等於 `5`，串中的第一部分 `n > 0` 為 `true`，就必須對第二個運算式 `k > 10` 求值，才能判斷整個運算式是否為 `true`。
不過，如果 `n` 等於 `-5`，我們知道整串運算式**不可能**為 `true`，因為它的第一個運算式是 `false`。

如果改成考慮 `n > 0 || k > 10`，情況正好相反。
如果 `n` 等於 `5`，串中的第一部分 `n > 0` 為 `true`，無論第二個運算式是什麼，整串運算式都會是 `true`。
不過，如果 `n` 等於 `-5`，就必須對第二個運算式求值。

這個行為可以用來寫出非常簡短的 `if` 敘述：

```julia
if a
    b
end
```

等價於

```julia
a && b
```

一串 `&&` 和 `||` 中的最後一個運算式不必是布林運算式。
你經常會看到這個功能被用來提早拋出錯誤或回傳。
舉例來說，使用上面提過的 `dessert(fruit)` 函式：

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
