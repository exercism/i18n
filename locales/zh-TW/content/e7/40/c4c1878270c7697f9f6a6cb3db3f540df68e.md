# `jq`中的函式

你可以在`jq`中定義自己的**自訂函式**，用來封裝你需要的任何邏輯。_函式_的行為就跟內建函式一樣：它們接收一個輸入，並產生零個、一個或多個輸出。

## 定義函式

你可以用下列語法定義`jq`_函式_：

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- 以`def`關鍵字開頭，
- 函式主體前面有一個冒號，
- 主體由單一運算式組成，
- 以分號結尾，
- 就像`jq`語法的其他部分一樣，你可以為了可讀性使用任意的空白。

## 函式要放在哪裡

_函式_必須先定義才能使用：下面這樣是錯誤：

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

這表示你必須把_函式_放在`jq`程式碼的開頭，也就是「主」運算式之前。

### 巢狀函式

_函式_可以巢狀：

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

在這裡，`B`_函式_只在`A`的主體內可見。

## 作用域

_函式_會為變數和巢狀函式引入一個新的**作用域**。

## 引數

_函式_的**引數**以_分號_分隔，而不是逗號。
例如，一個接收數字，然後加上一個數字並乘以一個數字的_函式_：

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

<!-- prettier-ignore -->
~~~~exercism/note
需要分號，是因為逗號在`jq`中已經有個用途：用來串接串流的運算子。

用逗號取代分號，會試圖對一個只收_一個引數_的`add_mul`函式做兩次呼叫，而這個函式並不存在，因此會在第一次嘗試呼叫時失敗：

```jq
10 | add_mul(5, 4)
# error: add_mul/1 is not defined
```

`5, 4`中的逗號會把數字 5 和 4 串接成一個串流。
當我們以串流作為引數呼叫函式時，`jq`會多次呼叫該函式，串流中的每個值各一次。
這是`jq`串流本身固有的「隱含疊代」的一個例子。
`10 | add_mul(5, 4)`等價於下面這樣。

```jq
(10 | add_mul(5)), (10 | add_mul(4))
```
這樣就能看出`add_mul/1 is not defined`這個錯誤是怎麼冒出來的了。
~~~~

### 引數是_運算式_

函式的_引數_是過濾器，而不是值。
就這層意義來說，它們的行為就像其他語言所說的回呼：

以`add_mul`函式為例：

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

這裡發生了什麼事？

- `adder`引數取得的是_運算式_`. + 5`
  - 當函式執行`. + adder`時，那會變成`. + . + 5`
  - 由於`. == 10`，它求值為 25
- 同樣地，`multiplier`引數是運算式`. - 2`
  - 它求值為 8
  - 於是結果是`25 * 8 == 200`

### 引數作為值

有時你會想把_引數_「具體化」成變數：

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

這有個簡寫：

```jq
def my_func($arg):
    other stuff ...
;
```

請注意，這只是「語法糖」：不帶`$`的名稱`arg`在_函式_內仍然在作用域中。

<!-- prettier-ignore -->
~~~~exercism/caution
舉例來說，我為了求解一個練習題，寫了像這樣的東西：

```jq
# function that encodes the input value
def code:
    # expression here
    ;

def equals($code):
    (. | code) as $this_code
    | $code == $this_code
    ;

("some key value" | code) as $key
| ["array", "of", "values"]
| map(select(equals($key)))
```

結果我驚訝地發現，陣列裡的每個值都等於那個鍵。

會發生這種事，是因為 jq 把`equals`函式看成

```jq
def equals(code):
    code as $code
    | (. | code) as $this_code
    | $code == $this_code
    ;
```

**引數**`code`_覆蓋_了先前定義的**函式**`code`。
這表示`(. | code)`只會輸出那個**引數**，而不是根據輸入值計算出新的編碼。
因此`$this_code`和`$code`永遠相同。
~~~~

## 引數個數

_函式_有**引數個數**，也就是它接收的_引數_數量。

_函式_可以同名，但_引數個數_不同。
內建的[`range`][man-range]函式就示範了這一點：`range/1`、`range/2`和`range/3`可以同時並存。

這在定義透過引數攜帶狀態的遞迴函式時很有用。
例如`map`_可以_這樣實作：

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## 遞迴

`jq`會執行尾呼叫最佳化，但僅限於引數個數為 0 的函式。

## 模組

`jq`模組是一個只包含函式的檔案。
模組透過[`include`][man-include]或[`import`][man-import]指令納入 jq 程式。
