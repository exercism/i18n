# 簡介

許多程式需要（看似）隨機的值來模擬真實世界的事件。

常見又熟悉的例子包括：

- 擲硬幣：一個隨機的值，可能是`"H"`或`"T"`。
- 擲骰子：一個 1 到 6 的隨機整數。
- 洗牌：把一份牌清單隨機排序。

用電腦產生真正隨機的值，是[出乎意料地困難的技術挑戰][web-truly-random]，所以你可能會看到這類結果被稱為「偽隨機」。

***重要***：這個概念*不*涵蓋密碼學上安全的隨機數，那是困難得多的挑戰。

不過，R 衍生自統計套件，而且經常用於模擬，因此它提供了各式各樣產生隨機值的方法。這些結果對大多數的建模、模擬與遊戲應用來說都已經夠好了。

## [放回與不放回的取樣][yt-sampling-with-replacement]

想像袋子裡有 3 顆紅球和 4 顆綠球，我們隨機從袋子裡抽出一顆球。要再抽第二顆球，有兩種做法：

1. 把第一顆球放回袋子，充分搖勻之後再抽出另一顆。袋裡的球數和之前相同（7 顆），而且*紅球與綠球的比例也一樣*。
2. 把第一顆球放到桌上，再抽出第二顆。現在袋子裡只剩 6 顆球，而且*紅綠比例取決於第一顆球的顏色*。

情境 1 是放回取樣，情境 2 是不放回取樣，而*兩者得到的結果不同*。

## 用`sample`處理離散值

若要從有限個離散值中挑選，可以使用`sample()`，並選擇放回或不放回。這對整數、字串等都很實用。

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

取樣很適合放進資料流程裡。舉例來說，要產生隨機的英數字字串：

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## 洗牌

其他幾種語言有專門用來洗牌的函式。

R 沒有洗牌函式。*為什麼呢？*

要理解這點，再仔細看看`sample`函式。

完整形式是`sample(x, size, replace = FALSE, prob = NULL)`，其中`x`（通常）是要取樣的序列，`size`是要挑選的項目數。

我們已經討論過`replace`，它的預設值是不放回取樣。現在先忽略`prob`，它讓你可以給`x`中各個元素不同的權重。

如果我們省略`size`，只提供`x`，會發生什麼事？

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

以典型的 R 風格來說，這個模式是「向量進、向量出」，而`size`預設為`length(x)`。

「從`x`中不放回地抽出所有元素」，只是「洗牌`x`」比較技術性的說法。

*因此*，沒有`shuffle`函式，因為`sample`已經正好做到我們需要的事！

## 處理分佈

上面的例子描述的是所有結果出現機率都相同的情況。例如，`sample(1:100)`產生 1 到 100 之間任何整數的機率都相同。

這稱為`uniform`分佈。

許多真實世界的情況遠比這單純。因此，統計學家建立了各式各樣的`distributions`，用數學方式描述「真實世界」的結果。

## 浮點數

### 均勻分佈

若要在浮點數上取得等權重的分佈，請用`runif()`（重點擺在「**r**andom-**unif**orm」，並克制把它讀成「run if」這個自然但*錯誤*的傾向）。`min`和`max`都可以指定，不過預設值是 0 和 1。

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
