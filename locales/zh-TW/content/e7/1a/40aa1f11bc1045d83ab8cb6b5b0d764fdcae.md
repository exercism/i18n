# 提示

## 一般

- DFT
    - 這可以直接從 DFT 的定義推出來：`Xₖ = Σ xₙ * ℯ^(-2iπk * n/N)`
    - 雖然複雜度固定是`O(n²)`，但還是有更有效率的方法可以做到。
    - 一般來說，迴圈比矩陣乘法慢。

- FFT
    - 如同簡介所述，這通常是用分而治之的策略來完成，所以遞迴很可能會是你的好幫手，不過`while`迴圈也沒被排除（甚至可能更有效率）。
    - 演算法的概要如下：
        - 當輸入向量的長度小於或等於 1 時，就回傳輸入向量；否則……
        - 把訊號拆成兩部分：索引為偶數的元素`Xₑ`，以及索引為奇數的元素`Xₒ`。
        - 對這兩部分分別執行 FFT。
        - 建立出向量`f(n) = ℯ^(-2iπ * n/N)`的（其中`n`從 0 到 N/2-1）。
        - 把`Xₑ`和`Xₒ`這兩部分重新合併成完整的向量`[Xₑ + f(n) * Xₒ; Xₑ - f(n) * Xₒ]`，其中加法和乘法都是逐元素進行的。
