# 簡介

## 模式匹配常值

`if/else`運算式可以用來執行條件邏輯，但 Haskell 還有一種更強大的方式來執行條件邏輯：[模式匹配][pattern-matching]。
有了模式匹配，就可以把一個值與一或多個_模式_進行比對。
這類模式的其中一個例子是_常數模式_，它會將值與常數進行比對（例如`1`或`"hello"`）。

定義函式時，你可以為不同的模式定義各自的函式主體。
這能讓程式碼簡潔、簡單又易讀。
你可以對任何資料型態進行模式匹配，例如數字、字元、陣列、元組等等。

舉例來說，一個接收整數（`Int`）並讓它往 _0_ 靠近 _1_ 的簡單函式，可以這樣表示：

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

模式匹配與其他模式搭配使用時才真正發揮威力，例如_變數模式_：

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

上述範例會把所有非 _0_ 的輸入一視同仁，因此對負數會產生不正確的結果。
這個問題可以用條件模式來解決，也就是_守衛_，以`|`符號表示：

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

在上述範例中，並非所有可能的輸入都有對應的模式。
編譯器會偵測到這點並發出警告。
這是 Haskell 非常實用的一項功能，能協助確保所有可能的路徑都被涵蓋，以避免執行期間的錯誤。
這稱為_完整性檢查_。
要解決這個警告，你必須處理所有情況。
在_守衛_中，你可以使用`otherwise`運算式作為`True`的語法糖，來捕捉所有剩下的模式。

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

模式匹配會由上而下依序將值與每個模式比對，直到找到相符的模式，並執行該模式對應的邏輯。
**模式的順序很重要！**
