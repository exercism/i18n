# 指令

在這個練習中，你將實作一組實用的常式，協助開發者清理識別字名稱。

在 4 個任務中，你將逐步建構 `clean` 這個常式。有效的識別字由零個或多個字母與底線組成。

在所有情況下，輸入字串保證不為 nil。如果傳入 `clean` 函式的是空字串，就應該回傳空字串。

請注意，呼叫端應避免以空識別字呼叫 `clean` 常式，因為這類識別字不具任何作用。

## 1. 將遇到的所有空格替換為底線

實作 `clean` 函式，將所有空格替換為底線。這也適用於開頭與結尾的空格。

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. 將控制字元替換為大寫字串 "CTRL"

修改 `clean` 函式，將控制字元替換為大寫字串 `"CTRL"`。

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. 將 kebab-case 轉換為 camelCase

修改 `clean` 函式，將 kebab-case 轉換為 camelCase。

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. 省略希臘文小寫字母

修改 `clean` 函式，省略 'α' 到 'ω' 範圍內的所有希臘字母。

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
