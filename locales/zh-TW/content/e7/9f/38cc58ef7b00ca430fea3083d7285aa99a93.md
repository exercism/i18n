# 提示

## 1. 定義預期的烤箱時間（分鐘）

- 定義一個[常數][constants]，內容是食譜中指定的[`number`][numbers]值。
- 用[`export`][export]將這個常數匯出。

## 2. 計算剩餘的烤箱時間（分鐘）

- [從函式明確地回傳數字][return]。
- 使用[減法的數學運算子][operators]來相減。

## 3. 計算準備時間（分鐘）

- [從函式明確地回傳數字][return]。
- 使用[乘法的數學運算子][operators]來相乘。
- 使用額外的常數來表示每層所需的時間（分鐘）。

## 4. 計算總工作時間（分鐘）

- [從函式明確地回傳數字][return]。
- [呼叫][invocation]先前實作過的其他方法的其中一個。
- 使用[加法的數學運算子][operators]來相加。
