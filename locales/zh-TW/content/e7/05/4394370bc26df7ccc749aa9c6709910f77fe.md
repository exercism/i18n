# 簡介

[陣列][list] 是一種可變的集合，其中的項目按*序列*排列。
陣列可以存放對任何（或多種）資料型態的參照，包括其他陣列，或其他資料結構，例如[元組][tuples]、[集合][sets]或[字典][dicts]。
當中的內容可以使用`for item in <list>`結構來疊代。
如果內容還需要索引，可以使用`for index, item in enumerate(<list>)`。
`list`裡面的元素可以從左邊以`0-based index`編號存取，也可以從右邊以`-1-based index`編號存取。
陣列可以使用*切片語法*或`<list>.copy()`來整份複製，或只複製其中一部分。
Python 提供許多實用又方便的[方法][list-methods]來操作陣列。
