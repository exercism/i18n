# 簡介

在 Go 中，[`Time`][time]是一種用來描述某個時間點的型別。日期和時間資訊可以透過它的方法來存取、比較和操作，不過也有一些函式是直接在`time`套件上呼叫的。目前的日期和時間則可以透過[`time.Now`][now]函式取得。

[`time.Parse`][parse]函式會把字串解析成`Time`型別的值。Go 有一套特別的方式，讓你定義解析時預期的格式。你需要用這個特殊時間戳記裡的值，寫出一個格式範例：`Mon Jan 2 15:04:05 -0700 MST 2006`。

例如：

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

[`Time.Format()`][format]方法會回傳時間的字串表示。就和`Parse`函式一樣，目標格式同樣是透過範例來定義，而這個範例使用的是特殊時間戳記裡的值。

例如：

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## 格式選項

如果想自訂格式，可以組合使用這些選項。在 Go 中，也有預先定義好的日期和時間戳記[格式常數][const]可以使用。

| 時間        | 選項                                        |
| ----------- | ---------------------------------------------- |
| 年        | 2006 ; 06                                      |
| 月        | Jan ; January ; 01 ; 1                         |
| 日        | 02 ; 2 ; \_2（表示前置的 0）                 |
| 星期     | Mon ; Monday                                   |
| 小時        | 15（24 小時制）；3；03（AM 或 PM） |
| 分鐘        | 04 ; 4                                         |
| 秒        | 05 ; 5                                         |
| AM/PM 標記  | PM                                             |
| 一年中的第幾天 | 002 ; \_\_2                                    |

`time.Time`型別有許多方法可以存取特定的時間，例如小時：[`Time.Hour()`][hour]、月份：[`Time.Month()`][month]。關於實際運作方式的更多說明，可以參考[官方文件][time]。

[`time`][time]套件還包含另一種型別[`Duration`][duration]，用來表示經過的時間，另外也支援時區、計時器，以及其他相關功能，這些會在另一個概念中介紹。
