# 安裝

Crystal 可在 Linux、macOS 和 Windows 上使用。

要注意的是，Crystal 在 Windows 上的支援仍屬於實驗性質。
這表示某些邊緣情況可能無法運作，也可能不適合用於正式環境。
不過，對 Exercism 和基本用途來說，原生 Windows 大致上都能正常使用。

如果你希望在 Windows 上開發時避開預覽版的體驗，建議使用 [WSL（Windows 子系統 Linux 版）][wsl]。
這是 Windows 10（1903 以上）與 11 的**免費**功能，讓開發者不需要虛擬機器就能執行 Linux 環境。

請參考其中一份[安裝指南][installation guides]，了解如何安裝 Crystal。

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
