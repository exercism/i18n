# 分析器標籤

分析器標籤用來辨識一個解答是_如何_解出來的。

這些標籤接著可以用來：

- 將解答連結到解題方式
- 將解答連結到概念
- 搜尋帶有特定標籤的解答

## 格式

標籤是一個格式如下的字串：`<category>:<thing>`。

我們支援四種不同的分類，由最高層級排到最低層級：

| 分類        | 說明                                            | 具體程度                                 | 範例                                  |
| ----------- | ----------------------------------------------- | ---------------------------------------- | ------------------------------------- |
| `paradigm`  | [程式設計典範][programming-paradigms]           | 非常高的層級，不特定於 track             | `imperative`, `functional`            |
| `technique` | 所使用的技巧                                    | 高層級，多數不會特定於 track             | `recursion`, `immutability`           |
| `construct` | 語言構造                                        | 許多不會特定於 track                     | `bitwise-and`, `for-loop`             |
| `uses`      | 語言特定的用法，例如型別或方法                  | 低層級，特定於 track                     | `DateTime.add_seconds`, `IEnumerable` |

一些範例標籤：

- `paradigm:functional`
- `technique:recursion`
- `construct:bitwise-and`
- `uses:DateTime.add_seconds`

## 常用標籤

雖然每個 track 都可以自由地為解答標上他們認為合適的標籤，我們仍建議盡量使用下面這份常用標籤清單。
使用一組共通的標籤，能讓我們做出一些很酷的功能，例如跨 track 連結解答。
