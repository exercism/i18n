# 指令

Sarah 正在開發一款新的角色扮演遊戲，需要你幫忙處理玩家機制。

## 1. 定義 `player` 元組

定義一個具有四個欄位和預設值的元組類別 `player`：

| 欄位     | 預設值  |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

定義完成後，就可以用字面值建立一個玩家：

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. 介紹玩家

定義 `introduce`，讓它回傳玩家的名字。隱匿的玩家會隱藏自己的名字（`name` 為 `f`），此時應介紹為 `"Mighty Magician"`。

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. 復活倒下的玩家

定義 `revive`，當玩家的 `health` 為 `0` 時，回傳一個 `health` 設為 100、`mana` 設為 100 的*全新*玩家。如果玩家仍然活著，則回傳 `f`。

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. 受到傷害

定義 `take-damage`，讓它回傳一個 `health` 依指定數值減少、且永遠不會低於 `0` 的*全新*玩家。

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
