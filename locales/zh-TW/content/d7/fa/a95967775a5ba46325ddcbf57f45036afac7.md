# 簡介

Cairo 的型別轉換讓你能把資料從一種型別轉換成另一種，實現靈活又安全的資料操作。

## 基礎

Cairo 提供了幾種型別轉換的機制：

### 直接轉型

對於相容的數值型別，你可以使用直接轉型：

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### `Into`特質

`Into`特質能讓你把一種型別轉換成另一種：

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### `TryInto`特質

對於可能失敗的轉換，請使用`TryInto`，它會回傳一個`Option`：

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## 自訂型別轉換

你可以為自己的型別實作`Into`：

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## 安全性考量

- 當轉換可能失敗時（例如由大到小的型別），使用`TryInto`
- 當轉換一定會成功時，使用`Into`
- 一律要處理`TryInto`回傳的`Option::None`情況
- 在有號與無號型別之間轉換時，要考慮溢位與下溢
