# 簡介

## 匯出函式

匯出函式在第一個概念已經介紹過了，這裡就快速複習一下吧。

每個 Elm 檔案都是一個模組，而且必須在所有其他程式碼之前包含 `module`敘述。

模組名稱必須與其檔案名稱相符，所以`Calculator`模組必須放在 Calculator.elm 檔案中，而`Parser.Utils`模組則需要放在 Parser/Utils.elm 檔案中。

在模組內定義的任何內容，其作用域都僅限於該模組，除非列在 `exposing`中，否則無法從這個模組外部存取。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 從其他模組匯入函式

要存取定義在其他模組中的函式，得透過匯入來完成。
匯入某個模組時，該模組所公開的所有函式都會變成可存取。
但它們的存取方式，取決於該模組是怎麼匯入的。

限定匯入是預設做法，要存取這類模組中的函式（例如 `List`模組裡的 `map`函式）時，就在前面加上模組名稱（`List.map`）。

開放匯入可以不必加前綴，直接存取該模組中公開的函式。它是用 `exposing`關鍵字完成的，就像匯出時所用的那個關鍵字一樣。你可以公開所有可用的函式（用 `..`），也可以只公開特定的幾個（例如 `map`）。

你也可以從其他模組匯入型別及其建構子，這是之後才會介紹的概念。

限定匯入比較受青睞，有助於清晰並避免名稱衝突。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 型別標註

型別標註的定義方式是 `name : parameter types -> return type`，其中參數型別之間也用 `->`分隔。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

括號可以用來定義函式參數（參數本身也是用同樣的語法定義的，所以才需要括號）。

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 數字

Elm 提供兩種數字型別，分別由 `Int`和 `Float`型別定義。
`Int`對應正整數與負整數的集合。
`Float`對應實數的集合，但會受到電腦精確度的限制。
定義在數字上的運算通常只適用於其中一種型別，不能混用兩者。
有一些函式可以在兩者之間轉換，例如 `toFloat`能把 `Int`轉成 `Float`，而 `round`、`floor`、`ceiling`或 `truncate`則會用不同的語意把 `Float`轉成 `Int`。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 字串操作

若要在程式碼中描述詞語和句子，Elm 有原生的 `String`型別。
字串字面值寫在雙引號之間，例如 `"Hello World!"`。
預設就提供了字串串接運算子 `++`和相等運算子 `==`。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

其他大多數的字串函式都位於 `String`模組中，使用前需要先匯入。

https://package.elm-lang.org/packages/elm/core/latest/String
