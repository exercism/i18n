# 簡介

像 `LocalDate` 和 `LocalDateTime` 這樣的類別，描述的是時間中的一個_點_。
`java.time` 套件另外還有兩個類別，用來描述一段時間的_長度_：

- `java.time.Period` 是一段以年、月、日表示的時間長度，例如「2 個月又 5 天」。
- `java.time.Duration` 是一段以時、分、秒、毫秒和奈秒表示的時間長度，例如「1 小時 30 分鐘」。

`Period` 依循日曆，所以搭配日期和日期時間使用。
`Duration` 衡量的是確切的時間，所以搭配時間和日期時間使用，但不搭配日期。

```exercism/note
和其他 `java.time` 類別一樣，`Period` 和 `Duration` 都是不可變的。
看起來會改變它們的方法，其實是回傳一個_新的_實例。
```

## `Period`

`Period` 用它的其中一個靜態工廠方法建立：

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()` 的結果使用 [ISO-8601][iso-8601-durations] 標記法：`P`（代表「period」）後面接著年數（`Y`）、月數（`M`）和日數（`D`）。

一段 `Period` 可以加到某個日期上，或從某個日期減去：

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

因為每個月的天數不同，加上幾個月後可能落在不存在的日期上。
這種情況下，結果會退回到該月最後一個有效日期：

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` 會回傳從第一個日期（包含）到第二個日期（不包含）之間的 `Period`：

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## 用 `ChronoUnit` 計算單位

`Period` 會把年、月和日分開保存。
所以 `getDays()` 只回傳這段期間中日的_部分_，而不是總天數。
若要計算兩個日期之間某個單位的總數，請使用 [`java.time.temporal.ChronoUnit`][chronounit-docs] 的 `between()` 方法：

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

當第二個日期早於第一個日期時，結果會是負數：

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration` 一樣用靜態工廠方法建立：

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

在 ISO-8601 標記法中，`T` 用來分隔日期部分和時間部分，這就是為什麼 `Duration` 會寫成 `PT...`。

一段 `Duration` 可以加到某個日期時間上，或從某個日期時間減去：

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` 會回傳兩個日期時間之間確切的時間長度：

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

`Duration` 可以用 `toHours()`、`toMinutes()` 和 `toSeconds()` 等方法換算成單一單位。
這些方法回傳的是該單位的_總_量，採無條件捨去：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

若要把 `Duration` 拆成各部分，像時鐘上的顯示那樣，請改用 `toXxxPart()` 系列方法：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
