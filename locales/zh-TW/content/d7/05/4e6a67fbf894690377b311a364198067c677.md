# 簡介

用其他語言的術語來說，JSON **物件**就是「hash」、「map」或「字典」。

JSON 對*物件*的定義如下：

> 物件是一組無序的**名稱**／**值**配對。
> 物件以`{`左大括號開頭，以`}`右大括號結尾。
> 每個*名稱*後面接著`:`冒號，而*名稱*／*值*配對之間則以`,`逗號分隔。

*名稱* **必須是字串**。
*名稱*的另一個說法是*鍵*。

*值*可以是任何 JSON 型別。
同一個物件裡不同的*值*可以是不同的型別，就像下面這個例子。

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

注意，*最後*一組鍵值配對後面**不能**有逗號。

## 建立物件

用大括號收集名稱／值配對。
雖然名稱必須是字串，但如果名稱**類似識別字**（由英數字元和底線組成，且不以數字開頭），就不需要用引號括起來。

```jq
{name: "Jane", age: 42}
```

使用不*類似識別字*的鍵是合法的。
只要用引號括起來就好。

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

如果名稱是某個運算式的結果，該運算式**必須**放在括號裡。

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## 索引取值

我們可以用**點記法**從物件取出值。

```jq
{name: "Jane", age: 42} | .age    # => 42
```

如果沒辦法用識別字表示鍵，就改用**方括號記法**。

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## 新增或修改鍵值配對

要在陣列裡新增一組鍵值配對，或更新現有鍵的值，請使用`=`賦值運算子，並在左側放一個索引運算式。

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+`運算子會*合併*物件。

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## 移除鍵

用`del`函式移除鍵。
它會回傳更新後的物件。

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

傳給`del`的參數是一個**索引運算式**（使用點記法或方括號記法），它會解析成物件裡的某個鍵。
`jq`稱之為**路徑運算式**。
只給一個字串是不夠的。

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## 成員檢查

- 要測試物件是否有某個鍵，可以使用`has`函式。

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- 用`in`測試某個鍵是否在物件裡。

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## 列出所有鍵

用`keys`函式輸出所有鍵的陣列。

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

注意，`keys`會*排序*這些鍵。
如果想按照原本的順序取得鍵，請使用`keys_unsorted`。

沒有對等的函式可以列出所有*值*。
不過`.[]`篩選器會把物件的值輸出成*串流*，而這個串流可以用`[...]`陣列建構子捕捉下來。

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## 疊代

- `map_values(filter)`函式會把篩選器套用到物件裡的每個*值*。

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- 要疊代一個物件，必須先把它轉成由鍵值物件組成的陣列。
  `to_entries`函式就是做這件事的。

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  這時候，我們就可以使用陣列疊代函式，例如`map`。

- `from_entries`函式則是反向操作：把由鍵值物件組成的陣列轉成物件。

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- 要對物件裡的*每一組*鍵值配對套用篩選器，請使用`with_entries(filter)`函式。

  舉例來說，假設有個把名稱對應到年齡的物件，可以像下面這樣把鍵和值對調。

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  輸出結果為

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)`等同於

  ```jq
  to_entries | map(filter) | from_entries
  ```
