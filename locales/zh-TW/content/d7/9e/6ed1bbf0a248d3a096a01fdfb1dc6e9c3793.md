# 指令

在這道練習中，你需要實作一些來自 [Pac-Man][Pac-Man] 這款 1980 年代經典街機遊戲的規則。

你有四條規則要實作，全都和遊戲狀態有關。

> _不用擔心引數是怎麼產生的，只要專注在組合這些引數、回傳預期的結果就好。_

## 1. 定義 Pac-Man 是否能吃掉幽靈

定義 `eat_ghost()` 函式，它接受兩個參數（_Pac-Man 是否有能量球生效中_ 和 _Pac-Man 是否碰到幽靈_），並在 Pac-Man 能吃掉幽靈時回傳布林值。
只有在 Pac-Man 有能量球生效中且碰到幽靈時，這個函式才應該回傳 `True`。

```python
>>> eat_ghost(False, True)
...
False
```

## 2. 定義 Pac-Man 是否得分

定義 `score()` 函式，它接受兩個參數（_Pac-Man 是否碰到能量球_ 和 _Pac-Man 是否碰到小點_），並在 Pac-Man 得分時回傳布林值。
只要 Pac-Man 碰到能量球或小點，這個函式就應該回傳 `True`。

```python
>>> score(True, True)
...
True
```

## 3. 定義 Pac-Man 是否落敗

定義 `lose()` 函式，它接受兩個參數（_Pac-Man 是否有能量球生效中_ 和 _Pac-Man 是否碰到幽靈_），並在 Pac-Man 落敗時回傳布林值。
如果 Pac-Man 碰到幽靈且沒有能量球生效中，這個函式就應該回傳 `True`。

```python
>>> lose(False, True)
...
True
```

## 4. 定義 Pac-Man 是否獲勝

定義 `win()` 函式，它接受三個參數（_Pac-Man 是否已經吃掉所有小點_、_Pac-Man 是否有能量球生效中_，以及 _Pac-Man 是否碰到幽靈_），並在 Pac-Man 獲勝時回傳布林值。
如果 Pac-Man 已經吃掉所有小點，而且根據第 3 部分定義的規則判斷並未落敗，這個函式就應該回傳 `True`。

```python
>>> win(False, True, False)
...
False
```
