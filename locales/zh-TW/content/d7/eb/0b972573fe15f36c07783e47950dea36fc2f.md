# 關於

Elixir 以布林型態表示 true 和 false 這兩種值。這種型態只有兩個值：`true`和`false`。這些值可以用布林運算子（[`and/2`][strict-and]、[`or/2`][strict-or]、[`not/1`][strict-not]）組合起來：

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

[`and/2`][strict-and]、[`or/2`][strict-or]和[`not/1`][strict-not]這幾個運算子都是嚴格的布林運算子，也就是說，它們要求_第一個_引數必須是布林值。另外也有功能相同的布林運算子，可以接受任何型態的引數：[`&&/2`][and]、[`||/2`][or]和[`!/1`][not]。

布林運算子採用_短路求值_，意思是運算子右邊的運算式只有在需要時才會被求值。

每個運算子的優先順序都不一樣，其中`not/1`會比`and/2`和`or/2`先被求值。括號可以用來讓運算式中的某個部分比其他部分先求值：

```elixir
not true and false
# => false

not (true and false)
# => true
```

撰寫會回傳布林值的函式時，[按照慣例，函式名稱會以][naming]`?`結尾。同樣的慣例也適用於儲存布林值的變數。

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
