# 安裝 Python

如果你的系統上還沒有 Python，官方文件的 [Python Setup and Usage][using python] 一節裡有各平台的詳細安裝說明。
Real Python 也有一份[不錯的指南][helpful guide]，介紹各種平台的安裝方式，包括 iOS 和 Android。

最後，Brett Cannon 的這兩篇文章 [A quick-and-dirty guide][quick-and-dirty] 與 [Why you should use `python -m pip`][python-m-pip]，對於如何管理 Python 的安裝與套件提供了很實用的建議。

**MacOS 使用者請注意：**在 MacOS Monterey（12.3）之前，作業系統會預先安裝 `Python 2.7`。
Exercism 或大多數其他程式都不支援使用 `Python 2.7`。
你應該改用以下詳述的其中一種方法來安裝 [Python 3][Python-three downloads]。
從 MacOS Monterey（12.3）起，MacOS 不再預先安裝任何版本的 Python。

以下是一些依作業系統分類的文件快速連結：

-  [Windows][windows] 此外，這篇 Microsoft 關於 [installing Python on windows][python-on-windows] 的文章也很實用。
-  [Unix & Linux Systems][unix-and-linux]（_這些方法大多也適用於 MacOS_）
-  [MacOS][macos]

   我們也建議看看 Real Python 文章 [Installing Python][installing-python] 中概述的一些方法，或是上面連結的 Brett Cannon 文章。


Exercism 的測試與工具目前支援 `3.10` - `3.13.5`（_測試_）以及 [`Python 3.13.5`][313-new-features]（_工具_）。
這項支援的例外情況會在出現時註明。
大多數練習在 `Python 3.6+` 甚至更早的版本上也能運作。
但對於未列在 [Active Python Releases][active-python-releases] 中的版本，我們不保證支援。


關於目前支援的內容，請參閱 [Python 3.13.x documentation][3.13 docs]。
