# 提示

## 一般

- 負責讀取的字詞放在 [`io`][io]；字串串流的建構子和`with-string-writer`放在 [`io.streams.string`][io.streams.string]。
- 在沖刷 writer 的任務中，當你需要兩次碰觸同一個串流時，區域變數（`::`和`:>`）可以讓主體保持好讀。

## 1. 聽完所有內容

- 一個字詞：`stream-contents`。

## 2. 計算訊息數量

- `stream-lines`會把串流切成由多行組成的陣列；`length`會回傳數量。

## 3. 回顯最後一次呼叫

- 和上面一樣用`stream-lines`，接著用`last`，再用`>upper`（來自`ascii`）。

## 4. 廣播訊息

- `stream-write`會寫入訊息，`stream-flush`會把它送出去。writer 會被用到兩次，所以請動用`::`區域變數：`:: broadcast ( message writer -- ) message writer stream-write writer stream-flush ;`。

## 5. 擷取 quotation 的輸出

- 一個字詞：`with-string-writer`。在結尾的`;`後面加上`inline`，讓編譯器能看穿 quotation 引數：`: capture ( quot -- captured ) with-string-writer ; inline`。
