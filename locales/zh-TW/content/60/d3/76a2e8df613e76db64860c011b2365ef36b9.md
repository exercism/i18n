# 指令

在這道練習中，你將撰寫程式碼，協助一位自由工作者與客戶溝通某些專案的價格。你會寫幾個工具函式，用來快速計算客戶所需的費用。

## 1. 根據時薪計算日薪

一位客戶聯繫這位自由工作者，詢問他們的費率。
這位自由工作者說明他們**_每天工作 8 小時。_**
不過，這位自由工作者只知道他們在這個專案上的時薪。
請幫他們根據時薪估算日薪。

請實作函式 `dailyRateFrom(hourlyRate:)`，它接受引數 `hourlyRate`，其中存放自由工作者的時薪。  
這個函式應根據時薪回傳日薪。

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

回傳的日薪應該是 `Double`。

## 2. 根據時薪與折扣計算月薪

有時，客戶會有興趣以較長的期間聘用這位自由工作者。
這位自由工作者願意給客戶折扣，但只有在客戶聘用他們至少一個月時才願意。
一個月總共有 **_22 個工作日_**。
請幫這位自由工作者根據時薪，以及他們願意在固定費率上提供的折扣百分比，計算出月薪，並四捨五入至最接近的整數。

請實作函式 `monthlyRateFrom(hourlyRate:withDiscount:)`，它接受引數 `hourlyRate`（存放自由工作者的時薪）與 `withDiscount`（存放自由工作者願意給客戶的折扣）。
這個函式應回傳四捨五入至最接近整數的月薪。

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. 根據預算、時薪與折扣計算工作日數

有一天，一位專案經理向這位自由工作者提議，以固定預算進行一個專案。
請根據固定預算與這位自由工作者的時薪，幫他們計算在預算用完之前可以工作幾天。
請注意，在這個情境中，無論聘用幾天，這位自由工作者都願意提供折扣。
結果_必須_**無條件捨去**至最接近的整數。

請實作函式 `workdaysIn(budget:hourlyRate:withDiscount:)`，它接受以下引數：
- `budget`，存放專案的預算。
- `hourlyRate`，存放自由工作者的時薪。
- `withDiscount`，存放自由工作者願意給客戶的折扣。

這個函式應回傳這位自由工作者在此專案上的工作日數，並無條件捨去。

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
