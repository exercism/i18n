# 測試

如果你的 PATH 裡有 phix 執行檔，請輸入下列指令：

```bash
p test 
```
這會執行測試檔（test.exw）。

如果 PATH 中沒有 phix 執行檔，在 Windows 中請輸入

```cmd
\path\to\p.exe test
```

Linux：

```bash
/path/to/p test
```

## 略過的測試

完成一項練習，就代表要讓它的所有測試都通過。
預設情況下，test.exw 檔案中的所有測試都會被執行。
如要略過某個測試，請在該行開頭加上兩個破折號（Phix 標準的註解標記）。

請注意，測試不會理會 tests.toml 中的任何 include=false 標記；這些標記必須由 test.exw 的作者在該檔案中手動維護，以反映實際情況，讓 Exercism 網站能從中受益（例如收集軌道的統計資料）。不過軌道本身完全不會用到這些標記，尤其是測試產生器和測試執行器都不會。
