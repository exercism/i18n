# 簡介

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) 提供了一種裝飾宣告的方式，可以把中繼資料關聯到類別、方法、列舉、欄位、屬性，或任何[其他支援的](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets)宣告。

你可以在宣告的前一行加上 attribute，使用`ClassAttribute`和`FieldAttribute`：

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

這種宣告式的中繼資料只是把額外的結構化資訊關聯到程式碼上，並不會改變程式碼的行為；不過程式碼的其他部分會利用這些中繼資料，來改變目標的行為，或是新增、修改、移除、限制目標的某些功能。

Attribute 有很多種[預先定義與保留的](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)，例如：`Flags`、`Obsolete`、`Conditional`，各自都有特定的用途，可以在 C# 文件中查到。請注意，像 [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) 這樣的 attribute，依慣例全名是`FlagsAttribute`，但套用在宣告上時可以省略 _Attribute_ 後綴。
