# 提示

## 一般

- `set-nth ( elt n seq -- )`、`change-nth ( i seq quot -- )`、`push ( elt seq -- )` 和 `pop ( seq -- elt )` 都會*修改*其序列引數，並且不會在堆疊上回傳任何與其相關的內容，這個改變本身就是效果。

## 1. 全新的馬賽克

- `<array>`（在[`arrays`][arrays]中）接受一個長度和一個填充值，並回傳一個新的陣列。

## 2. 放置磁磚

- `set-nth`負責指定，但它預期的是`( elt n seq -- )`，而輸入進來的順序是`( row position colour -- )`。來自`kernel`的`spin ( x y z -- z y x )`能在單一詞中重新排列堆疊上的三個值，讓它們符合`set-nth`的順序。

## 3. 鑿掉一塊磁磚

- 「將這個位置設為`f`」，與任務 2 的形式相同，但你必須先把`f`推入堆疊。

## 4. 重新為磁磚上色

- `change-nth`會在指定位置的元素上執行一個引述，並將結果存回。

## 5. 快照

- `clone`（位於[`kernel`][kernel]）會回傳一份獨立的副本。

## 6. 暫存

- `push`會將元素就地附加到向量中。

## 7. 回傳

- `pop`會移除並回傳向量中的最後一個元素。
