# 比較運算子

PHP 內建十個比較運算子：

| 名稱  | 範例    | 結果                                             |
| ----- | ---------- | -------------------------------------------------- |
| 等於 | `$a == $b` | 若`$a`在型別轉換後等於`$b`，則為 true。 |
| 全等 | `$a === $b` | 若`$a`等於`$b`，且型別相同，則為 true。 |
| 不等於 | `$a != $b` | 若`$a`在型別轉換後不等於`$b`，則為 true。 |
| 不等於 | `$a <> $b` | 若`$a`在型別轉換後不等於`$b`，則為 true。 |
| 不全等 | `$a !== $b` | 若`$a`不等於`$b`，或型別不同，則為 true。 |
| 小於 | `$a < $b` | 若`$a`嚴格小於`$b`，則為 true。 |
| 大於 | `$a > $b` | 若`$a`嚴格大於`$b`，則為 true。 |
| 小於或等於 | `$a <= $b` | 若`$a`小於或等於`$b`，則為 true。 |
| 大於或等於 | `$a >= $b` | 若`$a`大於或等於`$b`，則為 true。 |
| 太空船運算子 | `$a <=> $b` | 當`$a`時，回傳小於、等於或大於`0`的整數。 |

PHP 對`equal`和`identical`有不同的定義來區分兩者。
有時候`identical`也稱為`strictly equal`。

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
