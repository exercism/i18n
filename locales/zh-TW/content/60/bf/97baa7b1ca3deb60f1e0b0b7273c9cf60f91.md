# 說明

你是一個國際志工消防隊的成員。由於團隊成員來自世界各地，過去幾次出勤時，大家為了估算燃燒中建築物內的溫度，得在華氏與攝氏之間來回換算，浪費了許多寶貴的時間。為了節省時間，也為了救人，你決定寫一個程式，替你的國際團隊自動換算華氏與攝氏。

## 1. 將華氏轉換為攝氏

實作 `tempToC` 函式，將以華氏表示的 `Integer` 溫度轉換成對應的攝氏 `Float`，並四捨五入到小數點後第二位。
攝氏溫度的定義為：T(°C) = (T(°F) - 32) / 1.8。

```haskell
> tempToC 32
0.00
```

## 2. 將攝氏轉換為華氏

實作 `tempToF` 函式，將以攝氏表示的 `Float` 溫度轉換成對應的華氏溫度。
基於安全考量，請將結果**無條件進位**到**下一個最大**的 `Integer`。
華氏溫度的定義為：T(°F) = T(°C) × 1.8 + 32。

```Haskell
> tempToF 4
40
```
