# 簡介

## 比較

在 Go 中，可以使用下列的關係運算子和相等運算子來比較數字。

| 比較        | 運算子  |
| ------------------| --------- |
| 等於             | `==`      |
| 不等於         | `!=`      |
| 小於              | `<`       |
| 小於或等於     | `<=`      |
| 大於           | `>`       |
| 大於或等於  | `>=`      |

比較的結果永遠是布林值，所以只會是`true`或`false`。

```go
a := 3

a != 4 // true
a > 5  // false
```

上面的比較運算子也可以用來比較字串。
在這種情況下，會套用字典順序。
例如：

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## `if`敘述

Go 中的條件判斷和其他語言類似。
任何條件運算的底層型別都是`bool`型別，它的值可以是`true`或`false`。
條件判斷經常被用來做為流程控制機制，以檢查各種條件。

若要檢查特定的情況，可以使用`if`敘述；當底層條件為`true`時，它就會執行其中的程式碼，就像這樣：

```go
var value string

if value == "val" {
    return "was val"
}
```

當情況不只一種時，可以用`else if`和`else`敘述把多個`if`敘述串接在一起。

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`敘述也可以包含一段簡短的初始化敘述，用來為這個`if`敘述初始化一個或多個變數。
例如：

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> 注意：在初始化敘述中建立的任何變數，都會在`if`敘述結束之後超出作用域。
