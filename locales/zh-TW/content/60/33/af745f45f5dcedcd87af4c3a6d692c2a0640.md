# 指令

給定一段輸入文字，將它轉置後輸出。

簡單來說，一個矩陣的轉置：

```text
ABC
DEF
```

如下所示：

```text
AD
BE
CF
```

行會變成列，列會變成行。
參見 [轉置][transpose]。

如果輸入的各行長度不同，請依照以下方式處理：

- 在左側用空格補齊。
- 不要在右側補齊。

因此，將這個矩陣轉置：

```text
ABC
DE
```

會得到：

```text
AD
BE
C
```

而轉置：

```text
AB
DEF
```

會得到：

```text
AD
BE
 F
```

一般來說，輸入中的所有字元也都應該出現在轉置後的輸出中。
也就是說，如果輸入文字的某一列在最底部的幾行只包含空格，對應的輸出行就應該在最右側的幾列保留這些空格。

[transpose]: https://en.wikipedia.org/wiki/Transpose
