# 關於

列舉指的是逐一走訪一個集合（`Array`、`Hash` 等），並對其中的每個物件執行某些動作。

列舉是 Ruby 中很關鍵的概念，常用於排序（`sort_by`）、分組（`group_by`）、映射（`map`）、歸約（`reduce`）等各種操作。
你最常看到的情況是：用列舉逐一走訪集合，而不是使用迴圈，這才是 Ruby 的慣用寫法。

以下是一個簡單的列舉範例，會印出陣列中的每個單字：

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

在這個範例中，我們呼叫了`Array#each`方法，並傳入一個_區塊_，這個區塊接受一個參數（`word`）並將它印出。

我們也可以把列舉方法串接起來。
舉例來說，我們可以把`.with_index`串接到`each`之後，同時印出物件的索引和它的值：

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

列舉`Hash`物件和列舉`Array`物件完全相同，差別只在於區塊會接收兩個引數：鍵和值：

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

上面介紹的方法都屬於 [`Enumerable`模組][enumerable-module]，這個模組被納入`Array`、`Hash`，以及其他需要具備列舉能力的類別。

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
