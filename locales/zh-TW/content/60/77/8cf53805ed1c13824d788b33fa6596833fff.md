# 簡介

一旦值離開你的程式，無論是傳到網路上、寫入日誌檔，還是透過 socket，它都必須是*文字*。在封裝值以便傳輸時，有三個 Factor 慣用語會不斷出現：序列化器`unparse`、在不複製的情況下檢視序列的切片變體，以及讓你能用單一詞組從堆疊中投射出多個欄位的多輸入 cleave 組合子。

```factor
USING: combinators kernel prettyprint sequences strings ;

123 unparse .                          ! => "123"
"NS-1024" 2 head-slice >string .       ! => "NS"
1 2 [ + ] [ - ] 2bi . .
! => -1
! => 3
```

`unparse`是 Factor 解析器的反函式，`dup unparse parse`可以往返轉換。`head-slice`會回傳一個*檢視*（一個`slice`物件），而不是像`head`那樣配置一個全新的序列，當你只需要查看某個區域時，這很有用。`2bi`、`3bi`、`2tri`和`3tri`將 cleave 家族擴展到兩個或三個堆疊輸入。
