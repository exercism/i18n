# 提示

## 一般

- 這裡的每個迴圈都是由疊代器驅動的，所以都不需要計數變數，也不需要`until!`。
- 答案一律放在迴圈開始前就宣告好的變數裡，因為在迴圈裡面宣告的東西，會在迴圈結束時消失。

## 1. 總和

- `counts.elt!`每繞一圈就會取出一個計數值。
- 把總和從`0`開始，這樣即使這份調查沒有任何一天，算出來的答案也會是對的。

## 2. 最好的一天

- 用一個變數記住目前為止最好的一天，起始值設為`0`。
- 每繞一圈就比較一次，如果這天比它更好就取代它。`.max`能一步完成比較：`best := best.max(counts.elt!)`。

## 3. 忙碌的日子

- 這裡要的是計數，不是相加：`if counts.elt! > n then found := found + 1; end;`
- 在`if`條件裡只向疊代器要一次值就好。在同一個主體裡寫兩次`counts.elt!`，就會把陣列走訪兩遍。

## 4. 要檢查的賞鳥亭

- 這裡不需要走訪任何東西，所以`elt!`派不上用場。`1.upto!(days)`會幫你數。
- `1.upto!(0)`什麼都不會產生，而這正是零天時該有的答案。

## 5. 第一個忙碌的日子

- 答案是一個位置，不是值，所以要逐一走訪位置：`i ::= 0.upto!(counts.size - 1)`。
- 答案從`-1`開始。如果什麼都沒找到，那本來就是應該回傳的值。
- 一旦找到某一天，就用`break!`跳出來，否則後面某個忙碌的日子會把第一個蓋掉。
