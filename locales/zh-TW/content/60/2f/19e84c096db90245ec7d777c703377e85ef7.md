# 提示

## 一般

- 閱讀入門指南中關於[錯誤][errors]的說明。
- 在文件中閱讀關於 [`try`][docs-try] 的內容。

## 1. 警告團隊

- 讓運算函式拋出它的錯誤。
- 若要呼叫存在變數中的函式，請使用 `.` 運算子。

## 2. 包裝錯誤

- 使用 try .. rescue 來回傳預期的結果。

## 3. 傳遞訊息

- 使用 try .. rescue 來回傳預期的結果。
- rescue 區塊讓你可以對錯誤的模組名稱進行模式比對，也可以將錯誤綁定到變數。

[errors]: https://hexdocs.pm/elixir/try-catch-and-rescue.html#errors
[docs-try]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#try/1
