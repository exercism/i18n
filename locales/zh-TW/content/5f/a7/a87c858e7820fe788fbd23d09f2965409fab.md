# 測試

## 撰寫程式碼

把你的程式碼寫在`src/lib.cairo`裡。
每個練習都附有一份`src/lib.cairo`的 stub 檔案，它會顯示你需要撰寫的程式碼的簽章。

對大多數練習來說，最好把你所有的程式碼都寫在`src/lib.cairo`這個檔案裡。
如果你想把自己的解法拆分成幾個檔案，請參考 The Cairo Book 的[模組章節][chapter-modules]。

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## 執行測試

要執行測試，首先你需要把工作目錄切換到你想測試的那個練習所在的目錄：

```bash
cd path/to/exercise
```

然後執行以下指令：

```bash
scarb cairo-test
```

預設情況下，只有第一個測試是啟用的。
當你準備好要通過下一個測試時，請把下一個測試的 ignore 旗標移除（`#[ignore]`）。

要執行所有測試（包括被忽略的那些），你可以移除所有測試的`ignore`旗標，或者直接執行：

```bash
scarb cairo-test --include-ignored
```

儘管寫最少的程式碼讓測試通過就好。
測試失敗的訊息會指引你下一步該寫什麼喔。

由於 Cairo 會在編譯時期檢查所有程式碼，你可能會發現，在你寫好所需的程式碼之前，測試根本無法編譯。
即使是標上`ignore`的測試，也會在編譯時期被檢查。
你可以[註解掉][comments]無法編譯的測試，只要在每一行開頭加上`//`即可。
之後，當你準備好要處理那個測試時，再把註解取消掉就好。
Cairo 還有一個特殊的巨集`panic!()`，你可以把它用在尚未完成的程式碼路徑上，讓你的程式能夠編譯。

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
