# 關於

[三元運算子][ternary-operators] 讓 if 條件可以定義在運算式裡，而不是寫在敘述區塊中。這呼應了函式程式設計的做法，往往能讓程式碼更具表達力，也更不容易出錯。

三元運算子結合了 3 個運算式：一個條件，接著是條件為真時要求值並回傳的運算式（`if`的部分，由`?`開頭），以及條件為假時要求值並回傳的運算式（`else`的部分，由`:`開頭）。

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
