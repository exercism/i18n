# 安裝

## Linux

Bash 是 GNU 的 shell，在任何 GNU/Linux 系統上都能找到。
BSD 與其他 UNIX 衍生系統則通常需要使用者自行安裝。
如果你用的是 BSD、AIX，或是沒有內建 bash 的 Linux，請查閱你的作業系統的相關資源，了解如何安裝非核心套件。

在你想用的圖形介面中，尋找名為「Terminal」的應用程式：它可能位在「Administrative/System Tools」分類底下。

若要確認可用的 Bash 版本，請在命令列或終端機中執行：

    echo $BASH_VERSION

如果你的 shell 是 `bash`，應該會顯示類似以下的內容：

    4.4.19(1)-release

到這裡你應該不需要做其他事了，bash 應該已經安裝好，而且就在你的 PATH 裡，因為它就是你目前使用的 shell。

如果你的 shell 不是 bash，也沒有理由要換掉它。
即使不在 bash shell 裡，你一樣可以撰寫並執行 bash 腳本。

若要確認已安裝的 bash 版本，請執行：

```plain
bash --version
```

它會顯示類似以下的內容：

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

如果沒有顯示，可能就是沒安裝 bash。
你應該用你的發行版的套件管理員來安裝它。

## Windows

Windows 10 可以安裝 [WSL](https://docs.microsoft.com/en-us/windows/wsl/about)。
這會安裝一套完整的 Linux 發行版（嗯，是不含圖形介面的部分），以原生方式在 Windows 上執行。

或者，你也可以安裝：

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* 在[虛擬機器](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)裡安裝完整的 Linux 發行版

## MacOS

如果是 Apple OSX：

* 打開 Finder，
* 打開你的 Applications 資料夾，
* 打開 Utilities 資料夾，
* 最後打開 `Terminal` 應用程式。

請注意，MacOS 上安裝的 bash 版本非常舊，是 3.2 版。
這是因為 (i) 較新的 bash 版本採用 GPLv3 授權，以及 (ii) Apple 不想被迫遵守該授權的條款。
此外，Apple 已經預告 bash 將會從 MacOS 中消失：預設的登入 shell 最近[從 bash 改為 zsh](https://support.apple.com/en-us/HT208050)。

想在 Mac 上取得最新版的 bash：

1. 安裝 [Homebrew](https://brew.sh)
1. 在 Terminal 中輸入：`brew install bash`

這會安裝最新版的 bash，位置（我記得）是 `/usr/local/bin/bash`（如此一來就不會覆蓋系統預設的 bash，其他工具可能依賴 /bin/bash）。

如果你希望輸入 `bash` 時啟動的是 Homebrew 的 bash，請編輯你的 ~/.bash_profile（或 ~/.profile）檔，把 /usr/local/bin 放到 PATH 中比 /bin **更前面**：

    PATH=/usr/local/bin:$PATH
