# 補充說明

## 輸出格式

將動作序列輸出成以 null 結尾的字串，並以逗號和空格作為分隔符。

## 暫存器

| 暫存器   | 用途         | 型別    | 說明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 輸入         | 整數    | 1 到 31 之間的數字            |
| `$a1`    | 輸入/輸出    | 位址    | 以 null 結尾的輸出字串        |
| `$t0-9`  | 暫時性       | 任意    | 用於暫存                      |
</english-text>
