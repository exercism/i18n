# 一般

- 確保你充分了解如何建立和更新陣列。
- Python 的[`lists`說明文件][python lists]會很有幫助。
- Python 的[`lists`教學章節][more on lists]也是很好的資源。

## 1. 把我加入佇列

- `if-else`敘述可以幫你判斷目前處理的是哪一種票種。
- 接著就能根據票種，用`append()`把這個人加入佇列。

## 2. 我的朋友在哪裡

- 你需要從佇列中找出那位朋友名字的`index()`。

## 3. 我可以加入他們嗎？

- 既然你知道`index()`，就可以用`insert()`把朋友插入佇列的那個位置。

## 4. 佇列裡那個刻薄的人

- 你知道那個刻薄的人的姓名，所以可以用`remove()`把他從佇列中移除。

## 5. 同名的人

- 在這裡，用`count()`數一數`name`在佇列中出現的次數，可能是個好策略。

## 6. 移除最後一個人

- 雖然你可以用`remove()`依名字移除那個人，但用`pop()`把他彈出可能更快。

## 7. 排序佇列

- 別忘了，你需要避免改動佇列而失去它原本的順序。
- 一旦你取得`copy()`，要`sort()`應該就輕而易舉。
- 我們要的是_遞增_排序，也就是_依字母從 a 到 z 排序_。
