# 說明

在這道練習中，你將寫一些程式碼，幫助你依照最愛的食譜烤出完美的千層麵。

你有四項任務，全都和烤千層麵所花費的時間有關。

## 1. 定義烤箱的預期時間（分鐘）

定義`OvenTime`常數，表示千層麵應該在烤箱裡待幾分鐘。
根據食譜，烤箱的預期時間是 40 分鐘：

```go
OvenTime
// => 40
```

```go
func RemainingOvenTime(actual int) int {
    // TODO
}

RemainingOvenTime(30)
// => 10
```
