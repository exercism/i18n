# 簡介

## 映射

映射是指把函式套用到序列的每個元素上，產生一個新的序列。

用 `mapcar` 這個函式就能輕鬆地對陣列做到這件事。
假設我們有一個 `double` 函式，它會把引數乘以 `2`：

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

注意第一個引數是要呼叫的函式。`#'` 是一種特殊的引號語法，用來指定函式。

`double` 會先以第一個元素呼叫，然後是第二個，依此類推。
這些結果會收集成一個陣列，也就是這個運算式求值後的值。

## 過濾

過濾是指從一個序列產生另一個序列的過程，作法是複製原始序列中除了某些元素之外的所有元素。
至於新序列要包含哪些項目，可以透過述詞函式（一種求值結果為布林值的函式）來決定，也可以依據與特定物件是否相等來決定。

### 用述詞移除元素

`remove-if` 這個函式接受一個述詞函式和一個序列做為引數，並回傳一個只包含述詞求值為 false 之元素的序列。
換句話說，它會「移除」序列中所有讓述詞求值為 true 的元素。不過要注意，這個函式不會修改原始序列！
而是回傳一個不包含這些元素的新序列。如果述詞對所有值都求值為 true，就會回傳一個空序列。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### 移除特定項目

如果想從序列中移除某個特定項目，可以使用 `remove`，它接受要移除的項目和一個序列。
序列中所有不等於要移除項目的值都會被回傳。
注意：預設會用 `eql` 這個[通用相等性述詞][concept-equality]來檢查相等性。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
