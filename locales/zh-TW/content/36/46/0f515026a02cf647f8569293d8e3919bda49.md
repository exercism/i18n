# 關於

ABAP 有幾種數值型態。在小型入門練習裡最常見的，是代表整數值的 `i`，以及代表壓縮十進位值的 `p`。

當值必須是整數時（例如天數），請使用 `i`。當值可能包含小數位時（例如時薪），請使用十進位型態。

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

當需要固定的小數位數時，商業應用程式經常使用壓縮十進位數。ABAP 也有十進位浮點數（`decfloat16` 和 `decfloat34`）以及二進位浮點數（`f`）。二進位浮點數對科學計算很有用，但因為許多十進位小數無法精確表示，所以不適合當作金錢類範例的預設選擇。
