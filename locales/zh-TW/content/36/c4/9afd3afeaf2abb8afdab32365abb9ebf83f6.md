# 疊代器

疊代器是一種名稱以`!`結尾的常式，而且只能在`loop`裡面呼叫。迴圈每繞一圈，它就產生下一個值；等到它產生不出來時，迴圈就立刻結束。

```sather
   loop
      total := total + counts.elt!;
   end;
```

Sather 沒有`for`敘述。這就是取代它的做法，也是這個語言為人所知的功能。

## 值得先認識的幾個

| 疊代器 | 產生的值 |
| --- | --- |
| `a.elt!` | 依序產生`a`的每個元素 |
| `a.ind!` | `a`的每個位置：0、1、2…… |
| `n.upto!(m)` | `n`、`n+1`……`m` |
| `n.downto!(m)` | `n`、`n-1`……`m` |
| `n.times!` | 執行`n`次，不產生任何值 |
| `n.up!` | `n`、`n+1`……而且永不結束 |
| `s.elt!` | 字串的每個字元 |

`until!`、`while!`和`break!`也是疊代器。這就是為什麼它們以`!`結尾，也是為什麼它們只能在迴圈裡運作。

## 呼叫要寫在哪裡

疊代器的呼叫可以出現在任何運算式能出現的地方，包括條件的中間：

```sather
   loop
      if counts.elt! > 10 then busy := busy + 1; end;
   end;
```

程式中每個寫下疊代器的*位置*都保有自己的進度。在同一個迴圈主體裡寫兩次`counts.elt!`，會對陣列做兩趟各自獨立的走訪，而這幾乎永遠不是你想要的：

```sather
   loop
      #OUT + counts.elt! + " and " + counts.elt!;   -- two separate walks
   end;
```

改成只問一次，把值放進變數裡。

## 結束迴圈

只要迴圈裡*任何一個*疊代器用完，迴圈就立刻結束，而不是等全部用完才結束。只有一個疊代器時，這很明顯。有好幾個的時候，這條規則會難倒所有人，而這就是下一個練習要談的主題。

## 該用哪一個

需要值的時候用`elt!`，需要位置的時候用`ind!`。只有在兩者同時都需要，或者要的答案是位置而不是值時，才退而改用`upto!`，而不要自己寫`0 .. a.size - 1`。
