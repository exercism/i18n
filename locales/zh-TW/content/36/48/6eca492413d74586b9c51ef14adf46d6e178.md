# 關於

`Maybe` 型別是 Elm 語言用來表示可有可無的值的方式。
因此，許多核心 Elm 函式的型別簽章中都會出現它，理解它至關重要。

## 定義與型別變數

`Maybe` 型別的定義如下：

```elm
type Maybe a = Nothing | Just a
```

這在 Elm 的術語中稱為「自訂型別」定義。
這個學習路徑的另一個概念會詳細介紹自訂型別，不過要理解`Maybe`並不需要它。
`Maybe a`和`Just a`當中的`a`代表型別變數，表示它可以是任何型別，例如`Int`、`Bool`或`String`。
因此，`Maybe String`是可以選擇性存放`String`的變數，而`Maybe Int`則可以選擇性存放`Int`。

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

`Maybe`型別定義中的垂直線`|`代表「OR」。
它表示這個型別的值可能是`Nothing`，也可能是型別為`a`的`Just`值。
假設這個人沒有填寫名字和年齡，就會變成下面這樣。

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## 讀取 Maybe 值的內容

讀取`Maybe`值內容的方式是透過「模式比對」。
模式比對同樣會在另一個概念中詳細介紹，這裡我們只專注於如何對`Maybe`進行模式比對。

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

每次使用`Maybe`值時，Elm 編譯器都會檢查你的程式碼是否處理了所有可能的情況，所以你無法在對`Maybe`做模式比對時只處理有`Just someValue`的情況。
這在一開始可能有點煩人，但這正是 Elm 語言最強大的優點之一。
這能避免數以百計的 bug，也讓由編譯器引導的重構成為一件無所畏懼、充滿成就感的事。

## 更多操作 Maybe 的函式

`Maybe`模組中還有許多實用的函式可以用來操作`Maybe`型別。

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
