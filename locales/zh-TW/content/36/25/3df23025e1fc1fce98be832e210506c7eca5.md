# 指令

在這個練習中，你會和最好的朋友一起玩一款名為「Wizard and Warriors」的角色扮演遊戲。
你是遊戲主持人，負責讓遊戲世界在玩家眼前鮮活起來。
其中一個關鍵在於向玩家描述遊戲：角色的狀態是什麼、他們造訪的城鎮長什麼樣子等等。

你有五項任務，要分別向玩家描述遊戲的各個部分。

## 1. 描述角色

每個角色都有類別、等級和生命值，描述方式如下：`"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`。
請實作`GameMaster.describe`方法，它只接受一個`Character`參數，並回傳該角色的描述。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 描述目的地

每個目的地都有名稱和居民人數，描述方式如下：`"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`。
請實作`GameMaster.describe`方法，它只接受一個`Destination`參數，並回傳該目的地的描述。

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 描述旅行方式

角色可以用下列兩種方式的其中一種前往目的地：

- 步行，描述為：`"You're traveling to your destination by walking."`
- 騎馬，描述為：`"You're traveling to your destination on horseback."`

請實作`GameMaster.describe`方法，它只接受一個`TravelMethod`參數，並回傳該旅行方式的描述。

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. 描述角色前往目的地的情況

當角色前往某個目的地時，描述方式是個別描述的組合：`"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`。
請實作`GameMaster.describe`方法，它接受一個`Character`、一個`Destination`和一個`TravelMethod`參數，並回傳該描述。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 描述角色前往目的地而未指定旅行方式的情況

大多數情況下，角色都是以步行前往目的地。
為了方便，玩家可以省略旅行方式；在這種情況下，會假設旅行方式為步行。
請實作`GameMaster.describe`方法，它接受一個`Character`和一個`Destination`參數，並回傳該描述。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
