# 說明

你對 Blorkemon™️ 卡片的懷舊之情絲毫沒有減退，甚至又開始收集它們，還拉著朋友一起加入。

在這個練習中，卡片收藏是用 `MapSet` 來表示的，因為當你的目標是蒐集所有現有的卡片時，重複的卡片並不重要。

## 1. 開始收藏

你真的很希望朋友們一起陷入 Blorkemon™️ 的狂熱，而最好的方式就是送他們一張卡片，幫他們的收藏起步。

實作 `GottaSnatchEmAll.new_collection`，它會把一張卡片轉換成一個收藏。

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. 擴充收藏

一旦有了收藏，它就會有自己的生命，必須不斷成長。

實作 `GottaSnatchEmAll.add_card`，它接受一張卡片和一個收藏，並回傳一個含有兩個值的元組：一個布林值，表示這張卡片是否已經在收藏中，以及加入這張卡片後的收藏。

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. 開始交換

既然朋友們又為 Blorkemon™️ 瘋狂了，你就可以藉由交換卡片來壯大自己的收藏。

不是每次交換都值得做，甚至不一定做得成。
你不能交換自己沒有的卡片，也不該拿卡片去換自己已經有的。

實作 `GottaSnatchEmAll.trade_card`，它接受兩張要交換的卡片（你的和對方的）以及你目前的收藏。
回傳值是一個含有兩個值的元組：一個布林值，表示這次交換是否可行又值得做，以及完成交換後你會得到的收藏（即使實際上根本不可能交換）。

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. 每種卡片只能有一張

你在跳蚤市場找到一批舊卡片。
你必須把卡片排序並移除重複的，才能把清單和你的收藏做比較。

實作 `GottaSnatchEmAll.remove_duplicates`，它會把卡片清單排序，並回傳一份排序過、不重複的卡片清單。

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. 對方沒有的卡片

該是為自己的收藏感到得意的時候了。

實作 `GottaSnatchEmAll.extra_cards`，它接受你的收藏和另一個收藏，並回傳對方收藏中沒有的卡片數量。

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. 大家都有的卡片

你和熱愛 Blorkemon™️ 的朋友們聚在一起，想知道哪些卡片最常見。

實作 `GottaSnatchEmAll.boring_cards`，它接受一個收藏清單，並回傳一份排序過、所有收藏都有的卡片清單。

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. 所有的卡片

你和朋友們合起來是否擁有所有的 Blorkemon™️ 卡片呢？

實作 `GottaSnatchEmAll.total_cards`，它接受一個收藏清單，並回傳所有收藏中不同卡片的總數。

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. 閃卡最棒

你的侄子快要來拜訪你了，你想讓他印象深刻。
小孩子都喜歡閃亮亮的東西，對吧？
Blorkemon™️ 卡片也會有閃亮版本喔！

實作 `GottaSnatchEmAll.split_shiny_cards`，它接受一個收藏，並回傳一個含有兩份排序卡片清單的元組：一份是所有以 `"Shiny"` 開頭的卡片，另一份是其他卡片。

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
