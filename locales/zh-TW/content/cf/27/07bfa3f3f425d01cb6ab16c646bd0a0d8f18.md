**我們正在尋找新的軌道維護者。有興趣嗎？請繼續讀下去！**

Exercism 是由許多志工的熱情所驅動，尤其是負責建立與管理各語言軌道的[軌道維護者](https://exercism.io/team/maintainers)。

我們即將全力推動 Exercism 版本 3（v3）。要讓所有軌道都準備好迎接 v3，會需要整個社群一起投入，而我們希望能增加更多維護者來監督並管理這項任務。

在推動 v3 的過程中，維護者將負責：

- **設計軌道：** 釐清一個人要學會什麼才能流利使用一門語言，並把它規劃成一條學習路徑。
- **做決策：** 針對軌道使用的工具、遵循的標準、採用的預設值等，做出設計上的決定。
- **鼓勵並支持貢獻：** 為想幫忙的人營造友善的環境、回答他們的問題等。
- **審查 PR：** 建置 v3 軌道的實際工作，大多會由社群完成。維護者扮演守門人的角色，審查社群完成的工作，確保軌道的標準被落實。

這一切聽起來可能有點嚇人，但當工作分散到整個維護者團隊時，每個人都可以負責自己最有把握的部分。我們經驗較豐富的維護者也會幫助你起步，在你慢慢上手的過程中手把手帶你。

要能勝任這個角色，你需要：

- 平均每週能投入 3 小時（最好分散在一週之中），持續大約 6 個月。我們知道生活本來就有起有落，所以完全理解有些星期你可能比較有餘力貢獻。
- 用過 Exercism。
- 最好曾為 Exercism 貢獻過，無論是擔任導師，或為程式碼庫做出貢獻。這雖然不是絕對的必要條件，但我們發現，如果維護者對 Exercism 已經有一些經驗，會更享受這個過程。

維護者是志工，所以沒有酬勞。最理想的動力，會是你想幫助別人培養程式設計能力，也想幫助一個非營利組織。擔任 Exercism 維護者也是絕佳的機會，能和其他聰明的人共事、更深入了解你選用的語言，並累積有助於朝技術領導方向發展職涯的技能與經驗。寫在履歷上也相當加分喔。

如果你有興趣成為維護者，我們很期待收到你的消息。每個仍在運作的軌道在 GitHub 上都有一個 issue，你可以在那裡留言自我介紹。你可以在[這裡找到這些 issue 的清單](https://github.com/exercism/exercism/issues/5161)。
