# 字串方法

`String`有幾個可以用來操作字串的方法。
這些方法會直接在字串上呼叫，而且經常串接在一起，對同一個字串執行多項操作。

以下列出一些最常用的方法。
完整的方法清單請見 [`String` API 文件][string-api]。

## String#upcase & String#downcase

[`upcase`][upcase] 方法會回傳一個新字串，其中所有字元都轉成大寫。

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase] 方法會回傳一個新字串，其中所有字元都轉成小寫。

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

有幾個方法可以進行更特定的大小寫轉換。
在把字串轉成特定格式時，這會很有用。
以下列出一些最常用的方法：

| 方法                              | 說明                                                                                                               | 範例                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | 將第一個字母轉成大寫，其餘轉成小寫                                                                                 | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | 將底線轉成駝峰式命名                                                                                               | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | 與 String#camelcase 相同，但將第一個字元保持小寫                                                                   | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | 將所有字元轉成小寫，並在小寫字母與大寫字母之間插入底線                                                             | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | 將每個字的第一個字母大寫，其餘轉成小寫                                                                             | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal 有一些用來取代字串中部分內容的方法。
它們分別是 [`sub`][sub]（_substitution_）和 [`gsub`][gsub]（_global substitution_）。

這兩個方法的第一個引數可以接受字串、字元或正規表達式，第二個引數則接受字串或字元。
第一個引數是要被取代的那部分字串，第二個引數則是取代後的內容。
`Char` 和正規表達式會在後面的概念中介紹。

`sub` 方法會用第二個引數取代第一個引數首次出現的位置。

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub` 方法的運作方式和 `sub` 相同，但會用第二個引數取代第一個引數所有出現的位置。

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

可以用 chomp 和 strip 來移除字串中不需要的字元。

[`chomp`][chomp] 方法預設會移除字串結尾的 `\r`、`\n` 或 `\r\n` 字元。
如果呼叫這個方法時帶有引數，則會從字串結尾移除指定的值，
前提是該值確實位於字串結尾。

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

[`strip`][strip] 方法預設會移除字串開頭和結尾的所有空白。
如果呼叫這個方法時帶有引數，則會從字串開頭和結尾移除該引數，
前提是它確實出現在字串的開頭或結尾。

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

你可以用 [`reverse`][reverse] 方法反轉字串。
這個方法會回傳一個新字串，其中字元的順序相反。

```crystal
"hello".reverse
# => "olleh"
```

## String#index

[`index`][index] 方法可以用來找出某個字元在字串中的索引。
`index` 方法接受 `String`、`Char` 或正規表達式作為引數。
它還可以有第二個選擇性引數，用來指定從哪個索引開始搜尋。
`index` 方法會回傳引數首次出現的索引。

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

你可以用 [`delete_at`][delete_at] 方法從字串中移除某個字元。
`delete_at` 方法接受一個索引作為引數，並移除該索引位置上的字元。

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

[`insert`][insert] 方法可以用來在特定索引位置插入字串。
`insert` 方法的第一個引數是索引，第二個引數是字串。
`insert` 方法會回傳一個新字串，並把第二個引數插入到該索引位置。

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
