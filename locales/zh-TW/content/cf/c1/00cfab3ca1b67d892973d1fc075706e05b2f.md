# 簡介

## 多重子句函式

Elixir 允許函式擁有多個子句，藉此實踐**開放封閉原則**。所以與其寫出龐雜、寫死的控制邏輯，不如把函式寫得更聚焦，就能輕鬆地新增或移除行為。

Elixir 提供了_多重函式子句_與_警衛_，讓你寫出：

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

在執行時，Elixir 會從原始檔的頂端往下依序檢查，決定要呼叫哪一個函式子句。

未使用的變數應該以底線作為前綴。

## 警衛

警衛用來防止 Elixir 呼叫函式，判斷的依據是警衛函式對引數的求值結果。警衛以`when`關鍵字開頭，後面接著一個布林運算式。警衛函式是特殊的函式，它們：

- 必須是純粹的，且不得改變任何全域狀態。
- 必須回傳嚴格的`true`或`false`值。

常見的警衛清單可以在 [Elixir 文件][kernel-guards] 中找到。其中包括型別檢查、基本算術、比較，以及嚴格的布林運算子。

## 預設引數

函式可以為一個或多個引數宣告預設值。我們來看看這個函式吧：

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

編譯時，Elixir 會建立`number/0`（沒有引數）和`number/1`（一個引數）兩個函式定義。

如果多個引數都有預設值，這些預設值會由左至右套用到函式，補上缺少的引數。

如果函式有多個子句，預設引數應該定義在函式子句之前的函式標頭（沒有主體的函式）中：

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
