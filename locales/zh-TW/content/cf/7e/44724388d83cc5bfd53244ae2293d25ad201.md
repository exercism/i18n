# 簡介

函式讓你可以把程式碼整理成可重複使用的單位。
它由 `func` 關鍵字、函式名稱，以及放在括號中、以逗號分隔的零個或多個參數與型別組成。

## 函式參數

所有參數都必須明確標示型別；參數沒有型別推斷。
參數沒有預設值，因此所有函式參數都是必填的。

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

相同型別的參數可以一起宣告，後面只要接一次型別宣告。

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 參數與引數

我們快速來看兩個經常被混淆的名詞：`parameters` 與 `arguments`。
函式參數是定義在函式簽章中的名稱，例如上面 `PrintGreetingName` 函式裡的 `greeting` 和 `name`。
函式引數則是我們呼叫函式時，實際傳給函式參數的值。
例如在下面的範例中，`"Hello"` 和 `"Katrina"` 就是傳給 `greeting` 和 `name` 這兩個參數的引數：

```go
PrintGreetingName("Hello", "Katrina")
```

## 回傳值

函式參數之後接著零個或多個回傳值，回傳值同樣必須明確標示型別。
單一回傳值直接寫就好，多個回傳值則要用括號包起來。
函式使用 `return` 關鍵字把值回傳給呼叫它的程式碼。
一個函式裡可以有多個 `return` 敘述。
函式的執行會在遇到其中一個 `return` 敘述時立刻結束。
如果要從函式回傳多個值，這些值之間用逗號分隔。

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 呼叫函式

呼叫函式時，要寫出函式名稱，並在括號中為函式的每個參數傳入引數。

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 具名回傳值與裸回傳

和參數一樣，回傳值也可以選擇加上名稱。
如果使用了具名回傳值，那麼不帶引數的 `return` 敘述就會回傳這些值。
這就叫做「裸回傳」。

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
