# 簡介

Julia 的核心目標之一，就是能快速且有效率地對數值資料進行運算。
_大量_的數值資料。

一般來說，這些資料會儲存在陣列（或某種相關的型別）中，所以說陣列是 Julia 語言的核心，一點也不為過。

陣列的大小可以任意（只受限於硬體的記憶體），維度也可以任意多。

這篇入門概念聚焦在一維陣列的基礎，也就是所謂的向量。

## 建立向量

在 Julia 中，向量是一串有順序的值，可以透過索引編號來存取。

建立向量最簡單的方法，就是把值列在方括號裡：

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

Vector 的型別會與每個元素的型別一致。

_所以向量必須是同質的（所有元素的型別都相同）嗎？_

某種程度上，是的，而且如果你想要最好的效能，建議盡量朝這個方向做。
不過，Julia 在必要時可以透過 `Any` 型別繞過這個限制：

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

建立空向量時，Julia 預設的元素型別是 `Any`，但你可以在空陣列上標註想要的元素型別，把它定義得更明確。

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# 索引

請閱讀並記住這條規則：

- ***在 Julia 中，索引預設從 1 開始，而不是 0***。

用過其他資料科學語言（R、Matlab、Fortran……）的人對這點應該很熟悉，但對有 C 類型語言背景的資訊科學家來說，可能會覺得很震撼。

除此之外，索引的運作方式就和你想的一樣：把它們放進方括號裡就行了：

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

請注意，用 `end`（非常實用）和 `begin`（大概沒那麼實用）來索引有多方便。

用 Python 寫程式的人可能會好奇負索引。
別這麼想，Julia 並沒有負索引，用了會拋出`BoundsError`，任何小於 1 或大於`length(squares)`的索引也一樣。

## 向量運算

Julia 的向量是_可變的_：我們可以改變個別元素的內容。

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

有許多函式可以用來操作向量，不過 Julia 的文件把它們一般化為「collection」，而不只是向量。

注意，依照慣例，會修改輸入的函式名稱會帶有 `!`。
編譯器不會強制執行這點，但這在 Julia 的世界裡是非常_強烈_的慣例。

以下是幾個實用的函式：

- 要把值加到向量末端，用`push!()`。
- 要移除最後一個值，用`pop!()`。
- 要操作向量的開頭，對應的函式是`pushfirst!()`和`popfirst!()`。
- 要在任何位置插入或移除元素，有`insert!()`和`deleteat!()`。

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
