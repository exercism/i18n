# 說明

你正在建立一個簡單的線上遊戲，讓朋友可以猜一個秘密數字。你想提供一些回饋，但又不想因為一次猜測就洩漏答案。你需要設計一個函式，根據猜測與秘密數字之間的關係，提供不同的回應。

| 條件                                                     | 回應       |
| ------------------------------------------------------------- | -------------- |
| 當猜測與秘密數字相符時                      | "Correct"      |
| 當猜測比秘密數字多一或少一時 | "So close"     |
| 當猜測大於秘密數字時              | "Too high"     |
| 當猜測小於秘密數字時              | "Too low"      |
| 當沒有進行猜測時                                       | "Make a guess" |

所有猜測和秘密數字都是整數。

## 1. 當猜測與秘密數字相符時，產生回應

實作`compare/2`函式，它接受兩個引數：`secret_number`和`guess`，兩者都是整數。

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. 當猜測大於秘密數字時，產生回應

修改`compare`函式，讓它能回應高於秘密數字的猜測。

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. 當猜測小於秘密數字時，產生回應

修改`compare`函式，讓它能回應低於秘密數字的猜測。

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. 當猜測比秘密數字多一或少一時，產生回應

修改`compare`函式，讓它能回應接近秘密數字的猜測。

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. 當沒有猜測時，產生回應

修改`compare`函式，讓它能回應沒有猜測的情況。

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
