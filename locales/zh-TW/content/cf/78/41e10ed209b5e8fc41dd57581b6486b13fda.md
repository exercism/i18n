# 簡介

## `switch` 敘述

維基百科將 `switch` 敘述描述為「一種選擇控制機制，用來讓變數或運算式的值改變程式的控制流程」。

這個機制涉及以下關鍵字：`switch`、`case`、`break` 和 `default`。

最簡單的形式是測試一個基本型別或字串運算式，並根據它的值做出決定。例如：

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

最複雜的形式則會用到向下轉型`case <Type> <variable>:`和防護條件（`when`）。

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
