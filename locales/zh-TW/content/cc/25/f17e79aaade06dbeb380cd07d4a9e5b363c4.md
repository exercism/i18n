# 指令

你最近買的那台遙控車，已經變成了一項全新的嗜好。你一直在籌辦遙控車比賽。

你快要寫完一個能執行比賽模擬的程式時，你的貓跳到鍵盤上，刪掉了幾行程式碼。現在你的程式已經無法編譯了……

## 1. 修正編譯錯誤 `Race.__struct__/0 is undefined`

新增一個 alias，讓模組`NeedForSpeed.Race`可以用較短的名稱`Race`來引用。

## 2. 修正編譯錯誤 `Car.__struct__/0 is undefined`

新增一個 alias，讓模組`NeedForSpeed.RemoteControlCar`可以用較短的名稱`Car`來引用。

## 3. 修正編譯錯誤 `undefined function puts/1`

函式`puts/1`來自模組`IO`。將它 import 進來，就能直接使用，不需要再引用模組。

## 4. 修正編譯錯誤 `undefined function default_color/0`

函式`default_color/0`、`red/0`、`cyan/0`、`green/0`全都來自模組`IO.ANSI`。你打算支援更多車色，所以想把整個模組 import 進來。可惜的是，模組`IO.ANSI`的函式`color/1`會和你其中一個本地函式衝突。把整個`IO.ANSI`模組 import 進來，唯獨排除那個函式。
