# 關於

這個程式設計練習示範了參數的幾個特性：

- 未加修飾詞（例如`out`或`ref`）的參數是[以傳值方式傳遞][passing-parameters]的。也就是說，這個參數可以在被呼叫的方法裡使用與指定，但任何變更都不會影響到呼叫端。
- 當參數是陣列的參考或類別的執行個體時，被呼叫的方法可以變更該執行個體的元素/欄位，而呼叫端也會看到這些變更。無論是否加上`ref`修飾詞，這一點都成立。
- 帶有[`out`][out-parameter]修飾詞的參數會把值從被呼叫的方法傳回給呼叫端。這個參數可以不經初始化就傳給被呼叫的方法，而且無論如何，在被呼叫的方法內，它在進入時都會被視為尚未初始化。想理解參數修飾詞的行為與規則，透過範例（見下文）和編譯器訊息是最容易的方式。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out`參數必須在被呼叫的方法內指定值。

- 帶有[`ref`][ref-parameter]修飾詞的參數會把值傳入被呼叫的方法。當方法傳回時，呼叫端會看到被呼叫的方法對該參數所做的任何更新。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`參數必須是變數，因為被呼叫的方法會直接操作呼叫端所看到的該參數。

- `out` 和 `ref` 修飾詞在被呼叫的方法簽章和呼叫位置都必須出現。
- `out` 參數可以在呼叫位置內嵌宣告，即：`Foo(out int importantValue);`
- 如果你呼叫的方法有 `out` 參數，但你對其中一個或多個參數被指定的值不感興趣，可以使用[捨棄][discard]虛擬變數`_`，例如：`Foo(out int _);`

所有關於 `ref` 和 `out` 參數的規則都由編譯器強制執行。

[`in`][in-parameter]參數也存在，但它主要是一種效能最佳化，會在 `structs` 練習中討論，因為在那裡最相關。

上面連結的說明文件摘要如下：

- [傳遞參數][passing-parameters]：說明值可以如何作為引數傳遞。請注意，struct 加參數這個主題會在 `structs` 練習中討論。
- [ref 參數][ref-parameter]：說明 `ref` 參數的運作方式。
- [out 參數][out-parameter]：說明 `out` 參數的運作方式。

研究這些說明文件時，請注意它使用了以下術語：

- parameter / formal parameter：指被呼叫的方法所看到的參數。
- argument：指呼叫端所看到的參數。

[可以這麼說][so-tuples-vs-out]，自從 C# 7 引入 `tuples` 之後，`out` 參數的許多價值都已被取代。`tuples` 練習示範了如何使用 `tuples` 傳回多個值。

雖然 `ref` 使用起來很容易，也沒有效能上的損失，但在廣泛使用之前，值得先看看某個特定的程式碼庫是如何處理它所解決的問題的。還有其他替代做法，例如以傳值方式傳入，並使用被呼叫方法 return 敘述所傳回的值。同樣地，`tuples` 也能派上用場。

從[說明文件][ref-parameter]中你會看到，`out` 和 `ref` 在某些情況下不能使用，但你現在可以先忽略這些情況。當這類情況出現時，編譯器會讓你知道。

請注意，`optional parameters` 和 `named arguments` 會在 `method-overloading` 練習中討論。

[`ref local`][ref-local] 和 [`ref return`][ref-return] 這兩個相關主題會在別處討論。

## 堆疊配置

關於參數及其修飾詞的規則相當直接明瞭，你可以照字面理解，並在它們的抽象層次上掌握它們。不過，如果你對底層機制有興趣，想知道為什麼這些關鍵字可能造成效能差異（至少在 `struct` 的情況下），可以從這篇[_維基百科條目_][calling-conventions]開始，並留意 C# 在 x86/64 上使用 `stdcall`。

重點在於：對於未加修飾詞的參數，變數的**值**會被複製到程式的堆疊上，讓被呼叫的常式可以使用；而對於 `ref`、`out` 和 `in` 參數，則是把指向存放該值之記憶體的指標（**參考**）放到程式的堆疊上，值則被指定到該參考所指向的記憶體。
