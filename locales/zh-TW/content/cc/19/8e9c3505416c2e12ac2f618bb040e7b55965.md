# 說明

在這道練習中，你會動手實作幾個管理預約的函式。
系統會把所有資料都存成 ISO 8601 格式的字串，但人們並不是這樣使用行事曆的。
因此需要各種函式來在不同格式之間轉換。

## 1. 建立一筆預約

建立一筆從現在起 `n` 天後、時間為當下時刻的預約。
這個函式接收 `n` 天，並回傳從現在起 `n` 天後的預約時間。

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

如果沒有用到第二個參數 `now`，就應該改用目前時間。

## 2. 將日期轉換成時間戳記

許多工具只支援國際標準化的 ISO 8601 格式。
請撰寫函式`getAppointmentTimestamp`，接收一個日期並回傳該格式的字串。

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. 取得預約的詳細資料

時間戳記不好閱讀，而一個能取得預約詳細資料的函式正好可以幫上忙。
函式`getAppointmentDetails`接收 ISO 8601 格式的時間戳記，並回傳年、月、日、時、分。

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. 用指定的選項更新預約

這個函式的第一個引數是預約時間，第二個引數則是裝有一些選項的物件。
你必須依照物件中的選項更新預約，並回傳新的預約日期。
選項物件裡可能包含多個選項。

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. 取得兩筆預約之間可用的時間

這個函式會接收兩筆預約（時間戳記）作為引數。
你必須回傳這兩個時間相差的秒數。

由於半秒幾乎沒有意義，請在回傳前先將數字四捨五入。

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. 檢查預約目前是否有效

最後，當預約建立後，系統需要檢查它是否有效。
換句話說，預約必須落在未來，而不是過去。

請撰寫函式`isValid`，它接收兩個引數：一個是預約的時間戳記（字串），另一個是以時間戳記表示的目前時間（字串）；在給定目前時間的情況下，如果該預約位在未來，就回傳`true`。

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
