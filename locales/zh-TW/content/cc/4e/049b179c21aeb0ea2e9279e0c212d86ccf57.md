# 說明

在這個練習中，你會處理儲蓄帳戶。
每年，儲蓄帳戶的餘額會根據利率更新。
銀行給你的利率取決於你帳戶裡的金額（也就是餘額）：

- 餘額為負時為 3.213%（餘額會變得更負）。
- 餘額為正且小於`1000`元時為 0.5%。
- 餘額為正、大於等於`1000`元且小於`5000`元時為 1.621%。
- 餘額為正且大於等於`5000`元時為 2.475%。

你有四項任務，每項都會涉及你的餘額和它的利率。

## 1. 計算利率

實作方法`SavingsAccount.interest_rate()`，它接受一個餘額作為引數。
這個方法應該回傳指定餘額的利率。

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. 計算利息

實作方法`SavingsAccount.interest()`，它接受一個餘額作為引數。
這個方法應該回傳指定餘額的利息。

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. 計算年度餘額更新

實作方法`SavingsAccount.annual_balance_update()`，它接受一個餘額作為引數。
這個方法應該回傳一年後的餘額。

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. 計算達到目標餘額所需的年數

實作方法`SavingsAccount.years_before_desired_balance()`，它接受一個餘額和一個目標餘額作為引數。
這個方法應該回傳達到目標餘額所需的年數。

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
對本金餘額套用單利時，會把餘額乘以利率，兩者的乘積就是利息金額。

複利則不同，它是定期套用利息。
每次套用時都會計算出利息金額並加到本金餘額上，讓之後的利息計算都建立在更大的本金餘額之上。
~~~~
