# 關於

[守衛][guards]是[模式比對][exercism-pattern-matching]的補充，可以用來做更複雜的檢查。在可以使用模式比對的[某些（但並非全部）情況][where-guards-can-be-used]下也能使用守衛，例如函式子句或 case 子句。

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- 守衛以 `when` 關鍵字開頭，後面接著一個布林運算式。
- 守衛運算式是特殊的函式，它們：
  - 必須是[純函式][pure-function]，且不會改變任何全域狀態。
  - 必須回傳嚴格的 `true` 或 `false` 值。
- 常見的守衛清單記錄在 [Elixir 文件][kernel-guards] 中，其中包括：
  - 型別檢查：[`is_integer/1`][guard-is-integer]、[`is_list/1`][guard-is-list]、[`is_nil/1`][guard-is-nil] 等。
  - 算術運算子：[`+/2`][guard-plus]、[`-/2`][guard-minus] 等。
  - 比較：[`==/2`][guard-equals]、[`>/2`][guard-greater]、[`</2`][guard-less] 等。
  - 布林運算子：[`and/2`][guard-and]、[`or/2`][guard-or]、[`not/1`][guard-not]
  - 成員運算子：[`in/2`][guard-in]
- 你可以用 [`defguard`][defguard] 定義自己的守衛。

  - 依照 Elixir 的[命名慣例][naming]，守衛的名稱應該以 `is_` 開頭。

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
