# 指令補充

## 詞

定義一個`game`元組，以及一個建構子`<game> ( -- game )`，它會回傳一個還沒有任何投球的新遊戲。

請提供這些可作用於遊戲的詞：

- `roll ( pins game -- )`：記錄有`pins`根球瓶被擊倒。當投球無效時，請拋出錯誤：
  - `"Negative roll is invalid"`：球瓶數為負數時。
  - `"Cannot roll after game is over"`：十局（以及任何補球）全部投完之後，還要再投球時。
  - `"Pin count exceeds pins on the lane"`：被擊倒的球瓶比球道上還站著的球瓶多時。
- `score ( game -- n )`：整場遊戲的總分。遊戲還沒完成時，拋出`"Score cannot be taken until the end of the game"`。

注意，`roll`會遮蔽`kernel`詞彙表中洗牌的`roll`詞。測試套件用`FROM: bowling => roll ;`來區分。
