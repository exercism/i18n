# 關於

C# 的`struct`和`class`密切相關。
它們有狀態和行為。
它們可以有相同種類的成員：建構函式、方法、欄位、屬性等。

欄位和屬性可以是簡單型別、`struct`或參考型別。
`struct`和`class`一樣，遵循相同的作用域、讀寫規則和存取層級規則。

```csharp
enum Unit
{
    Kg,
    Lb
}

struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```

要記住的主要事情之一是，當一個 struct 被指定給變數或作為參數傳遞時，值會被複製過去，因此對原始變數的變更不會影響複製出來的變數，反之亦然。
總而言之，`struct`是**實值型別**。

這篇[文章][class-or-struct]討論了`struct`與`class`之間的差異。
從文章中你會看到，`struct`傾向於輕量且[不可變][structs-immutable]，不過這項指導方針（預設）不會由編譯器或執行階段強制執行。

有幾件事你會遇到（而且編譯器會提醒你）：

1. `struct`的成員無法內嵌初始化。
2. `struct`無法被繼承。
3. `struct`一律有預設建構函式，即使提供了非預設建構函式也一樣，而且你無法提供明確的無參數建構函式。

由於上述第 1 點和第 3 點，`struct`的開發者無法防止無效的執行個體產生。

## 常見的 struct

從文件中你會看到，基本型別與 struct 之間有密切關係。
請參閱[`Int32/int`][int32]以取得範例。
更常見的`struct`範例是型別[`TimeSpan`][time-span]。

`TimeSpan`的執行個體行為很像數字，具有比較運算子（例如`>`和`<`）以及算術運算子。
當你需要時，可以為自己的`struct`實作這些運算子。

關於`TimeSpan`有一點要注意：它實作了許多介面，例如`IComparable<TimeSpan>`。
雖然`struct`無法從其他`struct`衍生，但它們可以實作介面。

## 相等性

`struct`的相等性測試通常比`class`的簡單許多，因為預設會直接比較欄位是否相等。
不需要覆寫`object.Equals()`（或`GetHashCode()`）。
請記住，如果你依賴`Object.GetHashCode()`，仍然必須確保產生雜湊碼的欄位（也就是所有欄位）在雜湊集合使用期間不會變更。
實際上，這表示以這種方式使用的 struct 應該是不可變的。

與方法`Equals()`不同，相等運算子`==`和`!=`沒有預設實作。
如果你的`struct`需要它們，就必須自行實作。

另一方面，這篇[文章][equality]說明如何透過建立自己的自訂`Equals()`和`GetHashCode()`方法來最佳化效能，就像`class`常見的做法一樣。
在這個練習的情況下，差異大約是 20%，但這是在不太嚴謹的比較中得到的結果；不過這可能偏低，因為所有欄位都是相同型別，詳見下文。

在[網路][equality-performance]上有一些關於速度改進的討論，探討在所有欄位都是相同型別時，未覆寫`Equals()`方法的情況。
在這個練習中，包含不同型別欄位時的差異大約是 60%。
Microsoft 的文件並未提及這一點，因此這算是未記載的實作細節，應該審慎利用。

```csharp
public bool Equals(Weight other)
{
    return count.Equals(other.count) && unit.Equals(other.unit);
}

public override bool Equals(object obj)
{
    return obj is Weight other && Equals(other);
}

public override int GetHashCode()
{
    return HashCode.Combine(count, unit);
}
```
