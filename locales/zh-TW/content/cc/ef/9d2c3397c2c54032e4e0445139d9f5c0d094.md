# 簡介

PowerShell 是 Microsoft 推出的動態隱含型別（也支援強型別變數）指令碼語言，主要專注於工作自動化與設定管理。

PowerShell 支援命令式、函式式、物件導向程式設計，甚至支援管線風格。

PowerShell 建構於 .NET 平台上，並於 2006 年首次發布。
所有現代 Windows 作業系統都預設內建，也可以安裝在 Mac 與 Linux 上。


## 變數

在 PowerShell 中有兩種常見的方式可以定義變數。

PowerShell 中的變數名稱必須以`$`開頭，並使用賦值運算子`=`將變數名稱綁定到某個值。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

如果你想強制要求特定的[型別][strong typed]，也可以明確指定變數的型別。
如果可行的話，PowerShell 會盡力將值從一種型別轉換成另一種。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### 常數

PowerShell 中的常數是唯讀變數，定義之後就無法**移除**。
這帶出了第二種定義變數的方式：使用 cmdlet `New-Variable`。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

如果想了解更詳細、更進階的建立變數方式與各種選項，請參閱 [New-Variable][New-Variable] cmdlet。


## 函式

PowerShell 中的[函式][functions]是使用`function`關鍵字定義的。
每個函式可以在`()`括號中擁有零個或多個正式的[參數][parameters]，接著是它自己的[作用域][scope]，以`{`開始、以`}`結束。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell 中的函式可以透過`return`關鍵字明確地回傳值，呼叫時使用`FuncName $Arg`這樣的語法。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

如何撰寫詳細的函式定義，以及函式如何隱含地回傳值，這些進階內容會在`Functions`概念模組中介紹。


## 註解

PowerShell 的單行註解以`#`開頭，在該行結束時結束。
PowerShell 的註解區塊以`<#`開頭，以`#>`結束。
如何使用註解區塊建立 Comment-Based Help 的進階範例，會在`Functions`概念模組中介紹。

```powershell
function Main() {
    #This is a comment
}
```
