# 阿姆斯壯數的概念

> [阿姆斯壯數](https://en.wikipedia.org/wiki/Narcissistic_number)是一種數字，它的每個位數各自取「位數個數」次方後相加，總和恰好等於該數字本身。

## 範例解法

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## 概念

- 函式：驗證解法、定義邏輯時不可或缺
- 測試套件：驗證解法時必備
- 整數：以 u32 表示引數，並用於判斷是否相等的斷言
- `&str`：由於 Rust 是強型別語言，計算數字長度時會用到
- `Option<T>`：取得 `char::to_digit` 實際值時會用到
- 型別轉換：進行算術運算時必須使用
- 疊代器功能：
  - turbofish：讓我們能用單一運算式完成解法
  - `map` 與 `sum`：方便將運算式化簡成我們要斷言的結果
