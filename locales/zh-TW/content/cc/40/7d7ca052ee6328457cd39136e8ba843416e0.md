# 簡介

處理二進位資料有時並不容易，所以 Gleam 提供了`BitArray`型別，以及用來建構二進位資料與進行模式配對的相關語法。

位元陣列常值使用`<<>>`語法來定義。定義位元陣列常值時，是以區段為單位。每個區段包含一個值與一個標註，兩者以`:`分隔。標註指定了編碼這個值需要多少位元，也可以完全省略，此時預設為 8 位元整數值。

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

將型別寫成`:1`，是`:size(1)`的簡寫。如果位元大小來自變數，就必須使用較長的語法。

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## 二進位

撰寫二進位整數常值時，可以在常值前面加上`0b`，直接以 2 為基底來書寫。要注意的是，在測試或程式裡印出時，它們會以十進位數字顯示。

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## 截斷

如果區段的值超出該區段型別的容量，就會從左側截斷。

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## 前置與附加

使用位元陣列語法，可以對現有的位元陣列前置或附加內容。現有的位元陣列必須使用`:bits`標註。

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## 串接

我們可以用這個語法串接儲存在變數中的位元陣列。串接兩個大小不定的位元陣列時，必須使用`:bits`標註。

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## 模式配對

也可以透過模式配對從位元陣列中取出值。你必須知道每個想捕捉的片段有多少位元，只有一個例外：可以用`:bits`標註對大小未知的位元陣列進行模式配對，但這只能用於最後一個片段。

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## 檢視位元陣列

~~~~exercism/note
位元陣列印出來的形式，可能和當初建立它們時使用的形式不同。這在學習位元陣列時常常造成困惑。
~~~~

預設情況下，位元陣列會以 8 位元（一個位元組）的片段顯示，即使你建立時使用的是不同大小的片段。

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

如果你建立的位元陣列代表一個可列印的 UTF-8 編碼字串，像`io.debug`這樣的函式可能會把它顯示成字串。這是因為 Gleam 內部表示字串的方式有這樣的實作細節。

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
