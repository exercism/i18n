# 提示

## 一般

- x86-64 的記憶體位址是 64 位元（8 位元組）的數字。
- 你應該使用`rel`來建立記憶體中有效的相對位址。

## 1. 取得顏色的 RGB 值

- x86-64 的記憶體位址是 64 位元（8 位元組）的數字。
- 你應該使用`rel`來建立記憶體中有效的相對位址。
- 若要存取記憶體中某個位址所儲存的內容，你需要使用`[]`對它解參考。
- 32 位元（4 位元組）的整數會回傳在`eax`中。

## 2. 加入基色

- x86-64 的記憶體位址是 64 位元（8 位元組）的數字。
- 你應該使用`rel`來建立記憶體中有效的相對位址。
- 已初始化的變數會定義在 _section .data_ 中。
- 變數必須宣告為`global`，才能被其他原始碼檔案看見。
- 你可以重複使用已經實作的`get_color_value`函式。

## 3. 定義原色的常數

- x86-64 的記憶體位址是 64 位元（8 位元組）的數字。
- 你應該使用`rel`來建立記憶體中有效的相對位址。
- 已初始化的常數會定義在 _section .rodata_ 中。
- 常數必須宣告為`global`，才能被其他原始碼檔案看見。

## 4. 混合顏色

- x86-64 的記憶體位址是 64 位元（8 位元組）的數字。
- 你應該使用`rel`來建立記憶體中有效的相對位址。
- 若要存取記憶體中某個位址所儲存的內容，你需要使用`[]`對它解參考。
- 外部函式或資料必須在對應的區段中宣告為`extern`。
- 外部函式可能會修改你正在使用的任何一般暫存器，所以呼叫它之前，你需要先把變數存到記憶體中。
- `combining_function`會從`rdi`取得基色的 32 位元值（不是位址），並從`rsi`取得次要色的 32 位元值（不是位址）。
