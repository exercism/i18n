# 簡介

## 註解

Common Lisp 允許程式設計師撰寫會被電腦忽略的「註解」。
單行註解以一個或多個分號（`;`）開頭，偶爾你也會看到下面這種寫法：

```lisp
(code...) ; => value
```

這種註解用來表示 Common Lisp 執行該行程式碼後回傳什麼值。

慣例上，行末的簡短註解用一個分號，一段程式碼上方的較長註解用兩個分號，描述函式這類事物的長註解用三個，而原始檔最上方的標頭之類註解則用四個。

## Cons

所有 Common Lisp 物件不是「原子」（單一且不可分割的值），就是「cons」（由建構函式 cons 建立）。
一個 cons 由兩部分組成：第一個元素與其餘的元素。
基於歷史因素，這兩部分分別稱為 `car` 和 `cdr`。
當這些 cons 被當作程式碼求值時，第一個元素（`car`）代表被呼叫的函式，而其餘的元素（`cdr`）則代表傳給該函式的引數：

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## 運算式

所有 Common Lisp 程式碼都是由 S-Expressions（符號運算式）組成。它們簡稱 sexprs。每個 sexpr 不是原子就是 cons。S-Expressions 被求值時，會自動回傳某個值，取代原本的運算式。當你撰寫自己的函式（使用 `defun`）時，`defun` 主體中的最後一個值會自動被回傳：

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## 符號

Common Lisp 中的符號是特殊的值，可以指向其他值，或者，就_關鍵字_而言，指向它們自己。
當 Lisp 對符號求值時，會將它們替換成所指向的值：

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

請注意，關鍵字以開頭的冒號（`:`）表示。

引用是指在 S-expression 前面加上 `'`，它會告訴 Lisp 不要對該運算式求值。
在我們的 `defun` 範例中，透過引用 `'foo`，我們避免了 Lisp 試圖尋找（卻找不到）`FOO` 應該指向的對象，反而直接回傳 `FOO` 這個值本身。
如果程式中任何地方都沒有定義 `FOO`：

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

目前你可以把它想成一種從函式回傳符號的方法，但我們之後會再回來看引用，並在未來的概念練習中進一步探討它的影響。
