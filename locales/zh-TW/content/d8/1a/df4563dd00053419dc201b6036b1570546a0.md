# 簡介

Common lisp 提供了幾種不同的條件運算式，主要差別在於它們支援的分支數量。

- `when` 和 `unless` 只允許單一分支：

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

測試運算式之後的部分可以包含不只一個運算式。

- `if` 提供經典的 if-then-else 結構：

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

請注意，then 和 else 子句都只能放一個運算式。

- `cond` 讓你不必巢狀 `if` 運算式就能有多個分支：

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

請注意，測試運算式之後的運算式數量沒有限制。

- `case` 提供經典的「switch」風格結構：它會拿單一值去比對多個分支：

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

請注意，和 `cond` 一樣，測試運算式之後的運算式數量沒有限制。
