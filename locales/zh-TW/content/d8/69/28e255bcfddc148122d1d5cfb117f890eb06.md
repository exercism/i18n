# 說明

你正在紐西蘭健行，並用羅盤測量方位。方位是整數度數，而且它是一個值：轉動 20 度不會改變你測得的方位，而是會得到另一個方位。

請撰寫一個`immutable class BEARING`。程式碼骨架會提供類別標頭及其屬性。

## 1. 測量方位

`create`接受一個度數，並回傳一個方位。度數範圍是 0 到 359，因此超出範圍的數值會繞回來：370 是 10，-10 是 350。

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. 轉動

`turned`接受要轉動的度數，並回傳新的方位。傳入負數會朝另一個方向轉。原本的方位保持不變。

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. 比較

`is_eq`接受另一個方位，並回傳兩者是否相同。一旦它存在，`=`就能用於方位。

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. 指出方位點

`point`會回傳最接近該方位的羅盤方位點，其值為`"N"`、`"NE"`、`"E"`、`"SE"`、`"S"`、`"SW"`、`"W"`、`"NW"`其中之一。

每個方位點涵蓋 45 度，並以其精確方位為中心：北從 337.5 經過 0 到 22.5，東北從 22.5 到 67.5，依此類推。由於這裡的方位都是整數，方位 22 會是`"N"`，而方位 23 會是`"NE"`。

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. 寫下來

`str`會回傳度數和方位點，例如`"90 degrees (E)"`。

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
