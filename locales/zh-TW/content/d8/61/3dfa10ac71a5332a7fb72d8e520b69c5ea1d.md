# 關於

Rust 是一門系統程式設計語言，執行速度極快、能避免區段錯誤，並保證執行緒安全。
它的目標是為系統程式設計帶來現代化的語言設計與先進的型別系統。
Rust 不使用垃圾回收器，而是透過進階的靜態分析，提供確定性的資源釋放。
這一切是透過[所有權](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html)的概念達成的。

Rust 的核心與標準函式庫刻意保持精簡，並不預先附上「電池」。
因此我們鼓勵 Rustaceans 透過 [crates.io](https://crates.io/) 分享稱為 _crates_ 的函式庫，為這個語言增添更多功能。

Rust 最常用於講求速度、效能與穩定性的應用程式。
[Awesome Rust](https://github.com/kud1ing/awesome-rust) 清單蒐集了各種 Rust 專案範例，包括 CLI 工具、ORM、作業系統與遊戲。
無論你用 Rust 打造什麼，它都會既快速又記憶體安全喔！

Rust 的首頁是 [rust-lang.org](https://www.rust-lang.org/)。
Rust 在 [rust-lang.org/documentation.html](https://www.rust-lang.org/documentation.html) 有很棒的說明文件。
新手建議從 [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/) 的「The Book」開始看起。
