# 指令

在這個練習中，你會玩一款角色扮演遊戲，不同類型的鬥士可以在裡面互相對戰。
遊戲為每種類型的鬥士訂定了不同的規則。
我們會把焦點放在兩種特定的類型上：巫師與戰士。

對戰士來說，規則如下：

- 戰士永遠不易受傷。
- 如果戰士攻擊的鬥士不易受傷，戰士會造成`6`點傷害。
- 如果戰士攻擊的鬥士處於易受傷狀態，戰士會造成`10`點傷害。

對巫師來說，規則如下：

- 巫師可以事先準備法術。
- 巫師若沒有事先準備法術，就會處於易受傷狀態。
- 如果巫師事先準備了法術，會造成`12`點傷害。
- 如果巫師沒有事先準備法術，會造成`3`點傷害。

## 1. 建立 Warrior 類別

建立一個叫做`Warrior`的新類別。
這個類別應該繼承現有的`Fighter`類別。

## 2. 描述 Warrior

更新`Warrior`類別，讓它的`toString()`方法描述他們是哪種類型的鬥士。
這個方法應該回傳字串`"Fighter is a Warrior"`。

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. 讓戰士不會受傷

更新`Warrior`類別，讓它的`isVulnerable()`方法永遠回傳`false`。

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. 計算 Warrior 的傷害點數

更新`Warrior`類別，讓它的`getDamagePoints(Fighter)`方法依照上面的規則計算戰士造成的傷害。

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. 建立 Wizard 類別

再建立一個叫做`Wizard`的新類別。
這個類別同樣應該繼承現有的`Fighter`類別。

## 6. 描述 Wizard

更新`Wizard`類別，讓它的`toString()`方法描述他們是哪種類型的鬥士。
這個方法應該回傳字串`"Fighter is a Wizard"`。

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. 讓巫師可以準備法術，並在尚未準備法術時處於易受傷狀態

更新`Wizard`類別，新增一個叫做`prepareSpell()`的方法。
這個類別應該記住這個方法何時被呼叫，並確保只有在已準備法術時，它的`isVulnerable()`方法才回傳`false`。

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. 計算 Wizard 的傷害點數

更新`Wizard`類別，讓它的`getDamagePoints(Fighter)`方法依照上面的規則計算巫師造成的傷害。

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
