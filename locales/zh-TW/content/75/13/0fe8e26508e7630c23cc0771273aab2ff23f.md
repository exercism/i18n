# 提示

## 1. 定義 Coord 型別。

- `Coord` 是一個 `struct`。
- 它的欄位是 `x` 和 `y`。
- 兩者的型別都是 `UInt16`。

## 2. 定義 Plot 型別。

- `Plot` 是以 `struct` 關鍵字定義的。
- 它的欄位是 `bottom_left` 和 `top_right`。
- 兩者的型別都是 `Coord`。

## 3. 檢查你的主張是否已經登記。

- 這個主張是否已經是 `register` 中的元素？
- 如有需要，複習一下 [`Sets`][sets]。

## 4. 投機者可以指定一塊以角落座標標示的地塊來提出主張。

- 如果同樣的主張已經登記過，就回傳 `false`，表示你的主張失敗。
- 如果允許，就把主張加入 register。[`push!()][push] 函式可能很有用。
- 由於 `stake_claim!()` 是會修改狀態的函式，`register` 的變更對呼叫方是可見的。
- 可以串接點號表示法，例如 `claim.bottom_left.x`。
- 回傳 `true` 表示成功。

## 5. 找出地塊較長邊的長度。

- 記得這些矩形地塊的方向。你可以推斷出 `top_left` 和 `bottom_right` 座標。
- 計算各邊的長度只是簡單的算術。
- 注意 [`max()`][max] 和 [`maximum()`][maximum] 之間的差別。`max` 接受任意數量的引數進行比較，`maximum` 則接受單一可迭代物件。

```julia-repl
julia> max(1, 2, 3)
3

julia> v = [1, 2, 3];
julia> maximum(v)
3
```

## 6. 基於研究用途，找出已提出主張且邊最長的地塊。

- register 是一個 Set，無序但可迭代。
  - 把 register 轉換成有序的結構可能比較方便，例如使用 `collect()`。
  - 你已經寫了一個計算地塊最長邊的函式，可以把這個函式套用到整個集合上。
- 關於 `max` 與 `maximum` 的說明，請參閱任務 5。
- 找出一或多個長度最長的地塊。
- 把結果以 `Set{Plot}` 回傳。
