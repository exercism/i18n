# 簡介

Factor 中的字串是字元的序列。大部分`sequences`詞彙中的函式都能處理字串，另外還有[`splitting`][splitting]、[`ascii`][ascii]等詞彙中專門用來處理字串的函式。

```factor
USING: ascii sequences splitting ;

"hello, world" .                  ! => "hello, world"
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
"WARNING" >lower .                ! => "warning"
"  spaced  " [ blank? ] trim .    ! => "spaced"
"warning" "(" ")" surround .      ! => "(warning)"
```

`split1`和`split`（位於[`splitting`][splitting]）會切割字串，`split1`會在第一個出現的分隔符號處切割，`split`則會依字元集合中的任一字元來切割。`surround`和`glue`（位於[`sequences`][sequences]）則會建立字串，`surround`會用前綴和後綴把字串包起來，`glue`則會用分隔符號連接兩個字串。[關於](./about.md)頁面會列出每個處理字串的函式，以及它所屬的詞彙。

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[ascii]: https://docs.factorcode.org/content/vocab-ascii.html
