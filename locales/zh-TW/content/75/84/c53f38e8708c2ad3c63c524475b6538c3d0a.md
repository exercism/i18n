# 指示

Conda Airlines 是程式設計界最大的航空公司，每天有超過 10,000 個航班！

他們目前以人工方式為所有乘客分配座位，這必須自動化。

他們請_你_開發一套軟體，讓乘客座位分配自動化。
他們要求你的軟體要節省記憶體、效能要好。

## 1. 產生座位字母

Conda 想為他們的飛機產生座位字母。
一架飛機是由一排排座位組成的。
每一排有 _4 個座位_。
每一排的座位一律命名為`A`、`B`、`C`和`D`。
一排中的第一個座位是`A`，第二個座位是`B`，以此類推。
到達`D`之後，應該重新從`A`開始。

實作一個函式`generate_seat_letters(<number>)`，它接受一個`int`，代表要產生多少個座位字母。
這個函式接著應該回傳座位字母的_可迭代物件_。

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. 產生座位

Conda 想要一套能為他們的飛機產生指定數量座位的系統。
每架飛機的每一排都有 _4 個座位_。
排數以數字定義，從`1`開始往上遞增。
座位的排序應該像這樣：`1A`、`1B`、`1C`、`1D`、`2A`、`2B`、`2C`、`2D`、`3A`、`3B`、`3C`、`3D`、……

以下是一個例子：

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|      排      |  5  | 21  |
|   座位字母    |  A  |  D  |
|     結果     | 5A  | 21D |

由於乘客的迷信，許多航空公司的班機上沒有 13 號_排_。
Conda Airlines 也遵循這項慣例，所以請務必_不要_產生 13 號_排_的座位。

實作一個函式`generate_seats(<number>)`，它接受一個`int`，代表要產生多少個座位。
這個函式接著應該回傳這些座位的_可迭代物件_。

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. 將座位分配給乘客

現在你已經有個會產生座位的函式，可以用它來把座位分配給乘客。

實作一個函式`assign_seats(<passengers>)`，它接受一份乘客姓名的`list`。
這個函式接著應該回傳一個_字典_，以`passenger`為_鍵_，`seat_number`為_值_。

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. 票券代碼

Conda Airlines 希望每張票都有唯一的代碼。
由於他們是大型航空公司，航班非常多。
這表示會有多個航班擁有相同的座位號碼。
他們要你打造一套系統，產生一組由 _12_ 個字元組成的唯一票券字串。

這組代碼以`assigned_seat`開頭，接著是`flight_id`。
代碼其餘部分以`0s`填滿。

實作一個函式`generate_codes(<seat_numbers>, <flight_id>)`，它接受一份由`seat_numbers`組成的`list`，以及一個含有航班編號的`string`。
這個函式接著應該回傳一個`generator`，逐一產生`ticket_number`。

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
