# 簡介

`Option`是一個列舉，用來檢查函式回傳值是否有效。它的定義如下：

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

It is a part of the `haxe.ds` package:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
