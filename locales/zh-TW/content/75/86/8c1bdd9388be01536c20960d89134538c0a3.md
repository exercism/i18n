# 說明

在這個練習中，我們要為核子反應爐開發一套簡單的控制系統。

反應爐要產生電力，就必須處於_臨界_狀態。如果反應爐的狀態低於臨界，就可能受損；如果反應爐的狀態超過臨界，就可能過載，導致爐心熔毀。我們希望能降低熔毀的機率，並正確地管理反應爐的狀態。

以下三個任務都與撰寫程式碼來維持理想的反應爐狀態有關。

## 1. 檢查臨界狀態

控制系統第一件要做的事，就是檢查反應爐是否處於平衡的臨界狀態。當反應爐滿足以下條件時，就稱為處於臨界：

- 溫度低於 800 K。
- 每秒釋放的中子數大於 500。
- 溫度與每秒釋放中子數的乘積小於 500000。

請實作方法`Reactor.criticality_balanced?`，它接受以克氏溫標計量的`temperature`和`neutrons_emitted`作為參數，並在符合臨界條件時回傳`true`，不符合時回傳`false`。

```crystal
Reactor.criticality_balanced?(750, 600)
# => true
```

## 2. 判斷功率輸出範圍

反應爐開始產生電力之後，就必須判斷它的效率。效率可以分為 4 個等級：

1. `green` -> 效率達 80% 以上，
2. `orange` -> 效率低於 80%，但至少 60%，
3. `red` -> 效率低於 60%，但仍有 30% 以上，
4. `black` -> 效率低於 30%。

百分比數值可以用`(generated_power/theoretical_max_power)*100`計算，其中`generated_power` = `voltage` \* `current`。請注意，百分比數值通常不會是整數，因此務必留意`<`和`<=`比較的正確用法。

請實作方法`Reactor.reactor_efficiency`，它有三個參數：`voltage`、`current`和`theoretical_max_power`。這個函式應回傳反應爐的效率等級："green"、"orange"、"red"或"black"。

```crystal
Reactor.reactor_efficiency(200,50,15000)
# => "orange"
```

## 3. 失效安全機制

你的最後一項任務，是建立一套失效安全機制，以避免過載與爐心熔毀。這套機制會判斷反應爐是低於、等於還是高於理想的臨界門檻。接著就能透過將控制棒插入（或移出）反應爐，來提升、降低或停止臨界程度。

請實作方法`Reactor.fail_safe()`，它接受 3 個參數：以克氏溫標計量的`temperature`、`neutrons_produced_per_second`和`threshold`，並輸出反應爐的狀態代碼。

- 如果`temperature * neutrons_produced_per_second`小於`threshold`的 90%，請輸出狀態代碼 "LOW"，表示必須移除控制棒才能產生電力。

- 如果`temperature * neutrons_produced_per_second`落在`threshold`加減 10% 的範圍內，反應爐就處於_臨界_狀態，此時應輸出狀態代碼 "NORMAL"，表示反應爐處於最佳狀態，控制棒也位於理想位置。

- 如果`temperature * neutrons_produced_per_second`不在上述範圍內，反應爐正邁向爐心熔毀，必須傳遞狀態代碼 "DANGER"，以立即關閉反應爐。

```crystal
temperature = 1000
neutrons_produced_per_second = 30
threshold = 5000
Reactor.fail_safe(temperature, neutrons_produced_per_second, threshold)
# => "DANGER"
```
