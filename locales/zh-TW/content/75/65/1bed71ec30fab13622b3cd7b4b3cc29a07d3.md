# Entry API

entry API 通常是操作 map 結構內容最慣用的方式。不過，對 Rust 來說這點不太尋常，它並沒有被形式化成 trait，只是一組實作在標準函式庫 map 型別上的型別和方法。

基本上，`map.entry()`方法會提供一個`enum`：

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

它的好用之處，來自實作在那個 enum 上的更多方法。舉例來說，如果你想取得某個鍵對應的值、而且可能修改它，而該值型別的預設值又剛好合用，你只要這樣寫：

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

對於像計數器這樣的應用，這讓事情變得非常簡單：

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

如果該型別的預設值不適合你的應用，你可以用`or_insert`提供自己的常數預設值，或用`or_insert_with`計算一個。

在某些情況下，你可能想先對既有的值做一番計算，再進行任何可能的插入。這時`and_modify`可以辦到，不過這種用法比較少見。`and_modify`更常見的用途，是省去解參考的需要：

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

有時候，我們會想直接對 entry 做 match。這是允許的：

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

想了解更多資訊，請參閱[`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html)與[`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html)。
