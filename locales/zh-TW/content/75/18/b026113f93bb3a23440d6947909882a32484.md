# Match 運算式

match 運算式會對一個值和一個條件求值，並回傳一個接下來要再求值的運算式。就像三元運算式一樣，如果條件不符合，就不會對要回傳的運算式求值。要比對一個條件時，會進行身分比對（嚴格相等，或`===`）。

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

如果要進行相等比對（`==`），可以重新安排條件的寫法：

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

在 match 運算式中，如果沒有任何條件符合，就會拋出`UnhandledMatchError`。
