# 指令

給定任意兩個陣列`A`和`B`，判斷下列何者成立：

- 陣列`A`等於陣列`B`；或
- 陣列`A`包含陣列`B`（`A`是`B`的超陣列）；或
- 陣列`A`被陣列`B`包含（`A`是`B`的子陣列）；或
- 以上皆非，因此陣列`A`和`B`不相等

具體來說，如果兩個陣列以相同順序含有相同的值，則陣列`A`等於陣列`B`。
如果`A`包含一段與`B`相等的子序列，則`A`是`B`的超陣列。
如果`B`包含一段與`A`相等的子序列，則`A`是`B`的子陣列。

範例：

- 如果`A = []`且`B = []`（兩個陣列都是空的），則`A`和`B`相等
- 如果`A = [1, 2, 3]`且`B = []`，則`A`是`B`的超陣列
- 如果`A = []`且`B = [1, 2, 3]`，則`A`是`B`的子陣列
- 如果`A = [1, 2, 3]`且`B = [1, 2, 3, 4, 5]`，則`A`是`B`的子陣列
- 如果`A = [3, 4, 5]`且`B = [1, 2, 3, 4, 5]`，則`A`是`B`的子陣列
- 如果`A = [3, 4]`且`B = [1, 2, 3, 4, 5]`，則`A`是`B`的子陣列
- 如果`A = [1, 2, 3]`且`B = [1, 2, 3]`，則`A`和`B`相等
- 如果`A = [1, 2, 3, 4, 5]`且`B = [2, 3, 4]`，則`A`是`B`的超陣列
- 如果`A = [1, 2, 4]`且`B = [1, 2, 3, 4, 5]`，則`A`和`B`不相等
- 如果`A = [1, 2, 3]`且`B = [1, 3, 2]`，則`A`和`B`不相等
