# 簡介

陣列是 Factor 主要的固定長度序列型別，寫成`{ … }`：你可以改變元素，但不能改變長度。`arrays`和`sequences`這兩個詞彙庫一起提供了從堆疊取值的小型建構子，以及用於連接、反轉和查找元素的日常操作。

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
