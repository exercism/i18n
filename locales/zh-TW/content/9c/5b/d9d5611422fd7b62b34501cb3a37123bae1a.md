# 簡介

型別定義會建立一個新的具名型別，它和其他所有型別都不相同，即使兩者的底層型別一樣也一樣。

## 定義型別

型別定義以`type`關鍵字開頭，後面接著新型別的名稱和它的底層型別：

```go
type File []bool
```

`File`在這裡指的是棋盤上單一直行，通常標示為 A 到 H。這個直行裡的每個格子都用一個布林值表示，標記它是否被佔用。現在`File`定義好了，我們就能在其他定義裡使用它：

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`會把直行的識別碼對應到`File`值。每個`File`都是一個由布林值組成的切片，代表棋盤上某一直行裡的格子。如果沒有這些型別定義，`board`就會是`map[string][]bool`，這樣一來，我們就更難理解它到底代表什麼了。
