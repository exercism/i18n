# 使用模組說明文件

[comment]: # (當提交的解答缺少模組的 @moduledoc 時，就會產生這個錯誤)

建議加上 [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) 屬性，說明模組的用途。

- 在 Elixir 中，說明文件是[一等公民](https://hexdocs.pm/elixir/writing-documentation.html)。Elixir 的說明文件設計得既容易閱讀，也容易撰寫。
- 在說明文件屬性`@moduledoc`和`@doc`裡可以使用 Markdown 語法。
