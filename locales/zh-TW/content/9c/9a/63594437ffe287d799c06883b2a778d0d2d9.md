# 指令

威靈頓的氣象站將以全新的數位系統，取代原本的人工溫度記錄系統。
在舊系統中，所有計算都是以人工方式完成。
在新系統中，這些計算將會自動化。
這些計算包括將溫度從攝氏轉換為華氏，以及求出平均溫度。
新系統配備了感測器，用來記錄以攝氏表示的溫度資料。

威靈頓氣象站希望你能協助他們打造這套新系統。

## 1. 將溫度從攝氏轉換為克氏

氣象站的網站上有一個專為研究人員設計的區塊。
研究人員關心的是以克氏表示的溫度。

克氏是測量溫度的一種單位。
它和攝氏使用相同的刻度，但起始點不同。
它的起始點是絕對零度，也就是 0K（克氏）或 -273.15°C（攝氏）。

下表列出攝氏與克氏之間的換算：

| 攝氏（°C） | 克氏（K） |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

氣象站希望你能實作一個將溫度從攝氏轉換為克氏的方法。

請實作`Temperature#to_kelvin`方法，它接受一個引數`celsius`，並在給定的`celsius`值加上 273.15 後，回傳以克氏表示的溫度。

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. 將溫度四捨五入

氣象站的溫度感測器非常精確。
它能測量到 0.0001°C。
由於大多數使用者對這樣的精確度並不感興趣，氣象站只想顯示四捨五入到小數點後一位的溫度。

氣象站希望你能實作一個將溫度四捨五入到小數點後一位的方法。

請實作`Temperature#round`方法，它接受一個引數`celsius`，並回傳四捨五入到小數點後一位的溫度。

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. 將溫度從攝氏轉換為華氏

氣象站的網站上有一個專為遊客設計的區塊。
遊客關心的是以華氏表示的溫度。

華氏是測量溫度的一種單位。
它的刻度與攝氏不同。
0°C 等於 32°F，而 1 度的攝氏等於 1.8 度的華氏。

下表列出攝氏與華氏之間的換算：

| 攝氏（°C） | 華氏（°F） |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

氣象站希望你能實作一個將溫度從攝氏轉換為華氏的方法。

請實作`Temperature#to_fahrenheit`方法，它接受一個引數`celsius`，並以整數回傳以華氏表示的溫度。

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. 取得缺少的感測器數量

在安裝溫度感測器的過程中，維護人員發現少了幾個感測器。
每個溫度測量單元需要四個溫度感測器。
維護團隊清點了手邊的感測器數量，但還需要知道缺少多少個。
他們希望有人能協助計算，為了再建置一個完整的溫度測量單元，還需要購買多少個感測器。

請實作`Temperature#number_missing_sensors`方法，它接受一個引數`number_of_sensors`，並回傳缺少的感測器數量。

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
