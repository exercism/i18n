# 簡介

在 Go 裡，每個變數都有值。
宣告變數時如果沒有指定值，就會把它設成該型別的零值。

基本型別，包括 `bool`、數字型別和 `string`，都有固定的零值：

| 型別                   | 零值       |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64 等    | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

指標、函式、介面、切片、通道和映射的零值都是 `nil`。

陣列和 struct 永遠不會是 `nil`，因為它們直接存放資料，而不是存放資料的參考。
陣列的每個元素，以及 struct 的每個欄位，都會初始化為自己所屬型別的零值。
例如，`var a [3]int` 會建立陣列 `[0, 0, 0]`。

## 宣告零值

用 `var` 來宣告變數：

```go
var myBool bool   // false
var mySlice []int // nil
```

用複合字面值 `T{}` 來建立 struct：

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
