# 提示

這些任務全都會用到`print`指令：
```awk
{print "something", "something else"}
```

## 1. 列出使用者名稱

* 使用[`FS`變數][var-fs]來定義欄位分隔符。

## 2. 印出行號

* 使用[內建變數`NR`][var-nr]來取得行號。

## 3. 印出家目錄無效的記錄。

* 家目錄是第 6 個欄位。
* 使用提供的`startsWith`函式。
* 使用[布林運算子][boolean-ops]：`&&`、`||`、`!`。

## 4. 印出使用 bash 的有效使用者數量

* 登入 shell 是最後一個欄位，你可以使用[`NF`變數][var-nf]。
