# 關於

Ruby 是一門動態且強型別的語言。
在動態語言中，變數或物件的型別是在執行階段才決定的，這代表它的值或型別可以一路改變到最後一刻（也就是被翻譯員剖析的時候）。
那強型別又是什麼意思呢？
一旦我們知道變數或物件的型別，Ruby 就會嚴格限制你能對它做什麼，例如：

```ruby
x = '2'
y = x + 'n'
# => '2n'
```

**但是**

```ruby
x = '2'
y = x + 2
# => TypeError (no implicit conversion of Integer into String)
```

記住，在 Ruby 裡，一切都是物件。
就連類別本身也是`Class`類別的實例。

例如：

```ruby
1.class
# => Integer

Integer.is_a?(Object)
# => true

Class.is_a?(Object)
# => true
```

這代表我們也可以像這樣定義類別：

```ruby
Car = Class.new do
  def run
    'running'
  end
end

Car.new.run
# => 'running'
```

最後，請記住，`Integer`物件所持有的值可以是一個或多個（連續的）數字，而它的方法支援許多[數學運算子][integers-docs]。

[integers-docs]: https://docs.ruby-lang.org/en/master/Integer.html

~~~~exercism/note
文件裡經常會用像`Class#method_name`這樣的語法來指涉實例方法，而類別或模組層級的方法則寫成`Class::method_name`。
`::`稱為*作用域解析運算子*，用來指涉類別或模組層級的常數或方法。
你會在 Ruby 的文件、郵件論壇以及其他支援管道中看到這種寫法。
你會發現，我們在撰寫內容時反而會用`ClassName.method_name`或`ModuleName.method_name`來表示類別與模組方法。
~~~~
