# 簡介

Common Lisp 中的符號是特殊的值，可以指向其他值；就_關鍵字_而言，則是指向它們自己。
當 Lisp 對符號求值時，會把符號換成它所指向的值：

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

請注意，關鍵字會以開頭的冒號（`:`）標示。

引用，也就是在 S-expression 前加上`'`，會告訴 Lisp 不要對該運算式求值。
在我們的 `defun` 範例中引用 `'foo`，就能避免 Lisp 試著尋找（卻找不到）`FOO` 原本該指向的東西，而是直接回傳 `FOO` 這個值本身。
如果 `FOO` 在我們的程式中沒有在任何地方定義過：

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

目前你可以把它想成一種從函式回傳符號的方式，不過我們之後會再回來看引用，並在未來的概念練習中進一步探討它的影響。
