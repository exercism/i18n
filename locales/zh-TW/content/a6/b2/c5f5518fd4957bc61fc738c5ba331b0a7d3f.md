# 簡介

## 真值與假值

在 Common Lisp 中，所有值都是 "true"，只有`()`是 "false"。
有兩個特殊的常數符號`t`和`nil`，它們的值分別是 true 和 false。

## 條件式

Common Lisp 提供了幾種不同的條件運算式，主要的差別在於它們支援的分支數量。

- `when`和`unless`允許使用單一分支：

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

測試運算式之後可以有多個運算式。

- `if`提供經典的 if-then-else 結構：

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

請注意，then 和 else 子句都只能是一個運算式。

- `cond`提供了多分支的寫法，不需要巢狀`if`運算式：

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

請注意，測試運算式之後的運算式數量沒有限制。 

- `case`提供經典的「switch」風格結構，它會用單一值比對多個分支：

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

請注意，和`cond`一樣，測試運算式之後的運算式數量沒有限制。
