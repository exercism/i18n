# 簡介

## 標籤欄位

當自訂型別的變體帶有資料時，就稱為記錄，其中所含的每個值都存放在一個_欄位_裡。

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

為了提升可讀性，Gleam 允許替欄位標上名稱。

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

標籤可以用來以任意順序把引數傳給記錄的建構子。

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

當自訂型別只有一個變體時，就能用`.label`存取子語法取得記錄的欄位。

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

當自訂型別只有單一變體時，可以使用記錄更新語法，從既有的記錄建立新的記錄，並把其中部分欄位換成新的值。

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

標籤也可以在模式匹配時使用，從記錄中取出值。

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

如果只想匹配其中幾個欄位，可以用展開運算子`..`忽略其餘欄位。

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
