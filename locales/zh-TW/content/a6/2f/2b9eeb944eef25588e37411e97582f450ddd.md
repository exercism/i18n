# 關於

Gleam 可以在 Erlang 虛擬機器（BEAM）上執行，也可以在 JavaScript 執行環境上執行。還有許多其他語言也使用這些執行環境，而能夠從 Gleam 呼叫以這些語言撰寫的程式碼，通常很實用。

Gleam 的*外部函式*功能可讓其他語言的函式匯入 Gleam，並在呼叫時不會有執行期額外負擔。

如果你的 Gleam 專案在 Erlang 虛擬機器上執行，而你希望從 Erlang 的`lists`模組呼叫`reverse`函式，可以像這樣在 Gleam 函式標頭加上`@external`屬性：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

接著就能像一般 Gleam 函式一樣呼叫它：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

如果你嘗試為 JavaScript 執行環境編譯這段程式碼，會因為沒有 JavaScript 的實作而失敗，並顯示錯誤訊息。可以像這樣為 JavaScript 執行環境指定另一個實作：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

也可以撰寫一個 Gleam 實作，當目前編譯目標沒有外部實作時就會使用它：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
