# 簡介

Haxe 中的屬性是一個類別的成員，可提供對該類別內資料的存取。呼叫端可以設定或取得（get）這些資料。屬性由 set 存取子和／或 get 存取子組成。

屬性和其他類別成員一樣，具有存取修飾詞（public、private 等），但 set 存取子的存取層級可以和 get 存取子不同，反之亦然。屬性不一定要同時具備兩個存取子，也可以只有其中一個（get 或 set）。

讀取權限和寫入權限會直接反映在語法上，如下例所示：

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default`和`null`都是特殊的**存取識別字**。存取識別字會決定欄位被讀取時（第一個識別字）以及被寫入時（第二個識別字）的行為。可接受的值有：

- `default`：若欄位是 public，則允許一般的欄位存取。
- `null`：僅允許從定義該欄位的類別內部存取。
- `get/set`：存取會以呼叫存取子方法（`get_x()`）的方式產生。
- `dynamic`：和`get/set`相同，但無法驗證存取子方法是否存在。
- `never`：完全不允許任何存取。

以下是完整的範例：

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
