# 簡介

## Attribute

[C# 的 `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) 提供了一種裝飾宣告的方式，用來將中繼資料關聯到類別、方法、列舉、欄位、屬性，或任何[其他支援的](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets)宣告。

你可以將 `ClassAttribute` 和 `FieldAttribute` 加在宣告的上一行來套用 Attribute：

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

這種宣告式中繼資料只是為程式碼關聯額外的結構化資訊，並不會改變它的行為；不過程式碼的其他部分會利用這些中繼資料，來改變目標的行為，或新增、變更、移除、限制它的某些功能。

有許多[預先定義和保留的 Attribute](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)，例如：`Flags`、`Obsolete`、`Conditional` 和 `Experimental`。每一個都有特定的語意，可以查閱 C# 文件來了解。請注意，像 [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) 這樣的 Attribute，完整名稱會採用 `<Name>Attribute` 的形式（例如 `FlagsAttribute`）。

## 旗標列舉

C# 的[`enum` 型別](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)代表一組固定的具名常數（也就是列舉）。

一般來說，一個 `enum` 成員只能代表其中一個具名常數。不過有時候，我們會需要同時代表多個常數，這時就可以用 [`Flags` Attribute](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) 來標註 `enum`。

旗標列舉可以這樣定義（使用二進位整數表示法`0b`）：

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

一個值為 `0b00000011` 的 `PhoneFeatures` 執行個體，會同時設定 `Call` _和_ `Text` 兩個旗標。

預設情況下，列舉成員的值會使用 `int` 型別。只要在列舉宣告中指定型別，就能改用其他整數型別：

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
