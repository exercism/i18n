# 關於

許多[結構與類別的成員型別][expression-bodied-members]（欄位是主要的例外）都能使用運算式主體成員語法。用運算式來定義成員，通常會比傳統的區塊或敘述寫出更精簡、更好讀的程式碼。

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

運算式主體成員不能包含由多個敘述組成的區塊，但有函式程式設計背景的人要留意：傳統成員能做的事，用這類成員都做得到。這裡的「運算式」可以是一個產生副作用的指定運算，也可以是一個方法呼叫，也就是說，什麼事都有可能發生。

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
