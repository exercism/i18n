# 提示

## 一般

- 每天的鳥隻數量會儲存在名為`birdsPerDay`的欄位中。
- 每天的鳥隻數量是一個陣列，裡面正好包含 7 個整數。

## 1. 檢查上週的數量

- 既然我們保留了上週的資料，只需要回傳上週的值就行了。

## 2. 檢查今天有多少隻鳥來訪

- 請記得，這些數量是按日期從最舊到最新排序的，最後一個元素代表今天。
- 要取得最後一個元素，可以使用它（固定）的索引（記得從零開始算），或是利用陣列的大小來計算它的索引。

## 3. 將今天的數量加一

- 把代表今天數量的元素設成今天的數量加 1。

## 4. 檢查是否有哪一天沒有鳥來訪

- 可以使用`for`迴圈來疊代陣列。
- 另一個解法是使用 Java Stream API。

## 5. 計算前幾天來訪鳥隻的數量

- 可以使用一個變數來保存來訪鳥隻的數量。
- 可以使用`for`迴圈來疊代陣列。
- 變數可以在迴圈內更新。
- 請記得：陣列的索引從`0`開始。

## 6. 計算忙碌的天數

- 可以使用一個變數來保存忙碌的天數。
- 可以使用`foreach`迴圈來疊代陣列。
- 變數可以在迴圈內更新。
- 可以在迴圈內使用條件敘述。
