# 簡介

列舉型別是一種特殊的資料型別，可以讓變數的值是為它預先定義好的一組常數。
變數必須等於其中一個預先定義好的值。
常見的例子包括指南針方向（`NORTH`、`SOUTH`、`EAST`和`WEST`這些值）以及一週中的每一天。

因為它們是常數，所以列舉型別欄位的名稱會使用大寫字母。

## 定義列舉型別

在 Java 程式語言中，你可以使用`enum`關鍵字來定義列舉型別。
例如，你可以這樣定義一個一週中每一天的列舉型別：

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

每當你需要表示一組固定的常數時，就應該使用列舉型別。
這包括像是太陽系行星這類自然的列舉型別，以及你在編譯時期就知道所有可能值的資料集，例如選單上的選項、命令列旗標等等。

## 使用列舉型別

以下程式碼示範如何使用上面定義的`DayOfWeek`列舉：

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## 新增方法與欄位

Java 程式語言的列舉型別比其他語言中對應的型別強大得多。
`enum`宣告會定義一個類別（稱為列舉型別）。
列舉類別的主體可以包含方法和其他欄位：

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

對`Rating`列舉型別的成員呼叫`getNumberOfStars`方法：

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
