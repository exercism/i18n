# Haskell 內建數值型別

## 數字

Haskell 的標準函式庫又稱 ***Prelude***，它定義了大多數基本的數值型別：固定大小的整數（`Int`）、任意精度的整數（`Integer`）、單精度浮點數（`Float`），以及雙精度浮點數（`Double`）。
其他數值型別，例如有理數和複數，則定義在額外的函式庫中。

`Integer` 可以容納任何數字，無論多大，只受限於你機器的記憶體，而 `Int` 對應的是能以 32 或 64 位元表示的正負整數集合（保證至少有 -2^29 到 2^29）。

`Float` 對應實數的集合，但受電腦精度所限。
定義在數字上的運算通常只適用於其中一種型別，而不是兩者通用。

在 `Float` 與 `Integer` 之間轉換的函式，其中包括 `toFloat`，它將 `Int`/`Integer` 轉換成 `Float`，以及 `ceiling`，它將 `Float` 轉換成 `Int`。

## 算術運算子

Haskell 有三個「次方」運算子，它們的運作方式不同，接受的引數型別也不同。

- `**` 接受兩個**浮點數**，並使用對數來計算次方。
- `^^` 接受一個**浮點數**，並將它提升到正或負**整數**次方。
- `^` 接受**任何數值型別**，並將它提升到**正整數**次方。

從整數型別（`Int` 或 `Integer`）轉換成任何其他數值型別，是使用函式 `fromIntegral` 完成的。
目標型別會自動推斷出來。
例如：

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```

整數的除法稍微複雜一些。
如果你對整數使用一般的 `/` 運算子，就會得到錯誤訊息（不過運算式 `4/3` 確實能運作，因為 Haskell 會在需要時貼心地把整數字面值提升成浮點數）。
整數除法改用一組具名運算子來完成。

Haskell 對運算子有個巧妙的手法：任何接受兩個引數的函式，只要用反引號把名稱包起來，就能當作運算子使用。
所以下面這兩行的意思完全相同：

```haskell
 d = 7 `div` 3
 d = div 7 3
```

了解了這一點之後，以下是整數除法的運算子：

- `quot`：回傳兩數的商。
  這是除法結果截斷至零的方向。
- `rem`：回傳商的餘數。
- `div`：類似 `quot`，但會向下取整至負無限大。
- `mod`：回傳兩數的模。
  這與 `rem` 類似，但當 `div` 回傳負數時，規則不同。

就如同你可以把接受兩個引數的函式轉成運算子，你也可以把運算子放進括號，將它轉成接受兩個引數的函式。
所以下面這兩行的意思相同：

```haskell
(+) 3 4
3 + 4
```
