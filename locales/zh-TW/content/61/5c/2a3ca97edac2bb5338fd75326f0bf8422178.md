# 指令

在這個練習中，我們會模擬一局 [Blackjack][blackjack] 遊戲的第一回合。

## 1. 計算任一張牌的值。

你會拿到兩張牌，並且能看到莊家的明牌。
所有牌都以字串表示，例如「ace」、「king」、「three」、「two」等等。
每張牌的值如下：

| 牌  | 值 |  牌   | 值 |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
一般來說，ace 可以取 1 或 11 的值，但為了簡化，我們假設 ace 只能取 11 的值。
~~~~

實作`Blackjack.parse_card`方法，它會接受一張牌作為字串引數。
這個方法應該以整數回傳該張牌的值。

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. 為值範圍命名。

玩家的分數必須被歸類到不同的值範圍中。
玩家的分數是將兩張玩家牌的值相加而得。
所使用的範圍如下：

|   範圍    |   值   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

實作`Blackjack.card_range`方法，它會接受兩張牌作為字串引數。
這個方法應該回傳這兩張牌所屬的值範圍名稱。

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. 實作第一回合的決策邏輯。

根據你的兩張牌和莊家的牌，遊戲的第一回合有一套策略，你有以下選項：

- 停牌（S）
- 要牌（H）
- 分牌（P）
- 自動獲勝（W）

雖然還不是最佳策略，但你要遵循你朋友 Alex 一直在開發的策略，內容如下：

- 如果你有一對 ace，就一定要分牌。
- 如果你有 Blackjack（兩張牌加起來的值為 21），而莊家沒有 ace、人頭牌或 ten，你就會自動獲勝。
  如果莊家有其中任何一張牌，你就得停牌，等待另一張牌揭曉。
- 如果你的牌加起來的值落在 [17, 20] 這個範圍內，你就應該總是停牌。
- 如果你的牌加起來的值落在 [12, 16] 這個範圍內，你應該總是停牌，除非莊家有 7 或更高，這種情況你就應該總是要牌。
- 如果你的牌加起來是 11 或更低，你就應該總是要牌。

實作`Blackjack.first_turn`方法，它會接受三張牌作為字串引數。
這個方法應該以字串回傳你應該採取的決策。

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
