# 說明

瑪麗是電視影集 _Star Trek: The Next Generation_ 的超級粉絲。
她經常玩紙筆角色扮演遊戲，在遊戲中她和朋友們假扮成 _Starship Enterprise_ 的船員。
瑪麗的角色是 Picard 艦長，這表示她得負責記錄艦長日誌。
她喜歡遊戲中發揮創意的部分，但不喜歡臨時隨機產生資料。

~~~~exercism/note
這道練習的起始實作以`java.util.Random`實例作為建構子參數。
這讓這道練習的測試能傳入帶有預先定義隨機種子的實例，使測試結果可以預測。

因此，你的實作應該使用提供的`java.util.Random`實例。
~~~~

## 1. 隨機產生一顆行星

_Starship Enterprise_ 在航行途中會遇到許多行星。
Star Trek 宇宙中的行星會依其特性分成不同類別。
例如地球是 `M` 級行星。
所有可能的行星等級有：`D`、`H`、`J`、`K`、`L`、`M`、`N`、`R`、`T` 和 `Y`。

實作`randomPlanetClass()`方法。
它應該隨機回傳其中一個行星等級。

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. 隨機產生星艦註冊編號

Enterprise（註冊編號`NCC-1701`）可不是唯一在宇宙中飛行的星艦！
當它與其他星艦會合時，瑪麗需要記錄那艘星艦的註冊編號。

註冊編號以「NCC-」開頭，後面接著`1000`到`9999`（含）之間的數字。

實作`randomShipRegistryNumber()`方法，讓它回傳隨機的星艦註冊編號。

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. 隨機產生星曆

如果日誌裡沒有日期，那還有什麼用呢？

星曆是一個浮點數。
_Starship Enterprise_ 在 _The Next Generation_ 第一季的冒險，發生在星曆`41000.0`到`42000.0`之間。
「4」代表 24 世紀，「1」代表第一季。

實作`randomStardate()`方法，讓它回傳`41000.0`（含）到`42000.0`（不含）之間的浮點數。

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
