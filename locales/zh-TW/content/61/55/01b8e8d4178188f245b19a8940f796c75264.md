# Alias

[特殊形式`alias`][alias]可以讓你縮短或更改參照外部模組時所用的名稱。自訂名稱可以用`:as`選項指定。

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

不使用任何引數時，它會把模組名稱縮減到最後一個部分，例如：

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

多個`alias`可以用`{}`群組在一起：

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

通常`alias`會加在模組定義的開頭，但也可以加在任何地方。它們具有詞法作用域，這表示加在某個函式定義內的`alias`，在另一個函式中無法使用。

未使用的`alias`會造成編譯器警告。

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
