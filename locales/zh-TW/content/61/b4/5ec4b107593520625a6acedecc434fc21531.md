# 指令

在這個練習中，你要和朋友玩一場猜數字遊戲。
規則很簡單：你偷偷選一個`1`到`100`之間的數字，你的朋友試著猜出你選了哪個數字。
為了幫助你的朋友，你要根據猜測的數字與你選的數字（`42`）有多接近，給出不同的回應。
以下是各種可能輸入的規則：

- 如果猜測的數字是`42`："Correct"
- 如果猜測的數字是`41`或`43`："So close"
- 如果猜測的數字小於`41`："Too low"
- 如果猜測的數字大於`43`："Too high"

你有四個任務，要為這些猜測編寫對應的回覆。

## 1. 回覆猜對的情況

實作`reply`函式，讓它能回覆猜對的情況：

```haskell
reply 42
-- -> "Correct"
```

## 2. 回覆很接近的猜測

修改`reply`函式，讓它也能回覆很接近的猜測：

```haskell
reply 41
-- -> "So close"
```

## 3. 回覆猜得太低的情況

修改`reply`函式，讓它也能回覆猜得太低的情況：

```haskell
reply 25
-- -> "Too low"
```

## 4. 回覆猜得太高的情況

修改`reply`函式，讓它也能回覆猜得太高的情況：

```haskell
reply 88
-- -> "Too high"
```
