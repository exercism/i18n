# 說明

有一間製造商可以生產兩種不同類型的馬達，以下分別稱為馬達 A 與馬達 B。這兩種馬達的生產都需要經過 3 個階段：配線、鑽孔與組裝。每個馬達在這些生產階段所需的時間各不相同。一般來說，生產一單位馬達 A 需要 t_a_1 小時配線、t_a_2 小時鑽孔，以及 t_a_3 小時組裝；另一方面，生產一單位馬達 B 則需要 t_b_1 小時配線、t_b_2 小時鑽孔，以及 t_b_3 小時組裝。請實作一個函式：給定分配給每個生產階段的總時數（配線 t_1 小時、鑽孔 t_2 小時、組裝 t_3 小時）以及各類型馬達的價格（p_a、p_b），計算出能讓利潤最大化的馬達 A 與馬達 B 最佳產量。

這個函式總共會有 4 個輸入參數，說明如下：
1. a_hours：（t_a_1, t_a_2, t_a_3）三元組，單位為小時
2. b_hours：（t_b_1, t_b_2, t_b_3）三元組，單位為小時
3. total_hours：（t_1, t_2, t_3）三元組，單位為小時
4. prices：（p_a, p_b）二元組，單位為美元

輸出應該是一個三元組（q_a, q_b, profit），其中：
1. q_a：馬達 A 的最佳生產數量
2. q_b：馬達 B 的最佳生產數量
3. profit：最大化的利潤值，單位為美元

其它需要注意的重點：q_a 與 q_b 不能是浮點數，因為無法生產分數個馬達。Z3 模型算出的變數結果在輸出前必須先轉成整數。如果 Z3 模型的結果型別是 `IntNumRef`，可以使用 `as_long()` 這個類別方法將它轉成整數。如果問題因為輸入不合法而無法滿足，請拋出 Python 內建的 `ArithmeticError()` 例外。
