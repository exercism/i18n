# 指令

你將要寫一些程式碼，來管理一份你想學習的程式語言陣列。
這個陣列叫做`@LanguageList::Languages`。

## 1. 新增語言到 @Languages 陣列

修改`LanguageList::add_language`副程式，它會接受一個語言名稱作為引數，把該語言加到`@LanguageList::Languages`陣列的尾端。

## 2. 從 @Languages 陣列移除語言

修改`LanguageList::remove_language`副程式，從`@LanguageList::Languages`陣列中移除最後一個語言。

## 3. 從 @Languages 陣列取得第一個語言

修改`LanguageList::first_language`副程式，讓它回傳`@LanguageList::Languages`陣列中的第一個語言。

## 4. 從 @Languages 陣列取得最後一個語言

修改`LanguageList::last_language`副程式，讓它回傳`@LanguageList::Languages`陣列中的最後一個語言。

## 5. 從 @Languages 陣列取得一段切片

修改`LanguageList::get_languages`副程式，它會接受一組數字，代表想要的元素，並回傳`@LanguageList::Languages`陣列的切片。

## 6. 檢查 @Languages 陣列中是否有某個語言

修改`LanguageList::has_language`副程式，它會接受一個語言名稱作為引數，回傳 true 或 false 值，表示該語言是否存在於`@LanguageList::Languages`陣列中。
