# 簡介

Lambda 類別集結了許多函式方法，讓我們能在 Haxe 中使用函式風格的程式設計。它讓我們能一次操作整個 Iterable。比起寫迴圈，這種做法通常更理想，因為比較不容易出錯，也更容易閱讀。為了方便起見，Array 和 List 類別也包含了一些 Lambda 類別中常用的方法。

`Lambda` 類別的部分函式包括：

- `Lambda.array`、`Lambda.list`：將 Iterable 轉換成 Array 或 List。它一律回傳新的實例。
- `Lambda.count`：計算元素的數量。如果 Iterable 是 Array 或 List，使用它的 length 屬性會更快。
- `Lambda.has`：判斷指定的元素是否在 Iterable 中。
- `Lambda.indexOf`：找出指定元素的索引。
- `Lambda.find`：找出符合指定搜尋函式的第一個元素。
- `Lambda.concat`：合併兩個 Iterable，並回傳一個新的 List。
- `Lambda.filter`：找出符合條件的元素，並回傳一個新的 List。

以下範例示範了幾個函式：

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
