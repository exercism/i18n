# 指令

將以某個基數的一連串數字表示的數字，轉換成任何其他基數。

請實作通用的基數轉換。給定一個以基數**a**表示、由一連串數字組成的數字，將它轉換成基數**b**。

## 注意

- 試著自己實作這個轉換吧。
  不要使用其他工具來替你完成轉換。

## 關於[位值記法](https://en.wikipedia.org/wiki/Positional_notation)

在位值記法中，以基數**b**表示的數字，可以理解為**b**的次方所構成的線性組合。

數字 42，*以 10 為基數*，代表：

(4 * 10^1) + (2 * 10^0)

數字 101010，*以 2 為基數*，代表：

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

數字 1120，*以 3 為基數*，代表：

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

*沒錯，上面這三個數字完全相同。恭喜！*
