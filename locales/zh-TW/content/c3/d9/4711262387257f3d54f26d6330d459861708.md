# 陣列

**陣列**會依序存放一整排型別相同的值。

型別寫作 `ARRAY{T}`，其中 `T` 是它存放的內容。字串陣列是 `ARRAY{STR}`；整數陣列是 `ARRAY{INT}`。

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

兩個 `|` 符號之間的值就是**陣列字面值**。Sather 會根據值的數量推算大小。

## 取出值

中括號裡放的是位置：

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

計數從 **0** 開始，不是 1。所以第一個值在 `0`，而三個值當中的最後一個在 `2`。

## 有幾個？

`.size` 表示陣列存放了幾個值。

```sather
row.size    -- 3
```

因為計數從 0 開始，最後一個位置永遠是 `.size - 1`：

```sather
row[row.size - 1]     -- "Ben"
```

要求一個不存在的位置，例如 `row[3]` 或 `row[-1]`，是 Sather 不會幫你抓到的錯誤，所以值得寫 `.size - 1`，而不是用眼睛數。

## 逐一走訪

陣列和迴圈是一對的。用一個變數逐一數過每個位置，再用它取得每個值：

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
