# 整數

整數是不含小數的數字，它們屬於集合`{..., -2, -1, 0, 1, 2, ...}`。
整數的最大值和最小值取決於 PHP 執行的系統。
在大多數現代系統上，整數通常是 64 位元的值，也就是說它可以表示從`-9_223_372_036_854_775_808`到`9_223_372_036_854_775_807`（含）的範圍。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

你可以使用進位前綴，用 10 進位以外的進位來書寫整數字面值：

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
