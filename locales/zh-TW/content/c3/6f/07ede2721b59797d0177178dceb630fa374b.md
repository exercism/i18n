# 安裝

## 安裝 Clojure CLI
Clojure 提供命令列工具，可用來啟動 Clojure REPL、使用 Clojure 和 Java 函式庫，以及啟動 Clojure 程式。

如果你需要安裝 Java，我們推薦 [Adoptium Temurin 17](https://adoptium.net/)。

### Linux
請確認已安裝以下相依項目：`bash`、`curl`、`rlwrap` 和 `Java`。
你可以用以下 2 種方式的任一種安裝 Clojure：

1. LinuxBrew：需要 [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. 安裝腳本

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Mac OS X 的 Homebrew
使用 brew 從 [clojure/tools](https://github.com/clojure/homebrew-tools) tap 安裝命令列工具：

```bash
brew install clojure/tools/clojure
```

#### Java

任何 Java 發行版都可以。如有需要，你可以用 brew 安裝 Temurin：

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Windows 上的 Clojure 最近有顯著的改善。我們以前建議使用 WSL2，它運作得很好，但現在有 PowerShell 安裝程式。Windows 上的 Clojure 目前處於 alpha 階段，已知問題請參閱 [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues)。

請確認已安裝 Java，並已設定 `JAVA_HOME` 環境變數，然後執行：

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

在 Windows 上安裝 Clojure 的另一種方式是使用 [Scoop](https://scoop.sh/) 套件管理器。要安裝 Scoop，請開啟 PowerShell 並依序執行以下 2 個命令：

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

要用 Scoop 安裝 Clojure，你必須先加入兩個重要的 bucket：

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

現在我們可以執行下列命令來安裝 Java 和 Clojure：

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

成功執行上述步驟後，你應該就能用以下方式執行 Clojure：

```sh
clj
```

## 安裝 Leiningen（選用）

雖然已不再必要，我們仍然支援功能完整的專案管理工具 [Leiningen](https://leiningen.org/)。它提供各式各樣實用的工作，例如方便的測試、建置，以及改良的 REPL。

1. 下載 [lein script](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) 或 [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat)（Windows）
2. 將它放到你的 `$PATH` 中，讓你的 shell 能找到它（例如`/usr/local/bin/`）
3. 將它設為可執行（`sudo chmod a+x /usr/local/bin/lein`）
4. 執行 `lein`。
