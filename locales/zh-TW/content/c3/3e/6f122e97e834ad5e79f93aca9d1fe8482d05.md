# 佔位符

## `jq` 小技巧

這個練習要拿一個輸入物件，把它轉換成一個新的物件。
有幾個內建函式可能幫得上忙：

- [`to_entries`][x_entries]
  - 這個函式會接受一個物件作為輸入
  - 它會輸出一個_陣列_，每個陣列元素都是一個物件 `{"key": "K", "value": V}`
    - 每個 `K` 都是輸入物件裡的一個鍵
    - 每個 `V` 都是 `K` 對應的值。
- [`from_entries`][x_entries]
  - 反向的操作
  - 接受一個由 `{"key": K, "value": V}` 物件組成的陣列，並建構出一個物件

例如：

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

會輸出

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
