# 說明

在這道練習中，你會寫程式碼，幫助自己照著最愛的食譜做出美味的千層麵。

你有四個任務，全都和烹煮千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

在`Lasagna`類別中定義`EXPECTED_MINUTES_IN_OVEN`常數，用來儲存千層麵應該在烤箱中待幾分鐘。
根據食譜，預期的烤箱時間是 40 分鐘：

```Crystal
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`Lasagna#remaining_minutes_in_oven`方法，它接受千層麵實際待在烤箱中的分鐘數作為參數，並根據上一個任務的預期烤箱時間，回傳千層麵還需要在烤箱中待幾分鐘。

```Crystal
Lasagna.new.remaining_minutes_in_oven(30)
# => 10
```

## 3. 計算準備時間（分鐘）

定義`Lasagna#preparation_time_in_minutes`方法，它接受你加在千層麵中的層數作為參數，並回傳你花在準備上的分鐘數，假設每一層需要 2 分鐘準備。

```Crystal
Lasagna.new.preparation_time_in_minutes(2)
# => 4
```

## 4. 計算總工作時間（分鐘）

定義`Lasagna#total_time_in_minutes`方法，它接受兩個具名參數：`number_of_layers`參數是你加在千層麵中的層數，而`actual_minutes_in_oven`參數是千層麵待在烤箱中的分鐘數。
這個方法應該回傳你烹煮千層麵所花費的總分鐘數，也就是準備時間的分鐘數，加上千層麵目前為止待在烤箱中的時間。

```Crystal
number_of_layers = 3
actual_minutes_in_oven = 20
Lasagna.new.total_time_in_minutes(number_of_layers, actual_minutes_in_oven)
# => 26
```
