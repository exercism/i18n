# 簡介

大多數時候，Factor 會透過 `each`、`map` 和 `count` 這類組合子來處理疊代。不過有時候，描述一段運算最簡潔的方式是**遞迴**，也就是一個會呼叫自己的詞。

## 定義遞迴的詞

一個 `:` 定義可以直接呼叫自己：

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## 判斷序列是否為空的分支

`if-empty`（在 [`sequences`][sequences] 中）是最自然的遞迴基本情況：

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

執行`emptyquot`時，序列（此時已空）已經被消耗；執行`nonemptyquot`時，序列還留在堆疊上。

## `cond`：一連串帶有條件的分支

當你的遞迴超過兩種情況時，`cond`（在 [`combinators`][combinators] 中）能讓程式碼保持易讀：

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## 用 `DEFER:` 做前向引用

一個 `:` 定義可以直接呼叫自己，但當兩個詞互相呼叫時，解析器在看到第二個詞之前，就已經先看到第一個詞了。`DEFER:` 會先保留一個名稱，讓第一個定義能順利編譯：

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

當某個輔助詞讀起來最自然的位置，是在使用它的那個詞*之後*時，`DEFER:` 也同樣好用。
