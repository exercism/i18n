# 簡介

Flags 屬性可以讓差別聯合中定義的值以位元位置（也就是旗標）來表示。
做為旗標，這些值可以合併使用，因此多個布林條件能夠用單一個值來表示。

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

設定旗標可以使用位元 OR 運算子（`|||`）；取消旗標則可以結合位元 AND 運算子（`&&&`）與位元否定運算子（`~~~`）。
檢查旗標狀態可以用位元 AND 運算子，也可以使用 `HasFlag()` 方法。

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

關於 F# 語言中所有可用的位元運算子，請參閱[位元運算子的摘要][bitwise-operators]。
