# 指令

你的朋友 Leticia 在捷運站的失物招領處工作。

每件被撿到的物品，都會在當天的物品清單裡新增成一筆條目。
到了月底，所有沒被領回的物品都會被移到一個箱子裡存放，箱子上標著找到它的日期。
這些事全都靠紙本記錄，所以有時候會變得棘手！

~~~~exercism/note
以下是這個概念中介紹的指令：

| 指令     | 說明                                                     |
|----------|----------------------------------------------------------|
| push a   | 把 a 推入堆疊，並將 `rsp` 減少 a 的大小                  |
| pop a    | 從堆疊取出 a，並將 `rsp` 增加 a 的大小                   |
~~~~

## 1. 為每個物品建立條目

你要做的第一件事，是把所有物品整理好，之後查詢起來會更方便。
每件物品在存放時，會用它的 ID、描述、找到的日期，以及數量不固定的分類來辨識。

定義一個函式`create_item_entry`，它沒有回傳值，會在某個記憶體位置插入一筆物品條目。
這個函式可以接受任意數量的參數，其中前六個一律是：

1. 用來存放這筆條目的記憶體位置位址。
2. 物品的 ID，為 64 位元無號整數。
3. 裝有物品描述的字串位址。
4. 找到物品的日子，為 64 位元無號整數。
5. 找到物品的月份，為 64 位元無號整數。
6. 物品的分類數量，為 64 位元無號整數。

之後的每個參數，則是其中一個分類字串的位址。

這些值應該依照引數的順序，存放在指定的記憶體位置：ID、描述、日、月、分類數量，接著再依序存放每個分類。

## 2. 為每月的物品清單保留空間

要在這麼多不同的清單裡尋找物品，實在很麻煩。
所以，你決定把每個月的東西都整理成單一清單。
這個清單是用陣列實作的。

定義`create_monthly_list`函式，它會在記憶體中為陣列配置空間，並回傳該記憶體位置的位址。
它的參數有：

1. 陣列的容量，以位元組為單位，為 64 位元無號整數。
2. 一個配置函式。

配置函式會接受一個 64 位元無號整數作為參數，代表要配置的記憶體大小（以位元組為單位），並回傳配置到的空間位址。

請注意，配置到的空間值是_未定義_的，所以應該清除該空間中的所有位元組，也就是把它們的值設為`0`。

## 3. 將物品插入每月清單

每天找到的物品都應該插入每月清單中。

定義`insert_found_item`函式，它沒有回傳值，參數有：

1. 每月清單所在之記憶體空間的位址。
2. 清單中目前已存放的條目數量，為 64 位元無號整數。
3. 要加入清單的新條目。

你可以假設新條目一定能放進清單，而且清單中每個條目都佔用 120 位元組的空間。

## 4. 列印物品

如果 Leticia 能看到條目印在螢幕上，要找特定的一筆就會容易得多。

定義`print_item`函式，參數有：

1. 用來存放開頭那串以 ASCII NUL 結尾之字串的緩衝區位址。
2. 每月清單所在之記憶體空間的位址。
3. 要列印的物品條目在陣列中的索引，為 64 位元無號整數。
4. 一個列印函式。

這個函式沒有回傳值，而且應該以下列引數呼叫列印函式：

1. 存放開頭字串的記憶體位置位址；如果沒有傳入字串，則為`0`（以 64 位元整數表示）。
2. 要列印的物品條目在陣列中的索引，為 64 位元無號整數。
3. 物品的 ID，為 64 位元無號整數。
4. 裝有物品描述的字串位址。
5. 找到物品的日子，為 64 位元無號整數。
6. 找到物品的月份，為 64 位元無號整數。
7. 物品的分類數量，為 64 位元無號整數。
8. 第一個分類字串的位址。

開頭字串是選用的。
如果列印函式會用到它，這個字串必須以 NUL 結尾（結尾為`0`），而且最多只能有 50 個字元，且已把 NUL 結束字元算在內。
否則，應該改為傳入`0`給列印函式。

你可以假設清單中每個條目都佔用 120 位元組的空間。
