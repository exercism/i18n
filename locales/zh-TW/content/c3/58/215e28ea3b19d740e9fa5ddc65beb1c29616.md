# 測試

## 執行測試

1. 取得練習：

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. 切換目錄到練習資料夾：

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. 執行測試：

    ```bash
    $ ./gradlew test
    ```

在多數練習中，預設只會執行第一個測試。  
其他測試都加上了 `@Ignore` 註解來略過。  
每解決一個測試，就移除下一個測試的 `@Ignore`，一步步往前進。

這是測試驅動開發（test-driven development，簡稱 TDD）的常見做法。
它能確保你一次只專注在一個問題上。
