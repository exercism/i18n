# 測試

## 重點摘要

- 前往練習目錄（例如`~/Exercism/hello-world`）。
- 在終端機中啟動`jconsole`工作階段。
- 載入你的解答檔案（例如`load 'hello-world.ijs'`）。
- 輸入`load  'general/unittest'`來載入單元測試框架。
- 輸入`unittest 'test.ijs'`來測試你的解答。
<br></br>
- 或者也可以用一行指令執行測試，像這樣：`jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`。

## Jconsole 工作階段

我們希望這個 track 的測試設定方式盡可能簡單。
如果你正在進行某個練習，例如`hamming.ijs`，以下是建議的工作流。
編輯`hamming.ijs`，寫出你的解答。
先輸入以下指令，以互動方式逐步建立。

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

接著在 J 主控台內輸入以下指令重新載入：

```j
load 'hamming.ijs'
```

下一步是載入單元測試框架，請輸入：

```j
load 'general/unittest'
```

載入你的解答後，要執行測試，請輸入：

```j
unittest 'test.ijs'
```

然後觀察結果。

## 命令列

你可以在終端機中使用 -js 旗標，以單行指令執行測試：

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
其中每個引數代表一個會依序執行的指令。
