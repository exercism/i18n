# 簡介

元組（tuple）是把一組固定數量、型別各異的資料集合在一起的輕量方式。
元組沒有特定的名稱；一旦為資料結構命名，它就變成了`struct`。
元組的欄位沒有名稱，只能透過解構或按位置來存取。

## 建立

元組一律以元組運算式建立：

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

元組可以有任意數量的元素。

## 以解構存取

我們可以透過解構來存取元組的元素。
這只是把變數名稱指定給元組中的個別元素，並同時消耗掉這個元組。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
