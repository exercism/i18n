# 測試

每個練習都包含一個測試檔案。
使用`bats`程式執行測試。
```bash
bats test-hello-world.bats
```

`bats`需要先安裝。
請參閱 [Bash 軌道的測試][bash] 頁面，了解如何為你的系統安裝`bats`。

### bats 是以 bash 實作的

bats 檔案是一份 bash 腳本，裡面有一些`bats`指令能辨識的特殊函式。
你會看到一些測試長得像這樣：
```sh
gawk -f some-exercise.awk <<< "some,input,here"
```
那個`<<<`語法是 bash 的 [Here String][here-string]。
它會把右邊的字串送進左邊程式的標準輸入。
它[大致上][so]等同於
```sh
echo "some,input,here" | gawk -f some-exercise.awk
```

## 斷言函式的說明

這些測試使用了 [bats-assert][bats-assert] 函式庫裡的函式。
各種`assert*`函式的說明都可以在那裡找到。

## 略過的測試

解完一個練習，代表你要讓它的所有測試都通過。
預設情況下，執行測試時只會執行一個測試（也就是第一個）。
這是刻意設計的，讓你專注在讓那一個測試通過就好。
一旦它通過了，你就可以註解掉或移除

    [[ $BATS_RUN_SKIPPED == true ]] || skip

這些加在其他測試前面的註解，來啟用下一個測試。

## 覆寫略過設定

想要執行所有測試，包括帶有`skip`註解的測試，可以執行：
```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

用一個包裝函式來省下打字功夫很方便：在`bash`裡可以這樣做：
```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```
之後只要輸入這樣就能執行測試：
```bash
bats
```

## 除錯輸出

```exercism/caution
這在本機搭配`bats`可以運作，但在 Exercism 線上編輯器裡**不行**。
```

執行測試時，`bats`會同時擷取標準輸出與標準錯誤，用來和預期的輸出比較。
如果你把除錯訊息印到標準輸出或標準錯誤，這些訊息會被納入擷取的輸出，可能導致測試失敗。

若想印出除錯資訊又不影響測試結果，`bats`為此提供了檔案描述符**3**。
任何印到`/dev/fd/3`這個檔案的內容，都會在測試執行時顯示，但不會被納入用來做斷言的擷取輸出中。

範例：

```awk
BEGIN {
    # This debug message will not interfere with test output comparison
    print "a debug message" > "/dev/fd/3"

    # Normal program output (this is what your tests will see and compare)
    print "Hello, World!"
}
```

執行範例：

```none
$ bats test-hello-world.bats
test-hello-world.bats
 ✓ Say Hi!
a debug message

1 test, 0 failures
```

這樣你就能看到有用的除錯訊息，又不會影響測試。

如果你在程式碼中好幾個地方都用到它，把這些細節藏進函式裡可以提升可讀性：

```awk
BEGIN {
    debug("starting ...")
}

# do stuff here ...

END {
    debug("... finished")
}

function debug(msg) {print msg > "/dev/fd/3"}
```
