# 測試

你可以在練習的目錄中執行下列指令來執行測試：

```bash
dub test
```

## 通過測試

依照[測試驅動開發的三個規則](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd)，讓第一個測試能編譯、連結並通過。只宣告剛剛好的命名空間、函式、類別等結構，足以讓編譯器不再報錯，並讓測試失敗就好。接著只寫剛剛好的程式碼，讓測試通過。完成之後，把下面這行移到下一個測試之後，即可取消註解下一個測試。

```D
static if (all_tests_enabled)
```

這可能會造成編譯錯誤，因為你可能會用到還沒宣告或定義的新結構。同樣地，用最少的修改修好編譯錯誤，讓測試失敗；再用最少的修改讓測試通過，接著重構你的實作，讓它更好讀、表達更清楚，然後繼續下一個測試。

盡量使用 D 的標準功能，而不是自己手寫低階的演算法或其他功能。
