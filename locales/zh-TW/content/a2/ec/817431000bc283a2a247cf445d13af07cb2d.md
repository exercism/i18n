# 關於

PowerShell 是 Microsoft 推出的動態、隱含型別的指令碼語言（_但也支援[強型別][strong typed]變數_），主要聚焦在任務自動化與設定管理。

PowerShell 支援命令式、函式式、物件導向，甚至管線風格的程式設計。

PowerShell 建構於 .NET 平台之上，並於 2006 年首次發行。
所有現代 Windows 作業系統都預設包含它，也可以安裝在 Mac 和 Linux 上。


## 變數

在 PowerShell 中，定義變數有兩種常見的方式。

PowerShell 的變數名稱必須以`$`開頭，並使用指定運算子`=`將變數名稱綁定到某個值。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

你也可以明確指定變數的型別，如果你想強制要求值必須是某種型別的話。
PowerShell 會盡可能嘗試把值從一種型別轉換成另一種。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### 常數

PowerShell 中的常數是定義之後就無法**變更**也無法**移除**的變數。
這帶我們來到定義變數的第二種方式：使用 Cmdlet `New-Variable`。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## 函式

PowerShell 中的函式使用 `function` 關鍵字定義。
每個函式可以在`()`括號中有零個或多個形式參數，接著是函式作用域，以`{`開始、以`}`結束。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell 的函式可以透過 `return` 關鍵字明確回傳值；呼叫時則是使用 `FuncName $Arg` 這樣的語法。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## 註解

PowerShell 的單行註解以`#`開頭，並在該行結束時結束。
PowerShell 的註解區塊以`<#`開頭，以`#>`結束。

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
