# 學習

## 從零開始學習 C

一般來說，Exercism 假設你已經熟悉某個軌道語言的語法與運作機制。不過，認識一門語言的語法，只是精通這門語言的第一步。Exercism 讓你練習解題，並和那些解過相同問題的程式設計師一起討論交流。正是在這樣的共同討論中，我們才得以累積專業能力，也更懂得如何成為更好的程式設計師。

如果你是完全剛接觸 C 語言的新手，應該先花點時間學習這門語言的基礎。以下幾個資源可以幫助你踏出第一步：

* [Learn C][]
* [CS50x][]

[CodeChef][] 是一個連到 C 編譯器的簡單網頁表單介面，讓你可以試跑一些小型程式。有時候，比起在本機的整合開發環境裡建置專案，這會是更快做個小實驗的方式。

## C 的測試驅動開發

Exercism 假設你已經熟悉測試驅動開發的概念。每道練習都附有一系列已經為你寫好的測試。你會一次通過一個測試地推進這道練習，逐步撰寫實作來滿足測試。

如果你剛接觸測試驅動開發，強烈建議你先看過[一些 C 測試框架的快速總覽][test-frameworks]，或是讀 James Grenning 的 [Test-Driven Development for Embedded C][tdd] 這本書。這些資源涵蓋[Unity][]和[CppUTest][]；這個軌道使用的是 Unity。
