# 關於

在 Python 中，[列舉][enum-docs]（英文：_enum_）是一組獨特的名稱，每個名稱都綁定到獨特且**固定**的值。列舉是透過繼承`Enum`類別來定義的。內建的列舉型別可以在`enum`模組中使用，而`Enum`類別可以用`from enum import Enum`匯入。

```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

請注意，`enum`成員的值可以是任何資料型態，例如`str`、`tuple`、`float`等等。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

`Enums`也可以用[函式呼叫語法][enum-functional-example]來建立。

```python
from enum import Enum

Animal = Enum('Animal', 'ANT BEE CAT DOG')
list(Animal)
#=> [<Animal.ANT: 1>, <Animal.BEE: 2>, <Animal.CAT: 3>, <Animal.DOG: 4>]

Animal.ANT.value
#=> 1
```

在`enum`中將相同的值指定給兩個成員時，後指定的成員會成為前一個成員的別名。不允許對`enum`中兩個不同的成員使用相同的名稱。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>
```

使用標準的`for member in`語法即可疊代列舉的成員：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)

# __members__.items() helps you to loop through alias as well
for member in Color.__members__.items():
    print(member)
#=> ('RED', <Color.RED: 1>)
#=> ('GREEN', <Color.GREEN: 2>)
#=> ('ALIAS_OF_RED', <Color.RED: 1>)
```

`Enum`成員可以使用[`is`（_身分運算子_）][identity-keyword]或`is not`來比較。`==`或`!=`（_相等運算子_）的運作方式也一樣：

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

若要指定整數值，[`auto()`函式][enum-auto-docs]會從`1`開始，並自動設定後續的值。

```python
class Shape(Enum):
    CIRCLE = auto()
    SQUARE = auto()
    OVAL = auto()
```

若要禁止別名（_避免以不同名稱重複相同的值_），可以使用[類別裝飾器][class-decorator][`@enum.unique`][enum-unique-decorator]。

```python
@enum.unique
class Shape(Enum):
    CIRCLE = 1
    SQUARE = 2
    TRIANGLE = 1
#=> ValueError: duplicate values found in <enum 'Shape'>: TRIANGLE -> CIRCLE
```

若要依給定的值存取`enum`成員，可以使用這種表示法：`<EnumName>(<value>)`。

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

只要用任何 mix-in 或資料型態來繼承`Enum`類別，就能寫出自訂的[受限`Enum`][restricted-enums]。
例如：

```python
class StrEnum(str, Enum):
    pass
```

只有在`enum`**未**定義任何成員時，才允許繼承`Enum`。
