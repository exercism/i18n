# 說明

在這個練習中，你會再寫一些程式碼，內容跟準備和烹調你最愛食譜裡的極品千層麵有關。

這次有四項任務。
第一項跟烹調本身有關，另外三項則是關於完美的準備工作。

## 1. 估算準備時間

為了下一份要做的千層麵，你想確保預留了足夠的時間，好讓你能好好享受烹調的過程。
你已經規劃好千層麵要有哪些層了。
現在你想據此估算準備工作會花多久時間。

請實作一個函式 `PreparationTime`，它接受以 `[]string` 表示的層的切片，以及每層的平均準備時間（以分鐘為單位）作為 `int`。
這個函式應該根據層數，回傳預估的總準備時間，型別為 `int`。
Go 的函式沒有預設值。
如果傳入的平均準備時間是 `0`（`int` 的預設初始值），就應該採用預設值 `2`。

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. 計算所需的麵條和醬汁份量

除了預留時間之外，你也想確保有足夠的醬汁和麵條，好做出你夢想中的千層麵。
千層麵中每一層麵條層，需要 50 公克的麵條。
每一層醬汁層，則需要 0.2 公升的醬汁。

定義函式 `Quantities`，它接受以 `[]string` 表示的層的切片作為參數。
這個函式接著會算出做這道料理所需的麵條和醬汁數量。
結果應該以兩個值回傳：`noodles` 為 `int`，`sauce` 為 `float64`。

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. 加入祕密食材

前陣子你去拜訪一位朋友，並在他家吃了千層麵。
那千層麵非常棒，而且有股特別的風味。
朋友把食材陣列寄給你，並告訴你陣列上的最後一項，就是讓那頓飯如此特別的「祕密食材」。
現在你也想把这个祕密食材加進自己的食譜裡。

撰寫一個函式 `AddSecretIngredient`，它接受兩個型別為 `[]string` 的食材切片作為參數。
第一個參數是朋友寄給你的陣列，第二個是你自己食譜的食材陣列。
你的食材陣列中，最後一個元素一定是 `"?"`。
這個函式應該把它替換成你朋友陣列中的最後一項。
**注意：** `AddSecretIngredient` 不會回傳任何東西，你應該直接修改你自己的食材陣列。
朋友的食材陣列則**不該**被修改。
另外，由於 `slice` 是以指標的形式傳入函式，傳進 `AddSecretIngredient` 的兩個 `[]string` 引數若有變動，會直接生效。

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. 調整食譜份量

你的食譜上列出的份量，只夠做出兩人份的千層麵。
因為你下次想煮給更多人吃，所以你想算出不同份數所需的份量。

請實作一個函式 `ScaleRecipe`，它接受兩個參數。

- 一個 `float64` 的切片，內含兩人份所需的份量。
- 你想做的份數。

這個函式應該回傳一個 `float64` 切片，內含所需份數的份量。
不過，你想保留原本的食譜。
這表示 `quantities` 這個引數不應該在這個函式中被修改。

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
