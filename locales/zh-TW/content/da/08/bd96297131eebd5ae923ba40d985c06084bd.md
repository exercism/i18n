# 資源

## 推薦學習資源

ClojureScript 是精心設計的 Clojure 方言。你對 Clojure 的了解（指的是語言本身，而不是 JVM 這個宿主平台）同樣可以運用在 ClojureScript 上。

- [ClojureScript API](http://cljs.github.io/api/) 官方的 API 文件。
- [ClojureScript Cheat-Sheet](https://clojure.org/api/cheatsheet)，一份官方的速查表。
- [Learn ClojureScript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes) 一個教你這個語言語法的 GitHub 儲存庫。
