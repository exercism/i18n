# 指示

在這道練習中，你將為朋友正在開發的新角色扮演遊戲延伸任務邏輯。
為了讓遊戲更有意思，你的朋友希望你加入能改變局勢的隨機事件。

整體設定和上一道練習相同。
新的隨機事件在下方文字中以粗體標示。

遊戲的主角是 Annalyn，一位勇敢的女孩，身邊帶著一隻兇猛又忠誠的寵物狗。
不幸的是，災難降臨了：她最要好的朋友在森林裡尋找莓果時遭到綁架。
Annalyn 將試著找到並救出她最好的朋友，這趟任務中她可以選擇帶狗同行。

沿著好朋友的蹤跡追查一段時間後，她找到了囚禁她好朋友的營地。原來綁匪有兩個人：一名強悍的騎士和一名狡猾的弓箭手。

找到綁匪後，Annalyn 思考自己可以採取下列哪些行動：

- _快速攻擊_：如果騎士正在睡覺，就可以發動快速攻擊，因為他需要時間穿上盔甲，這段期間他會很脆弱。<!-- **Annalyn 有 5% 的機率在接近騎士時絆倒。這會吵醒騎士，並替他爭取到足夠的時間穿上盔甲，因此無法再發動快速攻擊。** [未來可能加入的測試案例] -->
- _偵察_：如果敵方至少有一個人醒著，就可以對他們進行偵察。否則偵察只是浪費時間。**在一半的遊戲過程中都會起霧，因此無法選擇偵察。**
- _向囚犯打信號_：如果囚犯醒著，而且弓箭手正在睡覺，就可以用鳥叫聲向囚犯打信號，因為弓箭手受過鳥叫聲信號的訓練，可能會攔截訊息。
- _釋放囚犯_：Annalyn 可以試著潛入營地釋放囚犯，但這個策略只有在囚犯醒著、另外兩人都在睡覺時才行得通。如果囚犯正在睡覺，會被 Annalyn 突然出現嚇到，並且會吵醒另外兩個人。如果弓箭手正在睡覺，而且 Annalyn 帶著她的寵物狗，也能釋放囚犯，因為騎士會被狗嚇到而撤退，而弓箭手來不及裝備他的弓，無法阻止囚犯被釋放。**可惜的是，Annalyn 的狗很愛追兔子。在前往營地的路上有 25% 的機率會遇到兔子。在這種情況下，就無法靠狗來嚇退騎士了。**

**釋放朋友之後，Annalyn 還有一些時間可以迅速搜刮營地。她可以找到三到十三枚金幣。她還會遇到一個寶箱，裡面裝著隨機的物品。**

你的任務是實作這些用來判斷隨機事件是否發生的函式，並決定 Annalyn 的戰利品。

### 1. 新增一個判斷是否起霧的函式

實作一個名為`is_foggy`的函式。這個函式有一半的機率回傳`true`，否則回傳`false`。

```julia-repl
julia> is_foggy()
true

julia> is_foggy()
false
```

### 2. 新增一個判斷狗是否分心的函式

實作一個名為`is_dog_distracted`的函式。這個函式有 25% 的機率回傳`true`，否則回傳`false`。

```julia-repl
julia> is_dog_distracted()
false

julia> is_dog_distracted()
true

julia> is_dog_distracted()
false
```

### 3. 新增一個搜刮金幣的行動

實作一個名為`loot`的函式，回傳 Annalyn 在營地找到的金幣數量。例如：

```julia-repl
julia> loot()
4

julia> loot()
7

julia> loot()
3
```

### 4. 新增一個搜刮寶箱的行動

實作一個名為`loot`的函式，它接受一個物品集合作為引數，並回傳 Annalyn 在寶箱中找到的物品。例如：

```julia-repl
julia> loot(["Cabbage", "Daring Dagger", "Sneaky Shoes"])
"Cabbage"

julia> loot(["Cabbage", "Daring Dagger", "Sneaky Shoes"])
"Sneaky Shoes"
```
