# 簡介

Cairo 中的函式讓你能把程式碼組織成可重複使用的單位，讓程式更模組化、也更容易理解。
Cairo 的函式由`fn`關鍵字、函式名稱、括號中的參數列表，以及定義函式行為的程式區塊所組成。

## 函式參數

在 Cairo 中，所有函式參數都必須明確標註型別。
有別於某些語言，Cairo 不會推斷型別，也沒有預設參數值，因此所有參數都是必填的。

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## 參數與引數

區分`parameters`和`arguments`很重要：

- **參數**是函式定義中使用的變數名稱，例如函式`print_greeting_name`中的`greeting`和`name`。
- **引數**是在呼叫函式時實際傳入的值。

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## 敘述與運算式

函式主體由一連串敘述組成，最後可以選擇以一個運算式結尾。

- 敘述是執行某些動作、但不回傳值的指令。
- 運算式會求值為一個結果值。

使用`let`關鍵字建立變數並指定值，這是一個敘述。

```rust
let y = 6;
```

但上述敘述中的`6`是一個運算式，會求值為值`6`。

呼叫函式是一種運算式，因為它一定會求值為一個值：如果函式有明確指定回傳值，就是該回傳值；否則就是「單位」型別`()`。

## 回傳值

Cairo 的函式可以回傳值給呼叫它的程式碼。
回傳值列在參數之後，以箭號`->`分隔。
在 Cairo 中，函式的回傳值等同於函式主體區塊中最後一個運算式的值。
你可以使用`return`關鍵字並指定一個值，提前從函式回傳。

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## 呼叫函式

在 Cairo 中呼叫函式，只要使用函式名稱，後面接著括號中的引數即可。

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
