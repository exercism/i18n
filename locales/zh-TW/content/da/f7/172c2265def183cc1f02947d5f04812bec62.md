# 關於

Factor 的`<iota>`會產生一串*虛擬*的整數序列`0, 1, …, n-1`。用`map`走訪它，會得到一個表格化的序列，其中每個元素都是其位置的函式：

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

要把整數碼序列轉成字串，靠的是兩個詞：

| 詞        | 用途                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | 剖析時的字面值，會推入字元的碼位                        |
| `>string` | 將碼位序列轉換成字串                                    |

兩者合起來，就是建立一列以位置為索引的字元時最標準的寫法：

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

在引號內用`if`（或`?`）挑選字元，能讓每個位置的判斷貼近它所依據的索引。
