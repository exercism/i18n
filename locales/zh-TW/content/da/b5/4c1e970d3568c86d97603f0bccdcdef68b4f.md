# Break, Continue

使用迴圈或疊代控制結構時，`break`和`continue`關鍵字可以協助控制程式的流程。
`break`關鍵字會跳出迴圈，進入外層作用域，因而終止迴圈。
`continue`關鍵字會跳過目前疊代的剩餘部分，並從下一次疊代的開頭重新開始迴圈。
雖然不常見，但可以為關鍵字加上一個數字，藉此控制要跳出幾層，或跳到下一次疊代時要略過幾層。

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

在前面的範例中，`continue`被執行了五（5）次，但在第六（6）次疊代時執行了`break`，使得程式碼離開迴圈。
