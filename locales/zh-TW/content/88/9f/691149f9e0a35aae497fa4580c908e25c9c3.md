# 說明

在這個練習中，你會撰寫程式碼，協助自由工作者與專案經理溝通。你的任務是提供幾個工具，以便快速計算每日與每月費率，並可選擇套用指定的折扣。

我們先為自由工作者與專案經理之間建立幾條規則：

- 每日費率是每小時費率的 8 倍。
- 一個月有 22 個可計費工作日。

有時，自由工作者會針對每日費率提供折扣（例如給最忠誠的客戶或非營利客戶）。

折扣以代表百分比的小數來表示，例如 `25.0`（25%）。

## 1. 根據每小時費率計算每日費率

實作一個名為`daily_rate`的函式，接收每小時費率作為參數，並計算每日費率。合約定義一天有 8 個可計費小時。

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

回傳的每日費率應為浮點數。

## 2. 計算折扣後的價格

實作一個`apply_discount`函式，計算折扣後的價格。

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

回傳值應一律為浮點數，且不進行任何四捨五入。

## 3. 根據每小時費率和折扣計算每月費率

實作一個`monthly_rate`函式，計算折扣後的每月費率。它接收兩個參數：每小時費率和折扣百分比。

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

回傳的每月費率應無條件進位（取上界）至最接近的整數。

## 4. 根據預算、每小時費率和折扣計算完整工作天數

實作一個`days_in_budget`函式，接收預算、每小時費率和折扣，並計算這樣能涵蓋多少個完整的工作天。

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

回傳的天數應無條件捨去（取下界）至小數點後一位。
