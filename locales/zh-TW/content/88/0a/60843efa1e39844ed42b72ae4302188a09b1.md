# 簡介

Cairo 中的智慧指標是進階的資料結構，它們在一般指標之上加入各種安全機制，確保記憶體管理既安全又有效率，並避免對空指標解參考或存取未初始化記憶體這類常見問題。

## 什麼是智慧指標？

智慧指標的行為就像一般指標，但它會追蹤所有權，並確保記憶體存取安全，避免對空指標或懸空指標解參考這類問題。

## 智慧指標的型別

Cairo 提供了幾種智慧指標型別，例如 `Box<T>` 和 `Nullable<T>`：

- **`Box<T>`**：將資料存放在特殊的記憶體區段中，很適合大型或動態大小的資料。它可以在不複製資料的情況下轉移所有權。
- **`Nullable<T>`**：指向型別 `T` 的有效值或 `null`，適合用來處理選擇性的值。

## 記憶體安全

智慧指標有助於避免不安全的記憶體存取，確保記憶體在不再需要時自動釋放，進而降低記憶體洩漏的風險。

### 範例：用 `Box<T>` 處理遞迴型別

像 `Box<T>` 這樣的智慧指標能安全地處理遞迴型別，例如二元樹，它會有效率地配置記憶體，避免無限遞迴。

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## 效能優勢

智慧指標會傳遞資料的參考，而不是複製大型結構，藉此提升效能並降低記憶體額外負擔。

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
