# 排序

把東西排好順序這件事太常見了，所以程式庫已經幫你處理好了。

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort`能用在任何已經知道怎麼比較自己的東西上，數字和字串都可以，因為它們都有 `is_lt`。

## 依照自己的規則排序

大多數的排序方式都不是內建的那一種。籃網球的排名表既不是按字母順序，也不是按名稱長度來排，而是按積分，積分相同的隊伍再比淨勝分。`ARRAY`沒辦法猜到這種規則。

所以你要把這個順序交給它，方式是傳入一個綁定常式：

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by`接受一個 `ROUT{T,T}:BOOL`，也就是一個常式，它接收兩個正在被排序的東西，並回傳第一個是不是該排在第二個前面。它會視需要盡量呼叫這個常式，然後依照這些答案把陣列排成對應的順序。

這就是 `understudy` 的用途。程式庫懂得怎麼排序，卻完全不知道你心目中的順序；綁定常式就是兩者交會的地方。

## 撰寫比較

常式要**在第一個引數排在前面時回傳 true**。

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

如果規則不只一個部分，就照重要性依序處理這些部分：

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

只要積分不同，第一個 `if`就會決定結果。只有在積分相同時，第二行才有發言的機會。如果把決勝條件寫在前面，積分就永遠無關緊要了。

## 排序會改變陣列

`insertion_sort_by`會直接把陣列本身排好，不會回傳任何東西：

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

如果原本的順序很重要，就排序一份複本：

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
