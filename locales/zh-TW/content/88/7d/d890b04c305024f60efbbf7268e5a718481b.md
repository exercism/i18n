# 操作說明

你的朋友一直想成為藝術家，他帶著一個專案構想來找你。讓我們把他的視覺創意和你的技術專長結合起來吧。該來玩玩[生成式藝術][generative-art]了！

限制有助於激發創意，也能縮短專案的截止期限，所以你們兩個講好，這件曠世巨作只能有一種形狀：圓形。不過，圓形會有很多個，而且它們還能到處移動！你們就叫它……跳舞的點點吧。

你朋友之後一定會想為這些點設計更多花俏的新動作，所以你打算先建立一套架構，讓你之後能輕鬆定義新的動畫。

## 1. 定義動畫行為

每個動畫模組都需要實作兩個回呼：`init/1`和`handle_frame/3`。請在`Animation`模組中定義它們。

定義`init/1`回呼。它應該接受一個型別為`opts`的引數，並回傳`{:ok, opts}`元組或`{:error, error}`元組。這個回呼的實作會檢查傳入的選項對這種特定的動畫型別是否有效。

定義`handle_frame/3`回呼。它應該接受三個引數：點、影格編號和選項。它應該一律回傳一個點。這個回呼的實作會根據目前的影格編號和動畫的選項來修改點的屬性。

## 2. 為`init/1`回呼提供預設實作

只要呼叫`use DancingDots.Animation`，就能輕鬆把`Animation`行為納入其他模組。

為了做到這點，請在`Animation`模組中實作`__using__`巨集，讓它把`Animation`模組設為另一個模組的行為。它還應該提供`init/1`回呼的預設實作。`init/1`的預設實作應該原封不動地回傳傳入的選項。

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. 實作`Flicker`動畫

請使用`Animation`行為來實作一個閃爍動畫。

它應該沿用預設的`init/1`回呼，因為它不接受任何選項。

請實作`handle_frame/3`回呼，它負責處理單一影格。如果影格編號是四的倍數，函式應該回傳不透明度為原本一半的點。在其他影格中，則回傳不變的點。

影格從`1`開始計算。傳給`handle_frame/3`的點一律是原始狀態的點，而不是前一個影格留下的狀態。

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. 實作`Zoom`動畫

請使用`Animation`行為來實作一個縮放動畫。

這個動畫接受一個選項：速度。速度可以是任何數字。如果是負數，點就會縮小而不是放大。

實作`init/1`回呼。它應該驗證傳入的選項是帶有`:velocity`鍵的關鍵字清單。速度的值必須是數字。如果它不是數字，就回傳錯誤`"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`。

實作`handle_frame/3`回呼。它應該回傳一個點，其半徑增加（目前影格編號減一）乘以速度的量。

影格從`1`開始計算。傳給`handle_frame/3`的點一律是原始狀態的點，而不是前一個影格留下的狀態。

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
