# 簡介

Factor 的字元就是整數，也就是 Unicode 碼位，所以數值的`<`、`>`、`=`可以直接提供區分大小寫的排序。`unicode`詞彙加入了支援 Unicode 的述詞，以及單一字元的大小寫轉換。

## 字元述詞

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## 大小寫轉換

`ch>upper`和`ch>lower`會切換單一字元的大小寫。字串層級的`>upper`和`>lower`則會把它們套用到字串中的每一個字元。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
