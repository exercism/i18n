# 介紹

## 正規表達式

Gleam 的正規表達式遵循**PCRE**規格（**P**erl **C**ompatible **R**egular **E**xpressions），類似於其他熱門語言，例如 Java、JavaScript 或 Ruby。

來自`gleam_regexp`套件的`gleam/regexp`模組提供了處理正規表達式的函式。

~~~~exercism/note
這個練習假設你已經知道正規表達式的語法，包括字元類別、量詞、群組和捕獲。

如果你需要複習正規表達式的知識，可以參考以下資源：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

建立正規表達式最常見的方式是使用`regexp.from_string`函式。

```gleam
let assert Ok(re) = regexp.from_string("test")
```

如果正規表達式的語法無效，建立正規表達式的函式會回傳錯誤，因此這裡使用了 let assert 斷言來確保正規表達式是有效的。

可以使用`regexp.check`函式來檢查正規表達式是否匹配字串。

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### 捕獲

如果你想使用正規表達式捕獲子字串，可以使用`regexp.scan`函式來回傳一個匹配的陣列。

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### 修飾符

正規表達式的行為可以透過使用`regexp.compile`函式建立並傳入選項來修改。

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
