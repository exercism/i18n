# 說明

在這個練習中，你會處理儲蓄帳戶。每年，你的儲蓄帳戶餘額都會根據利率更新。銀行給你的利率取決於你帳戶裡的金額（也就是餘額）：

- 餘額為負時為 3.213%（會產生負利息）。
- 餘額為正且小於`1000`美元時為 0.5%。
- 餘額為正、大於或等於`1000`美元且小於`5000`美元時為 1.621%。
- 餘額為正且大於或等於`5000`美元時為 2.475%。

每年政府都允許你把一部分的錢免稅捐給慈善機構。因為你是個好人，如果到了年底你的餘額是正的，你就把免稅的比例加倍，並向下取整到最接近的整數美元。捐贈金額的另一半要繳稅，你不介意。

你有三個任務，每個任務都會處理你的餘額和它的利率。

## 1. 計算利率

實作`interestRate`函式，根據指定的餘額計算利率：

```fsharp
interestRate 200.75m
// => 0.5f
```

注意回傳值是`single`。

## 2. 計算利息

實作`interest`方法，根據指定的餘額計算利息：

```fsharp
interest 200.75m
// => 1.00375m
```

注意回傳值是`decimal`。

## 3. 計算年度餘額更新

實作`annualBalanceUpdate`函式，計算年度餘額更新，並將利率納入考量：

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

注意回傳值是`decimal`。

## 4. 計算要捐贈多少錢

實作`amountToDonate`函式，根據餘額以及政府允許的免稅比例，計算要捐給慈善機構多少錢：

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

注意回傳值是`int`。
