# 數字

Crystal 有一個型別`Number`，它是所有數值型別的基礎型別。
`Number`型別底下有兩個主要的子型別：[`Int`][int] 和 [`Float`][float]。

`Int`是 integer 的縮寫，代表整數。
`Int`可以是負數，也可以是正數，不含小數點。

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float`代表帶有小數點的數字。
`Float`可以是負數，也可以是正數。

```crystal
10.5.class
# => Float64
```

## 在`Int`和`Float`之間轉換

使用 'to_i' 和 'to_f' 方法，就能在`Int`和`Float`之間轉換。
從`Float`轉成`Int`時，數字會向下取整。

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## 算術運算子

你可以在`Int`和`Float`上使用[基本算術運算子][math]。
這些運算子包括`+`、`-`、`*`、`/`和`%`。
使用這些運算子時，你可以混用`Int`和`Float`。

### 加法、減法與乘法

`+`運算子用於加法，`-`運算子用於減法，`*`運算子則用於乘法。

| 運算子 | 範例        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 除法

除法用來將數字相除。
`/`運算子用於除法。
結果一定會是浮點數。

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
在某些程式語言中，除以零的結果會是錯誤。

在 Crystal 中，除以零的結果是`Infinity`或`-Infinity`。
唯一的例外是零除以零，結果會是`NaN`（Not a Number）。
`Infinity`和`NaN`是`Float`型別中的特殊值。

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### 取餘數

取餘數用來取得相除之後的餘數。
`%`運算子用於取餘數。

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
使用模除時除以零，會產生 DivisionByZeroError。
這和一般的除法不同。

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## 四捨五入

`round`方法接受一個選用引數：要四捨五入到的小數位數。
預設的小數位數是 0。

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## 優先順序與括號

Crystal 允許使用括號（`()`），可以用來將運算式分組。
當你想改變運算順序時，這就很實用。

使用多個算術運算子時，運算順序和數學裡一樣，也就是所謂的 [PEMDAS][pemdas]。
它依序是括號（`()`）、指數（`**`）、乘法（`*`）與除法（`/`），以及加法（`+`）與減法（`-`）。

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
