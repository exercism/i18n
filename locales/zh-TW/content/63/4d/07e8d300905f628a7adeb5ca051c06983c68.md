# Instructions

你的朋友剛傳了一則訊息給你，裡面藏著重要的秘密。為了不讓其他人輕易讀懂內容，這則訊息在加密時進行了一連串的位元操作。你需要撰寫這些 word 來協助解密這則訊息。

## 1. 將位元移回去

解密訊息的第一步，是把位元往右移回來，以還原加密過程中的位移。後續步驟假設會從左側補入 0。

定義`shift-back`，接受一個 32 位元的值和一個位移量，回傳將該值向右位移該數量、並以 0 填補的結果。

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. 設定一些位元

接下來，有些位元需要設為 1。

定義`set-bits`，接受一個值和一個遮罩。`value`中每個對應到`mask`為 1 的位元，都應設為 1；其他位元則保持不變。

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. 翻轉特定的位元

加密過程中有些位元會被翻轉。要解密訊息，就得把它們翻轉回來。

定義`flip-bits`，接受一個值和一個遮罩。`value`中每個對應到`mask`為 1 的位元，都應被翻轉；其他位元則保持不變。

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. 清除特定的位元

最後，也有一些位元解密後永遠是 0。

定義`clear-bits`，接受一個值和一個遮罩。`value`中每個對應到`mask`為 1 的位元，都應清除為 0；其他位元則保持不變。

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
