# 簡介

`Result`型別讓函式可以回傳單一值，表示下列所有事項：
- 操作成功或失敗
- 成功時，操作的結果值
- 失敗時，失敗的原因

## 用法

`Result`型別是一種泛型型別，包含兩種底層型別：
- 操作成功時結果值的型別
- 失敗時錯誤的型別

`Result`型別也是一種[差別聯集][discriminated-union]，可能的情況如下：
* `Ok <value>`代表成功的結果
* `Error <reason>`代表失敗

下列函式示範如何建立`Result`值：

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

在這個例子中，`Ok`值是字串（傳入的名稱），`Error`值也是字串（錯誤的原因，以人類可讀的形式呈現）。

```
| NotFound
| AccessDenied
| FileLocked

```

呼叫`openFile`函式的程式碼可以用模式比對來處理成功與失敗的情況，如下列範例所示：

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
