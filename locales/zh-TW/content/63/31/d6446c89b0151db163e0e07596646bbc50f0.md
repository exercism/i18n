# 資源

## 取得協助

1. [The Emacs Wiki](http://emacswiki.org/) 極具價值，非常值得你花時間好好探索。
2. [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) 是 GNU Emacs 的官方手冊。
3. IRC：在 [Libera.Chat](https://libera.chat/) 上有`#emacs`、`#org-mode`以及許多 Emacs 套件的頻道，也有很多熱心的人。而且在 Emacs 裡，IRC 就只差`M-x erc`這一步。
4. Matrix：在 [Matrix](https://matrix.org/) 上有 [emacs](https://matrix.to/#/#emacs:matrix.org)、[org-mode](https://matrix.to/#/#org-mode:matrix.org) 及其他 Emacs 套件的聊天室。你可以[加入 Emacs Matrix space](https://matrix.to/#/#emacs-space:matrix.org) 來概覽有哪些可用頻道。如果想在 Emacs 裡加入 Matrix，可以使用 [Ement.el](https://github.com/alphapapa/ement.el) 套件。
5. [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) 和 [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) 可以用來搜尋你的問題，看看是否已經有人回答過。你也可以在上面發問和回答問題。
