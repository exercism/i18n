# 提示

## 一般

- `locals`詞彙提供了`::`和`[| | ]`。
- 區域變數不會取代堆疊程式碼，請在能提升清晰度的地方使用它們。

## 1. 判斷烹飪狀態

- 來自[`combinators`][combinators]的`cond`正是合適的形式：一個分支檢查`dup not`（計時器為`f`），另一個檢查`dup zero?`，其餘則交由預設分支處理。每個分支都應在推入字串之前先`drop`計時器。

## 2. 估算準備時間

- 使用`:: preparation-time ( layers minutes-per-layer -- total )`，搭配`layers length minutes-per-layer *`。

## 3. 計算所需的麵條與醬料

- 區域變數讓你不必用`dup`就能引用`layers`兩次。用述詞`[ "noodles" = ]`（或`"sauce" =`）搭配`count`，就能取得每一層的數量。
- `1/5`是 Factor 的有理數字面值。

## 4. 加入祕密食材

- [`sequences`][sequences]裡的`last`會讀取最後一個元素；`suffix`則會在尾端附加一個。

## 5. 調整食譜份量

- 縮放係數是`portions / 2`。區域變數讓你能在 lambda 內引用`portions`。
- 來自[`assocs`][assocs]的`assoc-map`接受一個`( key value -- newkey newvalue )`引述。在`[| key value | … ]`內，回傳這兩個值，就能保留相同的鍵並產生新的值。
