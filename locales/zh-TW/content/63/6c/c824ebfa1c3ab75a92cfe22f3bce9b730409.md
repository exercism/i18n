# 布林

有些問題只有兩個答案：是或否。Sather 用來表示這種答案的型別是`BOOL`，而這兩個答案寫成`true`和`false`。

```sather
   ready : BOOL is
      return true;
   end;
```

## 比較

比較兩個數字會得到一個`BOOL`。

| 運算子 | 問的是 |
| --- | --- |
| `=` | 它們一樣嗎？ |
| `/=` | 它們不同嗎？ |
| `<` | 左邊的比較小嗎？ |
| `<=` | 比較小，還是一樣？ |
| `>` | 左邊的比較大嗎？ |
| `>=` | 比較大，還是一樣？ |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

注意，`=` 是在問一個問題。把值*放進*某個東西裡用的是`:=`，你已經看過了，兩者並不相同。

## 組合

有三個運算子可以拿較小的問題組出更大的問題。

`and` 在**兩邊**都是 true 時，結果才是 true。

```sather
harness_on and rope_checked
```

`or` 在其中**任一**邊為 true 時為 true，或兩邊都為 true。

```sather
mat_below or net_below
```

`~` 會把答案翻轉過來：把 true 變成 false，把 false 變成 true。

```sather
~ready       -- true exactly when ready is false
```

`and` 和`or`放在兩個答案之間；`~` 則放在一個答案前面。
