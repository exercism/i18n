# 指令補充

在 Roc 中，lens 並不常用，因為記錄更新語法就能漂亮地涵蓋大多數使用情境。舉例來說，看看這個巢狀記錄：

```roc
bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
```

現在來幫 Bob 剪個頭髮吧：

```roc
new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
```

完全不需要 lens！話說回來，雖然 lens 在 Roc 裡很罕見，但在 Haskell、Scala 等其他語言中卻很常見，所以你可能會好奇該怎麼在 Roc 裡實作它們。這也是練習一些進階 Roc 功能的好方法，例如參數化型別，以及包含函式的記錄。其實，以下就是在 Roc 裡表示 lens 的一種方式：

```roc
Lens(whole, part) := {
	get : whole -> part,
	set : whole, part -> whole,
}
```

這是參數化型別：`whole`和`part`可以是任何型別。`whole`通常是記錄，而`part`則可以是任何欄位型別。`get`欄位包含一個函式，會回傳指定`whole`中的特定`part`；`set`欄位則包含一個函式，會回傳指定`whole`的副本，只是把特定的`part`換成給定的`part`。

舉例來說，以下是取得或設定某人頭髮的 lens：

```roc
hair_lens = {
	get: |person| person.hair,
	set: |person, hair| { ..person, hair },
}
```

我們可以用這個 lens 把焦點放在 Bob 的頭髮上，就像這樣：

```roc
bob_hair = bob |> hair_lens.get
```

也可以像這樣改變他的頭髮：

```roc
new_hair = { ..bob.hair, length: Short }
new_bob = bob |> (hair_lens.set)(new_hair)
```

注意：`hair_lens.set`外面的括號是必要的：少了它們，Roc 會去`hair_lens`的型別裡尋找一個名為`set`的函式。

當你開始組合 lens 時，它們會變得特別有用，讓你取得和設定深度巢狀的部分。這可以透過實作像這樣的函式來達成：

```roc
compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
```

這個函式實作好之後，你就可以用它建立像這樣的頭髮長度 lens：

```roc
length_lens = {
	get: |hair| hair.length,
	set: |hair, length| { ..hair, length },
}
hair_length_lens = compose(hair_lens, length_lens)

```

現在你可以再幫 Bob 剪一次頭髮：

```roc
set_hair_length = hair_length_lens.set
new_bob = bob |> set_hair_length(Short)
```

你可能也會想實作一個函式，讓你能對巢狀的部分套用任何轉換：

```roc
over : Lens(whole, part), whole, (part -> part) -> whole
```

實作好之後，你可以像這樣使用`over`：

```roc
cut_hair = |current_length| match current_length {
	Long => Short
	Short => Bald
	Bald => Bald
}
new_bob = hair_length_lens |> over(bob, cut_hair)
```

在這個練習中，測試會檢查你的程式碼是否能修改以下巢狀記錄的各種巢狀部分：

```roc
test_person : Person
test_person = {
	name: { forenames: "Jane Joanna", surname: "Doe" },
	birth: {
		born_at: { street: "Longway", house_number: 1024, place: "Springfield", country: "United States" },
		born_on: { year: 1984, month: 4, day: 12 },
	},
	address: { street: "Shortlane", house_number: 2, place: "Fallmeadow", country: "Canada" },
}
```

我們建議你先用 Roc 的記錄更新語法通過測試，然後再試著改用 lens。
