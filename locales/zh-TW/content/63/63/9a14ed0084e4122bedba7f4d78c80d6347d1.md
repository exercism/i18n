# Elm 語法基礎 2

## 匯出函式

匯出函式在第一個概念中已經介紹過，這裡快速複習一下。

Elm 中的每個檔案都是一個模組，而且必須在所有其他程式碼之前包含一個`module`敘述。

模組名稱必須與檔名相符，所以模組`Calculator`必須放在檔案 Calculator.elm 中，而模組`Parser.Utils`則需要放在檔案 Parser/Utils.elm 中。

在模組中定義的任何內容，其作用域都僅限於該模組，除非列在`exposing`中，否則無法從這個模組外部存取。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 從其他模組匯入函式

要存取在其他模組中定義的函式，必須透過匯入。
匯入某個模組時，該模組所匯出的所有函式都會變成可以存取。
不過存取的方式會依模組的匯入方式而有所不同。

限定匯入是預設做法，要存取這類模組中的函式（例如`List`模組裡的`map`函式）時，會在模組名稱前加上前綴（`List.map`）。

開放匯入則可以直接存取該模組所匯出的函式，不需要加前綴。它們是用`exposing`關鍵字完成的，就像是匯出時所用關鍵字的鏡像。你可以匯出所有可用的函式（使用`..`），或只匯出特定的函式（例如`map`）。

你也可以從其他模組匯入型別及其建構子，這會是後面的概念。

建議優先使用限定匯入，以提升清晰度並避免名稱衝突。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 型別標註

型別標註用`name : parameter types -> return type`來定義，參數型別之間同樣以`->`分隔。

括號可以用來定義函式的參數（參數本身也是用同樣的語法定義，所以才需要括號）。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 數字

Elm 中有 2 種可用的數字型別，分別由`Int`與`Float`型別定義。
`Int`對應到正整數與負整數的集合。
`Float`對應到實數的集合，並受限於電腦的精度。
定義在數字上的運算通常只適用於其中一種型別，而不能混用兩者。
有些函式可以在兩者之間轉換，例如`toFloat`會把`Int`轉成`Float`，而`round`、`floor`、`ceiling`或`truncate`則會以不同的語意把`Float`轉成`Int`。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 字串操作

若要在程式碼中描述詞語和句子，Elm 有一種原生的`String`型別。
字串字面值寫在雙引號之間，例如`"Hello World!"`。
字串串接運算子`++`和相等運算子`==`預設就能使用。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

其他大多數的字串函式都在`String`模組裡，需要先匯入才能使用。

https://package.elm-lang.org/packages/elm/core/latest/String
