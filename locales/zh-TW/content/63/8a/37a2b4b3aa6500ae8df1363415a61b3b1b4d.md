# 指令

墨爾本的電車依區域收費，市中心則是免費的。你正在為售票機撰寫票價規則。所有票價都以分為單位。

這四個任務都要寫在`TRAM_FARES`類別裡。

## 1. 各區域的票價

第 0 區是免費電車區，不收任何費用。第 1 區是 550。第 2 區是 370。其他任何數字都完全不是電車區，費用為零。

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. 這是哪種票？

票券上會有一個字母。`'f'`代表全票。`'c'`和`'s'`都是優待票，一個給兒童，一個給學生。`'x'`是免費票。其他任何字母都是未知。

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

四個答案分別是`"Full fare"`、`"Concession"`、`"Free pass"`和`"Unknown"`。

## 3. 這是哪種日子？

`"Sat"`和`"Sun"`是週末。`"Mon"`到`"Fri"`是平日。其他任何值都是未知。

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

三個答案分別是`"Weekend"`、`"Weekday"`和`"Unknown"`。

## 4. 每日上限

不論你搭了幾趟電車，當天的花費都不會超過上限：平日 1100，週末 700。無法辨識的日子沒有上限，也就是 0。

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
