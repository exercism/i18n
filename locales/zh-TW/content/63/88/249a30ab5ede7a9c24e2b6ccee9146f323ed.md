# 簡介

自 `PHP 8.0.0` 起，**聯合型別宣告**可以接受多種不同型別的值，而不只是單一型別。聯合型別的定義使用豎線（`|`）分隔各個型別。

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

在嚴格模式下，如果傳入的參數不是 `float` 或 `int`，PHP 會拋出 `TypeError`。在非嚴格模式下，如果傳入的參數無法強制轉換成 `float` 或 `int`，也會拋出型別錯誤。

同樣地，如果函式沒有回傳已宣告型別的其中一種，PHP 會在執行階段拋出 `TypeError`。
