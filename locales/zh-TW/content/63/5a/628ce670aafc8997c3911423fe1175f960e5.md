# 指令

Lucian 的女朋友正在回家的路上，而他還沒煮好他們的週年紀念晚餐！

在這個練習中，你將寫一些程式碼，幫 Lucian 依照他最愛的食譜做出一道美味的千層麵。

你有四項任務，全都和烹調千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義 `Lasagna.ExpectedMinutesInOven()` 方法，它不接受任何參數，並回傳千層麵應該在烤箱裡待幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義 `Lasagna.RemainingMinutesInOven()` 方法，它接受千層麵實際待在烤箱裡的分鐘數作為參數，並根據上一項任務中預期的烤箱時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. 計算準備時間（分鐘）

定義 `Lasagna.PreparationTimeInMinutes()` 方法，它接受你加進千層麵的層數作為參數，並回傳你花了幾分鐘準備千層麵，假設每一層要花你 2 分鐘準備。

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. 計算經過的時間（分鐘）

定義 `Lasagna.ElapsedTimeInMinutes()` 方法，它接受兩個參數：第一個參數是你加進千層麵的層數，第二個參數是千層麵待在烤箱裡的分鐘數。這個函式應該回傳你花了幾分鐘烹調千層麵，也就是準備時間的分鐘數，加上千層麵當下已經待在烤箱裡的分鐘數。

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
