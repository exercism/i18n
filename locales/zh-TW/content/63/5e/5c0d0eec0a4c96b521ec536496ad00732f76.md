# 說明

你正在維護一份野外圖鑑，裡面記錄著動物名稱與牠們棲地之間的對應關係。

這 5 個任務都要寫在 `FIELD_GUIDE` 類別裡。

## 1. 圖鑑裡有牠嗎？

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. 牠住在哪裡？

回傳圖鑑中為某隻動物記錄的棲地。如果圖鑑裡從來沒有牠的紀錄，就回傳 `"Unknown"`。

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. 新增一筆紀錄

回傳一份多了一隻動物的圖鑑。如果這隻動物已經在圖鑑裡，就取代牠的棲地。

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

它回傳的圖鑑，就是接下來要繼續使用的圖鑑。在一份完全空白的圖鑑上新增資料也沒問題，結果會是一份只有一隻動物的圖鑑。

## 4. 有幾隻動物？

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. 有哪些棲地？

回傳圖鑑中提到的棲地所組成的集合。好幾隻動物可能共用同一個棲地，而每個棲地只應該出現一次。

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
