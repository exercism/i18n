# 學習

Haskell 是一門純函式語言，它採用的典範，和較常見、也較常被傳授的[物件導向](https://en.wikipedia.org/wiki/Object-oriented_programming)做法從根本上有很大的不同。因此，學習 Haskell 的感受，會和單純再學一門程式語言很不一樣。

幸運的是，有許多資源都預設你已經具備一些程式設計基礎，例如：

  - An opinionated beginner's guide to Haskell（[2019](https://github.com/theindigamer/not-a-blog/blob/master/opinionated-haskell-guide-2019.md)、[2018](https://lexi-lambda.github.io/blog/2018/02/10/an-opinionated-guide-to-haskell-in-2018/)）
  - 這本廣受歡迎又免費的線上書籍 [Learn You a Haskell For Great Good!](https://learnyouahaskell.github.io/)
  - 格拉斯哥大學的 [Functional Programming in Haskell](https://www.futurelearn.com/courses/functional-programming-haskell) 課程
  - FP Complete 的 [School of Haskell](https://www.schoolofhaskell.com/)
  - [Happy Learn Haskell Tutorial](http://www.happylearnhaskelltutorial.com/)
  - [Haskell for Mac](http://learn.hfm.io/) 的教學

近期出版的 Haskell 書籍還包括
  - Christopher Allen 與 Julie Moronuki 的 [Haskell Programming From First Principles](https://haskellbook.com)（本書不預設任何程式設計基礎）
  - Graham Hutton 的 [Programming in Haskell](https://www.cambridge.org/us/academic/subjects/computer-science/programming-languages-and-applied-logic/programming-haskell-2nd-edition?format=PB&isbn=9781316626221)

你也可以參考 [Haskell wiki](https://wiki.haskell.org/Learning_Haskell#Online_tutorials)，裡面還有大量其他入門資源喔。
