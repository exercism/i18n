# 指示

在這道練習中，你會協助一位密碼學家管理並驗證一套安全通訊系統。
這套系統非常依賴體元素，特別是 Cairo 中的`felt252`型別，以確保所有算術運算都維持在定義好的範圍內。

## 1. 計算 2 則訊息的總和

2 則加密訊息，各自以`felt252`表示，需要相加成一則合併的訊息。
不過因為加密的關係，任何超過最大值$P - 1$的結果，都必須以取模$P$的方式繞回。

實作一個函式，接受 2 個`felt252`值並回傳它們的總和，同時確保結果維持在有效範圍內：

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **注意：** 回傳值應該是`felt252`。

## 2. 計算 2 則訊息之間的差

有時候，訊息需要相減才能取回原始資料。
如果相減的結果是負數，系統會自動加上$P$來調整結果，讓它回到有效`felt252`值的範圍內。

實作一個函式，接受 2 個`felt252`值並回傳它們的差，同時確保結果維持在有效範圍內：

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **注意：** 回傳值應該是`felt252`。

## 3. 計算 2 則訊息的有效乘積

為了確保加密資料的完整性，這套密碼系統經常會將 2 則訊息（`felt252`）相乘，以確保它們的乘積維持在有效範圍內。
結果必須以取模$P$的方式計算，才能確保它維持在有效範圍內。

實作一個函式，接受 2 個`felt252`值並回傳它們的乘積，同時確保結果維持在有效範圍內：

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **注意：** 回傳值應該是`felt252`。
