# 指令

在這個練習中，你需要把經典遊戲 Pac-Man 的一些規則轉換成 Haskell 函式。

你有四條規則要轉換，全都和遊戲狀態有關。

> 不用擔心引數是怎麼產生的，只要專注在組合這些引數，回傳預期的結果就好。

## 1. 定義 Pac-Man 是否吃掉幽靈

定義 `eatsGhost` 函式，它接受兩個引數（_Pac-Man 是否有能量藥丸生效_ 和 _Pac-Man 是否碰到幽靈_），並在 Pac-Man 能吃幽靈時回傳一個 `Bool` 值。
這個函式應該只在 Pac-Man 有能量藥丸生效且碰到幽靈時回傳 `True`。

```haskell
eatsGhost False True
-- -> False
```

## 2. 定義 Pac-Man 是否得分

定義 `scores` 函式，它接受兩個引數（_Pac-Man 是否碰到能量藥丸_ 和 _Pac-Man 是否碰到點_），並在 Pac-Man 得分時回傳一個 `Bool` 值。
當 Pac-Man 碰到能量藥丸或點時，這個函式應該回傳 `True`。

```haskell
scores True True
-- -> True
```

## 3. 定義 Pac-Man 是否輸掉

定義 `loses` 函式，它接受兩個引數（_Pac-Man 是否有能量藥丸生效_ 和 _Pac-Man 是否碰到幽靈_），並在 Pac-Man 輸掉時回傳一個 `Bool` 值。
當 Pac-Man 碰到幽靈且沒有能量藥丸生效時，這個函式應該回傳 `True`。

```haskell
loses False True
-- -> True
```

## 4. 定義 Pac-Man 是否獲勝

定義 `wins` 函式，它接受三個引數（_Pac-Man 是否已經吃掉所有點_、_Pac-Man 是否有能量藥丸生效_ 和 _Pac-Man 是否碰到幽靈_），並在 Pac-Man 獲勝時回傳一個 `Bool` 值。
當 Pac-Man 已經吃掉所有點，_而且_ 根據第 3 部分定義的引數判斷並未輸掉時，這個函式應該回傳 `True`。

```haskell
wins False True False
-- -> False
```
