# 關於

PHP 是一種伺服器端語言，適合用於網頁開發。這個縮寫是遞迴式的，代表 _PHP: Hypertext Preprocessor_。

PHP 的用途比 CGI 腳本廣泛得多，常被用來為純 HTML 增添互動性，並強化網頁框架。

這門語言可以在任何作業系統上使用。PHP 受到大多數常見網頁伺服器的支援，通常透過翻譯員模組來處理，讓靜態的網頁程式碼能結合動態內容。

PHP 不只是網頁伺服器框架，它對命令列腳本（無介面解析）以及開發 GUI 也很有用。

你應該學 PHP，因為：

- 它是開放原始碼語言
- 它有完善的文件與支援
- 它與大多數常見的網頁伺服器相容
- 它容易上手，好學
- 它具有高度擴展性且可延伸
