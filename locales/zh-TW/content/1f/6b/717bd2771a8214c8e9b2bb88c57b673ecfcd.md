# 說明

盧頓圖書館是一間大型圖書館，收藏了大量文學作品，範圍從書籍到藝術品都有。
圖書館設有一個部門，專門研究文學並將書籍登錄到電腦系統中。

其中某些部分希望自動化，因此請你來協助他們。
這包括從將登錄流程表單自動化，到協助解密文本等各種工作。

## 1. 取得標題的第一個字母

圖書館的書籍應該要容易找到，因此它們依標題的第一個字母排序。

實作`Library.first_letter`方法，它接受一個引數`title`，其中存放書籍的標題。
這個方法應該回傳標題的第一個字母。

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. 取得作者姓名的首字母

圖書館有許多由不同作者撰寫的書。
作者經常以姓名首字母來稱呼，因此圖書館要求一套系統，只要輸入作者的名字和姓氏，就能取得作者的首字母。
首字母的格式應該如下：`{first_letter_of_first_name}.{first_letter_of_last_name}`

實作`Library.initials`方法，它接受兩個引數`first_name`和`last_name`，分別存放作者的名字和姓氏。
這個方法應該回傳作者姓名首字母。

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. 解密字母

有些文學作品經過加密，而圖書館有大量加密文本。
圖書館想要一套新的特殊加密解密系統。

這種加密的做法是取一個字母，並用字母表中它前面的字母取代它。
例如`a`變成`z`，`b`變成`a`，`c`變成`b`，依此類推。

圖書館希望它能解密大寫和小寫字母，並保留與原字母相同的大小寫。

實作`Library.decrypt_character`方法，它接受一個引數`character`，其中存放要解密的字母。
這個方法應該回傳解密後的字母。

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. 解密文本

圖書館也想解密整段文本，同樣採用取字母表中前一個字母的加密方式。

解密程式應該只解密字母，其他字元都保持原樣。

實作`Library.decrypt_text`方法，它接受一個引數`text`，其中存放要解密的文本。
這個方法應該回傳解密後的文本。

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
