## 建立你的第一個 Coffee 模組

若要建立一個能用 `Bob = require './bob'` 載入的模組，請把這段程式碼放進 `bob.coffee`：

```coffeescript
class Bob

module.exports = Bob
```

你可以在 [Node 文件](http://nodejs.org/api/modules.html#modules_module_exports) 找到更多關於模組的資訊。

## Windows 上的 Visual Studio

如果你有付費版的 Visual Studio，可以下載一份已經設定好、能搭配 CoffeeScript 以及 Visual Studio 支援的其他語言使用的 Visual Studio 方案。

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. 點選頁面上的 Download Zip 按鈕，從 GitHub 下載 [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio)。
2. 把範本解壓縮到你的練習目錄，例如 `C:\src\exercises`
2. 安裝 [Exercism CLI](http://exercism.io/cli)
3. 在練習目錄開啟命令提示字元
4. 把 API 金鑰加入 exercism `exercism configure --key=YOUR_API_KEY`
5. 設定 exercism 的來源目錄 `exercism configure --dir=C:\src\exercises`
6. [取得你的第一個練習](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. 在 Visual Studio 中開啟 Exercism 方案
8. 展開 Exercism.coffeescript 專案
9. 在 Solution Explorer 中點選 **Show All Files**（見下圖）
10. 你剛才取得的練習會以灰色顯示。在該資料夾上按右鍵，然後選擇 **Include In Project**
11. 開始寫程式吧！

![Add files](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

若要在 Visual Studio 中使用 CoffeeScript，你應該安裝 [Web Essentials](http://vswebessentials.com/) 擴充功能。它也會讓使用 JavaScript 變得容易許多。

你可以用專案裡的批次檔，從 Node.js 命令列執行單元測試。

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

如果執行測試時沒看到任何輸出，你很可能不在 Node.js 命令提示字元裡。
