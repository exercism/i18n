# 百分比或「舊式」格式化

這份解答對字串使用了`%%-formatting`或[舊式格式化][old-style formatting]。

`%%-formatting`雖然是完全可行的做法，但可能產生呈現方式或可讀性上的問題。使用 [str.format()][str.format()] 方法或 [f-strings][f-strings]（_也就是所謂的「formatted string literals」或「interpolated strings」_），能提供一些選項來提升可讀性，並讓字串內的變數替換更加清楚。

部落格文章 [String Formatting in Python][string formatting in python] 是了解 Python 所有字串格式化選項的絕佳起點，而 [Newer Python String Format Techniques][newer python string format techniques] 也提供了一些使用`str.format()`和`f-strings`的實用技巧。
