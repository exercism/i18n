# 簡介

在 SQL 中，`SELECT`敘述能讓你從資料庫擷取資料。
`SELECT`敘述的結果稱為結果集（result set）。
結果集包含以資料列和資料行排列的值。
每個資料行代表資料的某個特定屬性。
每個資料列則包含每個資料行對應的值。

你可以這樣想：一組資料行就代表一種資料結構，其中每個資料行是該資料結構的一個欄位，而每個資料列則是該資料結構的一個實例。

透過`SELECT`敘述，你可以指定想擷取的資料。
你還可以選擇性地轉換、篩選，或修改輸出資料的形狀。

## 基礎

基本`SELECT`敘述的結構如下：

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM`和`WHERE`子句都是選用的。
例如，像`SELECT "Hello, world.";`這樣的敘述完全合法。

另外也請注意，換行並不是必要的；只要有任何空白，就足以區隔`SELECT`敘述中的各個子句（也就是各個部分）。
~~~~

緊接在`SELECT`關鍵字之後的，是你希望在結果中出現的資料行清單。
`FROM`子句指出資料的來源，通常是資料庫中的一張資料表。
`WHERE`子句則依據一或多個條件篩選輸出的資料。

## 用 WHERE 子句篩選資料

`WHERE`子句可以讓你篩選`SELECT`敘述取回的資料。
例如，如果只要 Appliances 類的資料，可以這樣寫：

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

結果：
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

或者，只想取出重量介於 2.0 和 6.0 之間的資料：

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

結果：
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

除了`=`和`BETWEEN...AND`之外，`WHERE`子句還支援各式各樣的運算式，包括比較（`<`、`<=`、`>`、`>=`）、樣式比對（`LIKE`、`GLOB`、`REGEXP`、`MATCH`），以及檢查是否屬於某個清單（`IN`、`NOT IN`）。
完整的說明請參閱 [SQL Language Expressions](sql-expr)。
