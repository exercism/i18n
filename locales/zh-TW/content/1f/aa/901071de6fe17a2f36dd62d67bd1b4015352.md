玩家會在地圖上四處移動，一邊走一邊撿拾寶藏。
寶藏和地點的座標格式刻意不同，好增加一點挑戰性。
另外還有一些特殊地點，在那裡特定的寶藏可以兌換成其他特定的寶藏，為遊戲增添額外的變化。
你的任務就是撰寫函式，幫他們完成這款遊戲。

## 1. Convert locations

實作 `placeLocationToTreasureLocation` 函式，它接受一個地點座標（例如 `('C', 1)`），並將其轉換成寶藏座標（例如 `(1, 'C')`）。

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. Compare Treasure and Place locations

實作 `treasureLocationMatchesPlaceLocation` 函式，它接受一個 `PlaceLocation`（例如 `('C', 1)`），如果符合 `TreasureLocation`（例如 `(1, 'C')`），就回傳 true。

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. Count Treasure Locations

實作 `countPlaceTreasures` 函式，它接受一個地點（例如 `("Aqua Lagoon (Island of Mystery)", ('F', 1))`）和寶藏陣列，並回傳在該地點能找到的寶藏數量。

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. Special Places

實作 `specialCaseSwapPossible` 函式，它接受一個寶藏（例如 `("Amethyst Octopus", (1, 'F'))`）和一個地點（例如 `("Seaside Cottages ", ('C', 1))`），並在下列組合中回傳 true：

- Brass Spyglass 可以在 Abandoned Lighthouse 兌換成任何其他寶藏
- Amethyst Octopus 可以在 Stormy Breakwater 兌換成 Crystal Crab 或 Glass Starfish
- Vintage Pirate Hat 可以在 Harbor Managers Office 兌換成 Model Ship in Large Bottle 或 Antique Glass Fishnet Float

試著把這個函式實作成帶有臨時元組的 case 敘述，而不要使用 `if` 敘述（這是 Elm 中常見的慣用寫法）。
