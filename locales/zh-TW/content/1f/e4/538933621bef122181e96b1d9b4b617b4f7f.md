# 簡介

## 字典

字典是一種元素的集合，每個元素都由一個鍵和一個值組成；如果把某個鍵傳給字典的方法，就會回傳它對應的值。它在其他語言裡的角色，就相當於映射或關聯式陣列。

字典可以這樣建立：

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

或是

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

注意，鍵和值的型別是字典定義的一部分。

字典建構完成之後，可以透過它內建的方法`Add`和`Remove`來新增或移除項目。

要取得或更新字典裡的值，可以用鍵來對字典進行索引：

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

你可以這樣測試某個值是否存在於字典中：

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

列舉字典時，會列舉它的鍵/值對。字典也有屬性，可以讓你列舉它的鍵或值。
