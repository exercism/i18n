# 補充說明

## 例外訊息

有時候，我們會需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做的時候，記得一定要附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。這能讓你的程式碼更容易閱讀，對除錯也有很大的幫助。如果你知道錯誤來源會是某種特定的型別，可以選擇引發其中一種[內建的錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習特別要求你，當給定的值無法在陣列中找到時，使用 [raise 陳述句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「拋出」一個 `ValueError`。只有同時`raise`這個`exception`並附上訊息，測試才會通過。

若要引發帶有訊息的`ValueError`，請把訊息寫成`exception`型別的引數：

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
