# 簡介

## 原子

Elixir 的`atom`型別代表一個固定的常數。原子的值就是它本身的名稱。這讓我們能以型別安全的方式與資料互動。原子可以像這樣定義：

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_原子_在內部是由查表中的整數表示，這些整數會自動設定。我們無法改變這個內部的值。

## Cond

我們經常會想寫出能根據條件分支的程式碼。在 Elixir 中雖然有很多種做法，但最簡單的方法之一就是使用`cond/1`。

最簡單的情況下，`cond`可以有一或多個分支，並且會採用第一個評估為`true`的路徑：

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

如果沒有任何路徑評估為`true`，執行環境就會引發錯誤。
