# Null

Null 是一種原始型別，只有一個值：`null`。
Null 常用來表示空無。
它被視為「假值」，但與`false`及其他假值不同。

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## 處理 null 值

在 PHP 中，null 值常常是錯誤的來源，因為函式經常以回傳 null 來代替錯誤狀態，或表示空無。
為了避免錯誤發生，通常需要進行「null 檢查」，在操作值之前先確認它不是 null。

反覆進行 null 檢查很容易出錯，因此 PHP 提供了兩個處理 null 值的運算子：null 安全存取運算子`?->`，以及 null 合併運算子`??`。
