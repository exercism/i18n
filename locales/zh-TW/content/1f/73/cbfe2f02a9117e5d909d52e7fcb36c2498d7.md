# 關於

`while`和`until`（位於 [`kernel`][kernel]）是以 quotation 驅動的迴圈組合子，適合用在事先不知道會疊代幾次的情況：

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

只要 `pred` 留下真值，`while` 就會繼續執行；只要 `pred` 留下 `f`，`until` 就會繼續執行。兩者都會在述詞翻轉時停止並回傳。

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

當堆疊上流動的單一值不足以表示狀態時（例如同時需要剩餘的陣列、累計總和和計數器），最簡潔的做法是使用具名的*區域變數*，讓程式更清楚。區域變數在後續的課程大綱中會有更完整的介紹；在這裡只要知道`:: word ( a b -- c )`會把輸入宣告成具名區域變數，而`:> name!`則會新增一個可變的區域變數，讓主體可以用`value name!`更新它。

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
