# 關於

檔案是磁碟上一個有名稱的串流。[`io.files`][io.files] 詞彙表提供兩種操作方式：能在單次呼叫中讀取或寫入全部內容的整檔便利詞彙，以及用來逐步讀寫的串流開啟工具（`with-…` 組合子）。兩者都和 `io-streams` 概念的記憶體內串流一樣，建立在同一套[串流協定][stream-protocol]之上：`<file-reader>` 和 `<string-reader>` 會回應相同的詞彙。

每個檔案詞彙都會接受一個**編碼**，也就是在位元組和字元之間來回對應的規則。處理文字時，這幾乎總是 `io.encodings.utf8` 的 [`utf8`][utf8]；處理二進位資料則使用 `latin1` 或 `<byte-array>` 編碼。

## 整檔讀取

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` 會把整個檔案以單一字串回傳。`file-lines` 則以陣列回傳檔案的每一行，並去掉行終止符，當每一行都是一筆記錄時特別好用。

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## 整檔寫入

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

兩者都會**取代**檔案，若檔案不存在則會建立它。`set-file-contents` 會原樣寫入一個字串；`set-file-lines` 則把序列中的每個元素寫成獨立的一行，並自動補上換行。

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## 具作用域的串流

當你想在檔案中追加內容，或逐段讀寫時，用 `with-…` 組合子開啟檔案，並在 quotation 內使用環境中的串流詞彙：

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

`with-file-writer` 會先清空檔案；`with-file-appender` 則保留現有內容，並寫在它們之後。每一個都是解構子作用域：即使 quotation 拋出例外，檔案控制代碼也會在 quotation 結束時關閉。這和 `boatswains-bilge` 組合子提供的保證相同，只是這裡專門用在檔案上。

## 該用整檔還是具作用域的寫法？

當檔案小到可以放進記憶體，而你想一次拿到全部內容時，就用 `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines`。當你需要追加內容、用 `readln` 一行一行串流處理大型檔案，或交錯進行讀取和寫入時，就用 `with-…` 開啟工具；凡是把整個檔案放進記憶體會浪費或不可行的情況，都適用這些工具。
