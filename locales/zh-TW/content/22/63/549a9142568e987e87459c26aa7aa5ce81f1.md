# 簡介

Clojure 中的 `vector` 是一種有序、有索引且不可變的集合，可以包含零個或多個值。這表示一旦建立向量之後，就無法修改它。用來操作向量的函式會回傳一個新的向量，而原本的向量則保持不變。向量中的值可以有不同的型別。向量可以這樣定義：

```clojure
(def empty [])
(def single-value [5])
```

可以使用索引從向量中取出元素。Clojure 的向量以零為起始，也就是說第一個元素的索引一定是零：

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

原本的向量不會改變：

```clojure
numbers
;;=> [2 3 5]
```

如果想記住更新後的值，就需要把它傳遞下去，或存進 var 裡：

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
