# 關於

C++ 內建的數字型別可以分為整數和浮點數兩類。
整數是像 `0`、`691` 或 `-2` 這種沒有小數部分的數字。
浮點數則是帶有小數點的數字，例如 `6.02214076`、`0.1` 或 `-1.616`。

## 整數

下面的範例展示了四個不同變數的宣告與初始化

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

當你指定值給 `int` 變數時，可以直接用字面值來指定。
字面值就是像 `9241` 這樣直接寫在程式裡的數字。
針對不同的進位表示法，有不同的整數字面值。
十進位整數字面值最為常見，使用 `0` 到 `9` 這些數字。
只要加上像 `0x` 這樣特殊的前綴，就能使用其他進位。
上面的範例展示了數字 `9421` 的四種表示法與前綴。
所有變數都初始化為相同的值。

想更深入了解各種表示法系統的細節，可以參考[這份小型教學][cpp_numerical_bases]。

你可以用單引號分隔數字，讓它更容易閱讀。
`9'241` 等同於 `0b0100'100'0001'1001` 或 `92'4'1`。

## 浮點數

浮點數字面值有兩種形式。
除了直觀的 `0.0024`，也可以使用它的科學記號 `2.4e-3`。
最常見的浮點數型別是 `double`。

## 算術運算

C++ 支援 `+`、`-`、`*`、`/`、`(`、`)` 和 `%` 來組成運算式。
兩個整數之間運算的結果也是整數。
`5 / 2` 會回傳 `2`。
當參與運算的其中一個型別是浮點數型別時，結果也會是浮點數。
`5.0 / 2` 和 `5 / 2.0` 會回傳 `2.5`。
`%` 是取餘數運算子，會回傳整數除法的餘數：`5%3` 是 `2`。

## 賦值運算子

賦值運算子會用字面值來指定變數。
永遠由右至左進行，絕不會反過來。

```cpp
int length = 5;
int width = 2;
length = width;
```

這裡整數值 `5` 被指定給變數 `length`。
接著整數值 `2` 被指定給變數 `width`。
最後 `width` 的值被複製到變數 `length`，先前的值 `5` 就消失了。
另外要注意，我們只是在賦值運算的那一刻，把 `width` 的值指定給 `length`。
因此，如果 `width` 的值之後改變了，也不會影響 `length` 所持有的值。

賦值運算子可以和其他運算子（算術與位元運算）結合，也就是所謂的 `compound assignment` 運算子 `+=`、`-=`、`*=`、`/=`、`%=`。
這些運算子會對變數目前的值進行運算，藉此加以修改。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

變數 `people` 和 `eggs` 初始化為 `0`。
接著，我們把整數值 `2` 加到變數 `people` 現有的值 `0` 上，再指定回 `people`。
`people`現在變成 `2`。
之後，我們為每個人加上 `3` 顆蛋，總共是 `6` 顆蛋。
現在把這個 `6` 加到變數 `eggs` 現有的值 `0` 上，再指定回 `eggs`。
`eggs`現在會是 `6`。
等效的運算式會是 `people = people + 2` 和 `eggs = eggs + (3 * people)`。

## 型別轉換

型別轉換就是把一種型別轉成另一種型別。
如果需要 `double`，可以用 `int` 來代替。
上面 `5.0 / 2` 的例子，就是靠把 `2` 隱式轉換成 `2.0` 來處理。
把 `double` 轉型成 `int` 可能會遺失資訊。
比較好的做法，是用 `static_cast<T>` 明確地把值轉型成另一個型別 T。
現代 C++ 不鼓勵使用舊式的 C 風格轉型 `(T)`，但仍應該知道它的存在。

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## 精確度與表示法

C++ 中的數字不能無限大。
例如 `int` 以 32 位元表示。
這樣足以表示 `2^32` 個數字，大約 40 億。
包含 `0` 在內，這設定了 `int` 的最大值與最小值為 `-2^31` 和 `2^31 - 1`。

浮點數通常以 15 位小數的精確度來實作，但實際的表示法會因主機系統而異。
