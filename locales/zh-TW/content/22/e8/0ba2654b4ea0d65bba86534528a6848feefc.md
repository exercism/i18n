# 關於

[Reason](https://reasonml.github.io/) 是一套為 JavaScript 開發者設計的語法與工具鏈，以函式語言 [OCaml](https://ocaml.org/) 為基礎。

Reason 採用靜態型別，通常比 JavaScript 更安全；它擁有強大的型別推論能力，因此型別標註不會妨礙你。

Exercism 的練習會直接編譯成 JS，但 Reason 也能透過 OCaml 工具鏈編譯成原生程式碼、IoS、Android，甚至是[微控制器](http://www.algo-prog.info/ocapic/web/index.php?id=ocapic)。
