# 簡介

Python 中的`str`是 [Unicode 碼點][unicode code points]的[不可變序列][text sequence]。
這些字元可能包含字母、變音符號、定位字元、數字、貨幣符號、表情符號、標點符號、空白與換行字元等等。

字串支援所有[常見序列操作][common sequence operations]，也可以使用`for item in <string>`或`for index, item in enumerate(<string>)`語法來疊代。

字串可以用`<str> + <other str>`或`<str>.join(<iterable>)`串接，也可以用`<str>.split(<separator>)`分割。
字串還提供多種額外的格式化、組合與樣板選項。

因為不可變，`str`物件在記憶體中的值不會改變；看似會修改字串的方法，實際上會回傳新的副本或`str`實例。

Python 的官方文件也提供了非常詳細的 [Unicode HOWTO][unicode how-to]，其中討論了 Python 對 Unicode 規格的支援（在`str`、`bytes`和`re`模組中）、地區設定的考量，以及一些常見的編碼與轉譯問題。
