# 關於

Gleam 中的陣列是零個或多個值的不可變集合。陣列中的值都必須具有相同的型別。由於陣列是不可變的，一旦建立完成，它的值就永遠不會改變。任何看似會修改陣列的函式或運算子（例如新增元素），實際上都會回傳一個新的陣列。

陣列可以這樣定義：

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

要把元素加入陣列，最常見的方式是使用展開語法將它加到最前面：

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam 標準函式庫中的 [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) 模組包含許多處理陣列的實用函式。這個模組在 Gleam 程式碼中非常常用，所以熟悉它很有幫助。

陣列模式可以用在 case 運算式中比對陣列，並將其中包含的值指定給變數：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

除了比對長度完全相符的陣列之外，展開語法也可以用來比對至少有特定長度的陣列：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

展開語法也可以用來將陣列其餘的部分指定給變數：

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

case 運算式應該為被比對型別的每個可能值都準備一個模式，因此通常會用最後的忽略模式（`_`）來處理所有剩下的值。
