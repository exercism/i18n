# 簡介
## Switch

[switch 敘述][switch] 讓你可以把一個值與多個可能的相符值做比較。相較於使用多個 `else-if` 敘述，它能讓你寫出更精簡的程式碼。switch 敘述以 `switch` 關鍵字開頭，後面接著要比較的值。接著你可以用 `case` 關鍵字定義各種情況，後面接著要比對的值。當沒有任何情況相符時，會用 `default` 關鍵字定義預設情況。和 `else-if` 敘述一樣，`switch` 敘述只會執行第一個相符情況所對應的程式區塊。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

來看看下面這個例子：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

也可以改寫成：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## While 迴圈

[while 迴圈][while-loops] 是一種控制流程敘述，讓程式碼在特定條件為真時持續執行。Swift 提供兩種 while 迴圈：while 迴圈和 repeat-while 迴圈。while 迴圈的條件會在迴圈主體執行前先求值；如果條件為假，迴圈主體就完全不會執行。Swift 裡的 while 迴圈結構如下：

```swift
while <#condition#> {
  <#code#>
}
```

這裡的迴圈會在 count 大於 0 時持續執行，因此會依序印出數字 2、1 和 "Liftoff!"。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[repeat-while 迴圈][while-loops] 和 while 迴圈類似，但條件是在迴圈主體執行後才求值。這代表迴圈主體至少會執行一次，即使條件為假也一樣。Swift 裡的 repeat-while 迴圈結構如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

這裡的迴圈只會執行一次，因為條件為假。由於它是 repeat-while 迴圈，迴圈主體會在條件求值前先執行一次。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 控制轉移

Swift 有一組敘述可以用來改變迴圈正常的控制流程。這些敘述稱為控制轉移敘述。你已經看過 `return`；這個概念會介紹其他的，包括 `continue`、`break` 和標籤。這個概念不會涵蓋 `fallthrough`，但你可以在 [Swift 書籍][fallthrough] 中讀到相關內容。

### Continue

有時候需要提早跳到迴圈的下一次疊代，而不完成目前這次疊代中其餘的敘述。這時可以使用 `continue` 關鍵字。執行 `continue` 時，迴圈會跳到下一次檢查，看看是否能執行下一次疊代，也就是 while 和 repeat-while 迴圈中的 `while`，或是 for-in 迴圈中檢查序列裡是否還有下一個元素。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

break 用來提早離開迴圈。執行 `break` 時，迴圈會立刻結束，程式會繼續執行迴圈後面的第一個敘述。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### 標籤

當迴圈形成巢狀時，有時會想用 `break` 或 `continue` 來離開或重新開始外層迴圈。這些外層迴圈包住使用 `break` 或 `continue` 的那個迴圈。在這種情況下，可以用標籤指定要離開或重新開始的迴圈。只要在開始迴圈的 `while`、`repeat` 或 `for` 前面放上名稱加冒號，就能為迴圈加上標籤。

想看看這樣使用標籤的效果，請看下面這個迴圈。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
