# 測試

  ## 快速總覽

  1. 在`<myFileName>.u`檔案中進行修改
  2. 儲存`<myFileName>.u`檔案
  3. 如果檔案通過型別檢查，就執行`add`或`update`這些 UCM 指令
    * 如果檔案沒有通過型別檢查，請修改`<myFileName>.u`檔案中的程式碼，直到它能編譯為止。修改之後，別忘了`update`你的函式喔！
  4. 在 UCM CLI 中執行`load <myFileName>.test.u`指令，把測試帶入範圍並執行它們

  ## 逐步操作

  如果你在命令列上解 Exercism 的題目，你很可能會在與該練習同名的目錄中實作你的解答。舉例來說，如果練習是`hello-world`，你應該先在命令列中`cd`到`~/exercism/unison/hello-world`，再開啟`ucm`。在`hello.u`檔案中進行實作修改，當你對自己的實作感到滿意時，就在 Unison 程式碼庫管理員 CLI（UCM）中輸入`add`或`update`指令，把你的成果從檔案加入程式碼庫。

  每個練習的測試檔案都以`.test.u`作為副檔名。你會想在 UCM 中使用`load`指令，把測試帶入範圍並執行它們。`load`指令會接收檔案路徑作為引數。以 hello world 練習為例，看起來可能像這樣：

  ```
  .> load hello.test.u
  ```

  你應該會看到 UCM 顯示一則訊息，說明有哪些詞彙被帶入範圍，更重要的是，還會顯示測試執行的結果：

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  假設你的測試第一次沒有通過。切回去編輯你的`myExercise.u`檔案，儲存之後就可以`update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  接著我們可以重新載入測試，看看有沒有任何改變！

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
