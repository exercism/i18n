# 除錯

為了幫助除錯，你可以善用一點：所有主控台輸出都會被擷取並顯示在測試結果視窗中。
你可以把任何值傳給`@show`來輸出。

`@show`會顯示一個運算式及其結果，同時回傳它的結果。

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

你也可以使用[`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println)或任何其他將輸出寫入[`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout))的方法。
