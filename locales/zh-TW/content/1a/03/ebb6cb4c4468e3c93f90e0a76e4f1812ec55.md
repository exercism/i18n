# 指示

在這道練習中，你要實作一個程式，判斷一場[井字遊戲][tic-tac-toe]的狀態。
（_你可能也聽過這個遊戲叫「noughts and crosses」或「Xs and Os」。_）

遊戲在 3×3 的方格上進行。
玩家輪流在方格上放置`X`和`O`。
當某位玩家在方格的橫列、直行或對角線上連成 3 個記號而獲勝，或是整個方格被填滿時，遊戲就結束。

在這道練習中，我們假設由`X`先下。

你的任務是判斷給定的遊戲處於哪一種狀態。

遊戲狀態有 3 種可能：

- 遊戲是**ongoing**。
- 遊戲以**draw**收場。
- 遊戲以**win**收場。

如果給定的棋盤不合法，請拋出適當的錯誤。

棋盤符合下列任一條件時，就是不合法：

- 按照正確的順序輪流下棋時，無法得到這個棋盤（別忘了是由`X`先下）。
- 遊戲結束後仍然繼續下棋。

## 範例

### 遊戲進行中

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 平手

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 勝利

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 不合法

#### 下棋順序錯誤

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 勝利後繼續下棋

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```

[tic-tac-toe]: https://en.wikipedia.org/wiki/Tic-tac-toe
