# 指令

在這個練習中，你會寫程式來追蹤你想在 Exercism 上學習的程式語言陣列。
這個練習有六個任務，全都和處理陣列有關。

## 1. 建立新的陣列

為了追蹤你想學習的程式語言，你需要建立一個新的陣列。
定義`newList`常數，它包含一個新的空陣列。

```elm
newList
    --> []
```

## 2. 定義現有的陣列

目前你有一張紙，上面列出了你想學習的語言：Elm、Clojure 和 Haskell。
定義`existingList`常數來表示這個陣列。

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. 將新的語言加入陣列

當你在 Exercism 上探索、發現更多有趣的程式語言時，會想把它們加到你的陣列裡。
實作`addLanguage`函式，把新的語言加到陣列開頭。

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. 計算陣列中的語言數量

手動計算語言數量很不方便。
實作`countLanguages`函式，計算你的陣列裡有幾個語言。

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. 反轉陣列

某個時刻，你會發現你的陣列其實是反過來排的！
實作`reverseList`函式來反轉你的陣列。

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. 檢查陣列是否令人興奮

雖然你喜歡所有的程式語言，但 Elm 在你心中有個特別的位置。
因此，只要符合以下條件，你就會對一份程式語言陣列感到興奮：

- 陣列的第一個元素是 Elm。
- 或者陣列的第二個元素是 Elm，而且陣列包含三個或更少的語言。

實作`excitingList`函式，檢查一份程式語言陣列是否令人興奮：

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
