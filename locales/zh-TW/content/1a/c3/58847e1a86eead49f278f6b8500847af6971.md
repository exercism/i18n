# 提示

## General

- `MACRO:`位於 [`macros`][macros]。這些積木分別位於 `kernel`（`dup`、`curry`）、`sequences`（`append`、`concat`、`<repetition>`、`map`）以及 `quotations`（`>quotation`）。
- 巨集的主體必須在堆疊上留下**一個 quotation**。如果你的主體產生的是程式碼陣列，結尾要用 `>quotation`。
- 想驗證自己的想法，可以在 listener 中對一個字面值執行主體裡的詞，再看看拿回來的 quotation 是什麼。它應該就是題目「compiles to」那一行所寫的直線程式碼。

## 1. 重複兩次

- 你會拿到 `[ A ]`，想要得到 `[ A A ]`。複製一份再連接起來：`dup append`。

## 2. N 次重複

- 你會拿到 `[ A ] n`，想要得到連接在一起的 `n` 份複本。
- `<repetition>` 會做出那些複本，但它的堆疊效果是 `( length elt -- repetition )`，因此數量必須在堆疊頂端，所以要先用 `swap`。
- 接著攤平並轉換：`swap <repetition> concat >quotation`。

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. 組合多個

- 你會直接拿到 quotation 的陣列，只要把它攤平成一個就好。整個主體就是 `concat >quotation`。

## 4. 展開的疊代

你會拿到一個序列和一個 quotation，例如 `{ 10 20 30 } [ + ]`，想要得到 `[ 10 + 20 + 30 + ]`。用三個步驟把它組出來。

**單一元素。** 把元素預先綁進 quotation 裡，正是 `curry` 在做的事：

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**每個元素。** 你想把這個做法 `map` 到整個序列上，但 `map` 只會傳給負責對應的 quotation 一個輸入（也就是元素），而你每次還需要手邊有 `[ + ]`。所以先用 `curry` 把 `[ + ]` 綁進那個對應的 quotation：

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` 讀作「推入小小的 quotation `[ curry ]`，再把 `[ + ]` curry 進去」，結果是 `[ [ + ] curry ]`。把 `map` 套用到元素 `e` 上，就會執行 `e [ + ] curry`，也就是 `[ e + ]`。

**連接起來。** 和其他任務一樣的收尾：

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- 整個主體就是：`[ curry ] curry map concat >quotation`。
