# 簡介

## 背景

字串就是一段以引號包住的文字。
目前仍受支援的 R 版本都以 UTF-8 編碼字串，因此世界上大多數語言都能獲得支援。

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

可惜的是，對熟悉其他語言的程式設計師來說，這裡的術語可能會讓人一頭霧水。

雖然 `type`是`character`，但 R 並不區分單一字母（在其他幾種語言裡叫 `char`，但在 R 裡_不是_）和長字串。
兩者都是單一項目，可以互換地使用單引號 `' '` 或雙引號 `" "` 包住。

風格指南建議使用雙引號，除非你想在字串裡直接用雙引號而不跳脫它們。

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

因此，`character vector`就是一串字串組成的向量，每個字串都是單一元素。

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

在上面的例子裡，`length(s[1])`等同於`length("some")`：它算的是_向量元素_的數量，而不是_字串長度_。

要操作單一字串當然做得到，就像上面例子裡的 `nchar()`那樣，但這需要特定的函式，稍後會再討論。

### 字串函式

在 base R 裡，_幾乎什麼都做得到_，但許多程式設計師覺得它對字串操作的支援相當有限又令人困惑。

幸好，`tidyverse`系列套件直覺得多、更有彈性，也更一致。

### base R

仍有大量舊程式碼使用舊式的字串函式。
Exercism 上大多數社群解答也是如此。

此外，對於小型任務，使用內建函式而不匯入大型套件庫可能更方便。
R track 的維護者在撰寫範例解答來驗證練習時，通常也採用這種做法。

因此，了解一下舊做法還是值得的。

#### `nchar`

回傳字串中的字元數。

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

「字元」到底是什麼，這個（_很複雜！_）話題超出了本文的範圍。
只要注意上面例子裡的幾個重點就好：

- 雖然 R 內部是以 C 實作，但 R 的字串並不是以 `\0` 結尾（那樣會讓長度多 1）。
- 多位元組的 Unicode 字元會如你所期望（或希望）地處理。「Hrōðgār」有 7 個字元（也稱為「符文」或「碼位」），但儲存時需要 10 個位元組。

#### `paste` 與 `paste0`

把任意數量的字串合併成單一字串。

`paste`可以選擇性地指定分隔符，預設是空格。

`paste0(v)`等同於`paste(v, sep = "")`。

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

若想更精細地控制字串的組合方式，R 是從 C 沿用 `sprintf`這個函式（後來也有好幾種語言跟進：維基百科[列出][wiki-printf-ports]了大約 30 種）。

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

開頭和／或結尾的空白可以用 `trimws()`移除：

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

有個 `which = "left"`（或 `"right"`）參數，可以只修剪其中一端。

#### `substr`

作用在單一字串上，回傳兩個（含端點）界限之間的子字串。

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

依照分隔字串，把字串拆分成 R 的陣列。
分隔符是必填的（沒有預設值），但可以是空字串。

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

陣列會在另一篇[概念][concept-lists]中介紹。
如果你還沒讀到課程大綱的那個部分，現在只要知道 `unlist()`函式（在這個例子裡）會把陣列轉成向量就好。

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

客氣一點地說，舊式字串函式並不是 R 最引以為傲的部分（_也可以有不那麼客氣的說法_）。

為了改善這種情況，`stringr`套件庫從 2009 年就開始開發，如今已是 Tidyverse 系列的核心成員。

用 `library(stringr)`或 `library(tidyverse)`將它載入你的命名空間。

幾個主要特色包括：

- 所有函式名稱都有 `str_`前綴，並盡量讓用途一目了然。
- 引數的順序盡量保持一致，把輸入資料放在第一個引數。
- 輸入可以是單一字串，也可以是複雜的資料結構。函式會盡量配合，做出最合理的處理。

和所有 Tidyverse 套件一樣，`stringr`有完善的文件，通常由套件作者親自撰寫。

- [參考網站][ref-stringr]
- [速查表][cheat-stringr]
- 《R for Data Science》裡的[一章][book-strings]。

#### 岔題：管道快速入門

用管道 `|>`串接函式的做法，會在課程大綱的其他部分更詳細地討論。

現在只要知道以下幾點就很有幫助：

- 管道左邊的結果會成為右邊函式的第一個引數（這裡的「右邊」會忽略可有可無的換行）。
- 其餘的引數可以一併寫在函式呼叫裡。
- 在 R 裡，管道後面必須接函式的_呼叫_，不能只接_名稱_，所以括號一定要寫（_這點和其他一些語言不同_）。

下面的例子示範了這種語法。
個別函式稍後會再討論。

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### 管理長度

`str_length`計算的是碼位（類似 `nchars`）。

還有其他各種處理空白的函式，包括 `str_trim()`和 `str_squish()`。
在任何資料科學專案一開始，這往往是不可或缺的清理工作。

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### 擷取子字串

`str_sub(string, start, end)`函式會回傳從 `start` 到 `end`（含端點）的子字串，而 `str_sub_all()`可以一次處理多個字串。

用法非常有彈性。
`start` 和 `end` 預設分別是第一個和最後一個字元。
它們可以是索引組成的向量。
和向量索引不同的是（這點令人欣慰），負數會從字串結尾往回算，就像 Python 那樣。

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### 連接字串

`str_flatten`會把字元向量轉成單一字串。
`collapse` 引數會插入每個元素之間，預設是 `""`。

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c`會把多個字元向量轉成單一的字元向量，必要時會自動循環重用較短的元素。

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue`為 R 帶來簡單的字串插值。
大括號 `{ }` 裡的運算式會被求值，並以文字表示取代。

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### 拆分字串

R 一個很常見的用途，就是把雜亂的資料整理成一致的格式以便分析。
為了幫上忙，R 提供了好幾種把文字拆成子字串的方法。
大部分都超出本文範圍。

`str_split_1`最簡單，它會把單一字串依指定的模式拆成由片段組成的向量（沒有預設模式）。

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### 變換字串

有些語言（主要是歐洲語言）會區分大寫和小寫字母。
`stringr`提供了一組函式，可以依地區設定用合適的方式在兩者之間轉換：

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()`：把每個字的第一個字母轉成大寫
- `str_to_sentence()`：把句子的第一個字母轉成大寫

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

若要依模式比對來取代子字串，`str_replace()`會替換第一個符合模式的地方，`str_replace_all()`則會替換所有符合的地方。

若要依字元索引來取代子字串，str_sub() 有一種賦值的形式。

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
