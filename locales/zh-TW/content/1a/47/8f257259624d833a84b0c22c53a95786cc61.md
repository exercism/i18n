# 關於

Factor 的[`calendar`][calendar]詞彙圍繞兩個元組建構：

- `timestamp`，時間中的一個點（`year`、`month`、`day`、`hour`、`minute`、`second`，以及 GMT 位移）。
- `duration`，一段時間（同樣的欄位，但當成數量使用）。

## 時間戳記

`<date>`會建立一個午夜的時間戳記；`>date<`則把時間戳記拆開：

```
<date> ( year month day -- timestamp )
>date< ( timestamp -- year month day )
```

```factor
USING: calendar ;

2024 7 14 <date> >date< .   ! => 14   (2024 and 7 below it)
```

常見的查詢：

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1   (0 = Sunday .. 6 = Saturday)
2024 1 8 <date> day-of-week day-names nth .   ! => "Monday"
2024 leap-year? .                      ! => t
2024 2 1 <date> days-in-month .        ! => 29
```

`day-names`（以及 `month-names`）位於[`calendar.english`][english]裡。

## 持續時間與運算

像是 `days`、`weeks`、`hours` 和 `minutes` 這類詞會建立 `duration`，而 `time+` / `time-` 則用持續時間來推移時間戳記：

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .   ! => 29   (2024-02-29)
```

運算會跨越月份和年份的界線進位，而兩個指向同一時刻的時間戳記用 `=` 比較時會相等。

除此之外，`calendar` 還提供一日中的時刻（`set-time`、`+hour`）、時區轉換（`>gmt`、`>local-time`）、目前時間（`now`），以及透過 `calendar.format` 提供的剖析與格式化。
