# 指令

在這個練習中，你將會處理日誌行。

每一行日誌都是格式如下的字串：`"[<LVL>]: <MESSAGE>"`。

以下是不同的日誌等級：

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

你有 3 個任務。

## 1. 解析日誌等級

定義一個`LogLevel`列舉，其中包含 6 個元素，分別對應上述的日誌等級。

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

接著，實作（_static_）`LogLine.ParseLogLevel()`方法，用來解析日誌行的日誌等級：

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. 支援未知的日誌等級

很遺憾，偶爾會有些日誌行帶有未知的日誌等級。為了優雅地處理這些日誌行，請在`LogLevel`列舉中新增一個`Unknown`元素；解析到未知的日誌等級時，就應該回傳這個元素：

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. 將日誌行轉換成簡短格式

日誌行的日誌等級相當冗長。為了減少儲存日誌行所需的磁碟空間，我們設計出一種簡短格式：`"[<ENCODED_LEVEL>]:<MESSAGE>"`。

編碼後的日誌等級，就是把日誌等級簡單對應到一個數字：

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

實作（_static_）`LogLine.OutputForShortLog()`方法，輸出縮短後的日誌行格式：

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
