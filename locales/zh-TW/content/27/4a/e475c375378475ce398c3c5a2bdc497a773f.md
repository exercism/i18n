# 簡介

在 Go 裡，`map` 是一種內建的資料型態，用來把鍵對應到值。
在其他程式語言中，你可能已經熟悉類似的概念，例如字典、雜湊表、鍵值儲存或關聯式陣列。

以語法來說，`map` 看起來像這樣：

```go
map[KeyType]ElementType
```

另外也要知道，每個鍵都是唯一的，也就是說，對同一個鍵指定兩次值，會覆寫掉該鍵原本的值。

要建立 map，可以這樣做：

```go
  // With map literal
  foo := map[string]int{}
```

或者

```go
  // or with make function
  foo := make(map[string]int)
```

以下是你可以對 map 執行的一些操作

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

如果你試著取得某個不存在於 map 中的鍵的值，它會回傳該值型態的零值。
這可能會讓你困惑，特別是當你的 `ElementType` 的預設值（例如 int 的 0）本身也是個合法的值時。
要確認某個鍵是否存在於 map 中，你可以這樣做

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
