# 介紹

在 Elixir 中，映射是用來以鍵值對儲存資料的資料結構。在其他程式語言中，這類結構也稱為關聯陣列（PHP）、雜湊（Perl 5、Raku）或字典（Python）。

鍵和值可以是任何資料型態，但如果鍵是 atom，我們就能使用簡寫語法。映射在存取或回傳時，不保證項目的順序。

## 字面值形式

空的映射只要用`%{}`就能宣告。如果想在映射字面值中加入項目，可以使用兩種形式：

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

雖然沒有標準格式，但表示鍵值字面值配對時，請選擇一致的方式。

## Map 模組的函式

Elixir 在 _Map 模組_ 中提供了許多處理映射的函式。有些 _Map 模組_ 函式需要傳入一個 _匿名_ 函式，來協助轉換映射。
