# 簡介

某個事物能用自身來定義，這種能力稱為遞迴。在 F# 中，遞迴最常出現在遞迴函式裡，也就是會呼叫自己的函式。

遞迴函式至少需要一個_基礎情況_，以及至少一個_遞迴情況_。_基礎情況_會回傳一個值，不再呼叫函式。_遞迴情況_會再次呼叫函式，並修改輸入，讓它在某個時間點符合基礎情況。

遞迴函式的定義方式和一般函式一樣，只是多了一個`rec`修飾詞。少了這個修飾詞，函式就_無法_呼叫自己，任何嘗試這麼做的行為都會導致編譯錯誤。因此，使用遞迴必須明確選擇加入。

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# 也透過差別聯集支援遞迴型別。遞迴差別聯集的其中一個或多個案例，其資料會參照到這個差別聯集本身。和遞迴函式一樣，遞迴型別也必須有基礎情況。和遞迴函式不同的是，遞迴型別不使用`rec`關鍵字。

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
