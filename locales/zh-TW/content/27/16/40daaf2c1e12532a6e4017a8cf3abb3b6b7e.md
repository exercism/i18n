# 關於

## 簡介

泛型是一種語言功能，能讓程式碼重複使用。舉例來說，無論陣列裡裝的是什麼型別，都應該能計算出它的長度。這就是為什麼`length`函式在其型別簽章中使用了泛型型別參數`a`。

```elm
length : List a -> Int
```

## 型別中的參數

當一個型別對另一個型別泛型時，我們會為那個型別取一個小寫名稱，並稱之為型別參數。常見的例子是`List`、`Maybe`和`Result`這些自訂型別。

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

關於型別參數的名稱，有一點很重要：它們的長度可以超過一個字元。唯一的限制是它們必須是小寫名稱。因此，在有用的時候，我們通常會給它們取有描述性的名稱。

一個型別可以對多個其他型別泛型，因而擁有多個型別參數。在這種情況下，每個獨立的型別都會取得不同的小寫名稱。獨立並不表示它們不能變成相同的型別，只是讓它們可以不同而已。

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

記錄型別別名也可以有型別參數，雖然比較少見。

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## 函式中的型別參數

既然型別可以是泛型的，函式當然也可以。我們可以撰寫處理泛型型別的函式，例如`Maybe.withDefault`。

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

以其他函式作為參數的函式稱為高階函式，而這些函式也可以是泛型的。

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
