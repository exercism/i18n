# Case

[`case`][case]（在其他語言中常被稱為 switch）是一種像 if-else 一樣的控制運算式。
`case`允許串接多個 if-else-if 敘述，可以更具可讀性，也能實現強大的結構。

一個`case`由關鍵字`case`定義，後面接著一個選用的運算式。
接著，針對每個 case，會使用關鍵字`when`，後面接著一個與 case 運算式相比較的運算式。
`when`關鍵字不應相對於`case`關鍵字縮排。
`when`關鍵字之後，是當 case 運算式符合 when 運算式時應該執行的程式碼。
case 允許一個選用的`else`敘述，當沒有其他 case 符合時便會執行它。

case 運算式會被求值，然後與每個 when 運算式相比較。
運算式是使用 [case subsumption 運算子（`===`）][case-subsumption]進行比較。

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Case subsumption 運算子（`===`）

case subsumption 運算子（`===`）與相等運算子（`==`）有點不同。
這個運算子會檢查右邊是否為左邊所描述集合的成員。
這表示每個運算元擺放的位置確實有影響。
運作方式取決於左邊的型別，例如`Range`會檢查右邊是否在該範圍內，而`Object`會檢查右邊是否為`Object`的實例。

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## 使用多個運算式的 case

case 允許在單一 case 中比對多個運算式，每個可能的值以逗號分隔。
只要任一個運算式符合，就會執行該程式碼。
這在單一 case 有多個可能值時很有用。

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## 使用範圍的 case

case 也可以檢查某個值是否在範圍內。
做法是把範圍當作 when 運算式。

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## 沒有 case 運算式的 case

當不需要 case 運算式時，可以將它省略。
這麼做會讓每個 when 運算式都改以真值來判斷。
並讓它們的行為表現得像 if-else-if 敘述。

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## 單行 when

Crystal 允許單行的 case 敘述。
當你有簡單的單行敘述時可以使用。
單行 when 敘述寫成`when <expression> then <statement>.`
而用在 else 敘述時，則寫成`else <statement>`。

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## 使用型別的 case

case 允許搭配型別進行比對。
比較時會使用`is_a?`運算子來檢查變數的型別。
例如，這讓聯合型別中的每個型別都能有一個分支。

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## 隱式物件

case 允許使用隱式物件。
這讓 when 運算式可以是對 case 運算式的方法呼叫。
根據方法回傳的是真值還是假值，決定這個 case 是否符合。

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```

## 窮舉的 case

case 允許窮舉的 case，這表示可以確保所有可能的值都被處理到。
它類似於 when 敘述，但改用`in`關鍵字而非`when`。
當 case 是窮舉的，它不支援任何`when`或`else`敘述。

窮舉的 case 可以用在`Bools`、`Union`型別、`Enum`和`Tuples`上。
後面兩者會在之後的概念中介紹。

窮舉的 case 代表所有可能性都必須被處理，否則會引發編譯錯誤。
以窮舉的 case 處理`Union`型別，類似於非窮舉的 case。

```Crystal
var : (Int32 | String | Bool)
case var 
in Int32
  puts "Int32"
in String
  puts "String"
in Bool
  puts "Bool"
end
```

`Bools`可以使用`true`和`false`關鍵字，以窮舉的 case 來處理。

```Crystal
var : Bool
case var
in true
  puts "True"
in false
  puts "False"
end
```
