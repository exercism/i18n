# 簡介

在 F# 中，`string` 是一種物件，用來表示以一系列 Unicode 字元（字母、數字、標點符號等）構成的不可變文字，定義方式如下：

```fsharp
let fruit = "Apple"
```

字串的操作方式有兩種：呼叫字串的方法，或是使用 `String` 模組的函式。字串一旦建立，它的值就永遠不會改變。任何看似會修改字串的方法或函式，實際上都會回傳一個新的字串。

字串可以用幾種不同的方式串接或格式化。
* 你可以使用 `+` 運算子來串接字串：
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* 你可以使用 `sprintf` 函式來格式化文字，在格式文字中放入佔位符（`string` 用 `%s`），並以引數的形式提供對應的值：
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
