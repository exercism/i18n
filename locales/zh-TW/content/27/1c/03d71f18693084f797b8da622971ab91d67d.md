## 腳本用法

產生測試需要一份本機的 [problem-specifications][problem-specifications] 儲存庫副本。腳本應從根目錄`python`執行，才能正確存取這些練習。

執行`bin/generate_tests.py --help`即可查看使用說明。


## 測試範本

測試範本支援 [Jinja2] 語法，並可從標準資料取得下列情境變數：
- `exercise`：練習的連字號名稱（例如：`two-fer`）
- `version`：標準資料的版本（例如 `1.2.0`）
- `cases`：案例物件的清單，或是由 `cases` 清單組成的清單。關於你正在處理的練習的確切結構，請查閱`canonical-data.json`
- `has_error_case`：指出是否有任何測試案例預期會擲回錯誤（例如：`False`）
- `additional_cases`：結構與 `cases` 類似，但若練習有 `.meta/additional_tests.json` 檔案，就會從中填入內容（範例請見 `exercises/word-count/.meta/additional_tests.json`）

此外，為了方便起見，還加入了下列範本篩選器：
- `to_snake`：將字串轉換成 snake_case（例如：`{{ "CamelCaseString" | to_snake }}` -> `camel_case_string`）
- `camel_case`：將字串轉換成 CamelCase（例如：`{{ "snake_case_string" | camel_case }}` -> `SnakeCaseString` ）
- `error_case`：檢查測試案例是否預期會擲回錯誤（例如：`{% for case in cases%}{% if case is error_case}`）
- `regex_replace`：以正規表示式取代字串（例如：`{{ "abc123" | regex_replace("\\d", "D") }}` -> `abcDDD`）


### 慣例

- 高度重複的範本結構所用的通用巨集定義在`config/generator_macros.j2`。
  - 這些巨集可以用下列方式匯入：
  `{%- import "generator_macros.j2" as macros with context -%}`
- 所有測試範本都應以`{{ macros.footer() }}`結尾。
- 所有 Python 類別名稱都應使用 CamelCase（例如：`TwoFer`）。
  - 使用`{{ "two-fer" | camel_case }}`轉換。
- 所有 Python 模組和函式名稱都應使用 snake_case（例如：`high_scores`、`personal_best`）。
  - 使用`{{ "personalBest" | to_snake }}`轉換。
- 軌道專屬的測試定義在選項檔`.meta/additional_tests.json`。這個檔案定義的 JSON 物件只會有一個鍵`cases`，其結構與`canonical-data.json`中的`cases`相同。
- 在測試檔案中，軌道專屬的測試應放在標準測試之後。
- 軌道專屬的測試應在測試檔案中以這行註解標示：
```
# Additional tests for this track
```


### 版面配置

多數範本看起來會像這樣：

```Jinja2
{%- import "generator_macros.j2" as macros with context -%}
{{ macros.header() }}

class {{ exercise | camel_case }}Test(unittest.TestCase):
    {% for case in cases -%}
    def test_{{ case["description"] | to_snake }}(self):
        value = {{ case["input"]["value"] }}
        expected = {{ case["expected"] }}
        self.assertEqual({{ case["property"] }}(value), expected)

    {% endfor %}

{{ macros.footer() }}
```


### 覆寫匯入

在`macros.header()`中匯入的名稱，可以加入要匯入的替代名稱清單來覆寫（例如：`clock`）：

```Jinja2
{{ macros.header(["Clock"])}}
```


### 忽略屬性

偶爾會需要濾除這個軌道沒有測試的屬性。`header`巨集也接受`ignore`引數（例如：`high-scores`）：

```Jinja2
{{ macros.header(ignore=["scores"]) }}
```

## 建立範本

1. 為你正在實作的練習建立`.meta/template.j2`，
  並在編輯器中開啟它。
2. 將[範例版面配置](#Layout)複製貼到範本檔案中
  並儲存。
3. 對範本檔案做適當的修改，直到它能產生
  有效的測試程式碼；輸入名稱和案例結構請參考
  練習的`canonical-data.json`。
    - 使用[可用的巨集](../config/generator_macros.j2)來避免重寫標準化的區段。
    - 如果你是為現有的練習實作範本，
    不一定要完全符合現有測試檔案的結構，
    但盡量減少差異能讓 PR 審查對所有參與的人都順暢許多。
