# 簡介

## 字元

### 字元

Java 的`char`基本型別以 16 位元來表示單一字元。
多個`char`可以組成一個字串，例如`"word"`，也可以獨立處理每個`char`。
`char`字面值以單引號包住（例如`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

### 取得`String`的字元

`String.toCharArray`方法會將字串的字元以陣列的形式回傳。
如同陣列單元所提到的，你可以使用`for`迴圈疊代整個陣列。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### Character 類別

程式庫中有許多內建方法可以檢查和操作`char`。
這些方法都是`java.lang.Character`類別的靜態方法。
以下是一些例子：

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### 將`char`加入`String`

你可以使用`+`運算子將`char`加入`String`。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
千萬小心，_不要_用`+`把兩個`char`串接成一個`String`！
這樣把兩個`char`相加會得到`int`，_而不是_`String`！
例如：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

這是因為 Java 會將`char`提升為`int`（請參閱《[Java Language Specification][jls-main]》的[4.2 基本型別與值 ][jls-primitives]）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

不過，當要加入的字元很多時，改用`StringBuilder`會更有效率：

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
