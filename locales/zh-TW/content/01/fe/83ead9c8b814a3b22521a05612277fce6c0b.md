# 函式

函式是 Cairo 的根本。

依照慣例，Cairo 的函式和變數名稱使用 **snake case**，也就是單字全部小寫並以底線分隔。

來看一個例子：

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

定義函式時使用 `fn`，後面接著名稱、用於參數的括號（如果有的話），以及以大括號包住的函式主體。

呼叫函式時，寫出函式名稱並在後面加上括號即可。

只要都在作用域內，函式的先後順序並不重要。

## 參數

函式可以接受**參數**，也就是定義在函式簽章裡的變數。

呼叫函式時，你要提供**引數**，也就是傳遞給這些參數的值。

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

這裡，`x` 是型別為 `felt252` 的參數。

以`5`呼叫時，函式會印出「The value of x is: 5」。

多個參數之間以逗號分隔：

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

這會印出：`The measurement is: 5h`。

## 敘述與運算式

Cairo 函式由**敘述**與**運算式**組成：

- **敘述**會執行動作，但不會回傳值。
例如`let x = 3;`就是一個敘述。
- **運算式**會求出一個值。
例如`5 + 6`會求出`11`。

以大括號包住的區塊也是運算式，而且區塊最後的值會被回傳：

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

這裡`y`被指定為`4`。

## 回傳值

函式可以使用 `->` 語法指定回傳型別，藉此回傳值。

預設情況下，函式會回傳最後一個運算式的值：

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

這會輸出：`The value of x is: 5`。

更複雜的情況：

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

這會印出：`The value of x is: 6`。

注意不要在最後一個運算式結尾加上分號，因為那會把運算式變成敘述，導致函式回傳 `()`（單位型別），而不是預期的值。
