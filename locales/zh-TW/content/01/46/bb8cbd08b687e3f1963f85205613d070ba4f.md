# 簡介

條件式是一種敘述，會根據條件是`true`還是`false`，執行不同的程式碼。

`if`敘述只有在條件為`true`時，才會執行它的主體。Go 沒有真值或假值的概念，所以條件必須是`bool`型別。像`if mySlice { ... }`或`if 1 { ... }`這類運算式都會造成編譯錯誤。

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

用`else if`可以檢查更多條件，如果都不符合，就用`else`當作後備。條件是由上往下逐一判斷，只有第一個條件為 true 的分支會執行。

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`敘述也可以包含一段簡短的初始化敘述。用這種方式宣告的變數，作用域僅限於整個`if`/`else`鏈之內。

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
