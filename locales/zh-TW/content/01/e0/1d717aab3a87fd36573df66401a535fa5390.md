# 指令補充

## 輸出格式

將歌詞輸出為以 null 結尾的字串。

## 暫存器

| 暫存器  | 用途         | 型別    | 說明                          |
| ------- | ------------ | ------- | ----------------------------- |
| `$a0`   | 輸入         | 整數    | 起始段落                      |
| `$a1`   | 輸入         | 整數    | 結束段落                      |
| `$a2`   | 輸入/輸出    | 位址    | 以 null 結尾的輸出字串        |
| `$t0-9` | 暫存         | 任意    | 供暫時儲存使用                |
