# 簡介

## 字串

在 F# 中，`string` 是一種物件，用來表示不可變的文字，也就是一連串的 Unicode 字元（字母、數字、標點符號等），定義方式如下：

```fsharp
let fruit = "Apple"
```

字串的操作方式有兩種：呼叫字串本身的方法，或是使用 `String` 模組的函式。字串一旦建立，它的值就永遠不會改變。任何看起來會修改字串的方法或函式，實際上都會回傳一個新的字串。

字串可以用幾種不同的方式串接或格式化。
* 你可以使用 `+` 運算子來串接：
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* 你可以使用 `sprintf` 函式來格式化文字，在格式文字中放置預留位置（`%s` 代表 `string`），並把值當作引數傳入：
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
