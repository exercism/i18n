# 關於

介面可以理解為類別的簽章，因為它描述了類別的 public 欄位。類別會用`implments`關鍵字實作一個`interface`。

它的語法與類別非常相似，差別在於方法是以沒有主體的簽章形式出現：

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

從介面實作的欄位**必須**一律使用相同的可見性修飾子。例如，如果變數`a`在介面中是`public`，它的實作也必須是`public`。
