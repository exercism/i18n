# Debug

你可以使用 [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) 把訊息附加到失敗的測試上，就像這樣：

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

測試失敗時，附加的記錄會是 `secondsInOneHour: 3600`。

有一個要注意的地方：頂層常數只會在測試開始執行前求值一次，因此測試無法捕捉到它們的記錄訊息。例如：

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

在測試期間不會記錄任何東西，因為與`secondsInOneHour`相關聯的 JavaScript 變數已經被求值為 3600。
