# 安裝

## 必備項目

用 Common Lisp 開發所需的基本項目有：

- Lisp 的「實作」，它能讓你編譯和執行程式碼，並提供 REPL。
- 具備 Lisp 程式碼支援功能的文字編輯器。
- （非必要，但推薦）Common Lisp 語言常用的參考文件，也就是[「Common Lisp Hyperspec」][hyperspec]。

## Roswell

[Roswell][roswell] 是一個用來安裝與管理 Common Lisp 實作的指令，並提供許多功能，讓你輕鬆開發與發布 Lisp 應用程式。
我們用它來簡化安裝與測試的步驟。

### 安裝 Roswell

請參閱[安裝指南][ros-inst]，並依照你所使用平台的說明操作。
對大多數使用者而言，以下做法就很夠了：

* 在 MacOS 和 Linux 上，用 [Homebrew][brew] 就能輕鬆搞定：
  ```sh
  brew install roswell
  ```
* 在 Windows 上，請使用 [Scoop][scoop]：
  ```powershell
  scoop install roswell
  ```

第一次使用 Roswell 時，它會下載並安裝 SBCL 和 Quicklisp。
只要執行這個指令：
```sh
ros help
```

用以下指令進入 REPL：
```sh
ros run
```

## 設定你的文字編輯器

對於剛接觸 Common Lisp 的人，尤其是先前用過 Emacs 的人，安裝 [Portacle，可攜式 Common Lisp 環境][portacle] 就能輕鬆快速地上手。
它免費且功能完整，能在所有常見平台上運作，而且「開箱即用」，已經預先設定好了。它會提供：

- Lisp 實作：SBCL，內含 Quicklisp 和 ASDF。
- 文字編輯器：Emacs

……還有大量用於撰寫 Lisp 程式碼的附加元件：
- SLIME，也就是「Superior Lisp Interaction Mode for Emacs」，能將 Emacs 變成 Common Lisp 的 IDE
- ParEdit，讓處理括號變得輕鬆。

所有東西都已預先設定好，開箱即可使用。請從[首頁][portacle]下載並安裝 Portacle。

注意：Emacs（文字編輯器）如果你不習慣，一開始可能會有點無所適從。幸好網路上有很多 Emacs 和 SLIME 的入門教學。

## 傳統安裝方式

如果你偏好分開安裝所需的工具，你需要安裝並設定：

- 支援 Lisp 的文字編輯器：[Emacs][emacs] 搭配 [Slime][slime] 或 [Sly][sly] 套件是常見的選擇，不過 [VIM][vim] 搭配 [SLIMV][slimv]、[Atom][atom] 搭配 [SLIMA][slima]，或 [VSCode][vscode] 搭配 [Common Lisp 外掛][vscode-plugin] 也都不錯。
- Common Lisp 實作：[SBCL][sbcl] 是「安全」的選擇，可在 Linux、MacOS 和 Windows 上運作。由於這門語言以標準為基礎，其他[符合標準的實作][awesome-cl-implementations]也同樣可用。
- [Quicklisp][quicklisp]，用於管理函式庫。下載後，請依照[說明][quicklisp-install]操作，確保它正確整合到你的 Common Lisp 實作中。
