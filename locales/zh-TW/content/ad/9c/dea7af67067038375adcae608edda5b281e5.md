# 簡介

當你需要`n`個值組成的序列，而每個值都取決於它的索引時，Factor 提供了`<iota>`（整數`0, 1, …, n-1`的虛擬序列）和`map`：

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>`不會事先配置這些整數；`map`會依序走訪它們，並把 quotation 套用到每一個上。

如果每個位置算出來的結果是字元碼，`>string`就會把結果轉成字串，這也是根據索引做決策、組出一整列字元時最自然的方式：

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
