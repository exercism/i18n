# 提示

## 一般

- 一個[`Period`][period-docs]代表以年、月、日為單位的一段時間，會搭配日期和日期時間使用。
- 一個[`Duration`][duration-docs]代表以小時、分鐘、秒、毫秒和奈秒為單位的一段時間，會搭配時間和日期時間使用。
- 這兩個類別都是不可變的：它們的方法會回傳新的實例，原本的實例則維持不變。

## 1. 算出會員資格何時結束

- 有一個[工廠方法][period-ofmonths]可以建立指定月數的`Period`。
- 可以把一段期間加到日期上，用的是日期的[`plus()`][localdate-plus]方法。
- `plus()`已經會把不存在的日期退回當月最後一天，所以你不需要自己處理。

## 2. 顯示會員資格持續多久

- `Period`上有一個[靜態方法][period-between]，會回傳兩個日期之間的期間。

## 3. 計算會員資格還剩下幾天

- `Period`的`getDays()`方法只會回傳期間中的「日」這個部分，而不是總天數。
- 某個[`ChronoUnit`][chronounit-docs]常數的[`between()`][chronounit-between]方法，會計算兩個日期之間該單位的總數量。
- [`Math.max()`][math-max]會回傳兩個數字中比較大的那個。

## 4. 測量一次造訪的時間

- `Duration`上有一個[靜態方法][duration-between]，會回傳兩個日期時間之間的持續時間。

## 5. 在收據上印出一次造訪

- 有一個[方法][duration-tohours]會回傳一段持續時間的總小時數。
- 有一個[方法][duration-tominutespart]只會回傳持續時間中的分鐘部分，介於 0 到 59 之間。
- 使用格式指定符`%02d`的[`String.format()`][string-format]會把數字寫成至少兩位數，並在前方補零。
