# 指令

Lilly 喜歡烹飪。
她想和朋友舉辦一場披薩派對。
為了充分利用食材，她需要在開始前知道每種食材需要多少。

為了解決這個問題，Lilly 已經草擬了一個程式來自動處理部分規劃，但需要你幫忙完成。
你願意幫 Lilly 舉辦一場比例完美的披薩派對嗎？

## 1. 麵團比例

Lilly 喜歡薄脆、餅皮較薄的披薩。
中間所需的麵團至少為 200 公克，但每多供應一個人，就需要再 20 公克麵團。

`grams = pizzas * ((persons * 20) + 200)`

Lilly 需要一個函式，它會：

- 接受披薩的數量
- 以及每個披薩要供應的人數
- 並回傳所需麵團量，取最接近的公克數。

例如，要做 4 個可供 8 人食用的披薩：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. 一點醬汁

Lilly 塗抹醬汁時非常講究，但她的披薩大小可能不一致。
根據她的經驗，她知道每個披薩需要 125 毫升醬汁。
Lilly 需要一個函式，計算要買幾罐醬汁。

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

例如，Lilly 需要做 8 個披薩，而每罐是 250 毫升：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. 來點起司吧

起司以正立方體販售，並依大小計價。

Lilly 使用的公式不是披薩面積公式，因為她 _不想_ 讓起司覆蓋整個面積。
她決定使用以下公式，來判斷邊長（`cheese_dimension`）的起司方塊可以做出多少個直徑（`diameter`）的披薩：

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

建立一個函式，它會：

- 接受起司方塊的邊長
- 接受想要的起司層厚度
- 接受披薩的直徑
- 並使用 Lilly 的公式回傳可做出的披薩數量，並無條件捨去。

例如，給定一個 25x25x25 公分的起司方塊、0.5 公分厚的起司層，以及直徑 30 公分的披薩：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. 公平分配

最後，Lilly 想讓她的披薩每個都切成 8 片，並平均分給她的朋友。

建立一個函式，它會：

- 接受披薩數量和朋友數量
- 並回傳如果每個人拿走相同數量的切片後，會剩下多少片披薩。

例如：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
