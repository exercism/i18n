# 簡介

## Struct

Struct 是建立在 [maps][exercism-maps] 之上的擴充機制，提供編譯期檢查與預設值。Struct 會以定義它的模組來命名。要定義 struct，請使用`defstruct`建構。這個建構通常緊接在模組定義之後。`defstruct`可以接受 atom 的陣列（用於`nil`預設值），或關鍵字陣列（用於指定的預設值）。沒有預設值的欄位必須排在具有預設值的欄位前面。

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### 存取與更新欄位

由於 struct 建立在 map 之上，我們可以使用大多數的 map 函式來取得與操作值。struct **並未**實作 _Access Behaviour_。建議改用_靜態存取運算子_`.`來存取 struct 的欄位。

- 取得/擷取欄位值：

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- 更新欄位值

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### 模式配對

struct 可以用於模式配對，帶或不帶 struct 名稱都可以。

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

在模式中帶上 struct 名稱，就能確保左右兩側都是相同型別的 struct。

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### 強制初始化欄位值

我們可以使用`@enforce_keys`模組屬性，搭配欄位鍵的陣列，確保 struct 建立時這些值就已經初始化。如果某個鍵沒有列在其中，它的值就會是`nil`，就像上面的範例一樣。如果強制要求的鍵沒有被初始化，就會引發錯誤。

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
