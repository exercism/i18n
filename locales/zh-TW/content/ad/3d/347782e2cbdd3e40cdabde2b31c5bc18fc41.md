# 說明

給定一個 0 到 999,999,999,999 的數字，用英文拼寫出那個數字。

## 步驟 1

處理 0 到 99 的基本情況。

如果程式的輸入是`22`，輸出應該會是`'twenty-two'`。

如果給定的數字超出允許範圍，你的程式應該要大聲抱怨。

以下是這個程式的一些好測試案例：

- 0
- 14
- 50
- 98
- -1
- 100

### 延伸

如果你使用 Mac，可以透過命令列呼叫 Mac OS X 的`say`程式來大聲唸出來。
如果你使用 Linux 或 Windows，也許可以透過指令`espeak`使用 eSpeakNG。

## 步驟 2

實作將數字拆成以千為單位的區塊。

所以`1234567890`應該產生像 1、234、567 和 890 這樣的陣列，而簡單許多的`1000`應該只產生 1 和 0。

## 步驟 3

現在處理在這些區塊之間插入適當的數量級詞。

所以`1234567890`應該產生`'1 billion 234 million 567 thousand 890'`

程式也必須回報任何超出範圍的值。
停在「trillion」就可以了。

## 步驟 4

將所有部分組合起來，只產生純英文。

`12345`應該產生`twelve thousand three hundred forty-five`。
