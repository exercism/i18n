# 簡介

## 數學函式

只用 `+`、`-`、`*` 和 `/`，很難算出平方根、角度和成長曲線。[`math.functions`][math.functions] 詞彙表裡有能直接幫你算好的詞，而 [`math.constants`][math.constants] 裡有 π。就像其他每一個詞一樣，它們都從堆疊取得輸入，並把答案留在堆疊上。

## 平方根

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

一把 5 公尺長的梯子，腳離牆 3 公尺，靠上牆可以搆到 4 公尺高：

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## 圓周率

`pi`（來自 `math.constants`）會把 π 推上堆疊，π 就是圓周長是直徑的多少倍：

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## 角度以弧度為單位

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`、`cos` 和 `tan` 接受角度，但不是以度為單位。它們用的是**弧度**，半圈是 π 而不是 180。傳入度數並不會報錯，只會默默地給你錯誤的答案。

`deg>rad` 把度換成弧度，`rad>deg` 再換回來。效果等同於乘以 π 再除以 180，或反過來：

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

呼叫 `sin` 之前，先把度換成弧度：

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

一條 10 公尺長、坡度 30 度的斜坡，會升高 5 公尺。答案印成 `4.999999999999999`，是因為數學函式給的是最接近的浮點數，而不是精確值。如果沒有換單位，`30 sin` 會把 30 當成弧度（將近五整圈），這條斜坡就會「升高」`-9.88` 公尺。

## 求出角度

`fatan2` 則是反過來：給你往上的距離和往旁邊的距離，它回答以弧度表示的角度。它住在 [`math.libm`][math.libm] 裡。*往上*的距離先放進堆疊，然後才是*往旁邊*的距離：

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

角度是從*往旁邊*的正方向量起。`fatan2` 會看兩個距離的正負號，所以答案可以落在 −180 到 180 度之間。

## 十的次方：10^ 與 log10

`10^` 會算出 10 的次方：

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` 則是反過來。它回答的問題是：「10 的幾次方會得到這個數？」這個答案就是該數的**對數**：

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ 與 log

`e^` 和 `log` 是同一對，只是把 10 換成 *e*（大約 2.718）。`e^` 算出 *e* 的次方，而 `log` 回答「*e* 的幾次方會得到這個數？」

```
e^  ( x -- y )
log ( x -- y )
```

數學家用 *e* 來描述每一步都按相同比例成長或縮減的事物。錢生利息是一個例子，一杯茶變涼則是另一個：

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` 是 `e^` 的反運算。它把問題反過來問：要過幾分鐘，差距才會降到 40 度？

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
