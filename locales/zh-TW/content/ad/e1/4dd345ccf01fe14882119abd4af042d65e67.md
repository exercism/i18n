# 執行測試

選擇你的作業系統：

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. 開啟 Command Prompt。
2. 取得第一個練習：

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. 切換到該練習的目錄：

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. 執行測試：

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _（一開始測試失敗不用擔心，每個練習都是這樣開始的。）_

5. 完成這個練習。找到並閱讀`instructions.append.md`指南（[在 GitHub 上查看](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)）。

祝你好運，玩得開心喔！
