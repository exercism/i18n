# 簡介

## 自訂型別

自訂型別是在 Gleam 中定義新資料型態的方式。它們可以有多個_變體_，每個變體都有自己的名稱。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

自訂型別的每個變體可以選擇性地帶有一些資料，而不同的變體可以有不同的資料型態。當變體帶有資料時，就稱為_記錄_。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

要為特定變體建立值，如果它不含額外資料（`Spring`），可以直接使用其名稱；如果含有資料，則像呼叫函式一樣呼叫它（`SomeInt(2)`）。

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

自訂型別和 Gleam 中的所有東西一樣，具有_結構相等_，這表示相同變體且資料相同的兩個值相等。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

可以使用 case 運算式對自訂型別的變體進行模式比對。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
