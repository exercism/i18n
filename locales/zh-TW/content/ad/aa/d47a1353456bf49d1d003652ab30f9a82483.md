# 先決條件

D 語言學習軌道要求你的系統上已安裝以下軟體：

* 一套 D 語言第 2 版編譯器
* （選用，但建議安裝）DUB

## 先決條件：D 第 2 版編譯器

在 D 語言官網 [dlang.org](https://dlang.org) 上，可以下載並安裝參考編譯器 DMD (Digital Mars D) 的最新版本，它支援多個平台。
詳情請見[官方下載頁面](https://dlang.org/download.html)。
在 Windows 上，另一個選擇是[使用 Chocolatey](https://chocolatey.org/packages/dmd)。
在搭載 Intel 處理器的 Mac 上，另一個選擇是[使用 Homebrew](https://formulae.brew.sh/formula/dmd)。

### 其他編譯器

除了使用自家後端的 DMD 參考編譯器之外，還有兩個編譯器可以從 dlang.org 的下載區取得：

* [GDC](http://gdcproject.org/downloads)：使用 GCC 後端
* [LDC](https://github.com/ldc-developers/ldc#installation)：以 LLVM 後端為基礎

GDC 和 LDC 不見得會跟上最新的 DMD 前端版本，但它們提供更好的最佳化等級，也支援 ARM 等其他平台。

請參閱 wiki 以取得[更多資訊](https://wiki.dlang.org/Compilers)。

### IDE 支援

各種 IDE 也支援 D 語言，例如 Visual Studio 的 [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html)，以及 IntelliJ CLion 的 [D plugin](https://plugins.jetbrains.com/plugin/7727?pr=clion)。
請參閱 wiki 以取得[更多資訊](https://wiki.dlang.org/IDEs)。

### 先決條件：DUB

[DUB](https://github.com/dlang/dub) 是 D 的建置管理器。

我們建議用它來簡化執行測試的流程，但如果你無法或不願意安裝 DUB，仍然可以在沒有 DUB 的情況下執行。

#### Windows

[DUB 網站的下載頁面](https://code.dlang.org/download)提供 Windows 安裝程式。

#### MacOS

* [DUB 網站的下載頁面](https://code.dlang.org/download)提供 macOS 二進位檔。
