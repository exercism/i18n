# 簡介

C++ 中的布林值以`bool`型別表示。
`bool`的值不是`true`就是`false`。

## 邏輯運算子

C++ 支援三種布林運算子：`!`（NOT）、`&&`（AND）與`||`（OR）。
你也可以使用替代的寫法：`not`、`and`與`or`。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 優先順序

這三種布林運算子各有不同的_運算子優先順序_。
因此，它們的求值順序是：先算`!`，再算`&&`，最後才算`||`。
如果你想強制使用不同的順序，可以把布林運算式用括號包起來（即`()`），因為括號的運算子優先順序更高。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 轉換

如果你在需要數字的地方使用`true`或`false`，它們會分別被轉換成`1`和`0`。
如果你在布林運算中使用數字，除了`0`以外的所有值都會被當成`true`，即使是負數也一樣。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
