# 說明補充

## 整數最大值

根據 [Vim 文件][number]：

> 假設使用 64 位元數字（請見 v:numbersize），無號數會被截斷為 0x7fffffffffffffff 或 9223372036854775807。

換句話說，Vim script 無法將任何大於或等於 `2^63` 的數字表示成整數。

這個練習的部分測試需要 64 位元整數，這已經超出 Vim script 的整數大小限制。基於這項限制，計算結果會與一個表示該整數值的字串進行比對，而不是把答案表示成整數。你能避開比這個語言直接允許範圍更大的數字，來解決這個問題嗎？

[number]: https://vimhelp.org/eval.txt.html#expr-number
