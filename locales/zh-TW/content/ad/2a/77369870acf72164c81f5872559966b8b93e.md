# 簡介

## 型別別名

在 Gleam 中，你可以使用型別別名，為原本難以書寫的既有型別取一個方便的名稱。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

使用 `pub type` 撰寫時，這個別名可以在定義它的模組之外使用。如果省略 `pub`，別名就會是私有的，無法在其他模組中被參照。
