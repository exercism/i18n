# 說明

今天是情人節。你的伴侶有幾個活動的想法，想請你為每一個評分：`yes`、`no` 或 `maybe`。

活動以 2 個元素的陣列`{ tag value }`表示，其中`tag`是`board-game`、`chill`、`movie`、`restaurant`或`walk`其中之一。

| 活動 | 形式 |
| ------------------------- | --------------------------- |
| 玩桌遊 | `{ board-game f }` |
| 放鬆一下 | `{ chill f }` |
| 看一部`genre`類型的電影 | `{ movie genre }` |
| 去一家`cuisine`餐廳吃飯 | `{ restaurant cuisine }` |
| 走`km`公里 | `{ walk km }` |

類型是`crime`、`horror`、`romance`、`thriller`其中一種。料理是`korean`或`turkish`。

## 1. 為料理評分

定義`rate-restaurant`，從堆疊取出一個料理並回傳你的評價：

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. 為電影類型評分

定義`rate-movie`，接受一個類型並回傳：

- `romance` → `yes`
- 其他任何類型 → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. 為散步評分

定義`rate-walk`，接受一個公里數並回傳：

- 超過`11` → `yes`
- 超過`6`，最多到`11` → `maybe`
- 其他情況 → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. 為活動評分

定義`rate-activity`，從堆疊取出一個`{ tag value }`活動並回傳你的評價。重複使用上面的輔助函式：

- `board-game`、`chill` → 一律`no`
- `movie` → 交給`rate-movie`判斷
- `restaurant` → 交給`rate-restaurant`判斷
- `walk` → 交給`rate-walk`判斷

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. 統計評價

定義`approval-counts`，接受一個活動陣列，並回傳一個 3 個元素的陣列`{ yes-count maybe-count no-count }`，表示每種評分各有幾個。

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
