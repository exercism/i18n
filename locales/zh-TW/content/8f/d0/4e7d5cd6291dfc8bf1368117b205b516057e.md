# 範圍解析運算子

範圍解析運算子（`::`）讓我們可以參照某個類別，存取它的名稱常數、靜態屬性或靜態方法。

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## 搭配範圍解析運算子使用`self`與`static`

有時物件會需要參照自己所屬的範圍。為了做到這點，`self`關鍵字讓類別可以參照自身的範圍。使用`self`關鍵字能讓類別與自己的名稱解耦，長期下來更容易維護程式碼。

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

搭配範圍解析運算子使用`static`關鍵字，可以把參照「延遲綁定」到目前這個子類別。

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## 搭配範圍解析運算子使用`parent`

`parent`關鍵字用來參照父類別的常數、屬性或方法。它常見的用途是在建立物件時呼叫父類別的建構函式：

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 注意事項

### 常數、屬性與方法的可見性

範圍解析運算子仍然遵循`public`、`private`和`protected`這些可見性修飾子所訂下的規則。
