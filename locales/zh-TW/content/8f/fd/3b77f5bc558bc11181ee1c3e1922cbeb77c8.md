# 簡介

Ruby 的例外，就像許多語言一樣，提供了一種處理突發狀況的方式。想避免程式崩潰，妥善處理例外就很重要。

當例外被拋出時，不論是你明確地拋出，還是由 Ruby 翻譯員拋出，程式都會偏離正常的運作，最後帶著錯誤訊息結束：

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

如果我們想阻止這個關閉流程，就需要對例外做出反應。這就叫做「rescuing」例外：

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

這個程式不會崩潰，而且會輸出「Got an exception」。Ruby 不會直接結束，而是執行 rescue 區塊裡的程式碼，印出一則訊息。

就像 Ruby 裡的一切，例外也是物件，而且通常會保存關於該例外的資料。以下是取得例外物件的方式：

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

在 Ruby 中，你也可以拋出自己定義的例外。例如：

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

前面提到的例外是 Ruby 內建的例外之一，不過你也可以定義自訂例外並拋出它們：

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
