## 指令

你的任務是為 Mickey 和 Minerva 產生完美的迷宮，也就是只有一個解、沒有孤立區域的迷宮。以下是你需要知道的事情：

- 迷宮的形狀是矩形，在起點和終點各有一個開口。
- 迷宮包含房間和通道，兩者以直角相交。
- 程式應該接受兩個參數：列與欄。迷宮的大小應該介於 5 到 100 格之間。
- 一個寬`x`欄、高`y`列的迷宮，寬度應該是`2x + 1`個字元，高度是`2y + 1`個字元。
- 如果沒有提供種子，就產生隨機的迷宮。如果多次提供相同的種子，產生的迷宮每次都會一樣。
- 使用[方框繪圖][Box-drawing]字元來繪製牆壁，並用箭頭符號（⇨）標示左側的入口和右側的出口。

是時候為這些愛冒險的老鼠打造完美的迷宮了！

### 範例

1. 小型正方形迷宮，5x5 格（或 11x11 字元）
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. 長方形迷宮，6x18 格
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
