# 簡介

使用 `try..rescue` 是捕捉錯誤的強大結構。捕捉錯誤能讓函式在必要時回傳已定義的值。`try..rescue` 結構還提供了兩個額外的功能可以使用：

- `else` 區塊
  - 當 try 區塊成功時，結果會與這個區塊進行比對。
- `after` 區塊
  - 無論 try 區塊成功或引發錯誤，只要程式在該時間點仍在執行，`after` 區塊中的程式碼就一定會被執行。
  - `after` 區塊的結果不會回傳到呼叫端的作用域。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
