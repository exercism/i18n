# 資料庫員工到職

## 問題描述

ABC Corp 打算把所有支付給員工的零用金付款資訊保存在資料庫中。你正在協助 ABC Corp 的財務部門實作這項功能。由於 ABC Corp 正在擴展業務，因為新進員工而需要在系統中新增員工，是常見的需求。

你的任務是把提供的新員工資料新增到資料庫的`Employee`資料表，並回傳自動產生的`employee_id`欄位值，而且不能再向資料庫發出另一次查詢來取得它。如果執行期間發生錯誤，應該回傳`-1`。

## 資料庫詳細資料

這個題目請使用提供的 H2 資料庫。

> 範例資料庫檔案是`gofigure.mv.db`，資料庫名稱是`gofigure`。它位於`db`資料夾中。

範例 H2 資料庫中已經有以下資料表及一些範例資料。欄位名稱與資料型態如下。

**資料表名稱**：`Employee`

| **欄位：**      | 型態 |
| -----------       | ----------- |
| `employee_id`     | 整數，自動遞增主鍵       |
| `name`            | 字串        |
| `city`            | 字串        |
| `department`      | 字串        |
| `age`             | 整數        |

**資料表名稱**：`Payment`

| **欄位：**      | 型態 |
| -----------       | ----------- |
| `payment_id`      | 整數，自動遞增主鍵       |
| `date`            | 日期        |
| `amount`          | 小數        |
| `employee_id`     | 整數        |
| `reason`          | 字串        |

* 資料庫檔案是`gofigure.mv.db`。JDBC URL 請使用`jdbc:h2:file:/path/to/db/file`
* 使用者名稱：`root`
* 密碼：`root`

## 限制條件

* 使用`db`資料夾中提供的 H2 資料庫檔案來驗證查詢與 Ballerina 範例
* 使用 maven dependency params 的做法，在你的 Ballerina.toml 中把 H2 資料庫驅動程式新增為平台相依性
* 不要再向資料庫發出另一次查詢來取得自動產生的 id


## 測試環境

* 你可以用`bal test`執行測試，它會針對提供的範例資料庫執行測試。

## 範例

### 範例 1

**輸入**：dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**輸出**：`4`

### 範例 2

**輸入**：dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**輸出**：`-1`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模組來操作資料庫
* 請參閱 [先決條件](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 章節，了解如何把 JDBC 驅動程式新增為相依性
* 使用 [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute) 遠端方法來插入資料
* 參考 [DML 與 DDL 操作](https://ballerina.io/learn/by-example/mysql-execute-operation/) 範例
