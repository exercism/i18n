# 指令補充

## 例外訊息

有時候，我們需要[引發例外][raising-exceptions]。
這麼做時，你應該一律附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。
這能讓你的程式碼更容易閱讀，對除錯也有很大的幫助。
如果你已經知道錯誤來源會是某一種類型，可以選擇引發其中一種[內建錯誤類型][error-base-classes]，但還是要附上有意義的訊息。

一場有效的`Tic Tac Toe`對局會在某一位玩家獲勝時結束。
如果兩位玩家都處於獲勝狀態，這個練習會要你在解法中使用 [raise 敘述][raise]「拋出」`ValueError`。
如果某位玩家被判定為連續下了兩手，或是在被指派下第二手時卻下了第一手，你的程式碼同樣應該拋出`ValueError`。

若要引發帶有訊息的`ValueError`，請把訊息寫成`exception`型別的引數：

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

測試會檢查錯誤訊息是否完全相符，所以請仔細閱讀預期的結果。
