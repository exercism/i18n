# 簡介

在 Ruby 中，**陣列**是有序、以整數索引的任意物件集合。
陣列索引從 `0` 開始。
負索引代表從陣列尾端往回算，也就是說，索引 `-1` 表示陣列的最後一個元素，`-2` 是倒數第二個元素，以此類推。
Ruby 陣列混入了 [Enumerable 模組][enumerable-module]，加入了多種走訪與搜尋方法，以及排序的能力。

## 建立陣列

- Ruby 中的陣列可以包含不同型態的物件。

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## 元素指定

元素可以透過索引存取或修改。
指定起始索引和長度即可存取子陣列。

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- 負索引會從陣列尾端往回數。

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## 元素參照

- 陣列中的元素可以用 #[] 方法取出。
- 它會回傳索引處的元素，或回傳從起始索引開始、往後算 length 個元素的子陣列。

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- 負索引會從陣列尾端往回數（-1 是最後一個元素）

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## 取得陣列的相關資訊

陣列隨時都會記錄自己的長度。
要查詢陣列包含多少個元素，可以使用 length、count 或 size。

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## 將項目加入陣列

項目可以透過 `push` 或 `<<` 加到陣列的尾端：

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## 從陣列移除項目

pop 方法會移除陣列的最後一個元素並回傳它：

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
