# 指令補充

## 例外訊息

有時候，你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。這會讓你的程式碼更容易閱讀，也對除錯大有幫助。如果你已經知道錯誤來源屬於某種特定型態，可以選擇引發其中一種[內建錯誤型態](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習要求你使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在`matrix`不規則時「拋出」`ValueError`。只有在你同時`raise`這個`exception`並附上訊息時，測試才會通過。

若要引發帶有訊息的`ValueError`，請把訊息當作引數傳給`exception`型別：

```python
# if the matrix is irregular
raise ValueError("irregular matrix")
```
