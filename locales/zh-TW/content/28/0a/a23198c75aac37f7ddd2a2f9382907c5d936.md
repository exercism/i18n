# 除錯

與許多程式語言不同，WebAssembly 程式碼不會自動存取主控台這類全域資源，這類功能必須改用匯入的方式提供。

為了提供類似`console.log`的功能與其他一些便利功能，Exercism 的 WebAssembly track 在所有練習中提供了一套標準函式庫。

這些函式必須在 WebAssembly 模組開頭匯入，接著就能在 WebAssembly 程式碼中呼叫。

`log_mem_*`函式需要能存取 WebAssembly 模組的線性記憶體。預設情況下那是私有狀態，因此為了讓它可供存取，你必須用`mem`這個匯出名稱來匯出線性記憶體。做法如下：

```wasm
(memory (export "mem") 1)
```

# 記錄區域與全域變數

我們為每個 WebAssembly 基本型別都提供了記錄函式。這對記錄全域與區域變數很有用。

## log_i32_s - 將 32 位元有號整數記錄到主控台

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# 從線性記憶體記錄

WebAssembly 線性記憶體是可由位元組定址的值陣列，相當於 WebAssembly 程式的虛擬記憶體

我們提供的記錄函式能把線性記憶體中某段位址範圍解讀成特定型別的靜態陣列，作用類似 JavaScript 的 TypedArrays。長度參數不是以位元組計算，而是以函式對應型別的連續元素個數計算。

**這些函式要能運作，你的 WebAssembly 模組就必須使用名為 "mem" 的匯出名稱來宣告並匯出線性記憶體**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - 將一串 UTF8 字元記錄到主控台

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - 將一串有號 8 位元整數記錄到主控台

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
