# 關於

Kotlin 中的布林值以`Boolean`型別表示，它的值可以是`true`或`false`。

Kotlin 支援三種內建的[布林運算子][reference]：`!`（否定，又稱 NOT）、`&&`（惰性合取，又稱 AND），以及`||`（惰性析取，又稱 OR）。`&&`和`||`運算子採用_短路求值_，也就是說，只有在需要時才會對運算子的右側求值。

```kotlin
true || false // => true
true && false // => false
```

這三種布林運算子各有不同的[_運算子優先順序_][precedence]。因此，它們的求值順序是：先`!`，接著`&&`，最後是`||`。如果你想「跳脫」這些規則，可以把布林運算式用括號（`()`）括起來，因為括號的運算子優先順序更高。

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
