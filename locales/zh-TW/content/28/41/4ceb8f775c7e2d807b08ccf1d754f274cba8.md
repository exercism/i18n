# 說明補充

## 例外訊息

有時你會需要[拋出例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，你應該一律附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。這能讓你的程式碼更好讀，對除錯也大有幫助。如果你已經知道錯誤來源會是某一種類型，可以選擇[拋出內建的錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習特別要求你使用[`raise`敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「拋出」`ValueError`。只有同時`raise`這個`exception`並附上訊息，測試才會通過。

要拋出帶有訊息的`ValueError`，請把訊息寫成`exception`型別的引數：

```python
raise ValueError("A meaningful error message here.")
```
