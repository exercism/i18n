# 引導的心態

## 心態究竟_是_什麼？

在探討引導的心態之前，先了解什麼是心態可能會有幫助。
根據《牛津英語詞典》，`Mindset`是指「一套既有的態度，尤其被視為某個特定群體的社會或文化價值觀的典型」。
一個人可能因為個人的動機而投入某項活動，但心態會引導這份動機與群體的價值觀保持一致。
對 Exercism 的導師而言，這意味著要以 Exercism 社群的精神來看待引導的過程。

## Exercism 社群的精神

不妨看看[關於][exercism-about]頁面上所表達的 Exercism 宗旨，這會很有幫助。
整頁都值得閱讀與思考，特別是以下幾點：

- 「我們正在打造一個地方，讓任何人都能免費學習並精通程式設計，而且永遠不會覺得迷惘，也不會覺得自己很笨。」
- 「Exercism 應該是有趣的、有挑戰性的，而且有價值。」
- 「Exercism 應該鼓勵成長心態、清晰且富有同理心的溝通，並強調一起學習的價值。」
- 「Exercism 應該讓人感到安全，並感受到關懷。」
- 「Exercism 著重的是學習的旅程，而不是終點。學習的過程與樂趣，比絕對的事實正確性更重要。」

## 學員的精神

學員表現出來的精神，有時乍看之下可能令人卻步。

有些學員的留言裡可能帶著自我貶抑。
他們可能會說「我不太聰明」、「我看不懂」或「我不太擅長這個」。
以 Exercism 重視同理心與關懷的精神，直接回應這些話，或許很誘人。
不過，身為導師，具體說出你喜歡他們解答的哪些地方，可能比給他們某種含糊的安慰更有效。
如果他們的解答中沒有任何你能真心讚美的地方，你可以祝賀他們通過測試；如果他們沒通過測試，至少肯定他們的努力。

有些學員的留言開頭可能讓人覺得帶有負面意味。
他們可能會說「為什麼我非得做某某事？」
這感覺就像是他們在抱怨：「為什麼我非得吃豌豆？我_討厭_豌豆！」
你可能會因為對方一開始就顯得對立，而打消引導這個人的念頭。
但看起來像挑釁或抱怨的東西，可能只是單純的提問，即使表達得有點唐突。

```exercism/note
許多學員的母語並不是英文。
這也是為什麼學員一開始的留言，可能顯得比實際上不友善的另一個原因。
```

最好的做法是忽略他們的留言可能勾起的情緒，單純回答問題就好。

這只是兩個例子，說明學員給人的精神印象不該影響導師回應他們的態度。

## 導師的精神

導師的精神可能建立在驕傲或謙遜之上。
導師可能覺得自己_有資格_引導別人，因為自己聰明，或是有一定的經驗。
他們可能覺得自己應該引導別人，因為自己比別人懂得多。
以驕傲為精神基礎的導師，仍可能以耐心與禮貌的引導來面對學員，即使這份寬容可能出自大度，而非同理心。

或者，導師可能懷有謙遜的精神。
他們可能清楚記得自己學習程式設計時遇過哪些挑戰。
他們可能知道自己並非無所不知，但至少知道_一些_，而且願意分享自己辛苦得來的知識。
以謙遜為精神基礎的導師也仍是人，面對一場棘手的引導會談時，也可能忍不住用冷淡或爭辯的方式回應。
即使是最出於善意的人，在心情不好的日子裡也需要保持警覺。

還有第三種精神，它是驕傲精神的一種變體，那就是缺乏安全感的精神。
導師可能對自己的名聲感到不安，並向學員尋求肯定來補償。
他們可能用大量資料與參考文獻淹沒學員，以展現自己見多識廣。
學員或許能從這樣的大量傾倒中獲得有用的資訊，但這只是缺乏安全感的導師的次要目標。
主要目標是展示導師有多博學。
雖然動機不同，只要沒讓學員迷失在細節裡，缺乏安全感的導師仍可能成功達成 Exercism 心態的目標。

## 真理的精神

事實正確性當然很重要，也有它的地位。
例如，在預期使用公制單位的地方，就不該使用英制單位，這點很重要。
否則，一臺[造價 3.27 億美元的火星氣候探測者號就可能墜毀][crash]。
當然，以某種程式語言從事專業工作的人，會被要求把正確性視為關鍵條件。

不過，對正在_學習_某種程式語言的人來說，要求就有些不同。
首先，我們不希望讓對方就此打消繼續學習這門語言的念頭。
對某些導師來說，尤其是抱持驕傲精神的人，讓對方領悟到自己或許不適合某種程式語言，或是現在還不是學這門語言的適當時機，可能會有種成就感。
雖然在某些工作環境裡這或許是可接受的結果，但它並不是 Exercism 心態所認可的結果。

```exercism/note
有一個例外，就是正在學習第一門程式語言的人。
Exercism 的對象是已經會寫程式、想再學一門語言或精進現有技能的人。
即將推出的 Learn to Code 平台則會以剛開始學程式設計的人為對象。
```

很多時候，想接受引導的人已經學了幾週或幾個月的程式語言，並希望把學到的基礎再提升。
這個人可能有其他語言的經驗，也可能沒有。
如果這是他們的第一門語言，但他們已經掌握了基本的關鍵字與概念，那麼他們很有機會從引導中受益。
他們可能需要多一點耐心與解說，這是導師當初接受引導請求時可能沒意識到的。
不過，一旦投入這場交流，Exercism 的心態就是盡可能給予支持與鼓勵，即使需要多花一些心力；或者禮貌地建議結束這次會談，讓學員能重新提交給另一位導師。

當然，學員可能自己決定不再繼續鑽研某門語言。
大多數人大概不會告訴我們，只是不再解那個語言的練習。
不過，在一場引導會談的過程中，我們應該忠實地給予支持與鼓勵。
但做法有許多種。
我們不想要的一種做法是[有毒的正能量][toxic-positivity]。
例如，當對方在某件事上理解困難時，如果我們還熱血地堅持「我知道你一定想得出來」，這不但幫助不大，還可能讓人覺得自己「不如人」。
比起用聽起來像「拜託！你懂了沒啊？」的鼓勵去推他們，不斷嘗試不同的解說方式、提供其他例子，可能更有幫助。

學員最後得到的解答，即使在與導師來回幾次之後，也未必是效能最好的，或者未必_完全_符合程式碼標準。
逼迫學員追求完美解答，就是那種不符 Exercism 精神的絕對事實正確性的例子。
解答可能已經[夠好了][good-enough]，此時技巧上的精進可以留到下一次引導會談。

## 義務的精神

導師可能不太確定自己的義務是什麼。
義務很少也很簡單：有幫助、能鼓勵。
如果導師在任一時點覺得自己做不到其中任何一項，最好禮貌地建議結束會談，讓學員能重新提交給另一位導師。
最好的做法可能是由導師邀請學員結束討論；但如果導師覺得必須結束討論，那麼以一則說明原因的最後留言來收尾會比較禮貌。
雖然把焦點放在讓會談不順的學員過失上可能很誘人，但把責任歸咎於學員，並不符合 Exercism 的精神。

## 合作的精神

Exercism 的合作精神，最好的展現方式不是直接把（更好的）練習解答送出去，而是描述其他可以採用的做法，並把這些建議的實作留給學員自己寫。
解答可以_選擇性地_提供給學員，以備他們卡住時使用。
它可以是一段放在可收合細節區塊裡的範例片段，也可以是一個連到已發布解答的連結。
要不要展開區塊或點開連結，由學員自己決定。

學員可能會表示喜歡某個建議，但說會留待日後再考慮。
導師可以建議再提交一個以該建議為基礎的版本，但學員也可能決定不修改原本的解答就結束討論。
雖然看到自己引導過的解答被標記為已發布，而自己覺得還能更好，可能會有點尷尬，但如果學員似乎不太願意，仍不該強推他們實作這個建議，這才符合合作的精神。

合作精神的另一種體現，是導師向學員學習。
在會談過程中，學員可能提出導師不懂的東西。
導師不需要擺出「無所不知」的樣子。
導師完全可以表示自己不知道，或是沒想過學員提出的某件事。
讓學員知道你從他們身上學到了東西，可能是你能給的最大鼓舞之一。
這也是合作學習過程的一部分。
