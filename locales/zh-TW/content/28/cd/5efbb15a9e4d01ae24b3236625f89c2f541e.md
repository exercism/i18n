# Instructions

在這項練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出美味的千層麵。

你有四個任務，全都和烹調千層麵所花的時間有關。

## 1. 將預期的烘烤時間存成常數

定義`expected_bake_time`常數，它會回傳千層麵應該在烤箱裡烘烤幾分鐘。

根據食譜，千層麵總共需要在烤箱裡烤 60 分鐘。

```julia-repl
julia> expected_bake_time
60
```

## 2. 計算準備時間的分鐘數

定義`preparation_time`函式，它接收你加進千層麵的層數作為引數，並回傳你準備千層麵花了幾分鐘，假設每一層要花你 2 分鐘準備。

```julia-repl
julia> preparation_time(4)
8
```

## 3. 計算剩餘烘烤時間的分鐘數

定義`remaining_time`函式，它接收千層麵實際已在烤箱裡的分鐘數作為參數，並回傳千層麵還需要在烤箱裡待幾分鐘。

```julia-repl
julia> remaining_time(50)
10
```

## 4. 計算總工作時間的分鐘數

定義`total_working_time`函式，它接收兩個引數：第一個引數是你加進千層麵的層數，第二個引數是千層麵已經在烤箱裡的分鐘數。

這個函式應該回傳你烹調千層麵總共工作了幾分鐘，也就是準備時間的分鐘數，加上千層麵目前待在烤箱裡的時間的分鐘數。

```julia-repl
julia> total_working_time(3, 20)
26
```
