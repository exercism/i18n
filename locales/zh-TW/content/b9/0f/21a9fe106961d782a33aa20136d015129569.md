# 指令補充

## 這個 Python 練習的結構

這個練習的測試預期你的解法要用 Python 的 `RelativeDistance` `class` 來實作。
如果你還不熟悉 Python 的 `class`，[concept:python/classes]() 和[官方 Python 文件裡的 `classes`][classes in python]都是很好的起點。


`RelativeDistance` 要用 `family_tree` 來初始化（_詳情請見 [`__init__()`][init]_）。`family_tree` 是一個字典，其中的 `keys` 是個人，而 `values` 是那個人的子女的 `list`。
你還需要實作一個 `degree_of_separation` [方法][methods]，它會回傳 `person_a` 和 `person_b` 之間的分隔度，這兩人是傳入的家族樹中的個人。


我們提供了 `__init__` [特殊方法][special-methods]的雛形實作，用來建立 `RelativeDistance` 類別的實例，另外也提供了 `degree_of_separation` 方法的雛形。
首先，你要在 `self`（_實例_）上自訂一個適當的屬性，用來代表 `family_tree` 資料。
接著，你就可以在 `degree_of_separation` 方法中加入你的邏輯，來計算 `person_a` 和 `person_b` 之間的分隔度。


## 例外訊息

有時候，我們必須[拋出例外][raising-exceptions]。
這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。
這會讓你的程式碼更好讀，也對除錯很有幫助。
如果你知道錯誤來源屬於某種類型，可以選擇拋出[內建的錯誤類型][base-error-classes]之一，但仍然要附上有意義的訊息。

這個練習要求你使用 [raise 陳述式][raise-statement]來「拋出」多個 `ValueError`。
在第一個情境中，當傳給 `RelativeDistance.degree_of_separation` 方法的人（其中一人或兩者）不存在於家族樹中時，你需要拋出 `ValueError`。

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

如果兩人都存在於家族樹中，但依規則定義，兩人之間沒有有效的連結時，你需要拋出 `ValueError`。

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

只有當你 `raise` 了預期的 `exception` 類型，並附上預期的訊息，測試才會通過。
請仔細檢查測試和它們預期的結果，因為這裡的說明並不完整。
