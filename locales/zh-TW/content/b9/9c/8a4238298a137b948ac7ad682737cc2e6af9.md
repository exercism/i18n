# 簡介

Factor 透過 [`io`][io] 串流來讀取和寫入。大多數程式碼都是跟*環境*的輸入與輸出打交道：`read`、`readln`、`print`和`write`這些詞，都是對當下綁定的那個串流運作；而少數幾個`with-…`組合器，則會在一段 quotation 的執行期間，暫時把這個環境串流替換掉。

```factor
USING: io io.streams.string ;

"hello\nworld" <string-reader> [ readln . readln . ] with-input-stream
! prints "hello"
! prints "world"

[ "captured" print ] with-string-writer .
! prints (returns) "captured\n"
```

`<string-reader>`和`<string-writer>`是這個練習會用到的記憶體內串流。`<file-reader>`和`<file-writer>`則是對應的磁碟版本，介面完全相同；把它們跟`with-file-reader` / `with-file-writer`搭配使用，就能在限定的作用域內存取檔案。

[io]: https://docs.factorcode.org/content/vocab-io.html
