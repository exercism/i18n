不過事情有點雜亂：Azara 的座標格式和排序似乎和 Rui 的不同，他們必須在兩份清單之間來回查看，才能弄清楚哪些寶物對應哪些地點。
身為剛起步的 Python 愛好者，他們來找你幫忙寫一個小程式（其實就是幾個函式），好把尋寶資訊整理得更有條理。


## 1. 擷取座標

實作`get_coordinate()`函式，它會接收 Azara 清單中的一個`(treasure, coordinate)`配對，並只回傳擷取出的地圖座標。


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. 格式化座標

實作`convert_coordinate()`函式，它會接收格式為 "2A" 的座標，並回傳格式為`("2", "A")`的元組。


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. 比對座標

實作`compare_records()`函式，它會接收一個`(treasure, coordinate)`配對和一個`(location, coordinate, quadrant)`紀錄，並比對兩者的座標。
如果座標「相符」，就回傳 **`True`**；如果不同，則回傳 **`False`**。
視需要重新格式化座標，以便準確比對。


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. 合併相符的紀錄

實作`create_record()`函式，它會接收 Azara 清單中的一個`(treasure, coordinate)`配對和 Rui 清單中的一個`(location, coordinate, quadrant)`紀錄，**如果座標相符**，就回傳`(treasure, coordinate, location, coordinate, quadrant)`。
如果座標_不_相符，則回傳字串 **"not a match"**。
視需要重新格式化座標，以便準確比對。


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
