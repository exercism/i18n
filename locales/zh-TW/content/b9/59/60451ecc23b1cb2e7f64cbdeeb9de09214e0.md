# 簡介

## 持續時間與期間

像`LocalDate`和`LocalDateTime`這樣的類別，描述的是時間中的一個_點_。`java.time`套件還有兩個類別，用來描述_時間長度_：

- `java.time.Period`表示以年、月和日為單位的時間長度，例如「2 個月又 5 天」。
- `java.time.Duration`表示以小時、分鐘、秒、毫秒和奈秒為單位的時間長度，例如「1 小時 30 分鐘」。

`Period`會依循日曆，因此用於日期和日期時間。`Duration`測量的是確切時間，因此用於時間和日期時間，但不適用於日期。

```exercism/note
就像其他`java.time`類別一樣，`Period`和`Duration`都是不可變的。看起來會改變它們的方法，其實會回傳一個_新_的實例。
```

### `Period`

`Period`可以用它的其中一個靜態工廠方法建立：

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`的結果會使用 [ISO-8601][iso-8601-durations] 表示法：先寫`P`（代表「期間」），接著是年數（`Y`）、月數（`M`）和日數（`D`）。

可以將`Period`加到日期，或從日期減去`Period`：

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

因為每個月的長度不同，加上幾個月後可能會落在不存在的日期。這種情況下，結果會退回到該月最後一個有效日期：

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()`會回傳從某個日期（含）到另一個日期（不含）之間的期間：

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### 用`ChronoUnit`計算單位

`Period`會把年、月和日分開保存。所以`getDays()`只會回傳期間中屬於「日」的_部分_，而不是總天數。若要計算兩個日期之間某個單位的總數，請使用[`java.time.temporal.ChronoUnit`][chronounit-docs]的`between()`方法：

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

當第二個日期早於第一個日期時，結果會是負數：

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

`Duration`同樣可以透過靜態工廠方法建立：

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

在 ISO-8601 表示法中，`T`會分隔日期部分與時間部分，這就是為什麼持續時間會寫成`PT...`。

可以對日期時間加上或減去一段持續時間：

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()`會回傳兩個日期時間之間確切的時間長度：

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

持續時間可以用`toHours()`、`toMinutes()`和`toSeconds()`這類方法轉換成單一單位。這些方法會回傳該單位的_總_量，並向下取整：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

若想依照時鐘的方式把持續時間拆成各個部分，請改用`toXxxPart()`方法：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
