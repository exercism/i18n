# 測試

## 設定

請依照 WebAssembly 的設定[說明][docs-exercism-wasm]，安裝所需的相依套件。

## 需求

安裝練習的相依套件：

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## 讓測試套件通過

所有練習都附有測試套件，幫助你在提交前驗證自己的解法。
你可以在練習的目錄中開啟命令提示字元，然後執行下列指令來執行這些測試：

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

有些測試套件會略過第一個測試以外的所有測試。

當你的測試通過之後，只要把`xtest`改成`test`，就能啟用下一個測試。

## 撰寫自訂測試

如果你想撰寫額外的自訂測試，請建立一個新檔案`custom.spec.js`，並將它連同你的解法一起提交：

```shell
exercism submit numbers.wat custom.spec.js
```
