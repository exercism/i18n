# 指令

Turndit Inc. 正在製作一款新的黑膠唱盤，可以在唱片上的曲目之間跳轉。沒人知道這有什麼好處，但他們堅持要做，那就隨他們去吧。他們目前需要協助，想辦法在需要時把唱針導向唱片的正確位置。

這套裝置分成兩個部分：

唱針懸在唱盤上方，可以在唱片上左右、前後移動（想像一下夾娃娃機！）。
由於控制唱針的機構是線性移動的，它會用一對座標`(x, y)`來追蹤自己的位置，原點位在唱片中心。

另外還有一套光學裝置，用來追蹤唱針的位置，以及前一首或下一首歌曲從哪裡開始。
由於唱片在旋轉，追蹤這兩點之間的徑向差與角距離`(r, θ)`會比較容易，同樣以唱片中心為原點。

Turndit 需要知道，當選擇不同的曲目時，要如何找出唱針將移動到的新座標`(x', y')`。

~~~~exercism/note
這些運算可以用三角函式和／或旋轉矩陣來完成，但如果改用複數，透過旋轉與徑向位移來處理，可以變得更簡單（而且更有趣，我保證！）。
事實上，如果你願意，這個練習裡的每個函式都能用複數以及 Julia 內建的方法／功能，以賦值形式（也就是一行搞定）寫出來。
~~~~

## 1. 由笛卡兒座標建立複數

實作`z(x, y)`函式，它接受複數平面上的一個`x`座標、一個`y`座標，並回傳對應的複數。

```julia-repl
julia> z(1, 1)
1.0 + 1.0im

julia> z(4.5, -7.3)
4.5 - 7.3im
```

## 2. 由極座標建立複數

實作`euler(r, θ)`函式，它接受一個徑向座標`r`、一個角度`θ`（單位為弧度），並回傳對應的直角座標形式複數。

```julia-repl
julia> euler(1, π)
-1.0 + 0.0im

julia> euler(3, π/2)
0.0 + 3.0im

julia> euler(2, -π/4)
1.4142135623730951 - 1.414213562373095im  # √2 - √2im
```

## 3. 執行二維向量旋轉

實作`rotate(x, y, θ)`函式，它接受一個`x`座標、一個`y`座標以及角位移`θ`（單位為弧度）。
這個函式應該把該點繞原點旋轉給定的角度`θ`，並以元組回傳新的座標：`(x', y')`。

```julia-repl
julia> rotate(0, 1, π)
(0, -1)

julia> rotate(1, 1, -π/2)
(1, -1)
```
## 4. 執行徑向位移

實作`rdisplace(x, y, r)`函式，它接受一個`x`座標、一個`y`座標以及徑向位移`r`。
這個函式應該沿著半徑把 x-y 座標位移 `r` 的量，並以元組回傳新的座標：`(x', y')`。

```julia-repl
julia> rdisplace(0, 1, 1)
(0, 2)

julia> rdisplace(1, 1, √2)
(2, 2)
```
## 5. 找出目標歌曲

實作`findsong(x, y, r, θ)`函式，它接受唱針的`x`與`y`座標，以及唱針與目標歌曲起點之間的`r`與`θ`位移。唱針的新座標應以元組回傳：`(x', y')`。

```julia-repl
julia> findsong(0, 1, 3, -π/2)
(4, 0)

julia> findsong(√2, √2, 0, 3π/4)
(-2, 0)
```
