# 字串

`STR`用來存放文字。字串寫在雙引號之間。

```sather
   composer : STR is
      return "Sibelius";
   end;
```

`STR`一旦存在就不會改變。以下每個操作都會回傳一個*新*字串，而不會改動原本被詢問的那個字串。

## 串接

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+`也能把數字串接到字串上，這就是數字進入句子的方式：

```sather
"Opus " + 27           -- "Opus 27"
```

## 長度

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size`計算的是字元數，結果是一個`INT`。

## 片段

| 呼叫 | 結果 |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

要求的長度超過實際字串時，會回傳實際有的部分，而不是失敗。

## 比較

`=`詢問兩個字串是否為相同的文字，`/=`則詢問兩者是否不同。

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

大小寫有別。`.upper`和`.lower`會回傳轉成該大小寫的副本，這是不在乎大小寫時常用的比較方式：

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## 關於長度的一點說明

`STR`是一列位元組，`.size`計算的是位元組數。對英文文字而言，這等同於計算字母數；但對帶有重音或其他字母系統的文字就不是了，因為那些字母每個會佔用超過一個位元組。
