## 一般

別把 `SimpleLinkedList` 這個 struct 實作成包在 `Vec` 外面的包裝，請改為在堆積上配置節點。

可以這樣實作：

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

`head`欄位指向這個鏈結串列的第一個元素（Node）。

這個實作還需要一個 struct `Node`，包含下列欄位：

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data`儲存資料，`next`則指向下一個節點（如果有的話），或是 None。

## 為什麼要用`Option<Box<Node<T>>>`，而不是只用`Option<Node<T>>`？

自己試試看吧。你會看到下面這個錯誤。

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

問題在於，編譯時期必須知道 next 的大小。
因為`next`是遞迴的（「一個節點裡有節點，節點裡又有節點……」），編譯器不知道該配置多少記憶體。
相較之下，[Box](https://doc.rust-lang.org/std/boxed/) 是大小固定的堆積指標。
