# 關於

布林值代表某個條件是 `true` 還是 `false`。在 Go 中，`bool` 型別只能是這兩個值的其中一個。

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## 邏輯運算子

邏輯運算子會作用在一個或兩個布林值上，並產生布林結果。

| 運算子 | 名稱 | 行為 |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | 回傳單一布林值的相反值 |
| `&&`     | AND  | 只有在兩邊都是 `true` 時才回傳 `true` |
| `\|\|`   | OR   | 只要任一邊是 `true` 就回傳 `true` |

當你需要某個布林值的相反值時，使用 `!`（NOT）：

```go
!isDoorLocked // false
```

當兩個條件都必須是 `true` 時，使用 `&&`（AND）：

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

當至少要有一個條件是 `true` 時，使用 `||`（OR）：

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

邏輯運算子的求值順序是：先 `!`，再 `&&`，最後 `||`。使用括號將程式碼分組，控制哪些運算先執行：

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
