# 測試

## 執行測試

當你位於某個練習的目錄中時，應該會看到兩個子目錄：

* `src`包含你對這個練習的解法
* `spec`包含要為這個練習執行的測試

如果你在正確的目錄中（也就是包含`src`和`spec`的那一個），只要執行`crystal spec`，就能執行那個練習的測試：

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

這會執行`spec`目錄中的所有測試檔案。

在每個測試檔案中，除了第一個測試之外，其餘的測試都已被跳過。

當你讓某個測試通過之後，只要把`pending`改成`it`，就能取消跳過下一個測試。

## Crystal 格式化

提交之前，建議你先對你的解法執行`crystal tool format`。

你可以用以下指令把目前目錄中的所有內容格式化：

```bash
$ crystal tool format ./
```

或者，你也可以只格式化指定的檔案：

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## 提交你的解法

提交解法時，請務必提交`src`目錄中的原始檔：

```bash
$ exercism submit src/<exercise>.cr
```
