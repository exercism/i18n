# 簡介

Common Lisp 在大多數運算中都使用標準的算術運算子，但它有個獨特之處：採用「前綴表示法」，而非常見的中綴表示法。

用圖來看更清楚：

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前綴表示法雖然會把 `2 + 2` 這類運算變成比較不熟悉的`(+ 2 2)`形式，卻讓一次對多個數字進行運算變得容易許多。

## 基本數學

Common Lisp 具備所有典型的函式：`+`、`-`、`*`、`/`，分別用於加、減、乘、除。

談到除法時，你可能會想知道相除之後的餘數，這可以交給 `mod`（modulo，取模）函式處理，它接受一個數字和一個除數作為引數：

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## 比較數字

最後，你可能會發現用 `=`（等於）、`/=`（不等於）、`>=`（大於或等於）這類函式來比較不同的數字很有用。
當這些比較成立時（例如`(= 1 1)`），會回傳 `T`；當它們不成立時（例如`(> 0 1)`），則回傳 `NIL`。
