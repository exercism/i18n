# 二進位、八進位與十六進位

二進位、八進位和十六進位（_也稱 hex_）是不同的[數字系統][numeral-systems]，各有不同的基數。
二進位是基數 2，八進位是基數 8，十六進位是基數 16。
在 Crystal 中，一般的整數是基數 10。
二進位、八進位和十六進位都是整數的表示法。
這代表它們可以表示正數和負數（_包括零_），而且沒有分數或小數，並支援所有我們能對整數做的運算。

## 二進位

[二進位][binary]是基數 2 的數字系統，只使用 0 和 1 這兩個數字。
它通常用來表示電腦中電流通過電晶體和開關的 0（「關」）與 1（「開」）狀態，以及磁性儲存媒介中的正負電荷。
二進位可以表示所有十進位裡用到的整數。

基數 2 系統的一小段看起來像這樣，不過它會無限延伸，不會停在 128：

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

所以如果我們想表示數字 6，用二進位就是：110

| 位值         | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| 二進位數字    | 1   | 1   | 0   |

而運算過程會是：`4 + 2 + 0 = 6`

另一個例子：19

| 位值         | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| 二進位數字    | 1   | 0   | 0   | 1   | 1   |

二進位數字會是：10011
而運算過程會是：`16 + 0 + 0 + 2 + 1 = 19`

## Crystal 中的二進位

在 Crystal 中，我們可以用 `0b` 前綴來表示二進位字面值。
如果我們寫 `0b10011`，Crystal 會將它解讀為二進位數字，並轉換成基數 10。

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

如果你寫了一個帶有 `0b` 前綴但不符合二進位系統的數字，就會引發編譯錯誤。

```crystal
0b10211
# => Error: unexpected token: "211"
```

### 二進位數字的運算

由於二進位數字就是整數，我們可以對它們做所有能對整數做的運算。

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### 二進位表示法的雙向轉換

Crystal 會自動將二進位字面值轉換成 `Int32`。
要將 `Int32` 轉換成二進位表示法，可以使用 [`<int>.to_s(base)`][to_s] 方法，並將 base 引數設為 2。
這個方法會回傳二進位數字的字串表示法：

```crystal
19.to_s(2)
# => "10011"
```

要將二進位的字串表示法轉換成整數，我們可以使用 [`<int>.to_i(base)`][to_i] 方法，並將基數（2）作為引數傳入：

```crystal
"10011".to_i(2)
# => 19
```

給予錯誤的基數（_或是無效的二進位表示法_）會引發 `ArgumentError`：

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### 二進位相關方法

有些方法可以用在整數上，取得數字二進位表示法的相關資訊。

[`<int>.bit_length`][bit_length] 會回傳表示該數字所需的位元數：

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] 會回傳指定索引位置的位元，從最右邊（_最低有效位元_）開始算起：

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## 八進位

[八進位][octal]是基數 8 的數字系統。
它使用 0、1、2、3、4、5、6、7 這些數字。

在 Crystal 中，我們可以用 `0o` 前綴來表示八進位數字。
和二進位一樣，Crystal 會自動將八進位表示法轉換成 `Int32`。

```crystal
0o123
# => 83
```

在不符合八進位系統的數字前加上 `0o` 會引發編譯錯誤。

### 八進位表示法的雙向轉換

和二進位一樣，我們可以使用 [`<int>.to_s(base)`][to_s] 方法，將 `Int32` 轉換成八進位表示法。
我們也可以使用 [`<int>.to_i(base)`][to_s] 方法，將八進位表示法轉換成 `Int32`。

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

和二進位一樣，給予錯誤的基數會引發 `ArgumentError`。

## 十六進位

[十六進位][hexadecimal]是基數 16 的數字系統。
它使用數字 0 到 9，以及字母 A、B、C、D、E、F。
A 是 10，B 是 11，C 是 12，D 是 13，E 是 14，F 是 15。

我們可以在 Crystal 中用 `0x` 前綴來表示十六進位數字。
和二進位、八進位一樣，Crystal 會自動將十六進位字面值轉換成 `Int32`。

```crystal
#=> 0x123
291
```

在非十六進位的數字前加上 `0x` 會引發編譯錯誤。

### 十六進位表示法的雙向轉換

和二進位一樣，我們可以使用 [`<int>.to_s(base)`][to_i] 方法，將 `Int32` 轉換成十六進位表示法。
我們也可以使用 [`<int>.to_i(base)`][to_s] 方法，將十六進位表示法轉換成 `Int32`。

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

和二進位、八進位一樣，給予錯誤的基數會引發 `ArgumentError`。

## 精度

將數字轉換成字串表示法時，我們可以指定該數字的精度。
也就是用來表示這個數字的**最少**位數。
如果數字的位數比精度少，就會在字串表示法的前面補上零。
這是透過將 `precision` 引數傳給 [`<int>.to_s(<base>, precision: <value>)`][to_s] 方法來完成。

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## 大寫

將數字轉換成字串表示法時，我們可以指定是否要將字串中的字母轉成大寫。
這是透過將 `upcase` 引數傳給 [`<int>.to_s(<base>, upcase: <value>)`][to_s] 方法來完成。

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
