# 說明

你的朋友 Chandler 計劃到世界各地充滿異國風情的國家旅行。可惜的是，Chandler 的數學不太好。他很擔心在旅途中被貨幣兌換騙錢，所以希望你能幫他做一個貨幣計算機。以下是他為這個應用程式所列的規格：

## 1. 估算兌換後的價值

建立`exchange_money()`函式，它接受 2 個參數：

1. `budget`：你打算兌換的金額。
2. `exchange_rate`：相當於一單位外幣的本國貨幣金額。

這個函式應該回傳兌換後的貨幣價值。

**注意：** 如果你的貨幣是 USD，而你想以`1.20`的匯率把 USD 兌換成 EUR，那麼`1.20 USD == 1 EUR`。

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. 計算兌換後剩下的貨幣

建立`get_change()`函式，它接受 2 個參數：

1. `budget`：兌換前的金額。
2. `exchanging_value`：從預算中*取出*用來兌換的金額。

這個函式應該回傳預算中*剩下*的金額。

```python
>>> get_change(127.5, 120)
7.5
```

## 3. 計算紙鈔的價值

建立`get_value_of_bills()`函式，它接受 2 個參數：

1. `denomination`：單張紙鈔的面額。
2. `number_of_bills`：紙鈔的總張數。

這個兌換窗口只收受特定面額單位的現金。
你收到的總金額必須能被一張「紙鈔」或單位的價值整除，而這可能會留下小數或餘數。
你的函式應該只回傳兌換窗口會找給你的紙鈔總價值（_不含小數部分_）。
可惜的是，剩下的餘數或零頭就歸兌換窗口所有，當作額外的好處。

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. 計算紙鈔的張數

建立`get_number_of_bills()`函式，接受`amount`和`denomination`。

這個函式應該回傳在給定的_amount_之內，你能收到的_紙鈔張數_。
換句話說：起始的金額裡可以容納多少張_整張的紙鈔_？
記住，你只能收到_整張的紙鈔_，不能收到不足一張的部分，所以要記得據此做除法。
實際上，你就是_向下_取整到最接近的整張紙鈔或面額。

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. 計算兌換成紙鈔後的剩餘金額

建立`get_leftover_of_bills()`函式，接受`amount`和`denomination`。

這個函式應該回傳在給定紙鈔面額的情況下，無法從你起始的_amount_中兌換回來的_剩餘金額_。
確切知道兌換窗口能留下多少錢，非常重要。

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 計算兌換後的價值

建立`exchangeable_value()`函式，接受`budget`、`exchange_rate`、`spread`和`denomination`。

參數`spread`是以整數表示、作為兌換手續費*收取的百分比*。
你需要將它除以 100 換算成小數。
如果`1.00 EUR == 1.20 USD`，而*spread*是`10`，實際的匯率會是：`1.00 EUR == 1.32 USD`，因為 1.20 的 10% 是 0.12，而這筆額外的手續費會加到兌換上。

這個函式應該回傳在計算*匯率*加上*spread*之後，新貨幣的最大價值。
記住，貨幣的*面額*是整數，無法再細分。

**注意：** 回傳值應為`int`型別。

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
