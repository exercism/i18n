# 提示

## 一般

- 如果需要重溫基礎，可以再看一次[物件概念][concept-class-basics]。
- 請仔細閱讀說明中關於`x`、`y`、`width`和`height`參數位置的部分，這些很容易搞混。

## 1. 定義 ProgramWindow 類別

- 記得在這項任務中使用[類別語法][php-class]。
- 將[屬性][php-properties]加入類別宣告中來定義它們。

## 2. 為 ProgramWindow 類別定義建構函式

- 確認你的建構函式不接受任何引數。
- 確認每個屬性都設為預期的整數值。

## 3. 新增方法來調整視窗大小

- 記得在這項任務中於`Size.php`檔案裡使用新的[類別][php-class]。
  - 依照慣例，檔案通常只包含一個類別。
- `Size`建構函式應接受引數，用於設定該類別[屬性][php-properties]的初始值。
- 為`ProgramWindow`物件建立一個`resize`方法，使用`Size`的實例來套用這項變更。

## 4. 新增方法來移動視窗

- 記得在這項任務中於`Position.php`檔案裡使用新的[類別][php-class]。
  - 依照慣例，檔案通常只包含一個類別。
- `Position`建構函式應接受引數，用於設定該類別[屬性][php-properties]的初始值。
- 為`ProgramWindow`物件建立一個`move`方法，使用`Position`的實例來套用這項變更。
