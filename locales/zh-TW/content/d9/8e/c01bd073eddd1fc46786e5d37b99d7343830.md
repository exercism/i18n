# 指示

Lucy 經營著一家線上貼紙商店，專門販售以大家最愛的程式語言為主題的可愛貼紙。世界各地的顧客都會來向她購買貼紙，而面對這麼多種不同的貨幣，她應付起來有點吃力。

請寫一個程式，讓 Lucy 能用它來計算價格，同時確保她每次都使用正確的貨幣。

## 1. 定義`Usd`、`Eur`和`Jpy`型別

這些型別用來代表 Lucy 的顧客購買貼紙時所使用的各種貨幣。

它們要當作幽靈型別使用，不需要有任何建構子。

## 2. 定義`Money`型別

`Money`型別應該有一個代表金額的`Int`欄位、一個貨幣幽靈型別參數，並且是一個不透明型別。

## 3. 定義`dollar`、`euro`和`yen`函式

定義`dollar`、`euro`和`yen`函式，它們接受一個`Int`引數，並回傳帶有正確貨幣的`Money`值。

## 4. 定義`total`函式

定義`total`函式，它接受一個由`Money`值組成的陣列，並回傳該陣列中所有金額的總和。

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
