# 說明

你是一位專業的調酒師，負責為夜晚外出放鬆的客人調製美味飲料。但你想到，只要寫一點程式碼來協助工作，就能讓日子輕鬆一些。

## 1. 判斷製作一份訂單需要多少時間

不同的飲料需要的準備時間不同：

- `"beer"`、`"soda"`和`"water"`各需要 0.5 分鐘。
- `"shot"`需要 1.0 分鐘，`"mixed drink"`需要 1.5 分鐘，
- `"fancy drink"`需要 2.5 分鐘，
- `"frozen drink"`需要 3.0 分鐘。

實作函式`timeToPrepare(drinks:)`，它接受引數`drinks`，該引數是一個字串陣列，代表需要準備的飲料。
這個函式應回傳準備陣列中所有飲料所需的總時間。

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. 補充你的萊姆角存量

開始值班時，你要做的第一件事之一，就是確保裝萊姆角的小盒子為接下來的一班補滿。
萊姆有不同的大小，能切出的萊姆角數量也不同：一顆 "small" 萊姆可以切出 6 個萊姆角，一顆 "medium" 萊姆可以切出 8 個，一顆 "large" 萊姆則可以切出 10 個。

只要你還需要更多萊姆角，而且還有萊姆可以切，就從陣列中取出第一顆萊姆，並從你需要的數量中扣掉它對應的萊姆角數量。
持續這個過程，直到你不再需要任何萊姆角，或是萊姆用完為止。

實作函式`makeWedges(needed:limes:)`，它接受引數`needed`，代表你需要切出的萊姆角數量，以及`limes`，代表一個字串陣列，內含你可以切的萊姆大小。
這個函式應回傳你總共切了幾顆萊姆。

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. 完成你的值班

恭喜！漫長的工作日快要結束了，你很快就能回家開發你的新應用程式。
但在你把訂單交接給下一班、離開之前，還有一連串的飲料訂單要做。

只要值班時間還有剩，你就要製作陣列中的第一筆訂單，然後把該筆訂單從陣列中移除。
接著，你可以依照函式`timeToPrepare(drinks:)`算出準備那筆訂單所花費的時間，並從剩餘的值班時間中扣掉。

實作函式`finishShift(minutesLeft:remainingOrders:)`，它接受你值班剩餘的分鐘數（保證大於 0），以及一個非空的飲料訂單陣列。
這個函式應回傳在你值班結束前還來不及處理的訂單陣列。

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. 追蹤特定的訂單

為了確保啤酒和汽水保持新鮮，你需要追蹤它們的訂單以及下單的時間。

實作函式`orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`，它在給定一份訂單與時間的清單時，回傳一對選擇性的元組，內含啤酒與汽水第一筆及最後一筆訂單的時間，以及各自的訂單總數；若沒有那些飲料的訂單，則值為`nil`。你不需要追蹤其他任何飲料。

實作函式`orderTracker(orders:)`，它接受一個元組陣列，其中每個元組包含所點的飲料以及下單的時間。
這個函式應回傳一個元組，內含啤酒第一筆與最後一筆的下單時間、啤酒訂單總數、汽水第一筆與最後一筆的下單時間，以及汽水訂單總數。
其格式應為：`(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`。

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
