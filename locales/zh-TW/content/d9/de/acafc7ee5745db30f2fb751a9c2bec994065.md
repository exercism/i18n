# 介紹

## 常數

Gleam 中的常數是一種為值取名字的方式。它們是用`const`關鍵字定義的。

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

用`pub`關鍵字定義的模組常數可以從其他模組存取，否則就只能從定義它們的模組內存取。

## 順序

Gleam 標準函式庫中的`gleam/order`模組包含了`Order`型別，用來比較值。

`Order`的定義看起來像這樣：

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

這個型別有三個變體，分別用來表示某個值與另一個值之間的關係：

- `Gt`：這個值_大於_另一個值。
- `Eq`：這個值_等於_另一個值。
- `Lt`：這個值_小於_另一個值。

如果某個資料型態可以比較大小，模組通常會定義一個回傳`Order`值的`compare`函式。例如，`gleam/float`和`gleam/int`分別定義了可處理浮點數和整數的`compare`函式。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

像`list.sort`這樣的排序函式通常會接收一個回傳`Order`值的函式，讓呼叫端可以定義陣列該如何排序。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
