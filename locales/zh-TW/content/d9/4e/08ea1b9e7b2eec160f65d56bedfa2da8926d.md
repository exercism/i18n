# 簡介

向量是一維陣列。它們可以包含不同型別的元素。

## 建立向量

向量可以透過`vector`函式建立，也可以使用它的讀取器形式`#()`。

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

因為向量是陣列，所以也可以用`make-array`建立：

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## 向量述詞

若要檢查某個物件是否為向量，只要使用述詞`vectorp`就好。

## 存取元素

要存取向量中的元素，請使用`aref`，索引從 0 開始：

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
