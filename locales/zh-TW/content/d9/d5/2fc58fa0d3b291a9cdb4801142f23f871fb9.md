# 提示

## 一般

關於繼承的詳細說明，請見[繼承][inheritance-concept]。
整個繼承概念和[覆寫][java-overriding]相關的概念有很大的關係。

## 1. 建立 Warrior 類別

- 複習 [concept:java/classes](https://github.com/exercism/java/tree/main/concepts/classes) 概念。
- 複習[繼承][inheritance-concept]概念。

## 2. 描述 Warrior

- 在 Java 中，`toString()`方法其實存在於 `Object` 類別裡（它是 Java 中所有類別的父類別）。
  你可以在官方的 [Oracle 文件][object-class-java] 閱讀更多相關內容。
- 若要在你的實作類別中覆寫這個方法，你應該有一個名稱相同（即 `toString()`）、回傳型別也相同（即 `String`）的方法。
- `toString()`方法必須是 `public`。

## 3. 讓 Warrior 不受傷害

- 在 `Warrior` 類別中覆寫 `isVulnerable()`方法，讓 Warrior 永遠不會受傷。

## 4. 計算 Warrior 的傷害點數

- 在 `Warrior` 類別中覆寫 `getDamagePoints(Fighter)`方法。
- 使用[條件式][if-else]來回傳傷害點數，並將目標是否處於受傷狀態納入考量。

## 5. 建立 Wizard 類別

- 複習 [concept:java/classes](https://github.com/exercism/java/tree/main/concepts/classes) 概念。
- 複習[繼承][inheritance-concept]概念。

## 6. 描述 Wizard

- 在 Java 中，`toString()`方法其實存在於 `Object` 類別裡（它是 Java 中所有類別的父類別）。
  你可以在官方的 [Oracle 文件][object-class-java] 閱讀更多相關內容。
- 若要在你的實作類別中覆寫這個方法，你應該有一個名稱相同（即 `toString()`）、回傳型別也相同（即 `String`）的方法。
- `toString()`方法必須是 `public`。

## 7. 讓 Wizard 可以準備咒語，並在尚未準備咒語時處於受傷狀態

- 只有 Wizard 才能準備咒語。因此，將這個屬性定義在 `Wizard` 類別裡是合理的。
- 在 `Wizard` 類別裡建立 `prepareSpell()`方法。
- 記住：父類別（這裡是 `Fighter`）無法存取子類別（例如 `Wizard`）的屬性。
- 記住：由於這個方法沒有回傳型別，你應該改用 `void`。
- 在 `Wizard` 類別中覆寫 `isVulnerable()`方法，讓尚未準備咒語的 Wizard 處於受傷狀態。

## 8. 計算 Wizard 的傷害點數

- 在 `Wizard` 類別中覆寫 `getDamagePoints(Fighter)`方法。
- 使用[條件式][if-else]來回傳傷害點數，並將準備咒語欄位的值納入考量。
