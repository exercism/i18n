# 簡介

## 布林值

`Bool`型別是這個程式語言的基礎之一。
它用來描述某件事是 true 還是 false，分別對應 `True` 和 `False` 這兩個值。

布林值可以用 `&&`「AND」和 `||`「OR」運算子組合，也可以用 `not`函式取反。

布林值也非常適合用來在程式碼中建立分支，這些分支只有在符合某些條件時才會執行。
在 Elm 中，這是用 `if-then-else`運算式完成的，用法如下。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
