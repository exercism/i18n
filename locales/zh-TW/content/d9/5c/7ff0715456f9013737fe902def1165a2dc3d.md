# 簡介

`Complex numbers`其實一點也不複雜。它們只是需要一個不那麼嚇人的名字。

它們非常實用，尤其是在工程與科學領域，因此 Julia 把複數納入標準數值型別，與整數、浮點數並列。

## 基礎

在 Julia 中，一個`complex`值基本上就是一對數字：通常是浮點數，但不一定都是。基於一些不幸的歷史原因，這兩個部分被稱為「實部」與「虛部」。同樣地，最好把重點放在它背後的單純概念，而不是這些奇怪的名字。

想從兩個實數建立複數，只要在虛部加上後綴`im`即可。

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> typeof(z)
ComplexF64 (alias for Complex{Float64})
julia> zi = 1 + 2im
1 + 2im
julia> typeof(zi)
Complex{Int64}
```

因此，`Complex`有各種不同的型別，分別對應到整數或浮點數型別。

如果想用實數變數建立複數，上面的寫法行不通。寫成`a + bim`會讓解析器誤以為`bim`是一個（不存在的）變數名稱。

寫成`b*im`也可以，但比較建議的做法是使用`complex()`函式，這樣就能避開乘法與加法運算。

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

想個別取得複數的各個部分：

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> real(z)
1.2
julia> imag(z)
3.4
```

或是同時取得兩者：

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

任一部分都可以是零，數學家可能會因此說這個數「全然是實數」或「全然是虛數」。不過在 Julia 裡，它仍然是一個複數。

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im
julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})
julia> zi = 3.4im
0.0 + 3.4im
julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

你可能聽過「`i`（或`j`）是 -1 的平方根」這種說法。

就目前而言，這只表示虛部_依定義_會滿足以下的等式：

```julia-repl
julia> 1im * 1im == -1
true
```

這是個簡單的概念，卻會帶來有趣的結果。

## 算術

所有搭配浮點數與整數使用的標準數學`operators`與初等函式，也都適用於複數。以下舉幾個例子：

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im
julia> z2 = 2 + 1.5im
2.0 + 1.5im
julia> z1 + z2  # addition
3.5 + 3.5im
julia> z1 * z2  # multiplication
0.0 + 6.25im
julia> z1 / z2  # division
0.96 + 0.28im
julia> z1^2  # exponentiation
-1.75 + 6.0im
julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## 函式

除了`real()`與`imag()`之外，還有幾個函式與複數特別相關。

- `conj()`只是把複數虛部的正負號反轉（_由 + 變成 -，或反過來_）。
    - 由於複數乘法的運作方式，這個函式的實用性比你想像的還高。
- `abs(<complex number>)`保證會回傳一個沒有虛部的實數。
- `abs2(<complex number>)`會回傳`abs(<complex number>)`的平方：計算起來比`abs()`更快，而且常常正是計算所需要的。
- `angle(<complex number>)`會回傳以弧度為單位的相位角。

```julia-repl
julia> z1
1.5 + 2.0im
julia> conj(z1)
1.5 - 2.0im
julia> abs(z1)
2.5
julia> abs2(z1)
6.25
julia> angle(z1)
0.9272952180016122
```
針對喜歡數學的人，這裡提供部分的說明：

- `z1`的`(real, imag)`表示法，實際上就是在複數平面上使用笛卡兒座標。
- 同一個複數也可以用`(r, θ)`標記法來表示，也就是使用極座標。
- 在這裡，`r`與`θ`分別由`abs(z1)`與`angle(z1)`得出。

以下是一個使用一些常數的例子：

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im
julia> real(euler)
-1.0
julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

`(r, θ)`極座標標記法非常實用，因此 Julia 內建了`cis`（`cos(x) + isin(x)`的縮寫）與`cispi`（`cos(πx) + isin(πx)`的縮寫）這兩個函式，可以幫助你更有效率地建構它。

極座標標記法的妙用，體現在歐拉優雅的公式`ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`，其中`|x + iy| = 1`。當`|x + iy| = r`時，我們就得到更一般的極座標形式`r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`。特別值得一提的是，指數形式既簡潔又容易操作。

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

上面之所以是近似相等，是因為`cis`與`cispi`這兩個函式能給出更漂亮的數值輸出，尤其是`cispi`，在處理引數為 π 的任意倍數（例如弧度！）時更是如此。

```julia-repl
julia> cis(π)
-1.0 + 0.0im
julia> cispi(1)
-1.0 + 0.0im
julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im
julia> cis(θ)
6.123233995736766e-17 + 1.0im
julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

順帶一提，這讓複數在 2D 中進行旋轉與徑向位移時非常實用。

就旋轉而言，複數`z = x + iy`只要簡單地乘上一個數，就能繞原點旋轉`θ`角：`z * ℯ^(iθ)`。注意這裡的`x`與`y`就只是實數 2D 笛卡兒平面上的一般座標，正的角度會造成*逆時針*旋轉，而負的角度則造成*順時針*旋轉。

同樣簡單地，只要把徑向位移`Δr`加到極座標形式複數的大小`r`上，就能完成位移（例如`z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`）。注意角度部分保持不變，只有大小`r`改變，一如預期。
