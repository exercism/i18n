# 提示

## 一般

- `unparse` 位於 [`prettyprint`][prettyprint] 裡；切片相關的變體在 [`sequences`][sequences] 中；多輸入的 cleave 系列則在 [`combinators`][combinators] 裡。

## 1. 將值加上引號

- 一個字：`unparse`。

## 2. 剝除旗標的外框

- 用 `1 tail-slice` 去掉開頭的標記，再用 `1 head-slice*` 去掉結尾的標記。

## 3. 拆分旗標

- `head-slice` 和 `tail-slice` 都需要堆疊上有旗標*和*標頭長度。也就是 `[ head-slice ] [ tail-slice ] 2bi`。

## 4. 由兩組讀數三角定位

- 三個不同的引述，每個都取相同的兩組讀數：`[ - ] [ + 2 / ] [ / ] 2tri`。

## 5. 彙總三組讀數

- 三個引述，每個各取三個輸入：`3tri`。求和的引述是 `[ + + ]`；求積的是 `[ * * ]`；求最大值的是 `[ max max ]`。
