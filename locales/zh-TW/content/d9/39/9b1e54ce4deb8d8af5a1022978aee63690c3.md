# 關於

## 引入

C++ 使用 `include` 指令來引入其他檔案的內容。
這些引入指令應該寫在檔案的最上方。
編譯期間，帶有指令的那一行會被對應檔案的內容取代。
引入之後，命名空間仍與原始檔案中相同。

## 標準函式庫

標準函式庫提供許多常用的函式、演算法和資料結構。
標準函式庫使用 `std` 命名空間。

其中一個例子是 C 的數值函式庫 `cmath`。
它提供許多常見的數學運算。

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
標準函式庫使用尖括號 `<>` 引入，而不是雙引號 `"`。
差別在於編譯器搜尋對應檔案的位置。
使用尖括號的版本會略過在目前專案中的搜尋，直接從系統的引入目錄開始。
如果你想引入本機檔案，就要使用雙引號：`#include "myfile"`
~~~~
