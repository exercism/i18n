# 安裝

你需要 [Vim](http://www.vim.org) 才能完成這些練習：

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [從原始碼建置](#source)

## macOS

macOS 預設就隨附 Vim，但內建的版本已經過時到難以使用。

你安裝軟體時，用的很可能是 [MacPorts](https://www.macports.org) 或
[Homebrew](https://brew.sh)。

Homebrew：

```
$ brew update
$ brew install vim
```

MacPorts：

```
$ sudo port install vim +huge
```

如果你想要圖形介面，可以改用 [MacVim](https://macvim-dev.github.io/macvim)。

## Ubuntu / Debian

安裝功能完整、支援圖形介面的 Vim（`gvim`）：

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

使用 [Chocolatey](https://chocolatey.org)：

```
C:\> choco install vim
```

或者直接從[這裡](http://www.vim.org/download.php#pc)下載並安裝。

## 從原始碼建置

如果你想自己編譯最新版的 Vim，請參考 [GitHub 上的官方儲存庫](https://github.com/vim/vim)。
