# 簡介

*泛型詞*會宣告一項操作，這項操作可以根據引數的類別而有不同的實作。方法是使用`M:`加入的。

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:`會宣告詞本身以及它的堆疊效應。`M:`則是在某個特定類別上定義方法。Factor 會在執行時依據最上層引數的類別來分派。

你可以詢問泛型詞它有哪些類別的方法，也可以事後新增或移除方法。這裡沒有特別的繼承語法：任何 tuple 類別都自動可以在其上定義方法。
