# 關於

## if 運算式

`jq`的**條件運算式**是`if A then B else C end`。

`if-then-else`就像所有`jq`內建函式一樣，是個篩選器：它接收輸入並產生輸出。

如果運算式`A`產生「真值」，`if`篩選器就會求值`B`。
否則會求值`C`。
`if`篩選器的輸入會傳遞給`B`或`C`。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`子句是**選用的**；下面兩個敘述是等價的。

```jq
if A then B else . end
if A then B end
```
~~~~

## 巢狀 if 敘述

可以用`elif`加上更多條件。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

需要多少`elif`子句就用多少。

## 真值

`jq`中唯一的「假」值是：`false`和`null`。
其他一切都是「真」，連數字零、空字串、空陣列和空物件也是。

## 布林運算子

**布林運算子**`and`和`or`可以用來建立複雜的查詢。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

要取反，請用`not`。它是**篩選器**，不是運算子。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## 替代運算子

**替代運算子**讓你能在運算式為假或 null 時指定「預設」值。

```jq
A // B

# This is identical to
if A then A else B end
```

舉例來說

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```

## 還有更多嗎？

來自其他程式語言的程式設計師，可能會期待更多種類的條件指令，例如`cond`、`case`、`switch`、`when`、`unless`、三元運算子等等。
上面列出的運算子就是`jq`提供的全部。
