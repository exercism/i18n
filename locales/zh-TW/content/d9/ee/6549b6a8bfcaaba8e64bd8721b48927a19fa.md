# 條件判斷入門

## Bash 中的真值判斷

Bash 沒有布林值這個概念。
它只有字串和數字，以及由字串或數字組成的陣列。
那麼，條件指令要如何處理 true 和 false 呢？

## 結束狀態

指令結束時會產生一個_結束狀態_（exit status）。
結束狀態是介於 0 到 255（含）之間的整數。
Bash 認為結束狀態為**零**代表_成功_。
任何其他的結束狀態則代表_失敗_。

這適用於所有指令，包括 Bash 的內建指令、關鍵字和函式。

## `if` 指令

`if` 指令的基本語法是

```bash
if CONDITIONAL_COMMANDS; then TRUE_COMMANDS; else FALSE_COMMANDS; fi
```

它以 `if` 開頭；條件指令與「成功」指令之間以 `then` 分隔；最後以 `fi` 結束。
`else` 分支是選用的。

CONDITIONAL_COMMANDS 可以是單一指令，也可以是一份[指令清單][command-list]。

CONDITIONAL_COMMANDS 會被執行，然後

* 如果結束狀態為零（成功），就會執行 TRUE_COMMANDS。
* 如果結束狀態為非零（失敗），就會執行 FALSE_COMMANDS，前提是它們存在。

可以用 `elif` 串接多個分支
```bash
if CONDITIONAL_COMMANDS
then TRUE_COMMANDS
elif CONDITIONAL_COMMANDS_2
then TRUE_COMMANDS_2
# more elif branches ...
else FALSE_COMMANDS
fi
```

在 `then`、`elif`、`else` 和 `fi` 這些字之前，必須要有分號或換行。

特別強調：控制流程的是條件指令的**結束狀態**。
舉例來說，`grep` 在找到符合的項目時會回傳 0，找不到時則回傳 1。
`-q` 選項會抑制輸出，只產生結束狀態。

```bash
if grep -q "my pattern" my_file; then echo "the pattern is found in the file"; fi
```

## `[` 和 `test` 指令

CONDITIONAL_COMMANDS 本身並沒有特殊的語法。
你可能習慣看到像這樣的 if 敘述：

```if
if [ "$password" = "secure" ]; then
    echo "Welcome!"
fi
```

`[` 並不是特殊語法。
它是一個_指令_，會評估條件運算式，並以成功或失敗的狀態結束。
和所有指令一樣，它與引數之間**必須**有空白。

`[` 其實是 `test` 指令的同義詞。
兩者完全相同，唯一的差別是 `[` 的最後一個引數_必須_是 `]`。

### 條件運算式

在 `[` 和 `]` 之間，你要寫一個條件運算式。
一些常見的條件運算式包括：

```bash
[ -f "$filename" ]             # file operations
[ "$string1" = "$string2" ]    # string comparisons
[ "$num1" -eq "$num2" ]        # arithmetic comparisons
```

還有更多可用的運算；它們列在手冊的 [Bash 條件運算式][cond-expr] 一節中。

~~~~exercism/note
在上面這些範例中，請注意所有變數都加了引號。
`test` 和 `[` 指令是單純的指令，它們的引數就像其他指令一樣，會受到單字分割和檔名展開的影響。

這點必須特別說明，因為條件運算式會依你提供_多少個引數_而有不同的評估方式：

* 0 個引數：結束狀態為非零（失敗）
* 1 個引數：如果引數不是空的，結束狀態為零（成功）；如果引數是空的，則為非零。
* 2 個引數：第一個引數必須是一元運算子（例如 `[ -z "$name" ]`），或者是 `!`（將單一引數測試的狀態反轉）
* 以及[更多][test]情形。

如果你忘記加引號，可能會得到意想不到的結果：

```bash
str=""

# this prints "empty"
if [ -n "$str" ]; then echo "not empty"; else echo "empty"; fi

# leaving the variable unquoted results in incorrect "not empty" output
if [ -n $str ]; then echo "not empty"; else echo "empty"; fi
```

[test]: https://www.gnu.org/software/bash/manual/bash.html#index-test
~~~~

## `[[` 關鍵字

[`[[...]]` 條件結構][cond-construct]不是_指令_，而是一個**關鍵字**。
這表示，雖然它的處理方式和一般指令無異，但它有特殊的解析規則。
`[[` 特別的地方在於，在其中展開的變數**不會**受到單字分割或檔名展開的影響。
這表示即使不加引號，這個指令的行為也會符合你的預期。

```bash
if [[ -n $str ]]; then echo "not empty"; else echo "empty"; fi
```

`[[` 支援 `test` 和 `[` 能處理的所有條件運算式。
除此之外，`[[` 還提供

* `=~` 正規表示式比對運算子，
* `==` 和 `!=` 可作為 glob 樣式比對運算子，
* `&&` 和 `||` 可作為邏輯運算子（特殊解析規則），
* `<` 和 `>` 可作為「裸」字串比較運算子（特殊解析規則：因為這些是重導向符號，在 `[` 中必須經過跳脫）。

普遍認為，這些特殊功能帶來的好處太大，因此應該只用 `[[`。
（例如 [Google Shell Style Guide][goog-test]。）

## `case` 指令

[`case`][case] 是另一種控制流程指令。
它類似其他語言中的「switch」敘述。

```bash
case WORD in [PATTERN [| PATTERN]...) COMMANDS ;;]... esac
```

WORD 會逐一與每個 PATTERN 比對。
當某個樣式符合時，就會執行對應的 COMMANDS。

```bash
read -p "Guess the secret word: " word
case "$word" in
    secret) echo "Yes, you guessed it!" ;;
    ??????) echo "That's the right number of letters." ;;
    s*)     echo "You guessed the first letter." ;;
    *)      echo "Not even close! Try again." ;;
esac
```

每個 COMMANDS 子句都必須以**兩個**分號 `;;` 結尾。
