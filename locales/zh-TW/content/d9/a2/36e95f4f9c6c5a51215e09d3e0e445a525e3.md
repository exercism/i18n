# 簡介

在 Go 裡，你可以搭配索引並使用 `for` 對 `slice` 進行疊代，也可以使用 `range`。`range` 還能讓你對 `map` 進行疊代。

每次疊代都會回傳兩個值：索引／鍵，以及該索引／鍵對應元素的副本。

## 對 slice 進行疊代

對 slice 執行迴圈輕而易舉，順序也和預期的一樣。

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## 對 map 進行疊代

對 map 進行疊代則會出現新的問題：順序變成隨機的。

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
上面的輸出看起來可能不太對，因為大家會預期在 map 宣告中排第一個的鍵／值組合 `9 10` 應該最先印出，而不是最後印出。
然而，map 本質上是無序的，並沒有所謂的第一個或最後一個鍵／值組合。
因此，對 map 的項目進行疊代時，項目的存取順序是隨機的，不會依循任何特定模式。
這表示上面的輸出是可能發生的，但你實際執行時得到的結果可能不同。
想了解更多，請參閱 [Go 語言規格：range 子句](https://go.dev/ref/spec#RangeClause)。
~~~~

## 略過鍵或值的疊代

在 Go 裡，未使用的變數會在建置時產生錯誤。
有時你只需要值，就像第一個範例那樣：

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

你可以用 `_` 取代 `i`，告訴編譯器我們不使用那個值：

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

如果你只想印出索引，可以用 `_` 取代 `x`，或是乾脆省略宣告：

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## 非 struct 型別

你之前看過如何定義 struct 型別。
你也可以定義非 struct 型別，把它們當作內建型別的別名，並在這些型別上定義接收者函式，用和 struct 型別一樣的方式擴充它們。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

你也可以定義由陣列和 map 組成的非 struct 型別。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
