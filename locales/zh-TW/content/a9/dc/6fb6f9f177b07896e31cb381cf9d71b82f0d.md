# 說明補充

## 專案結構

Exercism 上的 Clojure 練習使用 [leiningen](http://leiningen.org/) 來設定並執行你的程式碼，並採用 [leiningen 的標準目錄結構](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout)。

你會在`test`目錄裡找到一個名為`hello_world_test.clj`的測試檔。請把你的程式碼寫在`src/hello_world.clj`。它應該使用命名空間`hello-world`，這樣測試才能找到它。

## 執行測試

使用`lein test`指令執行測試，並讓它們全部通過：

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

接著用以下指令提交練習：

```
$ exercism submit src/hello_world.clj
```

更詳細的說明與學習資源，請參考 [Exercism 的 Clojure 語言頁面](http://exercism.io/languages/clojure)。
