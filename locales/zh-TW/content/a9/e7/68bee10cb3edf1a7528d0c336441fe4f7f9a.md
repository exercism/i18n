# 關於

[結構][structs-and-classes]（通常稱為 *structs*）是 Swift 程式的主要組成要素之一。
結構讓你建立自訂型別，把相關的屬性（資料）和方法（行為）群組在一起。
事實上，Swift 的標準型別，包括 `Int`、`Double`、`Bool`、`String`、`Array` 和 `Dictionary`，全都是用結構實作的。

## 定義結構

使用 `struct` 關鍵字定義結構，後面接著型別名稱，以及包含其定義的大括號。
依照 Swift 慣例，結構名稱使用 `UpperCamelCase`：

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## 建立實例

結構定義只是一份藍圖。
要建立結構的*實例*，就呼叫它的初始化器：寫出型別名稱，後面加上括號：

```swift
var someStats = CharacterStats()
```

這會建立一個實例，並以定義中的預設屬性值填入。

Swift 也會為結構自動產生**成員逐一初始化器**，讓你依名稱初始化屬性：

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## 存取與修改屬性

你可以用*點語法*存取並修改實例的屬性：

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

由於結構是值型別，要修改實例的屬性，實例本身就必須以 `var` 宣告。
如果實例以 `let` 宣告，它的所有屬性都會變成不可變。
