# 操作說明

在你繼續於 _Instruments of Texas_ 工作的同時，RPN 計算機的 Elixir 實作也有了進展。你的團隊希望能引發比標準函式庫提供的通用錯誤更具體的錯誤。你正在做一些研究，但已經決定要實作兩個新的錯誤，這兩個錯誤會實作 _Exception Behaviour_。

## 1. 除以零的錯誤

將一個數字除以零會產生未定義的結果，團隊認為用錯誤來表示最為合適。

實作`DivisionByZeroError`模組，讓它的錯誤訊息為：`"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. 遇到堆疊下溢時的錯誤

RPN 計算機使用_堆疊_來追蹤尚未相加的數字。團隊用數字（整數和浮點數）的陣列來表示這個_堆疊_，例如：`[3, 4.0]`。每個運算需要在堆疊上有特定數量的數字，才能執行計算。當堆疊上的數字不夠時，就稱為堆疊下溢錯誤。實作`StackUnderflowError`例外，它提供一則預設訊息，以及可選的額外情境資訊。

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. 撰寫除法函式

實作`divide/1`函式，它接收一個堆疊_（兩個數字組成的陣列）_，並且：

- 當堆疊沒有包含足夠的數字時，引發_堆疊下溢_
- 當除數為 0 時，引發_除以零_（注意，堆疊中的數字是以相反的順序儲存的）
- 當沒有引發任何錯誤時，執行除法

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> 注意，陣列的順序是相反的！
