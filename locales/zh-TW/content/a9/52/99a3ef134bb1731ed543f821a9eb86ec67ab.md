# 簡介

`|>`運算子稱為管道運算子。它能串接一連串的函式呼叫，讓前一個函式呼叫回傳的值傳給下一個函式呼叫。

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

上面的程式碼等同於下面這樣：

```gleam
string.append(string.uppercase("hello"), "?!")
```

管道運算子會把值當作第一個引數傳入函式呼叫，或是當作新呼叫的唯一引數，並自動選擇型別正確的那一種。

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

有時候我們想把值傳到其他位置，這時可以用`_`佔位符來指出值應該插入的地方。

```gleam
100
|> some_function(1, _, 2)
```
