# 關於

迴圈是一種重複呼叫一批一或多個敘述的方式。
每一次執行一批敘述，稱為一次疊代。

## `while` 迴圈

當迴圈頂端的布林運算式為 true 時，`while` 迴圈會執行一批敘述。
當布林運算式為 false 時，迴圈會停止執行，並接著執行迴圈之後的下一行程式碼。

如果布林運算式一開始就求值為 false，`while` 迴圈完全不會執行，執行流程會直接進到迴圈之後的下一行程式碼。

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

迴圈一定要有結束的條件，否則就會變成無限迴圈，讓程式完全無法繼續進行。
如果上面那段程式碼把 `i` 的 `++` 拿掉，就會變成無限迴圈。

## `do` 迴圈

`do` 迴圈的布林運算式是在迴圈底部才測試。
`do` 迴圈至少會執行一次，如下例所示

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

改用 `while` 迴圈的話，寫法會冗長許多

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` 迴圈

迴圈經常會更新某個變數，並在變數達到特定值時結束。
`for` 迴圈可以在一行的小括號內，完成一或多個變數的初始化、更新與測試。
第一個區段用來初始化變數，第二個區段用來測試變數，第三個區段則用來更新變數的值。

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

這比等效的 `while` 迴圈精簡，而且仍然容易閱讀。

`for` 迴圈的初始化與更新區段可以處理多個變數，只要用逗號運算子分隔條件裡的運算式即可。

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

這會印出

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

`for` 迴圈的各個區段都不一定要填。
空的測試運算式會求值為 true，所以可以用 `for` 迴圈寫出無限迴圈，像這樣

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

這和 `while` 迴圈很像，`i` 都在迴圈之前初始化，並在迴圈內遞增。
此外，`i` 是在迴圈內測試，而迴圈則以 `break` 敘述結束。

## `break` 敘述

有時迴圈可能需要在布林運算式沒有測到的特殊條件下結束。
`break` 敘述會結束迴圈，並接著執行迴圈之後的下一行程式碼。

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

這會印出

```
i is 0
j is 5
After the loop
```

## `continue` 敘述

有時迴圈可能需要在不執行完目前這輪疊代的情況下，就開始下一輪疊代。
`continue` 敘述會停止目前這輪疊代的執行，並從下一輪疊代的開頭繼續執行。

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

這會印出

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

當 `i` 和 `j` 都是 `2` 時，它不會印出它們的值。
