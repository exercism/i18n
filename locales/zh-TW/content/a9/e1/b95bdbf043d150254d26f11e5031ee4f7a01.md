# 關於

`use`巨集讓我們能快速用其他模組提供的功能來擴充自己的模組。當我們`use`一個模組時，該模組可以把程式碼注入我們的模組中，例如定義函式、`import`或`alias`其他模組，或是設定模組屬性。

如果你看過 Exercism 上一些 Elixir 練習的測試檔案，很可能會注意到它們全都以`use ExUnit.Case`開頭。就是這一行程式碼，讓`test`和`assert`這兩個巨集可以在測試模組中使用。

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## `__using__/1`巨集

當你`use`一個模組時，實際會發生什麼事，取決於該模組的`__using__/1`巨集。它接受一個引數，也就是帶有選項的關鍵字清單，並回傳一個[引用的運算式][concept-ast]。呼叫`use`時，這個引用運算式中的程式碼會被插入我們的模組。

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

呼叫`use`時，選項可以當作第二個引數傳入，例如`use ExUnit.Case, async: true`。如果沒有明確指定，它們會預設為空陣列。

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
