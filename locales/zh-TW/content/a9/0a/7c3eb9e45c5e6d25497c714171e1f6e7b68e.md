# 簡介

[結構與類別][structs-and-classes]是 Swift 中建立自訂型別的主要建構基礎。
兩者都能讓你將相關的屬性（資料）與方法（行為）組成可重複使用的單位。
Swift 中大多數核心型別，包括`Int`、`Double`、`String`，以及像`Array`和`Dictionary`這樣的集合型別，都是以結構實作的。

各型別的詳細指南請見：

- [concept:swift/structs]()
- [concept:swift/classes]()

## 在結構與類別之間做選擇

結構和類別都能讓你定義自訂型別，但兩者在記憶體中的傳遞方式有根本上的差異：

- **結構是值型別**：當你指定或傳遞結構時，Swift 會為它的資料建立一份獨立的副本。
對其中一份副本所做的變更不會影響其他副本。
- **類別是參考型別**：當你指定或傳遞類別的實例時，Swift 會共用同一個現有實例的參考。
透過其中一個參考所做的變更，會立即影響所有指向同一個實例的其他參考。

Swift 重視安全性與可預測的行為，因此對大多數自訂型別來說，結構是預設的建議做法。
使用值型別可以確保：在程式某個部分變更資料時，不會在其他地方產生非預期的副作用。

一般來說：

- 當你要建立代表獨立值的資料（例如座標、形狀、幾何尺寸或格式化記錄）時，**使用結構**。
- 當你要建立具有各自獨立身分或共用生命週期需求的實體（例如 UI 控制項、資料庫連線或檔案控制代碼）時，**使用類別**。
