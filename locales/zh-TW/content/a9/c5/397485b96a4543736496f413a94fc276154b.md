# 簡介

主要的算術與比較運算子，可以改寫成供你自己的類別與結構使用。這就稱為_運算子多載_。

這篇[文章][operator-overloading]深入討論了語法，以及哪些運算子可以多載、哪些不行。

大多數運算子的形式如下：

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

[轉型運算子][ud-conversion-operators]的形式如下：

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

運算子的行為和靜態方法一樣。

- 運算子符號取代了方法識別字，而且它們同樣有參數和一個回傳型別。參數與回傳型別的型別規則合乎直覺，你也可以仰賴編譯器提供詳細的指引。
- 在二元運算中，第一個參數會接收運算左側的引數。
- 運算子的簽章由兩個參數（二元運算的情況）與一個回傳型別組成；若是一元運算子，則由單一參數與回傳型別組成。
- 對二元運算子而言，其中一個參數型別必須是宣告類別的型別。
- 在型別轉換的情況中，參數或回傳型別其中之一必須是宣告類別的型別。
- 遞增與遞減運算子的參數與回傳型別，都必須是宣告類別的型別。

語法範例：

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

實作一個[`Equals()`][equals]方法並從`==`運算子呼叫它，通常很有用。同樣地，若要進行比較，你可以實作[`IComparable`][icomparable]介面。這兩種情況下，你都能一石二鳥，而且還不只兩隻。

請注意，你不能用不屬於標準運算子集合的符號來建立運算子。只有在文件指明可以多載的運算上，你才能使用既有的符號。可以多載的運算子列在[這裡][overloadable-operators]。

請注意，當參數的型別不同時，參數的順序就很重要。在上面的範例程式碼中，`pt * 10m`是合法的運算式，但`10m * pt`無法編譯。
