# 關於

Haxe 中的疊代器用來搭配`for`迴圈疊代某個值。疊代器有兩種：

- `Iterator`：用來疊代某個值。
- `Iterable`資料：讓你能夠疊代某種資料型態。

這兩種概念分別以`Iterator<T>`和`Iterable<T>`表示：

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

任何能與其中一種型別統一的類別，都可以用`for`迴圈來疊代。如果一個類別定義了`hasNext`和`next`方法，它就會被視為疊代器；否則，如果它定義了`iterator`方法，就會被視為可疊代的型別：

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

在上面的範例中，`MyStringIterator`這個類別因為同時實作了`hasNext`和`next`方法，所以被視為疊代器，也因此與`Iterator<String>`相容。

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

在這裡，`MyArrayWrap`這個類別與`Iterable<Array<T>>`相容，因此被視為可疊代的資料型態。
