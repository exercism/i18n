# 指示

Mary 是電視劇 _Star Trek: The Next Generation_ 的超級粉絲。
她經常玩紙筆角色扮演遊戲，在遊戲裡她和朋友們會假扮成 _Starship Enterprise_ 的船員。

Mary 的角色是畢凱艦長，這意味著她必須負責記錄艦長日誌。
她很喜歡遊戲中充滿創意的部分，卻不喜歡臨時產生隨機資料。

請幫 Mary 撰寫隨機產生器，用來產生艦長日誌中常見的資料。

## 1. 產生隨機行星

_Starship Enterprise_ 在旅途中會遇到許多行星。
星艦宇宙中的行星會依其特性分成不同類別。
例如，地球是 M 級行星。所有可能的行星級別為：D、H、J、K、L、M、N、R、T 和 Y。

實作 `random_planet_class` 函式。
它應該隨機回傳指定數量的行星級別，並以向量形式呈現。
重複的級別是可以接受的，而且在向量較長時可能是必要的。

```R
random_planet_class(number_needed)
#> "K"
```

### 2. 產生隨機星艦註冊編號

Enterprise（註冊編號 NCC-1701）不是唯一在宇宙中飛行的星艦！
當它與另一艘星艦會合時，Mary 需要記錄那艘星艦的註冊編號。

註冊編號以「NCC-」開頭，接著是 1000 到 9999（含）之間的數字。

實作 `random_ship_registry_number` 函式，它會回傳隨機的星艦註冊編號。

```R
random_ship_registry_number()
#> "NCC-1947"
```

## 3. 隨機排列星艦艦隊

遊戲的其中一個版本會與其他星艦互動，而 Mary 需要挑選一些星艦。

雖然有完整的可能星艦清單，但每場遊戲只需要其中幾艘，而且應該隨機挑選。

實作 `shuffle_starships(starships)` 函式，它接收一個由不重複星艦註冊編號組成的向量，並回傳長度相同、星艦順序隨機排列的向量。
這樣一來，Mary 就能輕鬆從向量的開頭隨機取出任意數量的星艦。

結果中的值必須取自 `starships`，且不能有重複。

```R
shuffle_starships(c("NCC-5011", "NCC-1228", "NCC-7039", "NCC-3978", "NCC-1476"))
#> [1] "NCC-1476" "NCC-7039" "NCC-3978" "NCC-5011" "NCC-1228"
```

## 4. 產生隨機星曆

如果日誌裡沒有日期，那還有什麼用呢？

星曆是一個浮點數。
在 _The Next Generation_ 第一季中，_Starship Enterprise_ 的冒險發生在星曆 41000.0 到 42000.0 之間。
開頭的「4」代表 24 世紀，「1」代表第一季。

實作 `random_stardate` 函式，它會回傳一個介於 41000.0 和 42000.0 之間的浮點數。

```R
random_stardate()
#> 41037.6
```
