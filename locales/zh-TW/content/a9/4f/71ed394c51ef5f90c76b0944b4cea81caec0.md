# 簡介

`switch()` 函式可以簡潔地取代一長串的 `if` ... `else if` 判斷。
要進行 switch 的變數最常見的是字串，若是字串，選擇器裡的引號可以省略。

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

請注意，只有當值留白時，選項才會「向下穿透」，就像上面範例中的 `M` 一樣。
不需要像某些其他語言那樣加入 `break` 敘述。

對 `character` 型別進行 switch 時，最後一個值是預設值，就像這裡一樣。
若是整數型別，則不能提供預設值。

## `dplyr` 中的函式

base R 裡的 `switch` 相當受限：它只能對單一輸入做精確比對。
這在 1993 年 R 首次發布時看似合理，但以現代用途來說需要改進。

~~~~exercism/note
如同 [`Conditionals`][concept-conditionals] 概念中提到的，`tidyverse` 套件集合的設計目的是補足（有時取代）base R 的功能，同時不影響向後相容性。

只要在程式碼最上方加入 `library(dplyr)`（單一套件）或 `library(tidyverse)`（整個集合），就能把 `dplyr` 套件引入作用域。

`dplyr` 函式庫提供了兩個與 `switch` 相關的額外函式。

### `recode_values` 與 `replace_values` 函式

這兩個相關的函式能以向量化的方式，把舊值對應到新值，類似 switch。

兩者的主要差別在於，`recode_values()` 會建立一個全新的向量，而 `replace_values()` 則允許局部更新既有的向量。

比對仍然是精確比對，不過：

- 左側的選項可以是向量，只要其中任一元素符合，輸入就算符合。
- 左側的選項與右側的結果以波浪號 `~` 連結，而不是 `=`。
- 任何情況下都能指定預設值。

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when` 函式

`case_when` 把 `case_match` 的語法更推進一步，允許在 `~` 左側使用任何邏輯運算式。

輸入向量（下面範例中的 `x`）不以引數的形式提供，只需要事先定義好即可。

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()` 函式也是 `dplyr` 的一部分。
