# 提示

## 一般

- [結構與類別][structs-and-classes]的定義語法很相似。

## 1. 定義 Size 結構

- 如果屬性可能會被修改，就必須用 `var` 定義。
- height 和 width 屬性應分別設為預設值 80 和 60。
- 結構中的方法如果會修改結構的屬性，就必須標記為 `mutating`。

## 2. 定義 Position 結構

- 如果屬性可能會被修改，就必須用 `var` 定義。
- x 和 y 屬性應設為預設值 0。
- 結構中的方法如果會修改結構的屬性，就必須標記為 `mutating`。

## 3. 定義 Window 類別

- 結構可以使用[成員逐一初始化器][memberwise-initializers]，以不同的屬性值初始化。
- 常數屬性應該用 `let` 定義。
- `contents`屬性應該是 optional，因為它可能沒有值。
- 你必須為這個類別定義一個空的初始化器（`init() {}`）。

## 4. 新增一個調整視窗大小的方法

- 這個方法應該接受一個型別為 `Size` 的 `to` 參數。
- 可以使用點記法從 `to` 參數中取出 width 和 height。

## 5. 新增一個移動視窗的方法

- 這個方法應該接受一個型別為 `Position` 的 `to` 參數。
- 可以使用點記法從 `to` 參數中取出 x 和 y。

## 6. 新增一個設定視窗內容的方法

- 在 Swift 中，可以有兩個名稱相同但參數不同的方法。
- 定義一個帶有 `title` 參數的方法，用來設定 `title` 屬性。
- 定義一個帶有 `text` 參數的方法，用來設定 `contents` 屬性。
- 定義一個顯示方法，用來印出視窗的 title 和 contents。

## 7. 為 Window 類別建立初始化器

- 這個類別應該有兩個初始化器，一個不接受任何參數，另一個接受參數。
- 新的初始化器應該有 `title` 和 `contents` 參數，也應該允許 optional 參數 `size` 和 `position`
    如果沒有提供任何參數，就應該使用預設值。
- Optional 參數可以透過[預設參數值][default-parameters-vales]達成。
