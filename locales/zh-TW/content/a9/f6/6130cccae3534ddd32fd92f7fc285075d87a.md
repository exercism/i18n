# 關於

Elm 是一門令人愉快的語言，適合用來打造可靠的網頁應用程式。它的錯誤訊息親切友善，效能優異，資源檔案輕巧，而且不會發生執行階段例外。

Elm 最著名、也最廣為仿效的部分，大概就是 The Elm Architecture。它是一套用來組織網頁應用程式的簡單模式，所有 Elm 網頁應用程式都是照著它寫出來的。

核心概念是：你的程式碼圍繞著應用程式狀態的`Model`、用來`update`你的 model 的方式，以及用來`view`你的 model 的方式來建構。

`Model`包含應用程式的狀態，也就是應用程式需要的所有資料。想像一個簡單的應用程式，裡面有一個文字輸入框，還有一段顯示該段文字反轉結果的文字，model 就會長得像下面這樣。你也可以在 [Elm Guide][elm-guide-text-fields] 看到這個例子喔。

```elm
type alias Model =
  { text : String
  }
```

`update`是一個函式，當有變化發生時（例如使用者點擊按鈕），它會被呼叫並收到一個`Msg`。它接收`Msg`和目前的`Model`，然後回傳一個新的`Model`。

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view`是一個函式，會回傳 HTML，在瀏覽器中顯示給使用者看。它接收目前的`Model`，並回傳一個`Html Msg`（Elm 用來表示 HTML 的型別）。

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
