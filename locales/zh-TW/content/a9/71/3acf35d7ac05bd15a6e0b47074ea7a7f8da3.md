# 簡介

在 Factor 中，字串是一連串的字元。除了 [`splitting`][splitting]、[`ascii`][ascii] 等詞彙中專門處理字串的詞之外，[`sequences`][sequences] 詞彙中的大多數詞也能用於字串。

## 字串字面值

字串以雙引號撰寫。常見的跳脫序列都支援：`\n`、`\t`、`\r`、`\\`、`\"`：

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## 長度與索引

因為字串是序列，[`sequences`][sequences] 詞彙中的`length`與`nth`可以直接用於字串。

`length`會回傳字元的數量：

```factor
"hello" length .    ! => 5
```

`nth`接受一個從 0 開始的索引和序列，並回傳該位置的元素。對字串而言，元素是一個*字元*，也就是一個碼位（整數），而不是長度為一的子字串：

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## 從字元回到字串

要把單一碼位轉成單一字元的字串，可以使用 [`strings`][strings] 詞彙中的`1string ( char -- str )`。`CHAR:`是字面碼位的剖析時期形式：

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## 分割

[`splitting`][splitting] 詞彙能把字串切成片段。

`split1`會在分隔符號*第一次*出現的位置切開，並回傳前後兩半：

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split`會在分隔字元集合中*任一個*字元處切開，可能產生空片段：

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest`（位於 [`sequences`][sequences]）會捨棄空片段：

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## 取出某個片段

字串被分割成片段的陣列之後，`first`、`second`、`third`和`fourth`（位於 [`sequences`][sequences]）會回傳該位置的片段：

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

當你想一次把前面幾個片段放到堆疊上時，`first2`和`first3`可以一步拆出其中兩個或三個：

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

用於字串本身時，`first`回傳的是第一個**字元**，也就是碼位，而不是子字串：

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## 修剪

`[ blank? ] trim`（來自 [`sequences`][sequences]，其中`blank?`來自 [`ascii`][ascii] 詞彙）會移除前後的空白：

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## 大小寫轉換

`>lower`和`>upper`（來自 [`ascii`][ascii]）會回傳大小寫改變後的新字串：

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## 連接

[`sequences`][sequences] 詞彙中有兩個詞可以組裝字串：

`surround`會用前綴和後綴包住字串：

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue`會用分隔符號連接兩個字串：

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
