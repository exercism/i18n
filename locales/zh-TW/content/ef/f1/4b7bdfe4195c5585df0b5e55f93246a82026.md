# 關於

在 Common Lisp 裡，所有東西都是運算式。
一個運算式不是單一的東西（稱為原子），就是一個由多個東西組成的陣列（以括號界定：`()`）。

## 引用

所有 S-運算式和符號一樣，都可以被引用：

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

引用可以避免 S-運算式被求值，轉而把它當成資料看待。
這裡有一篇很棒的 [Stack Overflow 回答][so-quoting]，更詳細地討論了引用。

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
