# 除錯

目前的測試執行器使用 [PonyTest](https://stdlib.ponylang.io/pony_test--index/)，因此 Main actor 位於 test.pony 中，不應該將它當作你解法的一部分來編輯。

按照 Pony 應用程式的最佳做法，除非有必要，我們不會提供`Env`的存取權。這表示在幾乎所有情況下，你都無法使用`env.out.print()`來進行 printf 風格的除錯。

不過，Pony 有個 [debug](https://stdlib.ponylang.io/debug--index/) 模組，能讓以`-d`旗標編譯的程式，在不存取`Env`的情況下特別取得 STDOUT 與 STDERR 的存取權。

如果你需要 printf 風格的除錯，就使用這個功能吧。

除錯範例：

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
