# 說明附錄

## 軌道專屬說明

在過去，Elm 使用的是函式響應式程式設計，後來才轉為專門採用 Elm 架構。

請把這個練習當成是在用 Elm 架構寫網頁應用程式來解。
程式的輸出應該要是具有以下結構的 HTML

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

其中`<dl>`是描述清單元素，`<dt>`是描述術語元素，`<dd>`是描述細節元素，這些都是標準的 HTML 元素。

如果發生錯誤，輸出應該要有以下結構

```html
<div>
  <p>error message</p>
</div>
```
