# 布林

Crystal 有一種稱為[`Bool`][bools]的型別。
它代表`true`和`false`這兩個值。

## 邏輯運算子

Crystal 有三個邏輯運算子（`!`、`||`、`&&`），它們會組合布林值，組成會產生不同結果的運算式。

### 且（`&&`）

Crystal 的且運算子以`&&`表示，如果兩邊的值都是`true`就回傳`true`，否則回傳`false`。
使用且運算子時，把一個布林值放在`&&`右邊，另一個放在左邊。

```crystal
true && true
# => true

true && false
# => false
```

### 或（`||`）

Crystal 的或運算子以`||`表示，只要給定的值中**至少有一個**是`true`，就回傳`true`。
如果兩個值都是`false`，就回傳`false`。
使用或運算子時，把一個布林值放在`||`右邊，另一個放在左邊。

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### 非（`!`）

Crystal 的非運算子以`!`表示：如果給定的布林值是`false`就回傳`true`，如果是`true`就回傳`false`。
使用非運算子時，把一個布林值放在運算子（`!`）後面。

```crystal
!true
# => false

!false
# => true
```

## 使用括號（`()`）

處理布林值時，你可以用括號決定要先計算哪些布林值。
括號的用法不同，結果也會不一樣。
在 Crystal 中，會先計算括號裡的部分。

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

由於會先計算括號裡的部分，在下面這個例子中，非運算子會套用到括號內的運算式。

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
只有當括號會影響結果時才使用它們；否則應該省略。
~~~~

## 真值與假值

在 Crystal 中，假值有：`false`、`nil`和空指標；**其他所有值**都是真值。
這些值可以和上面提到的邏輯運算子一起使用。

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## 布林值方法的命名慣例

在 Crystal 中，慣例上會用問號（`?`）來命名回傳真值或假值的方法。
大多數情況下，這類方法會回傳布林值，但不一定。
這表示這類方法可以用在預期會得到真值或假值的地方，例如當作`if`敘述的條件：

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

名稱以問號結尾但不回傳布林值的方法，通常會改為回傳`nil`。`nil`_類似其他語言的`None`或`null`_。
