# 簡介

## 比較

在 C++ 中，你可以使用比較運算子來比較值。

| 比較 | 運算子 |
| ------------------| --------- |
| 等於 | `==` |
| 不等於 | `!=` |
| 小於 | `<` |
| 小於或等於 | `<=` |
| 大於 | `>` |
| 大於或等於 | `>=` |

這些比較的結果一律是布林值：

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

運算子`==`和`!=`會分別檢查一個值是否等於另一個值，以及是否不等於另一個值。
以下是一些常見的例子：

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

其他運算子則檢查某個值是否大於（`>`）、大於或等於（`>=`）、小於（`<`）、或小於或等於（`<=`）另一個值。
這類比較適用於數字和字串。
比較字串時，會依字典順序（又稱字典序）進行。

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## `if`敘述

C++ 的條件判斷和其他語言很像。
任何條件運算的底層型別都是`bool`型別，它的值可以是`true`或`false`。
條件判斷經常被當成流程控制機制，用來檢查各種條件。

你可以使用`if`敘述，當底層條件為`true`時，它便會執行其中的程式碼，就像這樣：

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

如果需要處理多於一種情況，可以用`else if`和`else`敘述把多個`if`敘述串接起來。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

從 C++17 開始，`if`敘述還可以包含一段簡短的初始化敘述，用來為這個`if`敘述初始化一個或多個變數。
例如：

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：在初始化中建立的任何變數，都無法在`if`敘述結束之後存取。
