# 簡介

C# 中的例外提供了一套結構化、一致且型別安全的方式，用來處理執行階段發生的錯誤狀況。想要避免應用程式當掉，妥善處理例外與錯誤就很重要。

在 C# 中，所有例外都以`System.Exception`類別作為基底型別。它包含一些重要的屬性，例如`Message`，其中提供了易於理解的說明，描述該例外被擲回的原因。

若要表示程式碼的某個部分應該發生錯誤，就必須建立新的例外物件，然後使用`throw`關鍵字將它擲回：

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

當例外被擲回時，執行階段的任務是找到負責處理該例外的程式碼。如果找不到適當的處理常式，執行階段除了會停止程式執行之外，還會顯示未處理例外的訊息。

若要為例外建立處理常式，C# 使用 try-catch 敘述，它由一個`try`區塊和一或多個`catch`子句組成。`try`區塊應該包含並保護可能導致例外被擲回的程式碼。`catch`子句則應該包含錯誤發生後處理程式行為的程式碼。請注意，例外在`try`區塊之後的順序很重要，因為當列出多個例外時，會執行第一個符合的`catch`子句。

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
