# 關於

`|>`運算子稱為管線運算子。它可以將一連串的函式呼叫串接起來，讓前一個函式呼叫回傳的值傳入下一個函式呼叫。

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

上面的程式碼等同於下面這段：

```gleam
string.append(string.uppercase("hello"), "?!")
```

管線運算子會把值當成函式呼叫的第一個引數傳入，或是當成新呼叫的唯一引數傳入，並自動選擇型別正確的那一種。

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

有時我們想讓值傳入其他位置，這時可以用`_`這個佔位符指出值應該插入的地方。

```gleam
100
|> some_function(1, _, 2)
```
