# 簡介

## 正規表示式

正規表示式（regex）是在 Elixir 中處理字串的強大工具。Elixir 的正規表示式遵循 **PCRE** 規範（**P**erl **C**ompatible **R**egular **E**xpressions）。代表正規表示式意義的字串模式會先經過編譯，再用來比對字串的全部或部分內容。

在 Elixir 中，建立正規表示式最常見的方式是使用`~r` sigil。Sigil 為 Elixir 中常見的工作提供了_語法糖_的捷徑。要對_字串字面值_進行比對，我們可以把字串本身接在 sigil 之後當作模式。

```elixir
~r/test/
```

`=~/2` 運算子可用來對字串執行正規表示式比對，並回傳 `boolean` 結果。

```elixir
"this is a test" =~ ~r/test/
# => true
```

使用 sigil 時有兩點要注意：

- 視你的需求，可以使用許多不同的分隔符號，而不只是 `/`
- 字串模式已經經過_跳脫_；當你不使用正規表示式、而是以字串形式撰寫模式時，就必須_跳脫_反斜線（`\`）

### 字元類別

使用方括號 `[]` 比對字元範圍會定義一個_字元類別_。它會將任一個字元比對到類別中的字元。你也可以指定像 `a-z` 這樣的字元範圍，只要頭尾代表一段連續的碼點即可。

```elixir
regex = ~r/[a-z][ADKZ][0-9][!?]/
"jZ5!" =~ regex
# => true
"jB5?" =~ regex
# => false
```

_簡寫字元類別_能讓模式更簡潔。例如：

- `\d` 是 `[0-9]` 的簡寫（任何數字）
- `\w` 是 `[A-Za-z0-9_]` 的簡寫（任何「詞」字元）
- `\s` 是 `[ \t\r\n\f]` 的簡寫（任何空白字元）

當_簡寫字元類別_用在 sigil 之外時，就必須跳脫：`"\\d"`

### 選擇

_選擇_使用 `|` 作為特殊字元，表示比對其中_一個_或_另一個_

```elixir
regex = ~r/cat|bat/
"bat" =~ regex
# => true
"cat" =~ regex
# => true
```

### 量詞

_量詞_允許正規表示式中出現重複的模式。它們會影響量詞前面的群組。

- `{N, M}`，其中 `N` 是最少重複次數，`M` 是最多重複次數
- `{N,}` 比對 `N` 次以上的重複
  - `{0,}` 也可以寫成 `*`：比對零次以上的重複
  - `{1,}` 也可以寫成 `+`：比對一次以上的重複
- `{,N}` 比對最多 `N` 次的重複

### 群組

圓括號 `()` 用來表示_群組_和_擷取_。在某些情況下，群組也可以被_擷取_並回傳以供使用。在 Elixir 中，這些可以是具名的或未具名的。在開括號之後加上 `?<name>` 即可為擷取命名。群組會像單一單位般運作，例如後面接著_量詞_時。

```elixir
regex = ~r/(h)at/
Regex.replace(regex, "hat", "\\1op")
# => "hop"

regex = ~r/(?<letter_b>b)/
Regex.scan(regex, "blueberry", capture: :all_names)
# => [["b"], ["b"]]
```

### 錨點

_錨點_用來將正規表示式綁定到要比對字串的開頭或結尾：

- `^` 錨定到字串的開頭
- `$` 錨定到字串的結尾

### 內插

由於 `~r` 是 `"pattern" |> Regex.escape() |> Regex.compile!()` 的捷徑，你也可以使用字串內插來動態建立正規表示式的模式：

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```
