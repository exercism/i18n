# 簡介

Swift 提供了內建的型別 [`Bool`][bools]，用來表示真值：`true`和`false`。

## 邏輯運算子

Swift 提供了三種[邏輯運算子][logical-operators]（`!`、`&&` 和 `||`），用來組合並評估布林運算式。

### 邏輯 AND（`&&`）

[_and_ 運算子][and]（`&&`）只有在兩個運算元都是`true`時才會回傳`true`。
只要任一個運算元是`false`，它就回傳`false`。
在`&&`符號的兩側各放一個運算式或布林值：

```swift
true && true  // true
true && false // false
```

### 邏輯 OR（`||`）

[_or_ 運算子][or]（`||`）只要**至少一個**運算元是`true`就回傳`true`。
只有當兩個運算元都是`false`時，它才會回傳`false`。
在`||`符號的兩側各放一個運算式或布林值：

```swift
true || true   // true
true || false  // true
false || false // false
```

### 邏輯 NOT（`!`）

[_not_ 運算子][not]（`!`）會反轉布林值。
如果值是`false`，它就回傳`true`；如果值是`true`，它就回傳`false`。
把`!`運算子緊接在值或運算式之前：

```swift
!true  // false
!false // true
```

## 使用括號（`()`）

你可以用[括號][explicit-parentheses]把運算式分組，並控制評估的順序。
在 Swift 中，括號內的運算式會先被評估：

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

用括號分組也會決定 NOT 運算子如何套用到複雜的運算式：

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
當你需要釐清評估順序，或想讓複雜的條件更容易閱讀時，就使用括號。
當預設的優先順序已經很清楚時，就避免加上多餘的括號。
~~~~
