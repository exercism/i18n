## 配對

`Pair`是一種資料結構，裡面正好有兩個元素，可透過`first`與`second`兩個欄位存取。

可以用`x => y`來建立：

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

`Pair`的元素可以是不同的型別：

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

`Pair`在 Julia 中有兩種常見用途：字典與取代。

### 取代

許多取代方法會接受一個`Pair`作為引數，以清楚表明哪個元素要被取代。
這樣就能寫出像這樣的語法：

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

其中集合裡的每個`4`都會被取代成`0`，而不是用下面這種較不清楚的語法：

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
