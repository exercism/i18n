## 互動式 jq 工具

提供一些輸入，試試各種 jq 過濾器，看看會得到什麼結果。

- [jq playground][jqplay]，一種「線上試用」的體驗。
- [ijq][ijq]，互動式 jq 工具，相當於命令列版的 jqplay。
- [jqp][jqp] 是另一個命令列工具，它使用 gojq 作為後端，而 gojq 與原始的 jq 並非 100% 相容。

## 其他 JSON 處理工具

- [gron][gron]：將 JSON「攤平」成一連串個別指定，如此一來就能用 grep 等逐行工具來處理。
- [jo][jo]：從 shell 變數建立 JSON 物件的小工具。
- [jello][jello]：jello 與 jq 類似，差別在於 jello 使用標準的 Python dict 與 list 語法。
