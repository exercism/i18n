# 測試

想測試你的解法，只要執行：

```bash
make test
```

這會執行測試檔案 `<exercise-name>-test.ys`，裡面包含你的解法必須全部通過的所有測試。
你應該仔細研究這個測試檔案，確切了解你的解法需要做到什麼。

> 注意：第一次執行`make test`時，它也會確認正確版本的`ys` YAMLScript 翻譯員已安裝在正確的位置。

如果你還沒修改任何檔案就執行`make test`，所有測試都會失敗。
這是正確且預期的行為。
練習開發的正常流程，就是反覆改進你的解法，每次修改後都執行`make test`，直到所有測試都通過。

如果你只想執行某個特定的測試（專心處理解法的那個部分），可以在該測試中加入這組鍵值：

```yaml
  ONLY: true
```

如果你想略過某些測試（同時處理解法的其他部分），可以在那些測試中加入這組鍵值：

```yaml
  SKIP: true
```


## 測試前置條件

YAMLScript 目前可以在 MacOS 和 Linux 上執行。

你的電腦需要安裝以下這些非常常見的指令：

* `bash`：你可以在任何 shell 下執行測試，但必須有 `bash` 可用。
* `make`：你必須使用 GNU `make` 來執行測試。
  在某些環境中，它的名稱可能不叫 `make`。
  有可能是 `gmake`。
* `prove`：這個程式包含在一般的 Perl 安裝之中。
* `curl`：在尚未安裝 ys 時用來安裝 ys。

你極有可能早就已經安裝好這些程式了喔。
