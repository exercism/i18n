# 補充說明

## 暫存器

| 暫存器  | 用途    | 型別 | 說明               |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 輸入        | 整數 | 要進行因數分解的自然數     |
| `$a1`    | 輸入／輸出 | 位址 | 存放質因數的目標陣列 |
| `$v0`    | 輸出       | 整數 | 因數的個數                   |
| `$t0-9`  | 暫時    | 任意     | 用於暫存          |
