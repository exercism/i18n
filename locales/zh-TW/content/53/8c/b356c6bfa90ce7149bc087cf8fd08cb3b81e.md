# 安裝

## 安裝 Clojure CLI

Clojure 提供了命令列工具，用來：執行互動式 REPL（讀取-求值-輸出循環）、執行 Clojure 程式，以及求值 Clojure 運算式。
我們鼓勵你在練習中使用 Clojure CLI。如要安裝 [Clojure CLI](https://clojure.org/guides/deps_and_cli)：

### Windows
關於 Windows 的安裝說明，請參閱：[Clojure CLI 安裝](https://clojure.org/guides/getting_started#_installation_on_windows)。

### Linux
關於大多数平台的安裝說明，請參閱：[Clojure CLI 安裝](https://clojure.org/guides/getting_started#_installation_on_linux)。

### Mac OS X 的 Homebrew
更新你的 Homebrew：

``` bash
$ brew update
```

安裝 Clojure CLI：
``` bash
$ brew install node clojure/tools/clojure
```

使用 node 環境時需要`Node`。

## 測試安裝

若要測試安裝是否正確，請執行`clojure --help`；如果一切順利，它會顯示版本。

```bash
$ clojure --help
Version: 1.10.1.547
...
```
