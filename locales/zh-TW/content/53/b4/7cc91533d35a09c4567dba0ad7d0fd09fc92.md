# 範圍

[範圍][range] 代表兩個值之間的區間。
最常使用範圍的型別是 `Integer` 和 `String`。
它們可以應用在許多地方，例如快速建立集合、切割字串、檢查某個值是否在範圍內，以及疊代。
使用範圍運算子`..`或`...`即可建立（分別代表包含與不包含結尾值）。

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

之所以有兩個範圍運算子，是為了讓你建立包含或不包含結尾值的範圍，這在處理從 0 開始的索引時特別實用。

你也可以透過 `Range` 初始化器來建立範圍。

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Ruby 中使用範圍運算子`..`或`...`建立範圍，並想對該範圍呼叫方法時，你需要把範圍用括號包起來。
這是因為如果不這麼做，方法會被當成範圍運算子的第二個引數來呼叫。

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## 取得子字串

當你想切割字串時，可以使用範圍運算子來取得子字串，也就是建立一個以子字串起始與結束索引構成的範圍。

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

你也可以使用負數索引，從字串尾端取得子字串。

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 範圍方法

範圍本身有一組方法可以使用。
例如，這些方法可以用來計算範圍中所有值的總和，或檢查範圍是否包含某個值。

| 方法                    | 說明                                                                    | 範例                            |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | 回傳範圍中所有值的總和                                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | 回傳範圍的大小                                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | 如果範圍包含給定的值就回傳 `true`，否則回傳 `false`                     | `(1..5).include?(3) # => true` |

## 無盡範圍與無起始範圍

範圍可以是無盡的，也可以是無起始的。
無盡或無起始的範圍，其起始值或結尾值為 `nil`，但定義範圍時可以省略 `nil`。

當你想從字串開頭或結尾切割字串時，使用無起始與無盡範圍就很方便。

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
如果沒有用在集合上，無盡範圍可能會導致無盡的序列，請謹慎使用。
~~~~

## 字串範圍

字串也可以用於範圍，讓你能取得兩個字串之間的字串區間。
使用某些字串時，行為可能會有點出乎意料，所以請謹慎使用。

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
