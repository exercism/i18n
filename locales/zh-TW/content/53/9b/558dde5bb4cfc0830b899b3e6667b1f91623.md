# 提示

## 1. 產生 SELECT 查詢

- 記得你不需要用建構子或字面值來初始化 builder。只要一個簡單的 `var sb strings.Builder` 就能馬上使用。
- 務必處理 `columns` 切片為空或為 `nil` 的情況，這時要附加萬用字元 `*` 符號。
- 請注意，這裡不需要也不預期你處理任何中繼字元或 SQL 清理。你可以直接用 `sb.WriteString(col)` 安全地附加欄位名稱。

## 2. 產生批次 INSERT 敘述

- 在 `for` 迴圈裡每次都配置全新的 `strings.Builder`，會讓效能優勢蕩然無存。請改在迴圈開始*之前*宣告單一個 builder。
- 每次迴圈疊代開始時，對你的 builder 實例呼叫 `Reset()` 方法。這會清空緩衝區，讓你可以在底層保留已配置的記憶體容量的同時，開始一段全新的查詢。
- 別忘了 SQL `VALUES` 子句中的字串值必須明確用單引號 `'` 包起來。你可以用 `WriteByte('\'')` 乾淨地加上去。
- 就像 SELECT 查詢一樣，不用擔心要跳脫特殊字元或在欄位值裡防止 SQL 注入。把輸入字串當成可以直接安全使用就好。
