# 說明

在這個練習中，你將撰寫程式碼來分析汽車工廠組裝線的生產情形。
組裝線的速度範圍可以從 `0`（關閉）到 `10`（最高）。

在最低速度（`1`）時，每小時可以生產 `221` 輛車。
產量會隨速度呈線性成長。
因此當速度設為 `4` 時，每小時應該生產 `4 * 221 = 884` 輛車。
不過，速度越快，生產出瑕疵車的可能性也越高，這些瑕疵車之後必須被丟棄。

你有三個任務。
每個需要實作的函式都接受一個整數參數，也就是組裝線的速度。

## 1. 計算成功率

實作 `success_rate()` 方法，計算在指定速度下，產品能夠正確無誤地製造出來的機率。
下表說明速度如何影響成功率：

- `0`：成功率 0%。
- `1` 到 `4`：成功率 100%。
- `5` 到 `8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

```julia-repl
julia> success_rate(10)
0.77
```

## 2. 計算每小時產量

實作 `production_rate_per_hour()` 方法，計算組裝線每小時的產量，並將成功率納入考量。

```julia-repl
julia> production_rate_per_hour(6)
1193.4
```

請注意，回傳的值是浮點數。

## 3. 計算每分鐘生產的可用產品數量

實作 `working_items_per_minute()` 方法，計算每分鐘能生產多少輛可用的車：

```julia-repl
julia> working_items_per_minute(6)
19
```

請注意，回傳的值是整數：未完成的產品不會計入。
