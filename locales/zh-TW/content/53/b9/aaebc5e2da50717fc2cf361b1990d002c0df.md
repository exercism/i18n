# 安裝

## 安裝 .NET 10

Visual Basic 軌道使用 .NET 10。
若要在本機建置並測試這些練習，請安裝[適用於你的作業系統的 .NET 10 SDK][install-sdk]：
請安裝 SDK，而不只是執行階段。

## 檢查你的安裝

開啟新的終端機並執行：

```bash
dotnet --version
```

這個指令應該會輸出 `10.0.0` 或更新的版本。

## 編輯器支援

完成這些練習只需要 .NET SDK 和一個基本的文字編輯器。
如果你想要程式碼自動完成、除錯等更進階的功能，可以考慮以下編輯器：

- Windows 上的 [Visual Studio 2026][visual-studio]
- Windows、Linux 或 macOS 上的 [Visual Studio Code][visual-studio-code]
- Windows、Linux 或 macOS 上的 [JetBrains Rider][rider]

[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
