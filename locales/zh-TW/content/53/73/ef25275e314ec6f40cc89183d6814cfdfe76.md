# 關於

在走訪一個序列時，有時光有元素還不夠，還需要位置。Factor 的*索引*疊代詞會把元素和索引兩者都交給處理每個元素的 quotation，並讓索引位在堆疊頂端。`times`則是相關的詞，用於沒有底層序列的計次疊代。

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| 詞           | 堆疊效果                                                            |
|--------------|--------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                  |
| `times`      | `( n quot: ( -- ) -- )`，但請見下文                                 |

`times`有個微妙之處：它的 quotation 雖然記載為`( -- )`，但這個詞是`inline`，所以像`( str -- str )`這種效果平衡的 quotation 也能正常運作，並在每次疊代之間把堆疊串起來。這樣就能在沒有任何可變狀態的情況下，得到一個計次累加器：

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

同樣的技巧也適用於`each-index`和`map-index`：宣告的每元素效果是*下限*，而不是上限。
