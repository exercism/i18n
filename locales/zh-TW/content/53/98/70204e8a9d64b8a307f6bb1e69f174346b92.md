# 關於

當你有一組固定的常數值時，就可以使用[列舉型別][enumeration types]。使用列舉能讓你以型別安全的方式操作常數值。定義列舉要透過 `enum` 關鍵字。列舉成員的參照方式，是在前面加上列舉名稱和一個點（例如 `Status.Active`）。

每個列舉成員都是名稱和一個 `int` 值的組合。如果第一個成員沒有明確指定值，它的值會被設為 `0`。如果某個列舉成員沒有明確指定值，它的值會自動設為前一個成員的值加 `1`。

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

列舉的宣告性很強。比較以下兩個方法呼叫：

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

對閱讀程式碼的人來說，第二個版本（使用列舉）比較容易理解。

## 數值型別的列舉

值的預設數值型別是 `int`，但只要明確指定其他任何[整數型別][integral numeric]，就可以改變它。

以下列舉使用 `byte` 數值型別來存放它的值：

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## 轉換為列舉成員

每當你想為某個類似布林值的東西建立模型時，都應該考慮使用列舉。除了前面提到的可讀性優點之外，列舉相較於布林值還有另一個好處：列舉永遠可以新增值，而布林值只會是 `true` 或 `false`。因此，使用列舉更能因應未來的變化。

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

請注意，雖然_可以_把整數值轉型成列舉，但如果整數值沒有對應到任何列舉值，這麼做可能會導致非預期的結果：

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## 剖析列舉

有時候，用名稱把字串轉換成列舉成員是很有用的，這時可以使用 [`Enum.Parse`][enum parse]：

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

如果要檢查某個名稱或值是否存在於列舉中，可以使用 [`Enum.TryParse`][enum tryparse] 或 [`Enum.IsDefined`][enum isdefined]，兩者都會回傳布林值，指出該列舉成員是否存在：

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
