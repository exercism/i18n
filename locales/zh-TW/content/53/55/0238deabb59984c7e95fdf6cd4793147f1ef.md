# 取模

在 Crystal 中，取模比較完全沒有問題，但要比較除法的餘數時，改用 [`divisible_by?`][divisible_by] 方法會更好讀。
如果你只是想判斷一個數字是奇數還是偶數，那更好的做法就是用 [`odd?`][odd?] 和 [`even?`][even?] 方法。

例如：

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
