# 簡介

你目前看過的多數序列字詞都會回傳*新的*序列，原本的輸入則保持不變，例如`suffix`、`reverse`、`map`等等。不過陣列和向量也支援**原地修改**，當你想記錄會隨時間改變的狀態時，這兩者都會派上用場。

## 可變序列的兩種形式

- **陣列**（`{ … }`）的長度固定。[`arrays`][arrays] 中的`<array> ( n elt -- array )`會建立一個長度為`n`的全新陣列，裡面填滿`elt`的副本。
- **向量**（`V{ … }`）可以增長與縮短。用`V{ } clone`取得一個全新的空向量；[`vectors`][vectors] 中的`<vector> ( n -- vector )`會預先配置`n`個元素的容量。

```factor
USING: arrays kernel prettyprint vectors ;

5 0 <array> .   ! => { 0 0 0 0 0 }
V{ } clone .    ! => V{ }
```

## 改變某個位置

這兩個字詞在兩種序列上都能運作，兩者都預期索引後面接著序列：

```
set-nth    ( elt n seq -- )
change-nth ( n seq quot -- )
```

`set-nth`負責指定；`change-nth`會把一個 quotation 套用到位置`n`的元素上。這兩個 [`sequences`][sequences] 字詞都不會在堆疊上回傳任何東西，修改本身就是效果。

```factor
USING: arrays kernel math prettyprint sequences ;

5 0 <array>                 ! { 0 0 0 0 0 }
7 2 pick set-nth            ! mutates: position 2 becomes 7
0 over [ 1 + ] change-nth   ! mutates: position 0 += 1
.                           ! => { 1 0 7 0 0 }
```

## 增長與縮短

這三個字詞只對向量有意義，因為陣列的長度無法改變：

```
push  ( elt seq -- )    ! append to the end
pop   ( seq -- elt )    ! remove and return the last
pop*  ( seq -- )        ! remove the last, discard
```

```factor
USING: kernel sequences vectors ;

V{ } clone              ! a fresh empty vector
"alice" over push       ! V{ "alice" }
"bob"   over push       ! V{ "alice" "bob" }
dup pop .               ! prints "bob"
.                       ! prints V{ "alice" }
```

## 向量 → 陣列

當你建立好一個向量，想交回一個固定長度的陣列時，[`arrays`][arrays] 中的`>array ( seq -- array )`會回傳一個含有相同元素的新陣列：

```factor
USING: arrays kernel prettyprint sequences vectors ;

V{ "alice" "bob" "carol" } >array .
! => { "alice" "bob" "carol" }
```

## `clone`：保留一份快照

修改會直接就地變更序列。如果呼叫端交給你一個序列，而你正打算改動它，[`kernel`][kernel] 中的`clone`會給你一份全新的獨立副本，這樣呼叫端看到的內容就不會跟著變動：

```factor
USING: kernel prettyprint ;

V{ "a" "b" "c" } clone .    ! => V{ "a" "b" "c" }   (a fresh copy)
```

同樣的預防措施也適用於`V{ }`和其他空字面值。在某些語言裡，`[]`或`vec![]`會在每次運算式求值時配置一個全新的容器。在 Factor 中，寫在原始碼裡的`V{ }`字面值是*同一個*物件，由每個提到它的呼叫位置共用。如果你直接對`V{ }`執行`push`，下一次呼叫就會看到上次留下的內容。`V{ } clone`會建立你幾乎總是想要的那份全新副本。
