# 介紹

Factor 的字元是整數，也就是 Unicode 碼位，所以直接用`<`、`>`、`=`這些數值運算子，就能得到區分大小寫的排序。[`unicode`][unicode] 詞彙則新增了能辨識 Unicode 的述詞，以及單一字元的大小寫轉換。

## 字元述詞

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## 大小寫轉換

`ch>upper` 和 `ch>lower` 會轉換單一字元的大小寫。字串層級的`>upper`和`>lower`則會把它們套用到字串中的每個字元。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` 會先把整串字串轉成小寫，再把第一個字元轉成大寫，也就是單一詞的標題大小寫：

```factor
"hELLO" capitalize .   ! => "Hello"
```

## 字元常值

`CHAR: A` 會解析成`A`的整數碼位。如果要使用具名字元，可以用`space`、`tab`、`\n`等名稱：

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## 符號

當一個詞需要回傳標籤而不是值時，例如用`yes`/`no`/`maybe`代替布林值，就把每個標籤宣告成*符號*。符號是一種在被呼叫時會把自己推入堆疊的詞，而兩個符號只有在名稱相同時才會被視為相等。

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` 宣告一個符號；`SYMBOLS: a b c ;` 則可以一次宣告多個。
