# 簡介

JavaScript 是一種動態語言，支援物件導向、指令式與宣告式（例如函式程式設計）等風格。

## （重新）賦值

在 JavaScript 中，把值指定給名稱有幾種主要方式：使用變數或常數。在 Exercism 上，變數一律以 [camelCase][wiki-camel-case] 撰寫，常數則以 [SCREAMING_SNAKE_CASE][wiki-snake-case] 撰寫。這沒有官方指南可循，各家公司和組織也各有不同的風格指南。_變數要怎麼寫都可以_。依照練習準備的方式來寫的好處是，它們在網頁介面與大多數 IDE 中會有不同的醒目提示。

JavaScript 中的變數可以使用 [`const`][mdn-const]、[`let`][mdn-let] 或 [`var`][mdn-var] 關鍵字來定義。

使用 `let` 或 `var` 時，變數在其生命週期內可以參照不同的值。例如，`myFirstVariable` 可以用賦值運算子 `=` 定義並重新定義許多次：

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

和 `let` 與 `var` 不同，使用 `const` 定義的變數只能被指定一次。在 JavaScript 中，這用來定義常數。

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 在之後的學習練習中，會探討並說明_常數_的賦值／綁定與_常數_值之間的差異。

## 函式宣告

在 JavaScript 中，功能單位會封裝在_函式_裡，通常會把屬於同一組的函式放在同一個檔案中。這些函式可以接受參數（引數），並且可以使用 `return` 關鍵字_回傳_值。函式使用 `()` 語法來呼叫。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 在 JavaScript 中，宣告函式的方法_很多_。這些方法看起來和 `function` 關鍵字不同。這個 track 會逐步介紹它們，但如果你已經認識它們，想用哪一種都可以。大多數情況下，用哪一種並沒有優劣之分。

## 開放給其他檔案

想讓_其他檔案_也能使用某個 `function`、常數或變數，就必須用 `export` 關鍵字把它們[匯出][mdn-export]。另一個檔案接著可以用 `import` 關鍵字[匯入][mdn-import]它們。這就是所謂的模組系統。所有測試的運作方式正是絕佳的例子。每個練習至少有一個檔案，例如 `lasagna.js`，裡面包含_實作_。此外，至少還有另一個檔案，例如 `lasagna.spec.js`，裡面包含_測試_。這個檔案會_匯入_公開（也就是已匯出）的實體，用來測試實作：

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
