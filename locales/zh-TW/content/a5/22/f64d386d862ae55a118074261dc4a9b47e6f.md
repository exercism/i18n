# 測試

## 安裝 Exercism GDScript 軌道的測試執行器

你需要先正確[安裝 Godot][installation]，才能使用測試執行器。

若要為 Exercism 建置並測試 GDScript 指令碼，Godot 會透過 CLI 以「headless」模式執行。
這些說明目前需要 Linux 和 bash。

### 步驟 1：安裝整體測試執行器基礎架構

為了設定測試環境，請複製 [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] 並將其內容移到 `/opt/test-runner/`：

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 步驟 2：下載單一練習的測試執行器指令碼

假設你已經設定好`exercism`工具，並且至少下載了一個 GDScript 練習，它應該會建立一個`exercism/gdscript`資料夾來存放這些練習。
請將[測試執行器][test-local-gdscript-solution]存到這個資料夾，並把該檔案標記為可執行，或者直接建立一個連結指向它：

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## 執行測試

完成安裝步驟後，你應該可以從任何練習目錄（例如`~/exercism/gdscript/two-fer`）開始，執行上一層目錄（也就是`../`）中的指令碼，來測試你在該練習的本機解答：

```sh
../test-local-gdscript-solution.sh
```
