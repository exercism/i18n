# 測試

依照[測試驅動開發的三項規則][3-tdd-rules]，讓第一個測試能編譯、連結並通過。

內附的 makefile 可以用`test`任務來建立並執行測試。

```console
$ make test
```

只需建立足以解決所有編譯器錯誤的函式，並讓測試失敗。
接著只寫剛好足夠的程式碼讓測試通過。
完成之後，再繼續進行下一個測試。

隨著測試一步步推進，花點時間重構你的實作，讓它更好讀、更能表達意圖，然後再繼續下一個測試。

盡量使用標準 C99 提供的功能，而不是自己動手寫低階的演算法或工具。

## 檢查記憶體洩漏

makefile 也附帶了一個建置目標，用來檢查一些關於記憶體洩漏和陣列越界存取的常見錯誤。
要執行這些檢查，請在命令列輸入：

```console
$ make memcheck
```
