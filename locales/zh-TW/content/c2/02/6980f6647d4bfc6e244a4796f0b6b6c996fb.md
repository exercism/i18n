# 安裝

我們會使用 *PolyML* 作為 Standard ML 的實作。

如果你使用 Windows，可以從 [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases) 下載安裝程式。
Linux/OS X/Free BSD 的一般說明可以在 [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme) 找到。

如果你想從原始碼安裝，過程很簡單：

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

如果你想把它安裝在自訂的位置，例如 `$HOME/.local`：

```sh
$ ./configure --prefix=$HOME/.local
```

最後一步：

```sh
$ make compiler
$ make install
```

檢查是否安裝正確：

```sh
$ poly
```

如果你看到翻譯員，就代表準備好了！
如果沒有，你可能得把`$HOME/.local/bin`（或`<you prefix>/bin`）加入你的`$PATH`。
