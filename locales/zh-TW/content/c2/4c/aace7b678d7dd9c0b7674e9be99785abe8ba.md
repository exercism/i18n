# 簡介

Elixir 是動態型別的語言，這表示它不提供編譯期的型別檢查。不過，型別規格仍然可以當成一種文件形式來使用。

只要在函式定義前面加上`@spec`模組屬性，就能為函式加上型別規格。`@spec`後面接著函式名稱，以及用逗號分隔、放在小括號裡的所有引數型別清單。回傳值的型別則用雙冒號`::`與函式的引數隔開。

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## 型別

最常用的型別包括：

- 布林值：`boolean()`
- 字串：`String.t()`
- 數字：`integer()`、`non_neg_integer()`、`pos_integer()`、`float()`
- 陣列：`list()`
- 任意型別的值：`any()`

有些型別還可以加上參數，例如`list(integer)`就是整數的陣列。

字面值也可以當作型別使用。

聯集型別可以用豎線`|`來表示。例如`integer() | :error`代表整數或原子字面值`:error`。

完整的型別清單可以在[官方文件中的「Typespecs」一節][types]找到。

## 為引數命名

型別規格裡的引數也可以命名，這在區分多個同型別的引數時很有用。引數名稱後面接雙冒號，放在該引數的型別前面。

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## 自訂型別

型別規格不限於內建型別。自訂型別可以用`@type`模組屬性來定義。自訂型別的定義從型別名稱開始，接著是雙冒號，然後才是型別本身。

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

自訂型別可以在定義它的同一個模組裡使用，也可以在其他模組裡使用。
