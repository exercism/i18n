# 簡介

## 數字

Ruby 中最常見的兩種數字型別是：

- **整數：**小數點後沒有位數的數字（整數）。例如`-6`、`0`、`1`、`25`、`976`和`500000`。
- **浮點數：**小數點後有一位或多位數字的數字。例如`-2.4`、`0.1`、`3.14`、`16.984025`和`1024.0`。

它們是透過`Integer`和`Float`類別實作的。

這些類別帶有方法，可以將值從一種型別轉換成另一種。`Integer`數字精確到整個單位，而`Float`的精確度則是相對於整數的小數：
- `Integer#to_f`：轉換成新的浮點數
- `Float#ceil`：向上取整至最接近的整數
- `Float#floor`：向下取整至最接近的整數
- `Float#round`：四捨五入至最接近的整數
- `Float#to_i`：截斷至最接近的整數

## 條件判斷

Ruby 有所謂的流程控制運算式，用來控制程式的執行方式，它們會接收真值或假值。
有些運算子可以用來產生真值或假值，這些運算子稱為[比較運算子][comparison-operators]。

有兩種主要的控制運算式，用來控制哪些程式碼會執行、哪些不會。
也就是控制會執行哪個分支。

這兩種是：`if`和`unless`運算式。

## 比較運算子

[比較運算子][comparison-operators]用來比較值，並回傳`true`或`false`值。
下列運算子需要兩個型別相同的值才能比較。
如果這兩個值的型別不同，編譯器就會拋出錯誤。
以下是這些運算子的清單，以及它們得到`true`值的例子：

| 方法 | 說明           | 範例 |
| ------ | --------------------- | ------- |
| <      | 小於             | 4 < 5   |
| <=     | 小於或等於    | 4 <= 4  |
| >      | 大於          | 3 > 1   |
| >=     | 大於或等於 | 2 >= 2  |

有別於前面提到的運算子，等於與不等於運算子可以用來比較任何型別的值。
`==`運算子用來檢查兩個值是否相等，其中也包含檢查值的型別。
`!=`的運作方式相同，但如果兩個值不相等就會回傳`true`，相等則回傳`false`。
以下是等於與不等於運算子的清單，以及它們得到`true`值的例子：

| 方法 | 說明  | 範例 |
| ------ | ------------ | ------- |
| ==     | 等於        | 4 == 4  |
| !=     | 不等於    | 5 != 4  |

## `if`敘述

[`if`][if]敘述用來檢查給定的條件是「真值」還是「假值」。
如果條件是真值，`if`敘述內的程式碼就會執行。
`if`敘述以`end`關鍵字作結。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless`敘述

`unless`敘述的運作方式與`if`敘述非常類似，但如果條件是假值，它就會執行`unless`敘述內的程式碼。

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else`敘述

`else`敘述可以與`if`敘述搭配使用。
如果`if`分支沒有執行，就會執行`else`敘述。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## 「串接式 `if`」敘述

`elsif`敘述可以與 if 敘述搭配使用。
如果 if 分支沒有執行，且 elsif 敘述的條件為真值，就會執行`elsif`敘述。
elsif 敘述可以串接在一起，第一個為真值的條件會被執行。
在 if 敘述的最後也可以加上 else 敘述，如果先前沒有任何敘述的條件為真值，它就會執行。

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
