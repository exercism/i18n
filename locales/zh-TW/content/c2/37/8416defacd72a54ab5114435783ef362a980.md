# 安裝

## 安裝 tclsh

你唯一需要的工具就是 TCL 翻譯員，也就是 `tclsh`。

在 Windows 上，取得 Tcl 最好的來源是 [Magicsplat 的 Tcl 安裝程式][magicsplat]。

在 MacOS 和類 Unix 作業系統上，`tclsh`通常已經安裝好了。
通常安裝的版本會是 8.6.*某個數字*。
如果要安裝目前的穩定版本 9.1：
 - 在 MacOS 上，使用 [Homebrew][brew]。
 - 在 Linux 上，查看你的套件管理工具。
 - 或是[下載原始碼][download]並[自行建置][build]。

若你使用 Exercism 網頁介面來解練習，測試執行器（截至 2023 年 2 月）使用的是 Tcl 8.7a4 版。

## 使用互動式的 tclsh 殼層

寫程式的時候，很常會開啟互動式的 [`tclsh`][tclsh] 工作階段來測試各種指令。
不過 tclsh 只提供非常基本的 REPL 翻譯員，沒有命令列編輯，也沒有指令歷史紀錄。
想要更好的體驗，有個叫做 `rlwrap` 的程式可以加上 readline 的功能：

```bash
rlwrap tclsh
```

要安裝 rlwrap：
 - 在 MacOS 上，使用 [Homebrew][brew]。
 - 在 Linux 上，查看你的套件管理工具。
 - 或是[下載原始碼][rlwrap-download]並[自行建置][rlwrap-build]。

它實在太方便了，你會想一直用它：把下面這行加進你的 ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## 該用哪個版本？

目前的穩定版本是 9.1。
正如上面提到的，8.6 版仍然被廣泛使用。

你可以執行下面這道指令，看看自己安裝的是哪個版本的`tclsh`：

```bash
echo 'puts [info patchlevel]' | tclsh
```
