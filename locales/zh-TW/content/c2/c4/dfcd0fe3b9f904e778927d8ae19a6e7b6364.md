# 簡介

Kotlin 中的[`string`][ref-string]是不可變的 Unicode 字元序列。

[`Immutable`][wiki-immutable]的意思是，對字串所做的任何操作都必須回傳新的字串：原始字串永遠不會改變。

[`Unicode`][wiki-unicode]的意思是，世界上大多數書寫系統都能表示，但（與 C 等較舊的語言不同）字元和位元組之間並沒有 1:1 的對應關係。

字串通常用雙引號`" "`包住。

有些字元需要逸出：`\'`、`\\`，以及一些常見的非列印字元，例如`\t`（定位字元）和`\n`（換行字元）。

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

多行字串用 3 個雙引號包住，可以包含任意文字（不需要逸出）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

使用 [trimIndent][trimIndent-doc] 移除各行共同的縮排。這在格式化字串時很方便：

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

或者，[trimMargin][trimMargin-doc] 可以讓你指定分隔符號。接著`String`中的每一行都會從分隔符號之後開始。分隔符號預設為`|`，但你可以用參數指定不同的分隔符號。例如：

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

字串可以用`+`串接，但最好只用在簡短單純的情況。還有其他而且通常更好的做法。

## 字串範本

這是指某些其他語言所稱的「內插」。

如果字串中包含錢號`$`，後面接著一個識別碼，或是包含一對大括號（`{expression}`）夾住一個運算式，這些都會分別被替換成該值或該運算式的結果。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

當剖析時可能會產生歧義，就需要用大括號`{ }`把運算式括起來。

一般來說，使用字串範本比用`+`來組合字串更有效率，也更道地。

## 字串函式

Kotlin 提供了_許多_[`functions`][ref-string-functions]可以操作字串。

大部分來說，這些是[`extensions functions`][ref-extensions]而不是`String`類別的成員，不過這對我們使用它們的方式影響不大。

~~~~exercism/note
Kotlin 相當複雜的[文件][ref-string-functions]頁面會把擴充函式藏在預設檢視中。
記得點選`Members & Extensions`來展開這個區段。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

下列範例只展示了可用功能中的一小部分：

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
