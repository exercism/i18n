# C 風格指南

本指南說明 C track 練習的範例檔與測試檔所應遵循的風格。

本指南中的規則，是對 [.clang-format][] 檔案所設定規則的補充，或是特別加以強調。

## C 標準

程式碼應符合 C99 標準，更正式的名稱是 ISO/IEC 9899:1999。
不應使用 POSIX，或其他非標準的程式庫函式、型別，或實作外部的其他參照。

## 命名

一般來說，型別、變數、結構體和檔案的名稱應使用蛇形命名，所有字母皆為小寫，並以底線 `_` 分隔名稱的各個部分。

```c
void some_foo_function(char * input_string, int input_string_length);
```

### 列舉

列舉的名稱通常應使用單數，而非複數。

列舉的標籤應使用蛇形命名，所有字母皆為大寫。

```c
enum heading {
    HEADING_NORTH,
    HEADING_EAST,
    HEADING_SOUTH,
    HEADING_WEST
}
```

### 巨集

定義常數的巨集使用蛇形命名，所有字母皆為大寫。

```c
#define CONSTANT 0x4000
```

巨集名稱採用大寫蛇形命名是比較好的做法，但類似函式的巨集可以用小寫蛇形命名。

### 型別

標準的固定寬度型別（位於 `stdint.h`）優於基本的整數型別。

型別 `bool`（來自 `stdbool.h`）優於 `_Bool`。

同樣地，表示與記憶體相關的數量時，偏好使用 `size_t` 和 `ptrdiff_t`（位於 `stddef.h`）。

程式使用 `typedef` 定義的型別，名稱應加上 `_t` 後綴。
雖然我們知道 POSIX 保留了 `_t` 後綴，但目前這個 track 並未使用 POSIX。

## 引入防護

所有標頭檔都應該使用引入防護。

一般來說，一組引入防護應該包住標頭檔的完整內容。

範例實作（`.meta/example.h`）和練習的程式骨架（`exercise_name.h`）中的防護，應使用遵循練習名稱的巨集名稱。
防護巨集的名稱，大小寫應遵循上述針對巨集的規則。

例如，對於練習 `hello-world`，請使用：

```c
#ifndef HELLO_WORLD_H
#define HELLO_WORLD_H

//...

#endif
```

## 參數

所有函式的宣告和定義都應該為函式參數命名。
這同時適用於 `.c` 和 `.h` 檔。
所有地方使用的名稱都應該一致。
也就是說，下面這個函式原型雖然是合法的 C，但因為參數沒有名稱，所以不符合本風格：`void foo(int);`。
只要其他所有宣告和定義也都使用參數名稱 `bar`，正確的原型就會是 `void foo(int bar);`。

在比較簡單或比較合適的情況下，偏好使用需要以傳值而非傳指標方式傳遞引數的參數。
請特別注意，這也包括 `struct` 型別的參數。

如果在學生的實作中，預期不會改變指標型別參數的值，該參數就應該加上 `const` 限定。

## 測試檔配置

每個練習的測試檔都遵循特定的配置。
這樣的配置一方面是為了協助貢獻者辨識檔案中的各個部分，另一方面也是為了幫助學習者了解測試的運作方式。

和大多數 C 原始碼檔一樣，測試檔會以 include 開頭。

```c
#include "vendor/unity.h"
#include "../src/file_under_test.h"
// any other includes here
```

接著是 `setUp()` 和 `tearDown()` 函式。
到目前為止，沒有任何練習用到它們（函式主體是空的），但必須保留它們，測試檔才能在所有平台上正確編譯。

```c
void setUp(void)
{
}

void tearDown(void)
{
}
```

接下來是測試函式會用到的任何輔助函式。
這類輔助函式的名稱不應使用 `test_` 前綴。

接下來是測試函式本身。
這些函式的名稱會使用 `test_` 前綴。
除了第一個之外，每個測試函式都應該以 `TEST_IGNORE();` 作為第一個敘述。
第一次出現這個時，後面應該跟著行註解 `// delete this line to run test`。

例如：

```c
static void test_the_first(void)
{
   test_first_foo();
}

static void test_the_second(void)
{
   TEST_IGNORE();               // delete this line to run test
   test_second_foo();
}

static void test_the_third(void)
{
   TEST_IGNORE();
   char grade = 'A';
   test_third_foo(grade);
}
```

檔案的最後是 `main()` 函式。
main 的函式主體本身也遵循特定的配置。
首先是呼叫 `UNITY_BEGIN()`，接著一個空行，然後是各個測試。
最後一個測試之後再空一行，然後回傳 `UNITY_END()` 的結果。

```c
int main(void)
{
    UNITY_BEGIN();

    RUN_TEST(test_foo);
    RUN_TEST(test_bar);

    return UNITY_END();
}
```
