# 簡介

Haxe 是強型別的語言，但在需要時，型別系統是可以被繞過的。將值指定給一個名稱，就叫做定義變數。定義變數時，可以明確指定它的型別，也可以讓 Haxe 編譯器自行推斷型別。因此，下面這兩種變數定義方式是等價的：

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

更新變數的值可以使用`=`運算子：

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

當你試著把型別不同的值指定給變數時，編譯器會拋出錯誤：

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

定義在類別裡的函式稱為方法（英文：_method_）。方法可以有零個或多個參數，而且所有參數都必須明確標註型別。和參數一樣，方法的回傳型別無法被推斷，也必須明確標註。方法使用`return`關鍵字來回傳值：

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

呼叫方法時，要指定它的類別和方法名稱，並傳入引數：

```haxe
var sum = add(1, 2) // sum = 3
```

Haxe 的作用域定義在`{`和`}`字元之間。

Haxe 支援兩種註解。單行註解以`//`開頭，多行註解則寫在`/*`和`*/`之間。
