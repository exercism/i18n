# 指示

在這個練習中，你會撰寫程式碼，協助一位自由工作者和客戶溝通特定專案的價格。你會寫幾個工具方法，為客戶快速計算費用。

```exercism/note
`rate_per_hour` 參數和 `day_rate` 方法都與金錢有關。它們的計量單位是「每單位時間的金額」：分別是小時和天。
```

## 1. 根據時薪計算日薪

有位客戶聯絡這位自由工作者，詢問收費標準。自由工作者說明他們 **_每天工作 8 小時_**。不過，他們只知道專案的時薪。請協助他們根據時薪估算日薪。

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

日薪不需要四捨五入，也不需要改成「固定」的精確度。

## 2. 根據固定預算計算工作天數

某天，有位專案經理邀請這位自由工作者承接一個有固定預算的專案。請根據固定預算和這位自由工作者的時薪，協助他們計算在預算用完前可以工作幾天。結果_必須_**無條件捨去**至最接近的整數。

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. 計算大型專案的折扣價格

自由工作者的客戶經常請他們承接橫跨數個月的專案。在這些情況下，自由工作者會決定為每個完整月份提供折扣，剩下的天數則以日薪計費。你良好的工作與生活平衡代表你在每個日曆月只工作 22 天，所以 **_每個月有 22 個計費天數_**。請根據時薪、專案包含的計費天數，以及每月折扣率，協助他們估算這類專案的成本。折扣一律以數字傳入，其中`42%`會變成`0.42`。結果_必須_**無條件進位**至最接近的整數。

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
