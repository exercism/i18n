# 簡介

Swift 有一組敘述，可以用來改變迴圈正常的控制流程。這些敘述稱為控制轉移敘述。你已經看過`return`；這個概念會介紹其他幾種，包括`continue`、`break`和標籤。

## Continue

有時候，我們需要提早跳到迴圈的下一次疊代，而不完成目前這次疊代中剩下的敘述。這時可以使用`continue`關鍵字。執行`continue`時，迴圈會跳到下一次檢查，確認是否能執行下一次疊代；也就是 while 迴圈和 repeat-while 迴圈中的`while`，或是 for-in 迴圈中檢查序列裡是否還有下一個元素。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break 用來提早結束迴圈。執行`break`時，迴圈會立刻結束，程式會繼續執行迴圈後面的第一個敘述。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## 標籤

當迴圈是巢狀的時候，有時我們會想用`break`或`continue`，來結束或重新開始那些包含`break`或`continue`所在迴圈的外層迴圈。在這種情況下，可以使用標籤來指定要結束或重新開始的迴圈。只要在開始迴圈的`while`、`repeat`或`for`前面放上名稱加上冒號，就能為迴圈加上標籤。

想看看這樣使用標籤的效果，請參考下面這個迴圈。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

`fallthrough`關鍵字用來讓程式在 switch 敘述中繼續往下執行到下一個 case。這表示下一個 case 裡的程式碼會直接執行，不會檢查它的條件。這會讓 switch 敘述的行為像其他程式語言一樣：在符合某個 case 之後，不需要用`break`敘述來離開 switch 敘述。你可以在 [Swift 書][fallthrough] 中讀到更多關於`fallthrough`的內容。

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
