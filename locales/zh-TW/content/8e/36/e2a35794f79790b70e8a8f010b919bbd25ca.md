# 提示

## 1. 幫 Lenny 複習符號

- 如果你沒辦法從函式回傳符號，也許該看看[引用][so-quoting]！
- 別忘了，關鍵字和一般符號有點不同，而且[必須以不同的字元開頭][clhs-keywordp]。

## 2. 幫 Lenny 分辨 atom 和 cons

- Common Lisp 內建了許多用來判斷各種事情的述詞函式。其中特別有兩個和[這裡][clhs-conses]非常相關。找找名字裡有 "atom" 或 "cons" 的函式。
- 注意：一般而言，述詞函式的名稱會以 `p` 或 `-p` 結尾。atom 述詞的命名很不一致，這點挺可惜的。

## 3. 幫 Lenny 拆解 cons

- 談到取得 sexpr 的第一個元素和其餘部分，[這裡][clhs-conses]有幾個選擇。
- 特別留意 _Accessors_，而不是函式。
- 有幾個選擇的名稱可能比你想像中更直覺！
