# 運算子多載

運算子多載是某些程式語言的功能，允許重新定義標準運算子，例如加法（`+`）、減法（`-`）、乘法（`*`）和除法（`/`），讓它們能套用在使用者自訂的型別上。

這麼一來，程式碼的語法會更直覺，因為對使用者自訂型別進行的運算，可以用和基本型別運算相同的方式來表達。

在 Cairo 中，運算子多載是透過實作特定的 trait 來達成。

每個運算子都有對應的 trait，而要多載某個運算子，就得為自訂型別提供該 trait 的實作。
不過，務必審慎使用運算子多載。

誤用會造成混淆，讓程式碼更難維護，例如被多載的運算子本身並沒有語意上的意義時。

想想一個例子：需要把兩個 `Potions` 結合起來。

`Potions` 有兩個資料欄位，分別是 mana 和 health。

結合兩個 `Potions` 時，應該把各自對應的欄位相加。

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

在上面的程式碼中，我們為 `Potion` 型別實作了 `Add` trait。

add 函式接受兩個引數：`lhs` 和 `rhs`（分別代表左側和右側）。

函式主體會回傳一個新的 `Potion` 實例，而它的欄位值則是 `lhs` 和 `rhs` 的組合。

如同範例所示，多載運算子時必須指明要進行多載的具體型別。

被多載的泛型 trait 是 `Add<T>`，而我們透過 `Add<Potion>` 為 `Potion` 型別定義具體的實作。
