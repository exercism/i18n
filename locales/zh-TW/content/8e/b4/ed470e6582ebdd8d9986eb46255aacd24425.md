# 指令

數一數下面這種 ASCII 圖中有多少個矩形。

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

上面的圖包含這 6 個矩形：

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

你可以假設輸入永遠是完整的矩形（也就是每一行的長度和第一行的長度相等）。
