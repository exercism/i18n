# 提示

## 一般

- 別忘了在每個敘述後面加上`;`喔。
- 你可以用`int myInteger = 44;`定義一個整數。

## 1. 取得烘焙時間。

- 說明中有食譜所需時間的資訊。
- 函式可以用`return 2;`這樣的形式回傳值。

## 2. 取得準備時間。

- 你可以使用對應的參數取得層數。
- 定義整數時可以直接做計算：`int myInteger = 3 + myOtherInteger;`

## 3. 計算烤箱中剩餘的時間

- 你可以呼叫其他函式，並像使用變數一樣使用回傳值：`return 22 * myOtherCalculation();`

## 4. 計算千層麵花費的總時間

- 輸出應該結合準備時間，以及千層麵已經在烤箱中的時間。
