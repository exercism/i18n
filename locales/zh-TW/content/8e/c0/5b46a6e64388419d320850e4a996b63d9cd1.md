# 說明補充

## 實作

機器人的名稱有可能會用完。當所有可能的機器人名稱都已經被分配完之後，就應該回傳錯誤。

## 加分測試

當你讓`go test`通過之後，你會發現在測試套件裡有一個名為`TestCollisions`的測試，它預設會被跳過，因為執行起來可能需要很久。
這個測試會不斷建立新的機器人，直到再也沒有新名稱可以分配給機器人為止。

想讓這個測試執行，請移除這一行：

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

想讓這個測試通過，你必須確保機器人的名稱以前沒有被使用過，並且名稱能夠有效率地分配。
