# 測試

## Clojure CLI

Exercism 上的 Clojure 練習會附帶一個`deps.edn`檔，裡面有`:test`別名，用來呼叫 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)：

``` bash
$ clj -X:test
```

## Leiningen

你也可以用 Leiningen 來執行練習的測試，只要在練習的目錄中執行下列指令：

```bash
lein test
```

## REPL

如果想用 REPL 執行練習的測試，請在練習的目錄中執行下列指令：

```bash
$ clj
```

或

```bash
$ lein repl
```

接著用`require`載入練習的測試命名空間與 Clojure 測試命名空間：

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

接著對`<exercise>-test`呼叫`run-tests`：

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
