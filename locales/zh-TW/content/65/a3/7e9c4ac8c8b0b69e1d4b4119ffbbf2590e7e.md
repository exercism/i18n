# 簡介

在 Gleam 中，`case`運算式可以用來依照條件執行不同的程式碼。使用`case`運算式時，可以把一個值拿去和一個或多個_模式_比對。這類模式的例子之一是_字面模式_，它會將值與字面值（例如`1`或`"hello"`）比對。

`case`運算式是用`case`關鍵字寫成的：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

這看起來或許像其他語言的`switch`敘述，不過當你搭配使用其他模式時，模式比對才會真正發揮它的威力。其中一種就是_變數模式_，它能讓你將值指定給變數。在這個範例中，如果`number`不是`0`，變數`i`就會被指定為`number`的值：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

在某些情況下，你可能想為模式加上額外的條件。這稱為_守衛_（子句），可以用`if`關鍵字加上：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

基於效能考量，守衛中只允許使用基本的數學與布林運算子，其他函式不能在守衛中使用。

在上面的範例中，並非所有可能的輸入都有對應的模式。編譯器會偵測到這一點並輸出錯誤。這稱為_窮舉檢查_。要解決這個警告，必須處理所有情況。為此，可以使用_丟棄模式_，這種模式能比對任何值：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

`case`運算式會由上而下把值逐一與每個模式比對，直到找到相符的模式，並執行該模式對應的邏輯。模式的順序很重要喔！
