# 簡介

類別是在 F# 中進行物件導向程式設計的主要結構。

F# 的類別由它的欄位和方法組成。類別的欄位和方法稱為它的成員。

F# 的類別使用`type`關鍵字定義。方法使用`member`關鍵字定義，而且一律是公開的。若要定義（私有的）欄位，可以使用`let`繫結。

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

類別是建立物件時使用的範本。若要建立類別的實例，就把類別名稱當成函式來呼叫。類別的實例也稱為物件。

可以使用點記法存取物件的成員。

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
