# 說明補充

## 實作

定義兩個函式：（兩個？沒錯，有時候我們會對 Go 有更多要求。）

`All`會回傳一個陣列，包含`s`中所有長度為`n`的子字串。

`All(n int, s string) []string`

`UnsafeFirst`會回傳`s`中長度為`n`的第一個子字串。

`UnsafeFirst(n int, s string) string`

到這裡，你可以認為這個練習已經完成，繼續往下走了。

但是等等，也許你會問一個很合理的問題：為什麼這個函式叫做**Unsafe** First？如果你有興趣，就繼續往下讀，看看額外的練習吧。

## 額外練習

當你讓`go test`通過之後，試試`go test -tags asktoomuch`吧。
這會使用一個_建置標籤_來啟用先前沒有啟用的測試。
建置標籤可以讓套件選擇要使用哪些檔案。
在這裡，它會控制要使用哪些測試檔案。
你可以在 [the Go documentation](https://golang.org/pkg/go/build/#hdr-Build_Constraints) 讀到更多相關資訊。

你可能會發現，你沒辦法讓這個 _asktoomuch_ 測試通過。
我們需要一種方式來表示：在某些情況下，你無法取得字串的前 N 個字元。
`UnsafeFirst`只會回傳一個字串，所以做不到這件事。

為了解決這個問題，我們讓這個函式多回傳一個值吧。
定義`First(int, string) (first string, ok bool)`，並用`go test -tags first`測試。

`ok bool`這個第二個回傳引數，是 Go 中常見且慣用的模式。
例如，你可以在 [Map lookups](https://blog.golang.org/go-maps-in-action) 和 [type assertions](https://tour.golang.org/methods/15) 中看到這種做法。
