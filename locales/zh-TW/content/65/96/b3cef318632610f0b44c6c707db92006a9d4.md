# 簡介

`:`定義可以直接呼叫自己。Factor 的編譯器會像推斷其他任何詞一樣，推斷遞迴詞的堆疊效應，單純的遞迴不需要任何特殊宣告。

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

這兩個部分分別是遞迴的*基本情況*（在這裡，空序列的總和是`0`）與*遞迴步驟*（剝掉一個元素，對剩下的部分遞迴，再合併結果）。

`if-empty`和`unclip`是序列遞迴的標準搭檔。`if-empty ( seq emptyquot nonemptyquot -- )`會根據序列執行兩段引述中的其中一段；`unclip`則會剝掉第一個元素，讓遞迴步驟有更簡單的東西可以處理。
