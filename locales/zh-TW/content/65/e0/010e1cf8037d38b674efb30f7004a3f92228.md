# 透過 GitHub 貢獻

對 Exercism 程式碼庫的貢獻，都是透過 [GitHub][github] 完成的。

如同名稱所示，GitHub 以 [git][git] 作為版本控制系統。如果你不熟悉 Git，最好的線上資源是 [Pro Git][pro-git]。

如果你還不熟悉 GitHub 和貢獻流程，這裡有一些資源可以幫助你上手：

- [GitHub 簡介：互動式課程][github-course]
- [如何在 GitHub 上建立提取要求：教學][pr-tutorial]
- [如何建立簡單的 GitHub PR：anthonywritescode 的影片][anthonywritescode]

## 指南

想知道怎麼讓你的貢獻受到歡迎，可以閱讀[如何建立優秀的提取要求][great-pr]這份指南。

我們還有幾份 Exercism 專屬的提取要求指南：

- [如何建立優秀的提取要求][how-to-make-a-great-pr]
- [貢獻者提取要求指南][contributors-pr-guide]
- [維護者提取要求指南][maintainers-pr-guide]
- [維護者的儲存庫權限][maintainers-repo-permissions]
