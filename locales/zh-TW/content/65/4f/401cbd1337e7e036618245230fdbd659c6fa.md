# 關於

可能很難找到比 [Raku](https://raku.org/) 更有表達力的程式語言。Raku 是一門現代、多範式的程式語言，提供[程序導向](https://docs.raku.org/language/functions)、[物件導向](https://docs.raku.org/language/objects)與[函式式程式設計](https://docs.raku.org/language/functions#Functions_are_first-class_objects)等方法。

[好奇嗎？](https://raku.org/)到[文件](https://docs.raku.org/)或模組[儲存庫](https://raku.land/)（類似 pypi 或 CPAN）深入探索看看吧。

這是一門極度[靈活](https://docs.raku.org/language/operators)的語言，會[配合](https://docs.raku.org/language/glossary#gradual_typing)你的程式設計風格，無論是系統管理員用的快速[單行指令](https://docs.raku.org/language/create-cli)、管理資料庫匯入的指令碼，還是實現[整個網站](https://cro.services/)所需的整套模組堆疊。

Raku 向其他語言學習：

* 它透過完善的物件系統，提升了 Perl 長久以來的吸引力，其中包含[角色](https://docs.raku.org/language/typesystem#role)、[執行緒](https://docs.raku.org/language/concurrency)與[多重方法](https://docs.raku.org/language/glossary#Multi-dispatch)分派。
* 它從 Java 取用執行緒，並將它[簡化](https://docs.raku.org/language/concurrency)成少數幾個方法。
* 採用 Lisp 的[外部函式介面](https://docs.raku.org/language/nativecall)，讓取用函式庫變得像一行程式碼那麼簡單。
* [正規表達式](https://docs.raku.org/language/regexes)現在火力全開，導入了剖析表達式[文法](https://docs.raku.org/language/grammars)，讓你處理龐大的剖析工作。
* 嚴格模式與警告現在會自動生效，大幅減少潛在錯誤。
* ……而且它還懂[數學](https://docs.raku.org/language/math)：```1/10 * 3 == 0.3 ```，試著用你最愛的語言跑跑看！

Raku 的座右銘：
* 「Raku 的設計目標是讓簡單的事變簡單，同時不讓困難的事變得不可能。」
* 「做同一件事的方法不只一種，現在還加入了更多 -Ofun（為了樂趣而最佳化）。」
