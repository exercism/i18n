# 學習

想開始學 Groovy，或是在做練習的同時多學一點嗎？

你可以用這些方式試試 Groovy：

* [用瀏覽器搭配線上翻譯員](https://www.jdoodle.com/execute-groovy-online)
* [Groovy Console](http://groovy-lang.org/groovyconsole.html)：在命令列輸入`groovyConsole`
* [Groovy Shell](http://groovy-lang.org/groovyconsole.html)：在命令列輸入`groovysh`

想快速認識 Groovy，可以看看：

* Tim Rows 的 [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/)，對不是寫 Java 的開發者來說也同樣好用
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* SmartThings 的 [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html)
* JDriven 的幾個[線上 Groovy Koans](http://www.groovy-koans.org/)

想更深入探索，可以參考：

* [Groovy 文件](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition)，談 Groovy 的_經典之作_
* Ken Kousen 的 [Making Java Groovy](https://www.manning.com/books/making-java-groovy)
