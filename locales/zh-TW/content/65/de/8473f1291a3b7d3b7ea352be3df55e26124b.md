# 關於

型別定義會建立一個全新的具名型別，它和其他所有型別都不相同，即使是底層型別相同的型別也一樣。

## 定義型別

型別定義以`type`關鍵字開頭，接著是新型別的名稱和它的底層型別：

```go
type File []bool
```

這裡的`File`指的是西洋棋棋盤上單一的垂直直行，通常標示為 A 到 H。
這條直行上的每個格子都用一個布林值表示，標記該格是否被佔用。
既然`File`已經定義好了，我們就可以在其他定義裡使用它：

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`把直行識別碼對應到`File`值。
每個`File`都是一串由布林值組成的切片，代表某個直行裡的各個格子。
如果沒有這些型別定義，`board`就會是`map[string][]bool`，這樣就比較難理解我們想表示的內容是什麼。

## 定義的型別彼此不同

雖然`Score`和`int`都存放整數值，但要在兩者之間轉換，必須使用明確的轉換：

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42`是無型別常數，因此可以直接指定給`Score`變數。

定義的型別也可以有方法，這部分會在「方法」概念中介紹。

## 結構體

結構體定義也使用同樣的`type`關鍵字：

```go
type Player struct {
    Name  string
    Score Score
}
```

結構體型別會在「結構體」概念中介紹。

## 型別別名

型別別名是為現有的型別建立另一個名稱，而不是建立一個新型別。
由於別名和原本的型別完全相同，它們的值可以互通使用。
宣告別名時，要使用`type`關鍵字、別名、等號（`=`）以及現有的型別。

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
