# 唯讀類別與屬性

唯讀類別與屬性讓類別可以定義公開屬性以便取用，同時防止修改。
若要將某個屬性宣告為唯讀，必須在型別標註前加上`readonly`。
屬性只允許賦值一次，任何重新賦值或修改值的嘗試都會產生錯誤。

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

唯讀類別建立在這項行為之上：若類別宣告為`readonly`，就會把唯讀宣告套用到每個屬性。
此外，它也會阻止新增動態屬性。

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
