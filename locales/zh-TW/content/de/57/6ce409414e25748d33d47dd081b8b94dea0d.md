# 介紹

泛型讓你寫出可處理多種型別、又不必重複的程式碼。使用角括號 `<T>` 來定義泛型型別，其中 `T` 是任何型別的佔位符。

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo 要求使用 trait 界限來說明泛型型別必須支援哪些操作。你可以用 `+` 語法來加上限制：

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

結構體也可以是泛型的：

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

trait 也能是泛型的，因此可以搭配不同的型別使用：

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

函式可以接受帶有 trait 界限的泛型參數，讓它能用在任何實作了所需 trait 的型別上：

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
