# 關於

`bit`是電腦運算中最細微的值。
`bit`這個詞代表「二進位數字」。
它是執行環境中的一種資料儲存單位，其大小足以容納一個只能擁有兩種值其中之一的物件。
因此，它的二進位值不是`1`就是`0`。
其他所有資料型態都由多個`bits`組成。
例如，一個`byte`通常由 8 個`bits`組成。

## 如何撰寫位元值

`Bits`構成了以 2 為基底的數字系統。
`2`的每一個倍數會放在我們認知的十位、百位、千位等位置上，只是這裡的「十」其實是「二」，「百」是「四」，「千」是「八」，以此類推。
所以，十進位值`2`對應的二進位值是`10`，`4`是`100`，`8`則是`1000`。
和十進位數字一樣，位值由右至左愈來愈高。
我們可以把十進位值`5`想成二進位的`101`，其中「個位」是`1`，「四位」也是`1`。
不過，二進位字面值並不屬於 C 語言標準的一部分。
C 語言標準所支援的二進位值，只有單一的`1`或`0`。
有些非標準的編譯器擴充功能_確實_支援二進位字面值，例如 gnu 編譯器，只要在字面值前面加上`0b`即可。

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

請務必記得，這種寫法並非所有編譯器都支援，而且可能成為程式碼在不同編譯器之間移植的障礙。

撰寫二進位值的常見做法是使用十六進位標記法，也就是以 16 為基底的數字系統。
C 語言的十六進位標記法會在字面值前面加上`0x`或`0X`。
由於十進位值`16`在十位數以`1`表示，因此十進位值`10`在十六進位中表示為`0xA`，`11`是`0xB`，`12`是`0xC`，`13`是`0xD`，`14`是`0xE`，`15`則是`0xF`。
舉例來說，十進位值`42`會寫成`0x2A`：`2`乘以`16`（= `32`）再加上`10`（= `42`）。

在二進位中，我們可以把`42`想成`00101010`：`32`加`8`加`2`。
我們會說從右邊數來的第二、第四和第六個位元「已設定」，意思是它們是`1`而不是`0`。
第二個位元是`2`，第四個位元是`8`，第六個位元是`32`。
設定這三個位元就定義出`42`這個值。

## 位元遮罩

位元遮罩可以是任何用來設定個別位元的值。
舉例來說，英文有 26 個字母。
一個至少有 26 個位元的值，例如無號 32 位元整數，就可以當作位元遮罩，為每個英文字母設定`true`或`false`的狀態。
任何位元數足以處理所需的一組`true`或`false`條件的值，都可以當作位元遮罩。
設定和讀取個別位元，都要透過位元運算子來完成。

## 位元運算子

假設我們想追蹤一個`string`中出現了哪些字母。
在這個例子裡，我們只會用到英文的 26 個字母。
我們的位元遮罩會是無號的 32 位元整數。
`0`代表這個字母沒有出現。
`1`代表這個字母出現一次或多次。
一開始，位元遮罩的位元表示會是連續 32 個`0s`：`00000000000000000000000000000000`。
最右邊的位置代表`A`。
從左邊數來第二個位置代表`B`，以此類推。
假設我們用迴圈處理字串中的所有字母，所以我們希望有一行程式碼就能設定任何字母。

### 位元左移運算子：定位位元的方法

`<<`是向左移位的位元運算子。

如果我們的字母是`A`，我們不想左移；但如果字母是`B`，我們想左移一個位置；如果字母是`C`，我們想左移兩個位置，以此類推。
雖然我們可以把`chars`看成`A`或`B`這樣的字母，但`char`在記憶體中是以整數型態實作的，所以我們可以對`char`做簡單的數學運算。
假設有一個名為`letter`的變數，代表我們正在處理的`char`，我們可以把`1`左移`letter`與`A`這個`char`之間的差值，來左移所需的位置數，寫成：`1 << letter - 'A'`。
`A` - `A`是`0`，所以如果`letter`是`A`，就會左移`0`個位置。
`B` - `A`是`1`，所以如果`letter`是`B`，就會左移`1`個位置，以此類推。

### 位元包含或運算子：設定位元的方法

一旦知道我們想在哪裡_設定_某個位元，就可以用位元包含或運算子（也就是`|`）來實際設定它。
`|`運算子的結果，會在左運算元或右運算元其中一方設有位元的位置上得到`1`。
所以，`0010 | 0001`的結果會是`0011`。
（要記得，這個值在二進位是`11`，但在十進位是`3`。）
要把結果指定給某個值時，`|`運算子可以和指定運算子結合，像這樣設定位元：`|=`。
為了簡單起見，下面的範例沒有使用迴圈，但它示範了我們如何用位元遮罩處理`ABA`這幾個字母。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

我們把遮罩最右邊的部分為`A`設成`0001`，接著為`B`把遮罩設成`0011`。
再設定一次`A`並不會改變現有的遮罩。
我們可以先檢查`A`是否已經設定過，來避免重複設定同一個位元。

### 位元且運算子：讀取位元的方法

`&`是位元且運算子。
`&`運算子的結果，會在左、右運算元都設有位元的位置上得到`1`。
所以，`0011 & 0001`的結果會是`0001`。
我們可以在下面的範例中看到實際運作。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### 位元互斥或運算子：翻轉位元的方法

`^`是位元互斥或運算子。
有_包含_或運算子，就意味著存在行為不同的_互斥_或運算子。
`^`運算子的結果，會在左、右運算元中_只有一個_設有位元的位置上得到`1`。
所以，`0001 ^ 0011`的結果會是`0010`。
最右邊的位元不會被設定，因為_兩個_運算元在最右邊的位置都是`1`。
互斥或運算有時會寫成 XOR。
如果把一個值做 XOR 之後的結果再 XOR 一次，就會還原成原來的值。
這可以用來做非常簡單的加密，也就是用同一把金鑰來加密和解密資料。
例如

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### 位元右移運算子：將值減半的方法

`>>`是向右移位的位元運算子。
一般來說，一個值的位元每向右移一個位置，結果就相當於該值除以二。
例如

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

如果右運算元的值是負數，或大於等於提升後左運算元的寬度，則行為未定義。
這也適用於左移運算子。
當使用有號整數而非無號整數時，正負號也可能有影響。
下面的範例顯示在有號整數上左移或右移太多時，某個系統上的行為。

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

由於行為未定義，不同的系統可能會得到不同的結果。
移位時，重要的是要了解所用資料型態的範圍限制。

## 位元欄位

我們已經看到，封裝在簡單資料型態中的位元，可以依位置來存取。
封裝在`struct`中的位元，則可以依名稱來存取。
這樣的資料型態稱為`bit field`。
`bit fields`的適用情境之一，是需要一組開／關旗標，同時希望盡量減少記憶體用量時。

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;`這樣的語法，會在 struct 中建立一個位於`unsigned int`內、寬度為`1`位元的欄位。
除了`unsigned int`，也可以使用`signed int`，或者從 C99 之後，也可以使用`bool`型態。
含有位元欄位的 struct 也可以包含其他資料型態的欄位，例如上面範例中的`number_of_lights`。
