# 附加說明

## 實作

在西洋棋中，橫列稱為「rank」，直行稱為「file」。
rank 的範圍從 1 到 8，file 的範圍則從 A 到 H。

在這個練習中，`Square`是一種不透明型別，代表棋盤上的一個格子。
它在內部使用從 0 開始索引的`row`和`column`欄位，並保證這些欄位永遠有效（也就是 0 到 7）。

`create`函式接受一個`Str`作為輸入，代表棋盤上以官方記法表示的有效格子，例如`"C5"`。
`create`函式必須解析這個`Str`，確認它代表一個有效的格子，若是如此，就必須回傳一個`Square`值，其中包含適當的`row`和`column`欄位。
rank 1 對應到 row 0，rank 8 對應到 row 7。
例如，`create("C5")`必須回傳一個 row 為 4、column 為 2 的格子。

`Square`型別也提供方便的`rank`和`file`方法。
在上面的例子中，`rank`必須回傳整數`5`，`file`則必須回傳字元`'C'`。

最後，`queen_can_attack`函式接受兩個不同的`Square`值，並檢查放在這兩個格子上的皇后是否能互相攻擊。

重點：當你想提供一些保證時，像`Square`這樣的不透明型別就很好用，例如`row`和`column`永遠介於 0 到 7 之間。
不透明型別也會向使用者隱藏實作細節，讓 API 更簡潔。
