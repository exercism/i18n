# 簡介

處理輸入與輸出的函式由`IO`模組提供。

## 輸出

要把字串寫到標準輸出，請使用`IO.puts`。`IO.puts`一律會在字串結尾加上換行。如果你不想要這種行為，請改用`IO.write`。這兩個函式如果成功，都會回傳原子`:ok`。

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`很適合用來寫字串，但除此之外用途不多。如果你需要一個除錯用的工具，能把任何值寫到標準輸出，請改用`IO.inspect`。`IO.inspect`會原封不動地回傳傳入的值，所以可以安插在程式碼中的任何位置。它也接受許多選項，例如`:label`，讓你能把它和其他`IO.inspect`呼叫區分開來。

## 輸入

要從標準輸入讀取一行，請使用`IO.gets`。`IO.gets`接受一個引數，也就是會印出來當作輸入提示的字串。`IO.gets`不會在提示後面加上換行，如果需要就自己加。

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
