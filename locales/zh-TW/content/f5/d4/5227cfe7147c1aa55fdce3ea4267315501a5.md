# 測試

每個練習都包含一個測試檔案。
使用`bats`程式來執行測試。

```bash
bats test-hello-world.bats
```

你需要先安裝`bats`。
請參閱[在 Bash track 上測試][bash]頁面，了解如何為你的系統安裝`bats`。

### bats 是以 bash 實作的

bats 檔案就是一個 bash 腳本，裡面有一些`bats`指令認得的特殊函式。
你會看到一些測試長得像這樣

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

`<<<`這種語法是 bash 的 [Here String][here-string]。
它會把右邊的字串送進左邊程式的標準輸入。
它（[大致上][so]）等同於

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## assert 函式的說明

這些測試使用了 [bats-assert][bats-assert] 函式庫裡的函式。
各種`assert*`函式的說明都可以在那裡找到。

## 略過的測試

解完一個練習，代表要讓它所有的測試都通過。
預設情況下，當你執行測試時，只會跑一個測試（第一個）。
這是刻意的，這樣你就能專心先讓那一個測試通過。
一旦它通過了，只要把加在其他測試前面的這行註解註解掉或刪除，就能啟用下一個測試：

    [[ $BATS_RUN_SKIPPED == true ]] || skip

## 覆寫略過設定

如要執行所有測試，包括帶有`skip`註解的那些，可以執行：

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

用一個包裝函式來省點打字還滿方便的：在`bash`裡你可以這樣做：

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

之後只要這樣就能執行測試：

```bash
bats
```

## 在`jq`中除錯

`jq`內建一個方便的[`debug`][debug]篩選器。
在開發練習解答時，可以用它來檢視目前位在 jq 管線中的資料。
詳情請參閱[除錯文件][debugging]。
