# 指令

在這個練習中，你將實作一部分的工具函式，協助開發者清理識別字名稱。

在這 5 個任務中，你會逐步打造出`clean`函式。
有效的識別字由零個或多個字母與底線組成。

如果傳入`clean`函式的是一個空字串，就應該回傳空字串。

## 1. 將空格替換為底線

實作`clean1`函式，將任何空格替換為底線。開頭與結尾的空格也一樣要處理。

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. 將控制字元替換為大寫字串「[CTRL]」

實作`clean2`，做到前一個函式的所有事情，並將常見的控制字元（\n、\t 和 \r）替換為字串`"[CTRL]"`。

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. 將 kebab-case 轉換成 camelCase

實作`clean3`，做到前一個函式的所有事情，並將 kebab-case 轉換成 camelCase。

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. 省略數字

實作`clean4`，做到前一個函式的所有事情，並省略所有數字。

```elm
clean4 "123"
    --> ""
```

## 5. 省略希臘小寫字母

最後，實作`clean`，做到前一個函式的所有事情，並省略範圍從 'α' 到 'ω' 的希臘字母。

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
