# 簡介

在 Common Lisp 中，函式不只可以回傳一個值，還可以回傳多個值。
例如`floor`會朝零的方向向下取整，並回傳兩個值：第一個是取整後的值，第二個是餘數。

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
（我們會把回傳的多個值分別顯示在輸出的不同行。）

## 回傳多個值

如果你想讓函式回傳多個值，就要使用`values`存取器：

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## 處理多個值

如果你只在意第一個值，那就不需要做任何特別的事，語言本身會處理好：

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

不過，如果你想存取其他那些值，就會需要用到幾個函式。
兩個主要的巨集是`multiple-value-list`和`multiple-value-bind`。
它們用來包住會回傳多個值的東西，並捕捉所有的值。
第一個會建立一個包含所有值的陣列。
第二個則讓你將變數綁定到各個值上。

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

另一個實用的函式是`nth-value`。
