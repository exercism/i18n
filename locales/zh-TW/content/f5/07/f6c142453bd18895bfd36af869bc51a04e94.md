# 關於

*堆積*是一種集合，它隨時知道自己的最小（或最大）項目，並讓你快速移除它，是*優先佇列*最自然的實作方式。堆積位於[`heaps`][heaps]詞彙表中。

`<min-heap>`會建立一個空堆積，最小的鍵會最先出來；`<max-heap>`則先取出最大的。每個項目都是以*鍵*儲存的*值*，而鍵就是 Factor 排序時所依據的優先順序：

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

堆積是*可變的*：`heap-push`和`heap-pop`會就地修改它。

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek`會讀取前端的項目，但不會移除它；`heap-pop`會移除並回傳它；`heap-pop-all`則會把堆積依優先順序清空成由`{ key value }`配對組成的關聯清單。

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

推入的成本是`O(log n)`，讀取前端則是`O(1)`，所以即使是很大的佇列，反覆「取出最緊急的項目，再加入更多項目」依然很快。實作方式是把二元堆積存放在可成長的陣列中；鍵可以是任何可排序的值（數字、字串、……）。
