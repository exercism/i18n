# Exercism 的 24 Pull Requests：Ruby 版！

我們歡迎大家為這個專案貢獻一份心力。

在我們的 issue 清單中，請留意下列標籤：

* first-timers only
* good first patch
* bug
* enhancement

或者，你注意到了什麼可以貢獻的地方嗎？文件還不夠完善？少了什麼東西嗎？在 Exercism 上提交與審閱練習時，發現了你不喜歡的地方嗎？那就建立一個 pull request 吧！

請參閱[參與語言軌道](https://github.com/exercism/docs/blob/master/contributing-to-language-tracks/README.md#getting-involved-in-an-exercism-language-track)文件，以及一些[我們正在尋找的點子](http://exercism.io/languages/ruby/todo)，看看有哪些練習需要實作。

我們會在論壇 [building-exercism] 回答大家的問題。

[building-exercism]: https://forum.exercism.org/c/general/building-exercism/125
