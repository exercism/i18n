# 說明

在這個練習中，你要實作一個程式，用來判斷[井字棋][tic-tac-toe]遊戲的狀態。
（這個遊戲你可能也聽過叫做「noughts and crosses」或「Xs and Os」。）

遊戲在 3×3 的網格上進行。
玩家輪流在網格上放置 `X` 和 `O`。
當其中一位玩家把三個記號連成一線（橫向、縱向或斜向），或是整個網格都被填滿時，遊戲就結束。

在這個練習中，我們假設由 `X` 先下。

你的任務就是判斷給定的遊戲處於哪一種狀態。

遊戲狀態有三種可能：

- 遊戲仍在**ongoing**。
- 遊戲最終結果為**draw**。
- 遊戲最終結果為**win**。

如果給定的棋盤不合法，請拋出適當的錯誤。

棋盤符合下列條件時就是不合法：

- 在正確的輪流順序下（記得`X`先下），這個棋盤不可能出現。
- 遊戲在結束之後還繼續進行。

## 範例

### 遊戲進行中

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 和局

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 獲勝

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 不合法

#### 輪流順序錯誤

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 獲勝後繼續下棋

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```

[tic-tac-toe]: https://en.wikipedia.org/wiki/Tic-tac-toe
