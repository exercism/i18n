# 簡介

## 遞迴

某個事物能夠以自身來定義，這種能力稱為遞迴。在 Gleam 中，遞迴最常出現在遞迴函式裡，也就是會呼叫自身的函式。

遞迴函式至少需要一個_基本情況_，以及至少一個_遞迴情況_。_基本情況_會回傳一個值，而不會再次呼叫函式。_遞迴情況_會再次呼叫函式，並修改輸入，使它最終會符合基本情況。

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam 沒有專門用來迴圈的語法，所以所有迴圈都是透過遞迴完成。

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam 也支援遞迴自訂型別。遞迴自訂型別會有一個或多個變體在其所含的資料中參照自身。

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
