# 撰寫程式碼

請把你的程式碼寫在`<exercise_name>.zig`裡。
有些練習會附上針對特定 Zig 語法結構預先寫好的簽章，例如[常數][constants]、[函式][functions]、[匯入][imports]、[結構體][structs]，還有[更多其他內容][et-cetera]！

這些預先寫好的簽章是為了提供清楚的起點，幫助你完成練習。
不過，你不一定要從這些簽章開始。
畢竟只要能通過測試，任何寫法都是完全可以接受的解答。

## 執行測試

要執行測試，你只需要執行以下指令：

```bash
zig test test_exercise_name.zig
```

並把`exercise_name`替換成練習的名稱。
上述指令必須在練習的根目錄中執行，因為它的測試檔應該就在同一個位置。
此外，任何練習的所有測試預設都是啟用的，也沒有任何測試可以跳過。

由於所有測試都是這樣規定的，如果你想一個一個通過測試，就必須把還沒通過的測試[註解掉][comments]。
註解掉一個測試很簡單，只要在每一行開頭加上`//`就行了。
反過來說，當你確信自己的解法能通過測試時，可以把那些測試的註解取消，看看能不能通過吧。
