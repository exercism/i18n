# 指令補充

## 網格格式

網格以 null 結尾的字串表示，每一列的結尾都有一個換行字元。

## 暫存器

| 暫存器  | 用途     | 型別   | 說明                                                                                          |
| -------- | ------------ | ------- | ------------------------------------------------------------------------- |
| `$a0`    | 輸入        | 位址 | 以 null 結尾的輸入字串                                              |
| `$a1`    | 輸入/輸出 | 位址 | 以 null 結尾的結果字串，若網格尺寸無效則為空字串           |
| `$v0`    | 輸出       | 整數 | 網格狀態（`0` = `ok`，`-1` = `invalid columns`，`-2` = `invalid rows`） |
| `$t0-9`  | 暫存    | 任意     | 用於暫存資料                                                     |
