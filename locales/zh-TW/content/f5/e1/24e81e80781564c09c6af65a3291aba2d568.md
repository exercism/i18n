# 指令

學習如何把兩個不同內表中的資料合併成一個結果內表。

你的類別會收到兩個內表，裡面包含兩組完全不同的資料集：ALPHAS 和 NUMS。

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

ALPHA 資料表中的資料如下所示。

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

NUMS 資料表中的資料如下所示。

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

你的任務是回傳一個內表，其中的每筆記錄會把內表 ALPHAS 和內表 NUMS 中每個儲存格的值合併在一起。舉例來說，COMBINED_DATA 內表第一列第一欄的值應該是「A1」。

預期回傳的內表定義如下：

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
