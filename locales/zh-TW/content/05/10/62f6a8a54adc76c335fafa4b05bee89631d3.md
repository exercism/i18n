# 基礎介紹

[Go](https://golang.org) 是一門靜態型別、需要編譯的程式語言。
Go 的語法與 C 相似。
由於先前的網域名稱 golang.org，這門語言常被稱為 Golang，但它的正式名稱是 Go。

基礎概念會介紹三個主要的語言特性：套件、函式與變數。

## 套件

Go 應用程式是以套件來組織的。
套件是位於同一個目錄下的一組原始碼檔案。
同一個目錄中的所有原始碼檔案都必須共用相同的套件名稱。
依照慣例，套件名稱會是匯入路徑中的最後一個目錄。
舉例來說，["math/rand" 套件](https://golang.org/src/math/rand/)中的檔案會以 `package rand` 這道敘述開頭。
匯入套件時，只有名稱以大寫字母開頭的實體（函式、型別、變數、常數）才能被使用或存取。
Go 建議的命名風格是使用 `camelCase` 來命名識別字，但要在套件之間存取的名稱則應使用 `PascalCase`。

```go
package lasagna
```

## 變數

Go 是靜態型別的，這表示所有變數在編譯時就[必須有明確的型別](https://en.wikipedia.org/wiki/Type_system)。

變數可以透過明確指定型別來定義：

```go
var explicit int // Explicitly typed
```

你也可以使用初始值，編譯器會依照初始值的型別來指定變數的型別。

```go
implicit := 10   // Implicitly typed as an int
```

變數一旦宣告後，就可以用 `=` 運算子指定值。
變數一旦宣告後，它的型別就永遠不會改變。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 常數

常數和變數一樣用來保存一份資料，但它的值在程式執行期間不能改變。

常數使用 `const` 關鍵字定義，可以是數字、字元、字串或布林值：

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 函式

Go 函式接受零個或多個參數。
參數必須明確標註型別，沒有型別推論。

函式使用 `return` 關鍵字回傳值。

呼叫函式時，要指定函式名稱，並為函式的每個參數傳入引數。

注意，Go 支援兩種註解。
單行註解以 `//` 開頭，多行註解則放在 `/*` 與 `*/` 之間。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
