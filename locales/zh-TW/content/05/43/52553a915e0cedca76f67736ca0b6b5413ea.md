# 指令補充

## 提示

在 Java 中，一般認為使用實例方法會比類別方法更好。不過在某些情況下，讓函式成為`static`是絕對恰當的。因為 Java 的類別是封閉的、無法修改（也就是說，你無法像在 Ruby 或 JavaScript 等其他語言那樣，在類別定義之外為它新增成員），所以你沒辦法直接為類別加上新的行為。如果你還是想為某個型別定義行為，該怎麼辦？這種情況下最道地的做法，就是寫一個工具方法。
這類方法集合起來，通常被稱為「工具類別」。JRE 裡就有這類類別，例如 [Arrays](https://docs.oracle.com/javase/9/docs/api/java/util/Arrays.html) 和 [Collections](https://docs.oracle.com/javase/9/docs/api/java/util/Collections.html)。
在這個練習中，我們希望 List 能有`map()`、`reduce()`、`filter()`等方法。但 List 本身沒有這些方法，所以我們改用靜態方法。

`foldLeft` 和 `foldRight` 這兩個方法是「fold」函式，這個概念在函式程式設計的世界裡廣為人知，在物件導向的世界裡卻比較少見。想了解摺疊的[一般背景](https://en.wikipedia.org/wiki/Fold_(higher-order_function))與[簽章／實作提示](https://en.wikipedia.org/wiki/Fold_(higher-order_function)#Linear_folds)，請參閱維基百科上關於摺疊的頁面。
