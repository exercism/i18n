# 我們使用的詞語

詞語本身並沒有意義。它們只是從我們肺裡吐出的陣陣氣流所引起的振動。不過，正是因為**脈絡**，詞語才充滿力量。

你很容易知道自己希望詞語_帶給人什麼感受_，卻很難知道別人_怎麼理解你的詞語_。我們所說的話，深受人生經歷、文化規範，以及母語的影響。在 Exercism，我們相信最好選擇那些在不同文化之間，甚至盡可能在不同自然語言之間，都**清楚**而**明確**的詞語。這表示在使用比喻、縮寫或某些詞句時要格外小心，因為它們可能只有具備特定背景或特定知識的人才聽得懂。這也意味著要樂於了解不同文化的人可能如何誤解你的用意，並據此調整你使用的詞語。

其中一個例子是，在 Exercism 裡，我們請大家不要使用「guys」這個詞。雖然在許多地方，「guys」可以指一群人，不分性別，但在其他許多地方，它明確指的是「男人」。所以，無論說話者的用意是什麼，來自那種文化背景的人聽到「guys」時，都會理解為說話者只在對男性說話；如果自己不是男性，就會覺得被排除在外。在男性占了絕大多數的科技業，這又讓其他所有人多了一分負面與被排擠的感受。

一開始，很多人覺得這條規則吹毛求疵、不講道理，因為他們很清楚自己無意排除任何人。不過，當他們以「清楚、明確地溝通」這個原則為依歸，並且出於想善待社群中其他人的心意時，就會明白「guys」這個詞未必能把想表達的意思傳達給每一個人，於是選擇使用更清楚的詞語。

```exercism/note
我們的共同創辦人 Jeremy 來自英國，英國的字典明確寫著「guys」是不分性別的詞。在現實生活中，他經常用「guys」來稱呼一群女性。不過，在會議這類國際場合，或在 Exercism 這樣跨國的平台裡，他會選擇使用更清楚的詞，例如「folks」（偶爾在他特別有德州味的時候，會用 y'all）。因此，我們無意評斷「guys」該代表什麼意思、是好是壞，純粹是這個詞的用法應該隨著脈絡而改變。
```

### 你不知道自己不知道什麼

說對的話很重要，同樣重要的是理解：冒犯到別人的人，可能根本無意這麼做。文化差異意味著，人們常說出一些他們自己和朋友都清楚是指某個意思的話，但對你來說，那句話的意思卻完全不同。語言隔閡則意味著，非母語者可能用了一些詞，而這些詞的翻譯效果不如他們預期。在這些情況下，**請先假設對方是善意的。** 最好的做法，永遠是先假設對方是出於清楚表達與善待他人的用意，而且並不知道自己說的話會怎麼影響別人。人很容易在不知道某句話會冒犯人的情況下，不小心說錯話。

重要的不是犯錯，而是從中學到的事以及因此帶來的改變。所以，如果有人說了讓你覺得被冒犯的話，而你也不介意的話，就儘管告訴對方。而如果有人告訴你，你說了冒犯到他的話，請相信他，修改你的訊息，刪掉或改寫相關文字，並好好把握這個機會，多認識另一種文化，也讓自己的溝通能力更上一層樓，未來不再冒犯他人。

Exercism 的美好之處，就在於犯錯並從中學習。Exercism 很擅長透過引導幫助你做到這一點，也很擅長透過我們龐大且跨國的社群，帶你認識新的想法與資訊。盡情擁抱吧！
