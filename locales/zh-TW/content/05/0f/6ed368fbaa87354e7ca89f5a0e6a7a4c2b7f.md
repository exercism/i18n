# 簡介

類別是 Swift 程式的基本組成要素。
它們讓你能把相關的屬性（資料）和方法（函式）組成獨立、自成一體的功能單位。

### 定義類別

要定義類別，使用 `class` 關鍵字，後面接著類別名稱，並用大括號把類別定義包住：

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

類別的主體可以包含儲存屬性，這些屬性的定義方式和行為就跟一般的常數（`let`）或變數（`var`）一樣。

### 實例

類別定義就像一份藍圖：它定義一個新的型別，描述它的值長什麼樣子，但它本身不會建立任何實例。

要建立類別的*實例*，請呼叫它的初始化器，寫法是在類別名稱後面加上括號：

```swift
let someCharacter = GameCharacter()
```

這會建立一個新實例，它的屬性會以類別定義中指定的預設值初始化。
對於沒有明確預設值的可選屬性（例如 `name`），Swift 會將它們預設為 `nil`。

### 存取屬性

你可以用*點記法*存取實例的屬性：寫出實例名稱、一個點（`.`），再加上屬性名稱。
點記法也能用來存取巢狀屬性。

你可以用點記法讀取值，而如果屬性是可變的（`var`），也能指定新值：

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### 方法

除了屬性之外，類別還能定義*方法*，也就是與類別相關聯的函式。

在類別主體中使用標準的 `func` 語法來定義方法。
如果方法會修改某個屬性，那個屬性就必須用 `var` 宣告：

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

用點記法在實例上呼叫方法，就跟屬性一樣：

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

每個類別的實例都有一個名為 `self` 的隱含屬性，指向實例本身。
雖然在取用屬性或方法時經常省略，但當屬性名稱和方法參數名稱相同時，通常會用 `self` 來區分兩者。
