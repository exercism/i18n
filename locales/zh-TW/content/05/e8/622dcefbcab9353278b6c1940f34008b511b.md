# 說明

在這個練習中，你將寫一些程式碼，幫助你依照最愛的食譜做出美味的千層麵。

你有四項任務，全都和烹調千層麵所花費的時間有關。

## 1. 定義預計的烤箱時間（以分鐘為單位）

定義一個名為`$expected_minutes_in_oven`的常數。
根據食譜，烤箱的預計時間是 40 分鐘：

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. 計算剩餘的烤箱時間（以分鐘為單位）

這個值會以千層麵實際已經待在烤箱裡的分鐘數作為輸入，並根據上一項任務得到的烤箱預計時間，回傳千層麵還需要留在烤箱裡幾分鐘。

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. 計算準備時間（以分鐘為單位）

準備時間是指千層麵放進烤箱之前，需要花多少時間準備好。
每一層需要花 2 分鐘準備。

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. 計算總工作時間（以分鐘為單位）

計算你烹調千層麵總共花了幾分鐘。
這是準備時間的分鐘數，加上千層麵目前已經待在烤箱裡的分鐘數。

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
