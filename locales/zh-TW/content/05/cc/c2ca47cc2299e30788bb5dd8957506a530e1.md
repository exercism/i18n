# 測試

## 互動式測試

從你下載練習的目錄啟動 REPL。

你可以用`(load "exercise-test")`把測試檔案載入 REPL 來執行測試（把「exercise」換成對應的名稱）。接著求值`(exercise-test:run-tests)`，即可執行所有測試。

如果你直接在 REPL 裡寫程式碼，只要直接求值`(exercise-test:run-tests)`就好。

如果你把程式碼寫在練習的 Lisp 檔案裡，就先以`(load "exercise")`載入，再求值`(exercise-test:run-tests)`。

## 從命令列測試

你可以用下面這個命令列指令啟動測試（同樣地，請把兩處的「exercise」換成對應的名稱）

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
