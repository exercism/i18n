# 簡介

`bit`是運算中最小的單位。
`bit`這個字代表「binary digit」。
它是執行環境中的一種資料儲存單位，大到足以容納一個可能具有兩種值之一的物件。
因此，它的二進位值是`1`或`0`。
其他所有資料型態都由多個`bits`組成。
舉例來說，一個`byte`通常由 8 個`bits`組成。

## 位元遮罩

位元遮罩可以是任何用來設定個別位元的值。
舉例來說，英文字母有 26 個字母。
一個至少有 26 位元的值，例如無號 32 位元整數，就能當作位元遮罩，為每個英文字母設定`true`或`false`條件。
任何位元數足以處理一組所需`true`或`false`條件的值，都能當作位元遮罩。
設定與讀取個別位元，都是透過位元運算子來完成。

## 位元運算子

假設我們想記錄哪些字母出現在某個`string`中。
在這個例子裡，我們只會用到英文的 26 個字母。
我們的位元遮罩會是一個無號 32 位元整數。
`0`代表該字母沒有出現。
`1`代表該字母出現 1 次或多次。
一開始，位元遮罩的位元表示會是連續 32 個`0s`：`00000000000000000000000000000000`。
最右邊的位置對應`A`。
從左邊數來第二個位置對應`B`，依此類推。
假設我們用迴圈處理字串中的所有字母，所以我們想要一行能設定任何字母的程式碼。

### 位元左移運算子：定位位元的方法

`<<`是用來左移的位元運算子。

如果我們的字母是`A`，我們不想左移；但如果字母是`B`，我們想左移 1 個位置；如果字母是`C`，我們想左移 2 個位置，依此類推。
雖然我們可以把`chars`看成`A`或`B`這樣的字母，但`char`在記憶體中是以整數型別實作的，所以我們可以對`char`做簡單的數學運算。
假設有一個名為`letter`的變數，代表我們正在處理的`char`，我們可以把`1`向左移動`letter`與`A`這個`char`之間的差值，來左移所需的位數，就像這樣：`1 << letter - 'A'`。
`A`減`A`是`0`，所以如果`letter`是`A`，就會左移`0`個位置。
`B`減`A`是`1`，所以如果`letter`是`B`，就會左移`1`個位置，依此類推。

### 位元含或運算子：設定位元的方法

一旦知道我們想在哪裡設定位元，就能用位元含或運算子（也就是`|`）實際設定它。
`|`運算子的結果，會在左運算元或右運算元設有位元的每個位置上得到`1`。
所以，`0010 | 0001`的結果會是`0011`。
（重要的是要記住，這個值以二進位表示是`11`，但以十進位表示是`3`。）
要把結果指定給某個值，可以把`|`運算子和指定運算子結合起來設定位元，就像這樣：`|=`。

為了簡單起見，下面的範例不使用迴圈，但它示範了我們如何用位元遮罩處理字母`ABA`。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

我們把遮罩最右邊的位元設成`0001`來表示`A`，接著把遮罩設成`0011`來表示`B`。
再設定一次`A`不會改變既有的遮罩。
我們原本可以先檢查`A`是否已經設定過，來避免重複設定位元。

### 位元且運算子：讀取位元的方法

`&`是位元且運算子。
`&`運算子的結果，會在左、右運算元都設有位元的每個位置上得到`1`。
所以，`0011 & 0001`的結果會是`0001`。
我們可以在下面的範例中看到實際運作。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### 位元互斥或運算子：翻轉位元的方法

`^`是位元互斥或運算子。
有_含或_運算子，就表示也存在行為不同的_互斥或_運算子。
`^`運算子的結果，會在左、右運算元中_只有一個_設有位元的每個位置上得到`1`。
所以，`0001 ^ 0011`的結果會是`0010`。
最右邊的位元不會被設定，因為_兩個_運算元在最右邊的位置都有`1`。
互斥或運算有時寫成 XOR。
如果把某個值做互斥或運算後的結果，再做一次互斥或運算，就會得到原來的值。
這可以用來做非常簡單的加密，用同一把金鑰同時加密與解密資料。
例如

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## 位元欄位

我們已經看到，打包進簡單資料型態的位元可以依位置來存取。
打包進`struct`的位元可以依名稱來存取。
這樣的資料型態稱為`bit field`。
`bit fields`的一個使用情境，是需要一組開/關旗標，並且希望盡量減少記憶體用量時。

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;`這樣的語法，會在置於 struct 內的一個`unsigned int`裡建立一個`1`位元的欄位。
除了`unsigned int`，也可以使用`signed int`；或者從 C99 以後，也可以使用`bool`型別。
含有位元欄位的 struct 也可以包含其他資料型態的欄位，例如上面範例中的`number_of_lights`。
