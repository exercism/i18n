# 測試

每個練習都會附上一組單元測試，以及建置和執行測試所需的一切。
實作則由你來負責。

## 執行測試

在練習資料夾中開啟終端機，然後執行：

```
make
```

這會編譯你的實作和測試，然後執行測試。
每次修改實作後，都再執行一次。

如果你有 [Exercism CLI](https://exercism.org/docs/using/solving-exercises/working-locally)，也可以改用這個指令，它同樣會執行`make`：

```
exercism test
```

想移除建置產生的檔案，請執行`make clean`。

### 沒有 make 的情況

如果你沒有`make`（例如在 Windows 上），也可以直接編譯並執行測試。
以練習「Bob」為例：

```
gfortran TesterMain.f90 bob.f90 bob_test.f90 -o run_tests
```

接著在 Linux 或 macOS 上執行測試：

```
./run_tests
```

或在 Windows 上：

```
.\run_tests
```

## 完成一個練習

每個練習的檔案都以練習名稱命名。
以練習「Bob」為例：

| 檔案             | 內容                                                              |
| ---------------- | ----------------------------------------------------------------- |
| `bob.f90`        | 實作的雛形，等著你來完成                                          |
| `bob_test.f90`   | 測試                                                              |
| `TesterMain.f90` | 測試函式庫                                                        |
| `Makefile`       | 給`make`的指示                                                    |
| `CMakeLists.txt` | [CMake](#using-cmake-instead) 的設定，這是選用的                  |

你只需要修改實作檔案。

完成每個練習的流程，就是重複下列步驟，直到所有測試都通過：

- 修正所有編譯錯誤，然後執行測試，看看哪些測試失敗。
- 只實作到足以讓下一個失敗的測試通過。
- 重構你的實作，提升可讀性、減少重複等。
- 再次執行測試，然後繼續處理下一個失敗的測試。

每個失敗的測試都會印出一則訊息，最後再附上摘要。
如果有任何測試失敗，`make`會以錯誤結束。

每個測試都會先有一段描述該測試的註解，接著才是以`call assert_equal`開頭的實際測試，例如

```
  ! Test 16: non-letters with question
  call assert_equal("Sure.", hey(":) ?"), "non-letters with question")
```

想停用某個測試，只要用`'!'`把它註解掉就行了，例如

```
  ! Test 16: non-letters with question
  ! call assert_equal("Sure.", hey(":) ?"), "non-letters with question")
```

## 改用 CMake

你不需要 CMake，但如果你使用 Visual Studio、Xcode 這類 IDE，或使用 GFortran 以外的編譯器，它可能很有用。

練習資料夾必須保留原本的名稱，因為 CMake 會用它來尋找原始檔。
從練習資料夾開始：

```
mkdir build
cd build
cmake ..
cmake --build .
ctest -V
```

修改實作後，只需要再執行最後兩個指令。

**注意：**請一律在另一個資料夾（例如`build`）中執行`cmake`。
在練習資料夾中執行`cmake .`，會覆蓋練習隨附的`Makefile`。

CMake 會為你的系統選擇合適的產生器。
想改用其他產生器，請使用`-G`選項，例如`cmake -G Xcode ..`。
執行`cmake --help`可以列出你能使用的產生器。
搭配 Visual Studio 或 Xcode 時，請用`ctest -V -C Debug`執行測試。

如果你的練習資料夾裡沒有`Makefile`，代表它是在這些檔案加入練習之前下載的。
你仍然可以使用 CMake。
