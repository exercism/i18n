## GNU awk 與任意精度運算

預設情況下，`awk` 裡的數字是以雙精度浮點數表示的。這提供了 53 位元的精確度（請參閱手冊中的 [Table 16.3][table-16.3]）。很遺憾，這不足以完成這道練習（劇透警告：其中一個測試需要 63 位元的精確度）。

「精確度不足」看起來像這樣：
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

如果相關的函式庫已經編譯進 `awk` 執行檔，GNU `awk` 就有能力使用任意精度的數字。檢查你的 awk 版本，看看有沒有「GNU MPFR」：
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

如果有的話，用 `-M` 選項啟用這項能力：
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

那如果我的 `awk` 沒有 `-M` 呢？你得呼叫外部程式來做任意精度運算，例如 `bc`。做法範例請參閱 [Using getline into a Variable from a Pipe][getline-pipe] 一節。
