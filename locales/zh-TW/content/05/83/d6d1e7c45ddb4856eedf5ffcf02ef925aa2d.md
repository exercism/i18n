# 簡介

抽象語法樹（AST），也稱為引述運算式，是一種把程式碼表示成資料的方式。

AST 中的每個節點都是一個包含三個元素的元組。

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

第一個元素是原子，代表運算。第二個元素是關鍵字陣列，也就是中繼資料。第三個元素是引數陣列，裡面包含其他節點。像整數、原子和字串這類的字面值，在 AST 中會以本身表示，而不是用三個元素的元組。

## 把程式碼轉成 AST

把 Elixir 程式碼轉成 AST，以及把 AST 轉回程式碼，都是標準函式庫的一部分。處理 AST 的函式可以在 `Code`模組（例如把含有程式碼的字串轉成 AST）和 `Macro`模組（例如走訪 AST，或把它轉成字串）裡找到。

請注意，標準函式庫中所有函式都用「quoted」這個名稱來表示 AST（為引述運算式的簡稱）。

把程式碼轉成 AST 的特殊形式叫做 `quote`。它接受一個程式區塊，並回傳它的 AST。

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

## 使用情境

把程式碼表示成 AST 的能力，是 Elixir 元程式設計的核心。巨集是一種寫出會產生 Elixir 程式碼的 Elixir 程式碼的方式，它的運作方式就是回傳 AST 作為輸出。

AST 的另一個使用情境是靜態程式碼分析，例如 Exercism 自己的工具 Analyzer，你可能已經知道它就是那個會在你的解法上留下評論的小機器人。
