# 提示

## 一般

- 若想在函式參數中接收多個引數，可以用`*arguments`運算子把它們打包成**陣列**，或針對以關鍵字為基礎的引數使用`**keyword_arguments`。
- 如要打包或解開，請使用 splat 運算子（`*` 或 `**`）。

## 1. 建立所有車廂的清單

- 函式參數中的多個引數可以用`*arguments`運算子打包。

## 2. 修正車廂清單

- 使用 splat 運算子（`*`）解開，可以取出**陣列**的前兩個元素，同時保持其餘部分不變。
- 如要將另一個**陣列**加入現有的**陣列**，你可以用 splat 運算子（`*`）把**陣列**「展開」。

## 3. 新增缺少的停靠站

- 將`**keyword_arguments`用作方法引數，就能傳入任意數量的關鍵字引數。
- 將`**<hash>`用作引數，會把`Hash`解開成關鍵字引數。
- 你也可以把關鍵字引數放進`{}`裡，這是另一種建立`Hash`的方式。
- 如要從`Hash`取出值，可以使用`Hash#values`方法。

## 4. 擴充路線資訊

- 將`**{some_hash: value}`用作引數，會把`Hash`解開成關鍵字引數。
