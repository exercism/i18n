# 關於

常數是在編譯期設定的值，無法重新賦值。
使用`const`關鍵字來宣告單一常數：

```go
const greeting = "hello"
```

多個常數可以在同一個區塊中宣告。
在區塊中，沒有明確設定值的常數會重複前一個運算式：

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

常數通常宣告在套件層級，不過也可以在函式內宣告。

## 有型別與無型別的常數

宣告常數時若未指定型別，它就是無型別的。
無型別常數沒有固定的型別；它的值決定了它能與哪些型別相容。
只要底層的值相容，編譯器就會在每次使用時將它轉換成所需的型別：

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

有型別的常數會在宣告時固定型別：

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## 哪些東西可以當作常數

常數只能存放布林、數字、字串和 rune。
因為這些值是在編譯期設定的，所以函式呼叫的結果不能用在常數上。

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

在常數區塊中，`iota`代表常數在區塊裡的位置：

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

第一個之後的每個常數都會沿用相同的運算式，而`iota`每次遞增一。

`iota`也能用在運算式中。

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
