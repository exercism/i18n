# 簡介

在 Clojure 中，`vector` 是一種有序、可索引、不可變的集合，可包含零個或多個值。這表示向量一旦建立之後就無法修改。用來操作向量的函式會回傳新的向量，而原本的向量保持不變。向量中的值可以是不同的型別。向量可以這樣定義：

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

我們可以用索引從向量中取出元素。Clojure 向量的索引從零開始，也就是說，第一個元素的索引一律是零：

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

原本的向量並不會改變：

```clojure
numbers
;;=> [2 3 5]
```

若要記住更新後的值，我們需要把它傳遞下去，或是將它存進 var 中：

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
