# 簡介

`for` 迴圈是最常用來重複執行某些邏輯的敘述之一。在 JavaScript 中，它由 `for` 關鍵字、以小括號包住的_標頭_，以及以大括號包住、包含迴圈_主體_的程式區塊組成。

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

初始化通常會設定一個計數器變數，條件會檢查迴圈應該繼續還是停止，而步進則會在每次重複結束時遞增計數器。標頭的每個部分以分號分隔。

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

定義步進通常會使用 JavaScript 的遞增或遞減運算子，如上例所示。這些運算子會直接修改變數本身。`++`會將數字加一，`--`會將數字減一。

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
