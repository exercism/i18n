# 說明

你正在開發一款備受好評的新遊戲 **Wings Quest**。
在遊戲中，你是一隻四處移動並收集種子的鳥。
玩家撿起所有種子就能獲勝。
如果玩家碰到老鷹，就會失去所有種子並輸掉遊戲。
這條規則有一個例外：玩家可以擁有作用中的強化道具，讓自己飛得比其他鳥更高。

你的目標是撰寫一些遊戲會用到的規則。

## 1. 定義鳥是否獲得額外分數

在遊戲中，如果鳥在擁有強化道具時碰到老鷹，就會獲得額外分數。

定義函式`bonusPoints(powerUpActive:touchingEagle:)`，它接受兩個引數：`powerUpActive`表示鳥是否有作用中的強化道具，`touchingEagle`表示鳥是否正碰到老鷹。
只有當鳥有作用中的強化道具且正碰到老鷹時，這個函式才應該回傳`true`，否則回傳`false`。

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. 定義鳥是否得分

在遊戲中，玩家撿起種子或強化道具時會得分。

定義函式`score(touchingPowerUp:touchingSeed:)`，它接受兩個引數：`touchingPowerUp`表示鳥是否正碰到強化道具，`touchingSeed`表示鳥是否正碰到種子。
如果鳥正碰到強化道具或種子，這個函式應該回傳`true`，否則回傳`false`。

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. 定義鳥是否落敗

定義函式`lose(powerUpActive:touchingEagle:)`，它接受兩個引數：`powerUpActive`表示鳥是否有作用中的強化道具，`touchingEagle`表示鳥是否正碰到老鷹。
如果角色正碰到老鷹且沒有作用中的強化道具，這個函式應該回傳`true`，否則回傳`false`。

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. 定義鳥是否獲勝

定義函式`win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`，它接受以下引數：

- `hasPickedUpAllSeeds`表示鳥是否已撿起所有種子。
- `powerUpActive`表示鳥是否有作用中的強化道具。
- `touchingEagle`表示鳥是否正碰到老鷹。

如果鳥已收集所有種子，且根據第 3 部分定義的引數判斷並未落敗，這個函式應該回傳`true`，否則回傳`false`。

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
