# 不要使用 rescue

不要用例外來做流程控制。
試著不要用`rescue`來解這道練習。

如果你用到的標準函式庫函式名稱以`!`結尾（會引發錯誤），就找找看有沒有不含`!`的等效函式（通常會回傳`{:ok, result}`或`{:error, message}`）。

注意：如果你在自己的解法上看到這則自動評論，其他自動評論可能不準確。
請先修正這個問題！

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
