# 說明

在這個練習中，你會寫一些程式碼，幫助一位自由工作者與專案經理溝通。你的任務是提供幾個工具，用來快速計算每日費率和每月費率，也可以套用指定的折扣。

我們先在自由工作者和專案經理之間訂下幾條規則：

- 每日費率是時薪的 8 倍。
- 一個月有 22 個可計費天數。

有時候，自由工作者會想在每日費率上套用折扣（例如給最忠誠的客戶，或是非營利客戶）。

折扣會以代表百分比的小數表示，例如`25.0`（25%）。

~~~~exercism/note
以下是浮點數指令的後綴：

| 後綴 | 運算元大小 |
|--------|--------------|
| `ss`   | 32 位元       |
| `sd`   | 64 位元       |

以下是這個概念中提到的部分指令：

| 指令       | 說明                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | 將 b 複製到 a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | 將整數 b 轉換成浮點數 a                                |
| roundss/roundsd a, b, c | 根據 c 將浮點數 b 取整，並存到 a                       |
| cvtss2si/cvtsd2si a, b  | 將浮點數 b 轉換成整數 a                                |
| comiss/comisd a, b      | 比較 a 和 b，若為 `NaN` 則產生例外                     |
| ucomiss/ucomisd a, b    | 比較 a 和 b，若為 `NaN` 則設定 `PF`                    |

以下是`roundss`和`roundsd`中的取整控制編號：

| 編號 | 模式         |
|:-------|:-------------|
| 0      | 最接近      |
| 1      | 向下取整 |
| 2      | 向上取整    |
| 3      | 截斷     |
~~~~

## 1. 根據時薪計算每日費率

實作一個名為`daily_rate`的函式，根據參數時薪計算每日費率，時薪為 64 位元浮點數。
合約定義一天有 8 個可計費小時。

```c
daily_rate(60)
// => 480.0
```

回傳的每日費率應該是 64 位元浮點數。

## 2. 計算折扣後的價格

實作一個函式`apply_discount`，計算折扣後的價格。
它應該接受兩個參數：原始價格和折扣百分比，兩者都是 64 位元浮點數。

```c
apply_discount(150.0, 10.0)
// => 135.0
```

回傳值一律應該是 64 位元浮點數。

## 3. 根據時薪和折扣計算每月費率

實作一個`monthly_rate`函式，計算折扣後的每月費率。
它接受兩個參數：時薪和折扣百分比，兩者都是 64 位元浮點數。

```c
monthly_rate(77.0, 10.5)
// => 12130
```

回傳的每月費率應該向上取整（取天花板值），成為最接近的 64 位元整數。

## 4. 根據預算、時薪和折扣計算完整工作天數

實作一個函式`days_in_budget`，參數如下：

1. 預算，64 位元無號整數。
2. 時薪，64 位元浮點數。
3. 折扣百分比，64 位元浮點數。

這個函式應該回傳預算能負擔的完整工作天數。

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

回傳的天數應該向下取整（取地板值），成為最接近的 32 位元整數。
