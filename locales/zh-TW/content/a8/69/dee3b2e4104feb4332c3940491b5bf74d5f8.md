# 簡介

Behaviour 讓我們能在一個 _behaviour 模組_ 中定義介面（一組函式與巨集），之後再由不同的 _回呼模組_ 實作。因為共用同一組介面，這些回呼模組可以互換使用。

~~~~exercism/note
注意，「behaviours」用的是英式拼法。
~~~~

## 定義 behaviour

要定義 behaviour，得先建立一個新模組，並指定一組構成該介面的函式。每個函式都必須用 `@callback` 模組屬性來定義，語法和[函式型別規格][concept-typespecs]（`@spec`）完全相同。我們需要指定函式名稱、引數型別的清單，以及所有可能的回傳型別。

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer
end
```

## 實作 behaviour

要把現有的 behaviour 加進我們的模組（也就是建立回呼模組），使用的是 `@behaviour` 模組屬性，它的值就是我們要加入的 behaviour 模組名稱。

接著，我們必須定義該 behaviour 模組要求的所有函式（回呼）。如果我們要實作別人寫的 behaviour，例如 Elixir 內建的 `Access` 或 `GenServer` behaviour，可以在 [hexdocs.pm][hexdocs] 的文件裡找到該 behaviour 所有回呼的清單。

回呼模組並不是只能實作自己 behaviour 裡的函式，同一個模組也可以實作多個 behaviour。

為了標明哪個函式來自哪個 behaviour，我們應該在每個函式前面加上模組屬性 `@impl`，它的值是定義這個回呼的 behaviour 模組名稱。

```elixir
defmodule BookCollection do
  @behaviour Countable

  defstruct [:list, :owner]

  @impl Countable
  def count(collection) do
    Enum.count(collection.list)
  end

  def mark_as_read(collection, book) do
    # other function unrelated to the Countable behaviour
  end
end
```

## 回呼的預設實作

定義 behaviour 時，可以為回呼提供預設實作。這個實作應該定義在 `__using__/1` 巨集的引用表達式中。為了讓使用這個 behaviour 模組的人能覆寫預設實作，請在函式實作之後呼叫 `defoverridable/1` 巨集，它接受一個關鍵字清單，以函式名稱為鍵、函式元數為值。

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer

  defmacro __using__(_) do
    quote do
      @behaviour Countable
      def count(collection), do: Enum.count(collection)
      defoverridable count: 1
    end
  end
end
```

請注意，在 `__using__/1` 裡定義函式，除了用來定義回呼的預設實作之外，其他用途都不建議；不過你隨時可以把函式定義在另一個模組，再於 `__using__/1` 巨集中匯入它們。
