# 簡介

## 介面是一組方法

最簡單的形式中，一個**介面型別**就是一組方法簽章。
以下是介面定義的範例，其中包含兩個方法`Add`和`Value`：

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

像`increment`這樣的參數名稱可以從介面定義中省略，但保留它們通常能提升可讀性。

Go 的介面名稱不含`Interface`或`I`這個字。
它們反而通常以`er`結尾，例如`Reader`、`Stringer`。

## 實作介面

任何定義了介面的方法的型別，都會自動隱式地「實作」該介面。
Go 中沒有`implements`這個關鍵字。

以下的型別實作了我們前面看到的`Counter`介面。

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

就實作介面而言，方法使用值接收者或指標接收者並沒有差別。
（如果對這些不確定，可以回頭看看[方法的概念][concept-methods]。）

> 介面型別的值可以存放任何實作了這些方法的值。((Go Tour: Interfaces)[go-tour-interfaces])

這表示`Stats`現在可以用在所有需要`Counter`介面的地方。

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

由於介面是隱式實作的，一個型別可以輕鬆實作多個介面。
它只需要定義好所有必要的方法就夠了。

## 空介面

Go 中有一種非常特別的介面型別，也就是包含零個方法的**空介面**。
空介面寫成這樣：`interface{}`。
在 Go 1.18 或更高的版本中，也可以使用`any`。
它被定義為別名。

由於空介面沒有任何方法，每個型別都會隱式地實作它。
這在定義能通用地接受任何值的函式時很有幫助。
在這種情況下，函式參數會使用空介面的型別。
