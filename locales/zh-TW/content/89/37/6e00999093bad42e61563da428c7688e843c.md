# 關於

Swift 中的[閉包][closures]是獨立的程式區塊，可以接收參數來觸發運算並回傳值
閉包也會從自身的環境中捕獲值，並在運算中使用它們。
由於閉包是獨立的，它們可以像其他值一樣在程式中傳遞，也可以指定給常數和變數。

閉包聽起來可能很像 Swift 的函式；確實如此，而且這是有原因的。
Swift 中的函式是閉包的特例，它們必須有名稱，而且定義時使用的語法略有不同。

雖然 Swift 中的函式在技術上算是閉包，但當人們在 Swift 裡提到「closures」時，指的其實是[閉包運算式][closure-expressions]。
閉包運算式的寫法是一串參數列表，接著是回傳型別和關鍵字`in`，然後是閉包的主體，全部包在一對大括號裡：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

這定義了一個型別為`(Double, Double) -> Double`的閉包運算式，執行方式類似於同型別的函式，只要將它套用到適當型別的參數上：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

由於每次想執行閉包時都寫出完整的閉包運算式並不太方便，閉包可以像 Swift 中其他任何值一樣被指定給名稱。
之後只要把這個名稱套用到參數上，就能呼叫它：

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

如上面所見，閉包和一般函式一樣，如果主體只有單一運算式，可以省略`return`關鍵字。

閉包最常和高階函式一起使用，不是作為參數傳入，就是作為結果回傳：

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
