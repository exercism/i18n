# 簡介

在 JavaScript 中，陣列是一種像清單的結構，長度不固定，可以存放任何型別的原始值或物件，甚至可以混用不同型別。

建立陣列時，把元素放在方括號 `[]` 之間。
要從陣列讀取資料時，把索引放在識別字後面的方括號 `[]` 中。
陣列的索引從 0 開始。

例如：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

想取得陣列中有多少個元素，可以使用`length`屬性：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

要改變陣列中的某個元素，就在對應的索引指定一個值：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## 方法

每個 Array 物件都有一些可用的[方法][array_methods]，其中一部分可以用來在陣列中新增或移除元素。

### push

> `push()` 方法會把一個或多個元素加到陣列末端，並回傳陣列的新長度。[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> `pop()` 方法會移除陣列的最後一個元素，並回傳該元素。
> 這個方法會改變陣列的長度。[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> `shift()` 方法會移除陣列的第一個元素，並回傳被移除的那個元素。
> 這個方法會改變陣列的長度。[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> unshift() 方法會把一個或多個元素加到陣列的開頭，並回傳陣列的新長度。[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> splice() 方法會就地移除、取代現有元素，或加入新元素，藉此改變陣列的內容。這個方法會回傳一個包含被刪除元素的陣列。[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
