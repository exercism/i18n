# 測試

因為 OCaml 是編譯式語言，你必須先編譯你提交的內容和測試程式碼，才能執行測試。
我們使用 [`dune`](https://dune.build/) 來建置。
每個資料夾都有一個 dune 檔案，說明該如何建置，另外還有一個 Makefile，把工作交給 dune。

要編譯並執行測試，只要在練習資料夾中輸入：

```bash
make
```
