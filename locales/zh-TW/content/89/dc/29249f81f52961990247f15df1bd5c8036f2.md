# 字串

字串是一連串的字元，用引號包起來。
單引號和雙引號都支援。

```php
<?php

$where = "Spain";
$what = 'rain';
```

## 字串變數展開

在雙引號字串中，如果變數在作用域內被引用，它的值會被插入字串中。

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## 字元編碼支援

長久以來，PHP 的字串函式只支援 ASCII 字元，不支援現代的 Unicode 編碼。
ASCII 字元各佔 1 位元組，而 Unicode 字元的長度可能是 1 到 4 位元組。
如果需要安全地操作 Unicode 字串，請參考這些歷史函式的[多位元組版本][multi-byte-fns]。

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
