# 簡介

## 模組

到目前為止，你看過的練習都使用了類別。
有時我們不需要承擔建立帶有狀態的物件所需的額外開銷，因此改用`module`。

模組和類別非常相似（實際上，在物件階層中，`Module`是`Class`的父類別），主要差別在於我們用的是類別方法，而不是實體方法。
類別方法以`self.`開頭，並直接在模組上呼叫。

例如：

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## 迴圈

在 Ruby 中有幾種寫迴圈的方式，但因為我們一般傾向使用列舉而非迴圈，所以最常見的迴圈或許就是`while`迴圈：

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

你也可以使用和它成對的`until`：

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
