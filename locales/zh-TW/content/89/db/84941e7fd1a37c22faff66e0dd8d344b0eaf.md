# 說明

請參閱 PHP 的[型別宣告][type-declaration]文件。

## 1. 為 Address 類別標註型別

- 在 PHP 中，基本型別的型別標註和它的名稱相同，請參閱[型別簡介][type-intro]

## 2. 標註以空白值填寫表單時所用的型別

- 在 PHP 中，基本型別的型別標註和它的名稱相同，請參閱[型別簡介][type-intro]

## 3. 將值拆成個別字元時，標註型別

- 在 PHP 中，基本型別的型別標註和它的名稱相同，請參閱[型別簡介][type-intro]

## 4. 檢查值是否能填入表單時，標註型別

- 在 PHP 中，基本型別的型別標註和它的名稱相同，請參閱[型別簡介][type-intro]

## 5. 在表單中格式化地址時，標註型別

- 在 PHP 中，類別的型別宣告可以使用`object`或特定的類別名稱作為宣告的型別。
