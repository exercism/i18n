# 提示

## 1. 取得句子的第一個字母

- 回頭看看介紹，了解如何取得字串中的某個字母。
- 索引從 0 開始計算。

## 2. 將單字的第一個字母改成大寫

- 首字母大寫指的是單字開頭是一個_大寫_字母，後面接著_小寫_字母。
- 所以首先要取出第一個字母，並將它[轉成大寫][mdn-to-upper-case]。
- 接著要找出字串剩下的部分（第一個字元以外的所有內容）。[slice 方法][mdn-slice]可以幫上忙。
- 將字串[轉成小寫][mdn-to-lower-case]之後，就可以用加法運算子`+`把第一個字母和剩下的部分合併起來。

## 3. 取得句子的最後一個字母

- 回頭看看介紹，了解如何取得字串中的某個字母。
- 最後一個字母的索引可以從字串的`.length`屬性，加上索引從 0 開始計算這點推導出來。
- 字串有 [trim][mdn-trim] 方法，可以移除開頭和結尾的空白。

## 4. 有禮貌

- 重複使用現有的函式，把這個單字的第一個字母改成大寫。
- 可以用加法運算子`+`來串接兩個字串。
