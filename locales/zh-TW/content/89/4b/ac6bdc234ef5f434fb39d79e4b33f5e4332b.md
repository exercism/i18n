# 關於

*不相交集*（併查集）會把一群值分成互不重疊的群組，並且能快速回答一個問題：這兩個值是否在同一組？它位於[`disjoint-sets`][disjoint-sets]詞彙庫中。

`<disjoint-set>`會建立一個空的結構。值，也就是*元素*，可以用`add-atom`加入，或用`add-atoms`批次加入；每個元素一開始都自成一組：

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate`會合併包含兩個元素的群組。合併具有遞移性：一旦`a`與`b`合併，`b`又與`c`合併，三個元素就同屬一組。

```
equate ( atom1 atom2 disjoint-set -- )
```

每個群組都由一個正規成員來識別，也就是它的*代表*。`representative`會回傳這個代表，而兩個元素屬於同一組，若且唯若它們的代表相同。`equiv?`則直接做這項測試：

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

哪個元素會被選為群組的代表屬於實作細節：它可以是群組裡的任何成員，而且會隨著群組合併而改變。千萬不要依賴某個特定元素一定是代表，只要確定同一組的兩個元素會有相同的代表就好。

`disjoint-set-members`會回傳所有已加入的元素。

這個結構是*可變的*：`equate`和`add-atom`會直接修改這個不相交集，而不是回傳一個新的。實作採用依秩合併與路徑壓縮，所以連續呼叫`equate`和`representative`時，每次操作實際上都是常數時間。
