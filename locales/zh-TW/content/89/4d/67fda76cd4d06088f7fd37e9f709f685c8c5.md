# 提示

## 一般

- 透鏡在 Roc 裡不太常用，因為記錄更新語法已經能漂亮地涵蓋大多數使用情境。
  例如，看看這個巢狀記錄：

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  現在來幫 Bob 剪個頭髮：

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  完全不需要透鏡！

- 話雖如此，雖然透鏡在 Roc 裡很少見，但在 Haskell、Scala 等其他語言中卻很常見，所以你或許會好奇要怎麼在 Roc 裡實作透鏡。
  這也是練習一些進階 Roc 特色的好方法，例如參數化型別，以及包含函式的記錄。
  沒錯，以下是在 Roc 裡表示透鏡的一種方式：

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  這是參數化型別：`whole` 和 `part` 可以是任何型別。
  `whole` 通常是記錄，而 `part` 可以是任何欄位型別。
  `get` 欄位包含一個函式，會回傳指定 `whole` 的某個 `part`；而 `set` 欄位包含一個函式，會回傳指定 `whole` 的副本，只是把某個 `part` 換成指定的 `part`。

  例如，這裡有一個可以取得或設定某人頭髮的透鏡：

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  我們可以用這個透鏡把焦點放在 Bob 的頭髮上，像這樣：

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  也可以像這樣改變他的頭髮：

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- 注意：`hair_lens.set` 外面的括號是必要的，少了它們，Roc 會到 `hair_lens` 的型別裡尋找名為 `set` 的函式。

- 當你開始組合透鏡時，它們就變得特別有用，讓你能取得和設定深層巢狀的部分。
  可以透過實作像這樣的函式來達成：

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  實作這個函式之後，你就能用它建立像這樣的頭髮長度透鏡：

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  現在你可以再幫 Bob 剪一次頭髮：

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- 你可能也會想實作一個函式，讓你對巢狀的部分套用任何轉換：

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  實作之後，你就可以像這樣使用 `over`：

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- 我們建議你先用 Roc 的記錄更新語法通過測試，再試著改用透鏡吧。
