# 關於

## 術語

你已經在幾個概念裡用過也寫過 C++ 函式。
現在該來點技術性的內容了。
下面的程式碼片段列出了最常見的術語，方便你隨時查閱。
由於 C++ 會忽略空白，這裡調整了格式，把每個元素各放在一行。

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
宣告就像是給編譯器的一則備註，說明有個函式具有那樣的名稱、回傳型別和參數列表。
如果缺少定義，程式就無法運作。
宣告是選用的，只有在你於定義之前就使用該函式時才需要。
宣告可以解決循環參考之類的問題，也可以用來把介面與實作分離。
~~~~

## `const` 修飾詞

有時候你會想確保某些值在初始化之後就不能再被修改。
C++ 使用`const`關鍵字作為常數的修飾詞。

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
你經常會看到常數以_UPPER_SNAKE_CASE_的形式書寫。
如果沒有其他慣例，建議把這種大小寫形式保留給巨集使用。
~~~~

如果你在設定之後試圖修改常數變數，程式就無法編譯。
這有助於避免非預期的修改，同時也為編譯器開啟了最佳化的可能性。
對人來說，如果你知道某些部分不會受到影響，也更容易推斷程式碼的行為。

你也可以把`const`當作函式參數的修飾詞。

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

當你把`const`參考傳給函式時，就能確定它不會被修改。
你可能經常會看到對複製成本較高的物件（例如較長的字串）使用`const`參考。
`const`修飾詞的第三種用途，是不會改變類別實例的成員函式。

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return "";}
        return response;
    }
    private:
    string response{};
};
```

`Stubborn`的成員函式`answer`使用`const string&`參考作為參數。
這樣可以避免從傳入函式的原始物件複製一份。

## 函式重載

只要參數列表不同，多個函式就可以同名。
這叫做函式重載，通常用於這些函式執行非常相似的任務時。

不含回傳型別的函式標頭，就是這個函式的__型別簽章__。
型別簽章有所改變，就會產生一個新的函式。

`play_sound`這個例子有六種不同的重載，以因應不同的情境：

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
型別簽章是由函式的名稱、參數的數量、它們的型別，以及它們的修飾詞所定義（但不包含它們的名稱）。
回傳型別明確地不屬於型別簽章的一部分，如果你有兩個只有回傳型別不同的函式，就會出現編譯錯誤。
編譯器會抱怨，因為它不清楚該用這兩個之中的哪一個。
~~~~

## 預設引數

有些函式可能變得非常冗長，而且它的許多呼叫可能對大多數參數都使用相同的值。
這些呼叫中的重複，可以用預設引數來避免。

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

由於函式宣告通常會在定義之前被讀到，因此它是設定預設引數較好的地方。
如果某個參數有預設值宣告，它右邊的所有參數也都需要有預設值宣告。
有時候，可以把複雜的函式重載重構成使用預設引數的較少函式，以提升可維護性。
