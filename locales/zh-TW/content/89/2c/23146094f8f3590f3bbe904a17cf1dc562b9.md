# 指令補充

## Tcl 的 `apply` 指令

測試案例看起來可能令人困惑。
你需要實作的是：

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

為什麼最後那個引數有這麼多的大括號？

回想一下，`proc` 指令的定義是：

```tcl
proc procName argList body
```

Tcl 有一個 `apply` 指令：

```tcl
apply func ?arg1 arg2 ...?
```

這個「func」是一個兩元素的串列 `{argList body}`，本質上就是一個匿名 proc（或「lambda」）。
`apply` 指令會呼叫那個匿名 proc，並把它需要的引數傳進去。

舉例來說，以下這些寫法是等價的：

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

使用 `apply` 可以更輕鬆地傳遞程式碼區塊。

參考：[`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm)、[`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm)。
