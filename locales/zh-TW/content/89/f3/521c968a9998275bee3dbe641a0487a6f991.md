# 關於條件式

## 比較運算子

[比較運算子][operators]和許多其他語言相似，只是多了幾項延伸。

判斷是否相等時，用的是`==`（等於）和`!=`（不等於）這兩個運算子。

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

此外，`===`和`!==`運算子則是用來測試[「參照相等」][referential-equality]：只有在`a`和`b`指向同一個物件時，`a === b`才會成立。
這在之後的課程大綱中會更容易理解。

大於和小於運算子也遵循一般慣例。

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## 使用`if`分支

這是[`if`運算式][if-else]的完整形式：

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 每個條件都必須用括號`()`包住。
- 條件的結果必須是布林值`true`或`false`。
  Kotlin 沒有某些語言中「truthy」和「falsy」的概念。
- 如果只有單一運算式，大括號`{}`可以省略。
- `else if`和`else`都是選用的，而且可以有多個`else if`區塊。

`if`運算式也可以用來「選擇」一個值：

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 有其他選擇嗎？

基於刻意的設計選擇，Kotlin 並_沒有_Java 中的三元運算子`? :`。
反而偏好使用`if ... else`的精簡形式：

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

和 Ruby 不同，精簡的`if ... else`形式*一定*需要`else`，因此無法當作防護敘述使用：

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

請注意，在 Kotlin 中，`if`是一種會回傳值的[_運算式_][expression]。
它不像 Java 那樣是一種[_敘述_][statement]。

之後在介紹其他概念時，我們會看到 Kotlin 有個強大的[`when`][when]構造，用來以模式比對取代一長串的`else if`子句。
