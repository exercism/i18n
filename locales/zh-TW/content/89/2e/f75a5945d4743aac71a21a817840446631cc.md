# 關於

在 C# 中，元組是一種用來組織資料的資料結構，能存放兩個以上、型別不拘的欄位。

元組通常是這樣建立的：在一對括號內放入兩個以上以逗號分隔的運算式。

```csharp
string boast = "All you need to know";
bool success = !string.IsNullOrWhiteSpace(boast);
(bool, int, string) tripple = (success, 42, boast);
```

元組和任何其他運算式一樣，可以有各式各樣的用途：[指定][tuple-assignment]、初始化欄位或變數、作為方法的[回傳值][tuple-return-values]，或當成參數傳遞。它們也能進行[相等性][tuple-equality]測試。元組的相等性在`pattern-matching-tuples`練習裡有完整的示範，不過為了完整起見，下面的程式碼也提供了一個例子。

欄位是以點號語法擷取的。預設情況下，第一個欄位是`Item1`，第二個是`Item2`，依此類推。非預設的名稱會在底下的*命名*一節中討論。

元組可以當作泛型參數使用，例如`IList<(bool, string)>`。

此外，元組也支援「解構」（下文會討論），並可用於模式比對，這部分會在之後的練習中介紹。

```csharp
// initialization
(int, int, int) vertices = (90, 45, 45);

// assignment
vertices = (60, 60, 60);

//  return value
(bool, int) GetSameOrBigger(int num1, int num2)
{
    return (num1 == num2, num1 > num2 ? num1 : num2);
}

// method argument
int Add((int, int) operands)
{
    return operands.Item1 + operands.Item2;
}

// equality testing
var estimateA = (42, 1729);
var estimateB = (2*3*7, 7*13*19);
bool result = estimateA == estimateB;
// => result == true
```

這篇[介紹][tuples]說明如何定義與使用元組。

## 命名

欄位名稱`Item1`之類的寫法不容易閱讀。要為欄位命名有三種方式：a) 在型別宣告中，b) 在建立它的運算式中，c) 透過[元組投影初始設定式][tuple-projection-initializers]（這裡不示範）。

```csharp
// name items in declaration
(bool success, string message) results = (true, "well done!");
bool mySuccess = results.success;
string myMessaage = results.message;

// name items in creating expression
var results2 = (success: true, message: "well done!");
bool mySuccess2 = results2.success;
string myMessaage2 = results2.message;
```

別在命名機制上想得太過花俏，它其實只是語法糖。例如，當你把另一個元組指定給某個元組時，並不能改變它的名稱。

## 解構

有時候，把一個元組的各個欄位指定給多個變數，並視情況初始化它們，會很方便。這個機制稱為[解構][tuple-deconstruction]。（它也能套用在你自己的物件上，請見[這裡][udt-deconstruction]。）

```csharp
var goodNumbers = (42, 3.142, 1729);
(int ultimateQuestion, var π, var ramanujan) = goodNumbers;
return ultimateQuestion;
// => 42
```

## 欄位指定

元組的各個欄位可以逐一指定。不過，由於 C# 有朝向不可變性的趨勢，這種用法並不常見。元組經常被當成不可變來使用，但當然它們並非不可變。

```csharp
(int, string) tpl;
tpl.Item1 = 1;
tpl.Item2 = "bad";
tpl.Item2 = "even worse";
// => (1, "even worse";
```

## 背景

我們討論的元組不該與[`System.Tuple`][system-tuple]混為一談，後者大概只會出現在舊版的程式碼基底中。

談到`System.ValueTuple`，情況就稍微複雜一些。[`System.ValueTuple`][system-value-tuple]最後一個多載的[文件][system-value-tuple]指出：「實值元組型別提供支援 C# 中元組的執行階段實作。」這裡說的「實值元組型別」指的是`System.ValueTuple`的泛型多載；而「元組」指的則是這個練習所關注的東西。實際上，他們是在說`System.ValueTuple`只是元組的實作細節。對大多數人來說，多數時候這大概沒什麼好深究的。可惜的是，許多關於「元組」的文件，包括微軟自己的，都大量穿插著對`System.ValueTuple`的引用。這些引用大概可以略過不看。

## 其他用途與限制

模式比對是元組特別好用的用途之一，這會在之後的練習中介紹。

元組還有一些其他的小幅風格妙用：

- 多重指定（特別是在建構函式中），例如`(this.field1, this.field2) = (arg1, arg2);`
- 交換或重複利用值，例如`(a, b) = (b, a);`
- 在陣列中用來取代`struct`
- 當作字典的鍵，或當作集合的內容
- 用於 LINQ。（LINQ 會在之後的練習中介紹）

文件把元組描述為一種輕量的機制，而這正是成功運用它的關鍵。用元組取代類別或`struct`時，可能會導致欄位型別（甚至名稱）冗長地重複出現。這在把元組當作方法引數，或當作集合中的泛型引數時尤其明顯。

最好審慎使用多重指定和交換這類技巧。

除了相等與不相等之外，不支援其他的關聯運算。

請注意，元組是相對晚近才被引進這門語言（C# 7），所以如果你想使用它們，請確認你的程式碼基底使用的是[版本][language-version] 7 或之後的語言版本。
