# 簡介

一如[`Nothingness`][concept-nothingness]概念中所探討的，R 有各種方式來表示不存在的資料（`NULL`）、未知的資料（`NA`），或是數學上無效的資料（`NaN`、`Inf`）。
一般來說，R 會試著用這些值就地標示問題，並繼續執行，而不會拋出例外。

## `stop()`

有些問題太過根本，無法讓程式繼續執行。
這種情況下，請使用`stop(msg)`立刻中止程式、產生`Error`，並印出`msg`。

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

類似其他語言中的`assert`，這是`stop()`的便利包裝函式。
它的參數是任意數量、以逗號分隔的布林條件，只有當這些條件全為`TRUE`時，程式才會繼續執行。

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()`和`message()`

這些是對非致命狀況的回應，例如：

- 針對程式至少還能部分復原的問題提出警告。
- 在長時間執行的程式中，告知使用者目前的進度。

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

`suppressWarnings()`函式有時在 Exercism 上很好用，可以避免讓非預期的輸出混淆測試執行器。
