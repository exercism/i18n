# 說明

海佩利亞這個國家問題不少。尤其是通貨膨脹，已經完全失控。你被特地請來，接下中央銀行的一份合約。

## 1. 印出鈔票面額

為了簡化內部行政作業，中央銀行把每個面額拆成幾個部分：一個相對穩定的_基數_，以及一個_乘數_（所有面額共用同一個），可以每年、每週、甚至每天調整。

鈔票印出來時，上面的面額就是_基數_與_乘數_的乘積。

這套制度推行時，最小的鈔票面額就已經是 10,000,000。下表列出這套制度剛上路時的情況（前三種面額）。之後情況惡化了不少，不只乘數會變，基數也會變。

| 基數    | 乘數       | 面額         |
| ------- | ---------- | ------------ |
| 10,000  | 1,000      | 10,000,000   |
| 50,000  | 1,000      | 50,000,000   |
| 100,000 | 1,000      | 100,000,000  |
| ...     | 1,000      | ...          |

總結來說，這表示_面額_ = _基數_ \* _乘數_。

請實作`CentralBank.DisplayDenomination()`方法，它接收基數與乘數，並回傳兩者乘積（基數 \* 乘數）的字串。回傳的數字字串不應加上任何格式。

如果乘法運算造成溢位，則應回傳字串`"*** Too Big ***"`。

```csharp
CentralBank.DisplayDenomination(10000L, 1000L);
// => "10000000"
CentralBank.DisplayDenomination(long.MaxValue / 2, 10000L);
// => "*** Too Big ***"
```

## 2. 顯示海佩利亞的國內生產毛額

中央銀行內部記錄國內生產毛額時，採用同一套乘數做法。統計數據先以基數面額記錄，再用乘數放大。

請實作`CentralBank.DisplayGDP()`方法，它接收國內生產毛額的基數與目前的乘數，並以字串回傳計算結果。

若無法計算國內生產毛額，則回傳`"*** Too Big ***"`。

```csharp
CentralBank.DisplayGDP(555f, 10000f);
// => "5550000"
CentralBank.DisplayGDP(float.MaxValue / 2, 10000f);
// => "*** Too Big ***"
```

## 3. 顯示首席經濟學家的薪水

你在銀行的上司想確保發薪水時不會出任何問題。

請實作`CentralBank.DisplayChiefEconomistSalary()`方法，它接收以基數單位表示的薪水（如上所述）與一個乘數，並回傳包含乘積的字串。

若無法計算薪水，則回傳`"*** Much Too Big ***"`。

```csharp
CentralBank.DisplayChiefEconomistSalary(555000m, 10000m);
// => "5550000000"
CentralBank.DisplayChiefEconomistSalary(555000m, decimal.MaxValue / 2L);
// => "*** Much Too Big ***"
```
