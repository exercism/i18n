# 簡介

Gleam 可以執行在 Erlang 虛擬機器（BEAM）上，也可以執行在 JavaScript 執行環境上。還有許多其他語言同樣使用這些執行環境，而能夠從 Gleam 呼叫以這些語言撰寫的程式碼，往往十分實用。

Gleam 的*外部函式*功能，讓其他語言的函式可以匯入 Gleam 中並直接呼叫，不會帶來執行期的額外負擔。

如果你的 Gleam 專案執行在 Erlang 虛擬機器上，而你想呼叫 Erlang 的`lists`模組裡的`reverse`函式，只要在 Gleam 函式宣告前加上`@external`屬性就可以了，像這樣：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

接著就能像呼叫一般的 Gleam 函式那樣使用它：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

如果你試著為 JavaScript 執行環境編譯這段程式碼，會因為沒有對應的 JavaScript 實作而編譯失敗，並出現錯誤訊息。你可以像這樣為 JavaScript 執行環境指定另一份實作：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

你也可以撰寫一份 Gleam 實作，在目前的編譯目標沒有對應的外部實作時派上用場：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
