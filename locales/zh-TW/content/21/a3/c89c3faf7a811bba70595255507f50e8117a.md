# 字典

Cairo 中的字典是鍵值儲存結構，類似其他語言中的 map 或雜湊表。

不過，由於 Cairo 採用不可變的記憶體模型，字典有一些獨特的特性。

## 核心概念

`Felt252Dict<T>`型別在 Cairo 中提供了字典功能，以`felt252`作為鍵的型別，任何支援的型別`T`作為值的型別。

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## 重要特性

與其他語言的字典不同，Cairo 的字典有一些特殊性質：

1. 鍵必須是`felt252`值。
2. 所有鍵都隱含以零作為初始值。
3. 你不能刪除項目，只能更新值。
4. 值必須實作`Felt252DictValue` trait。

## 效能說明

由於 Cairo 的不可變記憶體模型，字典操作的複雜度為 $O(n)$，其中 $n$ 是對字典執行的操作次數。

每次操作都會建立一個新項目來記錄變更。

## 處理複雜型別

對於未實作`Felt252DictValue`的型別（例如陣列或 struct），你可以把它們包進`Nullable<T>`：

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## 記憶體管理

字典實作了`Destruct` trait，這表示當它們離開作用域時，會自動被「壓縮」（驗證並最佳化）。

這是 Cairo 證明系統的一部分，並且在幕後進行。

記住：雖然字典看起來可能不如其他語言有效率，但它們這樣設計，是為了配合 Cairo 獨特的記憶體模型與證明系統需求喔。
