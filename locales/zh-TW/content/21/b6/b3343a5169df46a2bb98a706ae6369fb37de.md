身為見習魔術師，Elyse 需要練習一些基本技巧。
她有一副牌，想要好好操作一番。

為了讓事情簡單一些，她只使用 1 到 10 的牌。

## 1. 從牌組中取出一張牌

回傳指定牌組中位置`idx`的那張牌。

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. 替換牌組中的一張牌

用提供的新牌替換位置`idx`的牌，並回傳調整後的牌組。
請注意，這會修改（改變）輸入的向量，這是可以的。

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. 在牌組頂端插入一張牌

在牌組頂端插入新牌，並回傳牌組。

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. 從牌組中移除一張牌

從牌組中移除位置`idx`的牌，並回傳牌組。

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. 移除牌組頂端的牌

移除牌組頂端的牌，並回傳牌組。

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. 在牌組底部插入一張牌

在牌組底部插入一張新牌，並回傳牌組。

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. 從牌組底部移除一張牌

移除牌組底部的牌，並回傳牌組。

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. 檢查牌組的大小

檢查牌組的大小是否等於指定的`deck_size`。

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
