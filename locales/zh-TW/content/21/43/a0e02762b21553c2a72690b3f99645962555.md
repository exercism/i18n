# 簡介

在 Clojure 中，把值繫結到名稱的做法稱為 _var_。頂層（全域）var 類似其他語言裡的常數。

頂層 var 使用`def`定義：

```clojure
(def fingers 10)

fingers
;;=> 10
```

你可以用`defn`定義接受零個或多個引數的函式。以下是一個會把 2 個數字相加的函式：

```clojure
(defn add [x y]
  (+ x y))
```

這個函式接受 2 個引數，這些引數放在向量`[x y]`中，接著是函式的*主體*，主體可以包含任意數量的運算式。回傳值一律是求值主體中最後一個運算式的結果，也就是`(+ x y)`。這個運算式是一個代表函式呼叫的陣列。陣列的第一個項目是`+`函式，它會以接下來的項目`x`和`y`作為引數來求值。

上面定義的`add`函式也是用同樣的方式呼叫：

```clojure
(add 2 3)
;;=> 5
```

在 Clojure 中，函式和值都必須先定義才能使用，也就是說，形式一律會依照出現的順序求值。

在 Clojure 中，空白除了排版之外沒有任何意義。

Clojure 的函式和 var 是以命名空間來組織的。命名空間會把相關的功能群組在一起，並使用`ns`巨集定義：

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure 支援兩種註解。單行註解以`;`開頭，而`comment`形式則用來避免求值`(comment`與`)`之間的所有內容。
