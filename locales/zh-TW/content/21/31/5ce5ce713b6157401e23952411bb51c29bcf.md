# 說明

你又回到了廚房，改良來自 [Leah 的美味千層麵][lasagna] 的千層麵食譜。這裡的任務要你同時處理多個輸入，而這正是區域變數（英文：_locals_），也就是 Factor 的具名綁定，派上用場的時候。

## 1. 判斷烹飪狀態

定義 `cooking-status`，從堆疊上取得計時器讀數，並回傳一個狀態字串。

- `0` → `"Lasagna is done."`
- `f`（計時器從未設定）→ `"You forgot to set the timer."`
- 其他任何數字 → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. 估算準備時間

定義 `preparation-time`，接收一個包含各層名稱的陣列，以及每層平均所需的分鐘數，並回傳總準備時間。

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. 計算所需的麵條和醬汁

定義 `quantities`，接收一個包含各層名稱的陣列，並回傳*兩個*值：所需的麵條公克數（每層麵條 50 公克）以及所需的醬汁公升數（每層醬汁 `1/5`公升）。

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. 加入秘密食材

你的朋友傳來一份食材清單，其中*最後*一項就是他們的秘密食材。定義 `add-secret-ingredient`，接收他們的清單和你的清單，並回傳在尾端加上這個秘密食材後你的清單。

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. 調整食譜份量

這本食譜書上的食譜可做出兩份。定義 `scale-recipe`，接收一份食譜（從食材名稱對應到份量的雜湊表）以及目標份數，並回傳依比例調整後的新食譜。

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
