# 說明

Astrid 是一位愛探險的鍊金術師，她正試著把從不同國度收集來的魔法度量單位標準化。
有些國度使用有號數值（可以是負數），有些則使用無號數值（永遠是正數）。
除此之外，Astrid 還為某些稀有材料準備了兩個自訂型別，她需要一個能輕鬆在這些型別之間轉換的方法。

你的任務是幫 Astrid 在有號與無號整數之間轉換，並運用 Cairo 的`Into`和`TryInto`特徵，為她那些特殊材料型別建立自訂的型別轉換。

## 1. 在有號與無號之間轉換魔法單位

Astrid 的測量值有時是正數、有時是負數（有號整數），但某些任務需要她確保這些值永遠是正數（無號整數）。

來幫幫 Astrid 吧，寫一個函式來轉換：

1. 把有號整數（`i32`）轉成無號整數（`u16`）。
2. 把無號整數（`u16`）轉成有號整數（`i32`）。

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. 自訂材料型別轉換

Astrid 會用到兩種稀有材料，**Essence**和**Elixir**，它們以自訂型別表示。
她希望能把**Essence**轉成**Elixir**，但反過來則不行。

幫幫 Astrid 建立`Essence`和`Elixir`兩個自訂型別，並實作`Into`特徵，把`Essence`轉成`Elixir`。

寫一個接受`Essence`的函式，並用`.into()`將它轉換成`Elixir`。

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
