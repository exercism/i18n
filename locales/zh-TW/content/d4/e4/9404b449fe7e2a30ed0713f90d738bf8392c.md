# 簡介

JavaScript 有一個內建的物件 `Date`，用來儲存日期與時間，並提供管理它們的方法。

<!-- prettier-ignore -->
~~~exercism/caution
它是以 Java 的 `java.util.Date` 類別為基礎，該類別在 2010 年代初被取代，但為了向後相容，JavaScript 的 `Date` 至今仍保留著。

由於日期本身就很難處理，加上時區處理既糟糕又常常付之闕如，因此市面上存在許多函式庫，例如 `moment.js`、`day.js`、`date-fns` 和 `luxon`。
這些在 Exercism 上都無法使用。

在你自己的專案中，不要使用 `moment.js` 這類已棄用或無人維護的套件，請改用 `luxon` 等更現代的做法，或是尚未普及的 [Temporal][mdn-temporal]。
本練習的重點是 `Date`，它在 JavaScript 走到盡頭之前都會是重要的存在。

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal

## 建立

`Date` 物件是 `Date` 類別的實例。
它可以在不傳任何引數給建構函式的情況下建立。
這樣會得到一個代表目前日期與時間的 `Date` 物件：

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### **Unix 時間戳記（數字）**

如果傳入的是數字，它會被解讀為 `timestamp`。
時間戳記是一個整數，代表自 **1970 年 1 月 1 日 [UTC][defn-utc]+0** 以來所經過的**毫秒**數。

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

你可能會以為 `new Date(0)` 會產生「最早」的日期物件，但 JavaScript 會把日期轉換成你的本地時區，這表示只有身處 [GMT / UTC+0][defn-gmt] 時區附近的人，才會真正得到 [Unix 紀元][defn-unix-epoch] 的值。

### **ISO 8601 時間戳記（字串）**

你可以傳入一個代表日期的字串值給 `Date` 建構函式。
在所有實作之間唯一一致的格式，是國際公認且標準化的所謂 [ISO 8601 時間戳記字串][defn-iso8601] 的[簡化版本][mdn-date-string-format]。

一個位於 [UTC][defn-gmt] 的時刻看起來像這樣：

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

其中各部分的替換如下：

| 鍵   | 說明                                       | 預設值 |
| ---- | ------------------------------------------ | ------ |
| YYYY | 西元年，以 4 位數表示                       |        |
| MM   | 月份，以 2 位數表示                         | 01     |
| DD   | 日期，以 2 位數表示                         | 01     |
| T    | 字面上的字母 T，用來分隔日期與時間          |        |
| HH   | 24 小時制的小時，以 2 位數表示              | 00     |
| mm   | 分鐘，以 2 位數表示                         | 00     |
| ss   | 秒，以 2 位數表示                           | 00     |
| mss  | 毫秒，以 3 位數表示                         | 000    |
| Z    | 字面上的字母 Z，或位移 `+/-HH:mm`           |        |

字面上的字母 `Z` 代表 UTC（沒有時區，也沒有日光節約時間）。

由於大多數組成部分都有預設值，因此省略結尾的部分是有效的：

```text
YYYY-MM-DD
```

預設時間為 00:00:00.000。

如果時間戳記的結尾不是 `Z`，也不是以 `+HH:mm` 或 `-HH:mm`（代表時區位移）結尾，那麼基於歷史因素，下列規則適用：

> 當缺少時區位移時，只含日期的格式會解讀為 UTC 時間，而含日期與時間的格式則會解讀為本地時間。
> 解讀成 UTC 時間是源自一個歷史上的規格錯誤，它與 ISO 8601 並不一致，但因為網頁相容性的緣故已無法更動。
> 請參閱 [損壞的剖析器：一個網頁現實問題][ref-broken-parser]。

### **`Date` 物件**

既有的日期物件也可以當作建構函式的引數傳入。
這會複製既有的 `Date` 物件，並帶有相同的日期與時間。

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### **分別提供日期與時間的各個組成值**

傳入三個數字可以建立一個代表日期的物件。
傳入 6 個數字則可以建立一個代表日期與時間的物件。

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

第二個值是 `month`，從代表一月的 `0` 開始，一直到代表十二月的 `11`。

## `Date.parse()`

你可能會看到有人提到或引用一個日期剖析函式 `Date.parse`。
由於這個函式只有少數不變的規則，其餘的實作並未被規定（因此也不標準），所以不應該使用它。

## 存取 `Date` 的組成部分

日期物件上有各種方法可以回傳日期的組成部分：

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

每一個都有對應的 `set` 版本（例如 `setFullYear`）可以更新值。
任何超出範圍的值都會進位到下一個組成部分：

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

所有方法都有忽略本地時區的 UTC 版本。

## 從日期轉換

日期物件有一個方法 `getTime()`，會回傳以毫秒為單位的 UNIX 時間戳記，也就是自 1970 年 1 月 1 日 UTC 午夜起算的毫秒數。
此外，還有 `toISOString()` 方法可以將日期物件轉換成 ISO 8601 時間戳記字串。

## 比較日期

大於（`>`）與大於等於（`>=`），以及小於（`<`）與小於等於（`<=`），都可以直接用在兩個日期之間，或日期與數字之間。
之所以可行，是因為 JavaScript 會嘗試把日期強制轉型成原始型別。

<!-- prettier-ignore -->
~~~exercism/advanced
在比較兩個日期，或比較日期與數字時，JavaScript 會呼叫 [`[Symbol.toPrimitive]("number")`][mdn-to-primitive]，而它內部會呼叫 [`date.valueOf()`][mdn-date-value-of]。
後者等同於呼叫 [`date.getTime()`][mdn-date-get-time]。

如果你不想依賴這種行為，請先用 `getTime()` 轉換成數字。

[mdn-to-primitive]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/Symbol.toPrimitive
[mdn-date-value-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf
[mdn-date-get-time]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime
~~~

日期不能使用相等運算子（`==` 和 `===`）比較，但 `.getTime()` 的結果可以。
