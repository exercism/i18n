# 簡介

Java 8 引進的 `java.time` 套件包含了幾個處理日期與時間的類別。

## `LocalDate`

`java.time.LocalDate` 類別代表 [ISO-8601 曆法系統][iso-8601]中不含時區的日期，例如 `2007-12-03`：

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

日期可以和其他日期比較：

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

`LocalDate` 實例提供了一些 getter，可以取出其中的時間部分：

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

`LocalDate` 實例也有一些方法可以在上面加上時間單位：

```exercism/note
這些方法會回傳一個_新的_ `LocalDate` 實例，不會更新原有的實例，因為 `LocalDate` 類別是不可變的。
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

`java.time.LocalDateTime` 類別代表 [ISO-8601 曆法系統][iso-8601]中不含時區的日期時間，例如 `2007-12-03T10:15:30`：

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

你可以把 `LocalDate` 實例轉換成 `LocalDateTime`：

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## 格式化日期時間

`LocalDate` 和 `LocalDateTime` 在與 `String` 互相轉換時，都採用 [ISO-8601][iso-8601] 的標準表示法。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

想用不同的格式，像這樣從 `String` 解析出 `LocalDate` 或 `LocalDateTime` 是行不通的。
這時若要自訂日期格式，就該改用 `java.time.format.DateTimeFormatter`：

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

建立自訂格式時也可以指定地區設定，以便針對不同區域進行格式化與解析：

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
