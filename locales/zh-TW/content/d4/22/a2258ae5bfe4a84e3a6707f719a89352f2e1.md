# 指令附加說明

## 提示

[雙向連結串列](https://en.wikipedia.org/wiki/Doubly_linked_list)是一種可變的資料結構。F# 是函式優先的語言，通常偏好不可變性，不過有些語言特性允許在需要時進行變動。

- `mutable`關鍵字可以放在 `let`繫結和[記錄](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records)欄位前面，讓你對它們指定新值。

- 只要用 `set`關鍵字指定屬性設定子，就能讓[類別](https://fsharpforfunandprofit.com/posts/classes)的屬性變成可變的。

可變的繫結必須用 `<-`重新指定。

```fsharp
let mutable x = "initial value"
x <- "new value"
```
