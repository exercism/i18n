# 說明

在這個練習中，你要寫一個好用的程式，讓你不用再記住每個色環代表的數值。
這個程式會接收 1 個、4 個或 5 個顏色作為輸入，並輸出正確的歐姆值。
色環的編碼方式如下：

| 顏色 | 數值 |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

在[`Resistor Color Trio`][resistor-color-trio-exercise]中，你解碼了前三個色環。
例如：orange-orange-brown 會換算成主要數值`330`。
在這個練習中，你需要把_公差_也加進來。
公差是數值可以高於或低於主要數值的最大幅度。
例如，如果最後一個色環是 green，最大公差就是`±0.5%`。

公差色環會是下列其中一種數值：

| 顏色 | 公差 |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

四環電阻的組成方式如下：

| 色環 1 | 色環 2 | 色環 3 | 色環 4 |
| ------- | ------- | ---------- | --------- |
| 數值 1 | 數值 2 | 倍率 | 公差 |

範例：

- orange-orange-brown-green 會是`330`歐姆，公差為`±0.5%`。
- orange-orange-red-grey 會是`3300`歐姆，公差為`±0.05%`。

四環電阻和五環電阻的差別在於，五環電阻多了一個色環，用來表示更精確的數值。

| 色環 1 | 色環 2 | 色環 3 | 色環 4 | 色環 5 |
| ------- | ------- | ------- | ---------- | --------- |
| 數值 1 | 數值 2 | 數值 3 | 倍率 | 公差 |

範例：

- orange-orange-orange-black-green 會是`333`歐姆，公差為`±0.5%`。
- orange-red-orange-blue-violet 會是`323 million`歐姆，公差為`±0.1%`。

另外還有單環電阻。
單環電阻只有 black 這一種顏色，數值為 0。

你的程式要把輸入的電阻色環顏色`list`轉換成一個標籤：

「... ohms ±...%」

所以，當輸入的`list`是`["orange", "orange", "black", "green"]`時，應該回傳：

「33 ohms ±0.5%」

當歐姆數達到好幾千時，我們會說「kiloohms」。
這就像把 1000 公尺說成「公里」、把 1000 公克說成「公斤」一樣。

所以，當輸入的`list`是`["orange", "orange", "orange", "grey"]`時，應該回傳：

「33 kiloohms ±0.05%」

當歐姆數達到好幾百萬時，我們會說「megaohms」。

所以，當輸入的`list`是`["orange", "orange", "blue", "red"]`時，應該回傳：

「33 megaohms ±2%」
