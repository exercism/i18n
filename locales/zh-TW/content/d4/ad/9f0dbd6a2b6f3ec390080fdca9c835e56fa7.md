# 提示

## 一般

- `<min-heap>`、`heap-push`、`heap-peek` 和 `heap-pop-all` 都位於 [`heaps`][heaps] 中；`values` 則位於 [`assocs`][assocs] 中。
- 堆積會把每個項目儲存成帶有*鍵*的*值*；這個鍵就是優先順序。`heap-push` 接收它們的形式是 `( value key heap -- )`。

## 1. 開啟佇列

- `<min-heap>` 會建立一個空的最小堆積，鍵最小的會最先被服務。

## 2. 新增顧客

- 顧客名稱是值，優先順序是鍵，這正好就是 `heap-push` 想要的順序。
- `heap-push` 會消耗掉佇列。用 `[ heap-push ] keep` 來新增顧客，同時仍然回傳佇列。

## 3. 下一位是誰？

- `heap-peek` 會回傳最前面項目的 `value key`，但不會把它移除。你只想要名稱，所以用 `drop` 把鍵丟掉。

## 4. 服務所有人

- `heap-pop-all` 會把堆積清空，變成由 `{ key value }` 配對組成的關聯陣列，而且已經是優先順序。
- `values` 只保留值，也就是名稱。

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
