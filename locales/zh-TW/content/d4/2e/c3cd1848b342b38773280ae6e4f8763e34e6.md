# 說明

歡迎來到 *ChronoRealms* 的世界，這是一個魔法國度，強大的 Timekeepers 在此掌控時間的流動。

在這個國度裡，Timekeepers 管理「TimeShards」，這是一種特殊單位，可以相加、相減、比較，甚至檢查是否相等。

你的任務是為這些 TimeShards 實作自訂運算子，來幫助 Timekeepers 操控它們。

Timekeepers 需要你建立一個自訂的 struct `TimeShard`，支援以下操作：

1. **相加與相減 TimeShards**：Timekeepers 需要能相加與相減 TimeShards，以控制時間線。
2. **比較 TimeShards**：有時需要比較 TimeShards，看看哪個較大，或它們是否相等。
3. **檢查相等性**：Timekeepers 需要檢查兩個 TimeShards 的值是否相等。

你的任務是為`TimeShard`這個 struct 實作以下 trait：

1. **加法（`Add`）**：讓兩個`TimeShard`實例可以相加。
2. **減法（`Sub`）**：讓一個`TimeShard`可以減去另一個。
3. **相等性（`PartialEq`）**：讓 Timekeepers 可以檢查兩個`TimeShard`實例是否相同。
4. **比較（`PartialOrd`）**：讓兩個`TimeShard`實例可以比較，看看哪個較大或較小。

`TimeShard`會由一個 struct 表示，該 struct 儲存一個整數值（`i32`）。

實作必要的 trait，讓 Timekeepers 的工作更輕鬆。

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
