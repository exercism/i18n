# 指示

你剛被一家新的計程車服務公司錄取，這家公司想在早已飽和的市場中做出區隔。
為了達成這個目標，執行長決定在曼哈頓推出極致奢華的服務，在每個路口都安排服務人員，在乘客搭乘前後協助他們。
現在，你需要寫一些程式碼，來協助這項服務的營運。

## 1. 簡單複數

你的執行長認為，既然曼哈頓的街道大致呈格狀，用複數來表示街道的交叉口會很方便。
其中正實數代表東方，負實數代表西方，正虛數代表北方，負虛數代表南方。

由於在 R 中建立複數的方式有點……嗯，與眾不同，所以你被指派實作一個簡單的複數函式。

實作`simplex(a, b)`函式，它接受整數`a`和`b`。
回傳複數`a+bi`。

```r
simplex(1, 1)
#> 1+1i

simplex(-3, 4)
#> -3+4i
```

## 2. 取得駕駛的行進方向

當乘客說出目的地的路口時，你的駕駛會取得前往該處的方向指引。
這些指引以複數的形式呈現，實部代表要往北或往南走幾個街區，虛部則代表東西向的距離。
為了對應標準的羅盤方位，你的專案經理決定把北方定在正虛數方向，南方定在負虛數方向。
同樣地，東方是正實數方向，西方是負實數方向。

實作`driver_directions(start, end)`函式，它接受起始路口的座標`start`以及目的地的座標`end`。
回傳一個複數，代表駕駛要往東／西和往北／南各走多少個街區。

```r
driver_directions(0+0i, 7+5i)
#> 7+5i

driver_directions(-2+3i, 4-5i)
#> 6-8i
```

## 3. 取得曼哈頓距離

乘客需依計程車必須行駛的距離付費。
由於曼哈頓的街道呈格狀，計程車只能沿著這些路線行駛。
這樣的結構使得距離的計算必須沿著格線進行。
這個距離可以把走過的街道線數加總，或把抵達的路口數加總（也就是不含起點路口）得出。
這種度量方式通常稱為曼哈頓距離或 L1 範數。

實作`manhattan(start, end)`函式，它接受`start`與`end`兩個路口。
回傳`start`與`end`兩個路口之間的曼哈頓距離。

```r
manhattan(0+0i, 3+4i)
#> 7

manhattan(-2-3i, -1+1i)
#> 5
```

## 4. 取得「直線距離」

執行長向投資銀行強調，這項服務不僅極致奢華，還很環保，因為它會利用訓練過的烏鴉，在各路口的服務人員之間傳遞訊息（由他們轉達乘客的資訊，以提供個人化的體驗），因此成功說服了投資銀行加入。
看來這些投資銀行家都沒費心去查清楚，這到底為什麼環保，甚至也沒去了解什麼樣的執行長會喜歡在空閒時間訓練烏鴉，因為投資資金已經源源不絕地湧入。

這項服務同樣依飛行距離收費。
不過，烏鴉會飛，不必沿著格狀的道路網移動，可以走最短路徑。
當然，如果有巨大的摩天大樓，情況可能就不是如此；但執行長把這項服務設在堪薩斯州的曼哈頓（又稱「小蘋果」），這裡的烏鴉可以輕鬆飛越低矮的建築物。
這類服務在堪薩斯州曼哈頓的潛在需求，以及當地行人對這些鳥兒在頭頂飛來飛去會有什麼感受，都是以後再說的事了。

實作`as_crow_flies(start, end)`函式，它接受`start`與`end`兩個路口。
回傳兩者之間的直線距離。

```r
as_crow_flies(0+0i, 3+4i)
#> 5
```

## 5. 取得烏鴉的行進方向

你的執行長把烏鴉訓練成能聽懂與駕駛類似的方向指引。
不過，執行長熱愛南半球，所以訓練烏鴉時用的是與專案經理在系統其他部分使用的不同方位。
你的執行長原來是個相當古怪的人。
執行長的方位把北方定在負虛數方向，南方定在正虛數方向。
這與駕駛的南北方向正好相反，而東西方向則維持不變。

實作`crows_directions(start, end)`函式，它接受`start`與`end`兩個路口。
回傳與駕駛行進方向類似的複數，但南北方向對調。

```r
driver_directions(0+0i, 7+5i)
#> 7-5i

driver_directions(-2+3i, 4-5i)
#> 6+8i
```
