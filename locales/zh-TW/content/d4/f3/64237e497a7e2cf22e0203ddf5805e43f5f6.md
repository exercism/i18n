# 關於

在 Common Lisp 中，全域的具名函式是用`defun`定義的。

這個形式的第一個引數，是正在定義的那個函式的一份參數列表（這份參數列表也稱為「lambda list」）。在那之後，它還可以選擇性地接受一個字串，作為該函式的說明文件。最後則是零個或多個構成函式主體的運算式。

呼叫函式的方式，是把函式的名稱放在運算式的第一個位置，後面接著要傳給該函式的任何引數。

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

函式也可以接受[選擇性參數][concept-optional-parameters]、[關鍵字參數][concept-keyword-parameters]、[剩餘參數][concept-rest-parameters]。這些會在後面的概念中介紹。

函式的名稱在函式主體的作用域內，因此可以進行遞迴。

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
