# 指令

你正在打造一台小型的逆波蘭表示法（RPN）計算機。計算機的狀態是一個*值的堆疊*，以 Factor 陣列表示，而一個*運算*則是一個 quotation，接收這樣的堆疊並回傳一個新的堆疊。

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. 實作加法

定義`add-op`，從堆疊取出最上面的兩個值、推入它們的總和，然後回傳新的堆疊。

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. 實作乘法

用同樣的方式定義`multiply-op`，但改成乘法。

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. 套用單一運算

定義`apply-op`，從資料堆疊取出一個堆疊和一個運算（quotation），並回傳新的計算機堆疊。

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. 求值一個程式

定義`evaluate`，接收一個起始堆疊和一個運算陣列，依序套用每一個運算，並回傳最終的堆疊。

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. 依名稱求值

現在程式是一個由*運算子名稱*（字串）組成的陣列，計算機會在一個 assoc 中查詢每個名稱，而這個 assoc 會將名稱對應到運算。

定義`evaluate-named`，接收一個起始堆疊、一個具名運算的 assoc，以及一個名稱陣列，並回傳最終的堆疊。

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. 安全地做除法

真正的計算機在被要求除以零時，不能默默產生垃圾結果。錯誤類別`zero-divisor-error`已經幫你定義好了。實作`divide-op`，做法類似`add-op`和`multiply-op`，差別在於當堆疊最上層的除數是`0`時，它會`throw`一個新的`zero-divisor-error`。

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
