# 簡介

在 Cairo 中，運算子重載讓你可以在操作自訂型別時，為 `+`、`-`、`==`、`<` 等標準運算子定義自訂行為。

這是透過為自訂型別實作特定的 trait 來達成的。

## 運算子的核心 trait

### `Add` 與 `Sub`

`Add` 與 `Sub` 這兩個 trait 讓你定義加法（`+`）與減法（`-`）在你的型別上如何運作：

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`PartialEq` trait 可以比較你的型別實例是否相等（`==` 與 `!=`）。

這通常可以用 `#[derive(PartialEq)]` 自動衍生。

### `PartialOrd`

`PartialOrd` trait 讓你的型別實例之間可以進行比較運算（`<`、`>`、`<=`、`>=`）。

使用這個 trait 時，你至少要實作 `lt`（小於）方法：

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
