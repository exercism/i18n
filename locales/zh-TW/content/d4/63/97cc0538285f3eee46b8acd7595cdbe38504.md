# 簡介

## 比較運算子

Julia 的比較運算子與許多其他語言相似，不過為數學愛好者多準備了一些選項。

判斷是否相等時，運算子有`==`（等於）以及`!=`或`≠`（不等於）。

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

此外，還有各種大於與小於的運算子。

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

就像 Julia 常見的情況一樣，適合的編輯器能讓你輕鬆使用這些數學符號。輸入`\ne`、`\le`或`\ge`後按`TAB`，就能得到`≠`、`≤`或`≥`。

前面的例子只用了數字，不過我們會在課程大綱的其他部分看到，各種額外的型別也具有順序的概念，可以拿來比較大小。

比較運算子可以串接，這讓語法能夠清楚又精簡：

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

前面的例子等同於`1 ≤ n && n ≤ 5`。

## 使用`if`進行分支

以下是`if`敘述的完整形式：

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

不需要括號`()`或大括號`{}`，縮排「只是」為了讓程式更容易閱讀_（但可讀性非常重要！）_。

`elseif`和`else`都是選用的，而且可以有好幾個`elseif`區塊。
不過`end`是必要的。

`if`敘述可以巢狀，不過你可以善用括號、縮排和註解來幫助閱讀。

`if`敘述最短的形式大概像這樣：

```julia
if n < 0
    n = 0
end
```

提醒一下：只有運算結果為`true`或`false`的運算式可以當作條件式。
Julia 刻意避開任何「真值性」的概念，所以零值、空字串和空陣列都_不_等同於`false`。

## 三元運算子

一種簡單又常見的情況，是根據條件從兩個值中挑選一個。

Julia 和許多語言一樣有三元運算子，可以讓寫法更精簡。

語法是`conditional ? value_if_true : value_if_false`。

所以前面的例子可以改寫成：

```julia
n = n < 0 ? 0 : n
```

編譯器並不要求加上括號，但括號可以提升可讀性。
