# 簡介

## 隨機性

在 Elixir 裡，如果想從可列舉的資料結構（例如陣列或範圍）中隨機挑選一個元素，我們會使用 `Enum.random`。這個函式會挑出單一元素，而且每個元素被挑中的機率都相同。

Elixir 本身沒有挑選隨機浮點數的函式。要做到這件事，我們必須直接使用 Erlang。

## Erlang 函式庫

Elixir 程式碼執行在 BEAM 虛擬機上。BEAM 是 Erlang 執行階段系統的一部分。由於受到 Erlang 啟發，又共用它的執行環境，Elixir 與 Erlang 函式庫之間有著絕佳的互通性。這表示 Elixir 開發者可以在自己的 Elixir 程式碼裡使用 Erlang 函式庫。事實上，在 Elixir 社群中，若某個功能已由 Erlang 函式庫提供，並不鼓勵再為它寫一套 Elixir 函式庫。

因此，某些功能（例如數學運算或計時器函式）在 Elixir 中只能透過 Erlang 取得。

Erlang 的標準函式庫可以直接在我們的 Elixir 程式碼中使用，不需要任何額外步驟。

Erlang 函式的呼叫方式和我們呼叫 Elixir 函式一樣，只有一個小差別：Erlang 模組的名稱是 `snake_case` 的原子。舉例來說，若要從 `math` 模組呼叫 Erlang 的 `pi/0` 函式，可以這樣寫：

```elixir
:math.pi()
# => 3.141592653589793
```

最常用、而且 Elixir 沒有對應版本的 Erlang 函式有：

- `:timer.sleep/1`：讓行程暫停指定的毫秒數。
- `:rand.uniform/0`：產生一個隨機浮點數 `x`，其中 `0.0 <= x < 1.0`。
- `:io_lib.format/2`：提供 C 風格的字串格式化（使用控制序列）。用這個函式，我們可以把整數以 2 到 36 之間的任意進位印出，也可以用想要的小數位數格式化浮點數。注意，這個函式和許多 Erlang 函式一樣，回傳的是字元列表。
- `math` 模組，提供 `sin/1`、`cos/1`、`log2/1`、`log10/1`、`pow/2` 等數學函式。

想探索 Erlang 的標準函式庫，可以閱讀 [STDLIB 參考手冊][erl-stdlib-ref]。

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
