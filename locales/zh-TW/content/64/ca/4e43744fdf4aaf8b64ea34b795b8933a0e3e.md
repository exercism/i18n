# 指令

你的任務是判斷家族樹中兩個人之間的分隔度數。
這有點像流行文化中的說法：每位好萊塢演員都在[與 Kevin Bacon 相距六度][six-bacons]之內。

- 你會收到一份輸入，裡面包含所有父母的名字和他們的小孩。
- 每個名字都是獨一無二的，一個小孩_可以_有一或兩個父母。
- 分隔度數的定義是：從一個人到另一個人之間最少的連結數。
- 如果兩個人沒有連結，就回傳一個代表「沒有已知關係」的值。
  實際的實作方式請參考測試案例。

## 範例

給定以下家族樹：

```text
      ┌──────────┐            ┌──────────┐     ┌───────────┐
      │  Helena  │            │  Erdős   ├─────┤  Shusaku  │
      └───┬───┬──┘            └─────┬────┘     └────┬──────┘
      ┌───┘   └───────┐             └───────┬───────┘
┌─────┴────┐     ┌────┴───┐           ┌─────┴────┐
│   Isla   ├─────┤ Tariq  │           │   Kevin  │
└────┬─────┘     └────┬───┘           └──────────┘
     │                │
┌────┴────┐      ┌────┴───┐
│   Uma   │      │ Morphy │
└─────────┘      └────────┘
```

Tariq 和 Uma 之間的分隔度數是 2（Tariq → Isla → Uma）。
Isla 和 Kevin 之間沒有已知關係，因為給定的資料中沒有連結。
Uma 和 Isla 之間的分隔度數是 1。

~~~~exercism/note
Isla 和 Tariq 是手足，兩人之間的分隔度數是 1。
同樣地，這個實作會回報你和父親的兄弟之間的分隔度數是 2。
~~~~
