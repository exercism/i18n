# 指令

你的任務是根據會議開始的時間，把交付日期的描述轉換成_實際_的交付日期。

交付日期的描述有兩種：

1. 固定：一組事先定義好的字詞。
2. 變動：帶有可變部分，但遵循事先定義好模式的字詞。

## 固定交付日期描述

固定交付日期描述有三種：

- `"NOW"`
- `"ASAP"`（盡快）
- `"EOW"`（一週結束時）

下表說明如何轉換它們：

| 描述    | 會議開始時間           | 交付日期       |
| ------- | ---------------------- | -------------- |
| `"NOW"` | -                      | 會議開始後兩小時 |
| `"ASAP"` | 13:00 之前            | 今天 17:00     |
| `"ASAP"` | 13:00 或之後          | 明天 13:00     |
| `"EOW"` | 星期一、星期二或星期三 | 星期五 17:00   |
| `"EOW"` | 星期四或星期五         | 星期日 20:00   |

## 變動交付日期描述

變動交付日期描述有兩種模式：

- `"<N>M"`（第 N 個月）
- `"Q<N>"`（第 N 季）

| 描述     | 會議開始時間        | 交付日期                                          |
| -------- | ------------------- | ------------------------------------------------- |
| `"<N>M"` | 第 N 個月之前       | 今年第 N 個月的_第一個_工作日 8:00                |
| `"<N>M"` | 第 N 個月或之後     | 明年第 N 個月的_第一個_工作日 8:00                |
| `"Q<N>"` | 第 N 季或之前       | 今年第 N 季的_最後一個_工作日 8:00                |
| `"Q<N>"` | 第 N 季之後         | 明年第 N 季的_最後一個_工作日 8:00                |

~~~~exercism/note
工作日是星期一、星期二、星期三、星期四或星期五。

一年有四季，每季各有三個月：
1. 一月／二月／三月
2. 四月／五月／六月
3. 七月／八月／九月
4. 十月／十一月／十二月。
~~~~
