# 指令補充

## 輸出格式

將蛋白質序列輸出為以 null 結尾的字串，並在每個蛋白質之後加上換行字元。

例如，輸出會是 `"Methionine\nPhenylalanine\nSerine\n"`

如果輸入無效，輸出空字串。

## 暫存器

| 暫存器 | 用途        | 型別    | 說明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 輸入        | 位址 | 以 null 結尾的輸入字串  |
| `$a1`    | 輸入/輸出 | 位址 | 以 null 結尾的輸出字串 |
| `$t0-9`  | 暫存    | 任意     | 用於暫存    |
