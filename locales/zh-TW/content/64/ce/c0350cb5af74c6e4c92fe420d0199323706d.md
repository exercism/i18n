# 關於

Swift 是一門現代化的開放原始碼程式語言，可在 macOS、Linux 和 Windows 上執行。

Swift 最初由 Apple 開發，用來與他們的核心框架 Cocoa 和 CocoaTouch 互通，這兩個框架大多以 Objective-C 實作。

Swift 受到許多現有程式語言的影響，並融合了各式各樣程式設計方法的概念，從腳本撰寫到物件導向與函式式程式設計，全都涵蓋在內。

Apple 將 Swift 稱為「協定導向程式語言」，並表示目標是最終讓 Swift 適用於從腳本到作業系統的一切。
