# 抽象類別

馬戲團的演出是一連串的節目。雜耍、高空鞦韆和翻滾是不同的東西，內在也各不相同，但排演出順序的人只需要知道每項節目的兩件事：它叫什麼名字，以及它要花多久。

**抽象類別**描述的就正好是這些，不多也不少。

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

它的名稱以`$`開頭。它列出沒有內容的常式：只有簽章，每一項都結束於分號。沒辦法用它產生任何東西：既沒有`create`，也沒有`new`。

## 符合

真正的類別只要把`$ACT`寫在`<`後面，就承諾自己是個`$ACT`：

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<`讀作「is a」。這個類別必須提供抽象類別列出的每一個常式，而且引數和回傳型別都要相同。漏掉任何一個都是編譯錯誤，而不是執行時才冒出來的意外。

類別可以自由增加任何其他東西。`TRAPEZE`可以保存其他節目都沒有的高度；抽象類別既不知道，也不在乎。

## 使用型別

`$ACT`是一種型別，所以任何東西都可以用它來宣告：

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

這個陣列同時保存三個不同類別的物件，而`ARRAY{JUGGLING}`做不到這一點。

## 分派

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!`是一個`$ACT`。執行到那一行時，才會依物件實際上是什麼來決定執行哪個`minutes`：雜耍執行`JUGGLING::minutes`，高空鞦韆執行`TRAPEZE::minutes`。這種選擇就叫做**分派**。

負責加總的常式從不詢問自己拿到的是哪一種節目。要增加第四種節目，只需要寫一個新的類別，其他什麼都不用改，這正是要這樣做的全部理由喔。
