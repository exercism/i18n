# 舊版檔案

```exercism/note
如果你在開始使用 v3 之後，在 Elixir 或 Elm 上看到這段訊息，最有可能的原因是這些 track 改變了它們的檔案結構。
如何處理這個變更，請參閱本文件底部的章節。
```

## 什麼是舊版檔案？

如果你使用 Exercism 線上編輯器，有時可能會遇到關於舊版檔案的警告。
會看到這個警告，原因有兩種。

### 透過 CLI 錯誤上傳的檔案

使用 CLI 時，你可以上傳任何你想要的檔案。
不過，線上編輯器只允許你編輯它認得的檔案。
所以如果你上傳了編輯器不認得的檔案，它就無法讓你編輯，並且會顯示警告，讓你知道可以刪除它。

### 因為練習變更而產生的檔案

有時候練習的結構會改變。
檔案可能會被重新命名，或整個練習結構都可能改變。
雖然我們盡量避免，但有時候這在實務上就是正確的決定。
舉例來說，某個 track 可能改變它的建置系統，就像 Elixir 從 `exs` 檔改用 `ex` 檔那樣。
或者某個語言的一般目錄結構可能改變，就像 Elm 把所有東西都搬進子目錄那樣。

在這些情況下，我們無法自動幫你搬移檔案，所以你需要做一些手動的工作。
在編輯器裡，你會看到舊的解答檔案（帶有舊版標示），以及新解答檔案的骨架。
把你的成果從舊檔案複製到新檔案，並調整任何需要修改的程式碼。
等測試通過之後，你就可以刪除舊的解答檔案，然後把這一切通通忘掉吧 🙂

## 刪除舊版檔案

當你刪除舊版檔案時，它**不會**影響先前的疊代。
那個檔案仍然會存在於那些疊代裡。
刪除檔案只是把它從你透過編輯器提交的**下一個**疊代中移除。

## Track 結構的變更

### Elixir

2019 年 7 月，Elixir 把它的練習結構從使用 Elixir 指令碼（`*.exs` 檔）改為每個練習都是一個完整的 [Mix 專案](https://elixir-lang.org/getting-started/mix-otp/introduction-to-mix.html)。
為了使用 v3 的功能，請把你的解答複製到位於 `lib/<exercise_stub>.ex` 的骨架檔案。
你不需要搬移測試檔，更新後的版本已經會出現在正確的位置。

### Elm

在 v3 推出時，Elm 改變了它的練習。
