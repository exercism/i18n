# 指示

這個練習會帶你進入特洛伊的世界。
這裡居民的生活充滿了驚奇與魔法。
特洛伊的許多人類擁有*力量*，並且在日常生活中頻繁使用。
力量可以用來重塑世界，或影響特洛伊的動物和其他人。
魔法也會顯現在*獨特的器物*上，這些器物深受冒險者、工匠和賢者追捧。

在這個練習中，你將撰寫程式碼來模擬特洛伊的人類、他們所擁有的器物，以及力量之間的互動。

你有 6 項任務。
第一項與建立人類有關，其餘 5 項則與處理力量和器物有關。

## 1. 將人類帶到特洛伊的世界

在你的特洛伊模型中，人類是最重要的部分。
你模型裡的人類應該要能擁有*獨特的器物*。
他們也應該要能顯現*力量*。
這些力量可能會影響其他人類，所以你也會想模擬人類是否受到其他力量影響。

你已經有`artifact`和`power`結構的基本實作。
請實作一個`human`結構（或類別），其中有一個名為`possession`的`artifact`成員變數，並以*智慧指標*指向它。
在任何時刻，每件器物只能由單一人類擁有。

`human`還必須有 2 個額外的成員變數。
一個用來存放`own_power`，另一個則存放他們`influenced_by`的力量。
`own_power`和`influenced_by`都是指向`power`的*智慧指標*。
每個`power`可能由單一人類擁有，但同時也能影響其他人類。

預設情況下，人類出生時不帶任何器物，既不擁有任何力量，也不受任何力量影響。

```cpp
human mindy_mccready{};
mindy_mccready.possession;
// => nullptr
mindy_mccready.own_power;
// => nullptr
mindy_mccready.influenced_by;
// => nullptr
```

## 2. 將器物帶入特洛伊

如果模型中的各個部分不能互動，就太無聊了。
你想創造獨特的器物，並把它們交給特定的人類。

定義函式`give_new_artifact`，它不會回傳任何東西，但接受一個`human`的參考和一個`string`。
它應該用這個`string`定義一個新的`artifact`物件，並據此設定該`human`的`possession`指標。
這個函式不應該回傳任何東西。

```cpp
human erik_magnus_lehnsherr{};
give_new_artifact(erik_magnus_lehnsherr, "Mind shielding helmet");

erik_magnus_lehnsherr.possession->name;
// "Mind shielding helmet"
```

## 3. 讓物品可以交易

特洛伊的世界充滿了互動。
你希望人們能透過交換彼此的所有物來進行交易。

撰寫一個函式`exchange_artifacts`，它不會回傳任何東西，但接受 2 個器物智慧指標來交換物品。
請記住，你無法複製`unique_ptr`。
這也包括用在函式參數上的情況。
請改用`unique_ptr`的參考。

```cpp
human uchiha{};
give_new_artifact(uchiha, "konoha headband");
human uzumaki{};
give_new_artifact(uzumaki, "forehead protector");

exchange_artifacts(uchiha.possession, uzumaki.possession);

uchiha.possession->name;
// "forehead protector"
uzumaki.possession->name;
// "konoha headband"
```

## 4. 將力量賦予人們

特洛伊最令人興奮的特色，就是人們可能擁有的特殊力量。
有些人能用意念熔煉鋼鐵，有些人則能在夜晚瞬間治癒所有傷口。

定義函式`manifest_power`，它不會回傳任何東西，但接受一個`human`的參考和一個`string`。
它應該用這個`string`定義一個新的`powers`物件，並據此設定該`human`的`own_power`指標。
這個函式不應該回傳任何東西。

```cpp
human eleven {};
manifest_power(eleven, "psychokinesis");

eleven.own_power->effect;
// "psychokinesis"
```

## 5. 使用力量

再強大的力量，如果不能使用，又有什麼用呢。
你的模型聚焦於人類，所以你想追蹤力量的影響。

撰寫一個*void*函式`use_power`，它接受 2 個 human 的參考。
第一個是施術的人類，第二個則代表目標。
目標的`influenced_by`指標應該指向施術者的力量。

為了簡單起見，人類只能受到單一力量的影響。
即使施術者已經不存在，這股力量仍會持續作用。

```cpp
human pamela_isley{};
manifest_power(pamela_isley, "control pheromones");

human count_vertigo{};
use_power(pamela_isley, count_vertigo);
count_vertigo.influenced_by->effect;
// "control pheromones"
```

## 6. 留意力量的強度

某些力量在施加於多個人類時，會失去效力，或在你的模擬中觸發特定效果。
你想追蹤與每個力量連結的人數。

定義函式`power_intensity`，它接受一個 human，並以*int*回傳其力量的強度。
如果這個人沒有任何力量，回傳值應該是`0`。
否則，強度應該反映出施術者以及目前所有受影響的人。

```cpp
human jean_grey{};
manifest_power(jean_grey, "uplifting personality");

human scott{};
human logan{};
human ororo{};

use_power(jean_grey, ororo);
use_power(jean_grey, logan);
use_power(jean_grey, scott);

power_intensity(jean_grey);
// 4
```
