# 簡介

## 屬性

C# 中的屬性是類別的一種成員，提供存取該類別內資料的方式。呼叫端可以設定或取得（get）資料。屬性可以是自動實作，也可以有支援欄位。屬性由 set 存取子和／或 get 存取子組成。在其他某些語言中，「mutator」大致等同於 set 存取子，「accessor」則大致等同於 get 存取子，儘管兩者的語法組合方式完全不同。

設定屬性時，輸入值可以被驗證、格式化或以其他方式處理，事實上，只要是類別中程式碼能存取的任何程式化操作，都可以執行。

同樣地，取得屬性時，資料可以被計算或格式化，而且類別可用的任何程式化操作也都可以執行。

屬性和其他類別成員一樣具有存取修飾詞（如 `public`、`private` 等），但 set 存取子的存取層級可以獨立於取得（get）存取子，反之亦然。屬性不一定要同時具備兩個存取子，也可以只有其中一個（get 或 set）。

表達屬性的基本語法有兩種形式：

### 以欄位／運算式為基礎的屬性：

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### 自動實作屬性

```
public int MyProperty { get; private set; } = 42;
```

初始化並非必要。
