# 指令補充

## 暫存器

| 暫存器 | 用途     | 型態    | 說明                                                                           |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | 輸入     | 整數 | 數字                                                                                |
| `$v0`    | 輸出     | 整數 | 分類（`1` = `perfect`、`2` = `abundant`、`3` = `deficient`、`-1` = `error`） |
| `$t0-9`  | 暫存 | 任意     | 用於暫存資料                                                            |
