# 說明

你那位在圖書館工作的朋友請你擴充她的圖書館軟體，讓它能自動計算逾期費用。
她目前的系統會把每本書借出時的確切日期與時間，以 [ISO8601](https://en.wikipedia.org/wiki/ISO_8601) 日期時間字串的形式儲存起來。
她在迦納的一個小鎮經營地方圖書館，當地使用的是 GMT 時區（UTC +0），不實施日光節約時間，也不需要煩惱其他時區的問題。

## 1. 解析儲存的日期時間

實作`LibraryFees.datetime_from_string/1`函式。它應該接受一個 ISO8601 日期時間字串作為引數，並回傳一個`NaiveDateTime`結構。

```elixir
LibraryFees.datetime_from_string("2021-01-01T13:30:45Z")
# => ~N[2021-01-01 13:30:45]
```

## 2. 判斷書是否在中午前借出

如果書是在中午前借出，讀者有 28 天的歸還期限；如果是在中午或中午之後借出，則是 29 天。

實作`LibraryFees.before_noon?/1`函式。它應該接受一個`NaiveDateTime`結構，並回傳布林值。

```elixir
LibraryFees.before_noon?(~N[2021-01-12 08:23:03])
# => true
```

## 3. 計算歸還日期

根據借出的日期時間，計算歸還日期。

實作`LibraryFees.return_date/1`函式。它應該接受一個`NaiveDateTime`結構，並回傳一個`Date`結構，也就是 28 或 29 天後的日期。

```elixir
LibraryFees.return_date(~N[2020-11-28 15:55:33])
# => ~D[2020-12-27]
```

## 4. 判斷書逾期歸還了多久

圖書館對逾期歸還採單一費率。為了計算費用，我們需要知道書實際歸還時，距離歸還日期已經過了幾天。

實作`LibraryFees.days_late/2`函式。它應該接受兩個引數：一個`Date`結構，也就是預計的歸還日期；以及一個`NaiveDateTime`結構，也就是實際歸還的日期時間。

如果實際歸還日期早於或等於預計的歸還日期，函式應該回傳 0；否則，函式應該回傳這兩個日期相差的天數。

圖書館會為了統計用途記錄書實際歸還的日期與時間，但計算逾期費用時不會用到時間。

```elixir
LibraryFees.days_late(~D[2020-12-27], ~N[2021-01-03 09:23:36])
# => 7
```

## 5. 判斷書是否在星期一歸還

圖書館有星期一還書的特別優惠。

實作`LibraryFees.monday?/1`函式。它應該接受一個`NaiveDateTime`結構，並回傳布林值。

```elixir
LibraryFees.monday?(~N[2021-01-03 13:30:45Z])
# => false
```

## 6. 計算逾期費用

實作`LibraryFees.calculate_late_fee/3`函式。它應該接受三個引數：兩個 ISO8601 日期時間字串，分別是借出的日期時間與實際歸還的日期時間，以及一天的逾期費用。它應該根據書實際逾期歸還的程度，回傳總逾期費用。

記得納入星期一的特別優惠。如果你在星期一還書，逾期費用可享半價，並無條件捨去。

```elixir
# Sunday, 7 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-03T13:30:45Z", 100)
# => 700

# one day later, Monday, 8 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-04T09:02:11Z", 100)
# => 400
```
