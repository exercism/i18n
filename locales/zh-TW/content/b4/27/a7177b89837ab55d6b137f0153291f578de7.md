## 變數

變數是符號化的名稱，指向的可能是值，也可能是容器。
變數名稱的開頭可以有、也可以沒有稱為 sigil 的特殊字元，後面接著一個識別字。
sigil 後面還可以再接一個 twigil。

帶有不同 sigil 的變數，存放的資料結構也不同。

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

你常會看到的 twigil 是`^`和`:`，它們是程式區塊簽章的簡寫。
`^`用於位置參數，`:`用於具名參數。

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## 容器

容器讓變數可以被修改。

用`constant`宣告的變數，以及不帶 sigil 的變數（在識別字前面加上`\`宣告），都沒有容器，而是直接指向值。

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## 型別

變數可以用型別約束來宣告。
型別約束也可以有強制轉型，做法是把可接受的型別當作引數，傳給想要的型別。

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

使用型別約束，是運用多重分派常式的一種方式。

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

在 Raku 裡，型別只是另一種物件。
宣告`class`、`role`或`enum`，都是建立自己的型別物件的方法。
例如，內建的型別`Bool`就是用 enum 建立出來的：`enum Bool <False True>`。

你也可以用`subset`關鍵字，根據其他型別建立簡單的型別約束。
你還可以用`where`子句進一步限制這個新型別。
`where`子句也可以用於簽章。

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
