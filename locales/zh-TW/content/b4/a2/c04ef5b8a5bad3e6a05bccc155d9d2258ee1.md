# 指示

你是船上的事務長，負責管理糧食儲藏室的庫存。庫存是一個雜湊表，其中每個鍵是物品名稱，而值則是庫存量。

## 1. 從陣列建立庫存

定義`create-inventory`，讓它接受一個物品名稱序列，並回傳一個雜湊表，把每個不重複的名稱與其數量配對。

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. 加入更多物品

定義`add-items`，讓它接受一個庫存和一個物品序列，並回傳一個新的庫存，其中每個列出物品的數量都已遞增。原始庫存不應被修改。

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. 遞減數量

定義`decrement-items`，讓它接受一個庫存和一個物品序列，並回傳一個新的庫存，其中每個列出物品的數量都已減一。數量絕不能降到零以下，而原本不在庫存裡的物品則應略過（不會插入負數的條目）。

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. 徹底移除某個物品

定義`remove-item`，讓它接受一個庫存和一個物品，並回傳一個移除了該物品的新庫存。如果該物品不存在，則回傳一份未變更的副本。

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. 列出可用的物品

定義`list-inventory`，讓它接受一個庫存，並回傳一個由`{ name quantity }`配對組成的陣列，其中只包含數量高於零的物品，並依名稱的字母順序排序。

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
