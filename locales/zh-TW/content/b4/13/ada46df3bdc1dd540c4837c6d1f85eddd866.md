# 簡介

AWK 是一種非常小巧的語言，只有少數幾種基本資料型態。
在本單元中，我們會介紹數字與字串。

## 數字

AWK 的數字是以雙精度浮點數實作的。
整數、浮點數和倍精度浮點數之間並沒有區別。

AWK 看得懂八進位數字常數（以 `0` 開頭）和十六進位數字常數（以 `0x` 或 `0X` 開頭）。

### 數值運算

你可以使用[標準算術運算子][ops-arith]`+`、`-`、`*`、`/`、`%`。
指數運算子是 `^`（POSIX 有規定），不過也可以用 `**`。
還有一些[內建數值函式][funcs-numeric]，包括三角函式、隨機數字產生，以及 `int(x)`可以將數字截斷成 _x_ 與零之間最接近的整數。

並沒有位元_運算子_。
gawk 則以函式來實作這些運算。
這些引數必須是非負數。

| 函式                | 運算                                           |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | 引數的位元 AND                                 |
| `or(a, b [, ...])`  | 引數的位元 OR                                  |
| `xor(a, b [, ...])` | 引數的位元 XOR                                 |
| `lshift(v, count)`  | 將 _v_ 的值向左位移 _count_ 個位元             |
| `rshift(v, count)`  | 將 _v_ 的值向右位移 _count_ 個位元             |
| `compl(v, count)`   | _v_ 的位元補數                                 |

## 字串

AWK 的字串是字元組成的序列。
字串常數用雙引號來指定。

~~~~exercism/caution
GNU awk 允許字串中包含 Unicode 字元：其他 awk 實作可能不行。
比較 `gawk` 與另一個熱門的 AWK 實作 `mawk`：

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### 字串運算

字串運算只有一種：串接。
串接沒有專屬的運算子；
只要把兩個字串並排放在一起，就會將它們串接起來：

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print`是**敘述**，不是函式。
`print`不需要括號。
~~~~

AWK 有大量[字串處理函式][funcs-string]。
隨著我們逐步走過這門課程，會再深入介紹它們。

## 數字與字串之間的轉換

沒有明確的運算子可以在數字與字串之間轉換。
AWK 會根據程式的情境隱式地完成轉換。
這讓處理輸入欄位的值變得非常簡單：AWK 通常就是照你想要的方式去做。

* `print x + y`會因為 `+` 這個數值運算，把 `x`和 `y`變數的值轉換成數字。
* `print x y`會因為串接運算，把 `x`和 `y`變數的值轉換成字串。

如果你想明確表達，`0 + x`會得到 _x_ 的數字表示法，而 `"" x`會得到 _x_ 的字串表示法。

### 從字串轉換成數字

AWK 把字串轉換成數字的方式可能會讓人困惑。
簡單的想像是，AWK 會從字串開頭讀取「數字字元」，直到遇到「非數字」字元為止。
舉幾個例子：

* `"2.5"`會轉換成數字 `2.5`；
* `"1e3"`會轉換成數字 `1000`（科學記號）；
* `"456abc"`會轉換成數字 `456`（因為 `a` 不是「數字」，轉換就停在那裡）。
* `"abc789"`會轉換成數字 `0`（字串**開頭**沒有任何數字）。

完整細節請看[使用手冊][str-to-num]。

## 判斷變數的型別

[`typeof(var)` 函式][func-typeof]會以字串回傳型別。

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
輸出
```none
42 string
43 number
```
