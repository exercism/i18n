# 指令

你為一間小公司記帳，每天的交易會以零亂的文字行送達。你將使用正規表達式來驗證金額、依標記的符號把數字抽出來，並標記出需要進一步查看的行。

## 1. 驗證金額

格式正確的金額是由一個`$`、一或多個數字，以及*非必要*的美分部分（一個點後面接著剛好兩個數字）組成：`$100` 或`$100.50`，但不是`$100.5`。定義`valid-amount?`，當*整份*字串是格式正確的金額時回傳`t`。

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. 取出美元金額

定義`dollar-amounts`，依序回傳該行中緊接在`$`之後的每個數字，只取數字，不含`$`。

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. 取出百分比

定義`percentages`，回傳每個緊接著`%`的數字。

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. 標記一行

定義`flagged?`，當該行以任意大小寫組合提到`refund`或`chargeback`時回傳`t`。

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
