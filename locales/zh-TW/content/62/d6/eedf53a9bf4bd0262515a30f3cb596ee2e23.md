# 布林值

`bool`型別（布林的縮寫）只有兩個值：`true`和`false`。
`true`和`false`這兩個字面值在程式碼中不區分大小寫。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

布林值常用於邏輯運算式中，作為運算子的結果，然後用於控制結構。

## 邏輯運算子

有幾個邏輯運算子：

- `!$a`：如果`$a`不是`true`，回傳`true`
- `$a && $b`：如果`$a`和`$b`都是`true`，回傳`true`
- `$a || $b`：如果`$a`或`$b`任一個是`true`，回傳`true`

~~~~exercism/caution
有`and`和`or`運算子，它們分別與`&&`和`||`互補。
它們的行為和`&&`與`||`不同，可能會產生非預期的結果，因此不建議使用它們。
~~~~
