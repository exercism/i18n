# 關於

[Standard ML (SML)](https://en.wikipedia.org/wiki/Standard_ml) 是 ML 程式語言的兩大主要方言之一。[ML](https://en.wikipedia.org/wiki/ML_programming_language) 是第一種強靜態型別的語言，於 1970 年代初期在愛丁堡大學開發。

儘管 SML 年代久遠，它在許多方面卻顯得非常年輕：SML 擁有的一些特色，主流語言要再過幾十年才會採用，有些甚至到今天還在實驗階段。

以下是 ML 一些「走在最前端」的特色：

- [**強**靜態型別](https://en.wikipedia.org/wiki/Type_system#Static_typing)
- [自動型別推論](https://en.wikipedia.org/wiki/Type_inference)
- 例外處理
- [模式比對](https://en.wikipedia.org/wiki/Pattern_matching)
- 參數化多型
- [一級函式](https://en.wikipedia.org/wiki/First-class_function)

SML 最初的設計目的是用來發展一階述詞演算的證明（讀作：*電腦程式*），所以它帶有一種明顯的學術氣息。

不過，SML 對不可變性與強型別的重視，使它被應用在許多程式正確性至關重要的領域（編譯器設計、程式碼分析、金融系統、醫療系統等等……）。

學習 SML 會讓你成為更優秀的程式設計師，因為它迫使你寫出無狀態的程式碼，並有效地運用閉包。

這也是許多程式設計師第一次接觸模式比對與（真正的）強型別。而且，由於 SML 的型別系統既強大又設計周延，用起來常常反而像在寫動態型別語言。

目前有幾種常見的實作：

- [MLton](https://github.com/MLton/mlton#readme)
- [SML/NJ](https://www.smlnj.org/)
- [PolyML](https://www.polyml.org/)。

你可以在每個實作各自的網站上找到這個語言的相關資訊。
