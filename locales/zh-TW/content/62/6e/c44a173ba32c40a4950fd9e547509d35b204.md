# 說明

在這個練習中，你要和朋友玩一場猜數字遊戲。規則很簡單：你心裡悄悄選一個`1`到`100`之間的數字，而你的朋友試著猜出你選了哪個數字。為了幫助朋友，你會依照猜測與你選的數字（`42`）有多接近，給出不同的回應。以下是各種回應的規則：

- 如果猜的是`42`：「Correct」
- 如果猜的是`41`或`43`：「So close」
- 如果猜的數字小於`41`：「Too low」
- 如果猜的數字大於`43`：「Too high」

你有四個任務，要分別實作出這些猜測對應的回應。

## 1. 回覆正確的猜測

實作`reply`函式，讓它能回覆正確的猜測：

```fsharp
reply 42
// => "Correct"
```

## 2. 回覆接近的猜測

修改`reply`函式，讓它能回覆接近的猜測：

```fsharp
reply 41
// => "So close"
```

## 3. 回覆太低的猜測

修改`reply`函式，讓它能回覆太低的猜測：

```fsharp
reply 25
// => "Too low"
```

## 4. 回覆太高的猜測

修改`reply`函式，讓它能回覆太高的猜測：

```fsharp
reply 88
// => "Too high"
```
