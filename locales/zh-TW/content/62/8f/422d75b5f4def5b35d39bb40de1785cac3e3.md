# 指令

在這個練習中，你會實作一部分的公用常式，來協助開發者清理識別字名稱。
在這 5 個任務中，你會逐步建構出`Clean`常式。
有效的識別字由零個或多個字母和底線組成。
在所有情況下，輸入字串都保證不是 null。
如果傳入`Clean`函式的是一個空字串，就應該回傳空字串。
請注意，呼叫者應避免用空識別字呼叫`Clean`常式，因為這樣的識別字沒有任何作用。

## 1. 將遇到的任何空格替換成底線

實作（_static_）`Identifier.Clean()`方法，將任何空格替換成底線。
這也適用於開頭和結尾的空格。

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. 將控制字元替換成大寫字串 "CTRL"

修改（_static_）`Identifier.Clean()`方法，將控制字元替換成大寫字串`"CTRL"`。

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. 將 kebab-case 轉換成 camelCase

修改（_static_）`Identifier.Clean()`方法，將 kebab-case 轉換成 camelCase。

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. 略過不是字母的字元

修改（_static_）`Identifier.Clean()`方法，略過任何不是字母的字元。

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. 略過希臘小寫字母

修改（_static_）`Identifier.Clean()`方法，略過範圍從「α」到「ω」的任何希臘字母。

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
