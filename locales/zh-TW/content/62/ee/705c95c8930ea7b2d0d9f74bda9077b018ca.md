# 關於

[WebAssembly](https://webassembly.org/) 是一種二進位指令格式，用於以堆疊為基礎的虛擬機器。它是 W3C 標準，內建於所有主流瀏覽器，並具備串流編譯，以及與 JavaScript 便利互通的能力。[大多數編譯式語言](https://github.com/appcypher/awesome-wasm-langs)現在都能產生 WebAssembly 二進位檔，讓 JavaScript 以外的語言也能在用戶端執行。此外，[許多伺服器端執行環境](https://github.com/appcypher/awesome-wasm-runtimes)和雲端服務也會執行 WebAssembly，其中不少都支援新興的 [WebAssembly Systems Interface (WASI)](https://wasi.dev/)。

這條學習軌道的主軸，是親手撰寫 WebAssembly 文字格式（\*.wat）檔案，藉此熟悉這台虛擬機器、指令集架構，以及核心規格所提供的模組抽象。雖然 WebAssembly 在正式環境中的部署大多是從更高階的語言編譯而來，但許多開發者依賴的卻是相對笨重的框架：這些框架透過厚重的 JavaScript 黏合程式碼，把 WebAssembly 虛擬機器抽象掉，並產生相對龐大、動輒數百萬位元組的二進位檔，導致啟動時間變慢。更深入理解 WebAssembly，就能打造出更小的模組，並讓你完全掌控模組與周遭主機環境互動的方式。你可能會很驚訝，光靠親手寫的幾千位元組 WebAssembly，竟然就能完成這麼多事情喔！
