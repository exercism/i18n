# 提示

## 一般

- `throw` 位於 [`kernel`][kernel]；`recover` 位於 [`continuations`][continuations]。

## 1. 檢查濕度

- 用 `>` 比較，然後執行 `[ "humidity too high" throw ] when`，只在出問題的情況下觸發錯誤。

## 2. 檢查溫度

- 形式和第 1 個任務一樣，只是改用 `500` 和不同的訊息。

## 3. 定義自訂錯誤

- `ERROR: machine-error ;` 會宣告類別，*也*會宣告一個建構詞，這個詞會拋出全新的實例。

## 4. 監控機器

- 把每個檢查包在 `[ check-… ] [ drop machine-error ] recover` 裡。回復用的引述會丟掉原本的錯誤，並拋出全新的 `machine-error`，如此既保留了「任一項失敗」的語意，又隱藏了原始例外的身分。
- `kernel` 中的 `bi*` 會把一個引述套用到每個輸入上。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
