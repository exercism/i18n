# 簡介

## 隨機性

在 Java 中，可以使用 `java.util.Random` 類別的實例來產生隨機數字。

### 隨機整數

可以使用`nextInt()`方法產生隨機整數。
這會產生一個值，範圍從`Integer.MIN_VALUE`到`Integer.MAX_VALUE`。

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

若要限制產生值的範圍，請使用`nextInt(int)`。
這會產生一個值，範圍從`0`（含）到給定的上界（不含）。

例如，下面這行程式會產生一個從`0`到`9`的隨機數字。

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

而下面這行程式則會產生一個從`10`到`19`的隨機數字。

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### 隨機浮點數

可以使用`nextDouble()`方法產生隨機浮點數。
這會產生一個值，範圍從`0.0`到`1.0`。

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

而下面這行程式則會產生一個從`100.0`到`200.0`的隨機數字。

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
