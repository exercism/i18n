# PowerShell

自動化一切！
在任何作業系統上撰寫指令碼，管理檔案、處理程序、資料中心或雲端服務。
互動式探索 JSON、XML、CSV 等結構化資料；從 Web API、CIM 到命令列應用程式，各種管理介面都能得心應手。

# 關於 PowerShell

PowerShell 是開放原始碼、跨平台的 .NET 指令碼語言、殼層與設定管理框架，能幫助 IT 專業人員和進階使用者控制及自動化幾乎所有事情。

PowerShell 建構在 .NET Framework 之上，改造了經典的 Unix 管線概念，將它從單純傳遞文字或二進位串流，擴展到支援傳遞物件執行個體，這些執行個體帶有型別資訊（例如日期和時間），以及內含結構化資料的複雜狀態。
在傳統殼層中，你可能會用文字處理從命令的輸出中擷取特定資訊；但在 PowerShell 裡，你可以直接存取屬性和方法（包括用來檢查物件、判斷有哪些屬性和方法可用的方式）。
你可以處理 CSV 檔案、把 JSON 轉成雜湊表、瀏覽 XML 文件，還有很多很多，讓許多用文字解析難以做到或不切實際的工作，變得容易組合。

PowerShell 具有擴充性。
它的擴充方式和其他殼層不同，不只是透過獨立的命令列工具，而是透過散布於模組中的指令碼、函式和 cmdlet，這些東西能真正完整整合 PowerShell 的說明系統、語法突顯的命令列編輯器、自動參數探索與 Tab 自動補全。
你甚至可以將檔案系統那套簡單、可探索的屬性 + 內容語法，延伸到 Windows 登錄檔、憑證存放區、SQL Server，甚至 Azure 等資料存放區！

PowerShell 還包含許多額外功能：

- 內建「cmdlet」，用於常見的系統管理工作，例如管理檔案、服務、處理程序，甚至登錄檔、事件記錄、通用資訊模型（CIM）、Web 要求等等。
- 與現有指令碼和命令列工具相容。
- 可擴充的介面，以及容易探索的模組和命令。
- 完整存取 .NET Framework，並可透過 NuGet 的 .NET 組件進行擴充。
- 豐富的命令歷程記錄，包含命令執行成功與否及所花時間的資訊。
- 強大的物件操作能力。物件可以直接操作、序列化，甚至傳送給其他工具或資料庫。

關於 PowerShell 這個語言、核心概念與功能的詳細文件，可以在安裝程式中找到：https://docs.microsoft.com/en-us/powershell。
