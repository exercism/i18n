# 測試

## 練習檔案

下載下來的練習會包含這些檔案，用來建置與測試你的解答：

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

檔名會因練習而異。
請把解答寫在檔名結尾不是`Tests`的`.vb`檔案裡。
檔名以`Tests.vb`結尾的檔案是 xUnit 測試套件；一般來說，你只應該為了移除`Skip`引數而編輯它。
你通常不需要編輯專案檔或鎖定檔。

## 執行測試

在練習目錄中開啟終端機，然後執行：

```bash
dotnet test
```

這個命令會還原專案的相依性、建置專案，並執行它的測試。
你也可以使用`dotnet watch test`，在原始碼檔案變更時重新執行測試。

## 略過的測試

練習一開始只會啟用第一個測試，讓你一次一步地解開其餘的測試。
開啟檔名以`Tests.vb`結尾的檔案，就能找到這些測試。
每個測試都是標上 xUnit `<Fact>` 屬性的`Sub`副程式。
只要`<Fact>`屬性帶有`Skip`引數，該測試就會被略過：

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

只要移除`Skip`引數，就能啟用該測試：

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

新啟用的測試通過之後，就對下一個被略過的測試重複同樣的流程。
當每個測試都已啟用並通過，你就完成了喔！
