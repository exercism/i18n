# 指示

Andrew 是公司的開發者，最近為資料庫遷移工具打造了一個輕量的 SQL 查詢產生器。他最初採用的樸素實作在小量資料上運作得完美無缺。然而在正式環境的大規模遷移期間，應用程式開始佔用過多記憶體，在沉重負載下也顯得吃力。在對應用程式做完效能分析後，Andrew 發現，在迴圈裡直接串接字串，會逼得 Go 不斷重新配置記憶體。現在，他需要你幫忙，用 Go 的 `strings.Builder` 重構這個工具，讓應用程式能順利擴展，並在處理大量文字時不會壓垮記憶體堆。

## 1. 產生 SELECT 查詢

實作 `BuildSelectQuery` 函式。它接受一個資料表名稱（`string`）和一組欄位名稱切片（`[]string`）。它應該回傳一個完整成形的 SQL `SELECT` 敘述，並以分號結尾。如果欄位切片是空的或為 `nil`，查詢就應該退回到使用 `*` 萬用字元來選取所有欄位。

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. 產生批次 INSERT 敘述

實作 `BuildBatchInserts` 函式。它接受一個資料表名稱（`string`）和一個代表資料庫資料列的二維切片（`[][]ColumnValue`）。資料列中的每個元素會把特定的欄位名稱連結到它的字串值。這個函式必須回傳一組個別的 `INSERT` SQL 字串切片。結構化的切片格式保證了查詢輸出的順序可預期且穩定。如果傳入的資料列切片是空的，就回傳空的字串切片。如果其中任何一個資料列是空的，就略過它。`VALUES` 子句中的字串值必須用單引號 `'` 包住。

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
