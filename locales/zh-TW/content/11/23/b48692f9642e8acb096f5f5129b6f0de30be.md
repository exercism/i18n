# 提示

## 一般

- `struct`是一連串具名的元素，稱為欄位，每個欄位各有名稱和型別。

## 1. 建立一台遙控車

- 建立一個新的 [struct][struct] 並填入欄位，但 `distance` 除外。
- 建立一個函式，回傳新建 struct 的型別，並據此更新欄位。

## 2. 建立一條賽道

- 定義一個新的 [struct][struct]，包含 1 個欄位。
- 建立一個函式，回傳新建 struct 的型別，並據此更新欄位。

## 3. 駕駛這台車

- 新增一個欄位來追蹤已行駛的距離。
- 你需要檢查電池電量是否足以驅動這台車。

## 4. 檢查遙控車是否能跑完比賽

- 假設這台車才正要開始比賽。
- 你需要計算在目前電量下，這台車最多能行駛多遠。
- 這台車能行駛的次數可以用 `battery / batteryDrain` 計算。
- 這台車能行駛的最大距離，是它的速度和可行駛次數的乘積。
- 知道這台車能行駛的最大距離後，將它與賽道的距離相比較。
