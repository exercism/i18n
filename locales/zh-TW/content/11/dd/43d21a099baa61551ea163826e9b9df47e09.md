# 指令

你在布拉格伏爾塔瓦河畔經營一個小小的氣象站，每次值班你都會把溫度讀數記進純文字日誌，一行一筆讀數。五個簡短的字詞就能處理一整班的記錄工作。

每個字詞都會收到日誌檔的路徑。

## 1. 讀取每一筆讀數

定義`read-readings`，回傳日誌中所有的讀數，以字串陣列的形式呈現，一行一個。

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. 找出最新的讀數

定義`latest-reading`，回傳最近的一筆讀數，也就是日誌的最後一行。

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. 讀取原始日誌

定義`log-text`，把整份日誌檔以單一字串回傳，內容與儲存時完全相同。

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. 記錄一筆讀數

定義`record-reading`，在日誌結尾附加一筆新讀數，讓它自成一行，先前的讀數保持不變。不回傳任何東西。

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. 重寫日誌

定義`rewrite-log`，用全新的讀數陣列取代整份日誌，一行一筆。

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
