# 關於

## 陣列疊代

`for`迴圈可以疊代陣列，並為每個元素重複執行程式碼：

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

在上面的例子中，`fruit`是變數，用來存放陣列`fruitList`中單一元素的值。編譯器會確保`fruitList`可以被疊代，否則就會停止執行。

## 範圍疊代

你可以使用範圍運算子來疊代數字。這個運算子接受兩個`Int`運算元，寫成`min...max`。`min`包含在內，`max`則不包含（`min` <= i AND `max` > i）

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## 鍵值疊代

你也可以疊代由鍵值對組成的集合。語法上唯一的差別在於，這裡不使用單一變數，而是先寫鍵的變數識別字，接著是`=>`，然後是值的變數識別字：

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
