# 說明

## Cairo 安裝

請參閱 [Exercism 說明頁面][help-page]，了解如何安裝 Cairo 以及相關的學習資源。

## 提交解答

一般來說，你應該提交所有用來實作解答的檔案（多數情況下是`src/lib.cairo`）。如果你使用了任何外部 crate，請考慮一併提交`Scarb.toml`檔案。這會讓審查流程更快、更清楚。

## 意見回饋、問題與 Pull Request

GitHub 上的 [track 儲存庫][github]是存放所有 Cairo 練習的地方。如果你對某個練習有任何意見回饋，或想協助實作新的練習，歡迎前往該處建立 issue。Cairo track 團隊的成員都很樂意幫忙喔！

如果你想更了解 Exercism，可以看看[貢獻指南]。

## 提交未完成的解答

你可以提交未完成的解答，這樣就能看看其他人是怎麼完成這個練習的。
