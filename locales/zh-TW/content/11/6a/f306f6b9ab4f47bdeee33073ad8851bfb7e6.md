# 關於

`TUPLE:` 會宣告一個帶有具名欄位的類別。Factor 會自動產生一個建構子詞彙（類別名稱加上`new`後綴）、一個`boa`建構子（依引數順序）、一種字面語法`T{ class … }`，以及每個欄位各自的存取子詞彙。

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

[`accessors`][accessors] 中的存取子系統為每個欄位提供四種形式：`name>>`、`>>name`、`change-name`，以及成對變更的`[ … ] change-name`。`>>name` 和 `change-name` 會變更這個元組；若想讓原始元組保持不變，請先`clone`。

元組支援以結構相等比較的`=`，列印時則會顯示非預設的欄位值。

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
