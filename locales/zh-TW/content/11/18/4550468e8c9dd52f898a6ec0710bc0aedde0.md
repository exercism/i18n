# 說明

HTTP 端點加上型別檢查會更好。為 POST 請求加上 Record 型別，就能確保每次傳送的資料都正確。

## 目標

- 修改提供的程式碼。
- 為這個 Record 加上必要的屬性，讓它能接受兩個運算元和一個運算子。
- 新增一個 HTTP 資源函式，用來接受路徑 '/calc' 上的 POST 請求。
- 這個函式應該接受 Calculation record 型別作為酬載，並回傳一個泛型的 JSON 物件。

### 接受

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### 回傳

```json
{ "expression": "4+10.2", "result": 14.2 }
```
