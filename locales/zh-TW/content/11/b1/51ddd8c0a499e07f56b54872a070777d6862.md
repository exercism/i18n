# 指令補充

複數的冪運算需要指數函式、正弦函式和餘弦函式，而這些在 WebAssembly 裡全都無法使用。幸運的是，我們可以用[泰勒級數](https://en.wikipedia.org/wiki/Taylor_series)來計算這些函式。你至少需要 `1/26!` 的精確度，才能與預期值相符。

## 指數函式

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## 正弦函式

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## 餘弦函式

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
