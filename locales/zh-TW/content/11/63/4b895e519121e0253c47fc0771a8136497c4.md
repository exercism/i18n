# 說明補充

## 例外訊息

有時候，你需要[拋出例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，你應該一律附上**有意義的錯誤訊息**，指出錯誤的來源是什麼。這能讓你的程式碼更容易閱讀，對除錯也有很大的幫助。如果你知道錯誤的來源會是某個特定類型，可以選擇拋出其中一種[內建錯誤類型](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然應該附上有意義的訊息。

這個練習特別要求你使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在未遵守計分或投球規則時「拋出」錯誤。只有同時`raise`了`exception`並附上訊息，測試才會通過。

若要拋出帶有訊息的`ValueError`，請把訊息寫成`exception`類型的引數：

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
