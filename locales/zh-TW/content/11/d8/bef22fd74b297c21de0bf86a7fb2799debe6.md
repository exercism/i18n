# 說明

你是某艘穿越白令海峽之巡邏艦上的值更官。三個來源正在報出視野內每一塊浮冰與岬角的位置：

- **海圖桌**使用羅盤方位發話：`north`、`east`、`south`、`west`。只有航向，沒有距離。
- **航海官**使用以巡邏艦上一次定位為基準的*極座標*發話：以海里為單位的量值，以及從北方順時針計算的方位角（所以`0`是北方、`90`是東方、`180`是南方、`270`是西方）。
- **桅頂瞭望員**使用*相對*座標發話：一個向前的距離，以及`ahead`、`starboard`、`behind`、`port`其中之一。

相對方位是以*船艦目前的航向*為基準量測的，船長會在每次值更前，於艦橋上宣布該航向。

你的任務是把這三者都轉換成共同的笛卡兒`(x, y)`座標系，以便在海圖上標繪。方位以度為單位；`(0, 1)`是往北一海里，`(1, 0)`是往東一海里。

## 1. 資料模型，以及基本方位的笛卡兒座標

首先，先把整個練習共用的部分定義出來：

- 定義三個元組：`cardinal`（一個欄位，`direction`）、`polar`（欄位`magnitude`與`bearing`），以及`relative`（欄位`distance`與`bearing`）。
- 用`SYMBOLS:`宣告航向符號：`north`、`east`、`south`、`west`、`ahead`、`starboard`、`behind`、`port`。
- 用`SYMBOL:`宣告一個動態變數`heading`（任務 3 會用到它）。
- 宣告兩個泛型詞，分別是`GENERIC: >cartesian ( direction -- x y )`與`GENERIC: flip ( direction -- direction' )`。你會在接下來幾個任務中為它們加入方法。

接著為`>cartesian`加入`M: cardinal`方法，回傳指定方向的單位向量。

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. 極座標的笛卡兒座標

為`>cartesian`加入`M: polar`方法，把極座標形式轉換成`(x, y)`：

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. 相對座標的笛卡兒座標

為`>cartesian`加入`M: relative`方法。麻煩的地方在於：相對方位是以船艦的*目前航向*為基準量測的，而這個航向並不屬於該元組。用`heading get`讀取（任務 1 宣告的）`heading`變數，加上方位偏移（`ahead = 0`、`starboard = 90`、`behind = 180`、`port = 270`），再產生笛卡兒座標點。呼叫端會在`with-variable`區塊內設定`heading`。

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. Flip

加入`flip`泛型（在任務 1 宣告）的方法，讓它回傳相反的方向。

- `cardinal`：north ↔ south、east ↔ west。
- `polar`：把方位角加上 180°（取 360 的模）。
- `relative`：ahead ↔ behind、starboard ↔ port。

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. 相加方位

定義`add-bearings ( a b -- x y )`，把兩個方向都轉換成笛卡兒座標並回傳它們的和。它適用於`cardinal`、`polar`與`relative`的任意組合，這正是把`>cartesian`寫成泛型所帶來的好處。

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
