# 說明

在完成的踩地雷盤面上加入地雷數量。

踩地雷是一款熱門遊戲，玩家要利用數字提示找出地雷，這些提示會指出與某個方格直接相鄰（水平、垂直、對角）的地雷有幾顆。

在這道練習中，你要寫一段程式碼，計算與某個空格相鄰的地雷數量，並把該方格換成這個數量。

盤面是一個由空白字元（' '）組成的長方形。地雷以星號（'\*'）字元表示。

若某個空格周圍完全沒有地雷，就讓該方格保持空白。

## 範例

例如你可能會收到像這樣的 5 x 4 盤面（這裡用 '·' 字元代表空格，方便在螢幕上顯示）：

```
·*·*·
··*··
··*··
·····
```

你的程式碼會把它轉換成這樣：

```
1*3*1
13*31
·2*2·
·111·
```
