# 軌道工具

軌道工具分為兩種類型：

- 正式環境：為該語言的學習體驗扮演關鍵角色
- 維護：協助軌道的維護

工具通常（大致上）以該軌道的語言撰寫，並由維護者建置與維護。

## 正式環境工具

這些工具在 Exercism 的正式環境伺服器上執行。

### 軌道專用的正式環境工具

軌道專用的正式環境工具有三種：

- **[測試執行器](/docs/building/tooling/test-runners)**（必備）
- **[表徵器](/docs/building/tooling/representers)**（選用）
- **[分析器](/docs/building/tooling/analyzers)**（選用）

### 一般正式環境工具

有兩種一般正式環境工具可以為你的軌道設定：

- **[程式碼行數計數器](/docs/building/tooling/lines-of-code-counter)**（選用）
- **[程式碼片段擷取器](/docs/building/tooling/snippet-extractor)**（選用）

### 部署

正式環境工具會建置成 Docker 映像檔。
它們會透過 CI 工作流自動部署到 Exercism 的正式環境伺服器。

## 維護工具

維護工具的目的是協助維護軌道。
它們通常在本機執行（在維護者或貢獻者的電腦上），有時在 CI 中執行，但絕不會在正式環境執行。

以下是維護工具的一些例子：

- **[測試產生器](/docs/building/tooling/test-generators)**

## 實作

軌道工具通常（大多）以該軌道的語言撰寫。

```exercism/caution
你當然可以自由使用其他語言，但每多一種語言，都會讓軌道的維護或貢獻變得更加困難。
因此，我們建議盡量使用該軌道的語言，因為這樣會讓維護和貢獻更容易。
```
