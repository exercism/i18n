# 關於

Clojure 的標準資料型態全都是不可變的，因此它提供了*參考型別*，讓你以可控的方式變更值。這些型別當中最簡單、也最常用的一種叫做 Atom。

Atom 是用 `atom` 函式建立的，它會接受一個初始值：

```clojure
(def players (atom ()))
```

用 `deref` 或 `@` 簡寫就能取出 atom 目前的值：

```clojure
@players
;;=> ()
```

你可以用 `swap!` 修改 `players` atom 目前的值，它會套用一個函式來更新值：

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!` 函式則會直接取代 atom 的值，不管它目前的值是什麼：

```clojure
(reset! players ())
```
