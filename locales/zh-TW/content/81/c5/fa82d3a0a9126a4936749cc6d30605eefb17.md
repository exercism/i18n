# 指令

鎮上新開了一間詩社，你正考慮要不要去參加。
由於過去發生過一些狀況，這間詩社有一套非常講究的入場規定，你得先摸熟這套規定，才能嘗試進場。

詩社有兩道門，一道前門、一道後門，兩邊都有人看守。
想進門，你得先推算出當天的密碼。

密碼一律以一首詩為依據，可以透過兩個步驟推導出來。

1. 警衛會一次朗誦一行詩，你要針對那一行回覆對應的字母。
2. 接著警衛會一次把你回覆過的所有字母告訴你，你要用特定格式把它們寫在一張紙上。

流程的細節取決於你想走哪一道門。

~~~~exercism/note
這個練習中的所有字串都是 ASCII 編碼，並以 NUL 結尾。
這代表所有字元都採用 ASCII 編碼，而且每個字串在遇到 `'\0'`（NUL 字元，值為`0`）時就結束。
~~~~

~~~~exercism/note
以下是這個概念中介紹的字串指令：

| 指令  | 作用                                                                                                      |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | 從 `rsi` 所指的記憶體位置載入一個值到 `rax`                                                |
| `stos`       | 把 `rax` 中的值存入 `rdi` 所指的記憶體位置                                               |
| `movs`       | 從 `rsi` 所指的記憶體位置複製一個值，並存入 `rdi` 所指的記憶體位置    |

這些指令都必須加上後綴，用來指出操作的長度：

| 後綴 | 大小             |
|--------|------------------|
| `b`    | 位元組             |
| `w`    | 字組（2 位元組）   |
| `d`    | 雙字組（4 位元組）  |
| `q`    | 四字組（8 位元組）  |

所有字串指令也會修改`rsi`和／或`rdi`中的位址（只限該指令會用到的那些暫存器）。
預設情況下，它們會依操作的大小遞增位址。

上述任何字串指令都可以加上`rep`前綴，讓它重複執行，次數等於`rcx`。
~~~~

## 1. 取得句子的第一個字母

要決定前門密碼的字母，你得回覆警衛朗誦給你的那一行詩的第一個字母。

為了讓密碼好看，詩社成員喜歡用_藏頭詩_。
這代表每個句子的第一個字母會拼成一個單字。
以下是他們最喜歡的作家之一 Michael Lockwood 的作品範例。

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

所以當警衛朗誦**Stands so high**時，你要回覆**S**；當警衛朗誦**Huge hooves too**時，你要回覆**H**。

實作`front_door_response`函式，它接受詩中某一行的記憶體位址作為引數，並回傳該行的第一個字母。
這個字母必須以 ASCII 編碼的字元回傳，佔 1 個位元組。

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. 調整單字的大小寫

現在你已經拿到所有正確的字母了，接下來只要把這個單字的大小寫調整正確，就能得到前門的密碼。

實作`front_door_password`函式，它接受一個字串的記憶體位址作為引數，這個字串只包含你在第 1 個任務中找到的字母組合。
它應該[就地][in-place]修改輸入字串，使它的大小寫正確。
也就是說，調整正確後的字串要存放在和輸入相同的記憶體位置上。

這個函式沒有回傳值。

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. 取得句子的最後一個字母

要決定後門密碼的字母，你得回覆警衛朗誦給你的那一行詩的最後一個字母。

詩社的成員真的很聰明。
前面提到的那首詩同時也是_藏尾詩_，意思是每個句子的最後一個字母也會拼成一個單字：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

當警衛朗誦**Stands so high**時，你要回覆**h**；當警衛朗誦**Huge hooves too**時，你要回覆**o**。

注意，警衛朗誦時有時會為了風格而停頓（形式可能是標點或空白）。
你需要忽略這些停頓，才能推出正確的字母。

實作`back_door_response`函式，它接受詩中某一行的記憶體位址作為引數，並回傳該行的最後一個字母。
這個字母必須以 ASCII 編碼的字元回傳，佔 1 個位元組。

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. 要有禮貌

想從後門進入詩社，你得格外有禮貌。
所以要推出密碼，這次你得把單字的大小寫調整正確，並在結尾加上`", please."`。

實作`back_door_password`函式，它依序接受下列引數：

1. 用來存放結果字串的緩衝區的記憶體位址。
2. 包含你在第 3 個任務中找到的字母組合的字串的記憶體位址。

這個函式應該把大小寫調整正確後的禮貌版密碼存入[緩衝區][buffer]。
_緩衝區_是一個陣列，可以用來在記憶體中存放值，以便在不同函式之間傳遞。

這個函式沒有回傳值。

```c
back_door_password("horse");
// => "Horse, please."
```

[in-place]: https://en.wikipedia.org/wiki/In-place_algorithm
[buffer]: https://en.wikipedia.org/wiki/Data_buffer
