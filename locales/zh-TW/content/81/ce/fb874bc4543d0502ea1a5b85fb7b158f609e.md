# 提示

## 一般

- [無法復原的錯誤][unrecoverable]：以錯誤訊息觸發 panic。
- [`panic!` 巨集][panic-excl-macro]：以`ByteArray`錯誤訊息觸發 panic。
- [`assert!` 巨集][assert]：當條件求值為`false`時觸發 panic。
- [Result 列舉][result]：如何使用`Result`列舉。

## 2. 處理不合法的運算

- 你需要在這裡[回傳錯誤][result]。

## 3. 處理未提供運算的情況

- 你需要在這裡[panic][panic-excl-macro]，並附上`ByteArray`訊息，來處理運算的空字串。

## 4. 處理除以零的錯誤

- 你需要在這裡 panic，以處理除以零的情況。
