# 關於

`Bool` 型別是這門語言的基礎積木之一。它的用途是描述某件事是真的還是假的，分別對應`True`和`False`這兩個值。`Bool`這個名稱是 Boolean（布林）的縮寫，Boolean 是數學中與邏輯思考相關的一個領域，得名於 George Boole 的研究。

## 布林運算子

有兩個函式和兩個運算子可以操作`Bool`型別的值。

- `not : Bool -> Bool`
  這個函式會把`True`變成`False`，並把`False`變成`True`。
- `(&&) : Bool -> Bool -> Bool`
  這個稱為「AND」的運算子接收兩個布林值，若兩者都是`True`就回傳`True`。例如`True && True`會回傳`True`，但`True && False`會回傳`False`。
- `(||) : Bool -> Bool -> Bool`
  這個稱為「OR」的運算子接收兩個布林值，只要其中至少有一個是`True`就回傳`True`。例如`False || False`會回傳`False`，但`True || False`會回傳`True`。
- `xor : Bool -> Bool -> Bool`
  這個稱為「XOR」的函式（不是運算子）接收兩個布林值，若且唯若其中一個是`True`、另一個是`False`時，回傳`True`。

`&&`和`||`運算子的優先順序不同。`&&`的優先順序比`||`高，就像乘法`*`和加法`+`一樣。因此，運算式`True || False && False`等同於`True || (False && False)`，不同於`(True || False) && False`。前者會回傳`True`，後者則回傳`False`。

## 條件分支

布林值在建立程式碼分支時極為好用，這些分支只在符合特定條件時才會執行。在 Elm 中，這是用`if-then-else`運算式做到的，用法如下。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

`someCondition`這個值可以是任何回傳`Bool`的運算式。若這個布林值是`True`，程式碼就會執行`doSomething`。否則它就是`False`，程式碼會執行`doSomethingElse`。與某些其他程式語言不同，這裡的`else`分支是必要的。

如果你需要串接多個條件，只要把`if-then-else`運算式一層層串起來就行了。

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
