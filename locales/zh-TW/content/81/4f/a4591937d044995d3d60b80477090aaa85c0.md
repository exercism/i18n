# 介紹

## 整數

Elixir 裡有兩種不同的數字：整數和浮點數。

整數就是沒有小數的數字。

```elixir
integer = 3
# => 3
```

## 浮點數

浮點數是指小數點後還有一或多位數字的數字。它們採用 64 位元雙精度浮點格式。

```elixir
float = 3.45
# => 3.45
```

### 處理數字

在[`Integer`][integer-functions]和[`Float`][float-functions]模組中，你可以找到一些處理這些型別的實用函式。基本的算術運算子則定義在[`Kernel`][kernel-arithmetic-operators]模組裡。

### 轉換

整數和浮點數可以在同一個算術運算式中混用。在運算式中使用浮點數，能確保結果也會是浮點數。

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

不過，進行除法時，結果一定都是浮點數，即使只用到整數也一樣。

```elixir
6 / 2
# => 3.0
```

要把浮點數轉成整數，可以用[`trunc/1`][trunc-1]捨去小數部分。
