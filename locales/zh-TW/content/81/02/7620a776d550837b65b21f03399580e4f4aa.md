# 說明

你是一位熱衷的賞鳥愛好者，會記錄過去七天有多少鳥飛到你的花園。

你有六個任務，全都和造訪你花園的鳥的數量有關。

## 1. 查看上週的計數

為了方便比較，你總是會在身邊留一份上週的計數，分別是：0、2、5、3、7、8 和 4。請實作（_static_）`BirdCount.LastWeek()`方法，回傳上週的計數：

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 查看今天有多少鳥來訪

請實作`BirdCount.Today()`方法，回傳今天有多少鳥造訪你的花園。鳥的計數是按日期排序的，第一個元素是最早那天的計數，最後一個元素則是今天的計數。

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. 增加今天的計數

請實作`BirdCount.IncrementTodaysCount()`方法，將今天的計數加一：

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. 檢查是否有某天沒有任何鳥來訪

請實作`BirdCount.HasDayWithoutBirds()`方法，如果有某一天沒有任何鳥造訪花園，就回傳`true`；否則回傳`false`：

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. 計算前幾天來訪的鳥數

請實作`BirdCount.CountForFirstDays()`方法，回傳從這週開始以來造訪你花園的鳥數，但只計算從這週開始算起的指定天數。

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. 計算忙碌的天數

有些日子比其他日子更忙碌。所謂忙碌的一天，是指有 5 隻或更多鳥造訪你的花園。
請實作`BirdCount.BusyDays()`方法，回傳忙碌的天數：

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
