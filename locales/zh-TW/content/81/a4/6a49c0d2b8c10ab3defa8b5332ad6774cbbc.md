在這份練習中，你會寫一些程式碼，幫助你依照最愛的食譜書做出美味的千層麵。

你有四個任務，全都和烹調千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（以分鐘計）

定義`expected_minutes_in_oven()`函式，它不接受任何參數，並回傳千層麵應該待在烤箱裡幾分鐘。根據食譜書，預期的烤箱時間是 60 分鐘。

```r
> expected_minutes_in_oven()
[1] 60
```

## 2. 計算剩餘的烤箱時間（以分鐘計）

定義`remaining_time_in_minutes`函式，它把千層麵實際已經待在烤箱裡的分鐘數當作參數，並根據上一個任務算出的預期烤箱時間，回傳千層麵還需要待在烤箱裡幾分鐘。

```r
> remaining_time_in_minutes(50)
[1] 10
```

## 3. 計算準備時間（以分鐘計）

定義`prep_time_in_minutes()`函式，它把你加在千層麵裡的層數當作參數，並回傳你準備千層麵花了幾分鐘，假設每一層要花你 2 分鐘準備。

```r
> prep_time_in_minutes(2)
[1] 4
```

## 4. 計算經過的時間（以分鐘計）

定義`elapsed_time_in_minutes`函式，它接受兩個引數：第一個引數是你加在千層麵裡的層數，第二個參數是千層麵已經待在烤箱裡的分鐘數。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間的分鐘數，加上千層麵當下已經待在烤箱裡的分鐘數的總和。

```r
> elapsed_time_in_minutes(3, 20)
[1] 26
```
