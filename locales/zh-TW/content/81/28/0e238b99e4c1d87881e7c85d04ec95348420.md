# 關於

在 Rust 中，方法是為 struct（或 `enum`、`trait` 物件）定義的函式。這改變了呼叫的模式：方法不是寫成 `frobnicate(foo)`，而是以 `foo.frobnicate()` 呼叫。

方法與函式很相似：它們以 `fn` 關鍵字宣告，有名稱，也可以有參數和回傳值。

和函式不同的是，方法的第一個參數一定是 `self`（或它的變體），代表呼叫這個方法時所作用的那個 struct 實例（詳見下文）。

我們來為霍格華茲的學院建立一個 `enum`，再建立一個描述巫師 `age` 和 `house` 的 `struct`：

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## 定義方法

要為 struct `Wizard` 定義方法，我們要先為 `Wizard` 開啟一個 `impl` 區塊（implementation 的縮寫）。

```rust
impl Wizard { }
```

這個 `impl` 區塊裡的所有內容都會關聯到 `Wizard` 型別。附帶一提，一個 struct 可以有多個 `impl` 區塊。

### 使用 `self`

方法的第一個參數必須是名為 `self`、型別為 `Self` 的參數。型別 `Self` 是這個 `impl` 區塊所對應型別的別名。在我們的例子中，`Self` 代表 `Wizard`。

為了方便，Rust 允許我們在第一個參數的位置只寫 `self` 來省略型別。方法常見的 `self` 型別包括：

- `self`：是 `self: Self` 的縮寫。單獨寫 `self` 的簽名會消耗實例。
- `&self`：是 `self: &Self` 的縮寫。這會以不可變的方式借用實例。
- `&mut self`：是 `self: &mut Self` 的縮寫。這會以可變的方式借用實例。

在更進階的程式碼中，你可能還會看到 `self: Pin<&self>`、`self: Rc<Self>` 之類的簽名。不過這超出了本教學的範圍。

### 定義使用 `&self` 的方法

如果我們想實作一個 `info` 方法來顯示巫師的基本資料，可以在 `Wizard` 的 `impl` 區塊裡定義這個方法：

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

注意，在 `info` 的簽名中，我們用 `&self` 以不可變的方式借用實例。這樣一來，我們就能讀取 `Wizard` 實例的 `age` 和 `house` 欄位，而不會修改它們。如果我們改用會消耗實例的 `self` 而不是借用，那麼方法呼叫之後就無法再取用這個實例了。

實作好 `info` 方法之後，我們就能印出巫師的基本資料：

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### 定義使用 `&mut self` 的方法

如果我們想實作一個會修改 struct 實例欄位的方法，就要在方法的簽名中用 `&mut self` 以可變的方式借用實例。

假設我們想在霍格華茲訂一條新規定，允許學生轉換學院。我們可以像下面這樣實作一個 `switch_house` 方法：

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

現在我們就能幫在霍格華茲就讀的巫師轉換學院了：

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## 多個「impl」區塊

在 Rust 中，每個項目都可以有多個 `impl` 區塊。所以我們可以把所有方法都放在同一個 `impl` 區塊裡，也可以針對不同的方法群組使用多個 `impl` 區塊。這兩種寫法在語法上都成立，不過典型的專案組織方式，是針對每一組不同的 `impl` 層級 `where` 界限各用一個 `impl` 區塊。

## 關聯函式

我們可以在 `impl` 區塊裡定義沒有 `self` 參數的函式。因為它們少了 `self` 參數，所以不算方法。不過它們仍然和被實作的型別關聯在一起，而且呼叫時要寫出該型別的名稱。基於這個理由，它們被稱為關聯函式（或型別關聯函式）。

你已經看過一些關聯函式了，例如 `String::from()`：

```rust
let some_string = String::from("This is an associated function but not a method");
```

建構子經常以關聯函式的方式實作。我們來建立一個關聯到 `Wizard` 型別的 `new` 函式：

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

注意，我們可以用 `Self` 代替 `Wizard` 來表示函式要回傳的型別。並非一定要這樣使用 `Self` 型別別名，但對於名稱複雜或冗長的型別來說，它可以簡化實作。現在我們可以執行下面這段：

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
