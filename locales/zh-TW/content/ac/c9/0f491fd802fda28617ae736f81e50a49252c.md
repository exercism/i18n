# 簡介

函式能讓你將程式碼組成可重複使用的單位。
它由`func`關鍵字、函式的名稱，以及以小括號包住、以逗號分隔的零個或多個參數和型別所組成。

## 函式參數

所有參數都必須明確標註型別；參數沒有型別推斷。
參數也沒有預設值，所以所有函式參數都是必填的。

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

型別相同的參數可以一起宣告，後面接著單一的型別宣告。

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 參數與引數

讓我們快速說明兩個經常被混為一談的詞：`parameters`和`arguments`。
函式參數是定義在函式簽章中的名稱，例如上方`PrintGreetingName`函式中的`greeting`和`name`。
函式引數則是我們呼叫函式時，實際傳給函式參數的具體值。
例如，在下面的範例中，`"Hello"`和`"Katrina"`就是傳給`greeting`和`name`參數的引數：

```go
PrintGreetingName("Hello", "Katrina")
```

## 回傳值

函式參數之後接著零個或多個回傳值，這些回傳值也必須明確標註型別。
單一的回傳值不加括號，多個回傳值則以括號包住。
函式使用`return`關鍵字將值回傳給呼叫端的程式碼。
一個函式中可以有多個`return`敘述。
函式的執行會在遇到其中一個`return`敘述時立刻結束。
如果要從函式回傳多個值，值與值之間以逗號分隔。

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 呼叫函式

呼叫函式時，要指定函式名稱，並在小括號中為函式的每一個參數傳入引數。

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 具名回傳值與裸回傳

除了參數之外，回傳值也可以選擇性地命名。
如果使用了具名回傳值，那麼不帶引數的`return`敘述就會回傳這些值。
這就是所謂的「裸回傳」。

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## 傳值與傳參考

釐清傳值與傳參考的概念也很重要。

首先，讓我們釐清傳值。
在下面的範例中，當我們把變數`val`傳給函式`MultiplyByTwo`時，傳入的是`val`的複本。
因此，`newVal`會是更新後的值`4`，但原始的變數`val`仍然是`2`。
在背後，Go 基本上會複製原始值，因此只有這個複本（也就是`v`）會被函式修改。

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

嚴格來說，在 Go 中所有引數都是傳值，也就是會複製提供給函式的值或資料。
但如果你不想複製傳入函式的資料，並且想在函式中修改這些資料，
就應該改用`pointers`作為引數，也就是傳參考。

## 指標

我們使用`pointer`來達成傳參考。
將`pointer`引數傳入函式之後，
我們就能修改傳入函式的底層資料，而不只是對資料的複本進行操作。

目前你只需要知道，指標型別可以透過函式簽章中型別前面的`*`來辨認。

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

如果`pointer`的概念讓你感到困惑，別擔心。
我們在課程大綱後面的內容有專門的章節，可以幫助你精通指標。

## 例外

請注意，`slices`和`maps`是上述規則的例外。
當我們把`slice`或`map`當作引數傳入函式時，即使型別中沒有明確的`*`，它們也會被視為指標型別。
這表示如果我們把 slice 或 map 傳入函式並修改其底層資料，
這些變更會反映在原始的 slice 或 map 上。
