# 說明

判斷一個三角形是 equilateral、isosceles 還是 scalene。

_equilateral_ 三角形的三條邊長度都相同。

_isosceles_ 三角形至少有兩條邊的長度相同。
（有時會規定它必須恰好有兩條邊等長，但就這個練習而言，我們說至少有兩條就好。）

_scalene_ 三角形的三條邊長度都不相同。

## 注意

一個圖形要能算是三角形，每一條邊的長度都必須大於 0，而且任兩條邊的長度之和必須大於或等於第三條邊的長度。

用方程式表示：

設 `a`、`b`、`c` 為三角形的三條邊。
那麼以下三個運算式都必須成立：

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```
