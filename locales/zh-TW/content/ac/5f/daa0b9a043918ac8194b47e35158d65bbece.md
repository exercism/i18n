# 提示

## 一般

- `H{ } clone` 是建立全新、可變雜湊表的正確做法，`H{ }` 字面值可能會在呼叫之間共用。
- 來自 [`assocs`][assocs] 的 `inc-at` 會將鍵的值加 1（若鍵不存在，則以 1 插入）。

## 1. 從一個陣列建立庫存

- 先從 `H{ } clone` 開始，並對每個元素使用 `inc-at`。fry 的 quotation `'[ _ inc-at ]` 會捕捉該雜湊表，讓你得以透過 `each` 傳遞它。
- 將疊代包在 `[ … ] keep` 裡，讓雜湊表成為留在堆疊上的值。

## 2. 新增更多項目

- 結構與任務 1 相同，差別在於你是從輸入庫存的 `clone` 開始，而不是從空的庫存開始。

## 3. 遞減計數

- 先使用 `key?`，只有已經在庫存中的項目才會被更動。
- `change-at` 接受一個 quotation `( old -- new )`，將它與 `[ 1 - 0 max ]` 搭配使用（`max` 來自 [`math.order`][math.order]），讓計數永遠不會變成負數。

## 4. 完全移除某個項目

- `delete-at` 會修改雜湊表且不回傳任何東西。請先 `clone`，再 `delete-at`，然後將 clone 留在堆疊上。

## 5. 列出可用的項目

- `>alist` 會將雜湊表轉換成由鍵值對組成的序列。
- `[ second 0 > ] filter` 只保留有庫存的項目。
- `sort-keys`（位於 [`sorting`][sorting]）會依鍵為 alist 排序。

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
