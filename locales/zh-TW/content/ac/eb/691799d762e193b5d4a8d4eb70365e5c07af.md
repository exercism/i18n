# 指令

Bob 是一位財務顧問，協助人們管理支出。
Bob 的客戶會把支出記錄寄給他分析。
Bob 手上有先前期間的記錄，因此能看出花費的變化。
Bob 不喜歡行事曆，所以改用 *Bob epoch* 來取代日期。
Bob epoch 是從 Bob 的客戶開始活動起算，已經過的天數。

在這個練習中，你將打造一支程式，協助 Bob 管理和分析客戶的支出。

Bob 處理的是`Record`和`DaysPeriod`。

一筆`Record`代表一筆支出記錄，其中包含這筆支出發生的日期、花費的金額，以及這筆支出的類別。

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

一個`DaysPeriod`代表一段日期範圍，涵蓋從 `From` 這天到 `To` 這天的所有日期。
範圍的兩端都包含在內。

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. 實作通用的記錄篩選器

Bob 每天都要處理大量記錄，但根據他正在做的分析，並不是每一筆都有意義。
我們來幫 Bob 對記錄做一些基本的篩選吧。

實作泛型的`Filter`函式，依照某個函式給定的條件來篩選記錄。
這個篩選函式接受一組記錄和一個述語函式，只回傳集合中符合述語的那些記錄。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. 篩選特定期間內的記錄

Bob 經常需要篩選落在特定期間內的記錄。

實作`ByDaysPeriod`函式，幫助 Bob 建立這類篩選器。
這個函式接受一個`DaysPeriod`，並回傳一個函式；該函式接受一筆記錄，並判斷這筆記錄是否落在引數所給的`DaysPeriod`指定的期間內。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. 依類別篩選記錄

除了依期間篩選記錄，Bob 也需要依類別篩選記錄。

實作`ByCategory`函式，幫助 Bob 建立這類篩選器。
這個函式接受一個類別，並回傳一個函式；該函式接受一筆記錄，並判斷這筆記錄的類別是否和引數所給的類別相同。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. 計算某期間內的支出總額

Bob 也想知道某段期間內的支出總額。

實作`TotalByPeriod`函式，回傳該日期期間內的支出總和。

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. 計算某期間內某類別記錄的支出總額

對 Bob 提供給客戶最複雜的報告來說，Bob 需要同時依類別和期間來篩選記錄。
也就是說，Bob 想知道特定期間內某類別記錄的支出總額。

實作`CategoryExpenses`函式，回傳特定期間內某類別的支出總額。
這個函式還必須區分兩種情況：給定的類別不存在於支出記錄中，以及提供的期間內沒有該類別的支出。
當某個類別不是任何一筆記錄的類別時（不論期間為何），這個函式應該回傳錯誤。

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
