# 說明

你正在開發一套健康監測系統。其中一項工作，就是追蹤使用者的健康統計資料。

你會先從`impl`區塊裡幾個預留的函式，以及下面這個 struct 定義開始：

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

你的目標是實作`impl`區塊中`User` `struct`那些尚未完成的方法。

例如，`new`方法應該回傳一個`User` `struct`的實例，其中包含指定的 name、age 和 weight 值。

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

`weight`方法應該回傳`User`的 weight 值。

```rust
bob.weight();
// Returns: 72
```

`set_age`方法應該設定`User`的 age 值。

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
