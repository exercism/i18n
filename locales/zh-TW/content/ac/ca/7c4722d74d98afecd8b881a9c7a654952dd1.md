# 簡介

某個事物能夠用自身來定義，這種能力就叫做遞迴。在 Gleam 裡，遞迴最常出現在遞迴函式中，也就是會呼叫自己的函式。

一個遞迴函式至少需要一個_基本情況_，以及至少一個_遞迴情況_。_基本情況_會回傳一個值，而不會再次呼叫函式。_遞迴情況_則會再次呼叫函式，並修改輸入，讓它終究會符合基本情況。

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam 沒有專門用來迴圈的語法，所以所有的迴圈都是靠遞迴完成的。

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam 也支援遞迴自訂型別。遞迴自訂型別會有一個或多個變體，在其所含的資料中參照型別自身。

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
