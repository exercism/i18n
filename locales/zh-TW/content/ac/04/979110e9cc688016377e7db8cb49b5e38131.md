# 所有權

在 Cairo 中，所有權的概念是附屬於_變數_，而不是變數所持有的_值_。

Cairo 中的值是不可變的，這種不可變性確保即使有許多變數參考同一個值，值本身仍保持不變且不會被更動。
因此，編譯器必須確保程式設計師正確地使用它們。
這就是變數_所有權_的意義：擁有者是能夠讀取（若為可變則可寫入）該變數的程式碼。

## 變數所有權規則

```console
1. Each variable in Cairo has an owner.
2. There can only be one owner at a time.
3. When the owner goes out of scope, the variable is destroyed.
```

## 變數作用域

作用域是程式中的一個範圍，在該範圍內變數是有效的。
我們來看看下面這個範例，它宣告了一個無號整數型別的變數`x`，並用註解標示變數在哪些地方有效：

```rust
fn main() {
                      // `x` is not valid here, it has not been declared yet
    let x: u32 = 3;   // `x` is declared, it is valid from this point forward
                      // do stuff with `x`

} // this scope ended here, `x` goes out of scope and is no longer valid
```

注意事項：

- 當`x`進入作用域時，它是有效的。
- 它會一直有效，直到離開作用域為止，在這個例子中就是直到`main()`函式結束。

## 移動值

當一個值被傳遞給另一個函式時，就會發生移動：原本參考該值的變數會被銷毀（因此該變數變得無法使用），並建立一個新變數來持有相同的值。

陣列就是一個例子，這種複雜型別在傳遞給另一個函式時會被移動。
這裡簡單回顧一下陣列的樣子：

```rust
    let mut arr: Array<u128> = array![];
    arr.append(1);
    arr.append(2);
```

型別系統如何確保 Cairo 程式永遠不會嘗試寫入同一個記憶體單元兩次？
看看下面這段程式碼，我們試著移除陣列的前端兩次：

```rust
fn foo(mut arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let arr: Array<u128> = array![1];
    foo(arr);
    foo(arr); // -> compiler error: Variable was previously moved.
}
```

在這個例子中，我們試著把同一個值（`arr`變數中的陣列）傳給這兩次函式呼叫。
這表示我們的程式碼試圖移除第一個元素兩次，也就是嘗試寫入同一個記憶體單元兩次，這是 Cairo VM 禁止的行為，會導致執行期錯誤。
幸好，這段程式碼其實無法編譯。
一旦我們把陣列傳給`foo`函式，`arr`變數就不能再使用了。

## Copy 特徵

如果某個型別實作了`Copy`特徵，把它傳給函式時並不會移動值，而是建立一個參考同一個值的新變數。
這是不需付出任何成本的操作，因為變數是 Cairo 的抽象，而值永遠是不可變的。

若要為你的型別實作`Copy`特徵，請在型別定義加上`#[derive(Copy)]`標註。
不過，如果該型別或它的任何組成部分沒有實作`Copy`特徵，Cairo 就不允許這麼做。

```rust
#[derive(Copy, Drop)]
struct Point {
    x: u128,
    y: u128,
}

fn main() {
    let p1 = Point { x: 5, y: 10 };
    foo(p1);
    foo(p1);
}

fn foo(p: Point) { // do something with p
}
```

## 銷毀值

線性型別也可以藉由被銷毀來使用，這能確保相關的資源被正確釋放。
這是透過實作或衍生`Drop`特徵來達成，它會向編譯器表示，該型別一旦不再有用，就可以安全地被銷毀。

```rust
#[derive(Drop)]
struct A {}

fn main() {
    A {}; // this value can be destroyed after going out of scope
}
```

目前，所有型別都可以衍生`Drop`實作，但字典（`Felt252Dict`）以及包含字典的型別除外。
這是因為字典在銷毀時必須被「squash」。
為此，我們衍生`Destruct`特徵：

```rust
#[derive(Destruct)]
struct A {
    dict: Felt252Dict<u128>
}

fn main() {
    A { dict: Default::default() };
}
```

## 回傳值與作用域

回傳值等同於移動值。
下面的範例展示了一個會回傳某個值的函式：

```rust
#[derive(Drop)]
struct A {}

fn main() {
    let a1 = gives_ownership();           // gives_ownership moves its return
                                          // value into a1

    let a2 = A {};                        // a2 comes into scope

    let a3 = takes_and_gives_back(a2);    // a2 is moved into
                                          // takes_and_gives_back, which also
                                          // moves its return value into a3

} // Here, a3 goes out of scope and is dropped. a2 was moved, so nothing
  // happens. a1 goes out of scope and is dropped.

fn gives_ownership() -> A {               // gives_ownership will move its
                                          // return value into the function
                                          // that calls it

    let some_a = A {};                    // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}

// This function takes an instance some_a of A and returns it
fn takes_and_gives_back(some_a: A) -> A { // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}
```
