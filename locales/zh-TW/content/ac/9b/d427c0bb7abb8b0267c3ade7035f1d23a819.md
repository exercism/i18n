# 使用`_is`和問號的 defmacro

[comment]: # (需要 3 個參數：)
[comment]: # (- actual：學生使用的不正確名稱)
[comment]: # (- option1：函式的正確名稱)
[comment]: # (- option2：守衛子句的正確名稱)

Elixir 有特定的命名慣例，其中包括如何命名[回傳布林值的函式](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)和[回傳布林值且可用於守衛子句的檢查](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)：

> 回傳布林值的函式，名稱以問號結尾。

> 型別檢查，以及其他可用於守衛子句的布林檢查，名稱則以 `is_` 開頭。

巨集在這兩種情境中都能使用，因此命名方式取決於情境，但兩種命名慣例不能混用。

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
