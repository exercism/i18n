# 不要使用日期值

請使用 [`Date#getTime`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime) 取代 [`Date#valueOf`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf)。兩者功能上完全相同，但 `valueOf` 被標記如下：

> 這個方法通常由 JavaScript 在內部呼叫，而不是在程式碼中明確呼叫。
