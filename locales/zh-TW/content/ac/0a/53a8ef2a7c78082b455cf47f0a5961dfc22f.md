# 產生器

`generator`是一種函式或運算式，會回傳一種特殊的[疊代器][iterator]，稱為[`generator iterator`][generator-iterator]。
`Generator-iterator`s 是[惰性][lazy iterator]的：它們不會把`values`存放在記憶體中，而是在需要時才_產生_值。

產生器函式和其他函式看起來沒什麼兩樣，但它包含一個或多個[yield 運算式][yield expression]。
每個`yield`都會暫停程式碼執行，並保存當下的執行狀態（_包含所有區域變數和 try 敘述_）。
當產生器恢復執行時，會從暫停的地方接續狀態，這點和每次呼叫都會重置的一般函式不同。


## 建立產生器

產生器的建構方式和其他迴圈或遞迴函式很像，但它需要一個[`yield`運算式](#the-yield-expression)，我們稍後會深入探討。

舉例來說，有個函式會從給定的數字陣列中回傳這些數字的_平方_。
以目前的寫法，必須先處理完所有輸入，才能回傳任何值：

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

你可以像這樣把那個函式改寫成產生器：

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

這麼做的理由是，當你不需要_一次_產生所有值時，就可以使用產生器。
這樣能節省記憶體和運算資源，因為只會計算你_目前正在處理_的那個值。


## 使用產生器

在 Python 中，產生器可以替代大多數的`iterables`。
這包括需要`iterable`/`iterator`作為引數的_函式_或_物件_。

如要使用`squares_generator()`產生器：

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

`generator`中的值也可以透過`next()`函式來產生或存取。
`next()`會呼叫產生器疊代器物件的`__next__()`方法，「推進」或求值程式碼直到它的`yield`運算式，接著「讓出」或回傳一個值：

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

當`generator-iterator`完全被取用完、沒有更多值可以回傳時，它會拋出`StopIteration`錯誤。

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

產生器疊代器是[疊代器][iterator]的一個特殊子集。
`Iterators`是讓我們能對_可疊代物件_進行迴圈的機制／協定。
產生器疊代器和常見 Python [`iterables`][iterables]所回傳的疊代器行為非常相似，但有幾個重要差異值得注意：

- 它們是_[惰性求值][lazy evaluation]_的；疊代是_單向_的，無法「退回」到前一個值。
- 它們會因為疊代回傳的值而被_取用_；不會重置，也不會保存在記憶體中。
- 它們無法排序，也無法反轉。
- 它們不是序列型態，而且_沒有_`indexes`。 
  你不能用加法或減法來參照前一個或未來的值，也不能使用方括號（`[]`）表示法或切片。
- 它們不能和`len()`函式一起使用，因為它們沒有長度。
- 它們可以是_有限_或_無限_的，從_無限_的`generator-iterator`收集所有值時請務必小心！

## yield 運算式

[yield 運算式][yield expression]和`return`運算式非常相似。
_不同於_`return`運算式，`yield`會在_特定時間點_把值交給呼叫者，並暫停其餘任何值的求值或回傳，直到有人要求它們為止。
當`yield`被求值時，它會暫停外層函式的執行，並_在當下_回傳函式的值。
接著函式會_繼續留在作用域中_，而當`__next__()`被呼叫時，執行會繼續進行，直到再次遇到`yield`為止。


~~~~exercism/note
在函式之外禁止使用`yield`運算式。
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## 為什麼要建立產生器？

產生器在許多應用中都很實用。

當你面對可能很龐大的一批值時，可能不會想把它們全部放進記憶體。
產生器可以讓你一件一件地處理較大的資料，既能節省記憶體，也能提升效能。

當某個流程或計算很_複雜_、很_耗費資源_，或是_無限_時，產生器也非常有幫助：

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

現在，每當對`infinite_sequence`物件呼叫`__next__()`時，它就會回傳_前一個數字_ + 1。
