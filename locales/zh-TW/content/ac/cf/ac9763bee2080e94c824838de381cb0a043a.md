# 簡介

理解參照是有效運用 Perl 的根本要素。
由於參照本身是純量，而陣列和雜湊只能存放純量，因此參照是將這些資料結構巢狀化的關鍵。

你可以使用反斜線運算子`\`，為現有的變數和副程式建立參照：

* 用`\$scalar`建立純量參照（這可以是任何純量，例如`\1`，不一定要是變數）。
* 用`\@array`建立陣列參照。
* 用`\%hash`建立雜湊參照。
* 用`\&sub`建立程式碼參照。

你也可以為陣列、雜湊和副程式建立所謂的匿名參照：

* 用`['Alice', 'Bob', 'Charlie']`建立匿名陣列參照。
* 用`{foo => 'a', bar => 'b', baz => 'c'}`建立匿名雜湊參照。
* 用`sub { return 1 }`建立匿名程式碼參照。

警告：在 Perl 中，大括號在某些情境下會有歧義。如果你得不到預期的雜湊參照，可以在前面加上一個加號來消除歧義，例如`+{}`。詳情請參閱[大括號][perlrefcurlybrackets]。

你可以使用箭頭運算子`->`來存取參照：

* 用`$ref->[0]`存取陣列參照中的元素。
* 用`$ref->{foo}`存取雜湊參照中的值。
* 用`$ref->($arg)`透過程式碼參照呼叫副程式。

對於複雜資料結構（例如多維陣列和巢狀雜湊）裡的資料，可以串接下標來存取，例如`$ref->{foo}[0]{bar}`（等同於`$ref->{foo}->[0]->{bar}`）。

如果你想解參照整個陣列或雜湊，可以分別使用箭頭運算子加上`@*`或`%*`，例如`$ref->@*`或`$ref->%*`。
你也可以把`*`換成一個下標，取得陣列或雜湊參照的切片，例如`$ref->@[0..2]`或`$ref->@{'Foo', 'Bar'}`。
就切片而言，sigil 的變化在這裡也同樣適用，就跟陣列與雜湊變數一樣。

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
