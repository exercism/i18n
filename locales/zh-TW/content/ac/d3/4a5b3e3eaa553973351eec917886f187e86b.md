# 操作說明

在這個練習中，你將會處理日誌行。

每一行日誌都是一個格式如下的字串：`"[<LVL>]: <MESSAGE>"`。

以下是各種不同的日誌等級：

- `TRC`（trace）
- `DBG`（debug）
- `INF`（info）
- `WRN`（warning）
- `ERR`（error）
- `FTL`（fatal）

你有三個任務，必須全部完成才能提供必要的功能。

## 1. 建立 LogLevel 列舉

定義一個 `LogLevel` 列舉，其中包含六個對應上述日誌等級的 case，以及一個用於缺少或非標準日誌等級的 unknown case。

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. 解析日誌等級

接著，實作 `LogLevel` 的初始化方法來解析日誌行的日誌等級：

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. 將日誌行轉換成簡短格式

日誌行的日誌等級相當冗長。
為了減少儲存這些日誌行所需的磁碟空間，我們設計了一種簡短格式：`"<ENCODED_LEVEL>:<MESSAGE>"`。

編碼後的日誌等級，就只是把日誌等級簡單對應到一個數字：

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

實作 `shortFormat(message: String) -> String` 方法，讓它可以將日誌行以簡短格式輸出成一個 `String`：

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
