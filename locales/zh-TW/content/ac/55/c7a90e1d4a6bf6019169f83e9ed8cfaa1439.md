# 提示

## General

- 如果需要複習基礎，可以回顧[物件概念][concept-objects]喔。

## 1. 定義 Size 以儲存視窗的尺寸

- 這個任務請記得使用[原型語法][mdn-prototype]。
- 先定義一個名為 `Size` 的函式，並確認將它[匯出][mdn-export]。
- 傳遞給建構函式的引數需要加到 `this` 物件上。
- 可以使用[預設參數][mdn-default-params]來套用預設值。
- 你可以透過建構函式的 `prototype` 屬性來新增方法。

## 2. 定義 Position 以儲存視窗位置

- 這個任務請記得使用[原型語法][mdn-prototype]。
- 先定義一個名為 `Position` 的函式，並確認將它[匯出][mdn-export]。
- 傳遞給建構函式的引數需要加到 `this` 物件上。
- 可以使用[預設參數][mdn-default-params]來套用預設值。
- 你可以透過建構函式的 `prototype` 屬性來新增方法。

## 3. 定義 ProgramWindow 類別

- 這個任務請記得使用[類別語法][mdn-class]。
- 確認將這個類別[匯出][mdn-export]。
- 將欄位加到 `this` 物件上來定義它們。
- 使用你在前面任務中定義的類別。
- 確認你的建構函式不接受任何引數。

## 4. 新增方法來調整視窗大小

- 這個任務請記得使用[類別語法][mdn-class]。
  也就是說，方法定義要直接寫在類別主體中。
- 要找出調整大小的正確數值，先想想你希望達到的寬度，並把下限（`1`）納入考量。
- 接著計算出在考量螢幕大小與視窗目前 `x` 位置之下，所允許的最大寬度。
- 有了這兩個數值，你就能決定要套用什麼，高度也用類似的邏輯處理。
- 使用 `Size` 物件的 `resize` 方法來套用變更。

## 5. 新增方法來移動視窗

- 這個任務請記得使用[類別語法][mdn-class]。
  也就是說，方法定義要直接寫在類別主體中。
- 要找出移動的正確數值，先想想你希望達到的 `x` 位置，並把下限（`0`）納入考量。
- 接著計算允許的最大 `x` 值。
  把螢幕大小和視窗目前的寬度納入考量。
- 有了這兩個數值，你就能決定要套用什麼，高度也用類似的邏輯處理。
- 使用 `Position` 物件的 `move` 方法來套用變更。

## 6. 變更程式視窗

- 首先，定義一個 `changeWindow` 函式，並確認將它[匯出][mdn-export]。
- 使用 `new` 關鍵字建立 `Size` 類別的實例，並把想要的尺寸當作引數傳入。（需要的位置物件也一樣。）
- 使用任務 4 和 5 中定義的方法。例如，你可以用 `obj.a()` 呼叫物件 `obj` 的方法 `a`。
- 確認回傳接收到的 `Window` 實例。
