# 解練習

Exercism 幫助你學習最主要的方式，就是解練習。

在 Exercism 上有兩種解練習的方式：

1. [線上，透過網站內建的瀏覽器編輯器](/docs/using/solving-exercises/using-the-online-editor)
2. [在自己的本機上透過 CLI](/docs/using/solving-exercises/working-locally)

## 我該選擇哪一種？

使用線上編輯器或 CLI 各有不同的取捨：

|            | 線上編輯器                     | CLI                                    |
| ---------- | ------------------------------ | -------------------------------------- |
| 安裝       | 不需要                         | 需要（例如 SDK）                       |
| 編輯       | 瀏覽器                         | 你慣用的編輯器                         |
| 測試       | 在網站上執行測試               | 在本機執行測試                         |
| 除錯       | 支援有限（僅限部分軌道）       | 完整支援（依你的環境而定）             |

一般而言，線上編輯器很適合用來開始新的軌道；如果你想使用自己個人化的程式設計環境，以 CLI 為主的方式就非常合適。
