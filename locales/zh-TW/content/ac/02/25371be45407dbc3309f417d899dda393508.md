# 提示

## General

- 在入門指南中閱讀關於[結構][getting-started-structs]的內容。
- 在文件中閱讀關於[`defstruct`][docs-defstruct]的說明。
- 觀看 [Elixir Casts - #106: Intro to Structs][elixir-casts]。

## 1. Create a brand-new remote controlled car

- 可以使用模組屬性`@enforce_keys`來指定必填的值。它必須在呼叫`defstruct`之前定義。
- `nickname`欄位不應指定預設值。
- `new/0`函式應將`nickname`初始化為`"none"`。

## 2. Create a brand-new remote controlled car with a nickname

- 使用[`multiple-function-clauses`][multiple-fn-clauses]來重複使用同一個函式名稱，但接受不同的引數。
- 可以考慮為函式使用[`default-argument`][default-arg]。

## 3. Display the distance

- 對於只接受特定類型結構的函式，請務必進行模式配對來檢查引數。
- 使用_靜態存取運算子_來取得欄位值。

## 4. Display the battery percentage

- 對於只接受特定類型結構的函式，請務必進行模式配對來檢查引數。
- 使用_靜態存取運算子_來取得欄位值。

## 5. Driving changes the battery and distance driven

- 對於只接受特定類型結構的函式，請務必進行模式配對來檢查引數。
- 使用_靜態存取運算子_來取得欄位值。
- 複習簡介中關於更新結構的內容。

## 6. Account for driving with a dead battery

- 如果電池已耗盡，應原樣回傳該結構。
