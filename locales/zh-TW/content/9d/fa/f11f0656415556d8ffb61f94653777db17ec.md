# 說明

在這個練習中，你會撰寫程式碼來分析汽車工廠的生產情形。

## 1. 計算每小時生產的可用車輛數量

這些汽車是在生產線上製造的。
生產線有固定的速度，而這個速度是可以改變的。
生產線的速度越快，生產出的汽車就越多。
不過，改變生產線的速度也會改變成功生產的汽車數量，也就是生產過程沒有任何錯誤的汽車。

實作一個函式，接收每小時生產的汽車數量和成功率，並計算每小時成功製造的汽車數量。
成功率以百分比表示，範圍從`0`到`100`：

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**注意：**回傳值應該是`float64`。

## 2. 計算每分鐘生產的可用車輛數量

實作一個函式，接收每小時生產的汽車數量和成功率，並計算每分鐘成功生產多少輛汽車：

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**注意：**回傳值應該是`int`。

## 3. 計算生產成本

每輛汽車單獨生產的成本通常是 $10,000，無論它是否成功。
但只要稍微規劃一下，10 輛汽車就能一起生產，成本為 $95,000。

舉例來說，37 輛汽車可以用以下方式生產：
37 = 3 組十輛 + 7 輛個別汽車

所以 37 輛汽車的成本是：
3\*95,000+7\*10,000=355,000

實作函式`CalculateCost`，計算生產若干汽車的成本，無論它們是否成功：

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**注意：**回傳值應該是`uint`。
