# 說明

在這個練習中，你將實作一個方法，用來追蹤你當地街機廳裡最受歡迎遊戲的高分。

## 1. 將玩家加入高分榜

要將玩家加入高分榜，請定義兩個`add_player!`方法，它們接受下列引數：

- 第一個引數是分數的字典。
- 第二個引數是玩家的名稱，型別為字串。
- 第三個引數是分數，型別為整數。
  這個引數是選用的，未提供值時，分數應設為 0。

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. 從高分榜移除玩家

要從高分榜移除玩家，請定義`remove_player!`，它接受 2 個引數：

- 第一個引數是分數的字典。
- 第二個引數是玩家的名稱，型別為字串。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. 更新玩家的分數

要用新分數取代先前的分數來更新玩家分數，請定義`update_score!`，它接受 3 個引數：

- 第一個引數是分數的字典。
- 第二個引數是玩家的名稱，型別為字串，也就是你想更新分數的玩家。
- 第三個引數是你想設為儲存高分的那個分數。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. 重設玩家的分數

要重設玩家的分數，請定義`reset_score!`，它接受 2 個引數：

- 第一個引數是分數的字典。
- 第二個引數是玩家的名稱，型別為字串，也就是你想重設分數的玩家。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. 取得玩家陣列

要取得玩家陣列，請定義`players`，它接受 1 個引數：

- 第一個引數是分數的字典。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
