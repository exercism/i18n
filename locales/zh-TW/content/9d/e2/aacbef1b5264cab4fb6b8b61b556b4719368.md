# 測試

Clojurescript 的 REPL 讓你輕鬆執行程式碼、立即獲得回饋，也能用來執行測試。

## Leiningen

若要使用 Clojure CLI 開啟 REPL，請先切換到包含這個練習的目錄，然後執行：
``` bash
$ clojure -m cljs.main -re node
```

請注意：你的系統必須安裝 Node。

當你準備好開始做某個練習，並建立好存放解答的檔案（例如`bob.cljs`）之後，就可以在終端機中用 `$ clojure -A:test` 執行測試。

首先，`require`測試命名空間：
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

將 ns 切換成測試命名空間：
```clojure
=> (ns bob-test)
nil
```

接著對`bob-test`呼叫`run-tests`：
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

若要使用 Clojure CLI 執行某個練習的測試，只要呼叫：
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
