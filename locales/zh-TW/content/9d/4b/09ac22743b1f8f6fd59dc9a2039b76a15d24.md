# 簡介

## JavaScript 中的正規表達式

[正規表達式][mdn-regular-expressions]（或稱 Regex）是一連串的字元，我們可以用它來鎖定並操作字串中的特定元素。因此，我們可以：

- 在字串中**搜尋**文字
- **取代**字串中的子字串
- 從字串中**擷取**資訊

> 💡 JavaScript 的正規表達式實作是 ECMA-262 語言標準的一部分，這表示你不必擔心瀏覽器之間的相容性問題。

## 如何建立正規表達式

在 JavaScript 中，正規表達式大多以`/pattern/modifiers`的格式撰寫。

建立正規表達式有兩種方式：

1. **正規表達式實字**：

```javascript
const regex = /[a-z]/;
```

2. **RegExp**建構函式：

```javascript
const regex = new RegExp('[a-z]');
```

這兩種情況都會讓 JavaScript 從正規表達式建立一個物件。建議預設使用實字寫法，建立不可變的模式。

當正規表達式會變動，或是我們還不知道它的內容時（例如來自使用者的輸入），就可以使用`RegExp`建構函式。

## 🏴‍☠️ 旗標

正規表達式有一些選用的超能力，稱為[`flags`][mdn-flags]，可以啟用額外的功能。

以下是幾個常見的：

- `/g` - 全域搜尋
- `/i` - 忽略大小寫
- `/m` - 多行搜尋

來看一個簡單的例子：

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

`g`這個字元讓我們能解析字串中所有可能的匹配。如果沒有這個功能，JavaScript 只會擷取出第一個`Home`匹配。

忽略大小寫的`/i`旗標讓我們在尋找模式時更有彈性。這樣一來，我們要找的內容是大寫`UPPERCASE`還是小寫`lowercase`都無所謂。

使用`RegExp`建構函式時，加入旗標的語法不太一樣。

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## 最常用的函式

當正規表達式與 JavaScript 目前內建的函式結合時，我們就能用強大的方式操作字串並從中取得資料。

以下是幾個最常與正規表達式搭配使用的函式。

### Test

[`test()`][mdn-regex-test]方法會搜尋正規表達式與指定字串之間的匹配。回傳 true 或 false。

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

使用[`match()`][mdn-regex-match]方法時，我們會得到一個實用的陣列，它的內容取決於是否找到匹配。

這樣一來，我們就能從任何字串中**搜尋**並**擷取**資訊。例如：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

當帶有全域搜尋旗標`/g`時，這個方法不會只回傳唯一的匹配以及索引或輸入等實用資訊，而是回傳所有出現的結果並顯示在陣列中：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScript 的[`replace()`][mdn-regex-replace]方法讓我們能在指定的字串中搜尋某個值，並將它替換成想要的新值。

```javascript
string.replace(searchValue, newValue);
```

用來搜尋待替換內容的模式可以是單一字串，也可以是正規表達式。

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

此外，我們也可以在替換的位置套用函式，對每個值做額外的處理。

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### Split

JavaScript 的[`split()`][mdn-regex-split]方法則是用正規表達式來使用與操作字串的另一種方式。

這樣一來，我們會用正規表達式辨識某個模式，藉此分割指定的字串，例如`str.split(/[,.\s]/)`。這個模式會用作`separator`。

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
