# 指示補充

## 定義歸納型別

這個練習預期回傳值是一個你必須自行定義的[歸納型別][inductive]`Classification`。

這個型別必須有 [BEq][beq] 執行個體，也就是說，它要能進行布林相等性測試；還必須有 [Repr][repr] 執行個體，也就是說，這個型別的值可以格式化以供顯示。

你可以參考[這個頁面][instance]，了解執行個體宣告。
Lean 可以自動為許多類別[產生執行個體][deriving]。

## 子型別

`classify`函式的引數是一個名為`Positive`的[子型別][subtype]：

```
def Positive := { x : Nat // x > 0 }
```

子型別代表某個特定型別中滿足述詞的元素。
`Positive`代表`Nat`中大於`0`的元素。

子型別的任何元素都可以想成一組配對：一個底層型別的值，加上一個數學意義上的證明，證明這個值滿足對應的述詞。

子型別在型別層級強制維持不變式，確保無法建構出格式錯誤的值。
