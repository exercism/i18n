# 指令

在這個練習中，你會撰寫程式碼，協助一家招牌公司為他們的招牌製作自訂訊息。

## 1. 建立一組實用的字串

定義以下常數字串，這些字串會用來製作招牌：

- `birthday`：這個常數存放 "Birthday" 這個值
- `valentine`：這個常數存放 "Valentine's Day" 這個值
- `anniversary`：這個常數存放 "Anniversary" 這個字串

## 2. 建立一組實用的字元

定義以下常數字元，這些字元會用來製作招牌：

- `space`：這個常數存放 " " 這個值（一個空格）
- `exclamation`：這個常數存放 "!" 這個值

## 3. 組合詞句來建立訊息

實作函式 `buildSign(for:name:)`，它接受引數 `for`，這個引數存放你在第一個任務中定義的三個字串之一，以及引數 `name`，這是一個存放招牌對象姓名的字串。
你要使用串接來建立招牌的訊息，並記得重複使用已經定義好的常數。
這個函式應該以字串回傳招牌訊息。

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. 建立畢業招牌

實作函式 `graduationFor(name:year:)`，它接受引數 `name`，這是一個存放招牌對象姓名的字串，以及引數 `year`，這是一個存放對方畢業年份的整數。
你要使用模板字串來建立招牌的訊息。
這個函式應該以字串回傳招牌訊息。

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. 計算招牌的費用

實作函式 `costOf(sign:)`，它接受引數 `sign`，這是一個存放招牌訊息的字串。
招牌的基本價格是 20（以指定貨幣計）。此外，每個字母要花費 2（空白也計入計算）。
這個函式應該以整數回傳招牌的費用。

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
