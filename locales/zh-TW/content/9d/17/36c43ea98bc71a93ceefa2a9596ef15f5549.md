# 簡介

當你要為只能取特定幾種可能狀態的資料建立模型時，例如一週中的每一天、羅盤方向，或控制器上的按鈕，像`Int`或`String`這類基本型別有很大的缺點。
使用整數或字串時，你的程式碼必須不斷檢查無效的值（例如狀態碼`999`，或`"leftt"`這種拼錯的字），而人類讀者也無法輕易看出這些數字代表什麼。

Swift 用[列舉（_Enumerations_）][enumerations]（通常簡稱為*列舉*）解決了這個問題。
列舉為一組相關的具名值定義了一個共同的型別。因為編譯器事先就知道所有可能的成員，所以能在編譯時期檢查你的程式碼是否正確且完整。
列舉也可以有方法、初始化器和計算屬性。

## 定義列舉

使用`enum`關鍵字來定義列舉，後面接著型別名稱，並在大括號內列出各個成員。
依照 Swift 的慣例，型別名稱使用`UpperCamelCase`，而每個成員使用`lowerCamelCase`：

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

你也可以把多個成員寫在同一行，用逗號分隔：

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

要取用某個列舉成員時，寫出列舉的型別名稱、一個點（`.`），再加上成員名稱。一旦型別已知，或編譯器能推斷出來，就可以省略型別名稱，改用更簡短的點語法：

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## 方法與初始化器

列舉就像類別和結構體一樣，可以定義方法和自訂初始化器。在列舉的方法裡，`self`指的是目前的成員值：

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## 原始值

列舉成員可以預先填入預設值，這些值叫做[_原始值_][raw-values]。
列舉中所有的原始值都必須共用相同的型別（例如`Int`、`String`或`Character`）：

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

你可以用`init(rawValue:)`從原始值初始化列舉。由於可能傳入無效的原始值，這個初始化器會回傳一個 Optional：

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift 可以自動為`String`和`Int`列舉指定原始值：

- 對`String`列舉來說，每個成員的原始值預設就是它的成員名稱。
- 對`Int`列舉來說，原始值從`0`開始，除非另有指定，否則每次遞增 1。

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```
