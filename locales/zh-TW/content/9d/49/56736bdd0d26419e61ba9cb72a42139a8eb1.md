# 提示

## 1. 從牌堆中取出一張牌

- `Vector`的索引從`1`開始。
- 你可以用`v[n]`取得向量`v`中的第`n`個值。

## 2. 交換牌堆中的一張牌

- `Vector`是可變的，你可以隨時透過指定新值來改變它的內容。

## 3. 在牌堆頂端插入一張牌

- Base 中有一個方法[`push!`][push]，可以在集合的尾端加入新值。

## 4. 從牌堆中移除一張牌

- Base 中有一個方法[`deleteat!`][deleteat]，可以從`Vector`中刪除指定索引的元素。

## 5. 移除牌堆頂端的牌

- Base 中有一個方法[`pop!`][pop]，可以移除集合尾端的元素。

## 6. 在牌堆底部插入一張牌

- Base 中有一個方法[`pushfirst!`][pushfirst]，可以在集合的開頭插入新值。

## 7. 移除牌堆底部的牌

- Base 中有一個方法[`popfirst!`][popfirst]，可以移除集合開頭的元素。

## 8. 檢查牌堆的大小

- Base 中有一個方法[`length`][length]，可以取得集合的長度。
