# 指令補充

輸出的排列應該採用[列優先順序](https://en.wikipedia.org/wiki/Row-_and_column-major_order)：先放第一列的所有字組，再放第二列的所有字組，依此類推。

## 暫存器

| Register | Usage        | Type    | Description                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 輸入         | 整數    | 大小                                |
| `$a1`    | 輸入／輸出   | 位址    | 以列優先順序排列的字組矩陣          |
| `$v0`    | 輸出         | 整數    | 矩陣中字組的數量                    |
| `$t0-9`  | 暫時         | 任意    | 供暫時儲存使用                      |
