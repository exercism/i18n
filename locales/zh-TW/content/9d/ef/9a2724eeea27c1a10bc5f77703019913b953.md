# 簡介

## 轉型

轉型和型別轉換，是將運算式從一種資料型態改成另一種的兩種不同方式。

運算式可以透過轉型運算子`(<type>)`轉型成另一種型別。

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

如果型別不相容，就會擲回`InvalidCastException`的執行個體。以數字來說，這表示接收的型別無法表示轉型後的值。以類別來說，其中一個型別必須衍生自另一個（這對結構來說也同樣成立，只是顯而易見）。

_轉型_的另一種做法，是使用`is`運算子的_型別轉換_。這種做法通常用在參考型別和可為 Null 的型別上。

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

如果你需要偵測物件的確切型別，`is`可能就稍微寬鬆了點，因為對某個類別，以及它直接或間接衍生的任何類別和介面，它都會傳回 true。在這種情況下，`typeof`和`Object.GetType()`就是解答。

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
