# 指示

在這個練習中，你要寫一些程式碼，幫助你依照最愛的食譜做出美味的千層麵。

你有三個任務，全都和烹調千層麵所花費的時間有關喔。

## 1. 定義預期的烤箱時間（分鐘）

定義`expectedMinutesInOven`來計算千層麵應該在烤箱中待幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```elm
expectedMinutesInOven
    --> 40
```

## 2. 計算準備時間（分鐘）

定義`preparationTimeInMinutes`，它會接收千層麵的層數作為參數，並回傳準備千層麵需要幾分鐘，假設每一層需要 2 分鐘準備。

```elm
preparationTimeInMinutes 3
    --> 6
```

## 3. 計算經過的時間（分鐘）

定義`elapsedTimeInMinutes`函式，它接收兩個參數：第一個參數是千層麵的層數，第二個參數是千層麵已經在烤箱中待了幾分鐘。這個函式應該回傳你烹調千層麵所花的時間（分鐘），也就是準備時間（分鐘）加上當下千層麵已經待在烤箱中的時間（分鐘）的總和。

```elm
elapsedTimeInMinutes 3 20
    --> 26
```
