# 指令補充

## 例外訊息

有時候我們需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。當你這麼做時，一定要附上**有意義的錯誤訊息**，說明錯誤的來源是什麼。這能讓你的程式碼更容易閱讀，對除錯也有很大的幫助。如果你已經知道錯誤來源屬於某種類型，可以選擇引發其中一種[內建錯誤類型](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習要求你使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)來「拋出」`ValueError`，以處理不同的輸入和輸出進位。只有當你同時`raise`該`exception`，並附上有意義的訊息時，測試才會通過。

若要引發帶有訊息的 `ValueError`，請把訊息寫成 `exception` 型別的引數：

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
