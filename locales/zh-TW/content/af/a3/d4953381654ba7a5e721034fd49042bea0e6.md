# 佔位符

## 實作 List 操作

這道練習的目標，是讓你親自實作一些 List 方法。
在底層用一個 List 物件來存放資料是很自然的做法。
別去碰 List 既有的方法（例如`where`、`map`等）。

有些「原始」的 List 操作是無法避免的，例如：

* 切片：`list[from..to]`
* 新增：`list.add(item)`

## 疊代器協定

要實作的這些 List 操作，全都和各種不同的疊代方式有關。
請閱讀[疊代器協定][iter]的相關說明。
接著你就能這樣做：

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
