# 簡介

Gleam 的不透明型別是一種自訂型別，只有定義該型別的模組才能建構或模式配對這種型別的值。這對於建立只應該以特定方式使用的型別很有用。

不透明型別使用`opaque`關鍵字定義。

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

這個`PositiveInt`型別適合用在需要整數、但該整數必須大於或等於零的情境。這時不能直接使用一般的 Gleam `Int`，因為它也可能是負數。

定義這個型別的模組可以定義一個函式來取得內部的整數值，也可以定義一個建立`PositiveInt`型別的函式，後者在值不是正數時會回傳錯誤。

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

有了這組 API，其他模組就無法建構值為負數的`PositiveInt`，因此任何接受`PositiveInt`的函式都能確定這個值是正數。
