# 關於

`Time`模組用來顯示人類可讀的日期與時間。
雖然技術上可以用`Time`操作時間，但 Elm 社群有些套件更適合這項任務，例如 [`justinmimbs/date`][date] 或 [`CoderDennis/elm-time-format`][elm-time-format]。

## Posix

時間以不透明型別`Posix`表示，它包裝了 Unix 紀元時間，也就是自 1970 年 1 月 1 日 UTC 午夜起經過的毫秒數。
`Posix`是不帶歧義的值，不會因時區而有所不同，因此是保存時間的好選擇。
在 Elm 應用程式中，`Posix`時間通常由外部來源提供，例如瀏覽器。

可以透過下列函式把`Posix`轉換成毫秒數字，反之亦然：

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## 時區

在日常生活中，我們通常不會直接讀取`Posix`，而是偏好當地時間，這取決於我們在地球上的位置以及當地的日光節約時間規則。
在 Elm 中，這些資訊編碼在不透明型別`Zone`裡，通常由瀏覽器提供。

有個特別的`Zone`永遠可以取用：

```elm
utc : Zone
```

## 人類可讀的時間

有了`Posix`和`Zone`，我們就有足夠的資訊，以各種細節程度顯示當地時間。
以下列出可以用來做到這件事的函式：

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

你應該已經注意到`Time`還有另外兩個自訂型別：

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

把這些自訂型別轉換成人類可讀的值，就交給使用者自行處理。
