# 關於

屬性的兩大主要類型是

1. 自動實作的屬性，其中`get`和`set`存取子沒有主體。它們可以明確初始化，也可以不初始化。例如：
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. 另一種是存取子會評估運算式並執行敘述的屬性。程式碼可以簡單到只是回傳支援欄位，或將值指定給支援欄位。例如：
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

屬性和方法在行為與能力上有相當大的重疊。當屬性不是自動實作時，它們可以包含任何能出現在類別作用域內的敘述或運算式。常見的情況是，它們通常被描述為包裝支援欄位。雖然在特定情況下，把行為撰寫成屬性還是方法，很多時候是很明顯的，但這往往需要開發者自行判斷，尤其是存取子內應該執行多少程式碼。常見的做法是在 set 存取子中進行驗證，並在 get 存取子中進行簡單的計算或格式化：

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

與其他類別成員類似，屬性也可以有存取層級。大多數情況下，屬性會具有非私用的存取層級，以符合其基本用途。有時其中一個存取子會具有與屬性不同的存取層級。以`TareWeight`為例，在相當人工化的「安全性」限制下，有機會使用具有私用 get 存取子的公用屬性。這表示類別外部的程式碼可以設定屬性的值，但只有類別內的程式碼可以讀取（get）它。

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

也支援非公用的 set 存取子，但更常見的情況是 set 存取子可以完全省略。這可能是因為屬性的值是在類別的建構函式中設定的。

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

這個練習談到了屬性的基本用法。你會在其他的練習中找到更多進階主題：

- 以運算式為主體的屬性、get 存取子和 set 存取子（涵蓋於以運算式為主體的成員）
- 介面上的屬性（涵蓋於介面）
- 抽象類別上的屬性/抽象屬性（涵蓋於繼承）
- 屬性搭配`readonly`關鍵字的用法（涵蓋於不可變性）
- 靜態屬性（涵蓋於靜態）
- 索引子（涵蓋於索引子）
