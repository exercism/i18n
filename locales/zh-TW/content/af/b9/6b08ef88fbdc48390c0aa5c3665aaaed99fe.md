# 簡介

Haxe 內建支援正規表達式。它們可以用來驗證字串的格式、轉換字串，或從給定的文字中擷取一些符合規則的資料。

要建立正規表達式，請在`~/`和`/`之間輸入：

```haxe
var r = ~/haxe/i;
```

另一種做法是使用`EReg()`實例：

```haxe
var r = new EReg("haxe", "i");
```

這裡的`i`是讓模式不分大小寫的旗標。其他旗標還包括：

- `g`：全域取代。
- `m`：多行比對

在`~/`和`/`之間輸入正規表達式模式。例如，你想尋找包含 A 到 Z 字母的字串。這裡我們可以使用範圍模式`[A-Z]`。有許多表達式模式，包括：

- `.`：任何字元
- `*`：重複零次或多次
- `+`：重複一次或多次
- `[A-Z0-9]`：字元範圍
