# 關於

除了字元類別與量詞之外，正規表達式還能描述文字的*結構*與*脈絡*。這些功能都屬於同一套 [`regexp`][regexp] 詞彙表，以`R/ /`字面值寫成。

## 分組與交替

小括號`( )`會把樣式的一部分分成一組，讓量詞或`|`（「這個或那個」）套用到整組。群組後面加上`?`就代表這一組可以省略：

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## 錨點

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

*單字邊界*（`\b`）是單字字元（字母、數字或底線）與非單字字元交界的位置，字串的開頭與結尾也算在內。所以`\bcat\b`只在`cat`單獨出現時才會比對：

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## 前後查找

*前後查找*會檢查某個位置前面或後面緊鄰的內容，但不會把那些字元算進比對的一部分，它的寬度為零：

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## 選項

結尾的`/`後面加上選項字母，就會改變整個樣式的行為。`i`代表忽略大小寫：

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## 逐一轉換每個比對結果

`map-matches`會對每個比對結果執行一段 quotation，並收集結果；`each-match`也一樣，但只用來產生副作用。兩者都會把比對結果的`start`索引、`end`索引和整個字串傳給 quotation，所以用`subseq`就能取回比對到的文字：

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Factor 不支援的功能

Factor 的正規表達式引擎不支援**擷取群組**（群組`( )`只是用來組織樣式，沒辦法事後讀回它比對到的文字）、**反向參照**（`\1`），也沒有**惰性／非貪婪**量詞（`*?`、`+?`）。前後查找是擷取群組的慣用替代做法：比對你想要的那一部分，再靠它前後的脈絡認出來。
