# 簡介

這個練習會帶你認識 Ruby 最基礎的組成要素。

它涵蓋的範圍很廣，但如果覺得有點吃不消，別擔心喔，隨著我們繼續這條學習路徑，之後每一項都會更深入地介紹。

要理解 Ruby，其中一個關鍵是它是一門[物件導向語言][object-oriented-programming]，而且**Ruby 裡的所有東西都是[物件][object]**。數字、字串、陣列，它們通通都是物件。

## 變數與常數

我們通常會透過幫物件命名來使用它們，命名的方式可以是變數或常數。

變數一律以[蛇形命名法][snake-case]書寫。
同一個變數在其生命週期內可以指向不同的物件。
例如，`my_first_variable`可以用`=`運算子一再定義與重新定義：

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

不過，常數只應該被指定一次。
常數必須以大寫字母開頭，而且通常全部以大寫書寫，字詞之間用底線分隔。
例如：

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## 類別

Ruby 是以類別來組織的。
類別是使用`class`關鍵字定義的，後面接著類別名稱。
一般來說，物件是透過`.new`方法將類別實例化而建立。
例如：

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## 方法

功能單位會被封裝在方法裡，這點和其他語言的_函式_很像。

方法可以用位置引數或關鍵字引數（定義與呼叫時使用`:`語法）來定義，也可以完全沒有引數。

方法會隱式回傳最後一個被求值敘述的結果，也可以透過`return`關鍵字明確地回傳一個物件。

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

方法使用`.`語法呼叫：

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
