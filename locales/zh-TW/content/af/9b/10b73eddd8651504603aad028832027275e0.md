# 測試

執行測試需要先執行`cmake -G`，然後使用適合你所使用平台的建置指令。
詳細的操作說明可以在 exercism.org 上 C++ 的[執行測試][cpp-tests-instructions]頁面找到。

## 通過測試

當你在本機開始一個新的練習時，這些檔案已設定成只會執行第一個測試。
依照[測試驅動開發的三個法則][three-laws-of-tdd]，讓第一個測試能編譯、連結並通過。
只要建立剛好足夠的結構就好：宣告命名空間、函式、類別等，以解決編譯器錯誤，並讓測試失敗。
接著，只要寫剛好足夠的程式碼讓測試通過就好。
完成之後，把`if defined(EXERCISM_RUN_ALL_TESTS)`這一行移到下一個測試的後面，就能取消註解下一個測試。

請看以下來自 Bob 練習的範例（檔案`bob_test.cpp`，第 15 行）：

```diff
-#if defined(EXERCISM_RUN_ALL_TESTS)
TEST_CASE("shouting")
{
    REQUIRE("Whoa, chill out!" == bob::hey("WATCH OUT!"));
}
+#if defined(EXERCISM_RUN_ALL_TESTS)
```

把這一行移到下一個測試的後面，可能會產生編譯錯誤，因為接下來可能會用到你還沒宣告或定義的新結構。
同樣地，以最小的幅度修正編譯錯誤，讓測試失敗；接著以最小的幅度修改程式碼，讓測試通過；然後重構你的實作，讓它更容易閱讀、更清楚表達，再繼續進行下一個測試。

盡量優先使用標準 C++17 的功能，而不是自己手寫低階的演算法或功能。
