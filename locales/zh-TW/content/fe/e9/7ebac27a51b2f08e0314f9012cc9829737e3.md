# 提示

## 一般

- [Python 教學][the python tutorial]是很棒的入門資源。
- [PEP 8][pep8]是 Python 的程式碼風格指南。
- [PEP 257][PEP257]詳細說明了 Python 說明字串的慣例。
- [數字][numbers]在 Python 中可以是整數、浮點數或複數。


## 1. 定義預期的烘焙時間（分鐘）

- 你需要[命名][naming]一個[常數][constants]，並[指定][assignment]它一個[整數][numbers]值。
  這個常數應該放在檔案最上方說明字串之後的第一個位置。
  定義常數之後，記得移除 #TODO 註解。

## 2. 計算剩餘的烘焙時間（分鐘）

- 你需要定義一個[函式][defining functions]，它帶有一個參數，代表目前為止經過的時間。
- 使用[減法的數學運算子][numbers]來減去數值。
- 這個函式應該[回傳一個值][return]。

## 3. 計算準備時間（分鐘）

- 你需要定義一個[函式][defining functions]，它帶有一個參數，代表層數。
- 使用[乘法的數學運算子][numbers]來相乘數值。
- 你可以定義一個 PREPARATION_TIME _常數_來表示每層所需的分鐘數，而不必在程式碼裡使用[「魔術數字」][magic-numbers]。
- 這個函式應該[回傳一個值][return]。

## 4. 計算總共花費的烹調時間（準備 + 烘焙）（分鐘）

- 你需要定義一個帶有 2 個參數的[函式][defining functions]。
- 記住：你隨時可以_呼叫_之前定義過的函式。
- 你可以使用[加法的數學運算子][python as a calculator]來加總數值。
- 這個函式應該[回傳一個值][return]。

## 5. 為食譜加上附註

- 無論如何，都建議依照 [PEP257][pep257] 清楚地[註解][comments]並[撰寫說明字串][docstrings]你的程式碼。
- 在 Sphinx 文件中可以找到一些 Google 風格說明字串的範例，請參考 [napoleon 模組][napoleon]。
