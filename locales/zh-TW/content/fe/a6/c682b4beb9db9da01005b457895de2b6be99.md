# 簡介

[`Basics`][basics]概念介紹了兩種定義函式的方式。

最常見的是多行形式：

```julia
function muladd(x, y, z)
    x * y + z
end
```

如果是簡短的定義，可以用「賦值」或「單行」形式：

```julia
muladd(x, y, z) = x * y + z
```

第三種、甚至更精簡的形式，可以建立沒有名稱的短期、單次使用的函式：

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

在這裡，`x -> 2x`是「匿名函式」。這等同於其他語言所稱的「lambda 函式」。

注意，多個引數需要用括號，例如`(x, y) -> x * y`。

匿名函式在 Julia 程式碼中很常見，尤其是搭配`map()`和`filter()`這類高階函式使用時（後續概念會有更詳細的介紹）。

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## 函式引數

到目前為止，在這門課程中，我們只看過引數數量固定的函式，而且呼叫時必須依照正確的順序提供所有引數。這樣會綁手綁腳，所以還有其他幾種做法。

### 選擇性引數

與許多語言一樣，Julia 允許函式定義為個別引數提供預設值。

呼叫函式時，可以為該引數提供值，也可以省略它並採用預設值。

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

所有_沒有_預設值的引數都必須排在_有_預設值的引數前面，也就是說`f(x=2, y)`是不合法的。

### 關鍵字引數

到目前為止的所有範例都使用`positional arguments`，也就是呼叫函式時提供的值必須與函式定義中對應引數的順序一致。

與許多語言一樣，Julia 也允許`keyword arguments`。呼叫函式時必須指定引數名稱，但多個關鍵字引數可以用任意順序指定。

Julia 的一個獨特之處是，函式定義中的關鍵字引數（如果有的話）前面必須加上分號`;`，以便與位置引數區隔。呼叫函式時，最後一個位置引數與第一個關鍵字引數之間可以使用`;`或`,`。

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

預設值可以選擇性提供，方式和位置引數完全相同。

當事先算好一個與參數同名的變數時，函式呼叫中常會出現像`myarg=myarg`這樣的語法。這種情況下可以使用簡寫語法：

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat 與 Slurp

這兩個是 Julia 語法中某個實用面向的標準名稱，免得你納悶。兩者指的都是`...`運算子。

#### Splat

Splat 用於函式_呼叫_，把集合展開成函式所需的個別值。

用示範來說明可能比解釋還容易：

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

有些「函式呼叫」被語法糖隱藏起來，所以 splat 也可能用在比較不明顯的地方。

例如，多重賦值在內部使用了元組的建構函式：

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

關鍵字引數也可以用 splat 提供，通常使用`named tuple`。`Dict`也可以，但鍵必須是符號（字串不行）。

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Slurp 用於函式_定義_，把任意數量的個別值打包成一個集合。

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

被 slurp 的引數名稱（這裡是`more`）並不重要。這個變數的型別由編譯器決定，但對位置引數來說，很可能是`tuple`或類似的東西。

關鍵字引數也可以 slurp，得到一個`Dict`（或類似的東西）。

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

呼叫時可以使用任何關鍵字引數。要回應哪些關鍵字、忽略哪些，由函式定義決定。
