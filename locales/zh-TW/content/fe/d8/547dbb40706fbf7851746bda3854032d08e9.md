# 提示

## 1. 取得翻譯，忽略品質

- Promise 可以串接，例如使用`.then`。
- Promise 會傳遞任何值。
  意思是說，如果 promise 成功，它會把那個值往下傳，直到鏈的末端或遇到`.then`，由`.then`接收該值作為它的引數。
- Promise 會傳遞任何錯誤。
  意思是說，如果 promise 失敗，它會把該失敗往下傳，直到鏈的末端或遇到`.catch`，由`.catch`接收該值作為它的引數，並加以處理。

## 2. 取得一批翻譯，全有或全無

- 若要回傳帶有錯誤的 promise，請建立一個從一開始就是`rejected`的`Promise`。
- `Promise`上有一個輔助方法，它會等一個 promise 陣列全部完成後，自己才會完成。

## 3. 請求翻譯，最多重試 2 次

- 使用`new Promise`建構子把`callback`轉成 promise。

## 4. 取得翻譯，檢查品質，或請求翻譯

- 不必巢狀使用`.then`和／或`.catch`，`.then`可以接受第二個引數，它會捕捉_之前_（鏈中較早）的一切，並忽略`.then`第一個引數中的錯誤。
