# 簡介

## 變數

回想一下，`jq`程式是一條_運算式管線_。
**變數賦值**遵循這條規則：_變數賦值_是一種看起來像這樣的運算式：

```jq
... | expr as $varname | ...
```

### 篩選器的輸出就是它的輸入

跟_恆等運算式_`.`一樣，_變數賦值_的輸出和它的輸入相同。
設定變數的值是一種副作用。

範例：可以看到賦值之後的`.`和最初的輸入相同：

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### 變數的作用域

變數的作用域是「詞法」的，也就是說，變數在管線剩下的部分都會在作用域內。
在函式內定義的變數（我們之後會談到函式）是函式的「區域」變數。

### 變數名稱

變數必須以`$`開頭。
變數名稱剩下的部分是**識別字**：以字母或底線開頭，後面接著字母、數字或底線。

### 解構賦值

手冊上寫道：

> 只要提供一個_符合輸入結構_的模式，就能用單一的`as`運算式宣告多個變數（這稱為「解構」）。

範例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

把變數名稱對應到_物件鍵_是一種簡寫：

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### 常數

如上面的範例所示，變數很方便用來儲存常數。
比起讓「魔術數字」出現在程式碼裡，更好的做法是給常數取個名字。

### 很多時候不需要變數

省略變數通常更好讀。

想想看計算某個數字陣列平均值的情況

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

和下面這種寫法相比：

```jq
[2, 4, 8, 7] | add / length
```

這凸顯了`jq`最強大的特點之一：篩選器的輸入會提供給_每一個_子運算式：

- 輸入陣列`[2,4,8,7]`會傳給`add`（它對所有元素套用`+`運算子來加總這些數字）
- _同時_，`[2,4,8,7]`也會傳給`length`
- 等這些子運算式都完成後，再把它們的結果相除，回傳輸入陣列中這些數字的平均值。

### 學習練習會用到的`jq`運算子

#### 替代運算子：`//`

運算式`a // b`在`a`是 false 或 null 時輸出`b`，否則輸出`a`。
在設定變數的情境下，這對於提供預設值非常方便：

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### 算術運算子

- `+`、`-`、`*`就是一般數字用的加法、減法和乘法運算子。
