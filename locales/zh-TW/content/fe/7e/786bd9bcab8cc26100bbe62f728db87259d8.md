# 說明

在這個練習中，你要實作一個方式，來記錄當地電動遊樂場最熱門遊戲的最高分。

你要實作 6 個函式，大多與操作一個存放最高分的物件有關。

## 1. 建立新的最高分板

撰寫一個函式`create_score_board`，它會建立一個用來當作最高分板的物件。
這個物件的鍵會是玩家名稱，值則是他們的分數。
為了測試，你要在物件中直接加入一筆項目。
這筆初始項目應該包含`"The Best Ever"`這個玩家名稱，以及`1000000`這個分數。

```jq
create_score_board
# returns an object with one initial entry
```

## 2. 將玩家加入分數板

要把玩家加入最高分板，請實作函式`add_player`。
它接收一個分數板作為輸入，並且需要兩個參數：玩家名稱和玩家的分數。
這個函式會輸出加入新玩家後的分數板物件。

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

如果玩家已經在分數板上，就原樣輸出這個分數板。

## 3. 從分數板移除玩家

如果玩家違反電動遊樂場的規則，就會被手動從最高分板移除。
實作`remove_player`，它接收一個分數板作為輸入，以及一個參數：要移除的玩家名稱。
這個函式應該從分數板移除指定玩家的項目，並輸出新的分數板。
如果玩家本來就不在分數板上，分數板就不應該有任何變化，應該原樣回傳。

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. 增加玩家的分數

如果玩家在電動遊樂場又完成了一局遊戲，就會有一定數量的分數加到分數板上原本的分數。
實作`update_score`，它接收一個分數板作為輸入，並需要兩個參數：玩家名稱和要增加的分數。
這個函式應該在更新完成後回傳分數板。

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

如果玩家還不在分數板上，這個函式應該把他們加入分數板。

## 5. 套用週一獎勵分數

電動遊樂場在週一會使用另一個分數板。
當天結束時，那個分數板上的每位玩家都會額外獲得 100 分。

實作函式`apply_monday_bonus`。
這個函式會為分數板上列出的每位玩家加上獎勵分數。

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. 找出總分

不同的電動遊樂場會互相競爭，看誰擁有最厲害的玩家。
總分最高的遊樂場贏得這份榮耀。

撰寫一個函式`total_score`。
它接收一個分數板作為輸入，並輸出所有玩家分數的總和。

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
