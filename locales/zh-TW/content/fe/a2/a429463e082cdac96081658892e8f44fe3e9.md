# 指令

在這個練習中，你會寫一些程式碼，幫你照著最愛的食譜做出美味的千層麵。

你有四個任務，全都與烹調千層麵的時間有關。

## 1. 將預期的烘烤時間存入常數

定義`expected-bake-time`常數，它應該回傳千層麵需要在烤箱裡烤幾分鐘。

根據食譜，千層麵總共需要在烤箱裡烤 40 分鐘。

```factor
expected-bake-time .
! => 40
```

## 2. 計算準備時間（以分鐘為單位）

定義`preparation-time`這個詞。它會從堆疊取出你加進千層麵的層數，並留下你花了多少分鐘準備，假設每一層需要 2 分鐘準備。

```factor
4 preparation-time .
! => 8
```

## 3. 計算剩餘的烘烤時間（以分鐘為單位）

定義`remaining-time`這個詞。它會從堆疊取出千層麵已經在烤箱裡烤過的分鐘數，並留下它還需要在裡面待多少分鐘。

```factor
25 remaining-time .
! => 15
```

## 4. 計算總工作時間（以分鐘為單位）

定義`total-working-time`這個詞。它會從堆疊取出兩個引數，先是千層麵的層數，然後是千層麵已經在烤箱裡的分鐘數，並留下到目前為止花費的總烹調時間：準備時間加上已經在烤箱裡的時間。

```factor
3 20 total-working-time .
! => 26
```
