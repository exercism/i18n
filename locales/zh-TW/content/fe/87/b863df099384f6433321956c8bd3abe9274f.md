# 提示

## 1. 為員工印出名牌

- 在 Base R 中建構字串時，[`sprintf`][ref-sprintf]函式相當好用。
- 如果想用 Tidyverse 的做法，可以使用`stringr`套件提供的[`str_glue`][ref-str_glue]。

## 2. 為新進員工印出名牌

- 依[`is.na`][ref-isna]的結果來分支。

## 3. 為老闆印出名牌

- 依[`is.null`][ref-isnull]的結果來分支。

## 4. 計算沒有 ID 的員工薪資總和

- 你可以先對[`is.na`][ref-isna]的結果[篩選][concept-vector-filtering]，再呼叫[`sum`][ref-sum]加總。
- 如果沒有員工缺少 ID，`salaries[is.na(ids)]`會是什麼？在 R 主控台裡檢查一下會很有幫助。如果你的電腦沒有安裝 R，可以試試像 [rdrr.io][web-rdrr] 這樣的線上主控台。
