# 簡介

Lua 用兩種方式表示數字：64 位元整數和雙精度浮點數。它支援一般常見的算術運算子：加法、減法、乘法、除法和取負。除此之外，還支援向下取整除法、取餘數和次方運算。

| 運算子 | 範例                |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
