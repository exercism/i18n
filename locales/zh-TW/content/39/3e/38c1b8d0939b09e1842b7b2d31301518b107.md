# 說明

Lucian 的女朋友正在回家的路上，而他還沒煮好他們的週年晚餐！

在這個練習中，你會寫一些程式碼，幫 Lucian 按照他最愛的食譜做出精緻的千層麵。

這個練習有四個任務，都跟烹調千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義 `EXPECTED_MINUTES_IN_OVEN`常數，代表千層麵應該在烤箱裡烤幾分鐘。這個常數必須匯出。根據食譜，預期的烤箱時間是 `40`分鐘。

## 2. 計算剩餘的烤箱時間（分鐘）

實作 `remainingMinutesInOven`函式，它會接收千層麵實際在烤箱裡的分鐘數作為_參數_，並根據上一個任務的**預期烤箱時間（分鐘）**，_回傳_千層麵還需要留在烤箱裡幾分鐘。

```javascript
remainingMinutesInOven(30);
// => 10
```

## 3. 計算準備時間（分鐘）

實作 `preparationTimeInMinutes`函式，它會接收你加到千層麵裡的層數作為_參數_，並_回傳_你準備千層麵花了幾分鐘，假設每一層要花你 2 分鐘準備。

```javascript
preparationTimeInMinutes(2);
// => 4
```

## 4. 計算總工作時間（分鐘）

實作 `totalTimeInMinutes`函式，它會接收_兩個參數_：`numberOfLayers`參數是你加到千層麵裡的層數，而 `actualMinutesInOven`參數則是千層麵已經在烤箱裡的分鐘數。這個函式應該_回傳_你烹調千層麵總共花了幾分鐘，也就是準備時間（分鐘）加上千層麵當下已經待在烤箱裡的分鐘數。

```javascript
totalTimeInMinutes(3, 20);
// => 26
```
