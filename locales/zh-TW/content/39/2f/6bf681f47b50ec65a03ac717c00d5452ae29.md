# 簡介

## 別名

若想在同一個專案裡的不同 Elixir 模組之間共用程式碼，你需要用完整名稱來參照外部的模組。但如果這個名稱太長或讓人搞不清楚呢？

特殊形式`alias`可以讓你縮短或改變參照外部模組時所用的名稱。不加任何引數時，它會把模組名稱縮減到最後一段，例如`MyApp.Logger.Settings`會變成`Settings`。自訂名稱則可以用`:as`選項指定。

別名通常會加在模組定義的開頭。

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## 匯入

特殊形式`import`可以讓你使用外部模組的函式，而不必寫出模組名稱。

匯入整個外部模組時，可能會與模組內既有的函式產生衝突。為了避免這種情況，有兩個選項可用：`:except`和`:only`。兩者都接受關鍵字列表，其中鍵是函式名稱，值則是函式的引數個數。

匯入通常會加在模組定義的開頭。

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
