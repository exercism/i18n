# 元組

Elm 的元組可以存放兩個或三個值，而且每個值可以是任何型別。
在 Elm 中，元組大多用於簡單的暫時性型別。
基於這個原因，元組最多只能有 3 個值；而且為了進一步鼓勵這麼做，只提供處理 2 個值的便利函式。
對於更複雜的資料，最好改用記錄。
一個常見的用途，是需要從函式回傳多個值的時候。
元組的欄位沒有名稱，只能透過解構或依位置來存取。

你可以閱讀[元組的簡明介紹][tuples-concise]。
另外還有[更深入的介紹][tuples-in-depth]，而 [Tuple 模組的 API 文件][tuple-core] 也包含程式碼範例與詳細說明。

## 宣告

元組的型別以括號建立，其中的元素型別以逗號分隔。

```elm
type alias IntStringTuple = (Int, String)
```

### 建立

元組以括號建立，其中的元素以逗號分隔。

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

你也可以使用 `Tuple.pair` 建立包含兩個值的元組。

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### 存取

也有依位置存取元組值的函式：`Tuple.first` 和 `Tuple.second`。

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

元組可以在綁定中透過元組模式比對來_解構_。
解構可以用在 `let`運算式、函式宣告與 `case`敘述中。

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

在 `case`敘述中的模式比對，也能讓你比對值本身的內容：

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
