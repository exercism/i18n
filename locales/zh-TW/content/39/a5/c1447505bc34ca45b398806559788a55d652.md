# 簡介

在 R 裡，`list`是一種有順序的項目集合，和`vectors`有幾個不同之處：

- 項目可以是不同的型別（例如把`numeric`和`character`混在一起）。
- 項目可以是複雜的結構（例如向量、其他 list 等等）。
- 存取元素時也有不同的語法。

和其他語言做類比並不精確。
R 的`list`有點像 Python 的字典，但`list`是有順序的，而且可以用數字索引來存取。
它也有點像 C 的`struct`，只是`list`可以在執行時輕鬆擴充。

## 建立 list

為元素命名（通常稱為「標籤」）在 list 上比在向量上更常見：

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

不過標籤是可有可無的，沒有標籤時，R 就會直接使用索引編號：

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## 存取 list 元素

有三種做法，各自適合不同的情境。

### 1. 使用`$tag`記法

如果事先就知道標籤名稱，這是最常用的方式。

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. 使用`[[tag]]`記法

這種方式的好處是，標籤名稱可以在執行時才決定。
注意這裡用了兩層中括號。

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 使用位置索引

不論 list 有沒有標籤，這種方式都能用。
同樣地，這裡的括號也是兩層。

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 新增與刪除元素

很簡單：對元素指定值時，如果元素已經存在就會修改，如果是新的就會插入。

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

要刪除時，把`NULL`指定給不想要的元素。

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
