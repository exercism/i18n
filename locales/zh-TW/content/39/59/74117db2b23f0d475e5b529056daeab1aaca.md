# 說明

籃網球訓練從跑圈開始。教練會讓每一圈都比上一圈再長一點：第一圈 100 公尺，第二圈 110 公尺，第三圈 120 公尺，以此類推，每次多 10 公尺。

這三個任務都寫在`WARM_UP_LAPS`類別裡。

## 1. 總共多遠？

給定圈數，算出總距離。

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

也就是 100 + 110 + 120。零圈就是零公尺。

## 2. 要跑幾圈才夠遠？

給定一個以公尺為單位的距離，要跑幾圈，累計距離才會至少達到這麼遠？

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

零公尺不需要跑任何一圈。

## 3. 哪一圈首先變長？

給定一個以公尺為單位的距離，哪一圈*本身*的長度第一個超過這個距離？第 1 圈是 100 公尺，第 2 圈是 110 公尺，以此類推。

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

第 3 圈是 120 公尺，是第一個超過 115 的圈。
