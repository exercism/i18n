# 簡介

`Enum`是一個非常實用的模組，提供了一整套處理可列舉資料的演算法。它能排序、篩選、分組、計數、搜尋、找出最小值與最大值，還有許多其他功能。

一般來說，_可列舉資料_就是任何可以被疊代的資料，也就是一種集合。在 Elixir 裡，可列舉資料是指任何實作了`Enumerable`[協定][exercism-protocols]的資料型態。其中最常見的是[陣列][exercism-lists]和[字典][exercism-maps]。

許多`Enum`函式都接受函式作為引數。

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

最常見的`Enum`函式是`map`和`reduce`。

## `map/2`

`Enum.map/2`讓你用另一個元素取代可列舉資料中的每一個元素。`Enum.map/2`的第二個引數是一個函式，它接受原始的元素，並回傳用來取代它的新元素。

## `reduce/3`

`Enum.reduce/3`讓你把整個可列舉資料_縮減_成單一的值。為了做到這件事，會使用一個特別的變數，叫做_累加器_。累加器會在每一次疊代之間，保存縮減過程的中間狀態。

`Enum.reduce/3`的第二個引數是累加器的初始值。第三個引數是一個函式，它接受一個元素和一個累加器，並回傳累加器的新值。

## 處理字典

在把字典搭配`Enum`函式使用時，字典會自動轉換成一個由 2 個`{key, value}`元組組成的陣列。

如果要把它轉回字典，請使用`Enum.into/2`。`Enum.into/2`會把可列舉資料轉換成可收集資料，也就是任何實作了`Collectable`協定的資料結構。你可以把它想成`Enum.reduce/3`的反向操作。

`Enum`也有`Enum.into/3`。`Enum.into/3`是`Enum.into/2`的變化版，它接受一個轉換函式，在把可列舉資料轉換成可收集資料的過程中套用。

### 對字典進行映射

除了用`Enum.into/3`，或是用`Enum.map/2`加上`Enum.into/2`來對字典套用轉換（映射）之外，我們也可以使用專用的`Map.new/2`函式。它的運作方式和`Enum.into/3`一模一樣，同樣接受一個可列舉資料和一個轉換函式，但它一定回傳一個新的字典，而不是讓我們自己挑選可收集資料。
