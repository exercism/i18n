# 簡介

Gleam 中的陣列是零個或多個值的不可變集合。陣列中的值都必須具有相同的型別。由於陣列是不可變的，一旦建立陣列，它的值就永遠不會改變。任何看似會修改陣列（例如新增元素）的函式/運算子，實際上都會回傳一個新的陣列。

陣列可以像這樣定義：

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

將元素新增到陣列最常見的方式，是透過展開語法：

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam 標準函式庫中的[`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html)模組包含許多處理陣列的實用函式。這個模組在 Gleam 程式碼中非常常用，因此熟悉它會很有幫助。

陣列模式可以在`case`運算式中使用，以比對陣列並將其中包含的值指定給變數：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

除了比對確切長度的陣列之外，展開語法也可以用來比對至少某個長度的陣列：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

展開語法也可以用來將陣列其餘的部分指定給變數：

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

`case`運算式應該為被比對的型別中每個可能的值都有一個模式，因此通常會使用最後的丟棄模式（`_`）來處理任何剩餘的值。
