# 數字

`INT` 是 Sather 用來表示整數的型別：`0`、`7`、`-3`。一個以整數回應的常式，會在冒號後面說明這件事，就像以文字回應的常式會寫 `STR` 一樣。

```sather
   goals : INT is
      return 42;
   end;
```

常式可以接受**引數**，也就是呼叫常式時傳入的值。每個引數都有名稱和型別，寫在常式名稱後面的括號裡：

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

當兩個引數的型別相同時，可以把它們的名稱寫在一起：

```sather
   total(first, second : INT) : INT is
```

呼叫時把值放進括號裡：

```sather
SCORES::total(3, 4)     -- this is 7
```

算術運算子一共有五個：`+`、`-`、`*`、`/` 和 `%`。

用在兩個 `INT` 上的 `/` 是**整數除法**：它會把餘數直接捨去，而不是得到小數。

```sather
7 / 2      -- 3, not 3.5
```

`%` 則會給出那次除法剩下來的部分。

```sather
7 % 2      -- 1
```

兩者互相搭配：`7` 是 `3` 個 `2`，還剩下 `1`。
