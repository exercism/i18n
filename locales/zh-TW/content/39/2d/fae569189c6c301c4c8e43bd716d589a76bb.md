# 指示

你的一位朋友開了一家老字號的批發店，叫做**Gross Store**。

這個名字來自店裡販售的商品數量：全部都是以 [gross 單位][gross-unit] 來計算。

你的朋友請你幫他的店實作一套銷售時點系統（POS）。

**首先，你要先為它建立一個雛型。**

**在你的雛型中，系統只會記錄數量。**

你的朋友給了你一份測量單位清單，方便你參考：

| 單位               | 數值 |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 在你的程式中儲存測量單位

為了使用這些測量單位，你需要先把單位儲存在程式中。

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. 建立新的客戶帳單

你需要實作一個函式，為客戶建立一張新的（空的）帳單。

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. 在客戶帳單中加入項目

要實作這個功能，你需要：

- 如果給定的`unit`不在`units`對照表中，回傳`false`。
- 否則，將該項目以項目名稱為索引加入客戶的`bill`，然後回傳`true`。
- 如果該項目已經在帳單中，就依給定的`unit`所屬的數量增加它的數量。

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> 注意，回傳值的型別是`bool`。

## 4. 從客戶帳單移除項目

要實作這個功能，你需要：

- 如果給定的項目**不在**帳單中，回傳`false`。
如果項目的數量是 0，就視為不在帳單中。
- 如果給定的`unit`不在`units`對照表中，回傳`false`。
- 如果新的數量會小於 0，回傳`false`。
- 如果新的數量是 0，就視為已從`bill`移除該項目，因此可以回傳`true`。
- 否則，減少該項目的數量並回傳`true`。

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> 注意，回傳值的型別是`bool`。

## 5. 回傳客戶帳單中特定項目的數量

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> 注意，回傳值的型別是`u32`。

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
