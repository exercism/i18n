# 簡介

Common Lisp 中的雜湊表是一種用來儲存關聯式資料的資料結構。
它會把鍵（可以是任何物件）對應到值（可以是任何物件）。
其他程式語言可能把這個概念稱為映射、字典或雜湊。

## 建立雜湊表

雜湊表可以用`make-hash-table`函式建立。

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

（請注意，雜湊表列印出來的樣貌取決於實作，所以在你的 REPL 中看起來可能不一樣。）

## 用鍵取得值

想從雜湊表中用鍵取得值，可以使用`gethash`函式：

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash`會回傳[多重值][concept-multiple-values]，這會在另一個概念中說明。

## 插入值

想把值插入雜湊表，可以像這樣把`setf`和`gethash`搭配使用：

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

這會把雜湊表`*hash-table*`中鍵`:foo`的值改成`:bar`。
它會回傳這個值。

`setf`的用法會在另一個概念中說明。
