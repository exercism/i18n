# 簡介

Common Lisp 有許多不同的相等性述詞。
這點和其他程式語言不同，那些語言可能只有 1、2 個（例如`==`和`===`）。
Common Lisp 中有些述詞是特定型別專用的，有些則是通用的。
這裡要談的是後者。

通用的相等性述詞有四個，它們的差別在於判斷「相等」時的嚴格程度。
由最嚴格到最寬鬆依序是：`eq`、`eql`、`equal` 和 `equalp`。

以下是簡要的定義（省略了一些細節）：

- `eq`：將相等定義為兩個物件是同一個物件。
  _例如_：

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`：將相等定義為：型別和值都相同的兩個數字、相同的兩個字元，或者對其他任何東西而言，只要它們 `eq` 便相等。
  _例如_：

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`：將相等定義為：兩個串列若其中每個元素也 `equal`，則它們 `equal`；兩個字串若其中每個元素 `eql`，則它們 `equal`；兩個陣列若 `eq`，則它們 `equal`；其他一切若 `eql`，則 `equal`。
  _例如_：

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`：將相等定義為：字串和字元以不區分大小寫的方式比較；數字比較時會做某些型別轉換；串列和陣列若每個元素也 `equalp`，則它們 `equalp`；結構若型別相同且所有槽都 `equalp`，則它們 `equalp`；雜湊表若其鍵和值都 `equalp`，則它們 `equalp`。
  _例如_：

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
