# 指令

在這個練習中，你將會產生半結構化的日誌訊息。

## 產生半結構化的訊息

你會從幾個尚未實作的函式，以及下面這個 enum 開始：

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

你的目標是產生像這樣的日誌訊息：`"[<LEVEL>]: <MESSAGE>"`。
你需要實作對應各日誌等級的函式。

例如，下面的程式碼片段示範了 `log` 函式預期的輸出。

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

那`info`呢？

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```
