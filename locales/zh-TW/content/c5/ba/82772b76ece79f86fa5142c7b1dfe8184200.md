# 關於

在 Haxe 中，**陣列**是一群（通常）型別相同的元素。在 Haxe 裡有三種建立陣列的方式，可以透過建構子，也可以透過宣告語法。在 Haxe 中，陣列的第一個元素索引為零：

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

若要使用建構子建立陣列，你需要傳入要放進陣列中的元素型別：

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

由於在 Haxe 中存取陣列沒有邊界限制，也就是保證不會拋出例外，因此這需要進一步討論：

- 若讀取不存在的索引，會回傳一個依目標平台而異的值。
- 若以超出範圍的正索引寫入，`null`（或靜態目標上基本型別的預設值）會插入到最後一個已定義索引與新寫入的索引之間的所有位置。
- 若以負索引寫入，結果未明確定義。

如果想讓陣列包含多種型別的元素，就在型別標註中加上`Dynamic`型別：

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## 疊代

陣列可以使用`for`迴圈來疊代：

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
