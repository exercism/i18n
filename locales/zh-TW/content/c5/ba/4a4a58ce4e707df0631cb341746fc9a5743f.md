# 簡介

## 元組

元組是一種有序的容器，用來存放值。就像所有 Gleam 資料型態一樣，元組是不可變的。元組中的每個元素可以是不同的型別，甚至可以再是其他元組。

元組的定義方式，是把以逗號分隔的值放在`#(`和`)`之間：`#(1, 2.0, "Three")`。

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

長度相同、型別也相同（且順序相同）的元組可以比較是否相等。

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

有三種方式可以把元組裡的值取出來：

- 索引。
- 用`let`做模式配對。
- 用`case`做模式配對。

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 170

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
