# 說明

在這個練習中，你會寫程式來分析汽車工廠裝配線的生產狀況。
裝配線的速度範圍從`0`（關閉）到`10`（最高）。

在最慢的速度（`1`）下，每小時可以生產`221`輛車。
產量會隨速度呈線性成長。
所以當速度設為`4`時，每小時應該生產`4 * 221 = 884`輛車。
不過，速度越高，就越可能生產出瑕疵車，而這些車之後必須被淘汰。
下表說明速度如何影響成功率：

- `1`到`4`：100% 的成功率。
- `5`到`8`：90% 的成功率。
- `9`：80% 的成功率。
- `10`：77% 的成功率。

你有兩項任務。

## 1. 計算每小時的生產率

實作`AssemblyLine#production_rate_per_hour`方法，計算裝配線每小時的生產率，並將成功率納入考量。
請注意，回傳的值是`Float`的實例。

```ruby
AssemblyLine.new(6).production_rate_per_hour
#=> 1193.4
```

## 2. 計算每分鐘生產多少個可用的成品

實作`AssemblyLine#working_items_per_minute`方法，計算每分鐘生產多少輛**完成且可用**的車。
請注意，回傳的值是`Integer`的實例。

```ruby
AssemblyLine.new(6).working_items_per_minute
#=> 19
```
