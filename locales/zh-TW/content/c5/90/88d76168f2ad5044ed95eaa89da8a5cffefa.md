# 指令

你附近的一所學校有個非常活躍的學生會。
學生會由會長管理，每 2 年會舉辦一次選舉，選出新任會長。

今年的選舉決定要採用一套新的數位計票系統。
學校需要你幫忙打造這套新系統。

## 1. 建立計票器

新的投票系統首先需要的東西之一，就是計票器。
這個計數器可以用來追蹤某位候選人目前的票數。

建立一個函式`NewVoteCounter`，它接受某位候選人的初始票數，並回傳一個指向`int`的指標，以給定的初始票數初始化。

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. 從計數器取得票數

現在你有辦法建立新的計數器了！但你發現新系統還需要一個方法，能從計數器取得票數。

建立一個函式`VoteCount`，它接受一個計數器（`*int`）作為引數，並回傳該計數器中的票數。
如果計數器是`nil`，就假設該計數器沒有任何票數：

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. 增加計數器的票數

終於要來計票了！現在你需要一個方法來增加計數器裡的票數。

建立一個函式`IncrementVoteCount`，它接受一個計數器（`*int`）和一個票數作為引數，並將計數器增加該票數。
你可以假設傳入的指標永遠不會是`nil`。

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. 建立選舉結果

所有票都算完之後，該準備向全校公布結果了。
為此，你發現只有票數的計數器還不夠。
需要一個方法把票數和某位候選人關聯起來。

建立一個函式`NewElectionResult`，它接收候選人的名字和票數，並回傳一個新的選舉結果。

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

選舉結果的結構體已經幫你建立好了，定義如下：

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. 宣布結果

該向全校宣布新任會長了！
新任會長會透過學校裡的小型數位看板來公布。
訊息應該以下列格式顯示新任會長的名字和得票數：`<candidate_name> (<votes>)`。
這種訊息的範例如下：`"Peter (51)"`。

建立一個函式`DisplayResult`，它接收一個`*ElectionResult`作為引數，並回傳一個字串，內容是要顯示的訊息。

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. 重新計票

為了確認最終結果準確無誤，票數重新計算了一次。
在重新計票時，發現某些候選人的票數差了一票。

建立一個函式`DecrementVotesOfCandidate`，它接收最終結果，以及一位要調降票數的候選人名字。
最終結果以`map[string]int`的形式提供，其中鍵是候選人的名字，值是該候選人的總票數。

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
