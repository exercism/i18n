# 簡介

## 型別轉換

Go 在不同型別之間需要明確的轉換。
型別之間的轉換（也稱為**型別轉型**）是透過以目標型別為名的函式來完成。
舉例來說，要把 `int` 轉換成 `float64`，你需要這樣做：

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## 在基本型別與字串之間轉換

有一個 `strconv` 套件可以在基本型別（例如 `int`）與 `string` 之間轉換。

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## 型別斷言

Go 中的介面可能會讓底層型別變得不明確。
型別斷言讓我們可以用以下語法，取出介面值底層的具體值：`interfaceVariable.(concreteType)`。

例如：

```go
var input any = 12
number := input.(int)
```

注意：如果介面變數沒有持有具體型別的值，就會導致 panic。

我們可以利用型別斷言的兩個回傳值，來測試介面值是否持有某個特定的具體型別：底層的值，以及一個回報斷言是否成功的布林值。
例如：

```go
str, ok := input.(string) // no panic if input is not a string
```

如果 `input` 持有 `string`，那麼 `str` 會是底層的值，而 `ok` 會是 true。
如果 `input` 沒有持有 `string`，那麼 `str` 會是 `string` 型別的零值（也就是 `""`，空字串），而 `ok` 會是 false。
無論哪種情況都不會發生 panic。

## 型別切換

**型別切換**可以連續執行多個型別斷言。
它的語法和型別斷言（`interfaceVariable.(concreteType)`）相同，只是把 `concreteType` 換成關鍵字 `type`。
以下是一個例子：

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
