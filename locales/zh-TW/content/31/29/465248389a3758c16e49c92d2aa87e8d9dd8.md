# 避免使用 print 敘述

試著從你的程式碼中移除像`System.out.println()`這樣的敘述吧。
練習的測試要求解法要從方法_回傳_值，而不是把它們印出來。

通常，這類敘述是為了協助除錯才加進去的。
不過，更好的做法是在執行一或多個單元測試的同時除錯。
這樣做還有一個額外的好處：可以專注於除錯某個特定的測試案例。

以下是一些連結，說明如何在各種 IDE 中一邊執行單元測試、一邊除錯 Java 程式碼：

- [在 Visual Studio Code 中執行與除錯 Java 測試](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [在 IntelliJ IDEA 中除錯測試](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
