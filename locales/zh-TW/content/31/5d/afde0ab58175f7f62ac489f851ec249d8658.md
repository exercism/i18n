# 關於

[類別](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes)是在 F# 中進行物件導向程式設計的主要建構。

F# 中的類別是由它的欄位和方法組成。類別的欄位和方法稱為它的_成員_。

在 F# 中，類別是使用`type`關鍵字定義的。方法是使用`member`關鍵字定義，而且一律是公開的。若要定義（私有）欄位，可以使用`let`繫結。

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

類別是用來建立物件的範本。若要建立類別的執行個體，請把類別名稱當成函式來呼叫。類別的執行個體也稱為_物件_。

可以使用點記法存取物件的成員。

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
