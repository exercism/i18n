# 說明

在這個練習中，你會處理日誌行。

每一行日誌都是一個格式如下的字串：`"[<LEVEL>]: <MESSAGE>"`。

日誌等級有三種：

- `INFO`
- `WARNING`
- `ERROR`

你有三個任務，每個任務都會拿到一行日誌，並要你對它做點處理。

你可以自由使用 base R 的舊式函式，或是`stringr`套件，兩者都能寫出簡短可行的解法。

## 1. 從日誌行取得訊息

實作`message`函式，回傳日誌行的訊息：

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

開頭或結尾的空白都應該被移除：

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. 從日誌行取得日誌等級

實作`log_level`函式，回傳日誌行的日誌等級，而且要以小寫回傳：

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. 重新格式化日誌行

實作`reformat`函式，重新格式化日誌行，把訊息放在前面，並在後面用小括號加上日誌等級：

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
