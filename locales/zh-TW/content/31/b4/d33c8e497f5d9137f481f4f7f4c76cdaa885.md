# 簡介

## 例外篩選

`when`是篩選例外時所用的關鍵字。它放在 catch 敘述之後，可以接受一個布林運算式，其中包含當下作用域內的任何值。如果該運算式評估為 true，就會執行該 `catch` 敘述所屬的程式區塊；否則會檢查下一個 `catch` 敘述（如果有的話）。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## 自訂例外

自訂例外是你程式碼中任何衍生自`System.Exception`的類別。它必須遵守類別繼承的所有規則，但除此之外，編譯器和語言執行階段會以特殊方式對待這類類別，讓它們的執行個體可以在正常控制流程之外被拋出和攔截，就如同`exceptions`練習中所討論的那樣。

自訂例外常用來攜帶額外資訊，例如訊息和其他相關資料，供負責攔截的程式碼取用。
