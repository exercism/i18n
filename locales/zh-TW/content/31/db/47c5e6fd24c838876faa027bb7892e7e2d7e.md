# 說明

Elaine 正在開發一款新的兒童遊戲，裡面有動物和魔杖。現在該來寫幾個函式了：擲骰子、產生隨機的魔杖能量，還有打亂切片。

## 1. 擲骰子

實作一個`RollADie`函式。

這會是傳統的二十面骰，數字從 1 到 20。

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. 產生魔杖能量

實作一個`GenerateWandEnergy`函式。
魔杖能量要是一個隨機的浮點數，大於等於 0.0 且小於 12.0。

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. 打亂切片

遊戲裡有 8 種不同的動物：

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

寫一個`ShuffleAnimals`函式，回傳一個把這 8 種動物隨機排列的切片。
