# 說明

你是個超級鐵道模型迷，決定開始發行電子報，把你的熱情分享給全世界。首先，你要把電子報的第一期寄給同樣熱愛這項嗜好的朋友和熟人。你有一個文字檔，裡面是他們的電子郵件地址清單。

## 1. 從檔案讀取電子郵件地址

實作`Newsletter.read_emails/1`函式。它應該接受一個檔案路徑。這個檔案是純文字檔，裡面是以換行符號分隔的電子郵件地址。這個函式應該回傳檔案中所有電子郵件地址的陣列。

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. 開啟日誌檔以寫入

寄送電子郵件可能因為許多難以預期的原因而失敗，例如電子郵件地址打錯字，或是暫時的網路問題。為了確保你能重試寄送郵件給所有朋友，又不會重複寄送，你需要記錄下已經收到郵件的電子郵件地址。為此，你需要一個日誌檔。

實作`Newsletter.open_log/1`函式。它應該接受一個檔案路徑，開啟該檔案以寫入，並回傳處理這個檔案的行程 PID。

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. 記錄已寄出的郵件

實作`Newsletter.log_sent_email/2`函式。它應該接受處理該檔案的行程 PID，以及包含電子郵件地址的字串。它應該把電子郵件地址寫入檔案，後面加上一個換行符號。

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. 關閉日誌檔

實作`Newsletter.close_log/1`函式。它應該接受處理該檔案的行程 PID，並關閉該檔案。

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. 寄送電子報

現在你已經有了寄送郵件流程的所有基礎元件，接著要把這些元件組合成單一個函式。

實作`Newsletter.send_newsletter/3`函式。它應該接受電子郵件地址檔案的路徑、日誌檔的路徑，以及一個匿名函式，用來把郵件寄給指定的電子郵件地址。它應該從指定的檔案讀取所有電子郵件地址，並嘗試寄送郵件給每一個地址。如果負責寄送郵件的匿名函式回傳`:ok`，就把該電子郵件地址寫入日誌檔，後面加上一個換行符號。請務必在郵件寄出後立即寫入。所有郵件都寄送完畢後，關閉日誌檔。

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
