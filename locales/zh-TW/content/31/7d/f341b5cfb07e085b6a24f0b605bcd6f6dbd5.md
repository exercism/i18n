# 安裝

## 安裝 Node.js

**Windows 和 OS X 使用者**：請[透過套件管理器][node-download]安裝 [Node.js][node]。

**Linux 使用者**：請依照你的發行版本在 [Node.js 套件管理器][linstall] 上找到的說明安裝 [Node.js][node]。

## 安裝 `jasmine-node` 和 `coffeescript`

對大多數使用者來說，只需要執行下面這道指令：

```bash
$ npm install -g jasmine-node coffeescript
```

視你的環境設定而定，你可能需要超級使用者權限，才能全域安裝 `npm` 模組。
如果你用的是上面連結的官方安裝程式，就會遇到這種情況。
如果 NPM 出現錯誤訊息說你沒有存取權限，請在上面的指令加上 `sudo`：

```bash
$ sudo npm install -g jasmine-node coffeescript
```

如果你用的是官方安裝程式，你的 `PATH` 應該已經自動設定好了。但如果你的 shell 找不到全域安裝的模組，或者你是從原始碼建置 Node.js，請把下面這行加進 `~/.bash_profile` 或 `~/.zshrc`，讓 `PATH` 包含 `npm` 的執行檔：

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
