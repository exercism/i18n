# 簡介

在 Go 裡，應用程式是以套件來組織的。
套件是位於同一個資料夾裡的一組原始碼檔案。
同一個資料夾裡的所有原始碼檔案，在檔案最上方都必須有相同的套件名稱。
依照慣例，套件的名稱會和它所在的資料夾相同。

```go
package greeting
```

Go 提供了豐富的標準函式庫，你可以在程式中使用`import`關鍵字來取用這些套件。
匯入標準函式庫的套件時，使用的是套件名稱。

```go
package greeting

import "fmt"
```

匯入套件之後，就使用套件名稱來取用它：

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go 會依據項目的宣告方式，決定其他套件中的程式碼能不能呼叫它。
想讓函式、型別、變數、常數或結構體欄位能從外部看見（也就是_匯出_），名稱就必須以大寫字母開頭。
這和 Java 等其他會使用`public`、`private`這類存取修飾子的程式語言很類似。

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
