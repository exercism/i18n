# 指令

在這個練習中，你會撰寫程式碼，用來追蹤你想在 Exercism 上學習的程式語言陣列。

這個練習有九個任務，每個任務都會用到陣列。

## 1. 建立一個新的陣列

為了追蹤你想學的語言，你需要建立一個新的陣列。

請實作 static 方法 `Languages.NewList()`，讓它回傳一個新的空陣列。

```csharp
Languages.NewList()
// => empty list
```

## 2. 定義一個現有的陣列

目前，你有一張紙，上面列出你想學的語言：C#、Clojure 和 Elm。

請實作 static 方法 `Languages.GetExistingLanguages()`，回傳這個陣列。

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. 在陣列中加入新語言

當你在 Exercism 上探索、發現更多有趣的語言時，你會想把它們加進你的陣列。

請實作 static 函式 `Languages.AddLanguage()`，把新語言加到陣列的最後。

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. 計算陣列中的語言數量

一個一個數這些語言很不方便。

請實作 static 方法 `Languages.CountLanguages()`，計算陣列中語言的數量。

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. 檢查某個語言是否在陣列中

請實作 static 方法 `Languages.HasLanguage()`，檢查某個語言是否存在。

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. 反轉陣列

某個時刻，你發現你的陣列其實是反過來排序的！

請實作 static 方法 `Languages.ReverseList()`，把你的陣列反轉過來。

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. 檢查陣列是否令人興奮

雖然你喜歡所有語言，但 C# 在你心中有個特別的位置。因此，只要符合下列其中一個條件，你就會對一份語言陣列感到非常興奮：

- 陣列中的第一個是 C#。
- 陣列中的第二個項目是 C#，且陣列中剛好有兩個或三個語言。

請實作 static 方法 `Languages.IsExciting()`，檢查語言陣列是否令人興奮：

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.移除語言

請實作 static 方法 `Languages.RemoveLanguage()`，從陣列中移除指定的語言。

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. 檢查陣列中所有語言是否都不重複

請實作 static 方法 `Languages.IsUnique()`，檢查陣列中是否有任何語言重複。

呼叫這個方法時，語言陣列（也就是參數）保證不會是空的，而且陣列有沒有被修改都無所謂。

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
