# 說明

這是地方俱樂部的賽季最終戰。你在終點線負責成績排行榜，選手依序通過終點，車道需要標籤，而官方紀錄簿必須在下一輪賽事開始前完成註記。

選手名字會以陣列的形式、依完賽順序傳入，第 0 個名字是冠軍，第 1 個是亞軍，依此類推。

## 1. 指派號碼布

定義`assign-bibs`，接收一個選手名字的陣列，並回傳一個由`{ position name }`配對組成的陣列，位置排在前面。

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. 車道標籤

定義`lane-labels`，接收一個選手名字的陣列，並回傳像`"Lane 0: Bolt"`這樣的字串。

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. 為選手加上標記

定義`tag-racers`，接收一個選手名字的陣列*和*一個標記字串，回傳格式為`"<tag>/<index>: <name>"`的標籤。同一個標記會內嵌進每一個標籤。

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. 記錄完賽結果

定義`record-finishes`，接收一個選手名字的陣列和一本紀錄簿（向量）。對每一位選手，就地將格式為`"<index>: <name>"`的字串附加到紀錄簿。不回傳任何東西。

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. 圈數鈴聲

定義`lap-bells`，接收一個數字`laps`，並回傳由`"ding "`重複`laps`次所組成的字串。

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
