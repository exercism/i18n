# 指令

Lucian 的女朋友正在回家的路上，而他還沒煮好他們的週年紀念晚餐！

在這道練習中，你會寫一些程式碼，幫 Lucian 用他最愛的食譜做出一份精緻的千層麵。

這道練習共有四項任務，都跟烹調千層麵所花費的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義常數`expected_minutes_in_oven`，代表千層麵應該放在烤箱裡幾分鐘。根據食譜，預期的烤箱時間是`40`分鐘。

## 2. 計算剩餘的烤箱時間（分鐘）

實作`remaining_minutes_in_oven`方法，它會接受千層麵實際放在烤箱裡的分鐘數作為_參數_，並根據上一個任務的**預期的烤箱時間（分鐘）**，_回傳_千層麵還需要在烤箱裡待幾分鐘。

```abap
remaining_minutes_in_oven( 30 ).
// => 10
```

## 3. 計算準備時間（分鐘）

實作`preparation_time_in_minutes`方法，它會接受你加在千層麵裡的層數作為_參數_，並_回傳_你準備千層麵花了幾分鐘，假設每一層要花你 2 分鐘準備。

```abap
preparation_time_in_minutes( 2 ).
// => 4
```

## 4. 計算總工作時間（分鐘）

實作`total_time_in_minutes`方法，它會接受_兩個參數_：`numbernumber_of_layers`參數是你加在千層麵裡的層數，`actual_minutes_in_oven`參數則是千層麵放在烤箱裡的分鐘數。這個方法應該_回傳_你總共花了幾分鐘烹調千層麵，也就是準備時間（分鐘）加上千層麵當下已經放在烤箱裡的分鐘數。

```abap
total_time_in_minutes( 
  numbernumber_of_layers = 3
  actual_minutes_in_oven = 20 ).
// => 26
```
