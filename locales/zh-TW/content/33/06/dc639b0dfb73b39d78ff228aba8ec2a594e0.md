# 關於

F# 中的 [`list`][lists] 是零個或多個值的不可變集合。陣列中的值全都必須具有相同的型別。由於陣列是不可變的，一旦建立完成，它的值就永遠無法改變。F# 的陣列有_頭_（第一個元素）和_尾_（第一個元素之後的所有元素）。陣列的尾本身也是一個陣列。

定義陣列的方式如下：

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

最常見的新增元素方式，是透過 `::`（cons）運算子：

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

可以使用 `@` 運算子或 `List.append` 來串接陣列：

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

陣列是透過 [`List` 模組][list-module] 中定義的函式和運算子來操作。其中有些函式也可以透過 `list` 執行個體的[屬性][list-properties]來使用：

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

這裡沒有絕對的對錯。一般來說，`List` 模組中的函式在型別推斷上表現得更好，而屬性則可以讓程式碼更為精簡。

任何看起來會修改陣列的函式或運算子（例如新增元素），實際上都會回傳一個新的陣列。不過效能通常不是問題，因為陣列的實作會避免不必要的配置與複製。

由於陣列是以單向連結串列實作的，在開頭加入元素（使用 `::` 運算子）非常快速，而透過索引存取元素則可能相對較慢。

陣列也可以透過[_list_][list-pattern]和[_cons_][cons-pattern]模式，以模式比對來處理：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

在模式比對時，你也可以_捨棄_某個值；當你在某個特定情況中_不在意_某個值時（也就是你不打算_使用_它），可以用底線（`'_'`）來表示：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

在模式比對時，單一的 `'_'` 一定要放在_最後_，任何_不符合_其他情況的值，都會由這個情況來處理。
