# Import

[特殊形式 `import`][import] 允許你使用外部模組的函式和巨集，而不需要使用該模組的名稱。

匯入整個外部模組可能會與現有的本地函式產生衝突。為了避免這種情況，有兩個選項可用：`:except`和`:only`。兩者都接受一個關鍵字列表，其中鍵是函式名稱，值是該函式的引數個數。

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

通常 import 會加在模組定義的開頭，但也可以加在任何地方。它們具有詞法作用域，這表示加在函式定義內部的 import 就無法在另一個函式中使用。

未使用的 import 會導致編譯器警告。

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
