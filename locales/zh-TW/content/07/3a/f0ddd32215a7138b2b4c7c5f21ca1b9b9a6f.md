# 關於

迴圈基本上有兩種：

1. 重複執行直到某個條件成立。
2. 逐一走訪集合中的元素。

兩者在 [R 中都能做到][web-loops]，不過第一種可能更常見。

## `while` 與 `repeat`

對於沒有固定終點、事先不知道迴圈要跑幾次的問題，R 提供了帶有條件的 [`while`][ref-control] 迴圈，以及不帶條件的 [`repeat`][ref-control] 迴圈（等同於 `while (TRUE)`）。

基本形式相當簡單：

```R
while (condition) {
  do_something()
}
```

在這個例子中，程式會一直重複執行迴圈，直到`condition`不再是`TRUE`為止。

有兩種方法可以提早離開迴圈：

- `break`會讓迴圈結束，程式從迴圈結尾大括號`}`之後的下一行繼續執行。
- `return(x)`會停止目前函式的執行，並把回傳值`x`交還給呼叫方。

有了這些選項，有時會很方便：用`repeat { ... }`建立一個「無限」迴圈，然後在迴圈主體裡找出停止條件來觸發`break`或`return`。

這三種寫法等價，最後都會得到`x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## 走訪向量（或其他集合）

在 R 中，這通常不是必要的。
如同其他概念所討論的，許多函式會直接對整個向量運作。

不過，有時候還是無法避免使用明確的迴圈。
尤其是在下列情況：

- 迴圈主體帶有副作用，例如列印輸出或檔案 I/O。
- 迴圈會持續到某個條件達成，而疊代次數無法預期。

迴圈條件必須放在括號中。
和函式主體一樣，單行的迴圈主體可以省略大括號（但通常還是會寫上）。

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

如果目前這輪疊代不符合某個條件，可以用`next`直接跳到下一輪疊代：

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

如果需要數值索引，請使用 [`seq_along()`][ref-seq_along]。

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

不建議使用`i in 1:length(v)`，因為當`length(v)`為零時可能會出問題。
範圍`1:0`等同於`c(1, 0)`，所以迴圈主體會執行，而且很可能出錯。
`seq_along()`函式就是為了正確處理這種情況而設計的。
