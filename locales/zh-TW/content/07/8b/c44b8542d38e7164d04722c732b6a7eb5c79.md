# 練習測試

依照下列步驟，為練習開發解法並在本機測試。

## 下載練習

開啟 Command Prompt，並在下方指令中帶入你想下載的練習名稱來執行它。

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## 開發你的解法

1. 執行下方指令，切換到剛下載好的練習目錄。

     >**提示：** 下方指令中的目錄位置取決於你的作業系統，以及你設定的 Exercism 工作區。你可以執行`exercism configure`指令來查詢工作區的位置。

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. 依照提供的說明，為這個練習開發解法。

## 測試你的解法

有些 Ballerina 練習只包含一個測試，有些則包含多個測試。測試位於練習根目錄下`/tests`目錄中對應的測試檔案裡。

### 測試只有單一測試的練習

執行下方指令來執行這個練習的測試。

預設情況下，只有第一個測試是啟用的。這是刻意設計的，讓你專注在讓這一個測試通過就好。

```sh
bal test
```

### 測試有多個測試的練習

依照下列步驟來測試含有多個測試的練習。

1. 當第一個測試通過後，移除`@test:Config`註解的`enable: false`屬性，即可啟用下一個測試。

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  執行下方指令來執行已啟用的測試。

   ```sh
     bal test
   ```

3. 重複上面兩個步驟，啟用剩下的測試。

當你啟用所有測試，並確認你的實作能通過每一個測試，就成功完成這個練習了。
