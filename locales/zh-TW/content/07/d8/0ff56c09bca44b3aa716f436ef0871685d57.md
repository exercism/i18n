# 關於

`Complex numbers`一點也不複雜。
它們只是需要一個不那麼嚇人的名字。

它們非常實用，尤其在工程與科學領域，因此 Julia 將[複數][complex]與整數、浮點數並列為標準數值型別。

## 基礎

在 Julia 中，`complex`值本質上是一對數字：通常是浮點數，但並非總是如此。
基於一些不幸的歷史原因，它們被稱為「實部」與「虛部」。
同樣地，最好專注於它內在的簡潔本質，而不要被這些奇怪的名稱分心。

只要在虛部加上後綴`im`，就能用兩個實數建立複數。

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

因此，`Complex`型別有許多種，分別衍生自對應的整數或浮點數型別。

若要用實數變數建立複數，上述語法就行不通了。
寫成`a + bim`會讓解析器誤以為`bim`是一個（不存在的）變數名稱。

寫成`b*im`雖然可行，但偏好的方法是使用`complex()`函式。

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

你可能會想，為什麼是`im`，而不是`i`或`j`呢？

大多數工程師對`j`就很滿意了。
大多數科學家與數學家則偏好用數學符號`i`來表示_虛數_，但這個符號與電機工程中用`i`表示_電流_的慣例衝突。

[手冊][complex]指出：「使用數學家的 i 或工程師的 j 作為這個全域常數被否決，因為它們是非常熱門的索引變數名稱」。

巧合的是，這也避免了工程師與其他人之間的漫長爭執。
至於這是否影響了這項決定，就由你自己判斷吧。

若要分別取得複數的各個部分：

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

任一部分都可以是零，此時數學家可能會說這個數「完全為實」或「完全為虛」。
然而，在 Julia 中它仍然是複數。

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

你可能聽過「`i`（或`j`）是 -1 的平方根」這種說法。

就目前而言，這只代表虛部_依定義_滿足以下等式：

```julia-repl
julia> 1im * 1im == -1
true
```

這是個簡單的概念，卻能引出有趣的結果。

## 算術

所有用於浮點數與整數的標準數學`operators`與基本函式，也同樣適用於複數。以下是一些範例：

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

解釋複數乘法與除法的規則超出了這個概念的範圍（_而且你不太常有機會「手動」進行這些運算_）。

如果你想深入研究這個主題，任何關於複數的[數學][math-complex]或[電機工程][engineering-complex]入門教材都會涵蓋這些內容。

或者，Exercism 有一個`Complex Numbers`練習，讓你從基本原理出發，實作一個具備這些運算的複數類別。

整數除法在複數上（大多）___不可___行，因此`//`、`÷`與`%`運算子對複數型別會失敗。
例外情況是對複數_整數_使用`//`來得到複數有理數，但這大概不常派上用場。

## 函式

大多數數學函式都能接受複數輸入。

然而，提供實數輸入卻期待得到複數輸出，通常行不通。
這是一項效能最佳化，在你了解多重派發的概念之後應該會更能體會。

```julia-repl
julia> sin(1.5 + 2.0im)
3.752771340479298 + 0.25655395609048176im

julia> sqrt(-1)
ERROR: DomainError with -1.0:
sqrt was called with a negative real argument but will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).

julia> sqrt(-1 + 0im)
0.0 + 1.0im
```

除了`real()`與`imag()`之外，還有幾個函式與複數特別相關。
如果這些內容對你來說毫無意義，請直接略過！

- `conj()`只是把複數虛部的正負號反轉（_從 + 變 -，或反之_）。
    - 由於複數乘法的運作方式，它的用處比你想像的還要大。
- `abs(<complex number>)`保證會回傳一個沒有虛部的實數。
- `abs2(<complex number>)`會回傳`abs(<complex number>)`的平方：計算起來比`abs()`快，而且往往正是運算所需要的。
- `angle(<complex number>)`會回傳以弧度表示的相位角。

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
給對數學有興趣的人的部分解釋（_再次提醒，可以直接略過_）：

- `z1`的`(real, imag)`表示法實際上是在複數平面上使用笛卡兒座標。
- 同一個複數也可以用`(r, θ)`標記法表示，使用極座標。
- 在這裡，`r`與`θ`分別由`abs(z1)`與`angle(z1)`給出。

以下是一個使用一些常數的範例：

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

所以，一個含有自然界三個最重要常數`e`、`i`（或`j`）與`pi`的簡單運算式，得到了結果`-1`。
有些人認為這是整個數學中最美的結果。
這可以追溯到約 1740 年。

極座標`(r, θ)`標記法非常實用，因此內建了`cis`（`cos(x) + isin(x)`的縮寫）與`cispi`（`cos(πx) + isin(πx)`的縮寫）等函式，能幫助你更有效率地建構它。

極座標標記法的實用性體現在歐拉優雅的公式`ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`，其中`|x + iy| = 1`。
當`|x + iy| = r`時，我們得到更一般的極座標形式`r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`。
特別值得注意的是，指數形式既簡潔又易於操作。

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

上面的近似相等，是因為[`cis`][cis]與[`cispi`][cispi]這兩個函式能給出更漂亮的數值輸出，尤其是`cispi`在處理 π 的任意倍數（例如弧度！）作為引數時。

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

順帶一提，這讓複數在 2D 中進行旋轉與徑向位移時非常有用。

就旋轉而言，複數`z = x + iy`只要做一次簡單的乘法，就能繞原點旋轉一個角度`θ`：`z * ℯ^(iθ)`。
請注意，這裡的`x`與`y`只是實數 2D 笛卡兒平面上的普通座標，正角度會造成*逆時針*旋轉，負角度則會造成*順時針*旋轉。

同樣簡單地，只要把徑向位移`Δr`加到極座標形式複數的大小`r`上即可（例如`z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`）。
注意角度部分保持不變，只有大小`r`改變，正如預期。

## 選讀章節：複數常見問題

除非你有興趣，否則這部分可以略過。

### 這不是某種奇怪又嶄新的純數學嗎？

在 16 世紀時，它確實又奇怪又嶄新。

500 年後，它成了大多數工程與自然科學的核心。

### 為什麼會有人用這個？

事實證明，複數是描述任何會旋轉的事物、或任何具有波動性質之事物最簡單的方式。
因此它們被廣泛用於電機工程、音訊處理、物理、電腦遊戲與導航，這裡只列舉了其中幾個應用而已。

你能看見事物在旋轉。
複數或許不能讓世界運轉，但非常適合用來解釋世界運轉所造成的_各種現象_：看看任何一張大型風暴的衛星影像就知道了。

不那麼明顯的是，聲音具有波動性，光具有波動性，無線電訊號具有波動性，甚至你家鄉的經濟也至少有一部分具有波動性。

這些波動處理有很多可以用三角函式（`sin()`與`cos()`）來完成，但很快就會變得一團亂。

複數指數處理起來___容易___得多。

### 可是我根本不需要複數啊！

只有當你住在洞穴裡、靠覓食為生時，這句話才成立。

如果你正透過任何一種螢幕閱讀這段文字，你就完全仰賴著 20 世紀一些因複數而來的實用進展。

1. __半導體晶片__。
    - 它們在古典物理中毫無意義，只能用量子力學（QM）來解釋（與設計）。
    - 在 QM 中，一切依定義都是複數值。（_一路到底都是波形_）

2. __快速傅立葉轉換演算法__。
    - 快速傅立葉轉換（FFT）是複數的一項應用，凡是與聲音傳輸、音訊處理、照片與影片有關的_一切_，都少不了它。

    - MP3 與其他音訊格式使用 FFT 來壓縮，讓更多音訊能塞進更小的儲存空間。
    - 在眾多影像與影片格式中，JPEG 壓縮與 MP4 影片也使用 FFT 來壓縮。

    - FFT 也部署在數位濾波器中，讓手機基地台能把你的個人手機訊號與其他人的區分開來。

所以，你正在使用的科技，很可能每秒都依賴著數千次的複數運算。
