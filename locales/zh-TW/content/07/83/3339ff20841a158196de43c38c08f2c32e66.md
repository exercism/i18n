# 簡介

在硬體的最底層，[電晶體只有開啟和關閉兩種狀態][how-transistors-work]：我們傳統上用`1`和`0`來表示這兩種狀態。
這就是[`binary digits`][binary-digits]，縮寫為[`bits`][bits]。
對使用低階語言的系統程式設計師來說，了解`bits`和`binary`特別重要。
不過，縱觀電腦運算的發展史，程式設計一直以來的首要目標，就是找出越來越精妙的方法，把這個二進位的現實_抽象掉_。


在 Python（以及許多其他[高階程式語言][high-level-language]）中，我們使用`int`、`float`、`string`等各種已定義的_型別_，甚至涵蓋音訊和視訊格式。
Python 的內部機制會（_最終_）負責把所有更高階的資料轉換成位元。


不過，使用[位元運算子][python-bitwise-operators]和[位元運算][python-bitwise-operations]有時能在速度和記憶體效率上帶來明顯的優勢，即使是在 Python 這樣的高階語言中也不例外。
