# 提示

## 一般

- 不可變類別裡沒有`new`。`create`會從一個類別變數開始，而那個變數已經存在：

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)`不會改變`b`。它會得出一個新的方位，所以它就是被回傳的東西。

## 1. 取得方位

- `%`能把數字帶進範圍內，但`-10 % 360`會是`350`，只是因為 Sather 的`%`在右邊是正數時從不給出負值。所以光靠`d % 360`就夠了。

## 2. 轉向

- 把轉向加到角度上，再用總和產生新的方位：`#BEARING(degrees + by)`。
- `create`已經會把答案帶回範圍內，所以就算轉過北方也不用做任何事。

## 3. 比較

- 一行就好：比較兩個`degrees`。
- 引數的型別是`SAME`，用平常的方式讀取它的屬性：`other.degrees`。

## 4. 為方位點命名

- 訣竅是在相除之前先位移半個區段，這樣每個方位點就是以它的*中心*為基準來測量：`((degrees + 22) / 45) % 8`對北方會得到 0，對東北會得到 1，依此類推。
- 然後對那個數字用`case`，配上八個名稱，還要一個`else`；即使八個分支已經涵蓋所有可能的值，`case`永遠都需要`else`。

## 5. 寫下來

- `+`能把片段接起來，但只有字串可以加上東西。這裡數字在前面，所以需要`degrees.str`來起頭連接。`"a" + 1`沒問題；`1 + "a"`無法編譯。
- 呼叫`point`，不要再重新推算名稱。
