# 如何寫出好的支援請求

在 Exercism 上需要協助嗎？
學會怎麼寫出好的支援請求，並讓我們社群願意支持你，就能大大提升你得到好回覆的機會。

以下是一些關鍵訣竅。

## 使用程式碼區塊，不要用圖片

當你想分享程式碼（不論是你自己寫的，或是操作說明），請使用程式碼區塊，不要用圖片。

身為開發者，我們讀程式碼的速度，遠比把圖片放大來看清內容快得多。
而且我們有很多使用者會使用螢幕閱讀器，而螢幕閱讀器讀不出圖片。
所以如果你想當個優質的社群成員、想鼓勵我們的志工來幫你，也想讓自己看起來很專業，就用文字分享程式碼，而不是圖片！

例如，你可以輸入以下內容：

````
```
for number in range(10):
  total += number;
```
````

呈現出來會像這樣：

```
for number in range(10):
  total += number;
```

只要在程式碼區塊的開頭加上語言，還能獲得語法高亮：

````
```python
for number in range(10):
  total += number;
```
````

就會變成：

```python
for number in range(10):
  total += number;
```

## 使用包容性的語言

Exercism 是由不同性別的人組成的。
如果你在我們的 Discord 上說「Hey boys」這類的話，等於立刻把社群裡一半的人排除在外。
那代表他們比較不會幫你，但同時也代表社群裡其他人也比較不會幫你，因為 Exercism 很重視包容性。

所以如果你想獲得協助，也想當個友善的人，就不要用帶有性別指向的語言。
試試「Hey folks」、「Hey everyone」，或者大膽一點，選「Hey fellow Exercists!」

更多相關內容，請閱讀我們的文章[我們所使用的詞彙](./the-words-that-we-use)。
