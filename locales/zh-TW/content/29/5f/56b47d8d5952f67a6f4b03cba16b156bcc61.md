# 關於

F# 字串是不可變的物件，用來表示一段由 Unicode 字元（字母、數字、標點符號等）組成的文字。定義`string`實例時使用雙引號：

```fsharp
let fruit = "Apple"
```

要操作字串，可以呼叫它的[方法][methods]或[屬性][properties]，也可以使用[`String`模組][string-module]裡的函式。由於字串值一旦定義之後就永遠不會改變，所有字串操作方法或函式都會回傳一個新的字串。

字串是由雙引號（`"`）包起來的。有些特殊字元需要使用反斜線（`\`）來[跳脫][escaping]。字串也可以在開頭加上 at 符號（`@`），這樣就會成為[逐字字串][verbatim]，忽略所有的跳脫字元。

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

另一種定義字串的方式是使用[三重引號][triple-quoted]（`"""`），這樣就能在字串裡直接使用雙引號，不需要跳脫。

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

最後，可以用[`+`運算子][plus-operator]來串接字串：

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
