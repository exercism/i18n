# 綁定常式

到目前為止，我們傳遞來傳遞去的都是*值*：數字、字串、物件。**綁定常式**則讓你傳遞常式本身，也就是一個之後才會被呼叫的東西，而呼叫它的程式碼並不知道它是什麼。

替角正好就是這個概念：舞台監督手上握有一種飾演這個角色的方式，卻不知道要由誰來演，也不知道他會怎麼演。

## 建立一個綁定常式

`bind`接收一個帶有洞的呼叫，洞寫成`_`：

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

`part`現在就跟其他任何值一樣。要等到之後才會呼叫它：

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## 型別

綁定常式的型別是`ROUT`，引數型別放在大括號裡，回傳型別則接在冒號之後：

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

把`ROUT{STR}:STR`讀成「一個接受`STR`並回傳`STR`的常式」。

| 寫法 | 意義 |
| --- | --- |
| `ROUT{STR}:STR` | 接受一個`STR`，回傳一個`STR` |
| `ROUT{INT,INT}:BOOL` | 接受兩個`INT`，回傳一個`BOOL` |
| `ROUT{STR}` | 接受一個`STR`，不回傳任何東西 |
| `ROUT:INT` | 不接受任何東西，回傳一個`INT` |

既然它是一種型別，自然也能當成引數：

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse`完全不知道`part`在做什麼。這正是重點：它可以收到`shout`、`whisper`，或任何其他同樣形狀的東西。

## 填入部分引數

不是每個引數都非得是洞。凡是明確寫出來的部分，都會在綁定的當下固定下來：

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice`只接收 line，因為`2`已經決定了。這個值會在綁定的當下算出來並保存下來，所以之後再改動它來自的那個變數也沒有影響。

這就是一個通用常式變成許多專用常式的方式。

## 連物件一起綁定

對於物件上的常式來說，物件是呼叫中的第一個東西，可以固定下來，也可以留成一個洞：

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
