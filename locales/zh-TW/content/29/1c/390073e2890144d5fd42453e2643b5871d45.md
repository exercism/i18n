# 提示

## 一般

SGF 語言具有遞迴定義：

```none
GameTree = "(" Sequence { GameTree } ")"
```

也就是說，一個 GameTree 是一段以`(`開頭的文字，後面接著一段稱為「Sequence」的文字（一連串遊戲節點），_後面再接著**零個或多個**子 GameTree_，最後以`)`結尾。

不過，由於遊戲樹可以任意深度地巢狀在其他遊戲樹中，標準的正規表示式功能不夠強大，無法追蹤巢狀層級。

解決這個練習有幾種做法：

### 狀態機

你可以逐字元掃描輸入字串，並維護一個保存目前位置的變數。
你可以根據目前位置的字元，追蹤解析後文字的目前狀態。
「目前狀態」可能像是「正在讀取屬性名稱」或「位於屬性值內」。
用這種做法需要追蹤許多值。

### 解析器

[以 PEG 為基礎的解析器][PEG-parser]是解析具有定義文法的語言的絕佳方式。
LPeg 是一種 PEG 解析器，而它是 MoonScript 的必要相依套件之一，所以你已經可以使用它。
解析器讓你可以撰寫規則，描述文字應該長什麼樣子。
例如，「屬性名稱全部是大寫字母」，或「屬性值被包在括號中」。
接著，解析器會負責將輸入文字與你的規則比對，處理最繁重的工作。
