# 簡介

和其他程式語言一樣，C++ 也提供了 `switch` 敘述。
`switch` 敘述是改寫冗長 `if ... else if` 敘述的更簡短方式。
要建立 switch 敘述時，我們會先使用關鍵字 `switch`，後面接著一個整數。
接著用 `case` 關鍵字宣告每一個條件。
我們也可以宣告一個 `default` 分支，當前面所有 `case` 條件都不符合時，就會執行它。
每個 case 都應該以 `break`（或 `return`）敘述做結尾。

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## 貫穿

switch 建構有一個很重要的地方：程式碼會繼續執行，直到被 `break`（或 `return`）敘述停下來為止。
這可能會導致非預期的行為。

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

這種繼續執行特性最主要的用途，是讓一個敘述擁有多個標籤。
多個 switch 結果可以對應到同一段要執行的程式碼。
這樣一來，舉例來說，在訂房應用程式中，團體人數為 2 和 3 時所呼叫的函式就可以是同一個：
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
