# 說明補充

## 軌道專屬說明

為了簡單易讀，可以考慮使用 Scala 的集合函式來取代 Java 的`String`方法。
請記住，在 Scala 中，`String`隱式地也是`Seq[Char]`，所以你可以像呼叫`String`方法一樣輕鬆地呼叫它們。

例如：
- 用`filter`取代`replaceAll`
- 用`take`、`takeRight`、`drop`、`head`、`tail`取代`substring`

另一個值得探索的想法，可能是把`String`改成`List[Char]`，然後使用`::`運算子來進行[模式匹配][pattern matching]。

[pattern matching]: http://alvinalexander.com/scala/how-to-use-lists-nil-cons-scala-match-case-expressions
