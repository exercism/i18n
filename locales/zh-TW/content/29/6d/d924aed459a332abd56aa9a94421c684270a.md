# 測試

## 執行測試

要執行測試，請執行以下指令：

```bash
bats test-<exercise-slug>.bats
```

### bats 是以 bash 實作的

bats 檔案是一個 bash 腳本，裡面有一些 `bats`指令能辨識的特殊函式。
你會看到一些測試長得像這樣

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

那個`<<<`語法是 bash 的*Here String*。
它會把右邊的字串送進左邊程式的標準輸入。
它大致等同於

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## 跳過的測試

解開一道練習，代表要讓它所有的測試都通過。
預設情況下，執行測試時只會執行一個測試（第一個）。
這是刻意設計的，讓你專注在讓那一個測試通過就好。
一旦它通過了，只要把加在其他測試前面的

    [[ $BATS_RUN_SKIPPED == true ]] || skip

標註註解掉或刪除，就能啟用下一個測試。

## 覆寫跳過設定

若要執行所有測試，包括帶有 `skip`標註的測試，可以執行：

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

或者，你也可以從測試檔案中把這一行註解掉或刪除：

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```
