# 疊代

在程式設計中，[疊代][iteration]指的是重複執行程式區塊多次的過程。你可以使用 while 迴圈和 until 迴圈等概念來達成，也可以使用遞迴，也就是一個會呼叫自己的函式。

不過，大多數時候你想疊代的是一組項目，例如`Array`、`Range`或`String`。Crystal 中的`Array`和`Range`類別都包含[`Enumerable`][enumerable]模組，它提供了許多疊代元素的方法。而`String`類別則有自己的一套方法，用來疊代字元。

Crystal 也沒有其他語言那樣的 for 敘述。它改用幾個方法來進行疊代。

## 疊代

對集合進行疊代最常見的方式，是使用[`each`][each]方法，它會把集合中的每個元素傳給區塊。用`Range`就能輕鬆做到這點。假設你想在 1 到 3 之間迴圈，就可以用`each`方法疊代這個範圍。

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

更簡單的是，如果你只想疊代固定的次數，可以使用[`times`][times]方法，它定義在`Int`類別上。

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## 疊代`String`

`String`是一串字元，不屬於`Enumerable`模組，也就是說它有自己的方法來疊代字元。疊代`String`最常見的方式是使用[`each_char`][each_char]方法，它會把`String`中的每個字元傳給區塊。

~~~~exercism/note
`each_char`方法傳給區塊的是`Char`物件，而不是`String`物件。
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

疊代`String`的另一種方式是使用[`each_line`][each_line]方法。這個方法大多用在逐行讀取檔案的時候。

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## 疊代包含`Enumerable`模組的物件

[`Enumerable`][enumerable]模組提供了許多方法，用來疊代集合中的元素。包含`Enumerable`模組的集合有`Array`、`Range`、`Hash`、`Set`等等，後面這些會在之後的概念中介紹。

疊代`Array`最常見的方式是使用[`each`][each]方法，它會把`Array`中的每個元素傳給區塊。

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### map

[`map`][map]方法是疊代`Array`的另一種方式，它會回傳一個新的`Array`，裡面是把區塊套用到每個元素後的結果。它和`each`方法很類似，但會回傳一個包含轉換後元素的新`Array`。當你想把某個函式套用到集合中的每個元素時，轉換就非常有用，而這是很常見的操作。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

搭配`if`之類的控制流程，你還可以篩選要轉換哪些元素。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### 搭配索引

有時候你需要知道目前疊代到的元素索引，這時可以使用[`each_with_index`][each_with_index]或[`map_with_index`][map_with_index]方法。它會把每個元素和它的索引傳給區塊，這個方法也接受一個選用引數來指定起始索引。

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

請注意，`String`物件也可以使用[`each_char_with_index`][each_char_with_index]方法。

### sum

[`sum`][sum]方法會回傳集合中所有元素的總和，它也接受選用的區塊，在加總前先轉換元素。它還接受一個選用引數，用來指定總和的初始值。

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce]，在其他語言中稱為 fold，是一個搭配合併方法和初始值，把集合中所有元素合併起來的方法。`reduce`方法有一個累加器會傳給區塊，累加器是前一次疊代的結果。這會形成一個遞迴的過程，把集合中的所有元素合併起來。

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce`看起來可能和`sum`很像，但`reduce`更有彈性，因為它可以讓你指定累加器的初始值和合併方法。`reduce`可以用來實作`sum`、`count`等方法。
