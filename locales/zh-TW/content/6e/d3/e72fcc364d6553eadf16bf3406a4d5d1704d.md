# 指令補充

## 例外訊息

有時候，我們必須[拋出例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做的時候，一定要附上**有意義的錯誤訊息**，說明錯誤的來源是什麼。這能讓你的程式碼更容易閱讀，也對除錯有很大的幫助。如果你知道錯誤來源會是某個特定的型別，可以選擇拋出其中一種[內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習要求你使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在`classify()`函式收到不是_正整數_的數字時「拋出」`ValueError`。唯有同時`raise`這個`exception`並附上訊息，測試才會通過。

若要拋出帶有訊息的`ValueError`，請把訊息寫成`exception`型別的引數：

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
