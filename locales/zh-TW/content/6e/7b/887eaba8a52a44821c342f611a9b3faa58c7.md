# 指令

請實作一個函式：給定二維座標平面上的 2 個點，產生第三個點，讓這些點連起來後可形成一個正三角形。這個函式會輸出 2 個點，因為給定最初的 2 個點之後，有 2 個可能的「第三個」點都能形成正三角形。值得留意的是，正三角形的定義是一個 3 條邊長度都相等的圖形。

函式的輸入是 2 個 Python 元組，每個元組以浮點數指定該點的 x 與 y 座標。例如，(0.0, 0.0) 和 (1.0, 1.0) 都可以是輸入。

函式應輸出一個元組，其中包含 2 個元組，每個元組以浮點數指定該點的 x 與 y 座標。例如，((0.0, 0.0), (1.0, 1.0)) 可能是其中一種輸出。

如果 Z3 solver 產生的結果無法滿足，函式應引發 Python 內建的 ArithmeticError 例外。如果 2 個輸入點相同，也應該引發 ArithmeticError。

函式不應使用 z3 函式庫中的「set_option()」函式來設定全域參數。這件事會在測試案例中完成，以確保浮點數具備預期的精確度（小數點位數）。

由於 Z3 Real 變數的模型解讀會是 AlgebraicNumRef、IntNumRef 或 RatNumRef 的實例，因此提供了一個函式，將這個實例轉換成浮點數。
