# 關於

在 Haskell 中有一個型別 `Num`，它是所有數值型別的基礎型別。
數字型別底下有四種主要的子型別：[`Int`][int]、[`Integer`][integer]、[`Double`][double] 和 [`Float`][float]。

Haskell 中有兩種整數型別，用來表示整數。
`Int` 是固定大小的整數，而 `Integer` 是任意精度的整數。
`Integer` 可以容納任何數字，無論多大，只受限於你機器的記憶體，而 `Int` 對應的是能以 32 或 64 位元表示的正負整數集合（保證至少有 -2^29 到 2^29 - 1）。

請注意，書寫負數時你應該使用括號，以避免產生歧義。

```haskell
1

(-1)
```

`Float` 對應實數的集合，但受電腦精度所限。
定義在數字上的運算通常只適用於其中一種型別，而不是兩者通用。
`Double` 是雙精度的浮點數。

```haskell
10.5
```

## 整數與浮點數之間的轉換

使用 `toFloat` 函式，可以將 `Int` 或 `Integer` 轉換成 `Float`。

```haskell
toFloat 1
-- -> 1.0
```

另外還有 `fromIntegral`，它會將任何數值型別轉換成推斷出的所需型別。

```haskell
fromIntegral 1
-- -> 1.0
```

若要將 `Float` 轉換成 `Int`，可以使用 [`round`][round]、[`floor`][floor] 或 [`ceiling`][ceiling] 函式。
`round` 函式會取最接近的整數，`floor` 會向下取整，而 `ceiling` 會向上取整。

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## 算術運算子

你可以在數值型別上使用[基本算術運算子][math]。
這些運算子是 `+`、`-`、`*`、`/` 和 `%`。
使用這些運算子時，數字的型別必須相符。
`fromIntegral` 函式會負責轉換，讓型別相符。

### 加法、減法與乘法

`+` 運算子用於加法，`-` 運算子用於減法，`*` 運算子則用於乘法。

| 運算子 | 範例 |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 除法

除法用來將數字相除。
`/` 運算子用於除法。
結果一律是浮點數。

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
在某些程式語言中，除以零的結果會是錯誤。

在 Haskell 中，除以零的結果會是 `Infinity` 或 `-Infinity`。
唯一的例外是零除以零，結果會是 `NaN`（非數字）。

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## 整數除法

整數除法用來將整數相除，並取得結果的整數部分。
Haskell 有兩個整數除法函式，它們的差異在於結果為負數時的取整方式：

- `div` 會向下取整，朝負無限大的方向。
- `quot` 則朝零的方向取整。

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
使用整數除法時除以零，會產生例外。
這與一般除法不同。
~~~~

### 餘數

整數除法的餘數可以用 `mod` 或 `rem` 求得。
當其中一個數字為負數時，它們的差別在於結果的正負號：

- `mod` 會與 `div` 搭配使用，其結果的正負號與除數相同。
- `rem` 會與 `quot` 搭配使用，其結果的正負號與被除數相同。

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

對於任何 `x` 和 `y`（其中 `y` 不為零），下列定律成立：

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
當兩個數字都是正數時，`div` 和 `quot` 的結果相同，`mod` 和 `rem` 也是如此。
這種情況下，`quot` 和 `rem` 可能會稍微更有效率，因為 `div` 和 `mod` 需要額外的步驟來處理負數。
~~~~

~~~~exercism/caution
使用 `mod` 或 `rem` 除以零，會產生例外。
這與一般除法不同。

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## 指數運算

Haskell 有三個「次方」運算子，它們的運作方式不同，接受的引數型別也不同。

- `**` 接受兩個**浮點數**，並使用對數來計算次方。
- `^^` 接受一個**浮點數**，並將它提升到正或負**整數**次方。
- `^` 接受**任何數值型別**，並將它提升到**正整數**次方。

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## 優先順序與括號

Haskell 允許使用括號（`()`），可以用來將運算式分組。
當你想改變運算順序時，這就很有用。

使用多個算術運算子時，運算順序與數學中相同，也就是所謂的 [PEMDAS][pemdas]。
它依循括號（`()`）、指數（`**`）、乘法（`*`）與除法（`/`），以及加法（`+`）與減法（`-`）的順序。

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
