# 簡介

Elixir 提供了優雅的語法來處理二進位資料，就像我們在處理[位元字串][exercism-bitstrings]時所看到的`<<>>`特殊形式一樣。

二進位型別是位元字串型別的一種特例。位元字串的長度可以是任意的（任意數量的[位元][wiki-bit]），而二進位則要求位元數能被 8 整除。也就是說，處理二進位資料時，我們通常會以[位元組][wiki-byte]（8 位元）為單位來思考。一個位元組可以表示從`0`到`255`的整數。我們經常以[十六進位][wiki-hexadecimal]來處理位元組值，例如 `0x00 - 0xFF`。

二進位字面值是用位元字串的特殊形式`<<>>`來定義的。定義二進位字面值時，我們可以使用整數和字串字面值。大於 255 的整數值會溢位，只有整數的最後 8 個位元會被採用。預設情況下，值會套用`::binary`修飾符。我們可以用`<>/2`運算子來串接二進位資料。

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

_空位元組_是`<<0>>`的另一個名稱。

## 二進位資料的模式匹配

[模式匹配][exercism-pattern-matching]甚至可以延伸到二進位上，我們可以對一部分的二進位資料做模式匹配，就像我們對陣列所做的一樣。

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

和其他類型的模式匹配一樣，我們可以在函式簽章中使用這個技巧，在從多個函式子句中挑選時進行匹配。
