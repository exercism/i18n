# 說明

在這個練習中，你會實作一組部分的工具常式，用來協助開發者清理識別字名稱。

在這 6 個任務中，你會逐步建構出兩個函式：`transform`用來轉換單一字元，`clean`則用來轉換字串。

有效的識別字可以由零個或多個字母、底線、連字號、問號和表情符號組成。

如果傳入`clean`函式的是一個空字串，就應該回傳空字串。

## 1. 將遇到的連字號換成底線

實作`transform`函式，將任何連字號取代為底線。

```fsharp
transform '-'  // => "_"
```

## 2. 移除所有空白

移除所有空白字元。
這也包含開頭和結尾的空白。

```fsharp
transform ' '  // => ""
```

## 3. 將 camelCase 轉成 kebab-case

修改`transform`函式，將 camelCase 轉成 kebab-case。

```fsharp
transform 'D'  // => "-d"
```

## 4. 略過數字字元

修改`transform`函式，略過任何數字字元。

```fsharp
transform '7'  // => ""
```

## 5. 將希臘小寫字母換成問號

修改`transform`函式，將 'α' 到 'ω' 範圍內的希臘字母換成問號。

```fsharp
transform 'β' // => "?"
```

## 6. 組合這些操作來處理字串

實作`clean`函式，將這些操作套用到整個字串。

不符合規則的字元應該原封不動地保留下來。

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## 從字元組合成字串

這個主題之後會在課程大綱中詳細介紹。

目前先知道有個叫做[`String.collect`][string-collect]的[高階函式][higher-order-function]可能會有幫助，它會使用你提供的函式，把一組`char`轉換成字串。

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```

[higher-order-function]: https://exercism.org/tracks/fsharp/concepts/higher-order-functions
[string-collect]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-stringmodule.html#collect
