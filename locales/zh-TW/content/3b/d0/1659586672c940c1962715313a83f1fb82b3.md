# 說明

你的朋友剛傳了一則訊息給你，裡面有個重要的秘密。
他不想讓別人輕易讀懂，所以把訊息經過一連串的位元操作加密了。
你需要撰寫函式來協助解密這則訊息。

## 1. 將位元移回去

解密訊息的第一步，就是把加密時做的移位還原，將位元往右移回去。
解密過程後續還有一些步驟，會假設是從左側補進 0。

實作`shift_back()`函式，它接受一個值和要移位的位數，並執行移位。

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. 設定一些位元

接下來，有些位元需要設為 1。

實作`set_bits()`函式，它接受一個值和一個遮罩，並回傳把值中的位元設為 1 的結果。
當 `mask` 中的某個位元是 1 時，`value` 中對應的位元也應該設為 1。
其他所有位元則保持不變。

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. 翻轉特定的位元

加密時有些位元會被翻轉。
要解密訊息，就得把它們翻轉回來。

實作`flip_bits()`函式，它接受一個值和一個遮罩。
遮罩指出值中哪些位元要翻轉。
如果 `mask` 中的位元是 1，`value` 中的該位元就會被翻轉。
其他所有位元則保持不變。

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. 清除特定的位元

最後，還有一些特定的位元解密後一定是 0。

實作`clear_bits()`函式，它接受一個值和一個遮罩。
當遮罩中的位元是 1 時，`value` 中對應的位元應設為 0。
其他所有位元則保持不變。

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
