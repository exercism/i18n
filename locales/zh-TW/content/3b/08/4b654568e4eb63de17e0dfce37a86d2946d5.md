# 提示

## 一般

這些函式的回傳值屬於特定的型別，所以要特別留意。

## 1. 定義一個具名向量

- 名稱與值所需的資訊都在說明裡。
- 建構具名向量的方法在簡介中有詳細介紹。

## 2. 回傳某個色環對應的值

- 你可以用你的`resistor_bands`具名向量輕鬆完成這件事。
- 你需要單獨回傳一個數值。

## 3. 回傳兩個色環對應的值

- 你的`band_value`函式在這裡很好用。
- 具名向量的索引提示在簡介裡。
- 有幾種方式可以建構這個數字，最常見的是透過字串處理或數值方式。
- 回傳的數字必須是單獨的數值。

## 4. 回傳三個色環對應的歐姆值

- `band_value`和`two_band_value`在這裡都很有用。
- 向量中的前兩個值構成雙色環的值，第三個則是乘數。
- 同樣地，可以用字串處理或數值方式取得這個數字。
- 回傳的數字必須是單獨的數值。
