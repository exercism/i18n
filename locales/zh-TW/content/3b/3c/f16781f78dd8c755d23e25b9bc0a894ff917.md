# 說明

在這個練習中，我們要模擬一場 [Blackjack](https://en.wikipedia.org/wiki/Blackjack) 遊戲的第一回合。

你會拿到兩張牌，並能看到莊家的明牌。所有牌都用字串表示，例如 "ace"、"king"、"three"、"two" 等等。每張牌的點數如下：

| 牌  | 點數 | 牌  | 點數 |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**注意**：一般來說，ace 可以算作 1 點或 11 點，但為了簡單起見，我們假設它只能算作 11 點。

根據你的兩張牌以及莊家的牌，遊戲的第一回合有一套策略，你可以從中選擇以下幾個選項：

    - Stand (S)
    - Hit (H)
    - Split (P)
    - Automatically win (W)

雖然還不是最佳策略，但你要採用你朋友 Alex 正在開發的策略，內容如下：

類別：大牌

- 如果你拿到一對 ace，一定要分牌。
- 如果你拿到 Blackjack（兩張牌加總為 21 點），而莊家的牌不是 ace、人頭牌或 ten，你就會自動獲勝。如果莊家有其中任何一張牌，你就必須停牌，等待另一張牌揭曉。

類別：小牌

- 如果你的牌加總為 17 點或以上，一律停牌。
- 如果你的牌加總為 11 點或以下，一律要牌。
- 如果你的牌加總落在 [12, 16] 這個範圍內，一律停牌，除非莊家持有 7 點或以上，這種情況下就一律要牌。

整體的邏輯已經實作完成。你有四個任務：

## 1. 計算任一張牌的點數。

實作一個函式，根據牌的名稱並使用條件式來計算出這張牌的點數。

```java
parseCard("ace")
// returns 11
```

## 2. 判斷兩張牌是否組成 Blackjack。

實作一個函式，如果兩張牌組成 Blackjack 就回傳`true`，否則回傳`false`。

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. 實作手牌點數大於 20 點時的決策邏輯。

實作一個函式，根據你的牌回傳代表某項決策的字串。這個函式只有在`handScore`大於 20 時才會被呼叫。它會接收 2 個引數：`isBlackJack`和`dealerScore`。它應該實作上面「大牌」類別中列出的要點。

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. 實作手牌點數小於 21 點時的決策邏輯。

實作一個函式，根據你的牌回傳代表某項決策的字串。這個函式只有在`handScore`小於 21 時才會被呼叫。它會接收 2 個引數：`handScore`和`dealerScore`。它應該實作上面「小牌」類別中列出的要點。

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
