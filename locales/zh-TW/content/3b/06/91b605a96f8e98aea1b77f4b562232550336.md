# `case`敘述

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## 比對的方式

`case`後面的值會由上而下，用`=`和每個`when`的值做比較。第一個相符的分支會執行，而且只執行那一個。其餘的`when`部分會被跳過，流程接著從`end`之後繼續。

任何支援`=`的型別都可以使用：`INT`、`CHAR`、`STR`、`BOOL`。

## `else`

如果`case`比對不到任何值，又沒有寫`else`，執行時就會引發致命錯誤。所以一定要寫一個。當剩下的情況確實不該發生時，就在那裡明講，而不是乾脆省略：

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise`之後才會學到；在那之前，回傳一個合理的預設值是沒問題的。

## 什麼時候該用`if`

`case`是把一個值和常數做比較。其他情況就該用`if`：

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

硬把一段範圍塞進`case`，寫出來的東西會比原本的`if`更長、更糟。

## `case`當作運算式

`case`是敘述，不是運算式，所以下面這種寫法不是 Sather：

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

請在各個分支裡直接回傳，或是在各個分支裡把值指定給變數。
