# 程式碼內含

```sather
   include WARM_UP;
   include WARM_UP count -> warm_up_count;
   include WARM_UP describe -> ;
   include WARM_UP count -> beats, describe -> ;
```

`include`會把另一個類別的程式碼複製到這個類別裡。它是在編譯期進行的操作，沒有執行期成本，也不會建立任何執行期關係：這兩個類別之後並不相連。

## 子句

```
   include CLASS  old_name -> new_name , old_name -> ;
```

每個項目會為一個特性重新命名。`-> ;`後面沒有新名稱，就代表把它排除在外。沒有提到的部分則原封不動地引入。

重新命名只影響*外部*看到的部分。被引入的常式之間的呼叫仍然有效：如果`describe`呼叫`count`，而`count`被重新命名為`beats`，那麼`describe`呼叫的就是`beats`。

## 引入多個類別

```sather
   include WARM_UP;
   include COOL_DOWN;
```

這是允許的，也是 Sather 實現其他語言所稱多重繼承的方式，而且沒有常見的麻煩，因為衝突會是編譯錯誤，解決辦法就是重新命名或省略其中一個。沒有任何東西得靠你必須背下來的優先順序來決定。

## private include

```sather
   private include WARM_UP;
```

會把程式碼引入，供這個類別自己使用，而不對外公開。當你想要的是實作而不是介面時，這就很有用。

## 兩者並用

類別家族常見的形式如下：

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class ACT_BASICS is
   minutes : INT is return 5; end;
end;

class JUGGLING < $ACT is
   include ACT_BASICS;
   name : STR is return "Juggling"; end;
end;
```

`< $ACT`說明它能做什麼；`include ACT_BASICS`則提供部分的做法。當你改變做法時，`<`不需要跟著更動。

## 為什麼要這樣做

抽象類別沒有程式碼，所以不會在無意間被繼承，也不會有那種行為在你腳下悄悄改變的父類別。重複使用是在編譯期從你指定的類別複製一份，而且每一次重新命名都寫得清清楚楚。

代價是每個類別都必須明確要求重複使用。這就是取捨：要打的字更多，但沒有任何隱含的東西。
