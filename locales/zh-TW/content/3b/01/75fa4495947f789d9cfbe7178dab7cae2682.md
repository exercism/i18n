# 說明

Daphne 一直在開發一套系統，用來執行並記錄她實驗的結果。有些程式碼變得有點冗長、重複，所以她請你寫幾個`use`運算式來幫忙整理。

## 1. 定義`with_retry`函式

有時候實驗可能會因為一次偶發的失誤而失敗，所以如果實驗失敗了，Daphne 想再重試一次，看看第二次是否會成功。

定義`with_retry`函式，它接受一個會回傳結果的函式作為引數。

如果這個函式回傳`Ok`值，`with_retry`就應該回傳那個值。

如果這個函式回傳`Error`值，`with_retry`就應該再次呼叫這個函式，並回傳那次呼叫的結果。

Daphne 會這樣使用這個函式：

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. 定義`record_timing`函式

Daphne 會在每個實驗前後呼叫記錄時間的函式，藉此記錄每個實驗執行所需的時間。

定義`record_timing`函式，它接受兩個引數：
- 一個記錄時間的函式，它不接受任何引數，並回傳`Nil`。
- 一個實驗函式，它不接受任何引數，並回傳結果。

`record_timing`應該先呼叫記錄時間的函式，接著呼叫實驗函式，然後再次呼叫記錄時間的函式，最後回傳實驗函式的結果。

Daphne 會這樣使用這個函式：

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. 定義`run_experiment`函式

實驗由三個階段組成：設定、動作與記錄。三個階段都會回傳結果，而且每個階段都需要前一個階段成功回傳的結果才能執行。

定義`run_experiment`函式，它接受四個引數：
- 實驗名稱，型別為`String`。
- 一個設定函式，它不接受任何引數，並回傳結果。
- 一個動作函式，它接受設定函式的`Ok`值作為引數，並回傳結果。
- 一個記錄函式，它接受設定與動作函式的`Ok`值作為引數，並回傳結果。

如果三個函式都成功，`run_experiment`應該回傳`Ok(#(experiment_name, recording_data))`。

如果其中任何一個函式回傳`Error`值，`run_experiment`就應該回傳那個值。

Daphne 會這樣使用這個函式：

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
