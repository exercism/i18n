# 可變性

Cairo 的設計以區塊鏈為導向，預設採用不可變的記憶體模型。
這表示一旦某個值被寫入記憶體，就無法被覆寫，只能讀取。
不過，Cairo 提供了使用`mut`關鍵字建立可變變數的機制。
當變數宣告為可變，而且值被改變時，新的值會寫入新的記憶體單元，變數也會更新為指向這個新的記憶體單元。
這套機制在保有不可變性的優點之餘，也帶來了彈性。

在下面的範例中，`x`被宣告為不可變變數。
如果改變`x`的值，編譯器會拋出錯誤。

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

我們可以使用`mut`關鍵字，把`x`宣告成可變變數。
這讓`x`的值可以在宣告之後被改變。

```rust
let mut x = 5;
x = 10;
```

最後，要不要使用可變性取決於你，取決於你認為在當下的情況裡怎麼寫最清楚。

## 常數

就像不可變變數一樣，常數是綁定到某個名稱、不允許改變的值，但常數和變數之間有幾點不同：

- 常數使用`const`關鍵字宣告
- 你不能在常數上搭配`mut`使用
- 值的型別必須一律明確指定
- 常數只能在全域作用域中宣告
- 常數只能設為常數運算式，不能是執行時期計算出來的結果

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

你可以使用`consteval_int!`巨集，建立值為某種計算結果的`const`變數。

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## 遮蔽

當某個值經過轉換時，可以透過多次`let`重新宣告來重複使用同一個變數名稱，這不僅可行，也常常是慣用寫法。
這就叫做_遮蔽_。
實際上，第二個變數會遮蔽第一個變數，變數名稱的所有使用都會指向第二個變數，直到它本身也被遮蔽，或是作用域結束為止。

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

善用遮蔽，我們甚至可以在重複使用同一個變數名稱的同時，改變變數的型別。

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
