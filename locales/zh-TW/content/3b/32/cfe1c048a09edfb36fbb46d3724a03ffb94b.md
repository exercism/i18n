# 簡介

## 字串

回想一下，`jq`支援與 JSON 相同的資料型態。
JSON 將**字串**描述為：

> 字串是由零個或多個 Unicode 字元組成的序列，並以雙引號包住，使用反斜線跳脫。

### 跳脫序列

在字串中，使用反斜線字元來嵌入「特殊」字元：

- `\"`字面上的引號，
- `\\`字面上的反斜線，
- 空白字元`\n`、`\t`、`\r`、`\f`、`\b`
- Unicode 字元`\uAAAA`，其中`A`是十六進位數字

### 字串長度

若要找出字元數量，請使用`length`函式。

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### 子字串

**slice**標記法可用來擷取子字串。
語法是`.[i:j]`。
回傳的子字串長度為`j - i`，包含從索引`i`（含）到索引`j`（不含）之間的字元。
任一個索引都可以是負數，此時會從字串結尾往回計算。
任一個索引都可以省略，此時代表字串的開頭或結尾。
索引從 0 開始。

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### 串接

使用`+`來串接字串：

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

當你拿到一個字串陣列時，使用`add`：

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### 分割與合併

分割使用`split/1`函式或`/`運算子：

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1`的反向操作是`join/1`。

我們經常需要把字串轉成字元陣列。
有兩種做法：

1. 以空字串分割

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. 用`explode`拆解成一個_碼點_陣列

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode`是`explode`的反向操作。

### 尋找子字串的索引

使用`index/1`函式；索引從 0 開始。

```jq
"hello" | index("el")'   # => 1
```

如果字串中沒有這個子字串，結果會是`null`

```jq
"hello" | index("elk")   # => null
```

### 字串插值

在字串中，`\(expression)`這個序列會把該運算式的_結果_[嵌入字串][interpolate]：

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### 大小寫轉換

使用`ascii_downcase`和`ascii_upcase`函式。

### 正規表示式

`jq`對正規表示式有豐富的支援：這會是之後某個單元的主題。

[interpolate]: https://jqlang.org/manual/#string-interpolation
