# 關於

在 C# 中處理數字時，其中一個關鍵面向，就是區分整數（小數點後沒有位數的數字）與浮點數（小數點後有零或多個位數的數字）。

C# 中最常用的兩種數值型別是`int`（32 位元整數）與`double`（64 位元浮點數）。

```csharp
int i = 123;
double d = 54.29;
```

整數與浮點數都可以使用`_`字元作為_數字分隔符號_，這在定義大數字時很有幫助：

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

算術運算使用標準的[算術運算子][arithmetic-operators]（`+`、`-`、`*`等）來進行。數字可以使用標準的[比較運算子][comparison-operators]（`<`、`>=`等），以及[等於][equality-operators]運算子（`==`）和[不等於][equality-operators]運算子（`!=`）來比較。

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

在數值型別之間轉換時，有兩種數值轉換：

1. 隱式轉換：不會遺失資料，也不需要額外的語法。
2. 顯式轉換：可能會遺失資料，而且需要以_轉型_形式呈現的額外語法。

由於`int`的精確度比`double`低，因此從`int`轉換成`double`是安全的，所以屬於隱式轉換。不過，從`double`轉換成`int`可能會遺失資料，因此需要顯式轉換。

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
