# 指令

身為一位見習魔術師，Elyse 需要練習一些基本功。

她有一疊牌，想要加以擺弄。

為了讓事情簡單一點，她只使用 1 到 10 的牌。

這疊牌以`Array`表示，牌堆的底部在陣列的前端，牌堆的頂端在後端。

## 1. 在牌堆頂端插入一張牌

實作函式`insert_top`，它會回傳一份牌堆的副本，並將提供的新牌加到牌堆頂端。

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. 從牌堆移除頂端的牌

實作函式`remove_top_card`，它會回傳一份已移除頂端那張牌的牌堆副本。

如果給定的牌堆是空的，就應該回傳原本的牌堆，內容不變。

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. 在牌堆底部插入一張牌

實作函式`insert_bottom`，它會回傳一份牌堆的副本，並將提供的新牌加到牌堆底部。

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. 從牌堆底部移除一張牌

實作函式`remove_bottom_card`，它會回傳一份已移除底部那張牌的牌堆副本。

如果給定的牌堆是空的，就應該回傳原本的牌堆，內容不變。

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. 檢查牌堆的大小

實作函式`check_size_of_stack`，用來檢查牌堆的大小是否等於給定的`stack_size`。

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
