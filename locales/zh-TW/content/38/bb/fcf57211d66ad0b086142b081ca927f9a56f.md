# 簡介

## 方法多載

在 Java 中，方法多載是一項功能，讓同一個類別可以有多個同名的方法，只要它們的參數列不同就好。
它與編譯時期（或靜態）多型有關。
想要建立執行相似工作、但輸入不同的方法，就要先了解這個概念。

### 為什麼要使用方法多載？

方法多載能提升程式的可讀性。
不同的方法可以取相同的名稱，但使用不同的參數。
程式會根據參數的數量或參數的型態，呼叫對應的方法。

### 如何使用方法多載？

方法多載的關鍵在於方法的簽章。
如果兩個方法的簽章不同，就會被視為不同的方法。
方法多載有兩種方式：

1. **參數數量不同**：方法可以同名，但參數數量不同。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **參數型態不同**：方法可以同名、參數數量也相同，但型態不同。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### 注意事項

- 多載的方法必須改變引數列。
- 多載的方法也可以改變回傳型別，但只是改變回傳型別並不算方法多載。
- 方法可以在同一個類別中多載，也可以在子類別中多載。
