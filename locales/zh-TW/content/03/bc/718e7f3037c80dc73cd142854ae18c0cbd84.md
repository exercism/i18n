# 簡介

我們在`Vectors`概念中看過，向量可以用在條件運算式裡，產生一個邏輯向量。
而這個邏輯向量又能用在`all()`和`any()`這類函式中。

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

這個技巧的威力遠不只如此。

## 向量子集

我們可以用索引數字，或是一組索引構成的向量，把向量中選定的元素取出來：

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

或者，你也可以用邏輯向量來篩選原始向量，回傳對應到`TRUE`的那些項目所構成的子集：

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

從這裡再往前一小步，就能用條件運算式產生布林向量：

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## 找出索引

`which()`函式接受一個布林引數，並回傳會得到`TRUE`的索引向量。

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## 檢查某個項目是否存在

前面幾節談的是找出符合某個條件的項目。

如果你只是想知道向量裡有沒有某個特定元素，可以使用`%in%`運算子。

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

這在功能上等同於下面這段程式碼，但方便得多：

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
