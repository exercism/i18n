# 指令

你任職的公司想減少碳足跡，因此希望你寫一支程式，用來計算他們電子設備的用電量和運轉成本。

## 1. 取得額外時數

你的雇主有一個程式，可以計算不同電子設備的運轉時間。目前時間是以小時為單位儲存。當你的雇主把時數加總時，發現時間長度不正確。他們希望你替時間資料再加上 3 小時。他們也想知道，在把資料換算成「完整」天數（一天是 24 小時）之後，會剩下多少「額外」時數。要換算的時間未必是完整的天數。

實作一個 `get_extra_hours()` 函式，接受一個代表時數的整數。這個函式應該做出適當的「額外時數」調整，然後 `return` 一個整數，代表必須從總時數中扣除多少小時，才能得到以「完整」天數表示的時間。

```python
>>> get_extra_hours(25)
4
```

## 2. 取得 kW 值

你的雇主想知道各個電子設備以 kW 計算的用電量。kW 代表千瓦（kilowatt），其中瓦特是功率的單位。單位名稱中的 kilo 是公制字首，意思是 1000。1 千瓦等於 1000 瓦特。

實作一個 `get_kW_value()` 函式，接受一個代表瓦特數的整數。這個函式應該把瓦特數換算成千瓦，然後 `return` 四捨五入到小數點後 1 位的結果。

```python
>>> get_kW_value(1150)
1.2
```

## 3. 取得 kWh 值

為了計算電子設備的運轉成本，你的雇主需要知道以 kWh 表示的用電量。kWh 代表千瓦小時（kilowatt-hour），其中小時是時間單位。1 千瓦小時等於 1000 瓦特持續使用 1 小時。1 小時由 60 分鐘組成，1 分鐘由 60 秒組成。1 小時等於 3600 秒。要計算 kWh 值，你必須把瓦特換算成 kW，再將結果除以 3600 並向下取整。

實作一個 `get_kWh_value()` 函式，接受一個代表瓦特數的整數。這個函式應該 `return` 千瓦小時數，並以整數表示。

```python
>>> get_kWh_value(5000000)
1
```

## 4. 取得效率

電子設備並非 100% 有效率。因此，你的雇主希望你計算電子設備的_效率_。要取得效率，你必須把功率因數（_0 到 100 之間的浮點數_）除以 100。

實作一個 `get_efficiency()` 函式，接受一個代表功率因數的浮點數。這個函式應該 `return` 計算出的效率，並以浮點數表示。

```python
>>> get_efficiency(80)
0.8
```

## 5. 取得成本

你的雇主想知道電子設備的運轉成本。運轉成本等於使用的電力乘以每 kWh 的成本。使用的電力等於給定的功率除以計算出的效率。

實作一個 `get_cost(<watts>,<power_factor>,<price>)` 函式，接受一個代表瓦特數的整數、一個代表功率因數的浮點數，以及一個代表每 kWh 成本的浮點數。這個函式應該 `return` 電子設備的運轉成本，並以浮點數表示。

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
