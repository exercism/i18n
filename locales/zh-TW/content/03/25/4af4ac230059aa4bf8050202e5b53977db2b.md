# 簡介

## 基礎

[Lua](https://lua.org) 是一門簡單卻強大、高效、輕量且可嵌入的腳本語言。自 1993 年起，它由 Roberto Ierusalimschy、Waldemar Celes 與 Luiz Henrique de Figueiredo 組成的團隊，在巴西的 [PUC-RIO](https://www.puc-rio.br/) 設計、實作並維護至今。

### 註解

Lua 的單行註解以`--`開頭，多行註解則以`--[[`開頭、以`]]`結尾。
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### 變數

Lua 裡的變數有三種：全域變數、區域變數與表格欄位。為了保持簡單，這裡只說明區域變數。變數預設都是全域的，所以我們必須用關鍵字`local`把變數宣告成區域變數。
```lua
local x
```

使用`=`運算子就能把值指定給變數。
```lua
local x = 1
```

`local`變數的作用域僅限於宣告它的程式區塊。程式區塊可以是一個控制結構的主體、一個函式的主體，或是宣告該變數的檔案或字串。
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### 函式

函式以關鍵字`function`宣告，而且和變數一樣，預設是全域的。函式定義包含名稱、一連串的參數，以及主體。執行到關鍵字`return`時函式就會結束，並回傳其後列出的所有值。如果沒有指定`return`，函式會回傳`nil`。

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### 表格

表格是 Lua 中唯一的資料結構機制，而且功能非常強大。它們可以用來表示陣列、集合、物件、模組，以及更多東西。基本上，Lua 的表格就是一種關聯式陣列。
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```
這裡只是先稍微認識一下，為下一節做準備。之後我們會再回來詳細討論這個主題。

### 模組

模組是一組程式碼，儲存在`.lua`原始檔中。模組匯出的所有內容都會放進一個表格，並在檔案結尾回傳這個表格。所以表格基本上扮演了某種命名空間的角色。
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

接著就能透過函式`require`把該模組載入另一個檔案，`require`會回傳那個表格。
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

當我們看到`say.hello`時，會想到「模組`say`裡的函式`hello`」。但因為我們知道`say-hello.lua`會回傳一個表格，再回頭看看表格那一節，就會發現這個運算式在 Lua 中的意思是「用字串`hello`當作鍵來索引表格`say`」。

雖然模組回傳表格是很好的做法，但回傳其他任何型別也完全可行，例如函式。

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
