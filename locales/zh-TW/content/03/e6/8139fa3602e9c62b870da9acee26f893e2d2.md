# 提示

前三個任務都會呼叫同一個`print_name_badge()`函式。實作可以一步步建立起來，在進行的過程中為任務 2 和任務 3 加上邏輯。

## 1. 為員工建立名牌

- 這是預設情況，只要把 3 個引數組合成合適的字串就好。
- [字串內插][interpolation]大概是最簡單的做法。

## 2. 為新進員工建立名牌

- 現在這個 ID 是`missing,`，所以目標字串格式也不一樣。
- 這裡用得上[`ismissing()`][ismissing]。
- Julia 有語法簡潔的[三元運算子][ternary]。

## 3. 為擁有者建立名牌

- 現在部門是`nothing`。
- 有一個[`isnothing()`][isnothing]函式。

## 4. 計算沒有 ID 的員工薪資總和

- 有任何 ID 遺漏嗎？如果沒有，回傳值就是零。
- 要取出 ID 遺漏的項目，或許可以先從[把`ids`和`salaries`這兩個向量 `zip` 起來][zip]開始。
- 有幾種方法可以疊代產生的元組向量，而不必寫出明確的迴圈。
  - 用 Python 風格，透過向量[推導式][comprehension]。
  - 用函式風格，透過[`map()`][map]和[匿名函式][anonymous]。
  - 用向量風格，透過[匿名函式][anonymous]的[廣播][broadcasting]。
- 最後會對修改後的薪資向量使用[`sum()`][sum]。
   - 有 ID 的員工薪資可以省略，也可以設為零。
