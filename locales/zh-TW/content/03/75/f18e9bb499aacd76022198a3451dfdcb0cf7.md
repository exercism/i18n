# 指令

在這項練習中，你會處理儲蓄帳戶。每年，你的儲蓄帳戶餘額會根據利率更新。銀行給你的利率取決於你帳戶裡有多少錢（也就是餘額）：

- 餘額為負時，利率為 -3.213%。
- 餘額低於`1000`元時，利率為 0.5%。
- 餘額大於等於`1000`元且低於`5000`元時，利率為 1.621%。
- 餘額大於等於`5000`元時，利率為 2.475%。

每年，在儲蓄帳戶餘額更新**之前**，政府允許你將一定比例的錢捐給慈善機構，而且免稅。因為你是個好人，如果年底時你的餘額是正的，你會捐出這個金額的兩倍給慈善機構，並向下取整到最接近的整數元。

你有三項任務，每一項都會涉及你的餘額和它的利率。

## 1. 計算利率

實作`interest-rate`函式，根據指定的餘額計算利率：

```clojure
(interest-rate 200.75M)
;;=> 0.5
```

注意，回傳的值是`Double`。

## 2. 計算年度餘額更新

實作`annual-balance-update`函式，計算年度餘額更新，並將利率納入考量：

```clojure
(annual-balance-update 200.75M)
;;=> 201.75375M
```

注意，回傳的值是`BigDecimal`。

## 3. 計算要捐多少錢

實作`amount-to-donate`函式，根據餘額和政府允許的免稅百分比，計算要捐多少錢給慈善機構：

```clojure
(def balance 550.5M)
(def tax-free-percentage 2.5)

(amount-to-donate balance tax-free-percentage)
;;=> 27
```

注意，回傳的值是`int`。
