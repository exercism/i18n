# 指令

Ellen 正在做一款遊戲，玩家必須對抗外星人。
她剛學會物件導向程式設計（OOP），很期待能運用 `classes` 為她的程式帶來的好處。

令 Ellen 欣喜的是，你主動表示願意幫忙，於是她把撰寫玩家要對抗的外星人程式的任務交給了你。


## 1. 建立 `Alien` 類別

定義 `Alien` 類別，並替它加上一個建構子，接受兩個 `int` 參數 `x` 和 `y`，將它們存入 `x_coordinate` 和 `y_coordinate` 成員變數。
每個外星人一開始的生命值都是 `3`，所以 `health` 成員變數也要一併初始化。

`health` 應該是私有的成員變數。
為了讓程式的其他部分能讀取生命值資訊，Ellen 希望有一個 `public` 的 `get_health()` 方法，回傳 `int`。

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

現在，每個外星人都應該能在內部追蹤自己的位置和生命值。

## 2. `hit` 函式

Ellen 希望 Alien `class` 有一個 `hit` 方法，被呼叫時會將外星人物件的生命值減少 `1`。
這樣一來，她只要呼叫 `some_alien_instance.hit()` 就好，不必手動修改外星人的生命值。
請確保生命值不會降到零以下。
這個函式應該回傳 `true`。
Ellen 之後想加入護盾，屆時若護盾開啟，就會回報 `false`。

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. `is_alive` 函式

你發現如果生命值一直下降，總有一天會變成 `0`。
這時最好加上一個 `is_alive` 方法，讓 Ellen 能快速呼叫，確認外星人是不是……還活著。😉
`some_alien_instance.is_alive()` 應該回傳布林值。

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. `teleport` 函式

在 Ellen 的遊戲裡，外星人會瞬間移動！
你需要撰寫一個 `teleport` 方法，接受 `x_new` 和 `y_new` 兩個值，並據此變更外星人的座標。
目前這個函式應該回傳 `true`。
Ellen 想在之後的關卡加入能阻擋瞬間移動的炸彈，屆時瞬間移動失敗就會回報 `false`。

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. `collision_detection` 函式

如果外星人會被東西擊中，牠們就得能偵測這種碰撞可能何時發生。
Ellen 需要知道兩個外星人是否佔據相同的座標。
`collision_detection()` 函式接受另一個外星人物件作為引數，並回傳 `bool`。

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
