# 說明

在這道練習中，你將寫一些程式碼來協助 Betty's Bike Shop，這是一間販售自行車與零件的線上商店。
你有三個任務，目標是在網站上正確顯示自行車與零件的價格。

## 1. 匯出`pence_to_pounds`函式

你的同事已經寫好這個模組的骨架，也就是尚未完成的`pence_to_pounds`和`pounds_to_string`函式。
不過，他們忘了匯出`pence_to_pounds`函式，所以它目前無法被其他模組或測試套件看見。

請匯出`pence_to_pounds`函式。

## 2. 將便士轉換為英鎊

目前，價格是以整數的*便士*儲存（這間自行車店位於英國）。
在網站上，我們想以*英鎊*顯示價格，其中 1.00 英鎊相當於 100 便士。
你的第一個任務是實作`pence_to_pounds`函式，它接受以`Int`表示的便士數量，並將其轉換成等值的英鎊，型別為`Float`。
你也應該為這個函式加上型別標註。

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. 格式化價格，以便在網站上顯示

由於 Betty's 的自行車是以英鎊販售，價格應該以「£」符號顯示。
你的第二個任務因此是實作`pounds_to_string`函式，它接受以`Float`表示的英鎊金額，並回傳把英鎊符號加在前面、以`String`顯示的價格。

在使用之前，你應該先匯入`gleam/float`和`gleam/string`模組。

你也應該為`pounds_to_string`定義型別標註。

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
