# 指令附加說明

## 實作注意事項

樹狀物件有兩個屬性：

- `String`標籤
- `List<Tree>`子節點

測試程式會透過反覆套用`Tree.of`建立函式來建立樹。例如，以下敘述

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

會建構出下面這棵樹：

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

你可以假設測試用的樹不會有重複的值。

---

`FromPov`和`PathTo`這兩個方法是這個練習有趣的部分。

`FromPov`方法接受一個字串引數`from`，用來透過值指定樹中的某個節點。它應該回傳一棵以`from`這個值為根的樹。你可以修改原本的樹並回傳它，也可以建立一棵新的樹再回傳。如果你回傳新的樹，就可以任意取用或摧毀原本的樹。當然，讓它保持原狀也很好喔。

`PathTo`方法接受兩個字串引數`from`和`to`，用來透過值指定樹中的兩個節點。它應該回傳樹中從第一個節點到第二個節點的最短路徑。

## 例外訊息

有時候必須[拋出例外](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)。

當你這麼做時，應該一律附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓你的程式碼更容易閱讀，對除錯也有很大的幫助。

這個練習特別要求你使用[throw 關鍵字](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)，在`Tree()`類別被傳入無法重新定向的樹，或是在`start node`和`end node`之間找不到路徑時，「拋出」多個`UnsupportedOperationException`。你必須同時`throw`這個`exception`並附上訊息，測試才會通過。

若要拋出帶有訊息的`UnsupportedOperationException`，請把訊息寫成`exception`型別的引數：

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
