# 指令

在這道練習中，你會撰寫程式碼來分析汽車工廠裡一條組裝線的產量。
組裝線的速度範圍從`0`（關閉）到`10`（最高）。

在最低速度（`1`）下，每小時會生產`221`輛車。
產量會隨速度呈線性增加。
因此當速度設為`4`時，每小時應該會生產`4 * 221 = 884`輛車。
不過，速度越高，就越可能生產出有瑕疵的車，這些車之後必須被丟棄。

你有三個任務。

## 1. 計算成功率

實作（_static_）`AssemblyLine.SuccessRate()`方法，計算每件產品在指定速度下順利完成而不出錯的比例。
下表顯示速度如何影響成功率：

- `0`：成功率 0%。
- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. 計算每小時的產量

實作（_static_）`AssemblyLine.ProductionRatePerHour()`方法，計算組裝線每小時的產量，並將成功率納入考量：

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

請注意，回傳的值是`double`。

## 3. 計算每分鐘生產出的可用車輛數

實作（_static_）`AssemblyLine.WorkingItemsPerMinute()`方法，計算每分鐘能生產出多少可用車輛：

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

請注意，回傳的值是`int`。
