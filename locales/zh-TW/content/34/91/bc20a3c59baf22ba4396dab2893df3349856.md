# 簡介

Python 有三種不同的內建數字型別：整數（[`int`][int]）、浮點數（[`float`][float]）與複數（[`complex`][complex]）。
分數（[`fractions.Fraction`][fractions]）與小數（[`decimal.Decimal`][decimals]）也可以透過匯入標準函式庫來取得。

**沒有**小數部分的整數，包括十六進位（[_`hex()`_][hex]）、八進位（[_`oct()`_][oct]）與二進位（[_`bin()`_][bin]）數字，也同樣被視為 `ints`。

Python 完整支援這些不同數字型別之間的算術運算，並且在使用二元算術運算子（`+`、`-`、`*`、`/`、`//` 與 `%`）時，會將範圍較窄的數字轉換成與較寬的對應型別相符。
