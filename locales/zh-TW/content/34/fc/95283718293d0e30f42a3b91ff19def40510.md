# 說明

你將繼續開發之前建立的庫存管理系統。自從認識了`OpenStruct`和區塊簡寫之後，你決定稍微重構一下程式碼。這次不再把項目存成雜湊，而是要運用你新學到的技巧。

## 1. 讓項目可以被取得

你想要繼續取得庫存項目的陣列，但這次它們應該是可以在上面呼叫方法的物件。

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. 重構 `item_names`

重構 `item_names`，改用你新學到的區塊簡寫，而不要使用雜湊。
提醒你，這個方法應該回傳：

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. 重構 `total_stock`

重構 `total_stock`，改用 OpenStruct 的方法，而不要參照雜湊。
提醒你，這個方法應該回傳：

