# 測試

## 執行測試
Haxe 賽道採用 [Buddy](https://github.com/ciscoheat/buddy) 這個測試框架。
你可以用以下指令安裝：

```bash
haxelib install buddy
```

要執行測試，請執行以下指令：

```bash
haxe test.hxml
```

在測試檔案中，每個 describe 區塊代表練習測試的一個區段，而每個測試則是一個 `it` 或 `xit` 區塊。
當你執行測試時，`it` 區塊會執行，而 `xit` 區塊則是擱置中的測試。
當你提交解答時，Exercism 的測試執行器會執行所有 `it` 或 `xit` 區塊。
在本機操作時，預設只會執行第一個測試。
若要執行其他測試，請把對應的 `xit` 區塊改成 `it` 區塊，然後重新執行`haxe test.hxml`。


此外，有些練習可能需要用 haxelib 安裝額外的函式庫。
遇到這種情形時，練習的說明裡會有提醒。

## 解題

解題就是讓練習裡的所有測試都通過。
為了幫你起步，每個練習都會附上一份實作骨架檔案。
你可以把這個檔案當作建構解答的起點。
如果你認為這麼做是對的，可以自行刪除或修改這個檔案。
在朝解答邁進的同時，試著一次只專注在一個測試上吧。
