# 簡介

在 Java 中，布林值由`boolean`型別表示，其值可以為`true`或`false`。

Java 支援三種布林運算子：

- `!`（否定）：對布林值取反
- `&&`（且）：接受兩個布林值，若兩者皆為 true，則結果為 true
- `||`（或）：只要兩個布林值中有一個為 true，結果即為 true

## 範例

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
