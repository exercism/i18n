# 簡介

## Nil

Gleam 中的`Nil`是一種只有單一值的型別，這個值本身也叫做`Nil`。它和其他語言中的`void`類似，都是在函式沒有更合適的值可以回傳時使用。

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Gleam 中的值不像某些其他語言那樣有「nil-able」或「nullable」的概念。只有型別為`Nil`的值才可能是`Nil`，而其他任何型別的值永遠不可能是`Nil`。

## IO

和大多數程式語言一樣，Gleam 也有「副作用」，所以函式除了回傳值，還能讀取並改變世界的狀態。

Gleam 標準函式庫中的`gleam/io`模組提供了將字串輸出到主控台的函式。

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

其他套件也可能提供其他 IO 函式，例如`simplifile`這個套件就提供了讀取和寫入檔案的函式。

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
