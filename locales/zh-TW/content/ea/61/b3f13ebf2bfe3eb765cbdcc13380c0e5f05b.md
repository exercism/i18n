# 推薦學習資源

## 部落格

- 官方的 [.NET 部落格](https://blogs.msdn.microsoft.com/dotnet/) 有許多有趣的 C# 文章，難度從初學者到專家都有。
- Scott Hanselman 的[部落格](http://www.hanselman.com/blog/)十分活躍、文筆流暢，主題涵蓋各式各樣的 C# 與 .NET 相關題材。
- Eric Lippert 的 [Fabulous adventures in coding](https://ericlippert.com/) 是很出色的 C# 部落格，不過他談的主題通常相當進階。
- 由 James Michael Hare 製作的 [C#/.NET Little Wonders](https://www.slideshare.net/BlackRabbitCoder/little-wonders-5747749) 投影片，介紹較少人知道的 C# 功能。
- 由 James Michael Hare 製作的 [C#/.NET Little Pitfalls](https://www.slideshare.net/BlackRabbitCoder/cnet-little-pitfalls) 投影片，說明如何避免對 C# 的錯誤假設。

## 社群媒體

- 你可以用 [StackOverflow](http://stackoverflow.com/questions/tagged/c%23) 搜尋你的問題，看看是否已經有人問過。你也可以在上面提問和回答問題。
- [/r/csharp](https://www.reddit.com/r/csharp) 是 C# 的 Reddit 看板。
- [@dotnet](https://twitter.com/DotNet) 是官方的 .NET Twitter 帳號。
- [Gitter](https://gitter.im/exercism/xcsharp) 是 C# 的 Gitter 聊天室，想取得支援或詢問 C# 軌道相關問題，都可以來這裡。

## 影片

- 在 [On .NET](https://www.youtube.com/watch?v=GpLU0UdcGic&list=PL4Sf58qFxdyQuzB1mH5kln_otKpsIuoCO) 中，Bertrand Le Roy 訪問來賓，暢談各式與 C#/.NET 相關的主題。
- PluralSight 上有幾門很棒的 [C# 課程](https://www.pluralsight.com/search?q=*&categories=course&roles=software-development%7C&subjects=c%23)。缺點是：PluralSight 是付費服務，不過你可以申請[免費試用](https://www.pluralsight.com/pricing)。

## Podcast

- [.NET Rocks](https://www.dotnetrocks.com/) 是很棒的 .NET Podcast，內容十分精彩。

## 書籍

- [Expert C# 5.0](http://www.apress.com/us/book/9781430248606)
