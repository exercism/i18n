# 簡介

推導式提供了一種簡單且宣告式的方式來轉換 _Enumerables_。

要宣告一個最簡單的推導式，可以使用`for`關鍵字，後面接著一個產生器和一個`do`區塊，由列舉出的值建立新的值。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

推導式也可以加上篩選器。沒有通過篩選的值，會從最終的陣列中移除：

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

我們可以跨好幾行，宣告更複雜的推導式：

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

使用多個產生器，可以建立笛卡兒乘積。也就是說，第一個產生器產生的每個值，都會和第二個產生器產生的每個值配對一次：

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
