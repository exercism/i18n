# 簡介

## 條件敘述

條件敘述是用來做決定的敘述，它能執行副作用，也能控制程式執行的流程。
條件敘述包括`if`、`if/else`、`switch`和`ternary`敘述。

條件敘述用來針對某個值，或值與值之間的關係提出問題。
這個問題會求值成布林答案，但`if`敘述本身可以回傳任何值，也可以單純執行副作用。

## if 敘述

最簡單的`if`敘述會對一個運算式求值，並執行一行。
被測試的運算式一律放在小括號內。

它可以執行副作用

```c
if (count > 10)
    printf("count is greater than 10");
```

也能改變執行的流程


```c
if (count > 10)
    return sum;
```

如果`if`敘述要執行超過一行，就必須把這些行放在大括號內

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

有些開發團隊可能會統一規定，`if`敘述一律使用大括號，即使只有一行也一樣。


## if else

`if`敘述可以搭配`else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if else if


`else`可以再搭配另一個`if`，形成所謂的`if-else-if ladder`。

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


有時候，`if-else-if ladder`用`switch`表示會更好。
和`if`一樣，被測試的運算式一律放在小括號內。

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

若被測試的值與前面任何一個 case 都不相符，就會執行`default` case。

如果`switch`的某個 case 不是回傳，通常會插入`break`來結束每個 case，否則邏輯會「貫穿」到下一個 case。
有時候，貫穿是刻意使用的。

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

當貫穿不是刻意發生時，那就是一個 bug。

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

當要測試的是特定值，而不是一段值的範圍時，switch 會是很好的選擇。
它可能比`if-else-if ladder`更快，因為編譯器能用某些對`if-else-if ladder`行不通的方式來最佳化`switch`敘述。
有時候，switch 看起來也比`if-else-if ladder`更好讀。

## 三元運算子（又稱條件運算子）

三元運算子是一種由三個部分組成的條件敘述，常用來設定值。
要測試的運算式放在問號前面，不一定要用小括號包起來。
true 時回傳的值放在冒號前面，false 時回傳的值放在冒號後面。
可以回傳常值，也可以回傳變數。

```c
int i = j > 5 ? 5: j;
```

三元運算子可以巢狀使用，以減少語法上的雜亂。

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
