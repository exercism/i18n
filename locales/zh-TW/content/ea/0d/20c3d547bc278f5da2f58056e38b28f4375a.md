# 提示

## 1. 建立遙控車

- [定義一個建構子][constructor-syntax]，它帶有兩個 `int` 參數。
- 將這兩個參數儲存為[欄位][fields]，以便從各個類別的方法中存取它們。

## 2. 建立賽道

- [定義一個建構子][constructor-syntax]，它帶有一個 `int` 參數。
- 將這個參數儲存為[欄位][fields]，以便從類別的方法中存取它。

## 3. 駕駛車子

- 新增一個[欄位][fields]來記錄行駛的距離。
- 將車子的速度加到用來記錄行駛距離的[欄位][fields]。

## 4. 檢查電池是否耗盡

- 新增一個[欄位][fields]來記錄剩餘電量百分比（初始值為 100%）。
- 從用來記錄電量的[欄位][fields]中扣除車子的耗電量。
- 如果電池已耗盡，就不要更新行駛的距離。
- 記住，如果電池電量低於耗電百分比，就視為已耗盡。

## 5. 建立 Nitro 遙控車

- 使用正確的引數[建立][instance-constructors]一個 `RemoteControlCar` 的實例。

## 6. 檢查遙控車是否能完成比賽

- 試著套用一個公式，將距離和速度與電池電量及耗電量做比較。
- 記住，車子有一個方法可以取得它行駛過的距離。
