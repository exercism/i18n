# 簡介

除了函式宣告和函式運算式之外，JavaScript 還提供了另一種非常簡潔的函式定義語法。
這種函式稱為 _箭頭函式_。

在這個概念中，我們會聚焦在撰寫箭頭函式所使用的語法。
箭頭函式的運作方式有一些差異，例如 _this_ 綁定，這些會在其他概念中介紹。

這裡比較了函式宣告和箭頭函式。

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

從上面可以看到，箭頭函式的語法：

1. 移除了關鍵字`function`
2. 以`const`宣告了識別字`addUpTwoNumbers`
3. 加上了粗箭頭`=>`

如果函式主體只包含一個回傳敘述，就像上面的範例一樣，那麼可以省略`{}`和`return`關鍵字。

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

在箭頭函式只回傳物件這個特殊情況下，需要用括號把物件包起來，才能省略回傳敘述。

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

參數兩側要不要加括號，取決於參數的數量。

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
