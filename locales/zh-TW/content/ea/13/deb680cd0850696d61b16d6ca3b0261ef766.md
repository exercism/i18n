# 簡介

[Go](https://golang.org) 是一門靜態型別的編譯式程式語言。這個練習會介紹 3 項重要的語言特性：套件、函式和變數。

## 套件

Go 應用程式是以套件的方式來組織的。套件是位於同一個目錄中的原始碼檔案集合。同一個目錄裡的所有原始碼檔案都必須共用相同的套件名稱。匯入套件時，只有名稱以大寫字母開頭的實體（函式、型別、變數、常數）才能使用或存取。Go 建議的命名風格是使用`camelCase`來命名識別字，唯一的例外是那些需要跨套件存取的識別字，應該使用`PascalCase`。

```go
package lasagna
```

## 變數

Go 是靜態型別的，意思是在編譯期所有變數[都必須有明確的型別](https://en.wikipedia.org/wiki/Type_system)。

定義變數時，可以明確指定型別：

```go
var explicit int // Explicitly typed
```

你也可以使用初始值，編譯器會把變數的型別指定成與初始值相符的型別。

```go
implicit := 10   // Implicitly typed as an int
```

變數一旦宣告，就能用`=`運算子指定值。變數一旦宣告，它的型別就永遠不會改變。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 常數

常數就像變數一樣，用來存放一筆資料，但它的值在程式執行期間不能改變。

常數使用`const`關鍵字定義，可以是數字、字元、字串或布林值：

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 函式

Go 函式可以接受 0 個或多個參數。參數必須明確標註型別，沒有型別推斷。

函式使用`return`關鍵字回傳值。

呼叫函式時，要寫出函式名稱，並為函式的每個參數傳入引數。

注意 Go 支援 2 種註解。單行註解以`//`開頭，多行註解則寫在`/*`和`*/`之間。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
