# 簡介

## 常數

`const`修飾詞可以（而且通常應該）套用在任何欄位上，只要它的值在編譯期就已經知道，而且在程式的生命週期內不會改變。

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly`修飾詞可以（而且通常應該）套用在任何無法標為`const`的欄位上，只要它的值在程式的生命週期內不會改變，而且是在內嵌初始設定式中設定，或是在具現化時設定（由建構函式，或由建構函式呼叫的方法來設定）。

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## 防禦性複製

在安全性敏感的情境下（或者單純在開發者各有不同優先順序與目標的大型程式碼基底裡），你都應該避免讓類別的公開 API 遭到繞過：不要接受並儲存方法傳入的可變參數，也不要透過回傳值或`out`參數，把類別中的可變成員暴露出去。

## 唯讀集合

雖然`readonly`修飾詞可以防止欄位中的值或參考被覆寫，它對參考型別的成員卻沒有任何保護作用。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

若要確保參考型別的所有成員都受到保護，可以把欄位標為`readonly`，並定義不含`set`存取子的自動屬性。

基底類別庫（BCL）提供了一些集合的唯讀版本，用於需要阻止集合成員被更新的情況。這些版本以包裝函式的形式提供：

- `ReadOnlyDictionary<T>`將`Dictionary<T>`以唯讀形式公開。
- `ReadOnlyCollection<T>`將`List<T>`以唯讀形式公開。
