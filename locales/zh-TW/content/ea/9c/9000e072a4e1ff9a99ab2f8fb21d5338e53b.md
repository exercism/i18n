# 簡介

在 Python 中，[列舉](https://docs.python.org/3/library/enum.html)是一組名稱，這些名稱會繫結到唯一的 `literal` 或 `constant` 值。列舉的定義方式是繼承 `Enum` 類別。內建的列舉型別位於 `enum` 模組中，而 `Enum` 類別則可以使用 `from enum import Enum` 匯入。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

請注意，列舉成員的值可以是任何資料型態，例如 str、tuple、float 等。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

當同一個值被指定給列舉中的兩個成員時，後被指定的成員會成為先被指定成員的別名。列舉中不允許兩個成員使用相同的名稱。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

走訪列舉的成員可以使用標準的 `for member in` 語法：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

列舉成員可以使用 [`is`（_身分運算子_）](https://www.w3schools.com/python/ref_keyword_is.asp)或 `is not` 來比較。`==` 或 `!=`（_相等運算子_）的運作方式也相同。

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

若要依指定的值取得列舉成員，可以使用 `EnumName(value)`：

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
