# 學習 C#

## 網站

- [C# 官方文件](https://docs.microsoft.com/en-us/dotnet/articles/csharp/)涵蓋各種主題的優質內容，包括[教學](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tutorials/index)和[語言導覽](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tour-of-csharp/index)。
- [Learn C#](http://www.learncs.org/) 是互動式的瀏覽器內教學，帶你認識 C# 程式設計的核心概念。

## 影片

- [C# 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oVxKLQCHpiUWun7vlJJvUiN) 透過即時編碼示範，介紹 C# 程式語言的概念與語法。
- [.NET Core 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oWoazjhXQzBKMrFuArxpW80) 深入淺出地說明「什麼是 .NET」，以及如何發佈你的第一個應用程式。
- [Programming in C# Jump Start](https://channel9.msdn.com/Series/Programming-in-C-Jump-Start) 是循序漸進認識 C# 程式設計的好選擇。
- [C# Fundamentals for Absolute Beginners](https://mva.microsoft.com/en-US/training-courses/c-fundamentals-for-absolute-beginners-16169?l=Lvld4EQIC_2706218949) 是認識 C# 的絕佳方式。
- [PluralSight](https://www.pluralsight.com/) 有幾門很棒的[入門](https://www.pluralsight.com/courses/csharp-6-from-scratch)[課程](https://www.pluralsight.com/courses/c-sharp-fundamentals-with-visual-studio-2015)（[連結](http://www.pluralsight.com/courses/csharp-best-practices-improving-basics)）。缺點是：PluralSight 是付費服務，不過你可以申請[免費試用](https://www.pluralsight.com/pricing)。
