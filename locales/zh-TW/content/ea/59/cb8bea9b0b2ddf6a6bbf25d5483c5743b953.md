# 說明

在這個練習中，情人節到了，你和你的另一半打算一起做點開心的事。你的另一半有很多想法，現在要你為這些想法評分，好找出要進行的活動。

你的另一半提出了以下幾個想法：

- 玩桌遊
- 放鬆一下
- 看電影
- 上餐廳吃飯
- 散步

你有 6 項任務，幫助你挑選情人節的活動。

## 1. 定義核准

你的另一半每提出一個想法，你都要從三種選項中擇一回應：「是」、「否」或「也許」。

定義`Approval`差別聯合，用下列 3 個案例來表示這些選項：`Yes`、`No`和`Maybe`。

## 2. 定義料理種類

你的另一半選了 2 間可能的餐廳：其中一間是韓式料理，另一間是土耳其料理。

定義`Cuisine`差別聯合，用下列 2 個案例來表示這些料理種類：`Korean`和`Turkish`。

## 3. 定義電影類型

可以選的電影多到數不清，所以為了縮小範圍，你的另一半也列出了自己想看的類型。

定義`Genre`差別聯合，用下列幾個案例來表示這些類型：`Crime`、`Horror`、`Romance`和`Thriller`。

## 4. 定義活動

如前所述，你的另一半想出了 5 種不同的活動：玩桌遊、放鬆一下、看電影、上餐廳吃飯和散步。

定義`Activity`差別聯合，用下列案例來表示這些活動類型：

- `BoardGame`：沒有附帶資料。
- `Chill`：沒有附帶資料。
- `Movie`：以`Genre`作為附帶資料。
- `Restaurant`：以`Cuisine`作為附帶資料。
- `Walk`：以`int`作為附帶資料，代表要走的公里數。

## 5. 為活動評分

最後，你準備好要為另一半的想法評分了。以下是你對每個想法的感受：

- 玩桌遊：「否」。
- 放鬆一下：「否」。
- 看電影：如果是浪漫愛情片就是「是」，否則「否」。
- 上餐廳吃飯：如果是韓式料理就是「是」，如果是土耳其料理就是「也許」。
- 散步：如果走不到 3 公里就是「是」；不到 5 公里就是「也許」；否則「否」。

實作一個名為`rateActivity`的函式，它接收一個`Activity`值，並根據上述的感受回傳對應的`Approval`：

```fsharp
rateActivity (Restaurant Turkish)
// => Maybe
```
