# 指示補充

## 這個練習在 Python 中的結構

Python 提供了豐富的數學函式，包括 [math 模組][math-module]以及內建函式，例如指數運算子 `**`、[`pow()`][pow] 和 [`sum()`][sum]。
不過，我們希望你能挑戰看看，在不使用這些內建函式或模組的情況下解出這個練習。

雖然有數學公式可以求出任何數字的平方根，但我們選擇只以 [自然數][nautral-number]（正整數）作為解。  
只用自然數來運算，就能算出任何自然數的平方根。
