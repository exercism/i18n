# 泛型資料型態

Cairo 的泛型讓你能寫出可重複使用的程式碼，適用於各種型別，避免重複，也提升可維護性。

你可以在函式、結構體、列舉、特質和方法上使用泛型。

## 泛型函式

泛型函式能處理不同的型別，不需要分別寫好幾份實作。

例如：

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

這裡的`T`是任何型別的佔位符。

不過，Cairo 需要特質界限，以確保泛型型別符合特定要求。

如果`T`需要能被 Drop，我們可以改寫簽章：

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

特質界限，例如`Drop`或`PartialOrd`，會為泛型加上限制，讓它能進行特定操作。

## 匿名限制

如果某個特質實作沒有直接在函式中使用，你可以用`+`寫出匿名限制：

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

這樣就不必為特質命名，例如`TPartialOrd`，減少冗長。

## 帶有泛型的結構體

結構體裡的泛型讓欄位更有彈性。

例如：

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

如果結構體需要多個泛型型別，只要再加上更多佔位符就行：

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## 帶有泛型的列舉

列舉也能容納泛型資料型態。

例如：

```rust
enum Option<T> {
    Some: T,
    None,
}
```

`Option<T>`列舉可以表示任何型別的選擇性值。

同樣地，`Result<T, E>`讓你能定義成功與失敗的型別：

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## 泛型方法

方法也可以使用泛型。

例如：

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

你也可以為特定的泛型型別定義方法，例如`Wallet<u128>`：

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## 混用泛型型別

泛型可以處理複雜的組合。

舉例來說，把兩個不同型別的`Wallet`實例組合起來：

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

加上`+Drop`限制後，編譯器就能確保資源被妥善處理。

泛型很強大，但需要小心管理限制。

用它來寫出可重複使用、不綁定特定型別又精簡的程式碼。
