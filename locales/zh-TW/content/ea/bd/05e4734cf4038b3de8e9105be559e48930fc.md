# 提示

## 一般

- Python 文件中的[字串教學][python-str-doc]提供了 Python `str` 型別的概覽。
- 處理字串時，字串方法[`str.join()`][str-join]和[`str.split()`][str-split]非常有用。
- Python 文件中的[序列型別][common sequence operations]列出了所有序列共通的運算，包括`strings`、`lists`、`tuples`和`ranges`。

這份作業包含四個活動，每個活動都有一組要處理的文字或單字。

## 1. 為單字加上前綴

- 短的字串可以用`+`運算子串接。

## 2. 為字組加上前綴

- 信不信由你，這裡只需要[`str.join()`][str-join]。**不需要迴圈**。
- 測試會把一個`list`傳進你的函式。只要能想出合適的分隔字串，就不需要更動這個`list`。
- 記住，分隔字串會放在元素之間，把它們「黏」成單一字串。插入分隔字串時_不會_加上空格，不過你可以在裡面自行加入空格字元。
- 就像[`str.split()`][str-split]一樣，`str.join()`能處理由任意 Unicode 碼點組成、長度不拘的字串。_不同於_`str.split()`的是，它也能處理`list`、`tuple`和`set`這類長度不拘的可疊代物件。

## 3. 移除單字的後綴

- 字串可以從左邊（從 0 開始）或右邊（從 -1 開始）建立索引或切片。
- 如果想取得任意長度字串的最後一個碼點，可以使用`[-1]`。
- 字串最後三個字母可以用負索引「切掉」。例如`beautiful'[:-3] == 'beauti`

## 4. 擷取並轉換單字

- 使用[`str.split()`][str-split]會回傳一個依空白切分的字串`list`。
- `lists`是序列，可以建立索引。
- [`str.split()`][str-split]可以直接索引：`'Exercism rocks!'.split()[0] == 'Exercism'`
- 小心標點符號！句點可以透過切片移除：`'dark.'[:-1] == 'dark'`
