# 指令

你！沒錯，就是你，勇敢的 lisper！[Lenny 這位 lisp 外星人][alien] 需要你的幫忙！Lenny 想和其他 lisp 外星人一起出去玩，但他們的父母說了，房間沒打掃乾淨之前，哪裡都不准去。

問題是，Lenny 幾乎看不到地板！Lenny 分不清哪些是原子、哪些是 cons，哪些是符號、哪些是關鍵字，也分不清 `car` 和 `cdr`！

你可以幫 Lenny 收拾這團混亂嗎？別忘了[你的括號][xkcd]，你會需要它們的！

## 1. 幫 Lenny 複習符號

在 Lenny 開始動手之前，得先複習一下符號和關鍵字長什麼樣子。畢竟他們上次整理已經是好一陣子以前的事了…… 幫幫 Lenny，定義兩個函式：`lennys-favorite-food` 會求值成某個符號，`lennys-secret-keyword` 則會求值成某個關鍵字。例如：

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

請注意，你可以回傳任何你喜歡的符號或關鍵字（如果你不愛千層麵，或是不相信外星人，那也不要緊）。

## 2. 幫 Lenny 分辨原子和 cons

等 Lenny 複習完符號和關鍵字，就該開始打掃了！要整理散落在他們房間裡的 S-Expressions，Lenny 需要有人幫忙判斷哪些是 cons、哪些是原子。你可以實作兩個函式來幫忙：`is-an-atom-p` 和 `is-a-cons-p`：

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

這一段裡有幾個內建的 lisp 函式可能會派上用場。另外，目前你可以先把 `T` 視為 true，把 `NIL` 視為 false。

## 3. 幫 Lenny 拆開他們的 cons

最後，Lenny 的 cons 太龐大了，沒辦法整齊收好，所以得把它們拆成更小的部分。你能再定義兩個函式來拆解它們的 cons 嗎（`first-thing` 和 `rest-of-it`）？

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

同樣地，Common Lisp 的某些內建函式在這裡也許能幫上忙。
