# 說明補充

## 專案結構

Exercism 上的 Clojure 練習支援兩種最常見的依賴管理與測試工具：[leiningen][leiningen] 和 [Clojure CLI][clojure-cli]。

你會在`test`目錄裡找到一個名為`hello_world_test.clj`的測試檔。請把你的程式碼寫在`src/hello_world.clj`。它應該使用命名空間`hello-world`，這樣測試才能找到它。

### 使用 Clojure CLI 執行測試

```
$ clj -X:test
```

### 使用 Leiningen 執行測試

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

接著用以下指令提交練習：

```
$ exercism submit src/hello_world.clj
```

更詳細的說明與學習資源，請參考 [Exercism 的 Clojure 語言頁面][exercism-clojure]。

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
