# 時尚精品店

## 故事

你正在經營一間線上時尚精品店。黑色星期五即將到來，所以你需要盤點庫存，確保一切準備就緒。

庫存中的單一項目以映射／字典表示，而整份庫存則是這些映射／字典組成的列表／陣列。

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 任務

- 依價格排序項目
- 找出所有缺少價格的項目
- 增加項目的數量
- 計算項目的總數量
