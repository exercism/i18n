Elixir 有自己的一套命名慣例，其中也包含[回傳布林值的函式](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)該怎麼命名：

> 回傳布林值的函式，名稱結尾會帶一個問號。

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

請注意，守衛、某些會回傳布林值而且能用在守衛中的內建函式與巨集，遵循的是另一套慣例：名稱會加上`is_`前綴（`def is_integer`、`defguard is_foo`、`defmacro is_foo`）。這兩套慣例不能混用。
