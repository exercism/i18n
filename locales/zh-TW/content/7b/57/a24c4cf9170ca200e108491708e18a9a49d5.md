# 指令

陛下即將在[卡爾馬聯盟][kalmar_union]的首都哥本哈根舉辦一場晚宴。
這是年度最盛大的宴會，所有貴族都受邀參加。
但全國上下正謠傳著有人密謀要毒害陛下。

女王陛下請你這位皇家毒物搜查員，查出是否有任何食物或飲料被下毒。
陛下打算只供應**Mushroom pasties**作為食物，但飲料方面則有各式各樣的選擇。

## 1. 確認食物是否正確

如果食物不是女王陛下點的東西，那它被下毒的機率就很高。
若食物不是女王陛下點的，就應該把它丟掉。

請實作`check_food?`方法，它接受引數`food`，該引數以`String`的形式存放食物名稱。
如果食物是`Mushroom pasties`，方法應該回傳該食物；否則應該回傳`nil`。

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. 確認飲料是否被下毒

飲料有可能被下毒，但要判斷出來稍微困難一些。
如果飲料名稱中**沒有**包含字母`i`，那它就被下毒了，大小寫不拘。
飲料若被下毒，就應該倒掉。

請實作`check_drink?`方法，它接受引數`drink`，該引數以`String`的形式存放飲料名稱。
如果飲料沒有被下毒，方法應該回傳該飲料；否則應該回傳`nil`。

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. 替換飲料

陛下不會想讓賓客擔心食物裡有毒。
因此，如果飲料被下毒，就應該換成新的飲料，也就是**Apple juice**。

請實作`replace_drink`方法，它接受引數`drink`，該引數以`String`的形式存放飲料名稱。
如果飲料沒有被下毒，方法應該回傳該飲料；否則應該回傳`"Apple juice"`。

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
