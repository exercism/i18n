# 簡介

自訂型別是 Gleam 定義新資料型態的方式。自訂型別可以有多個_變體_，每個變體都有自己的名稱。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

自訂型別的每個 case 可以選擇性地攜帶一些資料，而不同的 case 可以攜帶不同型別的資料。當變體攜帶資料時，就稱為_記錄_。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

如果某個 case 不含額外資料，可以直接用它的名稱建立值（`Spring`）；如果含有額外資料，則可以像呼叫函式一樣呼叫它來建立值（`SomeInt(2)`）。

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

自訂型別和 Gleam 裡的其他一切一樣，具有_結構相等性_，也就是說，同一個變體、資料也相同的兩個值彼此等價。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

可以使用 case 運算式對自訂型別的變體進行模式比對。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
