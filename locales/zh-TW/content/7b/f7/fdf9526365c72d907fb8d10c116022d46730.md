# 說明補充

## 提示

你需要實作 `recite` 函式，它會輸出「The Twelve Days of Christmas」的歌詞。如果你不確定型別，可以使用提供的函式簽章，但別讓它限制了你的創意喔。

這個練習處理的是文字資料。基於歷史因素，Haskell 的 `String` 型別等同於 `[Char]`，也就是字元組成的陣列。如果要更有效率地處理文字資料，可以使用 `Text` 型別。

作為這個練習的選用延伸，你可以

- 閱讀 Haskell 的[字串型別](https://haskell-lang.org/tutorial/string-types)。
- 在 package.yaml 的相依清單中加入 `- text`。
- 依照[下列方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)匯入 `Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 例如寫出 `recite :: Int -> Int -> [Text]`，並以 `T.pack` 之類的方式取用 `Data.Text` 的組合子。
- 查閱 [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) 的說明文件。
- 把 TwelveDays.hs 中所有 `String` 都換成 `Text`，也就是：

```haskell
recite :: Int -> Int -> [Text]
```

這個部分完全是選用的。
