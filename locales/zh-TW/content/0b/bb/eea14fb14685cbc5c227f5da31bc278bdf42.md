# 有 main 函式

移除`Main`函式，因為測試並不需要它，而且留著會讓程式碼稍微難以閱讀。

通常會加上`Main`函式來協助為程式碼除錯。不過，更好的做法是在執行 1 個或多個單元測試時，一邊為程式碼除錯。這樣做還有個好處：可以專注於為某個特定的測試案例除錯。以下是一些連結，說明如何在各種 IDE 中一邊執行單元測試、一邊為 Scala 程式碼除錯：

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
