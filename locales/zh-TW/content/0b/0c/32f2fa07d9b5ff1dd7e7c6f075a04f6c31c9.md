# 整數

整數是沒有小數部分的數字，它們構成集合`{..., -2, -1, 0, 1, 2, ...}`。
整數的最大值和最小值取決於 PHP 執行所在的系統。
對大多數現代系統來說，整數通常是 64 位元的值，這表示它可以表示從`-9_223_372_036_854_775_808`到`9_223_372_036_854_775_807`的範圍（含端點）。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

除了 10 進位之外，你還可以使用基底前綴來撰寫整數字面值：

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
