# 忽略

## 額外的 jq 命令列選項

你會在測試中注意到`jq`多了些選項。

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

它們是什麼？

- `-s`

  這是「slurp」模式。
  輸入不會被當成一連串的 JSON 物件來處理，
  而是整份輸入都會被放進一個陣列裡。

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  你或許已經看過`-r`，用來輸出「原始」字串（不含引號）。
  這個選項正好相反。
  輸入的每一行都會被視為一個字串。

  兩個例子：

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

把這兩個選項搭在一起時，你_不會_得到一個字串陣列，
而是會把整份輸入當成單一個字串，包括每一行結尾的換行字元。

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

怎麼處理這種情況，也是這道練習的挑戰之一。
