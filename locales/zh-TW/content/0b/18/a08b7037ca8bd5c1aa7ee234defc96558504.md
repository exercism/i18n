# 關於

如果一個函式_最後_執行的事情是呼叫它自己，這個函式就是[尾端遞迴][recursion-tc]。

每次呼叫任何函式時，都會把一個含有區域變數、引數等內容的_堆疊框架_放到[函式呼叫堆疊][call-stack]的最上層。當函式回傳時，這個堆疊框架就會從堆疊中被移除。

尾端遞迴的函式可以使用[尾端呼叫最佳化][tail-call-optimization]。這種最佳化讓下一次函式呼叫可以重複使用上一個堆疊框架，因為前一個函式保證不再需要它。這能減少函式呼叫堆疊溢出的問題；所謂溢出，就是函式呼叫堆疊上的框架太多，多到沒有剩餘記憶體可以再建立新的框架。

- 在 Elixir 中，因為資料不可變的規則，要達成尾端遞迴通常需要一個累加器。

  - 累加器是一個會在遞迴呼叫之間傳遞的變數，用來保存遞迴函式_到目前為止_的狀態，直到最終結果在基本情況中被回傳。

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- 處理陣列時請記住，它們是以單向鏈結陣列實作的：從前端加入的操作非常快，但從尾端加入的操作非常慢。

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
