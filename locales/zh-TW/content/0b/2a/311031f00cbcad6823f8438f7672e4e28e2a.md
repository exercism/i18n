# 補充說明

## 本練習的專屬說明

這個練習中，你需要定義一個名為`robot`的**locale**，它定義了**名詞**`position`與`direction`，以及**動詞**`move`。

- `robot`的`create`動詞會以由 box 組成的陣列接收初始位置與方向。

    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move`會更新所建立**實體**的`position`與`direction`值。
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
