# 補充說明

## 例外訊息

有時候，你需要[引發例外](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。這麼做時，一定要附上**有意義的錯誤訊息**，指出錯誤的來源。這能讓程式碼更容易閱讀，對除錯也有很大的幫助。如果你知道錯誤來源會是某種特定的型別，可以選擇引發其中一種[內建錯誤型別](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要附上有意義的訊息。

這個練習要求你使用 [raise 敘述](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) 來「拋出」`ValueError`，表示無法用給定的硬幣湊出零錢。只有在你同時`raise`這個`exception`並附上訊息時，測試才會通過。

若要以訊息引發`ValueError`，請把訊息寫成`exception`型別的引數：

```python
# example when change cannot be made with the coins passed in
raise ValueError("can't make target with given coins")
```
