# 簡介

在 Common Lisp 裡，就像許多語言一樣，數字有幾種不同的型別，其中最基本的兩種是：

## 整數

和許多語言一樣，Common Lisp 也有整數。
這些是不含小數點的整數（例如`-6`、`0`、`25`、`1234`等等）。

Common Lisp 對整數的大小沒有限制。
整數可以任意大（如果是負數，也可以任意小）。

一般來說，如果你只處理整數，應該優先使用整數，因為在經過大量運算之後，整數不會像浮點數那樣損失精度。

## 浮點數

和許多語言一樣，Common Lisp 也有浮點數。
這些是帶有小數點的數字，可以是小數或整數（例如`3.14`、`-1.7`、`99.99`、`2048.0`）。

## 算術

Common Lisp 在大多數運算中使用標準的算術運算子，但比較特別的是它採用「前綴表示法」，而不是大家比較熟悉的「中綴表示法」。

用圖來看更清楚：

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前綴表示法雖然會把像`2 + 2`這樣的運算變成比較不熟悉的`(+ 2 2)`形式，但要一次對多個數字做運算時，就方便多了。

### 基本數學

Common Lisp 具備所有常見的函式：`+`、`-`、`*`、`/`，分別代表加、減、乘、除。

進行除法時，有時會想知道相除之後的餘數，這可以用`mod`函式（modulo，取模）來做，它接受一個數字和一個除數作為引數：

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

### 比較數字

最後，你可能會發現用`=`（等於）、`/=`（不等於）、`>=`（大於或等於）等函式來比較不同的數字很實用。
當比較結果為真（例如`(= 1 1)`）時，會回傳`T`；結果不成立時（例如`(> 0 1)`），則回傳`NIL`。
