# 提示

## 1. 檢查指令是否有效

- 使用 [test()][mdn-regex-test] 方法來回傳布林值。
- 記得可以在正規表達式結尾加上[旗標][mdn-flags]，以取得額外功能，例如不分大小寫。

## 2. 移除加密的表情符號

- 在這個情況下，我們必須使用 [RexExp][mdn-regular-expressions] 建構函式來建立正規表達式。
- 由於每個表情符號的加密方式都相同，我們可以用`[0-9]`來搜尋`emoji`這個字後面的任何數字。
- 字元`+`會比對一或多個連續項目。
- 對每個表情符號使用 [split()][mdn-regex-split] 方法搭配正規表達式，就能去除所有加密內容。
- 最後，使用 [join()][mdn-join] 方法把分割後的陣列以字串回傳。

## 3. 檢查電話號碼是否有效

- 在這道練習中，我們會用到`groups and ranges`。閱讀這份[說明文件][mdn-groups]，可以進一步了解相關內容。
- 這篇[文章][phone-validation]非常善於說明各種號碼驗證的方式。
- 你也可以使用這份[速查表][mdn-regex-cheatsheet]，綜覽正規表達式提供的各種功能。
- 使用`test()`方法檢查電話號碼是否有效。
- 用簡單的`if statement`回傳最終答案。

## 4. 取得網站連結

- 我們要找出以一個或多個`.(dots)`連接起來的單字。
- 記得在結尾加上旗標`g`，這樣才能取得句子中的所有網域。
- 使用 [match()][mdn-regex-match] 方法回傳一個包含先前所有比對結果的陣列。

## 5. 向使用者打招呼

- 首先，直接對給定的字串使用 [replace()][mdn-regex-replace] 方法。
- 使用[具名捕獲群組][mdn-groups]把`name`和`surname`儲存到不同的值裡。
- 把`(...match)`解構傳給替換函式，就能把名字和姓氏放進比對群組裡的物件中。
- 使用`pop()`方法儲存含有`name`和`surname`的比對物件。
- 最後，實作`template String`，就能從正規表達式物件中取得這些值。想知道 match() 如何儲存物件，請參考[這個][mdn-capturing-groups]範例。
