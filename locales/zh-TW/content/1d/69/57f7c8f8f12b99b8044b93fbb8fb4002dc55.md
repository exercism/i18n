# 關於

模式匹配是一種依照值是否匹配指定的模式（可能是深層模式）來分支的過程。在 Haxe 中，**模式匹配**是透過`switch`運算式和個別的`case`運算式來完成的。

看看這個資料結構：

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- 模式一律會由上往下匹配。
- 最上面那個匹配輸入值的模式，會執行它對應的運算式。
- `_` 模式可以匹配任何東西，所以`case _:`等同於`default:`

## 列舉匹配

列舉可以依它們的建構子自然地匹配：

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
