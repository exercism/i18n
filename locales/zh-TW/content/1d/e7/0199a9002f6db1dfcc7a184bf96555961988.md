# 關於

## 條件式

條件式是做出決策的敘述，可以執行副作用，也能控制程式執行的流程。
條件式包含`if`、`if/else`、`switch` 和`ternary`敘述。

條件式用來對某個值，或值與值之間的關係提出問題。
問題會求值為一個布林答案，但`if`敘述本身可以回傳任何值，也可以單純執行副作用。

## `if` 敘述

最簡單的`if`敘述會對一個運算式求值，並執行一行。
被測試的運算式一律放在括號中。

它可以執行副作用

```c
if (count > 10)
    printf("count is greater than 10");
```

也可以改變執行的流程


```c
if (count > 10)
    return sum;
```

如果`if`敘述要執行超過一行，就必須把這些行放在大括號裡

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

有些開發團隊可能會統一規定`if`敘述一律使用大括號，即使只有一行也一樣。


## `if` 與 `else`

`if`敘述可以搭配`else`一起使用

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`、`else if`


`else`可以再搭配另一個`if`，形成所謂的`if-else-if ladder`。

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


有時候`if-else-if ladder`用`switch`來表達會更好。
和`if`一樣，被測試的運算式一律放在括號中。

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

當被測試的值不符合前面任何一個`case`時，就會執行`default`。

如果某個`switch`的`case`沒有回傳，通常會插入`break`來結束每個`case`，否則邏輯會「穿透」到下一個 case。
有時候穿透是刻意使用的

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

當穿透不是刻意發生時，那就是個 bug。

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

當要測試的是特定值，而不是一段範圍的值時，switch 會很有用。
它可能比`if-else-if ladder`更快，因為編譯器可以用某些方式最佳化`switch`敘述，而用階梯時做不到。
有時候 switch 看起來也比階梯更好閱讀。

## 三元運算子（又稱條件運算子）

三元運算子是一種由三個部分組成的條件式，常用來設定值。
要測試的運算式放在問號前面，不一定要用括號包起來。
條件為真時回傳的值放在冒號前，條件為假時回傳的值放在冒號後。
可以回傳字面值，也可以回傳變數。

```c
int i = j > 5 ? 5: j;
```

三元運算子可以巢狀使用，以減少語法上的雜亂。

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## 浮點數的條件比較

由於浮點數的實作方式，一個簡單的數學運算就可能產生捨入誤差，導致相等性的測試無法回傳預期的結果。

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

可以使用一個稱為`epsilon`的容差值，來決定某個值要落在什麼範圍內，才會在與另一個值比較時仍被視為相等。
有些平台內建了 float 和 double 的 epsilon 常數。
想了解更多，請參考你的編譯器文件。
計算 epsilon 可能相當複雜，而且可能因平台而異，甚至在不同機器之間也有所不同。
以下是一個使用簡單比較的範例程式。

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

比較`float`s 或`double`s 是否相等時要特別小心！
