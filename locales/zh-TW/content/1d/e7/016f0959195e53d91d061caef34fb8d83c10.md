# 說明

鑽石 kata 會接收一個字母作為輸入，並將它輸出成鑽石形狀。給定一個字母後，它會印出一個從 'A' 開始、並在鑽石最寬處放上該字母的鑽石。

## 需求

* 第一列包含一個 'A'。
* 最後一列包含一個 'A'。
* 除了第一列和最後一列以外，每一列都恰好有兩個相同的字母。
* 每一列的前導空格數與尾隨空格數相同。（可能是 0 個。）
* 鑽石左右對稱。
* 鑽石上下對稱。
* 鑽石的形狀是正方形（寬度等於高度）。
* 字母排列成鑽石形狀。
* 上半部的字母依遞增順序排列。
* 下半部的字母依遞減順序排列。
* 四個角落（包含空格的部分）是三角形。

## 範例

在以下範例中，空格以`·`字元表示。

字母 'A' 的鑽石：

```text
A
```

字母 'C' 的鑽石：

```text
··A··
·B·B·
C···C
·B·B·
··A··
```

字母 'E' 的鑽石：

```text
····A····
···B·B···
··C···C··
·D·····D·
E·······E
·D·····D·
··C···C··
···B·B···
····A····
```
