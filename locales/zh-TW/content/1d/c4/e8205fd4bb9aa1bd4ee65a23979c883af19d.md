# 關於

關於 Java 字串，最重要的一點是它們是不可變的物件，代表一串 Unicode 字元（字母、數字、標點符號等）。
雙引號用來定義`String`實例：

```java
String fruit = "Apple";
```

操作字串可以使用[`String`][string-class]類別的方法。
由於字串的值在定義之後永遠不會改變，所有字串操作方法都會回傳一個新的字串。

字串是由雙引號（`"`）字元所界定。
有些特殊字元需要使用反斜線（`\`）字元跳脫。
在 Java 中需要跳脫的字元有：

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

最後，串接字串有許多種方式。
最簡單的是`+`運算子：

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

如果字串格式化比單純串接更複雜，建議使用`String.format`方法。

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

其他做法還有：

- 使用[`StringBuilder`類別][string-builder]
- 使用[`String.concat`方法][string-concat]
