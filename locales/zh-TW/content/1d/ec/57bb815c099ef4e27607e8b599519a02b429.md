# 疊代器的組合

一個迴圈可以呼叫多個疊代器。每一輪會向每個疊代器索取它的下一個值，而它們會一起往前推進。

```sather
   loop
      first ::= violin_one.elt!;
      second ::= violin_two.elt!;
      #OUT + first + " against " + second + "\n";
   end;
```

這會讓兩個陣列並排前進：第一個元素配第一個元素，第二個配第二個。

## 讓所有人都意外的規則

**迴圈會在其中*第一個*疊代器用盡時立刻結束。**

不是最後一個用盡的時候，也不是全部都用盡的時候。是第一個。

所以如果`violin_one`有四小節，而`violin_two`只有兩小節，上面的迴圈會執行**兩次**。第一部的第三和第四小節永遠不會被看到，因為到那個時候，第二部已經沒有東西可以提供。

這通常正是我們想要的：配對只有在還湊得成對的時候才有意義。但這條規則必須事先知道，而不是自己撞見了才發現。

## 同時計數

一個永遠不會用盡的疊代器，正是因為這條規則才顯得有用。`up!`會一直數下去：

```sather
1.up!        -- 1, 2, 3, 4, ... and never ends
```

單獨使用時，它會永遠迴圈下去。搭配一個會結束的疊代器，它就能為這些值編號，而完全不必決定要數到哪裡：

```sather
   loop
      number ::= 1.up!;
      bar ::= part.elt!;
      #OUT + "Bar " + number + ": " + bar + "\n";
   end;
```

`part.elt!`負責結束迴圈；`1.up!`負責提供編號。兩者都不需要知道這個部有多長。

## 順序不重要

所有疊代器每一輪都只被索取一次，所以哪一個先寫並沒有差別。重要的是每一個都恰好被索取一次，在同一輪裡寫兩次`part.elt!`會取到兩個值，而不是一個。
