# 安裝 Emacs

由於 Emacs Lisp（elisp）是 Emacs 的擴充語言，你需要先安裝 [GNU Emacs](http://www.gnu.org/software/emacs/)。

建議安裝最新版的 Emacs，不過這些練習的目標實作版本應以 28.1 以上為準。
如果你已經安裝了 Emacs，可以用`M-x emacs-version RET`檢查 Emacs 版本。

## 在 OS X 上
最簡單的方式是前往 [Emacs For Mac OS X](http://emacsformacosx.com/) 下載 dmg 檔，它會把 GNU Emacs
安裝成一個打包好的 OS X 應用程式。

也有其他選擇，例如 Aquamacs（不建議），或者如果你偏好，也可以透過
[Homebrew](https://formulae.brew.sh/formula/emacs) 安裝。

## 在 Linux 上
在某些發行版上，Emacs 已經預先安裝好了，因為它是 GNU 的一部分。

### Ubuntu
目前建議透過 [snap](https://snapcraft.io/emacs) 安裝最新版的 Emacs：

```
sudo snap install emacs --classic
```

如果你不想用 snap，也可以透過 snap 安裝 Emacs，但 Ubuntu 軟體倉庫提供的版本通常已經過時。
如果你想透過 apt 安裝較新版本的 Emacs，就需要使用 [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs)，或是[從原始碼建置](https://www.emacswiki.org/emacs/BuildingEmacs)。

如果你不在意是否安裝最新版本，那應該就只是這樣：

```
sudo apt-get install emacs
```

### Arch
Arch 通常會直接搭載最新版的 Emacs，所以只要執行：

```
sudo pacman -S emacs
```

這樣就搞定了。

### 其他發行版
查一下你的發行版目前提供哪個版本，再視情況使用套件管理器，或從原始碼建置。

### Windows
要在 Windows 上安裝 Emacs，請前往最接近你的
[FTP 封存鏡像站](https://ftpmirror.gnu.org/emacs/windows)，取得安裝檔（=emacs-XX.X-installer.exe=），然後執行它。
如果你想不安裝就使用 Emacs，可以下載符合 =emacs-XX.x.zip= 模式的檔案，解壓縮後執行 `bin\runemacs.exe`。

如果你使用 [MSYS2](https://www.msys2.org/)，可以用以下指令安裝 64 位元的 Emacs

```
pacman -S mingw-w64-x86_64-emacs
```

或是用以下指令安裝 32 位元的版本

```
pacman -S mingw-w64-i686-emacs
```
