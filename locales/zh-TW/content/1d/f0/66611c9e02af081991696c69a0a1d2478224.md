# 補充說明

## 輸出

在這個練習中，你要實作一個動詞，用來產生指定列數以內的巴斯卡三角形。你的動詞所產生的輸出可以有兩種格式：

  1. 盒裝列表的陣列，其中每個列表代表巴斯卡三角形的一列。
  1. 表格，其中的數字靠右對齊，左邊的空白則用 0 填補。

### 輸出範例

以下是`pascal 3`的兩個有效輸出：

  - 盒裝列表的陣列：
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - 含補齊的表格：
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
