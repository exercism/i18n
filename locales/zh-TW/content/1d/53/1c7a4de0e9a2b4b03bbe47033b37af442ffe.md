# 資源

- [C++ Reference](http://en.cppreference.com/w/)：C 與 C++ 程式語言的線上參考文件。不確定某個方法在做什麼，或是某個 STL 資料結構的介面該怎麼寫嗎？cppreference.com 都能幫你解答。
- [The Definitive C++ Book Guide and List](https://stackoverflow.com/questions/388242/the-definitive-c-book-guide-and-list)：StackOverflow 上那個討論 C++ 書籍的傳奇問題。
- [StackOverflow 上的`c++-faq`標籤](https://stackoverflow.com/tags/c%2b%2b-faq/info)
- [isocpp.com 的 C++ FAQ](https://isocpp.org/faq)
