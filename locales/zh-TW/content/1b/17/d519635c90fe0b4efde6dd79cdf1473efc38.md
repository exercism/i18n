# 指令

在這道練習中，你會寫一支程式，幫助你為購買車輛做好準備。

你有兩個任務：判斷自己是否需要取得駕照，以及估算中古車的合理價格。

## 1. 判斷自己是否需要駕照

某些種類的車輛需要駕照才能操作。
假設只有名稱包含`car`或`truck`的車輛需要駕照；其他車輛都不需要駕照就能操作。

實作一組 `pattern {action}`，當第一個欄位是 `needs_license` 時就會符合。
它應該從第二個欄位取得車輛種類，並在該種類車輛需要駕照時印出 "true"。
如果不需要駕照，就不必印出任何東西。

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. 估算中古車的價格

既然你已經做出決定，就會希望確保自己在經銷商那裡拿到合理的價格。
由於你有意購買中古車，價格取決於車齡。
粗略估計的話，假設車輛不到 3 年，價格就是全新時原價的 80%。
如果超過 10 年，就是 50%。
如果車輛至少 3 年但未超過 10 年，價格就是原價的 70%。

實作一組 `pattern {action}`，當第一個欄位是 `resell_price` 時就會符合。
它應該從第二個欄位取得車輛的原價，並從第三個欄位取得車齡。
動作應該印出估算的價格。

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
