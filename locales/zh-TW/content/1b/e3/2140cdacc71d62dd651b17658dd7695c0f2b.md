# 條件判斷

Crystal 有所謂的控制運算式，它們用來控制程式的執行方式，並接收真值或假值。
有些運算子可以用來產生真值或假值，這些運算子稱為[相等與比較運算子][equality-and-comparison]。

主要有兩種控制運算式，用來決定哪些程式碼會執行、哪些不會執行。
也就是決定會執行哪個分支。

這兩種是：`if` 和 `unless` 運算式。

## 比較運算子

比較運算子用來比較值，並回傳 `true` 或 `false` 值。
這些運算子要求被比較的兩個值具有相同的型別。
如果兩個值的型別不同，編譯器會拋出錯誤。
以下是比較運算子的列表，以及它們得到 `true` 值的範例：

| Method | Description           | Example |
| ------ | --------------------- | ------- |
| <      | 小於                  | 4 < 5   |
| <=     | 小於或等於            | 4 <= 4  |
| >      | 大於                  | 3 > 1   |
| >=     | 大於或等於            | 2 >= 2  |

## 相等運算子

相等運算子與比較運算子類似，但它們用來檢查兩個值是否相等。

`==` 運算子會檢查兩個值是否相等，包括值的型別。
如果兩個值相同，它會回傳 `true`，否則回傳 `false`。
`==` 運算子可以比較任何型別的值與任何其他型別的值。
`!=` 的運作方式相同，但如果兩個值不相等就回傳 `true`，相等則回傳 `false`。

## 太空船運算子

太空船運算子是一種獨特的比較運算子，它的名稱來自它的外觀。
它的獨特之處在於，它不回傳真值或假值，而是回傳一個數字。
它寫成 `<=>`，用來比較兩個值。
如果左邊的值大於右邊的值，它會回傳 `1`；如果左邊的值小於右邊的值，回傳 `-1`；如果兩個值相等，回傳 `0`。

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## `if` 敘述

[`if`][if] 敘述用來檢查給定的條件是真還是假。
如果條件為真，`if` 敘述內部的程式碼就會執行。
`if` 敘述以 `end` 關鍵字結束。

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## `unless` 敘述

[`unless`][unless] 敘述的運作方式與 `if` 敘述非常類似，但如果條件為假，它會執行 `unless` 敘述內部的程式碼。

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## `else` 敘述

`else` 敘述可以搭配 `if` 和 `unless` 敘述使用。
如果 `if` 分支或 `unless` 分支沒有執行，`else` 敘述就會執行。

~~~~exercism/warning
雖然 `else` 分支可以搭配 `unless,` 使用，但不建議這麼做，因為這會影響可讀性。
建議改用 `if !condition` 搭配 else 分支。
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## 「串接式 if」敘述

`elsif` 敘述可以搭配 `if` 敘述使用。
如果 `if` 分支沒有執行，且 `elsif` 敘述的條件為真，`elsif` 敘述就會執行。
`elsif` 敘述可以串接在一起，第一個為真的條件會被執行。
`if` 敘述的結尾也可以加上 else 敘述，當前面的條件都不成立時，就會執行它。

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## 三元運算子

Crystal 有三元運算子，也就是單行的 if-else 敘述：`condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## 把 if 和 unless 當成後綴

if 和 unless 敘述也可以當作[後綴][if-as-suffix]使用，當你想在條件成立時執行單行程式碼，這就很有用。
做法是把 if 或 unless 敘述放在你想執行的程式碼後面。

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## 條件判斷與型別

當變數被指定不同型別的值時，它會同時帶有這兩種型別。
這是因為編譯器不知道哪個分支會被執行。
這種多重指定，也就是所謂的聯合型別，會在後續的概念中說明。
可以從以下範例看出：

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
