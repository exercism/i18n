# 測試

選擇你目前的作業系統：

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# 執行測試

## Windows

1. 開啟 Command Prompt。

2. 取得第一個練習：

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. 切換到練習資料夾：

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. 執行測試：

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *（第一次執行測試失敗時別擔心喔，每個練習都是這樣開始的。）*

5. 解開這個練習。
    閱讀 `instructions.md`，了解如何解開這個練習（[在 GitHub 上查看](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)）。


祝你好運，玩得開心，歡迎加入 COBOL 軌道喔！

----

## macOS

1. 開啟終端機視窗。

2. 取得第一個練習：

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. 切換到練習資料夾：

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. 執行測試：

    ```
     $ bash test.sh
    ```
    *（第一次執行測試失敗時別擔心喔，每個練習都是這樣開始的。）*

    提示：如果出現`basename`遺失的訊息，你可以用 [brew](https://brew.sh/) 安裝 coreutils。（`brew install coreutils`）

5. 解開這個練習。

    閱讀 `instructions.md`，了解如何解開這個練習（[在 GitHub 上查看](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)）。


祝你好運，玩得開心，歡迎加入 COBOL 軌道喔！
