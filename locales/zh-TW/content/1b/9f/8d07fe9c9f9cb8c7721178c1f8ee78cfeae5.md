# 補充指令

## 關於 Enum

enum 敘述讓你能建立一組強型別的標籤。你可以在程式碼中使用這種列舉，不必解析，也不用檢查拼字錯誤。

列舉在內部會以整數表示，起始值為零。預設情況下，PowerShell 會把清單中的第一個標籤指定為 0，其餘的標籤則依序指定連續整數。

範例：
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

想進一步了解 PowerShell 中的 Enum，不妨參閱 [Enum 模組](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)。
