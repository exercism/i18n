# 關於

`Option`型別是 F# 用來處理「值可能存在、也可能不存在」的語言機制。它提供了型別安全的做法，取代其他語言常用來處理這類值的`null`。許多 F# 標準函式庫的函式都會用到它，因此想有效運用 F# 標準函式庫，就一定要了解它。

## 使用 `Option`型別的好處

* __編譯期安全__：把值的存在與否明確表達在型別系統中，編譯器就能確保你處理了「沒有值」的情況，避免一大類使用 null 時可能發生的 bug。

* __執行期安全__：F# 不用`null`，而是用`None`來表示值不存在，因此`NullReferenceException`不可能發生。

* __強制明確處理__：型別系統要求程式碼明確處理`Some value`和`None`兩種情況，讓你的程式碼更穩健、更可預測。

* __可搭配模式比對__：`Option`能與 F# 的模式比對慣用語法完美搭配，提供乾淨又安全的方式：值存在時就解構並處理它，不存在時則執行其他動作。

## 用法

`Option`型別是泛型型別（具有一個底層型別）。  
`Option`值不是`Some value`（代表某個特定的值），就是`None`（代表沒有值）。

下面這個函式示範如何建立`Option`值：

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`是`Option<T>`的後置語法寫法，這兩種語法形式可以互換使用。
不過，根據 F# 樣式指南，Option 型別建議採用後置標記法（參見 [F# 樣式指南中關於型別與型別標註格式化的章節](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)）。
~~~~

`Option`的典型用途是搜尋函式。
例如，當項目在清單中時，`List.tryFind`函式會回傳`Some index`（其中`index`是所求的值在清單中的位置）；當項目不在清單中時，則回傳`None`。

## 讀取 Option 值的內容

讀取`Option`值的慣用方式是透過模式比對，如下例所示：

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## 以預設值解開 Option

`Option`可以透過`Option.defaultValue`函式提供預設值來「解開」（轉換成它內含的型別）。
當你想確保值不是`None`時，這特別有用。例如：

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## `Option`模組中的其他函式

`Option`模組還包含一些函式，對應到清單、陣列、序列和其他集合型別可用的函式，例如`Option.map`、`Option.iter`、`Option.forall`、`Option.count`。
這些函式讓`Option`可以像包含 0 個或 1 個元素的集合那樣操作。
