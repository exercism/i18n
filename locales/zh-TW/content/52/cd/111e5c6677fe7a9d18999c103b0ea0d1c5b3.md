# 簡介

## 迴圈

迴圈用來重複執行某段邏輯。
最常見的兩種是 `while loop`（不確定次數的迴圈）與 `for loop`（確定次數，也就是計數迴圈）。
另外還有 `for each` 迴圈，之後的某個概念會再提到。

### 一般語法

`for loop` 由一個標頭和一段程式區塊組成，程式區塊裡是用大括號包住的迴圈主體。
標頭由 3 個以分號`;`分隔的元件組成：初始化敘述、條件，以及另一個運算式。
這三個元件都可以是空的。

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- **初始化敘述**這個元件是一段只會在迴圈開始前執行一次的程式碼。
- **條件**這個元件必須是一段會求值為`boolean`的運算式，用來控制迴圈何時該停止。
  只要這個條件的求值結果是`true`，迴圈內的程式碼就會持續執行。
  一旦這個運算式求值為`false`，迴圈就不會再進行任何疊代。
- **運算式**這個元件是一段會在每次疊代結束時執行的程式碼。

`while loop` 只要它的**條件**檢查結果為`true`，就會一直執行它的主體。
下面的程式碼片段示範如何把`for`改寫成`while loop`。

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### 中場休息：遞增與遞減

使用迴圈時，經常需要對記錄疊代次數的計數變數加 1 或減 1。
這種動作實在太常見了，所以遞增與遞減有專屬的運算子：`++`和`--`。

它們有**前置**與**後置**兩種形式。
前置形式會在敘述中使用變數之前先改變變數，後置形式則是在使用之後才改變。
大多數時候，你想要的應該都是前置形式。

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### `for` 迴圈：範例

_初始化元件_通常用來設定計數變數，_條件_用來檢查迴圈該繼續還是停止，而_後置元件_則通常在每次重複結束時遞增計數器。

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

這個迴圈會把`1`到`9`的數字加總（包含`9`）。

### break 與 continue

在迴圈主體中，你可以使用`break`關鍵字來完全停止迴圈的執行：

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

相對地，`continue`關鍵字只會停止目前這一次疊代的執行，然後繼續進行下一次：

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
當`break`和`continue`的使用降到最低，或完全避免時，迴圈的邏輯通常會比較容易理解。
這兩個關鍵字都會略過程式碼中的某些部分，往往讓人更難跟上。
~~~~
