# 說明

你在社區藝術中心當志工，正門入口上方正貼起一幅長長的陶瓷磁磚馬賽克。設計團隊把這件作品**一列一列**地排好了：每一列是磁磚顏色組成的陣列，而整幅馬賽克則是各列組成的陣列。

當其他志工在切割、擺放和重新排列磁磚時，你則在寫一些小型、可重複使用的詞，用來建構、組合和查詢這份設計的各個部分。

## 1. 單一磁磚的條

定義`tile-strip`，讓它接受一個顏色，並回傳只裝著該顏色、含 1 個元素的列。

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. 三個磁磚的一列

定義`row-of-three`，讓它從堆疊取出三個顏色，並回傳含 3 個元素的列。

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. 把各列合併成攤平的磁磚清單

設計團隊需要快速檢查整幅馬賽克所有列的顏色總數。定義`combine-rows`，讓它接受由各列組成的陣列，並依照順序回傳所有磁磚的單一序列。

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. 鏡像反轉一列

為了做出對稱的面板，團隊會先把一列鏡像反轉，再把複本放到對面那一側。定義`mirror-row`，回傳順序相反的一列。

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. 這個顏色在列中的哪個位置？

定義`tile-position`，讓它接受一列和一個顏色，並回傳該列中第一個這種顏色磁磚的索引（從 0 開始）。如果列中沒有這個顏色，就回傳`f`。

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. 這一列含有這個顏色嗎？

定義`has-colour?`，讓它接受一列和一個顏色；如果該顏色出現在列中的任何位置就回傳`t`，否則回傳`f`。

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
