# 說明

在卡牌遊戲 Spellbound Steel 中，你的牌組裡有各種卡牌，上頭可能是不同的角色，例如 warrior、mage 和 rogue，也可能是不同的法術，例如 fireball、ice storm 和 lightning bolt。
遊戲中有二到四位玩家，目標是打出威力值更高的卡牌來擊敗其他玩家。

你想建立各種方法來計算、排序和比較卡牌的威力值，好在遊戲中取得優勢。

## 1. 在牌組中尋找卡牌

你不確定某張卡牌是否在牌組裡。
因此，你想要一個方法，能告訴你牌組中第一張你想找的卡牌在哪裡。
如果牌組裡沒有這張卡牌，你也想知道。

實作一個方法 `SpellboundSteel.find_card?`，它接受一個由 `String` 卡牌組成的 `Array`，以及一張要尋找的 `String` 卡牌。
這個方法應該回傳牌組中第一張符合要尋找卡牌的索引。
如果牌組裡沒有這張卡牌，方法應該回傳 `nil`。

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. 將所有字元改成大寫

為了讓卡牌更容易閱讀，你想把卡牌名稱中的所有字元改成大寫。
這樣一來，你打出卡牌時就能輕易看清卡牌名稱。

實作一個方法 `SpellboundSteel.capitalize_cards`，它接受一個由 `String` 卡牌組成的 `Array`，並回傳所有字元都已改成大寫的卡牌。

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. 計算所有卡牌的威力值

在遊戲中，計算所有卡牌的威力值很重要。
所有卡牌的威力值可以在下表中看到：

| 卡牌類型       | 威力值 |
|----------------|-------------|
| Warrior        | 10          |
| Mage           | 20          |
| Rogue          | 30          |
| Fireball       | 15          |
| Ice Storm      | 25          |
| Lightning Bolt | 35          |

實作一個方法 `SpellboundSteel.calculate_power_level`，它接受一個由 `String` 卡牌組成的 `Array`，並回傳所有卡牌的威力值總和。

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. 解碼卡牌

遊戲中有所謂的詛咒卡牌。
這些卡牌是隱藏的卡牌，只有打出它的玩家才能解碼。
要解碼卡牌，你需要取出卡牌名稱中每隔一個的字元，並移除其餘的字元。
這樣就會得到卡牌的名稱。

實作一個方法 `SpellboundSteel.decode_card`，它接受一張 `String` 卡牌，並回傳解碼後的卡牌。

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
