## 使用方法

### 建置

`npx blueprint build`或`yarn blueprint build`

### 測試

`npx blueprint test`或`yarn blueprint test`

### 部署或執行其他指令碼

`npx blueprint run`或`yarn blueprint run`

### 新增合約

`npx blueprint create ContractName`或`yarn blueprint create ContractName`
