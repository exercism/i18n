# 說明

你在一家名為「Doctor Data」的澳洲公司開始你的第一天，該公司專門從事資訊復原。
你憑藉對 C++ 和[馮·諾伊曼探測器][van-neumann-probes]的知識，順利通過了工作面試。
由於你見過許多測試檔案，你的新老闆希望你能從公司最近恢復的一些測試程式碼中，重建各自的原始碼與標頭檔案。

~~~~exercism/note
這個概念練習的工作流與 Exercism 練習題的結構非常相似。
練習的介紹文字只是規格的一部分。
測試檔案是解決給定問題的權威指南。
由於 C++ 編譯的運作方式，在你實作測試所要求的每個類別、函式與列舉的最小版本之前，測試結果可能不會顯示在網頁介面上。
如果你收到編譯錯誤，在你處理完所有任務與測試後，它們可能會消失。
~~~~

你有四項任務，全都與從標頭檔與原始碼檔案中復原遺失的程式碼有關。

## 1. 試著提取一些初步線索

你查看從測試檔案中恢復的兩行程式碼：

```cpp
heaven::Vessel bob{"Robert Johansson", 1};
heaven::Vessel will{"Riker", 2, star_map::System::BetaHydri};
```

你銳利的眼睛立刻認出一個命名空間`heaven`。
你也看到一定有一個叫做`Vessel`的類別。
建構子顯然可以用兩個或三個引數來呼叫。
第一個引數的型別似乎是`string`，第二個是數字。
可以使用第三個引數來初始化`Vessel`類別。
第三個引數來自`star_map`命名空間。
它是型別為`System`的列舉值。
你甚至得到了其中一個列舉值：`BetaHydri`。

準備原始碼與標頭檔案，並寫入你發現的資訊。
你需要兩個命名空間：`heaven`和`star_map`。
`heaven`命名空間有一個類別`Vessel`，它可以用兩個或三個引數來呼叫。
`System`列舉應放在`star_map`命名空間中，並有一個`BetaHydri`列舉值。
留意其他列舉值，以便你能不斷更新`System`列舉。

## 2. 找出更多細節

你發現更多來自測試的程式碼行：

```cpp
heaven::Vessel bob{"Robert Johansson", 1};
REQUIRE(bob.current_system == star_map::System::Sol);
REQUIRE(bob.generation == 1);
heaven::Vessel bob5 = bob.replicate("Mario");
REQUIRE(bob5.current_system == star_map::System::Sol);
REQUIRE(bob5.generation == 2);
```

新發現的測試程式碼行揭露了`Vessel`類別的另一個成員函式：`replicate`。
這個函式接收一個字串並回傳另一個`Vessel`實例。
你從前一項任務中得知建構子第三個引數的預設值。
你也看到`Vessel`類別的兩個公開成員變數，以及`replicate`成員函式的規格。

將`replicate`函式以及公開成員變數`current_system`和`generation`加入標頭檔與原始碼檔案中。

## 3. 探究內部運作

你在恢復的測試檔案中發現一些更有趣的程式碼行：

```cpp
heaven::Vessel bob6{"Homer", 3, star_map::System::EpsilonEridani};
REQUIRE(bob6.busters == 0);
bob6.make_buster();
REQUIRE(bob6.busters == 1);
bool success = bob6.shoot_buster();
REQUIRE(success);
REQUIRE(bob6.busters == 0);
success = bob6.shoot_buster();
REQUIRE_FALSE(success);
```

顯然，`Vessel`類別有一個成員變數`busters`，可以透過兩個類別成員函式`make_buster`和`shoot_buster`來改變。
在其他資訊出現之前，你猜測`make_buster`函式回傳`void`。
由於有針對`shoot_buster`回傳值的測試，你假設該函式回傳`bool`。

將這兩個函式與成員變數加入`Vessel`類別。
繼續尋找其他`System`列舉值。

## 4. 完成全貌

在你掃描測試檔案時，你只發現兩個尚未涵蓋的程式碼區段：

```cpp
heaven::Vessel bob1{"Bob", 1, star_map::System::AlphaCentauri};
heaven::Vessel marv{"Marvin", 2, star_map::System::DeltaEridani};
heaven::Vessel milo{"Milo", 3, star_map::System::DeltaEridani};
heaven::Vessel howie{"Howard", 4, star_map::System::Omicron2Eridani};

REQUIRE("Bob" == heaven::get_older_bob(bob1, marv));
REQUIRE(heaven::in_the_same_system(marv, milo));
REQUIRE_FALSE(heaven::in_the_same_system(marv, howie));
```

你看到兩個函式，它們不是`Vessel`類別的成員，因為它們不是用實例來呼叫的。
`get_older_bob`比較兩個`Vessel`實例並回傳一個`string`。
`in_the_same_system`比較兩個`Vessel`實例並回傳一個`bool`。

實作上述恢復的程式碼行中最後缺少的函式。
