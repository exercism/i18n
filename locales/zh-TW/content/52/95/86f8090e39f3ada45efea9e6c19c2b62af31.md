# 條件判斷

Ruby 有所謂的流程控制運算式，這些運算式用來控制程式的執行方式，而且會接受為真或為假的值。
有一些運算子可以用來產生為真或為假的值，這些運算子稱為[比較運算子][comparison-operators]。

主要有兩種控制運算式，用來決定哪些程式碼會被執行、哪些不會。
也就是決定要執行哪個分支。

這兩種分別是：`if`和`unless`運算式。

## 比較運算子

[比較運算子][comparison-operators]用來比較值，並回傳`true`或`false`值。
以下運算子需要兩個型別相同的值才能進行比較。
如果兩個值的型別不同，編譯器就會拋出錯誤。
以下是這些運算子的清單，以及它們產生`true`值的範例：

| 方法 | 說明           | 範例 |
| ------ | --------------------- | ------- |
| <      | 小於             | 4 < 5   |
| <=     | 小於或等於    | 4 <= 4  |
| >      | 大於          | 3 > 1   |
| >=     | 大於或等於 | 2 >= 2  |

相對於前面提到的運算子，等於和不等於運算子可以用來比較任何型別的值。
`==`運算子用來檢查兩個值是否相等，而且會一併檢查值的型別。
`!=`的運作方式相同，但如果兩個值不相等就會回傳`true`，相等則回傳`false`。
以下是等於和不等於運算子的清單，以及它們產生`true`值的範例：

| 方法 | 說明  | 範例 |
| ------ | ------------ | ------- |
| ==     | 等於        | 4 == 4  |
| !=     | 不等於    | 5 != 4  |

## `if`敘述

[`if`][if]敘述用來檢查給定的條件是否「為真」或「為假」。
如果條件為真，就會執行`if`敘述內的程式碼。
`if`敘述會以`end`關鍵字結尾。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless`敘述

`unless`敘述的運作方式和`if`敘述非常類似，但只有在條件為假時，才會執行`unless`敘述內的程式碼。

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else`敘述

`else`敘述可以搭配`if`敘述一起使用。
如果`if`分支沒有被執行，就會執行`else`敘述。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## 「串接式`if`」敘述

`elsif`敘述可以搭配`if`敘述一起使用。
如果`if`分支沒有被執行，且`elsif`敘述的條件為真，就會執行`elsif`敘述。
`elsif`敘述可以串接在一起，第一個為真的條件會被執行。
`if`敘述的結尾也可以加上`else`敘述，如果前面沒有任何敘述為真，就會執行它。

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
