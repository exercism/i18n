# 關於

JavaScript 使用`true`和`false`來表示邏輯中的兩個真值。

在 JavaScript 中，三種邏輯運算（AND、OR 和 NOT）各有對應的運算子：`&&`、`||`和`!`。
一般來說，運算的順序是有規則的：在這裡，會先套用`!`（否定），接著是`&&`（合取），最後才是`||`（析取）。

如果想改變運算子之間的運算順序，可以使用優先順序更高的運算子，也就是`( )`，它稱為「分組運算子」，或者簡單一點，就叫做「括號」。
事實上，`( )`運算子的優先順序是所有 JavaScript 運算子中最高的。
