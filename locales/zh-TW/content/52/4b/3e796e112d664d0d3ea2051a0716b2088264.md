# 指令補充

# 輸入

這個練習的輸入有：

- `target`：一個字串（例如`'stone'`），會是_左引數_。
- `candidates`：裝箱字串的陣列（例如`'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`），會是_右引數_。

你的動詞會像這樣被呼叫：

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## 輸出

你的動詞應該回傳一個裝著盒子的_陣列_，盒子裡放的是 `target` 的重組字。如果沒有重組字，結果應該是 `empty`。
