# 指令

在這道練習中，你將撰寫程式碼，協助一位自由工作者與專案經理溝通。你的任務是提供幾個工具函式，用來快速計算日薪與月薪，並可選擇性套用指定的折扣。

我們先在自由工作者與專案經理之間訂立幾條規則：

- 日薪是時薪的 8 倍。
- 一個月有 22 個可計費工作日。

有時，自由工作者會選擇在日薪上套用折扣（例如提供給最忠實的客戶，或非營利客戶）。

折扣以代表百分比的小數來表示，例如 `25.0`（25%）。

## 1. 根據時薪計算日薪

請實作名為 `dailyRateFrom` 的函式，根據作為參數的時薪計算日薪。
合約定義一天有 8 個可計費小時。

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

回傳的日薪應該是 `Double`。

## 2. 根據時薪與折扣計算月薪

請實作 `monthlyRateFrom` 函式，計算折扣後的月薪。
它接受兩個參數：時薪與折扣百分比。

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

回傳的月薪應該向上取整（取天花板值）至最接近的整數。

## 3. 根據預算、時薪與折扣計算完整工作日數

請實作函式 `workdaysIn`，它接受預算、時薪與折扣，並計算這樣能涵蓋多少個完整的工作日。

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
回傳的天數應該向下取整（取地板值）至最接近的整數。
