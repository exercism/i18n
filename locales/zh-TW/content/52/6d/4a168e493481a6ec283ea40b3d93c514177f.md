# 指示補充

## 重構

`Markdown.roc` 中的實作已經通過測試了。
請重構它，同時保留它的行為，以及`parse : Str -> Try(Str, _)`介面。
成功時回傳`Ok(html)`，並用`Err(...)`把任何解析錯誤往外傳遞。
這個練習涵蓋的只是 Markdown 的一小部分子集，而不是完整的 Markdown 規格。
測試定義了要保留的行為，包括空白行和沒有成對的強調標記該怎麼處理。

## 提示

<details>
<summary>顯示提示</summary>

找找看有沒有重複的邏輯、過度巢狀的條件、難以理解的名稱，以及不必要的可變狀態。
可以考慮把行的分類、行內強調和 HTML 渲染分開處理。
如果想用，測試應用程式裡已經把[`roc-parser`套件](https://github.com/lukewilliamboswell/roc-parser)以`parser`的名字提供了。
`Parser.one_of`、`Parser.many`和`Parser.between`可以幫你把小型的解析器組合起來。
用一般的字串和陣列函式寫出來的解法，也一樣歡迎喔。
