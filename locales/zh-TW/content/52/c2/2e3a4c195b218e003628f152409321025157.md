# 關於

C# 是一種多範式、靜態型別的程式語言，具備物件導向、宣告式、函式式、泛型、延遲與整合查詢等特性，以及型別推斷。

**靜態型別**指的是識別碼在編譯時期就已設定[型別](https://en.wikipedia.org/wiki/Type_system#Static_type_checking)，就像 Java、C++ 或 Haskell 那樣，而不是像 Python、Ruby 或 JavaScript 那樣可以存放任何型別的資料。

**物件導向**指的是 C# 提供命令式的[以類別為基礎的物件](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming)，具備單一繼承、介面與封裝等特性。

**宣告式**指的是撰寫[要做什麼](https://stackoverflow.com/questions/1784664/what-is-the-difference-between-declarative-and-imperative-programming)的程式，而不是怎麼做（也就是命令式程式設計）；後者屬於實作細節，可能反而讓人分心，忽略了領域或商業邏輯。

**函式式**指的是[函式是頭等型別](https://livebook.manning.com/#!/book/functional-programming-in-c-sharp/chapter-1)，可以作為引數傳入其他函式，也可以從其他函式回傳。

**泛型**指的是演算法以[稍後才會指定的](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/generic-type-parameters)型別來撰寫，等到需要時，再針對作為參數提供的特定型別具現化。

**延遲**[（又稱「延後執行」）](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/)指的是編譯器會把項目的求值延後到真正需要時才進行。這讓你可以安全地做些奇怪的事，例如操作無限的陣列；語言只會建立陣列到最後一個需要的值為止。

**整合查詢**指的是稱為 [LINQ「Language-Integrated Query」](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/)的語言特性，讓你直接在語言內進行延遲查詢，查詢的對象不只是語言本身的物件，還能透過 XML、JSON、SQL、NoSQL 資料庫與事件串流等格式查詢外部資料來源。

**型別推斷**指的是編譯器通常會自行推斷出識別碼的型別，讓你不必親自指定。Scala 和 F# 都會這麼做。

**語法**與 C、C++、Java 等其他 C 語言風格的語言相似。

**.NET**是 C# 執行所在的受控環境，因此你可以使用整個 .NET 生態系統，包括 [nuget.org](http://www.nuget.org) 上的所有套件。.NET 過去只能在 Windows 上執行，但隨著 [.NET Core](https://www.microsoft.com/net/core) 以及 [Mono](http://www.mono-project.com/) 的推出，你也能在 Mac、Linux 或 Unix 系統，以及行動平台上使用 C#。

C# 還有其他許多特性，讓多執行緒／多處理器程式設計、平行化、非同步、在受控環境中使用非受控程式碼，以及語言互通性都變得更容易。C# 由 Microsoft 開發與維護，並由 Microsoft 提供官方[文件](https://docs.microsoft.com/en-us/dotnet/csharp/)。
