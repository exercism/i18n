# 幫助

如果你遇到困難，可以試試下列其中一個資源：

- [Groovy Language Documentation](http://docs.groovy-lang.org/docs/latest/html/documentation/)
- Groovy Language Documentation 裡的 [Groovy Community](http://www.groovy-lang.org/community.html) 條目
- [/r/groovy](https://www.reddit.com/r/groovy) 是 Groovy 的 subreddit。
- 你可以用 [StackOverflow](http://stackoverflow.com/questions/tagged/groovy) 搜尋你的問題，看看是否已經有人回答過。你也可以發問和回答問題。
