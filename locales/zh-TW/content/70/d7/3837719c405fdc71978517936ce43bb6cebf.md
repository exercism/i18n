# 陣列

`ARRAY{T}`是一列型別為`T`的值，長度固定。

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## 大括號

`ARRAY{STR}`讀作「`STR`的陣列」。大括號裡放的是一個**型別參數**：單獨的`ARRAY`不是一個型別，因為陣列一定得是某種東西的陣列。Sather 函式庫有很多部分就是這樣建構出來的，之後你才會自己寫出這樣的類別。

## 位置

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

位置從`0`到`.size - 1`。陣列知道自己的大小，而且永遠不會改變：`ARRAY`沒有附加元素這回事。

## 不用字面值建立陣列

`#ARRAY{INT}(n)`會建立一個有`n`個值的陣列，每個值都是零：

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

要指定某個位置的值時，`:=`左邊用的也是同樣的方括號。

## 超出範圍

讀取或寫入不存在的位置，在一般建置中不會被檢查。它不會用有用的訊息讓程式停下來，而是去讀取或寫入記憶體裡剛好排在下一個的東西。兩個習慣可以避開這種情況：用`.size - 1`，不要用自己目測數出來的數字；迴圈則用`until!(i >= a.size)`收尾，不要用字面值。

## 印出陣列

`.str`會用大括號列出內容，在推敲的時候很方便：

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
