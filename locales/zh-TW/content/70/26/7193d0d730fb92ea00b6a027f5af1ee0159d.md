# 簡介

我們會將_語言_稱為 **AWK**，並將解讀 AWK 程式的_執行檔_稱為 **`awk`** 或 **`gawk`**。

## 模式與動作

一支 AWK 程式是由**模式與動作配對**所組成

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**模式**可以是與輸入進行比對的正規表達式模式。
它也可以是任何結果為 true 或 false 的運算式。

**動作**則是一或多個 AWK 指令。
外層的大括號是必要的。

如果模式的結果為 _true_，就會執行對應的動作。

## 記錄與欄位

AWK 會將輸入解析成一連串的**記錄**。
每筆記錄會再分割成零個或多個**欄位**。

預設行為是：

- 使用換行作為「記錄分隔符」，將輸入分割成記錄，因此每一_行_都是一筆記錄。
- 使用空白作為「欄位分隔符」，將記錄分割成欄位，因此每一個_詞_都是一個欄位。

## 模式與動作（續）

模式可以省略，此時動作會_針對每一筆輸入記錄_執行。

動作也可以省略，此時預設動作是印出目前的記錄。

### 特殊模式

有兩個經常使用的特殊模式。

- `BEGIN` 會在消耗任何輸入之前執行對應的動作。
- `END` 會在消耗完所有輸入之後執行對應的動作。

## 欄位變數

你可以用 `$1`、`$2`、`$3` 等來取用欄位。

目前的記錄是 `$0`。

以下是一些其他常用的內建變數。

### 控制輸入解析的內建變數

- `RS` 是輸入記錄分隔符。
  如前所述，它的預設值是換行。
- `FS` 是輸入欄位分隔符。

這些變數通常會在 `BEGIN` 動作區塊中設定。

### 傳達資訊的內建變數

這些變數會由 AWK 在程式執行期間自動設定。

- `NF` 會儲存目前記錄中的欄位數量。
  - 要取得最後一個欄位的值，請使用 `$NF`。
- `NR` 會儲存目前的記錄編號。
  - 當處理多個輸入檔時，`NR` 會存有目前為止已處理的記錄總數。
- `FNR` 會儲存目前輸入檔的目前記錄編號。
  - 為了說明 NR 與 FNR 的差異，以下是常見的 AWK 慣用語。
    ```awk
    NR == FNR {action}
    ```
    這代表「如果累計的記錄編號等於目前檔案的記錄編號」。
    這只會對_第一個輸入檔_中的記錄成立。

## 真值性

AWK 使用與 C 相同的真值性概念。

- 數字 `0` 為 false。
- 其他任何數字都為 true。

由於 AWK 是文字處理語言，真值也延伸到了字串。

- 空字串 `""` 為 false。
- 任何非空字串都為 true。

## 註解

註解以 `#` 字元開頭，並延伸到該行的結尾。

## 範例

在類 Unix 系統上，`/etc/passwd` 包含使用者的資訊。
每位使用者各佔一行，欄位之間以冒號分隔。

若要列出使用者名稱：

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

請注意，`{print $1}` 動作沒有模式，因此會對每一筆記錄執行。

如果我們想將輸出限制為只包含使用 bash 作為登入 shell 的使用者，可以這樣做：

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
