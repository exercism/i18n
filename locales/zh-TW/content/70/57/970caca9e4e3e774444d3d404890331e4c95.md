# 學習

Odin 是一門系統程式語言。
和 C 一樣，程式設計師必須手動管理記憶體。
不過，它是一門相當簡單的語言。

以下資源可以幫助你學習 Odin：

想先體驗這門語言，不妨從這裡開始：

* 觀看 [Introduction to Odin][video]，由 Odin 的創造者親自講解。
* 閱讀 [Introduction to Odin][intro] 這篇文章，作者是 ["Understanding the Odin Programming Language"][book] 一書的作者。
* 研讀 [Demo File][demo]，它用程式碼展示 Odin 的各種概念。

想更深入的話，可以參考：

* [Odin language overview][overview]。
* [官方套件][packages]的文件。
* ["Understanding the Odin Programming Language"][book] 這本書（需付費）。
* 官方的 ["Odin Examples"][examples] 範例集。
