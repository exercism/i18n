# 介紹

## `if`運算式

`jq`的**條件運算式**是`if A then B else C end`。

`if-then-else`就像所有`jq`內建函式一樣，是一種篩選器：它接受一個輸入，並產生一個輸出。

如果運算式`A`產生「真」的值，`if`篩選器就會求值`B`，否則就求值`C`。
傳進`if`篩選器的輸入會傳遞給`B`或`C`。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`子句是**選用的**，下面兩個敘述等價。

```jq
if A then B else . end
if A then B end
```
~~~~

## 巢狀`if`敘述

想加入更多條件，可以用`elif`。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

需要幾個`elif`子句就用幾個。

## 真值判斷

在`jq`裡，只有`false`和`null`算是「假」的值。
其他一切都是「真」，連數字 0、空字串、空陣列和空物件也是。

## 布林運算子

**布林運算子**`and`和`or`可以用來建立複雜的查詢。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

要取反，就用`not`。它是**篩選器**，不是運算子。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## 替代運算子

**替代運算子**讓你在運算式為 false 或 null 時，指定一個「預設」值。

```jq
A // B

# This is identical to
if A then A else B end
```

以下示範：

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
