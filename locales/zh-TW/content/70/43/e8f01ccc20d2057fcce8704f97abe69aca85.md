# 測試

大多數測試會檢查你是否藉由指定[result]，或將值傳給[exit]，來回傳預期的值。

有些測試會檢查你是否[raise]了預期的例外。

## 執行測試

`make`工具是執行測試時的相依項目。

在練習目錄中，於主控台或終端機輸入：

```sh
make
```

如果你完全還沒動過練習的解答檔案，就會看到類似這樣的訊息：

```
Please implement your solution.
```

所以在開始撰寫解答之前，請先移除這一行。

預設情況下，只會執行第一個測試。

```text
TAP version 14
1..10
ok 1 - ...
```

若要執行所有測試，請輸入：

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

所有測試都通過後，你就完成了這道練習，可以提交解答了。

你也可以傳入對應的編號，只執行單一測試，例如：

```sh
make test=2
```

就只會執行第二個測試。
