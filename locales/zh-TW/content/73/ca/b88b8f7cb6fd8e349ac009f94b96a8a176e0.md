# 說明

在這道練習中，你會寫一些程式碼，幫助你依照最愛的食譜書做出一份美味的千層麵。

你有五個任務，全都和烹調千層麵所花費的時間有關。

## 1. 定義千層麵在烤箱中的預期時間（分鐘）

定義`Lasagna.expected_minutes_in_oven/0`函式，這個函式不接受任何引數，並回傳千層麵應該在烤箱中待幾分鐘。根據食譜書，預期的烤箱時間為 40 分鐘：

```elixir
Lasagna.expected_minutes_in_oven()
# => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`Lasagna.remaining_minutes_in_oven/1`函式，這個函式接受千層麵已經在烤箱中的實際分鐘數作為引數，並根據上一個任務算出的預期烤箱時間（分鐘），回傳千層麵還需要在烤箱中待幾分鐘。

```elixir
Lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. 計算備料時間（分鐘）

定義`Lasagna.preparation_time_in_minutes/1`函式，這個函式接受你加到千層麵中的層數作為引數，並回傳你準備千層麵花了幾分鐘，假設每一層需要花你 2 分鐘準備。

```elixir
Lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. 計算總工作時間（分鐘）

定義`Lasagna.total_time_in_minutes/2`函式，這個函式接受兩個引數：第一個引數是你加到千層麵中的層數，第二個引數是千層麵已經在烤箱中的分鐘數。這個函式應該回傳你總共花了幾分鐘烹調千層麵，也就是備料時間（分鐘）加上千層麵當下已經在烤箱中待的分鐘數。

```elixir
Lasagna.total_time_in_minutes(3, 20)
# => 26
```

## 5. 建立千層麵完成的提示通知

定義`Lasagna.alarm/0`函式，這個函式不接受任何引數，並回傳一則訊息，表示千層麵已經可以吃了。

```elixir
Lasagna.alarm()
# => "Ding!"
```
