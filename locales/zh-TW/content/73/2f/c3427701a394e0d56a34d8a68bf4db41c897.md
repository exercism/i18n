# 關於

[`switch` 運算式][switch-expressions] 的行為，和 [concept:csharp/switch-statements]() 中介紹過的 [`switch` 敘述][switch-statements] 很類似。它們支援一種決策表，能把輸入條件對應到動作或值。

switch 運算式的核心是_模式比對_。在程式設計練習中，我們把值與 `const` 模式做比對。在這裡，`switch` 的輸入是一個_範圍運算式_，它會與 `const` 值以及_案例護衛_使用的值做比對。

這些案例（也稱為 _switch 分支_）會依文字順序求值。一旦找到符合的項目，比對過程就會立即中止，並回傳對應的值。

清單中最後的 `_` 案例，可以確保比對涵蓋所有情況，並避免可能的執行階段錯誤。

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

當模式與範圍變數符合，而且任何案例護衛的求值結果為 true 時，就會選中 `switch` 的某個「分支」。

switch 運算式也支援[型別模式][pattern-matching]和遞迴比對。
