# 關於

[Lua](https://lua.org) 是一門簡單卻強大、高效、輕量且可嵌入的腳本語言。它自 1993 年起，由 Roberto Ierusalimschy、Waldemar Celes 與 Luiz Henrique de Figueiredo 組成的團隊，在巴西的 [PUC-RIO](https://www.puc-rio.br/) 設計、實作與維護。

## 註解

Lua 的單行註解以`--`開頭，多行註解則以`--[[`開頭、以`]]`結尾。
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## 變數

Lua 中有三種變數：全域變數、區域變數與 table 欄位。為了保持簡單，這裡只說明區域變數。預設情況下所有變數都是全域的，所以我們必須用關鍵字`local`把變數宣告成區域變數。
```lua
local x
```

可以使用`=`運算子把值指定給變數。
```lua
local x = 1
```

`local`變數的作用域僅限於它被宣告的那個區塊。一個區塊可以是控制結構的主體、函式的主體，或是變數被宣告所在的檔案或字串。
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## 函式

函式用關鍵字`function`宣告，而且和變數一樣，預設是全域的。一個函式定義包含名稱、參數列表和主體。當執行到關鍵字`return`時，函式就會結束，並回傳列在它後面的所有值。如果沒有指定`return`，函式會回傳`nil`。

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## Table

Table 是 Lua 中唯一的資料結構機制，而且功能非常強大。它們可以用來表示陣列、集合、物件、模組等許多東西。基本上，Lua 的 table 就是關聯式陣列。
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

這裡只是先稍微了解一下，因為下一節會用到。之後我們會再回來詳細討論這個主題。

## 模組

模組是一組程式碼，存放在`.lua`原始碼檔案中。模組匯出的所有內容都會放在一個 table 裡，並在檔案最後回傳這個 table。所以這個 table 基本上就扮演類似命名空間的角色。
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

接著就可以透過`require`函式把那個模組載入另一個檔案，這個函式會回傳那個 table。
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

當我們看到`say.hello`時，會想到「模組`say`裡的函式`hello`」。但知道`say-hello.lua`會回傳一個 table，再回頭看前面 table 那一節，就會發現這個運算式在 Lua 中的意思是「用字串`hello`作為鍵來索引 table`say`」。

雖然讓模組回傳 table 是良好的做法，但要回傳其他任何型別也完全可行，例如函式。

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
