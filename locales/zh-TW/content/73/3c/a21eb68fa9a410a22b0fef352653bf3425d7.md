# 測試

你可以在 Exercism 網站上使用線上編輯器來解練習。
或者，把練習下載到自己的電腦，在本機解完之後再提交到 Exercism。
這份文件接下來要談的是在本機作業。

## Exercism CLI

你需要 `exercism` 命令列工具來下載與提交練習。
下載與設定的操作說明請參閱 [Exercism CLI 文件][exercism-cli]。

要下載一道練習，請這樣做：

```bash
exercism download --track 8th --exercise hello-world
```

然後切換到練習所在的目錄：

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

如果你使用的是 Windows，則是：

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

請注意，你可以用 `exercism configure` 指令取得自己的 exercism 工作區。

## 在本機測試

要執行一道練習的測試，你必須位於正確的練習目錄中。
接著用這個指令啟動測試：

```bash
8th -f test.8th
```

## 跳過的測試

解一道練習，就是讓它所有的測試都通過。
預設情況下，執行測試時只會執行一個測試（第一個）。
這是刻意的，讓你專心先讓那一個測試通過。
等它通過之後，把 `SKIP-REST-OF-TESTS` 那一行移到下一個測試的下方，就能啟用下一個測試。

### 覆寫跳過設定

若要執行所有測試，包括 `SKIP-REST-OF-TESTS` 字樣之後的測試，你可以把環境變數 `RUN_ALL_TESTS` 設為 `true`。
只想在這次執行測試期間設定它的其中一個做法是（macOS 與 Linux）：

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## 提交你的解法

使用 exercism 工具把你的解法上傳到 Exercism 網站：

```bash
exercism submit
```

請注意，就算你的程式碼還沒通過所有測試，一樣可以上傳。
如果你卡住了，需要導師的協助，這麼做很有用。
