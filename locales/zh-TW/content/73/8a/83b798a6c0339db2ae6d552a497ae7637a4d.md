# 簡介

基本上，迴圈分成兩種：

1. 一直迴圈，直到某個條件被滿足。
2. 對集合中的元素逐一迴圈。

兩者在 R 裡都做得到，不過第一種可能更常見。

## `while`與`repeat`

對於不知道會繞幾次的開放式問題，R 提供了帶條件的`while`迴圈，以及不帶條件的`repeat`迴圈（等同於`while (TRUE)`）。

基本形式相當簡單：

```R
while (condition) {
  do_something()
}
```

在這個例子中，程式會一直繞著迴圈跑，直到`condition`不再是`TRUE`為止。

有兩種方式可以提早離開迴圈：

- `break`會讓迴圈結束，執行流程從迴圈結尾大括號`}`之後的下一行繼續。
- `return(x)`會停止目前函式的執行，並把回傳值`x`交還給呼叫者。

有了這些選擇，有時候用`repeat { ... }`建立一個「無限」迴圈會很方便，接著只要在迴圈主體裡找到停止條件，就能觸發`break`或`return`。

下面這三種寫法等價，最後都會得到`x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## 對向量進行疊代

在 R 裡，這通常不是必要的。
正如其他概念中所討論的，許多函式會直接對整個向量運算。

不過，明確的迴圈有時還是無可避免。
尤其是下列情況：

- 迴圈主體帶有副作用，例如列印輸出或檔案 I/O。
- 迴圈要一直執行，直到某個準則被滿足為止，而疊代次數無法預先預測。

迴圈條件必須放在括號裡。
和函式主體一樣，單行的迴圈主體可以省略大括號（但通常還是會寫上）。

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

如果目前的疊代不滿足某個條件，可以用`next`直接跳到下一次疊代：

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

如果需要數值索引，請使用`seq_along()`。

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

使用`i in 1:length(v)`是_不_建議的，因為當`length(v)`為零時可能會出問題。
範圍`1:0`等同於`c(1, 0)`，所以迴圈主體還是會執行，而且很可能出錯。
`seq_along()`函式就是為了正確處理這種情況而設計的。
