# 說明

你在德國慕尼黑的一間大公司擔任系統管理員，其中一項職責就是管理電子郵件帳號。

你一直聽到有人抱怨，說他們沒辦法寄電子郵件給 Müller 先生。你很快發現，公司大多數人使用的一款老舊電子郵件用戶端，因為`müller@firma.de`裡有非 ASCII 字元，所以無法將它辨識為有效的電子郵件地址。

要大家放棄自己慣用的老舊電子郵件用戶端是徒勞無功的，於是你決定為所有電子郵件帳號建立清理過的別名。

## 1. 清理現有使用者名稱，移除所有非小寫字母的字元

實作`sanitize/1`函式。它接受以 charlist 表示的使用者名稱，並回傳移除所有非小寫字母後的使用者名稱。

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. 允許底線

擴充`sanitize/1`函式，讓它不會移除使用者名稱中的底線。

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. 替換德文字元

德文字母中有 4 個非 ASCII 字元，它們都有大家熟知的 ASCII 替代寫法。

| 德文字元 | ASCII 替代字元 |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

擴充`sanitize/1`函式，讓它依照表格替換德文字元。你可以放心假設所有使用者名稱都已經是小寫。

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
