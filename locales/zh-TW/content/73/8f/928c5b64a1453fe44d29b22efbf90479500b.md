# 說明

你的任務是計算一個單字的 Scrabble 分數，也就是把每個字母的值加總起來。

字母的值如下：

| 字母                         | 值    |
| ---------------------------- | ----- |
| A, E, I, O, U, L, N, R, S, T | 1     |
| D, G                         | 2     |
| B, C, M, P                   | 3     |
| F, H, V, W, Y                | 4     |
| K                            | 5     |
| J, X                         | 8     |
| Q, Z                         | 10    |

舉例來說，「cabbage」這個單字值 14 分：

- C 得 3 分
- A 得 1 分
- B 得 3 分
- B 得 3 分
- A 得 1 分
- G 得 2 分
- E 得 1 分
