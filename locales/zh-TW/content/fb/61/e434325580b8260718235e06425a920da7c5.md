# 多餘的條件式

這份解法不必要地使用了[條件式][conditionals]。把[預設引數][default argument]搭配 [str.format][str.format] 或 [f-strings][f-strings]（_也就是俗稱的「格式化字串字面值」或「內插字串」_）一起使用，可以讓程式碼更清楚、更精簡。

想了解更多細節，請參考這篇關於 [python default arguments][python default arguments] 的文章。部落格文章 [string formatting in python][string formatting in python] 也是認識 Python 各種字串格式化選項的好起點。
