# Elm 語法基礎 1

## 常數與函式

Elm 程式由定義和運算式組成。
Elm 裡的每個東西，不是定義就是運算式。

常數值用`name = expression`定義。

```elm
five = 5

six = 3 + 3
```

函式用`name parameters... = expression`定義，參數之間只用空格分隔。

```elm
add number1 number2 = number1 + number2
```

呼叫函式同樣是一種運算式，做法是寫出函式名稱，並為函式的每個參數傳入對應的引數，以空格分隔，就跟定義函式時一樣。

```elm
five = add 2 3
```

括號可以用來指定運算式的求值順序。

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 縮排 / 有意義的空白

Elm 不用大括號、小括號或分號這類語法標記來界定程式碼的範圍，而是用空白和縮排。

- 模組、import 與最上層的函式定義都必須從最左欄開始。
- 如果一個運算式被拆成多行，屬於這個運算式的程式碼必須縮排在這個運算式底下，至少縮排一個空格。
- 運算式裡歸為同一組的部分，應該縮排相同數量的空格。

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## 模組

Elm 裡的每個檔案都是一個模組，而且必須在所有其他程式碼之前先有`module`敘述。
模組名稱必須和檔名一致，所以模組`Calculator`必須放在 Calculator.elm 這個檔案裡。
在模組裡定義的任何東西，作用域都只限於該模組，除非列在`exposing`中，否則無法從這個模組外部存取。

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 註解

註解是 Elm 檔案裡不會被當成程式碼解讀的文字。
它主要是寫給你自己和其他程式設計師看的。
單行註解有一種輕量的語法，以兩個連字號為基礎。
多行註解也可以用`{-`和`-}`這對開始與結束的定界符來寫。

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
