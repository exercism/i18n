# 關於

Swift 中的 `guard` 敘述用於從 Swift 函式提前回傳，也就是當後續處理要繼續下去所需的必要條件沒有滿足時，就提早退出，例如：

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

在這裡，`guard` 會檢查緊接在 `guard` 關鍵字之後的布林運算式是否評估為 true。若是，處理就會繼續執行 guard 敘述之後的程式碼（這裡是 `let root = myValue.squareRoot()`）。否則就會執行 else 子句中的程式碼。與 `if` 敘述不同，`guard` 敘述「必須」有 else 子句；而且和 if-else 的 else 子句不同，guard 的 else 子句「必須」離開 guard 敘述的作用域，也就是說，它必須使用控制轉移敘述，例如 `return`、`continue`、`break`，或是必須拋出錯誤或結束程式。

它的一個使用範例是 sinc 函式，這個函式等於 sin(x)/x，並將 sinc(0) 定義為 1，以避免除以 0 的問題。這個函式可以用 Swift 寫成，並使用 `guard`：

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
