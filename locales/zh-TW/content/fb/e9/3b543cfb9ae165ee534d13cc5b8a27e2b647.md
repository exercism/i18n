# 說明

你突然很想吃鬆餅。
身為一個現代、喜愛科技的人，你用 JSON 格式寫了一份鬆餅材料的購物清單。
清單的結構是：

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

一份材料會用 JSON 物件表示，像這樣：

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

每份材料都有一個名為 `"substitute"` 的選用屬性，裡面是一個字串，代表可以拿來替代的另一項材料。

來看看我們怎麼用 `jq` 檢查這份購物清單吧。

## 1. 取出購物清單的名稱

寫一個運算式，輸出購物清單的 `"name"` 元素。

## 2. 計算需要多少材料

只計算「必要」的材料。不要包含選用的材料。

## 3. 糖要多少？

寫一個運算式，輸出糖的份量。
只要數字的部分。

## 4. 對應可替換的材料

有些材料可以替換（如果你沒有材料 X，可以用 Y 代替）。
輸出一個 JSON 物件，將建議的材料對應到它的替代品。
在對應中包含選用的材料。
