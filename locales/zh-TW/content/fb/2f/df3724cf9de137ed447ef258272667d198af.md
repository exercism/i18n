程式碼庫的公開介面應該審慎規劃，因為每個公開函式都會增加長期維護成本，也讓重構變得更加困難。

在 Exercism 的每個練習中，公開介面都是由測試套件定義的。
如果某個函式有被測試，它就必須是公開的。
其他所有函式都應該是私有的，包括同名但參數個數不同的函式。

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
請注意，預設引數會改變函式的參數個數。

撰寫程式庫時，常常需要把函式設為公開，讓其他模組可以使用。
若不想讓這類函式出現在文件中，程式庫作者會在函式定義前加上 `@doc false`，或加上 `@moduledoc false` 來隱藏整個模組。
