# 關於

篩選是從另一個序列建立新序列的過程，做法是複製原始序列中除了特定元素以外的所有元素。
至於要把哪些項目放進新序列，可以交由述詞函式（會求值為布林值的函式）決定，也可以透過與特定物件是否相等來決定。

## 用述詞移除

`remove-if` 是一個函式，接受一個述詞函式和一個序列作為引數，並回傳只包含述詞求值為 false 的那些元素的序列。
換句話說，它會「移除」序列中所有讓述詞求值為 true 的元素。不過請注意，這個函式不會修改原始序列！
它會回傳一個少了這些元素的新序列。如果述詞對所有值都為 true，則會回傳一個空序列。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 用述詞保留元素

有一個函式 `remove-if-not`，它和 `remove-if` 很像，差別在於它會*保留*述詞求值為 true 的元素。

另一個做法是使用 `complement`，把述詞轉換成它的「相反」。

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## 移除特定項目

如果想從序列中移除某個特定項目，可以使用 `remove`，它接受要移除的項目和一個序列。
序列中所有不等於要移除的項目的值都會被回傳。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

用來判斷相等的函式可以透過`:test`[關鍵字參數][concept-keyword-parameters]來指定。

請注意，`remove` 也可以用 `remove-if` 來實作，只要寫一個測試某個物件是否等於特定項目的述詞即可。

## 許多選項

這些函式也都接受許多其他的[關鍵字參數][concept-keyword-parameters]，讓它們能只作用於子序列、只套用特定次數等等。完整細節請參閱 [Hyperspec 文件][hyperspec-remove]。


## 破壞性選項

除了 `remove`、`remove-if` 和 `remove-if-not` 之外，還有 `delete`、`delete-if` 和 `delete-if-not`，它們的效果相同，差別在於它們可能會修改傳入的序列。
