# 簡介

就像指標可以指向`int`或其他基本資料型態一樣，指標也可以指向函式。
函式指標可以用來把函式傳給另一個函式。
以參數值的形式傳給另一個函式的函式，稱為一級函式。
接受一個或多個函式作為參數，或是回傳函式的函式，則稱為高階函式。

在下面的範例中，`is_even`和`is_odd`是一級函式。
高階函式則是`test_number`。

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
`test_number`第一個引數的函式簽章`bool (*func) (int)`，和傳入的函式簽章相符。
`is_even`和`is_odd`都接受一個`int`參數，並回傳`bool`。
在`(*func)`中，`func`代表要使用的函式名稱。
如果改用`(*fn)`，那麼呼叫的方式就會變成：`printf(text, number, fn(number)? "true": "false");`。
為了符合函式指標參數的要求，我們在呼叫`test_number`時，會傳入一個具有預期簽章的函式名稱。
因此，我們可以看出，函式名稱會指向那個具名函式的位址。
