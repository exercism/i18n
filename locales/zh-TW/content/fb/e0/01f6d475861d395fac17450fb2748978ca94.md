# 簡介

在 Swift 中，你不能用整數對字串取索引（例如 `string[3]`）。
因為 Swift 的字串是由長度不固定的 Unicode 字元組成，想找到某個字元，就得逐一走過它前面的字元。

若要取得特定位置的字元，你必須先計算出一個型別為 `String.Index` 的索引。
這種索引稱為「不透明索引」，因為它們的內部結構是由 Swift 管理，而不是讓你當成原始整數直接操作：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
