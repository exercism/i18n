# 關於

Kotlin 由 JetBrains 設計與開發，也就是打造 IntelliJ 的公司。
它是一種執行在 JVM 上的語言，可支援 6 以上的版本（包括 [Android 平台](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)）。
JetBrains 想採用一種靜態型別的語言，既能去除 Java 的樣板程式碼、提供現代化的函式範式，還能與他們既有的程式碼庫無縫地雙向互通 Java。
JVM 上早有 Groovy 和 Scala 等替代語言，但兩者都不符合他們期望的條件，於是他們打造了 Kotlin。

Kotlin 的語法類似 Scala 和 Swift，但同時汲取了 C#、Groovy 等其他語言的頂尖特色。
Kotlin 在語言功能的取捨上採取務實的做法，只提供已證實對開發者有用的功能。
基於這個決定，他們只實作了 Scala 的一部分功能，希望藉此讓程式碼更容易維護，也讓想找「更好的 Java」的開發者能更輕鬆地上手。

JetBrains 有一支專門的開發團隊投入 Kotlin，其程式碼庫可在 [Github](https://github.com/JetBrains/kotlin) 上取得。
