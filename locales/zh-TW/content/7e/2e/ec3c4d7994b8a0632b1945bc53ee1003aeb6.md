# For-Each 迴圈簡介

[for-each 迴圈](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)提供了一種機制，能為集合中的每個元素執行一段程式區塊。
有些文件（例如 Oracle 的文件）會把這類迴圈稱為增強的 for 迴圈。

一般語法如下：

```java
for(declaration: collection) {
    body;
}
```

`declaration`會宣告一個變數，用來保存從集合指派過來的值。

`collection`是陣列或集合，存放將被指派給迴圈變數的值。

`body`包含的敘述會對集合中的每個值執行一次。

例如：

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

輸出結果為：

```text
a
e
i
o
u
```

一般而言，`for-each`迴圈比`for`迴圈更適合，原因如下：

- `for-each`迴圈保證會疊代過_所有_值。
- `for-each`迴圈更具_宣告式_風格，意思是程式碼傳達的是它_做了什麼_，而不是_如何_做到。
- `for-each`迴圈不易出錯，而使用`for`迴圈時則很容易發生差一錯誤（想想使用`<`以及`<=`的差別）。
- `for-each`迴圈適用於所有集合型別，包括那些不支援以索引存取元素的集合（例如`Set`）。
