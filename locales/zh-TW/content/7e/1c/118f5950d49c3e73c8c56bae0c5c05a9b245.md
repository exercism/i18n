# 指示

在這道練習中，你會處理日誌行。

每行日誌都是格式化為 `"[<LEVEL>]: <MESSAGE>"` 的字串。

日誌層級有三種：`INFO`、`WARNING` 和 `ERROR`。

你有三個任務。每個任務會從堆疊取出一行日誌。

## 1. 從日誌行取得訊息

定義`message`，回傳日誌行裡的訊息。開頭和結尾的空白都應該移除。

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. 從日誌行取得日誌層級

定義`log-level`，回傳日誌行的層級，並轉成小寫。

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. 重新格式化日誌行

定義`reformat`，把訊息放在最前面，並在後面用括號加上小寫的日誌層級。

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***注意：*** 這道練習裡的所有字串都是 ASCII。之後的練習則會處理支援 Unicode 的字串處理。
