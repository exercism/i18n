# 說明

準魔術師 Elyse 要繼續她的訓練了。她會拿到好幾疊牌，用來表演她的魔術。
為了讓事情簡單一點，她只用 1 到 10 的牌。

在這道練習裡，請使用內建方法來分析向量裡的內容。

## 1. 判斷某張牌是否存在

Elyse 想知道某張牌是否在牌堆裡，也就是說，牌堆裡是否包含某個特定的數字。

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. 找出某張牌的位置

Elyse 想知道某張牌在牌堆裡的位置（索引）。
如果這張牌不在牌堆裡，就回傳 `-1`。

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. 判斷每張牌是否都是偶數

Elyse 想知道每張牌是否都是偶數，也就是說，牌堆裡的每個數字是否都是偶數。

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. 檢查牌堆裡是否有奇數值的牌

Elyse 想知道牌堆裡是否有奇數。

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. 取得牌堆裡的第一張奇數牌

Elyse 想知道第一張奇數牌的值。  
如果牌堆裡沒有奇數牌，就回傳 `-1`。

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. 判斷第一張偶數牌的位置

Elyse 想知道第一張偶數牌的位置。
如果牌堆裡沒有偶數牌，就回傳 `-1`。

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
