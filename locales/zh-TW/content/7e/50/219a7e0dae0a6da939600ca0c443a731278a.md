# 說明

你是個熱衷的賞鳥者，會記錄過去 7 天內有多少鳥造訪你的花園。

你有 6 個任務，全都和造訪你花園的鳥的數量有關。

## 1. 檢查今天有多少鳥造訪

實作`today()`函式，回傳今天有多少鳥造訪你的花園。鳥的數量依日期排序，第一個元素是最早那天的數量，最後一個元素則是今天的數量。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. 增加今天的數量

實作`increment_todays_count()`函式，把今天的數量加一：

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. 檢查是否有沒有任何鳥造訪的一天

實作`has_day_without_birds()`函式，如果有一天沒有任何鳥造訪花園，就回傳`TRUE`；否則回傳`FALSE`：

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. 計算前幾天造訪的鳥的數量

實作`count_for_first_days()`函式，回傳從本週第一天起造訪你花園的鳥的數量，但只計算從本週第一天起算的指定天數。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. 計算忙碌的日子有幾天

有些日子比其他日子更忙碌。只要一天有 5 隻以上的鳥造訪你的花園，就算是忙碌的一天。
實作`busy_days()`函式，回傳忙碌的日子有幾天：

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. 計算過去一週鳥造訪次數的累計總和

你很好奇這週到目前為止總共有多少鳥造訪。
請計算每一天的累計總和。

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. 依忙碌程度排序星期名稱

你懷疑鳥的造訪受到附近道路交通型態的影響，所以週末和平日有所不同。

請依造訪鳥數的_遞減_順序，排序這些星期的縮寫。

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
