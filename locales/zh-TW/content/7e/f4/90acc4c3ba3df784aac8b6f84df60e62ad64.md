# 關於

GDScript 是一種漸進式型別的物件導向指令式腳本語言，專為 [Godot Engine][godot-engine] 所打造（而且通常也只搭配它使用）。Godot Engine 是一款開源的 2D 與 3D 遊戲引擎兼 IDE。因此，GDScript 針對 Godot 以場景為基礎的架構做了大量最佳化，並原生支援像是這類的資料型態。

由於 GDScript 與許多熱門語言有不少相似之處（舉例來說，它的語法和 Python 很像），學習 GDScript 可以是通往 Godot 遊戲開發，以及學習其他程式語言的有趣入口。如果你已經對 Godot 感興趣，卻不確定該學它支援的哪一種語言，也許會想讀讀[什麼是 GDScript，我為什麼該用它？][why-use-gdscript]。

如果你好奇 Godot 為什麼要打造自己的語言，不妨進一步閱讀[當初打造 GDScript 的動機是什麼？][why-create-gdscript]喔。
