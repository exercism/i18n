# 指令

你是一名碼頭裝卸工，正在碼頭上重新堆放貨箱。每一項任務都只要定義一個詞，而且詞的內容只會用到搬移堆疊的詞，不會用到算術。

## 1. 交換最上面的兩個貨箱

定義`swap-crates`這個詞。它會從堆疊取下兩個貨箱，然後以相反的順序把它們放回去。

```factor
1 2 swap-crates .s
! 2
! 1
```

## 2. 清掉打翻的貨箱

定義`clear-spill`這個詞。它會從堆疊取下三個貨箱，留下底下兩個，丟掉最上面那個。

```factor
1 2 3 clear-spill .s
! 1
! 2
```

## 3. 保留下面那個貨箱的副本

定義`peek-under`這個詞。它會從堆疊取下兩個貨箱，把它們放回去，並在最上面放一份下面那個貨箱的副本。

```factor
1 2 peek-under .s
! 1
! 2
! 1
```

## 4. 整理甲板

定義`tidy-deck`這個詞。它會從堆疊取下三個貨箱（順序為`x y z`），然後留下`z z y`：丟掉最底下的貨箱，接著把最上面那個貨箱的兩份留在中間那個貨箱上方。

```factor
1 2 3 tidy-deck .s
! 3
! 3
! 2
```
