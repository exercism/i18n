# 簡介

Ruby 附帶一個標準函式庫（常簡稱為「stdlib」），這是一組類別，用來處理日期、json 和網路等事物。
它也提供一些實用功能，讓你的程式碼更容易處理。

`OpenStruct`是標準函式庫的一部分，讓你能輕鬆從`Hash`建立物件。
`OpenStruct`不用透過`Hash`鍵來存取，而是讓我們用方法來存取和設定值。

當你使用標準函式庫或其他函式庫中的類別時，需要用`require`方法來載入該類別。

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

這還有一個額外好處：使用區塊語法時，你可以利用一個捷徑。
當區塊只呼叫單一方法時，你可以用`&:`後面接著方法名稱來取代區塊。
例如，下面這兩行是等價的：

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
