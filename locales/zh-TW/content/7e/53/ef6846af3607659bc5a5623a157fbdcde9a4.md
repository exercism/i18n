# 三元運算子

三元條件式是撰寫簡單`if/else`敘述的簡短方式。
如果`if/else`敘述只包含兩個分支，一個用於條件為 true 時，另一個用於條件為 false 時，就可以改寫成三元條件式。

三元運算子結合`?`和`:`兩個符號來拆分條件式：
```ruby
condition ? true_branch : false_branch
```

`?`左邊的程式碼是條件，右邊的程式碼則包含兩個可能的分支，並以`:`分隔。
如果條件為 _true_，就會執行`:`_左_邊的程式碼。
如果條件為 _false_，則會執行`:`_右_邊的程式碼。

例如：

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

可以改寫成：

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
