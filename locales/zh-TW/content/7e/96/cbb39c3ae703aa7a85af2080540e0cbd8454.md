# 簡介

## 陣列與 vector

C++ 提供了不同的容器，讓你能以有序的方式儲存同一型別的元素。
`std::array` 用於固定大小的容器，而 `std::vector` 則具備動態調整大小的能力。

### 建構

當你宣告一個陣列或 vector 時，需要指定該容器所容納元素的型別。
陣列還需要指定大小。
看看以下範例，了解這兩種容器型別的初始化方式：

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Vector 通常需要更多空間，因為它會配置記憶體以因應後續的成長。
你不需要指定大小：

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> 注意：你現在還不需要了解模板概念背後的確切機制，在課程大綱的樹狀結構中，之後會有專屬的概念單元來介紹它。

### 存取元素

Vector 和陣列存取元素的方式相同，用的是同一組函式。
你可以用成員函式 `front` 和 `back` 取得容器的第一個與最後一個元素。
另外還有 `at` 和 `[]` 運算子可以存取特定的元素。

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> 注意：如果你選的位置不在容器的範圍內，`[]` 可能會導致未定義行為。
> `at` 函式則會發出例外，長遠來看，這或許能讓你的日子好過一些。

### Vector 的修改方法

由於 `vector` 的大小並非固定，因此可以新增或移除元素。
常用來做這件事的兩個函式是 `emplace_back` 和 `pop_back`。

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### 容量

你可以用成員函式 `empty` 檢查容器是否為空。
如果你想知道元素的數量，可以使用 `size`。
