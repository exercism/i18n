# 說明

在這個練習中，你需要實作一些函式來操作一個程式語言的陣列。

## 1. 定義一個回傳空語言陣列的函式

定義`new`函式，它不接受任何引數，並回傳一個空的陣列。

```haskell
new
-- -> []
```

## 2. 定義一個將語言新增到陣列的函式

定義`add/2`函式，它接受 2 個引數（一個_語言陣列_和一個_語言_的字串字面值）。
它應該回傳將新語言加到給定陣列最前面的結果陣列。

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. 定義一個從陣列移除語言的函式

定義`remove`函式，它接受 1 個引數（一個_語言陣列_）。
它應該回傳移除第一個項目後的陣列。假設陣列永遠至少有一個項目。

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. 定義一個回傳陣列中第一個項目的函式

定義`first`函式，它接受 1 個引數（一個_語言陣列_）。
它應該回傳陣列中的第一個語言。
假設陣列永遠至少有一個項目。

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. 定義一個回傳陣列中有多少語言的函式

定義`count`函式，它接受 1 個引數（一個_語言陣列_）。
它應該回傳陣列中的語言數量。

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. 定義一個判斷陣列是否包含函式語言的函式

定義`isFunctionalList`函式，它接受 1 個引數（一個_語言陣列_）。
它應該回傳一個布林值。
如果_"Haskell"_是陣列中的語言之一，它應該回傳`True`。

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
