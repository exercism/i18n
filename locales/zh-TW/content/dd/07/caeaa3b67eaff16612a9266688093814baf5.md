# 關於

## 簡介

泛型是一種能讓程式碼重複使用的語言功能。
舉例來說，要計算一個陣列的長度，不應該在意它裝的是什麼型別。
這就是為什麼`length`函式在其型別簽章中使用了泛型型別參數`a`。

```elm
length : List a -> Int
```

## 型別中的參數

當一個型別可以泛型於另一個型別時，我們會用一個小寫名稱來表示那個型別，並稱它為型別參數。
常見的例子是`List`、`Maybe`和`Result`這幾個自訂型別。

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

關於型別參數的名稱，有一點很重要：它們的長度可以超過一個字元。
唯一的限制是它們必須是小寫名稱。
因此，在有用的時候，我們通常會給它們取描述性的名稱。

一個型別可以泛型於多個其他型別，因而擁有多個型別參數。
在這種情況下，每個互相獨立的型別會各自得到不同的小寫名稱。
獨立並不代表它們不能變成相同的型別，只是讓它們得以有所不同。

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

記錄型別別名也可以有型別參數，雖然這比較少見。

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

> 這就是為什麼`Html`套件定義了`Html msg`型別，其中有一個名為`msg`的型別參數。
> Elm 架構會引導你建立一個自訂型別`Msg`，用來描述你的網頁能觸發的所有訊息。
> 因此，你的程式碼會建構出型別為`Html Msg`的檢視，其中`Msg`就是你定義的具體型別。
> 初學者有時會搞混提到`Html msg`（小寫）的錯誤，以及提到`Html Msg`的錯誤。
> 現在你知道了！
> 差別在於，前者的泛型適用於任何`msg`型別，而後者則專屬於你的`Msg`型別。

## 函式中的型別參數

既然型別可以泛型，函式也可以。
我們可以撰寫處理泛型型別的函式，例如`Maybe.withDefault`。

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

把其他函式當作參數接收的函式稱為高階函式，而它們也可以是泛型的。

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

型別參數可以同時出現在函式的輸入和輸出中，而由型別參數所帶來的泛型能力通常稱為**參數化多型**。
這與特設多型形成對比，特設多型也稱為函式重載，同一個函式名稱可以用在多個型別不同的實作上。
這也與子型別多型形成對比，在子型別多型中，型別可以定義在一個階層結構裡，定義在某個型別上的函式也可以用其子型別的引數來呼叫。
在 Elm 中，唯一可用的泛型機制就是參數化多型。
