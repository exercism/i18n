# 資源

以下是一些實用資源，能幫助你更深入了解 SQLite，並精進你的技能：

- [SQLite 官方文件][sqlite-docs]提供完整的指南、教學與參考資料。

- [SQLite 命令列 Shell][sqlite-shell]：SQLite 命令列 Shell 的說明文件，讓你能用 SQL 指令與 SQLite 資料庫互動。

- [SQLite 常見問題][sqlite-faq]：關於 SQLite 的常見問題，涵蓋從安裝到疑難排解的各種主題。

- [SQLite 論壇][sqlite-forum]：SQLite 論壇適合提問、回報 bug、提出改進建議、尋求指導，以及討論與 SQLite 相關的軟體。

- [SQLite Browser][sqlite-browser]：一套視覺化工具，用來建立、設計及管理 SQLite 資料庫，讓你瀏覽並編輯 SQLite 資料庫檔案。

深入探索這些資源，加深你對 SQLite 的理解，並讓你更熟練地運用這套強大的資料庫管理系統吧！

[sqlite-docs]: https://www.sqlite.org/docs.html
[sqlite-shell]: https://www.sqlite.org/cli.html
[sqlite-faq]: https://www.sqlite.org/faq.html
[sqlite-forum]: https://sqlite.org/forum/forum
[sqlite-browser]: https://sqlitebrowser.org/
