# 說明

學校的失物招領處把所有東西都收在箱子裡，而放進箱子的可能是任何東西：一件毛衣、一些數字、一個名字。

請撰寫一個 `LOST_BOX{T}` 類別。程式骨架已經提供了類別標頭。

## 1. 收下物品

`create`會接收物品和送交者的名字，並回傳一個箱子。箱子一開始是未認領的狀態。

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. 認領它

`claim`會把箱子標記為已認領，不回傳任何東西。

```sather
box.claim;
box.claimed
-- => true
```

## 3. 它還在等待嗎？

`waiting`會回傳箱子是否尚未被認領。

```sather
box.waiting
-- => false
```

## 4. 交換內容物

`replace`會接收一個新的物品，把它放進箱子，並回傳原本在裡面的東西。放進去的物品和拿出來的物品都是`T`。

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. 寫成描述

`describe`會回傳一句描述箱子的話，例如`"blue jumper, handed in by Mia"`。

要把物品放進字串裡，類別必須知道`T`可以轉換成字串。請為參數加上限制：把類別標頭寫成`class LOST_BOX{T < $STR}`，這樣就能使用`item.str`。

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
