# 簡介

Go 內建了一些基本數值型別，可以表示整數或浮點數的集合。

這個概念會聚焦在兩種數字型別：

- `int`：例如 `0`、`255`、`2147483647`。
   一種帶正負號的整數，大小至少為 32 位元（值域：-2147483648 到 2147483647）。
   但這取決於系統架構。
   大多數現代電腦都是 64 位元，因此`int`的大小會是 64 位元（值域：-9223372036854775808 到 9223372036854775807）。

- `float64`：例如 `0.0`、`3.14`。
   包含所有 64 位元浮點數的集合。

Go 支援標準的算術運算子：`+`、`-`、`*`、`/` 和 `%`（取餘數，而非取模）。

在 Go 中，在不同型別之間賦值需要明確轉換。
例如，要把`int`轉換成`float64`，你需要這樣做：

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
