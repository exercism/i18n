# 指令

重構一個 Markdown 解析器。

markdown 練習是一項重構練習。
有一段程式碼會解析帶有 [Markdown 語法][markdown] 的字串，並回傳該字串對應的 HTML。
雖然這段程式碼寫得令人困惑、難以理解，但它不知怎麼地就是能運作，而且所有測試都通過了！
你的挑戰是重寫這段程式碼，讓它更容易閱讀和維護，同時確保所有測試仍然通過。

如果你在註解中記下自己重構時做了什麼，讓審閱者能看到，會很有幫助，但這並非絕對必要。
最重要的是讓程式碼變得更好喔！

[markdown]: https://guides.github.com/features/mastering-markdown/
