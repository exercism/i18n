# 說明

當地的詩社正要展開新的季度。詩人加入詩社後，只要其中兩位共同寫下一首詩，他們就屬於同一個*寫作圈*。詩社想記錄誰和誰共享同一個寫作圈，於是請你寫出管理這套關係的函式。

並查集正好適合這個任務：每位詩人是一個原子，而每個寫作圈是一個群組。

## 1. 開啟詩社

定義 `new-club`，接受一個詩人序列，回傳一個全新的並查集，其中每位詩人都已登記。每位詩人一開始都待在自己的寫作圈裡。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. 記錄一次合作

定義 `collaborate`，接受兩位詩人和一個詩社。它會合併這兩位詩人的寫作圈，並回傳該詩社，這樣就能接連記錄多筆合作。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. 找出詩人的寫作圈

定義 `circle-of`，接受一位詩人和一個詩社，回傳該詩人寫作圈的代表。共享同一個寫作圈的兩位詩人，永遠會回報相同的代表。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. 共享同一個寫作圈？

定義 `same-circle?`，接受兩位詩人和一個詩社，當兩位詩人屬於同一個寫作圈時回傳 `t`，否則回傳 `f`。請比較兩位詩人的代表，而不是使用內建的等價性測試。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
