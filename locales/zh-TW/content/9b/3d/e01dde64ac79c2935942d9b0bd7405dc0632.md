# 補充說明

## 提示

要完成這道練習，你需要實作`wordCount`這個函式，它會接收一段*文字*，並回傳每個*單字*出現的次數。

如果這是你第一次解這道練習，建議先沿用題目提供的函式簽章：

```haskell
wordCount :: String -> [(String, Int)]
```

之後，不妨回過頭重新看看這個問題，玩玩其他的資料型態和函式庫：

- `Text`，來自 *text* 套件。
- `Map`，來自 *containers* 套件。
- `MultiSet`，來自 *multiset* 套件

測試套件刻意設計成能接受幾乎任何合理的型別簽章，所以歡迎你找出自己認為最好的那一種。
