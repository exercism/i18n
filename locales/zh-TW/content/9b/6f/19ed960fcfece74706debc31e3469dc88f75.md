# 關於

在 PHP 中，只要在變數後面加上括號 [`()`]，就能把變數當成函式來呼叫。當 PHP 嘗試呼叫這個函式時，會尋找名稱和該變數的值相同的函式。

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## 呼叫靜態類別函式

靜態類別函式也可以用同樣的方式呼叫：

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## 呼叫類別實例的函式

要呼叫某個類別實例的函式也沒問題：

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
