## MacOS

首先使用 [Homebrew][1] 安裝 Lua 和 [Luarocks][2]：

```shell
$ brew install lua luarocks
```

接著安裝 Lua 的 [Busted][3] 測試框架：

```shell
$ luarocks install --local busted
```

將`~/.luarocks/bin`加入系統的`$PATH`

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

請注意，這只是暫時的。
若要將它永久加入你的`$PATH`，就必須視你使用的 shell，把它加到`.bashrc`、`.zshrc`或`config.fish`。

接著執行你的測試：

```shell
$ busted
```

## Ubuntu

首先使用 [Apt][6] 安裝 Lua 和 [Luarocks][2]：

```shell
$ sudo apt-get install lua5.4 liblua5.4-dev luarocks
```

接著安裝 Lua 的 [Busted][3] 測試框架：

$ luarocks install --local busted

## Windows 10: WSL

首先，你必須以 [PowerShell][8]（系統管理員）啟用 [WSL（適用於 Linux 的 Windows 子系統）][7]：

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

這需要重新開機。

接著，從 [Microsoft Store][9] 安裝 Ubuntu，**或**使用 PowerShell 下載後再安裝：

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

然後更新你的套件清單：

```shell
PS> wsl
$ sudo apt-get update
```

現在你可以依照上面的[Ubuntu 操作說明](#ubuntu)安裝 [LuaRocks][2] 和 [Busted][3]。

完成後，你就可以直接從任何 Windows 命令列執行測試：

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### 安裝 Gitbash

這個步驟是選用的。如果你想改用 Windows 原生的 CLI 或其他 CLI，可能得稍微調整以下的步驟。

在[這裡][10]下載。
安裝說明在[這裡][11]。

### 安裝 Docker

依照指示安裝 [Docker for Windows][12]。
安裝完成後，你可以執行下列指令，確認是否安裝正確。

```shell
$ docker --version
```

_第一次執行 Docker 時，你可能會遇到錯誤。_

`cannot enable hyper-v service`

_如果發生這種情況，你可以依照這些說明來[啟用 Hyper V][13]。你可能需要先停用該設定、重新啟動電腦，並在開機後重新啟用它。_

### 安裝 busted

安裝好 Gitbash 和 Docker 之後，你就可以安裝 busted 的「容器」。

在 Gitbash 中執行以下指令：

執行以下指令，下載這個廣為使用的 Docker 容器：

```shell
$ docker pull imega/busted
```

建立一個函式，這樣你就不必每次都輸入完整的指令。
把下面這行加入你的`.bashrc`：

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

現在，你可以在 CLI 中切換到想要執行測試的目錄，然後執行以下指令：

```shell
$ dbusted $PWD
```

你應該會看到 busted 測試的輸出。
