# 簡介

C# 型別可以定義在類別或 struct 的作用域內。外層型別提供了一種命名空間。存取型別時，要透過外層型別並使用點號語法。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

你可以為內部型別設定存取層級。

外層型別的私有成員對內部型別的成員來說在作用域內，但反過來則不然。
