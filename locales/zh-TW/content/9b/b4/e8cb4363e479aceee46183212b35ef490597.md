# 關於

## 算術運算子

JavaScript 提供了 6 種不同的運算子，用來對數字進行基本的算術運算。

- `+`：加法運算子用來計算數字的和。

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`：減法運算子用來計算兩個數字的差。

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`：乘法運算子用來計算兩個數字的乘積。

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`：除法運算子用來將兩個數字相除。
  由於 JavaScript 的數字一律是浮點數，因此沒有整數除法。

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`：餘數運算子用來計算相除後的餘數。

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`：指數運算子用來求一個數字的次方。
  它等同於使用 [`Math.pow()`][mdn-math-pow]。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## 運算優先順序

在同一行裡使用多個運算子時，JavaScript 會依照[這張優先順序表][mdn-operator-precedence]所列的規則決定先後順序。
用我們這裡的情境簡單來說，JavaScript 採用的是小學數學課學過的 PEDMAS 規則（括號、指數、除法/乘法、加法/減法）。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## 簡寫指定運算子

簡寫指定運算子能用更精簡的方式，寫出對變數進行算術運算、並把新的值指定給同一個變數的程式碼。
舉例來說，假設有兩個變數`x`和`y`。
那麼`x += y`就等同於`x = x + y`。
通常，這裡會用數字取代變數`y`。
其他 5 種運算也可以用類似的方式進行。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
