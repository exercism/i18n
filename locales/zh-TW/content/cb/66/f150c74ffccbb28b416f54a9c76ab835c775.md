# 說明

在這個練習中，你將建立一些常數，用於銀行的營運。

你有五個任務：

## 1. 表示貸款的固定利率

建立無型別的數值常數`FixedInterestRate`來存放 5%（5/100），然後實作`GetFixedInterestRate`函式回傳它：

```go
GetFixedInterestRate()
// => 0.05
```

## 2. 表示一年中的天數

建立型別為`int`的常數`DaysPerYear`來存放 365，然後實作`GetDaysPerYear`函式回傳它：

```go
GetDaysPerYear()
// => 365
```

## 3. 表示一年中的月份

在一個區塊中，使用 Go 的列舉器建立十二個無型別的數值常數，存放一年中各個月份的值 1 到 12。
將它們命名為`Jan`、`Feb`、`Mar`等，然後實作`GetMonth`函式回傳指定月份的值：

```go
GetMonth(Jan)
// => 1
```

## 4. 表示帳號

建立無型別的字串常數`AccountNo`來存放值 XF348IJ，然後實作`GetAccountNumber`函式回傳它：

```go
GetAccountNumber()
// => "XF348IJ"
```
