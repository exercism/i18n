# 說明

在這道練習裡，你會玩到一台遙控車，這是你終於存夠錢買下的。

車子一開始的電池是滿的（100%）。每次你用遙控器開動車子，它就會前進 20 公尺，並消耗 1% 的電池電量。

這台遙控車有個酷炫的 LED 顯示器，會顯示兩項資訊：

- 總共行駛的距離，顯示為：`"Driven <METERS> meters"`。
- 剩餘的電池電量，顯示為：`"Battery at <PERCENTAGE>%"`。

如果電池電量是 0%，你就不能再開這台車了，電池顯示器會顯示 `"Battery empty"`。

你有六個任務，每個任務都會用到遙控車的實例。

## 1. 買一台全新的遙控車

實作（_static_）`JedliksToyCar.buy()` 方法，回傳一台全新的遙控車實例：

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. 顯示行駛的距離

實作 `JedliksToyCar.distanceDisplay()` 方法，回傳 LED 顯示器上顯示的距離：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. 顯示電池百分比

實作 `JedliksToyCar.batteryDisplay()` 方法，回傳 LED 顯示器上顯示的電池百分比：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. 開車時更新行駛的公尺數

實作 `JedliksToyCar.drive()` 方法，更新行駛的公尺數：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. 開車時更新電池百分比

更新 `JedliksToyCar.drive()` 方法，讓它一併更新電池百分比：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. 電池耗盡時阻止繼續行駛

更新 `JedliksToyCar.drive()` 方法，讓它在電池耗盡（0%）時不會增加行駛的距離，也不會減少電池百分比：

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
