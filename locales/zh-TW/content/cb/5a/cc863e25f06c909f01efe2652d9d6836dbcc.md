# 說明

身為一位西洋棋愛好者，你想寫出屬於自己的遊戲版本。
沒錯，網路上或許已經有很多現成的西洋棋實作了，但你的版本會是獨一無二的！

你會先從實作一個棋盤開始。

這款西洋棋遊戲會在一個寬 8 格、長 8 格的棋盤上進行。
每個格子由一個字母和一個數字來標示。

## 1. 定義橫列與直行的範圍

遊戲需要儲存棋盤的橫列。
橫列是棋盤的橫排，編號從 1 到 8。

遊戲也需要儲存棋盤上的直行。
直行是棋盤的直排，由字母 A 到 H 來標示。

定義`ranks`和`files`這兩個常數，分別儲存橫列和直行的範圍。

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. 檢查格子是否有效

遊戲需要檢查某個格子是否有效。
如果橫列和直行都落在橫列與直行的範圍內，這個格子就是有效的。

定義`isValidSquare(rank:file:)`方法，它接受引數`rank`和`file`，其中`rank`存放代表橫列的`Int`，而`file`存放代表直行的`String`。
如果橫列和直行都在橫列與直行的範圍內，這個方法應該回傳`true`，否則回傳`false`。

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. 取得橫列

遊戲會把棋盤上所有的格子存放在一個一維陣列中。
格子是由橫列和直行組成的字串，例如"1A"、"8B"、"4G"等等。
要取得某個格子所在的橫列，遊戲需要計算該橫列第一個格子的索引。

定義`getRow(rank:)`方法，它接受引數`rank`，其中存放代表橫列的`Int`。
這個方法應該回傳一個字串陣列，代表該橫列上的各個格子。

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
