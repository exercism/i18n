# 說明

你是一位熱衷的賞鳥者，會記錄有多少鳥類造訪你的花園。
通常你會在筆記本上以記數的方式計算鳥類數量，但為了更方便處理資料，你已經將過去幾週的鳥類數量數位化。

## 1. 算出你目前為止總共數到的鳥類數量

我們先從整體的角度來分析資料。
找出你開始記錄以來總共數到了多少鳥類。

實作一個函式`TotalBirdCount`，它接受一個包含每日鳥類數量的`int`切片。
它應該回傳你總共數到的鳥類數量。

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. 計算特定某一週來訪鳥類的數量

現在你對鳥類數量數據有了大致了解，你想要做更精細的分析。

實作一個函式`BirdsInWeek`，它接受一個每日鳥類數量的切片和一個週數。

它會回傳你在該特定一週內總共數到的鳥類數量。
你可以假設每一週的記錄都是完整的。

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. 修正計數錯誤

你發現，一直以來當你試著記錄鳥類時，有一隻鳥躲在花園遠處的角落。

你推斷出這隻鳥每隔一天都會待在你的花園裡。

你不知道牠在那些日子之間確切在哪裡，但可以肯定不在你的花園裡。

你的賞鳥者直覺也告訴你，這隻鳥在你清單中記錄的第一天就在你的花園裡。

根據這項新資訊，撰寫一個函式`FixBirdCountLog`，它接受一個每日鳥類數量的切片作為引數，並在修正計數錯誤後回傳該切片。

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
