# 指令補充

## 暫存器

| 暫存器 | 用途 | 型態 | 說明 |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | 輸入        | 位址 | 存放水桶容量的字組陣列              |
| `$a1`    | 輸入        | 整數 | 起始水桶（1 或 2）                          |
| `$a2`    | 輸入        | 整數 | 目標容量                                  |
| `$a3`    | 輸入/輸出 | 位址 | 存放最終水桶內容的字組陣列          |
| `$v0`    | 輸出       | 整數 | 所需動作數，若無法達成則為 -1 |
| `$t0-9`  | 暫時    | 任意     | 用於暫存                     |
