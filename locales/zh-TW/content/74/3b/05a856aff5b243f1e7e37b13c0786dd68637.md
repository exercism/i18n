# 執行緒

## Tcl 專用的執行緒資訊

你將用執行緒來實現平行處理：把輸入切分成數個區塊，讓在執行緒中執行的程式碼能以非同步的方式逐一檢查。

關於 Tcl 執行緒的一些閱讀素材：

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf)，
  摘自 _Practical Programming in Tcl and Tk, 4th Ed._ 的其中一章，
版權所有 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * 注意，這一章提到「大多數的 Tcl 二進位發行版都沒有啟用執行緒支援」。現在已經不是這樣了：Tcl 發行版在建置時都已經支援執行緒（參考 [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md)）
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) 出自 Tcl 文件。
