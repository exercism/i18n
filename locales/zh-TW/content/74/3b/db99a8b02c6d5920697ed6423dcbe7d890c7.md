# PaySwitch - 薪資轉換器

## 問題陳述

一家名為**Insure Everyone**的公司以多種外幣支付員工薪資。但基於法規要求，薪資必須換算成當地貨幣。這家公司的員工遍布世界各地。
Insure Everyone 的人資部門正在尋找一位優秀的開發者，協助打造一支程式，把每位員工的薪資換算成他們對應的當地貨幣。Insure Everyone 依賴外部 API 提供的匯率。

有了這個外部匯率 API，你需要寫一個函式，接收`source currency`、`salary`（以來源貨幣計價）以及員工的`local currency`，並回傳換算成當地貨幣的薪資。

## 限制

* 500 <= `salary` <= 10000
* `sourceCurrency` 和 `targetCurrency` 是 [ISO 貨幣代碼（字母）](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)。測試輸入可能包含無效的貨幣代碼。
* 回傳匯率的準確度會計算到小數點後`5`位。

## 範例

### 範例 1

#### 輸入：
* 薪資：1000
* 來源貨幣：USD
* 目標貨幣：GBP

#### 輸出：

假設外部貨幣匯率服務回傳了以下的換算匯率回應（已省略）：

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

這個函式必須回傳`735.84000`
