# 指示

在這道練習中，你將會套用[圍棋的規則](https://matmoore.github.io/learngo/)。規則本身已經寫好了，你只需要套用它們來更新 Game，並處理任何錯誤或違反規則的情況。

遊戲的表示方式如下：

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

這個遊戲有 4 條規則：

- 每個點只能有一顆棋子（`oneStonePerPointRule`）
- 對手的棋子可以被吃掉！（`captureRule`）
- 你不能把棋子下在會讓它自己被吃掉的位置（`libertyRule`）
- 你不能重複使用同一個點（`koRule`）

## 1. 套用規則

請撰寫`applyRules`函式的內容。它會接收一個初始的`Game`和一組規則，並在套用規則之後回傳新的`Game`。

`oneStonePerPointRule`、`libertyRule`和`koRule`都會檢查是否違反規則，而且可能回傳錯誤，因此它們的回傳型別是`Result String Game`。如果其中任何一條規則失敗，就應該回傳原始的遊戲，但要把`error`欄位更新成相關的錯誤。

`captureRule`不會檢查是否違反規則，因此不會失敗（不過它可能回傳改變過的`Game`），所以它的回傳型別是`Game`。

如果所有規則都通過，就要保留規則對`Game`所做的任何變更，並且切換玩家。`changePlayer`函式就是為此提供的。

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
