# 簡介

三元運算子讓`if`條件可以定義在運算式裡，而不是定義在敘述區塊裡。這與函式程式設計的做法相呼應，而且通常能讓程式碼更具表達力、更不容易出錯。

三元運算子結合 3 個運算式：一個條件，後面接著一個在條件為 true 時求值並回傳的運算式（`if`部分，由`?`開頭），以及一個在條件為 false 時求值並回傳的運算式（`else`部分，由`:`開頭）。

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
