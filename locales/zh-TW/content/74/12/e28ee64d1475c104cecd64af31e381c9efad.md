# for 迴圈簡介

[for 迴圈](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)提供了一種機制，可以重複執行一組敘述，直到符合某個條件為止。
迴圈由四個部分組成：

```java
for (initialization; test; update) {
    body;
}
```

`initialization`會設定迴圈的初始狀態，而且只在迴圈開始時執行一次。
它通常會宣告並指定一個變數，供 test 運算式和 update 敘述使用。
例如：

```java
int i = 1
```

`test` 運算式會測試迴圈是否該結束。
如果它的結果為 `true`，就會先執行 body，再執行 update 運算式。
如果結果為 `false`，body 和 update 敘述都不會執行，程式會從迴圈結尾的右大括號之後繼續執行。
它通常會檢查在 initialization 區塊中指定的變數。
例如：

```java
i <= 10
```

執行完迴圈主體之後，就會執行 `update` 運算式。
它通常會將迴圈變數增加或減少某個值。
例如：

```java
i++
```

一個印出前四個平方數的 `for` 迴圈看起來會像這樣：

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

輸出結果會是：

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

如果要疊代集合中的每個元素，建議使用 `for-each` 迴圈，不過用 `for` 迴圈也可以做到，像這樣：

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for` 迴圈確實比 `for-each` 迴圈有一些優點：

- 你可以從想要的索引開始，或在想要的索引結束。
- 你可以使用任何想要的（布林）結束條件。
- 你可以自訂迴圈變數的遞增量來跳過某些元素。
- 你可以用倒數的方式，從後往前處理集合。
- 你可以在不涉及集合的情境中使用 `for` 迴圈。
