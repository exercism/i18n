# HTTP 十億美元的問題

## 問題陳述

你被要求從一組給定的國家中找出淨資產排名前`x`名的億萬富翁（國家數量為`N`）。為了做到這件事，你可以使用一個會依國家回傳億萬富翁詳細資料的 API。

為了簡化 API 的存取，你可以使用 [`ims/billionairehub` 用戶端](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client)連接器，連上這個會依國家回傳億萬富翁詳細資料的 API。


```ballerina
import ims/billionairehub;

# Client ID and Client Secret to connect to the billionaire API
configurable string clientId = ?;
configurable string clientSecret = ?;

public function getTopXBillionaires(string[] countries, int x) returns string[]|error {
    // Create the client connector
    billionairehub:Client cl = check new ({auth: {clientId, clientSecret}});

    // TODO Write your logic here
    return [];
}
```

## 限制條件

* 1 <= N <= 5
* 1 <= x <= 10

## 範例 1

輸入

```
Countries: ["United States"]
Limit: 3
```

輸出

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## 範例 2

輸入

```
Countries: ["China", "India"]
Limit: 5
```

輸出

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## 測試環境

* 連上億萬富翁 API 所需的 Client ID 與 Client Secret 已提供給你，放在`tests/Config.toml`中。你可以用它們來初始化用戶端。
* 使用`bal test`來執行並測試你的實作。

## 提示

* `ims/billionairehub`套件的[用戶端](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client)可以用來呼叫「依國家取得億萬富翁」的 API。你可以特別使用`getBillionaires("<country>")`這個遠端方法。
* 你可以先找出各國最有錢的人，再合併這些結果，找出前`x`名
* [查詢運算式](https://ballerina.io/learn/by-example/query-expressions/)很適合用來篩選和排序
