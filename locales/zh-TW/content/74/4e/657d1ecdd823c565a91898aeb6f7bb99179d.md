# 指令

在這道練習中，你需要把經典遊戲 Pac-Man 的幾條規則翻譯成 C++ 函式。

你有四條規則要翻譯，全都和遊戲狀態有關。

> 不用擔心引數是怎麼產生的，只要專注在組合這些引數，回傳預期的結果就好。

## 1. 定義 Pac-Man 是否會吃掉鬼

定義 `can_eat_ghost` 函式，它接受兩個引數（_Pac-Man 是否有作用中的能量藥丸_ 和 _Pac-Man 是否碰到鬼_），並回傳 Pac-Man 是否能吃掉鬼的布林值。只有在 Pac-Man 有作用中的能量藥丸且碰到鬼時，這個函式才應該回傳 true。

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. 定義 Pac-Man 是否得分

定義 `scored` 函式，它接受兩個引數（_Pac-Man 是否碰到能量藥丸_ 和 _Pac-Man 是否碰到豆子_），並回傳 Pac-Man 是否得分的布林值。只要 Pac-Man 碰到能量藥丸或豆子，這個函式就應該回傳 true。

```cpp
scored(true, true);
// => true
```

## 3. 定義 Pac-Man 是否會輸

定義 `lost` 函式，它接受兩個引數（_Pac-Man 是否有作用中的能量藥丸_ 和 _Pac-Man 是否碰到鬼_），並回傳 Pac-Man 是否輸掉的布林值。如果 Pac-Man 碰到鬼，而且沒有作用中的能量藥丸，這個函式就應該回傳 true。

```cpp
lost(false, true);
// => true
```

## 4. 定義 Pac-Man 是否獲勝

定義 `won` 函式，它接受三個引數（_Pac-Man 是否已經吃掉所有豆子_、_Pac-Man 是否有作用中的能量藥丸_ 和 _Pac-Man 是否碰到鬼_），並回傳 Pac-Man 是否獲勝的布林值。如果 Pac-Man 已經吃掉所有豆子，且根據第 3 部分定義的引數判斷沒有輸掉，這個函式就應該回傳 true。

```cpp
won(false, true, false);
// => false
```
