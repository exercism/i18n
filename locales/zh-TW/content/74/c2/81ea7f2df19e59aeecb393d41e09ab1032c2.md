# 認識 JavaScript 中的遞迴

遞迴是程式設計中一個很強大的概念，它指的是函式呼叫自己。一開始可能有點難掌握，但只要你理解了基本原則，它就會成為解決複雜問題的利器。我們會用淺顯易懂的範例，一起來探索 JavaScript 中的遞迴。

## 什麼是遞迴？

遞迴發生在函式直接或間接呼叫自己的時候。它和迴圈很像，但會把問題拆解成更小、更好處理的子問題。

### 範例 1：倒數

先從一個簡單的範例開始：倒數函式。

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

在這個範例中：

- **基準情況**：當 `num` 小於或等於 0 時，函式會印出「Blastoff!」並停止呼叫自己。
- **遞迴情況**：函式會印出目前的 `num`，接著用 `num - 1` 呼叫自己。

### 範例 2：階乘

現在來看一個遞迴的經典範例：計算一個數字的階乘。

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

在這個範例中：

- **基準情況**：當 `n` 為 0 或 1 時，函式會回傳 1。
- **遞迴情況**：函式會把 `n` 乘上 `n - 1` 的階乘。

## 重要概念

### 基準情況

每個遞迴函式至少都要有一個基準情況，也就是函式停止呼叫自己的條件。少了基準情況，遞迴就會無限持續下去，導致堆疊溢位。

### 遞迴情況

遞迴情況定義了函式如何用更小或更簡單的問題版本來呼叫自己。

## 遞迴的優缺點

**優點：**

- 對某些問題來說是優雅的解法。
- 模擬了數學歸納法的概念。

**缺點：**

- 效率可能不如疊代解法。
- 遞迴太深時可能導致堆疊溢位。

## 結論

遞迴是一項很有價值的技巧，它把複雜的問題拆解成更小、更好處理的子問題，讓問題變得簡單一些。理解基準情況和遞迴情況，是你在 JavaScript 中寫出有效遞迴解法的關鍵。
