# 關於

可以容納零個或多個元素的資料結構稱為_集合_。**陣列**是一種集合，它的大小／長度固定，而且所有元素都必須是相同的型別。你可以使用索引將元素指定給陣列，或從陣列中取出元素。C# 陣列是從零開始的，也就是第一個元素的索引一律是零：

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

也可以使用簡寫語法來定義陣列，讓你同時建立陣列並設定它的值。由於編譯器現在可以判斷陣列會有多少個元素，因此可以省略長度：

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

你可以呼叫陣列執行個體的[方法][array-methods]或[屬性][array-properties]來操作陣列，也可以使用 [`Array` 類別][array-class]中定義的靜態方法。

## 疊代

陣列也是一種_集合_，這表示你可以使用 [`foreach` 迴圈][foreach-statement]來疊代它的_所有_值：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

你也可以使用 [`for` 迴圈][for-statement]來疊代陣列：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

不過，一般來說，基於下列理由，`foreach` 迴圈會比 `for` 迴圈更適合：

- `foreach` 迴圈保證會疊代_所有_值。使用 `for` 迴圈時，很容易漏掉元素，例如因為差一錯誤。
- `foreach` 迴圈更具_宣告式_，你的程式碼傳達的是你想讓它做_什麼_，而不像 `for` 迴圈那樣傳達你想_如何_做。
- `foreach` 迴圈萬無一失，而使用 `for` 迴圈時很容易發生差一錯誤。
- `foreach` 迴圈適用於所有集合型別，包括那些不支援使用索引子來存取元素的集合。

為了保證 `foreach` 迴圈會疊代_所有_值，編譯器不允許在 `foreach` 迴圈內更新集合：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for` 迴圈確實比 `foreach` 迴圈有一些優點：

- 你可以從想要的索引開始或結束。
- 你可以使用任何想要的（布林）終止條件。
- 你可以自訂迴圈變數的遞增方式來略過元素。
- 你可以藉由倒數，從後往前處理集合。
- 你可以在不涉及集合的情境中使用 `for` 迴圈。

相關主題：

- 你應該要知道 C# 支援[多維陣列][multi-dimensional-arrays]，例如 `int[,] arr = new int[10, 5]`，這可能非常實用。
- 你也應該要知道，你可以使用 `Array.CreateInstance` 建立 [`System.Array`][system-array-object] 型別的物件。這類物件沒什麼用處，主要是用來與 VB.NET 程式碼互通。它們無法與標準陣列（`T[]`）互換。它們可以有不為零的下界。
