# 關於

`GENERIC:`宣告會定義一個詞，它的行為取決於其中一個引數的類別。具體的行為則由針對特定類別的方法（`M:`）提供。

```factor
GENERIC: stringify ( obj -- str )
M: integer stringify number>string ;
M: string  stringify ;
M: f       stringify drop "(none)" ;
```

呼叫`stringify`時，Factor 會檢查堆疊頂端，找出類別相符且最具體的方法，然後執行它。如果沒有方法相符，就會拋出錯誤。

## 分派類別

預設情況下，分派會根據最上層的引數（堆疊效應中宣告的第一個輸入）來進行。若要多引數分派，請參考`HOOK:`和`MATH:`，它們分別會依第二個引數或數值提升來分派。

## 為泛型新增方法

只要你能`USE:`該泛型與該類別，隨時都可以擴充泛型，即使是在不同的詞彙表裡也一樣：

```factor
USING: math ;
M: ratio  area drop 0 ;     ! adds an `area` method for ratios
```

## 內建類別上的方法

泛型用在內建類別（`integer`、`string`、`array`、`f`、`t`）上，和使用者定義的 tuple 一樣好用。在`f`和`t`上的方法，對於帶有自然預設值的「is-set?」風格述詞特別有用。

## 什麼時候該用泛型

以下情況適合使用`GENERIC:`：

- 某個操作對不同輸入有真正不同的實作方式（而不只是針對標籤做`case`）。
- 你預期之後會有其他程式碼加入新的型別。
- 你希望型別系統能確保這個操作在每個相關類別上都有定義，而 Factor 還能替你列出缺少的方法。

如果變化只是少量且固定的標籤列舉，用`case`會更簡單。
