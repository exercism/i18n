# 關於

Elixir 使用 [_Behaviours_][behaviours] 來提供通用的介面，同時讓每個實作該 behaviour 的模組能有各自的實作。其中一種 behaviour 就是 _Access Behaviour_。

_Access Behaviour_ 提供了一套通用介面，用來從資料結構中取得以鍵為基礎的資料。映射和關鍵字列表都實作了它。

[`Access`][access]模組定義了這個介面所需的回呼。[`Map`][map]和[`Keyword`][keyword]模組則實作了所需的回呼 [`fetch/2`][map-fetch]、[`get_and_update/3`][map-get-and-update] 和 [`pop/2`][map-pop]。

要使用這個 behaviour，你可以在已綁定的變數後面加上 _方括號_，再用鍵取得與該鍵相關的值。映射支援任何型別的鍵，關鍵字列表則只支援原子鍵。

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

如果資料結構中沒有這個鍵，就會回傳`nil`。這可能會導致非預期的行為，因為它不會拋出錯誤。

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

注意，`nil`本身也實作了 Access Behaviour，而且對任何鍵都一律回傳`nil`。

```elixir
nil[:key]
# => nil
```

結構體沒有實作 Access behaviour。
