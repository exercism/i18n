# 關於

Clojure 中的`vector`是一種循序、有索引、不可變的集合，可包含零個或多個值。這表示 vector 一旦建立之後，就無法再修改。用來操作 vector 的函式會回傳一個新的 vector，而原本的 vector 則維持不變。vector 中的值可以是不同的型別。vector 可以像這樣定義：

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

可以使用索引從 vector 取出元素。Clojure 的 vector 以零為基準，也就是說，第一個元素的索引一律為零：

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

原本的 vector 維持不變：

```clojure
numbers
;;=> [2 3 5]
```

若要記住更新後的值，我們必須把它繼續傳遞下去，或用 var 承接它：

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
