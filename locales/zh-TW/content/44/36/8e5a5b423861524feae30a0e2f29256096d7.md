# 說明

在這道練習中，你要為紐約一間在 2012 年 9 月 15 日開幕的美容沙龍製作預約排程系統。

你有五個任務，每個任務都和預約日期有關。
時間採用 24 小時制（沒有 AM/PM）。
為了盡量簡化時區問題，請假設所有時間都使用 UTC。

## 1. 解析全數字的預約日期

實作`schedule_appointment()`函式，把以文字表示的預約日期解析成對應的`DateTime`格式。

請注意，輸入採用美式的月/日/年順序。

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 檢查預約是否已經過了

實作`has_passed()`函式，它接受一個預約日期，並檢查該預約是否已成為過去：

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 檢查預約是否在下午

實作`is_afternoon_appointment()`函式，它接受一個預約日期，並檢查該預約是否在下午（>= 12:00 且 < 18:00）：

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 檢查預約是星期幾

實作`day_of_week()`函式，它會回傳一週中_以數字表示_的那一天。
沙龍在週日休息，所以週一是第 1 天，週六是第 6 天。

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. 重新安排預約

當顧客需要重新安排預約時，系統會自動安排到下一個星期五的同一時間（因為這是一週中最冷清的一天）。

實作`reschedule()`函式，它接受原始的預約（以月/日/年順序的文字字串表示），並回傳重新安排後的預約。

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

如果原始預約是在週一到週四，就重新安排到_本_週的星期五。
如果是週五或週六的預約，就重新安排到_下_週的星期五。
