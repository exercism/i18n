# 安裝

請參閱 [System/Installation][install-link]，了解如何在你的系統上完成設定。

~~~exercism/caution
如果你安裝了 Java Development Kit（JDK），`jconsole` 執行檔可能會與同名的 Java Console 衝突。

可能的解決方法包括：

- 將 J 程式語言的 `jconsole` 執行檔改成不重複的名稱（例如 `jconsole-jlang`）。

- 調整系統的環境變數或 PATH，讓 J 程式語言的 `jconsole` 優先。

- **Linux 使用者請注意**，`bin/install.sh` 這支 bash 腳本會在 `/usr/` 目錄中建立一個名為 `ijconsole` 的**符號連結**。你可以在終端機輸入 `ijconsole` 來使用這個連結。
~~~

安裝好 J 之後，在終端機開啟 J 主控台，輸入以下指令來安裝單元測試框架：

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
