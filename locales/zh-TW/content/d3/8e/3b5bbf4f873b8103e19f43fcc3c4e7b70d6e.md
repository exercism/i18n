# 說明

將以字串表示的三進位數字（例如 '102012'）從基本原則出發，轉換成十進位的等值數字。

程式應將指定無效三進位的字串視為數值 0。

三進位數字包含三個符號：0、1 和 2。

三進位數字的最後一位代表 1，倒數第二位代表 3，倒數第三位代表 9，以此類推。

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

如果你的程式語言在標準函式庫中提供了轉換的方法，請假裝它不存在，自己動手實作。
