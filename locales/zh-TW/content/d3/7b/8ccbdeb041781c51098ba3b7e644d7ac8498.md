# 提示

## 1. 追蹤撲克牌回合

- [`list`][list]函式會回傳一個由傳入的引數所組成的陣列。

## 2. 將所有回合保存在同一個地方

- [`concat`][concat]函式可以用來將兩個陣列串接在一起。

## 3. 尋找先前的回合

- [`some`][some]函式會回傳集合中第一個邏輯為真的值。
- 當函式回傳某個值，但測試預期的是布林值時，[`boolean`][boolean]函式就很好用。

## 4. 計算卡片點數的平均值

- 回想一下基本的算術運算子，例如 [`/`][division]和 [`+`][addition]。
- 可以使用 [`apply`][apply]或 [`reduce`][reduce]來計算一串數字的總和。
- [`count`][count]函式會回傳集合中的項目數量。
- 對整數進行運算時，[`/`][division]函式會回傳比率型別。你可以用 [`double`][double]將比率轉換成小數。

## 5. 另一種平均方式

- 有些序列函式可以回傳序列集合中的 [`first`][first]或 [`last`][last]元素。
- 想找出中間的卡片，可以將卡片數量除以 2，用 [`int`][int]向下取整，再使用 [`nth`][nth]取出該索引位置的卡片。
- 使用 [`or`][or]判斷兩個條件中是否有任一成立。

## 6. 更多計算平均值的技巧

- 要取出偶數或奇數索引位置的卡片，其中一種做法是在 [`range`][range]上使用 [`nth`][nth]來 [`map`][map]一個函式，而 [`range`][range]可以接受選用的 `step` 引數。

## 7. 獎勵回合規則

- 回想一下條件式練習中 [`if`][if]的用法。
- 你可以使用 [`butlast`][butlast]回傳集合中除了最後一項以外的所有項目。
