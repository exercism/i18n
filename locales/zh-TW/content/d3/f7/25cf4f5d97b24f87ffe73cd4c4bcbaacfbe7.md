# 關於

ColdFusion（CFML）是一種 JVM 腳本語言，語法類似 C 或 JavaScript。它會經由 JIT 編譯成位元組碼並在 JVM 上執行，但本身是動態、弱型別的語言，因此開發起來快速又輕鬆。CF 是多範式的語言，同時支援傳統的物件導向與函式式程式設計。

CFML 也內建標籤式的樣板語言，這讓它非常適合開發網頁應用程式。它執行於 J2EE 容器中，並隨附許多函式庫，因此生產力很高，不需要另外安裝大量套件。CFML 原生支援 zip 檔案、PDF 與 Excel 產生、電子郵件、FTP、HTTP、S3 檔案系統、ESAPI 安全性函式庫、JDBC 驅動程式，以及 JSON 與 REST API。

CFML 也能運用任何 Java 專案：只要把 jar 檔放進專案，就能直接在程式碼中實例化 Java 物件。想進一步了解基本語法與一級資料型態，可以參考這份指南：[Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
