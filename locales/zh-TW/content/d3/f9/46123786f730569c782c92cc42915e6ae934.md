# 指示

當你準備為朋友烤餅乾時，發現食譜裡有些計量單位得先換算過。你只熟悉公制，所以需要想個辦法，把常見的美式烘焙計量換算成毫升（mL），讓自己方便一些。

請用這張換算表來解題：

| 要換算的單位 | 體積 | 以毫升（mL）計 |
| --------------- | ------ | ------------------- |
| 毫升 | 1 | 1 |
| 美制杯 | 1 | 240 |
| 美制液量盎司 | 1 | 30 |
| 美制茶匙 | 1 | 5 |
| 美制湯匙 | 1 | 15 |

身為一位正在學習、才華洋溢的程式設計師，你決定用毫升當作轉換的中介單位，方便把表上任何一種單位換算成其他任何一種（甚至換算成自己）。

## 1. 從體積配對中取得數值部分

實作`KitchenCalculator.get_volume/1`函式。給定一個體積配對元組，它應該只回傳其中的數值部分。

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. 將體積配對換算成毫升

實作`KitchenCalculator.to_milliliter/1`函式。給定一個體積配對元組，它應該依照換算表把體積換算成毫升。

請使用多重函式子句和模式配對，為每個單位建立對應的函式。用來表示各單位的 atom 有：`:cup`、`:fluid_ounce`、`:teaspoon`、`:tablespoon`、`:milliliter`。把換算結果包在元組裡回傳。

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. 把毫升體積配對換算成其他單位

實作`KitchenCalculator.from_milliliter/2`函式。給定一個體積配對元組和想要的單位，它應該依照換算表把體積換算成該單位。

請使用多重函式子句和模式配對，為每個單位建立對應的函式。用來表示各單位的 atom 有：`:cup`、`:fluid_ounce`、`:teaspoon`、`:tablespoon`、`:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. 從任何單位換算成任何單位

實作`KitchenCalculator.convert/2`函式。給定一個體積配對元組和想要的單位，它應該把指定的體積換算成該單位。

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
