# 簡介

## 使用`use`運算式

在 Gleam 裡，撰寫並使用高階函式是很常見的事，也就是把其他函式當作引數的函式。有時候同時使用很多高階函式，程式碼會變得難以閱讀，出現一層又一層的縮排。

舉例來說，底下這個函式會呼叫好幾個回傳`Result(Int, Nil)`的函式，並在四個都成功時把它們的值加總。

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam 的`use`運算式讓我們可以不用縮排就寫出這段程式碼，通常也讓程式更好讀。

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

一個`use`運算式會收集程式區塊中後續的所有敘述，並把它當作回呼函式，作為最後一個引數傳給函式呼叫。`use`關鍵字和`<-`符號之間的變數，就是將會傳給回呼函式的引數名稱。

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

回呼函式可以接受任意數量的引數，也可以完全不接受引數。

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

要建立一個能用`use`運算式呼叫的函式，並沒有什麼特別的要求，只要它把回呼函式當作最後一個引數就好。

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam 的`use`運算式是非常強大的功能，可以運用在很多問題上，但如果過度使用，反而會讓程式碼難以閱讀。一般來說，比較建議使用一般的函式呼叫語法，只有在`use`運算式能讓程式碼更好讀時才用它。
