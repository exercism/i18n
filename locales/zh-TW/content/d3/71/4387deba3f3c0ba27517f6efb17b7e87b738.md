# 簡介

Pyret 有兩個截然不同的布林基本值：`true`和`false`。
這兩個值代表一個敘述或條件是否成立。

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret 提供了`and`和`or`運算子，可以用來結合布林值。

and 運算子會在兩邊都是 true 時回傳 true，其他所有組合則回傳 false。

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

or 運算子會在至少一邊是 true 時回傳 true，兩邊都是 false 時則回傳 false。

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()`是一個內建函式，會把 true 變成 false，或把 false 變成 true。

```pyret
not(true) # false
not(false) # true
```
