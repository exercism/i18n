# 關於

Lua 的布林型別有兩個傳統的布林值：`true`和`false`。這些值可以指定給變數、與邏輯運算子（`and`、`or`、`not`）結合，也可以用在條件測試中（例如控制結構）。

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

條件測試和邏輯運算子都會把布林`false`和`nil`視為假，其他任何東西則視為真。
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and`和`or`都採用*短路求值*，也就是只在必要時才會計算第二個運算元。所有運算都依照[運算子優先順序](https://www.lua.org/manual/5.4/manual.html#3.4.8)來計算，其中`not`會比`and`和`or`先計算。

既然只有`false`和`nil`被視為假，其他一切都是真，Lua 中一個常見的慣用寫法是：
```lua
x = x or y
```

這等同於：
```lua
if not x then
  x = y
end
```

在函式中很常這樣用：當參數沒有值（是`nil`）時，指定一個預設值：
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
