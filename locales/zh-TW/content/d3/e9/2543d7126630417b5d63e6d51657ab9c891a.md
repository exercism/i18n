# 說明

柏林的新機場聘請你擔任他們機器人實驗室的開發者。
他們有笨重、看起來有點像人形的機器人，正試著用它們來改善客戶服務。

你到職後的第一項任務，就是寫程式讓機器人在自助報到櫃檯掃描護照後，用對方的母語向他們問候。

機器人對自己的能力很自豪，所以它總是先說自己會說哪種語言，再向對方問候。
例如，如果有人掃描德國護照，機器人會說：

```txt
I can speak German: Hallo Dietrich!
```

## 1. 建立抽象的問候功能

你需要把程式碼組織好，讓你和其他的開發者都能輕鬆加入新的語言。

第一步，定義一個 trait `Greeter`，裡面包含兩個函式。

- `language_name`：回傳機器人用來向訪客問候的語言（`ByteArray`）。
- `greet`：接受訪客的名字（`ByteArray`），並回傳以特定語言表達的問候訊息（`ByteArray`）。

接著，實作一個函式`say_hello`，它接受訪客的名字，以及任何實作了`Greeter` trait 的東西，並回傳想要的問候訊息（`ByteArray`）。
例如，想像一個德文版的`Greeter`實作，它的`language_name`回傳`"German"`，而`greet`回傳`"Hallo {name}!"`：

```rust
say_hello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. 實作義大利文

現在讓機器人也能為掃描義大利護照的人服務。

建立一個 struct `Italian`，並實作那兩個函式來滿足任務 1 的`Greeter` trait。
你可以用`"Ciao {name}!"`向人問候。

## 3. 實作法文

在收工之前，你還得加上用法文向人問候的功能。

建立一個 struct `French`，並實作那兩個函式來滿足`Greeter` trait。
你可以用`"Bonjour {name}!"`向人問候。
