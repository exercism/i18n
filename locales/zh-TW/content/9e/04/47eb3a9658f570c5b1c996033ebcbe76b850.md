# 測試

## 互動式測試

在你正在進行的練習目錄中啟動你的 Common Lisp 實作（或者，如果 Common Lisp 實作已經在執行，就把目前目錄切換到那個目錄）。
使用 roswell 的話，可以執行`ros run`來做到這件事。

（這裡所有範例都假設練習名稱是`exercise-name`，請視情況調整。）

把測試檔案載入到正在執行的 Lisp 實作中，例如`(load "exercise-name-test")`。
（這也會順便幫你載入解答檔案。）
測試檔案載入之後，你可以在 REPL 中求值`(exercise-name-test:run-tests)`來執行測試。

當你修改正在寫的解答時，請利用編輯器的功能載入這些變更，或求值`(load "exercise-name")`來載入你的解答檔案。

記得在載入更新後的解答之後，求值`(exercise-name-test:run-tests)`來重新執行測試。

## 從命令列測試

你可以用下面這個命令列指令來啟動測試（同樣地，記得在兩個地方把「exercise」換成正確的名稱）

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

那個指令用起來還挺麻煩的。
有位貢獻者寫了一些筆記，說明[如何讓它更容易執行](https://glennj.github.io/exercism/cli)。
