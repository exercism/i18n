## 布林值

Raku 有`True`和`False`這 2 個布林常值。
在布林上下文中，任何未定義的東西都會被視為`False`。
除了`Bool::False`本身之外，會被視為`False`的已定義值包括`0`、`NaN`、`()`（空陣列）、`""`（空字串），以及`Failure`型別的物件。

前綴`?`運算子會強制將物件置於布林上下文。
它的行為等同於在該物件上呼叫`Bool`方法。
前綴`!`運算子會得到前綴`?`的相反結果。

## 布林中綴運算子

### 智慧匹配

中綴`~~`（又稱智慧匹配運算子）是 Raku 中常用的工具。
它的行為取決於運算子右側是哪個物件，因為它是該物件`ACCEPTS`方法的捷徑。
左側的值會作為引數傳給`ACCEPTS`。
結果是布林值。

### 邏輯 AND/OR

Raku 有[`&&`][&infix:<&&>]/[`and`][&infix:<and>]、[`||`][&infix:<||>]/[`or`][&infix:<or>]、[`//`][&infix:<//>]/[`orelse`][&infix:<orelse>]和[`^^`][&infix:<^^>]/[`xor`][&infix:<xor>]這些運算子，用於布林邏輯（分別為高優先序與低優先序）。
這些運算子可以串接。

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### 三元運算子

Raku 有三元／條件中綴`?? !!`運算子，寫法為`$condition ?? $true !! $false`。

## 控制流程

### if/elsif/else

`if`敘述用來依條件執行一段程式區塊。
要建立`if`敘述，先寫`if`關鍵字，後面接運算式，再接程式區塊。

運算式會在布林上下文中求值；若運算式求值為`True`，就會執行該程式區塊。

`if`敘述可以用`elsif`和`else`這兩個關鍵字擴充，寫法和`if`相同。如果先前所有運算式都求值為`False`，就會執行`else`區塊；`elsif`區塊也一樣，只要它自己的運算式求值為`True`就會執行。

或者，`if`也可以寫成敘述修飾形式：

```raku
say 'success' if True;
```

敘述修飾形式不能搭配`elsif`或`else`。

### given/when/default

`given`敘述是 Raku 的主題化關鍵字，類似 C 等語言中的`switch`也會進行主題化。
各案例的關鍵字是`when`和`default`。

### for/while/loop

`for`敘述會疊代指定的陣列，並為陣列中的每個元素執行一次程式區塊。

`while`敘述會在指定的運算式求值為`True`時，重複執行一個程式區塊。

`loop`敘述有 2 種寫法。
如果只給它一個程式區塊，它會重複執行該程式區塊，直到有東西明確地跳出迴圈。
也可以寫成 C 風格的`for`迴圈，在程式區塊前的小括號中放入初始化、條件和遞增運算式。

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
