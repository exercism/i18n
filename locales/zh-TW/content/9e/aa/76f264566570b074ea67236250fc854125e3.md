# 求助

如果你遇到問題，可以透過下列資源尋求協助：

- [ClojureScript API](http://cljs.github.io/api/) 的官方 API 文件。
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet)，官方的速查表。
- [/r/clojurescript](https://www.reddit.com/r/clojurescript) 是 C# 的 subreddit。
- [StackOverflow](http://stackoverflow.com/questions/tagged/clojurescript) 可以用來搜尋你的問題，看看是不是已經有人問過並解答了。你也可以在上面提問和回答問題。
