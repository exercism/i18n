# 指令

Jen 在一間大工廠的分揀室工作。
分揀室需要處理送進來的一切物品，方式是為它們貼上標籤分類。
Jen 負責的是那些事先被歸類為數字的東西，她需要一個程式來協助她分揀。

大多數基本型別的值都應該拿到簡單直接的標籤。
對於數字，她想要像`"This is the number 2.0"`這樣的字串（如果那個數字是 2）。
不論是整數還是浮點數，Jen 都想要同樣的輸出。

有幾個`Box`介面需要拆開才能取出裡面的內容。
對於`NumberBox`，她想要像`"This is a box containing the number 3.0"`這樣的字串（如果`Number()`方法回傳 3）。
對於`FancyNumberBox`，她想要像`"This is a fancy box containing the number 4.0"`這樣的字串，但只有在型別是`FancyNumber`的時候。

任何意料之外的東西都應該回傳`"Return to sender"`，這樣 Jen 就能把它們送回原來的地方。

## 1. 描述簡單的數字

Jen 想要數字回傳像`"This is the number 2.0"`這樣的字串（包含小數點後一位）：

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. 描述數字盒

Jen 想要數字盒回傳像`"This is a box containing the number 2.0"`這樣的字串（同樣包含小數點後一位）：

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. 實作從花俏數字盒取出數字的方法

Jen 需要一個輔助函式，從`FancyNumberBox`取出數字。
如果`FancyNumberBox`是`FancyNumber`，就取出它的值，並把它從`string`轉換成`int`。
其他任何型別的`FancyNumberBox`都應該回傳 0。

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. 描述花俏數字盒

如果`FancyNumberBox`是`FancyNumber`，Jen 想要像`"This is a fancy box containing the number 4.0"`這樣的字串。
其他任何型別的`FancyNumberBox`都應該回傳`"This is a fancy box containing the number 0.0"`。

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

注意：我們應該使用`ExtractFancyNumber`函式！

## 5. 實作`DescribeAnything`，它會用到上述全部功能

這是 Jen 需要的主要函式，它可以接受任何輸入。
`DescribeAnything`應該根據傳入值的型別，把工作委派給其他函式。
更精確地說：

- `int`和`float64`都應該委派給`DescribeNumber`
- `NumberBox`應該委派給`DescribeNumberBox`
- `FancyNumberBox`應該委派給`DescribeFancyNumberBox`
- 其他任何東西都應該產生`"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
