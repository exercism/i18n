# 簡介

除了 `cond` 之外，Elixir 還提供了巨集 [`if/2`][getting-started-if]，當你只需要檢查一個條件時，它就很好用。

[`if/2`][kernel-if] 接受一個條件和兩個選項。如果條件是 _truthy_，就回傳第一個選項；如果條件是 _falsy_，就回傳第二個選項。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

也可以把 `if` 運算式寫成單行。注意條件後面有一個逗號。

```elixir
if age > 16, do: "beer", else: "no beer"
```

這種語法對非常短的運算式很有幫助，但如果運算式塞不進單行，就應該避免使用。

## _Truthy_ 與 _falsy_

在 Elixir 中，所有資料型態在布林脈絡（例如 `if` 運算式）中出現時，都會求值為 _truthy_ 或 _falsy_。除了 `false` 和 `nil` 之外，所有資料都會被視為 _truthy_。特別是，空字串、整數 `0` 和空陣列在 Elixir 中都被視為 _truthy_。
