# 測試

你需要先正確[安裝 Godot][installation]，才能使用測試執行器。

## 執行測試

[測試執行器][test runner]用來載入並測試解答。
若要執行測試執行器，請先將它下載到本機，再使用`godot`來執行。
未來使用`exercism download`時，測試執行器會隨著練習自動下載。

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
