# Instructions

在這項練習中，你會在一間提供外送服務的披薩店工作。

店裡提供 3 種披薩：

- Margherita：\$7
- Caprese：\$9
- Formaggio：\$10

顧客也可以支付少許額外費用，選擇 2 個額外選項：

1. 額外醬料：\$1
1. 額外配料：\$2

當顧客下訂單時，如果他們只訂 1 或 2 個披薩，就會加收額外費用：

- 1 個披薩：\$3
- 2 個披薩：\$2

你有 3 個任務，每個任務都會處理披薩和價格。

## 1. 定義披薩類型和選項

定義`Pizza`差別聯合，以代表披薩類型以及可以加到披薩上的 2 個額外選項：

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. 計算披薩的價格

實作`pizzaPrice`函式來計算披薩的價格：

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. 計算訂單的價格

實作`orderPrice`函式來計算披薩訂單的價格：

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
