# 關於

[範圍][range]代表由一個或多個連續整數組成的序列。它們：

- 使用[`..`運算子][range-operator]建立，可以遞增也可以遞減。
- 預設的步進值為`1`，但可以使用[`..//`運算子][range-operator-with-step]修改（自 Elixir 1.12 起）。
- 包含第一個與最後一個值。
- 實作了[_可列舉協定_][enumerable]。
- 在內部以結構體表示，但可以使用`..`進行模式匹配。
- 可以搭配以二進位、八進位、十六進位與碼點記法撰寫的整數使用。
- 可以使用[`Enum.to_list/1`][enum-to-list]或[`Enum.map/2`][enum-map]等函式轉換成陣列。

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
