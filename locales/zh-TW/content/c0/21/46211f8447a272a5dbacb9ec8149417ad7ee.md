# 簡介

Cairo 的核心程式庫提供字典，並以`Felt252Dict<T>`型別表示。

Cairo 字典的鍵型別僅限於`felt252`，這與其他語言不同，其他語言可以自行定義鍵的型別。

若要建立字典，可以使用`Default` trait 的`default`方法，例如：

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

最常使用的基本操作有：

1. `insert(felt252, T) -> ()`，用來把值寫入字典實例，以及
2. `get(felt252) -> T`，用來從中讀取值。

以下是這些操作的使用方式：

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

如果你試著取得字典中某個不存在的鍵所對應的值，它會回傳該值型別的零值。

這可能會讓你混淆，特別是當你的值型別的預設值（例如整數的 0）本身就是有效的值時。

這也代表你無法從字典中刪除資料。

將這個結構融入你的程式碼時，這點值得留意喔。
