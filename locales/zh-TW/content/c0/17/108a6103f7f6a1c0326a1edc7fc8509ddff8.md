# 提示

## 一般

- 這個挑戰要運用[單向鏈結串列][singly linked list]，建立一個[_堆疊_][Baeldung: The Stack Data Structure]。
- 不同於以`lists`、`collections.deque`或`queue.LifoQueue`為基礎的堆疊，我們要你自己建立`Node`和`LinkedList`[`classes`][classes tutorial]來儲存與串接元素。

![以鏈結串列實作堆疊的示意圖。最左側是一個虛線邊框的圓圈，名為 New_Node，有兩條點狀箭頭往右指。New_Node 上寫著「(becomes head) - New_Node - next = node_6」。上方那條點狀箭頭標示為「push」，指向右上方更遠處的 Node_6。Node_6 上寫著「(current) head - Node_6 - next = node_5」。下方那條點狀箭頭標示為「pop」，指向一個寫著「gets removed on pop()」的方框。Node_6 有一條實線箭頭往右指向 Node_5，Node_5 上寫著「Node_5 - next = node_4」。Node_5 有一條實線箭頭往右指向 Node_4，Node_4 上寫著「Node_4 - next = node_3」。這個模式一直延續到 Node_1，Node_1 上寫著「(current) tail - Node_1 - next = None」。Node_1 有一條點狀箭頭往右指向一個寫著「None」的節點。](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- 想了解實作細節，可以參考 [Real Python: Linked Lists][Real Python Linked Lists]、[Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] 和 [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python]。
- 你的`LinkedList`應該要能接受`list`引數傳入它的_建構子_，但不該用`list`來儲存節點或元素。
- `len()`是大多數 Python 物件的內建函式。想讓_自訂物件_支援`len()`，就必須定義特殊方法[`__len__`][__len__]。
- Python 大多數的序列、容器或集合型別物件都支援疊代。想讓_自訂_物件支援迴圈或重新排序，就必須定義特殊方法`__iter__`。[為類別實作疊代器][implementing iterators]可以幫助你了解做法。
