# 操作說明

在這個練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出美味的千層麵。

你有四個任務，全都和烹調千層麵所花的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義`expected_minutes_in_oven`綁定，用來確認千層麵應該待在烤箱裡幾分鐘。
根據食譜，預期的烤箱時間是 40 分鐘：

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remaining_minutes_in_oven`函式，它接收千層麵實際待在烤箱裡的分鐘數作為參數，並根據前一個任務算出的預期烤箱時間，回傳千層麵還需要在烤箱裡待幾分鐘。

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. 計算準備時間（分鐘）

定義`preparation_time_in_minutes`函式，它接收你加進千層麵的層數作為參數，並回傳你花幾分鐘準備千層麵，假設每一層要花 2 分鐘準備。

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. 計算經過的時間（分鐘）

定義`elapsed_time_in_minutes`函式，它接收兩個參數：第一個參數是你加進千層麵的層數，第二個參數是千層麵已經待在烤箱裡的分鐘數。這個函式應該回傳你花了幾分鐘烹調千層麵，也就是準備時間的分鐘數，加上千層麵目前待在烤箱裡的分鐘數。

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
