# 說明

給定一段輸入文字，輸出它的轉置結果。

簡單來說，矩陣的轉置：

```text
ABC
DEF
```

會變成：

```text
AD
BE
CF
```

列會變成行，行會變成列。請參閱 <https://en.wikipedia.org/wiki/Transpose>。

如果輸入的各列長度不同，處理方式如下：

- 在左側補上空格。
- 不要在右側補空格。

因此，將這個矩陣轉置：

```text
ABC
DE
```

會得到：

```text
AD
BE
C
```

而將這個矩陣轉置：

```text
AB
DEF
```

則會得到：

```text
AD
BE
 F
```

一般來說，輸入中的所有字元都應該出現在轉置後的輸出中。也就是說，如果輸入文字的某一行在最底部的列只有空格，那麼輸出中對應的那一列，就應該在最右側的行中包含這些空格。
