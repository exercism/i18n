# 關於

Ceylon 是一門通用程式語言，語法類似 Java 和 C#。它是指令式的、靜態型別的、區塊結構化的、物件導向的，也是高階的。所謂_靜態型別_，是指編譯器會藉助程式碼中的型別標註，進行大量的型別檢查。所謂_物件導向_，是指這門語言支援使用者自訂型別，並具備名義型別系統，其中一個型別是一組具名屬性與操作的集合，而且它支援繼承與子型別多型。所謂_高階_，是指每一個可被引用的程式元素（每一個屬性、每一個操作，以及每一個型別）本身也是一個值。所謂_區塊結構化_，是說這門語言具備詞法作用域，以及一套極度規則、可遞迴的宣告與敘述語法。

Ceylon 改良了 Java 的語言與型別系統，和 Java 及 C# 相比，能減少冗長度並提升型別安全。Ceylon 鼓勵更函式式、稍微不那麼指令式的程式設計風格，寫出來的程式碼更容易推理，也更容易重構。
