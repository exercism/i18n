# 測試

## Clojure CLI

Exercism 上的 Clojure 練習都隨附一個`deps.edn`檔案，裡面有個`:test`別名，可用來呼叫 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)：

``` bash
$ clj -X:test
```

這會掃描專案中的`test`目錄，執行所有使用`clojure.test`定義的測試。

## Leiningen

如要使用 Leiningen 執行某個練習的測試，只要執行以下指令：

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
