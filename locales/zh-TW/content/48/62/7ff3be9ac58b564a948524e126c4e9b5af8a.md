# 提示

## 一般

- [`Set` API 文件][set-docs]列出了`Set`介面上可用的方法。

## 1. 開始收集

- [`HashSet`類別][hashset-docs]有一個接受`Collection`的建構子。

## 2. 擴充收集

- 看看`Set`介面上定義的[`add`方法][set-add-docs]簽章。

## 3. 開始交換

- 你可以把`Set`包進`new HashSet<>()`裡，建立一份副本。
- [`Set`介面][set-docs]有個方法會移除另一個`Collection`中包含的所有項目。

## 4. 找出共同的卡片

- 你可以把`Set`包進`new HashSet<>()`裡，建立一份副本。
- [`Set`介面][set-docs]有個方法會保留另一個`Collection`中包含的所有項目。

## 5. 全部的卡片

- 你可以把`Set`包進`new HashSet<>()`裡，建立一份副本。
- [`Set`介面][set-docs]有個方法會新增另一個`Collection`中包含的所有項目。

[set-add-docs]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Set.html#add(E)
[set-docs]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Set.html
