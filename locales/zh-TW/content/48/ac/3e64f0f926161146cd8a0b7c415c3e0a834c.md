# 簡介

[`Rational numbers`][rational]是分子為整數、分母為整數的分數。

舉例來說，我們可以把`2//3`儲存成精確的分數，而不是`Float64`的近似值`0.6666...`。

這麼做的好處是，有理數能維持精確（除非碰上[整數溢位][integer-overflow]這類極端情況），避免浮點數經常無可避免的捨入誤差。

更多細節請見 Julia 的[手冊頁面][julia-rational]。

有理數是相當簡單的數值型別，運作方式大致符合你的預期。
由於有理數從早期版本就一直是 Julia 的標準型別，大多數函式都能像接受整數和浮點數那樣，把它們當作輸入。

## 建立有理數

建立的方式很簡單，只要在兩個整數之間使用`//`就行了。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

公因數會自動約掉，把分數化成[「最簡分數」][lowest-terms]：也就是能準確表示該分數的最小整數，而且分母不為負。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

無限大的結果可以接受，但[`NaN`][NaN]不行。

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## 有理數的算術運算

一般常見的[`arithmetic operators`][operators]`+ - * / ^ %`都能用在有理數上，行為基本上和其他數值型別相同。

整數和其他`Rational`也能一起參與運算，結果會是`Rational`。
如果運算式中包含`float`，輸出的結果也會是`float`，也因此可能損失精確度。

如果需要`float`，只要用`float()`函式把有理數轉過去就好。
為了在冗長的計算過程中維持精確度，先用有理數運算、最後再轉成浮點數，是很常見的做法。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

有理數也能和[複數][complex]合併使用。
複數會在另一個[概念][complex-concept]裡介紹。

## 其他運算

在 Julia 裡，有理數就只是數字。
編譯器通常會在需要時自動轉換型別。

不過要注意，比較運算只對能寫成有限小數的分數成立：

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

其他情況則必須先把`Rational`轉型成`Float`才能比較：

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

數學函式可以接受有理數作為輸入，但結果可能是浮點數：

```julia-repl
julia> sqrt(9//16)
0.75
```
