# 簡介

Elixir 透過讓函式擁有多個子句，來實踐**開閉原則**。如此一來，開發者不必寫出龐雜又寫死的控制邏輯，而是能寫出目標明確的函式，輕鬆地新增或移除行為。

Elixir 提供_多重函式子句_和_守衛_，讓你寫出這樣的程式碼：

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

在執行期間，Elixir 會從原始碼檔案的最上方開始往下測試，決定要呼叫哪一個函式子句。

沒有用到的變數，應該在名稱前面加上底線。
