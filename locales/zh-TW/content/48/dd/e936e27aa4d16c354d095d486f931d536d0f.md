# 說明

你負責維護地震儀陣列的處理站，這是一套記錄地面如何移動的感測器網路。

讀數會以數值區塊的形式送達。
有些是以 32 位元浮點數儲存的地面位移，其他則是以 32 位元整數儲存的原始計數與狀態字組。
處理站一次處理整個區塊，對每個數值套用相同的運算。

本練習有六個任務，每個任務都對記憶體中的一個數值區塊進行操作。
你透過記憶體位址接收運算元，並透過結果位址寫回答案。
本練習中的所有記憶體位址皆為 16 位元組對齊。

~~~~exercism/note
本練習的運算應使用 SIMD 位元運算與移位來完成，而非純量運算。
~~~~

## 1. 將軌跡整流

就震級分析而言，重要的只有每個地面位移的大小，而不是它的方向。
第一個處理步驟會把每筆讀數折疊成非負值。

實作 `rectify_trace` 函式，計算每筆讀數的絕對值。
一個區塊包含 4 筆讀數，每筆皆為 32 位元浮點數。

這個函式的引數依序如下：

- `result`：用來寫入 4 筆整流後讀數的緩衝區記憶體位址。
- `trace`：記錄讀數的記憶體位址，內含 4 個值，每個皆為 32 位元浮點數。

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

這個函式沒有回傳值。

## 2. 讀取震動的尺度

分析師依 2 的次方為震動分級：讀數接近`8.0`時落在尺度`3`，讀數接近`0.25`時落在尺度`-2`。
那個尺度其實已經存在於每個浮點數之中，也就是它的指數欄位。

一個 32 位元浮點數的配置為：位元 31 是符號位元，位元 30 到 23 是 8 位元指數，位元 22 到 0 是 23 位元小數部分。
儲存的指數帶有 127 的偏移值，因此該數的值為 `(-1)^sign * 1.fraction * 2^(exponent - 127)`。

實作 `reading_scale` 函式，將每筆讀數去除偏移後的指數以有號 32 位元整數取出。

這個函式的引數依序如下：

- `result`：用來寫入 4 個尺度的緩衝區記憶體位址，每個皆為有號 32 位元整數。
- `trace`：整流後讀數的記憶體位址，內含 4 個值，每個皆為 32 位元浮點數。

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

這個函式沒有回傳值。
所有讀數皆為正規且非零的浮點數。

## 3. 降低解析度

為了長期儲存，原始位移計數會以較粗的解析度保存：每個計數都會除以 2 的次方。

位移計數是有號的：地面可能往兩個方向移動。
要正確地對它們做除法，得採用能保留正負號的移位方式。

實作 `coarsen_displacements` 函式，將每個有號計數除以`2^shift`，並朝負無窮大的方向捨入。

這個函式的引數依序如下：

- `result`：用來寫入 4 個粗化後計數的緩衝區記憶體位址，每個皆為有號 32 位元整數。
- `counts`：原始計數的記憶體位址，內含 4 個有號 32 位元整數。
- `shift`：要除的 2 的次方，為介於`0`與`31`之間的 64 位元無號整數。

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
指令`movq`可用來將 64 位元整數從一般用途暫存器複製到`xmm`暫存器，而不改變底層的位元表示。
~~~~

這個函式沒有回傳值。

## 4. 閘控通道

每個測站會合併兩次記錄活動，然後把硬體報告中標示為故障的通道設為靜音。
每個區塊包含 4 個通道遮罩，每個皆為無號 32 位元整數，其中每個位元代表一個通道：`1`代表啟用，`0`代表停用。

實作 `gate_channels` 函式，它會合併兩個記錄活動中任一已啟用的通道，然後清除所有被標示為故障的通道。

這個函式的引數依序如下：

- `result`：用來寫入 4 個閘控後遮罩的緩衝區記憶體位址，每個皆為無號 32 位元整數。
- `enable_a`：第一個記錄活動之啟用遮罩的記憶體位址，內含 4 個無號 32 位元整數。
- `enable_b`：第二個記錄活動之啟用遮罩的記憶體位址，內含 4 個無號 32 位元整數。
- `faulty`：故障通道遮罩的記憶體位址，內含 4 個無號 32 位元整數。

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

這個函式沒有回傳值。

## 5. 切換校正位元

測站每天會執行一次校正，翻轉每個狀態字組中一組選定的設定位元，其餘位元則維持不變。
但有些位元被硬體鎖定，無論校正要求什麼，都絕不能改變。
執行同一次校正兩次，即可還原成原本的設定。

實作 `toggle_calibration` 函式，它會在每個狀態字組中，翻轉那些在對應切換遮罩中已設定、且在對應鎖定遮罩中未設定的位元。

這個函式的引數依序如下：

- `result`：用來寫入 4 個更新後狀態字組的緩衝區記憶體位址，每個皆為無號 32 位元整數。
- `status`：目前狀態字組的記憶體位址，內含 4 個無號 32 位元整數。
- `toggle`：切換遮罩的記憶體位址，內含 4 個無號 32 位元整數。
- `locked`：鎖定遮罩的記憶體位址，內含 4 個無號 32 位元整數。

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

這個函式沒有回傳值。

## 6. 放大軌跡

陣列的每個通道都有自己的增益微調，以 2 的次方表示：增益`3`會將該通道的讀數乘以`8`，增益`-5`則會把它除以`32`。

測站套用這些增益時完全不使用乘法，而是藉由操作每個浮點數的指數欄位來達成。

實作 `amplify_trace` 函式，將每筆讀數乘以`2`的該通道增益次方，且只操作原始位元。

這個函式的引數依序如下：

- `result`：用來寫入 4 筆放大後讀數的緩衝區記憶體位址。
- `trace`：讀數的記憶體位址，內含 4 個值，每個皆為 32 位元浮點數。
- `gains`：各通道增益的記憶體位址，內含 4 個有號 32 位元整數。

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

這個函式沒有回傳值。
所有讀數皆為正規且非零的浮點數，且每個放大後的結果也都是正規數。
