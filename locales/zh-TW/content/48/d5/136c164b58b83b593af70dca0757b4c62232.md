# 測試

安裝相依套件。

```sh
dart pub get
```

執行測試。

```sh
dart test
```

如果想看到各個測試更詳細的輸出，可以使用 expanded reporter。

```sh
dart test -r expanded
```

大多數練習都包含多個測試，預設情況下除了第一個測試之外，其餘都會被跳過。
如果想一次只處理一個測試，就隨著進度把每個測試的 `skip: true` 改成 `skip: false`。

或者，也可以在不修改檔案的情況下，一次執行所有測試。

```sh
dart test --run-skipped
```

提交時，線上測試執行器會執行所有測試，包括被跳過的測試。
