# 指令

在這個練習中，你會協助高中情侶在社群媒體上公開示愛，方法是產生一個帶有他們姓名縮寫的 ASCII 方框：

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. 取得名字的第一個字母

實作 `HighSchoolSweetheart.first_letter/1` 函式。它應該接受一個名字，並回傳它的第一個字母。它應該清除名字中任何多餘的空白。

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. 將第一個字母格式化為姓名縮寫

實作 `HighSchoolSweetheart.initial/1` 函式。它應該接受一個名字，並回傳它的第一個字母，轉成大寫，後面加上一個點。請務必重複使用你在前一步定義的 `HighSchoolSweetheart.first_letter/1`。

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. 將全名拆分成名字和姓氏

實作 `HighSchoolSweetheart.initials/1` 函式。它應該接受一個全名，全名由名字和姓氏組成，兩者以空格分隔，並回傳姓名縮寫。請務必重複使用你在前一步定義的 `HighSchoolSweetheart.initial/1`。

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. 將姓名縮寫放進 ASCII 方框內

實作 `HighSchoolSweetheart.pair/2` 函式。它應該接受兩個全名，並回傳放在 ASCII 方框內的姓名縮寫。你不需要自己畫方框，請使用程式碼註解中附的方框。請務必重複使用你在前一步定義的 `HighSchoolSweetheart.initials/1`。

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
