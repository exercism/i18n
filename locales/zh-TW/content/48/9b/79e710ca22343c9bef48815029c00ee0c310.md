# 簡介

## 箭頭函式

除了函式宣告和函式運算式之外，JavaScript 還有另一種非常簡潔的函式定義語法。
這類函式稱為_箭頭函式_。

以下是函式宣告與箭頭函式的比較。

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

如果函式主體只包含一個 return 敘述，就像上面的範例一樣，那麼 `{}` 和 `return` 關鍵字都可以省略。
如果只有一個參數，括號`()`也可以省略。

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

箭頭函式經常用來在函式呼叫中直接定義簡短的回呼函式。

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## 陣列分析

[陣列][arrays-concept]有內建的方法可以分析陣列的內容。
這些方法大多會接受一個回傳 true 或 false 的函式作為引數。
這樣的函式稱為[`predicate`][predicate_in_programming]。

這些內建方法的用途是_取代`for`迴圈_或內建的 `forEach` 方法：

使用`for`迴圈進行分析的範例：

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

使用內建方法進行分析的範例：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

以下列出一些其他可以用來分析陣列的實用內建方法。
完整的陣列方法列表請參閱 [MDN][mdn-array-methods]。

### `includes`

`includes(value)`方法會判斷陣列是否包含某個特定的值。
當陣列包含該值時會回傳 `true`，否則回傳 `false`。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

`every(predicate)`方法會接受一個函式，而這個函式就是_一個 predicate_。
它會測試陣列中的每個元素在傳入這個 predicate 之後是否都回傳 `true`。
換句話說，這個方法會測試它的所有元素是否都通過傳入這個函式呼叫的測試。
當每個元素都通過 predicate 測試時，它會回傳 `true`，否則回傳 `false`。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

`some(predicate)`方法和 `every` 方法相同，但只要陣列中至少有一個元素通過_predicate_測試，就會回傳 `true`。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

`find(predicate)`方法會回傳陣列中第一個通過`predicate`測試的元素的值。
`some()`在通過測試時會回傳 `true`，而`find()`則會回傳陣列中實際的值。
當陣列中沒有任何元素通過_predicate_測試時，這個方法會回傳 `undefined`。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

`findIndex(predicate)`和`find()`方法相同，但它回傳的是通過_predicate_測試的元素的（第一個）_索引_，而不是 `value`。
當陣列中沒有任何元素通過_predicate_測試時，這個方法會回傳 `-1`。

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
