# 關於

在篩選例外時，`when` 是使用的關鍵字。它放在 catch 敘述之後，可以接受一個布林運算式，運算式中可以使用當下作用域裡的任何值。這些值不一定要是例外本身的成員。如果例外的型別相符，且運算式的結果為 true，就會執行該 `catch` 敘述對應的程式區塊；否則會檢查下一個 `catch` 敘述（如果有的話）。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- 這篇[例外篩選][exception-filters]文章說明如何篩選例外。

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
