# 介紹

許多語言都有像`null`或`none`這樣的方式，用來表示不存在的值。
由於 R 是為了處理大量（而且通常很雜亂）的資料而設計，因此它有多種表示「空無」的形式。

整體的目標，是在遇到缺失或可疑的值時將它們標記出來，然後在不引發例外的情況下繼續執行。

## NULL

如果某個值真的不存在，就會用`NULL`來表示。這大概最接近 C 或 Python 可能會有的做法。

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

在許多情況下，`NULL`值會被直接忽略：

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

遇到值確實存在、但我們不知道它是什麼的情況時，就會使用`NA`。例如，在計算道路上行駛的車輛時，人類觀察員可能請病假，或是自動感測器故障，但車流仍然持續不斷。

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

因此`NA`是一個佔位符，提醒人類必須決定要怎麼處理它。

## NaN

`NaN`是「Not a Number」的縮寫，用來標記在預期會得到數字時所發生的計算問題。

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

這並不是「無效」計算的唯一可能。
當分子不為零時，除以零會回傳`Inf`或`-Inf`，而不會引發錯誤。

```R
1 / 0
#> [1] Inf
```

## 空的向量

或許令人意外的是，R 並沒有檢查「空」的標準做法。

就連產生一個空的向量也不是那麼顯而易見。
我們在前面某一節看過，不帶引數的`c()`會回傳`NULL`，而不是一個向量。

```R
is.vector(c())
#> [1] FALSE
```

像`logical()`或`integer()`這類函式會接受一個指定所需長度的引數，而這個長度可以是零。

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

我們也可以先產生一個向量，再移除其中的每一個元素，如[向量概念][concept-vectors]所述。
這樣會得到一個長度為 0、型別適當的向量。

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
