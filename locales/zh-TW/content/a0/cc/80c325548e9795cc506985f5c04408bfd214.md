# 說明

在這個練習中，你會寫一些程式碼，幫助你照著最愛的食譜做出美味的千層麵。

你有四項任務，全都和烹調千層麵所花的時間有關。

## 1. 定義預期的烤箱時間（分鐘）

定義`expectedMinutesInOven()`方法，這個方法不接受任何參數，並回傳千層麵應該在烤箱中烤幾分鐘。根據食譜，預期的烤箱時間是 40 分鐘：

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. 計算剩餘的烤箱時間（分鐘）

定義`remainingMinutesInOven()`方法，這個方法接受千層麵已經在烤箱中的實際分鐘數作為參數，並根據上一項任務的預期烤箱時間，回傳千層麵還需要在烤箱中待幾分鐘。

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. 計算準備時間（分鐘）

定義`preparationTimeInMinutes()`方法，這個方法接受你加到千層麵中的層數作為參數，並回傳你準備千層麵花了多少分鐘，假設每一層需要花 2 分鐘準備。

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. 計算總共的工作時間（分鐘）

定義`totalTimeInMinutes()`方法，這個方法接受兩個參數：第一個參數是你加到千層麵中的層數，第二個參數是千層麵已經在烤箱中的分鐘數。這個函式應該回傳你烹調千層麵總共花了幾分鐘，也就是準備時間的分鐘數，加上千層麵當下已經在烤箱中待的分鐘數。

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
