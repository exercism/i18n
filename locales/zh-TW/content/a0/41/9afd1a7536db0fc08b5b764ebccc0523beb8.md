# 學習

## 推薦學習資源

Exercism 提供練習與回饋，但對第一次學 SML 的人來說，ML 可能不太好入門。
這些資源可以幫助你起步：

### 我完全沒有程式設計經驗

對程式設計新手來說，ML 大概不是最適合的語言。
你從 Ruby 或 Python 這類語言開始，可能會更好；不過如果你特別有膽識，也許可以讀一讀 [Programming in Standard ML '97: An On-line Tutorial][tutorial]。
我建議跳過前言，直接跳到 [Simple applicative programming][node13]，因為前言非常技術性。

Coursera 有一門關於 [programming languages][coursera] 的課程。
這門課的對象是有一些經驗的程式設計師，不過要找到更好的 ML 語言入門資源並不容易。


### 我聽過函式式程式設計

值得一讀的是 [Programming in Standard ML '97: An On-line Tutorial][tutorial]。

另一本是 [A Gentle Introduction to ML][gentle]。

Coursera 有一門關於 [programming languages][coursera] 的課程。
很難找到更好的 ML 語言入門資源。

[SML/NJ 網站][smlnj] 列了不少書。
不過大多相當老舊，可能也不太容易找到。
這門語言沒什麼改變，所以如果你找得到，也別覺得它們太過時。
另外也可以看看頁面上列出的 Four Lectures on Standard ML。


## 我是有自信的程式設計師

如果你是有自信的程式設計師，而且非常熟悉函式語言，那麼你可以在 [Learn X in Y minutes][learnxy] 上快速掌握語法概觀。

[Four Lectures on Standard ML][four-lectures] 是很好的入門。
