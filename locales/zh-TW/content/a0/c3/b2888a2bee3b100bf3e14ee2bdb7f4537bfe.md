# 簡介

C# 中有兩種不同的數字型別：

- 整數：小數分隔符號後面沒有數字的數字（也就是沒有小數部分的數）。例如`-6`、`0`、`1`、`25`、`976`和`500000`。
- 浮點數：小數分隔符號後面有零個或多個位數的數字。例如`-2.4`、`0.1`、`3.14`、`16.984025`和`1024.0`。

C# 中最常見的兩種數字型別是`int`和`double`。`int`是 32 位元整數，`double`則是 64 位元的浮點數。

算術運算使用標準的算術運算子來完成。數字可以使用標準的數值比較運算子，以及相等（`==`）和不等（`!=`）運算子來比較。

C# 有兩種數值轉換：

1. 隱含轉換：不會遺失任何資料，也不需要額外的語法。
2. 明確轉換：資料可能會遺失，且需要額外的語法，也就是_轉型_。

由於`int`的精確度比`double`低，因此從`int`轉換成`double`是安全的，屬於隱含轉換。不過，從`double`轉換成`int`可能代表會遺失資料，因此需要明確轉換。

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
