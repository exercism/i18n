# 指令補充

## 暫存器

| 暫存器 | 用途         | 型別    | 說明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 輸入         | 位址    | 以 null 結尾的輸入字串        |
| `$a1`    | 輸入         | 整數    | 位移量                        |
| `$a2`    | 輸入/輸出    | 位址    | 以 null 結尾的結果字串        |
| `$t0-9`  | 暫時         | 任意    | 供暫時儲存使用                |
