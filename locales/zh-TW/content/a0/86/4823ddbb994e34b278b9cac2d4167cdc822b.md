# 補充說明

## 在 Prolog 中處理日期

Prolog 對日期的內建支援[相當基本][built-in-dates-support]。處理日期更優雅的方式，是使用 [date_time 套件][date_time-package]。

### 安裝 date_time 套件

如果你安裝的 Swipl 版本夠新，可以執行下列指令來安裝這個套件：

```bash
swipl pack install date_time
```

如果這樣行不通，可以改成執行：

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
如果你使用的是線上編輯器，就不需要手動安裝任何東西。
~~~~

### 使用 date_time 套件

在解答檔案的最前面加入下列程式碼，就能使用`date_time`套件：

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
提示：date_time 套件的[原始碼][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src]有完整的說明文件，會是很大的幫助！
~~~~
