# 簡介

在 Haxe 中，**陣列**是一組（通常）型別相同的元素集合。在 Haxe 裡有三種建立陣列的方式：可以透過建構子，也可以使用宣告語法。在 Haxe 中，陣列第一個元素的索引是零：

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

如果想用建構子建立陣列，你需要傳入要放進陣列裡的元素型別：

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

如果我們想讓陣列包含多種型別的元素，就在型別標註中加上 `Dynamic` 型別：

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
