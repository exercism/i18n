# 資源

Lua 有許多很棒的免費線上資源，包括：

1.  [lua.org][8]
2.  由 Lua 首席架構師撰寫、極力推薦、詳盡且具權威性的 Lua 程式設計全方位介紹：[Programming in Lua, by Roberto Ierusalimschy][6]
3.  若要查閱 Lua 語言的官方定義，請參考由 R. Ierusalimschy、L. H. de Figueiredo、W. Celes 撰寫的 [Lua 5.4 Reference Manual][7]。
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  雖然 [lua-users.org][14] wiki 看起來不太美觀，但裡面有許多有用的資訊與知識
7.  一些 lint 的選項
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Lua 的 Language Server Protocol 實作
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
