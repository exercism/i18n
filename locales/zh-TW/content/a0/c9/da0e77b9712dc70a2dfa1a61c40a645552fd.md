# 指令

附近有一間叫做「Tech Palace」的電器行。
老闆最近裝了一台大型顯示器，用來播放行銷訊息，並在顧客於入口掃描會員卡時顯示特別的問候語。
這台顯示器由許多小 LED 燈組成，可以顯示多行文字。

老闆需要你幫忙處理用來產生新顯示器文字內容的程式碼。

## 1. 建立歡迎訊息

<!-- markdownlint-disable-next-line MD038 -->
對大多數掃描會員卡的顧客，老闆希望顯示器顯示 `Welcome to the Tech Palace, ` 後面接著顧客名字的大寫字母。

實作函式 `welcome_message`，它接受顧客的名字作為短字串（`felt252`）引數，並回傳所需的訊息作為`ByteArray`。

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. 加上花俏的邊框

對於經常在店裡大量消費的忠實顧客，老闆想在歡迎訊息前後各加一行星星，讓歡迎畫面更花俏。
他們還不確定每行應該要有幾顆星星，所以希望這個數量可以設定。

寫一個函式 `add_border`，接受一段歡迎訊息（`ByteArray`）和每行的星星數量（型別`u32`）作為引數。
它應該回傳一個由 3 行組成的`ByteArray`：先是一行包含指定數量的星星，接著是原本傳入的歡迎訊息，然後再一行星星。

```rust
add_border("Welcome!", 10)
```

應該回傳以下內容：

```bash
**********
Welcome!
**********
```

## 3. 清理舊的行銷訊息

在安裝這台新顯示器之前，店裡有一台類似的顯示器，只能顯示無法設定、固定不變的文字行。
老闆想在新顯示器上重複使用一些舊的行銷訊息。
不過，這些資料本身已經包含了星星邊框，還有一些多餘的空白。
你的任務是清理這些訊息，讓它們能夠被重複使用。

實作函式 `clean_up_message`，接受舊的行銷訊息作為`ByteArray`。
這個函式應該先移除文字中所有的星星，接著移除剩餘文字開頭與結尾的空白。
然後，函式應該回傳清理後的訊息。

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
