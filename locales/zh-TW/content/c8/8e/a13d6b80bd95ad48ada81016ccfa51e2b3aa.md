# 基礎

一個 Sather 程式由內含**常式**的**類別**組成。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## 類別

類別名稱使用大寫字母，字與字之間用底線：
`GREETER`、`STAGE_DIRECTIONS`。檔案名稱通常會對應，但使用小寫：`stage_directions.sa`。

每個常式都位於類別內。類別外沒有任何程式碼。

## 常式

會產生結果的常式會在冒號後宣告結果的型別：

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR`是文字的型別。不接受引數的常式在定義和呼叫時都不加括號。

常式可以接受引數，寫在名稱後面的括號裡：

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return`會把結果交回，並立刻停止常式，因此它下面的任何程式行都會被跳過。

## 呼叫

從類別外部呼叫時，先寫類別名稱，接著寫`::`，再寫常式名稱：

```sather
GREETER::hello
```

從同一個類別內部呼叫時，可以省略類別名稱。這是讓一個常式使用另一個常式的常見做法：

```sather
   greeting_again : STR is
      return hello;
   end;
```

## 註解

兩個連字號會開始一段持續到行尾的註解。

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

依照慣例，類別會以註解結尾，寫出它的名稱。常式、迴圈和類別都以`end;`結束，所以註解會指出這個`end;`屬於哪一個：

```sather
end; -- class GREETER
```

## 分號

敘述以分號結尾。常式中最後一個敘述後的分號可以省略，但每次都寫分號，就能少一件需要思考的事。
