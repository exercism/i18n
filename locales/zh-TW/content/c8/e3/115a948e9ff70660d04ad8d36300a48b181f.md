# Instructions append

## 打造你自己的 DSL

在這個練習中，你可以完全自由地設計你理想中的圖形 DSL。

也許你想建立一個以標籤和記錄清單為基礎的 DSL，就像這樣：

```roc
my_graph =
    Graph.create([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

或者你偏好以函式呼叫鏈為基礎的 DSL，就像這樣：

```roc
my_graph =
    Graph.create()
        .with_title("My Graph")
        .add_node("a", Attr.create().with_color(Green))
        ...
```

又或者你完全有別的想法？放手去做吧！測試只要求你建立幾個特定的圖形，至於要怎麼建立，完全由你決定。

話說回來，一個 DSL 如果能做到清楚、簡潔，又不會太出乎意料，通常會更好（例如 `minus`函式的用途是相減，而不是在兩個節點之間建立邊，像`node("a") - node("b")`這樣）。

想讓樂趣加倍的話，你還可以試著實作一個`to_dot`函式，把你的圖形轉換成 DOT 格式！
