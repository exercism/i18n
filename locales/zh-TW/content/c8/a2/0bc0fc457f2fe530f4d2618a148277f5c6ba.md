# 說明

在這個練習中，你需要實作一些函式來操作程式語言陣列。

## 1. 定義一個函式來回傳空的程式語言陣列

定義`language_list`函式，它不接受任何引數，並回傳一個空的陣列。

```php
<?php

language_list();
// => []
```

## 2. 修改函式，讓它能從任意數量的程式語言建立陣列

修改`language_list`函式，讓它接受可變數量的程式語言引數（字串）。它應該回傳包含這些程式語言的陣列。

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. 定義一個函式來將程式語言加入陣列

定義`add_to_language_list`函式，它接受 2 個引數：一個程式語言陣列，以及新的程式語言。

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. 定義一個函式來從程式語言陣列中移除項目

定義`prune_language_list`函式，以從程式語言陣列中移除第一個程式語言。

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. 定義一個函式來取得陣列中的第一個項目

定義`current_language`函式，它接受 1 個引數（一個_程式語言陣列_）。
它應該回傳陣列中的第一個程式語言。
假設陣列中至少會有一個項目。

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. 定義一個函式來回傳陣列中有多少個程式語言

定義`language_list_length`函式，它接受 1 個引數（一個_程式語言陣列_）。
它應該回傳陣列中程式語言的數量。

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
