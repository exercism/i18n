# 簡介

迴圈基本上分成兩種：

1. 迴圈直到某個條件成立為止。
2. 逐一走訪集合中的元素。

Julia 兩種都支援，不過第二種可能更常見。

## `while`迴圈

對於次數事先無法確定、沒有明確終點的問題，Julia 提供了`while`迴圈。

基本形式相當簡單：

```julia
while condition
    do_something()
end
```

在這種情況下，程式會一直繞著迴圈執行，直到`condition`不再是`true`為止。

有兩種方式可以提早離開迴圈：

- `break`會讓迴圈結束，並從迴圈`end`之後的下一行繼續執行。
- `return x`會停止目前函式的執行，並把回傳值`x`交還給呼叫方。

有了這些選擇，有時候用`while true ... end`建立一個「無限」迴圈會很方便，接著只要在迴圈主體裡找到停止條件，就能觸發`break`或`return`。

## 走訪集合

最簡單的例子是走訪一段範圍。

如果我們想把某件事做 10 次：

```julia
for n in 1:10
    do_something(n)
end
```

如果目前這一輪疊代不符合某個條件，可以用`continue`直接跳到下一輪疊代：

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

寫得更精簡的話，這個`if`區塊可以換成`is_useless(n) && continue`。

還有許多其他型別的集合可以走訪：陣列裡的元素、字串裡的字元、字典裡的鍵……

到目前為止的例子都是走訪範圍`1:10`，其中的值同時也是迴圈索引。

更一般來說，我們可能需要索引，而不只是值。這時就要用`eachindex()`函式，例如`for i in eachindex(my_array) ... end`。
