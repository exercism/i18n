# 說明

Josh 正在開發一款新的角色扮演遊戲，需要你幫忙實作其中一些機制。

## 1. 定義聯合型別

定義一個由`String`和`Missing`組成的聯合型別，命名為`StringOrMissing`，以便在之後的程式碼中使用。
定義一個由`Int64`和`Nothing`組成的聯合型別，命名為`IntOrNothing`，以便在之後的程式碼中使用。

## 2. 實作 Player 複合型別

Player 複合型別應該包含四個欄位，每個欄位都有型別標註與預設值：
- `name` 是 `StringOrMissing`，預設值為 `missing`
- `level` 是 `Int64`，預設值為 `0`
- `health` 是 `Int64`，預設值為 `100`
- `mana` 是 `IntOrNothing`，預設值為 `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. 自我介紹

實作`introduce`函式。

隱匿行蹤的玩家可能隱藏了自己的名字，此時會以`"Mighty Magician"`來介紹他們。
否則，就直接用玩家的名字來介紹他們。

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. 實作 increment 方法

`increment`輔助函式有兩個方法，每個方法的函式簽章都不同。
每個方法的引數都需要型別標註，讓簽章明確。

處理名字的`increment`方法應該接收玩家的`name`。
- 如果名字是`missing`，就回傳稱號 "The Great"。
- 否則就把稱號 " the Great" 加到名字後面。

這個`increment`方法會回傳新的名字。

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

處理 mana 的`increment`方法應該接收玩家的`mana`。
- 如果玩家的 mana 是`missing`，就回傳值`50`。
- 否則 mana 應該增加`100`。

這個`increment`方法會回傳更新後的 mana。

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. 實作 title! 函式

遊戲中的最高等級是`42`。為了表揚達成這個等級的玩家，他們的名字會被加上一個稱號。`title!`函式會依照以下方式更新玩家的名字。

- 如果玩家的等級是 42，就會用`increment`函式更新名字。
- 否則名字保持不變。

無論哪種情況，`title!`函式都會回傳玩家的名字。

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. 實作 revive! 函式

`revive!`函式應該檢查玩家的角色是否真的死亡（生命值已經降到`0`）。

如果玩家已經死亡：
- 玩家應該以`100`點生命值復活。
- 玩家的 mana 應該用`increment`函式來增加。

如果玩家還活著，則不會發生任何事。

`revive!`函式應該回傳玩家。

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
