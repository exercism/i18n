# 說明

你的朋友 Li Mei 經營一家果汁吧，販售美味的綜合果汁。你是她店裡的常客，發現可以用一些 Factor 程式碼讓她的生活輕鬆一點。

## 1. 判斷調製一杯果汁需要多久

Li Mei 喜歡事先告訴客人，他們點菜單上的果汁要等多久。她很難記住確切的數字，因為調製每種果汁所需的時間各不相同：

- `"Pure Strawberry Joy"`需要`0.5`分鐘。
- `"Energizer"`與`"Green Garden"`各需要`1.5`分鐘。
- `"Tropical Island"`需要`3`分鐘。
- `"All or Nothing"`需要`5`分鐘。
- 其他所有飲料（例如特價品）需要`2.5`分鐘。

定義`time-to-mix-juice`，從堆疊取出果汁名稱，並回傳調製該飲料所需的分鐘數。

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. 補充萊姆角庫存

Li Mei 的許多創作都會用到萊姆角，無論是作為材料還是裝飾的一部分。所以她早上開始值班時，必須確保萊姆角儲備箱是滿的，足以應付接下來的一天。

定義`wedges-from-lime`，接收萊姆大小並回傳能切出的萊姆角數量：`"small"`萊姆可切出`6`個，`"medium"`可切出`8`個，`"large"`則可切出`10`個。

接著定義`limes-to-cut`，接收需要的萊姆角數量（`needed`）與一個`limes`陣列（依切開順序排列的萊姆大小）。它會依序一顆一顆切開萊姆，一旦切出足夠的萊姆角，或萊姆用完，就立刻停止。回傳它總共必須切開幾顆萊姆。

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. 列出佇列中每筆訂單的調製時間

Li Mei 喜歡掌握調製客人等待中的飲料需要多少時間。

定義`order-times`，接收一個訂單陣列，並回傳一個包含每筆訂單調製時間的陣列，順序與原陣列相同。

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. 結束值班

Li Mei 總是工作到下午 3 點，之後由她的員工 Dmitry 接手。Li Mei 值班結束時，經常還有已經點好但還沒調製的飲料；這時 Dmitry 會負責調製剩下的果汁。

為了讓交接更順利，定義`remaining-orders`，接收 Li Mei 值班剩餘的分鐘數（`time-left`）與一個`orders`陣列（已點好但還沒調製的果汁）。回傳 Dmitry 需要接手的訂單，也就是 Li Mei 在值班結束前來不及開始的那些。

`time-left`一律大於`0`。訂單會依它們在陣列中出現的順序調製。Li Mei 一旦開始調製一杯果汁，就一定會完成，即使得多工作一會兒。如果她有時間開始每一筆訂單，就回傳一個空陣列。

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
