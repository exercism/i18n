# 關於

在 F# 中處理數字時，其中一個關鍵環節就是要區分整數（小數分隔符號後沒有數字）與浮點數（小數分隔符號後有零或多個數字）。

F# 中最常用的兩種數值型別是 `int`（32 位元整數）與 `float`（64 位元浮點數）。

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

整數與浮點數都可以使用 `_` 字元作為_數字分隔符_，這在定義大數字時很有幫助：

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

算術運算使用標準的[算術運算子][arithmetic-operators]（`+`、`-`、`*` 等）。數字可以用[標準比較運算子][comparison-operators]（`<`、`>=` 等）以及相等（`=`）與不相等（`<>`）運算子來比較。

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

要在數值型別之間轉換，必須使用內建的[轉換運算子][conversion-operators]。這些運算子的名稱取自它們要轉換成的型別。

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

在型別之間轉換時，務必小心。如果某個值無法用目標型別表示，這個值就會_溢位_。
