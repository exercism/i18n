# परिचय

## C++ में `auto` कीवर्ड

C++ में `auto` कीवर्ड एक शक्तिशाली सुविधा है, जिसे C++11 में जोड़ा गया था। इसका उपयोग ऐसे वेरिएबल घोषित करने के लिए किया जाता है जिनका डेटा टाइप अनुमान से तय होता है। कंपाइलर वेरिएबल के इनिशियलाइज़र को देखकर उसका टाइप निकालता है। इससे कोड पढ़ने में आसान और बनाए रखने में सरल बन जाता है।

## उपयोग का उदाहरण

नीचे दिए उदाहरण में देखिए कि `auto` से वेरिएबल कैसे घोषित किए जाते हैं:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

हर मामले में वेरिएबल का टाइप उस वैल्यू से अनुमान लगाया जाता है जिससे उसे इनिशियलाइज़ किया गया है।

## टाइप अनुमान

`auto` कीवर्ड स्पष्ट टाइप लिखने की भरमार घटाता है, जिससे कोड छोटा और पढ़ने में आसान बनता है।

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

इस उदाहरण में `auto`, `purple_wedding_pie` का टाइप `std::vector<std::string>` मान लेता है, इसलिए टाइप को दोबारा स्पष्ट रूप से लिखने की ज़रूरत नहीं पड़ती।

## अनुकूलता

`auto` कीवर्ड C++ की कई तरह की रचनाओं के साथ काम करता है, इसलिए आधुनिक C++ प्रोग्रामिंग में यह एक बहुमुखी टूल है।

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

आगे के कॉन्सेप्ट में हम `auto` कीवर्ड को लैम्ब्डा एक्सप्रेशन, रेंज-आधारित `for` लूप और इटरेटर के साथ अक्सर देखेंगे।
