# एब्सट्रैक्ट क्लास

सर्कस का शो करतबों की एक सूची है। जगलिंग, ट्रैपीज़ और टंबलिंग अलग-अलग चीज़ें हैं और उनका अंदरूनी हिस्सा भी अलग है, लेकिन शो का क्रम तय करने वाले व्यक्ति को हर एक से सिर्फ दो चीज़ें चाहिए: उसका नाम क्या है, और वह कितना समय लेता है।

एक **एब्सट्रैक्ट क्लास** बस इतना ही बताती है, इससे ज़्यादा कुछ नहीं।

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

इसका नाम `$` से शुरू होता है। यह उन रूटीन की सूची देती है जिनकी कोई बॉडी नहीं होती: सिर्फ सिग्नेचर, और हर एक सेमीकोलन पर खत्म होता है। इससे कुछ भी बनाया नहीं जा सकता। इसमें न `create` है और न `new`.

## अनुरूपता

एक असली क्लास `<` के बाद नाम लिखकर वादा करती है कि वह एक `$ACT` है:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` को "एक है" पढ़ा जाता है। क्लास को हर वह रूटीन देना ही होगा जो एब्सट्रैक्ट क्लास में लिखा है, वही आर्गुमेंट और वही रिटर्न टाइप के साथ। किसी एक को छोड़ देने पर कंपाइल एरर मिलती है, चलने के समय कोई अचानक आश्चर्य नहीं।

क्लास चाहे तो इसके अलावा और कुछ भी जोड़ सकती है। `TRAPEZE` ऐसी ऊँचाई रख सकती है जो किसी और करतब के पास नहीं है। एब्सट्रैक्ट क्लास न यह जानती है, न इसकी परवाह करती है।

## टाइप का उपयोग

`$ACT` एक टाइप है, इसलिए इससे किसी भी चीज़ को घोषित किया जा सकता है:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

वह ऐरे एक साथ तीन अलग-अलग क्लास के ऑब्जेक्ट रखता है, जो `ARRAY{JUGGLING}` नहीं कर सकता।

## डिस्पैच

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` एक `$ACT` है। कौन-सा `minutes` चलेगा, यह वह लाइन चलने के समय तय होता है। यह इस पर निर्भर करता है कि ऑब्जेक्ट असल में क्या है: जगलिंग के लिए `JUGGLING::minutes`, ट्रैपीज़ के लिए `TRAPEZE::minutes`. उस चुनाव को **डिस्पैच** कहते हैं।

जोड़ने वाला रूटीन कभी यह नहीं पूछता कि उसके पास किस तरह का करतब है। चौथी तरह का करतब जोड़ने का मतलब है एक नई क्लास लिखना, और बाकी कुछ भी न बदलना। इसी वजह से यह तरीका अपनाया जाता है।
