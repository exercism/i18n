# निर्देश परिशिष्ट

## आउटपुट का प्रारूप

प्रोटीन अनुक्रम को null पर समाप्त होने वाली स्ट्रिंग के रूप में दीजिए। हर प्रोटीन के बाद एक नई लाइन का अक्षर आना चाहिए।

एक उदाहरण आउटपुट इस तरह होगा: `"Methionine\nPhenylalanine\nSerine\n"`

अगर इनपुट अमान्य हो, तो एक खाली स्ट्रिंग दीजिए।

## रजिस्टर

| रजिस्टर | उपयोग | प्रकार | विवरण |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | एड्रेस | null पर समाप्त होने वाली इनपुट स्ट्रिंग  |
| `$a1`    | इनपुट/आउटपुट | एड्रेस | null पर समाप्त होने वाली आउटपुट स्ट्रिंग |
| `$t0-9`  | अस्थायी      | कोई भी | अस्थायी भंडारण के लिए इस्तेमाल    |
