# परिचय

Gleam की स्टैंडर्ड लाइब्रेरी में मौजूद `gleam/order` मॉड्यूल में `Order` टाइप होता है, जिससे वैल्यू की तुलना की जाती है।

`Order` की परिभाषा कुछ इस तरह है:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

इस टाइप के तीन वेरिएंट होते हैं। इनमें से हर वेरिएंट एक वैल्यू और दूसरी वैल्यू के बीच के संबंध को दर्शाता है:

- `Gt` - वैल्यू दूसरी वैल्यू से _बड़ी_ होती है।
- `Eq` - वैल्यू दूसरी वैल्यू के _बराबर_ होती है।
- `Lt` - वैल्यू दूसरी वैल्यू से _छोटी_ होती है।

अगर किसी डेटा टाइप की तुलना आकार के आधार पर की जा सकती है, तो उस मॉड्यूल में आम तौर पर एक `compare` फंक्शन बनाया जाता है, जो एक `Order` वैल्यू लौटाता है। उदाहरण के लिए, `gleam/float` और `gleam/int` में ऐसे `compare` फंक्शन बनाए गए हैं जो क्रमशः दशमलव संख्याओं और पूर्णांकों पर काम करते हैं।

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

क्रम में लगाने वाले फंक्शन, जैसे `list.sort`, आम तौर पर ऐसा फंक्शन लेते हैं जो एक `Order` वैल्यू लौटाता है। इससे कॉल करने वाला तय कर सकता है कि ऐरे को किस क्रम में लगाया जाए।

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
