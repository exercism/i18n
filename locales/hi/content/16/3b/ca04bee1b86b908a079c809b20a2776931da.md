अगर आप इसे स्वीकार करना चाहें, तो आपका मिशन यह है: आपको UMBRA (United Minions Being Really Awful) के मुख्यालय में घुसना है और उनके ताज़ा, बेहद खतरनाक षड्यंत्र की योजनाएँ निकाल लानी हैं। इस मिशन को पूरा करने के लिए आपको दो टूल लिखने होंगे।

## 1. प्राप्त गुप्त योजनाओं को पासवर्ड से सुरक्षित कीजिए

गुप्त योजनाएँ मिल जाने के बाद आपको उन्हें ऐसे सुरक्षित करना होगा कि सिर्फ वही लोग उन्हें वापस पा सकें जिन्हें पासवर्ड पता है।

इसके लिए आपको यह फंक्शन बनाना होगा: `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`. यह फंक्शन एक और फंक्शन लौटाता है, जो इनपुट के रूप में संभावित पासवर्ड स्ट्रिंग लेता है। अगर दिया गया पासवर्ड सही है, तो नया फंक्शन छिपा हुआ रहस्य लौटाता है। अगर पासवर्ड गलत है, तो यह फंक्शन "Sorry. No hidden secrets here." लौटाता है।

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. उनकी तिजोरी खोलने का कॉम्बिनेशन बनाइए

हमें पता चला है कि UMBRA अपने ठिकानों की तिजोरियों के सारे कॉम्बिनेशन उस कमरे के नंबर के आधार पर बनाती है जिसमें वह ठिकाना होता है। तिजोरी के कॉम्बिनेशन कमरे के नंबर पर बार-बार एक खास फंक्शन लगाकर बनाए जाते हैं। यानी कॉम्बिनेशन का पहला नंबर कमरे के नंबर पर फंक्शन लगाने से मिलेगा, दूसरा पहले नंबर पर फंक्शन लगाने से, और तीसरा दूसरे नंबर पर फंक्शन लगाने से।

लेकिन UMBRA कॉम्बिनेशन बनाने में इस्तेमाल होने वाला फंक्शन समय-समय पर बदलती रहती है, इसलिए कॉम्बिनेशन बनाने के लिए आपके टूल को कमरे का नंबर और उपयुक्त फंक्शन, दोनों लेने होंगे।

जो कॉम्बिनेशन आपको चाहिए होगा, उसे बनाने के लिए यह फंक्शन बनाइए: `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)`.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
