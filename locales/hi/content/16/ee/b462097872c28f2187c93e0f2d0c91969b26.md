# परिचय

Go में, `struct` नामित एलिमेंटों का एक क्रम होता है, जिन्हें _फील्ड_ कहते हैं। हर फील्ड का एक नाम और एक टाइप होता है। किसी `struct` के अंदर फील्ड का नाम अद्वितीय होना चाहिए। ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग में `struct` की तुलना _क्लास_ से की जा सकती है।

## `struct` को परिभाषित करना

आप `type` और `struct` कीवर्ड का उपयोग करके नया `struct` बनाते हैं, और फील्डों के नाम और टाइप को स्पष्ट रूप से परिभाषित करते हैं। उदाहरण के लिए, यहाँ हम `Shape` नामक `struct` परिभाषित करते हैं, जिसमें किसी आकृति का नाम और उसका आकार रखा जाता है:

```go
type Shape struct {
    name string
    size int
}
```

`struct` में फील्डों के नाम Go के कन्वेंशन का पालन करते हैं। जिन फील्डों का नाम छोटे अक्षर से शुरू होता है, वे केवल उसी पैकेज के कोड को दिखाई देते हैं। जबकि जिन फील्डों का नाम बड़े अक्षर से शुरू होता है, वे दूसरे पैकेजों में भी दिखाई देते हैं।

## `struct` के इंस्टेंस बनाना

एक बार जब आप `struct` परिभाषित कर लेते हैं, तो आपको फील्डों के नाम का उपयोग करके किसी भी क्रम में फील्डों को परिभाषित करते हुए नया इंस्टेंस बनाना होता है:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

इंस्टेंस के फील्डों को पढ़ने या बदलने के लिए, `.` नोटेशन का उपयोग कीजिए:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

जिन फील्डों को कोई प्रारंभिक वैल्यू असाइन नहीं की गई होती, उनकी शून्य वैल्यू होती है। उदाहरण के लिए:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

आप फील्डों के नामों का उपयोग किए बिना भी `struct` का इंस्टेंस बना सकते हैं, बशर्ते आप फील्डों को _क्रम में_ परिभाषित करें:

```go
s := Shape {
	"Oval",
	20,
}
```

लेकिन, इस सिंटैक्स को _नाज़ुक कोड_ माना जाता है, क्योंकि जब कोई फील्ड जोड़ा जाता है, तो यह टूट सकता है, खासकर तब जब नए फील्ड का टाइप अलग हो। नीचे दिए उदाहरण में हम `Shape` में एक अतिरिक्त फील्ड जोड़ते हैं:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## "`New`" फंक्शन

कभी-कभी ऐसे फंक्शन होना अच्छा लगता है जो हमें `struct` के इंस्टेंस बनाने में मदद करें। परंपरागत रूप से, इन फंक्शनों को आमतौर पर `New` कहा जाता है या उनके नाम `New` से शुरू होते हैं, लेकिन चूँकि ये सिर्फ साधारण फंक्शन हैं, आप इन्हें कोई भी नाम दे सकते हैं। ये आपको दूसरी भाषाओं के कंस्ट्रक्टर की याद दिला सकते हैं, लेकिन Go में ये सिर्फ साधारण फंक्शन हैं।

नीचे दिए उदाहरण में, इनमें से एक `New` फंक्शन का उपयोग `Shape` का नया इंस्टेंस बनाने और आकृति के `size` के लिए स्वतः एक डिफ़ॉल्ट वैल्यू सेट करने के लिए किया गया है:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New` फंक्शनों का उपयोग करने के निम्नलिखित लाभ हो सकते हैं:

* दी गई वैल्यू की जाँच
* डिफ़ॉल्ट वैल्यू को संभालना
* चूँकि `New` फंक्शन अक्सर उन `struct` के उसी पैकेज में घोषित किए जाते हैं जिन्हें वे इनिशियलाइज़ करते हैं, वे `struct` के प्राइवेट फील्डों को भी इनिशियलाइज़ कर सकते हैं
