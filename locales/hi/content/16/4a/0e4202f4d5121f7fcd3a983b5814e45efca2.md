# परिचय

बहुत से प्रोग्राम को वास्तविक दुनिया की घटनाओं का अनुकरण करने के लिए (_दिखने में_) यादृच्छिक वैल्यू चाहिए।

आम और परिचित उदाहरण इस प्रकार हैं:
- सिक्का उछालना: `('Heads', 'Tails')` में से एक यादृच्छिक वैल्यू।
- पासा फेंकना: 1 से 6 के बीच एक यादृच्छिक पूर्णांक।
- ताश की गड्डी फेंटना: कार्डों के ऐरे का एक यादृच्छिक क्रम।
- 3-D ग्राफिक्स सिमुलेशन में पेड़ों और झाड़ियों का बनना।

कंप्यूटर से _वास्तव में_ यादृच्छिक वैल्यू बनाना एक [आश्चर्यजनक रूप से कठिन तकनीकी चुनौती][truly-random] है। इसीलिए ऐसे परिणामों को "स्यूडोरैंडम" कहा जाता है।

व्यवहार में, Python की मानक लाइब्रेरी के [`random`][random] मॉड्यूल जैसी अच्छी तरह बनाई गई लाइब्रेरी तेज़ और लचीली होती है, और मॉडलिंग, सिमुलेशन तथा गेम जैसे ज़्यादातर कामों के लिए पर्याप्त रूप से अच्छे परिणाम देती है।

इस संक्षिप्त परिचय में हम इस मॉड्यूल के सबसे अधिक उपयोग किए जाने वाले चार फंक्शन दिखाते हैं।
हम आपको प्रोत्साहित करते हैं कि आप [`random`][random] का पूरा डॉक्यूमेंटेशन देखें, क्योंकि इसमें बहुत से टूल और विकल्प हैं।

इसके बजाय Python [`secrets`][secrets] मॉड्यूल देता है।

secrets मॉड्यूल बनाने के पीछे के कुछ पुराने मुद्दे और कारण [PEP 506][PEP 506] में मिल सकते हैं।

`random` मॉड्यूल के टूल इस्तेमाल करने से पहले आपको इसे इंपोर्ट करना होगा:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

मॉड्यूल का नाम बार-बार लिखने से बचने के लिए, आप कुछ फंक्शन उनके नाम से इंपोर्ट कर सकते हैं:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` और `randint()`

ऊपर के पहले उदाहरण में दिखाया गया है कि `randrange()` फंक्शन के तीन रूप हैं:

1. `randrange(stop)` एक ऐसा पूर्णांक `n` देता है जिसके लिए `0 <= n < stop` हो
2. `randrange(start, stop)` एक ऐसा पूर्णांक `n` देता है जिसके लिए `start <= n < stop` हो
3. `randrange(start, stop, step)` एक ऐसा पूर्णांक `n` देता है जिसके लिए `start <= n < stop` हो
    और `n` इस क्रम में हो: `start, start + step, start + 2*step...`

सबसे आम स्थिति, जहाँ `step == 1` हो, के लिए `randint(a, b)` ज़्यादा सुविधाजनक और पढ़ने में आसान हो सकता है।
`randint()` से मिलने वाले संभावित परिणामों में ऊपरी सीमा भी _शामिल_ होती है, इसलिए `randint(a, b)` का मतलब `randrange(a, b+1)` इस्तेमाल करने जैसा ही है।



## `choice()` और `choices()`

ये दोनों फंक्शन यह मान लेते हैं कि आप किसी [अनुक्रम][sequence-types] या ऐसे ही किसी कंटेनर से शुरू कर रहे हैं।
यह आमतौर पर एक `list` होगा, या कुछ सीमाओं के साथ एक `tuple` या `set` हो सकता है (_एक `tuple` अपरिवर्तनीय होता है, और `set` का कोई क्रम नहीं होता_)।

`choice()` फंक्शन दिए गए अनुक्रम में से यादृच्छिक रूप से चुना गया एक सदस्य लौटाता है, और `choices()` दिए गए अनुक्रम में से यादृच्छिक रूप से चुने गए निर्दिष्ट संख्या के सदस्य (`k`) लौटाता है।
ऊपर दिखाए गए उदाहरणों में हमने एक निष्पक्ष सिक्का माना था, जिसमें हेड्स और टेल्स की संभावना बराबर थी, लेकिन वेट भी दिए जा सकते हैं।

उदाहरण के लिए, यदि किसी थैले में 10 लाल गेंदें और 15 हरी गेंदें हैं, और हम यादृच्छिक रूप से एक निकालना चाहते हैं:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
