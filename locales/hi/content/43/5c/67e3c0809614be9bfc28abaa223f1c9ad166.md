# इंस्टॉलेशन

## Godot Engine इंस्टॉल कीजिए

GDScript ट्रैक [Godot Engine][godot-engine] पर बना है, जो Windows, Linux, macOS और Android पर चलता है।
अभी [स्थानीय रूप से काम करने][working-locally] के लिए टेस्ट रनर को Linux की ज़रूरत होती है।
इस ट्रैक के लिए Godot वर्ज़न 4.0 या उससे ऊपर ज़रूरी है।

इंस्टॉलेशन पूरा करने के बाद आप टर्मिनल में यह कमांड चलाकर जाँच सकते हैं कि CLI ठीक से इंस्टॉल हुआ है या नहीं:

```bash
godot --version
```

## Exercism GDScript ट्रैक का टेस्ट रनर इंस्टॉल कीजिए

टेस्ट रनर इस्तेमाल करने के लिए [Godot का ठीक से इंस्टॉल होना][installation] ज़रूरी है।

Exercism के लिए GDScript स्क्रिप्ट बनाने और उनका टेस्ट करने के लिए Godot को CLI से "headless" मोड में चलाया जाता है।
इन निर्देशों के लिए फिलहाल Linux और bash चाहिए।

### चरण 1: टेस्ट रनर की पूरी व्यवस्था इंस्टॉल कीजिए

टेस्टिंग की तैयारी के लिए [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] को क्लोन कीजिए और उसकी सामग्री `/opt/test-runner/` में ले जाइए:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### चरण 2: एक अभ्यास के लिए टेस्ट रनर स्क्रिप्ट डाउनलोड कीजिए

मान लीजिए कि आपने `exercism` टूल सेट कर लिया है और कम से कम एक GDScript अभ्यास डाउनलोड कर लिया है। उस स्थिति में आपके वर्कस्पेस के अंदर अभ्यासों को रखने के लिए एक `gdscript` फोल्डर बन चुका होगा (`exercism configure` चलाने पर यही दिखता है)।
[टेस्ट रनर][test-local-gdscript-solution] को इस फोल्डर में सहेजिए और उस फाइल को एक्ज़ीक्यूटेबल बनाइए।

## टेस्ट चलाइए

इंस्टॉलेशन के चरण पूरे हो जाने के बाद आप किसी भी अभ्यास डायरेक्टरी से शुरू कर सकते हैं, जैसे `~/exercism/gdscript/two-fer`। उस अभ्यास के अपने स्थानीय हल को टेस्ट करने के लिए उस स्क्रिप्ट को चलाइए, जो एक लेवल ऊपर यानी `../` में है:

```sh
../test-local-gdscript-solution.sh
```

## IDE का उपयोग कीजिए

[Visual Studio Code][vscode] जैसे एडिटर में GDScript का सिंटैक्स हाइलाइटिंग पाने के लिए आपको [godot-tools][godot-tools] जैसा एक्सटेंशन इंस्टॉल करना होगा और साथ में एक चलता हुआ डीबग सर्वर भी चाहिए।
जब भी कोई प्रोजेक्ट Godot के अपने ही एडिटर में खुला रहता है, Godot यह डीबग सर्वर अपने आप शुरू कर देता है और उसे तब तक चलाता रहता है जब तक प्रोजेक्ट या खुद Godot बंद न हो जाए।
