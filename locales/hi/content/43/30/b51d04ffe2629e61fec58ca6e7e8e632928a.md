# निर्देश

आपके आस-पास के एक स्थानीय स्कूल में छात्रों की एक बहुत सक्रिय संस्था है।
इस छात्र संस्था का संचालन एक अध्यक्ष करता है, और हर 2 साल में एक बार नया अध्यक्ष चुनने के लिए चुनाव होते हैं।
इस साल के चुनाव में तय हुआ कि वोट गिनने के लिए एक नई डिजिटल प्रणाली की ज़रूरत है।

यह नई प्रणाली बनाने में स्कूल को आपकी मदद चाहिए।

## 1. वोट काउंटर बनाइए

नई वोटिंग प्रणाली के लिए सबसे पहले जिन चीज़ों की ज़रूरत पड़ेगी, उनमें से एक है वोट काउंटर।
इस काउंटर की मदद से किसी एक उम्मीदवार को मिले वोटों का हिसाब रखा जा सकता है।

एक फंक्शन `new_vote_counter` बनाइए जो किसी उम्मीदवार के शुरुआती वोटों की संख्या लेता है और `VoteCounter` स्ट्रक्चर का एक स्नैपशॉट लौटाता है, जिसे दिए गए शुरुआती वोटों की संख्या के साथ शुरू किया गया हो।

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. काउंटर से वोटों की संख्या निकालिए

अब आपके पास नए काउंटर बनाने का तरीका है!
लेकिन अब आप देखते हैं कि नई प्रणाली को किसी काउंटर से वोटों की संख्या निकालने का तरीका भी चाहिए।

एक फंक्शन `vote_count` बनाइए जो एक काउंटर (`@VoteCounter`) को आर्गुमेंट के रूप में लेगा और उस काउंटर में मौजूद वोटों की संख्या लौटाएगा।

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. काउंटर के वोट बढ़ाइए

अब वोट गिनने का समय आ ही गया है!
अब आपको काउंटर में वोट बढ़ाने का तरीका चाहिए।

एक फंक्शन `increment_vote_count` बनाइए जो एक काउंटर (`@VoteCounter`) और वोटों की एक संख्या आर्गुमेंट के रूप में लेगा, और उस काउंटर को उतने वोटों से बढ़ा देगा।

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. चुनाव के परिणाम बनाइए

अब जब सारे वोट गिन लिए गए हैं, तो पूरे स्कूल को परिणाम सुनाने की तैयारी का समय आ गया है।
इसके लिए आप देखते हैं कि सिर्फ वोटों के काउंटर होना काफी नहीं है।
वोटों की संख्या को किसी खास उम्मीदवार से जोड़ने का तरीका भी होना चाहिए।

एक फंक्शन `new_election_result` बनाइए जो किसी उम्मीदवार का नाम और उसके वोटों की संख्या लेता है और एक नया चुनाव परिणाम लौटाता है।

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

चुनाव परिणाम का स्ट्रक्चर पहले से आपके लिए बनाया गया है और इसे इस तरह परिभाषित किया गया है:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. परिणाम घोषित कीजिए

अब स्कूल को नए अध्यक्ष की घोषणा करने का समय आ गया है!
नए अध्यक्ष की घोषणा स्कूल के छोटे डिजिटल मैसेज बोर्डों पर की जाएगी।

मैसेज में नए अध्यक्ष का नाम और उन्हें मिले वोट इस प्रारूप में दिखने चाहिए: `<candidate_name> (<votes>)`.
ऐसे मैसेज का एक उदाहरण यह है: `"Peter (51)"`.

एक फंक्शन `display_result` बनाइए जो एक `@ElectionResult` को आर्गुमेंट के रूप में लेगा और दिखाने वाला मैसेज एक `ByteArray` के रूप में लौटाएगा।

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. वोटों की दोबारा गिनती

अंतिम परिणाम सही हैं या नहीं, यह पक्का करने के लिए वोटों की दोबारा गिनती की गई।
दोबारा गिनती करने पर पता चला कि कुछ उम्मीदवारों के वोटों की संख्या में एक का अंतर था।

एक फंक्शन `decrement_votes_of_candidate` बनाइए जो अंतिम परिणाम और उस उम्मीदवार का नाम लेता है, जिसके वोटों की संख्या घटानी है।
अंतिम परिणाम `Felt252Dict<u32>` के रूप में दिए गए हैं, जिसमें कीज़ उम्मीदवारों के नाम हैं और वैल्यूज़ उनके कुल वोट हैं।

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
