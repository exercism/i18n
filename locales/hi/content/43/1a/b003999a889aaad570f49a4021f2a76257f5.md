# टेस्ट

अगर 8th बाइनरी आपके PATH में है, तो यह कमांड चलाइए:

```bash
8th -f test.8th
```

अगर 8th बाइनरी PATH में नहीं है, तो Windows में यह लिखिए:

```cmd
\path\to\8th -f test.8th
```

Linux या macOS में:

```bash
/path/to/8th -f test.8th
```

## REPL में टेस्ट चलाना

test-words.8th लोड करते हुए 8th शुरू कीजिए:

```sh
8th -f test-words.8th
```

इससे एक CLI सेशन शुरू होता है। जब आप अपनी हल फाइल में कुछ कोड लिख लेते हैं, तो उसे REPL में लोड कर सकते हैं।
उदाहरण के लिए, "word-count" अभ्यास के लिए आप यह लिखेंगे:

```8th
"word-count.8th" f:include
```

और टेस्ट चलाने के लिए आप यह लिख सकते हैं:
```sh
"word-count-tests.8th" f:include
```

या फिर आप उस फाइल से कोई एक टेस्ट कॉपी करके पेस्ट कर सकते हैं, या अपना खुद का लिख सकते हैं।

## छोड़े गए टेस्ट

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना।
डिफॉल्ट रूप से टेस्ट चलाने पर सिर्फ एक टेस्ट (पहला वाला) चलता है।
यह जानबूझकर ऐसा है, ताकि आपका ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर लगा रहे।
वह पास हो जाने के बाद आप `SKIP-REST-OF-TESTS` शब्द को उसके बाद ले जाकर अगला टेस्ट चालू कर सकते हैं।

## स्किप को ओवरराइड करना

सारे टेस्ट चलाने के लिए, उन टेस्टों समेत जो `SKIP-REST-OF-TESTS` शब्द के बाद आते हैं, आप एक एनवायरनमेंट वेरिएबल `RUN_ALL_TESTS` को `true` वैल्यू पर सेट कर सकते हैं।
इसे सिर्फ टेस्ट चलने की अवधि के लिए सेट करने का एक तरीका यह है (macOS और Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
