## AWK के नए कॉन्सेप्ट

GNU awk की कुछ दिलचस्प भाषा विशेषताओं को याद ताज़ा करने के लिए [`matrix` अभ्यास के निर्देश][ex-matrix] देखिए।

### फंक्शन को डायनैमिक रूप से कॉल करना

awk के फंक्शन first-class ऑब्जेक्ट नहीं होते। कुछ अन्य भाषाओं की तरह इन्हें एक जगह से दूसरी जगह पास नहीं किया जा सकता।
लेकिन एक वेरिएबल में किसी फंक्शन का _नाम_ (एक स्ट्रिंग) रखा जा सकता है, और फिर उस फंक्शन को एक खास `@varname(args)` नोटेशन से कॉल किया जाता है।
एक उदाहरण:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
इसका वर्णन [अप्रत्यक्ष फंक्शन कॉल][indirect] में किया गया है।
यह `gawk` का एक्सटेंशन है।
