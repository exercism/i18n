# परिचय

एक्सटेंशन मेथड की मदद से हम पहले से बने टाइपों में नए मेथड जोड़ सकते हैं, बिना कोई नया डेराइव्ड टाइप बनाए, बिना कोड दोबारा कंपाइल किए, और बिना मूल टाइप में कोई और बदलाव किए। इन्हें स्टैटिक मेथड के रूप में बनाया जाता है, लेकिन कॉल करने के लिए इंस्टेंस मेथड वाला तरीका इस्तेमाल किया जाता है। इनका पहला पैरामीटर `this` मॉडिफायर से शुरू होता है और बताता है कि यह मेथड किस टाइप पर काम करता है। इन्हें नेमस्पेस के स्तर पर स्कोप में लाया जाता है।

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
