# स्ट्रिंग

Crystal में [`String`][strings] नाम का एक टाइप होता है, जो टेक्स्ट को दर्शाने के लिए इस्तेमाल किया जाता है।
Crystal की स्ट्रिंग यूनिकोड अक्षरों का एक क्रम होती है।
स्ट्रिंग अपरिवर्तनीय होती हैं, यानी एक बार बन जाने के बाद उन्हें बदला नहीं जा सकता।
इसका मतलब है कि जब भी आप किसी स्ट्रिंग में बदलाव करते हैं, एक नई स्ट्रिंग बनती है। इसलिए मूल स्ट्रिंग नहीं बदलती।

स्ट्रिंग बनाने के लिए आप डबल कोट्स `"` का इस्तेमाल करते हैं।

```crystal
"Hello World"
```

## स्ट्रिंग जोड़ना

दो स्ट्रिंग जोड़ने के लिए `+` ऑपरेटर का इस्तेमाल कीजिए।
`+` ऑपरेटर दोनों स्ट्रिंग को मिलाकर एक नई स्ट्रिंग लौटाता है।

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## स्ट्रिंग और संख्याओं के बीच बातचीत

`to_i` मेथड स्ट्रिंग को पूर्णांक में बदल देता है।
वैकल्पिक रूप से, दशमलव संख्या पाने के लिए `to_f` मेथड इस्तेमाल की जा सकती है।
अगर स्ट्रिंग को संख्या में नहीं बदला जा सकता, तो `ArgumentError` फेंका जाता है।

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

किसी पूर्णांक या दशमलव संख्या को `to_s` मेथड की मदद से स्ट्रिंग में बदला जा सकता है।

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## इंटरपोलेशन

इंटरपोलेशन स्ट्रिंग जोड़ने और स्ट्रिंग के अंदर एक्सप्रेशन डालने का एक आसान तरीका है।
किसी स्ट्रिंग में इंटरपोलेशन करने के लिए `#` अक्षर के बाद घुंघराले ब्रैकेट `{}` लगाइए और उनके अंदर एक्सप्रेशन लिखिए।

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal एक्सप्रेशन के परिणाम को अपने आप स्ट्रिंग में बदल देता है।

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## आकार

जब आपको किसी स्ट्रिंग में अक्षरों की संख्या जाननी हो, तो `size` मेथड इस्तेमाल कीजिए, जो स्ट्रिंग की लंबाई पूर्णांक के रूप में लौटाता है।
स्ट्रिंग का आकार स्ट्रिंग में ही संग्रहीत एक प्रॉपर्टी होती है, इसलिए मेथड को कॉल करने पर हर बार आकार की गणना नहीं करनी पड़ती, और यह बहुत तेज़ होता है।

```crystal
"Hello World".size
# => 11
```

## इंडेक्सिंग

इंडेक्सिंग का मतलब है किसी स्ट्रिंग से कोई खास अक्षर निकालना।
किसी `String` से अक्षर निकालने के लिए आप ब्रैकेट वाला जाना-पहचाना तरीका इस्तेमाल कर सकते हैं।

~~~~exercism/note
`[]` एक String इंस्टेंस मेथड के रूप में लागू किया गया है, जिसमें इंडेक्स ही मेथड का आर्गुमेंट होता है।
~~~~

किसी स्ट्रिंग का पहला अक्षर इंडेक्स 0 पर होता है।

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

स्ट्रिंग के अंत से कोई अक्षर निकालने के लिए आप स्ट्रिंग की लंबाई में से एक घटाकर अंतिम अक्षर का इंडेक्स पा सकते हैं। अंत से दूसरे अक्षर के लिए लंबाई में से दो घटाइए, और इसी तरह आगे भी।
इसका एक छोटा तरीका भी है, और वह है बस ऋणात्मक इंडेक्स इस्तेमाल करना। इसमें अंतिम अक्षर का इंडेक्स -1 होता है, अंत से दूसरे अक्षर का -2, और इसी तरह आगे भी।

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## एस्केपिंग

कुछ अक्षर स्ट्रिंग में सीधे नहीं लिखे जा सकते। ऐसे में आपको एस्केप सीक्वेंस इस्तेमाल करना पड़ता है।
जैसे, अगर आप स्ट्रिंग में डबल कोट्स लिखना चाहते हैं, तो डबल कोट्स को एस्केप करना पड़ता है।
एस्केप सीक्वेंस लिखने के लिए `\` अक्षर इस्तेमाल कीजिए और उसके बाद वह अक्षर लिखिए जिसे एस्केप करना है।

Crystal में ये खास अक्षर हैं:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | अलर्ट                          |
| `\b`     | बैकस्पेस                       |
| `\e`     | एस्केप                         |
| `\f`     | फॉर्म फीड                      |
| `\n`     | लाइन फीड या नई लाइन             |
| `\r`     | कैरिज रिटर्न                    |
| `\t`     | आड़ा टैब                       |
| `\v`     | खड़ा टैब                       |
| `\\`     | बैकस्लैश                       |
| `\'`     | सिंगल कोट                      |
| `\"`     | डबल कोट                        |
| `\377`   | ऑक्टल ASCII अक्षर              |
| `\xFF`   | हेक्साडेसिमल ASCII अक्षर        |
| `\uFFFF` | हेक्साडेसिमल यूनिकोड अक्षर       |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## बहु-पंक्ति स्ट्रिंग

बहु-पंक्ति स्ट्रिंग लिखने के लिए वही सिंटैक्स इस्तेमाल कीजिए जो एक-पंक्ति स्ट्रिंग के लिए करते हैं, बस स्ट्रिंग में जितनी पंक्तियाँ चाहिए, उतनी बार नई लाइन लिखिए।

```crystal
"Hello
World"
# => "Hello\nWorld"
```
