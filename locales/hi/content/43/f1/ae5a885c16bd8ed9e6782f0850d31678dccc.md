# निर्देश

इस अभ्यास में आपको अपने नज़दीकी आर्केड हॉल के सबसे लोकप्रिय गेम के हाई स्कोर का हिसाब रखने का एक तरीका बनाना है।

आपको 7 फंक्शन बनाने हैं, जो सब हाई स्कोर के डेटा की एक डिक्शनरी लौटाने और उसमें बदलाव करने से जुड़े हैं।

## 1. नई हाई स्कोर डिक्शनरी बनाइए

एक फंक्शन `newScoreBoard()` बनाइए जो कोई पैरामीटर नहीं लेता और एक नई हाई स्कोर डिक्शनरी लौटाता है। इस डिक्शनरी में की `String` टाइप की होती हैं और वैल्यू `Int` टाइप की।

## 2. हाई स्कोर डिक्शनरी में खिलाड़ी जोड़िए

हाई स्कोर डिक्शनरी में एक खिलाड़ी जोड़ने के लिए `addPlayer(_:_:_:)` बनाइए। यह एक फंक्शन है जो 3 पैरामीटर लेता है:

- पहला पैरामीटर स्कोर की डिक्शनरी है।
    यह एक इन-आउट पैरामीटर होना चाहिए।
- दूसरा पैरामीटर खिलाड़ी का नाम है, जो एक स्ट्रिंग है।
- तीसरा पैरामीटर स्कोर है, जो एक पूर्णांक है।
    यह पैरामीटर वैकल्पिक है, इसे 0 की डिफॉल्ट वैल्यू के साथ बनाइए।

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. स्कोर डिक्शनरी से खिलाड़ियों को हटाइए

हाई स्कोर डिक्शनरी से किसी खिलाड़ी को हटाने के लिए `removePlayer(_:_:)` बनाइए, जो 2 पैरामीटर लेता है:

- पहला पैरामीटर स्कोर की डिक्शनरी है।
    यह एक इन-आउट पैरामीटर होना चाहिए।
- दूसरा पैरामीटर खिलाड़ी का नाम है, जो एक स्ट्रिंग है।

अगर खिलाड़ी डिक्शनरी में है, तो यह फंक्शन उसे डिक्शनरी से हटा दे। अगर नहीं है, तो कुछ नहीं होना चाहिए।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. किसी खिलाड़ी का स्कोर रीसेट कीजिए

किसी खिलाड़ी का स्कोर रीसेट करने के लिए `resetPlayer(_:_:)` बनाइए, जो 2 पैरामीटर लेता है:

- पहला पैरामीटर स्कोर की डिक्शनरी है।
    यह एक इन-आउट पैरामीटर होना चाहिए।
- दूसरा पैरामीटर खिलाड़ी का नाम है, जो एक स्ट्रिंग है और जिसका स्कोर आप रीसेट करना चाहते हैं।

यह फंक्शन खिलाड़ी का स्कोर 0 कर देता है।
अगर खिलाड़ी डिक्शनरी में नहीं है, तो कुछ नहीं होना चाहिए।

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. किसी खिलाड़ी का स्कोर अपडेट कीजिए

किसी खिलाड़ी का स्कोर उसके पिछले स्कोर में जोड़कर अपडेट करने के लिए `updateScore` बनाइए, जो 3 पैरामीटर लेता है:

- पहला पैरामीटर स्कोर की डिक्शनरी है। यह एक इन-आउट पैरामीटर होना चाहिए।
- दूसरा पैरामीटर खिलाड़ी का नाम है, जो एक स्ट्रिंग है और जिसका स्कोर आप अपडेट करना चाहते हैं।
- तीसरा पैरामीटर वह स्कोर है जिसे आप संग्रहीत हाई स्कोर में **जोड़ना** चाहते हैं।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. खिलाड़ी के नाम के अनुसार क्रम में लगी खिलाड़ियों की सूची पाइए

`orderByPlayers` फंक्शन बनाइए, जो 1 पैरामीटर लेता है:

- पहला पैरामीटर स्कोर की डिक्शनरी है।

यह फंक्शन `(String, Int)` टपल का एक ऐरे लौटाता है, जिनमें खिलाड़ी और उनके हाई स्कोर होते हैं और जो खिलाड़ी के नाम के अनुसार बढ़ते क्रम में लगे होते हैं।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. खिलाड़ी के स्कोर के अनुसार घटते क्रम में लगी खिलाड़ियों की सूची पाइए

खिलाड़ियों की सूची स्कोर के अनुसार घटते क्रम में पाने के लिए `orderByScores` बनाइए, जो 1 पैरामीटर लेता है:

- पहला पैरामीटर स्कोर की डिक्शनरी है।

यह फंक्शन `(String, Int)` टपल का एक ऐरे लौटाता है, जिनमें खिलाड़ी और उनके हाई स्कोर होते हैं और जो खिलाड़ी के स्कोर के अनुसार घटते क्रम में लगे होते हैं।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
