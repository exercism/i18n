# परिचय

## ऐरे

PHP में ऐरे क्रमित मैप होते हैं।
मैप एक डेटा स्ट्रक्चर है जो एक की को एक वैल्यू से जोड़ता है।
ऐरे बहुत लचीले होते हैं और इन्हें रैखिक ऐरे (जैसे `C` या `Java` में), सूची [वेक्टर], हैश-टेबल, डिक्शनरी, कलेक्शन, स्टैक या क्यू की तरह इस्तेमाल किया जा सकता है।

की देना ज़रूरी नहीं है, लेकिन अगर दी जाए तो वह `int` या `string` ही होनी चाहिए।
जब कोई की नहीं दी जाती, तो PHP डिफ़ॉल्ट रूप से बढ़ते क्रम में पूर्णांक की का इस्तेमाल करता है, जो `0` से शुरू होती हैं।

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

एक ऐरे सभी टाइप की वैल्यू संग्रहीत कर सकता है।
हर वैल्यू का टाइप अलग हो सकता है।

### ऐरे का उपयोग

ऐरे को लिटरल के रूप में घोषित किया जा सकता है (यानी ऊपर की तरह कोड में लिखकर) या फंक्शनों की मदद से बनाया और बदला जा सकता है।
इंडेक्स ऑपरेटर की मदद से वैल्यू एक्सेस कीजिए, असाइन कीजिए और जोड़िए:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

#### ऐरे के साथ काम करना

PHP में ऐसे फंक्शन दिए गए हैं जिनसे आप ऐरे में बदलाव कर सकते हैं और ऐरे के एलिमेंट के साथ काम कर सकते हैं।
PHP के डॉक्यूमेंटेशन में [ऐरे][array] फंक्शन के बारे में विस्तार से जानकारी मिलती है।

## परिवर्तनीय लंबाई के आर्गुमेंट

आप फंक्शन के आर्गुमेंट ऐसे लिख सकते हैं कि वह कितने भी आर्गुमेंट ले सके:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```

[array]: https://www.php.net/manual/en/language.types.array.php
