# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग      | प्रकार  | विवरण                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | पता     | null-टर्मिनेटेड नाम स्ट्रिंग    |
| `$a1`    | इनपुट        | पूर्णांक | संख्या                        |
| `$a2`    | इनपुट/आउटपुट | पता     | null-टर्मिनेटेड परिणाम स्ट्रिंग |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए          |
