# परिचय

[वेरिएडिक पैरामीटर][variadic-parameters] किसी फंक्शन को एक ही पैरामीटर के लिए निर्दिष्ट टाइप की शून्य या अधिक वैल्यू लेने देते हैं।
आप पैरामीटर के टाइप एनोटेशन के आगे तीन बिंदु (`...`) जोड़कर एक वेरिएडिक पैरामीटर बनाते हैं।

फंक्शन के अंदर Swift इन वैल्यू को निर्दिष्ट टाइप के एक ऐरे के रूप में उपलब्ध कराता है:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
अगर किसी फंक्शन में वेरिएडिक पैरामीटर के बाद और भी पैरामीटर आते हैं, तो वेरिएडिक पैरामीटर के बाद वाले पहले पैरामीटर के लिए एक स्पष्ट आर्गुमेंट लेबल होना **ज़रूरी** है, ताकि Swift को पता चले कि वेरिएडिक आर्गुमेंट की सूची कहाँ खत्म होती है।
~~~~
