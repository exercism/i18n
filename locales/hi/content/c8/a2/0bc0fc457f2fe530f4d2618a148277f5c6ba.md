# निर्देश

इस अभ्यास में आपको प्रोग्रामिंग भाषाओं की एक ऐरे पर काम करने के लिए कुछ फंक्शन बनाने हैं।

## 1. खाली भाषाओं की ऐरे लौटाने के लिए एक फंक्शन बनाइए

`language_list` नाम का फंक्शन बनाइए, जो कोई आर्गुमेंट नहीं लेता और एक खाली ऐरे लौटाता है।

```php
<?php

language_list();
// => []
```

## 2. कितनी भी संख्या में भाषाओं से ऐरे बनाने के लिए फंक्शन में बदलाव कीजिए

`language_list` फंक्शन में ऐसा बदलाव कीजिए कि यह कितनी भी भाषाएँ (स्ट्रिंग) आर्गुमेंट के रूप में ले सके। इसे वह ऐरे लौटानी चाहिए जिसमें ये भाषाएँ शामिल हों।

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. ऐरे में एक भाषा जोड़ने के लिए फंक्शन बनाइए

`add_to_language_list` फंक्शन बनाइए, जो 2 आर्गुमेंट लेता है: भाषाओं की एक ऐरे और वह नई भाषा।

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. भाषाओं की ऐरे से एक एलिमेंट हटाने के लिए फंक्शन बनाइए

भाषाओं की ऐरे से पहली भाषा हटाने के लिए `prune_language_list` फंक्शन बनाइए।

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. ऐरे का पहला एलिमेंट पाने के लिए फंक्शन बनाइए

`current_language` फंक्शन बनाइए, जो 1 आर्गुमेंट (एक _भाषाओं की ऐरे_) लेता है। इससे ऐरे की पहली भाषा लौटनी चाहिए। मान लीजिए कि ऐरे में हमेशा कम से कम एक एलिमेंट रहेगा।

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. ऐरे में कितनी भाषाएँ हैं, यह लौटाने के लिए फंक्शन बनाइए

`language_list_length` फंक्शन बनाइए, जो 1 आर्गुमेंट (एक _भाषाओं की ऐरे_) लेता है। इससे ऐरे में मौजूद भाषाओं की संख्या लौटनी चाहिए।

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
