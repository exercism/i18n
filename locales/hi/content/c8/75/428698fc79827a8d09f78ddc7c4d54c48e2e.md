# परिचय

वेक्टर एक 1-आयामी ऐरे होता है।
इनमें अलग-अलग टाइप के एलिमेंट हो सकते हैं।

## वेक्टर बनाना

वेक्टर `vector` फंक्शन से या उसके रीडर रूप `#()` का उपयोग करके बनाए जा सकते हैं।

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## एलिमेंट तक पहुँचना

वेक्टर के एलिमेंट तक पहुँचने के लिए `aref` का उपयोग कीजिए। इंडेक्स शून्य से शुरू होते हैं:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
