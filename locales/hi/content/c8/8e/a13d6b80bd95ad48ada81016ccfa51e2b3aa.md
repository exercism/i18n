# मूल बातें

Sather का प्रोग्राम **क्लास** से बनता है, और इन क्लास के अंदर **रूटीन** रहते हैं।

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## क्लास

क्लास का नाम बड़े अक्षरों में लिखा जाता है, और शब्दों के बीच अंडरस्कोर लगता है: `GREETER`, `STAGE_DIRECTIONS`. फाइल का नाम भी आम तौर पर इसी से मेल खाता है, बस छोटे अक्षरों में: `stage_directions.sa`.

हर रूटीन किसी क्लास के अंदर ही रहता है। क्लास के बाहर कोई कोड नहीं होता।

## रूटीन

जो रूटीन कोई जवाब देता है, वह जवाब का प्रकार कोलन के बाद घोषित करता है:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` टेक्स्ट का टाइप है। जो रूटीन कोई आर्गुमेंट नहीं लेता, उसे ब्रैकेट के बिना लिखा और कॉल किया जाता है।

रूटीन आर्गुमेंट भी ले सकता है, जिन्हें नाम के बाद ब्रैकेट में लिखा जाता है:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` जवाब लौटा देता है और रूटीन को वहीं रोक देता है, इसलिए उसके नीचे की सारी लाइनें छोड़ दी जाती हैं।

## कॉल करना

क्लास के बाहर से पहले क्लास का नाम लिखिए, फिर `::`, और फिर रूटीन:

```sather
GREETER::hello
```

उसी क्लास के अंदर से क्लास का नाम छोड़ा जा सकता है। एक रूटीन को दूसरे रूटीन से इस्तेमाल करवाने का यही आम तरीका है:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## कमेंट

दो डैश से कमेंट शुरू होता है, जो लाइन के अंत तक चलता है।

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

परंपरा के अनुसार क्लास का अंत उसका नाम बताने वाले कमेंट से होता है। रूटीन, लूप और क्लास, सब `end;` से बंद होते हैं, इसलिए कमेंट बताता है कि यह `end;` किसका है:

```sather
end; -- class GREETER
```

## सेमीकोलन

स्टेटमेंट के अंत में सेमीकोलन लगता है। रूटीन के अंतिम स्टेटमेंट के बाद सेमीकोलन लगाना ज़रूरी नहीं है, लेकिन हर बार लगा देना सोचने की एक चीज़ कम कर देता है।
