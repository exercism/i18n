# परिचय

F# में संख्याओं के साथ काम करते समय सबसे ज़रूरी बात यह समझना है कि पूर्णांक और दशमलव संख्या दो अलग चीज़ें हैं। पूर्णांक ऐसी संख्या होती है जिसमें दशमलव चिह्न के बाद कोई अंक नहीं होता, जबकि दशमलव संख्या में दशमलव चिह्न के बाद शून्य या उससे अधिक अंक होते हैं।

F# में सबसे अधिक इस्तेमाल होने वाले दो संख्यात्मक टाइप `int` (32-बिट पूर्णांक) और `float` (64-बिट दशमलव संख्या) हैं।

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

पूर्णांक और दशमलव संख्या, दोनों में `_` अक्षर को _अंक विभाजक_ की तरह इस्तेमाल किया जा सकता है, जो बड़ी संख्याएँ लिखते समय काम आता है:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

अंकगणित के लिए मानक [अंकगणितीय ऑपरेटर][arithmetic-operators] (`+`, `-`, `*` आदि) इस्तेमाल किए जाते हैं। संख्याओं की तुलना मानक [तुलना ऑपरेटरों][comparison-operators] (`<`, `>=` आदि) से की जा सकती है, और बराबरी (`=`) तथा असमानता (`<>`) वाले ऑपरेटर भी इसी काम आते हैं।

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

संख्यात्मक टाइप के बीच कन्वर्ज़न के लिए अंतर्निहित [कन्वर्ज़न ऑपरेटर][conversion-operators] इस्तेमाल करने पड़ते हैं। इन ऑपरेटरों के नाम उसी टाइप के नाम पर रखे गए हैं जिसमें ये कन्वर्ज़न करते हैं।

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

टाइप बदलते समय हमेशा सावधान रहिए। अगर किसी वैल्यू को लक्ष्य टाइप में नहीं दर्शाया जा सकता, तो वह वैल्यू _ओवरफ्लो_ हो जाती है।
