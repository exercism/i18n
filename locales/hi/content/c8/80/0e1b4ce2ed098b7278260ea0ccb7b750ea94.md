# स्ट्रिंग मेथड

`String` में कई मेथड हैं जिनकी मदद से स्ट्रिंग में बदलाव किए जा सकते हैं। इन मेथड को स्ट्रिंग पर ही कॉल किया जाता है, और अक्सर एक ही स्ट्रिंग पर कई काम करने के लिए इन्हें एक के बाद एक जोड़ा जाता है।

नीचे कुछ सबसे आम मेथड की सूची दी गई है। सभी मेथड की पूरी सूची के लिए [`String` API दस्तावेज़][string-api] देखिए।

## String#upcase और String#downcase

[`upcase`][upcase] मेथड एक नई स्ट्रिंग लौटाता है जिसमें सभी अक्षर बड़े अक्षरों में बदल दिए जाते हैं।

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase] मेथड एक नई स्ट्रिंग लौटाता है जिसमें सभी अक्षर छोटे अक्षरों में बदल दिए जाते हैं।

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub और String#gsub

Crystal में स्ट्रिंग के कुछ हिस्सों को बदलने के लिए मेथड हैं। इन्हें [`sub`][sub] (_प्रतिस्थापन_) और [`gsub`][gsub] (_वैश्विक प्रतिस्थापन_) कहा जाता है।

ये मेथड पहले आर्गुमेंट के रूप में एक स्ट्रिंग, अक्षर या रेजेक्स ले सकते हैं, और दूसरे आर्गुमेंट के रूप में एक स्ट्रिंग या अक्षर ले सकते हैं। पहला आर्गुमेंट स्ट्रिंग का वह हिस्सा होता है जिसे बदला जाएगा, और दूसरा आर्गुमेंट उसकी जगह लगने वाली चीज़ होती है। `Char` और रेजेक्स को आगे के कॉन्सेप्ट में समझाया जाएगा।

`sub` मेथड स्ट्रिंग में पहले आर्गुमेंट के पहले मिलने वाले हिस्से को दूसरे आर्गुमेंट से बदल देता है।

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub` मेथड `sub` की तरह ही काम करता है, लेकिन यह पहले आर्गुमेंट के सभी मिलने वाले हिस्सों को दूसरे आर्गुमेंट से बदल देता है।

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp और String#strip

chomp और strip की मदद से स्ट्रिंग से अनचाहे अक्षर हटाए जा सकते हैं।

[`chomp`][chomp] मेथड डिफॉल्ट रूप से स्ट्रिंग के अंत से अंतिम `\r`, `\n` या `\r\n` अक्षर हटा देता है। अगर मेथड को किसी आर्गुमेंट के साथ कॉल किया जाए, तो यह स्ट्रिंग के अंत से दी गई वैल्यू हटा देता है, बशर्ते वह वैल्यू स्ट्रिंग के अंत में मौजूद हो।

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

डिफॉल्ट रूप से [`strip`][strip] मेथड स्ट्रिंग के शुरू और अंत से सारी व्हाइटस्पेस हटा देता है। अगर मेथड को किसी आर्गुमेंट के साथ कॉल किया जाए, तो यह स्ट्रिंग के शुरू और अंत से उस आर्गुमेंट को हटा देता है, बशर्ते वह आर्गुमेंट स्ट्रिंग के शुरू या अंत में मौजूद हो।

```crystal
" hello ".strip
# => "hello"
```

## String#index

[`index`][index] मेथड की मदद से स्ट्रिंग में किसी अक्षर का इंडेक्स पता किया जा सकता है। `index` मेथड आर्गुमेंट के रूप में एक `String`, `Char` या रेजेक्स लेता है। यह एक वैकल्पिक दूसरा आर्गुमेंट भी ले सकता है, जो बताता है कि खोज किस इंडेक्स से शुरू करनी है। `index` मेथड आर्गुमेंट जहाँ पहली बार मिलता है, उसका इंडेक्स लौटाता है।

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

आप [`delete_at`][delete_at] मेथड की मदद से स्ट्रिंग से कोई अक्षर हटा सकते हैं। `delete_at` मेथड आर्गुमेंट के रूप में एक इंडेक्स लेता है और उस इंडेक्स पर मौजूद अक्षर हटा देता है।

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

[`insert`][insert] मेथड की मदद से किसी खास इंडेक्स पर एक स्ट्रिंग डाली जा सकती है। `insert` मेथड पहले आर्गुमेंट के रूप में एक इंडेक्स और दूसरे आर्गुमेंट के रूप में एक स्ट्रिंग लेता है। `insert` मेथड एक नई स्ट्रिंग लौटाता है जिसमें दूसरा आर्गुमेंट उस इंडेक्स पर डाल दिया जाता है।

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
