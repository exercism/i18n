# बारे में

[cons][hyper-conses] Common Lisp की एक बुनियादी डेटा टाइप है। एक cons एक सिर और एक पूँछ से मिलकर बनता है (इन्हें [ऐतिहासिक वजह][history] से `car` और `cdr` कहा जाता है)। cons के सिर और पूँछ के डेटा टाइप पर कोई रोक नहीं है।

cons [`cons`][hyper-cons] फंक्शन से बनते हैं, जो दो ऑब्जेक्ट लेता है और एक cons देता है (कभी-कभी इसे 'cons cell' भी कहते हैं)।

cons के हिस्सों तक [`car`][hyper-car] और [`cdr`][hyper-cdr] फंक्शनों से पहुँचा जा सकता है।

## संदर्भ

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
