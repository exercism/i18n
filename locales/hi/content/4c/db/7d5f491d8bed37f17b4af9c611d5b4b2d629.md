# परिचय

## सेट

एक सेट अद्वितीय वैल्यूओं का अपरिवर्तनीय और अक्रमित संग्रह है। एक सेट में सभी एलिमेंट एक ही टाइप के होने चाहिए।

`gleam/set` मॉड्यूल `Set` टाइप को परिभाषित करता है और सेट के साथ काम करने के लिए फंक्शन प्रदान करता है।

आप `set.to_list` और `set.from_list` की मदद से ऐरे और सेट को एक-दूसरे में बदल सकते हैं। सेट में एलिमेंट का क्रम निश्चित नहीं होता।

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

आप `set.new`, `set.insert` और `set.delete` की मदद से सेट बना सकते हैं और भर सकते हैं।

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

आप `set.contains` और `set.size` फंक्शन की मदद से सेट के कंटेंट की जाँच कर सकते हैं।

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

सेट को `set.union` और `set.intersection` की मदद से जोड़ा जा सकता है।

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

आप सेट को फिल्टर कर सकते हैं।

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
