# नेस्टेड if स्टेटमेंट का इस्तेमाल न कीजिए

गहरी नेस्टिंग से बचने के लिए इन if स्टेटमेंट को दोबारा लिखने की कोशिश कीजिए। ऐसा इसलिए, क्योंकि बहुत अधिक नेस्टिंग से ऐसा कोड बन जाता है जिसे पढ़कर समझ पाना मुश्किल होता है। इन दो कोड टुकड़ों को देखिए:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

अब इसकी तुलना नीचे दिए गए कोड से कीजिए:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

दूसरे उदाहरण का ढाँचा बहुत ही खास है: एरर से जुड़े सारे रास्ते इंडेंट किए गए ब्लॉकों में संभाले जाते हैं, जबकि 'हैपी पाथ' हमेशा सबसे बाईं ओर सीध में रहता है। इससे कोड पढ़ना बहुत आसान हो जाता है, क्योंकि पढ़ने वाला तुरंत देख सकता है कि कोड में सबसे आम और बिना एरर वाला रास्ता कौन-सा है।
