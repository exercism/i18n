# परिचय

फंक्शन डिक्लेरेशन और फंक्शन एक्सप्रेशन के अलावा JavaScript में फंक्शन बनाने का एक और बहुत संक्षिप्त तरीका भी है। ऐसे फंक्शनों को _एरो फंक्शन_ कहा जाता है।

इस कॉन्सेप्ट में हम उस सिंटैक्स पर ध्यान देंगे जिससे एरो फंक्शन लिखा जाता है। एरो फंक्शन के काम करने के तरीके में कुछ अंतर भी हैं, जैसे _this_ बाइंडिंग, जिन्हें दूसरे कॉन्सेप्ट में समझाया जाएगा।

यहाँ एक फंक्शन डिक्लेरेशन और एक एरो फंक्शन की तुलना दी गई है।

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

ऊपर आप देख सकते हैं कि एरो फंक्शन का सिंटैक्स:

1. `function` कीवर्ड हटा देता है
2. आइडेंटिफायर `addUpTwoNumbers` को `const` के रूप में घोषित करता है
3. एक फैट एरो `=>` जोड़ता है

अगर फंक्शन बॉडी में सिर्फ एक `return` स्टेटमेंट हो, जैसा ऊपर के उदाहरण में है, तो `{}` और `return` कीवर्ड हटाए जा सकते हैं।

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

एरो फंक्शन से सिर्फ एक ऑब्जेक्ट लौटाने की खास स्थिति में, `return` स्टेटमेंट हटाने के लिए ऑब्जेक्ट के चारों ओर ब्रैकेट लगाने पड़ते हैं।

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return { num1, num2 };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

पैरामीटर के चारों ओर ब्रैकेट लगाना पैरामीटर की संख्या पर निर्भर करता है।

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
