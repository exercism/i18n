# परिचय

बहुत से प्रोग्राम को वास्तविक दुनिया की घटनाओं का अनुकरण करने के लिए (स्यूडो-)रैंडम वैल्यू चाहिए।

कुछ आम और परिचित उदाहरण:

- सिक्का उछालना: ('H', 'T') में से एक रैंडम वैल्यू।
- पासा फेंकना: 1 से 6 तक एक रैंडम पूर्णांक।
- ताश की गड्डी फेंटना: कार्ड के ऐरे का एक रैंडम क्रम।
- 3-D ग्राफिक्स सिमुलेशन में पेड़ों और झाड़ियों का बनना।

कंप्यूटर से सचमुच रैंडम वैल्यू बनाना एक [आश्चर्यजनक रूप से कठिन तकनीकी चुनौती][why-randomness-is-hard] है। इसीलिए "स्यूडोरैंडम" जनरेटर भी होते हैं।

## रैंडम संख्याएँ बनाना

JavaScript में आप [`Math.random()`][Math.random] फंक्शन की मदद से स्यूडोरैंडम संख्याएँ बना सकते हैं।
यह 0 (शामिल) और 1 (शामिल नहीं) के बीच एक स्यूडोरैंडम दशमलव संख्या लौटाता है।

_min_ (शामिल) और _max_ (शामिल नहीं) के बीच एक रैंडम संख्या पाने के लिए आप इस जैसा कोई फंक्शन इस्तेमाल कर सकते हैं:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## रैंडम पूर्णांक बनाना

रैंडम पूर्णांक बनाने के लिए आप `Math.floor()` या `Math.ceil()` इस्तेमाल करके किसी रैंडम संख्या को पूर्णांक में बदल सकते हैं।
