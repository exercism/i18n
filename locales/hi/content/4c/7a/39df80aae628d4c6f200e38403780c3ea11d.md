# निर्देश

आपने अभी-अभी एक क्लाइम्बिंग जिम के फ्रंट डेस्क पर काम करना शुरू किया है।
सदस्य कुछ महीनों के लिए सदस्यता खरीदते हैं और हर बार आने पर चेक-इन और चेक-आउट करते हैं।
मैनेजर ने आपसे एक हेल्पर लिखने के लिए कहा है जो सदस्यों के सबसे अधिक पूछे जाने वाले सवालों के जवाब दे।

## 1. पता कीजिए कि सदस्यता कब खत्म होती है

किसी तारीख को शुरू होने वाली सदस्यता उतने ही महीनों बाद उसी महीने की उसी तारीख को खत्म होती है।
अगर खत्म होने वाले महीने में वह तारीख मौजूद नहीं है, तो सदस्यता उस महीने के अंतिम दिन खत्म होती है।

`FrontDesk.membershipEnd()` मेथड लागू कीजिए जो सदस्यता की शुरू होने की तारीख और महीनों की संख्या लेता है, और वह तारीख लौटाता है जिस दिन सदस्यता खत्म होती है:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. दिखाइए कि सदस्यता कितने समय तक चलती है

जिम सदस्यता कार्ड पर यह छापता है कि सदस्यता कितने साल, महीने और दिन तक चलती है।

`FrontDesk.membershipLength()` मेथड लागू कीजिए जो सदस्यता की शुरू होने की तारीख और खत्म होने की तारीख लेता है, और सदस्यता की अवधि `Period` के रूप में लौटाता है:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. सदस्यता में बचे दिन गिनिए

सदस्य अक्सर पूछते हैं कि उनकी सदस्यता खत्म होने में कितने दिन बचे हैं।

`FrontDesk.daysLeft()` मेथड लागू कीजिए जो आज की तारीख और सदस्यता की खत्म होने की तारीख लेता है, और आज से खत्म होने की तारीख तक कुल दिनों की संख्या लौटाता है।
जब खत्म होने की तारीख आज है या पहले ही बीत चुकी है, तो कोई दिन बचा नहीं है, इसलिए मेथड `0` लौटाता है:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. विज़िट का समय नापिए

जिम चौबीसों घंटे खुला रहता है, और टर्नस्टाइल वह तारीख और समय दर्ज करता है जब कोई सदस्य चेक-इन और चेक-आउट करता है।

`FrontDesk.visitDuration()` मेथड लागू कीजिए जो किसी विज़िट के चेक-इन और चेक-आउट की तारीख और समय लेता है, और विज़िट कितनी देर चली, यह `Duration` के रूप में लौटाता है:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. रसीद पर विज़िट छापिए

रसीद पर विज़िट की अवधि घंटों और मिनटों में दिखाई जाती है, जैसे `1h 35m`।
मिनट हमेशा दो अंकों में लिखे जाते हैं, सेकंड छोड़ दिए जाते हैं, और घंटे एक दिन तक सीमित नहीं हैं।

`FrontDesk.formatVisit()` मेथड लागू कीजिए जो विज़िट की अवधि लेता है और उसे इस फॉर्मेट में लौटाता है:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
