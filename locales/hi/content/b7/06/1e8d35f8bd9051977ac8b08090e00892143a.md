# गेटर और सेटर

गेटर और सेटर ऐसे मेथड हैं जो आपको किसी ऑब्जेक्ट की प्रॉपर्टी की वैल्यू पढ़ने और लिखने देते हैं।
Crystal में मैक्रो होते हैं, जिनकी मदद से किसी प्रॉपर्टी के लिए गेटर और सेटर बनाना आसान हो जाता है।
मैक्रो कंपाइल के समय कोड बनाने का एक तरीका है, जिसे आगे मैक्रो कॉन्सेप्ट में समझाया जाएगा।

Ruby में ये मेथड `attr_reader`, `attr_writer` और `attr_accessor` मेथड से बनाए जाते हैं, और देखने में Crystal के तरीके से बहुत मिलते-जुलते हैं।
Crystal ने इन्हें `getter`, `setter` और `property` मैक्रो के रूप में बनाया है।

## गेटर

गेटर एक ऐसा मैक्रो है जो एक इंस्टेंस वेरिएबल की वैल्यू लौटाने वाला मेथड बनाता है।
इसका मतलब है कि जब आप किसी इंस्टेंस वेरिएबल का इस्तेमाल करना चाहते हैं (मेथड के अंदर, initialize को छोड़कर), तो अब आपको उसके आगे `@` लिखने की ज़रूरत नहीं पड़ती। इसके बजाय आप उस मेथड को कॉल कर सकते हैं जो गेटर मैक्रो ने बना दिया है।

गेटर मैक्रो एक से ज़्यादा इंस्टेंस वेरिएबल भी ले सकता है, बस उनके बीच कॉमा लगाना होता है।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

जैसा कि आप देख सकते हैं, गेटर इस्तेमाल करने से आपका लिखा कोड कम हो जाता है और पढ़ने में आसान हो जाता है।
साथ ही, Ruby और Crystal में एक फर्क यह भी है कि Crystal गेटर मैक्रो के आर्गुमेंट के तौर पर वेरिएबल का नाम और सिंबल, दोनों ले लेता है।
सिंबल के बारे में आगे सिंबल कॉन्सेप्ट में बताया जाएगा।

## सेटर

सेटर एक ऐसा मैक्रो है जो एक इंस्टेंस वेरिएबल की वैल्यू सेट करने वाला मेथड बनाता है।
यह मैक्रो उतना ज़्यादा इस्तेमाल नहीं होता, इसकी जगह आमतौर पर `property` मैक्रो इस्तेमाल किया जाता है।
जो मेथड बनेंगे, उनका रूप `name_of_method=` जैसा होगा। `=` ही वह चीज़ है जिससे प्रॉपर्टी सेट की जा सकती है।

इस मेथड की परिभाषा थोड़ी खास है, क्योंकि मेथड को मिलने वाला आर्गुमेंट `=` चिह्न के बाद आता है।
Crystal में कई और खास मेथड भी यही सिंटैक्स इस्तेमाल करते हैं, जैसे `+` मेथड।

गेटर मैक्रो की तरह ही, सेटर बनाने के बाद जब आप किसी इंस्टेंस वेरिएबल की वैल्यू बदलना चाहते हैं, तो आप उस मेथड को कॉल कर सकते हैं जो सेटर मैक्रो ने बना दिया है।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## प्रॉपर्टी

प्रॉपर्टी एक ऐसा मैक्रो है जो एक इंस्टेंस वेरिएबल के लिए गेटर और सेटर, दोनों बनाता है।

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
