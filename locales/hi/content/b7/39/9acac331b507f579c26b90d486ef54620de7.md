# परिचय

Haxe में एक्सेप्शन, कोड चलाते समय होने वाली एरर को संभालने का एक सुरक्षित तरीका हैं। हर एक्सेप्शन में एरर के बारे में बताने वाला एक संदेश होना चाहिए। हम `throw` कीवर्ड की मदद से एक्सेप्शन फेंक सकते हैं:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

जब कोई एक्सेप्शन फेंका जाता है, तो कोड ऐसे हिस्से को ढूँढता है जो उस एरर को संभालने के लिए बनाया गया हो। अगर ऐसा हिस्सा नहीं मिलता, तो कोड एरर संदेश प्रदर्शित करता है और साथ ही प्रोग्राम का चलना भी रोक देता है।

Haxe में एक्सेप्शन संभालने के लिए हम `try-catch` ब्लॉक का उपयोग करते हैं। यह ब्लॉक स्टेटमेंट एक `try` ब्लॉक और एक या अधिक `catch` ब्लॉक से मिलकर बनता है। `try` ब्लॉक कोड के एक हिस्से को चलाने की कोशिश करता है, जबकि `catch` ब्लॉक इस इंतज़ार में रहता है कि कोई एक्सेप्शन फेंका जाए और वह उसे पकड़ ले, ताकि प्रोग्राम का चलना रुक न जाए। जब `catch` ब्लॉक किसी एक्सेप्शन को पकड़ता है, तो वह ब्लॉक के अंदर का पूरा कोड भी चला देता है:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch` ब्लॉक के आर्गुमेंट का टाइप छोड़ देना चाहिए।
