# परिचय

क्लोज़र के साथ काम करते समय Swift के सिंटैक्स में एक बदलाव मिलता है, जिसे ट्रेलिंग क्लोज़र कहते हैं। ट्रेलिंग क्लोज़र तब होते हैं जब फंक्शन के पैरामीटर की सूची में आखिरी पैरामीटर फंक्शन टाइप का हो। ऐसी स्थिति में, अगर कोई क्लोज़र पास कर रहा है, तो उसे बंद होने वाले गोल ब्रैकेट के _बाद_ लिखा जा सकता है। साथ ही आर्गुमेंट लेबल छोड़ दिया जाता है। ध्यान दीजिए कि अगर फंक्शन में सिर्फ एक पैरामीटर है, तो ब्रैकेट पूरी तरह छोड़े जा सकते हैं।

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
