# परिचय

## `for` लूप

`for` स्टेटमेंट एक कोड ब्लॉक को बार-बार चलाता है।
इसकी पहली लाइन तय करती है कि यह ब्लॉक कितनी बार दोहराया जाएगा:

```go
for init; condition; post {
    // loop body
}
```

- **init** स्टेटमेंट पहले इटरेशन से पहले सिर्फ एक बार चलता है। आम तौर पर लूप में इस्तेमाल होने वाला काउंटर वेरिएबल यहीं घोषित और शुरू किया जाता है।
- **condition** एक बूलियन एक्सप्रेशन है जिसे हर इटरेशन से पहले जाँचा जाता है। जब यह `false` हो जाता है, तो लूप रुक जाता है।
- **post** स्टेटमेंट हर पूरे हो चुके इटरेशन के बाद चलता है। इसका इस्तेमाल काउंटर अपडेट करने के लिए किया जा सकता है।

`init; condition; post` के चारों ओर गोल ब्रैकेट न लगाइए।
लेकिन लूप के अंदर के कोड के चारों ओर घुंघराले ब्रैकेट `{ }` हमेशा ज़रूरी होते हैं।

यह लूप `i` को `1` से शुरू करता है और हर बार `i` की मौजूदा वैल्यू प्रिंट करता है। फिर अगले इटरेशन के लिए इसे बढ़ा देता है, और जब `i` `10` पर पहुँचता है तो रुक जाता है:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
