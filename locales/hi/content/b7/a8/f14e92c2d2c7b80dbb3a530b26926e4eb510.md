# प्रिंटिंग

Cairo में प्रिंटिंग की मदद से आप कंसोल पर संदेश और वैल्यू प्रदर्शित कर सकते हैं। इससे प्रोग्राम डीबग करना आसान हो जाता है, और प्रोग्राम चलने के दौरान जानकारी देना भी सरल हो जाता है।

प्रिंटिंग की यह व्यवस्था कई तरह से काम आती है और आसान भी है। यह अलग-अलग तरह के डेटा को फॉर्मेट करने और आउटपुट देने के टूल देती है।

## प्रिंटिंग की मूल बातें

Cairo में कंसोल पर टेक्स्ट प्रिंट करने के लिए दो मुख्य मैक्रो हैं:

- **`println!`**: आउटपुट को नई लाइन पर प्रिंट करता है।
- **`print!`**: आउटपुट को उसी लाइन में प्रिंट करता है, बिना नई लाइन जोड़े।

दोनों मैक्रो अपने मुख्य आर्गुमेंट के रूप में एक `ByteArray` लेते हैं। यह एक साधारण स्ट्रिंग हो सकती है, या वैल्यू के लिए प्लेसहोल्डर वाली फॉर्मेटेड स्ट्रिंग।

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

ऊपर के उदाहरण में:

- `{}` प्लेसहोल्डर की जगह `x` और `y` की वैल्यू आ जाती हैं।
- `println!` यह सुनिश्चित करता है कि आउटपुट के अंत में एक नई लाइन आए।

## स्ट्रिंग को फॉर्मेट करना

कभी-कभी आपको एक फॉर्मेटेड स्ट्रिंग बनानी होती है, बिना उसे तुरंत प्रिंट किए।

`format!` मैक्रो यही काम करता है।

यह `println!` की तरह ही काम करता है, लेकिन कंसोल पर आउटपुट भेजने के बजाय एक `ByteArray` लौटाता है।

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

इस उदाहरण में:

- `format!` `s1`, `s2` और `s3` को जोड़कर एक ही स्ट्रिंग बना देता है, और उनके बीच डैश (`-`) लगाता है।
- बनी हुई स्ट्रिंग को बाद में दोबारा इस्तेमाल किया जा सकता है या प्रिंट किया जा सकता है।

## अपने बनाए डेटा टाइप प्रिंट करना

डिफ़ॉल्ट रूप से Cairo सिर्फ बुनियादी टाइप ही प्रिंट कर सकता है, जैसे पूर्णांक और स्ट्रिंग।

अगर आप कोई अपना बनाया टाइप प्रिंट करने की कोशिश करें, जैसे कोई स्ट्रक्ट, तो आपको एरर मिलेगी, जब तक कि उस टाइप के लिए `Display` या `Debug` ट्रेट लागू न किए गए हों।

### खास फॉर्मेटिंग के लिए `Display` का उपयोग

`Display` ट्रेट से आप तय कर सकते हैं कि कोई अपना टाइप कैसे प्रिंट होना चाहिए।

यहाँ एक उदाहरण है:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

इस उदाहरण में:

- `fmt` फंक्शन तय करता है कि `Point` स्ट्रक्ट को प्रिंट होने लायक स्ट्रिंग में कैसे बदला जाए।
- `write!` मैक्रो फॉर्मेटेड स्ट्रिंग को `Formatter` में जोड़ता है।

### `Debug` की मदद से डीबग करना

डीबग करने के लिए Cairo `Debug` ट्रेट देता है।

ज़्यादातर टाइप के लिए आप इसे अपने आप बनवा सकते हैं, जिससे आपके स्ट्रक्ट की अंदरूनी जानकारी प्रिंट करना आसान और तेज़ हो जाता है।

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

इस उदाहरण में:

- `#[derive(Debug)]` `Debug` ट्रेट का इम्प्लीमेंटेशन अपने आप बना देता है।
- `{:?}` प्लेसहोल्डर `println!` को बताता है कि फॉर्मेटिंग के लिए `Debug` ट्रेट इस्तेमाल करे।

## हेक्साडेसिमल में प्रिंट करना

Cairo में `{:x}` प्लेसहोल्डर की मदद से पूर्णांक को हेक्साडेसिमल फॉर्मेट में प्रिंट किया जा सकता है।

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

यह खास तौर पर तब काम आता है जब आप डेटा के लो-लेवल रूपों के साथ काम कर रहे हों।
