# परिचय

JavaScript में _टेम्पलेट लिटरल_ की मदद से स्ट्रिंग के अंदर एक्सप्रेशन रखे जा सकते हैं। इसे स्ट्रिंग इंटरपोलेशन भी कहते हैं।
यह सुविधा JavaScript में पहले से मौजूद [`String`][string-reference] ग्लोबल ऑब्जेक्ट की क्षमता को बढ़ा देती है।

JavaScript में आप टेक्स्ट को बैकटिक के बीच लिखकर टेम्पलेट लिटरल बना सकते हैं।
इससे सिर्फ नई लाइनें और दूसरे खास अक्षर ही टेक्स्ट में नहीं आते, बल्कि आप वेरिएबल और दूसरे एक्सप्रेशन भी उसके अंदर रख सकते हैं।

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

ऊपर के उदाहरण में बैकटिक (<code>\`\`</code>) का इस्तेमाल टेम्पलेट लिटरल लिखने के लिए किया गया है। `${...}` वह प्लेसहोल्डर है जिसकी जगह बाद में असल वैल्यू रखी जाती है।
जो भी टाइप स्ट्रिंग नहीं है, वह _अपने आप_ स्ट्रिंग में बदल जाता है।
यह विषय [टाइप कन्वर्ज़न][type-conversion-concept] कॉन्सेप्ट में समझाया गया है।
टेम्पलेट लिटरल के साथ हर तरह के एक्सप्रेशन इस्तेमाल किए जा सकते हैं।

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

जब आपको स्ट्रिंग को कई लाइनों में लिखना हो:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

अगर टेम्पलेट लिटरल की जगह आम स्ट्रिंग के अंदर नई लाइन दिखानी हो (यानी बैकटिक इस्तेमाल न करते हुए), तो आप न्यूलाइन एस्केप सीक्वेंस `\n` इस्तेमाल कर सकते हैं:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

स्ट्रिंग के अंदर इस तरह वैल्यू रखने की सुविधा की मदद से आप इस प्रक्रिया में तर्क भी जोड़ सकते हैं, ताकि तय हो सके कि आउटपुट स्ट्रिंग क्या होनी चाहिए।
इस तर्क को संभालने का एक तरीका [टर्नरी ऑपरेटर][ternary-operator] का इस्तेमाल है।
यह वही `if/else` शर्त वाली सुविधा थोड़े अलग रूप में देता है।

टेम्पलेट लिटरल के सिंटैक्स में तर्क जोड़ने के लिए:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
