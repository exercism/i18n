# NuVoc

[NuVoc][nuvoc-link] J का सबसे प्रामाणिक संदर्भ है।
यह J के प्रिमिटिव और पूरी भाषा का बहुत ही संक्षिप्त और सूचनाओं से भरपूर अवलोकन है।

# Rosetta Code

Rosetta Code के बहुत से टास्क के हल `J` में लिखे गए हैं।
J प्रोग्राम पढ़कर सीखने के लिए यह एक अच्छा स्रोत है।
[यहाँ](https://rosettacode.org/wiki/Sudoku#J) Roger Hui द्वारा लिखा एक सुडोकू सॉल्वर है।
