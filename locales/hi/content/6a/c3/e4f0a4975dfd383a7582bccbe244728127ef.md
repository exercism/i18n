# निर्देश

API कॉल करते समय गलती होना आसान है, खासकर जब कच्चे टेक्स्ट या JSON का सीधे इस्तेमाल किया जाए। इस अभ्यास में आप रिक्वेस्ट पेलोड को व्यवस्थित करने के लिए Ballerina Records का इस्तेमाल करेंगे। इस तरह बाहरी रिज़र्वेशन एंडपॉइंट के साथ बातचीत सफल होगी।

## उद्देश्य

- दिए गए कोड को बदलिए।
- एयरलाइन रिज़र्वेशन सर्विस को कॉल करके उपयोगकर्ता के लिए एयरलाइन टिकट आरक्षित कीजिए। उचित पेलोड के साथ airlineReservationService पर एक post रिक्वेस्ट भेजिए और जवाब पाइए।
- होटल रिज़र्वेशन सर्विस को कॉल करके उपयोगकर्ता के लिए होटल का कमरा आरक्षित कीजिए। उचित पेलोड के साथ hotelReservationService पर एक post रिक्वेस्ट भेजिए और जवाब पाइए।
- कार रेंटल सर्विस को कॉल करके उपयोगकर्ता के लिए कार किराए पर लीजिए। उचित पेलोड के साथ carRentalService पर एक post रिक्वेस्ट भेजिए और जवाब जाँचिए।
- अगर सब कुछ सफल हो, तो ऐसी बॉडी लौटाइए जिसका message एट्रिब्यूट "Congratulations! Your journey is ready!!" हो।
