# परिचय

## रेगुलर एक्सप्रेशन

Elixir में रेगुलर एक्सप्रेशन **PCRE** स्पेसिफिकेशन (**P**erl **C**ompatible **R**egular **E**xpressions) का पालन करते हैं। ऐसा ही Java, JavaScript या Ruby जैसी दूसरी लोकप्रिय भाषाओं में भी होता है।

`Regex` मॉड्यूल में रेगुलर एक्सप्रेशन के साथ काम करने के लिए फंक्शन मौजूद हैं। `String` मॉड्यूल के कुछ फंक्शन भी आर्गुमेंट के तौर पर रेगुलर एक्सप्रेशन लेते हैं।

~~~~exercism/note
इस अभ्यास में यह मान लिया गया है कि आप रेगुलर एक्सप्रेशन का सिंटैक्स पहले से जानते हैं, जिसमें कैरेक्टर क्लास, क्वांटिफायर, ग्रुप और कैप्चर शामिल हैं।

अगर आपको अपने रेगुलर एक्सप्रेशन के ज्ञान को दोहराना है, तो इनमें से किसी एक स्रोत को देखिए: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

### सिगिल

रेगुलर एक्सप्रेशन बनाने का सबसे आम तरीका `~r` सिगिल का उपयोग करना है।

```elixir
~r/test/
```

ध्यान दीजिए कि Elixir के सारे सिगिल में सिर्फ `/` ही नहीं, बल्कि [कई तरह के डेलिमिटर][sigils] इस्तेमाल किए जा सकते हैं।

### मैच करना

`=~/2` ऑपरेटर की मदद से रेगुलर एक्सप्रेशन का मैच किया जा सकता है, जो `boolean` परिणाम लौटाता है। इसके अलावा `Regex` मॉड्यूल और `String` मॉड्यूल दोनों में `match?/2` फंक्शन भी हैं।

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### कैप्चर करना

अगर सिर्फ बूलियन जाँच से काम नहीं चलता, तो `Regex.run/3` फंक्शन का उपयोग कीजिए। यह सारे कैप्चर का एक ऐरे लौटाता है (और अगर कोई मैच नहीं मिला, तो `nil`)। लौटाए गए ऐरे का पहला एलिमेंट हमेशा पूरे रेगुलर एक्सप्रेशन के मैच से मेल खाता है, और उसके बाद के एलिमेंट मैच हुए ग्रुप होते हैं।

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### मॉडिफायर

रेगुलर एक्सप्रेशन का व्यवहार खास फ्लैग जोड़कर बदला जा सकता है। सिगिल से रेगुलर एक्सप्रेशन बनाते समय मॉडिफायर दूसरे डेलिमिटर के बाद लगाइए।

आम मॉडिफायर ये हैं:
- `i` - मैच करते समय छोटे और बड़े अक्षरों में फर्क नहीं करता।
- `u` - `\p` जैसे Unicode-विशेष पैटर्न को चालू करता है, और साथ ही `\w`, `\s` जैसे कैरेक्टर क्लास को Unicode से भी मैच कराता है।

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
