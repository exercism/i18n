# निर्देश

इस अभ्यास में आप रिमोट कंट्रोल कारों पर कुछ और काम करेंगे।

एक एक्सपेरिमेंटल कार बनाई जा चुकी है, और अब टेस्ट ट्रैक को ऐसा बनाना है कि वह प्रोडक्शन और एक्सपेरिमेंटल, दोनों तरह के मॉडलों को संभाल सके। दोनों तरह की कारें पहले ही बन चुकी हैं, और आपको कोई ऐसा तरीका निकालना है जिससे टेस्ट ट्रैक पर दोनों के साथ काम चल सके।

इसके अलावा, प्रोडक्शन कारों को अब कुछ सफलता भी मिलने लगी है। टीम के मुखिया प्रोडक्शन कारों की रैंकिंग जारी करके प्रतिस्पर्धा की भावना बनाए रखना चाहते हैं।

## 1. दोनों तरह की कारों को एक ही टेस्ट ट्रैक पर चलाने की सुविधा दीजिए

कृपया `IRemoteControlCar` इंटरफेस में एक मेथड जोड़िए, जो दोनों तरह की कारों के लिए `Drive()` का इम्प्लीमेंटेशन सामने लाए।

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. टेस्ट ट्रैक पर अलग-अलग मॉडलों की तय की गई दूरी की तुलना करने की सुविधा दीजिए

कृपया `IRemoteControlCar` इंटरफेस में एक प्रॉपर्टी जोड़िए, जो दोनों तरह की कारों के लिए `DistanceTravelled` प्रॉपर्टी का इम्प्लीमेंटेशन सामने लाए।

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. प्रोडक्शन कारों की रैंकिंग संभव बनाइए

कृपया `ProductionRemoteControlCar` क्लास में `IComparable<T>` इंटरफेस लागू कीजिए। कारों को छाँटने का सामान्य क्रम जीतों के आरोही क्रम में होना चाहिए।

static `TestTrack.GetRankedCars()` मेथड को लागू कीजिए, जो दी गई कारों को जीतों की संख्या के आरोही क्रम में छाँटकर लौटाए।

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
