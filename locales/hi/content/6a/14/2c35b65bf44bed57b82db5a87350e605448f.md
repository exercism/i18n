# मैच की मूल बातें

`match` ऑपरेटर एक वैल्यू की तुलना पैटर्न की एक श्रृंखला से करता है, और फिर इस आधार पर कोड चलाता है कि कौन-सा पैटर्न मैच होता है।

## लिटरल का मैच

सबसे बुनियादी रूप में, `match` एक वैल्यू की तुलना कई संभावित मेलों से करता है और पहला मैच होने वाला आर्म चुनता है। कभी केवल एक ही आर्म चुना जाता है, और कंट्रोल कभी "बहकर" किसी दूसरे आर्म तक नहीं पहुँचता। `match` एक एक्सप्रेशन है, और इसका परिणाम एक वैल्यू हो सकता है।

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## पूर्णता

मैचिंग हमेशा पूर्ण होती है: अगर किसी वैल्यू का बीच से निकल जाना संभव है, तो Rust प्रोग्राम को कंपाइल नहीं करेगा। इसमें मदद के लिए `_` एक वाइल्डकार्ड है, जो किसी भी चीज़ से मैच हो जाता है।

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## कंट्रोल फ्लो के रूप में मैच

`match` का इस्तेमाल एक एक्सप्रेशन की तरह एक वैल्यू देने के लिए किया जा सकता है, लेकिन इसे सिर्फ कंट्रोल फ्लो के लिए एक स्टेटमेंट की तरह भी इस्तेमाल किया जा सकता है।

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## रेंज का मैच

मैच के आर्म को हमेशा अकेली वैल्यू के रूप में लिखना ज़रूरी नहीं है; ये रेंज भी हो सकती हैं।

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## या पैटर्न

एक मैच आर्म `|` टोकन को अलग करने वाले चिह्न की तरह इस्तेमाल करके कई संभावित विकल्पों में से किसी एक से मैच कर सकता है।

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## संरचनात्मक मैचिंग और बाइंडिंग

मैचिंग किसी खास मैच आर्म के अंदर मान्य एक बाइंडिंग बना सकती है। यह खास तौर पर उन एनम को खोलने में काम आती है जिनके वेरिएंट में डेटा होता है।

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

इस विषय पर और जानकारी `match-advanced` कॉन्सेप्ट में है।
