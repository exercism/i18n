# समानांतर अक्षर आवृत्ति की अवधारणाएँ

इस अभ्यास में बाहरी क्रेट की मदद से कई तरह के हल संभव हैं। काम की मात्रा सीमित रखने के लिए इस दस्तावेज़ में कुछ चुनिंदा संभावनाएँ दी गई हैं। Crossbeam वाले हलों में भी लगभग यही अवधारणाएँ आती हैं जो यहाँ दी गई हैं, और Rayon में इनका एक छोटा हिस्सा ही चाहिए।

  - Unicode तरीके बनाम ASCII तरीके
- **स्लाइस**
- **टपल**

  - हायर-ऑर्डर फंक्शन

### समानांतरता से जुड़ी अवधारणाएँ

- **चैनल**
- **`Mutex` और `RwLock`**
- **फ्यूचर**
- **रेफरेंस काउंटिंग**

\*<sub>संबंधित, पर यहाँ उचित हलों के लिए लागू नहीं</sub>

## सामान्य

- स्ट्रिंग: यहाँ खास तौर पर `str` की भूमिका हमेशा बनी रहती है
- Unicode: ASCII और Unicode तरीकों के बीच परफॉर्मेंस और सुविधाओं का अंतर। जब बेंचमार्क Unicode तरीके इस्तेमाल करता है और हल ASCII तरीके, तो बेंचमार्क के नतीजे गड़बड़ा जाते हैं।
- इटरेटर: इनपुट पर या उसके हिस्सों पर इटरेशन करना।
- कलेक्शन: `HashMap` पर इटरेशन करना और `Entry` का उपयोग करना। आम तौर पर हैंडल को `Vec` में इकट्ठा किया जाता है।
- रेफरेंस
- संख्या: खास तौर पर `Add` ट्रेट
- for लूप: move की वजह से इटरेटर में थ्रेड जॉइन नहीं किए जा सकते।
- **वैकल्पिक** विज़िबिलिटी: इम्प्लीमेंटेशन का विवरण सार्वजनिक न रखें
- **वैकल्पिक** स्लाइस: इनपुट को वर्कर थ्रेड में बाँटने के लिए `.chunks()` अकसर इस्तेमाल किया जाने वाला मेथड है। इसके बजाय सबस्लाइस इस्तेमाल किए जाते हैं।
- **वैकल्पिक** हायर-ऑर्डर फंक्शन: HashMap को एक इटरेटर के साथ हायर-ऑर्डर फंक्शन की मदद से मर्ज किया जा सकता है।
- **वैकल्पिक** टाइप: इनपुट बाँटने के लिए हम पूर्णांकों को फ्लोटिंग पॉइंट वैल्यू में बदल सकते हैं, ताकि राउंडिंग लागू हो सके
- **वैकल्पिक** क्रेट

## std वाला तरीका, चैनल के साथ या बिना

- समानांतरता - उपविषय: थ्रेड स्पॉन करना/जॉइन करना।
- इटरेटर - उपविषय: लेज़ी इवैल्यूएशन। एक ही इटरेटर से थ्रेड स्पॉन और जॉइन करने पर समानांतरता नहीं मिलती।
- लाइफटाइम - उपविषय: `'static lifetime` और स्पष्ट `move` सिमैंटिक्स
- इटरेटर/लाइफटाइम - उपविषय: इटरेटर को कंज़्यूम करना। इटरेटर से थ्रेड जॉइन नहीं किए जा सकते।
- Option टाइप: थ्रेड या चैनल के नतीजों को अनरैप करना
- फंक्शन: खास तौर पर थ्रेड स्पॉन करने के लिए हायर-ऑर्डर फंक्शन चाहिए। क्लोज़र यहाँ एक विकल्प हैं।

## std वाला तरीका, चैनल के साथ

- समानांतरता - उपविषय: चैनल।
- टपल: `mpsc::channel()` एक टपल लौटाता है
- डिस्ट्रक्चरिंग: असाइनमेंट के समय टपल को डिस्ट्रक्चर किया जा सकता है
- लाइफटाइम: `drop()`

## साझा वेरिएबल वाला दूसरा तरीका

- रेफरेंस काउंटिंग: रेफरेंस काउंटेड कलेक्शन की मदद से थ्रेड के बीच समग्र डेटा साझा करना।
- **विशेष उल्लेख**: समानांतरता - उपविषय: म्यूटेक्स। इस अभ्यास के लिए ज़रूरी या उपयोगी नहीं है, फिर भी यह एक आम अवधारणा है। संबंधित: `RwLock`।

### std और चैनल का उदाहरण

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### क्रेट और Arc का उदाहरण

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
