# लूप

Rust में लूप की मदद से कोड के एक ब्लॉक को बार-बार चलाया जा सकता है। यह तब तक चलता रहता है, जब तक आप उसे रुकने न कहें या कोई तय शर्त पूरी न हो जाए।

लूप का सबसे साधारण रूप `loop` कीवर्ड से बनता है:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

ऊपर दिया गया कोड एक अनंत लूप बनाता है। किसी लूप से बाहर निकलने के लिए break कीवर्ड का उपयोग कीजिए:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## `for` और `while` वाले लूप

`loop` कीवर्ड के अलावा, आप `for` और `while` की मदद से भी लूप बना सकते हैं।

`for` लूप का उपयोग किसी कलेक्शन या इटरेटर के एलिमेंट पर इटरेशन करने के लिए किया जाता है।

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

रेंज भी इटरेटर होती हैं, इसलिए `for` लूप से उन पर इटरेशन करना बहुत आसान हो जाता है:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

`while` लूप कोड को तब तक दोहराता रहता है, जब तक कोई शर्त पूरी न हो जाए। हम पिछले उदाहरण को `while` लूप की मदद से इस तरह फिर से लिख सकते हैं:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

लूप के बारे में अधिक जानकारी के लिए Rust की किताब में [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) देखिए।
