# परिचय

फंक्शन एक या अधिक आर्गुमेंट के लिए डिफॉल्ट वैल्यू घोषित कर सकते हैं। आइए इस फंक्शन को देखते हैं:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

कंपाइल होने पर Elixir `number/0` (बिना आर्गुमेंट) और `number/1` (एक आर्गुमेंट) के लिए एक फंक्शन की परिभाषा बनाता है।

अगर एक से अधिक आर्गुमेंट की डिफॉल्ट वैल्यू हों, तो छूटे हुए आर्गुमेंट भरने के लिए ये डिफॉल्ट वैल्यू बाएँ से दाएँ फंक्शन पर लागू की जाती हैं।

अगर फंक्शन में एक से अधिक क्लॉज़ हों, तो डिफॉल्ट आर्गुमेंट फंक्शन क्लॉज़ से पहले एक फंक्शन हेडर (बिना बॉडी वाला फंक्शन) में परिभाषित किए जाने चाहिए:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
