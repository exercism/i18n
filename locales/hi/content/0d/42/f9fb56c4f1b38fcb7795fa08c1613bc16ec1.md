# परिचय

क्लास Swift प्रोग्राम की एक बुनियादी इकाई है। इसकी मदद से आप आपस में जुड़ी प्रॉपर्टी (डेटा) और मेथड (फंक्शन) को एक अलग, आत्मनिर्भर इकाई में बाँध सकते हैं।

### क्लास बनाना

क्लास बनाने के लिए `class` कीवर्ड लिखिए, उसके बाद क्लास का नाम, और क्लास की परिभाषा को घुंघराले ब्रैकेट में रखिए:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

क्लास के अंदर संग्रहीत प्रॉपर्टी रखी जा सकती हैं, जो सामान्य कॉन्स्टेंट (`let`) या वेरिएबल (`var`) की तरह बनाई जाती हैं और वैसा ही व्यवहार करती हैं।

### इंस्टेंस

क्लास की परिभाषा एक खाका होती है: यह एक नया टाइप बनाती है और बताती है कि उसकी वैल्यू कैसी दिखती हैं, लेकिन अकेले में कोई इंस्टेंस नहीं बनाती।

किसी क्लास का *इंस्टेंस* बनाने के लिए उसके इनिशियलाइज़र को कॉल कीजिए। क्लास का नाम लिखिए और उसके बाद गोल ब्रैकेट लगाइए:

```swift
let someCharacter = GameCharacter()
```

इससे एक नया इंस्टेंस बनता है, जिसकी प्रॉपर्टी क्लास की परिभाषा में दी गई डिफ़ॉल्ट वैल्यू से इनिशियलाइज़ होती हैं।
जिन ऑप्शनल प्रॉपर्टी के लिए साफ़ तौर पर कोई डिफ़ॉल्ट वैल्यू नहीं दी गई हो (जैसे `name`), उन्हें Swift अपने आप `nil` बना देता है।

### प्रॉपर्टी तक पहुँचना

आप किसी इंस्टेंस की प्रॉपर्टी तक *डॉट नोटेशन* से पहुँचते हैं: इंस्टेंस का नाम लिखिए, फिर एक डॉट (`.`), और फिर प्रॉपर्टी का नाम।
डॉट नोटेशन नेस्टेड प्रॉपर्टी के लिए भी काम करता है।

डॉट नोटेशन से आप वैल्यू पढ़ भी सकते हैं और, अगर प्रॉपर्टी म्यूटेबल (`var`) है, तो नई वैल्यू असाइन भी कर सकते हैं:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### मेथड

प्रॉपर्टी के अलावा क्लास *मेथड* भी बना सकती हैं, यानी ऐसे फंक्शन जो उस क्लास से जुड़े होते हैं।

मेथड को क्लास के अंदर सामान्य `func` सिंटैक्स से बनाइए।
अगर कोई मेथड किसी प्रॉपर्टी को बदलता है, तो उस प्रॉपर्टी को `var` से घोषित करना ज़रूरी है:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

किसी इंस्टेंस पर मेथड को प्रॉपर्टी की तरह ही डॉट नोटेशन से कॉल कीजिए:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### `self`

क्लास के हर इंस्टेंस में `self` नाम की एक अंतर्निहित प्रॉपर्टी होती है, जो उस इंस्टेंस को ही दिखाती है।
प्रॉपर्टी या मेथड को दिखाते समय `self` अक्सर छोड़ दिया जाता है, लेकिन जब किसी प्रॉपर्टी और मेथड पैरामीटर का नाम एक ही हो, तो दोनों में फ़र्क बताने के लिए `self` आम तौर पर इस्तेमाल किया जाता है।
