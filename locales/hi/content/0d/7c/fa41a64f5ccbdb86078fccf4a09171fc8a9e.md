# परिचय

कोई भी वैल्यू एरर हो सकती है। `throw` (`kernel` में) संकेत देता है। वर्तमान वर्ड का स्टैक इफेक्ट छोड़ दिया जाता है और नियंत्रण सबसे नज़दीकी संलग्न `recover` तक लौट जाता है।

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` एक पार्सिंग वर्ड है जो एक ही बार में एक एरर टपल क्लास *और* एक कंस्ट्रक्टर वर्ड बनाता है:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

इससे हर कस्टम एरर को एक अनोखी क्लास, एक सुविधाजनक थ्रो करने वाला कंस्ट्रक्टर, और पकड़ी गई एररों की जाँच करने के लिए एक क्लास प्रेडिकेट (`name?`) मिलते हैं:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

फाइनली-शैली की सफाई के लिए `continuations` में `cleanup` देखिए। रीस्टार्ट करने योग्य शर्तों के लिए `condition` देखिए।
