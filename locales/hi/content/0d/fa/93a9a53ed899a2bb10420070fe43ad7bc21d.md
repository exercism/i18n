# परिचय

## ऐरे

C# में जो डेटा स्ट्रक्चर शून्य या उससे अधिक एलिमेंट रख सकते हैं, उन्हें _कलेक्शन_ कहा जाता है। **ऐरे** एक ऐसा कलेक्शन है जिसका आकार यानी लंबाई निश्चित होती है और जिसके सारे एलिमेंट एक ही टाइप के होने चाहिए। एलिमेंट को इंडेक्स की मदद से ऐरे में असाइन किया जा सकता है या ऐरे से प्राप्त किया जा सकता है। C# के ऐरे शून्य से शुरू होते हैं, यानी पहले एलिमेंट का इंडेक्स हमेशा शून्य होता है:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

ऐरे बनाने का एक शॉर्टकट तरीका भी है, जिससे आप एक ही बार में ऐरे बना सकते हैं और उसकी वैल्यू असाइन कर सकते हैं। चूँकि अब कंपाइलर बता सकता है कि ऐरे में कितने एलिमेंट होंगे, इसलिए लंबाई लिखने की ज़रूरत नहीं होती:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

ऐरे के साथ काम करने के दो तरीके हैं: ऐरे इंस्टेंस के मेथड या प्रॉपर्टी कॉल करना, या `Array` क्लास में परिभाषित स्टैटिक मेथड इस्तेमाल करना।

## `for` लूप

`for` लूप की मदद से आप कोड को बार-बार चलाते रह सकते हैं, जब तक कोई शर्त पूरी न हो जाए।

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

एक `for` लूप में चार हिस्से होते हैं:

1. इनिशियलाइज़र: लूप में घुसने से पहले एक बार चलाया जाता है। आम तौर पर इसमें वे वेरिएबलो बनाए जाते हैं जो लूप के अंदर इस्तेमाल होते हैं।
2. शर्त: हर इटरेशन से पहले चलाई जाती है। जब तक इसका परिणाम `true` होता है, लूप चलता रहता है।
3. इटरेटर: हर इटरेशन के बाद चलाया जाता है। आम तौर पर इसमें लूप के वेरिएबल बदले जाते हैं (अक्सर बढ़ाए या घटाए जाते हैं)।
4. लूप के अंदर का कोड: वह कोड जो हर इटरेशन में चलता है।

## `foreach` लूप

चूँकि ऐरे एक _कलेक्शन_ भी है, इसलिए इंडेक्स की मदद से वैल्यू तक पहुँचने के अलावा आप एक `foreach` लूप की मदद से उसकी **सारी** वैल्यू पर एक-एक करके इटरेशन कर सकते हैं:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
