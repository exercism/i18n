# निर्देश

स्टेज मैनेजर चाहता है कि रिहर्सल स्क्रिप्ट टाइप कर दी जाए, और इसमें कई हिस्से चीज़ों को दोहराकर या जोड़कर बनाए जाते हैं।

चारों काम `REHEARSAL_SCRIPT` क्लास में होने चाहिए।

## 1. संकेत दोहराइए

एक संकेत और एक संख्या दिए गए हों, तो उस संकेत को उतनी बार लौटाइए, बीच में कुछ भी न रखते हुए।

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

किसी चीज़ को शून्य बार दोहराने पर खाली स्ट्रिंग मिलती है।

## 2. कलाकारों के आद्याक्षर

कलाकारों की सूची दी गई हो, तो हर नाम का पहला अक्षर लौटाइए, सबको एक साथ जोड़कर।

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. पंक्तियों पर संख्याएँ लगाइए

किसी दृश्य की पंक्तियाँ दी गई हों, तो उन पर एक से शुरू करके संख्याएँ लगाइए, हर एक को अपनी अलग लाइन पर।

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

पंक्तियों के *बीच* एक नई लाइन होती है और आखिरी के बाद कोई नहीं। जिस दृश्य में कोई पंक्ति न हो, उसके लिए खाली स्ट्रिंग मिलती है।

## 4. पंक्ति को ज़ोर से बोलिए

हर अक्षर को बड़े अक्षर में बदलकर पंक्ति लौटाइए।

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
