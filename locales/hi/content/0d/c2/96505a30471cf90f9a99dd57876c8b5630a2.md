# निर्देश

अपने दोस्तों के लिए कुकीज़ बनाने की तैयारी में आपको पता चलता है कि रेसिपी में इस्तेमाल किए गए कुछ मापों को बदलना पड़ेगा।
चूँकि आप केवल मीट्रिक प्रणाली से परिचित हैं, इसलिए अपनी सुविधा के लिए आपको अमेरिकी बेकिंग के आम मापों को मिलीलीटर (mL) में बदलने का कोई तरीका निकालना है।

अपने हल के लिए इस रूपांतरण चार्ट का इस्तेमाल कीजिए:

| बदलने वाली इकाई | वॉल्यूम | मिलीलीटर (mL) में |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| अमेरिकी कप       | 1      | 240                 |
| अमेरिकी द्रव औंस   | 1      | 30                  |
| अमेरिकी छोटा चम्मच | 1      | 5                   |
| अमेरिकी बड़ा चम्मच  | 1      | 15                  |

चूँकि आप एक प्रतिभाशाली प्रशिक्षु प्रोग्रामर हैं, आप मिलीलीटर को बीच की इकाई बनाने का फैसला करते हैं, ताकि सूची में दी गई किसी भी इकाई से किसी भी दूसरी इकाई में, या उसी इकाई में भी, बदलना आसान हो जाए।

## 1. वॉल्यूम-पेयर से संख्यात्मक भाग निकालिए

`KitchenCalculator.get_volume` मेथड बनाइए।
इसे एक वॉल्यूम-पेयर टपल दिया जाए, तो यह केवल संख्यात्मक भाग लौटाता है।

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. वॉल्यूम-पेयर को मिलीलीटर में बदलिए

`KitchenCalculator.to_milliliter` मेथड बनाइए।
इसे एक वॉल्यूम-पेयर टपल दिया जाए, तो यह रूपांतरण चार्ट का इस्तेमाल करके उस वॉल्यूम को मिलीलीटर में बदल देता है।

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. मिलीलीटर वाले वॉल्यूम-पेयर को दूसरी इकाई में बदलिए

`KitchenCalculator.from_milliliter` मेथड बनाइए। 
इसे एक वॉल्यूम-पेयर टपल और मनचाही इकाई दी जाए, तो यह रूपांतरण चार्ट का इस्तेमाल करके उस वॉल्यूम को मनचाही इकाई में बदल देता है।

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. किसी भी इकाई से किसी भी इकाई में बदलिए

`KitchenCalculator.convert` मेथड बनाइए।
इसे एक वॉल्यूम-पेयर टपल और मनचाही इकाई दी जाए, तो यह दिए गए वॉल्यूम को मनचाही इकाई में बदल देता है।

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
