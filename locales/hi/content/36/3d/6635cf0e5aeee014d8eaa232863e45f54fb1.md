# निर्देश

इस अभ्यास में आप कुछ कोड लिखेंगे, ताकि अपनी पसंदीदा पकाने की किताब से एक शानदार लसाग्ना बनाने में आपको मदद मिले।

आपके सामने चार काम हैं, और चारों लसाग्ना पकाने में लगने वाले समय से जुड़े हैं।

## 1. ओवन में लगने वाले अनुमानित समय को मिनटों में तय कीजिए

`OvenTime` कॉन्स्टेंट बनाइए और उसमें तय कीजिए कि लसाग्ना को ओवन में कितने मिनट रहना चाहिए।
पकाने की किताब के अनुसार, ओवन में रखने का अनुमानित समय 40 मिनट है:

```go
OvenTime
// => 40
```

## 2. ओवन में बचे हुए समय को मिनटों में निकालिए

`RemainingOvenTime()` फंक्शन बनाइए। यह फंक्शन पैरामीटर के रूप में वे असली मिनट लेता है जितनी देर लसाग्ना ओवन में रह चुका है। पिछले काम में तय हुए ओवन के अनुमानित समय के आधार पर यह लौटाता है कि लसाग्ना को ओवन में अभी कितने मिनट और रहना है।

```go
func RemainingOvenTime(actual int) int {
    // TODO
}

RemainingOvenTime(30)
// => 10
```

## 3. तैयारी में लगने वाले समय को मिनटों में निकालिए

`PreparationTime` फंक्शन बनाइए। यह पैरामीटर के रूप में उन परतों की संख्या लेता है जो आपने लसाग्ना में लगाईं, और लौटाता है कि लसाग्ना तैयार करने में आपने कितने मिनट लगाए। यह मानकर चलिए कि हर परत तैयार करने में आपको 2 मिनट लगते हैं।

```go
func PreparationTime(numberOfLayers int) int {
    // TODO
}

PreparationTime(2)
// => 4
```

## 4. बीते हुए काम के समय को मिनटों में निकालिए

`ElapsedTime` फंक्शन बनाइए, जो दो पैरामीटर लेता है। पहला पैरामीटर उन परतों की संख्या है जो आपने लसाग्ना में लगाईं, और दूसरा पैरामीटर यह कि लसाग्ना कितने मिनट से ओवन में है।
इस फंक्शन को लौटाना चाहिए कि लसाग्ना पकाने पर आपने कुल कितने मिनट काम किया। यह तैयारी में लगे मिनटों और इस समय लसाग्ना के ओवन में बिताए मिनटों का जोड़ है।

```go
func ElapsedTime(numberOfLayers, actualMinutesInOven int) int {
    // TODO
}

ElapsedTime(3, 20)
// => 26
```
