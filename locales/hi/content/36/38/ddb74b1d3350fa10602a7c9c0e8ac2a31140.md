# निर्देश

एक ट्रिनरी संख्या, जिसे स्ट्रिंग के रूप में लिखा गया है (जैसे '102012'), को बुनियादी सिद्धांतों से दशमलव में बदलिए।

जो स्ट्रिंग मान्य ट्रिनरी संख्या नहीं दर्शाती, प्रोग्राम उसे वैल्यू 0 माने।

ट्रिनरी संख्याओं में तीन चिह्न होते हैं: 0, 1 और 2।

किसी ट्रिनरी संख्या में सबसे अंतिम स्थान 1 का होता है, अंत से दूसरा स्थान 3 का, अंत से तीसरा स्थान 9 का, और इसी तरह आगे।

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

अगर आपकी भाषा की स्टैंडर्ड लाइब्रेरी में यह बदलाव करने का कोई मेथड मौजूद है, तो मान लीजिए कि वह नहीं है, और इसे खुद लागू कीजिए।
