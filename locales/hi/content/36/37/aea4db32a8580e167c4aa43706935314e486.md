# परिचय

अगर पैरामीटर के टाइप का अनुमान लगाया जा सके, तो Swift क्लोज़र बनाते समय पैरामीटर के नाम और `in` कीवर्ड छोड़ने की अनुमति भी देता है। इसके बजाय पैरामीटर को एक खास शॉर्टहैंड सिंटैक्स से दर्शाया जा सकता है, जहाँ `$0` पहले पैरामीटर को दर्शाता है, `$1` दूसरे पैरामीटर को दर्शाता है, और इसी तरह आगे भी।

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
