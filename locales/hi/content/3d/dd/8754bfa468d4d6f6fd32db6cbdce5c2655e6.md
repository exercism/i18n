# निर्देश

जैसे-जैसे कोई केस आगे बढ़ता है, जासूस की नोटबुक भरती जाती है। जाँच की दिशाएँ हटने पर नोटबुक फिर खाली हो जाती है।

पाँचों काम `CASE_NOTES` क्लास में लिखने हैं।

## 1. केस खोलिए

एक नई, खाली नोटबुक लौटाइए।

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. सुराग लिखिए

नोटबुक के अंत में एक सुराग जोड़िए। यह कुछ नहीं लौटाता, बल्कि जो नोटबुक इसे दी जाती है, उसी को बदल देता है।

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. कितने सुराग हैं?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. एक सुराग को बाहर कीजिए

किसी स्थान पर मौजूद सुराग को नोटबुक से बाहर निकाल दीजिए। उसके बाद के सारे सुराग एक जगह आगे खिसक जाते हैं। यह भी कुछ नहीं लौटाता।

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. केस पढ़कर सुनाइए

नोटबुक के सारे सुरागों को `"; "` से जोड़कर लौटाइए। खाली नोटबुक खाली स्ट्रिंग के रूप में पढ़ी जाती है।

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
