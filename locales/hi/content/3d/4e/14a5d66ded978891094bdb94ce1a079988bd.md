# टेस्ट

## clojure.test

Babashka के साथ clojure.test पहले से मिलता है। जब आप कोई अभ्यास करने के लिए तैयार हो जाएँ और अपना हल रखने के लिए एक फाइल बना लें (जैसे `bob.clj`), तो आप `clojure.test/run-tests` की मदद से टेस्ट चला सकते हैं, [जैसा यहाँ बताया गया है](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests)।


REPL की मदद से आप आसानी से कोड चला सकते हैं और तुरंत नतीजा देख सकते हैं, और इससे टेस्ट भी चलाए जा सकते हैं। लाइन एडिटिंग और ऊपर/नीचे के तीरों से कमांड इतिहास के लिए `rlwrap` इस्तेमाल करने की सलाह दी जाती है। किसी अभ्यास का टेस्ट चलाने के लिए उसकी डायरेक्टरी में जाइए और `src` तथा `test` डायरेक्टरियों को क्लासपाथ में जोड़कर एक socket REPL खोलिए:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

सबसे पहले टेस्ट नेमस्पेस को `require` कीजिए:
``` clojure
=> (require 'bob-test)
nil
```

फिर `bob-test` पर `run-tests` कॉल कीजिए:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

टेस्ट रनर स्क्रिप्ट बनाने के लिए:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
