# परिचय

Haxe टाइप और फील्ड के रनटाइम रिफ्लेक्शन का समर्थन करता है। रिफ्लेक्शन का सही उपयोग करने के लिए यह समझना ज़रूरी है कि किस तरह के ऑपरेशन समर्थित हैं और कौन-से नहीं। चूँकि रिफ्लेक्शन की प्रकृति गतिशील है, इसे कंपाइल-टाइम पर हमेशा तय नहीं किया जा सकता।

रिफ्लेक्शन API में दो क्लास हैं:

- `Reflect`: एक हल्का API जो अनाम स्ट्रक्चर पर सबसे अच्छा काम करता है, और क्लास के लिए सीमित समर्थन देता है।
- `Type`: क्लास और एनम के साथ काम करने के लिए एक अधिक मजबूत API।

आगे के उदाहरण में हम JavaScript टारगेट का उपयोग कर रहे हैं:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
