# निर्देश

आपको पक्षी देखने का बहुत शौक है और आप यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए।

आपके पाँच काम हैं, और वे सब आपके बगीचे में आए पक्षियों की संख्याओं से जुड़े हैं।

## 1. जाँचिए कि पिछले सप्ताह की गिनती क्या थी

तुलना करने के लिए आप पिछले सप्ताह की गिनती की एक प्रति हमेशा पास रखते हैं, जो यह थी: 0, 2, 5, 3, 7, 8 और 4। `BirdCount.last_week` मेथड बनाइए। यह पिछले सप्ताह की गिनती लौटाता है:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. जाँचिए कि कल कितने पक्षी आए थे

`BirdCount#yesterday` मेथड बनाइए। यह कल आपके बगीचे में आए पक्षियों की संख्या लौटाता है। पक्षियों की गिनती दिन के क्रम में लगी है: पहला एलिमेंट सबसे पुराने दिन की गिनती है, और अंतिम एलिमेंट आज की गिनती।

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. आने वाले पक्षियों की कुल संख्या निकालिए

`BirdCount#total` मेथड बनाइए। यह आपके बगीचे में आए पक्षियों की कुल संख्या लौटाता है:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरों से ज़्यादा व्यस्त होते हैं। व्यस्त दिन वह होता है जब आपके बगीचे में पाँच या उससे अधिक पक्षी आए हों।
`BirdCount#busy_days` मेथड बनाइए। यह व्यस्त दिनों की संख्या लौटाता है:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. जाँचिए कि क्या कोई ऐसा दिन था जब एक भी पक्षी नहीं आया

`BirdCount#day_without_birds?` मेथड बनाइए। अगर किसी दिन बगीचे में एक भी पक्षी नहीं आया था, तो यह `true` लौटाता है; वरना `false` लौटाता है:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
