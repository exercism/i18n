# सीखना

Vim के साथ पहले से ही बहुत अच्छा डॉक्युमेंटेशन मौजूद होता है। इस डॉक्युमेंटेशन को देखने का तरीका `:help` कमांड है।

शुरुआत के लिए `:h user-manual` देखिए।

लगभग सभी Vim इंस्टॉलेशन के साथ एक इंटरैक्टिव ट्यूटोरियल भी आता है:

```
$ vimtutor
```

Vim दशकों पुराना है और आज भी लोकप्रिय है। इसके बारे में आपको वेब पर बहुत सारे संसाधन मिल जाएँगे, कुछ दूसरों से बेहतर भी। अच्छे संसाधन [यहाँ](https://exercism.org/docs/tracks/vimscript/resources) सूचीबद्ध हैं।
