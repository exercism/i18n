# परिचय

## बुनियादी बातें

F# में किसी नाम को वैल्यू असाइन करने को _बाइंडिंग_ कहा जाता है। बाइंडिंग अपरिवर्तनीय होती हैं, इसलिए वे दूसरी भाषाओं के कॉन्स्टेंट जैसी लगती हैं। चूँकि F# एक स्टैटिक टाइप वाली भाषा है, हर बाइंडिंग का टाइप कंपाइल के समय ही तय हो जाता है।

बाइंडिंग `let` कीवर्ड से बनाई जाती हैं। ज़्यादातर बाइंडिंग में टाइप लिखना ज़रूरी नहीं होता, क्योंकि F# का _टाइप इन्फरेंस_ आम तौर पर वैल्यू के आधार पर टाइप का अनुमान लगा लेता है। एक बाइंडिंग ऐसी दिखती है:

```fsharp
// Automatically inferred type
let fingers = 10
```

फंक्शन भी साधारण बाइंडिंग ही हैं, बस उनमें एक या अधिक पैरामीटर होते हैं। फंक्शन अपने अंतिम एक्सप्रेशन को अपने आप लौटा देता है। ज़्यादातर फंक्शन के लिए भी टाइप इन्फरेंस काम करता है: यह देखकर कि फंक्शन को किन वैल्यू के साथ कॉल किया जाता है और फंक्शन कौन-सी वैल्यू लौटाता है।

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और फंक्शन के हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं।

```fsharp
let five = add 2 3
```

अगर किसी बाइंडिंग का टाइप नहीं पहचाना जा सकता, तो कंपाइलर एक एरर बताता है। इसे ठीक करने के लिए बाइंडिंग में स्पष्ट टाइप एनोटेशन लगाइए।

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F# में बाइंडिंग का उपयोग उनके बनाए जाने के _बाद_ ही किया जा सकता है। किसी बाइंडिंग को बनाए जाने से पहले उपयोग करने पर कंपाइल एरर मिलती है।

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# में स्कोप तय करने के लिए खाली जगह का खास महत्व होता है। इसका मतलब है कि कोड को स्पेस से इंडेंट करके स्कोप तय किया जाता है। यह इंडेंटेशन उस लाइन के मुकाबले नापा जाता है जिसमें बाइंडिंग बनाई गई है। आम तौर पर इंडेंटेशन के लिए चार स्पेस इस्तेमाल किए जाते हैं:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F# की बाइंडिंग (जिनमें फंक्शन भी शामिल हैं) आम तौर पर मॉड्यूल में रखी जाती हैं। एक मॉड्यूल आपस में जुड़ी चीज़ों को एक जगह रखता है और `module` कीवर्ड से बनता है। मॉड्यूल को उसकी बाइंडिंग से पहले बनाया जाना चाहिए:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# में दो तरह की कमेंट लिखी जा सकती हैं। सिंगल लाइन कमेंट से पहले `//` लगाया जाता है, और मल्टीलाइन कमेंट `(*` और `*)` के बीच लिखी जाती हैं।
