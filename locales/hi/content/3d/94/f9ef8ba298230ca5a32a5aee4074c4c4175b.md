# परिचय


## बूलियन

PowerShell में [`bool`][booleans] टाइप होता है, जो सही और गलत वैल्यू दर्शाता है।
इस टाइप में केवल दो ही वैल्यू होती हैं: `True` और `False`.
आप इन वैल्यू को आगे `$` लगाकर वेरिएबल में रख सकते हैं:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

बूलियन एक्सप्रेशन जोड़ने और उनका मूल्यांकन करने के लिए हम `-and`, `-or` और `-not` जैसे [लॉजिकल ऑपरेटर][logical-operators] इस्तेमाल कर सकते हैं।

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## कमेंट-आधारित हेल्प

PowerShell में [`Comment-based help`][comment-based help] कमेंट के रूप में लिखे गए फंक्शन और स्क्रिप्ट के लिए विस्तृत जानकारी देने में मदद करता है।
यह विशेष हेल्प कमेंट कीवर्ड इस्तेमाल करता है, जो बताते हैं कि किन विषयों पर ध्यान केंद्रित है, जैसे `.SYNOPSIS`, `.EXAMPLE` या `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

आप `Get-Help` कमांडलेट की मदद से कमेंट-आधारित हेल्प की जानकारी दिखा सकते हैं।

```powershell
> Get-Help -Name "ExampleFunction"
```
