# परिचय

जैसे `int` या किसी अन्य बेसिक डेटा टाइप का पॉइंटर बनाया जा सकता है, वैसे ही किसी फंक्शन का पॉइंटर भी बनाया जा सकता है।
फंक्शन पॉइंटर का उपयोग एक फंक्शन को दूसरे फंक्शन में पास करने के लिए किया जा सकता है।
जो फंक्शन किसी दूसरे फंक्शन में पैरामीटर वैल्यू के रूप में पास किया जाता है, उसे फर्स्ट क्लास फंक्शन कहा जाता है।
जो फंक्शन एक या अधिक फंक्शन को पैरामीटर के रूप में लेता है, या जो कोई फंक्शन लौटाता है, उसे हायर ऑर्डर फंक्शन कहा जाता है।

नीचे दिए गए उदाहरण में, `is_even` और `is_odd` फर्स्ट क्लास फंक्शन हैं।
हायर ऑर्डर फंक्शन `test_number` है।

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```

`test_number` के पहले आर्गुमेंट के लिए `bool (*func) (int)` का फंक्शन सिग्नेचर पास किए गए फंक्शनों के सिग्नेचर से मेल खाता है।
`is_even` और `is_odd` दोनों एक `int` पैरामीटर लेते हैं और एक `bool` लौटाते हैं।
`(*func)` में, `func` उस फंक्शन का नाम दर्शाता है जिसका उपयोग किया जाना है।
अगर `(*fn)` का उपयोग किया जाता, तो इसे इस तरह कॉल किया जाता: `printf(text, number, fn(number)? "true": "false");`.
फंक्शन पॉइंटर पैरामीटर को पूरा करने के लिए, हम `test_number` को कॉल करते समय अपेक्षित सिग्नेचर वाले फंक्शन का नाम पास करते हैं।
इस प्रकार, हम देखते हैं कि एक फंक्शन का नाम उस नाम वाले फंक्शन के एड्रेस को इंगित करता है।
