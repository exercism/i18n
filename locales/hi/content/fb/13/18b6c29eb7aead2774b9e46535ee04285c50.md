# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जिसका प्रारूप ऐसा होता है: `"[<LEVEL>]: <MESSAGE>"`।

तीन अलग-अलग लॉग लेवल होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके पास कई काम हैं। हर काम में आपको एक लॉग लाइन मिलेगी और उसके साथ कुछ करना होगा।

## 1. किसी खास सबस्ट्रिंग के बाद वाली स्ट्रिंग निकालने की सुविधा दीजिए

पिछले महीने के लॉग देखने पर आपको दिखता है कि टेस्ट मैसेज हमेशा किसी खास सबस्ट्रिंग के बाद ही होता है। आपको लगता है कि आने वाले समय में कभी आपको यह मैसेज निकालना पड़ेगा। इसलिए आप इसके लिए एक हेल्पर मेथड बनाने का फैसला करते हैं।

(_static_) `LogAnalysis.SubstringAfter()` एक्सटेंशन मेथड बनाइए, जो एक स्ट्रिंग डेलिमिटर लेता है और उस डेलिमिटर के बाद वाली सबस्ट्रिंग लौटाता है।

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. दो सबस्ट्रिंग के बीच की स्ट्रिंग निकालने की सुविधा दीजिए

आगे जाँच करने पर आपको दिखता है कि लॉग लेवल हमेशा चौकोर ब्रैकेट (`[` और `]`) के बीच ही होता है। आपको भी लगता है कि आने वाले समय में कभी आपको लॉग लेवल निकालना पड़ेगा। इसलिए आप इसके लिए एक और हेल्पर मेथड बनाने का फैसला करते हैं।

(_static_) `LogAnalysis.SubstringBetween()` एक्सटेंशन मेथड बनाइए, जो दो स्ट्रिंग डेलिमिटर लेता है और उन दोनों डेलिमिटर के बीच आने वाली सबस्ट्रिंग लौटाता है।

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. किसी लॉग से मैसेज निकालिए

(_static_) `LogAnalysis.Message()` एक्सटेंशन मेथड बनाइए, जो लॉग में मौजूद मैसेज लौटाता है।

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. किसी लॉग से लॉग लेवल निकालिए

(_static_) `LogAnalysis.LogLevel()` एक्सटेंशन मेथड बनाइए, जो लॉग का लॉग लेवल लौटाता है।

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
