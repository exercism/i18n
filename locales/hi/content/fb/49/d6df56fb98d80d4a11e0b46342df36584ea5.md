# विवरण

Swift में `guard` स्टेटमेंट का उपयोग फंक्शन से समय से पहले लौटने के लिए किया जाता है। यह तब काम आता है जब आगे की प्रक्रिया जारी रखने के लिए ज़रूरी कोई शर्त पूरी नहीं होती। उदाहरण:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

यहाँ `guard` यह जाँचता है कि `guard` कीवर्ड के बाद लिखा बूलियन एक्सप्रेशन सही है या नहीं। अगर वह सही है, तो प्रक्रिया guard स्टेटमेंट के बाद वाले कोड के साथ आगे बढ़ती है (यहाँ `let root = myValue.squareRoot()`). वरना यह else क्लॉज़ वाला कोड चलाता है। `if` स्टेटमेंट के उलट, एक `guard` स्टेटमेंट में else क्लॉज़ होना _ज़रूरी_ है। और if-else के else क्लॉज़ के उलट, किसी guard के else क्लॉज़ से guard स्टेटमेंट के स्कोप से बाहर निकलना _ज़रूरी_ होता है। यानी उसे `return`, `continue`, `break` जैसे किसी कंट्रोल ट्रांसफर स्टेटमेंट का उपयोग करना होता है, या कोई एरर थ्रो करना होता है, या प्रोग्राम से बाहर निकलना होता है।

इसके उपयोग का एक उदाहरण sinc फंक्शन है। यह sin(x)/x के बराबर होता है, जहाँ sinc(0) को 1 माना जाता है, ताकि 0 से भाग देने की समस्या न आए। इस फंक्शन को Swift में `guard` का उपयोग करके इस तरह लिखा जा सकता है:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
