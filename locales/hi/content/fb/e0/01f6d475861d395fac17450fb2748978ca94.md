# परिचय

Swift में आप किसी स्ट्रिंग को किसी पूर्णांक से इंडेक्स नहीं कर सकते (जैसे `string[3]`)।
क्योंकि Swift की स्ट्रिंग अलग-अलग लंबाई वाले यूनिकोड अक्षरों से बनी होती हैं, किसी अक्षर तक पहुँचने के लिए उससे पहले के अक्षरों से होकर गुज़रना पड़ता है।

किसी निश्चित स्थान पर मौजूद अक्षर तक पहुँचने के लिए आपको `String.Index` टाइप का इंडेक्स निकालना होगा।
इन इंडेक्सों को *अपारदर्शी इंडेक्स* कहा जाता है, क्योंकि इनकी आंतरिक संरचना Swift संभालता है, न कि इन्हें सीधे पूर्णांकों की तरह इस्तेमाल किया जाता है:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
