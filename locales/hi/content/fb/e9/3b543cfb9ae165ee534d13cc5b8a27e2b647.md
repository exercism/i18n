# निर्देश

आपको अचानक पैनकेक खाने का मन करता है।
आप एक आधुनिक, तकनीक में रुचि रखने वाले इंसान हैं, इसलिए पैनकेक बनाने की सामग्री की शॉपिंग लिस्ट JSON फॉर्मैट में लिखते हैं।
लिस्ट की संरचना इस तरह है:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

हर सामग्री को एक JSON ऑब्जेक्ट के रूप में लिखा जाता है, जैसे:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

हर सामग्री में एक वैकल्पिक प्रॉपर्टी हो सकती है जिसका नाम `"substitute"` है, और उसमें किसी दूसरी चीज़ का नाम स्ट्रिंग के रूप में रखा जाता है, जिसे उसकी जगह इस्तेमाल किया जा सकता है।

चलिए देखते हैं कि `jq` की मदद से शॉपिंग लिस्ट को कैसे जाँचा जा सकता है।

## 1. शॉपिंग लिस्ट का नाम निकालिए

एक एक्सप्रेशन लिखिए जो शॉपिंग लिस्ट का "name" एलिमेंट आउटपुट देता है।

## 2. गिनिए कि कितनी सामग्रियाँ चाहिए

सिर्फ़ ज़रूरी सामग्रियों को गिनिए। वैकल्पिक सामग्रियों को शामिल न कीजिए।

## 3. कितनी चीनी?

एक एक्सप्रेशन लिखिए जो चीनी की मात्रा आउटपुट देता है।
सिर्फ़ संख्यात्मक हिस्सा चाहिए।

## 4. जिन सामग्रियों को बदला जा सकता है, उनकी मैपिंग बनाइए

कुछ सामग्रियों की जगह कोई और चीज़ इस्तेमाल की जा सकती है (अगर आपके पास सामग्री X नहीं है, तो आप Y इस्तेमाल कर सकते हैं)।
एक JSON ऑब्जेक्ट आउटपुट दीजिए जो सुझाई गई सामग्री को उसके विकल्प से जोड़ता हो।
मैपिंग में वैकल्पिक सामग्रियों को भी शामिल कीजिए।
