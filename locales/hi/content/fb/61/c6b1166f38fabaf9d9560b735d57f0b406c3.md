# Elm सिंटैक्स की मूल बातें 1

## स्थिर वैल्यू और फंक्शन

Elm के प्रोग्राम परिभाषाओं और एक्सप्रेशनों से मिलकर बनते हैं।
Elm में हर चीज़ या तो परिभाषा होती है या एक्सप्रेशन।

स्थिर वैल्यू `name = expression` से परिभाषित की जाती है।

```elm
five = 5

six = 3 + 3
```

फंक्शन `name parameters... = expression` से बनाए जाते हैं, जहाँ पैरामीटर के बीच सिर्फ खाली जगह छोड़नी होती है।

```elm
add number1 number2 = number1 + number2
```

फंक्शन को कॉल करना भी एक एक्सप्रेशन होता है। तब आप फंक्शन का नाम लिखते हैं और उसके हर पैरामीटर के लिए एक आर्गुमेंट देते हैं, बीच में खाली जगह छोड़ते हुए, ठीक उसी तरह जैसे फंक्शन बनाते समय।

```elm
five = add 2 3
```

गोल ब्रैकेट लगाकर यह तय किया जा सकता है कि किसी एक्सप्रेशन का मूल्यांकन किस क्रम में होगा।

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## इंडेंटेशन / महत्वपूर्ण खाली जगह

कोड की सीमाएँ तय करने के लिए Elm घुंघराले ब्रैकेट, गोल ब्रैकेट या अर्धविराम जैसे चिह्न इस्तेमाल नहीं करता। इसके बजाय वह खाली जगह और इंडेंटेशन पर निर्भर करता है।

- मॉड्यूल, इंपोर्ट और टॉप-लेवल फंक्शन की परिभाषाएँ सबसे बाएँ कॉलम से शुरू होनी चाहिए।
- अगर कोई एक्सप्रेशन कई लाइनों में बाँटा गया है, तो उस एक्सप्रेशन का हिस्सा बनने वाला कोड उसके नीचे कम से कम एक खाली जगह के इंडेंटेशन के साथ होना चाहिए।
- एक्सप्रेशन के जो हिस्से एक साथ रखे गए हैं, उनका इंडेंटेशन बराबर खाली जगह के साथ होना चाहिए।

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## मॉड्यूल

Elm में हर फाइल एक मॉड्यूल होती है, और उसमें बाकी सारे कोड से पहले एक `module` स्टेटमेंट होना चाहिए।
मॉड्यूल के नाम उसकी फाइल के नाम से मेल खाने चाहिए, यानी मॉड्यूल `Calculator` को Calculator.elm फाइल में होना चाहिए।
किसी मॉड्यूल के अंदर परिभाषित हर चीज़ का स्कोप उसी मॉड्यूल तक सीमित रहता है। उसे उस मॉड्यूल के बाहर से इस्तेमाल नहीं किया जा सकता, जब तक कि वह `exposing` में न लिखा हो।

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## कमेंट

कमेंट Elm फाइल में लिखा वह हिस्सा है जिसे कोड के रूप में नहीं पढ़ा जाता।
इसे मुख्य रूप से आपके और दूसरे प्रोग्रामर के पढ़ने के लिए लिखा जाता है।
एक लाइन के कमेंट के लिए एक आसान सिंटैक्स है, जो दो डैश पर आधारित है।
कई लाइनों के कमेंट भी संभव हैं, जिनके लिए शुरू और अंत के चिह्नों की `{-` और `-}` जोड़ी इस्तेमाल होती है।

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
