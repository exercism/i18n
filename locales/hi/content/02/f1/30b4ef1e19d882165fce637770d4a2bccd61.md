# परिचय

## संख्याएँ

Lua में संख्याओं के दो रूप होते हैं: 64-बिट पूर्णांक संख्याएँ और डबल प्रिसिज़न फ्लोटिंग-पॉइंट संख्याएँ। इसमें अंकगणित के सामान्य ऑपरेटर मौजूद हैं: जोड़, घटाव, गुणा, भाग और नेगेशन। इसके अलावा इसमें फ्लोर डिवीज़न, मॉड्यूलो और घातांकन भी हैं।

| Operator | Example             |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
