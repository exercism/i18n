# परिचय

Gleam में फर्स्ट-क्लास फंक्शन होते हैं। इसका मतलब है कि फंक्शन भी सामान्य वैल्यू होते हैं: इन्हें वेरिएबलो में असाइन किया जा सकता है, आर्गुमेंट के रूप में दिया जा सकता है, और दूसरे फंक्शन से लौटाया जा सकता है।

मॉड्यूल में बनाए गए फंक्शन का नाम लेकर उसे इस्तेमाल किया जा सकता है।

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam में अनाम फंक्शन भी होते हैं, जिन्हें दूसरे फंक्शन के अंदर बनाया जाता है।

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

फंक्शन का टाइप लिखने के लिए भी लगभग वही सिंटैक्स इस्तेमाल होता है जो अनाम फंक्शन में होता है। जो फंक्शन एक `Int` और एक `Float` लेता है और एक `Int` लौटाता है, उसका टाइप ऐसे लिखा जाता है:

```gleam
fn(Int, Float) -> Int
```

अनाम फंक्शन उन वेरिएबलो को इस्तेमाल कर सकते हैं जो उन्हें बनाते समय स्कोप में थे, इसी वजह से इन्हें _क्लोज़र_ कहा जाता है।

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

जब आपको ऐसा अनाम फंक्शन बनाना हो जो किसी फंक्शन को एक ही आर्गुमेंट देता है, तो _फंक्शन कैप्चर_ सिंटैक्स इसका एक आसान संक्षिप्त रूप देता है। ये दोनों एक्सप्रेशन एक ही काम करते हैं:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
