# बिट मैनिपुलेशन

Crystal में बाइनरी लेवल पर [`Int`][ints] के साथ काम करने के लिए बिटवाइज़ ऑपरेटर हैं।

## शिफ्ट ऑपरेटर

Crystal में बिट को बाईं ओर (`<<`) या दाईं ओर (`>>`) खिसकाने के लिए [शिफ्ट ऑपरेटर][shift] हैं।

### बाईं ओर शिफ्ट (`<<`)

शिफ्ट लेफ्ट ऑपरेटर (`<<`) बिट को बाईं ओर खिसकाता है।
जिस वैल्यू को खिसकाना है वह बाईं ओर दी जाती है और खिसकाने वाले स्थानों की संख्या दाईं ओर।

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

अगर संख्या ऋणात्मक है, तो यह दाईं ओर खिसक जाएगी।

```crystal
0b0010 << -1
# => 0b0001
```

### दाईं ओर शिफ्ट (`>>`)

शिफ्ट राइट ऑपरेटर (`>>`) बिट को दाईं ओर खिसकाता है।
शिफ्ट लेफ्ट ऑपरेटर की तरह, जिस वैल्यू को खिसकाना है वह बाईं ओर दी जाती है और खिसकाने वाले स्थानों की संख्या दाईं ओर।

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

और इसी तरह, अगर संख्या ऋणात्मक है तो यह ऑपरेटर बाईं ओर खिसकेगा।

```crystal
0b0100 >> -1
# => 0b1000
```

## बाइनरी ऑपरेटर

Crystal में बिटवाइज़ ऑपरेशन करने के लिए 3 [बाइनरी ऑपरेटर][binary] (`&`, `|`, `^`) और एक `~` ऑपरेटर है।

### बिटवाइज़ AND (`&`)

बाइनरी AND ऑपरेटर (`&`) दो वैल्यू पर बिटवाइज़ AND करता है।
यह पहली वैल्यू के हर बिट की तुलना दूसरी वैल्यू में उसी स्थान पर मौजूद बिट से करता है।
अगर दोनों बिट 1 हैं, तो परिणामी बिट 1 होता है।
वरना यह 0 होता है।

```crystal
0b0011 & 0b1010
# => 0b0010
```

### बिटवाइज़ OR (`|`)

बाइनरी OR ऑपरेटर (`|`) दो वैल्यू पर बिटवाइज़ OR करता है।
यह भी पहली वैल्यू के हर बिट की तुलना दूसरी वैल्यू में उसी स्थान पर मौजूद बिट से करता है।
अगर इनमें से कोई एक बिट 1 है, तो परिणामी बिट 1 होता है।
वरना यह 0 होता है।

```crystal
0b0011 | 0b1010
# => 0b1011
```

### बिटवाइज़ XOR (`^`)

बाइनरी XOR ऑपरेटर (`^`) बिटवाइज़ XOR करता है।
बिटवाइज़ AND और बिटवाइज़ OR ऑपरेटर की तरह, यह पहली वैल्यू के हर बिट की तुलना दूसरी वैल्यू में उसी स्थान पर मौजूद बिट से करता है।
अगर इनमें से _सिर्फ एक_ 1 है, तो परिणामी बिट 1 होता है।
वरना यह 0 होता है।

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### बिटवाइज़ NOT (`~`)

अंत में, बिटवाइज़ NOT ऑपरेटर (`~`) वैल्यू के हर बिट को उलट देता है।
बाकी बाइनरी ऑपरेटरों के उलट, यह एक यूनरी ऑपरेटर है, जो सिर्फ दाईं ओर की वैल्यू पर काम करता है।

```crystal
~0b1110_0010
# => 0b0001_1101
```
