# परिचय

किसी `while` लूप की मदद से आप कोड को बार-बार चला सकते हैं, जब तक कि कोई निश्चित शर्त पूरी होती रहे।
इसे `while` कीवर्ड से लिखा जाता है। इसके बाद गोल ब्रैकेट में लिपटी एक शर्त आती है और एक कोड ब्लॉक, जिसमें लूप का _अंदर का कोड_ कर्ली ब्रैकेट में लिपटा होता है।

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript में do-while लूप भी होता है।
यहाँ शर्त लूप के अंदर के कोड के चलाए जाने के बाद जाँची जाती है।
यह तब काम आता है जब शर्त लूप के अंदर के कोड के परिणाम पर निर्भर करती हो।

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

लूप के अंदर के कोड में आप `break` कीवर्ड का इस्तेमाल करके लूप का चलना पूरी तरह रोक सकते हैं।
इसके उलट, `continue` कीवर्ड केवल वर्तमान इटरेशन का चलना रोकता है और अगले इटरेशन पर चला जाता है।
`continue` की मदद से आप अक्सर लूप के अंदर के कोड के बड़े हिस्सों को `if` स्टेटमेंट में लपेटने से बच सकते हैं।

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
