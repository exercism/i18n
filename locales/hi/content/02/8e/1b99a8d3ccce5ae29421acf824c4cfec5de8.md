# परिचय

`case` (जो [`combinators`][combinators] में है) क्लॉज़ की सूची पर एक-एक करके चलता है और पहले मेल खाने वाले क्लॉज़ के अंदर का कोड चला देता है।

```
case ( obj assoc -- )
```

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

हर क्लॉज़ `{ value [ body ] }` के रूप का होता है। बराबरी `=` से जाँची जाती है। जो क्लॉज़ मेल खाता है, उसे चलाते समय इनपुट वैल्यू *पहले ही ले ली गई* होती है। अंत में लिखा गया `[ body ]` (जिसके साथ कोई वैल्यू नहीं होती) डिफाल्ट होता है। यह तब चलता है जब इनपुट *अब भी* स्टैक पर रहता है, इसलिए इसके कोड की शुरुआत आम तौर पर `drop` से होती है।

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
