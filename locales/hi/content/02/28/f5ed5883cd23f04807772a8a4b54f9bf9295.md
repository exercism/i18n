# डेटाबेस भुगतान बैच

## समस्या विवरण

आपको भुगतान डेटा का एक बैच `Payment` टेबल में डालना है। आपका काम है कि दी गई इनपुट JSON फाइल से भुगतान डेटा पढ़िए और JDBC Client के `batchExecute` ऑपरेशन का उपयोग करके उस भुगतान डेटा को `Payment` टेबल में डालिए। नमूना इनपुट फाइल `payments.json` के रूप में दी गई है।

इनपुट JSON फाइल की सामग्री नीचे दिए गए JSON स्कीमा पर आधारित है।

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

आपको बैच में डाले गए भुगतान डेटा के लिए ऑटो-जनरेट हुई भुगतान ID आउटपुट के रूप में लौटानी हैं और इसके लिए डेटाबेस पर कोई और क्वेरी नहीं चलानी है।

आप यह मान सकते हैं कि `payments.json` फाइल में दिए गए `employee_id` वैध हैं और पहले से ही `Employee` टेबल में मौजूद हैं।

## डेटाबेस का विवरण

इस समस्या के लिए दिए गए H2 डेटाबेस का उपयोग कीजिए।

> नमूना डेटाबेस फाइल `gofigure.mv.db` है और डेटाबेस का नाम `gofigure` है। यह `db` फोल्डर में दिया गया है।

नमूना H2 डेटाबेस में कुछ नमूना डेटा के साथ पहले से ही ये टेबल मौजूद हैं। कॉलमों के नाम और डेटा टाइप नीचे दिए गए हैं।

**टेबल का नाम** : `Employee`

| **कॉलम:**      | टाइप |
| -----------       | ----------- |
| `employee_id`     | पूर्णांक, ऑटो-इंक्रीमेंटेड प्राइमरी की       |
| `name`            | स्ट्रिंग        |
| `city`            | स्ट्रिंग        |
| `department`      | स्ट्रिंग        |
| `age`             | पूर्णांक        |

**टेबल का नाम**: `Payment`

| **कॉलम:**      | टाइप |
| -----------       | ----------- |
| `payment_id`      | पूर्णांक, ऑटो-इंक्रीमेंटेड प्राइमरी की       |
| `date`            | दिनांक        |
| `amount`          | दशमलव संख्या        |
| `employee_id`     | पूर्णांक        |
| `reason`          | स्ट्रिंग        |

* डेटाबेस फाइल `gofigure.mv.db` है। JDBC URL को `jdbc:h2:file:/path/to/db/file` के रूप में इस्तेमाल कीजिए।
* यूज़रनेम: `root`
* पासवर्ड: `root`

## प्रतिबंध

* क्वेरी और Ballerina नमूने की जाँच के लिए `db` फोल्डर में दी गई H2 डेटाबेस फाइल का उपयोग कीजिए
* अपनी Ballerina.toml में H2 डेटाबेस ड्राइवर को प्लेटफॉर्म डिपेंडेंसी के रूप में जोड़ने के लिए Maven डिपेंडेंसी पैराम्स वाला तरीका अपनाइए
* आपको डेटाबेस पर एक और क्वेरी चलाए बिना ऑटो-जनरेट हुई भुगतान ID ढूँढनी हैं।

## टेस्ट वातावरण

* आप `bal test` से टेस्ट चला सकते हैं, और यह दिए गए नमूना DB पर टेस्ट चलाएगा।

## उदाहरण

### उदाहरण 1

**इनपुट:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

नमूना `payments.json` फाइल का डेटा:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**आउटपुट:** `[1,2,3]`

## संकेत

* डेटाबेस के साथ काम करने के लिए [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) मॉड्यूल का उपयोग कीजिए
* JDBC ड्राइवर को डिपेंडेंसी के रूप में जोड़ने के चरणों के लिए [पूर्वापेक्षा](https://lib.ballerina.io/ballerinax/java.jdbc/latest) अनुभाग देखिए
* JSON इनपुट फाइल पढ़ने के लिए [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) का उपयोग कीजिए
* डेटा के साथ टाइप-सेफ तरीके से काम करने के लिए JSON वैल्यू को एप्लिकेशन-विशिष्ट टाइप में बदलिए। [उपयोगकर्ता द्वारा परिभाषित टाइप में बदलने](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) का उदाहरण देखिए
* डेटाबेस के साथ काम करने के लिए [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) और [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) रिमोट मेथड का उपयोग कीजिए
* [बैच एक्ज़ीक्यूट](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) का उदाहरण देखिए
