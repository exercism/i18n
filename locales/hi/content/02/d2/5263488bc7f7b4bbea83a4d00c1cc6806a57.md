# परिचय

एक [`switch` स्टेटमेंट][switch] की मदद से आप एक वैल्यू की तुलना कई संभावित वैल्यूओं से कर सकते हैं, जो उससे मेल खा सकती हैं।
कई `else-if` स्टेटमेंट इस्तेमाल करने की तुलना में यह आपको अधिक संक्षिप्त कोड लिखने देता है।
`switch` स्टेटमेंट की शुरुआत `switch` कीवर्ड से होती है, और उसके बाद वह वैल्यू आती है जिसकी तुलना करनी है।
इसके बाद आप `case` कीवर्ड की मदद से अलग-अलग केस तय कर सकते हैं, और हर कीवर्ड के बाद वह वैल्यू लिखते हैं जिससे तुलना करनी है।
जब कोई भी केस मेल न खाए, तो डिफ़ॉल्ट केस तय करने के लिए `default` कीवर्ड का उपयोग किया जाता है।
`else-if` स्टेटमेंट की तरह, `switch` स्टेटमेंट भी सिर्फ पहले मेल खाने वाले केस से जुड़ा कोड ब्लॉक ही चलाता है।

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

इस उदाहरण को देखिए:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

इसके बजाय इसे ऐसे लिखा जा सकता है:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## बाइंडिंग और `where` स्टेटमेंट

`switch` स्टेटमेंट में जिन वैल्यूओं का मेल कराया जाता है, उन्हें नामों से बाँधा भी जा सकता है, और उन नामों का इस्तेमाल केस के अंदर किया जा सकता है।
इन नामों का इस्तेमाल `where` क्लॉज़ में भी किया जा सकता है। ये ऐसे अतिरिक्त बूलियन एक्सप्रेशन होते हैं जिनका मान केस मेल खाने के लिए `true` होना ज़रूरी है।

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
