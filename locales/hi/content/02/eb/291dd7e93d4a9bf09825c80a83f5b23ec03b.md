# लीप वर्ष के कॉन्सेप्ट

मुझे पहला उदाहरण हल ज़्यादा पसंद है, क्योंकि उसका संक्षिप्त होना Rust की उस स्वाभाविक शैली से मेल खाता है जो मैंने देखी है। यह कैनोनिकल हल में क्लोज़र कॉन्सेप्ट जोड़ने से भी बच जाता है।

## निकाले गए कॉन्सेप्ट

### सामान्य

- बूलियन लॉजिक
  - बूलियन
- एक्सप्रेशन
  - Rust के फंक्शन अंतर्निहित रूप से एक्सप्रेशन लौटाते हैं।
- अंकगणित
  - मॉड्यूलस

### टाइप

- अनसाइन्ड पूर्णांक - `u64`
- बूलियन - `bool`

## उदाहरण अभ्यास 1

["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09) का हल

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## उदाहरण अभ्यास 2

[कैनोनिकल](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
