# परिचय

यह विषय काफी _बड़ा_ हो सकता है!
इस पर एक लंबी किताब लिखी जा सकती है, और कई लोगों ने लिखी भी है (कुछ उदाहरण देखने के लिए Amazon पर "unicode book" खोजिए)।

## बहुत संक्षिप्त इतिहास

पिछले दशकों में कंप्यूटर में अक्षरों को संभालना बहुत आसान था, जब प्रोग्रामर मानते थे कि अंग्रेज़ी ही एकमात्र महत्वपूर्ण भाषा है।
यानी 26 अक्षर, बड़े और छोटे रूप, 10 अंक, कई विराम चिह्न, और घंटी बजाने के लिए एक कोड (0x07)। यह सब 7 बिट में समा जाता था: [ASCII][wiki-ascii] अक्षर सेट।

स्वाभाविक रूप से, लोग पूछने लगे कि à, ä और Ł का क्या होगा। फिर दूसरे लोग ऄ, ஹ और ญ के बारे में पूछने लगे, और युवाओं को इमोजी 😱 चाहिए थे।
तो किया क्या जाए?

कहानी को छोटा करें तो, कई बुद्धिमान और धैर्यवान लोगों को सालों तक समितियों में काम करना पड़ा। उन्होंने [Unicode][web-unicode] अक्षर सेट और [UTF-8][wiki-utf-8] जैसी एन्कोडिंग की बारीकियाँ तय कीं। साथ ही, बहुत सारे सॉफ्टवेयर को _बहुत_ जटिल तरीके से दोबारा लिखना पड़ा।
इससे बहुत सारे नए बग भी पैदा हुए।

_सब कुछ_ टूटने से बचाने के लिए, Unicode/UTF-8 का डिज़ाइन यह सुनिश्चित करता है कि पहले 127 कोड ASCII के समान ही हों _(घंटी वाला कोड भी)_।

## Kotlin में अक्षर

लगभग 2005 के बाद बनी भाषाओं के पास यह बड़ा फायदा था कि तब तक एक काफी स्थिर Unicode मानक मौजूद था।

Kotlin (पहली बार 2011 में जारी) यह मान सकती थी कि उपयोगकर्ता कई तरह की (मानव) भाषाएँ इस्तेमाल करेंगे, और उन्हें व्यक्त करने के लिए Unicode की ज़रूरत होगी।

अक्षर लिटरल सिंगल कोट में लिखे जाते हैं, और डबल कोट में लिखी स्ट्रिंग से अलग होते हैं।
C/C++ की दुनिया से आने वालों के लिए यह शायद स्पष्ट है, लेकिन Python और JavaScript प्रोग्रामर के लिए यह उलझन भरा हो सकता है।

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

`Char` और `Int` के बीच बदलना आसान है:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

कंपाइलर `Char` पर पूर्णांक अंकगणित के _कुछ_ रूपों की अनुमति देता है:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char` के लिए कुछ फंक्शन

हमेशा की तरह, यहाँ चर्चा के लिए [कई फंक्शन][ref-char-lib] बहुत ज़्यादा हैं, इसलिए यह सिर्फ एक चयन है।

- जिन वर्णमालाओं पर लागू हो, उनमें [`uppercase()`][ref-uppercase] और [`lowercase()`][ref-lowercase] से केस बदलिए।
- केस जाँचने के लिए [`isUpperCase()`][ref-isuppercase] और [`isLowerCase()`][ref-islowercase] इस्तेमाल कीजिए।
- अक्षर का प्रकार जाँचने के लिए:
    - [`isLetter()`][ref-isletter], कई वर्णमालाओं पर लागू होता है
    - [`isDigit()`][ref-isdigit], 0..9 की सीमा में
    - `isLetterOrDigit()`, पिछले दोनों को मिलाता है
    - [`isWhitespace()`][ref-iswhitespace], कोई भी व्हाइटस्पेस अक्षर

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Char लिस्ट और स्ट्रिंग के आपसी रूपांतरण

स्ट्रिंग से Char लिस्ट बनाने के लिए हम `toList()` इस्तेमाल कर सकते हैं।

Char लिस्ट से स्ट्रिंग बनाने के लिए [`joinToString()`][ref-jointostring] फंक्शन है, जो आर्गुमेंट के रूप में एक सेपरेटर (अक्सर खाली स्ट्रिंग) लेता है।

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

ध्यान दीजिए कि `joinToString()` लिस्ट या ऐरे पर काम करता है।
किसी एक `Char` को 1 अक्षर की स्ट्रिंग में _कास्ट_ करने के लिए `toString()` इस्तेमाल कीजिए।

```kotlin
'a'.toString() // => "a"
```

यह जाँचने के लिए कि कोई अक्षर किसी `String` में, या `Char` लिस्ट या ऐरे में मौजूद है या नहीं, हमारे पास `in` है, जो [`contains()`][ref-contains] फंक्शन से जुड़ा है।

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
