# स्ट्रिंग के बारे में

Kotlin में [`string`][ref-string] Unicode अक्षरों का एक अपरिवर्तनीय क्रम है।

[`Immutable`][wiki-immutable] का मतलब है कि स्ट्रिंग पर किया गया कोई भी ऑपरेशन एक नई स्ट्रिंग लौटाता है। मूल स्ट्रिंग कभी नहीं बदल सकती।

[`Unicode`][wiki-unicode] का मतलब है कि दुनिया की ज़्यादातर लेखन प्रणालियाँ दर्शाई जा सकती हैं। लेकिन C जैसी पुरानी भाषाओं के उलट, अक्षरों और बाइट्स के बीच 1:1 संबंध नहीं होता।
इसकी चर्चा आगे [`Chars`][concept-chars] कॉन्सेप्ट में की जाएगी।

स्ट्रिंग को डबल कोट्स `" "` के बीच रखा जाता है।

कुछ अक्षरों को एस्केप करना पड़ता है: `\\`, और साथ ही `\t` (टैब) तथा `\n` (नई लाइन) जैसे वे आम अक्षर भी, जो प्रिंट नहीं होते।

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

मल्टी-लाइन स्ट्रिंग को 3 डबल कोट्स के बीच रखा जाता है, और उसमें कोई भी टेक्स्ट हो सकता है (एस्केप करने की ज़रूरत नहीं)।

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

लाइनों से आम इंडेंटेशन हटाने के लिए [trimIndent][trimIndent-doc] का इस्तेमाल कीजिए।
यह स्ट्रिंग को फॉर्मैट करने में काम आता है:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

दूसरा तरीका है [trimMargin][trimMargin-doc], जिससे आप एक डेलिमिटर तय कर सकते हैं।
तब `String` की हर लाइन उस डेलिमिटर के बाद से शुरू होती है।
डेलिमिटर का डिफॉल्ट `|` है, लेकिन आप पैरामीटर के तौर पर कोई दूसरा डेलिमिटर भी दे सकते हैं।
उदाहरण के लिए:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

स्ट्रिंग को `+` से जोड़ा जा सकता है, लेकिन इसे छोटे और सरल मामलों तक ही सीमित रखना बेहतर है।
इसके अलावा और भी तरीके हैं, जो अक्सर बेहतर होते हैं।

## स्ट्रिंग टेम्पलेट

[`Templates`][ref-templates] उसी चीज़ को कहते हैं जिसे कुछ दूसरी भाषाएँ "इंटरपोलेशन" कहती हैं।

अगर किसी स्ट्रिंग में डॉलर का चिह्न `$` हो और उसके बाद कोई आइडेंटिफायर आता है, या घुंघराले ब्रैकेट (`{expression}`) के अंदर कोई एक्सप्रेशन हो, तो वहाँ क्रमशः उस आइडेंटिफायर की वैल्यू या उस एक्सप्रेशन का परिणाम लगा दिया जाता है।

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## स्ट्रिंग फॉर्मैटिंग

JVM प्लेटफॉर्म पर ही `String.format()` आपको स्ट्रिंग टेम्पलेट से ज़्यादा सटीक फॉर्मैटिंग की सुविधा देता है। इसका [सिंटैक्स][web-formats] उन (_बहुत पुराने!_) [`printf`][wiki-printf] फंक्शनों जैसा होता है।

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

~~~~exercism/advanced
Kotlin को कई अलग-अलग टारगेट पर कंपाइल किया जा सकता है: Java Virtual Machine, JavaScript, Linux, Windows, Android और Apple के लिए नेटिव बाइनरी, और साथ ही WebAssembly के दो वेरिएंट।

हर टारगेट के लिए लगभग वही कोड इस्तेमाल किया जा सकता है, लेकिन टारगेट प्लेटफॉर्म की क्षमताएँ अलग होने से यह भी बदल जाता है कि कौन-से स्टैंडर्ड लाइब्रेरी फंक्शन समर्थित होंगे।

Exercism इस समय टेस्टिंग के लिए JVM इस्तेमाल करता है।
~~~~

## स्ट्रिंग फंक्शन

Kotlin स्ट्रिंग पर काम करने के लिए _कई_ [`functions`][ref-string-functions] देता है।

इनमें से ज़्यादातर `String` क्लास के मेंबर नहीं, बल्कि [`extensions functions`][ref-extensions] होते हैं। हालाँकि हमारे इन्हें इस्तेमाल करने के तरीके पर इसका कोई खास असर नहीं पड़ता।

~~~~exercism/note
Kotlin के [डॉक्युमेंटेशन][ref-string-functions] पेज काफ़ी जटिल हैं और डिफॉल्ट व्यू में एक्सटेंशन फंक्शन छिपा देते हैं।
यह लिखे जाने के समय, सबसे काम की जानकारी `Members & Extensions` नाम के टैब में छिपी हुई है।
उस पर क्लिक कीजिए, तो यह सेक्शन खुल जाएगा और आप `String` क्लास पर उपलब्ध सारे मेंबर और एक्सटेंशन देख सकेंगे।

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

आगे दिया गया उदाहरण उपलब्ध चीज़ों में से बस एक छोटा-सा हिस्सा दिखाता है:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## स्ट्रिंग बनाना

कभी-कभी एक लंबी स्ट्रिंग को कई चरणों में बनाना पड़ता है, जैसे किसी लूप के अंदर।

`+` से स्ट्रिंग जोड़ने का तरीका जल्दी ही न सुंदर रह जाता है और न तेज़। अपरिवर्तनीयता का मतलब है कि इसमें _बहुत_ ज़्यादा कॉपी करनी पड़ती है।

Kotlin में कई स्ट्रिंग को जोड़ने के कुछ और ज़्यादा कुशल तरीके हैं:

- स्ट्रिंग टेम्पलेट, जिनकी चर्चा ऊपर की गई है।
- [`joinToString()`][ref-jointostring], जिसकी चर्चा [ऐरे][concept-lists] कॉन्सेप्ट में की जाएगी।
- Java का [`StringBuilder`][ref-stringbuilder], जिसे खास तौर पर Kotlin का अपना तरीका नहीं माना जाता।
- Kotlin का [`buildString()`][ref-buildstring], जो `StringBuilder` को ज़्यादा संक्षिप्त और स्वाभाविक सिंटैक्स में लपेट देता है।
यह स्ट्रिंग बनाने का पूरा लॉजिक एक लैम्ब्डा आर्गुमेंट के रूप में लेता है, जिसकी चर्चा आगे किसी कॉन्सेप्ट में की जाएगी।

मोटे तौर पर `StringBuilder` एक ऐरे जैसी संरचना है, जिसमें कई काम के मेथड होते हैं। इनमें से कुछ ये हैं:

- अंत में कुछ जोड़ने के लिए [`append()`][ref-sb-append] इस्तेमाल कीजिए।
- किसी तय जगह पर जोड़ने के लिए [`insert()`][ref-sb-insert] इस्तेमाल कीजिए।
- तय जगह (या जगहों) से हटाने के लिए [`deleteAt()`][ref-sb-deleteat] और [`deleteRange()`][ref-sb-deleterange] इस्तेमाल कीजिए।
- अंत में सामान्य स्ट्रिंग में बदलने के लिए `toString()` इस्तेमाल कीजिए: यह सब कुछ एक ही तेज़ ऑपरेशन में जोड़ देता है।

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

आगे के कॉन्सेप्ट का सिंटैक्स इस्तेमाल करते हुए `buildString()` का एक उदाहरण:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
