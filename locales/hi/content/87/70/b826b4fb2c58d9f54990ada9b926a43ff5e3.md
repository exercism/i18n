# निर्देश

एंटवर्प के मार्शलिंग यार्ड में आज फिर एक व्यस्त रात है। आप ड्यूटी पर तैनात डिस्पैचर हैं: आने वाली मालवाहक कारों को जाने वाली ट्रेनों में फिर से लगाना है, कपलिंग की जाँच करनी है, जंक्शनों पर मार्ग बाँटने हैं, और बिलिंग के लिए एक जैसे कार्गो को एक साथ करना है।

हर *कार* एक स्ट्रिंग है जिसमें यह लिखा होता है कि उसमें क्या भरा है:
`"coal"`, `"timber"`, `"crates"`, आदि।

## 1. कारों को ट्रेनों में जोड़िए

`couple` फंक्शन बनाइए जो कारों का एक ऐरे और एक लंबाई `n` लेता है, और `n`-`n` कारों वाली ऐसी ट्रेनें लौटाता है जिनमें कोई कार दो बार न आए। अगर कारों की संख्या बराबर न बँटे तो अंतिम ट्रेन छोटी हो सकती है।

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. कपलिंगों पर एक नज़र डालिए

`peek-couplings` फंक्शन बनाइए जो कारों का एक ऐरे लेता है और हर पड़ोसी जोड़ी लौटाता है, ताकि निरीक्षक हर कपलिंग की जाँच कर सके।

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. जंक्शनों पर श्रृंखला बाँटिए

`split-at-junctions` फंक्शन बनाइए जो कारों का एक ऐरे और `junctions` का एक ऐरे (यानी वे कारें जो विराम बिंदु दर्शाती हैं) लेता है, और जंक्शन कारों के बीच के खंड लौटाता है। जंक्शन कारें खुद नहीं रखी जातीं।

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. एक जैसे कार्गो को एक साथ कीजिए

`coalesce-cargo` फंक्शन बनाइए जो कारों का एक ऐरे लेता है और एक ही कार्गो ढोने वाली *लगातार* कारों को एक-एक समूह में जोड़ देता है।

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
