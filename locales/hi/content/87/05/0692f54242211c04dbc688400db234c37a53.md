# परिचय

Gleam में हायर-ऑर्डर फंक्शन, यानी ऐसे फंक्शन जो दूसरे फंक्शन को आर्गुमेंट के रूप में लेते हैं, लिखना और इस्तेमाल करना आम बात है। कभी-कभी एक साथ कई हायर-ऑर्डर फंक्शन इस्तेमाल करने पर कोड में इंडेंटेशन की कई परतें बन जाती हैं और कोड पढ़ना मुश्किल हो जाता है।

उदाहरण के लिए, यहाँ एक फंक्शन है जो कई ऐसे फंक्शन कॉल करता है जो `Result(Int, Nil)` लौटाते हैं। अगर चारों सफल हों, तो यह उन वैल्यू का जोड़ देता है।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam के `use` एक्सप्रेशन हमें यह कोड बिना इंडेंटेशन के लिखने देते हैं, जिससे इसे पढ़ना अक्सर आसान हो जाता है।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

एक `use` एक्सप्रेशन ब्लॉक में आगे लिखे सारे स्टेटमेंट इकट्ठा कर लेता है और उन्हें एक कॉलबैक फंक्शन के रूप में फंक्शन कॉल के अंतिम आर्गुमेंट की तरह भेज देता है। `use` कीवर्ड और `<-` चिह्न के बीच लिखे वेरिएबल उन आर्गुमेंट के नाम होते हैं जो कॉलबैक फंक्शन को दिए जाएँगे।

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

कॉलबैक फंक्शन कितने भी आर्गुमेंट ले सकता है, या एक भी नहीं।

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

ऐसे फंक्शन बनाने के लिए, जिसे `use` एक्सप्रेशन के साथ कॉल किया जा सके, कोई खास शर्त नहीं है। बस अंतिम आर्गुमेंट के रूप में एक कॉलबैक फंक्शन लेना ज़रूरी है।

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam के `use` एक्सप्रेशन एक बहुत शक्तिशाली फीचर हैं, जिनका इस्तेमाल कई तरह की समस्याओं में किया जा सकता है। लेकिन ज़रूरत से ज़्यादा इस्तेमाल करने पर ये कोड को पढ़ना मुश्किल बना सकते हैं। इसलिए आम तौर पर सामान्य फंक्शन कॉल सिंटैक्स ही इस्तेमाल करना बेहतर माना जाता है, और `use` एक्सप्रेशन तभी अपनाने चाहिए जब उनसे कोड पढ़ने में आसान हो जाए।
