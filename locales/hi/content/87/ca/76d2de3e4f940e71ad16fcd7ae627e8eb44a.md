# संबद्ध आइटम

संबद्ध आइटम वे आइटम होते हैं जो ट्रेट में घोषित किए जाते हैं या इम्प्लीमेंटेशन में परिभाषित किए जाते हैं।

इनमें ये शामिल हैं:

- **संबद्ध फंक्शन** (मेथड की तरह)
- **संबद्ध टाइप**
- **संबद्ध कॉन्स्टेंट**
- **संबद्ध इम्प्लीमेंटेशन**

ये तार्किक रूप से जुड़ी कार्यक्षमता को किसी टाइप के साथ एक साथ रखते हैं।

उदाहरण के लिए, `Option` का `is_some` मेथड मूल रूप से `Option` से जुड़ा हुआ है।

## संबद्ध टाइप

संबद्ध टाइप ट्रेट में टाइप के लिए प्लेसहोल्डर तय करते हैं, जिन्हें इम्प्लीमेंट करने वाले तय करते हैं।

इससे ट्रेट की परिभाषाएँ लचीली और संक्षिप्त बनी रहती हैं।

उदाहरण:

```rust
trait Pack<T> {
    type Result;

    fn pack(self: T, other: T) -> Self::Result;
}

impl PackU32Impl of Pack<u32> {
    type Result = u64;

    fn pack(self: u32, other: u32) -> Self::Result {
        let shift: u64 = 0x100000000; // 2^32
        self.into() * shift + other.into()
    }
}
```

यहाँ `Result` एक संबद्ध टाइप है जिसे हर इम्प्लीमेंटेशन तय करता है।

इस ट्रेट का उपयोग करने वाले फंक्शन को अतिरिक्त जेनेरिक्स तय करने की ज़रूरत नहीं होती:

```rust
fn combine<T, impl PackImpl: Pack<T>>(a: T, b: T) -> PackImpl::Result {
    a.pack(b)
}
```

## संबद्ध कॉन्स्टेंट

संबद्ध कॉन्स्टेंट ऐसी निश्चित वैल्यू होती हैं जो किसी टाइप से जुड़ी होती हैं और किसी ट्रेट या उसके इम्प्लीमेंटेशन में परिभाषित की जाती हैं।

उदाहरण:

```rust
trait Shape<T> {
    const SIDES: u32;
    fn describe() -> ByteArray;
}

struct Triangle {}

impl TriangleShape of Shape<Triangle> {
    const SIDES: u32 = 3;
    fn describe() -> ByteArray {
        "I am a triangle."
    }
}

struct Square {}

impl SquareShape of Shape<Square> {
    const SIDES: u32 = 4;
    fn describe() -> ByteArray {
        "I am a square."
    }
}
```

इससे `SIDES` जैसे कॉन्स्टेंट कहीं और हार्डकोड करने के बजाय `Shape` से जुड़ जाते हैं।

## संबद्ध इम्प्लीमेंटेशन

संबद्ध इम्प्लीमेंटेशन टाइप और ट्रेट के बीच के संबंधों को अनिवार्य बनाते हैं।

उदाहरण के लिए:

```rust
// Collection type that contains a simple array
#[derive(Drop)]
pub struct ArrayIter<T> {
    array: Array<T>,
}

// T is the collection type
pub trait Iterator<T> {
    type Item;
    fn next(ref self: T) -> Option<Self::Item>;
}

impl ArrayIterator<T> of Iterator<ArrayIter<T>> {
    type Item = T;
    fn next(ref self: ArrayIter<T>) -> Option<T> {
        self.array.pop_front()
    }
}

/// Turns a collection of values into an iterator
pub trait IntoIterator<T> {
    /// The iterator type that will be created
    type IntoIter;
    impl Iterator: Iterator<Self::IntoIter>;

    fn into_iter(self: T) -> Self::IntoIter;
}

impl ArrayIntoIterator<T> of IntoIterator<Array<T>> {
    type IntoIter = ArrayIter<T>;
    fn into_iter(self: Array<T>) -> Self::IntoIter {
        ArrayIter { array: self }
    }
}
```

यह गारंटी देता है कि `Array` को हमेशा एक इटरेटर (`IntoIter`) में बदला जा सकता है, जिससे निरंतरता और टाइप की सुरक्षा बनी रहती है।
