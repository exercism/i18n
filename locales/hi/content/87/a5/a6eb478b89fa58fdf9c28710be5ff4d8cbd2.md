# परिचय

`List` और `Array` काफी मिलते-जुलते हैं। लेकिन इन दोनों में कुछ बड़े अंतर हैं, जिन्हें आप छोड़ना नहीं चाहेंगे:

1. लिस्ट को चौकोर ब्रैकेट, यानी `[0]`, से इंडेक्स नहीं किया जा सकता।
2. लिस्ट को बनाते समय ही वैल्यू नहीं दी जा सकती।
3. लिस्ट कॉम्प्रिहेंशन जैसी कोई सुविधा नहीं है।
4. लिस्ट पर इटरेशन करते समय आप उसके एलिमेंट को आसानी से बदल सकते हैं।

`List` `haxe.ds` पैकेज का हिस्सा है, इसलिए जब भी आपको लिस्ट इस्तेमाल करनी हो, आपको उसका पैकेज इंपोर्ट करना पड़ता है:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
