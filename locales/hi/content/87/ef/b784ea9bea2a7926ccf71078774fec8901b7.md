# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जो इस तरह बनी होती है: `"[<LEVEL>]: <MESSAGE>"`।

लॉग के तीन अलग-अलग लेवल होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके सामने तीन काम हैं। हर काम में आपको एक लॉग लाइन दी जाएगी और उसके साथ कुछ करना होगा।

## 1. लॉग लाइन से मैसेज निकालिए

लॉग लाइन का मैसेज लौटाने के लिए (_static_) `LogLine.Message()` मेथड बनाइए:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

शुरू या अंत में मौजूद अतिरिक्त खाली जगह हटा दी जानी चाहिए:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

(_static_) `LogLine.LogLevel()` मेथड बनाइए, जो लॉग लाइन का लॉग लेवल लौटाता है। यह लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. लॉग लाइन को नए रूप में लिखिए

(_static_) `LogLine.Reformat()` मेथड बनाइए, जो लॉग लाइन को नया रूप देता है: मैसेज पहले आता है और उसके बाद कोष्ठकों में लॉग लेवल।

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
