# फंक्शन हेडर का उपयोग

[comment]: # (यह एरर तब मिलती है जब हल में फंक्शन हेडर का उपयोग किया गया हो)

फंक्शन हेडर (यानी बिना बॉडी वाला फंक्शन) की ज़रूरत सिर्फ़ उन फंक्शनों में होती है जिनके डिफ़ॉल्ट आर्गुमेंट हों और जिनमें एक से अधिक क्लॉज़ हों।

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

जिन फंक्शनों के डिफ़ॉल्ट आर्गुमेंट हों और जिनमें सिर्फ़ एक ही क्लॉज़ हो, उनमें डिफ़ॉल्ट आर्गुमेंट सीधे उसी क्लॉज़ में दिए जा सकते हैं।

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

फंक्शन `two_fer/1` को सिर्फ़ एक ही क्लॉज़ की ज़रूरत है, इसलिए उसे फंक्शन हेडर की ज़रूरत नहीं है।
