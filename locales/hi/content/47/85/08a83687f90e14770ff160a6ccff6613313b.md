# ट्यूपल

ट्यूपल, अलग-अलग तरह के डेटा के एक निश्चित समूह को एक साथ रखने का एक हल्का-फुल्का तरीका है। ट्यूपल का कोई खास नाम नहीं होता; किसी डेटा स्ट्रक्चर को नाम देने से वह `struct` बन जाता है। ट्यूपल के फील्ड के नाम नहीं होते; उन तक डीस्ट्रक्चरिंग के ज़रिए या स्थिति के आधार पर पहुँचा जाता है।

## सिंटैक्स

ट्यूपल फील्ड की एक सूची होता है, जिसे गोल ब्रैकेट से घेरा जाता है:

- `()` `unit type` है, जो एक [खास मामला](https://doc.rust-lang.org/std/primitive.unit.html) है
- **(** _एक्सप्रेशन_ **,)** एक एलिमेंट वाला ट्यूपल एक्सप्रेशन है
- **(** _टाइप_ **,)** एक एलिमेंट वाला ट्यूपल टाइप है
- **(** _एक्सप्रेशन_ **,** ... **)** सामान्य ट्यूपल एक्सप्रेशन है
- **(** _टाइप_ **,** ... **)** सामान्य ट्यूपल टाइप है

### बनाना

ट्यूपल हमेशा एक ट्यूपल एक्सप्रेशन से बनते हैं:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

ट्यूपल में कितने भी एलिमेंट हो सकते हैं।

### डीस्ट्रक्चरिंग से पहुँचना

ट्यूपल के एलिमेंट तक डीस्ट्रक्चरिंग से पहुँचा जा सकता है। इसका मतलब बस इतना है कि ट्यूपल के हर एलिमेंट को एक वेरिएबल का नाम दे दिया जाता है, और इस तरह ट्यूपल इस्तेमाल हो जाता है।

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### स्थिति के आधार पर पहुँचना

ट्यूपल के एलिमेंट तक संख्या वाली स्थिति के इंडेक्स से भी पहुँचा जा सकता है। इंडेक्स हमेशा की तरह 0 से शुरू होता है।

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## ट्यूपल स्ट्रक्ट

आपको ट्यूपल स्ट्रक्ट के साथ भी काम करना होगा। सामान्य स्ट्रक्ट की तरह ये भी नाम वाले टाइप होते हैं; लेकिन सामान्य स्ट्रक्ट से अलग, इनके फील्ड बेनाम होते हैं। इनका सिंटैक्स सामान्य ट्यूपल सिंटैक्स से बहुत मिलता-जुलता है। इनमें डीस्ट्रक्चरिंग और स्थिति के आधार पर पहुँचना, दोनों का इस्तेमाल किया जा सकता है।

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### फील्ड की विज़िबिलिटी

बेनाम ट्यूपल के सारे फील्ड हमेशा पब्लिक होते हैं। लेकिन ट्यूपल स्ट्रक्ट के फील्ड की अपनी अलग-अलग विज़िबिलिटी होती है, जो सामान्य स्ट्रक्ट के फील्ड की तरह डिफ़ॉल्ट रूप से प्राइवेट होती है। सामान्य स्ट्रक्ट की तरह ही आप `pub` मॉडिफायर से फील्ड को पब्लिक बना सकते हैं।

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
