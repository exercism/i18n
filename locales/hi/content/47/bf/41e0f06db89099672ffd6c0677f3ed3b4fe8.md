# इंस्टॉलेशन

elm का मौजूदा वर्ज़न 0.19.1 है।
भाषा के विकास के साथ इंस्टॉलेशन के निर्देश भी बदलते रहते हैं।
इंस्टॉलेशन के सबसे नए निर्देशों के लिए [elm गाइड के इंस्टॉलेशन निर्देश][elm-install] देखिए।

[elm-install]: https://guide.elm-lang.org/install/elm.html

## अतिरिक्त टूल

**elm-test**

कमांड लाइन से टेस्ट चलाने के लिए जिस टूल का उपयोग किया जाता है, उसे elm-test कहते हैं।
फिलहाल elm-test के लिए Node.js और npm ज़रूरी हैं, इसलिए अगर आपने अभी तक इन्हें इंस्टॉल नहीं किया है
तो कृपया [पहले Node.js और npm इंस्टॉल कीजिए][npm-install]।
npm इंस्टॉल हो जाने के बाद आप elm-test इस तरह इंस्टॉल कर सकते हैं:

```shell
npm install --global elm-test@latest-0.19.1
```

ज़्यादा जानकारी [elm-test के npm होम पेज][elm-test] पर उपलब्ध है।

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

ज़्यादातर elm प्रोग्रामर अपने elm कोड को फॉर्मेट करने के लिए elm-format का उपयोग करते हैं।
यह बिना किसी कॉन्फ़िगरेशन के चलने वाला कोड फॉर्मेटिंग टूल है।
अगर आप ऑटोमैटिक फॉर्मेटिंग टूल के आदी नहीं हैं, तो शुरू में यह थोड़ा खटक सकता है।
लेकिन एक बार आदत पड़ जाने के बाद आप सोचने लगेंगे कि पहले इसके बिना आप कोड कैसे लिखते थे।
इसे npm से भी इंस्टॉल किया जा सकता है:

```shell
npm install --global elm-format@latest-0.19.1
```

ज़्यादा जानकारी [GitHub पर elm-format के होम पेज][elm-format] पर उपलब्ध है।

[elm-format]: https://github.com/avh4/elm-format

**टेक्स्ट एडिटर**

कम से कम [IntelliJ][intellij] में Elm का सपोर्ट अच्छा है, और VS Code, Sublime Text या Vim जैसे उन
टेक्स्ट एडिटर में भी जो [elm language server][els] के साथ काम करते हैं।

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## npm के साथ परमिशन एरर

elm-test या elm-format इंस्टॉल करते समय आपको npm के साथ EACCESS परमिशन एरर मिल सकती है।
अगर ऐसा हो, तो कृपया npm की वेबसाइट पर दिए निर्देशों का पालन कीजिए।
[पैकेज ग्लोबली इंस्टॉल करते समय आने वाली EACCES परमिशन एरर ठीक करना][eaccess]।

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
