# निर्देश परिशिष्ट

## ट्री को प्रिंट करना

इस अभ्यास में पहले से परिभाषित कुछ क्लास मेथड मौजूद हैं, जो ट्री को एक अच्छे फॉर्मेट में प्रिंट करने में मदद करते हैं।
इनका मुख्य उद्देश्य डीबगिंग में मदद करना और चीज़ों को अधिक साफ़ बनाना है।
अगर आप क्लास का बाकी हिस्सा सही तरीके से लागू करते हैं, तो ये मेथड आपके लिए ट्री प्रिंट कर देंगे।

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
