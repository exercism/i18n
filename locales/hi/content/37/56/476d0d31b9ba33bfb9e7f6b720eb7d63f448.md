# परिचय

प्रोग्रामिंग में एरर को समझदारी से सँभालना बहुत ज़रूरी है, ताकि कोई अनपेक्षित स्थिति प्रोग्राम को क्रैश न करा दे या उसका व्यवहार अनिश्चित न हो जाए।
एरर सँभालने के लिए Cairo दो मुख्य तरीके देता है:

1. `panic` के साथ **ऐसी एरर जिसे सँभाला नहीं जा सकता**, जो प्रोग्राम को तुरंत रोक देती है।
2. `Result` के साथ **ऐसी एरर जिसे सँभाला जा सकता है**, जिससे प्रोग्राम एरर को सँभालकर उस पर प्रतिक्रिया दे सकता है।

## `panic` के साथ सँभाली न जा सकने वाली एरर

कभी-कभी किसी प्रोग्राम में ऐसी गंभीर एरर आ जाती है कि वह आगे बढ़ ही नहीं सकता।
ऐसी स्थितियों में Cairo तुरंत रोकने के लिए `panic` फंक्शन का उपयोग करता है।
यह तब मददगार होता है जब कोई एरर, जैसे ऐरे की सीमा से बाहर के इंडेक्स तक पहुँचने की कोशिश, प्रोग्राम के लिए समझदारी से आगे बढ़ना असंभव बना देती है।
`panic` फंक्शन एक `ByteArray` संदेश लेता है, जो बताता है कि एरर क्यों हुई।

उदाहरण के लिए, Cairo में:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

यह उदाहरण एक जबरन पैनिक दिखाता है, जो एक संदेश के साथ प्रोग्राम को तुरंत रोक देता है।

### `assert!` मैक्रो

`assert!` मैक्रो आपके कोड में कुछ खास शर्तें लागू करने का एक काम का टूल है।
अगर `assert!` में दी गई शर्त `false` निकलती है, तो प्रोग्राम एक `ByteArray` एरर संदेश के साथ तुरंत रुक जाता है।
विकास के दौरान अपनी मान्यताएँ जाँचने और यह पक्का करने के लिए कि वैल्यू कुछ तय मानदंडों पर खरी उतरती हैं, इसका अक्सर उपयोग किया जाता है।

उदाहरण के लिए:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

अगर `x` शून्य से बड़ा नहीं है, तो प्रोग्राम `"x must be greater than zero"` संदेश के साथ रुक जाएगा। `assert!` बिना हाथ से एरर सँभालने वाला कोड लिखे, इनवेरिएंट और प्रीकंडिशन जाँचने में मददगार है।

## `Result` के साथ सँभाली जा सकने वाली एरर

सभी एरर के लिए प्रोग्राम रोकना ज़रूरी नहीं होता।
कुछ एरर को समझदारी से सँभाला जा सकता है, ताकि प्रोग्राम आगे चलता रहे।
Cairo का `Result` एनम इन सँभाली जा सकने वाली एरर को दर्शाता है, और इसके दो रूप होते हैं:

- `Result::Ok` सफलता दर्शाता है।
- `Result::Err` किसी एरर को दर्शाता है।

`Result` का उपयोग करके कोई फंक्शन या तो सफलता की वैल्यू लौटा सकता है या एरर। इससे कॉल करने वाला फंक्शन तय कर सकता है कि आगे क्या करना है।

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

इस उदाहरण में, अगर `b` शून्य है तो एरर लौटाई जाती है; वरना भाग का परिणाम लौटाया जाता है।
