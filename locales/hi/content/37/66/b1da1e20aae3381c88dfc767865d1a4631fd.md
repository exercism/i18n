# निर्देश परिशिष्ट

## ट्रैक-विशिष्ट निर्देश

इन फंक्शन को गुणनफल और factors ऐरे का ऑफसेट और लंबाई लौटाना होता है। factors को मेमोरी में बस i32 के जोड़ों के रूप में लिखा जाता है:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

सबसे बड़े एक-अंकीय पैलिंड्रोम गुणनफल के लिए यह कुछ इस तरह दिखेगा:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
