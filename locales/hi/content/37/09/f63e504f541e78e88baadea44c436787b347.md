# स्ट्रिंग

Crystal में [`String`][strings] नाम का एक टाइप होता है, जिसका उपयोग टेक्स्ट दर्शाने के लिए किया जाता है।
Crystal की स्ट्रिंग यूनिकोड अक्षरों का अनुक्रम होती है।
स्ट्रिंग अपरिवर्तनीय होती हैं, यानी एक बार बन जाने के बाद उन्हें बदला नहीं जा सकता।
इसका मतलब है कि जब भी आप किसी स्ट्रिंग में बदलाव करते हैं, तब एक नई स्ट्रिंग बनती है। इसलिए मूल स्ट्रिंग में कोई बदलाव नहीं होता।

स्ट्रिंग बनाने के लिए आप डबल कोट्स `"` का उपयोग करते हैं।

```crystal
"Hello World"
```

## जोड़ना

दो स्ट्रिंग जोड़ने के लिए `+` ऑपरेटर का उपयोग कीजिए।
`+` ऑपरेटर दोनों स्ट्रिंग को मिलाकर एक नई स्ट्रिंग लौटाता है।

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## स्ट्रिंग और संख्याओं के बीच रूपांतरण

`to_i` मेथड एक स्ट्रिंग को पूर्णांक में बदल देता है।
इसके अलावा, `to_f` मेथड से दशमलव संख्या लौटाई जा सकती है।
अगर स्ट्रिंग को संख्या में नहीं बदला जा सकता, तो `ArgumentError` उठाया जाता है।

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

`to_s` मेथड की मदद से पूर्णांक या दशमलव संख्या को स्ट्रिंग में बदला जा सकता है।

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## इंटरपोलेशन

इंटरपोलेशन स्ट्रिंग जोड़ने और स्ट्रिंग के अंदर एक्सप्रेशन डालने का एक सुविधाजनक तरीका है।
किसी स्ट्रिंग में इंटरपोलेशन करने के लिए `#` अक्षर लिखिए और उसके बाद घुंघराले ब्रैकेट `{}` लगाइए, जिनके अंदर एक्सप्रेशन होता है।

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal एक्सप्रेशन के परिणाम को अपने आप स्ट्रिंग में बदल देता है।

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## आकार

जब आपको किसी स्ट्रिंग में अक्षरों की संख्या जाननी हो, तो `size` मेथड का उपयोग कीजिए, जो स्ट्रिंग की लंबाई पूर्णांक के रूप में लौटाता है।
किसी स्ट्रिंग का आकार उस स्ट्रिंग की एक संग्रहीत प्रॉपर्टी है, इसलिए हर बार मेथड कॉल करने पर आकार दोबारा निकालना नहीं पड़ता। इसी वजह से यह बहुत तेज़ होता है।

```crystal
"Hello World".size
# => 11
```

## इंडेक्सिंग

इंडेक्सिंग का इस्तेमाल तब होता है जब आपको स्ट्रिंग से कोई खास अक्षर निकालना हो।
`String` से कोई अक्षर निकालने के लिए आप वही जानी-पहचानी ब्रैकेट नोटेशन इस्तेमाल कर सकते हैं।

~~~~exercism/note
`[]` को `String` का एक इंस्टेंस मेथड के रूप में लागू किया गया है, जिसमें इंडेक्स मेथड का आर्गुमेंट होता है।
~~~~

किसी स्ट्रिंग का पहला अक्षर इंडेक्स 0 पर होता है।

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

स्ट्रिंग के अंत से कोई अक्षर निकालने के लिए आप स्ट्रिंग की लंबाई में से एक घटाकर अंतिम अक्षर का इंडेक्स निकाल सकते हैं। दूसरे अंतिम अक्षर के लिए लंबाई में से दो घटाइए, और इसी तरह आगे भी।
इसका एक आसान तरीका भी है: बस ऋणात्मक इंडेक्स इस्तेमाल कीजिए। इसमें अंतिम अक्षर का इंडेक्स -1 होता है, दूसरे अंतिम अक्षर का -2, और इसी तरह आगे भी।

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### सबस्ट्रिंग की जाँच

Crystal में इंडेक्सिंग की मदद से यह जाँचा जा सकता है कि किसी स्ट्रिंग में कोई सबस्ट्रिंग मौजूद है या नहीं।
इसमें भी वही ब्रैकेट नोटेशन काम करता है, बस इंडेक्स की जगह सबस्ट्रिंग दी जाती है।
अगर सबस्ट्रिंग स्ट्रिंग में मिल जाती है, तो वही सबस्ट्रिंग लौटा दी जाती है, वरना `NilAssertionError` उठाया जाता है।

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

अगर आपको सबस्ट्रिंग मिली है या नहीं, यह बताने के लिए `Bool` वैल्यू चाहिए, तो `includes?` मेथड का उपयोग कीजिए।

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## एस्केपिंग

कुछ अक्षर स्ट्रिंग में सीधे नहीं लिखे जा सकते, उनके लिए एस्केप सीक्वेंस इस्तेमाल करना पड़ता है।
उदाहरण के लिए, अगर आप स्ट्रिंग में डबल कोट्स इस्तेमाल करना चाहते हैं, तो डबल कोट्स को एस्केप करना पड़ता है।
एस्केप सीक्वेंस लिखने के लिए `\` अक्षर लगाइए और उसके बाद वह अक्षर, जिसे एस्केप करना है।

Crystal के ये विशेष अक्षर हैं:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | अलर्ट                         |
| `\b`     | बैकस्पेस                      |
| `\e`     | एस्केप                        |
| `\f`     | फॉर्म फीड                     |
| `\n`     | लाइन फीड या नई लाइन           |
| `\r`     | कैरिज रिटर्न                   |
| `\t`     | आड़ा टैब                      |
| `\v`     | खड़ा टैब                      |
| `\\`     | बैकस्लैश                      |
| `\'`     | सिंगल कोट                     |
| `\"`     | डबल कोट                       |
| `\377`   | ऑक्टल ASCII अक्षर             |
| `\xFF`   | हेक्साडेसिमल ASCII अक्षर      |
| `\uFFFF` | हेक्साडेसिमल यूनिकोड अक्षर     |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## मल्टी-लाइन स्ट्रिंग

मल्टी-लाइन स्ट्रिंग लिखने के लिए वही सिंटैक्स इस्तेमाल कीजिए जो सिंगल-लाइन स्ट्रिंग का है, बस स्ट्रिंग में जितनी लाइनें चाहिए, हर लाइन के लिए नई लाइन बनाइए।

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## यूनिकोड

[Unicode][unicode] अलग-अलग लेखन प्रणालियों में टेक्स्ट को एन्कोड करने, दर्शाने और प्रोसेस करने का एक मानक है।
यूनिकोड 100,000 से ज़्यादा अक्षरों को सपोर्ट करता है, जिनमें अक्षर, विराम चिह्न, प्रतीक और इमोजी शामिल हैं।

चूँकि Crystal स्ट्रिंग के लिए यूनिकोड इस्तेमाल करता है, आप स्ट्रिंग में इमोजी भी रख सकते हैं।

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

कभी-कभी आपको ऐसा अक्षर इस्तेमाल करना होता है जो आपके एडिटर या सिस्टम में मौजूद नहीं होता।
ऐसी स्थिति में आप उस अक्षर को लिखने के लिए यूनिकोड एस्केप सीक्वेंस इस्तेमाल कर सकते हैं।

```crystal
"\u{1F310}"
# => "🌐"
```
