# परिचय

Haxe में एब्सट्रैक्ट टाइप एक ऐसा टाइप है, जो रनटाइम पर अलग टाइप होता है। यह कंपाइल टाइम का एक फीचर है, जो ठोस टाइप के "ऊपर" टाइप परिभाषित करता है, ताकि उनके व्यवहार को बदला जा सके या उसका विस्तार किया जा सके:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

यहाँ हम `abstract` कीवर्ड का इस्तेमाल करके `AbstractInt` टाइप घोषित कर रहे हैं। इसका सिंटैक्स `class` के सिंटैक्स से काफी मिलता-जुलता है। और क्लासों की तरह ही एब्सट्रैक्ट टाइप में भी मेथड हो सकते हैं। इन्हें भी क्लासों की तरह इंस्टैंशिएट किया जा सकता है और इस्तेमाल किया जा सकता है:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

जैसा कि ऊपर बताया गया है, एब्सट्रैक्ट टाइप कंपाइल टाइम का एक फीचर है। ऊपर दिए उदाहरण को JavaScript में कंपाइल करने पर यह परिणाम मिलता है:

```javascript
var a = 12;
console.log(a)
```

आउटपुट से `AbstractInt` एब्सट्रैक्ट टाइप पूरी तरह गायब हो जाता है। ऐसा इसलिए होता है क्योंकि `Abstract` का कंस्ट्रक्टर [इनलाइन][inline] किया जाता है, जिसे हम आगे देखेंगे।

[inline]: https://haxe.org/manual/class-field-inline.html
