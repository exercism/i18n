# निर्देश

नमस्ते, एजेंट Double-Null0111।

आपका मिशन यह है (अगर आप इसे स्वीकार करना चाहें): UMBRA (United Minions Being Really Awful) के मुख्यालय में घुसकर उनकी नई बहुत भयानक चाल की योजनाएँ बरामद करने के लिए आपको दो टूल लिखने होंगे।
इस मिशन को पूरा करने के लिए आपको तीन टूल की ज़रूरत होगी।

## 1. एक आईडी नंबर बनाइए

हर मिनियन की एक अनोखी आईडी होती है, जो हर दिन बदलती है और इस पर निर्भर करती है कि उसके पास कितने रहस्य हैं और वह कितने घंटे सोता है।
आपको एक ऐसा फंक्शन लिखना होगा जो दिन (एक `Int` के रूप में) लेता है और उस दिन के लिए एक आईडी बनाने वाला फंक्शन बनाता है।
यह आईडी बनाने वाला फंक्शन दो पैरामीटर लेता है:

1. उसके पास मौजूद रहस्यों की संख्या
2. मिनियन के सोने के घंटों की संख्या

आईडी इस तरह निकाली जाती है:

1. रहस्यों की संख्या को सोने के घंटों की संख्या से गुणा कीजिए
2. परिणाम में दिन (जिसे एक `Int` से दर्शाया गया है) जोड़िए

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. बरामद गुप्त योजनाओं को एक गुप्त पासवर्ड से सुरक्षित कीजिए

एक बार गुप्त योजनाएँ आपके हाथ लग जाएँ, तो आपको उन्हें इस तरह सुरक्षित करना होगा कि सिर्फ पासवर्ड जानने वाले ही उन्हें बरामद कर सकें।
इसके लिए आपको `protectSecret(secret: String, password: String) : (String) -> String` फंक्शन लागू करना होगा।
यह फंक्शन एक और फंक्शन लौटाता है, जो संभावित पासवर्ड स्ट्रिंग को इनपुट के रूप में लेता है।
अगर डाला गया पासवर्ड सही है, तो यह नया फंक्शन छिपा हुआ रहस्य लौटाता है, लेकिन अगर पासवर्ड गलत है, तो यह फंक्शन "Sorry. No hidden secrets here." लौटाता है।

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. गुप्त पासवर्ड ढूँढिए

UMBRA के ठिकाने में कई कमरे हैं, जिनकी सुरक्षा एक गार्ड करता है, और वह आपसे गुप्त पासवर्ड पूछेगा।
यह गुप्त पासवर्ड कमरे के नंबर पर निर्भर करता है।
दुर्भाग्य से, पासवर्ड निकालने का एल्गोरिदम हमें सिर्फ आधा पता है।
बाकी आधा हिस्सा किसी एक मिनियन से पूछकर पता लगाया जा सकता है।

`getPassword` फंक्शन लागू कीजिए, जो नीचे दी गई चीज़ें लेता है और पासवर्ड लौटाता है:

1. कमरे का नंबर
2. मिनियन का फंक्शन और गुप्त पासवर्ड लौटाता है

गुप्त पासवर्ड उस मिनियन के फंक्शन को उस एल्गोरिदम को दर्शाने वाले एक और फंक्शन के साथ कॉल करके निकाला जाता है, जो हमें पता है।
एल्गोरिदम का हमारा हिस्सा:

1. दो संख्याएँ लेता है और उन्हें जोड़ देता है
2. परिणाम को कमरे की आईडी से गुणा करता है

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
