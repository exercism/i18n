# परिचय

## वेरिएबल

Elixir एक डायनामिक टाइप वाली भाषा है, यानी किसी वेरिएबल का टाइप रनटाइम पर ही जाँचा जाता है। मैच `=` ऑपरेटर की मदद से हम किसी भी टाइप की वैल्यू को किसी वेरिएबल के नाम से बाँध सकते हैं:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## मॉड्यूल

Elixir एक [फंक्शनल प्रोग्रामिंग भाषा][functional-programming] है और इसमें सभी नाम वाले फंक्शन को किसी _मॉड्यूल_ के अंदर ही बनाना पड़ता है। मॉड्यूल बनाने के लिए `defmodule` कीवर्ड का उपयोग किया जाता है। रनटाइम पर हर मॉड्यूल बाकी सभी मॉड्यूल के लिए उपलब्ध रहता है, और प्रोग्राम के दूसरे हिस्सों को उसे दिखाने के लिए किसी _एक्सेस मॉडिफायर_ की ज़रूरत नहीं पड़ती। _मॉड्यूल_ दूसरी प्रोग्रामिंग भाषाओं की _क्लास_ जैसा होता है।

```elixir
defmodule Calculator do
  # ...
end
```

## नाम वाले फंक्शन

_नाम वाले फंक्शन_ किसी मॉड्यूल के अंदर ही बनाए जाने चाहिए। _पब्लिक_ नाम वाला फंक्शन बनाने के लिए `def` कीवर्ड का उपयोग किया जाता है।

हर फंक्शन में शून्य या उससे अधिक आर्गुमेंट हो सकते हैं। फंक्शन के अंदर अंतिम एक्सप्रेशन की वैल्यू हमेशा _अपने आप लौटा दी जाती है_।

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

किसी फंक्शन को कॉल करने के लिए हम उसके मॉड्यूल और फंक्शन का नाम लिखते हैं और फंक्शन के हर आर्गुमेंट के लिए वैल्यू पास करते हैं।

```elixir
sum = Calculator.add(1, 2)
# => 3
```

`def` की जगह `defp` कीवर्ड का उपयोग करके _प्राइवेट_ फंक्शन भी बनाया जा सकता है। प्राइवेट फंक्शन का उपयोग केवल उसी मॉड्यूल के अंदर से किया जा सकता है जिसने उसे बनाया है।

जिस मॉड्यूल में फंक्शन बनाया गया है, उसी के अंदर से उसे कॉल करते समय मॉड्यूल का नाम लिखना ज़रूरी नहीं है।

छोटे फंक्शन आप एक लाइन वाले सिंटैक्स में भी लिख सकते हैं (ध्यान दीजिए कि `do` कीवर्ड से पहले कॉमा `,` और उसके बाद कोलन `:` लगता है)।

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## फंक्शन की आरिटी

फंक्शन को अक्सर उनकी _आरिटी_ के साथ पुकारा जाता है। किसी फंक्शन की _आरिटी_ उन आर्गुमेंट की संख्या होती है जो वह स्वीकार करता है।

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## नाम रखने के नियम

मॉड्यूल के नाम `PascalCase` में लिखे जाने चाहिए। मॉड्यूल के नाम की शुरुआत बड़े अक्षर `A-Z` से होनी चाहिए और उसमें अक्षर `a-zA-Z`, संख्याएँ `0-9` और अंडरस्कोर `_` हो सकते हैं।

वेरिएबल और फंक्शन के नाम `snake_case` में लिखे जाने चाहिए। वेरिएबल या फंक्शन के नाम की शुरुआत छोटे अक्षर `a-z` या अंडरस्कोर `_` से होनी चाहिए, उसमें अक्षर `a-zA-Z`, संख्याएँ `0-9` और अंडरस्कोर `_` हो सकते हैं, और वह प्रश्नवाचक चिह्न `?` या विस्मयादिबोधक चिह्न `!` पर खत्म हो सकता है।

## मानक लाइब्रेरी

Elixir की मानक लाइब्रेरी बहुत समृद्ध है और उसका डॉक्युमेंटेशन अच्छी तरह लिखा गया है। यह डॉक्युमेंटेशन ऑनलाइन [hexdocs.pm/elixir][docs] पर उपलब्ध है। इस लिंक को कहीं सेव कर लीजिए, आपको इसकी बहुत ज़रूरत पड़ेगी!

ज़्यादातर बिल्ट-इन डेटा टाइप के लिए एक ऐसा मॉड्यूल होता है जिसमें उस डेटा टाइप पर काम करने वाले फंक्शन मिलते हैं। जैसे पूर्णांक के लिए `Integer` मॉड्यूल है, स्ट्रिंग के लिए `String` मॉड्यूल, ऐरे के लिए `List` मॉड्यूल, और इसी तरह आगे भी।

एक खास मॉड्यूल `Kernel` मॉड्यूल है। यह वे बुनियादी सुविधाएँ देता है जिनके ऊपर बाकी पूरी मानक लाइब्रेरी बनी है, जैसे गणितीय ऑपरेटर, कंट्रोल फ्लो मैक्रो और बहुत कुछ। `Kernel` मॉड्यूल के फंक्शन अपने आप इम्पोर्ट हो जाते हैं, इसलिए आप उन्हें `Kernel.` प्रीफिक्स के बिना भी इस्तेमाल कर सकते हैं।
