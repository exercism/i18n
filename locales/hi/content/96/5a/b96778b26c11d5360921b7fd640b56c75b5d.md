# निर्देश

बोसन हर दिन डेक पर वॉच ब्रीफिंग करता है: एक तय अभिवादन, फिर ड्यूटी पर मौजूद चालक दल की नाम-पुकार, और अंत में विदाई। आप ब्रीफिंग को छोटी-छोटी नामित पंक्तियों में बाँटेंगे और फिर उन्हें जोड़कर बनाएँगे।

इस अभ्यास के लिए आप **दो फाइलों** में बदलाव करेंगे:

- `bosuns-briefing/helpers/helpers.factor` में छोटे, दोबारा इस्तेमाल होने वाले टुकड़े रहते हैं। वोकैबुलरी: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor` मुख्य फाइल है, जो हेल्परों को जोड़कर ब्रीफिंग तैयार करती है। वोकैबुलरी: `bosuns-briefing`.

## 1. अभिवादन

`helpers.factor` में `greeting` ऐसा बनाइए कि वह तय शुरुआती स्ट्रिंग `"All hands, attention!"` लौटाए।

```factor
greeting .
! => "All hands, attention!"
```

## 2. चालक दल की पंक्ति

`helpers.factor` में `crew-line` ऐसा बनाइए कि वह एक नाम की स्ट्रिंग ले और उस नाम से पहले `"  - "` लगाकर लौटाए (दो स्पेस, एक डैश और एक स्पेस)।

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. विदाई

`helpers.factor` में `closing` ऐसा बनाइए कि वह तय विदाई स्ट्रिंग `"Carry on."` लौटाए।

```factor
closing .
! => "Carry on."
```

## 4. नामावली

`bosuns-briefing.factor` में `roster` ऐसा बनाइए कि वह चालक दल के नामों का एक ऐरे ले और एक ही स्ट्रिंग लौटाए जिसमें कई पंक्तियाँ हों। उस स्ट्रिंग में हर नाम `crew-line` से फॉर्मेट किया गया हो और सभी नाम न्यूलाइन से जुड़े हों।

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. ब्रीफिंग

`bosuns-briefing.factor` में `briefing` ऐसा बनाइए कि वह चालक दल के नामों का एक ऐरे ले और पूरी ब्रीफिंग एक ही स्ट्रिंग के रूप में लौटाए: पहली पंक्ति में अभिवादन, उसके बाद की पंक्तियों में नामावली, और अंतिम पंक्ति में विदाई। इसके लिए हेल्परों और `roster` का इस्तेमाल कीजिए।

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
