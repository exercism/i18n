# परिचय

C# में, [`null` लिटरल][null-keyword] का इस्तेमाल किसी वैल्यू के न होने को दर्शाने के लिए किया जाता है। एक _नेबल_ टाइप ऐसा टाइप होता है जिसमें `null` वैल्यू रखी जा सकती है।

C# 8.0 से पहले, रेफरेंस टाइप हमेशा नेबल होते थे और वैल्यू टाइप नहीं होते थे। हालाँकि, किसी [वैल्यू टाइप को नेबल बनाया जा सकता है][nullable-value-types], बस उसके आगे प्रश्नचिह्न (`?`) लगाकर।

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

जिस वेरिएबल की वैल्यू `null` है, उसके किसी मेंबर को एक्सेस करने पर कंपाइल तो ठीक हो जाएगा, लेकिन रनटाइम पर `NullReferenceException` फेंका जाएगा:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

इस तरह की आम गलती से बचने के लिए C# 8 में [एक फीचर चुनने][nullable-csharp-8] की सुविधा दी गई है, जो [रेफरेंस टाइप को डिफ़ॉल्ट रूप से नॉन-नेबल बना देती है][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

नेबल वैल्यू के साथ [सुरक्षित तरीके से काम करने][nullable-types-tutorial] के लिए, उन वैल्यू पर काम करने से पहले जाँच लेना चाहिए कि वे `null` हैं या नहीं:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

जब वैल्यू `null` हो, तब [`??` ऑपरेटर][null-coalescing-operator] डिफ़ॉल्ट वैल्यू लौटाने देता है:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

[`?.` ऑपरेटर][null-conditional-operator] किसी संभवतः `null` वैल्यू पर सुरक्षित तरीके से मेंबर कॉल करने देता है:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

अगर कंपाइलर को लगता है कि कोई वैल्यू `null` हो सकती है, लेकिन आपको पक्का है कि वह नहीं होगी, तो चेतावनी दबाने के लिए [`!.` ऑपरेटर][null-forgiving-operator] इस्तेमाल किया जा सकता है। हालाँकि, इस ऑपरेटर का इस्तेमाल सिर्फ अंतिम उपाय के तौर पर ही कीजिए।

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```

अगर आप नेबल रेफरेंस के साथ काम करने के बारे में और जानना चाहते हैं, तो [यह ट्यूटोरियल देखिए][nullable-reference-types-tutorial]।
