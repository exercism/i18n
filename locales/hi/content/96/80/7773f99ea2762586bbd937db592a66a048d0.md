# परिचय

## स्थिरांक और फंक्शन

Haskell प्रोग्राम परिभाषाओं और एक्सप्रेशन से बने होते हैं।

एक स्थिरांक वैल्यू `name = expression` से परिभाषित की जाती है।

```haskell
five = 5

six = 3 + 3
```

फंक्शन `name parameters... = expression` से परिभाषित किए जाते हैं। इनमें पैरामीटर को सिर्फ स्पेस से अलग किया जाता है।

```haskell
add number1 number2 = number1 + number2
```

किसी फंक्शन को कॉल करना भी एक एक्सप्रेशन होता है। इसमें उसका नाम लिखा जाता है और फंक्शन के हर पैरामीटर के लिए आर्गुमेंट दिए जाते हैं, जिन्हें स्पेस से अलग किया जाता है। यह ठीक वैसा ही है जैसा फंक्शन परिभाषित करते समय किया जाता है।

```haskell
five = add 2 3
```

गोल ब्रैकेट लगाकर यह तय किया जा सकता है कि किसी एक्सप्रेशन का मूल्यांकन किस क्रम में होगा।

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## इंडेंटेशन / महत्वपूर्ण व्हाइटस्पेस

Haskell कोड की सीमाएँ तय करने के लिए व्हाइटस्पेस और इंडेंटेशन का उपयोग करता है।
***जो कोड किसी एक्सप्रेशन का हिस्सा है, उसे उस एक्सप्रेशन की शुरुआत से ज़्यादा अंदर की ओर इंडेंट किया जाना चाहिए।***

- मॉड्यूल, import और टॉप-लेवल फंक्शन की परिभाषाएँ सबसे बाईं ओर वाले कॉलम से शुरू होनी चाहिए।
- अगर किसी एक्सप्रेशन को कई लाइनों में बाँटा गया है, तो उस एक्सप्रेशन का हिस्सा बने कोड को उस एक्सप्रेशन के नीचे कम से कम एक स्पेस से इंडेंट किया जाना चाहिए।
- एक्सप्रेशन के जो हिस्से एक साथ रखे जाते हैं, उन्हें बराबर संख्या के स्पेस से इंडेंट किया जाना चाहिए।

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## मॉड्यूल

मॉड्यूल फंक्शन एक्सपोर्ट करते हैं।
इसका मतलब है कि आप उन फंक्शन का उपयोग कर सकते हैं जिन्हें मॉड्यूल अपने एक्सपोर्ट स्टेटमेंट में उपलब्ध कराता है।
एक मॉड्यूल ऐसे फंक्शन भी बना सकता है जो सिर्फ अंदरूनी उपयोग के लिए हों।
डिफॉल्ट रूप से, जो फंक्शन साफ़-साफ़ एक्सपोर्ट नहीं किए गए हैं, उनका उपयोग मॉड्यूल के बाहर से नहीं किया जा सकता।

मॉड्यूल की शुरुआत में हम मॉड्यूल का नाम लिखते हैं।
अगर हमारे पास Calculator.hs नाम की फाइल है, तो हमें अपने मॉड्यूल का नाम Calculator रखना चाहिए।
फिर हम बताते हैं कि यह कौन-कौन से फंक्शन एक्सपोर्ट करता है, और उसके बाद हम फंक्शन लिखना शुरू कर सकते हैं।
तो हम इसी से शुरू करेंगे।

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## कमेंट

कमेंट Haskell फाइल के अंदर लिखा वह टेक्स्ट होता है जिसे कोड के रूप में नहीं समझा जाता।
यह मुख्य रूप से आपके और दूसरे प्रोग्रामर के पढ़ने के लिए होता है।
सिंगल लाइन कमेंट के लिए एक आसान सिंटैक्स है, जो दो डैश पर आधारित है।
मल्टीलाइन कमेंट खोलने और बंद करने वाले डेलिमिटर `{-` और `-}` की जोड़ी से भी लिखे जा सकते हैं।

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
