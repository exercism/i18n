# परिचय

`Result` टाइप Elm भाषा में एरर की जानकारी देने का समाधान है, और यह एरर से उबरने में भी मदद करता है। यह कुछ-कुछ `Maybe` टाइप जैसा होता है, लेकिन जो फंक्शन फेल हो सकते हैं वे `Maybe` तो लौटा सकते हैं, मगर `Maybe` यह नहीं बताता कि फेल क्यों हुआ। `Result` में इस बात की जानकारी भी शामिल होती है कि कोई चीज़ क्यों फेल हुई।

`Result` टाइप को इस तरह परिभाषित किया गया है:

```elm
type Result error value
  = Ok value
  | Err error
```

Elm की शब्दावली में इसे "कस्टम टाइप" की परिभाषा कहते हैं।
`OK value` और `Error error` में `error` और `value` एक टाइप वेरिएबल दर्शाते हैं, यानी ये कोई भी टाइप हो सकते हैं, जैसे `Int`, `Bool` या `String`।
इसी तरह, `Result String Int` एक ऐसी वैल्यू है जिसमें `Int` होने की अपेक्षा होती है, और अगर कोई एरर हो तो वह `String` के रूप में दिखाई जाएगी।
इसके लिए बहुत सारे काम के हेल्पर फंक्शन वाला एक [Result मॉड्यूल](https://package.elm-lang.org/packages/elm/core/latest/Result) भी है।
