# परिचय

जब आप ऐसे डेटा का मॉडल बनाते हैं जो केवल कुछ तय स्थितियों में ही रह सकता है, जैसे सप्ताह के दिन, कम्पास की दिशाएँ, या कंट्रोलर के बटन, तो `Int` या `String` जैसे बुनियादी टाइप में बड़ी कमियाँ होती हैं।
पूर्णांकों या स्ट्रिंग के साथ, आपके कोड को हर बार गलत वैल्यू की जाँच करनी पड़ती है (जैसे `999` जैसा स्टेटस कोड, या `"leftt"` जैसी लिखने की गलती), और पढ़ने वाले इंसान आसानी से नहीं समझ पाते कि इन संख्याओं का मतलब क्या है।

Swift इस समस्या को [_एन्यूमरेशन_][enumerations] (जिन्हें अक्सर छोटा करके *एनम* कहा जाता है) से हल करता है।
एक एनम जुड़ी हुई और नाम वाली वैल्यूओं के समूह के लिए एक साझा टाइप बनाता है। चूँकि कंपाइलर को पहले से ही सभी संभावित केस पता होते हैं, यह कंपाइल के समय आपके कोड की सटीकता और पूर्णता की जाँच कर सकता है।
एनम में मेथड, इनिशियलाइज़र और कंप्यूटेड प्रॉपर्टी भी हो सकते हैं।

## एनम बनाना

किसी एनम को बनाने के लिए `enum` कीवर्ड लिखिए और उसके बाद टाइप का नाम दीजिए, और उसके केस घुंघराले ब्रैकेट के अंदर लिखिए।
Swift की परंपरा के अनुसार टाइप के नाम में `UpperCamelCase` इस्तेमाल होता है, और हर केस में `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

आप एक ही लाइन में कई केस भी बना सकते हैं, जिन्हें कॉमा से अलग किया जाता है:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

किसी एनम केस को दर्शाने के लिए एनम टाइप का नाम, एक डॉट (`.`), और केस का नाम लिखिए। जब टाइप पता हो या कंपाइलर उसका अनुमान लगा सके, तो आप टाइप का नाम छोड़ सकते हैं और छोटा डॉट सिंटैक्स इस्तेमाल कर सकते हैं:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## एनम और `switch` स्टेटमेंट

एनम [`switch` स्टेटमेंट][enums-and-switches] के साथ बड़ी आसानी से काम करते हैं।
चूँकि Swift में `switch` को सभी केस कवर करने ही पड़ते हैं, कंपाइलर यह सुनिश्चित करता है कि आप हर संभव केस संभालें:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

अगर आप `default` क्लॉज़ दिए बिना कोई केस छोड़ दें, तो कंपाइलर एरर बताता है:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

सभी केस अलग-अलग लिखना अक्सर `default` इस्तेमाल करने से बेहतर होता है। इस तरह, अगर आप आगे कोई नया केस जोड़ें, तो कंपाइलर तुरंत आपको चेतावनी देगा कि आप उस एनम को संभालने वाले हर `switch` स्टेटमेंट को अपडेट करें।

## मेथड और इनिशियलाइज़र

एनम में क्लास और स्ट्रक्ट की तरह मेथड और अपने इनिशियलाइज़र बनाए जा सकते हैं। एनम के किसी मेथड के अंदर `self` मौजूदा केस की वैल्यू को दर्शाता है:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## रॉ वैल्यू

एनम के केस पहले से डिफ़ॉल्ट वैल्यूओं के साथ भरे जा सकते हैं, जिन्हें [_रॉ वैल्यू_][raw-values] कहते हैं।
एक एनम की सभी रॉ वैल्यू एक ही टाइप की होनी चाहिए (जैसे `Int`, `String`, या `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

आप `init(rawValue:)` की मदद से किसी रॉ वैल्यू से एनम को इनिशियलाइज़ कर सकते हैं। चूँकि कोई अमान्य रॉ वैल्यू दी जा सकती है, यह इनिशियलाइज़र एक ऑप्शनल लौटाता है:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift `String` और `Int` एनम के लिए रॉ वैल्यू अपने आप असाइन कर सकता है:

- `String` एनम में हर केस की रॉ वैल्यू डिफ़ॉल्ट रूप से उसी केस का नाम होती है।
- `Int` एनम में रॉ वैल्यू `0` से शुरू होती हैं और हर बार 1 बढ़ती जाती हैं, जब तक कुछ और तय न किया जाए।

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## असोसिएटेड वैल्यू

एनम के केस हर केस के साथ अलग-अलग टाइप की अपनी वैल्यू भी संग्रहीत कर सकते हैं, जिन्हें [_असोसिएटेड वैल्यू_][associated-values] कहते हैं:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

एक एनम या तो रॉ वैल्यू इस्तेमाल कर सकता है या असोसिएटेड वैल्यू, दोनों नहीं।

## रिकर्सिव एन्यूमरेशन

एक [रिकर्सिव एन्यूमरेशन][recursive-enumerations] ऐसा एनम होता है जिसके एक या अधिक केसों में उसी एनम की एक और इंस्टेंस असोसिएटेड वैल्यू के रूप में होती है।
रिकर्सन चालू करने के लिए उस केस (या पूरे एनम) पर `indirect` कीवर्ड लगाइए:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
