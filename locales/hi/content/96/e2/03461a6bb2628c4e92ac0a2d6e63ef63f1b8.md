# निर्देशों का परिशिष्ट

## Stream एबिलिटी के बारे में

`Stream` Unison की एक एबिलिटी है जिसका उपयोग वैल्यू निकालने के लिए किया जाता है।

आप `Stream` एबिलिटी का उपयोग तब कर सकते हैं जब आपके पास ऐसा फंक्शन हो जो कॉल किए जाने के दौरान अतिरिक्त प्रभाव के रूप में वैल्यू पैदा करता हो। उदाहरण के लिए, यह फंक्शन ऐरे की अंतिम वैल्यू लौटाता है, लेकिन जैसे-जैसे हर एलिमेंट देखा जाता है, एक रनिंग टोटल भी निकालता है:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

एबिलिटी हैंडलर की मदद से हम Stream को List में बदलकर उस फंक्शन की रिटर्न वैल्यू के साथ पा सकते हैं जो उस Stream को बनाता है:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
