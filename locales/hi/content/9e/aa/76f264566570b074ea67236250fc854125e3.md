# मदद

अगर आपको कोई दिक्कत आ रही है, तो मदद के लिए आप इन संसाधनों में से किसी एक का उपयोग कर सकते हैं:

- [ClojureScript API](http://cljs.github.io/api/) आधिकारिक API डॉक।
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet), एक आधिकारिक चीट-शीट।
- [/r/clojurescript](https://www.reddit.com/r/clojurescript) C# का सबरेडिट है।
- [StackOverflow](http://stackoverflow.com/questions/tagged/clojurescript) पर आप अपनी समस्या खोज सकते हैं और देख सकते हैं कि उसका जवाब पहले ही दिया जा चुका है या नहीं। आप वहाँ सवाल पूछ भी सकते हैं और जवाब भी दे सकते हैं।
