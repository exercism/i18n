# निर्देश

Jen एक बड़ी फैक्ट्री के छँटाई कक्ष में काम करती है।
छँटाई कक्ष को अंदर आने वाली हर चीज़ को एक लेबल लगाकर वर्गीकृत करके निपटाना होता है।
Jen उन चीज़ों की ज़िम्मेदार है जिन्हें पहले से संख्याओं के रूप में वर्गीकृत किया गया था, और उसे छँटाई में मदद के लिए एक प्रोग्राम चाहिए।

ज़्यादातर प्रिमिटिव वैल्यू के लिए सीधे लेबल होने चाहिए।
संख्याओं के लिए, वह चाहती है कि स्ट्रिंग `"This is the number 2.0"` कहे (अगर संख्या 2 थी)।
Jen पूर्णांकों और दशमलव संख्याओं के लिए भी वही आउटपुट चाहती है।

कुछ `Box` इंटरफ़ेस हैं जिनके अंदर का कंटेंट निकालने के लिए उन्हें खोलना पड़ता है।
`NumberBox` के लिए, वह चाहती है कि स्ट्रिंग `"This is a box containing the number 3.0"` कहे (अगर `Number()` मेथड 3 लौटाता है)।
`FancyNumberBox` के लिए, वह चाहती है कि स्ट्रिंग `"This is a fancy box containing the number 4.0"` कहे, लेकिन केवल तब जब टाइप `FancyNumber` हो।

कोई भी अनपेक्षित चीज़ `"Return to sender"` कहे ताकि Jen उन्हें वापस वहीं भेज सके जहाँ से वे आई थीं।

## 1. साधारण संख्याओं का वर्णन कीजिए

Jen चाहती है कि संख्याएँ `"This is the number 2.0"` जैसी स्ट्रिंग लौटाएँ (दशमलव के बाद एक अंक सहित):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. एक संख्या बॉक्स का वर्णन कीजिए

Jen चाहती है कि संख्या बॉक्स `"This is a box containing the number 2.0"` जैसी स्ट्रिंग लौटाएँ (फिर से, दशमलव के बाद एक अंक सहित):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. एक मेथड बनाइए जो फैंसी संख्या बॉक्स से संख्या निकाले

Jen को `FancyNumberBox` से संख्या निकालने के लिए एक हेल्पर फंक्शन चाहिए।
अगर `FancyNumberBox` एक `FancyNumber` है, तो उसकी वैल्यू निकालिए और उसे `string` से `int` में बदलिए।
किसी भी अन्य टाइप के `FancyNumberBox` को 0 लौटाना चाहिए।

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. एक फैंसी संख्या बॉक्स का वर्णन कीजिए

अगर `FancyNumberBox` एक `FancyNumber` है, तो Jen चाहती है कि स्ट्रिंग `"This is a fancy box containing the number 4.0"` कहे।
किसी भी अन्य टाइप के `FancyNumberBox` को `"This is a fancy box containing the number 0.0"` कहना चाहिए।

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

ध्यान दें: हमें `ExtractFancyNumber` फंक्शन का उपयोग करना चाहिए!

## 5. `DescribeAnything` बनाइए जो इन सबका उपयोग करता है

यह मुख्य फंक्शन है जिसकी Jen को ज़रूरत है और जो कोई भी इनपुट लेता है।
`DescribeAnything` को पास की गई वैल्यू के टाइप के आधार पर अन्य फंक्शनों को सौंपना चाहिए।
और खास तौर पर:

- `int` और `float64` दोनों को `DescribeNumber` को सौंपना चाहिए
- `NumberBox` को `DescribeNumberBox` को सौंपना चाहिए
- `FancyNumberBox` को `DescribeFancyNumberBox` को सौंपना चाहिए
- किसी और चीज़ का परिणाम `"Return to sender"` होना चाहिए

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
