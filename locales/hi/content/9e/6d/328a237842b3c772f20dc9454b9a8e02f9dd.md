# परिचय

जैसा कि [`Nothingness`][concept-nothingness] कॉन्सेप्ट में बताया गया है, R में ऐसे डेटा को दर्शाने के कई तरीके हैं जो अनुपस्थित (`NULL`), अज्ञात (`NA`) या गणितीय रूप से अमान्य (`NaN`, `Inf`) होता है। सामान्य तौर पर, R इनका उपयोग समस्याओं को वहीं इंगित करने के लिए करता है, और बिना कोई एक्सेप्शन उठाए आगे बढ़ता रहता है।

## `stop()`

कुछ समस्याएँ इतनी बुनियादी होती हैं कि प्रोग्राम को आगे बढ़ने नहीं देतीं। ऐसे में, `stop(msg)` का उपयोग करके प्रोग्राम को तुरंत रोक दें, जिससे एक `Error` उत्पन्न होगा, और `msg` प्रिंट होगा।

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

अन्य भाषाओं में `assert` के समान, यह `stop()` के लिए एक सुविधाजनक रैपर है। इसके पैरामीटर कॉमा से अलग किए गए कई बूलियन शर्तें हो सकती हैं, और प्रोग्राम तभी आगे बढ़ेगा जब ये सभी `TRUE` हों।

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `try()`

R में एरर को संभालने के कई तरीके हैं। ये Common Lisp पर आधारित हैं और कई लोकप्रिय भाषाओं से काफी अलग हैं। सबसे आसान तरीका यह है कि संभावित समस्या वाले कोड को `try()` में लपेट दें।

```R
g <- function(val) {
  log10(val)
}

g(3)
#> [1] 0.4771213

g("3")
#> Error in log10(val) : non-numeric argument to mathematical function

# with try() and a default value
h <- function(val) {
  result <- NA
  try(result <- log10(val))
  result
}

h(3) # works as before
#> [1] 0.4771213

h("3") # returns a default value plus the error message
#> Error in log10(val) : non-numeric argument to mathematical function
#> [1] NA
```

## `warning()` और `message()`

ये गैर-घातक शर्तों के प्रति प्रतिक्रियाएँ हैं, उदाहरण के लिए:

- किसी ऐसी समस्या की चेतावनी देने के लिए जिससे प्रोग्राम कम से कम आंशिक रूप से उबर सकता है।
- लंबे समय तक चलने वाले प्रोग्राम में उपयोगकर्ता को प्रगति की जानकारी देने के लिए।

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

`suppressWarnings()` फंक्शन कभी-कभी Exercism में उपयोगी हो सकता है, ताकि अनचाहे आउटपुट से टेस्ट रनर भ्रमित न हो।
