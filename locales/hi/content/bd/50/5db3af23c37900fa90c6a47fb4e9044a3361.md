# निर्देश परिशिष्ट

## अपना खुद का DSL बनाइए

इस अभ्यास में आप पूरी तरह स्वतंत्र हैं: अपने सपनों वाला ग्राफ DSL आप जैसा चाहें बना सकते हैं।

टेस्ट सिर्फ इतना चाहते हैं कि आप कुछ खास ग्राफ बनाइए। उन्हें बनाने का तरीका पूरी तरह आप पर है।

मज़े को दोगुना करना चाहें तो आप एक `to_dot` फंक्शन बनाकर देख सकते हैं, जो आपके ग्राफ को DOT फॉर्मेट में बदल देता है!

## ग्राफ का निरूपण

अपना DSL `Graph.roc` में परिभाषित कीजिए, फिर उसी से स्टब में माँगे गए ग्राफ बनाइए। हर `EdgeId` में दोनों नोड ID वर्णानुक्रम में होने चाहिए।

| परिभाषा | बनाने के लिए ग्राफ |
| --- | --- |
| `empty_graph` | एक खाली ग्राफ |
| `graph_with_one_node` | एक नोड |
| `graph_with_one_node_with_attribute` | एक नोड, जिसमें एक एट्रिब्यूट हो |
| `graph_with_one_edge` | एक एज |
| `graph_with_one_attribute` | एक ग्राफ एट्रिब्यूट |
| `graph_with_nodes_edges_and_attributes` | नोड, एज और एट्रिब्यूट |
| `multiple_edges_on_one_line` | एक ही लाइन पर लिखी कई एज |
| `only_1_edge_between_nodes` | नोड के हर जोड़े के बीच सिर्फ एक एज |
