# निर्देश

इस अभ्यास में आप हाई स्कूल के प्रेमी-प्रेमिकाओं की मदद करेंगे। इसके लिए आप उनके इनिशियलों से एक यूनिकोड हृदय बनाएँगे, जिसे वे सोशल मीडिया पर अपना प्यार जताने के लिए इस्तेमाल कर सकें:

```
❤ J.  +  M. ❤
```

## 1. नाम को साफ कीजिए

`cleanupname` मेथड लागू कीजिए।
यह एक नाम लेता है और उसमें से सारे `-` अक्षर हटाकर उनकी जगह स्पेस डालता है।
यह नाम के शुरू और अंत से सारी खाली जगह भी हटा देता है।

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. नाम का पहला अक्षर निकालिए

`firstletter` मेथड लागू कीजिए।
यह एक नाम लेता है और उसका पहला अक्षर स्ट्रिंग के रूप में लौटाता है।
ध्यान रखिए कि पिछले चरण में बनाए गए `cleanupname` का दोबारा उपयोग कीजिए और उसे दूसरे फंक्शनों के साथ मिलाइए।

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. पहले अक्षर को इनिशियल के रूप में लिखिए

`initial` मेथड लागू कीजिए।
यह एक नाम लेता है और उसका पहला अक्षर बड़े अक्षर में, उसके बाद एक बिंदु लगाकर लौटाता है।
ध्यान रखिए कि पिछले चरण में बनाए गए `firstletter` का दोबारा उपयोग कीजिए।

```julia-repl
initial("Robert")
"R."
```

## 4. इनिशियलों को हृदय के अंदर रखिए

`couple` मेथड लागू कीजिए।
यह दो नाम लेता है और उनके इनिशियलों के आसपास इमोजी हृदय लगाकर लौटाता है।
ध्यान रखिए कि पिछले चरण में बनाए गए `initial` का दोबारा उपयोग कीजिए।

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
