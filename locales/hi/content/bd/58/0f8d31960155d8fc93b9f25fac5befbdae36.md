# परिचय

## शुरुआत

### वेरिएबल

आप एक [वेरिएबल][constants-variables] बनाकर वैल्यू को संग्रहीत कर सकते हैं और उन्हें नाम दे सकते हैं।
एक बार वेरिएबल बना लेने के बाद, आप अपने पूरे कोड में उस वैल्यू को उसके नाम से इस्तेमाल कर सकते हैं।
वेरिएबल _म्यूटेबल_ होते हैं, यानी बनाने के बाद उनकी वैल्यू बदली जा सकती है।

किसी वेरिएबल को `var` कीवर्ड से बनाइए:

```swift
var variableName = 10
```

Swift एक स्टैटिकली टाइप्ड भाषा है, यानी कंपाइल के समय हर वैल्यू का टाइप पहले से ज्ञात होता है।
आप [टाइप एनोटेशन][type annotations] की मदद से टाइप स्पष्ट रूप से घोषित कर सकते हैं, या Swift कंपाइलर को असाइन की गई वैल्यू से [टाइप का अनुमान लगाने][type-inferring] दे सकते हैं:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

आप असाइनमेंट ऑपरेटर (`=`) की मदद से वेरिएबल की वैल्यू बदल सकते हैं:

~~~~exercism/note
घोषित होने के बाद वेरिएबल का टाइप नहीं बदल सकता।

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

आप टाइप बताकर किसी वेरिएबल को बिना शुरुआती वैल्यू के घोषित कर सकते हैं, लेकिन उसका इस्तेमाल करने से पहले उसमें वैल्यू असाइन करनी होगी:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### कॉन्स्टेंट

[कॉन्स्टेंट][constants-variables] भी एक नाम को वैल्यू से जोड़ते हैं, लेकिन असाइन करने के बाद उनकी वैल्यू नहीं बदली जा सकती।
वे _इम्यूटेबल_ होते हैं।
किसी कॉन्स्टेंट को `let` कीवर्ड से बनाइए:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### अंकगणितीय ऑपरेटर

Swift बुनियादी गणित के लिए मानक [अंकगणितीय ऑपरेटर][arithmetical-operators] देता है:

- जोड़: `+`
- घटाव: `-`
- गुणा: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### फंक्शन

Swift में [फंक्शन][functions] कोड के ऐसे स्वतंत्र ब्लॉक होते हैं जो कोई खास काम करते हैं।
फंक्शन इनपुट ले सकते हैं, कोई वैल्यू लौटा सकते हैं, और वैल्यू की तरह दूसरे फंक्शन को दिए जा सकते हैं।
किसी फंक्शन को `func` कीवर्ड से बनाइए। इसके बाद फंक्शन का नाम, ब्रैकेट में पैरामीटर की सूची, और वैकल्पिक रिटर्न टाइप लिखिए:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift फंक्शन [आर्गुमेंट लेबल][argument-labels] इस्तेमाल करते हैं, जिनसे कोड आम वाक्यों की तरह पढ़ा जाता है:

- फंक्शन को कॉल करते समय **आर्गुमेंट लेबल** इस्तेमाल होता है।
- वैल्यू तक पहुँचने के लिए फंक्शन के अंदर **पैरामीटर नाम** इस्तेमाल होता है।

अगर आप सिर्फ एक नाम लिखते हैं, तो Swift उसे आर्गुमेंट लेबल और पैरामीटर नाम दोनों की तरह इस्तेमाल करता है:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

अगर फंक्शन को कॉल करते समय आप आर्गुमेंट लेबल नहीं चाहते, तो पैरामीटर नाम से पहले अंडरस्कोर (`_`) लिखिए:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

फंक्शन के सारे पैरामीटर डिफ़ॉल्ट रूप से कॉन्स्टेंट (`let`) होते हैं, यानी फंक्शन के अंदर उनकी वैल्यू नहीं बदली जा सकती।

किसी फंक्शन से वैल्यू लौटाने के लिए `->` के बाद रिटर्न टाइप लिखिए और `return` कीवर्ड इस्तेमाल कीजिए:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

जब कोई फंक्शन कोई वैल्यू नहीं लौटाता, तो उसका रिटर्न टाइप `Void` होता है (खाली टपल `()` के बराबर)।
ऐसे फंक्शन में आप `-> Void` रिटर्न टाइप और `return` स्टेटमेंट दोनों छोड़ सकते हैं।

### कमेंट

Swift [कमेंट][comments] के दो रूपों का समर्थन करता है:

- **सिंगल-लाइन कमेंट** `//` से शुरू होते हैं और लाइन के अंत तक चलते हैं।
- **मल्टीलाइन कमेंट** `/*` और `*/` के बीच बंद रहते हैं।

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
