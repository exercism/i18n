# परिचय

_स्ट्रिंग_ JavaScript का वह डेटा टाइप है जिसमें टेक्स्ट डेटा संग्रहीत किया जाता है।

## स्ट्रिंग बनाना

आप टेक्स्ट को सिंगल कोट या डबल कोट में लपेटकर एक स्ट्रिंग बनाते हैं।
Exercism पर सिंगल कोट इस्तेमाल किए जाते हैं।

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## अक्षरों की सूची के रूप में स्ट्रिंग

स्ट्रिंग को अक्षरों की एक सूची की तरह देखा जा सकता है, जिसमें पहले अक्षर का इंडेक्स `0` होता है।
आप चौकोर ब्रैकेट और जिस अक्षर को निकालना चाहते हैं उसके इंडेक्स की मदद से स्ट्रिंग के किसी एक अक्षर तक पहुँच सकते हैं।

```javascript
'cat'[1];
// => 'a'
```

आप `length` प्रॉपर्टी की मदद से पता कर सकते हैं कि एक स्ट्रिंग में कितने अक्षर हैं।

```javascript
'cat'.length;
// => 3
```

## जोड़ना और मेथड

स्ट्रिंग जोड़ने का सबसे आसान तरीका है जोड़ के ऑपरेटर `+` का इस्तेमाल करना।

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

स्ट्रिंग में कई सारे हेल्पर मेथड होते हैं। पूरी सूची के लिए [स्ट्रिंग मेथड पर MDN डॉक्स][mdn-string-methods] देखिए।
नीचे दी गई सूची में कुछ आम तौर पर इस्तेमाल होने वाले हेल्पर दिए गए हैं।

- [`toUpperCase`][mdn-to-upper-case] और [`toLowerCase`][mdn-to-lower-case] - सभी अक्षरों का केस बदलते हैं
- [`trim`][mdn-trim] - शुरू और अंत की खाली जगह हटाते हैं
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] और [`endsWith`][mdn-ends-with] - बताते हैं कि कोई दूसरी स्ट्रिंग दी गई स्ट्रिंग का हिस्सा है या नहीं
- [`slice`][mdn-slice] - स्ट्रिंग का एक हिस्सा निकालते हैं

JavaScript में स्ट्रिंग बदली नहीं जा सकती। इसलिए ऊपर दिए गए कुछ मेथड के ज़रिए कोई "बदलाव" करने पर हमेशा एक नई स्ट्रिंग बनती है।
