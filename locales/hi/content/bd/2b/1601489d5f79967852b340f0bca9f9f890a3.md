# परिचय

`Result` डेटा टाइप की मदद से एक फंक्शन एक ही वैल्यू लौटाकर ये सारी बातें बता सकता है:

- ऑपरेशन सफल हुआ या असफल
- सफल होने पर, ऑपरेशन की मिलने वाली वैल्यू
- असफल होने पर, असफलता का कारण

## उपयोग

`Result` एक जेनेरिक डेटा टाइप है जिसके अंदर दो डेटा टाइप होते हैं:

- सफल ऑपरेशन पर बनने वाली वैल्यू का डेटा टाइप
- असफल होने पर असफलता के कारण को बताने वाला डेटा टाइप

`Result` डेटा टाइप एक [डिस्क्रिमिनेटेड यूनियन][discriminated-union] भी है, जिसकी नीचे दी गई स्थितियाँ हो सकती हैं:

- `Ok <value>`, जो सफल परिणाम को दर्शाता है
- `Error <reason>`, जो असफलता को दर्शाता है

नीचे दिया गया फंक्शन दिखाता है कि `Result` वैल्यू कैसे बनाई जाती है:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

इस उदाहरण में `Ok` वैल्यू एक स्ट्रिंग है (दिया गया नाम), और `Error` वैल्यू भी एक स्ट्रिंग है (एरर का कारण, इंसान के पढ़ने लायक रूप में)।

## `Result` वैल्यू के अंदर की जानकारी पढ़ना

नीचे दी गई डेटा टाइप की परिभाषा और फंक्शन सिग्नेचर को ध्यान से देखिए:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

जो कोड `openFile` फंक्शन को कॉल करता है, वह पैटर्न मैचिंग की मदद से सफलता और असफलता, दोनों स्थितियों को संभाल सकता है। इसका उदाहरण नीचे दिया गया है:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```

[discriminated-union]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/discriminated-unions
