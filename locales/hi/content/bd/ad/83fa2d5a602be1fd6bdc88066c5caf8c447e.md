# परिचय

## संसाधन का जीवनकाल

[concept:csharp/resource-cleanup]() `IDispose` इंटरफेस का उपयोग यह बताने के लिए करता है कि जब किसी ऑब्जेक्ट की ज़रूरत नहीं रहती, तब उस ऑब्जेक्ट के संसाधन या प्रोग्राम की दूसरी स्थिति को छोड़ना या रीसेट करना ज़रूरी हो जाता है (और सिर्फ गार्बेज कलेक्टर पर भरोसा करने से यह काम नहीं होगा, और न ही ज़रूरी स्तर का नियंत्रण मिलेगा), और ऐसे सफाई के कामों की स्वाभाविक जगह `IDisposable.Dispose()` मेथड ही है।

एक और तरीका भी है, `using` ब्लॉक, जिसकी मदद से कॉल करने वाले की नज़र में संसाधन के जीवनकाल का पूरा प्रबंधन एक ही स्टेटमेंट में समेटा जा सकता है।

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

ऊपर के उदाहरण में `file` से जुड़े फाइल सिस्टम के संसाधन `using` ब्लॉक से बाहर निकलते ही ऑपरेटिंग सिस्टम को वापस लौटा दिए जाते हैं।

यह पैटर्न काम करे, इसके लिए using स्टेटमेंट वाला वेरिएबल ऐसा रेफरेंस टाइप होना चाहिए जो `IDisposable` इंटरफेस को लागू करता हो, और अपने `Dispose()` मेथड में संसाधन छोड़ता हो या प्रोग्राम की स्थिति रीसेट करता हो।

C# 8 इस पैटर्न में एक सुधार लेकर आया है। using स्टेटमेंट को किसी ब्लॉक के शुरू में भी लिखा जा सकता है।

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java के डेवलपर इसे Java 7 में पेश किए गए _स्वचालित संसाधन प्रबंधन_ तंत्र जैसा ही मान सकते हैं।
