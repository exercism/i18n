# Debug

जब कोई टेस्ट फेल होता है, तो एक संदेश दिखता है जो बताता है कि क्या गलत हुआ और किस इनपुट के लिए।
अपने प्रोग्राम में किसी भी वैल्यू की जाँच करने के लिए उसे `debug` मेथड को दीजिए (यह `exercism/test_runner` में उपलब्ध है)।
यह उन वैल्यू को अपने पास रख लेता है और आपको आउटपुट दिखा देता है।


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
