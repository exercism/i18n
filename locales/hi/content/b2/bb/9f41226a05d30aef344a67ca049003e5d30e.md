# मदद

अगर आपको कोई परेशानी आ रही है, तो मदद के लिए आप नीचे दिए गए संसाधनों में से किसी एक का उपयोग कर सकते हैं:

- [/r/javascript](https://www.reddit.com/r/javascript) JavaScript का सबरेडिट है।
- [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) की मदद से आप अपनी समस्या खोज सकते हैं और देख सकते हैं कि उसका जवाब पहले ही मिल चुका है या नहीं। आप वहाँ सवाल भी पूछ सकते हैं और जवाब भी दे सकते हैं।
- [Github इश्यू ट्रैकर](https://github.com/exercism/javascript/issues) वह जगह है जहाँ हम Exercism में JavaScript अभ्यासों के विकास और रखरखाव पर नज़र रखते हैं। लेकिन अगर ऊपर दिए गए किसी भी लिंक से आपकी मदद नहीं हो पाई, तो बेझिझक यहाँ एक इश्यू पोस्ट कीजिए।
