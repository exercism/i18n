# परिचय

Java में [`null` लिटरल][null-keyword] का उपयोग यह बताने के लिए किया जाता है कि किसी वैल्यू का अभाव है।

Java में हर [प्रिमिटिव डेटा टाइप][primitive-data-types] में एक डिफ़ॉल्ट वैल्यू होती है, इसलिए वे कभी `null` नहीं हो सकते। परंपरा के अनुसार इनके नाम छोटे अक्षर से शुरू होते हैं, जैसे `int`।

[रेफरेंस टाइप][reference-data-types] में किसी ऑब्जेक्ट का मेमोरी एड्रेस होता है और इनकी वैल्यू `null` भी हो सकती है। आमतौर पर इनके नाम बड़े अक्षर से शुरू होते हैं, जैसे `String`।

किसी प्रिमिटिव वेरिएबल को `null` असाइन करने की कोशिश करने पर कंपाइल टाइम एरर मिलती है, क्योंकि वह वेरिएबल हमेशा अपने टाइप की डिफ़ॉल्ट वैल्यू ही रखता है।

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

किसी रेफरेंस वेरिएबल को `null` वैल्यू असाइन करने पर कंपाइल टाइम एरर नहीं मिलती, क्योंकि रेफरेंस वेरिएबल `null` वैल्यू रख सकते हैं।

```java
//No error will occur as the String variable str is nullable
String str = null;
```

जिस रेफरेंस वेरिएबल की वैल्यू `null` हो, उसे एक्सेस करना कंपाइल तो ठीक से हो जाता है, लेकिन रनटाइम पर `NullPointerException` आ जाता है।

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

जब किसी रेफरेंस वेरिएबल में `null` हो, पर उससे ऑब्जेक्ट चाहिए, तो उसे एक्सेस करने की कोशिश करने पर [`NullPointerException` मिलता है][null-pointer-exception]।

जिन वैल्यू में `null` हो सकता है, उनके साथ सुरक्षित तरीके से काम करने के लिए उन्हें इस्तेमाल करने से पहले जाँच लेना चाहिए कि वे `null` तो नहीं हैं। यह जाँच [इक्वलिटी ऑपरेटरों][equality-operators] जैसे `==` या `!=` से की जा सकती है:

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
