# अतिरिक्त निर्देश

ग्रिड की हर पंक्ति एक वर्ड के रूप में दर्शाई जाती है।

उदाहरण के लिए,

```
    0 1 0
    1 0 0
    1 1 0
```

इसे इस तरह दर्शाया जाता है:

```
0x2
0x4
0x6
```

ग्रिड में अधिकतम 32 स्तंभ होते हैं।

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप    | विवरण                       |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | पंक्तियों की संख्या          |
| `$a1`    | इनपुट        | पूर्णांक | स्तंभों की संख्या            |
| `$a2`    | इनपुट        | एड्रेस  | वर्तमान पीढ़ी के लिए ग्रिड    |
| `$a3`    | इनपुट/आउटपुट | एड्रेस  | अगली पीढ़ी के लिए ग्रिड       |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए इस्तेमाल होता है |
