# निर्देश परिशिष्ट

## इस ट्रैक के खास निर्देश

इस अभ्यास में मुख्य रूप से Swift के `Array` स्ट्रक्चर में मेथड जोड़ने पर ध्यान दिया गया है। ऐसा करने का सबसे आसान तरीका है [एक्सटेंशन][extensions] का इस्तेमाल करना।

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

`Array` का डॉक्युमेंटेशन [यहाँ][array] मिल सकता है।

[array]: https://developer.apple.com/documentation/swift/array
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
