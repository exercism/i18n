# परिचय

_टर्नरी ऑपरेटर_ सरल _if/else_ स्टेटमेंट के लिए एक हल्का, संक्षिप्त विकल्प है।
इसका उपयोग आमतौर पर रिटर्न स्टेटमेंट में होता है (लेकिन यह सिर्फ इन्हीं तक सीमित नहीं है)। निर्णय लेने के लिए इसमें बस एक ही लाइन चाहिए। अगर एक्सप्रेशन `true` है तो यह बाईं ओर की वैल्यू लौटाता है, और अगर `false` है तो दाईं ओर की वैल्यू, जैसा कि नीचे दिखाया गया है:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

बहुत से सरल _if/else_ एक्सप्रेशन को _टर्नरी ऑपरेटर_ की मदद से सरल बनाया जा सकता है।
