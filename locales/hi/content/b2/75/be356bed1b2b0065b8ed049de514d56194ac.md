# निर्देश परिशिष्ट

## आउटपुट का प्रारूप

छात्र के पौधों को null पर समाप्त होने वाली स्ट्रिंग के रूप में दीजिए और विभाजक के तौर पर कॉमा तथा एक स्पेस का इस्तेमाल कीजिए।

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप    | विवरण                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | एड्रेस | बगीचे का आरेख                |
| `$a1`    | इनपुट        | एड्रेस | छात्र का नाम                |
| `$a2`    | इनपुट/आउटपुट | एड्रेस | null पर समाप्त होने वाली आउटपुट स्ट्रिंग |
| `$t0-9`  | अस्थायी    | कोई भी     | अस्थायी भंडारण के लिए इस्तेमाल होता है    |
