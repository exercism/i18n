# परिचय

Pairs and Dicts कॉन्सेप्ट में Julia के डिक्शनरी टाइप की बुनियादी बातें बताई गई थीं।

`Dict` एक महत्वपूर्ण और बहुत इस्तेमाल होने वाला कलेक्शन टाइप है, इसलिए इन्हें संभालने के लिए कई फंक्शन भी हैं।

## एंट्री पाना

किसी एंट्री को पाने का सबसे आसान तरीका की से है, जैसा कि कई भाषाओं में होता है।
लेकिन अगर आप ऐसी की माँगें जो मौजूद ही नहीं है, तो `KeyError` मिलती है।

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

एंट्री निकालने से पहले हम यह जाँच सकते हैं कि की मौजूद है या नहीं (जैसे `haskey(d, 4)` से), लेकिन जो की मौजूद नहीं हैं, उनके लिए सीधे एक डिफॉल्ट वैल्यू ले लेना भी काम का होता है।

इसके लिए हमारे पास `get()` फंक्शन है, और उसका `Dict` को बदल देने वाला रूप `get!()` भी।
दोनों में यह अंतर है कि जो की मौजूद नहीं है, वह `Dict` में जोड़ी जाती है या नहीं।

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

पिछले कॉन्सेप्ट में हमने देखा था कि `delete!()` किसी एंट्री को उसकी की के आधार पर हटा देता है।
वैल्यू निकालने के साथ इसे जोड़ा जा सकता है, और इसके लिए `pop!()` फंक्शन है।

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## इटरेशन

किसी `Dict` पर इटरेशन करने पर डिफॉल्ट रूप से `key => value` जोड़े मिलते हैं।
इनके हिस्सों तक पहुँचने के लिए आमतौर पर `.first` और `.second` नाम इस्तेमाल होते हैं।

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

अकसर हमें सिर्फ की चाहिए होती हैं या सिर्फ वैल्यू, और यह आसान है।

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## मर्ज करना

दो `Dict` को मिलाना काम का हो सकता है, लेकिन हमें साफ तौर पर तय करना होता है कि जो की एक से अधिक इनपुट में मौजूद हैं, उनका हम क्या करना चाहते हैं।

`merge()` और `merge!()` फंक्शन दिए गए कितने भी `Dict` को बाएँ से दाएँ क्रम में मिला देते हैं।

जो की पहले से मौजूद हैं, उनकी वैल्यू पर बस नई वैल्यू लिख दी जाती है, यानी सबसे दाईं ओर वाला `Dict` जीत जाता है।

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()` और `mergewith!()` फंक्शन में हम पहला आर्गुमेंट एक फंक्शन दे सकते हैं, जो तय करता है कि दोहराई गई की को कैसे मिलाया जाए।
जोड़ इसका एक आसान उदाहरण है।

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

ध्यान रखिए कि `mergewith` फंक्शन हायर ऑर्डर फंक्शन के अच्छे उदाहरण हैं।
