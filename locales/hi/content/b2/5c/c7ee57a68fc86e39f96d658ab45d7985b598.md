# टेस्ट

सभी अभ्यास मॉकिंग और टेस्टिंग के लिए [Pester][pester] फ्रेमवर्क का इस्तेमाल करते हैं।
सभी टेस्ट `[Exercise].tests.ps1` नाम की फाइल में होंगे, जैसा Pester फ्रेमवर्क का मानक है।
आपको सही डायरेक्टरी में होना चाहिए (यानी उस डायरेक्टरी में, जिसमें `[Exercise].ps1` और `[Exercise].tests.ps1` मौजूद हैं)।
PowerShell से टेस्ट चलाने के लिए यह लिखिए:

``` PowerShell
Invoke-Pester
```

यह डायरेक्टरी में मिलने वाली सभी `.tests.ps1` फाइलें चला देगा।

अगर आप PowerShell के अलावा कोई और शेल इस्तेमाल कर रहे हैं, तो टेस्ट चलाने के लिए यह लिखिए:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Visual Studio Code में टेस्ट चलाना

आपको यह पक्का करना है कि Visual Studio Code में [PowerShell एक्सटेंशन][extension] इंस्टॉल है।

Visual Studio Code में आप कुछ तरीकों से टेस्ट चला सकते हैं:

- Debug मेन्यू से `.Tests.ps1` स्क्रिप्ट चलाकर। कीबोर्ड शॉर्टकट हैं: `F5` या `Shift + F5`
- एडिटर के अंदर ही टेस्ट कोड में `Describe` कीवर्ड के ऊपर दिए "Run Tests" लिंक पर क्लिक करके
- Pester फ्रेमवर्क चलाने के लिए एक Task कॉन्फ़िगर करके

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
