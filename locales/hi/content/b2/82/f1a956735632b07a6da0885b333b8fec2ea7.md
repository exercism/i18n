# परिचय

Swift में, आप किसी पूर्णांक (जैसे `string[3]`) का उपयोग करके स्ट्रिंग में इंडेक्स नहीं कर सकते।
चूँकि Swift की स्ट्रिंग्स अलग-अलग लंबाई वाले यूनिकोड अक्षरों से बनी होती हैं, किसी अक्षर को ढूँढ़ने के लिए उससे पहले के अक्षरों से होकर गुज़रना पड़ता है।

किसी विशेष स्थान पर मौजूद अक्षर तक पहुँचने के लिए आपको `String.Index` टाइप का एक इंडेक्स निकालना होगा।
इन इंडेक्सों को *अपारदर्शी इंडेक्स* कहा जाता है, क्योंकि इनकी आंतरिक संरचना Swift द्वारा प्रबंधित की जाती है, न कि इन्हें सीधे कच्चे पूर्णांकों के रूप में संचालित किया जाता है:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
