# निर्देश

इस अभ्यास में आपको फोन नंबरों का विश्लेषण करना है।

आपको 2 फीचर बनाने हैं।

इन फंक्शनों को दिए जाने वाले फोन नंबर हमेशा NNN-NNN-NNNN के रूप में होते हैं, जैसे 212-515-9876, और ये कभी null नहीं होते।

## 1. फोन नंबर का विश्लेषण कीजिए

आपके विश्लेषण से 3 चीज़ें मिलनी चाहिए

1. इसका संकेत कि नंबर में न्यूयॉर्क का डायलिंग कोड है या नहीं, यानी पहले 3 अंक 212 हैं या नहीं
2. इसका संकेत कि नंबर नकली है या नहीं, यानी उसके 5 से 7 स्थानों पर (गिनती 1 से शुरू करके) प्रीफिक्स कोड 555 है
3. नंबर के अंतिम 4 अंक।

फोन नंबर की जानकारी देने के लिए (स्टैटिक) मेथड `PhoneNumber.Analyze()` बनाइए।

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. पता लगाइए कि फोन नंबर का प्रीफिक्स कोड (555) नकली है या नहीं

फोन नंबर नकली है या नहीं, यह पता लगाने के लिए कार्य 1 में मिली जानकारी का उपयोग करके (स्टैटिक) मेथड `PhoneNumber.IsFake()` बनाइए।

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
