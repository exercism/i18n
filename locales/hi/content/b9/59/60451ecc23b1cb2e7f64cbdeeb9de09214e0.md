# परिचय

## ड्यूरेशन और पीरियड

`LocalDate` और `LocalDateTime` जैसी क्लासें समय के किसी एक _बिंदु_ को बताती हैं। `java.time` पैकेज में ऐसी दो क्लासें भी हैं जो समय की _मात्रा_ बताती हैं:

- `java.time.Period` साल, महीनों और दिनों में नापी गई समय की मात्रा है, जैसे "2 महीने और 5 दिन"।
- `java.time.Duration` घंटों, मिनटों, सेकंडों, मिलीसेकंडों और नैनोसेकंडों में नापी गई समय की मात्रा है, जैसे "1 घंटा और 30 मिनट"।

`Period` कैलेंडर के हिसाब से चलता है, इसलिए इसका उपयोग तारीखों और तारीख-समय के साथ होता है। `Duration` सटीक समय नापता है, इसलिए इसका उपयोग समय और तारीख-समय के साथ होता है, तारीखों के साथ नहीं।

```exercism/note
`java.time` की बाकी क्लासों की तरह `Period` और `Duration` भी इम्यूटेबल हैं। जो मेथड उन्हें बदलते दिखते हैं, वे असल में एक _नया_ इंस्टेंस लौटाते हैं।
```

### `Period`

किसी `Period` को उसके स्टैटिक फैक्ट्री मेथड में से किसी एक से बनाया जाता है:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()` का परिणाम [ISO-8601][iso-8601-durations] संकेतन में होता है: `P` (यानी "period"), और उसके बाद सालों (`Y`), महीनों (`M`) और दिनों (`D`) की संख्या।

किसी पीरियड को तारीख में जोड़ा या उससे घटाया जा सकता है:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

महीनों की लंबाई अलग-अलग होती है, इसलिए महीने जोड़ने पर कभी-कभी ऐसा दिन आ जाता है जो होता ही नहीं। ऐसी स्थिति में परिणाम को उस महीने के अंतिम वैध दिन पर ले जाया जाता है:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` एक तारीख (उसे भी शामिल करके) से दूसरी तारीख (उसे शामिल न करके) तक का पीरियड लौटाता है:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### `ChronoUnit` से यूनिट गिनना

`Period` अपने सालों, महीनों और दिनों को अलग-अलग रखता है। इसलिए `getDays()` पीरियड के सिर्फ दिन वाले _हिस्से_ को लौटाता है, कुल दिनों की संख्या नहीं। दो तारीखों के बीच किसी एक यूनिट की कुल संख्या गिनने के लिए [`java.time.temporal.ChronoUnit`][chronounit-docs] का `between()` मेथड इस्तेमाल कीजिए:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

जब दूसरी तारीख पहली से पहले की हो, तो परिणाम ऋणात्मक आता है:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

`Duration` भी स्टैटिक फैक्ट्री मेथड से ही बनाया जाता है:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601 संकेतन में `T` तारीख वाले हिस्से को समय वाले हिस्से से अलग करता है, इसी कारण ड्यूरेशन `PT...` की तरह लिखे जाते हैं।

किसी ड्यूरेशन को तारीख-समय में जोड़ा या उससे घटाया जा सकता है:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` दो तारीख-समय के बीच का सटीक समय लौटाता है:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

किसी ड्यूरेशन को `toHours()`, `toMinutes()` और `toSeconds()` जैसे मेथड से एक ही यूनिट में बदला जा सकता है। ये उस यूनिट में _कुल_ मात्रा लौटाते हैं, नीचे की ओर पूर्णांकित करके:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

किसी ड्यूरेशन को घड़ी की तरह उसके हिस्सों में बाँटने के लिए इसके बजाय `toXxxPart()` मेथड इस्तेमाल कीजिए:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
