# टेस्ट

## सेटअप

ज़रूरी डिपेंडेंसी इंस्टॉल करने के लिए [WebAssembly के सेटअप निर्देश][docs-exercism-wasm] देखिए।

## आवश्यकताएँ

अभ्यास की डिपेंडेंसी इंस्टॉल कीजिए:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## टेस्ट सूट को पास कराना

हर अभ्यास के साथ एक टेस्ट सूट आता है, जो आपको सबमिट करने से पहले अपने हल की जाँच करने में मदद करता है।
आप अभ्यास की डायरेक्टरी में कमांड प्रॉम्प्ट खोलकर ये टेस्ट चला सकते हैं:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

कुछ टेस्ट सूट में पहले वाले के अलावा बाकी सारे टेस्ट छोड़ दिए जाते हैं।

एक टेस्ट पास हो जाने के बाद आप `xtest` को `test` में बदलकर अगला टेस्ट चालू कर सकते हैं।

## अपने खुद के टेस्ट लिखना

अगर आप अतिरिक्त, कस्टम टेस्ट लिखना चाहते हैं, तो एक नई फाइल `custom.spec.js` बनाइए और अपने हल के साथ उस नई फाइल को भी सबमिट कीजिए:

```shell
exercism submit numbers.wat custom.spec.js
```
