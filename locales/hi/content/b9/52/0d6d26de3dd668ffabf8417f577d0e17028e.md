## सामान्य

`SimpleLinkedList` स्ट्रक्चर को `Vec` के रैपर के रूप में लागू न कीजिए। इसके बजाय नोड को हीप पर आवंटित कीजिए।

इसे कुछ इस तरह लागू किया जा सकता है:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

`head` फील्ड इस लिंक्ड लिस्ट के पहले एलिमेंट (Node) को इंगित करता है।

इस तरह लागू करने के लिए एक `Node` स्ट्रक्चर भी चाहिए, जिसमें ये फील्ड होते हैं:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` में संग्रहीत डेटा रहता है, और `next` अगले नोड (अगर मौजूद हो) को इंगित करता है, वरना None।

## `Option<Box<Node<T>>>` क्यों, और सिर्फ `Option<Node<T>>` क्यों नहीं?

इसे खुद आज़माकर देखिए। आपको यह एरर मिलेगी:

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

समस्या यह है कि कंपाइल के समय next का साइज़ पता होना ज़रूरी है।
चूँकि `next` रिकर्सिव है ("एक नोड के अंदर नोड, उसके अंदर नोड..."), कंपाइलर को यह नहीं पता चलता कि कितनी मेमोरी आवंटित करनी है।
इसके विपरीत, [Box](https://doc.rust-lang.org/std/boxed/) एक हीप पॉइंटर है, जिसका साइज़ तय होता है।
