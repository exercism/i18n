# बारे में

एक बूलियन वैल्यू बताती है कि कोई शर्त `true` है या `false`.
Go में `bool` टाइप इन दो वैल्यू में से केवल एक ही हो सकता है।

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## तार्किक ऑपरेटर

तार्किक ऑपरेटर एक या दो बूलियन वैल्यू पर काम करते हैं और बूलियन परिणाम देते हैं।

| ऑपरेटर | नाम | व्यवहार |
| -------- | ---- | ---------------------------------------------- |
| `!`      | नॉट | एक बूलियन वैल्यू का विपरीत लौटाता है |
| `&&`     | एंड | `true` तभी लौटाता है जब दोनों ओर `true` हों |
| `\|\|`   | ऑर | `true` तब लौटाता है जब कोई भी एक ओर `true` हो |

जब आपको किसी बूलियन वैल्यू का विपरीत चाहिए, तब `!` (नॉट) का इस्तेमाल कीजिए:

```go
!isDoorLocked // false
```

जब दोनों शर्तों का `true` होना ज़रूरी हो, तब `&&` (एंड) का इस्तेमाल कीजिए:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

जब कम से कम एक शर्त का `true` होना ज़रूरी हो, तब `||` (ऑर) का इस्तेमाल कीजिए:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

तार्किक ऑपरेटरों का मूल्यांकन इस क्रम में होता है: पहले `!`, फिर `&&`, और फिर `||`.

कोड को समूहों में बाँटने और यह तय करने के लिए कि कौन-से ऑपरेशन पहले हों, गोल ब्रैकेट का इस्तेमाल कीजिए:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
