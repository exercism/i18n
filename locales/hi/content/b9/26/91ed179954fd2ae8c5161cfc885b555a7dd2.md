# परिचय

कमेंट की मदद से आप कोड में नोट छोड़ सकते हैं। इससे कोड के चलने पर कोई असर नहीं पड़ता।
सिंगल-लाइन कमेंट `//` से शुरू होते हैं, और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखे जाते हैं:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

कमेंट के उद्देश्य अलग-अलग होते हैं, यह इस बात पर निर्भर करता है कि वे कहाँ लिखे गए हैं।

## कोड कमेंट

कोड कमेंट यह समझाते हैं कि कोई चीज़ क्यों की गई है, यह नहीं कि क्या की गई है।
जब कोड देखकर यह साफ न पता चले कि कोई फैसला क्यों लिया गया, तब इनका इस्तेमाल कीजिए:

```go
results = results[1:] // skipping the header row
```

## डॉक कमेंट

डॉक कमेंट सीधे किसी घोषणा से पहले लिखे जाते हैं। कमेंट और घोषणा के बीच कोई खाली लाइन नहीं होती।
[`godoc`][godoc] इन्हें पार्स करके पैकेज का डॉक्युमेंटेशन बनाता है।
डॉक कमेंट एक पूरा वाक्य होना चाहिए, जो उस आइडेंटिफायर के नाम से शुरू हो और अंत में पूर्ण विराम पर खत्म हो।

पैकेज कमेंट पैकेज के नाम से शुरू होते हैं:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

फंक्शन कमेंट फंक्शन के नाम से शुरू होते हैं:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
