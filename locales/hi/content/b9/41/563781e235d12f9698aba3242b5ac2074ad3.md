# टेस्ट

## टेस्ट चलाना

जब आप किसी अभ्यास की डायरेक्टरी में होते हैं, तो आपको दो सबडायरेक्टरी दिखनी चाहिए:

* `src` में उस अभ्यास के लिए आपका हल रहता है
* `spec` में उस अभ्यास के लिए चलाए जाने वाले टेस्ट रहते हैं

अगर आप सही डायरेक्टरी में हैं (यानी वह डायरेक्टरी जिसमें `src` और `spec` दोनों हैं), तो उस अभ्यास के टेस्ट `crystal spec` चलाकर चला सकते हैं:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

इससे `spec` डायरेक्टरी की सभी टेस्ट फाइलें चल जाएँगी।

हर टेस्ट फाइल में पहले टेस्ट के अलावा बाकी सभी टेस्ट छोड़ दिए गए हैं।

एक बार कोई टेस्ट पास हो जाए, तो `pending` को `it` में बदलकर अगले टेस्ट को भी चलने लायक बना सकते हैं।

## Crystal फॉर्मेट

सबमिट करने से पहले यह सलाह दी जाती है कि आप अपने हल पर `crystal tool format` चलाएँ।

आप अपनी मौजूदा डायरेक्टरी की हर चीज़ इस तरह फॉर्मेट कर सकते हैं:

```bash
$ crystal tool format ./
```

या आप चुनकर कुछ फाइलें इस तरह फॉर्मेट कर सकते हैं:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## अपना हल सबमिट करना

अपना हल सबमिट करते समय `src` डायरेक्टरी की सोर्स फाइल ज़रूर सबमिट कीजिए:

```bash
$ exercism submit src/<exercise>.cr
```
