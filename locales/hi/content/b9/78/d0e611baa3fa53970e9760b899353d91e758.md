# स्ट्रिंग

`STR` में टेक्स्ट रखा जाता है। स्ट्रिंग को डबल कोट्स के बीच लिखा जाता है।

```sather
   composer : STR is
      return "Sibelius";
   end;
```

एक बार बन जाने के बाद `STR` कभी नहीं बदलती। नीचे दिया गया हर तरीका जवाब में एक नई स्ट्रिंग देता है, उस स्ट्रिंग को बदलता नहीं जिसके बारे में पूछा गया था।

## जोड़ना

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` किसी संख्या को भी स्ट्रिंग से जोड़ देता है, और इसी तरह कोई संख्या वाक्य के अंदर पहुँच जाती है:

```sather
"Opus " + 27           -- "Opus 27"
```

## लंबाई

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` अक्षर गिनता है, और जवाब एक `INT` होता है।

## टुकड़े

| कॉल | जवाब |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

मौजूद अक्षरों से ज़्यादा माँगने पर विफल होने के बजाय उतना ही मिलता है जितना मौजूद है।

## तुलना करना

`=` बताता है कि दो स्ट्रिंग का टेक्स्ट एक ही है या नहीं, और `/=` बताता है कि वे अलग हैं या नहीं।

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

अक्षरों का बड़ा या छोटा होना मायने रखता है। `.upper` और `.lower` स्ट्रिंग की एक ऐसी कॉपी देते हैं जिसमें सारे अक्षर एक ही आकार के होते हैं, और छोटे-बड़े अक्षरों की परवाह किए बिना तुलना करने का आम तरीका यही है:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## साइज़ के बारे में एक बात

`STR` बाइट्स की एक कतार होती है, और `.size` बाइट्स गिनता है। अंग्रेज़ी टेक्स्ट के लिए यह अक्षर गिनने के बराबर ही है। लेकिन जिन टेक्स्ट में एक्सेंट या दूसरी लिपियाँ हों, वहाँ ऐसा नहीं है, क्योंकि वहाँ हर अक्षर एक से ज़्यादा बाइट लेता है।
