# मैच एक्सप्रेशन

एक मैच एक्सप्रेशन एक वैल्यू और एक शर्त का मूल्यांकन करके एक ऐसा एक्सप्रेशन लौटाता है जिसका मूल्यांकन किया जाएगा। टर्नरी ऑपरेटर की तरह ही, अगर शर्त नहीं मिलती, तो लौटाया जाने वाला एक्सप्रेशन मूल्यांकित नहीं होता। शर्त मिलाने के लिए पहचान की जाँच की जाती है, यानी सख्त समानता या `===` की जाँच।

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

समानता [`==`] की जाँच करने के लिए आप शर्त को इस तरह बदल सकते हैं:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

मैच एक्सप्रेशन में अगर कोई भी शर्त नहीं मिलती, तो एक `UnhandledMatchError` फेंका जाता है।
