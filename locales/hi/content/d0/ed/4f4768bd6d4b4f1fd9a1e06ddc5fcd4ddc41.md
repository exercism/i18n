# परिचय

Go में [`Time`][time] एक ऐसा टाइप है जो समय के किसी एक पल को बताता है।
तारीख और समय की जानकारी इसके मेथडों के ज़रिए देखी जा सकती है, उनकी तुलना की जा सकती है और उन्हें बदला जा सकता है, लेकिन कुछ फंक्शन सीधे `time` पैकेज पर भी कॉल किए जाते हैं।
वर्तमान तारीख और समय [`time.Now`][now] फंक्शन से प्राप्त किया जा सकता है।

[`time.Parse`][parse] फंक्शन स्ट्रिंग को पार्स करके `Time` टाइप की वैल्यू बनाता है।
Go में यह तय करने का एक खास तरीका है कि पार्स करते समय आप किस लेआउट की उम्मीद करते हैं।
आपको इस खास टाइमस्टैम्प की वैल्यू इस्तेमाल करके लेआउट का एक उदाहरण लिखना है:
`Mon Jan 2 15:04:05 -0700 MST 2006`।

उदाहरण के लिए:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

[`Time.Format()`][format] मेथड समय का स्ट्रिंग रूप लौटाता है।
ठीक वैसे ही जैसे `Parse` फंक्शन में, यहाँ भी लक्ष्य लेआउट उसी खास टाइमस्टैम्प की वैल्यू इस्तेमाल करने वाले एक उदाहरण से तय किया जाता है।

उदाहरण के लिए:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## लेआउट के विकल्प

अपने किसी लेआउट के लिए इन विकल्पों का मेल इस्तेमाल कीजिए।
Go में तारीख और टाइमस्टैम्प के लिए पहले से तय [फॉर्मैट कॉन्स्टेंट][const] भी उपलब्ध हैं।

| समय           | विकल्प                                              |
| ----------- | ---------------------------------------------- |
| साल        | 2006 ; 06                                      |
| महीना       | Jan ; January ; 01 ; 1                         |
| दिन         | 02 ; 2 ; \_2 (आगे 0 लगाने के लिए)                 |
| सप्ताह का दिन     | Mon ; Monday                                   |
| घंटा        | 15 ( 24 घंटे का टाइम फॉर्मैट ) ; 3 ; 03 (AM या PM) |
| मिनट       | 04 ; 4                                         |
| सेकंड      | 05 ; 5                                         |
| AM/PM का निशान  | PM                                             |
| साल का दिन | 002 ; \_\_2                                    |

`time.Time` टाइप में किसी खास समय को पढ़ने के लिए कई मेथड हैं। जैसे घंटा: [`Time.Hour()`][hour] , महीना: [`Time.Month()`][month]।
यह कैसे काम करता है, इसके बारे में और जानकारी [आधिकारिक डॉक्युमेंटेशन][time] में मिल सकती है।

[`time`][time] पैकेज में एक और टाइप भी शामिल है, [`Duration`][duration], जो बीते हुए समय को दर्शाता है। इसके अलावा इसमें स्थान/टाइम ज़ोन, टाइमर और जुड़ी हुई दूसरी सुविधाओं का सपोर्ट भी है, जिन पर किसी और कॉन्सेप्ट में बात की जाएगी।
