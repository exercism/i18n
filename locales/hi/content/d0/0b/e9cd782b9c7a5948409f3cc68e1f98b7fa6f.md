# इंस्टॉलेशन

## Mac

Homebrew का उपयोग करके इंस्टॉल कीजिए: `brew install swi-prolog`.
या फिर अपनी मशीन के लिए सोर्स [SWI Prolog वेबसाइट](http://www.swi-prolog.org/download/devel) से डाउनलोड कीजिए।

## Windows

अपनी मशीन के लिए सोर्स [SWI Prolog वेबसाइट](http://www.swi-prolog.org/download/devel) से डाउनलोड कीजिए।

## Linux

अपने डिस्ट्रो के लिए निर्देश [यहाँ](http://www.swi-prolog.org/build/unix.html) दिए गए हैं, उनका पालन कीजिए।
