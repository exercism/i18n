# प्लेसहोल्डर

## bash के साथ हल कैसे करें

`bash` में डेटटाइम स्ट्रिंग **पार्स** करने का कोई बिल्ट-इन तरीका नहीं है।
इस अभ्यास में आपको बाहरी यूटिलिटी को कॉल करना होगा।

* GNU `date` कमांड के `-d` ऑप्शन की मदद से [कई तरह के फॉर्मैट][gnu-date] पार्स किए जा सकते हैं।
* Mac उपयोगकर्ताओं के लिए [BSD `date` कमांड][bsd-date] और उसका `-f` ऑप्शन देखिए।
* Perl लगभग हर जगह उपलब्ध है, और इसके [`Time::Piece` मॉड्यूल][time-piece] की मदद से टाइमस्टैंप पार्स किए जा सकते हैं।

bash किसी बाहरी टूल के बिना भी तारीखों को **फॉर्मैट** कर सकता है।
अगर आपके पास समय की वैल्यू पूर्णांक के रूप में है (एपॉक के बाद के सेकंड), तो [`printf` `%()T` फॉर्मैटर][bash-printf] की मदद से "strftime" शैली की फॉर्मैटिंग लगाई जा सकती है।

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```
