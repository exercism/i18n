# परिचय

PowerShell, Microsoft की एक गतिशील और इम्प्लिसिट टाइपिंग वाली स्क्रिप्टिंग भाषा है (_हालाँकि यह [स्ट्रॉन्गली टाइप्ड][strong typed] वेरिएबल भी सपोर्ट करती है_), जो मुख्य रूप से काम के ऑटोमेशन और कॉन्फिगरेशन मैनेजमेंट पर केंद्रित है।

PowerShell इम्परेटिव, फंक्शनल, ऑब्जेक्ट-ओरिएंटेड और यहाँ तक कि पाइपलाइन शैली की प्रोग्रामिंग भी सपोर्ट करती है।

PowerShell को .NET प्लेटफॉर्म पर बनाया गया था और इसे पहली बार 2006 में रिलीज़ किया गया था।
यह हर आधुनिक Windows OS में डिफॉल्ट रूप से शामिल रहा है, और इसे Mac तथा Linux पर भी इंस्टॉल किया जा सकता है।


## वेरिएबल

PowerShell में वेरिएबल बनाने के दो आम तरीके हैं।

PowerShell में वेरिएबल के नाम की शुरुआत `$` से होनी चाहिए, और वेरिएबल के नाम को किसी वैल्यू से जोड़ने के लिए असाइनमेंट ऑपरेटर `=` का इस्तेमाल किया जाता है।

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

अगर आप चाहते हैं कि वैल्यू किसी खास टाइप की ही हो, तो आप वेरिएबल का टाइप साफ-साफ बता भी सकते हैं।
अगर मुमकिन हो, तो PowerShell वैल्यू को एक टाइप से दूसरे टाइप में बदलने की पूरी कोशिश करता है।

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### कॉन्स्टेंट

PowerShell में कॉन्स्टेंट ऐसे वेरिएबल होते हैं जिन्हें बनाने के बाद न **बदला** जा सकता है और न **हटाया** जा सकता है।
यह हमें वेरिएबल बनाने के दूसरे तरीके तक ले आता है: कमांडलेट `New-Variable` का उपयोग करना।

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

नया वेरिएबल बनाने के अधिक विस्तृत और एडवांस्ड तरीकों के लिए, कृपया [New-Variable][New-Variable] पढ़िए।


## फंक्शन

PowerShell में [फंक्शन][functions] `function` कीवर्ड से बनाए जाते हैं।
हर फंक्शन में शून्य या उससे अधिक पैरामीटर `()` ब्रैकेट के अंदर हो सकते हैं, और उसके बाद फंक्शन का स्कोप होता है, जो `{` से शुरू होकर `}` पर खत्म होता है।

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell में आप फंक्शन को `FuncName $Arg` सिंटैक्स से कॉल करने के बाद `return` कीवर्ड के जरिए वैल्यू सीधे लौटा सकते हैं।

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

विस्तृत फंक्शन डेफिनिशन कैसे लिखें, और फंक्शन वैल्यू कैसे इम्प्लिसिट रूप से लौटाते हैं, इस पर एक एडवांस्ड नज़र `Functions` कॉन्सेप्ट मॉड्यूल में डाली जाएगी।


## कमेंट

PowerShell में एकल कमेंट `#` से शुरू होते हैं और लाइन खत्म होने पर खत्म हो जाते हैं।
PowerShell में कमेंट ब्लॉक `<#` से शुरू होते हैं और `#>` पर खत्म होते हैं।
कमेंट ब्लॉक से Comment-Based Help बनाने का एडवांस्ड नमूना `Functions` कॉन्सेप्ट मॉड्यूल में दिया जाएगा।

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
