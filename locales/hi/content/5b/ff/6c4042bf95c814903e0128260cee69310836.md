# परिचय

## कॉन्स्टेंट और फंक्शन

कॉन्स्टेंट वैल्यू को `name = expression` के रूप में परिभाषित किया जाता है। ध्यान दीजिए कि एल्म में परिभाषाओं के अलावा बाकी सब कुछ एक्सप्रेशन होता है।

```elm
five = 5

six = 3 + 3
```

फंक्शन `name parameters... = expression` के रूप में बनाए जाते हैं, और पैरामीटर के बीच केवल स्पेस डाला जाता है।

```elm
add number1 number2 = number1 + number2
```

किसी फंक्शन को कॉल करना भी एक एक्सप्रेशन है। इसमें आप फंक्शन का नाम लिखते हैं और उसके हर पैरामीटर के लिए एक-एक आर्गुमेंट देते हैं। आर्गुमेंट के बीच स्पेस डाला जाता है, बिल्कुल उसी तरह जैसे फंक्शन बनाते समय पैरामीटर के बीच डाला जाता है।

```elm
five = add 2 3
```

किसी एक्सप्रेशन के मूल्यांकन का क्रम तय करने के लिए ब्रैकेट का उपयोग किया जा सकता है।

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## इंडेंटेशन / महत्वपूर्ण व्हाइटस्पेस

कोड की सीमाएँ बताने के लिए एल्म घुंघराले ब्रैकेट, ब्रैकेट या सेमीकोलन जैसे सिंटैक्स चिह्नों का उपयोग नहीं करता। इसके बजाय यह व्हाइटस्पेस और इंडेंटेशन का उपयोग करता है।

- मॉड्यूल, इम्पोर्ट और टॉप-लेवल फंक्शन की परिभाषाएँ सबसे बाएँ कॉलम से शुरू होनी चाहिए।
- अगर किसी एक्सप्रेशन को कई लाइनों में बाँटा जाए, तो उस एक्सप्रेशन का हिस्सा बने कोड को उस एक्सप्रेशन के नीचे कम से कम एक स्पेस इंडेंट करके लिखा जाना चाहिए।
- एक्सप्रेशन के जो हिस्से एक साथ रखे जाते हैं, उन्हें बराबर संख्या के स्पेस से इंडेंट किया जाना चाहिए।

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## मॉड्यूल

एल्म की हर फाइल एक मॉड्यूल होती है, और उसमें बाकी सारे कोड से पहले एक `module` स्टेटमेंट होना चाहिए।
मॉड्यूल का नाम उसकी फाइल के नाम से मेल खाना चाहिए, यानी मॉड्यूल `Calculator` को Calculator.elm फाइल में होना चाहिए।
मॉड्यूल के अंदर परिभाषित हर चीज़ निजी तौर पर उसी मॉड्यूल तक सीमित रहती है और इसे इस मॉड्यूल के बाहर से एक्सेस नहीं किया जा सकता, जब तक कि उसे `exposing` में सूचीबद्ध न किया गया हो।

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## कमेंट

कमेंट एल्म फाइल के अंदर लिखा वह टेक्स्ट होता है जिसे कोड के रूप में नहीं समझा जाता।
यह मुख्य रूप से आपके और दूसरे प्रोग्रामर के पढ़ने के लिए होता है।
एक लाइन वाले कमेंट के लिए डबल डैश पर आधारित एक हल्का सिंटैक्स है।
मल्टीलाइन कमेंट भी संभव हैं, जिनके लिए शुरू और बंद करने वाले डेलिमिटर का जोड़ा, `{-` और `-}`, इस्तेमाल किया जाता है।

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
