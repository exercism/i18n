# निर्देश परिशिष्ट

## बिटवाइज़ ऑपरेटर

PHP में [बिटवाइज़ ऑपरेटर](https://www.php.net/manual/en/language.operators.bitwise.php) मौजूद हैं।

उदाहरण के लिए, “बिटवाइज़ और” ऑपरेटर (`&`) का उपयोग यह जाँचने के लिए किया जा सकता है कि किसी संख्या का कोई बिट सेट है या नहीं:

```php
$number = 89; // 0b01011001
$mask16 = 16; // 0b00010000
$mask32 = 32; // 0b00100000

$isMask16 = ($number & $mask16) > 0; // 0b00010000 > 0 => TRUE
$isMask32 = ($number & $mask32) > 0; // 0b00000000 > 0 => FALSE
```
