# परिचय

Factor में तारीख और समय के साथ काम करने के लिए [`calendar`][calendar] वोकैबुलरी है। समय का एक बिंदु `timestamp` होता है, और समय का एक फैलाव `duration` होता है।

## तारीख बनाना

`<date>` (जो [`calendar`][calendar] में है) दिए गए दिन की आधी रात का `timestamp` बनाता है:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` किसी टाइमस्टैम्प को वापस उसके हिस्सों में बाँट देता है:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## तारीख की जाँच

`day-of-week` हफ्ते के दिन को एक पूर्णांक के रूप में लौटाता है, रविवार के लिए `0` से शनिवार के लिए `6` तक। `day-names` (जो [`calendar.english`][english] में है) उन्हीं के नामों की सूची है, इसलिए `day-names nth` किसी संख्या को उसके नाम में बदल देता है:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` एक वर्ष (या एक टाइमस्टैम्प) लेता है, और `days-in-month` किसी टाइमस्टैम्प के महीने की लंबाई लौटाता है, जिसमें लीप वर्ष का हिसाब पहले से शामिल होता है:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## तारीख का गणित

`days`, `weeks` और `hours` जैसे वर्ड एक `duration` बनाते हैं, और `time+` किसी टाइमस्टैम्प को एक `duration` जितना आगे बढ़ा देता है:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

गणित महीने और साल की सीमाओं के पार भी सही ढंग से काम करता है, और जो दो टाइमस्टैम्प एक ही पल को दर्शाते हैं, वे `=` से बराबर माने जाते हैं।

## दिन के समय

`<timestamp>` सेकंड तक का पूरा टाइमस्टैम्प बनाता है। इसका अंतिम आर्गुमेंट UTC से ऑफसेट होता है; `instant` (एक शून्य `duration`) टाइमस्टैम्प को UTC पर ही रखता है:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<`, `>date<` का उल्टा काम करता है और किसी टाइमस्टैम्प को उसके घंटे, मिनट और सेकंड में बाँट देता है:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` और `minutes` ठीक `days`, `weeks` और `hours` की तरह एक `duration` बनाते हैं, इसलिए इनमें से कोई भी `time+` को दिया जा सकता है:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

किसी टाइमस्टैम्प के अलग-अलग फील्ड `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` और `second>>` एक्सेसर से पढ़े जाते हैं:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
