# परिचय

Factor एक *कॉन्कैटिनेटिव* भाषा है: हर वर्ड अपने इनपुट एक साझा **डेटा स्टैक** से पढ़ता है और अपने आउटपुट वापस उसी पर रख देता है। वैल्यू को एक जगह से दूसरी जगह भेजने का और कोई तरीका नहीं है।

कोई लिटरल लिखने पर वह स्टैक के सबसे ऊपर चला जाता है; कोड बाएँ से दाएँ पढ़ा जाता है:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

एक *स्टैक इफेक्ट* डिक्लरेशन किसी वर्ड का कॉन्ट्रैक्ट बताता है:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` का मतलब है कि यह वर्ड दो वैल्यू हटाता है और दो वैल्यू उलटे क्रम में छोड़ जाता है। नाम केवल डॉक्युमेंटेशन के लिए हैं। कंपाइलर इनपुट और आउटपुट की सिर्फ *संख्या* जाँचता है। स्टैक का सबसे ऊपर वाला नाम सबसे दाईं ओर लिखा होता है।

रोज़मर्रा के `kernel` **शफल वर्ड** स्टैक के ऊपरी हिस्से को नया क्रम देते हैं:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

वर्ड `:` से बनाए जाते हैं और `;` पर खत्म होते हैं; कंपाइलर ऐसी परिभाषा स्वीकार नहीं करता जिसके अंदर का कोड घोषित स्टैक इफेक्ट से मेल नहीं खाता।
