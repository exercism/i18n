# परिचय

Haxe में `class` मुख्य डेटा स्ट्रक्चर है, जिसमें डेटा (फील्ड) और व्यवहार (मेथड) एक साथ रहते हैं। फील्ड और मेथड को क्लास के सदस्य भी कहा जाता है।

सदस्यों तक पहुँच को [एक्सेस मॉडिफायर][visibility] की मदद से सीमित किया जा सकता है। ये हैं:

- `public`: इस सदस्य तक कहीं से भी पहुँचा जा सकता है।
- `private`: इस सदस्य तक सिर्फ उसी क्लास से पहुँचा जा सकता है।

क्लास को इंस्टेंस बनाने के खाके की तरह समझा जा सकता है। [इंस्टेंस][class-instance] बनाने के लिए बस `new` कीवर्ड इस्तेमाल कीजिए:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

फील्ड बनाने के लिए एक्सेस मॉडिफायर, उसके बाद वेरिएबल का नाम और टाइप लिखिए:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

फील्ड बनाते समय आप उसकी शुरुआती वैल्यू भी तय कर सकते हैं। अगर किसी फील्ड की शुरुआती वैल्यू तय न की गई हो, तो उसकी वैल्यू `null` हो जाती है। किसी फील्ड तक डॉट नोटेशन से पहुँचा जा सकता है:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
