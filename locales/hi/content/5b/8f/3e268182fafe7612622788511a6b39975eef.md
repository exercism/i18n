# निर्देश

इस अभ्यास में आप एक विंडो पर आधारित कंप्यूटर सिस्टम का अनुकरण करेंगे।
आप कुछ विंडो बनाएँगे, जिन्हें हिलाया जा सकता है और जिनका आकार बदला जा सकता है।
नीचे दिया गया चित्र उन वैल्यू को दर्शाता है जिनके साथ आप आगे काम करेंगे।

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. Program Window की प्रॉपर्टी घोषित कीजिए

दिए गए क्लास ढाँचे का उपयोग करके `y`, `x`, `height` और `width` वैल्यू के लिए प्रॉपर्टी दीजिए।

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Program Window की शुरुआती वैल्यू तय कीजिए

`ProgramWindow` के लिए एक कंस्ट्रक्टर फंक्शन बनाइए।
इसे कोई आर्गुमेंट नहीं लेना चाहिए, लेकिन कंस्ट्रक्टर के चलने के दौरान इसकी प्रॉपर्टी की डिफॉल्ट वैल्यू तय कीजिए।
इसे शुरुआती `y` और `x` वैल्यू `0` पर रखना चाहिए।
शुरुआती `height` और `width` को `600x800` स्क्रीन साइज़ पर रखना चाहिए।

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. विंडो का आकार बदलने के लिए फंक्शन बनाइए

`Size.php` में `Size` नाम की एक नई क्लास बनाइए।
इस क्लास के कंस्ट्रक्टर को ऐसे आर्गुमेंट लेने चाहिए जो `height` और `width` प्रॉपर्टी तय करें।
इसके अलावा `ProgramWindow` को एक आकार बदलने वाला फंक्शन चाहिए, जो `Size` ऑब्जेक्ट का इंस्टेंस लेता है और `ProgramWindow` की अपनी प्रॉपर्टी बदल देता है।

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. विंडो को हिलाने के लिए फंक्शन बनाइए

`Position.php` में `Position` नाम की एक नई क्लास बनाइए।
इस क्लास के कंस्ट्रक्टर को ऐसे आर्गुमेंट लेने चाहिए जो `y` और `x` प्रॉपर्टी तय करें।
इसके अलावा `ProgramWindow` को एक हिलाने वाला फंक्शन चाहिए, जो `Position` ऑब्जेक्ट का इंस्टेंस लेता है और `ProgramWindow` की अपनी प्रॉपर्टी बदल देता है।

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
