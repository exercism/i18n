# टेस्ट

Exercism की वेबसाइट पर मौजूद ऑनलाइन एडिटर की मदद से भी आप अभ्यास हल कर सकते हैं।
या फिर अभ्यास अपने कंप्यूटर पर डाउनलोड कीजिए, उन्हें वहीं हल कीजिए और फिर Exercism पर सबमिट कीजिए।
इस दस्तावेज़ के बाकी हिस्से में बात होगी अपने कंप्यूटर पर काम करने की।

## Exercism CLI

अभ्यास डाउनलोड करने और सबमिट करने के लिए आपको `exercism` कमांड-लाइन टूल की ज़रूरत होगी।
इसे डाउनलोड करने और कॉन्फिगर करने के निर्देश [exercism cli के दस्तावेज़][exercism-cli] में दिए गए हैं।

किसी अभ्यास को डाउनलोड करने के लिए यह कीजिए:

```bash
exercism download --track 8th --exercise hello-world
```

और अभ्यास की डायरेक्टरी में चलिए:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

या अगर आप Windows पर हैं:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

ध्यान रखिए कि अपना exercism वर्कस्पेस आप `exercism configure` कमांड की मदद से पता कर सकते हैं।

## स्थानीय रूप से टेस्ट चलाना

किसी अभ्यास के टेस्ट चलाने के लिए आपको उस अभ्यास की सही डायरेक्टरी में होना चाहिए।
फिर इस कमांड से टेस्ट शुरू कीजिए:

```bash
8th -f test.8th
```

## छोड़े गए टेस्ट

किसी अभ्यास को हल करने का मतलब है कि उसके सारे टेस्ट पास हो जाएँ।
जब आप टेस्ट चलाते हैं, तो डिफॉल्ट रूप से सिर्फ एक टेस्ट (पहला वाला) चलाया जाता है।
यह जानबूझकर ऐसा रखा गया है, ताकि आपका ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर लगा रहे।
वह पास हो जाए, तो `SKIP-REST-OF-TESTS` लाइन को अगले टेस्ट के नीचे खिसका दीजिए और वह अगला टेस्ट चालू हो जाएगा।

### स्किप को ओवरराइड करना

`SKIP-REST-OF-TESTS` शब्द के बाद वाले टेस्ट भी समेत सारे टेस्ट चलाने के लिए आप एनवायरनमेंट वेरिएबल `RUN_ALL_TESTS` की वैल्यू `true` रख सकते हैं।
सिर्फ टेस्ट चलने के दौरान इसे सेट करने का एक तरीका यह है (macOS और Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## अपना हल सबमिट कीजिए

exercism टूल की मदद से अपना हल Exercism की वेबसाइट पर अपलोड करने के लिए:

```bash
exercism submit
```

ध्यान दीजिए कि आप अपना कोड तब भी अपलोड कर सकते हैं, जब वह सारे टेस्ट पास न कर रहा हो।
अगर आप अटक गए हैं और किसी मेंटर से मदद चाहिए, तो यह अच्छा रहता है।

[exercism-cli]: https://exercism.org/docs/using/solving-exercises/working-locally
