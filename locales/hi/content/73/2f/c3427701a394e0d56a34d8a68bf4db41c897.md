# विवरण

[स्विच एक्सप्रेशन][switch-expressions] उसी तरह काम करते हैं जैसे [स्विच स्टेटमेंट][switch-statements], जिनकी चर्चा [concept:csharp/switch-statements]() में की गई है। ये एक तरह की निर्णय तालिका का काम करते हैं, जो इनपुट की शर्तों को कार्यों या वैल्यू से जोड़ती है।

स्विच एक्सप्रेशन का आधार _पैटर्न मैचिंग_ है। कोडिंग अभ्यास में हमने वैल्यू को `const` पैटर्न से मिलाया था। यहाँ `switch` को मिलने वाले इनपुट एक _रेंज एक्सप्रेशन_ होते हैं, जिसे const वैल्यू और _केस गार्ड_ द्वारा इस्तेमाल की जाने वाली वैल्यू से मिलाया जाता है।

केस (जिन्हें _स्विच आर्म_ भी कहा जाता है) टेक्स्ट के क्रम में जाँचे जाते हैं। जैसे ही कोई मेल मिल जाता है, प्रक्रिया वहीं रोक दी जाती है और संबंधित वैल्यू लौटा दी जाती है।

सूची में सबसे अंत में आने वाला `_` केस यह सुनिश्चित करने के लिए उपयोगी है कि मिलान सभी संभावित स्थितियों को कवर करता है, और संभावित रन-टाइम एरर से बचा जा सके।

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

`switch` का कोई "आर्म" तब चुना जाता है जब पैटर्न रेंज वेरिएबल से मेल खाता है और कोई केस गार्ड सही निकलता है।

स्विच एक्सप्रेशन [टाइप पैटर्न][pattern-matching] और रिकर्सिव मैचिंग का भी समर्थन करते हैं।
