# अधिक जानकारी

[Lua](https://lua.org) एक सरल, फिर भी शक्तिशाली, कुशल, हल्की और एम्बेड करने योग्य स्क्रिप्टिंग भाषा है। इसे 1993 से ब्राज़ील के [PUC-RIO](https://www.puc-rio.br/) में Roberto Ierusalimschy, Waldemar Celes और Luiz Henrique de Figueiredo की टीम डिज़ाइन करती आ रही है, बनाती आ रही है और इसका रखरखाव करती आ रही है।

## टिप्पणियाँ

Lua में एक पंक्ति की टिप्पणी `--` से शुरू होती है और कई पंक्तियों की टिप्पणी `--[[` से शुरू होकर `]]` पर खत्म होती है।
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## वेरिएबल

Lua में तीन तरह के वेरिएबल होते हैं: ग्लोबल वेरिएबल, लोकल वेरिएबल और टेबल फील्ड। बात आसान रखने के लिए यहाँ सिर्फ लोकल वेरिएबल के बारे में बताया गया है। डिफॉल्ट रूप से सभी वेरिएबल ग्लोबल होते हैं, इसलिए लोकल वेरिएबल को `local` कीवर्ड के साथ घोषित करना पड़ता है।
```lua
local x
```

`=` ऑपरेटर की मदद से किसी वेरिएबल को एक वैल्यू असाइन की जा सकती है।
```lua
local x = 1
```

किसी `local` वेरिएबल का स्कोप उस ब्लॉक तक ही सीमित रहता है जहाँ उसे घोषित किया गया हो। ब्लॉक किसी कंट्रोल स्ट्रक्चर की बॉडी हो सकता है, किसी फंक्शन की बॉडी हो सकता है, या वह फाइल या स्ट्रिंग हो सकता है जहाँ वेरिएबल घोषित किया गया है।
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## फंक्शन

फंक्शन को `function` कीवर्ड से घोषित किया जाता है और वेरिएबल की तरह यह भी डिफॉल्ट रूप से ग्लोबल होता है। फंक्शन की परिभाषा में एक नाम, पैरामीटर की सूची और एक बॉडी होती है। जब `return` कीवर्ड तक पहुँचा जाता है, तो फंक्शन वहीं से निकल जाता है और उसके बाद लिखी सारी वैल्यू लौटा देता है। अगर `return` न दिया जाए, तो फंक्शन `nil` लौटाता है।

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## टेबल

टेबल Lua में डेटा को व्यवस्थित करने का इकलौता तरीका है और बहुत शक्तिशाली होता है। ऐरे, सेट, ऑब्जेक्ट, मॉड्यूल जैसी चीज़ों को दर्शाने के लिए टेबल का इस्तेमाल किया जाता है, और ऐसा बहुत कुछ और भी है। मूल रूप से Lua का टेबल एक असोसिएटिव ऐरे होता है।
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

यह सिर्फ एक छोटी-सी झलक है, जो अगले भाग के लिए ज़रूरी है। इस विषय पर हम बाद में विस्तार से लौटेंगे।

## मॉड्यूल

मॉड्यूल कोड का एक समूह है जो `.lua` सोर्स फाइल में संग्रहीत रहता है। मॉड्यूल जो कुछ भी एक्सपोर्ट करता है, वह सब एक टेबल में रखा जाता है, और फाइल के अंत में यही टेबल लौटाया जाता है। यानी टेबल किसी नेमस्पेस जैसा काम करता है।
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

उसके बाद उस मॉड्यूल को `require` फंक्शन के ज़रिए किसी दूसरी फाइल में लोड किया जा सकता है, और यह फंक्शन वह टेबल लौटाता है।
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

जब हम `say.hello` देखते हैं, तो हमारे मन में यह आता है कि यह "मॉड्यूल `say` का फंक्शन `hello`" है। लेकिन यह जानते हुए कि हमारी `say-hello.lua` एक टेबल लौटाती है, और टेबल वाले भाग को दोबारा देखते हुए, हमें पता चलता है कि Lua में इस एक्सप्रेशन का मतलब है "टेबल `say` में स्ट्रिंग `hello` को की के रूप में इस्तेमाल करके इंडेक्स करना"।

हालाँकि मॉड्यूल के लिए टेबल लौटाना अच्छा तरीका माना जाता है, लेकिन किसी भी दूसरे टाइप को लौटाना भी उतना ही संभव है, जैसे कोई फंक्शन।

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
