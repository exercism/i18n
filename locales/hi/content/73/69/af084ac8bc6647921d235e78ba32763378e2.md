# निर्देश

आप जर्मनी के म्यूनिख शहर की एक बड़ी कंपनी में सिस्टम एडमिनिस्ट्रेटर के रूप में काम करते हैं। आपकी जिम्मेदारियों में से एक ईमेल अकाउंट का प्रबंधन है।

कई लोग शिकायत कर रहे हैं कि वे मिस्टर मुलर को ईमेल नहीं भेज पा रहे। आपको जल्द ही समझ आ जाता है कि कंपनी के ज़्यादातर लोग एक पुराना ईमेल क्लाइंट इस्तेमाल करते हैं, जो गैर-ASCII अक्षर की वजह से `müller@firma.de` को मान्य ईमेल पता नहीं मानता।

लोगों से यह कहना कि वे अपना पसंदीदा पुराना ईमेल क्लाइंट छोड़ दें, एक हारी हुई लड़ाई है, इसलिए आप तय करते हैं कि सभी ईमेल अकाउंट के लिए साफ किए गए उपनाम बनाए जाएँ।

## 1. छोटे अक्षरों के अलावा सब कुछ हटाकर मौजूदा यूज़रनेम साफ कीजिए

`sanitize/1` फंक्शन बनाइए। यह एक यूज़रनेम को चारलिस्ट के रूप में लेता है और वह यूज़रनेम लौटाता है जिसमें छोटे अक्षरों के अलावा बाकी सभी अक्षर हटा दिए गए हैं।

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. अंडरस्कोर की अनुमति दीजिए

`sanitize/1` फंक्शन को बढ़ाइए। यह यूज़रनेम से अंडरस्कोर नहीं हटाता।

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. जर्मन अक्षरों की जगह ASCII विकल्प लगाइए

जर्मन वर्णमाला में 4 गैर-ASCII अक्षर हैं, और इन सभी के लिए आम तौर पर मान्यता प्राप्त ASCII विकल्प मौजूद हैं।

| जर्मन अक्षर | ASCII विकल्प |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

`sanitize/1` फंक्शन को बढ़ाइए। यह जर्मन अक्षरों को तालिका के अनुसार बदल देता है। आप यह मान सकते हैं कि सभी यूज़रनेम पहले से ही लोअरकेस में हैं।

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
