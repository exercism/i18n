# परिचय

जहाँ डेटा टाइप को अंतर्निहित रूप से कास्ट नहीं किया जा सकता, वहाँ आपको एक स्पष्ट कास्ट ऑपरेटर का उपयोग करना होगा।
कास्ट ऑपरेटर उस वैल्यू से पहले ब्रैकेट में लिखा गया लक्ष्य टाइप ही होता है जिसे आप कास्ट करना चाहते हैं:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```
