# परिचय

मूल रूप से दो तरह के लूप होते हैं:

1. किसी शर्त के पूरा होने तक लूप चलाना।
2. किसी संग्रह के एलिमेंट पर लूप चलाना।

दोनों R में संभव हैं, हालाँकि पहला ज़्यादा आम हो सकता है।

## `while` और `repeat`

ऐसी समस्याओं के लिए जहाँ लूप कितनी बार चलेगा यह पहले से नहीं पता होता, R में एक शर्त वाला `while` लूप होता है और बिना शर्त वाला `repeat` लूप होता है (जो `while (TRUE)` के बराबर है)।

इसका मूल रूप काफी सरल है:

```R
while (condition) {
  do_something()
}
```

इस स्थिति में प्रोग्राम तब तक लूप में चलता रहेगा जब तक `condition` `TRUE` न रहे।

लूप से समय से पहले बाहर निकलने के दो तरीके हैं:

- `break` लूप से बाहर निकाल देता है, और उसके बाद निष्पादन लूप के अंतिम कर्ली ब्रैकेट `}` के बाद वाली अगली लाइन से जारी रहता है।
- `return(x)` वर्तमान फंक्शन का निष्पादन रोक देता है और रिटर्न वैल्यू `x` को उस फंक्शन को कॉल करने वाले को लौटा देता है।

इन विकल्पों के साथ, कभी-कभी `repeat { ... }` से एक "अनंत" लूप बनाना सुविधाजनक होता है, और फिर लूप के अंदर के कोड में कोई रुकने की शर्त ढूँढकर `break` या `return` वाली लाइन चलाना।

ये तीनों वेरिएंट बराबर हैं और सभी `x == 0.4444...` पर खत्म होते हैं।

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## वेक्टर पर लूप चलाना

R में यह अक्सर जरूरी नहीं होता।
जैसा कि अन्य कॉन्सेप्ट में बताया गया है, कई फंक्शन पूरे वेक्टर पर काम करते हैं।

हालाँकि, कभी-कभी स्पष्ट लूप लिखने से बचा नहीं जा सकता।
यह खासकर तब सच होता है जब:

- लूप के अंदर के कोड में साइड इफेक्ट होते हैं, जैसे प्रिंट करना या फाइल I/O.
- जब तक कोई मानदंड पूरा न हो जाए, लूप चलता रहता है, और कितने इटरेशन लगेंगे यह पहले से नहीं पता होता।

लूप की शर्त गोल ब्रैकेट में होनी चाहिए।
फंक्शन के अंदर के कोड की तरह, एक लाइन वाले लूप के अंदर के कोड के लिए कर्ली ब्रैकेट वैकल्पिक होते हैं (लेकिन अक्सर लगाए जाते हैं)।

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

अगर वर्तमान इटरेशन किसी शर्त को पूरा नहीं करता, तो `next` की मदद से सीधे अगले इटरेशन पर जा सकते हैं:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

अगर संख्यात्मक इंडेक्स की जरूरत हो, तो `seq_along()` इस्तेमाल कीजिए।

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)` का इस्तेमाल करना _नहीं_ सुझाया जाता, क्योंकि जब `length(v)` शून्य हो तो यह समस्याएँ पैदा कर सकता है।
`1:0` रेंज `c(1, 0)` के बराबर है, इसलिए लूप के अंदर का कोड चलेगा और शायद फेल हो जाएगा।
`seq_along()` फंक्शन इस स्थिति को ठीक से संभालने के लिए बनाया गया है।
