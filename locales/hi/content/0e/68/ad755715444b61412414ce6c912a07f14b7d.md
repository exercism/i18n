# परिचय

टर्नरी ऑपरेटर की मदद से if शर्तों को स्टेटमेंट ब्लॉक के बजाय एक्सप्रेशन में लिखा जा सकता है। यह फंक्शनल प्रोग्रामिंग के तरीकों से मेल खाता है और अक्सर कोड को अधिक अभिव्यक्तिपूर्ण बनाता है तथा एरर होने की संभावना कम करता है।

टर्नरी ऑपरेटर तीन एक्सप्रेशन जोड़ता है। पहले एक शर्त आती है। शर्त सही होने पर उसके बाद वाले एक्सप्रेशन का मूल्यांकन किया जाता है और उसकी वैल्यू लौटाई जाती है (यह `if` वाला हिस्सा है, जो `?` से शुरू होता है)। शर्त गलत होने पर दूसरे एक्सप्रेशन का मूल्यांकन किया जाता है और उसकी वैल्यू लौटाई जाती है (यह `else` वाला हिस्सा है, जो `:` से शुरू होता है)।

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
