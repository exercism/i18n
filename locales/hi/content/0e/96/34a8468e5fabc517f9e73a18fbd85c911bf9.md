# परिचय

[`for` लूप][for-statement] की मदद से कोड को बार-बार तब तक चलाया जा सकता है जब तक कि कोई शर्त पूरी न हो जाए।

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for` लूप के चार हिस्से होते हैं:

1. इनिशियलाइज़र: लूप में घुसने से पहले एक बार चलाया जाता है। आम तौर पर लूप के अंदर इस्तेमाल होने वाले वेरिएबल घोषित करने के लिए।
2. शर्त: हर इटरेशन से पहले जाँची जाती है। जब तक यह `true` होती है, लूप चलता रहता है।
3. इटरेटर: हर इटरेशन के बाद चलाया जाता है। आम तौर पर लूप वेरिएबल को बदलने (अकसर बढ़ाने/घटाने) के लिए इस्तेमाल होता है।
4. बॉडी: वह कोड जो हर इटरेशन में चलता है।

## `for` बनाम `foreach` लूप

सामान्य तौर पर [concept:csharp/foreach-loops]() को `for` लूप से बेहतर माना जाता है, और इसके ये कारण हैं:

- `foreach` लूप _सभी_ वैल्यू पर चलना तय करता है। `for` लूप में एलिमेंट छूट जाना आसान है, जैसे ऑफ-बाय-वन एरर की वजह से।
- `foreach` लूप ज़्यादा _डिक्लेरेटिव_ होता है: आपका कोड बताता है कि आप _क्या_ करना चाहते हैं, जबकि `for` लूप बताता है कि आप इसे _कैसे_ करना चाहते हैं।
- `foreach` लूप में गलती की गुंजाइश नहीं रहती, जबकि `for` लूप में ऑफ-बाय-वन एरर होना आसान है।
- `foreach` लूप हर तरह के कलेक्शन पर काम करता है, उन पर भी जो एलिमेंट तक पहुँचने के लिए इंडेक्सर के इस्तेमाल का समर्थन नहीं करते।

यह तय करने के लिए कि `foreach` लूप _सभी_ वैल्यू पर चलेगा, कंपाइलर `foreach` लूप के अंदर कलेक्शन को बदलने की इजाज़त नहीं देता:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for` लूप के पास `foreach` लूप की तुलना में कुछ फायदे भी हैं:

- आप जिस इंडेक्स से चाहें, वहाँ से शुरू या रोक सकते हैं।
- आप कोई भी (बूलियन) रुकने की शर्त इस्तेमाल कर सकते हैं।
- लूप वेरिएबल को बढ़ाने का तरीका बदलकर आप एलिमेंट छोड़ सकते हैं।
- आप उलटी गिनती करके कलेक्शन पर पीछे से आगे तक काम कर सकते हैं।
- जिन परिस्थितियों में कलेक्शन शामिल नहीं हैं, वहाँ भी आप `for` लूप इस्तेमाल कर सकते हैं।
