# परिचय

एक *टपल* कई नामित वैल्यू को मिलाकर एक ऑब्जेक्ट बना देता है। दूसरी भाषाएँ इसी को रिकॉर्ड, स्ट्रक्ट या क्लास कहती हैं। हर टपल क्लास में नामित स्लॉट का एक तय सेट होता है, और Factor इनके लिए गेटर और सेटर अपने आप बना देता है।

## टपल को परिभाषित कीजिए

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

हर स्लॉट `{ name initial: default-value }` के रूप में घोषित किया जाता है। `initial:` क्लॉज़ न हो, तो डिफॉल्ट `f` होता है।

## टपल बनाइए

सबसे आसान कंस्ट्रक्टर `new` है:

```factor
point new .
! => T{ point }
```

`boa` (आर्गुमेंट के क्रम में) डेटा स्टैक से स्लॉट को घोषणा के क्रम में भरता है:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

लिटरल सिंटैक्स `T{ class { slot value } … }` से आप स्लॉट का कोई हिस्सा सेट करके टपल बना सकते हैं, और यह उसी तरह प्रिंट होता है:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

जब किसी स्लॉट की वैल्यू उसके डिफॉल्ट से मेल खाती है, तो प्रिंटर उसे छोड़ देता है।

## स्लॉट पढ़िए

Factor हर स्लॉट के लिए `slot>>` गेटर बना देता है। गेटर [`accessors`][accessors] में रहते हैं:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## स्लॉट बदलिए

सेटर `>>slot` के रूप में लिखे जाते हैं और टपल को उसी जगह *बदल* देते हैं:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

मूल टपल को वैसा ही रखना हो, तो पहले `clone` कीजिए:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` एक कोटेशन लेता है, जो मौजूदा वैल्यू को नई वैल्यू में बदल देता है:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` भी टपल को उसी जगह बदल देता है, इसलिए मूल टपल को बचाए रखना हो तो इसे कॉल करने से पहले `clone` कीजिए।

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
