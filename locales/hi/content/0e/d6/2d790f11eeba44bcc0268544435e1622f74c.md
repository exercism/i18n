# परिचय

`Map` का इस्तेमाल **की** और **वैल्यू** के जोड़े रखने के लिए किया जाता है। `Map` बनाने का तरीका ऐरे जैसा ही है, बस इसमें मैप लिटरल ऑपरेटर `=>` इस्तेमाल होता है। आप इनके की-वैल्यू टाइप स्पष्ट रूप से घोषित कर सकते हैं, या टाइप का अनुमान भी लगा सकते हैं। सभी की अलग-अलग होनी चाहिए, वरना एक एरर आ जाती है।

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Maps` पर `for` लूप से इटरेशन किया जा सकता है। आप या तो वैल्यू पर इटरेशन कर सकते हैं या की पर:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
