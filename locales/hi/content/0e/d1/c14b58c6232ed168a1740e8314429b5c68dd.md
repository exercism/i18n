# टाइप जगलिंग

टाइप जगलिंग को टाइप कोर्ज़न के नाम से भी जाना जाता है।
टाइप जगलिंग तब होती है जब कोई काम करने के लिए अलग-अलग टाइप की दो वैल्यू को एक ही टाइप में बदल दिया जाता है।

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

यह काम अपने आप भी हो सकता है (ऊपर का उदाहरण देखिए), और `C`-स्टाइल टाइप कास्टिंग से स्पष्ट रूप से भी किया जा सकता है:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

खुद से की जाने वाली टाइप कास्टिंग के लिए ये टाइप इस्तेमाल किए जा सकते हैं: `bool`, `int`, `float`, `string`, `array`, `object`.
अधिकतर टाइप कास्टिंग का इस्तेमाल पूर्णांक (`int`) को दशमलव संख्या (`float`) में बदलने के लिए किया जाता है, या इसका उलटा करने के लिए।
