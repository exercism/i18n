# परिचय

C# में एक प्रॉपर्टी क्लास का एक सदस्य होती है जो उस क्लास के अंदर के डेटा तक पहुँच प्रदान करती है। कॉल करने वाले डेटा को सेट कर सकते हैं या प्राप्त (get) कर सकते हैं। प्रॉपर्टी या तो ऑटो-इम्प्लीमेंटेड हो सकती है या उसका एक बैकिंग फील्ड होता है। इनमें एक set एक्सेसर और/या एक get एक्सेसर होते हैं। कुछ अन्य भाषाओं में एक "म्यूटेटर" लगभग set एक्सेसर के बराबर होता है और एक "एक्सेसर" लगभग get एक्सेसर के बराबर होता है, हालाँकि सिंटैक्स की बनावट पूरी तरह से अलग होती है।

जब कोई प्रॉपर्टी सेट की जाती है, तो इनपुट वैल्यू को जाँचा जा सकता है, फॉर्मेट किया जा सकता है या किसी और तरह से बदला जा सकता है। वास्तव में, क्लास में मौजूद कोड के लिए उपलब्ध कोई भी प्रोग्रामेटिक ऑपरेशन निष्पादित किया जा सकता है।

इसी तरह, जब कोई प्रॉपर्टी प्राप्त की जाती है, तो डेटा की गणना की जा सकती है या उसे फॉर्मेट किया जा सकता है, और फिर क्लास के लिए उपलब्ध कोई भी प्रोग्रामेटिक ऑपरेशन निष्पादित किया जा सकता है।

प्रॉपर्टी में एक्सेस मॉडिफायर (`public`, `private` आदि) उसी तरह होते हैं जैसे अन्य क्लास सदस्यों में होते हैं, लेकिन set एक्सेसर का एक्सेस लेवल get एक्सेसर से स्वतंत्र हो सकता है और इसके विपरीत भी। किसी प्रॉपर्टी में दोनों एक्सेसर होना ज़रूरी नहीं है, वह सिर्फ एक भी रख सकती है (या तो get या set)।

प्रॉपर्टी को व्यक्त करने के लिए बुनियादी सिंटैक्स दो रूप ले सकता है:

## फील्ड/एक्सप्रेशन बैक्ड प्रॉपर्टी:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## ऑटो-इम्प्लीमेंटेड प्रॉपर्टी

```
public int MyProperty { get; private set; } = 42;
```

इनिशियलाइज़ेशन वैकल्पिक है।
