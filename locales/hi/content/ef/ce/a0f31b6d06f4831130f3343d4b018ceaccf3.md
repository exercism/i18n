# बूलियन

Crystal में [`Bool`][bools] नाम का एक टाइप होता है।
यह `true` और `false` वैल्यू को दर्शाता है।

## लॉजिकल ऑपरेटर

Crystal में तीन लॉजिकल ऑपरेटर हैं (`!`, `||`, `&&`) जो बूलियन वैल्यू को जोड़कर ऐसे एक्सप्रेशन बनाते हैं जो अलग-अलग वैल्यू देते हैं।

### और(`&&`)

Crystal में [_और_ ऑपरेटर][and] को `&&` से दर्शाया जाता है। यह `true` लौटाता है अगर दोनों वैल्यू `true` हों; वरना यह `false` लौटाता है।
_और_ ऑपरेटर इस्तेमाल करते समय एक बूलियन `&&` के दाईं ओर और दूसरा बाईं ओर रखा जाता है।

```crystal
true && true
# => true

true && false
# => false
```

### या(`||`)

Crystal में [_या_ ऑपरेटर][or] को `||` से दर्शाया जाता है। यह `true` लौटाता है अगर दी गई वैल्यू में से **कम से कम एक** `true` हो।
अगर दोनों वैल्यू `false` हों, तो यह `false` लौटाता है।
_या_ ऑपरेटर इस्तेमाल करते समय एक बूलियन `||` के दाईं ओर और दूसरा बाईं ओर रखा जाना चाहिए।

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### नहीं(`!`)

Crystal में _नहीं_ ऑपरेटर को `!` से दर्शाया जाता है। यह `true` लौटाता है अगर दिया गया बूलियन `false` हो, और `false` लौटाता है अगर `true` दिया गया हो।
_नहीं_ ऑपरेटर इस्तेमाल करते समय एक बूलियन को ऑपरेटर (`!`) के बाद रखा जाना चाहिए।

```crystal
!true
# => false

!false
# => true
```

## गोल ब्रैकेट(`()`) का इस्तेमाल

बूलियन के साथ काम करते समय आप गोल ब्रैकेट का इस्तेमाल करके तय कर सकते हैं कि पहले किन बूलियन वैल्यू का मूल्यांकन होगा।
गोल ब्रैकेट कैसे इस्तेमाल किए जाते हैं, उसके हिसाब से नतीजा अलग हो सकता है।
Crystal में गोल ब्रैकेट के अंदर जो लिखा होता है, उसका मूल्यांकन पहले होता है।

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

चूँकि गोल ब्रैकेट के अंदर लिखी चीज़ का मूल्यांकन पहले होता है, नीचे के उदाहरण में _नहीं_ ऑपरेटर गोल ब्रैकेट के अंदर वाले एक्सप्रेशन पर लागू होगा।

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
गोल ब्रैकेट सिर्फ तभी इस्तेमाल कीजिए जब वे नतीजे को बदलते हों; वरना उन्हें छोड़ देना चाहिए।
~~~~

## ट्रूथी और फॉल्सी

Crystal में "फॉल्सी" वैल्यू ये हैं: `false`, `nil` और नल पॉइंटर; **बाकी सब कुछ** "ट्रूथी" होता है।
इन वैल्यू का इस्तेमाल ऊपर बताए गए लॉजिकल ऑपरेटरों के साथ किया जा सकता है।

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## बूलियन के साथ मेथड के नाम रखने का तरीका

Crystal में ऐसा मेथड, जो ट्रूथी या फॉल्सी वैल्यू लौटाता है, उसके नाम के अंत में प्रश्नचिह्न (`?`) लगाना आम बात है।
अधिकतर मामलों में यह मेथड बूलियन वैल्यू लौटाता है, लेकिन ज़रूरी नहीं कि हमेशा लौटाए।
इसका मतलब है कि इस मेथड का इस्तेमाल वहाँ किया जा सकता है जहाँ ट्रूथी या फॉल्सी वैल्यू की अपेक्षा होती है, जैसे कि `if` स्टेटमेंट की शर्त के रूप में:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

जिन मेथड के नाम के अंत में प्रश्नचिह्न होता है, पर जो बूलियन वैल्यू नहीं लौटाते, वे अक्सर इसके बजाय `nil` लौटाते हैं। `nil` _दूसरी भाषाओं के `None` या `null` जैसा होता है_।
