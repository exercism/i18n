# Debug

वर्तमान टेस्ट रनर [PonyTest](https://stdlib.ponylang.io/pony_test--index/) का उपयोग करता है, इसलिए Main एक्टर test.pony में रहता है और अपने हल के हिस्से के तौर पर उसे बदलना नहीं चाहिए।

Pony ऐप्लिकेशन में यह सबसे अच्छा तरीका माना जाता है: जब तक ज़रूरत न हो, हम `Env` तक पहुँच नहीं देते। इसका मतलब यह है कि लगभग सभी मामलों में आप `env.out.print()` से printf जैसी डिबगिंग नहीं कर सकते।

लेकिन Pony में [debug](https://stdlib.ponylang.io/debug--index/) मॉड्यूल मौजूद है, जिससे `-d` फ्लैग के साथ कंपाइल किए गए प्रोग्राम `Env` तक पहुँच के बिना भी STDOUT और STDERR का खास एक्सेस पा लेते हैं।

अगर आपको printf जैसी डिबगिंग की ज़रूरत पड़े, तो यही सुविधा इस्तेमाल कीजिए।

डिबगिंग का उदाहरण:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```


वही कोड, `-d` फ्लैग के साथ और उसके बिना कंपाइल करने पर:
