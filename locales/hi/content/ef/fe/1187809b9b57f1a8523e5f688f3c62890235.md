# परिचय

Swift में [`Bool`][bools] नाम का एक बिल्ट-इन टाइप होता है, जो सत्य मान दिखाने के लिए इस्तेमाल होता है: `true` और `false`।

## लॉजिकल ऑपरेटर

Swift में बूलियन एक्सप्रेशन को जोड़ने और उनका मूल्यांकन करने के लिए तीन [लॉजिकल ऑपरेटर][logical-operators] (`!`, `&&` और `||`) हैं।

### लॉजिकल AND (`&&`)

[_and_ ऑपरेटर][and] (`&&`) तभी `true` लौटाता है जब दोनों ऑपरेंड `true` हों।
अगर इनमें से कोई एक ऑपरेंड `false` है, तो यह `false` लौटाता है।
`&&` चिह्न के दोनों ओर एक एक्सप्रेशन या बूलियन वैल्यू रखिए:

```swift
true && true  // true
true && false // false
```

### लॉजिकल OR (`||`)

[_or_ ऑपरेटर][or] (`||`) `true` लौटाता है अगर **कम से कम एक** ऑपरेंड `true` है।
यह तभी `false` लौटाता है जब दोनों ऑपरेंड `false` हों।
`||` चिह्न के दोनों ओर एक एक्सप्रेशन या बूलियन वैल्यू रखिए:

```swift
true || true   // true
true || false  // true
false || false // false
```

### लॉजिकल NOT (`!`)

[_not_ ऑपरेटर][not] (`!`) एक बूलियन वैल्यू को उलट देता है।
अगर वैल्यू `false` है, तो यह `true` लौटाता है; और अगर वैल्यू `true` है, तो `false` लौटाता है।
`!` ऑपरेटर को वैल्यू या एक्सप्रेशन के ठीक पहले रखिए:

```swift
!true  // false
!false // true
```

## गोल ब्रैकेट (`()`) का इस्तेमाल

आप [गोल ब्रैकेट][explicit-parentheses] की मदद से एक्सप्रेशन को समूहों में बाँध सकते हैं और मूल्यांकन का क्रम तय कर सकते हैं।
Swift में पहले गोल ब्रैकेट के अंदर वाले एक्सप्रेशन का मूल्यांकन होता है:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

गोल ब्रैकेट से समूह बनाने से यह भी तय होता है कि NOT ऑपरेटर जटिल एक्सप्रेशन पर कैसे लागू होगा:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
जब आपको मूल्यांकन का क्रम साफ़ करना हो या जटिल शर्तों को पढ़ने में आसान बनाना हो, तब गोल ब्रैकेट का इस्तेमाल कीजिए।
जहाँ डिफ़ॉल्ट प्राथमिकता पहले से साफ़ है, वहाँ बेवजह गोल ब्रैकेट जोड़ने से बचिए।
~~~~
