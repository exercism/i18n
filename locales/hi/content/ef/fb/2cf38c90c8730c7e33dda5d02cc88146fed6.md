# परिचय

C# में एक्सेप्शन रनटाइम के दौरान होने वाली एरर स्थितियों को संभालने का संरचित, एकसमान और टाइप-सुरक्षित तरीका देते हैं। एप्लिकेशन क्रैश होने से रोकने की कोशिश में एक्सेप्शन और एरर को ठीक से संभालना ज़रूरी है।

C# में सभी एक्सेप्शन का आधार टाइप `System.Exception` क्लास है। इसमें `Message` जैसी ज़रूरी प्रॉपर्टी होती हैं, जिसमें एक्सेप्शन फेंके जाने के कारण का मानव-पठनीय विवरण होता है।

कोड के किसी खास हिस्से में एरर होनी चाहिए, यह संकेत देने के लिए एक नया एक्सेप्शन ऑब्जेक्ट बनाना और फिर `throw` कीवर्ड से उसे फेंकना ज़रूरी है:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

जब कोई एक्सेप्शन फेंका जाता है, तो रनटाइम का काम कोड का एक ऐसा हिस्सा खोजना होता है जो उस एक्सेप्शन को संभालने के लिए ज़िम्मेदार हो। अगर उपयुक्त हैंडलर नहीं मिलता, तो रनटाइम प्रोग्राम का चलना रोकने के साथ-साथ बिना संभाले गए एक्सेप्शन का संदेश भी दिखाता है।

किसी एक्सेप्शन के लिए हैंडलर बनाने के लिए C# try-catch स्टेटमेंट का इस्तेमाल करता है, जिसमें एक `try` ब्लॉक और एक या अधिक `catch` क्लॉज़ होते हैं। `try` ब्लॉक में ऐसा कोड होना चाहिए जिससे एक्सेप्शन फेंका जा सकता है, और उसकी निगरानी होनी चाहिए। `catch` क्लॉज़ में वह कोड होना चाहिए जो एरर होने के बाद प्रोग्राम का व्यवहार संभालता है। यह ध्यान देना ज़रूरी है कि `try` ब्लॉक के बाद एक्सेप्शन का क्रम मायने रखता है, क्योंकि जब कई एक्सेप्शन सूचीबद्ध होते हैं, तो पहला मेल खाने वाला `catch` क्लॉज़ चलाया जाता है।

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
