# निर्देश परिशिष्ट

## ट्रैक के खास निर्देश

पहले Elm फंक्शनल रिएक्टिव प्रोग्रामिंग का उपयोग करता था, लेकिन बाद में इसने खास तौर पर Elm Architecture का ही उपयोग करना शुरू किया।

इस अभ्यास को ऐसे हल कीजिए जैसे आप Elm Architecture का उपयोग करके कोई वेब ऐप लिख रहे हों।
प्रोग्राम का आउटपुट HTML होना चाहिए, जिसकी संरचना इस प्रकार होगी

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

यहाँ `<dl>` डिस्क्रिप्शन लिस्ट एलिमेंट है, `<dt>` डिस्क्रिप्शन टर्म एलिमेंट और `<dd>` डिस्क्रिप्शन डिटेल्स एलिमेंट है। ये सभी मानक HTML एलिमेंट हैं।

अगर कोई एरर हो, तो आउटपुट की संरचना इस प्रकार होनी चाहिए

```html
<div>
  <p>error message</p>
</div>
```
