# परिचय

## तुलना

C++ में आप तुलना ऑपरेटरों की मदद से वैल्यू की तुलना कर सकते हैं।

| तुलना             | ऑपरेटर   |
| ------------------| --------- |
| बराबर             | `==`      |
| बराबर नहीं         | `!=`      |
| कम               | `<`       |
| कम या बराबर        | `<=`      |
| अधिक              | `>`       |
| अधिक या बराबर      | `>=`      |

इन तुलनाओं का परिणाम हमेशा एक बूलियन वैल्यू होता है:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

ऑपरेटर `==` और `!=` क्रमशः जाँचते हैं कि कोई वैल्यू दूसरी वैल्यू के बराबर है या नहीं। यहाँ कुछ आम उदाहरण दिए गए हैं:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

बाकी ऑपरेटर जाँचते हैं कि कोई वैल्यू दूसरी वैल्यू से अधिक (`>`) है, अधिक या बराबर (`>=`) है, कम (`<`) है, या कम या बराबर (`<=`) है।
इस तरह की तुलना संख्याओं और स्ट्रिंग, दोनों के लिए उपलब्ध है।
स्ट्रिंग की तुलना करते समय डिक्शनरी क्रम (जिसे लेक्सिकोग्राफिक क्रम भी कहते हैं) का पालन किया जाता है।

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## `if` स्टेटमेंट

C++ में शर्तें दूसरी भाषाओं की शर्तों जैसी ही होती हैं।
किसी भी शर्त वाले ऑपरेशन का मूल टाइप `bool` होता है, जिसकी वैल्यू `true` या `false` हो सकती है।
शर्तों का उपयोग अक्सर कोड के प्रवाह को नियंत्रित करने और अलग-अलग शर्तें जाँचने के लिए किया जाता है।

`if` स्टेटमेंट का उपयोग किया जा सकता है, जो अपना कोड तब चलाता है जब उसकी शर्त `true` हो, ऐसे:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

जिन मामलों में एक से अधिक स्थितियाँ होती हैं, वहाँ `else if` और `else` स्टेटमेंट की मदद से कई `if` स्टेटमेंट एक साथ जोड़े जा सकते हैं।

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17 से `if` स्टेटमेंट में एक छोटा इनिशलाइज़ेशन स्टेटमेंट भी शामिल किया जा सकता है, जिसका उपयोग `if` स्टेटमेंट के लिए एक या अधिक वेरिएबल शुरू करने में किया जा सकता है।
उदाहरण:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> ध्यान दें: इनिशलाइज़ेशन में बनाए गए किसी भी वेरिएबल का उपयोग `if` स्टेटमेंट खत्म होने के बाद नहीं किया जा सकता।
