## जोड़े

एक `Pair` एक ऐसा डेटा स्ट्रक्चर है जिसमें ठीक दो एलिमेंट होते हैं, जिन्हें `first` और `second` फील्ड के ज़रिए पढ़ा जा सकता है।

इन्हें `x => y` की मदद से बनाया जा सकता है:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

एक `Pair` के एलिमेंट अलग-अलग टाइप के हो सकते हैं:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Julia में `Pair` के दो आम उपयोग हैं: डिक्शनरी और रिप्लेसमेंट।

### रिप्लेसमेंट

बहुत-से रिप्लेसमेंट मेथड आर्गुमेंट के तौर पर एक `Pair` लेते हैं, ताकि साफ पता चले कि कौन-सा एलिमेंट बदला जा रहा है।
इससे ऐसा सिंटैक्स लिखा जा सकता है:

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

यहाँ संग्रह के हर `4` की जगह `0` आ जाता है, जबकि कम साफ सिंटैक्स यह होता है:

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
