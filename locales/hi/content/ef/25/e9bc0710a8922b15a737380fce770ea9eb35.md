# परिचय

`|>` ऑपरेटर को पाइप ऑपरेटर कहते हैं। इसकी मदद से फंक्शन कॉल को एक के बाद एक इस तरह जोड़ा जाता है कि पिछले फंक्शन कॉल से लौटी वैल्यू अगले फंक्शन कॉल को मिल जाती है।

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

ऊपर दिया गया कोड नीचे दिए गए कोड के बराबर है:

```gleam
string.append(string.uppercase("hello"), "?!")
```

पाइप ऑपरेटर वैल्यू को या तो फंक्शन कॉल के पहले आर्गुमेंट के रूप में भेजता है, या फिर नई कॉल के एकमात्र आर्गुमेंट के रूप में। इनमें से वह चुनता है जिससे टाइप सही रहे।

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

कभी-कभी हमें वैल्यू को किसी और जगह भेजनी होती है। ऐसे में `_` प्लेसहोल्डर से बता सकते हैं कि वैल्यू कहाँ डालनी है।

```gleam
100
|> some_function(1, _, 2)
```
