# इसके बारे में

Common Lisp में हर चीज़ एक एक्सप्रेशन है।
एक एक्सप्रेशन या तो कोई एक चीज़ होता है (जिसे एटम कहते हैं) या कई चीज़ों का ऐरे (जिसे ब्रैकेटों के बीच रखा जाता है: `()`).

## कोट करना

सभी एस-एक्सप्रेशन, जैसे सिंबल, कोट किए जा सकते हैं:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

कोट करना एस-एक्सप्रेशन के मूल्यांकन को रोक देता है और उसके साथ डेटा जैसा व्यवहार करता है।
कोट करने के बारे में थोड़ा और विस्तार से जानने के लिए यह बेहतरीन [Stack Overflow जवाब][so-quoting] देखिए।

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
