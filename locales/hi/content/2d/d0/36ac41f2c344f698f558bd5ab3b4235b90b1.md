# निर्देश

आप एक पक्षी सर्वेक्षण में मदद कर रहे हैं। हर दिन कोई व्यक्ति एक हाइड में बैठता है और जो उड़कर गुज़रता है उसकी गिनती करता है। उस दिन की गिनतियाँ एक ऐरे के रूप में वापस आती हैं।

पाँचों कार्य `BIRD_SURVEY` क्लास में होते हैं।

## 1. कुल योग

हर दिन की गिनती जोड़ दीजिए।

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

जिस सर्वेक्षण में एक भी दिन नहीं है, वह शून्य पक्षियों की गिनती करता है।

## 2. सबसे अच्छा दिन

सबसे बड़ी गिनती लौटाइए। अगर एक भी दिन न हो, तो उत्तर शून्य है।

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. व्यस्त दिन

कितने दिनों की गिनती किसी संख्या से अधिक थी?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

अधिक का मतलब अधिक ही है: ठीक 2 की गिनती गिनती में नहीं आती।

## 4. जाँचने के लिए हाइड

सर्वेक्षण के पहले दिन आप एक हाइड की जाँच करते हैं, दूसरे दिन दो हाइड की, और इसी तरह आगे भी। कुल मिलाकर कितनी हाइड की जाँचें होती हैं?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

यह 1 + 2 + 3 + 4 है।

## 5. पहला व्यस्त दिन

किसी संख्या से अधिक गिनती वाला पहला दिन कौन-सा था? दिनों की गिनती शून्य से शुरू होती है, ठीक वैसे ही जैसे ऐरे के इंडेक्स होते हैं। अगर कोई दिन उतना व्यस्त नहीं था, तो उत्तर `-1` है।

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
