# कोई नेम्ड एक्सपोर्ट नहीं

[`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) नहीं मिला। इस एक्सपोर्ट के बिना टेस्ट पास नहीं होंगे।

सुनिश्चित कीजिए कि `%{export.name}` मौजूद है और उसके आगे `export` जोड़िए:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
