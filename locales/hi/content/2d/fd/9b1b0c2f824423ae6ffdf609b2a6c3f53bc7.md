# निर्देश

आप एक ऐसे गेम पर काम कर रहे हैं जो कम बिजली खपत वाले एम्बेडेड सिस्टम के लिए बनाया जा रहा है। आपको कई सुविधाजनक फंक्शन लिखने हैं, जिनका उपयोग गेम के बाकी हिस्से करेंगे।

## 1. किसी भाग का भागफल और शेषफल निकालिए

भाग देने पर जो आउटपुट मिलता है, उसे भागफल कहते हैं।

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

उदाहरण:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. एक इटरेटर से सम स्थानों वाले एलिमेंट चुनिए

आपके बॉस का वादा है कि यह स्क्रीन-बफर ऑप्टिमाइज़ेशन को संभव बनाने में मदद करेगा।

इटरेटर ऐसी चीज़ें हैं जिनके पास [`Iterator` ट्रेट](https://doc.rust-lang.org/std/iter/trait.Iterator.html) में परिभाषित मेथड होते हैं। वह डॉक्युमेंटेशन काफी विस्तृत है, क्योंकि इनमें बहुत सारे मेथड होते हैं; यहाँ सबसे काम की बातें दी गई हैं:

- एक इटरेटर किसी भी लंबाई वाली आइटम की स्ट्रीम होता है
- इनमें एक [`enumerate` मेथड](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) होता है, जो हर वैल्यू के लिए एक टपल `(i, val)` लौटाता है
- इनमें एक [`filter` मेथड](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) होता है, जो क्लोज़र की मदद से तय करता है कि इटरेटर का कोई एलिमेंट देना है या नहीं
- इनमें एक [`map` मेथड](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) होता है, जो क्लोज़र की मदद से इटरेटर के एलिमेंट बदलता है

चूँकि आपका फंक्शन किसी भी तरह के इटरेटर पर चल सकता है, इसलिए यह `impl` का उपयोग करके बताता है कि यह किसी साधारण आइटम के बजाय एक ट्रेट इंस्टेंस है। इसी तरह, `<Item=T>` सिंटैक्स का मतलब बस इतना है कि इससे कोई फर्क नहीं पड़ता कि इटरेटर किस तरह का आइटम बनाता है; आपका फंक्शन किसी भी इटरेटर के सम एलिमेंट बना सकता है।

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

उदाहरण:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. मूल बिंदु से किसी स्थान की मैनहट्टन दूरी निकालिए

मैपिंग की सुविधा के लिए आपके पास `Position` नाम का एक टपल स्ट्रक्चर है:

```rust
struct Position(i16, i16);
```

आपको `Position` पर एक `manhattan` मेथड बनाना है, जो उस स्थान की मूल बिंदु (`Position(0, 0)`) से [मैनहट्टन दूरी](https://en.wikipedia.org/wiki/Taxicab_geometry) लौटाता है।

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

उदाहरण:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
