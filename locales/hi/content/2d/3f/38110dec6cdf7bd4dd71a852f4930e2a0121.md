# परिचय

Swift में कंट्रोल ट्रांसफर स्टेटमेंट उपलब्ध हैं, जिनसे लूप और switch स्टेटमेंट के चलने का क्रम बदला जा सकता है। `return` के अलावा Swift में `continue`, `break`, लूप लेबल और `fallthrough` भी शामिल हैं।

## Continue

`continue` स्टेटमेंट लूप को कहता है कि वह मौजूदा इटरेशन को चलाना बंद कर दे और तुरंत अगला इटरेशन शुरू करे। `while` या `repeat-while` लूप में यह सीधे शर्त की जाँच पर पहुँच जाता है। `for-in` लूप में यह सीक्वेंस के अगले एलिमेंट पर आगे बढ़ जाता है।

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break` स्टेटमेंट पूरे लूप या switch स्टेटमेंट से तुरंत बाहर निकल जाता है। इसके बाद कोड लूप या switch के बाद वाली पहली लाइन से फिर चलना शुरू करता है।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## लेबल वाले स्टेटमेंट

नेस्टेड लूप में कभी-कभी आप चाहते हैं कि `break` या `continue` सबसे अंदर वाले लूप के बजाय किसी बाहरी लूप पर असर डाले। आप किसी लूप के शुरू होने से पहले उसका नाम और कोलन (`labelName:`) लगाकर उसे लेबल कर सकते हैं। फिर आप वही लेबल `break` या `continue` को दे सकते हैं:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

Swift में `switch` स्टेटमेंट डिफ़ॉल्ट रूप से अगले case में नहीं जाते; मैच हो चुके case के अंत में चलना अपने आप रुक जाता है। अगर आप साफ़ तौर पर चाहते हैं कि कोड अगले case में उसके पैटर्न की जाँच किए बिना ही आगे चले, तो `fallthrough` कीवर्ड का उपयोग कीजिए:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
