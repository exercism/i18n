# निर्देश

आप एक तटीय गश्ती नाव पर सिग्नलर हैं। सुबह का पहरा शुरू होने से पहले आज की थैली के लिए पाँच छोटे शब्द तैयार करने हैं।

## 1. किसी वैल्यू को उद्धृत कीजिए

लॉग बुक हर अवलोकन को *Factor सोर्स फॉर्म* में लिखती है, यानी उसी टेक्स्ट में जिसे पार्सर वापस पढ़ेगा। `quote-value` बनाइए, जो किसी भी वैल्यू को उसके सोर्स-फॉर्म स्ट्रिंग में बदल देता है।

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. झंडे का फ्रेम हटाइए

अंदर आने वाले हर सिग्नल झंडे के दोनों सिरों पर एक मार्कर अक्षर होता है। `flag-body` बनाइए, जो दोनों मार्करों के *बीच* की सारी चीज़ लौटाता है, यानी पहला अक्षर और अंतिम अक्षर हटा देता है।

कॉपी करने के बजाय स्लाइस (व्यू) लौटाइए।

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. झंडे को बाँटिए

हर झंडे में एक छोटा प्रीफिक्स कोड होता है, जिसके बाद पेलोड आता है। `split-flag` बनाइए। यह एक झंडा और हेडर की लंबाई लेता है, और हेडर तथा बॉडी *दोनों* के स्लाइस लौटाता है।

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. दो रीडिंग से ट्रायंगुलेट कीजिए

लगातार दो सिग्नल रीडिंग से तीन माप निकलते हैं: उनका *अंतर* `a - b`, उनका *मध्यबिंदु* `(a + b) / 2`, और उनका *अनुपात* `a / b`। हर माप दोनों रीडिंग का उपयोग करता है।

`triangulate` बनाइए, जो रीडिंग की एक जोड़ी से तीनों माप लौटाता है।

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. तीन रीडिंग का सारांश बनाइए

लगातार तीन रीडिंग का सारांश उनके **जोड़**, **गुणनफल** और **अधिकतम** के रूप में निकलता है। हर आँकड़ा तीनों रीडिंग का उपयोग करता है।

`triangle-stats` बनाइए, जो तीनों आँकड़े लौटाता है।

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
