# निर्देश परिशिष्ट

## कार्यान्वयन

आप भाषा की मूल सुविधाओं का उपयोग करके डिस्ट्रक्चरिंग के ज़रिए ऐरे बना और तोड़ सकते हैं, और ऐरे लिटरल `[]` का उपयोग भी कर सकते हैं। लेकिन `Array.prototype` के किसी भी फंक्शन का उपयोग नहीं करना चाहिए।

अपने हल की जाँच हो सके, इसके लिए यह सुनिश्चित कीजिए कि `forEach` लागू किया गया हो।

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
