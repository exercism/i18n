# परिचय

रिकर्शन एक ऐसा तरीका है जिससे कोई फंक्शन खुद को कॉल करके कोड दोहरा सकता है। इसे लूप करने या इटरेशन करने का एक और तरीका भी माना जा सकता है। लूप की तरह ही, यह तय करने के लिए कि रिकर्शन कब रोकना है, एक बूलियन एक्सप्रेशन या `True`/`False` की जाँच इस्तेमाल की जाती है। लूप के _विपरीत_, Python में बिना रुके चलता रहने वाला रिकर्शन अनंत तक नहीं चल सकता। फंक्शन को कॉल करने पर जो वैल्यू इस्तेमाल होती हैं, वे Python के [इंटरप्रेटर स्टैक][what-is-the-call-stack] पर अपने अलग [फ्रेम][stack-frame] में रखी जाती हैं। अगर फंक्शन कॉल की कुल संख्या स्टैक में जगह से ज़्यादा हो जाए, तो इससे एक एरर मिलती है।

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

इससे यह प्रिंट होगा

```
The step is 1
The step is 2
After recursion
```

कुछ ऐसी स्थितियाँ भी हो सकती हैं, जिन्हें लूप से लिखने की तुलना में रिकर्शन से लिखने पर पढ़ना और समझना ज़्यादा आसान होता है।
