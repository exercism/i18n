# विवरण

मेथड में एक वरआर्ग्स पैरामीटर हो सकता है, जो कॉल करने वाले को शून्य या अधिक आर्गुमेंट देने की अनुमति देता है, जैसे वे सामान्य पैरामीटर हों। यह मेथड इन आर्गुमेंट को एक ही ऐरे में प्राप्त करता है।

किसी पैरामीटर को वरआर्ग्स पैरामीटर बनाने के लिए, पैरामीटर की घोषणा में [`params` कीवर्ड](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) जोड़िए:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
