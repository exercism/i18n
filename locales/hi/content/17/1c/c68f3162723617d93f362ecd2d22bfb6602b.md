# परिचय

## संख्याएँ

Swift में संख्याओं की दो मुख्य श्रेणियाँ होती हैं: पूर्णांक और दशमलव संख्याएँ।

- [पूर्णांक][integers] उन पूर्ण संख्याओं को दर्शाते हैं जिनमें कोई भिन्नात्मक भाग नहीं होता, जैसे `0`, `1`, `-1`, `42` और `-273`.
- [दशमलव संख्याएँ][floatingpoint] उन संख्याओं को दर्शाती हैं जिनमें भिन्नात्मक भाग होता है, जैसे `0.0`, `3.14` और `-1.36969e-10`.

पढ़ने में आसानी के लिए आप संख्यात्मक लिटरल के बीच अंडरस्कोर डाल सकते हैं: `1_000_000` और `1000000` एक जैसे ही होते हैं।
दशमलव संख्याओं के लिटरल दशमलव या घातांक रूप में लिखे जा सकते हैं।

अधिकतर मामलों में पूर्णांकों के लिए [`Int`][int] और दशमलव संख्याओं के लिए [`Double`][double] इस्तेमाल किया जाता है:

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## अंकगणितीय ऑपरेटर

Swift गणनाओं के लिए मानक [अंकगणितीय ऑपरेटर][arithmetic-operators] देता है:

| Operator | Description    | Example |
| -------- | -------------- | ------- |
| `+`      | जोड़       | `4 + 6` का मान `10` होता है |
| `-`      | घटाव    | `15 - 10` का मान `5` होता है |
| `*`      | गुणा | `2 * 3` का मान `6` होता है  |

~~~~exercism/caution
Swift टाइप की दृष्टि से सुरक्षित है और अंकगणितीय क्रियाओं में अलग-अलग संख्या टाइपों को मिलाने की अनुमति नहीं देता।
आप किसी `Int` और `Double` को सीधे जोड़ या गुणा नहीं कर सकते; पहले आपको एक टाइप को दूसरे से मिलाने के लिए बदलना होगा।
~~~~

### भाग

`/` ऑपरेटर भाग करता है।
जब दोनों ऑपरेंड पूर्णांक हों, तो पूर्णांक भाग किसी भी भिन्नात्मक शेष को हटा देता है:

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

किसी गैर-शून्य दशमलव संख्या को शून्य से भाग देने पर `inf` या `-inf` मिलता है।
`0.0` को `0.0` से भाग देने पर `nan` (संख्या नहीं) मिलता है।
इसके विपरीत, किसी पूर्णांक को शून्य से भाग देने पर कंपाइल-टाइम या रनटाइम एरर होती है:

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### शेषफल ऑपरेटर

[शेषफल ऑपरेटर][remainder-operator] (`%`) दो पूर्णांकों को भाग देने के बाद बचे शेषफल की गणना करता है:

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
Swift में `%` मॉड्यूलो ऑपरेटर नहीं, बल्कि असली *शेषफल* ऑपरेटर है।
परिणाम हमेशा पहले ऑपरेंड (भाज्य) का चिह्न लेता है, चाहे दूसरे ऑपरेंड का चिह्न कुछ भी हो:

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## दशमलव संख्याओं को पूर्णांकित करना

आप किसी दशमलव संख्या को `rounded()` मेथड से पूर्णांकित कर सकते हैं।
डिफ़ॉल्ट रूप से `rounded()` निकटतम पूर्णांक तक पूर्णांकित करता है।
आप [पूर्णांकन नियम][rounding-rule] भी दे सकते हैं, जैसे `.up` या `.down`:

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## टाइप का अनुमान

जब आप किसी संख्यात्मक कॉन्स्टेंट या वेरिएबल को टाइप एनोटेशन के बिना घोषित करते हैं, तो Swift उसका टाइप अनुमान लगा लेता है:

- पूर्ण संख्याओं का टाइप डिफ़ॉल्ट रूप से `Int` होता है।
- दशमलव बिंदु वाली संख्याओं का टाइप डिफ़ॉल्ट रूप से `Double` होता है।

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## टाइप बदलना

अलग-अलग टाइप की वैल्यू के बीच गणना करने के लिए, किसी एक वैल्यू को `Double(_:)` या `Int(_:)` जैसे टाइप इनिशियलाइज़र से बदल लीजिए:

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
