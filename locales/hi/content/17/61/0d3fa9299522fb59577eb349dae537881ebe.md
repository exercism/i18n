# SQLite के लिए विशेष निर्देश

**list_one** और **list_two** कॉलमों में पूर्णांकों की JSON एनकोडेड सूची होती है।

उदाहरण:

```json
[1, 2, 3]
```

## टेबल स्कीमा

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
