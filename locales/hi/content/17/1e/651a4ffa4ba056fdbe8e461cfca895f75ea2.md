# परिचय

C++ में `string` एक ऐसा ऑब्जेक्ट है जिसे बदला जा सकता है और जो टेक्स्ट को अक्षरों, अंकों, विराम चिह्नों आदि के क्रम के रूप में दर्शाता है।
स्ट्रिंग पर काम करने के लिए उसके मेथड कॉल किए जाते हैं।

## स्ट्रिंग लाइब्रेरी

C++ में स्ट्रिंग टाइप और उससे जुड़े फंक्शन इस्तेमाल करने से पहले स्ट्रिंग लाइब्रेरी से शामिल करने पड़ते हैं।
इसके लिए आप अपनी फाइल के सबसे ऊपर `#include <string>` जोड़ सकते हैं।
इसके बाद ये `std` नेमस्पेस में आ जाते हैं।
स्ट्रिंग टाइप का पूरा योग्य नाम `std::string` होता है।
स्ट्रिंग लिटरल में डबल कोट (`"`) चिह्न का इस्तेमाल होता है।

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## स्ट्रिंग के आम ऑपरेशन

आप स्ट्रिंग जोड़ने के लिए `+` ऑपरेटर इस्तेमाल कर सकते हैं:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

स्ट्रिंग लाइब्रेरी इस्तेमाल करने के लिए आपको यह जानना ज़रूरी है कि किसी ऑब्जेक्ट से जुड़े फंक्शन को कॉल करना संभव होता है।
इन्हें मेंबर फंक्शन कहते हैं।
सिलेबस में आगे आप मेंबर फंक्शन और उनसे जुड़े क्लास कॉन्सेप्ट के बारे में और जानेंगे।

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


`find` फंक्शन भी बहुत काम का है।
इसे स्ट्रिंग पर मेंबर फंक्शन की तरह कॉल किया जाता है और यह आर्गुमेंट के रूप में एक स्ट्रिंग लेता है।
`find` उस जगह का इंडेक्स लौटाता है जहाँ यह स्ट्रिंग में _पहली_ बार मिलती है, और यह इंडेक्स शून्य से शुरू होता है।

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

एक और फंक्शन भी है, `std::to_string`, जिसका उपयोग पूर्णांकों और float/double वैल्यू को स्ट्रिंग में बदलने के लिए किया जा सकता है।

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
