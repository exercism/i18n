# निर्देश

आप एक हेल्थ-मॉनिटरिंग सिस्टम बना रहे हैं। इसी काम के लिए आपको उपयोगकर्ताओं के स्वास्थ्य के आँकड़ों का हिसाब रखना है।

आपकी शुरुआत एक `impl` ब्लॉक में दिए गए कुछ अधूरे फंक्शनों से होगी। इसके अलावा नीचे दी गई स्ट्रक्चर परिभाषा भी है:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

आपको `impl` ब्लॉक में परिभाषित `User` `struct` के अधूरे मेथड लागू करने हैं।

उदाहरण के लिए, `new` मेथड को दिए गए नाम, उम्र और वज़न की वैल्यू के साथ `User` स्ट्रक्चर का एक इंस्टेंस लौटाना चाहिए।

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

`weight` मेथड को `User` का वज़न लौटाना चाहिए।

```rust
bob.weight();
// Returns: 155.2
```

`set_age` मेथड को `User` की उम्र तय करनी चाहिए।

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
