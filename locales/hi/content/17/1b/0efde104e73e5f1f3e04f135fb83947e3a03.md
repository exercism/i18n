# परिचय

इंटरफेस एक ऐसा टाइप है जिसमें ऐसे मेंबर होते हैं जो आपस में जुड़ी हुई कार्यक्षमता के एक समूह को परिभाषित करते हैं।
यह किसी क्लास के इस्तेमाल को उसके इंप्लीमेंटेशन से अलग कर देता है। इससे एक ही चीज़ के कई अलग-अलग इंप्लीमेंटेशन बन पाते हैं, या फॉर्मैटिंग, तुलना या कन्वर्ज़न जैसे किसी जेनेरिक व्यवहार का इस्तेमाल किया जा सकता है।

इंटरफेस का सिंटैक्स क्लास जैसा ही होता है, बस इसमें मेथड सिर्फ सिग्नेचर के रूप में होते हैं और उनकी कोई बॉडी नहीं दी जाती।

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

इंटरफेस में परिभाषित हर ऑपरेशन उस क्लास को इंप्लीमेंट करना ही पड़ता है जो इस इंटरफेस को इंप्लीमेंट करती है।

इंटरफेस में आमतौर पर इंस्टेंस मेथड होते हैं।

ऊपर दिखाए गए `Cloneable` के अलावा Java क्लास लाइब्रेरी में एक और इंटरफेस मिलता है, `Comparable<T>`.

जहाँ कलेक्शन में जेनेरिक सॉर्ट का डिफॉल्ट क्रम चाहिए होता है, वहाँ `Comparable<T>` इंटरफेस को इंप्लीमेंट किया जा सकता है।
