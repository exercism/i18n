# परिचय

Java में रैंडम संख्याएँ बनाने के लिए आप `java.util.Random` क्लास के एक इंस्टेंस का उपयोग कर सकते हैं।

## रैंडम पूर्णांक

`nextInt()` मेथड से एक रैंडम पूर्णांक बनाया जा सकता है।
यह `Integer.MIN_VALUE` से `Integer.MAX_VALUE` तक की रेंज में एक वैल्यू बनाता है।

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

बनाई गई वैल्यू की रेंज सीमित करने के लिए `nextInt(int)` का उपयोग कीजिए।
यह `0` से लेकर दी गई ऊपरी सीमा तक एक वैल्यू बनाता है। इसमें `0` शामिल होता है, लेकिन ऊपरी सीमा नहीं।

उदाहरण के लिए, यह `0` से `9` तक की एक रैंडम संख्या बनाता है।

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

और यह `10` से `19` तक की एक रैंडम संख्या बनाता है।

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## रैंडम दशमलव संख्याएँ

`nextDouble()` मेथड से एक रैंडम दशमलव संख्या बनाई जा सकती है।
यह `0.0` से `1.0` तक की रेंज में एक वैल्यू बनाता है।

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

और यह `100.0` से `200.0` तक की एक रैंडम संख्या बनाता है।

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
