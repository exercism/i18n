# परिचय

रिकर्सिव फंक्शन ऐसे फंक्शन होते हैं जो खुद को कॉल करते हैं।

एक रिकर्सिव फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना चाहिए।

_बेस केस_ बिना फंक्शन को दोबारा कॉल किए एक वैल्यू लौटाता है।
_रिकर्सिव केस_ फंक्शन को दोबारा कॉल करता है। साथ ही यह इनपुट को इस तरह बदलता है कि वह किसी समय बेस केस से मेल खाने लगे।

Elm में रिकर्सिव फंक्शन आमतौर पर `case` एक्सप्रेशन या कई फंक्शन क्लॉज़ के साथ पैटर्न मैचिंग का उपयोग करके बनाए जाते हैं।

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## रिकर्सन के ज़रिए लूप

इम्यूटेबिलिटी के कारण, Elm में लूप इम्परेटिव भाषाओं से अलग तरीके से लिखे जाते हैं।
उदाहरण के लिए, लूप आमतौर पर इस तरह के होते हैं:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Elm जैसी फंक्शनल भाषा में वेरिएबल को बदलना संभव नहीं है।
इसलिए, लूप को रिकर्सन से लागू करना पड़ता है।

Elm में `for` लूप के बराबर कुछ इस तरह होगा:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

व्यवहार में, Elm में ऐरे और अन्य डेटा स्ट्रक्चर पर इटरेशन करना अक्सर `List` मॉड्यूल के फंक्शनों का उपयोग करके किया जाता है, जैसे `List.map`, `List.filter`, और `List.foldl`।
अंदर ही अंदर, ये फंक्शन रिकर्सन का उपयोग करके लागू किए गए हैं।
