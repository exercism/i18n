# केस

[केस][case] (अक्सर दूसरी भाषाओं में इसे switch कहा जाता है), if-else की तरह कंट्रोल एक्सप्रेशन का ही एक रूप है।
केस की मदद से कई if-else-if स्टेटमेंट एक साथ जोड़े जा सकते हैं। ऐसा कोड पढ़ने में ज़्यादा साफ़ लगता है, और फ्लो कंट्रोल भी बना रहता है।

केस `case` कीवर्ड से बनता है, जिसके बाद एक वैकल्पिक एक्सप्रेशन लिखा जाता है।
फिर हर केस के लिए `when` कीवर्ड लिखा जाता है, और उसके बाद वह एक्सप्रेशन आता है जिसकी तुलना केस एक्सप्रेशन से की जाती है।
`when` कीवर्ड को `case` कीवर्ड से अधिक इंडेंट नहीं करना चाहिए।
`when` कीवर्ड के बाद वह कोड लिखा जाता है जो तब चलाया जाता है जब केस एक्सप्रेशन और when एक्सप्रेशन मेल खाते हैं।
केस में एक वैकल्पिक `else` स्टेटमेंट भी लिखा जा सकता है, जो तब चलता है जब कोई और केस मेल नहीं खाता।

केस एक्सप्रेशन का मूल्यांकन किया जाता है, और फिर उसकी तुलना हर `when` एक्सप्रेशन से की जाती है।
तुलना के लिए केस समानता ऑपरेटर (`===`) का उपयोग किया जाता है।

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## केस समानता ऑपरेटर (`===`)

केस समानता ऑपरेटर (`===`) समानता ऑपरेटर (`==`) से थोड़ा अलग है।
यह ऑपरेटर जाँचता है कि दाईं ओर की वैल्यू, बाईं ओर बताए गए समूह का सदस्य है या नहीं।
इसका मतलब है कि यह मायने रखता है कि हर ऑपरेंड किस तरफ़ रखा गया है।
यह कैसे काम करता है, यह बाईं ओर के टाइप पर निर्भर करता है। जैसे `Range` यह जाँचता है कि दाईं ओर की वैल्यू रेंज के अंदर है या नहीं, और `Object` यह जाँचता है कि दाईं ओर की वैल्यू `Object` का इंस्टेंस है या नहीं।

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## एक से ज़्यादा एक्सप्रेशन वाले केस

केस में एक ही जगह कई एक्सप्रेशन मैच किए जा सकते हैं, जहाँ हर संभव वैल्यू को कॉमा से अलग किया जाता है।
अगर इनमें से कोई भी एक्सप्रेशन मैच हो जाए, तो कोड चल जाता है।
यह तब काम आता है जब आप चाहते हैं कि एक ही केस के लिए कई संभव वैल्यू हों।

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## रेंज वाले केस

केस यह भी जाँच सकता है कि कोई वैल्यू किसी रेंज के अंदर है या नहीं।
इसके लिए when एक्सप्रेशन के रूप में एक रेंज का उपयोग किया जाता है।

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## जब कोई केस एक्सप्रेशन न हो

जब केस एक्सप्रेशन की ज़रूरत न हो, तो उसे छोड़ा जा सकता है।
ऐसा करने पर हर when एक्सप्रेशन की जाँच केवल इस आधार पर की जाती है कि वह सही है या नहीं।
इससे ये if-else-if स्टेटमेंट की तरह व्यवहार करते हैं।

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## एक ही लाइन में when

Ruby में एक ही लाइन वाले केस स्टेटमेंट लिखे जा सकते हैं।
इसका उपयोग तब किया जा सकता है जब आपके पास कोई सरल, एक लाइन वाला स्टेटमेंट हो।
एक लाइन वाला when स्टेटमेंट इस तरह लिखा जाता है: `when <expression> then <statement>`।
और जब इसे else स्टेटमेंट में इस्तेमाल किया जाता है, तो यह `else <statement>` लिखा जाता है।

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## टाइप के साथ केस

केस की मदद से टाइप के आधार पर भी मैच किया जा सकता है।
यह तब काम आता है जब वेरिएबल के टाइप के हिसाब से अलग-अलग व्यवहार चाहिए हो।

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
