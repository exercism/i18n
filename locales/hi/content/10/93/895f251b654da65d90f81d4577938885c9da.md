# निर्देश

एलेन एक ऐसा गेम बना रही है जिसमें खिलाड़ी को एलियन से लड़ना है।
उसने अभी-अभी ऑब्जेक्ट ओरिएंटेड प्रोग्रामिंग (OOP) सीखी है और वह उत्सुक है कि `classes` के इस्तेमाल से उसके प्रोग्राम को क्या-क्या फायदा हो सकता है।

एलेन को बहुत खुशी हुई कि आपने मदद करने की पेशकश की, और उसने आपको वे एलियन प्रोग्राम करने का काम सौंपा है जिनसे खिलाड़ी को लड़ना है।

## 1. Alien क्लास बनाइए

Alien क्लास को एक ऐसे कंस्ट्रक्टर के साथ बनाइए जो दो पैरामीटर लेता है, `<x_coordinate>` और `<y_coordinate>`, और उन्हें `x_coordinate` तथा `y_coordinate` इंस्टेंस वेरिएबलो में रखता है।
हर एलियन का हेल्थ लेवल भी शुरू में 3 होगा, इसलिए `health` वेरिएबल को भी इनिशियलाइज़ करना होगा।

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

अब हर एलियन अपनी जगह और अपनी हेल्थ खुद ट्रैक कर सकेगा।

## 2. `hit` मेथड

एलेन चाहती है कि Alien `class` में एक `hit` मेथड हो, जो कॉल किए जाने पर एलियन ऑब्जेक्ट की हेल्थ 1 कम कर दे।
इस तरह वह एलियन की हेल्थ हाथ से बदलने के बजाय सीधे `<alien>.hit()` कॉल कर सकती है।
यह आप पर है कि `hit()` हेल्थ पॉइंट्स को शून्य _तक_ पहुँचाता है या शून्य से _नीचे_ भी ले जाता है।

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. `is_alive` मेथड

आपको समझ आता है कि अगर हेल्थ ऐसे ही घटती रही, तो किसी समय वह शायद 0 तक पहुँच जाएगी (_या उससे भी नीचे!_)।
बेहतर होगा कि एक `is_alive` मेथड जोड़ दिया जाए, जिसे एलेन झट से कॉल करके देख सके कि एलियन... वैसे... ज़िंदा है या नहीं। 😉
`<alien>.is_alive()` को एक बूलियन लौटाना चाहिए।

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. `teleport` मेथड

एलेन के गेम में एलियन टेलीपोर्ट कर सकते हैं!
आपको एक `teleport` मेथड लिखना होगा जो नई `x_coordinate` और `y_coordinate` वैल्यू लेता है और उसी हिसाब से एलियन के निर्देशांक बदल देता है।

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. `collision_detection` मेथड

साफ़ बात है, अगर एलियन से कोई चीज़ टकरा सकती है, तो उन्हें यह पहचानने की क्षमता भी चाहिए कि ऐसा टकराव हुआ है।
लेकिन टकराव पहचानने वाले एल्गोरिदम पेचीदा हो सकते हैं, और आपको अभी यह नहीं आता कि उन्हें कैसे लागू करें।
एलेन ने कहा है कि वह यह काम बाद में करेगी, पर वह चाहती है कि `collision_detection` मेथड क्लास में मौजूद रहे, ताकि यह याद रहे कि यह सुविधा आगे बनानी है।
उसे किसी तरह का वेरिएबल लेना होगा (शायद कोई दूसरा ऑब्जेक्ट), पर आपको बस इतना ही पता है।
आपको यह ध्यान रखना होगा कि मेथड की परिभाषा क्लास में डालने से कॉल करने पर कोई एरर न आए:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. एलियन काउंटर

एलेन एक नई माँग लेकर लौटी है।
वह जानना चाहती है कि गेम के दौरान अब तक कितने एलियन बन चुके हैं।
उसके मुताबिक इसका स्कोरिंग सिस्टम से कुछ संबंध है।

उदाहरण के लिए:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. एलियन की सूची बनाइए

एलेन को आपका अब तक का काम बहुत पसंद आया है, पर उसे एक और मदद चाहिए।
वह चाहती है कि एक अलग (_`Alien()` क्लास के बाहर_) फंक्शन हो, जो पोज़िशन की सूची (जो `tuples` के रूप में दी गई हो) लेकर `Alien()` ऑब्जेक्ट की `list` बनाए।

उदाहरण के लिए:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
