# परिचय

C# एक स्टैटिक टाइपिंग वाली भाषा है। इसका मतलब है कि कंपाइल टाइम पर हर चीज़ का एक टाइप होता है। किसी नाम को वैल्यू असाइन करना ही वेरिएबल बनाना कहलाता है। वेरिएबल बनाने के दो तरीके हैं: या तो आप उसका टाइप स्पष्ट रूप से बता दें, या C# कंपाइलर को असाइन की गई वैल्यू के आधार पर उसका टाइप खुद अनुमान लगाने दें (इसे _टाइप अनुमान_ कहते हैं)। इसलिए नीचे दिखाए गए वेरिएबल बनाने के ये दोनों तरीके एक जैसे हैं:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

वेरिएबल की वैल्यू बदलने के लिए `=` ऑपरेटर इस्तेमाल होता है। एक बार वेरिएबल बन जाने के बाद उसका टाइप कभी नहीं बदल सकता।

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# एक [ऑब्जेक्ट-ओरिएंटेड भाषा][object-oriented-programming] है। इसमें हर फंक्शन को किसी _क्लास_ के अंदर ही बनाना पड़ता है। क्लास बनाने के लिए `class` कीवर्ड का इस्तेमाल किया जाता है। ऑब्जेक्ट (या _इंस्टेंस_) `new` कीवर्ड से बनाए जाते हैं।

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

क्लास के अंदर लिखे फंक्शन को _मेथड_ कहा जाता है। किसी भी मेथड में शून्य या उससे अधिक पैरामीटर हो सकते हैं। सभी पैरामीटर का टाइप स्पष्ट रूप से लिखना ज़रूरी है; पैरामीटर के लिए टाइप अनुमान नहीं होता। इसी तरह रिटर्न टाइप भी स्पष्ट रूप से बताना पड़ता है। मेथड से वैल्यू `return` कीवर्ड की मदद से लौटाई जाती है। किसी मेथड को दूसरी फाइलों के कोड से कॉल कर पाने के लिए `public` एक्सेस मॉडिफायर जोड़ना ज़रूरी है।

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

मेथड को इंस्टेंस पर डॉट (`.`) सिंटैक्स से कॉल किया जाता है। इसमें कॉल करने वाले मेथड का नाम लिखते हैं और मेथड के हर पैरामीटर के लिए आर्गुमेंट पास करते हैं। आर्गुमेंट में चाहें तो उससे जुड़े पैरामीटर का नाम भी लिख सकते हैं।

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C# में स्कोप `{` और `}` के बीच होता है।

C# दो तरह के कमेंट सपोर्ट करता है। सिंगल-लाइन कमेंट से पहले `//` लगाया जाता है, और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
