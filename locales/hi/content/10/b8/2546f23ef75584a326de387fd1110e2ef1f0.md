# निर्देश

इस अभ्यास में आप `Map` की मदद से अंतरराष्ट्रीय डायलिंग कोड की एक डिक्शनरी संभालने वाला कोड लिखेंगे।

इस डिक्शनरी में अंतरराष्ट्रीय डायलिंग कोड (मैप की की, एक `Integer`) की मदद से किसी देश का नाम (मैप की वैल्यू, एक `String`) खोजा जा सकता है।

## 1. मैप में सारे कोड लौटाइए

`getCodes` मेथड बनाइए। यह कोई पैरामीटर नहीं लेता और डिक्शनरी में अभी मौजूद डायलिंग कोड से देश का मैप लौटाता है।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. डिक्शनरी में एंट्री जोड़िए

इस डिक्शनरी को भरना ज़रूरी है।
`setDialingCode` मेथड बनाइए। यह एक डायलिंग कोड और उससे जुड़ा देश लेता है और डायलिंग कोड तथा देश जोड़ देता है।
अगर डायलिंग कोड मैप में पहले से मौजूद है, तो मैप में दिए गए कोड और देश डाल दीजिए।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. डायलिंग कोड से देश ढूँढिए

`getCountry` मेथड बनाइए। यह एक डायलिंग कोड लेता है और उस कोड वाले देश का नाम लौटाता है।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. दोहराव की इजाज़त न दीजिए

डायलिंग कोड जोड़ते समय यह ध्यान रखना ज़रूरी है कि कोई कोड या देश दो बार न जुड़ जाए।
ऐसी स्थिति में मान लीजिए कि पहली एंट्री ही सही एंट्री है।
`addNewDialingCode` मेथड बनाइए, जो दिए गए डायलिंग कोड और देश की एक एंट्री जोड़ता है।
लेकिन `setDialingCode` के उलट, अगर डायलिंग कोड या देश पहले से मैप में मौजूद है, तो यह कुछ नहीं करता।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. देश का डायलिंग कोड ढूँढिए

ऐसा कम होता है, पर गलतियाँ हो सकती हैं।
गलती सुधारने के लिए हमें यह जानना होगा कि उस देश से अभी कौन-सा डायलिंग कोड जुड़ा है।
यह पता लगाने के लिए कि कौन-सा डायलिंग कोड सुधारना है, `findDialingCode` मेथड बनाइए। यह एक देश लेता है और उस देश का डायलिंग कोड लौटाता है।
अगर देश मैप में _नहीं_ है, तो `null` लौटाइए।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. देश का डायलिंग कोड बदलिए

अब जब हम जान गए हैं कि कौन-सा डायलिंग कोड सुधारना है, तो चलिए उसे बदलते हैं।
`updateCountryDialingCode` मेथड बनाइए। यह देश का नया डायलिंग कोड और देश का नाम लेता है और उसी के अनुसार बदलाव करता है।
अगर देश मैप में _नहीं_ है, तो कुछ न कीजिए (क्योंकि यह मेथड सिर्फ गलतियाँ सुधारने में मदद करने के लिए है)।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
