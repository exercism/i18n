# निर्देश

इस अभ्यास में आप अपनी पसंदीदा कुकबुक से बनी शानदार लसान्या पकाने के लिए कुछ और कोड लिखेंगे।

आपके सामने पाँच काम हैं, और सबका संबंध लसान्या पकाने में लगने वाले समय से है।

## 1. अपेक्षित ओवन समय बदलने दीजिए

आप `remainingMinutesInOven` फंक्शन को बेहतर बनाना चाहते हैं। यह फंक्शन पैरामीटर के रूप में वे बीते हुए मिनट लेता है जितनी देर लसान्या ओवन में रही है, और पिछले काम में तय किए गए अपेक्षित ओवन समय के हिसाब से बताता है कि लसान्या को ओवन में अभी कितने मिनट और रहना है।
पहले आप `expectedMinutesInOven` नाम की एक स्थिर वैल्यू पर निर्भर थे, जो `remainingMinutesInOven` फंक्शन के बाहर से आती थी।
इसमें दो दिक्कतें थीं: यह आपकी पसंद के हिसाब से थोड़ा बहुत उलझा हुआ था, और लचीला भी कम था, क्योंकि इससे ओवन का अपेक्षित समय बदलना संभव नहीं था।

इसे साफ-सुथरा बनाने के लिए `remainingMinutesInOven` फंक्शन बनाइए। यह फंक्शन पैरामीटर के रूप में वे बीते हुए मिनट लेता है जितनी देर लसान्या ओवन में रही है, और साथ ही एक `expectedMinutesInOven` पैरामीटर भी लेता है, जिसकी वैल्यू पहले से 40 तय है।
आपके फंक्शन को पिछले काम में तय अपेक्षित ओवन समय के हिसाब से बताना चाहिए कि लसान्या को ओवन में अभी कितने मिनट और रहना है।

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. परतों की अलग-अलग संख्या की सुविधा दीजिए

पिछले अभ्यास में आपने `preparationTimeInMinutes` फंक्शन लिखा था, जो पैरामीटर के रूप में लसान्या में डाली गई परतों की संख्या लेता है और बताता है कि लसान्या तैयार करने में आपने कितने मिनट लगाए, यह मानकर कि हर परत तैयार करने में 2 मिनट लगते हैं।
लेकिन यह फंक्शन आपको खास पसंद नहीं है, क्योंकि इस फंक्शन को कॉल करने से पहले आपको अपनी लसान्या की परतें खुद गिननी पड़ती हैं। और इतना सब करने का समय किसके पास है?

अपना काम आसान बनाने के लिए `preparationTimeInMinutes` नाम का एक फंक्शन लिखिए, जो एक वेरिएडिक `String` पैरामीटर, `layers`, लेता है, जिसमें आप अपनी लसान्या की अलग-अलग परतें लिखते हैं।
फिर यह फंक्शन आपकी लसान्या की परतें गिनकर बताएगा कि तैयारी में कितना समय लगेगा।

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. नूडल्स और सॉस की मात्रा निकालिए

अपनी लसान्या की परतें लगाना शुरू करने से पहले आप यह पक्का करना चाहते हैं कि आपके सपनों की लसान्या बनाने के लिए आपके पास पर्याप्त सॉस और नूडल्स हों।
लसान्या की हर नूडल परत के लिए आपको 3 नूडल्स चाहिए।
लसान्या की हर सॉस परत के लिए 0.2 लीटर सॉस चाहिए।

`quantities` फंक्शन बनाइए, जो एक वेरिएडिक `String` पैरामीटर, `layers`, लेता है, जिसमें आप अपनी लसान्या की अलग-अलग परतें लिखते हैं।
फिर यह फंक्शन तय करेगा कि आपका खाना बनाने के लिए कितने नूडल्स और कितना सॉस चाहिए। नतीजा `(noodles: Int, sauce: Double)` टाइप के टपल में लौटाना चाहिए।

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. लीटर को वहीं फ्लुइड औंस में बदलिए

दुर्भाग्य से, आपके पास जो सॉस है उसका आयतन लीटर की जगह फ्लुइड औंस में लिखा है।
यह जानने के लिए कि आपके पास पर्याप्त सॉस है या नहीं, `toOz` नाम का एक फंक्शन लिखिए, जो एक इन-आउट टपल पैरामीटर, `(noodles: Int, sauce: Double)`, लेता है और सॉस की मात्रा को फ्लुइड औंस में बदल देता है।
ध्यान रखिए कि एक लीटर में 33.814 फ्लुइड औंस होते हैं।

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. परोसने के लिए सबसे अच्छी वाइन तय कीजिए

अंत में, आप जानना चाहते हैं कि अपनी लसान्या के साथ किस तरह की वाइन परोसी जाए।
आपने सुना है कि अगर लसान्या में मोज़रेला, रिकोटा और बेशमेल की परतें मीट और सॉस की परतों से अधिक हों, तो सफेद वाइन परोसनी चाहिए, वरना रेड वाइन।
`redWine` फंक्शन लिखिए, जो एक वेरिएडिक `String` पैरामीटर, `layers`, लेता है, जिसमें आप अपनी लसान्या की अलग-अलग परतें लिखते हैं।
यह फंक्शन पाँच नेस्टेड फंक्शन इस्तेमाल करके लसान्या में मोज़रेला, रिकोटा, बेशमेल, सॉस और मीट की परतों की संख्या निकालेगा, और परतों की संख्याओं की तुलना करके तय करेगा कि रेड वाइन परोसनी चाहिए या नहीं। अगर हाँ, तो यह `true` लौटाएगा, और अगर नहीं, तो `false`।

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
