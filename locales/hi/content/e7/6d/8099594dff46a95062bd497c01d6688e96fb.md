# परिचय

## पैटर्न मैचिंग लिटरल

`if/else` एक्सप्रेशनों से शर्त के हिसाब से कोड चलाया जा सकता है, लेकिन Haskell में यही काम करने का एक और ज़्यादा शक्तिशाली तरीका भी है: [पैटर्न मैचिंग][pattern-matching]।
पैटर्न मैचिंग में किसी वैल्यू को एक या अधिक _पैटर्न_ से मिलाकर जाँचा जाता है।
ऐसे पैटर्न का एक उदाहरण _स्थिरांक पैटर्न_ है, जो किसी वैल्यू को एक स्थिरांक से मिलाता है (जैसे `1` या `"hello"`)।

फंक्शन बनाते समय आप हर पैटर्न के लिए अलग फंक्शन बॉडी लिख सकते हैं।
इससे कोड साफ और सरल रहता है, पढ़ने में भी आसान।
आप किसी भी डेटा टाइप पर पैटर्न मैचिंग कर सकते हैं: संख्याएँ, अक्षर, ऐरे, टपल, वगैरह।

उदाहरण के लिए, एक छोटा-सा फंक्शन जो एक पूर्ण संख्या (`Int`) लेता है और उसे _0_ के _1_ और करीब ले आता है, ऐसे लिखा जा सकता है:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

पैटर्न मैचिंग की असली शक्ति तब दिखती है जब इसे दूसरे पैटर्नों के साथ मिलाकर इस्तेमाल किया जाए, जैसे _वेरिएबल पैटर्न_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

ऊपर का उदाहरण _0_ के अलावा सभी इनपुट को एक जैसा मानता है, और ऋणात्मक संख्याओं के लिए गलत परिणाम देगा।
इसे शर्त वाले पैटर्नों से हल किया जा सकता है, जिन्हें _गार्ड_ कहते हैं और जो `|` चिह्न से लिखे जाते हैं:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

ऊपर के उदाहरणों में सभी संभावित इनपुट से मेल खाने वाला पैटर्न मौजूद नहीं है।
कंपाइलर इसे पकड़ लेगा और एक चेतावनी देगा।
यह Haskell का बहुत काम का फीचर है, जो यह सुनिश्चित करने में मदद करता है कि सभी संभावित रास्ते कवर हों और रनटाइम एरर न हों।
इसे _एक्सहॉस्टिव चेकिंग_ कहते हैं।
इस चेतावनी को दूर करने के लिए आपको सभी केस संभालने होंगे।
_गार्ड_ के अंदर आप बाकी सभी पैटर्नों को पकड़ने के लिए `True` के सिंटैक्टिक शुगर के रूप में `otherwise` एक्सप्रेशन इस्तेमाल कर सकते हैं।

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

पैटर्न मैचिंग एक वैल्यू को ऊपर से नीचे तक हर पैटर्न से मिलाकर जाँचती है, जब तक कि कोई मेल खाता पैटर्न न मिल जाए और उससे जुड़ा कोड न चल जाए।
**पैटर्नों का क्रम मायने रखता है!**
