# परिचय

Julia में मुख्य रूप से तीन शर्त वाले स्टेटमेंट इस्तेमाल किए जाते हैं:

- `if` एक्सप्रेशन
- टर्नरी ऑपरेटर
- शॉर्ट-सर्किट मूल्यांकन

## `if` एक्सप्रेशन

Julia में `if` एक्सप्रेशन वैसे ही होते हैं जैसे दूसरी भाषाओं में देखने को मिलते हैं:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

अगर `if` के बाद वाला बूलियन एक्सप्रेशन `true` देता है, तो कोड का पहला ब्लॉक चलता है और दूसरा ब्लॉक छोड़ दिया जाता है।
अगर `if` के बाद वाला बूलियन एक्सप्रेशन `false` देता है, तो कोड का पहला ब्लॉक छोड़ दिया जाता है और दूसरा ब्लॉक चलता है।
`end` कीवर्ड के बाद वाली कोड की पहली लाइन से प्रोग्राम चलता रहता है।

~~~~exercism/note
Julia में `end` कीवर्ड हर ब्लॉक एक्सप्रेशन के अंत को दर्शाता है।
यह सिंटैक्स सिर्फ `if` एक्सप्रेशन या फंक्शन बनाने तक ही सीमित नहीं है।
~~~~

ऐसे मामलों में जहाँ कोड का दूसरा ब्लॉक बस एक और `if` एक्सप्रेशन होगा, वहाँ `elseif` हमें ब्लॉक के अंदर `if` एक्सप्रेशन नेस्ट करने से बचाता है:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

अगर किसी `if` एक्सप्रेशन को सिर्फ एक ही स्थिति में कोड चलाना है, तो `else` शाखा लिखने की ज़रूरत नहीं है।

## टर्नरी ऑपरेटर

साधारण `if-else` स्टेटमेंट टर्नरी ऑपरेटर `a ? b : c` की मदद से भी लिखे जा सकते हैं।
अगर `a` सही है, तो `b` का मूल्यांकन होगा।
वरना `c` का मूल्यांकन होगा।

उदाहरण के लिए, यह फंक्शन

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

इस तरह भी लिखा जा सकता है

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

यह तब खास तौर पर काम आता है जब आप किसी शर्त के हिसाब से एक वेरिएबल को अलग-अलग वैल्यू असाइन करना चाहें।
`x = a ? b : c` में अगर `a` `true` है, तो `x` को `b` असाइन होता है, वरना `x` को `c` असाइन होता है।
उदाहरण के लिए:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## शॉर्ट-सर्किट मूल्यांकन

अगर कई बूलियन एक्सप्रेशन `&&` और `||` ऑपरेटरों की मदद से एक श्रृंखला में जोड़े जाएँ, तो Julia पूरी श्रृंखला की वैल्यू तय करने के लिए सिर्फ उतने ही एक्सप्रेशन का मूल्यांकन करता है जितने ज़रूरी हैं।

उदाहरण के लिए, एक्सप्रेशन की यह श्रृंखला देखिए: `n > 0 && k > 10`.
अगर `n` की वैल्यू `5` है, तो श्रृंखला का पहला हिस्सा `n > 0` `true` है, और यह तय करने के लिए कि पूरा एक्सप्रेशन `true` है या नहीं, दूसरे एक्सप्रेशन `k > 10` का मूल्यांकन करना ज़रूरी है।
लेकिन अगर `n` की वैल्यू `-5` है, तो हम जानते हैं कि पूरी श्रृंखला `true` **नहीं** हो सकती, क्योंकि उसका पहला एक्सप्रेशन `false` है।

इसके बजाय अगर हम `n > 0 || k > 10` लें, तो उल्टा होता है।
अगर `n` की वैल्यू `5` है, तो श्रृंखला का पहला हिस्सा `n > 0` `true` है, और हम जानते हैं कि दूसरे एक्सप्रेशन से कोई फर्क नहीं पड़ता, पूरी श्रृंखला `true` ही रहेगी।
लेकिन अगर `n` की वैल्यू `-5` है, तो दूसरे एक्सप्रेशन का मूल्यांकन करना ज़रूरी है।

इस व्यवहार का इस्तेमाल करके बहुत छोटे `if` स्टेटमेंट लिखे जा सकते हैं:

```julia
if a
    b
end
```

इसके बराबर है

```julia
a && b
```

`&&` और `||` की श्रृंखला में आखिरी एक्सप्रेशन का बूलियन एक्सप्रेशन होना ज़रूरी नहीं है।
आप देखेंगे कि इस फीचर का इस्तेमाल अक्सर समय से पहले एरर देने या फंक्शन से लौटने के लिए किया जाता है।
उदाहरण के लिए, ऊपर वाले `dessert(fruit)` फंक्शन का इस्तेमाल कीजिए:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
