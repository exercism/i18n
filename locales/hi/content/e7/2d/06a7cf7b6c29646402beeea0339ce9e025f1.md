# कोई नाम वाला एक्सपोर्ट नहीं

`%{export.name}` नाम का कोई [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) नहीं मिला। इसके बिना टेस्ट पास नहीं हो पाएँगे।

ध्यान रखिए कि `%{export.name}` मौजूद हो, और उसके आगे `export` लगाइए:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
