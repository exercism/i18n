# इसके बारे में

Flags एट्रिब्यूट डिस्क्रिमिनेटेड यूनियन में परिभाषित वैल्यू को बिट पोज़िशन (यानी फ्लैग्स) के रूप में दर्शाने की सुविधा देता है।
फ्लैग्स के रूप में ऐसी वैल्यू को आपस में मिलाया जा सकता है, जिससे एक ही वैल्यू में कई बूलियन शर्तें दर्शाई जा सकती हैं।

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

किसी फ्लैग को सेट करना बिटवाइज़ OR ऑपरेटर (`|||`) की मदद से किया जा सकता है; किसी फ्लैग को अनसेट करना बिटवाइज़ AND ऑपरेटर (`&&&`) और बिटवाइज़ निगेशन ऑपरेटर (`~~~`) को मिलाकर किया जा सकता है।
फ्लैग की स्थिति जाँचने के लिए बिटवाइज़ AND ऑपरेटर का इस्तेमाल किया जा सकता है, हालाँकि आप HasFlag() मेथड का भी इस्तेमाल कर सकते हैं।

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

F# भाषा में उपलब्ध सभी बिटवाइज़ ऑपरेटरों की पूरी सूची के लिए [बिटवाइज़ ऑपरेटरों का सारांश][bitwise-operators] देखिए।
