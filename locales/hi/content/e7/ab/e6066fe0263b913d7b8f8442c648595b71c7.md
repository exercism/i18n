# निर्देश परिशिष्ट

## संकेत

टेस्ट पास कराने के लिए आपको कुछ ऐसे टाइप बनाने होंगे जिन पर आपका कोड काम करेगा। आपको `School` के लिए एक ऑब्जेक्ट चाहिए जो `Student` टाइप की सीक्वेंस रख सके। यहाँ `Student` `string` और `int` का टपल होगा, जिसमें छात्रों का नाम और ग्रेड रखे जाएँगे।

शुरुआत करते समय यहाँ इन टाइप का कुछ कोड दिया गया है, जो मददगार हो सकता है:

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
