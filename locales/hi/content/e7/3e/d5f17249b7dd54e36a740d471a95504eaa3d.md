# निर्देश

आप एक रोल-प्लेइंग गेम बनाने पर काम कर रहे हैं।
खिलाड़ी का पात्र इस तरह दर्शाया गया है:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

इस गेम में खिलाड़ियों को स्पेल चलाने के लिए इस्तेमाल होने वाला मैना पूल अनलॉक करने से पहले लेवल 10 तक पहुँचना होता है।
उससे पहले प्लेयर का मैना `Option::None` होता है।

इस गेम में आप दो चीज़ों पर काम कर रहे हैं: रिवाइव करने का तरीका और स्पेल कास्टिंग का तरीका।

`revive` मेथड को यह जाँचना चाहिए कि प्लेयर वाकई मर चुका है (उसकी हेल्थ 0 तक पहुँच गई है), और अगर ऐसा है, तो मेथड को 100 हेल्थ वाला एक नया प्लेयर इंस्टेंस लौटाना चाहिए।
`revive` मेथड को प्लेयर का लेवल वैसा ही रखना चाहिए।
अगर प्लेयर का लेवल 10 या उससे अधिक है, तो उसे 100 मैना के साथ रिवाइव किया जाना चाहिए।
अगर प्लेयर का लेवल 10 से कम है, तो उसका मैना `Option::None` होना चाहिए।

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

अगर `revive` मेथड ऐसे प्लेयर पर कॉल किया जाता है जिसकी हेल्थ 1 या उससे अधिक है, तो मेथड को `Option::None` लौटाना चाहिए।

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

`cast_spell` मेथड प्लेयर का म्यूटेबल रेफरेंस लेता है और साथ में एक `mana_cost` पैरामीटर भी, जो बताता है कि उस स्पेल पर कितना मैना लगता है।
यह उस डैमेज की मात्रा लौटाता है जो चला गया स्पेल करता है।

- अगर खिलाड़ी के पास मैना पूल नहीं है, तो स्पेल चलाने की कोशिश करने पर उसकी हेल्थ उतनी कम हो जानी चाहिए जितना मैना वह स्पेल माँगता है।
  लौटाया गया डैमेज 0 होना चाहिए।

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- अगर खिलाड़ी के पास मैना पूल है लेकिन मैना कम है, तो मेथड को पूल पर कोई असर नहीं डालना चाहिए।
लौटाया गया डैमेज 0 होना चाहिए।

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- वरना, स्पेल सफलतापूर्वक चल जाता है।
  प्लेयर के मैना पूल से `mana_cost` घटा दिया जाना चाहिए।
  लौटाया गया डैमेज स्पेल पर लगने वाले मैना से दुगुना होना चाहिए।

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```

मज़े कीजिए!
