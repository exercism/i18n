# निर्देश परिशिष्ट

## कार्यान्वयन

इस अभ्यास के फंक्शन एक ऐरे लेते हैं, जिसमें एक या अधिक संख्याएँ होती हैं। इनमें हर संख्या एक 'गेम स्कोर' को दर्शाती है।

खिलाड़ी के गेम स्कोर यहाँ से पढ़े जा सकते हैं:

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` को खिलाड़ी के सबसे ऊँचे स्कोर यहाँ लिखना चाहिए:

| `output`   |
|---|
| `output[0]` |
| ... |
