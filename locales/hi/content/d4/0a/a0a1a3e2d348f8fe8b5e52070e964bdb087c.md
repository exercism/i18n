# टेस्ट

अपने हल को टेस्ट करने के लिए टर्मिनल खोलिए और यह चलाइए

```
mason test
```

अभ्यास फोल्डर में (वह फोल्डर जिसमें `Mason.toml` फाइल और `src/` तथा `test/` फोल्डर हैं)।

अगर आपको लगता है कि एरर संदेश में पर्याप्त जानकारी नहीं मिलती, तो ज़्यादा विस्तृत संदेश पाने के लिए आप यह आज़मा सकते हैं।

```
mason test --show
```
