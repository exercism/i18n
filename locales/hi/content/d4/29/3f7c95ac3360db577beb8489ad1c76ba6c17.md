# निर्देश

आप एक छोटा रिवर्स पोलिश नोटेशन (RPN) कैलकुलेटर बना रहे हैं।
कैलकुलेटर की स्थिति *वैल्यू का स्टैक* होती है, जिसे Factor ऐरे के रूप में दर्शाया जाता है, और एक *ऑपरेशन* एक कोटेशन होता है जो ऐसा स्टैक लेकर एक नया स्टैक लौटाता है।

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. जोड़ लागू कीजिए

`add-op` को इस तरह बनाइए कि वह स्टैक से ऊपर की दो वैल्यू निकाले, उनका जोड़ स्टैक पर डाले, और नया स्टैक लौटाए।

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. गुणा लागू कीजिए

`multiply-op` को भी उसी तरह बनाइए, बस गुणा के लिए।

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. एक अकेला ऑपरेशन लागू कीजिए

`apply-op` को इस तरह बनाइए कि वह डेटा स्टैक से एक स्टैक और एक ऑपरेशन (एक कोटेशन) निकाले और कैलकुलेटर का नया स्टैक लौटाए।

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. प्रोग्राम का मूल्यांकन कीजिए

`evaluate` को इस तरह बनाइए कि वह शुरुआती स्टैक और ऑपरेशनों का एक ऐरे ले, हर ऑपरेशन को बारी-बारी लागू करे, और अंतिम स्टैक लौटाए।

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. नाम से मूल्यांकन कीजिए

अब प्रोग्राम *ऑपरेटर नामों* (स्ट्रिंग) की एक सूची है, और कैलकुलेटर हर नाम को एक असॉक में ढूँढता है, जो नामों को ऑपरेशनों से जोड़ता है।

`evaluate-named` को इस तरह बनाइए कि वह शुरुआती स्टैक, नामित ऑपरेशनों का एक असॉक, और नामों का एक ऐरे ले, और अंतिम स्टैक लौटाए।

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. सुरक्षित भाग दीजिए

जब किसी असली कैलकुलेटर से शून्य से भाग देने को कहा जाए, तो उसे चुपचाप बेतुका नतीजा नहीं देना चाहिए। `zero-divisor-error` एरर क्लास आपके लिए पहले से बनी हुई है। `divide-op` को `add-op` और `multiply-op` की तरह ही लागू कीजिए, बस जब स्टैक के ऊपर रखा भाजक `0` हो, तो यह एक नई `zero-divisor-error` `throw` करे।

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
