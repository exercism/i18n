# निर्देश

*ChronoRealms* की दुनिया में आपका स्वागत है। यह एक जादुई भूमि है, जहाँ शक्तिशाली Timekeepers समय के प्रवाह को नियंत्रित करते हैं।

इस दुनिया में Timekeepers "TimeShards" नाम की खास इकाइयों को संभालते हैं। इन इकाइयों को जोड़ा और घटाया जा सकता है, इनकी तुलना की जा सकती है, और इनकी बराबरी भी जाँची जा सकती है।

आपको Timekeepers की मदद करनी है। इसके लिए आपको इन TimeShards पर काम करने वाले कस्टम ऑपरेटर लागू करने हैं।

Timekeepers चाहते हैं कि आप एक कस्टम स्ट्रक्ट `TimeShard` बनाइए जो ये ऑपरेशन कर सके:

1. **TimeShards जोड़ना और घटाना**: Timekeepers को टाइमलाइन नियंत्रित करने के लिए TimeShards जोड़ने और घटाने की ज़रूरत होती है।
2. **TimeShards की तुलना करना**: कभी-कभी TimeShards की तुलना करनी होती है, ताकि पता चले कि कौन सा बड़ा है या क्या वे बराबर हैं।
3. **बराबरी जाँचना**: Timekeepers को जाँचना होता है कि दो TimeShards की वैल्यू एक जैसी हैं या नहीं।

आपको `TimeShard` स्ट्रक्ट के लिए ये ट्रेट लागू करने हैं:

1. **जोड़ (`Add`)**: दो `TimeShard` इंस्टेंस को आपस में जोड़ना संभव बनाइए।
2. **घटाव (`Sub`)**: एक `TimeShard` को दूसरे से घटाना संभव बनाइए।
3. **बराबरी (`PartialEq`)**: Timekeepers को यह जाँचने दीजिए कि दो `TimeShard` इंस्टेंस एक जैसे हैं या नहीं।
4. **तुलना (`PartialOrd`)**: दो `TimeShard` इंस्टेंस की तुलना करने की सुविधा दीजिए, ताकि पता चले कि कौन सा बड़ा या छोटा है।

`TimeShard` को एक ऐसे स्ट्रक्ट से दर्शाया जाएगा जो एक पूर्णांक वैल्यू (`i32`) रखता है।

Timekeepers का काम आसान बनाने के लिए ज़रूरी ट्रेट लागू कीजिए।

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
