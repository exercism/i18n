# परिचय

Cairo में ऑपरेटर ओवरलोडिंग की मदद से आप अपने ही टाइप के साथ काम करते समय `+`, `-`, `==`, `<` जैसे मानक ऑपरेटरों का व्यवहार अपने हिसाब से तय कर सकते हैं।

यह आपके कस्टम टाइप के लिए विशेष ट्रेट लागू करके किया जाता है।

## ऑपरेटरों के लिए मुख्य ट्रेट

### `Add` और `Sub`

`Add` और `Sub` ट्रेट की मदद से आप तय कर सकते हैं कि आपके टाइप के साथ जोड़ (`+`) और घटाव (`-`) कैसे काम करते हैं:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`PartialEq` ट्रेट आपके टाइप के इंस्टेंस के बीच बराबरी की तुलना (`==` और `!=`) संभव बनाता है।

इसे अक्सर `#[derive(PartialEq)]` की मदद से अपने आप बनाया जा सकता है।

### `PartialOrd`

`PartialOrd` ट्रेट आपके टाइप के इंस्टेंस के बीच तुलना के ऑपरेशन (`<`, `>`, `<=`, `>=`) करने देता है।

इसके लिए ज़रूरी है कि आप कम से कम `lt` (इससे कम) मेथड लागू करें:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
