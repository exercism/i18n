# परिचय

Java 8 में जोड़ा गया `java.time` पैकेज दिनांक और समय के साथ काम करने के लिए कई क्लास देता है।

## `LocalDate`

`java.time.LocalDate` क्लास [ISO-8601 कैलेंडर प्रणाली][iso-8601] में बिना टाइम ज़ोन वाले दिनांक को दर्शाता है, जैसे `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

दिनांकों की तुलना दूसरे दिनांकों से की जा सकती है:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

`LocalDate` इंस्टेंस में ऐसे गेटर होते हैं जिनसे आप उसके समय के अलग-अलग भाग निकाल सकते हैं:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

`LocalDate` इंस्टेंस में समय की इकाइयाँ जोड़ने के लिए मेथड होते हैं:

```exercism/note
ये मेथड एक _नया_ `LocalDate` इंस्टेंस लौटाते हैं और मौजूदा इंस्टेंस को नहीं बदलते, क्योंकि `LocalDate` क्लास अपरिवर्तनीय है।
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

`java.time.LocalDateTime` क्लास [ISO-8601 कैलेंडर प्रणाली][iso-8601] में बिना टाइम ज़ोन वाले दिनांक-समय को दर्शाता है, जैसे `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

आप एक `LocalDate` इंस्टेंस को `LocalDateTime` में बदल सकते हैं:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## दिनांक और समय फॉर्मैट करना

`String` से और `String` में बदलते समय `LocalDate` और `LocalDateTime` दोनों [ISO-8601][iso-8601] मानक संकेतन का उपयोग करते हैं।

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

इस तरह किसी अलग फॉर्मैट का उपयोग करके `String` से `LocalDate` या `LocalDateTime` पार्स करना संभव नहीं है।
इसके बजाय, कस्टम फॉर्मैट से दिनांक फॉर्मैट करने के लिए आपको `java.time.format.DateTimeFormatter` का उपयोग करना चाहिए:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

अलग-अलग क्षेत्रों के लिए फॉर्मैट करने और पार्स करने के लिए कस्टम फॉर्मैट बनाते समय लोकेल भी दिया जा सकता है:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
