# अधिक जानकारी

हैक्स में **ऐरे** आम तौर पर एक ही टाइप के एलिमेंटों का संग्रह होता है। हैक्स में ऐरे बनाने के तीन तरीके हैं। इसे कंस्ट्रक्टर से बनाया जा सकता है या घोषणा सिंटैक्स से। हैक्स में ऐरे के पहले एलिमेंट का इंडेक्स शून्य होता है:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

कंस्ट्रक्टर की मदद से ऐरे बनाने के लिए आपको उन एलिमेंटों का टाइप पास करना होता है जो ऐरे में शामिल किए जाएँगे:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

चूँकि हैक्स में ऐरे की पहुँच की कोई सीमा नहीं होती, यानी यह पक्का है कि इससे कोई एक्सेप्शन नहीं आएगा, इसलिए इस पर आगे चर्चा करना ज़रूरी है:

- अगर किसी ऐसे इंडेक्स को पढ़ा जाए जो मौजूद नहीं है, तो टारगेट पर निर्भर वैल्यू लौटाई जाती है।
- अगर किसी धनात्मक इंडेक्स पर लिखा जाए जो सीमा से बाहर है, तो पिछले निर्धारित इंडेक्स और नए लिखे गए इंडेक्स के बीच की सभी जगहों पर `null` (या स्टैटिक टारगेट पर बेसिक टाइप के लिए डिफ़ॉल्ट वैल्यू) डाल दी जाती है।
- अगर किसी ऋणात्मक इंडेक्स पर लिखा जाए, तो परिणाम तय नहीं होता।

अगर हम चाहते हैं कि एक ऐरे में अलग-अलग टाइप के एलिमेंट रहें, तो हम टाइप इंडिकेटर में `Dynamic` टाइप जोड़ देते हैं:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## इटरेशन

ऐरे पर `for` लूप की मदद से इटरेशन किया जा सकता है:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
