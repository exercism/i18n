# निर्देश

इस अभ्यास में आप अर्ध-संरचित लॉग संदेश बनाएँगे।

## अर्ध-संरचित संदेश बनाइए

आपकी शुरुआत कुछ स्टब फंक्शन और नीचे दिए गए एनम से होगी:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

आपका उद्देश्य इस तरह का लॉग संदेश बनाना है: `"[<LEVEL>]: <MESSAGE>"`.
इसके लिए आपको लॉग लेवल के अनुरूप फंक्शन बनाने होंगे।

उदाहरण के लिए, नीचे दिया गया स्निपेट `log` फंक्शन के अपेक्षित आउटपुट को दर्शाता है।

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

और `info` के लिए:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```
