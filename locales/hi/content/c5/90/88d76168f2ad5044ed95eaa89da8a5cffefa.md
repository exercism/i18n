# निर्देश

आपके आस-पास के एक स्थानीय स्कूल में छात्रों का एक बहुत सक्रिय संघ है।
इस छात्र संघ का संचालन एक अध्यक्ष करता है, और हर 2 साल में एक बार नया अध्यक्ष चुनने के लिए चुनाव होते हैं।

इस साल के चुनाव में यह तय हुआ कि वोट गिनने के लिए एक नए डिजिटल सिस्टम की ज़रूरत है।
यह नया सिस्टम बनाने में स्कूल को आपकी मदद चाहिए।

## 1. वोट काउंटर बनाइए

नए वोटिंग सिस्टम को सबसे पहले जिन चीज़ों की ज़रूरत है, उनमें से एक है वोट काउंटर।
यह काउंटर किसी एक उम्मीदवार को मिले वोटों का हिसाब रखने का तरीका है।

एक फंक्शन `NewVoteCounter` बनाइए जो किसी उम्मीदवार के शुरुआती वोटों की संख्या लेता है और एक `int` की ओर इशारा करने वाला पॉइंटर लौटाता है, जिसमें दी गई शुरुआती वोट संख्या रखी जाती है।

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. काउंटर से वोटों की संख्या निकालिए

अब आपके पास नए काउंटर बनाने का तरीका है! लेकिन अब आपको एहसास होता है कि नए सिस्टम को काउंटर से वोटों की संख्या निकालने का तरीका भी चाहिए होगा।

एक फंक्शन `VoteCount` बनाइए जो एक काउंटर (`*int`) को आर्गुमेंट के रूप में लेता है और काउंटर में मौजूद वोटों की संख्या लौटाता है।
अगर काउंटर `nil` है, तो मान लीजिए कि उस काउंटर में कोई वोट नहीं है:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. काउंटर के वोट बढ़ाइए

अब वोट गिनने का समय आ गया है! अब आपको काउंटर के वोट बढ़ाने का तरीका चाहिए।

एक फंक्शन `IncrementVoteCount` बनाइए जो एक काउंटर (`*int`) और वोटों की एक संख्या आर्गुमेंट के रूप में लेता है, और काउंटर को उतने वोटों से बढ़ा देता है।
आप मान सकते हैं कि दिया गया पॉइंटर कभी `nil` नहीं होगा।

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. चुनाव के नतीजे बनाइए

अब जब सारे वोट गिन लिए गए हैं, तो पूरे स्कूल को नतीजे सुनाने की तैयारी का समय आ गया है।
इसके लिए आप देखते हैं कि सिर्फ वोटों के काउंटर होना काफी नहीं है।
वोटों की संख्या को किसी खास उम्मीदवार से जोड़ने का तरीका होना चाहिए।

एक फंक्शन `NewElectionResult` बनाइए जो किसी उम्मीदवार का नाम और उसके वोटों की संख्या लेता है और
एक नया चुनाव परिणाम लौटाता है।

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

चुनाव परिणाम का struct आपके लिए पहले से बना दिया गया है और इसे इस तरह परिभाषित किया गया है:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. नतीजों की घोषणा कीजिए

अब स्कूल को नए अध्यक्ष की घोषणा करने का समय है!
नए अध्यक्ष की घोषणा स्कूल के छोटे डिजिटल मैसेज बोर्ड पर की जाएगी।
संदेश में नए अध्यक्ष का नाम और उसे मिले वोट इस प्रारूप में दिखने चाहिए: `<candidate_name> (<votes>)`।
ऐसे संदेश का एक उदाहरण है: `"Peter (51)"`।

एक फंक्शन `DisplayResult` बनाइए जो एक `*ElectionResult` को आर्गुमेंट के रूप में लेता है और दिखाने के लिए संदेश वाली एक स्ट्रिंग लौटाता है।

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. वोटों की दोबारा गिनती

यह पक्का करने के लिए कि अंतिम नतीजे सही थे, वोटों की दोबारा गिनती की गई।
दोबारा गिनती में पता चला कि कुछ उम्मीदवारों के वोटों की संख्या में एक का अंतर था।

एक फंक्शन `DecrementVotesOfCandidate` बनाइए जो अंतिम नतीजे और उस उम्मीदवार का नाम लेता है जिसके वोटों की संख्या एक कम करनी है।
अंतिम नतीजे `map[string]int` के रूप में दिए गए हैं, जिसमें कीज़ उम्मीदवारों के नाम हैं और वैल्यूज़ उनके कुल वोट हैं।

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
