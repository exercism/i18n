# परिचय

## टाइप कन्वर्ज़न

Go में अलग-अलग टाइप के बीच बदलने के लिए स्पष्ट कन्वर्ज़न ज़रूरी है।
टाइप के बीच बदलाव, जिसे **टाइप कास्टिंग** भी कहते हैं, उस टाइप के नाम वाले फंक्शन से किया जाता है जिसमें आपको बदलना है।
उदाहरण के लिए, किसी `int` को `float64` में बदलने के लिए आपको ऐसा करना होगा:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## प्रिमिटिव टाइप और स्ट्रिंग के बीच बदलाव

प्रिमिटिव टाइप (जैसे `int`) और `string` के बीच बदलने के लिए एक `strconv` पैकेज है।

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## टाइप असर्शन

Go में इंटरफेस की वजह से यह साफ़ नहीं रहता कि उसके अंदर कौन-सा टाइप है।
टाइप असर्शन से हम इंटरफेस वैल्यू के अंदर की कंक्रीट वैल्यू निकाल सकते हैं। इसके लिए यह सिंटैक्स इस्तेमाल होता है: `interfaceVariable.(concreteType)`.

उदाहरण के लिए:

```go
var input any = 12
number := input.(int)
```

ध्यान दीजिए: अगर इंटरफेस वेरिएबल में उस कंक्रीट टाइप की वैल्यू नहीं होती, तो इससे पैनिक हो जाता है।

हम यह भी जाँच सकते हैं कि किसी इंटरफेस वैल्यू में कोई खास कंक्रीट टाइप है या नहीं। इसके लिए टाइप असर्शन की दोनों रिटर्न वैल्यू काम आती हैं: अंदर की वैल्यू, और एक बूलियन वैल्यू जो बताती है कि असर्शन सफल रहा या नहीं।
उदाहरण के लिए:

```go
str, ok := input.(string) // no panic if input is not a string
```

अगर `input` में `string` टाइप की वैल्यू है, तो `str` में अंदर की वैल्यू होगी और `ok` की वैल्यू सही होगी।
अगर `input` में `string` टाइप की वैल्यू नहीं है, तो `str` में `string` टाइप की ज़ीरो वैल्यू होगी (यानी `""`, यानी खाली स्ट्रिंग) और `ok` की वैल्यू गलत होगी।
किसी भी हालत में पैनिक नहीं होता।

## टाइप स्विच

एक **टाइप स्विच** एक के बाद एक कई टाइप असर्शन कर सकता है।
इसका सिंटैक्स टाइप असर्शन जैसा ही होता है (`interfaceVariable.(concreteType)`), बस इसमें `concreteType` की जगह `type` कीवर्ड आ जाता है।
यह एक उदाहरण है:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
