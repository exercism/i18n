# परिचय

[`Box`][box] को समझने के लिए यह समझना मददगार रहता है कि [स्टैक और हीप][stack and heap] क्या हैं।

स्टैक मेमोरी का एक ऐसा भाग है जो अंत में आने वाले को पहले बाहर निकालने वाले (LIFO) बफर की तरह काम करता है। स्टैक पर डेटा डालना बहुत तेज़ होता है और उसे निकालना भी तेज़ होता है।
इस डेटा में वेरिएबल या फंक्शन के एड्रेस शामिल हो सकते हैं, लेकिन कंपाइल के समय इस डेटा का आकार ज्ञात और निश्चित होना चाहिए।

अगर कंपाइल के समय डेटा का आकार ज्ञात न हो, या उसका आकार बदल सकता हो, तो उसे हीप पर आवंटित करना पड़ता है। आवंटन की प्रक्रिया में हीप में उतनी बड़ी जगह ढूँढनी पड़ती है जितनी उस डेटा को संग्रहीत करने के लिए काफी हो, डेटा को हीप पर लिखना पड़ता है, और उस डेटा का मेमोरी एड्रेस स्टैक पर डालना पड़ता है। इन सब में डेटा को सीधे स्टैक पर रखने की तुलना में कहीं ज़्यादा समय लगता है। हीप से डेटा निकालना थोड़ा धीमा होता है, क्योंकि हमें स्टैक पर मौजूद एड्रेस से होकर जाना पड़ता है और उसका पीछा करते हुए हीप पर उस डेटा की जगह तक पहुँचना पड़ता है।

`Box` एक स्मार्ट पॉइंटर है जो डेटा को हीप पर आवंटित करता है। एड्रेस स्टैक पर रहता है और हीप पर मौजूद डेटा को इंगित करता है। `Box` इस्तेमाल करने का एक [कारण][reasons] यह है कि जब आपके पास ऐसा टाइप हो जिसका आकार कंपाइल के समय ज्ञात नहीं हो सकता, और आप उस टाइप की किसी वैल्यू को ऐसी जगह इस्तेमाल करना चाहते हों जहाँ सटीक आकार ज़रूरी हो, तो डेटा को हीप पर रखा जाए। इसका एक व्यावहारिक उदाहरण यह है कि जब आपके पास कई struct हों जिन्हें आप एक ही तरीके से संभालना चाहते हों, उस trait के ज़रिए जिसे वे सभी लागू करते हैं, जैसा नीचे उदाहरण में दिखाया गया है।

मान लीजिए हमारे पास दो struct हैं। हर struct किसी ऐसी चीज़ का है जो चिढ़ा सकती है। हम हर struct से एक Annoyance trait इस तरह लागू करा सकते हैं:

```rust
struct WerewolfOfLondon;
struct Rooster;

trait Annoyance {
    fn annoy(&self) -> &'static str;
}

impl Annoyance for WerewolfOfLondon {
    fn annoy(&self) -> &'static str {
        "ahhh-OOOOOOO!"
    }
}

impl Annoyance for Rooster {
    fn annoy(&self) -> &'static str {
        "errr-errr-errr-errr-ERRRRRRRRR!"
    }
}
```

अब मान लीजिए हम एक ऐसा फंक्शन चाहते हैं जो उसे दिए गए दिन के समय के आधार पर हमें एक Annoyance दे। सबसे पहले हम यह आज़मा सकते हैं, और हमें पता चलेगा कि यह कंपाइल नहीं होगा:

```rust
enum TimeOfDay {
    Midnight,
    Morning,
}

//return something that implements Annoyance
fn annoy_me(time_of_day: TimeOfDay) -> impl Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// `match` arms have incompatible types
// expected struct `WerewolfOfLondon`, found struct `Rooster`
// this is found to be of type `WerewolfOfLondon`
// `match` arms have incompatible types
// you could change the return type to be a boxed trait object
// if you change the return type to expect trait objects, box the returned expressions

```

कंपाइलर अपनी पूरी मददगारी के साथ हमें ठीक-ठीक बता देता है कि करना क्या है, यानी एक बॉक्स किया हुआ trait ऑब्जेक्ट लौटाना है। अगर आप नहीं जानते कि trait ऑब्जेक्ट क्या होता है, तो उसे समझने का एक आसान तरीका यह है कि यह किसी ऐसे फंक्शन से [डायनामिक डिस्पैच][dynamic dispatch] के ज़रिए कोई खास ऑब्जेक्ट लौटाने का तरीका है, जो ऐसा कोई भी ऑब्जेक्ट लौटा सकता हो जो बताया गया trait लागू करता हो। चूँकि हमें डायनामिक डिस्पैच चाहिए, हम trait के नाम के आगे बस एक `dyn` लगाकर देख सकते हैं कि यह काम कर जाता है या नहीं।

```rust
fn annoy_me(time_of_day: TimeOfDay) -> dyn Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// the size for values of type `dyn Annoyance` cannot be known at compilation time
// the trait `Sized` is not implemented for `dyn Annoyance`
// all local variables must have a statically known size
// unsized locals are gated as an unstable feature
```

इनमें से एक एरर यह है कि `dyn Annoyance` का आकार कंपाइल के समय ज्ञात नहीं किया जा सकता। इसकी वजह यह है कि `annoy_me` को कॉल किए जाने से पहले यह नहीं पता होता कि वह कौन-सा खास trait ऑब्जेक्ट लौटाएगा। Annoyance लागू करने वाले struct के फील्ड अलग-अलग हो सकते हैं और उनके आकार भी अलग-अलग हो सकते हैं। और हमें याद दिलाया जाता है कि `Box` का एक उपयोग ऐसे टाइप के लिए है जिसका आकार कंपाइल के समय ज्ञात नहीं हो सकता। तो अब हम `Box` किया हुआ रिटर्न वैल्यू इस्तेमाल करके देखते हैं, और match एक्सप्रेशन से लौटाई गई वैल्यू को `Box` कर देते हैं, इस तरह:

```rust
fn annoy_me(time_of_day: TimeOfDay) -> Box<dyn Annoyance> {
    match time_of_day {
        TimeOfDay::Midnight => Box::new(WerewolfOfLondon),
        TimeOfDay::Morning => Box::new(Rooster),
    }
}
```

`Box` का सिग्नेचर `Box<T>` है, जहाँ `T` उस खास टाइप को दर्शाता है जिसे बॉक्स किया जाना है और जिसे कोणीय ब्रैकेट के अंदर रखा जाता है, जैसा ऊपर `Box<dyn Annoyance>` में है।

हम बॉक्स किए हुए trait ऑब्जेक्ट का उपयोग इस तरह कर सकते हैं:

```rust
fn be_annoying(annoying_one: &dyn Annoyance) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(&*my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(&*my_annoyance);
}
```

जो यह प्रिंट करता है:

```rust
"ahhh-OOOOOOO!"
"errr-errr-errr-errr-ERRRRRRRRR!"
```

चूँकि `my_annoyance` का टाइप `Box<dyn Annoyance>` है, इसलिए इसे डीरेफ ऑपरेटर `*` की मदद से `Box` से डीरेफरेंस करना पड़ता है। इसके बाद इसे एक `dyn Annoyance` के रूप में संदर्भित किया जाता है, ताकि `be_annoying` फंक्शन इसे उधार ले सके।

इसे लागू करने का एक और तरीका यह होगा कि पैरामीटर का आकार ज्ञात होने की शर्त हटा दी जाए। उस स्थिति में कंपाइल करते समय Annoyance के हर रूप के लिए एक अलग फंक्शन बनाया जाएगा, ताकि इसे स्टैटिक रूप से डिस्पैच किया जा सके (इस प्रक्रिया को [मोनोमॉर्फाइज़ेशन][monomorphization] कहते हैं), इस तरह:

```rust
fn be_annoying<A: Annoyance + ?Sized>(annoying_one: &A) {
    println!("{:?}", annoying_one.annoy());
}
```

इसे लागू करने का एक और तरीका यह होगा कि `be_annoying` फंक्शन एक `Box<dyn Annoyance>` स्वीकार करे और [डीरेफ कोएर्शन][deref coercion] का इस्तेमाल करके `Box` को खुद से डीरेफरेंस करने की ज़रूरत से बचे। इससे Annoyance trait ऑब्जेक्ट का स्वामित्व `be_annoying` फंक्शन को चला जाएगा। फंक्शन के अंत में वह स्कोप से बाहर हो जाएगा और फिर उपलब्ध नहीं रहेगा।

```rust
fn be_annoying(annoying_one: Box<dyn Annoyance>) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(my_annoyance);
}
```

`Box` का इस्तेमाल कैसे करें, इसके बारे में आप The Rust Programming Language किताब के [उसके अध्याय][using box] में और जान सकते हैं।
