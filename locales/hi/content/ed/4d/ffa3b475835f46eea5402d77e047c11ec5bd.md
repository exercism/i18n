# निर्देश

आपका स्ट्रिंग समूह एक रीसाइटल में बजा रहा है। उसका प्रोग्राम किसी को लिखना है।

पाँचों काम `PROGRAMME_NOTES` क्लास में करने हैं।

## 1. रचना और संगीतकार का नाम लिखिए

पहले रचना का नाम लिखिए, फिर ` by `, और उसके बाद संगीतकार का नाम।

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. लाइन की लंबाई नापिए

प्रिंटर को यह जानना होता है कि लाइन कितनी लंबी है।

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. शुरू के कुछ अक्षर

टाइटल और एक संख्या दी जाए तो शुरू से उतने ही अक्षर लौटाइए।

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. अंत के कुछ अक्षर

यही काम अंत से गिनकर कीजिए।

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. लंबे टाइटल को छोटा कीजिए

जो टाइटल जगह में नहीं समाते, उन्हें उनके पहले छह अक्षरों तक काट दिया जाता है, और उनके बाद तीन बिंदु लगा दिए जाते हैं।

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
