# परिचय

सारा Common Lisp कोड एस-एक्सप्रेशन (प्रतीकात्मक एक्सप्रेशन) से बना होता है। इन्हें छोटा करके सेक्सप्र कहा जाता है। हर सेक्सप्र या तो एटम होता है या कॉन्स। जब एस-एक्सप्रेशन का मूल्यांकन किया जाता है, तो वे अपने आप कोई वैल्यू लौटाते हैं, जो उस एक्सप्रेशन की जगह ले लेती है। अपने फंक्शन लिखते समय (`defun` का उपयोग करते हुए), `defun` के अंदर की अंतिम वैल्यू अपने आप लौटा दी जाती है:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
