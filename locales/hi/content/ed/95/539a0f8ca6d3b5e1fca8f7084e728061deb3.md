# निर्देश

इस अभ्यास में आप एक जेनेरिक (या जादुई!) TreasureChest लिखेंगे, जिसमें थोड़ा खज़ाना रखा जा सके।

## 1. TreasureChest टाइप बनाइए

दो फील्ड वाला एक `TreasureChest{T}` पैरामेट्रिक टाइप बनाइए।

- `String` टाइप का एक `password` फील्ड, जिसका उपयोग खज़ाने के संदूक का पासवर्ड रखने के लिए किया जाएगा।
- `T` टाइप का एक `treasure` फील्ड, जिसमें खज़ाना रखा जाएगा।
यह वैल्यू जेनेरिक है, ताकि खज़ाना कुछ भी हो सके।

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. get_treasure() फंक्शन बनाइए

इस फंक्शन को दो आर्गुमेंट लेने चाहिए।

- एक `String` (पासवर्ड आज़माने के लिए)
- एक `TreasureChest` टाइप

इस फंक्शन को दिए गए पासवर्ड को `TreasureChest` के `password` से मिलाना चाहिए।

- अगर पासवर्ड मेल खाते हैं, तो खज़ाना लौटाइए।
- अगर पासवर्ड मेल नहीं खाते, तो `nothing` लौटाइए।

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. multiply_treasure() फंक्शन बनाइए

इस फंक्शन को दो आर्गुमेंट लेने चाहिए।

- एक पूर्णांक गुणक `n`।
- एक `TreasureChest{T}` टाइप।

फंक्शन को एक नया `TreasureChest{Vector{T}}` लौटाना चाहिए, जिसमें ये हों:

- मूल संदूक जैसा ही पासवर्ड
- `n` लंबाई के `Vector{T}` के रूप में गुणा किया गया खज़ाना, यानी मूल खज़ाना `n` बार दोहराया गया।

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
