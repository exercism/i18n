# इटरेशन

प्रोग्रामिंग में [इटरेशन][iteration] का मतलब है कोड के एक ब्लॉक को कई बार दोहराना। ऐसा while लूप और until लूप जैसे तरीकों से किया जा सकता है। रिकर्शन से भी किया जा सकता है, यानी ऐसे फंक्शन से जो खुद को कॉल करता है।

लेकिन ज़्यादातर मामलों में आपको किसी संग्रह के एलिमेंट पर इटरेशन करना होता है, जैसे `Array`, `Range` या `String` पर। Crystal में `Array` और `Range` क्लास दोनों में [`Enumerable`][enumerable] मॉड्यूल शामिल है, जो एलिमेंट पर इटरेशन करने के लिए कई मेथड देता है। वहीं `String` क्लास में अक्षरों पर इटरेशन करने के लिए अपने अलग मेथड हैं।

दूसरी भाषाओं के उलट Crystal में कोई for स्टेटमेंट भी नहीं है। इसके बजाय इसमें इटरेशन के लिए कई मेथड हैं।

## इटरेशन करना

किसी संग्रह पर इटरेशन करने का सबसे आम तरीका [`each`][each] मेथड है, जो ब्लॉक को संग्रह का हर एलिमेंट देता है। `Range` के साथ यह आसानी से हो जाता है। मान लीजिए आपको 1 से 3 के बीच लूप चलाना है, तो आप रेंज पर इटरेशन के लिए `each` मेथड इस्तेमाल कर सकते हैं।

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

और भी आसान तरीका यह है: अगर आपको बस कुछ बार इटरेशन करना है, तो आप [`times`][times] मेथड इस्तेमाल कर सकते हैं, जो `Int` क्लास में मौजूद है।

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## `String` पर इटरेशन करना

`String` अक्षरों का एक क्रम है और यह `Enumerable` मॉड्यूल में नहीं आता, इसलिए इसके पास अक्षरों पर इटरेशन करने के लिए अपने अलग मेथड हैं। `String` पर इटरेशन करने का सबसे आम तरीका [`each_char`][each_char] मेथड है, जो ब्लॉक को `String` का हर अक्षर देता है।

~~~~exercism/note
`each_char` मेथड ब्लॉक को `String` ऑब्जेक्ट नहीं, बल्कि `Char` ऑब्जेक्ट देता है।
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String` पर इटरेशन करने का एक और तरीका [`each_line`][each_line] मेथड है। यह मेथड ज़्यादातर तब इस्तेमाल होता है जब किसी फाइल को एक-एक लाइन करके पढ़ा जाता है।

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## `Enumerable` मॉड्यूल वाले ऑब्जेक्ट पर इटरेशन करना

[`Enumerable`][enumerable] मॉड्यूल किसी संग्रह के एलिमेंट पर इटरेशन करने के लिए कई मेथड देता है। जिन संग्रहों में `Enumerable` मॉड्यूल शामिल है उनमें `Array`, `Range`, `Hash`, `Set` और कुछ और हैं; बाद वाले संग्रह आगे के कॉन्सेप्ट में समझाए जाएँगे।

`Array` पर इटरेशन करने का सबसे आम तरीका [`each`][each] मेथड है, जो ब्लॉक को `Array` का हर एलिमेंट देता है।

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map] मेथड `Array` पर इटरेशन करने का एक और तरीका है। यह एक नया `Array` लौटाता है, जिसमें ब्लॉक को हर एलिमेंट पर लगाने का परिणाम होता है। यह `each` मेथड जैसा ही है, लेकिन यह बदले हुए एलिमेंट वाला नया `Array` लौटाता है। जब आपको किसी फंक्शन को संग्रह के हर एलिमेंट पर लगाना हो, तो यह बदलाव बहुत काम का होता है, और ऐसा करना एक आम बात है।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if` जैसी शर्तों की मदद से आप यह भी चुन सकते हैं कि किन एलिमेंट को बदलना है।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## संक्षिप्त रूप

Crystal में किसी संग्रह के हर एलिमेंट पर इटरेशन करने और उस पर कोई मेथड लगाने के लिए एक संक्षिप्त सिंटैक्स मौजूद है। यह तब काम आता है जब आपको किसी सरल चीज़ को सिर्फ एक मेथड से बदलना हो। इसके लिए `&.` सिंटैक्स के बाद मेथड का नाम लिखा जाता है।

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### इंडेक्स के साथ

कभी-कभी आपको यह जानना होता है कि जिस एलिमेंट पर आप इटरेशन कर रहे हैं उसका इंडेक्स क्या है। इसके लिए आप [`each_with_index`][each_with_index] या [`map_with_index`][map_with_index] मेथड इस्तेमाल कर सकते हैं। यह ब्लॉक को हर एलिमेंट और उसका इंडेक्स देता है, और यह मेथड शुरुआती इंडेक्स तय करने के लिए एक वैकल्पिक आर्गुमेंट भी लेता है।

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

ध्यान दीजिए कि `String` ऑब्जेक्ट के लिए [`each_char_with_index`][each_char_with_index] मेथड भी उपलब्ध है।

### sum

[`sum`][sum] मेथड संग्रह के सभी एलिमेंट का जोड़ लौटाता है। यह जोड़ने से पहले एलिमेंट बदलने के लिए एक वैकल्पिक ब्लॉक भी लेता है। यह जोड़ की शुरुआती वैल्यू तय करने के लिए एक वैकल्पिक आर्गुमेंट भी लेता है।

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], जिसे दूसरी भाषाओं में फोल्ड कहा जाता है, एक ऐसा मेथड है जो एक जोड़ने वाली मेथड और एक शुरुआती वैल्यू के साथ संग्रह के सभी एलिमेंट को मिला देता है। `reduce` मेथड में एक एक्युमुलेटर होता है जो ब्लॉक को दिया जाता है, और यह एक्युमुलेटर पिछले इटरेशन का परिणाम होता है। इस तरह यह एक रिकर्शन वाली प्रक्रिया बन जाती है जो संग्रह के सभी एलिमेंट को मिला देती है।

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` `sum` जैसा लग सकता है, लेकिन `reduce` ज़्यादा लचीला है क्योंकि इसमें आप एक्युमुलेटर की शुरुआती वैल्यू और जोड़ने वाली मेथड खुद तय कर सकते हैं। `reduce` की मदद से `sum`, `count` और दूसरे मेथड भी बनाए जा सकते हैं।
