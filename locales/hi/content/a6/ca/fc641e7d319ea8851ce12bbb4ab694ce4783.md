# परिचय

Common Lisp में सिंबल एक खास तरह की वैल्यू होते हैं। ये किसी दूसरी वैल्यू की ओर इशारा कर सकते हैं, और कीवर्ड के मामले में खुद अपनी ओर भी।

जब Lisp किसी सिंबल का मूल्यांकन करता है, तो उस सिंबल की जगह वह वैल्यू आ जाती है जिसकी ओर वह इशारा करता है:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

ध्यान रखिए कि कीवर्ड से पहले एक कोलन (`:`) लगाया जाता है।

कोट करने का मतलब है किसी एस-एक्सप्रेशन से पहले `'` लगाना। यह Lisp को बताता है कि उस एक्सप्रेशन का मूल्यांकन न करे। हमारे `defun` वाले उदाहरण में `'foo` को कोट करके हमने Lisp को यह देखने की कोशिश करने से रोक दिया (जिसमें वह सफल नहीं होता) कि `FOO` किस चीज़ की ओर इशारा करता है। इसके बजाय Lisp ने खुद वैल्यू `FOO` लौटा दी। अगर हमारे प्रोग्राम में `FOO` कहीं परिभाषित ही न किया गया हो:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

अभी के लिए आप इसे बस फंक्शन से सिंबल लौटाने का एक तरीका मान सकते हैं। लेकिन कोट करने पर हम दोबारा बात करेंगे, और आने वाले अवधारणा अभ्यासों में इसके निहितार्थों को और गहराई से समझेंगे।
