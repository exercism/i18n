# परिचय

Gleam, Erlang वर्चुअल मशीन (BEAM) पर चल सकता है, या JavaScript रनटाइम पर। ऐसी कई और भाषाएँ भी हैं जो इन रनटाइम का इस्तेमाल करती हैं, और इन भाषाओं में लिखे कोड को Gleam से कॉल कर पाना अक्सर उपयोगी होता है।

Gleam की _बाहरी फंक्शन_ सुविधा की मदद से दूसरी भाषाओं के फंक्शन Gleam में इम्पोर्ट किए जा सकते हैं और बिना किसी रनटाइम ओवरहेड के कॉल किए जा सकते हैं।

अगर आपका Gleam प्रोजेक्ट Erlang वर्चुअल मशीन पर चलता है और आप Erlang के `lists` मॉड्यूल से `reverse` फंक्शन को कॉल करना चाहते हैं, तो आप किसी Gleam फंक्शन के हेड पर `@external` एट्रिब्यूट जोड़कर ऐसा कर सकते हैं:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

इसे फिर किसी सामान्य Gleam फंक्शन की तरह कॉल किया जा सकता है:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

अगर आप इस कोड को JavaScript रनटाइम के लिए कंपाइल करने की कोशिश करते हैं, तो यह एक एरर संदेश के साथ विफल हो जाएगा, क्योंकि JavaScript के लिए कोई इम्प्लीमेंटेशन नहीं है। JavaScript रनटाइम के लिए दूसरा इम्प्लीमेंटेशन ऐसे दिया जा सकता है:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

ऐसा भी संभव है कि आप एक ऐसा Gleam इम्प्लीमेंटेशन लिखें जो तब इस्तेमाल होगा जब मौजूदा कंपाइल टारगेट के लिए कोई बाहरी इम्प्लीमेंटेशन न हो:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
