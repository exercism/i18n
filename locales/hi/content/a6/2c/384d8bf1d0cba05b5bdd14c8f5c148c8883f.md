# संकेत

इन सभी कार्यों के लिए आपको `print` कमांड की ज़रूरत पड़ेगी:

```awk
{print "something", "something else"}
```

## 1. उपयोगकर्ता नामों की सूची बनाइए

* फील्ड सेपरेटर तय करने के लिए [`FS` वेरिएबल][var-fs] इस्तेमाल कीजिए।

## 2. लाइन संख्या छापिए

* लाइन संख्या पाने के लिए [बिल्ट-इन वेरिएबल `NR`][var-nr] इस्तेमाल कीजिए।

## 3. अमान्य होम डायरेक्टरी वाले रिकॉर्ड छापिए।

* होम डायरेक्टरी छठा फील्ड है।
* दिए गए `startsWith` फंक्शन का इस्तेमाल कीजिए।
* [बूलियन ऑपरेटर][boolean-ops] इस्तेमाल कीजिए: `&&`, `||`, `!`.

## 4. bash इस्तेमाल करने वाले मान्य उपयोगकर्ताओं की संख्या छापिए

* लॉगिन शेल अंतिम फील्ड है। इसके लिए आप [`NF` वेरिएबल][var-nf] इस्तेमाल कर सकते हैं।
