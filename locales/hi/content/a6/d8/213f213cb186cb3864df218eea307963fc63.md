# परिचय

Haxe में एक प्रॉपर्टी क्लास का एक सदस्य होती है जो उस क्लास के अंदर के डेटा तक एक्सेस देती है। कॉलर उस डेटा को सेट या रिट्रीव (गेट) कर सकते हैं। इनमें एक सेट एक्सेसर और/या एक गेट एक्सेसर होता है।

प्रॉपर्टी में एक्सेस मॉडिफायर (public, private आदि) उसी तरह होते हैं जैसे क्लास के दूसरे सदस्यों में होते हैं। लेकिन सेट एक्सेसर का एक्सेस लेवल रिट्रीव (गेट) एक्सेसर से अलग हो सकता है, और इसका उलटा भी। किसी प्रॉपर्टी में दोनों एक्सेसर होना ज़रूरी नहीं है; यह सिर्फ एक भी रख सकती है (या तो गेट या सेट)।

पढ़ने का एक्सेस और लिखने का एक्सेस सीधे सिंटैक्स में दिखाई देते हैं, जैसा कि नीचे दिया गया उदाहरण दिखाता है:

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default` और `null` दोनों विशेष **एक्सेस आइडेंटिफायर** हैं। एक्सेस आइडेंटिफायर यह तय करते हैं कि फील्ड को पढ़ते समय (पहला आइडेंटिफायर) और लिखते समय (दूसरा आइडेंटिफायर) क्या व्यवहार होगा। स्वीकार्य वैल्यू ये हैं:

- `default`: अगर फील्ड public है तो सामान्य फील्ड एक्सेस की अनुमति देता है।
- `null`: सिर्फ उसी क्लास के अंदर से एक्सेस की अनुमति देता है जिसमें इसे परिभाषित किया गया है।
- `get/set`: एक्सेस को एक एक्सेसर मेथड (`get_x()`) के कॉल के रूप में बनाया जाता है।
- `dynamic`: `get/set` जैसा ही, लेकिन एक्सेसर मेथड के होने की पुष्टि नहीं की जा सकती।
- `never`: किसी भी तरह का एक्सेस नहीं देता।

यहाँ एक पूरा उदाहरण है:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
