# परिचय

## सही और गलत जैसी वैल्यू

Common Lisp में हर वैल्यू "सही" होती है, सिवाय `()` के, जो "गलत" होती है।
दो खास कॉन्स्टेंट सिंबल हैं, `t` और `nil`, जिनकी वैल्यू क्रमशः सही और गलत होती हैं।

## शर्त वाले एक्सप्रेशन

Common Lisp कई अलग-अलग शर्त वाले एक्सप्रेशन देता है। इनमें मुख्य अंतर यह है कि ये कितनी ब्रांच सपोर्ट करते हैं।

- `when` और `unless` सिर्फ एक ब्रांच की अनुमति देते हैं:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

टेस्ट एक्सप्रेशन के बाद वाले भाग में एक से अधिक एक्सप्रेशन हो सकते हैं।

- `if` क्लासिक if-then-else ढाँचा देता है:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

ध्यान दीजिए कि then और else, दोनों क्लॉज़ में सिर्फ एक ही एक्सप्रेशन हो सकता है।

- `cond` से कई ब्रांच बनाई जा सकती हैं, और इसके लिए `if` एक्सप्रेशन को नेस्ट करने की ज़रूरत नहीं होती:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

ध्यान दीजिए कि टेस्ट एक्सप्रेशन के बाद एक्सप्रेशन की संख्या की कोई सीमा नहीं है।

- `case` क्लासिक 'switch' शैली का ढाँचा देता है। यह एक वैल्यू की तुलना कई ब्रांचों से करता है:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

ध्यान दीजिए कि `cond` की तरह यहाँ भी टेस्ट एक्सप्रेशन के बाद एक्सप्रेशन की संख्या की कोई सीमा नहीं है।
