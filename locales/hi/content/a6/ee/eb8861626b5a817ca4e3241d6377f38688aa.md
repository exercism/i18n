# परिचय

Ruby एक डायनामिक और स्ट्रॉन्गली टाइप्ड भाषा है।
डायनामिक भाषाओं में किसी वेरिएबल या ऑब्जेक्ट का टाइप रनटाइम पर तय होता है, यानी उसकी वैल्यू या टाइप अंतिम पल तक बदले जा सकते हैं (जब उसे इंटरप्रेटर पार्स करता है)।
और स्ट्रॉन्गली टाइप्ड से हमारा क्या मतलब है?
जब हमें किसी वेरिएबल या ऑब्जेक्ट का टाइप पता चल जाता है, तो Ruby इस बात पर सख्त है कि आप उसके साथ क्या कर सकते हैं, जैसे:

```ruby
x = '2'
y = x + 'n'
# => '2n'
```

**लेकिन**

```ruby
x = '2'
y = x + 2
# => TypeError (no implicit conversion of Integer into String)
```

याद रखिए, Ruby में सब कुछ एक ऑब्जेक्ट है।
यहाँ तक कि क्लास भी `Class` क्लास के इंस्टेंस होती हैं।

उदाहरण के लिए:

```ruby
1.class
# => Integer

Integer.is_a?(Object)
# => true

Class.is_a?(Object)
# => true
```

इसका मतलब है कि हम क्लास इस तरह भी बना सकते हैं:

```ruby
Car = Class.new do
  def run
    'running'
  end
end

Car.new.run
# => 'running'
```

अंत में, ध्यान रखिए कि `Integer` ऑब्जेक्ट ऐसी वैल्यू रखता है जिन्हें एक या अधिक (लगातार) अंकों के रूप में लिखा जा सकता है, और उसके मेथड कई [गणितीय ऑपरेटरों][integers-docs] को सपोर्ट करते हैं।

[integers-docs]: https://docs.ruby-lang.org/en/master/Integer.html

~~~~exercism/note
डॉक्यूमेंटेशन में अक्सर इंस्टेंस मेथड का उल्लेख `Class#method_name` जैसे सिंटैक्स से किया जाता है, जबकि क्लास या मॉड्यूल लेवल के मेथड को `Class::method_name` के रूप में लिखा जाता है।
`::` को _स्कोप रेज़ोल्यूशन ऑपरेटर_ कहा जाता है, और यह उस कॉन्स्टेंट या मेथड को दिखाता है जिसका क्लास या मॉड्यूल लेवल पर संदर्भ दिया जा रहा हो।
आपको यह Ruby के डॉक्यूमेंटेशन में, मेलिंग लिस्ट में और दूसरे सपोर्ट क्षेत्रों में मिलेगा।
आप देखेंगे कि हम अपने लेखन में क्लास और मॉड्यूल मेथड को इसके बजाय `ClassName.method_name` या `ModuleName.method_name` के रूप में लिखते हैं।
~~~~
