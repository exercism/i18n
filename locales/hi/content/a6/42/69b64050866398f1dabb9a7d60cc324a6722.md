# इस बारे में

Go एक स्टैटिकली टाइप्ड भाषा है, इसलिए हर वेरिएबल का टाइप कंपाइल के समय ही तय हो जाता है।
एक बार घोषित होने के बाद वेरिएबल का टाइप बदल नहीं सकता।

## वेरिएबल बनाना

`var` स्टेटमेंट किसी नए वेरिएबल का टाइप घोषित कर सकता है, उसकी वैल्यू सेट कर सकता है, या दोनों एक साथ कर सकता है:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

किसी फंक्शन के अंदर `:=` शॉर्ट असाइनमेंट स्टेटमेंट भी इस्तेमाल किया जा सकता है।

```go
count := 1 // Type implictly declared, value explicitly set
```

Go में किसी वेरिएबल की वैल्यू हमेशा होती है।
अगर घोषणा के समय वैल्यू सेट नहीं की जाती, तो Go वेरिएबल के टाइप के आधार पर एक वैल्यू देता है, जिसे [ज़ीरो वैल्यू][zero-values] कहते हैं।

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## वेरिएबल की वैल्यू बदलना

किसी फंक्शन के अंदर `=` असाइनमेंट ऑपरेटर किसी मौजूदा वेरिएबल के लिए नई वैल्यू सेट कर सकता है:

```go
count := 1
count = 2
```

नई वैल्यू का टाइप वेरिएबल के टाइप जैसा ही होना चाहिए:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
