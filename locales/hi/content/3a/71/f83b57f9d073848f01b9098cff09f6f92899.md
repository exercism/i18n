# परिचय

पंप, वाल्व, होज़, इन जैसी कोई भी चीज़ जो ऑपरेटिंग सिस्टम का कोई संसाधन (खुली फाइल, नेटवर्क कनेक्शन) थामे रखती है, उसे काम पूरा हो जाने पर *मुक्त करना* पड़ता है। Factor का [`destructors`][destructors] वोकैब इन सबको एक ऐसे फ्रेमवर्क में लपेट देता है जो सफाई की गारंटी देता है, तब भी जब कोई एरर बीच में ही आपका कोड रोक दे।

## क्लास और जेनेरिक

एक क्लास `disposable` का विस्तार करके और `dispose*` जेनेरिक को लागू करके इस फ्रेमवर्क से जुड़ जाती है:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` टपल को बनाता है *और* उसे फ्रेमवर्क में दर्ज कर देता है। इस तरह बनाने और अगले सेफ पॉइंट के बीच आने वाला एक्सेप्शन संसाधन को लीक नहीं कर सकता। फ्रेमवर्क गारंटी देता है कि हर ऑब्जेक्ट के लिए `dispose*` **ज़्यादा से ज़्यादा एक बार** चलता है। बार-बार किए गए `dispose` कॉल का कोई असर नहीं होता।

## बाहरी कॉलर `dispose` इस्तेमाल करते हैं

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` एक ही संसाधन वाला रूप है: यह अंदर वाले कोटेशन के लिए डिस्पोज़ेबल को स्टैक पर रखता है और बाहर निकलते समय उसे मुक्त कर देता है।

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

एक से ज़्यादा संसाधनों के लिए `with-destructors` स्कोप खोलिए और हर बार लिए गए संसाधन को दर्ज कीजिए। `&dispose` (ऐम्परसैंड) का मतलब है "बाहर निकलते समय हमेशा संसाधन मुक्त करना, चाहे सफलता मिले या असफलता।" `|dispose` (पाइप) का मतलब है "सिर्फ़ असफलता पर मुक्त करना", जो तब काम आता है जब सफलता वाला रास्ता संसाधन को ऐसे कॉलर को सौंप देता है जो उसका मालिकाना ले लेगा।

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

बिना रजिस्ट्री के सादे try/finally के लिए [`cleanup`][cleanup] (जो `continuations` में है) निचले स्तर का प्रिमिटिव है, लेकिन `with-destructors` ही आधुनिक Factor का मुहावरेदार तरीका है।
