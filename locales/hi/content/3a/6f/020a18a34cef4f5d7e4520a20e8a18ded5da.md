# परिचय

C++ में बूलियन को `bool` टाइप से दर्शाया जाता है।
एक `bool` या तो `true` होता है या `false`.

## लॉजिकल ऑपरेटर

C++ तीन बूलियन ऑपरेटर का समर्थन करता है: `!` (नॉट), `&&` (एंड), और `||` (ऑर)।
आप वैकल्पिक रूपों `not`, `and`, और `or` का भी इस्तेमाल कर सकते हैं।

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## प्राथमिकता

तीनों बूलियन ऑपरेटरों की _ऑपरेटर प्राथमिकता_ अलग-अलग होती है।
परिणामस्वरूप, इनका मूल्यांकन इस क्रम में होता है: पहले `!`, फिर `&&`, और अंत में `||`.
अगर आप अलग क्रम लागू करना चाहते हैं, तो आप बूलियन एक्सप्रेशन को ब्रैकेट (यानी `()`) में बंद कर सकते हैं, क्योंकि ब्रैकेट की ऑपरेटर प्राथमिकता और भी अधिक होती है।

```cpp
!true && false   // => false
!(true and false) // => true
```

## रूपांतरण

अगर आप `true` या `false` का उपयोग ऐसी जगह करते हैं जहाँ एक संख्या की अपेक्षा होती है, तो वे क्रमशः `1` और `0` में बदल दिए जाएँगे।
अगर आप किसी बूलियन ऑपरेशन में संख्या का उपयोग करते हैं, तो `0` को छोड़कर सब कुछ `true` माना जाता है, ऋणात्मक वैल्यू भी।

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
