# परिचय

## कीवर्ड ऐरे

कीवर्ड ऐरे एक की-वैल्यू डेटा स्ट्रक्चर है।

```elixir
[month: "April", year: 2018]
```

कीवर्ड ऐरे, `{key, value}` [टुपलों][exercism-tuples] का ऐरे होते हैं, और इन्हें इसी तरह भी लिखा जा सकता है, लेकिन छोटा सिंटैक्स ज़्यादा इस्तेमाल किया जाता है।

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

कीवर्ड ऐरे में की एटम होनी चाहिए, लेकिन वैल्यू कुछ भी हो सकती हैं। हर की को एक से अधिक बार इस्तेमाल किया जा सकता है। कीवर्ड ऐरे में की-वैल्यू जोड़े क्रम में रहते हैं।

आप कीवर्ड ऐरे के साथ ऐरे जैसे ही तरीके अपना सकते हैं, या `Keyword` मॉड्यूल का इस्तेमाल कर सकते हैं।
