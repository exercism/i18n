# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग | टाइप | विवरण |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | इनपुट     | पूर्णांक | श्रेणी: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | इनपुट     | एड्रेस | पासे (वर्ड ऐरे)                                          |
| `$v0`    | आउटपुट    | पूर्णांक | परिणामी स्कोर                                            |
| `$t0-9`  | अस्थायी   | कोई भी  | अस्थायी भंडारण के लिए उपयोग किया जाता है                                 |
