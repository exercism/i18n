# परिचय

**यूज़र-डिफाइंड** फंक्शन `function` कीवर्ड की मदद से बनाए जाते हैं। इस कीवर्ड के बाद फंक्शन का नाम और आर्गुमेंट की सूची लिखनी होती है।

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

किसी फाइल में फंक्शन को उसके बनाए जाने से पहले भी कॉल किया जा सकता है, क्योंकि फंक्शन अपने स्कोप के सबसे ऊपर उठा दिए जाते हैं।

## नामकरण

PHP में फंक्शन के नाम बाकी लेबल के नियमों का ही पालन करते हैं: नाम की शुरुआत अंडरस्कोर या किसी अक्षर से होनी चाहिए, और उसके बाद कितने भी अक्षर, संख्याएँ या अंडरस्कोर आ सकते हैं।
