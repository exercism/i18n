# परिचय

Kotlin में [`string`][ref-string] यूनिकोड अक्षरों का एक अपरिवर्तनीय क्रम है।

[`Immutable`][wiki-immutable] का मतलब है कि स्ट्रिंग पर किया गया कोई भी ऑपरेशन एक नई स्ट्रिंग ही लौटाता है: मूल स्ट्रिंग कभी नहीं बदल सकती।

[`Unicode`][wiki-unicode] का मतलब है कि दुनिया की अधिकांश लेखन प्रणालियों को दर्शाया जा सकता है, लेकिन C जैसी पुरानी भाषाओं के विपरीत, अक्षरों और बाइट्स के बीच 1:1 संबंध नहीं होता।

स्ट्रिंग को दोहरे उद्धरण चिह्न `" "` के बीच लिखा जाता है।

कुछ अक्षरों के लिए एस्केप की ज़रूरत पड़ती है: `\\`, साथ ही `\t` (टैब) और `\n` (न्यूलाइन) जैसे आम नॉन-प्रिंटिंग अक्षर।

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

मल्टी-लाइन स्ट्रिंग को तीन दोहरे उद्धरण चिह्नों के बीच लिखा जाता है, और इसमें कोई भी टेक्स्ट हो सकता है (एस्केप की ज़रूरत नहीं)।

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

पंक्तियों से सामान्य इंडेंटेशन हटाने के लिए [trimIndent][trimIndent-doc] का उपयोग कीजिए।
यह स्ट्रिंग को फॉर्मेट करने में उपयोगी है:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

या फिर, [trimMargin][trimMargin-doc] से आप एक डेलिमिटर तय कर सकते हैं।
तब `String` की हर पंक्ति उस डेलिमिटर के बाद से शुरू होती है।
डेलिमिटर का डिफॉल्ट `|` होता है, लेकिन आप पैरामीटर के रूप में कोई दूसरा डेलिमिटर दे सकते हैं।
उदाहरण:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

स्ट्रिंग को `+` से जोड़ा जा सकता है, लेकिन इसे सिर्फ़ छोटे और आसान मामलों तक ही सीमित रखना बेहतर है।
दूसरे और अक्सर बेहतर विकल्प भी मौजूद हैं।

## स्ट्रिंग टेम्पलेट

यह वही चीज़ है जिसे कुछ अन्य भाषाएँ "इंटरपोलेशन" कहती हैं।

अगर किसी स्ट्रिंग में डॉलर चिह्न `$` के बाद कोई आइडेंटिफायर आता है, या किसी एक्सप्रेशन के चारों ओर घुंघराले ब्रैकेट (`{expression}`) होते हैं, तो उनके स्थान पर क्रमशः उस वैल्यू या उस एक्सप्रेशन का परिणाम रख दिया जाता है।

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

जहाँ बिना घुंघराले ब्रैकेट के पार्सिंग अस्पष्ट हो जाती, वहाँ एक्सप्रेशन के चारों ओर घुंघराले ब्रैकेट `{ }` लगाना ज़रूरी है।

आम तौर पर, स्ट्रिंग जोड़ने के लिए `+` इस्तेमाल करने की तुलना में स्ट्रिंग टेम्पलेट का उपयोग अधिक कुशल और स्वाभाविक तरीका है।

## स्ट्रिंग फंक्शन

Kotlin में स्ट्रिंग पर काम करने के लिए _बहुत सारे_ [`functions`][ref-string-functions] मौजूद हैं।

अधिकतर ये `String` क्लास के मेंबर नहीं, बल्कि [`extensions functions`][ref-extensions] होते हैं। हालाँकि हम उन्हें कैसे इस्तेमाल करते हैं, उस पर इसका खास असर नहीं पड़ता।

~~~~exercism/note
Kotlin के काफी जटिल [डॉक्यूमेंटेशन][ref-string-functions] पेज डिफॉल्ट व्यू में एक्सटेंशन फंक्शन छिपा देते हैं।
इस सेक्शन को खोलने के लिए `Members & Extensions` पर ज़रूर क्लिक कीजिए।

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

आगे दिए उदाहरण उपलब्ध चीज़ों में से सिर्फ़ एक छोटा-सा हिस्सा दिखाते हैं:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
