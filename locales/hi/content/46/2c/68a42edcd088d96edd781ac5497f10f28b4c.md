# निर्देश

इस अभ्यास में आप हाई स्कूल के प्रेमी जोड़ों को सोशल मीडिया पर अपना प्यार जताने में मदद करेंगे। इसके लिए आप उनके नाम के पहले अक्षरों से एक ASCII दिल बनाएँगे:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. नाम का पहला अक्षर निकालिए

`first_letter` फंक्शन लिखिए। यह एक नाम लेता है और उसका पहला अक्षर लौटाता है। यह नाम से सारी अनावश्यक व्हाइटस्पेस हटा देता है।

```gleam
first_letter("Jane")
// -> "J"
```

## 2. पहले अक्षर को इनिशियल के रूप में तैयार कीजिए

`initial` फंक्शन लिखिए। यह एक नाम लेता है और उसका पहला अक्षर लौटाता है। पहला अक्षर बड़े अक्षर में होता है और उसके बाद एक बिंदु लगा होता है। ध्यान रखिए कि आप पिछले चरण में बनाए गए `first_letter` को ही दोबारा इस्तेमाल करें।

```gleam
initial("Robert")
// -> "R."
```

## 3. पूरे नाम को पहले नाम और अंतिम नाम में बाँटिए

`initials` फंक्शन लिखिए। यह एक पूरा नाम लेता है, जिसमें पहला नाम और अंतिम नाम एक स्पेस से अलग किए होते हैं, और उनके इनिशियल लौटाता है। ध्यान रखिए कि आप पिछले चरण में बनाए गए `initial` को ही दोबारा इस्तेमाल करें।

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. इनिशियल को दिल के अंदर रखिए

`pair` फंक्शन लिखिए। यह दो पूरे नाम लेता है और उनके इनिशियल एक ASCII दिल के अंदर लौटाता है। ध्यान रखिए कि आप पिछले चरण में बनाए गए `initials` को ही दोबारा इस्तेमाल करें।

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
