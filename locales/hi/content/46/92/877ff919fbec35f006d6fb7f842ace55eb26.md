# निर्देश

सामुदायिक कला केंद्र का मोज़ेक पिछले महीने लगकर तैयार हुआ था, और अब Magpie Marg ने उसे ढूँढ लिया है। अधिकतर दिनों में वह पास रखे अपने **भंडार** से एक-दो टाइल निकालकर उनकी जगह ज़्यादा चमकदार टाइलें लगा देती है। कभी कोई टाइल उखाड़कर एक घंटे के लिए गायब हो जाती है।

हर बदलाव दर्ज करने वाले स्वयंसेवक आप हैं। मोज़ेक खुद एक **तय आकार का ऐरे** है। मोज़ेक में हर टाइल की जगह के लिए एक खाना होता है, और उस खाने में रंग की स्ट्रिंग रखी जाती है, या टाइल के गायब होने पर `f`.

Magpie Marg का भंडार एक **वेक्टर** है, जिसमें उसके चुराए हुए ढीले टाइल रखे हैं।

## 1. एक नई पंक्ति तैयार कीजिए

ऐसा `fresh-mosaic` बनाइए जो एक लंबाई `n` लेता है और `n` खाली खानों का ऐरे लौटाता है (हर खाने में `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. एक टाइल रखिए

ऐसा `place-tile` बनाइए जो एक पंक्ति, एक स्थान और एक रंग लेता है, और उस पंक्ति को मौके पर ही ऐसे बदल देता है कि बताए गए स्थान पर वह रंग आ जाए। यह शब्द कुछ भी नहीं लौटाता।

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. एक टाइल निकालिए

ऐसा `chip-tile` बनाइए जो एक पंक्ति और एक स्थान लेता है, और उस पंक्ति को मौके पर ही ऐसे बदल देता है कि बताया गया स्थान फिर से `f` हो जाए।

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. टाइल का रंग बदलिए

ऐसा `recolour-tile` बनाइए जो एक पंक्ति, एक स्थान और एक आर्गुमेंट लेने वाला कोटेशन लेता है, और उस स्थान पर रखी टाइल पर कोटेशन लगाकर पंक्ति को मौके पर ही बदल देता है।

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Marg के आने से पहले का स्नैपशॉट

ऐसा `snapshot-mosaic` बनाइए जो एक पंक्ति लेता है और उसकी एक स्वतंत्र प्रतिलिपि लौटाता है, जिस पर मूल पंक्ति में बाद में किए गए बदलावों का असर नहीं पड़ेगा।

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg एक टाइल जेब में डालती है

ऐसा `stash-tile` बनाइए जो Marg का भंडार (एक वेक्टर) और एक रंग लेता है, और भंडार के अंत में वह रंग जोड़ देता है। कुछ नहीं लौटाता।

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg एक टाइल वापस कर देती है

ऐसा `return-tile` बनाइए जो Marg का भंडार लेता है और सबसे हाल में जोड़ी गई टाइल (यानी सबसे ऊपर वाली) को भंडार से हटाकर लौटाता है।

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
