# Cairo में मॉड्यूल और पाथ

Cairo कोड को व्यवस्थित करने के लिए **मॉड्यूल** का उपयोग करता है।

मॉड्यूल प्रोजेक्ट को व्यवस्थित करने और फंक्शन, स्ट्रक्ट और ट्रेट जैसी चीज़ों की दृश्यता नियंत्रित करने में मदद करते हैं।

## मॉड्यूल बनाना

मॉड्यूल `mod` से बनाए जाते हैं और इन्हें नेस्टेड किया जा सकता है:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

फंक्शन, स्ट्रक्ट और ट्रेट डिफ़ॉल्ट रूप से **निजी** होते हैं।

उन्हें उनके मॉड्यूल के बाहर से इस्तेमाल करने योग्य बनाने के लिए `pub` का उपयोग कीजिए।

## पाथ: एब्सोल्यूट बनाम रिलेटिव

किसी दूसरे मॉड्यूल में किसी चीज़ को रेफ़र करने के लिए आप इनका उपयोग कर सकते हैं:

- **एब्सोल्यूट पाथ** (`crate::` से शुरू होने वाले):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **रिलेटिव पाथ** (मौजूदा मॉड्यूल से शुरू होने वाले):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  यह तब काम करता है जब `front_of_house` उसी मॉड्यूल में हो।

## `use` की मदद से मॉड्यूल को स्कोप में लाना

पूरे पाथ बार-बार लिखना असुविधाजनक होता है।

`use` कीवर्ड से छोटे रेफ़रेंस लिखे जा सकते हैं:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` **केवल उसी स्कोप में लागू होता है जहाँ वह लिखा गया है**। अगर कहीं और ज़रूरत हो, तो इसे दोहराना पड़ता है।

### `use` का सहज उपयोग

- स्कोप में **मॉड्यूल** लाइए, फंक्शन नहीं:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  इसके बजाय:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- **ट्रेट, स्ट्रक्ट और एनम** के लिए पूरा पाथ इस्तेमाल कीजिए:

  ```rust
  use core::num::traits::BitSize;
  ```

### `as` के साथ एलियास

ज़रूरत पड़ने पर इम्पोर्ट का नाम बदलिए:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### एक से ज़्यादा चीज़ें इम्पोर्ट करना

कई `use` स्टेटमेंट लिखने के बजाय इम्पोर्ट को एक साथ लिखिए:

```rust
use shapes::{Square, Circle, Triangle};
```

## `pub use` से फिर से एक्सपोर्ट करना

किसी मॉड्यूल को किसी दूसरी संरचना में दिखाने के लिए `pub use` का उपयोग कीजिए:

```rust
pub use crate::front_of_house::hosting;
```

अब बाहरी कोड `restaurant::front_of_house::hosting::add_to_waitlist()` के बजाय `restaurant::hosting::add_to_waitlist()` का उपयोग कर सकता है।

## Scarb के साथ बाहरी पैकेज का उपयोग

कोई डिपेंडेंसी जोड़ने के लिए `Scarb.toml` को अपडेट कीजिए:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

डिपेंडेंसी जोड़ने के लिए `scarb add <package>` और हटाने के लिए `scarb rm <package>` का उपयोग कीजिए।

## ग्लोब ऑपरेटर (`*`)

किसी मॉड्यूल से सब कुछ इम्पोर्ट करने के लिए:

```rust
use core::num::traits::*;
```

इसका उपयोग सावधानी से करना चाहिए, क्योंकि इससे कोड पढ़ना मुश्किल हो सकता है।
