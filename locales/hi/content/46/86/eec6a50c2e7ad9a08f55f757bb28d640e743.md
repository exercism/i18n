# परिचय

Swift एक कंपाइल की जाने वाली, बहु-प्रतिमान प्रोग्रामिंग भाषा है। इसे बनाते समय तीन मुख्य उद्देश्य सामने रखे गए थे:

- **सुरक्षा**: भाषा में पहले से मौजूद सुविधाएँ आपके कोड के प्रोडक्शन में चलने से पहले ही बग पकड़ने और उनसे बचने में मदद करती हैं।
- **गति**: C पर आधारित भाषाओं के बराबर अनुकूलित प्रदर्शन।
- **अभिव्यक्ति क्षमता**: साफ़-सुथरा और आधुनिक सिंटैक्स, जिसे पढ़ना-लिखना दोनों आसान और आनंददायक है।

Apple ने 2014 में Swift को पेश किया। यह Objective-C का आधुनिक विकल्प था, जो पहले iOS और macOS डेवलपमेंट के लिए इस्तेमाल होने वाली भाषा थी। आज Swift ओपन सोर्स है और Apple के प्लेटफॉर्म, Linux तथा Windows पर चलता है।

## शुरुआत

### वेरिएबल

आप किसी [वेरिएबल][constants-variables] को बनाकर वैल्यू को संग्रहीत कर सकते हैं और उसे नाम दे सकते हैं।
वेरिएबल बनाने के बाद आप उसका नाम लेकर पूरे कोड में उस वैल्यू को दर्शा सकते हैं।
वेरिएबल _म्यूटेबल_ होते हैं, यानी बनने के बाद उनकी वैल्यू बदल सकती है।

किसी वेरिएबल को `var` कीवर्ड से बनाइए:

```swift
var variableName = 10
```

Swift एक स्टैटिक टाइप वाली भाषा है, यानी कंपाइल के समय हर वैल्यू का टाइप पता होता है।
आप [टाइप एनोटेशन][type annotations] की मदद से टाइप स्पष्ट रूप से घोषित कर सकते हैं, या Swift कंपाइलर को असाइन की गई वैल्यू से [टाइप का अनुमान लगाने][type-inferring] दे सकते हैं:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

असाइनमेंट ऑपरेटर (`=`) की मदद से आप वेरिएबल की वैल्यू बदल सकते हैं:

~~~~exercism/note
वेरिएबल का टाइप एक बार घोषित होने के बाद बदला नहीं जा सकता।

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

आप टाइप बताकर बिना शुरुआती वैल्यू के भी वेरिएबल घोषित कर सकते हैं, लेकिन उसका उपयोग करने से पहले आपको उसमें वैल्यू असाइन करनी होगी:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### कॉन्स्टेंट

[कॉन्स्टेंट][constants-variables] भी किसी नाम को एक वैल्यू से जोड़ते हैं, लेकिन असाइन करने के बाद उनकी वैल्यू बदली नहीं जा सकती।
वे _इम्यूटेबल_ होते हैं।
किसी कॉन्स्टेंट को `let` कीवर्ड से बनाइए:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### अंकगणितीय ऑपरेटर

Swift बुनियादी गणित के लिए मानक [अंकगणितीय ऑपरेटर][arithmetical-operators] देता है:

- जोड़: `+`
- घटाव: `-`
- गुणा: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### फंक्शन

Swift में [फंक्शन][functions] कोड के ऐसे ब्लॉक होते हैं जो अपने आप में पूरे होते हैं और कोई खास काम करते हैं।
फंक्शन इनपुट ले सकते हैं, कोई वैल्यू लौटा सकते हैं, और उन्हें वैल्यू की तरह दूसरे फंक्शन को दिया जा सकता है।
किसी फंक्शन को `func` कीवर्ड से बनाइए। उसके बाद फंक्शन का नाम, ब्रैकेट के अंदर पैरामीटर की सूची, और ज़रूरत पड़ने पर रिटर्न टाइप लिखिए:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift के फंक्शन [आर्गुमेंट लेबल][argument-labels] इस्तेमाल करते हैं, जिनसे कोड सामान्य वाक्यों की तरह पढ़ा जाता है:

- फंक्शन को कॉल करते समय **आर्गुमेंट लेबल** का उपयोग होता है।
- फंक्शन के अंदर वैल्यू तक पहुँचने के लिए **पैरामीटर नाम** का उपयोग होता है।

अगर आप सिर्फ़ एक नाम लिखते हैं, तो Swift उसी को आर्गुमेंट लेबल और पैरामीटर नाम दोनों की तरह इस्तेमाल करता है:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

अगर फंक्शन को कॉल करते समय आप आर्गुमेंट लेबल नहीं चाहते, तो पैरामीटर नाम से पहले अंडरस्कोर (`_`) लिखिए:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

डिफॉल्ट रूप से फंक्शन के सारे पैरामीटर कॉन्स्टेंट (`let`) होते हैं, यानी फंक्शन के अंदर उनकी वैल्यू बदली नहीं जा सकती।

किसी फंक्शन से वैल्यू लौटाने के लिए `->` के बाद रिटर्न टाइप लिखिए और `return` कीवर्ड का उपयोग कीजिए:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

जब कोई फंक्शन कोई वैल्यू नहीं लौटाता, तो उसका रिटर्न टाइप `Void` होता है, जो खाली टपल `()` के बराबर है।
ऐसे फंक्शन में आप `-> Void` रिटर्न टाइप और `return` स्टेटमेंट, दोनों छोड़ सकते हैं।

### कमेंट

Swift में [कमेंट][comments] के दो रूप होते हैं:

- **सिंगल-लाइन कमेंट** `//` से शुरू होते हैं और लाइन के अंत तक चलते हैं।
- **मल्टीलाइन कमेंट** `/*` और `*/` के बीच लिखे जाते हैं।

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
