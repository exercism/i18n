# निर्देश

आप एक छोटे द्वीप की फेरी की समय-सारणी रखते हैं। फेरी यात्राएँ तारीखों के रूप में दर्ज की जाती हैं, और इनके साथ काम करने के लिए आपको कुछ मददगार फंक्शन चाहिए।

## 1. फेरी यात्रा की तारीख दर्ज कीजिए

`make-date` ऐसा फंक्शन बनाइए जो एक साल, महीना और दिन लेकर उसके अनुरूप टाइमस्टैम्प लौटाता है।

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. हफ्ते के दिन का नाम बताइए

`weekday-name` ऐसा फंक्शन बनाइए जो किसी फेरी यात्रा का टाइमस्टैम्प लेकर उस दिन का नाम लौटाता है जिस दिन वह पड़ती है।

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. लीप वर्ष

`leap?` ऐसा फंक्शन बनाइए जो एक साल लेता है और लौटाता है कि वह लीप वर्ष है या नहीं।

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. महीने के दिन

`month-length` ऐसा फंक्शन बनाइए जो एक साल और एक महीना लेकर उस महीने के दिनों की संख्या लौटाता है (फरवरी का ध्यान रखिए)।

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. कुछ दिन बाद

`add-days` ऐसा फंक्शन बनाइए जो एक टाइमस्टैम्प और दिनों की एक संख्या लेकर उतने दिन बाद का टाइमस्टैम्प लौटाता है।

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
