# परिचय

C++ में कंडीशनल दूसरी भाषाओं के कंडीशनल जैसे ही होते हैं।
किसी भी कंडीशनल ऑपरेशन का मूल टाइप `bool` होता है, जिसकी वैल्यू `true` या `false` हो सकती है।
अलग-अलग शर्तें जाँचने के लिए कंडीशनल का उपयोग अक्सर फ्लो कंट्रोल के तरीके के रूप में किया जाता है।

आप `if` स्टेटमेंट का इस्तेमाल कर सकते हैं, जो अपना कोड तभी चलाता है जब शर्त `true` हो। जैसे:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

जब एक से अधिक स्थितियाँ सामने हों, तो कई `if` स्टेटमेंट को `else if` और `else` स्टेटमेंट की मदद से एक के बाद एक जोड़ा जा सकता है।

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17 से `if` स्टेटमेंट में एक छोटा इनिशलाइज़ेशन स्टेटमेंट भी लिखा जा सकता है, जिसका उपयोग `if` स्टेटमेंट के लिए एक या अधिक वेरिएबलो को इनिशलाइज़ करने में किया जा सकता है।
उदाहरण के लिए:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> ध्यान दें: इनिशलाइज़ेशन में बने वेरिएबलो को `if` स्टेटमेंट के अंत के बाद इस्तेमाल नहीं किया जा सकता।
