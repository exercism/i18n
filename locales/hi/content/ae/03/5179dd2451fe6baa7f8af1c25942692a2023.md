# परिचय

Haxe में किसी वैल्यू पर `for` लूप की मदद से एक-एक करके चलने के लिए इटरेटर का उपयोग किया जाता है। इटरेटर दो तरह के होते हैं:

- `Iterator`, जो किसी वैल्यू पर एक-एक करके चलता है।
- `Iterable` डेटा, जिससे किसी डेटा टाइप पर एक-एक करके चलना संभव हो जाता है।

इन दोनों कॉन्सेप्ट को `Iterator<T>` और `Iterable<T>` से दर्शाया जाता है:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

कोई भी क्लास जो इनमें से किसी एक टाइप से मेल खाती है, उस पर `for` लूप की मदद से एक-एक करके चलाया जा सकता है। अगर कोई क्लास `hasNext` और `next` मेथड बनाती है, तो उसे इटरेटर माना जाता है; वरना अगर वह `iterator` मेथड बनाती है, तो उसे इटरेबल टाइप माना जाता है।
