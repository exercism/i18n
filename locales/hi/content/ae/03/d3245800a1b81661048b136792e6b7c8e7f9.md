Haxe में [बूलियन][booleans] को `Bool` टाइप से दर्शाया जाता है, जिसकी वैल्यू या तो `true` हो सकती है या `false`।

Haxe तीन बूलियन ऑपरेटर का समर्थन करता है: `!` (यूनरी नॉट), `&&` (बाइनरी ऐंड), और `||` (बाइनरी ऑर)।

संयुक्त बूलियन एक्सप्रेशन (`&&` और `||`) _शॉर्ट-सर्किट_ मूल्यांकन का उपयोग करते हैं। इसमें एक्सप्रेशन का मूल्यांकन बाएँ से दाएँ होता है, लेकिन सिर्फ उतना ही जितना ज़रूरी होता है। यह कुछ स्थितियों में बहुत मायने रखता है, जैसे इस उदाहरण में:

```haxe
object != null && object.field == x
```

पहली बूलियन जाँच यह सुनिश्चित करती है कि `object.field` तभी पढ़ा जाए जब `object` `null` न हो, और इस तरह रनटाइम एरर से बचाव होता है।

तीनों बूलियन ऑपरेटर की [प्राथमिकता][precedence] अलग-अलग होती है और इनका मूल्यांकन इस क्रम में होता है: `!` -> `&&` -> `||`।

एक्सप्रेशन को गोल ब्रैकेट `()` में रखने से इन प्राथमिकता के नियमों को बदला जा सकता है, क्योंकि ब्रैकेट की प्राथमिकता इनसे ऊँची होती है।

```haxe
!true && false   // => false
!(true && false) // => true
```
