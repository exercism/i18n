# निर्देश

इस अभ्यास में आप एक इन्वेंटरी सिस्टम संभालेंगे।

इन्वेंटरी को आइटम के नाम के अनुसार व्यवस्थित किया जाना चाहिए, और उसमें उपलब्ध आइटमों की संख्या का हिसाब रखा जाना चाहिए।

आपको इन्वेंटरी में आइटम जोड़ने का काम भी करना होगा।
जब भी कोई आइटम दिए गए वेक्टर में आता है, इन्वेंटरी में उस आइटम की मात्रा `1` से बढ़ाई जानी चाहिए।
इसी तरह, अनुरोध मिलने पर मात्राएँ `1` से घटाकर आपको इन्वेंटरी से आइटम हटाने भी होंगे।

अंत में, आपको एक ऐसा फंक्शन बनाना होगा जो दी गई इन्वेंटरी के सारे की-वैल्यू जोड़ों को `pair` के `vector` के रूप में लौटाए।

~~~~exercism/note
इस अभ्यास के टेस्ट इस बात पर निर्भर नहीं करते कि इनपुट बदला जाता है या नहीं, लेकिन फंक्शनों के नाम बताते हैं कि उन्हें इनपुट नहीं बदलना चाहिए।
अगर आप इनपुट को बदले बिना परिचय में बताए गए फंक्शन इस्तेमाल करना चाहते हैं, तो `copy()` फंक्शन काम आएगा।
~~~~

## 1. वेक्टर के आधार पर इन्वेंटरी बनाइए

`create_inventory(<input vector>)` फंक्शन बनाइए, जो आइटम के इनपुट वेक्टर से एक "इन्वेंटरी" तैयार करता है।
यह एक `dict` लौटाता है जिसमें हर आइटम का नाम उसकी अपनी मात्रा के साथ जुड़ा होता है।

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. किसी मौजूदा डिक्शनरी में वेक्टर से आइटम जोड़िए

`add_items(<inventory dict>, <item vector>)` फंक्शन बनाइए, जो दी गई इन्वेंटरी में आइटम का एक वेक्टर जोड़ता है:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. इन्वेंटरी से आइटम घटाइए

`decrement_items(<inventory dict>, <items vector>)` फंक्शन बनाइए, जो आइटम का एक `vector` लेता है।
आपके फंक्शन को उस आइटम की गिनती में से `1` घटाना चाहिए, जितनी बार वह आइटम `vector` में आता है:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

इन्वेंटरी में किसी आइटम की गिनती 0 से नीचे नहीं जानी चाहिए।
अगर कोई आइटम इनपुट `vector` में उपलब्ध गिनती से ज़्यादा बार आता है, तो उस आइटम के लिए दर्ज मात्रा 0 ही रहनी चाहिए।
एक बार गिनती शून्य हो जाने पर घटाने के और अनुरोध माने नहीं जाने चाहिए।

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. इन्वेंटरी से कोई प्रविष्टि पूरी तरह हटाइए

`remove_item(<inventory dict>, <item>)` फंक्शन बनाइए, जो किसी आइटम को और उसकी गिनती को इन्वेंटरी से पूरी तरह हटा देता है:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

अगर वह आइटम इन्वेंटरी में न मिले, तो फंक्शन को बिना कुछ बदले मूल इन्वेंटरी लौटानी चाहिए।

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. इन्वेंटरी की पूरी सामग्री लौटाइए

`list_inventory(<inventory dict>)` फंक्शन बनाइए, जो एक इन्वेंटरी लेता है और `(item, quantity)` जोड़ों का एक वेक्टर लौटाता है।

इस वेक्टर में सिर्फ _उपलब्ध_ आइटम (_यानी जिनकी मात्रा शून्य से अधिक हो_) शामिल होने चाहिए, और ये आइटमों के वर्णानुक्रम में क्रमबद्ध होने चाहिए:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
