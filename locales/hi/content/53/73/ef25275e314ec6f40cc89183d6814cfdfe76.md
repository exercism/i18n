# इसके बारे में

किसी सीक्वेंस पर एक-एक करके चलते समय कभी-कभी सिर्फ एलिमेंट से काम नहीं चलता, आपको उसका स्थान भी चाहिए होता है। Factor के *इंडेक्स वाले* इटरेशन वर्ड हर एलिमेंट के कोटेशन को ये दोनों चीज़ें देते हैं, और इंडेक्स स्टैक के सबसे ऊपर रहता है। `times` इनसे जुड़ा वर्ड है, जो बिना किसी सीक्वेंस के, तय गिनती में इटरेशन करता है।

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| वर्ड         | इफ़ेक्ट                                                              |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, पर नीचे देखिए                               |

`times` की एक बारीकी है: हालाँकि इसके कोटेशन का इफ़ेक्ट `( -- )` बताया गया है, लेकिन यह वर्ड `inline` है। इसलिए `( str -- str )` जैसा संतुलित इफ़ेक्ट वाला कोटेशन भी ठीक से काम करता है और स्टैक को एक इटरेशन से अगले तक ले जाता है। इससे आपको बदलने योग्य स्थिति के बिना ही एक गिनती वाला एक्युमुलेटर मिल जाता है:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

यही तरीका `each-index` और `map-index` के लिए भी चलता है: हर एलिमेंट के लिए बताया गया इफ़ेक्ट एक *न्यूनतम* है, कोई अधिकतम नहीं।
