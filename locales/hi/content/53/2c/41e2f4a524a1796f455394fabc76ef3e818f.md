# स्ट्रिंग

स्ट्रिंग अक्षरों की एक श्रृंखला होती है, जिसे कोट्स के बीच लिखा जाता है।
सिंगल और डबल, दोनों तरह के कोट्स इस्तेमाल किए जा सकते हैं।

```php
<?php

$where = "Spain";
$what = 'rain';
```

## स्ट्रिंग में वेरिएबल का विस्तार

डबल कोट वाली स्ट्रिंग में, अगर किसी वेरिएबल का इस्तेमाल तब किया जाए जब वह स्कोप में हो, तो उसकी वैल्यू स्ट्रिंग में जोड़ दी जाती है।

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## अक्षर एन्कोडिंग का समर्थन

पहले PHP के स्ट्रिंग फंक्शन सिर्फ ASCII अक्षरों का समर्थन करते थे और आधुनिक Unicode एन्कोडिंग का समर्थन नहीं करते थे।
ASCII के हर अक्षर का आकार 1 बाइट होता है, जबकि Unicode अक्षरों की लंबाई 1 से 4 बाइट तक हो सकती है।
अगर Unicode स्ट्रिंग को सुरक्षित तरीके से संभालना हो, तो इन पुराने फंक्शनों के [मल्टीबाइट संस्करणों][multi-byte-fns] को देखिए।

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
