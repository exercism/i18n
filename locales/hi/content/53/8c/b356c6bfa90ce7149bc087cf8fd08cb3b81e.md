# इंस्टॉलेशन

## Clojure CLI इंस्टॉल करना

Clojure कमांड लाइन टूल उपलब्ध कराता है, जिनकी मदद से आप ये काम कर सकते हैं: एक इंटरैक्टिव REPL (Read-Eval-Print Loop) चलाना, Clojure प्रोग्राम चलाना, और Clojure एक्सप्रेशन का मूल्यांकन करना।
हमारा सुझाव है कि अभ्यासों के लिए आप Clojure CLI का इस्तेमाल कीजिए। [Clojure CLI](https://clojure.org/guides/deps_and_cli) इंस्टॉल करने के लिए:

### Windows
Windows पर इंस्टॉल करने के निर्देशों के लिए देखिए: [Clojure CLI इंस्टॉलेशन](https://clojure.org/guides/getting_started#_installation_on_windows)।

### Linux
ज़्यादातर प्लेटफॉर्म पर इंस्टॉल करने के निर्देशों के लिए देखिए: [Clojure CLI इंस्टॉलेशन](https://clojure.org/guides/getting_started#_installation_on_linux)।

### Mac OS X के लिए Homebrew
अपना Homebrew अपडेट कीजिए:

``` bash
$ brew update
```

Clojure CLI इंस्टॉल कीजिए:
``` bash
$ brew install node clojure/tools/clojure
```

node वातावरण के लिए `Node` ज़रूरी है।

## इंस्टॉलेशन की जाँच

इंस्टॉलेशन सही हुआ है या नहीं, यह जाँचने के लिए `clojure --help` चलाइए। अगर सब कुछ ठीक रहा, तो `clojure --help` आपको वर्ज़न दिखा देगा।

```bash
$ clojure --help
Version: 1.10.1.547
...
```
