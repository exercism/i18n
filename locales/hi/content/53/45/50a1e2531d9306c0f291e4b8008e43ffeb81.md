# निर्देश परिशिष्ट

## रजिस्टर

| Register | Usage        | Type    | Description                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | वह प्राकृतिक संख्या जिसके गुणनखंड निकालने हैं |
| `$a1`    | इनपुट/आउटपुट | एड्रेस  | अभाज्य गुणनखंडों के लिए गंतव्य ऐरे   |
| `$v0`    | आउटपुट       | पूर्णांक | गुणनखंडों की संख्या                 |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए उपयोग किया जाता है |
