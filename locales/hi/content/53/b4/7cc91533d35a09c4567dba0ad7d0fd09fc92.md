# रेंज

[रेंज][range] दो वैल्यू के बीच के अंतराल को दर्शाती हैं।
रेंज को सपोर्ट करने वाले सबसे आम टाइप `Integer` और `String` हैं।
इनका उपयोग कई तरह के कामों के लिए किया जा सकता है, जैसे कोई कलेक्शन जल्दी से बनाना, स्ट्रिंग को काटना, यह जाँचना कि कोई वैल्यू रेंज के अंदर है या नहीं, और इटरेशन करना।
इन्हें रेंज ऑपरेटर `..` या `...` की मदद से बनाया जाता है (`..` अंतिम वैल्यू को शामिल करता है और `...` नहीं करता)।

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

दो रेंज ऑपरेटर होने की वजह यह है कि इससे ऐसी रेंज बनाई जा सकती हैं जिनमें अंतिम वैल्यू शामिल हो या न हो। यह तब काम आता है, जब आप शून्य से शुरू होने वाले इंडेक्स के साथ काम कर रहे हों।

रेंज को `Range` इनिशलाइज़र की मदद से भी बनाया जा सकता है।

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
जब आप Ruby में `..` या `...` रेंज ऑपरेटर की मदद से कोई रेंज बनाते हैं और उस रेंज पर कोई मेथड कॉल करना चाहते हैं, तो आपको रेंज को ब्रैकेट में लपेटना पड़ता है।
ऐसा इसलिए है, क्योंकि ऐसा न करने पर वह मेथड रेंज ऑपरेटर के दूसरे आर्गुमेंट पर कॉल हो जाता है।

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## सबस्ट्रिंग निकालना

जब आप किसी स्ट्रिंग को काटकर उसका कोई हिस्सा निकालना चाहते हैं, तो सबस्ट्रिंग पाने के लिए रेंज ऑपरेटर का उपयोग कर सकते हैं। यानी सबस्ट्रिंग के शुरू और अंत वाले इंडेक्स से एक रेंज बनाकर।

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

स्ट्रिंग के अंत से सबस्ट्रिंग पाने के लिए आप ऋणात्मक इंडेक्स का भी उपयोग कर सकते हैं।

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## रेंज के मेथड

रेंज के साथ काम करने के लिए उनमें कई मेथड होते हैं। जैसे इन मेथड की मदद से आप रेंज की सारी वैल्यू का जोड़ निकाल सकते हैं या यह जाँच सकते हैं कि कोई वैल्यू रेंज में शामिल है या नहीं।

| मेथड                  | विवरण                                                             | उदाहरण                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | रेंज की सारी वैल्यू का जोड़ लौटाता है                          | `(1..5).sum # => 15`            |
| [`size`][size]          | रेंज का साइज़ लौटाता है                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | अगर रेंज में दी गई वैल्यू शामिल है तो `true` लौटाता है, वरना `false` | `(1..5).include?(3) # => true` |

## अंतहीन और बिना शुरुआत वाली रेंज

एक रेंज अंतहीन भी हो सकती है और बिना शुरुआत वाली भी। ऐसी रेंज की शुरुआत या अंत वाली वैल्यू `nil` होती है, लेकिन रेंज बनाते समय `nil` लिखना ज़रूरी नहीं है।

बिना शुरुआत वाली और अंतहीन रेंज तब काम आती हैं, जब आप किसी स्ट्रिंग को शुरुआत से या अंत तक काटना चाहते हों।

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
अगर अंतहीन रेंज का उपयोग किसी कलेक्शन पर नहीं किया जाता और सावधानी नहीं बरती जाती, तो यह एक अंतहीन क्रम बना सकती है।
~~~~

## स्ट्रिंग रेंज

रेंज में स्ट्रिंग का भी उपयोग किया जा सकता है, और इससे दो स्ट्रिंग के बीच की सारी स्ट्रिंग का अंतराल मिलता है। कुछ खास स्ट्रिंग के साथ इसका व्यवहार थोड़ा अप्रत्याशित हो सकता है, इसलिए इसका उपयोग सावधानी से कीजिए।

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
