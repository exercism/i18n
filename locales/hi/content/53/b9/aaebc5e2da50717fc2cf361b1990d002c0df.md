# इंस्टॉलेशन

## .NET 10 इंस्टॉल कीजिए

Visual Basic ट्रैक .NET 10 का उपयोग करता है।
अभ्यासों को अपने कंप्यूटर पर बनाने और जाँचने के लिए [अपने ऑपरेटिंग सिस्टम के लिए .NET 10 SDK][install-sdk] इंस्टॉल कीजिए:
सिर्फ रनटाइम नहीं, SDK भी इंस्टॉल कीजिए।

## अपना इंस्टॉलेशन जाँचिए

एक नया टर्मिनल खोलिए और यह चलाइए:

```bash
dotnet --version
```

इस कमांड का आउटपुट `10.0.0` या उससे नया होना चाहिए।

## एडिटर का सपोर्ट

अभ्यास पूरे करने के लिए आपको बस .NET SDK और एक सादा टेक्स्ट एडिटर चाहिए।
कोड कम्पलीशन और डीबगिंग जैसी ज़्यादा उन्नत सुविधाओं के लिए, इनमें से कोई एक एडिटर चुनिए:

- Windows पर [Visual Studio 2026][visual-studio]
- Windows, Linux, या macOS पर [Visual Studio Code][visual-studio-code]
- Windows, Linux, या macOS पर [JetBrains Rider][rider]

[install-sdk]: https://learn.microsoft.com/en-us/dotnet/core/install
[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
[visual-studio-code]: https://code.visualstudio.com/download
