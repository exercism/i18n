# परिचय

जब भी आपके पास कॉन्स्टेंट वैल्यू का एक तय समूह हो, आप [एन्यूमरेशन टाइप्स][enumeration types] इस्तेमाल कर सकते हैं। एक एनम इस्तेमाल करने से कॉन्स्टेंट वैल्यू के साथ काम करने का टाइप-सेफ तरीका मिलता है। एनम बनाने के लिए `enum` कीवर्ड का इस्तेमाल किया जाता है। किसी एनम मेंबर का उल्लेख करने के लिए उससे पहले एनम का नाम और एक डॉट लगाया जाता है (जैसे `Status.Active`)।

हर एनम मेंबर एक नाम और एक `int` वैल्यू का जोड़ा होता है। अगर पहले मेंबर की कोई स्पष्ट वैल्यू नहीं दी गई है, तो उसकी वैल्यू `0` कर दी जाती है। अगर किसी एनम मेंबर के लिए कोई वैल्यू स्पष्ट रूप से नहीं दी जाती, तो उसकी वैल्यू अपने आप पिछले मेंबर की वैल्यू में `1` जोड़कर असाइन कर दी जाती है।

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

एनम काफी घोषणात्मक होते हैं। नीचे दी गई दो मेथड कॉल की तुलना कीजिए:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

कोड पढ़ने वाले किसी भी व्यक्ति के लिए दूसरा तरीका (एनम के साथ) समझना ज़्यादा आसान होगा।

## संख्यात्मक टाइप वाले एनम

वैल्यू का डिफ़ॉल्ट संख्यात्मक टाइप `int` होता है, पर इसे किसी और [इंटीग्रल न्यूमेरिक][integral numeric] टाइप को स्पष्ट रूप से बताकर बदला जा सकता है।

नीचे दिया गया एनम अपनी वैल्यू के लिए `byte` संख्यात्मक टाइप इस्तेमाल करता है:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## एनम मेंबर में बदलना

जब भी आपको बूलियन जैसी किसी चीज़ को दर्शाना हो, तो आपको हमेशा एनम इस्तेमाल करने के बारे में सोचना चाहिए। पढ़ने में आसानी के ऊपर बताए गए फ़ायदों के अलावा, एनम का बूलियन के मुकाबले एक और फ़ायदा है: एनम में हमेशा नई वैल्यू जोड़ी जा सकती हैं, जबकि बूलियन वैल्यू हमेशा सिर्फ `true` या `false` ही होगी। इसलिए एनम इस्तेमाल करना भविष्य के लिहाज़ से बेहतर है।

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

ध्यान दीजिए कि पूर्णांक वैल्यू को एनम में _बदला_ जा सकता है, लेकिन जब कोई पूर्णांक वैल्यू किसी एनम वैल्यू से मेल नहीं खाती, तो ऐसा करने पर अनपेक्षित परिणाम मिल सकते हैं:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## एनम को पार्स करना

कभी-कभी किसी स्ट्रिंग को उसके नाम के आधार पर एनम मेंबर में बदलना काम का होता है, इसके लिए [`Enum.Parse`][enum parse] इस्तेमाल कीजिए:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

यह जाँचने के लिए कि कोई नाम या वैल्यू एनम में मौजूद है या नहीं, आप [`Enum.TryParse`][enum tryparse] या [`Enum.IsDefined`][enum isdefined] इस्तेमाल कर सकते हैं। दोनों एक बूलियन लौटाते हैं जो बताता है कि एनम मेंबर मौजूद है या नहीं:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
