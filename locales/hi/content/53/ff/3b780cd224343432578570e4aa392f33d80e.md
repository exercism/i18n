# परिचय

अधिकांश प्रोग्रामिंग भाषाओं की तरह Gleam में भी "साइड इफेक्ट" होते हैं, इसलिए फंक्शन एक वैल्यू लौटाने के साथ-साथ दुनिया की स्थिति भी पढ़ सकते हैं और बदल सकते हैं।

Gleam की स्टैंडर्ड लाइब्रेरी में `gleam/io` मॉड्यूल स्ट्रिंग को कंसोल पर छापने के फंक्शन देता है।

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

अन्य पैकेज अन्य IO फंक्शन दे सकते हैं, जैसे `simplifile`, एक पैकेज जो फाइलें पढ़ने और लिखने के फंक्शन उपलब्ध कराता है।

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
