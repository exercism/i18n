# `for` लूप

लूप लगाना प्रोग्रामिंग की एक बुनियादी अवधारणा है, जिससे आप एक कोड ब्लॉक को कई बार चला सकते हैं।
Swift में दो तरह के लूप होते हैं: [`for-in` लूप][for-loops] और `while` लूप।
इस अध्याय में आप `for-in` लूप के बारे में जानेंगे।

`for` लूप की मदद से आप वैल्यू के किसी सीक्वेंस पर इटरेशन कर सकते हैं। इसमें हर एलिमेंट बारी-बारी से लिया जाता है और आपकी पसंद के वेरिएबल में रख दिया जाता है।
Swift में आप कई तरह के सीक्वेंस पर इटरेशन कर सकते हैं, जैसे रेंज, ऐरे और स्ट्रिंग (और भी कई टाइप, जिन पर आगे बात की जाएगी)।
जब सीक्वेंस के हर एलिमेंट पर इटरेशन हो जाता है, तब लूप खत्म हो जाता है।

`for` लूप को घोषित करने के लिए `for` कीवर्ड लिखते हैं, उसके बाद एक वेरिएबल का नाम, फिर `in` कीवर्ड, और अंत में वैल्यू का वह सीक्वेंस जिस पर इटरेशन करना है।
`for-in` लूप में दिया गया वेरिएबल अपरिवर्तनीय होता है, यानी लूप के अंदर आप उसकी वैल्यू नहीं बदल सकते।
यहाँ संख्याओं के एक ऐरे पर इटरेशन करने वाले `for-in` लूप का उदाहरण दिया गया है:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` वेरिएबल `for-in` लूप में घोषित किया जाता है और सिर्फ लूप के स्कोप के अंदर ही उपलब्ध रहता है।

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## रेंज पर इटरेशन करना

`for-in` लूप की मदद से आप संख्याओं की एक रेंज पर भी इटरेशन कर सकते हैं।
इससे आप एक कोड ब्लॉक को एक तय संख्या में बार-बार चला सकते हैं। जैसे रेंज `1...5` पर इटरेशन 1, 2, 3, 4 और 5 संख्याओं पर होगा, इसलिए लूप 5 बार चलेगा।
कभी-कभी आपको ऐरे जैसे डेटा स्ट्रक्चर के इंडेक्स पर इटरेशन करना होता है, तब आप `0..<array.count` रेंज इस्तेमाल कर सकते हैं।

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## स्ट्रिंग पर इटरेशन करना

`for-in` लूप की मदद से आप किसी स्ट्रिंग पर भी इटरेशन कर सकते हैं।
इससे आप स्ट्रिंग के हर अक्षर पर इटरेशन कर सकते हैं। ध्यान दीजिए कि लूप में जो टाइप दिया जाता है, वह `Character` होता है।

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift में एक `stride` फंक्शन भी होता है, जिसकी मदद से आप किसी रेंज पर एक तय स्टेप के साथ सीक्वेंस बना सकते हैं।
फिर उस सीक्वेंस पर `for-in` लूप की मदद से इटरेशन किया जा सकता है।
`stride` को [`stride(from:to:by:)`][stride-to] या [`stride(from:through:by:)`][stride-through] के रूप में परिभाषित किया गया है। पहला एक्सक्लूसिव होता है और दूसरा इन्क्लूसिव।

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

ध्यान दीजिए कि `to` पैरामीटर एक्सक्लूसिव है, इसलिए लूप `to` पैरामीटर से पहले वाली संख्या तक ही चलता है, जबकि `through` पैरामीटर इन्क्लूसिव है, इसलिए यहाँ `10` भी शामिल होगा।

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
