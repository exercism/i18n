# परिचय

## समानता

Elm के टाइप की "समान होना" की जाँच समानता ऑपरेटर `(==)` से की जा सकती है।
असमानता ऑपरेटर `(/=)` है (*न* कि `!=`, जैसा कई भाषाओं में होता है)।
समानता ऑपरेटर लिटरल, टपल, रिकॉर्ड और कस्टम टाइप पर काम करता है।

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

ध्यान दीजिए कि आपको फंक्शन की तुलना *कभी नहीं* करनी चाहिए, क्योंकि इससे प्रोग्राम रनटाइम पर क्रैश हो जाएगा।

## तुलना

तुलना ऑपरेटर `(<)`, `(<=)`, `(>)`, `(>=)` और फंक्शन `min`, `max`, `compare` `comparable` टाइप पर काम करते हैं।
`comparable` एक खास टाइप है, जो उन सभी बिल्ट-इन टाइप को एक साथ रखता है जिनकी तुलना की जा सकती है: संख्याएँ, अक्षर, स्ट्रिंग, comparable चीज़ों के ऐरे, और comparable चीज़ों के टपल।

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

रिकॉर्ड या कस्टम टाइप जैसे दूसरे टाइप की वैल्यू की सीधे तुलना नहीं की जा सकती।

कुछ बिल्ट-इन टाइप को अपनी सामग्री के `comparable` होने की ज़रूरत होती है, जैसे `Set` या `Dict` की चाबियाँ, क्योंकि उनकी बनावट एक अंदरूनी क्रम पर निर्भर करती है।

comparable वैल्यू वाले ऐरे को `List.sort` से क्रम में लगाया जा सकता है, और ऐसी वैल्यू वाले ऐरे जिन्हें comparable वैल्यू में बदला जा सकता है, उन्हें `List.sortBy` से क्रम में लगाया जा सकता है।
अगर आपको एक के बाद एक कई मानदंडों पर क्रम में लगाना है (पहले एक प्रॉपर्टी से, और बराबरी होने पर दूसरी से), तो टपल या ऐरे भी `List.sortBy` के साथ इस्तेमाल किए जा सकते हैं, क्योंकि टपल और ऐरे शब्दकोश-क्रम में लगाए जाते हैं।


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

फंक्शन `compare` दो `comparable` वैल्यू लेता है और एक `Order` लौटाता है।
`Order` एक ऐसा टाइप है जो एक ही काम में बताता है कि कोई वैल्यू किसी दूसरी से बड़ी (`GT`), बराबर (`EQ`) या छोटी (`LT`) है या नहीं।

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

किसी भी टाइप के लिए तुलना फंक्शन बनाए जा सकते हैं, और इन्हें इस्तेमाल किया जा सकता है, जैसे `List.sortWith` से क्रम में लगाने के लिए:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
