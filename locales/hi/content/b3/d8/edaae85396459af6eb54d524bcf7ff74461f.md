# परिचय

`Complex numbers` कोई जटिल चीज़ नहीं हैं।
इन्हें बस एक कम डरावना नाम चाहिए।

ये इतने उपयोगी हैं, खासकर इंजीनियरिंग और विज्ञान में, कि Julia ने इन्हें पूर्णांकों और दशमलव संख्याओं के साथ मानक संख्या टाइप के रूप में शामिल किया है।

## मूल बातें

Julia में एक `complex` वैल्यू मूल रूप से दो संख्याओं का जोड़ा होती है: आम तौर पर ये दशमलव संख्याएँ होती हैं, पर हमेशा नहीं।
इन्हें "वास्तविक" और "काल्पनिक" भाग कहा जाता है, और इसकी वजह इतिहास की कुछ दुर्भाग्यपूर्ण बातें हैं।
फिर, बेहतर यही है कि आप अजीब नामों पर नहीं, इनके पीछे छिपी सादगी पर ध्यान दें।

दो वास्तविक संख्याओं से कॉम्प्लेक्स संख्या बनाने के लिए, काल्पनिक भाग के आगे बस `im` लगा दीजिए।

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

इस तरह, विभिन्न `Complex` टाइप होते हैं, जो उनसे मिलते-जुलते पूर्णांक या दशमलव संख्या टाइप से बने होते हैं।

वास्तविक वेरिएबल से कॉम्प्लेक्स संख्या बनाने के लिए ऊपर दिया गया तरीका काम नहीं करेगा।
`a + bim` लिखने पर पार्सर को लगता है कि `bim` किसी (न होने वाले) वेरिएबल का नाम है।

`b*im` लिखना भी संभव है, लेकिन इसके लिए `complex()` फंक्शन का इस्तेमाल करना बेहतर है, जो गुणा और जोड़ की क्रियाओं से बचा लेता है।

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

कॉम्प्लेक्स संख्या के भागों को अलग-अलग पाने के लिए:

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

या एक साथ:

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

कोई भी भाग शून्य हो सकता है, और तब गणितज्ञ उस संख्या को "पूरी तरह वास्तविक" या "पूरी तरह काल्पनिक" कह सकते हैं।
लेकिन Julia में यह फिर भी एक कॉम्प्लेक्स संख्या ही है।

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

आपने शायद सुना हो कि "`i` (या `j`) -1 का वर्गमूल है"।

फिलहाल, इसका मतलब इतना ही है कि काल्पनिक भाग _परिभाषा से_ नीचे दी गई समानता को पूरा करता है:

```julia-repl
julia> 1im * 1im == -1
true
```

यह एक सरल विचार है, लेकिन इसके नतीजे दिलचस्प होते हैं।

## अंकगणित

दशमलव संख्याओं और पूर्णांकों के साथ इस्तेमाल होने वाले सभी मानक गणितीय `operators` और बुनियादी फंक्शन कॉम्प्लेक्स संख्याओं के साथ भी काम करते हैं। यहाँ एक छोटा-सा नमूना है:

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## फंक्शन

`real()` और `imag()` के अलावा भी कई फंक्शन हैं, जिनका कॉम्प्लेक्स संख्याओं में खास महत्व है।

- `conj()` कॉम्प्लेक्स संख्या के काल्पनिक भाग का चिह्न बस उलट देता है (_+ से - या इसके उलट_)।
    - कॉम्प्लेक्स गुणा जिस तरह काम करता है, उसकी वजह से यह आपकी सोच से कहीं ज़्यादा उपयोगी है।
- `abs(<complex number>)` हमेशा एक वास्तविक संख्या लौटाता है, जिसका कोई काल्पनिक भाग नहीं होता।
- `abs2(<complex number>)`, `abs(<complex number>)` का वर्ग लौटाता है: यह `abs()` से जल्दी निकलता है, और अक्सर किसी गणना में इसी की ज़रूरत होती है।
- `angle(<complex number>)` रेडियन में फेज़ कोण लौटाता है।

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
गणित में रुचि रखने वालों के लिए एक आंशिक व्याख्या:

- `z1` को `(real, imag)` के रूप में लिखने पर वास्तव में कॉम्प्लेक्स प्लेन के कार्टीशियन निर्देशांक इस्तेमाल होते हैं।
- इसी कॉम्प्लेक्स संख्या को ध्रुवीय निर्देशांक इस्तेमाल करते हुए, `(r, θ)` संकेतन में भी लिखा जा सकता है।
- यहाँ `r` और `θ` क्रमशः `abs(z1)` और `angle(z1)` से मिलते हैं।

यहाँ कुछ स्थिरांकों का इस्तेमाल करने वाला एक उदाहरण है:

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

ध्रुवीय `(r, θ)` संकेतन इतना उपयोगी है कि इसके लिए बिल्ट-इन फंक्शन `cis` (जो `cos(x) + isin(x)` का छोटा रूप है) और `cispi` (जो `cos(πx) + isin(πx)` का छोटा रूप है) मौजूद हैं, जो इसे और कुशलता से बनाने में मदद करते हैं।

ध्रुवीय संकेतन की उपयोगिता यूलर के सुंदर सूत्र `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy` में दिखती है, जहाँ `|x + iy| = 1` है।
`|x + iy| = r` लेने पर हमें अधिक सामान्य ध्रुवीय रूप मिलता है: `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`.
ध्यान दीजिए कि घातांकीय रूप खास तौर पर संक्षिप्त होता है और इस पर काम करना आसान है।

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

ऊपर दी गई लगभग-समानता इसलिए है क्योंकि `cis` और `cispi` फंक्शन बेहतर संख्यात्मक आउटपुट दे सकते हैं, और खास तौर पर `cispi` तब, जब आर्गुमेंट π के मनमाने गुणक हों (जैसे रेडियन में!)।

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

संयोग से, इसी वजह से कॉम्प्लेक्स संख्याएँ 2D में घूर्णन और त्रिज्यीय विस्थापन करने के लिए बहुत उपयोगी हो जाती हैं।

घूर्णन के लिए, कॉम्प्लेक्स संख्या `z = x + iy` को मूल बिंदु के चारों ओर `θ` कोण से एक साधारण गुणा से घुमाया जा सकता है: `z * ℯ^(iθ)`.
ध्यान दीजिए कि यहाँ `x` और `y` वास्तविक 2D कार्टीशियन प्लेन के सामान्य निर्देशांक ही हैं, और धनात्मक कोण से *वामावर्त* घूर्णन होता है, जबकि ऋणात्मक कोण से *दक्षिणावर्त* घूर्णन होता है।

इसी तरह, ध्रुवीय रूप में लिखी कॉम्प्लेक्स संख्या के परिमाण `r` में त्रिज्यीय विस्थापन `Δr` जोड़कर वह विस्थापन किया जा सकता है (जैसे `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`)।
ध्यान दीजिए कि कोण वाला भाग वैसा ही रहता है और सिर्फ परिमाण `r` बदलता है, जैसा अपेक्षित है।
