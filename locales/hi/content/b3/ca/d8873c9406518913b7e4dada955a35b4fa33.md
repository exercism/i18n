# परिचय

Common Lisp में, दूसरी भाषाओं की तरह, ऐरे एलिमेंट्स का एक ऐसा समूह होता है जिन तक पूर्णांक इंडेक्स के ज़रिए पहुँचा जाता है।
एलिमेंट्स के प्रकार अलग-अलग हो सकते हैं।
ऐरे बहुआयामी भी हो सकता है (सिर्फ 1-आयामी ही नहीं)।

## बनाना

`make-array` की मदद से ऐरे बनाए जा सकते हैं।
इसमें कई ऑप्शन हैं, लेकिन इसके आसान रूपों की मदद से N-आयामी ऐरे बनाए जा सकते हैं, जिनमें या तो सभी एलिमेंट्स को एक ही वैल्यू दी जाती है, या ऐरे को किसी दूसरे सीक्वेंस (जैसे ऐरे) की वैल्यूज़ से भर दिया जाता है।
इसका पहला आर्गुमेंट एक ऐरे होता है जिसमें हर आयाम का साइज़ होता है।

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(ध्यान दीजिए कि N-आयामी ऐरे कैसे आयामों की संख्या के साथ प्रिंट होते हैं।)

ऐरे उसी फॉर्मैट का इस्तेमाल करके भी बनाए जा सकते हैं जिसमें वे प्रिंट होते हैं:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## एलिमेंट्स तक पहुँचना

वेक्टर के एलिमेंट्स तक पहुँचने के लिए `aref` का इस्तेमाल कीजिए।
इंडेक्स 0 से शुरू होते हैं।
दिए गए इंडेक्स की संख्या ऐरे के रैंक के बराबर होनी चाहिए।

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
