# परिचय

[`repeat-while` लूप][repeat-loops] `while` लूप जैसे ही होते हैं, लेकिन एक खास अंतर है: शर्त की जाँच लूप के अंदर का कोड चलने के बाद होती है, पहले नहीं।

इसलिए एक `repeat-while` लूप अपने कोड ब्लॉक को कम से कम एक बार चलाएगा ही।

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
