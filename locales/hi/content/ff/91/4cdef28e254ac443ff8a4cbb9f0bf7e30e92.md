# सीखना

* [The Rust Programming Language](https://doc.rust-lang.org/book/) Rust की शुरुआत करने और Rust की कुछ खास फीचर को गहराई से समझने, दोनों के लिए बहुत अच्छा संसाधन है।
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) Rust में आप जो सबसे आम चीज़ें लिखेंगे, उनके उदाहरण यहाँ दिखते हैं।
* [Into_rust()](http://intorust.com/) "Rust सीखने के लिए स्क्रीनकास्ट।"
* [Rustlings](https://github.com/carols10cents/rustlings) "छोटे अभ्यास, जिनसे आप Rust कोड पढ़ने और लिखने में अभ्यस्त हो जाएँगे।"
* [Rust User Forum](http://users.rust-lang.org) पर हर स्तर के सवालों के जवाब मिलते हैं
