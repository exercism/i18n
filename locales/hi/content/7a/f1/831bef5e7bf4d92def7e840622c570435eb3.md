# परिचय

R में `list` क्रमबद्ध तरीके से रखी गई चीज़ों का एक संग्रह होता है, जो `vectors` से कुछ मामलों में अलग है:

- इन चीज़ों के टाइप अलग-अलग हो सकते हैं (जैसे `numeric` को `character` के साथ मिलाना)।
- ये चीज़ें जटिल संरचनाएँ भी हो सकती हैं (जैसे वेक्टर, दूसरे ऐरे, वगैरह)।
- एलिमेंट तक पहुँचने का सिंटैक्स थोड़ा अलग होता है।

दूसरी भाषाओं से इनकी तुलना करना सटीक नहीं होता।
R का `list` कुछ हद तक Python की डिक्शनरी जैसा होता है, लेकिन `list` में क्रम बना रहता है और उस तक संख्या वाले इंडेक्स से पहुँचा जा सकता है।
यह C के `struct` से भी कुछ हद तक मिलता-जुलता है, बस फर्क यह है कि `list` को रनटाइम पर आसानी से बढ़ाया जा सकता है।

## ऐरे बनाना

एलिमेंट को नाम देना (जिसे अक्सर "टैग" कहते हैं) वेक्टर के मुकाबले ऐरे में ज़्यादा आम है:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

लेकिन टैग ज़रूरी नहीं हैं, और तब R सिर्फ इंडेक्स संख्याएँ इस्तेमाल करता है:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## ऐरे के एलिमेंट तक पहुँचना

इसे करने के तीन तरीके हैं, और हर तरीका अलग-अलग जगह काम आता है।

### 1. `$tag` नोटेशन से

जब टैग के नाम पहले से पता हों, तो यह बहुत आम है।

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]` नोटेशन से

इसका फायदा यह है कि टैग का नाम रनटाइम पर चुना जा सकता है।
ध्यान दीजिए कि यहाँ ब्रैकेट दोहरे हैं।

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. पोज़िशन इंडेक्स से

यह तब भी काम करता है जब ऐरे में टैग हों या न हों।
यहाँ भी ब्रैकेट दोहरे लगते हैं।

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## एलिमेंट जोड़ना और हटाना

यह आसान है: किसी एलिमेंट को वैल्यू असाइन करने पर वह बदल जाता है अगर पहले से मौजूद है, और नया हो तो जुड़ जाता है।

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

हटाने के लिए उस अनचाहे एलिमेंट को `NULL` असाइन कीजिए।

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
