# टेस्ट

टेस्ट सूट चलाने के लिए:
```bash
tclsh exercise.test
```

## छोड़े गए टेस्ट

किसी भी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना। डिफ़ॉल्ट रूप से, जब आप टेस्ट चलाते हैं तो सिर्फ एक टेस्ट (पहला वाला) चलता है। यह जानबूझकर ऐसा है, ताकि आपका ध्यान सिर्फ उस एक टेस्ट को पास कराने पर लगा रहे। वह पास हो जाए, तो उससे पहले लिखे `skip` कमांड को कॉमेंट करके या हटाकर आप अगला टेस्ट चालू कर सकते हैं।

या फिर, उनके "छोड़ा गया" स्टेटस की परवाह किए बिना सारे टेस्ट चलाने के लिए:
```bash
RUN_ALL=1 tclsh exercise.test
```
