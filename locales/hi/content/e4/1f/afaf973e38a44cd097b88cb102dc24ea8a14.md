# `for` लूप

लूप प्रोग्रामिंग की एक बुनियादी कॉन्सेप्ट है, जिससे आप कोड के एक ब्लॉक को कई बार चला सकते हैं।
Swift में दो तरह के लूप होते हैं: [`for-in` लूप][for-loops] और `while` लूप।
इस अध्याय में हम `for-in` लूप के बारे में सीखेंगे।

`for` लूप की मदद से आप वैल्यू के किसी सीक्वेंस पर एक-एक करके चल सकते हैं: हर एलिमेंट बारी-बारी से लिया जाता है और आपके चुने हुए वेरिएबल में बाँध दिया जाता है।
Swift में आप कई तरह के सीक्वेंस पर चल सकते हैं, जैसे रेंज, ऐरे और स्ट्रिंग (और भी कई टाइप, जिनके बारे में आगे बताया जाएगा)।
सीक्वेंस के हर एलिमेंट पर चल लेने के बाद लूप खत्म हो जाता है।

`for` लूप बनाने के लिए `for` कीवर्ड लिखा जाता है, उसके बाद एक वेरिएबल का नाम, फिर `in` कीवर्ड, और अंत में वे वैल्यू का सीक्वेंस जिस पर चलना है।
`for-in` लूप में दिया गया वेरिएबल बदला नहीं जा सकता, यानी लूप के अंदर उसकी वैल्यू आप नहीं बदल सकते।
यहाँ संख्याओं के ऐरे पर चलने वाले एक `for-in` लूप का उदाहरण है:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` वेरिएबल `for-in` लूप में घोषित किया जाता है और सिर्फ लूप के स्कोप में ही उपलब्ध रहता है।

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## रेंज पर चलना

`for-in` लूप की मदद से आप संख्याओं की एक रेंज पर भी चल सकते हैं।
इससे आप कोड के एक ब्लॉक को तय संख्या में कई बार चला सकते हैं। जैसे रेंज `1...5` संख्याओं 1, 2, 3, 4 और 5 पर चलेगी, इसलिए लूप 5 बार चलेगा।
कभी-कभी आपको ऐरे जैसी डेटा स्ट्रक्चर के इंडेक्स पर चलना पड़ सकता है, तब आप `0..<array.count` रेंज इस्तेमाल कर सकते हैं।

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## स्ट्रिंग पर चलना

`for-in` लूप की मदद से आप स्ट्रिंग पर भी चल सकते हैं।
इससे आप स्ट्रिंग के हर अक्षर पर चल सकते हैं। ध्यान दीजिए कि लूप में जो टाइप मिलता है वह `Character` होता है।

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift में एक `stride` फंक्शन भी है, जिससे आप किसी रेंज पर एक तय स्टेप के साथ सीक्वेंस बना सकते हैं।
इस सीक्वेंस पर फिर `for-in` लूप की मदद से चला जा सकता है।
`stride` को [`stride(from:to:by:)`][stride-to] या [`stride(from:through:by:)`][stride-through] के रूप में परिभाषित किया गया है। पहला एक्सक्लूसिव है और दूसरा इंक्लूसिव।

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

ध्यान दीजिए कि `to` पैरामीटर एक्सक्लूसिव है, इसलिए लूप `to` पैरामीटर से ठीक पहले वाली संख्या तक चलेगा। वहीं `through` पैरामीटर इंक्लूसिव है, इसलिए इस मामले में `10` भी शामिल होगा।

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
