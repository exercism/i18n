# परिचय

`case` Factor का समानता पर आधारित कई रास्तों वाला स्विच है। यह तब सही टूल है जब चुनाव इस पर निर्भर करता है कि *एक ही* वैल्यू कई विकल्पों में से किसी एक के बराबर हो। जब हर ब्रांच के लिए अलग जाँच की ज़रूरत हो, तब यह सही टूल नहीं है (उसके लिए `cond` इस्तेमाल कीजिए)।

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

कुछ बातें ध्यान में रखने लायक हैं:

- समानता की जाँच `=` से होती है। जिन चीज़ों पर `=` काम करता है, वे सब की बन सकती हैं: संख्याएँ, स्ट्रिंग, अक्षर, सिंबल, यहाँ तक कि ट्यूपल भी।
- *मैच* होने वाली ब्रांच को इनपुट वैल्यू के *बिना* स्टैक दिखता है। *डिफॉल्ट* ब्रांच को वह वैल्यू अब भी स्टैक के ऊपर दिखती है।
- अगर `case` में डिफॉल्ट न हो और कोई क्लॉज़ मैच न करता हो, तो एरर आ जाती है।

जहाँ संभव होता है, वहाँ `case` जंप टेबल में बदल जाता है। इसलिए यह केवल `if` की श्रृंखला के लिए शुगर नहीं है, बल्कि तेज़ भी है।
