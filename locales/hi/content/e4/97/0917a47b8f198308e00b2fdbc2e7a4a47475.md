# विवरण

Haxe में संख्या के दो टाइप होते हैं: पूर्णांक और दशमलव संख्याएँ:

- `Int`: एक पूर्णांक दर्शाता है।
- `Float`: 64-बिट डबल-प्रिसिज़न फ्लोटिंग पॉइंट संख्या दर्शाता है।

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

हर `Int` को वहाँ इस्तेमाल किया जा सकता है जहाँ `Float` की अपेक्षा होती है (यानी `Int` को `Float` में **असाइन किया जा सकता है** या वह `Float` के साथ **एकीकृत होता है**), लेकिन इसका उल्टा सही नहीं है। किसी `Float` को `Int` में असाइन करने पर परिशुद्धता खो सकती है, इसलिए ऐसा असाइन करना अपने आप अनुमत नहीं है।

## तुलना

यदि दो संख्याओं की वैल्यू समान हो, तो वे बराबर होती हैं।

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```
