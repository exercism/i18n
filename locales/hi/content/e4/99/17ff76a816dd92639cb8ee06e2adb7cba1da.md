# परिचय

ऐरे Factor के ऐसे सीक्वेंस हैं जिनकी लंबाई तय होती है: आप उनके एलिमेंट बदल सकते हैं, पर लंबाई नहीं। आप पहले से जानते हैं कि ऐरे लिटरल `{ … }` कैसे लिखा जाता है, और किसी ऐरे को स्लाइस या एग्रीगेट कैसे किया जाता है। यह अभ्यास उस छोटे टूलकिट के बारे में है जो तब काम आता है जब आप स्टैक पर पड़ी वैल्यू से ऐरे बनाते हैं और फिर उनके अंदर की चीज़ें ढूँढते हैं या उनका क्रम बदलते हैं।

## स्टैक से ऐरे बनाना

`1array`, `2array`, `3array` और `4array` ([`arrays`][arrays] में) स्टैक के ऊपर से 1, 2, 3 या 4 वैल्यू उठाते हैं और उन्हें एक साथ बाँध देते हैं:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## जोड़ना

`concat` ([`sequences`][sequences] में) ऐसा सीक्वेंस लेता है जिसके एलिमेंट खुद सीक्वेंस हों, और उन्हें एक लेवल तक समतल कर देता है। `join` यही काम करता है, बस हर जोड़ी के बीच एक सेपरेटर डालकर:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## उलटना

`reverse` एक नया सीक्वेंस लौटाता है जिसमें एलिमेंट उलटे क्रम में होते हैं:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## क्या यह ऐरे है?

`array?` ([`arrays`][arrays] में) टाइप प्रेडिकेट है। `<array>`, `1array`/`2array`/... या ऐरे लिटरल `{ … }` से बनी किसी भी वैल्यू के लिए यह सही होता है, और बाकी हर चीज़ के लिए गलत, जिसमें वेक्टर, स्ट्रिंग और दूसरे सीक्वेंस भी शामिल हैं:

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## ढूँढना

`index` उस पहले एलिमेंट की स्थिति लौटाता है जो इनपुट वैल्यू के बराबर है। अगर वह मौजूद नहीं है, तो यह `f` लौटाता है। `member?` सिर्फ़ बूलियन लौटाता है। दोनों **पहले एलिमेंट** लेते हैं और **सीक्वेंस उसके बाद**। `members` ([`sets`][sets] में) किसी सीक्वेंस के *बिना दोहराव वाले* एलिमेंट लौटाता है, यानी दोहराव हटाने का काम करता है, और `all-unique?` (यह भी `sets` में) जाँचता है कि सीक्वेंस में पहले से कोई दोहराव नहीं है:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
