# परिचय

कोटलिन एक **स्टैटिक टाइपिंग वाली** प्रोग्रामिंग भाषा है, जिसे JetBrains ने बनाया है। इसका मतलब है कि वेरिएबलो का टाइप कंपाइल टाइम पर तय होता है।

## वेरिएबल

अन्य स्टैटिक टाइपिंग वाली प्रोग्रामिंग भाषाओं की तरह, हर वेरिएबल का टाइप कंपाइल टाइम पर तय करना होता है। जहाँ कंपाइलर संदर्भ से टाइप का अनुमान लगा सकता है, वहाँ आप स्पष्ट टाइप घोषणा लिखने से बच सकते हैं।

कोटलिन में अपरिवर्तनीय (`val`) और परिवर्तनीय (`var`) वेरिएबल होते हैं। किसी अपरिवर्तनीय वेरिएबल की शुरुआती वैल्यू असाइन होने के बाद उसकी वैल्यू बदली नहीं जा सकती। आप अक्सर इसी तरह का वेरिएबल इस्तेमाल करेंगे।

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

किसी परिवर्तनीय वेरिएबल की वैल्यू एक या अधिक बार बदली जा सकती है:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

कोटलिन में सेमीकोलन वैकल्पिक होते हैं, सिर्फ कुछ खास मामलों को छोड़कर, जिन पर आगे बात की जाएगी।

## फंक्शन

कोटलिन में फंक्शन `fun` कीवर्ड से बनाए जाते हैं और ये _फर्स्ट-क्लास सिटिज़न_ होते हैं (इसका ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग से कोई लेना-देना नहीं है)। इसका मतलब है कि आप इन्हें सीधे फाइलों में घोषित कर सकते हैं (इन्हें `top-level functions` कहा जाता है)। जैसे Java में आप मेथड सिर्फ क्लास में बना सकते हैं, फाइल में नहीं:

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

फंक्शन आर्गुमेंट ले सकते हैं। हर आर्गुमेंट का एक नाम और एक टाइप होता है। वेरिएबल के विपरीत, आर्गुमेंट का टाइप अनुमान से नहीं लगाया जा सकता। फंक्शन में शून्य या उससे अधिक आर्गुमेंट हो सकते हैं:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

हो सकता है कोटलिन का कोई फंक्शन वैल्यू लौटाए, और हो सकता है न लौटाए:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

किसी फंक्शन से वैल्यू लौटाने के लिए `return` कीवर्ड इस्तेमाल किया जाता है:

```kotlin
fun getName(): String {
    return "Alice"
}
```

फंक्शन में डिफॉल्ट वैल्यू वाले पैरामीटर हो सकते हैं। अगर फंक्शन को कॉल करते समय इन्हें छोड़ दिया जाए, तो ये वैल्यू इस्तेमाल होंगी:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## कमेंट

एक लाइन का कमेंट लिखने के लिए `//` इस्तेमाल कीजिए:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

और कई लाइनों वाला कमेंट लिखने के लिए `/*` और `*/` इस्तेमाल कीजिए:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
