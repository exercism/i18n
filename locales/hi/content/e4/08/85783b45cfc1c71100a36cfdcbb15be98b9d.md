# इसके बारे में

Gleam में नए डेटा टाइप बनाने का तरीका कस्टम टाइप है। इनके कई _वेरिएंट_ हो सकते हैं, और हर वेरिएंट का अपना नाम होता है।

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

कस्टम टाइप का हर केस चाहें तो अपने अंदर कुछ डेटा भी रख सकता है, और अलग-अलग केसों में अलग-अलग तरह का डेटा हो सकता है। जब किसी वेरिएंट के पास डेटा होता है, तो उसे _रिकॉर्ड_ कहते हैं।

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

किसी खास केस की वैल्यू बनाने के लिए, अगर उसके साथ कोई अतिरिक्त डेटा नहीं जुड़ा है तो उसका नाम लिख दीजिए (`Spring`)। और अगर डेटा जुड़ा है, तो उसे किसी फंक्शन की तरह कॉल कीजिए (`SomeInt(2)`)।

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

कस्टम टाइप में, और Gleam की हर चीज़ में, _स्ट्रक्चरल समानता_ होती है। इसका मतलब है कि एक ही वेरिएंट की और एक जैसे डेटा वाली दो वैल्यू बराबर होती हैं।

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

कस्टम टाइप के वेरिएंट को `case` एक्सप्रेशन से पैटर्न मैच किया जा सकता है।

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
