# परिचय

Python में [टपल][tuple] _क्रम_ में रखे आइटमों का एक _अपरिवर्तनीय_ संग्रह है।
ज़्यादातर संग्रहों की तरह `tuples` किसी भी (या एक से अधिक) डेटा टाइप की चीज़ें रख सकते हैं, जिनमें दूसरे `tuples` भी शामिल हैं।
टपल [सामान्य अनुक्रम ऑपरेशन][common sequence operations] का समर्थन करते हैं, लेकिन [परिवर्तनीय अनुक्रम ऑपरेशन][mutable sequence operations] का समर्थन **नहीं** करते।

टपल के एलिमेंट पर `for item in <tuple>` रचना की मदद से इटरेशन किया जा सकता है।
अगर एलिमेंट का इंडेक्स और वैल्यू दोनों चाहिए, तो `for index, item in enumerate(<tuple>)` इस्तेमाल किया जा सकता है।
किसी भी अनुक्रम की तरह `tuples` के अंदर के एलिमेंट तक _ब्रैकेट नोटेशन_ से पहुँचा जा सकता है, बाईं ओर से `0-based index` संख्या या दाईं ओर से `-1-based index` संख्या इस्तेमाल करके।
टपल को पूरा या उसका कोई हिस्सा स्लाइस नोटेशन (_`<tuple>[<start>:<stop>:<step>]`_) की मदद से कॉपी भी किया जा सकता है।


## टपल बनाना

टपल कई तरीकों से बनाए जा सकते हैं: या तो `tuple(<iterable>)` क्लास कंस्ट्रक्टर से, या `tuple` लिटरल डिक्लेरेशन से।

### `tuple()` कंस्ट्रक्टर को खाली या किसी _इटरेबल_ के साथ इस्तेमाल करना:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

स्ट्रिंग भी इटरेबल होती हैं, इसलिए `tuple()` कंस्ट्रक्टर को आर्गुमेंट के तौर पर अकेली `str` देना चौंकाने वाले नतीजे दे सकता है:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

अकेले इटरेबल के एलिमेंट एक-एक करके जोड़े जाते हैं:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### टपल को _लिटरल_ के रूप में घोषित करना:

चूँकि `tuple(<iterable>)` कंस्ट्रक्टर आर्गुमेंट के तौर पर सिर्फ _इटरेबल_ (या कुछ नहीं) लेता है, इसलिए एक-एलिमेंट वाला टपल लिटरल तरीके से बनाना कहीं ज़्यादा आसान है।

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

नेस्टेड डेटा स्ट्रक्चर को `tuple` के एलिमेंट के रूप में शामिल किया जा सकता है, जिनमें दूसरे `tuples` भी शामिल हैं:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## टपल जोड़ना

टपल को प्लस `+` ऑपरेटर से जोड़ा जा सकता है, जो हर `tuple` को खोलकर एक नया, संयुक्त `tuple` बनाता है।

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## टपल के अंदर के एलिमेंट तक पहुँचना

`tuple` के अंदर के एलिमेंट तक _ब्रैकेट नोटेशन_ से पहुँचा जा सकता है, बाईं ओर से `0-based index` संख्या या दाईं ओर से `-1-based index` संख्या इस्तेमाल करके।

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## टपल के एलिमेंट पर इटरेशन करना

`tuple` के अंदर के एलिमेंट पर लूप में `for item in <tuple>` सिंटैक्स की मदद से _इटरेशन_ किया जा सकता है।
अगर इंडेक्स और वैल्यू दोनों चाहिए, तो `for index, item in enumerate(<tuple>)` इस्तेमाल किया जा सकता है।

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## टपल में सदस्यता की जाँच

`tuple` में सदस्यता जाँचने के लिए `in` ऑपरेटर इस्तेमाल किया जा सकता है।

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
