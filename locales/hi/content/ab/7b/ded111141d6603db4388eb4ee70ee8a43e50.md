# निर्देश

हल के घाट पर रात की पाली चल रही है। मालवाहक जहाज़ *Olwen* किनारे पर बँधा है, और घाट मज़दूरों का एक दल मैनिफेस्ट पर समानांतर में काम कर रहा है। हर क्रेट को जहाज़ पर चढ़ाने से पहले तौलना ज़रूरी है, और बंदरगाह प्रबंधक एक ही चलता हुआ **टनभार हिसाब** रखता है, जिसे हर उठाव अपडेट करता है। अड़चन यह है कि घाट पर सिर्फ एक ही क्रेन है, इसलिए हिसाब को एक ही समय में अपडेट करने वाले दो मज़दूर उसे बिगाड़ नहीं सकते।

हर क्रेट सामान के वज़नों का एक ऐरे होता है। क्रेट का वज़न इन वज़नों का जोड़ होता है।

## 1. क्रेट तोलिए

`weigh-crate` बनाइए जो एक क्रेट ले और उसका कुल वज़न लौटाए। यह सीधा क्रमिक काम है, यानी एक क्रेट से एक संख्या बाहर आती है।

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. पूरा मैनिफेस्ट समानांतर में तोलिए

`weigh-all` बनाइए जो क्रेटों का एक ऐरे ले और उनके वज़नों का ऐरे उसी क्रम में लौटाए। `parallel-map` इस्तेमाल कीजिए ताकि हर क्रेट का काम साथ-साथ हो।

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. नई क्रेन बनाइए

`<crane>` बनाइए जो एक नई क्रेन तैयार करे: एक टपल जिसमें एक नया `<lock>` और `0` टनभार हो। क्रेन वह साझा संसाधन है, जिसे आगे के काम सुरक्षित रखेंगे।

```factor
<crane> tonnage>> .
! => 0
```

## 4. क्रेट को चलते हिसाब में उठाइए

`hoist-crate` बनाइए जो एक `weight` और एक `crane` ले और उस वज़न को क्रेन के टनभार में **क्रेन के लॉक के अंदर** जोड़े, ताकि एक ही समय में माल उठाने वाले दूसरे मज़दूरों के मुकाबले पढ़ना-जोड़ना-लिखना एटॉमिक रहे।

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. चलता टनभार पढ़िए

`crane-tonnage` बनाइए जो क्रेन का मौजूदा टनभार लौटाए, वह भी लॉक के अंदर, ताकि उठाने के बीच में पढ़ने पर बिगड़ी हुई वैल्यू न दिखे।

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. माल लादिए

`load-cargo` बनाइए जो क्रेटों का एक ऐरे और एक क्रेन ले, और **हर क्रेट के लिए एक घाट मज़दूर थ्रेड शुरू करे** जो क्रेट को तोले और उसका वज़न क्रेन पर उठा दे। यह शब्द तभी लौटता है जब हर मज़दूर अपना काम पूरा कर चुका हो। सभी थ्रेड को जोड़ने के लिए `<promise>` और `?promise` का उपयोग कीजिए।

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
