# परिचय

JavaScript में `Array` क्लास में ऐरे बदलने के लिए कई शक्तिशाली बिल्ट-इन मेथड होते हैं।
इन मेथड की मदद से एक ऐरे को दूसरे ऐरे में बदलना किसी साधारण `for` लूप या सीधे-सीधे बदलाव करने की तुलना में कहीं ज़्यादा आसान हो जाता है।

कुछ मेथड [_प्योर_][pure-function-definition] होते हैं, यानी वे मूल ऐरे को नहीं बदलते।
वे उसकी जगह एक नया ऐरे लौटाते हैं।
लेकिन कुछ दूसरे मेथड उस ऐरे को ही बदल देते हैं जिस पर उन्हें कॉल किया जाता है, और बदला हुआ ऐरे **नहीं** लौटाते।

ऐरे बदलने के लिए सबसे ज़्यादा इस्तेमाल होने वाले कुछ मेथड नीचे दिए गए हैं।
उपलब्ध सभी मेथड की पूरी सूची [MDN डॉक्युमेंटेशन][array-methods] में मिल सकती है।

### map (प्योर)

एक आर्गुमेंट के रूप में दिए गए फंक्शन के हिसाब से हर एलिमेंट को बदलकर एक नया ऐरे बनाइए।
ऐसे कॉलबैक फंक्शन अक्सर [एरो फंक्शन][concept-arrow-functions] के रूप में लिखे जाते हैं।

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

ध्यान देने की बात है कि बनने वाला ऐरे हमेशा मूल ऐरे जितना ही लंबा होता है।

### filter (प्योर)

यह एक फ़िल्टर फंक्शन लेकर मौजूदा ऐरे को छानकर एक नया ऐरे बनाता है।
वह फंक्शन सही लौटाता है अगर एलिमेंट रखा जाना चाहिए, और गलत अगर उसे हटाया जाना चाहिए।

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (प्योर)

यह ऐरे को घटाकर एक ही वैल्यू बना देता है।
इसके लिए वह एक फंक्शन इस्तेमाल करता है, जो एक _अक्युमुलेटर_ और ऐरे के मौजूदा एलिमेंट को पैरामीटर के रूप में लेता है।
यह फंक्शन बताता है कि मौजूदा एलिमेंट को अक्युमुलेटर में कैसे जोड़ना है, और वह अक्युमुलेटर लौटाता है जो अगले इटरेशन में इस्तेमाल होगा।

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

यह ऐरे के एलिमेंट का क्रम उलट देता है।

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

यह मेथड उसी ऐरे को बदल देता है जिस पर इसे कॉल किया जाता है।

### slice (प्योर)

यह शुरू और अंत का इंडेक्स लेकर उसी ऐरे से एक छोटा ऐरे बना देता है जिस पर इसे कॉल किया जाता है।

अंत वाले इंडेक्स पर मौजूद एलिमेंट इसमें शामिल नहीं होता।
साथ ही, सारे पैरामीटर वैकल्पिक हैं:
शुरू का इंडेक्स अपने आप `0` मान लिया जाता है, और अंत का इंडेक्स ऐरे की लंबाई।

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

यह ऐरे के एलिमेंट हटाता है, बदलता है, और/या नए एलिमेंट जोड़ता है।

यह ये पैरामीटर लेता है:

- उस एलिमेंट का इंडेक्स जहाँ से ऐरे बदलना शुरू करना है
- हटाए जाने वाले एलिमेंट की संख्या
- ऐरे में डाले जाने वाले एलिमेंट (वैकल्पिक)

`splice` हटाए गए एलिमेंट लौटाता है।

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

डिफॉल्ट रूप से `sort` ऐरे के एलिमेंट को पहले स्ट्रिंग में बदलता है, और फिर स्ट्रिंग की तुलना लगाकर उन्हें क्रम में लगाता है (देखिए [कॉन्सेप्ट तुलना][concept-comparison])।
क्रम लगाना _इन-प्लेस_ होता है, यानी मूल ऐरे बदल जाता है।
`sort` वह बदला हुआ ऐरे भी लौटाता है, जो तब काम आता है जब आप उसके बाद दूसरे मेथड जोड़ना चाहते हैं।

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

क्रम लगाने का तरीका अपनी ज़रूरत के हिसाब से बदलने के लिए आप एक तुलना फंक्शन को आर्गुमेंट के रूप में दे सकते हैं।
इस तुलना फंक्शन को ऐरे के दो एलिमेंट आर्गुमेंट के रूप में दिए जाते हैं।
इसे यह लौटाना होता है:

- एक ऋणात्मक संख्या, अगर पहला आर्गुमेंट दूसरे से पहले आना चाहिए
- एक धनात्मक संख्या, अगर पहला आर्गुमेंट दूसरे के बाद आना चाहिए
- `0`, अगर एलिमेंट का क्रम वैसा ही रहना चाहिए

जैसे, संख्याओं को क्रम में लगाने के लिए यह तुलना फंक्शन इस्तेमाल किया जा सकता है।

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
