# विवरण

Swift में सत्य मानों को दर्शाने के लिए एक अंतर्निहित टाइप होता है, जिसे [`Bool`][bools] कहते हैं। सत्य मान यानी `true` और `false`.

## तार्किक ऑपरेटर

बूलियन एक्सप्रेशन जोड़ने और उनका मूल्यांकन करने के लिए Swift तीन तार्किक ऑपरेटर देता है: `!`, `&&` और `||`.

### तार्किक AND (`&&`)

[_and_ ऑपरेटर][and] (`&&`) तभी `true` लौटाता है जब दोनों ऑपरेंड `true` हों।
अगर इनमें से कोई एक ऑपरेंड `false` हो, तो यह `false` लौटाता है।
`&&` चिह्न के दोनों ओर एक एक्सप्रेशन या बूलियन वैल्यू रखिए:

```swift
true && true  // true
true && false // false
```

### तार्किक OR (`||`)

[_or_ ऑपरेटर][or] (`||`) तब `true` लौटाता है जब **कम से कम एक** ऑपरेंड `true` हो।
यह तभी `false` लौटाता है जब दोनों ऑपरेंड `false` हों।
`||` चिह्न के दोनों ओर एक एक्सप्रेशन या बूलियन वैल्यू रखिए:

```swift
true || true   // true
true || false  // true
false || false // false
```

### तार्किक NOT (`!`)

[_not_ ऑपरेटर][not] (`!`) एक बूलियन वैल्यू को उलट देता है।
अगर वैल्यू `false` हो तो यह `true` लौटाता है, और अगर वैल्यू `true` हो तो `false`.
`!` ऑपरेटर को वैल्यू या एक्सप्रेशन के ठीक पहले रखिए:

```swift
!true  // false
!false // true
```

## गोल ब्रैकेट (`()`) का उपयोग

[गोल ब्रैकेट][explicit-parentheses] की मदद से आप एक्सप्रेशनों को समूहों में बाँट सकते हैं और यह तय कर सकते हैं कि मूल्यांकन किस क्रम में हो।
Swift में गोल ब्रैकेट के अंदर वाले एक्सप्रेशन पहले मूल्यांकित किए जाते हैं:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

समूह बनाने के लिए गोल ब्रैकेट का उपयोग करने से यह भी तय होता है कि किसी जटिल एक्सप्रेशन पर NOT ऑपरेटर कैसे लागू होगा:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
जब आपको मूल्यांकन का क्रम साफ करना हो या जटिल शर्तों को पढ़ना आसान बनाना हो, तब गोल ब्रैकेट का उपयोग कीजिए।
जहाँ डिफॉल्ट प्राथमिकता पहले से साफ हो, वहाँ बिना ज़रूरत के गोल ब्रैकेट न जोड़िए।
~~~~
