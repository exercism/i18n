# परिचय

## एरर

जब किसी प्रोग्राम या कोड के किसी हिस्से में कुछ गलत या अनपेक्षित हो, तो उसकी जानकारी एरर के रूप में देना काम आता है।

ये JavaScript ऑब्जेक्ट होती हैं।

इस ऑब्जेक्ट की मुख्य प्रॉपर्टी `message` है:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw` सिंटैक्स का इस्तेमाल करके आप एक एरर फेंक सकते हैं।

```javascript
throw new Error('Oops');
```

जब कोई एरर फेंकी जाती है, तो वर्तमान निष्पादन रुक जाता है और कॉल स्टैक के पहले catch ब्लॉक से दोबारा शुरू होता है।

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## इनहेरिटेंस

इनहेरिटेंस क्लासों के बीच पैरेंट-चाइल्ड संबंध बनाने का एक तरीका है।
चाइल्ड क्लास (जिसे कभी-कभी _सबक्लास_ कहा जाता है) के पास पैरेंट क्लास (जिसे कभी-कभी _सुपरक्लास_ कहा जाता है) द्वारा परिभाषित व्यवहार और डेटा तक पहुँच होती है।

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

चाइल्ड क्लास के डिक्लेरेशन में `extends` कीवर्ड [प्रोटोटाइप चेन][prototype-chain] के ज़रिए पैरेंट क्लास से संबंध बनाता है।

चाइल्ड क्लास का कंस्ट्रक्टर जो ऑब्जेक्ट बनाता है, उन सबके प्रोटोटाइप चेन में पैरेंट क्लास का प्रोटोटाइप होता है। इससे उन्हें पैरेंट द्वारा परिभाषित सभी मेथड और डेटा तक पहुँच मिलती है।

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

JavaScript की किसी भी क्लास की तरह, सबक्लास `extends` कीवर्ड का इस्तेमाल करके `Error` से इनहेरिट कर सकते हैं और कस्टम एरर बना सकते हैं।
`instanceof` सिंटैक्स यह जाँचता है कि पकड़ी गई एरर `Error` के किसी खास सबक्लास की इंस्टेंस है या नहीं।

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
