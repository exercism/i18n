# परिचय

## मेथड ओवरलोडिंग

Java में मेथड ओवरलोडिंग एक फीचर है जिसकी मदद से एक क्लास में एक ही नाम के कई मेथड रखे जा सकते हैं, जिनकी पैरामीटर सूचियाँ अलग-अलग हों।
यह कंपाइल-टाइम (या स्टैटिक) पॉलिमॉर्फिज़्म से जुड़ा हुआ है।
यह कॉन्सेप्ट उन मेथड को बनाने के लिए बहुत ज़रूरी है जो एक जैसे काम करते हैं, लेकिन अलग-अलग इनपुट लेते हैं।

### मेथड ओवरलोडिंग क्यों करें?

मेथड ओवरलोडिंग से प्रोग्राम की पठनीयता बढ़ती है।
अलग-अलग मेथड को एक ही नाम दिया जा सकता है, लेकिन उनके पैरामीटर अलग-अलग होते हैं।
पैरामीटर की संख्या या उनके टाइप के आधार पर उससे मेल खाता मेथड कॉल किया जाता है।

### मेथड ओवरलोड कैसे करें?

मेथड ओवरलोडिंग का आधार मेथड का सिग्नेचर है।
अगर दो मेथड के सिग्नेचर अलग-अलग हों, तो उन्हें अलग माना जाएगा।
किसी मेथड को ओवरलोड करने के दो तरीके हैं:

1. **पैरामीटर की संख्या अलग-अलग**: मेथड का नाम एक ही हो सकता है, लेकिन पैरामीटर की संख्या अलग-अलग हो सकती है।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **पैरामीटर के टाइप अलग-अलग**: मेथड का नाम और पैरामीटर की संख्या एक ही हो सकती है, लेकिन टाइप अलग-अलग हो सकते हैं।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### ध्यान रखने योग्य बातें

- ओवरलोड किए गए मेथड में आर्गुमेंट की सूची बदलनी ज़रूरी है।
- ओवरलोड किए गए मेथड का रिटर्न टाइप भी बदला जा सकता है, लेकिन सिर्फ रिटर्न टाइप बदल देने से मेथड ओवरलोडिंग नहीं होती।
- मेथड को एक ही क्लास में या किसी सबक्लास में ओवरलोड किया जा सकता है।

इस कॉन्सेप्ट में हम Java में मेथड ओवरलोडिंग के कई उदाहरण और बारीकियाँ देखेंगे।
