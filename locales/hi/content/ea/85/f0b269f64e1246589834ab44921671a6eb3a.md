# परिचय

फंक्शन डिक्लेरेशन और फंक्शन एक्सप्रेशन के अलावा JavaScript में फंक्शन बनाने का एक और बहुत छोटा तरीका भी होता है।
ऐसे फंक्शन को _एरो फंक्शन_ कहते हैं।

इस कॉन्सेप्ट में हम उस सिंटैक्स पर ध्यान देंगे जिससे एरो फंक्शन लिखा जाता है।
एरो फंक्शन के काम करने के तरीके में कुछ अंतर होते हैं, जैसे _this_ बाइंडिंग, और इन्हें दूसरे कॉन्सेप्ट में समझाया जाएगा।

यहाँ फंक्शन डिक्लेरेशन और एरो फंक्शन की तुलना दी गई है।

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

ऊपर आप देख सकते हैं कि एरो फंक्शन का सिंटैक्स:

1. `function` कीवर्ड हटा देता है
2. `addUpTwoNumbers` आइडेंटिफायर को `const` के रूप में घोषित करता है
3. एक फैट एरो `=>` जोड़ता है

अगर फंक्शन के अंदर का कोड सिर्फ एक रिटर्न स्टेटमेंट हो, जैसा ऊपर के उदाहरण में है, तो `{}` और `return` कीवर्ड हटाए जा सकते हैं।

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

एक खास स्थिति में, जब एरो फंक्शन से सिर्फ ऑब्जेक्ट लौटाया जाता है, तो रिटर्न स्टेटमेंट हटाने के लिए ऑब्जेक्ट के चारों ओर गोल ब्रैकेट लगाना ज़रूरी होता है।

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

पैरामीटर के चारों ओर गोल ब्रैकेट लगाना या न लगाना पैरामीटर की संख्या पर निर्भर करता है।

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
