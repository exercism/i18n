# जेनेरिक डेटा टाइप

Cairo में जेनेरिक्स की मदद से आप ऐसा कोड लिख सकते हैं जो कई अलग-अलग टाइपों के साथ काम करता है। इससे एक ही कोड बार-बार लिखना नहीं पड़ता और उसे बनाए रखना भी आसान रहता है।

जेनेरिक्स का इस्तेमाल फंक्शन, स्ट्रक्ट, एनम, ट्रेट और मेथड, सबके साथ किया जा सकता है।

## जेनेरिक फंक्शन

एक जेनेरिक फंक्शन अलग-अलग टाइपों पर काम करता है। इसके लिए हर टाइप का अलग इम्प्लीमेंटेशन लिखने की ज़रूरत नहीं पड़ती।

उदाहरण के लिए:

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

यहाँ `T` किसी भी टाइप के लिए एक प्लेसहोल्डर है।

लेकिन Cairo में यह पक्का करने के लिए ट्रेट बाउंड लिखना पड़ता है कि जेनेरिक टाइप कुछ खास शर्तें पूरी करता हो।

अगर `T` को ड्रॉप होने की ज़रूरत है, तो हम सिग्नेचर को ऐसे बदल सकते हैं:

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

`Drop` या `PartialOrd` जैसे ट्रेट बाउंड जेनेरिक्स पर कुछ खास कामों के लिए कंस्ट्रेंट जोड़ते हैं।

## अनाम कंस्ट्रेंट

अगर किसी फंक्शन में किसी ट्रेट का इम्प्लीमेंटेशन सीधे तौर पर इस्तेमाल नहीं होता, तो आप `+` का उपयोग करके अनाम कंस्ट्रेंट लिख सकते हैं:

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

इससे `TPartialOrd` जैसे ट्रेट्स को नाम देने की ज़रूरत नहीं पड़ती और कोड छोटा रहता है।

## जेनेरिक्स वाले स्ट्रक्ट

स्ट्रक्ट में जेनेरिक्स की मदद से फील्ड किसी भी टाइप की हो सकती हैं।

उदाहरण के लिए:

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

अगर किसी स्ट्रक्ट को एक से ज़्यादा जेनेरिक टाइप चाहिए, तो बस और प्लेसहोल्डर जोड़ दीजिए:

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## जेनेरिक्स वाले एनम

एनम भी जेनेरिक डेटा टाइप रख सकते हैं।

उदाहरण के लिए:

```rust
enum Option<T> {
    Some: T,
    None,
}
```

`Option<T>` एनम किसी भी टाइप की वैकल्पिक वैल्यू दिखा सकता है।

इसी तरह, `Result<T, E>` से आप सफलता और विफलता के टाइप तय कर सकते हैं:

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## जेनेरिक मेथड

मेथड भी जेनेरिक्स का इस्तेमाल कर सकते हैं।

उदाहरण के लिए:

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

आप किसी खास जेनेरिक टाइप के लिए भी मेथड बना सकते हैं, जैसे `Wallet<u128>` के लिए:

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## जेनेरिक टाइपों को मिलाना

जेनेरिक्स से जटिल तरह के मेल भी संभाले जा सकते हैं।

उदाहरण के लिए, अलग-अलग टाइप वाले दो `Wallet` ऑब्जेक्ट मिलाना:

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

`+Drop` कंस्ट्रेंट जोड़ने से कंपाइलर संसाधनों को सही तरीके से संभालना पक्का करता है।

जेनेरिक्स बहुत काम के हैं, लेकिन इनके कंस्ट्रेंट को ध्यान से संभालना पड़ता है।

इनका इस्तेमाल कीजिए और ऐसा कोड लिखिए जो दोबारा इस्तेमाल हो सके, किसी भी टाइप के साथ चले और छोटा रहे।
