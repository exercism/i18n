# परिचय

Python में, [एक एनम](https://docs.python.org/3/library/enum.html) नामों का एक समूह होता है, जिनमें हर नाम किसी अनोखी `literal`, यानी `constant` वैल्यू से बँधा होता है। एनम को `Enum` क्लास से इनहेरिट करके बनाया जाता है। बिल्ट-इन एनम टाइप मॉड्यूल `enum` में उपलब्ध हैं, और `Enum` क्लास को `from enum import Enum` से इम्पोर्ट किया जा सकता है।

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

ध्यान दीजिए कि एनम मेंबर्स की वैल्यू कोई भी डेटा टाइप हो सकती है, जैसे str, tuple, float इत्यादि।

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

जब एनम के दो मेंबर्स को एक ही वैल्यू असाइन की जाती है, तो बाद में असाइन किया गया मेंबर पहले बने मेंबर का एलियस बन जाता है। एनम के दो मेंबर्स के लिए एक ही नाम इस्तेमाल करना मान्य नहीं है।

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

एनम के सभी मेंबर्स पर इटरेशन मानक `for member in` सिंटैक्स से किया जा सकता है:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

एनम के मेंबर्स की तुलना [`is` (_आइडेंटिटी ऑपरेटर_)](https://www.w3schools.com/python/ref_keyword_is.asp) या `is not` से की जा सकती है। `==` या `!=` (_समानता_ऑपरेटर_) भी इसी तरह काम करते हैं।

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

किसी दी गई वैल्यू वाले एनम मेंबर को पाने के लिए `EnumName(value)` इस्तेमाल किया जा सकता है:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
