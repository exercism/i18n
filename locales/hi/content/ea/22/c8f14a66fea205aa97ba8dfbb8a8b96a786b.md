# परिचय

## शर्त वाले स्टेटमेंट

शर्त वाले स्टेटमेंट ऐसे स्टेटमेंट होते हैं जिनमें कोई फैसला लिया जाता है। ये या तो साइड इफेक्ट पैदा करते हैं, या प्रोग्राम में कोड के चलने का क्रम नियंत्रित करते हैं।
शर्त वाले स्टेटमेंट में `if`, `if/else`, `switch` और `ternary` स्टेटमेंट शामिल हैं।

शर्त वाले स्टेटमेंट का इस्तेमाल किसी वैल्यू या वैल्यू के आपसी संबंध के बारे में सवाल पूछने के लिए किया जाता है।
इस सवाल का जवाब बूलियन के रूप में मिलता है, लेकिन `if` स्टेटमेंट खुद कोई भी वैल्यू लौटा सकता है, या सिर्फ कोई साइड इफेक्ट पैदा कर सकता है।

## if स्टेटमेंट

सबसे आसान `if` स्टेटमेंट एक एक्सप्रेशन का मूल्यांकन करता है और कोड की एक लाइन चलाता है।
जिस एक्सप्रेशन की जाँच की जा रही है, वह हमेशा ब्रैकेट में लिखा जाता है।

यह कोई साइड इफेक्ट पैदा कर सकता है

```c
if (count > 10)
    printf("count is greater than 10");
```

या यह तय कर सकता है कि प्रोग्राम आगे किस क्रम में चलेगा


```c
if (count > 10)
    return sum;
```

अगर किसी `if` स्टेटमेंट को एक से ज़्यादा लाइन चलानी हों, तो उन लाइनों को कर्ली ब्रैकेट के अंदर रखना ज़रूरी है

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

कुछ कोडिंग टीमें यह तय कर सकती हैं कि `if` स्टेटमेंट में हमेशा कर्ली ब्रैकेट इस्तेमाल हों, चाहे कोड सिर्फ एक लाइन का ही क्यों न हो।


## if और else

`if` स्टेटमेंट के साथ एक `else` जोड़ा जा सकता है

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## else if


`else` को किसी दूसरे `if` के साथ जोड़कर वह बनाया जा सकता है जिसे `if-else-if ladder` कहते हैं।

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


कभी-कभी `if-else-if ladder` की जगह `switch` से इसे बेहतर ढंग से दर्शाया जा सकता है।
`if` की तरह इसमें भी जिस एक्सप्रेशन की जाँच की जा रही है, वह हमेशा ब्रैकेट में डाला जाता है।

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default` केस तब चलता है, जब जिस वैल्यू की जाँच की जा रही है, वह पिछले किसी केस से मेल नहीं खाती।

अगर `switch` के किसी केस से कोई वैल्यू लौटाई नहीं जा रही, तो हर केस को खत्म करने के लिए आम तौर पर `break` लगाया जाता है। वरना तर्क फॉलथ्रू होकर अगले केस तक पहुँच जाता है।
कभी-कभी फॉलथ्रू जानबूझकर इस्तेमाल किया जाता है

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

जब फॉलथ्रू अनजाने में हो जाता है, तो यह एक बग होता है।

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

जब वैल्यू की किसी श्रेणी की जगह कुछ खास वैल्यू की जाँच करनी हो, तब switch फायदेमंद रहता है।
यह `if-else-if ladder` से तेज़ चल सकता है, क्योंकि कंपाइलर `switch` स्टेटमेंट को ऐसे तरीकों से अनुकूलित कर सकता है, जो लैडर के साथ संभव नहीं हैं।
कभी-कभी switch लैडर की तुलना में पढ़ने में ज़्यादा आसान लगता है।

## टर्नरी (यानी शर्त वाला) ऑपरेटर

टर्नरी ऑपरेटर तीन हिस्सों वाला शर्त वाला स्टेटमेंट है, जिसका इस्तेमाल अक्सर कोई वैल्यू सेट करने के लिए किया जाता है।
जिस एक्सप्रेशन की जाँच करनी है, वह प्रश्नवाचक चिह्न से पहले आता है और उसे ब्रैकेट में लिखना ज़रूरी नहीं है।
अगर शर्त सही हो तो जो वैल्यू लौटाई जाती है, वह कोलन से पहले आती है; अगर शर्त गलत हो तो जो वैल्यू लौटाई जाती है, वह कोलन के बाद आती है।
जो लौटाया जाता है, वह कोई वैल्यू लिटरल भी हो सकता है और कोई वेरिएबल भी।

```c
int i = j > 5 ? 5: j;
```

कोड कम उलझा रहे, इसके लिए टर्नरी ऑपरेटरों को नेस्टेड रखा जा सकता है।

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
