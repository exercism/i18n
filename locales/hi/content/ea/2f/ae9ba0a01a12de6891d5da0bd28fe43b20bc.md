# निर्देश

इस अभ्यास में आप फैक्ट्री के कर्मचारियों के लिए नाम बैज प्रिंट करने का कोड लिखेंगे।

## 1. कर्मचारी के लिए बैज प्रिंट कीजिए

कर्मचारियों के पास एक ID, नाम और विभाग का नाम होता है। कर्मचारी के बैज लेबल का प्रारूप इस तरह होता है: `"[id] - name - DEPARTMENT"`।
किसी कर्मचारी का बैज लेबल लौटाने के लिए `Badge.print()` मेथड लागू कीजिए:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

ध्यान दीजिए कि लेबल पर विभाग का नाम बड़े अक्षरों में होना चाहिए।

## 2. नए कर्मचारी के लिए बैज प्रिंट कीजिए

कंप्यूटर सिस्टम में एक अजीब सी बात है, जिसके कारण कभी-कभी नए कर्मचारियों के पास फैक्ट्री में काम शुरू करते समय अभी तक ID नहीं होता।
चूँकि बैज ज़रूरी होते हैं, इसलिए उन्हें ID प्रीफिक्स के बिना एक अस्थायी बैज मिलेगा। `Badge.print()` मेथड में बदलाव कीजिए ताकि वह उन नए कर्मचारियों के लिए भी काम करे जिनके पास अभी तक ID नहीं है:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. मालिक के लिए बैज प्रिंट कीजिए

फैक्ट्री के मालिक को भी हर समय बैज पहनना पड़ता है।
लेकिन मालिक का कोई विभाग नहीं होता। ऐसी स्थिति में, लेबल पर विभाग के नाम की जगह `"OWNER"` प्रिंट होना चाहिए।
मालिक के लिए लेबल प्रिंट करने के लिए `Badge.print()` मेथड में बदलाव कीजिए:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

ध्यान दीजिए कि यह भी संभव है कि मालिक नया कर्मचारी भी हो:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
