# निर्देश

आप! हाँ, आप ही, बहादुर Lisp कोडर! [Lisp एलियन Lenny][alien] को आपकी मदद चाहिए! Lenny दूसरे सारे Lisp एलियन के साथ घूमने जाना चाहते हैं, लेकिन Lenny के माता-पिता ने कह दिया है कि जब तक Lenny का कमरा साफ नहीं हो जाता, वे कहीं नहीं जाएँगे।

दिक्कत यह है कि Lenny को फर्श तक ठीक से दिखता ही नहीं! Lenny अपने एटम और कॉन्स में फर्क नहीं कर पाते, अपने सिंबल और कीवर्ड में नहीं, और अपने `car` और `cdr` में भी नहीं!

क्या आप Lenny को यह गड़बड़ सुलझाने में मदद कर सकते हैं? अपने [कोष्ठक][xkcd] मत भूलिए, आपको इनकी ज़रूरत पड़ेगी!

## 1. Lenny को सिंबल याद दिलाइए

शुरू करने से पहले Lenny को यह याद करना है कि सिंबल और कीवर्ड दिखते कैसे हैं। पिछली बार सफाई किए बहुत समय हो गया है... आप Lenny की मदद दो फंक्शन बनाकर कीजिए: `lennys-favorite-food`, जो किसी सिंबल का मान देता है, और `lennys-secret-keyword`, जो किसी कीवर्ड का मान देता है। उदाहरण:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

ध्यान दीजिए कि आप कोई भी सिंबल या कीवर्ड लौटा सकते हैं (अगर आपको लसागना पसंद नहीं है या आप एलियन के अस्तित्व पर विश्वास नहीं करते)।

## 2. Lenny को एटम और कॉन्स में फर्क करने में मदद कीजिए

सिंबल और कीवर्ड की समझ ताज़ा कर लेने के बाद Lenny को सफाई शुरू करनी है! कमरे में बिखरे सारे एस-एक्सप्रेशन छाँटने के लिए Lenny को यह तय करने में मदद चाहिए कि कौन-सा कॉन्स है और कौन-सा एटम। आप दो फंक्शन लिखकर मदद कर सकते हैं: `is-an-atom-p` और `is-a-cons-p`:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

इस भाग के लिए Lisp के कई बिल्ट-इन फंक्शन आपके काम आ सकते हैं। साथ ही, फिलहाल आप `T` को सही और `NIL` को गलत मान सकते हैं।

## 3. Lenny के कॉन्स को टुकड़ों में बाँटने में मदद कीजिए

अंत में, Lenny के कॉन्स इतने बड़े हैं कि करीने से रखे नहीं जा सकते, इसलिए Lenny को इन्हें छोटे-छोटे हिस्सों में बाँटना है। क्या आप Lenny के कॉन्स तोड़ने के लिए दो और फंक्शन बनाकर मदद कर सकते हैं (`first-thing` और `rest-of-it`)?

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

यहाँ भी Common Lisp के कुछ बिल्ट-इन फंक्शन आपके काम आ सकते हैं।
