# परिचय

[Go](https://golang.org) एक स्टैटिकली टाइप्ड, कंपाइल्ड प्रोग्रामिंग भाषा है।
यह अभ्यास भाषा की तीन बड़ी विशेषताओं से आपका परिचय कराता है: पैकेज, फंक्शन और वेरिएबल।

## पैकेज

Go के एप्लिकेशन पैकेजों में व्यवस्थित होते हैं।
पैकेज एक ही डायरेक्टरी में रखी सोर्स फाइलों का समूह होता है।
एक डायरेक्टरी की सभी सोर्स फाइलों का पैकेज नाम एक ही होना चाहिए।
जब किसी पैकेज को इम्पोर्ट किया जाता है, तो उसकी केवल वे चीज़ें (फंक्शन, टाइप, वेरिएबल, कॉन्स्टेंट) इस्तेमाल की जा सकती हैं जिनके नाम बड़े अक्षर से शुरू होते हैं।
Go में नाम रखने का सुझाया हुआ तरीका यह है कि आइडेंटिफायर `camelCase` में लिखे जाते हैं।
इसका अपवाद वे आइडेंटिफायर हैं जिन्हें अलग-अलग पैकेजों से उपलब्ध होना चाहिए; उन्हें `PascalCase` में लिखा जाना चाहिए।

```go
package lasagna
```

## वेरिएबल

Go स्टैटिकली टाइप्ड है, यानी कंपाइल होने के समय ही हर वेरिएबल का [टाइप तय होना ज़रूरी है](https://en.wikipedia.org/wiki/Type_system)।

वेरिएबल को टाइप स्पष्ट रूप से बताकर भी बनाया जा सकता है:

```go
var explicit int // Explicitly typed
```

आप इनिशियलाइज़र का उपयोग भी कर सकते हैं। तब कंपाइलर वेरिएबल का टाइप इनिशियलाइज़र के टाइप के हिसाब से असाइन कर देगा।

```go
implicit := 10   // Implicitly typed as an int
```

घोषित होने के बाद वेरिएबलो को `=` ऑपरेटर से वैल्यू असाइन की जा सकती है।
लेकिन घोषित होने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## कॉन्स्टेंट

कॉन्स्टेंट भी वेरिएबलो की तरह एक डेटा रखते हैं, लेकिन प्रोग्राम के चलने के दौरान उनकी वैल्यू नहीं बदल सकती।

कॉन्स्टेंट `const` कीवर्ड से बनाए जाते हैं। ये संख्या, अक्षर, स्ट्रिंग या बूलियन हो सकते हैं:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## फंक्शन

Go के फंक्शन शून्य या उससे अधिक पैरामीटर लेते हैं।
हर पैरामीटर का टाइप स्पष्ट रूप से लिखना ज़रूरी है। टाइप का अनुमान नहीं लगाया जाता।

फंक्शन से वैल्यू `return` कीवर्ड से लौटाई जाती हैं।

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट दिए जाते हैं।

ध्यान दीजिए कि Go में दो तरह के कमेंट होते हैं।
एक लाइन वाले कमेंट से पहले `//` लगाया जाता है, और कई लाइनों वाले कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
