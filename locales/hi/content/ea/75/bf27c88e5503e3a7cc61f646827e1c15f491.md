# फैशन बुटीक

## कहानी

आप एक ऑनलाइन फैशन बुटीक चला रहे हैं। ब्लैक फ्राइडे नज़दीक है, इसलिए तैयार रहने के लिए आपको अपनी इन्वेंटरी का हिसाब लगाना है।

इन्वेंटरी की एक चीज़ को एक मैप/डिक्शनरी से दर्शाया जाता है, और पूरी इन्वेंटरी ऐसे ही मैप/डिक्शनरी की एक लिस्ट/ऐरे होती है।

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## कार्य

- चीज़ों को कीमत के हिसाब से क्रम में लगाइए।
- जिन चीज़ों की कीमत नहीं है, उन सभी को ढूँढिए।
- चीज़ की मात्रा बढ़ाइए।
- चीज़ की कुल मात्रा निकालिए।
