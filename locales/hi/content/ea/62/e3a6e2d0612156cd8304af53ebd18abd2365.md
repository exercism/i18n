# निर्देश परिशिष्ट

## प्रोजेक्ट संरचना

Exercism में Clojure के अभ्यास डिपेंडेंसी प्रबंधन और टेस्टिंग के लिए सबसे आम दो टूल के साथ काम करते हैं: [leiningen][leiningen] और [Clojure CLI][clojure-cli].

`test` डायरेक्टरी के अंदर आपको `hello_world_test.clj` नाम की एक टेस्ट फाइल मिलेगी।
अपना कोड `src/hello_world.clj` में लिखिए। उसे `hello-world` नेमस्पेस इस्तेमाल करना चाहिए ताकि टेस्ट उसे पहचान सकें।

### Clojure CLI से टेस्ट चलाना

```
$ clj -X:test
```

### Leiningen से टेस्ट चलाना

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

इसके बाद अभ्यास सबमिट करने के लिए यह कमांड चलाइए:

```
$ exercism submit src/hello_world.clj
```

अधिक विस्तृत निर्देशों और सीखने के संसाधनों के लिए [Exercism के Clojure भाषा पेज][exercism-clojure] देखिए।

[clojure-cli]: https://clojure.org/guides/deps_and_cli
