# निर्देश परिशिष्ट

## शब्द

`classify ( n -- str )` इनमें से कोई एक स्ट्रिंग लौटाता है: `"perfect"`, `"abundant"`, या `"deficient"`।

## एरर

जब इनपुट शून्य या ऋणात्मक हो, तो यह स्ट्रिंग थ्रो कीजिए:

```
"Classification is only possible for positive integers."
```

(हूबहू, अंत में लगे पूर्ण विराम सहित)।
