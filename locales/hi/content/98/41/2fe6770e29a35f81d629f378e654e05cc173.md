# स्ट्रिंग बिल्डर

एक `STR` कभी नहीं बदलता। इसलिए `+` उसमें जोड़ नहीं सकता। उसे दोनों का सारा सामान लेकर एक पूरी नई स्ट्रिंग बनानी पड़ती है।

एक बार तो यह ठीक है। लेकिन लूप के अंदर नहीं:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

हर चक्कर में अब तक जो बना है वह पूरा एक नई स्ट्रिंग में कॉपी होता है और पुरानी स्ट्रिंग फेंक दी जाती है। दस लाइनों का मतलब है दस कॉपियाँ, और हर कॉपी पिछली से लंबी। सौ लाइनों का मतलब है सौ कॉपियाँ। काम लाइनों की संख्या के *वर्ग* के हिसाब से बढ़ता है, और जो लूप देखने में बिलकुल ठीक लगता है वही प्रोग्राम का धीमा हिस्सा बन जाता है।

## FSTR

`FSTR` एक ऐसी स्ट्रिंग है जिसे बदला जा सकता है, यानी एक **स्ट्रिंग बिल्डर**। इसमें जोड़ने पर आम तौर पर सीधे उसी जगह लिखा जाता है जो पहले से मौजूद है। इसलिए सौ लाइनों वाले लूप में सौ कॉपियों के बजाय लगभग सौ लाइनों जितना ही काम होता है।

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

तीन बातों पर ध्यान दीजिए।

**`#FSTR` एक खाली बिल्डर बनाता है।** `#FSTR(100)` ऐसा बिल्डर बनाता है जिसमें सौ अक्षरों की जगह पहले से अलग रखी होती है। जब आकार पता हो तो ऐसा करना फायदेमंद होता है।

**नतीजे को लौटाकर वापस असाइन करना ज़रूरी है।** `script := script + ...` लिखिए, कभी अकेले `script + ...` नहीं। आम तौर पर नतीजा वही बिल्डर होता है जो अंदर गया था, लेकिन जब उसमें जगह खत्म हो जाती है तो वह एक बड़ा, नया बिल्डर होता है। ऐसे में नतीजे को छोड़ देने का मतलब है कि आप पुराने बिल्डर में ही लिखते रह जाएँगे।

**अंत में `.str`।** जो रूटीन `: STR` लौटाने का वादा करता है, उसे एक `STR` लौटाना ही होता है, और `.str` बिल्डर से वह `STR` बना देता है।

## क्या-क्या जोड़ा जा सकता है

`FSTR` पर लगाया गया `+` स्ट्रिंग, अक्षर, पूर्णांक या बूलियन, इनमें से किसी को भी स्वीकार कर लेता है। इसलिए आम तौर पर पहले बदलने की ज़रूरत नहीं पड़ती:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## नई लाइनें

स्ट्रिंग के अंदर `"\n"` एक नई लाइन होती है। यह एक ही अक्षर है, जिसे दो अक्षरों में लिखा जाता है।

```sather
   script := script + "Enter" + "\n" + "Exit";
```
