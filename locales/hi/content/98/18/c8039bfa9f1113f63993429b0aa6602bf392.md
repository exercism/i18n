# निर्देश परिशिष्ट

## Python ट्रैक के लिए यह अभ्यास किस तरह बनाया गया है

इस अभ्यास के टेस्ट यह अपेक्षा करते हैं कि आपका हल Python में एक School `class` के रूप में लिखा जाए। अगर आप Python में `class` से परिचित नहीं हैं, तो [concept:python/classes]() और [आधिकारिक Python डॉक्युमेंटेशन में `classes`][classes in python] से शुरुआत करना अच्छा रहेगा।

[classes in python]: https://docs.python.org/3/tutorial/classes.html
