# निर्देश

इस अभ्यास में आप न्यूयॉर्क के एक ब्यूटी सैलून के लिए अपॉइंटमेंट शेड्यूलर पर काम करेंगे। यह सैलून 15 सितंबर 2012 को खुला था।

## 1. अपॉइंटमेंट की तारीख पढ़िए

अपॉइंटमेंट की तारीख के टेक्स्ट रूप को पढ़कर उसे संबंधित `LocalDateTime` में बदलने के लिए `AppointmentScheduler.schedule()` मेथड लागू कीजिए:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. जाँचिए कि अपॉइंटमेंट का समय बीत चुका है या नहीं

`AppointmentScheduler.hasPassed()` मेथड लागू कीजिए, जो अपॉइंटमेंट की तारीख लेता है और जाँचता है कि अपॉइंटमेंट का समय कहीं अतीत में तो नहीं था:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. जाँचिए कि अपॉइंटमेंट दोपहर में है या नहीं

`AppointmentScheduler.isAfternoonAppointment()` मेथड लागू कीजिए, जो अपॉइंटमेंट की तारीख लेता है और जाँचता है कि अपॉइंटमेंट दोपहर में है या नहीं (>= 12:00 और < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. अपॉइंटमेंट की तारीख और समय बताइए

`AppointmentScheduler.getDescription()` मेथड लागू कीजिए, जो अपॉइंटमेंट की तारीख लेता है और उस तारीख और समय का विवरण लौटाता है:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. सालगिरह की तारीख लौटाइए

`AppointmentScheduler.getAnniversaryDate()` मेथड लागू कीजिए, जो इस साल की सालगिरह की तारीख लौटाता है, यानी 15 सितंबर:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
