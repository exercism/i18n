# निर्देश

इस अभ्यास में आप कुछ कोड लिखेंगे जो आपको वाहन खरीदने की तैयारी में मदद करेगा।

आपके सामने तीन काम हैं: एक यह तय करना कि आपको लाइसेंस की ज़रूरत है या नहीं, दूसरा दो वाहनों में से चुनने में मदद करना, और तीसरा पुराने वाहन के लिए उचित कीमत का अनुमान लगाना।

## 1. तय कीजिए कि आपको ड्राइविंग लाइसेंस की ज़रूरत होगी या नहीं

कुछ तरह के वाहन चलाने के लिए ड्राइविंग लाइसेंस ज़रूरी होता है।
मान लीजिए कि सिर्फ `"car"` और `"truck"` तरह के वाहनों के लिए लाइसेंस ज़रूरी है, बाकी सब बिना लाइसेंस के चलाए जा सकते हैं।

`needsLicense(kind)` फंक्शन बनाइए, जो वाहन का प्रकार लेता है और एक बूलियन लौटाता है। यह बूलियन बताता है कि उस प्रकार के वाहन के लिए आपको लाइसेंस चाहिए या नहीं।

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. खरीदने के लिए दो संभावित वाहनों में से एक चुनिए

आप अपने पास उपलब्ध वाहनों के विकल्पों को देखते हैं।
आप उन्हें दो विकल्पों तक सीमित कर लेते हैं, लेकिन अंतिम फैसला करने में आपको मदद चाहिए।
इसके लिए `chooseVehicle(option1, option2)` फंक्शन बनाइए, जो दो वाहन आर्गुमेंट के रूप में लेता है और ऐसा फैसला लौटाता है जिसमें वह विकल्प शामिल होता है जो [शब्दकोशीय क्रम][lexicographical-order] में पहले आता है।

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. पुराने वाहन की कीमत का अनुमान लगाइए

अब जब आपने फैसला कर लिया है, तो आप चाहते हैं कि डीलरशिप पर आपको उचित दाम मिले।
चूँकि आप पुराना वाहन खरीदना चाहते हैं, इसलिए कीमत इस बात पर निर्भर करती है कि वाहन कितना पुराना है।
मोटे अनुमान के लिए मान लीजिए कि अगर वाहन 3 साल से कम पुराना है, तो उसकी कीमत उस मूल कीमत का 80% होती है जो बिल्कुल नया होने पर थी।
अगर वह कम से कम 10 साल पुराना है, तो उसकी कीमत 50% होती है।
अगर वाहन कम से कम 3 साल पुराना है लेकिन 10 साल से कम, तो उसकी कीमत मूल कीमत का 70% होती है।

`calculateResellPrice(originalPrice, age)` फंक्शन बनाइए जो `if`, `else if` और `else` का उपयोग करके यह तर्क लागू करता है (अगर आप अभ्यास करना चाहें तो और भी तरीके हैं)।
यह मूल कीमत और वाहन की उम्र आर्गुमेंट के रूप में लेता है और डीलरशिप पर अनुमानित कीमत लौटाता है।

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
