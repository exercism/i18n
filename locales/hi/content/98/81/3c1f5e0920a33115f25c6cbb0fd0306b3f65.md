# निर्देश अपेंड

## वर्ड

एक `custom-set` टपल बनाइए और `INSTANCE: custom-set set` लिखकर उसे `set` मिक्सिन का इंस्टेंस घोषित कीजिए।

- `<custom-set> ( -- set )`: खाली सेट बनाता है।
- `>custom-set ( seq -- set )`: किसी सीक्वेंस से सेट बनाता है और डुप्लिकेट चुपचाप हटा देता है।

इसके बाद `custom-set` के लिए `members`, `in?`, `adjoin` और `set-like` पर `M:` मेथड (जो `sets` से आते हैं) दीजिए। `INSTANCE:` घोषणा और ये चारों मेथड मौजूद होने पर `sets` वोकैबुलरी के `null?`, `union`, `intersect`, `diff`, `subset?`, `set=` और `intersects?` सब प्रोटोकॉल के डिफ़ॉल्ट इम्प्लीमेंटेशन के ज़रिए आपके सेट पर काम करते हैं। टेस्ट उन वर्ड को सीधे कॉल करते हैं।

`adjoin ( elt set -- )` सेट को बदल देता है: अगर `elt` पहले से `set` में नहीं है, तो यह उसे उसी `set` में जोड़ देता है।
