# `while` और `until` लूप

लूप एक कंट्रोल स्ट्रक्चर है, जो किसी दी गई शर्त के आधार पर कोड को बार-बार चलाने देता है।

## `while` लूप

`while` लूप एक कंट्रोल स्ट्रक्चर है, जो किसी दी गई शर्त के आधार पर कोड को बार-बार चलाने देता है।
जब तक शर्त सही होती है, `while` लूप के अंदर का कोड चलता रहता है।
`while` लूप अक्सर तब इस्तेमाल किए जाते हैं जब इटरेशन की संख्या पहले से पता न हो, लेकिन इन्हें हर उस जगह इस्तेमाल किया जा सकता है जहाँ लूप की ज़रूरत हो।

लूप के अंदर का कोड चलने से पहले शर्त की जाँच की जाती है। इसका मतलब है कि अगर शर्त गलत है, तो लूप के अंदर का कोड कभी नहीं चलेगा।

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

किसी स्ट्रिंग पर इटरेशन करना हो, तो आप स्ट्रिंग की लंबाई पर लूप चला सकते हैं।

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until` लूप

`until` लूप `while` लूप की तरह ही काम करते हैं, बस फर्क इतना है कि लूप के अंदर का कोड तब तक चलता रहता है जब तक शर्त सही न हो जाए।
यह वही अंतर है जो `if` और `unless` के बीच होता है।

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### अनंत लूप

`while` लूप के साथ एक आम गलती है अनंत लूप में फँस जाना, जो कभी खत्म नहीं होता।
अनंत लूप की एक वजह यह भी हो सकती है कि कोई शर्त _कभी_ सही या गलत न हो।
ऐसा अक्सर प्रोग्रामर की गलती से होता है, जैसे लूप वेरिएबल को बढ़ाना भूल जाना।
लेकिन कई बार प्रोग्राम का लॉजिक लागू करने का सबसे साफ़ तरीका अनंत लूप ही होता है।
या कभी-कभी हमेशा के लिए लूप चलाना ज़रूरी होता है, जैसे कोई HTTP सर्वर किसी आने वाले कनेक्शन की प्रतीक्षा करता है, उसे संभालता है, और फिर अगले कनेक्शन की प्रतीक्षा करता है।

## `break`

`break` कीवर्ड का इस्तेमाल लूप से जल्दी बाहर निकलने के लिए किया जा सकता है।
यह तब काम आता है जब आप किन्हीं खास शर्तों के तहत लूप से जल्दी बाहर निकलना चाहते हों।

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next` कीवर्ड का इस्तेमाल लूप के अगले इटरेशन पर जाने के लिए किया जा सकता है।
यह तब काम आता है जब आप लूप के कुछ खास इटरेशन छोड़ना चाहते हों।

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## लूप के दौरान टाइप

लूप के दौरान वेरिएबल का टाइप बदल सकता है।
नीचे दिए उदाहरण में `a` का टाइप `Int32 | String` है, क्योंकि लूप के पहले हिस्से में यह `Int32` या `String` हो सकता है।
लूप के पहले हिस्से में ही वेरिएबल `a` का टाइप `Int32 | String` रहता है, क्योंकि लूप शुरू होते समय उसमें `Int32` रहता है और दूसरे इटरेशन में उसमें `String` रहता है।
एक वेरिएबल का टाइप एक से ज़्यादा हो सकता है, इसे आगे विस्तार से समझाया जाएगा।
लेकिन चूँकि हमें पक्का पता है कि लूप के दूसरे हिस्से में सिर्फ `String` रहेगा, इसलिए लूप के दूसरे हिस्से में `a` का टाइप `String` है।
रनटाइम पर यह कभी एक ही समय में `Int32` और `String` दोनों नहीं रखेगा।

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
