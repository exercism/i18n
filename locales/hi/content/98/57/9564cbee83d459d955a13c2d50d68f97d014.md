# संकेत

## 1. स्वीकृति बनाइए

- कस्टम टाइप `pub type Name { Variant1 }` सिंटैक्स से बनाए जा सकते हैं।

## 4. गतिविधि बनाइए

- डेटा रखने वाले कस्टम टाइप `pub type Name { Variant1(SomeType) }` सिंटैक्स से बनाए जा सकते हैं।

## 5. गतिविधि को रेटिंग दीजिए

- कस्टम टाइप के वेरिएंट पर case एक्सप्रेशन से पैटर्न मैच किया जा सकता है।
- अगर आप किसी पैटर्न में एक और शर्त जोड़ना चाहते हैं, तो आप `if` कीवर्ड का उपयोग करके उस पैटर्न में एक गार्ड जोड़ सकते हैं।
