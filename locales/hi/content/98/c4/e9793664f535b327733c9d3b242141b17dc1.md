# निर्देश

स्वागत है, इंजीनियर!
आप Speedywagon Foundation के उन गिने-चुने दिग्गजों में से हैं जो अब तक बचे हैं। यह एक गुप्त संस्था है, जो दशकों से Pillar Men जैसे पुराने खतरों से लोहा लेती आ रही है।
इस काम के दौरान आपने कई साल Speedywagon Foundation के तकनीकी सिस्टम की देखरेख करने में लगाए हैं, जो नई तकनीक और पुरानी लाइब्रेरी के मेल से बने हैं।

लेकिन इन दिनों Pillar Men की गतिविधियों पर नज़र रखने वाले सेंसर ठीक से काम नहीं कर रहे हैं।
Speedywagon Foundation के सिस्टम पुराने हैं, और यह कोड एक पुरानी C++ लाइब्रेरी से जुड़ा है जिसे अपडेट नहीं किया जा सकता।
आपको चार मुख्य फंक्शन बनाने हैं, जो पुराने ज़माने की पॉइंटर-आधारित लाइब्रेरी की मदद से Pillar Men सेंसर की गतिविधि पर नज़र रखते हैं।

आधुनिक C++ इंजीनियर होने के नाते आप स्मार्ट पॉइंटर इस्तेमाल करना पसंद करेंगे, लेकिन पुराने कोड को पुराने तरीकों का सम्मान देना ही पड़ता है।
मानवता का भविष्य इन पॉइंटरों पर टिका हो सकता है, इसलिए सावधानी से आगे बढ़िए, और Hamon ऊर्जा आपका मार्गदर्शन करे।

~~~~exercism/note
चूँकि सेंसर की रीडिंग बहुत बड़ी हो सकती है, इसलिए हम एक नमूना _struct_ दे रहे हैं, जो असली लाइब्रेरी में इस्तेमाल होता है।
यह कोड आपके लिए हेडर फाइल में पहले से बना दिया गया है।

```cpp
struct pillar_men_sensor {
    int activity{};
    std::string location{};
    std::vector<int> data{};
};
```
~~~~

## 1. सेंसर कनेक्शन जाँचिए (`connection_check`)

सबसे पहले आपको यह देखना है कि Pillar Men सेंसर ठीक से जुड़ा है या नहीं।
सेंसर के जुड़े न होने पर झूठे अलार्म नहीं बजने चाहिए।
आप एक फंक्शन `connection_check` लिखेंगे, जो `nullptr` जाँचकर बताता है कि सेंसर का पॉइंटर मान्य है या नहीं।

- ऐसा फंक्शन बनाइए जो `pillar_men_sensor` _struct_ के पॉइंटर को लेता हो।
- अगर सेंसर का पॉइंटर null नहीं है तो फंक्शन `true` लौटाए, वरना `false`।

```cpp
pillar_men_sensor* sensor{nullptr};
bool isConnected = connection_check(sensor);
// isConnected => false
```

## 2. सेंसर की गतिविधि गिनिए (`activity_counter`)

Pillar Men छाया में छिपे हुए हैं, और हमें पता होना चाहिए कि सेंसरों ने कोई गतिविधि पकड़ी है या नहीं।
आप `activity_counter` फंक्शन लिखेंगे, जो सेंसरों का एक ऐरे और ऐरे में मौजूद सेंसरों की संख्या बताने वाली क्षमता लेता है।

- ऐसा फंक्शन बनाइए जो ऐरे के पहले एलिमेंट का पॉइंटर और ऐरे की क्षमता लेता हो।
- पॉइंटर अरिथमेटिक की मदद से सेंसर ऐरे पर लूप चलाइए और गतिविधि की रीडिंग जोड़ते जाइए।
- जोड़ी गई कुल गतिविधि लौटाइए।

```cpp
pillar_men_sensor sensor_array[3] = {{0}, {101}, {22}};
int totalActivity = activity_counter(sensor_array, 3);
// totalActivity => 123
```

## 3. अलार्म नियंत्रण (`alarm_control`)

हर सेंसर से अलार्म नहीं बजना चाहिए; अलार्म तभी बजना चाहिए जब वाकई कोई खतरा हो।
`alarm_control` फंक्शन यह सुनिश्चित करता है कि सेंसर अलार्म तभी बजाए जब उसकी गतिविधि का स्तर 0 से ज़्यादा हो।
यह फंक्शन null सेंसर भी जाँचता है, ताकि सिस्टम क्रैश न हो।

- ऐसा फंक्शन बनाइए जो `pillar_men_sensor` का पॉइंटर लेता हो।
- फंक्शन सबसे पहले देखे कि सेंसर `nullptr` है या नहीं। अगर सेंसर `nullptr` है तो `false` लौटाइए।
- अगर सेंसर मान्य है और उसकी गतिविधि 0 से ज़्यादा है तो `true` लौटाइए, वरना `false`।

```cpp
pillar_men_sensor db{9008, "songokunoie", {7, 7, 7}};
bool alarm = alarm_control(&db);
// alarm => true
```

## 4. `uv_alarm` फंक्शन से डेटा में असामान्यताएँ जाँचिए

इस काम में आप `uv_alarm` फंक्शन बनाएँगे, जो यह तय करता है कि UV रोशनी के स्तर और सेंसर की गतिविधि के आधार पर अलार्म बजाना चाहिए या नहीं।
`uv_alarm` फंक्शन को दिए गए `uv_light_heuristic` फंक्शन का इस्तेमाल करना चाहिए, जो डेटा के वेक्टर पर काम करता है और कुछ सीमाओं के आधार पर एक वैल्यू लौटाता है।
यह उस जटिल कोड का नमूना रूप है जो असल में चलेगा, इसलिए कृपया इसका इंटरफेस न बदलिए।

`uv_alarm` फंक्शन को `speedywagon` नेमस्पेस में बनाइए। इस फंक्शन को यह करना है:

- अपने पैरामीटर के रूप में `pillar_men_sensor` _struct_ का पॉइंटर लेना।
- सेंसर का पॉइंटर null हो तो `false` लौटाना।
- सेंसर के `data` ऐरे का पता देकर `uv_light_heuristic` फंक्शन को कॉल करना।
- अगर `uv_light_heuristic` से लौटी वैल्यू `sensor->activity` के स्तर से ज़्यादा है तो `true` लौटाना, वरना `false`।
