# निर्देश

आप एक कटर पर तैनात वॉच ऑफ़िसर हैं, जो बेरिंग जलडमरूमध्य से गुज़र रहा है। तीन स्रोत नज़र में आने वाली हर बर्फ़ की चादर और हर अंतरीप की स्थिति बता रहे हैं:

- **चार्ट डेस्क** कम्पास की दिशाओं में बोलता है: `north`, `east`, `south`, `west`. सिर्फ़ हेडिंग, कोई दूरी नहीं।
- **नेविगेटर** कटर की अंतिम ज्ञात स्थिति से *ध्रुवीय* निर्देशांकों में बोलता है: नॉटिकल माइल में मैग्निट्यूड, और उत्तर से दक्षिणावर्त डिग्री में बेयरिंग (यानी `0` उत्तर है, `90` पूर्व, `180` दक्षिण, `270` पश्चिम)।
- **मस्तूल पर तैनात पहरेदार** *सापेक्ष* निर्देशांकों में बोलता है: आगे की दूरी, और `ahead`, `starboard`, `behind`, `port` में से एक। सापेक्ष बेयरिंग *जहाज़ की मौजूदा हेडिंग* के सापेक्ष मापी जाती हैं। कप्तान हर वॉच से पहले ब्रिज पर वह हेडिंग बताता है।

आपको इन तीनों को एक ही कार्टीशियन `(x, y)` तंत्र में बदलना है, ताकि चार्ट बनाया जा सके। बेयरिंग डिग्री में होती हैं; `(0, 1)` उत्तर की ओर एक नॉटिकल माइल है, और `(1, 0)` पूर्व की ओर एक नॉटिकल माइल।

## 1. डेटा मॉडल, और कार्डिनल के लिए कार्टीशियन

सबसे पहले पूरे अभ्यास में साझा होने वाले हिस्से तैयार कीजिए:

- तीन ट्यूपल परिभाषित कीजिए: `cardinal` (एक स्लॉट, `direction`), `polar` (स्लॉट `magnitude` और `bearing`), और `relative` (स्लॉट `distance` और `bearing`)।
- `SYMBOLS:` से हेडिंग सिंबल घोषित कीजिए: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`.
- `SYMBOL:` से एक डायनामिक वेरिएबल `heading` घोषित कीजिए (टास्क 3 में इसका उपयोग होता है)।
- दो जेनेरिक शब्द घोषित कीजिए: `GENERIC: >cartesian ( direction -- x y )` और `GENERIC: flip ( direction -- direction' )`. इनके मेथड आप आगे के टास्कों में जोड़ेंगे।

फिर `>cartesian` का `M: cardinal` मेथड जोड़िए, जो नामित दिशा का इकाई वेक्टर लौटाता है।

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. ध्रुवीय के लिए कार्टीशियन

`>cartesian` में एक `M: polar` मेथड जोड़िए जो ध्रुवीय रूप को `(x, y)` में बदलता है:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. सापेक्ष के लिए कार्टीशियन

`>cartesian` में एक `M: relative` मेथड जोड़िए। ध्यान देने की बात यह है कि सापेक्ष बेयरिंग जहाज़ की *मौजूदा हेडिंग* के सापेक्ष मापी जाती है, और वह हेडिंग ट्यूपल का हिस्सा नहीं है। (टास्क 1 में घोषित) `heading` वेरिएबल को `heading get` से पढ़िए, उसमें बेयरिंग ऑफ़सेट जोड़िए (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`), और कार्टीशियन बिंदु बनाइए। जो कोड इसे कॉल करता है, वह `heading` को एक `with-variable` ब्लॉक के अंदर सेट करता है।

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. उलटिए

`flip` जेनेरिक (टास्क 1 में घोषित) के मेथड जोड़िए, ताकि यह उलटी दिशा लौटाए।

- `cardinal` के लिए: उत्तर ↔ दक्षिण, पूर्व ↔ पश्चिम।
- `polar` के लिए: बेयरिंग में 180° जोड़िए (360 का मॉड्यूलो)।
- `relative` के लिए: आगे ↔ पीछे, दाएँ ↔ बाएँ।

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. बेयरिंग जोड़िए

`add-bearings ( a b -- x y )` परिभाषित कीजिए, जो दोनों दिशाओं को कार्टीशियन में बदलकर उनका जोड़ लौटाता है। यह `cardinal`, `polar` और `relative` के किसी भी मेल पर काम करता है। `>cartesian` के लिए जेनेरिक इस्तेमाल करने का फ़ायदा यही है।

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
