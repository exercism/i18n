# निर्देश

टाइप जाँच के साथ HTTP एंडपॉइंट और बेहतर हो जाते हैं। POST रिक्वेस्ट में एक रिकॉर्ड टाइप जोड़ने से हर बार सही डेटा भेजा जाना सुनिश्चित होता है।

## उद्देश्य

- दिए गए कोड में बदलाव कीजिए।
- इस रिकॉर्ड में ज़रूरी एट्रिब्यूट जोड़िए ताकि यह दो ऑपरेंड और एक ऑपरेटर ले सके।
- '/calc' पाथ पर POST रिक्वेस्ट लेने के लिए एक HTTP रिसोर्स फंक्शन जोड़िए।
- यह फंक्शन पेलोड के रूप में Calculation रिकॉर्ड टाइप ले और एक जेनेरिक JSON ऑब्जेक्ट लौटाए।

### स्वीकार करता है

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### लौटाता है

```json
{ "expression": "4+10.2", "result": 14.2 }
```
