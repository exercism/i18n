# निर्देश

अपनी कंपनी में डेवलपर एंड्रयू ने हाल ही में डेटाबेस माइग्रेशन टूल के लिए एक हल्का-फुल्का SQL क्वेरी जनरेटर टूल बनाया था।
छोटे डेटा सेट के लिए उनका पहला सरल कार्यान्वयन बिल्कुल ठीक काम कर गया।
लेकिन बड़े प्रोडक्शन माइग्रेशन के दौरान ऐप्लिकेशन बहुत ज़्यादा मेमोरी खाने लगा और भारी लोड में बुरी तरह फँसने लगा।
ऐप्लिकेशन की प्रोफाइलिंग करने के बाद एंड्रयू को समझ आया कि लूप के अंदर सामान्य स्ट्रिंग जोड़ने से Go को बार-बार मेमोरी फिर से आवंटित करनी पड़ रही थी।
अब उन्हें इस टूल को Go की `strings.Builder` का उपयोग करके फिर से लिखने में आपकी मदद चाहिए, ताकि ऐप्लिकेशन अच्छी तरह स्केल कर सके और मेमोरी हीप को कुचले बिना बड़ी मात्रा में टेक्स्ट संभाल सके।

## 1. SELECT क्वेरी बनाइए

`BuildSelectQuery` फंक्शन लिखिए।
यह एक टेबल का नाम (`string`) और कॉलम के नामों का स्लाइस (`[]string`) लेता है।
इसे एक पूरी तरह बनी SQL `SELECT` स्टेटमेंट लौटाना चाहिए जिसके अंत में सेमीकोलन हो।
अगर कॉलम का स्लाइस खाली है या `nil` है, तो क्वेरी को सभी कॉलम चुनने के लिए `*` वाइल्डकार्ड का उपयोग करना चाहिए।

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. बैच INSERT स्टेटमेंट बनाइए

`BuildBatchInserts` फंक्शन लिखिए।
यह एक टेबल का नाम (`string`) और डेटाबेस की पंक्तियाँ दर्शाने वाला दो आयामों वाला स्लाइस (`[][]ColumnValue`) लेता है।
पंक्ति का हर एलिमेंट किसी खास कॉलम के नाम को उसकी स्ट्रिंग वैल्यू से जोड़ता है।
फंक्शन को अलग-अलग `INSERT` SQL स्ट्रिंग का स्लाइस लौटाना है।
स्लाइस का यह संरचित रूप क्वेरी के आउटपुट का क्रम पहले से तय और स्थिर रखता है।
अगर पंक्तियों का इनपुट स्लाइस खाली है, तो खाली स्ट्रिंग स्लाइस लौटाइए।
अगर कोई एक पंक्ति खाली है, तो उसे छोड़ दीजिए।
`VALUES` क्लॉज़ के अंदर स्ट्रिंग वैल्यू को सिंगल कोट `'` में रखना ज़रूरी है।

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
