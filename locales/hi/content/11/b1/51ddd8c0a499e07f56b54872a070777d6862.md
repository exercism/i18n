# निर्देश परिशिष्ट

सम्मिश्र संख्याओं की घात निकालने के लिए एक एक्सपोनेंशियल फंक्शन, और साइन तथा कॉसाइन फंक्शन चाहिए। इनमें से कोई भी WebAssembly में उपलब्ध नहीं है। अच्छी बात यह है कि इन्हें निकालने के लिए [टेलर श्रेणी](https://en.wikipedia.org/wiki/Taylor_series) का उपयोग किया जा सकता है। अपेक्षित वैल्यू से मेल खाने के लिए आपके पास कम से कम `1/26!` तक की सटीकता होनी चाहिए।

## एक्सपोनेंशियल फंक्शन

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## साइन फंक्शन

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## कॉसाइन फंक्शन

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
