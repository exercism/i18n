# टेस्ट

कमांड लाइन पर टेस्ट चलाने के लिए अभ्यास की डायरेक्टरी से यह कमांड चलाइए:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## GUI

MARS सिम्युलेटर के GUI से टेस्ट चलाने के लिए `runner.mips` की अंतिम लाइन से कमेंट हटाइए और अपने इम्प्लीमेंटेशन को उसके अंत में `include` कीजिए।
