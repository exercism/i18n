# परिचय

C# का `enum` टाइप नामित कॉन्स्टैंट के एक निश्चित समूह को दर्शाता है (एक इन्यूमरेशन)। इसका मुख्य उद्देश्य संख्यात्मक कॉन्स्टैंट के साथ काम करने का एक टाइप-सेफ़ तरीका देना है। इस तरीके में उपलब्ध वैल्यू पहले से तय समूह तक सीमित रहती हैं। एक साधारण enum को इस तरह बनाया जा सकता है:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

अगर वैल्यू स्पष्ट रूप से न दी जाए, तो enum के मेंबर को अपने आप बढ़ती हुई पूर्णांक वैल्यू असाइन हो जाती हैं, और पहली वैल्यू शून्य होती है। वैल्यू को स्पष्ट रूप से असाइन करना भी संभव है:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
