# परिचय

## ऐरे पर इटरेशन

एक `for` लूप से ऐरे पर इटरेशन करके हर एलिमेंट के लिए कोड दोहराया जा सकता है:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

ऊपर के उदाहरण में, `fruit` वह वेरिएबल है जो ऐरे `fruitList` के एक अलग एलिमेंट की वैल्यू रखता है। कंपाइलर यह सुनिश्चित करता है कि `fruitList` पर इटरेशन किया जा सके, अन्यथा वह कोड का चलना रोक देगा।

## रेंज पर इटरेशन

आप रेंज ऑपरेटर का उपयोग करके संख्याओं पर इटरेशन कर सकते हैं। यह ऑपरेटर दो `Int` ऑपरेंड लेता है और इसे `min...max` के रूप में लिखा जाता है। `min` शामिल है और `max` शामिल नहीं है (`min` <= i AND `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## की-वैल्यू इटरेशन

की-वैल्यू जोड़ों के संग्रह पर इटरेशन करना संभव है। सिंटैक्स में केवल यह अंतर है कि एक वेरिएबल के बजाय, एक की वेरिएबल आइडेंटिफायर का उपयोग किया जाता है, उसके बाद `=>`, और फिर वैल्यू वेरिएबल आइडेंटिफायर:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
