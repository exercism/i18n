# निर्देश

आप प्राग में व्लटावा नदी के किनारे एक छोटा मौसम केंद्र चलाते हैं, और हर शिफ्ट में तापमान की रीडिंग एक सादे टेक्स्ट लॉग में लिख लेते हैं, हर पंक्ति में एक रीडिंग। एक शिफ्ट का पूरा हिसाब पाँच छोटे शब्द संभाल लेते हैं।

हर शब्द को लॉग फाइल का पाथ दिया जाता है।

## 1. हर रीडिंग पढ़िए

`read-readings` बनाइए जो लॉग की सारी रीडिंग एक ऐरे के रूप में लौटाता है, हर पंक्ति में एक।

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. सबसे नई रीडिंग ढूँढ़िए

`latest-reading` बनाइए जो सबसे नई रीडिंग लौटाता है, यानी लॉग की अंतिम पंक्ति।

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. कच्चा लॉग पढ़िए

`log-text` बनाइए जो पूरी लॉग फाइल को एक ही स्ट्रिंग के रूप में लौटाता है, ठीक वैसे ही जैसे वह संग्रहीत है।

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. रीडिंग दर्ज कीजिए

`record-reading` बनाइए जो लॉग के अंत में एक नई रीडिंग अपनी अलग पंक्ति के रूप में जोड़ता है, और पहले की रीडिंग को वैसा ही छोड़ देता है। यह कुछ नहीं लौटाता।

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. लॉग फिर से लिखिए

`rewrite-log` बनाइए जो पूरे लॉग को रीडिंग के एक नए ऐरे से बदल देता है, हर पंक्ति में एक।

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
