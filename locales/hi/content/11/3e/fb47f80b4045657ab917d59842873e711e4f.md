# परिचय

पिछले कॉन्सेप्ट में हमने देखा था कि Julia में टाइप एक पदानुक्रम बनाते हैं, जिसके सबसे ऊपर `Any` होता है।

`Number` जैसे अमूर्त टाइप के सबटाइप होते हैं, लेकिन इनसे खुद कोई वैल्यू नहीं बनाई जा सकती। किसी वेरिएबल को किसी अमूर्त टाइप पर सेट करने पर उस वेरिएबल की वैल्यू पर यह शर्त लग जाती है कि वह उस अमूर्त टाइप का कोई भी सबटाइप हो। उदाहरण देखिए:

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

इससे हमें कौन-से इनपुट मान्य होंगे, यह तय करने में एक तरह का लचीलापन मिलता है।

लेकिन मान लीजिए हम चाहते हैं कि एक वेरिएबल पूर्णांक और स्ट्रिंग, दोनों तरह की वैल्यू ले सके? ये दोनों टाइप पदानुक्रम की एक ही शाखा में नहीं आते।

हम टाइप को `Any` सेट कर सकते हैं, या उसे अपने आप वही बना रहने दे सकते हैं, लेकिन तब अनुमत टाइप पर हमारा पूरा नियंत्रण खत्म हो जाता है।

इससे बेहतर तरीका यह है कि हम `Union{ }` सिंटैक्स इस्तेमाल करें, जिसमें कोष्ठकों के अंदर दो या अधिक टाइप लिखे जाते हैं।

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

एक और उदाहरण में वही टाइप यूनियन एक फंक्शन सिग्नेचर में इस्तेमाल हुआ है:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

यहाँ हमने इस टाइप को एक नाम दिया है, जिससे काम आसान हो जाता है, पर यह ज़रूरी नहीं है। फंक्शन `g(z::Union{Integer, String}) = z^3` भी ठीक इसी तरह काम करता है।

फंक्शन सिग्नेचर के बारे में और बहुत कुछ मल्टीपल डिस्पैच कॉन्सेप्ट में कहा जाएगा।

## `nothing` वाले यूनियन

कई दूसरी भाषाओं में ऐसे टाइप होते हैं जिनमें कोई वैल्यू हो भी सकती है और नहीं भी। ऐसे टाइप के नाम `Option`, `Nullable` या `Maybe` जैसे होते हैं।

Julia में इसके लिए कोई खास सिंटैक्स नहीं है, लेकिन टाइप यूनियन इसी विचार का व्यापक रूप हैं।

`Nothingness` कॉन्सेप्ट में हमने देखा था कि Julia में ऐसी जगहों को दिखाने के कई तरीके हैं जहाँ कोई वैल्यू नहीं होती, जिनमें `nothing` और `missing` भी शामिल हैं। इनमें से कोई भी टाइप यूनियन में शामिल किया जा सकता है।

उदाहरण के लिए, किसी तरह की लिंक्ड लिस्ट बनाते समय हमें लिस्ट को खत्म करने का तरीका चाहिए, जब आगे कोई नोड न बचे। `Nothing` वह टाइप है जिसकी एकमात्र वैल्यू `nothing` है। Node की यह परिभाषा श्रृंखला का अंत बताने में मदद करती है:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

इसी तरह, `missing` को उन वैल्यू की जगह प्लेसहोल्डर की तरह इस्तेमाल किया जा सकता है जो वहाँ मौजूद नहीं हैं, खास तौर पर वेक्टर जैसे कलेक्शन में। नीचे दिया गया उदाहरण बहुत बनावटी है, लेकिन वास्तविक दुनिया के डेटा सेट में ऐसी वैल्यू आम हैं जो मौजूद नहीं होतीं।

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
