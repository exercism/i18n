## निर्देश

एक रीसाइक्लिंग सेंटर ने आपको नौकरी पर रखा है।
जगह की कमी के कारण सारे उत्पाद एक ही कन्वेयर बेल्ट पर डाले जाते हैं, लेकिन इससे अलग-अलग सामग्री आपस में मिल जाती है और बेकार हो जाती है।
इसे ठीक करने के लिए आपको ऐसे फंक्शन बनाने का काम सौंपा गया है जो किसी उत्पाद का प्रकार पहचान सकें।

### 1. जाँचिए कि कोई वैल्यू बूलियन है या नहीं

`isBoolean` फंक्शन बनाइए, जो जाँचता है कि कोई वैल्यू बूलियन है या नहीं।

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. जाँचिए कि कोई वैल्यू संख्या है या नहीं।

`isNumber` फंक्शन बनाइए, जो जाँचता है कि कोई वैल्यू एक _सीमित_ `number` या `bigint` है, यानी `NaN` या `Infinity` नहीं।

कभी-कभी आईडी पढ़ने वाला डिवाइस गड़बड़ कर देता है और किसी गैर-संख्यात्मक वैल्यू को `NaN` (यानी संख्या नहीं) या `Infinity` के रूप में पढ़ लेता है।
आपके फंक्शन को इसे भी ठीक से संभाल पाना चाहिए।

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. जाँचिए कि कोई वैल्यू ऑब्जेक्ट है या नहीं

`isObject` फंक्शन बनाइए, जो जाँचना चाहिए कि वैल्यू एक ऑब्जेक्ट है या नहीं।
कन्वेयर पर `null` कुछ नहीं है और इसे ऑब्जेक्ट नहीं माना जाता।

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. जाँचिए कि कोई स्ट्रिंग संख्यात्मक है या नहीं

`isNumericString` फंक्शन बनाइए, जो यह जाँचना चाहिए कि वैल्यू एक ऐसी स्ट्रिंग है जिसमें सिर्फ अंक हों, या ऋणात्मक संख्या दर्शाने के लिए माइनस और उसके बाद अंक हों।
यहाँ सिर्फ पूर्णांक गिने जाने चाहिए; रीसाइक्लिंग रोबोट की इस जाँच में दशमलव संख्याओं को संख्यात्मक नहीं माना जाता।

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. जाँचिए कि कोई ऑब्जेक्ट इलेक्ट्रॉनिक है या नहीं

`isElectronic` फंक्शन बनाइए, जो जाँचता है कि कोई ऑब्जेक्ट दी गई `ElectronicDevice` क्लास का इंस्टेंस है या उसकी किसी चाइल्ड क्लास का।

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. जाँचिए कि कोई वैल्यू गैर-खाली ऐरे है या नहीं

`isNonEmptyArray` फंक्शन बनाइए, जो जाँचता है कि कोई वैल्यू गैर-खाली ऐरे है या नहीं।

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. जाँचिए कि कोई वैल्यू खाली ऐरे है या नहीं

`isEmptyArray` फंक्शन बनाइए, जो जाँचता है कि कोई वैल्यू खाली ऐरे है या नहीं।

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. जाँचिए कि किसी ऑब्जेक्ट में `type` प्रॉपर्टी या मेथड है या नहीं

`hasType` फंक्शन बनाइए, जो जाँचता है कि किसी ऑब्जेक्ट में `type` प्रॉपर्टी या मेथड है या नहीं।

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. अगर किसी ऑब्जेक्ट में `id` प्रॉपर्टी या मेथड न हो, तो एरर दीजिए

`assertHasId` फंक्शन बनाइए, जो एक `Error` देगा अगर किसी ऑब्जेक्ट में `id` प्रॉपर्टी न हो।

अगर ऑब्जेक्ट में `id` प्रॉपर्टी है, तो इस फंक्शन को कुछ नहीं लौटाना चाहिए।

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. जाँचिए कि किसी ऑब्जेक्ट में `id` प्रॉपर्टी है या नहीं

`hasIdProperty` फंक्शन बनाइए, जो जाँचता है कि किसी ऑब्जेक्ट में `id` प्रॉपर्टी है या नहीं।

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. जाँचिए कि किसी ऑब्जेक्ट में एक परिभाषित `type` प्रॉपर्टी है या नहीं

`hasDefinedType` फंक्शन बनाइए, जो जाँचता है कि किसी ऑब्जेक्ट में एक ऐसी `type` प्रॉपर्टी है जो `undefined` नहीं है।

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
