# परिचय

रिकॉर्ड उन फील्ड का समूह होता है जो एक साथ रहते हैं (और जो अलग-अलग टाइप के हो सकते हैं)। रिकॉर्ड परिभाषित करने के लिए `type` कीवर्ड का उपयोग किया जाता है। रिकॉर्ड के फील्ड `{` और `}` के बीच परिभाषित किए जाते हैं, और हर फील्ड का एक नाम _और_ एक टाइप होता है। रिकॉर्ड बनाने के लिए फील्ड के नाम लिखिए और `{` और `}` के बीच उन्हें वैल्यू असाइन कीजिए। रिकॉर्ड बनाते समय सभी फील्ड को वैल्यू असाइन करना ज़रूरी होता है। किसी रिकॉर्ड इंस्टेंस के फील्ड की वैल्यू डॉट नोटेशन से एक्सेस की जा सकती हैं।

रिकॉर्ड परिभाषित या बनाते समय हर फील्ड या तो अलग लाइन पर होना चाहिए, या एक ही लाइन पर होने पर सेमीकोलन (`;`) से अलग किया होना चाहिए।

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

चूँकि रिकॉर्ड इम्यूटेबल होते हैं, एक बार रिकॉर्ड बन जाने के बाद उसके फील्ड की वैल्यू कभी नहीं बदल सकतीं। अगर आप रिकॉर्ड की वैल्यू बदलना चाहते हैं, तो `with` कीवर्ड की मदद से आप किसी मौजूदा रिकॉर्ड की कॉपी बना सकते हैं, जिसमें एक या अधिक फील्ड की वैल्यू नई होंगी।

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

रिकॉर्ड में _स्ट्रक्चरल इक्वालिटी_ होती है, यानी एक ही रिकॉर्ड के जिन दो इंस्टेंस की वैल्यू बिल्कुल एक जैसी हों, वे बराबर होते हैं।

रिकॉर्ड के फील्ड एक्सेस करने के लिए डॉट नोटेशन इस्तेमाल करने के अलावा, रिकॉर्ड को बाइंडिंग और पैटर्न मैचिंग में _डीकंस्ट्रक्ट_ भी किया जा सकता है:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
