# निर्देश

कुछ "अन्य" डेवलपर रिमोट कंट्रोल कार प्रोजेक्ट [exercise:csharp/remote-control-competition]() पर काम कर रहे थे। कोड साफ़ करने के लिए आपको बुलाया गया है।

## 1. कार खुद और टेलीमेट्री सिस्टम के बीच ज़िम्मेदारियाँ अलग कीजिए

`RemoteControlCar` क्लास को रीफैक्टर कीजिए और टेलीमेट्री के मेथड तथा प्रॉपर्टी अलग कर दीजिए, जिन तक `Telemetry` प्रॉपर्टी के ज़रिए पहुँचा जाता है।

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. दूसरे कोड को Telemetry टाइप पर ज़्यादा निर्भरता लेने से रोकिए

यह सुनिश्चित कीजिए कि `Telemetry` इंस्टेंस कार के स्कोप के बाहर नहीं बनाया जा सके।

## 3. दूसरे कोड को Speed struct पर निर्भरता लेने से रोकिए

यह सुनिश्चित कीजिए कि `Speed` struct का इस्तेमाल `RemoteControlCar` क्लास के स्कोप के बाहर नहीं किया जा सके।

## 4. दूसरे कोड को SpeedUnits enum पर निर्भरता लेने से रोकिए

यह सुनिश्चित कीजिए कि `SpeedUnits` enum का इस्तेमाल `RemoteControlCar` क्लास के स्कोप के बाहर नहीं किया जा सके।
