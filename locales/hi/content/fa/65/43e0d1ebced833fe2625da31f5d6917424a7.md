# मेंटेनर के लिए

## Fortran टेस्ट बनाने के लिए मददगार स्क्रिप्ट: create_fortran_test.py

किसी अभ्यास का टेस्ट बनाने का एक आसान तरीका है स्क्रिप्ट `bin/create\_fortran\_test.py` इस्तेमाल करना।

इस स्क्रिप्ट से आप शुरुआती <exercise>\_test.f90 फाइल बना सकते हैं, जिसे अपने टेस्ट के टेम्पलेट की तरह इस्तेमाल किया जा सकता है।
आम तौर पर आपको बनाई गई फाइल में मौजूद 'response'-फंक्शन की जगह सही फंक्शन कॉल डालनी होगी।

यह भी ध्यान रखिए कि Fortran में `\n` और `\t` जैसे खास अक्षरों को लेकर दिक्कतें आती हैं, इसलिए इन्हें संभालते समय खास सावधानी बरतिए।

### पूर्वापेक्षाएँ

- काम करने वाले CMake और Fortran कंपाइलर
- Python3.x (आप चाहें तो इसे Python2 के साथ भी चलाने लायक बना सकते हैं, पर इसे बैकवर्ड कंपैटिबल बनाने की मेहनत मैंने नहीं की है)
- https://github.com/exercism/problem-specifications.git का नवीनतम वर्शन
- git

### नया टेस्ट बनाने का वर्कफ्लो

- `exercism/problem-specifications` से नवीनतम बदलाव खींचिए, जैसे git clone git@github.com:exercism/problem-specifications.git
- नया अभ्यास बनाने के लिए नई ब्रांच बनाइए, जैसे git checkout -b exercise-bob
- जिस उदाहरण को बनाना है, उसके लिए यह स्क्रिप्ट चलाइए
- `config/CMakeLists.txt` को अभ्यास की डायरेक्टरी में कॉपी कीजिए (इसके लिए `bin/update-cmake-files` इस्तेमाल कर सकते हैं)
- अभ्यास को इस तरह लिखिए कि वह चल जाए
- जिन टेस्ट में दिक्कत आ सकती है, उन्हें ठीक कीजिए (जैसे exercise/bob के "Test 20" और "Test 24")
- पक्का कीजिए कि `ctest` कमांड बिना किसी एरर के जाँच पास कर दे
- अपने हल को .meta/example.f90 में कॉपी कीजिए और अभ्यास की फाइल से असली इम्प्लीमेंटेशन हटा दीजिए, जैसे bob.f90 से
- .docs और .meta डायरेक्टरियों को अपडेट कीजिए
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - "# Description" को "# Instructions" से बदलिए
  - .meta/tests.toml को हाथ से भरिए (जब तक कोई अपने-आप करने वाला तरीका न हो)
  - .meta/config.json को हाथ से भरिए (जब तक कोई अपने-आप करने वाला तरीका न हो)
    - ../problem-specifications/exercises/bob/metadata.yml इस्तेमाल कीजिए
- अपने बदलावों के साथ एक पुल रिक्वेस्ट खोलिए

bob के उदाहरण के लिए:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### `CMakeLists.txt` बदलना

जब आप cmake फाइल बदलें, तो `config/` में मौजूद मास्टर कॉपी भी अपडेट कीजिए और `bin/update-cmake-files` से उसे हर अभ्यास की डायरेक्टरी में कॉपी कीजिए।

## हल

जब आपके पास हल तैयार हो, तो उस हल को ".meta" डायरेक्टरी में "example.f90" के तौर पर कॉपी कीजिए।

हो सकता है आप फंक्शन या सबरूटीन का एक ढाँचा छोड़ना चाहें जो विद्यार्थी की मदद करे, और अभ्यास की डायरेक्टरी में अभ्यास के नाम वाली फाइल छोड़ देना चाहें।
