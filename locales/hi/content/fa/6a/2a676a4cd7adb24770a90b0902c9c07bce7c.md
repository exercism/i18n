# इंस्टॉलेशन

PureScript इंस्टॉल करने का सबसे आसान तरीका Node.js और NPM के ज़रिए है।

अगर आपके कंप्यूटर पर Node.js पहले से इंस्टॉल नहीं है, तो आप इसे [Node.js वेबसाइट](https://nodejs.org/) से डाउनलोड कर सकते हैं। Node.js चलना शुरू हो जाने के बाद, PureScript कंपाइलर और Spago बिल्ड टूल इंस्टॉल करने के लिए टर्मिनल में यह कमांड डालिए:

    npm install --global purescript spago

अधिक जानकारी [PureScript रिपॉज़िटरी](https://github.com/purescript/purescript/blob/master/INSTALL.md) में मिल सकती है।
