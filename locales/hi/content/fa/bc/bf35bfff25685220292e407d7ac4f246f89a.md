# निर्देश परिशिष्ट

गैर-मानक स्ट्रिंग लिटरल और मेटाप्रोग्रामिंग के साथ प्रयोग करने के लिए यह एक अच्छा अभ्यास है।

गैर-मानक स्ट्रिंग लिटरल का एक संक्षिप्त परिचय इस [ब्लॉग पोस्ट](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html) में मिल सकता है। मेटाप्रोग्रामिंग की विस्तृत गाइड [मैनुअल](https://docs.julialang.org/en/v1/manual/metaprogramming/) में मिल सकती है।

नीचे बताई गई कार्यक्षमता जोड़कर आप अपने हल को आगे बढ़ा सकते हैं।

बोनस A के लिए ब्लॉग पोस्ट में बताई गई बुनियादी बातें ही काफी हैं। बोनस B के लिए Julia में मेटाप्रोग्रामिंग का ज्ञान कहीं अधिक होना चाहिए।

## बोनस A
ऐसा स्ट्रिंग लिटरल बनाइए जो स्ट्रिंग पर `ROT13` की तरह काम करे:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## बोनस B
`R<i>` स्ट्रिंग लिटरल बनाइए, जहाँ `i = 0, ..., 26` है और ये स्ट्रिंग को `i` मानों के अनुसार खिसका दें:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
