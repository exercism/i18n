# इंस्टॉलेशन

## Ubuntu (और ज़्यादातर अन्य Debian-आधारित डिस्ट्रीब्यूशन)

कोड को अपने कंप्यूटर पर बिल्ड करने के लिए आपको gcc और make की ज़रूरत होगी, जिन्हें इस कमांड से इंस्टॉल किया जा सकता है:

```shell
sudo apt install gcc make
```

अगर आप ARM64 हार्डवेयर पर नहीं चला रहे हैं, तो [QEMU][] एमुलेटर और GCC ARM64 क्रॉस-टूलचेन इन कमांड से इंस्टॉल कीजिए:

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Debian-आधारित डिस्ट्रीब्यूशन के साथ [Windows Subsystem for Linux][] इस्तेमाल कीजिए और ऊपर दिए गए Ubuntu वाले निर्देशों का पालन कीजिए। इसके अलावा, एक Linux वर्चुअल मशीन भी बनाई जा सकती है।

## macOS

किसी भी उपयुक्त वर्चुअलाइज़ेशन समाधान (जैसे [Lima][]) की मदद से एक Linux वर्चुअल मशीन शुरू की जा सकती है।

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
