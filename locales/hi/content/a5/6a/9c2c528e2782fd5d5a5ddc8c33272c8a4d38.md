# परिचय

Factor में अक्षर पूर्णांक होते हैं, यानी Unicode कोड पॉइंट। इसलिए `<`, `>`, `=` जैसे संख्यात्मक ऑपरेटर आपको सीधे केस-सेंसिटिव क्रम देते हैं। [`unicode`][unicode] वोकैबुलरी Unicode को समझने वाले प्रेडिकेट और एक अक्षर का केस बदलने की सुविधा जोड़ती है।

## अक्षरों के प्रेडिकेट

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## केस बदलना

`ch>upper` और `ch>lower` एक अक्षर का केस बदल देते हैं। स्ट्रिंग पर काम करने वाले `>upper` और `>lower` इन्हें स्ट्रिंग के हर अक्षर पर लागू करते हैं।

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` पूरी स्ट्रिंग को लोअरकेस कर देता है और फिर उसके पहले अक्षर को अपरकेस कर देता है। यह एक शब्द का टाइटल केस है:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## अक्षर लिटरल

`CHAR: A` का पार्स होकर `A` का पूर्णांक कोड पॉइंट बनता है। नाम वाले अक्षरों के लिए `space`, `tab`, `\n` जैसे नाम इस्तेमाल कीजिए:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## सिंबल

जब किसी वर्ड को वैल्यू के बजाय टैग लौटाना हो, मान लीजिए बूलियन के बजाय `yes`/`no`/`maybe`, तो हर टैग को *सिंबल* के रूप में घोषित कीजिए। सिंबल एक ऐसा वर्ड है जो कॉल किए जाने पर खुद को स्टैक पर रख देता है, और दो सिंबल तभी बराबर माने जाते हैं जब उनका नाम एक ही हो।

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` एक सिंबल घोषित करता है; `SYMBOLS: a b c ;` कई सिंबल घोषित करता है।
