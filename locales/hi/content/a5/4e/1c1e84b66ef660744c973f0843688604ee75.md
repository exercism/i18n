# परिचय

JavaScript एक डायनैमिक भाषा है, जो ऑब्जेक्ट-ओरिएंटेड, इम्पेरेटिव और डिक्लेरेटिव (जैसे फंक्शनल प्रोग्रामिंग) शैलियों का समर्थन करती है।

## (दोबारा) असाइनमेंट

JavaScript में नामों को वैल्यू असाइन करने के कुछ मुख्य तरीके हैं: वेरिएबल या कॉन्स्टेंट इस्तेमाल करना। Exercism पर वेरिएबल हमेशा [camelCase][wiki-camel-case] में लिखे जाते हैं और कॉन्स्टेंट [SCREAMING_SNAKE_CASE][wiki-snake-case] में। इसके लिए कोई आधिकारिक गाइड नहीं है, और अलग-अलग कंपनियों और संगठनों के अपने-अपने स्टाइल गाइड होते हैं। _आप अपने वेरिएबल जैसे चाहें वैसे लिख सकते हैं_। अभ्यासों में जिस तरह लिखा गया है उसी तरह वेरिएबल लिखने का फायदा यह है कि वेब इंटरफ़ेस और ज़्यादातर IDE में वे अलग-अलग रंगों में दिखाई देते हैं।

JavaScript में वेरिएबल को [`const`][mdn-const], [`let`][mdn-let] या [`var`][mdn-var] कीवर्ड की मदद से बनाया जा सकता है।

`let` या `var` इस्तेमाल करते समय एक वेरिएबल अपने पूरे जीवनकाल में अलग-अलग वैल्यू रख सकता है। जैसे `myFirstVariable` को असाइनमेंट ऑपरेटर `=` की मदद से कई बार बनाया और फिर बदला जा सकता है:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let` और `var` के उलट, `const` से बनाए गए वेरिएबल को सिर्फ एक बार ही वैल्यू असाइन की जा सकती है। JavaScript में कॉन्स्टेंट बनाने के लिए इसी का इस्तेमाल किया जाता है।

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 आगे आने वाले किसी अभ्यास में _constant_ असाइनमेंट / बाइंडिंग और _constant_ वैल्यू के बीच के फर्क पर चर्चा की जाएगी और उसे समझाया जाएगा।

## फंक्शन घोषणाएँ

JavaScript में काम करने वाले कोड के हिस्सों को _फंक्शन_ में समेटा जाता है। अगर कई फंक्शन एक साथ रखने लायक हों, तो उन्हें आम तौर पर एक ही फाइल में रखा जाता है। ये फंक्शन पैरामीटर (आर्गुमेंट) ले सकते हैं, और `return` कीवर्ड की मदद से एक वैल्यू _लौटा_ सकते हैं। फंक्शन को `()` सिंटैक्स से कॉल किया जाता है।

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 JavaScript में फंक्शन घोषित करने के _कई_ अलग-अलग तरीके हैं। ये दूसरे तरीके `function` कीवर्ड इस्तेमाल करने से अलग दिखते हैं। यह ट्रैक उन्हें धीरे-धीरे पेश करने की कोशिश करता है, लेकिन अगर आप उन्हें पहले से जानते हैं, तो आप उनमें से कोई भी इस्तेमाल कर सकते हैं। ज़्यादातर मामलों में एक या दूसरा तरीका इस्तेमाल करना बेहतर या खराब नहीं होता।

## दूसरी फाइलों के लिए उपलब्ध कराना

किसी `function`, कॉन्स्टेंट या वेरिएबल को _दूसरी फाइलों_ में उपलब्ध कराने के लिए उसे `export` कीवर्ड की मदद से [एक्सपोर्ट][mdn-export] करना पड़ता है। इसके बाद कोई दूसरी फाइल `import` कीवर्ड से इन्हें [इम्पोर्ट][mdn-import] कर सकती है। इसे ही मॉड्यूल सिस्टम कहा जाता है। इसका एक बढ़िया उदाहरण यह है कि सारे टेस्ट कैसे काम करते हैं। हर अभ्यास में कम से कम एक फाइल होती है, जैसे `lasagna.js`, जिसमें _इम्प्लीमेंटेशन_ होता है। इसके अलावा कम से कम एक और फाइल होती है, जैसे `lasagna.spec.js`, जिसमें _टेस्ट_ रहते हैं। यह फाइल इम्प्लीमेंटेशन को टेस्ट करने के लिए सार्वजनिक (यानी एक्सपोर्ट की गई) चीज़ों को _इम्पोर्ट_ करती है:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
