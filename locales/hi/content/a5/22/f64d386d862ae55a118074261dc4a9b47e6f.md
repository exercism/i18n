# टेस्ट

## Exercism GDScript ट्रैक का टेस्ट रनर इंस्टॉल करना

टेस्ट रनर का इस्तेमाल करने के लिए आपको [Godot ठीक से इंस्टॉल][installation] करना होगा।

Exercism के लिए GDScript स्क्रिप्ट बनाने और उनका टेस्ट करने के लिए, Godot को CLI से "headless" मोड में चलाया जाएगा। इन निर्देशों के लिए फिलहाल Linux और bash की ज़रूरत है।

### चरण 1: टेस्ट रनर का पूरा ढाँचा इंस्टॉल करना

टेस्टिंग की तैयारी के लिए [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] को क्लोन कीजिए और उसकी सामग्री को `/opt/test-runner/` में ले जाइए:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### चरण 2: एक अभ्यास के लिए टेस्ट रनर स्क्रिप्ट डाउनलोड करना

अगर आपने `exercism` टूल सेट कर लिया है और कम से कम एक GDScript अभ्यास डाउनलोड कर लिया है, तो उसने अभ्यासों को रखने के लिए `exercism/gdscript` फोल्डर बना लिया होगा। इस फोल्डर में [टेस्ट रनर][test-local-gdscript-solution] को सेव कीजिए और फाइल को एक्ज़ीक्यूटेबल बनाइए, या उसका लिंक ही बना दीजिए:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## टेस्ट चलाना

इंस्टॉल के चरण पूरे हो जाने के बाद, आप किसी भी अभ्यास की डायरेक्टरी से शुरू कर सकते हैं (जैसे `~/exercism/gdscript/two-fer`) और उस अभ्यास के अपने लोकल हल की जाँच के लिए उस स्क्रिप्ट को चला सकते हैं, जो एक लेवल ऊपर यानी `../` में रहती है:

```sh
../test-local-gdscript-solution.sh
```
