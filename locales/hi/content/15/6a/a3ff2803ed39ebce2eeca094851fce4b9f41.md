# परिचय

हम [`fractions`][fractions] मॉड्यूल की मदद से [`rational numbers`][rational] बना सकते हैं और उन पर काम कर सकते हैं: ऐसी भिन्नें जिनका अंश और हर दोनों पूर्णांक होते हैं।
उदाहरण के लिए, हम `2/3` को सटीक भिन्न के रूप में संग्रहीत कर सकते हैं, न कि अनुमानित `float` वैल्यू `0.6666...` के रूप में।

`int`, `float` और `complex` संख्याओं के विपरीत भिन्नों का कोई लिटरल रूप नहीं होता।
लेकिन भिन्न बनाने वाला कंस्ट्रक्टर काफी लचीला होता है।

सबसे स्पष्ट रूप से, यह दो पूर्णांकों को आर्गुमेंट के रूप में ले सकता है।
सामान्य गुणनखंड अपने आप हट जाते हैं, और भिन्न अपने "न्यूनतम रूप" (_वे सबसे छोटे पूर्णांक जो भिन्न को सटीक रूप से दर्शाते हैं_) में आ जाती है:

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

भिन्न बनाने वाला कंस्ट्रक्टर स्ट्रिंग के रूप में दी गई वैल्यू को भी पढ़ सकता है:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

भिन्नें `float` पैरामीटर के साथ भी काम कर सकती हैं, लेकिन दशमलव वैल्यू को अंदर से बाइनरी के रूप में दर्शाने की अनुमानित प्रकृति के कारण इसमें समस्याएँ आ सकती हैं।
वैल्यू को अंदर से कैसे दर्शाया जाता है, इससे जुड़ी इस समस्या के बारे में और जानने के लिए [0.30000000000000004][0.30000000000000004] वेबसाइट देखिए।
Python के डॉक्युमेंटेशन में [Floating Point Arithmetic: Issues and Limitations ][fp-issues] भी देखिए।

भिन्नों के साथ फ्लोट संख्याएँ इस्तेमाल करते समय ज़्यादा भरोसेमंद नतीजा पाने के लिए `<fraction>.limit_denominator()` मेथड मौजूद है।


## भिन्नों के साथ अंकगणित

आम [`arithmetic operators`][operators] `+ - * / **` बाकी संख्यात्मक टाइप की तरह भिन्नों के साथ भी काम करते हैं।

पूर्णांकों और दूसरे `Fraction` को भी इस गणना में शामिल किया जा सकता है, और नतीजा `Fraction` ही आता है।
एक्सप्रेशन में `float` शामिल करने पर नतीजा `float` में आता है, और इससे सटीकता में (संभवतः) कमी आ जाती है:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Python के कई मानक संख्यात्मक फंक्शन भी वही नतीजा देते हैं जिसकी आप `int` और `float` टाइप के साथ काम करते समय उम्मीद करेंगे:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
