# परिचय

फंडामेंटल्स कॉन्सेप्ट से याद कीजिए कि AWK प्रोग्राम **पैटर्न-क्रिया जोड़ों** से बना होता है।

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## "पैटर्न" से हमारा क्या मतलब है?

"पैटर्न" कोई भी AWK एक्सप्रेशन हो सकता है।
एक्सप्रेशन के परिणाम से पता चलता है कि वह सही है या गलत, और इसी से तय होता है कि क्रिया चलेगी या नहीं।

## खाली पैटर्न

पैटर्न छोड़ा जा सकता है।
ऐसी स्थिति में क्रिया हर रिकॉर्ड के लिए चलाई जाती है।

हम passwd फाइल के सारे यूज़रनेम प्रिंट कर सकते हैं।

```sh
awk -F: '{print $1}' /etc/passwd
```

## रेगुलर एक्सप्रेशन

AWK स्ट्रिंग की तुलना रेगुलर एक्सप्रेशन से करके बूलियन परिणाम निकाल सकता है।

किसी खास फील्ड का मिलान करने के लिए `~` रेगेक्स-मिलान ऑपरेटर का इस्तेमाल कीजिए।
यह ऑपरेटर बाईं ओर ऑपरेंड के तौर पर एक स्ट्रिंग लेता है और दाईं ओर ऑपरेंड के तौर पर एक रेगुलर एक्सप्रेशन लेता है।
रेगुलर एक्सप्रेशन लिटरल `/` स्लैश के बीच लिखा जाता है।

passwd फाइल में वे यूज़र ढूँढने के लिए जो bash से लॉग इन करते हैं:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` वह ऑपरेटर है जो बताता है कि रेगेक्स **मैच नहीं** करता।

मौजूदा रिकॉर्ड पर रेगेक्स का मिलान करने के लिए आप `$0 ~ /regex/` लिख सकते हैं।
यह इतना आम है कि इसका छोटा रूप भी है: आप `$0` और `~` हटाकर सीधे `/regex/` लिख सकते हैं।

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
AWK की उस एक लाइन वाली कमांड की तुलना grep की उसी काम वाली कमांड से कीजिए

```sh
grep 'regex' data.txt
```

AWK आपको पूरी प्रोग्रामिंग भाषा देता है, बिना संक्षिप्तता खोए।
~~~~

GNU AWK के रेगुलर एक्सप्रेशन के इस रूप के बारे में हम आगे के किसी कॉन्सेप्ट में और विस्तार से जानेंगे।

## एक्सप्रेशन

AWK के एक्सप्रेशन (गणितीय, तार्किक, या किसी और तरह के) पैटर्न की तरह इस्तेमाल किए जा सकते हैं।

UID 1000 या उससे ऊपर वाले सारे यूज़र निकालने के लिए:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

याद रखिए कि AWK में गलत मान ये हैं: संख्या शून्य और खाली स्ट्रिंग। बाकी हर संख्या या स्ट्रिंग सही होती है।
जो एक्सप्रेशन किसी संख्या या स्ट्रिंग के रूप में निकलता है, उसे पैटर्न की तरह इस्तेमाल किया जा सकता है।

## फंक्शन

किसी भी [बिल्ट-इन][builtins] या [यूज़र-डिफाइंड][user-defined] फंक्शन को एक्सप्रेशन में इस्तेमाल किया जा सकता है, और इस तरह पैटर्न में भी।
कुछ उदाहरण:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## स्थिर पैटर्न

AWK में एक आम तरीका यह है:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` एक सही मान वाला पैटर्न है जिसके साथ कोई क्रिया जुड़ी नहीं है।
इसका मतलब है "मौजूदा रिकॉर्ड प्रिंट कीजिए।"
