# ऐरे के मेथड्स

ऐरे एक ऐसा डेटा स्ट्रक्चर है जिसके साथ काम करना आम बात है।
इसलिए ऐरे के साथ काम करने के लिए मेथड्स का एक पूरा संग्रह है, जिसमें सॉर्ट करना, उलटना, डालना और बहुत कुछ शामिल है।

इनमें से कुछ मेथड्स डेस्ट्रक्टिव होते हैं, यानी वे मूल ऐरे को बदल देते हैं।
बाकी नॉन-डेस्ट्रक्टिव होते हैं, यानी वे एक नया ऐरे लौटाते हैं और मूल ऐरे को नहीं बदलते।

ऐरे के साथ काम करते समय इस्तेमाल होने वाले कुछ सबसे आम मेथड्स ये हैं:

## insert

ऐरे में कोई एलिमेंट डालते समय आप [`insert`][insert] मेथड का उपयोग कर सकते हैं, जो आर्गुमेंट के रूप में एक इंडेक्स और एक एलिमेंट लेता है।
एलिमेंट दिए गए इंडेक्स पर डाला जाता है, और ऐरे के बाकी एलिमेंट दाईं ओर खिसक जाते हैं।
अगर इंडेक्स दायरे से बाहर है, तो `IndexError` आता है।

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

जब आप ऐरे से कोई खास एलिमेंट हटाना चाहते हैं, तो आप [`delete`][delete] मेथड का उपयोग कर सकते हैं, जो आर्गुमेंट के रूप में एक एलिमेंट लेता है।
यह मेथड हटाया गया एलिमेंट लौटाता है।
अगर एलिमेंट ऐरे में मौजूद नहीं है, तो `nil` लौटता है।

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

किसी ऐरे का पहला या अंतिम एलिमेंट निकालने के लिए आप [`first`][first] और [`last`][last] मेथड का उपयोग कर सकते हैं।
ये मेथड्स एक वैकल्पिक आर्गुमेंट लेते हैं, जो बताता है कि कितने एलिमेंट लौटाने हैं।
इंडेक्स `0` या `-1` इस्तेमाल करने, या किसी रेंज का उपयोग करने की तुलना में ये कोड को पढ़ने में आसान बनाते हैं।
अगर ऐरे खाली है, तो `Enumerable::EmptyError` आता है।

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

ऐरे को उलटने के लिए आप [`reverse`][reverse] मेथड का उपयोग कर सकते हैं, जो एलिमेंट्स को उलटे क्रम में रखकर एक नया ऐरे लौटाता है।
ध्यान देना ज़रूरी है कि `reverse` एक नया ऐरे लौटाता है और मूल ऐरे को नहीं बदलता।
अगर आप मूल ऐरे को बदलना चाहते हैं, तो मेथड के नाम के अंत में `!` लगाइए।

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

नीचे दिए गए मेथड्स तब काम आते हैं जब आप ऐरे को एक-आयामी बनाना, `nil` एलिमेंट हटाना, दोहरी वैल्यू हटाना या ऐरे के ऐरे को ट्रांसपोज़ करना जैसे काम करते हैं।
`reverse` की तरह ये मेथड्स भी एक नया ऐरे लौटाते हैं और मूल ऐरे को नहीं बदलते।

| मेथड | विवरण | उदाहरण |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | इस ऐरे को (बार-बार) चपटा करके एक-आयामी बनाकर एक नया ऐरे लौटाता है। यानी ऐरे के हर एलिमेंट के अंदर मौजूद एलिमेंट निकालकर नए ऐरे में डाल दिए जाते हैं। | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | इसी ऐरे की एक प्रति लौटाता है, जिसमें से सभी nil एलिमेंट हटा दिए गए हैं। | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | यह मानकर चलता है कि यह ऐरे ऐरे का ऐरे है, और इसकी पंक्तियों और स्तंभों को [ट्रांसपोज़ कर देता है][transpose]। | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | इसी ऐरे में मौजूद दोहरी वैल्यू हटाकर एक नया ऐरे लौटाता है। | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

ऐरे में ऑब्जेक्ट जोड़ने के लिए append मेथड (`<<`) काम आता है।
लेकिन दो ऐरे जोड़ते समय आप [`+`][concat] ऑपरेटर का उपयोग कर सकते हैं, जो दोनों ऐरे के एलिमेंट्स वाला एक नया ऐरे लौटाता है।

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

अगर आप एक ऐरे को दूसरे ऐरे में जोड़ते हैं, तो पूरा ऐरे एक ही एलिमेंट के रूप में जुड़ जाता है।

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

यह जाँचने के लिए कि कोई ऐरे खाली है या नहीं, आप [`empty?`][empty?] मेथड का उपयोग कर सकते हैं, जो ऐरे खाली होने पर `true` और वरना `false` लौटाता है।
ऐरे की लंबाई की `0` से तुलना करने के मुकाबले यह कोड को पढ़ने में आसान बनाता है।

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

जब आप ऐरे में किसी एलिमेंट का इंडेक्स निकालना चाहते हैं, तो आप [`index`][index] मेथड का उपयोग कर सकते हैं, जो आर्गुमेंट के रूप में एक एलिमेंट लेता है।
अगर एलिमेंट ऐरे में मौजूद नहीं है, तो `nil` लौटता है।

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

जब आप जानना चाहते हैं कि किसी ऐरे में कितने एलिमेंट हैं, तो आप [`size`][size] मेथड का उपयोग कर सकते हैं।

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

जब आप गिनना चाहते हैं कि कोई एलिमेंट किसी ऐरे में कितनी बार मौजूद है, तो आप [`count`][count] मेथड का उपयोग कर सकते हैं।

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

जब आप किसी ऐरे को सॉर्ट करना चाहते हैं, तो आप [`sort`][sort] मेथड का उपयोग कर सकते हैं, जो एलिमेंट्स को क्रम में लगाकर एक नया ऐरे लौटाता है।
`reverse` की तरह यह मेथड भी एक नया ऐरे लौटाता है और मूल ऐरे को नहीं बदलता।

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
