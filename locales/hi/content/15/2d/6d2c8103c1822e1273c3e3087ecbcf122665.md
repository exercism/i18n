# रिप्रेज़ेंटर नॉर्मलाइज़ेशन

[JavaScript रिप्रेज़ेंटर][github-javascript-representer] निम्नलिखित नॉर्मलाइज़ेशन लागू करता है:

## कमेंट हटाइए

सभी कमेंट हटा दिए जाते हैं।
निम्नलिखित उदाहरण समान हैं:

### कमेंट के साथ उदाहरण

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### कमेंट के बिना उदाहरण

```javascript
function hello() {
  return 'hi there';
}
```

## व्हाइटस्पेस सामान्यीकृत कीजिए

जब कोड को निरूपित किया जाता है, तो उसका _क्रम_ महत्वपूर्ण होता है, लेकिन उसका भौतिक स्थान नहीं।
इसका मतलब है कि व्हाइटस्पेस सामान्यीकृत किया जाता है।
निम्नलिखित उदाहरण समान हैं:

### दो स्पेस के इंडेंटेशन वाला उदाहरण

```javascript
function hello() {
  return 'hello world';
}
```

### चार स्पेस के इंडेंटेशन वाला उदाहरण

```javascript
function hello() {
  return 'hello world';
}
```

### दिलचस्प इंडेंटेशन वाला उदाहरण

```javascript
function hello() {
  return 'hello world';
}
```

## आइडेंटिफायर सामान्यीकृत कीजिए

आइडेंटिफायर एक प्लेसहोल्डर वैल्यू में सामान्यीकृत किए जाते हैं।

### पहले

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### बाद में

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
