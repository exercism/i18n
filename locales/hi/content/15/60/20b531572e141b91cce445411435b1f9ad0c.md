# परिचय

एन्यूमरेशन का अर्थ है किसी कलेक्शन (`Array`, `Hash` आदि) के हर ऑब्जेक्ट पर एक-एक करके जाकर उस पर कुछ न कुछ करना।

एन्यूमरेशन Ruby का एक अहम कॉन्सेप्ट है। इसका उपयोग सॉर्टिंग (`sort_by`), ग्रुपिंग (`group_by`), मैपिंग (`map`), रिड्यूसिंग (`reduce`) और बहुत कुछ के लिए किया जाता है।
कलेक्शन पर इटरेशन के लिए लूप इस्तेमाल करने के बजाय एन्यूमरेशन को ही स्वाभाविक तरीका माना जाता है, और यही आपको सबसे अधिक दिखेगा।

`map` और `with_index` का उपयोग करने वाला एक सरल एन्यूमरेशन ऐसा दिखता है:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
