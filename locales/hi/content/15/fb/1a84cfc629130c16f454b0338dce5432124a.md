# परिचय

Elm में [`Array`][array] एक तेज़, अपरिवर्तनीय संग्रह है जिसमें एक ही टाइप की शून्य या अधिक वैल्यू होती हैं।
चूँकि ऐरे अपरिवर्तनीय होते हैं, एक बार ऐरे बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती।
ऐरे के लिए कोई लिटरल सिंटैक्स नहीं है (जैसा List के लिए होता है), इसलिए इसके बजाय Array.fromList सिंटैक्स इस्तेमाल किया जाता है।
उदाहरण के लिए, "a", "b" और "c" वाला एक `Array` आमतौर पर `Array.fromList ["a", "b", "c"]` के रूप में दिखाया जाता है।
आपको यह कंसोल आउटपुट में, डीबगर में, और ऐसी ही दूसरी जगहों पर दिखेगा।

`List` के विपरीत, जो एक [डिफॉल्ट इंपोर्ट][default-imports] है, `Array` मॉड्यूल को स्पष्ट रूप से इंपोर्ट करना पड़ता है, `import Array` या इसी तरह की चीज़ का उपयोग करके।

ऐरे के लिए टाइप एनोटेशन इस तरह लिखे जा सकते हैं

```elm
Array String --> an array of String
Array Int --> an array of Int
```

ऐरे इस तरह बनाए जा सकते हैं:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

एलिमेंट को ऐरे में `Array.push` की मदद से जोड़ा जाता है:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

ऐरे को `Array.append` की मदद से जोड़ा जाता है:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

ऐरे में मौजूद एलिमेंट को `Array.get` की मदद से निकाला जाता है:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

ऐरे में मौजूद एलिमेंट की वैल्यू `Array.set` की मदद से बदली जाती है:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

ऐरे पर [`Array` मॉड्यूल][array-module] में बनाए गए फंक्शन काम करते हैं।

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

कोई भी फंक्शन/ऑपरेटर जो किसी `Array` को बदलता हुआ दिखता है (जैसे कोई एलिमेंट जोड़ना), वास्तव में एक नया `Array` लौटाता है।
हालाँकि प्रदर्शन आमतौर पर कोई समस्या नहीं होती, क्योंकि `Array` का कार्यान्वयन अनावश्यक एलोकेशन/कॉपी रोकता है।
