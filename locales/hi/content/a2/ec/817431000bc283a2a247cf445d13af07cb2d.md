# परिचय

PowerShell, Microsoft की एक डायनामिक और इम्प्लिसिटली टाइप्ड स्क्रिप्टिंग भाषा है (_लेकिन यह [strongly typed][strong typed] वेरिएबलो का भी समर्थन करती है_), जिसका ध्यान मुख्य रूप से काम के ऑटोमेशन और कॉन्फ़िगरेशन मैनेजमेंट पर है।

PowerShell इम्पेरेटिव, फंक्शनल, ऑब्जेक्ट-ओरिएंटेड और यहाँ तक कि पाइपलाइन शैली की प्रोग्रामिंग का भी समर्थन करती है।

PowerShell .NET प्लेटफॉर्म पर बनाई गई थी और पहली बार 2006 में जारी हुई थी।
यह सभी आधुनिक Windows OS में डिफ़ॉल्ट रूप से शामिल रही है, और इसे Mac और Linux पर भी इंस्टॉल किया जा सकता है।


## वेरिएबल

PowerShell में वेरिएबल बनाने के दो आम तरीके हैं।

PowerShell में वेरिएबल के नाम की शुरुआत `$` से होनी चाहिए, और वेरिएबल के नाम को किसी वैल्यू से जोड़ने के लिए असाइनमेंट ऑपरेटर `=` का उपयोग किया जाता है।

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

अगर आप चाहते हैं कि वैल्यू किसी खास टाइप की ही हो, तो आप वेरिएबल का टाइप साफ़-साफ़ भी बता सकते हैं।
अगर संभव हो, तो PowerShell अपनी पूरी कोशिश करती है कि वैल्यू को एक टाइप से दूसरे टाइप में बदल दे।

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### स्थिरांक

PowerShell में स्थिरांक ऐसे वेरिएबल होते हैं जिन्हें बनाने के बाद न **बदला** जा सकता है, न **हटाया** जा सकता है।
इसी से वेरिएबल बनाने का दूसरा तरीका सामने आता है: कमांडलेट `New-Variable` का उपयोग करना।

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## फंक्शन

PowerShell में फंक्शन `function` कीवर्ड से बनाए जाते हैं।
हर फंक्शन में शून्य या उससे अधिक फॉर्मल पैरामीटर `()` ब्रैकेट के अंदर हो सकते हैं, और उसके बाद फंक्शन का स्कोप आता है, जो `{` से शुरू होकर `}` पर खत्म होता है।

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell में फंक्शन `return` कीवर्ड के ज़रिए वैल्यू स्पष्ट रूप से लौटा सकते हैं। इन्हें `FuncName $Arg` सिंटैक्स से कॉल किया जाता है।

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## कमेंट

PowerShell में सिंगल कमेंट `#` से शुरू होते हैं और लाइन के खत्म होने पर खत्म हो जाते हैं।
PowerShell में कमेंट ब्लॉक `<#` से शुरू होते हैं और `#>` पर खत्म होते हैं।

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
