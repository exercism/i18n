# परिचय

पार्सिंग वह प्रक्रिया है जिसमें टेक्स्ट को अर्थपूर्ण डेटा में बदला जाता है।
इस काम के लिए `String` पैकेज के फंक्शन सीमित पड़ जाते हैं और रेगुलर एक्सप्रेशन इस्तेमाल करना मुश्किल होता है, इसलिए Elm में पार्स करने का स्वाभाविक तरीका `elm/parser` पैकेज है।

चलिए एक उदाहरण देखते हैं, जिसमें हम प्रोग्रामिंग भाषा [LOLCODE][lolcode] के एक हिस्से के लिए पार्सर लिखेंगे।
टिप्पणियों वाले इस प्रोग्राम को देखिए:

```
HAI 1                 # program version 1
CAN HAS STDIO?        # import stdio
VISIBLE "HAI WORLD!"  # print "HAI WORLD!"
KTHXBYE               # end of program
```

सबसे पहले, संभावित कमांड दर्शाने वाला एक Elm टाइप लिखते हैं:

```elm
type Command
    = Version Int
    | Import String
    | Print String
```

फिर हमारे LOLCODE प्रोग्राम को `List Command` के रूप में दर्शाया जा सकता है।
चलिए `HAI 1` लाइन के लिए एक पार्सर से शुरू करते हैं:

```elm
versionP : Parser Command
versionP =
    Parser.succeed Version
        |. Parser.keyword "HAI"
        |. Parser.spaces
        |= Parser.int
```

`versionP` एक _पार्सर पाइपलाइन_ की मदद से बनाया गया है।
`(|.)` ऑपरेटर का मतलब है "स्ट्रिंग को पार्स करो, पर परिणाम छोड़ दो" और `(|=)` का मतलब है "स्ट्रिंग को पार्स करो और परिणाम रख लो"।
इस उदाहरण में `Parser.keyword "HAI"` एक "HAI" पढ़ लेगा, पर उस परिणाम पर ध्यान नहीं दिया जाता।
`Parser.spaces` किसी भी संख्या में ' ', '\n' और '\r' अक्षर पढ़ लेगा, पर उसे भी छोड़ दिया जाएगा।
`Parser.int` एक पूर्णांक पार्स करेगा, और उस पूर्णांक की वैल्यू (मान लीजिए 1) सबसे ऊपर वाले `Parser.succeed Version` को दी जाएगी, और पार्सर `Version 1` वैल्यू लौटाने में सफल हो जाएगा।

अगर पाइपलाइन का कोई भी पार्सर विफल होता है, तो वह एक `Parser.DeadEnd` लौटाता है और पूरा पार्सर विफल हो जाता है।
किसी पार्सर को `Parser.run` से चलाया जा सकता है:

```elm
Parser.run versionP "HAI 1"
    --> Ok (Version 1)
Parser.run versionP "HAI 2"
    --> Ok (Version 2)
Parser.run versionP "BYE 2"
    --> Err [{ problem = ExpectingKeyword "HAI", col = 1, row = 1 }]
Parser.run versionP "HAI MOM"
    --> Err [{ problem = ExpectingInt, col = 5, row = 1 }]
```

अब "CAN HAS STDIO?" लाइन के लिए यह लिखते हैं:

```elm
importP : Parser Command
importP =
    Parser.succeed Import
        |. Parser.keyword "CAN HAS"
        |. Parser.spaces
        |= packageP
        |. Parser.symbol "?"
```

`importP` भी एक पार्सर पाइपलाइन है, पर इस बार यह `Parser.symbol` पर खत्म होती है, जो "?" जैसे सिंबल पार्स करने के लिए उपयुक्त है।
जिस वैल्यू को हम रखना चाहते हैं (इम्पोर्ट होने वाले पैकेज का नाम), उसे यह पार्स करता है:

```elm
packageP : Parser String
packageP =
    Parser.chompWhile Char.isAlphaNum
        |> Parser.getChompedString
        |> Parser.map String.toLower
```

चूँकि हमें पता नहीं होता कि पैकेज का नाम क्या होगा, हम `Parser.keyword` इस्तेमाल नहीं कर सकते, इसलिए उसकी जगह `Parser.chompWhile` लेते हैं, जो तब तक एक-एक अक्षर पढ़ता जाता है जब तक वे कोई शर्त पूरी करते रहें (यहाँ, अल्फान्यूमेरिक अक्षर होना)।
इन पढ़े गए अक्षरों को फिर `Parser.getChompedString` इकट्ठा करता है, जो एक `Parser String` लौटाता है।
यहाँ हम पैकेज के नामों को एक समान रूप देना चाहते हैं, इसलिए `Parser.map` से पार्सर में मौजूद स्ट्रिंग को बदलकर उसे छोटे अक्षरों में कर देते हैं।

```elm
Parser.run importP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS StDiO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS STDIO"
    -->  Err [{ problem = ExpectingSymbol "?", col = 14, row = 1 }]
```

इसके बाद, `VISIBLE "HAI WORLD!"` को यह पार्स करता है:

```elm
printP : Parser Command
printP =
    Parser.succeed Print
        |. Parser.keyword "VISIBLE"
        |. Parser.spaces
        |. Parser.symbol "\""
        |= stringP
        |. Parser.symbol "\""

stringP : Parser String
stringP =
    Parser.chompWhile (\c -> c /= '"')
        |> Parser.getChompedString

Parser.run printP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
```

अब हमारे पास हर कमांड के लिए एक पार्सर है।
बेशक, किसी सामान्य प्रोग्राम में इन कमांड का क्रम पहले से नहीं बताया जा सकता, इसलिए हम एक सामान्य कमांड पार्सर बनाते हैं:

```elm
commandP : Parser Command
commandP =
    Parser.oneOf
        [ versionP
        , importP
        , printP
        ]
```

`Parser.oneOf` दिए गए क्रम में एक-एक पार्सर आज़माता है।
अगर कोई पार्सर विफल होता है, तो अगला आज़माया जाता है, पर अगर वह सफल हो जाए, तो बाकी पार्सर आज़माए बिना उसका परिणाम लौटा दिया जाता है।
अगर सारे पार्सर विफल हो जाएँ, तो `Parser.oneOf` भी विफल हो जाता है।

```elm
Parser.run commandP "HAI 2"
    --> Ok (Version 2)
Parser.run commandP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run commandP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
Parser.run commandP "O NOES"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 1 }
    --      ]
```

ध्यान दीजिए कि हर विफल कोशिश एक `Parser.DeadEnd` बनाती है, जिसे `Parser.oneOf` इकट्ठा कर लेता है।

पूरे प्रोग्राम को पार्स करने के लिए हमें कई कमांड एक के बाद एक पार्स करने होते हैं:

```elm
programP : Parser (List Command)
programP =
    Parser.sequence
        { start = ""
        , separator = "\n"
        , end = "KTHXBYE"
        , spaces = Parser.succeed ()
        , item = commandP
        , trailing = Parser.Optional
        }
```

`Parser.sequence` को कई विकल्पों के साथ अपनी ज़रूरत के हिसाब से बनाया जा सकता है।
`start`, `separator` और `end` ऐसी स्ट्रिंग लेते हैं जो सीक्वेंस के आइटम को अलग करती हैं; Elm की लिस्ट पार्स करने के लिए हम "[", "," और "]" इस्तेमाल करेंगे।
`spaces` ऐसा पार्सर लेकर लचीलापन देता है जो आइटम और सेपरेटर के बीच संभावित स्पेस संभाल लेगा; Elm की लिस्ट पार्स करने के लिए हम `Parser.spaces` इस्तेमाल करेंगे, पर यहाँ हम कोई स्पेस स्वीकार नहीं करते, इसलिए `Parser.succeed ()` लेते हैं, जो बिना कुछ पढ़े तुरंत सफल हो जाता है।
`item` आइटम का पार्सर लेता है, और आखिर में `trailing` तय करने देता है कि अंत में आने वाले सेपरेटर `Parser.Forbidden`, `Parser.Mandatory` या `Parser.Optional` हैं।

```elm
Parser.run programP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run programP "KTHXBYE"
    --> Ok []
Parser.run programP "HAI 2\nCAN HAS STDIO?\n"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 3 }
    --      , { problem = Expecting "KTHXBYE", col = 1, row = 3 }
    --      ]
```

जब पार्सर सफल हो जाते हैं, तो वे स्ट्रिंग पढ़ना वहीं रोक देते हैं:

```elm
Parser.run Parser.int "1"
    --> Ok 1
Parser.run Parser.int "1 BTW VISIBLE \"U SEE NOTHING\""
    --> Ok 1
```

इसलिए अगर हमें यह पक्का करना हो कि स्ट्रिंग में सब कुछ पार्स हो गया, तो हम `Parser.end` इस्तेमाल कर सकते हैं:

```elm
fullProgramP : Parser (List Command)
fullProgramP =
    programP
        |. Parser.spaces
        |. Parser.end

Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE\nBTW VISIBLE \"U SEE NOTHING\""
    --> Err [{ problem = ExpectingEnd, col = 1, row = 4 }]
```

अंत में, कभी-कभी हमें पार्स किए गए कंटेंट के आधार पर पार्सर को विफल करने का फैसला लेना पड़ता है।
जैसे, अगर हमें ऐसा पार्सर चाहिए जो उन प्रोग्राम को विफल कर दे जो लगातार दो "HAI" कमांड से शुरू होते हैं, तो हम यह लिख सकते हैं:

```elm
singleVersionProgramP : Parser (List Command)
singleVersionProgramP =
    fullProgramP
        |> Parser.andThen
            (\commands ->
                case commands of
                    (Version _) :: (Version _) :: _ ->
                        Parser.problem "Multiple versions defined"

                    _ ->
                        Parser.succeed commands
            )
```

`Parser.andThen` किसी पार्सर के कंटेंट को देख सकता है और उसकी वैल्यू के हिसाब से एक नया पार्सर लौटाता है।
यहाँ हमने एक स्थिति में `Parser.problem` से अपना संदेश देकर पार्सर को विफल किया, और दूसरी स्थिति में मूल वैल्यू लौटा दी।

```elm
Parser.run singleVersionProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run singleVersionProgramP "HAI 1\nHAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Err [{ problem = Problem "Multiple versions defined", col = 8, row = 4 }]
```
