# परिचय

## स्ट्रिंग

Elm में टेक्स्ट दिखाने का आधार अक्षर और स्ट्रिंग हैं।
स्ट्रिंग को अक्षरों का ऐरे माना जा सकता है, और `List` के ज़्यादातर फंक्शन का समकक्ष `String` मॉड्यूल में मौजूद होता है।

### अक्षर

`Char` टाइप एक अकेला यूनिकोड अक्षर दिखाता है, जिसे सिंगल कोट में लिखा जाता है, जैसे `'a'`।
`Char` मॉड्यूल में किसी अक्षर के गुण जाँचने के लिए प्रेडिकेट फंक्शन (`Char -> Bool`) मिलते हैं: `isUpper`, `isLower`, `isAlpha` और `isAlphaNum`
इस मॉड्यूल में अक्षर को अपर केस या लोअर केस में बदलने वाले फंक्शन भी हैं: `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, और साथ ही `toCode` तथा `fromCode` की मदद से अक्षर को उसकी संख्यात्मक यूनिकोड वैल्यू (`Int`) में बदलने और वहाँ से वापस बदलने वाले फंक्शन भी।

### स्ट्रिंग

`String` टाइप में कुशल स्ट्रिंग संचालन के लिए पहले से मौजूद व्यवस्था है, और यह यूनिकोड अक्षरों के किसी भी क्रम को दिखा सकता है, जैसे "this is an Elm string."
मल्टी-लाइन स्ट्रिंग तीन डबल कोट के बीच लिखी जाती है, और उसमें बिना एस्केप किए कोट तथा नई लाइनें हो सकती हैं।
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### स्ट्रिंग के फंक्शन

`String` मॉड्यूल में नीचे दी गई टेबल में बताए गए सभी फंक्शन मौजूद हैं।
इनमें से सबसे ज़्यादा इस्तेमाल होने वाले कुछ फंक्शन ये हैं:

`cons : Char -> String -> String` स्ट्रिंग के शुरू में एक अक्षर जोड़ता है।
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` दो स्ट्रिंग को जोड़ता है।
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` दी गई सेपरेटर पर स्ट्रिंग को स्ट्रिंग के ऐरे में तोड़ देता है।
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` स्ट्रिंग के ऐरे को दिए गए सेपरेटर के साथ जोड़ देता है।
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` दिए गए सबस्ट्रिंग की सभी जगहों को बदल देता है।
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` किसी स्ट्रिंग में अक्षरों की संख्या लौटाता है।
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` किसी स्ट्रिंग को `Just Int` में बदलने की कोशिश करता है, और गलत तरीके से लिखी स्ट्रिंग के लिए `Nothing` लौटाता है।
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` जाँचता है कि दूसरी स्ट्रिंग में पहली स्ट्रिंग मौजूद है या नहीं।
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` स्ट्रिंग के हर `Char` पर दिया गया फंक्शन लागू करता है।
ध्यान दीजिए कि दिया गया फंक्शन `Char` से `Char` की ओर मैपिंग होना चाहिए।
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
