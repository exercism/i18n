# परिचय

Clojure एक फंक्शनल भाषा है, और इसमें फंक्शन को भी डेटा जितना ही महत्व मिलता है। इसका मतलब है कि फंक्शन को डेटा की तरह ही दूसरे फंक्शन को दिया जा सकता है, और दूसरे फंक्शन उन्हें बना भी सकते हैं। Clojure में खास तौर पर हायर-ऑर्डर फंक्शन का एक समृद्ध समूह मौजूद है, जो पहले से मौजूद फंक्शन के आधार पर नए फंक्शन बनाते हैं। यहाँ हम चार महत्वपूर्ण मामले देखेंगे: `partial`, `comp`, `memoize` और `juxt`। फंक्शन बनाने वाले ये फंक्शन हायर-ऑर्डर फंक्शन की एक बड़ी श्रेणी में आते हैं, जैसे `map`, `reduce`, `apply`, `complement`, और भी कई, जो मौजूदा फंक्शन पर काम करते हैं।

## partial

आम तौर पर, अगर हमारे पास एक मौजूदा फंक्शन `my-function` है जिसके पैरामीटर `p1, p2, ..., pN` हैं, तो हम उसके कुछ पैरामीटर `p1, p2, ..., pM` को स्थिर वैल्यू `v1, v2, ..., vM` पर जमा सकते हैं। ऐसा करने के लिए हम `partial` का इस्तेमाल इस तरह करते हैं: `(partial my-function v1 v2 ... vM)`। 

नतीजा एक नया फंक्शन होता है, जो `p1=v1, p2=v2, ..., pM=vM` तय करके असली फंक्शन `my-function` को लागू करता है। हमारा नया फंक्शन बाकी पैरामीटर `pM+1, pM+2, ..., pN` इनपुट के तौर पर लेता है, जिनकी वैल्यू `partial` लगाते समय नहीं बताई जाती:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

एक आसान उदाहरण लीजिए। चलिए एक फंक्शन `inc-by-9` बनाते हैं, जो हम जो भी वैल्यू दें उसे हमेशा 9 से बढ़ा देता है। ऐसा फंक्शन हम इस तरह बना सकते हैं:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

दूसरे उदाहरण में हमारे पास एक फंक्शन `generic-greetings` है, जो जिस व्यक्ति का अभिवादन करना है उसका नाम, और शुरू तथा अंत का संदेश लेता है:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

अब हम `partial` की मदद से हमेशा एक तय अभिवादन संदेश इस्तेमाल कर सकते हैं:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` की मदद से हम जितने भी फंक्शन जोड़ना चाहें, उनका एक संयोजन बना सकते हैं। आम तौर पर `N` फंक्शन `f1, f2, ..., fN` को जोड़ने का मतलब है उन्हें एक के बाद एक क्रम में लगाना, यानी पिछले फंक्शन का आउटपुट अगले को देना। गणित की भाषा में इसे ऐसे लिखा जाता है:

```
f1 (f2 (... fN(x)))
```

Clojure में यह इसके बराबर है:
```clojure
(f1 (f2 (... (fN x))))
```

comp का इस्तेमाल करके हम एक नया फंक्शन बना सकते हैं जो यह संयोजन हमारे लिए कर देता है:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

एक उदाहरण लीजिए: मान लीजिए हम कई संख्याओं का जोड़ निकालना चाहते हैं और फिर परिणाम को 6 से गुणा करना चाहते हैं। यह हम इस तरह कर सकते हैं:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` की मदद से हम किसी दिए गए इनपुट से जुड़े पहले निकाले गए परिणामों को दोबारा इस्तेमाल कर सकते हैं। एक ही इनपुट मिलने पर *मेमोइज़ किया गया* फंक्शन वही परिणाम लौटा देता है, बिना उसे दोबारा निकाले। यह इस बात का लाभ उठाता है कि `clojure` के फंक्शन डिफ़ॉल्ट रूप से *रेफरेंशियल ट्रांसपेरेंट* होते हैं: एक ही इनपुट पर वे हमेशा एक ही आउटपुट देते हैं, इसलिए पिछली गणनाओं को आसानी से दोबारा इस्तेमाल किया जा सकता है। 

इसे काम करते देखने के लिए चलिए एक कृत्रिम उदाहरण लेते हैं, जिसमें फंक्शन आउटपुट देने से पहले दो सेकंड रुक जाता है। इससे हम `memoize` इस्तेमाल करने से पहले और बाद के *गणना के समय* की आसानी से तुलना कर सकते हैं।

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` एक ऐसा फंक्शन बनाता है जो उसे दिए गए फंक्शन को बाएँ से दाएँ क्रम में लागू करता है। परिणाम एक वेक्टर होता है, जिसके एलिमेंट हर फंक्शन के अलग-अलग परिणाम होते हैं: 

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

एक आसान उदाहरण लीजिए: हम एक ऐसा फंक्शन बनाते हैं जो x को 2 से 5 तक के गुणकों से एक के बाद एक गुणा करके गुणनफल निकालता है:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
