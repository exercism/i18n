# परिचय

Factor की `random` वोकैबुलरी एक जेनेरिक वर्ड, `random`, देती है, जो अपने आर्गुमेंट के अनुसार ढल जाता है। इसके साथ ही इसमें सीक्वेंस को शफल करने और उनसे सैंपल लेने के हेल्पर भी हैं।

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

किसी पूर्णांक `n` पर `random` एक वैल्यू लौटाता है जो `[0, n)` में आती है, और किसी सीक्वेंस पर यह एक रैंडम एलिमेंट लौटाता है। `randomize` सीक्वेंस को वहीं पर शफल कर देता है, और `sample` अलग-अलग एलिमेंट निकालता है।

डिफ़ॉल्ट रूप से ये सभी एक ग्लोबल जेनरेटर से वैल्यू लेते हैं, जिसे सिस्टम क्लॉक से सीड किया जाता है। परिणाम हर बार एक जैसे पाने के लिए `<mersenne-twister>` (जो [`random.mersenne-twister`][mt] से आता है) और `with-random` की मदद से एक सीड किया हुआ जेनरेटर सेट कीजिए:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[random]: https://docs.factorcode.org/content/vocab-random.html
[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
