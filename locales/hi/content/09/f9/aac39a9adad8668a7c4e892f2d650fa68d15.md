# परिचय

[Stringer][stringer-interface] एक इंटरफेस है जिसके ज़रिए तय किया जाता है कि किसी वैल्यू का स्ट्रिंग फॉर्मेट कैसा होगा।

इस इंटरफेस में सिर्फ एक मेथड है, `String`:

```go
type Stringer interface {
    String() string
}
```

जो टाइप इस इंटरफेस को लागू करना चाहते हैं, उनमें एक `String()` मेथड होना ज़रूरी है जो उस टाइप का इंसान के लिए पढ़ने लायक स्ट्रिंग रूप लौटाता है।
[fmt][fmt-package] पैकेज (और कई और पैकेज भी) वैल्यू को फॉर्मेट करके छापने के लिए इसी मेथड को ढूँढता है।

## उदाहरण: दूरियाँ

मान लीजिए हम एक ऐसी ऐप पर काम कर रहे हैं जिसमें अलग-अलग इकाइयों में नापी गई भौगोलिक दूरियों से काम पड़ता है।
हमने `DistanceUnit` और `Distance` टाइप इस तरह बनाए हैं:

```go
type DistanceUnit int

const (
	Kilometer    DistanceUnit = 0
	Mile         DistanceUnit = 1
)

type Distance struct {
	number float64
	unit   DistanceUnit
}
```

ऊपर के उदाहरण में `Kilometer` और `Mile`, `DistanceUnit` टाइप के कॉन्स्टेंट हैं।

इन टाइप में `String` मेथड नहीं है, इसलिए ये `Stringer` इंटरफेस को लागू नहीं करते।
इस वजह से `fmt` के फंक्शन `Distance` वैल्यू को Go के "डिफ़ॉल्ट फॉर्मेट" में छापते हैं:

```go
mileUnit := Mile
fmt.Sprint(mileUnit)
// => 1
// The result is '1' because that is the underlying value of the 'Mile' constant (see constant declarations above)

dist := Distance{number: 790.7, unit: Kilometer}
fmt.Sprint(dist)
// => {790.7 0}
// not a very useful output!
```

आउटपुट को और जानकारीपूर्ण बनाने के लिए हम `DistanceUnit` और `Distance` टाइप के लिए `Stringer` इंटरफेस लागू करते हैं और हर टाइप में एक `String` मेथड जोड़ते हैं:

```go
func (sc DistanceUnit) String() string {
	units := []string{"km", "mi"}
	return units[sc]
}

func (d Distance) String() string {
	return fmt.Sprintf("%v %v", d.number, d.unit)
}
```

`Distance` वैल्यू फॉर्मेट करते समय `fmt` पैकेज के फंक्शन इन मेथड को कॉल करते हैं:

```go
kmUnit := Kilometer
kmUnit.String()
// => km

mileUnit := Mile
mileUnit.String()
// => mi

dist := Distance{
	number: 790.7,
	unit: Kilometer,
}
dist.String()
// => 790.7 km
```
