# निर्देश अपेंड

## आउटपुट के प्रारूप

`treeFromTraversals` फंक्शन से अपेक्षा है कि वह 3 प्रॉपर्टी वाला एक ऑब्जेक्ट लौटाए:

- `value` मौजूदा नोड की वैल्यू
- `left` ऐसा ऑब्जेक्ट जिसमें नोड का बायाँ चाइल्ड होता है
- `right` ऐसा ऑब्जेक्ट जिसमें नोड का दायाँ चाइल्ड होता है

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

अगर ट्री खाली हो, तो एक खाली ऑब्जेक्ट लौटाया जाना चाहिए।
