# निर्देश

एक बार फिर नमस्ते, एजेंट डबल-नल0111।

UMBRA की शक्तियाँ फिर से सिर उठा रही हैं, और उनकी नई चाल विफल करना आपके ही हाथ में है। हमारे गुप्तचर विभाग ने बताया है कि वे मिनियन गवर्नर के बॉल में एक बदबूदार बम फोड़ने की योजना बना रहे हैं।

चूँकि मिनियन बहुत अनाड़ी हैं, वे अक्सर अपनी लैब और दफ्तरों में गलती से बदबूदार बम चालू कर देते हैं। और चूँकि वे बार-बार भूल जाते हैं कि अपने इन बमों को निष्क्रिय कैसे करना है, उन्होंने एक ऐसा सिस्टम बना लिया है जो निष्क्रिय करने के निर्देश तैयार करता है। ये निर्देश बम के ID नंबर के आधार पर बताते हैं कि तार किस क्रम में काटने हैं।

आपका काम यह कोड लिखना है जिसकी मदद से आप बॉल में लगे बदबूदार बम को फूटने से पहले निष्क्रिय कर सकें।

## 1. दो तारों की अदला-बदली के लिए क्लोजर लिखिए

हर बदबूदार बम पर अलग-अलग रंग के तीन तार होते हैं।
एक क्लोजर लिखिए जो `(String, String, String)` ट्यूपल लेता है और उस ट्यूपल को लौटाता है जिसमें पहले दो एलिमेंट का क्रम आपस में बदल दिया गया हो।
इस क्लोजर को `flip` नाम दीजिए।

यह ध्यान रखना ज़रूरी है कि टाइप `ChangeClosure` होना चाहिए (या कोई sendable टाइप); टाइप की परिभाषा स्टब फाइल में दी गई है।
वरना कोड कंपाइल नहीं होगा।

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. तारों को घुमाने के लिए क्लोजर लिखिए

एक क्लोजर लिखिए जो `(String, String, String)` ट्यूपल लेता है और उस ट्यूपल को लौटाता है जिसमें तारों का क्रम बाईं ओर घुमा दिया गया हो।
इस क्लोजर को `rotate` नाम दीजिए।

यह ध्यान रखना ज़रूरी है कि टाइप `ChangeClosure` होना चाहिए (या कोई sendable टाइप); टाइप की परिभाषा स्टब फाइल में दी गई है।

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. तारों के शफल का जनरेटर बनाइए

बदबूदार बम के तार किस क्रम में काटने हैं, यह पता लगाने के लिए आपको एक ऐसा फंक्शन बनाना होगा जो बम के ID नंबर के आधार पर सही शफल करने वाला फंक्शन तैयार करे।

यह फंक्शन बनाइए:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

यह फंक्शन इनपुट में दो तारों की अदला-बदली करने वाला एक क्लोजर और तीनों तारों को घुमाने वाला एक क्लोजर लेता है, और एक क्लोजर लौटाता है।
जो क्लोजर लौटता है, वह बदबूदार बम का ID नंबर और तीनों तारों का क्रम लेता है, और फिर यह पता लगाता है कि तार किस क्रम में काटने हैं।
ID नंबर आठ बिट का बना होता है, और हर बिट यह तय करता है कि तारों की अदला-बदली करनी है या उन्हें घुमाना है।

ID नंबर की हर बिट के लिए, सबसे दाईं बिट से शुरू करते हुए, अगर बिट 0 है तो तारों के ट्यूपल पर `flipper` क्लोजर लगाइए, और अगर बिट 1 है तो `rotator` क्लोजर लगाइए। इससे तारों की नई स्थिति मिलती है।
ID की आठों बिट पर सही क्लोजर लगाने के बाद, तारों की अंतिम स्थिति से ही यह तय होता है कि उन्हें किस क्रम में काटना है।

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
