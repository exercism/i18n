# निर्देश

इस अभ्यास में आप कई तरह की रिमोट कंट्रोल कारों के बीच रेस का आयोजन करेंगे। हर कार की अपनी खास विशेषताएँ होती हैं। टूर्नामेंट सीज़न भर में वह कई अलग-अलग ट्रैक पर होने वाली रेसों में दौड़ती है।

~~~~exercism/note
इस अभ्यास के फंक्शन एक C सोर्स फाइल में दिए गए सिग्नेचर के साथ घोषित किए गए हैं।
आपके x86-64-assembly कोड को उन सिग्नेचर का पालन करना चाहिए।
~~~~

## 1. रिमोट कंट्रोल कार बनाइए

रिमोट कंट्रोल कार को दर्शाने के लिए आपने एक struct `car_t` बनाया है:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

x86-64 assembly में `new_car` फंक्शन बनाकर रिमोट कंट्रोल कार बनाना संभव कीजिए।
`battery` फील्ड की शुरुआती वैल्यू हमेशा `100.0` रहती है।

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. नया ट्रैक बनाइए

ट्रैक को एक struct `track_t` से दर्शाया जाता है:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t` ट्रैक की अलग-अलग सतहों का हिसाब रखता है:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

x86-64 assembly में `new_track` फंक्शन बनाकर नया ट्रैक बनाना संभव कीजिए।

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. रेसिंग इवेंट बनाइए

हर रेस में अधिकतम 6 कारें हिस्सा लेती हैं और ट्रैक पर तय संख्या में लैप पूरे करती हैं।
रेस को एक struct `race_t` से दर्शाया जाता है:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

x86-64 assembly में `new_race` फंक्शन बनाइए।
शुरू में रेस में हिस्सा लेने वाली कोई भी कार पक्की नहीं होती:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. रेस में कार की भागीदारी पक्की कीजिए

जब कार का मालिक उसे किसी रेस में शामिल करने के लिए कहता है, तो उसकी भागीदारी तभी पक्की होती है जब सूची में अभी जगह बाकी हो।

x86-64 assembly में `add_participant` फंक्शन बनाइए।
अगर रेस में एक और प्रतिभागी के लिए जगह है, तो कार को सूची में जोड़ दिया जाता है और काउंटर बढ़ा दिया जाता है। इस तरह उसकी भागीदारी पक्की हो जाती है।
वरना रेस के आयोजकों को कार के मालिक को बताना होता है कि यह इस बार हिस्सा नहीं ले सकती।

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. टूर्नामेंट बनाइए

सीज़न के लिए तय रेसों का हिसाब आप एक struct `tournament_t` में रखते हैं:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

टूर्नामेंट के ऐरे में एक रेस जोड़ने और साथ ही उसका काउंटर बढ़ाने के लिए x86-assembly में `add_race` फंक्शन बनाइए।
आप यह मान सकते हैं कि `races` ऐरे में नई रेस के लिए जगह हमेशा पर्याप्त रहेगी।

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
