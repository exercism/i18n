# इसके बारे में

Common Lisp में गलत वैल्यू को खाली लिस्ट `()` या सिंबल `nil` से दर्शाया जाता है। इन वैल्यू को क्वोट किया जा सकता है या बिना क्वोट किए भी लिखा जा सकता है।

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Lisp में बाकी सभी वैल्यू सही होती हैं। एक खास कॉन्स्टेंट सिंबल `t` भी होता है, जो हमेशा `t` के बराबर होता है, और इसलिए हमेशा सही होता है।

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
