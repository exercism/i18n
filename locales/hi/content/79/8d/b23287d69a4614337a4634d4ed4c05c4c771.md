# संकेत

## सामान्य

- हो सकता है आप टैग और रिकॉर्ड की सूचियों पर आधारित एक DSL बनाना चाहें, जैसे:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- या शायद आप फंक्शन कॉल की चेन पर आधारित DSL ज़्यादा पसंद करें, जैसे:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  या फिर आपकी योजना बिल्कुल ही अलग हो? तो उसे ज़रूर आज़माइए!

- फिर भी, DSL आम तौर पर तब बेहतर होता है जब वह स्पष्ट, संक्षिप्त और ज़्यादा चौंकाने वाला न हो (जैसे `minus` फंक्शन घटाने के लिए है, दो नोड के बीच एज बनाने के लिए नहीं, जैसा `node("a") - node("b")` में दिखता है)।
