# निर्देश

Isaacs Asteroid Exploration Co. के क्लेम विभाग ने आपको उनके भूमि दावा सिस्टम का प्रदर्शन बेहतर बनाने का काम सौंपा है।

हर बार जब कोई नया क्षुद्रग्रह उपयोग के लिए तैयार होता है, तो सट्टेबाज़ों को भूमि के एक टुकड़े पर अपना दावा करने के लिए आमंत्रित किया जाता है। क्षुद्रग्रह की भूमि चार भुजाओं वाले प्लॉटों में बाँटी गई है। सट्टेबाज़ प्लॉट के आयाम बताकर उस पर अपना दावा करते हैं।

आपको एक ऐसा तेज़ सिस्टम बनाना है जो भूमि के लिए इस होड़ को संभाल सके, जिसकी वजह से पहले वेबसाइट क्रैश हो चुकी है।

माप की इकाई 100 मीटर है, लेकिन इन कामों में इस पर ध्यान देने की ज़रूरत नहीं है।

## 1. एक प्लॉट बनाइए

`Plot` स्ट्रक्चर का कार्यान्वयन पूरा कीजिए। इस स्ट्रक्चर में चार coord स्ट्रक्चर होते हैं, जिन्हें यह अपने कंस्ट्रक्टर में स्वीकार करता है।

## 2. सट्टेबाज़ आयामों से पहचाने जाने वाले प्लॉट का दावा दर्ज कर सकते हैं

दावा दर्ज करने की सुविधा देने के लिए `ClaimsHandler.StakeClaim()` मेथड लागू कीजिए।

कोई दावा दर्ज हुआ है या नहीं, यह देखने के लिए `ClaimsHandler.IsClaimStaked()` मेथड लागू कीजिए।

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsClaimStaked(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 3. जाँचिए कि मौजूदा दावा पिछले दावे जैसा ही है या नहीं

मौजूदा दावे की तुलना पिछले दावे से करने के लिए `ClaimsHandler.IsLastClaim()` मेथड लागू कीजिए।

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsLastClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 4. शोध के उद्देश्य से सबसे लंबी भुजा वाला दावा किया गया प्लॉट ढूँढिए

सभी दर्ज दावों की जाँच करके सबसे लंबी भुजा वाला प्लॉट लौटाने के लिए `ClaimsHandler.GetClaimWithLongestSide()` मेथड लागू कीजिए। किसी प्लॉट के निर्देशांक हमेशा एक ही जुड़े हुए आयताकार आकार में होते हैं।

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.StakeClaim(new Plot(new Coord(10,1), new Coord(20,1), new Coord(10,2), new Coord(20,2)));
ch.GetClaimWithLongestSide();
// => new Plot(new Coord(1,1), new Coord(20,1), new Coord(1,2), new Coord(2,2))
```
