# परिचय

`Option` एक एनम है जिसका उपयोग फंक्शन से लौटाई गई वैल्यू की वैधता जाँचने के लिए किया जाता है। इसकी परिभाषा इस तरह है:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

यह `haxe.ds` पैकेज का हिस्सा है:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
