# मैच एक्सप्रेशन

एक मैच एक्सप्रेशन एक वैल्यू और एक शर्त का मूल्यांकन करके एक ऐसा एक्सप्रेशन लौटाता है जिसका मूल्यांकन होना है। टर्नरी की तरह ही, अगर शर्त मेल नहीं खाती, तो लौटाए जाने वाले एक्सप्रेशन का मूल्यांकन नहीं होता। शर्त का मेल जाँचने के लिए पहचान की जाँच की जाती है [सख्त समानता या `===`]।

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

समानता [`==`] की जाँच करने के लिए आप शर्त को दूसरे रूप में लिख सकते हैं:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

मैच एक्सप्रेशन में अगर कोई शर्त मेल नहीं खाती, तो एक `UnhandledMatchError` फेंकी जाती है।
