# एंट्री API

मैप संरचना की सामग्री को बदलने का सबसे स्वाभाविक तरीका अक्सर एंट्री API ही होता है। लेकिन Rust में यह असामान्य बात है कि इसे किसी ट्रेट का रूप नहीं दिया गया। यह सिर्फ टाइप और मेथड का एक समूह है, जिन्हें स्टैंडर्ड लाइब्रेरी के मैप टाइप पर लागू किया गया है।

मूल रूप से, `map.entry()` मेथड एक `enum` देता है:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

इसका फायदा उन और मेथड से मिलता है जो इस एनम पर लागू किए गए हैं। उदाहरण के लिए, अगर आप किसी खास की की वैल्यू निकालना चाहते हैं और शायद उसे बदलना भी चाहते हैं, और उस वैल्यू के टाइप का डिफॉल्ट ठीक बैठता है, तो आप सीधे यह कर सकते हैं:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

काउंटर जैसे कामों के लिए इससे ज़िंदगी बहुत आसान हो जाती है:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

अगर टाइप की डिफॉल्ट वैल्यू आपके काम के लिए ठीक न हो, तो आप `or_insert` के ज़रिए अपना खुद का स्थिर डिफॉल्ट दे सकते हैं, या `or_insert_with` से एक की गणना कर सकते हैं।

कुछ मामलों में आप कोई नई वैल्यू डालने से पहले मौजूदा वैल्यू पर कोई गणना करना चाह सकते हैं। ऐसे मामलों में `and_modify` यह काम करने देता है। हालाँकि ऐसा इस्तेमाल कुछ कम ही होता है। `and_modify` का इस्तेमाल ज़्यादातर डीरेफरेंस करने की ज़रूरत टालने के लिए होता है:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

कभी-कभी एंट्री को सीधे match करना भी अच्छा रहता है। यह भी मान्य है:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

ज़्यादा जानकारी के लिए [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) और [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html) देखिए।
