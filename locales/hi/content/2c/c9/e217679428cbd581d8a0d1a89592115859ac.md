# परिचय

कोड को शर्त के अनुसार चलाने के लिए [`if/elif/else` एक्सप्रेशन][conditional-expression] का उपयोग किया जा सकता है। किसी `if/elif/else` एक्सप्रेशन में इस्तेमाल होने वाली शर्त का टाइप `bool` होना चाहिए। F# में _truthy_ वैल्यू की कोई अवधारणा नहीं है।

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

चूँकि `if/elif/else` एक एक्सप्रेशन है, इसे किसी नाम से बाँधा जा सकता है या फंक्शन से लौटाया जा सकता है।

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

सभी शाखाओं को एक ही टाइप लौटाना चाहिए। ऐसा न करने पर कंपाइलर एरर मिलती है:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

`else` और `elif` शाखाएँ ज़रूरी नहीं हैं, लेकिन केवल तब जब लौटाए गए एक्सप्रेशन का टाइप [`unit`][unit-type] हो।

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

एक `if/else` एक्सप्रेशन को एक ही लाइन पर भी लिखा जा सकता है। इसका उपयोग केवल सरल `if` एक्सप्रेशन के लिए ही करना चाहिए।

```fsharp
let y = if x > 5 then 10 else 20
```
