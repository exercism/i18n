# परिचय

स्टैटिक एक्सटेंशन की मदद से मौजूदा टाइप को उनका सोर्स कोड बदले बिना छद्म रूप से बढ़ाया जा सकता है। यह काम `using` स्टेटमेंट से होता है। स्टैटिक एक्सटेंशन एक शक्तिशाली टूल हो सकता है, जिससे टाइप को वास्तव में बदले बिना उनमें नई चीज़ें जोड़ी जा सकती हैं।

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
