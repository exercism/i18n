# `case` स्टेटमेंट

जब एक वैल्यू की तुलना संभावनाओं की सूची से की जाती है, तो `elsif` की एक श्रृंखला एक ही बात बार-बार कहती है:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` इसे एक ही बार में कहता है:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

वैल्यू `case` के बाद आती है। हर `when` तुलना के लिए एक वैल्यू देता है, और जो पहला मेल खाता है वही चलता है।

## एक ही `when` में कई वैल्यू

एक `when` कई वैल्यू की सूची दे सकता है, जो कॉमा से अलग होती हैं:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

यह पूर्ण संख्याओं, अक्षरों और स्ट्रिंग पर काम करता है, यानी किसी भी ऐसी चीज़ पर जिसकी तुलना `=` से की जा सकती है।

## `else` वैकल्पिक नहीं है

**ऐसा `case` जो किसी वैल्यू से मेल नहीं खाता और जिसमें `else` नहीं है, एक एरर है जो होने पर प्रोग्राम को रोक देती है।**

यह `if` से अलग है, जहाँ `else` छोड़ देने का मतलब बस यह होता है कि कुछ नहीं होता। यह अधिकांश भाषाओं से भी अलग है, जहाँ किसी से मेल न खाने वाला `case` चुपचाप कुछ नहीं करता।

इसलिए हर `case` को एक `else` की ज़रूरत होती है, भले ही आपको यकीन हो कि `when` वाले हिस्से पहले से ही हर वैल्यू को कवर करते हैं। बाद में एक चौथा ज़ोन जोड़ा जाता है, `case` को उसके हिसाब से बदला नहीं जाता, और जो पहला यात्री उस चौथे ज़ोन का इस्तेमाल करता है, उस पर प्रोग्राम रुक जाता है।

## केवल एक `when` चलता है

जब कोई `when` मेल खाता है, तो उसके `then` के बाद वाले स्टेटमेंट चलते हैं और `case` समाप्त हो जाता है। प्रोग्राम `end` के बाद आगे चलता रहता है। इसके नीचे वाले `when` हिस्सों को कभी देखा ही नहीं जाता, इसलिए अगले `when` को भी चलने से रोकने के लिए आपको कुछ लिखने की ज़रूरत नहीं होती।
