# निर्देश

जादूगर बनने की तैयारी में Elyse को कुछ बुनियादी बातों का अभ्यास करना है। उसके पास कार्डों का एक स्टैक है, जिसके साथ वह तरह-तरह के करतब दिखाना चाहती है।

चीज़ों को थोड़ा आसान बनाने के लिए वह सिर्फ 1 से 10 तक के कार्ड इस्तेमाल करती है। इसलिए उसके कार्डों के स्टैक को संख्याओं की एक इंटरनल टेबल से दिखाया जा सकता है। किसी कार्ड की स्थिति टेबल की पंक्ति के अनुरूप होती है। इसका मतलब है कि पंक्ति 1 पहले कार्ड को दर्शाती है, पंक्ति 2 दूसरे कार्ड को, और इसी तरह आगे भी।

## 1. स्टैक से एक कार्ड निकालिए

एक कार्ड उठाने के लिए दिए गए स्टैक से इंडेक्स `position` पर मौजूद कार्ड लौटाइए।

```abap
data(stack) = value #( ( 1 ) ( 2 ) ( 4 ) ( 1 ) ).
data(card) = get_Item( stack = stack
                       position = 3 ).   " card = 4
```

## 2. स्टैक में एक कार्ड की अदला-बदली कीजिए

ज़रा-सी हाथ की सफाई दिखाइए और इंडेक्स `position` पर मौजूद कार्ड को दिए गए नए कार्ड से बदल दीजिए। बदले हुए स्टैक को लौटाइए।

```abap
data(stack) = value #( ( 1 ) ( 2 ) ( 4 ) ( 1 ) ).
data(new_Stack) = set_Item( stack = stack
                            position = 3 
                            replacement = 6 ).   
" new_Stack = 1, 2, 6, 1
```

## 3. स्टैक के ऊपर एक कार्ड डालिए

स्टैक के ऊपर एक नया कार्ड डालकर एक कार्ड को प्रकट कीजिए। बदले हुए स्टैक को लौटाइए।

```abap
data(stack) = value #( ( 5 ) ( 9 ) ( 7 ) ( 1 ) ).
data(new_Stack) = insert_Item_at_Top( stack    = stack
                                      new_Card = 8 ).   
" new_Stack = 5, 9, 7, 1, 8
```

## 4. स्टैक से एक कार्ड हटाइए

स्टैक से दिए गए `position` पर मौजूद कार्ड को हटाकर एक कार्ड को गायब कीजिए। बदले हुए स्टैक को लौटाइए।

```abap
data(stack) = value #( ( 3 ) ( 2 ) ( 6 ) ( 4 ) ( 8 ) ).
data(new_Stack) = remove_Item( stack    = stack
                               position = 3 ).   
" new_Stack = 3, 2, 4, 8
```

## 5. स्टैक से सबसे ऊपर वाला कार्ड हटाइए

स्टैक के सबसे ऊपर मौजूद कार्ड को हटाकर एक कार्ड को गायब कीजिए। बदले हुए स्टैक को लौटाइए।

```abap
data(stack) = value #( ( 3 ) ( 2 ) ( 6 ) ( 4 ) ( 8 ) ).
data(new_Stack) = remove_Item_from_Top( stack ).   
" new_Stack = 3, 2, 6, 4
```

## 6. स्टैक के सबसे नीचे एक कार्ड डालिए

स्टैक के सबसे नीचे एक नया कार्ड डालकर एक कार्ड को प्रकट कीजिए। बदले हुए स्टैक को लौटाइए।

```abap
data(stack) = value #( ( 5 ) ( 9 ) ( 7 ) ( 1 ) ).
data(new_Stack) = insert_Item_at_Bottom( stack    = stack
                                         new_Card = 8 ).   
" new_Stack = 8, 5, 9, 7, 1
```

## 7. स्टैक के सबसे नीचे से एक कार्ड हटाइए

स्टैक के सबसे नीचे मौजूद कार्ड को हटाकर एक कार्ड को गायब कीजिए। बदले हुए स्टैक को लौटाइए।

```abap
data(stack) = value #( ( 8 ) ( 5 ) ( 9 ) ( 7 ) ( 1 ) ).
data(new_Stack) = remove_Item_from_Top( stack ).   
" new_Stack = 5, 9, 7, 1
```

## 8. स्टैक का आकार जाँचिए

स्टैक का आकार (पंक्तियों की संख्या) लौटाइए।

```abap
data(stack) = value #( ( 3 ) ( 2 ) ( 6 ) ( 4 ) ( 8 ) ).
data(size_of_Stack) = get_Size_of_Stack( stack ).
```
