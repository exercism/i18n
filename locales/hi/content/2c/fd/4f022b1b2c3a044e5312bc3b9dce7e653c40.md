# टास्क

टास्क ऐसे GitHub इश्यू होते हैं जिनमें हम चाहते हैं कि लोग मदद करें। ऐसे काम टेक्स्ट की प्रूफरीडिंग से लेकर कॉन्सेप्ट अभ्यास बनाने तक, कुछ भी हो सकते हैं।
ये वेबसाइट पर दिखते हैं और GitHub पर मौजूद संबंधित इश्यू से जुड़े होते हैं।
हर टास्क पर एक या अधिक प्रॉपर्टी का टैग लगा होता है, और ये प्रॉपर्टियाँ उस इश्यू के लेबल से भरी जाती हैं।
इसके बाद उपयोगकर्ता इन्हीं प्रॉपर्टी के आधार पर टास्क फिल्टर कर सकता है।

## टैग

किसी इश्यू को टास्क माने जाने के लिए उस पर एक या अधिक टास्क-विशेष लेबल लगे होने चाहिए।
इस तरह मेंटेनर चुन सकते हैं कि कुछ ही इश्यू टास्क के रूप में दिखें।

हर टास्क लेबल इस तरह परिभाषित होता है: `x:<type>/<value>`, और पाँच तरह के टास्क समर्थित हैं:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### एक्शन टैग

`x:action/<value>` लेबल बताते हैं कि इश्यू पर काम करते समय योगदानकर्ता किस तरह का काम करेगा।

| टैग                  | विवरण                                  |
| -------------------- | -------------------------------------- |
| `x:action/create`    | शुरू से कुछ बनाना                      |
| `x:action/fix`       | किसी इश्यू को ठीक करना                  |
| `x:action/improve`   | मौजूदा फंक्शनैलिटी या कंटेंट को बेहतर बनाना |
| `x:action/proofread` | टेक्स्ट की प्रूफरीडिंग करना             |
| `x:action/sync`      | कंटेंट को उसके नए वर्शन के साथ सिंक करना |

### नॉलेज टैग

`x:knowledge/<value>` लेबल बताते हैं कि योगदानकर्ता को Exercism की कितनी जानकारी चाहिए।

| टैग                        | विवरण                                      |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | Exercism की पहले से कोई जानकारी ज़रूरी नहीं   |
| `x:knowledge/elementary`   | Exercism की थोड़ी जानकारी ज़रूरी             |
| `x:knowledge/intermediate` | Exercism की काफी जानकारी ज़रूरी             |
| `x:knowledge/advanced`     | Exercism की व्यापक जानकारी ज़रूरी           |

### मॉड्यूल टैग

`x:module/<value>` लेबल बताते हैं कि योगदानकर्ता Exercism के किस हिस्से पर काम करेगा।

| टैग                          | विवरण                       |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | एनालाइज़र पर काम             |
| `x:module/concept`           | कॉन्सेप्ट पर काम             |
| `x:module/concept-exercise`  | कॉन्सेप्ट अभ्यास पर काम      |
| `x:module/generator`         | अभ्यास जनरेटर पर काम         |
| `x:module/practice-exercise` | प्रैक्टिस अभ्यास पर काम      |
| `x:module/representer`       | रिप्रेज़ेंटर पर काम          |
| `x:module/test-runner`       | टेस्ट रनर पर काम             |

### साइज़ टैग

`x:size/<value>` लेबल बताते हैं कि किसी योगदानकर्ता के लिए कितना काम अपेक्षित है।

| टैग              | विवरण            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | बहुत थोड़ा काम    |
| `x:size/small`   | थोड़ा काम   |
| `x:size/medium`  | मध्यम काम  |
| `x:size/large`   | बड़ा काम   |
| `x:size/massive` | बहुत बड़ा काम |

### टाइप टैग

`x:type/<value>` लेबल बताते हैं कि योगदानकर्ता किस तरह का काम करेगा।

| टैग              | विवरण                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | कंटीन्यूअस इंटीग्रेशन पर काम (जैसे GitHub Actions वर्कफ्लो)                                                                                                                                                 |
| `x:type/coding`  | ऐसा कोड लिखना जो छात्रों को दिखने वाले कंटेंट का हिस्सा न हो। आम तौर पर यह प्रोडक्शन-टूलिंग (जैसे टेस्ट रनर), इंटरनल-टूलिंग (जनरेटर), या ऐसी लाइब्रेरी से जुड़े टास्क होते हैं जिनका रखरखाव Exercism करता है। |
| `x:type/content` | कंटेंट पर काम (जैसे अभ्यास, कॉन्सेप्ट)                                                                                                                                                                     |
| `x:type/docker`  | Dockerfiles पर काम                                                                                                                                                                                            |
| `x:type/docs`    | डॉक्यूमेंटेशन पर काम                                                                                                                                                                                          |

## क्लेम किए गए और बिना क्लेम वाले टैग

अगर किसी टास्क पर पहले से कोई और काम कर रहा हो और हम उसे छिपाना चाहें, तो इश्यू पर `x:status/claimed` लेबल जोड़ा जा सकता है।
