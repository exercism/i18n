# निर्देश

इस अभ्यास में आपको क्लासिक गेम Pac-Man के कुछ नियम लागू करने हैं।

आपको चार नियम लागू करने हैं, जो सभी गेम की स्थितियों से जुड़े हैं।

## 1. तय कीजिए कि Pac-Man भूत को खाता है या नहीं

एक फंक्शन बनाइए जो दो बातें लेता है: क्या Pac-Man का पावर पेलेट सक्रिय है, और क्या Pac-Man किसी भूत को छू रहा है। फिर यह बूलियन वैल्यू लौटाता है कि Pac-Man उस भूत को खा सकता है या नहीं। फंक्शन को `true` तभी लौटाना चाहिए जब Pac-Man का पावर पेलेट सक्रिय हो और वह किसी भूत को छू रहा हो।

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. तय कीजिए कि Pac-Man अंक पाता है या नहीं

एक फंक्शन बनाइए जो दो बातें लेता है: क्या Pac-Man किसी पावर पेलेट को छू रहा है, और क्या Pac-Man किसी बिंदु को छू रहा है। फिर यह बूलियन वैल्यू लौटाता है कि Pac-Man को अंक मिले या नहीं। फंक्शन को `true` तभी लौटाना चाहिए जब Pac-Man किसी पावर पेलेट या बिंदु को छू रहा हो।

```lua
rules.score(true, true)
-- => true
```

## 3. तय कीजिए कि Pac-Man हारता है या नहीं

एक फंक्शन बनाइए जो दो बातें लेता है: क्या Pac-Man का कोई पावर पेलेट सक्रिय है, और क्या Pac-Man किसी भूत को छू रहा है। फिर यह बूलियन वैल्यू लौटाता है कि Pac-Man हारता है या नहीं। फंक्शन को `true` तभी लौटाना चाहिए जब Pac-Man किसी भूत को छू रहा हो और उसका कोई पावर पेलेट सक्रिय न हो।

```lua
rules.lose(false, true)
-- => true
```

## 4. तय कीजिए कि Pac-Man जीतता है या नहीं

एक फंक्शन बनाइए जो तीन बातें लेता है: क्या Pac-Man सारे बिंदु खा चुका है, क्या उसका कोई पावर पेलेट सक्रिय है, और क्या वह किसी भूत को छू रहा है। फिर यह बूलियन वैल्यू लौटाता है कि Pac-Man जीतता है या नहीं। फंक्शन को `true` तभी लौटाना चाहिए जब Pac-Man सारे बिंदु खा चुका हो और भाग 3 में दिए गए आर्गुमेंट के आधार पर हारा न हो।

```lua
rules.win(false, true, false)
-- => false
```
