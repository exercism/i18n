# परिचय

## बूलियन

PowerShell में [`bool`][booleans] टाइप होता है, जो सही और गलत वैल्यू दर्शाता है।
इस टाइप में केवल दो वैल्यू होती हैं: `True` और `False`।
आप इन वैल्यू को `$` प्रीफिक्स के साथ वेरिएबल में बाँध सकते हैं:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

हम `-and`, `-or` और `-not` जैसे [लॉजिकल ऑपरेटर][logical-operators] की मदद से बूलियन एक्सप्रेशन जोड़ सकते हैं और उनका मूल्यांकन कर सकते हैं।

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## रूपांतरण और सत्यता

PowerShell किसी भी टाइप को अपने आप बूलियन की तरह मान सकता है।
लेकिन आप स्पष्ट रूपांतरण के लिए बूलियन टाइप एक्सेलरेटर `[bool]` का भी उपयोग कर सकते हैं।

यहाँ कुछ सामान्य नियम दिए गए हैं, जिनका उपयोग PowerShell दूसरे टाइप को बूलियन वैल्यू में बदलने के लिए करता है:

$false:
- खाली स्ट्रिंग जैसे `''` या `""`
- `$null` जैसी नल वैल्यू
- शून्य (0) वैल्यू वाला न्यूमेरिक टाइप

$true:
- वे स्ट्रिंग जो खाली नहीं हैं
- किसी भी अन्य नॉन-कलेक्शन टाइप के इंस्टेंस

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

कलेक्शन टाइप से बूलियन वैल्यू में रूपांतरण के विस्तृत नियमों के लिए [यहाँ][collection-conversion] पढ़िए।
