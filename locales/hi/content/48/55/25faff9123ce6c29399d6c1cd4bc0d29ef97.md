# निर्देश

आप केप क्रोज़ियर प्रकाशस्तंभ के रखवाले हैं। लालटेन कक्ष से आप हर उस जहाज़ को दर्ज करते हैं जो वहाँ से गुज़रता है। हर जहाज़ की पहचान उसके अपने कॉलसाइन से होती है। इसके अलावा आप तट पर ऊपर-नीचे बने दूसरे प्रकाशस्तंभों के साथ सिग्नल रिले का समन्वय भी करते हैं।

## 1. एक नई लॉगबुक

`empty-log` को परिभाषित कीजिए, जो कॉलसाइन जमा करने के लिए तैयार एक नई, खाली हैश-सेट लौटाता है।

```factor
empty-log .
! => HS{ }
```

## 2. दिखाई देने की प्रविष्टि दर्ज कीजिए

`sight` को परिभाषित कीजिए, जो एक लॉगबुक और एक कॉलसाइन लेता है और उस दिखाई देने की प्रविष्टि को उसी लॉगबुक में दर्ज कर देता है। कुछ नहीं लौटाता।

```factor
empty-log dup "NS-1024" sight .
! => HS{ "NS-1024" }
```

## 3. क्या हमने इसे पहले देखा है?

`seen?` को परिभाषित कीजिए, जो एक लॉगबुक और एक कॉलसाइन लेता है और अगर वह कॉलसाइन दर्ज हो चुका है तो `t` लौटाता है, वरना `f`।

```factor
HS{ "NS-1024" "WB-203" } "NS-1024" seen? .   ! => t
HS{ "NS-1024" "WB-203" } "X-99"    seen? .   ! => f
```

## 4. दिखाई देने की प्रविष्टि भुला दीजिए

`forget-sighting` को परिभाषित कीजिए, जो एक लॉगबुक और एक कॉलसाइन लेता है और उसी लॉगबुक में से वह कॉलसाइन हटा देता है। कुछ नहीं लौटाता। अगर वह कॉलसाइन वहाँ नहीं है, तो कुछ न कीजिए।

```factor
HS{ "NS-1024" "WB-203" } clone dup "WB-203" forget-sighting .
! => HS{ "NS-1024" }
```

## 5. कितने अलग-अलग जहाज़ हैं?

`unique-count` को परिभाषित कीजिए, जो लॉग में मौजूद अलग-अलग कॉलसाइन की संख्या लौटाता है।

```factor
HS{ "NS-1024" "WB-203" "AC-77" } unique-count .   ! => 3
empty-log unique-count .                          ! => 0
```

## 6. पहुँच में आने वाले प्रकाशस्तंभ

तटरक्षक बल एक `relay-map` रखता है। यह एक हैशटेबल है जिसमें प्रकाशस्तंभों के नाम कुंजी होते हैं, और हर नाम के सामने उन प्रकाशस्तंभों का एक ऐरे होता है जिन तक वह प्रकाशस्तंभ सीधे रिले भेज सकता है।

`reachable` को परिभाषित कीजिए, जो एक `start` प्रकाशस्तंभ और एक `relay-map` लेता है, और बार-बार रिले करने पर `start` से पहुँच में आने वाले हर प्रकाशस्तंभ का हैश-सेट लौटाता है, जिसमें `start` खुद भी शामिल है।

```factor
H{
    { "Crozier"  { "Beacon"  "Hadley"  } }
    { "Beacon"   { "Crozier" "Spiral"  } }
    { "Hadley"   { "Crozier"           } }
    { "Spiral"   { "Beacon"  "Outpost" } }
    { "Outpost"  { "Spiral"            } }
    { "Far-Isle" { "Lonely"            } }
    { "Lonely"   { "Far-Isle"          } }
}
"Crozier" swap reachable .
! => HS{ "Crozier" "Beacon" "Hadley" "Spiral" "Outpost" }
```

`Far-Isle` और `Lonely` की जोड़ी अपना एक अलग जुड़ा हुआ समूह बनाती है, इसलिए नतीजे में इनमें से कोई भी नहीं आता।
