# टेस्ट

डिपेंडेंसी इंस्टॉल कीजिए।

```sh
dart pub get
```

टेस्ट चलाइए।

```sh
dart test
```

हर टेस्ट का ज़्यादा विस्तृत आउटपुट देखने के लिए एक्सपैंडेड रिपोर्टर इस्तेमाल कीजिए।

```sh
dart test -r expanded
```

ज़्यादातर अभ्यासों में कई टेस्ट होते हैं। इनमें से पहले वाले को छोड़कर बाकी सब डिफॉल्ट रूप से स्किप रहते हैं। टेस्ट एक-एक करके पूरे करने के लिए हर टेस्ट में `skip: true` को `skip: false` करते जाइए।

या फिर, फाइल को बदले बिना सारे टेस्ट एक साथ चलाइए।

```sh
dart test --run-skipped
```

जमा करने पर ऑनलाइन टेस्ट रनर सभी टेस्ट चलाता है, स्किप किए गए टेस्ट भी।
