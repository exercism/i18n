# परिचय

[`Rational numbers`][rational] ऐसी भिन्न होती हैं जिनका अंश और हर दोनों पूर्णांक होते हैं।

उदाहरण के लिए, हम `2//3` को अनुमानित `Float64` वैल्यू `0.6666...` के बजाय एक सटीक भिन्न के रूप में रख सकते हैं।

इसका फायदा यह है कि परिमेय संख्या सटीक बनी रहती है और फ्लोटिंग-पॉइंट संख्याओं के साथ अक्सर आने वाली राउंडिंग एरर से बच जाती है। इसका एकमात्र अपवाद [पूर्णांक ओवरफलो][integer-overflow] जैसी चरम स्थिति है।

Julia के [मैनुअल पेज][julia-rational] में कुछ और जानकारी दी गई है।

परिमेय संख्याएँ काफी सरल संख्या टाइप हैं और ठीक वैसा ही व्यवहार करती हैं जैसा आप उम्मीद करेंगे।
चूँकि शुरुआती वर्शन से ही ये Julia में एक मानक टाइप रही हैं, अधिकांश फंक्शन इन्हें पूर्णांकों और फ्लोट की तरह ही इनपुट के रूप में स्वीकार कर लेते हैं।

## परिमेय संख्याएँ बनाना

इन्हें बनाना बहुत आसान है: बस दो पूर्णांकों के बीच `//` लगाइए।

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

सामान्य गुणनखंड अपने आप हट जाते हैं और भिन्न अपने ["न्यूनतम रूप"][lowest-terms] में बदल जाती है: यानी वे सबसे छोटे पूर्णांक जो उस भिन्न को सटीक रूप से दर्शाते हैं, और जिनका हर ऋणात्मक नहीं होता।

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

अनंत परिणाम स्वीकार किए जाते हैं, लेकिन [`NaN`][NaN] नहीं।

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## परिमेय संख्याओं के साथ अंकगणित

सामान्य [`arithmetic operators`][operators] `+ - * / ^ %` परिमेय संख्याओं के साथ लगभग उसी तरह काम करते हैं जैसे बाकी संख्या टाइप के साथ करते हैं।

पूर्णांक और दूसरी `Rational` संख्याएँ भी शामिल की जा सकती हैं, और परिणाम `Rational` ही आता है।
एक्सप्रेशन में `float` शामिल करने पर आउटपुट `float` आता है, जिससे सटीकता में (संभवतः) कमी आ सकती है।

अगर `float` चाहिए, तो परिमेय संख्या को बदलने के लिए बस `float()` फंक्शन इस्तेमाल कीजिए।
लंबी गणना के दौरान सटीकता बनाए रखने के लिए परिमेय संख्याओं का उपयोग करना और अंत में उन्हें float में बदल देना बिलकुल सामान्य बात है।

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

परिमेय संख्याओं को [सम्मिश्र संख्याओं][complex] के साथ भी मिलाया जा सकता है।
सम्मिश्र संख्याओं पर [एक अलग कॉन्सेप्ट][complex-concept] में चर्चा की गई है।

## अन्य ऑपरेशन

Julia में परिमेय संख्याएँ बस संख्याएँ ही होती हैं।
कंपाइलर ज़रूरत पड़ने पर सामान्यतः टाइप अपने आप बदल देता है।

लेकिन ध्यान रखिए कि तुलना केवल उन भिन्नों के साथ ही सही बैठती है जिनका दशमलव रूप सीमित होता है:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

इसके अलावा, तुलना के लिए `Rational` को `Float` में बदलना चाहिए:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

गणितीय फंक्शन परिमेय संख्याएँ इनपुट के रूप में लेते हैं, लेकिन परिणाम फ्लोटिंग-पॉइंट में भी दे सकते हैं:

```julia-repl
julia> sqrt(9//16)
0.75
```
