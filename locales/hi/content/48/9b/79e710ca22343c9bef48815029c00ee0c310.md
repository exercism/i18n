# परिचय

## एरो फंक्शन

फंक्शन डिक्लेरेशन और फंक्शन एक्सप्रेशन के अलावा JavaScript में फंक्शन बनाने का एक और बहुत संक्षिप्त तरीका भी होता है।
ऐसे फंक्शन को _एरो फंक्शन_ कहते हैं।

यहाँ एक फंक्शन डिक्लेरेशन और एक एरो फंक्शन की तुलना दी गई है।

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

अगर फंक्शन बॉडी में सिर्फ एक रिटर्न स्टेटमेंट हो, जैसा ऊपर के उदाहरण में है, तो `{}` और `return` कीवर्ड छोड़े जा सकते हैं।
अगर सिर्फ एक पैरामीटर हो, तो ब्रैकेट `()` भी छोड़े जा सकते हैं।

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

एरो फंक्शन का उपयोग अक्सर फंक्शन कॉल के अंदर ही छोटे कॉलबैक फंक्शन बनाने के लिए किया जाता है।

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## ऐरे का विश्लेषण

[ऐरे][arrays-concept] में ऐरे की सामग्री का विश्लेषण करने के लिए पहले से मौजूद मेथड होते हैं।
इनमें से ज़्यादातर मेथड एक ऐसा फंक्शन आर्गुमेंट के रूप में लेते हैं जो सही या गलत लौटाता है।
ऐसे फंक्शन को [`predicate`][predicate_in_programming] कहते हैं।

ये पहले से मौजूद मेथड _`for` लूप_ या पहले से मौजूद `forEach` मेथड की जगह इस्तेमाल करने के लिए बने हैं:

for लूप का उपयोग करके विश्लेषण का उदाहरण:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

पहले से मौजूद मेथड का उपयोग करके विश्लेषण का उदाहरण:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

ऐरे का विश्लेषण करने के लिए उपलब्ध कुछ और उपयोगी पहले से मौजूद मेथड नीचे दिए गए हैं।
ऐरे के सभी मेथड की पूरी सूची के लिए [MDN][mdn-array-methods] देखिए।

### `includes`

`includes(value)` मेथड यह तय करता है कि ऐरे में कोई खास वैल्यू मौजूद है या नहीं।
अगर वैल्यू मौजूद हो तो यह `true` लौटाता है, वरना `false`।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

`every(predicate)` मेथड एक ऐसा फंक्शन लेता है जो _एक प्रेडिकेट_ होता है।
यह जाँचता है कि ऐरे के सारे एलिमेंट प्रेडिकेट को दिए जाने पर `true` लौटाते हैं या नहीं।
दूसरे शब्दों में: यह मेथड जाँचता है कि उसके सारे एलिमेंट उस जाँच में पास होते हैं जो फंक्शन कॉल को दी गई थी।
जब हर एलिमेंट प्रेडिकेट की जाँच में पास होता है तो यह `true` लौटाता है, वरना `false`।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

`some(predicate)` मेथड `every` मेथड जैसा ही है, लेकिन यह `true` लौटाता है अगर ऐरे में कम से कम एक एलिमेंट _प्रेडिकेट_ की जाँच में पास हो।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

`find(predicate)` मेथड ऐरे के उस पहले एलिमेंट की वैल्यू लौटाता है जो `predicate` की जाँच में पास होता है।
जहाँ `some()` पास होने पर `true` लौटाता है, वहाँ `find()` ऐरे में मौजूद असली वैल्यू लौटाता है।
जब ऐरे का कोई भी एलिमेंट _प्रेडिकेट_ की जाँच में पास नहीं होता, तो यह मेथड `undefined` लौटाता है।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

`findIndex(predicate)` मेथड `find()` मेथड जैसा ही है, लेकिन यह `value` की जगह उस एलिमेंट का (पहला) _इंडेक्स_ लौटाता है जो _प्रेडिकेट_ की जाँच में पास होता है।
जब ऐरे का कोई भी एलिमेंट _प्रेडिकेट_ की जाँच में पास नहीं होता, तो यह मेथड `-1` लौटाता है।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
