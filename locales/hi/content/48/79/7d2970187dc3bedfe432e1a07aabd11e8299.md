# निर्देश

इस अभ्यास में आप हाई स्कूल के प्रेमी जोड़ों को सोशल मीडिया पर अपना प्यार जताने में मदद करेंगे, उनके नाम के शुरुआती अक्षरों वाला एक ASCII बॉक्स बनाकर:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. नाम का पहला अक्षर निकालिए

`HighSchoolSweetheart.first_letter/1` फंक्शन बनाइए। यह एक नाम लेता है और उसका पहला अक्षर लौटाता है। इसे नाम से सारी अनावश्यक खाली जगह भी हटा देनी चाहिए।

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. पहले अक्षर को इनिशियल के रूप में ढालिए

`HighSchoolSweetheart.initial/1` फंक्शन बनाइए। यह एक नाम लेता है और उसके पहले अक्षर को बड़े अक्षर में बदलकर, उसके बाद एक बिंदु लगाकर लौटाता है। ध्यान रहे कि आप पिछले चरण में बनाए गए `HighSchoolSweetheart.first_letter/1` का ही दोबारा उपयोग करें।

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. पूरे नाम को पहले नाम और अंतिम नाम में बाँटिए

`HighSchoolSweetheart.initials/1` फंक्शन बनाइए। यह एक पूरा नाम लेता है, जिसमें पहला नाम और अंतिम नाम एक खाली जगह से अलग किए होते हैं, और इनिशियल लौटाता है। ध्यान रहे कि आप पिछले चरण में बनाए गए `HighSchoolSweetheart.initial/1` का ही दोबारा उपयोग करें।

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. इनिशियल को ASCII बॉक्स के अंदर रखिए

`HighSchoolSweetheart.pair/2` फंक्शन बनाइए। यह दो पूरे नाम लेता है और इनिशियल को एक ASCII बॉक्स के अंदर लौटाता है। आपको बॉक्स खुद बनाने की ज़रूरत नहीं है, कोड कमेंट में दिए गए बॉक्स का उपयोग कीजिए। ध्यान रहे कि आप पिछले चरण में बनाए गए `HighSchoolSweetheart.initials/1` का ही दोबारा उपयोग करें।

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
