# परिचय

Gleam में डिक्शनरी एक डेटा स्ट्रक्चर है जिसमें जानकारी की-वैल्यू जोड़ों में संग्रहीत की जाती है। अन्य भाषाओं में इन्हें असोसिएटिव ऐरे, हैश या डिक्शनरी भी कहा जाता है।

किसी भी टाइप का उपयोग डिक्शनरी में की और वैल्यू के लिए किया जा सकता है, और जब उन्हें एक्सेस किया जाता है या लौटाया जाता है तो वे अपनी प्रविष्टियों का क्रम सुनिश्चित नहीं करते।

## डिक्शनरी के साथ काम करना

डिक्शनरी बनाने और उन्हें संचालित करने के लिए `gleam/dict` मॉड्यूल के फंक्शनों का उपयोग किया जाता है।

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
