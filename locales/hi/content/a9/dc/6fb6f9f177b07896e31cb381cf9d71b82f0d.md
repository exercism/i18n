# निर्देश परिशिष्ट

## प्रोजेक्ट संरचना

Exercism में Clojure के अभ्यास आपका कोड कॉन्फिगर करने और चलाने के लिए [leiningen](http://leiningen.org/) का इस्तेमाल करते हैं। ये अभ्यास [leiningen की मानक डायरेक्टरी संरचना](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout) का पालन करते हैं।

`test` डायरेक्टरी के अंदर आपको `hello_world_test.clj` नाम की एक टेस्ट फाइल मिलेगी।
अपना कोड `src/hello_world.clj` में लिखिए। उसे `hello-world` नेमस्पेस इस्तेमाल करना चाहिए ताकि टेस्ट उसे पहचान सकें।

## टेस्ट चलाना

`lein test` कमांड से टेस्ट चलाइए और उन्हें पास कराइए:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

इसके बाद अभ्यास सबमिट करने के लिए यह कमांड चलाइए:

```
$ exercism submit src/hello_world.clj
```

अधिक विस्तृत निर्देशों और सीखने के संसाधनों के लिए [Exercism के Clojure भाषा पेज](http://exercism.io/languages/clojure) देखिए।
