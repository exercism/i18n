# इसके बारे में

[स्ट्रक्चर][structs-and-classes] (जिन्हें आमतौर पर *स्ट्रक्ट* कहा जाता है) Swift प्रोग्राम की बुनियादी इकाइयों में से एक हैं। स्ट्रक्ट की मदद से आप अपने कस्टम टाइप बना सकते हैं, जिनमें जुड़ी हुई प्रॉपर्टी (डेटा) और मेथड (व्यवहार) एक साथ रखे जाते हैं। दरअसल, Swift के स्टैंडर्ड टाइप, जैसे `Int`, `Double`, `Bool`, `String`, `Array` और `Dictionary`, सभी स्ट्रक्ट के रूप में बनाए गए हैं।

## स्ट्रक्ट बनाना

स्ट्रक्ट बनाने के लिए `struct` कीवर्ड लिखिए, उसके बाद टाइप का नाम और उसकी परिभाषा रखने वाले घुंघराले ब्रैकेट लगाइए। Swift के कन्वेंशन के मुताबिक, स्ट्रक्ट के नाम `UpperCamelCase` में लिखे जाते हैं:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## इंस्टेंस बनाना

स्ट्रक्ट की परिभाषा एक खाका होती है। किसी स्ट्रक्ट का *इंस्टेंस* बनाने के लिए उसका इनिशियलाइज़र कॉल कीजिए। इसके लिए टाइप का नाम लिखिए और उसके बाद गोल ब्रैकेट लगाइए:

```swift
var someStats = CharacterStats()
```

इससे एक इंस्टेंस बनता है, जिसमें परिभाषा में दी गई डिफ़ॉल्ट प्रॉपर्टी वैल्यू भरी होती हैं।

Swift स्ट्रक्ट के लिए एक अपने-आप **मेंबरवाइज़ इनिशियलाइज़र** भी बनाता है, जिससे आप प्रॉपर्टी को नाम से इनिशियलाइज़ कर सकते हैं:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## प्रॉपर्टी पढ़ना और बदलना

आप किसी इंस्टेंस की प्रॉपर्टी को *डॉट नोटेशन* की मदद से पढ़ते और बदलते हैं:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

चूँकि स्ट्रक्ट वैल्यू टाइप होते हैं, किसी इंस्टेंस की प्रॉपर्टी बदलने के लिए ज़रूरी है कि इंस्टेंस खुद `var` से घोषित हो। अगर इंस्टेंस `let` से घोषित है, तो उसकी सभी प्रॉपर्टी अपरिवर्तनीय हो जाती हैं।
