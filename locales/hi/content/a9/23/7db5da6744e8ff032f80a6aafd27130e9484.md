# परिचय

## ऐरे

Ruby में **ऐरे** क्रम में रखे गए संग्रह होते हैं, जिनका इंडेक्स पूर्णांक होता है और जिनमें किसी भी तरह के ऑब्जेक्ट रखे जा सकते हैं।
ऐरे की इंडेक्सिंग `0` से शुरू होती है।
ऋणात्मक इंडेक्स को ऐरे के अंत के सापेक्ष माना जाता है। जैसे `-1` इंडेक्स ऐरे के अंतिम एलिमेंट को दिखाता है, `-2` अंत से ठीक पहले वाले एलिमेंट को, और इसी तरह आगे भी।

### ऐरे बनाना

ऐरे आम तौर पर `[]` नोटेशन से बनाए जाते हैं।
इनमें किसी भी तरह के ऑब्जेक्ट रखे जा सकते हैं।

```ruby
array = [1, "two", 3.0]
```

### एलिमेंट का संदर्भ

ऐरे के एलिमेंट उनके इंडेक्स की मदद से `#[]` मेथड से निकाले जा सकते हैं।
यह दिए गए इंडेक्स पर मौजूद एलिमेंट लौटाता है, या फिर शुरुआती इंडेक्स से शुरू होकर तय लंबाई तक चलने वाला सब-ऐरे लौटाता है।
ऋणात्मक इंडेक्स ऐरे के अंत से पीछे की ओर गिने जाते हैं।

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### सहायक मेथड

ऐरे पर बहुत से काम के सहायक मेथड होते हैं।
यहाँ कुछ ज़्यादा आम मेथड दिए गए हैं:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## एन्यूमरेशन

संग्रहों पर एक-एक करके चलने के लिए लूप इस्तेमाल करने के बजाय Ruby में हम एन्यूमरेशन का उपयोग करते हैं।

एन्यूमरेशन का मतलब है किसी संग्रह (यहाँ ऐरे) पर एक-एक करके आगे बढ़ना और हर ऑब्जेक्ट पर कोई काम करना।  एन्यूमरेशन Ruby की एक महत्वपूर्ण अवधारणा है और इसका इस्तेमाल छाँटने, समूह बनाने, मैप करने, घटाने और बहुत कुछ करने में होता है।

ऐरे के हर शब्द को प्रिंट करने वाला एन्यूमरेशन कुछ ऐसा दिखेगा:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

इस उदाहरण में हमने अपने ऐरे पर `.each` मेथड कॉल किया है और उसमें एक _ब्लॉक_ पास किया है, जो एक पैरामीटर (`word`) लेता है और उसे प्रिंट कर देता है।

_ब्लॉक_ को हम ट्रैक में आगे और विस्तार से देखेंगे, लेकिन फिलहाल इन्हें ऐसे फंक्शन मानिए जिनका कोई नाम नहीं होता और जो शून्य या ज़्यादा आर्गुमेंट ले सकते हैं।
इन्हें `do...end` सिंटैक्स (ऊपर) या `{}` सिंटैक्स (नीचे) से बनाया जा सकता है।

यहाँ ब्लॉक इस्तेमाल करने वाले कुछ और ऐरे मेथड के उदाहरण दिए गए हैं:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
