# परिचय

`use` मैक्रो की मदद से हम अपने मॉड्यूल में किसी दूसरे मॉड्यूल की कार्यक्षमता बहुत जल्दी जोड़ सकते हैं। जब हम किसी मॉड्यूल का `use` करते हैं, तो वह मॉड्यूल हमारे मॉड्यूल में कोड डाल सकता है। उदाहरण के लिए, वह फंक्शन बना सकता है, दूसरे मॉड्यूल को `import` या `alias` कर सकता है, या मॉड्यूल एट्रिब्यूट तय कर सकता है।

अगर आपने यहाँ Exercism पर Elixir के कुछ अभ्यासों की टेस्ट फाइलें कभी देखी हैं, तो आपने ज़रूर देखा होगा कि वे सभी `use ExUnit.Case` से शुरू होती हैं। कोड की यह एक ही लाइन टेस्ट मॉड्यूल में `test` और `assert` मैक्रो को उपलब्ध कराती है।

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## `__using__/1` मैक्रो

जब आप किसी मॉड्यूल का `use` करते हैं, तो ठीक-ठीक क्या होता है, यह उस मॉड्यूल का `__using__/1` मैक्रो तय करता है। यह एक आर्गुमेंट लेता है, जो विकल्पों वाली एक कीवर्ड ऐरे होती है, और यह एक [क्वोटेड एक्सप्रेशन][concept-ast] लौटाता है। जब `use` कॉल किया जाता है, तब इस क्वोटेड एक्सप्रेशन का कोड हमारे मॉड्यूल में डाल दिया जाता है।

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

विकल्पों को `use` कॉल करते समय दूसरे आर्गुमेंट के रूप में दिया जा सकता है, जैसे `use ExUnit.Case, async: true`. जब वे स्पष्ट रूप से नहीं दिए जाते, तो उनका डिफ़ॉल्ट एक खाली ऐरे होता है।

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
