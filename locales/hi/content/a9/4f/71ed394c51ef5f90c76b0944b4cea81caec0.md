# परिचय

`switch()` फंक्शन `if` ... `else if` वाली लंबी जाँचों की शृंखला की जगह एक संक्षिप्त विकल्प हो सकता है।

जिस वेरिएबल पर `switch` लगाया जाता है वह आमतौर पर एक स्ट्रिंग होता है, और ऐसा होने पर सिलेक्टर में कोटेशन चिह्न लगाने की ज़रूरत नहीं होती।

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

ध्यान दीजिए कि कोई विकल्प अगले विकल्प तक तभी पहुँचता है जब उसकी वैल्यू खाली छोड़ी गई हो, जैसा ऊपर के उदाहरण में `M` के साथ है।
कुछ अन्य भाषाओं की तरह यहाँ `break` स्टेटमेंट लगाने की ज़रूरत नहीं होती।

`character` टाइप पर `switch` लगाने पर अंतिम वैल्यू एक डिफ़ॉल्ट होती है, जैसा यहाँ है।
पूर्णांक टाइप के साथ कोई डिफ़ॉल्ट नहीं दिया जा सकता।

## `dplyr` में फंक्शन

बेस R में `switch` काफी सीमित है: यह सिर्फ एक ही इनपुट से ठीक-ठीक मैच करता है।
1993 में जब R पहली बार जारी हुआ था तब यह ठीक लगता था, लेकिन आज के इस्तेमाल के लिए इसमें सुधार की ज़रूरत है।

~~~~exercism/note
जैसा कि [`Conditionals`][concept-conditionals] कॉन्सेप्ट में बताया गया था, `tidyverse` पैकेजों का संग्रह बेस R की कार्यक्षमता को बढ़ाने के लिए बनाया गया है (और कभी-कभी उसे बदल भी देता है), बिना बैकवर्ड कंपैटिबिलिटी को प्रभावित किए।

आप `dplyr` पैकेज को स्कोप में ला सकते हैं, इसके लिए अपने कोड के सबसे ऊपर `library(dplyr)` या `library(tidyverse)` जोड़िए, पहला सिर्फ इसी पैकेज के लिए और दूसरा पूरे संग्रह के लिए।

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

`dplyr` लाइब्रेरी `switch` से जुड़े दो अतिरिक्त फंक्शन देती है।

### `recode_values` और `replace_values` फंक्शन

ये दोनों जुड़े फंक्शन पुरानी वैल्यूओं को नई वैल्यूओं पर मैप करने का वेक्टराइज़्ड, `switch` जैसा तरीका देते हैं।

इन दोनों में मुख्य अंतर यह है कि `recode_values()` एक बिल्कुल नया वेक्टर बनाता है, जबकि `replace_values()` किसी मौजूदा वेक्टर को आंशिक रूप से अपडेट करने देता है।

मैचिंग अब भी ठीक-ठीक ही होती है, लेकिन:

- बाईं ओर के विकल्प वेक्टर हो सकते हैं, और इनपुट तब मैच होता है जब उसका कोई भी एलिमेंट मैच करे।
- बाईं ओर के विकल्प और दाईं ओर के परिणाम `=` के बजाय टिल्ड `~` से जुड़े होते हैं।
- हर स्थिति में एक डिफ़ॉल्ट दिया जा सकता है।

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when` फंक्शन

`case_when` `case_match` के सिंटैक्स को एक कदम आगे ले जाता है, क्योंकि यह `~` के बाईं ओर किसी भी लॉजिकल एक्सप्रेशन की अनुमति देता है।

इनपुट वेक्टर (नीचे के उदाहरण में `x`) को आर्गुमेंट के रूप में नहीं दिया जाता, बल्कि वह पहले से बना हुआ होना चाहिए।

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()` फंक्शन भी `dplyr` का ही हिस्सा है।
