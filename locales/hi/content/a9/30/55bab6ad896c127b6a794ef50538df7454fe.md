# परिचय

Haxe में इटरेटर का उपयोग `for` लूप की मदद से किसी वैल्यू पर इटरेशन करने के लिए किया जाता है। इटरेटर दो तरह के होते हैं:

- `Iterator`, जो किसी वैल्यू पर इटरेशन करता है।
- `Iterable` डेटा, जिससे किसी डेटा टाइप पर इटरेशन करना संभव हो जाता है।

इन दोनों कॉन्सेप्ट को `Iterator<T>` और `Iterable<T>` से दर्शाया जाता है:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

कोई भी क्लास जो इनमें से किसी एक टाइप से मेल खाती है, उस पर `for` लूप की मदद से इटरेशन किया जा सकता है। अगर कोई क्लास `hasNext` और `next` मेथड बनाती है, तो उसे इटरेटर माना जाता है। वरना, अगर वह `iterator` मेथड बनाती है, तो उसे इटरेबल टाइप माना जाता है:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

ऊपर के उदाहरण में क्लास `MyStringIterator` को इटरेटर माना गया है, क्योंकि यह `hasNext` और `next` दोनों मेथड लागू करती है, जिससे यह `Iterator<String>` के अनुरूप हो जाती है।

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

यहाँ क्लास `MyArrayWrap` को इटरेबल डेटा टाइप माना गया है, क्योंकि यह `Iterable<Array<T>>` के अनुरूप है।
