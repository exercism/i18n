# परिचय

लूप एक ऐसा तरीका है जिसमें एक या अधिक स्टेटमेंट को एक समूह में बार-बार चलाया जाता है। स्टेटमेंट के समूह को हर बार चलाने को इटरेशन कहते हैं।

## while लूप

`while` लूप स्टेटमेंट के एक समूह को तब तक चलाता है जब तक लूप के ऊपर लिखा बूलियन एक्सप्रेशन सही रहता है। जब बूलियन एक्सप्रेशन गलत हो जाता है, तो लूप चलना बंद कर देता है। इसके बाद कोड लूप के बाद वाली अगली लाइन से आगे चलने लगता है।

अगर बूलियन एक्सप्रेशन शुरू से ही गलत हो, तो `while` लूप एक बार भी नहीं चलेगा और कोड सीधे लूप के बाद वाली अगली लाइन से आगे चलने लगेगा।

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

लूप को खत्म करने के लिए एक शर्त का होना ज़रूरी है, वरना यह अनंत लूप बन जाता है जो कोड को पूरी तरह आगे बढ़ने से रोक देगा। अगर ऊपर दिए कोड में से `i` के बाद वाला `++` हटा दिया जाए, तो यह अनंत लूप बन जाएगा।

## do लूप

`do` लूप में बूलियन एक्सप्रेशन की जाँच लूप के नीचे की जाती है। `do` लूप हमेशा कम से कम एक बार चलता है, जैसा कि नीचे दिए उदाहरण में है।

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

`while` लूप के साथ यही काम ज़्यादा लंबे कोड में होता है

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## for लूप

अक्सर लूप किसी वेरिएबल की वैल्यू बदलता रहता है और तब खत्म होता है जब वेरिएबल कोई तय वैल्यू तक पहुँच जाता है। `for` लूप एक ऐसा तरीका है जिसमें कोष्ठक के अंदर एक ही लाइन में एक या अधिक वेरिएबलो को शुरू किया जाता है, बदला जाता है और जाँचा जाता है। पहला भाग वेरिएबल को शुरू करने के लिए है, दूसरा भाग वेरिएबल की जाँच करने के लिए, और तीसरा भाग वेरिएबल की वैल्यू बदलने के लिए।

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

यह अपने `while` लूप वाले रूप से कम लंबा है, फिर भी पढ़ने में आसान है।

`for` लूप के शुरू करने और बदलने वाले भाग, कॉमा ऑपरेटर की मदद से शर्तों के अंदर एक्सप्रेशन को अलग-अलग करके, एक से अधिक वेरिएबलो को संभाल सकते हैं।

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

इससे यह प्रिंट होगा

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

`for` के किसी भी भाग को लिखना ज़रूरी नहीं है। खाली जाँच वाला एक्सप्रेशन सही निकलता है, इसलिए `for` लूप से अनंत लूप भी बनाया जा सकता है, जैसे:

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

यह `while` लूप जैसा ही है, क्योंकि इसमें `i` को लूप से पहले शुरू किया जाता है और लूप के अंदर बढ़ाया जाता है। साथ ही, `i` की जाँच लूप के अंदर होती है और लूप `break` स्टेटमेंट से खत्म हो जाता है।

## break स्टेटमेंट

कभी-कभी लूप को किसी ऐसी खास शर्त पर खत्म करना पड़ सकता है जिसकी जाँच उसके बूलियन एक्सप्रेशन में नहीं होती। `break` स्टेटमेंट लूप को खत्म कर देता है और कोड लूप के बाद वाली अगली लाइन से आगे चलने लगता है।

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

इससे यह प्रिंट होगा

```
i is 0
j is 5
After the loop
```

## continue स्टेटमेंट

कभी-कभी लूप को मौजूदा इटरेशन पूरा किए बिना अपना अगला इटरेशन शुरू करना पड़ सकता है। `continue` स्टेटमेंट मौजूदा इटरेशन को चलना रोक देता है और अगले इटरेशन की शुरुआत से चलना जारी रखता है।

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

इससे यह प्रिंट होगा

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

जब `i` और `j` दोनों `2` होते हैं, तो यह उनकी वैल्यू प्रिंट नहीं करता।
