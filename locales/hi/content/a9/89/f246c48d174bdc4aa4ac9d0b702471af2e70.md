# परिचय

## ट्यूपल

ट्यूपल बिना नाम की, लेकिन क्रम में रखी वैल्यू का एक _अपरिवर्तनीय_ समूह होता है। ट्यूपल में किसी भी डेटा टाइप की वैल्यू रखी जा सकती है, या एक साथ कई डेटा टाइप की भी। इनमें दूसरे ट्यूपल भी शामिल हो सकते हैं।

ट्यूपल को `(` और `)` के बीच कॉमा से अलग की गई वैल्यू के रूप में लिखा जाता है: `(<element_1>, ... , <element_n>)`।

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

सिर्फ एक ही लंबाई और एक ही टाइप (उसी क्रम में) वाले ट्यूपल की ही तुलना की जा सकती है। ट्यूपल में संरचनात्मक समानता होती है, यानी वे _सिर्फ_ तभी बराबर होते हैं जब उनकी सारी वैल्यू बराबर हों।

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

किसी ट्यूपल से वैल्यू निकालने के तीन तरीके हैं:

- `fst` और `snd` फंक्शन
- ट्यूपल डिकंस्ट्रक्शन
- पैटर्न मैचिंग

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
