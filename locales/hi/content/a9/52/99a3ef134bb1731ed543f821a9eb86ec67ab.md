# परिचय

`|>` ऑपरेटर को पाइप ऑपरेटर कहा जाता है। इसका उपयोग फंक्शन कॉल को इस तरह एक के बाद एक जोड़ने के लिए किया जा सकता है कि पिछले फंक्शन कॉल से लौटाई गई वैल्यू अगले फंक्शन कॉल को दी जाती है।

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

ऊपर दिया गया कोड इसके बराबर है:

```gleam
string.append(string.uppercase("hello"), "?!")
```

पाइप ऑपरेटर वैल्यू को या तो फंक्शन कॉल के पहले आर्गुमेंट के रूप में भेजता है, या नई कॉल के एकमात्र आर्गुमेंट के रूप में। यह उसी रूप को चुनता है जिसमें टाइप सही बैठता है।

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

कभी-कभी हमें वैल्यू को किसी और जगह भेजनी होती है। ऐसे में `_` प्लेसहोल्डर का उपयोग यह बताने के लिए किया जा सकता है कि वैल्यू कहाँ डाली जानी चाहिए।

```gleam
100
|> some_function(1, _, 2)
```
