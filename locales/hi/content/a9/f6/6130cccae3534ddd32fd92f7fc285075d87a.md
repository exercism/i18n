# परिचय

Elm भरोसेमंद वेब एप्लिकेशन बनाने के लिए एक आनंददायक भाषा है। इसमें एरर के संदेश बहुत मददगार होते हैं, प्रदर्शन बेहतरीन रहता है, एसेट छोटे बनते हैं, और रनटाइम एक्सेप्शन होते ही नहीं।

Elm का शायद सबसे प्रसिद्ध और सबसे ज़्यादा अपनाया गया हिस्सा एल्म आर्किटेक्चर है। यह वेब एप्लिकेशन को व्यवस्थित करने का एक आसान पैटर्न है, और Elm के सारे वेब एप्लिकेशन इसी तरह लिखे जाते हैं।

इसका मूल विचार यह है कि आपका कोड तीन चीज़ों के इर्द-गिर्द बना होता है: आपके एप्लिकेशन की स्थिति रखने वाला एक `Model`, अपने मॉडल को `update` करने का एक तरीका, और अपने मॉडल को `view` करने का एक तरीका।

`Model` में एप्लिकेशन की स्थिति रहती है, यानी वह सारा डेटा जो एप्लिकेशन को चाहिए।
सोचिए, एक सरल एप्लिकेशन है जिसमें एक टेक्स्ट बॉक्स है, और उसमें लिखे टेक्स्ट को उल्टा करके दिखाने वाला टेक्स्ट भी है। ऐसे एप्लिकेशन का मॉडल नीचे दिखाए अनुसार होगा।
यह उदाहरण आप [Elm Guide][elm-guide-text-fields] में भी देख सकते हैं।

```elm
type alias Model =
  { text : String
  }
```

`update` एक फंक्शन है, जिसे कोई बदलाव होने पर एक `Msg` के साथ कॉल किया जाता है (जैसे उपयोगकर्ता के किसी बटन पर क्लिक करने पर)।
यह `Msg` और मौजूदा `Model` लेता है, और एक नया `Model` लौटाता है।

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` एक फंक्शन है जो ब्राउज़र में उपयोगकर्ता को दिखाने के लिए HTML लौटाता है।
यह मौजूदा `Model` लेता है और एक `Html Msg` लौटाता है (यह वह टाइप है जिससे Elm HTML को दर्शाता है)।

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
