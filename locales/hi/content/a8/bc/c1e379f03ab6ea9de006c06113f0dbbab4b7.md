# rescue न कीजिए

फ्लो कंट्रोल के लिए एक्सेप्शन का उपयोग न कीजिए।
इस अभ्यास को `rescue` के बिना हल करने की कोशिश कीजिए।

अगर आप स्टैंडर्ड लाइब्रेरी के किसी ऐसे फंक्शन का उपयोग कर रहे हैं जिसके नाम के अंत में `!` है (यानी वह एरर उठाता है), तो उसके बराबर का कोई ऐसा फंक्शन ढूँढिए जिसमें `!` न हो (ऐसे फंक्शन अक्सर `{:ok, result}` या `{:error, message}` लौटाते हैं)।

ध्यान दीजिए: अगर आपको अपने हल पर यह स्वचालित कमेंट दिख रहा है, तो हो सकता है कि बाकी स्वचालित कमेंट सही न हों।
पहले इस समस्या को ठीक कीजिए!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
