# परिचय

किसी लॉजिक को बार-बार चलाने के लिए `for` लूप सबसे ज़्यादा इस्तेमाल किए जाने वाले स्टेटमेंट में से एक है। JavaScript में इसमें `for` कीवर्ड, गोल ब्रैकेट में लिखा एक _हेडर_ और कर्ली ब्रैकेट में लिखा एक कोड ब्लॉक होता है, जिसमें लूप की _बॉडी_ रहती है।

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

इनिशियलाइज़ेशन आम तौर पर एक काउंटर वेरिएबल तैयार करता है, शर्त जाँचती है कि लूप जारी रहना चाहिए या रुक जाना चाहिए, और स्टेप हर इटरेशन के अंत में काउंटर बढ़ाता है। हेडर के अलग-अलग हिस्से सेमीकोलन से अलग किए जाते हैं।

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

जैसा ऊपर के उदाहरण में दिखाया गया है, स्टेप बनाने के लिए अक्सर JavaScript के इंक्रीमेंट या डिक्रीमेंट ऑपरेटर इस्तेमाल किए जाते हैं। ये ऑपरेटर वेरिएबल को उसी जगह बदल देते हैं। `++` किसी संख्या में एक जोड़ता है, `--` किसी संख्या से एक घटाता है।

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
