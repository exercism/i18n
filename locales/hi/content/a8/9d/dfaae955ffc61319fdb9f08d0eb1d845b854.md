# निर्देश

आप एक नया और बहुत पसंद किए जाने वाला गेम **Wings Quest** बना रहे हैं।
इस गेम में आप एक पक्षी हैं, जो इधर-उधर घूमता है और बीज इकट्ठा करता है।
खिलाड़ी सारे बीज उठाकर जीत जाता है।
अगर खिलाड़ी किसी चील के संपर्क में आ जाता है, तो वह अपने सारे बीज खो देता है और गेम हार जाता है।
इस नियम का एक अपवाद है: खिलाड़ी के पास कोई सक्रिय पावर-अप हो सकता है, जिससे वह दूसरे पक्षियों से ऊँचा उड़ सकता है।

आपका उद्देश्य गेम में इस्तेमाल होने वाले कुछ नियम लिखना है।

## 1. तय कीजिए कि पक्षी को बोनस अंक मिलते हैं या नहीं

गेम में पक्षी को बोनस अंक तब मिलते हैं जब वह पावर-अप के साथ चील को छूता है।

फंक्शन `bonusPoints(powerUpActive:touchingEagle:)` बनाइए, जो दो आर्गुमेंट लेता है: `powerUpActive`, जिसमें यह रहता है कि पक्षी के पास सक्रिय पावर-अप है या नहीं, और आर्गुमेंट `touchingEagle`, जिसमें यह रहता है कि पक्षी चील को छू रहा है या नहीं।
यह फंक्शन `true` तभी लौटाना चाहिए जब पक्षी के पास सक्रिय पावर-अप हो और वह चील को छू रहा हो, और बाकी हालतों में `false`.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. तय कीजिए कि पक्षी को अंक मिलते हैं या नहीं

गेम में खिलाड़ी को बीज या पावर-अप उठाने पर अंक मिलते हैं।

फंक्शन `score(touchingPowerUp:touchingSeed:)` बनाइए, जो दो आर्गुमेंट लेता है: `touchingPowerUp`, जिसमें यह रहता है कि पक्षी पावर-अप को छू रहा है या नहीं, और आर्गुमेंट `touchingSeed`, जिसमें यह रहता है कि पक्षी बीज को छू रहा है या नहीं।
यह फंक्शन `true` तब लौटाना चाहिए जब पक्षी पावर-अप या बीज को छू रहा हो, और बाकी हालतों में `false`.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. तय कीजिए कि पक्षी हारता है या नहीं

फंक्शन `lose(powerUpActive:touchingEagle:)` बनाइए, जो दो आर्गुमेंट लेता है: `powerUpActive`, जिसमें यह रहता है कि पक्षी के पास सक्रिय पावर-अप है या नहीं, और आर्गुमेंट `touchingEagle`, जिसमें यह रहता है कि पक्षी चील को छू रहा है या नहीं।
यह फंक्शन `true` तब लौटाना चाहिए जब पात्र चील को छू रहा हो और उसके पास सक्रिय पावर-अप न हो, और बाकी हालतों में `false`.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. तय कीजिए कि पक्षी जीतता है या नहीं

फंक्शन `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` बनाइए, जो ये आर्गुमेंट लेता है:

- `hasPickedUpAllSeeds`: पक्षी ने सारे बीज उठा लिए हैं या नहीं।
- `powerUpActive`: पक्षी के पास सक्रिय पावर-अप है या नहीं।
- `touchingEagle`: पक्षी चील को छू रहा है या नहीं।

यह फंक्शन `true` तब लौटाना चाहिए जब पक्षी ने सारे बीज इकट्ठा कर लिए हों और भाग 3 में बताए गए आर्गुमेंट के हिसाब से वह हारा न हो, और बाकी हालतों में `false`.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
