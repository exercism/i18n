# परिचय

कॉन्स्टेंट ऐसी वैल्यू होती हैं जो कंपाइल के समय तय हो जाती हैं और दोबारा असाइन नहीं की जा सकतीं।
एक अकेला कॉन्स्टेंट घोषित करने के लिए `const` कीवर्ड का उपयोग कीजिए:

```go
const greeting = "hello"
```

एक ब्लॉक में कई कॉन्स्टेंट घोषित किए जा सकते हैं।
ब्लॉक के अंदर, जिस कॉन्स्टेंट की वैल्यू साफ़ तौर पर नहीं दी गई हो, वह पिछले एक्सप्रेशन को ही दोहराता है:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

कॉन्स्टेंट आमतौर पर पैकेज लेवल पर घोषित किए जाते हैं, हालाँकि इन्हें किसी फंक्शन के अंदर भी घोषित किया जा सकता है।

## टाइप वाले और बिना टाइप वाले कॉन्स्टेंट

किसी कॉन्स्टेंट को बिना टाइप बताए घोषित करने पर वह बिना टाइप वाला बन जाता है।
बिना टाइप वाले कॉन्स्टेंट का कोई तय टाइप नहीं होता; उसकी वैल्यू तय करती है कि वह किन टाइपों के साथ संगत है।
जब तक मूल वैल्यू संगत रहती है, कंपाइलर हर इस्तेमाल पर उसे ज़रूरी टाइप में बदल देता है:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

टाइप वाला कॉन्स्टेंट घोषित करते समय ही टाइप तय कर देता है:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## कॉन्स्टेंट क्या-क्या हो सकता है

कॉन्स्टेंट में सिर्फ बूलियन, संख्याएँ, स्ट्रिंग और रून रखे जा सकते हैं।
चूँकि वैल्यू कंपाइल के समय तय होती हैं, इसलिए फंक्शन कॉल के परिणाम का उपयोग कॉन्स्टेंट के लिए नहीं किया जा सकता।

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## आयोटा

कॉन्स्टेंट के एक ब्लॉक के अंदर `iota` उस कॉन्स्टेंट की ब्लॉक में स्थिति बताता है:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

पहले के बाद का हर कॉन्स्टेंट वही एक्सप्रेशन दोहराता है, और `iota` हर बार एक बढ़ जाता है।

`iota` एक्सप्रेशनों में भी काम करता है।

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```

Go में कॉन्स्टेंट पर गहराई से जानने के लिए [The Go Blog][const-blog] और [Effective Go][effective-go] देखिए।
