# परिचय

## मेथड के समूह के रूप में इंटरफेस

अपने सबसे सरल रूप में, **इंटरफेस टाइप** मेथड सिग्नेचर का एक समूह होता है।
यहाँ इंटरफेस की परिभाषा का एक उदाहरण है जिसमें दो मेथड `Add` और `Value` शामिल हैं:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

`increment` जैसे पैरामीटर के नाम इंटरफेस की परिभाषा से छोड़े जा सकते हैं, लेकिन अक्सर ये पढ़ने में आसानी बढ़ा देते हैं।

Go में इंटरफेस के नामों में `Interface` या `I` शब्द नहीं होता।
इसके बजाय, वे अक्सर `er` पर खत्म होते हैं, जैसे `Reader`, `Stringer`।

## इंटरफेस को लागू करना

कोई भी टाइप जो इंटरफेस के मेथड बनाता है, वह अपने आप इंटरफेस को लागू कर देता है।
Go में `implements` कीवर्ड नहीं होता।

नीचे दिया गया टाइप ऊपर दिखाए गए `Counter` इंटरफेस को लागू करता है।

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

इंटरफेस को लागू करने के लिए इससे कोई फर्क नहीं पड़ता कि मेथड में वैल्यू रिसीवर है या पॉइंटर रिसीवर।
(अगर आपको इनके बारे में संदेह है, तो [मेथड से जुड़ी अवधारणाएँ][concept-methods] दोबारा देखिए।)

> इंटरफेस टाइप की वैल्यू ऐसी कोई भी वैल्यू रख सकती है जो उन मेथड को लागू करती हो। ((Go Tour: Interfaces)[go-tour-interfaces])

इसका मतलब है कि अब `Stats` का इस्तेमाल उन सभी जगहों पर किया जा सकता है जहाँ `Counter` इंटरफेस की अपेक्षा होती है।

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

चूँकि इंटरफेस अंतर्निहित रूप से लागू होते हैं, एक टाइप आसानी से कई इंटरफेस लागू कर सकता है।
उसे बस सभी ज़रूरी मेथड बनाने होते हैं।

## खाली इंटरफेस

Go में एक बहुत खास इंटरफेस टाइप है, **खाली इंटरफेस** टाइप, जिसमें शून्य मेथड होते हैं।
खाली इंटरफेस ऐसे लिखा जाता है: `interface{}`.
Go 1.18 या उससे नए संस्करण में `any` का भी इस्तेमाल किया जा सकता है।
इसे एक एलियस के रूप में परिभाषित किया गया था।

चूँकि खाली इंटरफेस में कोई मेथड नहीं होते, हर टाइप इसे अंतर्निहित रूप से लागू करता है।
यह ऐसा फंक्शन बनाने में मददगार है जो सामान्य रूप से कोई भी वैल्यू स्वीकार कर सके।
उस स्थिति में, फंक्शन का पैरामीटर खाली इंटरफेस टाइप का इस्तेमाल करता है।
