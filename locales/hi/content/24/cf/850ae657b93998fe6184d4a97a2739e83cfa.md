# परिचय

डायनैमिक मेमोरी लाइब्रेरी फंक्शनो से लागू होती है, जिन्हें प्रोग्रामर रनटाइम पर मेमोरी आवंटित करने और मुक्त करने के लिए इस्तेमाल करता है।
चूँकि मेमोरी का आवंटन और मुक्त करना प्रोग्रामर के हाथ में होता है, डायनैमिक मेमोरी उतनी ही सुरक्षित रहती है जितना प्रोग्रामर मानवीय गलती से मुक्त हो।
इसीलिए डायनैमिक मेमोरी प्रोग्रामिंग बग का एक बड़ा स्रोत है और हैकिंग हमलों का भी बड़ा निशाना।

## malloc

`malloc`, `stdlib.h` में घोषित एक फंक्शन है, जिसका इस्तेमाल डायनैमिक मेमोरी आवंटित करने के लिए किया जाता है।
अगर आवंटन सफल होता है, तो एक पॉइंटर लौटाया जाता है, जो आवंटित मेमोरी के पहले बाइट के पते की ओर संकेत करता है।
अगर आवंटन सफल नहीं होता, तो `NULL` लौटाया जाता है।
`malloc` का परिणाम `NULL` है या नहीं, यह जाँच लेना समझदारी है। अगर वह विफल हो जाए, तो उसे भली-भाँति संभाल लीजिए।
लौटाया गया पॉइंटर `pointer-to-void` टाइप का होता है, जिसे मोटे तौर पर एक "जेनेरिक" पॉइंटर माना जा सकता है, जिसे मेमोरी के विशिष्ट टाइप में बदला जा सकता है।
`malloc` में एक पैरामीटर होता है, जो चाही गई मेमोरी का बाइट में आकार होता है।
किसी ऐरे को आवंटित करने के लिए कुल आकार, हर एलिमेंट के डेटा टाइप के आकार को एलिमेंटो की संख्या से गुणा करके निकाला जाता है।
हर एलिमेंट के डेटा टाइप का आकार पाने के लिए आमतौर पर `sizeof` ऑपरेटर का इस्तेमाल किया जाता है।
इसे नीचे दिया गया उदाहरण दिखाता है।

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

यह याद रखना ज़रूरी है कि `malloc` से नई आवंटित मेमोरी इनिशियलाइज़ नहीं होती, बल्कि उसमें कचरा वैल्यू पड़ी हो सकती हैं।
ध्यान दीजिए कि `numbers` पॉइंटर का `sizeof` न ऐरे के एलिमेंटो की संख्या है और न ही आवंटित कुल मेमोरी की मात्रा।
`malloc` से जो पॉइंटर लौटता है, उसका आकार उस विशेष सिस्टम पर किसी भी पॉइंटर के आकार जितना होता है।
उदाहरण का कोड 64-बिट सिस्टम पर चलाया गया था, इसलिए पॉइंटर का आकार 8 बाइट था (8 बिट प्रति बाइट से गुणा करने पर = 64 बिट)।
पॉइंटर का टाइप pointer-to-void से pointer-to-int में अपने आप बदल गया।
इसे साफ़-साफ़ ऐसे भी बदला जा सकता था: `int * numbers = (int *) malloc(sizeof(int) * count);`।
अगर वैल्यू को पढ़े जाने से पहले उसमें निश्चित रूप से लिखा जाएगा, तो मेमोरी आवंटित करने का `malloc` एक कुशल तरीका हो सकता है।
लेकिन अगर ऐसी कोई संभावना है कि वैल्यू इनिशियलाइज़ होने से पहले ही पढ़ ली जाएगी, तो `malloc` का इस्तेमाल जोखिम भरा है।
मेमोरी आवंटित करने का ज़्यादा सुरक्षित तरीका `calloc` है, जो नई आवंटित मेमोरी को शून्य से इनिशियलाइज़ कर देता है।

ऊपर के उदाहरणों में ध्यान दीजिए कि `free(numbers)` का इस्तेमाल किया गया था।

## free

`free`, `stdlib.h` में घोषित एक फंक्शन है, जिसका इस्तेमाल डायनैमिक रूप से आवंटित मेमोरी को मुक्त करने के लिए किया जाता है।
डायनैमिक रूप से आवंटित मेमोरी तब तक मेमोरी में कब्ज़े में रहती है जब तक `free` उसे छोड़ न दे।
कुछ ऑपरेटिंग सिस्टम प्रोग्राम खत्म होने पर डायनैमिक रूप से आवंटित मेमोरी अपने आप मुक्त कर देते हैं, लेकिन उस पर निर्भर न रहना ही सबसे अच्छा तरीका है।
`free` में एक पैरामीटर होता है, जो डायनैमिक रूप से आवंटित मेमोरी की ओर इशारा करने वाला पॉइंटर होता है।
जिस पॉइंटर को मुक्त करने के बाद `NULL` पर सेट नहीं किया जाता, उसे डैंगलिंग पॉइंटर कहा जाता है।
एक डैंगलिंग पॉइंटर उस मेमोरी के अलावा किसी और मेमोरी की ओर इशारा कर सकता है।
इस तरह एक डैंगलिंग पॉइंटर डेटा करप्शन और मनमाने कोड के प्रतिस्थापन और निष्पादन तक ले जा सकता है।
आवंटित मेमोरी वाला ऐसा पॉइंटर, जिसे `NULL` पर सेट करके साफ़ नहीं किया गया हो, प्रोग्राम को हैक करने के काम आ सकता है।
पॉइंटर को `free` को सौंपने के बाद उसे `NULL` पर सेट कर देना सबसे अच्छा तरीका है।

## calloc

`calloc`, `stdlib.h` में घोषित एक फंक्शन है, जिसका इस्तेमाल डायनैमिक मेमोरी आवंटित करने और नई आवंटित मेमोरी को शून्य से इनिशियलाइज़ करने, दोनों के लिए किया जाता है।
अगर आवंटन सफल होता है, तो एक पॉइंटर लौटाया जाता है, जो आवंटित मेमोरी के पहले बाइट के पते की ओर संकेत करता है।
अगर आवंटन सफल नहीं होता, तो `NULL` लौटाया जाता है।
`calloc` का परिणाम `NULL` है या नहीं, यह जाँच लेना समझदारी है। अगर वह विफल हो जाए, तो उसे भली-भाँति संभाल लीजिए।
लौटाया गया पॉइंटर `pointer-to-void` टाइप का होता है, जिसे मोटे तौर पर एक "जेनेरिक" पॉइंटर माना जा सकता है, जिसे मेमोरी के विशिष्ट टाइप में बदला जा सकता है।
`calloc` में दो पैरामीटर होते हैं।
पहला पैरामीटर बताता है कि निर्दिष्ट डेटा टाइप की कितनी मात्रा आवंटित करनी है।
दूसरा पैरामीटर बताता है कि आवंटित किए जाने वाले निर्दिष्ट डेटा टाइप का आकार कितना है।

नीचे दिए उदाहरण में सभी `printf` स्टेटमेंट हमेशा `0` दिखाएँगे, क्योंकि `calloc` नई आवंटित वैल्यू को शून्य करना सुनिश्चित करता है।

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc`, `stdlib.h` में घोषित एक फंक्शन है, जिसका इस्तेमाल पहले से आवंटित मेमोरी को बढ़ाने या घटाने के लिए किया जाता है।
अगर पुनः आवंटन सफल होता है, तो एक पॉइंटर लौटाया जाता है, जो पुनः आवंटित मेमोरी के पहले बाइट के पते की ओर संकेत करता है।
अगर पुनः आवंटन सफल नहीं होता, तो `NULL` लौटाया जाता है।
`realloc` का परिणाम `NULL` है या नहीं, यह जाँच लेना समझदारी है। अगर वह विफल हो जाए, तो उसे भली-भाँति संभाल लीजिए।
`realloc` में दो पैरामीटर होते हैं।
पहला पैरामीटर उस मौजूदा मेमोरी की ओर इशारा करने वाला पॉइंटर होता है, जिसे पुनः आवंटित करना है।
दूसरा पैरामीटर पुनः आवंटित मेमोरी के बाइट में आकार के लिए होता है।
मेमोरी बढ़ाने से पहले जो वैल्यू सेट की गई थीं, वे बनी रहती हैं।
यह याद रखना ज़रूरी है कि मेमोरी बढ़ाते समय जोड़ी गई मेमोरी शून्य से इनिशियलाइज़ नहीं होती और उसकी वैल्यू कुछ भी हो सकती है।
इसी तरह मेमोरी घटाते समय हटाई गई मेमोरी भी इनिशियलाइज़ नहीं होती और उसमें पहले की वैल्यू बनी रह सकती हैं।
नीचे दिया गया उदाहरण ऐरे को बढ़ाना और घटाना दिखाता है।

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
