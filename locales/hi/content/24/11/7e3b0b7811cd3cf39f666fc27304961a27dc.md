# परिचय

## ऐरे डीस्ट्रक्चरिंग

JavaScript का ऐरे डीस्ट्रक्चरिंग सिंटैक्स ऐरे से वैल्यू निकालने और उन्हें अलग-अलग वेरिएबलो में असाइन करने का एक संक्षिप्त तरीका है।

इस उदाहरण में `numberOfMoons` ऐरे की हर वैल्यू उससे जुड़े ग्रह को असाइन की जाती है:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

संक्षेप में:

- यह सिंटैक्स ऐरे में _किसी खास जगह पर रखे गए_ एलिमेंट को नाम देने और री-असाइनमेंट के ज़रिए वेरिएबलो को आपस में बदलने, दोनों की सुविधा देता है।
- डीस्ट्रक्चरिंग सिंटैक्स फंक्शन के पैरामीटर के अंदर भी लिखा जा सकता है, और यह किसी भी इटरेबल पर काम करता है।
- किसी जगह को बिना नाम दिए छोड़ देने पर (यानी कोई भी वेरिएबल नाम न लिखने पर) उस जगह को चुपचाप अनदेखा कर दिया जाता है।

## ऑब्जेक्ट डीस्ट्रक्चरिंग

JavaScript में ऑब्जेक्ट की प्रॉपर्टी निकालकर उन्हें अलग-अलग वेरिएबलो में असाइन करने के लिए भी डीस्ट्रक्चरिंग सिंटैक्स मौजूद है।

इस उदाहरण में `weather` ऑब्जेक्ट से मौसम के प्रतीक निकाले गए हैं:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

संक्षेप में:

- यह सिंटैक्स प्रॉपर्टी निकालने के साथ-साथ उन्हें नया नाम देने की भी सुविधा देता है।
- डीस्ट्रक्चरिंग सिंटैक्स फंक्शन के पैरामीटर के अंदर भी इस्तेमाल किया जा सकता है।
