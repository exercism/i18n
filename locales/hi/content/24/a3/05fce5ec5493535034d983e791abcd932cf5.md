# परिचय

Clojure एक फंक्शनल भाषा है, इसलिए यहाँ फंक्शन को प्रथम श्रेणी का दर्जा मिला हुआ है। इसका मतलब है कि फंक्शन को डेटा की तरह दूसरे फंक्शन को दिया जा सकता है और दूसरे फंक्शन उन्हें बना भी सकते हैं। Clojure में खास तौर पर हायर-ऑर्डर फंक्शन का बड़ा संग्रह है, जो पहले से बने फंक्शन के आधार पर नए फंक्शन बनाते हैं। यहाँ हम चार ज़रूरी मामले देखेंगे: `partial`, `comp`, `memoize` और `juxt`। ये फंक्शन बनाने वाले फंक्शन हायर-ऑर्डर फंक्शन की एक व्यापक श्रेणी में आते हैं, जैसे `map`, `reduce`, `apply`, `complement` इत्यादि, जो पहले से बने फंक्शन पर काम करते हैं।

## partial

आम तौर पर, अगर हमारे पास कोई मौजूदा फंक्शन `my-function` है जिसके पैरामीटर `p1, p2, ..., pN` हैं, तो हम उसके कुछ पैरामीटर `p1, p2, ..., pM` को तय वैल्यू `v1, v2, ..., vM` दे सकते हैं। हम ऐसा `partial` को इस तरह लगाकर करते हैं: `(partial my-function v1 v2 ... vM)`।

नतीजा यह मिलता है कि एक नया फंक्शन बनता है, जो `p1=v1, p2=v2, ..., pM=vM` तय करके मूल फंक्शन `my-function` को लागू करता है। हमारा यह नया फंक्शन इनपुट में बाकी बचे पैरामीटर `pM+1, pM+2, ..., pN` लेता है, जिनकी वैल्यू `partial` लगाते समय नहीं दी गई थीं:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

एक आसान उदाहरण लेते हैं। चलिए एक फंक्शन `inc-by-9` बनाते हैं, जो हम जो भी इसे पास करें, उसमें 9 की तय मात्रा जोड़ देता है। ऐसा फंक्शन हम इस तरह लिख सकते हैं:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

दूसरा उदाहरण देखिए। हमारे पास एक फंक्शन `generic-greetings` है। यह उस व्यक्ति का नाम लेता है जिसे हम अभिवादन करना चाहते हैं, और साथ में शुरू और अंत का संदेश भी:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

और हमेशा एक तय अभिवादन संदेश इस्तेमाल करने के लिए हम `partial` का प्रयोग करते हैं:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` की मदद से हम जितने भी फंक्शन जोड़ना चाहें, उनका संयोजन बना सकते हैं। आम तौर पर `N` फंक्शन `f1, f2, ..., fN` को जोड़ने का मतलब है उन्हें एक के बाद एक क्रम में लागू करना, यानी पिछले फंक्शन का आउटपुट अगले फंक्शन को देना। गणित की भाषा में इसे इस तरह लिखा जाता है:

```
f1 (f2 (... fN(x)))
```

Clojure में यह इसके बराबर है:
```clojure
(f1 (f2 (... (fN x))))
```

comp इस्तेमाल करके हम एक नया फंक्शन बना सकते हैं, जो यह संयोजन हमारे लिए कर देता है:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

उदाहरण के लिए, मान लीजिए हम कई संख्याओं का जोड़ करना चाहते हैं और फिर नतीजे को 6 से गुणा करना चाहते हैं। हम ऐसा इस तरह कर सकते हैं:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` की मदद से हम किसी इनपुट के लिए पहले निकाले गए नतीजों को दोबारा इस्तेमाल कर सकते हैं। एक ही इनपुट मिलने पर *मेमोइज़्ड* फंक्शन वही नतीजा लौटाता है, बिना उसे दोबारा निकाले। यह इस तथ्य का फायदा उठाता है कि `clojure` के फंक्शन डिफ़ॉल्ट रूप से *रेफरेंशियली ट्रांसपेरेंट* होते हैं: एक ही इनपुट पर वे हमेशा वही आउटपुट देते हैं, जिससे पहले की गई गणनाएँ आसानी से दोबारा इस्तेमाल की जा सकती हैं।

यह कैसे काम करता है, यह देखने के लिए चलिए एक बनावटी मामला लेते हैं, जिसमें फंक्शन आउटपुट देने से पहले दो सेकंड सोता है। इससे हम `memoize` इस्तेमाल करने से पहले और बाद का *गणना समय* आसानी से तुलना कर सकते हैं।

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` एक ऐसा फंक्शन बनाता है, जो उसे दिए गए फंक्शनों को बाएँ से दाएँ क्रम में लागू करता है। नतीजा एक वेक्टर होता है, जिसमें हर फंक्शन का अलग-अलग नतीजा उस वेक्टर के कंपोनेंट के रूप में मौजूद होता है:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

एक आसान उदाहरण देखिए। हम एक ऐसा फंक्शन बनाते हैं, जो x का गुणनफल 2 से 5 तक के क्रमिक गुणकों के साथ निकालता है:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
