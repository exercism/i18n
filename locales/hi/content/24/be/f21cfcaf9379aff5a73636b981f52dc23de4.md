# संख्याएँ

Crystal में एक टाइप है, `Number`, जो सभी संख्यात्मक टाइप का आधार टाइप है।
`Number` टाइप के अंदर दो मुख्य उप-टाइप हैं: [`Int`][int] और [`Float`][float]।

`Int`, पूर्णांक का छोटा रूप है और पूर्ण संख्याओं को दर्शाता है।
`Int` ऋणात्मक और धनात्मक दोनों हो सकता है, और इसमें दशमलव बिंदु नहीं होता।

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` दशमलव बिंदु वाली संख्याओं को दर्शाता है।
`Float` संख्याएँ ऋणात्मक और धनात्मक दोनों हो सकती हैं।

```crystal
10.5.class
# => Float64
```

## `Int` और `Float` के बीच बदलना

'translating to `to_i' and 'to_f' methods, you can convert between `Int` and `Float`.
The number is rounded down when converting from `Float` to `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## अंकगणितीय ऑपरेटर

आप `Int` और `Float` पर [आधारभूत अंकगणितीय ऑपरेटर][math] इस्तेमाल कर सकते हैं।
ये ऑपरेटर `+`, `-`, `*`, `/` और `%` हैं।
इन ऑपरेटरों का उपयोग करते समय, आप `Int` और `Float` को मिला सकते हैं।

### जोड़, घटाव और गुणा

`+` ऑपरेटर जोड़ के लिए, `-` ऑपरेटर घटाव के लिए, और `*` ऑपरेटर गुणा के लिए इस्तेमाल होता है।

| ऑपरेटर | उदाहरण        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### भाग

भाग का उपयोग संख्याओं को बाँटने के लिए किया जाता है।
`/` ऑपरेटर भाग के लिए इस्तेमाल होता है।
परिणाम हमेशा एक `Float` होगा।

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
कुछ प्रोग्रामिंग भाषाओं में, शून्य से भाग देने पर परिणाम एक एरर होता है।

Crystal में, शून्य से भाग देने पर परिणाम `Infinity` या `-Infinity` होता है।
केवल एक अपवाद है: शून्य को शून्य से भाग देना, जिसका परिणाम `NaN` (संख्या नहीं) होता है।
`Infinity` और `NaN`, `Float` टाइप की खास वैल्यू हैं।

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## पूर्णांक भाग

पूर्णांक भाग का उपयोग संख्याओं को भाग देकर परिणाम का पूरा भाग पाने के लिए किया जाता है।
परिणाम हमेशा नीचे की ओर राउंड करके `Int` बनाया जाता है।

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
पूर्णांक भाग में शून्य से भाग देने पर `DivisionByZeroError` एरर मिलती है।
यह सामान्य भाग से अलग है।
~~~~

### मॉड्यूलस

मॉड्यूलस का उपयोग भाग का शेषफल निकालने के लिए किया जाता है।
`%` ऑपरेटर मॉड्यूलस के लिए इस्तेमाल होता है।

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
मॉड्यूलो में शून्य से भाग देने पर `DivisionByZeroError` एरर मिलती है।
यह सामान्य भाग से अलग है।

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## घातांकन

घातांकन का उपयोग किसी संख्या को घात तक बढ़ाने के लिए किया जाता है।
`**` ऑपरेटर घातांकन के लिए इस्तेमाल होता है।
`Float` और `Int` वाले किसी ऑपरेशन का परिणाम `Float` होगा।

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## राउंडिंग

`round` मेथड एक वैकल्पिक आर्गुमेंट लेता है: कितने दशमलव स्थानों तक राउंड करना है, यह संख्या।
दशमलव स्थानों की डिफ़ॉल्ट संख्या 0 है।

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### ऊपर और नीचे राउंड करना

आप `ceil` और `floor` मेथड का उपयोग करके किसी संख्या को ऊपर या नीचे `Int` तक राउंड कर सकते हैं।
`ceil` मेथड ऊपर की ओर राउंड करता है, और `floor` मेथड नीचे की ओर राउंड करता है।

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## प्राथमिकता और गोल ब्रैकेट

Crystal गोल ब्रैकेट (`()`) की अनुमति देता है, जिनका उपयोग एक्सप्रेशनों को समूहित करने के लिए किया जा सकता है।
यह तब उपयोगी होता है जब आप ऑपरेशनों का क्रम बदलना चाहते हैं।

कई अंकगणितीय ऑपरेटरों का उपयोग करते समय, ऑपरेशनों का क्रम गणित जैसा ही होता है, जिसे [PEMDAS][pemdas] भी कहा जाता है।
यह गोल ब्रैकेट (`()`), घात (`**`), गुणा (`*`) और भाग (`/`), तथा जोड़ (`+`) और घटाव (`-`) के क्रम का पालन करता है।

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
