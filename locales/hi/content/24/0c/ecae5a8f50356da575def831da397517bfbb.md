# परिचय

पूर्णांकों को सिर्फ़ संख्यात्मक वैल्यू ही नहीं, बल्कि बिट के पैटर्न के रूप में भी देखा जा सकता है। Factor की [`math`][math] शब्दावली में ऐसे बिट पैटर्न पर काम करने वाले मानक निम्न-स्तरीय ऑपरेशन मौजूद हैं, और [`math.bitwise`][bitwise] शब्दावली निश्चित चौड़ाई वाली वैल्यू के साथ काम करने के लिए कुछ मददगार चीज़ें जोड़ती है।

## बिट शिफ्ट

`shift ( m n -- m' )` `m` के बिट शिफ्ट कर देता है। *धनात्मक* `n` बाएँ शिफ्ट करता है (हर कदम पर 2 से गुणा); *ऋणात्मक* `n` दाएँ शिफ्ट करता है (हर कदम पर 2 से भाग):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

धनात्मक पूर्णांकों में दाएँ शिफ्ट नीचे से बिट हटा देता है और शून्य से भर देता है। *ऋणात्मक* पूर्णांकों के लिए Factor का `shift` अंकगणितीय शिफ्ट होता है: यह साइन बिट को बनाए रखता है और मानो बाईं ओर से साइन बिट की प्रतियाँ भरता चला जाता है। (Factor में पूर्णांकों की प्रिसीज़न की कोई सीमा नहीं होती, इसलिए "बाईं ओर" जहाँ तक ज़रूरत पड़े वहाँ तक फैलती चली जाती है।)

## बिटवाइज़ लॉजिक

चार बुनियादी लॉजिक ऑपरेशन ये हैं:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`0b1011` का `bitnot` `-12` होता है, क्योंकि Factor में पूर्णांकों की प्रिसीज़न की कोई सीमा नहीं होती। `0b1011` के बिट पलटने का मतलब है "सारे बिट एक, बस नीचे के चार बिट `0100` हो गए", और इसे साइन्ड बिगनम की तरह पढ़ने पर `-12` मिलता है।

## किसी वैल्यू को N बिट के रूप में देखना

`math.bitwise` का `bits ( x n -- y )`, `x` को उसके नीचे के `n` बिट तक सीमित कर देता है। Factor में "किसी वैल्यू को N बिट के अनसाइन्ड पूर्णांक की तरह फिर से पढ़ने" का यही तरीका है:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

यह दूसरा उदाहरण इस अभ्यास के लिए खास मायने रखता है। मान लीजिए आपके पास ऋणात्मक टूज़ कॉम्प्लिमेंट वाली Int32 वैल्यू है और आप उसे `amount` के बराबर "लॉजिकल" तरीके से दाएँ शिफ्ट करना चाहते हैं (बाईं ओर से शून्य भरते हुए), तो Factor में इसका तरीका यह है:

```
( value -- shifted )
32 bits  amount neg  shift
```

पहले 32 बिट तक सीमित कीजिए, ताकि वैल्यू अनसाइन्ड की तरह पढ़ी जाने लगे, और उसके बाद शिफ्ट कीजिए। सीमित की गई वैल्यू ऋणात्मक नहीं होती, इसलिए `shift` बस नीचे से बिट हटा देता है और शून्य भर देता है।
