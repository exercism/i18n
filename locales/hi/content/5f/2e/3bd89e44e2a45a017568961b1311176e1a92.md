# इंस्टॉलेशन

## Linux

GNU शेल के रूप में Bash किसी भी GNU/Linux सिस्टम पर मिल जाएगा।
BSD और अन्य UNIX डेरिवेटिव के लिए संभवतः उपयोगकर्ता को खुद इंस्टॉल करना पड़ेगा।
अगर आप BSD, AIX या ऐसे Linux पर हैं जिसके साथ bash नहीं आता, तो गैर-कोर पैकेज इंस्टॉल करने के बारे में अपने ऑपरेटिंग सिस्टम के संसाधनों से जानकारी ले लीजिए।

अपनी पसंद के ग्राफिकल इंटरफेस में "Terminal" नाम का ऐप ढूँढिए: यह "Administrative/System Tools" सेक्शन के अंदर मिल सकता है।

उपलब्ध Bash का वर्ज़न जाँचने के लिए, कमांड लाइन या टर्मिनल से यह चलाइए:

    echo $BASH_VERSION

अगर आपका शेल `bash` है, तो यह कुछ ऐसा दिखाना चाहिए:

    4.4.19(1)-release

आपको और कुछ करने की ज़रूरत नहीं होनी चाहिए। इस समय bash इंस्टॉल होकर आपके पाथ में होना चाहिए, क्योंकि यही आपका मौजूदा शेल है।

अगर आपका शेल bash नहीं है, तो उसे बदलने की कोई ज़रूरत नहीं है।
आप bash शेल में हुए बिना भी bash स्क्रिप्ट लिख और चला सकते हैं।

इंस्टॉल किए गए bash का वर्ज़न जाँचने के लिए यह चलाइए:

```plain
bash --version
```

यह कुछ ऐसा दिखाएगा:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

अगर ऐसा नहीं दिखता, तो हो सकता है कि bash इंस्टॉल न हो।
इसे अपने डिस्ट्रीब्यूशन के पैकेज मैनेजर से इंस्टॉल कीजिए।

## Windows

Windows 10 पर आप [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) इंस्टॉल कर सकते हैं।
इससे एक पूरा (खैर, बिना GUI वाले हिस्से) Linux डिस्ट्रीब्यूशन इंस्टॉल होता है, जो Windows में नेटिव तौर पर चलता है।

वैकल्पिक रूप से, आप ये इंस्टॉल कर सकते हैं:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* [वर्चुअल मशीन](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/) में एक पूरा Linux डिस्ट्रीब्यूशन

## MacOS

Apple OSX के लिए:

* Finder खोलिए,
* अपना Applications फोल्डर खोलिए,
* Utilities फोल्डर खोलिए,
* और अंत में `Terminal` ऐप खोलिए।

ध्यान दीजिए कि MacOS पर इंस्टॉल bash का वर्ज़न बहुत पुराना है, वर्ज़न 3.2।
यह इसलिए है कि (i) नए bash वर्ज़न GPLv3 के तहत लाइसेंस किए जाते हैं और (ii) Apple उस लाइसेंस की शर्तों का पालन करने के लिए मजबूर नहीं होना चाहता।
इसके अलावा, Apple ने संकेत दिया है कि bash जल्द MacOS से हट जाएगा: डिफॉल्ट लॉगिन शेल हाल ही में [bash से zsh में बदल दिया गया](https://support.apple.com/en-us/HT208050)।

अपने Mac पर नया bash पाने के लिए:

1. [Homebrew](https://brew.sh) इंस्टॉल कीजिए
1. टर्मिनल में यह डालिए: `brew install bash`

इससे नया bash (मेरे ख्याल से) `/usr/local/bin/bash` पर इंस्टॉल होता है (ताकि सिस्टम का डिफॉल्ट bash ओवरराइट न हो, क्योंकि दूसरे टूल /bin/bash पर निर्भर हो सकते हैं)।

अगर आप चाहते हैं कि `bash` टाइप करने पर homebrew वाला bash चले, तो अपनी ~/.bash_profile (या ~/.profile) फाइल में PATH में /usr/local/bin को /bin से *पहले* रखने के लिए बदलाव कीजिए:

    PATH=/usr/local/bin:$PATH
