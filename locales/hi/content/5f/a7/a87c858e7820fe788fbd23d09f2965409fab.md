# टेस्ट

## कोड लिखना

अपना कोड `src/lib.cairo` में लिखिए।
हर अभ्यास के साथ `src/lib.cairo` में एक स्टब फाइल आती है, जो आपको उस कोड के सिग्नेचर दिखाती है जो आपको लिखना है।

ज़्यादातर अभ्यासों में अपना सारा कोड `src/lib.cairo` फाइल में ही लिखना सबसे अच्छा रहता है।
अगर आप अपने हल को कई फाइलों में बाँटना चाहते हैं, तो The Cairo Book का [मॉड्यूल वाला अध्याय][chapter-modules] देखिए।

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## टेस्ट चलाना

टेस्ट चलाने के लिए सबसे पहले आपको अपनी वर्किंग डायरेक्टरी उस अभ्यास की डायरेक्टरी में बदलनी होगी जिसका आप टेस्ट करना चाहते हैं:

```bash
cd path/to/exercise
```

और फिर यह कमांड चलाइए:

```bash
scarb cairo-test
```

डिफ़ॉल्ट रूप से सिर्फ पहला टेस्ट ही सक्रिय रहता है।
जब आप अगला टेस्ट पास करने के लिए तैयार हो जाएँ, तो अगले टेस्ट से ignore फ्लैग (`#[ignore]`) हटा दीजिए।

जिन टेस्टों पर `ignore` लगा है, उन सहित सारे टेस्ट चलाने के लिए आप सभी टेस्टों से `ignore` फ्लैग हटा सकते हैं, या सिर्फ यह चला सकते हैं:

```bash
scarb cairo-test --include-ignored
```

टेस्ट पास कराने के लिए आप जितना कम कोड लिखें, उतना बेहतर है।
टेस्ट फेल होने पर जो एरर दिखेंगी, वही आपको बताएँगी कि अब आगे क्या लिखना है।

Cairo सारा कोड कंपाइल के समय ही जाँच लेता है। इसलिए ज़रूरी कोड लिखने तक हो सकता है कि आपके टेस्ट कंपाइल ही न हों।
जिन टेस्टों पर `ignore` लगा है, वे भी कंपाइल के समय जाँचे जाते हैं।
जो टेस्ट कंपाइल नहीं होंगे, उन्हें आप हर लाइन की शुरुआत `//` से करके [कमेंट कर सकते हैं][comments]।
फिर जब आप उस टेस्ट पर काम करने के लिए तैयार हों, तो उससे कमेंट हटा सकते हैं।
Cairo में `panic!()` नाम का एक खास मैक्रो भी है, जिसे आप अपने प्रोग्राम को कंपाइल कराने के लिए अधूरे कोड वाली जगहों पर इस्तेमाल कर सकते हैं।

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
