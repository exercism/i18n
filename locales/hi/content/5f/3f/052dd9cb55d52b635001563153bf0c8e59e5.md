# परिचय

## रिकॉर्ड

एक रिकॉर्ड कई फील्ड का संग्रह होता है। इन फील्ड के टाइप अलग-अलग हो सकते हैं, और ये सब आपस में जुड़ी होती हैं। रिकॉर्ड परिभाषित करने के लिए `type` कीवर्ड का उपयोग किया जाता है। रिकॉर्ड की फील्ड `{` और `}` के बीच लिखी जाती हैं, और हर फील्ड का एक नाम _और_ एक टाइप होता है। रिकॉर्ड बनाने के लिए फील्ड के नाम लिखिए और `{` तथा `}` के बीच उनमें वैल्यू असाइन कीजिए। रिकॉर्ड बनाते समय हर फील्ड को वैल्यू असाइन करना ज़रूरी है। किसी रिकॉर्ड इंस्टेंस की फील्ड की वैल्यू डॉट-नोटेशन से पढ़ी जा सकती हैं।

रिकॉर्ड परिभाषित या बनाते समय हर फील्ड या तो अलग लाइन पर होनी चाहिए, या एक ही लाइन पर हो तो सेमीकोलन (`;`) से अलग होनी चाहिए।

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

चूँकि रिकॉर्ड अपरिवर्तनीय होते हैं, इसलिए एक बार रिकॉर्ड बन जाने के बाद उसकी फील्ड की वैल्यू कभी नहीं बदल सकतीं। अगर आप रिकॉर्ड की वैल्यू बदलना चाहते हैं, तो `with` कीवर्ड की मदद से मौजूदा रिकॉर्ड की एक प्रति बना सकते हैं, जिसमें एक या अधिक फील्ड की वैल्यू नई होती हैं।

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

रिकॉर्ड में _संरचनात्मक समानता_ होती है, यानी एक ही रिकॉर्ड के दो इंस्टेंस जिनकी वैल्यू समान हों, बराबर माने जाते हैं।

डॉट-नोटेशन से रिकॉर्ड की फील्ड पढ़ी जा सकती हैं। इसके अलावा रिकॉर्ड को बाइंडिंग में और पैटर्न मैचिंग में _डीकंस्ट्रक्ट_ भी किया जा सकता है:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
