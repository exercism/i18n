# परिचय

[टर्नरी ऑपरेटर][ternary-operators] की मदद से `if` की शर्तें स्टेटमेंट ब्लॉक के बजाय एक्सप्रेशन में परिभाषित की जा सकती हैं। यह फंक्शनल प्रोग्रामिंग के तरीकों से मेल खाता है, और इससे कोड अक्सर ज़्यादा अभिव्यक्तिपूर्ण बन जाता है और गलतियों की गुंजाइश कम हो जाती है।

टर्नरी ऑपरेटर तीन एक्सप्रेशन को जोड़ता है: पहले एक शर्त, फिर वह एक्सप्रेशन जिसकी वैल्यू शर्त सही होने पर निकाली और लौटाई जाती है (यह `if` वाला भाग है, जो `?` से शुरू होता है), और अंत में वह एक्सप्रेशन जिसकी वैल्यू शर्त गलत होने पर निकाली और लौटाई जाती है (यह `else` वाला भाग है, जो `:` से शुरू होता है)।

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
