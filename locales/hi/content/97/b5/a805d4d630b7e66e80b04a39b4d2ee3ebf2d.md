# परिचय

## फ्लोटिंग पॉइंट संख्याएँ

फ्लोटिंग पॉइंट संख्या वह संख्या होती है जिसमें दशमलव चिह्न के बाद शून्य या उससे अधिक अंक होते हैं। उदाहरण हैं `-2.4`, `0.1`, `3.14`, `16.984025` और `1024.0`।

अलग-अलग फ्लोटिंग पॉइंट टाइप दशमलव चिह्न के बाद अलग-अलग संख्या में अंक संग्रहीत कर सकते हैं। इसे ही उसकी प्रिसीज़न कहा जाता है।

C# में तीन फ्लोटिंग पॉइंट टाइप होते हैं:

- `float`: 4 बाइट (~6-9 अंकों की प्रिसीज़न)। इसे `2.45f` लिखा जाता है।
- `double`: 8 बाइट (~15-17 अंकों की प्रिसीज़न)। यह सबसे आम टाइप है। इसे `2.45` या `2.45d` लिखा जाता है।
- `decimal`: 16 बाइट (28-29 अंकों की प्रिसीज़न)। आम तौर पर इसे पैसे से जुड़े डेटा के साथ काम करते समय इस्तेमाल किया जाता है, क्योंकि इसकी प्रिसीज़न राउंडिंग एरर की संभावना कम कर देती है। इसे `2.45m` लिखा जाता है।

जैसा कि देखा जा सकता है, हर टाइप अलग-अलग संख्या में अंक संग्रहीत कर सकता है। उदाहरण के लिए, अगर PI को किसी `float` में संग्रहीत करने की कोशिश कीजिए, तो सिर्फ पहले 6 दशमलव स्थान ही संग्रहीत होंगे (और अंत में संग्रहीत अंक को राउंड कर दिया जाएगा)।

## `while` लूप

इस अभ्यास में आपको लूप की ज़रूरत पड़ सकती है। C# में लूप लिखने के कई तरीके हैं, लेकिन यहाँ `while` लूप सबसे उपयुक्त है:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## `do`/`while` लूप

अगर लूप का कोड कम से कम एक बार हमेशा चलना ही चाहिए, तो `do`/`while` लूप इस्तेमाल किया जा सकता है:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
