## इंटरैक्टिव jq टूल

कुछ इनपुट दीजिए और अलग-अलग jq फिल्टर आज़माकर देखिए कि क्या परिणाम मिलता है।

- [jq playground][jqplay], ऑनलाइन आज़माकर देखने का अनुभव।
- [ijq][ijq], इंटरैक्टिव jq टूल, कमांड लाइन के लिए jqplay जैसा।
- [jqp][jqp] एक और कमांड लाइन टूल है। यह बैकएंड के तौर पर gojq का उपयोग करता है, जो मूल jq से 100% संगत नहीं है।

## JSON को संसाधित करने वाले अन्य टूल

- [gron][gron]: JSON को अलग-अलग असाइनमेंट के क्रम में "समतल" कर देता है, जिससे लाइन-आधारित टूल (grep आदि) की मदद से इसे संसाधित करना संभव हो जाता है।
- [jo][jo]: शेल वेरिएबलो से JSON ऑब्जेक्ट बनाने वाला एक छोटा टूल।
- [jello][jello]: jello, jq जैसा ही है, सिर्फ इतना अंतर है कि यह मानक python dict और list सिंटैक्स का उपयोग करता है।
