# निर्देश

इस अभ्यास में आप अलग-अलग तरह की रिमोट कंट्रोल कारों के बीच दौड़ आयोजित करेंगे। हर कार की गति और बैटरी ड्रेन अलग-अलग होते हैं।

कारें पूरी (100%) बैटरी के साथ शुरू होती हैं। जब भी आप रिमोट कंट्रोल से कार चलाते हैं, वह कार की गति के बराबर मीटर तय करती है और बची हुई बैटरी का प्रतिशत उसके बैटरी ड्रेन के बराबर घट जाता है।

अगर किसी कार की बैटरी उसके बैटरी ड्रेन प्रतिशत से कम है, तो आप उस कार को और नहीं चला सकते।

हर रेस ट्रैक की अपनी लंबाई होती है। कारों की जाँच यह देखकर की जाती है कि वे बैटरी खत्म हुए बिना ट्रैक पूरा कर सकती हैं या नहीं।

## 1. रिमोट कंट्रोल कार बनाइए

इन एलिमेंट्स वाला एक `car` ऐरे बनाइए:

- speed
- battery_drain
- battery
- distance_traveled

`new_car` नाम का फंक्शन बनाकर रिमोट कंट्रोल कार बनाने की सुविधा दीजिए। यह फंक्शन अपने दो पैरामीटर के तौर पर कार की गति मीटर में और बैटरी ड्रेन प्रतिशत लेता है, और एक `car` ऐरे लौटाता है।

नई कार की बैटरी 100% पर होती है और तय की गई दूरी शून्य होती है।

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. रेस ट्रैक बनाइए

`track_length` नाम के अकेले एलिमेंट वाला एक और ऐरे बनाइए जिसका नाम `track` हो। `new_track` नाम का फंक्शन बनाकर रेस ट्रैक बनाने की सुविधा दीजिए। यह फंक्शन ट्रैक की दूरी मीटर में लेता है:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. बैटरी खत्म होने की जाँच कीजिए

`battery_drained()` फंक्शन लागू कीजिए, जो बताता है कि बैटरी खत्म हो चुकी है या नहीं। अगर एक बार और चलने के लिए बैटरी काफी न हो, तो बैटरी खत्म मानी जाती है।

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. कार चलाइए

`drive` फंक्शन लागू कीजिए, जो कार की गति के हिसाब से तय किए गए मीटर अपडेट करता है और बैटरी ड्रेन के मुताबिक बैटरी कम करता है। अगर एक बार और चलाने के लिए बैटरी काफी न हो, तो कार नहीं चलेगी।

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. जाँचिए कि रिमोट कंट्रोल कार दौड़ पूरी कर सकती है या नहीं

दौड़ पूरी करने के लिए कार को दौड़ की पूरी लंबाई चल पाना ज़रूरी है। यानी फिनिश लाइन पार करने से पहले उसकी बैटरी खत्म नहीं होनी चाहिए।

`can_finish` फंक्शन लागू कीजिए, जो अपने पैरामीटर के तौर पर एक `car` और एक `track` लेता है और `TRUE` लौटाता है अगर कार दौड़ पूरी कर सकती है; वरना `FALSE` लौटाता है।

मान लीजिए कि आप इस समय दौड़ की शुरुआती लाइन पर हैं और दौड़ के लिए कार का इंजन शुरू करते हैं। ध्यान रखिए कि दौड़ शुरू करते समय कार की बैटरी ज़रूरी नहीं कि पूरी चार्ज हो।

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. यह संग्रहीत कीजिए कि कार पूरी बैटरी पर ट्रैक पूरा कर सकती है या नहीं

आपने अलग-अलग लंबाई के कई ट्रैक बनाए हैं, और आपको यह संग्रहीत करना है कि पूरी चार्ज होने पर आपकी कार उन्हें पूरा कर सकती है या नहीं।

`store_track` फंक्शन लागू कीजिए, जो एक कार, एक ट्रैक और ट्रैक का नाम लेता है, और एक अतिरिक्त एलिमेंट वाली अपडेटेड कार लौटाता है। इस एलिमेंट का नाम ट्रैक के `name` के बराबर होना चाहिए, और इसकी वैल्यू एक और ऐरे होनी चाहिए जिसमें `track_length` और यह जानकारी हो कि कार उसे `complete` कर सकती है या नहीं।

आर्गुमेंट में दी गई कार शायद पूरी चार्ज न हो, इसलिए इसे इस्तेमाल करने से पहले बैटरी और तय की गई दूरी ज़रूर रीसेट कर दीजिए।

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
