# निर्देश परिशिष्ट

## Arturo से जुड़ी जानकारी

इस अभ्यास में आपको उम्रें एक [भौतिक राशि] के रूप में लौटानी होंगी। इस राशि की इकाई आपको खुद बनानी होगी, और वह उस ग्रह पर एक साल की लंबाई दर्शाएगी।
Arturo में एक मात्रा एक संख्यात्मक मान और उससे जुड़ी [माप की इकाई][unit-of-measurement] से मिलकर बनती है।

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Arturo की बिल्ट-इन `yr इकाई 31556952 सेकंड के बराबर होती है।
इसलिए आपको अपनी खुद की वर्ष इकाई बनानी होगी, और उसका इस्तेमाल करना होगा। इस इकाई को उन सेकंडों की संख्या के आधार पर तय करना होगा जिनका उल्लेख निर्देशों में पहले किया गया है।
~~~~

मात्राओं को किसी अन्य संगत इकाई में [बदला][convert] जा सकता है।
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
दशमलव संख्याओं में परिशुद्धता की सीमाओं के कारण Arturo कभी-कभी स्केलर को परिमेय संख्या के रूप में संग्रहीत करता है।
इसके बजाय उस मान को अनुमानित दशमलव संख्या के रूप में निकालने के लिए [`to` फंक्शन][to] का इस्तेमाल किया जा सकता है।

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo में हम मात्राओं के लिए अपनी इकाइयाँ [निर्दिष्ट][specify] भी कर सकते हैं।

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
