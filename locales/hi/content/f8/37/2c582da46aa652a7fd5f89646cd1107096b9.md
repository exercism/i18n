# Luhn की अवधारणाएँ

Luhn एक वैलिडेशन एल्गोरिदम है, जो टेक्स्ट और संख्याओं से जुड़े दावों को साथ लेकर चलता है। Rust में इसके हल फंक्शनल तरीकों को पसंद करते हैं।

## सामान्य

### प्रिमिटिव

- `&str` और `char`
  - दिए गए इनपुट के किन हिस्सों को शामिल करना है और किन्हें बाहर करना है, यह सही तरीके से तय करने के लिए सीखने वालों को `char` और `&str` के अंतर को समझना ज़रूरी है।
- पूर्णांक
  - ज़रूरी संख्यात्मक वैलिडेशन करने के लिए पूर्णांक की समझ होना आवश्यक है।
- बूलियन
  - पहचान जाँचने और अंतिम तुलना करने के लिए बूलियन अनिवार्य हैं।

### इटरेटर की विशेषताएँ

- चेनिंग
  - यहाँ समस्या को क्रम से हल करने के लिए इटरेटर चेन को समझना ज़रूरी है।
- `map`, `filter`, टर्बोफिश, और शायद `fold`
  - `map` और `filter` को मिलाने से इस जैसी वैलिडेशन समस्याओं के लिए एक बुनियादी डिज़ाइन पैटर्न मिलता है। `fold` से बने हल और भी संक्षिप्त होते हैं।
  - कुछ हलों में टर्बोफिश की ज़रूरत पड़ती है, ताकि Rust को बताया जा सके कि चेन वाले एक्सप्रेशन से आप कौन-सा टाइप बना रहे हैं।

## हल का उदाहरण 1

york का [हल](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## हल का उदाहरण 2

मानक

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
