# परिचय

JavaScript एक डायनामिक भाषा है। यह ऑब्जेक्ट-ओरिएंटेड, इम्परेटिव और डिक्लेरेटिव (जैसे फंक्शनल प्रोग्रामिंग) शैलियों का समर्थन करती है।

## वेरिएबल

JavaScript में नामों को वैल्यू असाइन करने के कुछ मुख्य तरीके हैं, जैसे वेरिएबल या कॉन्स्टेंट का इस्तेमाल।
Exercism पर वेरिएबल हमेशा [camelCase][wiki-camel-case] में लिखे जाते हैं और कॉन्स्टेंट [SCREAMING_SNAKE_CASE][wiki-snake-case] में।
इसके लिए कोई आधिकारिक गाइड नहीं है, और अलग-अलग कंपनियों और संगठनों के अपने-अपने स्टाइल गाइड होते हैं।
_वेरिएबल आप जैसे चाहें वैसे लिख सकते हैं_।
अभ्यास जिस तरह तैयार किए गए हैं, उसी तरह वेरिएबल लिखने का फायदा यह है कि वेब इंटरफेस और ज़्यादातर IDE में वे अलग तरह से हाइलाइट होते हैं।

JavaScript में वेरिएबल [`const`][mdn-const], [`let`][mdn-let] या [`var`][mdn-var] कीवर्ड से बनाए जा सकते हैं।

`let` या `var` इस्तेमाल करने पर एक वेरिएबल अपने जीवनकाल में अलग-अलग वैल्यू रख सकता है।
उदाहरण के लिए, `myFirstVariable` को असाइनमेंट ऑपरेटर `=` की मदद से कई बार बनाया और फिर से बनाया जा सकता है:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let` और `var` के उलट, `const` से बनाए गए वेरिएबल को सिर्फ एक बार ही असाइन किया जा सकता है।
JavaScript में कॉन्स्टेंट बनाने के लिए इसी का इस्तेमाल किया जाता है।

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## फंक्शन घोषणाएँ

JavaScript में काम की इकाइयाँ _फंक्शन_ में समेट दी जाती हैं। जो फंक्शन एक-दूसरे से जुड़े होते हैं, उन्हें आम तौर पर एक ही फाइल में रखा जाता है।
इन फंक्शन के पैरामीटर होते हैं (ताकि वे आर्गुमेंट ले सकें), और ये `return` कीवर्ड की मदद से वैल्यू _लौटा_ सकते हैं।
फंक्शन को `()` सिंटैक्स से कॉल किया जाता है।

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

इस उदाहरण में फंक्शन का नाम `add` है।
इसके दो पैरामीटर हैं, `num1` और `num2`।
यह एक वैल्यू लौटाता है: एक्सप्रेशन `num1 + num2` का परिणाम

फिर फंक्शन `add` को दो आर्गुमेंट देकर _कॉल_ किया जाता है: `1` और `3`।
फंक्शन का परिणाम, यानी लौटाई गई वैल्यू, `4` है।

```exercism/note
💡 JavaScript में फंक्शन घोषित करने के _कई_ अलग-अलग तरीके हैं।
इनमें से कुछ तरीके `function` कीवर्ड इस्तेमाल करने से अलग लगते हैं।
यह ट्रैक इनसे धीरे-धीरे परिचित कराने की कोशिश करता है, लेकिन अगर आप इनके बारे में पहले से जानते हैं, तो इनमें से कोई भी बेझिझक इस्तेमाल कर सकते हैं।
ज़्यादातर मामलों में किसी एक का इस्तेमाल करना दूसरे से बेहतर या खराब नहीं होता।
```

## दूसरी फाइलों के लिए उपलब्ध कराना

किसी `function`, कॉन्स्टेंट या वेरिएबल को _दूसरी फाइलों_ में उपलब्ध कराने के लिए उन्हें `export` कीवर्ड से [एक्सपोर्ट][mdn-export] करना पड़ता है।
इसके बाद कोई दूसरी फाइल `import` कीवर्ड से इन्हें [इम्पोर्ट][mdn-import] कर सकती है।
इसे मॉड्यूल सिस्टम भी कहते हैं।

सारे टेस्ट कैसे काम करते हैं, इसका एक बढ़िया उदाहरण यही है।
हर अभ्यास में कम से कम एक फाइल होती है, जैसे `lasagna.js`, जिसमें _इम्प्लीमेंटेशन_ रहता है।
_इम्प्लीमेंटेशन_ को फाइल से `export` किया जाता है, जिससे वह किसी दूसरी फाइल में इम्पोर्ट करने के लिए उपलब्ध हो जाता है।
इसके अलावा कम से कम एक और फाइल होती है, जैसे `lasagna.spec.js`, जिसमें _टेस्ट_ होते हैं।
इम्प्लीमेंटेशन को टेस्ट करने के लिए यह फाइल सार्वजनिक (यानी `export` की गई) चीज़ों को `import` करती है:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
