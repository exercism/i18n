# परिचय

## लेबल वाले आर्गुमेंट

कभी-कभी किसी फंक्शन में बहुत सारे आर्गुमेंट हो जाते हैं, और तब यह याद रखना मुश्किल हो जाता है कि उन्हें किस क्रम में देना है। कोड पढ़ने में आसानी हो, इसके लिए Gleam में आर्गुमेंट के साथ एक नाम का लेबल लगाया जा सकता है।

किसी आर्गुमेंट पर लेबल लगाने के लिए आर्गुमेंट के नाम से पहले लेबल का नाम लिखिए और दोनों के बीच एक स्पेस छोड़िए।

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

लेबल वाले आर्गुमेंट लेने वाले फंक्शन को कॉल करते समय आर्गुमेंट किसी भी क्रम में दिए जा सकते हैं। `replace` को कॉल करने के ये सारे तरीके एक जैसे हैं:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

लेबल लगाना हमेशा ज़रूरी नहीं होता। किसी फंक्शन में लेबल वाले आर्गुमेंट हों, तब भी उसे बिना लेबल के कॉल किया जा सकता है।

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
