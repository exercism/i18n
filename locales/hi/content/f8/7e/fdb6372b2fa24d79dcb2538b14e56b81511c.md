# परिचय

## फंक्शन

Gleam में फंक्शन `pub fn` सिंटैक्स से बनाए जाते हैं।

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

यह फंक्शन दो आर्गुमेंट लेता है, जो दोनों `Int` टाइप के हैं, और `Int` टाइप की एक वैल्यू लौटाता है। Gleam में `return` कीवर्ड नहीं होता। फंक्शन में अंतिम एक्सप्रेशन की वैल्यू हमेशा _अपने आप लौटा दी जाती है_।

आर्गुमेंट के टाइप एनोटेशन और रिटर्न टाइप लिखना ज़रूरी नहीं है, फिर भी Gleam आपके कोड की टाइप जाँच हमेशा पूरी करता है। आम तौर पर Gleam प्रोग्रामर साफ़ समझ के लिए अपने फंक्शन पर टाइप एनोटेशन लिखते हैं, लेकिन आप चाहें तो इन्हें छोड़ सकते हैं।

```gleam
pub fn add(x, y) {
  x + y
}
```

फंक्शन को `function_name(argument1, argument2)` सिंटैक्स से कॉल किया जाता है।

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## वेरिएबल

Gleam में वेरिएबल `let name = expression` सिंटैक्स से बनाए जाते हैं।

```gleam
pub fn main() {
  let count = 1
}
```

वेरिएबल टाइप एनोटेशन के साथ घोषित किए जा सकते हैं। फंक्शन के आर्गुमेंट की तरह ये भी ज़रूरी नहीं हैं, हालाँकि ज़्यादातर Gleam प्रोग्रामर वेरिएबल पर टाइप एनोटेशन नहीं लिखते।

```gleam
pub fn main() {
  let count: Int = 1
}
```

## स्ट्रिंग लिटरल

Gleam में स्ट्रिंग डबल कोट्स के बीच लिखी जाती हैं।

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## कोड कमेंट

कोड कमेंट की मदद से आप सोर्स कोड पढ़ने वाले दूसरे डेवलपर के लिए नोट छोड़ सकते हैं। Gleam में कमेंट एक लाइन के होते हैं और उनसे पहले `//` लिखा जाता है।

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
