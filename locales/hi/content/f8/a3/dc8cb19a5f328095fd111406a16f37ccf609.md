# SQLite के लिए विशेष निर्देश

* **candidates** कॉलम में JSON में एनकोड किया गया स्ट्रिंग का ऐरे होता है।
  उदाहरण:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* **result** कॉलम में भी JSON में एनकोड किया गया स्ट्रिंग का ऐरे होना चाहिए।

## टेबल स्कीमा

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
