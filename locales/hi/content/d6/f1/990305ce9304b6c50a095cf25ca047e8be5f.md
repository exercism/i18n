# निर्देश परिशिष्ट

## अतिरिक्त निर्देश

आपको "isogram" नाम की एक टेबल दी जाएगी।
पहला कॉलम, "phrase", कुछ टेक्स्ट रखता है।
आपको यह पता लगाना है कि वह वाक्यांश आइसोग्राम है या नहीं।
दूसरे कॉलम, "is_isogram", में एक पूर्णांक वैल्यू डालिए:

* अगर वाक्यांश आइसोग्राम है तो 1,
* अगर नहीं है तो 0।

~~~~exercism/note
SQLite में तुलना के ऑपरेशन बूलियन वैल्यू को 0/1 संख्याओं के रूप में लौटाते हैं।

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
~~~~
