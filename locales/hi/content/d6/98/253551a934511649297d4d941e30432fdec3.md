# परिचय

[`function`][function] कोड को छोटे-छोटे हिस्सों में बाँटने का एक तरीका है, ताकि प्रोग्राम में एक या एक से अधिक जगहों से उसे नाम लेकर कॉल किया जा सके। फंक्शन का उपयोग खास और बार-बार दोहराए जाने वाले कामों को करने के लिए किया जाता है।

अधिक औपचारिक रूप से: फंक्शन Python का कोई भी ऐसा ऑब्जेक्ट है जिस पर [`function call`][calls] की क्रिया लागू की जा सकती है। किसी फंक्शन का उपयोग किसी क्रिया के परिणामस्वरूप एक या एक से अधिक वैल्यू [`return`][return] करने के लिए किया जा सकता है, या फिर इसका उपयोग एक या एक से अधिक [`side effects`][side effects] के लिए किया जा सकता है। अगर कोई फंक्शन रिटर्न वैल्यू तय नहीं करता, तो भी वह `None` लौटाता है।

नीचे साइड इफेक्ट वाले एक फंक्शन का उदाहरण दिया गया है:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

ऊपर के उदाहरण में [`def`][def] कीवर्ड फंक्शन की परिभाषा शुरू होने का संकेत देता है। `hello` फंक्शन का नाम है। खाली ब्रैकेट बताते हैं कि फंक्शन को कोई वैल्यू नहीं दी जा रही है। फंक्शन के अंदर का कोड अकेला `print("Hello")` स्टेटमेंट है। `print` भी एक फंक्शन है। `print` फंक्शन के ब्रैकेट में लिखा `"Hello"` एक [`argument`][arguments] कहलाता है। `print` फंक्शन इस आर्गुमेंट का उपयोग यह जानने के लिए करता है कि उसे क्या छापना है। ध्यान दीजिए कि फंक्शन के अंदर का कोड इंडेंट किया गया है। यह इंडेंटेशन ज़रूरी है, क्योंकि Python इसी के आधार पर जानता है कि कोड का वह ब्लॉक कहाँ खत्म होता है। फंक्शन के अंदर का कोड या तो प्रोग्राम के अंत में खत्म होता है, या ठीक उस अगली कोड लाइन से पहले जो इंडेंट _नहीं_ है। चूँकि `hello()` कोई `return` वैल्यू तय नहीं करता, इसलिए वह अपना साइड इफेक्ट पूरा करता है, यानी `print()` को कॉल करता है, और फिर `None` लौटाता है। अंत में, हम फंक्शन को उसका नाम और ब्रैकेट लगाकर कॉल करते हैं, जिससे Python इंटरप्रेटर को संकेत मिलता है कि यह नाम _कॉल करने योग्य_ है।

नीचे रिटर्न वैल्यू वाले एक फंक्शन का उदाहरण दिया गया है:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

इस फंक्शन के अंदर का कोड बदल दिया गया है: पहले वह `print` को _कॉल_ करता था, अब `string` "Hello" _लौटाता_ है। अंत में, कोड अब भी `"Hello"` ही छापता है, लेकिन यह साइड इफेक्ट `hello` फंक्शन के बजाय _कॉल करने वाले कोड_ में होता है। अगर `hello` फंक्शन को कॉल करते समय ब्रैकेट हटा दिए जाएँ (जैसे `print(hello)`), तो `print` कुछ ऐसा छापेगा:

```
<function hello at 0x0000026E18E93E20>
```

यह ज़रूरी है कि भले ही कोई फंक्शन कोई आर्गुमेंट न लेता हो (यानी उसके कोई पैरामीटर न हों), फिर भी उसे सही तरीके से _कॉल_ करने के लिए खाली ब्रैकेट लगाना ही होगा। यह Ruby जैसी भाषा से अलग है, जहाँ बिना किसी आर्गुमेंट वाले फंक्शन को कॉल करने के लिए खाली ब्रैकेट की ज़रूरत नहीं होती।

एक फंक्शन शून्य या उससे अधिक [`parameters`][parameters] घोषित कर सकता है। एक पैरामीटर तय करता है कि फंक्शन कौन-से आर्गुमेंट स्वीकार करता है।

नीचे आर्गुमेंट लेने वाले एक फंक्शन का उदाहरण दिया गया है:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

यहाँ पैरामीटर `name` के रूप में तय किया गया है। `"Bob"` वह आर्गुमेंट है जो प्रोग्राम `hello` फंक्शन को देता है। फंक्शन `string` "Hello, Bob" _लौटाता_ है।

अगर कोई `hello` को बिना कोई आर्गुमेंट दिए कॉल कर दे, तो क्या होगा? प्रोग्राम एक एरर देता है:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

अगर हम नहीं चाहते कि बिना आर्गुमेंट के प्रोग्राम एरर दे (पर यह चाहते हैं कि कॉल करने वाला कोड आर्गुमेंट न दे तो भी काम चले), तो हम एक [डिफ़ॉल्ट आर्गुमेंट][default arguments] तय कर सकते हैं। डिफ़ॉल्ट आर्गुमेंट तय करता है कि फंक्शन कॉल करते समय अगर आर्गुमेंट न दिया जाए तो कौन-सी वैल्यू उपयोग की जाए।

नीचे डिफ़ॉल्ट आर्गुमेंट वाले एक फंक्शन का उदाहरण दिया गया है:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

`name` पैरामीटर को `"you"` का डिफ़ॉल्ट आर्गुमेंट दिया गया है, इसलिए अगर `name` आर्गुमेंट न दिया जाए तो प्रोग्राम `Hello, you` छापता है।

फंक्शन आर्गुमेंट के बारे में अधिक जानने के लिए कृपया [फंक्शन आर्गुमेंट][function arguments] कॉन्सेप्ट देखिए।
