# निर्देश परिशिष्ट

## वर्ड

एक `linked-list-node` टुपल बनाइए।

एक `linked-list` टुपल बनाइए और `sequences` से आने वाला एक `M: linked-list length` मेथड भी दीजिए, ताकि टेस्ट आपकी लिस्ट पर सीधे `length` कॉल कर सकें।

- `<linked-list> ( -- linked-list )`: एक खाली लिस्ट बनाता है।
- `>linked-list ( seq -- linked-list )`: `seq` का हर एलिमेंट क्रम से एक नई लिस्ट पर डालता है।
- `linked-list>array ( linked-list -- array )`: वैल्यू लौटाता है, जिसमें लिस्ट के सबसे ऊपर वाली वैल्यू पहले आती है।
- `list-push ( linked-list value -- linked-list )`: एक वैल्यू को ऊपर डालता है।
- `list-pop ( linked-list -- linked-list value )`: ऊपर वाली वैल्यू हटाकर लौटाता है।
- `list-peek ( linked-list -- value )`: ऊपर वाली वैल्यू को हटाए बिना लौटाता है।
- `list-reverse ( linked-list -- linked-list )`: एक ऐसी लिस्ट लौटाता है जिसमें एलिमेंट उल्टे क्रम में हों।

जब लिस्ट खाली हो, तो `list-pop` और `list-peek` को `list-empty` एरर क्लास देनी चाहिए।
