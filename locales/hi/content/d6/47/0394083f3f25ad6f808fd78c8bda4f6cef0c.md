# अनाम फंक्शन और क्लोज़र के बारे में

PHP में आप एक फंक्शन के अंदर दूसरे फंक्शन घोषित कर सकते हैं। ऐसे फंक्शन को कोई नाम देने की ज़रूरत नहीं होती। इसे किसी वेरिएबल में असाइन किया जा सकता है, या सीधे किसी ऐसे फंक्शन को दिया जा सकता है जो एक फंक्शन पैरामीटर माँगता है।

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

ऊपर जो फंक्शन बनाया गया और `array_filter` को दिया गया, वह एक अनाम फंक्शन है। `array_filter` फंक्शन इसी की मदद से तय करता है कि ऐरे की दी गई वैल्यू `array_filter` के परिणाम में लौटाई जाएगी या नहीं। अगर फंक्शन किसी वैल्यू के लिए `true` लौटाता है, तो वह वैल्यू परिणाम वाले ऐरे में शामिल कर ली जाती है।

अनाम फंक्शन की मदद से फंक्शन के बाहर के स्कोप वाले वेरिएबलो को फंक्शन के अंदर से भी इस्तेमाल किया जा सकता है। जब फंक्शन का स्कोप अपने अंदर इस्तेमाल किए गए वेरिएबल पर इस तरह "बंद" हो जाता है, तो इसे "क्लोज़र" कहा जाता है। कुछ भाषाओं में स्कोप के सारे वेरिएबल क्लोज़र के अंदर अपने आप इस्तेमाल किए जा सकते हैं। PHP में `$this`, यानी वर्तमान ऑब्जेक्ट, क्लोज़र के अंदर अपने आप इस्तेमाल किया जा सकता है। बाकी सारे वेरिएबलो का `use` कीवर्ड की मदद से साफ-साफ संदर्भ देना पड़ता है।

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

ऊपर वाले फंक्शन `makeAdderFunction` में जो `$number` वैल्यू अंदर भेजी जाती है, वह अंदर बनाए गए अनाम फंक्शन पर "बंद" कर दी जाती है, और फिर वही फंक्शन लौटाया जाता है। इसके बाद जब भी वह फंक्शन चलाया जाता है, उसे पता होता है कि अंदर भेजी गई `$number` की वैल्यू क्या थी। अगर आप इस फंक्शन को किसी दूसरी संख्या के साथ फिर से कॉल करें, तो आपको एक बिल्कुल अलग फंक्शन मिलेगा। इससे पहले वाले फंक्शन कॉल की वैल्यू या उसका काम नहीं बदलेगा।
अगर आपको एक से ज़्यादा वेरिएबल पर क्लोज़ करना है, तो उन्हें `use` कीवर्ड में कॉमा से अलग करके लिखा जा सकता है।

PHP में एक छोटा फंक्शन सिंटैक्स भी है, जिसे `arrow functions` कहा जाता है। इन्हें काफी सरल होना ज़रूरी है। इनका मूल रूप यह है:

```php
fn(arguments) => expression
```

इस फंक्शन शैली में आपको `use` इस्तेमाल करने की ज़रूरत नहीं होती। यह पैरेंट स्कोप की सारी वैल्यू अपने आप कैप्चर कर लेता है और उन पर क्लोज़ कर लेता है। इन एरो फंक्शन के एक्सप्रेशन अपने आप लौटा दिए जाते हैं, `return` कीवर्ड इस्तेमाल करने की ज़रूरत नहीं पड़ती। इसी वजह से हम ऊपर वाले `onlyOdds` फंक्शन को इस तरह फिर से लिख सकते हैं:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

ऊपर वाले `makeAdderFunction` को इस तरह फिर से लिखा जा सकता है:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**ध्यान दें:** अगर फंक्शन को एक्सप्रेशन के रूप में नहीं लिखा जा सकता, तो छोटे एरो फंक्शन सिंटैक्स का इस्तेमाल नहीं किया जा सकता।

अनाम फंक्शन और क्लोज़र को वेरिएबल वैल्यू के रूप में दिए जाते हैं और उनके अंदर वैल्यू के रूप में ही इस्तेमाल होते हैं। इसका मतलब है कि अगर आप फंक्शन के अंदर वेरिएबल की वैल्यू बदलते हैं, तो फंक्शन के बाहर वाले वेरिएबल की वैल्यू पर इसका कोई असर नहीं पड़ेगा। अगर आपको वैल्यू में बदलाव चाहिए, तो उसे संदर्भ के रूप में भेजा जा सकता है।

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

ऊपर के उदाहरण में `array_walk` ऐरे के हर एलिमेंट पर एक-एक करके चलता है और हर वैल्यू को कॉल में घोषित फंक्शन तक भेजता है। यह `$total` में चलता हुआ कुल योग रखता है, जिसमें हर बार जोड़ी जाने वाली वैल्यू संख्या का निरपेक्ष मान होती है। यह इस बात का हिसाब भी रखता है कि कितनी संख्याएँ थीं। दोनों वैल्यू क्लोज़र में संदर्भ के रूप में इस्तेमाल होती हैं, जिसे `use` वाले हिस्से में हर वेरिएबल के आगे लगे `&` से दिखाया गया है। इसका मतलब है कि `array_walk` पूरा होने पर भी वेरिएबलो में हुए बदलाव बने रहेंगे, ताकि फंक्शन ऐरे की संख्याओं के निरपेक्ष मानों का औसत लौटा सके।

अनाम फंक्शन और क्लोज़र किसी ऐसे फंक्शन को बनाने का सुविधाजनक तरीका देते हैं जिसकी ज़रूरत शायद सिर्फ एक ही जगह पड़े। इनकी मदद से ऐसा फंक्शन भी बनाया जा सकता है जो कुछ पैरामीटर के आधार पर एक डायनैमिक फंक्शन लौटाता है, जिनकी वैल्यू किसी और समय ज्ञात होती है, न कि उस समय जब फंक्शन असल में इस्तेमाल होता है।
