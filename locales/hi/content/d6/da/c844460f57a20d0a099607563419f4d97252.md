# परिचय

Factor में एक *कोटेशन*, यानी `[ ]` ब्रैकेट के अंदर लिखा कोड, खुद एक वैल्यू होता है, बिल्कुल किसी संख्या या स्ट्रिंग की तरह। आप एक कोटेशन किसी वेरिएबल में संग्रहीत कर सकते हैं, किसी ऐरे में रख सकते हैं, किसी दूसरे वर्ड को पास कर सकते हैं, और बाद में उसे *call* कर सकते हैं।

## `call`

`call` (जो [`kernel`][kernel] में है) एक कोटेशन चलाता है:

```factor
3 4 [ + ] call .
! => 7
```

जब आप किसी कोटेशन को ऐसी जगह `call` करते हैं जहाँ Factor उसका स्टैक इफेक्ट नहीं समझ पाता, तो आपको इफेक्ट साफ-साफ घोषित करना होगा:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

इससे एक रनटाइम जाँच कंपाइल होती है, जो देखती है कि कोटेशन में घोषित इफेक्ट वाकई है।

## सीक्वेंस में कोटेशन

चूँकि कोटेशन भी वैल्यू हैं, एक ऐरे में संख्याएँ और कोटेशन दोनों रखे जा सकते हैं:

```factor
{ 3 4 [ + ] }
```

इससे "एक प्रोग्राम" एक साधारण सीक्वेंस बन जाता है, और उसे चलाने का स्वाभाविक तरीका `each` बन जाता है:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## सीक्वेंस के अंत से हिस्सा निकालना

`head*` अंतिम `n` एलिमेंट को छोड़कर बाकी सब कुछ लौटाता है; `last2` अंतिम दो लौटाता है:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

`suffix` के साथ मिलाकर, "ऊपर के दो एलिमेंट लेकर एक नतीजा ऊपर रखने" वाला स्टैक ऑपरेशन लिखने के लिए इतना ही काफी है।
