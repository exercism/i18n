# बूलियन

Crystal में एक टाइप होता है जिसे [`Bool`][bools] कहते हैं।
यह `true` और `false` वैल्यू को दर्शाता है।

## लॉजिकल ऑपरेटर

Crystal में तीन लॉजिकल ऑपरेटर हैं (`!`, `||`, `&&`)। ये बूलियन को मिलाकर ऐसे एक्सप्रेशन बनाते हैं जो अलग-अलग वैल्यू देते हैं।

### और(`&&`)

Crystal में [_और_ ऑपरेटर][and] को `&&` से दर्शाया जाता है। अगर दोनों वैल्यू `true` हों तो यह `true` लौटाता है; वरना यह `false` लौटाता है।
_और_ ऑपरेटर का उपयोग करते समय एक बूलियन `&&` के दाईं ओर और दूसरा बाईं ओर रखा जाता है।

```crystal
true && true
# => true

true && false
# => false
```

### या(`||`)

Crystal में [_या_ ऑपरेटर][or] को `||` से दर्शाया जाता है। अगर दी गई वैल्यू में से **कम से कम एक** `true` हो तो यह `true` लौटाता है।
अगर दोनों वैल्यू `false` हों तो यह `false` लौटाता है।
_या_ ऑपरेटर का उपयोग करते समय एक बूलियन `||` के दाईं ओर और दूसरा बाईं ओर रखा जाना चाहिए।

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### नहीं(`!`)

Crystal में _नहीं_ ऑपरेटर को `!` से दर्शाया जाता है। अगर दिया गया बूलियन `false` हो तो यह `true` लौटाता है, और अगर `true` दिया गया हो तो `false` लौटाता है।
_नहीं_ ऑपरेटर का उपयोग करते समय एक बूलियन ऑपरेटर (`!`) के बाद रखा जाना चाहिए।

```crystal
!true
# => false

!false
# => true
```

## गोल ब्रैकेट(`()`) का उपयोग

बूलियन के साथ काम करते समय आप गोल ब्रैकेट का उपयोग यह तय करने के लिए कर सकते हैं कि पहले किस बूलियन का मूल्यांकन होगा।
गोल ब्रैकेट का उपयोग कैसे किया गया है, उसके आधार पर परिणाम अलग हो सकता है।
Crystal में गोल ब्रैकेट के अंदर जो होता है, उसका मूल्यांकन पहले होता है।

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

चूँकि गोल ब्रैकेट के अंदर जो होता है उसका मूल्यांकन पहले होता है, नीचे के उदाहरण में _नहीं_ ऑपरेटर गोल ब्रैकेट के अंदर वाले एक्सप्रेशन पर लागू होगा।

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
गोल ब्रैकेट सिर्फ तब इस्तेमाल कीजिए जब वे परिणाम को बदलते हों; वरना उन्हें छोड़ दीजिए।
~~~~
