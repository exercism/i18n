# परिचय

Java का `char` प्रिमिटिव टाइप एक यूनिकोड अक्षर का 16 बिट प्रतिनिधित्व है।

~~~~exercism/note
`char` टाइप [मूल यूनिकोड स्पेसिफिकेशन][unicode-specification] पर आधारित है, जिसमें अक्षरों को दर्शाने के लिए 16 बिट का उपयोग किया गया था।
यह ज़्यादातर सामान्य अक्षरों को कवर करने के लिए पर्याप्त है और 0x0000 से 0xFFFF तक की रेंज के अक्षरों को कवर करता है।
इसके बाद स्पेसिफिकेशन ने संभावित अक्षरों की रेंज को 0x01FFFF तक बढ़ा दिया है।

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

कई `char` मिलकर एक स्ट्रिंग बना सकते हैं, जैसे `"word"`, या `char` को अलग-अलग संभाला जा सकता है।
`char` लिटरल को सिंगल कोट्स से घेरा जाता है (जैसे `'A'`)।

```java
char lowerA = 'a';
char upperB = 'B';
```

## एक `String` के `char` प्राप्त करना

`String.toCharArray` मेथड एक स्ट्रिंग के `char` को ऐरे के रूप में लौटाता है।
जैसा कि [ऐरे][concept-arrays] में बताया गया है, आप ऐरे के हर एलिमेंट पर एक-एक करके जाने के लिए `for` लूप का उपयोग कर सकते हैं।

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## [Character][docs-character] क्लास

`char` को जाँचने और बदलने के लिए लाइब्रेरी में कई बिल्ट-इन मेथड मौजूद हैं।
ये [`java.lang.Character`][docs-character] क्लास के स्टैटिक मेथड के रूप में मिलते हैं।
यहाँ कुछ उदाहरण दिए गए हैं:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Character क्लास के कुछ मेथड में ओवरलोड होता है ताकि वे `char` या `int` दोनों में से कोई एक ले सकें।
उदाहरण के लिए, `isDigit` में एक ओवरलोड है जो [`char`][is-digit-char] लेता है, और दूसरा जो [`int`][is-digit-int] लेता है।
जैसा कि पहले बताया गया, `char` टाइप केवल 0x0000 से 0xFFFF तक की रेंज के अक्षरों को ही दर्शा सकता है।
लेकिन `int` सभी अक्षरों को दर्शा सकता है, इसीलिए `int` वाले ओवरलोड मौजूद हैं।

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## एक `String` में `char` जोड़ना

`+` ऑपरेटर का उपयोग एक `String` में `char` जोड़ने के लिए किया जा सकता है।

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
ध्यान रखें: दो `char` को जोड़कर एक `String` बनाने के लिए `+` का उपयोग _नहीं_ करें!
इस तरह दो `char` जोड़ने पर `int` मिलता है, `String` _नहीं_!
उदाहरण के लिए:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

इसका कारण यह है कि Java `char` को `int` में प्रोमोट कर देता है ([Java Language Specification][jls-main] के [4.2 प्रिमिटिव टाइप और वैल्यू ][jls-primitives] देखें)।

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

लेकिन जब जोड़ने के लिए बहुत सारे अक्षर हों, तो इसके बजाय [`StringBuilder`][docs-stringBuilder] का उपयोग करना ज़्यादा कुशल हो सकता है:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
