# टेस्ट

टेस्ट चलाने की कोशिश करने से पहले, इंस्टॉलेशन के चरणों का पालन करके यह सुनिश्चित कीजिए कि असाइनमेंट फोल्डर ठीक से सेट-अप हो गया है, यानी `corepack yarn install` और Editor SDK सेटअप।

टेस्ट इस तरह चलाइए:

```bash
$ corepack yarn test
```

यह सुनिश्चित कीजिए कि आपका कोड बेस्ट प्रैक्टिसेस का पालन करता है, जैसा कि दूसरे यूज़र करते हैं। इसके लिए eslint इस्तेमाल कीजिए, जो आपके कोड का स्टैटिक एनालिसिस करने वाला टूल है। ऐसे टूल आपके कोड में टाइपो या छोटी-मोटी गलतियाँ ढूँढने में आपका कुछ समय बचाते हैं:

```bash
$ corepack yarn lint
```

या दोनों काम एक साथ कीजिए:

```bash
$ corepack yarn test && corepack yarn lint
```

Exercism पर TypeScript ट्रैक कोड की _स्टाइल_ को अनिवार्य नहीं बनाता, इसलिए आप सेमीकोलन, टैब बनाम स्पेस, और इनके बीच के हर तरीके में से जो चाहें चुन सकते हैं।

## अपना पहला मॉड्यूल बनाइए

आम तौर पर इस ट्रैक के टेस्ट आपके इम्प्लीमेंटेशन को एक मॉड्यूल के रूप में इम्पोर्ट करके लोड करते हैं: `import Bob from './bob';`.
इसे काम कराने के लिए आपको अपना इम्प्लीमेंटेशन उस फाइल से एक्सपोर्ट करना होगा जिसमें टेस्ट आपका मॉड्यूल ढूँढते हैं, यानी `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

हमने हर अभ्यास में स्टब दिए हैं और यह `export` आपके लिए उनमें रख दिया है।
