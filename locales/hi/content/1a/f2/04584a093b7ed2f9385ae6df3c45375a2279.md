# निर्देश

इस अभ्यास में आप ऐसा कोड लिखेंगे जो उन प्रोग्रामिंग भाषाओं का हिसाब रखेगा जिन्हें आप Exercism पर सीखना चाहते हैं। यहाँ छह कार्य हैं, और हर कार्य में आपको ऐरे से काम करना है।

## 1. नया ऐरे बनाइए

जिन भाषाओं को आप सीखना चाहते हैं उनका हिसाब रखने के लिए आपको एक नया ऐरे बनाना होगा। `newList` नाम का कॉन्स्टेंट बनाइए जिसमें एक नया, खाली ऐरे हो।

```elm
newList
    --> []
```

## 2. मौजूदा ऐरे के लिए कॉन्स्टेंट बनाइए

अभी आपके पास एक कागज़ है जिस पर वे भाषाएँ लिखी हैं जो आप सीखना चाहते हैं: Elm, Clojure और Haskell। इस ऐरे को दर्शाने के लिए `existingList` कॉन्स्टेंट बनाइए।

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. ऐरे में नई भाषा जोड़िए

जैसे-जैसे आप Exercism पर घूमते हैं और नई दिलचस्प भाषाएँ ढूँढते हैं, आप उन्हें अपने ऐरे में जोड़ना चाहते हैं। अपने ऐरे के शुरू में नई भाषा जोड़ने के लिए `addLanguage` फंक्शन बनाइए।

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. ऐरे में भाषाओं की गिनती कीजिए

भाषाओं को हाथ से गिनना सुविधाजनक नहीं है। अपने ऐरे में मौजूद भाषाओं की संख्या गिनने के लिए `countLanguages` फंक्शन बनाइए।

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. ऐरे को उल्टा कीजिए

एक समय ऐसा भी आता है जब आपको एहसास होता है कि आपका ऐरे वास्तव में उल्टे क्रम में है! अपने ऐरे को उल्टा करने के लिए `reverseList` फंक्शन बनाइए।

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. जाँचिए कि ऐरे रोमांचक है या नहीं

आपको सभी भाषाएँ पसंद हैं, लेकिन Elm का स्थान आपके दिल में खास है। इसलिए आप भाषाओं की ऐसी ऐरे से बहुत उत्साहित होते हैं जिसमें:

- ऐरे का पहला एलिमेंट Elm हो।
- या ऐरे का दूसरा एलिमेंट Elm हो और ऐरे में तीन या उससे कम भाषाएँ हों।

भाषाओं का कोई ऐरे रोमांचक है या नहीं, यह जाँचने के लिए `excitingList` फंक्शन बनाइए:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
