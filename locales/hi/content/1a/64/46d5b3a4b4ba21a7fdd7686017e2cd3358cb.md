# डीबगिंग

डीबगिंग में मदद के लिए आप यह बात ध्यान में रख सकते हैं कि कंसोल का सारा आउटपुट कैप्चर किया जाता है और टेस्ट के परिणामों की विंडो में दिखाया जाता है।
आप किसी भी वैल्यू को `@show` को पास करके दिखा सकते हैं।

`@show` एक एक्सप्रेशन और उसका परिणाम दिखाता है, और साथ ही वही परिणाम लौटाता भी है।

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

आप [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) या किसी और ऐसे मेथड का भी इस्तेमाल कर सकते हैं जो आउटपुट [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)) पर लिखता है।
