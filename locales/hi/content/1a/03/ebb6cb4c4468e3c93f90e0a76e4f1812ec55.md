# निर्देश

इस अभ्यास में आपको एक ऐसा प्रोग्राम बनाना है जो बताता है कि [टिक-टैक-टो][tic-tac-toe] के किसी खेल की स्थिति क्या है।
(_आप इस खेल को "noughts and crosses" या "Xs and Os" के नाम से भी जानते होंगे।_)

यह खेल 3×3 के ग्रिड पर खेला जाता है।
खिलाड़ी बारी-बारी से ग्रिड पर `X` और `O` रखते हैं।
खेल तब खत्म होता है जब कोई एक खिलाड़ी एक ही पंक्ति, स्तंभ या ग्रिड के किसी विकर्ण पर तीन चिह्न लगाकर जीत जाए, या जब पूरा ग्रिड भर जाए।

इस अभ्यास में हम मान लेंगे कि खेल की शुरुआत `X` से होती है।

आपको यह पता लगाना है कि दिया गया खेल किस स्थिति में है।

खेल की तीन संभावित स्थितियाँ हैं:

- खेल **ongoing** है।
- खेल **draw** पर खत्म हुआ।
- खेल **win** पर खत्म हुआ।

अगर दिया गया बोर्ड अमान्य है, तो एक उपयुक्त एरर फेंकिए।

अगर कोई बोर्ड इन शर्तों को पूरा करता है, तो वह अमान्य है:

- बारी सही क्रम में लेने पर दिए गए बोर्ड तक पहुँचा ही नहीं जा सकता (याद रखिए कि शुरुआत `X` से होती है)।
- खेल खत्म हो चुकने के बाद भी खेला गया है।

## उदाहरण

### चल रहा खेल

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### बराबरी

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### जीत

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### अमान्य

#### बारी का गलत क्रम

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### जीत के बाद भी खेलना जारी रखना

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
