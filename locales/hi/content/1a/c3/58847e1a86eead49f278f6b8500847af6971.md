# संकेत

## सामान्य

- `MACRO:` [`macros`][macros] में है। इसके बुनियादी टुकड़े `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`, `<repetition>`, `map`) और `quotations` (`>quotation`) में रहते हैं।
- मैक्रो के बॉडी को स्टैक पर **एक ही क्वोटेशन** छोड़ना चाहिए। अगर आपका बॉडी कोड का ऐरे बनाता है, तो अंत में `>quotation` लगाइए।
- अपनी सोच जाँचने के लिए बॉडी के शब्दों को लिसनर में किसी लिटरल पर चलाइए और जो क्वोटेशन वापस मिलता है उसे देखिए। वह कार्य की "compiles to" पंक्ति वाला सीधा कोड ही होना चाहिए।

## 1. दो बार

- आपको `[ A ]` मिलता है और आपको `[ A A ]` चाहिए। एक कॉपी बनाइए और दोनों को जोड़ दीजिए: `dup append`.

## 2. N बार दोहराव

- आपको `[ A ] n` मिलता है और आपको `n` कॉपियाँ जोड़कर एक बनानी हैं।
- `<repetition>` कॉपियाँ बनाता है, लेकिन वह इस तरह काम करता है: `( length elt -- repetition )`। यानी गिनती स्टैक में सबसे ऊपर होनी चाहिए, इसलिए पहले `swap` कीजिए।
- फिर उन्हें समतल करके बदल दीजिए: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. कई क्वोटेशन जोड़ना

- आपको क्वोटेशन का ऐरे पहले से मिल जाता है; आपको उसे समतल करके एक बनाना है। पूरा बॉडी बस `concat >quotation` है।

## 4. अनरोल्ड इटरेशन

आपको एक सीक्वेंस और एक क्वोटेशन मिलते हैं, जैसे `{ 10 20 30 } [ + ]`, और आपको `[ 10 + 20 + 30 + ]` चाहिए। इसे तीन चरणों में बनाइए।

**एक एलिमेंट।** किसी एलिमेंट को क्वोटेशन के अंदर पहले से डाल देना ही `curry` का काम है:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**हर एलिमेंट।** आप उसे सीक्वेंस पर `map` करना चाहते हैं, लेकिन `map` मैपिंग क्वोटेशन को सिर्फ एक ही इनपुट (एलिमेंट) देता है, जबकि आपको हर बार `[ + ]` भी पास रखना है। इसलिए पहले `[ + ]` को मैपिंग क्वोटेशन के अंदर डालिए, वह भी `curry` से:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` का मतलब है "छोटा क्वोटेशन `[ curry ]` स्टैक पर डालिए, फिर उसमें `[ + ]` को curry कीजिए", जिससे `[ [ + ] curry ]` मिलता है। इसे किसी एलिमेंट `e` पर मैप करने से `e [ + ] curry` चलता है, यानी `[ e + ]`.

**इन्हें जोड़िए।** बाकी कार्यों की तरह ही अंत कीजिए:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- पूरा बॉडी: `[ curry ] curry map concat >quotation`.
