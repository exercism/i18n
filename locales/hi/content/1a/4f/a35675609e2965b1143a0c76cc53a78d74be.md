# परिचय
## Switch

एक [switch स्टेटमेंट][switch] की मदद से आप एक वैल्यू की तुलना कई संभावित वैल्यूओं से कर सकते हैं, जिनसे वह मेल खा सकती है।
यह आपको कई `else-if` स्टेटमेंट इस्तेमाल करने की तुलना में ज़्यादा संक्षिप्त कोड लिखने देता है।
एक switch स्टेटमेंट `switch` कीवर्ड से शुरू होता है, जिसके बाद वह वैल्यू आती है जिसकी तुलना करनी है।
इसके बाद आप `case` कीवर्ड से केस बनाते हैं, जिसके बाद वह वैल्यू आती है जिससे तुलना करनी है।
जब कोई भी केस मेल न खाए, तो डिफॉल्ट केस बनाने के लिए `default` कीवर्ड इस्तेमाल किया जाता है।
`else-if` स्टेटमेंट की तरह, `switch` स्टेटमेंट भी सिर्फ पहले मेल खाने वाले केस से जुड़ा कोड ब्लॉक ही चलाता है।

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

इस उदाहरण को देखिए:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

इसके बजाय इसे ऐसे लिखा जा सकता है:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## `while` लूप

एक [`while` लूप][while-loops] एक नियंत्रण प्रवाह स्टेटमेंट है, जिससे कोड तब तक चलाया जा सकता है जब तक कोई शर्त सही रहती है।
Swift दो तरह के `while` लूप देता है: `while` लूप और `repeat-while` लूप।
`while` लूप की शर्त का मूल्यांकन लूप के अंदर का कोड चलने से पहले होता है; अगर शर्त गलत है, तो लूप के अंदर का कोड बिल्कुल नहीं चलेगा।
Swift में `while` लूप का ढाँचा इस तरह होता है:

```swift
while <#condition#> {
  <#code#>
}
```

यहाँ लूप तब तक चलेगा जब तक count 0 से बड़ा रहता है, और इस तरह वह संख्याएँ 2, 1 और "Liftoff!" छापेगा।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

एक [`repeat-while` लूप][while-loops] `while` लूप जैसा ही होता है, लेकिन इसमें शर्त का मूल्यांकन लूप के अंदर का कोड चलने के बाद होता है।
इसका मतलब है कि लूप के अंदर का कोड हमेशा कम से कम एक बार चलेगा, भले ही शर्त गलत हो।
Swift में `repeat-while` लूप का ढाँचा इस तरह होता है:

```swift
repeat {
  <#code#>
} while <#condition#>
```

यहाँ लूप सिर्फ एक बार चलेगा, क्योंकि शर्त गलत है।
चूँकि यह `repeat-while` लूप है, शर्त का मूल्यांकन होने से पहले लूप के अंदर का कोड एक बार चल चुकेगा।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## नियंत्रण हस्तांतरण

Swift में कुछ स्टेटमेंट हैं जिनसे लूप के सामान्य नियंत्रण प्रवाह को बदला जा सकता है।
इन्हें नियंत्रण हस्तांतरण स्टेटमेंट कहा जाता है।
आप `return` पहले ही देख चुके हैं; यह कॉन्सेप्ट कुछ और स्टेटमेंट से मिलवाएगा, जिनमें `continue`, `break` और लेबल शामिल हैं।
इस कॉन्सेप्ट में हम `fallthrough` को नहीं समझाएँगे, लेकिन आप इसके बारे में [Swift की किताब][fallthrough] में पढ़ सकते हैं।

### Continue

कभी-कभी लूप के मौजूदा इटरेशन के बाकी स्टेटमेंट पूरे किए बिना ही सीधे अगले इटरेशन पर पहुँचना ज़रूरी हो जाता है।
इसके लिए `continue` कीवर्ड इस्तेमाल किया जा सकता है।
जब `continue` चलाया जाता है, तो लूप सीधे अगली जाँच पर पहुँच जाता है ताकि देखा जा सके कि लूप का अगला इटरेशन चल सकता है या नहीं, यानी `while` और `repeat-while` लूप में `while` की जाँच, या `for-in` लूप में यह जाँच कि सीक्वेंस में कोई और एलिमेंट है या नहीं।

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

`break` का इस्तेमाल लूप से जल्दी बाहर निकलने के लिए किया जाता है।
जब `break` चलाया जाता है, तो लूप तुरंत खत्म हो जाता है और प्रोग्राम लूप के बाद वाले पहले स्टेटमेंट से आगे बढ़ जाता है।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### लेबल

जब लूप नेस्टेड होते हैं, तो कभी-कभी ऐसा होता है कि आप `break` या `continue` का इस्तेमाल करके उन बाहरी लूपों से बाहर निकलना या उन्हें फिर से शुरू करना चाहते हैं जिनके अंदर वह लूप है जिसमें `break` या `continue` इस्तेमाल किया गया है।
ऐसे मामलों में लेबल का इस्तेमाल करके यह बताया जा सकता है कि किस लूप से बाहर निकलना है या किस लूप को फिर से शुरू करना है।
किसी लूप को लेबल देने के लिए उस लूप को शुरू करने वाले `while`, `repeat` या `for` से पहले एक नाम और उसके बाद कोलन लगाया जाता है।

इस तरह लेबल इस्तेमाल करने का असर देखने के लिए इस लूप को देखिए:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
