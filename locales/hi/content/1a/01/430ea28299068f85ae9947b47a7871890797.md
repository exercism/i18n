# बूलियन वैल्यू की true या false से तुलना न कीजिए

बूलियन वैल्यू की true या false से तुलना करना अनावश्यक है।
`==` इस्तेमाल करने पर एक बूलियन वैल्यू बनती है, इसलिए उसकी तुलना किसी और हार्डकोडेड बूलियन वैल्यू से करने की ज़रूरत नहीं है।
अगर आप बूलियन वैल्यू को उलटना चाहते हैं, तो `!` ऑपरेटर का इस्तेमाल कीजिए।

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
