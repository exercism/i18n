# निर्देश

आप एक शिक्षक हैं।
साल के अंत में आपने अपने हर छात्र के लिए एक संख्यात्मक ग्रेड तैयार किया है।
अब आपको उसे अक्षर ग्रेड में बदलना है और यह गिनना है कि हर अक्षर ग्रेड कितने छात्रों ने पाया है।

## 1. संख्यात्मक ग्रेड को अक्षर ग्रेड में बदलिए

`letter_grade` फंक्शन एक संख्यात्मक ग्रेड लेता है और बदले में अक्षर ग्रेड लौटाता है।
इन रेंजों का उपयोग कीजिए:

| अक्षर |      ग्रेड |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

उदाहरण:

```jq
75 | letter_grade   # => "C"
```

## 2. हर अक्षर ग्रेड के लिए छात्रों की संख्या गिनिए

`count_letter_grades` फंक्शन एक ऑब्जेक्ट लेता है जिसमें हर छात्र का नाम उसके ग्रेड से जुड़ा होता है।
यह एक ऑब्जेक्ट लौटाता है जिसमें हर अक्षर ग्रेड के सामने उस ग्रेड वाले छात्रों की संख्या होती है।

उदाहरण:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

इसे हल करने के कुछ अलग-अलग तरीके हैं।
अभ्यास के लिए `reduce` फिल्टर का उपयोग कीजिए।
