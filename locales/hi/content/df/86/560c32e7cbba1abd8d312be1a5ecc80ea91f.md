# निर्देश

आपकी डीएनए शोध प्रयोगशाला में आप अपने शोध डेटा को स्टोरेज की जगह बचाने के लिए कंप्रेस करने के अलग-अलग तरीके आज़मा रहे हैं। आपके एक साथी का सुझाव है कि डीएनए डेटा को बाइनरी रूप में बदल दिया जाए:

| न्यूक्लिक अम्ल | कोड  |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

आप इस पर सोचते हैं। इससे ज़रूरी डेटा स्टोरेज की लागत घट सकती है, लेकिन इंसानों के लिए डेटा पढ़ना मुश्किल हो जाएगा। आप तय करते हैं कि एक मॉड्यूल लिखेंगे जो आपके डेटा को एनकोड और डिकोड करे, ताकि आप अपनी बचत को माप सकें।

## 1. न्यूक्लिक अम्ल को बाइनरी वैल्यू में एनकोड कीजिए

`encode_nucleotide` बनाइए। यह एक न्यूक्लियोटाइड लेता है और एनकोड किए गए कोड की पूर्णांक वैल्यू लौटाता है।

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. बाइनरी वैल्यू को न्यूक्लिक अम्ल में डिकोड कीजिए

`decode_nucleotide` बनाइए। यह एनकोड किए गए कोड की पूर्णांक वैल्यू लेता है और न्यूक्लियोटाइड लौटाता है।

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. डीएनए ऐरे को एनकोड कीजिए

`encode` बनाइए। यह न्यूक्लियोटाइड का ऐरे लेता है और एनकोड किए गए डेटा का बिट ऐरे लौटाता है।

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. डीएनए बिट ऐरे को डिकोड कीजिए

`decode` बनाइए। यह न्यूक्लिक अम्ल को दर्शाने वाला बिट ऐरे लेता है और डिकोड किए गए डेटा को न्यूक्लियोटाइड के ऐरे के रूप में लौटाता है।

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
