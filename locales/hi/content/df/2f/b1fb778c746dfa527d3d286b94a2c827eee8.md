# निर्देश

आपको पक्षी देखना बहुत पसंद है और आप यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए।

आपके सामने छह काम हैं, और ये सब आपके बगीचे में आने वाले पक्षियों की संख्याओं से जुड़े हैं।

## 1. जाँचिए कि पिछले हफ्ते की गिनती क्या थी

तुलना के लिए आप हमेशा पिछले हफ्ते की गिनती की एक कॉपी पास रखते हैं, जो यह थी: 0, 2, 5, 3, 7, 8 और 4। `BirdWatcher.getLastWeek()` मेथड बनाइए, जो पिछले हफ्ते की गिनती लौटाता है:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. जाँचिए कि आज कितने पक्षी आए

`BirdWatcher.getToday()` मेथड बनाइए। यह लौटाता है कि आज आपके बगीचे में कितने पक्षी आए। पक्षियों की गिनती दिन के क्रम में रखी जाती है, जिसमें पहला एलिमेंट सबसे पुराने दिन की गिनती है और अंतिम एलिमेंट आज की गिनती है।

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. आज की गिनती बढ़ाइए

`BirdWatcher.incrementTodaysCount()` मेथड बनाइए, जो आज की गिनती बढ़ाता है:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. जाँचिए कि क्या कोई ऐसा दिन था जब एक भी पक्षी नहीं आया

`BirdWatcher.hasDayWithoutBirds()` मेथड बनाइए। यह `true` लौटाता है अगर कोई एक दिन भी ऐसा था जब बगीचे में एक भी पक्षी नहीं आया; नहीं तो `false` लौटाता है:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. शुरू के कुछ दिनों में आए पक्षियों की संख्या निकालिए

`BirdWatcher.getCountForFirstDays()` मेथड बनाइए, जो हफ्ते की शुरुआत से आपके बगीचे में आए पक्षियों की संख्या लौटाता है। लेकिन गिनती को हफ्ते की शुरुआत से दिए गए दिनों की संख्या तक ही सीमित रखिए।

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरों से ज़्यादा व्यस्त होते हैं। व्यस्त दिन वह होता है जब आपके बगीचे में पाँच या उससे अधिक पक्षी आए हों। `BirdWatcher.getBusyDays()` मेथड बनाइए, जो व्यस्त दिनों की संख्या लौटाता है:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
