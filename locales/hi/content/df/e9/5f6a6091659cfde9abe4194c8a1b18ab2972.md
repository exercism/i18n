# परिचय

Elm में टेक्स्ट दर्शाने का आधार अक्षर और स्ट्रिंग ही हैं।
स्ट्रिंग को अक्षरों के ऐरे की तरह देखा जा सकता है, और `List` के ज़्यादातर फंक्शन का बराबर वाला रूप `String` मॉड्यूल में मौजूद है।

## अक्षर

`Char` टाइप सिंगल कोट्स के बीच एक ही यूनिकोड अक्षर दर्शाता है, जैसे `'a'`.
`Char` मॉड्यूल में अक्षर के गुण जाँचने के लिए शर्त वाले फंक्शन (`Char -> Bool`) मिलते हैं: `isUpper`, `isLower`, `isAlpha` और `isAlphaNum`.
इसी मॉड्यूल में अक्षर को `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower` से बदलने के फंक्शन भी हैं, और `toCode` तथा `fromCode` की मदद से अक्षर को उसकी संख्यात्मक यूनिकोड वैल्यू (`Int`) में या उससे वापस बदला जा सकता है।

## स्ट्रिंग

`String` टाइप स्ट्रिंग को कुशलता से संभालने का पहले से मौजूद तरीका देता है, और यूनिकोड अक्षरों के किसी भी क्रम को दर्शा सकता है।
स्ट्रिंग डबल कोट्स के बीच लिखी जाती है: `"this is a string"`.
कई लाइनों वाली स्ट्रिंग तीन डबल कोट्स के बीच लिखी जाती है, और इनमें कोट्स तथा नई लाइनों को एस्केप करने की ज़रूरत नहीं पड़ती।

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## स्ट्रिंग के साथ काम करना

`reverse : String -> String` स्ट्रिंग को उलट देता है।
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` किसी स्ट्रिंग को n बार दोहराता है।
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` दी गई सबस्ट्रिंग की सारी जगहों को बदल देता है।
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` दो स्ट्रिंग जोड़ देता है।
इसके लिए `++` ऑपरेटर का भी इस्तेमाल किया जा सकता है।
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` स्ट्रिंग के ऐरे को जोड़कर एक ही स्ट्रिंग बना देता है।
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` स्ट्रिंग को दिए गए सेपरेटर पर तोड़कर स्ट्रिंग के ऐरे में बदल देता है।
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` स्ट्रिंग के ऐरे को दिए गए सेपरेटर के साथ जोड़कर एक स्ट्रिंग बना देता है।
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` स्ट्रिंग को खाली जगह के हिस्सों पर तोड़कर स्ट्रिंग के ऐरे में बदल देता है।
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` स्ट्रिंग को नई लाइनों पर तोड़कर लाइनों के ऐरे में बदल देता है।
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` स्ट्रिंग के शुरू में एक अक्षर जोड़ देता है।
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` किसी खाली न होने वाली स्ट्रिंग को उसके पहले अक्षर और बाकी हिस्से में बाँट देता है।
इससे आप स्ट्रिंग पर ठीक वैसे ही पैटर्न मैच कर सकते हैं जैसे ऐरे पर करते हैं।
खाली स्ट्रिंग के लिए यह `Nothing` लौटाता है।
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## सबस्ट्रिंग निकालना

`slice : Int -> Int -> String -> String` शुरुआती और अंतिम इंडेक्स देकर एक सबस्ट्रिंग निकालता है।
ऋणात्मक इंडेक्स ऐरे के अंत से गिने जाते हैं।
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` और `right : Int -> String -> String` क्रमशः स्ट्रिंग के बाएँ या दाएँ से n अक्षर निकालते हैं।

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` और `dropRight : Int -> String -> String` क्रमशः स्ट्रिंग के बाएँ या दाएँ से n अक्षर हटा देते हैं।
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## स्ट्रिंग के गुणों की जाँच

`length : String -> Int` स्ट्रिंग में अक्षरों की संख्या लौटाता है।
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` बताता है कि स्ट्रिंग खाली है या नहीं।
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` जाँचता है कि दूसरी स्ट्रिंग में पहली स्ट्रिंग है या नहीं।
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` और `endsWith : String -> String -> Bool` जाँचते हैं कि दूसरी स्ट्रिंग दी गई सबस्ट्रिंग से शुरू होती है या उस पर खत्म होती है।
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` किसी स्ट्रिंग में सबस्ट्रिंग शुरू होने वाले सारे इंडेक्स का ऐरे लौटाता है।
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## स्ट्रिंग का रूप बदलना
`toInt : String -> Maybe Int` स्ट्रिंग को `Just Int` में बदलने की कोशिश करता है, और गलत तरीके से लिखी स्ट्रिंग के लिए `Nothing` लौटाता है।
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` पूर्णांक को स्ट्रिंग में बदल देता है।
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` स्ट्रिंग को दशमलव संख्या में बदलने की कोशिश करता है, और गलत तरीके से लिखी स्ट्रिंग पर नाकाम हो जाता है।
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` दशमलव संख्या को स्ट्रिंग में बदल देता है।
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` और `fromList : List Char -> String` क्रमशः स्ट्रिंग को अक्षरों के ऐरे में और अक्षरों के ऐरे को स्ट्रिंग में बदलते हैं।
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` अक्षर को स्ट्रिंग में बदल देता है।
```elm
fromChar 'a' 
    --> "a"
```

## स्ट्रिंग की फॉर्मेटिंग

`toUpper : String -> String` और `toLower : String -> String` क्रमशः स्ट्रिंग को पूरी तरह बड़े या पूरी तरह छोटे अक्षरों में बदल देते हैं।
केस को न देखते हुए तुलना करने में यह काम आता है।
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` दिए गए `Char` से स्ट्रिंग को दोनों तरफ़ तब तक भरता है जब तक उसकी लंबाई दी गई लंबाई न हो जाए।
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
इसी तरह, `padLeft` और `padRight` स्ट्रिंग को किसी एक तरफ़ तब तक भरते हैं जब तक उसकी लंबाई दी गई लंबाई न हो जाए।

`trim : String -> String` स्ट्रिंग के दोनों तरफ़ की खाली जगह हटा देता है।
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` और `trimRight` स्ट्रिंग के किसी एक तरफ़ की खाली जगह हटा देते हैं।

## हायर-ऑर्डर फंक्शन

`map : (Char -> Char) -> String -> String` स्ट्रिंग के हर अक्षर को दिए गए फंक्शन से बदल देता है।
ध्यान रहे कि दिया गया फंक्शन `Char` से `Char` पर ही मैपिंग होना चाहिए।
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` सिर्फ वे अक्षर रखता है जो जाँच पास करते हैं।
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` बाएँ से शुरू करके स्ट्रिंग को समेटता है।
यह फंक्शन पहले अक्षर को अपने पहले पैरामीटर के रूप में और दी गई शुरुआती वैल्यू को अपने दूसरे पैरामीटर के रूप में लेकर चलता है।
फंक्शन का नतीजा उसी टाइप का होना चाहिए जिस टाइप की दी गई शुरुआती वैल्यू है, और यह हर अक्षर पर एक के बाद एक लगाया जाता है।
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` भी वही करता है, लेकिन स्ट्रिंग के दाएँ से शुरू करके।

`any : (Char -> Bool) -> String -> Bool` बताता है कि दी गई शर्त पर कोई भी अक्षर `True` लौटाता है या नहीं।
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` बताता है कि स्ट्रिंग के सारे अक्षर दी गई शर्त पर `True` लौटाते हैं या नहीं।
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
