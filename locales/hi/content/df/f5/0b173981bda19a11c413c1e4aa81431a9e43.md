# परिचय

## संख्याएँ

Python में तीन अलग-अलग तरह की बिल्ट-इन संख्याएँ होती हैं: `ints`, `floats`, और `complex`। लेकिन इस अभ्यास में आप केवल `ints` और `floats` के साथ काम करेंगे।

### ints

`ints` पूर्ण संख्याएँ होती हैं। जैसे `1234`, `-10`, `20201278`।

Python में पूर्णांकों की [मनमानी परिशुद्धता][arbitrary-precision] होती है। अंकों की संख्या केवल होस्ट सिस्टम की उपलब्ध मेमोरी तक सीमित होती है।

### floats

`floats` दशमलव बिंदु वाली संख्याएँ होती हैं। जैसे `0.0`,`3.14`,`-9.01`।

फ्लोटिंग पॉइंट संख्याएँ आमतौर पर Python में C के `double` की मदद से लागू की जाती हैं (_15 दशमलव स्थानों की परिशुद्धता_), लेकिन इनका प्रतिनिधित्व होस्ट सिस्टम और अन्य कार्यान्वयन विवरणों के आधार पर अलग-अलग हो सकता है। दशमलव संख्याओं के साथ काम करते समय यह कुछ चौंकाने वाली बातें पैदा कर सकता है, लेकिन ज़्यादातर स्थितियों के लिए यह "काफी अच्छा" है।

## अंकगणित

Python `ints` और `floats` के बीच अंकगणित का पूरा समर्थन करता है। बाइनरी अंकगणितीय ऑपरेटरों (`+`, `-`, `*`, `/`, `//`, और `%`) के साथ इस्तेमाल करने पर यह छोटी संख्याओं को उनसे बड़ी संख्याओं के अनुरूप बदल देता है।

Python `ints` को `floats` से छोटा मानता है। इसलिए किसी एक्सप्रेशन में दशमलव संख्या इस्तेमाल करने पर परिणाम भी दशमलव संख्या ही होगा। लेकिन भाग करते समय परिणाम हमेशा दशमलव संख्या ही होगा, भले ही केवल पूर्णांक इस्तेमाल किए गए हों।

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

अगर पूर्णांक परिणाम चाहिए, तो आप `//` से परिणाम को छोटा कर सकते हैं।

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

किसी दशमलव संख्या को पूर्णांक में बदलने के लिए आप `int()` इस्तेमाल कर सकते हैं। किसी पूर्णांक को दशमलव संख्या में बदलने के लिए आप `float()` इस्तेमाल कर सकते हैं।

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
