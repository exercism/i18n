# विवरण

Elm पूरी तरह से फंक्शनल भाषा है, इसलिए इसमें स्टेटमेंट नहीं होते, सिर्फ एक्सप्रेशन होते हैं, और फंक्शन हमेशा एक ही एक्सप्रेशन होते हैं।

यह छोटे और सरल फंक्शन लिखने को प्रोत्साहित करता है और आम तौर पर अच्छी बात है, लेकिन कभी-कभी फंक्शन अनिवार्य रूप से अधिक जटिल हो जाते हैं, और हमें ऐसा तरीका चाहिए जिससे ये फंक्शन सुंदर ढंग से लिखे जा सकें।

यहीं `let` एक्सप्रेशन काम आते हैं। इनके दो हिस्से होते हैं: एक `let` भाग, जहाँ आप जितनी चाहें उतनी परिभाषाएँ बना सकते हैं, और फिर एक `in` भाग, जो एक ही एक्सप्रेशन होता है और इन परिभाषाओं का उपयोग कर सकता है।

कंप्यूटिंग की दृष्टि से, `let` एक स्कोप बनाता है जो `in` के एक्सप्रेशन तक ही सीमित रहता है।

`let` एक्सप्रेशन कुछ स्थितियों में उपयोगी होता है:

- एक्सप्रेशन को सरल बनाने के लिए
- मध्यवर्ती एक्सप्रेशनों के परिणामों को नाम देने के लिए
- अगर कोई एक्सप्रेशन बड़ा होता जा रहा हो, तो उसे छोटे-छोटे हिस्सों में बाँटने के लिए

`let` एक्सप्रेशन के अंदर आप ज़्यादातर चीज़ें कर सकते हैं, जैसे डीस्ट्रक्चरिंग, लेकिन नीचे दी गई चीज़ों की अनुमति नहीं है:

- कस्टम टाइप
- टाइप एलियस
- नेम शैडोइंग (आप किसी ऐसे नाम को दोबारा परिभाषित या दोबारा इस्तेमाल नहीं कर सकते जो पहले से स्कोप में हो)

## एक्सप्रेशन को सरल बनाना

यह एक्सप्रेशन 3 संख्याओं के घनों को जोड़ता है, लेकिन इसे पढ़ना कठिन है, और अलग-अलग संख्याओं के लिए गणना अलग हो जाना आसान होगा।

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

गणना को सरल, अधिक अर्थपूर्ण और सुरक्षित बनाने के लिए हम `let` एक्सप्रेशन में एक `cube` फंक्शन बना सकते हैं। इस फंक्शन का टाइप एनोटेशन हो सकता है, लेकिन Elm में स्वाभाविक शैली में लिखे कोड में यह अपेक्षाकृत दुर्लभ होता है।

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## मध्यवर्ती एक्सप्रेशनों के परिणामों को नाम देना

यह कोड sideArea और topArea बनाता है ताकि गणना को सरल और अधिक अर्थपूर्ण बनाया जा सके।

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## बड़े एक्सप्रेशन को बाँटना

यह कोड [गेम ऑफ लाइफ](https://playgameoflife.com/) के लिए शुरुआती पैटर्न बनाता है (प्रोग्रामिंग का एक आम उदाहरण अभ्यास)।

यह समझना ज़रूरी नहीं है कि यह ठीक से कैसे काम करता है, लेकिन उम्मीद है कि यह साफ़ है कि इसे `let` के बिना एक ही एक्सप्रेशन के रूप में लिखा जाए तो यह बहुत बड़ा हो जाएगा।

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
