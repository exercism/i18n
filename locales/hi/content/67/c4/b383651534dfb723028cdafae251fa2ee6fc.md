# निर्देश

ABAP के इंटरनल टेबल के बारे में बुनियादी बातें सीखिए।

आपकी क्लास में `initial_data` नाम का एक इंटरनल टेबल है। इसमें तीन कॉलम हैं: `GROUP`, `NUMBER`, और `DESCRIPTION`।

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## चरण 1

आपको मेथड `fill_itab` पूरा करना है और इस टेबल में नीचे दी गई वैल्यू वाले 6 रिकॉर्ड डालने हैं:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## चरण 2

इसके बाद मेथड `add_to_itab` लागू कीजिए, जो इंटरनल टेबल के अंत में नीचे दी गई वैल्यू वाला एक रिकॉर्ड जोड़ेगा:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## चरण 3

अब मेथड `sort_itab` में इंटरनल टेबल को इस तरह क्रमबद्ध कीजिए कि `GROUP` कॉलम वर्णमाला के क्रम में हो और `NUMBER` कॉलम घटते क्रम में हो।

## चरण 4

मेथड `search_itab` में क्रमबद्ध टेबल में खोज कीजिए और उस रिकॉर्ड का इंडेक्स लौटाइए जिसके `NUMBER` कॉलम की वैल्यू 6 है।
