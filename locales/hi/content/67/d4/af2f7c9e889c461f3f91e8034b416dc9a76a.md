# परिचय

स्ट्रक्ट और क्लास के कई तरह के सदस्य (फील्ड मुख्य अपवाद हैं) एक्सप्रेशन-बॉडी सदस्य सिंटैक्स इस्तेमाल कर सकते हैं। किसी सदस्य को एक्सप्रेशन के साथ परिभाषित करने पर अक्सर पारंपरिक ब्लॉक/स्टेटमेंट वाले कोड से ज़्यादा संक्षिप्त और पढ़ने योग्य कोड बनता है।

मेथड और केवल पढ़ने योग्य प्रॉपर्टी उन सदस्यों में शामिल हैं जिन्हें एक्सप्रेशन बॉडी के साथ परिभाषित किया जा सकता है।

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
