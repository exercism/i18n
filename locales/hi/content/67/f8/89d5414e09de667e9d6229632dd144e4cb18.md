# परिचय

[बिटवाइज़ बाइनरी फंक्शन][bitwise-wiki] पूर्णांकों पर लागू किए जा सकते हैं। इनके लिए [Bitwise मॉड्यूल][bitwise-hexdocs] के फंक्शन इस्तेमाल होते हैं।

- [`band/2`][bitwise-and]: बिटवाइज़ AND
- [`bsl/2`][bitwise-shift-left]: बिटवाइज़ SHIFT LEFT
- [`bsr/2`][bitwise-shift-right]: बिटवाइज़ SHIFT RIGHT
- [`bxor/2`][bitwise-xor]: बिटवाइज़ XOR
- [`bor/2`][bitwise-or]: बिटवाइज़ OR
- [`bnot/1`][bitwise-not]: बिटवाइज़ NOT

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
