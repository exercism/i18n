# टेस्ट

## सभी टेस्ट चलाइए

`.rakutest` एक्सटेंशन वाली एक Raku स्क्रिप्ट होती है, जिसका इस्तेमाल आपके हल को टेस्ट करने के लिए किया जाएगा।
आप इन टेस्ट को इस कमांड से चला सकते हैं:

`prove6`

अभ्यास शुरू करने से पहले आउटपुट कुछ ऐसा दिख सकता है:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

आपको `lib/` डायरेक्टरी में मौजूद `.rakumod` एक्सटेंशन वाले मॉड्यूल में बदलाव करना होगा और टेस्ट पास करने के लिए एक हल लिखना होगा।
जब टेस्ट पास होने लगेंगे, तो ऊपर वाले कमांड का आउटपुट कुछ ऐसा दिखेगा:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## पहली विफलता पर रुकिए

अगर आपने `RAKU_TEST_DIE_ON_FAIL` एनवायरनमेंट वेरिएबल सेट किया हुआ है, तो टेस्ट रनर पहली विफलता के बाद रुक जाएगा। उदाहरण के लिए:

Linux / OS X में:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

या Windows में:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

अधिक जानकारी के लिए [Raku डॉक्युमेंटेशन का टेस्टिंग अध्याय](https://docs.raku.org/language/testing.html) देखिए।
