# मेंटरिंग में Markdown का उपयोग कैसे करें

GitHub पर आप अपनी मेंटरिंग टिप्पणियों में markdown इस्तेमाल कर सकते हैं।
इससे आप कोड स्निपेट डाल सकते हैं, हेडिंग, बोल्ड, इटैलिक और सूचियाँ जोड़ सकते हैं, और पहले लिखे वाक्यों को उद्धृत कर सकते हैं।

Exercism पर हम "Github-flavoured Markdown" के कुछ एलिमेंट की अनुमति भी देते हैं, खास तौर पर सिंटैक्स हाइलाइटिंग, टेबल और स्ट्राइक-थ्रू की।

अगर आप Markdown या GitHub की इन अतिरिक्त सुविधाओं से परिचित नहीं हैं, तो हम [GitHub की Markdown गाइड](https://guides.github.com/features/mastering-markdown/) पढ़ने की सलाह देते हैं।
