# परिचय

जब कोई टाइप _टाइप पैरामीटर_ की मदद से किसी भी टाइप की वैल्यू रख सकता है, तो उसे _जेनेरिक टाइप_ कहते हैं।

उदाहरण के लिए, इस `Box` टाइप में `a` टाइप पैरामीटर है (जिसे छोटे अक्षरों में लिखा जाता है)।

```gleam
pub type Box(a) {
  Box(a)
}
```

`a` टाइप पैरामीटर किसी भी टाइप के लिए एक प्लेसहोल्डर है, इसलिए `Box` को स्ट्रिंग, पूर्णांक या किसी भी अन्य टाइप के साथ इस्तेमाल किया जा सकता है।

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

एक टाइप में कई टाइप पैरामीटर हो सकते हैं, जिन्हें कॉमा से अलग किया जाता है।

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## जेनेरिक फंक्शन

टाइप पैरामीटर फंक्शन के आर्गुमेंट में भी इस्तेमाल किए जा सकते हैं।

यह फंक्शन `a` टाइप की एक वैल्यू लेता है और ऐसे फंक्शन को दो बार कॉल करता है जो एक `a` लेकर `b` लौटाता है।

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
