# निर्देश

इस अभ्यास में आप एक दोस्त के बना रहे नए RPG गेम के लिए अभियान का लॉजिक लिखेंगे। गेम का मुख्य पात्र Annalyn है, जो एक बहादुर लड़की है और उसके साथ उसका हिम्मती और निष्ठावान पालतू कुत्ता है। लेकिन अफसोस, एक मुसीबत आ पड़ती है, क्योंकि जंगल में बेर ढूँढते समय उसके सबसे अच्छे दोस्त का अपहरण कर लिया जाता है। Annalyn अपने दोस्त को ढूँढकर छुड़ाने की कोशिश करेगी, और चाहे तो इस अभियान में अपने कुत्ते को भी साथ ले जाएगी।

अपने दोस्त का पीछा करते हुए कुछ समय बाद, उसे वह शिविर मिलता है जहाँ उसका दोस्त कैद है। पता चलता है कि अपहरण करने वाले दो लोग हैं: एक शक्तिशाली शूरवीर और एक चालाक धनुर्धर।

अपहरण करने वालों को ढूँढ लेने के बाद Annalyn सोचती है कि वह नीचे दिए गए इन एक्शनों में से कौन-से कर सकती है:

- तेज़ हमला: तेज़ हमला तभी किया जा सकता है जब शूरवीर सो रहा हो। उसे अपना कवच पहनने में समय लगता है, इसलिए वह कमज़ोर रहेगा।
- जासूसी: समूह पर जासूसी तभी की जा सकती है जब उनमें से कम से कम एक जाग रहा हो। वरना जासूसी करना व्यर्थ है।
- कैदी को संकेत भेजना: अगर कैदी जाग रहा हो और धनुर्धर सो रहा हो, तो उसे पक्षियों की आवाज़ों से संकेत भेजा जा सकता है। धनुर्धरों को पक्षियों के संकेत भेजने का प्रशिक्षण होता है, इसलिए वे संदेश को पकड़ सकते हैं।
- _कैदी को छुड़ाना_: Annalyn कैदी को छुड़ाने के लिए चुपके से शिविर में घुसने की कोशिश कर सकती है।
  यह एक जोखिम भरा काम है और केवल दो तरीकों में से एक में ही सफल हो सकता है:
  - अगर Annalyn के पास उसका पालतू कुत्ता है और धनुर्धर सो रहा है, तो वह कैदी को छुड़ा सकती है।
    शूरवीर कुत्ते से डरता है, और Annalyn और कैदी के भागने से पहले धनुर्धर को तैयार होने का समय नहीं मिलेगा।
  - अगर Annalyn के पास उसका कुत्ता नहीं है, तो उसे और कैदी को बहुत चुपचाप रहना होगा!
    अगर कैदी जाग रहा हो और शूरवीर तथा धनुर्धर दोनों सो रहे हों, तो Annalyn कैदी को छुड़ा सकती है। लेकिन अगर कैदी सो रहा हो, तो उसे छुड़ाया नहीं जा सकता: Annalyn को अचानक देखकर कैदी चौंक जाएगा और शूरवीर तथा धनुर्धर को जगा देगा।

आपके पास चार काम हैं: जंगल में मिले तीन पात्रों की स्थिति और Annalyn के पालतू कुत्ते की मौजूदगी के आधार पर यह तय करने का लॉजिक बनाना कि ऊपर बताए गए एक्शन उपलब्ध हैं या नहीं।

## 1. जाँचिए कि 'तेज़ हमला' एक्शन संभव है या नहीं

`canExecuteFastAttack` नाम का एक फंक्शन बनाइए, जो एक बूलियन वैल्यू लेता है, जो बताती है कि शूरवीर जाग रहा है या नहीं। अगर पात्र की स्थिति के आधार पर 'तेज़ हमला' एक्शन उपलब्ध है, तो यह फंक्शन `true` लौटाता है। वरना `false` लौटाता है:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. जाँचिए कि 'जासूसी' एक्शन संभव है या नहीं

`canSpy` नाम का एक फंक्शन बनाइए, जो तीन बूलियन वैल्यू लेता है, जो क्रमशः बताती हैं कि शूरवीर, धनुर्धर और कैदी जाग रहे हैं या नहीं। अगर पात्रों की स्थिति के आधार पर 'जासूसी' एक्शन उपलब्ध है, तो यह फंक्शन `true` लौटाता है। वरना `false` लौटाता है:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. जाँचिए कि 'कैदी को संकेत भेजना' एक्शन संभव है या नहीं

`canSignalPrisoner` नाम का एक फंक्शन बनाइए, जो दो बूलियन वैल्यू लेता है, जो क्रमशः बताती हैं कि धनुर्धर और कैदी जाग रहे हैं या नहीं। अगर पात्रों की स्थिति के आधार पर 'कैदी को संकेत भेजना' एक्शन उपलब्ध है, तो यह फंक्शन `true` लौटाता है। वरना `false` लौटाता है:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. जाँचिए कि 'कैदी को छुड़ाना' एक्शन संभव है या नहीं

`canFreePrisoner` नाम का एक फंक्शन बनाइए, जो चार बूलियन वैल्यू लेता है। पहले तीन पैरामीटर क्रमशः बताते हैं कि शूरवीर, धनुर्धर और कैदी जाग रहे हैं या नहीं। अंतिम पैरामीटर बताता है कि Annalyn का पालतू कुत्ता मौजूद है या नहीं। अगर पात्रों की स्थिति और Annalyn के पालतू कुत्ते की मौजूदगी के आधार पर 'कैदी को छुड़ाना' एक्शन उपलब्ध है, तो यह फंक्शन `true` लौटाता है। वरना यह `false` लौटाता है:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
