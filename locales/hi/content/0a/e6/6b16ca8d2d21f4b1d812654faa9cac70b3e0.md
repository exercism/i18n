# निर्देश

आप एक पिज़्ज़ा की दुकान चलाते हैं और तीन तरह के पिज़्ज़ा बेचते हैं:

- Margherita: $7
- Caprese: $9
- Formaggio: $10

ग्राहक चाहें तो कितने भी अतिरिक्त विकल्प जोड़ सकते हैं: "ExtraSauce" 1 डॉलर में या "ExtraToppings" 2 डॉलर में।

आपको ऐसा कोड लिखना है जो ग्राहक को यह पता लगाने में मदद करे कि उसे कितना देना है।

## पिज़्ज़ा की कीमत निकालिए

फंक्शन को पहले आर्गुमेंट के रूप में पिज़्ज़ा का नाम दिया जाता है, और उसके बाद कितने भी जोड़े गए विकल्प। आपको पिज़्ज़ा की कीमत डॉलर में निकालनी है।

```js
pizzaPrice('Margherita');
// => 7

pizzaPrice('Caprese', 'ExtraSauce', 'ExtraToppings');
// => 12

pizzaPrice(
  'Caprese',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
);
// => 17
```

## ऑर्डर की कुल कीमत निकालिए

आपके फंक्शन को `PizzaOrder` के ऐरे के साथ कॉल किया जाता है और उसे ऑर्डर की कुल कीमत डॉलर में लौटानी चाहिए।
हर `PizzaOrder` में एक `pizza` प्रॉपर्टी होती है, जो पिज़्ज़ा का नाम है, और एक `extras` प्रॉपर्टी होती है, जो अतिरिक्त विकल्पों का ऐरे है।

```js
const margherita = new PizzaOrder('Margherita');
const caprese = new PizzaOrder('Caprese', 'ExtraToppings');
orderPrice([margherita, caprese]);
// => 18
```

आप देखेंगे कि इसे रिकर्शन से नहीं लिखा जा सकता, क्योंकि बहुत सारे ऑर्डर वाले एक टेस्ट में `Maximum call stack size exceeded` एरर आएगी।
कोई बात नहीं, यह जानबूझकर है। इस फंक्शन को एक इम्पेरेटिव लूप से लागू करके देखिए!
आपके पास कई विकल्प हैं, जैसे `reduce` या `for` लूप का उपयोग करना, पर ये ही सब कुछ नहीं हैं।

जब JavaScript इंटरप्रेटर JavaScript कोड चला रहा होता है, तो वह यह याद रखता है कि उसने किन-किन फंक्शन में प्रवेश किया है (जिन्हें कॉल करना शुरू किया है)। यह जानकारी वह "स्टैक" नाम की एक डेटा संरचना पर रखता है।
जब फंक्शन लौटता है (खत्म होता है), तो उसे स्टैक से हटा दिया जाता है।

लेकिन इस स्टैक का आकार सीमित होता है।
सबसे आम गलती ऐसा रिकर्शिव फंक्शन लिखना है जो कभी खत्म ही न हो।
हर कॉल स्टैक पर रखी जाती है, लेकिन उसके लौटने से पहले एक और कॉल स्टैक पर रख दी जाती है।

```javascript
function kaboom() {
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded
```

इस एरर का स्टैकट्रेस बार-बार वही लाइन दिखाता है, जो समझ में आता है, क्योंकि फंक्शन खुद को ही कॉल करता है।
ज़्यादातर मामलों में इसका कोई असली व्यावहारिक उपयोग तो नहीं है, पर आप यह पता लगा सकते हैं कि वह स्टैक कितना ऊँचा हो सकता है।

```javascript
let calls = 0;
function kaboom() {
  calls +=1 ;
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded

console.log(calls)
// => a number, generally higher than 10.000
```

सिंक्रोनस रिकर्शिव फंक्शन के कारण होने वाली कॉल स्टैक एरर के सिर्फ दो काम के हल हैं:
- यह सुनिश्चित कीजिए कि फंक्शन स्टैक की सीमा तक पहुँचने से पहले लौट आएँ, आमतौर पर एक बेस केस जोड़कर या ठीक करके।
- रिकर्शिव फंक्शन को इम्पेरेटिव लूप में बदल दीजिए, जो लूप के अंदर का कोड चलाएगा, बिना किसी फंक्शन में प्रवेश किए, और इस तरह स्टैक को बढ़ाए बिना।
