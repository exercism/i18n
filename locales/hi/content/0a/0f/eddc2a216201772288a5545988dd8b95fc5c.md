# main मेथड का इस्तेमाल न कीजिए

अपने कोड से `main` मेथड हटाकर देखिए।
अभ्यास के टेस्ट के लिए हल में `main` मेथड होना ज़रूरी नहीं है, और मेथड होने से कोड पढ़ना थोड़ा मुश्किल हो जाता है।

आम तौर पर `main` मेथड कोड को डीबग करने में मदद के लिए जोड़ा जाता है।
लेकिन इससे बेहतर तरीका यह है कि कोड को एक या अधिक यूनिट टेस्ट चलाते समय डीबग किया जाए।
इसका एक और फायदा यह है कि ध्यान एक खास टेस्ट केस को डीबग करने पर लगाया जा सकता है।

यहाँ कुछ लिंक दिए गए हैं, जिनमें बताया गया है कि अलग-अलग IDE में यूनिट टेस्ट चलाते समय Java कोड को कैसे डीबग किया जाए:

- [Visual Studio Code में Java टेस्ट चलाना और डीबग करना](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [IntelliJ IDEA में टेस्ट डीबग करना](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
