# फंक्शन एनोटेशन का क्रम

आम तौर पर `@doc` फंक्शन एनोटेशन `@spec` फंक्शन एनोटेशन से पहले आने चाहिए, और `@spec` फंक्शन एनोटेशन ठीक फंक्शन से पहले आना चाहिए। अगर फंक्शन में एक से अधिक क्लॉज़ हैं, तो फंक्शन एनोटेशन पहले क्लॉज़ से पहले होने चाहिए।

उदाहरण:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
