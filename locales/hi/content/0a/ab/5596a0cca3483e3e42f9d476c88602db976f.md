# परिचय

Lua में बूलियन टाइप की दो पारंपरिक वैल्यू होती हैं: `true` और `false`। इन वैल्यू को आप किसी वेरिएबल में असाइन कर सकते हैं और लॉजिकल ऑपरेटरों (`and`, `or`, `not`) के साथ जोड़ सकते हैं। इनका इस्तेमाल शर्त की जाँच में भी होता है, जैसे कंट्रोल स्ट्रक्चर में।

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

शर्त की जाँच और लॉजिकल ऑपरेटर, बूलियन `false` और `nil` दोनों को गलत मानते हैं, और बाकी हर चीज़ को सही मानते हैं।
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and` और `or`, दोनों *शॉर्ट-सर्किट इवैल्यूएशन* का इस्तेमाल करते हैं, यानी ये दोनों अपने दूसरे ऑपरेंड को सिर्फ ज़रूरत पड़ने पर ही आँकते हैं। सभी ऑपरेशन [ऑपरेटर प्राथमिकता](https://www.lua.org/manual/5.4/manual.html#3.4.8) के अनुसार आँके जाते हैं। इस प्राथमिकता में `not` को `and` और `or` से पहले आँका जाता है।
