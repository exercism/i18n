# परिचय

## बुनियादी बातें 1

### कॉन्स्टेंट और फंक्शन

एक कॉन्स्टेंट वैल्यू `name = expression` के रूप में परिभाषित की जाती है। ध्यान रखिए कि Elm में परिभाषाओं के अलावा बाकी सब कुछ एक्सप्रेशन होता है।

```elm
five = 5

six = 3 + 3
```

फंक्शन `name parameters... = expression` के रूप में बनाए जाते हैं, जहाँ पैरामीटर को केवल स्पेस से अलग किया जाता है।

```elm
add number1 number2 = number1 + number2
```

फंक्शन को कॉल करना भी एक एक्सप्रेशन ही होता है। इसके लिए फंक्शन का नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं, जिन्हें स्पेस से अलग किया जाता है, ठीक वैसे ही जैसे फंक्शन बनाते समय किया जाता है।

```elm
five = add 2 3
```

किसी एक्सप्रेशन के मूल्यांकन का क्रम तय करने के लिए गोल ब्रैकेट का उपयोग किया जा सकता है।

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### इंडेंटेशन / महत्वपूर्ण व्हाइटस्पेस

कोड की सीमाएँ तय करने के लिए Elm कर्ली ब्रैकेट, गोल ब्रैकेट या सेमीकोलन जैसे सिंटैक्स चिह्नों का उपयोग नहीं करता। इसके बजाय यह व्हाइटस्पेस और इंडेंटेशन का उपयोग करता है।

- मॉड्यूल, इंपोर्ट और टॉप-लेवल फंक्शन की परिभाषाएँ सबसे बाएँ कॉलम से शुरू होनी चाहिए।
- अगर किसी एक्सप्रेशन को कई लाइनों में बाँटा गया है, तो उस एक्सप्रेशन का जो कोड है उसे उसके नीचे कम से कम एक स्पेस के इंडेंटेशन के साथ लिखा जाना चाहिए।
- एक्सप्रेशन के जो हिस्से एक साथ समूहित हैं, उन्हें समान संख्या में स्पेस से इंडेंट करना चाहिए।

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### मॉड्यूल

Elm में हर फाइल एक मॉड्यूल होती है, और उसमें बाकी सारे कोड से पहले `module` स्टेटमेंट होना ज़रूरी है।
मॉड्यूल के नाम उसकी फाइल के नाम से मेल खाने चाहिए, यानी मॉड्यूल `Calculator` को Calculator.elm फाइल में होना चाहिए।
किसी मॉड्यूल के अंदर परिभाषित हर चीज़ उस मॉड्यूल तक ही सीमित रहती है, और `exposing` में नाम लिखे बिना बाहर से उसका उपयोग नहीं किया जा सकता।

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### कमेंट

कमेंट Elm फाइल के अंदर लिखा वह टेक्स्ट होता है जिसे कोड के रूप में नहीं पढ़ा जाता।
यह मुख्य रूप से आपके और दूसरे प्रोग्रामर के पढ़ने के लिए होता है।
सिंगल-लाइन कमेंट के लिए दो डैश पर आधारित एक आसान सिंटैक्स है।
`{-` और `-}` को खोलने और बंद करने वाले डिलिमिटर की जोड़ी के रूप में इस्तेमाल करके मल्टीलाइन कमेंट भी लिखे जा सकते हैं।

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
