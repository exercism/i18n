# निर्देश

आपकी डिज़ाइन कंपनी अब तक वेब पेज बनाने के लिए मुख्य रूप से CSS ट्रांसफॉर्मेशन का उपयोग करती आ रही है। कुछ चर्चा के बाद तय हुआ कि अब कुछ गणनाएँ गतिशील रूप से करने के लिए JavaScript का उपयोग शुरू किया जाए। आपकी टीम के कुछ साथियों को JavaScript का अनुभव कम है। इसलिए आप `{x, y}` निर्देशांक जोड़ों के लिए दोबारा उपयोग हो सकने वाला ट्रांसफॉर्मेशन बनाने के लिए फंक्शन क्लोज़र का उपयोग करने का फैसला करते हैं।

## 1. निर्देशांकों को स्थानांतरित कीजिए

`translate2d` फंक्शन बनाइए, जो एक ऐसा फंक्शन लौटाता है जो क्लोज़र का उपयोग करके किसी निर्देशांक जोड़े का दोबारा किया जा सकने वाला दो-आयामी स्थानांतरण करता है।

> ज्यामिति में, [स्थानांतरण][wiki-translate] का अर्थ है किसी बिंदु, सदिश या आकृति को एक ही दिशा में समान दूरी तक खिसकाना।
> इसे हर बिंदु में एक स्थिरांक जोड़ने के रूप में समझा जा सकता है।

```javascript
const moveCoordinatesRight2Px = translate2d(2, 0);
const result = moveCoordinatesRight2Px(4, 8);
// result => [6, 8]
```

## 2. निर्देशांकों को स्केल कीजिए

`scale2d` फंक्शन बनाइए, जो एक ऐसा फंक्शन लौटाता है जो क्लोज़र का उपयोग करके किसी निर्देशांक जोड़े की दोबारा की जा सकने वाली दो-आयामी स्केलिंग करता है।

> ज्यामिति में, समान [स्केलिंग][wiki-scale] का अर्थ है सदिशों या आकृतियों को एक ही दिशा में बड़ा या छोटा करना।
> इसे हर बिंदु को एक स्थिरांक (स्केलिंग गुणक) से गुणा करने के रूप में समझा जा सकता है।
>
> इस अभ्यास में मान लीजिए कि स्केलिंग की सभी वैल्यू धनात्मक ही होंगी।

```javascript
const doubleScale = scale2d(2, 2);
const result = doubleScale(6, -3);
// result => [12, -6]
```

## 3. ट्रांसफॉर्मेशन फंक्शन संयोजित कीजिए

दो ट्रांसफॉर्मेशन फंक्शन संयोजित करके एक दोबारा किया जा सकने वाला ट्रांसफॉर्मेशन बनाइए। इसे अक्सर _फंक्शन संयोजन_ कहा जाता है, जिसमें पहले फंक्शन _'f(x)'_ का परिणाम दूसरे फंक्शन _'g(x)'_ को इनपुट के रूप में दिया जाता है।

```javascript
const moveCoordinatesRight2Px = translate2d(2, 0);
const doubleCoordinates = scale2d(2, 2);
const composedTransformations = composeTransform(
  moveCoordinatesRight2Px,
  doubleCoordinates,
);
const result = composedTransformations(0, 1);
// result => [4, 2]
```

## 4. फंक्शनों के परिणाम सहेजिए

`memoizeTransform` फंक्शन बनाइए। यह उस फंक्शन को लेता है जिसे _मेमोइज़_ करना है, और फिर एक नया फंक्शन लौटाता है जो उस फंक्शन को दिए गए इनपुट याद रखता है। इससे अंतिम रिटर्न वैल्यू "याद" रह जाती है, और उसी आर्गुमेंट के साथ दोबारा कॉल करने पर वह केवल एक बार ही गणना की जाती है।

> मेमोइज़िंग का उपयोग कभी-कभी _डायनैमिक प्रोग्रामिंग_ में किया जाता है।
> इससे भारी ऑपरेशन केवल एक बार ही करने पड़ते हैं, क्योंकि उनके परिणाम याद रखे जाते हैं।
> **ध्यान दें** कि इस अभ्यास में केवल अंतिम परिणाम ही याद रखा जाता है, जबकि डायनैमिक प्रोग्रामिंग के कुछ हल _सभी_ परिणाम मेमोइज़ करते हैं।

```javascript
const tripleScale = scale2d(3, 3);
const memoizedScale = memoizeTransform(tripleScale);

memoizedScale(4, 3); // => [12, 9], this is computed since it hasn't been computed before for the arguments
memoizedScale(4, 3); // => [12, 9], this is remembered, since it was computed already
```
