# टेस्ट

CLI से अभ्यास का टेस्ट चलाने के लिए, अभ्यास की डायरेक्टरी से यह कमांड चलाइए:

```bash
clojure -M:test
```

## REPL

REPL से अभ्यास का टेस्ट चलाने के लिए, अभ्यास की डायरेक्टरी से यह कमांड चलाइए:

```bash
$ clojure -m cljs.main -re node
```

फिर अभ्यास का टेस्ट नेमस्पेस और Clojure का टेस्ट नेमस्पेस `require` कीजिए:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

ns को टेस्ट नेमस्पेस में बदलिए:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

फिर `run-tests` को कॉल कीजिए:

```clojure
=> (cljs.test/run-tests)
```
