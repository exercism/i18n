# निर्देश

आप समुद्र किनारे के बोर्डवॉक आर्केड में भाग्य के खेल चलाते हैं। खिलाड़ी पासे फेंकते हैं, क्लॉ मशीन इनाम पकड़ती है, और ताश की मेज़ पर गड्डी फेंटनी पड़ती है और हैंड बाँटने पड़ते हैं। यह सब बेतरतीब ढंग से होता है। रात के अंत में आपको एक "रिप्ले" सुविधा भी चाहिए, ताकि किसी विवादित खेल को उसी सीड से दोबारा चलाया जा सके।

## 1. पासा फेंकिए

`roll-die` बनाइए, जो पासे के फलकों की संख्या लेता है और `1` से `sides` तक (दोनों समेत) के बीच एक रोल लौटाता है।

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. इनाम पकड़िए

`pick-prize` बनाइए, जो इनामों का एक सीक्वेंस लेता है और उनमें से कोई एक बेतरतीब ढंग से लौटाता है।

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. गड्डी फेंटिए

`shuffle-deck` बनाइए, जो एक गड्डी (सीक्वेंस) लेता है और उस गड्डी को बेतरतीब क्रम में लौटाता है।

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. एक हैंड बाँटिए

`deal-hand` बनाइए, जो एक गड्डी और एक संख्या `n` लेता है, और गड्डी से `n` *अलग-अलग* कार्ड लौटाता है।

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. सीड से दोबारा चलाइए

`play-seeded` बनाइए, जो एक सीड और एक कोटेशन लेता है, और उस कोटेशन को ऐसे जनरेटर से चलाता है जिसका सीड उस पूर्णांक से लिया गया है, ताकि वही सीड हमेशा वही परिणाम दोबारा दे। कोटेशन का परिणाम कॉल करने वाले को लौटाया जाना चाहिए।

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
