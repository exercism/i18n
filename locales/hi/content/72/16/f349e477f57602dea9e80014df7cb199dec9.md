# इंस्टॉलेशन

## इंस्टॉलेशन के विकल्प

Unison का मौजूदा रिलीज़ Mac OS X, 64-बिट Linux और Windows उपयोगकर्ताओं के लिए उपलब्ध है! हमें उम्मीद है कि अगर आप Unison आज़मा रहे हैं, तो आप Exercism फोरम में या [Unison Discord](https://unison-lang.org/discord) पर हमसे बात करने ज़रूर आएँगे। आइए, सवाल पूछिए और अपनी आने वाली दिक्कतों की जानकारी दीजिए! हम चाहते हैं कि शुरुआत करते समय आपका अनुभव स्वागत भरा और सकारात्मक हो! 😊

Unison को [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage) या सीधे पैकेज्ड बाइनरी से डाउनलोड किया जा सकता है। इन सभी डाउनलोड विकल्पों के बारे में [हमारी वेबसाइट के इंस्टॉलेशन निर्देश वाले पेज](https://www.unison-lang.org/learn/quickstart/#installation-options) पर बताया गया है। UCM इंस्टॉल हो जाने के बाद यहाँ वापस आइए!

### विकल्प 1: Homebrew का इस्तेमाल

अगर आपने अभी तक [homebrew इंस्टॉल](https://brew.sh/) नहीं किया है, तो पहले वह कीजिए।

फिर कमांड लाइन से ये कमांड डालिए:

```
brew tap unisonweb/unison
brew install unison-language
```

इससे Unison कोडबेस मैनेजर का एक्ज़ीक्यूटेबल, `ucm`, इंस्टॉल हो जाएगा। अगर आप पिछले वर्शन से अपग्रेड कर रहे हैं, तो बस यह कीजिए

```
brew upgrade unison-language.
```

ध्यान दीजिए: अगर इस समय आपसे GitHub का यूज़रनेम और पासवर्ड माँगा जाए, तो देख लीजिए कि आपने unisonweb/unison की स्पेलिंग सही लिखी है।

### विकल्प 2: Mac और Linux उपयोगकर्ताओं के लिए मैन्युअल इंस्टॉलेशन

[Linux और Mac के मैन्युअल इंस्टॉल के लिंक यहाँ दिए गए हैं](https://www.unison-lang.org/learn/quickstart/#installation-options), जो संबंधित Linux और Mac मैन्युअल डाउनलोड सेक्शन में मौजूद हैं।

आप अपने शेल में कुछ इस तरह का कमांड चलाएँगे, लेकिन ऊपर दिए लिंक पर सबसे नई बाइनरी मिलेगी:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### विकल्प 3: Windows उपयोगकर्ताओं के लिए मैन्युअल इंस्टॉलेशन

1. सबसे अच्छे नतीजों के लिए अपना डिफाल्ट टर्मिनल ऐप “Windows Terminal” सेट कीजिए। Settings में “Terminal” खोजिए, या [इस गाइड को देखिए।](https://bit.ly/3IXwdlY)
2. अगर आपको पक्का नहीं पता कि Git पहले से इंस्टॉल है या नहीं, तो Git इंस्टॉल कीजिए:
  * winget के ज़रिए: `winget install --id Git.Git -e --source winget`
  * अगर आप Windows 10 पर हैं और आपके पास winget नहीं है, तो आप इसे [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) से इंस्टॉल कर सकते हैं और फिर ऊपर दिया कमांड चला सकते हैं।
3. [यहाँ दिए गए लिंक से UCM डाउनलोड कीजिए](https://www.unison-lang.org/learn/quickstart/#installation-options) और उसे अपनी पसंद की जगह पर खोल लीजिए।
4. `ucm.exe` चलाइए

### विकल्प 4: Nix इंस्टॉलेशन

[https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) पर जाइए और वहाँ रीडमी में दिए निर्देशों का पालन कीजिए।

## अपना Unison कोडबेस बनाइए

`$HOME/.unison` में Unison कोडबेस शुरू करने के लिए `ucm` चलाइए। यहीं Unison फंक्शन की परिभाषाएँ, टाइप, नेमस्पेस और ऐसी ही चीज़ें संग्रहीत करेगा। डिफाल्ट रूप से Unison कोडबेस मैनेजर (जिसे छोटा करके “UCM” कहते हैं) `base` नाम की स्टैंडर्ड लाइब्रेरी डाउनलोड करना शुरू कर देगा, जिसका इस्तेमाल आप Unison कोड लिखने में करेंगे। इसमें थोड़ा समय लग सकता है! 🕰

## Unison वर्कफ्लो

जब आप Unison कोड लिखना चाहें, तो कोडबेस मैनेजर शुरू करने के लिए `ucm` कमांड चलाइए। इसके बाद UCM उस डायरेक्टरी में मौजूद हर `.u` एक्सटेंशन वाली फाइल में होने वाले बदलावों पर नज़र रखेगा, जहाँ से उसे चलाया गया है।

उदाहरण के लिए, हो सकता है आप `~/exercism/unison/my-exercise/` नाम की डायरेक्टरी में `scratch.u` नाम की फाइल में फंक्शन लिख रहे हों। आपको `~/exercism/unison/my-exercise/` में `cd` करके `ucm` चलाना चाहिए। इससे यह पक्का होगा कि UCM आपकी `scratch.u` फाइल में होने वाले बदलावों पर नज़र रख रहा है।

अगर कभी आपको भ्रम हो कि `ucm` किस डायरेक्टरी में फाइल बदलावों पर नज़र रख रहा है, तो CLI शुरू होते समय यह वेलकम स्क्रीन पर दिख जाता है।

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[और वर्कफ्लो टिप्स यहाँ देखिए!](https://exercism.org/docs/tracks/unison/workflow)

## एडिटर सपोर्ट

अपनी `.u` फाइलें लिखने के लिए आप कोई भी टेक्स्ट एडिटर इस्तेमाल कर सकते हैं। Unison में [LSP सपोर्ट](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown) है, इसलिए आपका पसंदीदा IDE होवर करने पर टाइप दिखाने और ऑटो-कम्पलीट जैसी चीज़ों में आपकी मदद कर सकता है। Unison सपोर्ट वाले कुछ लोकप्रिय एडिटर नीचे दिए गए हैं:

### Vim

[vim-plug](https://github.com/junegunn/vim-plug) का इस्तेमाल करके:

1. अगर [`vim-plug`](https://github.com/junegunn/vim-plug) पहले से इंस्टॉल नहीं है, तो उसे इंस्टॉल कीजिए।
2. अपनी .vimrc में यह लाइन जोड़िए: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. vim में `:PlugInstall` कमांड चलाइए।

अधिक जानकारी के लिए vim के अंदर `:help unison` चलाइए या [ऑनलाइन हेल्प डॉक](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt) देखिए।

### Atom

कंसोल से यह चलाइए:

```
apm install unisonweb/atom-unison
```

### VS Code

1. VS Code के किनारे Activity Bar में Extensions आइकन पर क्लिक करके, या ⇧⌘X दबाकर Extensions व्यू खोलिए।
2. “unison” खोजिए
3. [Unison VS Code एक्सटेंशन](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison) इंस्टॉल कीजिए

### Emacs

[`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs) इंस्टॉल कीजिए।
