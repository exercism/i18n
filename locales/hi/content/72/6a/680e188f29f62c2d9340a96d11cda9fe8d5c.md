# टेस्ट चलाइए

किसी अभ्यास के टेस्ट चलाने के लिए, उस अभ्यास की डायरेक्टरी में `<exercise>.test` स्क्रिप्ट चलाइए:

```bash
tclsh <exercise>.test
```

अधिकांश अभ्यासों में पहले टेस्ट के अलावा बाकी सभी टेस्ट "skipped" होंगे।
इससे आप एक डेवलपर के रूप में टेस्ट-ड्रिवन डेवलपमेंट अपना सकते हैं: यानी हर टेस्ट को एक-एक करके पास करने के लिए जितनी ज़रूरत हो, उतनी ही कोडिंग कीजिए।
स्किप कमांड को ओवरराइड करने के लिए, टेस्ट सूट चलाने से पहले `RUN_ALL` एनवायरनमेंट वेरिएबल को मान्य Tcl सही वैल्यू \[1\] पर सेट कीजिए:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Tcl की सही/गलत वैल्यू C लाइब्रेरी फंक्शन [Tcl_GetBoolean][bool] के मैन पेज में बताई गई हैं।

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
