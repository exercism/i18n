# निर्देशों का परिशिष्ट

## संकेत

आपको `decode` और `encode` फंक्शन बनाने हैं, जो Atbash सिफर का उपयोग करके `String` को डिकोड और एनकोड करते हैं।
अगर आपको टाइप को लेकर संदेह है, तो आप दिए गए सिग्नेचर का उपयोग कर सकते हैं, लेकिन यह आपकी रचनात्मकता को सीमित न करे।

यह अभ्यास टेक्स्ट डेटा के साथ काम करता है। ऐतिहासिक कारणों से Haskell का
`String` टाइप `[Char]` का समानार्थी है, यानी अक्षरों का एक ऐरे। टेक्स्ट डेटा को और अधिक
कुशलता से संभालने के लिए `Text` टाइप का उपयोग किया जा सकता है।

इस अभ्यास के लिए एक वैकल्पिक विस्तार के रूप में, आप यह कर सकते हैं:

- Haskell में [स्ट्रिंग टाइप](https://haskell-lang.org/tutorial/string-types) के बारे में पढ़िए।
- package.yaml में अपनी डिपेंडेंसी की सूची में `- text` जोड़िए।
- [इस तरीके](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) से `Data.Text` इंपोर्ट कीजिए:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` टाइप का उपयोग कीजिए, जैसे `decode :: Text -> Text`, और
  `Data.Text` कॉम्बिनेटरों को जैसे `T.pack` के नाम से इस्तेमाल कीजिए।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) का
  डॉक्युमेंटेशन देखिए।
- Atbash.hs में `String` के सभी प्रयोगों को `Text` से बदल दीजिए, यानी:

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

यह हिस्सा पूरी तरह वैकल्पिक है।
