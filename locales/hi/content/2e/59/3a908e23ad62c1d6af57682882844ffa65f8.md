# परिचय

`readonly` मॉडिफायर किसी फील्ड में रखी वैल्यू या रेफरेंस को फिर से लिखे जाने से रोकता है, लेकिन रेफरेंस टाइप के मेंबर को यह कोई सुरक्षा नहीं देता।

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

रेफरेंस टाइप के सभी मेंबर सुरक्षित रहें, इसके लिए फील्ड को `readonly` बनाया जा सकता है, और ऑटोमैटिक प्रॉपर्टी ऐसी बनाई जा सकती हैं जिनमें `set` एक्सेसर न हो।

जहाँ कलेक्शन के मेंबर बदले जाने से रोकने की आवश्यकता होती है, वहाँ Base Class Library (BCL) कलेक्शन के कुछ ऐसे रूप देती है जो केवल पढ़ने योग्य होते हैं। ये रैपर के रूप में उपलब्ध होते हैं:

- `ReadOnlyDictionary<T>` एक `Dictionary<T>` को केवल पढ़ने योग्य रूप में उपलब्ध कराता है।
- `ReadOnlyCollection<T>` एक `List<T>` को केवल पढ़ने योग्य रूप में उपलब्ध कराता है।
