# परिचय

F# में किसी नाम को वैल्यू देने को _बाइंडिंग_ कहा जाता है। बाइंडिंग अपरिवर्तनीय होती हैं, जिससे वे दूसरी भाषाओं के स्थिरांक जैसी लगती हैं। चूँकि F# एक स्टैटिक टाइप वाली भाषा है, इसलिए हर बाइंडिंग का टाइप कंपाइल समय पर ही तय हो जाता है।

बाइंडिंग को `let` कीवर्ड से बनाया जाता है। ज़्यादातर बाइंडिंग के लिए उसका टाइप लिखना ज़रूरी नहीं है, क्योंकि F# का _टाइप इन्फरेंस_ आम तौर पर वैल्यू देखकर टाइप का अनुमान लगा लेता है। एक बाइंडिंग ऐसी दिखती है:

```fsharp
// Automatically inferred type
let fingers = 10
```

फंक्शन भी साधारण बाइंडिंग ही होते हैं, बस उनमें एक या अधिक पैरामीटर होते हैं। फंक्शन अपने आखिरी एक्सप्रेशन को अपने आप लौटा देता है। ज़्यादातर फंक्शन के लिए भी टाइप इन्फरेंस इस बात से काम करता है कि फंक्शन को किन वैल्यू के साथ कॉल किया जाता है और वह कौन-सी वैल्यू लौटाता है।

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट दिए जाते हैं।

```fsharp
let five = add 2 3
```

अगर किसी बाइंडिंग का टाइप अनुमान से तय नहीं हो पाता, तो कंपाइलर एक एरर दिखाता है। इसे ठीक करने के लिए बाइंडिंग में साफ-साफ टाइप एनोटेशन जोड़िए।

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F# में बाइंडिंग का इस्तेमाल उसे बनाने के _बाद_ ही किया जा सकता है। बनने से पहले किसी बाइंडिंग का इस्तेमाल करने पर कंपाइल एरर आती है।

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# में स्कोप तय करने के लिए व्हाइटस्पेस का महत्व होता है। इसका मतलब है कि स्कोप इस बात से तय होता है कि कोड को, बाइंडिंग बनाने वाली लाइन के मुकाबले, कितने स्पेस से इंडेंट किया गया है। डिफॉल्ट तरीका यह है कि इंडेंट करने के लिए चार स्पेस इस्तेमाल किए जाएँ:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F# में बाइंडिंग (जिनमें फंक्शन भी शामिल हैं) आम तौर पर मॉड्यूल में रखी जाती हैं। एक मॉड्यूल आपस में जुड़े काम को एक जगह रखता है और इसे `module` कीवर्ड से बनाया जाता है। मॉड्यूल की परिभाषा उसकी बाइंडिंग से पहले आनी चाहिए:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# दो तरह के कमेंट का समर्थन करता है। सिंगल-लाइन कमेंट `//` से शुरू होते हैं और मल्टीलाइन कमेंट `(*` और `*)` के बीच लिखे जाते हैं।
