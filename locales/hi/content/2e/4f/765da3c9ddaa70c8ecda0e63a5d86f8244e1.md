# इसके बारे में

## संख्याओं की तुलना

`jq` में संख्याओं की तुलना नीचे दिए गए संबंध और समानता वाले ऑपरेटरों से की जा सकती है।

| तुलना                  | ऑपरेटर |
| ---------------------- | -------- |
| बड़ा है                | `a > b`  |
| बड़ा या बराबर है       | `a >= b` |
| छोटा है                | `a < b`  |
| छोटा या बराबर है       | `a <= b` |
| बराबर है               | `a == b` |
| बराबर नहीं है          | `a != b` |

तुलना का परिणाम हमेशा एक बूलियन वैल्यू होता है, यानी `true` या `false`।

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## स्ट्रिंग की तुलना

ऊपर दिए गए ऑपरेटरों से स्ट्रिंग की तुलना भी की जा सकती है।
ऐसा करने पर डिक्शनरी (लेक्सिकोग्राफ़िकल) क्रम लागू होता है।
यह क्रम [यूनिकोड कोडपॉइंट वैल्यू के अनुसार][sort] तय होता है।

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

ऐसे दो वेरिएबल की तुलना करते समय सावधान रहना ज़रूरी है जिनमें संख्याएँ दिखती तो हैं, लेकिन उनका टाइप स्ट्रिंग है।
डिक्शनरी क्रम के कारण परिणाम वैसा नहीं आएगा जैसा संख्या टाइप की वैल्यू की तुलना में आता है।

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## "सख्त" समानता

`jq` का `==` ऑपरेटर Javascript के `===` जैसा है: जो चीज़ें देखने में एक जैसी लगती हैं, पर उनके टाइप अलग होते हैं, वे बराबर नहीं होतीं।

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## ऐरे की तुलना

अगर दो ऐरे के सभी संगत एलिमेंट बराबर हों, तो वे ऐरे बराबर होते हैं।

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## ऑब्जेक्ट की तुलना

अगर दो ऑब्जेक्ट के की-वैल्यू जोड़े एक जैसे हों, तो वे ऑब्जेक्ट बराबर होते हैं।

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
