# परिचय

## व्याख्या

`number` और `string` जैसे प्रिमिटिव डेटा टाइप के अलावा JavaScript में एक और ज़रूरी डेटा टाइप होता है, जिसे `object` कहते हैं।
ऑब्जेक्ट की-वैल्यू जोड़ों के संग्रह होते हैं।
इसीलिए इन्हें उस चीज़ की तरह इस्तेमाल किया जा सकता है, जिसे दूसरी भाषाओं में अक्सर मैप या डिक्शनरी कहा जाता है।

दूसरी भाषाओं में मैप की सारी वैल्यू का डेटा टाइप अक्सर एक ही होना चाहिए।
JavaScript में सिर्फ की का टाइप तय होता है: वह स्ट्रिंग होना चाहिए।
एक ही ऑब्जेक्ट के अंदर की वैल्यू के अलग-अलग टाइप हो सकते हैं।
ये संख्या जैसे प्रिमिटिव टाइप हो सकती हैं, लेकिन ऐरे, दूसरे ऑब्जेक्ट या फंक्शन भी हो सकती हैं।
इस वजह से ऑब्जेक्ट बहुत लचीले होते हैं, और JavaScript में ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग (OOP) की मुख्य इकाइयाँ भी यही हैं।

आगे हम ऑब्जेक्ट को संग्रह या मैप के रूप में देखेंगे। ऑब्जेक्ट के बाकी उपयोग दूसरे कॉन्सेप्ट में समझाए जाएँगे, जैसे [क्लास][concept-classes]।

## ऑब्जेक्ट बनाना

आप ऑब्जेक्ट घुंघराले ब्रैकेट से बनाते हैं।
आप सीधे कुछ एंट्री भी शामिल कर सकते हैं।
इसके लिए पहले की लिखिए, उसके बाद कोलन और फिर वैल्यू।

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

JavaScript में अंतिम एंट्री के बाद लगने वाला कॉमा ज़रूरी नहीं है।

आपके मन में सवाल आ सकता है कि जब की स्ट्रिंग होनी चाहिए, तो उन्हें उद्धरण चिह्नों में क्यों नहीं लपेटा गया।
यह एक छोटा रूप है।
अगर की JavaScript [आइडेंटिफायर][mdn-identifier] के नामकरण नियमों का पालन करती है, तो आप उद्धरण चिह्न छोड़ सकते हैं।
जिन की के नाम में खास अक्षर हों, उनके लिए स्ट्रिंग वाला आम तरीका इस्तेमाल करना पड़ता है।

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## वैल्यू निकालना

किसी की की वैल्यू निकालने के दो तरीके हैं: डॉट नोटेशन और ब्रैकेट नोटेशन।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

छोटे रूप की तरह डॉट नोटेशन इस्तेमाल करने पर भी वही नियम लागू होता है जो उद्धरण चिह्न छोड़ने पर होता है।
यह तभी काम करता है जब की आइडेंटिफायर के नामकरण नियमों का पालन करती हो।
दूसरे शब्दों में, अगर आपकी की सिर्फ अक्षरों से बना एक शब्द नहीं है, तो आपको चौकोर ब्रैकेट नोटेशन इस्तेमाल करना होगा।

## वैल्यू जोड़ना या बदलना

आप असाइनमेंट ऑपरेटर `=` की मदद से वैल्यू जोड़ या बदल सकते हैं।
यहाँ भी डॉट और ब्रैकेट, दोनों नोटेशन मौजूद हैं।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## एंट्री हटाना

आप `delete` कीवर्ड की मदद से ऑब्जेक्ट से कोई की-वैल्यू जोड़ा हटा सकते हैं।

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## की मौजूद है या नहीं, यह जाँचना

आप `hasOwnProperty` मेथड से जाँच सकते हैं कि कोई की ऑब्जेक्ट में मौजूद है या नहीं।

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## ऑब्जेक्ट पर लूप चलाना

ऑब्जेक्ट की सारी की पर इटरेशन करने के लिए एक खास `for...in` लूप होता है।

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

बारीक एरर से बचने के लिए आपको हमेशा यह मानना चाहिए कि `for...in` लूप की को किसी भी क्रम में देखता है।
साथ ही, यह भी ध्यान रखिए कि `for...in` अपने इटरेशन में [विरासत में मिली की][concept-inheritance] को भी शामिल करता है।
