# निर्देश

इस अभ्यास में आप कोड लिखेंगे जो उन प्रोग्रामिंग भाषाओं के ऐरे पर नज़र रखेगा जिन्हें आप Exercism पर सीखना चाहते हैं।

आपको छह काम करने हैं, और इन सबमें ऐरे के साथ काम करना होगा।

## 1. नया ऐरे बनाइए

जिन भाषाओं को आप सीखना चाहते हैं, उन पर नज़र रखने के लिए आपको एक नया ऐरे बनाना होगा। `new_list` फंक्शन बनाइए जो एक नया, खाली ऐरे लौटाता है।

```gleam
new_list()
// -> []
```

## 2. मौजूदा ऐरे बनाइए

फिलहाल आपके पास एक कागज़ है जिस पर आपकी सीखने वाली भाषाएँ लिखी हैं: Gleam, Go और TypeScript। `existing_list` फंक्शन बनाइए जो यही ऐरे लौटाता है।

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. ऐरे में नई भाषा जोड़िए

जैसे-जैसे आप Exercism पर घूमते हैं और नई दिलचस्प भाषाएँ ढूँढते हैं, आप उन्हें अपने ऐरे में जोड़ना चाहते हैं। `add_language` फंक्शन बनाइए जो आपके ऐरे की शुरुआत में एक नई भाषा जोड़ता है।

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. ऐरे में भाषाओं की गिनती कीजिए

भाषाओं को एक-एक करके गिनना सुविधाजनक नहीं है। `count_languages` फंक्शन बनाइए जो आपके ऐरे में भाषाओं की संख्या गिनता है।

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. ऐरे को उलटिए

किसी समय आपको पता चलता है कि आपका ऐरे वास्तव में उल्टे क्रम में है! `reverse_list` फंक्शन बनाइए जो आपके ऐरे को उलट देता है।

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. जाँचिए कि ऐरे रोमांचक है या नहीं

आपको सभी भाषाएँ पसंद हैं, लेकिन Gleam का दिल में एक खास स्थान है। इसलिए भाषाओं के किसी ऐरे को लेकर आप सचमुच उत्साहित होते हैं, अगर:

- ऐरे में पहली भाषा Gleam हो।
- ऐरे में दूसरा एलिमेंट Gleam हो और ऐरे में दो या तीन भाषाएँ हों।

`exciting_list` फंक्शन बनाइए जो जाँचता है कि भाषाओं का ऐरे रोमांचक है या नहीं:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
