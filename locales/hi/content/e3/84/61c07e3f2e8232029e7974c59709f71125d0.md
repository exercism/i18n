# परिचय

Java एक स्टैटिक टाइप वाली भाषा है, यानी किसी वेरिएबल का टाइप कंपाइल समय पर ही पता हो जाता है।
किसी नाम को वैल्यू असाइन करने को ही वेरिएबल बनाना कहा जाता है।
वेरिएबल बनाने के लिए उसका टाइप साफ़-साफ़ लिखा जाता है।

```java
int explicitVar = 10;
```

वेरिएबल की वैल्यू अपडेट करने के लिए `=` ऑपरेटर इस्तेमाल किया जाता है।
यहाँ `=` का मतलब गणित की बराबरी नहीं है।
यह सिर्फ़ वेरिएबल को एक वैल्यू असाइन करता है।
एक बार वेरिएबल बन जाने पर उसका टाइप कभी नहीं बदल सकता।

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java एक [ऑब्जेक्ट-ओरिएंटेड भाषा][object-oriented-programming] है और इसमें सभी फंक्शन एक _क्लास_ के अंदर बनाना ज़रूरी होता है।
क्लास बनाने के लिए `class` कीवर्ड का उपयोग किया जाता है।

```java
class Calculator {
    // ...
}
```

क्लास के अंदर मौजूद फंक्शन को _मेथड_ कहा जाता है।
हर मेथड में शून्य या उससे अधिक पैरामीटर हो सकते हैं।
सभी पैरामीटर का टाइप साफ़-साफ़ लिखना पड़ता है, पैरामीटर के टाइप का कोई अनुमान नहीं लगाया जाता।
इसी तरह रिटर्न टाइप भी साफ़-साफ़ लिखना पड़ता है।
मेथड से वैल्यू लौटाने के लिए `return` कीवर्ड का उपयोग किया जाता है।
किसी मेथड को दूसरी क्लास से कॉल करने की अनुमति देने के लिए `public` एक्सेस मॉडिफायर जोड़ना पड़ता है।

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

किसी मेथड को इनवोक या कॉल करने के लिए उसकी क्लास और मेथड का नाम लिखा जाता है और मेथड के हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं।

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Java में स्कोप `{` और `}` के बीच तय होता है।

Java दो तरह के कमेंट का समर्थन करता है।
सिंगल-लाइन कमेंट से पहले `//` लगाया जाता है और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
