# इंस्टॉलेशन

## लक्ष्य वर्शन

इस ट्रैक के परीक्षण में `alpine:3.24.1` Docker इमेज इस्तेमाल होती है, जो सितंबर 2026 तक `sqlite3 version 3.53.4` इस्तेमाल करती है।
हम यह सुनिश्चित करने की कोशिश करते हैं कि इस ट्रैक में दिए गए टूल Ubuntu के नवीनतम LTS रिलीज़ पर काम करें।
हालाँकि उपयोगकर्ताओं के पास नए वर्शन इंस्टॉल हो सकते हैं, लेकिन उन्हें ध्यान रखना चाहिए कि कुछ फीचर हमारे टेस्ट रनर के साथ काम नहीं कर सकते।
फीचर की तुलना [SQLite वर्शन हिस्ट्री][version-history] पर की जा सकती है।

## Windows

Windows पर SQLite इंस्टॉल करने के लिए ये चरण अपनाइए:

1. [आधिकारिक डाउनलोड पेज][sqlite-download] से पहले से कंपाइल किए गए Windows बाइनरी डाउनलोड कीजिए।
2. डाउनलोड की गई ZIP फाइल को अपनी पसंद की किसी डायरेक्टरी में एक्सट्रैक्ट कीजिए।
   जैसे, `C:\Program Files\sqlite3`.
3. `sqlite3.exe` वाली डायरेक्टरी को सिस्टम के PATH एनवायरनमेंट वेरिएबल में जोड़िए।
   हर Windows वर्शन में यह प्रक्रिया थोड़ी अलग है, लेकिन यह जानकारी खोजना आसान होना चाहिए।
   जैसे [Windows 11 के लिए निर्देश][windows-11-install] और [Windows 10][windows-10-install].

## macOS

macOS पर SQLite पहले से इंस्टॉल होता है।
लेकिन अगर आपको नया वर्शन चाहिए, तो आप [Homebrew][homebrew] इस्तेमाल कर सकते हैं:

```bash
brew install sqlite
```

## Ubuntu / Debian

Ubuntu और Debian आधारित सिस्टम पर आप apt की मदद से SQLite इंस्टॉल कर सकते हैं:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

CentOS, Fedora और Red Hat आधारित सिस्टम पर आप yum या dnf की मदद से SQLite इंस्टॉल कर सकते हैं:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Arch Linux पर आप pacman की मदद से SQLite इंस्टॉल कर सकते हैं:

```bash
sudo pacman -S sqlite
```

## इंस्टॉलेशन के अन्य तरीके और पुराने वर्शन

अधिक जानकारी और इंस्टॉलेशन के दूसरे तरीकों के लिए [SQLite डाउनलोड पेज][sqlite-download] देखिए।
`Build Product Names and Info` सेक्शन में अलग-अलग SQLite वर्शन के नाम का टेम्पलेट दिया गया है, इसलिए आप अपने पसंदीदा सर्च इंजन से अपना मनचाहा वर्शन खोज पाएँगे।
