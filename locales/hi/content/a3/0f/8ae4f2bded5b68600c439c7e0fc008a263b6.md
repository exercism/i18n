# परिचय

## स्ट्रक्ट टाइप

हम स्ट्रक्ट टाइप पहले ही देख चुके हैं। एक बार फिर याद कर लें: `struct` ऐसे एलिमेंट्स का क्रम होता है जिन्हें _फील्ड_ कहा जाता है, और हर फील्ड का एक नाम और एक टाइप होता है।
स्ट्रक्ट के भीतर हर फील्ड का नाम अद्वितीय होना चाहिए।
स्ट्रक्ट की तुलना ऑब्जेक्ट ओरिएंटेड प्रोग्रामिंग पैराडाइम की _क्लास_ से की जा सकती है।

आप `type` और `struct` कीवर्ड का उपयोग करके नया स्ट्रक्ट बनाते हैं, और फिर नीचे दिए उदाहरण की तरह फील्ड के नाम और टाइप को स्पष्ट रूप से तय करते हैं।

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## नॉन-स्ट्रक्ट टाइप

नॉन-स्ट्रक्ट टाइप भी बनाए जा सकते हैं, जिन्हें आप किसी पहले से मौजूद टाइप के लिए दूसरे नाम की तरह इस्तेमाल कर सकते हैं।

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

आप ऐरे और मैप से बने नॉन-स्ट्रक्ट टाइप भी बना सकते हैं।

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
