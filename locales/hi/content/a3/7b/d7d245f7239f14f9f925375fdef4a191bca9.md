# परिचय

`for` लूप की मदद से आप किसी ऐरे पर इटरेशन कर सकते हैं और हर एलिमेंट के लिए कोड दोहरा सकते हैं:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

ऊपर के उदाहरण में `fruit` वह वेरिएबल है जिसमें ऐरे `fruitList` के किसी एक एलिमेंट की वैल्यू रखी जाती है। कंपाइलर यह सुनिश्चित करता है कि `fruitList` पर इटरेशन किया जा सकता है। अगर ऐसा न हो, तो वह कोड चलाना रोक देता है।

संख्याओं पर इटरेशन करने के लिए आप रेंज ऑपरेटर का उपयोग कर सकते हैं। यह ऑपरेटर दो `Int` ऑपरेंड लेता है और इसे `min...max` लिखा जाता है:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
