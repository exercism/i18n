# फंक्शन

JavaScript में फंक्शन _फर्स्ट-क्लास ऑब्जेक्ट_ होते हैं, यानी इन्हें वेरिएबल और प्रॉपर्टी को असाइन किया जा सकता है, दूसरे फंक्शन को पास किया जा सकता है, और फंक्शन से लौटाया भी जा सकता है। किसी भी अन्य _ऑब्जेक्ट_ की तरह इनमें भी प्रॉपर्टी और मेथड हो सकते हैं।

## इनपुट: आर्गुमेंट पास करना

JavaScript में फंक्शन को कॉल करते समय आप आर्गुमेंट पास कर सकते हैं। आर्गुमेंट हमेशा [वैल्यू द्वारा पास किए जाते हैं](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7)। दूसरे शब्दों में, अगर कोई फंक्शन अपने अंदर किसी पैरामीटर को फिर से असाइन करता है, तो फंक्शन के बाहर उसकी वैल्यू नहीं बदलेगी। इसका मतलब यह नहीं है कि पास किए गए ऑब्जेक्ट को बदला नहीं जा सकता।

> [!TIP]
> जब कोई ऑब्जेक्ट पास किया जाता है, तो उस ऑब्जेक्ट का रेफरेंस वैल्यू द्वारा पास होता है। इससे _ऐसा लगता है_ कि ऑब्जेक्ट पास करने का तरीका अलग है, लेकिन ऐसा नहीं है।

दो आर्गुमेंट लेकर उनका गुणा करने वाले फंक्शन का एक उदाहरण यह है:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## आउटपुट: रिटर्न वैल्यू

JavaScript में आप `return` कीवर्ड का उपयोग करके किसी फंक्शन से एक वैल्यू लौटा सकते हैं, और उसके बाद एक एक्सप्रेशन लिखते हैं। जब किसी फंक्शन से कुछ भी लौटाया नहीं जाता, तो लौटाई गई वैल्यू `undefined` होती है।

एक वैल्यू लौटाने वाले फंक्शन का उदाहरण यह है:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## फंक्शन बनाना

JavaScript में फंक्शन के चार प्रकार होते हैं:

1. सामान्य फंक्शन, जो कुछ भी लौटा सकते हैं और हमेशा पूरे चलते हैं;
2. async फंक्शन, जो हमेशा एक `Promise` लौटाते हैं और `await` ऑपरेटर से रोके और फिर से शुरू किए जा सकते हैं;
3. जेनरेटर फंक्शन: जो हमेशा एक `Generator` ऑब्जेक्ट लौटाते हैं और `yield` ऑपरेटर से रोके और फिर से शुरू किए जा सकते हैं;
4. async जेनरेटर फंक्शन; जो हमेशा एक `AsyncGenerator` ऑब्जेक्ट लौटाते हैं और `yield` तथा `await` _दोनों_ ऑपरेटर से रोके और फिर से शुरू किए जा सकते हैं।

इन चारों प्रकारों में से हर एक को बनाने के तीन तरीके हैं:

1. घोषणा का उपयोग करके
2. एक्सप्रेशन का उपयोग करके
3. कंस्ट्रक्टर का उपयोग करके

अंत में, _एरो फंक्शन और मेथड_ बनाने के लिए कुछ खास सिंटैक्स भी है।
