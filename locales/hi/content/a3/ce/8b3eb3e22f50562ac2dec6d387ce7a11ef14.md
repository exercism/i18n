# निर्देश

आपको पक्षी देखना बहुत पसंद है, और आप यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए हैं।

आपके सामने छह काम हैं, और सभी आपके बगीचे में आए पक्षियों की संख्याओं से जुड़े हैं।

## 1. देखिए कि पिछले सप्ताह की गिनती क्या थी

तुलना करने के लिए आप पिछले सप्ताह की गिनती की एक कॉपी हमेशा अपने पास रखते हैं, जो यह थी: 0, 2, 5, 3, 7, 8 और 4। पिछले सप्ताह की गिनतियों वाला एक वेक्टर बनाइए:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. देखिए कि आज कितने पक्षी आए

`today` फंक्शन बनाइए जो यह लौटाता है कि आज आपके बगीचे में कितने पक्षी आए। पक्षियों की गिनतियाँ दिन के क्रम में लगी हैं: पहला एलिमेंट सबसे पुराने दिन की गिनती है और अंतिम एलिमेंट आज की गिनती है।

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. आज की गिनती बढ़ाइए

`inc-bird` फंक्शन बनाइए जो आज की गिनती बढ़ा दे:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. देखिए कि क्या कोई ऐसा दिन था जब कोई पक्षी नहीं आया

`day-without-birds?` प्रेडिकेट फंक्शन बनाइए जो `true` लौटाता है अगर कोई ऐसा दिन था जब बगीचे में शून्य पक्षी आए; वरना `false` लौटाइए:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. शुरू के दिए गए दिनों में आए पक्षियों की संख्या निकालिए

`n-days-count` फंक्शन बनाइए जो बताता है कि सप्ताह की शुरुआत से आपके बगीचे में कितने पक्षी आए, लेकिन गिनती को सप्ताह की शुरुआत से दिए गए दिनों तक ही सीमित रखिए।

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरे दिनों से ज़्यादा व्यस्त होते हैं। व्यस्त दिन वह होता है जब आपके बगीचे में पाँच या उससे अधिक पक्षी आए हों। `busy-days` फंक्शन बनाइए जो व्यस्त दिनों की संख्या लौटाए:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. विषम सप्ताह की जाँच कीजिए

पिछले एक साल में आपने देखा है कि कुछ सप्ताह एक ही विषम पैटर्न पर चलते हैं, जिसमें गिनतियाँ एक और शून्य पक्षियों के बीच बदलती रहती हैं। `odd-week?` फंक्शन बनाइए जो `true` लौटाता है अगर इस सप्ताह का पक्षी-गिनती पैटर्न उस विषम पैटर्न से मेल खाता है:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
