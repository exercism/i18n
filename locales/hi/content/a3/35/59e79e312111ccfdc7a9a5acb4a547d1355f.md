# निर्देश

इस अभ्यास में आप एक रोल-प्लेइंग गेम के मेकैनिक लागू करेंगे।
खिलाड़ी के पात्र को इस टाइप से दर्शाया जाता है:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

इस गेम में खिलाड़ियों को जादू चलाना शुरू करने से पहले लेवल 10 तक पहुँचना होता है; तभी उनका माना पूल खुलता है।
इस गेम में आप दो चीज़ों पर काम करेंगे: रिवाइव मेकैनिक और जादू चलाने का मेकैनिक।

## 1. अपना परिचय दीजिए

`introduce` फंक्शन के अंदर का कोड लिखिए।
ध्यान दीजिए कि `Player` रिकॉर्ड का `Name` फील्ड एक `Option` है।
चुपके खिलाड़ी अपना नाम छिपाने के लिए उसे `None` पर ही छोड़ना चाह सकते हैं; ऐसे खिलाड़ियों का परिचय `"Mighty Magician"` के रूप में दिया जाएगा।
वरना अपना परिचय देने के लिए बस अपना नाम इस्तेमाल कीजिए।

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. रिवाइव मेकैनिक लागू कीजिए

`revive` फंक्शन को यह जाँचना चाहिए कि खिलाड़ी का पात्र वाकई मर चुका है या नहीं (उसकी हेल्थ 0 हो चुकी है)।
अगर मर चुका है, तो उसे 100 हेल्थ वाली एक नई `Player` इंस्टेंस लौटानी चाहिए।
वरना, अगर खिलाड़ी का पात्र मरा नहीं है, तो `revive` फंक्शन `None` लौटाता है।

अगर खिलाड़ी का लेवल 10 या उससे ज़्यादा है, तो उसे 100 माना के साथ भी जीवित किया जाना चाहिए।
अगर खिलाड़ी का लेवल 10 से कम है, तो उसका माना `None` होना चाहिए।
`revive` फंक्शन को खिलाड़ी का लेवल बनाए रखना चाहिए।

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

अगर `revive` मेथड ऐसे खिलाड़ी पर कॉल किया जाए जिसकी हेल्थ 1 या उससे ज़्यादा है, तो यह फंक्शन `None` लौटाता है।

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. जादू चलाने का मेकैनिक लागू कीजिए

`castSpell` फंक्शन आर्गुमेंट के तौर पर एक `int` लेता है, जो बताता है कि जादू में कितना माना लगता है, और साथ ही एक `Player` भी।
यह अपडेट हुआ खिलाड़ी लौटाता है और साथ ही उस चले गए जादू से होने वाले नुकसान की मात्रा भी।
जादू सफल होने पर नुकसान जादू की माना लागत का दोगुना होता है।
लेकिन अगर खिलाड़ी के पास काफी माना नहीं है, तो कुछ नहीं होता: खिलाड़ी जैसा था वैसा ही रहता है और कोई नुकसान नहीं होता।
अगर खिलाड़ी के पास माना पूल ही नहीं है, तो जादू चलाने की कोशिश करने पर उसकी हेल्थ जादू की माना लागत के बराबर घट जानी चाहिए, और कोई नुकसान नहीं होगा।

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
