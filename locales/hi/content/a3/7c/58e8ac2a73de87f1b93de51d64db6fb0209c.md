# परिचय

## स्ट्रिंग

Elixir में स्ट्रिंग को डबल कोट्स के बीच लिखा जाता है, और वे UTF-8 में एन्कोड होती हैं:

```elixir
"Hi!"
```

स्ट्रिंग को `<>/2` ऑपरेटर की मदद से जोड़ा जा सकता है:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir में स्ट्रिंग में `#{}` सिंटैक्स की मदद से इंटरपोलेशन किया जा सकता है:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

स्ट्रिंग में न्यूलाइन अक्षर डालने के लिए `\n` एस्केप कोड का इस्तेमाल कीजिए:

```elixir
"1\n2\n3\n"
```

जिन टेक्स्ट में बहुत सारे न्यूलाइन हों, उनके साथ आराम से काम करने के लिए इसके बजाय तीन डबल कोट्स वाले हेरडॉक सिंटैक्स का इस्तेमाल कीजिए:

```elixir
"""
1
2
3
"""
```

Elixir में स्ट्रिंग के साथ काम करने के लिए `String` मॉड्यूल में कई फंक्शन मौजूद हैं।

## पाइप ऑपरेटर

`|>` ऑपरेटर को पाइप ऑपरेटर कहा जाता है। इसका इस्तेमाल कई फंक्शन कॉल को एक साथ जोड़ने के लिए किया जा सकता है। इसमें पिछले फंक्शन कॉल से लौटी वैल्यू अगले फंक्शन कॉल को पहले आर्गुमेंट के रूप में मिलती है।

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
