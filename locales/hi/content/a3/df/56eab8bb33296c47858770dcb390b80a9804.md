# विवरण

Elixir में [स्ट्रिंग][getting-started-strings] दोहरे उद्धरण चिह्नों के बीच लिखी जाती हैं, और ये UTF-8 में एन्कोड होती हैं:

```elixir
"Hi!"
```

स्ट्रिंग को [`<>/2`][kernel-concat] ऑपरेटर की मदद से जोड़ा जा सकता है:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir की स्ट्रिंग में `#{}` सिंटैक्स की मदद से [इंटरपोलेशन][string-interpolation] किया जा सकता है:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

इंटरपोलेशन के अंदर कोई भी Elixir एक्सप्रेशन मान्य होता है। अगर कोई स्ट्रिंग दी जाए, तो वह स्ट्रिंग जैसी है वैसी ही इंटरपोलेट कर दी जाती है। अगर कोई और वैल्यू दी जाए, तो Elixir उसे स्ट्रिंग में बदलने की कोशिश करता है।

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir `String` मॉड्यूल में स्ट्रिंग के साथ काम करने के लिए कई फंक्शन देता है। अगर आपको समझ न आए कि किसी स्ट्रिंग को अपनी ज़रूरत के मुताबिक कैसे प्रोसेस करें, तो [इस बात को ज़रूर देखिए कि `String` मॉड्यूल में कौन-कौन से फंक्शन उपलब्ध हैं][string-module-functions], और आपको जो चाहिए वह लगभग ज़रूर मिल जाएगा।

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

इनमें से कुछ फंक्शन इस्तेमाल करते समय याद रखिए कि स्ट्रिंग के पहले अक्षर का इंडेक्स `0` होता है।

कुछ अक्षरों को स्ट्रिंग में रखने के लिए उन्हें [एस्केप][escape-characters] करना पड़ता है, जैसे नई लाइन, दोहरे उद्धरण चिह्न, या `#` अक्षर:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

जिन टेक्स्ट में बहुत सारी नई लाइनें हों, उनके साथ आराम से काम करने के लिए इसके बजाय [तीन दोहरे उद्धरण वाला हेरडॉक सिंटैक्स][heredoc-syntax] इस्तेमाल कीजिए:

```elixir
"""
1
2
3
"""
```

कोड का डॉक्युमेंटेशन करने के लिए यह सिंटैक्स आपको बहुत बार इस्तेमाल में मिलेगा:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
