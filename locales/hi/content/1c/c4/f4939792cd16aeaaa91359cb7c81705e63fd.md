# निर्देश

आप पक्षियों को बड़े चाव से देखते हैं और यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए।

आपके पाँच काम हैं, और ये सब आपके बगीचे में आने वाले पक्षियों की संख्याओं से जुड़े हैं।

## 1. जाँचिए कि पिछले सप्ताह की गिनतियाँ क्या थीं

आप पक्षियों की गिनती JSON फॉर्मैट में रखते हैं।
एक "मुख्य" ऐरे में हर सप्ताह की गिनती के ऐरे रखे जाते हैं।
हर सप्ताह की गिनती सात पूर्णांकों का एक ऐरे है, यानी सप्ताह के हर दिन के लिए एक संख्या।
नए सप्ताह आप हमेशा मुख्य ऐरे के अंत में जोड़ते हैं।
वह फिल्टर बनाइए जो पिछले सप्ताह की गिनतियाँ लौटाता है।

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. जाँचिए कि कल कितने पक्षी आए थे

एक ऐसा फिल्टर बनाइए जो लौटाए कि कल आपके बगीचे में कितने पक्षी आए थे।
पक्षियों की गिनती दिन के क्रम में लगी है: पहला एलिमेंट सबसे पुराने दिन की गिनती है और अंतिम एलिमेंट आज की गिनती।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. आने वाले पक्षियों की कुल संख्या निकालिए

एक ऐसा फिल्टर बनाइए जो लौटाए कि इस सप्ताह आपके बगीचे में कुल कितने पक्षी आए।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. व्यस्त दिनों की संख्या निकालिए

कुछ दिन बाकी दिनों से ज़्यादा व्यस्त होते हैं।
व्यस्त दिन वह है जिस दिन आपके बगीचे में पाँच या उससे ज़्यादा पक्षी आए हों।
एक ऐसा फिल्टर बनाइए जो इस सप्ताह के व्यस्त दिनों की संख्या लौटाए।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. जाँचिए कि क्या कोई दिन ऐसा था जब एक भी पक्षी नहीं आया

एक ऐसा फिल्टर बनाइए जो `true` लौटाए अगर इस सप्ताह कोई ऐसा दिन था जब बगीचे में शून्य पक्षी आए; वरना `false` लौटाए।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
