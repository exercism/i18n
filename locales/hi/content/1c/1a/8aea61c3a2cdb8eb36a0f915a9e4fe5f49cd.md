# निर्देश

पाइथागोरस त्रिक तीन प्राकृतिक संख्याओं {a, b, c} का एक ऐसा समूह है जिसके लिए

```text
a² + b² = c²
```

और साथ ही

```text
a < b < c
```

होता है।

उदाहरण के लिए,

```text
3² + 4² = 5².
```

एक इनपुट पूर्णांक N लीजिए और वे सभी पाइथागोरस त्रिक खोजिए जिनके लिए `a + b + c = N` हो।

उदाहरण के लिए, N = 1000 लेने पर ठीक एक ही ऐसा पाइथागोरस त्रिक है जिसके लिए `a + b + c = 1000` हो: `{200, 375, 425}`.
