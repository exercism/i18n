# परिचय

[निल][nil-dictionary] एक अंग्रेज़ी शब्द है जिसका अर्थ "कुछ नहीं" या "शून्य" है। Elixir में, `nil` एक विशेष वैल्यू है जो किसी वैल्यू के _अभाव_ को दर्शाती है।

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` एक एटम है, लेकिन इसे आमतौर पर `nil` लिखा जाता है, `:nil` नहीं। बूलियन वैल्यू `true` और `false` भी एटम होती हैं।

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

आप [`==`][kernel-equal] का उपयोग करके, पैटर्न मैचिंग के ज़रिए, या [`is_nil` गार्ड][kernel-is-nil] का उपयोग करके जाँच सकते हैं कि किसी वेरिएबल की वैल्यू `nil` है या नहीं।

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
