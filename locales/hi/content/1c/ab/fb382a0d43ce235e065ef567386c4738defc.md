# निर्देशों का पूरक

## रुकिए, यह तो असंभव है!

Roc में इन ऐरे ऑपरेशनों को बिना _किसी भी_ बिल्ट-इन फंक्शन का उपयोग किए लागू करना लगभग असंभव है, क्योंकि आपको ऐरे के अंत में या शुरू में एलिमेंट जोड़ने का कोई तरीका चाहिए होता है।
दूसरी भाषाओं में आप Haskell के `:` या Python के `+=` जैसे ऑपरेटर इस्तेमाल कर सकते हैं, लेकिन Roc में आपको [`List` फंक्शन](https://www.roc-lang.org/builtins/main/#Builtin.List) ही इस्तेमाल करने पड़ते हैं।

तो इस अभ्यास में आप `List.append` इस्तेमाल कर सकते हैं (लेकिन किसी और बिल्ट-इन फंक्शन का उपयोग करने से बचिए)।

बहुत सी फंक्शनल प्रोग्रामिंग भाषाएँ मुख्य संग्रह टाइप के रूप में लिंक्ड लिस्ट इस्तेमाल करती हैं।
लिंक्ड लिस्ट में एलिमेंट को शुरू में जोड़ना या पहला एलिमेंट निकालना कुशल होता है, इसलिए उन भाषाओं में आप ऐरे ऑपरेशन `List.prepend` से लागू करते हैं।
लेकिन Roc में `List` एक ऐरे होता है (बाइट्स का एक लगातार टुकड़ा)।
ऐरे की विशेषताएँ लिंक्ड लिस्ट से अलग होती हैं, जैसे कि इंडेक्स के ज़रिए एलिमेंट तक कुशलता से पहुँचने और नए एलिमेंट जोड़ने की क्षमता।
इसी वजह से Roc में हम `List.append` का इस्तेमाल अक्सर करते हैं और `List.prepend` का इस्तेमाल कम करते हैं।

## नामकरण

Roc में सामान्य निर्देशों में दिए गए नामों से थोड़े अलग नाम इस्तेमाल होते हैं:

- `append` के बजाय `concat`
- `concatenate` के बजाय `join`
- `length` के बजाय `len`
- `foldl` के बजाय `fold`
- `foldr` के बजाय `fold_rev`

लेकिन Roc में ये फंक्शन नाम मानक हैं:
- `filter`
- `map`
- `reverse`

## संकेत

यह आज़माकर देखिए:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

या

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
