# परिचय

अक्सर कई चीज़ों को एक समूह में रखना और उन समूहों को एक इकाई की तरह संभालना उपयोगी होता है। Cairo में हम ऐसे समूह को स्ट्रक्ट कहते हैं, और समूह की हर चीज़ को स्ट्रक्ट का एक फील्ड। एक स्ट्रक्ट यह तय करता है कि कौन-कौन से फील्ड उपलब्ध हैं, लेकिन स्ट्रक्ट के किसी एक खास उदाहरण को इंस्टेंस कहते हैं।

इसके अलावा, स्ट्रक्ट पर मेथड बनाए जा सकते हैं, और इन मेथड को फील्ड तक पहुँच होती है। ऐसी स्थिति में स्ट्रक्ट को ही `self` कहा जाता है। जब कोई मेथड `ref self: SomeStruct` लिखता है, तो फील्ड बदले जा सकते हैं, यानी म्यूटेट किए जा सकते हैं। जब कोई मेथड `self: SomeStruct` या `self: @SomeStruct` लिखता है, तो फील्ड बदले नहीं जा सकते: वे अपरिवर्तनीय होते हैं। म्यूटेबिलिटी को नियंत्रित करने से बॉरो-चेकर को यह सुनिश्चित करने में मदद मिलती है कि Cairo में कॉन्करेंसी से जुड़ी कई तरह की गलतियाँ होती ही नहीं।

इस अभ्यास में आप एक स्ट्रक्ट पर दो तरह के मेथड लागू करेंगे। पहले को आम तौर पर गेटर कहा जाता है: ये स्ट्रक्ट के फील्ड सबके सामने खोल देते हैं, पर किसी और को उस वैल्यू को बदलने नहीं देते।

आप दूसरी तरह के मेथड भी लागू करेंगे, जिन्हें आम तौर पर सेटर कहा जाता है। ये फील्ड की वैल्यू बदल देते हैं। Cairo में सेटर बहुत आम नहीं हैं। अगर किसी फील्ड को खुलकर बदला जा सकता है, तो उसे सिर्फ पब्लिक बना देना ज़्यादा आम है। लेकिन अगर फील्ड को अपडेट करने का कोई साइड इफेक्ट हो, तो सेटर काम आते हैं।

स्ट्रक्ट `struct` कीवर्ड से परिभाषित किए जाते हैं। कीवर्ड के बाद उस टाइप का नाम लिखा जाता है जिसे यह स्ट्रक्ट बता रहा है, और यह नाम बड़े अक्षर से शुरू होता है:

```rust
struct Item {}
```

इसके बाद और टाइप स्ट्रक्ट के अंदर उसके _फील्ड_ के रूप में जोड़े जाते हैं, और हर फील्ड का अपना टाइप होता है:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

एक ट्रेट उन मेथड का समूह तय करता है जिन्हें कोई टाइप लागू कर सकता है (यहाँ हम स्ट्रक्ट पर ध्यान देंगे, पर ट्रेट को इनम पर भी लागू किया जा सकता है)। जब यह ट्रेट लागू किया गया हो, तब इन मेथड को उस टाइप के इंस्टेंस पर कॉल किया जा सकता है। ट्रेट `trait` कीवर्ड से परिभाषित किए जाते हैं, और ट्रेट के अंदर हम वे मेथड सिग्नेचर लिखते हैं जिन्हें हम अपने टाइप में लागू कराना चाहते हैं।

```rust
trait ImplTrait {
    // Define the method signature
    fn new() -> Item;
}
```

अंत में, स्ट्रक्ट पर मेथड `impl` ब्लॉक के अंदर परिभाषित किए जा सकते हैं, और यह ब्लॉक तय किए गए ट्रेट को लागू करता है:

```rust
impl ItemImpl of ImplTrait {
    // initializes and returns a new instance of our Item struct
    fn new() -> Item {
        Item {}
    }
}
```
