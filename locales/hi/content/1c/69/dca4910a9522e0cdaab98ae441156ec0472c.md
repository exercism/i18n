# परिचय

F# का `char` प्रकार टेक्स्ट के सबसे छोटे एड्रेस योग्य घटकों को दर्शाने वाली 16 बिट की वैल्यू है, जो डिफ़ॉल्ट रूप से अपरिवर्तनीय है।

`char` को सिंगल कोट्स के साथ लिटरल के रूप में परिभाषित किया जा सकता है:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

स्ट्रिंग `char` का एक अनुक्रम होती है।

किसी स्ट्रिंग से एक `char` को (शून्य-आधारित) इंडेक्सिंग की मदद से निकाला जा सकता है:

```fsharp
"Exercism"[4] //  =>  'c'
```

स्ट्रिंग पर इटरेशन करने पर हर कदम पर एक `char` मिलता है।

अगला उदाहरण सुविधा के लिए एक हायर-ऑर्डर फंक्शन और एक अनाम फंक्शन इस्तेमाल करता है।
इन्हें आगे सिलेबस में ठीक से समझाया जाएगा, लेकिन अभी के लिए ये किसी स्ट्रिंग के अक्षरों पर लूप लिखने का संक्षिप्त तरीका हैं।

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

जैसा ऊपर दिखाया गया है, एक `char` को उसकी `int` वैल्यू में कास्ट किया जा सकता है।
यह दूसरी लिपियों के लिए भी (*कम से कम कुछ मामलों में*) काम करता है:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

अक्षरों की तुलना करते समय अंतर्निहित Int16 इस्तेमाल होता है:

```fsharp
'A' < 'D'  // =>  true
```

इसके अलावा, एक `int` को `char` में कास्ट किया जा सकता है:

```fsharp
char 77  // => 'M'
```

`System.Char` लाइब्रेरी में .NET भाषा के लिए अपेक्षित सभी मेथड मौजूद हैं, जैसे ऊपरी/निचली केस में बदलना:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
