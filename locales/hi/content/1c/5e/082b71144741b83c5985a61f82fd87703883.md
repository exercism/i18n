# परिचय

**रिकर्सिव फंक्शन** वे फंक्शन होते हैं जो खुद को कॉल करते हैं।

एक _रिकर्सिव फंक्शन_ में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना चाहिए।

**बेस केस** फंक्शन को दोबारा कॉल किए बिना एक वैल्यू लौटाता है।
**रिकर्सिव केस** फंक्शन को दोबारा कॉल करता है और इनपुट को इस तरह बदलता है कि वह किसी समय बेस केस से मेल खाए।

यहाँ एक उदाहरण है जो एक ऐरे के एलिमेंट गिनता है।

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

एक _रिकर्सिव फंक्शन_ में कई _बेस केस_ और/या कई _रिकर्सिव केस_ हो सकते हैं।
उदाहरण के लिए [फिबोनाची श्रेणी][wiki-fibonacci] एक रिकर्सिव श्रेणी है जिसमें दो _बेस केस_ होते हैं।

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

किसी ऐरे में दी गई वैल्यू `x` कितनी बार आती है, यह गिनने के लिए दो _रिकर्सिव केस_ होते हैं।

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

व्यवहार में, ऐरे और दूसरे एन्यूमरेबल डेटा स्ट्रक्चर पर इटरेशन करने के लिए अक्सर बिल्ट-इन फंक्शन इस्तेमाल किए जाते हैं, जैसे `map` और `reduce`, या `[.[] | select(...)]` जैसे [स्ट्रीम के ज़रिए][map-implementation]।
भीतर से देखें तो, कुछ बिल्ट-इन [रिकर्सन का इस्तेमाल करके बनाए गए हैं][walk-implementation]।
