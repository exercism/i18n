# परिचय

एक स्ट्रिंग टेक्स्ट डेटा को दर्शाती है।
Swift में [`String`][strings-and-characters] `Character` वैल्यू का एक क्रमबद्ध संग्रह है, जिसमें हर अक्षर एक Unicode अक्षर को दर्शाता है।

स्ट्रिंग बनाने के लिए आप स्ट्रिंग लिटरल इस्तेमाल करते हैं। स्ट्रिंग लिटरल डबल कोटेशन चिह्न (`"`) से घिरे अक्षरों का क्रम होता है।
कई लाइनों वाली स्ट्रिंग के लिए तीन डबल कोटेशन चिह्न (`"""`) लगाइए:

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift की स्ट्रिंग, Foundation फ्रेमवर्क की [`NSString`][nsstring-docs] क्लास के साथ सहज ही जुड़ जाती है। इससे टेक्स्ट प्रोसेस करने की कई सुविधाएँ उपलब्ध होती हैं।

## अक्षर

एक `Character` एक ही विस्तृत ग्रेफीम क्लस्टर को दर्शाता है, यानी ऐसा अक्षर जिसे मनुष्य पढ़ सकता है और जो एक या अधिक [Unicode स्केलर वैल्यू][unicode-scalar-values] से मिलकर बनता है।
Unicode स्केलर वैल्यू, `U+0000` से `U+D7FF` तक या `U+E000` से `U+10FFFF` तक की सीमा में रहने वाला 21-बिट कोड पॉइंट होती है, जिसमें दोनों सिरे शामिल हैं।

```swift
let aChar: Character = "A"
```

## टाइप अनुमान

जब आप स्ट्रिंग लिटरल लिखते हैं, तो Swift उसका टाइप अपने आप `String` मान लेता है।
किसी एक अक्षर को `Character` के रूप में संग्रहीत करने के लिए आपको उसका टाइप साफ़-साफ़ लिखना पड़ता है:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## जोड़ना

आप जोड़ने वाले ऑपरेटर (`+`) की मदद से स्ट्रिंग को जोड़ सकते हैं:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

पहले अक्षर को स्ट्रिंग में बदले बिना आप `+` की मदद से किसी `Character` को सीधे `String` से नहीं जोड़ सकते।
लेकिन [`append(_:)`][append] मेथड की मदद से आप किसी स्ट्रिंग या अक्षर को सीधे ऐसी स्ट्रिंग में जोड़ सकते हैं जिसे बदला जा सकता है:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## स्ट्रिंग इंटरपोलेशन

[स्ट्रिंग इंटरपोलेशन][string-interpolation] की मदद से आप स्ट्रिंग लिटरल के अंदर कॉन्स्टेंट, वेरिएबल, लिटरल और एक्सप्रेशन डालकर एक स्ट्रिंग बना सकते हैं।
हर एक्सप्रेशन को ब्रैकेट में लपेटिए और उससे पहले बैकस्लैश लगाइए (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## स्ट्रिंग और अक्षर की प्रॉपर्टी

स्ट्रिंग और अक्षर अपनी सामग्री देखने के लिए कई प्रॉपर्टी देते हैं।

### स्ट्रिंग की प्रॉपर्टी

आम स्ट्रिंग प्रॉपर्टी:

| प्रॉपर्टी  | विवरण                                    | उदाहरण                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | अगर स्ट्रिंग में कोई अक्षर न हो तो `true` लौटाती है | `"Hello".isEmpty` का मान `false` होता है |
| `count`   | स्ट्रिंग में अक्षरों की संख्या लौटाती है | `"Hello".count` का मान `5` होता है       |

प्रॉपर्टी की पूरी सूची के लिए [Apple की String डॉक्युमेंटेशन][string-docs] देखिए।

### अक्षर की प्रॉपर्टी

आम अक्षर प्रॉपर्टी:

| प्रॉपर्टी       | विवरण                                   | उदाहरण                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | अगर अक्षर छोटा हो तो `true` लौटाती है  | `"a".isLowercase` का मान `true` होता है |
| `isUppercase`  | अगर अक्षर बड़ा हो तो `true` लौटाती है  | `"A".isUppercase` का मान `true` होता है |
| `isNumber`     | अगर अक्षर एक अंक हो तो `true` लौटाती है    | `"1".isNumber` का मान `true` होता है    |
| `isWhitespace` | अगर अक्षर व्हाइटस्पेस हो तो `true` लौटाती है | `" ".isWhitespace` का मान `true` होता है|

प्रॉपर्टी की पूरी सूची के लिए [Apple की Character डॉक्युमेंटेशन][character-docs] देखिए।

## टाइप बदलना

आप `String(_:)` इनिशियलाइज़र की मदद से दूसरे टाइप को स्ट्रिंग में बदल सकते हैं। यह `Int`, `Double` और `Character` जैसे मानक टाइप सपोर्ट करता है:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## खास अक्षर

Swift के स्ट्रिंग लिटरल खास अक्षरों के लिए कई [एस्केप सीक्वेंस][special-characters] सपोर्ट करते हैं:

| सीक्वेंस   | विवरण                   |
| ---------- | ----------------------------- |
| `\0`       | नल अक्षर                |
| `\\`       | बैकस्लैश                     |
| `\t`       | आड़ा टैब                |
| `\n`       | लाइन फीड (नई लाइन)           |
| `\r`       | कैरिज रिटर्न               |
| `\'`       | सिंगल कोटेशन चिह्न         |
| `\"`       | डबल कोटेशन चिह्न         |
| `\u{n}`    | कोई भी Unicode स्केलर (हेक्साडेसिमल) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
