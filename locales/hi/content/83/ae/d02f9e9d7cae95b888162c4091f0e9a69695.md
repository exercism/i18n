# परिचय

[सिंबल][symbols] ऐसे आइडेंटिफायर होते हैं जिनका एक नाम होता है और जिन्हें किसी वैल्यू को दर्शाने के लिए इस्तेमाल किया जा सकता है।
सिंबल, सिंबल लिटरल से बनते हैं। इसमें नाम से पहले `:` अक्षर लगाया जाता है, जैसे `:foo`.
इन्हें कोट्स के साथ भी लिखा जा सकता है, जैसे `:"foo"`। इससे नाम में स्पेस जैसी चीज़ें भी रखी जा सकती हैं।

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

इस भाषा में सिंबल कई जगहों पर इस्तेमाल होते हैं, जैसे हैश में की के तौर पर, और मेथड तथा वेरिएबल के नाम दर्शाने के लिए।

## आइडेंटिफायर

सिंबल स्ट्रिंग से अलग इसलिए हैं क्योंकि ये आइडेंटिफायर होते हैं, कोई डेटा या टेक्स्ट नहीं।
इसका मतलब है कि एक ही नाम वाले दो सिंबल हमेशा एक ही ऑब्जेक्ट होते हैं।

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## सिंबल में बदलाव

सिंबल अपरिवर्तनीय होते हैं, यानी इन्हें बदला नहीं जा सकता।
इसका मतलब है कि जब आप किसी सिंबल को "बदलते" हैं, तो वास्तव में एक नया सिंबल बनता है।
सिंबल को बदलने के लिए कुछ मेथड मौजूद हैं, और ये सभी नया सिंबल लौटाते हैं।
सभी मेथड [सिंबल API][symbols-api] में मिलते हैं।

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

सिंबल अपरिवर्तनीय होते हैं, इसका फायदा यह है कि ये स्ट्रिंग की तुलना में कम मेमोरी लेते हैं, और आइडेंटिफायर के तौर पर इस्तेमाल करना भी ज़्यादा सुरक्षित होता है।

## रूपांतरण

सिंबल को स्ट्रिंग में बदला जा सकता है, और स्ट्रिंग को सिंबल में।
यह तब काम आता है जब आप किसी सिंबल में बदलाव करना चाहते हैं, या किसी सिंबल को स्ट्रिंग की तरह इस्तेमाल करना चाहते हैं।
किसी स्ट्रिंग को सिंबल बनाने के लिए `String#to_sym` मेथड इस्तेमाल कीजिए, और इसका उल्टा करने के लिए `Symbol#to_s` मेथड।
सिंबल पर उपलब्ध मेथड की संख्या सीमित है। इसलिए जब किसी नए सिंबल की ज़रूरत हो, तो सिंबल को स्ट्रिंग में बदलकर उस पर स्ट्रिंग के मेथड इस्तेमाल करना काम आ सकता है।

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
