# सीखना

## Emacs से शुरुआत

तो आपने Emacs इंस्टॉल कर लिया है। अब आगे क्या?

खैर, `C-h t` दबाकर आप ट्यूटोरियल शुरू कर सकते हैं, और शुरुआत के लिए यह बुरी जगह नहीं है। यह ट्यूटोरियल आपको Emacs में एडिट करने, खोजने और इधर-उधर घूमने की बुनियादी बातें सिखाएगा।

अगर आप Emacs में बिल्कुल नए हैं, तो स्टार्टर किट ले लेना ठीक रहेगा, जिसमें कॉन्फ़िगरेशन और पैकेज पहले से सेट होकर आते हैं।

[Emacs Prelude](http://batsov.com/prelude/) पैकेज में समझदार डिफ़ॉल्ट सेटिंग्स और पैकेजों का बढ़िया संग्रह मिलता है।

Emacs Prelude इंस्टॉल करने के लिए टर्मिनल में यह चलाइए:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

और आगे के निर्देशों के लिए [इंस्टॉलेशन गाइड](https://prelude.emacsredux.com/en/latest/installation/) ज़रूर देखिए।


अगर आप vim से परिचित हैं, तो आपको [Doom Emacs](https://github.com/doomemacs/doomemacs) स्टार्टर किट पसंद आ सकता है, जिसमें [evil-mode](https://github.com/emacs-evil/evil) की मदद से vim इम्युलेशन जोड़ा गया है।

Doom Emacs इंस्टॉल करने के लिए टर्मिनल में यह चलाइए:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

और आगे के निर्देशों के लिए [इंस्टॉलेशन गाइड](https://github.com/doomemacs/doomemacs#install) ज़रूर देखिए।

## सिंटैक्स जाँच और लिंटिंग सेट करना

[Flycheck](https://www.flycheck.org/en/latest/) के साथ सिंटैक्स जाँच और लिंटिंग सेट करने की सलाह दी जाती है।

अगर आपने अपने Emacs में [MELPA](https://melpa.org/) रिपॉज़िटरी पहले से नहीं जोड़ी है, तो अपनी [इनिश फ़ाइल](https://www.flycheck.org/en/latest/glossary.html#term-init-file) में यह जोड़कर ऐसा कीजिए:

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

[use-package](https://github.com/jwiegley/use-package) के बिना Flycheck इंस्टॉल और सेट करने के लिए अपनी इनिश फ़ाइल में यह जोड़िए:

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

[use-package](https://github.com/jwiegley/use-package) के साथ Flycheck इंस्टॉल और सेट करने के लिए अपनी इनिश फ़ाइल में यह जोड़िए:

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

ज़्यादा जानकारी और समस्या हल करने के लिए [Flycheck का डॉक्युमेंटेशन](https://www.flycheck.org/en/latest/user/troubleshooting.html) देखिए।

## Emacs Lisp सीखना

Emacs Lisp का सबसे अच्छा डॉक्युमेंटेशन... खुद Emacs के साथ आता है!
[Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html) खोलने के लिए `C-h i` दबाइए और Elisp वाली प्रविष्टि ढूँढिए, या Help &rarr; More Manuals
&rarr; Emacs Lisp Reference चुनिए। ध्यान रखिए कि कुछ डिस्ट्रीब्यूशन में यह मैनुअल नहीं मिल सकता; ऐसी स्थिति में आप इसे [ऑनलाइन](https://www.gnu.org/software/emacs/manual/elisp.html) पा सकते हैं।

अगर आप Elisp में बिल्कुल नए हैं, तो [Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro) पढ़ सकते हैं, जो इसी तरीके से खुलता है।

## Emacs Lisp की बेस्ट प्रैक्टिस और कन्वेंशन

Emacs मैनुअल में Emacs Lisp की [Coding Conventions](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) पर एक सेक्शन है।
GitHub पर समुदाय द्वारा बनाई और संभाली जाने वाली एक [Style Guide](https://github.com/bbatsov/emacs-lisp-style-guide) भी है।
