# संसाधन

* [The Rust Programming Language](https://doc.rust-lang.org/book/) Rust की शुरुआत करने और Rust की खास विशेषताओं को गहराई से समझने के लिए बहुत अच्छा संसाधन है।
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) Rust में आप जो सबसे आम चीज़ें लिखेंगे, उनके उदाहरण दिखाता है।
* [Rust API Documentation](http://doc.rust-lang.org/std/) का इस्तेमाल नए मेथड खोजने और यह समझने के लिए किया जा सकता है कि वे कैसे काम करते हैं।
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) का इस्तेमाल अपनी समस्या खोजने और यह देखने के लिए किया जा सकता है कि उसका जवाब पहले ही दिया जा चुका है या नहीं। आप सवाल पूछ भी सकते हैं और जवाब दे भी सकते हैं।
* [Rust User Forum](http://users.rust-lang.org), Rust के बारे में सामान्य चर्चा के लिए है।
* [/r/rust](http://www.reddit.com/r/rust/) Rust का आधिकारिक सबरेडिट है।
* [The Rust Programming Language](https://discord.gg/rust-lang) का आधिकारिक सर्वर [Discord](https://discordapp.com/) पर Rust के बारे में तुरंत सवाल पूछने और चर्चा करने के लिए इस्तेमाल किया जा सकता है।
