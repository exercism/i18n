# निर्देश परिशिष्ट

## `from_quote` के लाभ और हानि

`DateOfBirth.from_quote` फंक्शन `"YYYY-MM-DD"` के रूप में लिखी गई स्ट्रिंग को पार्स करके एक `DateOfBirth` बनाता है।
इससे ऐसा कोड लिखना संभव हो जाता है:

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

यह कोड कंपाइल टाइम पर अपने आप `DateOfBirth.from_quote("2019-01-20")` को कॉल करता है।
इससे प्रोग्राम तेज़ चल सकता है, क्योंकि रनटाइम पर पार्सिंग संभालने की ज़रूरत नहीं पड़ती। साथ ही यह पक्का करता है कि जिन तारीखों को `from_quote` अस्वीकार करता है, वे रनटाइम के बजाय कंपाइल टाइम पर ही पकड़ ली जाती हैं।
इसके अलावा, इससे कोड सुंदर और पढ़ने लायक बन जाता है।
उदाहरण के लिए, इस अभ्यास के टेस्ट में से एक यह है:

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

लेकिन इस कोड को पढ़ने वाला कोई भी यह मान सकता है कि `shared_birthday` फंक्शन `List(Str)` लेता है, जबकि वास्तव में यह `List(DateOfBirth)` लेता है।
इससे भ्रम और गलतियाँ हो सकती हैं।
इसी वजह से आप थोड़ा लंबा, पर ज़्यादा स्पष्ट तरीका पसंद कर सकते हैं: `"2019-01-20".DateOfBirth`, जो कंपाइल टाइम पर `from_quote` को ही कॉल करता है।

अपने खुद के प्रोग्राम में आप एक सुविधाजनक कंस्ट्रक्टर देना पसंद कर सकते हैं, जैसे यह:

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

इस कंस्ट्रक्टर को कंपाइल टाइम पर भी कॉल किया जा सकता है, जैसे यह:

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

ध्यान दीजिए: इस परिभाषा को टॉप लेवल पर रखने से यह कंपाइल टाइम पर ही चल जाती है (क्योंकि फंक्शन प्योर है और इनपुट कंपाइल टाइम पर ही पता होते हैं)।
किसी फंक्शन के अंदर आप उसी कंस्ट्रक्टर का रनटाइम पर इस्तेमाल कर सकते हैं।

## रैंडम लाइब्रेरी

टेस्ट ऐप में [`roc-random` पैकेज](https://github.com/kili-ilo/roc-random) `random` एलियास के साथ उपलब्ध है।
स्टब `random.Random` इंपोर्ट करता है।

## संकेत

<details>
<summary>संकेत देखें</summary>

`Random.Generator(a)` बताता है कि टाइप `a` की वैल्यू कैसे बनाई जाए।
कई रैंडम ड्रॉ को जोड़ने के लिए `Random.list` का इस्तेमाल कीजिए और उनके नतीजों को बदलने के लिए `Random.map` का।
`Random.step(state, generator)` `{ value, state }` लौटाता है। सिम्युलेट किए गए समूहों के बीच अपडेट हुई स्थिति को आगे ले जाइए, ताकि आप वही नमूना दोबारा न लें।

</details>
