# दृश्यता

कोड को व्यवस्थित करने के लिए क्लास का उपयोग करते समय, प्रॉपर्टी, मेथड और कॉन्स्टेंट की दृश्यता सही एब्स्ट्रैक्शन और ज़िम्मेदारियों को बढ़ावा दे सकती है।
प्रॉपर्टी, मेथड और कॉन्स्टेंट को घोषित करते समय `public`, `private` या `protected` कीवर्ड का उपयोग करने से उनकी दृश्यता तय होती है।
दृश्यता हमेशा क्लास की प्रॉपर्टी, मेथड या कॉन्स्टेंट के बाहरी उपयोग के संदर्भ में होती है।
यानी, अगर कोई प्रॉपर्टी `public` घोषित है, तो उसे बाहरी कॉल से देखा और इस्तेमाल किया जा सकता है।
प्राइवेट प्रॉपर्टी, मेथड और कॉन्स्टेंट को बाहरी कॉल से न देखा जा सकता है, न इस्तेमाल किया जा सकता है।

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

प्रोटेक्टेड प्रॉपर्टी, मेथड और कॉन्स्टेंट सिर्फ अपनी ही क्लास और इनहेरिटेंस से बनी चाइल्ड क्लास को दिखाई देते हैं।

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
