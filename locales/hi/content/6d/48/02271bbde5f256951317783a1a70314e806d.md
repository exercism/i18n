# इंस्टॉलेशन

## .NET इंस्टॉल करना

C# ट्रैक [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) प्लेटफॉर्म पर बना है। यह प्लेटफॉर्म Windows, Linux और macOS पर चलता है।
.NET प्रोजेक्ट बनाने के लिए आप .NET कमांड लाइन इंटरफेस (CLI) का इस्तेमाल कर सकते हैं।
यह CLI .NET SDK का हिस्सा है। आप [इंस्टॉलेशन निर्देशों](https://dotnet.microsoft.com/download/dotnet/8.0) का पालन करके इसे इंस्टॉल कर सकते हैं।
ध्यान दें: C# ट्रैक के लिए SDK का वर्ज़न 9.0 या उससे अधिक ज़रूरी है।

इंस्टॉलेशन पूरा होने के बाद आप टर्मिनल में यह कमांड चलाकर जाँच सकते हैं कि CLI ठीक से इंस्टॉल हुआ है या नहीं:

```bash
dotnet --version
```

अगर आउटपुट में `9.0.100` के बराबर या उससे बड़ा वर्ज़न दिख रहा है, तो .NET SDK ठीक से इंस्टॉल हो चुका है।

## आईडीई का इस्तेमाल करना

अगर आपको कोड लिखने का ज़्यादा सुविधाओं वाला अनुभव चाहिए, तो आप शायद [आईडीई या इंटीग्रेटेड डेवलपमेंट एनवायरनमेंट)](https://en.wikipedia.org/wiki/Integrated_development_environment) इस्तेमाल करना चाहेंगे।
ये सबसे लोकप्रिय आईडीई हैं जिनमें .NET प्रोजेक्ट बनाए जा सकते हैं:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) और उसका [C# एक्सटेंशन](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

ध्यान दें: .NET प्रोजेक्ट का फॉर्मैट पुराने वर्ज़न से काफी अलग है, इसलिए Visual Studio 2015 जैसे पुराने आईडीई समर्थित नहीं हैं।
