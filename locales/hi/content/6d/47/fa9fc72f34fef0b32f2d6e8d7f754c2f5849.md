# इंस्टॉलेशन

इस ट्रैक के हल 32-बिट RISC-V असेंबली में लिखे जाते हैं और एमुलेशन पर चलते हैं, इसलिए RISC-V हार्डवेयर की ज़रूरत नहीं पड़ती।
हर अभ्यास के साथ एक Makefile आता है, जो टेस्ट बनाता है और उन्हें चलाता है।
इसे इस्तेमाल करने के लिए आपको तीन टूल चाहिए:

- [Zig][zig], जो `zig cc` के ज़रिए RISC-V असेंबलर, C कंपाइलर और लिंकर देता है।
- [Make][make], जो बिल्ड चलाता है।
- [QEMU][qemu] से `qemu-riscv32`, जो तैयार किए गए प्रोग्राम को चलाता है।

## macOS

किसी भी उपयुक्त वर्चुअलाइज़ेशन समाधान (जैसे [Lima][lima]) की मदद से एक Linux वर्चुअल मशीन शुरू कीजिए और नीचे दिए गए किसी Linux डिस्ट्रिब्यूशन वाले हिस्से का पालन कीजिए।

## Windows

[Windows Subsystem for Linux][wsl] का उपयोग कीजिए और नीचे दिए गए किसी Linux डिस्ट्रिब्यूशन वाले हिस्से का पालन कीजिए।
इसके अलावा, आप एक Linux वर्चुअल मशीन भी सेटअप कर सकते हैं।

## Debian / Ubuntu

Make और QEMU के यूज़र-मोड एमुलेटर इंस्टॉल कीजिए:

```shell
sudo apt install make qemu-user
```

इसके बाद [सीधे डाउनलोड][zig-install] में बताए अनुसार Zig 0.15.2 या उससे नया संस्करण इंस्टॉल कीजिए।

## Fedora

तीनों टूल इस तरह इंस्टॉल कीजिए:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

तीनों टूल इस तरह इंस्टॉल कीजिए:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

तीनों टूल इस तरह इंस्टॉल कीजिए:

```shell
sudo zypper install zig make qemu-linux-user
```

## अपना इंस्टॉलेशन जाँचिए

पुष्टि कीजिए कि तीनों टूल मिल रहे हैं:

```shell
zig version
make --version
qemu-riscv32 --version
```

इसके बाद Exercism CLI की मदद से एक अभ्यास डाउनलोड कीजिए और उसके टेस्ट चलाइए:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
