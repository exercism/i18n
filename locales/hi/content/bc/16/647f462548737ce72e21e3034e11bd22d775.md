# परिचय

टपल कई वैल्यू का एक _अपरिवर्तनीय_ समूह होता है। इन वैल्यू के नाम नहीं होते, लेकिन उनका क्रम तय रहता है।
टपल में किसी भी डेटा टाइप, या एक साथ कई डेटा टाइप, की वैल्यू रखी जा सकती है। इसमें दूसरे टपल भी रखे जा सकते हैं।

टपल लिखते समय वैल्यू को कॉमा से अलग करके `(` और `)` के बीच रखा जाता है: `(<element_1>, ... , <element_n>)`।

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

सिर्फ उन्हीं टपल की आपस में तुलना की जा सकती है जिनकी लंबाई और टाइप एक जैसे हों और क्रम भी एक जैसा हो।
टपल में संरचनात्मक समानता होती है। इसका मतलब है कि दो टपल तभी बराबर होते हैं जब उनकी सारी वैल्यू बराबर हों।

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

टपल से वैल्यू निकालने के तीन तरीके हैं:

- `fst` और `snd` फंक्शन
- टपल डिकंस्ट्रक्शन
- पैटर्न मैचिंग

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
