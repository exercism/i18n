# परिचय

Unison सही और गलत वैल्यू को `Boolean` टाइप से प्रदर्शित करता है। ऐसी वैल्यू केवल दो हैं: `true` और `false`।

```unison
trueVariable = true
falseVariable = false
```

हम बूलियन एक्सप्रेशन का मूल्यांकन एंड, ऑर और नॉट ऑपरेटरों की मदद से कर सकते हैं। एंड को `&&` से, ऑर को `||` से, और नॉट को `not` से दर्शाया जाता है।

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Unison के बूलियन एक्सप्रेशन शॉर्ट-सर्किटिंग की सुविधा देते हैं। अगर किसी `&&` एक्सप्रेशन का पहला आर्गुमेंट `false` है, तो दूसरे आर्गुमेंट का मूल्यांकन जारी रखने का कोई कारण नहीं है। इसी तरह, अगर किसी `||` एक्सप्रेशन का पहला आर्गुमेंट `true` है, तो वह एक्सप्रेशन तुरंत `true` लौटा देता है।

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
