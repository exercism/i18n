# मेंटेनरों की रेपो अनुमतियाँ

ट्रैक मेंटेनर वह होता है जो उस ट्रैक की GitHub टीम का सदस्य हो। किसी ट्रैक टीम का सदस्य बनना _केवल निमंत्रण से_ होता है।

```exercism/note
अगर आप ट्रैक मेंटेनर बनना चाहते हैं, तो कृपया [फोरम](https://forum.exercism.org/c/exercism/building-exercism/125) पर एक टॉपिक खोलिए।
```

## रखरखाव श्रेणी

रखरखाव की पाँच श्रेणियाँ हैं:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

किसी ट्रैक की रखरखाव श्रेणी तीन बातों से तय होती है:

1. ट्रैक सक्रिय है या नहीं (यानी छात्र वेबसाइट पर ट्रैक से जुड़ सकते हैं)
2. ट्रैक मेंटेनरों की संख्या
3. उन ट्रैक मेंटेनरों की संख्या जो `cross-track-maintainers` GitHub टीम में भी हैं

रखरखाव श्रेणी तय करने के लिए, इस तालिका में से वह पहली श्रेणी ढूँढिए जो ट्रैक पर लागू होती है:

| श्रेणी                | सक्रिय? | मेंटेनरों की संख्या   | क्रॉस-ट्रैक मेंटेनरों की संख्या    |
| --------------------- | ------- | --------------------- | --------------------------------- |
| wip-track             | नहीं    | कोई भी                | कोई भी                            |
| unmaintained          | हाँ     | 0                     | 0                                 |
| maintained-autonomous | हाँ     | > 0                   | = मेंटेनरों की संख्या              |
| maintained-solitary   | हाँ     | 1                     | 0                                 |
| maintained            | हाँ     | > 1                   | < मेंटेनरों की संख्या              |

## रेपो अनुमतियाँ

रेखरखाव श्रेणी का उपयोग ट्रैक के GitHub रेपो की अनुमतियाँ तय करने के लिए किया जाता है।

| श्रेणी                | PR ज़रूरी | PR की मंज़ूरी ज़रूरी | क्रॉस-ट्रैक टीम समीक्षाएँ |
| --------------------- | --------- | ------------------- | ------------------------ |
| wip-track             | नहीं      | नहीं                | नहीं                     |
| unmaintained          | हाँ       | हाँ                 | हाँ                      |
| maintained-solitary   | हाँ       | हाँ                 | हाँ                      |
| maintained-autonomous | हाँ       | नहीं                | नहीं                     |
| maintained            | हाँ       | नहीं                | नहीं                     |

```exercism/caution
`wip-track` ही एकमात्र श्रेणी है जिसमें मेंटेनर `main` पर सीधे बदलाव भेज सकते हैं।
```

```exercism/caution
टूलिंग रेपो में PR की मंज़ूरी _हमेशा_ ज़रूरी होगी, क्योंकि उनकी सामग्री [CODEOWNERS फाइल](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) से सुरक्षित रहती है।
```
