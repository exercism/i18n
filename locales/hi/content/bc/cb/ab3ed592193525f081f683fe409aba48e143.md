# परिचय

एक switch एक्सप्रेशन किसी वैल्यू का मिलान पैटर्न के समूह के किसी एक केस से कर सकता है और संबंधित वैल्यू लौटा सकता है या संबंधित कार्रवाई कर सकता है। यह संबंध `=>` चिह्न से दर्शाया जाता है। इसके अलावा, हर पैटर्न के साथ एक वैकल्पिक केस गार्ड भी हो सकता है, जिसे `when` कीवर्ड से शुरू किया जाता है। switch की उस "आर्म" का चयन हो सके, इसके लिए केस गार्ड एक्सप्रेशन का मान सही होना ज़रूरी है। केस (जिन्हें _switch आर्म_ भी कहा जाता है) टेक्स्ट के क्रम में जाँचे जाते हैं। जैसे ही कोई मिलान मिलता है, यह प्रक्रिया बीच में रोक दी जाती है और संबंधित वैल्यू लौटा दी जाती है।

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
