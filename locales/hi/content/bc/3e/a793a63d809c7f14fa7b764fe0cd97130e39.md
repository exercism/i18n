# बारे में

Elixir में दो तरह की संख्याएँ होती हैं: पूर्णांक और दशमलव संख्याएँ।

पूर्णांक पूरी संख्याएँ होती हैं।

```elixir
integer = 3
# => 3
```

पूर्णांकों के साथ काम करने के लिए कुछ उपयोगी फंक्शन [`Integer`][integer] मॉड्यूल में मिलते हैं।

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

बड़े पूर्णांक (और दशमलव संख्याएँ भी) आमतौर पर हर 3 अंकों के समूह को अंडरस्कोर से अलग करके लिखे जाते हैं।

```elixir
1_000_000
# => 1000000
```

Elixir में संख्याओं का अधिकतम आकार सिर्फ सिस्टम पर उपलब्ध मेमोरी से सीमित होता है, क्योंकि Elixir [आर्बिट्रेरी प्रिसिज़न अर्थमेटिक][arbitrary-precision-arithmetic] इस्तेमाल करता है।

Elixir में [बाइनरी, ऑक्टल और हेक्साडेसिमल पूर्णांक][integers-in-other-bases] लिखने के लिए शॉर्टकट नोटेशन भी उपलब्ध हैं।

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## तुलना

अगर पूर्णांक और दशमलव संख्या की वैल्यू एक जैसी हो, तो उन्हें बराबर ([`==`][kernel-equal]) माना जा सकता है। लेकिन चूँकि दोनों अलग-अलग डेटा टाइप के हैं, इसलिए वे कभी सख्ती से बराबर ([`===`][kernel-strictly-equal]) नहीं होते।

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
