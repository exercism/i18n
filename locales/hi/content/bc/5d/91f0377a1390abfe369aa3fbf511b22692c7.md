# स्ट्रिंग

**स्ट्रिंग** टेक्स्ट का एक हिस्सा होती है। Sather में इसका टाइप `STR` है, और स्ट्रिंग दोहरे कोट्स के बीच लिखी जाती है।

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## स्ट्रिंग जोड़ना

`+` दो स्ट्रिंग को एक के बाद एक जोड़ देता है।

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

इनके बीच कुछ नहीं रखा जाता, इसलिए स्पेस के लिए अलग से लिखना पड़ता है। इसे छोड़ देने पर `"JeanSibelius"` मिलता है।

## यह कितनी लंबी है?

`.size` बताता है कि एक स्ट्रिंग में कितने अक्षर हैं। यह एक पूर्णांक होता है, इसलिए इसका टाइप `INT` है।

```sather
"Sibelius".size      -- 8
```

`.size` के बाद कोई ब्रैकेट नहीं लगते, ठीक वैसे ही जैसे ऐसे रूटीन में नहीं लगते जो कोई आर्गुमेंट नहीं लेता।

## एक टुकड़ा निकालना

`.head(n)` पहले `n` अक्षर देता है। `.tail(n)` अंतिम `n` अक्षर देता है।

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` शुरू से गिनता है, `tail` पीछे से गिनता है। दोनों मूल स्ट्रिंग को वैसा ही छोड़ देते हैं और एक नई स्ट्रिंग लौटा देते हैं।
