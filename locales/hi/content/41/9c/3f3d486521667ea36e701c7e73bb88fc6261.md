# परिचय

`Complex numbers` कोई जटिल चीज़ नहीं हैं।
इन्हें बस एक कम डरावने नाम की ज़रूरत है।


ये इतनी उपयोगी हैं, खासकर इंजीनियरिंग और विज्ञान में, कि Python ने पूर्णांक ([`int`s][ints]) और दशमलव संख्याओं ([`float`s][floats]) की तरह [`complex`][complex] को भी एक मानक संख्या टाइप के रूप में शामिल किया है।


Python में एक `complex` वैल्यू असल में दो दशमलव संख्याओं का जोड़ा होती है:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

इन दोनों भागों को "वास्तविक" और "काल्पनिक" कहा जाता है।
आपने शायद सुना होगा कि "`i` (या `j`) -1 का वर्गमूल है"।
फिलहाल इसका मतलब बस इतना है कि काल्पनिक भाग _परिभाषा से_ समानता `1j * 1j == -1` को संतुष्ट करता है।
यह एक सरल विचार है, लेकिन इससे गणित में रोचक परिणाम निकलते हैं।

Python में "काल्पनिक" भाग को `j` से दर्शाया जाता है (_गणित की किताबों में दिखने वाले `i` से नहीं_), और `j` को किसी संख्या के ठीक बाद ही आना चाहिए, ताकि Python उसे वेरिएबल का नाम न समझ ले:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


सम्मिश्र संख्याएँ बनाने के दो आम तरीके हैं।

1) [`complex(real, imag)`][complex] कंस्ट्रक्टर दो `float` पैरामीटर लेता है:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    यह कंस्ट्रक्टर स्ट्रिंग इनपुट को भी पढ़ सकता है।
    इसमें एक अजीब सीमा है: अगर स्ट्रिंग में स्पेस हों, तो यह काम नहीं करता।

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) सम्मिश्र संख्या को `<real part> + <complex part>j` लिटरल के रूप में लिखा जा सकता है, या अगर वास्तविक भाग शून्य हो तो सिर्फ `<complex part>j` के रूप में:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    अंतिम परिणाम वही होता है जो `complex()` कंस्ट्रक्टर इस्तेमाल करने पर मिलता है।


## अंकगणित

पूर्णांकों और दशमलव संख्याओं के साथ इस्तेमाल होने वाले अधिकांश [`operators`][operators] सम्मिश्र संख्याओं के साथ भी काम करते हैं।

सम्मिश्र संख्याओं पर पूर्णांक विभाजन _**नहीं**_ हो सकता, इसलिए `//` और `%` ऑपरेटर तथा `divmod()` फंक्शन सम्मिश्र संख्या टाइप के लिए काम नहीं करेंगे।

सम्मिश्र संख्याओं के गुणा और भाग के नियम समझाना इस कॉन्सेप्ट के दायरे से बाहर है (_और ऐसा शायद ही होगा कि आपको ये क्रियाएँ अक्सर "हाथ से" करनी पड़ें_)।

अगर आप इस विषय में गहराई से जाना चाहें, तो सम्मिश्र संख्याओं पर कोई भी [गणितीय][math-complex] या [इलेक्ट्रिकल इंजीनियरिंग][engineering-complex] परिचय इन स्थितियों को समझा देगा।

Python की मानक लाइब्रेरी में [`math`][math-module] मॉड्यूल है, जो वास्तविक संख्याओं पर काम करने के लिए बहुत सी उपयोगी सुविधाएँ देता है। सम्मिश्र संख्याओं के लिए वही काम [`cmath`][cmath] मॉड्यूल करता है।
