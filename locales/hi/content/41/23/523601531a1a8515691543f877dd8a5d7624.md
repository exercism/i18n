# इंस्टॉलेशन

आपको [NodeJS LTS](https://nodejs.org/en) चाहिए।

> 💡 यह ट्रैक संभवतः पुराने स्थिर वर्शनों के साथ भी काम करता है, साथ ही "current" वर्शन के साथ भी।
> हालाँकि, [डिज़ाइन के अनुसार](https://github.com/nodejs/release#release-schedule) विषम वर्शन कभी स्थिर नहीं होते।
> इसलिए हमेशा ध्यान रखिए कि आप NodeJS का सम वर्शन ही इंस्टॉल करें।

[Yarn 4+](https://yarnpkg.com/getting-started/install) को Node.JS `corepack` की मदद से इंस्टॉल कीजिए:

```shell
corepack enable yarn
```

## इंस्टॉलेशन की जाँच

जो बाइनरी आपने अभी इंस्टॉल की हैं, उन्हें इस्तेमाल करने के लिए आम तौर पर आपको एक नया टर्मिनल खोलना पड़ता है।

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_नोट: आपके वर्शन इनसे अलग हो सकते हैं।_

## अभ्यास का इंस्टॉलेशन

**हर अभ्यास** को टेस्ट चलाने के लिए कुछ टूल चाहिए:

इन्हें हर अभ्यास की डायरेक्टरी के अंदर यह कमांड चलाकर इंस्टॉल किया जा सकता है:

```bash
$ corepack yarn install
```

आपके एडिटर के अनुसार, Plug'n'Play इंस्टॉल के साथ काम करने के लिए हर अभ्यास में [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) इंस्टॉल करना पड़ता है।
इसे लिखे जाने के समय निम्नलिखित समर्थित हैं:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
