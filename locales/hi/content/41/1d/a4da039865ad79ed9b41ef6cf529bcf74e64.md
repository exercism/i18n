# इंस्टॉलेशन

सबसे पहले यह पक्का कर लीजिए कि आपके सिस्टम पर Erlang इंस्टॉल है। अपने सिस्टम के अनुसार [Erlang][1] के इंस्टॉलेशन पेज पर दिए गए निर्देशों का पालन कीजिए।
[1]: /languages/erlang

## Mac OS X के लिए Homebrew

अपने Homebrew को नवीनतम संस्करण में अपडेट कीजिए:

```bash
$ brew update
```

LFE इंस्टॉल कीजिए:

```bash
$ brew install lfe
```

## सोर्स से इंस्टॉल करना
अपने सिस्टम के "developer tools" या "essential build packages", `git` और Erlang का `erl` इंस्टॉल कीजिए।

उदाहरण के लिए, Ubuntu 18.04 पर:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

इसके बाद आप नीचे दिए गए तरीके से LFE डाउनलोड करके बिल्ड कर सकते हैं:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

LFE कंपाइल हो जाने के बाद आप ``lfe`` बाइनरी चलाकर REPL (इंटरैक्टिव सेशन) शुरू कर सकते हैं:

```bash
$ ./bin/lfe
```
