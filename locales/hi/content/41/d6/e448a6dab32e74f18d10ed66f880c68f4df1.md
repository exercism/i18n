# परिचय

Elixir की मानक लाइब्रेरी में तारीख़ों और समय के साथ काम करने के लिए 4 अलग-अलग मॉड्यूल हैं, और हर मॉड्यूल का अपना स्ट्रक्ट होता है।

- [`Date` मॉड्यूल][date]। `Date` स्ट्रक्ट को [`~D` सिगिल][sigil-d] की मदद से बनाया जा सकता है।
    ```elixir
    ~D[2021-01-01]
    ```

- [`Time` मॉड्यूल][time]। `Time` स्ट्रक्ट को [`~T` सिगिल][sigil-t] की मदद से बनाया जा सकता है।
    ```elixir
    ~T[12:00:00]
    ```

- [`NaiveDateTime` मॉड्यूल][naivedatetime] उन डेटटाइम के लिए है जिनमें टाइमज़ोन नहीं होता। `NaiveDateTime` स्ट्रक्ट को [`~N` सिगिल][sigil-n] की मदद से बनाया जा सकता है।
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- [`DateTime` मॉड्यूल][datetime] टाइमज़ोन वाले डेटटाइम के लिए है। UTC के अलावा किसी और टाइमज़ोन के लिए इस मॉड्यूल का उपयोग करने के लिए एक बाहरी डिपेंडेंसी चाहिए, यानी एक टाइमज़ोन डेटाबेस। एक `DateTime` स्ट्रक्ट को [`~U` सिगिल][sigil-u] से दर्शाया जा सकता है, लेकिन इसे बनाने के लिए `DateTime` के फंक्शन इस्तेमाल करने चाहिए।
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## तुलना

तारीख़ों या समय की आपस में तुलना करने के लिए संबंधित मॉड्यूल में `compare` या `diff` फंक्शन देखिए। `==`, `>` और `<` जैसे तुलना ऑपरेटर काम करते _दिखते_ हैं, लेकिन ये उन स्ट्रक्ट के लिए सही अर्थ में तुलना नहीं करते।

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## तारीख़ों और समय को आगे-पीछे करना

आप संबंधित मॉड्यूल के `add/2` फंक्शन की मदद से तारीख़ों, समय और डेटटाइम को समय में आगे या पीछे कर सकते हैं।

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## रूपांतरण

एक `NaiveDateTime` स्ट्रक्ट को [`NaiveDateTime.to_date/1`][naivedatetime-to-date] और [`NaiveDateTime.to_time/1`][naivedatetime-to-time] की मदद से एक `Date` स्ट्रक्ट और एक `Time` स्ट्रक्ट में तोड़ा जा सकता है। इसका उलटा [`NaiveDateTime.new!/2`][naivedatetime-new] से किया जा सकता है।

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
