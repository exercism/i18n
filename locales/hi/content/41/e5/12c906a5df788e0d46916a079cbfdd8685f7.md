# परिचय

Ruby के साथ एक स्टैंडर्ड लाइब्रेरी आती है (जिसे अक्सर छोटा करके "stdlib" कहा जाता है), जो क्लासों का एक संग्रह है, जिनकी मदद से तारीखों, JSON और नेटवर्किंग जैसी चीज़ों के साथ काम किया जाता है।
यह आपके कोड के साथ काम करना आसान बनाने के लिए कुछ उपयोगी सुविधाएँ भी देती है।

`OpenStruct` स्टैंडर्ड लाइब्रेरी का हिस्सा है और आपको `Hash` से आसानी से एक ऑब्जेक्ट बनाने देता है।
`Hash` की कीज़ से एक्सेस करने के बजाय, `OpenStruct` हमें वैल्यू एक्सेस करने और सेट करने के लिए मेथड इस्तेमाल करने देता है।

स्टैंडर्ड लाइब्रेरी या किसी अन्य लाइब्रेरी की क्लास इस्तेमाल करते समय, आपको `require` मेथड का उपयोग करके उस क्लास को शामिल करना होता है।

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

इसका एक अतिरिक्त फायदा यह है कि ब्लॉक सिंटैक्स इस्तेमाल करते समय आप एक शॉर्टकट का फायदा उठा सकते हैं।
ऐसी स्थितियों में जहाँ कोई ब्लॉक एक ही मेथड को कॉल करता है, आप ब्लॉक की जगह `&:` और उसके बाद मेथड का नाम लिख सकते हैं।
उदाहरण के लिए, ये दोनों लाइनें एक ही काम करती हैं:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
