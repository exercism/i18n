# स्ट्रक्ट

स्ट्रक्ट तय संख्या में अलग-अलग किस्म के डेटा को एक ही इकाई में समेट लेते हैं। Rust में स्ट्रक्ट के ये गुण होते हैं:

- हर स्ट्रक्ट टाइप का अपना एक नाम होता है।
- स्ट्रक्ट के हर सदस्य को **फील्ड** कहा जाता है।
- स्ट्रक्ट के हर फील्ड का अपना एक नाम होता है।
- विज़िबिलिटी फील्ड के स्तर पर देखी जाती है: हर फील्ड अलग-अलग पब्लिक, प्राइवेट या किसी और तरह की[^1] हो सकती है।

# स्ट्रक्ट का अवलोकन

स्ट्रक्ट `struct` कीवर्ड से बनाए जाते हैं, जिसके बाद उस टाइप का नाम लिखा जाता है जिसे वह स्ट्रक्ट बता रहा है। नाम के बाद घुंघराले ब्रैकेट (सामान्य स्ट्रक्ट के लिए), गोल ब्रैकेट (टपल स्ट्रक्ट के लिए) या सेमीकोलन (यूनिट स्ट्रक्ट के लिए) आ सकता है।

```rust
struct Item {}
```

इसके बाद स्ट्रक्ट के शरीर में और टाइप जोड़े जाते हैं, जो स्ट्रक्ट के _फील्ड_ होते हैं और हर एक का अपना टाइप होता है:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

अंत में, स्ट्रक्ट पर मेथड `impl` ब्लॉक के अंदर बनाए जा सकते हैं:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# स्ट्रक्ट के प्रकार

स्ट्रक्ट तीन तरह के होते हैं: नामित फील्ड वाले स्ट्रक्ट (सामान्य स्ट्रक्ट), टपल स्ट्रक्ट, और यूनिट स्ट्रक्ट।

स्ट्रक्ट **टपल** से बहुत मिलते-जुलते हैं। वास्तव में स्ट्रक्ट और टपल में फर्क सिर्फ इस बात का है कि किस चीज़ का नाम नहीं होता। इनका सामान्य रूप कुछ इस तरह होता है:

- स्ट्रक्ट का नाम होता है और फील्ड के भी नाम होते हैं:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  फील्ड तक नाम से पहुँचा जाता है:

  ```rust
  let bar = foo.bar;
  ```

- टपल स्ट्रक्ट का नाम होता है, पर फील्ड अनाम होते हैं:

  ```rust
  Foo(Bar, Bat)
  ```

  फील्ड तक पहुँचने के लिए टपल को खोलकर निकाला जाता है या संख्यात्मक इंडेक्स का उपयोग किया जाता है:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- टपल अनाम होते हैं और उनके फील्ड भी अनाम होते हैं:

  ```rust
  (Bar, Bat)
  ```

  टपल स्ट्रक्ट की तरह ही, फील्ड तक पहुँचने के लिए टपल को खोलकर निकाला जाता है या संख्यात्मक इंडेक्स का उपयोग किया जाता है।

- अनाम स्ट्रक्ट, जैसा नाम से ही पता चलता है, अनाम होते हैं, पर उनके फील्ड के नाम होते हैं। आप इनसे दूसरी भाषाओं में परिचित हो सकते हैं, जैसे Go या Java में। Rust में ये नहीं होते; यहाँ इनकी जगह टपल इस्तेमाल करना सही तरीका माना जाता है।

# ज़ीरो साइज़्ड टाइप

स्ट्रक्ट में जितने फील्ड चाहें उतने रखे जा सकते हैं, और कम भी। इसका मतलब है कि स्ट्रक्ट में शून्य फील्ड होना भी मान्य है। शून्य फील्ड वाले स्ट्रक्ट को **ज़ीरो-साइज़्ड टाइप** कहा जाता है, और कंपाइलर इसे कुछ खास तरीके से संभालता है: ज़ीरो-साइज़्ड टाइप (जिन्हें अक्सर **ZST** कहा जाता है) स्टैक या हीप में कोई जगह नहीं लेते, भले ही आपको उम्मीद हो कि वे लेंगे। जैसे, अगर `T` एक ZST है तो `Box<T>` कोई हीप मेमोरी नहीं लेता।

ZST लिखते समय आप सामान्य स्ट्रक्ट या टपल स्ट्रक्ट का सिंटैक्स इस्तेमाल कर सकते हैं:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

ZST के लिए एक छोटा रूप भी है:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

आम तौर पर ZST लिखते समय इसी छोटे रूप को प्राथमिकता दी जाती है, क्योंकि आप इन्हें मिला नहीं सकते: ZST को जिस शैली से घोषित किया गया हो[^2], उसे बनाने के लिए भी वही शैली चाहिए।

ZST के सिंटैक्स पर इतनी बात करने के बाद, चलिए देखते हैं कि आपको ऐसी चीज़ की ज़रूरत आखिर क्यों पड़ेगी। ZST कोई डेटा संग्रहीत नहीं कर सकता, पर ट्रेट लागू करने के लिए यह बहुत काम का है।

---

[^1]: [ये डॉक्स](https://doc.rust-lang.org/reference/visibility-and-privacy.html) विज़िबिलिटी के कुछ कम इस्तेमाल होने वाले विकल्पों के बारे में बताते हैं।
[^2]: यह एक सामान्य नियम का ही एक उदाहरण है: किसी भी स्ट्रक्ट टाइप को जिस शैली से घोषित किया गया हो, उसे बनाने के लिए भी वही शैली चाहिए।
