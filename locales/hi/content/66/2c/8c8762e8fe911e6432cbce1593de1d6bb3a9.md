# निर्देशों का परिशिष्ट

## एक्सेप्शन संदेश

कभी-कभी [एक्सेप्शन उत्पन्न करना](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) ज़रूरी होता है। ऐसा करते समय आपको हमेशा एक **अर्थपूर्ण एरर संदेश** शामिल करना चाहिए, जिससे पता चले कि एरर का स्रोत क्या है। इससे आपका कोड पढ़ने में आसान हो जाता है और डिबगिंग में काफी मदद मिलती है। ऐसी स्थितियों में, जहाँ आप जानते हैं कि एरर का स्रोत किसी एक खास टाइप का होगा, आप [बिल्ट-इन एरर टाइप](https://docs.python.org/3/library/exceptions.html#base-classes) में से कोई एक उत्पन्न करना चुन सकते हैं, लेकिन तब भी एक अर्थपूर्ण संदेश शामिल करना चाहिए।

इस अभ्यास में [raise स्टेटमेंट](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) का उपयोग करना ज़रूरी है। अगर `PhoneNumber()` क्लास के कंस्ट्रक्टर को ऐसी संख्या दी जाती है जो _मान्य फोन नंबर_ नहीं है, तो आपको कई `ValueError` "फेंकने" होंगे। इसमें वे एरर भी शामिल हैं जो तब मिलती हैं जब एरिया कोड या एक्सचेंज कोड अमान्य हों, जब संख्या में बहुत ज़्यादा (या बहुत कम) अंक हों, और जब इनपुट में विराम चिह्न या अक्षर दिए गए हों। टेस्ट तभी पास होंगे जब आप `exception` को `raise` भी करें और उसके साथ कोई संदेश भी शामिल करें।

किसी संदेश के साथ `ValueErrors` उत्पन्न करने के लिए, संदेश को `exception` टाइप के आर्गुमेंट के रूप में लिखिए:

```python
# if a phone number has less than 10 digits.
raise ValueError("must not be fewer than 10 digits")

# if a phone number has more than 11 digits.
raise ValueError("must not be greater than 11 digits")

# if a phone number has 11 digits, but starts with a number other than 1.
raise ValueError("11 digits must start with 1")

# if a phone number has an exchange code that starts with 0.
raise ValueError("exchange code cannot start with zero")

# if a phone number has an exchange code that starts with 1.
raise ValueError("exchange code cannot start with one")

# if a phone number has an area code that starts with 0.
raise ValueError("area code cannot start with zero")

# if a phone number has an area code that starts with 1.
raise ValueError("area code cannot start with one")

# if a phone number has punctuation in place of some digits.
raise ValueError("punctuations not permitted")

# if a phone number has letters in place of some digits.
raise ValueError("letters not permitted")
```
