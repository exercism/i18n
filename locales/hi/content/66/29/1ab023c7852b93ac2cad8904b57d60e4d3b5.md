# परिचय

`java.time` के मुख्य क्लास, जैसे `LocalDate` और `LocalDateTime`, समय की इकाइयाँ जोड़ने या घटाने के बुनियादी मेथड देते हैं। लेकिन तारीख में ज़्यादा जटिल बदलाव के लिए अक्सर ज़्यादा उन्नत तर्क चाहिए (जैसे महीने का "दूसरा मंगलवार" या साल का अंतिम दिन ढूँढना)।

`java.time.temporal` पैकेज इस काम के लिए [`TemporalAdjuster`][temporaladjuster-docs] फंक्शनल इंटरफेस देता है।
यह किसी टेम्पोरल ऑब्जेक्ट (जैसे `LocalDate`) को बदलने की एक रणनीति दर्शाता है।
[`TemporalAdjusters`][temporaladjusters-docs] (ध्यान दीजिए, अंत में बहुवचन 's' है) यूटिलिटी क्लास में ऐसे कई स्टैटिक फैक्ट्री मेथड होते हैं जो सामान्य, पहले से तय एडजस्टर कार्यान्वयन देते हैं।

## TemporalAdjusters का उपयोग

`LocalDate` और `LocalDateTime` जैसे टेम्पोरल ऑब्जेक्ट में एक `with()` मेथड होता है जो `TemporalAdjuster` लेता है।
यह मेथड बदलाव लागू करके एक *नया* टेम्पोरल ऑब्जेक्ट लौटाता है।

```exercism/note
`with(TemporalAdjuster)` एक _नया_ इंस्टेंस लौटाता है और मौजूदा इंस्टेंस को बदलता नहीं है, क्योंकि सभी `java.time` टेम्पोरल क्लास अपरिवर्तनीय होते हैं।
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## सामान्य पहले से तय एडजस्टर

`TemporalAdjusters` क्लास कई उपयोगी स्टैटिक मेथड देती है। यहाँ कुछ सामान्य उदाहरण हैं:

### सप्ताह के किसी दिन की क्रम संख्या ढूँढना

`dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` एडजस्टर महीने में सप्ताह के किसी खास दिन की nवीं बार पड़ने वाली तारीख ढूँढता है।

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### महीने में सप्ताह के पहले/अंतिम दिन ढूँढना

`firstInMonth(DayOfWeek dayOfWeek)` और `lastInMonth(DayOfWeek dayOfWeek)` एडजस्टर महीने में सप्ताह के किसी दिन की पहली या अंतिम बार पड़ने वाली तारीख ढूँढते हैं।

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### महीने/साल का पहला/अंतिम दिन ढूँढना

सरल एडजस्टर मौजूदा महीने या साल का पहला या अंतिम दिन ढूँढते हैं।

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### सापेक्ष एडजस्टमेंट (अगला/पिछला)

`next()`, `previous()`, `nextOrSame()` और `previousOrSame()` जैसे एडजस्टर मौजूदा तारीख के सापेक्ष सप्ताह के किसी दिए गए दिन की अगली या पिछली बार पड़ने वाली तारीख ढूँढते हैं।

- `next()`/`previous()`: अगर मौजूदा तारीख मेल खाती है तो उसे छोड़ देते हैं।
- `nextOrSame()`/`previousOrSame()`: अगर मौजूदा तारीख मेल खाती है तो उसे शामिल करते हैं।

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## कस्टम एडजस्टर

चूँकि `TemporalAdjuster` एक [`@FunctionalInterface`][functionalinterface-docs] है, आप अपने खुद के कस्टम एडजस्टर लैम्ब्डा एक्सप्रेशन से बना सकते हैं, उस तर्क के लिए जो पहले से तय मेथड नहीं संभालते।
इंटरफेस में एक ही मेथड लागू करना होता है: `Temporal adjustInto(Temporal temporal)`।

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

कस्टम एडजस्टर शक्तिशाली होते हैं, लेकिन `TemporalAdjusters` क्लास के पहले से तय एडजस्टर सामान्य उपयोग के कई मामलों को संभाल लेते हैं।
