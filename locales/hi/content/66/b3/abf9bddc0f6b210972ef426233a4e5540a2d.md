# निर्देश

बनती हुई जादूगरनी एलिस को कुछ बुनियादी बातों का अभ्यास करना है। उसके पास ताश के पत्तों का एक डेक है, जिसे वह अपने हिसाब से बदलना चाहती है।

चीज़ें थोड़ी आसान रखने के लिए वह सिर्फ 1 से 10 तक के पत्ते इस्तेमाल करती है।

## 1. डेक से एक पत्ता निकालिए

`getCard` फंक्शन बनाइए जो दिए गए डेक में `index` स्थान पर रखा पत्ता लौटाता है। अगर वह इंडेक्स डेक में मौजूद न हो, तो Nothing लौटाइए।

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. डेक में एक पत्ता बदलिए

`setCard` फंक्शन बनाइए जो एक ऐसा डेक लौटाता है जिसमें `index` स्थान वाला पत्ता बदलकर दिया गया नया पत्ता कर दिया गया हो। अगर `index` डेक में न हो, तो मूल डेक ही लौटाइए।

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. डेक में एक पत्ता जोड़िए

`addCard` फंक्शन बनाइए जो नया पत्ता जोड़कर डेक लौटाता है।

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. डेक से एक पत्ता हटाइए

`removeCard` फंक्शन बनाइए जो एक ऐसा डेक लौटाता है जिसमें से `index` स्थान वाला पत्ता हटा दिया गया हो। अगर दिया गया `index` डेक का कोई मान्य इंडेक्स न हो, तो मूल डेक ही लौटाइए।

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. डेक में सम पत्तों की गिनती कीजिए

`evenCardCount` फंक्शन बनाइए जो डेक में सम संख्या वाले पत्तों की गिनती करता है।

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
