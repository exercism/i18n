# परिचय

## मूल बातें

इन विषयों की अधिक विस्तृत जानकारी के लिए [कॉन्सेप्ट पेज][exercism-concept] देखिए।

### सामान्य सिंटैक्स

PHP का ओपनिंग टैग `<?php` बताता है कि PHP कोड कहाँ से शुरू होता है।
निर्देशों को अलग करने के लिए हर स्टेटमेंट के अंत में `;` ज़रूरी है।

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

पढ़ने में आसानी के लिए सभी कोड उदाहरणों में PHP का ओपनिंग टैग `<?php` छोड़ दिया गया है।

### कमेंट

सिंगल लाइन कमेंट `//` से शुरू होते हैं।

```php
// Single line comment
```

### वैल्यू और वेरिएबल

असाइनमेंट ऑपरेटर `=` की मदद से किसी वेरिएबल को एक वैल्यू असाइन की जा सकती है।
वेरिएबल के नाम डॉलर चिह्न `$` से शुरू होने चाहिए और [नाम रखने के नियम][exercism-concept-naming-conventions] का पालन करना चाहिए।

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### फंक्शन और मेथड

फंक्शन को वैल्यू और वेरिएबल पास किए जा सकते हैं।
फंक्शन के आर्गुमेंट नए वेरिएबल बन जाते हैं, जिनमें पास की गई वैल्यू रखी जाती है।
फंक्शन `return` कीवर्ड की मदद से कोई भी वैल्यू लौटा सकते हैं।

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

क्लास के अंदर वाले फंक्शन और उनके इंस्टेंस मेथड कहलाते हैं।
किसी मेथड को कॉल करने के लिए उसके नाम से पहले इंस्टेंस और `->` लिखा जाता है।
मेथड के पास एक विशेष वेरिएबल `$this` होता है, जो वर्तमान इंस्टेंस को दर्शाता है।

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
