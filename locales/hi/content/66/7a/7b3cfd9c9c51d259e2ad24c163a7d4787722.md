# निर्देश

जादूगर बनने की तैयारी में जुटी एलिस को कुछ बुनियादी बातों का अभ्यास करना है। उसके पास ताश के पत्तों का एक स्टैक है और वह उसके साथ तरह-तरह के करतब करना चाहती है।

चीज़ों को थोड़ा आसान बनाने के लिए वह सिर्फ 1 से 10 तक के पत्ते इस्तेमाल करती है। इसलिए उसके पत्तों के स्टैक को संख्याओं के वेक्टर से दिखाया जा सकता है। किसी पत्ते की स्थिति वेक्टर में उसके इंडेक्स से मेल खाती है।

## 1. स्टैक से एक पत्ता निकालिए

कोई पत्ता उठाने के लिए दिए गए स्टैक से इंडेक्स `position` पर रखा पत्ता लौटाइए।

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. स्टैक में एक पत्ता बदलिए

थोड़ा जादू दिखाइए और इंडेक्स `position` पर रखे पत्ते को बदले में दिए गए पत्ते से बदल दीजिए।
बदले हुए स्टैक को लौटाइए।

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. स्टैक के ऊपर एक पत्ता डालिए

स्टैक के ऊपर एक नया पत्ता डालकर एक पत्ता सामने लाइए।
बदले हुए स्टैक को लौटाइए।

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. स्टैक से एक पत्ता हटाइए

स्टैक से दिए गए `position` पर रखा पत्ता हटाकर एक पत्ता गायब कीजिए।
बदले हुए स्टैक को लौटाइए।

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. स्टैक का आकार जाँचिए

जाँचिए कि स्टैक का आकार `stack_size` के बराबर है या नहीं।

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. स्टैक से सबसे ऊपर का पत्ता हटाइए

स्टैक के सबसे ऊपर का पत्ता हटाकर एक पत्ता गायब कीजिए।
बदले हुए स्टैक को लौटाइए।

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. स्टैक के नीचे एक पत्ता डालिए

स्टैक के नीचे एक नया पत्ता डालकर एक पत्ता सामने लाइए।
बदले हुए स्टैक को लौटाइए।

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. स्टैक से नीचे का पत्ता हटाइए

स्टैक के सबसे नीचे का पत्ता हटाकर एक पत्ता गायब कीजिए।
बदले हुए स्टैक को लौटाइए।

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
