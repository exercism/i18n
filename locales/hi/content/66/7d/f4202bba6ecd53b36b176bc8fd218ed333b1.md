# निर्देश

आप नेटबॉल के एक मैच में स्कोरबोर्ड चला रहे हैं। अब तक की हर चीज़ से अलग, स्कोरबोर्ड को यह याद रखना पड़ता है कि क्या-क्या हो चुका है।

`SCOREBOARD` क्लास को नीचे दी गई चीज़ें चाहिए। स्टब आपको क्लास और उसके दो एट्रिब्यूट की घोषणाएँ देता है; बाकी आप खुद जोड़िए।

## 1. बोर्ड तैयार कीजिए

`create` होम टीम का नाम और अवे टीम का नाम लेता है, और ऐसा स्कोरबोर्ड लौटाता है जिसमें दोनों स्कोर शून्य होते हैं।

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. गोल दर्ज कीजिए

`home_goal` होम स्कोर में एक जोड़ता है, और `away_goal` अवे स्कोर में एक जोड़ता है। इनमें से कोई भी कुछ नहीं लौटाता।

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. बोर्ड पढ़िए

`summary` बोर्ड को वैसे ही लौटाता है जैसे वह लिखा जाता है: होम टीम, उसका स्कोर, एक डैश, अवे स्कोर, और फिर अवे टीम।

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

स्पेस ठीक वैसे ही हैं जैसे दिखाए गए हैं, और डैश एक ही `-` है।

## 4. कौन जीत रहा है?

`leader` आगे वाली टीम का नाम लौटाता है, या स्कोर बराबर होने पर `"Draw"` लौटाता है।

```sather
board.leader
-- => "Vixens"
```

## 5. कितना आगे?

`margin` लौटाता है कि दोनों टीमों के बीच कितने गोलों का अंतर है। चाहे कोई भी आगे हो, यह कभी नकारात्मक नहीं होता।

```sather
board.margin
-- => 1
```
