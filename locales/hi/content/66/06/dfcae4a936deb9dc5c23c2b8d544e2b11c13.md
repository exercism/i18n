# टपल

एक [टपल][tuple] एलिमेंट की एक सीमित और क्रमबद्ध सूची होता है, जो अपरिवर्तनीय होता है।
टपल में हर स्थान का टाइप तय होना ज़रूरी है।
इसका मतलब है कि कंपाइलर को पता रहता है कि हर स्थान पर कौन-सा टाइप है।
टपल में इस्तेमाल होने वाले टाइप हर स्थान पर अलग-अलग हो सकते हैं, लेकिन उन टाइप का कंपाइल के समय पता होना ज़रूरी है।

## टपल बनाना

टपल की वैल्यू के टाइप कंपाइल के समय पता लगाए जा सकते हैं या नहीं, इसके आधार पर टपल को अलग-अलग तरीकों से बनाया जा सकता है।
अगर वैल्यू कंपाइल के समय पता हों, तो टपल को टपल लिटरल सिंटैक्स से बनाया जा सकता है; वरना उन्हें स्पष्ट रूप से घोषित करना पड़ता है।
यह भी ज़रूरी है कि वैल्यू के टाइप टपल में दिए गए टाइप से मेल खाएँ और वैल्यू की संख्या दिए गए टाइप की संख्या से मेल खाए।
टपल लिटरल सिंटैक्स से परिभाषित करने का एक उदाहरण यहाँ है:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

`Tuple` क्लास की मदद से भी टपल बनाया जा सकता है।

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

इसके अलावा, आप टपल को असाइन किए गए वेरिएबल का टाइप स्पष्ट रूप से बता सकते हैं।

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

टपल का टाइप स्पष्ट रूप से बताना काम आता है, क्योंकि इससे यह तय किया जा सकता है कि किसी स्थान पर यूनियन टाइप हो।
इसका मतलब है कि एक स्थान पर एक से अधिक टाइप रखे जा सकते हैं।

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## रूपांतरण

### ऐरे से टपल बनाना

`Tuple` क्लास के `from` मेथड से आप एक ऐरे से टपल बना सकते हैं।
इसके लिए टपल का टाइप बताना ज़रूरी है।

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### ऐरे में बदलना

`to_a` मेथड से आप टपल को ऐरे में बदल सकते हैं।
इससे बने ऐरे के एलिमेंट का टाइप टपल के हर फील्ड के टाइप का यूनियन होता है।

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### टपल टाइप लिखने का छोटा तरीका

स्पष्ट रूप से टपल टाइप लिखने का एक छोटा तरीका भी है।
वह यह है कि टाइप को टपल लिटरल के अंदर लिख दिया जाए।

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## एलिमेंट ऐक्सेस करना

ऐरे की तरह टपल भी ज़ीरो-इंडेक्स होते हैं, यानी पहला एलिमेंट इंडेक्स 0 पर होता है।
लेकिन ऐरे के उलट, हर एलिमेंट का टाइप तय होता है और कंपाइल के समय पता रहता है। इसलिए टपल को इंडेक्स करते समय एलिमेंट का टाइप उसके स्थान के हिसाब से होता है।
टपल में किसी एलिमेंट तक पहुँचने के लिए आप `[]` ऑपरेटर इस्तेमाल कर सकते हैं।

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

ऐरे से एलिमेंट ऐक्सेस करने और टपल से एलिमेंट ऐक्सेस करने में एक और फर्क है: अगर इंडेक्स सीधे दिया गया हो, तो कंपाइलर जाँच लेता है कि इंडेक्स टपल की सीमा के अंदर है या नहीं।
इसका मतलब है कि रनटाइम एरर की जगह आपको कंपाइल के समय ही एरर मिल जाती है।

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

लेकिन अगर इंडेक्स किसी वेरिएबल में रखा गया हो, तो कंपाइलर कंपाइल के समय यह नहीं जाँच पाएगा कि इंडेक्स टपल की सीमा के अंदर है या नहीं, और इसके बजाय रनटाइम एरर देगा।

## सबटपल

आप `[]` ऑपरेटर के साथ रेंज देकर टपल का सबटपल निकाल सकते हैं।
इससे जो मिलता है वह एक नया टपल होता है, जिसमें दी गई रेंज के एलिमेंट होते हैं।
रेंज कंपाइल के समय ही देनी होती है; वरना कंपाइलर सबटपल के एलिमेंट के टाइप नहीं जान पाएगा।
इसका मतलब है कि रेंज को रेंज लिटरल होना चाहिए, उसे किसी वेरिएबल में असाइन नहीं किया जा सकता।

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## टपल का इस्तेमाल कब करें

टपल तब काम आता है जब आपको तय संख्या की वैल्यू एक साथ रखनी हों और उन वैल्यू के टाइप कंपाइल के समय पता हों।
ऐसा इसलिए है क्योंकि टपल को कम मेमोरी चाहिए और अपरिवर्तनीय होने के कारण टपल ऐरे से तेज़ होते हैं।
एक और उपयोग यह है कि मेथड से एक साथ कई वैल्यू लौटाई जा सकें।
यह खास तौर पर तब काम आता है जब वैल्यू के टाइप अलग-अलग हों, क्योंकि टपल में हर स्थान का टाइप अलग हो सकता है।

जब ऐसी डेटा स्ट्रक्चर की ज़रूरत हो जिसका आकार बढ़ या घट सके, या जिसे बार-बार बदलना पड़े, तो टपल का इस्तेमाल नहीं करना चाहिए।
