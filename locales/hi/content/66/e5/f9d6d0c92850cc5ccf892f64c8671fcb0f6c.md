# परिचय

हर बार किसी फंक्शन को कॉल करने पर मेमोरी में एक नया स्टैक फ्रेम बनाया जाता है। इसमें उस फंक्शन के आर्गुमेंट और लोकल वेरिएबल रखे जाते हैं। फंक्शन के लौटने पर यह स्टैक फ्रेम मुक्त कर दिया जाता है। क्योंकि Gleam लूपिंग सिंटैक्स के बजाय रिकर्सिव फंक्शन कॉल का उपयोग करता है, इससे इन स्टैक फ्रेम के कारण बहुत अधिक मेमोरी का उपयोग हो सकता है।

इस समस्या से बचने के लिए Gleam टेल कॉल ऑप्टिमाइज़ेशन का समर्थन करता है। यह कंपाइलर को वर्तमान फंक्शन का स्टैक फ्रेम दोबारा इस्तेमाल करने देता है, अगर फंक्शन का आखिरी काम किसी फंक्शन को कॉल करना हो। इसका मतलब है कि कोई फंक्शन खुद को अनंत बार कॉल कर सकता है, बिना कोई अतिरिक्त मेमोरी इस्तेमाल किए।

बिना ऑप्टिमाइज़ किए गए रिकर्सिव फंक्शन अक्सर एक _एक्युमुलेटर_ का उपयोग करके टेल कॉल ऑप्टिमाइज़्ड फंक्शन में दोबारा लिखे जा सकते हैं।

एक्युमुलेटर एक वेरिएबल है जिसे डेटा के साथ-साथ आगे भेजा जाता है। इसका उपयोग फंक्शन के चलने की वर्तमान स्थिति को तब तक आगे भेजने के लिए किया जाता है, जब तक बेस केस तक न पहुँच जाए।

एक्युमुलेटर को शुरुआती वैल्यू फंक्शन बनाने वाला ही दे, उसे इस्तेमाल करने वाला नहीं। इसके लिए दो फंक्शन घोषित कीजिए: एक पब्लिक फंक्शन जो आर्गुमेंट के रूप में सिर्फ ज़रूरी डेटा लेता है और एक्युमुलेटर को शुरुआती वैल्यू देता है, और एक प्राइवेट फंक्शन जो एक्युमुलेटर भी लेता है।

```gleam
// Count the length of a list without tail call optimisation
pub fn count(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> {
      let amount = count(rest) // Non-tail recursive call
      amount + 1
    }
  }
}
```

```gleam
// Count the length of a list with tail call optimisation
pub fn count(list: List(String)) -> Int {
  count_elements(list, 0)
}

fn count_elements(list: List(String), accumulator: Int) -> Int {
  case list {
    [] -> accumulator
    [_, ..rest] -> {
      let accumulator = accumulator + 1
      count_elements(rest, accumulator) // Tail recursive call
    }
  }
}
```
