# टेस्ट

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
$ gradlew test
```

> अगर आप Windows पर हैं तो `gradlew.bat` इस्तेमाल कीजिए।

## छोड़े गए टेस्ट

टेस्ट सूट में पहले टेस्ट को छोड़कर बाकी सभी टेस्ट छोड़ दिए गए हैं।

जब एक टेस्ट पास हो जाए, तो आप `@Ignore` एनोटेशन हटाकर अगला टेस्ट चालू कर सकते हैं।
