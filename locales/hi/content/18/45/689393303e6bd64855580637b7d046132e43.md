# लोकल में डीबग करना

जब आप [Bats](https://github.com/bats-core/bats-core) के साथ Bash ट्रैक के टेस्ट चलाते हैं, तो Bats आउटपुट एसर्शनों के लिए STDOUT और STDERR दोनों कैप्चर करता है।

```exercism/caution
यह `bats` के साथ लोकल में काम करता है, लेकिन Exercism ऑनलाइन एडिटर में **नहीं**।
```

अगर आप टेस्ट के परिणाम को प्रभावित किए बिना डीबग आउटपुट प्रिंट करना चाहते हैं, तो उसे फाइल डिस्क्रिप्टर (fd) 3 पर लिखिए।

```bash
echo 'debug message' >&3
```

Bats टेस्ट चलने के दौरान fd 3 पर लिखा गया आउटपुट दिखाता है, लेकिन `assert_output` जैसे एसर्शनों में उस आउटपुट को शामिल नहीं करता।

उदाहरण:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

यह तब उपयोगी होता है जब आप टेस्ट लोकल में चला रहे हों।
