# विवरण

[वेरिएडिक पैरामीटर][variadic-parameters] की मदद से किसी फंक्शन का एक ही पैरामीटर किसी तय टाइप की शून्य या उससे अधिक वैल्यू ले सकता है। वेरिएडिक पैरामीटर बनाने के लिए आप पैरामीटर के टाइप एनोटेशन के आगे तीन बिंदु (`...`) जोड़ते हैं।

फंक्शन के अंदर Swift इन वैल्यू को तय टाइप के एक ऐरे के रूप में उपलब्ध करा देता है:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
अगर किसी फंक्शन में वेरिएडिक पैरामीटर के बाद कुछ और पैरामीटर भी हों, तो वेरिएडिक पैरामीटर के बाद आने वाले पहले पैरामीटर के लिए स्पष्ट आर्गुमेंट लेबल **होना ज़रूरी है**, ताकि Swift समझ सके कि वेरिएडिक आर्गुमेंट की सूची कहाँ खत्म होती है।
~~~~
