# परिचय

## फंक्शन

Gleam में फंक्शन `pub fn` सिंटैक्स से बनाए जाते हैं।

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

यह फंक्शन दो आर्गुमेंट लेता है, जो दोनों `Int` टाइप के हैं, और `Int` टाइप की एक वैल्यू लौटाता है। Gleam में `return` कीवर्ड नहीं होता। किसी फंक्शन में अंतिम एक्सप्रेशन की वैल्यू हमेशा _अपने आप लौटाई जाती है_।

आर्गुमेंट के टाइप एनोटेशन और रिटर्न टाइप देना ज़रूरी नहीं है। Gleam आपके कोड की पूरी टाइप जाँच हमेशा करता है। आम तौर पर Gleam प्रोग्रामर अपने फंक्शनो पर स्पष्टता के लिए टाइप एनोटेशन लगाते हैं, लेकिन आप चाहें तो उन्हें छोड़ सकते हैं।

```gleam
pub fn add(x, y) {
  x + y
}
```

किसी फंक्शन को `function_name(argument1, argument2)` सिंटैक्स से कॉल किया जा सकता है।

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## वेरिएबल

Gleam में वेरिएबलो को `let name = expression` सिंटैक्स से बनाया जाता है।

```gleam
pub fn main() {
  let count = 1
}
```

वेरिएबलो को टाइप एनोटेशन के साथ भी घोषित किया जा सकता है। फंक्शन के आर्गुमेंट की तरह ये भी ज़रूरी नहीं हैं। फिर भी ज़्यादातर Gleam प्रोग्रामर संक्षिप्तता के लिए वेरिएबलो के टाइप एनोटेशन छोड़ देते हैं।

```gleam
pub fn main() {
  let count: Int = 1
}
```

## स्ट्रिंग लिटरल

Gleam में स्ट्रिंग डबल कोट्स के बीच लिखी जाती हैं।

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## कोड कमेंट

कमेंट की मदद से सोर्स कोड पढ़ने वाले दूसरे डेवलपरो के लिए नोट छोड़े जा सकते हैं। Gleam में कमेंट एक-एक लाइन के होते हैं और उनसे पहले `//` लगता है।

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
