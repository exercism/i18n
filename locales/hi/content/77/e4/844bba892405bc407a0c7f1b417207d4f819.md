# परिचय

Gleam में कॉन्स्टेंट वैल्यूओं को नाम देने का एक तरीका हैं। इन्हें `const` कीवर्ड से परिभाषित किया जाता है।

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

जब किसी मॉड्यूल कॉन्स्टेंट को `pub` कीवर्ड के साथ परिभाषित किया जाता है, तो उसका इस्तेमाल दूसरे मॉड्यूल में भी किया जा सकता है। वरना उसका इस्तेमाल सिर्फ उसी मॉड्यूल के अंदर किया जा सकता है जिसमें वह परिभाषित किया गया है।
