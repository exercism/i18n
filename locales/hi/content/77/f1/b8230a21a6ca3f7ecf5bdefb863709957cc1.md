# परिचय

JavaScript का ऑब्जेक्ट डिस्ट्रक्चरिंग सिंटैक्स, किसी ऑब्जेक्ट से प्रॉपर्टी निकालकर उन्हें अलग-अलग वेरिएबल में असाइन करने का एक संक्षिप्त तरीका है।

इस उदाहरण में, `weather` ऑब्जेक्ट से मौसम के प्रतीक निकाले गए हैं:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

cloud_with_lightning;
// => '🌩️'
```
