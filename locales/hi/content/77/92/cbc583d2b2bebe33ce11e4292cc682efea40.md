# निर्देश

आप एक ऑनलाइन फैशन बुटीक चलाते हैं। आपकी सालाना बड़ी सेल आने वाली है, इसलिए आप कुछ ऐसी सुविधाएँ बनाना चाहते हैं जिनसे अपनी इन्वेंटरी का हिसाब रखकर यह पक्का कर सकें कि आप तैयार हैं।

इन्वेंटरी का एक आइटम एक हैश से दर्शाया जाता है, और पूरी इन्वेंटरी इन हैशों का एक ऐरे होती है।

```ruby
[
  {
    name: "White Shirt",
    price: 40,
    quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}
  },
  { ... }
]
```

## 1. आइटम के नामों का ऐरे लौटाइए

`BoutiqueInventory.item_names` लागू कीजिए। इसे आइटम के नामों का ऐरे वर्णमाला के क्रम में लौटाना चाहिए।

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

#=> ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 2. सभी सस्ते आइटम लौटाइए

`BoutiqueInventory.cheap` लागू कीजिए। इसे वे सभी आइटम लौटाने चाहिए जिनकी कीमत $30 से कम है।

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).cheap

# => [
#      {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
#      {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
#    ]
```

## 3. स्टॉक से बाहर वाले सभी आइटम लौटाइए

`BoutiqueInventory.out_of_stock` लागू कीजिए। इसे वे सभी आइटम लौटाने चाहिए जिनका कोई स्टॉक नहीं है (यानी जिनमें `quantity_by_size` खाली है)।

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).out_of_stock

#=> [{price: 50.00, name: "Red Short Skirt", quantity_by_size: {}}]
```

## 4. किसी एक आइटम का स्टॉक लौटाइए

किसी आइटम का नाम देखकर उसका स्टॉक लौटाने के लिए `BoutiqueInventory.stock_for_item(name)` लागू कीजिए:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).stock_for_item("Black Short Skirt")

#=> {s: 1, xl: 4}
```

## 5. कुल स्टॉक लौटाइए

अपने गोदाम में मौजूद आइटम की कुल संख्या निकालने के लिए `BoutiqueInventory.total_stock` लागू कीजिए:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

#=> 36
```
