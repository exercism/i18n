# परिचय

[ReScript][rescript-lang] लिखिए, JavaScript डिप्लॉय कीजिए।
ReScript, OCaml के मज़बूत टाइप सिस्टम पर बना है और BuckleScript तथा ReasonML का आधुनिक उत्तराधिकारी है। JavaScript इकोसिस्टम के भीतर यह संपूर्ण पैटर्न मैचिंग और कंपाइल-टाइम गारंटी देता है।
React के साथ इसका फर्स्ट-क्लास इंटीग्रेशन इसे उन डेवलपर्स के लिए TypeScript का आकर्षक विकल्प बनाता है, जो एनोटेट JavaScript के बजाय असली टाइप सुरक्षा चाहते हैं।
न कोई `any`, न कोई चौंकाने वाला `undefined`.

[rescript-lang]: https://rescript-lang.org
