# परिचय

## एनम

_एनम टाइप_ एक खास डेटा टाइप है जो किसी वेरिएबल को पहले से तय कॉन्स्टेंट के समूह में से कोई एक मान लेने देता है।
वेरिएबल की वैल्यू उसके लिए पहले से तय वैल्यू में से किसी एक के बराबर होनी चाहिए।
आम उदाहरणों में दिशाएँ (जैसे `NORTH`, `SOUTH`, `EAST` और `WEST` वैल्यू) और सप्ताह के दिन शामिल हैं।

चूँकि ये कॉन्स्टेंट हैं, इसलिए एनम टाइप के फील्ड के नाम बड़े अक्षरों में लिखे जाते हैं।

### एनम टाइप बनाना

Java प्रोग्रामिंग भाषा में आप `enum` कीवर्ड इस्तेमाल करके एक एनम टाइप बनाते हैं।
उदाहरण के लिए, सप्ताह के दिनों वाला एनम टाइप आप ऐसे लिखेंगे:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

जब भी आपको कॉन्स्टेंट के एक तय समूह को दर्शाना हो, आपको एनम टाइप का उपयोग करना चाहिए।
इसमें हमारे सौरमंडल के ग्रहों जैसे प्राकृतिक एनम टाइप भी शामिल हैं, और वे डेटा सेट भी जिनकी सारी संभावित वैल्यू कंपाइल टाइम पर ही पता होती हैं। जैसे किसी मेन्यू के विकल्प, कमांड लाइन फ्लैग, वगैरह।

### एनम टाइप का उपयोग करना

यहाँ कुछ कोड दिया गया है जो बताता है कि ऊपर बनाए गए `DayOfWeek` एनम का उपयोग कैसे करें:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### मेथड और फील्ड जोड़ना

Java प्रोग्रामिंग भाषा के एनम टाइप दूसरी भाषाओं के अपने समकक्षों से कहीं ज़्यादा शक्तिशाली होते हैं।
`enum` डिक्लेरेशन एक _क्लास_ बनाता है (जिसे _एनम टाइप_ कहा जाता है)।
एनम क्लास की बॉडी में मेथड और दूसरे फील्ड भी शामिल हो सकते हैं:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating` एनम टाइप के किसी मेंबर पर `getNumberOfStars` मेथड कॉल करना:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
