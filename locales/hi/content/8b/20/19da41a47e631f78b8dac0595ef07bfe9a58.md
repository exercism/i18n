# SQLite के लिए खास निर्देश

**result** कॉलम में JSON में एनकोड किया गया ऑब्जेक्टों का ऑब्जेक्ट होना चाहिए, जिसमें हर शब्द एक की और गिनती एक पूर्णांक हो।

उदाहरण के लिए, ऊपर दिया गया वाक्य लीजिए: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
इस इनपुट के लिए **result** यह होना चाहिए:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## टेबल स्कीमा

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
