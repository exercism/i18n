# परिचय

ABAP ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग मॉडल का समर्थन करता है। यह मॉडल ABAP Objects की क्लास और इंटरफेस पर आधारित है।

## (फिर से) वैल्यू असाइन करना

ABAP में नामों को वैल्यू असाइन करने के कुछ मुख्य तरीके हैं, जिनमें वेरिएबल या स्थिरांक का इस्तेमाल होता है। Exercism पर वेरिएबल हमेशा [स्नेक-केस][wiki-snake-case] में लिखे जाते हैं। इसके लिए कोई आधिकारिक गाइड नहीं है, और अलग-अलग कंपनियों और संस्थाओं के अपने-अपने स्टाइल गाइड होते हैं। _आप वेरिएबल अपनी पसंद के किसी भी तरीके से लिख सकते हैं_। अभ्यास जिस तरह तैयार किए गए हैं, उसी तरह वेरिएबल लिखने का फायदा यह है कि वेब इंटरफेस और ज़्यादातर आईडीई में वे अलग तरह से दिखाई देते हैं।

ABAP में वेरिएबल को [`constant`][constant] या [`data`][data] कीवर्ड से घोषित किया जा सकता है।

`data` का इस्तेमाल करके बनाया गया वेरिएबल अपने जीवनकाल में अलग-अलग वैल्यू रख सकता है। उदाहरण के लिए, [असाइनमेंट ऑपरेटर `=`][assignment] से `my_first_variable` को कई बार नई वैल्यू असाइन की जा सकती है:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

`data` के उलट, `constant` से घोषित वेरिएबल को केवल एक बार ही वैल्यू असाइन की जा सकती है। ABAP में स्थिरांक बनाने के लिए इसका ही इस्तेमाल होता है।

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## क्लास और मेथड की घोषणाएँ

ABAP में कार्यक्षमता की इकाइयाँ _मेथड_ में समाहित होती हैं। जो मेथड आपस में जुड़े होते हैं, उन्हें आमतौर पर एक ही [क्लास][classes] में इकट्ठा किया जाता है। ये मेथड पैरामीटर (आर्गुमेंट) ले सकते हैं, और मेथड बनाते समय `returning` कीवर्ड का इस्तेमाल करके एक वैल्यू _लौटा_ सकते हैं। मेथड को `( )` सिंटैक्स से कॉल किया जाता है।

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 ABAP में क्लास और मेथड घोषित करने के _कई_ अलग-अलग तरीके हैं। यह ट्रैक उन्हें धीरे-धीरे शुरू करवाने की कोशिश करता है, लेकिन अगर आप इनके बारे में पहले से जानते हैं, तो आप इनमें से कोई भी इस्तेमाल कर सकते हैं। ज़्यादातर मामलों में किसी एक तरीके का इस्तेमाल करना दूसरे से बेहतर या खराब नहीं होता।
