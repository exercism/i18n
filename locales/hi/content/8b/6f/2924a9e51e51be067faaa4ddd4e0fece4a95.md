# परिचय

## रिकर्शन

रिकर्सिव फंक्शन वे फंक्शन होते हैं जो खुद को कॉल करते हैं।

एक रिकर्सिव फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना चाहिए।

_बेस केस_ बिना फंक्शन को दोबारा कॉल किए एक वैल्यू लौटाता है।
_रिकर्सिव केस_ फंक्शन को दोबारा कॉल करता है और इनपुट को ऐसे बदलता है कि वह किसी बिंदु पर बेस केस से मेल खाने लगे।

Elm में रिकर्सिव फंक्शन आम तौर पर `case` एक्सप्रेशन के साथ पैटर्न मैचिंग या कई फंक्शन क्लॉज़ इस्तेमाल करके बनाए जाते हैं।

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### रिकर्शन के ज़रिए लूप

इम्यूटेबिलिटी की वजह से Elm में लूप इम्परेटिव भाषाओं से अलग तरीके से लिखे जाते हैं।
उदाहरण के लिए, लूप आम तौर पर ऐसे दिखते हैं:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Elm जैसी फंक्शनल भाषा में वेरिएबल की वैल्यू बदलना संभव नहीं होता।
इसलिए लूप रिकर्शन की मदद से ही बनाने पड़ते हैं।

Elm में `for` लूप के बराबर कोड ऐसा दिखेगा:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

व्यवहार में Elm में ऐरे और दूसरे डेटा स्ट्रक्चर पर इटरेशन करने के लिए अक्सर `List` मॉड्यूल के फंक्शन इस्तेमाल किए जाते हैं, जैसे `List.map`, `List.filter` और `List.foldl`.
अंदर से ये फंक्शन रिकर्शन की मदद से बने होते हैं।
