# परिचय

## एक्सटर्नल फंक्शन

Gleam को Erlang वर्चुअल मशीन (BEAM) पर चलाया जा सकता है, और JavaScript रनटाइम पर भी। इन रनटाइम को कई और भाषाएँ भी इस्तेमाल करती हैं, और ऐसी भाषाओं में लिखे कोड को Gleam से कॉल कर पाना अक्सर बहुत काम आता है।

Gleam के _एक्सटर्नल फंक्शन_ फीचर की मदद से दूसरी भाषाओं के फंक्शन Gleam में इंपोर्ट किए जा सकते हैं और बिना किसी रनटाइम ओवरहेड के कॉल किए जा सकते हैं।

अगर आपका Gleam प्रोजेक्ट Erlang वर्चुअल मशीन पर चलता है और आप Erlang के `lists` मॉड्यूल से `reverse` फंक्शन कॉल करना चाहते हैं, तो इसके लिए आप Gleam फंक्शन के हेड में `@external` एट्रिब्यूट जोड़ सकते हैं, जैसे:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

इसके बाद इसे किसी सामान्य Gleam फंक्शन की तरह कॉल किया जा सकता है:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

अगर आप इस कोड को JavaScript रनटाइम के लिए कंपाइल करने की कोशिश करेंगे, तो एक एरर मिलेगी, क्योंकि JavaScript के लिए इसका कोई इम्प्लीमेंटेशन नहीं है। JavaScript रनटाइम के लिए दूसरा इम्प्लीमेंटेशन इस तरह दिया जा सकता है:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

ऐसा भी हो सकता है कि आप Gleam में ही एक इम्प्लीमेंटेशन लिखें, जो तब इस्तेमाल होगा जब मौजूदा कंपाइल टारगेट के लिए कोई एक्सटर्नल इम्प्लीमेंटेशन न हो:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## एक्सटर्नल टाइप

एक्सटर्नल टाइप की मदद से दूसरी भाषाओं, जैसे Erlang या JavaScript, में परिभाषित डेटा टाइप दर्शाए जा सकते हैं।

एक्सटर्नल टाइप बनाने के लिए एक टाइप घोषित कीजिए, पर कोई कंस्ट्रक्टर मत दीजिए। इसके बाद इसका इस्तेमाल किसी भी दूसरे टाइप की तरह किया जा सकता है।

```gleam
pub type OrderedDictionary(element)
```
