# टेस्ट

हम अपनी वेबसाइट के टेस्ट रनर के रूप में [pytest][pytest: Getting Started Guide] का उपयोग करते हैं।
अगर आप Python ट्रैक के टेस्ट अपनी मशीन पर लोकल रूप से चलाना चाहते हैं, तो आपको अपनी डेवलपमेंट मशीन पर `pytest` इंस्टॉल करना होगा।
आपको ये `pytest` प्लगइन भी इंस्टॉल करने चाहिए:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

विस्तृत जानकारी हमारी वेबसाइट की [Python टेस्टिंग गाइड][Python track tests page] में मिल सकती है।


### टेस्ट चलाना

दिए गए टेस्ट चलाने के लिए, अपने टर्मिनल में `cd` का उपयोग करके उस फोल्डर में जाइए जहाँ अभ्यास रखा गया है (नीचे दिए गए `<exercise-folder-location>` को अपने पाथ से बदल दीजिए)।
टेस्ट फाइलों के नाम आमतौर पर `_test.py` पर खत्म होते हैं, और ये वही टेस्ट हैं जो वेबसाइट पर कोई हल अपलोड करने पर चलते हैं।

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

अब अपने टर्मिनल में `pytest` कमांड चलाइए, और `<exercise_test.py>` को टेस्ट फाइल के नाम से बदल दीजिए:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### आम विकल्प
- `-o` : डिफ़ॉल्ट `pytest.ini` को ओवरराइड कीजिए (_आप इसका उपयोग मार्कर चेतावनियों से बचने के लिए कर सकते हैं_)
- `-v` : विस्तृत आउटपुट चालू कीजिए।
- `-x` : पहली विफलता पर टेस्ट चलाना बंद कर दीजिए।
- `--ff` : दूसरे टेस्ट केस चलाने से पहले पिछले टेस्ट की विफलताएँ चलाइए।

और विकल्पों के लिए, `python3 -m pytest -h` या `py -m pytest -h` का उपयोग कीजिए।


### चेतावनियाँ ठीक करना

अगर आप `pytest` चलाते समय `pytest -o markers=task` का उपयोग नहीं करते, तो उन टेस्ट के लिए, जो हमारे नए सिंटैक्स का उपयोग करते हैं, आपको `PytestUnknownMarkWarning` चेतावनी मिल सकती है:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

हर बार टेस्ट चलाते समय `pytest -o markers=task` टाइप करने से बचने के लिए, आप एक `pytest.ini` कॉन्फ़िगरेशन फाइल का उपयोग कर सकते हैं।
हमने एक ऐसी फाइल बनाई है जिसे Python ट्रैक डायरेक्टरी के टॉप लेवल से डाउनलोड किया जा सकता है: [pytest.ini][pytest.ini]।

आप अपनी खुद की `pytest.ini` फाइल भी इस सामग्री के साथ बना सकते हैं:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

`pytest.ini` फाइल को अपने Python ट्रैक के अभ्यासों के लिए _root_ या _working_ डायरेक्टरी में रखने से मार्क रजिस्टर हो जाएँगे और चेतावनियाँ बंद हो जाएँगी।
pytest मार्क के बारे में अधिक जानकारी `pytest` के डॉक्युमेंटेशन में [टेस्ट फंक्शन पर मार्क लगाना][pytest: marking test functions with attributes] और [कस्टम मार्कर के साथ काम करना][pytest: working with custom markers] वाले हिस्सों में मिलेगी।

pytest कॉन्फ़िगरेशन को कस्टमाइज़ करने की जानकारी `pytest` के डॉक्युमेंटेशन में [कॉन्फ़िगरेशन फाइल फॉर्मैट][pytest: configuration file formats] पर मिल सकती है।


### अपने IDE या कोड एडिटर का विस्तार करना

कई IDE और कोड एडिटर में `pytest` तथा कोड क्वालिटी के दूसरे टूल का उपयोग करने के लिए बिल्ट-इन सपोर्ट होता है।
कम्युनिटी से जुटाए गए कुछ विकल्प हमारे [Python ट्रैक टूल पेज][Python track tools page] पर मिल सकते हैं।
