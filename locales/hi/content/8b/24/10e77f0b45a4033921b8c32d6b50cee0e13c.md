# परिचय

## इटरेटर

Gleam में `Iterator` किसी ऐरे की तरह वैल्यू का एक क्रमबद्ध संग्रह होता है, जिसमें सभी वैल्यू एक ही डेटा टाइप की होती हैं। यह ऐरे से इस मामले में अलग है कि यह लेज़ी होता है, यानी यह अपनी सारी वैल्यू एक साथ मेमोरी में संग्रहीत नहीं करता, बल्कि जैसे-जैसे ज़रूरत पड़ती है, उन्हें बनाता जाता है।

यह बहुत बड़े या अनंत लंबाई वाले क्रमों के साथ काम करते समय बहुत उपयोगी होता है, क्योंकि इससे हम ऐसे क्रमों पर भी काम कर पाते हैं जिन्हें एक साथ पूरा संग्रहीत करने के लिए हमारे पास पर्याप्त खाली मेमोरी नहीं होती।

`gleam/iterator` मॉड्यूल `Iterator` टाइप के साथ-साथ इटरेटर पर काम करने वाले फंक्शन भी परिभाषित करता है।

ऐरे के लिए मिलने वाले बहुत से फंक्शन इटरेटर के लिए भी मौजूद हैं, जैसे `map`, `filter` और `take`। ये फंक्शन इटरेटर लौटाते हैं, इसलिए जब तक इटरेटर से वैल्यू नहीं निकाली जातीं, ये असल में कोई काम नहीं करते।

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` फंक्शन की मदद से ऐसे फंक्शन से इटरेटर बनाए जा सकते हैं जिसे क्रम में अगली वैल्यू बनाने के लिए बार-बार कॉल किया जाता है।

यहाँ `unfold` फंक्शन से एक ऐसा इटरेटर बनाया गया है जो फिबोनाची क्रम बनाता है:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

यहाँ क्रम अनंत है, इसलिए वैल्यू को ऐरे में इकट्ठा करने से पहले `take` फंक्शन से इसे सीमित बनाया जाता है। किसी अनंत इटरेटर पर `to_list` कॉल किया जाए, तो प्रोग्राम तब तक चलता रहेगा जब तक उसकी मेमोरी खत्म नहीं हो जाती और वह क्रैश हो जाता है।
