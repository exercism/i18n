# परिचय

Gleam में दो अलग-अलग तरह की संख्याएँ होती हैं: पूर्णांक और दशमलव संख्याएँ।

पूर्णांक पूर्ण संख्याएँ होते हैं।

```gleam
let integer = 3
// -> 3
```

स्पष्टता के लिए पूर्णांकों में अंडरस्कोर भी जोड़े जा सकते हैं।

```gleam
1_000_000 // One million
```

Gleam में ऐसे कई ऑपरेटर हैं जो पूर्णांकों के साथ काम करते हैं।

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
