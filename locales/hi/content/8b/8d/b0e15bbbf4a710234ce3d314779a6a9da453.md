# निर्देश

आप एक Take-A-Number मशीन के लिए एम्बेडेड सिस्टम लिख रहे हैं। यह बहुत ही सरल मॉडल है। यह लगातार संख्याएँ दे सकती है और बता सकती है कि सबसे अंत में कौन-सी संख्या दी गई थी।

## 1. मशीन शुरू कीजिए

`start/0` फंक्शन को लागू कीजिए। इसे एक नया प्रोसेस बनाना चाहिए और उस प्रोसेस की PID लौटानी चाहिए। नए प्रोसेस को अभी कुछ करने की ज़रूरत नहीं है।

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

ध्यान दीजिए कि हर बार यह कोड चलाने पर PID अलग हो सकती है।

## 2. मशीन की स्थिति बताइए

मशीन में बदलाव कीजिए ताकि नया बनाया गया प्रोसेस संदेश प्राप्त करने के लिए तैयार हो जाए (एक _रिसीव लूप_ शुरू कीजिए) और उसकी शुरुआती स्थिति `0` हो। यह `{:report_state, sender_pid}` संदेश प्राप्त कर सके। इन संदेशों के जवाब में इसे अपनी वर्तमान स्थिति (सबसे अंत में दी गई टिकट संख्या) `sender_pid` को भेजनी चाहिए और फिर आगे के संदेशों का इंतज़ार करना चाहिए।

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. संख्याएँ दीजिए

मशीन में बदलाव कीजिए ताकि यह `{:take_a_number, sender_pid}` संदेश प्राप्त कर सके। इसे अपनी स्थिति 1 से बढ़ानी चाहिए, नई स्थिति `sender_pid` को भेजनी चाहिए, और फिर आगे के संदेशों का इंतज़ार करना चाहिए।

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. मशीन रोकिए

मशीन में बदलाव कीजिए ताकि यह `:stop` संदेश प्राप्त कर सके। इसे आगे के संदेशों का इंतज़ार करना बंद कर देना चाहिए।

## 5. अनपेक्षित संदेशों को अनदेखा कीजिए

मशीन में बदलाव कीजिए ताकि जब उसे कोई अनपेक्षित संदेश मिले, तो वह उसे अनदेखा कर दे और आगे के संदेशों का इंतज़ार करता रहे।
