# परिचय

बाकी कई भाषाओं के उलट, JavaScript में ऐसी दो अलग-अलग चीज़ें हैं जो किसी (काम की) वैल्यू के न होने को दर्शाती हैं।
ये हैं `null` और `undefined`।

## Null

प्रिमिटिव वैल्यू `null` का उपयोग किसी भी टाइप के वेरिएबलो के लिए जान-बूझकर रखी गई "खाली वैल्यू" की तरह किया जाता है।

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

आप [सख्त समानता ऑपरेटर][mdn-strict-equality] `===` की मदद से जाँच सकते हैं कि कोई वेरिएबल null है या नहीं।

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> जिस वेरिएबल को कोई वैल्यू असाइन नहीं किया गया है, उसका टाइप `undefined` होता है।<sup>1</sup>

यानी `null` खाली वैल्यू को दर्शाता है (लेकिन वह फिर भी एक वैल्यू है), जबकि `undefined` वैल्यू के बिल्कुल न होने को दर्शाता है। 🤯

`undefined` अलग-अलग संदर्भों में सामने आता है।

- अगर किसी वेरिएबल को बिना कोई वैल्यू दिए घोषित किया जाए (इनिशियलाइज़ेशन), तो वह `undefined` होता है।
- अगर आप किसी ऑब्जेक्ट में ऐसी की की वैल्यू निकालने की कोशिश करते हैं जो वहाँ है ही नहीं, तो आपको `undefined` मिलता है।
- अगर कोई फंक्शन कोई वैल्यू नहीं लौटाता, तो परिणाम `undefined` होता है।
- अगर किसी फंक्शन को कोई आर्गुमेंट पास नहीं किया जाता, तो वह `undefined` होता है, जब तक कि उस आर्गुमेंट की कोई डिफॉल्ट वैल्यू न दी गई हो।

```javascript
let name;
console.log(name);
// => undefined
```

आप सख्त समानता ऑपरेटर `===` की मदद से जाँच सकते हैं कि कोई वेरिएबल undefined है या नहीं।

```javascript
let name;

name === undefined;
// => true
```

## ऑप्शनल चेनिंग

अगर आप किसी ऑब्जेक्ट में कोई नेस्टेड वैल्यू निकालने की कोशिश करें, लेकिन उसकी पैरेंट की मौजूद न हो, तो JavaScript एक एरर देता है।
इससे आसानी से बचने के लिए 2020 में भाषा के स्पेसिफिकेशन में ऑप्शनल चेनिंग जोड़ी गई।
ऑप्शनल चेनिंग ऑपरेटर `?.` की मदद से आप यह पक्का कर सकते हैं कि JavaScript नेस्टेड की को तभी निकालने की कोशिश करे जब उसका पैरेंट `null` या `undefined` न हो।
वरना `undefined` लौटाया जाता है।

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## नलिश कोलेसिंग

कुछ स्थितियों में आप चाहते हैं कि अगर कोई वेरिएबल null या undefined हो, तो उस पर एक डिफॉल्ट वैल्यू लग जाए (लेकिन सिर्फ़ तभी)।
इसे हल करने के लिए 2020 में नलिश कोलेसिंग ऑपरेटर `??` पेश किया गया।
यह दाएँ तरफ वाला ऑपरेंड तभी लौटाता है जब बाएँ तरफ वाला ऑपरेंड `null` या `undefined` हो।
वरना बाएँ तरफ वाला ऑपरेंड लौटा दिया जाता है।

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
