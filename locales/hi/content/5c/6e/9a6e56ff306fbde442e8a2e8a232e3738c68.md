# परिचय

ऐरे एक _कलेक्शन_ भी होता है। इसलिए इंडेक्स के ज़रिए वैल्यू तक पहुँचने के अलावा आप एक `foreach` लूप की मदद से उसकी _सभी_ वैल्यू पर इटरेशन कर सकते हैं:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
