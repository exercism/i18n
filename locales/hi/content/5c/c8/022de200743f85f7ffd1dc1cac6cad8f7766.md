# निर्देश

इस अभ्यास में आप एक साधारण पूर्णांक कैलकुलेटर के लिए एरर हैंडलिंग बनाएँगे।
बातें आसान रखने के लिए, जोड़, गुणा और भाग निकालने के मेथड पहले से दिए गए हैं।

लक्ष्य यह है कि दिए गए आर्गुमेंट `16`, `51` और `+` के साथ एक ऐसा कैलकुलेटर काम करे जो इस पैटर्न वाली स्ट्रिंग लौटाए: `16 + 51 = 67`।

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. कुछ बुनियादी ऑपरेशनों के लिए calculate मेथड लागू कीजिए

इस टास्क में जो मुख्य मेथड लागू करना है वह `CalculatorConundrum.calculate()` है।
यह तीन आर्गुमेंट लेता है।
पहले दो आर्गुमेंट `operand1` और `operand2` पूर्णांक संख्याएँ हैं, जिन पर कोई ऑपरेशन चलेगा।
तीसरा आर्गुमेंट `operation` स्ट्रिंग टाइप का है, और इस अभ्यास में इन ऑपरेशनों को लागू करना ज़रूरी है:

- `+` स्ट्रिंग से जोड़
- `*` स्ट्रिंग से गुणा
- `/` स्ट्रिंग से भाग

## 2. गलत ऑपरेशनों को संभालिए

गलत ऑपरेशनों को संभालने के लिए `CalculatorConundrum.calculate()` मेथड को अपडेट कीजिए:

- जब `operation` आर्गुमेंट `null` हो, तो `Operation cannot be null` संदेश के साथ एक `IllegalArgumentException` थ्रो होना चाहिए।
- जब `operation` आर्गुमेंट `""` हो, तो `Operation cannot be empty` संदेश के साथ एक `IllegalArgumentException` थ्रो होना चाहिए।
- जब `operation` आर्गुमेंट `+`, `*` या `/` के अलावा कोई और ऑपरेशन हो, तो `Operation '{operation}' does not exist` संदेश के साथ एक `IllegalOperationException` थ्रो होना चाहिए।

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. शून्य से भाग देने पर थ्रो हुए एक्सेप्शन को संभालिए

Java में शून्य से भाग देने की कोशिश करने पर एक `ArithmeticException` थ्रो होता है।
`CalculatorConundrum.calculate()` मेथड को अपडेट कीजिए ताकि वह इस एक्सेप्शन को कैच करे और फिर `Division by zero is not allowed` संदेश तथा कैच किए गए `ArithmeticException` को उसके कारण के रूप में लेते हुए एक `IllegalOperationException` थ्रो करे।

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
