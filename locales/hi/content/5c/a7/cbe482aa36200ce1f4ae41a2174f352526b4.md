# Nil

Crystal में `Nil` नाम का एक टाइप होता है, जिसकी केवल एक ही वैल्यू हो सकती है: `nil`.
इसका उपयोग किसी वैल्यू के न होने को दर्शाने के लिए किया जाता है, और यह दूसरी भाषाओं के `null` या `None` जैसा होता है।

कई मेथड nil भी लौटा सकते हैं, जैसे [`String#[]?`][string-index], जो इंडेक्स सीमा के बाहर होने पर `nil` लौटाता है।

```crystal
"foo"[10]? # => nil
```

Crystal में **NULL REFERENCE CHECKS** होते हैं। इसका मतलब है कि डिफॉल्ट रूप से किसी भी टाइप में nil नहीं रखा जा सकता।
इसका मतलब है कि आप किसी वेरिएबल को `nil` तब तक असाइन नहीं कर सकते जब तक कि उसे स्पष्ट रूप से `Nil` टाइप घोषित न कर दें।
और इसका मतलब यह है कि कंपाइलर null रेफरेंस की जाँच अपने आप कर लेता है।

## फॉल्सी वैल्यू

`nil` वैल्यू को संभालने के लिए कुछ तरीके अपनाए जा सकते हैं।
`false` की तरह `nil` भी एक [फॉल्सी][truthy-falsey] वैल्यू है।
इसका मतलब है कि जहाँ भी किसी फॉल्सी या ट्रुथी वैल्यू की अपेक्षा होती है, वहाँ इसे `false` की तरह ही माना जाता है, चाहे वह स्टेटमेंट हो या कोई और जगह।

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

इसका मतलब है कि अगर किसी ऐसे वेरिएबल की वैल्यू `nil` हो जिसमें nil रखा जा सकता है, तो ट्रुथी शाखा नहीं चुनी जाएगी।

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## nil की जाँच

Crystal में एक मेथड है जिससे यह जाँचा जा सकता है कि कोई वैल्यू `nil` है या नहीं।
इसे [`nil?`][nil?] कहते हैं, और यह सभी ऑब्जेक्ट पर उपलब्ध होता है।

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

यह तब थोड़ा अलग होता है जब आप वैल्यू को सीधे `if` स्टेटमेंट में इस्तेमाल करते हैं, क्योंकि पिछले उदाहरणों में `false` और `nil` दोनों को ही `false` जैसा माना जाता था।
यहाँ केवल `nil` को ही फॉल्सी माना जाता है; अगर वह `false` होती, तो वह nil न होती, और इसलिए वह ट्रुथी होती।

## या ऑपरेटर

`nil` वैल्यू से निपटने का सबसे आसान तरीका यह है कि वे शुरू में ही nil न बनें।
या ऑपरेटर ([`||`][or]) का उपयोग अक्सर `Bools` के साथ किया जाता है, लेकिन अगर इसे ठीक से समझा जाए, तो इसका उपयोग nil वैल्यू से निपटने के लिए भी किया जा सकता है।
या ऑपरेटर जाँचता है कि पहली वैल्यू ट्रुथी है या नहीं; अगर नहीं है, तो दूसरी वैल्यू इस्तेमाल की जाती है।
इसे इस तरह इस्तेमाल किया जा सकता है: अगर वैल्यू `nil` हो, तो वह फॉल्सी मानी जाएगी, और इस तरह दूसरी वैल्यू इस्तेमाल हो जाएगी।

```crystal
"foo"[10]? || "bar" # => "bar"
```

## not_nil!

~~~~exercism/caution 
इस तरीके को अंतिम उपाय मानना चाहिए, और इसका उपयोग तभी कीजिए जब आपको **पक्का** पता हो कि वैल्यू nil नहीं है।
जहाँ संभव हो, वहाँ इसके बजाय दूसरे तरीके अपनाइए।
~~~~

[`not_nil!`][not_nil] एक मेथड है जिसके ज़रिए आप कंपाइलर को बता सकते हैं कि कोई वैल्यू nil नहीं है, और इससे उस वैल्यू का टाइप भी nil नहीं रह पाता।
अगर वैल्यू nil हो, तो यह एक एक्सेप्शन उठाकर यह काम करता है।

```crystal
foo = "foo"[4]?
foo.not_nil!
# => Error: Nil assertion failed (NilAssertionError)
```
