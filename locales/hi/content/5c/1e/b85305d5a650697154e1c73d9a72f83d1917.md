# निर्देश

इस अभ्यास में आप एक रिमोट कंट्रोल कार के साथ खेलेंगे, जिसे खरीदने के लिए आपने अब जाकर पूरा पैसा जोड़ लिया है।

कारें पूरी (100%) बैटरी के साथ शुरू होती हैं।
हर बार जब आप रिमोट कंट्रोल से कार चलाते हैं, तो वह 20 मीटर चलती है और बैटरी का एक प्रतिशत खर्च कर देती है।
कार बनने तक उसका उपनाम पता नहीं होता।

रिमोट कंट्रोल कार में एक शानदार LED डिस्प्ले है, जो दो तरह की जानकारी दिखाता है:

- अब तक तय की गई कुल दूरी, जो इस तरह दिखाई जाती है: `"<METERS> meters"`।
- बची हुई बैटरी चार्ज, जो इस तरह दिखाई जाती है: `"Battery at <PERCENTAGE>%"`।

अगर बैटरी 0% पर है, तो आप कार को और नहीं चला सकते, और बैटरी डिस्प्ले `"Battery empty"` दिखाएगा।

## 1. बिल्कुल नई रिमोट कंट्रोल कार बनाइए

`new_remote_control_car/0` फंक्शन बनाइए, जो एक बिल्कुल नई रिमोट कंट्रोल कार ऑब्जेक्ट लौटाए:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. उपनाम के साथ बिल्कुल नई रिमोट कंट्रोल कार बनाइए

`new_remote_control_car/1` फंक्शन बनाइए, जो दिए गए उपनाम के साथ एक बिल्कुल नई रिमोट कंट्रोल कार ऑब्जेक्ट लौटाए:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. दूरी दिखाइए

`display_distance/0` फंक्शन बनाइए, जो इनपुट में एक कार ऑब्जेक्ट लेता है और LED डिस्प्ले पर दिखाई जाने वाली दूरी की स्ट्रिंग देता है:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. बैटरी का प्रतिशत दिखाइए

`display_battery/0` फंक्शन बनाइए, जो इनपुट में एक कार ऑब्जेक्ट लेता है और LED डिस्प्ले पर दिखाई जाने वाली बैटरी प्रतिशत स्ट्रिंग देता है:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

अगर बैटरी 0% पर है, तो बैटरी डिस्प्ले "Battery empty" दिखाएगा।

## 5. चलाने से बैटरी और तय की गई दूरी बदलती है

`drive/0` फंक्शन बनाइए, जो:

- इनपुट में एक कार ऑब्जेक्ट लेता है
- तय किए गए मीटरों की संख्या 20 से बढ़ा देता है
- बैटरी का 1% खर्च कर देता है
- बदले हुए कार ऑब्जेक्ट को आउटपुट देता है

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. बैटरी खत्म होने पर चलाने का ध्यान रखिए

`drive/0` फंक्शन को ऐसे बदलिए कि जब बैटरी खत्म (0%) हो, तो न तय की गई दूरी बढ़े और न बैटरी का प्रतिशत घटे:

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
