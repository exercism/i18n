# परिचय

Elm में [`List`][lists] एक संग्रह है जिसमें एक ही टाइप की शून्य या उससे अधिक वैल्यू रखी जा सकती हैं। बन जाने के बाद इस संग्रह को बदला नहीं जा सकता।

ऐरे इस तरह बनाए जा सकते हैं:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

किसी ऐरे में कोई एलिमेंट जोड़ने का सबसे आम तरीका `::` (cons) ऑपरेटर है:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

ऐरे पर काम या तो [`List` मॉड्यूल][list-module] में बने फंक्शन और ऑपरेटर से होता है, या [पैटर्न मैचिंग][list-destructuring] से।

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
[list-destructuring]: https://www.bekk.christmas/post/2020/8/peeking-inside-lists
