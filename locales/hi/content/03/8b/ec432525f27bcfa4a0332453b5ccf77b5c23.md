# परिचय

Go में फंक्शन फर्स्ट-क्लास वैल्यू होते हैं।
इसका मतलब है कि फंक्शन के साथ आप वही सब कुछ कर सकते हैं जो आप दूसरी सारी वैल्यू के साथ कर सकते हैं: फंक्शन को वेरिएबल में असाइन करना, उन्हें आर्गुमेंट के रूप में दूसरे फंक्शन को देना, या किसी फंक्शन से कोई फंक्शन लौटाना।

नीचे हम दो फंक्शन बना रहे हैं, `engGreeting` और `espGreeting`, और उन्हें `greeting` वेरिएबल में असाइन कर रहे हैं:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

फंक्शन वैल्यू की मदद से हम फंक्शन को सिर्फ डेटा ही नहीं, बल्कि व्यवहार भी पैरामीटर की तरह दे सकते हैं।
अगले उदाहरण में हम `greetingFunc` पैरामीटर के ज़रिए `dialog` फंक्शन को व्यवहार दे रहे हैं:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

फंक्शन टाइप के जिस वेरिएबल को कोई शुरुआती वैल्यू नहीं दी गई हो, उसकी वैल्यू `nil` होती है।
इसलिए `nil` फंक्शन वैल्यू को कॉल करने पर पैनिक हो जाता है।

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

फंक्शन वैल्यू की तुलना `nil` से की जा सकती है।
यह प्रोग्राम में बेवजह होने वाले पैनिक से बचने में काम आ सकता है।

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## फंक्शन टाइप

Go में फंक्शन वैल्यू का इस्तेमाल फंक्शन टाइप की मदद से संभव होता है।
फंक्शन टाइप उन सारे फंक्शन के समूह को दर्शाता है जिनके पैरामीटर टाइप और परिणाम टाइप एक ही क्रम में होते हैं।
फंक्शन टाइप के ऊपर यूज़र-डिफाइंड टाइप घोषित किए जा सकते हैं।
जैसे, पिछले उदाहरणों वाले `dialog` फंक्शन को इस तरह बदला जा सकता है:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## अनाम फंक्शन

फर्स्ट-क्लास फंक्शन के समर्थन से एक और बहुत काम का साधन उपलब्ध होता है, जिसे अनाम फंक्शन कहते हैं।
अनाम फंक्शन को उसी जगह बनाया जाता है जहाँ उसका इस्तेमाल होता है, और `func` कीवर्ड के बाद कोई नाम नहीं लिखा जाता।
ऐसे फंक्शन उस फंक्शन के वेरिएबल तक पहुँच सकते हैं जिसके अंदर वे बनाए गए हैं।

उदाहरण के लिए:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib` को कॉल करने पर वेरिएबल `n1` और `n2` घोषित होते हैं और एक अनाम फंक्शन लौटता है। वह अनाम फंक्शन हर बार कॉल किए जाने पर इन वेरिएबल की वैल्यू बदल देता है।
अनाम फंक्शन को N बार कॉल करने पर फिबोनाची अनुक्रम की Nवीं संख्या मिलती है, जो 0 से शुरू होती है। अंदर वाला अनाम फंक्शन अपने बाहरी फंक्शन `fib` के लोकल वेरिएबल (`n1` और `n2`) तक पहुँच सकता है।
फंक्शन वैल्यू को कॉल के बीच अपनी स्थिति बनाए रखने का यह बहुत अच्छा तरीका है।
हम कहते हैं कि यह अनाम फंक्शन वेरिएबल `n1` और `n2` का क्लोज़र है। [क्लोज़र][closure] का इस्तेमाल प्रोग्रामिंग में बहुत जगह होता है, और हो सकता है आप दूसरी भाषाओं में भी इनका समर्थन देखें।

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
