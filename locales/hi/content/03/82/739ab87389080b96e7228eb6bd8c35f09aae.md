# निर्देश

Ellen एक ऐसा गेम बना रही हैं जिसमें खिलाड़ी को एलियन से लड़ना होता है।
उन्होंने अभी-अभी ऑब्जेक्ट ओरिएंटेड प्रोग्रामिंग (OOP) के बारे में सीखा है और वे उत्सुक हैं कि `classes` के इस्तेमाल से उनके प्रोग्राम को क्या-क्या मिल सकता है।

Ellen को खुशी हुई कि आपने मदद करने की पेशकश की, और अब उन्होंने आपको वे एलियन प्रोग्राम करने का काम सौंपा है जिनसे खिलाड़ी को लड़ना है।


## 1. `Alien` क्लास बनाइए

`Alien` क्लास को एक कंस्ट्रक्टर के साथ बनाइए जो दो `int` पैरामीटर `x` और `y` लेता है और उन्हें `x_coordinate` और `y_coordinate` मेंबर वेरिएबलो में रखता है।
हर एलियन की शुरुआती हेल्थ भी `3` होगी, इसलिए `health` मेंबर वेरिएबल को भी शुरू में ही वैल्यू देनी होगी।

`health` एक private मेंबर वेरिएबल होना चाहिए।
प्रोग्राम के बाकी हिस्से हेल्थ की जानकारी पढ़ सकें, इसके लिए Ellen एक `public` `get_health()` मेथड चाहती हैं जो एक `int` लौटाता है।

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

अब हर एलियन को अपनी जगह और हेल्थ का हिसाब खुद रख पाना चाहिए।

## 2. `hit` फंक्शन

Ellen चाहती हैं कि `class` क्लास में एक `hit` मेथड हो, जो कॉल करने पर एलियन ऑब्जेक्ट की हेल्थ `1` कम कर दे।
इससे वे एलियन की हेल्थ खुद बदलने के बजाय सीधे `some_alien_instance.hit()` कॉल कर सकेंगी।
ध्यान रखिए कि हेल्थ 0 से नीचे न गिरे।
फंक्शन को `true` लौटाना चाहिए।
Ellen आगे चलकर शील्ड जोड़ना चाहती हैं, और तब शील्ड चालू होने पर यही फंक्शन `false` लौटाएगा।

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. `is_alive` फंक्शन

आप समझ ही गए होंगे कि हेल्थ लगातार घटती रहे, तो किसी न किसी समय वह `0` तक पहुँच जाएगी।
तो बेहतर होगा कि एक `is_alive` मेथड जोड़ दिया जाए, जिसे Ellen जल्दी से कॉल करके यह देख सकें कि एलियन... अरे हाँ... ज़िंदा है या नहीं। 😉
`some_alien_instance.is_alive()` को एक बूलियन लौटाना चाहिए।

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. `teleport` फंक्शन

Ellen के गेम में एलियन टेलीपोर्ट कर सकते हैं!
आपको एक `teleport` मेथड लिखना होगा जो `x_new` और `y_new` वैल्यू लेता है और उसी हिसाब से एलियन के निर्देशांक बदल देता है।
फिलहाल इस फंक्शन को `true` लौटाना चाहिए।
Ellen आगे के लेवल में टेलीपोर्ट रोकने वाले बम जोड़ना चाहती हैं, और तब टेलीपोर्ट की असफल कोशिश पर यही फंक्शन `false` लौटाएगा।

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. `collision_detection` फंक्शन

अगर एलियन पर किसी चीज़ की चोट लग सकती है, तो उन्हें यह पता लगाने की भी ज़रूरत है कि ऐसी टक्कर कब हो सकती है।
Ellen को जानना है कि दो एलियन एक ही निर्देशांक पर हैं या नहीं।
`collision_detection()` फंक्शन आर्गुमेंट के तौर पर दूसरा एलियन ऑब्जेक्ट लेता है और एक `bool` लौटाता है।

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
