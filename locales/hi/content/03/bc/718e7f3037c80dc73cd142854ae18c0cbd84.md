# परिचय

हमने `Vectors` कॉन्सेप्ट में देखा था कि किसी वेक्टर को शर्त वाले एक्सप्रेशन में इस्तेमाल किया जा सकता है, जिससे एक लॉजिकल वेक्टर मिलता है। इसका इस्तेमाल आगे `all()` और `any()` जैसे फंक्शन में किया जा सकता है।

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

यह तरीका इससे कहीं ज़्यादा शक्तिशाली है।

## वेक्टर सबसेट

किसी वेक्टर के चुने हुए एलिमेंट इंडेक्स संख्या या इंडेक्स के वेक्टर से निकाले जा सकते हैं:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

दूसरा तरीका यह है कि मूल वेक्टर को फ़िल्टर करने के लिए लॉजिकल वेक्टर इस्तेमाल कीजिए, जिससे उन एलिमेंट का सबसेट मिलता है जो `TRUE` वैल्यू से मेल खाते हैं:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

वहाँ से शर्त वाले एक्सप्रेशन की मदद से बूलियन वेक्टर बनाना बस छोटा-सा कदम है:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## इंडेक्स ढूँढना

`which()` फंक्शन एक बूलियन आर्गुमेंट लेता है और उन इंडेक्स का वेक्टर लौटाता है जिन पर `TRUE` मिलता है।

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## किसी एलिमेंट के मौजूद होने की जाँच

पिछले भागों में ऐसे एलिमेंट ढूँढने की बात थी जो किसी मानदंड से मेल खाते हों।

अगर आपको सिर्फ यह जानना हो कि वेक्टर में कोई खास एलिमेंट मौजूद है या नहीं, तो `%in%` ऑपरेटर इस्तेमाल किया जाता है।

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

यह नीचे दिए कोड जितना ही काम करता है, लेकिन कहीं ज़्यादा सुविधाजनक है:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
