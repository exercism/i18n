# रेंज

[रेंज][range] दो वैल्यू के बीच के अंतराल को दर्शाता है।
रेंज को सबसे आम तौर पर `Int`, `Char` और `String` टाइप सपोर्ट करते हैं।
इनका उपयोग कई कामों के लिए किया जा सकता है, जैसे तेज़ी से कोई कलेक्शन बनाना, स्ट्रिंग को काटना, यह जाँचना कि कोई वैल्यू रेंज में है या नहीं, और इटरेशन करना।
इन्हें रेंज ऑपरेटर `..` या `...` से बनाया जाता है (क्रमशः समावेशी और अपवर्जी)।

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

दो रेंज ऑपरेटर होने की वजह यह है कि आप ऐसी रेंज बना सकें जो अंतिम वैल्यू को शामिल करे या न करे। यह तब काम आता है, जब आप शून्य से शुरू होने वाले इंडेक्स के साथ काम कर रहे हों।

रेंज को `Range` इनिशियलाइज़र की मदद से भी बनाया जा सकता है।

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
जब आप Crystal में `..` या `...` रेंज ऑपरेटर से कोई रेंज बनाते हैं और उस रेंज पर कोई मेथड कॉल करना चाहते हैं, तो रेंज को ब्रैकेट में लपेटना पड़ता है।
ऐसा न करने पर वह मेथड रेंज ऑपरेटर के दूसरे आर्गुमेंट पर कॉल हो जाता है।

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## सबस्ट्रिंग निकालना

जब आपको किसी स्ट्रिंग को काटकर उसका हिस्सा चाहिए, तो आप रेंज ऑपरेटर की मदद से सबस्ट्रिंग निकाल सकते हैं।
इसके लिए सबस्ट्रिंग के शुरुआती और अंतिम इंडेक्स से एक रेंज बनाइए।

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

आप नेगेटिव इंडेक्स का उपयोग करके स्ट्रिंग के अंत से भी सबस्ट्रिंग निकाल सकते हैं।

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## रेंज के मेथड

रेंज के साथ काम करने के लिए कई मेथड मौजूद हैं।
जैसे, इन मेथड की मदद से आप रेंज की सभी वैल्यू का जोड़ निकाल सकते हैं या यह जाँच सकते हैं कि कोई वैल्यू रेंज में शामिल है या नहीं।

| मेथड                    | विवरण                                                                   | उदाहरण                          |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | रेंज की सभी वैल्यू का जोड़ लौटाता है                                     | `(1..5).sum # => 15`            |
| [`size`][size]          | रेंज का आकार लौटाता है                                                  | `(1..5).size # => 5`            |
| [`includes?`][indludes] | अगर रेंज में दी गई वैल्यू शामिल है तो `true` लौटाता है, वरना `false`     | `(1..5).includes?(3) # => true` |

## अंत-रहित और शुरुआत-रहित रेंज

कोई रेंज अंत-रहित या शुरुआत-रहित हो सकता है।
अंत-रहित या शुरुआत-रहित रेंज की शुरुआत या अंत वाली वैल्यू `nil` होती है, लेकिन रेंज बनाते समय `nil` लिखने की ज़रूरत नहीं होती।

शुरुआत-रहित और अंत-रहित रेंज तब काम आते हैं, जब आपको, जैसे, किसी स्ट्रिंग को शुरुआत से या अंत तक काटना हो।

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
अगर अंत-रहित रेंज का इस्तेमाल किसी कलेक्शन पर नहीं किया जाए, तो सावधानी न बरतने पर यह एक अंतहीन क्रम बना सकता है।
~~~~

## Char रेंज

रेंज में अक्षरों का उपयोग किया जा सकता है, जिससे आप दो अक्षरों के बीच के अक्षरों का अंतराल पा सकते हैं।
उदाहरण के लिए, यह तब काम आता है जब आपको वर्णमाला चाहिए।

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## स्ट्रिंग रेंज

रेंज में स्ट्रिंग का भी उपयोग किया जा सकता है, जिससे दो स्ट्रिंग के बीच की स्ट्रिंग का अंतराल पाया जा सकता है।
लेकिन जब किसी स्ट्रिंग रेंज में एक से ज़्यादा अक्षर इस्तेमाल किए जाते हैं, तो इसका व्यवहार `Char` के मुकाबले थोड़ा अलग होता है।
ज़्यादा जटिल स्ट्रिंग रेंज बनाते समय इसका व्यवहार उलझाने वाला हो सकता है, इसलिए सावधानी बरतिए।

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## रेंज में कस्टम ऑब्जेक्ट

~~~~exercism/advanced
Crystal आपको रेंज में कस्टम ऑब्जेक्ट इस्तेमाल करने की सुविधा देता है।
इसके लिए ज़रूरी है कि ऑब्जेक्ट इन चीज़ों को लागू करे:

- `Comparable` मॉड्यूल को शामिल करे
- `succ` मेथड
- `<=>` मेथड

इन मेथड की वजह से रेंज ऑब्जेक्ट पर इटरेशन कर पाता है और रेंज के भीतर के ऑब्जेक्ट की तुलना कर पाता है।

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
