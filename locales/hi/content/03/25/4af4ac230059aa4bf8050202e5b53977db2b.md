# परिचय

## मूल बातें

[Lua](https://lua.org) एक सरल, फिर भी शक्तिशाली, कुशल, हल्की और एम्बेड करने योग्य स्क्रिप्टिंग भाषा है। इसे 1993 से ब्राज़ील के [PUC-RIO](https://www.puc-rio.br/) में Roberto Ierusalimschy, Waldemar Celes और Luiz Henrique de Figueiredo की टीम द्वारा डिज़ाइन किया गया है, लागू किया गया है और बनाए रखा जाता है।

### कमेंट

Lua में सिंगल-लाइन कमेंट `--` से शुरू होते हैं और मल्टीलाइन कमेंट `--[[` से शुरू होकर `]]` पर खत्म होते हैं।
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### वेरिएबल

Lua में तीन तरह के वेरिएबल होते हैं: ग्लोबल वेरिएबल, लोकल वेरिएबल और टेबल फील्ड। बातें आसान रखने के लिए यहाँ सिर्फ लोकल वेरिएबल समझाए गए हैं। डिफ़ॉल्ट रूप से सभी वेरिएबल ग्लोबल होते हैं, इसलिए हमें लोकल वेरिएबल को `local` कीवर्ड के साथ ही लोकल घोषित करना होता है।
```lua
local x
```

`=` ऑपरेटर की मदद से किसी वेरिएबल को एक वैल्यू असाइन की जा सकती है।
```lua
local x = 1
```

एक `local` वेरिएबल का स्कोप उसी ब्लॉक तक सीमित रहता है जहाँ उसे घोषित किया गया है। ब्लॉक किसी कंट्रोल स्ट्रक्चर के अंदर का कोड हो सकता है, किसी फंक्शन के अंदर का कोड हो सकता है, या वह फाइल या स्ट्रिंग हो सकता है जहाँ वेरिएबल घोषित किया गया है।
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### फंक्शन

फंक्शन `function` कीवर्ड से घोषित किया जाता है और वेरिएबल की तरह डिफ़ॉल्ट रूप से ग्लोबल होता है। फंक्शन की परिभाषा में एक नाम, पैरामीटर की सूची और अंदर का कोड होता है। जब `return` कीवर्ड तक पहुँचा जाता है तो फंक्शन बाहर निकल जाता है और उसके बाद लिखी सभी वैल्यू लौटाता है। अगर `return` न लिखा हो, तो फंक्शन `nil` लौटाता है।

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### टेबल

टेबल Lua में डेटा को व्यवस्थित करने का एकमात्र तरीका हैं और बहुत शक्तिशाली हैं। इनका इस्तेमाल ऐरे, सेट, ऑब्जेक्ट, मॉड्यूल और बहुत कुछ को दर्शाने के लिए किया जाता है। वास्तव में Lua में टेबल एक असोसिएटिव ऐरे है।
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

यह सिर्फ एक छोटी-सी झलक है, जो अगले हिस्से के लिए ज़रूरी है। इस विषय पर हम बाद में विस्तार से बात करेंगे।

### मॉड्यूल

मॉड्यूल कोड का एक ऐसा संग्रह है जो एक `.lua` सोर्स फाइल में संग्रहीत रहता है। मॉड्यूल जो कुछ भी एक्सपोर्ट करता है, वह सब एक टेबल में संग्रहीत होता है और यही टेबल फाइल के अंत में लौटाई जाती है। यानी यह टेबल एक तरह के नेमस्पेस का काम करती है।
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

फिर उस मॉड्यूल को `require` फंक्शन के ज़रिए किसी दूसरी फाइल में लोड किया जा सकता है; यह फंक्शन वह टेबल लौटाता है।
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

जब हम `say.hello` देखते हैं, तो हमें लगता है कि यह "`say` मॉड्यूल का `hello` फंक्शन" है। लेकिन अगर हमें पता है कि हमारी `say-hello.lua` एक टेबल लौटाती है और हम टेबल वाला हिस्सा फिर से देखें, तो हमें एहसास होगा कि Lua में इस एक्सप्रेशन का मतलब है "`say` टेबल को `hello` स्ट्रिंग को की के रूप में इस्तेमाल करके इंडेक्स करना"।  

हालाँकि यह अच्छा तरीका माना जाता है कि मॉड्यूल एक टेबल लौटाए, लेकिन किसी और टाइप को, जैसे किसी फंक्शन को, लौटाना भी बिल्कुल संभव है।

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
