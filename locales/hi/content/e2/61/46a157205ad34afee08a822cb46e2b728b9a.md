# निर्देश

इस अभ्यास में आप खेलों के बड़े प्रशंसक हैं और आपको NBA बास्केटबॉल से अभी-अभी लगाव हुआ है। चूँकि आप NBA बास्केटबॉल में नए हैं, इसलिए आप इसके इतिहास में गहराई तक उतर रहे हैं। आप टीमों और कोचों पर नज़र रखते हैं, उनके जीत-हार के आँकड़े जोड़ते हैं और उनकी एक-दूसरे से तुलना करते हैं।

चूँकि अभी आपकी कोई पसंदीदा टीम नहीं है, इसलिए आप एक एल्गोरिदम भी बनाएँगे जो यह तय करेगा कि किसी खास टीम का समर्थन करना चाहिए या नहीं। आपके पास सात काम हैं जो आपको अपना खुद का _टीम-का-समर्थन-करने-वाला_ एल्गोरिदम बनाने में मदद करेंगे।

## 1. मॉडल परिभाषित कीजिए

निम्नलिखित दो फील्ड वाले रिकॉर्ड के लिए `Coach` टाइप एलियस परिभाषित कीजिए, जिनका क्रम यह रहे:

- `name`: कोच का नाम; इसका टाइप `String` है।
- `formerPlayer`: बताता है कि कोच पहले खिलाड़ी रह चुका था या नहीं; इसका टाइप `Bool` है।

निम्नलिखित दो फील्ड वाले रिकॉर्ड के लिए `Stats` टाइप एलियस परिभाषित कीजिए, जिनका क्रम यह रहे:

- `wins`: जीत की संख्या; इसका टाइप `Int` है।
- `losses`: हार की संख्या; इसका टाइप `Int` है।

निम्नलिखित तीन फील्ड वाले रिकॉर्ड के लिए `Team` टाइप एलियस परिभाषित कीजिए, जिनका क्रम यह रहे:

- `name`: टीम का नाम; इसका टाइप `String` है।
- `coach`: टीम का कोच; इसका टाइप `Coach` है।
- `stats`: टीम के आँकड़े; इसका टाइप `Stats` है।

## 2. एक टीम बनाइए

आप किसी तीसरे पक्ष के कोड से जुड़ना चाहते हैं, जिसमें टीम की अवधारणा तो है, लेकिन जो आपके कोड को अलग क्रम में पैरामीटर देकर कॉल करता है। निम्नलिखित सिग्नेचर वाला `createTeam` फंक्शन जोड़िए: `String -> Stats -> Coach -> Team`.

## 3. कोच को बदलिए

NBA के मालिक सब्र नहीं रखते, और आपने देखा कि टीम के नतीजे खराब रहने पर अक्सर कोच बदल दिया जाता था।
`replaceCoach` फंक्शन बनाइए जो पैरामीटर के रूप में नया कोच और टीम लेता है और टीम को नए कोच के साथ लौटाता है:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. जाँचिए कि आपको किसी टीम का समर्थन करना चाहिए या नहीं

आगे चलकर आप एक जटिल एल्गोरिदम बनाने की सोच रहे हैं, जो तय करेगा कि किसी टीम का समर्थन करना चाहिए या नहीं। लेकिन पहली कोशिश के लिए आपने तय किया है कि जिस टीम की जीत उसकी हार से ज़्यादा हो, आप उस टीम का समर्थन करेंगे।

आप चाहते हैं कि यह फंक्शन दूसरे संदर्भों में भी काम आए, इसलिए टाइप सिग्नेचर में एक्स्टेंसिबल रिकॉर्ड इस्तेमाल कीजिए, ताकि यह ऐसा कोई भी रिकॉर्ड स्वीकार कर सके जिसमें संबंधित फील्ड मौजूद हों।
फंक्शन को जितना हो सके संक्षिप्त रखने के लिए आप पैटर्न मैचिंग इस्तेमाल करके फंक्शन के पैरामीटर से `stats` निकालना चाहते हैं।
`rootForTeam` फंक्शन बनाइए जो एक टीम लेता है और अगर आपको उस टीम का समर्थन करना चाहिए तो `True` लौटाता है; वरना `False` लौटाता है।

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
