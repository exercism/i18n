# परिचय

[स्ट्रक्चर][structs-and-classes] (इन्हें आमतौर पर *स्ट्रक्चर* कहा जाता है) Swift प्रोग्राम के मुख्य निर्माण खंडों में से एक हैं।
स्ट्रक्चर की मदद से आप ऐसे कस्टम टाइप बना सकते हैं जो आपस में जुड़ी प्रॉपर्टी (डेटा) और मेथड (व्यवहार) को एक साथ रखते हैं।
वास्तव में, Swift के मानक टाइप, जिनमें `Int`, `Double`, `Bool`, `String`, `Array`, और `Dictionary` शामिल हैं, सभी स्ट्रक्चर के रूप में लागू किए गए हैं।

## स्ट्रक्चर परिभाषित करना

`struct` कीवर्ड का उपयोग करके एक स्ट्रक्चर परिभाषित कीजिए। कीवर्ड के बाद टाइप का नाम लिखिए और फिर घुंघराले ब्रैकेट लगाइए, जिनके अंदर उसकी परिभाषा होती है।
Swift के कन्वेंशन के अनुसार स्ट्रक्चर के नाम `UpperCamelCase` में लिखे जाते हैं:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## इंस्टेंस बनाना

स्ट्रक्चर की परिभाषा एक खाका होती है।
किसी स्ट्रक्चर का *इंस्टेंस* बनाने के लिए उसका इनिशियलाइज़र कॉल कीजिए: टाइप का नाम लिखिए और उसके बाद गोल ब्रैकेट लगाइए।

```swift
var someStats = CharacterStats()
```

इससे एक इंस्टेंस बनता है, जिसमें परिभाषा में दी गई डिफ़ॉल्ट प्रॉपर्टी वैल्यू भरी होती हैं।

Swift स्ट्रक्चर के लिए अपने आप एक **मेंबरवाइज़ इनिशियलाइज़र** भी बनाता है, जिससे आप प्रॉपर्टी को नाम से इनिशियलाइज़ कर सकते हैं:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## प्रॉपर्टी तक पहुँचना और उन्हें बदलना

आप *डॉट नोटेशन* का उपयोग करके किसी इंस्टेंस की प्रॉपर्टी तक पहुँचते हैं और उन्हें बदलते हैं:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

चूँकि स्ट्रक्चर वैल्यू टाइप होते हैं, किसी इंस्टेंस की प्रॉपर्टी बदलने के लिए ज़रूरी है कि इंस्टेंस को `var` से घोषित किया गया हो।
अगर इंस्टेंस को `let` से घोषित किया गया है, तो उसकी सभी प्रॉपर्टी अपरिवर्तनीय हो जाती हैं।
