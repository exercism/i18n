# निर्देश परिशिष्ट

## शब्द

`real` और `imaginary` स्लॉट वाला एक `cmplx` टपल बनाइए। टपल बनाते ही
`real>>` और `imaginary>>` स्लॉट एक्सेसर अपने आप मिल जाते हैं, और टेस्ट
इन्हीं की मदद से कॉम्पोनेंट पढ़ते हैं।

- `<cmplx> ( real imag -- cmplx )` एक कॉम्प्लेक्स संख्या बनाता है।
- `>cmplx ( pair -- cmplx )` `{ real imaginary }` से एक `cmplx` बनाता है।
- `cmplx>pair ( cmplx -- pair )` `{ real imaginary }` लौटाता है।
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )` दो कॉम्प्लेक्स संख्याओं पर अंकगणित करते हैं।
- `c-abs ( a -- |a| )` निरपेक्ष मान (वास्तविक संख्या) देता है।
- `c-conj ( a -- a* )` कॉम्प्लेक्स संयुग्मी देता है।
- `c-exp ( z -- e^z )` कॉम्प्लेक्स चरघातांकी देता है।

Factor के `MATH:` जेनेरिक (`+`, `-`, `*`, `/`) सिर्फ पहले से मौजूद गणित
पदानुक्रम पर ही डिस्पैच करते हैं, इसलिए इस अभ्यास में उन जेनेरिक पर
मेथड बनाने के बजाय अलग शब्द नाम इस्तेमाल किए गए हैं।

जिस अंकगणित में वास्तविक संख्याएँ और कॉम्प्लेक्स संख्याएँ मिली हुई हों,
उसके टेस्ट शामिल नहीं हैं। यहाँ हर ऑपरेशन दो `cmplx` वैल्यू के बीच ही
होता है।
