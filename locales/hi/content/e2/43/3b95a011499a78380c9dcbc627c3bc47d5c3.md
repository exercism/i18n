# Nil

Crystal में `Nil` नाम का एक टाइप होता है, जिसमें सिर्फ एक ही वैल्यू हो सकती है: `nil`।
इसका उपयोग किसी वैल्यू के न होने को दर्शाने के लिए किया जाता है, और यह दूसरी भाषाओं के `null` या `None` जैसा होता है।

कई मेथड `nil` लौटा सकते हैं, जैसे [`String#[]?`][string-index], जो इंडेक्स के सीमा से बाहर होने पर `nil` लौटाता है।

```crystal
"foo"[10]? # => nil
```

Crystal में **NULL REFERENCE CHECKS** होते हैं। इसका मतलब है कि डिफ़ॉल्ट रूप से किसी भी टाइप की वैल्यू `nil` नहीं हो सकती।
यानी आप किसी वेरिएबल को `nil` असाइन नहीं कर सकते, जब तक कि आप उसे स्पष्ट रूप से `Nil` टाइप घोषित न करें।
और इसका मतलब है कि कंपाइलर null रेफ़रेंस की जाँच खुद कर लेता है।

## फॉल्सी वैल्यू

`nil` वैल्यू को संभालने के कुछ तरीके हैं।
`nil` एक [फॉल्सी][truthy-falsey] वैल्यू है, और `false` भी।
इसका मतलब है कि स्टेटमेंट में और ऐसी हर जगह जहाँ फॉल्सी या ट्रूथी वैल्यू की अपेक्षा होती है, `nil` के साथ वही व्यवहार होता है जो `false` के साथ होता है।

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

इसका मतलब है कि अगर किसी वेरिएबल में `nil` हो सकता है और उसकी वैल्यू `nil` है, तो ट्रूथी शाखा नहीं चुनी जाएगी।

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## nil की जाँच

Crystal में एक मेथड है जिससे जाँच सकते हैं कि कोई वैल्यू `nil` है या नहीं।
इसे [`nil?`][nil?] कहते हैं और यह सभी ऑब्जेक्ट पर उपलब्ध होता है।

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

यह उस स्थिति से थोड़ा अलग है जब आप वैल्यू को सीधे `if` स्टेटमेंट में इस्तेमाल करते हैं, क्योंकि पिछले उदाहरणों में `false` और `nil` दोनों को ही फॉल्सी माना जाता है।
यहाँ सिर्फ `nil` को ही फॉल्सी माना जाता है। अगर वैल्यू `false` होती, तो वह `nil` न होती, इसलिए वह ट्रूथी होती।

## ऑर ऑपरेटर

`nil` वैल्यू से निपटने का सबसे आसान तरीका यह है कि वे शुरू से ही `nil` न बनें।
ऑर ऑपरेटर ([`||`][or]) का इस्तेमाल अक्सर `Bools` को संभालते समय किया जाता है, लेकिन अगर इसे ठीक से समझ लिया जाए, तो यह `nil` वैल्यू को संभालने में भी काम आ सकता है।
ऑर ऑपरेटर जाँचता है कि पहली वैल्यू ट्रूथी है या नहीं। अगर नहीं, तो दूसरी वैल्यू इस्तेमाल की जाती है।
इसका इस्तेमाल इस तरह किया जा सकता है कि अगर वैल्यू `nil` हो, तो वह फॉल्सी होगी और इस तरह दूसरी वैल्यू इस्तेमाल की जाएगी।

```crystal
"foo"[10]? || "bar" # => "bar"
```
