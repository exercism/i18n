# परिचय

[एक्सटेंशन मेथड][extension-methods] की मदद से हम मौजूदा टाइप में नए मेथड जोड़ सकते हैं। इसके लिए नया डेराइव्ड टाइप बनाने, दोबारा कंपाइल करने या मूल टाइप में कोई और बदलाव करने की ज़रूरत नहीं पड़ती।

एक्सटेंशन मेथड स्टैटिक मेथड होते हैं, लेकिन इन्हें ऐसे कॉल किया जाता है जैसे ये उस टाइप के इंस्टेंस मेथड हों जिसमें ये जोड़े गए हैं। यह काम टाइप से पहले `this` लिखकर होता है, जो बताता है कि जिस इंस्टेंस पर हम `.` लगाते हैं, वही पहला पैरामीटर बनकर पास होता है। जो कोड एक्सटेंशन मेथड का इस्तेमाल करता है, उसे एक्सटेंशन मेथड कॉल करने और किसी टाइप में परिभाषित मेथड कॉल करने में कोई फर्क नहीं दिखता।

```csharp
namespace MyExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split().Length;
    }
}

"Hello World".WordCount();
// => 2
```

एक्सटेंशन मेथड नेमस्पेस के लेवल पर स्कोप में आते हैं। इसका मतलब है कि अगर आपका कोड किसी और नेमस्पेस में है और एक्सटेंशन मेथड किसी दूसरे नेमस्पेस में बनाया गया है, तो पहले उस नेमस्पेस को `using` डायरेक्टिव में लाना होगा। जैसे, ऊपर दिए उदाहरण को अपने कोड में इस्तेमाल करने के लिए हमें पहले `using MyExtensions` डायरेक्टिव लिखना होगा। अगर आप उसी नेमस्पेस में हैं जिसमें एक्सटेंशन मेथड बनाया गया है, तो आप बिना `using` डायरेक्टिव के भी एक्सटेंशन मेथड इस्तेमाल कर सकते हैं।

एक्सटेंशन मेथड का एक जाना-माना उदाहरण [LINQ][linq] के स्टैंडर्ड क्वेरी ऑपरेटर हैं, जो मौजूदा IEnumerable टाइप में क्वेरी की सुविधा जोड़ते हैं। इन्हें स्कोप में लाने के लिए हमें `using System.Linq;` डायरेक्टिव चाहिए।

[linq]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/
[extension-methods]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/extension-methods
