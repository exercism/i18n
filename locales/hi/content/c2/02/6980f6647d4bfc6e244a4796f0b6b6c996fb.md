# इंस्टॉलेशन

हम Standard ML के लिए *PolyML* इस्तेमाल करेंगे।

अगर आप Windows इस्तेमाल कर रहे हैं, तो आप [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases) से इंस्टॉलर डाउनलोड कर सकते हैं।
Linux/OS X/Free BSD के लिए आम निर्देश [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme) पर मिल जाएँगे।

अगर आप सोर्स से इंस्टॉल करना चाहते हैं, तो यह तरीका काफी आसान है:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

अगर आप इसे किसी अपनी पसंद की जगह पर इंस्टॉल करना चाहते हैं, जैसे `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

अंतिम चरण:

```sh
$ make compiler
$ make install
```

जाँचिए कि यह ठीक से इंस्टॉल हुआ है या नहीं:

```sh
$ poly
```

अगर आपको इंटरप्रेटर दिख रहा है, तो आप तैयार हैं!
अगर नहीं, तो आपको शायद अपने `$PATH` में `$HOME/.local/bin` (या `<you prefix>/bin`) जोड़ना पड़ेगा।
