# परिचय

C++ की यात्रा शुरू करने के लिए हम वेरिएबल, फंक्शन कॉल और कमेंट से शुरुआत कर रहे हैं।

## कमेंट

कमेंट दो तरह के होते हैं: एक लाइन वाले और कई लाइनों वाले।
एक ही लाइन पर `//` के बाद आने वाली हर चीज़ को कंपाइलर अनदेखा कर देता है।
कई लाइनों वाले कमेंट को C-स्टाइल कमेंट भी कहा जाता है।
इन्हें `/*` और `*/` के बीच लिखा जाता है।
इनके बीच आने वाली हर चीज़ भी अनदेखी कर दी जाती है।

## वेरिएबल

C++ एक टाइप्ड भाषा है।
सभी टाइप कंपाइल के समय पता होने चाहिए, और आम तौर पर आपको इन्हें साफ़-साफ़ बताना पड़ता है।
किसी वेरिएबल का टाइप बदल नहीं सकता।
`years` नाम का एक पूर्णांक वेरिएबल इस तरह घोषित किया जा सकता है:

```cpp
int years;
```

वेरिएबल को घोषित करते समय ही इनिशियलाइज़ कर देना अच्छा तरीका है।
C++ इसके लिए अलग-अलग तरीके देती है।
कर्ली ब्रैकेट वाला रूप आधुनिक C++ के ज़्यादा करीब है, लेकिन बराबर के चिह्न वाला रूप भी बहुत आम है।

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ बिना इनिशियलाइज़ किए वेरिएबल इस्तेमाल करने की अनुमति देती है।
जब तक वेरिएबल को जान-बूझकर सेट न किया जाए, तब तक वह अपरिभाषित रहता है और उसमें कुछ भी हो सकता है।
सेट करने से पहले इस्तेमाल होने की एररों और अपरिभाषित व्यवहार से बचने के लिए **हमेशा इनिशियलाइज़ करना** बेहतर है।
अपरिभाषित व्यवहार आपके प्रोग्राम को सबसे बुरे समय पर क्रैश कर सकता है, जबकि पहले वह ठीक चल रहा था।
यह बात कितनी भी ज़ोर देकर कही जाए कम है: अपरिभाषित व्यवहार से हर हाल में बचिए।
~~~~

## अंकगणितीय संक्रियाएँ

`*`, `+` या `-` जैसे अंकगणितीय ऑपरेटर `3 * 2` या `tomatoes + potatoes` जैसे एक्सप्रेशन का हिस्सा हो सकते हैं।

## वेरिएबल को अपडेट करना

आप वेरिएबल को फिर से असाइन कर सकते हैं, बस उनका टाइप वही रहना चाहिए:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## फंक्शन

हर फंक्शन का एक नाम, एक रिटर्न टाइप और एक पैरामीटर सूची होती है, जो खाली भी हो सकती है।
`always_fortyseven` नाम का ऐसा फंक्शन जो हमेशा 47 लौटाता है, इस तरह दिखेगा:

```cpp
int always_fortyseven() {
    return 47;
}
```

यहाँ `vip_fee` है, जिसमें एक पैरामीटर है:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

या `total_fee`, जो तीन पैरामीटर वाला फंक्शन है और इसमें एक और फंक्शन को कॉल किया गया है।

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

C++ में फंक्शन कुछ और भाषाओं की तरह अंतिम स्टेटमेंट की वैल्यू नहीं लौटाते।
कोड के कंपाइल होने के लिए `return` कीवर्ड ज़रूरी है।

### व्हाइटस्पेस

व्हाइटस्पेस का इस्तेमाल सोर्स कोड को फॉर्मेट करने के लिए होता है, और इसमें स्पेस, टैब या नई लाइनें शामिल होती हैं।
चूँकि कंपाइलर गैर-ज़रूरी व्हाइटस्पेस को अनदेखा कर देता है, आप इसका इस्तेमाल अपने कोड को व्यवस्थित करने के लिए कर सकते हैं।
व्हाइटस्पेस का समझदारी से किया गया इस्तेमाल आपके कोड को पढ़ने में आसान बना सकता है।
फॉर्मेट करने के अलग-अलग मानक हैं, लेकिन ये सब परंपराएँ हैं और कंपाइलर इन्हें थोपता नहीं है।

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
