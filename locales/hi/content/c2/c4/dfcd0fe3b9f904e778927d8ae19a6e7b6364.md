# परिचय

Kotlin में [`string`][ref-string] यूनिकोड अक्षरों का एक अपरिवर्तनीय क्रम है।

[`Immutable`][wiki-immutable] का मतलब है कि स्ट्रिंग पर किया गया कोई भी ऑपरेशन एक नई स्ट्रिंग लौटाता है: मूल स्ट्रिंग कभी नहीं बदल सकती।

[`Unicode`][wiki-unicode] का मतलब है कि दुनिया की अधिकांश लेखन प्रणालियाँ दर्शाई जा सकती हैं, लेकिन (C जैसी पुरानी भाषाओं के उलट) अक्षरों और बाइटों के बीच 1:1 का संबंध नहीं होता।

स्ट्रिंग आम तौर पर डबल कोट्स `" "` के बीच लिखी जाती है।

कुछ अक्षरों को एस्केप करना पड़ता है: `\'`, `\\`, और इसके अलावा `\t` (टैब) तथा `\n` (नई लाइन) जैसे आम नॉन-प्रिंटिंग अक्षर भी।

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

मल्टी-लाइन स्ट्रिंग तीन डबल कोट्स के बीच लिखी जाती है, और उसमें मनचाहा टेक्स्ट हो सकता है (एस्केप करने की ज़रूरत नहीं)।

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

लाइनों का साझा इंडेंटेशन हटाने के लिए [trimIndent][trimIndent-doc] का इस्तेमाल कीजिए। यह स्ट्रिंग को फॉर्मेट करने में काम आता है:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

दूसरा तरीका यह है कि [trimMargin][trimMargin-doc] से आप एक डेलिमिटर तय कर सकते हैं। तब `String` की हर लाइन उस डेलिमिटर के बाद से शुरू होती है। डेलिमिटर का डिफॉल्ट `|` है, लेकिन आप पैरामीटर के तौर पर कोई दूसरा डेलिमिटर दे सकते हैं। उदाहरण के लिए:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

स्ट्रिंग को `+` से जोड़ा जा सकता है, लेकिन इसे छोटे और आसान मामलों तक ही सीमित रखना बेहतर है। इसके और भी तरीके हैं, जो अक्सर ज़्यादा बेहतर होते हैं।

## स्ट्रिंग टेम्पलेट

इससे वही मतलब है जिसे कुछ दूसरी भाषाएँ "इंटरपोलेशन" कहती हैं।

अगर किसी स्ट्रिंग में डॉलर का चिह्न `$` हो और उसके बाद कोई आइडेंटिफायर हो, या कोई ब्रेस (`{expression}`) किसी एक्सप्रेशन को घेरते हों, तो उनकी जगह क्रमशः उस वैल्यू या उस एक्सप्रेशन के परिणाम को रख दिया जाता है।

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

जहाँ पार्सिंग अस्पष्ट हो सकती है, वहाँ एक्सप्रेशन के चारों ओर ब्रेस `{ }` लगाना ज़रूरी होता है।

आम तौर पर, स्ट्रिंग जोड़ने के लिए `+` से ज़्यादा कुशल और स्वाभाविक तरीका स्ट्रिंग टेम्पलेट का इस्तेमाल करना है।

## स्ट्रिंग फंक्शन

Kotlin स्ट्रिंग पर काम करने के लिए _बहुत सारे_ [`functions`][ref-string-functions] देता है।

आम तौर पर ये `String` क्लास के मेंबर नहीं, बल्कि [`extensions functions`][ref-extensions] होते हैं, हालाँकि इसका असर इस पर बहुत कम पड़ता है कि हम इन्हें कैसे इस्तेमाल करते हैं।

~~~~exercism/note
Kotlin के काफी जटिल [डॉक्युमेंटेशन][ref-string-functions] पेज डिफॉल्ट व्यू में एक्सटेंशन फंक्शन छिपा देते हैं।
इस सेक्शन को खोलने के लिए `Members & Extensions` पर ज़रूर क्लिक कीजिए।

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

नीचे दिए उदाहरण उपलब्ध चीज़ों में से बस एक छोटा-सा चयन दिखाते हैं:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
