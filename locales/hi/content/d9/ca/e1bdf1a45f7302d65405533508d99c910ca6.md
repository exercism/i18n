# परिचय

एक *जेनेरिक वर्ड* एक ऐसा काम घोषित करता है जिसे, उसके आर्गुमेंट की क्लास के अनुसार, अलग-अलग तरीकों से लागू किया जा सकता है। मेथड `M:` से जोड़े जाते हैं।

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` वर्ड और उसके स्टैक इफेक्ट को घोषित करता है। `M:` किसी खास क्लास पर एक मेथड बनाता है। प्रोग्राम चलते समय Factor सबसे ऊपर वाले आर्गुमेंट की क्लास देखकर तय करता है कि कौन-सा मेथड चलेगा।

आप जेनेरिक से पूछ सकते हैं कि उसके पास किन क्लासों के लिए मेथड हैं। आप बाद में मेथड जोड़ भी सकते हैं और हटा भी सकते हैं। इनहेरिटेंस के लिए कोई खास सिंटैक्स नहीं है: किसी भी tuple क्लास पर अपने आप मेथड बनाए जा सकते हैं।
