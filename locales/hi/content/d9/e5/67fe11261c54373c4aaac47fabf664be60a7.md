# मूल बातें

## सामान्य सिंटैक्स

PHP एक इंटरप्रेटेड भाषा है, यानी यह आपके लिखे कोड को सीधे चलाती है।
PHP कोड फाइलें टेक्स्ट फाइलें होती हैं, जिनमें PHP कोड की शुरुआत दिखाने के लिए एक ओपनिंग टैग `<?php` होता है।
अगर फाइल में सिर्फ PHP कोड है, तो क्लोज़िंग टैग `?>` छोड़ा जा सकता है, जो PHP कोड का अंत दिखाने के लिए इस्तेमाल होता है।
PHP टैग के बारे में और जानने के लिए [PHP टैग डॉक्स][php-tag] देखिए।

```php
<?php

// All PHP code goes here

// No closing tag required at the end
```

पढ़ने में आसानी के लिए सभी कोड उदाहरणों में PHP ओपनिंग टैग `<?php` छोड़ दिया गया है।
लेकिन सभी PHP अभ्यासों में यह पहले से होता है, इसलिए आपको इसे खुद जोड़ने की ज़रूरत नहीं है।

सभी स्टेटमेंट, जैसे असाइनमेंट या फंक्शन कॉल, का अंत `;` से होना ज़रूरी है, जो स्टेटमेंट को अलग करता है।
JavaScript की तरह `;` छोड़ना मान्य नहीं है, और इससे सिंटैक्स एरर मिलती हैं।
PHP डॉक्युमेंटेशन में [स्टेटमेंट अलग करने][php-semicolon] के बारे में और जानिए।

```php
$message = "Success!"; // Statement correctly ends with `;`
$message = "I know JavaScript." // PHP Parse error: syntax error, [...]
```

## वैल्यू और वेरिएबल

PHP एक डायनामिक टाइपिंग वाली प्रोग्रामिंग भाषा है।
वैल्यू के टाइप की जाँच केवल तभी होती है जब प्रोग्राम चल रहा होता है।
असाइनमेंट `=` ऑपरेटर की मदद से किसी भी टाइप की वैल्यू किसी भी वेरिएबल नाम को असाइन की जा सकती है।
वेरिएबल के नाम डॉलर `$` चिह्न से शुरू होने चाहिए।
वेरिएबल के बारे में और गहराई से जानने के लिए [PHP वेरिएबल डॉक्स][php-variables] देखिए।

```php
$count = 1; // Assign an integer value of 1
$count = 2; // Re-assign a new value to the variable

$count = false; // You may assign any value type

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## फंक्शन और मेथड

लिटरल वैल्यू और वेरिएबल में रखी वैल्यू फंक्शन को पास की जा सकती हैं।
फंक्शन के आर्गुमेंट बनाते समय नए वेरिएबल बनाए जाते हैं, जिनमें पास की गई वैल्यू रखी जाती हैं।

```php
// Declare the window_width function
function window_width($width)
{
    echo $width; // Access the value passed into the function as $width
    // ...
}

window_width(100); // Call the function with the literal value 100

$newWidth = 100;
window_width($newWidth); // Call the function with the value stored in $newWidth
```

फंक्शन `return` कीवर्ड का इस्तेमाल करके वैल्यू लौटा सकते हैं।
लौटाई जाने वाली वैल्यू लिटरल हो सकती हैं, वेरिएबल में रखी हो सकती हैं, या किसी स्टेटमेंट का परिणाम हो सकती हैं।

```php
function window_height()
{
    $heightOffset = 10;

    return 100 + $heightOffset;
}
```

क्लास के अंदर के फंक्शन और उनके इंस्टेंस को मेथड कहते हैं।
किसी मेथड को कॉल करने के लिए उसके नाम से पहले इंस्टेंस और `->` लगाया जाता है।
किसी क्लास का इंस्टेंस `new` ऑपरेशन से बनाया जाता है।
मेथड के पास खास वेरिएबल `$this` तक पहुँच होती है, जो मौजूदा इंस्टेंस को दिखाता है।

```php
<?php
// Calculator.php

class Calculator {
    // ...

    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```

हम फंक्शन और क्लास के बारे में आगे के अभ्यासों में और गहराई से जानेंगे।

## सरल डीबगिंग

डीबगिंग के एक सामान्य तरीके के तौर पर, वैल्यू और वेरिएबल की सामग्री प्रिंट करना यह समझने में मदद करता है कि क्या हो रहा है।
PHP इन तरीकों से वैल्यू प्रिंट कर सकता है:

- `echo $variable;` वैल्यू का स्ट्रिंग रूप दिखाने के लिए
- `print $variable;`, जो `echo $variable;` जैसा ही है
- `var_dump($variable);` वैल्यू के बारे में और जानकारी पाने के लिए, जैसे PHP कौन सा टाइप देखता है

`echo` या `print` इस्तेमाल करते समय: खाली स्ट्रिंग, `false` और `null` दिखाई नहीं देंगे।
और क्लास तथा इंस्टेंस इस पर एरर देते हैं।
इन्हें देखने के लिए `var_dump()` इस्तेमाल कीजिए।

ऑनलाइन एडिटर में आपका बनाया गया आउटपुट टेस्ट नतीजों के साथ दिखाया जाता है।
जब आप CLI इस्तेमाल करते हैं, तो आउटपुट टेस्ट सारांश से पहले प्रोग्रेस इंडिकेटर के साथ मिला हुआ दिखता है।

## कोड का संगठन

PHP और कई दूसरी भाषाओं में फाइलें कोड के संगठन की बुनियादी इकाइयाँ हैं।
किसी कोड ब्लॉक में यह दिखाने के लिए कि किस फाइल को देखना है, हम एक कमेंट इस्तेमाल करते हैं।
आपको अपनी फाइलों में ऐसे कमेंट कभी जोड़ने की ज़रूरत नहीं है:

```php
<?php
// NameOfPhpFile.php

[...]
```

कोड, फंक्शन और क्लास सब एक ही फाइल में हो सकते हैं।
लेकिन आम तौर पर इस तरह की कोड इकाइयाँ अलग-अलग फाइलों में होती हैं।

आम तौर पर हर फाइल में एक ही क्लास रखी जाती है, और फाइल का नाम क्लास से मेल खाता है।

```php
<?php
// Calculator.php

class Calculator {
    // ...

    function add($x, $y)
    {
        return $x + $y;
    }
}
```

फंक्शन आम तौर पर उनके साझा विषय को बताने वाली फाइलों में एक साथ रखे जाते हैं।

```php
<?php
// window_handling.php

function window_paint()
{
    // ...
}

function window_size($width, $height)
{
    // ...
}

function window_move($x, $y)
{
    // ...
}
```

और अक्सर ऐसी फाइलें होती हैं जिनमें सीधे चलाए जाने वाले स्टेटमेंट होते हैं, जैसे `index.php`, जो आम तौर पर वेब एप्लिकेशन के एंट्रीपॉइंट के तौर पर इस्तेमाल होती है।

```php
<?php
// index.php

$sum = add(1, 2);
// ...
```

## नामकरण की परंपराएँ

क्लास के नाम सब `PascalCase` में होने चाहिए।
स्टाइल स्टैंडर्ड के हिसाब से वेरिएबल, फंक्शन और मेथड के नाम `camelCase` या `snake_case` में हो सकते हैं।
नामों में अक्षर `a-zA-Z`, संख्याएँ `0-9` और अंडरस्कोर `_` हो सकते हैं, लेकिन वे किसी संख्या से शुरू नहीं हो सकते।

## कमेंट

सिंगल-लाइन कमेंट `//` से शुरू होते हैं, और टेक्स्ट के एक ब्लॉक को `/*` और `*/` से घेरकर मल्टी-लाइन कमेंट बनाया जा सकता है।

```php
// Single-line comment

/*
  Multi-line comment
*/
```
