# परिचय

वेक्टर एक 1-आयामी ऐरे होता है।
इनमें अलग-अलग टाइप के एलिमेंट हो सकते हैं।

## वेक्टर बनाना

वेक्टर `vector` फंक्शन से या उसके रीडर फॉर्म `#()` का उपयोग करके बनाए जा सकते हैं।

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

चूँकि ये ऐरे हैं, इसलिए इन्हें `make-array` से भी बनाया जा सकता है:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## वेक्टर प्रेडिकेट

यह जाँचने के लिए कि कोई ऑब्जेक्ट वेक्टर है या नहीं, बस `vectorp` प्रेडिकेट का उपयोग कीजिए।

## एलिमेंट तक पहुँचना

किसी वेक्टर के एलिमेंट तक पहुँचने के लिए `aref` का उपयोग कीजिए। इंडेक्स 0 से शुरू होते हैं:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
