# इंस्टॉलेशन

अभ्यास करने के लिए आपको [Vim](http://www.vim.org) चाहिए:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [सोर्स](#source)

## macOS

macOS में Vim पहले से मौजूद होता है, लेकिन उसका वर्ज़न बहुत पुराना होता है।

सॉफ्टवेयर इंस्टॉल करने के लिए आप शायद [MacPorts](https://www.macports.org) या
[Homebrew](https://brew.sh) इस्तेमाल करते हैं।

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

अगर आपको GUI चाहिए, तो इसके बजाय [MacVim](https://macvim-dev.github.io/macvim) देखिए।

## Ubuntu / Debian

GUI सपोर्ट वाला पूरा Vim (`gvim`) इंस्टॉल कीजिए:

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

[Chocolatey](https://chocolatey.org) का इस्तेमाल करके:

```
C:\> choco install vim
```

या सीधे [यहाँ](http://www.vim.org/download.php#pc) से डाउनलोड करके इंस्टॉल कीजिए।
