# परिचय

## इंक्लूड

C++ दूसरी फाइलों की सामग्री शामिल करने के लिए `include` डायरेक्टिव का उपयोग करता है।
ये `include` डायरेक्टिव फाइल के सबसे ऊपर लिखे जाने चाहिए।
कंपाइलेशन के दौरान, डायरेक्टिव वाली लाइन को संबंधित फाइल की सामग्री से बदल दिया जाता है।
इंक्लूड के बाद नेमस्पेस वैसे ही रखे जाते हैं जैसे मूल फाइल में थे।

## मानक लाइब्रेरी

मानक लाइब्रेरी कई सामान्य फंक्शन, एल्गोरिदम और डेटा स्ट्रक्चर प्रदान करती है।
मानक लाइब्रेरी `std` नेमस्पेस का उपयोग करती है।

एक उदाहरण C की न्यूमेरिक्स लाइब्रेरी `cmath` है।
यह कई सामान्य गणितीय ऑपरेशन प्रदान करती है।

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
मानक लाइब्रेरी को डबल कोट्स `"` के बजाय एंगल ब्रैकेट `<>` के साथ शामिल किया जाता है।
अंतर यह है कि कंपाइलर संबंधित फाइलों को कहाँ ढूँढता है।
एंगल ब्रैकेट वाले रूप में मौजूदा प्रोजेक्ट में खोज छोड़ दी जाती है, और कंपाइलर सीधे सिस्टम की इंक्लूड डायरेक्टरियों में खोज शुरू करता है।
अगर आप स्थानीय फाइलें शामिल करना चाहते हैं, तो डबल कोट्स का इस्तेमाल कीजिए: `#include "myfile"`
~~~~
