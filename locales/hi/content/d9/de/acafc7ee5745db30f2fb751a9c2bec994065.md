# परिचय

## कॉन्स्टेंट

Gleam में कॉन्स्टेंट की मदद से वैल्यू को नाम दिया जाता है। इन्हें `const` कीवर्ड से बनाया जाता है।

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

जब किसी मॉड्यूल कॉन्स्टेंट को `pub` कीवर्ड के साथ बनाया जाता है, तो उसे दूसरे मॉड्यूल से भी इस्तेमाल किया जा सकता है। ऐसा न होने पर उसका इस्तेमाल सिर्फ उसी मॉड्यूल के अंदर किया जा सकता है जिसमें उसे बनाया गया है।

## ऑर्डर

Gleam की स्टैंडर्ड लाइब्रेरी के `gleam/order` मॉड्यूल में `Order` टाइप होता है। इसका इस्तेमाल वैल्यू की तुलना करने के लिए किया जाता है।

`Order` की परिभाषा कुछ इस तरह दिखती है:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

इस टाइप के तीन वैरिएंट होते हैं, और हर वैरिएंट एक वैल्यू का दूसरी वैल्यू से संबंध बताता है:

- `Gt` - वैल्यू दूसरी वैल्यू से _बड़ी_ है।
- `Eq` - वैल्यू दूसरी वैल्यू के _बराबर_ है।
- `Lt` - वैल्यू दूसरी वैल्यू से _छोटी_ है।

अगर किसी डेटा टाइप की तुलना उसके आकार के आधार पर की जा सकती है, तो मॉड्यूल में आम तौर पर एक `compare` फंक्शन बनाया जाता है, जो `Order` वैल्यू लौटाता है। उदाहरण के लिए, `gleam/float` और `gleam/int` में ऐसे `compare` फंक्शन बनाए गए हैं जो क्रमशः दशमलव संख्याओं और पूर्णांकों पर काम करते हैं।

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

क्रम में लगाने वाले फंक्शन, जैसे `list.sort`, आम तौर पर ऐसा फंक्शन लेते हैं जो `Order` वैल्यू लौटाता है। इससे फंक्शन को कॉल करने वाला तय कर सकता है कि ऐरे को किस क्रम में लगाना है।

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
