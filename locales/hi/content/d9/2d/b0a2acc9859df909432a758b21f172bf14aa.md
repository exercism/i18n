# परिचय

PHP में किसी वेरिएबल को फंक्शन की तरह कॉल करने के लिए उस पर ब्रैकेट [`()`] लगाए जाते हैं। जब PHP उस फंक्शन को कॉल करने की कोशिश करता है, तो वह उस वेरिएबल की वैल्यू के समान नाम वाला फंक्शन ढूँढता है।

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
