# परिचय

## बुनियादी बातें

C# एक स्टैटिक टाइप वाली भाषा है। इसका मतलब है कि कंपाइल के समय हर चीज़ का एक टाइप होता है। किसी नाम को वैल्यू असाइन करने को वेरिएबल बनाना कहते हैं। वेरिएबल बनाने के दो तरीके हैं: या तो आप उसका टाइप साफ-साफ बताएँ, या C# कंपाइलर को असाइन की गई वैल्यू के आधार पर खुद उसका टाइप अनुमान लगाने दें (इसे _टाइप इन्फरेंस_ कहते हैं)। इसलिए नीचे दी गई दोनों वेरिएबल परिभाषाएँ एक ही हैं:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

वेरिएबल की वैल्यू बदलने के लिए `=` ऑपरेटर इस्तेमाल किया जाता है। एक बार बन जाने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# एक [ऑब्जेक्ट-ओरिएंटेड भाषा][object-oriented-programming] है और इसमें हर फंक्शन को एक _क्लास_ के अंदर बनाना ज़रूरी होता है। क्लास बनाने के लिए `class` कीवर्ड का इस्तेमाल किया जाता है। ऑब्जेक्ट (या _इंस्टेंस_) `new` कीवर्ड से बनाए जाते हैं।

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

क्लास के अंदर लिखे फंक्शन को _मेथड_ कहते हैं। हर मेथड में शून्य या उससे अधिक पैरामीटर हो सकते हैं। सभी पैरामीटर का टाइप साफ-साफ बताना ज़रूरी है, पैरामीटर के लिए टाइप इन्फरेंस नहीं होता। इसी तरह रिटर्न टाइप भी साफ-साफ बताना पड़ता है। मेथड `return` कीवर्ड की मदद से वैल्यू लौटाते हैं। अगर आप चाहते हैं कि दूसरी फाइलों का कोड भी मेथड को कॉल कर सके, तो `public` एक्सेस मॉडिफायर जोड़ना पड़ता है।

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

मेथड को किसी इंस्टेंस पर डॉट (`.`) सिंटैक्स से कॉल किया जाता है: कॉल करने के लिए मेथड का नाम लिखा जाता है और मेथड के हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं। आर्गुमेंट में आप चाहें तो उससे जुड़े पैरामीटर का नाम भी बता सकते हैं।

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C# में स्कोप `{` और `}` के बीच तय होता है।

C# में दो तरह के कमेंट लिखे जा सकते हैं। एक लाइन के कमेंट से पहले `//` लगाया जाता है, और कई लाइनों वाले कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
