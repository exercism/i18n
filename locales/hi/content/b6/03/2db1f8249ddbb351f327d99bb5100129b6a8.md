# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग | टाइप | विवरण |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | एड्रेस | नल-टर्मिनेटेड अंकों की स्ट्रिंग |
| `$a1`    | इनपुट        | पूर्णांक | स्पैन                          |
| `$v0`    | आउटपुट       | पूर्णांक | श्रृंखला का सबसे बड़ा गुणनफल |
| `$t0-9`  | अस्थायी    | कोई भी     | अस्थायी भंडारण के लिए         |
