# Haskell सिंटैक्स की मूल बातें

## कॉन्स्टेंट और फंक्शन

Haskell के प्रोग्राम परिभाषाओं और एक्सप्रेशन से मिलकर बने होते हैं।

एक कॉन्स्टेंट वैल्यू `name = expression` लिखकर बनाई जाती है।

```haskell
five = 5

six = 3 + 3
```

फंक्शन `name parameters... = expression` लिखकर बनाए जाते हैं, जिनमें पैरामीटर को सिर्फ स्पेस से अलग किया जाता है।

```haskell
add number1 number2 = number1 + number2
```

किसी फंक्शन को कॉल करना भी एक एक्सप्रेशन होता है। इसमें फंक्शन का नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट दिए जाते हैं। आर्गुमेंट को स्पेस से अलग किया जाता है, ठीक वैसे ही जैसे फंक्शन बनाते समय किया जाता है।

```haskell
five = add 2 3
```

किसी एक्सप्रेशन का मूल्यांकन किस क्रम में होगा, यह तय करने के लिए ब्रैकेट का इस्तेमाल किया जा सकता है।

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## इंडेंटेशन / अर्थपूर्ण व्हाइटस्पेस

Haskell कोड की सीमाएँ तय करने के लिए व्हाइटस्पेस और इंडेंटेशन का उपयोग करता है।
***किसी एक्सप्रेशन का हिस्सा बनने वाला कोड उस एक्सप्रेशन की शुरुआत से ज़्यादा अंदर की ओर इंडेंट किया जाना चाहिए।***

- मॉड्यूल, इम्पोर्ट और सबसे ऊपरी स्तर की फंक्शन परिभाषाएँ सबसे बाईं ओर के कॉलम से शुरू होनी चाहिए।
- अगर कोई एक्सप्रेशन कई लाइनों में बाँटा गया है, तो उस एक्सप्रेशन का हिस्सा बनने वाला कोड उसके नीचे कम से कम एक स्पेस से इंडेंट होना चाहिए।
- एक्सप्रेशन के जो हिस्से एक साथ समूह में रखे गए हैं, उन्हें बराबर संख्या में स्पेस से इंडेंट किया जाना चाहिए।

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## मॉड्यूल

मॉड्यूल फंक्शन एक्सपोर्ट करते हैं।
इसका मतलब है कि मॉड्यूल जो फंक्शन अपने एक्सपोर्ट स्टेटमेंट में उपलब्ध कराता है, आप उन्हें इस्तेमाल कर सकते हैं।
कोई मॉड्यूल सिर्फ अंदरूनी इस्तेमाल के लिए फंक्शन भी बना सकता है।
डिफॉल्ट रूप से, ऐसे फंक्शन जो स्पष्ट रूप से एक्सपोर्ट नहीं किए गए हैं, उन्हें मॉड्यूल के बाहर से इस्तेमाल नहीं किया जा सकता।

मॉड्यूल की शुरुआत में हम मॉड्यूल का नाम तय करते हैं।
अगर हमारे पास Calculator.hs नाम की फाइल है, तो हमें अपने मॉड्यूल का नाम Calculator रखना चाहिए।
इसके बाद हम वे फंक्शन तय करते हैं जो यह एक्सपोर्ट करता है, और उसके बाद हम फंक्शन लिखना शुरू कर सकते हैं।
तो चलिए इसी से शुरू करते हैं।

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## कमेंट

Haskell फाइल के अंदर लिखा कमेंट वह टेक्स्ट होता है जिसे कोड के रूप में नहीं समझा जाता।
यह मुख्य रूप से आपके और दूसरे प्रोग्रामरों के पढ़ने के लिए होता है।
सिंगल लाइन कमेंट के लिए एक सरल सिंटैक्स है, जो दो डैश पर आधारित है।
मल्टीलाइन कमेंट भी लिखे जा सकते हैं, जिनमें `{-` और `-}` शुरू और बंद करने वाले डेलिमिटर की जोड़ी बनाते हैं।

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
