# परिचय

## डिक्शनरी

डिक्शनरी एलिमेंट का एक संग्रह है। इसमें हर एलिमेंट एक की और एक वैल्यू से मिलकर बनता है। अगर डिक्शनरी के किसी मेथड को कोई की दी जाए, तो वह उससे जुड़ी वैल्यू लौटा देता है। दूसरी भाषाओं में मैप या असोसिएटिव ऐरे जो भूमिका निभाते हैं, वही भूमिका इसकी भी होती है।

डिक्शनरी इस तरह बनाई जा सकती है:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

या

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

ध्यान दीजिए कि की और वैल्यू के टाइप डिक्शनरी की परिभाषा का ही हिस्सा होते हैं।

डिक्शनरी बन जाने के बाद उसमें एंट्री जोड़ी या हटाई जा सकती हैं। इसके लिए उसके अंदर बने मेथड `Add` और `Remove` काम आते हैं।

डिक्शनरी की वैल्यू निकालने या बदलने का काम की के ज़रिए डिक्शनरी में इंडेक्स करके किया जाता है:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

कोई वैल्यू डिक्शनरी में मौजूद है या नहीं, यह आप इस तरह जाँच सकते हैं:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

डिक्शनरी पर एन्यूमरेट करने पर उसके की-वैल्यू जोड़ों पर एन्यूमरेट होता है। डिक्शनरी में ऐसी प्रॉपर्टी भी होती हैं जिनसे उसकी की या वैल्यू पर एन्यूमरेट किया जा सकता है।
