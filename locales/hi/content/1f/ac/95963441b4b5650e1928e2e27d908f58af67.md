# प्रतिशत या "पुरानी शैली" फॉर्मेटिंग

यह हल स्ट्रिंग के लिए `%%-formatting` या [पुरानी शैली की फॉर्मेटिंग][old-style formatting] का इस्तेमाल करता है।

`%%-formatting` पूरी तरह से मान्य तरीका है, लेकिन यह रिप्रेजेंटेशन या पठनीयता से जुड़ी समस्याएँ पैदा कर सकता है।
[str.format()][str.format()] या [f-strings][f-strings] (_जिन्हें "फॉर्मेटेड स्ट्रिंग लिटरल" या "इंटरपोलेटेड स्ट्रिंग" भी कहते हैं_) जैसे तरीके इस्तेमाल करने पर ऐसे विकल्प मिल सकते हैं जो पठनीयता बढ़ाते हैं और स्ट्रिंग के अंदर वेरिएबल बदलने की प्रक्रिया को और साफ़ बनाते हैं।

[String Formatting in Python][string formatting in python] ब्लॉग पोस्ट Python में स्ट्रिंग फॉर्मेट करने के सभी विकल्पों को समझने की अच्छी शुरुआत है। इसके अलावा [Newer Python String Format Techniques][newer python string format techniques] में भी `str.format()` और `f-strings` इस्तेमाल करने के कुछ अच्छे सुझाव और तरकीबें दी गई हैं।
