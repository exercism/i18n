# संसाधन

## अपना पहला Coffee मॉड्यूल बनाइए

`Bob = require './bob'` से लोड हो सकने वाला मॉड्यूल बनाने के लिए यह कोड `bob.coffee` में रखिए:

```coffeescript
class Bob

module.exports = Bob
```

मॉड्यूल के बारे में अधिक जानकारी आपको [Node के दस्तावेज़](http://nodejs.org/api/modules.html#modules_module_exports) में मिल सकती है।

## Windows पर Visual Studio

अगर आपके पास Visual Studio का खरीदा हुआ वर्शन है, तो आप एक ऐसा Visual Studio सॉल्यूशन डाउनलोड कर सकते हैं जो CoffeeScript के साथ और Visual Studio जिन दूसरी भाषाओं को सपोर्ट करता है, उनके साथ काम करने के लिए पहले से तैयार है।

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. पेज पर Download Zip बटन पर क्लिक करके GitHub से [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) डाउनलोड कीजिए।
2. टेम्पलेट को अपनी अभ्यास डायरेक्टरी में अनज़िप कीजिए, जैसे `C:\src\exercises`
2. [Exercism CLI](http://exercism.io/cli) इंस्टॉल कीजिए
3. अपनी अभ्यास डायरेक्टरी में एक कमांड प्रॉम्प्ट खोलिए
4. exercism में अपनी API कुंजी जोड़िए `exercism configure --key=YOUR_API_KEY`
5. exercism में अपनी सोर्स डायरेक्टरी कॉन्फ़िगर कीजिए `exercism configure --dir=C:\src\exercises`
6. [अपना पहला अभ्यास फेच कीजिए](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Visual Studio में Exercism सॉल्यूशन खोलिए
8. Exercism.coffeescript प्रोजेक्ट को एक्सपैंड कीजिए
9. Solution Explorer में **Show All Files** पर क्लिक कीजिए (नीचे देखिए)
10. जो अभ्यास आपने अभी फेच किया है वह ग्रे दिखेगा। फोल्डर पर राइट क्लिक कीजिए और **Include In Project** चुनिए
11. अब कोडिंग शुरू कीजिए...

![फाइलें जोड़ें](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Visual Studio में CoffeeScript के साथ काम करने के लिए आपको [Web Essentials](http://vswebessentials.com/) एक्सटेंशन इंस्टॉल करना चाहिए। इससे JavaScript के साथ काम करना भी काफी आसान हो जाएगा।

आप प्रोजेक्ट में मौजूद बैच फाइल की मदद से node.js कमांड लाइन से यूनिट टेस्ट चला सकते हैं।

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

अगर टेस्ट चलाने पर आपको कोई आउटपुट नहीं दिखता, तो संभव है कि आप Node.js कमांड प्रॉम्प्ट में न हों।
