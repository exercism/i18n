# निर्देश

इंटरनेट पर कोड लिखने में API को कॉल करना एक ज़रूरी हिस्सा है। इस अभ्यास में आपको एक एंडपॉइंट से डेटा लाना होगा और यह पक्का करना होगा कि वह डेटा ठीक से मिल गया।

## उद्देश्य

- दिए गए कोड को बदलिए।
- HTTP क्लाइंट को कॉल कीजिए और एक उद्धरण लाने की कोशिश कीजिए। इसका परिणाम एक यूनियन टाइप होना चाहिए जिसमें `string` और `error` शामिल हों।
- अगर उद्धरण मिल जाए, तो उसे कंसोल पर छापिए (`io:println()` का इस्तेमाल कीजिए)।
- अगर कोई `error` हो गई हो, तो एरर का संदेश कंसोल पर छापिए।
