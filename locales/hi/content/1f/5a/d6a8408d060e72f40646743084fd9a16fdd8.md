# Null

null एक प्रिमिटिव वैल्यू टाइप है, जिसमें केवल एक ही वैल्यू होती है: `null`।
null का उपयोग अक्सर किसी चीज़ के न होने को दर्शाने के लिए किया जाता है।
इसे "फॉल्सी" माना जाता है, पर यह `false` और बाकी फॉल्सी वैल्यू से अलग है।

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## null वैल्यू के साथ काम करना

PHP में null वैल्यू अक्सर एरर की आम वजह हो सकती हैं, क्योंकि अक्सर एरर की स्थिति की जगह या कुछ न होने को दर्शाने के लिए इन्हें ही लौटाया जाता है।
एरर पैदा होने से रोकने के लिए अक्सर यह जाँचना पड़ता है कि कोई वैल्यू null नहीं है। ऐसी जाँच के बाद ही उस वैल्यू पर काम किया जाता है।

बार-बार यह जाँच करना गलती की गुंजाइश बढ़ा देता है, इसलिए PHP null वैल्यू के साथ काम करने के लिए दो ऑपरेटर देता है: null-safe एक्सेस वाला `?->` ऑपरेटर, और null कोलेसिंग वाला `??` ऑपरेटर।
