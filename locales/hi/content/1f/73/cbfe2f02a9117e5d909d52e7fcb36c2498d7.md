# परिचय

`while` और `until` ([`kernel`][kernel] में मौजूद) कोटेशन-आधारित लूप कॉम्बिनेटर हैं, जो उस स्थिति के लिए हैं जब आपको पहले से पता न हो कि लूप कितनी बार चलेगा:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` तब तक चलता रहता है जब तक `pred` एक सही मान छोड़ता है; `until` तब तक चलता रहता है जब तक `pred` `f` छोड़ता है। दोनों तब रुकते हैं और लौटते हैं जब उनका प्रेडिकेट पलट जाता है।

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

जब स्टैक पर बहती हुई एक अकेली वैल्यू से पर्याप्त स्थिति न बने (एक साथ बचा हुआ ऐरे, चलता हुआ जोड़ और एक काउंटर, ऐसी स्थिति में), तो सबसे साफ तरीका यह है कि स्पष्टता के लिए नामित *लोकल* इस्तेमाल किए जाएँ। लोकल को पाठ्यक्रम में आगे और विस्तार से बताया गया है; यहाँ इतना जानना काफी है कि `:: word ( a b -- c )` इनपुट को नामित लोकल के रूप में घोषित करता है, और `:> name!` एक बदलने योग्य लोकल जोड़ता है जिसे बॉडी `value name!` से अपडेट कर सकती है।

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
