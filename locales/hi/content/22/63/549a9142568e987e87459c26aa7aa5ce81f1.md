# परिचय

Clojure में `vector` शून्य या अधिक वैल्यू का एक क्रमबद्ध, इंडेक्स वाला और अपरिवर्तनीय संग्रह होता है। इसका मतलब है कि एक बार वेक्टर बन जाने के बाद उसे बदला नहीं जा सकता। वेक्टर पर काम करने वाले फंक्शन एक नया वेक्टर लौटाते हैं, जबकि मूल वेक्टर वैसा ही रहता है। एक वेक्टर में अलग-अलग टाइप की वैल्यू हो सकती हैं। वेक्टर को इस तरह बनाया जा सकता है:

```clojure
(def empty [])
(def single-value [5])
```

वेक्टर से एलिमेंट इंडेक्स की मदद से निकाले जा सकते हैं। Clojure के वेक्टर में इंडेक्स शून्य से शुरू होता है, यानी पहले एलिमेंट का इंडेक्स हमेशा शून्य होता है:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

मूल वेक्टर वैसा ही रहता है:

```clojure
numbers
;;=> [2 3 5]
```

अपडेट की गई वैल्यू याद रखने के लिए हमें उसे आगे भेजना होता है या किसी वार में सहेजना होता है:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
