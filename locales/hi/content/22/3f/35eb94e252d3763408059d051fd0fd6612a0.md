# विवरण

C++ में अंतर्निहित संख्या टाइप को पूर्णांक और दशमलव संख्याओं में बाँटा जा सकता है।
पूर्णांक वे पूरी संख्याएँ हैं जैसे `0`, `691`, या `-2`।
दशमलव संख्याएँ वे संख्याएँ हैं जिनमें दशमलव बिंदु होता है, जैसे `6.02214076`, `0.1`, या `-1.616`।

## पूर्णांक

नीचे दिया गया उदाहरण दिखाता है कि चार अलग-अलग वेरिएबल कैसे घोषित किए जाते हैं और उन्हें शुरुआती वैल्यू कैसे दी जाती है।

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

जब आप किसी `int` वेरिएबल को कोई वैल्यू असाइन करते हैं, तो आप सीधे एक लिटरल की मदद से ऐसा कर सकते हैं।
लिटरल एक ऐसी संख्या है जो सीधे कोड में लिख दी जाती है, जैसे `9241`।
निरूपण के अलग-अलग आधारों के लिए अलग-अलग पूर्णांक लिटरल होते हैं।
दशमलव पूर्णांक लिटरल सबसे आम हैं और इनमें `0` से `9` तक के अंक इस्तेमाल होते हैं।
`0x` जैसा कोई खास प्रीफिक्स लगाकर दूसरे आधार भी इस्तेमाल किए जा सकते हैं।
ऊपर का उदाहरण संख्या `9421` को उसके चार निरूपणों और प्रीफिक्सों के साथ दिखाता है।
सभी वेरिएबलो को एक ही वैल्यू दी गई है।

अलग-अलग निरूपण प्रणालियों के बारे में अधिक जानकारी के लिए [एक छोटा ट्यूटोरियल][cpp_numerical_bases] देखिए।

पढ़ने में आसानी के लिए आप अंकों को अलग करने के लिए अपोस्ट्रॉफी लगा सकते हैं।
`9'241`, `0b0100'100'0001'1001` या `92'4'1` के बराबर है।

## दशमलव संख्याएँ

दशमलव संख्याओं के लिटरल दो तरह के होते हैं।
सहज लगने वाले `0.0024` के अलावा इसका वैज्ञानिक रूप `2.4e-3` भी इस्तेमाल किया जा सकता है।
सबसे आम दशमलव संख्या टाइप `double` है।

## अंकगणित

C++ में एक्सप्रेशन बनाने के लिए `+`, `-`, `*`, `/`, `(` और `)` तथा `%` का इस्तेमाल किया जा सकता है।
दो पूर्णांकों के बीच की संक्रिया का परिणाम भी एक पूर्णांक होता है।
`5 / 2` का परिणाम `2` होता है।
जब इसमें शामिल कोई एक टाइप दशमलव संख्या का हो, तो परिणाम भी दशमलव संख्या होगा।
`5.0 / 2` और `5 / 2.0` का परिणाम `2.5` होगा।
`%` शेष ऑपरेटर है और पूर्णांक विभाजन का शेष लौटाता है: `5%3` का मान `2` होता है।

## असाइनमेंट ऑपरेटर

असाइनमेंट ऑपरेटर किसी वेरिएबल को कोई लिटरल असाइन करता है।
यह हमेशा दाएँ से बाएँ होता है, कभी उलटा नहीं।

```cpp
int length = 5;
int width = 2;
length = width;
```

यहाँ पूर्णांक वैल्यू `5` को `length` वेरिएबल में असाइन किया गया है।
फिर पूर्णांक वैल्यू `2` को `width` वेरिएबल में असाइन किया गया है।
अंत में `width` की वैल्यू `length` वेरिएबल में कॉपी कर दी जाती है और पहले वाली वैल्यू `5` खो जाती है।
यह भी ध्यान रखिए कि हम असाइनमेंट की क्रिया के समय केवल `width` की वैल्यू `length` को दे रहे हैं।
इसलिए अगर बाद में `width` की वैल्यू बदल जाए, तो इसका `length` की वैल्यू पर कोई असर नहीं पड़ेगा।

असाइनमेंट ऑपरेटर को दूसरे ऑपरेटरों (अंकगणित और बिटवाइज़) के साथ जोड़ा जा सकता है; इन्हें `compound assignment` ऑपरेटर कहते हैं: `+=`, `-=`, `*=`, `/=`, `%=`।
ये ऑपरेटर वेरिएबल की मौजूदा वैल्यू पर कोई संक्रिया करके उसे बदल देते हैं।

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

`people` और `eggs` वेरिएबलो को `0` की शुरुआती वैल्यू दी गई है।
फिर हम `people` वेरिएबल की मौजूदा वैल्यू `0` में पूर्णांक वैल्यू `2` जोड़ते हैं और नतीजे को वापस `people` में असाइन कर देते हैं।
अब `people` की वैल्यू `2` हो जाती है।
इसके बाद हम हर व्यक्ति के लिए `3` अंडे जोड़ते हैं, जो कुल मिलाकर `6` अंडे बनते हैं।
अब इस `6` को `eggs` वेरिएबल की मौजूदा वैल्यू `0` में जोड़िए और नतीजे को वापस `eggs` में असाइन कर दीजिए।
अब `eggs` की वैल्यू `6` हो जाएगी।
इसके बराबर एक्सप्रेशन होंगे `people = people + 2` और `eggs = eggs + (3 * people)`।

## कास्टिंग

कास्टिंग एक टाइप से दूसरे टाइप में बदलने की प्रक्रिया है।
अगर किसी जगह `double` की ज़रूरत हो, तो उसकी जगह `int` इस्तेमाल किया जा सकता है।
ऊपर वाला `5.0 / 2` का उदाहरण `2` को `2.0` में बदलने वाली अंतर्निहित कास्टिंग से काम करता है।
किसी `double` को `int` में बदलने पर जानकारी खो सकती है।
अच्छा तरीका यह है कि किसी दूसरे टाइप T में ऐसी कास्टिंग को `static_cast<T>` के ज़रिए स्पष्ट रूप से लिखा जाए।
`(T)` के ज़रिए पुरानी C-शैली की कास्टिंग को आधुनिक C++ में हतोत्साहित किया जाता है, लेकिन फिर भी इसे जानना चाहिए।

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## सटीकता और निरूपण

C++ में संख्याएँ मनमाने ढंग से बड़ी नहीं हो सकतीं।
उदाहरण के लिए `int` को 32 बिट से दर्शाया जाता है।
यह `2^32` संख्याओं के एक समूह के लिए काफी है, यानी करीब 4 अरब।
`0` को शामिल करने पर सबसे बड़ी और सबसे छोटी `int` संख्याएँ `-2^31` और `2^31 - 1` होती हैं।

दशमलव संख्याएँ आमतौर पर 15 दशमलव स्थानों की सटीकता के साथ लागू की जाती हैं, लेकिन इनका निरूपण होस्ट सिस्टम के हिसाब से बदलता रहता है।
