# विवरण

Gleam में एक ऐरे शून्य या अधिक वैल्यू का अपरिवर्तनीय संग्रह होता है। ऐरे में मौजूद सभी वैल्यू का टाइप एक ही होना चाहिए। चूँकि ऐरे अपरिवर्तनीय होते हैं, एक बार ऐरे बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती। कोई भी फंक्शन या ऑपरेटर जो ऐरे को बदलता हुआ दिखता है (जैसे कोई एलिमेंट जोड़ना), असल में एक नया ऐरे लौटाता है।

ऐरे को इस तरह परिभाषित किया जा सकता है:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

किसी ऐरे में एलिमेंट जोड़ने का सबसे आम तरीका है उसे स्प्रेड सिंटैक्स से आगे जोड़ना:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam की स्टैंडर्ड लाइब्रेरी में मौजूद [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) मॉड्यूल में ऐरे के साथ काम करने के लिए कई उपयोगी फंक्शन हैं। इस मॉड्यूल का इस्तेमाल Gleam कोड में बहुत आम है, इसलिए इससे परिचित होना अच्छा है।

केस एक्सप्रेशन में ऐरे पैटर्न का इस्तेमाल ऐरे से मैच करने और उसमें मौजूद वैल्यू को वेरिएबलो में असाइन करने के लिए किया जा सकता है:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

ठीक लंबाई वाले ऐरे से मैच करने के अलावा, स्प्रेड सिंटैक्स का इस्तेमाल कम से कम एक निश्चित लंबाई वाले ऐरे से मैच करने के लिए भी किया जा सकता है:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

स्प्रेड सिंटैक्स का इस्तेमाल ऐरे के बाकी हिस्से को एक वेरिएबल में असाइन करने के लिए भी किया जा सकता है:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

केस एक्सप्रेशन में उस टाइप की हर संभावित वैल्यू के लिए एक पैटर्न होना चाहिए जिससे मैच किया जा रहा है, इसलिए बची हुई वैल्यू को संभालने के लिए अक्सर अंत में एक डिस्कार्ड पैटर्न (`_`) का इस्तेमाल किया जाता है।
