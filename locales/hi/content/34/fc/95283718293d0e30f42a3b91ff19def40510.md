# निर्देश

आप उस स्टॉक प्रबंधन सिस्टम पर काम जारी रख रहे हैं जो आपने पहले बनाया था। `OpenStruct` और ब्लॉक शॉर्टकट के बारे में जानने के बाद आपने कोड को थोड़ा रीफैक्टर करने का फैसला किया है। अब आइटमों को हैश के रूप में संग्रहीत करने के बजाय आप अपने नए सीखे हुए कौशल का इस्तेमाल करेंगे।

## 1. आइटमों को फिर से पाने की सुविधा दीजिए

आप स्टॉक में मौजूद आइटमों की सूची पहले की तरह पाना जारी रखना चाहते हैं, लेकिन इस बार वे ऐसे ऑब्जेक्ट होने चाहिए जिन पर मेथड कॉल किए जा सकें।

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. `item_names` को रीफैक्टर कीजिए

`item_names` को हैश के बजाय अपने सीखे हुए नए ब्लॉक शॉर्टकट का इस्तेमाल करने के लिए रीफैक्टर कीजिए। याद रहे, इस मेथड को यह लौटाना चाहिए:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. `total_stock` को रीफैक्टर कीजिए

`total_stock` को हैश का संदर्भ देने के बजाय OpenStruct के मेथड का इस्तेमाल करने के लिए रीफैक्टर कीजिए। याद रहे, इस मेथड को यह लौटाना चाहिए:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
