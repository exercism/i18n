# निर्देश परिशिष्ट

## कार्यान्वयन नोट्स

ट्री ऑब्जेक्ट में दो एट्रिब्यूट होते हैं:

- `String` लेबल
- `List<Tree>` चाइल्ड

टेस्ट प्रोग्राम, `Tree.of` बिल्डर फंक्शन को बार-बार लागू करके ट्री बनाता है। उदाहरण के लिए, यह स्टेटमेंट

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

निम्नलिखित ट्री बनाता है:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

आप मान सकते हैं कि टेस्ट ट्री में कोई डुप्लिकेट वैल्यू नहीं होगी।

---

इस अभ्यास का सबसे दिलचस्प हिस्सा `FromPov` और `PathTo` मेथड हैं।

`FromPov` मेथड एक स्ट्रिंग आर्गुमेंट `from` लेता है, जो ट्री के किसी नोड को उसकी वैल्यू के ज़रिए बताता है। इसे ऐसा ट्री लौटाना चाहिए जिसके रूट में `from` वैल्यू हो। आप मूल ट्री को बदलकर उसी को लौटा सकते हैं, या नया ट्री बनाकर उसे लौटा सकते हैं। अगर आप नया ट्री लौटाते हैं, तो मूल ट्री को आप जैसे चाहें इस्तेमाल कर सकते हैं या नष्ट कर सकते हैं। बेशक, बेहतर यही होगा कि आप उसे बिना बदले छोड़ दें।

`PathTo` मेथड दो स्ट्रिंग आर्गुमेंट `from` और `to` लेता है, जो ट्री के दो नोडों को उनकी वैल्यू के ज़रिए बताते हैं। इसे ट्री में पहले नोड से दूसरे नोड तक का सबसे छोटा रास्ता लौटाना चाहिए।

## एक्सेप्शन संदेश

कभी-कभी [एक्सेप्शन फेंकना](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) ज़रूरी हो जाता है। ऐसा करते समय आपको हमेशा एक **अर्थपूर्ण एरर संदेश** शामिल करना चाहिए, जो बताए कि इस एरर का स्रोत क्या है। इससे आपका कोड पढ़ने में आसान हो जाता है और डीबग करने में काफी मदद मिलती है।

इस अभ्यास में कुछ खास बातें हैं। अगर `Tree()` क्लास को ऐसा ट्री दिया जाए जिसका ओरिएंटेशन नहीं बदला जा सकता, या `start node` और `end node` के बीच कोई रास्ता न मिल सके, तो आपको [throw कीवर्ड](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) का उपयोग करके कई `UnsupportedOperationException` फेंकने होते हैं। टेस्ट तभी पास होंगे जब आप `throw` भी करें और `exception` के साथ संदेश भी शामिल करें।

किसी संदेश के साथ `UnsupportedOperationException` फेंकने के लिए, उस संदेश को `exception` टाइप के आर्गुमेंट के रूप में लिखिए:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
