# परिचय

Java में बूलियन को `boolean` टाइप से दर्शाया जाता है। इस टाइप की वैल्यू या तो `true` होती है या `false`।

Java में तीन बूलियन ऑपरेटर हैं:  

- `!` (NOT): बूलियन को उलट देता है।
- `&&` (AND): दो बूलियन लेता है और दोनों के सही होने पर परिणाम सही होता है।
- `||` (OR): दोनों में से कोई एक बूलियन सही होने पर परिणाम सही होता है।

## उदाहरण

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
