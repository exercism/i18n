# परिचय

## कंस्ट्रक्टर

किसी _क्लास_ का इंस्टेंस बनाने के लिए उसके _कंस्ट्रक्टर_ को `new` ऑपरेटर से कॉल किया जाता है।
कंस्ट्रक्टर एक खास तरह का मेथड होता है, जिसका उद्देश्य नए बने इंस्टेंस को शुरुआती वैल्यू देकर तैयार करना है।
कंस्ट्रक्टर दिखने में आम मेथड जैसे ही होते हैं, लेकिन इनका कोई रिटर्न टाइप नहीं होता और इनका नाम क्लास के नाम से मेल खाता है।

```java
class Library {
    private int books;

    public Library() {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

आम मेथड की तरह कंस्ट्रक्टर में भी पैरामीटर हो सकते हैं।
कंस्ट्रक्टर के पैरामीटर आम तौर पर (प्राइवेट) फील्ड के रूप में संग्रहीत कर दिए जाते हैं, ताकि बाद में उनका उपयोग किया जा सके, या फिर वे किसी एक बार की गणना में काम आते हैं।
कंस्ट्रक्टर को आर्गुमेंट भी उसी तरह दिए जा सकते हैं, जैसे आम मेथड को आर्गुमेंट दिए जाते हैं।

```java
class Building {
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight) {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```
