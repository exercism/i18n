# Char

`Char` Crystal में एक डेटा टाइप है, जो 32-बिट [Unicode][unicode] कोड पॉइंट को दर्शाता है। इनका आकार इन्हें मेमोरी की दृष्टि से कुशल बनाता है और इनमें ऐसे खास गुण देता है जो String में नहीं होते। इन्हें सिंगल कोट (`'`) से बनाया जाता है, और इनके अंदर सिर्फ एक ही Unicode कोड पॉइंट रखा जा सकता है।

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystal में स्ट्रिंग के साथ काम करते समय Char के साथ काम करना काफी आम है, क्योंकि String क्लास के कई मेथड Char लौटाते हैं या आर्गुमेंट के तौर पर Char लेते हैं। जैसे [`String#[]`][index] मेथड एक Char लौटाता है, और [`String#chars`][chars] मेथड Char का एक कलेक्शन लौटाता है।

## बढ़ाना / घटाना

चूँकि Char एक 32-बिट Unicode कोड पॉइंट है, इसलिए इन्हें बढ़ाया और घटाया जा सकता है। इसका मतलब है कि अगर आपके पास `'a'` है, तो उसमें एक जोड़कर आप `'b'` पा सकते हैं।

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

एक मेथड [`Char#succ`][succ] भी है, जो Unicode टेबल में अगला Char लौटाता है, और [`Char#pred`][pred], जो Unicode टेबल में पिछला Char लौटाता है।

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## जोड़ना

चूँकि Char सिर्फ 32-बिट Unicode को दर्शाने के लिए बने हैं, इसलिए दो Char को आपस में जोड़ा नहीं जा सकता। इसलिए, Char को सिर्फ स्ट्रिंग के साथ ही जोड़ा जा सकता है।

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## गुणों की जानकारी देने वाले मेथड

Crystal में किसी अक्षर के बारे में जानकारी पाने के लिए कुछ मेथड हैं, जैसे कि वह संख्या है या अक्षर, या वह अपरकेस है या लोअरकेस। यहाँ कुछ मेथड की सूची दी गई है। पूरी सूची के लिए [Char API][char-api] देखिए:

| मेथड                           | विवरण                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | अगर Char एक संख्या है तो `true` लौटाता है               |
| [`Char#letter?`][letter]         | अगर Char एक अक्षर है तो `true` लौटाता है               |
| [`Char#lowercase?`][lowercase]   | अगर Char लोअरकेस में है तो `true` लौटाता है              |
| [`Char#uppercase?`][uppercase]   | अगर Char अपरकेस में है तो `true` लौटाता है              |
| [`Char#ascii?`][ascii]           | अगर Char एक ASCII अक्षर है तो `true` लौटाता है     |
| [`Char#whitespace?`][whitespace] | अगर Char एक व्हाइटस्पेस अक्षर है तो `true` लौटाता है |

## कन्वर्ट करना

### कोड पॉइंट और Char के बीच कन्वर्ट करना

चूँकि Char एक 32-बिट Unicode कोड पॉइंट है, इसलिए आप Char और कोड पॉइंट (Int) के बीच कन्वर्ट कर सकते हैं। यह [`Char#ord`][ord] मेथड से किया जा सकता है, जो Char का कोड पॉइंट लौटाता है, या [`Int#chr`][chr] मेथड से, जो कोड पॉइंट का Char लौटाता है।

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### प्रकारों के बीच कन्वर्ट करना

दूसरे डेटा टाइप की तरह, Char में भी प्रकारों के बीच कन्वर्ट करने के लिए कुछ मेथड हैं। सबसे आम है `Char#to_s` मेथड, जो Char को String में बदलता है। इसके अलावा `Char#to_i` मेथड भी है, जो Char को Int में बदलता है, और `Char#to_f` मेथड, जो Char को Float में बदलता है।

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## एस्केप करना

स्ट्रिंग की तरह, कुछ अक्षर ऐसे होते हैं जिन्हें सीधे नहीं लिखा जा सकता, और उन्हें लिखने के लिए आपको उन्हें एस्केप करना पड़ता है। आप `\` अक्षर का इस्तेमाल करके एस्केप सीक्वेंस लिख सकते हैं, जिसके बाद वह अक्षर आता है जिसे आप एस्केप करना चाहते हैं।

Crystal में ये विशेष अक्षर हैं:

| मान    | विवरण                   |
| -------- | ----------------------------- |
| `\a`     | अलर्ट                         |
| `\b`     | बैकस्पेस                     |
| `\e`     | एस्केप                        |
| `\f`     | फॉर्म फीड                     |
| `\n`     | लाइन फीड या न्यूलाइन          |
| `\r`     | कैरिज रिटर्न               |
| `\t`     | आड़ी टैब                |
| `\v`     | खड़ी टैब                  |
| `\\`     | बैकस्लैश                     |
| `\'`     | सिंगल कोट                  |
| `\"`     | डबल कोट                  |
| `\377`   | ऑक्टल ASCII अक्षर         |
| `\xFF`   | हेक्साडेसिमल ASCII अक्षर   |
| `\uFFFF` | हेक्साडेसिमल Unicode अक्षर |
