# परिचय

## R में बूलियन

सही और गलत वैल्यू को `logical` टाइप से दिखाया जाता है।
इसमें सिर्फ दो वैल्यू होती हैं: `TRUE` और `FALSE`।

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## बूलियन ऑपरेटर

R में पाँच बूलियन ऑपरेटर हैं, लेकिन सिलेबस के इस चरण में सिर्फ तीन ही काम के हैं।
बाकी दो वेक्टर के साथ काम करते समय काम आएँगे, जिन पर आगे के कई कॉन्सेप्ट में बात की गई है।

`&&` बूलियन "और" है।
अगर `&&` के *दोनों* ओर के एक्सप्रेशन `TRUE` हों, तो इसका परिणाम `TRUE` होता है।

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` बूलियन "या" है।
अगर `||` के *किसी भी* ओर का एक्सप्रेशन `TRUE` हो, तो इसका परिणाम `TRUE` होता है।

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` बूलियन "नहीं" है।
यह `TRUE` और `FALSE` वैल्यू को आपस में बदल देता है।

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

लंबे और ज़्यादा जटिल एक्सप्रेशन के लिए बेहतर होता है कि आप अपना इरादा साफ़ रखने के लिए गोल ब्रैकेट लगाइए।

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
