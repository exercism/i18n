# विवरण

`if` स्टेटमेंट के अलावा, शर्त के आधार पर लॉजिक चलाने के लिए `switch` स्टेटमेंट भी होता है। इसका उपयोग तब किया जाता है जब एक ही वेरिएबल की तुलना कई वेरिएंट से करनी हो। किसी वेरिएबल x के लिए, Haxe में switch स्टेटमेंट का सिंटैक्स इस प्रकार है।

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

जब कोई अन्य केस मेल नहीं खाता, तब `default` केस चलता है।
