# परिचय

ब्लॉक, स्टेटमेंट और घोषणाओं का ऐसा समूह है जो मिलकर एक सिंटैक्स इकाई बनाता है। ब्लॉक अक्सर घुंघराले ब्रैकेट के अंदर परिभाषित किए जाते हैं, लेकिन हमेशा नहीं। ब्लॉक, फंक्शन के अंदर भी नेस्टेड हो सकते हैं और दूसरे ब्लॉक के अंदर भी।

फंक्शन कुछ हद तक ब्लॉक की तरह काम करता है। किसी फंक्शन के अंदर परिभाषित वेरिएबल का आइडेंटिफायर उस फंक्शन के बाहर दिखाई नहीं देता, ठीक वैसे ही जैसे किसी ब्लॉक के अंदर परिभाषित वेरिएबल का आइडेंटिफायर उस ब्लॉक के बाहर दिखाई नहीं देता। दो फंक्शनो में रखे दो वेरिएबल का नाम एक ही हो सकता है, क्योंकि ये दोनों फंक्शन एक-दूसरे के अंदर नहीं देख सकते। ठीक इसी तरह दो ब्लॉक के वेरिएबल का नाम भी एक ही हो सकता है, क्योंकि दोनों ब्लॉक एक-दूसरे के अंदर नहीं देख सकते। लेकिन फंक्शन और ब्लॉक एक जैसे नहीं होते। एक फंक्शन को दूसरे फंक्शन के अंदर नेस्टेड नहीं किया जा सकता, जबकि एक ब्लॉक को दूसरे ब्लॉक के अंदर नेस्टेड किया जा सकता है।

नीचे दिए गए उदाहरण में `number` को `main` फंक्शन के अंदर परिभाषित किया गया है। `flag` को उस `if` ब्लॉक के अंदर परिभाषित किया गया है, जो `main` फंक्शन के अंदर नेस्टेड है। ब्लॉक के अंदर परिभाषित वेरिएबल केवल उसी ब्लॉक में मान्य होते हैं। इसलिए इस कोड को कंपाइल करने पर एक कंपाइलेशन एरर मिलती है।

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

एरर संदेश भ्रमित करने वाला लग सकता है, क्योंकि फंक्शन में पहले `flag` का उपयोग _होता_ तो है। लेकिन `flag` तो फंक्शन के अंदर मौजूद एक ब्लॉक में परिभाषित है। अंदर वाला ब्लॉक अपने बाहरी फंक्शन के वेरिएबल `number` को "देख" सकता है, लेकिन बाहरी फंक्शन अपने अंदर वाले ब्लॉक में परिभाषित `flag` वेरिएबल को "देख" नहीं सकता। जैसे ही एग्ज़ीक्यूशन ब्लॉक से बाहर निकलता है, `flag` वेरिएबल अपने आप नष्ट हो जाता है और प्रोग्राम के लिए उपलब्ध नहीं रहता। `main` फंक्शन को `flag` आइडेंटिफायर पहली बार अंतिम `printf` स्टेटमेंट में दिखाई देता है। अगर अंतिम `printf` स्टेटमेंट हटा दिया जाए, तो प्रोग्राम कंपाइल हो जाएगा और चलाने पर `1` प्रिंट करेगा। इसका कारण यह है कि `flag` वेरिएबल उस ब्लॉक में मान्य है जिसमें पहला `printf` स्टेटमेंट है।

`C99` से, एक लाइन वाले `if`, `for`, `while` और `do` स्टेटमेंट भी ब्लॉक माने जाते हैं। अगले उदाहरण में, हालाँकि `i` घुंघराले ब्रैकेट के अंदर परिभाषित नहीं है, वह केवल `for` स्टेटमेंट से बने ब्लॉक में ही मौजूद रहता है और बाहरी `main` फंक्शन को दिखाई नहीं देता।

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

अगर अंतिम `printf` स्टेटमेंट हटा दिया जाए, तो प्रोग्राम कंपाइल हो जाएगा और चलाने पर `0 2 4 6 8 10 ` प्रिंट करेगा। कुछ भाषाएँ, जैसे Go और Rust, साफ़ तौर पर कहती हैं कि एक लाइन वाले शर्त वाले और लूप वाले स्टेटमेंट भी एक ब्लॉक बनाते हैं। उनमें यह ज़रूरी होता है कि ऐसे एक लाइन वाले स्टेटमेंट फिर भी घुंघराले ब्रैकेट के अंदर ही लिखे जाएँ।
