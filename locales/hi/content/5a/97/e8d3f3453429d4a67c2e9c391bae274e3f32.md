# SQLite से जुड़े खास निर्देश

* **digits** कॉलम में पूर्णांकों का एक ऐरे होता है, जो JSON में एनकोड किया गया होता है।
  उदाहरण:
  ```json
  [1,0,1,0,1,0]
  ```
* **result** कॉलम में JSON में एनकोड किया गया डेटा होना चाहिए: एक ऑब्जेक्ट जिसमें अंक पूर्णांकों के रूप में हों, या किसी भी एरर का विवरण।
  उदाहरण:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  या
  ```json
  {"error":"some error description"}
  ```

## टेबल स्कीमा

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
