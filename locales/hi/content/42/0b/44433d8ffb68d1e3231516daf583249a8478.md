# परिचय

लिटरल वे निश्चित वैल्यू हैं जिन्हें सीधे कोड में इस्तेमाल किया जाता है।
इन्हें प्रोग्राम चलते समय किसी गणना की ज़रूरत नहीं होती।
डेटा के अलग-अलग प्रकारों को कुशलता से दर्शाने के लिए ये कई रूपों में मिलते हैं।
सबसे ज़्यादा मिलने वाले लिटरल संख्यात्मक होते हैं, लेकिन दिनांक, समय और स्ट्रिंग टाइप के लिए भी लिटरल ऑपरेटर मौजूद हैं।
आगे के किसी कॉन्सेप्ट में बताया जाएगा कि उपयोगकर्ता द्वारा परिभाषित लिटरल ऑपरेटरों का इस्तेमाल कैसे किया जा सकता है।

## संख्यात्मक लिटरल

संख्यात्मक लिटरल में दशमलव, ऑक्टल, हेक्साडेसिमल और बाइनरी रूप शामिल हैं।
ऐसे बुनियादी रूपों की चर्चा [संख्या कॉन्सेप्ट][numbers-concept] में पहले ही हो चुकी है।

`23`, `0x50f7ba11` और `0xba5eba11` जैसे सभी रूपों को कंपाइलर `int` मानता है।
सामान्य `int` टाइप ऋणात्मक और धनात्मक, दोनों तरह की संख्याएँ ले सकता है, और ([कंपाइलर तथा सिस्टम के अनुसार][in-depth-integers]) इसकी रेंज अक्सर `-2'147'483'648` से `2'147'483'647` तक होती है।
ज़्यादातर मौकों पर यह काफी होता है और आपको किसी खास टाइप की चिंता करने की ज़रूरत नहीं होती।

कुछ मामलों में बड़ी रेंज चाहिए होती है, और कुछ में प्रोग्राम को बहुत कम मेमोरी में चलना होता है।
इसे साफ़-साफ़ बताने के लिए संख्यात्मक लिटरल के साथ सीधे कोई खास पूर्णांक टाइप लिखा जा सकता है।

जब ऋणात्मक संख्याएँ नहीं चाहिए, पर रेंज बढ़ानी है, तब _बिना चिह्न वाले_ पूर्णांकों के लिए `u` या `U` प्रत्यय लगाया जाता है।
इससे भी बड़ी रेंज के लिए `L` या `LL` का उपयोग किया जा सकता है, जो long और long long टाइपों के लिए हैं।

~~~~exercism/caution
छोटे अक्षर `l` का उपयोग मान्य है, पर उसे संख्या `1` से आसानी से भ्रम हो जाता है, इसलिए इससे बचने की सलाह दी जाती है।
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

फ्लोटिंग-पॉइंट संख्याएँ कंपाइल करते समय आम तौर पर `double` बन जाती हैं।
यह अच्छा डिफ़ॉल्ट है, और `float` जैसे छोटे टाइप वाले उपयोग ऊपर दिए गए बिना चिह्न वाले उदाहरण की तुलना में कम ही मिलते हैं।

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## अक्षर और स्ट्रिंग लिटरल

अन्य कॉन्सेप्ट में सिंगल कोट वाले अक्षर लिटरल पहले ही इस्तेमाल किए जा चुके हैं, जैसे `'}'` या `'@'`।

C++ में `char` सिर्फ़ पहले 128 [ASCII अक्षर कोडों][ascii-code] तक सीमित है।
कई ASCII अक्षरों या `‰` जैसे विस्तारित ASCII अक्षरों, या यहाँ तक कि `麗` और `ẞ` जैसे यूनिकोड अक्षरों का उपयोग करने के लिए अन्य टाइप चाहिए।
पिछले कॉन्सेप्ट में स्ट्रिंग लिटरल _डबल कोट_ के साथ पेश किए गए थे: `"一体どういう意味ですか。C++です"`.
इस जापानी वाक्य का असली टाइप `const char (&)[46]` है, जो एक C-शैली की स्ट्रिंग है।

स्ट्रिंग लिटरल का उपयोग डिफ़ॉल्ट रूप से चालू नहीं होता।
_स्ट्रिंग_ लिटरल `""s` या _स्ट्रिंग-व्यू_ लिटरल `""sv` का उपयोग करने के लिए उपयोगकर्ता को संबंधित नेमस्पेस का उपयोग करना होता है:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

एक _स्ट्रिंग-व्यू_ को const स्ट्रिंग के रेफ़रेंस की तरह देखा जा सकता है।
