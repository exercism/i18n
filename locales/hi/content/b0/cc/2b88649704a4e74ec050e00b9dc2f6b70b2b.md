# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग      | टाइप  | विवरण                                  |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | इनपुट        | एड्रेस | नल से समाप्त होने वाली प्रश्न स्ट्रिंग        |
| `$v0`    | आउटपुट       | पूर्णांक | परिणाम, प्रश्न मान्य न हो तो 0 |
| `$t0-9`  | अस्थायी    | कोई भी  | अस्थायी भंडारण के लिए                  |
