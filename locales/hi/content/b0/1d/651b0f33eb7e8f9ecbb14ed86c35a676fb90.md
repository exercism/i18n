# टॉप-लेवल कॉन्स्टेंट को प्राथमिकता दीजिए

`GIGASECOND` संख्या को एक कॉन्स्टेंट में निकालने पर विचार कीजिए:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

केवल वे फंक्शन, क्लास और कॉन्स्टेंट जिन्हें `export` किया गया है, बाहर से दिखाई देते हैं और उनका उपयोग किया जा सकता है। आम तौर पर [मैजिक नंबरों](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29) को नाम देना समझदारी होती है, जिससे कोड का रखरखाव बेहतर होता है। ये कॉन्स्टेंट उसी फाइल में रह सकते हैं, बिना दूसरे कोड के सामने आए।
