# परिचय

टेम्पलेट एक स्ट्रिंग या फाइल है। इसका उपयोग इनपुट के अनुसार किसी भी तरह का स्ट्रिंग आउटपुट बनाने के लिए किया जाता है।

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

इसके अलावा, आप टेम्पलेट के अंदर जाँच करने के लिए शर्तों का भी उपयोग कर सकते हैं:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
