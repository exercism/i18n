# Bash माइनस्वीपर अभ्यास के लिए संकेत

इस अभ्यास के लिए दो-आयामी ऐरे की ज़रूरत लगती है।
Bash में सिर्फ एक-आयामी इंडेक्स वाले ऐरे या असोसिएटिव [ऐरे][array] ही उपलब्ध हैं।

असोसिएटिव ऐरे की मदद से बहु-आयामी ऐरे जैसा बनाया जा सकता है: इंडेक्स को कॉमा से अलग की गई स्ट्रिंग में बदलिए और उसी स्ट्रिंग को ऐरे की की बनाइए।

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
