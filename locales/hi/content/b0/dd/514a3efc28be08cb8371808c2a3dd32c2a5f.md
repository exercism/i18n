# निर्देश

इस अभ्यास में आप कुछ कोड लिखेंगे, जो आपको वाहन खरीदने की तैयारी में मदद करेगा।

आपके पास तीन काम हैं: एक, यह तय करना कि आपको लाइसेंस लेना पड़ेगा या नहीं; दूसरा, दो वाहनों में से चुनने में मदद करना; और तीसरा, पुराने वाहन की स्वीकार्य कीमत का अनुमान लगाना।

## 1. तय कीजिए कि आपको ड्राइविंग लाइसेंस की ज़रूरत होगी या नहीं

कुछ तरह के वाहनों को चलाने के लिए ड्राइविंग लाइसेंस ज़रूरी होता है।
मान लीजिए कि केवल `'car'` और `'truck'` प्रकार के वाहनों के लिए लाइसेंस ज़रूरी है; बाकी सब बिना लाइसेंस चलाए जा सकते हैं।

`needsLicense(kind)` फंक्शन बनाइए जो वाहन का प्रकार लेता है और बूलियन लौटाता है, जो बताता है कि उस प्रकार के वाहन के लिए आपको लाइसेंस चाहिए या नहीं।

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. खरीदने के लिए दो संभावित वाहनों में से चुनाव कीजिए

आप उपलब्ध वाहनों में से अपने विकल्पों पर विचार करते हैं।
आप उन्हें दो विकल्पों तक सीमित कर पाते हैं, लेकिन अंतिम फैसला करने के लिए आपको मदद चाहिए।
इसके लिए `chooseVehicle(option1, option2)` फंक्शन बनाइए जो दो वाहनों को आर्गुमेंट के रूप में लेता है और एक ऐसा फैसला लौटाता है जिसमें वह विकल्प शामिल होता है जो शब्दकोश क्रम में पहले आता है।

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. पुराने वाहन की कीमत का अनुमान लगाइए

अब जब आपने अपना फैसला कर लिया है, तो आप यह सुनिश्चित करना चाहते हैं कि डीलरशिप पर आपको उचित कीमत मिले।
चूँकि आपको पुराना वाहन खरीदना है, इसलिए कीमत इस पर निर्भर करती है कि वाहन कितना पुराना है।
मोटे अनुमान के लिए मान लीजिए कि अगर वाहन 3 साल से कम पुराना है, तो उसकी कीमत उस मूल कीमत का 80% होती है जो बिल्कुल नया होने के समय थी।
अगर यह 10 साल से अधिक पुराना है, तो इसकी कीमत 50% होती है।
अगर वाहन कम से कम 3 साल पुराना है, लेकिन 10 साल से अधिक पुराना नहीं है, तो इसकी कीमत मूल कीमत का 70% होती है।

`calculateResellPrice(originalPrice, age)` फंक्शन बनाइए जो `if`, `else if` और `else` का इस्तेमाल करके यह तर्क लागू करता है (अगर आप अभ्यास करना चाहें तो और भी तरीके हैं)।
यह मूल कीमत और वाहन की उम्र को आर्गुमेंट के रूप में लेता है और डीलरशिप पर अनुमानित कीमत लौटाता है।

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
