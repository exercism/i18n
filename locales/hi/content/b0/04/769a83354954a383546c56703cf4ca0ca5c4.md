# निर्देश

इस अभ्यास में आप एक साधारण कैलकुलेटर के लिए एरर हैंडलिंग बनाएँगे।

इसका उद्देश्य यह है कि आप एक ऐसा कैलकुलेटर बनाएँ जो आर्गुमेंट `16`, `51` और `+` मिलने पर इस पैटर्न वाली स्ट्रिंग लौटाए: `16 + 51 = 67`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. `calculate` मेथड के अंदर एरर दे सकने वाला कोड लिखिए

इस टास्क में आपको मुख्य रूप से क्लास मेथड `SimpleCalculator.calculate()` बनाना है।
यह तीन आर्गुमेंट लेता है।
पहले दो आर्गुमेंट वे संख्याएँ हैं जिन पर ऑपरेशन किया जाएगा।
तीसरा आर्गुमेंट स्ट्रिंग टाइप का है, और इस अभ्यास में आपको ये ऑपरेशन लागू करने हैं:

- `+` स्ट्रिंग की मदद से जोड़ना
- `*` स्ट्रिंग की मदद से गुणा करना
- `/` स्ट्रिंग की मदद से भाग देना

## 2. गलत ऑपरेशन संभालिए

`SimpleCalculator.calculate()` मेथड को बदलिए ताकि अज्ञात ऑपरेशन चिह्नों के लिए यह `UnsupportedOperation` एक्सेप्शन दे।

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
इस अभ्यास में आपसे अपेक्षा है कि आप `UnsupportedOperation` एक्सेप्शन को किसी खास स्कोप के अंदर परिभाषित करें।
~~~~

## 3. अमान्य आर्गुमेंट संभालिए

`SimpleCalculator.calculate()` मेथड को बदलिए ताकि अमान्य आर्गुमेंट टाइप के लिए यह `ArgumentError` एक्सेप्शन दे।

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. DivideByZero एक्सेप्शन संभालिए

`SimpleCalculator.calculate()` को बदलिए ताकि यह `ZeroDivisionError` एक्सेप्शन संभाल सके।
संभालने वाले कोड को `Division by zero is not allowed.` वाली स्ट्रिंग लौटानी चाहिए।
इसके अलावा `SimpleCalculator.calculate()` मेथड को कोई और एक्सेप्शन संभालना नहीं चाहिए।

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
