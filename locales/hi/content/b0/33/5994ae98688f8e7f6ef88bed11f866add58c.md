# परिचय

स्ट्रक्चर या क्लास के हर इंस्टेंस में `self` नाम की एक अंतर्निहित प्रॉपर्टी होती है, जो उस इंस्टेंस को ही दर्शाती है।
`self` का सबसे आम उपयोग यह है कि इससे किसी इंस्टेंस प्रॉपर्टी और उसी नाम वाले पैरामीटर के बीच का फर्क साफ हो जाता है:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift के टाइप में `Self` नाम का एक कीवर्ड भी होता है, जिसे बड़े अक्षर से लिखा जाता है और जो इंस्टेंस के बजाय उस इंस्टेंस के *टाइप* को दर्शाता है।
