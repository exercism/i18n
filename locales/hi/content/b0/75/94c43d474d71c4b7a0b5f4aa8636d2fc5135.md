# परिचय

## `while` लूप

किसी `while` लूप की मदद से आप कोड को तब तक बार-बार चला सकते हैं, जब तक कि कोई शर्त पूरी होती रहे। इसे `while` कीवर्ड से लिखा जाता है। कीवर्ड के बाद गोल ब्रैकेट में लिपटी एक शर्त आती है, और फिर घुंघराले ब्रैकेट में लिपटा एक कोड ब्लॉक आता है, जिसमें _लूप के अंदर का कोड_ होता है।

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript में `do-while` लूप भी होता है। इसमें शर्त की जाँच लूप के अंदर का कोड चलने के बाद होती है। यह तब काम आता है जब शर्त लूप के अंदर की गई गणनाओं पर निर्भर होती है।

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

लूप के अंदर के कोड में आप `break` कीवर्ड का इस्तेमाल करके लूप का चलना पूरी तरह रोक सकते हैं। इसके उलट, `continue` कीवर्ड सिर्फ वर्तमान इटरेशन का चलना रोकता है और अगले इटरेशन के साथ आगे बढ़ जाता है। `continue` की मदद से आप अक्सर लूप के अंदर के कोड के बड़े हिस्सों को `if` स्टेटमेंट में लपेटने से बच सकते हैं।

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## `switch` स्टेटमेंट

`if` स्टेटमेंट के अलावा JavaScript में `switch` स्टेटमेंट भी होता है, जिससे शर्त के अनुसार लॉजिक चलाया जा सकता है। इसका इस्तेमाल तब होता है जब एक ही वेरिएबल की तुलना कई अलग-अलग विकल्पों से करनी हो। यह तुलना सख्त समानता (`===`) जाँचकर की जाती है। देखिए [तुलना का कॉन्सेप्ट][concept-comparison]। किसी वेरिएबल `x` के लिए JavaScript में `switch` स्टेटमेंट का सिंटैक्स इस तरह होता है।

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default` केस वैकल्पिक होता है। अगर कोई भी अन्य विकल्प वेरिएबल से मेल नहीं खाता और आप तब कुछ कोड चलाना चाहते हैं, तो इसका इस्तेमाल कीजिए।

ऊपर दिए गए `break` स्टेटमेंट इसलिए ज़रूरी हैं, क्योंकि JavaScript में डिफ़ॉल्ट रूप से सभी केस "फॉलथ्रू" होते हैं। इसका मतलब है कि बिना किसी `break` स्टेटमेंट के, पहले मेल खाने वाले विकल्प के नीचे के सभी केसों का कोड चल जाएगा, भले ही `x` उन विकल्पों से मेल न खाता हो। JavaScript में `switch` इस्तेमाल करते समय "डिफ़ॉल्ट रूप से फॉलथ्रू" वाला यह व्यवहार एक आम गलती है। फंक्शन के अंदर इस समस्या से बचने के लिए `break` की जगह `return` का भी इस्तेमाल किया जा सकता है।
