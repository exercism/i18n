# फॉर-ईच लूप का परिचय

[फॉर-ईच लूप](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) किसी कलेक्शन के हर एलिमेंट के लिए कोड का एक ब्लॉक चलाने का तरीका देता है। कुछ दस्तावेज़ (जैसे Oracle के दस्तावेज़) इन्हें एन्हांस्ड फॉर लूप कहते हैं।

इसका सामान्य सिंटैक्स इस प्रकार है:

```java
for(declaration: collection) {
    body;
}
```

`declaration` उस वेरिएबल को घोषित करता है जो कलेक्शन से असाइन की गई वैल्यू रखता है।

`collection` एक ऐरे या कलेक्शन है जिसमें वे वैल्यू रखी जाती हैं जो लूप वेरिएबल को असाइन की जाएँगी।

`body` में वे स्टेटमेंट होते हैं जो कलेक्शन की हर वैल्यू के लिए एक बार चलाए जाएँगे।

उदाहरण के लिए:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

जो आउटपुट देता है:

```text
a
e
i
o
u
```

आम तौर पर एक `for-each` लूप, `for` लूप की तुलना में, निम्नलिखित कारणों से बेहतर होता है:

- एक `for-each` लूप _सभी_ वैल्यू पर इटरेशन करता है, यह गारंटीड है।
- एक `for-each` लूप अधिक _डिक्लेरेटिव_ होता है, यानी कोड यह बताता है कि वह _क्या_ कर रहा है, न कि वह _कैसे_ कर रहा है।
- एक `for-each` लूप फूलप्रूफ होता है, जबकि `for` लूप में ऑफ-बाय-वन एरर होना आसान है (जैसे `<` बनाम `<=` का उपयोग करने के बारे में सोचिए)।
- एक `for-each` लूप सभी प्रकार के कलेक्शन पर काम करता है, उन सहित जो एलिमेंट को एक्सेस करने के लिए इंडेक्स का उपयोग नहीं कर सकते (जैसे एक `Set`)।
