# निर्देश

आप पक्षियों को देखने के शौकीन हैं और यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए।

आपके सामने छह कार्य हैं, और इन सबमें आपके बगीचे में आने वाले पक्षियों की संख्याओं से जुड़ा काम करना है।

## 1. जाँचिए कि आज कितने पक्षी आए

आज आपके बगीचे में कितने पक्षी आए, यह लौटाने के लिए `today()` फंक्शन लागू कीजिए। पक्षियों की गिनती दिन के क्रम में लगी है: पहला एलिमेंट सबसे पुराने दिन की गिनती है और अंतिम एलिमेंट आज की।

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. आज की गिनती बढ़ाइए

आज की गिनती बढ़ाने के लिए `increment_todays_count()` फंक्शन लागू कीजिए:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. देखिए कि कोई ऐसा दिन था या नहीं जब एक भी पक्षी नहीं आया

`has_day_without_birds()` फंक्शन लागू कीजिए, जो `TRUE` लौटाता है अगर कोई ऐसा दिन था जब बगीचे में शून्य पक्षी आए; वरना `FALSE` लौटाता है:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. शुरू के दिए गए दिनों में आए पक्षियों की संख्या निकालिए

`count_for_first_days()` फंक्शन लागू कीजिए। यह लौटाता है कि हफ्ते की शुरुआत से आपके बगीचे में कितने पक्षी आए हैं, लेकिन गिनती सिर्फ हफ्ते की शुरुआत से तय किए गए दिनों तक सीमित रहती है।

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरे दिनों से ज़्यादा व्यस्त होते हैं। व्यस्त दिन वह है जब आपके बगीचे में पाँच या उससे ज़्यादा पक्षी आए हों।
व्यस्त दिनों की संख्या लौटाने के लिए `busy_days()` फंक्शन लागू कीजिए:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. पिछले हफ्ते में पक्षियों के आने का चलता जोड़ निकालिए

आप जानना चाहते हैं कि इस हफ्ते अब तक कुल कितने पक्षी आए हैं।
हर दिन तक का चलता जोड़ निकालिए।

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. दिनों के नाम उनकी व्यस्तता के हिसाब से क्रम में लगाइए

आपको शक है कि पक्षियों के आने पर आसपास के सड़क यातायात के पैटर्न का असर पड़ता है, इसलिए छुट्टी के दिनों और काम के दिनों में यह अलग-अलग होता है।

दिनों के संक्षिप्त नामों को पक्षियों की संख्या के _घटते_ क्रम में लगाइए।

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
