# `jq` में फंक्शन

`jq` में आप अपनी ज़रूरत का लॉजिक समेटने के लिए खुद के **कस्टम फंक्शन** बना सकते हैं।
_फंक्शन_ बिल्ट-इन की तरह ही काम करते हैं: वे एक इनपुट लेते हैं और शून्य, एक या अधिक आउटपुट देते हैं।

## फंक्शन बनाना

आप नीचे दिए सिंटैक्स से एक `jq` _फंक्शन_ बना सकते हैं:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- `def` कीवर्ड से शुरू होता है,
- फंक्शन के अंदर के कोड से पहले एक कोलन आता है,
- अंदर एक ही एक्सप्रेशन होता है,
- अंत में सेमीकोलन लगता है,
- `jq` के बाकी सिंटैक्स की तरह, पढ़ने में आसानी के लिए आप जितना चाहें व्हाइटस्पेस इस्तेमाल कर सकते हैं।

## फंक्शन कहाँ लिखें

_फंक्शन_ इस्तेमाल करने से पहले बनाए जाने चाहिए। ऐसा करने पर एरर मिलती है:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

इसका मतलब है कि आपको _फंक्शन_ अपने `jq` कोड में सबसे ऊपर, "मुख्य" एक्सप्रेशन से पहले रखने होंगे।

### नेस्टेड फंक्शन

_फंक्शन_ नेस्टेड हो सकते हैं:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

यहाँ `B` _फंक्शन_ सिर्फ `A` के अंदर के कोड में ही दिखता है।

## स्कोप

एक _फंक्शन_ वेरिएबलो और नेस्टेड फंक्शन के लिए एक नया **स्कोप** बनाता है।

## आर्गुमेंट

_फंक्शन_ के **आर्गुमेंट** कॉमा से नहीं, बल्कि _सेमीकोलन_ से अलग किए जाते हैं।
उदाहरण के लिए, एक ऐसा _फंक्शन_ जो एक संख्या लेता है, और फिर एक संख्या जोड़ता है और एक संख्या से गुणा करता है:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

### आर्गुमेंट _एक्सप्रेशन_ होते हैं

फंक्शन के _आर्गुमेंट_ फिल्टर होते हैं, वैल्यू नहीं।
इस अर्थ में वे वैसा ही व्यवहार करते हैं जिसे दूसरी भाषाएँ कॉलबैक कहती हैं:

इसे `add_mul` फंक्शन के उदाहरण से समझिए:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

यहाँ क्या हो रहा है?

- `adder` आर्गुमेंट को _एक्सप्रेशन_ `. + 5` मिलता है
  - जब फंक्शन `. + adder` करता है, तो वह `. + . + 5` बन जाता है
  - चूँकि `. == 10` है, इसलिए इसका परिणाम 25 होता है
- इसी तरह, `multiplier` आर्गुमेंट एक्सप्रेशन `. - 2` है
  - इसका परिणाम 8 होता है
  - फिर नतीजा `25 * 8 == 200` बनता है

### आर्गुमेंट को वैल्यू बनाना

कभी-कभी आप किसी _आर्गुमेंट_ को वेरिएबल में "मटीरियलाइज़" करना चाहेंगे:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

इसका एक छोटा रूप भी है:

```jq
def my_func($arg):
    other stuff ...
;
```

ध्यान दीजिए कि यह सिर्फ "सिंटैक्टिक शुगर" है: बिना `$` वाला नाम `arg` भी _फंक्शन_ के स्कोप में मौजूद रहता है।

## आरिटी

_फंक्शन_ की एक **आरिटी** होती है, यानी वे कितने _आर्गुमेंट_ लेते हैं।

_फंक्शन_ एक ही नाम को अलग-अलग _आरिटी_ के साथ इस्तेमाल कर सकते हैं।
बिल्ट-इन [`range`][man-range] फंक्शन इसका उदाहरण है: `range/1`, `range/2` और `range/3`, तीनों एक साथ मौजूद रहते हैं।

यह उन रिकर्शिव फंक्शन को बनाने में काम आ सकता है जो अपनी स्थिति आर्गुमेंट के ज़रिए साथ लेकर चलते हैं।
उदाहरण के लिए `map` को ऐसे लागू किया जा _सकता_ है:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## रिकर्शन

`jq` टेलकॉल ऑप्टिमाइज़ेशन करता है, लेकिन सिर्फ 0-आरिटी वाले फंक्शन के लिए।

## मॉड्यूल

एक `jq` मॉड्यूल ऐसी फाइल होती है जिसमें सिर्फ फंक्शन होते हैं।
मॉड्यूल को किसी jq प्रोग्राम में [`include`][man-include] या [`import`][man-import] कमांड से शामिल किया जाता है।
