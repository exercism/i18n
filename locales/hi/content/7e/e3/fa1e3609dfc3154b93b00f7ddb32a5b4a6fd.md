# निर्देश

जादूगर बनने वाली एलिस अपनी ट्रेनिंग जारी रखती है। उसे कार्डों के कई ढेर दिए जाएँगे, जिनसे उसे अपने करतब दिखाने हैं।
चीज़ें थोड़ी आसान करने के लिए वह सिर्फ 1 से 10 तक के कार्ड इस्तेमाल करती है।

इस अभ्यास में वेक्टर की सामग्री का विश्लेषण करने के लिए अंतर्निहित मेथड का उपयोग कीजिए।

## 1. जाँचिए कि कोई कार्ड मौजूद है या नहीं

एलिस जानना चाहती है कि ढेर में कोई कार्ड मौजूद है या नहीं। दूसरे शब्दों में, क्या ढेर में कोई खास संख्या मौजूद है।

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. कार्ड का इंडेक्स पता कीजिए

एलिस जानना चाहती है कि ढेर में कार्ड का इंडेक्स क्या है।
अगर कार्ड ढेर में नहीं है, तो `-1` लौटाइए।

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. जाँचिए कि हर कार्ड सम है या नहीं

एलिस जानना चाहती है कि हर कार्ड सम है या नहीं। दूसरे शब्दों में, क्या ढेर की हर संख्या एक सम संख्या है।

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. जाँचिए कि ढेर में कोई विषम संख्या वाला कार्ड है या नहीं

एलिस जानना चाहती है कि ढेर में कोई विषम संख्या है या नहीं।

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. ढेर से पहला विषम कार्ड निकालिए

एलिस जानना चाहती है कि जो कार्ड विषम है, उसकी वैल्यू क्या है।  
अगर ढेर में कोई विषम कार्ड नहीं है, तो `-1` लौटाइए।

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. पहले सम कार्ड का इंडेक्स पता कीजिए

एलिस जानना चाहती है कि पहला सम कार्ड किस इंडेक्स पर है।
अगर ढेर में कोई सम कार्ड नहीं है, तो `-1` लौटाइए।

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
