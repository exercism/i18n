# परिचय

R में अलग सेट डेटा टाइप नहीं होता; इसके बजाय यह वेक्टर पर मिलते-जुलते काम करने के लिए कई तरह के फंक्शन इस्तेमाल करता है।

`%in%` ऑपरेटर जाँचता है कि कोई वैल्यू सेट में है या नहीं।

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

इससे जुड़े फंक्शनों में `unique` (डुप्लिकेट हटाने के लिए) और सेट के जोड़ों पर काम करने वाले `union()`, `intersect()`, `setdiff()` तथा `setequal()` शामिल हैं।

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

हर मामले में `set_1` और `set_2` में कोई बदलाव नहीं होता।
