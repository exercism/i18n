# परिचय

रूबी के साथ एक स्टैंडर्ड लाइब्रेरी आती है (जिसे अक्सर छोटा करके "stdlib" कहा जाता है), जिसमें तारीखों, JSON और नेटवर्किंग जैसी चीज़ों पर काम करने के लिए क्लासों का संग्रह होता है। यह आपके कोड के साथ काम करना आसान बनाने के लिए कुछ उपयोगी सुविधाएँ भी देती है।

`OpenStruct` स्टैंडर्ड लाइब्रेरी का हिस्सा है और इसकी मदद से आप `Hash` से आसानी से एक ऑब्जेक्ट बना सकते हैं। `Hash` की कीज़ से वैल्यू तक पहुँचने के बजाय `OpenStruct` में हम मेथड की मदद से वैल्यू पढ़ और बदल सकते हैं।

जब आप स्टैंडर्ड लाइब्रेरी या किसी दूसरी लाइब्रेरी की क्लासें इस्तेमाल करते हैं, तो उस क्लास को `require` मेथड की मदद से अपने कोड में शामिल करना होता है।

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

इसका एक और फायदा यह भी है कि ब्लॉक सिंटैक्स इस्तेमाल करते समय आप एक शॉर्टकट का फायदा उठा सकते हैं। जब कोई ब्लॉक सिर्फ एक मेथड को कॉल करता है, तो आप ब्लॉक की जगह `&:` लिख सकते हैं और उसके बाद मेथड का नाम लिख सकते हैं। उदाहरण के लिए, ये दोनों लाइनें एक ही बात कहती हैं:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
