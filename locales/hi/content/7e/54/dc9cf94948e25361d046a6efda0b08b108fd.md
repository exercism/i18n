# परिचय

JavaScript में _टेम्पलेट स्ट्रिंग_ की मदद से स्ट्रिंग के अंदर एक्सप्रेशन एम्बेड किए जा सकते हैं। इसे स्ट्रिंग इंटरपोलेशन भी कहते हैं। यह सुविधा पहले से मौजूद [`String`][string-reference] ग्लोबल ऑब्जेक्ट की क्षमता को और बढ़ा देती है।

JavaScript में टेक्स्ट को बैकटिक के बीच रखकर आप टेम्पलेट स्ट्रिंग बना सकते हैं। इनमें टेक्स्ट के अंदर नई लाइनें और दूसरे खास अक्षर तो आ ही सकते हैं, साथ ही आप वेरिएबल और दूसरे एक्सप्रेशन भी डाल सकते हैं।

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

ऊपर के उदाहरण में टेम्पलेट स्ट्रिंग दिखाने के लिए बैकटिक, यानी (<code>\`\`</code>) का इस्तेमाल किया गया है। `${...}` वह प्लेसहोल्डर है जिसकी जगह असली वैल्यू रखी जाती है। स्ट्रिंग के अलावा बाकी सभी टाइप की वैल्यू _अपने आप_ स्ट्रिंग में बदल दी जाती हैं। इस विषय पर [टाइप कन्वर्ज़न][type-conversion-concept] कॉन्सेप्ट में चर्चा की गई है। टेम्पलेट स्ट्रिंग के साथ हर तरह के एक्सप्रेशन इस्तेमाल किए जा सकते हैं।

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

जब आपको स्ट्रिंग को कई लाइनों में फॉर्मेट करना हो:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

वैल्यू को स्ट्रिंग में रखने की सुविधा की मदद से आप इस प्रक्रिया में तर्क भी जोड़ सकते हैं, जिससे तय होता है कि आउटपुट स्ट्रिंग क्या होनी चाहिए। इस तर्क को लिखने का एक तरीका [टर्नरी ऑपरेटर][ternary-operator] है। यह वही `if/else` जैसी शर्त वाली सुविधा थोड़े अलग रूप में देता है।

टेम्पलेट स्ट्रिंग के सिंटैक्स में तर्क जोड़ने के लिए:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
