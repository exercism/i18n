# परिचय

## ऐरे और वेक्टर

C++ में एक ही टाइप के एलिमेंट को एक तय क्रम में रखने के लिए अलग-अलग कंटेनर मौजूद हैं।
स्थिर आकार के कंटेनर के लिए `std::array` है, और `std::vector` है, जिसमें अपने आकार को गतिशील रूप से बदलने की क्षमता होती है।

### निर्माण

जब आप कोई ऐरे या वेक्टर घोषित करते हैं, तो आपको यह बताना होता है कि उस कंटेनर में किस टाइप के एलिमेंट रहेंगे।
ऐरे के लिए आकार भी बताना पड़ता है।
इन उदाहरणों में देखिए कि इन दोनों तरह के कंटेनर कैसे इनिशियलाइज़ किए जाते हैं:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

वेक्टर आम तौर पर ज़्यादा जगह लेते हैं, क्योंकि वे आगे बढ़ने के लिए अतिरिक्त मेमोरी लेते हैं।
आपको आकार बताने की ज़रूरत नहीं होती:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> ध्यान दें: टेम्पलेट कॉन्सेप्ट के पीछे की सटीक कार्यप्रणाली अभी आपको जानने की ज़रूरत नहीं है, सिलेबस में नीचे इसका अपना कॉन्सेप्ट आएगा।

### एलिमेंट तक पहुँचना

वेक्टर और ऐरे, अपने एलिमेंट तक पहुँचने के लिए एक ही फंक्शन इस्तेमाल करते हैं।
कंटेनर के पहले और अंतिम एलिमेंट पाने के लिए आप मेंबर फंक्शन `front` और `back` इस्तेमाल कर सकते हैं।
किसी खास एलिमेंट तक पहुँचने के लिए `at` और `[]` ऑपरेटर भी हैं।

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> ध्यान दें: अगर आप ऐसी जगह चुनते हैं जो आपके कंटेनर की सीमा में नहीं है, तो `[]` अपरिभाषित व्यवहार की ओर ले जा सकता है।
> `at` फंक्शन एक एक्सेप्शन उठाता है, जो लंबे समय में आपका काम आसान बना सकता है।

### वेक्टर को बदलने वाले फंक्शन

चूँकि `vector` का आकार तय नहीं होता, इसलिए उसमें एलिमेंट जोड़ना या हटाना संभव है।
इसके लिए दो आम फंक्शन हैं `emplace_back` और `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### क्षमता

कंटेनर खाली है या नहीं, यह मेंबर फंक्शन `empty` से जाँच सकते हैं।
एलिमेंट की संख्या जानने के लिए आप `size` इस्तेमाल कर सकते हैं।
