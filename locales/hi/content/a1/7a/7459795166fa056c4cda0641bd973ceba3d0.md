# विवरण

Swift में `guard` स्टेटमेंट का उपयोग फंक्शन, लूप या मेथड से समय से पहले बाहर निकलने के लिए किया जाता है जब कोई ज़रूरी शर्त पूरी नहीं होती:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

ऊपर के उदाहरण में `guard` अपने बाद आने वाले बूलियन एक्सप्रेशन का मूल्यांकन करता है।
अगर शर्त `true` है, तो `guard` स्टेटमेंट के बाद वाला कोड चलता रहता है।
अगर शर्त `false` है, तो `else` ब्लॉक के अंदर का कोड चलता है।

`if` स्टेटमेंट के उलट:

- एक `guard` स्टेटमेंट में `else` क्लॉज़ होना **ज़रूरी** है।
- `else` क्लॉज़ से कंट्रोल आसपास के स्कोप से बाहर निकलना **ज़रूरी** है (जैसे `return`, `continue`, `break` का उपयोग करके, या कोई एरर थ्रो करके)।

`guard` का उपयोग अक्सर शुरुआती शर्तों को साफ-सुथरे ढंग से जाँचने के लिए किया जाता है।
उदाहरण के लिए, sinc फंक्शन को देखिए ($\text{sinc}(x) = \frac{\sin(x)}{x}$, जहाँ शून्य से भाग देने से बचने के लिए $\text{sinc}(0) = 1$ है):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
