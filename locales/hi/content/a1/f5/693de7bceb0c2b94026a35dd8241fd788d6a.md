# निर्देश

आप एक ऐसा सिस्टम चला रहे हैं जिसमें कुछ एप्लिकेशन बहुत सारे लॉग बनाते हैं। आप एक छोटा प्रोग्राम लिखना चाहते हैं जो इन लॉग को इकट्ठा करे और उनकी गंभीरता के स्तर के अनुसार उन्हें लेबल दे। आपके सिस्टम के सभी एप्लिकेशन एक ही लॉग कोड इस्तेमाल करते हैं, लेकिन कुछ पुराने एप्लिकेशन सभी कोड का समर्थन नहीं करते।

| लॉग कोड              | लॉग लेबल | पुराने एप्लिकेशन में समर्थित? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | नहीं                      |
| 1                     | debug     | हाँ                       |
| 2                     | info      | हाँ                       |
| 3                     | warning   | हाँ                       |
| 4                     | error     | हाँ                       |
| 5                     | fatal     | नहीं                      |
| अन्य / असमर्थित        | unknown   | -                         |

## 1. लॉग लेबल तय कीजिए

`LogLevel.to_label/2` फंक्शन बनाइए। यह एक पूर्णांक कोड और एक बूलियन फ्लैग लेता है, जो बताता है कि लॉग किसी पुराने एप्लिकेशन से आया है या नहीं, और लॉग लाइन के लेबल को एक एटम के रूप में लौटाता है।

जो लॉग कोड तालिका में नहीं दिए गए हैं, उनके लिए _unknown_ लेबल लौटना चाहिए। जिन लॉग कोड के बारे में तालिका कहती है कि वे पुराने एप्लिकेशन में समर्थित नहीं हैं, उनके लिए भी _unknown_ लेबल लौटना चाहिए, अगर वह लॉग किसी पुराने एप्लिकेशन से आया हो।

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. अलर्ट भेजिए

जब कुछ अनपेक्षित होता है, तो किसी को सूचना देनी पड़ती है।

`LogLevel.alert_recipient/2` फंक्शन बनाइए, जो तय करता है कि अलर्ट किसे भेजा जाना चाहिए। यह फंक्शन एक पूर्णांक कोड और एक बूलियन फ्लैग लेता है, जो बताता है कि लॉग किसी पुराने एप्लिकेशन से आया है या नहीं, और प्राप्तकर्ता का नाम एक एटम के रूप में लौटाता है।

पिछले टास्क वाले `LogLevel.to_label/2` फंक्शन का इस्तेमाल कीजिए। अगर लॉग लेबल _error_ या _fatal_ है, तो अलर्ट _ops_ टीम को भेजिए। अगर आपको किसी पुराने सिस्टम से _unknown_ लेबल वाला लॉग मिलता है, तो अलर्ट _dev1_ टीम को भेजिए; बाकी unknown लेबल _dev2_ टीम को भेजे जाने चाहिए। बाकी सभी लॉग लेबल को _false_ लौटाकर छोड़ा जा सकता है।

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
