# परिचय

Gleam की मानक लाइब्रेरी `gleam/queue` मॉड्यूल में एक `Queue` टाइप देती है। यह `List` टाइप जैसा ही है, लेकिन इसमें कुछ खास अंतर हैं:

- `Queue` टाइप में कोई लिटरल सिंटैक्स नहीं होता, जिससे क्यू बनाई जा सके या उस पर पैटर्न मैच किया जा सके।
- `Queue` टाइप में एलिमेंट आगे और पीछे, दोनों तरफ से कुशलता से जोड़े और हटाए जा सकते हैं, जबकि `List` टाइप में एलिमेंट सिर्फ आगे से ही कुशलता से जोड़े और हटाए जा सकते हैं।

ज़्यादातर मौकों पर आप `List` टाइप ही इस्तेमाल करना चाहेंगे, लेकिन जब आपको किसी कलेक्शन के अंत से जोड़ना या हटाना हो, तब `Queue` टाइप अच्छा विकल्प है।

क्यू को `queue.new` और `queue.from_list` फंक्शन की मदद से बनाया जा सकता है:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

`queue.push_front` और `queue.push_back` फंक्शन की मदद से क्यू में एलिमेंट जोड़े जा सकते हैं:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

`queue.pop_front` और `queue.pop_back` फंक्शन की मदद से क्यू से एलिमेंट हटाए जा सकते हैं:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

`queue.to_list` फंक्शन की मदद से क्यू को ऐरे में बदला जा सकता है:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## क्यू की समानता

क्यू के काम करने के तरीके की वजह से, एक जैसे एलिमेंट और एक जैसा क्रम रखने वाली दो क्यू `==` ऑपरेटर के हिसाब से बराबर नहीं हो सकतीं। यह ऑपरेटर वैल्यू की तुलना उनकी संरचना के आधार पर करता है। उदाहरण के लिए:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

अगर आपको दो क्यू की समानता की तुलना करनी हो, तो आप `queue.is_logically_equal` फंक्शन इस्तेमाल कर सकते हैं।

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
