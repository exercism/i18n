# निर्देश

आप हाई स्कूल के प्रेमी युगलों की मदद करने जा रहे हैं। आप सोशल मीडिया पर उनके इनिशियल से एक यूनिकोड दिल बनाकर उनका प्यार जताएँगे:

```
❤ J.  +  M. ❤
```

## 1. नाम साफ कीजिए

एक फंक्शन `cleanupname` बनाइए जो स्टैक से एक नाम लेता है। हर `-` को एक स्पेस से बदलिए और फिर आगे तथा पीछे का व्हाइटस्पेस हटा दीजिए।

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. नाम का पहला अक्षर निकालिए

एक फंक्शन `firstletter` बनाइए जो एक नाम लेता है। पिछले काम के `cleanupname` को दोबारा इस्तेमाल कीजिए, फिर नतीजे का पहला अक्षर लीजिए और उसे एक अक्षर की स्ट्रिंग के रूप में लौटाइए।

```factor
"Jane" firstletter .
! => "J"
```

## 3. पहले अक्षर को इनिशियल का रूप दीजिए

एक फंक्शन `initial` बनाइए जो एक नाम लेता है। पिछले काम के `firstletter` को दोबारा इस्तेमाल कीजिए, उसे बड़े अक्षरों में बदलिए, और फिर उसके बाद एक `.` जोड़िए।

```factor
"Robert" initial .
! => "R."
```

## 4. इनिशियल को दिल के अंदर रखिए

एक फंक्शन `couple` बनाइए जो स्टैक से दो नाम लेता है। दोनों नामों पर पिछले काम के `initial` को दोबारा इस्तेमाल कीजिए, और फिर नतीजा जोड़कर तैयार कीजिए:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
