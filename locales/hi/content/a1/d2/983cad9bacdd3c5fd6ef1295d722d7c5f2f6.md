# परिचय

## वेरिएबल परिभाषित करना

किसी वेरिएबल को परिभाषित करने का मतलब है किसी नाम को एक वैल्यू असाइन करना। Scala में दो तरह के वेरिएबल होते हैं, val और var।

`val` इम्यूटेबल होता है, इसलिए पहली बार असाइन करने के बाद उसकी वैल्यू बदली नहीं जा सकती:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

इसके विपरीत, `var` में उसी टाइप की नई वैल्यू दोबारा असाइन की जा सकती है:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala एक स्टैटिकली टाइप्ड भाषा है, जिसका मतलब है कि कंपाइल-टाइम पर हर चीज़ का एक टाइप होता है। किसी वेरिएबल को उसका टाइप स्पष्ट रूप से बताकर परिभाषित किया जा सकता है, या Scala कंपाइलर को असाइन की गई वैल्यू के आधार पर उसका टाइप अनुमान लगाने देकर (जिसे टाइप इन्फरेंस कहते हैं)। इसलिए, नीचे दी गई दोनों वेरिएबल परिभाषाएँ एक जैसी हैं:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

एक बार परिभाषित होने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## क्लास के अंदर मेथड परिभाषित करना

Scala एक _ऑब्जेक्ट-ओरिएंटेड भाषा_ है और इसमें सभी मेथड को किसी _क्लास_ में परिभाषित करना ज़रूरी है। क्लास बनाने के लिए `class` कीवर्ड का उपयोग किया जाता है।

```scala
class Calculator {
  // ...
}
```

क्लास के अंदर मेथड को `def` कीवर्ड से शुरू करके उसके बाद नाम लिखकर परिभाषित किया जा सकता है। हर मेथड में शून्य या अधिक पैरामीटर हो सकते हैं, जिन्हें गोल ब्रैकेट के अंदर कॉमा से अलग करके लिखा जाता है। सभी पैरामीटर का टाइप स्पष्ट रूप से लिखना ज़रूरी है, पैरामीटर के लिए टाइप इन्फरेंस नहीं होता। पैरामीटर की सूची के बाद एक और कोलन लगाकर मेथड का रिटर्न टाइप लिखा जाता है।

मेथड की परिभाषा के बाद `=` चिह्न लगता है, जिसके बाद मेथड के अंदर का कोड आता है। नीचे के उदाहरण में मेथड के अंदर का कोड दो स्टेटमेंट से बना है, जो कर्ली ब्रैकेट के अंदर लिखे गए हैं।

मेथड अंतिम एक्सप्रेशन की वैल्यू लौटाता है; यहाँ `add` मेथड वेरिएबल `sum` की वैल्यू लौटाता है:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

उस मेथड को छोटा करने और पढ़ने में आसानी बढ़ाने के लिए कुछ सुधार किए जा सकते हैं:

- चूँकि वैल्यू लौटाने के लिए वेरिएबल `sum` का उपयोग सिर्फ़ एक बार होता है, इसे हटाया जा सकता है
- सिर्फ़ एक स्टेटमेंट वाले मेथड में कर्ली ब्रैकेट की ज़रूरत नहीं होती
- मेथड का रिटर्न टाइप भी वेरिएबल के टाइप की तरह अनुमान लगाया जा सकता है

इससे नीचे दिया गया एक पंक्ति वाला मेथड बनता है, जिसकी कार्यक्षमता वही है:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## क्लास का इंस्टेंस बनाना और मेथड कॉल करना

किसी मेथड को इनवोक करने के लिए पहले क्लास का एक इंस्टेंस बनाया जाता है, और फिर उस इंस्टेंस पर आर्गुमेंट के साथ मेथड कॉल किया जाता है:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## कमेंट करना

Scala दो तरह के कमेंट का समर्थन करता है, सिंगल लाइन कमेंट और मल्टीलाइन कमेंट:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
