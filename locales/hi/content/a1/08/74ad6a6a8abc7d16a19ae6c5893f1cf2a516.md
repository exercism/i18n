# निर्देश परिशिष्ट

दी गई फोन नंबर स्ट्रिंग को ओवरराइट कीजिए।
अगर फोन नंबर अमान्य हो, तो उसकी जगह खाली स्ट्रिंग रख दीजिए।

## रजिस्टर

| रजिस्टर | उपयोग        | प्रकार    | विवरण                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | इनपुट/आउटपुट | एड्रेस | नल-टर्मिनेटेड स्ट्रिंग के रूप में फोन नंबर |
| `$t0-9`  | अस्थायी    | कोई भी     | अस्थायी भंडारण के लिए इस्तेमाल होता है             |
