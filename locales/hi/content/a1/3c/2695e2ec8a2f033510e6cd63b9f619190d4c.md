# निर्देश परिशिष्ट

## उदाहरण इनपुट

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

इसका मतलब है कि आपके इनपुट ये हैं:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## अमान्य इनपुट को संभालना

अगर इनपुट वैल्यू में से कोई भी अमान्य है, तो आपके वर्ब को `empty` लौटाना चाहिए (जैसे `0$0` या `''`)।

### उदाहरण

- अगर _इनपुट आधार_ 2 से छोटा है:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- अगर _आउटपुट आधार_ 2 से छोटा है:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- अगर _अंक_ में इनपुट आधार के बराबर या उससे बड़ी कोई वैल्यू हो:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
