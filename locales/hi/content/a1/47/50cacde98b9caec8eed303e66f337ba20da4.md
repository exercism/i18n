# MoonScript इंस्टॉल कीजिए

सबसे पहले, Lua और busted इंस्टॉल करने के लिए [Lua ट्रैक][lua-install] पर दिए गए इंस्टॉलेशन निर्देशों का पालन कीजिए।

इसके बाद MoonScript को इस कमांड से इंस्टॉल कीजिए:

```console
$ luarocks install --local moonscript
```

[lua-install]: https://exercism.org/docs/tracks/lua/installation
