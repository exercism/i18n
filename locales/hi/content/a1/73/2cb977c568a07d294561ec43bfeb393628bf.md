# टेस्ट

## टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
$ gradle test
```

## और टेस्ट चालू करना

जब आपका कोड सभी सक्रिय टेस्ट पास कर ले, तो अगले रुचिकर टेस्ट से पहले लगे `@Ignore` को हटाकर एक और टेस्ट चालू कीजिए। इसके लिए `@Ignore` लाइन को हटा दीजिए, या लाइन के शुरू में दो स्लैश लगाकर उसे कमेंट कर दीजिए।

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
