# अपरिवर्तनीय क्लास

`SCOREBOARD` एक ऐसी चीज़ है जो बदलती रहती है। एक ही स्कोरबोर्ड के दो नाम वही स्कोर देखते हैं, क्योंकि बोर्ड एक ही है और दोनों नाम उसी की ओर इशारा करते हैं।

बेयरिंग ऐसी नहीं होती। `350 degrees` कोई और चीज़ नहीं बन जाती; वह बस होती है। संख्याएँ भी ऐसी ही होती हैं, और स्ट्रिंग भी। आपकी अपनी क्लास भी ऐसी हो सकती है।

## अपरिवर्तनीय

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

दो शब्द सब कुछ बदल देते हैं। अपरिवर्तनीय क्लास का ऑब्जेक्ट एक **वैल्यू** होता है, कोई ऐसी चीज़ नहीं जिसकी ओर इशारा किया जाता हो:

- असाइन करते या पास करते समय इसकी कॉपी बन जाती है, इसलिए कोई और आपकी वैल्यू नहीं बदल सकता;
- यह कभी void नहीं हो सकता;
- और इसके एट्रिब्यूट को असाइन नहीं किया जा सकता।

## एक को बदलने के लिए दूसरा बनाना

चूँकि `degrees := 90` की अनुमति नहीं है, `attr` कुछ और देता है: एक रूटीन जो नई वैल्यू लेता है और बदली हुई वैल्यू वाला **नया ऑब्जेक्ट** लौटाता है।

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

मूल ऑब्जेक्ट ज्यों का त्यों रहता है। यही पूरा तरीका है, और `create` इसी तरह लिखा जाता है:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

यहाँ कोई `new` नहीं है। अपरिवर्तनीय ऑब्जेक्ट हमेशा मौजूद रहता है, इसलिए `b : SAME` पहले से ही एक ऑब्जेक्ट है, जिसमें हर एट्रिब्यूट अपनी खाली वैल्यू पर होता है।

इसलिए जो रूटीन किसी बेयरिंग को "बदलती" है, वह एक नई बेयरिंग लौटाती है:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## तुलना

वैल्यू की तुलना इससे होती है कि उनमें क्या रखा है, इससे नहीं कि वे कौन-सा ऑब्जेक्ट हैं। लेकिन यह बताना आपको पड़ेगा कि तुलना कैसे हो। `is_eq` लिखिए, और `=` उसी का उपयोग करेगा:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

इसके बिना, दो बेयरिंग पर `=` कंपाइल नहीं होगा।

## किसे चुनें

अपरिवर्तनीय क्लास तब इस्तेमाल कीजिए जब चीज़ की कोई पहचान न हो और उसके बारे में कुछ भी समझदारी से न बदल सके: बेयरिंग, बिंदु, तारीख, लंबाई। साधारण क्लास तब इस्तेमाल कीजिए जब चीज़ कोई एक ऐसी खास चीज़ हो जिसके साथ कुछ घटित होता है: स्कोरबोर्ड, हैरनेस, फाइल।

कसौटी यह है कि "समान" का मतलब "बराबर" है या "बिल्कुल वही एक"।
