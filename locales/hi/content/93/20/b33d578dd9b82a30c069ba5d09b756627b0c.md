# इंस्टॉलेशन

अपने सिस्टम पर Julia इंस्टॉल करने के लिए [Julia Language Downloads पेज](https://julialang.org/downloads/) पर दिए निर्देशों का पालन कीजिए।

~~~~exercism/caution
Julia को अपने ऑपरेटिंग सिस्टम के पैकेज मैनेजर से इंस्टॉल करना सुझाया नहीं जाता। ऐसे पैकेजों का आधिकारिक रूप से रखरखाव नहीं होता और इनसे दिक्कतें आ सकती हैं।
~~~~

लोकल इंस्टॉलेशन के लिए बहुत सारे एडिटर और IDE के प्लगइन उपलब्ध हैं। [VS Code एक्सटेंशन](https://github.com/julia-vscode/julia-vscode) सबसे लोकप्रिय है। दूसरे एडिटर के लिए इंटीग्रेशन आप GitHub पर [JuliaEditorSupport](https://github.com/JuliaEditorSupport) ऑर्गनाइज़ेशन में पा सकते हैं।

अगर आपको ज़्यादा इंटरैक्टिव वातावरण पसंद है, तो आप [IJulia](https://github.com/JuliaLang/IJulia.jl) के साथ Jupyter नोटबुक इस्तेमाल कर सकते हैं, या Julia में सरल रिएक्टिव नोटबुक के लिए [Pluto.jl](https://github.com/fonsp/Pluto.jl) इस्तेमाल कर सकते हैं।

लोकल इंस्टॉलेशन की ज़रूरत के बिना Julia शुरू करने का एक आसान तरीका [Nextjournal](https://nextjournal.com/) है, जो नोटबुक पर आधारित ऑनलाइन IDE है। आप इसे अपने ब्राउज़र से खोल सकते हैं, लॉगिन कीजिए और अभ्यास हल करना शुरू कर दीजिए। अगर आपको सिर्फ एक ऑनलाइन REPL चाहिए, तो आप [Repl.it](https://repl.it/languages/julia) इस्तेमाल कर सकते हैं।
