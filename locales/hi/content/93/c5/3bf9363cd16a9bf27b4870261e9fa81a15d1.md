# टाइप जगलिंग

टाइप जगलिंग को टाइप कोएर्शन भी कहा जाता है।
टाइप जगलिंग तब होती है जब किसी ऑपरेशन को करने के लिए अलग-अलग टाइप की दो वैल्यू को एक ही टाइप में बदल दिया जाता है।

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

जब एक्सप्रेशन का मूल्यांकन होता है, तो `*` ऑपरेटर की अपेक्षा पूरी करने के लिए स्ट्रिंग वैल्यू अपने आप `int` में बदल दी जाती है।
किस टाइप में बदलना है, यह फैसला PHP ऑपरेशन के नियमों के आधार पर लेता है। ये नियम जगह-जगह काफी अलग होते हैं।

फंक्शन और मेथड कॉल करते समय भी टाइप कोएर्शन होता है:

```php
strlen(12321);
# => 5
```

## टाइप कास्टिंग

अपने आप होने वाले कोएर्शन पर भरोसा करने की जगह हम `C` शैली की टाइप कास्टिंग इस्तेमाल करके किसी वैल्यू को ज़बरदस्ती किसी तय टाइप के रूप में मूल्यांकित करवा सकते हैं:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

यह वैल्यू को ब्रैकेट `(...)` में लिखे गए टाइप में बदल देता है।
किसी भी प्रिमिटिव टाइप को लक्ष्य टाइप के रूप में इस्तेमाल किया जा सकता है: `bool`, `int`, `float`, `string`, `array`, `object`.

## केवल अस्थायी बदलाव

टाइप जगलिंग या कास्टिंग **वेरिएबल में रखी गई वैल्यू का टाइप नहीं बदलती।**
केवल ऑपरेशन को दिए गए इनपुट को ही बदला जाता है।

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## जानकारी का नुकसान

जब किसी वैल्यू को दूसरे टाइप में बदला जाता है, तो इस प्रक्रिया में जानकारी का कुछ हिस्सा खो सकता है:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

कास्टिंग पर भरोसा करना, चाहे वह स्पष्ट रूप से की गई हो या अपने आप हुई हो, किसी बड़े सिस्टम में एरर पैदा कर सकता है।

## `array` और `object` में स्पष्ट टाइप कास्टिंग

वैल्यू को `array` और `object` टाइप में भी कास्ट किया जा सकता है।
अगर किसी ऐसी वैल्यू को, जो ऐरे या ऑब्जेक्ट नहीं है, `array` में कास्ट किया जाए, तो वह ऐरे के अंदर मौजूद एक अकेले एलिमेंट में बदल जाती है:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

जब वैल्यू को `object` में कास्ट किया जाता है, तो वह `scalar` नाम की एक पब्लिक प्रॉपर्टी में रख दी जाती है:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` PHP में पहले से मौजूद एक अनाम क्लास का टाइप है।
