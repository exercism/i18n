# परिचय

Perl एक प्रोग्रामिंग भाषा है, जिसे Larry Wall ने बनाया था। इसे पहली बार 1987 में जारी किया गया था।

## पैकेज और मॉड्यूल

पैकेज कोड का एक संग्रह होता है, जो अक्सर उसी नाम की एक मॉड्यूल फाइल में रखा जाता है, जिसका एक्सटेंशन `.pm` होता है।
इसके बाद मॉड्यूल को किसी दूसरी फाइल में आयात किया जा सकता है, जो आम तौर पर `use` कीवर्ड से होता है।

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## वेरिएबल

वेरिएबल तीन तरह के होते हैं: स्केलर (`$foo`), ऐरे (`@bar`) और हैश (`%baz`)।
बातों को आसान रखने के लिए यहाँ सिर्फ स्केलर वेरिएबलो का इस्तेमाल किया जाएगा।
एक स्केलर वैल्यू इनमें से कोई भी हो सकती है: एक स्ट्रिंग, एक संख्या, एक बूलियन, या किसी चीज़ का [रेफरेंस][perlreftut]।
किसी वैल्यू का न होना `undef` होता है।


`my` और `our` कीवर्ड किसी वेरिएबल को लेक्सिकल स्कोप में घोषित करते हैं, जैसे `my $foo;`.
`our` के साथ यह वेरिएबल उसी नाम के पैकेज वेरिएबल का उपनाम भी बन जाता है।
वेरिएबल घोषित करने के और भी तरीके हैं, जिनके बारे में यहाँ नहीं बताया जाएगा।

आप `=` ऑपरेटर से किसी वेरिएबल को वैल्यू असाइन कर सकते हैं, जैसे `$foo = 1;`। यह वेरिएबल घोषित करने के साथ ही किया जा सकता है, जैसे `my $foo = 1;`।

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## सब्रूटीन

`sub` कीवर्ड एक [सब्रूटीन][perlsub] घोषित करता है।
`return` कीवर्ड सब्रूटीन से बाहर निकल जाता है और बताई गई वैल्यू लौटाता है; अगर कोई वैल्यू न दी गई हो, तो यह खाली ऐरे लौटाता है।
अगर `return` नहीं लिखा गया हो, तो लौटाई जाने वाली वैल्यू सब्रूटीन के संदर्भ (स्केलर, ऐरे या वॉइड) और उसके अंतिम स्टेटमेंट से तय होती है।

```perl
sub hello () {
    return 'Hello, World!';
}
```

Perl के हाल के संस्करणों में आप [सिग्नेचर][perlsubsig] में औपचारिक पैरामीटर बता सकते हैं।
पैरामीटर की सूची में स्केलर, ऐरे या हैश वेरिएबल हो सकते हैं।
अगर पैरामीटर की सूची खाली हो, तो इसका मतलब है कि सब्रूटीन कोई आर्गुमेंट नहीं लेता।
Perl के पुराने संस्करणों में आर्गुमेंट को `@_` नाम के खास वेरिएबल से निकालना पड़ता था, जिसके बारे में यहाँ नहीं बताया जाएगा।

## कमेंट

Perl में कमेंट `#` से शुरू होते हैं, जब वह `#` किसी स्ट्रिंग का हिस्सा न हो, और लाइन के अंत तक चलते हैं।
