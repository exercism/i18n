# टाइप असेर्शन का परिचय

Go में इंटरफेस अंतर्निहित टाइप को लेकर अस्पष्टता पैदा कर सकते हैं।
टाइप असेर्शन की मदद से हम इस सिंटैक्स का उपयोग करके इंटरफेस वैल्यू की अंतर्निहित ठोस वैल्यू निकाल सकते हैं: `interfaceVariable.(concreteType)`.

उदाहरण के लिए:

```go
var input interface{} = 12
number := input.(int)
```

ध्यान दें: अगर इंटरफेस वेरिएबल में ठोस टाइप की कोई वैल्यू नहीं हो, तो यह पैनिक हो जाएगा।

हम यह जाँच सकते हैं कि किसी इंटरफेस वैल्यू में कोई खास ठोस टाइप है या नहीं। इसके लिए हम टाइप असेर्शन की दोनों रिटर्न वैल्यू इस्तेमाल करते हैं: अंतर्निहित वैल्यू, और एक बूलियन वैल्यू जो बताती है कि असेर्शन सफल हुआ या नहीं।
उदाहरण के लिए:

```go
str, ok := input.(string) // no panic if input is not a string
```

अगर `input` में एक `string` है, तो `str` अंतर्निहित वैल्यू होगी और `ok` सही होगा।
अगर `input` में `string` नहीं है, तो `str` `string` टाइप की शून्य वैल्यू होगी (यानी `""`, खाली स्ट्रिंग) और `ok` गलत होगा।
किसी भी स्थिति में पैनिक नहीं होता।

## टाइप स्विच

एक **टाइप स्विच** एक के बाद एक कई टाइप असेर्शन कर सकता है।
इसका सिंटैक्स टाइप असेर्शन (`interfaceVariable.(concreteType)`) जैसा ही होता है, लेकिन इसमें `concreteType` की जगह `type` कीवर्ड लिखा जाता है।
यहाँ एक उदाहरण है:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
