# परिचय

स्ट्रक्ट, [मैप][exercism-maps] के ऊपर बनाए गए एक्सटेंशन हैं, जो कंपाइल के समय जाँच और डिफाल्ट वैल्यू देते हैं। किसी स्ट्रक्ट का नाम उसी मॉड्यूल के नाम पर रखा जाता है जिसमें उसे बनाया जाता है। स्ट्रक्ट बनाने के लिए `defstruct` का इस्तेमाल कीजिए। यह `defstruct` आम तौर पर मॉड्यूल बनाने के तुरंत बाद लिखा जाता है। `defstruct` या तो एटम की ऐरे लेता है (फील्ड की डिफाल्ट वैल्यू `nil` रखने के लिए) या कीवर्ड ऐरे लेता है (तय की गई डिफाल्ट वैल्यू देने के लिए)। जिन फील्ड के लिए कोई डिफाल्ट वैल्यू नहीं दी गई है, वे डिफाल्ट वैल्यू वाले फील्ड से पहले आने चाहिए।

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## फील्ड तक पहुँचना और उन्हें बदलना

चूँकि स्ट्रक्ट मैप के ऊपर ही बने होते हैं, इसलिए वैल्यू पाने और बदलने के लिए हम मैप के ज़्यादातर फंक्शन इस्तेमाल कर सकते हैं। _Access Behaviour_ स्ट्रक्ट के लिए लागू **नहीं** किया गया है। इसलिए स्ट्रक्ट के फील्ड तक पहुँचने के लिए _स्टैटिक एक्सेस ऑपरेटर_ `.` इस्तेमाल करना बेहतर है।

- फील्ड की वैल्यू पाना/निकालना:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- फील्ड की वैल्यू बदलना

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## पैटर्न मैचिंग

पैटर्न मैचिंग में स्ट्रक्ट का इस्तेमाल स्ट्रक्ट के नाम के साथ भी किया जा सकता है और बिना नाम के भी।

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

पैटर्न में स्ट्रक्ट का नाम शामिल करने से आप यह पक्का कर सकते हैं कि बाईं और दाईं, दोनों ओर एक ही टाइप के स्ट्रक्ट हों।

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## फील्ड वैल्यू को शुरू में सेट करना ज़रूरी बनाना

स्ट्रक्ट बनाते समय उसकी वैल्यू सेट हो जाएँ, यह पक्का करने के लिए हम `@enforce_keys` मॉड्यूल एट्रिब्यूट के साथ फील्ड के नामों की एक ऐरे दे सकते हैं। अगर किसी फील्ड का नाम इसमें नहीं दिया गया, तो उसकी वैल्यू `nil` रहेगी, जैसा ऊपर के उदाहरण में दिखाया गया है। जिस फील्ड को ज़रूरी ठहराया गया हो, अगर उसकी वैल्यू शुरू में सेट न की जाए, तो एक एरर मिलती है।

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
