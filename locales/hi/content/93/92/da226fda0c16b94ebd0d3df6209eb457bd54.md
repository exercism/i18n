# परिचय

C# में लिस्ट प्रिमिटिव वैल्यू, या स्ट्रक्ट और क्लास के इंस्टेंस का संग्रह होती हैं। इन्हें बेस क्लास लाइब्रेरी में `List<T>` के रूप में लागू किया गया है, जहाँ `T` लिस्ट में मौजूद चीज़ का टाइप होता है। इस API में लिस्ट बनाने और उन्हें बदलने के लिए बहुत सारे मेथड मौजूद हैं।

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

किसी कलेक्शन की परिभाषा में आम तौर पर एंगल ब्रैकेट के बीच एक प्लेसहोल्डर रखा जाता है, जिसके लिए परंपरा से अक्सर `T` चुना जाता है। इससे कलेक्शन इस्तेमाल करने वाला तय कर सकता है कि कलेक्शन में किस टाइप की चीज़ें रखनी हैं।

ऐरे के विपरीत, लिस्ट अपना आकार गतिशील रूप से बदल सकती हैं।

## LINQ

`List<T>` का बिल्ट-इन API काफी समृद्ध है, जिसमें `ConvertAll`, `FindAll` और `Foreach` जैसे मैपिंग और फिल्टर शामिल हैं। इसका [लूप लगाने का तरीका][for-each] भी बहुत साफ है, और इस API से आपको ज़रूर परिचित होना चाहिए। कई कामों के लिए Language Integrated Query ([LINQ][linq]) भी उपलब्ध है, जो इससे और भी ज़्यादा शक्तिशाली है और बहुत इस्तेमाल किया जाता है। इसका एक फायदा यह भी है कि यह लाइब्रेरी कलेक्शन, तीसरे पक्ष के कलेक्शन और आपकी अपनी क्लास, सबके लिए एक जैसा इंटरफेस देता है।
