# परिचय

## ऐरे

F# में `list` शून्य या अधिक वैल्यू का एक अपरिवर्तनीय संग्रह है। किसी ऐरे की सभी वैल्यू का टाइप एक ही होना चाहिए। चूँकि ऐरे अपरिवर्तनीय होते हैं, इसलिए एक बार बन जाने के बाद उनकी वैल्यू कभी नहीं बदल सकती। जो भी फंक्शन या ऑपरेटर ऐरे को बदलते हुए दिखते हैं (जैसे कोई एलिमेंट जोड़ना), वे वास्तव में एक नया ऐरे लौटाते हैं।

ऐरे को इस तरह बनाया जा सकता है:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

किसी ऐरे में एलिमेंट जोड़ने का सबसे आम तरीका `::` (cons) ऑपरेटर है:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

F# के ऐरे का एक _हेड_ (पहला एलिमेंट) और एक _टेल_ (पहले एलिमेंट के बाद का सब कुछ) होता है। किसी ऐरे का टेल खुद भी एक ऐरे होता है।

ऐरे के साथ काम करने के लिए या तो `List` मॉड्यूल में बने फंक्शन और ऑपरेटर इस्तेमाल किए जाते हैं, या फिर लिस्ट और कॉन्स पैटर्न की मदद से पैटर्न मैचिंग की जाती है:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

पैटर्न मैचिंग करते समय आप किसी वैल्यू को _छोड़_ भी सकते हैं; जब किसी खास केस में आपको किसी वैल्यू की परवाह नहीं होती (यानी आप उस वैल्यू का _इस्तेमाल_ नहीं करने वाले होते), तो इस बात को जताने के लिए आप अंडरस्कोर (`'_'`) लगा सकते हैं:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

पैटर्न मैचिंग में अकेला `'_'` हमेशा सबसे अंत में आना चाहिए; जो भी वैल्यू बाकी किसी भी केस से मेल नहीं खाती, उसे यही केस संभाल लेता है।
