# परिचय

## कॉलबैक फंक्शन

कॉलबैक फंक्शन ऐसे फंक्शन होते हैं जिन्हें आर्गुमेंट के रूप में भेजा जाता है। प्रोग्रामिंग का यह पैटर्न सिंक्रोनस और असिंक्रोनस, दोनों तरह की प्रोग्रामिंग में एक के बाद एक फंक्शन कॉल करने का क्रम बनाता है। कॉलबैक फंक्शन लिखना किसी और फंक्शन को लिखने से अलग नहीं है। हालाँकि, कॉलबैक फंक्शन को उस सिग्नेचर से मेल खाना चाहिए जो उसे कॉल करने वाला फंक्शन तय करता है।

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

आप कॉलबैक को फंक्शन एक्सप्रेशन के रूप में भी लिख सकते हैं:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
