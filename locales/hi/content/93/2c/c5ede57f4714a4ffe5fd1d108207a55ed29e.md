# परिचय

`null` वैल्यू का उपयोग किसी वैल्यू के _अभाव_ को दर्शाने के लिए किया जाता है। **नेलबल** टाइप ऐसा टाइप होता है जो किसी वेरिएबल को `null` वैल्यू लेने देता है। किसी भी टाइप को नेलबल बनाने के लिए, हम उसे `Null<T>` में लपेट देते हैं:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

यह जाँचने के लिए कि कोई वैल्यू इस समय `null` है या नहीं, बस एक `if` एक्सप्रेशन इस्तेमाल कीजिए:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
