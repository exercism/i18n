# निर्देश

इस अभ्यास में आप एक दोस्त के साथ संख्या अनुमान लगाने का खेल खेल रहे हैं। नियम आसान हैं: आप चुपके से `1` और `100` के बीच कोई संख्या चुनते हैं, और आपका दोस्त अंदाज़ा लगाने की कोशिश करता है कि आपने कौन-सी संख्या चुनी है। दोस्त की मदद के लिए, आपका जवाब इस बात पर निर्भर करता है कि अंदाज़ा आपकी चुनी हुई संख्या (`42`) के कितना करीब था। अलग-अलग जवाबों के नियम ये हैं:

- अगर अंदाज़ा `42` है: "Correct"
- अगर अंदाज़ा `41` या `43` है: "So close"
- अगर अंदाज़ा `41` से कम है: "Too low"
- अगर अंदाज़ा `43` से ज़्यादा है: "Too high"

अंदाज़ों के जवाब तय करने के लिए आपके पास चार काम हैं।

## 1. सही अंदाज़े का जवाब दीजिए

सही अंदाज़े का जवाब देने के लिए `reply` फंक्शन बनाइए:

```gleam
reply(42)
// -> "Correct"
```

## 2. करीब के अंदाज़े का जवाब दीजिए

करीब के अंदाज़ों का जवाब देने के लिए `reply` फंक्शन बदलिए:

```gleam
reply(41)
// -> "So close"
```

## 3. बहुत कम अंदाज़ों का जवाब दीजिए

बहुत कम अंदाज़ों का जवाब देने के लिए `reply` फंक्शन बदलिए:

```gleam
reply(25)
// -> "Too low"
```

## 4. बहुत ज़्यादा अंदाज़ों का जवाब दीजिए

बहुत ज़्यादा अंदाज़ों का जवाब देने के लिए `reply` फंक्शन बदलिए:

```gleam
reply(88)
// -> "Too high"
```
