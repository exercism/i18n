# निर्देश

ओज़ान एक आने वाली रोड ट्रिप के लिए प्लेलिस्ट तैयार कर रहा है। वह एक ही ट्रैक को एक से अधिक बार नहीं सुनना चाहता, लेकिन प्लेलिस्ट इतनी लंबी हो चुकी है कि उसे यह याद रखने में परेशानी हो रही है कि कौन-से ट्रैक पहले ही जोड़े जा चुके हैं।

ओज़ान के म्यूज़िक प्लेयर का API सिर्फ ऐरे के साथ काम करना जानता है, इसलिए वह कुछ कोड लिखने की कोशिश करता है जो `Array.indexOf()` का उपयोग करके ट्रैक को प्लेलिस्ट में जोड़ने से पहले यह जाँचता है कि वह पहले से मौजूद है या नहीं। दुर्भाग्य से, उसके प्रोग्राम को चलने में बहुत ज़्यादा समय लगता है। उसे आपकी मदद चाहिए!

ओज़ान की मदद करने पहुँचने पर आपको यह देखकर हैरानी होती है कि उसकी प्लेलिस्ट में _पाँच लाख_ ट्रैक हैं। शायद आप किसी ऐसे दूसरे डेटा स्ट्रक्चर के बारे में जानते हैं जिससे आप प्लेलिस्ट को ज़्यादा कुशलता से संभाल सकें?

## 1. डुप्लिकेट ट्रैक हटाइए

`removeDuplicates` फंक्शन बनाइए, जो एक प्लेलिस्ट को _पैरामीटर_ के रूप में लेता है और एक नई प्लेलिस्ट _लौटाता है_ जिसमें सारे ट्रैक अनोखे हों।

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. जाँचिए कि कोई ट्रैक पहले ही जोड़ा जा चुका है या नहीं

`hasTrack` फंक्शन बनाइए, जो एक प्लेलिस्ट और एक ट्रैक को _पैरामीटर_ के रूप में लेता है और एक बूलियन _लौटाता है_ जो बताता है कि प्लेलिस्ट में वह ट्रैक मौजूद है या नहीं।

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. एक ट्रैक जोड़िए

`addTrack` फंक्शन बनाइए, जो एक प्लेलिस्ट और एक ट्रैक को _पैरामीटर_ के रूप में लेता है और एक नई प्लेलिस्ट _लौटाता है_ जिसमें वह ट्रैक शामिल होता है।

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. एक ट्रैक हटाइए

`deleteTrack` फंक्शन बनाइए, जो एक प्लेलिस्ट और एक ट्रैक को _पैरामीटर_ के रूप में लेता है और एक नई प्लेलिस्ट _लौटाता है_ जिसमें वह ट्रैक शामिल नहीं होता।

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. अनोखे कलाकारों की सूची बनाइए

`listArtists` फंक्शन बनाइए, जो एक प्लेलिस्ट को _पैरामीटर_ के रूप में लेता है और प्लेलिस्ट के अनोखे कलाकारों की सूची _लौटाता है_। ध्यान दीजिए कि ट्रैकों के नाम `<SONG> - <ARTIST>` के रूप में होते हैं।

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
