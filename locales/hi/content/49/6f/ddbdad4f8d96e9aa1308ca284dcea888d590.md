# विस्तृत परिचय

Factor में यादृच्छिकता की सारी सुविधाएँ [`random`][random] वोकैब्युलरी के एक ही जेनेरिक शब्द के आसपास समेटी गई हैं:

```
random ( obj -- elt )
```

यह अपने आर्गुमेंट के आधार पर अलग-अलग तरीके से काम करता है:

- **पूर्णांक** `n` देने पर `[0, n)` के बीच एक यादृच्छिक पूर्णांक मिलता है;
- **सीक्वेंस** देने पर उसका एक यादृच्छिक एलिमेंट मिलता है;
- एसोक, हैश-सेट और `uniform-distribution` ट्यूपल भी समर्थित हैं।

इसी पर सीक्वेंस के दो हेल्पर बने हैं:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` सीक्वेंस को बदल देता है और उसी को लौटाता है, इसलिए अगर आपको मूल क्रम बनाए रखना है तो पहले `clone` कीजिए।

## यादृच्छिकता कहाँ से आती है

`random` उस जेनरेटर को पढ़ता है जो `random-generator` डायनैमिक वेरिएबल में रखा होता है। डिफॉल्ट रूप से यह एक मर्सेन ट्विस्टर होता है, जिसका सीड सिस्टम क्लॉक से लिया जाता है, इसलिए हर प्रोसेस अलग होता है। किसी कोटेशन के चलने की अवधि के लिए आप कोई दूसरा जेनरेटर भी लगा सकते हैं:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

चूँकि `with-random` कोटेशन के डायनैमिक विस्तार तक बस `random-generator` को बाँधता है, इसलिए इसे लपेटने वाले वर्ड को `inline` चिह्नित करना चाहिए, ताकि कोटेशन अपना परिणाम कॉल करने वाले के लिए स्टैक पर छोड़ सके।

इनके अलावा, `random` में दूसरे डिस्ट्रिब्यूशन के लिए `random-bits`, `random-unit`, `uniform-random` और `normal-random` मौजूद हैं, और ऐसी ज़रूरतों के लिए, जहाँ नतीजा हर बार एक जैसा न हो या क्रिप्टोग्राफिक काम हो, `system-random-generator` और `secure-random-generator` भी हैं।
