# परिचय

आपकी सहेली एलियुद को अपनी दादी टिगिस्ट से एक खेत विरासत में मिला है।
उनकी दादी एक आविष्कारक थीं और उन्हें चीज़ें बड़े ही उलझे ढंग से बनाने की आदत थी।
मुर्गी के दड़बे में एक डिजिटल डिस्प्ले लगा है, जो एक कोडित संख्या दिखाता है। यह संख्या उन सभी अंडों की स्थिति बताती है जो उठाए जा सकते हैं।

एलियुद आपसे एक ऐसा प्रोग्राम लिखने के लिए कह रही हैं जो दड़बे में मौजूद अंडों की वास्तविक संख्या दिखाए।

स्थिति की जानकारी का कोड इस तरह निकाला जाता है:

1. अंडे देने वाली संभावित जगहों को देखिए और हर जगह के लिए लिखिए: अगर वहाँ अंडा है तो `1`, और अगर जगह खाली है तो `0`।
2. उस संख्या को बाइनरी से दशमलव में बदलिए।
3. नतीजा डिस्प्ले पर दिखाइए।

उदाहरण 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

उदाहरण 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
