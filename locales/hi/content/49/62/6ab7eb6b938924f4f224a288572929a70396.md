# निर्देश

इस अभ्यास में आप एक वज़न करने वाली मशीन का मॉडल बनाएँगे।

## 1. वज़न करने वाली मशीन के लिए शुरुआती स्थिति बनाइए

जब मशीन इनिशियलाइज़ होती है, तो उसे अपनी फैक्ट्री सेटिंग्स का इस्तेमाल करना चाहिए। ये सेटिंग्स इस बात पर निर्भर करती हैं कि मशीन कहाँ बेची जाती है। इसलिए मशीन को इनिशियलाइज़ करते समय सटीकता दी जा सकती है, और यह भी बताया जा सकता है कि वह मीट्रिक प्रणाली इस्तेमाल करेगी या इम्पीरियल प्रणाली।

`WeighingMachine#initialize` मेथड बनाइए, जो दो आर्गुमेंट लेता है: `precision`, जो एक `Int32` है, और `metric`, जो एक `Bool` है। `metric` आर्गुमेंट के `true` होने का मतलब है कि मशीन को मीट्रिक प्रणाली इस्तेमाल करनी चाहिए, वरना उसे इम्पीरियल प्रणाली इस्तेमाल करनी चाहिए। इनिशियलाइज़ मेथड को इंस्टेंस वेरिएबल `@weight` पर `0.0` सेट करना भी चाहिए।

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. वज़न करने वाली मशीन में सटीकता की सुविधा दीजिए

अलग-अलग ज़रूरतों को पूरा करने के लिए हम हर मशीन में सटीकता सेट कर सकते हैं (यानी दशमलव चिह्न के बाद आने वाले अंकों की संख्या)।

`WeighingMachine#precision` गेटर मेथड बनाइए, जो मशीन की सटीकता लौटाता है।

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. वज़न करने वाली मशीन पर वज़न सेट करने की सुविधा दीजिए

`WeighingMachine#weight` प्रॉपर्टी बनाइए, ताकि वज़न पढ़ा भी जा सके _और_ सेट भी किया जा सके:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. मशीन को मीट्रिक और इम्पीरियल इकाइयों के बीच बदलने की सुविधा दीजिए

`WeighingMachine#metric=` प्रॉपर्टी बनाइए, जिससे इकाई सेट की जा सके। इसे एक बूलियन वैल्यू स्वीकार करनी चाहिए।

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
