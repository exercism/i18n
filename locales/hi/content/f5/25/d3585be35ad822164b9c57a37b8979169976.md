# निर्देश

इस अभ्यास में आप एक ऐसा प्रोग्राम बनाएँगे जो [tic-tac-toe][] खेल की स्थिति तय करता है।
(_आप इस खेल को "noughts and crosses" या "Xs and Os" के नाम से भी जानते होंगे।_)

यह खेल 3×3 के ग्रिड पर खेला जाता है।
खिलाड़ी बारी-बारी से ग्रिड पर `X` और `O` रखते हैं।
खेल तब खत्म होता है जब कोई खिलाड़ी ग्रिड की एक पंक्ति, स्तंभ या किसी विकर्ण में तीन चिह्न लगाकर जीत जाता है, या जब पूरा ग्रिड भर जाता है।

इस अभ्यास में हम मानेंगे कि शुरुआत `X` करता है।

आपको यह तय करना है कि दिया गया खेल किस स्थिति में है।

खेल की 3 संभावित स्थितियाँ हैं:

- खेल **ongoing** है।
- खेल **draw** के रूप में खत्म हुआ।
- खेल **win** के रूप में खत्म हुआ।

अगर दिया गया बोर्ड अमान्य है, तो उपयुक्त एरर फेंकिए।

अगर कोई बोर्ड इन शर्तों को पूरा करता है, तो वह अमान्य है:

- दिया गया बोर्ड तब नहीं बन सकता जब बारियाँ सही क्रम में ली जाती हैं (याद रखिए कि शुरुआत `X` करता है)।
- खेल खत्म होने के बाद भी खेला गया।

## उदाहरण

### जारी खेल

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### बराबरी

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### जीत

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

___|___|___
   |   |

___|___|___
   |   |
   |   |
   |   |
```
