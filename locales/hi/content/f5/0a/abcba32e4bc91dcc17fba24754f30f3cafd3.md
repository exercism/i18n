# निर्देशों का परिशिष्ट

## ग्रिड का प्रारूप

ग्रिड को नल-टर्मिनेटेड स्ट्रिंग के रूप में दर्शाया जाता है। हर पंक्ति के अंत में एक न्यूलाइन अक्षर होता है।

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप     | विवरण                                                                    |
| -------- | ------------ | -------- | ------------------------------------------------------------------------ |
| `$a0`    | इनपुट        | एड्रेस   | नल-टर्मिनेटेड इनपुट स्ट्रिंग                                              |
| `$a1`    | इनपुट/आउटपुट | एड्रेस   | नल-टर्मिनेटेड परिणाम स्ट्रिंग, जो ग्रिड के आयाम अमान्य होने पर खाली रहती है |
| `$v0`    | आउटपुट       | पूर्णांक | ग्रिड की स्थिति (`0` = `ok`, `-1` = `invalid columns`, `-2` = `invalid rows`) |
| `$t0-9`  | अस्थायी      | कोई भी   | अस्थायी भंडारण के लिए                                                     |
