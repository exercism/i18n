# परिचय

Common Lisp में कोई फंक्शन सिर्फ एक वैल्यू ही नहीं, कई वैल्यू लौटा सकता है।
उदाहरण के लिए `floor` संख्या को शून्य की ओर नीचे की तरफ पूर्णांक बनाता है और दो वैल्यू लौटाता है। पहली वैल्यू पूर्णांक बनी संख्या है और दूसरी शेषफल।

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(हम आउटपुट में लौटाई गई कई वैल्यू अलग-अलग पंक्तियों में दिखाएँगे।)

## कई वैल्यू लौटाइए

अगर आप चाहते हैं कि कोई फंक्शन कई वैल्यू लौटाए, तो आप `values` फंक्शन का इस्तेमाल कीजिए:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## कई वैल्यू को संभालना

अगर आपको सिर्फ पहली वैल्यू चाहिए, तो कुछ खास करने की ज़रूरत नहीं है। भाषा खुद इसका ध्यान रख लेती है:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

लेकिन अगर आपको बाकी वैल्यू भी चाहिए, तो इसके लिए कई फंक्शन इस्तेमाल करने पड़ेंगे।
इसके दो मुख्य मैक्रो हैं, `multiple-value-list` और `multiple-value-bind`.
इनका इस्तेमाल ऐसी चीज़ को लपेटने के लिए होता है जो कई वैल्यू लौटाती है। इस तरह ये सारी वैल्यू पकड़ लेते हैं।
पहला मैक्रो सारी वैल्यू का एक ऐरे बनाता है।
दूसरा मैक्रो आपको हर अलग वैल्यू को एक वेरिएबल से बाँधने देता है।

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

एक और उपयोगी फंक्शन है `nth-value`.
