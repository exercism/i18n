# परिचय

`for` लूप PHP में सबसे जटिल प्रकार के लूप हैं। ये `C`, `Java` और `JavaScript` के `for` लूपों की तरह काम करते हैं। इसका मूल रूप यह है:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

पहला एक्सप्रेशन (_expr1_) लूप शुरू होने से पहले मूल्यांकित होता है। दूसरा एक्सप्रेशन (_expr2_) हर इटरेशन से पहले मूल्यांकित होता है। अगर इसका मान _ट्रूथी_ होता है, तो स्टेटमेंट चलाए जाते हैं। चलाए गए स्टेटमेंट के बाद तीसरा एक्सप्रेशन (_expr3_) मूल्यांकित होता है।
