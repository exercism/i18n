# परिचय

*हीप* एक ऐसा संग्रह है जो हमेशा अपने सबसे छोटे (या सबसे बड़े) आइटम को जानता है और आपको उसे जल्दी से हटाने देता है। यह *प्रायोरिटी क्यू* को लागू करने का सबसे स्वाभाविक तरीका है। हीप [`heaps`][heaps] वोकैबुलरी में रहते हैं।

`<min-heap>` एक खाली हीप बनाता है जिसमें से सबसे छोटी की पहले निकलती है; `<max-heap>` सबसे बड़ी को पहले देता है। हर आइटम एक *वैल्यू* है जो किसी *की* के नीचे रखी जाती है, और की ही वह प्रायोरिटी है जिस पर Factor क्रम लगाता है:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

हीप *म्यूटेबल* होता है: `heap-push` और `heap-pop` उसे उसी जगह बदल देते हैं।

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` सबसे आगे वाला आइटम हटाए बिना पढ़ता है; `heap-pop` उसे हटाकर लौटाता है; `heap-pop-all` पूरे हीप को प्रायोरिटी क्रम में `{ key value }` जोड़ों की असोसिएशन लिस्ट में खाली कर देता है।

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

आइटम डालना `O(log n)` है और सबसे आगे वाला पढ़ना `O(1)`, इसलिए "सबसे ज़रूरी आइटम उठाइए, फिर और जोड़िए" को बार-बार करना बड़ी क्यू में भी तेज़ बना रहता है। इसका कार्यान्वयन एक बाइनरी हीप है जो बढ़ते हुए ऐरे में संग्रहीत रहता है; की कोई भी ऐसी वैल्यू हो सकती है जिस पर क्रम लगाया जा सके (संख्याएँ, स्ट्रिंग, …)।
