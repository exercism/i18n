# सुझाया गया पठन

Smalltalk का उपयोग व्यापक रूप से होता है, इसलिए पढ़ने के लिए सामग्री के बहुत सारे विकल्प मौजूद हैं।

## शुरुआत

* [Pharo Main Site](https://pharo.org/documentation):
इसमें बहुत सारे लेख और मदद उपलब्ध है
* [Pharo Syntax Cheatsheet](https://files.pharo.org/media/pharoCheatSheet.pdf):
यह एक पोस्टकार्ड पर फिट हो जाता है
* [I Can Read C but not Smalltalk](https://www.eli.sdsu.edu/courses/spring01/cs635/readingSmalltalk.pdf): Smalltalk को समझने के लिए कई आसान कदम
* [Pharo By Example (9.0)](https://books.pharo.org/pharo-by-example9/):
चरण-दर-चरण उदाहरणों वाली एक पूरी PDF पुस्तक
* [Learning OOP and TDD in Pharo](https://books.pharo.org/learning-oop/):
इसमें और भी प्रोग्रामिंग तकनीकें और अवधारणाएँ बताई गई हैं
* [Discord](https://discord.gg/QewZMZa) पर एक सक्रिय ऑनलाइन Pharo चर्चा फोरम है
(ऊपर [कम्युनिटी पेज](https://pharo.org/community) पर दिए गए निमंत्रण लिंक का उपयोग कीजिए)
* [Pharo Mooc](https://mooc.pharo.org/):
इसमें पूरे प्रोग्रामिंग कोर्स और वीडियो की एक श्रृंखला मिलती है

## अधिक उन्नत

* [Deep Into Pharo](https://books.pharo.org/deep-into-pharo/):
यह आपको ग्राफिक्स और पार्सिंग जैसे अधिक उन्नत विषयों तक ले जाता है
* [Pharo with style](https://github.com/SquareBracketAssociates/Booklet-PharoWithStyle):
यह Pharo के तरीके से फॉर्मेटिंग और डिज़ाइन करने की मार्गदर्शिका है
* [Smalltalk with style](http://sdmeta.gforge.inria.fr/FreeBooks/WithStyle/SmalltalkWithStyle.pdf):
यह Smalltalk में फॉर्मेटिंग और डिज़ाइन करने की एक व्यापक मार्गदर्शिका है
* [Enterprise Pharo - Web Perspective](http://books.pharo.org/enterprise-pharo/):
यह वेब एप्लिकेशन, HTTP और डेटा को शामिल करता है
