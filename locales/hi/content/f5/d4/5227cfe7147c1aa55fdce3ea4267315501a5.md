# टेस्ट

हर अभ्यास में एक टेस्ट फाइल होती है।
टेस्ट चलाने के लिए `bats` प्रोग्राम का उपयोग कीजिए।

```bash
bats test-hello-world.bats
```

`bats` को इंस्टॉल करना ज़रूरी होगा।
अपने सिस्टम पर `bats` इंस्टॉल करने के निर्देशों के लिए [Bash ट्रैक पर टेस्टिंग][bash] पेज देखिए।

### bats bash में लिखा गया है

bats फाइल एक bash स्क्रिप्ट होती है। इसमें कुछ खास फंक्शन होते हैं, जिन्हें `bats` कमांड पहचानता है।
आपको कुछ टेस्ट इस तरह के दिखेंगे:

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

वह `<<<` सिंटैक्स bash का [Here String][here-string] है।
यह दाईं ओर की स्ट्रिंग को बाईं ओर वाले प्रोग्राम के स्टैंडर्ड इनपुट में भेज देता है।
यह ([लगभग][so]) इसके समान है:

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## assert फंक्शन के लिए मदद

ये टेस्ट [bats-assert][bats-assert] लाइब्रेरी के फंक्शन इस्तेमाल करते हैं।
अलग-अलग `assert*` फंक्शनों की मदद वहीं मिल जाएगी।

## छोड़े गए टेस्ट

किसी भी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना।
जब आप टेस्ट चलाते हैं, तो डिफॉल्ट रूप से सिर्फ एक टेस्ट (पहला वाला) चलता है।
यह जानबूझकर ऐसा है, ताकि आपका ध्यान सिर्फ उस एक टेस्ट को पास कराने पर लगा रहे।
एक बार वह पास हो जाए, तो आप अगला टेस्ट चालू कर सकते हैं। इसके लिए बाकी टेस्टों के आगे लगे इन

    [[ $BATS_RUN_SKIPPED == true ]] || skip

एनोटेशन को कमेंट कर दीजिए या हटा दीजिए।

## स्किप को ओवरराइड करना

`skip` एनोटेशन वाले टेस्टों समेत सारे टेस्ट चलाने के लिए आप यह चला सकते हैं:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

टाइपिंग बचाने के लिए रैपर फंक्शन इस्तेमाल करना सुविधाजनक रहता है। `bash` में आप ऐसा कर सकते हैं:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

फिर टेस्ट चलाने के लिए सिर्फ इतना लिखिए:

```bash
bats
```

## `jq` में डीबग करना

`jq` के साथ एक उपयोगी [`debug`][debug] फिल्टर आता है।
अपने अभ्यास के हल लिखते समय इसका इस्तेमाल कीजिए, ताकि आप देख सकें कि इस समय jq पाइपलाइन में कौन-सा डेटा मौजूद है।
अधिक जानकारी के लिए [डीबगिंग दस्तावेज़][debugging] देखिए।
