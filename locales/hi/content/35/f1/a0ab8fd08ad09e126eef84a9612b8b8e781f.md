# परिचय

## लिस्ट कॉम्प्रिहेंशन

कॉम्प्रिहेंशन _एन्यूमरेबल_ को आसानी से और घोषणात्मक तरीके से बदलने की सुविधा देते हैं।

बहुत सरल कॉम्प्रिहेंशन बनाने के लिए हम `for` कीवर्ड लिखते हैं, जिसके बाद एक _जेनरेटर_ और एक _डू-ब्लॉक_ आता है। यह डू-ब्लॉक एन्यूमरेट की गई वैल्युओं से नई वैल्यू बनाता है।

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

कॉम्प्रिहेंशन में _फिल्टर_ भी हो सकते हैं। जो वैल्यू फिल्टर से नहीं गुज़रतीं, वे अंतिम ऐरे से हटा दी जाती हैं:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

हम इससे भी जटिल कॉम्प्रिहेंशन कई लाइनों में बना सकते हैं:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

कई _जेनरेटर_ इस्तेमाल करके एक _कार्टेशियन गुणनफल_ बनाया जा सकता है। इसका मतलब है कि पहले जेनरेटर से बनने वाली हर वैल्यू को दूसरे जेनरेटर से बनने वाली हर वैल्यू के साथ एक बार जोड़ा जाता है:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
