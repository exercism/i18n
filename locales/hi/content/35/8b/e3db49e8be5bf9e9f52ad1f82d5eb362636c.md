# परिचय

Factor के अक्षर *पूर्णांक* होते हैं, यानी Unicode कोड पॉइंट। इसलिए सादे `<`, `>`, `=` ऑपरेटर पहले से ही ऐसा क्रम देते हैं जिसमें अक्षरों का केस मायने रखता है। इसके ऊपर [`unicode`][unicode] वोकैबुलरी Unicode को समझने वाले प्रेडिकेट और एक अक्षर का केस बदलने का तरीका जोड़ती है।

## प्रेडिकेट

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## केस बदलना

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

स्ट्रिंग स्तर के `>upper`, `>lower` और `>title` इन्हें स्ट्रिंग के हर अक्षर पर लागू करते हैं।

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
