# gofmt का इस्तेमाल नहीं किया गया

अपने हल पर `gofmt` चलाइए, जो Go में कोड की फॉर्मेटिंग में मदद करता है।

Go में कोड की फॉर्मेटिंग समुदाय के लिए बहुत महत्वपूर्ण है। ज़्यादातर IDE को इस तरह सेट किया जा सकता है कि वे हर बार सेव करने पर कोड को अपने-आप फॉर्मेट कर दें। जैसे:

- Visual Studio Code में [Go का बेहतरीन सपोर्ट](https://code.visualstudio.com/docs/languages/go) है
- Vim में भी [Go का शानदार एक्सटेंशन](https://github.com/fatih/vim-go) है
- [Jetbrains Goland](https://www.jetbrains.com/go/) Go के लिए पूरा IDE है

`gofmt` को खुद से चलाने के लिए:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
