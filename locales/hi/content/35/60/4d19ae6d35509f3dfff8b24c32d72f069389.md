# परिचय

जब किसी क्वोटेशन को अपने आसपास से वैल्यू याद रखनी होती हैं, तो दूसरी भाषाएँ इसे क्लोज़र कहती हैं। ऐसी स्थिति में Factor दो टूल इस्तेमाल करता है: `curry` शब्द और `'[ ]` फ्राई सिंटैक्स।

## `curry`: एक वैल्यू कैप्चर करना

`curry` ([`kernel`][kernel] में) एक वैल्यू और एक क्वोटेशन लेता है और उस वैल्यू को अंदर रखकर एक नया क्वोटेशन लौटाता है:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

दो वैल्यू कैप्चर करने के लिए `curry` को दो बार लगाइए:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: दो क्वोटेशन जोड़ना

`compose` ([`kernel`][kernel] में) दो क्वोटेशनों को आपस में जोड़ता है:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## फ्राई क्वोटेशन: कई वैल्यू कैप्चर करना

एक या दो से अधिक कैप्चर के लिए, `curry` को बार-बार लगाना पढ़ने में कठिन हो जाता है। *फ्राई* `'[ … ]` का उपयोग एक या अधिक `_` प्लेसहोल्डर के साथ करता है; हर `_` को डेटा स्टैक से निकाली गई वैल्यू से क्रम में बदल दिया जाता है:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

`curry` और फ्राई दोनों क्लोज़र बनते ही अपनी वैल्यू स्टैक से ले लेते हैं। ऊपर की लाइन स्टैक पर कुछ नहीं छोड़ती और `[ + + ] curry curry` का सीधा विकल्प है।

प्लेसहोल्डर बाएँ से दाएँ स्टैक की वैल्यू से नीचे से ऊपर तक भरे जाते हैं: `2 3 '[ _ _ ]` का मतलब `[ 2 3 ]` है, `[ 3 2 ]` नहीं।

फ्राई नेस्टेड क्वोटेशन के *अंदर* तक भी पहुँचता है, जिससे आप कैप्चर की गई वैल्यू को ठीक वहीं रख सकते हैं जहाँ आप उन्हें चाहते हैं:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

`_` अंदर वाले `[ … ]` के भीतर बैठता है, फिर भी फ्राई उसे भर देता है।

## घोषित इफेक्ट के साथ `call`

जब आप अंत में संग्रहीत क्वोटेशन चलाते हैं, तो `call` पर उसका स्टैक इफेक्ट घोषित कीजिए ताकि कंपाइलर उसका टाइप-चेक कर सके:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## वेक्टर अंकगणित

[`math.vectors`][math.vectors] वोकैबुलरी समान लंबाई की दो सीक्वेंस को एलिमेंट के हिसाब से मिलाती है। `v+` और `v*` उन्हें जोड़ते या गुणा करते हैं; `vmax` और `vmin` हर कंपोनेंट में से बड़ा या छोटा रखते हैं। हर एक दो एलिमेंट वाला ऐरे लौटाता है:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
