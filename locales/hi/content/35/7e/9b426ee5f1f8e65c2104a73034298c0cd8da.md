# Babashka टेक्स्ट एडिटर इंटीग्रेशन

## nREPL

### Emacs: [CIDER](https://cider.mx/)

यह वही है जिससे यह सब शुरू हुआ, और इसका [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) इकोसिस्टम कई अन्य प्लग-इन को काम करवाता है।

1. अपने प्लेटफॉर्म के लिए [Emacs](https://www.gnu.org/software/emacs/download.html) इंस्टॉल कीजिए।

2. कोई मौजूदा Emacs डिस्ट्रीब्यूशन चुनिए ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) और [Doom Emacs](https://github.com/hlissner/doom-emacs) तीनों बढ़िया हैं) या इसे `init.el` में जोड़िए:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

[CIDER डॉक्स](https://docs.cider.mx/cider/platforms/babashka.html) से लिया गया सार:

प्रोजेक्ट डायरेक्टरी से nREPL सर्वर शुरू कीजिए:

```bash
$ bb --nrepl-server
```

`C-x C-f` से कोई भी Clojure फाइल (`.clj`) बनाइए या खोलिए, और `C-c C-x c j` (cider-connect-clj) की मदद से उससे कनेक्ट कीजिए।

[CIDER की बुनियादी कीबाइंडिंग](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` या `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` या `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. [VSCode](https://code.visualstudio.com/) इंस्टॉल कीजिए।

2. [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva) इंस्टॉल कीजिए।

फिलहाल Calva आपके सोर्स कोड को एक फोल्डर, यानी एक Clojure प्रोजेक्ट, के संदर्भ में समझता है। इसे बनाने का एक अच्छा तरीका [clj-new](https://github.com/seancorfield/clj-new) है:

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. प्रोजेक्ट की डायरेक्टरी से nREPL सर्वर शुरू कीजिए:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

VSCode में प्रोजेक्ट फोल्डर खोलिए (Ctrl+K Ctrl+O), या किसी दूसरे टर्मिनल से:

```bash
$ cd bbtest
bbtest$ code .
```

4. VSCode में Calva का `Connect to a running REPL` कमांड चलाइए (ctrl+alt+c ctrl+alt+c)। पूछे जाने पर `Generic` प्रोजेक्ट चुनिए और `localhost:1667` डालिए।

REPL कमांड:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

3. ज़्यादा जानकारी के लिए [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html) देखिए।

## सॉकेट REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/) इंस्टॉल कीजिए

2. `chlorine` पैकेज इंस्टॉल कीजिए

3. सॉकेट REPL शुरू कीजिए:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Atom का कमांड पैलेट खोलिए (ctrl+shift+p) और `Connect Clojure Socket REPL` कमांड को `localhost` `1666` के साथ चलाइए

5. `Edit` मेन्यू -> `Keymap...` के ज़रिए keymap.cson में की बाइंडिंग बदलिए:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Emacs के लिए, इसे अपने `init.el` में जोड़कर [inf-clojure](https://github.com/clojure-emacs/inf-clojure) इंस्टॉल कीजिए:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

ऊपर बताए अनुसार सॉकेट REPL शुरू कीजिए, और Emacs में `M-x inf-clojure-connect` चलाइए (C-c M-c)।

C-c C-e से फॉर्म का मूल्यांकन कीजिए। inf-clojure-mode (यानी REPL) और inf-clojure-minor-mode में उपलब्ध सभी कमांड की सूची के लिए आप C-h f RET inf-clojure-mode और C-h f RET inf-clojure-minor-mode चलाइए, या सीधे उनके मेन्यू देख लीजिए।

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

[Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) डाउनलोड कीजिए और उसका एलियस `vim` बनाइए।

* [vim-plug](https://github.com/junegunn/vim-plug) इंस्टॉल कीजिए:

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

`~/.config/nvim/init.vim` बनाइए:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Neovim खोलिए और `:PlugInstall` कमांड चलाइए।

`iced` कमांड को $PATH में जोड़िए:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* सॉकेट REPL सर्वर शुरू कीजिए, सोर्स फाइल खोलिए और `:IcedConnectSocketRepl 1666` चलाइए।

डिफॉल्ट REPL कमांड (डिफॉल्ट `<Leader>` `\` है):

- `<Leader>ei` : अंदरूनी एलिमेंट का मूल्यांकन कीजिए
- `<Leader>ee` : बाहरी लिस्ट का मूल्यांकन कीजिए
- `<Leader>et` : बाहरी सबसे ऊपरी लिस्ट का मूल्यांकन कीजिए
