# टाइप स्पेसिफिकेशन का इस्तेमाल

[comment]: # (यह चेतावनी तब दिखती है जब हल में टाइप स्पेसिफिकेशन न हो)

[टाइप स्पेसिफिकेशन](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) शामिल कीजिए, जो बताते हैं कि फंक्शन इनपुट में क्या लेता है और आउटपुट में क्या देता है।

- Elixir एक डायनैमिकली टाइप्ड भाषा है, यानी टाइप की जाँच केवल तब होती है जब कोड चलता है। टाइप स्पेसिफिकेशन इस्तेमाल करने से लिंटर और स्टैटिक एनालिसिस, जैसे [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (जो Erlang के [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) पर आधारित है), कोड में अनजाने व्यवहार ढूँढने में मदद करते हैं।
- सभी बिल्ट-इन टाइप की [पूरी सूची](https://hexdocs.pm/elixir/typespecs.html#basic-types) आपको [भाषा के डॉक्यूमेंटेशन](https://hexdocs.pm/elixir/typespecs.html#content) में मिल जाएगी
- टाइप ब्रैकेट के साथ या बिना, दोनों तरह से लिखे जा सकते हैं: `atom()` बनाम `atom`
  - Exercism Elixir में टाइप बिना ब्रैकेट लिखने का तरीका अपनाया जाता है।

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
