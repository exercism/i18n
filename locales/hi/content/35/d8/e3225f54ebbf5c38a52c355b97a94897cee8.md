# परिचय

यह अभ्यास मेथड पैरामीटर के कुछ विवरणों और C# में उनके इस्तेमाल पर चर्चा करता है।

पैरामीटर कॉल करने वाले मेथड से कॉल किए गए मेथड तक सूचना पहुँचाते हैं।

- `ref` और `out` जैसे मॉडिफायर इस्तेमाल करके पैरामीटर का व्यवहार बदला जा सकता है।

- `out` मॉडिफायर वाला पैरामीटर कॉल किए गए मेथड से कॉल करने वाले को एक वैल्यू वापस पहुँचाता है। पैरामीटर को बिना शुरुआती वैल्यू दिए भी कॉल किए गए मेथड को पास किया जा सकता है। कॉल किए गए मेथड के अंदर उसके साथ हर हाल में ऐसा व्यवहार होता है जैसे मेथड में आते समय उसे शुरुआती वैल्यू नहीं दी गई हो। पैरामीटर मॉडिफायर के व्यवहार और नियमों को सबसे आसानी से उदाहरणों (नीचे देखिए) और कंपाइलर संदेशों की मदद से समझा जा सकता है।

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out` पैरामीटर को कॉल किए गए मेथड के अंदर असाइन करना ज़रूरी है।

- `ref` मॉडिफायर वाला पैरामीटर एक वैल्यू कॉल किए गए मेथड में पास करता है। जब मेथड लौटता है, तो कॉल करने वाले को उस पैरामीटर में कॉल किए गए मेथड द्वारा किए गए सारे बदलाव मिलेंगे।

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` पैरामीटर वेरिएबलो होने चाहिए, क्योंकि कॉल किया गया मेथड सीधे उसी पैरामीटर पर काम करेगा जो कॉल करने वाले को दिखता है।
- `out` और `ref` मॉडिफायर कॉल किए गए मेथड के सिग्नेचर में और कॉल साइट पर, दोनों जगह ज़रूरी हैं।
