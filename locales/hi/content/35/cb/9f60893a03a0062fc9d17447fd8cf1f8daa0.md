# टर्नरी ऑपरेटर

टर्नरी ऑपरेटर, `if..else..` तुलना करने और एक वैल्यू लौटाने के लिए एक वैकल्पिक सिंटैक्स देता है।

## सिंटैक्स

PHP में एक `if` स्टेटमेंट होता है, जिसमें किसी शर्त की "सत्यता" के आधार पर कोई काम किया जा सकता है।

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

इसके अलावा, यही काम टर्नरी ऑपरेटर से भी किया जा सकता है:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

तुलना का सिंटैक्स छोटा होता है, जिसे `(condition) ? (evaluate if true) : (evaluate if false);` से दर्शाया जाता है।
