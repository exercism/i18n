# स्कोप रिज़ॉल्यूशन ऑपरेटर

स्कोप रिज़ॉल्यूशन ऑपरेटर (`::`) की मदद से हम किसी क्लास का संदर्भ लेकर उसके नाम कॉन्स्टेंट, स्टैटिक प्रॉपर्टी या स्टैटिक मेथड इस्तेमाल कर सकते हैं।

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## स्कोप रिज़ॉल्यूशन ऑपरेटर के साथ `self` और `static` का उपयोग

कभी-कभी ऑब्जेक्ट को अपने ही स्कोप का संदर्भ लेना पड़ सकता है। इसके लिए `self` कीवर्ड क्लास को उसके अपने स्कोप का संदर्भ लेने देता है। `self` कीवर्ड का उपयोग क्लास को उसके अपने नाम से अलग कर देता है, जिससे समय के साथ कोड बनाए रखना आसान हो जाता है।

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

संदर्भ को मौजूदा वंशज क्लास से देर से जोड़ने के लिए स्कोप रिज़ॉल्यूशन ऑपरेटर के साथ `static` कीवर्ड का उपयोग कीजिए।

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## स्कोप रिज़ॉल्यूशन ऑपरेटर के साथ `parent` का उपयोग

`parent` कीवर्ड का उपयोग पैरेंट क्लास के कॉन्स्टेंट, प्रॉपर्टी या मेथड का संदर्भ लेने के लिए किया जाता है। आम तौर पर इसका उपयोग तब किया जाता है जब कोई ऑब्जेक्ट बनाया जा रहा हो और पैरेंट कंस्ट्रक्टर को कॉल करना हो:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## सावधानियाँ

### कॉन्स्टेंट, प्रॉपर्टी और मेथड की विज़िबिलिटी

स्कोप रिज़ॉल्यूशन ऑपरेटर फिर भी `public`, `private` और `protected` विज़िबिलिटी मॉडिफायर के तय नियमों का पालन करता है।
