# परिचय

Python एक [डायनामिक और सख्त][dynamic typing in python] टाइप वाली प्रोग्रामिंग भाषा है।
यह [टाइप हिंट][type hints] के ज़रिए [डक टाइपिंग][duck typing] और [ग्रेजुअल टाइपिंग][gradual typing], दोनों का इस्तेमाल करती है।

Python कई अलग-अलग प्रोग्रामिंग _शैलियों_ का समर्थन करती है, लेकिन अंदर से **Python में सब कुछ एक [ऑब्जेक्ट][everythings an object] है**।
इसमें संख्याएँ, स्ट्रिंग, ऐरे, और फंक्शन तक शामिल हैं।

जैसे-जैसे हम ट्रैक में आगे बढ़ेंगे, इन सबका मतलब और गहराई से समझेंगे।

यह पहला अभ्यास Python भाषा की 4 प्रमुख विशेषताओं से परिचित कराता है:
1.  नाम असाइनमेंट (_वेरिएबल और कॉन्स्टेंट_),
2.  फंक्शन (_`def` कीवर्ड और `return` कीवर्ड_),
3.  कमेंट, और
4.  डॉकस्ट्रिंग।

## नाम असाइनमेंट (वेरिएबल और कॉन्स्टेंट)

प्रोग्रामर असाइनमेंट `=` ऑपरेटर की मदद से [_नाम_][facts-and-myths-about-python-names] (जिन्हें _वेरिएबल_ भी कहा जाता है) को किसी भी टाइप के ऑब्जेक्ट से बाँध सकते हैं: `<name> = <value>`.
एक नाम को उसके जीवनकाल में अलग-अलग वैल्यू (अलग-अलग ऑब्जेक्ट टाइप) असाइन किया जा सकता है (या दोबारा बाँधा जा सकता है)।


```python
>>> my_first_variable = 1  #<-- my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  #<-- my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." #<-- You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' #<-- Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### कॉन्स्टेंट

कॉन्स्टेंट ऐसे नाम होते हैं जिन्हें किसी प्रोग्राम में सिर्फ एक बार असाइन करना होता है।
इन्हें [मॉड्यूल][module] (फाइल) लेवल पर परिभाषित करना चाहिए, और आम तौर पर ये प्रोग्राम के सभी फंक्शन और क्लास को दिखाई देते हैं।
`SCREAMING_SNAKE_CASE` इस्तेमाल करने से यह संकेत मिलता है कि नाम को दोबारा असाइन नहीं करना चाहिए, और न ही उसकी वैल्यू बदलनी चाहिए।


## फंक्शन

`def` कीवर्ड एक [फंक्शन डेफिनिशन][function definition] शुरू करता है।
हर फंक्शन में `()` ब्रैकेट के अंदर शून्य या अधिक औपचारिक [पैरामीटर][parameters] हो सकते हैं, जिनके बाद एक `:` कोलन आता है।
फंक्शन के _बॉडी_ के स्टेटमेंट `def` वाली लाइन के बाद की लाइन से शुरू होते हैं और _ब्लॉक में इंडेंट_ होने चाहिए।


```python
# The body of a function is indented by 2 spaces, & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     #this was only indented by 3 spaces
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


फंक्शन [`return`][return] कीवर्ड के ज़रिए कोई वैल्यू या ऑब्जेक्ट _स्पष्ट रूप से_ लौटाते हैं:


```python
# Function definition on first line, explicit return used on final line.
>>> def add_two_numbers(number_one, number_two):
        return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing it 
# will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


जिन फंक्शन में `return` के बाद कोई _स्पष्ट_ एक्सप्रेशन नहीं होता, वे _अपने आप_ [`None`][none] ऑब्जेक्ट लौटा देते हैं।
`None` के ब्यौरे आगे के किसी अभ्यास में देखेंगे।
इस अभ्यास और इस समझाने के लिहाज़ से, `None` एक प्लेसहोल्डर है जो कुछ नहीं, यानी null, दर्शाता है:


```python

# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

जो फंक्शन `return` को छोड़ देते हैं, वे भी _अपने आप_ [`None`][none] ऑब्जेक्ट लौटाते हैं।
इसका मतलब है कि अगर आप किसी फंक्शन में `return` इस्तेमाल नहीं करते, तो Python आपके लिए `None` ऑब्जेक्ट लौटा देगा।

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


### फंक्शन को कॉल करना

फंक्शन को उसका नाम लिखकर और उसके बाद `()` लगाकर [_कॉल_][calls] किया जाता है।
किसी क्लास या मॉड्यूल के अंदर परिभाषित फंक्शन को कॉल करने के लिए डॉट (`.`) नोटेशन इस्तेमाल होता है।

```python
>>> def raise_to_power(number, power):
...     return number ** power
...

>>> raise_to_power(3,3) # <--Invoking the function with the arguments 3 and 3.
27


# A mismatch between the number of parameters and the number of arguments will raise an error.
>>> raise_to_power(4,)
...
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: raise_to_power() missing 1 required positional argument: 'power'


# Calling methods or functions in classes and modules.
>>> start_text = "my silly sentence for examples."
>>> str.upper(start_text)  # <--Calling the upper() method from the built-in str class on start_text.
'MY SILLY SENTENCE FOR EXAMPLES.'


# Importing the math module
>>> import math

>>> math.pow(2,4)  # <--Calling the pow() function from the math module.
16.0
```


## कमेंट

Python में [कमेंट][comments] `#` से शुरू होते हैं, जो किसी स्ट्रिंग का हिस्सा नहीं होता, और लाइन खत्म होने पर समाप्त हो जाते हैं।
कई दूसरी प्रोग्रामिंग भाषाओं के उलट, Python मल्टी-लाइन कमेंट मार्क **सपोर्ट नहीं करता**।
कमेंट ब्लॉक की हर लाइन `#` अक्षर से शुरू होनी चाहिए।


## डॉकस्ट्रिंग

किसी फंक्शन बॉडी का पहला स्टेटमेंट चाहें तो एक [_डॉकस्ट्रिंग_][docstring] हो सकता है, जो फंक्शन या ऑब्जेक्ट के उद्देश्य को संक्षेप में बताता है।
डॉकस्ट्रिंग ट्रिपल डबल कोट्स (""") से घोषित की जाती हैं और कोड ब्लॉक के समान लेवल पर इंडेंट होती हैं:

डॉकस्ट्रिंग को [Sphinx][sphinx] जैसे ऑटोमेटेड डॉक्युमेंटेशन टूल पढ़ते हैं, और फंक्शन, मेथड या क्लास के नाम पर खास एट्रिब्यूट `.__doc__` कॉल करके इन्हें पाया जा सकता है।
डॉकस्ट्रिंग के सामान्य कन्वेंशन [PEP257][pep257] में दिए गए हैं, लेकिन सटीक फॉर्मैट प्रोजेक्ट और टीम के हिसाब से बदलते हैं।
Exercism के कॉन्सेप्ट अभ्यास बिना टाइप हिंट वाले कोड के लिए Google स्टाइल अपनाने की कोशिश करते हैं।

डॉकस्ट्रिंग [हल्के यूनिट टेस्ट][doctests] की तरह भी काम कर सकती हैं, जिन्हें आगे के किसी अभ्यास में समझाया जाएगा।


```python
# An example on a user-defined function using a Google style docstring. 
>>> def raise_to_power(number, power):
    """Raise a number to an arbitrary power.

    Parameters:
        number (int): The base number.
        power (int): The power to raise the base number to.
    
    Returns:
        int: The number raised to the specified power.
    
    Takes a number and raises it to the specified power, returning the result.

    """

    return number ** power
...

# Calling the .__doc__ attribute of the function and printing the result.
>>> print(raise_to_power.__doc__)

Parameters:
    number (int): The base number.
    power (int): The power to raise the base number to.

Returns:
    int: The number raised to the specified power.

Takes a number and raises it to the specified power, returning the result.
```
