# परिचय

कई भाषाओं की तरह Ruby में भी एक्सेप्शन अचानक होने वाली घटनाओं से निपटने का तरीका देते हैं। जब आप अपने प्रोग्राम को क्रैश होने से बचाना चाहते हैं, तो एक्सेप्शन को ठीक से संभालना ज़रूरी होता है।

जब कोई एक्सेप्शन उत्पन्न होता है, चाहे आपने उसे स्पष्ट रूप से उत्पन्न किया हो या Ruby इंटरप्रेटर ने, तो प्रोग्राम अपना सामान्य काम छोड़ देता है और अंत में एक एरर संदेश के साथ बंद हो जाता है:

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

अगर हम चाहते हैं कि प्रोग्राम इस तरह बंद न हो, तो हमें उस एक्सेप्शन पर प्रतिक्रिया देनी होगी। इसी को किसी एक्सेप्शन को "rescue" करना कहते हैं:

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

यह प्रोग्राम क्रैश नहीं होगा और "Got an exception" छापेगा। बंद होने के बजाय Ruby rescue ब्लॉक के अंदर का कोड चलाता है, जो एक संदेश छापता है।

Ruby में बाकी सब चीज़ों की तरह एक्सेप्शन भी ऑब्जेक्ट होते हैं, और उनमें आम तौर पर उस एक्सेप्शन से जुड़ी जानकारी रहती है। इस तरह हम एक्सेप्शन ऑब्जेक्ट पा सकते हैं:

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

Ruby में आप अपने खुद के एक्सेप्शन भी उत्पन्न कर सकते हैं। उदाहरण के लिए:

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

पिछला एक्सेप्शन Ruby में पहले से मौजूद एक्सेप्शन में से एक है, लेकिन कस्टम एक्सेप्शन बनाकर उन्हें उत्पन्न करना भी संभव है:

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
