## निर्देश

आपको Mickey और Minerva के लिए परफेक्ट भूलभुलैया बनानी है। ऐसी भूलभुलैया का सिर्फ एक ही हल होता है और उसमें कोई अलग-थलग हिस्सा नहीं होता। आपको ये बातें पता होनी चाहिए:

- भूलभुलैया आयताकार होती है, और उसके शुरू तथा अंत में एक-एक द्वार होता है।
- भूलभुलैया में कमरे और गलियारे होते हैं, जो एक-दूसरे से समकोण पर मिलते हैं।
- प्रोग्राम को दो पैरामीटर लेने चाहिए: रो और कॉलम। भूलभुलैया का आकार 5 से 100 खानों के बीच होना चाहिए।
- जो भूलभुलैया `x` कॉलम चौड़ी और `y` रो ऊँची होती है, वह `2x + 1` अक्षर चौड़ी और `2y + 1` अक्षर ऊँची होनी चाहिए।
- अगर कोई सीड न दिया जाए, तो एक रैंडम भूलभुलैया बनाइए। अगर एक ही सीड कई बार दिया जाए, तो हर बार वही भूलभुलैया बननी चाहिए।
- दीवारें खींचने के लिए [बॉक्स-ड्रॉइंग][Box-drawing] अक्षरों का इस्तेमाल कीजिए, और बाईं ओर के प्रवेश द्वार तथा दाईं ओर के निकास के लिए तीर का चिह्न (⇨) लगाइए।

अब इन साहसी चूहों के लिए कुछ परफेक्ट भूलभुलैया बनाने का समय है!

### उदाहरण

1. छोटी वर्गाकार भूलभुलैया 5x5 खाने (या 11x11 अक्षर)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. आयताकार भूलभुलैया 6x18 खाने
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
