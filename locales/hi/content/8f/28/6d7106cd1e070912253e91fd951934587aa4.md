# परिचय

`try..rescue` का उपयोग एरर पकड़ने का एक शक्तिशाली तरीका है, जब वे होती हैं। एरर पकड़ने से फंक्शन ज़रूरत पड़ने पर तय वैल्यू लौटा पाते हैं। `try..rescue` का यह तरीका हमें दो और सुविधाएँ भी देता है जिनका हम उपयोग कर सकते हैं:

- `else` ब्लॉक
  - जब try ब्लॉक सफल होता है, तो परिणाम का मिलान इस ब्लॉक से किया जाता है।
- `after` ब्लॉक
  - try ब्लॉक सफल हो या एरर उठाए, `after` ब्लॉक का कोड हमेशा चलाया जाता है, जब तक उस समय प्रोग्राम चल रहा हो।
  - `after` ब्लॉक का परिणाम कॉल करने वाले स्कोप को नहीं लौटाया जाता।

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
