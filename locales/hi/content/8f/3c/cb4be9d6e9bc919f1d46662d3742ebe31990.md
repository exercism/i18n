# निर्देश

आज वैलेंटाइन डे है। आपके साथी के पास कुछ गतिविधियों के आइडिया हैं और वे चाहते हैं कि आप हर एक को रेट करें: `yes`, `no` या `maybe`।

गतिविधियों को 2 एलिमेंट वाले ऐरे `{ tag value }` के रूप में दर्शाया जाता है, जहाँ `tag` इनमें से एक है: `board-game`, `chill`, `movie`, `restaurant` या `walk`।

| गतिविधि                   | रूप                         |
| ------------------------- | --------------------------- |
| बोर्ड गेम खेलना           | `{ board-game f }`          |
| आराम करना                 | `{ chill f }`               |
| `genre` की फिल्म देखना    | `{ movie genre }`           |
| किसी `cuisine` रेस्टोरेंट में खाना खाना | `{ restaurant cuisine }`    |
| `km` किलोमीटर टहलना       | `{ walk km }`               |

`genre` इनमें से एक है: `crime`, `horror`, `romance`, `thriller`। `cuisine` `korean` या `turkish` होती है।

## 1. क्यूज़ीन को रेट कीजिए

`rate-restaurant` बनाइए, जो स्टैक से एक क्यूज़ीन लेता है और आपकी स्वीकृति लौटाता है:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. फिल्म के जॉनर को रेट कीजिए

`rate-movie` बनाइए, जो एक जॉनर लेता है और लौटाता है:

- `romance` → `yes`
- बाकी कुछ भी → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. टहलने को रेट कीजिए

`rate-walk` बनाइए, जो किलोमीटर की एक संख्या लेता है और लौटाता है:

- `11` से ज़्यादा → `yes`
- `6` से ज़्यादा, `11` तक → `maybe`
- बाकी मामलों में → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. गतिविधि को रेट कीजिए

`rate-activity` बनाइए, जो स्टैक से एक `{ tag value }` गतिविधि लेता है और आपकी स्वीकृति लौटाता है। ऊपर बनाए हेल्पर दोबारा इस्तेमाल कीजिए:

- `board-game`, `chill` → हमेशा `no`
- `movie` → `rate-movie` को सौंप दीजिए
- `restaurant` → `rate-restaurant` को सौंप दीजिए
- `walk` → `rate-walk` को सौंप दीजिए

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. स्वीकृतियों की गिनती कीजिए

`approval-counts` बनाइए, जो गतिविधियों का एक ऐरे लेता है और 3 एलिमेंट वाला ऐरे `{ yes-count maybe-count no-count }` लौटाता है, जिसमें यह बताया जाता है कि कितनी गतिविधियों को किस तरह रेट किया गया।

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
