# टेस्ट

## Clojure CLI

Exercism पर Clojure के अभ्यासों के साथ एक `deps.edn` फ़ाइल मिलती है, जिसमें एक `:test` एलियस होता है जो [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) को चलाता है:

``` bash
$ clj -X:test
```

यह आपके प्रोजेक्ट की `test` डायरेक्टरी को स्कैन करेगा और `clojure.test` का उपयोग करके लिखे गए सभी टेस्ट ढूँढकर उन्हें चलाएगा।

## Leiningen

Leiningen से किसी अभ्यास के टेस्ट चलाने के लिए बस यह कमांड चलाइए:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
