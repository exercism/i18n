# परिचय

`if` स्टेटमेंट के अलावा `switch` स्टेटमेंट भी होता है, जिससे शर्त के आधार पर लॉजिक लागू किया जा सकता है। इसका उपयोग तब किया जाता है जब किसी एक वेरिएबल की तुलना कई अलग-अलग विकल्पों से करनी होती है। Haxe में किसी वेरिएबल x के लिए `switch` स्टेटमेंट का सिंटैक्स इस प्रकार है।

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

`default` केस तब निष्पादित होता है जब कोई अन्य केस मेल नहीं खाता।
