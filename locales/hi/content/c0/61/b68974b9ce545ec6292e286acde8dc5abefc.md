# परिचय

स्ट्रक्ट या क्लास के हर इंस्टेंस में `self` नाम की एक अंतर्निहित प्रॉपर्टी होती है, जो उस इंस्टेंस को ही दर्शाती है।
`self` का सबसे आम उपयोग एक ही नाम वाली इंस्टेंस प्रॉपर्टी और पैरामीटर के बीच फर्क साफ करना है:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift के टाइप बड़े अक्षर से लिखा गया `Self` कीवर्ड भी देते हैं, जो इंस्टेंस के बजाय उसके *टाइप* को दर्शाता है।
