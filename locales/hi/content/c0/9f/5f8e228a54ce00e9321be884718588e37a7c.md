# निर्देश

रिमोट कंट्रोल कार प्रोजेक्ट पर काम आगे बढ़ रहा है। टेलीमेट्री सिस्टम में बैंडविड्थ बहुत सीमित है, इसलिए आपसे टेलीमेट्री डेटा के आदान-प्रदान के लिए एक मैसेज प्रोटोकॉल बनाने को कहा गया है।

डेटा एक बफर (बाइट ऐरे) में भेजा जाता है। पूर्णांक भेजते समय नीचे बताए गए प्रोटोकॉल का उपयोग करके बफर का आकार घटा दिया जाता है।

हर वैल्यू को सबसे छोटे संभव पूर्णांक टाइप में दर्शाना चाहिए (`byte` और `sbyte` टाइप इसमें शामिल नहीं हैं, क्योंकि उनसे बचत बहुत कम होगी):

| से                         | तक                        | टाइप     |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

वैल्यू को उसके असाइन किए गए टाइप के लिए ज़रूरी बाइट्स की संख्या में बदलना चाहिए। पूरा बफर दो हिस्सों से बनता है: पहला वह बाइट जो बताता है कि बफर में कितने अतिरिक्त बाइट हैं (_प्रीफिक्स बाइट_), और उसके बाद वे बाइट जिनमें पूर्णांक रखा जाता है (_पेलोड बाइट_)।

कुछ टाइप बाइट्स की एक ही संख्या इस्तेमाल करते हैं (जैसे `uint` और `int` टाइप)। आम तौर पर इनका _प्रीफिक्स बाइट_ एक ही होता, लेकिन तब डिकोड करना मुश्किल हो जाता। इससे बचने के लिए प्रोटोकॉल एक छोटी सी तरकीब लगाता है: साइन वाले टाइपों में _प्रीफिक्स बाइट_ की वैल्यू `256` में से बफर के अतिरिक्त बाइटों की संख्या घटाकर निकलती है।

संचार में सिर्फ प्रीफिक्स बाइट और प्रीफिक्स के बताए अनुसार उसके बाद आने वाले बाइट ही भेजे जाते हैं। अंदरूनी तौर पर भेजने और पाने वाली दोनों रूटीन 9 बाइट का बफर इस्तेमाल करती हैं (ज़रूरत पड़ने पर अंत में शून्य भरकर)।

## 1. भेजने के लिए तैयार पूर्णांक वैल्यू को एनकोड कीजिए

कृपया `TelemetryBuffer.ToBuffer()` स्टैटिक मेथड बनाइए, जो उसे दिए गए पैरामीटर को बफर में एनकोड करे।

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. प्राप्त बफर को डिकोड कीजिए

कृपया `TelemetryBuffer.FromBuffer()` स्टैटिक मेथड बनाइए, जो प्राप्त बफर को डिकोड करके वैल्यू को `long` के रूप में लौटाए।

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

अगर प्रीफिक्स बाइट की वैल्यू अनपेक्षित हो, तो `0` लौटाया जाना चाहिए।
