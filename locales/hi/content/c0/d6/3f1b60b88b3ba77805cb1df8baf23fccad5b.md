# परिचय

कोई `jq` प्रोग्राम जब किसी वैल्यू को प्रोसेस करते समय किसी समस्या में फँस जाता है, तो **रनटाइम एरर** देता है। ऐसा तब होता है जब किसी संख्या को स्ट्रिंग से इंडेक्स किया जाए, अमान्य JSON टेक्स्ट को पार्स किया जाए, या किसी फंक्शन को गलत टाइप का आर्गुमेंट देकर कॉल किया जाए। जो रनटाइम एरर पकड़ी नहीं जाती, उस पर `jq` _स्टैंडर्ड एरर_ पर एक संदेश प्रिंट करता है और एग्ज़िट स्टेटस `5` के साथ बाहर निकल जाता है।

## एरर देना: `error` और `error(message)`

- `error` एक एरर देता है जिसकी वैल्यू **इनपुट** वैल्यू होती है।
- `error(message)` एक एरर देता है जिसकी वैल्यू `message` के परिणाम से बनती है।

एरर की वैल्यू कोई भी JSON वैल्यू हो सकती है, सिर्फ स्ट्रिंग नहीं।

```jq
42 | error("invalid value: \(.)")
# => "invalid value: 42"

42 | error
(not a string): 42
```

## एरर पकड़ना: `try` और `catch`

एरर को `try EXP catch HANDLER` से पकड़ा जा सकता है। पहला एक्सप्रेशन चलाया जाता है; अगर उससे एरर मिलती है, तो `HANDLER` एक्सप्रेशन **एरर वैल्यू को अपने इनपुट के रूप में लेकर** चलाया जाता है। `try catch` का आउटपुट वही होता है जो उस एक्सप्रेशन से मिलता है जो सबसे बाद में चला हो (यानी `EXP` या `HANDLER`)।

```jq
{a: 42} | try .a catch "no index a in \(.)"
# => 42

true | try .a catch "cannot index a \(type)"
# => "cannot index a boolean"

true | try error("some exception") catch .
# => "some exception"
```

छोटा रूप `try EXP`, `try EXP catch empty` के बराबर है: एरर को छोड़ दिया जाता है और कोई आउटपुट नहीं मिलता।

```jq
[{}, true, {"a": 1}] | [.[] | try .a]
# => [null, 1]
```

## एरर अनदेखा करना: `?` ऑपरेटर

`?` ऑपरेटर, जब `EXP?` की तरह इस्तेमाल होता है, `try EXP` का छोटा रूप है। यह किसी फेल होने वाले एक्सप्रेशन को ऐसे एक्सप्रेशन में बदल देता है जो बस कोई आउटपुट नहीं देता।

```jq
["1", "invalid", "3", 4] | [.[] | tonumber?]
# => [1, 3, 4]
```

इसे अक्सर इंडेक्सिंग ऑपरेटरों के साथ लगा देखा जाता है: `.foo?` और `.[]?`.

## प्रोग्राम रोकना: `halt_error` और `halt`

`halt_error` प्रोग्राम को रोक देता है, उसका इनपुट _स्टैंडर्ड एरर_ पर कच्चे टेक्स्ट के रूप में प्रिंट करता है, और दिए गए स्टेटस के साथ बाहर निकलता है, जिसका डिफ़ॉल्ट `5` है। इससे जुड़ा `halt` फिल्टर बिना कुछ प्रिंट किए प्रोग्राम को रोक देता है, एग्ज़िट स्टेटस `0` के साथ।

```jq
"Error: something went wrong" | halt_error(1)
```
