# निर्देश

यह स्थानीय क्लब में सीज़न का अंतिम मुकाबला है। आप फिनिश लाइन पर लीडरबोर्ड संभाल रहे हैं: धावक क्रम से फिनिश लाइन पार करते हैं, लेनों पर लेबल लगाने हैं, और अगले दौर से पहले आधिकारिक बहीखाते में टिप्पणी करनी है।

धावकों के नाम एक ऐरे में, फिनिश के क्रम में मिलते हैं: ऐरे का पहला नाम (इंडेक्स 0) विजेता का होता है, अगला उपविजेता का, और इसी तरह आगे।

## 1. बिब असाइन कीजिए

`assign-bibs` को परिभाषित कीजिए। यह धावकों के नामों का एक ऐरे लेता है और `{ position name }` जोड़ों का ऐरे लौटाता है, जिनमें हर जोड़े में पहले स्थान और फिर नाम आता है।

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. लेन के लेबल

`lane-labels` को परिभाषित कीजिए। यह धावकों के नामों का एक ऐरे लेता है और `"Lane 0: Bolt"` जैसी स्ट्रिंग लौटाता है।

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. धावकों को टैग कीजिए

`tag-racers` को परिभाषित कीजिए। यह धावकों के नामों का एक ऐरे *और* एक टैग स्ट्रिंग लेता है, और `"<tag>/<index>: <name>"` रूप के लेबल लौटाता है। हर लेबल में वही टैग डाला जाता है।

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. फिनिश दर्ज कीजिए

`record-finishes` को परिभाषित कीजिए। यह धावकों के नामों का एक ऐरे और एक बहीखाता (एक वेक्टर) लेता है। हर धावक के लिए, यह बहीखाते में वहीं `"<index>: <name>"` रूप की एक स्ट्रिंग जोड़ देता है। यह कुछ नहीं लौटाता।

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. लैप की घंटियाँ

`lap-bells` को परिभाषित कीजिए। यह एक संख्या `laps` लेता है और `laps` बार दोहराई गई `"ding "` से बनी स्ट्रिंग लौटाता है।

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
