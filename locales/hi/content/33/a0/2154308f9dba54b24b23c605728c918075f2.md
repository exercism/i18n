# परिचय

## ऐरे

Gleam में ऐरे शून्य या अधिक वैल्यू का एक अपरिवर्तनीय संग्रह होता है। ऐरे की सभी वैल्यू का टाइप एक ही होना चाहिए। चूँकि ऐरे अपरिवर्तनीय होते हैं, इसलिए एक बार ऐरे बन जाने के बाद उस ऐरे की वैल्यू कभी नहीं बदल सकती। ऐसा दिखने वाला कोई भी फंक्शन या ऑपरेटर जो ऐरे को बदलता प्रतीत होता है (जैसे कोई एलिमेंट जोड़ना), वास्तव में एक नया ऐरे लौटाता है।

ऐरे इस तरह बनाए जा सकते हैं:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

ऐरे में एलिमेंट जोड़ने का सबसे आम तरीका स्प्रेड सिंटैक्स है:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam की स्टैंडर्ड लाइब्रेरी में [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) मॉड्यूल में ऐरे के साथ काम करने के लिए कई उपयोगी फंक्शन हैं। यह मॉड्यूल Gleam कोड में बहुत इस्तेमाल किया जाता है, इसलिए इससे परिचित होना अच्छा है।

`case` एक्सप्रेशन में ऐरे पैटर्न इस्तेमाल करके ऐरे से मैच किया जा सकता है और उसमें मौजूद वैल्यू को वेरिएबल में असाइन किया जा सकता है:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

ठीक-ठीक लंबाई वाले ऐरे से मैच करने के अलावा, स्प्रेड सिंटैक्स से कम-से-कम एक तय लंबाई वाले ऐरे से भी मैच किया जा सकता है:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

स्प्रेड सिंटैक्स का इस्तेमाल ऐरे के बाकी हिस्से को किसी वेरिएबल में असाइन करने के लिए भी किया जा सकता है:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

`case` एक्सप्रेशन में उस टाइप की हर संभव वैल्यू के लिए एक पैटर्न होना चाहिए जिससे मैच किया जा रहा है, इसलिए बची हुई वैल्यू को संभालने के लिए अक्सर अंत में एक डिस्कार्ड पैटर्न (`_`) लिखा जाता है।
