# निर्देश

इस अभ्यास में आप एक ऐरे बनाने का कोड लिखेंगे, जिसमें उन प्रोग्रामिंग भाषाओं का हिसाब रखा जाएगा जिन्हें आप Exercism पर सीखना चाहते हैं।

आपके सामने नौ काम हैं, और इन सभी में ऐरे से जुड़ा काम करना होगा।

## 1. नया ऐरे बनाइए

जिन भाषाओं को आप सीखना चाहते हैं, उनका हिसाब रखने के लिए आपको एक नया ऐरे बनाना होगा।

उस स्टैटिक `Languages.NewList()` मेथड को लागू कीजिए जो एक नया, खाली ऐरे लौटाता है।

```csharp
Languages.NewList()
// => empty list
```

## 2. मौजूदा ऐरे परिभाषित कीजिए

इस समय आपके पास एक कागज़ है, जिस पर उन भाषाओं की सूची लिखी है जिन्हें आप सीखना चाहते हैं: C#, Clojure और Elm।

कृपया स्टैटिक `Languages.GetExistingLanguages()` मेथड को लागू कीजिए, जो यही ऐरे लौटाता है।

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. ऐरे में नई भाषा जोड़िए

जैसे-जैसे आप Exercism को खोजते हैं और आपको और भी दिलचस्प भाषाएँ मिलती हैं, आप उन्हें अपने ऐरे में जोड़ना चाहते हैं।

उस स्टैटिक `Languages.AddLanguage()` फंक्शन को लागू कीजिए जो आपके ऐरे के अंत में एक नई भाषा जोड़ता है।

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. ऐरे में भाषाओं की गिनती कीजिए

भाषाओं को एक-एक करके गिनना असुविधाजनक है।

उस स्टैटिक `Languages.CountLanguages()` मेथड को लागू कीजिए जो आपके ऐरे में भाषाओं की संख्या गिनता है।

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. जाँचिए कि भाषा ऐरे में है या नहीं

उस स्टैटिक `Languages.HasLanguage()` मेथड को लागू कीजिए जो जाँचता है कि कोई भाषा मौजूद है या नहीं।

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. ऐरे को उलटिए

किसी समय आपको पता चलता है कि आपका ऐरे वास्तव में उलटे क्रम में है!

अपने ऐरे को उलटने के लिए स्टैटिक `Languages.ReverseList()` मेथड को लागू कीजिए।

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. जाँचिए कि ऐरे रोमांचक है या नहीं

आपको सभी भाषाएँ पसंद हैं, पर C# का दिल में एक खास स्थान है। इसी वजह से भाषाओं का कोई ऐरे आपके लिए रोमांचक होता है, अगर इनमें से कोई एक शर्त सही हो:

- ऐरे में सबसे पहली भाषा C# है।
- ऐरे में दूसरी भाषा C# है और ऐरे में या तो दो या तीन भाषाएँ हैं।

यह जाँचने के लिए कि भाषाओं का कोई ऐरे रोमांचक है या नहीं, स्टैटिक `Languages.IsExciting()` मेथड को लागू कीजिए:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Remove Language

कृपया स्टैटिक `Languages.RemoveLanguage()` मेथड को लागू कीजिए, जो ऐरे से बताई गई भाषा हटाता है।

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. जाँचिए कि ऐरे की सभी भाषाएँ अलग-अलग हैं

कृपया स्टैटिक `Languages.IsUnique()` मेथड को लागू कीजिए, जो जाँचता है कि ऐरे में कोई भाषा दोहराई गई है या नहीं।

जब यह मेथड कॉल किया जाता है, तब भाषाओं का ऐरे (यानी पैरामीटर) खाली नहीं होगा, इसकी गारंटी है। और इससे कोई फर्क नहीं पड़ता कि ऐरे बदला गया है या नहीं।

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
