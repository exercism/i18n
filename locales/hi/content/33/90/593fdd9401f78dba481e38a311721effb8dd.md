# निर्देशों का परिशिष्ट

## कार्यान्वयन

इस अभ्यास में आपको एक ऐसा प्रोसीजर बनाना है जिसका काम यह है कि जिस स्ट्रिंग को वह लौटाता है, उसके लिए मेमोरी आवंटित करे। उस स्ट्रिंग की मेमोरी मुक्त करना प्रोसीजर को कॉल करने वाले का काम है।

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
