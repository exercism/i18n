# टेस्ट

किसी अभ्यास को डाउनलोड करने के लिए, जैसे `hello-world`, टर्मिनल खोलिए और यह चलाइए:

```bash
exercism download --track roc --exercise hello-world
```

इसके बाद अभ्यास वाली डायरेक्टरी में जाइए और कोड बदलकर अभ्यास हल कीजिए। जैसे:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

हर अभ्यास के साथ एक टेस्ट सूट मिलता है। आप `roc test` कमांड से टेस्ट चला सकते हैं, जैसे:

```
roc test hello-world-test.roc
```

अगर आपने अभ्यास हल कर लिया है, तो आपको 0 फेल टेस्ट दिखने चाहिए। जैसे:

```
All (5) tests passed in 123.4 ms.
```

लेकिन अगर आपके कोड में कोई एरर है, तो वह ऐसी दिखेगी:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

इससे आपको अपना कोड ठीक करने में मदद मिलेगी। जब आपका कोड चलने लगे, तो आप उसे `exercism submit` कमांड से सबमिट कर सकते हैं (ज़्यादा जानकारी के लिए अभ्यास वाली डायरेक्टरी में `HELP.md` देखिए)।
