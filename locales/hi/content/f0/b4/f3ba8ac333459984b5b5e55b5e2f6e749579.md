# परिचय

अगर पैरामीटर के टाइप का अनुमान लगाया जा सके, तो Swift क्लोज़र की परिभाषा से पैरामीटर के नाम और `in` कीवर्ड छोड़ने की सुविधा भी देता है। इसके बजाय पैरामीटर को एक [खास संक्षिप्त सिंटैक्स][shorthand-argument-names] से दर्शाया जा सकता है, जिसमें `$0` पहले पैरामीटर को दर्शाता है, `$1` दूसरे को, और इसी तरह आगे भी।

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

यह तरीका अधिकतर तब इस्तेमाल होता है जब क्लोज़र को हायर-ऑर्डर फंक्शन में पास किया जाता है और संक्षिप्तता को महत्व दिया जाता है।

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
