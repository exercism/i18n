# वापसी

Crystal में, किसी मेथड का अंतिम एक्सप्रेशन उसकी वैल्यू लौटाता है।
लेकिन कभी-कभी आपको अंतिम एक्सप्रेशन से पहले ही कोई वैल्यू लौटानी होती है।
इसके लिए आप `return` कीवर्ड इस्तेमाल कर सकते हैं, जो अपने बाद वाले एक्सप्रेशन की वैल्यू लौटाता है।
`return` कीवर्ड के बाद लिखा गया कोड चलाया नहीं जाएगा।

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
जब किसी मेथड का अंतिम एक्सप्रेशन ही वह वैल्यू हो जिसे लौटाया जाना चाहिए, तब `return` कीवर्ड छोड़ देना चाहिए।
~~~~
