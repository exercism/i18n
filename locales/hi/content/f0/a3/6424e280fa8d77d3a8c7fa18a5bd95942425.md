# अधिक जानकारी

## ऑप्शनल

स्विफ्ट में [_ऑप्शनल_][optionals] की मदद से प्रोग्रामर यह जता सकते हैं कि कोई वैल्यू मौजूद न भी हो सकती है।
ऑप्शनल एक ऐसा टाइप है जो या तो कोई वैल्यू रख सकता है या [`nil`][nil] हो सकता है, और `nil` का मतलब है कि कोई वैल्यू मौजूद नहीं है।
किसी ऑप्शनल का उपयोग करने से पहले प्रोग्राम को यह जाँचना पड़ता है कि कोई वैल्यू मौजूद है या नहीं; उसे अनरैप करने के बाद ही उस वैल्यू का उपयोग किया जा सकता है।

किसी भी टाइप के नाम के अंत में `?` लगाकर उसे ऑप्शनल बनाया जा सकता है।
तो ऑप्शनल पूर्णांक का टाइप `Int?` होगा और ऑप्शनल स्ट्रिंग का टाइप `String?`।
ऑप्शनल टाइप के कॉन्स्टेंट या वेरिएबल बनाना और उन्हें वैल्यू असाइन करना उसी तरह होता है जैसे नॉन-ऑप्शनल टाइप की वैल्यू के लिए।

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

आप ऑप्शनल टाइप के वेरिएबल को खास वैल्यू `nil` असाइन करके यह जता सकते हैं कि उसमें कोई वैल्यू नहीं है।
`nil` हर ऑप्शनल टाइप के साथ इस्तेमाल किया जा सकता है, लेकिन दो अलग-अलग ऑप्शनल टाइप को दिए गए `nil` का टाइप एक जैसा नहीं होता। ऐसे `nil` को एक-दूसरे की जगह इस्तेमाल नहीं किया जा सकता, और न ही उनकी तुलना की जा सकती है।

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

यह भी ध्यान रखें कि `nil` किसी भी ऑप्शनल टाइप को असाइन किया जा सकता है, लेकिन नॉन-ऑप्शनल टाइप को नहीं (भले ही उस वेरिएबल में वास्तव में `nil` न हो)।
और जिस मेथड को नॉन-ऑप्शनल टाइप चाहिए, उसे पहले अनरैप किए बिना कोई ऑप्शनल टाइप नहीं दिया जा सकता।

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## ऑप्शनल का उपयोग

ऑप्शनल टाइप अपने बेस टाइप से अलग टाइप होते हैं, इसलिए दोनों का इस्तेमाल एक ही तरह से नहीं किया जा सकता।
उदाहरण के लिए: `Int("123") + 1` लिखने पर कंपाइलर एरर मिलती है: "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'"।
ऐसा इसलिए होता है क्योंकि `Int("123")` एक ऑप्शनल `Int?` टाइप लौटाता है, `Int` टाइप नहीं, क्योंकि अगर स्ट्रिंग को पूर्णांक में बदला न जा सके तो नतीजा `nil` होता है।
बदलाव के बाद मिले `Int` तक पहुँचने के लिए पहले उसे "अनरैप" करना पड़ता है।

स्विफ्ट में यह काम आमतौर पर [_ऑप्शनल बाइंडिंग_][optional-binding] के लिए इस्तेमाल होने वाले `if-let` और `guard-let` से किया जाता है।
ये जाँचते हैं कि वैल्यू `nil` है या नहीं। अगर वैल्यू मौजूद है, तो अनरैप की गई वैल्यू किसी दिए गए नाम से बाँध दी जाती है और कोड एक रास्ते पर चलता है; अगर `nil` मिला, तो कोड दूसरे रास्ते पर चला जाता है।

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

ध्यान देने वाली बात यह है कि `safeNum` वेरिएबल का टाइप `Int` है, `Int?` नहीं।
नीचे दिए उदाहरण में `num` का टाइप `Int?` है और `safeNum` का टाइप `Int`।

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

यह _ऑप्शनल बाइंडिंग_ इसलिए ज़रूरी है क्योंकि यह वैल्यू से ऑप्शनल टाइप को अनरैप (यानी हटा) देती है, जिससे उस वैल्यू को नॉन-ऑप्शनल वैल्यू की तरह इस्तेमाल किया जा सकता है।
अगर आप सिर्फ यह शर्त जाँचें कि वैल्यू `nil` है या नहीं, तो भी वैल्यू का टाइप ऑप्शनल ही रहेगा:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

जहाँ फंक्शन से जल्दी बाहर निकलना ज़रूरी हो, वहाँ `guard-let` का इस्तेमाल भी किया जा सकता है:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## ऑप्शनल की तुलना

ध्यान दें कि ऑप्शनल के जोड़े के बेस टाइप की तुलना भले ही आम तुलना ऑपरेटरों से की जा सकती हो, ऑप्शनल की खुद की तुलना नहीं की जा सकती।
उनकी सिर्फ बराबरी जाँची जा सकती है।
दो ऑप्शनल तब बराबर होते हैं जब वे दोनों `nil` हों, या जब उनके अंदर की वैल्यू अपने बेस टाइप के हिसाब से बराबर हों।

लेकिन दो ऑप्शनल वैल्यू की अपनी तरह से तुलना करने के लिए कोड लिखा जा सकता है।
नीचे एक `switch` स्टेटमेंट का उदाहरण है, जो `true` तभी लौटाता है जब दोनों ऑप्शनल वैल्यू नॉन-निल हों और पहली वैल्यू दूसरी से छोटी हो।
इसके लिए यह _ऑप्शनल पैटर्न_ `varName?` का इस्तेमाल करता है, जो सिर्फ नॉन-निल ऑप्शनल से मेल खाता है और ऑप्शनल के अंदर की वैल्यू को `varName` नाम से बाँध देता है।

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```

## निल कोएलसिंग

अनरैप करने का एक और तरीका भी है: अगर `nil` मौजूद हो तो [फॉलबैक वैल्यू][fallback] का इस्तेमाल किया जा सकता है।
यह _निल कोएलसिंग ऑपरेटर_ `??` से किया जा सकता है। मान लीजिए `x` एक `Int?` है। अगर आप `let y = x ?? 0` लिखें, तो स्विफ्ट जाँचेगा कि x में `nil` है या नहीं।
अगर नहीं है, तो वह `x` को अनरैप करके अनरैप की गई वैल्यू `y` को असाइन कर देगा। और अगर `x` में `nil` _है_, तो वह `y` को 0 असाइन करेगा।

चूँकि `x ?? y` मूल रूप से `x != nil ? x! : y` का संक्षिप्त रूप है, इसलिए अगर `x` निल नहीं है, तो एक्सप्रेशन `y` का मूल्यांकन ही नहीं होता।

अंत में, यह ध्यान देना ज़रूरी है कि निल कोएलसिंग ऑपरेटर राइट असोसिएटिव है, जिससे अनजान लोगों को चौंकाने वाले नतीजे मिल सकते हैं।

```swift
let k = 42 ?? 0 + 1    // returns 42
let j = nil ?? 0 + 1   // returns 1
```
