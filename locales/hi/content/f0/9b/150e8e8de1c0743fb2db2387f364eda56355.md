# डीबगिंग

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] एक एक्सप्रेशन है जो एक वैल्यू लौटाता है।
Pyret किसी कोड ब्लॉक के अंदर सिर्फ एक ही एक्सप्रेशन की अनुमति देता है, जब तक कि बाहरी ब्लॉक को `block` से चिह्नित न किया गया हो।
दूसरे उदाहरण में फंक्शन की घोषणा में `block` जोड़ने पर हम 42 को लौटाने से पहले उसे प्रिंट कर पाते हैं।

## `spy`

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

एक `spy` स्टेटमेंट एक वैकल्पिक लेबल और एक या अधिक वेरिएबल लेता है, और हर वेरिएबल तथा उसकी वैल्यू बताता है।
चूँकि `spy` एक एक्सप्रेशन नहीं है, इसे किसी ब्लॉक में इस्तेमाल किया जा सकता है और बाहरी ब्लॉक को `block` से चिह्नित करने की ज़रूरत नहीं होती।
