# विवरण

Elm में [`List`][lists] एक ही टाइप की शून्य या अधिक वैल्यू का अपरिवर्तनीय संग्रह होता है। ऐरे अपरिवर्तनीय होते हैं, यानी एक बार ऐरे बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती। Elm के ऐरे का एक _सिर_ होता है, यानी पहला एलिमेंट, और एक _पूँछ_, यानी पहले एलिमेंट के बाद का सब कुछ। किसी ऐरे की पूँछ खुद भी एक ऐरे होती है।

ऐरे के टाइप एनोटेशन इस तरह लिखे जा सकते हैं:

```elm
List String --> a list of String
List Int --> a list of Int
```

ऐरे इस तरह बनाए जा सकते हैं:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

ऐरे में एलिमेंट जोड़ने का सबसे आम तरीका `::` (कॉन्स) ऑपरेटर है:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

ऐरे को `++` ऑपरेटर या `List.append` की मदद से जोड़ा जा सकता है:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

ऐरे पर काम वे फंक्शन और ऑपरेटर करते हैं जो [`List` मॉड्यूल][list-module] में परिभाषित हैं।

```elm
List.length [ 7, 8 ] --> 2
```

कोई भी फंक्शन या ऑपरेटर जो ऐरे में बदलाव करता दिखता है (जैसे कोई एलिमेंट जोड़ना), वह असल में एक नया ऐरे लौटाता है।
आम तौर पर प्रदर्शन कोई समस्या नहीं होती, क्योंकि ऐरे का कार्यान्वयन अनावश्यक आवंटन और प्रतिलिपियाँ रोक देता है।

ऐरे पर [पैटर्न मैचिंग][list-destructuring] से भी काम किया जा सकता है।

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
