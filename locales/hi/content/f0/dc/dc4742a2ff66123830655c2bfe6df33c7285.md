# परिचय

Factor में आप `: name ( stack-effect ) body ;` से एक नया शब्द बनाते हैं।
इसकी बॉडी शब्दों का एक क्रम होती है, और जब आप अपने नए शब्द को कॉल करते हैं,
तो वे शब्द उसी क्रम में चलते हैं।

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

जब कोई रूटीन बड़ा हो जाता है, तो आप उसे *factor* कर सकते हैं, और करना चाहिए भी:
शब्दों के समूहों को छोटे-छोटे नाम वाले शब्दों में बाँट दीजिए, जिनमें हर एक का अपना
एक ही काम हो। इस भाषा का नाम इसी बात से पड़ा है।

## शब्दावलियाँ

हर `.factor` फाइल `IN:` से एक शब्दावली घोषित करती है। एक शब्दावली के शब्द किसी दूसरी
शब्दावली के शब्दों को भी कॉल कर सकते हैं, अगर `USING:` में उस दूसरी शब्दावली का नाम
लिखा हो।

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

डायरेक्टरी का ढाँचा शब्दावली के डॉट वाले नाम के हिसाब से बनता है: शब्दावली `my-vocab`
फाइल `my-vocab/my-vocab.factor` में रहती है, और शब्दावली `my-vocab.helpers` फाइल
`my-vocab/helpers/helpers.factor` में। Factor का लोडर `USING:` घोषणाओं का एक के बाद एक
अनुसरण करता है और ज़रूरत पड़ने पर हर शब्दावली लोड कर लेता है।
