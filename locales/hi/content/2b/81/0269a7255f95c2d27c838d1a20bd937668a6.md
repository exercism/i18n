# परिचय

Lua संख्याओं को दो रूपों में दर्शाता है: 64-बिट पूर्णांक संख्याएँ और दोहरी परिशुद्धता वाली दशमलव संख्याएँ।

~~~exercism/note
संस्करण 5.3 से पहले, Lua सभी संख्याओं को दोहरी परिशुद्धता वाले दशमलव प्रारूप में दर्शाता था।
~~~

संख्याएँ वैकल्पिक दशमलव भाग के साथ, और वैकल्पिक दशमलव घातांक के साथ लिखी जा सकती हैं।
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

जिस संख्या में दशमलव बिंदु या घातांक होता है, उसे दशमलव संख्या माना जाता है, और जिसमें नहीं होता, उसे पूर्णांक माना जाता है, लेकिन दोनों का टाइप 'number' होता है।
```lua
type(1)         --> number
type(2.0)       --> number
```

अगर हमें दशमलव संख्याओं और पूर्णांकों के बीच फर्क करना हो, तो `math` मॉड्यूल के `type` फंक्शन का उपयोग किया जा सकता है।
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## तुलना

समान वैल्यू वाले पूर्णांक और दशमलव संख्याएँ बराबर माने जाते हैं:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## अंकगणित

Lua सामान्य अंकगणितीय ऑपरेटरों का समर्थन करता है: जोड़, घटाव, गुणा, भाग और ऋणात्मकता। इसके अतिरिक्त यह फ्लोर डिवीजन, मॉड्यूलो और घातांकन का भी समर्थन करता है।

### जोड़, घटाव, गुणा और ऋणात्मकता

अगर दोनों ऑपरेंड पूर्णांक हैं, तो ऑपरेशन का परिणाम पूर्णांक होता है। यही बात दशमलव संख्याओं पर भी लागू होती है।
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

अगर एक ऑपरेंड दशमलव संख्या है, तो बाकी पूर्णांक भी दशमलव संख्याओं में बदल दिए जाते हैं और ऑपरेशन का परिणाम दशमलव संख्या होता है।
```lua
1.0 + 2   --> 3.0
```

### भाग

भाग हमेशा दशमलव संख्याओं पर काम करता है और परिणाम के रूप में दशमलव संख्या देता है।
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

शून्य से भाग देने पर `inf` या `-inf` मिलता है। शून्य को शून्य से भाग देने पर `-nan` मिलता है।
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### फ्लोर डिवीजन

अगर पूर्णांक परिणाम चाहिए, तो फ्लोर डिवीजन इस्तेमाल किया जा सकता है। फ्लोर डिवीजन भागफल को हमेशा ऋण अनंत की ओर पूर्णांकित करता है, जिससे सभी ऑपरेंडों के लिए पूर्णांक परिणाम सुनिश्चित होता है।

~~~exercism/note
संस्करण 5.3 से पहले, Lua में फ्लोर डिवीजन के लिए कोई अंकगणितीय ऑपरेटर नहीं था।
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

फ्लोर डिवीजन जोड़, घटाव, गुणा और ऋणात्मकता ऑपरेटरों के समान नियमों का पालन करता है। अगर दोनों ऑपरेंड पूर्णांक हैं, तो ऑपरेशन का परिणाम पूर्णांक होता है, वरना परिणाम दशमलव संख्या होता है।

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

फ्लोर डिवीजन से शून्य से भाग देने पर Lua एक एरर उठाएगा।
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### मॉड्यूलो

मॉड्यूलो का उपयोग दो ऑपरेंडों के भाग का शेषफल निकालने के लिए किया जाता है।
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### घातांकन

भाग की तरह, घातांकन भी दशमलव संख्याओं पर काम करता है और परिणाम के रूप में दशमलव संख्याएँ देता है।
```lua
10 ^ 2    --> 100.0
```

## प्राथमिकता

सभी ऑपरेशन [ऑपरेटर प्राथमिकता](https://www.lua.org/manual/5.4/manual.html#3.4.8) के अनुसार मूल्यांकित किए जाते हैं। कोष्ठकों का उपयोग करके किसी एक्सप्रेशन की प्राथमिकता बदली जा सकती है।

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## पूर्णांकन

`math` मॉड्यूल तीन पूर्णांकन फंक्शन देता है: `floor` नीचे की ओर (ऋण अनंत की ओर) पूर्णांकित करता है, `ceil` ऊपर की ओर (धन अनंत की ओर) पूर्णांकित करता है, और `modf` शून्य की ओर पूर्णांकित करता है।

### `math.floor`

`floor` ऋण अनंत की ओर पूर्णांकित करता है।
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` धन अनंत की ओर पूर्णांकित करता है।
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` शून्य की ओर पूर्णांकित करता है। यह फंक्शन पूर्णांकित वैल्यू के साथ-साथ संख्या का भिन्नात्मक भाग भी लौटाता है, जो हमेशा दशमलव संख्या होती है।
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## रूपांतरण

अगर हमें किसी पूर्णांक को दशमलव संख्या में बदलना हो, तो उसमें `0.0` जोड़ सकते हैं।
```lua
1 + 0.0         --> 1.0
```

अगर हमें किसी दशमलव संख्या को पूर्णांक में बदलना हो, तो हम उसका शून्य के साथ बिटवाइज़ OR कर सकते हैं या `math` मॉड्यूल के `tointeger` फंक्शन का उपयोग कर सकते हैं।
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

अगर संख्या को पूर्णांक में नहीं बदला जा सकता, तो OR ऑपरेटर एक एरर उठाएगा और `tointeger` फंक्शन `nil` लौटाएगा।
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## हेक्साडेसिमल

कई अन्य प्रोग्रामिंग भाषाओं की तरह, Lua हेक्साडेसिमल संख्याओं का समर्थन उनके आगे `0x` लगाकर करता है, लेकिन कई अन्य प्रोग्रामिंग भाषाओं से अलग, Lua दशमलव हेक्साडेसिमल संख्याओं का भी समर्थन करता है। इनमें भिन्नात्मक भाग और बाइनरी घातांक हो सकते हैं, जिनके आगे 'p' या 'P' लगाया जाता है।
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
