# निर्देश

आप एक ऐसे प्रोजेक्ट पर काम कर रहे हैं जिसमें उपयोगकर्ता सर्वर पर फाइलें अपलोड कर सकते हैं, ताकि वे उन्हें दूसरे उपयोगकर्ताओं के साथ साझा कर सकें। आपको एक फंक्शन लिखने का काम दिया गया है जो यह जाँचता है कि अपलोड की गई फाइल उसके [मीडिया टाइप][mimetype] से मेल खाती है या नहीं। थोड़ी खोज करने पर आपको पता चलता है कि किसी फाइल के पहले कुछ बाइट आम तौर पर उसी फाइल टाइप के लिए खास होते हैं, यानी वे उस फाइल को एक तरह का सिग्नेचर देते हैं।

संदर्भ के लिए यह तालिका देखिए:

| फाइल टाइप | आम एक्सटेंशन   | मीडिया टाइप                  | बाइनरी 'सिग्नेचर'                                |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. एक्सटेंशन देने पर अपेक्षित मीडिया टाइप लौटाइए

`type_from_extension/1` फंक्शन बनाइए। यह एक फाइल एक्सटेंशन (स्ट्रिंग) लेता है और उसका मीडिया टाइप (स्ट्रिंग) लौटाता है, या nil लौटाता है अगर एक्सटेंशन उन अपेक्षित एक्सटेंशन में से कोई न हो।

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. बाइनरी फाइल देने पर अपेक्षित मीडिया टाइप लौटाइए

`type_from_binary/1` फंक्शन बनाइए। यह एक फाइल (बाइनरी) लेता है और उसका मीडिया टाइप (स्ट्रिंग) लौटाता है, या nil लौटाता है अगर फाइल का सिग्नेचर उन अपेक्षित सिग्नेचर में से किसी से मेल न खाए।

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

फाइल को बाइनरी के रूप में पढ़ने की चिंता न कीजिए। मान लीजिए कि यह काम पहले ही आपके लिए किया जा चुका है और टेस्ट इसे आर्गुमेंट के रूप में देते हैं।

## 3. एक्सटेंशन और बाइनरी फाइल देने पर जाँचिए कि फाइल अपेक्षित टाइप से मेल खाती है

`verify/2` फंक्शन बनाइए। यह एक फाइल (बाइनरी) और एक्सटेंशन (स्ट्रिंग) लेता है और एक `:ok` या `:error` टपल लौटाता है।

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
