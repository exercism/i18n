# निर्देश

अखबार की एक फैक्ट्री में नई क्वालिटी मैनेजर एलेना आपसे कहती हैं कि आप प्रोडक्शन रूम पर नज़र रखने के लिए एक छोटा सा सॉफ्टवेयर लिखें।

## 1. एक कस्टम एरर बनाइए

`ERROR:` पार्सिंग शब्द का इस्तेमाल करके `machine-error` नाम की एक एरर टपल क्लास बनाइए। इसमें किसी स्लॉट की ज़रूरत नहीं है।

```factor
machine-error   ! throws a fresh machine-error
```

## 2. नमी की जाँच कीजिए

`check-humidity` बनाइए। यह स्टैक से नमी की रीडिंग लेता है और जब वह रीडिंग `70` से सख्ती से ज़्यादा हो, तो स्ट्रिंग `"humidity too high"` `throw` करता है। ऐसा न हो तो यह कुछ नहीं लौटाता।

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. तापमान की जाँच कीजिए

`check-temperature` बनाइए। यह तापमान की रीडिंग लेता है और जब वह रीडिंग `500` से सख्ती से ज़्यादा हो, तो स्ट्रिंग `"temperature too high"` `throw` करता है। ऐसा न हो तो यह कुछ नहीं लौटाता।

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. मशीन पर नज़र रखिए

`monitor` बनाइए, जो स्टैक से नमी और तापमान लेकर दोनों जाँच चलाता है। अगर कोई भी जाँच `throw` करती है, तो `monitor` को उसके बजाय एक नया `machine-error` `throw` करना चाहिए। अगर दोनों जाँच पास हो जाएँ, तो `monitor` कुछ नहीं लौटाता।

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. रीडिंग के एक बैच पर नज़र रखिए

`monitor-batch` बनाइए, जो `{ humidity temperature }` रीडिंग का एक ऐरे लेता है और लौटाता है कि उनमें से कितनी फेल होंगी (यानी कितनी रीडिंग की वजह से `monitor` `throw` करेगा)।

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
