# इंस्टॉलेशन

इन अभ्यासों को चलाने के लिए आपको बस [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) और [Java 8](https://java.com/en/download/) इंस्टॉल करने होंगे। CommandBox CLI, Mac, Linux और Windows पर काम करता है, और इसका इंस्टॉलेशन गाइड यहाँ है:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

अगर आप Mac पर Homebrew इस्तेमाल करते हैं, तो CommandBox CLI सेटअप करने का एक उदाहरण ऐसा होगा:

```bash
brew install commandbox
```

CLI इंस्टॉल हो जाने के बाद आप REPL आज़मा सकते हैं:

```bash
box repl
```

आप .cfm पेजों को सीधे चला सकते हैं:

```bash
box exec myTest.cfm
```

और आप अपनी हार्ड ड्राइव की किसी भी डायरेक्टरी में वेब सर्वर भी शुरू कर सकते हैं:

```bash
box server start
```

CommandBox में एक इंटरैक्टिव शेल भी है, जिसमें बेहतर टैब कम्पलीशन मिलता है और जो तेज़ चलता है। इसमें जाने के लिए बस `box` बाइनरी को बिना किसी आर्गुमेंट के चलाइए।

```bash
box
```
