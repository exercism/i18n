# परिचय

## ऐरे

Common Lisp में भी, दूसरी भाषाओं की तरह, ऐरे एलिमेंट का एक समूह होता है, जिन तक पूर्णांक इंडेक्स के ज़रिए पहुँचा जाता है।
एलिमेंट अलग-अलग टाइप के हो सकते हैं।
ऐरे बहु-आयामी भी हो सकता है (सिर्फ 1-आयामी नहीं)।

### बनाना

`make-array` की मदद से ऐरे बनाए जा सकते हैं।
इसमें कई विकल्प हैं, लेकिन इसके आसान रूपों से N-आयामी ऐरे बनाए जा सकते हैं, जिनमें या तो सभी एलिमेंट को एक ही वैल्यू दी जाती है, या ऐरे को किसी दूसरे सीक्वेंस (जैसे किसी लिस्ट) की वैल्यूज़ दी जाती हैं। 
इसका पहला आर्गुमेंट एक लिस्ट होता है, जिसमें हर आयाम का आकार दिया जाता है।

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(ध्यान दीजिए कि N-आयामी ऐरे आयामों की संख्या के साथ कैसे छपते हैं।)

ऐरे उसी फॉर्मेट का उपयोग करके भी बनाए जा सकते हैं जिसमें वे छपते हैं: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### एलिमेंट तक पहुँचना

वेक्टर के एलिमेंट तक पहुँचने के लिए `aref` का इस्तेमाल कीजिए। 
इंडेक्स 0 से शुरू होते हैं।
दिए गए इंडेक्स की संख्या ऐरे के रैंक से मेल खानी चाहिए।

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
