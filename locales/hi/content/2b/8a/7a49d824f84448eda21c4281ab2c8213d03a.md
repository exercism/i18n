# निर्देश

एक **सम्मिश्र संख्या** को `z = a + b * i` के रूप में व्यक्त किया जाता है, जहाँ:

- `a` **वास्तविक भाग** है (एक वास्तविक संख्या),

- `b` **काल्पनिक भाग** है (यह भी एक वास्तविक संख्या), और

- `i` **काल्पनिक इकाई** है जो `i^2 = -1` को संतुष्ट करती है।

## सम्मिश्र संख्याओं पर संक्रियाएँ

### संयुग्मी

सम्मिश्र संख्या `z = a + b * i` का संयुग्मी इस प्रकार दिया जाता है:

```text
zc = a - b * i
```

### निरपेक्ष वैल्यू

`z` की निरपेक्ष वैल्यू (या मापांक) इस प्रकार परिभाषित की जाती है:

```text
|z| = sqrt(a^2 + b^2)
```

निरपेक्ष वैल्यू का वर्ग `z` और उसके संयुग्मी `zc` के गुणनफल के रूप में निकाला जाता है:

```text
|z|^2 = z * zc = a^2 + b^2
```

### जोड़

दो सम्मिश्र संख्याओं `z1 = a + b * i` और `z2 = c + d * i` का योग उनके वास्तविक और काल्पनिक भागों को अलग-अलग जोड़कर निकाला जाता है:

```text
z1 + z2 = (a + b * i) + (c + d * i)
        = (a + c) + (b + d) * i
```

### घटाव

दो सम्मिश्र संख्याओं का अंतर उनके संगत भागों को घटाकर प्राप्त किया जाता है:

```text
z1 - z2 = (a + b * i) - (c + d * i)
        = (a - c) + (b - d) * i
```

### गुणा

दो सम्मिश्र संख्याओं का गुणनफल इस प्रकार परिभाषित किया जाता है:

```text
z1 * z2 = (a + b * i) * (c + d * i)
        = (a * c - b * d) + (b * c + a * d) * i
```

### व्युत्क्रम

किसी शून्येतर सम्मिश्र संख्या का व्युत्क्रम इस प्रकार दिया जाता है:

```text
1 / z = 1 / (a + b * i)
      = a / (a^2 + b^2) - b / (a^2 + b^2) * i
```

### भाग

एक सम्मिश्र संख्या को दूसरी से भाग देने पर यह प्राप्त होता है:

```text
z1 / z2 = z1 * (1 / z2)
        = (a + b * i) / (c + d * i)
        = (a * c + b * d) / (c^2 + d^2) + (b * c - a * d) / (c^2 + d^2) * i
```

### घातांकन

प्राकृतिक लघुगणक के आधार _e_ को एक सम्मिश्र घात तक उठाने को ऑयलर के सूत्र से व्यक्त किया जा सकता है:

```text
e^(a + b * i) = e^a * e^(b * i)
              = e^a * (cos(b) + i * sin(b))
```

## कार्यान्वयन की आवश्यकताएँ

चूँकि आपको सम्मिश्र संख्याओं के लिए भाषा के अंतर्निहित समर्थन का उपयोग नहीं करना है, इसलिए इन संक्रियाओं को कार्यान्वित कीजिए:

- दो सम्मिश्र संख्याओं का **जोड़**
- दो सम्मिश्र संख्याओं का **घटाव**
- दो सम्मिश्र संख्याओं का **गुणा**
- दो सम्मिश्र संख्याओं का **भाग**
- एक सम्मिश्र संख्या का **संयुग्मी**
- एक सम्मिश्र संख्या की **निरपेक्ष वैल्यू**
- **घातांकन**: प्राकृतिक लघुगणक के आधार _e_ को एक सम्मिश्र संख्या की घात तक उठाना
