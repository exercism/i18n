# परिचय

## रेगुलर एक्सप्रेशन

Gleam में रेगुलर एक्सप्रेशन **PCRE** स्पेसिफिकेशन का पालन करते हैं (**P**erl **C**ompatible **R**egular **E**xpressions), ठीक वैसे ही जैसे Java, JavaScript या Ruby जैसी दूसरी लोकप्रिय भाषाएँ करती हैं।

`gleam_regexp` पैकेज का `gleam/regexp` मॉड्यूल रेगुलर एक्सप्रेशन के साथ काम करने के लिए फंक्शन देता है।

~~~~exercism/note
यह अभ्यास मान लेता है कि आप रेगुलर एक्सप्रेशन का सिंटैक्स पहले से जानते हैं, जिसमें कैरेक्टर क्लास, क्वांटिफायर, ग्रुप और कैप्चर शामिल हैं।

अगर आपको अपना रेगुलर एक्सप्रेशन का ज्ञान ताज़ा करना है, तो इनमें से कोई एक स्रोत देखिए: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

रेगुलर एक्सप्रेशन बनाने का सबसे आम तरीका `regexp.from_string` फंक्शन का उपयोग करना है।

```gleam
let assert Ok(re) = regexp.from_string("test")
```

रेगुलर एक्सप्रेशन बनाने वाले फंक्शन अमान्य सिंटैक्स होने पर एक एरर लौटाते हैं, इसलिए यहाँ एक let-assertion का उपयोग किया गया है, ताकि यह पक्का हो सके कि रेगुलर एक्सप्रेशन मान्य है।

`regexp.check` फंक्शन से यह जाँचा जा सकता है कि कोई रेगुलर एक्सप्रेशन किसी स्ट्रिंग से मेल खाता है या नहीं।

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### कैप्चर

अगर आप रेगुलर एक्सप्रेशन की मदद से सबस्ट्रिंग कैप्चर करना चाहते हैं, तो `regexp.scan` फंक्शन मैचों का एक ऐरे लौटाता है।

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### मॉडिफायर

किसी रेगुलर एक्सप्रेशन का व्यवहार बदला जा सकता है। इसके लिए उसे `regexp.compile` फंक्शन से बनाइए और साथ में ऑप्शन दीजिए।

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
