# परिचय

Cairo में स्मार्ट पॉइंटर उन्नत डेटा स्ट्रक्चर हैं। ये साधारण पॉइंटर में सुरक्षा की सुविधाएँ जोड़कर मेमोरी का सुरक्षित और कुशल प्रबंधन सुनिश्चित करते हैं। इससे null पॉइंटर को डीरेफरेंस करने या बिना इनिशियलाइज़ की गई मेमोरी तक पहुँचने जैसी आम समस्याएँ रुक जाती हैं।

## स्मार्ट पॉइंटर क्या है?

स्मार्ट पॉइंटर साधारण पॉइंटर की तरह ही काम करता है, लेकिन यह ओनरशिप पर नज़र रखता है और मेमोरी तक सुरक्षित पहुँच सुनिश्चित करता है। इससे null या डैंगलिंग पॉइंटर को डीरेफरेंस करने जैसी समस्याएँ नहीं होतीं।

## स्मार्ट पॉइंटर के प्रकार

Cairo कई तरह के स्मार्ट पॉइंटर देता है, जैसे `Box<T>` और `Nullable<T>`:

- **`Box<T>`**: यह डेटा को एक खास मेमोरी सेगमेंट में रखता है, जो बड़े या डायनैमिक साइज़ वाले डेटा के लिए आदर्श है।
                यह डेटा की कॉपी बनाए बिना ओनरशिप को दूसरी जगह भेजने देता है।
- **`Nullable<T>`**: यह या तो `T` टाइप की कोई सही वैल्यू दिखाता है या `null` को। ऑप्शनल वैल्यू संभालने के लिए यह काम आता है।

## मेमोरी सुरक्षा

स्मार्ट पॉइंटर असुरक्षित मेमोरी एक्सेस रोकने में मदद करते हैं। ये यह भी सुनिश्चित करते हैं कि जब मेमोरी की ज़रूरत न रहे, तो वह अपने आप मुक्त हो जाए, जिससे मेमोरी लीक का खतरा कम हो जाता है।

### उदाहरण: रिकर्सिव टाइप के लिए `Box<T>` का इस्तेमाल

`Box<T>` जैसे स्मार्ट पॉइंटर मेमोरी कुशलता से आवंटित करके और अनंत रिकर्सन से बचकर बाइनरी ट्री जैसे रिकर्सिव टाइप को सुरक्षित तरीके से संभालने देते हैं।

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## परफॉर्मेंस के फायदे

स्मार्ट पॉइंटर बड़े स्ट्रक्चर की कॉपी बनाने के बजाय डेटा के रेफरेंस भेजते हैं। इससे परफॉर्मेंस बेहतर होती है और मेमोरी पर बोझ कम होता है।

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
