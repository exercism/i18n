# निर्देश

आपके एक मित्र ने, जो एक उभरते कलाकार हैं, एक प्रोजेक्ट आइडिया लेकर आपसे संपर्क किया। चलिए उनकी कलात्मक सोच को आपके तकनीकी कौशल के साथ मिलाते हैं। अब [जनरेटिव आर्ट][generative-art] में हाथ आज़माने का समय है!

सीमाएँ रचनात्मकता को बढ़ाती हैं और प्रोजेक्ट की समय-सीमा छोटी करती हैं, इसलिए आप दोनों ने तय किया है कि अपनी कलाकृति को सिर्फ़ एक आकार तक सीमित रखेंगे, वृत्त (circle)। लेकिन वृत्त बहुत सारे होंगे। और वे घूम-फिर भी सकते हैं! आप इसका नाम रखेंगे... डांसिंग डॉट्स।

आपके मित्र निश्चित रूप से डॉट्स के लिए नई और जटिल हरकतें सोचना चाहेंगे, इसलिए आप कोडिंग की शुरुआत एक ऐसा आर्किटेक्चर बनाकर करेंगे जिससे बाद में नए एनिमेशन आसानी से बना सकें।

## 1. एनिमेशन बिहेवियर बनाइए

हर एनिमेशन मॉड्यूल को दो कॉलबैक लागू करने होते हैं: `init/1` और `handle_frame/3`। इन्हें `Animation` मॉड्यूल में बनाइए।

`init/1` कॉलबैक बनाइए। इसे `opts` टाइप का एक आर्गुमेंट लेना चाहिए और या तो `{:ok, opts}` टपल लौटाना चाहिए या `{:error, error}` टपल। इस कॉलबैक के कार्यान्वयन जाँचेंगे कि दिए गए विकल्प इस खास तरह के एनिमेशन के लिए मान्य हैं या नहीं।

`handle_frame/3` कॉलबैक बनाइए। इसे तीन आर्गुमेंट लेने चाहिए: डॉट, फ्रेम संख्या और विकल्प। इसे हमेशा एक डॉट लौटाना चाहिए। इस कॉलबैक के कार्यान्वयन मौजूदा फ्रेम संख्या और एनिमेशन के विकल्पों के आधार पर डॉट के एट्रिब्यूट बदलेंगे।

## 2. `init/1` कॉलबैक का डिफ़ॉल्ट कार्यान्वयन दीजिए

`use DancingDots.Animation` कॉल करके `Animation` बिहेवियर को दूसरे मॉड्यूल में शामिल करना आसान होना चाहिए।

ऐसा करने के लिए, `Animation` मॉड्यूल में `__using__` मैक्रो लागू कीजिए, जो `Animation` मॉड्यूल को दूसरे मॉड्यूल का बिहेवियर बना दे। इसे `init/1` कॉलबैक का डिफ़ॉल्ट कार्यान्वयन भी देना चाहिए। `init/1` का डिफ़ॉल्ट कार्यान्वयन दिए गए विकल्पों को बिना बदले लौटाना चाहिए।

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. `Flicker` एनिमेशन लागू कीजिए

टिमटिमाने वाला एनिमेशन लागू करने के लिए `Animation` बिहेवियर का उपयोग कीजिए।

इसे डिफ़ॉल्ट `init/1` कॉलबैक का उपयोग करना चाहिए क्योंकि यह कोई विकल्प नहीं लेता।

`handle_frame/3` कॉलबैक लागू कीजिए, जो एक अकेले फ्रेम को संभालता है। अगर फ्रेम संख्या चार की गुणज है, तो फंक्शन को डॉट उसकी मूल ओपैसिटी की आधी ओपैसिटी के साथ लौटाना चाहिए। बाकी फ्रेम में इसे डॉट बिना बदले लौटाना चाहिए।

फ्रेम की गिनती `1` से होती है। `handle_frame/3` को दिया जाने वाला डॉट हमेशा अपनी मूल स्थिति में होता है, पिछले फ्रेम की स्थिति में नहीं।

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. `Zoom` एनिमेशन लागू कीजिए

ज़ूम करने वाला एनिमेशन लागू करने के लिए `Animation` बिहेवियर का उपयोग कीजिए।

यह एनिमेशन एक विकल्प लेता है, वेलोसिटी। वेलोसिटी कोई भी संख्या हो सकती है। अगर यह ऋणात्मक है, तो डॉट ज़ूम इन होने की बजाय ज़ूम आउट हो जाता है।

`init/1` कॉलबैक लागू कीजिए। इसे जाँचना चाहिए कि दिए गए विकल्प एक कीवर्ड लिस्ट हैं और उसमें `:velocity` की मौजूद है। वेलोसिटी की वैल्यू एक संख्या होनी चाहिए। अगर यह संख्या न हो, तो यह एरर लौटाइए: `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

`handle_frame/3` कॉलबैक लागू कीजिए। इसे डॉट लौटाना चाहिए, जिसकी त्रिज्या बढ़ी हुई हो। वृद्धि इतनी होगी: (मौजूदा फ्रेम संख्या में से एक घटाकर) गुणा वेलोसिटी।

फ्रेम की गिनती `1` से होती है। `handle_frame/3` को दिया जाने वाला डॉट हमेशा अपनी मूल स्थिति में होता है, पिछले फ्रेम की स्थिति में नहीं।

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
