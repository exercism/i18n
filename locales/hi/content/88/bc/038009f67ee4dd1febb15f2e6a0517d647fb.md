# सॉर्टिंग

चीज़ों को क्रम में लगाना इतना आम काम है कि लाइब्रेरी यह आपके लिए खुद कर देती है।

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` हर उस चीज़ पर काम करता है जो पहले से खुद की तुलना करना जानती है। संख्याएँ और स्ट्रिंग जानती हैं, क्योंकि उनके पास `is_lt` होता है।

## अपने नियम से सॉर्ट करना

ज़्यादातर क्रम बिल्ट-इन नहीं होते। नेटबॉल की तालिका न वर्णमाला के क्रम से लगती है और न नाम की लंबाई से। वह अंकों से लगती है, और जिन टीमों के अंक बराबर हों, उनके लिए गोल अंतर से। `ARRAY` के लिए यह अनुमान लगाने का कोई तरीका नहीं है।

इसलिए आप यह क्रम एक बाउंड रूटीन के रूप में देते हैं:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` एक `ROUT{T,T}:BOOL` लेता है, यानी ऐसा रूटीन जो सॉर्ट की जा रही चीज़ों में से दो लेता है और बताता है कि क्या पहली दूसरी से पहले आनी चाहिए। यह उस रूटीन को जितनी बार ज़रूरत हो उतनी बार कॉल करता है और ऐरे को उन जवाबों के मुताबिक क्रम में लगा देता है।

`understudy` इसी काम के लिए था। लाइब्रेरी को सॉर्ट करना आता है, पर आपके क्रम के विचार के बारे में कुछ नहीं जानती। बाउंड रूटीन वह जगह है जहाँ ये दोनों मिलते हैं।

## तुलना लिखना

रूटीन **तब सही जवाब देता है जब पहला आर्गुमेंट पहले आता है**।

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

जिस नियम में एक से ज़्यादा हिस्से हों, उसके हिस्सों को महत्व के क्रम में देखिए:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

जब भी अंक अलग हों, पहला `if` फैसला कर देता है। दूसरी लाइन की बात तभी चलती है जब अंक बराबर हों। बराबरी तोड़ने वाला नियम पहले लिखने का मतलब होता कि अंकों का कोई महत्व ही नहीं रहता।

## सॉर्ट करने से ऐरे बदल जाता है

`insertion_sort_by` ऐरे को खुद क्रम में लगा देता है और कुछ नहीं लौटाता:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

अगर मूल क्रम मायने रखता है, तो एक कॉपी को सॉर्ट कीजिए:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
