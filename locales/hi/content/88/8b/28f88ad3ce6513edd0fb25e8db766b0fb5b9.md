# परिचय

जब किसी कस्टम टाइप का कोई वेरिएंट डेटा रखता है, तो उसे रिकॉर्ड कहते हैं, और उसमें मौजूद हर वैल्यू एक _फील्ड_ में रहती है।

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

पढ़ने में आसानी के लिए Gleam फील्डों को नाम के साथ लेबल करने की सुविधा देता है।

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

लेबल की मदद से रिकॉर्ड के कंस्ट्रक्टर को आर्गुमेंट किसी भी क्रम में दिए जा सकते हैं।

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

जब किसी कस्टम टाइप में सिर्फ एक ही वेरिएंट हो, तो रिकॉर्ड की फील्ड पाने के लिए `.label` एक्सेसर सिंटैक्स का उपयोग किया जा सकता है।

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

रिकॉर्ड अपडेट सिंटैक्स तब काम आता है जब किसी कस्टम टाइप में एक ही वेरिएंट हो। इसकी मदद से किसी मौजूदा रिकॉर्ड से नया रिकॉर्ड बनाया जा सकता है, बस कुछ फील्ड की वैल्यू नई वैल्यू से बदल दी जाती हैं।

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

रिकॉर्ड से वैल्यू निकालने के लिए पैटर्न मैचिंग करते समय भी लेबल इस्तेमाल किए जा सकते हैं।

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h > 20.0 -> True
    _ -> False
  }
}
```

अगर हमें सिर्फ कुछ फील्ड पर ही मैच करना हो, तो बाकी बची फील्ड को नज़रअंदाज़ करने के लिए हम स्प्रेड ऑपरेटर `..` इस्तेमाल कर सकते हैं।

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
