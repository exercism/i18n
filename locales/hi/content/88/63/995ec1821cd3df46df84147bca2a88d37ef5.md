# परिचय

C# में मुख्य ऑब्जेक्ट-ओरिएंटेड संरचना _क्लास_ है, जो डेटा (_फील्ड_) और व्यवहार (_मेथड_) का मेल है। किसी क्लास के फील्ड और मेथड उसके _मेंबर_ कहलाते हैं।

मेंबर तक पहुँच को एक्सेस मॉडिफायर से सीमित किया जा सकता है। सबसे आम दो ये हैं:

- `public`: इस मेंबर को कोई भी कोड एक्सेस कर सकता है (कोई रोक नहीं)।
- `private`: इस मेंबर को सिर्फ़ उसी क्लास का कोड एक्सेस कर सकता है।

क्लास को आप उसके इंस्टेंस बनाने के टेम्पलेट की तरह देख सकते हैं। किसी क्लास का इंस्टेंस बनाने के लिए (जिसे _ऑब्जेक्ट_ भी कहा जाता है) `new` कीवर्ड का उपयोग होता है:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

फील्ड का एक टाइप होता है और उन्हें क्लास में कहीं भी परिभाषित किया जा सकता है।
public फील्ड PascalCase में और private फील्ड camelCase में परिभाषित होते हैं, और private फील्ड के आगे अंडरस्कोर `_` लगाया जाता है:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

आप चाहें तो किसी फील्ड को शुरुआती वैल्यू असाइन कर सकते हैं। अगर किसी फील्ड में शुरुआती वैल्यू _नहीं_ दी जाती, तो वह उसके टाइप की डिफॉल्ट वैल्यू पर सेट हो जाती है। किसी इंस्टेंस के फील्ड की वैल्यू को डॉट-नोटेशन की मदद से एक्सेस और अपडेट किया जा सकता है।

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

private फील्ड आम तौर पर किसी मेथड को कॉल करने के साइड इफेक्ट के रूप में अपडेट होते हैं। ऐसे मेथड आम तौर पर कोई वैल्यू नहीं लौटाते। ऐसी स्थिति में रिटर्न टाइप `void` होना चाहिए:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
