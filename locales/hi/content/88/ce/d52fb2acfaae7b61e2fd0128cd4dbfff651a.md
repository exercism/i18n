# परिचय

कभी-कभी कोड के किसी खास हिस्से को एक से अधिक बार इस्तेमाल करना पड़ता है। ऐसा हो तो उस कोड को एक फंक्शन में डालना सुविधाजनक हो सकता है। एक फंक्शन आम तौर पर सिर्फ एक ही खास काम करता है। Rust में फंक्शन बनाने के लिए ```fn``` कीवर्ड का इस्तेमाल किया जाता है। फंक्शन का कोड हमेशा ब्रेसिज़ (यानी `{}`) के बीच होता है। `main` नाम का फंक्शन खास होता है क्योंकि यह प्रोग्रामों का प्रवेश बिंदु होता है। उस फंक्शन से आप दूसरे फंक्शन कॉल कर सकते हैं।

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

फंक्शन पैरामीटर भी ले सकते हैं, जैसे ```say_my_name()``` में ```name: &str```। फंक्शन वैल्यू भी लौटा सकते हैं, जैसे ऊपर `-> &str`.
