# परिचय

Factor में अक्षर पूर्णांक होते हैं, यानी Unicode कोड पॉइंट। इसलिए `<`, `>`, `=` जैसे संख्यात्मक ऑपरेटर सीधे बड़े-छोटे अक्षरों में फर्क करने वाला क्रम देते हैं। [`unicode`][unicode] वोकैबुलरी Unicode को समझने वाले प्रेडिकेट और एक अक्षर का केस बदलने की सुविधा जोड़ती है।

## अक्षरों के प्रेडिकेट

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## केस बदलना

`ch>upper` और `ch>lower` एक अक्षर का केस बदल देते हैं। स्ट्रिंग के स्तर पर काम करने वाले `>upper` और `>lower` इन्हें स्ट्रिंग के हर अक्षर पर लागू कर देते हैं।

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
