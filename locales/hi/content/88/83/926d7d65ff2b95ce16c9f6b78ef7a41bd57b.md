# संख्याएँ

Crystal में `Number` नाम का एक टाइप होता है, जो सभी संख्यात्मक टाइपों का आधार टाइप है।
`Number` टाइप के अंदर मुख्य रूप से दो टाइप आते हैं: [`Int`][int] और [`Float`][float]।

`Int`, integer का छोटा रूप है और पूर्ण संख्याओं को दर्शाता है।
`Int` ऋणात्मक और धनात्मक दोनों हो सकता है, और इसमें दशमलव बिंदु नहीं होता।

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` दशमलव बिंदु वाली संख्याओं को दर्शाता है।
`Float` संख्याएँ ऋणात्मक और धनात्मक दोनों हो सकती हैं।

```crystal
10.5.class
# => Float64
```

## `Int` और `Float` को एक-दूसरे में बदलना

`to_i` और `to_f` मेथड की मदद से आप `Int` और `Float` को एक-दूसरे में बदल सकते हैं।
`Float` से `Int` में बदलते समय संख्या को नीचे की ओर राउंड कर दिया जाता है।

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## अंकगणितीय ऑपरेटर

आप `Int` और `Float` पर [बुनियादी अंकगणितीय ऑपरेटर][math] इस्तेमाल कर सकते हैं।
ये ऑपरेटर हैं `+`, `-`, `*`, `/` और `%`।
इन ऑपरेटरों का इस्तेमाल करते समय आप `Int` और `Float` को मिला भी सकते हैं।

### जोड़, घटाव और गुणा

`+` ऑपरेटर जोड़ के लिए इस्तेमाल होता है, `-` ऑपरेटर घटाव के लिए, और `*` ऑपरेटर गुणा के लिए।

| ऑपरेटर | उदाहरण        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### भाग

भाग का इस्तेमाल संख्याओं को बाँटने के लिए किया जाता है।
`/` ऑपरेटर भाग के लिए इस्तेमाल होता है।
परिणाम हमेशा एक `Float` ही होता है।

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
कुछ प्रोग्रामिंग भाषाओं में शून्य से भाग देने पर एरर मिलती है।

Crystal में शून्य से भाग देने पर परिणाम `Infinity` या `-Infinity` होता है।
केवल एक अपवाद है: शून्य को शून्य से भाग देना, जिसका परिणाम `NaN` (Not a Number) होता है।
`Infinity` और `NaN`, `Float` टाइप की खास वैल्यू हैं।

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### मॉड्यूलस

मॉड्यूलस का इस्तेमाल भाग का शेषफल निकालने के लिए किया जाता है।
`%` ऑपरेटर मॉड्यूलस के लिए इस्तेमाल होता है।

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
मॉड्यूलो के साथ शून्य से भाग देने पर DivisionByZeroError मिलती है।
यह सामान्य भाग से अलग है।

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## राउंड करना

`round` मेथड एक वैकल्पिक आर्गुमेंट लेता है: वह दशमलव स्थानों की संख्या जिन तक राउंड करना है।
दशमलव स्थानों की डिफॉल्ट संख्या 0 होती है।

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## प्राथमिकता और ब्रैकेट

Crystal में ब्रैकेट (`()`) लगाने की सुविधा है, और इनका इस्तेमाल एक्सप्रेशनों को समूह में रखने के लिए किया जा सकता है।
यह तब काम आता है जब आप संक्रियाओं का क्रम बदलना चाहते हैं।

कई अंकगणितीय ऑपरेटर इस्तेमाल करते समय संक्रियाओं का क्रम गणित जैसा ही होता है, जिसे [PEMDAS][pemdas] भी कहा जाता है।
इसमें क्रम यह होता है: ब्रैकेट (`()`), घात (`**`), गुणा (`*`) और भाग (`/`), और फिर जोड़ (`+`) और घटाव (`-`)।

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
