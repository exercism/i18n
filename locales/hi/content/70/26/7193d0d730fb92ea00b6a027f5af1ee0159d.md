# परिचय

हम _भाषा_ को **AWK** कहेंगे, और AWK प्रोग्राम को इंटरप्रेट करने वाले _एक्ज़ीक्यूटेबल_ को **`awk`** या **`gawk`** कहेंगे।

## पैटर्न और एक्शन

एक AWK प्रोग्राम **पैटर्न-एक्शन जोड़ों** से बना होता है

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**पैटर्न** एक रेगुलर एक्सप्रेशन हो सकता है, जिससे इनपुट का मिलान किया जाता है।
यह कोई भी एक्सप्रेशन हो सकता है जिसका परिणाम सही या गलत वैल्यू हो।

**एक्शन** एक या उससे अधिक AWK कमांड होते हैं।
लपेटने वाले घुंघराले ब्रैकेट ज़रूरी हैं।

अगर पैटर्न का परिणाम _सही_ हो, तो उससे जुड़ा एक्शन मूल्यांकित किया जाता है।

## रिकॉर्ड और फील्ड

AWK इनपुट को **रिकॉर्ड** की श्रृंखला के रूप में पार्स करता है।
हर रिकॉर्ड शून्य या अधिक **फील्ड** में बाँटा जाता है।

डिफ़ॉल्ट व्यवहार यह है:

- न्यूलाइन को "रिकॉर्ड सेपरेटर" मानकर इनपुट को रिकॉर्ड में बाँटना, यानी हर _लाइन_ एक रिकॉर्ड होती है।
- व्हाइटस्पेस को "फील्ड सेपरेटर" मानकर रिकॉर्ड को फील्ड में बाँटना, यानी हर _शब्द_ एक फील्ड होता है।

## पैटर्न और एक्शन, आगे

पैटर्न छोड़ा जा सकता है, और उस स्थिति में एक्शन _हर इनपुट रिकॉर्ड के लिए_ मूल्यांकित किया जाता है।

एक्शन छोड़ा जा सकता है, और उस स्थिति में डिफ़ॉल्ट एक्शन वर्तमान रिकॉर्ड को प्रिंट करना होता है।

### खास पैटर्न

दो खास पैटर्न हैं जिनका इस्तेमाल अक्सर किया जाता है।

- `BEGIN` किसी भी इनपुट को पढ़ने से पहले उससे जुड़ा एक्शन मूल्यांकित करता है।
- `END` सारा इनपुट पढ़े जाने के बाद उससे जुड़ा एक्शन मूल्यांकित करता है।

## फील्ड वेरिएबल

आप फील्ड को `$1`, `$2`, `$3`, आदि कहते हैं।

वर्तमान रिकॉर्ड `$0` होता है।

यहाँ कुछ और बिल्ट-इन वेरिएबल हैं जिनका इस्तेमाल अक्सर किया जाता है।

### इनपुट पार्सिंग को नियंत्रित करने वाले बिल्ट-इन वेरिएबल

- `RS` इनपुट रिकॉर्ड सेपरेटर है।
  जैसा कि बताया गया, इसकी डिफ़ॉल्ट वैल्यू न्यूलाइन होती है।
- `FS` इनपुट फील्ड सेपरेटर है।

ये वेरिएबल अक्सर `BEGIN` एक्शन ब्लॉक में सेट किए जाते हैं।

### जानकारी देने वाले बिल्ट-इन वेरिएबल

प्रोग्राम चलने के दौरान AWK इन वेरिएबल को अपने आप सेट कर देता है।

- `NF` वर्तमान रिकॉर्ड में फील्ड की संख्या संग्रहीत करता है।
  - अंतिम फील्ड की वैल्यू पाने के लिए `$NF` इस्तेमाल कीजिए।
- `NR` वर्तमान रिकॉर्ड संख्या संग्रहीत करता है।
  - जब कई इनपुट फाइलें प्रोसेस की जा रही हों, तो `NR` अब तक प्रोसेस किए गए कुल रिकॉर्ड की संख्या रखता है।
- `FNR` वर्तमान इनपुट फाइल में वर्तमान रिकॉर्ड की संख्या संग्रहीत करता है।
  - NR और FNR के बीच अंतर समझाने के लिए, यहाँ AWK का एक आम तरीका दिया गया है।
    ```awk
    NR == FNR {action}
    ```
    यह कहता है: "अगर अब तक जमा कुल रिकॉर्ड संख्या वर्तमान फाइल की रिकॉर्ड संख्या के बराबर हो।"
    यह केवल _पहली इनपुट फाइल_ के रिकॉर्ड के लिए ही सही हो सकता है।

## सत्यता

AWK सत्यता की वही अवधारणा इस्तेमाल करता है जो C में है।

- संख्या `0` गलत होती है।
- कोई भी अन्य संख्या सही होती है।

चूँकि AWK एक टेक्स्ट प्रोसेसिंग भाषा है, सत्य मान स्ट्रिंग तक भी बढ़ा दिए जाते हैं।

- खाली स्ट्रिंग `""` गलत होती है।
- कोई भी गैर-खाली स्ट्रिंग सही होती है।

## कमेंट

कमेंट `#` अक्षर से शुरू होते हैं और लाइन के अंत तक चलते हैं।

## उदाहरण

Unix जैसे सिस्टम पर `/etc/passwd` में उपयोगकर्ताओं की जानकारी होती है।
हर उपयोगकर्ता एक अलग लाइन पर दिया होता है, जिसमें फील्ड कोलन से अलग किए गए होते हैं।

उपयोगकर्ता नाम दिखाने के लिए:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

ध्यान दीजिए कि `{print $1}` एक्शन में कोई पैटर्न नहीं है, इसलिए यह हर रिकॉर्ड के लिए चलाया जाता है।

अगर हम आउटपुट को केवल उन उपयोगकर्ताओं तक सीमित करना चाहते हैं जो bash को अपने लॉगिन शेल के रूप में इस्तेमाल करते हैं, तो हम ऐसा कर सकते हैं:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
