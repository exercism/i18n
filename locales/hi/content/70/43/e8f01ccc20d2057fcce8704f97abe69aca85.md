# टेस्ट

अधिकतर टेस्ट यह जाँचते हैं कि आप [result] को वैल्यू असाइन करके या [exit] को वैल्यू पास करके अपेक्षित वैल्यू लौटाते हैं।

कुछ टेस्ट यह जाँचते हैं कि आप [raise] से अपेक्षित एक्सेप्शन उठाते हैं।

## टेस्ट चलाना

टेस्ट चलाने के लिए `make` यूटिलिटी ज़रूरी है।

अभ्यास की डायरेक्टरी के अंदर से कंसोल/टर्मिनल में टाइप कीजिए:

```sh
make
```

अगर आपने अभ्यास की हल फाइल को छुआ तक नहीं है, तो आपको ऐसा संदेश दिखेगा:

```
Please implement your solution.
```

इसलिए अपना हल लिखना शुरू करने से पहले इस लाइन को हटा दीजिए।

आम तौर पर सिर्फ पहला टेस्ट ही चलता है।

```text
TAP version 14
1..10
ok 1 - ...
```

सभी टेस्ट चलाने के लिए टाइप कीजिए:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

सारे टेस्ट पास हो जाने पर आपका अभ्यास पूरा हो जाता है और आप हल सबमिट कर सकते हैं।

संबंधित संख्या पास करके आप एक ही टेस्ट चुन सकते हैं, जैसे:

```sh
make test=2
```

इससे सिर्फ दूसरा टेस्ट ही चलेगा।
