# परिचय

## if एक्सप्रेशन

`jq` का **शर्त वाला एक्सप्रेशन** `if A then B else C end` है।

`if-then-else` भी `jq` के बाकी सभी बिल्ट-इन की तरह एक फिल्टर है: यह एक इनपुट लेता है और एक आउटपुट देता है।

अगर एक्सप्रेशन `A` कोई "ट्रुथी" वैल्यू देता है, तो `if` फिल्टर `B` का मूल्यांकन करता है।
वरना वह `C` का मूल्यांकन करता है।
`if` फिल्टर को जो इनपुट मिलता है, वह `B` या `C` को दिया जाता है।

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else` क्लॉज़ **वैकल्पिक** है; नीचे दिए गए दोनों स्टेटमेंट एक जैसे हैं।

```jq
if A then B else . end
if A then B end
```
~~~~

## नेस्टेड if स्टेटमेंट

`elif` की मदद से और शर्तें जोड़ी जा सकती हैं।

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

आप जितने चाहें उतने `elif` क्लॉज़ लगा सकते हैं।

## ट्रुथीनेस

`jq` में सिर्फ दो वैल्यू "गलत" मानी जाती हैं: `false` और `null`।
बाकी सब कुछ "सही" है, यहाँ तक कि संख्या शून्य, और खाली स्ट्रिंग, ऐरे और ऑब्जेक्ट भी।

## बूलियन ऑपरेटर

जटिल क्वेरी बनाने के लिए **बूलियन ऑपरेटर** `and` और `or` इस्तेमाल किए जा सकते हैं।

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

किसी बात को नकारने के लिए `not` इस्तेमाल कीजिए। यह एक **फिल्टर** है, ऑपरेटर नहीं।

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## अल्टरनेटिव ऑपरेटर

**अल्टरनेटिव ऑपरेटर** की मदद से आप एक "डिफ़ॉल्ट" वैल्यू तय कर सकते हैं, जो तब काम आती है जब कोई एक्सप्रेशन false या null हो।

```jq
A // B

# This is identical to
if A then A else B end
```

इसे समझने के लिए यह देखिए

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
