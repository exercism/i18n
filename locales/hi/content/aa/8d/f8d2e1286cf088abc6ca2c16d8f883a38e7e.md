# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग | टाइप | विवरण |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | इनपुट     | एड्रेस | वह इनपुट स्ट्रिंग जिसके अंत में null हो |
| `$v0`    | आउटपुट    | बूलियन | इनपुट एक पैंग्राम है (`0` = `false`, `1` = `true`) |
| `$t0-9`  | अस्थायी | कोई भी     | अस्थायी भंडारण के लिए इस्तेमाल किए जाते हैं |
