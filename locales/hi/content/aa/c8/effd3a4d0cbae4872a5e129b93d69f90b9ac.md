# इस बारे में

C# में बूलियन का टाइप `bool` होता है, जिसकी वैल्यू या तो `true` हो सकती है या `false`।

C# में चार [बूलियन ऑपरेटर][operators] होते हैं: `!` (नॉट), `&&` (एंड),  `||` (ऑर), और `^` (एक्सऑर)। `&&` और `||` ऑपरेटर _शॉर्ट-सर्किट मूल्यांकन_ का इस्तेमाल करते हैं, यानी ऑपरेटर के दाईं ओर वाले हिस्से का मूल्यांकन तभी किया जाता है जब उसकी ज़रूरत होती है।

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

तीनों बूलियन ऑपरेटरों की [_ऑपरेटर प्राथमिकता_][precedence] अलग-अलग होती है। इसलिए इनका मूल्यांकन इस क्रम में होता है: पहले `not`, फिर `&&`, फिर `^`, और अंत में `||`। अगर आप इन नियमों से 'बचना' चाहते हैं, तो किसी बूलियन एक्सप्रेशन को ब्रैकेट (`()`) के अंदर रख सकते हैं, क्योंकि ब्रैकेट की ऑपरेटर प्राथमिकता और भी ज़्यादा होती है।

```csharp
!true && false   // => false
!(true && false) // => true
```
