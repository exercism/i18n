# कमांड लाइन पर टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड इस्तेमाल कीजिए:

```bash
$ cargo test
```

पहले टेस्ट के अलावा बाकी सभी टेस्ट इग्नोर कर दिए गए हैं। पहला टेस्ट पास हो जाने के बाद, `tests` डायरेक्टरी में मौजूद टेस्ट सोर्स फाइल खोलिए और अगले टेस्ट से `#[ignore]` फ्लैग हटाइए, फिर उसे दोबारा पास कराइए। हर अलग टेस्ट एक फंक्शन होता है जिसके ऊपर `#[test]` फ्लैग लगा होता है। यह क्रम तब तक जारी रखिए जब तक आप हर टेस्ट पास न कर लें।

अगर आप टेस्ट सोर्स फाइल में बदलाव किए बिना _सिर्फ इग्नोर किए गए_ टेस्ट चलाना चाहते हैं, तो यह कमांड इस्तेमाल कीजिए:

```bash
$ cargo test -- --ignored
```

अगर आप Rust 1.51 या उससे नए वर्शन का इस्तेमाल कर रहे हैं, तो आप _सभी_ टेस्ट इस तरह चला सकते हैं:

```bash
$ cargo test -- --include-ignored
```

किसी एक खास टेस्ट को चलाने के लिए, जैसे `some_test`, आप यह कमांड इस्तेमाल कर सकते हैं:

```bash
$ cargo test some_test
```

अगर वह खास टेस्ट इग्नोर किया गया है, तो यह कमांड इस्तेमाल कीजिए:

```bash
$ cargo test some_test -- --ignored
```

Rust टेस्ट के बारे में और जानने के लिए ऑनलाइन [टेस्ट डॉक्युमेंटेशन][rust-tests] देखिए।

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
