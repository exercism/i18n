# परिचय

शर्त वाले स्टेटमेंट ऐसे स्टेटमेंट होते हैं जो यह देखकर अलग-अलग कोड चलाते हैं कि कोई शर्त `true` है या `false`।

[`if` स्टेटमेंट][if_statement] अपने अंदर का कोड तभी चलाता है जब उसकी शर्त `true` हो।
Go में सही या गलत मानी जाने वाली वैल्यू की कोई अवधारणा नहीं होती, इसलिए शर्त का टाइप `bool` ही होना चाहिए।
`if mySlice { ... }` या `if 1 { ... }` जैसे एक्सप्रेशन कंपाइल एरर देते हैं।

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

और शर्तें जाँचने के लिए `else if` का उपयोग कीजिए, और अगर कोई भी शर्त सही न निकले तो अंतिम विकल्प के तौर पर `else` लिखिए।
शर्तें ऊपर से नीचे के क्रम में जाँची जाती हैं। इनमें से सिर्फ पहली ऐसी शाखा चलती है जिसकी शर्त सही हो।

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

आम तौर पर Go में यह पसंद किया जाता है कि असामान्य स्थिति मिलते ही फंक्शन तुरंत वैल्यू लौटा दे और `else` लिखने से बचा जाए।

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

`if` स्टेटमेंट में एक छोटा इनिशलाइज़ेशन स्टेटमेंट भी शामिल हो सकता है।
इसका इस्तेमाल आम तौर पर किसी कॉल के तुरंत बाद एरर जाँचने के लिए किया जाता है:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

इनिशलाइज़ेशन स्टेटमेंट में घोषित वेरिएबल सिर्फ पूरी `if`/`else` श्रृंखला के स्कोप में ही रहते हैं।
ध्यान देने वाली बात यह है कि Go में टर्नरी ऑपरेटर नहीं है। यह जानबूझकर लिया गया डिज़ाइन का फैसला है, ताकि कोड को देखकर आसानी से समझा जा सके।

और जानने के लिए [Go by Example: If/Else][go_by_example_if] देखिए।
