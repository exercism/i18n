# परिचय

ABAP संख्यात्मक वैल्यू के लिए सामान्य अंकगणितीय ऑपरेटरों का समर्थन करता है:

- `+` वैल्यू जोड़ता है।
- `-` वैल्यू घटाता है।
- `*` वैल्यू को गुणा करता है।
- `/` वैल्यू को भाग देता है।
- `MOD` पूर्णांक विभाजन का शेषफल लौटाता है।

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

गुणा और भाग, जोड़ और घटाव से पहले किए जाते हैं। जब किसी गणना को स्पष्ट रूप से समूह में रखना हो, तो कोष्ठक लगाइए।

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
