# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग | प्रकार | विवरण |
| -------- | --------- | ------- | --------------------------------------------------------- |
| `$a0`    | इनपुट     | एड्रेस | नल-टर्मिनेटेड इनपुट स्ट्रिंग                              |
| `$v0`    | आउटपुट    | बूलियन | इनपुट में मेल खाते ब्रैकेट हैं (`0` = `false`, `1` = `true`) |
| `$t0-9`  | अस्थायी   | कोई भी | अस्थायी भंडारण के लिए उपयोग किया जाता है                 |
