# परिचय

Elixir में हम मॉड्यूल एट्रिब्यूट परिभाषित कर सकते हैं, जिन्हें हम अपने फंक्शन में कॉन्स्टेंट के रूप में इस्तेमाल कर सकते हैं।

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

जब मॉड्यूल कॉन्स्टेंट परिभाषित करने के लिए इनका इस्तेमाल किया जाता है, तब एट्रिब्यूट कोई भी एक्सप्रेशन हो सकते हैं जिसका मूल्यांकन कंपाइलेशन के समय किया जा सकता है। कंपाइलेशन के बाद, मॉड्यूल एट्रिब्यूट उपलब्ध नहीं रहते, क्योंकि कंपाइलेशन के दौरान उनका विस्तार हो जाता है, जैसा C जैसी भाषाओं में परिभाषित मैक्रो के साथ होता है।
