# परिचय

Kotlin में क्लास का उपयोग डेटा और व्यवहार को एनकैप्सुलेट करने के लिए किया जा सकता है।
क्लास `class` कीवर्ड से घोषित की जाती है।
उदाहरण के लिए:

```kotlin
class Car
```

क्लास को कॉल करके उसका इंस्टेंस बनाइए।

```kotlin
val instance = Car()
```

## प्रॉपर्टी

ऊपर के उदाहरणों में `Car` क्लास बिना किसी प्रॉपर्टी के घोषित की गई थी।
क्लास की प्रॉपर्टी क्लास की बॉडी में, यानी `{}` के बीच घोषित की जा सकती हैं। बदलने योग्य प्रॉपर्टी के लिए `var` और अपरिवर्तनीय प्रॉपर्टी के लिए `val` का उपयोग कीजिए।
उदाहरण के लिए:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

इसके अलावा, प्रॉपर्टी को ऐसे कंस्ट्रक्टर में भी बनाया जा सकता है जो उन प्रॉपर्टी को पैरामीटर के रूप में लेता है।

## कंस्ट्रक्टर

Kotlin में दो तरह के कंस्ट्रक्टर होते हैं: प्राइमरी और सेकंडरी कंस्ट्रक्टर।
प्राइमरी कंस्ट्रक्टर क्लास की घोषणा के साथ उसी लाइन पर घोषित किया जाता है।
उदाहरण के लिए:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

अगर कोई एनोटेशन नहीं है और कोई विज़िबिलिटी मॉडिफायर नहीं है, तो `constructor` कीवर्ड छोड़ा जा सकता है:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin में क्लास को बॉडी के बिना भी बनाया जा सकता है, अगर उसमें सिर्फ प्रॉपर्टी हों। ऐसी स्थिति में घुंघराले ब्रैकेट `{}` की ज़रूरत नहीं होती:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

एक क्लास में प्राइमरी कंस्ट्रक्टर सिर्फ एक ही हो सकता है।
सेकंडरी कंस्ट्रक्टर अतिरिक्त कंस्ट्रक्टर होते हैं, जिन्हें क्लास की बॉडी में `constructor` कीवर्ड के साथ घोषित करके जोड़ा जा सकता है।
उदाहरण के लिए:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

सेकंडरी कंस्ट्रक्टर में `this` को कॉल करके प्राइमरी कंस्ट्रक्टर को चलाना ज़रूरी होता है।

## इनिशियलाइज़र ब्लॉक

प्राइमरी कंस्ट्रक्टर क्लास की प्रॉपर्टी सेट करता है।
अगर ऑब्जेक्ट बनाते समय कुछ और करना हो, तो अतिरिक्त काम करने के लिए `init` ब्लॉक का उपयोग किया जा सकता है।

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## फंक्शन

फंक्शन क्लास की बॉडी में बनाए जा सकते हैं।
उदाहरण के लिए:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## विज़िबिलिटी

प्रॉपर्टी और फंक्शन `private`, `public`, `internal` या `protected` में से किसी एक तरह के हो सकते हैं।

- `private` तक पहुँच सिर्फ क्लास के अंदर से हो सकती है।
- `protected` तक क्लास के अंदर की चीज़ें और उसके सबक्लास, दोनों पहुँच सकते हैं।
- `internal` तक उसी मॉड्यूल के अंदर की चीज़ें पहुँच सकती हैं।
- `public` तक क्लास का उपयोग करने वाले दूसरे कंपोनेंट पहुँच सकते हैं।

उदाहरण के लिए:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
