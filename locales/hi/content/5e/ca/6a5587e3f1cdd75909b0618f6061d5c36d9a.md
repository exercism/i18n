# टेस्ट चलाइए

अपना ऑपरेटिंग सिस्टम चुनिए:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Command Prompt खोलिए।
2. पहला अभ्यास डाउनलोड कीजिए:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. exercism डायरेक्टरी में जाइए:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. टेस्ट चलाइए:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(पहली बार टेस्ट फेल होने की चिंता न कीजिए, हर अभ्यास की शुरुआत ऐसे ही होती है।)_

5. अभ्यास हल कीजिए। `instructions.append.md` गाइड ढूँढिए और उसे पूरा कीजिए ([GitHub पर देखिए][hello-world-tutorial])।

शुभकामनाएँ! मज़े कीजिए!

## macOS

1. टर्मिनल विंडो में, पहला अभ्यास डाउनलोड कीजिए:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. अभ्यास डायरेक्टरी में जाइए:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. टेस्ट चलाइए:

   ```sh
   ./gradlew test
   ```

   _(पहली बार टेस्ट फेल होने की चिंता न कीजिए, हर अभ्यास की शुरुआत ऐसे ही होती है।)_

4. अभ्यास हल कीजिए। `instructions.append.md` गाइड ढूँढिए और उसे पूरा कीजिए ([GitHub पर देखिए][hello-world-tutorial])।

शुभकामनाएँ! मज़े कीजिए!

## Linux

1. टर्मिनल विंडो में, पहला अभ्यास डाउनलोड कीजिए:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. अभ्यास डायरेक्टरी में जाइए:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. टेस्ट चलाइए:

   ```sh
   ./gradlew test
   ```

   _(पहली बार टेस्ट फेल होने की चिंता न कीजिए, हर अभ्यास की शुरुआत ऐसे ही होती है।)_

   अगर आपको यह एरर मिलती है:

   ```sh
   ./gradlew: Permission denied
   ```

   तो फाइल में एक्ज़ीक्यूट परमिशन नहीं है। इसे ठीक करने के लिए यह चलाइए:

   ```sh
   chmod +x ./gradlew
   ```

   अब आप पिछला कमांड चला पाएँगे।

4. अभ्यास हल कीजिए। `instructions.append.md` गाइड ढूँढिए और उसे पूरा कीजिए ([GitHub पर देखिए][hello-world-tutorial])।

शुभकामनाएँ! मज़े कीजिए!
