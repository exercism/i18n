# परिचय

`when` एक्सेप्शन फिल्टर करने का कीवर्ड है। इसे `catch` स्टेटमेंट के बाद रखा जाता है और यह उस समय स्कोप में मौजूद किसी भी वैल्यू वाला बूलियन एक्सप्रेशन ले सकता है। यदि एक्सप्रेशन का परिणाम सही होता है, तो उस `catch` स्टेटमेंट से जुड़ा ब्लॉक चलाया जाता है। अन्यथा अगला `catch` स्टेटमेंट, यदि कोई हो, जाँचा जाता है।

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
