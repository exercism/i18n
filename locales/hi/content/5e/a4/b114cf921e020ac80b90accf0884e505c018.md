# Rust संदर्भ

## कॉन्सेप्ट

Rust के कॉन्सेप्ट अभ्यास बुनियादी बातों से लेकर भाषा में महारत तक के कॉन्सेप्ट सिखाते हैं। इन्हें नीचे वर्गीकृत करके सूचीबद्ध किया गया है।

Exercism के कॉन्सेप्ट सीखने वालों की व्यावहारिक मदद के लिए बनाए गए हैं, इसलिए ये अमूर्त विचारों से अलग होते हैं। यह दस्तावेज़ बताता है कि Rust में इन कॉन्सेप्ट का क्या अर्थ है। ट्रैक मेंटेनरों को एक अच्छा संदर्भ दस्तावेज़ बनाने में मदद करने के लिए हमने नीचे इन कॉन्सेप्ट को समूहों में बाँटकर दिखाया है। ऐसे समूह शैक्षणिक विभाजन _नहीं_ हैं। इसलिए पढ़ाते समय इनका संदर्भ न दीजिए।

चेकबॉक्स बताते हैं कि अभ्यास मैपिंग सूची में कौन-से कॉन्सेप्ट अभी तक पढ़ाए गए हैं।

## कॉन्सेप्ट अभ्यास मैपिंग

सबसे अच्छा तो यह होगा कि ऊपर बताए गए हर कॉन्सेप्ट के लिए एक ही कॉन्सेप्ट अभ्यास हो, जो ठीक एक कॉन्सेप्ट सिखाए और जिसके लिए केवल उसकी पूर्वापेक्षाएँ ही चाहिए। लेकिन ऐसा करना पूरी तरह व्यावहारिक नहीं है। उदाहरण के लिए, ऐसा अभ्यास बनाना मुश्किल होगा जो फंक्शन क्या होते हैं, यह सिखाए, मगर प्रिमिटिव की कोई जानकारी न माँगे। इसी तरह, टेस्ट सूट के साथ प्रिमिटिव सिखाना भी मुश्किल होगा, अगर फंक्शन की कोई जानकारी न हो।

इस तालिका के अभ्यासों से एक DAG बनना चाहिए, जिसमें आगे चलकर ऊपर बताए गए सभी कॉन्सेप्ट शामिल होंगे।

| अभ्यास | पूर्वापेक्षाएँ | सिखाता है | विवरण |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | फंक्शन, टेस्ट सूट                                   | `&str` लिटरल `"hello world"` लौटाइए                                        |
| `compiled-calculator`    | `hello-world`                                | पूर्णांक, वेरिएबल असाइनमेंट                            | गणित की कुछ संक्रियाएँ कीजिए और परिणाम इम्प्लिसिट रूप से लौटाइए                |
| `conditionals`           | `hello-world`                                | शर्तें                                             | 3 शाखाओं वाले `if` / `else if` / `else` के रूप में होना चाहिए; इम्प्लिसिट रिटर्न          |
| `slices`                 | `hello-world`, `compiled-calculator`         | स्लाइस                                                   | ऐसे पैरामीटर से स्लाइस निकालिए जो पूर्णांकों का स्लाइस हो                        |
| `loops`                  | `slices`                                     | स्लाइस पर बुनियादी लूप चलाना                               | आदर्श रूप से अर्ली रिटर्न के साथ, ताकि इसे इटरेटर की तरह लिखना जटिल हो           |
| `iterator-use`           | `slices`                                     | इटरेटर का उपयोग, `collect`                                |
| `integer-sizes`          | `compiled-calculator`                        | `i32` के अलावा पूर्णांक, कास्टिंग                              | अब भी सभी साइन वाले                                                                 |
| `unsigned-ints`          | `integer-sizes`                              | अनसाइन पूर्णांक                                            |
| `indexing`               | `integer-sizes`, `slices`                    | इंडेक्सिंग, `usize`                                        |
| `floats`                 | `compiled-calculator`                        | दशमलव संख्या                                                   | शायद वही कंपाइल्ड कैलकुलेटर अभ्यास, पर गैर-पूर्णांक परिणामों के साथ             |
| `bools`                  | `compiled-calculator`                        | बूल, बूलियन ऑपरेटर                                 |
| `char`                   | `compiled-calculator`                        | `char` डेटा टाइप                                          | इसमें कुछ वाइड char उदाहरण होने चाहिए                                           |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | ध्यान दें: अपरिवर्तनीय!                                                                 |
| `string-use`             | `str-use`                                    | `String`                                                 | ध्यान दें: ओन्ड, परिवर्तनीय                                                             |
| `format-macro`           | `string-use`                                 | `format!` मैक्रो                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | जोड़ना, बदलना, लागत, आदि                        |
| `generics-basics`        | `integer-sizes`, `floats`                    | बाहरी ट्रेट को बाउंड की तरह उपयोग करना, बुनियादी जेनेरिक          | शायद अब भी कंपाइल्ड कैलकुलेटर, बस जेनेरिक                                 |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | डेटा संभालने के लिए स्ट्रक्ट बनाना और उपयोग करना               | `Person` में नाम, ऊँचाई, और उसके पास मौजूद जूतों की संख्या होती है                                   |
| `implicit-return`        | `compiled-calculator`                        | स्कोप, एक्सप्रेशन, इम्प्लिसिट रिटर्न                     |
| `explicit-return`        | `implicit-return`, `conditionals`            | स्पष्ट `return` स्टेटमेंट                              |
| `methods`                | `structs`, `explicit-return`                 | `impl` ब्लॉक, मेथड                                   |
| `tuples`                 | `structs`                                    | टपल                                                   | अनाम स्ट्रक्ट की तरह सिखाइए; `.0` सिंटैक्स सिखाइए                                    |
| `tuple-structs`          | `tuples`, `structs`                          | टपल स्ट्रक्ट (नाम वाले टपल)                             |
| `basic-enums`            | `unsigned-ints`                              | बुनियादी एनम (कोई फील्ड नहीं), `match`                         |
| `enums`                  | `basic-enums`, `tuple-structs`               | एनम वेरिएंट के लिए टपल सिंटैक्स                           |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | डिफॉल्ट रूप से अपरिवर्तनीयता; स्पष्ट परिवर्तनीयता             |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | शायद इम्प्लिमेंटेशन के आधार पर यह `option` या `result` में से किसी एक पर ही निर्भर करेगा |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | मैन्युअली एक ट्रेट लागू करना                            | शायद `Iterator` लागू करना                                                    |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
