# निर्देश

आप एक उत्साही पक्षी-निरीक्षक हैं, जो हर दिन अपने बगीचे में आने वाले पक्षियों की गिनती रखते हैं। ये गिनतियाँ एक ऐरे में संग्रहीत रहती हैं, जिसमें सबसे पुराना दिन सबसे पहले होता है।

## 1. आज की गिनती

`today` बनाइए, जो स्टैक से रोज़ाना की गिनतियों वाला ऐरे लेकर आज की गिनती लौटाए।

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. आज की गिनती बढ़ाइए

`increment-todays-count` बनाइए, जो एक नया ऐरे लौटाए जिसमें आज की गिनती एक से बढ़ी हुई हो। मूल ऐरे में कोई बदलाव नहीं होना चाहिए।

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. क्या कोई दिन बिना पक्षियों का था?

`has-day-without-birds?` बनाइए, जो `t` लौटाए अगर कम से कम एक दिन में शून्य पक्षी दर्ज हुए हों, वरना `f`।

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. पहले कुछ दिनों का जोड़

`count-for-first-days` बनाइए, जो गिनतियों का एक ऐरे और एक संख्या `n` ले, और पहली `n` गिनतियों का जोड़ लौटाए।

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. व्यस्त दिनों की गिनती

व्यस्त दिन वह होता है जिसमें पाँच या उससे अधिक पक्षी हों। `busy-days` बनाइए, जो ऐरे में व्यस्त दिनों की संख्या लौटाए।

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. छूटे हुए दिनों को भरिए

अगर आपने `n` दिनों की अवधि में हर दिन निरीक्षण नहीं किया, तो पीछे छूटे हुए दिनों को `0` से भर दीजिए। `pad-missing-days` बनाइए, जो गिनतियों का एक ऐरे और एक लक्ष्य लंबाई `n` ले, और कम से कम `n` लंबाई का ऐरे लौटाए जिसके अतिरिक्त खाने `0` हों। मौजूदा गिनतियाँ बिना बदले सुरक्षित रहनी चाहिए; अगर इनपुट पहले से ही कम से कम `n` लंबा है, तो उसे बिना बदले लौटा दीजिए।

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
