# परिचय

[`fold`][fold] एक [इटरेशन को खत्म करने वाला इटरेटर एडाप्टर][consuming iterator adaptor] है जो इटरेशन के हर एलिमेंट पर एक फंक्शन लागू करता है और परिणाम को जोड़ते हुए एक नई वैल्यू बनाता है।

`fold` के हर इटरेशन में दो आर्गुमेंट लगते हैं। पहला, एक्युमुलेटर की शुरुआती वैल्यू। दूसरा, एक क्लोज़र जो खुद दो आर्गुमेंट लेता है: एक्युमुलेटर और एक आइटम। क्लोज़र जो वैल्यू लौटाता है, वही आगे एक्युमुलेटर की वैल्यू बन जाती है। इटरेटर खत्म हो जाने पर एक्युमुलेटर की अंतिम वैल्यू लौटा दी जाती है।

जब किसी कलेक्शन को एक ही वैल्यू में बदलना हो, तब `fold` काम में लिया जा सकता है। उदाहरण के लिए, अगर आपको सभी सम संख्याओं का जोड़ चाहिए

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

तो यह `30` प्रिंट करता है।

जो काम `fold` में किया जा सकता है, वह अक्सर किसी दूसरे फंक्शन या फंक्शनों से भी हो सकता है। ऊपर के उदाहरण के लिए, `(1..=10)` पर [`filter`][filter] लगाकर फिर [`sum`][sum] करना कम लंबा होगा और वही परिणाम देगा, ऐसे

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

`fold` से ज़्यादा इस्तेमाल होने वाले दूसरे फंक्शनों में [`product`][product] और [`collect`][collect] शामिल हैं।

एक्युमुलेटर का इस्तेमाल सिर्फ संख्याओं के लिए ही नहीं, और चीज़ों के लिए भी किया जा सकता है। उदाहरण के लिए

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

यह `FeeFiFoFum` प्रिंट करता है।
