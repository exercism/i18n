# परिचय

JavaScript एक डायनामिक भाषा है, जो ऑब्जेक्ट-ओरिएंटेड, इम्परेटिव और डिक्लेरेटिव (जैसे फंक्शनल प्रोग्रामिंग) शैलियों का समर्थन करती है।

## (फिर से) असाइनमेंट

JavaScript में नामों को वैल्यू असाइन करने के कुछ मुख्य तरीके हैं, जैसे वेरिएबल या कॉन्स्टेंट का इस्तेमाल करना। Exercism पर वेरिएबलो को हमेशा [camelCase][wiki-camel-case] में लिखा जाता है और कॉन्स्टेंट को [SCREAMING_SNAKE_CASE][wiki-snake-case] में। इसके लिए कोई आधिकारिक नियम नहीं है, और अलग-अलग कंपनियों तथा संगठनों के अपने-अपने स्टाइल गाइड होते हैं। _आप अपने वेरिएबलो को जैसे चाहें वैसे लिख सकते हैं।_ अगर आप उन्हें उसी तरह लिखें जैसे अभ्यासों में तैयार किया गया है, तो इसका फायदा यह है कि वेब इंटरफेस और ज़्यादातर IDE में वे अलग तरह से हाइलाइट हो जाते हैं।

JavaScript में वेरिएबलो को [`const`][mdn-const], [`let`][mdn-let] या [`var`][mdn-var] कीवर्ड की मदद से परिभाषित किया जा सकता है।

`let` या `var` इस्तेमाल करने पर एक वेरिएबल अपने जीवनकाल में अलग-अलग वैल्यू रख सकता है। उदाहरण के लिए, `myFirstVariable` को असाइनमेंट ऑपरेटर `=` की मदद से कई बार परिभाषित और फिर से परिभाषित किया जा सकता है:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

`let` और `var` के उलट, `const` से परिभाषित वेरिएबलो को सिर्फ एक बार ही असाइन किया जा सकता है। JavaScript में कॉन्स्टेंट परिभाषित करने के लिए इसी का उपयोग किया जाता है।

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 आगे आने वाले एक कॉन्सेप्ट अभ्यास में यह खँगाला और समझाया जाएगा कि _कॉन्स्टेंट_ असाइनमेंट यानी बाइंडिंग और _कॉन्स्टेंट_ वैल्यू में क्या अंतर है।

## फंक्शन घोषणाएँ

JavaScript में कार्यक्षमता की इकाइयाँ _फंक्शन_ में समेटी जाती हैं। आम तौर पर जो फंक्शन एक साथ रहने चाहिए, उन्हें एक ही फाइल में रखा जाता है। ये फंक्शन पैरामीटर (आर्गुमेंट) ले सकते हैं और `return` कीवर्ड की मदद से कोई वैल्यू _लौटा_ सकते हैं। फंक्शन को `()` सिंटैक्स की मदद से कॉल किया जाता है।

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 JavaScript में फंक्शन घोषित करने के _कई_ तरीके हैं। ये बाकी तरीके `function` कीवर्ड इस्तेमाल करने से अलग दिखते हैं। यह ट्रैक इन्हें धीरे-धीरे पेश करने की कोशिश करता है, लेकिन अगर आप इनके बारे में पहले से जानते हैं, तो इनमें से कोई भी इस्तेमाल कर सकते हैं। ज़्यादातर मामलों में, एक या दूसरा इस्तेमाल करना बेहतर या खराब नहीं होता।

## दूसरी फाइलों के लिए उपलब्ध कराना

किसी `function`, कॉन्स्टेंट या वेरिएबल को _दूसरी फाइलों_ में उपलब्ध कराने के लिए ज़रूरी है कि उन्हें `export` कीवर्ड की मदद से [एक्सपोर्ट][mdn-export] किया जाए। इसके बाद कोई दूसरी फाइल इन्हें `import` कीवर्ड की मदद से [इम्पोर्ट][mdn-import] कर सकती है। इसे मॉड्यूल सिस्टम भी कहा जाता है। सभी टेस्ट कैसे काम करते हैं, इसका एक बढ़िया उदाहरण यही है। हर अभ्यास में कम से कम एक फाइल होती है, जैसे `lasagna.js`, जिसमें _इम्प्लीमेंटेशन_ होता है। इसके अलावा कम से कम एक और फाइल होती है, जैसे `lasagna.spec.js`, जिसमें _टेस्ट_ रहते हैं। यह फाइल इम्प्लीमेंटेशन को टेस्ट करने के लिए सार्वजनिक यानी एक्सपोर्ट की गई चीज़ों को _इम्पोर्ट_ करती है:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
