# विवरण

`reduce` Factor का सामान्य फोल्ड है। यह एक सीक्वेंस पर चलता है और एक एक्युमुलेटर को एक बाइनरी कोटेशन के माध्यम से आगे बढ़ाता है। वह कोटेशन वर्तमान एक्युमुलेटर और अगला एलिमेंट लेता है और नया एक्युमुलेटर बनाता है।

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

एक कस्टम सीड की मदद से `reduce` ऐसे फोल्ड लिख सकता है जो `sum` या `product` नहीं लिख सकते। उदाहरण के लिए, किसी सीक्वेंस की सबसे बड़ी वैल्यू निकालना, जहाँ सभी एलिमेंट के हार जाने पर एक डिफ़ॉल्ट वैल्यू ली जाती है:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

सीड `0` तुलना में भाग लेता है, इसलिए सभी ऋणात्मक एलिमेंट वाला सीक्वेंस अपनी सबसे छोटी वैल्यू के बजाय `0` ही देता है।

## `produce`: अनफोल्ड

`reduce` का जोड़ीदार `produce` है ([`sequences`][sequences] में): जहाँ `reduce` एक सीक्वेंस का *उपभोग* करता है, वहीं `produce` एक सीक्वेंस *उत्पन्न* करता है। एक प्रेडिकेट कोटेशन वर्तमान स्थिति की जाँच करता है; जब तक यह सही लौटाता है, तब तक एक बॉडी कोटेशन अगला एलिमेंट बनाता है।

```
produce ( pred quot -- seq )
```

साथ में इस्तेमाल करने पर, `reduce` और `produce` Factor का फोल्ड/अनफोल्ड जोड़ा बनाते हैं।

## संचयी रिडक्शन

`math.statistics` में संचयी रिडक्शनों का समूह इनपुट जितनी ही लंबाई का एक सीक्वेंस लौटाता है, जिसमें हर एलिमेंट उस स्थान तक और उस स्थान सहित प्रीफ़िक्स पर किए गए रिडक्शन के बराबर होता है:

| शब्द          | चलता हुआ ऑपरेशन |
|---------------|-------------------|
| `cum-sum`     | चलता हुआ कुल      |
| `cum-product` | चलता हुआ गुणनफल    |
| `cum-min`     | चलता हुआ न्यूनतम    |
| `cum-max`     | चलता हुआ अधिकतम    |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

संचयी रिडक्शन तब उपयोगी होते हैं जब आप यह देखना चाहते हैं कि सीक्वेंस में कोई राशि *कैसे* बदलती गई, केवल उसकी अंतिम वैल्यू ही नहीं। इन्हें चेन करना भी उपयोगी है: एक संचयी का आउटपुट खुद एक सीक्वेंस होता है, जो दूसरे में देने के लिए तैयार रहता है।
