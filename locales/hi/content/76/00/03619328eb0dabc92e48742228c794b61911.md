# परिचय

Common Lisp में स्ट्रिंग [अक्षरों][concept-characters] के [वेक्टर][concept-vectors] होती हैं। स्ट्रिंग को डबल कोट्स के बीच रखे अक्षरों के रूप में लिखा जाता है (_जैसे_ "Hello World!")।

`stringp` प्रेडिकेट तभी सही लौटाता है, जब दी गई वैल्यू एक स्ट्रिंग हो।

`subseq` फंक्शन की मदद से स्ट्रिंग को छोटे हिस्सों में बाँटा जा सकता है। यह फंक्शन स्ट्रिंग, शुरुआत का इंडेक्स और चाहें तो अंत का इंडेक्स लेता है। इंडेक्स 0 से शुरू होता है।

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

स्ट्रिंग की बराबरी `string=` से जाँची जा सकती है। अगर अक्षरों के केस को अनदेखा करना हो, तो `string-equal` इस्तेमाल किया जा सकता है।

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

स्ट्रिंग को बड़े अक्षरों में बदलने, छोटे अक्षरों में बदलने और कैपिटलाइज़ करने जैसे काम `string-upcase`, `string-downcase` और `string-capitalize` से किए जा सकते हैं।

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
