# अधिक जानकारी

C++ की यात्रा शुरू करने के लिए हम वेरिएबल, फंक्शन कॉल और कमेंट से शुरुआत करेंगे।

## कमेंट

कमेंट दो तरह के होते हैं: एक लाइन के और कई लाइनों के।
एक ही लाइन में `//` के बाद आने वाली हर चीज़ को कंपाइलर अनदेखा कर देता है।
कई लाइनों वाले कमेंट को C स्टाइल के कमेंट भी कहा जाता है।
इन्हें `/*` और `*/` के बीच लिखा जाता है।
इनके बीच आने वाली हर चीज़ को भी अनदेखा कर दिया जाता है।

## वेरिएबल

C++ एक टाइप वाली भाषा है।
सभी टाइप कंपाइल के समय ही पता होने चाहिए, और आम तौर पर आपको उन्हें स्पष्ट रूप से बताना पड़ता है।
किसी वेरिएबल का टाइप बदल नहीं सकता।
`years` नाम का एक पूर्णांक वेरिएबल इस तरह घोषित किया जा सकता है:

```cpp
int years;
```

वेरिएबल को घोषित करते समय ही उसे इनिशियलाइज़ कर देना अच्छी आदत है।
इसे करने के लिए C++ कई तरीके देता है।
कर्ली ब्रैकेट वाला तरीका आधुनिक C++ से अधिक मेल खाता है, लेकिन बराबर के चिह्न वाला तरीका भी बहुत आम है।

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ ऐसे वेरिएबल के उपयोग की अनुमति देता है जिन्हें इनिशियलाइज़ नहीं किया गया हो।
जब तक उस वेरिएबल में जान-बूझकर कोई वैल्यू न रखी जाए, वह अपरिभाषित रहता है और उसमें कुछ भी हो सकता है।
वैल्यू रखने से पहले वेरिएबल का उपयोग कर देने की गलतियों और अपरिभाषित व्यवहार से बचने के लिए उसे **हमेशा इनिशियलाइज़ कीजिए**।
अपरिभाषित व्यवहार आपके प्रोग्राम को सबसे बुरे समय पर क्रैश कर सकता है, जबकि पहले वह बिल्कुल ठीक चल रहा था।
इस पर जितना ज़ोर दिया जाए, उतना कम है: अपरिभाषित व्यवहार से हर हाल में बचिए।
~~~~

## अंकगणितीय संक्रियाएँ

`*`, `+` या `-` जैसे अंकगणितीय ऑपरेटर किसी एक्सप्रेशन का हिस्सा हो सकते हैं, जैसे `3 * 2` या `tomatoes + potatoes`।

## वेरिएबल की वैल्यू बदलना

जब तक वेरिएबल का टाइप वही रहे, आप उसमें नई वैल्यू असाइन कर सकते हैं:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## फंक्शन

फंक्शन का एक नाम, एक रिटर्न टाइप और पैरामीटर की एक सूची होती है (जो खाली भी हो सकती है)।
`always_fortyseven` नाम का एक फंक्शन, जो हमेशा 47 लौटाता है, ऐसा दिखेगा:

```cpp
int always_fortyseven() {
    return 47;
}
```

यहाँ `vip_fee` है, जो एक पैरामीटर लेता है:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

या `total_fee`, एक ऐसा फंक्शन जिसमें तीन पैरामीटर हैं और जो एक और फंक्शन को कॉल करता है।

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

कुछ अन्य भाषाओं में जैसा होता है, वैसा C++ में फंक्शन अंतिम स्टेटमेंट की वैल्यू नहीं लौटाते।
कोड के कंपाइल होने के लिए `return` कीवर्ड ज़रूरी है।

### व्हाइटस्पेस

व्हाइटस्पेस का उपयोग सोर्स कोड की फॉर्मैटिंग के लिए होता है, और इसमें स्पेस, टैब या नई लाइनें शामिल होती हैं।
चूँकि कंपाइलर अनावश्यक व्हाइटस्पेस को अनदेखा कर देता है, आप उसका उपयोग अपने कोड को व्यवस्थित करने के लिए कर सकते हैं।
व्हाइटस्पेस का समझदारी से किया गया उपयोग आपके कोड को पढ़ना आसान बना सकता है।
फॉर्मैटिंग के अलग-अलग मानक हैं, लेकिन ये सब परंपरा पर आधारित हैं और कंपाइलर इन्हें लागू नहीं करता।

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
