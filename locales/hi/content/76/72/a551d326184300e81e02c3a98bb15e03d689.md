# रिटर्न

Crystal में मेथड का अंतिम एक्सप्रेशन उस मेथड की वैल्यू लौटाता है।
लेकिन कभी-कभी आपको अंतिम एक्सप्रेशन से पहले ही कोई वैल्यू लौटानी पड़ती है।
इसके लिए आप `return` कीवर्ड का उपयोग कर सकते हैं। यह कीवर्ड अपने बाद वाले एक्सप्रेशन की वैल्यू लौटाता है।
`return` कीवर्ड के बाद लिखे कोड को नहीं चलाया जाता।

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
जब मेथड का अंतिम एक्सप्रेशन ही वह वैल्यू हो जो लौटाई जानी चाहिए, तो `return` कीवर्ड लिखने की ज़रूरत नहीं है।
~~~~
