# परिचय

C# में ऐरे, प्रिमिटिव वैल्यू या स्ट्रक्ट और क्लास के इंस्टेंस का संग्रह होते हैं। ये बेस क्लास लाइब्रेरी में `List<T>` के रूप में बनाए गए हैं, जहाँ `T` ऐरे के एलिमेंट का टाइप है। API में ऐरे बनाने और उन्हें बदलने के लिए बहुत सारे मेथड मौजूद हैं।

ऐरे में एलिमेंट जोड़े और हटाए जा सकते हैं। ज़रूरत पड़ने पर ये बढ़ते और घटते रहते हैं।

```csharp
var listOfStrings = new List<string>();
```
