# परिचय

जब किसी कोटेशन को अपने आसपास की वैल्यू *याद* रखनी हों, तो Factor के पास दो टूल हैं: [`kernel`][kernel] से `curry`/`compose`, और [`fry`][fry] से fry सिंटैक्स `'[ … ]`.

`curry` एक वैल्यू को कोटेशन के सबसे आगे डाल देता है:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` दो कोटेशन को आपस में चिपका देता है:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

एक-दो से ज़्यादा कैप्चर के लिए fry ज़्यादा साफ रहता है। हर `_` प्लेसहोल्डर को स्टैक से ली गई एक वैल्यू से, क्रम से, भर दिया जाता है:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry नेस्टेड कोटेशन के अंदर भी पहुँच जाता है।

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
