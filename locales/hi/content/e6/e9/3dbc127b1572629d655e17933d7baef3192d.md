# परिचय

CoffeeScript एक ऐसी भाषा है जो JavaScript में ट्रांसपाइल होती है। इसका इस्तेमाल डायनामिक वेबसाइट बनाने में होता है, चाहे वे वेब ब्राउज़र में चलें या सर्वर पर। कोड चलाने से पहले ट्रांसपाइलर CoffeeScript कोड को JavaScript में बदल देता है। ऐसा इसलिए किया जाता है ताकि JavaScript की कंपैटिबिलिटी और परफॉर्मेंस पहले जैसी ही बनी रहे, और साथ ही कई नए फीचर भी मिलें!

CoffeeScript को JavaScript लिखने का एक आसान तरीका देने के लिए बनाया गया था। यह Ruby और Python भाषाओं के मेल पर आधारित है। इसका एक अंतर यह है कि यहाँ इंडेंटेशन और एरो का इस्तेमाल होता है, जो JavaScript में फंक्शन लिखने के लंबे तरीके की जगह लेता है। साथ ही यह फंक्शनल भाषाओं से कई काम के फीचर लेता है, जैसे पैटर्न मैचिंग।

CoffeeScript उन कई नई भाषाओं में से एक है जो JavaScript में ट्रांसपाइल होती हैं, जैसे TypeScript और Flow. इन भाषाओं का समुदाय बढ़ रहा है, और इस तरह की भाषाएँ आज बहुत लोकप्रिय हैं।
