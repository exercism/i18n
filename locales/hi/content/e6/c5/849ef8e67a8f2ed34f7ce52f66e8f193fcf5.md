# इंस्टॉलेशन

## तुरंत शुरुआत

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

बिना कुछ बताए यह `/usr/local/bin` में इंस्टॉल हो जाता है। इसे बदलने के लिए डायरेक्टरी का नाम दीजिए:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Linux और macOS के लिए बाइनरी brew से उपलब्ध हैं।

इंस्टॉल कीजिए:

    brew install borkdude/brew/babashka

अपग्रेड कीजिए:

    brew upgrade babashka

## Arch (Linux)

`babashka` [Arch User Repository](https://aur.archlinux.org) में [उपलब्ध](https://aur.archlinux.org/packages/babashka-bin/) है। इसे [AUR](https://aur.archlinux.org) के किसी भी पसंदीदा हेल्पर से इंस्टॉल किया जा सकता है, जैसे [yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) और [pacaur](https://github.com/rmarquis/pacaur)। यहाँ `yay` का इस्तेमाल करके एक उदाहरण दिया गया है:

    yay -S babashka-bin

## Windows

Windows पर आप [scoop](https://scoop.sh/) और [scoop-clojure](https://github.com/littleli/scoop-clojure) बकेट की मदद से इंस्टॉल कर सकते हैं।

## डाउनलोड

आप [Github](https://github.com/borkdude/babashka/releases) से बाइनरी डाउनलोड भी कर सकते हैं। Linux के लिए एक स्टैटिक बाइनरी उपलब्ध है, जिसे Alpine पर इस्तेमाल किया जा सकता है।
