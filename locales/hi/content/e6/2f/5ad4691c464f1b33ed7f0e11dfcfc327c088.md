# परिचय

## ऐरे

Elm में [`List`][lists] एक ही टाइप की शून्य या अधिक वैल्यू का संग्रह होता है, जिसे बदला नहीं जा सकता।

ऐरे इस तरह बनाए जा सकते हैं:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

किसी ऐरे में एलिमेंट जोड़ने का सबसे आम तरीका `::` (cons) ऑपरेटर है:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

ऐरे पर काम करने के लिए या तो [`List` मॉड्यूल][list-module] में बनाए गए फंक्शन और ऑपरेटर इस्तेमाल किए जाते हैं, या [पैटर्न मैचिंग][list-destructuring] की जाती है।

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[lists]: https://elmprogramming.com/list.html
[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
[list-destructuring]: https://www.bekk.christmas/post/2020/8/peeking-inside-lists
