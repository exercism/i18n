# परिचय

[रेंज][range] दो वैल्यू के बीच का अंतराल दर्शाती हैं।
रेंज का इस्तेमाल आम तौर पर `Int`, `String` और `Character` जैसे टाइपों के साथ किया जाता है, ताकि किसी सीक्वेंस पर एक-एक करके चला जा सके, कलेक्शन को स्लाइस किया जा सके, या यह जाँचा जा सके कि कोई वैल्यू दी गई सीमाओं के अंदर आती है या नहीं।

Swift दो मुख्य रेंज ऑपरेटर देता है:

- **क्लोज़्ड रेंज ऑपरेटर (`...`)**: इसमें शुरू और अंत, दोनों वैल्यू शामिल होती हैं (`1...5` में 1, 2, 3, 4 और 5 आते हैं)।
- **हाफ-ओपन रेंज ऑपरेटर (`..<`)**: इसमें शुरू की वैल्यू शामिल होती है, पर अंत की वैल्यू नहीं (`1..<5` में 1, 2, 3 और 4 आते हैं)।

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
जब किसी रेंज लिटरल पर सीधे कोई मेथड कॉल करते हैं, तो रेंज एक्सप्रेशन को ब्रैकेट में लपेटिए, ताकि कंपाइलर पहले रेंज का मूल्यांकन करे:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## रेंज को ऐरे में बदलना

`Array(_:)` इनिशियलाइज़र की मदद से संख्याओं की रेंज को `Array` में बदला जा सकता है:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## रेंज से ऐरे को स्लाइस करना

ऐरे के किसी हिस्से को स्लाइस करने के लिए रेंज का इस्तेमाल किया जा सकता है:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## रेंज की प्रॉपर्टी और मेथड

रेंज पर आम तौर पर किए जाने वाले काम ये हैं:

| मेंबर                  | विवरण                                                | उदाहरण                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | रेंज में मौजूद एलिमेंट की संख्या लौटाता है                | `(1...5).count` `5` लौटाता है          |
| [`contains(_:)`][contains] | अगर रेंज में दी गई वैल्यू शामिल है तो `true` लौटाता है | `(1...5).contains(3)` `true` लौटाता है |

## एकतरफा रेंज

Swift में एकतरफा (आंशिक) रेंज भी होती हैं, जिनमें शुरू या अंत की वैल्यू में से कोई एक छोड़ दी जाती है:

- `array[2...]`: इंडेक्स 2 से लेकर कलेक्शन के अंत तक।
- `array[...2]`: कलेक्शन की शुरुआत से लेकर इंडेक्स 2 तक (2 समेत)।
- `array[..<2]`: कलेक्शन की शुरुआत से इंडेक्स 2 तक, पर 2 को शामिल किए बिना।

## स्ट्रिंग और अक्षर की रेंज

जो अक्षर या स्ट्रिंग `Comparable` के अनुरूप हों, उनके बीच भी रेंज बनाई जा सकती हैं:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
