# इंस्टॉलेशन

यह ट्रैक पूरे तौर पर [Wren Console][wren-console] पर निर्भर करता है, जो आपके कंप्यूटर पर Wren चलाने के लिए एक स्थानीय रनटाइम देता है। इसका मतलब है कि हम यह मानते हैं कि आपके कंप्यूटर पर Wren को चलाने का सारा काम [Wren Console][wren-console] से ही होगा। कृपया इसे Wren के आधिकारिक <abbr title="Command Line Interface">CLI</abbr> से अलग समझें, दोनों को आपस में न मिलाएँ। एक आदर्श दुनिया में आप उस रनटाइम का इस्तेमाल कर सकते थे, लेकिन अभी उसमें [कई](https://github.com/wren-lang/wren-cli/pull/74) [अलग-अलग](https://github.com/wren-lang/wren/pull/1006) [तरह की](https://github.com/wren-lang/wren-cli/issues/108) [समस्याएँ](https://github.com/wren-lang/wren-cli/pull/105) हैं, जिनकी वजह से Exercism के साथ Wren सीखने के लिए वह सबसे अच्छा विकल्प नहीं है।

Wren Console, Wren CLI से फोर्क किया गया है, इन समस्याओं को हल करता है और आपके सीखने के अनुभव को और आसान बनाने के लिए नए फीचर जोड़ता है। चिंता की बात नहीं है: यहाँ जो Wren भाषा का ज्ञान और कॉन्सेप्ट आप सीखेंगे, वे भविष्य में आप जहाँ भी Wren का उपयोग करना चाहें, वहाँ काम आएँगे।

## इंस्टॉलेशन का अवलोकन

- `git` कमांड के लिए Git इंस्टॉल कीजिए
- `wrenc` कमांड के लिए [Wren Console][wren-console] इंस्टॉल कीजिए

### Git इंस्टॉल कीजिए

आपके पास `git` बाइनरी इंस्टॉल होनी चाहिए और आपके पाथ में होनी चाहिए। Wren Package इसी तरीके से पैकेज इंस्टॉल करता है (जैसे वह टेस्ट सूट, जिसकी आपको अपने अभ्यासों की जाँच के लिए ज़रूरत पड़ेगी)।

- **Windows** - शुरू करने के लिए आधिकारिक [Git डाउनलोड](https://git-scm.com/download/win) अच्छी जगह है।
-  **Linux** - आपका पसंदीदा पैकेज मैनेजर आपकी मदद कर देगा।
- **Mac** - Mac OS के सभी हाल के वर्शनों में `git` पहले से ही मौजूद होता है।

आप `git --version` चलाकर जाँच सकते हैं कि Git इंस्टॉल है या नहीं:

```
$ git --version
git version 2.31.1
```

अगर वर्शन बिल्कुल मेल न खाए तो कोई बात नहीं, आम तौर पर यह उतना ज़रूरी नहीं होता।


### Wren Console इंस्टॉल कीजिए

#### Windows

सबसे संभव है कि आप GitHub से [नवीनतम रिलीज़ डाउनलोड][releases] करना चाहें। इसके बाद आपको उसे अनज़िप करना होगा और `wrenc` एक्ज़ीक्यूटेबल को अपने पाथ में कॉपी करना होगा।

Visual Studio की मदद से [सोर्स से बिल्ड करना][build-from-source] भी संभव है।

#### Linux

आप GitHub से [नवीनतम रिलीज़ डाउनलोड][releases] कर सकते हैं या [सोर्स से बिल्ड कर][build-from-source] सकते हैं।

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

और ध्यान रखें कि यह आपके `PATH` में उपलब्ध हो।

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

सबसे आसान तरीका है Exercism का [Homebrew][homebrew] टैप और फॉर्मूला इस्तेमाल करना:

```
brew tap exercism/wren
brew install wren-console
```

या फिर आप GitHub से [नवीनतम रिलीज़ डाउनलोड][releases] करके Linux के निर्देशों में दिखाए अनुसार इसे खुद इंस्टॉल कर सकते हैं। अगर आपको ऐसी चीज़ों का अनुभव है तो सोर्स से बिल्ड करना भी काफी आसान है।

### इंस्टॉलेशन की जाँच

एक बार जब आपको लगे कि बाइनरी ठीक से इंस्टॉल हो गई है, तो यह जाँच लेना अच्छा रहता है कि सब कुछ ठीक चल रहा है।

1. एक _टर्मिनल_ खोलिए (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. `wrenc -v` चलाइए

आपको `wrenc` और Wren दोनों के वर्शन दिखने चाहिए:

```
wrenc v0.3.1 (wren v0.4.0)
```

**ध्यान दें**: यह ज़रूरी है कि आप _नई_ टर्मिनल विंडो खोलें। इंस्टॉलेशन पूरा होने के बाद पहले से खुली टर्मिनल विंडो रीफ्रेश नहीं हुई होंगी। यानी उन खुली टर्मिनलों को पता ही नहीं होगा कि कोई नया प्रोग्राम इंस्टॉल हुआ है।

> _**मदद**_: `'wrenc' is not recognised`
>
> आपने शायद `wrenc` को अपने PATH में नहीं रखा है... MacOS और Linux पर आप अपना पाथ बदलने के लिए नीचे दी गई लाइन `~/.bash_profile` या `~/.zshrc` में जोड़ सकते हैं:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **पता नहीं, इनमें से कुछ भी सही है या नहीं।**
> Windows पर स्टार्ट मेन्यू खोलिए और "environment variables" खोजिए। आपको `PATH` एंट्री संपादित करनी होगी और यहाँ `wrenc` बाइनरियों का पाथ _जोड़ना_ होगा। आम तौर पर ये `C:\Program Files\nodejs` में मिलती हैं। अगर आप अपने `File Explorer` से यहाँ जाएँ, तो आपको `node.exe`, `npm.bat` और `npx.bat` मिलेंगी।
>
> सभी खुली टर्मिनल बंद कीजिए और नई टर्मिनल खोलिए।

## अभ्यास के लिए आवश्यक चीज़ें

अपने OS के लिए `exercism` CLI डाउनलोड करने के लिए कृपया [इन निर्देशों][cli-walkthrough] का पालन कीजिए।

CLI का सेटअप और कॉन्फिगरेशन हो जाने के बाद पहला अभ्यास डाउनलोड कीजिए - `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

इसके बाद हर अभ्यास को टेस्ट चलाने के लिए कुछ Wren पैकेज चाहिए। इन्हें अभ्यास की डायरेक्टरी के अंदर यह कमांड चलाकर इंस्टॉल किया जा सकता है:

```bash
$ wrenc package.wren install
```
