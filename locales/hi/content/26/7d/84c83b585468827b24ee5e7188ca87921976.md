# निर्देश

वायलिन को किसी संदर्भ स्वर के सहारे कान से सुर में किया जाता है। इसके तारों की पिच में बहुत अंतर होता है, और इसमें जो संख्याएँ आती हैं, वे पूर्णांक नहीं होतीं।

पाँचों कार्य `TUNING_THE_STRINGS` क्लास में लिखे जाते हैं।

## 1. एक सप्तक ऊपर

एक सप्तक ऊपर का स्वर आवृत्ति का दोगुना होता है।

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. एक सप्तक नीचे

एक सप्तक नीचे का स्वर आधा होता है।

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. ठीक बीच में

दो आवृत्तियाँ दी गई हों, तो उनके ठीक बीच वाली आवृत्ति लौटाइए।

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. कितना अंतर है?

जब दो स्वर करीब हों पर एक जैसे न हों, तो जितने चक्र का अंतर उनमें है, उतनी बार हर सेकंड एक बीट सुनाई देती है। दोनों आवृत्तियों के बीच का अंतर लौटाइए। जवाब कभी ऋणात्मक नहीं होता, चाहे कोई भी स्वर ऊँचा हो।

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. अभ्यास का बँटवारा

अगर मिनटों की संख्या और खिलाड़ियों की संख्या दी गई हो, तो हर एक को कितने मिनट मिलेंगे? मिनट और खिलाड़ी, दोनों पूर्णांक हैं, पर जवाब ज़रूरी नहीं कि पूर्णांक हो।

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
