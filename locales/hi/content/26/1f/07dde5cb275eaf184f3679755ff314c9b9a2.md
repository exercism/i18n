# इसके बारे में

[`throw` एक्सप्रेशन][throw-expressions] `throw` स्टेटमेंट का विकल्प हैं। खास तौर पर ये टर्नरी और अन्य संयुक्त एक्सप्रेशन को और शक्तिशाली बना सकते हैं।

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

ऊपर दिए गए कोड में अगर `str` की वैल्यू `null` है, तो कोड एक एक्सेप्शन फेंकता है।

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
