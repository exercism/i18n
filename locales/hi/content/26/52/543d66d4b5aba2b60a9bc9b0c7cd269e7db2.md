# परिचय

मेथड एक ऐसा फंक्शन है जिसमें एक खास आर्गुमेंट होता है, जिसे _रिसीवर_ कहते हैं।
रिसीवर अपनी अलग आर्गुमेंट सूची में `func` कीवर्ड और मेथड के नाम के बीच आता है।

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

आप किसी मेथड को केवल ऐसे रिसीवर के साथ बना सकते हैं जिसका टाइप उसी पैकेज में परिभाषित हो जिसमें वह मेथड है।

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

रिसीवर दो तरह के होते हैं: वैल्यू रिसीवर और पॉइंटर रिसीवर।

वैल्यू रिसीवर वाले मेथड उस वैल्यू की एक कॉपी पर काम करते हैं जो उन्हें दी जाती है। इसका मतलब है कि मेथड के अंदर रिसीवर में किया गया कोई भी बदलाव कॉल करने वाले को दिखाई नहीं देता।

आप पॉइंटर रिसीवर वाले मेथड भी घोषित कर सकते हैं, ताकि उस वैल्यू को बदला जा सके जिसकी ओर रिसीवर इशारा करता है।
इसके लिए टाइप के नाम से पहले `*` लगाया जाता है। जैसे `rect` टाइप के लिए पॉइंटर रिसीवर `*rect` के रूप में घोषित किया जाएगा।
ऐसे बदलाव मेथड को कॉल करने वाले को भी दिखाई देते हैं।

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
