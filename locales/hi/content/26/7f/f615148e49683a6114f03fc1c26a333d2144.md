# निर्देश

एक सम्मिश्र संख्या ऐसी संख्या होती है जिसे `a + b * i` के रूप में लिखा जाता है, जहाँ `a` और `b` वास्तविक हैं और `i` के लिए `i^2 = -1` होता है।

`a` को वास्तविक भाग कहते हैं और `b` को `z` का काल्पनिक भाग कहते हैं।
संख्या `a + b * i` का संयुग्मी संख्या `a - b * i` होती है।
सम्मिश्र संख्या `z = a + b * i` का निरपेक्ष मान एक वास्तविक संख्या `|z| = sqrt(a^2 + b^2)` होता है। निरपेक्ष मान का वर्ग `|z|^2`, `z` को उसके संयुग्मी से गुणा करने का परिणाम होता है।

दो सम्मिश्र संख्याओं का जोड़ या अंतर निकालने में उनके वास्तविक और काल्पनिक भागों को अलग-अलग जोड़ा या घटाया जाता है:
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

गुणा का परिणाम परिभाषा से यह होता है
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

किसी शून्येतर सम्मिश्र संख्या का व्युत्क्रम होता है
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

सम्मिश्र संख्या `a + i * b` को दूसरी संख्या `c + i * d` से भाग देने पर यह मिलता है:
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

e को एक सम्मिश्र घात तक बढ़ाने को `e^(a + i * b) = e^a * e^(i * b)` के रूप में लिखा जा सकता है, जिसका अंतिम पद ऑयलर के सूत्र `e^(i * b) = cos(b) + i * sin(b)` से मिलता है।

इन कार्यों को लागू कीजिए:
 - दो सम्मिश्र संख्याओं का जोड़, घटाव, गुणा और भाग,
 - किसी दी गई सम्मिश्र संख्या का संयुग्मी, निरपेक्ष मान और घात।


मान लीजिए कि आप जिस प्रोग्रामिंग भाषा का उपयोग कर रहे हैं, उसमें सम्मिश्र संख्याओं का कोई कार्यान्वयन नहीं है।
