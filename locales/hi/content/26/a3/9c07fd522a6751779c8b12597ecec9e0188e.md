# निर्देश

नौकरी करने वाले लगभग हर व्यक्ति की तरह, Lisp Alien लैला को भी कभी-कभी रिपोर्ट बनानी पड़ती है ताकि वे दूसरों को जानकारी दे सकें। वे आपसे पूछती हैं कि क्या आप इन रिपोर्टों के लिए उनके पास मौजूद डेटा को फॉर्मेट करने में उनकी मदद कर सकते हैं।

## 1. तिमाही वैल्यू को फॉर्मेट करना

लैला को सबसे पहले एक फंक्शन चाहिए: `format-quarter-value`, जो दो पैरामीटर लेता है: कैलेंडर तिमाही और वैल्यू, और इसे रिपोर्ट के लिए फॉर्मेट करता है। इसका परिणाम एक स्ट्रिंग होना चाहिए।

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. दो तिमाही वाली रिपोर्ट

लैला आपको `format-quarter-value` फंक्शन के लिए धन्यवाद देती हैं और कहती हैं कि जो *अगला* फंक्शन चाहिए, उसमें यह बहुत काम आएगा।

अगली रिपोर्ट में दो तिमाहियों की तिमाही और वैल्यू दो लाइनों में छपी हुई दिखनी चाहिए।

साथ ही आउटपुट उस स्ट्रीम में जाना चाहिए जो पहले आर्गुमेंट के रूप में दी गई है।

उदाहरण के लिए: `(format-two-quarters t "last" 3.14 "this" 0)` स्टैंडर्ड आउटपुट पर यह दिखाएगा:

```

The value last quarter: 3.14
The value this quarter: 0

```

ध्यान दीजिए कि इसके आगे-पीछे खाली लाइनें हैं।

## 3. इंसान बनाम Lisp Alien के लिए पढ़ने योग्य

लैला आपको बताना भूल गईं कि Lisp Alien वैल्यू को ऐसे रूप में देखना पसंद करते हैं जिसे Lisp डेटा की तरह पढ़ा जा सके। इसलिए उन्हें एक नया फंक्शन चाहिए जिसे Lisp डेटा की तरह पढ़ा जा सके (और यह भी उसी स्ट्रीम में जाए):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
