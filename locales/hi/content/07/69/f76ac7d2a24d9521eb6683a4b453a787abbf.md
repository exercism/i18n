# अच्छा सपोर्ट रिक्वेस्ट कैसे लिखें

क्या आपको Exercism में मदद चाहिए?
अच्छा सपोर्ट रिक्वेस्ट लिखना सीखकर और अपने समुदाय को आपकी मदद के लिए प्रेरित करके अच्छा जवाब मिलने की अपनी संभावनाएँ बढ़ाइए।

यहाँ कुछ खास सुझाव दिए गए हैं।

## कोड ब्लॉक इस्तेमाल कीजिए, इमेज नहीं

जब आप कोड साझा करना चाहें (चाहे वह आपका लिखा हुआ हो या कोई निर्देश), तो कोड ब्लॉक इस्तेमाल कीजिए, इमेज नहीं।

डेवलपर होने के नाते, हम इमेज में ज़ूम करके चीज़ें देखने से कहीं ज़्यादा तेज़ी से कोड पढ़ लेते हैं।
और हमारे बहुत से यूज़र स्क्रीन रीडर इस्तेमाल करते हैं, जो इमेज नहीं पढ़ सकते।
तो अगर आप समुदाय के अच्छे सदस्य बनना चाहते हैं, हमारे स्वयंसेवकों को आपकी मदद करने के लिए प्रेरित करना चाहते हैं, और एक प्रो जैसे दिखना चाहते हैं, तो अपना कोड इमेज के बजाय टेक्स्ट के रूप में साझा कीजिए!

उदाहरण के लिए, आप यह लिख सकते हैं:

````
```
for number in range(10):
  total += number;
```
````

यह ऐसे रेंडर होगा:

```
for number in range(10):
  total += number;
```

कोड ब्लॉक के शुरू में भाषा जोड़कर आप सिंटैक्स हाइलाइटिंग भी पा सकते हैं:

````
```python
for number in range(10):
  total += number;
```
````

जो ऐसा बन जाता है:

```python
for number in range(10):
  total += number;
```

## समावेशी भाषा इस्तेमाल कीजिए

Exercism अलग-अलग जेंडर के लोगों से बना है।
अगर आप हमारे Discord पर आकर "Hey boys" जैसी बातें कहते हैं, तो आप तुरंत हमारे समुदाय के आधे हिस्से को बाहर कर देते हैं।
इसका मतलब है कि उनके आपकी मदद करने की संभावना कम हो जाती है। साथ ही बाकी समुदाय के लोगों की भी आपकी मदद करने की संभावना कम हो जाती है, क्योंकि Exercism में हम समावेशिता को महत्व देते हैं।

तो अगर आप मदद पाना चाहते हैं और एक अच्छे इंसान बनना चाहते हैं, तो जेंडर-विशेष भाषा इस्तेमाल न कीजिए।
