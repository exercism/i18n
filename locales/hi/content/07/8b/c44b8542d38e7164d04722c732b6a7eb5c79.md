# अभ्यास का परीक्षण

किसी अभ्यास का हल तैयार करने और उसे अपने कंप्यूटर पर परखने के लिए नीचे दिए गए चरणों का पालन कीजिए।

## अभ्यास डाउनलोड कीजिए

एक Command Prompt खोलिए और नीचे दिया गया कमांड चलाइए। जिस अभ्यास को डाउनलोड करना है, उसका नाम इसमें डालिए।

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## अपना हल तैयार कीजिए

1. अभी डाउनलोड किए गए अभ्यास की डायरेक्टरी में जाने के लिए नीचे दिया गया कमांड चलाइए।

     >**सुझाव:** नीचे दिए गए कमांड में डायरेक्टरी की जगह आपके ऑपरेटिंग सिस्टम और आपके सेट किए गए Exercism वर्कस्पेस पर निर्भर करती है। आप अपने वर्कस्पेस की जगह `exercism configure` कमांड चलाकर पता कर सकते हैं।

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. दिए गए निर्देशों का पालन कीजिए और अभ्यास का हल तैयार कीजिए।

## अपने हल का परीक्षण कीजिए

Ballerina के कुछ अभ्यासों में एक ही टेस्ट होता है, जबकि कुछ में कई टेस्ट होते हैं। टेस्ट संबंधित टेस्ट फाइल में मिलते हैं, जो अभ्यास की रूट डायरेक्टरी के अंदर `/tests` डायरेक्टरी में होती है।

### एक टेस्ट वाले अभ्यास का परीक्षण कीजिए

अभ्यास का टेस्ट चलाने के लिए नीचे दिया गया कमांड चलाइए।

डिफ़ॉल्ट रूप से सिर्फ पहला टेस्ट ही सक्षम रहता है। यह जानबूझकर ऐसा है, ताकि आप अपना ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर लगा सकें। 
     
```sh
bal test
```

### कई टेस्ट वाले अभ्यास का परीक्षण कीजिए

कई टेस्ट वाले अभ्यास का परीक्षण करने के लिए नीचे दिए गए चरणों का पालन कीजिए।

1. पहला टेस्ट पास हो जाने पर, `@test:Config` एनोटेशन से `enable: false` प्रॉपर्टी हटाकर अगला टेस्ट सक्षम कीजिए।

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  सक्षम किए गए टेस्ट को चलाने के लिए नीचे दिया गया कमांड चलाइए।

   ```sh
     bal test
   ```

3. बाकी टेस्ट सक्षम करने के लिए ऊपर दिए गए दोनों चरण दोहराइए।

सारे टेस्ट सक्षम करके और यह सुनिश्चित करके कि आपका हल हर टेस्ट को पास करता है, आपने अभ्यास सफलतापूर्वक पूरा कर लिया है।
