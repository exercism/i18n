# निर्देश

कम्युनिटी गार्डन के रजिस्ट्रेशन संभालने के लिए आपकी कम्युनिटी एसोसिएशन ने आपसे एक सरल रजिस्ट्री एप्लिकेशन बनाने को कहा है। `Plot` स्ट्रक्चर आपके लिए पहले से दिया गया है।

## 1. गार्डन खोलिए

`CommunityGarden.start/1` फंक्शन बनाइए। इसे विकल्पों की एक वैकल्पिक कीवर्ड सूची मिलनी चाहिए, जिसे आगे _एजेंट प्रोसेस_ को भेजा जाएगा। शुरू में गार्डन की स्थिति ऐसी होनी चाहिए जो प्लॉट के खाली संग्रह को दर्शाए। इसे गार्डन की pid के साथ एक `:ok` टपल लौटाना चाहिए।

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. रजिस्ट्रेशन की सूची दिखाइए

`CommunityGarden.list_registrations/1` फंक्शन बनाइए। इसे कम्युनिटी गार्डन की `pid` मिलनी चाहिए। इसे उन संग्रहीत प्लॉट की सूची लौटानी चाहिए जो रजिस्टर हैं।

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> अभी हमने प्लॉट रजिस्टर करने की सुविधा नहीं जोड़ी है, इसलिए यह सूची खाली होनी चाहिए

## 3. प्लॉट किसी व्यक्ति के नाम रजिस्टर कीजिए

`CommunityGarden.register/2` फंक्शन बनाइए। इसे कम्युनिटी गार्डन की `pid` और प्लॉट रजिस्टर करने के लिए एक नाम मिलना चाहिए। सफल होने पर इसे वह `Plot` स्ट्रक्चर लौटाना चाहिए जिसमें प्लॉट की id और वह व्यक्ति हो जिसके नाम पर प्लॉट रजिस्टर हुआ है।

id बढ़ते क्रम में और अद्वितीय होनी चाहिए। आप एजेंट की स्थिति में एक id काउंटर रख सकते हैं।

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. प्लॉट खाली कीजिए

`CommunityGarden.release/2` फंक्शन बनाइए। इसे उस प्लॉट की `pid` और `id` मिलनी चाहिए जिसे खाली करना है। सफल होने पर इसे `:ok` लौटाना चाहिए। प्लॉट खाली होने पर उसकी id दोबारा इस्तेमाल नहीं होती। वह सिर्फ एक अद्वितीय पहचानकर्ता के तौर पर इस्तेमाल होती है।

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. रजिस्टर किए गए प्लॉट पाइए

`CommunityGarden.get_registration/2` फंक्शन बनाइए। इसे उस प्लॉट की `pid` और `id` मिलनी चाहिए जिसे जाँचना है। अगर प्लॉट रजिस्टर है तो इसे वह प्लॉट लौटाना चाहिए, और अगर रजिस्टर नहीं है तो `:not_found` लौटाना चाहिए।

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
