# निर्देश

इस अभ्यास में आप एक इन्वेंटरी सिस्टम संभालेंगे।

इन्वेंटरी को चीज़ों के नाम के अनुसार व्यवस्थित किया जाना चाहिए और उसमें उपलब्ध चीज़ों की संख्या का हिसाब रखना चाहिए।

आपको इन्वेंटरी में चीज़ें जोड़ने का काम भी करना होगा।
जब भी कोई चीज़ किसी दी गई ऐरे में आए, उस चीज़ की मात्रा इन्वेंटरी में `1` से बढ़ा देनी चाहिए।
आपको इन्वेंटरी से चीज़ें हटाने का काम भी करना होगा। इसके लिए कहने पर उनकी मात्रा `1` से घटानी होगी।

अंत में, आपको एक ऐसा फंक्शन बनाना होगा जो किसी दी गई इन्वेंटरी की सारी की-वैल्यू जोड़े `tuples` की एक `list` के रूप में लौटाए।


## 1. ऐरे के आधार पर एक इन्वेंटरी बनाइए

`create_inventory(<input list>)` फंक्शन बनाइए जो चीज़ों की एक इनपुट ऐरे से एक इन्वेंटरी बनाता है।
इसे एक `dict` लौटाना चाहिए जिसमें हर चीज़ का नाम उसकी मात्रा के साथ जुड़ा हो।

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. ऐरे से चीज़ें एक मौजूदा डिक्शनरी में जोड़िए

`add_items(<inventory dict>, <item list>)` फंक्शन बनाइए, जो चीज़ों की एक ऐरे को पास की गई इन्वेंटरी में जोड़ता है:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. इन्वेंटरी से चीज़ों की मात्रा घटाइए

`decrement_items(<inventory dict>, <items list>)` फंक्शन बनाइए, जो चीज़ों की एक `list` लेता है।
हर बार जब कोई चीज़ `list` में आए, आपके फंक्शन को उस चीज़ की मात्रा से `1` घटाना चाहिए:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

इन्वेंटरी में किसी भी चीज़ की मात्रा 0 से नीचे नहीं जानी चाहिए।
 अगर कोई चीज़ इनपुट `list` में उपलब्ध मात्रा से ज़्यादा बार आती है, तो उस चीज़ की मात्रा 0 ही रहनी चाहिए।
 एक बार मात्रा शून्य हो जाने के बाद घटाने के और अनुरोधों को अनदेखा कर देना चाहिए।

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. इन्वेंटरी से कोई प्रविष्टि पूरी तरह हटाइए

`remove_item(<inventory dict>, <item>)` फंक्शन बनाइए, जो किसी चीज़ को और उसकी मात्रा को इन्वेंटरी से पूरी तरह हटा देता है:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

अगर वह चीज़ इन्वेंटरी में न मिले, तो फंक्शन को मूल इन्वेंटरी बिना बदले ही लौटानी चाहिए।

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. इन्वेंटरी की पूरी सामग्री लौटाइए

`list_inventory(<inventory dict>)` फंक्शन बनाइए, जो एक इन्वेंटरी लेता है और `(item, quantity)` tuples का एक ऐरे लौटाता है।
इस ऐरे में सिर्फ _उपलब्ध_ चीज़ें ही शामिल होनी चाहिए (_यानी जिनकी मात्रा शून्य से ज़्यादा हो_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
