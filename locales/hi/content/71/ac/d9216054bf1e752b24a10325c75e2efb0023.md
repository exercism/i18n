# परिचय

Factor के अधिकतर सीक्वेंस शब्द *नए* सीक्वेंस लौटाते हैं और अपने इनपुट को जैसा का जैसा छोड़ देते हैं। लेकिन जब आपको समय के साथ बदलती रहने वाली स्थिति दर्ज करनी हो, तब ऐरे और वेक्टर, दोनों **इन-प्लेस म्यूटेशन** का साथ देते हैं।

`set-nth` और `change-nth` किसी स्लॉट को उसी जगह बदल देते हैं, और ऐरे तथा वेक्टर, दोनों पर काम करते हैं। `<array>` एक तय लंबाई वाला बदलने योग्य ऐरे बनाता है। `V{ }` लिटरल, `<vector>`, `push` और `pop` सिर्फ वेक्टर के लिए हैं, क्योंकि ऐरे की लंबाई बदली नहीं जा सकती। `clone` सीक्वेंस की एक और प्रति बना देता है, ताकि आगे के बदलाव मूल सीक्वेंस पर असर न डालें।

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
