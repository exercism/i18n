# परिचय

Gleam में स्ट्रिंग अपरिवर्तनीय टेक्स्ट होती हैं, जिनके चारों ओर डबल कोट्स लगे होते हैं। इनमें यूनिकोड अक्षर भी रह सकते हैं, और ये एक से ज़्यादा लाइनों में लिखी जा सकती हैं।

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

स्ट्रिंग को `<>` ऑपरेटर की मदद से जोड़ा जा सकता है:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

स्टैंडर्ड लाइब्रेरी में मौजूद [`gleam/string`][stdlib] मॉड्यूल स्ट्रिंग के साथ काम करने के लिए फंक्शन देता है।

`case` एक्सप्रेशन में स्ट्रिंग का मैच किया जा सकता है:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

अगर आप स्ट्रिंग की शुरुआत से मैच करना चाहते हैं और बाकी हिस्से को किसी वेरिएबल में असाइन करना चाहते हैं, तो आप `<>` ऑपरेटर पैटर्न इस्तेमाल कर सकते हैं:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
