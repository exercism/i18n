# टेस्ट

## टेस्ट चलाना

जब आप किसी अभ्यास की डायरेक्टरी में होते हैं, तो आपको दो सब-डायरेक्टरियाँ दिखनी चाहिए:

* `Sources/<Exercise>` में आपके अभ्यास का हल होता है
* `Tests/<Exercise>Tests` में उस अभ्यास के लिए चलाए जाने वाले टेस्ट होते हैं

अगर आप सही डायरेक्टरी में हैं (यानी वह डायरेक्टरी जिसमें `Sources` और `Tests` हैं), तो आप `swift test` चलाकर उस अभ्यास के टेस्ट चला सकते हैं:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

जब कोई एक टेस्ट पास हो जाए, तो अगला टेस्ट चालू करने के लिए `@Test` स्टेटमेंट में `.enabled(if: RUNALL)` हटा दीजिए। इसके अलावा, Linux या macOS पर `RUNALL` एनवायरनमेंट वेरिएबल को `true` पर सेट करके आप सारे टेस्ट चला सकते हैं:

```bash
$ export RUNALL=true
```

या अगर आप Windows पर PowerShell इस्तेमाल कर रहे हैं:

```powershell
set RUNALL=true
```

## अपना हल सबमिट करना

Exercism पर अपना हल अपलोड करने के लिए आपको उस डायरेक्टरी में होना चाहिए जिसमें `Sources` और `Tests` डायरेक्टरियाँ हों।

```bash
$ exercism submit 
```
