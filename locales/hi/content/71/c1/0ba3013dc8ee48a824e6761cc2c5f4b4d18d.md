# GitHub पर सिंक कीजिए

नमस्ते सभी को!

पिछले कुछ महीनों में हमने अपने [Coding Fundamentals](https://exercism.org/courses/coding-fundamentals) और [Front-End Fundamentals Bootcamp](https://exercism.org/courses/front-end-fundamentals) पर कड़ी मेहनत की है। ये दोनों हमारे लिए बहुत शानदार अनुभव रहे हैं। अब जब ये पूरे हो चुके हैं, तो हम थोड़ा समय Exercism की मुख्य साइट में कुछ नए फीचर जोड़ने पर लगा रहे हैं!

आज हम Exercism पर **दो नए फीचर** उपलब्ध करा रहे हैं:
1. अपने हल GitHub पर सिंक कीजिए।
2. अपने Favorites सहेजिए और उन्हें देखिए।

## अपने हल GitHub पर सिंक कीजिए

अपने हलों का एक सार्वजनिक बैकअप अपने पास हो, यह लोग बहुत समय से चाह रहे थे। बहुत से लोग अपने हल खुद GitHub पर सिंक करते हैं, या इसके लिए अपनी स्क्रिप्ट तक लिख लेते हैं। लेकिन अब यह फीचर **Exercism में ही मौजूद है!**

इस फीचर को चालू करते ही आपके हल अपने आप GitHub पर बैकअप होने लगेंगे। आप तय कर सकते हैं कि बैकअप Pull Requests के ज़रिए हो या commits के ज़रिए। साथ ही, अपने सारे पुराने हल एक साथ अपलोड भी कर सकते हैं!

एक महीना पहले हमने इसे चुपचाप Insiders के लिए उपलब्ध कराया था, और अब तक दसियों हज़ार हल GitHub पर बैकअप हो चुके हैं। जितने ज़्यादा लोगों ने इसका इस्तेमाल किया, उतना ही ज़्यादा उन्होंने इसकी सराहना की। जैसा कि एक Insider ने कहा:

> जब यह फीचर पहली बार प्रस्तावित हुआ था, तब मेरी इसके बारे में कोई खास राय नहीं थी, लेकिन अब जब यह आ गया है, तो मैं बहुत खुश हूँ कि आपने इसे आगे बढ़ाया! मैं तो अब इसके बिना Exercism की कल्पना भी नहीं कर सकता।
> 
> \- W8CYE, Discord पर

शुरू करने के लिए बस नए [GitHub Syncer सेटिंग्स पेज](https://exercism.org/settings/github_syncer) पर जाइए और एक रिपॉज़िटरी जोड़िए!

## Favorites

आज हम [Exercism Favorites](https://exercism.org/favorites) भी उपलब्ध करा रहे हैं। यह एक ऐसी जगह है जहाँ आप Exercism पर मिले सबसे अच्छे हल सहेज सकते हैं और उन्हें देख सकते हैं।

Favorites की मदद से आप जो भी चीज़ दिलचस्प, प्रेरक या प्रभावशाली लगे, उसे सहेज सकते हैं। आप साइट पर जहाँ भी जाएँ, किसी भी हल पर स्टार लगा सकते हैं, और जब भी किसी चीज़ में और गहराई तक जाना चाहें, उस पर फिर से लौट सकते हैं।

कोई चीज़ Favorites में जोड़ने के लिए बस किसी भी कम्युनिटी हल पर "Favorite" बटन क्लिक कीजिए। आप देखेंगे कि टेक्स्ट "Favorited" में बदल जाता है और स्टार सुनहरा हो जाता है!
अगर आप किसी चीज़ को Favorites से हटाना चाहते हैं, तो उसी बटन पर फिर से क्लिक कीजिए।

<img src="https://assets.exercism.org/images/community/favorites-button.png" alt="कम्युनिटी हल के पेज का स्क्रीनशॉट, जिसमें Favorite बटन दिख रहा है" style="width:100%; max-width:600px;" width="2182" height="980" />

आपने अब तक जिन हलों पर स्टार लगाया है, वे सब अपने आप आपके Favorites में पहुँच गए हैं। आप Favorites तक Learn मेन्यू से पहुँच सकते हैं, या सीधे [इस लिंक](https://exercism.org/favorites) से।
