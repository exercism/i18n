# परिचय

## मूल बातें

Java एक स्टैटिकली-टाइप्ड भाषा है, जिसका मतलब है कि किसी वेरिएबल का टाइप कंपाइल टाइम पर ही पता होता है।
किसी नाम को वैल्यू असाइन करने को वेरिएबल घोषित करना कहा जाता है।
वेरिएबल को उसका टाइप स्पष्ट रूप से लिखकर घोषित किया जाता है।

```java
int explicitVar = 10;
```

किसी वेरिएबल की वैल्यू को अपडेट करने के लिए `=` ऑपरेटर का उपयोग किया जाता है।
यहाँ `=` गणितीय समानता को नहीं दर्शाता।
यह केवल एक वेरिएबल को वैल्यू असाइन करता है।
एक बार घोषित होने के बाद, वेरिएबल का टाइप कभी नहीं बदल सकता।

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java एक [ऑब्जेक्ट-ओरिएंटेड भाषा][object-oriented-programming] है और इसमें सभी फंक्शन को एक _क्लास_ के अंदर बनाना जरूरी है।
क्लास बनाने के लिए `class` कीवर्ड का उपयोग किया जाता है।

```java
class Calculator {
    // ...
}
```

क्लास के अंदर के फंक्शन को _मेथड_ कहा जाता है।
प्रत्येक मेथड में शून्य या अधिक पैरामीटर हो सकते हैं।
सभी पैरामीटर का टाइप स्पष्ट रूप से लिखना जरूरी है, पैरामीटर के लिए कोई टाइप अनुमान नहीं होता।
इसी तरह, रिटर्न टाइप भी स्पष्ट रूप से लिखना जरूरी है।
मेथड से वैल्यू लौटाने के लिए `return` कीवर्ड का उपयोग किया जाता है।
किसी मेथड को दूसरी क्लासों से कॉल करने की अनुमति देने के लिए, `public` एक्सेस मॉडिफायर जोड़ना जरूरी है।

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

किसी मेथड को कॉल करने के लिए उसकी क्लास और मेथड का नाम बताना होता है और मेथड के प्रत्येक पैरामीटर के लिए आर्गुमेंट पास करने होते हैं।

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Java में स्कोप `{` और `}` के बीच तय होता है।

Java में दो तरह के कमेंट होते हैं।
सिंगल लाइन कमेंट `//` से पहले लिखे जाते हैं और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
