# परिचय

फंक्शन आर्गुमेंट की बुनियादी बातों के लिए [फंक्शन कॉन्सेप्ट][function concept] देखिए।

## पैरामीटर के नाम

पैरामीटर के नाम, वेरिएबलो के नाम की तरह, किसी अक्षर या अंडरस्कोर से शुरू होने चाहिए और उनमें अक्षर, अंडरस्कोर या संख्याएँ हो सकती हैं।
पैरामीटर के नामों में स्पेस या विराम चिह्न नहीं होने चाहिए।


## पोज़िशनल आर्गुमेंट

पोज़िशनल आर्गुमेंट वे वैल्यू हैं जो फंक्शन को उसी क्रम में दी जाती हैं जिस क्रम में उनसे जुड़े पैरामीटर होते हैं।
चाहें तो इन्हें इनके पैरामीटर के नाम से भी दिया जा सकता है:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

concat को पहली बार कॉल करने पर आर्गुमेंट पोज़िशन के अनुसार दिए जाते हैं।
concat को दूसरी बार कॉल करने पर आर्गुमेंट _नाम_ से दिए जाते हैं, जिससे उनके पोज़िशन बदले जा सकते हैं।

ध्यान रखिए कि पोज़िशनल आर्गुमेंट उन आर्गुमेंट के बाद नहीं आ सकते जो नाम से दिए गए हों (_इन्हें [कीवर्ड आर्गुमेंट][keyword-arguments] भी कहते हैं। इन्हें वर-पोज़िशनल पैरामीटर या [**kwargs][kwargs] से भ्रमित **न** कीजिए_)।

आर्गुमेंट का यह समूह:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

इससे यह एरर आएगी:

```
SyntaxError: positional argument follows keyword argument
```

## आर्गुमेंट की डिफॉल्ट वैल्यू

पैरामीटर लिस्ट में एक या अधिक आर्गुमेंट के लिए [डिफॉल्ट वैल्यू][default arguments] दी जा सकती हैं।
इससे ज़रूरत पड़ने पर फंक्शन को _कम_ आर्गुमेंट के साथ कॉल किया जा सकता है।
डिफॉल्ट वैल्यू को बदला जा सकता है: इसके लिए फंक्शन को डिफॉल्ट की जगह नए आर्गुमेंट के साथ कॉल कीजिए:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## कीवर्ड आर्गुमेंट

कीवर्ड आर्गुमेंट फंक्शन को आर्गुमेंट देते समय पैरामीटर के नाम का उपयोग करते हैं।
चाहें तो इन्हें पोज़िशन के अनुसार भी दिया जा सकता है:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
