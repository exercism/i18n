# Ceylon के टेस्ट चलाना

टेस्ट चलाने से पहले आपके कोड को [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html) से कंपाइल करना ज़रूरी है।

हम टेस्ट [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html) कमांड से चलाते हैं।

`ceylon test` को टेस्ट चलाने के लिए एक मॉड्यूल का नाम चाहिए।
Ceylon ट्रैक में हर अभ्यास में सिर्फ एक ही मॉड्यूल होता है।

इसलिए, आप टेस्ट इस तरह चला सकते हैं:

```bash
ceylon compile && ceylon test $(basename source/*)
```
