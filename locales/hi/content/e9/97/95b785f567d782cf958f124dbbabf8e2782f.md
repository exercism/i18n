# टेस्ट

दिए गए टेस्ट चलाने के लिए आपको Minitest जेम की ज़रूरत होगी। एक टर्मिनल विंडो खोलिए और minitest इंस्टॉल करने के लिए यह कमांड चलाइए:

```
gem install minitest
```


अभ्यास की डायरेक्टरी से यह कमांड चलाकर टेस्ट चलाइए:

```
ruby <snake-case-exercise>_test.rb
```

कृपया `<snake-case-exercise>` के स्थान पर अपने अभ्यास का नाम snake_case में लिखिए।

## रंगीन आउटपुट

रंगीन आउटपुट पाने के लिए आप `require 'minitest/pride'` लिख सकते हैं या यह कमांड चला सकते हैं:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
