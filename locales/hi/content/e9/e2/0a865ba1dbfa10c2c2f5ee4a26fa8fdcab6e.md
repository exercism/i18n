# परिचय

## अंकगणितीय ऑपरेटर

JavaScript संख्याओं पर आधारभूत अंकगणितीय ऑपरेशन करने के लिए 6 अलग-अलग ऑपरेटर देता है।

- `+`: जोड़ का ऑपरेटर संख्याओं का योग निकालने के लिए इस्तेमाल किया जाता है।
- `-`: घटाव का ऑपरेटर दो संख्याओं के बीच का अंतर निकालने के लिए इस्तेमाल किया जाता है।
- `*`: गुणा का ऑपरेटर दो संख्याओं का गुणनफल निकालने के लिए इस्तेमाल किया जाता है।
- `/`: भाग का ऑपरेटर दो संख्याओं को भाग देने के लिए इस्तेमाल किया जाता है।

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: शेषफल का ऑपरेटर भाग करने पर जो शेषफल बचता है, उसे निकालने के लिए इस्तेमाल किया जाता है।

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: घातांक का ऑपरेटर किसी संख्या को घात तक बढ़ाने के लिए इस्तेमाल किया जाता है।

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## ऑपरेशन का क्रम

एक ही लाइन में कई ऑपरेटर इस्तेमाल करने पर JavaScript [इस प्राथमिकता तालिका][mdn-operator-precedence] में दिखाए गए क्रम का पालन करता है।
इसे आसान बनाकर देखें तो JavaScript वही PEDMAS (कोष्ठक, घात, भाग/गुणा, जोड़/घटाव) नियम अपनाता है, जो हमने स्कूल की शुरुआती गणित कक्षाओं में सीखा था।

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## संक्षिप्त असाइनमेंट ऑपरेटर

संक्षिप्त असाइनमेंट ऑपरेटर किसी वेरिएबल पर अंकगणितीय ऑपरेशन करने और नई वैल्यू उसी वेरिएबल में असाइन करने का छोटा तरीका हैं।
उदाहरण के लिए, मान लीजिए `x` और `y` दो वेरिएबल हैं।
तब `x += y` का मतलब वही है जो `x = x + y` का है।
अक्सर इसे वेरिएबल `y` की जगह किसी संख्या के साथ इस्तेमाल किया जाता है।
बाकी 5 ऑपरेशन भी इसी तरह किए जा सकते हैं।

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
