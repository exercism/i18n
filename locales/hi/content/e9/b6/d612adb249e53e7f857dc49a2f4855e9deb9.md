# थ्रेड

यह अभ्यास थ्रेड से परिचय कराता है, ताकि जाँचा जा सके कि आपका बैंक खाता एक साथ होने वाली क्रियाओं के लिए कितना मज़बूत है। Tcl थ्रेड के लिए कुछ पढ़ने की सामग्री:

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf),
  जो _Practical Programming in Tcl and Tk, 4th Ed._ का एक अध्याय है,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * ध्यान दें, इस अध्याय में लिखा है कि "Tcl के अधिकांश बाइनरी डिस्ट्रिब्यूशन थ्रेड के बिना बनाए जाते हैं"। अब ऐसा नहीं है: अब Tcl डिस्ट्रिब्यूशन थ्रेड समर्थन के साथ बनाए जाते हैं (देखें [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* Tcl के डॉक्यूमेंटेशन से [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm)।

## इंस्टॉलेशन

कुछ Tcl डिस्ट्रिब्यूशन में Tcl का Thread पैकेज डिफ़ॉल्ट रूप से शामिल नहीं होता: उसे अलग से इंस्टॉल करना पड़ सकता है। इसे ऐसे जाँचिए
```bash
$ echo 'package require Thread' | tclsh
```
अगर उससे _कोई आउटपुट नहीं_ आता, तो Thread पैकेज पहले से इंस्टॉल है।

ज़रूरत पड़ने पर `apt install tcl-thread` (या `dnf install tcl-thread`) चलाइए।
