# निर्देश

नृत्य मंडली अपने साल के अंत के शो की तैयारी कर रही है। उसे यह तय करना है कि नर्तकों को कितने तरीकों से कतार में लगाया जा सकता है, और पूरा समय अंकों के बीच कैसे बँटता है।

पाँचों काम `FORMATION_COUNT` क्लास में लिखने हैं।

## 1. कितनी कतारें?

`n` नर्तकों को कतार में लगाने के `n` फैक्टोरियल तरीके होते हैं: सबसे आगे के लिए `n` विकल्प, फिर अगले के लिए `n-1`, और इसी तरह आगे भी। इसे एक `INTI` के रूप में लौटाइए। शून्य नर्तकों की ठीक एक कतार होती है, और वह खाली कतार है।

```sather
FORMATION_COUNT::line_ups(5)
-- => 120
FORMATION_COUNT::line_ups(20)
-- => 2432902008176640000
```

## 2. इसे लिखिए

वही संख्या एक स्ट्रिंग के रूप में, उसका हर अंक।

```sather
FORMATION_COUNT::line_ups_text(25)
-- => "15511210043330985984000000"
```

एक `INT` उतनी बड़ी संख्या नहीं रख सकता, और यही इस काम का उद्देश्य है।

## 3. एक अंक का हिस्सा

`acts` बराबर अंकों वाले शो में हर अंक को कुल समय का `1/acts` हिस्सा मिलता है। इसे एक `RAT` के रूप में लौटाइए।

```sather
FORMATION_COUNT::share(3)
-- => 1/3
```

## 4. दो अंक एक साथ

दो हिस्सों को जोड़िए और उनका कुल ठीक-ठीक लौटाइए।

```sather
FORMATION_COUNT::combined(FORMATION_COUNT::share(2), FORMATION_COUNT::share(3))
-- => 5/6
```

## 5. क्या यह पूरा शो भर देता है?

बताइए कि कोई हिस्सा ठीक पूरे शो के बराबर है या नहीं, यानी ठीक एक।

```sather
FORMATION_COUNT::covers_whole_show(#RAT(3, 3))
-- => true
FORMATION_COUNT::covers_whole_show(#RAT(2, 3))
-- => false
```
