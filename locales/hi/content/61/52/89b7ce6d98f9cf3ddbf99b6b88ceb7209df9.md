# परिचय

## एट्रिब्यूट

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) घोषणा को सजाने और उसके साथ मेटाडेटा जोड़ने का एक तरीका देता है: किसी क्लास, मेथड, एनम, फील्ड, प्रॉपर्टी या किसी भी [अन्य समर्थित](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) घोषणा के साथ।

आप `ClassAttribute` और `FieldAttribute` का इस्तेमाल करके किसी एट्रिब्यूट को घोषणा से ठीक पहले वाली लाइन पर जोड़कर लगा सकते हैं:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

यह घोषणात्मक मेटाडेटा कोड के साथ सिर्फ अतिरिक्त संरचित जानकारी जोड़ता है, कोड के व्यवहार को बदलता नहीं। लेकिन कोड के दूसरे हिस्से इस मेटाडेटा का उपयोग यह तय करने के लिए करते हैं कि उसका लक्ष्य कैसा व्यवहार करेगा, या उसकी कुछ कार्यक्षमताएँ जोड़ी जाएँ, बदली जाएँ, हटाई जाएँ या सीमित की जाएँ।

बहुत से [पहले से परिभाषित और आरक्षित एट्रिब्यूट](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) होते हैं, जैसे: `Flags`, `Obsolete`, `Conditional` और `Experimental`. इनमें से हर एक का अपना खास अर्थ होता है, जिसे C# के डॉक्युमेंटेशन में देखा जा सकता है। ध्यान दीजिए कि [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) जैसे किसी एट्रिब्यूट का पूरा नाम `<Name>Attribute` के रूप में होता है (जैसे `FlagsAttribute`).

## फ्लैग एनम

C# का [`enum` टाइप](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) नामित कॉन्स्टेंट का एक तय समूह दर्शाता है (यानी एक एनमरेशन)।

आम तौर पर `enum` का एक मेंबर उन नामित कॉन्स्टेंट में से सिर्फ एक को ही दर्शा सकता है। लेकिन कभी-कभी एक से ज़्यादा कॉन्स्टेंट दर्शाना काम का होता है। ऐसा करने के लिए आप `enum` पर [`Flags` एट्रिब्यूट](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) लगा सकते हैं।

फ्लैग एनम को इस तरह बनाया जा सकता है (बाइनरी पूर्णांक नोटेशन `0b` का उपयोग करके):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

जिस `PhoneFeatures` इंस्टेंस की वैल्यू `0b00000011` है, उसके `Call` _और_ `Text` दोनों फ्लैग सेट रहते हैं।

डिफॉल्ट रूप से एनम मेंबर की वैल्यू के लिए `int` टाइप इस्तेमाल होता है। एनम की घोषणा में टाइप बताकर आप कोई दूसरा पूर्णांक टाइप भी इस्तेमाल कर सकते हैं:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
