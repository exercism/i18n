# Alias

[स्पेशल फॉर्म `alias`][alias] की मदद से आप किसी बाहरी मॉड्यूल को जिस नाम से संदर्भित करते हैं, उसे छोटा या बदल सकते हैं। `:as` ऑप्शन के ज़रिए अपनी पसंद का नाम दिया जा सकता है।

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

जब इसे बिना किसी आर्गुमेंट के इस्तेमाल किया जाता है, तो यह मॉड्यूल के नाम को उसके अंतिम हिस्से तक छोटा कर देता है, जैसे

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

एक से अधिक एलियस को `{}` की मदद से एक साथ समूहित किया जा सकता है:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

आम तौर पर एलियस मॉड्यूल की परिभाषा की शुरुआत में जोड़े जाते हैं, लेकिन इन्हें कहीं भी जोड़ा जा सकता है। इनका स्कोप लेक्सिकल होता है, यानी किसी फंक्शन की परिभाषा के अंदर जोड़ा गया एलियस किसी दूसरे फंक्शन में उपलब्ध नहीं होगा।

इस्तेमाल न किए गए एलियस कंपाइलर चेतावनियाँ पैदा करते हैं।
