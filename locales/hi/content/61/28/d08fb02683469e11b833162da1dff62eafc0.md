# निर्देश

_Instruments of Texas_ में काम करते हुए आपको C# में लिखे एक प्रयोगात्मक कैल्कुलेटर पर काम करने की ज़िम्मेदारी दी गई है। आप गुणा से शुरू करके कैल्कुलेटर के कई फंक्शन जाँचने के लिए एक टेस्ट हार्नेस बना रहे हैं। आप देखेंगे कि जब गुणा के दोनों ऑपरेंड ऋणात्मक हों, तो विशेष ध्यान देने की ज़रूरत पड़ती है।

`Calculator` क्लास आपको पहले ही दी जा चुकी है और उसमें बदलाव नहीं करना है।

## 1. उपयोगकर्ता-परिभाषित एक्सेप्शन `CalculationException` की परिभाषा पूरी कीजिए

`CalculationException` के कंस्ट्रक्टर की परिभाषा पूरी कीजिए। इसमें कैल्कुलेटर द्वारा फेंकी गई किसी भी एक्सेप्शन को, और साथ ही उन ऑपरेंड को भी संग्रहीत (रैप) करना होगा जो एक्सेप्शन फेंके जाने के समय प्रोसेस हो रहे हों।

## 2. कैल्कुलेटर में ओवरफ्लो की स्थितियाँ सँभालिए और कॉल करने वाले को बेहतर जानकारी दीजिए

`CalculatorTestHarness.Multiply()` मेथड लागू कीजिए। इसे कंस्ट्रक्टर को दिए गए `Calculator` इंस्टेंस के `Calculator.Multiply()` मेथड को कॉल करना चाहिए और उसमें x तथा y पूर्णांक वैल्यू पास करनी चाहिए। अगर `Calculator.Multiply()` मेथड में ओवरफ्लो होता है, तो यह एक `OverflowException` फेंकता है। इस एक्सेप्शन को `CalculatorTestHarness.Multiply()` मेथड में पकड़कर `CalculationException` में रैप करना चाहिए, और जो x तथा y वैल्यू पास की जा रही हैं उन्हें एक्सेप्शन के ऑपरेंड के रूप में संग्रहीत करना चाहिए। नए बनाए गए `CalculationException` ऑब्जेक्ट को फेंकना चाहिए। अगर `Calculator.Multiply()` मेथड सफल होता है, तो उससे लौटाई गई वैल्यू को आप अनदेखा कर सकते हैं।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. मान्य इनपुट के लिए गुणा की क्रिया की जाँच कीजिए

`CalculatorTestHarness.TestMultiplication()` मेथड लागू कीजिए, जो दो पूर्णांक लेता है और `CalculatorTestHarness.Multiply()` मेथड को कॉल करता है। तब `"Multiply succeeded"` लौटाया जाता है।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. ऋणात्मक इनपुट के लिए गुणा की क्रिया की जाँच कीजिए

`CalculatorTestHarness.TestMultiplication()` मेथड में बदलाव कीजिए, ताकि अगर दोनों पूर्णांक आर्गुमेंट ऋणात्मक (शून्य से कम) हों, तो `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` लौटाया जाए।

`<INNER_EXCEPTION_MESSAGE>` प्लेसहोल्डर की जगह `CalculationException` की इनर एक्सेप्शन का संदेश रखा जाना चाहिए।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. धनात्मक इनपुट के लिए गुणा की क्रिया की जाँच कीजिए

`CalculatorTestHarness.TestMultiplication()` मेथड में बदलाव कीजिए, ताकि अगर पूर्णांक आर्गुमेंट में से कम से कम एक ऋणात्मक न हो, तो `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` लौटाया जाए।

`<INNER_EXCEPTION_MESSAGE>` प्लेसहोल्डर की जगह `CalculationException` की इनर एक्सेप्शन का संदेश रखा जाना चाहिए।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
