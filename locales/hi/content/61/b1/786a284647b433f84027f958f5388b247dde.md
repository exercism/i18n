# परिचय

_एनम टाइप_ एक खास डेटा टाइप है, जिसकी मदद से किसी वेरिएबल की वैल्यू पहले से तय स्थिरांकों में से कोई एक हो सकती है।
वेरिएबल की वैल्यू उन वैल्यूओं में से एक होनी चाहिए जो उसके लिए पहले से तय की गई हैं।
आम उदाहरणों में दिशाएँ (`NORTH`, `SOUTH`, `EAST` और `WEST` वैल्यूएँ) और सप्ताह के दिन शामिल हैं।

चूँकि ये स्थिरांक होते हैं, इसलिए एनम टाइप के फील्ड के नाम बड़े अक्षरों में लिखे जाते हैं।

## एनम टाइप बनाना

Java प्रोग्रामिंग भाषा में आप `enum` कीवर्ड का उपयोग करके एनम टाइप बनाते हैं।
उदाहरण के लिए, सप्ताह के दिनों वाला एनम टाइप आप ऐसे लिखेंगे:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

जब भी आपको स्थिरांकों के किसी तय समूह को दर्शाना हो, तब एनम टाइप का उपयोग कीजिए।
इसमें स्वाभाविक एनम टाइप भी शामिल हैं, जैसे हमारे सौरमंडल के ग्रह, और ऐसे डेटा सेट जिनकी सारी संभावित वैल्यूएँ आपको कंपाइल होने के समय ही पता होती हैं, जैसे मेन्यू के विकल्प, कमांड लाइन फ्लैग वगैरह।

## एनम टाइप का उपयोग

यहाँ कुछ कोड है जो दिखाता है कि ऊपर बनाए गए `DayOfWeek` एनम का उपयोग कैसे किया जाता है:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## मेथड और फील्ड जोड़ना

Java प्रोग्रामिंग भाषा के एनम टाइप दूसरी भाषाओं के अपने समकक्षों की तुलना में कहीं ज़्यादा शक्तिशाली होते हैं।
`enum` की घोषणा एक _क्लास_ बनाती है (जिसे _एनम टाइप_ कहते हैं)।
एनम क्लास के अंदर मेथड और दूसरे फील्ड भी हो सकते हैं:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating` एनम टाइप के किसी सदस्य पर `getNumberOfStars` मेथड कॉल करना:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
