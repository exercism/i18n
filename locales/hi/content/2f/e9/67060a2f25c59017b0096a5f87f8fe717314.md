# इंस्टॉलेशन

## tclsh इंस्टॉल करना

आपको सिर्फ एक ही टूल चाहिए: TCL इंटरप्रेटर, `tclsh`.

Windows के लिए Tcl पाने की सबसे अच्छी जगह [Magicsplat का Tcl इंस्टॉलर][magicsplat] है।

MacOS और Unix जैसे ऑपरेटिंग सिस्टम पर `tclsh` पहले से ही इंस्टॉल मिलता है।
आम तौर पर इंस्टॉल किया गया वर्ज़न 8.6.*कुछ भी* होता है।
मौजूदा स्टेबल वर्ज़न 9.0 इंस्टॉल करने के लिए:
 - MacOS पर [Homebrew][brew] इस्तेमाल कीजिए।
 - Linux के लिए अपना पैकेज मैनेजर देखिए।
 - या [सोर्स डाउनलोड कीजिए][download] और [उसे बिल्ड कीजिए][build]।

Exercism के वेब इंटरफेस से अभ्यास हल करने के लिए, टेस्ट रनर (फरवरी 2023 तक) Tcl वर्ज़न 8.7a4 इस्तेमाल करता है।

## इंटरैक्टिव tclsh शेल का इस्तेमाल

कोड लिखते समय कमांड आज़माने के लिए इंटरैक्टिव [`tclsh`][tclsh] सेशन शुरू करना आम बात है।
लेकिन tclsh सिर्फ बहुत बुनियादी REPL इंटरप्रेटर देता है, जिसमें न कमांड लाइन एडिटिंग है और न कमांड हिस्ट्री।
बेहतर अनुभव के लिए `rlwrap` नाम का एक प्रोग्राम है, जो readline की सुविधा जोड़ता है:

```bash
rlwrap tclsh
```

rlwrap इंस्टॉल करने के लिए:
 - MacOS पर [Homebrew][brew] इस्तेमाल कीजिए।
 - Linux पर अपना पैकेज मैनेजर देखिए।
 - या [सोर्स डाउनलोड कीजिए][rlwrap-download] और [उसे बिल्ड कीजिए][rlwrap-build]।

यह इतना काम का है कि आप इसे हमेशा इस्तेमाल करना चाहेंगे: इसे अपनी ~/.bashrc में जोड़ दीजिए

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## कौन-सा वर्ज़न इस्तेमाल करें?

मौजूदा स्टेबल वर्ज़न 9.0 है।
जैसा ऊपर बताया गया, वर्ज़न 8.6 अब भी बड़े पैमाने पर इस्तेमाल में है।

आप यह जाँच सकते हैं कि आपके पास `tclsh` का कौन-सा वर्ज़न इंस्टॉल है, इसके लिए यह कमांड चलाइए:

```bash
echo 'puts [info patchlevel]' | tclsh
```
