# परिचय

फंडामेंटल्स कॉन्सेप्ट से याद कीजिए: एक AWK प्रोग्राम **पैटर्न-एक्शन जोड़े** से बना होता है।

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## "पैटर्न" से हमारा क्या मतलब है?

यह "पैटर्न" कोई भी AWK एक्सप्रेशन होता है।
एक्सप्रेशन का परिणाम सही है या गलत, यह तय करता है कि एक्शन चलेगा या नहीं।

## खाली पैटर्न

पैटर्न छोड़ा जा सकता है।
ऐसे में हर रिकॉर्ड के लिए एक्शन चलाया जाता है।

हम passwd फाइल में मौजूद सभी यूज़रनेम प्रिंट कर सकते हैं।

```sh
awk -F: '{print $1}' /etc/passwd
```

## रेगुलर एक्सप्रेशन

AWK स्ट्रिंग की तुलना रेगुलर एक्सप्रेशन से करके बूलियन परिणाम निकाल सकता है।

किसी खास फील्ड से मिलान करने के लिए `~` रेगुलर एक्सप्रेशन मिलान ऑपरेटर का उपयोग कीजिए।
इस ऑपरेटर का बायाँ ऑपरेंड एक स्ट्रिंग होता है और दायाँ ऑपरेंड एक रेगुलर एक्सप्रेशन होता है।
रेगुलर एक्सप्रेशन लिटरल को `/` स्लैश के बीच लिखा जाता है।

passwd फाइल में उन यूज़र को ढूँढने के लिए जो bash से लॉग इन करते हैं:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` "रेगुलर एक्सप्रेशन **मिलान नहीं** करता" ऑपरेटर है।

वर्तमान रिकॉर्ड के साथ रेगुलर एक्सप्रेशन का मिलान करने के लिए आप `$0 ~ /regex/` लिख सकते हैं।
यह इतना आम है कि इसका एक छोटा रूप भी है: आप `$0` और `~` हटाकर सीधे `/regex/` लिख सकते हैं।

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
उस एक पंक्ति वाले AWK कोड की तुलना grep की समतुल्य कमांड से कीजिए।

```sh
grep 'regex' data.txt
```

AWK आपको पूरी प्रोग्रामिंग भाषा देता है, बिना संक्षिप्तता खोए।
~~~~

GNU AWK के रेगुलर एक्सप्रेशन के स्वरूप में हम आगे के किसी कॉन्सेप्ट में और गहराई से जाएँगे।

## एक्सप्रेशन

AWK एक्सप्रेशन (अंकगणितीय, तार्किक या किसी और तरह के) को पैटर्न के रूप में इस्तेमाल किया जा सकता है।

UID 1000 या उससे अधिक वाले सभी यूज़र निकालने के लिए:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

याद कीजिए कि AWK की गलत वैल्यू शून्य और खाली स्ट्रिंग होती हैं, और बाकी सभी संख्याएँ या स्ट्रिंग सही होती हैं।
जिस एक्सप्रेशन का परिणाम संख्या या स्ट्रिंग होता है, उसे पैटर्न के रूप में इस्तेमाल किया जा सकता है।

## फंक्शन

कोई भी [बिल्ट-इन][builtins] या [उपयोगकर्ता-परिभाषित][user-defined] फंक्शन किसी एक्सप्रेशन में, और इसलिए पैटर्न में भी, इस्तेमाल किया जा सकता है।
कुछ उदाहरण:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## कॉन्स्टेंट पैटर्न

AWK का एक आम तरीका यह है:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` एक सही मान वाला पैटर्न है जिसके साथ कोई एक्शन नहीं जुड़ा।
इसका मतलब है "वर्तमान रिकॉर्ड प्रिंट करना।"
