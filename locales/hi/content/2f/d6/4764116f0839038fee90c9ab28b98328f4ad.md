## डिक्शनरी

## वैकल्पिक आर्गुमेंट

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

यह इसके बराबर है

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

REPL में दिखने वाले जवाब में आप देख सकते हैं कि पहली परिभाषा एक साथ दो मेथड बनाती है।
