# परिचय

C एक स्टैटिक टाइप वाली भाषा है, जिसका मतलब है कि हर चीज़ का टाइप कंपाइल-टाइम पर ही तय हो जाता है। किसी वेरिएबल के लिए नाम चुनने और उसका टाइप तय करने की इस प्रक्रिया को वेरिएबल घोषित करना कहा जाता है।

किसी वेरिएबल को घोषित करने के लिए उसका टाइप साफ़-साफ़ बताया जाता है।
वेरिएबल का नाम अक्षर या अंडरस्कोर से शुरू होना चाहिए।
कुछ नाम इस्तेमाल नहीं किए जा सकते, क्योंकि वे [कीवर्ड][reserved-keywords] या [दूसरे आइडेंटिफायर][reserved-identifiers] के लिए आरक्षित हैं।

किसी वेरिएबल को वैल्यू देना या उसे बदलना, वेरिएबल असाइनमेंट से किया जाता है।
वैल्यू सेट करने से वह वेरिएबल परिभाषित होता है।
वेरिएबल को परिभाषित करना ही इनिशियलाइज़ेशन कहलाता है।

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

किसी वेरिएबल की वैल्यू को `=` सिंपल असाइनमेंट ऑपरेटर की मदद से असाइन और अपडेट किया जा सकता है।
एक बार परिभाषित होने के बाद, वेरिएबल का टाइप कभी नहीं बदल सकता।

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C एक इम्परेटिव प्रोसीजरल भाषा है।
सारी गणना स्टेटमेंट की एक श्रृंखला के रूप में होती है, जो किसी एक फंक्शन या कई फंक्शनों का हिस्सा होते हैं।

हर फंक्शन में शून्य या उससे अधिक पैरामीटर हो सकते हैं।
फंक्शन बनाते समय सभी पैरामीटर और रिटर्न वैल्यू का टाइप साफ़-साफ़ बताना ज़रूरी होता है।
वैल्यू `return` कीवर्ड की मदद से फंक्शन से लौटाई जाती हैं।
फंक्शन में डिफ़ॉल्ट रूप से एक्सटर्नल स्टोरेज क्लास होती है, यानी वह प्रोग्राम के पूरे जीवनकाल तक मौजूद रहता है और फाइल के बाहर भी दिखाई दे सकता है।
इसे रोकने के लिए `static` कीवर्ड जोड़ा जा सकता है, जो आंतरिक दृश्यता तय करता है।

```c
static int add(int x, int y) {
  return x + y;
}
```

ऊपर के उदाहरण में, वेरिएबल `x` और `y` सिर्फ उसी फंक्शन के अंदर इस्तेमाल किए जा सकते हैं, यानी उनका स्कोप फंक्शन तक सीमित है।
स्कोप का मतलब यह है कि किसी नाम (प्रोग्राम के किसी एलिमेंट का) से जुड़ी वैल्यू सिर्फ उसी कोड क्षेत्र के अंदर पहुँच में रहती है जहाँ वह परिभाषित है।
C में कोड के मुख्य क्षेत्र ये हैं:

- फाइल
- फंक्शन
- ब्लॉक (जैसे लूप और दूसरे कंस्ट्रक्ट के अंदर)

फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं।

```c
int sum = add(1, 2);
```

C दो तरह के कमेंट का समर्थन करता है।
सिंगल लाइन कमेंट से पहले `//` लगाया जाता है (C99 से) और मल्टी-लाइन कमेंट `/*` और `*/` के बीच लिखा जाता है।
