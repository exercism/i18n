# परिचय

## स्ट्रिंग

C# में `string` एक ऑब्जेक्ट है जो ऐसे टेक्स्ट को दर्शाता है जिसे बदला नहीं जा सकता। यह टेक्स्ट यूनिकोड अक्षरों का एक क्रम होता है: अक्षर, अंक, विराम चिह्न आदि। `string` का एक इंस्टेंस बनाने के लिए डबल कोट्स का उपयोग किया जाता है:

```csharp
string fruit = "Apple";
```

### मेथड

स्ट्रिंग के साथ काम करने के लिए आप उसके [बिल्ट-इन मेथड][docs-string-methods] कॉल करते हैं।
उदाहरण के लिए, किसी स्ट्रिंग से रिक्त स्थान हटाने के लिए आप [Trim मेथड][tutorial-docs.microsoft.com-trim-white-space] का उपयोग इस तरह कर सकते हैं:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

एक बार स्ट्रिंग बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती।
जो मेथड स्ट्रिंग में बदलाव करते दिखते हैं, वे वास्तव में एक नई स्ट्रिंग लौटाते हैं।

### जोड़ना

कई स्ट्रिंग को आपस में जोड़ा (कॉन्कैटिनेट किया) जा सकता है। इसे करने का सबसे आसान तरीका `+` ऑपरेटर का उपयोग करना है।

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### फॉर्मेटिंग

साधारण जोड़ने से ज़्यादा जटिल स्ट्रिंग फॉर्मेटिंग के लिए स्ट्रिंग इंटरपोलेशन बेहतर तरीका है। किसी स्ट्रिंग में इंटरपोलेशन इस्तेमाल करने के लिए उसके आगे डॉलर (`$`) चिह्न लगाइए। इसके बाद आप अपनी स्ट्रिंग के अंदर मौजूद वेरिएबलो तक पहुँचने के लिए कर्ली ब्रैकेट (`{}`) का उपयोग कर सकते हैं।

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
