# टाइप कन्वर्जन का परिचय

Go में अलग-अलग टाइप के बीच बदलने के लिए स्पष्ट कन्वर्जन करना ज़रूरी है।
अलग-अलग टाइप के बीच कन्वर्जन को **टाइप कास्टिंग** भी कहा जाता है। यह उस टाइप के नाम वाले फंक्शन से किया जाता है जिसमें आपको कन्वर्जन करना है।
उदाहरण के लिए, किसी `int` को `float64` में बदलने के लिए आपको यह करना होगा:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## प्रिमिटिव टाइप और स्ट्रिंग के बीच कन्वर्जन

प्रिमिटिव टाइप (जैसे `int`) और `string` के बीच कन्वर्जन के लिए एक `strconv` पैकेज है।

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```
