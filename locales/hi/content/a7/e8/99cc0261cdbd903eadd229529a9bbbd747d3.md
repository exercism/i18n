# परिचय

## इनहेरिटेंस

इनहेरिटेंस OOP (ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग) की एक मुख्य अवधारणा है।
यह IS-A संबंध को दर्शाता है।
प्रोग्रामिंग में इसका अर्थ बिल्कुल वही है जो अंग्रेज़ी में है: पैरेंट से विशेषताएँ विरासत में लेना (प्रोग्रामिंग में विशेषताएँ आम तौर पर फंक्शन और वेरिएबल होती हैं)।

एक क्लास `Animal` पर विचार कीजिए, जैसा कि यहाँ दिखाया गया है,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` एक पैरेंट क्लास है, क्योंकि इस क्लास की जो प्रॉपर्टी हैं, उन्हें सामान्य रूप से सभी जानवरों तक बढ़ाया जा सकता है।

एक जानवर की कल्पना कीजिए, जिसका नाम `Lion` है और जिसकी क्लास कुछ ऐसी है,

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` एनोटेशन यह बताने के लिए इस्तेमाल किया जाता है कि सबक्लास का कोई मेथड अपने सुपरक्लास के मेथड को ओवरराइड कर रहा है।
यह कड़ाई से ज़रूरी नहीं है, लेकिन इसे इस्तेमाल करना अच्छी आदत है।
~~~~

अब जब भी हम यह करते हैं,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

ध्यान दीजिए: यहाँ `Animal` क्लास को `Lion` से इनिशियलाइज़ किया जा रहा है।
आउटपुट कुछ इस तरह होगा

```java
Lion here!!
```

OOP के अनुसार इनहेरिटेंस कई प्रकार के होते हैं, लेकिन Java उनमें से कुछ ही प्रकारों का समर्थन करता है (मल्टी-लेवल और हायरार्किकल)।
