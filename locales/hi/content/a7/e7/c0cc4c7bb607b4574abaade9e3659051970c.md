# निर्देश

आप अभी-अभी एक ऐसी टीम में शामिल हुए हैं जो jq पर आधारित डेटा पाइपलाइन को बनाए रखती है।
अपने पहले पेयरिंग सेशन में आपके नए साथी को जिज्ञासा होती है:
*क्या आपको पता है कि `add`, `reverse` और `map` अंदर से कैसे काम करते हैं? चलिए देखते हैं। कोशिश कीजिए और इन्हें खुद रिकर्शन से बनाइए, बिल्ट-इन का उपयोग किए बिना।*

## 1. ऐरे की संख्याओं को जोड़ने वाला फंक्शन बनाइए

रिकर्शन का अभ्यास करने के लिए हम बिल्ट-इन `add` फिल्टर को फिर से बनाएँगे।
_बेस केस_ यह है कि खाली ऐरे का जोड़ **शून्य** होता है।

इसे रिकर्सिव फंक्शन से खुद बनाइए। बिल्ट-इन `add` का उपयोग न कीजिए।

```jq
[5, 4, 6, 10] | array_add     # => 25
```

## 2. ऐरे को उलटिए

हम बिल्ट-इन `reverse` फिल्टर को फिर से बनाएँगे।
_बेस केस_ यह है कि खाली ऐरे को उलटने पर भी खाली ऐरे ही मिलता है।

इसे रिकर्सिव फंक्शन से खुद बनाइए। बिल्ट-इन `reverse` का उपयोग न कीजिए।

```sh
[5, 4, 6, 10] | array_reverse   # => [10, 6, 4, 5]
```

## 3. ऐरे को मैप कीजिए

हम बिल्ट-इन `map` फिल्टर को फिर से बनाएँगे।
यह फंक्शन एक फिल्टर को पैरामीटर के रूप में लेता है। फिर इनपुट ऐरे के हर एलिमेंट पर उस फिल्टर को चलाता है और उन सबके आउटपुट एक नए ऐरे में लौटाता है।
_बेस केस_ यह है कि खाली ऐरे पर मैप करने से खाली ऐरे ही मिलता है।

इसे रिकर्सिव फंक्शन से खुद बनाइए। बिल्ट-इन `map` का उपयोग न कीजिए।

```sh
[5, 4, 6, 10] | array_map(. + 10)   # => [15, 14, 16, 20]
```
