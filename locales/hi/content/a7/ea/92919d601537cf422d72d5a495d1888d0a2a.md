# निर्दেশ

इस अभ्यास में आप लॉग लाइनों को प्रोसेस करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है जिसका फॉर्मेट इस तरह है: `"[<LEVEL>]: <MESSAGE>"`.

तीन अलग-अलग लॉग लेवल होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके पास तीन कार्य हैं। हर कार्य एक लॉग लाइन लेगा और आपसे उसके साथ कुछ करने को कहेगा।

## 1. लॉग लाइन से मैसेज निकालिए

लॉग लाइन का मैसेज लौटाने वाला `message` फंक्शन बनाइए:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

शुरू या अंत में आने वाला कोई भी व्हाइट स्पेस हटा देना चाहिए:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

लॉग लाइन का लॉग लेवल लौटाने वाला `logLevel` फंक्शन बनाइए; यह लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. लॉग लाइन का फॉर्मेट बदलिए

`reformat` फंक्शन बनाइए जो लॉग लाइन का फॉर्मेट बदलता है और मैसेज को पहले तथा लॉग लेवल को उसके बाद गोल ब्रैकेट में रखता है:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
