# इसके बारे में

JavaScript में इंक्रीमेंट और डिक्रीमेंट ऑपरेटर होते हैं।
ये किसी वेरिएबल को उसी जगह बदल देते हैं।
`++` किसी संख्या में एक जोड़ता है, `--` किसी संख्या में से एक घटाता है।

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

ऊपर दिया गया उदाहरण पोस्टफिक्स इंक्रीमेंट/डिक्रीमेंट ऑपरेटर दिखाता है।
इसमें ऑपरेटर वेरिएबल के बाद लगाया जाता है, और एक्सप्रेशन की रिटर्न वैल्यू वेरिएबल के बढ़ने/घटने से _पहले_ वाली वैल्यू होती है।

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

प्रीफिक्स वाला रूप भी होता है, जिसमें ऑपरेटर वेरिएबल से पहले लगाया जाता है।
तब रिटर्न वैल्यू वेरिएबल के बढ़ने/घटने के _बाद_ वाली वैल्यू होती है।

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
