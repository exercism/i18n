# इंस्टॉलेशन

Cairo को इंस्टॉल करने के लिए बस Scarb डाउनलोड करना काफी है। Scarb, Cairo कंपाइलर और Cairo भाषा सर्वर दोनों को एक ऐसे पैकेज में एक साथ रख देता है जिसे इंस्टॉल करना आसान है, ताकि आप तुरंत Cairo कोड लिखना शुरू कर सकें। Scarb, Cairo का पैकेज मैनेजर भी है।

अपने प्लेटफॉर्म के लिए सुझाए गए इंस्टॉलेशन निर्देश पाने के लिए [Cairo की आधिकारिक वेबसाइट](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/) पर जाइए।

ऑपरेटिंग सिस्टम के अनुसार:

- Linux/MacOS
    1. [asdf](https://asdf-vm.com/guide/getting-started.html) को इंस्टॉल कीजिए
    2. [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf) को इंस्टॉल कीजिए
    3. नए टर्मिनल सेशन में `scarb --version` चलाकर इंस्टॉलेशन जाँचिए
- Windows
    1. [scarb](https://docs.swmansion.com/scarb/download#windows) को इंस्टॉल कीजिए
    2. नए टर्मिनल सेशन में `scarb --version` चलाकर इंस्टॉलेशन जाँचिए

टूलचेन इंस्टॉल हो जाना ही सब कुछ नहीं है! IDE सपोर्ट से उत्पादकता में बड़ी बढ़ोतरी होती है, और अधिकांश डेवलपर अब इसकी उम्मीद करते हैं।
अगर आप Visual Studio Code इस्तेमाल कर रहे हैं, तो हमारा सुझाव है कि आप [Cairo एक्सटेंशन](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1) इंस्टॉल कीजिए, जो सिंटैक्स हाइलाइटिंग, कोड पूरा करने की सुविधा और कई अन्य उपयोगी फीचर देता है!
