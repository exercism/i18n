# परिचय

Go में, `for range` रेंज एक्सप्रेशन से मिलने वाली वैल्यूओं के लिए कोड का एक ब्लॉक दोहराता है।
रेंज एक्सप्रेशन तय करता है कि हर इटरेशन एक वैल्यू देगा या दो।

## रेंज एक्सप्रेशन

### स्लाइस पर रेंज

स्लाइस पर `range` हर एलिमेंट का इंडेक्स और वैल्यू क्रम से देता है:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### मैप पर रेंज

मैप पर `range` हर की और वैल्यू देता है, लेकिन इटरेशन का क्रम तय नहीं होता।
Go जानबूझकर मैप के इटरेशन का क्रम अनियमित करता है, इसलिए वही प्रोग्राम हर बार चलाने पर अलग आउटपुट दे सकता है।

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### स्ट्रिंग पर रेंज

स्ट्रिंग पर `range` बाइट इंडेक्स और हर रून (यूनिकोड कोड पॉइंट) देता है।
नीचे दिए उदाहरण में, `子` तीन बाइट लेता है, इसलिए `猫` बाइट इंडेक्स `3` से शुरू होता है, `1` से नहीं।

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

अगर आपको इसके बजाय रून इंडेक्स चाहिए, तो स्ट्रिंग को रून के स्लाइस में बदल दीजिए:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### पूर्णांक पर रेंज

`range` सीधे एक पूर्णांक पर इटरेट कर सकता है, और `0` से उस पूर्णांक तक की वैल्यूएँ देता है, उस पूर्णांक को छोड़कर।
शून्य और ऋणात्मक वैल्यूएँ मान्य होती हैं, लेकिन कोई इटरेशन नहीं देतीं।

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### इटरेटर पर रेंज

`range` `iter.Seq[V]` या `iter.Seq2[K, V]` टाइप के इटरेटर को स्वीकार करता है।
इटरेटर एक फंक्शन होता है जो वैल्यूओं को एक-एक करके देता है।
फिर `range` उन वैल्यूओं में से एक-एक करके आगे बढ़ सकता है।

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### चैनल पर रेंज

अंत में, `range` किसी चैनल से भेजी गई वैल्यूएँ तब तक प्राप्त कर सकता है जब तक वह चैनल कहीं और बंद न कर दिया जाए।
चैनलों के बारे में ट्रैक के सिलेबस में आगे और विस्तार से बताया गया है।

## इंडेक्स या वैल्यू छोड़ना

अगर कोई वेरिएबल घोषित किया गया है लेकिन कभी इस्तेमाल नहीं किया गया, तो Go कंपाइल नहीं होगा।

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

अगर सिर्फ वैल्यू चाहिए, तो इंडेक्स या की को `_` में असाइन कीजिए ताकि उसे अनदेखा किया जा सके।

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

अगर सिर्फ इंडेक्स चाहिए, तो उसे पूरी तरह छोड़ दीजिए:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

अगर न इंडेक्स चाहिए न वैल्यू, तो दोनों को छोड़ा जा सकता है:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
