# इसके बारे में

`List`, [`Array`][array] के बहुत करीब है। लेकिन इनमें कुछ बड़े अंतर हैं, जिन्हें नज़रअंदाज़ करना आप नहीं चाहेंगे:

1. लिस्ट को चौकोर ब्रैकेट, यानी `[0]`, से इंडेक्स नहीं किया जा सकता।
2. लिस्ट को इनिशियलाइज़ नहीं किया जा सकता।
3. लिस्ट कॉम्प्रिहेंशन नहीं होते।
4. इटरेशन के दौरान आप लिस्ट के एलिमेंट आज़ादी से बदल सकते हैं।

`List`, `haxe.ds` पैकेज का सदस्य है, इसलिए जब भी आपको लिस्ट इस्तेमाल करनी हो, आपको इसका पैकेज इंपोर्ट करना पड़ता है:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
