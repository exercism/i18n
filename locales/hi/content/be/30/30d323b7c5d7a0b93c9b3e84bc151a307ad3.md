# परिचय

**यूनियन टाइप घोषणाएँ** `PHP 8.0.0` से उपलब्ध हैं और कई अलग-अलग टाइप की वैल्यू स्वीकार करती हैं, सिर्फ एक टाइप की नहीं। यूनियन टाइप परिभाषाएँ पाइप (`|`) से टाइप को अलग करके बनाई जाती हैं।

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## बारीकियाँ

- `null` वाले टाइपों को _नेलबल_ घोषित किया जा सकता है, या तो `?Type` इस्तेमाल करके या `Type1|Type2|null` इस्तेमाल करके।
- अगर डुप्लिकेट या रिडंडेंट टाइप घोषित किए जाएँ, तो कंपाइल समय पर एरर मिलती है।
- `void` का उपयोग यूनियन टाइप घोषणा के हिस्से के रूप में नहीं किया जा सकता।
