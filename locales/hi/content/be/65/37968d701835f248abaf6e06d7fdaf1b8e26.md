# परिचय

Haxe में एब्स्ट्रैक्ट टाइप एक ऐसा टाइप है जो रनटाइम पर अलग टाइप होता है। यह कंपाइल-टाइम की एक सुविधा है, जो कंक्रीट टाइप के "ऊपर" टाइप परिभाषित करती है, ताकि उनके व्यवहार को बदला जा सके या बढ़ाया जा सके:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

यहाँ हम `abstract` कीवर्ड का उपयोग करके `AbstractInt` टाइप घोषित कर रहे हैं। इसका सिंटैक्स `class` के सिंटैक्स से बहुत मिलता-जुलता है। और क्लास की तरह ही, एब्स्ट्रैक्ट टाइप में भी मेथड हो सकते हैं। इन्हें भी क्लास की तरह ही इंस्टैंशिएट करके इस्तेमाल किया जा सकता है:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
