# https://www.php.net/manual/en/language.basic-syntax.phptags.php"स्कोप रिज़ॉल्यूशन ऑपरेटर

स्कोप रिज़ॉल्यूशन ऑपरेटर (`::`) की मदद से हम किसी क्लास को संदर्भित कर सकते हैं और उसके नाम कॉन्स्टेंट, स्टैटिक प्रॉपर्टी या स्टैटिक मेथड तक पहुँच सकते हैं।

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## स्कोप रिज़ॉल्यूशन ऑपरेटर के साथ `self` और `static` का उपयोग

कभी-कभी किसी ऑब्जेक्ट को अपने ही स्कोप को संदर्भित करने की ज़रूरत पड़ती है। इसके लिए `self` कीवर्ड किसी क्लास को उसके अपने स्कोप को संदर्भित करने देता है। `self` कीवर्ड इस्तेमाल करने से क्लास अपने नाम से आज़ाद हो जाती है, जिससे समय के साथ कोड बनाए रखना आसान हो जाता है।

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

लेकिन `self` जिस क्लास के अंदर लिखा जाता है, उसी क्लास से बँधा रहता है।

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

`MyOtherClass::getMyValue` का मान निकालने पर भी `99` नहीं, बल्कि `1` ही मिलता है। इसका हल यह है कि स्कोप रिज़ॉल्यूशन ऑपरेटर के साथ `static` कीवर्ड इस्तेमाल कीजिए, जो इस संदर्भ को वर्तमान चाइल्ड क्लास के साथ "लेट बाइंड" कर देता है।

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## स्कोप रिज़ॉल्यूशन ऑपरेटर के साथ `parent` का उपयोग

कभी-कभी पैरेंट स्कोप में उपलब्ध किसी कॉन्स्टेंट, प्रॉपर्टी या मेथड को खास तौर पर संदर्भित करने की ज़रूरत पड़ सकती है:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग में सबसे आम तौर पर `parent` का उपयोग तब किया जाता है जब कोई ऑब्जेक्ट बनाया जा रहा हो और पैरेंट कंस्ट्रक्टर को कॉल करना हो:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## सावधानियाँ

### कॉन्स्टेंट, प्रॉपर्टी और मेथड की विज़िबिलिटी

स्कोप रिज़ॉल्यूशन ऑपरेटर `public`, `private` और `protected` विज़िबिलिटी मॉडिफायर के तय किए नियमों का ही पालन करता है।
