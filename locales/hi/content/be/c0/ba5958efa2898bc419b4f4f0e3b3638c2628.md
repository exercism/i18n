# परिचय

*रेगुलर एक्सप्रेशन* (regex) एक छोटा पैटर्न होता है जो किसी टेक्स्ट का आकार बताता है। Factor के रेगुलर एक्सप्रेशन टूल [`regexp`][regexp] शब्दावली में रहते हैं, और पैटर्न को `R/ ` और `/` के बीच एक लिटरल के रूप में लिखा जाता है।

पैटर्न के ज़्यादातर अक्षर खुद से मेल खाते हैं। असली शक्ति कैरेक्टर क्लास और क्वांटिफायर से आती है:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

तो `R/ [A-Z]{2}-\d{4}/` "दो बड़े अक्षर, एक डैश, चार अंक" से मेल खाता है।

## पूरी स्ट्रिंग का मेल बनाम अंदर खोजना

`matches?` तभी सफल होता है जब *पूरी* स्ट्रिंग पैटर्न से मेल खाती है। बाकी शब्द स्ट्रिंग के *अंदर* खोजते हैं:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## स्लाइस

`first-match` और `re-split` `slice` ऑब्जेक्ट लौटाते हैं, जो मूल स्ट्रिंग को झाँकने का हल्का तरीका हैं, न कि नई स्ट्रिंग। जब आपको अलग स्ट्रिंग चाहिए (जैसे किसी स्ट्रिंग लिटरल से तुलना करने के लिए), तो स्लाइस को `>string` से बदल लीजिए। `all-matching-subseqs` पहले से स्ट्रिंग लौटाता है।

## बदलाव

`re-replace` हर मेल की जगह एक रिप्लेसमेंट स्ट्रिंग रख देता है और नतीजा लौटाता है:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## रनटाइम पर पैटर्न बनाना

फाइल लोड होते समय `R/ /` पार्स हो जाता है। रनटाइम पर बनी स्ट्रिंग से पैटर्न बनाने के लिए `<regexp>` का इस्तेमाल कीजिए:

```
<regexp> ( string -- regexp )
```
