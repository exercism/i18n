# निर्देश

इस अभ्यास में आप रिमोट कंट्रोल कारों पर कुछ और काम करेंगे।

एक प्रयोगात्मक कार बनाई गई है और टेस्ट ट्रैक को ऐसे बदलना है कि वह प्रोडक्शन और प्रयोगात्मक, दोनों तरह की मॉडलों को संभाल सके।
दोनों तरह की कारें बन चुकी हैं और आपको टेस्ट ट्रैक पर इन दोनों को संभालने का तरीका निकालना है।

इसके अलावा, प्रोडक्शन कारें अब कुछ सफलता पाने लगी हैं।
टीम का बॉस प्रोडक्शन कारों की रैंकिंग जारी करके मुकाबले की भावना बनाए रखना चाहता है।

## 1. इंटरफ़ेस लागू कीजिए

`RemoteControlCar` इंटरफ़ेस में दो मेथड जोड़िए:

- `drive()`, जो कुछ नहीं लौटाता, और
- `getDistanceTravelled()`, जो एक `int` लौटाता है।

फिर `ProductionRemoteControlCar` और `ExperimentalRemoteControlCar` से `RemoteControlCar` इंटरफ़ेस लागू करवाइए।
इसमें इंटरफ़ेस के लिए ज़रूरी सभी मेथड लागू करना भी शामिल है।

## 2. कार चलाइए

`.drive()` को हर बार कॉल करने पर कार को एक तय दूरी तय करनी चाहिए:

- एक `ProductionRemoteControlCar` 10 यूनिट चलती है,
- एक `ExperimentalRemoteControlCar` 20 यूनिट चलती है।

`.getDistanceTravelled()` मेथड को उन यूनिटों की संख्या लौटानी चाहिए जितनी दूरी कार ने अब तक तय की है।

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. रेस कराइए

`TestTrack.race(RemoteControlCar car)` मेथड लागू कीजिए, जिसमें `car` को `drive()` करने का मौका मिलता है।

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. प्रोडक्शन कारों को क्रमबद्ध होने दीजिए

कृपया `ProductionRemoteControlCar` क्लास में `Comparable<T>` इंटरफ़ेस लागू कीजिए।
कारों के लिए डिफ़ॉल्ट क्रम जीतों के अवरोही क्रम में होना चाहिए।

स्टैटिक `TestTrack.getRankedCars()` लागू कीजिए, जो इसे दी गई कारों को जीतों की संख्या के अवरोही क्रम में लगाकर लौटाए।

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
