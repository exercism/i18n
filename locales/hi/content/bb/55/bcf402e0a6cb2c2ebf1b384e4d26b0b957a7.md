# निर्देश

यह अभ्यास लॉग फाइलों की पार्सिंग से जुड़ा है।

हाल ही में हुई एक सुरक्षा समीक्षा के बाद आपसे कहा गया है कि आप संगठन की संग्रहीत लॉग फाइलों को साफ करें।

मेथड्स को दी जाने वाली सभी स्ट्रिंग के बारे में यह गारंटी है कि वे null नहीं होंगी और उनके शुरू तथा अंत में कोई स्पेस नहीं होगा।

## 1. बिगड़ी हुई लॉग लाइनों की पहचान कीजिए

आपको अंदाज़ा लगाना है कि आपके संग्रह में कितनी लॉग लाइनें मौजूदा मानकों के अनुरूप नहीं हैं। आपको लगता है कि एक सरल जाँच से पता चल जाता है कि कोई लॉग लाइन वैध है या नहीं। वैध माने जाने के लिए लाइन का शुरू इनमें से किसी एक स्ट्रिंग से होना चाहिए:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

`LogParser.IsValidLine()` मेथड लागू कीजिए, जो किसी स्ट्रिंग के वैध न होने पर `false` लौटाए और वरना `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. लॉग लाइन को टुकड़ों में बाँटिए

संगठन में एक नई टीम जुड़ी है, और आप देखते हैं कि उसकी लॉग फाइलें "फील्ड" के लिए एक अजीब सेपरेटर इस्तेमाल करती हैं। ":" जैसे किसी समझदार सेपरेटर की जगह वे "<--->" या "<=>" जैसी स्ट्रिंग इस्तेमाल करती हैं (क्योंकि वह ज़्यादा सुंदर लगती है)। वास्तव में वे कोई भी ऐसी स्ट्रिंग इस्तेमाल करती हैं जिसका पहला अक्षर "<" हो, अंतिम अक्षर ">" हो, और बीच में "^", "\*", "=" तथा "-" में से किन्हीं अक्षरों का कोई भी मेल हो।

`LogParser.SplitLogLine()` मेथड लागू कीजिए, जो एक लाइन लेता है और ऐसे स्ट्रिंग का ऐरे लौटाता है जिनमें से हर एक में एक फील्ड होता है।

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. उद्धरण चिह्नों में लिखे पासवर्ड वाली लाइनों की गिनती कीजिए

टीम को उन पासवर्ड के बारे में जानना है जो उद्धरण चिह्नों वाले टेक्स्ट में आते हैं, ताकि उनकी जाँच हाथ से की जा सके।

`LogParser.CountQuotedPasswords()` मेथड लागू कीजिए, जो इस बात का अंदाज़ा दे कि हाथ से करने वाला यह काम कितना बड़ा हो सकता है।

ऐसी लॉग लाइनें पहचानिए जिनमें "password" लिखी स्ट्रिंग के चारों ओर उद्धरण चिह्न हों। यह स्ट्रिंग बड़े या छोटे अक्षरों के किसी भी मेल में हो सकती है।

आपको इस बात का ध्यान रखना चाहिए कि "password" से पहले और बाद में, उद्धरण चिह्नों के अंदर, कुछ और भी लिखा हो सकता है।

इस रूटीन को दी गई लाइनें वैध हो भी सकती हैं और नहीं भी, जैसा कार्य 1 में बताया गया है। हम उन्हें एक ही तरीके से प्रोसेस करते हैं, चाहे वे वैध हों या न हों।

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. लॉग से अवशेष हटाइए

आपने पाया है कि लॉग पर पहले होने वाली कुछ प्रोसेसिंग "end-of-line" टेक्स्ट को, जिसके तुरंत बाद बिना स्पेस के एक लाइन नंबर आता है, पूरे लॉग में बिखेरती रही है।

`LogParser.RemoveEndOfLineText()` मेथड लागू कीजिए, जो एक स्ट्रिंग ले, उसमें से end-of-line टेक्स्ट हटाए और एक "साफ़" स्ट्रिंग लौटाए।

जिन लाइनों में end-of-line टेक्स्ट नहीं है, वे जैसी हैं वैसी ही लौटाई जानी चाहिए।

बस end-of-line स्ट्रिंग हटा दीजिए। स्पेस ठीक करने की कोशिश न कीजिए।

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. बहुत कमज़ोर पासवर्ड वाली लाइनें सूचीबद्ध कीजिए ताकि दोषियों को दंड मिल सके

फाइल से पासवर्ड हटाने से पहले हमें ऐसी सभी जगहों की सूची बनानी है जहाँ पासवर्ड "password" टेक्स्ट से शुरू होते हैं।

`LogParser.ListLinesWithPasswords()` मेथड लागू कीजिए, जो दोषी पासवर्ड और उसके बाद पूरी लाइन प्रिंट करे।

उद्धरण चिह्नों वाले पासवर्ड की लाइनें पहले ही हटा दी गई हैं, और आप लाइनों को इस बात की परवाह किए बिना प्रोसेस करते हैं कि वे वैध हैं या नहीं (कार्य 1 के अनुसार)।

जिन लाइनों में दोषी पासवर्ड है, उनके आगे "<password>: " लगाकर लौटाना चाहिए।

जिन लाइनों में दोषी पासवर्ड नहीं है, उनके आगे "--------: " लगाकर लौटाना चाहिए।

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
