# परिचय

## case एक्सप्रेशन

Gleam में `case` एक्सप्रेशन की मदद से कोड को शर्त के अनुसार चलाया जा सकता है। `case` एक्सप्रेशन की सहायता से किसी वैल्यू की जाँच एक या अधिक _पैटर्न_ के सामने की जा सकती है। ऐसे ही एक पैटर्न का उदाहरण _लिटरल पैटर्न_ है, जो किसी वैल्यू की तुलना किसी लिटरल वैल्यू (जैसे `1` या `"hello"`) से करता है।

`case` एक्सप्रेशन को `case` कीवर्ड के साथ लिखा जाता है:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

हालाँकि यह दूसरी भाषाओं के `switch` स्टेटमेंट जैसा दिख सकता है, लेकिन पैटर्न मैचिंग की असली शक्ति तब दिखती है जब आप दूसरे पैटर्न भी इस्तेमाल करते हैं। ऐसा ही एक पैटर्न _वेरिएबल पैटर्न_ है, जिसकी मदद से किसी वेरिएबल में वैल्यू असाइन की जा सकती है। इस उदाहरण में, अगर `number` की वैल्यू `0` नहीं है, तो वेरिएबल `i` को वह वैल्यू असाइन कर दी जाएगी:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

कुछ मामलों में आप किसी पैटर्न में एक और शर्त जोड़ना चाह सकते हैं। इसे _गार्ड_ (क्लॉज़) कहते हैं, जिसे `if` कीवर्ड की मदद से जोड़ा जा सकता है:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

परफॉर्मेंस के कारणों से गार्ड में सिर्फ बुनियादी गणितीय और बूलियन ऑपरेटर ही इस्तेमाल किए जा सकते हैं, गार्ड में दूसरे फंक्शन इस्तेमाल नहीं किए जा सकते।

ऊपर के उदाहरण में, हर संभव इनपुट के लिए कोई मिलता हुआ पैटर्न मौजूद नहीं है। कंपाइलर इसे पकड़ लेगा और एक एरर दिखाएगा। इसे _एक्सहॉस्टिव चेकिंग_ कहते हैं। इस चेतावनी को दूर करने के लिए सभी केसों को संभालना पड़ता है। इसके लिए _डिस्कार्ड पैटर्न_ इस्तेमाल किया जा सकता है, जो किसी भी वैल्यू से मैच कर जाता है:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

एक ही क्लॉज़ में कई पैटर्न मैच किए जा सकते हैं, और हर पैटर्न को अलग करने के लिए `|` इस्तेमाल किया जाता है। एक क्लॉज़ में सिर्फ एक ही गार्ड जोड़ा जा सकता है:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

case एक्सप्रेशन किसी वैल्यू को ऊपर से नीचे तक हर पैटर्न के सामने जाँचता है, जब तक कि उसे कोई मिलता हुआ पैटर्न न मिल जाए और वह उस पैटर्न से जुड़ा कोड चला न दे। पैटर्न का क्रम मायने रखता है!
