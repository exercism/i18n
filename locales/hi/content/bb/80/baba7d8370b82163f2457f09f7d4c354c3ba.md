# परिचय

## chars

Java का `char` प्रिमिटिव टाइप एक अक्षर को 16 बिट में दर्शाता है।
कई `char`s मिलकर एक स्ट्रिंग बना सकते हैं, जैसे `"word"`, या फिर `char`s को अलग-अलग संसाधित किया जा सकता है।
`char` लिटरल को सिंगल कोट्स के बीच रखा जाता है (जैसे `'A'`)।

```java
char lowerA = 'a';
char upperB = 'B';
```

## किसी `String` के `char`s प्राप्त करना

`String.toCharArray` मेथड किसी स्ट्रिंग के सभी अक्षरों को ऐरे के रूप में लौटाता है।
जैसा कि ऐरे में बताया गया है, आप ऐरे पर इटरेशन करने के लिए `for` लूप का उपयोग कर सकते हैं।

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Character क्लास

`char` को जाँचने और बदलने के लिए लाइब्रेरी में कई बिल्ट-इन मेथड मौजूद हैं।
ये `java.lang.Character` क्लास के स्टैटिक मेथड के रूप में उपलब्ध हैं।
यहाँ कुछ उदाहरण दिए गए हैं:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## किसी `String` में `char` जोड़ना

किसी स्ट्रिंग में `char` जोड़ने के लिए `+` ऑपरेटर का उपयोग किया जा सकता है।

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
ध्यान रखिए कि दो `char`s को जोड़कर एक स्ट्रिंग बनाने के लिए `+` का उपयोग _न_ करें!
इस तरह दो `char`s जोड़ने पर `int` मिलता है, `String` _नहीं_!
उदाहरण के लिए:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

ऐसा इसलिए होता है क्योंकि Java `char` को `int` में बदल देता है ([Java Language Specification][jls-main] के [4.2 Primitive Types and Values ][jls-primitives] देखिए)।

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

लेकिन जब बहुत सारे अक्षर जोड़ने हों, तो उनके बजाय `StringBuilder` का उपयोग करना ज़्यादा कुशल हो सकता है:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
