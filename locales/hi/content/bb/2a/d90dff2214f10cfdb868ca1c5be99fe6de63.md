# परिचय

C# के टाइप किसी क्लास या स्ट्रक्चर के स्कोप के अंदर परिभाषित किए जा सकते हैं। बाहरी टाइप एक तरह का नेमस्पेस देता है। किसी टाइप तक पहुँच बाहरी टाइप के ज़रिए डॉट सिंटैक्स से होती है।

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## एक्सेस लेवल

अंदरूनी टाइपों पर एक्सेस लेवल लागू किए जा सकते हैं। उदाहरण के लिए, अगर कोई क्लास `private` है, तो वह बाहरी टाइप के स्कोप के बाहर दिखाई नहीं देती, और ज़ाहिर है कि उसके इंस्टेंस भी स्कोप के बाहर न दिखाई देते हैं और न इस्तेमाल किए जा सकते हैं।

बाहरी क्लास के `private` सदस्य अंदरूनी क्लास के सभी सदस्यों के स्कोप में होते हैं, लेकिन अंदरूनी क्लास के सिर्फ गैर-`private` सदस्य ही बाहरी क्लास के सदस्यों के स्कोप में होते हैं। बाहरी क्लास के सदस्यों तक पहुँचने के लिए अंदरूनी क्लास को बाहरी क्लास का एक इंस्टेंस देना पड़ता है।

यह नीचे के उदाहरण में देखा जा सकता है:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## स्वतंत्र इंस्टेंस बनाना रोकिए

एक पैटर्न ऐसा होता है जिससे इंस्टेंस बना सकने वाला कोई टाइप बाहरी टाइप के बाहर बन ही नहीं सकता। आप एक `public` इंटरफेस सामने रखते हैं, लेकिन उसे लागू करने वाली क्लास को `private` रखते हैं।

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Java डेवलपर के लिए नोट

C# की नेस्टेड क्लास Java की static नेस्टेड क्लास और अंदरूनी क्लास के बीच की चीज़ है। C# में बाहरी क्लास के `private` सदस्य नेस्टेड क्लास के सदस्यों के स्कोप में होते हैं, लेकिन उन्हें इंस्टेंस बनाने और बाहरी क्लास के किसी इंस्टेंस से जोड़ने के लिए कोई खास सिंटैक्स नहीं है। आपको ऊपर के उदाहरणों में दिखाए गए पैटर्न का कोई रूप इस्तेमाल करना पड़ता है।

C# में static नेस्टेड क्लास होती हैं, लेकिन ये सिर्फ अंदर बंद क्लास होती हैं जिनका व्यवहार static होता है।
