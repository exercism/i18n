# निर्देश

आपकी डिज़ाइन टीम अपने कुछ लेआउट कामों के लिए CSS ट्रांसफॉर्म से हटकर अब Factor पर जा रही है। बाकी टीम को खुश रखने के लिए आप छोटे-छोटे, दोबारा इस्तेमाल में आने वाले रूपांतरण क्वोटेशन के रूप में बनाएँगे। ऐसा क्वोटेशन एक 2D पॉइंट लेता है और एक 2D पॉइंट लौटाता है।

एक पॉइंट दो एलिमेंट वाला ऐरे होता है, जैसे `{ x y }`।

## 1. निर्देशांकों का स्थानांतरण कीजिए

`translate-2d` को ऐसा बनाइए जो स्टैक से दो वैल्यू, `dx` और `dy`, ले और एक क्वोटेशन लौटाए। यह क्वोटेशन किसी पॉइंट को `(dx, dy)` से स्थानांतरित करता है।

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. निर्देशांकों को स्केल कीजिए

`scale-2d` को भी इसी तरह बनाइए। यह एक ऐसा क्वोटेशन लौटाता है जो किसी पॉइंट को `(sx, sy)` से स्केल करता है।

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. दो रूपांतरणों को मिलाइए

`compose-transformations` को ऐसा बनाइए जो दो रूपांतरण क्वोटेशन, `f` और `g`, ले और एक ही क्वोटेशन लौटाए। यह नया क्वोटेशन पहले `f` लागू करता है और उसके बाद `g`।

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. एक रूपांतरण लागू कीजिए

`apply-transformation` को ऐसा बनाइए जो स्टैक से एक पॉइंट और एक रूपांतरण क्वोटेशन ले और रूपांतरित पॉइंट लौटाए।

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. एक साथ कई पॉइंट का रूपांतरण कीजिए

`transform-points` को ऐसा बनाइए जो पॉइंट का एक ऐरे और एक रूपांतरण क्वोटेशन ले, और रूपांतरित पॉइंट का ऐरे लौटाए।

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
