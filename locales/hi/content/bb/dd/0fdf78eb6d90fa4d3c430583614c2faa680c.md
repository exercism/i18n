# निर्देशों का परिशिष्ट

## सेटअप

आवश्यक डिपेंडेंसी इंस्टॉल करने के लिए TypeScript के सेटअप निर्देश पढ़िए:

[https://exercism.org/docs/tracks/typescript/installation](https://exercism.org/docs/tracks/typescript/installation)

## आवश्यकताएँ

इस असाइनमेंट की डिपेंडेंसी इंस्टॉल कीजिए:

```bash
$ yarn install
```

## टेस्ट सूट पास कराना

टेस्ट चलाने के लिए यह कमांड इस्तेमाल कीजिए:

```bash
$ yarn test
```

बहुत से टेस्ट सूट में पहले वाले टेस्ट को छोड़कर बाकी सभी टेस्ट छोड़ दिए जाते हैं।

जब कोई एक टेस्ट पास हो जाए, तो `xit` को `it` में बदलकर आप अगला टेस्ट भी चालू कर सकते हैं।

## ट्यूटोरियल

यह भाग चरण-दर-चरण बताता है कि इस अभ्यास को कैसे हल करना है।

इस अभ्यास में दो फाइलें हैं:

- hello-world.ts
- hello-world.test.ts

पहली फाइल में आप अपना कोड लिखेंगे।
दूसरी फाइल में टेस्ट लिखे गए हैं।

टेस्ट यह जाँचेंगे कि आपका कोड सही काम कर रहा है या नहीं।
आपको शुरू से टेस्ट सूट लिखना आना ज़रूरी नहीं है, लेकिन यह समझना मददगार होता है कि एक टेस्ट कैसा दिखता है और क्या करता है।

टेस्ट फाइल hello-world.test.ts खोलिए।
इसके अंदर एक ही टेस्ट है:

```typescript
it('says hello world', () => {
  expect(hello()).toEqual('Hello, World!')
})
```

अब कमांड-लाइन पर यह कमांड चलाकर टेस्ट चलाइए:

```bash
$ yarn test
```

टेस्ट फेल होता है, जो स्वाभाविक है क्योंकि आपने अभी तक कोई कोड नहीं लिखा है।

फेल होने पर कुछ ऐसा दिखता है:

```
    × says hello world (5ms)

  ● Hello World › says hello world

    expect(received).toEqual(expected) // deep equality

    Expected: "Hello, World!"
    Received: "Goodbye, Mars!"

      4 |
      5 |   it('says hello world', () => {
    > 6 |     expect(hello()).toEqual('Hello, World!')
        |                     ^
      7 |   })
      8 |
      9 | })

      at Object.it (hello-world.test.ts:6:32)
```

और ये वे कोड लाइनें हैं, जिनमें `hello-world.test.ts` फाइल में संभावित त्रुटियाँ हैं:

छठी लाइन:

```typescript
    expect(hello()).toEqual('Hello, World!')
                    ^
```

तो समस्या `hello()` फंक्शन को कॉल करने में है।
हम देख सकते हैं कि टेस्ट आउटपुट के रूप में `'Hello, World!'` की अपेक्षा कर रहा है, लेकिन उसे `"Goodbye, Mars!"` मिल रहा है।

तो चलिए अब `hello-worlds.ts` फाइल में इस फंक्शन को देखते हैं:

```typescript
export function hello(): string {
  return 'Goodbye, Mars!'
}
```

अब हम देखते हैं कि फंक्शन गलत स्ट्रिंग लौटाता है, और यही हमारे फेल होने की वजह है। चलिए लौटाई जाने वाली वैल्यू बदलकर इसे ठीक करते हैं:

```typescript
export function hello(): string {
  return 'Hello, World!'
}
```

टेस्ट फिर से चलाइए:

```bash
 PASS  ./hello-world.test.ts
  Hello World
    √ says hello world (4ms)
```

और यह पास हो जाता है!
