# स्थिति वाली क्लास

अब तक की हर क्लास रूटीन का एक डिब्बा रही है। हर रूटीन अपने आर्गुमेंट लेता था, जवाब निकालता था और सब कुछ भूल जाता था।

क्लास इसके बजाय चीज़ें **याद** रख सकती है। स्कोरबोर्ड को तो याद रखना ही पड़ता है: अब स्कोर इस पर निर्भर करता है कि खेल शुरू होने के बाद से कितने गोल हुए हैं।

## एट्रिब्यूट

`attr` क्लास को याद रखने के लिए कुछ देता है।

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

हर `attr` दो रूटीन बन जाता है, एक जो वैल्यू पढ़ता है और एक जो उसे बदलता है:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

एक ही टाइप के एट्रिब्यूट एक ही घोषणा में लिखे जा सकते हैं, ठीक वैसे ही जैसे आर्गुमेंट लिखे जा सकते हैं:

```sather
   attr home_score, away_score : INT;
```

## ऑब्जेक्ट

एट्रिब्यूट वाली क्लास **ऑब्जेक्ट** बनाने का एक खाका होती है। हर ऑब्जेक्ट के पास एट्रिब्यूट की अपनी कॉपी होती है, इसलिए दो स्कोरबोर्ड दो स्कोर याद रखते हैं।

`new` एक ऑब्जेक्ट बनाता है। यह `create` नाम के रूटीन के अंदर लिखा जाता है, जो फिर ऑब्जेक्ट को भरता है और उसे लौटा देता है:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` का मतलब है "यही क्लास"। वहाँ `SCOREBOARD` लिखने से भी यही बात कही जाती, लेकिन क्लास का नाम बदल देने पर भी `SAME` काम करता रहता है।

## ऑब्जेक्ट बनाना

`#` `create` को कॉल करता है:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

आप `rehearsal-script` से ही `#` का इस्तेमाल करते आ रहे हैं। `#FSTR` बिल्कुल यही है।

## ऑब्जेक्ट बदलने वाले रूटीन

क्लास के अंदर एट्रिब्यूट का इस्तेमाल उसके नाम से होता है, आगे कोई ऑब्जेक्ट नहीं लिखा जाता। इसका मतलब वह ऑब्जेक्ट होता है जिस पर यह रूटीन कॉल किया गया था।

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` कोई रिटर्न टाइप घोषित नहीं करता, क्योंकि यह कोई जवाब नहीं देता, बल्कि ऑब्जेक्ट को बदल देता है। इसे स्टेटमेंट की तरह कॉल कीजिए:

```sather
   board.home_goal;
```

## एट्रिब्यूट शुरू में खाली होते हैं

जो एट्रिब्यूट किसी ने सेट नहीं किया, वह `INT` के लिए शून्य, `BOOL` के लिए `false`, और स्ट्रिंग या ऑब्जेक्ट के लिए void रखता है। इसलिए एक नया स्कोरबोर्ड अपने आप 0 से 0 दिखाता है, बिना कुछ कहे।
