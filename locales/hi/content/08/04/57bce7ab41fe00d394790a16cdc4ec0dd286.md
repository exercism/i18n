# निर्देश परिशिष्ट

## एक्सेप्शन संदेश

कभी-कभी [एक्सेप्शन उठाना](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) ज़रूरी हो जाता है। ऐसा करते समय आपको हमेशा एक **अर्थपूर्ण एरर संदेश** शामिल करना चाहिए, जो बताए कि एरर का स्रोत क्या है। इससे आपका कोड पढ़ने में आसान होता है और डीबग करने में काफी मदद मिलती है। जिन स्थितियों में आपको पता होता है कि एरर का स्रोत एक तय टाइप का होगा, वहाँ आप [अंतर्निहित एरर टाइप](https://docs.python.org/3/library/exceptions.html#base-classes) में से कोई एक चुनकर उठा सकते हैं, लेकिन तब भी एक अर्थपूर्ण संदेश शामिल करना चाहिए।

इस अभ्यास में ज़रूरी है कि अगर इनपुट में सही डेलिमिटर नहीं हैं, वह बड़े अक्षरों में नहीं है, वह नोड वाला ट्री नहीं बनाता, या ट्री बिल्कुल नहीं बनाता, तो आप [raise स्टेटमेंट](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) का उपयोग करके `ValueError` "फेंकें"। टेस्ट तभी पास होंगे, जब आप `exception` को `raise` भी करें और उसके साथ एक संदेश भी शामिल करें।

किसी संदेश के साथ `ValueError` उठाने के लिए, उस संदेश को `exception` टाइप के एक आर्गुमेंट के रूप में लिखिए:

```python
# if the tree properties as given do not have proper delimiters.
raise ValueError("properties without delimiter")

# if the tree properties as given are not all in uppercase.
raise ValueError("property must be in uppercase")

# if the input does not form a tree, or is empty.
raise ValueError("tree missing")

# if the input is a tree without any nodes.
raise ValueError("tree with no nodes")
```
