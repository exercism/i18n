# इंस्टॉलेशन


## GHCup इंस्टॉल कीजिए

Haskell के टूल इंस्टॉल करने का सुझाया गया तरीका [GHCup][ghcup] है।

GHCup की मदद से आप अपने इंस्टॉल किए गए कंपाइलर, प्रोजेक्ट/पैकेज मैनेजर और भाषा सर्वर संभाल सकते हैं।


## Stack इंस्टॉल कीजिए

Exercism के अभ्यास करने के लिए आपको सिर्फ Stack की ज़रूरत है।

Stack इंस्टॉल करने के लिए GHCup की इंस्टॉलेशन कमांड या स्क्रिप्ट चलाइए।
डिफ़ॉल्ट विकल्पों को स्वीकार करते जाइए, लेकिन यह ज़रूर बताइए कि आप Stack भी इंस्टॉल करना चाहते हैं।

क्या आपसे गलती से Stack का इंस्टॉलेशन छूट गया?
कोई बात नहीं: बाद में `ghcup install stack` चलाइए।

GHCup ये चीज़ें इंस्टॉल करता है

- **एक कंपाइलर** (GHC: ग्लासगो Haskell कंपाइलर)

  सख्ती से देखें तो Exercism के लिए आपको इसकी ज़रूरत नहीं है, लेकिन जब आप अभ्यास वाली डायरेक्ट्री के बाहर [GHCi][ghc-guide-ghci] के साथ खेलना चाहें, तब यह काम आता है।

- **Cabal**

  एक प्रोजेक्ट/पैकेज मैनेजर।
  Exercism के लिए आपको इसकी ज़रूरत नहीं है।

- **Stack**

  वह प्रोजेक्ट/पैकेज मैनेजर जिसका इस्तेमाल आप Exercism के लिए करेंगे।
  यह पक्का करेगा कि हर अलग प्रोजेक्ट (अभ्यास) के लिए आपके पास सही कंपाइलर और लाइब्रेरी मौजूद हों।

यह जाँचने के लिए कि इंस्टॉलेशन सफल रहा, इनमें से कोई भी कमांड चलाइए

- `ghcup list`: सफलता का मतलब है टूल वर्ज़न की एक लंबी सूची, जिसमें Stack पर इंस्टॉल का निशान लगा हो
- `stack --version`: सफलता ऐसी दिखती है: `Version 2.7.5, Git revision ...`


## सही GHC वर्ज़न प्राप्त कीजिए

जब GHC की ज़रूरत पड़ेगी, तब Stack उसे अपने आप डाउनलोड और इंस्टॉल कर लेगा।
आप टर्मिनल में ये कमांड चलाकर इंस्टॉलेशन शुरू कर सकते हैं और उसे जाँच भी सकते हैं:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

अगर यह कुछ ऐसा दिखाए

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

तो GHC सही तरीके से इंस्टॉल हो चुका है।


## अपने एडिटर को Haskell के साथ काम करने के लिए तैयार कीजिए

Haskell का सपोर्ट Haskell Language Server (HLS) देता है।
भाषा सपोर्ट ज़रूरी नहीं है, लेकिन इसकी पुरज़ोर सलाह दी जाती है।


### Visual Studio Code (सुझाया गया)

बस [Visual Studio Code के लिए Haskell एक्सटेंशन][vscode-haskell] ले लीजिए।
यह HLS को अपने आप इंस्टॉल करने के लिए GHCup का इस्तेमाल करेगा, और उसके बाद आप पूरी तरह तैयार होंगे।

**ध्यान दें:** नए डाउनलोड किए गए अभ्यासों के साथ HLS को शुरू होने में परेशानी आ सकती है।
अगर ऐसा हो, तो `stack test` चलाइए और भाषा सर्वर को फिर से शुरू कीजिए।


### दूसरे एडिटर

[एडिटर कॉन्फ़िगरेशन के लिए HLS का डॉक्युमेंटेशन][hls-editor-config] देखिए।
आपको HLS शायद खुद से इंस्टॉल करना पड़े।
इसके लिए `ghcup install hls` चलाइए।
