# निर्देश

आपके एक दोस्त ने अभी-अभी आपको एक ज़रूरी राज़ वाला संदेश भेजा है। दूसरों के लिए इसे पढ़ना आसान न हो, इसलिए संदेश को बिट में कई बदलाव करके एन्क्रिप्ट किया गया है। संदेश को डिक्रिप्ट करने में मदद के लिए आपको कुछ फंक्शन लिखने होंगे।

## 1. बिट को वापस शिफ्ट कीजिए

संदेश को डिक्रिप्ट करने का पहला कदम है एन्क्रिप्शन के समय हुई शिफ्टिंग को उलटना, यानी बिट को दाईं ओर वापस शिफ्ट करना। डिक्रिप्शन के आगे के कदम यह मानकर चलेंगे कि बाईं ओर से 0 डाले गए हैं।

`shiftBack` फंक्शन बनाइए, जो एक वैल्यू और जितने स्थान शिफ्ट करना है वह संख्या लेता है और शिफ्ट कर देता है।

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. कुछ बिट सेट कीजिए

इसके बाद, कुछ बिट ऐसे हैं जिन्हें 1 पर सेट करना है।

`setBits` फंक्शन बनाइए, जो एक वैल्यू और एक मास्क लेता है और वैल्यू के बिट को 1 पर सेट करके परिणाम लौटाता है। जहाँ मास्क में बिट 1 है, वहाँ वैल्यू का बिट भी 1 पर सेट होना चाहिए। बाकी सारे बिट जैसे हैं वैसे ही रहने चाहिए।

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. चुनिंदा बिट फ्लिप कीजिए

एन्क्रिप्शन के समय कुछ बिट फ्लिप किए जाते हैं। संदेश को डिक्रिप्ट करने के लिए उन्हें वापस फ्लिप करना होगा।

`flipBits` फंक्शन बनाइए, जो एक वैल्यू और एक मास्क लेता है। मास्क बताता है कि वैल्यू के कौन-से बिट फ्लिप करने हैं। जहाँ मास्क में बिट 1 है, वहाँ वैल्यू का बिट फ्लिप हो जाता है। बाकी सारे बिट जैसे हैं वैसे ही रहते हैं।

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. चुनिंदा बिट क्लियर कीजिए

अंत में, कुछ बिट ऐसे भी हैं जो हमेशा 0 पर डिक्रिप्ट होते हैं।

`clearBits` फंक्शन बनाइए, जो एक वैल्यू और एक मास्क लेता है। जहाँ मास्क में बिट 1 है, वहाँ `value` के बिट 0 पर सेट होने चाहिए। बाकी सारे बिट जैसे हैं वैसे ही रहने चाहिए।

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
