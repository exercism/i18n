# मूल बातें के बारे में

मूल बातें कॉन्सेप्ट में [Go](https://golang.org) को एक स्टैटिक टाइप वाली और कंपाइल होने वाली प्रोग्रामिंग भाषा के रूप में पेश किया गया।
इस भाषा को अक्सर Golang कहा जाता है, क्योंकि पहले इसका डोमेन नाम golang.org था, लेकिन इसका सही नाम Go है।

मूल बातें कॉन्सेप्ट भाषा की तीन बड़ी विशेषताओं से परिचय कराता है: पैकेज, फंक्शन और वेरिएबल।

## पैकेज

Go के एप्लिकेशन पैकेजों में व्यवस्थित रहते हैं।
पैकेज एक ही डायरेक्टरी में रखी सोर्स फाइलों का समूह होता है।
किसी डायरेक्टरी की सभी सोर्स फाइलों का पैकेज नाम एक ही होना चाहिए।
आम तौर पर पैकेज का नाम इंपोर्ट पाथ की अंतिम डायरेक्टरी होता है।
उदाहरण के लिए, ["math/rand" पैकेज](https://golang.org/src/math/rand/) की फाइलें `package rand` स्टेटमेंट से शुरू होती हैं।
जब कोई पैकेज इंपोर्ट किया जाता है, तो केवल उन्हीं चीज़ों (फंक्शन, टाइप, वेरिएबल, कॉन्स्टेंट) का इस्तेमाल किया जा सकता है या उन तक पहुँचा जा सकता है जिनके नाम बड़े अक्षर से शुरू होते हैं।
Go में नाम रखने का सुझाया गया तरीका यह है कि आइडेंटिफायर के नाम `camelCase` में रखे जाएँ, सिवाय उनके जिन्हें कई पैकेजों में इस्तेमाल करने के लिए बनाया गया हो; ऐसे नाम `PascalCase` में होने चाहिए।

```go
package lasagna
```

## वेरिएबल

Go स्टैटिक टाइप वाली भाषा है, यानी कंपाइल के समय हर वेरिएबल का [एक तय टाइप होना ज़रूरी है](https://en.wikipedia.org/wiki/Type_system)।

वेरिएबल को टाइप स्पष्ट रूप से लिखकर परिभाषित किया जा सकता है:

```go
var explicit int // Explicitly typed
```

आप इनिशियलाइज़र का भी इस्तेमाल कर सकते हैं, और कंपाइलर वेरिएबल का टाइप इनिशियलाइज़र के टाइप के मुताबिक असाइन कर देगा।

```go
implicit := 10   // Implicitly typed as an int
```

घोषित होने के बाद वेरिएबल में `=` ऑपरेटर की मदद से वैल्यू असाइन की जा सकती है।
एक बार घोषित होने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## कॉन्स्टेंट

कॉन्स्टेंट भी वेरिएबल की तरह एक डेटा रखते हैं, लेकिन प्रोग्राम चलने के दौरान उनकी वैल्यू नहीं बदल सकती।

कॉन्स्टेंट `const` कीवर्ड से बनाए जाते हैं, और ये संख्याएँ, अक्षर, स्ट्रिंग या बूलियन हो सकते हैं:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## फंक्शन

Go के फंक्शन शून्य या उससे अधिक पैरामीटर लेते हैं।
पैरामीटर का टाइप स्पष्ट रूप से लिखना होता है; यहाँ टाइप का अनुमान नहीं लगाया जाता।

फंक्शन `return` कीवर्ड की मदद से वैल्यू लौटाते हैं।

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं।

ध्यान दीजिए कि Go में दो तरह के कमेंट होते हैं।
एक लाइन वाले कमेंट `//` से शुरू होते हैं, और कई लाइन वाले कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
