# टेस्ट

टेस्ट चलाने के लिए यह कमांड इस्तेमाल कीजिए:

```bash
$ wrenc exercise-name.spec.wren
```

जैसे, `hello-world` के लिए:

```bash
$ wrenc hello-world.spec.wren
```


## स्किप किए गए टेस्ट को समझिए

`skip` मेथड टेस्ट सूट को बताता है कि वह किसी एक खास टेस्ट को न चलाए।

- इन्हें स्किप क्यों किया जाता है?

ताकि उपयोगकर्ता एक बार में एक टेस्ट पर ध्यान दे सकें और जैसे-जैसे वे अपना हल आगे बढ़ाएँ, एक-एक करके बाकी टेस्ट भी चालू कर सकें।

- इन्हें चालू कैसे करें?

एक स्किप किया गया टेस्ट:

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

बस `skip.test` को `do.test` में बदल दीजिए।

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## अपना पहला Wren मॉड्यूल बनाइए

इस ट्रैक के टेस्ट आपके इम्प्लीमेंटेशन को एक Wren मॉड्यूल के रूप में इम्पोर्ट करके लोड करते हैं: `import "./bob" for Bob`. अपने इम्प्लीमेंटेशन को एक्सपोर्ट करने के लिए कोई खास सिंटैक्स नहीं है। बस अपनी क्लास का नाम `Bob` रखिए, ताकि वह `for Bob` वाले इम्पोर्ट स्टेटमेंट से मेल खाए, और सब कुछ अपने आप ठीक से काम करने लगेगा।

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

मॉड्यूल के बारे में अधिक जानकारी आप [Wren मॉड्यूलरिटी डॉक्यूमेंटेशन][modularity] में पा सकते हैं। शुरुआत करना आसान बनाने के लिए हर अभ्यास की डायरेक्टरी में एक _स्केलेटन_ Wren फाइल मौजूद है।

[modularity]: https://wren.io/modularity.html
