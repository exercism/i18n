# अधिक जानकारी

Go में हम बराबरी और क्रम के ऑपरेटरों की मदद से वैल्यू की तुलना कर सकते हैं। ऐसे 6 ऑपरेटर हैं:

| तुलना              | ऑपरेटर   |
| ------------------| --------- |
| बराबर             | `==`      |
| बराबर नहीं         | `!=`      |
| कम                | `<`       |
| कम या बराबर        | `<=`      |
| अधिक              | `>`       |
| अधिक या बराबर      | `>=`      |

तुलना का परिणाम हमेशा एक बूलियन वैल्यू होता है:

```go
a := 3

a != 4 // true
a > 5  // false
```

## बराबरी के ऑपरेटर

बराबरी के ऑपरेटर `==` और `!=` जाँचते हैं कि कोई वैल्यू किसी दूसरी वैल्यू के बराबर है या नहीं। `==` बराबरी की जाँच करता है और `!=` असमानता की।
Go में हम बराबरी के ऑपरेटर ज़्यादातर टाइप पर इस्तेमाल कर सकते हैं।
यहाँ कुछ आम उदाहरण दिए गए हैं:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## क्रम के ऑपरेटर

क्रम के ऑपरेटर जाँचते हैं कि कोई वैल्यू किसी दूसरी वैल्यू से अधिक है (`>`), उससे अधिक या बराबर है (`>=`), उससे कम है (`<`), या उससे कम या बराबर है (`<=`)।
इस तरह की तुलना संख्याओं, बाइट, रून और स्ट्रिंग के लिए उपलब्ध है।
स्ट्रिंग की तुलना करते समय शब्दकोश क्रम का पालन किया जाता है, जिसे लेक्सिकोग्राफिक क्रम भी कहते हैं।

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
