# परिचय

Java में ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग का मुख्य आधार _क्लास_ है, जो डेटा (_फील्ड_) और व्यवहार (_मेथड_) को मिलाकर बनी होती है।
किसी क्लास के फील्ड और मेथड उसके _सदस्य_ कहलाते हैं।

सदस्यों तक पहुँच को एक्सेस मॉडिफायर से नियंत्रित किया जा सकता है। इनमें सबसे आम दो ये हैं:

- `public`: इस सदस्य तक कोई भी कोड पहुँच सकता है (कोई रोक नहीं)।
- `private`: इस सदस्य तक सिर्फ उसी क्लास का कोड पहुँच सकता है।

आप क्लास को उस क्लास के इंस्टेंस बनाने का टेम्पलेट मान सकते हैं।
किसी क्लास का इंस्टेंस बनाने के लिए (जिसे _ऑब्जेक्ट_ भी कहते हैं) `new` कीवर्ड का इस्तेमाल किया जाता है:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

फील्ड का एक टाइप और एक नाम होता है (जो camelCase में लिखा जाता है), और इन्हें क्लास में कहीं भी परिभाषित किया जा सकता है (परंपरा से PascalCase में):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

आप चाहें तो किसी फील्ड को शुरुआती वैल्यू असाइन कर सकते हैं।
अगर किसी फील्ड के लिए शुरुआती वैल्यू नहीं दी जाती, तो उसमें उसके टाइप की डिफ़ॉल्ट वैल्यू रख दी जाती है।
किसी इंस्टेंस के फील्ड की वैल्यू डॉट नोटेशन से पढ़ी और बदली जा सकती हैं।

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

प्राइवेट फील्ड आम तौर पर किसी मेथड को कॉल करने के साइड इफेक्ट के रूप में बदल जाते हैं।
ऐसे मेथड आम तौर पर कोई वैल्यू नहीं लौटाते। ऐसी स्थिति में रिटर्न टाइप `void` होना चाहिए:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
