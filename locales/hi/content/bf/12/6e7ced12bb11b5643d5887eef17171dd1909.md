# निर्देश

भावी जादूगरनी के रूप में एलिस को कुछ बुनियादी बातों का अभ्यास करना है। उसके पास कार्डों का एक ढेर है, जिसके साथ वह कुछ करना चाहती है।

चीज़ें थोड़ी आसान बनाने के लिए वह सिर्फ 1 से 10 तक के कार्ड इस्तेमाल करती है।

कार्डों के ढेर को एक `queue` से दर्शाया जाता है, जिसमें ढेर का निचला हिस्सा queue के आगे और ढेर का ऊपरी हिस्सा queue के पीछे होता है।

## 1. ढेर के ऊपर एक कार्ड डालिए

`insert_top` फंक्शन बनाइए जो ढेर की एक कॉपी लौटाता है, जिसमें दिया गया नया कार्ड ढेर के ऊपर जोड़ा गया हो।

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. ढेर से सबसे ऊपर का कार्ड हटाइए

`remove_top_card` फंक्शन बनाइए जो ढेर की एक कॉपी लौटाता है, जिसमें से सबसे ऊपर का कार्ड हटा दिया गया हो। अगर दिया गया ढेर खाली है, तो मूल ढेर बिना बदलाव के लौटाया जाना चाहिए।

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. ढेर के नीचे एक कार्ड डालिए

`insert_bottom` फंक्शन बनाइए जो ढेर की एक कॉपी लौटाता है, जिसमें दिया गया नया कार्ड ढेर के नीचे जोड़ा गया हो।

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. ढेर के नीचे से एक कार्ड हटाइए

`remove_bottom_card` फंक्शन बनाइए जो ढेर की एक कॉपी लौटाता है, जिसमें से सबसे नीचे का कार्ड हटा दिया गया हो। अगर दिया गया ढेर खाली है, तो मूल ढेर बिना बदलाव के लौटाया जाना चाहिए।

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. ढेर का आकार जाँचिए

`check_size_of_stack` फंक्शन बनाइए जो जाँचता है कि ढेर का आकार दिए गए `stack_size` के बराबर है या नहीं।

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
