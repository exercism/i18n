# CLI

## सेटअप

PureScript इंस्टॉल करने का सबसे आसान तरीका Node.js और NPM के ज़रिए है।

अगर आपके कंप्यूटर पर Node.js पहले से इंस्टॉल नहीं है, तो आप इसे [Node.js की वेबसाइट][nodejs-website] से डाउनलोड कर सकते हैं। Node.js चलना शुरू हो जाने के बाद, PureScript कंपाइलर और Spago पैकेज मैनेजर/बिल्ड टूल इंस्टॉल करने के लिए टर्मिनल में यह कमांड डालिए।

```shell
npm install -g purescript spago
```

और जानकारी [PureScript रिपॉज़िटरी][purescript-repository] में मिल सकती है।

## आवश्यकताएँ

अभ्यास की डिपेंडेंसी इंस्टॉल कीजिए:

```shell
spago install
spago build
```

## टेस्ट सूट पास कराना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```shell
spago test
```

टेस्ट सूट में पहले टेस्ट के अलावा बाकी सभी टेस्ट स्किप किए गए हैं। इसका उद्देश्य यह है कि आप अभ्यास को एक-एक कदम करके हल करें।

एक टेस्ट पास हो जाने पर, आप `xit` को `it` में बदलकर अगला टेस्ट चालू कर सकते हैं।

## हल जमा करना

जब कोई भी टेस्ट स्किप न रहे और सभी टेस्ट पास हो जाएँ, तो आप अपना हल इनके ज़रिए जमा कर सकते हैं:

```shell
exercism submit src/<NAME>.purs
```

## अपने खुद के टेस्ट लिखना

अगर आप अतिरिक्त, अपने खुद के टेस्ट लिखना चाहते हैं, तो एक नई फाइल `test/Custom.purs` बनाइए और अपने हल के साथ उस नई फाइल को भी जमा कीजिए:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
