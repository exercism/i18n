# परिचय

Python में, [एक `enum`][enum-docs] ऐसे नामों का समूह है जो अलग-अलग `literal` या `constant` वैल्यू से जुड़े होते हैं।
`Enums` को किसी `Enum` क्लास से इनहेरिट करके, या उसकी सबक्लास बनाकर परिभाषित किया जाता है।
बिल्ट-इन `enum` टाइप मॉड्यूल `enum` में उपलब्ध हैं, और `Enum` क्लास को `from enum import Enum` से इम्पोर्ट किया जा सकता है।


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

ध्यान दीजिए कि `enum` के सदस्यों की वैल्यू किसी भी डेटा टाइप की हो सकती है, जैसे `str`, `tuple`, `float` इत्यादि।

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

जब `enum` के दो सदस्यों को एक ही वैल्यू असाइन की जाती है, तो बाद में असाइन किया गया सदस्य पहले वाले का एलियस बन जाता है। `enum` के दो अलग सदस्यों के लिए एक ही नाम रखने की अनुमति नहीं है।

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

`enum` के सदस्यों पर इटरेशन मानक `for member in` सिंटैक्स से किया जा सकता है:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

`Enum` के सदस्यों की तुलना [`is` (_पहचान ऑपरेटर_)][identity-keyword] या `is not` से की जा सकती है। `==` या `!=` (_समानता ऑपरेटर_) भी वैसे ही काम करते हैं:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

किसी दी गई वैल्यू के लिए `enum` के सदस्य तक पहुँचने के लिए `<EnumName>(<value>)` का उपयोग किया जा सकता है:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
