# परिचय

अब तक हमने देखा है कि मेथड को दिए जाने वाले आर्गुमेंट, मेथड में घोषित पैरामीटर से क्रम के आधार पर मिलाए जाते हैं। एक दूसरा तरीका भी है। खास तौर पर जब किसी रूटीन में बहुत सारे आर्गुमेंट हों, तो कॉलर घोषित पैरामीटर का आइडेंटिफायर बताकर आर्गुमेंट मिला सकता है।

आगे दिया गया उदाहरण इस सिंटैक्स को दिखाता है:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
