# निर्देश

आपको GPS निर्देशांक पार्स करने हैं।
हर निर्देशांक [दशमलव अंश प्रारूप](https://en.wikipedia.org/wiki/Decimal_degrees) के उस रूप में लिखा जाता है जिसमें गोलार्ध स्पष्ट रूप से दिए जाते हैं:

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

हर अलग हिस्से के लिए ये मान्य वैल्यू हैं:

- `<LATITUDE_DEGREES>`: 0..90 (दोनों समेत) के बीच की एक दशमलव संख्या
- `<LATITUDE_HEMISPHERE>`: `N` या `S`
- `<LONGITUDE_DEGREES>`: 0..180 (दोनों समेत) के बीच की एक दशमलव संख्या
- `<LONGITUDE_HEMISPHERE>`: `E` या `W`

उदाहरण के लिए, `"48.8584 N, 2.2945 E"` पार्स होकर यह बनता है:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

आपके सामने 11 कार्य हैं, जिनमें आप GPS निर्देशांकों को एक-एक करके पार्स करेंगे।
आप Prolog के [डेफिनिट क्लॉज़ ग्रामर](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG) सपोर्ट का इस्तेमाल करेंगे, जिसे संरचित टेक्स्ट पार्स करने के लिए बनाया गया है।

````exercism/note
शुरू करने में मदद के लिए, स्टब फाइल में पहले से ही [`dcg/basics` लाइब्रेरी](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) शामिल है, इस तरह:

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. अल्पविराम पार्स कीजिए

सिर्फ एक अल्पविराम (`","`) पार्स करने के लिए `comma` रूल लागू कीजिए:

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. स्पेस पार्स कीजिए

सिर्फ एक स्पेस (`" "`) पार्स करने के लिए `space` रूल लागू कीजिए:

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. न्यूलाइनों के अलावा सभी व्हाइटस्पेस का सपोर्ट कीजिए

`space` रूल को बदलकर ऐसा बनाइए कि वह न्यूलाइनों को छोड़कर _सभी_ व्हाइटस्पेस पार्स करे:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. अक्षांश का गोलार्ध पार्स कीजिए

अक्षांश का गोलार्ध `"N"` या `"S"` हो सकता है, जिसे `north` या `south` एटम में पार्स किया जाना चाहिए।
अक्षांश का गोलार्ध पार्स करने के लिए `latitude_hemisphere` रूल लागू कीजिए:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. देशांतर का गोलार्ध पार्स कीजिए

देशांतर का गोलार्ध `"E"` या `"W"` हो सकता है, जिसे `east` या `west` एटम में पार्स किया जाना चाहिए।
देशांतर का गोलार्ध पार्स करने के लिए `longitude_hemisphere` रूल लागू कीजिए:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. अंश पार्स कीजिए

किसी देशांतर या अक्षांश के अंश एक दशमलव संख्या के रूप में परिभाषित होते हैं।
दशमलव संख्याएँ पार्स करने के लिए `degrees` रूल लागू कीजिए:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. अक्षांश के अंश पार्स कीजिए

अक्षांश के अंश सिर्फ दशमलव संख्याएँ नहीं हैं, बल्कि वे 0..90 (दोनों समेत) के बीच की दशमलव संख्याएँ हैं।
ऊपर दी गई सीमा का इस्तेमाल करके अक्षांश के अंश पार्स करने के लिए `latitude_degrees` रूल लागू कीजिए:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. देशांतर के अंश पार्स कीजिए

देशांतर के अंश सिर्फ दशमलव संख्याएँ नहीं हैं, बल्कि वे 0..180 (दोनों समेत) के बीच की दशमलव संख्याएँ हैं।
ऊपर दी गई सीमा का इस्तेमाल करके देशांतर के अंश पार्स करने के लिए `longitude_degrees` रूल लागू कीजिए:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. अक्षांश पार्स कीजिए

अक्षांश के दो हिस्से होते हैं: उसके अंश और गोलार्ध, जिन्हें एक स्पेस से अलग किया जाता है।
एक अक्षांश पार्स करने के लिए `latitude` रूल लागू कीजिए:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. देशांतर पार्स कीजिए

अक्षांश के दो हिस्से होते हैं: उसके अंश और गोलार्ध, जिन्हें एक स्पेस से अलग किया जाता है।
एक अक्षांश पार्स करने के लिए `latitude` रूल लागू कीजिए:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. निर्देशांक पार्स कीजिए

निर्देशांक के दो हिस्से होते हैं: उसके अक्षांश और देशांतर, जिन्हें एक अल्पविराम और उसके बाद एक स्पेस से अलग किया जाता है।
अक्षांश के दोनों हिस्सों, यानी उसके अंश और गोलार्ध, को पार्स करने के लिए `coordinate` रूल लागू कीजिए:

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
