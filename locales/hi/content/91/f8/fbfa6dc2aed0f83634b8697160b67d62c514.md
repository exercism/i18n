# बारे में

फ्लोटिंग-पॉइंट संख्याएँ वे भिन्नात्मक या पूर्ण संख्याएँ होती हैं जिनमें दशमलव बिंदु आता है (जैसे `3.14`, `-1.7`, `99.99`, `2048.0`)।

Common Lisp में फ्लोट टाइप को कई उपप्रकारों में बाँटा गया है, और हर उपप्रकार की अपनी विशेषताएँ और परिशुद्धता होती है: short-float, single-float, double-float और long-float.

short-float उपप्रकार आम तौर पर चारों उपप्रकारों में सबसे कम मेमोरी लेता है और सबसे कम परिशुद्धता देता है। यह उन स्थितियों के लिए उपयुक्त है जहाँ मेमोरी की खपत चिंता का विषय हो, पर कम परिशुद्धता चल जाए।

single-float उपप्रकार मेमोरी की खपत और परिशुद्धता के बीच संतुलन बनाता है। इसका उपयोग आम तौर पर सामान्य फ्लोटिंग-पॉइंट गणनाओं के लिए किया जाता है।

double-float उपप्रकार single-float की तुलना में अधिक परिशुद्धता देता है और ऐसे अनुप्रयोगों के लिए उपयुक्त है जिनमें अधिक सटीक गणनाएँ चाहिए, जैसे वैज्ञानिक गणनाएँ और संख्यात्मक अनुकरण।

long-float उपप्रकार चारों उपप्रकारों में सबसे अधिक परिशुद्धता देता है, पर बाकी सब की तुलना में इसे अधिक मेमोरी की ज़रूरत पड़ सकती है। इसका उपयोग आम तौर पर ऐसे विशेष अनुप्रयोगों में होता है जिनमें बेहद सटीक गणनाएँ चाहिए।

ये उपप्रकार Common Lisp प्रोग्रामरों को मौका देते हैं कि वे अपने विशेष अनुप्रयोगों की ज़रूरतों के हिसाब से परिशुद्धता और मेमोरी की खपत का उपयुक्त स्तर चुन सकें।

सामान्य तौर पर, अगर आपको सिर्फ पूर्ण संख्याओं के साथ काम करना है, तो पूर्णांक चुनना बेहतर है, क्योंकि कई गणनाओं के दौरान फ्लोटिंग-पॉइंट संख्याओं में परिशुद्धता जिस तरह घटती है, पूर्णांकों में वैसी कमी नहीं आती।

## संदर्भ

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
