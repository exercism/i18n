# निर्देश

Elyse, जो आगे चलकर जादूगर बनने वाली है, अपनी ट्रेनिंग जारी रखती है।
उसे कई ताश की गड्डियाँ दी जाएँगी, जिनका इस्तेमाल करके उसे अपने करतब दिखाने हैं।
चीज़ों को थोड़ा आसान बनाने के लिए वह सिर्फ 1 से 10 तक के पत्ते इस्तेमाल करती है।
हर पत्ता उसके पास सिर्फ एक ही है, उसकी गड्डियों में कोई पत्ता दोहराया नहीं जाता।

इस अभ्यास में, ऐरे की सामग्री का विश्लेषण करने के लिए Julia की Base लाइब्रेरी के मेथड इस्तेमाल कीजिए।

## 1. पता कीजिए कि कोई पत्ता मौजूद है या नहीं

Elyse यह पता करना चाहती है कि गड्डी में कोई पत्ता मौजूद है या नहीं, यानी कि गड्डी में कोई खास संख्या है या नहीं।

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. किसी पत्ते की जगह ढूँढिए

Elyse यह जानना चाहती है कि गड्डी में किसी पत्ते की जगह (इंडेक्स) क्या है।
अगर पत्ता गड्डी में नहीं है, तो `nothing` लौटाइए।

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. पता कीजिए कि हर पत्ता सम है या नहीं

Elyse यह जानना चाहती है कि हर पत्ता सम है या नहीं, यानी कि गड्डी की हर संख्या सम है या नहीं।

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. जाँचिए कि गड्डी में विषम संख्या वाला कोई पत्ता है या नहीं

Elyse यह जानना चाहती है कि गड्डी में कोई विषम संख्या है या नहीं।

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. पहले सम पत्ते की जगह पता कीजिए

Elyse यह जानना चाहती है कि पहला सम पत्ता कहाँ है।
अगर गड्डी में कोई सम पत्ता नहीं है, तो `nothing` लौटाइए।

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. गड्डी से पहला विषम पत्ता निकालिए

Elyse यह जानना चाहती है कि पहले विषम पत्ते की वैल्यू क्या है।
अगर गड्डी में कोई विषम पत्ता नहीं है, तो `nothing` लौटाइए।

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
