# ऐरे का परिचय

Bash दो तरह के पैरामीटर देता है: "स्केलर" वैल्यू और ऐरे।
एक स्केलर वैल्यू स्ट्रिंग या संख्या हो सकती है; यह एक अकेली "चीज़" को दर्शाती है।

अधिकतर मामलों में आपके डेटा को रखने के लिए स्केलर वैल्यू ही काफी होती हैं।
लेकिन कभी-कभी आपको कई स्केलर वैल्यू एक साथ संग्रहीत करनी पड़ती हैं।
ऐसे में आप एक _ऐरे_ इस्तेमाल करते हैं।

ऐरे दो तरह के होते हैं:

* संख्यात्मक इंडेक्स वाले ऐरे एक पूर्णांक की को एक स्ट्रिंग वैल्यू से जोड़ते हैं।
  (दूसरी भाषाएँ इसे "list" या "sequence" कह सकती हैं।)
* असोसिएटिव ऐरे एक स्ट्रिंग की को एक स्ट्रिंग वैल्यू से जोड़ते हैं।
  (दूसरी भाषाएँ इसे "map" या "dictionary" कह सकती हैं।)

इस दस्तावेज़ के पहले कुछ भाग संख्यात्मक इंडेक्स वाले ऐरे के बारे में बताएँगे (आगे इन्हें सिर्फ "ऐरे" कहा जाएगा)।
असोसिएटिव ऐरे की जानकारी अंत में आएगी।

~~~~exercism/caution
Bash ऐरे _सिर्फ_ स्केलर वैल्यू ही संग्रहीत कर सकते हैं।
द्वि-आयामी ऐरे (ऐरे का ऐरे) बनाने की कोई सुविधा नहीं है।
~~~~

## ऐरे वेरिएबल घोषित करना और इनिशियलाइज़ करना

किसी वेरिएबल को गोल ब्रैकेट के बीच लिखी एलिमेंट की सूची (जो खाली भी हो सकती है) असाइन करके आप एक ऐरे इनिशियलाइज़ कर सकते हैं।

```bash
myarray=("one" "two" "three")
```

हर वेरिएबल असाइनमेंट की तरह, बराबर के चिह्न के दोनों ओर कोई स्पेस नहीं होना चाहिए।

ध्यान दीजिए कि एलिमेंट के बीच कोई कॉमा सेपरेटर नहीं होता; यह स्ट्रिंग की ऐसी सूची है जिसमें हर स्ट्रिंग को स्पेस से अलग किया जाता है।

वास्तव में, गोल ब्रैकेट के अंदर स्पेस कितना होगा, यह पूरी तरह आप पर निर्भर है।
नई लाइनें लगाना भी मान्य है; पढ़ने में आसानी के लिए जितनी चाहें लगाइए।

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

इस तरह किसी ऐरे वेरिएबल को स्ट्रिंग की सूची असाइन करने पर पहली स्ट्रिंग इंडेक्स शून्य पर, दूसरी इंडेक्स एक पर, तीसरी इंडेक्स दो पर, और इसी तरह संग्रहीत होती है।

आप जिन इंडेक्स की ज़रूरत है, उन्हें देकर "स्पार्स ऐरे" भी इनिशियलाइज़ कर सकते हैं।

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
दोबारा याद दिला दें: ऐरे के इंडेक्स शून्य से शुरू होते हैं।
इस स्निपेट का आउटपुट "true" है:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

यह बताने के लिए कि किसी वेरिएबल में एक ऐरे रहेगा, आप `declare` कमांड इस्तेमाल कर सकते हैं (या किसी फंक्शन के अंदर `local`)।

```bash
declare -a myarray
```

वेरिएबल को इनिशियलाइज़ करने का ज़्यादा स्वाभाविक तरीका यह है कि आप उसे सीधे गोल ब्रैकेट के बीच लिखी सूची (चाहे वह खाली हो) असाइन कर दें।

## ऐरे के एलिमेंट तक पहुँचना

जैसा कि आपने ऊपर वाले नोट में देखा, किसी ऐरे के एलिमेंट तक पहुँचने का सिंटैक्स `${myarray[$index]}` है।
इंडेक्स चौकोर ब्रैकेट में लिखा जाता है।
कर्ली ब्रैकेट लगाना ज़रूरी है।

~~~~exercism/note
संख्यात्मक इंडेक्स वाले ऐरे के लिए इंडेक्स एक अंकगणितीय एक्सप्रेशन होता है।
Bash मैनुअल [कहता है][arithmetic]:

> अंकगणितीय एक्सप्रेशन के अंदर, शेल वेरिएबल को पैरामीटर एक्सपैंशन सिंटैक्स इस्तेमाल किए बिना नाम से भी संदर्भित किया जा सकता है।

इसका मतलब है कि "साधारण" वेरिएबल एक्सपैंशन के लिए `$` ज़रूरी नहीं है।
इस तरह आप एलिमेंट तक पहुँच सकते हैं, जो पढ़ने में थोड़ा आसान है:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

अगर दिया गया इंडेक्स ऐरे में मौजूद नहीं है, तो एक्सपैंशन का परिणाम एक खाली स्ट्रिंग होता है।

## ऐरे में वैल्यू असाइन करना

किसी खास ऐरे एंट्री में वैल्यू असाइन करने के लिए यह सिंटैक्स इस्तेमाल कीजिए:

```bash
myarray[10]="hello"
```

किसी ऐरे में _जोड़ने_ के लिए `+=` कॉन्कैटिनेटिंग-असाइनमेंट ऑपरेटर इस्तेमाल कीजिए और गोल ब्रैकेट लगाइए:

```bash
myarray+=("new element 1" "new element 2")
```

## ऐरे पर इटरेशन करना

अधिकतर आपको ऐरे की _वैल्यू_ पर इटरेशन करना पड़ता है।
इसके लिए `for` लूप इस्तेमाल कीजिए (जिसे आपने [लूपिंग][looping] कॉन्सेप्ट में देखा था):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

ऐरे को एक्सपैंड करने का खास सिंटैक्स ध्यान से देखिए: `"${myarray[@]}"`
पैरामीटर एक्सपैंशन का यह रूप ऐरे की हर वैल्यू को अलग-अलग शब्द के रूप में रखता है।
यह कुछ-कुछ इसके बराबर है:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

`"${myarray[@]}"` रूप स्पार्स ऐरे के साथ भी काम करता है और सिर्फ परिभाषित वैल्यू को ही एक्सपैंड करता है।

यह खास एक्सपैंशन, जिसमें इंडेक्स ऐम्परसैंड (`@`) होता है, सिर्फ डबल कोट्स के अंदर ही खास माना जाता है।

#### अन्य खास पैरामीटर एक्सपैंशन

ऐरे पर इटरेशन करने के लिए हमें कुछ और खास सिंटैक्स की ज़रूरत पड़ती है।
इनका वर्णन मैनुअल में [Shell Parameter Expansion][man-expn] में मिलता है।

ऐरे की _लंबाई_ निकालने के लिए `${#myarray[@]}` इस्तेमाल कीजिए, जिसमें नाम से पहले `#` लगता है।
ऐरे की "लंबाई" का मतलब उसमें मौजूद एलिमेंट की संख्या है।

ऐरे के _इंडेक्स_ की सूची निकालने के लिए `"${!myarray[@]}"` इस्तेमाल कीजिए, जिसमें नाम से पहले `!` लगता है और एक्सपैंशन डबल कोट्स में रहता है।
संख्यात्मक इंडेक्स वाले ऐरे के लिए इंडेक्स संख्यात्मक क्रम में एक्सपैंड होते हैं।

### ऐरे के इंडेक्स पर इटरेशन करना

कभी-कभी आपको वैल्यू के साथ-साथ इंडेक्स की भी ज़रूरत होती है।
इसके लिए कुछ तरीके हैं।

1. जब आपको पता हो कि इंडेक्स एक लगातार क्रम बनाते हैं, तो आप _अंकगणितीय_ `for` लूप इस्तेमाल कर सकते हैं।

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   ध्यान दीजिए कि `${#myarray[@]}` सिंटैक्स में ऐरे के नाम से पहले `#` अक्षर आता है।
   चूँकि ऐरे शून्य से इंडेक्सिंग करते हैं, ऐरे का अंतिम इंडेक्स उसकी लंबाई से एक कम होता है।

2. जब ऐरे स्पार्स हो, तो आप यह रूप इस्तेमाल कर सकते हैं:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   ध्यान दीजिए कि `${!myarray[@]}` सिंटैक्स में ऐरे के नाम से पहले `!` अक्षर आता है।

## ऐरे की जाँच करना

अगर आप किसी ऐरे की सामग्री देखना चाहते हैं, तो `declare` कमांड के साथ `-p` ऑप्शन इस्तेमाल कीजिए:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

यह सामग्री को शेल की मानक कोटिंग के साथ आउटपुट करता है।

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## असोसिएटिव ऐरे

दोबारा याद दिला दें, असोसिएटिव ऐरे इंडेक्स के लिए संख्याओं की जगह स्ट्रिंग इस्तेमाल करते हैं।
ऊपर लिखी हर बात असोसिएटिव ऐरे पर भी लागू होती है, बस थोड़े अंतर के साथ।
आम तौर पर हम "इंडेक्स" की जगह "की" शब्द इस्तेमाल करते हैं: असोसिएटिव ऐरे की को वैल्यू से जोड़ते हैं।

### असोसिएटिव ऐरे घोषित करना

ऐरे के उलट, असोसिएटिव ऐरे को घोषित करना **ज़रूरी** होता है।
`declare` के साथ `-A` ऑप्शन इस्तेमाल कीजिए (या किसी फंक्शन में `local`):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### असोसिएटिव ऐरे इनिशियलाइज़ करना

की-वैल्यू जोड़े गोल ब्रैकेट वाली सूची के अंदर लिखे जाते हैं:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

यह आउटपुट देता है:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
ध्यान रखिए कि असोसिएटिव ऐरे **बिना क्रम** के होते हैं।
~~~~

घोषणा और इनिशियलाइज़ेशन एक ही लाइन में हो सकते हैं।

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Bash के नए वर्शनों में इनिशियलाइज़ेशन के लिए `(key value key value ...)` सूची इस्तेमाल की जा सकती है।

```bash
declare -A mymap=(first foo second bar third baz)
```

### वैल्यू तक पहुँचना

एलिमेंट तक पहुँचने के लिए पहले जैसा ही सिंटैक्स इस्तेमाल होता है: `${mymap[$key]}`।

असोसिएटिव ऐरे की को अंकगणितीय संदर्भ में मूल्यांकित नहीं किया जाता।
इसके लिए आम पैरामीटर एक्सपैंशन सिंटैक्स ही चाहिए।

### असोसिएटिव ऐरे में वैल्यू असाइन करना

असाइनमेंट में पहले जैसा ही सिंटैक्स इस्तेमाल होता है:

```bash
mymap[$key]="$value"
```

### इटरेशन करना

इटरेशन के लिए आप `for value in "${mymap[@]}"` लूप इस्तेमाल कर सकते हैं।
लेकिन आम तौर पर आप वैल्यू के साथ-साथ की भी चाहते हैं।

ऊपर देखा गया `"${!mymap[@]}"` सिंटैक्स इस्तेमाल कीजिए।

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

यह आउटपुट देता है

```
second -> bar
first -> foo
third -> baz
```

एक बार फिर ज़ोर देकर कहें, की का कोई क्रम नहीं होता।
