# परिचय

इंटरफेस को किसी क्लास का सिग्नेचर समझा जा सकता है, क्योंकि यह क्लास के सार्वजनिक फील्ड बताता है। कोई क्लास `implments` कीवर्ड की मदद से किसी `interface` को _लागू_ करती है।

इसका सिंटैक्स किसी क्लास के सिंटैक्स से काफी मिलता-जुलता है, बस फर्क यह है कि इसमें मेथड बिना बॉडी के, सिर्फ सिग्नेचर के रूप में दिखते हैं:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

किसी इंटरफेस से लागू किए गए फील्ड में हमेशा वही विज़िबिलिटी मॉडिफायर **अवश्य** इस्तेमाल होना चाहिए। उदाहरण के लिए, अगर किसी इंटरफेस में वेरिएबल `a` `public` है, तो उसे लागू करने वाली क्लास में भी `a` को `public` रखना होगा।
