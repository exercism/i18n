# निर्देश

इस अभ्यास में आप खेलों के बड़े प्रशंसक हैं और अभी-अभी आपको NBA बास्केटबॉल से लगाव हुआ है। NBA बास्केटबॉल में नए होने के कारण आप NBA के इतिहास में गहराई तक उतर रहे हैं, टीमों और कोचों का हिसाब रख रहे हैं, उनके जीत-हार के आँकड़े जुटा रहे हैं और उनकी आपस में तुलना कर रहे हैं।

चूँकि अभी आपकी कोई पसंदीदा टीम नहीं है, इसलिए आप एक एल्गोरिदम भी बनाएँगे जो यह तय करेगा कि किसी टीम का समर्थन करना चाहिए या नहीं।

अपना खुद का _टीम-समर्थन_ एल्गोरिदम बनाने में आपकी मदद करने के लिए आपके पास सात काम हैं।

## 1. मॉडल परिभाषित कीजिए

`Coach` रिकॉर्ड को इन दो फील्डों के साथ परिभाषित कीजिए:

- `name`: कोच का नाम, जिसका टाइप `String` है।
- `former_player`: बताता है कि कोच पहले खिलाड़ी था या नहीं, जिसका टाइप `Bool` है।

`Stats` रिकॉर्ड को इन दो फील्डों के साथ परिभाषित कीजिए:

- `wins`: जीतों की संख्या, जिसका टाइप `Int` है।
- `losses`: हारों की संख्या, जिसका टाइप `Int` है।

`Team` रिकॉर्ड को इन तीन फील्डों के साथ परिभाषित कीजिए:

- `name`: टीम का नाम, जिसका टाइप `String` है।
- `coach`: टीम का कोच, जिसका टाइप `Coach` है।
- `stats`: टीम के आँकड़े, जिसका टाइप `Stats` है।

## 2. टीम का कोच बनाइए

`create_coach` फंक्शन बनाइए, जो पैरामीटर के रूप में कोच का नाम और उसकी पूर्व-खिलाड़ी स्थिति लेता है और उसका `Coach` रिकॉर्ड लौटाता है:

```gleam
create_coach("Larry Bird", True)
// -> Coach(name: "Larry Bird", former_player: True)
```

## 3. टीम के आँकड़े बनाइए

`create_stats` फंक्शन बनाइए, जो पैरामीटर के रूप में जीतों की संख्या और हारों की संख्या लेता है और उसका `Stats` रिकॉर्ड लौटाता है:

```gleam
create_stats(58, 24)
// -> Stats(wins: 58, losses: 24)
```

## 4. टीम बनाइए

`create_team` फंक्शन बनाइए, जो पैरामीटर के रूप में टीम का नाम, कोच और रिकॉर्ड लेता है और उसका `Team` रिकॉर्ड लौटाता है:

```gleam
let coach = create_coach("Larry Bird", True)
let stats = create_stats(58, 24)
create_team("Indiana Pacers", coach, stats)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Larry Bird", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 5. कोच बदलिए

NBA के मालिक जल्दबाज़ होते हैं, और आपने पाया कि टीम के खराब नतीजों पर अक्सर कोच बदल दिया जाता है। `replace_coach` फंक्शन बनाइए, जो पैरामीटर के रूप में टीम और उसका नया कोच लेता है और टीम को नए कोच के साथ लौटाता है:

```gleam
let coach = create_coach("Larry Bird", True)
let record = create_stats(58, 24)
let team = create_team("Indiana Pacers", coach, record)

let new_coach = create_coach("Isiah Thomas", True)
replace_coach(team, new_coach)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Isiah Thomas", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 6. जाँचिए कि दोनों टीमें एक ही हैं

आँकड़े खंगालते समय आप टीमों और उनके रिकॉर्ड की सूचियाँ रख रहे हैं। कभी-कभी आपसे गलती हो जाती है और आपकी सूची में दोहराव आ जाते हैं। `is_same_team` फंक्शन बनाइए, जो दो टीमें लेता है और अगर वे एक ही टीम हैं तो `True` लौटाता है, वरना `False` लौटाता है:

```gleam
let pacers_coach = create_coach("Larry Bird", True)
let pacers_stats = create_stats(58, 24)
let pacers_team = create_team("Indiana Pacers", pacers_coach, pacers_stats)

let lakers_coach = create_coach("Del Harris", False)
let lakers_stats = create_stats(61, 21)
let lakers_team = create_team("LA Lakers", lakers_coach, lakers_stats)

is_same_team(pacers_team, lakers_team)
// -> False
```

## 7. जाँचिए कि आपको किसी टीम का समर्थन करना चाहिए या नहीं

बहुत सी टीमों और मैचों को देखने के बाद आपने एक एल्गोरिदम तैयार किया है। अगर इनमें से कोई एक बात सही हो, तो आप उस टीम का समर्थन करते हैं:

- कोच का नाम "Gregg Popovich" है
- कोच पहले खिलाड़ी रह चुका है
- टीम का नाम "Chicago Bulls" है
- टीम ने 60 या उससे अधिक मैच जीते हैं
- टीम की हार जीत से ज़्यादा है

`root_for_team` फंक्शन बनाइए, जो एक टीम लेता है और अगर आपको उस टीम का समर्थन करना चाहिए तो `True` लौटाता है, वरना `False` लौटाता है:

```gleam
let spurs_coach = create_coach("Gregg Popovich", False)
let spurs_stats = create_stats(56, 26)
let spurs_team = create_team("San Antonio Spurs", spurs_coach, spurs_stats)
root_for_team(spurs_team)
// -> True
```
