# निर्देश

इस अभ्यास में आप एक ब्यूटी सैलून के लिए अपॉइंटमेंट शेड्यूलर पर काम करेंगे।

इसमें आपको तीन काम करने हैं। तीनों में अपॉइंटमेंट की तारीखों से जुड़ा काम है।

## 1. जाँचिए कि अपॉइंटमेंट बीत चुका है या नहीं

`appointment_has_passed` सबरूटीन बनाइए, जो एक तारीख की स्ट्रिंग लेता है और जाँचता है कि अपॉइंटमेंट अतीत में कभी था या नहीं:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

तारीख की स्ट्रिंग ISO 8601 डेटटाइम फॉर्मैट में दी जाएगी: `YYYY-mm-ddTHH:MM:SS`

आपको निजी `_parse_datetime` सबरूटीन बनाना होगा।
आपके लिए दो मॉड्यूल सुझाए गए हैं:

- [Time::Piece][time-piece] Perl का एक कोर मॉड्यूल है।
- [DateTime::Tiny][datetime-tiny] CPAN से उपलब्ध है।

## 2. जाँचिए कि अपॉइंटमेंट दोपहर में है या नहीं

`is_afternoon_appointment` फंक्शन बनाइए, जो एक तारीख की स्ट्रिंग लेता है और जाँचता है कि अपॉइंटमेंट दोपहर में है या नहीं (>= 12:00 और < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. अपॉइंटमेंट का समय और तारीख बताइए

`describe_appointment` फंक्शन बनाइए, जो एक तारीख की स्ट्रिंग लेता है और उस तारीख और समय का विवरण लौटाता है:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

ध्यान दीजिए कि घंटा 0-12 की सीमा में होता है और उसके आगे कोई शून्य या खाली जगह नहीं लगती।
