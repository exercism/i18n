# निर्देश

आपके शहर में पिज़्ज़ा स्लाइस की कई दुकानें हैं और आप एक वेब ऐप बनाना चाहते हैं जिससे आप दो अलग-अलग पिज़्ज़ा सेटअप की तुलना कर सकें और पता लगा सकें कि आपको बड़ा स्लाइस कौन देगा।

## 1. स्लाइस का आकार निकालने वाला फंक्शन लिखिए जो अमान्य इनपुट पर nil लौटाए

फंक्शन `sliceSize(diameter: Double?, slices: Int?) -> Double?` को लागू कीजिए। यह फंक्शन पिज़्ज़ा का व्यास और पिज़्ज़ा में स्लाइस की संख्या लेकर एक स्लाइस का क्षेत्रफल लौटाता है।
ऋणात्मक व्यास और 1 से कम स्लाइस की संख्या के लिए `nil` लौटाइए, क्योंकि ऋणात्मक व्यास वाला पिज़्ज़ा जैसी कोई चीज़ नहीं होती और पिज़्ज़ा को 1 से कम स्लाइस में काटना संभव नहीं है।
अगर इनमें से कोई भी पैरामीटर `nil` हो, तो भी `nil` लौटाइए।

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. वेब ऐप से मिले इनपुट को संसाधित करके बड़ा स्लाइस तय कीजिए

आपका वेब ऐप आपके फंक्शन `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String` को चार स्ट्रिंग देगा।
पहली और दूसरी स्ट्रिंग क्रमशः पहले पिज़्ज़ा का व्यास और स्लाइस की संख्या हैं, और तीसरी और चौथी स्ट्रिंग क्रमशः दूसरे पिज़्ज़ा का व्यास और स्लाइस की संख्या हैं।

`biggestSlice` को ऐसे लागू कीजिए कि यह हर पिज़्ज़ा के व्यास और स्लाइस की संख्या को क्रमशः एक `Double` और एक `Int` में बदलने की कोशिश करे।
अगर ये दोनों वैल्यू स्ट्रिंग से निकाली जा सकें, तो अपने पहले फंक्शन से क्षेत्रफल निकालने की कोशिश कीजिए, वरना उस स्लाइस का क्षेत्रफल `nil` होगा।
दोनों स्लाइस का क्षेत्रफल मिल जाने के बाद इन नियमों से दोनों की तुलना कीजिए:

1. अगर स्लाइस A का क्षेत्रफल एक `Double` है और स्लाइस B का `nil` है, तो "Slice A is bigger" लौटाइए। अगर इसका उल्टा सच हो, तो "Slice B is bigger" लौटाइए।
2. अगर दोनों क्षेत्रफल `Double`s हैं, तो जिस स्लाइस का क्षेत्रफल ज़्यादा है उसके अनुसार "Slice A is bigger" या "Slice B is bigger" लौटाइए।
3. अगर दोनों क्षेत्रफल `nil` हैं, या दोनों `Double`s हैं और बराबर हैं, तो "Neither slice is bigger" लौटाइए।

~~~~exercism/note
अगर इनपुट से स्लाइस का क्षेत्रफल 0 आता है, तब भी वह स्लाइस मान्य माना जाता है, और उसे `nil` क्षेत्रफल वाले स्लाइस से बड़ा माना जाना चाहिए।
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
