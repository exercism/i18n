# टेस्ट

अगर आपने CLI टूल से कोई अभ्यास डाउनलोड किया है, तो आपको अभ्यास के नाम वाली एक Uiua फाइल और एक `tests.ua` फाइल दिखनी चाहिए।
इस फाइल में सारे टेस्ट केस होते हैं। जब आप अपना हल अपलोड करते हैं, तो टेस्ट रनर भी यही टेस्ट केस चलाता है।
प्रयोग करने के लिए आप चाहें तो और टेस्ट केस जोड़ सकते हैं।
लेकिन टेस्ट बदलने से ऑनलाइन टेस्ट रनर की प्रक्रिया पर कोई असर नहीं पड़ता।

## स्थानीय टेस्टिंग

किसी अभ्यास के टेस्ट चलाने के लिए अभ्यास की डायरेक्टरी में एक टर्मिनल खोलिए और `uiua test tests.ua` कमांड चलाइए।

उदाहरण के लिए, बिना बदले गए `hello-world` अभ्यास का आउटपुट कुछ ऐसा दिख सकता है:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

`Error` लाइन आपके कोड का वास्तविक आउटपुट दिखाती है।
लाइन नंबर बताता है कि `tests.ua` में अपेक्षित परिणाम कहाँ है।
सही हल से यह मिलता है:

```bash
$ uiua test tests.ua
Test passed
```
