# निर्देशों का परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग | टाइप | विवरण |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0` | इनपुट | पूर्णांक | भुजा a |
| `$a1` | इनपुट | पूर्णांक | भुजा b |
| `$a2` | इनपुट | पूर्णांक | भुजा c |
| `$v0` | आउटपुट | पूर्णांक | त्रिभुज का प्रकार (`0` = विषमबाहु, `1` = समद्विबाहु, `2` = समबाहु, `3` = अमान्य) |
| `$t0-9` | अस्थायी | कोई भी | अस्थायी भंडारण के लिए उपयोग होता है |
