# निर्देश

भावी जादूगर एलिस अपना प्रशिक्षण जारी रखती है। उसे पत्तों के कई ढेर दिए जाएँगे, जिनका इस्तेमाल करके उसे अपने करतब दिखाने हैं। चीज़ें थोड़ी आसान करने के लिए वह सिर्फ 1 से 10 तक के पत्ते इस्तेमाल करती है।

इस अभ्यास में ऐरे के अंदर की चीज़ों का विश्लेषण करने के लिए बिल्ट-इन मेथड इस्तेमाल कीजिए।

## 1. पत्ते की जगह पता कीजिए

एलिस जानना चाहती है कि ढेर में किसी पत्ते की जगह (इंडेक्स) क्या है।

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. पता कीजिए कि कोई पत्ता मौजूद है या नहीं

एलिस जानना चाहती है कि ढेर में कोई पत्ता मौजूद है या नहीं, यानी यह कि ढेर में कोई खास `number` है या नहीं।

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. पता कीजिए कि हर पत्ता सम है या नहीं

एलिस जानना चाहती है कि हर पत्ता सम है या नहीं, यानी यह कि ढेर में मौजूद हर संख्या एक सम `number` है या नहीं।

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. जाँचिए कि ढेर में विषम वैल्यू वाला पत्ता है या नहीं

एलिस जानना चाहती है कि ढेर में कोई विषम संख्या है या नहीं।

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. ढेर से पहला विषम पत्ता निकालिए

एलिस जानना चाहती है कि जो पहला पत्ता विषम है उसकी वैल्यू क्या है।

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. पहले सम पत्ते की जगह पता कीजिए

एलिस जानना चाहती है कि जो पहला पत्ता सम है उसकी जगह क्या है।

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
