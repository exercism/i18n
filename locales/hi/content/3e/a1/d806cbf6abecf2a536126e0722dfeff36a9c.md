# परिचय

C# में `string` एक ऑब्जेक्ट है जो अपरिवर्तनीय टेक्स्ट को यूनिकोड अक्षरों (अक्षर, अंक, विराम चिह्न आदि) के क्रम के रूप में दर्शाता है। किसी `string` इंस्टेंस को बनाने के लिए दोहरे उद्धरण चिह्नों का उपयोग किया जाता है:

```csharp
string fruit = "Apple";
```

स्ट्रिंग पर काम उसके मेथड कॉल करके किया जाता है। एक बार स्ट्रिंग बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती। जो मेथड स्ट्रिंग को बदलते दिखते हैं, वे वास्तव में एक नई स्ट्रिंग लौटाते हैं।

कई स्ट्रिंग को आपस में जोड़ा जा सकता है। ऐसा करने का सबसे आसान तरीका `+` ऑपरेटर का उपयोग करना है।

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

साधारण जोड़ने से अधिक जटिल किसी भी स्ट्रिंग फॉर्मैटिंग के लिए स्ट्रिंग इंटरपोलेशन बेहतर है। किसी स्ट्रिंग में इंटरपोलेशन का उपयोग करने के लिए उससे पहले डॉलर (`$`) चिह्न लगाइए। फिर आप अपनी स्ट्रिंग के अंदर किसी भी वेरिएबल तक पहुँचने के लिए घुंघराले ब्रैकेट (`{}`) का उपयोग कर सकते हैं।

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
