# डीस्ट्रक्चरिंग

डीस्ट्रक्चरिंग वह प्रक्रिया है जिसमें किसी चीज़ को उसके घटक भागों में तोड़ा जाता है और हर भाग को एक छोटे वेरिएबल से जोड़ा जाता है।

## टपल का डीस्ट्रक्चरिंग

टपल का डीस्ट्रक्चरिंग आसान है: बस टपल के हर फील्ड को एक नया वेरिएबल नाम असाइन कर दीजिए:

```rust
let (first, second) = (1, 2);
```

## टपल स्ट्रक्ट का डीस्ट्रक्चरिंग

टपल स्ट्रक्ट का डीस्ट्रक्चरिंग टपल के डीस्ट्रक्चरिंग जैसा ही है, बस इसमें स्ट्रक्ट का नाम भी जोड़ा जाता है:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## स्ट्रक्ट का डीस्ट्रक्चरिंग

स्ट्रक्ट का डीस्ट्रक्चरिंग टपल स्ट्रक्ट के डीस्ट्रक्चरिंग जैसा ही होता है। बस फील्ड के नाम इस्तेमाल कीजिए:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## आंशिक डीस्ट्रक्चरिंग

डीस्ट्रक्चरिंग करते समय कुछ फील्ड छोड़ने के लिए `..` ऑपरेटर इस्तेमाल किया जा सकता है:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## सशर्त डीस्ट्रक्चरिंग

स्ट्रक्ट और टपल का डीस्ट्रक्चरिंग हमेशा सफल होता है। हालाँकि, `if let`, `while let` और `match` जैसी भाषा की सुविधाओं का उपयोग करके एनम का भी डीस्ट्रक्चरिंग किया जा सकता है।

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
