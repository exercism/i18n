# परिचय

*टपल* Factor का रिकॉर्ड/स्ट्रक्ट/क्लास टाइप है। हर टपल क्लास में नाम वाले स्लॉट का एक निश्चित समूह होता है, और Factor इनके लिए गेटर तथा सेटर अपने आप बना देता है।

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` (यानी "आर्गुमेंट के क्रम में") स्टैक से स्लॉट भरता है, घोषणा के क्रम में। `new` एक इंस्टेंस बनाता है जिसमें हर स्लॉट की वैल्यू उसकी घोषित `initial:` वैल्यू पर होती है (या `f`, अगर कोई न दी गई हो)।

हर स्लॉट का गेटर `slot>>` है और सेटर `>>slot` है। सेटर स्लॉट की वैल्यू *बदल देता है*, इसलिए अगर आपको ऐसा अपडेट चाहिए जो मूल को न बदले, तो पहले `clone` कीजिए:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

स्लॉट की डिफ़ॉल्ट वैल्यू देने के लिए `{ name initial: value }` लिखा जाता है; `initial:` न देने पर डिफ़ॉल्ट `f` होती है।
