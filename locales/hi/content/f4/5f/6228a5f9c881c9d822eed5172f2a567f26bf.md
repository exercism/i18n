# परिचय

Factor के एसोसिएटिव ऐरे (हैशटेबल और उनके जैसी चीज़ें) [`assocs`][assocs] से एक साझा [प्रोटोकॉल][assoc-protocol] लेते हैं। हैशटेबल का लिटरल `H{ }` है:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

अक्सर इस्तेमाल होने वाले ऑपरेशन:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

हैशटेबल *परिवर्तनीय* होते हैं। `H{ }` लिटरल को बदलने से पहले उसे `clone` कीजिए, ताकि वह लिटरल अलग-अलग कॉल के बीच साझा न हो।

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
