# Visual Basic सीखना

## वेबसाइट

Visual Basic पिछले कई सालों में काफी बदल चुका है, और कई बाहरी ट्यूटोरियल पुराने टूल या फीचर की बात करते हैं।
[Visual Basic का आधिकारिक डॉक्युमेंटेशन](https://learn.microsoft.com/en-us/dotnet/visual-basic/) सबसे नया और भरोसेमंद स्रोत है, और सीखना यहीं से शुरू कीजिए।

## .NET का इकोसिस्टम

Visual Basic .NET रनटाइम पर चलता है और C# तथा F# के साथ बहुत-सी मुख्य सुविधाएँ साझा करता है।
इसलिए यह समझना कि .NET कैसे काम करता है, आपको एक बेहतर VB डेवलपर बनाएगा।
