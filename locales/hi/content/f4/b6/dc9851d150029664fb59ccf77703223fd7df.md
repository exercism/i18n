# कर्नेल फॉर्मेट

`format` मेथड के अलावा, Ruby में स्ट्रिंग बनाने का एक आम तरीका [स्ट्रिंग इंटरपोलेशन](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) का उपयोग करना है। उदाहरण के लिए:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
