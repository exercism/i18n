# मदद

अगर आपको कोई दिक्कत आए, तो मदद लेने के लिए नीचे कुछ संसाधन दिए गए हैं:

- [PSF](https://www.python.org) Python के डाउनलोड, डॉक्युमेंटेशन और कम्युनिटी संसाधन उपलब्ध कराता है।
- [Python कम्युनिटी फोरम](https://discuss.python.org/) पर मदद, PEP पर चर्चा, Python के मुख्य कमिटर और बहुत कुछ मिलता है।
- [Discord पर Exercism कम्युनिटी](https://exercism.org/r/discord)
- [Exercism कम्युनिटी के चर्चा फोरम](https://forum.exercsim.org)
- [Discord पर Python कम्युनिटी](https://pythondiscord.com/) बहुत मददगार है और वहाँ लोग काफी सक्रिय रहते हैं।
- [/r/learnpython/](https://www.reddit.com/r/learnpython/) Python सीखने वालों के लिए बना एक सबरेडिट है।
- [#python, Libera.chat पर](https://www.python.org/community/irc/) इस भाषा के मुख्य डेवलपर यहीं जमा होते हैं और अपना काम निपटाते हैं।
- [Free Code Camp कम्युनिटी फोरम](https://forum.freecodecamp.org/)
- [Pythontutor](http://pythontutor.com/) छोटे कोड स्निपेट को आँखों के सामने कदम-दर-कदम चलाकर देखने के लिए।

इसके अलावा, [StackOverflow](http://stackoverflow.com/questions/tagged/python) आपकी समस्या या सवाल को खोजने के लिए अच्छी जगह है, ताकि आप देख सकें कि उसका जवाब पहले ही दिया जा चुका है या नहीं।
 अगर नहीं, तो आप हमेशा अपना सवाल [पूछ](https://stackoverflow.com/help/how-to-ask) सकते हैं या किसी और के सवाल का [जवाब दे](https://stackoverflow.com/help/how-to-answer) सकते हैं।
