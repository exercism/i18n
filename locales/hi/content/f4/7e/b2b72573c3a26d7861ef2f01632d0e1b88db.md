# निर्देश

सर्कस में सुरक्षा जाँच पास होने तक कोई भी ट्रैपीज़ पर नहीं चढ़ता। आप इन जाँचों को लिखकर दर्ज कर रहे हैं ताकि सब पर एक ही नियम लागू हो।

पाँचों काम `SAFETY_CHECK` क्लास में जाएँगे।

## 1. क्या चटाई तैयार है?

चटाई तभी तैयार मानी जाती है जब वह बिछी भी हो और साफ़ भी हो।

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. क्या नीचे उतरने के लिए कुछ है?

नीचे चटाई होनी चाहिए या नीचे जाल होना चाहिए। दोनों में से कोई एक होना काफी है, और अगर दोनों हों तो भी कोई दिक्कत नहीं।

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. किसे अभी भी ब्रीफिंग की ज़रूरत है?

जिसे अभी तक ब्रीफिंग नहीं मिली है, उसे ब्रीफिंग की ज़रूरत है।

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. क्या इस कलाकार की उम्र काफी है?

ट्रैपीज़ 13 साल और उससे बड़े कलाकारों के लिए है।

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. सब कुछ एक साथ जोड़िए

किसी कलाकार को ट्रैपीज़ के लिए तभी मंज़ूरी मिलती है जब वह उम्र में काफी बड़ा हो, उसे ब्रीफिंग मिल चुकी हो, और चटाई तैयार हो।

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

चारों आर्गुमेंट हैं: उम्र, ब्रीफिंग मिली है या नहीं, चटाई बिछी है या नहीं, और चटाई साफ़ है या नहीं।
