# निर्देश परिशिष्ट

## Python ट्रैक पर यह अभ्यास किस तरह बनाया गया है

इस अभ्यास के टेस्ट चाहते हैं कि आपका प्रोग्राम एक Garden [`class`][classes in python] के रूप में लिखा जाए (_देखिए [concept:python/classes]() भी_)। अगर आप Python की क्लासों से परिचित नहीं हैं, तो यह [Real Python ट्यूटोरियल][how-to-make-a-class] शुरुआत करने की एक और अच्छी जगह हो सकती है।

आपकी `class` में `plants` नाम का एक [`method`][methods] होना चाहिए, जो आर्गुमेंट के रूप में एक छात्र का नाम लेता है और उस छात्र से जुड़े पौधों के नामों की `list` लौटाता है।


## कंस्ट्रक्टर

उदाहरण वाला गार्डन बनाना:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

टेस्ट में इसे `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")` के रूप में दर्शाया जाएगा।

इस तरह दर्शाने के लिए आपकी `class` को एक [`__init__()`][init] [स्पेशल मेथड][special-methods] बनाना होगा।
अगर आप `__init__()` या [_कंस्ट्रक्टर_][what-is-a-constructor] से परिचित नहीं हैं, तो Python के डॉक्स में [क्लास और इंस्टेंस ऑब्जेक्ट][class vs instance objects in python] पर विस्तार से समझाया गया है।


## डिफाल्ट पैरामीटर

कुछ टेस्ट में `__init__()` को आर्गुमेंट के रूप में छात्रों की एक `list` दी जाती है।
इससे समस्या विवरण में दी गई बारह छात्रों की सूची बदल जानी चाहिए।
ये दोनों स्टेटमेंट आपके `__init__()` मेथड के साथ काम करने चाहिए:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

एक तरीका यह है कि छात्रों की `list` को [डिफाल्ट आर्गुमेंट][default argument values] बना दिया जाए; Python के डॉक्स [फंक्शन की परिभाषा][function definitions] समझाते हुए `default parameters` के बारे में विस्तार से बताते हैं।
