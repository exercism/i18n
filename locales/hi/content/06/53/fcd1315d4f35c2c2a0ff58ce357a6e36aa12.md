लेकिन चीज़ें कुछ बिखरी हुई हैं। Azara के निर्देशांक Rui के निर्देशांकों से अलग ढंग से लिखे और अलग क्रम में लगे हुए लगते हैं। कौन-सा खजाना किस स्थान के साथ जाता है, यह पता करने के लिए उन्हें बार-बार एक सूची से दूसरी सूची देखनी पड़ती है।
वे दोनों नए-नए fsharpie हैं, इसलिए अपनी खोज की जानकारी को बेहतर ढंग से व्यवस्थित करने वाला एक छोटा प्रोग्राम (वास्तव में कुछ फंक्शन) लिखने में मदद के लिए वे आपके पास आए हैं।

## 1. निर्देशांक निकालिए

`getCooordinate()` फंक्शन बनाइए, जो Azara की सूची से एक `(treasure, coordinate)` जोड़ी लेता है और सिर्फ नक्शे का निकाला गया निर्देशांक लौटाता है।

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. निर्देशांक का फॉर्मेट बदलिए

`convertCoordinate()` फंक्शन बनाइए, जो "2A" फॉर्मेट का एक निर्देशांक लेता है और `(2, 'A')` फॉर्मेट का टपल लौटाता है।

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. निर्देशांकों की तुलना कीजिए

`compareRecords()` फंक्शन बनाइए, जो एक `(treasure, coordinate)` जोड़ी और एक `(location, coordinate, quadrant)` रिकॉर्ड लेता है और दोनों के निर्देशांकों की तुलना करता है।
अगर निर्देशांक "मेल खाते" हैं तो **`true`** लौटाइए, और अगर नहीं मेल खाते तो **`false`** लौटाइए।
सही तुलना के लिए निर्देशांकों का फॉर्मेट ज़रूरत के अनुसार बदल लीजिए।

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. मेल खाने वाले रिकॉर्ड जोड़िए

`createrecord()` फंक्शन बनाइए, जो Azara की सूची से एक `(treasure, coordinate)` जोड़ी और Rui की सूची से एक `(location, coordinate, quadrant)` रिकॉर्ड लेता है, और **अगर निर्देशांक मेल खाते हैं** तो `(coordinate, location, quadrant, treasure)` लौटाता है।
अगर निर्देशांक मेल _नहीं_ खाते, तो उसी आकार का टपल लौटाइए, जिसमें हर जगह `""` हो।
सही तुलना के लिए निर्देशांकों का फॉर्मेट ज़रूरत के अनुसार बदल लीजिए।

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
