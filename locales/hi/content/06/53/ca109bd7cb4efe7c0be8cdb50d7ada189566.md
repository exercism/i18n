# निर्देश

सामान्य संख्याओं को [क्रमसूचक संख्याओं](https://en.wikipedia.org/wiki/Ordinal_numeral) में बदलने के लिए एक फंक्शन लिखिए। शून्य (0) के लिए बस "0" को स्ट्रिंग के रूप में लौटाइए।

क्रमसूचक संख्याएँ वे संख्याएँ होती हैं जो किसी सूची में किसी चीज़ की स्थिति बताती हैं। यहाँ क्रमसूचक संख्या का वही रूप इस्तेमाल किया जाएगा जो अंग्रेज़ी में लिखा जाता है।

क्रमसूचक संख्याएँ ये हैं (कम से कम, उनका एक रूप):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

यानी कोई सामान्य संख्या डालने पर उसका क्रमसूचक रूप मिलता है:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
