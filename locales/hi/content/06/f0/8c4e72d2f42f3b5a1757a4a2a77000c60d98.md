# परिचय

**रेगुलर एक्सप्रेशन** (रेगेक्स) अक्षरों के ऐसे क्रम हैं जो टेक्स्ट में खोज का पैटर्न तय करते हैं।

रेगुलर एक्सप्रेशन का सिंटैक्स सीखना इस विषय के दायरे से बाहर है।
हम यहाँ उन एक्सप्रेशनों पर ध्यान देंगे जो `jq` रेगेक्स इस्तेमाल करने के लिए उपलब्ध कराता है।

## रेगेक्स के रूप

अलग-अलग टूल, रेगुलर एक्सप्रेशन के अलग-अलग रूप लागू करते हैं।
`jq` में [Oniguruma][oniguruma] रेगेक्स लाइब्रेरी शामिल है, जो Perl v5.8 के रेगेक्स से काफी हद तक संगत है।

`jq` जो खास सिंटैक्स इस्तेमाल करता है, वह [Oniguruma के GitHub रेपो पर मिल सकता है][onig-syntax]।

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` में रेगुलर एक्सप्रेशन के लिए कोई खास सिंटैक्स नहीं है।
इन्हें बस स्ट्रिंग के रूप में लिखा जाता है।
इसका मतलब है कि रेगुलर एक्सप्रेशन में जो भी बैकस्लैश हों, उन्हें स्ट्रिंग में एस्केप करना पड़ता है।

उदाहरण के लिए, अंकों की कैरेक्टर क्लास (`\d`) को `"\\d"` लिखना ज़रूरी है।
~~~~

<!-- prettier-ignore-end -->

## रेगेक्स फंक्शन

`jq` में रेगुलर एक्सप्रेशन [कुछ खास फिल्टरों तक ही सीमित हैं][jq-regex-funcs]।

### साधारण मिलान

जब आपको यह जानना हो कि कोई स्ट्रिंग किसी पैटर्न से मेल खाती है या नहीं, तो `test` फिल्टर इस्तेमाल कीजिए।

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

यह फिल्टर _बूलियन_ परिणाम देता है।

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### मैच की जानकारी

जब आपको वह सबस्ट्रिंग निकालनी हो जो वास्तव में पैटर्न से मेल खाती है, तो `match` फिल्टर इस्तेमाल कीजिए।

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

यह फिल्टर देता है:

- अगर कोई मैच नहीं मिला, तो कुछ नहीं, या
- अगर मैच मिला, तो कई प्रॉपर्टी वाला एक ऑब्जेक्ट।

यह उदाहरण बैकरेफ सिंटैक्स `\1` का इस्तेमाल करके दो एक जैसे लगातार स्वर ढूँढता है।

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match` फिल्टर _हर_ मैच के लिए एक ऑब्जेक्ट लौटाता है।
यह उदाहरण `"g"` फ्लैग को काम करते हुए दिखाता है, जो सारे स्वर ढूँढता है।

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### कैप्चर की गई सबस्ट्रिंग

`match` फिल्टर की तरह ही, `capture` फिल्टर भी मैच मिलने पर एक ऑब्जेक्ट लौटाता है।

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

लौटाया गया ऑब्जेक्ट **नामित कैप्चर** की मैपिंग होती है।

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### सिर्फ सबस्ट्रिंग

`scan` फिल्टर `"g"` फ्लैग वाले `match` जैसा ही है।

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` सबस्ट्रिंग की एक _स्ट्रीम_ देता है।

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

सबस्ट्रिंग इकट्ठा करने के लिए `[...]` ऐरे कंस्ट्रक्टर इस्तेमाल कीजिए।

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### स्ट्रिंग को तोड़ना

अगर आपको पता है कि स्ट्रिंग के कौन-से हिस्से आप **रखना** चाहते हैं, तो `match` या `scan` इस्तेमाल कीजिए।
अगर आपको पता है कि कौन-से हिस्से आप **हटाना** चाहते हैं, तो `split` इस्तेमाल कीजिए।

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
**एक आर्गुमेंट वाला** `split` फिल्टर अपने आर्गुमेंट को एक **तय स्ट्रिंग** मानता है।

`split` के साथ रेगेक्स इस्तेमाल करने के लिए आपको दूसरा आर्गुमेंट देना **ज़रूरी** है; खाली स्ट्रिंग देना ठीक है।
~~~~

<!-- prettier-ignore-end -->

यहाँ एक उदाहरण है जो स्ट्रिंग को किसी भी व्हाइटस्पेस पर तोड़ता है।

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### प्रतिस्थापन

`sub` और `gsub` फिल्टर इनपुट स्ट्रिंग को बदल सकते हैं: ये इनपुट के जिन हिस्सों से मैच हुआ है, उन्हें रिप्लेसमेंट स्ट्रिंग से बदल देते हैं।

सिर्फ पहला मैच बदलने के लिए `sub` इस्तेमाल कीजिए।
सारे मैच बदलने के लिए `gsub` इस्तेमाल कीजिए।

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

रिप्लेसमेंट टेक्स्ट में मैच हुई सबस्ट्रिंग का इस्तेमाल किया जा सकता है; इसके लिए नामित कैप्चर और [स्ट्रिंग इंटरपोलेशन][jq-interp] इस्तेमाल कीजिए।

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## फ्लैग

ऊपर के सभी फिल्टरों में FLAGS एक स्ट्रिंग है, जो समर्थित फ्लैग में से शून्य या अधिक फ्लैग से बनी होती है।

- `g` - वैश्विक खोज (सिर्फ पहला नहीं, सारे मैच ढूँढता है)
- `i` - छोटे-बड़े अक्षरों में फर्क न करने वाली खोज
- `m` - मल्टी लाइन मोड ('.' न्यूलाइन से भी मेल खाएगा)
- `n` - खाली मैच अनदेखा करता है
- `p` - s और m, दोनों मोड चालू रहते हैं
- `s` - सिंगल लाइन मोड ('^' -> '\A', '$' -> '\Z')
- `l` - सबसे लंबे संभव मैच ढूँढता है
- `x` - एक्सटेंडेड रेगेक्स फॉर्मैट (व्हाइटस्पेस और कमेंट अनदेखा करता है)

उदाहरण के लिए

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
