# परिचय

जो टाइप `IEnumerable<T>` इंटरफेस को लागू करते हैं, उन्हें _एन्यूमरेबल_ कहा जाता है। सभी बिल्ट-इन कलेक्शन टाइप इस इंटरफेस को लागू करते हैं।

किसी एन्यूमरेबल टाइप पर `foreach` लूप की मदद से इटरेशन किया जा सकता है:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>` को लागू करने के लिए टाइप को एक मेथड लागू करना होता है: `IEnumerator<T> GetEnumerator()`। जैसा कि हमने देखा, एन्यूमरेबल कलेक्शन पर असली इटरेशन का काम `IEnumerator<T>` टाइप को सौंप देता है। इस इंटरफेस में एक प्रॉपर्टी और तीन मेथड लागू करने होते हैं:

- `public T Current { get; }`: वर्तमान एलिमेंट देता है।
- `public bool MoveNext ();`: अगले एलिमेंट पर ले जाता है। अगर अगले एलिमेंट पर जाना सफल रहा तो `true` लौटाता है, और अगर नहीं (और कोई एलिमेंट नहीं बचा) तो `false` लौटाता है।
- `public void Reset ();`: एन्यूमरेटर को फिर से उसकी शुरुआती स्थिति में (पहले एलिमेंट से पहले) ले जाता है।
