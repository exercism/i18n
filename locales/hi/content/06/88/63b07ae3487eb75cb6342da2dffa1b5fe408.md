# निर्देश

f(x) = ax^3 + bx^2 + cx + d के रूप वाले एक बहुपद फंक्शन पर विचार कीजिए। स्थानीय न्यूनतम को इस तरह परिभाषित किया जाता है: f(x) < f(x - delta) और f(x) < f(x + delta). इस परिभाषा का इस्तेमाल करके स्थानीय न्यूनतम के लिए एक व्यंजक निकालिए। साथ ही दिए गए गुणांकों (a, b, c, d) के लिए स्थानीय न्यूनतम ज्ञात कीजिए। ये गुणांक ऐसा फंक्शन बताएँगे जिसमें कम से कम एक न्यूनतम होगा। जहाँ न्यूनतम आता है, वहाँ का x निर्देशांक लौटाइए।
