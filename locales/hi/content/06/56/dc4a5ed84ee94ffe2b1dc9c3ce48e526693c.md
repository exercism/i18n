# परिचय

PHP अंकगणितीय संक्रियाएँ करने के लिए कई ऑपरेटर देता है। अपने अंकगणितीय ऑपरेटरों के लिए PHP गणित की संक्रियाओं के मानक क्रम का पालन करता है। PHP जो ऑपरेटर देता है, वे ये हैं:

* आइडेंटिटी (+)
* निगेशन (-)
* जोड़ (+)
* घटाव (-)
* गुणा (*)
* भाग (/)
* मॉड्यूलो (%)
* घातांकन (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
