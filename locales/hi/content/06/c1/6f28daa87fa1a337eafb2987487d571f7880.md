# परिचय

शर्त वाले एक्सप्रेशन कोड को इस आधार पर चलाते हैं कि **if** की शर्त **सही** है या **गलत**। ये एक्सप्रेशन ऐसे लिखे जाते हैं:

```haxe
if (condition) {
  expressions
};
```

शर्त का आउटपुट `Bool` टाइप का होता है, इसलिए जब आउटपुट `true` होता है, तब ये एक्सप्रेशन चलाए जाते हैं।

कभी-कभी ऐसा होता है कि शर्त वास्तव में `false` होती है, लेकिन हम चाहते हैं कि कोड का कोई और हिस्सा चले। ऐसे मौकों के लिए `else` एक्सप्रेशन है। जब शुरुआत वाली शर्त `false` होती है, तब `else` अपने एक्सप्रेशन चलाता है। लेकिन क्या हो अगर हमें एक से अधिक संभावनाओं के लिए शर्त जाँचनी हो? तब हम `else if (condition)` इस्तेमाल करते हैं। यहाँ एक पूरा उदाहरण दिया गया है:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
