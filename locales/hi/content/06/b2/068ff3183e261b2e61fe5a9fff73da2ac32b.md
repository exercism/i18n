# If, Elseif, Else

`if`, `elseif` और `else` का उपयोग करने वाले शर्त वाले स्टेटमेंट प्रोग्राम के कंट्रोल फ्लो का एक बुनियादी हिस्सा हैं।
`if` स्टेटमेंट एक एक्सप्रेशन का मूल्यांकन करता है, और अगर वह `true` है, तो कोड का वह हिस्सा चला देता है।

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

अगर एक्सप्रेशन बूलियन वैल्यू नहीं है, तो मूल्यांकन यह तय करता है कि वह वैल्यू सही मानी जाएगी या गलत नहीं।
PHP में, नीचे दी गई वैल्यू गलत के बराबर मानी जाती हैं:

- बूलियन `false`
- पूर्णांक `0`
- दशमलव संख्या `0.0` और `-0.0`
- एक खाली ऐरे `[]`
- एक खाली स्ट्रिंग `""` या एक संख्यात्मक स्ट्रिंग `"0"`
- `null`

बाकी सभी वैल्यू सही मानी जाती हैं।

## कई शर्तों को संभालना

`if` स्टेटमेंट के बाद आप `elseif` और `else` की मदद से कई शर्तें एक के बाद एक जोड़ सकते हैं।

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

सही निकलने वाला सिर्फ एक ही शर्त वाला स्टेटमेंट चलेगा।
इसलिए अगर कई शर्तें सही निकल सकती हैं, तो उन्हें किस क्रम में लिखा गया है, यह ज़रूरी हो जाता है।

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
