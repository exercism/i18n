# परिचय

**Map** एक डेटा स्ट्रक्चर है जो की-वैल्यू जोड़े संग्रहीत करता है।
यह दूसरी प्रोग्रामिंग भाषाओं की डिक्शनरी जैसा होता है।
[Map][map-javadoc] इंटरफ़ेस Map पर होने वाले ऑपरेशन परिभाषित करता है।

Java में Map के कई अलग-अलग इम्प्लीमेंटेशन मौजूद हैं।
इनमें [HashMap][hashmap-javadoc] का इस्तेमाल बहुत आम है।

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

[put][map-put-javadoc] की मदद से Map में एंट्रियाँ जोड़िए।

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

हर की के साथ सिर्फ एक ही वैल्यू जुड़ी हो सकती है।
एक ही की के साथ `put` कॉल करने पर उस की की वैल्यू बदल जाती है।

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

किसी की की वैल्यू पाने के लिए [get][map-get-javadoc] का इस्तेमाल कीजिए।

```java
fruitPrices.get("apple"); // => 100
```

यह देखने के लिए कि Map में कोई खास की मौजूद है या नहीं, [containsKey][map-containskey-javadoc] का इस्तेमाल कीजिए।

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

[remove][map-remove-javadoc] से एंट्रियाँ हटाइए।

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc] मेथड एंट्रियों की संख्या लौटाता है।

```java
fruitPrices.size();  // Returns 2
```

[keySet][map-keyset-javadoc] या [values][map-values-javadoc] मेथड की मदद से आप Map की सारी की या सारी वैल्यू पा सकते हैं, जो क्रमशः एक Set या Collection के रूप में मिलती हैं।

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
