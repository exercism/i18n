# परिचय

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) किसी डिक्लेरेशन को सजाने का एक तरीका देता है, जिससे उसके साथ मेटाडेटा जुड़ जाता है। यह डिक्लेरेशन क्लास, मेथड, एनम, फील्ड, प्रॉपर्टी या [अन्य समर्थित](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) डिक्लेरेशन में से कोई भी हो सकता है।

आप किसी एट्रिब्यूट को डिक्लेरेशन से ठीक पहले वाली लाइन पर जोड़कर लागू कर सकते हैं, जैसे `ClassAttribute` और `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

यह डिक्लेरेटिव मेटाडेटा कोड के साथ सिर्फ अतिरिक्त संरचित जानकारी जोड़ता है और कोड के व्यवहार को नहीं बदलता। लेकिन कोड का दूसरा हिस्सा इस मेटाडेटा का उपयोग यह तय करने के लिए करता है कि उसका लक्ष्य कैसा व्यवहार करेगा, या उसकी कुछ कार्यक्षमताएँ जोड़े, बदले, हटाए या सीमित करे।

कई [पहले से परिभाषित और आरक्षित एट्रिब्यूट](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) मौजूद हैं, जिनमें `Flags`, `Obsolete` और `Conditional` जैसे एट्रिब्यूट शामिल हैं। इनमें से हर एक की अपनी खास बात होती है, जिसे C# के डॉक्युमेंटेशन में देखा जा सकता है। ध्यान दीजिए कि [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) जैसे एट्रिब्यूट का पूरा नाम परंपरा से `FlagsAttribute` होता है, लेकिन किसी डिक्लेरेशन पर लगाते समय _Attribute_ प्रत्यय छोड़ा जा सकता है।
