# टेस्ट

अगर phix बाइनरी आपके PATH में है, तो यह कमांड डालिए:

```bash
p test 
```

इससे टेस्ट फाइल (test.exw) चल जाएगी।

अगर phix बाइनरी PATH में नहीं है, तो Windows में यह डालिए:

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## छोड़े गए टेस्ट

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना। डिफ़ॉल्ट रूप से test.exw फाइल के सारे टेस्ट चलाए जाते हैं। किसी टेस्ट को छोड़ने के लिए लाइन की शुरुआत में दो डैश (Phix में कमेंट लगाने का मानक चिह्न) लगाइए।

ध्यान रखिए कि टेस्ट tests.toml में लिखे किसी भी include=false फ्लैग को नहीं मानते। इसके बजाय यह test.exw के लेखक की ज़िम्मेदारी है कि वे उस फाइल में इन्हें खुद बनाए रखें, ताकि वास्तविक स्थिति का पता Exercism साइट को मिल सके (जैसे ट्रैक के आँकड़े जुटाने के लिए)। लेकिन ट्रैक में खुद कुछ भी इनका कोई इस्तेमाल नहीं करता, खास तौर पर टेस्ट जनरेटर और टेस्ट रनर।
