# तुलना ऑपरेटर

PHP में दस अंतर्निहित तुलना ऑपरेटर हैं:

| नाम | उदाहरण | परिणाम |
| ----- | ---------- | -------------------------------------------------- |
| बराबर | `$a == $b` | यदि `$a` टाइप जगलिंग के बाद `$b` के बराबर है तो सही। |
| समरूप | `$a === $b` | यदि `$a` `$b` के बराबर है और दोनों का टाइप एक ही है तो सही। |
| बराबर नहीं | `$a != $b` | यदि `$a` टाइप जगलिंग के बाद `$b` के बराबर नहीं है तो सही। |
| बराबर नहीं | `$a <> $b` | यदि `$a` टाइप जगलिंग के बाद `$b` के बराबर नहीं है तो सही। |
| समरूप नहीं | `$a !== $b` | यदि `$a` `$b` के बराबर नहीं है या दोनों का टाइप एक नहीं है तो सही। |
| कम | `$a < $b` | यदि `$a` `$b` से सख्ती से कम है तो सही। |
| अधिक | `$a > $b` | यदि `$a` `$b` से सख्ती से अधिक है तो सही। |
| कम या बराबर | `$a <= $b` | यदि `$a` `$b` से कम या बराबर है तो सही। |
| अधिक या बराबर | `$a >= $b` | यदि `$a` `$b` से अधिक या बराबर है तो सही। |
| स्पेसशिप | `$a <=> $b` | `$a` और `$b` की तुलना करने पर `0` से कम, बराबर या अधिक पूर्णांक लौटाता है। |

PHP में अलग-अलग परिभाषाएँ हैं जो `equal` और `identical` में अंतर करती हैं। कभी-कभी `identical` को `strictly equal` भी कहा जाता है।

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
