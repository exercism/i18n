# परिचय

## तुलना

Go में संख्याओं की तुलना इन संबंध और समानता ऑपरेटरों से की जा सकती है।

| तुलना            | ऑपरेटर   |
| ------------------| --------- |
| बराबर             | `==`      |
| बराबर नहीं         | `!=`      |
| कम                | `<`       |
| कम या बराबर        | `<=`      |
| अधिक              | `>`       |
| अधिक या बराबर      | `>=`      |

तुलना का परिणाम हमेशा एक बूलियन वैल्यू होता है, यानी या तो `true` या `false`।

```go
a := 3

a != 4 // true
a > 5  // false
```

ऊपर दिए गए तुलना ऑपरेटरों से स्ट्रिंग की तुलना भी की जा सकती है।
उस स्थिति में तुलना शब्दकोश के क्रम (lexicographical order) में होती है।
उदाहरण के लिए:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## `if` स्टेटमेंट

Go में शर्तें दूसरी भाषाओं की शर्तों जैसी ही होती हैं।
किसी भी शर्त वाले ऑपरेशन का मूल टाइप `bool` टाइप होता है, जिसकी वैल्यू `true` या `false` हो सकती है।
अक्सर शर्तों का इस्तेमाल यह तय करने के लिए किया जाता है कि कोड किस क्रम में चलेगा, यानी अलग-अलग शर्तों की जाँच के लिए।

किसी खास स्थिति की जाँच के लिए `if` स्टेटमेंट इस्तेमाल किया जा सकता है, जो अपना कोड तभी चलाता है जब उसकी शर्त `true` हो, ऐसे:

```go
var value string

if value == "val" {
    return "was val"
}
```

जहाँ एक से अधिक स्थितियाँ हों, वहाँ कई `if` स्टेटमेंट `else if` और `else` स्टेटमेंट की मदद से एक के बाद एक जोड़े जा सकते हैं।

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if` स्टेटमेंट में एक छोटा इनिशियलाइज़ेशन स्टेटमेंट भी हो सकता है, जिससे `if` स्टेटमेंट के लिए एक या अधिक वेरिएबल को शुरुआती वैल्यू दी जा सकती है।
उदाहरण के लिए:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> ध्यान दें: इनिशियलाइज़ेशन स्टेटमेंट में बनाए गए वेरिएबल `if` स्टेटमेंट के खत्म होने के बाद स्कोप से बाहर चले जाते हैं।
