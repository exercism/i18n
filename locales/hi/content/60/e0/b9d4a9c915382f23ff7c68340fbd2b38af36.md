# क्लास स्टैटिक कीवर्ड

PHP में क्लास कोड संगठन की एक इकाई है, जो अक्सर किसी चीज़, सेवा या प्रक्रिया के इंस्टेंस को दर्शाती है।
`static` और `self` कीवर्ड का उपयोग करके, प्रॉपर्टी और मेथड क्लास के संदर्भ में सभी इंस्टेंस के लिए (या बिना किसी इंस्टेंस के) मौजूद हो सकते हैं।

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## सीमा

स्टैटिक क्लास मेथड केवल अपनी ही क्लास की अन्य स्टैटिक प्रॉपर्टी या क्लास मेथड को कॉल कर सकते हैं।

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
