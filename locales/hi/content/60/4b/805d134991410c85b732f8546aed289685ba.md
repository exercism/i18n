# विवरण

एन्यूमरेशन किसी कलेक्शन (`Array`, `Hash`, आदि) पर एक-एक करके चलने और हर ऑब्जेक्ट पर कुछ करने की प्रक्रिया है।

Ruby में एन्यूमरेशन एक मुख्य कॉन्सेप्ट है और इसका इस्तेमाल क्रमबद्ध करने (`sort_by`), समूह बनाने (`group_by`), मैप करने (`map`), रिड्यूस करने (`reduce`) और बहुत कुछ के लिए होता है।
कलेक्शन पर लूप इस्तेमाल करने के बजाय एन्यूमरेशन से एक-एक करके चलना ही Ruby का स्वाभाविक तरीका है, और आप ऐसा सबसे ज़्यादा देखेंगे।

ऐरे के हर शब्द को प्रिंट करने वाला एक सरल एन्यूमरेशन ऐसा दिखेगा:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

इस उदाहरण में हमने `Array#each` मेथड को कॉल किया है और उसे एक _ब्लॉक_ दिया है, जो एक पैरामीटर (`word`) लेता है और उसे प्रिंट करता है।

हम एन्यूमरेबल मेथड को एक के बाद एक जोड़ भी सकते हैं।
उदाहरण के लिए, हम `each` पर `.with_index` जोड़कर किसी ऑब्जेक्ट का इंडेक्स और उसकी वैल्यू दोनों प्रिंट कर सकते हैं:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

`Hash` ऑब्जेक्ट पर एक-एक करके चलना बिल्कुल `Array` ऑब्जेक्ट पर एक-एक करके चलने जैसा है, बस फ़र्क इतना है कि ब्लॉक को दो आर्गुमेंट मिलते हैं: की और वैल्यू:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

ऊपर बताए गए मेथड [`Enumerable` मॉड्यूल][enumerable-module] का हिस्सा हैं, जो `Array`, `Hash` और उन अन्य क्लास में शामिल है जिन्हें एक-एक करके चलने की क्षमता चाहिए।

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
