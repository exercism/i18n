# पूर्णांक

पूर्णांक वे पूर्ण संख्याएँ हैं जो समुच्चय `{..., -2, -1, 0, 1, 2, ...}` में आती हैं।
किसी पूर्णांक की अधिकतम और न्यूनतम वैल्यू उस सिस्टम से तय होती है जिसमें PHP चलता है।
आम तौर पर अधिकांश आधुनिक सिस्टमों में पूर्णांक 64-बिट वैल्यू होता है, जिसका मतलब है कि यह `-9_223_372_036_854_775_808` से `9_223_372_036_854_775_807` तक (दोनों शामिल) को दर्शा सकता है।

```php
<?php

$a = 1234;
$a = 1_234_567;
```

आप आधार 10 के अलावा अन्य आधारों में पूर्णांक लिटरल वैल्यू लिख सकते हैं, इसके लिए आधार उपसर्ग का उपयोग कीजिए:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> PHP के [दस्तावेज़][syntax] से लिया गया।

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
