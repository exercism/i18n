# main फंक्शन मौजूद है

`Main` फंक्शन को हटा दीजिए, क्योंकि टेस्ट को इसकी ज़रूरत नहीं होती और यह कोड को पढ़ने में थोड़ा कठिन बना देता है।

आम तौर पर `Main` फंक्शन कोड को डीबग करने में मदद के लिए जोड़ा जाता है। लेकिन इससे बेहतर तरीका यह है कि यूनिट टेस्ट चलाते हुए कोड को डीबग कीजिए। इसका एक और फायदा यह है कि आप किसी एक खास टेस्ट केस को डीबग करने पर ध्यान दे सकते हैं। नीचे कुछ लिंक दिए गए हैं जिनमें बताया गया है कि अलग-अलग IDE में यूनिट टेस्ट चलाते हुए Scala कोड को कैसे डीबग किया जाए:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
