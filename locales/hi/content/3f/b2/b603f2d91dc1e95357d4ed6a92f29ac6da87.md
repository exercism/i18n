# निर्देश परिशिष्ट

## संकेत

इस अभ्यास को पूरा करने के लिए आपको `slices` फंक्शन बनाना है, जो एक *टेक्स्ट* लेता है और निर्दिष्ट आकार वाले अंकों के उपानुक्रम लौटाता है:

यदि आप पहली बार यह अभ्यास हल कर रहे हैं, तो सलाह दी जाती है कि आप दिए गए सिग्नेचर का ही पालन करें:

```haskell
slices :: Int -> String -> [[Int]]
```

बाद में, यह एक अच्छा विचार हो सकता है कि आप इस समस्या पर फिर से विचार करें और अन्य डेटा टाइपों और लाइब्रेरीज़ के साथ प्रयोग करें:

- `ByteString`, *bytestring* पैकेज से.
- `Sequence`, *containers* पैकेज से.
- `Text`, *text* पैकेज से.
- `Vector`, *vector* पैकेज से.

यह टेस्ट सूट जानबूझकर ऐसा बनाया गया है कि यह लगभग किसी भी ऐसे टाइप सिग्नेचर को स्वीकार कर ले जो तर्कसंगत हो, इसलिए आपको प्रोत्साहित किया जाता है कि आप वह सिग्नेचर चुनें जो आपको सबसे अच्छा लगे।
