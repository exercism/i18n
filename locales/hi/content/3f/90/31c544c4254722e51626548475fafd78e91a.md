# परिचय

## क्लास

Java में ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग की मुख्य रचना _क्लास_ है, जो डेटा (_फील्ड_) और व्यवहार (_मेथड_) का मेल है।
किसी क्लास के फील्ड और मेथड उसके _सदस्य_ कहलाते हैं।

सदस्यों तक पहुँच को एक्सेस मॉडिफायर के ज़रिए नियंत्रित किया जा सकता है। इनमें सबसे आम दो हैं:

- `public`: इस सदस्य तक कोई भी कोड पहुँच सकता है (कोई रोक नहीं)।
- `private`: इस सदस्य तक सिर्फ उसी क्लास का कोड पहुँच सकता है।

क्लास को उसके इंस्टेंस बनाने का एक टेम्पलेट मान सकते हैं।
किसी क्लास का इंस्टेंस बनाने के लिए (जिसे _ऑब्जेक्ट_ भी कहते हैं) `new` कीवर्ड का उपयोग किया जाता है:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

फील्ड का एक टाइप और एक नाम होता है (नाम camelCase में लिखा जाता है) और इसे क्लास में कहीं भी परिभाषित किया जा सकता है (परंपरा के अनुसार इसे PascalCase में लिखा जाता है):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

किसी फील्ड को शुरुआती वैल्यू असाइन करना वैकल्पिक है।
अगर किसी फील्ड में शुरुआती वैल्यू नहीं दी गई है, तो उसे उसके टाइप की डिफ़ॉल्ट वैल्यू मिल जाती है।
किसी इंस्टेंस के फील्ड की वैल्यू तक डॉट नोटेशन से पहुँचा जा सकता है और उसे बदला भी जा सकता है।

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

प्राइवेट फील्ड आमतौर पर किसी मेथड को कॉल करने के साइड इफेक्ट के रूप में बदले जाते हैं।
ऐसे मेथड आमतौर पर कोई वैल्यू नहीं लौटाते। ऐसी स्थिति में रिटर्न टाइप `void` होना चाहिए:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
