# परिचय

## पैरामीटर

यह अभ्यास मेथड पैरामीटर की कुछ बारीकियों और C# में उनके उपयोग पर चर्चा करता है।

पैरामीटर कॉल करने वाले मेथड से कॉल किए गए मेथड तक जानकारी पहुँचाते हैं।

- `ref` और `out` जैसे मॉडिफायर इस्तेमाल करके पैरामीटर का व्यवहार बदला जा सकता है।

- `out` मॉडिफायर वाला पैरामीटर कॉल किए गए मेथड से वापस कॉल करने वाले तक एक वैल्यू पहुँचाता है। इस पैरामीटर को बिना शुरुआती वैल्यू दिए ही कॉल किए गए मेथड को भेजा जा सकता है, और किसी भी हालत में कॉल किए गए मेथड के अंदर इसे ऐसे माना जाता है जैसे मेथड में प्रवेश करते समय इसे कोई वैल्यू मिली ही न हो। पैरामीटर मॉडिफायर से जुड़े व्यवहार और नियमों को समझने का सबसे आसान तरीका उदाहरण (नीचे देखिए) और कंपाइलर के संदेश हैं।

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out` पैरामीटर को कॉल किए गए मेथड के अंदर ही असाइन करना ज़रूरी है।

- `ref` मॉडिफायर वाला पैरामीटर कॉल किए गए मेथड के अंदर एक वैल्यू भेजता है। मेथड के लौटने पर कॉल करने वाले को उस पैरामीटर में वे सारे बदलाव दिखेंगे जो कॉल किए गए मेथड ने किए थे।

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` पैरामीटर वेरिएबल ही होने चाहिए, क्योंकि कॉल किया गया मेथड सीधे उसी पैरामीटर पर काम करता है जो कॉल करने वाले को दिखता है।
- `out` और `ref` मॉडिफायर दोनों जगह ज़रूरी हैं: कॉल किए गए मेथड के सिग्नेचर में भी, और जहाँ मेथड को कॉल किया जा रहा है वहाँ भी।
