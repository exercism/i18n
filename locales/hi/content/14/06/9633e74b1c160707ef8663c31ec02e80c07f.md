# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप    | विवरण                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | एड्रेस  | null-टर्मिनेटेड इनपुट स्ट्रिंग  |
| `$a1`    | इनपुट/आउटपुट  | एड्रेस  | null-टर्मिनेटेड परिणाम स्ट्रिंग |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए          |
