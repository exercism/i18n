# परिचय

स्ट्रिंग बफर छोटे-छोटे एलिमेंट जोड़कर एक बड़ी स्ट्रिंग बनाने का कुशल तरीका है। String के विपरीत, StringBuf का एक इंस्टेंस अपरिवर्तनीय नहीं होता। इसे ऐसे फंक्शनों को आर्गुमेंट के रूप में दिया जा सकता है, जो और वैल्यू जोड़कर उसे बदल देते हैं।

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
