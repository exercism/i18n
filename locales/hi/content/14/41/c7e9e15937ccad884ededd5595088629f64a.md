# निर्देश

साइफर व्हील में दो डिस्क होते हैं, जो एक दूसरे के अंदर लगे रहते हैं और वर्णमाला को गोल घुमाते हैं। इसे 3 पर सेट कीजिए, तो हर अक्षर तीन जगह आगे वाला अक्षर बन जाता है, और `z` घूमकर वापस `a` पर आ जाता है। जासूस सदियों से इसका इस्तेमाल करते आए हैं। आप भी एक बना रहे हैं।

पाँचों काम `CIPHER_WHEEL` क्लास में लिखने हैं।

## 1. क्या यह अक्षर है?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. इसे चिल्लाइए

किसी अक्षर का बड़ा रूप लौटाइए। जो अक्षर नहीं है, वह बिना बदले ही लौट आता है।

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. यह कौन-सी संख्या है?

वह संख्या लौटाइए जो किसी अक्षर को दर्शाती है।

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. पहला अक्षर

किसी स्ट्रिंग का पहला अक्षर लौटाइए।

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. व्हील घुमाइए

आपको एक छोटा अक्षर और जगहों की एक संख्या दी जाती है। वर्णमाला में उतनी जगह आगे वाला अक्षर लौटाइए। `z` से आगे जाने पर वह घूमकर वापस `a` पर आ जाता है।

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

जगहों की संख्या ऋणात्मक हो, तो पीछे की तरफ घुमाना भी काम करता है।

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

आप यह मान सकते हैं कि दिया गया अक्षर छोटा अक्षर है।
