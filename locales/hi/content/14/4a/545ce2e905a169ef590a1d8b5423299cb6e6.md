# विवरण

स्ट्रिंग टेक्स्ट डेटा को दर्शाती है।
Swift में [`String`][strings-and-characters] `Character` वैल्यू का एक क्रमबद्ध संग्रह है, जहाँ हर अक्षर एक यूनिकोड अक्षर को दर्शाता है।

आप स्ट्रिंग लिटरल की मदद से स्ट्रिंग बनाते हैं। स्ट्रिंग लिटरल अक्षरों का एक ऐसा क्रम है जिसके दोनों ओर दोहरे अवतरण चिह्न (`"`) लगाए जाते हैं।
जिन स्ट्रिंग में कई लाइनें हों, उनके लिए तीन दोहरे अवतरण चिह्न (`"""`) इस्तेमाल कीजिए:

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift की स्ट्रिंग और Foundation फ्रेमवर्क की [`NSString`][nsstring-docs] क्लास आपस में सहज ही जुड़ जाती हैं। इससे टेक्स्ट को प्रोसेस करने की बहुत सी सुविधाएँ मिल जाती हैं।

## अक्षर

एक `Character` एक ही एक्सटेंडेड ग्राफीम क्लस्टर को दर्शाता है, यानी एक ऐसा अक्षर जिसे इंसान पढ़ सकता है और जो एक या अधिक [यूनिकोड स्केलर वैल्यू][unicode-scalar-values] से मिलकर बना होता है।
यूनिकोड स्केलर वैल्यू 21 बिट का कोड पॉइंट होती है, जो `U+0000` से `U+D7FF` तक (दोनों शामिल) या `U+E000` से `U+10FFFF` तक (दोनों शामिल) के दायरे में आती है।

```swift
let aChar: Character = "A"
```

## टाइप अनुमान

जब आप स्ट्रिंग लिटरल लिखते हैं, तो Swift अपने आप उसका टाइप `String` मान लेता है।
किसी एक अक्षर को `Character` के रूप में संग्रहीत करने के लिए आपको टाइप साफ़-साफ़ लिखकर बताना पड़ता है:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## स्ट्रिंग को जोड़ना

आप जोड़ने वाले ऑपरेटर (`+`) की मदद से स्ट्रिंग को आपस में जोड़ सकते हैं:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

`+` की मदद से किसी `Character` को सीधे `String` में नहीं जोड़ा जा सकता। पहले उस अक्षर को स्ट्रिंग में बदलना पड़ता है।
लेकिन [`append(_:)`][append] मेथड की मदद से आप किसी स्ट्रिंग या अक्षर को सीधे एक ऐसी स्ट्रिंग में जोड़ सकते हैं जिसे बदला जा सकता है:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## स्ट्रिंग इंटरपोलेशन

[स्ट्रिंग इंटरपोलेशन][string-interpolation] की मदद से आप स्ट्रिंग लिटरल के अंदर कॉन्स्टेंट, वेरिएबलो, लिटरल और एक्सप्रेशन डालकर स्ट्रिंग बना सकते हैं।
हर एक्सप्रेशन को ऐसे गोल ब्रैकेट के बीच लिखिए जिनसे पहले बैकस्लैश आता है (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## स्ट्रिंग और अक्षर की प्रॉपर्टी

स्ट्रिंग और अक्षर में कई प्रॉपर्टी होती हैं, जिनसे आप उनकी सामग्री देख सकते हैं।

### स्ट्रिंग की प्रॉपर्टी

स्ट्रिंग की कुछ आम प्रॉपर्टी ये हैं:

| प्रॉपर्टी | विवरण                                    | उदाहरण                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | अगर स्ट्रिंग में कोई अक्षर न हो तो `true` लौटाती है | `"Hello".isEmpty` का मान `false` आता है |
| `count`   | स्ट्रिंग में मौजूद अक्षरों की संख्या लौटाती है | `"Hello".count` का मान `5` आता है       |

प्रॉपर्टी की पूरी सूची के लिए [Apple के String दस्तावेज़][string-docs] देखिए।

### अक्षर की प्रॉपर्टी

अक्षर की कुछ आम प्रॉपर्टी ये हैं:

| प्रॉपर्टी       | विवरण                                   | उदाहरण                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | अगर अक्षर लोअरकेस हो तो `true` लौटाती है  | `"a".isLowercase` का मान `true` आता है |
| `isUppercase`  | अगर अक्षर अपरकेस हो तो `true` लौटाती है  | `"A".isUppercase` का मान `true` आता है |
| `isNumber`     | अगर अक्षर एक अंक हो तो `true` लौटाती है    | `"1".isNumber` का मान `true` आता है    |
| `isWhitespace` | अगर अक्षर व्हाइटस्पेस हो तो `true` लौटाती है | `" ".isWhitespace` का मान `true` आता है|

प्रॉपर्टी की पूरी सूची के लिए [Apple के Character दस्तावेज़][character-docs] देखिए।

## टाइप बदलना

`String(_:)` इनिशियलाइज़र की मदद से आप दूसरे टाइप को स्ट्रिंग में बदल सकते हैं। यह `Int`, `Double` और `Character` जैसे आम टाइप के साथ काम करता है:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## खास अक्षर

Swift के स्ट्रिंग लिटरल में खास अक्षरों के लिए कई [एस्केप सीक्वेंस][special-characters] इस्तेमाल किए जा सकते हैं:

| सीक्वेंस   | विवरण                   |
| ---------- | ----------------------------- |
| `\0`       | नल अक्षर                |
| `\\`       | बैकस्लैश                     |
| `\t`       | आड़ा टैब                |
| `\n`       | लाइन फीड (नई लाइन)           |
| `\r`       | कैरिज रिटर्न               |
| `\'`       | एकल अवतरण चिह्न         |
| `\"`       | दोहरा अवतरण चिह्न         |
| `\u{n}`    | कोई भी यूनिकोड स्केलर (हेक्साडेसिमल) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
