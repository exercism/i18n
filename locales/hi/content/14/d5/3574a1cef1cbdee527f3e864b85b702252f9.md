# परिचय

## ऐरे

ऐरे Elixir भाषा में पहले से मौजूद हैं। इन्हें एक बुनियादी टाइप माना जाता है, और इन्हें चौकोर ब्रैकेट से दर्शाया जाता है। ऐरे खाली हो सकते हैं, या किसी भी टाइप की कितनी भी चीज़ें अपने अंदर रख सकते हैं। उदाहरण के लिए:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir ऐरे को लिंक्ड लिस्ट की तरह लागू करता है, जिसमें हर नोड दो वैल्यू संग्रहीत करता है: पहली चीज़, और बाकी सारी चीज़ों वाला एक और ऐरे। ऐरे की पहली चीज़ को _हेड_ कहा जाता है, और बाकी बची चीज़ों वाले ऐरे को _टेल_ कहा जाता है। आप कोड में यह नोटेशन इस्तेमाल कर सकते हैं:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

आप _`[head | tail]`_ नोटेशन से ऐरे के शुरू में एलिमेंट जोड़ सकते हैं:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

ऐरे के साथ काम करने के लिए `Kernel` मॉड्यूल में कई फंक्शन हैं, और इसके अलावा पूरा `List` मॉड्यूल भी है।

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
