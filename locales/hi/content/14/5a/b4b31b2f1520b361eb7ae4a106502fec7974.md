# परिचय

Haxe में `class` मुख्य डेटा स्ट्रक्चर है, जो डेटा (फील्ड) और व्यवहार (मेथड) को अपने अंदर समेटता है। फील्ड और मेथड को क्लास के सदस्य भी कहा जाता है।

इन सदस्यों तक पहुँच को एक्सेस मॉडिफायर की मदद से सीमित किया जा सकता है। ये मॉडिफायर हैं:

- `public`: सदस्य को कहीं से भी एक्सेस किया जा सकता है।
- `private`: सदस्य को केवल उसी क्लास से एक्सेस किया जा सकता है।

क्लास को इंस्टेंस बनाने के टेम्पलेट की तरह समझा जा सकता है। इंस्टेंस बनाने के लिए बस `new` कीवर्ड का इस्तेमाल कीजिए:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

किसी फील्ड को बनाने के लिए एक्सेस मॉडिफायर लिखिए, उसके बाद वेरिएबल का नाम और टाइप लिखिए:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

फील्ड बनाते समय आप उसकी शुरुआती वैल्यू भी तय कर सकते हैं। अगर किसी फील्ड की शुरुआती वैल्यू तय नहीं की जाती, तो उसकी वैल्यू `null` हो जाती है। आप किसी फील्ड को डॉट नोटेशन की मदद से एक्सेस कर सकते हैं:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
