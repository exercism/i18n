# इंस्टॉलेशन

यह ट्रैक ReScript 12 का उपयोग करता है और इसके लिए [Node.js][nodejs] 22 या उससे नए संस्करण की ज़रूरत होती है।
कई सिस्टमों में यह पहले से इंस्टॉल रहता है, या आपने इसे किसी दूसरे ट्रैक के लिए पहले ही इंस्टॉल कर लिया होगा।

टर्मिनल खोलिए और यह चलाइए:

```sh
node -v
```

अगर Node इंस्टॉल नहीं है, या सूची में कोई पुराना संस्करण दिख रहा है, तो अपने प्लेटफॉर्म के लिए [Node.js के आधिकारिक इंस्टॉलेशन][nodejs-install] के निर्देशों का पालन कीजिए।

## डिपेंडेंसी इंस्टॉल करना

हर ReScript अभ्यास अपने आप में पूरा एक npm प्रोजेक्ट होता है।
[Exercism CLI][exercism-cli] से कोई अभ्यास डाउनलोड करने के बाद, उस प्रोजेक्ट की डिपेंडेंसी इंस्टॉल कीजिए, जिनमें ReScript भी शामिल है। इसके बाद आप काम शुरू कर सकते हैं:

```sh
cd /path/to/exercise
npm install
```

## एडिटर सपोर्ट

ReScript प्रोजेक्ट आधिकारिक और कम्युनिटी, दोनों तरह के एडिटर प्लगइन की [सूची][rescript-plugins] बनाए रखता है।
