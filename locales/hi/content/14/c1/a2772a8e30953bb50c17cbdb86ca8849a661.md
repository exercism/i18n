# निर्देश

Izzy को पक्षी देखने का बहुत शौक है और वह यह हिसाब रखती है कि किसी भी दिन उसके बगीचे में कितने पक्षी आए।

उसने आपसे मदद माँगी है, ताकि उसके पक्षी-निरीक्षण को एक नए स्तर पर ले जाया जा सके और कुछ ऐसे टूल बनाए जा सकें जो उसे डेटा का हिसाब रखने और उसे संसाधित करने में मदद करें।

आपने डेटा को पूर्णांकों की एक ऐरे के रूप में रखने का फैसला किया है। ऐरे में पहली संख्या उन पक्षियों की संख्या है जो आज आपके बगीचे में आए, दूसरी कल के, और इसी तरह आगे भी।

## 1. देखिए कि आज कितने पक्षी आए

`today` फंक्शन बनाइए। इसे रोज़ की पक्षी-संख्याओं की एक ऐरे लेना चाहिए और आज की संख्या लौटानी चाहिए। अगर ऐरे खाली हो, तो इसे `0` लौटाना चाहिए।

```gleam
today([2, 5, 1])
// -> 2
```

## 2. आज की संख्या बढ़ाइए

`increment_day_count` फंक्शन बनाइए। इसे रोज़ की पक्षी-संख्याओं की एक ऐरे लेना चाहिए और आज की संख्या को 1 से बढ़ाना चाहिए। अगर ऐरे खाली हो, तो `[1]` लौटाइए।

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. देखिए कि क्या कोई ऐसा दिन था जब एक भी पक्षी नहीं आया

`has_day_without_birds` फंक्शन बनाइए। इसे रोज़ की पक्षी-संख्याओं की एक ऐरे लेना चाहिए। अगर कम से कम एक ऐसा दिन था जब बगीचे में कोई पक्षी नहीं आया, तो इसे `True` लौटाना चाहिए, वरना `False`। अगर ऐरे खाली हो, तो यह माना जाएगा कि _अभी तक_ कोई पक्षी दर्ज नहीं हुआ; `False` लौटाइए।

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. आने वाले पक्षियों की कुल संख्या निकालिए

`total` फंक्शन बनाइए। इसे रोज़ की पक्षी-संख्याओं की एक ऐरे लेना चाहिए और उन सब पक्षियों की कुल संख्या लौटानी चाहिए जो आपने डेटा जमा करना शुरू किया तब से आपके बगीचे में आए।

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरों से ज़्यादा व्यस्त होते हैं। व्यस्त दिन वह होता है जब आपके बगीचे में पाँच या उससे अधिक पक्षी आए हों।

`busy_days` फंक्शन बनाइए। इसे रोज़ की पक्षी-संख्याओं की एक ऐरे लेना चाहिए और व्यस्त दिनों की संख्या लौटानी चाहिए।

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
