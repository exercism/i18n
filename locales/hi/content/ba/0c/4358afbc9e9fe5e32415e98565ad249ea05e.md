# परिचय

## पाइप ऑपरेटर

`|>` ऑपरेटर को पाइप ऑपरेटर कहते हैं। इसका उपयोग कई फंक्शन कॉल को इस तरह एक के बाद एक जोड़ने के लिए किया जा सकता है कि पिछले फंक्शन कॉल से लौटाई गई वैल्यू अगले फंक्शन कॉल को दी जाती है।

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

ऊपर दिया गया कोड नीचे दिए गए कोड के बराबर है:

```gleam
string.append(string.uppercase("hello"), "?!")
```

पाइप ऑपरेटर या तो वैल्यू को फंक्शन कॉल के पहले आर्गुमेंट के रूप में देता है, या नई कॉल के एकमात्र आर्गुमेंट के रूप में। यह चुनता है कि किस विकल्प में सही टाइप होगा।

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

कभी-कभी हम वैल्यू को किसी और स्थान पर देना चाहते हैं। ऐसे में `_` प्लेसहोल्डर का उपयोग यह बताने के लिए किया जा सकता है कि वैल्यू कहाँ डाली जानी चाहिए।

```gleam
100
|> some_function(1, _, 2)
```
