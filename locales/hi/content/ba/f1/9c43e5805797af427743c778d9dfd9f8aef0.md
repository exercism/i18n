# Instructions

आप अपने स्कूल की प्रस्तुति के लिए क्यू बोल रहे हैं। स्टेज मैनेजर चाहते हैं कि मानक संवाद लिख दिए जाएँ ताकि कोई भी डेस्क चला सके।

आपके पास चार कार्य हैं, सभी `STAGE_DIRECTIONS` क्लास में।

## 1. शुरुआत की घोषणा कीजिए

वह संवाद लौटाइए जो शो की शुरुआत करता है।

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. मध्यांतर की घोषणा कीजिए

मध्यांतर पर बोला जाने वाला संवाद लौटाइए।

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. अंत की घोषणा कीजिए

वह संवाद लौटाइए जो शो का समापन करता है।

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. अंतिम क्यू बोलिए

अंतिम क्यू वही संवाद है जो शो का समापन करता है। टेक्स्ट को दूसरी बार लिखने के बजाय, उसी रूटीन को कॉल कीजिए जिसे आपने पहले ही लिखा है।

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
