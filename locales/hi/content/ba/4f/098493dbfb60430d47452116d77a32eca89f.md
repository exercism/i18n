# परिचय

Python में [`if`][if statement], `elif` (_'else and if' का छोटा रूप_) और `else` स्टेटमेंट का इस्तेमाल [कोड के चलने का क्रम नियंत्रित करने][control flow tools] और प्रोग्राम में निर्णय लेने के लिए किया जाता है। बहुत सी दूसरी प्रोग्रामिंग भाषाओं के विपरीत, Python के 3.9 और उससे पुराने संस्करणों में कोई औपचारिक केस-स्विच स्टेटमेंट नहीं होता। उसके बजाय कई `elif` स्टेटमेंट मिलकर वही काम करते हैं।

Python 3.10 में केस-स्विच स्टेटमेंट का एक अलग रूप आया है, जिसे `pattern matching` कहा जाता है। इसकी चर्चा किसी और कॉन्सेप्ट में अलग से की जाएगी।

शर्त वाले स्टेटमेंट ऐसे एक्सप्रेशन इस्तेमाल करते हैं जिनका परिणाम `True` या `False` होना ज़रूरी है, चाहे वह सीधे `bool` लौटाकर हो या ["truthy" या "falsy"][truth value testing] जाँचकर।


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

`if` के साथ जोड़े जाने पर, वैकल्पिक `else` कोड ब्लॉक तब चलता है जब मूल `if` शर्त का परिणाम `False` निकलता है:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` एक से अधिक जाँचों या शाखाओं की सुविधा देता है।

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

शर्तों के साथ [बूलियन ऑपरेशन][boolean operations] और [तुलना][comparisons] जोड़कर और भी जटिल जाँचें की जा सकती हैं:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
