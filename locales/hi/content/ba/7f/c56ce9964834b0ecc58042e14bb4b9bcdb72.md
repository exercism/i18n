# परिचय

कई भाषाओं में किसी ऐसी वैल्यू को दिखाने का तरीका होता है जो मौजूद नहीं है, जैसे `null` या `none`। चूँकि R को बड़ी मात्रा में (अक्सर बेतरतीब) डेटा संभालने के लिए बनाया गया है, इसलिए इसमें कुछ न होने के कई रूप मौजूद हैं।

पूरा उद्देश्य यह है कि जैसे-जैसे कोई गायब या संदिग्ध वैल्यू सामने आए, उसे चिह्नित किया जाए, और फिर बिना कोई एक्सेप्शन उठाए काम आगे चलता रहे।

## NULL

अगर कोई वैल्यू वाकई मौजूद नहीं है, तो उसे `NULL` से दिखाया जाता है। यह शायद C या Python के तरीके के सबसे करीब है।

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

कई जगहों पर `NULL` वैल्यू को बस नज़रअंदाज़ कर दिया जाता है:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

ऐसी स्थितियों के लिए, जहाँ वैल्यू मौजूद तो है पर हमें पता नहीं कि वह क्या है, `NA` का इस्तेमाल किया जाता है। उदाहरण के लिए, किसी सड़क पर चलने वाले वाहनों की गिनती करते समय हो सकता है कि गिनती करने वाले लोग बीमार पड़ जाएँ या स्वचालित सेंसर खराब हो जाएँ, पर यातायात बहता रहता है।

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

इस तरह `NA` एक प्लेसहोल्डर है, जो लोगों को यह चेतावनी देता है कि उन्हें तय करना होगा कि इसके साथ कैसे निपटना है।

## खाली वेक्टर

शायद हैरानी की बात है कि R में खालीपन जाँचने का कोई मानक तरीका नहीं है, हालाँकि कुछ थर्ड-पार्टी पैकेज अपने खुद के फंक्शन बनाते हैं, जैसे `is.empty()`।

यहाँ तक कि एक खाली वेक्टर बनाना भी उतना सीधा नहीं है। हमने पिछले एक भाग में देखा था कि बिना किसी आर्गुमेंट के `c()` वेक्टर नहीं, बल्कि `NULL` लौटाता है।

```R
is.vector(c())
#> [1] FALSE
```

`logical()` या `integer()` जैसे फंक्शन एक आर्गुमेंट लेते हैं जो मनचाही लंबाई बताता है, और यह लंबाई शून्य भी हो सकती है।

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

हम एक वेक्टर बनाकर उसके हर एलिमेंट को हटा भी सकते हैं, जैसा कि [वेक्टर कॉन्सेप्ट][concept-vectors] में बताया गया है। इससे उचित टाइप का शून्य लंबाई वाला वेक्टर बनता है।

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
