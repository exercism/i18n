# परिचय

## क्लास

C# में मुख्य ऑब्जेक्ट-ओरिएंटेड संरचना _क्लास_ है, जो डेटा (_फील्ड_) और व्यवहार (_मेथड_) का मेल है। किसी क्लास के फील्ड और मेथड को उसके _सदस्य_ कहा जाता है।

सदस्यों तक पहुँच को एक्सेस मॉडिफायर के ज़रिए सीमित किया जा सकता है। सबसे आम दो एक्सेस मॉडिफायर ये हैं:

- `public`: इस सदस्य तक कोई भी कोड पहुँच सकता है (कोई रोक नहीं)।
- `private`: इस सदस्य तक सिर्फ उसी क्लास का कोड पहुँच सकता है।

क्लास को उस क्लास के इंस्टेंस बनाने का एक टेम्पलेट मान सकते हैं। किसी क्लास का इंस्टेंस बनाने के लिए (जिसे _ऑब्जेक्ट_ भी कहते हैं) `new` कीवर्ड इस्तेमाल किया जाता है:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

फील्ड का एक टाइप होता है और इन्हें क्लास में कहीं भी परिभाषित किया जा सकता है।
Public फील्ड PascalCase में और private फील्ड camelCase में लिखे जाते हैं, और private फील्ड से पहले अंडरस्कोर `_` लगाया जाता है:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

किसी फील्ड को शुरुआती वैल्यू असाइन करना ज़रूरी नहीं है। अगर किसी फील्ड में शुरुआती वैल्यू नहीं दी गई हो, तो उसमें उसके टाइप की डिफॉल्ट वैल्यू रख दी जाती है। किसी इंस्टेंस के फील्ड की वैल्यू को डॉट नोटेशन से पढ़ा और बदला जा सकता है।

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

प्राइवेट फील्ड आम तौर पर किसी मेथड को कॉल करने के साइड इफेक्ट के रूप में बदले जाते हैं। ऐसे मेथड आम तौर पर कोई वैल्यू नहीं लौटाते। ऐसे में रिटर्न टाइप `void` होना चाहिए:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
