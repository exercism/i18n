# इंस्टॉलेशन

Exercism की मदद से आप अपना ABAP कोड सीधे अपने ब्राउज़र में लिख और टेस्ट कर सकते हैं। इसके लिए कोई अतिरिक्त इंस्टॉलेशन ज़रूरी नहीं है। लेकिन अगर आप अपने ही सिस्टम पर कोड लिखना और टेस्ट करना पसंद करते हैं, तो आप एक ABAP ट्रायल सिस्टम ले सकते हैं।

हो सकता है कि जहाँ आप काम करते हैं वहाँ SAP चल रहा हो। ABAP डेवलपमेंट सैंडबॉक्स तक आपकी पहुँच है या नहीं, और है तो कैसे, यह अपने IT विभाग से पूछ लीजिए।

## कौन-सा वर्ज़न चुनना चाहिए?

हम सलाह देते हैं कि आप ABAP प्लेटफॉर्म का कोई ऐसा वर्तमान रिलीज़ इस्तेमाल कीजिए जिसका सपोर्ट अभी चालू है। फिलहाल यह **ABAP 7.5 और उससे ऊपर** है। वर्तमान रिलीज़ों और उनकी समय-सीमाओं की जानकारी [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise) पर मिल सकती है।

## क्या इंस्टॉल करना है?

हम [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial) का सबसे नया वर्ज़न इस्तेमाल करने की सलाह देते हैं। यह ABAP 7.58 पर आधारित है। आप SAP ABAP सिस्टम को Docker इमेज के रूप में इंस्टॉल कर सकते हैं, या SAP Cloud Appliance Library में होस्ट किया हुआ ले सकते हैं। इसके अलावा आपको अपने ऑपरेटिंग सिस्टम के अनुसार Windows या Java के लिए SAP GUI इंस्टॉल करना होगा। SAP GUI आप [यहाँ](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui) से डाउनलोड कर सकते हैं।

अधिक जानकारी के लिए यह [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183) ब्लॉग देखिए।
