# टेस्ट चलाना

किसी दिए गए अभ्यास का टेस्ट चलाने के लिए, फोल्डर में `cd` कीजिए और नीचे दिए गए कमांड चलाइए:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

ये टेस्ट TestBox नाम की लाइब्रेरी का उपयोग करते हैं, जो xUnit और BDD शैली की टेस्टिंग का समर्थन करती है। सभी टेस्ट सूट [BDD शैली](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) में लिखे जाएँगे, जो टेस्ट स्पेक्स बनाने के लिए क्लोज़र का इस्तेमाल करती है। आपको TestBox इंस्टॉल करने की चिंता करने की ज़रूरत नहीं है। CLI टेस्ट रनर यह काम आपके लिए कर देगा। आपको बस पहली बार इसे चलाते समय इंटरनेट से जुड़ा होना ज़रूरी है। आप इसके बारे में और यहाँ पढ़ सकते हैं:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
