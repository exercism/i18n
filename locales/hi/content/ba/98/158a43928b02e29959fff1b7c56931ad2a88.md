# परिचय

## स्ट्रक्ट

C# में `struct` और `class` एक-दूसरे से बहुत मिलते-जुलते हैं। इनमें स्थिति और व्यवहार दोनों होते हैं। इनके कंस्ट्रक्टर आर्गुमेंट लेते हैं, इंस्टेंस को असाइन किया जा सकता है और उनकी समानता की जाँच की जा सकती है। इंस्टेंस को संग्रह में भी रखा जा सकता है।

```csharp
enum Unit
{
    Kg,
    Lb
}
struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```
