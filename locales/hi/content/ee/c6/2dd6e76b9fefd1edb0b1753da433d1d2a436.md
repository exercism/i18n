# `for` लूप

लूप का इस्तेमाल प्रोग्रामिंग की एक बुनियादी अवधारणा है। इससे आप एक कोड ब्लॉक को कई बार चला सकते हैं।
Swift में दो तरह के लूप होते हैं: [`for-in` लूप][for-loops] और `while` लूप।
इस अध्याय में आप `for-in` लूप के बारे में सीखेंगे।

`for` लूप की मदद से आप वैल्यू के किसी सीक्वेंस पर इटरेशन कर सकते हैं। इसमें हर एलिमेंट को एक-एक करके उठाया जाता है और आपके चुने हुए वेरिएबल में रखा जाता है।
Swift में आप कई तरह के सीक्वेंस पर इटरेशन कर सकते हैं, जैसे रेंज, ऐरे और स्ट्रिंग (और कुछ और टाइप भी, जिनकी चर्चा आगे की जाएगी)।
जब सीक्वेंस के हर एलिमेंट पर इटरेशन हो जाता है, तो लूप खत्म हो जाता है।

`for` लूप को `for` कीवर्ड से घोषित किया जाता है। उसके बाद एक वेरिएबल का नाम आता है, फिर `in` कीवर्ड, और अंत में वह वैल्यू का सीक्वेंस जिस पर इटरेशन करना है।
`for-in` लूप में दिया गया वेरिएबल बदला नहीं जा सकता, यानी आप लूप के अंदर उसकी वैल्यू नहीं बदल सकते।
यहाँ संख्याओं के एक ऐरे पर इटरेशन करने वाले एक `for-in` लूप का उदाहरण है:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` वेरिएबल `for-in` लूप में घोषित किया जाता है और सिर्फ लूप के स्कोप के अंदर ही उपलब्ध रहता है।

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## रेंज पर इटरेशन

`for-in` लूप की मदद से आप संख्याओं की एक रेंज पर भी इटरेशन कर सकते हैं।
इससे आप एक कोड ब्लॉक को तय संख्या में चला सकते हैं। जैसे, रेंज `1...5` संख्याओं 1, 2, 3, 4 और 5 पर इटरेशन करती है, इसलिए लूप 5 बार चलेगा।
कभी-कभी आपको ऐरे जैसे डेटा स्ट्रक्चर के इंडेक्स पर इटरेशन करना हो सकता है। तब आप `0..<array.count` रेंज इस्तेमाल कर सकते हैं।

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## स्ट्रिंग पर इटरेशन

`for-in` लूप की मदद से आप एक स्ट्रिंग पर भी इटरेशन कर सकते हैं।
इससे आप स्ट्रिंग के हर अक्षर पर इटरेशन कर सकते हैं। खास तौर पर ध्यान दीजिए कि लूप में जो टाइप दिया जाता है वह `Character` होता है।

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## ऐसे वेरिएबल जिनका इस्तेमाल नहीं होता

अगर लूप में वेरिएबल की वैल्यू की ज़रूरत नहीं है, तो आप उसे नज़रअंदाज़ करने के लिए अंडरस्कोर `_` इस्तेमाल कर सकते हैं।

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift एक `stride` फंक्शन भी देता है, जिससे आप किसी रेंज पर एक तय स्टेप के साथ सीक्वेंस बना सकते हैं।
इसके बाद उस पर `for-in` लूप की मदद से इटरेशन किया जा सकता है।
`stride` को [`stride(from:to:by:)`][stride-to] या [`stride(from:through:by:)`][stride-through] के रूप में परिभाषित किया गया है। पहला एक्सक्लूसिव है और दूसरा इन्क्लूसिव।

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

ध्यान दीजिए कि `to` पैरामीटर एक्सक्लूसिव है, इसलिए लूप उस संख्या तक चलेगा जो `to` पैरामीटर से ठीक पहले आती है। वहीं `through` पैरामीटर इन्क्लूसिव है, इसलिए यहाँ लूप में `10` भी शामिल होगा।

[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
