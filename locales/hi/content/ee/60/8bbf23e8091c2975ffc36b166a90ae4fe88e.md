# परिचय

एलिक्सिर में _बिहेवियर_ एक ऐसा कोड होता है जो सामान्य इंटरफेस तय करता है, और हर मॉड्यूल उसे अपने तरीके से लागू कर सकता है। ऐसा ही एक आम उदाहरण _एक्सेस बिहेवियर_ है।

_एक्सेस बिहेवियर_ ऐसी डेटा संरचना से डेटा निकालने के लिए एक सामान्य इंटरफेस देता है जिसमें हर वैल्यू एक की के आधार पर रखी जाती है। _एक्सेस बिहेवियर_ मैप और कीवर्ड लिस्ट के लिए लागू किया गया है, लेकिन चलिए, इसे समझने के लिए इसका इस्तेमाल मैप के साथ देखते हैं। _एक्सेस बिहेवियर_ कहता है कि जब आपके पास एक मैप हो, तो आप उसके बाद _चौकोर ब्रैकेट_ लगाकर उस की से जुड़ी वैल्यू निकाल सकते हैं।

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

अगर डेटा संरचना में वह की मौजूद नहीं है, तो `nil` लौटाया जाता है। इससे कभी-कभी वह नतीजा मिल सकता है जिसकी आपने उम्मीद नहीं की थी, क्योंकि ऐसी स्थिति में कोई एरर नहीं मिलती। ध्यान दीजिए कि `nil` खुद भी एक्सेस बिहेवियर लागू करता है और किसी भी की के लिए हमेशा `nil` लौटाता है।
