# कॉन्स्टेंट को टॉप लेवल पर निकालना बेहतर है

कॉन्स्टेंट को फंक्शन के _अंदर_ बनाने के बजाय उसे टॉप लेवल पर निकालना बेहतर होगा। जिन कॉन्स्टेंट, फंक्शन और क्लास को `export` नहीं किया गया होता, उन्हें फाइल के बाहर से इस्तेमाल नहीं किया जा सकता।

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
