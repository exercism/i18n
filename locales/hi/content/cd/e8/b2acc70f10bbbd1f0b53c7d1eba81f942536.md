# निर्देश

इस अभ्यास में आपको [Pac-Man][Pac-Man] के कुछ नियम लागू करने हैं, जो 1980 के दशक का क्लासिक आर्केड गेम है।

कुल छह काम हैं, जिनमें से चार गेम की स्थितियों से जुड़े नियम हैं।

> _फंक्शन में आर्गुमेंट कैसे निकाले जाते हैं, इसकी चिंता न कीजिए। बस इस पर ध्यान दीजिए कि आर्गुमेंट को मिलाकर वह परिणाम लौटाया जाए जो अपेक्षित है।_


## 0. पावर की स्थिति बनाइए

`PowerOn` नाम का एक वेरिएबल बनाइए, जिसकी वैल्यू यह दर्शाती है कि पावर वाकई चालू है।

```powershell
> $PowerOn
True
```

## 1. यह तय कीजिए कि Pac-Man भूत खाता है या नहीं

`EatGhost` फंक्शन बनाइए जो दो पैरामीटर लेता है (_यह कि Pac-Man का पावर पेलेट चालू है या नहीं_, और _यह कि Pac-Man किसी भूत को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man भूत खा सकता है या नहीं।
फंक्शन को `True` तभी लौटाना चाहिए जब Pac-Man का पावर पेलेट चालू हो और वह किसी भूत को छू रहा हो।

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. यह तय कीजिए कि Pac-Man स्कोर करता है या नहीं

`Score` फंक्शन बनाइए जो दो पैरामीटर लेता है (_यह कि Pac-Man किसी पावर पेलेट को छू रहा है या नहीं_, और _यह कि Pac-Man किसी डॉट को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man ने स्कोर किया या नहीं।
फंक्शन को `True` लौटाना चाहिए अगर Pac-Man किसी पावर पेलेट या डॉट को छू रहा हो।

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. यह तय कीजिए कि Pac-Man हारता है या नहीं

`Lose` फंक्शन बनाइए जो दो पैरामीटर लेता है (_यह कि Pac-Man का पावर पेलेट चालू है या नहीं_, और _यह कि Pac-Man किसी भूत को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man हार गया या नहीं।
फंक्शन को `True` लौटाना चाहिए अगर Pac-Man किसी भूत को छू रहा हो और उसका कोई पावर पेलेट चालू न हो।

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. यह तय कीजिए कि Pac-Man जीतता है या नहीं

`Win` फंक्शन बनाइए जो तीन पैरामीटर लेता है (_यह कि Pac-Man ने सारे डॉट खा लिए हैं या नहीं_, _यह कि Pac-Man का पावर पेलेट चालू है या नहीं_, और _यह कि Pac-Man किसी भूत को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man जीत गया या नहीं।
फंक्शन को `True` लौटाना चाहिए अगर Pac-Man ने सारे डॉट खा लिए हों और भाग 3 में बताए गए पैरामीटर के आधार पर वह हारा न हो।

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. जीतने की शर्त के लिए Synopsis लिखिए

पिछले फंक्शन पर वापस जाइए और कमेंट ब्लॉक में एक `Synopsis` सेक्शन जोड़िए, जो संक्षेप में बताए कि गेम कैसे जीता जाता है।
यह वर्णन कम से कम दस अक्षरों का होना चाहिए।

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
