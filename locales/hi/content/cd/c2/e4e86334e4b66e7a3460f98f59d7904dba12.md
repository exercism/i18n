## 1. कार्ड बनाने के लिए ज़रूरी जानकारी रेगुलर एक्सप्रेशन से निकालिए

- `\p{L}` किसी भी भाषा के किसी भी तरह के अक्षर से मेल खाएगा।
- जानकारी निकालने के लिए आप नीचे दिया गया एक्सप्रेशन इस्तेमाल कर सकते हैं:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
