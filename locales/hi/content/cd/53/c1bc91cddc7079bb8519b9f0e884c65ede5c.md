# परिचय

Kotlin का `when` एक सशर्त एक्सप्रेशन है, जो कई विकल्पों में से एक चुनने के लिए इस्तेमाल होता है।
यह Java के `switch` जैसा है, और `if` ... `else if` ... `else` की श्रृंखला से ज़्यादा लचीला है।

`if` की तरह `when` को भी ऐसे एक्सप्रेशन के रूप में इस्तेमाल किया जा सकता है जो एक वैल्यू देता है।

## किसी वैल्यू से मिलान

`when` को कोष्ठकों में वह वैल्यू दीजिए जिसका मिलान करना है।
हर ब्रांच उस वैल्यू से तब तक तुलना करती है जब तक कोई ब्रांच मेल न खा जाए:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- हर ब्रांच `pattern -> result` के रूप में लिखी जाती है।
- ब्रांचों को ऊपर से नीचे तक आज़माया जाता है, जब तक कोई ब्रांच मेल न खा जाए। केवल पहली ब्रांच चलती है।
- ऊपर दी गई सूची में न होने वाली किसी भी वैल्यू के लिए `else` का इस्तेमाल कीजिए (जैसे `if` श्रृंखला के अंत में आने वाले `else` की तरह)।

यह [पैटर्न मैचिंग][pattern-matching] जैसा है।
`pattern` वह वैल्यू हो सकता है जिसका मिलान करना है, या टाइप के आधार पर मिलान के लिए `is` का इस्तेमाल कीजिए:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

या यह जाँचने के लिए `in` का इस्तेमाल कीजिए कि वह किसी रेंज, कलेक्शन, स्ट्रिंग या `contains` मेथड वाली किसी अन्य चीज़ में मौजूद है या नहीं:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## गार्ड शर्तें

किसी वैल्यू से मिलान करते समय पैटर्न के बाद `if` में अतिरिक्त शर्तें लगाई जा सकती हैं।
इन शर्तों को गार्ड शर्तें कहा जाता है।

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

`else if` का भी इस्तेमाल किया जा सकता है।

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## शर्तों का मिलान

दूसरा तरीका यह है कि वैल्यू छोड़ दी जाए और हर ब्रांच पर बूलियन शर्तें लगाई जाएँ:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

फिर से, ब्रांचों को ऊपर से नीचे तक जाँचा जाता है और केवल वह पहली ब्रांच चलती है जिसकी शर्त `true` होती है।

## `when` को एक्सप्रेशन के रूप में इस्तेमाल करना

जब `when` का इस्तेमाल उसके परिणाम के लिए किया जाता है (जैसे किसी वेरिएबल को असाइन करना, किसी फंक्शन से लौटाना, वगैरह), तो हर संभावित केस को कवर करना ज़रूरी है।

- वैल्यू से मिलान करते समय `else` जोड़िए, जब तक कि हर संभावित वैल्यू पहले से संभाली न गई हो (जैसे किसी `Boolean` या `enum` की सभी वैल्यू)।
- शर्तों से मिलान करते समय `else` ब्रांच ज़रूरी होती है, क्योंकि कंपाइलर यह नहीं जान सकता कि आपकी शर्तें हर केस को कवर करती हैं।

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
