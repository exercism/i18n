# गेटर और सेटर

गेटर और सेटर ऐसे मेथड हैं जिनकी मदद से आप किसी ऑब्जेक्ट की प्रॉपर्टी की वैल्यू पढ़ और लिख सकते हैं।
Crystal में मैक्रो होते हैं, जिनसे किसी प्रॉपर्टी के लिए गेटर और सेटर बनाना आसान हो जाता है।
मैक्रो कंपाइल के समय कोड बनाने का तरीका हैं, जिसके बारे में आगे मैक्रो कॉन्सेप्ट में बताया जाएगा।

Ruby में ये मेथड `attr_reader`, `attr_writer` और `attr_accessor` मेथड से बनाए जाते हैं, और ऊपर से देखने पर Crystal के तरीके से काफी मिलते-जुलते हैं।
Crystal ने इन्हें `getter`, `setter` और `property` मैक्रो के रूप में बनाया है।

## गेटर

गेटर एक मैक्रो है जो एक ऐसा मेथड बनाता है जो इंस्टेंस वेरिएबल की वैल्यू लौटाता है।
इसका मतलब है कि जब आपको उस इंस्टेंस वेरिएबल की वैल्यू चाहिए (मेथड के अंदर, initialize को छोड़कर), तो अब आपको उसके आगे `@` लिखने की ज़रूरत नहीं है; उसके बजाय आप वह मेथड कॉल कर सकते हैं जिसे गेटर मैक्रो ने बनाया है।

गेटर मैक्रो एक से ज़्यादा इंस्टेंस वेरिएबल भी ले सकता है, बस उनके बीच कॉमा लगाइए।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

जैसा कि आप देख सकते हैं, गेटर इस्तेमाल करने से आपका लिखा कोड कम हो जाता है और पढ़ने में भी आसानी होती है।
साथ ही, Ruby और Crystal में यह अंतर भी है कि Crystal गेटर मैक्रो के आर्गुमेंट के तौर पर वेरिएबल का नाम और सिंबल, दोनों लेता है।
सिंबल के बारे में आगे सिंबल कॉन्सेप्ट में बताया जाएगा।

## सेटर

सेटर एक मैक्रो है जो एक ऐसा मेथड बनाता है जो इंस्टेंस वेरिएबल की वैल्यू सेट करता है।
यह मैक्रो ज़्यादा नहीं दिखता; आम तौर पर इसकी जगह `property` मैक्रो इस्तेमाल किया जाता है।
जो मेथड बनेंगे वे `name_of_method=` जैसे दिखेंगे; यही `=` है जिसकी वजह से प्रॉपर्टी सेट की जा सकती है।

इस मेथड की परिभाषा थोड़ी खास है, क्योंकि मेथड जो आर्गुमेंट लेता है वह `=` चिह्न के बाद आता है।
Crystal में और भी कई खास मेथड इसी सिंटैक्स का इस्तेमाल करते हैं, जैसे `+` मेथड।

गेटर मैक्रो की तरह ही, सेटर बनाने के बाद जब आप इंस्टेंस वेरिएबल की वैल्यू बदलना चाहते हैं, तो आप वह मेथड कॉल कर सकते हैं जिसे सेटर मैक्रो ने बनाया है।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## प्रॉपर्टी

प्रॉपर्टी एक ऐसा मैक्रो है जो किसी इंस्टेंस वेरिएबल के लिए गेटर और सेटर, दोनों बनाता है।

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
