# परिचय

Gleam में रेगुलर एक्सप्रेशन **PCRE** स्पेसिफिकेशन (**P**erl **C**ompatible **R**egular **E**xpressions) का पालन करते हैं, ठीक वैसे ही जैसे Java, JavaScript या Ruby जैसी दूसरी लोकप्रिय भाषाएँ करती हैं।

`gleam/regex` मॉड्यूल रेगुलर एक्सप्रेशन के साथ काम करने के लिए फंक्शन देता है।

~~~~exercism/note
इस अभ्यास में यह मान लिया गया है कि आप रेगुलर एक्सप्रेशन का सिंटैक्स पहले से जानते हैं, जिसमें कैरेक्टर क्लास, क्वांटिफायर, ग्रुप और कैप्चर शामिल हैं।

अगर आपको अपना रेगुलर एक्सप्रेशन ज्ञान ताज़ा करना है, तो इनमें से कोई एक स्रोत देखिए: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/)।
~~~~

रेगुलर एक्सप्रेशन बनाने का सबसे आम तरीका `regex.from_string` फंक्शन का इस्तेमाल करना है।

```gleam
let assert Ok(re) = regex.from_string("test")
```

अगर रेगुलर एक्सप्रेशन का सिंटैक्स अमान्य है, तो `regex.from_string` फंक्शन एक `Error` देता है, इसलिए यहाँ यह पक्का करने के लिए लेट-असर्शन इस्तेमाल किया गया है कि रेगुलर एक्सप्रेशन मान्य हो।

`regex.check` फंक्शन से यह जाँचा जा सकता है कि कोई रेगुलर एक्सप्रेशन किसी स्ट्रिंग से मेल खाता है या नहीं।

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## कैप्चर

अगर आप रेगुलर एक्सप्रेशन की मदद से सबस्ट्रिंग कैप्चर करना चाहते हैं, तो `regex.scan` फंक्शन से मैचों का एक ऐरे लौटाया जा सकता है।

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## मॉडिफायर

किसी रेगुलर एक्सप्रेशन का व्यवहार बदलने के लिए उसे `regex.compile` फंक्शन से बनाइए और उसमें ऑप्शन पास कीजिए।

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
