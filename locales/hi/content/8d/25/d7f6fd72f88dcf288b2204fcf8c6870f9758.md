# निर्देश

इस अभ्यास में आप एक रिमोट कंट्रोल कार के साथ खेलेंगे, जिसे खरीदने के लिए आपने अंत में इतना पैसा बचा लिया है।

कार की बैटरी शुरू में पूरी (100%) रहती है। जब भी आप रिमोट कंट्रोल से कार चलाते हैं, वह 20 मीटर तय करती है और बैटरी का एक प्रतिशत खर्च हो जाता है। कार का उपनाम तब तक पता नहीं चलता जब तक कार बन न जाए।

रिमोट कंट्रोल कार पर एक शानदार LED डिस्प्ले लगा है, जो दो तरह की जानकारी दिखाता है:

- अब तक तय की गई कुल दूरी, जो इस तरह दिखाई जाती है: `"<METERS> meters"`.
- बैटरी का बचा हुआ चार्ज, जो इस तरह दिखाया जाता है: `"Battery at <PERCENTAGE>%"`.

अगर बैटरी 0% पर पहुँच जाए, तो आप कार और नहीं चला सकते, और बैटरी डिस्प्ले पर `"Battery empty"` दिखाई देगा।

## 1. बिल्कुल नई रिमोट कंट्रोल कार बनाइए

एक बिल्कुल नई रिमोट कंट्रोल कार स्ट्रक्चर लौटाने के लिए `RemoteControlCar.new/0` फंक्शन लागू कीजिए:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

स्ट्रक्चर में उपनाम ज़रूरी है, इसलिए ध्यान रखिए कि वैल्यू `new` फंक्शन में शुरू में सेट की जाए, स्ट्रक्चर में नहीं।

## 2. उपनाम के साथ बिल्कुल नई रिमोट कंट्रोल कार बनाइए

दिए गए उपनाम के साथ बिल्कुल नई रिमोट कंट्रोल कार स्ट्रक्चर लौटाने के लिए `RemoteControlCar.new/1` फंक्शन लागू कीजिए:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. दूरी प्रदर्शित कीजिए

LED डिस्प्ले पर दिखाई जाने वाली दूरी लौटाने के लिए `RemoteControlCar.display_distance/1` फंक्शन लागू कीजिए:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

ध्यान रखिए कि यह फंक्शन आर्गुमेंट के रूप में सिर्फ `RemoteControlCar` स्ट्रक्चर ही स्वीकार करे।

## 4. बैटरी प्रतिशत प्रदर्शित कीजिए

LED डिस्प्ले पर दिखाया जाने वाला बैटरी प्रतिशत लौटाने के लिए `RemoteControlCar.display_battery/1` फंक्शन लागू कीजिए:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

ध्यान रखिए कि यह फंक्शन आर्गुमेंट के रूप में सिर्फ `RemoteControlCar` स्ट्रक्चर ही स्वीकार करे। अगर बैटरी 0% पर हो, तो बैटरी डिस्प्ले पर "Battery empty" दिखाई देगा।

## 5. चलाने से बैटरी और तय की गई दूरी बदलती है

ऐसा `RemoteControlCar.drive/1` फंक्शन लागू कीजिए जो:

- तय किए गए मीटरों की संख्या में 20 जोड़ता है
- बैटरी का 1% खर्च करता है

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

ध्यान रखिए कि यह फंक्शन आर्गुमेंट के रूप में सिर्फ `RemoteControlCar` स्ट्रक्चर ही स्वीकार करे।

## 6. बैटरी खत्म हो जाने पर चलाने का ध्यान रखिए

`RemoteControlCar.drive/1` फंक्शन को ऐसे बदलिए कि जब बैटरी खत्म हो (0% पर हो), तो न तय की गई दूरी बढ़े और न बैटरी प्रतिशत घटे:

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
