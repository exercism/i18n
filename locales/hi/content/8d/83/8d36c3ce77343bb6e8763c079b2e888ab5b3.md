# निर्देश

आप पक्षी देखने के बहुत शौकीन हैं और यह हिसाब रखते हैं कि किसी भी दिन आपके बगीचे में कितने पक्षी आए।

अब आपने अपने पक्षी-निरीक्षण को एक नए स्तर पर ले जाने का फैसला किया है और कुछ ऐसे टूल बनाने का भी, जो इस डेटा पर नज़र रखने और उसे सँभालने में आपकी मदद करेंगे।

आपने इस डेटा को पूर्णांकों के ऐरे के रूप में संग्रहीत करने का फैसला किया है।
इस ऐरे की पहली संख्या उन पक्षियों की संख्या है जो आज आपके बगीचे में आए, दूसरी कल आए पक्षियों की, और इसी तरह आगे भी।

```exercism/note
वास्तविक दुनिया के अनुप्रयोगों में, जहाँ भी लागू हो, आपको हमेशा कोर मॉड्यूल का उपयोग करना चाहिए। लेकिन रिकर्शन सीखने के उद्देश्य से इस अभ्यास में `List` के किसी भी फंक्शन का उपयोग न कीजिए।
```

## 1. जाँचिए कि आज कितने पक्षी आए

`today` फंक्शन बनाइए।
यह रोज़ की पक्षी-गिनती का ऐरे लेता है और आज की गिनती लौटाता है।
अगर ऐरे खाली है, तो इसे `Nothing` लौटाना चाहिए, वरना गिनती `Just` में लिपटी होगी।

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. आज की गिनती बढ़ाइए

`incrementDayCount` फंक्शन बनाइए।
यह रोज़ की पक्षी-गिनती का ऐरे लेता है और आज की गिनती 1 से बढ़ा देता है।
अगर ऐरे खाली है, तो `[1]` लौटाइए।

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. जाँचिए कि कोई ऐसा दिन भी था जब कोई पक्षी नहीं आया

`hasDayWithoutBirds` फंक्शन बनाइए।
यह रोज़ की पक्षी-गिनती का ऐरे लेता है।
अगर कम से कम एक ऐसा दिन था जब बगीचे में कोई पक्षी नहीं आया, तो इसे `True` लौटाना चाहिए, वरना `False`।

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. आने वाले पक्षियों की कुल संख्या निकालिए

`total` फंक्शन बनाइए।
यह रोज़ की पक्षी-गिनती का ऐरे लेता है और उन सबकी कुल संख्या लौटाता है जो आपके डेटा इकट्ठा करना शुरू करने के बाद से आपके बगीचे में आए।

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरों से ज़्यादा व्यस्त होते हैं।
व्यस्त दिन वह होता है जब पाँच या उससे अधिक पक्षी आपके बगीचे में आए हों।

`busyDays` फंक्शन बनाइए।
यह रोज़ की पक्षी-गिनती का ऐरे लेता है और व्यस्त दिनों की संख्या लौटाता है।

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
