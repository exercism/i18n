# विवरण

Haxe एक सख्त टाइपिंग वाली भाषा है, लेकिन ज़रूरत पड़ने पर टाइप सिस्टम को तोड़ा जा सकता है। किसी नाम को वैल्यू देना ही वेरिएबल घोषित करना कहलाता है। वेरिएबल को दो तरह से घोषित किया जा सकता है: या तो उसका टाइप साफ़-साफ़ बताकर, या [`var` कीवर्ड](var) की मदद से Haxe कंपाइलर से टाइप का अनुमान लगवाकर। इसलिए नीचे दिए गए वेरिएबल घोषित करने के दोनों तरीके एक ही हैं:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

वेरिएबल को अपडेट करने के लिए `=` ऑपरेटर का इस्तेमाल किया जा सकता है:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

जब किसी ऐसी वैल्यू को असाइन करने की कोशिश की जाती है जिसका टाइप वेरिएबल से अलग है, तो कंपाइलर एरर देता है:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Haxe में कोड आमतौर पर एक _फंक्शन_ के अंदर लिखा जाता है, जिसे [_मेथड_](method) भी कहा जाता है। ये फंक्शन पैरामीटर (आर्गुमेंट) ले सकते हैं और `return` कीवर्ड की मदद से वैल्यू लौटा सकते हैं। फंक्शन को `()` सिंटैक्स से कॉल किया जाता है। हर फंक्शन का कोई रिटर्न टाइप होना ज़रूरी है।

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Haxe में स्कोप `{` और `}` अक्षरों के बीच तय होता है।

Haxe में दो तरह के कमेंट होते हैं। एक लाइन के कमेंट से पहले `//` लगाया जाता है, और कई लाइनों वाले कमेंट `/*` और `*/` के बीच लिखे जाते हैं।
