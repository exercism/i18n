# परिचय

सेट एक ऐसा संग्रह है जिसे बदला नहीं जा सकता और जिसका कोई तय क्रम नहीं होता। सेट में हर वैल्यू अलग होती है। सेट के सभी एलिमेंट एक ही टाइप के होने चाहिए।

`gleam/set` मॉड्यूल `Set` टाइप को परिभाषित करता है और सेट के साथ काम करने के लिए फंक्शन देता है।

आप `set.to_list` और `set.from_list` की मदद से ऐरे और सेट को एक-दूसरे में बदल सकते हैं। सेट में एलिमेंट का क्रम तय नहीं होता।

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

आप `set.new`, `set.insert` और `set.delete` की मदद से सेट बना सकते हैं और भर सकते हैं।

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

आप `set.contains` और `set.size` फंक्शन की मदद से यह देख सकते हैं कि सेट में क्या-क्या है।

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

सेट को `set.union` और `set.intersect` की मदद से जोड़ा जा सकता है।

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

आप सेट को फिल्टर कर सकते हैं।

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
