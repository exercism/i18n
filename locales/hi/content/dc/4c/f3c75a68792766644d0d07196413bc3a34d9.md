# परिचय

विकिपीडिया `switch` स्टेटमेंट को ऐसे बताता है: "एक तरह का चयन नियंत्रण तंत्र, जो किसी वेरिएबल या एक्सप्रेशन की वैल्यू को प्रोग्राम के कंट्रोल फ्लो में बदलाव लाने देता है।"

इस तंत्र में ये कीवर्ड शामिल होते हैं: `switch`, `case`, `break` और `default`.

सबसे सरल रूप में यह किसी प्रिमिटिव या स्ट्रिंग एक्सप्रेशन की जाँच करता है और उसकी वैल्यू के आधार पर फैसला लेता है। उदाहरण:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

सबसे उन्नत रूप में यह डाउन कास्टिंग `case <Type> <variable>:` और गार्ड (`when`) का इस्तेमाल करता है।

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
