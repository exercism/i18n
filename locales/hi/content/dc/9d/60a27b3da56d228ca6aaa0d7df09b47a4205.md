# परिचय

कभी-कभी जब कोई फंक्शन बहुत सारे आर्गुमेंट लेता है, तो यह याद रखना मुश्किल हो जाता है कि उन्हें किस क्रम में देना है। पढ़ने में आसानी के लिए Gleam आर्गुमेंट पर नाम का लेबल लगाने की सुविधा देता है।

किसी आर्गुमेंट पर लेबल लगाने के लिए आर्गुमेंट के नाम से पहले लेबल का नाम लिखिए, और दोनों के बीच एक स्पेस छोड़िए।

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

लेबल वाले आर्गुमेंट वाले फंक्शन को कॉल करते समय आर्गुमेंट किसी भी क्रम में दिए जा सकते हैं। `replace` को किए गए ये सारे कॉल एक जैसे हैं:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

लेबल हमेशा वैकल्पिक होते हैं। किसी फंक्शन में लेबल वाले आर्गुमेंट हों, तब भी उसे बिना लेबल के कॉल किया जा सकता है।

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

लेबल वाले आर्गुमेंट वाला फंक्शन बनाते समय पहले लेबल वाले आर्गुमेंट के बाद आने वाले सभी आर्गुमेंट पर भी लेबल लगाना ज़रूरी है।

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
