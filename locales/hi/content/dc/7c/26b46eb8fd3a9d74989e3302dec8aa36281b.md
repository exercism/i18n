# निर्देश परिशिष्ट

## जाँच

टेस्ट कुछ ऑपरेशन एक साथ चलाएँगे।
आपकी कोशिश यह होनी चाहिए कि Account पर होने वाले ऑपरेशन उसे एक सुसंगत स्थिति में छोड़ें।
उदाहरण के लिए, कई गोरूटीन एक ही समय में पैसे जमा और निकाल रहे हों। ऐसा नहीं होना चाहिए कि एक साथ होने वाली दो निकासी बैलेंस को ऋणात्मक बना दें।

अपने कंप्यूटर पर काम करते समय आप जाँच सकते हैं कि आपका कोड कॉन्करेंसी को ठीक से संभालता है और डेटा रेस पैदा नहीं करता। इसके लिए टेस्ट `-race` फ्लैग के साथ चलाइए।

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
