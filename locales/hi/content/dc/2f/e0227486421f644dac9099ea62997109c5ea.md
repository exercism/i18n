# परिचय

JSON **ऐरे** को इस तरह परिभाषित करता है:

> ऐरे वैल्यू का एक क्रमबद्ध संग्रह होता है।
> ऐरे `[` बाएँ ब्रैकेट से शुरू होता है और `]` दाएँ ब्रैकेट पर खत्म होता है।
> वैल्यू को `,` कॉमा से अलग किया जाता है।

ऐरे में _किसी भी तरह की_ JSON वैल्यू शून्य या अधिक हो सकती हैं।
ऐरे के सारे एलिमेंट का एक ही टाइप होना ज़रूरी नहीं है।

## ऐरे बनाना

एलिमेंट को ऐरे में इकट्ठा करने के लिए ब्रैकेट का उपयोग कीजिए।

```jq
[1, 2, 3]
```

किसी _स्ट्रीम_ को ब्रैकेट में लपेटकर उसके एलिमेंट को ऐरे में बदला जा सकता है।

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## आकार

`length` फंक्शन ऐरे में मौजूद एलिमेंट की संख्या लौटाता है।

## इंडेक्सिंग और स्लाइसिंग

ऐरे की इंडेक्सिंग शून्य से शुरू होती है।

ब्रैकेट एक्सप्रेशन की मदद से ऐरे से कोई एलिमेंट निकालिए:
`.[2]` तीसरा एलिमेंट देता है।

ऋणात्मक इंडेक्स ऐरे के अंत से पीछे की ओर गिने जाते हैं:
`.[-1]` आखिरी एलिमेंट देता है, और `.[-2]` अंत से दूसरा।

**स्लाइस** ऐरे का एक छोटा, क्रमागत हिस्सा होता है।
`.[10:15]` इंडेक्स 10 से शुरू करके 5 एलिमेंट लौटाता है। इसमें अंत वाला इंडेक्स _शामिल नहीं_ होता।

कुछ और सुविधाजनक फंक्शन भी हैं:

- `first` पहला एलिमेंट देता है।
- `last` आखिरी एलिमेंट देता है।
- `nth(n)` इंडेक्स `n` पर मौजूद एलिमेंट देता है।

## इटरेशन करना

`jq` में आम इटरेशन के काम के लिए कई फंक्शन मौजूद हैं:

- `map(expr)` एक नया ऐरे लौटाता है, जिसमें `expr` बारी-बारी से हर एलिमेंट पर लागू किया जाता है।

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` एक ऐसा फंक्शन है जो `expr` को किसी _एक वैल्यू_ पर लागू करता है।
  अगर एक्सप्रेशन का परिणाम सही होता है, तो वह वैल्यू लौटा दी जाती है।
  अगर परिणाम गलत होता है, तो _कुछ भी_ नहीं लौटाया जाता, `null` भी नहीं, बल्कि बिल्कुल कुछ भी नहीं।

  इसे ऐरे पर लागू करने के लिए `map` के साथ जोड़िए।

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  दूसरा तरीका: `select` को किसी _स्ट्रीम_ पर लागू कीजिए और परिणाम इकट्ठा कर लीजिए।

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` और `all(condition)` एक बूलियन वैल्यू लौटाते हैं, जो बताती है कि ऐरे के कोई भी या सारे एलिमेंट उस शर्त को पूरा करते हैं या नहीं।

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
