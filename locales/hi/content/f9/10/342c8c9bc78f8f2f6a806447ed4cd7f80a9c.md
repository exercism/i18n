# परिचय

एक *क्वोटेशन* `[ ]` ब्रैकेट के अंदर लिखा गया कोड का एक टुकड़ा होता है। यह एक वैल्यू है: आप इसे स्टैक पर डाल सकते हैं, किसी दूसरे वर्ड को दे सकते हैं, या किसी ऐरे में रख सकते हैं।

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

ज़्यादातर हायर-ऑर्डर वर्ड अपने दूसरे आर्गुमेंट के रूप में एक क्वोटेशन लेते हैं:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

क्वोटेशन के अंदर का कोड बस आम Factor कोड होता है, यानी वही ऑपरेटर और स्टैक इफ़ेक्ट जो आप हर जगह इस्तेमाल करते हैं।

जब आप डेटा से कोड बनाते हैं, यानी टुकड़ों को जोड़ते हैं या टोकन को ऑपरेशन से जोड़ते हैं, तो परिणाम एक सीक्वेंस होता है। उसे कॉल करने योग्य बनाने के लिए `>quotation` में से गुज़ारिए:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
