# निर्देश

जिस दिन का आपको बहुत समय से इंतज़ार था, वह अंततः आ गया। अब आप आल्प्स में एक सुंदर खेत के गर्वित मालिक हैं।

आपको अब भी सुबह जल्दी उठकर अपनी गायों को चारा खिलाना पसंद नहीं है।
चूँकि आप एक बेहतरीन इंजीनियर हैं, इसलिए आप एक फूड डिस्पेंसर बनाते हैं, जिसका नाम `FEED-M-ALL` है।

अपना प्रोजेक्ट पूरा करने के लिए अब बस एक चीज़ बाकी है: ऐसा कोड जो हिसाब लगाए कि हर गाय को कितना चारा मिलना चाहिए।
यह ज़रूरी है कि हर गाय को बराबर मात्रा मिले, इसलिए झगड़ों से बचना होगा।
गायें बहुत संवेदनशील होती हैं।

अच्छी बात है कि चारे की मात्रा निकालने के सारे सूत्र आपको खुद नहीं बनाने पड़ेंगे।
इंटरनेट पर आपको एक रहस्यमयी बाहरी लाइब्रेरी मिली है, जिसका आप इस्तेमाल करते हैं।
माना जाता है कि इससे गायें सबसे खुश रहेंगी।
यह लाइब्रेरी एक टाइप देती है जो नीचे दिया गया इंटरफेस पूरा करता है।
जो कोड आप खुद लिखेंगे, उसमें आप इसी पर निर्भर रहेंगे।

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

जैसे-जैसे आप अपने कोड पर काम करेंगे, आप एरर हैंडलिंग को बेहतर बनाएँगे, ताकि जब आप इसका इस्तेमाल रोज़ के खेत के काम में करें, तब यह ज़्यादा मज़बूत रहे और इसे डीबग करना आसान हो।

## 1. भोजन बराबर बाँटिए

सबसे पहले आप वह कोड लिखने पर ध्यान देते हैं, जो हर गाय के लिए चारे की मात्रा निकालने के लिए ज़रूरी है।

ऐसा फंक्शन `DivideFood` बनाइए जो आर्गुमेंट के तौर पर एक `FodderCalculator` और गायों की संख्या (पूर्णांक) लेता है।
*इस काम के लिए यह मान लीजिए कि दी गई गायों की संख्या हमेशा शून्य से अधिक होती है।*
फंक्शन को हर गाय के लिए भोजन की मात्रा `float64` के रूप में लौटानी चाहिए, और अगर कोई एरर आई हो तो वह एरर भी लौटानी चाहिए।

गणना करने के लिए सबसे पहले आपको सारी गायों के लिए कुल चारे की मात्रा पता करनी होगी।
यह काम `FodderAmount` मेथड को कॉल करके और उसमें गायों की संख्या भेजकर किया जाता है।
इसके अलावा आपको एक फैक्टर चाहिए, जिससे इस मात्रा को गुणा करना है।
यह फैक्टर आपको `FatteningFactor` मेथड को कॉल करके मिलता है।
इन दोनों वैल्यू और गायों की संख्या की मदद से अब आप हर गाय के लिए भोजन की मात्रा निकाल सकते हैं (`float64` के रूप में)।
यही वैल्यू `DivideFood` फंक्शन से लौटाई जानी चाहिए।

अगर आपके कॉल किए गए मेथड में से कोई एक एरर लौटाता है, तो आगे का कोड चलना रुक जाना चाहिए और वही एरर `DivideFood` फंक्शन से (जैसी है वैसी) लौटाई जानी चाहिए।

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. गायों की संख्या जाँचिए

ऊपर दिए पहले काम पर काम करते समय आपको पता चला कि जिस बाहरी लाइब्रेरी का आप इस्तेमाल करते हैं, वह उतनी अच्छी नहीं है जितना आपने सोचा था।
उदाहरण के लिए, वह गलत इनपुट को ठीक से संभाल नहीं पाती।
आप इस कमी को दूर करने के लिए अपने कोड में इनपुट वैल्यू की जाँच जोड़ना चाहते हैं।

ऐसा फंक्शन `ValidateInputAndDivideFood` लिखिए, जिसका सिग्नेचर ऊपर दिए `DivideFood` जैसा ही हो।

- अगर दी गई गायों की संख्या 0 से अधिक है, तो फंक्शन को `DivideFood` को कॉल करना चाहिए और उस कॉल का परिणाम लौटाना चाहिए।
- अगर गायों की संख्या 0 या उससे कम है, तो फंक्शन को `"invalid number of cows"` संदेश वाली एरर लौटानी चाहिए।

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. एरर हैंडलिंग बेहतर कीजिए

गायों की संख्या आगे भेजने से पहले जाँच लेना अच्छा कदम था, लेकिन यह अस्पष्ट एरर संदेश आपको ज़्यादा अच्छा नहीं लगा।
आपने सोचा कि इसे बेहतर बनाएँ, और एक कस्टम एरर टाइप बनाया जिसका नाम `InvalidCowsError` है।

इस कस्टम एरर में गायों की संख्या (`int`) और एक कस्टम संदेश (`string`) रखा जाना चाहिए, और `Error` मेथड को डेटा को इस तरह सीरियलाइज़ करना चाहिए:

```txt
{number of cows} cows are invalid: {custom message}
```

अपनी कस्टम एरर तैयार होने के बाद ऐसा फंक्शन `ValidateNumberOfCows` बनाइए जो गायों की संख्या पूर्णांक के रूप में लेता है और एक एरर (या nil) लौटाता है।

- अगर गायों की संख्या 0 से कम है, तो फंक्शन एक `InvalidCowsError` लौटाता है जिसमें कस्टम संदेश `"there are no negative cows"` रखा गया हो।
- अगर गायों की संख्या 0 है, तो फंक्शन एक `InvalidCowsError` लौटाता है जिसमें कस्टम संदेश `"no cows don't need food"` रखा गया हो।
- बाकी मामलों में फंक्शन `nil` लौटाता है, यह बताने के लिए कि जाँच सफल रही।

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

इस वैलिडेशन फंक्शन को बनाने की मेहनत के बाद आपको ध्यान आता है कि अब शाम हो चुकी है, और आप अपनी डेस्क छोड़कर पहाड़ों पर सूरज ढलने का नज़ारा देखने चले जाते हैं।
नए वैलिडेशन फंक्शन को वास्तव में अपने कोड में जोड़ने का काम आप किसी और दिन के लिए छोड़ देते हैं।
