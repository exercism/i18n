# विवरण

बूलियन एक्सप्रेशन एक सवाल है, जो एक या अधिक वैल्यू से पूछा जाता है और जिसका जवाब `true` या `false` में दिया जा सकता है।
जो एक्सप्रेशन सही होता है वह `1` लौटाता है, और जो एक्सप्रेशन गलत होता है वह `0` लौटाता है।
इसके अलावा, संख्याओं की भी सही या गलत वैल्यू होती है। शून्य `false` होता है, और शून्य के अलावा कोई भी संख्या `true` होती है।

पुराने C कोड में या तो बूलियन वैल्यू के लिए सीधे `int` टाइप इस्तेमाल होता था, या प्रोग्रामर ने `TRUE` और `FALSE` जैसे स्थिरांक बना लिए होते थे, जो `1` और `0` को बूलियन रूप में मैप करते थे।

C99 वर्शन के साथ `_Bool` टाइप जोड़ा गया।
`stdbool.h` हेडर फाइल तीन नए बूलियन प्रतीक परिभाषित करती है: `bool`, `true` और `false`.
`true` `1` पर मैप होता है, `false` `0` पर, और `bool` `_Bool` पर।
तो अब प्रोग्रामर सीधे `int` इस्तेमाल करने या अपनी खुद की बूलियन मैपिंग बनाने के बजाय `stdbool.h` शामिल कर सकते हैं और अपने कोड में अपने आप बूलियन प्रतीक पा सकते हैं।

## तुलना ऑपरेटर

C छह तुलना ऑपरेटर का समर्थन करती है: `==` (बराबर), `!=` (बराबर नहीं), `>` (से बड़ा), `<` (से छोटा), `>=` (से बड़ा या बराबर), `<=` (से छोटा या बराबर)।
ये ऑपरेटर वैल्यू के बीच के संबंध की तुलना करते हैं और उन्हें बूलियन वैल्यू में बदल देते हैं।

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## बूलियन ऑपरेटर

C तीन बूलियन ऑपरेटर का समर्थन करती है: `||` (या), `&&` (और), और `!` (नहीं)।

`!` एक ऑपरेंड के साथ इस्तेमाल होता है।
यह ऑपरेंड की बूलियन वैल्यू को उलट देता है।
जैसे `0` तो `false` है, लेकिन `!0` `true` है।

`||` और `&&` दो ऑपरेंड के साथ इस्तेमाल होते हैं।
दाएँ वाले ऑपरेंड का मूल्यांकन तभी होता है जब बाएँ वाला ऑपरेंड एक्सप्रेशन का परिणाम पहले ही तय न कर चुका हो।
यानी `||` अपने दाएँ वाले ऑपरेंड का मूल्यांकन तभी करता है जब उसके बाएँ वाले ऑपरेंड का मूल्यांकन `false` हो.
`&&` अपने दाएँ वाले ऑपरेंड का मूल्यांकन तभी करता है जब उसके बाएँ वाले ऑपरेंड का मूल्यांकन `true` हो.


## शॉर्ट-सर्किटिंग

सारे ऑपरेंड का मूल्यांकन न करना शॉर्ट-सर्किटिंग कहलाता है।
शॉर्ट-सर्किटिंग कुछ खास स्थितियों को सँभालने का एक संक्षिप्त और शक्तिशाली तरीका है।
जैसे एक आम तरीका यह है कि पहले जाँचा जाए कि कोई पॉइंटर `NULL` नहीं है, और (&&) अगर वह `NULL` नहीं है, तो उस पॉइंटर को डीरेफरेंस किया जाए। इस तरह `NULL` पॉइंटर को डीरेफरेंस करने से बचा जाता है।
लेकिन शॉर्ट-सर्किटिंग से बग भी पैदा हो सकते हैं।
कभी-कभी प्रोग्रामर भूल जाता है कि `||` या `&&` के दाएँ वाले ऑपरेंड का मूल्यांकन हमेशा नहीं भी हो सकता है।
अगर दाएँ वाला ऑपरेंड ऐसा एक्सप्रेशन है जिसका साइड इफेक्ट हमेशा होना चाहिए, तो बाएँ वाले ऑपरेंड की बूलियन वैल्यू पर निर्भर करेगा कि यह बग बनेगा या नहीं।


## बूलियन एक्सप्रेशन लौटाना

बूलियन एक्सप्रेशन का परिणाम सीधे लौटाया जा सकता है।
जैसे, यह `if` स्टेटमेंट

```c
if (count > 0)
    return true;
else
    return false;
end
```

इसकी जगह यह लिखा जा सकता है

```c
return count > 0;
```
