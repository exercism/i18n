# परिचय

किसी वैल्यू की _अनुपस्थिति_ बताने के लिए `null` वैल्यू का उपयोग किया जाता है। **नल योग्य** टाइप ऐसा टाइप होता है जिसमें कोई वेरिएबल `null` वैल्यू ले सकता है। किसी भी टाइप को नल योग्य बनाने के लिए हम उसे `Null<T>` में लपेट देते हैं:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

कोई वैल्यू इस समय `null` है या नहीं, यह जाँचने के लिए बस एक `if` एक्सप्रेशन इस्तेमाल कीजिए:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
