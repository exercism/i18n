# संख्याएँ

`INT` Sather में पूर्ण संख्याओं का टाइप है: `0`, `7`, `-3`. जो रूटीन पूर्ण संख्या लौटाता है, वह कोलन के बाद यह बताता है, ठीक उसी तरह जैसे टेक्स्ट लौटाने वाला रूटीन `STR` बताता है।

```sather
   goals : INT is
      return 42;
   end;
```

रूटीन **आर्गुमेंट** ले सकते हैं, यानी वे वैल्यू जो रूटीन को कॉल करते समय दी जाती हैं। हर आर्गुमेंट का एक नाम रखा जाता है और उसे एक टाइप दिया जाता है, जो रूटीन के नाम के बाद ब्रैकेट में लिखा जाता है:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

जब दो आर्गुमेंट का टाइप एक जैसा हो, तो आप उन्हें एक साथ नाम दे सकते हैं:

```sather
   total(first, second : INT) : INT is
```

इसे कॉल करने के लिए वैल्यू को ब्रैकेट में रखिए:

```sather
SCORES::total(3, 4)     -- this is 7
```

पाँच अंकगणितीय ऑपरेटर हैं `+`, `-`, `*`, `/` और `%`.

दो `INT` पर लगाया गया `/` **पूर्णांक विभाजन** करता है: वह भिन्न देने के बजाय शेषफल हटा देता है।

```sather
7 / 2      -- 3, not 3.5
```

`%` उस विभाजन से बचा हुआ भाग देता है।

```sather
7 % 2      -- 1
```

दोनों आपस में जुड़े हैं: `7` में `2` ठीक `3` बार जाता है और `1` बच जाता है।
