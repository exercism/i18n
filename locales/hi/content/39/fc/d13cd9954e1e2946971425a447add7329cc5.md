# परिचय

जब किसी प्रोग्राम या कोड में कुछ गलत या अनपेक्षित होता है, तो उसे बताने के लिए एरर काम आती हैं।

ये JavaScript ऑब्जेक्ट हैं।

इस ऑब्जेक्ट की मुख्य प्रॉपर्टी `message` है:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw` सिंटैक्स का उपयोग करके आप एरर थ्रो कर सकते हैं।

```javascript
throw new Error('Oops');
```

जब कोई `Error` थ्रो होता है, तो मौजूदा एक्ज़ीक्यूशन वहीं रुक जाता है और कॉल स्टैक के पहले catch ब्लॉक से आगे बढ़ता है।

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

JavaScript की किसी भी क्लास की तरह, सबक्लास `extends` कीवर्ड का उपयोग करके `Error` से इनहेरिट करके कस्टम एरर बना सकती हैं।
`instanceof` सिंटैक्स यह जाँचता है कि पकड़ी गई एरर `Error` के किसी खास सबक्लास का इंस्टेंस है या नहीं।

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
