# टेस्ट

## टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
make
```

## अभ्यास हल करना

किसी अभ्यास को हल करने का मतलब है कि उसके सारे टेस्ट पास हों।
डिफॉल्ट रूप से, जब आप टेस्ट चलाते हैं, तो केवल एक टेस्ट (पहला टेस्ट) चलाया जाता है।
यह जानबूझकर ऐसा है, ताकि आप सिर्फ उसी एक टेस्ट को पास कराने पर ध्यान दे सकें।
एक बार वह पास हो जाए, तो आप `TEST_IGNORE()` लाइन हटाकर अगला टेस्ट चालू कर सकते हैं।
जब सारे टेस्ट चालू हो जाएँ और आपका कोड उन सबको पास करा दे, तो आपने अभ्यास हल कर लिया होगा!
