# निर्देश

आपके एक दोस्त की **Gross Store** नाम की एक पुरानी थोक की दुकान है।

यह नाम उस मात्रा से पड़ा है जिसमें यह दुकान चीज़ें बेचती है: यहाँ सब कुछ [ग्रॉस इकाई][gross-unit] में है।

आपके दोस्त ने आपसे उसकी दुकान के लिए एक पॉइंट ऑफ़ सेल (POS) सिस्टम बनाने को कहा है।

**सबसे पहले आप इसके लिए एक प्रोटोटाइप बनाना चाहते हैं।**

**आपके प्रोटोटाइप में आपका सिस्टम सिर्फ मात्रा दर्ज करेगा।**

आपकी मदद के लिए आपके दोस्त ने आपको मापों की एक सूची दी है:

| इकाई              | अंक   |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. अपने प्रोग्राम में माप की इकाई संग्रहीत कीजिए

माप का उपयोग करने के लिए आपको उस माप को अपने प्रोग्राम में संग्रहीत करना होगा।

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. ग्राहक का नया बिल बनाइए

आपको एक ऐसा फंक्शन बनाना है जो ग्राहक के लिए एक नया (खाली) बिल बनाता है।

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. ग्राहक के बिल में चीज़ जोड़िए

इसे बनाने के लिए आपको यह करना होगा:

- अगर दिया गया `unit` `units` मैप में नहीं है, तो `false` लौटाइए।
- वरना उस चीज़ को ग्राहक के `bill` में जोड़िए, चीज़ के नाम से इंडेक्स करके, और फिर `true` लौटाइए।
- अगर वह चीज़ बिल में पहले से मौजूद है, तो उसकी मात्रा उतनी बढ़ाइए जितनी दिए गए `unit` की है।

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> ध्यान दीजिए कि लौटाई गई वैल्यू का टाइप `bool` है।

## 4. ग्राहक के बिल से चीज़ हटाइए

इसे बनाने के लिए आपको यह करना होगा:

- अगर दी गई चीज़ बिल में **नहीं** है, तो `false` लौटाइए।
अगर किसी चीज़ की मात्रा 0 है, तो माना जाता है कि वह बिल में नहीं है।
- अगर दिया गया `unit` `units` मैप में नहीं है, तो `false` लौटाइए।
- अगर नई मात्रा 0 से कम हो जाए, तो `false` लौटाइए।
- अगर नई मात्रा 0 है, तो माना जाता है कि वह चीज़ `bill` से हट गई है, इसलिए आप `true` लौटा सकते हैं।
- वरना उस चीज़ की मात्रा घटाइए और `true` लौटाइए।

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> ध्यान दीजिए कि लौटाई गई वैल्यू का टाइप `bool` है।

## 5. ग्राहक के बिल में मौजूद किसी खास चीज़ की मात्रा लौटाइए

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> ध्यान दीजिए कि लौटाई गई वैल्यू का टाइप `u32` है।
