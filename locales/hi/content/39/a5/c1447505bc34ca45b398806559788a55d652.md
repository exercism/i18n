# परिचय

R में `list` एलिमेंट का एक क्रमबद्ध संग्रह होता है, जो `vectors` से कुछ मामलों में अलग होता है:

- एलिमेंट अलग-अलग टाइप के हो सकते हैं (जैसे `numeric` को `character` के साथ मिलाना)।
- एलिमेंट जटिल संरचनाएँ भी हो सकते हैं (जैसे वेक्टर, दूसरे ऐरे, आदि)।
- एलिमेंट तक पहुँचने के लिए सिंटैक्स थोड़ा अलग होता है।

दूसरी भाषाओं से तुलना करना सटीक नहीं होता।
R का `list` कुछ-कुछ Python की डिक्शनरी जैसा होता है, लेकिन `list` क्रमबद्ध रहता है और इसके एलिमेंट तक संख्या वाले इंडेक्स से पहुँचा जा सकता है।
यह C के `struct` से भी कुछ-कुछ मिलता-जुलता है, बस फर्क यह है कि `list` को प्रोग्राम चलते समय आसानी से बढ़ाया जा सकता है।

## ऐरे बनाना

एलिमेंट को नाम देना (जिन्हें अक्सर "टैग" कहा जाता है) वेक्टर की तुलना में ऐरे में ज़्यादा आम है:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

लेकिन टैग देना ज़रूरी नहीं है, और ऐसी स्थिति में R सिर्फ इंडेक्स की संख्याएँ इस्तेमाल करता है:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## ऐरे के एलिमेंट तक पहुँचना

यह करने के तीन तरीके हैं, और हर तरीका अलग-अलग स्थितियों में काम आता है।

### 1. `$tag` नोटेशन के ज़रिए

अगर टैग के नाम पहले से पता हों तो यह तरीका बहुत आम है।

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]` नोटेशन के ज़रिए

इसका फायदा यह है कि टैग का नाम प्रोग्राम चलते समय चुना जा सकता है।
ध्यान दीजिए, यहाँ ब्रैकेट दोहरे हैं।

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. इंडेक्स के ज़रिए

यह तरीका तब भी काम करता है जब ऐरे में टैग हों या न हों।
यहाँ भी ब्रैकेट दोहरे लगते हैं।

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## एलिमेंट जोड़ना और हटाना

यह आसान है: किसी एलिमेंट को असाइन करने पर, अगर वह पहले से मौजूद है तो बदल जाता है, और अगर नया है तो जुड़ जाता है।

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

हटाने के लिए, जिस एलिमेंट को हटाना है उसे `NULL` असाइन कीजिए।

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
