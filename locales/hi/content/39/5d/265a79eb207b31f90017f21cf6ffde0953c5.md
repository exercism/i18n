# परिचय

Gleam में ऐरे शून्य या उससे अधिक वैल्यूओं का एक अपरिवर्तनीय संग्रह होता है। ऐरे की सभी वैल्यूओं का टाइप एक ही होना चाहिए। चूँकि ऐरे अपरिवर्तनीय होते हैं, इसलिए एक बार ऐरे बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती। जो भी फंक्शन या ऑपरेटर ऐरे को बदलते हुए दिखते हैं (जैसे कोई एलिमेंट जोड़ना), वे वास्तव में एक नया ऐरे लौटाते हैं।

ऐरे इस तरह बनाए जा सकते हैं:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

ऐरे में एलिमेंट जोड़ने का सबसे आम तरीका स्प्रेड सिंटैक्स है:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam की स्टैंडर्ड लाइब्रेरी में मौजूद [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) मॉड्यूल में ऐरे के साथ काम करने के लिए कई उपयोगी फंक्शन हैं। Gleam के कोड में इस मॉड्यूल का बहुत इस्तेमाल होता है, इसलिए इससे परिचित होना अच्छा है।

`case` एक्सप्रेशन में पैटर्न की मदद से ऐरे से मिलान करके उनके अंदर की वैल्यूओं को वेरिएबलो में असाइन किया जा सकता है:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

सटीक लंबाई वाले ऐरे से मिलान करने के अलावा, स्प्रेड सिंटैक्स की मदद से कम से कम एक तय लंबाई वाले ऐरे से भी मिलान किया जा सकता है:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

स्प्रेड सिंटैक्स की मदद से ऐरे के बाकी हिस्से को एक वेरिएबल में असाइन भी किया जा सकता है:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

`case` एक्सप्रेशन में उस टाइप की हर संभव वैल्यू के लिए एक पैटर्न होना चाहिए, इसलिए बची हुई वैल्यूओं को संभालने के लिए अंत में अक्सर एक डिस्कार्ड पैटर्न (`_`) इस्तेमाल किया जाता है।
