# टपल

Elm में टपल दो या तीन वैल्यू रख सकते हैं, और हर वैल्यू किसी भी टाइप की हो सकती है।
Elm में टपल ज़्यादातर साधारण, अस्थायी टाइप के लिए इस्तेमाल किए जाते हैं।
इसी वजह से टपल में अधिकतम 3 वैल्यू ही हो सकती हैं, और इस बात को और प्रोत्साहित करने के लिए सुविधा वाले फंक्शन सिर्फ 2 वैल्यू के लिए दिए गए हैं।
ज़्यादा जटिल डेटा के लिए रिकॉर्ड इस्तेमाल करना बेहतर है।
इसका एक आम उपयोग तब होता है जब आपको किसी फंक्शन से एक से ज़्यादा वैल्यू लौटानी हों।
टपल के फील्ड के नाम नहीं होते। उन्हें डीस्ट्रक्चरिंग के ज़रिए या उनके स्थान के ज़रिए एक्सेस किया जाता है।

आप [टपल का संक्षिप्त परिचय][tuples-concise] पढ़ सकते हैं।
इसके अलावा एक [और विस्तृत परिचय][tuples-in-depth] भी है, और [Tuple मॉड्यूल के API दस्तावेज़][tuple-core] में कोड के उदाहरण और विस्तृत जानकारी दी गई है।

## घोषणा

टपल के टाइप गोल ब्रैकेट के साथ बनाए जाते हैं, और उनके एलिमेंट टाइप अल्पविराम से अलग किए जाते हैं।

```elm
type alias IntStringTuple = (Int, String)
```

### बनाना

टपल गोल ब्रैकेट के साथ बनाए जाते हैं, और उनके एलिमेंट अल्पविराम से अलग किए जाते हैं।

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

दो वैल्यू वाला टपल बनाने के लिए आप `Tuple.pair` का भी इस्तेमाल कर सकते हैं।

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### एक्सेस

टपल की वैल्यू को उनके स्थान के ज़रिए एक्सेस करने वाले फंक्शन भी हैं: `Tuple.first` और `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

टपल को बाइंडिंग में टपल पैटर्न मैचिंग की मदद से _डीस्ट्रक्चर_ किया जा सकता है।
डीस्ट्रक्चरिंग let एक्सप्रेशन, फंक्शन की घोषणा और case स्टेटमेंट में की जा सकती है।

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

case स्टेटमेंट में पैटर्न मैचिंग की मदद से आप वैल्यू के अंदर मौजूद चीज़ों से भी मैच कर सकते हैं:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
