# परिचय

PHP में कई बिल्ट-इन लूपिंग कंट्रोल स्ट्रक्चर हैं, जैसे `while`। `while` स्टेटमेंट का बुनियादी रूप यह है:

```php
while (expr) {
  // statements
}
```

जब तक एक्सप्रेशन (_expr_) की वैल्यू _ट्रुथी_ होती है, तब तक `while` स्टेटमेंट लूप के अंदर के स्टेटमेंट पर इटरेशन करता है। अगर पहले इटरेशन से पहले ही एक्सप्रेशन (_expr_) की वैल्यू गलत हो, तो लूप के अंदर के स्टेटमेंट कभी नहीं चलाए जाते।

आप चाहें तो `do-while` लूप भी इस्तेमाल कर सकते हैं, जो एक्सप्रेशन (_expr_) का मूल्यांकन करने से पहले लूप के स्टेटमेंट एक बार चलाता है।

```php
do {
  // statements
} while (expr);
```
