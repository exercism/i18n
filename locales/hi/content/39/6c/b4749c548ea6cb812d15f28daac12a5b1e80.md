# निर्देश परिशिष्ट

## फंक्शन और टेस्टिंग

आपको `SayHi` फंक्शन की एक शुरुआती परिभाषा दी गई है।

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

टेस्ट रनर इस फंक्शन को लेकर उसे चलाता है और जो वैल्यू यह [लौटाता है][returns], उसकी तुलना उस वैल्यू से करता है जिसकी उसे अपेक्षा है।
इस शुरुआती फंक्शन परिभाषा को अपने हल का आधार बनाइए।

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
