# और जानकारी

## मॉड्यूल

Gleam का कोड मॉड्यूल में बाँटा गया है। हर फाइल एक Gleam मॉड्यूल होती है।

अब तक हमने `pub fn` सिंटैक्स से फंक्शन बनाए हैं, जिससे ऐसा फंक्शन बनता है जो दूसरे मॉड्यूल के लिए भी उपलब्ध रहता है। `fn` से बनाए गए फंक्शन उसी मॉड्यूल तक सीमित रहते हैं जिसमें उन्हें बनाया गया है, और दूसरे मॉड्यूल उन्हें इस्तेमाल नहीं कर सकते।

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam मॉड्यूल के नाम होते हैं, और नाम उसकी `src` या `test` डायरेक्टरी के अंदर वाली फाइल पाथ पर आधारित होता है।

जैसे, `src\geometry\rectangle.gleam` (Windows पर) या `src/geometry/rectangle.gleam` (UNIX जैसे ऑपरेटिंग सिस्टम पर) में बनाए गए मॉड्यूल का नाम `geometry/rectangle` होगा।

## दूसरे मॉड्यूल से फंक्शन इम्पोर्ट करना

दूसरे मॉड्यूल में बनाए गए फंक्शन तक पहुँचने का तरीका इम्पोर्ट है। जब आप किसी मॉड्यूल को इम्पोर्ट करते हैं, तो उसके वे सारे फंक्शन उपलब्ध हो जाते हैं जिन्हें उस मॉड्यूल ने बाहर के लिए खोला है। लेकिन उन्हें कैसे इस्तेमाल किया जाएगा, यह इस पर निर्भर करता है कि मॉड्यूल किस तरह इम्पोर्ट किया गया है।

क्वालिफाइड इम्पोर्ट डिफॉल्ट होते हैं। ऐसे मॉड्यूल के फंक्शन (जैसे `gleam/list` मॉड्यूल का `map` फंक्शन) तक पहुँचने के लिए मॉड्यूल के नाम का प्रीफिक्स लगाया जाता है (`list.map`)।

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

डिफॉल्ट रूप से मॉड्यूल के लिए जो नाम इस्तेमाल होता है वह उसके नाम का अंतिम हिस्सा होता है, यहाँ `int`, लेकिन `as` कीवर्ड से इसे बदला जा सकता है।

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

अनक्वालिफाइड इम्पोर्ट से उस मॉड्यूल के खुले फंक्शन सीधे इस्तेमाल किए जा सकते हैं, बिना प्रीफिक्स लगाए।

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

क्वालिफाइड इम्पोर्ट को प्राथमिकता दी जाती है, क्योंकि इससे पढ़ने वाले को साफ पता चलता है कि फंक्शन कहाँ से आ रहा है, और नाम आपस में टकराने से भी बचाव होता है।
