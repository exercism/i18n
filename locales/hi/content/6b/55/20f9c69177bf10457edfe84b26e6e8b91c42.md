# निर्देश

आपकी टीम एक मौसम विज्ञान एप्लिकेशन पर काम कर रही है।
उन्होंने मौसम संबंधी डेटा दर्शाने वाले अलग-अलग टाइप और कॉन्स्टेंट के साथ एक API परिभाषित किया है। देखिए `meteorology.go` फाइल।

आपका काम सभी टाइप में उपयुक्त `String` मेथड जोड़ना है, ताकि ये `Stringer` इंटरफ़ेस लागू करें।

## 1. `TemperatureUnit` टाइप के लिए `Stringer` इंटरफ़ेस लागू कीजिए

काफी चर्चा के बाद टीम ने तय किया है कि तापमान की इकाई `Celsius` या `Fahrenheit` में से कोई एक होगी।
वैल्यू को नीचे दिए गए उदाहरणों के अनुसार फ़ॉर्मैट किया जाना चाहिए।

`TemperatureUnit` टाइप में एक `String` मेथड जोड़िए ताकि वह `Stringer` इंटरफ़ेस लागू करे।
अगर तापमान की इकाई Celsius है तो यह मेथड स्ट्रिंग `"°C"` लौटाना चाहिए, और अगर तापमान की इकाई Fahrenheit है तो `"°F"` लौटाना चाहिए।

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. `Temperature` टाइप के लिए `Stringer` इंटरफ़ेस लागू कीजिए

तापमान की वैल्यू एक पूर्णांक और एक तापमान इकाई से मिलकर बनती हैं।
इन्हें नीचे दिए गए उदाहरणों के अनुसार फ़ॉर्मैट किया जाना चाहिए।

इसके लिए `Temperature` टाइप में एक `String` मेथड जोड़िए ताकि वह `Stringer` इंटरफ़ेस लागू करे।
यह मेथड तापमान की संख्यात्मक वैल्यू और तापमान इकाई को एक स्पेस से अलग करके एक स्ट्रिंग लौटाना चाहिए: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. `SpeedUnit` टाइप के लिए `Stringer` इंटरफ़ेस लागू कीजिए

लंबी चर्चाओं के बाद टीम ने तय किया है कि हवा की गति की इकाई `KmPerHour` या `MilesPerHour` में से कोई एक होगी।
वैल्यू को नीचे दिए गए उदाहरणों के अनुसार फ़ॉर्मैट किया जाना चाहिए।

इसके लिए `SpeedUnit` टाइप में एक `String` मेथड जोड़िए ताकि वह `Stringer` इंटरफ़ेस लागू करे।
अगर गति की इकाई किलोमीटर प्रति घंटा है तो यह मेथड स्ट्रिंग `"km/h"` लौटाना चाहिए, और अगर गति की इकाई मील प्रति घंटा है तो `"mph"` लौटाना चाहिए:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. `Speed` के लिए `Stringer` इंटरफ़ेस लागू कीजिए

हवा की गति की वैल्यू एक पूर्णांक और एक गति इकाई से मिलकर बनती हैं।
इन्हें नीचे दिए गए उदाहरण के अनुसार फ़ॉर्मैट किया जाना चाहिए।

इसके लिए `Speed` टाइप में एक `String` मेथड जोड़िए ताकि वह `Stringer` इंटरफ़ेस लागू करे।
यह मेथड गति की संख्यात्मक वैल्यू और गति इकाई को एक स्पेस से अलग करके एक स्ट्रिंग लौटाना चाहिए: `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. `MeteorologyData` टाइप के लिए `Stringer` इंटरफ़ेस लागू कीजिए

मौसम संबंधी डेटा में स्थान, तापमान, हवा की दिशा, हवा की गति और आर्द्रता दी जाती है।
इसे नीचे दिए गए उदाहरण के अनुसार फ़ॉर्मैट किया जाना चाहिए:

इसके लिए `MeteorologyData` टाइप में एक `String` मेथड जोड़िए ताकि वह `Stringer` इंटरफ़ेस लागू करे।
यह मेथड मौसम संबंधी डेटा को इस फ़ॉर्मैट में लौटाना चाहिए:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
