# निर्देश

इस अभ्यास में आप कुछ उपयोगी रूटीन बनाएँगे जो एक डेवलपर को SqueakyClean नामों को साफ करने में मदद करेंगे।

इन 4 कार्यों में आप धीरे-धीरे `clean` मेथड तैयार करेंगे।
एक मान्य SqueakyClean नाम शून्य या अधिक अक्षरों और अंडरस्कोर से बना होता है।

हर मामले में यह निश्चित है कि इनपुट स्ट्रिंग null नहीं होगी। ध्यान दें कि `clean` मेथड को खाली स्ट्रिंग को भी मान्य मानना चाहिए।

## 1. मिलने वाले सभी स्पेस को अंडरस्कोर से बदलिए

(_static_) `SqueakyClean.clean()` मेथड को इस तरह बनाइए कि वह हर स्पेस को अंडरस्कोर से बदल दे। यह आगे और पीछे के स्पेस पर भी लागू होता है।

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. केबाब-केस को कैमलकेस में बदलिए

(_static_) `SqueakyClean.clean()` मेथड को इस तरह बदलिए कि वह केबाब-केस को कैमलकेस में बदल दे।

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. लीटस्पीक को सामान्य टेक्स्ट में बदलिए

(_static_) `SqueakyClean.clean()` मेथड को इस तरह बदलिए कि वह [लीटस्पीक][leet-speak] को सामान्य टेक्स्ट में बदल दे।

सरलता के लिए हम केवल `4`, `3`, `0`, `1` और `7` को क्रमशः `a`, `e`, `o`, `l` और `t` से बदलेंगे।

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. अक्षरों के अलावा बाकी सब छोड़ दीजिए

(_static_) `SqueakyClean.clean()` मेथड को इस तरह बदलिए कि वह सिर्फ अक्षर रखे और बाकी सब छोड़ दे।

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
