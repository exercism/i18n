# विवरण

F# में बूलियन को `bool` टाइप से दर्शाया जाता है। इस टाइप की वैल्यू या तो `true` हो सकती है या `false`।

F# तीन [बूलियन ऑपरेटर][operators] को सपोर्ट करता है: `not` (नहीं), `&&` (और) और `||` (या)। `&&` और `||` ऑपरेटर _शॉर्ट-सर्किट मूल्यांकन_ का उपयोग करते हैं, जिसका मतलब है कि ऑपरेटर का दायाँ पक्ष केवल तभी मूल्यांकित किया जाता है जब ज़रूरत हो।

```fsharp
true || false // => true
true && false // => false
```

तीनों बूलियन ऑपरेटरों की [_ऑपरेटर प्राथमिकता_][precedence] अलग-अलग होती है। इसका परिणाम यह है कि इनका मूल्यांकन इस क्रम में होता है: पहले `not`, फिर `&&`, और अंत में `||`। अगर आप इन नियमों से 'बचना' चाहते हैं, तो आप किसी बूलियन एक्सप्रेशन को गोल ब्रैकेट (`()`) में लपेट सकते हैं, क्योंकि गोल ब्रैकेट की ऑपरेटर प्राथमिकता और भी ज़्यादा होती है।

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
