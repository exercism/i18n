# निर्देशों का परिशिष्ट

## संकेत

आपको `decode` और `encode` फंक्शन बनाने हैं, जो एफाइन साइफर की मदद से एक `String` को डिकोड और एनकोड करते हैं।
अगर आपको टाइप को लेकर संदेह है, तो आप दिए गए सिग्नेचर का इस्तेमाल कर सकते हैं, लेकिन इसे अपनी रचनात्मकता पर बंधन मत बनने दीजिए।

यह अभ्यास टेक्स्ट डेटा के साथ काम करता है।
ऐतिहासिक कारणों से Haskell का `String` टाइप `[Char]` का समानार्थी है, यानी अक्षरों का एक ऐरे।
टेक्स्ट डेटा को और कुशलता से संभालने के लिए `Text` टाइप का उपयोग किया जा सकता है।

इस अभ्यास के लिए एक वैकल्पिक विस्तार के तौर पर आप यह कर सकते हैं:

- package.yaml में अपनी डिपेंडेंसी की सूची में `- text` जोड़िए।
- `Data.Text` को [इस तरीके से](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) इंपोर्ट कीजिए:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` टाइप का इस्तेमाल कीजिए, जैसे `decode :: Text -> Text`, और `Data.Text` के कॉम्बिनेटर को `T.pack` जैसे नाम से बुलाइए।
- [`Data.Text` का डॉक्युमेंटेशन](https://hackage.haskell.org/package/text/docs/Data-Text.html) देखिए।
- Affine.hs में `String` के सभी प्रयोगों को `Text` से बदल दीजिए, यानी:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

यह हिस्सा पूरी तरह से वैकल्पिक है।
