# परिचय

Gleam में `Iterator` एक ऐरे की तरह होता है, क्योंकि यह भी वैल्यूओं का एक क्रमबद्ध संग्रह होता है, जिन सभी वैल्यूओं का टाइप एक ही होता है। ऐरे से यह अलग इसलिए है क्योंकि यह आलसी होता है, यानी यह अपनी सारी वैल्यूएँ एक साथ मेमोरी में संग्रहीत नहीं करता, बल्कि ज़रूरत पड़ने पर ही उनकी गणना करता है।

बहुत बड़े या अनंत आकार के अनुक्रमों के साथ काम करते समय यह बहुत काम आता है। ऐसे अनुक्रमों को एक साथ संग्रहीत करने के लिए जब हमारे पास पर्याप्त खाली मेमोरी नहीं होती, तब भी इटरेटर की मदद से हम उन पर काम कर पाते हैं।

`gleam/iterator` मॉड्यूल `Iterator` टाइप को परिभाषित करता है, और साथ ही इटरेटर के साथ काम करने वाले फंक्शन भी देता है।

ऐरे के लिए मौजूद कई फंक्शन इटरेटर के लिए भी हैं, जैसे `map`, `filter` और `take`। ये फंक्शन इटरेटर लौटाते हैं, इसलिए जब तक किसी इटरेटर से वैल्यूएँ नहीं निकाली जातीं, तब तक ये असल में कोई काम नहीं करते।

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` फंक्शन की मदद से हम ऐसे फंक्शन से इटरेटर बना सकते हैं जिसे अनुक्रम की अगली वैल्यू बनाने के लिए बार-बार कॉल किया जाता है।

यहाँ `unfold` फंक्शन से एक ऐसा इटरेटर बनाया गया है जो फिबोनाची अनुक्रम बनाता है:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

यहाँ अनुक्रम अनंत है, इसलिए वैल्यूओं को ऐरे में इकट्ठा करने से पहले `take` फंक्शन से इसे सीमित बनाया जाता है। अगर किसी अनंत इटरेटर पर `to_list` कॉल किया जाए, तो प्रोग्राम तब तक चलता रहेगा जब तक उसकी मेमोरी खत्म न हो जाए और वह क्रैश हो जाए।
