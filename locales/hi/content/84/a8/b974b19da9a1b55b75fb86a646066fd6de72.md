# परिचय

Haxe में क्लासों का पदानुक्रम _इनहेरिटेंस_ की मदद से बनाया जा सकता है। इससे एक डिराइव्ड क्लास (`Car`) अपनी पैरेंट क्लास (`Vehicle`) का व्यवहार और डेटा इनहेरिट कर सकती है।

पैरेंट क्लास में आप ये काम कर सकते हैं:

- ऐसे मेथड जिन्हें ओवरराइड किया जा सकता है
- ऐब्स्ट्रैक्ट मेथड, जिन्हें डिराइव्ड क्लासों को लागू करना ही होता है

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

अगर पैरेंट क्लास में कोई कंस्ट्रक्टर है, तो हम उसे कॉल करने के लिए `super()` का इस्तेमाल करते हैं:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
