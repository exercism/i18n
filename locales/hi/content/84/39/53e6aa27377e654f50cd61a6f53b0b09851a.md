# निर्देश

इस अभ्यास में आप हाई स्कूल के प्रेमी जोड़ों को सोशल मीडिया पर अपना प्यार जताने में मदद करेंगे। इसके लिए आप उनके इनिशियल के साथ एक ASCII दिल बनाएँगे:

```
❤ J.  +  M. ❤
```

## 1. नाम को साफ कीजिए

`HighSchoolSweetheart.clean_up_name` मेथड लागू कीजिए।
यह एक नाम लेता है और उसमें से सभी `-` अक्षर हटाकर उनकी जगह एक स्पेस लगाता है।
इसे नाम के शुरू और अंत से कोई भी खाली स्थान भी हटा देना चाहिए।

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. नाम का पहला अक्षर निकालिए

`HighSchoolSweetheart.first_letter` मेथड लागू कीजिए।
यह एक नाम लेता है और उसका पहला अक्षर लौटाता है।
पिछले चरण में आपने जो `HighSchoolSweetheart.clean_up_name` बनाया था, उसका दोबारा इस्तेमाल ज़रूर कीजिए।

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. पहले अक्षर को इनिशियल के रूप में लिखिए

`HighSchoolSweetheart.initial` मेथड लागू कीजिए।
यह एक नाम लेता है और उसका पहला अक्षर बड़ा करके उसके बाद एक बिंदु लगाकर लौटाता है।
पिछले चरण में आपने जो `HighSchoolSweetheart.first_letter` बनाया था, उसका दोबारा इस्तेमाल ज़रूर कीजिए।

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. इनिशियल को दिल के अंदर रखिए

`HighSchoolSweetheart.pair` मेथड लागू कीजिए।
यह दो नाम लेता है और इनिशियल लौटाता है, जिनके दोनों तरफ इमोजी दिल हों।
पिछले चरण में आपने जो `HighSchoolSweetheart.initial` बनाया था, उसका दोबारा इस्तेमाल ज़रूर कीजिए।

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
