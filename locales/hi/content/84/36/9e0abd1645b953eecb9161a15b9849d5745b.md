# मूल बातें

## शुरुआत

### वेरिएबल

किसी [वेरिएबल][variables] को घोषित करने के लिए `=` असाइनमेंट ऑपरेटर का उपयोग कीजिए।
Crystal में वेरिएबलो के नाम [snake_case][snake-case] प्रारूप में लिखे जाते हैं।

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### स्थिरांक

[स्थिरांक][constants] भी उसी `=` असाइनमेंट ऑपरेटर से घोषित किए जाते हैं, लेकिन इनमें सभी अक्षर बड़े होते हैं, जिसे SCREAMING_SNAKE_CASE कहा जाता है।

```crystal
NUMBER = 1
puts NUMBER # => 1
```

पहले से परिभाषित स्थिरांक को वैल्यू असाइन करने पर कंपाइल के समय एरर मिलती है।

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### टाइप

Crystal एक ऐसी भाषा है जिसे कंपाइल किया जाता है। इसका मतलब है कि हर वेरिएबल या मेथड आर्गुमेंट को कंपाइल के समय एक टाइप दिया जाता है।
कंपाइलर किसी वेरिएबल या मेथड आर्गुमेंट का टाइप अनुमान लगा सकता है।
हालाँकि कुछ मामलों में टाइप बताना आवश्यक होता है।
जिन मामलों में टाइप देना आवश्यक होता है, उन्हें आगे के कॉन्सेप्ट में समझाया जाएगा।

### मेथड

[मेथड][methods] निर्देशों के एक समूह को एक साथ रखने का तरीका हैं। इस समूह को बार-बार इस्तेमाल किया जा सकता है।
Crystal में मेथड अक्सर किसी क्लास, मॉड्यूल या स्ट्रक्ट के अंदर बनाए जाते हैं।
लेकिन मेथड किसी क्लास, मॉड्यूल या स्ट्रक्ट के बाहर भी बनाए जा सकते हैं।
मेथड को `def` कीवर्ड से घोषित किया जाता है, और उसके बाद मेथड का नाम लिखा जाता है।
Crystal में मेथड का नाम snake_case में लिखा जाना चाहिए।
जब मेथड में कोई आर्गुमेंट न हो, तो आप ब्रैकेट छोड़ सकते हैं।
मेथड का अंत बताने के लिए आपको `end` कीवर्ड का उपयोग करना होता है।

```crystal
def hello
  puts "Hello World!"
end
```

किसी वेरिएबल या मेथड आर्गुमेंट के टाइप के लिए ऐसा मेथड इस्तेमाल करने पर, जो मौजूद नहीं है, कंपाइल के समय एरर मिलती है।

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### आर्गुमेंट

मेथड में [आर्गुमेंट][arguments] हो सकते हैं।
आर्गुमेंट वह डेटा है जो मेथड को दिया जाता है।
मेथड को आर्गुमेंट दे पाने के लिए आपको आर्गुमेंट का नाम बताना होता है।
Crystal में आर्गुमेंट snake_case में लिखे जाने चाहिए।
एक मेथड में कई आर्गुमेंट हो सकते हैं, लेकिन आर्गुमेंट को कॉमा से अलग किया जाना चाहिए।

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

मेथड में कई आर्गुमेंट भी हो सकते हैं।
ऐसी स्थिति में आर्गुमेंट को कॉमा से अलग करना आवश्यक है।

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### मेथड को कॉल करना

किसी क्लास, मॉड्यूल या स्ट्रक्ट से जुड़े मेथड को कॉल करते समय आपको डॉट ऑपरेटर (`.`) का उपयोग करना होता है।
इसे इस तरह लिखा जाता है: `<ClassName>.<method_name>`.
जब कोई मेथड किसी क्लास, मॉड्यूल या स्ट्रक्ट से नहीं जुड़ा होता, तो आप उसका नाम लिखकर उसे सीधे कॉल कर सकते हैं।
मेथड हमेशा अंतिम एक्सप्रेशन की वैल्यू अपने आप लौटाते हैं।

जब किसी मेथड में आर्गुमेंट हों, तो मेथड को कॉल करते और बनाते समय आर्गुमेंट लिखने के लिए आप ब्रैकेट का उपयोग कर सकते हैं, जैसे: `<method_name>(<argument_1>, <argument_2>, ...)`.
जब किसी मेथड में कोई आर्गुमेंट न हो, तो ब्रैकेट नहीं लिखे जाने चाहिए।

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

कई आर्गुमेंट वाले मेथड को कॉल करते समय आर्गुमेंट को कॉमा से अलग किया जाना चाहिए।
आर्गुमेंट उसी क्रम में देने चाहिए जिस क्रम में मेथड में दिए गए हैं।

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

गलत संख्या में आर्गुमेंट देकर मेथड को कॉल करने पर कंपाइल के समय एरर मिलती है।

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### जोड़, घटाव और गुणा

Crystal में आप दो संख्याओं को जोड़ने के लिए `+` ऑपरेटर का उपयोग कर सकते हैं।
आप दो संख्याओं को घटाने के लिए `-` ऑपरेटर का भी उपयोग कर सकते हैं।
और आप दो संख्याओं को गुणा करने के लिए `*` ऑपरेटर का उपयोग कर सकते हैं।

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### कमेंट

Crystal में [कमेंट][comments] `#` अक्षर से लिखे जाते हैं, उसके बाद एक स्पेस और फिर कमेंट।
कमेंट कोड को समझाने के लिए लिखे जाते हैं।
कंपाइलर कमेंट को चलाता नहीं है।

```crystal
# This is a comment
```
