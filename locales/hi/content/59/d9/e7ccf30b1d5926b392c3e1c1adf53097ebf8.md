# निर्देश

इस अभ्यास में आप "Wizard and Warriors" नाम का एक रोल-प्लेइंग गेम खेल रहे हैं, जिसमें आप विज़ार्ड या वॉरियर, इनमें से कोई भी बनकर खेल सकते हैं।

वॉरियर और विज़ार्ड के लिए अलग-अलग नियम हैं, जो तय करते हैं कि वे कितने डैमेज पॉइंट देते हैं।

वॉरियर के लिए ये नियम हैं:

- अगर हमला किया जा रहा पात्र असुरक्षित नहीं है, तो 6 डैमेज पॉइंट दिए जाते हैं।
- अगर हमला किया जा रहा पात्र असुरक्षित है, तो 10 डैमेज पॉइंट दिए जाते हैं।

विज़ार्ड के लिए ये नियम हैं:

- अगर विज़ार्ड ने पहले से कोई स्पेल तैयार किया है, तो 12 डैमेज पॉइंट दिए जाते हैं।
- अगर विज़ार्ड ने पहले से कोई स्पेल तैयार नहीं किया है, तो 3 डैमेज पॉइंट दिए जाते हैं।

आम तौर पर पात्र कभी असुरक्षित नहीं होते। लेकिन अगर विज़ार्ड ने स्पेल तैयार नहीं किया है, तो वे असुरक्षित होते हैं।

इस अभ्यास में वॉरियर और विज़ार्ड पात्रों से जुड़े छह टास्क हैं।

## 1. पात्र का वर्णन कीजिए

पात्र का वर्णन लौटाने के लिए `Character` क्लास पर `ToString()` मेथड को ओवरराइड कीजिए। यह वर्णन इस फ़ॉर्मैट में होना चाहिए: `"Character is a <CHARACTER_TYPE>"`।

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. पात्रों को डिफ़ॉल्ट रूप से असुरक्षित न रखिए

यह सुनिश्चित कीजिए कि `Character.Vulnerable()` मेथड हमेशा `false` लौटाता है।

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. विज़ार्ड को स्पेल तैयार करने दीजिए

विज़ार्ड को पहले से स्पेल तैयार करने की सुविधा देने के लिए `Wizard.PrepareSpell()` मेथड लागू कीजिए।

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. स्पेल तैयार न होने पर विज़ार्ड को असुरक्षित बनाइए

यह सुनिश्चित कीजिए कि अगर विज़ार्ड ने स्पेल तैयार नहीं किया है, तो `Vulnerable()` मेथड `true` लौटाता है; अगर किया है, तो `false` लौटाता है।

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. विज़ार्ड के डैमेज पॉइंट निकालिए

`Wizard.DamagePoints()` मेथड ऐसा लागू कीजिए जो दिए जाने वाले डैमेज पॉइंट लौटाए: स्पेल तैयार होने पर 12 डैमेज पॉइंट, और न होने पर 3 डैमेज पॉइंट।

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. वॉरियर के डैमेज पॉइंट निकालिए

`Warrior.DamagePoints()` मेथड ऐसा लागू कीजिए जो दिए जाने वाले डैमेज पॉइंट लौटाए: लक्ष्य के असुरक्षित होने पर 10 डैमेज पॉइंट, और न होने पर 6 डैमेज पॉइंट।

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
