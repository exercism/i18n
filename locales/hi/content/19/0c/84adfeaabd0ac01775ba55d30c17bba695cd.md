# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग  | टाइप | विवरण                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | इनपुट     | पता | पहले ऐरे के एलिमेंट                                         |
| `$a1`    | इनपुट     | पूर्णांक | पहले ऐरे का आकार, वर्ड में                                |
| `$a2`    | इनपुट     | पता | दूसरे ऐरे के एलिमेंट                                         |
| `$a3`    | इनपुट     | पूर्णांक | दूसरे ऐरे का आकार, वर्ड में                                |
| `$v0`    | आउटपुट    | पूर्णांक | `0` = बराबर, `1` = असमान, `2` = सबलिस्ट, `3` = सुपरलिस्ट |
| `$t0-9`  | अस्थायी | कोई भी     | अस्थायी भंडारण के लिए इस्तेमाल होता है                                 |
