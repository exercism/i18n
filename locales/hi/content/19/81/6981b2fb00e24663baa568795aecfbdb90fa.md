# परिचय

इनहेरिटेंस क्लासों के बीच पैरेंट-चाइल्ड संबंध बनाने का एक तरीका है।
चाइल्ड क्लास (जिसे कभी-कभी _सबक्लास_ भी कहा जाता है) के पास पैरेंट क्लास (जिसे कभी-कभी _सुपरक्लास_ भी कहा जाता है) द्वारा परिभाषित व्यवहार और डेटा तक पहुँच होती है।

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

चाइल्ड क्लास के डिक्लेरेशन में `extends` कीवर्ड होता है। यह [प्रोटोटाइप चेन][prototype-chain] के ज़रिए पैरेंट क्लास के साथ संबंध बनाता है।

चाइल्ड के कंस्ट्रक्टर से बने ऑब्जेक्ट के प्रोटोटाइप चेन में पैरेंट क्लास का प्रोटोटाइप होता है। इससे पैरेंट द्वारा परिभाषित किसी भी मेथड या डेटा तक पहुँच मिलती है।

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
