# परिचय

## बिट ऐरे

बाइनरी डेटा के साथ काम करना मुश्किल हो सकता है, इसलिए Gleam एक `BitArray` टाइप देता है, और उसके साथ बाइनरी डेटा बनाने तथा उस पर पैटर्न मिलान करने का सिंटैक्स भी।

बिट ऐरे लिटरल `<<>>` सिंटैक्स से लिखे जाते हैं। बिट ऐरे लिटरल लिखते समय उसे सेगमेंट में बाँटा जाता है। हर सेगमेंट में एक वैल्यू और एक एनोटेशन होता है, जिनके बीच `:` लगाया जाता है। एनोटेशन बताता है कि वैल्यू को एनकोड करने के लिए कितने बिट लगेंगे। इसे पूरी तरह छोड़ा भी जा सकता है, और तब अपने आप 8-बिट पूर्णांक वैल्यू मान ली जाती है।

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

टाइप को `:1` लिखना `:size(1)` लिखने का छोटा रूप है। अगर बिट का साइज़ किसी वेरिएबल से आ रहा हो, तो लंबा सिंटैक्स इस्तेमाल करना ज़रूरी है।

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### बाइनरी

बाइनरी पूर्णांक लिटरल लिखते समय हम उन्हें सीधे बेस-2 संकेतन में लिख सकते हैं, बस लिटरल के आगे `0b` लगा दीजिए। ध्यान रखिए कि टेस्ट में या आपके प्रोग्राम में छपने पर ये दशमलव संख्याओं के रूप में प्रदर्शित होंगे।

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### काटना

अगर सेगमेंट की वैल्यू उस सेगमेंट के टाइप की क्षमता से बढ़ जाए, तो वह बाईं ओर से काट दी जाएगी।

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### आगे और पीछे जोड़ना

बिट ऐरे सिंटैक्स की मदद से आप किसी मौजूदा बिट ऐरे के आगे भी जोड़ सकते हैं और पीछे भी। मौजूदा बिट ऐरे के लिए `:bits` एनोटेशन इस्तेमाल करना ज़रूरी है।

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### जोड़ना

वेरिएबलो में रखे बिट ऐरे हम बिट ऐरे सिंटैक्स से जोड़ सकते हैं। अलग-अलग साइज़ के दो बिट ऐरे जोड़ते समय `:bits` एनोटेशन इस्तेमाल करना ज़रूरी है।

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### पैटर्न मिलान

बिट ऐरे से वैल्यू निकालने के लिए पैटर्न मिलान भी किया जा सकता है। जिन-जिन सेगमेंट को आप पकड़ना चाहते हैं, उनमें से हर एक के लिए बिट की संख्या पता होनी चाहिए। इसका एक अपवाद है: किसी अनजान साइज़ के बिट ऐरे पर पैटर्न मिलान के लिए `:bits` एनोटेशन इस्तेमाल किया जा सकता है, लेकिन इसे सिर्फ अंतिम सेगमेंट के लिए ही इस्तेमाल किया जा सकता है।

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### बिट ऐरे को देखना

~~~~exercism/note
बिट ऐरे उस फॉर्मैट से अलग फॉर्मैट में छप सकते हैं जिस फॉर्मैट में उन्हें बनाया गया था। बिट ऐरे सीखते समय यह अक्सर उलझन पैदा करता है।
~~~~

डिफ़ॉल्ट रूप से बिट ऐरे 8 बिट के सेगमेंट में प्रदर्शित होते हैं (यानी एक बाइट), भले ही आपने उन्हें किसी और साइज़ के सेगमेंट में बनाया हो।

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

अगर आप ऐसा बिट ऐरे बनाएँ जो किसी छापने योग्य UTF-8 स्ट्रिंग को दर्शाता है, तो `io.debug` जैसे फंक्शन उसे स्ट्रिंग के रूप में प्रदर्शित कर सकते हैं। यह Gleam के अंदर स्ट्रिंग को दर्शाने के तरीके की एक इम्प्लीमेंटेशन बारीकी की वजह से होता है।

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
