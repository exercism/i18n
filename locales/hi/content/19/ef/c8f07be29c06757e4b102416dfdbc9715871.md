# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जो इस तरह बनी होती है: `"[<LEVEL>]: <MESSAGE>"`।

लॉग लेवल तीन तरह के होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके सामने तीन काम हैं। हर काम में एक लॉग लाइन दी जाएगी और आपको उसके साथ कुछ करना होगा। इन कामों को पूरा करने के कई तरीके हैं। ऊपर दिए गए उदाहरणों में से अपने पसंदीदा मेथड चुनिए और देखिए कि आप क्या कर सकते हैं।

## 1. लॉग लाइन से मैसेज निकालिए

लॉग लाइन का मैसेज लौटाने के लिए `LogLineParser#message` मेथड लागू कीजिए:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

आगे या पीछे का कोई भी व्हाइट स्पेस हटा देना चाहिए:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

लॉग लाइन का लॉग लेवल लौटाने के लिए `LogLineParser#log_level` मेथड लागू कीजिए। यह लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. लॉग लाइन को फिर से फॉर्मेट कीजिए

`LogLineParser#reformat` मेथड लागू कीजिए। यह मेथड लॉग लाइन को नए सिरे से फॉर्मेट करता है: मैसेज पहले रखता है और उसके बाद लॉग लेवल गोल ब्रैकेट में:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
