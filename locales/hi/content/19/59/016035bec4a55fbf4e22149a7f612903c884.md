# परिचय

रिकर्सिव फंक्शन वे फंक्शन होते हैं जो खुद को कॉल करते हैं।

एक रिकर्सिव फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना ज़रूरी है।

_बेस केस_ फंक्शन को दोबारा कॉल किए बिना एक वैल्यू लौटाता है। _रिकर्सिव केस_ फंक्शन को दोबारा कॉल करता है और इनपुट को इस तरह बदलता है कि वह किसी बिंदु पर बेस केस से मेल खाने लगे।

अक्सर हर केस को उसके अपने फंक्शन क्लॉज़ में लिखा जाता है।

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
