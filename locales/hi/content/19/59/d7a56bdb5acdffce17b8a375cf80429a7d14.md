# परिचय

`const` मॉडिफायर को ऐसे हर फील्ड पर लगाया जा सकता है (और सामान्यतः लगाना चाहिए) जिसकी वैल्यू कंपाइल समय पर ज्ञात होती है और प्रोग्राम के जीवनकाल में नहीं बदलती।

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly` मॉडिफायर को ऐसे हर फील्ड पर लगाया जा सकता है (और सामान्यतः लगाना चाहिए) जिसे `const` नहीं बनाया जा सकता। ऐसे फील्ड की वैल्यू प्रोग्राम के जीवनकाल में नहीं बदलती, और वह या तो इनलाइन इनिशलाइज़र सेट करती है या इंस्टैंशिएशन के समय (कंस्ट्रक्टर से, या कंस्ट्रक्टर द्वारा कॉल किए गए किसी मेथड से)।

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
