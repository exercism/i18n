# परिचय

## कमेंट

Common Lisp में प्रोग्रामर ऐसे "कमेंट" लिख सकता है जिन्हें कंप्यूटर अनदेखा कर देता है।
एक लाइन वाले कमेंट एक या अधिक सेमीकोलन (`;`) से शुरू होते हैं, और कभी-कभी आपको यह भी दिख सकता है:

```lisp
(code...) ; => value
```

यहाँ कमेंट यह बताने के लिए लगाया जाता है कि उस लाइन का कोड चलाने के बाद Common Lisp कौन-सी वैल्यू लौटाता है।

किसी लाइन के अंत में छोटा कमेंट लिखने के लिए एक सेमीकोलन लगाना आम बात है, कोड के किसी हिस्से के ऊपर लंबा कमेंट लिखने के लिए दो, फंक्शन जैसी किसी चीज़ का वर्णन करने वाले लंबे कमेंट के लिए तीन, और सोर्स फाइल के ऊपर हेडर जैसे कमेंट के लिए चार।

## कॉन्स

Common Lisp के सभी ऑब्जेक्ट या तो "एटम" होते हैं (अकेली, अविभाज्य वैल्यू) या "कॉन्स" (जो "cons" नाम के फंक्शन से बनते हैं)।
एक कॉन्स दो हिस्सों से बना होता है: पहला एलिमेंट और बाकी के एलिमेंट।
ऐतिहासिक कारणों से इन दोनों हिस्सों को `car` और `cdr` कहा जाता है।
जब इन कॉन्स का कोड की तरह मूल्यांकन किया जाता है, तो पहला एलिमेंट (`car`) उस फंक्शन को दर्शाता है जिसे कॉल किया जा रहा है, और बाकी एलिमेंट (`cdr`) उस फंक्शन के आर्गुमेंट दर्शाते हैं:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## एक्सप्रेशन

Common Lisp का सारा कोड एस-एक्सप्रेशन (सिंबॉलिक एक्सप्रेशन) से बना होता है। इन्हें छोटा करके एसएक्सप्र कहा जाता है। हर एसएक्सप्र या तो एक एटम होता है या एक कॉन्स। जब एस-एक्सप्रेशन का मूल्यांकन होता है, तो वह अपने आप कोई वैल्यू लौटाता है, जो उस एक्सप्रेशन की जगह ले लेती है। जब आप अपने फंक्शन बनाते हैं (`defun` का उपयोग करके), तो `defun` के अंदर की अंतिम वैल्यू अपने आप लौटा दी जाती है:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## सिंबल

Common Lisp में सिंबल खास वैल्यू होते हैं, जो दूसरी वैल्यू की ओर इशारा कर सकते हैं, या _कीवर्ड_ के मामले में खुद की ओर।
जब Lisp सिंबल का मूल्यांकन करता है, तो वे उन वैल्यू से बदल दिए जाते हैं जिनकी ओर वे इशारा करते हैं:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

ध्यान रखिए कि कीवर्ड के आगे कोलन (`:`) लगाया जाता है।

कोट करना, यानी किसी एस-एक्सप्रेशन से पहले `'` लगाना, Lisp को बताता है कि वह उस एक्सप्रेशन का मूल्यांकन न करे।
अपने `defun` वाले उदाहरण में `'foo` को कोट करके हमने Lisp को यह करने से रोक दिया कि वह ढूँढे कि `FOO` किसकी ओर इशारा करता है, और न मिलने पर फेल हो जाए। इसके बजाय Lisp खुद वैल्यू `FOO` लौटाता है।
अगर हमारे प्रोग्राम में `FOO` को कहीं भी परिभाषित नहीं किया गया हो:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

अभी के लिए आप इसे सिर्फ किसी फंक्शन से सिंबल लौटाने का एक तरीका मान सकते हैं, लेकिन हम आगे के कॉन्सेप्ट अभ्यासों में कोट करने पर दोबारा बात करेंगे और इससे जुड़ी बातों को और गहराई से समझेंगे।
