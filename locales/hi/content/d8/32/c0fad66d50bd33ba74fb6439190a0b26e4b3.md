# निर्देश

इस अभ्यास में आप एक रोल-प्लेइंग गेम खेल रहे हैं, जिसमें अलग-अलग तरह के फाइटर एक-दूसरे से लड़ सकते हैं।
हर तरह के फाइटर के लिए गेम के नियम अलग-अलग हैं।
हम दो खास तरहों पर ध्यान देंगे: Wizard और Warrior।

Warrior के लिए ये नियम हैं:

- एक Warrior कभी असुरक्षित नहीं होता।
- अगर वह फाइटर, जिस पर Warrior हमला कर रहा है, असुरक्षित नहीं है, तो Warrior `6` अंक का नुकसान पहुँचाता है।
- अगर वह फाइटर, जिस पर Warrior हमला कर रहा है, असुरक्षित है, तो Warrior `10` अंक का नुकसान पहुँचाता है।

Wizard के लिए ये नियम हैं:

- एक Wizard पहले से एक मंत्र तैयार कर सकता है।
- एक Wizard असुरक्षित होता है, जब तक कि उसने पहले से कोई मंत्र तैयार न किया हो।
- अगर उसने पहले से मंत्र तैयार किया है, तो वह `12` अंक का नुकसान पहुँचाता है।
- अगर उसने पहले से मंत्र तैयार नहीं किया है, तो वह `3` अंक का नुकसान पहुँचाता है।

## 1. Warrior क्लास बनाइए

`Warrior` नाम की एक नई क्लास बनाइए।
यह क्लास मौजूदा `Fighter` क्लास से इनहेरिट करनी चाहिए।

## 2. Warrior का वर्णन कीजिए

`Warrior` क्लास को इस तरह बदलिए कि उसका `toString()` मेथड बताए कि यह किस तरह का फाइटर है।
इस मेथड को `"Fighter is a Warrior"` स्ट्रिंग लौटानी चाहिए।

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Warrior को सुरक्षित बनाइए

`Warrior` क्लास को इस तरह बदलिए कि उसका `isVulnerable()` मेथड हमेशा `false` लौटाए।

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Warrior के लिए नुकसान के अंक निकालिए

`Warrior` क्लास को इस तरह बदलिए कि उसका `getDamagePoints(Fighter)` मेथड ऊपर बताए गए नियमों के अनुसार Warrior द्वारा पहुँचाए जाने वाले नुकसान की गणना करे।

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Wizard क्लास बनाइए

`Wizard` नाम की एक और नई क्लास बनाइए।
यह क्लास भी मौजूदा `Fighter` क्लास से इनहेरिट करनी चाहिए।

## 6. Wizard का वर्णन कीजिए

`Wizard` क्लास को इस तरह बदलिए कि उसका `toString()` मेथड बताए कि यह किस तरह का फाइटर है।
इस मेथड को `"Fighter is a Wizard"` स्ट्रिंग लौटानी चाहिए।

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Wizard को मंत्र तैयार करने दीजिए और मंत्र तैयार न होने पर उसे असुरक्षित बनाइए

`Wizard` क्लास में बदलाव कीजिए और `prepareSpell()` नाम का एक मेथड जोड़िए।
क्लास को याद रखना चाहिए कि यह मेथड कब कॉल किया गया, और यह सुनिश्चित करना चाहिए कि उसका `isVulnerable()` मेथड तभी `false` लौटाए जब कोई मंत्र तैयार हो।

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Wizard के लिए नुकसान के अंक निकालिए

`Wizard` क्लास को इस तरह बदलिए कि उसका `getDamagePoints(Fighter)` मेथड ऊपर बताए गए नियमों के अनुसार Wizard द्वारा पहुँचाए जाने वाले नुकसान की गणना करे।

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
