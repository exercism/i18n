# निर्देश

आप न्यूज़ीलैंड में पैदल यात्रा पर हैं और एक कंपास से बेयरिंग निकाल रहे हैं। बेयरिंग डिग्री में एक पूर्ण संख्या होती है, और वह एक वैल्यू है। 20 डिग्री घूमने से आपने जो बेयरिंग ली थी, वह नहीं बदलती। इससे आपको एक अलग बेयरिंग मिलती है।

एक `immutable class BEARING` लिखिए। स्टब में आपको क्लास हेडर और उसका एट्रिब्यूट दिया गया है।

## 1. बेयरिंग लीजिए

`create` डिग्री की एक संख्या लेता है और बेयरिंग देता है। डिग्री 0 से 359 तक चलती हैं, इसलिए इससे बाहर की कोई भी संख्या घूमकर वापस अंदर आ जाती है: 370 का मतलब 10, और -10 का मतलब 350।

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. घुमाइए

`turned` घूमने की डिग्री की संख्या लेता है और नई बेयरिंग बताता है। ऋणात्मक संख्या से घुमाने पर बेयरिंग दूसरी दिशा में घूम जाती है। जिस बेयरिंग पर इसे कॉल किया गया था वह वैसी की वैसी रहती है।

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. तुलना कीजिए

`is_eq` दूसरी बेयरिंग लेता है और बताता है कि दोनों एक ही हैं या नहीं। जैसे ही यह बन जाता है, `=` बेयरिंगों पर काम करने लगता है।

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. पॉइंट का नाम बताइए

`point` बताता है कि बेयरिंग जिस कंपास पॉइंट के सबसे करीब है वह कौन-सा है, इनमें से एक के रूप में: `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`।

हर पॉइंट 45 डिग्री कवर करता है और अपनी ठीक बेयरिंग पर केंद्रित होता है: उत्तर 337.5 से 0 होते हुए 22.5 तक जाता है, उत्तर-पूर्व 22.5 से 67.5 तक, और इसी तरह आगे भी। चूँकि यहाँ बेयरिंग पूर्ण संख्याएँ हैं, इसलिए 22 की बेयरिंग `"N"` होती है और 23 की `"NE"`।

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. इसे लिखिए

`str` डिग्री और पॉइंट बताता है, जैसे `"90 degrees (E)"`।

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
