# परिचय

Common Lisp में कई तरह के शर्त वाले एक्सप्रेशन मिलते हैं, और इनमें मुख्य अंतर यह है कि ये कितनी शाखाओं का समर्थन करते हैं।

- `when` और `unless` एक ही शाखा की अनुमति देते हैं:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

टेस्ट एक्सप्रेशन के बाद का हिस्सा एक से अधिक एक्सप्रेशन का भी हो सकता है।

- `if` क्लासिक if-then-else ढाँचा देता है:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

ध्यान रखिए कि then और else, दोनों में सिर्फ एक ही एक्सप्रेशन आ सकता है।

- `cond` से कई शाखाएँ बनाई जा सकती हैं, और इसके लिए `if` एक्सप्रेशन को एक के अंदर एक रखने की ज़रूरत नहीं होती:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

ध्यान रखिए कि टेस्ट एक्सप्रेशन के बाद कितने भी एक्सप्रेशन आ सकते हैं।

- `case` क्लासिक 'switch' जैसा ढाँचा देता है: यह एक वैल्यू की तुलना कई शाखाओं से करता है:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

ध्यान रखिए कि `cond` की तरह यहाँ भी टेस्ट एक्सप्रेशन के बाद कितने भी एक्सप्रेशन आ सकते हैं।
