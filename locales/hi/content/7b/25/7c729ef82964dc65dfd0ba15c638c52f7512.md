# परिचय

कस्टम टाइप, Gleam में नए डेटा टाइप बनाने का तरीका है। इनमें एक से ज़्यादा _वैरिएंट_ हो सकते हैं, और हर वैरिएंट का अपना नाम होता है।

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

कस्टम टाइप का हर केस चाहे तो कुछ डेटा भी अपने पास रख सकता है, और अलग-अलग केस अलग-अलग तरह का डेटा रख सकते हैं। जब कोई वैरिएंट डेटा रखता है, तो उसे _रिकॉर्ड_ कहते हैं।

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

किसी खास केस की वैल्यू बनाने के लिए, अगर उसमें कोई अतिरिक्त डेटा नहीं है (`Spring`) तो उसका नाम लिख दीजिए, और अगर डेटा है (`SomeInt(2)`) तो उसे एक फंक्शन की तरह कॉल कीजिए।

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

कस्टम टाइप में, और Gleam की हर दूसरी चीज़ में, _स्ट्रक्चरल इक्वैलिटी_ होती है। इसका मतलब है कि एक ही वैरिएंट की और एक ही डेटा वाली दो वैल्यू बराबर होती हैं।

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

कस्टम टाइप के वैरिएंट पर केस एक्सप्रेशन से पैटर्न मैचिंग की जा सकती है।

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
