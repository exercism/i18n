# is_ के साथ def

Elixir में नाम रखने के कुछ खास नियम हैं, जिनमें [बूलियन लौटाने वाले फंक्शनों के नाम रखने का तरीका](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) भी शामिल है:

> जो फंक्शन बूलियन लौटाते हैं, उनके नाम के अंत में प्रश्नचिह्न लगाया जाता है।

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

ध्यान दीजिए कि गार्ड और कुछ बिल्ट-इन फंक्शन तथा मैक्रो, जो बूलियन लौटाते हैं और गार्ड में मान्य होते हैं, दूसरा नियम अपनाते हैं और उनके नाम के आगे `is_` लगाया जाता है (`def is_integer`, `defguard is_foo`, `defmacro is_foo`)। इन दोनों नियमों को आपस में मिलाना नहीं चाहिए।
