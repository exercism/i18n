# निर्देश परिशिष्ट

## संकेत

आपको `recite` फंक्शन बनाना है, जो 'The Twelve Days of Christmas' के बोल देता है। अगर आपको टाइप को लेकर संदेह है, तो आप दिए गए सिग्नेचर का इस्तेमाल कर सकते हैं, लेकिन इसे अपनी रचनात्मकता को सीमित करने मत दीजिए।

यह अभ्यास टेक्स्ट डेटा के साथ काम करता है। ऐतिहासिक कारणों से, Haskell का `String` टाइप `[Char]` का पर्यायवाची है, जो अक्षरों का ऐरे है। टेक्स्ट डेटा को ज़्यादा कुशलता से संभालने के लिए `Text` टाइप का उपयोग किया जा सकता है।

इस अभ्यास के लिए एक वैकल्पिक विस्तार के रूप में, आप यह कर सकते हैं:

- Haskell में [स्ट्रिंग टाइप](https://haskell-lang.org/tutorial/string-types) के बारे में पढ़िए।
- package.yaml में अपनी डिपेंडेंसी की सूची में `- text` जोड़िए।
- `Data.Text` को [इस तरीके से](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) अपने कोड में लाइए:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- जैसे `recite :: Int -> Int -> [Text]` लिखिए, और `Data.Text` के कॉम्बिनेटर को जैसे `T.pack` लिखकर इस्तेमाल कीजिए।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) का डॉक्युमेंटेशन देखिए।
- TwelveDays.hs में जहाँ भी `String` आया है, उसे `Text` से बदल दीजिए, यानी:

```haskell
recite :: Int -> Int -> [Text]
```

यह हिस्सा पूरी तरह वैकल्पिक है।
