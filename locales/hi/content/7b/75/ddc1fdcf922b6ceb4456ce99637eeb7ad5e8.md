# ट्यूपल

एक [ट्यूपल][tuple] एलिमेंट की एक परिमित क्रमित ऐरे है जो अपरिवर्तनीय है।
ट्यूपल में हर स्थान का एक निश्चित टाइप होना जरूरी है।
इसका मतलब यह है कि कंपाइलर जानता है कि हर स्थान पर कौन-सा टाइप है।
ट्यूपल में इस्तेमाल होने वाले टाइप हर स्थान पर अलग-अलग हो सकते हैं, लेकिन टाइपों का कंपाइल समय पर पता होना चाहिए।

## ट्यूपल बनाना

ट्यूपल की वैल्यू के टाइप कंपाइल समय पर अनुमानित किए जा सकते हैं या नहीं, इसके आधार पर ट्यूपल को अलग-अलग तरीकों से बनाया जा सकता है।
अगर वैल्यू कंपाइल समय पर पता हैं, तो ट्यूपल को ट्यूपल लिटरल सिंटैक्स का इस्तेमाल करके बनाया जा सकता है; वरना उन्हें स्पष्ट रूप से घोषित करना पड़ता है।
यह भी महत्वपूर्ण है कि वैल्यू के टाइप ट्यूपल में दिए गए टाइप से मेल खाते हों और वैल्यू की संख्या दिए गए टाइप की संख्या से मेल खाती हो।
यहाँ ट्यूपल लिटरल सिंटैक्स से बनाने का एक उदाहरण है:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

ट्यूपल को `Tuple` क्लास का इस्तेमाल करके भी बनाया जा सकता है।

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

वैकल्पिक रूप से, आप ट्यूपल को असाइन किए गए वेरिएबल का टाइप स्पष्ट रूप से निर्दिष्ट कर सकते हैं।

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

ट्यूपल का टाइप स्पष्ट रूप से निर्दिष्ट करना उपयोगी हो सकता है, क्योंकि इससे यह तय किया जा सकता है कि किसी स्थान पर यूनियन टाइप होना चाहिए।
इसका मतलब है कि एक स्थान पर कई टाइप हो सकते हैं।

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## रूपांतरण

### ऐरे से ट्यूपल बनाना

आप `Tuple` क्लास के `from` मेथड का इस्तेमाल करके ऐरे से ट्यूपल बना सकते हैं।
इसके लिए जरूरी है कि ट्यूपल का टाइप निर्दिष्ट किया जाए।

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### ऐरे में रूपांतरण

आप `to_a` मेथड का इस्तेमाल करके ट्यूपल को ऐरे में बदल सकते हैं।
परिणामी ऐरे का एलिमेंट टाइप ट्यूपल के हर फील्ड के टाइप का यूनियन होता है।

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## एलिमेंट एक्सेस करना

ऐरे की तरह, ट्यूपल भी ज़ीरो-इंडेक्स्ड होते हैं, यानी पहला एलिमेंट इंडेक्स 0 पर होता है।
लेकिन ऐरे के विपरीत, हर एलिमेंट का टाइप निश्चित होता है और कंपाइल समय पर पता होता है; इसलिए ट्यूपल को इंडेक्स करते समय एलिमेंट का टाइप उस स्थान के अनुसार होता है।
ट्यूपल में किसी एलिमेंट को एक्सेस करने के लिए आप `[]` ऑपरेटर का इस्तेमाल कर सकते हैं।

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

ऐरे से एलिमेंट एक्सेस करने की तुलना में एक और अंतर यह है कि अगर इंडेक्स निर्दिष्ट है, तो कंपाइलर जाँचता है कि इंडेक्स ट्यूपल की सीमा के अंदर है या नहीं।
इसका मतलब है कि आपको रनटाइम एरर की जगह कंपाइल समय पर एरर मिलेगी।

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

लेकिन अगर इंडेक्स किसी वेरिएबल में संग्रहीत है, तो कंपाइलर कंपाइल समय पर यह जाँच नहीं कर पाएगा कि इंडेक्स ट्यूपल की सीमा के अंदर है या नहीं, और इसके बजाय रनटाइम एरर देगा।

## सबट्यूपल

आप `[]` ऑपरेटर का रेंज के साथ इस्तेमाल करके ट्यूपल का सबट्यूपल प्राप्त कर सकते हैं।
जो लौटाया जाता है वह निर्दिष्ट रेंज के एलिमेंट वाला एक नया ट्यूपल होता है।
रेंज कंपाइल समय पर दी जानी चाहिए, वरना कंपाइलर सबट्यूपल के एलिमेंट के टाइप नहीं जान पाएगा।
इसका मतलब है कि रेंज एक रेंज लिटरल होनी चाहिए, किसी वेरिएबल को असाइन नहीं की गई।

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## ट्यूपल का इस्तेमाल कब करें

ट्यूपल तब उपयोगी होते हैं जब आप निश्चित संख्या की वैल्यू को एक साथ समूहित करना चाहते हैं, जहाँ वैल्यू के टाइप कंपाइल समय पर पता हों।
ऐसा इसलिए है क्योंकि ट्यूपल कम मेमोरी लेते हैं और ट्यूपल की अपरिवर्तनीयता के कारण ऐरे से तेज होते हैं।
एक और उपयोग का मामला है किसी मेथड से कई वैल्यू लौटाना।
यह खास तौर पर तब मददगार है जब वैल्यू के टाइप अलग-अलग हों, क्योंकि ट्यूपल में हर स्थान का टाइप अलग हो सकता है।

ट्यूपल का इस्तेमाल तब नहीं करना चाहिए जब ऐसी डेटा संरचना की जरूरत हो जो आकार में बढ़ या घट सके, या जिसे अक्सर बदलना पड़े।
