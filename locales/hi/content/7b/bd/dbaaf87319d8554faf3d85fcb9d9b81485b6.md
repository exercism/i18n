# परिचय

Cairo में स्ट्रिंग के लिए कोई मूल डेटा टाइप नहीं है, लेकिन स्ट्रिंग संभालने के दो तरीके हैं: साधारण कोट्स से लिखी छोटी स्ट्रिंग और डबल कोट्स से लिखा `ByteArray`।

छोटी स्ट्रिंग एक ASCII स्ट्रिंग होती है, जिसमें हर अक्षर एक बाइट में एन्कोड किया जाता है।

Cairo छोटी स्ट्रिंग के लिए डिफॉल्ट रूप से जो डेटा टाइप इस्तेमाल करता है वह `felt252` है, जिससे उनकी अधिकतम लंबाई सिर्फ 31 अक्षर ही रह जाती है।

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

तकनीकी रूप से, `felt252` से छोटा कोई भी पूर्णांक टाइप छोटी स्ट्रिंग फॉर्मैट में दर्शाया जा सकता है।

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

31 अक्षरों से लंबी स्ट्रिंग के लिए Cairo `ByteArray` देता है, जिसकी लंबाई की कोई सीमा नहीं होती।

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

`ByteArray` को `+` ऑपरेटर से जोड़ा जा सकता है:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

कुछ खास अक्षरों के आगे बैकस्लैश लगाकर उन्हें एस्केप करना पड़ता है, जैसे स्ट्रिंग में टैब के लिए `\t` और नई लाइन के लिए `\n`।

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

आप किसी `ByteArray` के अंदर मौजूद अलग-अलग बाइट तक उसके इंडेक्स की मदद से पहुँच भी सकते हैं।

लेकिन ध्यान रखिए, जो बाइट लौटता है उसका टाइप `u8` होता है, `ByteArray` नहीं!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

कोर लाइब्रेरी में `ByteArray` पर काम करने के लिए बहुत से काम के मेथड और ऑपरेटर मौजूद हैं।

`ByteArray` के मेथड के बारे में अधिक जानकारी के लिए [ByteArrayTrait का डॉक्युमेंटेशन][docs] देखिए।

यहाँ कुछ उदाहरण दिए गए हैं:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
