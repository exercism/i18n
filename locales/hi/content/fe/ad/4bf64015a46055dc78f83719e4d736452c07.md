# परिचय

## Python में ऑब्जेक्ट ओरिएंटेड प्रोग्रामिंग

अगर आप [फंक्शनल][functional], [डिक्लेरेटिव][declarative] या [इम्पेरेटिव][imperative] शैली में प्रोग्रामिंग करते आए हैं, तो ध्यान [ऑब्जेक्ट ओरिएंटेड प्रोग्रामिंग][oop] (OOP) पर ले जाना आपको थोड़ा अजीब लग सकता है।
OOP का तरीका प्रोग्रामर से कहता है कि वह किसी समस्या को एक या अधिक `objects` के रूप में सोचे, जो आपस में बातचीत करते हैं, अपनी स्थिति बनाए रखते हैं और डेटा पर काम करते हैं।
ऑब्जेक्ट असली दुनिया की चीज़ों को दर्शा सकते हैं (_जैसे कार या बिल्लियाँ_), या अधिक अमूर्त अवधारणाओं को (_जैसे पूर्णांक, वाहन या स्तनधारी_)।
हर ऑब्जेक्ट कंप्यूटर मेमोरी में एक अलग इंस्टेंस बन जाता है और पूरे मॉडल के किसी एक हिस्से को दर्शाता है।

## क्लास

`Classes` नए ऑब्जेक्ट टाइप की परिभाषाएँ हैं, और इन्हीं से ऑब्जेक्ट के नए `instances` बनाए जाते हैं।
ये अक्सर डेटा के साथ उस डेटा पर काम करने वाला कोड या फंक्शन जोड़ देती हैं।
इस अर्थ में क्लास एक तरह का _खाका_ या निर्देशों का समूह होती हैं, जिनसे एक जैसे टाइप के कई ऑब्जेक्ट बनाए और इस्तेमाल किए जा सकते हैं।
एक जटिल प्रोग्राम में कई क्लास हो सकती हैं, और हर क्लास कई अलग-अलग तरह के ऑब्जेक्ट बनाती है।
किसी क्लास से ऑब्जेक्ट बनाने की प्रक्रिया को `instantiation` (_या क्लास का इंस्टेंस बनाना_) कहा जाता है।

Python में क्लास की परिभाषा सीधी और आसान होती है:

```python
class MyClass:
    # Class body goes here
```

### क्लास एट्रिब्यूट

क्लास फील्ड (_जिन्हें `properties`, `attributes`, `data members` या `variables` भी कहा जाता है_) क्लास की बॉडी में जोड़े जा सकते हैं:

```python
class MyClass:
    number = 5
    string = "Hello!"
```

`MyClass` का एक इंस्टेंस (_ऑब्जेक्ट_) क्लास को [_कॉल_][calling] करके बनाया जा सकता है और किसी नाम से बाँधा जा सकता है (_ठीक वैसे ही जैसे किसी फंक्शन को कॉल किया जाता है_):

```python
>>> new_object = MyClass()

# Class is instantiated and resulting object is bound to the "new_object" name.
# Note: the object address 'at 0x15adc55b0' will vary by computer.
>>> new_object
<__main__.MyClass at 0x15adc55b0>
```

`Class attributes` किसी क्लास से बने सभी ऑब्जेक्ट (_या इंस्टेंस_) में साझा रहते हैं, और इन्हें [`dot notation`][dot notation] से इस्तेमाल किया जा सकता है, यानी ऑब्जेक्ट के नाम के बाद और एट्रिब्यूट के नाम से पहले लगाया गया एक `.`:

```python
>>> new_object = MyClass()

# Accessing the class attribute "number" via dot-notation.
>>> new_object.number
5

# Accessing the class attribute "string" via dot-notation.
>>> new_object.string
'Hello!'

# Instantiating an additional object and binding it to the "second_new_object" name.
>>> second_new_object = MyClass()

>>> second_new_object
# Note: the object address "at 0x15ad99970" will vary by computer.
<__main__.MyClass at 0x15ad99970>

# Second_new_object shares the same class attributes as new_object.
>>> new_object.number == second_new_object.number
True
```

क्लास एट्रिब्यूट क्लास के अंदर ही, बाकी किसी भी मेथड से पहले परिभाषित किए जाते हैं।
ये क्लास के ही होते हैं, जिससे क्लास के सभी इंस्टेंस इन्हें साझा कर सकते हैं।
चूँकि ये एट्रिब्यूट साझा होते हैं, इनकी वैल्यू का इस्तेमाल और बदलाव क्लास से _सीधे_ किया जा सकता है।
क्लास एट्रिब्यूट की वैल्यू बदलने पर _**क्लास से बने सभी ऑब्जेक्ट के लिए**_ वैल्यू बदल जाती है:

```python
>>> obj_one = MyClass()
>>> obj_two = MyClass()

# Accessing a class attribute from an object.
>>> obj_two.number
5

# Accessing the class attribute from the class itself.
>>> MyClass.number
5

# Modifying the value of the "number" class attribute.
>>> MyClass.number = 27

# Modifying the "number" class attribute changes the "number" attribute for all objects.
>>> obj_one.number
27

>>> obj_two.number
27
```

हर समय एक जैसा डेटा रखने वाले ढेर सारे ऑब्जेक्ट होना कोई खास उपयोगी बात नहीं है।
अच्छी बात यह है कि क्लास से बने ऑब्जेक्ट को उनके अपने `instance attributes` (_या इंस्टेंस प्रॉपर्टी, वेरिएबल या फील्ड_) की मदद से अपने हिसाब से बनाया जा सकता है।
जैसा कि नाम से ही पता चलता है, इंस्टेंस एट्रिब्यूट हर ऑब्जेक्ट के लिए अलग होते हैं और इन्हें अलग-अलग बदला जा सकता है।


## `__init__()` से ऑब्जेक्ट इंस्टैंशिएशन को अपने हिसाब से ढालना

विशेष ["डंडर मेथड"][dunder] (_यानी "डबल अंडरस्कोर मेथड" का छोटा रूप_) `__init__()` का इस्तेमाल क्लास इंस्टेंस को अपने हिसाब से बनाने के लिए किया जाता है, और इससे ऑब्जेक्ट के इंस्टेंस एट्रिब्यूट या प्रॉपर्टी को शुरुआती वैल्यू दी जा सकती है।
इंस्टेंस एट्रिब्यूट को शुरुआती वैल्यू देने में इसकी भूमिका के कारण `__init__()` को `class constructor` या `initializer` भी कहा जाता है।
`__init__()` एक ज़रूरी पैरामीटर लेता है जिसका नाम `self` है, और यह नए शुरू किए गए या नए बने ऑब्जेक्ट को दर्शाता है।
इसके बाद `self` पैरामीटर के बाद, इंस्टेंस एट्रिब्यूट या प्रॉपर्टी का डेटा `__init__()` के आर्गुमेंट के रूप में दिया जा सकता है।

नीचे दिए उदाहरण में `MyClass` में अब `location_x` और `location_y` नाम के इंस्टेंस एट्रिब्यूट हैं।
जैसा कि आप देख सकते हैं, ये दोनों एट्रिब्यूट `__init__()` को दिए गए `location` (_एक टपल_) आर्गुमेंट के पहले और दूसरे इंडेक्स पर असाइन किए गए हैं।
जब आप क्लास का इंस्टेंस बनाते हैं, तो क्लास इंस्टेंस के `location_x` और `location_y` एट्रिब्यूट को शुरुआती वैल्यू मिल जाती है और ऑब्जेक्ट बन जाता है:

```python
class MyClass:
    # These are class attributes, variables, or fields.
    number = 5
    string = "Hello!"

    # This is the class "constructor", with a "location" parameter that is a tuple.
    def __init__(self, location):

        # This is an instance or object property, attribute, or variable.
        # Note that we are unpacking the tuple argument into two separate instance variables.
        self.location_x = location[0]
        self.location_y = location[1]

# Create a new object "new_object_one", with object property (1, 2).
>>> new_object_one = MyClass((1, 2))

# Create a second new object "new_object_two" with object property (-8, -9).
>>> new_object_two = MyClass((-8, -9))

# Note that new_object_one.location_x and new_object_two.location_x two different values.
>>> new_object_one.location_x
1

>>> new_object_two.location_x
-8
```

ध्यान दीजिए कि ऊपर `MyClass` को शुरू करते समय आपको सिर्फ एक ही आर्गुमेंट देना होता है। क्लास को कॉल करने पर `self` भेजने का काम Python खुद कर लेता है।


## मेथड

`method` एक ऐसा `function` है जो या तो खुद क्लास से बँधा होता है (_जिसे [क्लास मेथड][class method] कहते हैं, और इस पर आगे किसी अभ्यास में बात होगी_) या क्लास के किसी _इंस्टेंस_ (ऑब्जेक्ट) से।
किसी ऑब्जेक्ट (इंस्टेंस) पर काम करने वाले मेथड को `self` को पहला पैरामीटर बनाकर परिभाषित करना होता है।
इसके बाद बाकी पैरामीटर आप वैसे ही परिभाषित कर सकते हैं जैसे किसी "सामान्य" या बिना बँधे फंक्शन के लिए करते हैं:

```python
class MyClass:
    number = 5
    string = "Hello!"

    # Class constructor.
    def __init__(self, location):
        # Instance properties
        self.location_x = location[0]
        self.location_y = location[1]

    # Instance method. Note "self" as first parameter.
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y
```

एट्रिब्यूट की तरह ही, मेथड को कॉल करने के लिए बस ऑब्जेक्ट के नाम के बाद और मेथड के नाम से पहले एक `.` लगाना होता है।
कॉल किए गए मेथड को पहले पैरामीटर के रूप में ऑब्जेक्ट की कोई प्रति देने की ज़रूरत नहीं होती। Python खुद ही `self` भर देता है:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

# Make a new test_object with location (3,7)
>>> test_object = MyClass((3,7))
>>> (test_object.location_x, test_object.location_y)
(3,7)

# Call change_location to increase location_x and location_y by 7.
>>> test_object.change_location(7)
(10, 14)
```

क्लास एट्रिब्यूट का इस्तेमाल इंस्टेंस मेथड के अंदर भी उसी तरह किया जा सकता है जैसे क्लास के बाहर किया जाता है:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

    # Alter class variable number for all instances from within an instance.
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1


>>> test_object_one = MyClass((0,0))
>>> test_object_one.number
5

>>> test_object_two = MyClass((13, -3))
>>> test_object_two.increment_number()
>>> test_object_one.number
6
```

## pass के साथ कार्यान्वयन को खाली छोड़ना या स्टब करना

पिछले कॉन्सेप्ट अभ्यासों और प्रैक्टिस अभ्यास के स्टब में, आपने फंक्शन के अंदर असली कोड की जगह `pass` कीवर्ड का इस्तेमाल देखा होगा।
`pass` कीवर्ड सिंटैक्स की दृष्टि से मान्य प्लेसहोल्डर है। यह Python को खाली फंक्शन या क्लास की परिभाषा पर सिंटैक्स एरर देने से रोकता है।
आसान शब्दों में कहें तो, यह Python इंटरप्रेटर से कहने का एक तरीका है: "चिंता मत करो! यहाँ कोड _ज़रूर_ आएगा, बस अभी तक नहीं आया।"

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return  self.location_x, self.location_y

    # Alter class variable number for all instances
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1

    # This will compile and run without error, but has no current functionality.
    def pending_functionality(self):
       # Stubbing or placholding the body of this method.
       pass
```
