# परिचय

Lua संख्याओं के लिए दो तरह के निरूपण इस्तेमाल करता है: 64-बिट पूर्णांक संख्याएँ और दोहरी परिशुद्धता वाली दशमलव संख्याएँ। यह अंकगणित के सामान्य ऑपरेटरों का समर्थन करता है: जोड़, घटाव, गुणा, भाग और ऋण। इसके अलावा यह फ्लोर डिवीज़न, मॉडुलो और घातांक का भी समर्थन करता है।

| ऑपरेटर | उदाहरण              |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
