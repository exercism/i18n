# परिचय

## वेरिएबल

याद कीजिए कि एक `jq` प्रोग्राम एक्सप्रेशन की एक _पाइपलाइन_ होता है।
**वेरिएबल असाइनमेंट** इस नियम का पालन करता है: _वेरिएबल असाइनमेंट_ वह एक्सप्रेशन होता है जो ऐसा दिखता है:

```jq
... | expr as $varname | ...
```

### फिल्टर का आउटपुट इनपुट ही होता है

_आइडेंटिटी एक्सप्रेशन_ `.` की तरह, _वेरिएबल असाइनमेंट_ का आउटपुट भी उसके इनपुट जैसा ही होता है।
वेरिएबल की वैल्यू सेट करना एक साइड इफेक्ट है।

नीचे दिए उदाहरण में देखिए कि असाइनमेंट के बाद `.` शुरुआती इनपुट जैसा ही रहता है:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### वेरिएबल का स्कोप

वेरिएबल का स्कोप "लेक्सिकल" होता है, यानी वेरिएबल पाइपलाइन के बाकी हिस्से तक स्कोप में बना रहता है।
फंक्शन के अंदर बनाए गए वेरिएबल (फंक्शन की बात हम आगे करेंगे) उस फंक्शन के लिए "लोकल" होते हैं।

### वेरिएबल के नाम

वेरिएबल का नाम `$` से शुरू होना चाहिए।
नाम का बाकी हिस्सा एक **आइडेंटिफायर** होता है: यह किसी अक्षर या अंडरस्कोर से शुरू होता है, और उसके बाद अक्षर, संख्याएँ या अंडरस्कोर आ सकते हैं।

### डिस्ट्रक्चरिंग असाइनमेंट

मैनुअल से:

> एक ही `as` एक्सप्रेशन से कई वेरिएबल घोषित किए जा सकते हैं, बस एक ऐसा पैटर्न दीजिए जो _इनपुट की संरचना से मेल खाता हो_ (इसे "डिस्ट्रक्चरिंग" कहते हैं)।

उदाहरण:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

वेरिएबल के नाम को _ऑब्जेक्ट की_ से मिलाने पर एक शॉर्टकट मिल जाता है:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

~~~~exercism/note
यही शॉर्टकट _ऑब्जेक्ट कंस्ट्रक्शन_ के लिए उलटी दिशा में भी काम करता है।

```jq
4 as $x | 7 as $y | {$x, $y}    # => {"x":4, "y": 7}
```

### स्थिरांक

जैसा ऊपर के उदाहरण में दिखा, स्थिरांक संग्रहीत करने के लिए वेरिएबल काम आते हैं।
कोड में "मैजिक संख्याएँ" दिखने से बेहतर है कि स्थिरांक को कोई नाम दे दिया जाए।

### अक्सर वेरिएबल की ज़रूरत नहीं होती

वेरिएबल छोड़ देने पर कोड अक्सर ज़्यादा साफ़ पढ़ा जाता है।

संख्याओं के एक ऐरे का औसत निकालने की बात कीजिए:

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

इसकी तुलना में:

```jq
[2, 4, 8, 7] | add / length
```

यह `jq` की सबसे शक्तिशाली बातों में से एक दिखाता है: फिल्टर को मिला इनपुट _हर_ सब-एक्सप्रेशन को भी दिया जाता है:

- इनपुट ऐरे `[2,4,8,7]` को `add` को दिया जाता है (`add` सभी एलिमेंट पर `+` ऑपरेटर लगाकर संख्याओं का जोड़ निकालता है)
- _साथ ही_, `[2,4,8,7]` `length` को भी दिया जाता है
- जब ये सब-एक्सप्रेशन पूरे हो जाते हैं, तब उनके नतीजों को भाग दिया जाता है, जिससे इनपुट ऐरे की संख्याओं का औसत निकल आता है।

### इस अभ्यास के लिए ज़रूरी `jq` ऑपरेटर

#### वैकल्पिक ऑपरेटर: `//`

`a // b` एक्सप्रेशन `b` देता है जब `a` false या null हो, वरना यह `a` देता है।
वेरिएबल सेट करते समय यह डिफॉल्ट वैल्यू देने के लिए बहुत काम का है:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### अंकगणितीय ऑपरेटर

- `+`, `-`, `*` संख्याओं के जोड़, घटाव और गुणा के सामान्य ऑपरेटर हैं।
