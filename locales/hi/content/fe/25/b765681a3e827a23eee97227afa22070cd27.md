# दशमलव संख्याएँ

PHP में दशमलव संख्याओं का उपयोग वास्तविक संख्याओं के एक उपसमुच्चय को दर्शाने के लिए किया जाता है।
ये एक या अधिक अंकों से शुरू होती हैं, जिनके बाद दशमलव विभाजक आता है।

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## आम गलतियाँ

यह ज़रूरी नहीं कि हर संख्या और हर गणितीय संक्रिया दशमलव संख्याओं से की जा सके। डॉलर और सेंट को दर्शाने के लिए दशमलव संख्याओं का उपयोग करने पर अक्सर राउंडिंग एरर हो जाती है।

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
