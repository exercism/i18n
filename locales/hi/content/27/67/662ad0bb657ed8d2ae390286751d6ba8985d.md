# परिचय

किसी चीज़ को उसी के आधार पर परिभाषित करने की क्षमता को रिकर्सन कहते हैं। F# में रिकर्सन सबसे अधिक रिकर्सिव फंक्शन में दिखता है, यानी ऐसे फंक्शन में जो खुद को कॉल करते हैं।

एक रिकर्सिव फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना ज़रूरी है। _बेस केस_ फंक्शन को दोबारा कॉल किए बिना एक वैल्यू लौटाता है। _रिकर्सिव केस_ फंक्शन को दोबारा कॉल करता है और इनपुट को इस तरह बदलता है कि वह किसी न किसी बिंदु पर बेस केस से मेल खाने लगे।

रिकर्सिव फंक्शन सामान्य फंक्शन की तरह ही बनाए जाते हैं, फर्क सिर्फ यह है कि इनके साथ `rec` मॉडिफायर लगता है। इस मॉडिफायर के बिना कोई फंक्शन खुद को कॉल _नहीं_ कर पाएगा, और ऐसा करने की कोशिश करने पर कंपाइलेशन एरर मिलेगी। इसलिए रिकर्सन को स्पष्ट रूप से अपनाना पड़ता है।

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# में डिस्क्रिमिनेटेड यूनियन टाइप के ज़रिए रिकर्सिव टाइप भी होते हैं। किसी रिकर्सिव डिस्क्रिमिनेटेड यूनियन टाइप के एक या अधिक केस अपने डेटा में उसी डिस्क्रिमिनेटेड यूनियन टाइप को दर्शाते हैं। रिकर्सिव फंक्शन की तरह ही रिकर्सिव टाइप में भी एक बेस केस होना चाहिए। फर्क यह है कि रिकर्सिव टाइप `rec` कीवर्ड का इस्तेमाल नहीं करते।

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
