# परिचय

Go में `map` एक बिल्ट-इन डेटा टाइप है, जो की को वैल्यू से जोड़ता है।
दूसरी प्रोग्रामिंग भाषाओं में `map` जैसी चीज़ को आपने डिक्शनरी, हैश टेबल, की/वैल्यू स्टोर या असोसिएटिव ऐरे जैसे नामों से देखा होगा।

सिंटैक्स के हिसाब से `map` ऐसा दिखता है:

```go
map[KeyType]ElementType
```

यह जानना भी ज़रूरी है कि हर की अद्वितीय होती है। इसका मतलब यह है कि एक ही की को दो बार असाइन करने पर उससे जुड़ी वैल्यू बदल जाती है।

मैप बनाने के लिए आप यह कर सकते हैं:

```go
  // With map literal
  foo := map[string]int{}
```

या

```go
  // or with make function
  foo := make(map[string]int)
```

यहाँ कुछ ऑपरेशन दिए गए हैं जो आप मैप के साथ कर सकते हैं

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

अगर आप ऐसी की की वैल्यू निकालने की कोशिश करते हैं जो मैप में नहीं है, तो मैप उस वैल्यू टाइप की शून्य वैल्यू लौटाता है।
यह बात आपको उलझा सकती है, खासकर तब जब आपके `ElementType` की डिफॉल्ट वैल्यू (जैसे किसी int के लिए 0) ही एक मान्य वैल्यू हो।
यह जाँचने के लिए कि आपके मैप में कोई की है या नहीं, आप यह कर सकते हैं

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
