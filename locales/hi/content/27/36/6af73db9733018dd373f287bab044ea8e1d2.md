# परिचय

टपल वैल्यूओं का एक क्रमबद्ध कंटेनर है। Gleam के सभी डेटा टाइप अपरिवर्तनीय होते हैं, और टपल भी। टपल का हर एलिमेंट अलग-अलग टाइप का हो सकता है। ये एलिमेंट दूसरे टपल भी हो सकते हैं।

टपल को `#(` और `)` के बीच कॉमा से अलग की गई वैल्यूओं के रूप में लिखा जाता है: `#(1, 2.0, "Three")`।

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

जिन टपल की लंबाई और टाइप एक जैसे हों (और उसी क्रम में हों), उनकी समानता के लिए तुलना की जा सकती है।

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

टपल के अंदर रखी वैल्यूओं को निकालने के तीन तरीके हैं:

- इंडेक्सिंग।
- `let` के साथ पैटर्न मैचिंग।
- `case` के साथ पैटर्न मैचिंग।

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

`case` एक्सप्रेशन के गार्ड में टपल की इंडेक्सिंग का उपयोग किया जा सकता है।

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
