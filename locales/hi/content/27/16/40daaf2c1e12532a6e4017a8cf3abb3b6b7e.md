# परिचय

## भूमिका

जेनेरिक्स भाषा की एक ऐसी सुविधा है जिससे कोड दोबारा इस्तेमाल किया जा सकता है।
उदाहरण के लिए, किसी ऐरे की लंबाई निकालने के लिए यह देखना ज़रूरी नहीं है कि उसमें किस टाइप के एलिमेंट हैं।
इसीलिए `length` फंक्शन अपने टाइप सिग्नेचर में एक जेनेरिक टाइप पैरामीटर `a` इस्तेमाल करता है।

```elm
length : List a -> Int
```

## टाइप में पैरामीटर

जब कोई टाइप किसी दूसरे टाइप पर जेनेरिक होता है, तो उस दूसरे टाइप के लिए हम छोटे अक्षरों वाला नाम इस्तेमाल करते हैं और उसे टाइप पैरामीटर कहते हैं।
आम उदाहरण `List`, `Maybe` और `Result` जैसे कस्टम टाइप हैं।

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

टाइप पैरामीटर के नामों के बारे में एक ज़रूरी बात यह है कि वे कई अक्षरों के हो सकते हैं।
बस एक शर्त यह है कि वे छोटे अक्षरों वाले नाम होने चाहिए।
इसलिए जहाँ यह काम का हो, हम उन्हें ऐसे नाम देते हैं जो उनके बारे में कुछ बताते हैं।

कोई टाइप एक साथ कई टाइपों पर जेनेरिक हो सकता है, और इस तरह उसके कई टाइप पैरामीटर हो सकते हैं।
ऐसी स्थिति में हर स्वतंत्र टाइप को छोटे अक्षरों वाला अलग नाम मिलता है।
स्वतंत्र होने का मतलब यह नहीं है कि वे एक ही टाइप नहीं बन सकते, बल्कि इससे यह संभव होता है कि वे अलग-अलग हों।

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

रिकॉर्ड टाइप एलियस में भी टाइप पैरामीटर हो सकते हैं, हालाँकि यह कम आम है।

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## फंक्शन में टाइप पैरामीटर

चूँकि टाइप जेनेरिक हो सकते हैं, फंक्शन भी हो सकते हैं।
जेनेरिक टाइप पर काम करने वाले फंक्शन भी लिखे जा सकते हैं, जैसे `Maybe.withDefault`।

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

जो फंक्शन दूसरे फंक्शन को पैरामीटर के रूप में लेते हैं उन्हें हायर ऑर्डर फंक्शन कहा जाता है, और ये भी जेनेरिक हो सकते हैं।

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
