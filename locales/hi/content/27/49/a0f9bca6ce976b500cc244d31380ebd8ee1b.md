# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जिसका फॉर्मैट इस तरह होता है: `"[<LVL>]: <MESSAGE>"`.

ये अलग-अलग लॉग लेवल हैं:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

आपको तीन काम करने हैं।

## 1. लॉग लेवल पार्स कीजिए

एक `LogLevel` एनम बनाइए, जिसमें ऊपर दिए गए लॉग लेवलों के अनुरूप छह एलिमेंट हों।

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

इसके बाद, किसी लॉग लाइन का लॉग लेवल पार्स करने के लिए (_static_) `LogLine.ParseLogLevel()` मेथड लागू कीजिए:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. अज्ञात लॉग लेवल को संभालिए

दुर्भाग्य से कभी-कभी कुछ लॉग लाइनों में अज्ञात लॉग लेवल होता है। ऐसी लॉग लाइनों को ठीक से संभालने के लिए `LogLevel` एनम में एक `Unknown` एलिमेंट जोड़िए, जो किसी अज्ञात लॉग लेवल को पार्स करते समय लौटाया जाना चाहिए:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. लॉग लाइन को छोटे फॉर्मैट में बदलिए

लॉग लाइन का लॉग लेवल काफी लंबा होता है। लॉग लाइनों को संग्रहीत करने में जितनी डिस्क स्पेस लगती है, उसे कम करने के लिए एक छोटा फॉर्मैट बनाया गया है: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

एनकोड किया गया लॉग लेवल बस हर लॉग लेवल के लिए एक संख्या तय करता है:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

(_static_) `LogLine.OutputForShortLog()` मेथड लागू कीजिए, जो छोटे फॉर्मैट में लॉग लाइन आउटपुट कर सके:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
