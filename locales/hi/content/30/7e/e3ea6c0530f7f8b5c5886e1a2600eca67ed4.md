# परिचय

## फंक्शन टाइप

किसी Swift फंक्शन सिग्नेचर से अगर सारे नाम और लेबल हटा दिए जाएँ, तो जो बचता है वह उस फंक्शन का टाइप होता है।

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

ध्यान दीजिए कि पहले दो फंक्शनों के टाइप एक ही हैं, `(String, Int) -> String`, हालाँकि दोनों के सिग्नेचर अलग हैं और दोनों फंक्शन बहुत अलग तरीके से काम करते हैं। ये दोनों इनपुट में एक `String` और एक `Int` लेते हैं और एक `String` लौटाते हैं। और तीसरे फंक्शन के टाइप से पता चलता है कि फंक्शन के अंदर का कोड भले ही कुछ लौटाता न दिखे, वह वास्तव में अप्रत्यक्ष रूप से `()` लौटाता है, जो `Void` टाइप की एकमात्र वैल्यू है।

इन फंक्शन टाइपों का उपयोग Swift में किसी भी दूसरे टाइप की तरह किया जा सकता है। जैसे, इन्हें वेरिएबल या कॉन्स्टेंट घोषित करते समय इस्तेमाल किया जा सकता है। और चूँकि Swift में फंक्शन भी वैल्यू होते हैं, पहले से मौजूद फंक्शनों को इन कॉन्स्टेंट या वेरिएबल में असाइन किया जा सकता है:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

बाकी वेरिएबल या कॉन्स्टेंट की तरह, आप जो वैल्यू असाइन करते हैं वह सही टाइप की होनी चाहिए:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

### फंक्शन टाइप को पैरामीटर टाइप की तरह इस्तेमाल करना

फंक्शन टाइपों का उपयोग वहीं किया जा सकता है जहाँ बाकी टाइप किए जा सकते हैं। इसलिए इन्हें पैरामीटर टाइप की तरह भी इस्तेमाल किया जा सकता है, दूसरे फंक्शनों को दिया जा सकता है, और उन फंक्शनों के अंदर से कॉल किया जा सकता है।

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## फंक्शन टाइप को रिटर्न टाइप की तरह इस्तेमाल करना

इसी तरह, फंक्शन टाइपों को फंक्शन के रिटर्न टाइप की तरह भी इस्तेमाल किया जा सकता है। यानी ऐसे फंक्शन लिखे जा सकते हैं जो दूसरे फंक्शन बनाकर लौटाते हैं। ऐसा फंक्शन बनाते समय, जो फंक्शन लौटाया जाता है वह उस फंक्शन को दिए गए बाकी पैरामीटर या मूल फंक्शन के अंदर बनाए गए वेरिएबलो का उपयोग कर सकता है।

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
