# निर्देश परिशिष्ट

## संकेत

इस अभ्यास को पूरा करने के लिए आपको `score` फंक्शन लिखना है, जो बॉलिंग के *रोल* का एक क्रम लेता है और अंतिम स्कोर या उचित एरर लौटाता है:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

ये परिभाषाएँ आपको पहले से मौजूद मिलेंगी, लेकिन फंक्शन बनाना आपको खुद करना है।

ध्यान रखिए कि टेस्ट सूट यह मानकर चलता है कि रोल की गिनती शून्य से शुरू होती है।
