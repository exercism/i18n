# विवरण

## सामान्य सिंटैक्स

`while` लूप की मदद से आप एक ही कोड को बार-बार चला सकते हैं, जब तक कोई निश्चित शर्त पूरी होती रहती है।

इसे `while` कीवर्ड के साथ लिखा जाता है: पहले गोल ब्रैकेट में लिखी शर्त, और उसके बाद एक कोड ब्लॉक, जिसके घुंघराले ब्रैकेट के अंदर लूप का _अंदरूनी कोड_ रहता है।

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is
  // true
}
```

JavaScript में do-while लूप भी होता है। इसमें शर्त की जाँच लूप का कोड चल चुकने के बाद होती है। यह तब काम आता है, जब शर्त लूप के कोड के अंदर की गई गणनाओं पर निर्भर करती हो।

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

## `break`

लूप के कोड के अंदर आप `break` कीवर्ड की मदद से लूप का चलना पूरी तरह रोक सकते हैं। इसका इस्तेमाल अक्सर शर्त के रूप में `true` के साथ किया जाता है। इसकी मदद से आप लूप के कोड में किसी भी जगह से तय कर सकते हैं कि लूप कब रुकना चाहिए।

```javascript
const winningNumber = 7;

while (true) {
  const num = readUserGuess();
  if (num === winningNumber) {
    break;
  }
}
```

`break` कीवर्ड का उपयोग उस फंक्शन के अंदर नहीं किया जा सकता जो लूप के अंदर नेस्टेड हो। उदाहरण के लिए [MDN के दस्तावेज़][mdn-break-in-function] देखिए।

## `continue`

`break` के उलट, `continue` कीवर्ड सिर्फ मौजूदा इटरेशन को रोकता है और अगले इटरेशन के साथ आगे बढ़ जाता है। `continue` की मदद से आप अक्सर लूप के कोड के बड़े हिस्से को `if` स्टेटमेंट में लपेटने से बच सकते हैं।

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## अनंत लूप

जब लूप की शर्त हमेशा पूरी होती रहे और लूप के कोड में कोई break या return स्टेटमेंट तक पहुँच ही न हो, तो ऐसा लूप बनता है जो (सिद्धांत रूप में) हमेशा दोहराता रहता है। ऐसे लूप को बाहर से रोकना पड़ता है। ऐसा कोड जिस वातावरण में चलता है, उसके अनुसार यह काम अपने आप हो जाता है, या फिर इसे खुद करना पड़ता है।

```javascript
let i = 0;

while (i < 100) {
  if (i % 3 === 0) {
    continue;
  }

  i = i + 2;
}

// This loop runs forever since the variable i does not change
// anymore after it is divisible by 3 the first time.
```

इस छोटे उदाहरण में अनंत लूप पहचानना बहुत आसान लग सकता है, लेकिन जटिल कोड में यह हमेशा इतना आसान नहीं होता। अच्छा तरीका यह है कि आप अच्छी तरह सोचें कि आपकी शर्त अंततः गलत होती है या नहीं, और यह भी कि आपका break या return स्टेटमेंट तक पहुँचता है या नहीं।
