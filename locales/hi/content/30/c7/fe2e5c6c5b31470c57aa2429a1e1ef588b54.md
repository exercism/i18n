# परिचय
C++ में अंतर्निहित संख्या प्रकार दो तरह के होते हैं: पूर्णांक और दशमलव संख्याएँ।
पूर्णांक पूर्ण संख्याएँ होते हैं, जैसे `0`, `691` या `-2`.
दशमलव संख्याओं में दशमलव बिंदु होता है, जैसे `6.02214076`, `0.1` या `-1.616`.

## पूर्णांक
नीचे दिया गया उदाहरण चार अलग-अलग वेरिएबलो की घोषणा और इनिशियलाइज़ेशन दिखाता है

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

जब आप किसी `int` वेरिएबल को कोई वैल्यू असाइन करते हैं, तो आप यह सीधे लिटरल की मदद से कर सकते हैं।
लिटरल एक ऐसी संख्या है जो कोड में सीधे लिखी जाती है, जैसे `9241`.
एक ही संख्या को अलग-अलग आधारों में लिखने के लिए अलग-अलग पूर्णांक लिटरल होते हैं।
दशमलव पूर्णांक लिटरल सबसे आम होते हैं और इनमें `0` से `9` तक के अंक इस्तेमाल होते हैं।
`0x` जैसा खास प्रीफिक्स लगाकर दूसरे आधार भी इस्तेमाल किए जा सकते हैं।
ऊपर का उदाहरण संख्या `9421` को उसके चारों निरूपणों और प्रीफिक्सों के साथ दिखाता है।
सभी वेरिएबल एक ही वैल्यू से इनिशियलाइज़ किए गए हैं।

अलग-अलग निरूपण प्रणालियों के बारे में अधिक जानकारी के लिए [एक छोटा ट्यूटोरियल][cpp_numerical_bases] देखिए।

पढ़ने में आसानी के लिए आप अंकों के बीच एपॉस्ट्रॉफी लगा सकते हैं।
`9'241` का मतलब वही है जो `0b0100'100'0001'1001` या `92'4'1` का है।

## दशमलव संख्याएँ

दशमलव लिटरल दो तरह के होते हैं।
सहज `0.0024` के अलावा इसका वैज्ञानिक संकेतन `2.4e-3` भी इस्तेमाल किया जा सकता है।
सबसे आम दशमलव प्रकार `double` है।

## अंकगणित

C++ एक्सप्रेशन बनाने के लिए `+`, `-`, `*`, `/`, `(` और `)` तथा `%` का समर्थन करता है।
दो पूर्णांकों के बीच के ऑपरेशन का परिणाम भी एक पूर्णांक होता है।
`5 / 2` का परिणाम `2` आएगा.
जब इसमें शामिल कोई एक प्रकार दशमलव प्रकार का हो, तो परिणाम भी दशमलव होगा।
`5.0 / 2` और `5 / 2.0` का परिणाम `2.5` आएगा.
`%` शेष ऑपरेटर है और पूर्णांक विभाजन का शेष लौटाता है: `5%3` का मान `2` है।

## असाइनमेंट ऑपरेटर

असाइनमेंट ऑपरेटर किसी वेरिएबल को एक लिटरल असाइन करता है।
यह हमेशा दाएँ से बाएँ होता है, कभी इसके उलट नहीं।

```cpp
int length = 5;
int width = 2;
length = width;
```

यहाँ पूर्णांक वैल्यू `5` को वेरिएबल `length` में असाइन किया जाता है।
फिर पूर्णांक वैल्यू `2` को वेरिएबल `width` में असाइन किया जाता है।
अंत में `width` की वैल्यू को वेरिएबल `length` में कॉपी किया जाता है और पहले वाली वैल्यू `5` खो जाती है।
यह भी ध्यान रखिए कि असाइनमेंट करते समय हम केवल `width` की वैल्यू को `length` में असाइन कर रहे हैं।
इसलिए, अगर बाद में `width` की वैल्यू बदलती है, तो `length` की वैल्यू पर इसका कोई असर नहीं पड़ेगा।

असाइनमेंट ऑपरेटर को दूसरे ऑपरेटरों (अंकगणितीय और बिटवाइज़) के साथ जोड़ा जा सकता है, जिन्हें `compound assignment` ऑपरेटर कहते हैं: `+=`, `-=`, `*=`, `/=`, `%=`।
ये ऑपरेटर वेरिएबल की मौजूदा वैल्यू पर ऑपरेशन करके उसे बदल देते हैं।

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

वेरिएबल `people` और `eggs` को `0` से इनिशियलाइज़ किया गया है।
फिर हम वेरिएबल `people` की मौजूदा वैल्यू `0` में पूर्णांक वैल्यू `2` जोड़ते हैं और इसे वापस `people` में असाइन कर देते हैं।
अब `people` की वैल्यू `2` हो जाती है।
बाद में, हम हर व्यक्ति के लिए `3` अंडे जोड़ते हैं, जो कुल मिलाकर `6` अंडे होते हैं।
अब इस `6` को वेरिएबल `eggs` की मौजूदा वैल्यू `0` में जोड़िए और इसे वापस `eggs` में असाइन कर दीजिए।
अब `eggs` की वैल्यू `6` हो जाएगी।
इसके बराबर एक्सप्रेशन होंगे `people = people + 2` और `eggs = eggs + (3 * people)`.
