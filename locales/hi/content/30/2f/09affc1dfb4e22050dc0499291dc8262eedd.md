# विवरण

`assocs` एक [प्रोटोकॉल][assoc-protocol] है, कोई एक अकेला डेटा टाइप नहीं। हैशटेबल (`H{ }`), एसोसिएशन लिस्ट (`{ key value }` जोड़ियों का अनुक्रम) और ट्री मैप, ये सभी इस प्रोटोकॉल को लागू करते हैं। `assocs` के ज़्यादातर शब्द इन सब पर एक ही तरह काम करते हैं।

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

इस प्रोटोकॉल का पूरा दायरा बहुत बड़ा है: क्रमबद्ध इटरेशन, मैपिंग और फिल्टरिंग। लेकिन अभ्यास के स्तर पर ज़्यादातर काम इन्हीं में से कुछ ही शब्दों तक सीमित रहता है:

| शब्द        | प्रभाव                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` यह बताता है कि वैल्यू f है या वैल्यू मौजूद नहीं है |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )` एसोसिएशन को बदल देता है |
| `change-at` | `( key assoc quot -- )` यहाँ `quot` यानी `( old -- new )` |
| `inc-at`    | `( key assoc -- )` `+1` जोड़ता है, और अगर कोई की मौजूद न हो तो `1` डाल देता है |
| `delete-at` | `( key assoc -- )` एसोसिएशन को बदल देता है    |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` और `sort-values` (`sorting` में) अलिस्ट को चुने गए फील्ड के आधार पर क्रम में लगाते हैं।

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
