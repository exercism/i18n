# परिचय

Elm जैसी प्योर फंक्शनल भाषा में, एक जैसे आर्गुमेंट के साथ कॉल किया गया फंक्शन हमेशा वही वैल्यू लौटाता है। इसलिए `rand : Int` टाइप सिग्नेचर वाले फंक्शन को केवल `rand = 4` के रूप में ही बनाया जा सकता है, जो रैंडम पूर्णांक बनाने के लिए अच्छी बात नहीं है।

तो Elm में रैंडम वैल्यू हम कैसे बनाएँ?
हम समस्या को दो हिस्सों में बाँटते हैं: पहले, हम जिस वैल्यू को बनाना चाहते हैं उसका वर्णन `Random.Generator a` से करते हैं, फिर उस वैल्यू को बनाते हैं।

वैल्यू बनाने का पहला तरीका यह है कि `initialSeed : Int -> Seed` से एक `Random.Seed` बनाया जाए और फिर `step : Generator a -> Seed -> ( a, Seed )` का उपयोग किया जाए, जो एक वैल्यू और एक नया सीड लौटाता है। ध्यान दीजिए कि ये दोनों फंक्शन प्योर हैं, इसलिए एक ही आर्गुमेंट के साथ दो बार कॉल करने पर वही वैल्यू मिलेंगी।

वैल्यू बनाने का दूसरा तरीका `generate : (a -> msg) -> Generator a -> Cmd msg` का उपयोग करना है, लेकिन यह केवल Elm एप्लिकेशन के अंदर ही किया जा सकता है। ऐसी स्थिति में Elm रनटाइम सीड बनाने के लिए `step` के साथ-साथ बाहरी, गैर-प्योर संसाधनों का भी उपयोग कर सकता है।

अब से हम जनरेटर पर ध्यान देंगे।

उदाहरण दिखाने के लिए मान लीजिए कि हमने `initialSeed` और `step` की मदद से एक फंक्शन `generate : Int -> Generator a -> List a` बनाया है, जो एक जनरेटर से कई वैल्यू बनाता है।

`Random` मॉड्यूल एक तय रेंज के भीतर पूर्णांक और दशमलव संख्याएँ बनाने के लिए दो बुनियादी जनरेटर देता है:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

उन वैल्यू को टपल में, या वैल्यू की लिस्ट में जोड़ा जा सकता है:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra` पैकेज कई तरह के डेटा स्ट्रक्चर के लिए बहुत सारे और जनरेटर देता है: स्ट्रिंग, तारीखें, डिक्शनरी, ऐरे, सेट, इत्यादि।

`Random.constant` का उपयोग करके हम ऐसे जनरेटर बना सकते हैं जो केवल एक ही वैल्यू लौटाएँगे:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform` का उपयोग करके हम दिए गए एलिमेंट में से बराबर संभावना के साथ कोई एक चुन सकते हैं:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` दो आर्गुमेंट लेता है (`Red` और `[Green, Blue]`) ताकि यह पक्का हो कि चुनने के लिए कम से कम एक वैल्यू तो हो, क्योंकि एक अकेली लिस्ट खाली हो सकती है।

हम `Random.weighted` का उपयोग करके संभावनाओं को बदल भी सकते हैं:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

वैल्यू का जोड़ 100 होना ज़रूरी नहीं है, इन्हें फिर भी सामान्य रूप में बाँट लिया जाता है।

हम `Random.map` की मदद से जनरेटर के अंदर तक पहुँच सकते हैं:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

हम अधिक जनरेटर जोड़ने के लिए `Random.map2` से लेकर `Random.map5` तक का उपयोग कर सकते हैं:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

और जटिल उपयोगों के लिए हमारे पास `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` है, जो एक जनरेटर से बनी वैल्यू का उपयोग करके दूसरा जनरेटर बना सकता है:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

कभी-कभी एक जनरेटर को खुद को बार-बार बुलाते हुए बनाना काम का होता है। ऐसी स्थितियों में आपको `Random.lazy` का उपयोग करना पड़ सकता है ताकि कंपाइलर जनरेटर को बिना रुके खोलता न चला जाए।

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

यह उदाहरण थोड़ा भारी है, तो चलिए इसे टुकड़ों में समझते हैं।

`Peano` एक टाइप है जो धनात्मक पूर्णांक दर्शाता है: `Zero` का मतलब 0 है, `Next(Zero)` का 1, `Next(Next(Zero))` का 2, इत्यादि। हम `peano` को इस तरह बनाते हैं कि वह हमें एक रैंडम `Peano` संख्या दे।

सबसे पहले ध्यान दीजिए कि `Random.lazy` तर्क में कुछ नहीं जोड़ता, यह केवल कंपाइलर को `peano` को `peano` में अनंत तक लिखते जाने से रोकता है।

हम `Random.uniform` का उपयोग शून्य (50% संभावना के साथ) और किसी दूसरी `Peano` संख्या से एक अधिक (50% संभावना के साथ) में से चुनने के लिए करते हैं। लेकिन पिछले उदाहरण के विपरीत, `Random.uniform` वैल्यू (जैसे `Zero`) में से नहीं, बल्कि जनरेटर (जैसे `Random.constant Zero`) में से चुन रहा है, क्योंकि हमें `peano` का ही उपयोग करना है। इसका मतलब है कि `Random.uniform` `Generator (Generator Peano)` टाइप की वैल्यू लौटाएगा, जो हमें चाहिए वह नहीं है।

जनरेटर को "फ्लैट" करने के लिए हम उसे `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` में पाइप करते हैं, जहाँ हम चाहते हैं कि `b` का मतलब `Peano` हो। चूँकि `Generator a` का मतलब `Generator (Generator Peano)` है, `a` को `Generator Peano` होना चाहिए, और फंक्शन `(a -> Generator b)` का टाइप `(Generator Peano -> Generator Peano)` होना चाहिए। हम कुछ भी बदलना नहीं चाहते, इसलिए `identity` सही चुनाव है।

अंत में, `peano` किस तरह की संख्याएँ बनाएगा? हम जानते हैं कि यह 50% बार 0 बनाएगा, और 50% बार खुद को फिर से चलाकर मिली संख्या से एक अधिक बनाएगा। इसका मतलब है कि संख्याएँ होंगी: 0 (50% बार), 1 (25% बार), 2 (12% बार), 3 (6% बार), इत्यादि। `peano` बहुत बड़ी संख्याएँ बना सकता है, लेकिन उनकी संभावना तेज़ी से घटती जाती है।
