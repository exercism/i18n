# टेस्ट

आप दिए गए टेस्ट DrRacket से या कमांड लाइन से चला सकते हैं।

टेस्ट को DrRacket से चलाने के लिए बस टेस्ट फाइल खोलिए और ऊपर दाईं ओर मौजूद 'Run' बटन पर क्लिक कीजिए।

टेस्ट को कमांड लाइन से चलाने के लिए बस अभ्यास डायरेक्टरी से टेस्ट चलाइए। उदाहरण के लिए, अगर टेस्ट सूट का नाम `hello-world-test.rkt` है, तो आप यह कमांड चला सकते हैं:

```
raco test hello-world-test.rkt
```

जो यह दिखाएगा:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
