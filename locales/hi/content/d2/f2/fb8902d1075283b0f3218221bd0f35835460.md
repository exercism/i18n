# विवरण

Gleam में फर्स्ट क्लास फंक्शन होते हैं। इसका मतलब है कि फंक्शन भी आम वैल्यू की तरह होते हैं: इन्हें वेरिएबल में असाइन किया जा सकता है, आर्गुमेंट के तौर पर भेजा जा सकता है, और दूसरे फंक्शन से लौटाया जा सकता है।

किसी मॉड्यूल में बनाए गए नाम वाले फंक्शन का इस्तेमाल उसके नाम से किया जा सकता है।

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam में अनोनिमस फंक्शन भी होते हैं, जिन्हें दूसरे फंक्शन के अंदर बनाया जाता है।

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

फंक्शन का टाइप भी लगभग अनोनिमस फंक्शन जैसे सिंटैक्स में लिखा जाता है। जो फंक्शन एक `Int` और एक `Float` लेता है और एक `Int` लौटाता है, उसका टाइप ऐसे लिखा जाता है:

```gleam
fn(Int, Float) -> Int
```

अनोनिमस फंक्शन उन वेरिएबल को भी इस्तेमाल कर सकते हैं जो उन्हें बनाने के समय स्कोप में थे। इस वजह से इन्हें _क्लोज़र_ कहा जाता है।

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_फंक्शन कैप्चर_ सिंटैक्स अनोनिमस फंक्शन बनाने का एक आसान छोटा तरीका देता है, जो किसी फंक्शन को सिर्फ एक आर्गुमेंट भेजता है। ये दोनों एक्सप्रेशन बराबर हैं:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
