# परिचय

Gleam में `Iterator` एक ऐरे की तरह होता है, यानी वैल्यू का एक क्रमबद्ध संग्रह जिसमें सारी वैल्यू एक ही डेटा टाइप की होती हैं। यह ऐरे से इस बात में अलग है कि यह लेज़ी होता है, यानी यह अपनी सारी वैल्यू एक साथ मेमोरी में संग्रहीत नहीं करता, बल्कि ज़रूरत के समय उनकी गणना करता है।

यह तब बहुत काम आता है जब हम बहुत बड़े या अनंत लंबाई वाले अनुक्रमों के साथ काम कर रहे हों, क्योंकि ऐसे समय में भी हम उनके साथ काम कर पाते हैं जब उन सबको एक साथ संग्रहीत करने के लिए हमारे पास पर्याप्त खाली मेमोरी नहीं होती।

`gleam/iterator` मॉड्यूल `Iterator` टाइप को परिभाषित करता है, साथ ही इटरेटर के साथ काम करने वाले फंक्शन भी देता है।

ऐरे के लिए मौजूद बहुत-से फंक्शन इटरेटर के लिए भी होते हैं, जैसे `map`, `filter` और `take`. ये फंक्शन इटरेटर लौटाते हैं, इसलिए इटरेटर को कंज्यूम किए जाने तक ये असल में कोई काम नहीं करते।

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` फंक्शन की मदद से किसी ऐसे फंक्शन से इटरेटर बनाए जा सकते हैं जिसे अनुक्रम की अगली वैल्यू बनाने के लिए बार-बार कॉल किया जाता है।

यहाँ `unfold` फंक्शन से एक ऐसा इटरेटर बनाया गया है जो फिबोनाची अनुक्रम बनाता है:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

यहाँ अनुक्रम अनंत है, इसलिए वैल्यू को ऐरे में इकट्ठा करने से पहले `take` फंक्शन की मदद से इसे सीमित बनाया जाता है। किसी अनंत इटरेटर पर `to_list` कॉल करने पर प्रोग्राम तब तक चलता रहेगा जब तक प्रोग्राम की मेमोरी खत्म न हो जाए और वह क्रैश हो जाए।
