# टर्नरी ऑपरेटर

टर्नरी ऑपरेटर, `if..else..` तुलना करने और कोई वैल्यू लौटाने के लिए एक वैकल्पिक सिंटैक्स देता है।

## सिंटैक्स

PHP में `if` स्टेटमेंट होता है, जिसमें किसी शर्त की "सच्चाई" के आधार पर कोई काम किया जा सकता है।

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

दूसरे तरीके से, टर्नरी ऑपरेटर से यही काम ऐसे दिखाया जा सकता है:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

तुलना का सिंटैक्स छोटा होता है, जिसे `(condition) ? (evaluate if true) : (evaluate if false);` से दिखाया जाता है।

## लाभ

टर्नरी ऑपरेटर का सबसे साफ लाभ तो यह है कि यह छोटा होता है: `if..else..` स्टेटमेंट की तुलना में इसमें शर्त वाला एक्सप्रेशन लिखना बहुत कम जगह लेता है। लेकिन इसके अलावा भी कई लाभ हैं:

- यह एक एक्सप्रेशन है, इसलिए इसे किसी दूसरे एक्सप्रेशन के अंदर इस्तेमाल किया जा सकता है।
- इससे हर शाखा का मूल्यांकन तभी होता है जब उसकी ज़रूरत होती है।

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  इस उदाहरण में, अगर सटीक जवाब की ज़रूरत नहीं है, तो वह महँगी गणना करने वाला फंक्शन कॉल नहीं होता।

## कमियाँ

टर्नरी ऑपरेटर की भी कई कमियाँ हैं, इसलिए इसका इस्तेमाल करने से पहले अच्छी तरह सोचना ज़रूरी है:

- टर्नरी ऑपरेटर पढ़ने में कठिन हो सकता है, क्योंकि यह कीवर्ड के बजाय प्रतीकों को समझने पर निर्भर करता है।
- टर्नरी ऑपरेटर से अनजाने में बग भी पैदा हो सकते हैं, क्योंकि PHP में टर्नरी ऑपरेटर बाएँ से जुड़ता है, जबकि ज़्यादातर आधुनिक भाषाओं (जैसे C, Java, JavaScript) में यह दाएँ से जुड़ता है।
- सही या गलत शाखा में मूल्यांकित होने वाले एक्सप्रेशन को कोई वैल्यू लौटानी ही होती है।

## इससे भी छोटा

टर्नरी सिंटैक्स को और छोटा किया जा सकता है: `(condition) ?: (evaluate if falsey)`.
इसका एक इस्तेमाल यह हो सकता है कि किसी एक्सप्रेशन में फॉलबैक वैल्यू दी जा सके:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

इसे कभी-कभी _Elvis operator_ (`?:`) भी कहा जाता है।
