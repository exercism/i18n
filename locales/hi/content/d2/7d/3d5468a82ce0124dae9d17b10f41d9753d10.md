# परिचय

## मॉड्यूल

Gleam का कोड मॉड्यूल में बाँटा जाता है, और हर फाइल एक Gleam मॉड्यूल होती है।

अब तक हमने फंक्शन `pub fn` सिंटैक्स से लिखे हैं। इस सिंटैक्स से बनाया गया फंक्शन दूसरे मॉड्यूल के लिए सार्वजनिक रूप से उपलब्ध होता है। जो फंक्शन `fn` से बनाए जाते हैं, वे उसी मॉड्यूल तक सीमित रहते हैं जिसमें उन्हें बनाया गया है, और दूसरे मॉड्यूल उनका उपयोग नहीं कर सकते।

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam मॉड्यूल के नाम होते हैं, और यह नाम `src` या `test` डायरेक्टरी के अंदर उसके फाइल पाथ पर आधारित होता है।

उदाहरण के लिए, `src\geometry\rectangle.gleam` (Windows पर) या `src/geometry/rectangle.gleam` (UNIX जैसे ऑपरेटिंग सिस्टम पर) में बनाए गए मॉड्यूल का नाम `geometry/rectangle` होगा।

## दूसरे मॉड्यूल से फंक्शन इम्पोर्ट करना

दूसरे मॉड्यूल में बनाए गए फंक्शन तक पहुँचने का काम इम्पोर्ट से होता है।
जब आप किसी मॉड्यूल को इम्पोर्ट करते हैं, तो उस मॉड्यूल के अंदर के वे सारे फंक्शन उपलब्ध हो जाते हैं जिन्हें उसने बाहर के लिए खोला है।
लेकिन उन तक पहुँचने का तरीका इस पर बदलता है कि मॉड्यूल कैसे इम्पोर्ट किया गया है।

क्वालिफाइड इम्पोर्ट डिफॉल्ट होते हैं। ऐसे मॉड्यूल के किसी फंक्शन तक पहुँचने के लिए मॉड्यूल का नाम आगे लगाया जाता है (जैसे `gleam/list` मॉड्यूल के `map` फंक्शन के लिए `list.map`)।

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

डिफॉल्ट रूप से मॉड्यूल को जिस नाम से पुकारा जाता है, वह मॉड्यूल के नाम का अंतिम हिस्सा होता है, यहाँ `int`। लेकिन `as` कीवर्ड इस्तेमाल करके इसे बदला जा सकता है।

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

अनक्वालिफाइड इम्पोर्ट से उस मॉड्यूल के सार्वजनिक फंक्शन तक सीधे पहुँचा जा सकता है, बिना नाम आगे लगाए।

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

क्वालिफाइड इम्पोर्ट को प्राथमिकता दी जाती है, क्योंकि इससे पाठक को साफ पता चलता है कि फंक्शन कहाँ से आ रहा है, और नामों के टकराव से भी बचाव होता है।


## मानक लाइब्रेरी

Gleam की मानक लाइब्रेरी बहुत समृद्ध है और उसका डॉक्युमेंटेशन अच्छी तरह से तैयार है। यह डॉक्युमेंटेशन ऑनलाइन [hexdocs.pm/gleam_stdlib][docs] पर उपलब्ध है। इस लिंक को कहीं सहेज लीजिए, आप इसका बहुत उपयोग करेंगे!

ज़्यादातर बिल्ट-इन डेटा टाइप के लिए एक उससे जुड़ा मॉड्यूल होता है, जो उस डेटा टाइप पर काम करने के फंक्शन देता है। जैसे पूर्णांक के लिए `gleam/int` मॉड्यूल है, स्ट्रिंग के लिए `gleam/string` मॉड्यूल, ऐरे के लिए `gleam/list` मॉड्यूल, और इसी तरह आगे भी।

[docs]: https://hexdocs.pm/gleam_stdlib/
