# परिचय

## पूर्णांक

पूर्णांक वे पूर्ण संख्याएँ हैं जो `{..., -2, -1, 0, 1, 2, ...}` समुच्चय में आती हैं।
किसी पूर्णांक का अधिकतम और न्यूनतम मान उस सिस्टम से तय होता है जिसमें PHP चलता है।
आम तौर पर अधिकांश आधुनिक सिस्टमों में पूर्णांक एक 64-बिट वैल्यू होती है, यानी यह `-9_223_372_036_854_775_808` से `9_223_372_036_854_775_807` तक (दोनों सहित) की संख्याएँ दर्शा सकती है।

```php
<?php

$a = 1234;
$a = 1_234_567;
```

आप बेस प्रीफिक्स का इस्तेमाल करके पूर्णांक लिटरल वैल्यू 10 के अलावा किसी और बेस में भी लिख सकते हैं:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> PHP के [डॉक्युमेंटेशन][syntax] से लिया गया

## दशमलव संख्याएँ

दशमलव संख्याएँ PHP में वास्तविक संख्याओं के एक उपसमुच्चय को दर्शाने के लिए इस्तेमाल की जाती हैं।
ये एक या अधिक अंकों से शुरू होती हैं, जिन्हें एक दशमलव विभाजक अलग करता है।

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### आम गलतियाँ

सभी संख्याओं और अंकगणितीय क्रियाओं को दशमलव संख्याओं के साथ नहीं किया जा सकता।
डॉलर और सेंट दर्शाने के लिए दशमलव संख्याओं का इस्तेमाल करने से राउंडिंग एरर हो सकती है।

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## अंकगणितीय ऑपरेटर

PHP अंकगणितीय क्रियाएँ करने के लिए कई ऑपरेटर देता है। PHP अपने अंकगणितीय ऑपरेटरों के लिए गणित का मानक क्रम अपनाता है। PHP जो ऑपरेटर देता है, वे हैं:

* तत्समक (+)
* ऋणात्मकता (-)
* जोड़ (+)
* घटाव (-)
* गुणा (*)
* भाग (/)
* मॉड्यूलो (%)
* घातांक (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
