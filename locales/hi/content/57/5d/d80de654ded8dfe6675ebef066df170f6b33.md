# परिचय

Rust में जो भी टाइप [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) trait को लागू करता है, उसे इटरेटर की तरह इस्तेमाल किया जा सकता है।
Rust के बिल्ट-इन [`collections`](https://doc.rust-lang.org/std/collections/index.html) को `iter`, `iter_mut`, और `into_iter` मेथड की मदद से इटरेटर में बदला जा सकता है।
इटरेटर में कई [शक्तिशाली मेथड](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods) हैं, जैसे `collect`, `map`, `filter`, और `fold`। इनकी मदद से आप अपने डेटा पर अलग-अलग काम कर सकते हैं।

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
