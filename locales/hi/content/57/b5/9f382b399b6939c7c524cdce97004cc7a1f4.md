# निर्देश

Boris मॉडल ट्रेनों के बड़े शौकीन हैं और उन्होंने अपनी इस दिलचस्पी को दुनिया के साथ बाँटने का फैसला किया है: वे एक न्यूज़लेटर शुरू करेंगे। वे न्यूज़लेटर का पहला अंक उन दोस्तों और परिचितों को भेजेंगे जो इस शौक को साझा करते हैं। उनके ईमेल पते एक टेक्स्ट फाइल में रखे हुए हैं।

संकेत: फाइल से जुड़े कामों के लिए [simplifile](https://hexdocs.pm/simplifile/simplifile.html) मॉड्यूल इस्तेमाल कीजिए।

## 1. किसी फाइल से ईमेल पते पढ़िए

`read_emails` फंक्शन बनाइए। यह ऐसी टेक्स्ट फाइल का पाथ लेता है जिसमें हर ईमेल पता नई लाइन पर लिखा होता है, और फाइल में मौजूद सारे ईमेल पतों का एक ऐरे लौटाता है।

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. लिखने के लिए लॉग फाइल बनाइए

ईमेल भेजना एक ऐसा काम है जो कई अप्रत्याशित कारणों से असफल हो सकता है, जैसे ईमेल पता लिखने में हुई कोई गलती या नेटवर्क की अस्थायी समस्या। यह सुनिश्चित करने के लिए कि आप सभी दोस्तों को बिना एक ही ईमेल दोबारा भेजे, फिर से भेजने की कोशिश कर सकें, आपको उन ईमेल पतों को लॉग करना होगा जिन्हें ईमेल पहले ही भेजा जा चुका है। इसके लिए आपको एक लॉग फाइल चाहिए होगी।

`create_log_file` फंक्शन बनाइए। यह एक फाइल पाथ लेता है और उस जगह पर एक नई खाली फाइल बनाता है।

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. भेजा गया ईमेल लॉग कीजिए

`log_sent_email` फंक्शन बनाइए। यह लॉग फाइल का पाथ और ईमेल पता वाली एक स्ट्रिंग लेता है। यह ईमेल पता फाइल में लिखता है और उसके बाद एक नई लाइन जोड़ता है।

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. न्यूज़लेटर भेजिए

अब जब आपके पास ईमेल भेजने की पूरी प्रक्रिया के सारे हिस्से तैयार हैं, तो आपको इन सबको एक ही फंक्शन में जोड़ना है।

`send_newsletter` फंक्शन बनाइए। यह ईमेल पतों वाली फाइल का पाथ, एक लॉग फाइल का पाथ, और एक अनाम फंक्शन लेता है जो किसी दिए गए ईमेल पते पर ईमेल भेजता है।

इसे दी गई फाइल से सारे ईमेल पते पढ़ने चाहिए और हर पते पर ईमेल भेजने की कोशिश करनी चाहिए। अगर ईमेल भेजने वाला अनाम फंक्शन कोई `Ok` वैल्यू लौटाता है, तो उस ईमेल पते को लॉग फाइल में लिखिए। ध्यान रखिए कि ईमेल भेजे जाते ही यह काम हो जाना चाहिए।

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
