# निर्देश

लैमॉन्ट एक Lisp एलियन है जो अपना खुद का वीडियो गेम बनाना चाहता है। उसने आपसे जिस एक काम में मदद माँगी है, वह है हाई स्कोर की सूची का हिसाब रखना।

## 1. हाई स्कोर टेबल बनाना

एक फंक्शन `make-high-score-table` बनाइए जो कोई आर्गुमेंट नहीं लेता और एक नई खाली हैश टेबल देता है:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. टेबल में खिलाड़ी जोड़ना

टेबल में एक खिलाड़ी जोड़ने के लिए एक फंक्शन `add-player` बनाइए जो दो आर्गुमेंट लेता है:
- हाई स्कोर टेबल
- खिलाड़ी का नाम, एक कीवर्ड के रूप में

खिलाड़ी का शुरुआती स्कोर शून्य रखिए।

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. खिलाड़ी का स्कोर सेट करना

किसी खिलाड़ी का स्कोर सेट करने के लिए एक फंक्शन `set-score` बनाइए जो तीन आर्गुमेंट लेता है:
- हाई स्कोर टेबल
- खिलाड़ी का नाम, एक कीवर्ड के रूप में
- खिलाड़ी का स्कोर, एक पूर्णांक के रूप में

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. टेबल से स्कोर पाना

टेबल से किसी खिलाड़ी का स्कोर पाने के लिए एक फंक्शन `get-score` बनाइए जो दो आर्गुमेंट लेता है:
- हाई स्कोर टेबल
- खिलाड़ी का नाम, एक कीवर्ड के रूप में

इस फंक्शन को खिलाड़ी के लिए संग्रहीत स्कोर देना चाहिए।
अगर उस खिलाड़ी के लिए कोई स्कोर संग्रहीत नहीं है, या वह खिलाड़ी अभी टेबल में नहीं है, तो इसका मान `0` होना चाहिए।

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. टेबल से खिलाड़ी हटाना

हाई स्कोर टेबल से किसी खिलाड़ी को हटाने के लिए एक फंक्शन `remove-player` बनाइए जो दो आर्गुमेंट लेता है:
- हाई स्कोर टेबल
- खिलाड़ी का नाम, एक कीवर्ड के रूप में

इस फंक्शन को ऐसे मामले भी ठीक से संभालने चाहिए जिनमें खिलाड़ी को अभी टेबल में जोड़ा ही नहीं गया हो।
स्वाभाविक है कि किसी खिलाड़ी को हटाने के बाद अगर टेबल से उसका स्कोर लिया जाए, तो वह शून्य होगा।

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
