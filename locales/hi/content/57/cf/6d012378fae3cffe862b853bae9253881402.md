# Java इंस्टॉल कीजिए

Exercism CLI और अपने पसंदीदा टेक्स्ट एडिटर के अलावा, Java में Exercism के अभ्यास करने के लिए **Java Development Kit** (JDK) भी ज़रूरी है। JDK में Java Runtime _और_ डेवलपमेंट टूल, दोनों शामिल होते हैं (जिनमें सबसे खास है Java कंपाइलर)।

आजकल JDK के कई रूप मिलते हैं, जिनमें से कुछ ओपन-सोर्स हैं। Exercism में हम [Eclipse Temurin by Adoptium][adoptium] इस्तेमाल करने की सलाह देते हैं।

## समर्थित Java वर्शन

Exercism के Java ट्रैक में Java 25 LTS और उससे पहले के वर्शन समर्थित हैं।

## Eclipse Temurin इंस्टॉल कीजिए

अपने सिस्टम पर Eclipse Temurin इंस्टॉल करने के लिए, उनके बेहतरीन [इंस्टॉलेशन निर्देशों][adoptium-installation-guide] पर पहुँचिए। यहाँ आपको बताया गया है कि अपने पसंदीदा पैकेज मैनेजर से JDK कैसे इंस्टॉल करें। साथ ही, यहाँ सभी प्रमुख ऑपरेटिंग सिस्टम के लिए डाउनलोड करने योग्य इंस्टॉलर के लिंक भी हैं।

## Java के लिए IDE

Java के लिए कई मुफ्त IDE उपलब्ध हैं। इनमें से कुछ लोकप्रिय विकल्प यह हैं:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Java एक्सटेंशन के साथ Visual Studio Code][vscode-java]
