# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग     | टाइप    | विवरण                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | इनपुट     | पता | अंत में null वाली इनपुट स्ट्रिंग                      |
| `$v0`    | आउटपुट    | बूलियन | इनपुट एक आइसोग्राम है (`0` = `false`, `1` = `true`) |
| `$t0-9`  | अस्थायी | कोई भी     | अस्थायी भंडारण के लिए                        |
