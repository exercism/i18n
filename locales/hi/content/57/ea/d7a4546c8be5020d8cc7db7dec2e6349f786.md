# परिचय

`OpenStruct` आपको आसानी से एक `Hash` से एक ऑब्जेक्ट बनाने देता है। 
`Hash` कीज़ के ज़रिए वैल्यू तक पहुँचने के बजाय, `OpenStruct` हमें मेथड का उपयोग करके वैल्यू को पढ़ने और लिखने की सुविधा देता है।


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

इस तरीके का एक फायदा यह है कि ब्लॉक सिंटैक्स का उपयोग करते समय हम एक शॉर्टकट का लाभ उठा सकते हैं। 
ऐसी स्थितियों में जहाँ एक ब्लॉक एक ही मेथड को कॉल करता है, आप ब्लॉक को `&:` और उसके बाद मेथड के नाम से बदल सकते हैं। 
उदाहरण के लिए, ये दोनों लाइनें समान हैं:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## स्टैंडर्ड लाइब्रेरी

आपने पिछले अभ्यासों में जो क्लास देखी हैं, वे सभी Ruby की कोर लाइब्रेरी का हिस्सा रही हैं।

OpenStruct Ruby की स्टैंडर्ड लाइब्रेरी का हिस्सा है (जिसे अक्सर "stdlib" कहा जाता है), जो क्लास का एक संग्रह है और तारीखों, json, और नेटवर्किंग जैसी चीज़ों के साथ काम करने के लिए है।
यह आपके कोड के साथ काम करना आसान बनाने के लिए कुछ उपयोगी सुविधाएँ भी प्रदान करता है।

जब हम ऐसी क्लास का उपयोग करते हैं जो कोर लाइब्रेरी से नहीं हैं, जैसे अलग-अलग फाइलों में आपका अपना कोड, stdlib से क्लास, या बाहरी डिपेंडेंसी, तो हमें उनका उपयोग करने से पहले `require` मेथड का उपयोग करके उन्हें इम्पोर्ट करना होता है।
उदाहरण के लिए:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
