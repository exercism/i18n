# निर्देश

आप एक शोध स्टेशन के सुरक्षा डेस्क पर काम करते हैं। स्टाफ *बैज* लेकर चलते हैं, जिनके कोड एक तय फॉर्मैट का पालन करते हैं। एक्सेस लॉग में ये कोड आम टेक्स्ट के बीच भरे पड़े हैं, और साझा करने से पहले लॉग को साफ करना पड़ता है। इन सभी कामों के लिए रेगुलर एक्सप्रेशन सही टूल है।

एक मान्य बैज कोड में **दो बड़े अक्षर, एक डैश, और फिर चार अंक** होते हैं। उदाहरण के लिए `NS-1024`.

## 1. बैज कोड की जाँच कीजिए

`valid-badge?` बनाइए। यह एक बैज स्ट्रिंग लेता है। अगर *पूरी* स्ट्रिंग एक मान्य बैज कोड है तो यह `t` लौटाता है, वरना `f` लौटाता है।

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. लॉग लाइन से हर कोड निकालिए

`badge-codes` बनाइए। यह एक्सेस लॉग की एक लाइन लेता है और उसमें जो भी बैज कोड दिखते हैं, उन सबका क्रम में एक सीक्वेंस लौटाता है।

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. कोड के अंक गिनिए

`digit-count` बनाइए। यह एक स्ट्रिंग लेता है और लौटाता है कि उसमें कितने अंक हैं।

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. पासवर्ड छिपाइए

लॉग की लाइनों में कभी-कभी पासवर्ड `pass=` के बाद लिखा होता है, यानी वह गुप्त हिस्सा जो स्पेस को छोड़कर किन्हीं भी अक्षरों का क्रम हो सकता है। `redact` बनाइए। यह एक लाइन लेता है और उसे इस तरह लौटाता है कि हर ऐसा पासवर्ड `pass=****` से बदल दिया गया हो।

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
