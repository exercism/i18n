# निर्देश

लेस्ली नाम के Lisp Alien अपने भूलभुलैया वाले रोबोट को प्रोग्राम कर रहे हैं (जैसा कि नए-नए Lisp Alien अक्सर करते हैं) और उन्हें थोड़ी मदद चाहिए। भूलभुलैया कई कमरों से बनी है। हर कमरे में कई दरवाज़े हैं। हर दरवाज़े के लिए एक चाबी चाहिए। अगर आप किसी दरवाज़े पर गलत चाबी लगाते हैं तो वह दरवाज़ा फट सकता है (रोबोट के बारे में चिंता की ज़रूरत नहीं, उसे कोई नुकसान नहीं होगा, लेकिन जले के निशान रगड़कर मिटाना लेस्ली के लिए काफी झंझट भरा काम है)। अगर रोबोट के पास कोई भी दरवाज़ा खोलने वाली चाबी न हुई, तो पूरा कमरा फट जाएगा! (फिर कहें, चिंता की बात नहीं, इससे कोई नुकसान नहीं होगा, बस साफ करना झंझट भरा होगा।)

लेस्ली की मदद के लिए आपको रोबोट को हर कमरे की सही चाबी देनी है। रोबोट कमरे के हर दरवाज़े पर यह चाबी एक-एक करके लगाएगा और जो पहला दरवाज़ा खुलेगा, उसी में से निकल जाएगा।

हर टेस्ट एक भूलभुलैया है और हर जाँच एक कमरा। आपको ऐसे प्रेडिकेट फंक्शन लिखने हैं जिनका परिणाम तब `T` होता है जब आर्गुमेंट बराबर हों, और `NIL` तब जब वे बराबर न हों।

## 1. ऑब्जेक्ट की समानता की भूलभुलैया

इस भूलभुलैया में सिर्फ एक ही कमरा है। आपको एक ऐसा फंक्शन देना है जो बता सके कि दो ऑब्जेक्ट एक ही ऑब्जेक्ट हैं या नहीं।

उदाहरण के लिए:

```lisp
a                         ; => "pizza"
b                         ; => "pizza"

(key-object-identity a a) ; => T
(key-object-identity a b) ; => NIL
```

क्योंकि `a` और `b` दिखने में एक जैसे हैं, पर वे एक ही ऑब्जेक्ट नहीं हैं।

## 2. संख्याओं की भूलभुलैया

इस भूलभुलैया में दो कमरे हैं। पहले कमरे का दरवाज़ा तभी खुलेगा जब आपकी चाबी बता सके कि दो संख्याएँ बिल्कुल बराबर हैं या नहीं। दूसरे कमरे के लिए ऐसी चाबी चाहिए जो संख्याओं की बराबरी जाँचते समय थोड़ी छूट देती हो।

उदाहरण के लिए:

```lisp
a                                    ; => 13
b                                    ; => 13.0
c                                    ; => 13

(key-numbers a b)                    ; => NIL
(key-numbers a c)                    ; => T
(key-numbers-of-different-types a b) ; => T
```

क्योंकि `a` और `b` संख्या के रूप में एक ही हैं, पर उनके टाइप अलग-अलग हैं।

## 3. अक्षरों की भूलभुलैया

इस भूलभुलैया में दो कमरे हैं। पहले कमरे का दरवाज़ा तभी खुलेगा जब आपकी चाबी बता सके कि दो अक्षर बिल्कुल बराबर हैं या नहीं। दूसरे कमरे के लिए ऐसी चाबी चाहिए जो अक्षरों की तुलना करते समय छोटे-बड़े अक्षरों का फर्क न करे।

उदाहरण के लिए:

```lisp
a                                       ; => #\X
b                                       ; => #\x
c                                       ; => #\X

(key-characters a b)                    ; => NIL
(key-characters a c)                    ; => T
(key-characters-case-insensitively a b) ; => T
```

क्योंकि दो अक्षरों की तुलना करते समय छोटे-बड़े अक्षरों का फर्क सिर्फ बहुत छूट देने वाले प्रेडिकेट ही अनदेखा करते हैं।

## 4. स्ट्रिंग की भूलभुलैया

अक्षरों की भूलभुलैया की तरह यहाँ भी पहले कमरे के लिए ऐसी चाबी चाहिए जो जाँचे कि दो स्ट्रिंग बराबर हैं या नहीं, और दूसरे कमरे के लिए ऐसी चाबी जो छोटे-बड़े अक्षरों का फर्क न करते हुए तुलना करे।

उदाहरण के लिए:

```lisp
a                                    ; => "pizza"
b                                    ; => "PIZZA"
c                                    ; => "pizza"

(key-strings a b)                    ; => NIL
(key-strings a c)                    ; => T
(key-strings-case-insensitively a b) ; => T
```

क्योंकि दो स्ट्रिंग की तुलना करते समय छोटे-बड़े अक्षरों का फर्क सिर्फ बहुत छूट देने वाले प्रेडिकेट ही अनदेखा करते हैं।

## 5. कॉन्स की भूलभुलैया

यह एक बड़ी भूलभुलैया है जिसमें कई कमरे हैं। हर कमरे के लिए ऐसी चाबी चाहिए जो जाँचे कि कॉन्स के _अंदर_ मौजूद चीज़ें बराबर हैं या नहीं। हर कमरा अलग-अलग अंदरूनी चीज़ों वाले कॉन्स की बराबरी जाँचेगा: सिंबल, संख्या और अक्षर; और कुछ कमरों के लिए इन चीज़ों की और भी लचीली बराबरी की परिभाषाएँ चाहिए होंगी।

उदाहरण के लिए:

```lisp
syms-a                                     ; => (left . right)
syms-b                                     ; => (up . down)
syms-c                                     ; => (left . right)
chars-a                                    ; => (#\x . #\y)
chars-b                                    ; => (#\x . #\Y)
chars-c                                    ; => (#\x . #\y)
nums-a                                     ; => (13 . 23)
nums-b                                     ; => (13 . 23.0)
nums-c                                     ; => (13 . 23)


(key-conses-of-symbols syms-a syms-b)      ; => NIL
(key-conses-of-symbols syms-a syms-c)      ; => T

(key-conses-of-characters chars-a chars-b) ; => NIL
(key-conses-of-characters chars-a chars-c) ; => T
(key-conses-of-characters-case-insensitively 
  chars-a chars-b)                         ; => T

(key-conses-of-numbers nums-a nums-b)      ; => NIL
(key-conses-of-numbers nums-a nums-c)      ; => T
(key-conses-of-numbers-of-different-types 
  nums-a nums-b)                           ; => T
```

क्योंकि कॉन्स के अंदर देखने वाला बराबरी का प्रेडिकेट भी तुलना करते समय छोटे-बड़े अक्षरों या संख्या के टाइप को अनदेखा करने के लिए काफी छूट देने वाला नहीं हो सकता।

## 6. ऐरे की भूलभुलैया

यह भूलभुलैया ज़्यादा आसान है और इसमें सिर्फ दो कमरे हैं।
पहले कमरे के लिए ऐसी चाबी चाहिए जो जाँचे कि ऐरे वही ऐरे हैं या नहीं।
दूसरे कमरे के लिए ऐसी चाबी चाहिए जो ऐरे के अंदर की चीज़ें जाँचे।

उदाहरण के लिए:

```lisp
a                        ; => #[13 23]
b                        ; => #[13 23]
c                        ; => #[13 23.0]

(key-arrays a b)         ; => NIL
(key-arrays a c)         ; => NIL
(key-arrays-loosely a b) ; => T
(key-arrays-loosely a c) ; => T
```

क्योंकि ऐरे के अंदर की चीज़ें बराबर हैं या नहीं, यह सिर्फ बहुत छूट देने वाले बराबरी जाँचने वाले ही जाँचते हैं।
