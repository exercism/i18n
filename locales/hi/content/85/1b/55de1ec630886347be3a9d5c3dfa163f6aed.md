# परिचय

## फंक्शन टाइप

किसी Swift फंक्शन सिग्नेचर से अगर सारे नाम और लेबल हटा दिए जाएँ, तो आपके पास उस फंक्शन का टाइप ही बचता है।

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

ध्यान दीजिए कि पहले दो फंक्शन के टाइप एक ही हैं, `(String, Int) -> String`, भले ही दोनों सिग्नेचर अलग हैं और दोनों फंक्शन बहुत अलग तरीके से काम करते हैं। दोनों इनपुट में एक `String` और एक `Int` लेते हैं और एक `String` लौटाते हैं। और तीसरे फंक्शन के टाइप से साफ़ दिखता है कि भले ही उस फंक्शन के अंदर का कोड कुछ लौटाता न दिखे, वह असल में अप्रत्यक्ष रूप से `()` लौटाता है, जो `Void` टाइप की एकमात्र वैल्यू है।

इन फंक्शन टाइपों का इस्तेमाल Swift में किसी भी और टाइप की तरह किया जा सकता है। जैसे, इन्हें वेरिएबल या कॉन्स्टेंट घोषित करने में इस्तेमाल किया जा सकता है। और चूँकि Swift में फंक्शन भी वैल्यू होते हैं, इसलिए पहले से मौजूद फंक्शन को इन कॉन्स्टेंट या वेरिएबलो में असाइन किया जा सकता है:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

बाकी वेरिएबलो और कॉन्स्टेंट की तरह, आप जो वैल्यू असाइन करते हैं वह सही टाइप की होनी चाहिए:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## पैरामीटर टाइप के रूप में फंक्शन टाइप

चूँकि फंक्शन टाइपों का इस्तेमाल वहीं किया जा सकता है जहाँ बाकी टाइपों का किया जा सकता है, इसलिए इन्हें पैरामीटर टाइप के रूप में भी इस्तेमाल किया जा सकता है। ऐसे फंक्शन टाइप दूसरे फंक्शन को दिए जा सकते हैं और उन फंक्शन के अंदर से कॉल किए जा सकते हैं।

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## रिटर्न टाइप के रूप में फंक्शन टाइप

इसी तरह, फंक्शन टाइपों का इस्तेमाल फंक्शन के रिटर्न टाइप के रूप में भी किया जा सकता है। दूसरे शब्दों में, आप ऐसे फंक्शन लिख सकते हैं जो दूसरे फंक्शन बनाकर लौटाते हैं। ऐसे फंक्शन बनाते समय, जो फंक्शन लौटाया जाता है वह उस फंक्शन को दिए गए बाकी पैरामीटर या पैरेंट फंक्शन के अंदर बनाए गए लोकल वेरिएबल का इस्तेमाल कर सकता है।

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
