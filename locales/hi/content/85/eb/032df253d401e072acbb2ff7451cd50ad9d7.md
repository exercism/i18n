# परिचय

Python में सही और गलत वैल्यू को [`bool`][bools] टाइप से दर्शाया जाता है, जो `int` का सबक्लास है। इस टाइप के अंतर्गत केवल दो वैल्यू आती हैं: `True` और `False`। इन वैल्यू को किसी वेरिएबल में रखा जा सकता है:

```python
>>> true_variable = True
>>> false_variable = False
```

हम `and`, `or` और `not` ऑपरेटरों की मदद से बूलियन एक्सप्रेशन का मूल्यांकन कर सकते हैं।

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
