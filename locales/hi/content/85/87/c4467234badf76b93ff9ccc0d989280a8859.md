# परिचय

*डिस्पोज़ेबल* हर उस चीज़ को कहते हैं जो ओएस का कोई संसाधन अपने पास रखती है, जैसे कोई खुली हुई फाइल, कोई सॉकेट, या हैश टेबल पर आधारित कोई लॉक। ऐसी चीज़ का काम पूरा होने पर उसे छोड़ देना ज़रूरी होता है। Factor का [`destructors`][destructors] वोकैब इन संसाधनों को एक छोटे फ्रेमवर्क में लपेट देता है, ताकि एक्सेप्शन के कारण स्टैक खुल जाने पर भी सफाई हो सके।

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` कोटेशन को संसाधन के साथ चलाता है और बाहर निकलते समय उस संसाधन को डिस्पोज़ कर देता है। एक से ज़्यादा संसाधन हों, तो `with-destructors` से एक स्कोप खोलिए और हर संसाधन को `&dispose` (सामान्य रूप से बाहर निकलने पर *और* एरर होने पर डिस्पोज़) या `|dispose` (सिर्फ एरर होने पर डिस्पोज़) के साथ रजिस्टर कीजिए।

कोई क्लास `disposable` को एक्सटेंड करके और `dispose*` जेनेरिक को लागू करके इस फ्रेमवर्क में शामिल होती है। फ्रेमवर्क हर ऑब्जेक्ट के लिए इस जेनेरिक को एक बार ही कॉल करता है, और सिर्फ एक बार। कॉल करने वाले जो सार्वजनिक वर्ड इस्तेमाल करते हैं, वह `dispose` है।
