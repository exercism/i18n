# टेस्ट

## टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
dotnet test
```

## अभ्यास हल करना

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना। डिफॉल्ट रूप से जब आप टेस्ट चलाते हैं, तो सिर्फ एक टेस्ट (सबसे पहला) चलता है। यह जानबूझकर ऐसा रखा गया है, ताकि आपका ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर रहे। वह पास हो जाए, तो आप अगला टेस्ट चालू कर सकते हैं। इसके लिए टेस्ट के `[<Fact>]` या `[<Theory>]` एट्रिब्यूट से `Skip = "Remove this Skip property to run this test"` हटा दीजिए। जब सारे टेस्ट चालू हो जाएँ और आपका इम्प्लीमेंटेशन उन सबको पास करा दे, तो समझिए कि आपने अभ्यास हल कर लिया!

शुरुआत करने में मदद के लिए हर अभ्यास के साथ एक स्टब इम्प्लीमेंटेशन फाइल मिलती है। आप इस फाइल को अपना हल बनाने की शुरुआत के तौर पर इस्तेमाल कर सकते हैं। अगर आपको लगे कि इस फाइल को हटाना या बदलना सही है, तो बेझिझक ऐसा कीजिए।

## पैकेज इस्तेमाल करना

अधिकतर अभ्यास आप बिना किसी बाहरी पैकेज के हल कर सकते हैं। लेकिन जिन अभ्यासों में आप बाहरी पैकेज इस्तेमाल करना चाहते हैं, उनके लिए यह कमांड चलाकर वह पैकेज अपने प्रोजेक्ट में जोड़ सकते हैं:

```bash
dotnet add package [package-name]
```
