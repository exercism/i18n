# परिचय

## संख्याएँ

Java में दो तरह की संख्याएँ होती हैं:

- पूर्णांक: वे संख्याएँ जिनके दशमलव चिह्न के बाद कोई अंक नहीं होता (पूर्ण संख्याएँ)। जैसे `-6`, `0`, `1`, `25`, `976` और `-500000`।
- दशमलव संख्याएँ: वे संख्याएँ जिनके दशमलव चिह्न के बाद शून्य या उससे अधिक अंक होते हैं। जैसे `-20.4`, `0.1`, `2.72`, `16.984025` और `1024.0`।

Java में सबसे आम संख्यात्मक टाइप `int` और `double` हैं।
`int` एक 32-बिट पूर्णांक है और `double` एक 64-बिट दशमलव संख्या।

अंकगणित के लिए सामान्य अंकगणितीय ऑपरेटर इस्तेमाल किए जाते हैं।
संख्याओं की तुलना सामान्य संख्यात्मक तुलना ऑपरेटरों (जैसे `5 > 4` और `4 <= 5`) तथा समानता (`==`) और असमानता (`!=`) ऑपरेटरों से की जा सकती है।

Java में संख्यात्मक कन्वर्ज़न दो तरह के होते हैं:

1. इम्प्लिसिट कन्वर्ज़न: इसमें कोई डेटा नष्ट नहीं होता और अतिरिक्त सिंटैक्स लिखने की ज़रूरत नहीं पड़ती।
2. एक्सप्लिसिट कन्वर्ज़न: इसमें डेटा नष्ट हो सकता है और _कास्ट_ के रूप में अतिरिक्त सिंटैक्स लिखना पड़ता है।

चूँकि `int` में `double` से कम परिशुद्धता होती है, इसलिए `int` को `double` में बदलना सुरक्षित है और यह एक इम्प्लिसिट कन्वर्ज़न है।
लेकिन `double` को `int` में बदलने पर डेटा नष्ट हो सकता है, इसलिए वहाँ एक्सप्लिसिट कन्वर्ज़न की ज़रूरत पड़ती है।

## if-else स्टेटमेंट

### _if-then_ स्टेटमेंट

Java में सबसे बुनियादी कंट्रोल फ्लो स्टेटमेंट _if-then_ स्टेटमेंट है।
इस स्टेटमेंट का इस्तेमाल कोड के किसी हिस्से को तभी चलाने के लिए किया जाता है जब कोई खास शर्त `true` हो।
_if-then_ स्टेटमेंट `if` क्लॉज़ की मदद से बनाया जाता है:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

ऊपर के उदाहरण में, अगर कार में ईंधन नहीं बचा है, तो `Car.drive` मेथड को कॉल करने पर कुछ भी नहीं होगा।

### _if-then-else_ स्टेटमेंट

_if-then-else_ स्टेटमेंट तब चलने का एक वैकल्पिक रास्ता देता है जब `if` क्लॉज़ की शर्त का मान `false` होता है।
यह वैकल्पिक रास्ता `if` क्लॉज़ के बाद आता है और `else` क्लॉज़ की मदद से बनाया जाता है:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

ऊपर के उदाहरण में, अगर कार में ईंधन नहीं बचा है, तो `Car.drive` मेथड को कॉल करने पर कार को रोकने के लिए दूसरा मेथड कॉल किया जाएगा।

_if-then-else_ स्टेटमेंट `else if` क्लॉज़ की मदद से कई शर्तों के साथ भी काम करता है:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

ऊपर के उदाहरण में, ईंधन `5` से कम या उसके बराबर होने पर कार चलेगी, लेकिन ईंधन की लाइट जल जाएगी।
जब ईंधन `0` तक पहुँच जाता है, तो कार चलना बंद कर देगी।
