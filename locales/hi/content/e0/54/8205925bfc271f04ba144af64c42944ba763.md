# ब्रैकेट के बारे में ज़रूरी बातें

Tcl एक [बहुत ही आसान भाषा](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm) है, लेकिन इसके इंटरप्रेटर के कोड पढ़ने के तरीके में कुछ पेचीदा एज केस हैं।

## घुंघराले ब्रैकेट

Tcl में घुंघराले ब्रैकेट का काम टेक्स्ट के एक ब्लॉक को उद्धृत करना भर है। उस टेक्स्ट को कोड या डेटा की तरह पढ़ा जा सकता है। ब्रैकेट के अंदर नेस्टेड ब्रैकेट भी आ सकते हैं, लेकिन नेस्टेड ब्रैकेट संतुलित होने चाहिए। Tcl के मैन पेज में यह लिखा है:

> ब्रैकेट शब्द के अंदर एक के अंदर एक आ सकते हैं: हर अतिरिक्त खुले ब्रैकेट के लिए एक अतिरिक्त बंद ब्रैकेट होना चाहिए (लेकिन अगर शब्द के अंदर कोई खुला या बंद ब्रैकेट _बैकस्लैश से उद्धृत_ हो, तो मेल खाते बंद ब्रैकेट को पहचानते समय उसे गिना नहीं जाता)।

वहाँ लिखी बात बहुत स्पष्ट है: अगर आपको कोई ऐसा खुला या बंद ब्रैकेट चाहिए जिसका जोड़ा न हो, तो उसे बैकस्लैश से उद्धृत करना ज़रूरी है। तो ऐसा न कीजिए:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
आपको ऐसा करना होगा
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

Tcl कमेंट को जिस तरह पढ़ता है वह ज़्यादातर भाषाओं से अलग होता है, इसलिए यह मामला पेचीदा हो सकता है। इस पर [Tcl विकि](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments) पर और चर्चा है।

## चौकोर ब्रैकेट

इसी तरह, Tcl ब्रैकेट का इस्तेमाल [कमांड सब्स्टिट्यूशन](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11) के लिए करता है, इसलिए डबल कोट्स वाली स्ट्रिंग के अंदर भी खुले ब्रैकेट को एस्केप करते समय सावधानी रखनी पड़ती है।

## गोल ब्रैकेट

[एसोसिएटिव ऐरे वेरिएबलो](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12) को छोड़कर, गोल ब्रैकेट बस आम अक्षर होते हैं।
