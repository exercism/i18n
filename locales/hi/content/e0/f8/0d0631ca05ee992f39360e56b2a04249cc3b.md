# उदाहरण

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

डॉट से शुरू होने वाली लाइनें _डायरेक्टिव_ होती हैं: ये असेंबलर के लिए निर्देश हैं, प्रोसेसर के लिए नहीं।
`.equ` संख्या 16 को `FRAME_SIZE` नाम देता है।
`.text` बताता है कि इसके बाद जो आता है वह कोड है।
`.global` लेबल `is_triple` को इस फाइल के बाहर दिखने लायक बनाता है, ताकि बाकी कोड उसे कॉल कर सके।
आपको `.globl` भी दिख सकता है, जिसका मतलब भी यही है।

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` जाँचता है कि `a² + b² = c²` है या नहीं, और अगर है तो 1 लौटाता है, वरना 0।
उदाहरण के लिए, `(6, 8, 10)` पर 1 मिलता है, क्योंकि `36 + 64 = 100`।
लेबल `is_triple` बताता है कि फंक्शन कहाँ से शुरू होता है।
इसे `a0`, `a1` और `a2` रजिस्टरों में `a`, `b` और `c` के साथ कॉल किया जाता है।

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

रजिस्टर `ra` में _रिटर्न एड्रेस_ रहता है, यानी कॉलर में वह जगह, जहाँ हमारा काम पूरा होने पर वापस जाना है।
हर `call` `ra` पर नया मान लिख देता है, इसलिए हम पहले उसे _स्टैक_ पर सहेजते हैं।
स्टैक नीचे की ओर बढ़ता है, यानी छोटे पतों की ओर। इसलिए स्टैक पॉइंटर `sp` से 16 घटाने पर हमारे लिए 16 बाइट जगह आरक्षित हो जाती है।
(`sp` हमेशा 16 का गुणज होना चाहिए।)
हम `b` और `c` को भी सहेज लेते हैं, क्योंकि जिस फंक्शन को हम कॉल करते हैं, वह `a` रजिस्टरों को बदल सकता है।

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` पहले से `a0` में ही है, और `square` अपना इनपुट वहीं से लेता है।
`call` `ra` में अगली इंस्ट्रक्शन का पता रख देता है और `square` पर जंप कर देता है; `square` अपना परिणाम `a0` में लौटाता है।

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

हम `b` को स्टैक से वापस लाते हैं, उसका वर्ग करते हैं, और उसे `a * a` में जोड़ देते हैं।

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

यह अंतर ठीक तभी शून्य होता है जब `a² + b² = c²` हो।
`seqz` ("set if equal to zero") इसे 1 या 0 में बदल देता है।

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

हम `ra` को वापस लाते हैं और स्टैक की वे 16 बाइट लौटा देते हैं।
इसके बाद `ret` `ra` में मौजूद पते पर जंप कर देता है, यानी वापस कॉलर के पास।

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` किसी और फंक्शन को कॉल नहीं करता, इसलिए `ra` सुरक्षित रहता है और सहेजने के लिए कुछ नहीं होता।
इसे `.global` नहीं बनाया गया है, क्योंकि इसका इस्तेमाल सिर्फ `is_triple` करता है।
