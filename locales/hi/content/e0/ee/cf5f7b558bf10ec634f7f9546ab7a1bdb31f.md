# परिचय

## मेथड के सेट के रूप में इंटरफ़ेस

अपने सबसे सरल रूप में एक **इंटरफ़ेस टाइप** मेथड सिग्नेचर का एक सेट होता है।
यहाँ एक इंटरफ़ेस की परिभाषा का उदाहरण है जिसमें दो मेथड `Add` और `Value` शामिल हैं:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

`increment` जैसे पैरामीटर के नाम इंटरफ़ेस की परिभाषा से हटाए जा सकते हैं, लेकिन अक्सर ये पढ़ने में आसानी बढ़ा देते हैं।

Go में इंटरफ़ेस के नाम में `Interface` या `I` शब्द नहीं होता।
इसके बजाय ये अक्सर `er` पर खत्म होते हैं, जैसे `Reader`, `Stringer`.

## इंटरफ़ेस को लागू करना

जो भी टाइप इंटरफ़ेस के मेथड बनाता है, वह अपने आप उस इंटरफ़ेस को "लागू" कर देता है।
Go में `implements` नाम का कोई कीवर्ड नहीं होता।

नीचे दिया गया टाइप ऊपर देखे गए `Counter` इंटरफ़ेस को लागू करता है।

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

इंटरफ़ेस लागू करने के लिए इससे कोई फर्क नहीं पड़ता कि मेथड का रिसीवर वैल्यू रिसीवर है या पॉइंटर रिसीवर।
(अगर इनके बारे में आपको संदेह है, तो [मेथड से जुड़े कॉन्सेप्ट][concept-methods] दोबारा देख लीजिए।)

> इंटरफ़ेस टाइप की एक वैल्यू अपने अंदर वह कोई भी वैल्यू रख सकती है जो उन मेथड को लागू करती हो। [^1]

इसका मतलब है कि अब `Stats` को हर उस जगह इस्तेमाल किया जा सकता है जहाँ `Counter` इंटरफ़ेस की अपेक्षा होती है।

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

चूँकि इंटरफ़ेस अपने आप लागू हो जाते हैं, एक टाइप आसानी से कई इंटरफ़ेस लागू कर सकता है।
उसे बस सारे ज़रूरी मेथड बनाने होते हैं।

## खाली इंटरफ़ेस

Go में एक बहुत खास इंटरफ़ेस टाइप है, **खाली इंटरफ़ेस**, जिसमें एक भी मेथड नहीं होता।
खाली इंटरफ़ेस ऐसे लिखा जाता है: `interface{}`.
`any`, `interface{}` का दूसरा नाम है, और इसका इस्तेमाल ज़्यादा आम है।

चूँकि खाली इंटरफ़ेस में कोई मेथड नहीं होता, हर टाइप उसे अपने आप लागू कर देता है।
यह ऐसे फंक्शन बनाने में काम आता है जो सामान्य रूप से कोई भी वैल्यू ले सके।
ऐसी स्थिति में फंक्शन का पैरामीटर खाली इंटरफ़ेस टाइप का होता है।
