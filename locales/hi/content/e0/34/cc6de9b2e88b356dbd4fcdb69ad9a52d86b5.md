# निर्देशों का अपेंड

## प्रोजेक्ट संरचना

* `src` में आपके अभ्यास का हल होता है।
* `spec` में अभ्यास के लिए चलाए जाने वाले टेस्ट होते हैं।

## टेस्ट चलाना

यदि आप सही डायरेक्टरी में हैं (यानी वह जिसमें `src` और `spec` हैं), तो आप उस अभ्यास के टेस्ट `crystal spec` चलाकर चला सकते हैं:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

इससे `spec` डायरेक्टरी की सभी टेस्ट फाइलें चलेंगी।

हर टेस्ट फाइल में पहले टेस्ट के अलावा बाकी सभी टेस्ट छोड़ दिए गए हैं।

एक बार कोई टेस्ट पास हो जाए, तो `pending` को `it` में बदलकर आप अगले टेस्ट को छोड़ना बंद कर सकते हैं।

## अपना हल जमा करना

अपना हल जमा करते समय `src` डायरेक्टरी में मौजूद सोर्स फाइल ज़रूर जमा करें:

```bash
$ exercism submit src/hello_world.cr
```
