# संकेत

## सामान्य

- शुरू करने के लिए [कंट्रोल फ्लो टूल्स][control flow tools] पर Python Docs और [कंडीशनल][real python conditionals] पर Real Python का ट्यूटोरियल बढ़िया जगहें हैं।
- `bools` को दोहराने के लिए [बूलियन ऑपरेशन][boolean operations] पर Python Docs बहुत काम की है, और [बूलियन][python booleans] पर Real Python का ट्यूटोरियल भी।
- तुलना को दोहराने के लिए [तुलना][comparisons] और [तुलना के उदाहरण][python comparisons examples] पर Python Docs बहुत काम की है।

## 1. गंभीरता की जाँच कीजिए

- तुलना के ऑपरेटर ([तुलना][comparisons review]) और बूलियन ऑपरेशन ([concept:python/bools]()) को आपस में मिलाकर शर्तों के साथ इस्तेमाल किया जा सकता है।
- शर्त वाले एक्सप्रेशन का नतीजा `True` या `False` ही होना चाहिए।
- `else` का इस्तेमाल उस कोड ब्लॉक के लिए किया जा सकता है जो तभी चलता है जब सारी शर्त वाली जाँचें `False` लौटाएँ।

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. पावर आउटपुट की रेंज तय कीजिए

- तुलना के ऑपरेटरों को मिलाकर शर्तों के साथ इस्तेमाल किया जा सकता है।
- निर्णय की "शाखाओं" के रूप में कितने भी `elif` स्टेटमेंट इस्तेमाल किए जा सकते हैं।
- हर "शाखा" में अलग `return` हो सकता है, हालाँकि लिंटिंग टूल्स इसे "खराब तरीका" मान सकते हैं।
- अगर लिंटर शिकायत करे, तो शाखा के आउटपुट को एक सामान्य वेरिएबल में असाइन करने के बारे में सोचिए, और फिर उस वेरिएबल को `return` कीजिए।
