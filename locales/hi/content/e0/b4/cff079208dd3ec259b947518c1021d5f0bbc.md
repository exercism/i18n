# परिचय

Java में `null` लिटरल का इस्तेमाल किसी वैल्यू का न होना दर्शाने के लिए किया जाता है।

Java में सभी प्रिमिटिव डेटा टाइप की एक डिफॉल्ट वैल्यू होती है, इसलिए वे कभी `null` नहीं हो सकते। परंपरा से वे छोटे अक्षर से शुरू होते हैं, जैसे `int`.

रेफरेंस टाइप में किसी ऑब्जेक्ट का मेमोरी एड्रेस होता है और इनकी वैल्यू `null` हो सकती है। ये आम तौर पर बड़े अक्षर से शुरू होते हैं, जैसे `String`.

किसी प्रिमिटिव वेरिएबल को `null` वैल्यू असाइन करने की कोशिश करने पर कंपाइल टाइम एरर मिलती है, क्योंकि वह वेरिएबल हमेशा उसी टाइप की प्रिमिटिव वैल्यू रखता है जो उसे असाइन किया गया था।

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

किसी रेफरेंस वेरिएबल को `null` वैल्यू असाइन करने पर कंपाइल टाइम एरर नहीं मिलती, क्योंकि रेफरेंस वेरिएबल `null` वैल्यू ले सकते हैं।

```java
//No error will occur as the String variable str is nullable
String str = null;
```
