# निर्देश

इस अभ्यास में आप एक इंटरनेट फोरम पर यूज़र खातों की अनुमतियाँ जाँचेंगे। फोरम तीन अलग-अलग अनुमतियों का समर्थन करता है:

- Read
- Write
- Delete

खातों के तीन प्रकार हैं, और हर प्रकार की डिफॉल्ट अनुमतियाँ अलग हैं:

- Guests: पोस्ट पढ़ सकते हैं।
- Users: पोस्ट पढ़ और लिख सकते हैं।
- Moderators: पोस्ट पढ़, लिख और हटा सकते हैं, इनके पास सारी अनुमतियाँ होती हैं।

कभी-कभी अलग-अलग अनुमतियों को बदला जा सकता है। उदाहरण के लिए, किसी Guest खाते को पोस्ट लिखने की अनुमति भी दी जा सकती है, या किसी खाते से सारी अनुमतियाँ वापस ले लेने पर उसके पास कोई भी अनुमति नहीं बचेगी।

## 1. किसी खाता प्रकार की डिफॉल्ट अनुमतियाँ पाइए

सबसे पहले, तीनों खाता प्रकारों को दर्शाने के लिए एक `AccountType` enum बनाइए: `Guest`, `User` और `Moderator`.

इसके बाद, तीनों अनुमति प्रकारों को दर्शाने के लिए एक `Permission` enum बनाइए: `Read`, `Write`, `Delete`, और दो अतिरिक्त वाले: `All` सारी अनुमतियों के लिए और `None` किसी भी अनुमति के न होने के लिए।

फिर किसी खास खाता प्रकार की डिफॉल्ट अनुमतियाँ लौटाने के लिए (_static_) `Permissions.Default()` मेथड लागू कीजिए:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. अनुमति दीजिए

(_static_) `Permissions.Grant()` मेथड लागू कीजिए, जो कोई अनुमति देता (जोड़ता) है:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. अनुमति वापस लीजिए

(_static_) `Permissions.Revoke()` मेथड लागू कीजिए, जो कोई अनुमति वापस लेता (हटाता) है:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. किसी अनुमति की जाँच कीजिए

(_static_) `Permissions.Check()` मेथड लागू कीजिए, जो मौजूदा खाते की अनुमतियाँ लेता है और देखता है कि खाते के पास दी गई अनुमति है या नहीं:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
