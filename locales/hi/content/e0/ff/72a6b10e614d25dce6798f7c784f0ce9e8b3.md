# परिचय

`for` लूप की मदद से कोड को बार-बार चलाया जा सकता है, जब तक कोई शर्त पूरी न हो जाए।

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for` लूप में चार भाग होते हैं:

1. इनिशियलाइज़र: लूप में जाने से पहले एक बार चलाया जाता है। आम तौर पर इसका उपयोग लूप के अंदर इस्तेमाल होने वाले वेरिएबल बनाने के लिए किया जाता है।
2. शर्त: लूप के हर इटरेशन से पहले चलाई जाती है। जब तक यह `true` हो, लूप चलता रहता है।
3. इटरेटर: लूप के हर इटरेशन के बाद चलाया जाता है। आम तौर पर इसका उपयोग लूप वेरिएबल को बदलने (अक्सर बढ़ाने/घटाने) के लिए किया जाता है।
4. लूप के अंदर का कोड: वह कोड जो लूप के हर इटरेशन में चलाया जाता है।
