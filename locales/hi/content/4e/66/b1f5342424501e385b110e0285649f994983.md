# निर्देश

आप एक सिग्नल स्टेशन की कोड जनरेशन टूलकिट का रखरखाव कर रहे हैं। हर मैक्रो एक *स्टेंसिल* है, यानी एक छोटा टेम्पलेट जिसे कंपाइलर हर कॉल साइट पर विशेष कोड बनाने के लिए इस्तेमाल करता है।

आपको सिर्फ चार मैक्रो लिखने हैं। टेस्ट फाइल छोटे रैपर शब्द बनाती है जो आपके मैक्रो को *कॉल* करते हैं (मैक्रो को उसके द्वारा बनाए गए कोड के जरिए ही देखा जा सकता है), और फिर उन रैपर के रनटाइम परिणाम जाँचती है। रैपर को वैसे ही रहने दीजिए।

हर टास्क में बॉडी को स्टैक पर कॉल साइट के लिटरल इनपुट मिलते हैं, और उसे **एक कोटेशन** छोड़ना होता है। "कंपाइल होकर यह बनेगा" वाली लाइनें बताती हैं कि आपके कोटेशन से कौन-सा सीधा कोड बनना चाहिए।

## 1. दो बार

`twice` एक लिटरल कोटेशन लेता है और एक ऐसा कोटेशन लौटाता है जो मूल कोटेशन को लगातार दो बार चलाता है।

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N बार दोहराव

`repeat-quot` एक लिटरल कोटेशन और एक लिटरल गिनती `n` लेता है, और एक ऐसा कोटेशन लौटाता है जो मूल कोटेशन को लगातार `n` बार चलाता है। `n = 0` होने पर खाली कोटेशन `[ ]` लौटता है।

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. कई कोटेशन जोड़ना

`compose-many` कोटेशन का एक लिटरल ऐरे लेता है और एक ही कोटेशन लौटाता है जो हर एक को बारी-बारी चलाता है। खाली ऐरे खाली कोटेशन लौटाता है।

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. अनरोल्ड इटरेशन

`each-literal` एक लिटरल सीक्वेंस और एक कोटेशन लेता है। यह एक ऐसा कोटेशन लौटाता है जो सीक्वेंस के हर एलिमेंट के लिए पहले उस एलिमेंट को स्टैक पर रखता है और फिर कोटेशन चलाता है। यह इटरेशन कंपाइल समय पर ही होता है, इसलिए बनने वाला कोड सीधा होता है।

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

चारों में यह सबसे ज़्यादा संरचना पर निर्भर है: बनने वाले कोड को सीक्वेंस की लंबाई *और* उसके एलिमेंट की वैल्यू, दोनों आकार देते हैं। संकेतों में इसे एक-एक कदम करके बनाने का तरीका बताया गया है।
