# परिचय

## वेरिएबल और असाइनमेंट

R एक डायनैमिक टाइपिंग वाली भाषा है, इसलिए आम तौर पर वेरिएबल का टाइप बताने की ज़रूरत नहीं होती। वैल्यू असाइन करने के लिए पसंदीदा ऑपरेटर `<-` है।

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

`<-` की जगह `=` इस्तेमाल करना अक्सर काम कर जाता है, पर हमेशा नहीं। इसे खराब स्टाइल माना जाता है, इसलिए इससे बचना चाहिए।
अगर आप RStudio में काम कर रहे हैं, तो इसे कीबोर्ड शॉर्टकट `Alt-minus` से डाला जा सकता है।

ऑपरेटर ज़्यादातर आम हैं, लेकिन `%/%` और `%%` पर ध्यान दीजिए:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

R में `#` से एक लाइन का कमेंट शुरू होता है।
कई लाइनों वाले कमेंट के लिए कोई अलग सिंटैक्स नहीं है।

## फंक्शन

फंक्शन बनाने के लिए:

```R
squareit <- function(x) {
    x * x
}
```

फंक्शन में शून्य या उससे अधिक आर्गुमेंट हो सकते हैं, जिन्हें कॉमा से अलग किया जाता है।
`function()` के साथ ब्रैकेट `()` ज़रूरी होते हैं, भले ही कोई पैरामीटर न हो।

फंक्शन के आर्गुमेंट के लिए डिफ़ॉल्ट वैल्यू भी तय की जा सकती है, पर ऐसी वैल्यू उन सभी आर्गुमेंट के बाद आनी चाहिए जिनकी कोई डिफ़ॉल्ट वैल्यू नहीं है। डिफ़ॉल्ट वैल्यू असाइन करने के लिए `<-` की जगह `=` इस्तेमाल कीजिए।
थोड़ा बेमतलब सा उदाहरण:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

एक लाइन वाली फंक्शन बॉडी के लिए कर्ली ब्रैकेट `{ }` सख्ती से ज़रूरी नहीं हैं, पर उन्हें लिखना अच्छा स्टाइल माना जाता है।

ऊपर के उदाहरणों की तरह R फंक्शन की अंतिम वैल्यू अपने आप लौटा देता है।

फंक्शन बॉडी में कहीं भी `return()` इस्तेमाल करके रिटर्न वैल्यू को स्पष्ट किया जा सकता है।

फंक्शन कॉल करना कई दूसरी भाषाओं की तरह ही है:

```R
squareit(3)
#> [1] 9
```
