# परिचय

पिछले अभ्यास में हमने देखा था कि Go में कमेंट लिखने के दो तरीके होते हैं: सिंगल-लाइन कमेंट, जिनसे पहले `//` लिखा होता है, और मल्टीलाइन कमेंट ब्लॉक, जिन्हें `/*` और `*/` के बीच रखा जाता है।

## डॉक्युमेंटेशन कमेंट

Go में कोड के डॉक्युमेंटेशन में कमेंट की अहम भूमिका होती है।
`godoc` कमांड इन कमेंट को निकालकर Go पैकेजों का डॉक्युमेंटेशन बनाता है।
डॉक्युमेंटेशन कमेंट एक पूरा वाक्य होना चाहिए। यह वाक्य जिस चीज़ का वर्णन किया जा रहा है उसके नाम से शुरू होना चाहिए और पूर्ण विराम पर खत्म होना चाहिए।

कमेंट पैकेज से पहले भी लिखा जाना चाहिए और एक्सपोर्ट किए गए आइडेंटिफायर से भी, जैसे एक्सपोर्ट किए गए फंक्शन, मेथड, पैकेज वेरिएबलो, कॉन्स्टेंट और स्ट्रक्ट। इनके बारे में आप आगे के अभ्यासों में और जानेंगे।

पैकेज-लेवल वेरिएबल कुछ ऐसा दिख सकता है:

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## पैकेज कमेंट

पैकेज कमेंट ठीक पैकेज क्लॉज़ (`package x`) से पहले लिखा जाना चाहिए और `Package x ...` से शुरू होना चाहिए, जैसे यहाँ:

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## फंक्शन कमेंट

फंक्शन कमेंट ठीक फंक्शन की घोषणा से पहले लिखा जाना चाहिए।
यह एक पूरा वाक्य होना चाहिए जो फंक्शन के नाम से शुरू हो।
जैसे, फंक्शन `Calculate` के लिए एक्सपोर्ट किया गया कमेंट `Calculate  ...` के रूप में होना चाहिए।
इसमें यह भी बताया जाना चाहिए कि फंक्शन कौन से आर्गुमेंट लेता है, उनके साथ क्या करता है, और उसकी रिटर्न वैल्यू का क्या अर्थ है, और अंत में एक पूर्ण विराम हो):

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
