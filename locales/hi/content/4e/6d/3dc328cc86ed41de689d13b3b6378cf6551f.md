# परिचय

## _if-then_ स्टेटमेंट

Java में सबसे बुनियादी कंट्रोल फ्लो स्टेटमेंट _if-then_ स्टेटमेंट है।
इस स्टेटमेंट का उपयोग कोड के किसी हिस्से को सिर्फ तब चलाने के लिए किया जाता है, जब कोई खास शर्त `true` हो।
_if-then_ स्टेटमेंट को `if` क्लॉज़ की मदद से बनाया जाता है:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

ऊपर के उदाहरण में, अगर कार का ईंधन खत्म हो चुका है, तो `Car.drive` मेथड को कॉल करने पर कुछ नहीं होगा।

## _if-then-else_ स्टेटमेंट

जब `if` क्लॉज़ की शर्त `false` हो जाती है, तब कोड को चलाने का दूसरा रास्ता _if-then-else_ स्टेटमेंट देता है।
यह दूसरा रास्ता `if` क्लॉज़ के बाद आता है और इसे `else` क्लॉज़ से बनाया जाता है:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

ऊपर के उदाहरण में, अगर कार का ईंधन खत्म हो चुका है, तो `Car.drive` मेथड को कॉल करने पर कार को रोकने के लिए एक और मेथड कॉल होगा।

_if-then-else_ स्टेटमेंट `else if` क्लॉज़ की मदद से एक से ज़्यादा शर्तें भी संभाल सकता है:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

ऊपर के उदाहरण में, अगर ईंधन `5` या उससे कम है और आप कार चलाते हैं, तो कार चलेगी, लेकिन ईंधन की लाइट जल जाएगी।
जब ईंधन `0` तक पहुँच जाता है, तो कार चलना बंद कर देती है।
