# परिचय

Java में बूलियन को `boolean` टाइप से दर्शाया जाता है। इस टाइप की वैल्यू या तो `true` होती है या `false`।

Java में तीन [बूलियन ऑपरेटर][operators] होते हैं:

- `!` (NOT): बूलियन को उलट देता है।
- `&&` (AND): दो बूलियन लेता है और जब दोनों सही हों तो सही देता है।
- `||` (OR): अगर दोनों बूलियन में से कोई एक भी सही हो तो सही देता है।

`&&` और `||` ऑपरेटर _शॉर्ट-सर्किट मूल्यांकन_ का इस्तेमाल करते हैं। इसका मतलब है कि ऑपरेटर के दाईं ओर वाले हिस्से का मूल्यांकन तभी किया जाता है जब उसकी ज़रूरत होती है।

इन्हें कंडीशनल या लॉजिकल ऑपरेटर भी कहा जाता है।
डॉक्युमेंटेशन में `!` को कभी-कभी बिटवाइज़ ऑपरेशन माना जाता है, लेकिन इसका अर्थ पारंपरिक _NOT_ ही होता है।

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

इन तीनों बूलियन ऑपरेटरों की [_ऑपरेटर प्राथमिकता_][precedence] अलग-अलग होती है। इसलिए इनका मूल्यांकन इस क्रम में होता है: पहले `not`, फिर `&&`, और सबसे अंत में `||` आता है। अगर आप इन नियमों से 'बचना' चाहते हैं, तो बूलियन एक्सप्रेशन को गोल ब्रैकेट (`()`) में लिख सकते हैं, क्योंकि ब्रैकेट की ऑपरेटर प्राथमिकता इनसे और भी ज़्यादा होती है।

```java
!true && false   // => false
!(true && false) // => true
```
