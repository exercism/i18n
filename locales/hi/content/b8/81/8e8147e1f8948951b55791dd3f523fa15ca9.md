# परिचय

## Julia में बूलियन

सही या गलत वैल्यू को `Bool` टाइप से दर्शाया जाता है.
इसमें सिर्फ दो वैल्यू होती हैं: `true` और `false`.

```julia-repl
julia> true
true

julia> false
false
```

## बूलियन ऑपरेटर

Julia में तीन बूलियन ऑपरेटर होते हैं।

`&&` बूलियन "और" है।
अगर `&&` के *दोनों* तरफ के एक्सप्रेशन `true` हों, तो इसका परिणाम `true` होता है।

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` बूलियन "या" है।
अगर `||` के *किसी एक* तरफ का एक्सप्रेशन `true` हो, तो इसका परिणाम `true` होता है।

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` बूलियन "नहीं" है।
यह `true` और `false` वैल्यू को आपस में बदल देता है।

```julia-repl
julia> !true
false

julia> !false
true
```

लंबे और ज़्यादा जटिल एक्सप्रेशन लिखते समय अपना इरादा साफ़ रखने के लिए गोल ब्रैकेट इस्तेमाल कीजिए।

```julia-repl
julia> (true || false) && (false && true)
false
```
