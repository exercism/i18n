# स्थिति वाली क्लास

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| लिखा गया | बाहर से पढ़ा जा सकता है | बाहर से बदला जा सकता है |
| --- | --- | --- |
| `attr x : INT` | हाँ | हाँ |
| `readonly attr x : INT` | हाँ | नहीं |
| `private attr x : INT` | नहीं | नहीं |

डिफॉल्ट रूप से `readonly` ही चुनना चाहिए। यह किसी को भी स्कोर देखने देता है, और यह ज़रूरी बनाता है कि स्कोर बदलने का काम `home_goal` से ही हो। स्कोरिंग के नियम वहीं रहते हैं।

## create and new

`new` इस क्लास का एक ऑब्जेक्ट बनाता है जिसमें हर एट्रिब्यूट खाली रहता है। इसका इस्तेमाल सिर्फ क्लास के अंदर ही किया जा सकता है।

`create` एक आम रूटीन है जिसका नाम पहले से तय है: `#C(args)` ठीक `C::create(args)` ही है। एक क्लास में ऐसे कई रूटीन हो सकते हैं, जो अपने आर्गुमेंट के आधार पर अलग-अलग पहचाने जाते हैं, और जिस क्लास में एक भी न हो, उसे `#` से बनाया ही नहीं जा सकता।

## SAME

`SAME` उसी क्लास को दर्शाता है जिसमें वह लिखा गया है। `create` में यह रिटर्न टाइप है; यह आर्गुमेंट में भी काम आता है, और यही वह चीज़ है जिससे विरासत में मिला रूटीन उस क्लास की बात करता है जिसने विरासत पाई, न कि उस क्लास की जिससे वह आया था।

## बिना रिटर्न टाइप वाले रूटीन

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

न `:` और न कोई टाइप। ऐसे रूटीन को स्टेटमेंट की तरह कॉल किया जाता है और यह किसी एक्सप्रेशन में नहीं आ सकता। यह इस बात का संकेत है कि इस कॉल का उद्देश्य वह बदलाव है जो यह करता है।

## self

किसी रूटीन के अंदर `self` वह ऑब्जेक्ट होता है जिस पर उसे कॉल किया गया। इसे कम ही लिखा जाता है, क्योंकि अकेले नाम लिया गया एट्रिब्यूट या रूटीन अपने आप ही `self` का मतलब रखता है। इसकी ज़रूरत तब पड़ती है जब ऑब्जेक्ट को आगे भेजना हो या लौटाना हो:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` और `out`, ये सब Sather के अपने शब्द हैं, और इनमें से किसी को भी अपने नाम के तौर पर इस्तेमाल नहीं किया जा सकता।

## रेफरेंस, वैल्यू नहीं

किसी ऑब्जेक्ट तक रेफरेंस के ज़रिए पहुँचा जाता है। एक ही स्कोरबोर्ड के दो नामों को एक ही स्कोर दिखाई देता है:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

बाद में `immutable class` से यह दूसरा व्यवहार मिलता है।
