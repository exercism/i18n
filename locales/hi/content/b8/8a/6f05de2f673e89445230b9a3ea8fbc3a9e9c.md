# परिचय

[रेंज][range] दो वैल्यू के बीच के अंतराल को दर्शाती हैं।

रेंज का इस्तेमाल आम तौर पर `Int`, `String`, और `Character` जैसे टाइप के साथ किया जाता है। इससे आप सीक्वेंस पर इटरेशन कर सकते हैं, कलेक्शन के उप-भाग निकाल सकते हैं, या जाँच सकते हैं कि कोई वैल्यू सीमा के अंदर है या नहीं।

Swift दो मुख्य रेंज ऑपरेटर देता है:

- **क्लोज़्ड रेंज ऑपरेटर (`...`)**: इसमें शुरू और अंत दोनों वैल्यू शामिल होती हैं (`1...5` में 1, 2, 3, 4, और 5 शामिल हैं)।
- **हाफ-ओपन रेंज ऑपरेटर (`..<`)**: इसमें शुरू की वैल्यू शामिल होती है लेकिन अंत की वैल्यू शामिल नहीं होती (`1..<5` में 1, 2, 3, और 4 शामिल हैं)।

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
जब किसी रेंज लिटरल पर सीधे कोई मेथड कॉल कीजिए, तो रेंज एक्सप्रेशन को गोल ब्रैकेट में लपेटिए ताकि कंपाइलर पहले रेंज का मूल्यांकन करे:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## रेंज को ऐरे में बदलना

आप `Array(_:)` इनिशियलाइज़र की मदद से संख्याओं की रेंज को `Array` में बदल सकते हैं:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## रेंज से ऐरे के उप-भाग निकालना

आप रेंज का उपयोग करके ऐरे के उप-भाग निकाल सकते हैं:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## रेंज की प्रॉपर्टी और मेथड

रेंज पर आम ऑपरेशन में शामिल हैं:

| Member                  | Description                                                | Example                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | रेंज में एलिमेंट की संख्या लौटाता है                        | `(1...5).count` `5` लौटाता है        |
| [`contains(_:)`][contains] | `true` लौटाता है अगर रेंज में दी गई वैल्यू शामिल है        | `(1...5).contains(3)` `true` लौटाता है |

## एकतरफा रेंज

Swift एकतरफा (आंशिक) रेंज को भी सपोर्ट करता है, जहाँ आप शुरू या अंत की वैल्यू में से कोई एक छोड़ देते हैं:

- `array[2...]`: इंडेक्स 2 से कलेक्शन के अंत तक।
- `array[...2]`: कलेक्शन की शुरुआत से इंडेक्स 2 तक (2 सहित)।
- `array[..<2]`: कलेक्शन की शुरुआत से इंडेक्स 2 तक (लेकिन 2 को शामिल नहीं करते हुए)।

## स्ट्रिंग और अक्षर की रेंज

रेंज को उन अक्षरों या स्ट्रिंग के बीच भी बनाया जा सकता है जो `Comparable` का पालन करते हैं:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
