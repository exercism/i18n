# ऐरे का परिचय

Java में ऐरे एक ही टाइप की कई वैल्यू को एक स्ट्रक्चर में रखने का तरीका है।
दूसरे डेटा स्ट्रक्चर के उलट, एक बार बन जाने के बाद ऐरे का साइज़ तय रहता है।
ऐरे के एलिमेंट को इंडेक्स की मदद से असाइन किया जा सकता है या ऐरे से निकाला जा सकता है।
Java के ऐरे में गिनती शून्य से शुरू होती है: पहले एलिमेंट का इंडेक्स 0 होता है, दूसरे का 1, और इसी तरह।

ऐरे को इनिशियलाइज़ करने का मानक सिंटैक्स यह है:

```java
type[] variableName = new type[size];
```

यहाँ `type` ऐरे के एलिमेंट का टाइप है, जो प्रिमिटिव टाइप (जैसे `int`) या क्लास (जैसे `String`) हो सकता है।

`size` बताता है कि इस ऐरे में कितने एलिमेंट होंगे (इसे बाद में बदला नहीं जा सकता)।
ऐरे बनने के बाद उसके एलिमेंट अपनी डिफॉल्ट वैल्यू पर इनिशियलाइज़ हो जाते हैं (आम तौर पर `0`, `false` या `null`)।

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

ऐरे को एक शॉर्टकट तरीके से भी बनाया जा सकता है, जिसमें आप ऐरे बनाने और उसकी वैल्यू तय करने, दोनों काम एक साथ कर सकते हैं:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

अब कंपाइलर खुद बता सकता है कि ऐरे में कितने एलिमेंट होंगे, इसलिए लंबाई लिखने की ज़रूरत नहीं है।

ऐरे के एलिमेंट को ब्रैकेट वाले इंडेक्स नोटेशन से असाइन और एक्सेस किया जा सकता है:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

ऐरे के मान्य इंडेक्स के बाहर का कोई इंडेक्स एक्सेस करने पर `IndexOutOfBoundsException` मिलता है।

ऐरे पर काम करने के लिए या तो आप किसी ऐरे इंस्टेंस के मेथड या प्रॉपर्टी कॉल कर सकते हैं, या `Arrays` क्लास में बने स्टैटिक मेथड इस्तेमाल कर सकते हैं (इनका इस्तेमाल आम तौर पर सिर्फ जेनेरिक कोड में होता है)।
`length` प्रॉपर्टी ऐरे की लंबाई बताती है।
इसे इस तरह एक्सेस किया जा सकता है:

```java
int arrayLength = someArray.length;
```

Java में एक काम की यूटिलिटी क्लास [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) भी मिलती है, जिसमें ऐरे से जुड़े बहुत से उपयोगी मेथड हैं (जैसे `Arrays.equals`)।

Java [बहु-आयामी ऐरे](https://www.programiz.com/java-programming/multidimensional-array) को भी सपोर्ट करता है, जैसे `int[][] arr = new int[3][4];`, जो बहुत उपयोगी हो सकते हैं।

ऐरे एक _कलेक्शन_ भी होता है। इसका मतलब यह है कि इंडेक्स से वैल्यू एक्सेस करने के अलावा, आप `for-each` लूप की मदद से इसकी _सभी_ वैल्यू पर एक-एक करके चल सकते हैं:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

अगर आपको यह तय करना है कि किन वैल्यू पर चलना है, तो इसके लिए `for` लूप इस्तेमाल किया जा सकता है:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
