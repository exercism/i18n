# रेंज

[रेंज][range] दो वैल्यू के बीच के अंतराल को दर्शाती हैं।
जिन डेटा टाइप में रेंज का उपयोग होता है, उनमें सबसे आम `Int`, `Char` और `String` हैं।
इनका उपयोग कई कामों के लिए किया जा सकता है, जैसे कलेक्शन को जल्दी बनाना, स्ट्रिंग को काटना, यह जाँचना कि कोई वैल्यू रेंज में है या नहीं, और इटरेशन।
इन्हें रेंज ऑपरेटर `..` या `...` से बनाया जाता है (क्रमशः अंतिम वैल्यू को शामिल करने वाला और उसे शामिल न करने वाला)।

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

दो रेंज ऑपरेटर होने का कारण यह है कि हम ऐसी रेंज बना सकें जो अंतिम वैल्यू को शामिल करें या न करें। यह तब काम आता है जब, उदाहरण के लिए, आप शून्य से शुरू होने वाले इंडेक्स के साथ काम कर रहे हों।

रेंज को `Range` इनिशियलाइज़र से भी बनाया जा सकता है।

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystal में रेंज ऑपरेटर `..` या `...` से रेंज बनाते समय अगर आप उस रेंज पर कोई मेथड कॉल करना चाहते हैं, तो रेंज को गोल ब्रैकेट में रखना होगा।
वरना वह मेथड रेंज ऑपरेटर के दूसरे आर्गुमेंट पर कॉल हो जाएगा।

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## सबस्ट्रिंग निकालना

स्ट्रिंग को काटकर उसका कोई हिस्सा निकालने के लिए आप रेंज ऑपरेटर का उपयोग कर सकते हैं। इसके लिए सबस्ट्रिंग के शुरुआती और अंतिम इंडेक्स से एक रेंज बनाइए।

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

आप स्ट्रिंग के अंत से सबस्ट्रिंग निकालने के लिए ऋणात्मक इंडेक्स का भी उपयोग कर सकते हैं।

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## रेंज के मेथड

रेंज के पास कुछ मेथड होते हैं जिनकी मदद से उन पर काम किया जा सकता है। उदाहरण के लिए, इन मेथड की मदद से रेंज की सभी वैल्यू का जोड़ निकाला जा सकता है या यह जाँचा जा सकता है कि रेंज में कोई वैल्यू शामिल है या नहीं।

| मेथड                     | विवरण                                                                   | उदाहरण                          |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | रेंज की सभी वैल्यू का जोड़ लौटाता है                                     | `(1..5).sum # => 15`            |
| [`size`][size]          | रेंज का आकार लौटाता है                                                  | `(1..5).size # => 5`            |
| [`includes?`][indludes] | अगर दी गई वैल्यू रेंज में शामिल है तो `true` लौटाता है, वरना `false`     | `(1..5).includes?(3) # => true` |

## अंतहीन और शुरुआत-रहित रेंज

एक रेंज अंतहीन और शुरुआत-रहित दोनों हो सकती है। ऐसी रेंज में शुरुआत या अंत की वैल्यू `nil` होती है, लेकिन रेंज बनाते समय `nil` को छोड़ा जा सकता है।

बिना शुरुआत और बिना अंत वाली रेंज तब काम आती हैं जब आप, उदाहरण के लिए, स्ट्रिंग को शुरू से या अंत तक काटना चाहते हैं।

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
अगर अंतहीन रेंज का उपयोग किसी कलेक्शन पर नहीं किया जाए और सावधानी न बरती जाए, तो यह एक अंतहीन क्रम बना सकती है।
~~~~

## अक्षरों की रेंज

अक्षरों का उपयोग रेंज में किया जा सकता है, जिससे आप दो अक्षरों के बीच के सारे अक्षर पा सकते हैं। उदाहरण के लिए, यह तब काम आता है जब आपको वर्णमाला चाहिए।

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## स्ट्रिंग की रेंज

स्ट्रिंग का उपयोग भी रेंज में किया जा सकता है, जिससे दो स्ट्रिंग के बीच की सारी स्ट्रिंग मिल जाती हैं। लेकिन जब स्ट्रिंग रेंज में एक से अधिक अक्षर उपयोग किए जाते हैं, तो इसका व्यवहार `Char` के व्यवहार से थोड़ा अलग होता है। जटिल स्ट्रिंग रेंज बनाते समय यह व्यवहार उलझाने वाला हो सकता है, इसलिए सावधानी बरतिए।

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
