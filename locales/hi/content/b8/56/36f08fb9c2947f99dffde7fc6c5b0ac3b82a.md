# परिचय

C# कई दूसरी स्टैटिकली टाइप्ड भाषाओं की तरह कई ऐसे टाइप देती है जो पूर्णांकों को दर्शाते हैं, और हर टाइप की वैल्यू की अपनी रेंज होती है। सबसे छोटे सिरे पर `sbyte` टाइप की न्यूनतम वैल्यू -128 और अधिकतम वैल्यू 127 होती है। सभी पूर्णांक टाइपों की तरह ये वैल्यू `<type>.MinValue` और `<type>.MaxValue` के रूप में उपलब्ध होती हैं। सबसे बड़े सिरे पर `long` टाइप की न्यूनतम वैल्यू -9,223,372,036,854,775,808 और अधिकतम वैल्यू 9,223,372,036,854,775,807 होती है। इनके बीच में `short` और `int` टाइप आते हैं।

ये रेंज इस बात से तय होती हैं कि सिस्टम उस टाइप को स्टोर करने के लिए कितनी जगह देता है। जैसे `byte` 8 बिट इस्तेमाल करता है और `long` 64 बिट।

ऊपर बताए गए हर टाइप का एक अनसाइन्ड रूप भी है: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` और `long`/`ulong`। हर मामले में वैल्यू की रेंज 0 से लेकर (साइन्ड अधिकतम का ऋणात्मक मान × 2) + 1 तक होती है।

| टाइप   | चौड़ाई  | न्यूनतम                    | अधिकतम                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 बिट  | -128                       | +127                        |
| short  | 16 बिट | -32_768                    | +32_767                     |
| int    | 32 बिट | -2_147_483_648             | +2_147_483_647              |
| long   | 64 बिट | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 बिट  | 0                          | +255                        |
| ushort | 16 बिट | 0                          | +65_535                     |
| uint   | 32 बिट | 0                          | +4_294_967_295              |
| ulong  | 64 बिट | 0                          | +18_446_744_073_709_551_615 |

एक टाइप के वेरिएबल (या एक्सप्रेशन) को आसानी से दूसरे टाइप में बदला जा सकता है। जैसे असाइन करते समय, अगर जिस वैल्यू को असाइन किया जा रहा है (lhs) उसका टाइप यह तय कर देता है कि वैल्यू उस टाइप की रेंज के अंदर ही रहेगी जिसमें उसे असाइन किया जा रहा है (rhs), तो सीधे असाइन किया जा सकता है:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

वहीं अगर जिस टाइप से वैल्यू ली जा रही है उसकी रेंज, जिस टाइप में असाइन किया जा रहा है उसकी रेंज का उपसमुच्चय नहीं है, तो कास्ट यानी `()` ऑपरेशन करना पड़ता है, भले ही वह खास वैल्यू उस टाइप की रेंज के अंदर हो:

```csharp
short s = 42;
uint ui = (uint)s;
```
