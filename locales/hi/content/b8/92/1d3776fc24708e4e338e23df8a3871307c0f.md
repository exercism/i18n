# परिचय

## सही और गलत

Ruby में सही और गलत तार्किक अवस्थाओं को `true` और `false` से दर्शाया जाता है। इन्हें अकेले लिटरल के रूप में इस्तेमाल किया जा सकता है, या तार्किक या तुलना वाले मेथड के परिणाम के रूप में।

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _ट्रुथी_ और _फॉल्सी_

`if` स्टेटमेंट या अन्य बूलियन संदर्भों में ऑब्जेक्ट का मूल्यांकन करते समय, `false` और `nil` को **छोड़कर** बाकी सभी ऑब्जेक्ट _ट्रुथी_ माने जाते हैं।

## कंट्रोल फ्लो

_ट्रुथी_ और _फॉल्सी_ मूल्यांकन कंट्रोल फ्लो के संदर्भ में उपयोगी होते हैं। प्रोसीजरल भाषाओं की तरह Ruby में भी `if`...`else` की बनावट होती है, लेकिन किसी एक्सप्रेशन के मूल्यांकन को बदलने के लिए `if` को "गार्ड" स्टेटमेंट की तरह इस्तेमाल करना ज़्यादा आम हो सकता है।

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby कोड को अच्छी तरह पढ़ा जाए, इसके लिए `unless` देता है। जैसे, `eat_desert if not too_full` की जगह हम `eat_desert unless too_full` भी लिख सकते हैं।

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
