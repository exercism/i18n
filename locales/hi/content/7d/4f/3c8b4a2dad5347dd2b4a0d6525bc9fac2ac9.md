# परिचय

एक्सेप्शन एरर संभालने का एक तरीका हैं। इन्हें एक्सेप्शन कहा जाता है, क्योंकि ये आम तौर पर तभी सामने आते हैं जब कोई अनपेक्षित घटना होती है।

अपने कोड में किसी भी जगह हम एक एक्सेप्शन "raise" कर सकते हैं। इसके लिए हम `raise` मेथड का इस्तेमाल करते हैं और उसमें एक ऑब्जेक्ट देते हैं, आम तौर पर एक Exception ऑब्जेक्ट। हालाँकि हम साधारण स्ट्रिंग भी दे सकते हैं।
उदाहरण के लिए, अभ्यास के स्टब में आप देखेंगे कि हम पहले से मौजूद `RuntimeError` का इस्तेमाल करके Ruby को बताते हैं कि कोई मेथड अभी लागू नहीं किया गया है।
आप `raise(ExceptionObject, params)` का संक्षिप्त रूप भी इस्तेमाल कर सकते हैं।
अगर एक्सेप्शन क्लास नहीं दी जाए, तो डिफ़ॉल्ट रूप से `RuntimeError` इस्तेमाल होता है।
उदाहरण:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

जब Ruby यह देखता है, तो वह एरर को प्रोग्राम के सबसे ऊपर तक पहुँचा देता है और फिर प्रोग्राम बंद हो जाता है।
उदाहरण के लिए, अगर आप किसी संख्या को शून्य से भाग देकर देखें, तो आपको कुछ ऐसा दिखेगा:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
