# परिचय

सामान्यतः हर वेरिएबल उसी स्कोप तक सीमित रहता है जिसमें उसे बनाया जाता है। अगर किसी वेरिएबल को किसी फंक्शन या क्लास के बाहर किसी फाइल में बनाया जाता है, तो वह उस फाइल के स्कोप तक ही सीमित रहता है। और अगर उसे किसी फंक्शन या क्लास के अंदर बनाया जाता है, तो वह उस फंक्शन या क्लास के स्कोप तक ही सीमित रहता है।

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

इसके अलावा, वेरिएबलो को खास तौर पर `global` या `static` स्कोप का घोषित भी किया जा सकता है।
