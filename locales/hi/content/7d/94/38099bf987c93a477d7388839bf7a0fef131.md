# निर्देश

इस अभ्यास में आपको प्रोग्रामिंग भाषाओं के एक ऐरे में बदलाव करने के लिए कुछ मेथड बनाने हैं।

## 1. खाली भाषा ऐरे लौटाने वाला मेथड बनाइए

`LanguageList.list` मेथड बनाइए, जो कोई आर्गुमेंट नहीं लेता और `Array(String)` टाइप का एक खाली ऐरे लौटाता है।

```crystal
LanguageList.list()
# => []
```

## 2. ऐरे में भाषा जोड़ने वाला मेथड बनाइए

`LanguageList.add` मेथड बनाइए, जो 2 आर्गुमेंट लेता है (एक _भाषा ऐरे_ और एक _भाषा_ का स्ट्रिंग लिटरल)।
यह मेथड ऐरे को लौटाता है जिसमें नई भाषा ऐरे के अंत में जोड़ दी गई हो।

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. ऐरे से भाषा हटाने वाला मेथड बनाइए

`LanguageList.remove` मेथड बनाइए, जो 1 आर्गुमेंट (एक _भाषा ऐरे_) लेता है।
यह मेथड ऐरे को उसके अंतिम एलिमेंट के बिना लौटाता है।
मान लीजिए कि ऐरे में हमेशा कम से कम एक एलिमेंट रहेगा।

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. ऐरे के nवें एलिमेंट को लौटाने वाला मेथड बनाइए

`LanguageList.at` फंक्शन बनाइए, जो 2 आर्गुमेंट (एक _भाषा ऐरे_ और एक इंडेक्स) लेता है।
यह मेथड ऐरे में n इंडेक्स पर मौजूद भाषा लौटाता है।
मान लीजिए कि उस इंडेक्स पर हमेशा एक भाषा रहेगी।

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. भाषाओं की स्ट्रिंग पार्स करने वाला मेथड बनाइए

`LanguageList.parse` मेथड बनाइए, जो 1 आर्गुमेंट (कोमा से अलग की गई भाषाओं की एक स्ट्रिंग) लेता है।
यह मेथड भाषाओं का एक ऐरे लौटाता है।

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
