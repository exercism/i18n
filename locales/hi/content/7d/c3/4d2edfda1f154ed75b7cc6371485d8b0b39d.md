# निर्देश

RNA अनुक्रमों का प्रोटीन में अनुवाद कीजिए।

RNA को तीन न्यूक्लियोटाइड वाले अनुक्रमों में तोड़ा जा सकता है। इन अनुक्रमों को कोडॉन कहते हैं। फिर इनका पॉलीपेप्टाइड में अनुवाद किया जाता है, जैसे:

RNA: `"AUGUUUUCU"` => इसका अनुवाद होता है

कोडॉन: `"AUG", "UUU", "UCU"`
=> जो नीचे दिए अनुक्रम वाला पॉलीपेप्टाइड बनाते हैं =>

प्रोटीन: `"Methionine", "Phenylalanine", "Serine"`

कुल 64 कोडॉन होते हैं, जो आगे 20 अमीनो अम्लों से मेल खाते हैं। हालाँकि इस अभ्यास में सभी कोडॉन अनुक्रम और उनसे बनने वाले अमीनो अम्ल महत्वपूर्ण नहीं हैं।
अगर प्रोग्राम किसी एक कोडॉन के लिए काम करता है, तो उसे सभी के लिए काम करना चाहिए।
लेकिन अगर आप चाहें, तो टेस्ट सूट की सूची में सभी कोडॉन जोड़ सकते हैं।

तीन समापन कोडॉन भी होते हैं (जिन्हें 'STOP' कोडॉन भी कहते हैं)। अगर राइबोसोम को इनमें से कोई कोडॉन मिलता है, तो सारा अनुवाद रुक जाता है और प्रोटीन समाप्त हो जाता है।

इसके बाद आने वाले सभी कोडॉन नज़रअंदाज़ कर दिए जाते हैं, जैसे:

RNA: `"AUGUUUUCUUAAAUG"` =>

कोडॉन: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

प्रोटीन: `"Methionine", "Phenylalanine", "Serine"`

ध्यान दीजिए कि स्टॉप कोडॉन `"UAA"` अनुवाद को समाप्त कर देता है, और अंतिम मेथियोनीन का प्रोटीन अनुक्रम में अनुवाद नहीं होता।

नीचे इस अभ्यास के लिए आवश्यक कोडॉन और उनसे बनने वाले अमीनो अम्ल दिए गए हैं।

| कोडॉन              | प्रोटीन       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

[विकिपीडिया पर प्रोटीन अनुवाद][protein-translation] के बारे में और जानिए।
