# निर्देश

इस अभ्यास में आपको क्लासिक गेम Pac-Man के कुछ नियम Elixir फंक्शनों में बदलने हैं।

आपको चार नियम बदलने हैं, जो सब खेल की स्थितियों से जुड़े हैं।

> इस बात की चिंता न कीजिए कि आर्गुमेंट कैसे निकाले गए हैं, बस आर्गुमेंट को मिलाकर जो परिणाम चाहिए, वह लौटाने पर ध्यान दीजिए।

## 1. तय कीजिए कि Pac-Man भूत खाता है या नहीं

`Rules.eat_ghost?/2` फंक्शन बनाइए जो दो आर्गुमेंट लेता है (_क्या Pac-Man का पावर पेलेट चालू है_ और _क्या Pac-Man किसी भूत को छू रहा है_) और बूलियन वैल्यू लौटाता है कि Pac-Man भूत खा सकता है या नहीं। फंक्शन को true तभी लौटाना चाहिए जब Pac-Man का पावर पेलेट चालू हो और वह किसी भूत को छू रहा हो।

```elixir
Rules.eat_ghost?(false, true)
# => false
```

## 2. तय कीजिए कि Pac-Man स्कोर करता है या नहीं

`Rules.score?/2` फंक्शन बनाइए जो दो आर्गुमेंट लेता है (_क्या Pac-Man किसी पावर पेलेट को छू रहा है_ और _क्या Pac-Man किसी बिंदु को छू रहा है_) और बूलियन वैल्यू लौटाता है कि Pac-Man ने स्कोर किया या नहीं। फंक्शन को true तब लौटाना चाहिए जब Pac-Man किसी पावर पेलेट या किसी बिंदु को छू रहा हो।

```elixir
Rules.score?(true, true)
# => true
```

## 3. तय कीजिए कि Pac-Man हारता है या नहीं

`Rules.lose?/2` फंक्शन बनाइए जो दो आर्गुमेंट लेता है (_क्या Pac-Man का पावर पेलेट चालू है_ और _क्या Pac-Man किसी भूत को छू रहा है_) और बूलियन वैल्यू लौटाता है कि Pac-Man हारता है या नहीं। फंक्शन को true तब लौटाना चाहिए जब Pac-Man किसी भूत को छू रहा हो और उसका कोई पावर पेलेट चालू न हो।

```elixir
Rules.lose?(false, true)
# => true
```

## 4. तय कीजिए कि Pac-Man जीतता है या नहीं

`Rules.win?/3` फंक्शन बनाइए जो तीन आर्गुमेंट लेता है (_क्या Pac-Man सारे बिंदु खा चुका है_, _क्या Pac-Man का पावर पेलेट चालू है_, और _क्या Pac-Man किसी भूत को छू रहा है_) और बूलियन वैल्यू लौटाता है कि Pac-Man जीतता है या नहीं। फंक्शन को true तब लौटाना चाहिए जब Pac-Man सारे बिंदु खा चुका हो और भाग 3 में बताए गए आर्गुमेंट के आधार पर हारा न हो।

```elixir
Rules.win?(false, true, false)
# => false
```
