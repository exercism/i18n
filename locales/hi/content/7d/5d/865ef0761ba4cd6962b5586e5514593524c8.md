# लिस्ट का परिचय

**लिस्ट** जावा में चीज़ों को एक क्रम में रखने वाला संग्रह है।
ऐरे के उलट, एक [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) कितने भी आइटम रखने के लिए अपना आकार बढ़ा सकती है।
इसका एक मानक कार्यान्वयन `ArrayList` है, जो अंदर से एक ऐसे ऐरे पर टिका है जिसका आकार बदला जा सकता है।
दूसरा मानक कार्यान्वयन `LinkedList` क्लास है, जो एक डबल लिंक्ड लिस्ट पर टिकी है।

`List` खाली हो सकती है, या उसमें कितने भी आइटम (डुप्लिकेट सहित) रखे जा सकते हैं।
`List` एक **जेनेरिक इंटरफेस** है, जिसका टाइप बताता है कि उसमें किस तरह के ऑब्जेक्ट रखे जा सकते हैं।
उदाहरण के लिए:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List` में एलिमेंट जोड़ने, हटाने, प्राप्त करने और यह जाँचने के लिए कई उपयोगी मेथड होते हैं कि कोई एलिमेंट मौजूद है या नहीं:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
