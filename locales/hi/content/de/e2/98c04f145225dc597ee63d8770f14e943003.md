# विवरण

कंप्यूटिंग में `bit` सबसे सूक्ष्म वैल्यू है।
`bit` शब्द "बाइनरी अंक" का संक्षिप्त रूप है।
यह एक्ज़ीक्यूशन वातावरण में डेटा स्टोरेज की एक इकाई है, जो इतनी बड़ी होती है कि ऐसा ऑब्जेक्ट रख सके जिसकी दो में से एक वैल्यू हो सकती है।
इसलिए इसकी बाइनरी वैल्यू या तो `1` होती है या `0`.
बाकी सभी डेटा टाइप कई `bits` से बने होते हैं।
उदाहरण के लिए, एक `byte` आम तौर पर आठ `bits` से बना होता है।

## बिट वैल्यू लिखने का तरीका

`Bits` मिलकर आधार 2 की संख्या प्रणाली बनाते हैं।
`2` के हर गुणज को वह जगह मिलती है जिसे हम दहाई/सैकड़ा/हज़ार आदि की जगह मानते हैं, बस फ़र्क यह है कि वहाँ "दहाई" की जगह "दो", "सैकड़ा" की जगह "चार", "हज़ार" की जगह "आठ" होता है, और इसी तरह आगे भी।
तो दशमलव वैल्यू `2` की बाइनरी वैल्यू `10` होगी, `4` की `100`, और `8` की `1000`.
दशमलव संख्याओं की तरह ही, दाएँ से बाएँ चलने पर ये वैल्यू बड़ी होती जाती हैं।
हम दशमलव वैल्यू `5` को बाइनरी में `101` के रूप में सोच सकते हैं, जिसमें "इकाई" की जगह `1` है और "चार" की जगह `1`.
लेकिन बाइनरी लिटरल C भाषा के स्टैंडर्ड का हिस्सा नहीं हैं।
C भाषा का स्टैंडर्ड सिर्फ़ एक ही `1` या `0` को बाइनरी वैल्यू के रूप में सपोर्ट करता है।
कुछ गैर-स्टैंडर्ड कंपाइलर एक्सटेंशन, जैसे gnu कंपाइलर, बाइनरी लिटरल को _सपोर्ट करते हैं_, बस लिटरल के आगे `0b` लगाना होता है।

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

यह याद रखना ज़रूरी है कि ऐसा नोटेशन सभी कंपाइलर सपोर्ट नहीं करते, और यह अलग-अलग कंपाइलरों के बीच कोड की पोर्टेबिलिटी में रुकावट बन सकता है।

बाइनरी वैल्यू लिखने का एक आम तरीका हेक्साडेसिमल नोटेशन है, जो आधार 16 की संख्या प्रणाली है।
C भाषा के हेक्साडेसिमल नोटेशन में लिटरल के आगे `0x` या `0X` लगाया जाता है।
चूँकि दशमलव वैल्यू `16` को दहाई की जगह `1` के रूप में दर्शाया जाता है, इसलिए हेक्साडेसिमल में दशमलव वैल्यू `10` को `0xA`, `11` को `0xB`, `12` को `0xC`, `13` को `0xD`, `14` को `0xE` और `15` को `0xF` लिखा जाता है।
तो, उदाहरण के लिए, दशमलव वैल्यू `42` को `0x2A` लिखा जाएगा: `2` गुणा `16` (= `32`) जमा `10` (= `42`)।

बाइनरी में हम `42` को `00101010` के रूप में सोच सकते हैं: `32` जमा `8` जमा `2`.
हम कहेंगे कि दाएँ से दूसरा, चौथा और छठा बिट "सेट" है, यानी उनकी वैल्यू `0` के बजाय `1` है।
दूसरे बिट की वैल्यू `2` है, चौथे बिट की `8`, और छठे बिट की `32`.
इन तीनों बिट को सेट करने पर वैल्यू `42` बनती है।

## बिट मास्क

बिट मास्क कोई भी वैल्यू हो सकती है जो अलग-अलग बिट सेट करने के काम आती है।
जैसे अंग्रेज़ी वर्णमाला में छब्बीस अक्षर होते हैं।
कम से कम छब्बीस बिट की वैल्यू, जैसे कोई unsigned 32-बिट पूर्णांक, हर अंग्रेज़ी अक्षर के लिए `true` या `false` शर्त सेट करने के लिए बिट मास्क की तरह इस्तेमाल की जा सकती है।
जिस भी वैल्यू में ज़रूरी `true` या `false` शर्तों को सँभालने के लिए पर्याप्त बिट हों, वह बिट मास्क का काम कर सकती है।
अलग-अलग बिट को सेट करना और पढ़ना बिटवाइज़ ऑपरेटरों के इस्तेमाल से किया जाता है।

## बिटवाइज़ ऑपरेटर

मान लीजिए हम यह पता रखना चाहते हैं कि एक `string` में कौन-कौन से अक्षर आते हैं।
अपने उदाहरण में हम सिर्फ़ अंग्रेज़ी वर्णमाला के छब्बीस अक्षर इस्तेमाल करेंगे।
हमारा बिट मास्क एक unsigned 32-बिट पूर्णांक होगा।
`0` का मतलब होगा कि वह अक्षर नहीं आता।
`1` का मतलब होगा कि वह अक्षर एक या उससे ज़्यादा बार आता है।
शुरू में हमारे बिट मास्क का बिट प्रतिनिधित्व एक पंक्ति में 32 `0s` होगा: `00000000000000000000000000000000`.
सबसे दाईं जगह `A` के लिए होगी।
बाएँ से दूसरी जगह `B` के लिए होगी, और इसी तरह आगे भी।
मान लीजिए हम एक लूप में स्ट्रिंग के सारे अक्षरों को प्रोसेस कर रहे हैं, और हम चाहते हैं कि कोड की एक ही लाइन किसी भी अक्षर को सेट करने के लिए काम करे।

### बिटवाइज़ शिफ्ट लेफ्ट ऑपरेटर: किसी बिट को जगह देने का तरीका

`<<` बाएँ शिफ्ट करने वाला बिटवाइज़ ऑपरेटर है।

अगर हमारा अक्षर `A` है तो हमें बाएँ शिफ्ट नहीं करना है, लेकिन अगर अक्षर `B` है तो हमें एक जगह बाएँ शिफ्ट करना है, और अगर अक्षर `C` है तो दो जगह बाएँ शिफ्ट करना है, और इसी तरह आगे भी।
हालाँकि हम `chars` को `A` या `B` जैसे अक्षरों की तरह देखते हैं, मेमोरी में एक `char` पूर्णांक टाइप के रूप में लागू किया जाता है, इसलिए हम `char` के साथ साधारण गणित कर सकते हैं।
मान लीजिए हमारे पास `letter` नाम का एक वेरिएबल है, जो उस `char` को दर्शाता है जिसे हम प्रोसेस कर रहे हैं।
तब हम `1` को `letter` और `A` `char` के अंतर के बराबर बाईं ओर शिफ्ट करके उतनी जगह बाएँ शिफ्ट कर सकते हैं, ऐसे: `1 << letter - 'A'`.
`A` - `A` का मान `0` है, इसलिए अगर `letter` `A` है तो यह `0` जगह बाएँ शिफ्ट करेगा।
`B` - `A` का मान `1` है, इसलिए अगर `letter` `B` है तो यह `1` जगह बाएँ शिफ्ट करेगा, और इसी तरह आगे भी।

### बिटवाइज़ इन्क्लूसिव OR ऑपरेटर: बिट सेट करने का तरीका

एक बार जब हमें पता चल जाए कि हमें बिट _कहाँ_ सेट करना है, तो हम उसे बिटवाइज़ इन्क्लूसिव OR ऑपरेटर की मदद से सेट कर सकते हैं, जो `|` है।
`|` ऑपरेटर का परिणाम हर उस जगह `1` होगा जहाँ बाएँ या दाएँ ऑपरेंड में से किसी एक का बिट सेट हो।
तो `0010 | 0001` का परिणाम `0011` होगा।
(यह याद रखना ज़रूरी है कि यह वैल्यू बाइनरी में `11` है, लेकिन दशमलव में `3` है।)
परिणाम को किसी वैल्यू में असाइन करने के लिए `|` ऑपरेटर को असाइन करने वाले ऑपरेटर के साथ जोड़ा जा सकता है, जिससे बिट इस तरह सेट हो जाते हैं: `|=`.
इसे आसान रखने के लिए नीचे का उदाहरण लूप का इस्तेमाल नहीं करता, लेकिन यह दिखाता है कि हम `ABA` अक्षरों को बिट मास्क में कैसे प्रोसेस कर सकते हैं।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

हमने `A` के लिए अपने मास्क का सबसे दाहिना हिस्सा `0001` कर दिया, और फिर `B` के लिए मास्क `0011` कर दिया।
एक और `A` सेट करने पर मौजूदा मास्क में कोई बदलाव नहीं होता।
हम यह देखकर कि `A` पहले से सेट है या नहीं, बिट को दोबारा सेट करने से बच सकते थे।

### बिटवाइज़ AND ऑपरेटर: बिट पढ़ने का तरीका

`&` बिटवाइज़ AND ऑपरेटर है।
`&` ऑपरेटर का परिणाम हर उस जगह `1` होगा जहाँ बाएँ और दाएँ दोनों ऑपरेंड का बिट सेट हो।
तो `0011 & 0001` का परिणाम `0001` होगा।
यह नीचे के उदाहरण में काम करते हुए देखा जा सकता है।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### बिटवाइज़ एक्सक्लूसिव OR ऑपरेटर: बिट पलटने का तरीका

`^` बिटवाइज़ एक्सक्लूसिव OR ऑपरेटर है।
एक _इन्क्लूसिव_ OR ऑपरेटर होने का मतलब है कि एक _एक्सक्लूसिव_ OR ऑपरेटर भी है, जिसका व्यवहार अलग होता है।
`^` ऑपरेटर का परिणाम हर उस जगह `1` होगा जहाँ बाएँ या दाएँ ऑपरेंड में से _सिर्फ़ एक_ का बिट सेट हो।
तो `0001 ^ 0011` का परिणाम `0010` होगा।
सबसे दाहिना बिट सेट नहीं होगा, क्योंकि _दोनों_ ऑपरेंड की सबसे दाहिनी जगह `1` है।
एक्सक्लूसिव OR ऑपरेशन को कभी-कभी XOR लिखा जाता है।
किसी वैल्यू को XOR करने से जो परिणाम मिलता है, उसी को फिर XOR करने पर मूल वैल्यू वापस मिल जाती है।
इसका इस्तेमाल बहुत साधारण एन्क्रिप्शन के लिए किया जा सकता है, जिसमें डेटा को एन्क्रिप्ट और डिक्रिप्ट करने, दोनों के लिए एक ही की इस्तेमाल होती है।
उदाहरण के लिए

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### बिटवाइज़ शिफ्ट राइट ऑपरेटर: वैल्यू आधी करने का तरीका

`>>` दाएँ शिफ्ट करने वाला बिटवाइज़ ऑपरेटर है।
आम तौर पर, किसी वैल्यू के बिट जितनी जगह दाएँ शिफ्ट होते हैं, परिणाम वह वैल्यू होती है जो मूल वैल्यू को दो से भाग देने पर मिलती है।
उदाहरण के लिए

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

अगर दाएँ ऑपरेंड की वैल्यू ऋणात्मक है, या प्रोमोट किए गए बाएँ ऑपरेंड की चौड़ाई से बड़ी या उसके बराबर है, तो व्यवहार अपरिभाषित होता है।
यही बात लेफ्ट शिफ्ट ऑपरेटर पर भी लागू होती है।
जब unsigned पूर्णांक की जगह signed पूर्णांक इस्तेमाल किया जाता है, तो signed होने का भी असर पड़ सकता है।
नीचे का उदाहरण दिखाता है कि किसी सिस्टम पर signed पूर्णांक को बहुत ज़्यादा बाएँ या दाएँ शिफ्ट करने पर क्या व्यवहार होता है।

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

चूँकि व्यवहार अपरिभाषित है, किसी दूसरे सिस्टम पर नतीजे अलग आ सकते हैं।
बिट शिफ्ट करते समय यह समझना ज़रूरी है कि जिस डेटा टाइप का इस्तेमाल हो रहा है, उसकी सीमाएँ क्या हैं।

## बिट फील्ड

हमने देखा है कि किसी साधारण डेटा टाइप में पैक किए गए बिट तक उनकी जगह के हिसाब से पहुँचा जा सकता है।
`struct` में पैक किए गए बिट तक नाम के ज़रिए पहुँचा जा सकता है।
ऐसे डेटा टाइप को `bit field` कहा जाता है।
`bit fields` का एक उपयोग तब हो सकता है जब ON/OFF फ्लैग का एक समूह चाहिए और मेमोरी का इस्तेमाल कम से कम करना हो।

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;` का सिंटैक्स उस struct के अंदर रखे `unsigned int` में `1` बिट का एक फील्ड बनाता है।
`unsigned int` की जगह `signed int` इस्तेमाल किया जा सकता है, या C99 से आगे के स्टैंडर्ड में `bool` टाइप भी इस्तेमाल किया जा सकता है।
बिट फील्ड वाले struct में दूसरे डेटा टाइप के फील्ड भी हो सकते हैं, जैसे ऊपर के उदाहरण में `number_of_lights`.
