# परिचय

जेनेरिक्स की मदद से आप बिना कोड दोहराए ऐसा कोड लिख सकते हैं जो कई टाइप के साथ काम करता है। जेनेरिक टाइप बनाने के लिए एंगल ब्रैकेट `<T>` का प्रयोग कीजिए, जहाँ `T` किसी भी टाइप के लिए एक प्लेसहोल्डर है।

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo में ट्रेट बाउंड्स ज़रूरी होते हैं, जो तय करते हैं कि जेनेरिक टाइप को किन-किन ऑपरेशन का समर्थन करना है। आप `+` सिंटैक्स का उपयोग करके प्रतिबंध जोड़ सकते हैं:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

स्ट्रक्ट भी जेनेरिक हो सकते हैं:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

ट्रेट भी जेनेरिक हो सकते हैं, जिससे वे अलग-अलग टाइप के साथ काम कर पाते हैं:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

फंक्शन ऐसे जेनेरिक पैरामीटर भी ले सकते हैं जिन पर ट्रेट बाउंड्स लगे हों, जिससे वे हर उस टाइप के साथ काम करते हैं जो आवश्यक ट्रेट को लागू करता है:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
