# परिचय

Cairo में प्रिंट करने से आप प्रोग्राम चलने के दौरान संदेश या डीबग जानकारी प्रदर्शित कर सकते हैं।

## बुनियादी बातें

Cairo प्रिंट करने के लिए दो मैक्रो देता है:

- `println!`: एक संदेश प्रदर्शित करता है और उसके बाद एक नई लाइन जोड़ता है।
- `print!`: एक संदेश प्रदर्शित करता है, लेकिन नई लाइन के बिना।

```rust
println!("Hello, Cairo!"); 
println!("x = {}, y = {}", 10, 20); 
```

`{}` प्लेसहोल्डर की जगह दी गई वैल्यू रख दी जाती है।

## स्ट्रिंग को फॉर्मेट करना

`format!` की मदद से आप एक `ByteArray` बना सकते हैं, बिना उसे तुरंत प्रिंट किए:

```rust
let result = format!("{}-{}-{}", "tic", "tac", "toe");
println!("{}", result); // Output: tic-tac-toe
```

## कस्टम डेटा टाइप

कस्टम टाइप के लिए, प्रिंट करने के लिए `Display` लागू कीजिए या `Debug` डिराइव कीजिए:

```rust
#[derive(Debug)]
struct Point { x: u8, y: u8 }

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Debug output: Point { x: 3, y: 4 }
```

## हेक्साडेसिमल में प्रिंट करना

पूर्णांक को हेक्साडेसिमल में प्रिंट करने के लिए `{:x}` का इस्तेमाल कीजिए:

```rust
println!("{:x}", 255); // Output: ff
```
