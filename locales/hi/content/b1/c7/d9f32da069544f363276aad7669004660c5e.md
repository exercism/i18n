# संकेत

## सामान्य

- पढ़ने और लिखने का हर शब्द [`io.files`][io.files] में रहता है; और ये सारे शब्द जो `utf8` एन्कोडिंग लेते हैं, वह [`io.encodings.utf8`][utf8] से आती है।

## 1. हर रीडिंग पढ़िए

- `file-lines` हर लाइन से न्यूलाइन हटाकर लाइनों का एक ऐरे लौटाता है।

## 2. सबसे नई रीडिंग ढूँढ़िए

- लाइनों को `file-lines` से पढ़िए, फिर `last` वाली लीजिए (`sequences` से)।

## 3. कच्चा लॉग पढ़िए

- `file-contents` फाइल को एक ही स्ट्रिंग के रूप में लौटाता है, न्यूलाइनों सहित।

## 4. एक रीडिंग दर्ज कीजिए

- फाइल को जोड़ने के लिए खोलिए और रीडिंग को कोटेशन के अंदर `print` कीजिए: `with-file-appender ( path encoding quot -- )`. पथ उससे पहले ही ले लिया जाता है और रीडिंग कोटेशन के अंदर इस्तेमाल होती है, इसलिए `::` लोकल्स बॉडी को पढ़ने लायक बनाए रखते हैं: `:: record-reading ( reading path -- ) path utf8 [ reading print ] with-file-appender ;`.

## 5. लॉग दोबारा लिखिए

- `set-file-lines` किसी सीक्वेंस के हर एलिमेंट को अपनी अलग लाइन पर लिखता है और न्यूलाइनें खुद जोड़ देता है।
