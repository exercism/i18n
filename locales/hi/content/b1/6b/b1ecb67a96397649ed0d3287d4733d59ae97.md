# निर्देश परिशिष्ट

## शब्द

- `tick ( matrix cols -- matrix' )` ग्रिड को एक पीढ़ी आगे बढ़ाता है और नया ग्रिड लौटाता है।

ग्रिड की हर पंक्ति को एक 64-बिट पूर्णांक के रूप में दर्शाया जाता है; `cols` स्तंभों की संख्या है (अधिकतम 64)। उदाहरण के लिए,

```
    0 1 0
    1 0 0
    1 1 0
```

इसे इस तरह दर्शाया जाता है:

```
0b010
0b100
0b110
```
