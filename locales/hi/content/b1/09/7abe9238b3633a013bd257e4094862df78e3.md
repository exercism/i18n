# निर्देश

Alizé एक ऑनलाइन फैशन बुटीक चलाती हैं। सालाना बड़ी सेल आने वाली है, इसलिए वह इन्वेंटरी का हिसाब रखने में मदद के लिए कुछ सुविधाएँ बनाना चाहती हैं।

इन्वेंटरी की एक आइटम को एक कस्टम टाइप से दर्शाया जाता है।

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. आइटम के नामों की ऐरे लौटाइए

`item_names` फंक्शन बनाइए, जो आइटम का इटरेटर लेता है और उसी क्रम में उनके नामों का इटरेटर लौटाता है।

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. जो आइटम सस्ते हैं, उन्हें लौटाइए

`cheap` फंक्शन बनाइए, जो आइटम का इटरेटर लेता है और उन आइटम का इटरेटर लौटाता है जिनकी कीमत 30 से कम है।

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. जो आइटम स्टॉक से बाहर हैं, उन्हें लौटाइए

`out_of_stock` फंक्शन बनाइए, जो उन सभी आइटम को लौटाता है जिनका कोई स्टॉक नहीं बचा है।

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. कुल स्टॉक लौटाइए

`total_stock` फंक्शन बनाइए, जो आपके गोदाम में मौजूद कुल आइटम की संख्या निकालता है:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
