# विवरण

Haxe में [स्ट्रिंग][strings] अपरिवर्तनीय ऑब्जेक्ट होती हैं, जो टेक्स्ट को यूनिकोड अक्षरों (अक्षर, अंक, विराम चिह्न, आदि) के क्रम के रूप में दर्शाती हैं। `string` का इंस्टेंस बनाने के लिए डबल कोट (`"`) इस्तेमाल किए जाते हैं:

```haxe
var fruit:String = "Apple";
```

स्ट्रिंग पर काम करने के लिए उसके [मेथड या प्रॉपर्टी][string-api] में से किसी एक को कॉल किया जा सकता है। चूँकि किसी स्ट्रिंग की वैल्यू एक बार तय होने के बाद कभी नहीं बदल सकती, स्ट्रिंग से जुड़ा हर मेथड एक नई स्ट्रिंग लौटाता है।

स्ट्रिंग को डबल कोट (`"`) से घेरा जाता है। कुछ खास अक्षरों को बैकस्लैश (`\`) की मदद से [एस्केप][escaping] करना पड़ता है। इसके अलावा, Haxe की स्ट्रिंग मल्टीलाइन होती हैं, जिससे लंबे स्ट्रिंग लिटरल आसानी से बनाए जा सकते हैं:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

स्ट्रिंग जोड़ने का सबसे आसान तरीका [`+` ऑपरेटर][plus-operator] इस्तेमाल करना है।

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

और जटिल स्ट्रिंग फॉर्मेटिंग के लिए [स्ट्रिंग इंटरपोलेशन][interpolation] बेहतर रहता है। इसके लिए स्ट्रिंग को सिंगल कोट (`'`) में रखा जाता है और वेरिएबल इंटरपोलेशन के लिए डॉलर चिह्न (`$`) का उपयोग किया जाता है। `${expr}` लिखकर पूरे एक्सप्रेशन का मूल्यांकन भी किया जा सकता है, जहाँ `expr` कोई भी वैध Haxe एक्सप्रेशन हो सकता है:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
