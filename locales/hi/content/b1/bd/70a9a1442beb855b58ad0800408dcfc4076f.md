# परिचय

Gleam की स्टैंडर्ड लाइब्रेरी `gleam/queue` मॉड्यूल में एक `Queue` टाइप देती है। यह `List` टाइप जैसा है, लेकिन कुछ खास अंतर हैं:

- `Queue` टाइप में ऐसा कोई लिटरल सिंटैक्स नहीं है जिससे `Queue` बनाए जा सकें या उन पर पैटर्न मैच किया जा सके।
- `Queue` टाइप के आगे और पीछे, दोनों तरफ से एलिमेंट कुशलता से जोड़े और हटाए जा सकते हैं, जबकि `List` टाइप में एलिमेंट सिर्फ आगे से ही कुशलता से जोड़े और हटाए जा सकते हैं।

ज़्यादातर मामलों में आप `List` टाइप ही इस्तेमाल करना चाहेंगे, लेकिन जब आपको किसी कलेक्शन के अंत से एलिमेंट जोड़ने और हटाने की ज़रूरत हो, तो `Queue` टाइप अच्छा विकल्प है।

क्यू बनाने के लिए `queue.new` और `queue.from_list` फंक्शन इस्तेमाल किए जाते हैं:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

क्यू में एलिमेंट जोड़ने के लिए `queue.push_front` और `queue.push_back` फंक्शन इस्तेमाल किए जाते हैं:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

क्यू से एलिमेंट हटाने के लिए `queue.pop_front` और `queue.pop_back` फंक्शन इस्तेमाल किए जाते हैं:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

क्यू को लिस्ट में बदलने के लिए `queue.to_list` फंक्शन इस्तेमाल किया जाता है:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## क्यू की समानता

क्यू की अंदरूनी बनावट की वजह से, एक ही क्रम में एक जैसे एलिमेंट रखने वाले दो क्यू `==` ऑपरेटर के हिसाब से बराबर नहीं भी हो सकते हैं, क्योंकि यह ऑपरेटर वैल्यू की तुलना उनकी संरचना के आधार पर करता है। उदाहरण के लिए:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

अगर आपको दो क्यू के बराबर होने की जाँच करनी हो, तो `queue.is_logically_equal` फंक्शन इस्तेमाल कीजिए।

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
