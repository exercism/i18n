# परिचय

बाइनरी डेटा के साथ काम करना हर भाषा में एक ज़रूरी कॉन्सेप्ट है। Elixir में बाइनरी डेटा को लिखने, मिलान करने और बनाने के लिए एक सुंदर सिंटैक्स मौजूद है।

Elixir में बाइनरी डेटा को बिटस्ट्रिंग टाइप कहा जाता है। बाइनरी डेटा *टाइप* (जिसे सामान्य बाइनरी डेटा से अलग समझें) बिटस्ट्रिंग का एक विशेष रूप है। इस पर हम बाद के किसी अभ्यास में बात करेंगे।

बिटस्ट्रिंग लिटरल, बिटस्ट्रिंग स्पेशल फॉर्म `<<>>` की मदद से परिभाषित किए जाते हैं। बिटस्ट्रिंग लिटरल को सेगमेंट में परिभाषित किया जाता है। हर सेगमेंट में एक वैल्यू और एक टाइप होता है, जिन्हें `::` ऑपरेटर अलग करता है। टाइप बताता है कि वैल्यू को एन्कोड करने में कितने बिट लगेंगे। टाइप को पूरी तरह छोड़ा जा सकता है। ऐसा करने पर डिफॉल्ट रूप से 8-बिट पूर्णांक वैल्यू मान ली जाती है।

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

टाइप को `::1` लिखना `::size(1)` लिखने का शॉर्टहैंड है। अगर बिट साइज़ किसी वेरिएबल से आ रहा हो, तो लंबा सिंटैक्स इस्तेमाल करना ज़रूरी है।

## बाइनरी

बाइनरी पूर्णांक लिटरल लिखते समय हम उन्हें सीधे बेस-2 नोटेशन में लिख सकते हैं, बस लिटरल से पहले `0b` लगा दीजिए। ध्यान रखें कि टेस्ट के परिणामों में या जब iex इस्तेमाल करते हैं, तब ये वैसे भी दशमलव संख्याओं के रूप में प्रदर्शित होते हैं।

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## काटना

अगर सेगमेंट की वैल्यू सेगमेंट के टाइप की क्षमता से बढ़ जाए, तो उसे बाईं ओर से काट दिया जाएगा।

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## शुरू में और अंत में जोड़ना

आप स्पेशल फॉर्म की मदद से किसी मौजूदा बिटस्ट्रिंग के शुरू में और अंत में, दोनों जगह जोड़ सकते हैं। अगर मौजूदा बिटस्ट्रिंग का साइज़ मालूम न हो, तो उस पर `::bitstring` टाइप इस्तेमाल करना ज़रूरी है।

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## दो बिटस्ट्रिंग जोड़ना

वेरिएबल में रखी बिटस्ट्रिंग को स्पेशल फॉर्म की मदद से जोड़ा जा सकता है। जब दो अज्ञात साइज़ की बिटस्ट्रिंग जोड़ी जाती हैं, तो `::bitstring` टाइप इस्तेमाल करना ज़रूरी है।

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## पैटर्न मैचिंग

स्पेशल फॉर्म से वैल्यू निकालने के लिए पैटर्न मैचिंग भी की जा सकती है। हर उस टुकड़े के बिट की संख्या आपको पता होनी चाहिए जिसे आप लेना चाहते हैं, बस एक अपवाद है: अज्ञात साइज़ की बिटस्ट्रिंग पर पैटर्न मैच करने के लिए `::bitstring` टाइप इस्तेमाल किया जा सकता है, लेकिन इसे सिर्फ आखिरी टुकड़े के लिए ही इस्तेमाल किया जा सकता है।

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## बिटस्ट्रिंग को देखना

~~~~exercism/note
बिटस्ट्रिंग कभी-कभी (टेस्ट रनर द्वारा या iex में) उस फॉर्मैट से अलग फॉर्मैट में प्रदर्शित की जा सकती हैं, जिस फॉर्मैट में उन्हें बनाया गया था। बिटस्ट्रिंग सीखते समय यह अक्सर भ्रम पैदा करता है।
~~~~

डिफॉल्ट रूप से बिटस्ट्रिंग 8 बिट (यानी एक बाइट) के टुकड़ों में प्रदर्शित की जाती हैं, भले ही आपने उन्हें किसी और साइज़ के टुकड़ों में बनाया हो।

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

अगर आप ऐसी बिटस्ट्रिंग बनाते हैं जो किसी छापने योग्य UTF-8 एन्कोडेड स्ट्रिंग को दर्शाती है, तो वह स्ट्रिंग के रूप में प्रदर्शित की जाती है।

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
