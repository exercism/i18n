# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग | टाइप | विवरण |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | इनपुट     | पता | null पर समाप्त होने वाली हेक्स अक्षरों की स्ट्रिंग |
| `$v0`    | आउटपुट    | पूर्णांक | इनपुट स्ट्रिंग की दशमलव वैल्यू |
| `$t0-9`  | अस्थायी | कोई भी | अस्थायी भंडारण के लिए इस्तेमाल होता है |
