# निर्देश

इस अभ्यास में आप एक `TranslationService` बनाएँगे, जो मुफ्त सदस्यों को साधारण अनुवाद सेवाएँ देता है और प्रीमियम सदस्यों को गुणवत्ता की गारंटी के साथ उन्नत अनुवाद।

**API**

आपको अंतरिक्ष की एक अनुवाद API मिली है, जो किसी भी अनुवाद `request` को उचित समय में पूरा कर देती है।
आप इसका फायदा उठाना चाहते हैं।
अंतरिक्ष के अनुवादक बहुत मनमौजी हैं और दोहराव से चिढ़ते हैं, इसलिए वे _API storage_ सैटेलाइट भी देते हैं, जहाँ से आप पुराने अनुवाद `fetch` कर सकते हैं, बिना उन्हें परेशान किए।

**_एक अनुवाद लाना_**

`api.fetch(text)` _API storage_ से `text` का अनुवाद लाता है और एक `promise` लौटाता है जो दो वैल्यू देता है:

- `translation`: असली अनुवाद
- `quality`: एक संख्या के रूप में व्यक्त गुणवत्ता

अगर _API storage_ में अनुवाद नहीं मिलता, तो API एक `NotAvailable` एरर देती है।
अनुवाद `api.request` मेथड से जोड़े जा सकते हैं।
अगर 'text' का अनुवाद नहीं हो सकता, तो API एक `Untranslatable` एरर देती है।

```javascript
api.fetch('jIyaj');
// => Promise({ resolved: 'I understand' })
```

**_एक अनुवाद का अनुरोध करना_**

कुछ अनुवादों का होना तय है, लेकिन वे अभी _API storage_ में जोड़े नहीं गए हैं। यही `NotAvailable` (storage में नहीं है, पर अनुरोध किया जा सकता है) और `Untranslatable` (अनुवाद हो ही नहीं सकता) के बीच का फर्क है।

`api.request(text, callback)` अनुरोध करता है कि `text` का अनुवाद किया जाए और उसे _API storage_ में जोड़ा जाए।
पूरा होने पर `callback` फंक्शन को कॉल किया जाता है।

- सफल होने पर `callback` को `undefined` दिया जाता है: इसका मतलब है कि अनुवाद सफल रहा और उसे `api.fetch` मेथड से पाया जा सकता है।
- असफल होने पर `callback` को एक `error` दिया जाता है: इसका मतलब है कि कुछ गड़बड़ हुई।
  अंतरिक्ष की API _अस्थिर_ है, यानी यह अक्सर फेल होती है।
  ऐसा हो तो दोबारा `api.request` करना ठीक है।

```javascript
api.request('majQa’', callback);
// => undefined
//
// later: the passed callback is called with undefined
//        because it was successful.
```

**⚠ चेतावनी! ⚠**

~~~~exercism/caution
API अपना कमाल यह करती है कि जब कोई `request` आती है, तो वह अलग-अलग अनुवादकों को तुरंत पहुँचा देती है।
यह बहुत महँगा काम है, इसलिए जब कोई अनुवाद *उपलब्ध* हो, तब इसे कॉल नहीं करना चाहिए।
बदकिस्मती से, हर कोई नियमावली नहीं पढ़ता, इसलिए नियम तोड़ने वालों को बाहर निकालने की एक व्यवस्था भी है।

अगर किसी उपलब्ध `text` के लिए `api.request` कॉल की जाती है, तो API इस कॉल के लिए एक `AbusiveClientError` देती है, **और उसके बाद हर कॉल के लिए भी**।
अगर किसी चीज़ का अनुवाद पहले ही हो चुका है, तो आप उसका अनुवाद *कभी* अनुरोध न करें, यह सुनिश्चित कीजिए।
~~~~

## 1. अनुवाद लाइए, गुणवत्ता को नज़रअंदाज़ करते हुए

मुफ्त सेवा सिर्फ वे अनुवाद देती है जो अभी _API storage_ में मौजूद हैं।

एक मेथड `free(text)` बनाइए जो मुफ्त सदस्यों को वे अनुवाद देता है जो पहले से _API storage_ में मौजूद हैं।
गुणवत्ता को नज़रअंदाज़ कीजिए और API की ओर से आने वाली हर एरर आगे बढ़ा दीजिए।

- अगर अनुवाद निकाला जा सकता है, तो उसे लौटाता है, चाहे उसकी गुणवत्ता कुछ भी हो
- अनुवाद API की किसी भी एरर को आगे बढ़ा देता है
- `api.fetch` मेथड इस्तेमाल करता है (`api.fetch` एक `promise` लौटाता है)

```javascript
service.free('jIyaj');
// => Promise<...> resolves "I understand."

service.free("jIyajbe'");
// => Promise<...> rejects Error("Not yet translated")
```

## 2. अनुवादों का बैच लाइए, सब एक साथ वरना कुछ भी नहीं

मुफ्त सदस्यों के लिए एक मेथड `batch([text, text, ...])` बनाइए जो मुफ्त सेवा से टेक्स्ट के ऐरे का अनुवाद करता है और सारे अनुवाद लौटाता है, या एक ही एरर।

- अगर सारे अनुवाद उपलब्ध हैं, तो सारे अनुवादों के साथ रिज़ॉल्व होता है (उसी क्रम में)
- सबसे पहले मिलने वाली एरर के साथ रिजेक्ट होता है
- अगर कोई टेक्स्ट नहीं दिया गया हो, तो `BatchIsEmpty` एरर के साथ रिजेक्ट होता है

```javascript
service.batch(['jIyaj', "majQa'"]);
// => Promise<...> resolves ["I understand.", "Well done!"]

service.batch(['jIyaj', "jIyajbe'"]);
// => Promise<...> rejects new Error("Not yet translated")

service.batch([]);
// => Promise<...> rejects BatchIsEmpty()
```

## 3. अनुवाद का अनुरोध कीजिए, ज़्यादा से ज़्यादा 2 बार दोबारा कोशिश करते हुए

प्रीमियम उपयोगकर्ता के लिए एक मेथड `request(text)` बनाइए, जो _API storage_ में एक अनुवाद जोड़ने का _अनुरोध_ करता है।
अगर कोई गड़बड़ी हो, तो अनुरोध को अपने आप दोबारा कोशिश करनी चाहिए।
एक ही अनुरोध के लिए यह **3 से ज़्यादा कॉल** न करे (_अंतरिक्ष के अनुवादकों को नाराज़ मत कीजिए!!!_)।

- अगर `api.request` कोई एरर नहीं लौटाता, तो `undefined` के साथ रिज़ॉल्व कीजिए
- अगर `api.request` एरर लौटाता है, तो ज़्यादा से ज़्यादा दो बार दोबारा कोशिश कीजिए
- अगर कोशिशें खत्म हो जाएँ, तो अंतिम मिली एरर के साथ रिजेक्ट कीजिए

```javascript
service.request("jIyajbe'");
// => Promise<...> resolves (with nothing), can now be retrieved using the fetch API
```

## 4. अनुवाद लाइए, गुणवत्ता जाँचिए, या उसका अनुरोध कीजिए

अनुवाद लाने के लिए प्रीमियम उपयोगकर्ता का एक मेथड `premium(text, quality)` बनाइए।
अगर कोई अनुवाद `NotAvailable` है, तो उस अनुवाद का अनुरोध कीजिए और _API storage_ में जुड़ने के बाद उसे ले लीजिए।
मेथड तभी अनुवाद लौटाए, जब वह एक तय `quality` सीमा पर खरा उतरता हो।

- अगर `api.fetch` रिज़ॉल्व होता है, तो रिज़ॉल्व करने से पहले गुणवत्ता जाँचिए
- अगर `api.fetch` रिजेक्ट होता है, तो इसके बजाय अनुवाद का _अनुरोध_ कीजिए
- अगर `api.request` रिजेक्ट होता है, तो एरर आगे बढ़ा दीजिए

```javascript
service.premium("jIyajbe'", 100);
// => Promise<...> resolves "I don't understand."

service.premium("'arlogh Qoylu'pu'?", 100);
// => Promise<...> rejects QualityThresholdNotMet()

service.premium("'arlogh Qoylu'pu'?", 40);
// => Promise<...> resolves "What time is it?"
```
