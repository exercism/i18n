# बारे में

एक *डिसजॉइंट सेट* एक यूनियन-फाइंड ढाँचा है। यह वैल्यू का एक संग्रह रखता है जो बिना टकराव वाले समूहों में बाँटा गया हो। साथ ही यह एक सवाल का जवाब जल्दी देता है: क्या ये दोनों वैल्यू एक ही समूह में हैं? यह सुविधा [`disjoint-sets`][disjoint-sets] वोकैबुलरी में मिलती है।

`<disjoint-set>` एक खाली ढाँचा बनाता है। वैल्यू, यानी *एटम*, `add-atom` से जोड़े जाते हैं, या `add-atoms` से एक साथ कई जोड़े जाते हैं। हर एटम अपने अलग समूह से शुरू होता है:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` उन समूहों को जोड़ देता है जिनमें दो एटम होते हैं। यह जोड़ना संक्रामक है: जब एक बार `a` को `b` के साथ और `b` को `c` के साथ `equate` कर दिया जाए, तो तीनों एक ही समूह में आ जाते हैं।

```
equate ( atom1 atom2 disjoint-set -- )
```

हर समूह की पहचान उसके एक ही मानक सदस्य, यानी उसके *प्रतिनिधि* से होती है। `representative` उसी को लौटाता है, और दो एटम ठीक तभी एक ही समूह के होते हैं जब उनके प्रतिनिधि बराबर हों। `equiv?` यह जाँच सीधे कर देता है:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

किसी समूह का प्रतिनिधि कौन-सा एटम चुना जाता है, यह अंदर की बात है। वह समूह का कोई भी सदस्य हो सकता है, और समूह जुड़ने पर बदल भी सकता है। कभी यह मानकर न चलिए कि कोई खास एटम ही प्रतिनिधि होगा, बल्कि सिर्फ इस पर भरोसा कीजिए कि एक ही समूह के दो एटमों के प्रतिनिधि एक जैसे होंगे।

`disjoint-set-members` उन सारे एटमों को लौटाता है जो जोड़े जा चुके हैं।

यह ढाँचा *परिवर्तनीय* है: `equate` और `add-atom` नया ढाँचा लौटाने के बजाय उसी डिसजॉइंट सेट को उसी जगह बदल देते हैं। इसका कार्यान्वयन रैंक के अनुसार यूनियन और पाथ कंप्रेशन का इस्तेमाल करता है, इसलिए `equate` और `representative` को लगातार कई बार कॉल करने पर हर कॉल लगभग स्थिर समय लेती है।
