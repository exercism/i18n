# शर्तों के बारे में

## तुलना ऑपरेटर

[तुलना ऑपरेटर][operators] कई अन्य भाषाओं के ऑपरेटरों जैसे ही होते हैं, बस इनमें कुछ चीज़ें अतिरिक्त भी हैं।

बराबरी की जाँच के लिए ऑपरेटर `==` (बराबर) और `!=` (बराबर नहीं) हैं।

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

इसके अलावा, `===` और `!==` ऑपरेटर ["रेफरेंशियल समानता"][referential-equality] की जाँच करते हैं: `a === b` तभी और केवल तभी होता है जब `a` और `b` एक ही ऑब्जेक्ट की ओर इशारा करते हैं।
सिलेबस में आगे चलकर यह बात और साफ़ समझ आएगी।

इससे बड़ा या छोटा बताने वाले ऑपरेटर भी सामान्य तरीके से ही काम करते हैं।

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if` से शाखाएँ बनाना

यह [`if` एक्सप्रेशन][if-else] का पूरा रूप है:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- हर शर्त के चारों ओर गोल ब्रैकेट `()` लगाना ज़रूरी है।
- किसी शर्त का परिणाम बूलियन `true` या `false` ही होना चाहिए।
  कुछ भाषाओं में जैसा "ट्रुथी" और "फ़ॉल्सी" का विचार होता है, वैसा Kotlin में नहीं है।
- अगर अंदर सिर्फ़ एक ही एक्सप्रेशन है, तो ब्रैकेट `{}` लगाना ज़रूरी नहीं है।
- `else if` और `else`, दोनों ज़रूरी नहीं हैं, और एक से ज़्यादा `else if` ब्लॉक भी हो सकते हैं।

`if` एक्सप्रेशन की मदद से एक वैल्यू भी "चुनी" जा सकती है:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## दूसरे विकल्प?

जानबूझकर ऐसा चुना गया है कि Kotlin में वह टर्नरी ऑपरेटर `? :` न हो जो Java में मिलता है।
इसके बजाय `if ... else` का छोटा रूप पसंद किया जाता है:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

Ruby के उलट, `if ... else` के छोटे रूप में `else` *हमेशा* ज़रूरी होता है, इसलिए इसे गार्ड स्टेटमेंट की तरह इस्तेमाल नहीं किया जा सकता:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

ध्यान दीजिए कि Kotlin में `if` एक [_एक्सप्रेशन_][expression] है, जो एक वैल्यू लौटाता है।
यह Java की तरह [_स्टेटमेंट_][statement] नहीं है।

आगे किसी कॉन्सेप्ट में हम देखेंगे कि Kotlin में एक शक्तिशाली [`when`][when] रचना है, जिसका उद्देश्य `else if` की लंबी कतारों की जगह पैटर्न मैचिंग लाना है।
