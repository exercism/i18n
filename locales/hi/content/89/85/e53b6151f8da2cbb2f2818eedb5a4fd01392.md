# परिचय

JavaScript में ऐरे एक सूची जैसी संरचना होता है, जिसकी कोई तय लंबाई नहीं होती। ऐरे में किसी भी तरह के प्रिमिटिव या ऑब्जेक्ट रखे जा सकते हैं, और एक ही ऐरे में अलग-अलग डेटा टाइप की वैल्यू भी।

ऐरे बनाने के लिए चौकोर ब्रैकेट `[]` के बीच एलिमेंट लिखिए।
ऐरे से कोई वैल्यू पढ़ने के लिए आइडेंटिफायर के बाद चौकोर ब्रैकेट `[]` में इंडेक्स लिखिए।
ऐरे के इंडेक्स शून्य से शुरू होते हैं।

उदाहरण के लिए:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

ऐरे में कितने एलिमेंट हैं, यह जानने के लिए `length` प्रॉपर्टी इस्तेमाल कीजिए:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

ऐरे में कोई एलिमेंट बदलने के लिए उस इंडेक्स पर एक वैल्यू असाइन कीजिए:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## मेथड

हर Array ऑब्जेक्ट पर उपलब्ध कुछ [मेथड][array_methods] ऐरे में एलिमेंट जोड़ने या ऐरे से हटाने के काम आते हैं।

### push

> `push()` मेथड ऐरे के अंत में एक या अधिक एलिमेंट जोड़ता है और ऐरे की नई लंबाई लौटाता है।[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> `pop()` मेथड ऐरे से अंतिम एलिमेंट हटाता है और वह एलिमेंट लौटाता है।
> यह मेथड ऐरे की लंबाई बदल देता है।[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> `shift()` मेथड ऐरे से पहला एलिमेंट हटाता है और उस हटाए गए एलिमेंट को लौटाता है।
> यह मेथड ऐरे की लंबाई बदल देता है।[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> unshift() मेथड ऐरे की शुरुआत में एक या अधिक एलिमेंट जोड़ता है और ऐरे की नई लंबाई लौटाता है।[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> splice() मेथड ऐरे की सामग्री बदल देता है। यह मौजूदा एलिमेंट हटाता है या उनकी जगह दूसरे रखता है, और/या उसी जगह नए एलिमेंट जोड़ता है। यह मेथड हटाए गए एलिमेंट वाला एक ऐरे लौटाता है।[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
