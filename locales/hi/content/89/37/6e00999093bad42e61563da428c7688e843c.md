# परिचय

Swift में [क्लोज़र][closures] कोड के ऐसे ब्लॉक होते हैं जो अपने आप में पूर्ण होते हैं, और इन्हें पैरामीटर देकर इनकी गणना शुरू की जा सकती है और ये वैल्यू लौटाते हैं।
क्लोज़र अपने वातावरण से वैल्यू भी पकड़ लेते हैं और अपनी गणना में उनका उपयोग करते हैं।
चूँकि ये अपने आप में पूर्ण होते हैं, इसलिए इन्हें प्रोग्राम में दूसरी वैल्यू की तरह इधर-उधर भेजा जा सकता है, या स्थिरांक और वेरिएबलो में असाइन किया जा सकता है।

क्लोज़र सुनने में Swift के फंक्शन जैसे बहुत लग सकते हैं, और वाकई वे हैं, और इसकी एक अच्छी वजह है।
Swift में फंक्शन क्लोज़र का ही एक खास रूप हैं, जिनका नाम होना ज़रूरी होता है और जिन्हें थोड़े अलग सिंटैक्स से बनाया जाता है।

हालाँकि Swift में फंक्शन तकनीकी रूप से क्लोज़र ही हैं, लेकिन जब लोग Swift में "क्लोज़र" कहते हैं, तो उनका मतलब [closure expressions][closure-expressions] होता है।
क्लोज़र एक्सप्रेशन इस तरह लिखे जाते हैं: पहले पैरामीटर की सूची, उसके बाद रिटर्न टाइप, फिर `in` कीवर्ड, और उसके बाद क्लोज़र की बॉडी, और यह सब घुंघराले ब्रैकेट के एक जोड़े के अंदर रहता है:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

यह `(Double, Double) -> Double` टाइप का एक क्लोज़र एक्सप्रेशन बनाता है, और इसे इस टाइप के फंक्शन की तरह ही चलाया जा सकता है, यानी इसे सही टाइप के पैरामीटर देकर:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

हर बार चलाने के लिए पूरा क्लोज़र एक्सप्रेशन लिखना बहुत सुविधाजनक नहीं होता, इसलिए क्लोज़र को Swift की किसी भी दूसरी वैल्यू की तरह नामों में असाइन किया जा सकता है।
फिर उस नाम को पैरामीटर के साथ लिखकर उसे कॉल किया जा सकता है:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

जैसा ऊपर दिखा, क्लोज़र भी आम फंक्शन की तरह `return` कीवर्ड छोड़ सकते हैं, अगर क्लोज़र की बॉडी एक ही एक्सप्रेशन हो।

अक्सर क्लोज़र हायर-ऑर्डर फंक्शन के साथ इस्तेमाल होते हैं, या तो पैरामीटर के रूप में दिए जाते हैं या परिणाम के रूप में लौटाए जाते हैं:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
