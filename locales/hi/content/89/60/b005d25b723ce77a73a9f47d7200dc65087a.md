# परिचय

## मॉड्यूल

अब तक आपने जो भी अभ्यास देखे हैं, उन सबमें क्लास का उपयोग हुआ है।
कभी-कभी हमें स्थिति वाले ऑब्जेक्ट बनाने का अतिरिक्त बोझ नहीं चाहिए होता, इसलिए उसके बजाय हम `module` इस्तेमाल करते हैं।

मॉड्यूल क्लास से बहुत मिलता-जुलता है (दरअसल, ऑब्जेक्ट के पदानुक्रम में `Module`, `Class` से ऊपर होता है)। मुख्य अंतर यह है कि हम इंस्टेंस मेथड के बजाय क्लास मेथड इस्तेमाल करते हैं।
क्लास मेथड `self.` से शुरू होते हैं और सीधे मॉड्यूल पर कॉल किए जाते हैं।

उदाहरण के लिए:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## लूप

Ruby में लूप लिखने के कई तरीके हैं, लेकिन चूँकि सामान्य तौर पर हम लूप के बजाय एन्यूमरेशन इस्तेमाल करते हैं, इसलिए सबसे आम लूप शायद `while` लूप ही है:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

आप इसके साथी `until` का भी इस्तेमाल कर सकते हैं

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
