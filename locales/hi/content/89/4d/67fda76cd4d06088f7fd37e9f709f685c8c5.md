# संकेत

## सामान्य

- Roc में लेंस का उपयोग ज़्यादा नहीं होता, क्योंकि रिकॉर्ड अपडेट सिंटैक्स अधिकतर उपयोगों को अच्छी तरह संभाल लेता है।
  उदाहरण के लिए, इस नेस्टेड रिकॉर्ड को देखिए:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  अब चलिए Bob के बाल काटते हैं:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  किसी लेंस की ज़रूरत नहीं!

- फिर भी, Roc में लेंस दुर्लभ होते हैं, लेकिन Haskell और Scala जैसी अन्य भाषाओं में आम हैं। इसलिए आप जानना चाहेंगे कि Roc में इन्हें कैसे लागू किया जा सकता है।
  यह पैरामीटर वाले टाइप और फंक्शन रखने वाले रिकॉर्ड जैसे कुछ उन्नत Roc फीचर का अभ्यास करने का भी अच्छा तरीका है।
  वास्तव में, Roc में लेंस को दर्शाने का एक तरीका यह है:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  यह एक पैरामीटर वाला टाइप है: `whole` और `part` किसी भी टाइप के हो सकते हैं।
  `whole` आम तौर पर एक रिकॉर्ड होता है, जबकि `part` किसी भी फील्ड टाइप का हो सकता है।
  `get` फील्ड में एक फंक्शन है जो दिए गए `whole` का एक खास `part` लौटाता है, जबकि `set` फील्ड में एक फंक्शन है जो दिए गए `whole` की कॉपी लौटाता है, बस उसमें एक खास `part` को दिए गए `part` से बदल दिया जाता है।

  उदाहरण के लिए, किसी व्यक्ति के बाल पाने या सेट करने वाला लेंस यह है:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  इस लेंस से हम Bob के बालों पर फोकस कर सकते हैं, ऐसे:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  और हम उनके बाल ऐसे बदल सकते हैं:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- ध्यान दें: `hair_lens.set` के चारों ओर के गोल ब्रैकेट ज़रूरी हैं। इनके बिना Roc `hair_lens` के टाइप में `set` नाम का फंक्शन ढूँढेगा।

- लेंस खास तौर पर तब बहुत काम के हो जाते हैं जब आप इन्हें मिलाकर इस्तेमाल करना शुरू करते हैं, जिससे आप गहराई तक नेस्टेड हिस्सों को पा सकते हैं और उन्हें सेट कर सकते हैं।
  ऐसा करने के लिए इस जैसा फंक्शन लागू किया जा सकता है:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  यह फंक्शन लागू हो जाने के बाद, आप इससे बालों की लंबाई वाला लेंस ऐसे बना सकते हैं:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  अब आप Bob के बाल फिर से काट सकते हैं:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- आप ऐसा फंक्शन भी लागू करना चाह सकते हैं जो किसी नेस्टेड हिस्से पर कोई भी रूपांतरण लागू करने दे:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  लागू हो जाने के बाद, आप `over` का इस्तेमाल ऐसे कर सकते हैं:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- हमारा सुझाव है कि पहले आप Roc के रिकॉर्ड अपडेट सिंटैक्स से टेस्ट पास कीजिए, फिर उसके बजाय लेंस इस्तेमाल करके देखिए।
