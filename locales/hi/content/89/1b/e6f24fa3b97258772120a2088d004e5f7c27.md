# टेस्ट

चूँकि OCaml एक ऐसी भाषा है जिसे कंपाइल करना पड़ता है, इसलिए टेस्ट चलाने से पहले आपको अपना सबमिशन और टेस्ट कोड कंपाइल करना होगा।
हम बिल्ड करने के लिए [`dune`](https://dune.build/) का उपयोग करते हैं।
हर फोल्डर में एक dune फाइल होती है जो बताती है कि बिल्ड कैसे करना है, और एक Makefile भी होता है जो यह काम dune को सौंप देता है।

टेस्ट कंपाइल करने और चलाने के लिए, अभ्यास वाले फोल्डर से बस यह लिखिए:

```bash
make
```

## अपना पहला OCaml मॉड्यूल बनाइए

ऐसा मॉड्यूल बनाने के लिए जिसे `bob` अभ्यास के टेस्ट के साथ इस्तेमाल किया जा सके, `bob.ml` नाम की फाइल में यह लिखिए:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
