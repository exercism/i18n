# टेस्ट

MacOS/Linux पर यह चलाइए:

```sh
$ chmod +x gradlew
```

टेस्ट चलाने के लिए यह कमांड चलाइए:

```sh
$ ./gradlew test
```

> अगर आप Windows पर हैं तो `gradlew.bat` इस्तेमाल कीजिए

## छोड़े गए टेस्ट

पहला टेस्ट (या पहले टेस्ट) पास हो जाने के बाद, बाकी टेस्टों के आगे लगे `@Ignore` एनोटेशन को कमेंट करके या हटाकर आगे बढ़िए।
