# निर्देश

आपकी डिज़ाइन कंपनी मुख्य रूप से वेब पेज बनाने के लिए CSS ट्रांसफॉर्मेशन का उपयोग करती आ रही है। कुछ चर्चा के बाद यह निर्णय लिया गया कि कुछ गणनाएँ गतिशील रूप से करने के लिए Clojure का उपयोग शुरू किया जाए। आपके कुछ साथी Clojure में कम अनुभवी हैं, इसलिए आप `{x, y}` निर्देशांक जोड़ों के लिए दोबारा उपयोग किए जा सकने वाले ट्रांसफॉर्मेशन बनाने के लिए फंक्शन क्लोज़र का उपयोग करने का निर्णय लेते हैं।

## 1. निर्देशांकों को स्थानांतरित कीजिए

`translate2d` फंक्शन बनाइए जो एक फंक्शन लौटाता है जो क्लोज़र का उपयोग करके किसी निर्देशांक जोड़े का दोहराया जा सकने वाला 2d स्थानांतरण करता है।

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. निर्देशांकों का स्केल बदलिए

`scale2d` फंक्शन बनाइए जो एक फंक्शन लौटाता है जो क्लोज़र का उपयोग करके किसी निर्देशांक जोड़े पर दोहराया जा सकने वाला 2d स्केल लागू करता है।

> इस अभ्यास के लिए, मान लीजिए कि स्केलिंग वैल्यू केवल धनात्मक हैं।

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. ट्रांसफॉर्मेशन फंक्शनों को मिलाइए

एक दोहराया जा सकने वाला ट्रांसफॉर्मेशन करने के लिए दो ट्रांसफॉर्मेशन फंक्शनों को मिलाइए। इसे अक्सर _फंक्शन कंपोज़िशन_ कहा जाता है, जिसमें पहले फंक्शन _'f(x)'_ का परिणाम दूसरे फंक्शन _'g(x)'_ के इनपुट के रूप में उपयोग किया जाता है।

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. फंक्शनों के परिणाम संग्रहीत कीजिए

`memoize-transform` फंक्शन बनाइए। यह _मेमोइज़_ करने के लिए एक फंक्शन लेता है, फिर एक नया फंक्शन लौटाता है जो दिए गए फंक्शन के इनपुट याद रखता है ताकि पिछली रिटर्न वैल्यू याद रखी जा सके और अगर उसी आर्गुमेंट के साथ दोबारा कॉल किया जाए तो उसकी गणना केवल एक बार हो।

> मेमोइज़िंग को कभी-कभी _डायनैमिक प्रोग्रामिंग_ कहा जाता है; यह महँगे ऑपरेशनों को केवल एक बार करने देता है क्योंकि उनका परिणाम याद रखा जाता है।

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
