# पुल रिक्वेस्ट

पुल रिक्वेस्ट (PR) वह तरीका है जिससे आप Exercism के कोडबेस के किसी हिस्से में अपने प्रस्तावित बदलाव जमा करते हैं।
अगर आप यह पढ़ रहे हैं और एक PR तैयार कर रहे हैं, तो धन्यवाद!
इस गाइड का उद्देश्य PR के गैर-तकनीकी पक्ष में आपकी मदद करना है, ताकि आपका अनुभव बढ़िया रहे और साथ ही हमारी मेंटेनर टीम को भी मदद मिले।

## आप क्या उम्मीद कर सकते हैं

PR की प्रक्रिया इस तरह होती है:

- आप एक PR जमा करते हैं
- एक या अधिक मेंटेनर PR की समीक्षा करते हैं और सुझाव वाली टिप्पणियाँ छोड़ते हैं।
  कुछ मामलों में वे पूरे PR पर चर्चा करते हैं और देखते हैं कि यह जोड़ना सही चीज़ है या नहीं।
- आपका PR मर्ज हो जाता है और आपको वेबसाइट पर रेप्यूटेशन मिलता है।
  या फिर आपका PR बंद कर दिया जाता है।

## मेरा PR मर्ज कैसे होगा?

कुछ चीज़ें ऐसी हैं जो आप पहले से कर सकते हैं, जिससे इस बात की संभावना बढ़ जाती है कि आपका PR कम बदलावों के साथ मर्ज हो जाए।

सबसे ज़रूरी बात यह है कि **PR जमा करने से पहले** आप यह सुनिश्चित कर लें कि मेंटेनर आपके बदलावों का स्वागत करेंगे।
इसका सबसे आसान तरीका यह है कि पहले GitHub पर एक इश्यू खोलिए, उसमें बताइए कि आप क्या करना चाहते हैं, और पूछिए कि मेंटेनर इन बदलावों के लिए तैयार हैं या नहीं।

```exercism/note
अगर आपको Exercism की वेबसाइट पर एक टास्क मिलता है, तो नया इश्यू खोलने की ज़रूरत नहीं है।
आप मौजूदा इश्यू पर टिप्पणी करके बता सकते हैं कि आप उस पर काम करने वाले हैं, और फिर आगे बढ़ सकते हैं।
```

दूसरी बात यह सुनिश्चित करना है कि PR खोलते समय आप उसमें साफ़ विवरण लिखें।
जिन PR में विवरण नहीं होता, वे मेंटेनर के लिए **बेहद** निराशाजनक होते हैं, क्योंकि कोड पढ़ते समय उनके पास संदर्भ नहीं होता।
हमें बताइए कि आपने ये बदलाव क्यों किए, उस इश्यू का लिंक दीजिए जिससे यह PR जुड़ा है, और यह भी समझाइए कि किन चीज़ों में आपको समझौता करना पड़ा, इत्यादि।

अंत में, यह सुनिश्चित कीजिए कि आपके PR में सिर्फ़ एक ही सुधार से जुड़े बदलाव हों।
अगर आपके पास कई सुधार हैं, तो उन्हें अलग-अलग PR में बाँट दीजिए।
इससे मेंटेनर के लिए समीक्षा करना आसान और तेज़ हो जाता है, और आपका काम भी आसान हो जाएगा।

## मुझे कितना इंतज़ार करना चाहिए?

आम तौर पर मेंटेनर कुछ दिनों के भीतर आपके PR की समीक्षा कर लेते हैं।
कृपया पहले हफ्ते में बार-बार अतिरिक्त टिप्पणियाँ जोड़कर PR को बंप न करें। हमारे मेंटेनर स्वयंसेवक हैं और व्यस्त लोग हैं, इसलिए वे जैसे ही समय निकाल पाएँगे, इसकी समीक्षा कर लेंगे।
अगर 7 दिनों के भीतर कोई जवाब न मिले, तो कृपया PR पर एक **नई** टिप्पणी में `@exercism/reviewers` को टैग कीजिए, जिससे बड़ी टीम को इसकी जानकारी मिल जाएगी।

हमें उम्मीद है कि यह अनुभव आपके लिए मज़ेदार और उपयोगी रहेगा!
