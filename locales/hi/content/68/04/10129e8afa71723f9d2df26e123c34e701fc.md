# परिचय

Cairo में एनम की मदद से आप ऐसा टाइप बना सकते हैं जो कई नाम वाले वेरिएंट में से एक हो सकता है।

## मूल बातें

एनम, यानी एन्यूमरेशन, किसी डेटा की सारी संभावित वैल्यू को पहले से तय एक सेट तक सीमित कर देते हैं।
किसी `enum` की संभावित वैल्यू को वेरिएंट कहा जाता है:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

एनम वैल्यू बनाने के लिए वेरिएंट बताइए:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## पैटर्न मैचिंग

अलग-अलग एनम वेरिएंट संभालने के लिए match का इस्तेमाल कीजिए:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

match की हर शाखा एनम के एक वेरिएंट को संभालती है।

## डेटा वाले एनम

एनम वेरिएंट अपने अंदर अतिरिक्त डेटा रख सकते हैं:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

डेटा निकालने के लिए पैटर्न मैच कीजिए:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
