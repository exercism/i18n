# परिचय

`call` एक सार्वभौमिक प्रिमिटिव है जो कहता है: इस कोटेशन को अभी चलाइए। जब कंपाइलर कोटेशन को सीधे देख सकता है, तब वह इफेक्ट का अनुमान लगा सकता है। लेकिन जब कोटेशन किसी वेरिएबल, ऐरे या पैरामीटर से आता है, तब आपको इफेक्ट घोषित करना पड़ता है:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

`call( a b -- c )` घोषणा कंपाइल होकर रनटाइम पर एक जाँच बन जाती है, जो देखती है कि कोटेशन में सचमुच वही इफेक्ट है जो घोषित किया गया था। अगर दोनों में मेल नहीं बैठता, तो स्टैक की स्थिति बिगड़ने के बजाय एक साफ़ एरर मिलती है।

कोटेशन को डेटा मानना, यानी उन्हें स्टैक पर रखना, ऐरे में डालना या वर्ड से लौटाना, कंकैटेनेटिव कोड को इतना छोटा बनाने वाली बातों में से एक है। एक "प्रोग्राम" बस एक सीक्वेंस हो सकता है, और उसे चलाने के लिए `each` के साथ `call` काफ़ी है।
