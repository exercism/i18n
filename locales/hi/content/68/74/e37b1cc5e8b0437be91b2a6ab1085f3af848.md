# परिचय

[concept:csharp/resource-cleanup]() में `IDispose` इंटरफ़ेस का उपयोग किसी क्लास का इस्तेमाल करने वाले कोड को यह संकेत देने के लिए किया जाता है कि जब उस ऑब्जेक्ट की ज़रूरत न रहे, तो कुछ संसाधन या प्रोग्राम की स्थिति समय रहते छोड़नी या रीसेट करनी होती है। इस अभ्यास में हमने `using` कीवर्ड के ज़रिए थोड़ी सिंटैक्टिक शुगर जोड़ी है, जिससे कोड कम लंबा रहता है और यह संभावना भी घट जाती है कि कोई ज़रूरी कॉल छूट जाए।

कुछ मामलों में `using` को [`try/finally`][try-finally] की जगह लेने वाला माना जा सकता है।

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

इस सिंटैक्स की जगह अब यह ज़्यादा छोटा और भरोसेमंद रूप आता है:

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

ध्यान दीजिए कि एक ही लाइन वाले ब्लॉक के सामान्य नियमों का पालन करते हुए कई संसाधनों को एक साथ आसानी से जोड़ा जा सकता है:

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

C# 8 में यह नया रूप जोड़ा गया, जहाँ `using` स्टेटमेंट किसी ब्लॉक के शुरू में आता है:

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

इससे आप एक ही ब्लॉक में कई डिस्पोज़ेबल ऑब्जेक्ट रख सकते हैं और [`try/catch`][try-catch] को ज़्यादा स्वाभाविक तरीके से संभाल सकते हैं:

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

`using` कीवर्ड का इस्तेमाल कैसे किया जा सकता है और किस तरह के टाइप के इंस्टेंस के साथ, इसके नियम [यहाँ][using-statement] विस्तार से दिए गए हैं।

## Java डेवलपर के लिए एक नोट

Java डेवलपर इसे Java 7 में जोड़ी गई [_स्वचालित संसाधन प्रबंधन_][automatic-resource-management] व्यवस्था का समान रूप पहचान सकते हैं। दोनों बहुत मिलते-जुलते हैं। Java का सिंटैक्स `try` को ही नया काम सौंपता है, और उसका यह फ़ायदा है कि वह `catch` ब्लॉकों को C# के `using` से ज़्यादा स्वाभाविक ढंग से जोड़ पाता है।

## संस्करण

ध्यान दीजिए कि `using` का ज़्यादा लचीला रूप, जिसमें उसका अपना सिंटैक्स ब्लॉक नहीं होता, C# 8 में आया। इसलिए आपको देखना पड़ सकता है कि जिस कोडबेस पर आप काम कर रहे हैं, वह C# 8 या उससे नए संस्करण का इस्तेमाल करता है या नहीं।

## संदर्भ
