# परिचय

_स्ट्रिंग_ JavaScript का वह डेटा टाइप है जिसमें टेक्स्ट डेटा रखा जाता है।
किसी अकेले अक्षर के लिए कोई अलग डेटा टाइप नहीं होता।

## स्ट्रिंग बनाना

आप टेक्स्ट को सिंगल कोट या डबल कोट में लपेटकर एक स्ट्रिंग [लिटरल][literal] बनाते हैं।
Exercism पर सिंगल कोट इस्तेमाल किए जाते हैं।

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

टेक्स्ट के कुछ खास अक्षरों से पहले बैकस्लैश `\` लगाना पड़ता है, ज़्यादा जानकारी के लिए [MDN पर एस्केप सीक्वेंस][mdn-escape-sequences] देखिए।

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

सिंगल और डबल कोट के अलावा, आप टेक्स्ट को बैकटिक में लपेटकर भी एक स्ट्रिंग बना सकते हैं।
इस सिंटैक्स में सिंगल या डबल कोट और नई लाइनें भी बिना एस्केप किए शामिल की जा सकती हैं।
इसमें एक्सप्रेशन भी शामिल किए जा सकते हैं। ज़्यादा जानकारी के लिए [टेम्पलेट स्ट्रिंग][mdn-template-strings] देखिए।

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## अक्षरों की सूची के रूप में स्ट्रिंग

किसी स्ट्रिंग को अक्षरों की सूची की तरह देखा जा सकता है, जिसमें पहले अक्षर का इंडेक्स `0` होता है।
स्ट्रिंग का कोई एक अक्षर पाने के लिए आप चौकोर ब्रैकेट और उस अक्षर का इंडेक्स इस्तेमाल कर सकते हैं।
इसके अलावा `charAt` मेथड भी है।

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

`length` प्रॉपर्टी देखकर आप पता कर सकते हैं कि स्ट्रिंग में कितने अक्षर हैं।

```javascript
'cat'.length;
// => 3
```

## जोड़ना और मेथड

स्ट्रिंग जोड़ने का सबसे आसान तरीका जोड़ ऑपरेटर `+` इस्तेमाल करना है।

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

स्ट्रिंग में कई मददगार मेथड होते हैं। पूरी सूची के लिए [MDN के स्ट्रिंग मेथड दस्तावेज़][mdn-string-methods] देखिए।
नीचे दी गई सूची में कुछ आम तौर पर इस्तेमाल होने वाले मेथड दिखाए गए हैं।

- [`toUpperCase`][mdn-to-upper-case] और [`toLowerCase`][mdn-to-lower-case] - सभी अक्षरों का केस बदलना
- [`trim`][mdn-trim] - शुरू और अंत की खाली जगह हटाना
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] और [`endsWith`][mdn-ends-with] - पता लगाना कि कोई दूसरी स्ट्रिंग दी गई स्ट्रिंग का हिस्सा है या नहीं
- [`slice`][mdn-slice] - स्ट्रिंग का एक हिस्सा निकालना

## स्ट्रिंग बदली नहीं जा सकती

ऊपर दिए गए मेथड लगाने से मूल स्ट्रिंग कभी नहीं बदलती। इसके बजाय एक नई स्ट्रिंग बनाकर लौटा दी जाती है।
JavaScript में स्ट्रिंग और दूसरे प्रिमिटिव डेटा टाइप बदले नहीं जा सकते।
इसका यह भी मतलब है कि ऊपर दिखाए गए ब्रैकेट सिंटैक्स से आप किसी इंडेक्स पर कोई दूसरा अक्षर असाइन नहीं कर सकते (जैसे कि आप ऐरे में करते हैं)।

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
