# परिचय

C++ में शर्त वाले स्टेटमेंट दूसरी भाषाओं के शर्त वाले स्टेटमेंट जैसे ही होते हैं।
किसी भी शर्त वाले ऑपरेशन का मूल टाइप `bool` होता है, जिसकी वैल्यू `true` या `false` हो सकती है।
शर्त वाले स्टेटमेंट अक्सर अलग-अलग शर्तें जाँचने के लिए प्रोग्राम के प्रवाह को नियंत्रित करने का काम करते हैं।

एक `if` स्टेटमेंट इस्तेमाल किया जा सकता है, जो अपना कोड तब चलाता है जब उसकी मूल शर्त `true` हो, ऐसे:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

एक से ज़्यादा केस वाली स्थितियों में कई `if` स्टेटमेंट को `else if` और `else` स्टेटमेंट की मदद से एक साथ जोड़ा जा सकता है।

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17 से if स्टेटमेंट में एक छोटा इनिशलाइज़ेशन स्टेटमेंट भी शामिल किया जा सकता है, जिसका इस्तेमाल उस if स्टेटमेंट के लिए एक या अधिक वेरिएबलो को शुरुआती वैल्यू देने में किया जा सकता है।
उदाहरण के लिए:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> ध्यान दें: इनिशलाइज़ेशन में बनाए गए वेरिएबलो का इस्तेमाल if स्टेटमेंट खत्म होने के बाद नहीं किया जा सकता।
