# परिचय

कास्टिंग और टाइप कन्वर्ज़न किसी एक्सप्रेशन को एक डेटा टाइप से दूसरे डेटा टाइप में बदलने के दो अलग तरीके हैं।

किसी एक्सप्रेशन को कास्ट ऑपरेटर `(<type>)` की मदद से दूसरे टाइप में कास्ट किया जा सकता है।

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

अगर टाइप आपस में संगत नहीं हैं, तो `InvalidCastException` का एक इंस्टेंस फेंका जाता है। संख्याओं के मामले में यह बताता है कि जिस टाइप में कास्ट किया जा रहा है, वह कास्ट की गई वैल्यू को नहीं दर्शा सकता। क्लासों के मामले में, एक टाइप को दूसरे से व्युत्पन्न होना चाहिए (यह बात स्ट्रक्ट्स पर भी सीधे लागू होती है)।

_कास्टिंग_ का एक विकल्प `is` ऑपरेटर से किया गया _टाइप कन्वर्ज़न_ है। यह आम तौर पर रेफरेंस और नलएबल टाइपों पर लागू होता है।

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

अगर आपको किसी ऑब्जेक्ट का सटीक टाइप पता करना है, तो `is` थोड़ा ज़्यादा ढीला हो सकता है, क्योंकि यह किसी क्लास के लिए, और उन सभी क्लासों और इंटरफेसों के लिए भी सही लौटाता है जिनसे वह क्लास सीधे या परोक्ष रूप से व्युत्पन्न है। ऐसे मामले में `typeof` और `Object.GetType()` ही हल हैं।

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
