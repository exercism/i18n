# निर्देश

जादूगर बनने की तैयारी कर रही Elyse को कुछ बुनियादी बातों का अभ्यास करना है।
उसके पास कार्डों का एक ढेर है, जिसे वह अपने तरीके से बदलना चाहती है।

चीज़ें थोड़ी आसान बनाने के लिए वह सिर्फ 1 से 10 तक के कार्ड इस्तेमाल करती है, ताकि उसके कार्डों के ढेर को संख्याओं के एक ऐरे से दर्शाया जा सके।
किसी कार्ड की जगह ऐरे के इंडेक्स से मेल खाती है।
यानी जगह 0 पहले कार्ड को दिखाती है, जगह 1 दूसरे कार्ड को, और इसी तरह आगे भी।

~~~~exercism/note
सभी फंक्शन को कार्डों के ऐरे को अपडेट करना चाहिए और फिर बदले हुए ऐरे को लौटाना चाहिए। यह काम करने का एक आम तरीका है, जिसे बिल्डर पैटर्न कहते हैं, और इससे आप फंक्शनों को एक के बाद एक अच्छे से जोड़ सकते हैं।
~~~~

## 1. ढेर से एक कार्ड निकालिए

कार्ड उठाने के लिए दिए गए ढेर में `position` इंडेक्स पर मौजूद कार्ड लौटाइए।

फंक्शन `getCard(at:from:)` बनाइए, जो दो आर्गुमेंट लेता है: `at`, यानी ढेर में कार्ड की जगह, और `from`, यानी कार्डों का ढेर।
फंक्शन को दिए गए ढेर में `index` जगह पर मौजूद कार्ड लौटाना चाहिए।

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. ढेर में कार्ड बदलिए

थोड़ा जादू दिखाइए और दिए गए नए कार्ड से `position` इंडेक्स पर रखे कार्ड को बदल दीजिए।

फंक्शन `setCard(at:in:to)` बनाइए, जो तीन आर्गुमेंट लेता है: `at`, यानी ढेर में कार्ड की जगह; `in`, यानी कार्डों का ढेर; और `to`, यानी वह नया कार्ड जो `index` जगह वाले कार्ड की जगह लेगा।
फंक्शन को ढेर की एक कॉपी लौटानी चाहिए, जिसमें `index` जगह वाला कार्ड नए कार्ड से बदला हुआ हो।
अगर दिया गया `index` ढेर में मान्य इंडेक्स नहीं है, तो मूल ढेर बिना बदले लौटाया जाना चाहिए।

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. ढेर के सबसे ऊपर एक कार्ड डालिए

ढेर के सबसे ऊपर एक नया कार्ड डालकर एक कार्ड प्रकट कीजिए।

फंक्शन `insert(_:atTopOf:)` बनाइए, जो दो आर्गुमेंट लेता है: नया कार्ड जिसे डालना है, और कार्डों का ढेर।
फंक्शन को ढेर की एक कॉपी लौटानी चाहिए, जिसमें दिया गया नया कार्ड ढेर के सबसे ऊपर जोड़ा हुआ हो।

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. ढेर से एक कार्ड हटाइए

दिए गए `position` पर मौजूद कार्ड को ढेर से हटाकर एक कार्ड गायब कीजिए।

फंक्शन `removeCard(at:from:)` बनाइए, जो दो आर्गुमेंट लेता है: `at`, यानी ढेर में कार्ड की जगह, और `from`, यानी कार्डों का ढेर।
फंक्शन को ढेर की एक कॉपी लौटानी चाहिए, जिसमें से `index` जगह वाला कार्ड हटा हुआ हो।
अगर दिया गया `index` ढेर में मान्य इंडेक्स नहीं है, तो मूल ढेर बिना बदले लौटाया जाना चाहिए।

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. ढेर में एक कार्ड डालिए

ढेर में दी गई `position` जगह पर नया कार्ड डालकर एक कार्ड प्रकट कीजिए।

फंक्शन `insert(_:at:from:)` बनाइए, जो तीन आर्गुमेंट लेता है: नया कार्ड जिसे डालना है, वह जगह जहाँ नया कार्ड डालना है, और कार्डों का ढेर।
फंक्शन को ढेर की एक कॉपी लौटानी चाहिए, जिसमें दिया गया नया कार्ड दी गई जगह पर जोड़ा हुआ हो।
अगर दिया गया `index` ढेर में मान्य इंडेक्स नहीं है, तो मूल ढेर बिना बदले लौटाया जाना चाहिए।

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. ढेर का आकार जाँचिए

जाँचिए कि ढेर का आकार `stackSize` के बराबर है या नहीं।

फंक्शन `checkSizeOfStack(_:_:)` बनाइए, जो दो आर्गुमेंट लेता है: `stack`, यानी कार्डों का ढेर, और `stackSize`, यानी ढेर का आकार।
फंक्शन को `true` लौटाना चाहिए अगर ढेर का आकार `stackSize` के बराबर है, और बाकी मामलों में `false` लौटाना चाहिए।

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
