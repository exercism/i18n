# परिचय

Kotlin का `when` एक कंडीशनल एक्सप्रेशन है, जिससे कई विकल्पों में से एक चुना जाता है।
यह Java के `switch` जैसा है, और `if` ... `else if` ... `else` की लंबी श्रृंखला से ज़्यादा लचीला है।

`if` की तरह `when` को भी एक एक्सप्रेशन की तरह इस्तेमाल किया जा सकता है, जो एक वैल्यू देता है।

## वैल्यू का मिलान

`when` को ब्रैकेट में वह वैल्यू दीजिए जिससे मिलान करना है।
हर ब्रांच उस वैल्यू की तुलना करती है, जब तक कोई एक मेल न खा जाए:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- हर ब्रांच `pattern -> result` के रूप में लिखी जाती है।
- ब्रांचें ऊपर से नीचे तक आज़माई जाती हैं, जब तक कोई मेल न मिल जाए।
  सिर्फ पहली ब्रांच ही चलती है।
- ऊपर न दी गई किसी भी वैल्यू के लिए `else` का इस्तेमाल कीजिए (`if` की श्रृंखला में अंतिम `else` की तरह)।

यह [पैटर्न मैचिंग][pattern-matching] जैसा है।
`pattern` वह वैल्यू हो सकता है जिससे मिलान करना है, या टाइप से मिलान के लिए `is` का इस्तेमाल कीजिए:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

या फिर `in` का इस्तेमाल करके देखिए कि वह किसी रेंज, कलेक्शन, स्ट्रिंग या `contains` मेथड वाली किसी भी चीज़ में शामिल है या नहीं:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
आप दूसरे ऑब्जेक्ट के साथ भी `in` का इस्तेमाल कर सकते हैं, बस उसके लिए `contains` [ऑपरेटर एक्सटेंशन फंक्शन][kotlin-operator-overloading] बनाना होगा।
उदाहरण के लिए, [Regex][kotlin-regex] के साथ इसका इस्तेमाल:

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

fun replace(input: String) {
    return when(input) {
        in Regex("""ani*""") -> println("animal")
        in Regex("""fru.*""") -> println("fruit")
        in Regex("""num.*""") -> println("number")
        else -> println("unknown")
    }
}
```

## गार्ड शर्तें

वैल्यू का मिलान करते समय पैटर्न के बाद `if` में अतिरिक्त शर्तें लगाई जा सकती हैं।
इन शर्तों को गार्ड शर्तें कहते हैं।

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

`else if` का भी इस्तेमाल किया जा सकता है।

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## शर्तों का मिलान

दूसरा तरीका यह है कि वैल्यू हटा दी जाए और हर ब्रांच पर बूलियन शर्तें लगाई जाएँ:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

यहाँ भी ब्रांचें ऊपर से नीचे तक जाँची जाती हैं, और सिर्फ वही पहली ब्रांच चलती है जिसकी शर्त `true` हो।

## `when` का एक्सप्रेशन की तरह इस्तेमाल

जब `when` का इस्तेमाल उसके परिणाम के लिए होता है (यानी उसे किसी वेरिएबल में असाइन किया जाता है, किसी फंक्शन से लौटाया जाता है, वगैरह), तो हर संभावित केस कवर करना ज़रूरी है।

- वैल्यू से मिलान करते समय `else` जोड़िए, जब तक कि हर संभावित वैल्यू पहले से संभाली न गई हो (जैसे किसी `Boolean` या `enum` की सारी वैल्यू)।
- शर्तों का मिलान करते समय `else` ब्रांच ज़रूरी है, क्योंकि कंपाइलर यह नहीं जान सकता कि आपकी शर्तें हर केस कवर करती हैं।

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
