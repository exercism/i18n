# निर्देश परिशिष्ट

## प्रतिबंध

Rust की स्टैंडर्ड लाइब्रेरी में पहले से ही एक
[बाइनरी सर्च फंक्शन](https://doc.rust-lang.org/std/primitive.slice.html#method.binary_search) मौजूद है।
इस अभ्यास में आपको इस फंक्शन का इस्तेमाल नहीं करना है। इसके बजाय दूसरे बुनियादी टूल इस्तेमाल कीजिए।

## बोनस अंकों के लिए

क्या आप सारे टेस्ट पास कर पाए और कोड साफ़ रहा? अगर आप चाहें, तो कुछ और चीज़ें भी आज़मा सकते हैं।

- फिलहाल आपका find फंक्शन शायद सिर्फ संख्याओं के स्लाइस पर ही काम करेगा। लेकिन Rust का टाइप सिस्टम इतना लचीला है कि आप ऐसा find फंक्शन बना सकते हैं जो हर उस स्लाइस पर काम करे जिसमें ऐसे एलिमेंट हों जिन्हें क्रम में लगाया जा सके।
- इसके अलावा यह find फंक्शन सिर्फ स्लाइस पर ही नहीं, बल्कि Vec या Array पर भी काम कर सकता है।

बोनस टेस्ट चलाने के लिए `#[ignore]` फ्लैग हटा दीजिए और टेस्ट को `generic` फीचर के साथ चलाइए, इस तरह:

```bash
$ cargo test --features generic
```

इसके बाद सबमिशन पर एक कमेंट में अपने विचार ज़रूर साझा कीजिए। क्या इस प्रयोग से कोड बेहतर बना? खराब? क्या आपने इससे कुछ सीखा?
