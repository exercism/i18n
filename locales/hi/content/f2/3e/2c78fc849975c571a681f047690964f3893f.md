# Python ट्रैक पर इस अभ्यास के नोट्स

- सभी इनपुट संख्याएँ **_ऋणेतर `int`s_** हैं (_यानी शून्य सहित प्राकृतिक संख्याएँ_)।
- फैक्टर की एक `list` देना ज़रूरी है, और उसके एलिमेंट अद्वितीय तथा आरोही क्रम में क्रमबद्ध होते हैं।
