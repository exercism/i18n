# निर्देश

आपको पक्षियों को देखने का बड़ा शौक है और आप यह हिसाब रखते हैं कि आपके बगीचे में कितने पक्षी आए। आम तौर पर पक्षियों की गिनती के लिए आप एक नोटबुक में टैली बनाते हैं, लेकिन अपने डेटा के साथ बेहतर तरीके से काम करने के लिए आपने पिछले कई हफ्तों की पक्षी-गिनती को डिजिटल कर दिया है।

## 1. अब तक गिने गए पक्षियों की कुल संख्या निकालिए

चलिए, डेटा को थोड़ा ऊपर से देखकर उसका विश्लेषण शुरू करते हैं।
पता कीजिए कि जब से आपने यह हिसाब रखना शुरू किया, तब से आपने कुल कितने पक्षी गिने।

एक फंक्शन `totalBirdCount` बनाइए जो `Int` की एक ऐरे लेता है, जिसमें हर दिन की पक्षी-गिनती दी गई हो।
यह फंक्शन उन सभी पक्षियों की कुल संख्या लौटाता है जो आपने गिने।

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. किसी खास हफ्ते में आने वाले पक्षियों की संख्या निकालिए

अब जब आपको अपनी पक्षी-गिनती के आंकड़ों का अंदाज़ा हो गया है, तो आप और बारीक विश्लेषण करना चाहते हैं।

एक फंक्शन `birdsInWeek` बनाइए जो हर दिन की पक्षी-गिनती की एक ऐरे और हफ्ते की संख्या लेता है।

यह उस खास हफ्ते में आपके गिने गए पक्षियों की कुल संख्या लौटाता है।
आप मान सकते हैं कि हर हफ्ते का हिसाब पूरा रखा जाता है।

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. गिनती की एक गलती ठीक कीजिए

आपको एहसास हुआ कि जब-जब आप पक्षियों का हिसाब रखने की कोशिश कर रहे थे, तब एक पक्षी बगीचे के एक दूर के कोने में छिपा हुआ था।

आपने पता लगाया कि यह पक्षी हमेशा हर दूसरे दिन आपके बगीचे में रहता था।

आपको ठीक-ठीक पता नहीं है कि उन दिनों के बीच यह कहाँ रहता था, लेकिन यह तय है कि आपके बगीचे में नहीं।

पक्षी देखने का आपका अनुभव यह भी बताता है कि जिस पहले दिन की आपने अपनी सूची में गिनती की, उस दिन यह पक्षी आपके बगीचे में था।

इस नई जानकारी के आधार पर एक फंक्शन `fixBirdCountLog` लिखिए जो आर्गुमेंट के रूप में हर दिन गिने गए पक्षियों की एक ऐरे लेता है और गिनती की गलती सुधारने के बाद वह ऐरे लौटाता है।

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
