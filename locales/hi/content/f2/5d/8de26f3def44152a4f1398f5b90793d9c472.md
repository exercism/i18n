# परिचय

एक एल्जेब्रिक डेटा टाइप (एडीटी) निश्चित संख्या के नामित केसों को दर्शाता है।
एडीटी की प्रत्येक वैल्यू इन नामित केसों में से ठीक एक केस से मेल खाती है।

एक एडीटी को `data` कीवर्ड से परिभाषित किया जाता है, और उसके केस पाइप (`|`) अक्षरों से अलग किए जाते हैं।
यदि किसी भी केस के साथ डेटा जुड़ा न हो, तो यह एडीटी वैसा ही होता है जिसे अन्य भाषाएँ आमतौर पर _एन्यूमरेशन_ (या _एनम_) कहती हैं।

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

एडीटी के प्रत्येक केस के साथ वैकल्पिक रूप से डेटा जुड़ा हो सकता है, और अलग-अलग केसों के साथ अलग-अलग प्रकार का डेटा जुड़ा हो सकता है।
जब किसी केस के साथ डेटा जुड़ा हो, तो एक कंस्ट्रक्टर आवश्यक होता है।

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

किसी विशेष केस के लिए वैल्यू उसका नाम लिखकर बनाई जा सकती है (जैसे, `NInt 22`)।
चूँकि केसों के नाम केवल कंस्ट्रक्टर फंक्शन होते हैं, इसलिए जुड़ा हुआ डेटा एक सामान्य फंक्शन आर्गुमेंट की तरह दिया जा सकता है।

एडीटी में _स्ट्रक्चरल इक्वालिटी_ होती है, जिसका अर्थ है कि एक ही केस की और समान (वैकल्पिक) डेटा वाली दो वैल्यू बराबर होती हैं।

हालाँकि एडीटी के साथ काम करने के लिए `if/else` एक्सप्रेशन इस्तेमाल किए जा सकते हैं, लेकिन इनके साथ काम करने का सुझाया गया तरीका _case_ स्टेटमेंट का उपयोग करके पैटर्न मैचिंग है:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
