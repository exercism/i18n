# इंस्टॉलेशन

## Clojure CLI इंस्टॉल करना
Clojure कमांड लाइन टूल्स उपलब्ध कराता है, जिनसे आप Clojure REPL शुरू कर सकते हैं, Clojure और Java की लाइब्रेरी इस्तेमाल कर सकते हैं, और Clojure प्रोग्राम चला सकते हैं।

अगर आपको Java इंस्टॉल करना है, तो हमारा सुझाव है कि [Adoptium Temurin 17](https://adoptium.net/) इंस्टॉल कीजिए।

### Linux
ध्यान रखिए कि ये डिपेंडेंसी इंस्टॉल हों: `bash`, `curl`, `rlwrap` और `Java`.
आप Clojure को इन दो तरीकों में से किसी एक से इंस्टॉल कर सकते हैं:

1. LinuxBrew - इसके लिए [Homebrew](https://brew.sh/) ज़रूरी है

```bash
brew install clojure/tools/clojure
```

2. स्क्रिप्ट इंस्टॉलर

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Mac OS X के लिए Homebrew
[clojure/tools](https://github.com/clojure/homebrew-tools) टैप से brew की मदद से कमांड लाइन टूल्स इंस्टॉल कीजिए:

```bash
brew install clojure/tools/clojure
```

#### Java

Java का कोई भी डिस्ट्रिब्यूशन चलेगा। ज़रूरत पड़ने पर आप brew की मदद से Temurin इंस्टॉल कर सकते हैं:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

हाल ही में Windows पर Clojure में काफी सुधार हुआ है। पहले हम WSL2 इस्तेमाल करने की सलाह देते थे, जो बहुत अच्छी तरह काम करता है, लेकिन अब एक PowerShell इंस्टॉलर भी मौजूद है। फिलहाल Windows पर Clojure अल्फा अवस्था में है, ज्ञात समस्याओं के लिए [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) देखिए।

ध्यान रखिए कि Java इंस्टॉल हो और `JAVA_HOME` एनवायरनमेंट वेरिएबल सेट हो, फिर यह चलाइए:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Windows पर Clojure इंस्टॉल करने का एक और तरीका [Scoop](https://scoop.sh/) पैकेज मैनेजर है। Scoop इंस्टॉल करने के लिए PowerShell खोलिए और ये दोनों कमांड एक के बाद एक चलाइए:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Scoop की मदद से Clojure इंस्टॉल करने के लिए पहले दो ज़रूरी बकेट जोड़ने होंगे:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

अब हम Java और Clojure इंस्टॉल करने के लिए तैयार हैं। नीचे दिए गए कमांड चलाइए:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

ऊपर दिए गए चरण सफलतापूर्वक पूरे करने के बाद आप Clojure को इस तरह चला पाएँगे:

```sh
clj
```

## Leiningen इंस्टॉल करना (वैकल्पिक)

हालाँकि अब यह ज़रूरी नहीं रहा, फिर भी हम पूरी सुविधाओं वाले प्रोजेक्ट मैनेजमेंट टूल [Leiningen](https://leiningen.org/) का समर्थन करते हैं।
यह सुविधाजनक टेस्टिंग, बिल्ड और बेहतर REPL जैसे कई उपयोगी काम देता है।

1. [lein script](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) या [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows) डाउनलोड कीजिए
2. इसे अपने `$PATH` पर उस जगह रखिए जहाँ आपका शेल इसे ढूँढ सके (जैसे `/usr/local/bin/`)
3. इसे एक्ज़ीक्यूटेबल बनाइए (`sudo chmod a+x /usr/local/bin/lein`)
4. `lein` चलाइए।
