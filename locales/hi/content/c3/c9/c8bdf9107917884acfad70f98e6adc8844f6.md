# परिचय

Flags एट्रिब्यूट की मदद से डिस्क्रिमिनेटेड यूनियन में परिभाषित वैल्यू को बिट पोज़िशन (यानी फ्लैग) के रूप में दर्शाया जा सकता है।
फ्लैग होने के नाते ऐसी वैल्यू को आपस में जोड़ा जा सकता है, और इस तरह एक ही वैल्यू में कई बूलियन शर्तें दर्शाई जा सकती हैं।

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

किसी फ्लैग को सेट करने के लिए बिटवाइज़ OR ऑपरेटर (`|||`) इस्तेमाल किया जा सकता है; और किसी फ्लैग को अनसेट करने के लिए बिटवाइज़ AND ऑपरेटर (`&&&`) तथा बिटवाइज़ नेगेशन ऑपरेटर (`~~~`) को मिलाकर इस्तेमाल किया जा सकता है।
किसी फ्लैग की स्थिति जाँचने का काम बिटवाइज़ AND ऑपरेटर से भी हो सकता है, और `HasFlag()` मेथड से भी।

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

F# भाषा में उपलब्ध सारे बिटवाइज़ ऑपरेटरों की पूरी सूची के लिए [बिटवाइज़ ऑपरेटरों का सारांश][bitwise-operators] देखिए।

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
