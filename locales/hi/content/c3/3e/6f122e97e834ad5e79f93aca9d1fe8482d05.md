# प्लेसहोल्डर

## `jq` के लिए सुझाव

यह अभ्यास एक इनपुट ऑब्जेक्ट लेकर उसे एक नए ऑब्जेक्ट में बदलने के बारे में है।
कुछ बिल्ट-इन फंक्शन हैं जो इसमें मदद कर सकते हैं:

- [`to_entries`][x_entries]
  - यह फंक्शन इनपुट के रूप में एक ऑब्जेक्ट लेता है
  - यह एक _ऐरे_ देता है। ऐरे का हर एलिमेंट एक ऑब्जेक्ट होता है: `{"key": "K", "value": V}`
    - हर `K` इनपुट ऑब्जेक्ट में मौजूद एक की है
    - हर `V` उस `K` से जुड़ी वैल्यू है।
- [`from_entries`][x_entries]
  - इसका उल्टा काम
  - `{"key": K, "value": V}` ऑब्जेक्टों का एक ऐरे लेता है और उससे एक ऑब्जेक्ट बनाता है

एक उदाहरण:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

तो आउटपुट मिलता है:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
