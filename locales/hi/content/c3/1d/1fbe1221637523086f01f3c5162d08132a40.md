# परिचय

Lambda क्लास Haxe के साथ फंक्शनल-स्टाइल प्रोग्रामिंग करने के लिए फंक्शनल मेथड का संग्रह है। यह हमें एक पूरे Iterable पर एक साथ काम करने देती है। यह अक्सर लूप करने वाले तरीकों से बेहतर होती है, क्योंकि इसमें गलती की संभावना कम होती है और इसे पढ़ना आसान होता है। सुविधा के लिए Array और List क्लास में Lambda क्लास के कुछ अक्सर इस्तेमाल होने वाले मेथड शामिल हैं।

`Lambda` क्लास के कुछ फंक्शन इस प्रकार हैं:

- `Lambda.array`, `Lambda.list` Iterable को Array या List में बदलते हैं। यह हमेशा एक नया इंस्टेंस लौटाते हैं।
- `Lambda.count` एलिमेंट की संख्या गिनता है। यदि Iterable एक Array या List है, तो उसकी length प्रॉपर्टी का इस्तेमाल करना तेज़ होता है।
- `Lambda.has` बताता है कि दिया गया एलिमेंट Iterable में मौजूद है या नहीं।
- `Lambda.indexOf` दिए गए एलिमेंट का इंडेक्स पता लगाता है।
- `Lambda.find` दिए गए खोज फंक्शन के आधार पर पहला एलिमेंट ढूँढता है।
- `Lambda.concat` दो Iterable को मिलाकर एक नई List लौटाता है।
- `Lambda.filter` ऐसे एलिमेंट ढूँढता है जो एक मानदंड पूरा करते हैं, और एक नई List लौटाता है।

कुछ फंक्शन दिखाने वाला एक उदाहरण:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
