# टेस्ट

## संक्षेप में
 
- प्रॉब्लम डायरेक्टरी में जाइए (जैसे `~/Exercism/hello-world`)।
- टर्मिनल में एक `jconsole` सेशन शुरू कीजिए।
- अपने हल की फाइल लोड कीजिए (जैसे `load 'hello-world.ijs'`)।
- `load  'general/unittest'` टाइप करके यूनिट टेस्ट फ्रेमवर्क लोड कीजिए।
- `unittest 'test.ijs'` टाइप करके अपने हल की जाँच कीजिए।
<br></br>
- इसके अलावा, आप टेस्ट को एक ही पंक्ति में ऐसे भी चला सकते हैं: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Jconsole सेशन

ट्रैक के टेस्ट जितने आसान हो सकें, उतने आसान रखने की कोशिश की गई है।
अगर आप कोई अभ्यास कर रहे हैं, मान लीजिए `hamming.ijs`, तो काम इस तरह आगे बढ़ना चाहिए।
`hamming.ijs` को संपादित कीजिए और उसमें अपना हल लिखिए।
इसे इंटरैक्टिव तरीके से बनाते हुए आगे बढ़ने के लिए सबसे पहले यह टाइप कीजिए।

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

फिर J कंसोल के अंदर से यह टाइप करके दोबारा लोड कीजिए

```j
load 'hamming.ijs'
```

इसके बाद यूनिट टेस्ट फ्रेमवर्क लोड कीजिए, इसके लिए यह टाइप कीजिए

```j
load 'general/unittest'
```

अपना हल लोड करने के बाद टेस्ट चलाने के लिए यह टाइप कीजिए

```j
unittest 'test.ijs'
```

और फिर परिणाम देखिए।

## कमांड लाइन

आप टर्मिनल में -js फ्लैग का उपयोग करके एक ही पंक्ति के कमांड से टेस्ट चला सकते हैं:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
यहाँ हर आर्गुमेंट एक ऐसे कमांड को दर्शाता है जो क्रम से चलाया जाएगा।
