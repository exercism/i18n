# पूर्णांक

पूर्णांक पूरी संख्याएँ होती हैं, जो `{..., -2, -1, 0, 1, 2, ...}` समुच्चय में आती हैं।
पूर्णांक की अधिकतम और न्यूनतम वैल्यू उस सिस्टम से तय होती है जिस पर PHP चलता है।
आम तौर पर आधुनिक सिस्टमों में पूर्णांक एक 64-बिट वैल्यू होता है। इसका मतलब है कि यह `-9_223_372_036_854_775_808` से लेकर `9_223_372_036_854_775_807` तक की संख्याएँ दर्शा सकता है, और ये दोनों सीमाएँ भी इसमें शामिल हैं।

```php
<?php

$a = 1234;
$a = 1_234_567;
```

आप पूर्णांक के लिटरल मान 10 के अलावा किसी दूसरे आधार में भी लिख सकते हैं, बस शुरू में उस आधार को लिखिए:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> यह PHP के [डॉक्युमेंटेशन][syntax] से लिया गया है।

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
