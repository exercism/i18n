# टेस्ट

## टेस्ट चलाना

1. अभ्यास डाउनलोड कीजिए:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. अभ्यास की डायरेक्टरी में जाइए:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. टेस्ट चलाइए:

    ```bash
    $ ./gradlew test
    ```

अधिकांश अभ्यासों में डिफॉल्ट रूप से सिर्फ पहला टेस्ट ही चलता है।  
बाकी टेस्टों को छोड़ने के लिए उन पर `@Ignore` लगा होता है।  
जैसे-जैसे आप हर टेस्ट हल करते हैं, आगे बढ़ने के लिए अगले टेस्ट से `@Ignore` हटाइए।

यह टेस्ट-ड्रिवन डेवलपमेंट (या छोटे में TDD) में आम बात है।
इसे इस बात को पक्का करने के लिए इस्तेमाल किया जाता है कि आप एक समय में एक ही समस्या पर काम करें।
