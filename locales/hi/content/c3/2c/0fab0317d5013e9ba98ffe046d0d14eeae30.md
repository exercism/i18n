# परिचय

F# का `char` टाइप टेक्स्ट के सबसे छोटे हिस्सों को दर्शाने वाली 16 बिट की वैल्यू होती है। यह डिफ़ॉल्ट रूप से अपरिवर्तनीय होती है।

`char` को सिंगल कोट्स के साथ लिटरल के रूप में परिभाषित किया जा सकता है:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

स्ट्रिंग अक्षरों का एक क्रम होती है।

किसी स्ट्रिंग से एक-एक `char` को (शून्य से शुरू होने वाली) इंडेक्सिंग की मदद से निकाला जा सकता है:

```fsharp
"Exercism"[4] //  =>  'c'
```

स्ट्रिंग पर इटरेशन करने पर हर बार एक `char` मिलता है।

अगला उदाहरण सुविधा के लिए एक हायर-ऑर्डर फंक्शन और एक अनाम फंक्शन का उपयोग करता है।
इन्हें आगे सिलेबस में ठीक से समझाया जाएगा, लेकिन अभी के लिए ये स्ट्रिंग के अक्षरों पर लूप लिखने का एक संक्षिप्त तरीका भर हैं।

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

जैसा ऊपर दिखाया गया है, किसी `char` को उसकी `int` वैल्यू में बदला जा सकता है।
यह दूसरी लिपियों के लिए भी काम करता है (*कम से कम कुछ मामलों में*):

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

अक्षरों की तुलना करते समय अंदरूनी Int16 का उपयोग होता है:

```fsharp
'A' < 'D'  // =>  true
```

साथ ही, किसी `int` को `char` में बदला जा सकता है:

```fsharp
char 77  // => 'M'
```

`System.Char` लाइब्रेरी में वे सारे मेथड मौजूद हैं जो एक .NET भाषा से अपेक्षित होते हैं, जैसे अपरकेस और लोअरकेस में बदलाव:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
