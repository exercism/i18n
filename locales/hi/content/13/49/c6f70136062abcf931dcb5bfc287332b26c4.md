# बूलियन

Haskell में [`Bool`][bools] नाम का एक टाइप होता है।
यह `True` और `False` का एन्यूमरेशन है।

## तार्किक ऑपरेटर

Haskell में तीन तार्किक ऑपरेटर हैं (`not`, `||`, `&&`)। ये बूलियन को मिलाकर ऐसे एक्सप्रेशन बनाते हैं जिनका परिणाम अलग-अलग होता है।

### And(`&&`)

Haskell में [_and_ ऑपरेटर][and] को `&&` से दर्शाया जाता है। अगर दोनों वैल्यू `True` हों, तो यह `True` लौटाता है; वरना यह `False` लौटाता है।
_and_ ऑपरेटर इस्तेमाल करते समय एक बूलियन `&&` के दाईं ओर रखा जाता है और दूसरा बाईं ओर।

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Or(`||`)

Haskell में [_or_ ऑपरेटर][or] को `||` से दर्शाया जाता है। अगर दी गई वैल्यू में से **कम से कम एक** `True` हो, तो यह `True` लौटाता है।
अगर दोनों वैल्यू `False` हों, तो यह `False` लौटाता है।
_or_ ऑपरेटर इस्तेमाल करते समय एक बूलियन `||` के दाईं ओर रखा जाना चाहिए और दूसरा बाईं ओर।

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Not(`not`)

Haskell में _not_ ऑपरेटर को `not` से दर्शाया जाता है। अगर दिया गया बूलियन `False` है, तो यह `True` लौटाता है, और अगर `True` दिया गया है, तो यह `False` लौटाता है।
_not_ ऑपरेटर इस्तेमाल करते समय एक बूलियन को ऑपरेटर (`not`) के बाद रखा जाना चाहिए।

```haskell
not True
-- -> False

not False
-- -> True
```

## ब्रैकेट का उपयोग (`()`)

बूलियन के साथ काम करते समय आप ब्रैकेट लगाकर यह तय कर सकते हैं कि पहले किन बूलियन का मूल्यांकन होगा।
ब्रैकेट का उपयोग कैसे किया जाता है, इसके आधार पर परिणाम अलग हो सकता है।
Haskell में ब्रैकेट के अंदर लिखी चीज़ का मूल्यांकन सबसे पहले होता है।

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

चूँकि ब्रैकेट के अंदर लिखी चीज़ का मूल्यांकन पहले होता है, इसलिए नीचे दिए उदाहरण में _not_ ऑपरेटर ब्रैकेट के अंदर वाले एक्सप्रेशन पर लागू होगा।

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
आपको ब्रैकेट का उपयोग तभी करना चाहिए जब उनसे परिणाम पर असर पड़ता हो; वरना उन्हें हटा देना चाहिए।
~~~~
