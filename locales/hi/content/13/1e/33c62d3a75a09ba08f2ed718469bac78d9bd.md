# इंस्टॉलेशन

C भाषा के ट्रैक के लिए ज़रूरी है कि आपके सिस्टम पर ये सॉफ्टवेयर पहले से मौजूद हों:

* एक आधुनिक C कंपाइलर
* Make बिल्ड टूल

Apple का Xcode IDE कंपाइलर और नेटिव बिल्ड सिस्टम, दोनों को एक ही IDE (इंटीग्रेटेड डेवलपमेंट एनवायरनमेंट) में जोड़ देता है।
Linux वातावरण में कंपाइलर और नेटिव बिल्ड सिस्टम आम तौर पर अलग-अलग कमांड-लाइन टूल के रूप में मिलते हैं।

## Linux

Linux पर कंपाइलर के लिए आपको gcc या clang चाहिए, और नेटिव बिल्ड के लिए `make` चाहिए।
Make ज़्यादातर unix सिस्टमों पर पहले से इंस्टॉल होता है, लेकिन आम तौर पर आपके पैकेज मैनेजर से भी मिल जाता है।
Debian और Ubuntu आधारित डिस्ट्रीब्यूशन पर जो कुछ भी आपको चाहिए, वह पहले से न हो तो `sudo apt-get install build-essential` से इंस्टॉल कर सकते हैं।

## MacOS

MacOS पर आप gcc या clang, [Homebrew][] की मदद से `brew install gcc` या `brew install llvm` से इंस्टॉल कर सकते हैं।

## Windows

Windows 10 पर हमारा सुझाव है कि आप [Windows Subsystem for Linux][] इस्तेमाल कीजिए और ऊपर दिए गए Linux वाले निर्देशों का पालन कीजिए।

अगर आप Windows का कोई पुराना वर्ज़न इस्तेमाल कर रहे हैं, या आपके पास WSL Bash उपलब्ध नहीं है, तो आप [MSYS][] या [mingw-w64][] इस्तेमाल कर सकते हैं।

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
