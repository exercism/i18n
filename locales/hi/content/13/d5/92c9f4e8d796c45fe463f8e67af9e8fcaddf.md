# परिचय

## हैश टेबल

Common Lisp में हैश टेबल एसोसिएटिव डेटा संग्रहीत करने वाली डेटा संरचनाएँ हैं।
ये की (जो कोई भी ऑब्जेक्ट हो सकती हैं) को वैल्यू (जो कोई भी ऑब्जेक्ट हो सकती हैं) से जोड़ती हैं।
अन्य भाषाएँ इस कॉन्सेप्ट को मैप, डिक्शनरी या हैश कह सकती हैं।

### हैश टेबल बनाना

हैश टेबल बनाने के लिए आप `make-hash-table` फंक्शन इस्तेमाल कर सकते हैं।

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(ध्यान दीजिए कि हैश टेबल का छपा हुआ रूप इम्प्लीमेंटेशन पर निर्भर करता है, इसलिए आपके REPL में यह अलग दिख सकता है।)

### की के ज़रिए वैल्यू निकालना

हैश टेबल से किसी की के ज़रिए वैल्यू निकालने के लिए आप `gethash` फंक्शन इस्तेमाल करते हैं:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` [एक से अधिक वैल्यू][concept-multiple-values] लौटाता है, जिन्हें किसी अन्य कॉन्सेप्ट में समझाया जाएगा।

### वैल्यू डालना

हैश टेबल में वैल्यू डालने के लिए आप `setf` का `gethash` के साथ इस तरह इस्तेमाल करते हैं:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

यह हैश टेबल `*hash-table*` में की `:foo` से जुड़ी वैल्यू को `:bar` में बदल देगा।
यह वैल्यू लौटाता है।

`setf` का उपयोग किसी अन्य कॉन्सेप्ट में समझाया जाएगा।
