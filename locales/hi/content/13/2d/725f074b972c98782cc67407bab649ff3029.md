# परिचय

## बिट मैनिपुलेशन

Java में `byte`, `short`, `int`, `long` या `char` के बिट्स बदलने के लिए ऑपरेटर होते हैं।

### शिफ्ट ऑपरेटर

बिट्स को बाईं ओर शिफ्ट करने के लिए `<<` का और दाईं ओर शिफ्ट करने के लिए `>>` का इस्तेमाल कीजिए।

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

`<<` ऑपरेटर दाईं ओर हमेशा 0 डालता है।
लेकिन `>>` सबसे बाईं बिट के जैसी ही बिट डालता है (संख्या ऋणात्मक हो तो 1, धनात्मक हो तो 0)।

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

दाईं ओर शिफ्ट करते समय अगर 0 डालने हों, तो इसके बजाय `>>>` का इस्तेमाल कीजिए।

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### बिटवाइज़ ऑपरेशन

#### बिटवाइज़ AND

बिटवाइज़ AND (`&`) ऑपरेटर दो वैल्यू लेता है और हर बिट पर AND करता है।
यह पहली वैल्यू की हर बिट की तुलना दूसरी वैल्यू की उसी जगह वाली बिट से करता है।
अगर दोनों 1 हैं, तो परिणाम की बिट 1 होती है।
वरना परिणाम की बिट 0 होती है।

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### बिटवाइज़ OR

बिटवाइज़ OR (`|`) ऑपरेटर दो वैल्यू लेता है और हर बिट पर OR करता है।
यह पहली वैल्यू की हर बिट की तुलना दूसरी वैल्यू की उसी जगह वाली बिट से करता है।
अगर इनमें से कोई भी एक बिट 1 है, तो परिणाम की बिट 1 होती है।
वरना 0 होती है।

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### बिटवाइज़ XOR

बिटवाइज़ XOR ऑपरेटर (`^`) दो वैल्यू पर बिटवाइज़ XOR करता है।
बिटवाइज़ AND और बिटवाइज़ OR ऑपरेटर की तरह यह भी पहली वैल्यू की हर बिट की तुलना दूसरी वैल्यू की उसी जगह वाली बिट से करता है।
अगर इनमें से सिर्फ एक 1 है, तो परिणाम की बिट 1 होती है।
वरना 0 होती है।

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### बिटवाइज़ NOT(`~`)

अंत में, बिटवाइज़ NOT ऑपरेटर (`~`) हर बिट को उलट देता है।
पहले वाले ऑपरेटरों से अलग, यह एक यूनरी ऑपरेटर है, जो सिर्फ एक वैल्यू पर काम करता है।

```java
~0b0110_0101;
// # => 0b1001_1010
```
