# निर्देश

आपके नेटबॉल क्लब को हर राउंड के बाद अपनी अंक तालिका निकालनी होती है।

चारों कार्य `NETBALL_LADDER` क्लास में लिखने हैं।

## 1. अंक तालिका के अंक

जीत पर 4 अंक मिलते हैं और ड्रॉ पर 2। हार पर कोई अंक नहीं मिलता।

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. गोल अंतर

किए गए गोल में से खाए गोल घटाइए। यह ऋणात्मक भी हो सकता है।

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. खेले गए पूरे क्वार्टर

एक क्वार्टर 15 मिनट का होता है। मिनटों की एक संख्या दी हो, तो वह कितने पूरे क्वार्टर होंगे?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. क्वार्टर में बीते मिनट

उतने ही मिनट दिए हों, तो वर्तमान क्वार्टर में कितने मिनट बीत चुके हैं?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
