# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जिसका प्रारूप इस तरह होता है: `"[<LEVEL>]: <MESSAGE>"`.

लॉग लेवल तीन तरह के होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके सामने तीन काम हैं। हर काम में एक लॉग लाइन दी जाएगी और आपको उस पर कुछ करना होगा।

## 1. लॉग लाइन से संदेश निकालिए

लॉग लाइन का संदेश लौटाने के लिए `message()` फंक्शन बनाइए:

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

आगे या पीछे जो भी खाली जगह हो, वह हटा दी जानी चाहिए:

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

लॉग लाइन का लॉग लेवल लौटाने के लिए `logLevel()` फंक्शन बनाइए। यह लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. लॉग लाइन का प्रारूप बदलिए

`reformat()` फंक्शन बनाइए, जो लॉग लाइन का प्रारूप बदल देता है। यह संदेश को पहले रखता है और उसके बाद लॉग लेवल को गोल ब्रैकेट में रखता है:

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
