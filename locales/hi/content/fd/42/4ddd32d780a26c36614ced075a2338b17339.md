# निर्देश

आप [Numberphile Youtube चैनल](https://www.youtube.com/watch?v=PeUbRXnbmms) के बहुत बड़े प्रशंसक हैं और आपने अभी-अभी _लुकास संख्या अनुक्रम_ के बारे में एक मज़ेदार वीडियो देखा है। आप यह अनुक्रम Elixir की मदद से बनाना चाहते हैं।

अपना फंक्शन बनाते समय आप _लेज़ी इवैल्युएशन_ का इस्तेमाल करना चाहते हैं, ताकि आप जितनी चाहें उतनी संख्याएँ बना सकें, मगर सिर्फ तब जब आपको उनकी ज़रूरत हो। इसलिए आप स्ट्रीम इस्तेमाल करने का फैसला करते हैं।

## 1. गलत आर्गुमेंट पकड़िए

अगर अनुक्रम बनाने के लिए कोई ऐसी वैल्यू दी जाए जो पूर्णांक न हो, या 1 से छोटा पूर्णांक हो, तो एरर पैदा करने के लिए एक गार्ड क्लॉज़ जोड़िए। इसे पहले चरण में ही कर लेने से आगे के चरणों में अनंत रिकर्शन के बग नहीं आएँगे।

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. बेस केस बनाइए

आप जानते हैं कि इस अनुक्रम की शुरुआत में दो संख्याएँ ऐसी हैं जो एक ही नियम का पालन नहीं करतीं। इन संख्याओं को लौटाने के लिए दो बेस केस क्लॉज़ लिखिए:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. सामान्यीकृत केस बनाइए

2 से लंबे किसी भी अनुक्रम में अगली संख्या पाने के लिए पिछली दो संख्याओं को जोड़ना पड़ता है, और यही क्रम आगे भी चलता रहता है। अब सामान्यीकृत केस लिखिए।

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
