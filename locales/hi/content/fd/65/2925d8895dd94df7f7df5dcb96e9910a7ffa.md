# परिचय

सीक्वेंस से जुड़े सबसे उपयोगी शब्द अपने इनपुट में से एक के रूप में एक *कोटेशन* लेते हैं और उसी की मदद से ऑपरेशन चलाते हैं:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (`sequences` में भी है) एक कोटेशन को पूरे सीक्वेंस पर लागू करता है और एक ही बार में परिणामों को जोड़ देता है। इसी पैटर्न से `sort-by` ([`sorting`][sorting] में) और `minimum-by` / `maximum-by` (`sequences` में) भी काम करते हैं।

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
