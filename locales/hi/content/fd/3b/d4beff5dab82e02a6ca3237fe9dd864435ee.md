# टेस्ट

अभ्यास डायरेक्टरी के अंदर से टेस्ट चलाने के लिए यह कमांड चलाइए:

```sh
odin test .
```

टेस्ट चलाते समय Odin आपके कोड की "vet" कर सकता है: वह ऐसी चीज़ें ढूँढ सकता है, जैसे बिना इस्तेमाल किए गए इम्पोर्ट और वेरिएबलो। अपने टेस्ट इस तरह चलाइए:

```sh
odin test . -vet
```

और विकल्पों के लिए `odin test -help` देखिए।
