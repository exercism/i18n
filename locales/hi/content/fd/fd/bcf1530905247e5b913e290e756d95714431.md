# परिचय

एक *हीप* एक ऐसा संग्रह है जिसे हमेशा अपने सबसे छोटे एलिमेंट का पता रहता है, और जिससे आप उस एलिमेंट को जल्दी हटा सकते हैं। यह *प्राथमिकता कतार* बनाने का सबसे स्वाभाविक तरीका है। हीप [`heaps`][heaps] वोकैबुलरी में मिलते हैं।

`<min-heap>` एक खाली हीप बनाता है, जिसमें से सबसे छोटी की पहले निकलती है, और `<max-heap>` इसका उल्टा रूप है। हर एलिमेंट एक *वैल्यू* है जो एक *की* के नीचे रखी जाती है, और वही की प्राथमिकता होती है:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

हीप *परिवर्तनशील* होता है, यानी `heap-push` उसे वहीं बदल देता है। `heap-peek` सबसे आगे वाली वैल्यू और की को बिना हटाए लौटाता है। `heap-pop` उन्हें हटाकर लौटाता है, और `heap-pop-all` पूरे हीप को खाली करके उसके सारे `{ key value }` जोड़े प्राथमिकता के क्रम में एक एसोसिएशन लिस्ट के रूप में लौटा देता है:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
