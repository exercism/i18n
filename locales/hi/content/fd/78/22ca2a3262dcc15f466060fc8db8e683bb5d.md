# परिचय

Swift में ऐसे स्टेटमेंट का एक समूह है जिनका उपयोग लूप के सामान्य कंट्रोल फ्लो को बदलने के लिए किया जा सकता है। इन्हें कंट्रोल ट्रांसफर स्टेटमेंट कहा जाता है। आप `return` पहले ही देख चुके हैं; यह कॉन्सेप्ट कुछ और स्टेटमेंट से परिचित कराएगा, जिनमें `continue`, `break` और लेबल शामिल हैं। इस कॉन्सेप्ट में हम `fallthrough` को नहीं समझाएँगे, लेकिन इसके बारे में आप [Swift पुस्तक][fallthrough] में पढ़ सकते हैं।

## Continue

कभी-कभी लूप के मौजूदा इटरेशन के बाकी स्टेटमेंट पूरे किए बिना सीधे अगले इटरेशन पर चले जाना ज़रूरी होता है। इसके लिए `continue` कीवर्ड का उपयोग किया जा सकता है। जब `continue` चलाया जाता है, तो लूप यह देखने के लिए अगली जाँच पर चला जाता है कि लूप का अगला इटरेशन चलाया जा सकता है या नहीं, यानी while और repeat-while लूप में `while` की जाँच, या for-in लूप में यह जाँच कि सीक्वेंस में कोई और एलिमेंट है या नहीं।

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

लूप से समय से पहले बाहर निकलने के लिए `break` का उपयोग किया जाता है। जब `break` चलाया जाता है, तो लूप तुरंत खत्म हो जाता है और प्रोग्राम लूप के बाद वाले पहले स्टेटमेंट से आगे बढ़ता है।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## लेबल

जब लूप नेस्टेड होते हैं, तो कभी-कभी ऐसा चाहते हैं कि `break` या `continue` का उपयोग करके उन बाहरी लूपों से बाहर निकलें या उन्हें फिर से शुरू करें जिनके अंदर यह `break` या `continue` लिखा गया है। ऐसी स्थितियों में लेबल का उपयोग करके बताया जा सकता है कि किस लूप से बाहर निकलना है या किसे फिर से शुरू करना है। लूप को लेबल देने के लिए उस लूप को शुरू करने वाले `while`, `repeat` या `for` से पहले एक नाम और उसके बाद कोलन लगाया जाता है।

इस तरह लेबल इस्तेमाल करने का असर देखने के लिए इस लूप को देखिए।

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
