# परिचय

Go में स्थिरांक एक सरल, न बदलने वाली वैल्यू होती है, जिसे `const` कीवर्ड के साथ किसी नाम को असाइन किया जाता है:

```go
const myWebsite = "Exercism"
```

ऐसे स्थिरांक का कोई टाइप नहीं होता, लेकिन जब टाइप आवश्यक हो जाता है, जैसे कि जब उन्हें किसी मेथड को पास किया जाता है, तो उनकी सिंटैक्स के आधार पर उन्हें एक डिफ़ॉल्ट टाइप दिया जाता है।
टाइप वाले स्थिरांक बनाने के लिए स्थिरांक में साफ़-साफ़ टाइप जोड़ा जा सकता है:

```go
const myWebsite string = "Exercism"
```

Go में कुछ अन्य भाषाओं की तरह एनम नहीं होते, लेकिन इसमें `iota` नाम का एक पहले से घोषित आइडेंटिफ़ायर होता है, जिसका उपयोग सूचीबद्ध स्थिरांक बनाने के लिए किया जाता है।
एक ब्लॉक में लिखे स्थिरांक अपने आप दोहरा दिए जाते हैं:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
