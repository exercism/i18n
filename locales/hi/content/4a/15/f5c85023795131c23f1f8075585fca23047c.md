# परिचय

कई ऑपरेटरों का इस्तेमाल [कंपाउंड असाइनमेंट][compound-assignment] के रूप में भी किया जा सकता है। यह एक तरह का संक्षिप्त रूप है, जिसमें `x = op y` की जगह `x op= y` लिखा जा सकता है:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
