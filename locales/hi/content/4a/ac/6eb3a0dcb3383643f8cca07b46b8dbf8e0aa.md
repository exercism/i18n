# परिचय

Go में `Time` एक टाइप है जो समय के एक क्षण का वर्णन करता है। तारीख और समय की जानकारी इसके मेथड के ज़रिए प्राप्त, तुलना और बदली जा सकती है। लेकिन `time` पैकेज पर ही कुछ फंक्शन भी कॉल किए जाते हैं। वर्तमान तारीख और समय `time.Now` फंक्शन के ज़रिए प्राप्त किया जा सकता है।

`time.Parse` फंक्शन स्ट्रिंग को `Time` टाइप की वैल्यू में पार्स करता है। Go में यह तय करने का एक खास तरीका है कि पार्सिंग के लिए आप किस लेआउट की उम्मीद करते हैं। आपको इस खास टाइमस्टैम्प की वैल्यू का इस्तेमाल करके लेआउट का एक उदाहरण लिखना होता है: `Mon Jan 2 15:04:05 -0700 MST 2006`।

उदाहरण के लिए:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

`Time.Format()` मेथड समय का एक स्ट्रिंग रूप लौटाता है। जैसे `Parse` फंक्शन के साथ होता है, वैसे ही लक्ष्य लेआउट भी फिर से एक उदाहरण के ज़रिए तय किया जाता है। यह उदाहरण उस खास टाइमस्टैम्प की वैल्यू का इस्तेमाल करता है।

उदाहरण के लिए:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## लेआउट विकल्प

कस्टम लेआउट के लिए इन विकल्पों का संयोजन इस्तेमाल कीजिए। Go में पहले से तय तारीख और टाइमस्टैम्प [फॉर्मेट कॉन्स्टेंट][const] भी उपलब्ध हैं।

| समय         | विकल्प                                        |
| ----------- | ---------------------------------------------- |
| वर्ष        | 2006 ; 06                                      |
| महीना       | Jan ; January ; 01 ; 1                         |
| दिन         | 02 ; 2 ; \_2 (0 पहले लगाने के लिए)             |
| सप्ताह का दिन | Mon ; Monday                                   |
| घंटा        | 15 ( 24 घंटे का समय प्रारूप ) ; 3 ; 03 (AM या PM) |
| मिनट        | 04 ; 4                                         |
| सेकंड       | 05 ; 5                                         |
| AM/PM चिह्न  | PM                                             |
| वर्ष का दिन  | 002 ; \_\_2                                    |

`time.Time` टाइप में किसी खास समय को प्राप्त करने के लिए कई मेथड हैं। जैसे घंटा: [`Time.Hour()`][hour], महीना: [`Time.Month()`][month]। यह कैसे काम करता है, इस पर और जानकारी [आधिकारिक डॉक्युमेंटेशन][time] में मिल सकती है।

`time` पैकेज में एक और टाइप, [`Duration`][duration], भी शामिल है, जो बीता हुआ समय दर्शाता है। साथ ही यह लोकेशन/टाइम ज़ोन, टाइमर, और अन्य संबंधित कार्यक्षमता का समर्थन करता है। इन पर एक और कॉन्सेप्ट में चर्चा की जाएगी।
