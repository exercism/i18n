# परिचय

Kotlin में फंक्शन को प्रथम श्रेणी का दर्जा प्राप्त है।
इसका मतलब है कि इन्हें वेरिएबल में रखा जा सकता है, आर्गुमेंट के रूप में पास किया जा सकता है, और दूसरे फंक्शन इन्हें लौटा भी सकते हैं।
उदाहरण के लिए, एक फंक्शन को `addOne` वेरिएबल में असाइन करना:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

एक फंक्शन दूसरा फंक्शन भी लौटा सकता है:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

असाइन हो जाने के बाद उस फंक्शन को वेरिएबल के ज़रिए कॉल किया जा सकता है, जैसे वह कोई और सामान्य फंक्शन हो:
```kotlin
addOne(3)
// => 4
```

## फंक्शन टाइप घोषित करना

वेरिएबल या पैरामीटर का टाइप `(parameter types) -> return type` सिंटैक्स का उपयोग करके घोषित किया जा सकता है।
उदाहरण के लिए, एक वेरिएबल घोषित करना:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

और फंक्शन के पैरामीटर के लिए:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## लैम्ब्डा एक्सप्रेशन

लैम्ब्डा एक्सप्रेशन फंक्शन बनाने का एक छोटा तरीका है।
इन्हें `{ parameters -> body }` रूप में लिखा जाता है।
एक्सप्रेशन बॉडी के अंतिम स्टेटमेंट से अंतिम वैल्यू लौटाता है।
उदाहरण के लिए:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

जब पर्याप्त जानकारी मौजूद हो, तब Kotlin टाइप का अनुमान लगा सकता है।
उदाहरण के लिए, ऊपर दिए उदाहरणों को इस तरह भी लिखा जा सकता है:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## एक ही पैरामीटर वाले लैम्ब्डा के लिए `it`

जब एक्सप्रेशन में सिर्फ एक पैरामीटर हो, तो पैरामीटर को छोड़ा जा सकता है।
तब Kotlin बॉडी में `it` नाम का एक पैरामीटर उपलब्ध कर देता है।
उदाहरण के लिए:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## ट्रेलिंग लैम्ब्डा पास करना

जब किसी फंक्शन का अंतिम आर्गुमेंट एक लैम्ब्डा हो, तो लैम्ब्डा एक्सप्रेशन को ब्रैकेट के ठीक _बाद_ लिखा जाता है।
उदाहरण के लिए:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
