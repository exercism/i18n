# परिचय

PHP में फंक्शन को दूसरे फंक्शन के अंदर घोषित किया जा सकता है। ऐसे फंक्शन को नाम देने की ज़रूरत नहीं होती। आप इन्हें किसी वेरिएबल में असाइन कर सकते हैं, या सीधे किसी ऐसे फंक्शन को दे सकते हैं जो पैरामीटर के रूप में एक फंक्शन लेता है।

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
