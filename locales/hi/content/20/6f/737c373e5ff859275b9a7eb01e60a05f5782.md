# निर्देश

नृत्य दल पंक्तियों में खड़ा होता है, और आप ध्यान रखते हैं कि कौन कहाँ खड़ा है।

पाँचों काम `DANCE_FORMATION` क्लास में लिखने हैं।

## 1. पंक्ति में कितने हैं?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. सबसे आगे कौन है?

सबसे आगे वही रहता है जो सबसे पहले खड़ा होता है।

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. सबसे पीछे कौन है?

सबसे पीछे वही रहता है जो सबसे अंत में खड़ा होता है, चाहे पंक्ति कितनी भी लंबी हो।

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. शुरुआती क्रम

नृत्य दल हमेशा एक ही क्रम में शुरू करता है: Mia, Ana, Ben. वही पंक्ति लौटाइए।

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

यह फंक्शन कोई आर्गुमेंट नहीं लेता।

## 5. कदम गिनिए

हर नर्तक को कुछ कदम करने होते हैं। इन्हें जोड़िए।

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

खाली पंक्ति में शून्य कदम होते हैं।
