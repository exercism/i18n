# निर्देश

इस अभ्यास में आप लॉग एंट्री को प्रोसेस करेंगे।

हर लॉग लाइन एक स्ट्रिंग है जो इस तरह फॉर्मेट की गई है: `"[<LEVEL>]: <MESSAGE>"`।

यहाँ तीन अलग-अलग लॉग लेवल होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके पास तीन टास्क हैं। हर टास्क एक लॉग लाइन लेगा और आपसे उसके साथ कुछ करने को कहेगा। इन टास्क को हल करने के बहुत सारे तरीके हैं। ऊपर दिए गए उदाहरणों में से अपनी पसंदीदा तकनीक चुनिए और देखिए कि आप क्या बना सकते हैं।

## 1. लॉग लाइन से मैसेज निकालिए

`message` फंक्शन बनाइए जो लॉग लाइन का मैसेज लौटाए:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

लॉग लाइन के शुरू या अंत में मौजूद कोई भी खाली जगह हटा देनी चाहिए:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

`log_level` फंक्शन बनाइए जो लॉग लाइन का लॉग लेवल लौटाए। यह लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. लॉग लाइन को फिर से फॉर्मेट कीजिए

`reformat` फंक्शन बनाइए जो लॉग लाइन को फिर से फॉर्मेट करता है। यह मैसेज को पहले रखता है और उसके बाद लॉग लेवल को ब्रैकेट में लिखता है:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
