# परिचय

Elixir true और false वैल्यू को बूलियन टाइप से दर्शाता है। बूलियन टाइप में केवल दो वैल्यू होती हैं: `true` और `false`। इन वैल्यू को किसी वेरिएबल में रखा जा सकता है:

```elixir
true_variable = true
false_variable = false
```

हम `and/2`, `or/2` और `not/1` ऑपरेटरों का इस्तेमाल करके सख्त बूलियन एक्सप्रेशन का मूल्यांकन कर सकते हैं।

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

जब आप ऐसा फंक्शन लिखते हैं जो बूलियन वैल्यू लौटाता है, तो फंक्शन के नाम के अंत में `?` लगाना आम तरीका है। यही तरीका उन वेरिएबलो के लिए भी इस्तेमाल किया जा सकता है जो बूलियन वैल्यू रखते हैं।

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
