# गार्ड का उपयोग कीजिए

[comment]: # (यह एरर तब मिलती है जब हल में गार्ड का इस्तेमाल बिल्कुल नहीं किया गया हो)

[गार्ड](https://hexdocs.pm/elixir/master/guards.html) का उपयोग कीजिए ताकि `two_fer/1` गैर-बाइनरी इनपुट के साथ कोड न चलाए।

> याद रखिए, Elixir में [स्ट्रिंग](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) को [बाइनरी डेटा](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) माना जाता है।

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> इस गार्ड को `iex` में जाँचा जा सकता है

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
