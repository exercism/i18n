# परिचय

Haxe में `String` एक ऑब्जेक्ट है जो अपरिवर्तनीय टेक्स्ट को यूनिकोड अक्षरों (अक्षर, अंक, विराम चिह्न आदि) के अनुक्रम के रूप में दर्शाता है। `String` इंस्टेंस बनाने के लिए दोहरे उद्धरण चिह्नों का उपयोग किया जाता है:

```haxe
var fruit:String = "Apple";
```

स्ट्रिंग पर उसके मेथड कॉल करके काम किया जाता है। एक बार स्ट्रिंग बन जाने के बाद उसकी वैल्यू कभी नहीं बदल सकती। जो मेथड स्ट्रिंग को बदलते हुए लगते हैं, वे वास्तव में एक नई स्ट्रिंग लौटाते हैं।

एक से अधिक स्ट्रिंग को एक साथ जोड़ा जा सकता है। ऐसा करने का सबसे आसान तरीका `+` ऑपरेटर का उपयोग करना है।

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

साधारण जोड़ से ज़्यादा जटिल किसी भी स्ट्रिंग फॉर्मेटिंग के लिए स्ट्रिंग इंटरपोलेशन को प्राथमिकता दी जाती है। किसी स्ट्रिंग में इंटरपोलेशन इस्तेमाल करने के लिए उसे सिंगल कोट चिह्न (`'`) से घेरिए। फिर आप इंटरपोलेशन शुरू करने के लिए डॉलर चिह्न (`$`) का उपयोग कर सकते हैं:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
