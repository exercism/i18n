# परिचय

Factor के एरर सिस्टम में तीन हिस्से हैं। `throw` ([`kernel`][kernel] में) एरर उठाता है, `recover` ([`continuations`][continuations] में) उसे पकड़ता है, और `ERROR:` एक टपल-टाइप एरर क्लास बनाता है।

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` *try* क्वोटेशन को चलाता है। अगर *try* एरर उठाता है, तो उस एरर को स्टैक पर डाल दिया जाता है और *recovery* क्वोटेशन चलता है।

`ERROR:` एरर क्लास *और* एक कंस्ट्रक्टर शब्द, दोनों घोषित करता है। यह कंस्ट्रक्टर उस क्लास का नया इंस्टेंस उठाता है:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
