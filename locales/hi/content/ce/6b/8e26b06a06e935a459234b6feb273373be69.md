# परिचय

Ruby में संख्याओं के साथ काम करने की एक अहम बात यह है कि पूर्णांक और दशमलव संख्याएँ अलग-अलग होती हैं। पूर्णांक वे संख्याएँ हैं जिनमें दशमलव चिह्न के बाद कोई अंक नहीं होता, और दशमलव संख्याओं में दशमलव चिह्न के बाद शून्य या उससे अधिक अंक होते हैं। इन्हें [`Integer`][integer-ruby] और [`Float`][float-ruby] क्लास के ज़रिए लागू किया गया है।

```ruby
a = 1
b = 1.0
a.class
#=> Integer
b.class
#=> Float
```

- गणित की बुनियादी क्रियाएँ [गणितीय ऑपरेटरों][arithmetic-operators] (`+`, `-`, `*`, `/`) से की जाती हैं। संख्याओं की तुलना मानक [तुलना ऑपरेटरों][comparison-operators] से की जा सकती है।
- दो `Integer` संख्याओं के बीच की जाने वाली बुनियादी गणितीय क्रियाओं का परिणाम हमेशा `Integer` ही होता है।
- दो `Float` संख्याओं के बीच की जाने वाली बुनियादी गणितीय क्रियाओं का परिणाम हमेशा `Float` होता है।
- एक `Integer` और एक `Float` संख्या के बीच की जाने वाली बुनियादी गणितीय क्रियाओं का परिणाम `Float` होता है।
- `Float` और `Integer` क्लास में ऐसे मेथड हैं जो किसी वैल्यू को एक से दूसरे में बदल देते हैं। `Integer` संख्याएँ पूरी इकाई तक सटीक रहती हैं, जबकि `Float` की सटीकता दशमलव में होती है। इसका मतलब है कि किसी दशमलव संख्या को पूर्णांक में बदलने पर सटीकता खो सकती है।

```ruby
4.9.to_i
#=> 4

5.to_f
#=> 5.0

7 - 3.0
#=> 4.0

2 == 4
#=> false

1.0 == 1
#=> true
```

किसी शर्त के आधार पर कोड चलाने के लिए `if` स्टेटमेंट का उपयोग किया जा सकता है:

```ruby
x = 5

if x == 5
  # Execute logic if x equals 5
elsif x > 7
  # Execute logic if x greater than 7
else
  # Execute logic in all other cases
end
```

कभी-कभी आप कोई स्टेटमेंट तब चलाना चाहते हैं जब कोई शर्त _सही न हो_। ऐसी स्थितियों के लिए Ruby ने `unless` कीवर्ड दिया है:

```ruby
x = 4
unless x == 5
  # Execute logic if x does not equal 5
else
  # Execute logic if x == 5
end
```

अगर आप किसी वेरिएबल की वैल्यू के हिसाब से अलग-अलग कोड चलाना चाहते हैं, तो Ruby का `case` स्टेटमेंट आपके काम आ सकता है:

```ruby
y = 5
case y
when 3
  # Execute logic if y equals 3
when 5
  # Execute logic if y equals 5
else
  # Execute logic in all other cases
end
```

एक ही समस्या कभी-कभी अलग-अलग तरह के शर्त वाले स्टेटमेंट से हल की जा सकती है, और कभी कोई एक तरीका दूसरे की तुलना में समस्या के लिए ज़्यादा उपयुक्त होता है। इसलिए इन तीनों में से कोई भी शर्त वाला स्टेटमेंट इस्तेमाल करते समय एक पल रुककर बाकी दो विकल्पों पर भी विचार करना अच्छा रहता है।
