# विवरण

पाइथागोरस त्रिक तीन प्राकृतिक संख्याओं का एक समूह है, {a, b, c}, जिसके लिए

```text
a² + b² = c²
```

होता है और जिसमें

```text
a < b < c
```

भी होता है।

उदाहरण के लिए,

```text
3² + 4² = 5².
```

इनपुट के रूप में एक पूर्णांक N दिया गया हो, तो वे सारे पाइथागोरस त्रिक खोजिए जिनके लिए `a + b + c = N` हो।

उदाहरण के लिए, N = 1000 लेने पर ठीक एक ऐसा पाइथागोरस त्रिक होता है जिसके लिए `a + b + c = 1000` हो: `{200, 375, 425}`.
