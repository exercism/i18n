# इसके बारे में

Go में `string` बाइट का एक अपरिवर्तनीय क्रम है। ज़रूरी नहीं कि ये बाइट अक्षरों को ही दर्शाएँ।

स्ट्रिंग लिटरल डबल कोट के बीच लिखा जाता है:

```go
const name = "Jane"
```

स्ट्रिंग को `+` ऑपरेटर की मदद से जोड़ा जा सकता है:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

कुछ विशेष अक्षरों को शुरू में बैकस्लैश लगाकर एस्केप करना पड़ता है, जैसे स्ट्रिंग में टैब के लिए `\t` और नई लाइन के लिए `\n`।

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings` पैकेज में स्ट्रिंग पर काम करने वाले बहुत-से काम के फंक्शन हैं।
स्ट्रिंग फंक्शन के बारे में अधिक जानकारी के लिए [strings पैकेज का दस्तावेज़](https://pkg.go.dev/strings) देखिए।
यहाँ कुछ उदाहरण दिए गए हैं:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```

## विशेष अक्षर

जैसा ऊपर बताया गया है, कुछ विशेष अक्षरों को शुरू में बैकस्लैश लगाकर एस्केप करना पड़ता है।
इन विशेष अक्षरों की थोड़ी विस्तृत सूची नीचे दी गई है:

| वैल्यू | विवरण          |
| ----- | -------------------- |
| `\a`  | अलर्ट या घंटी        |
| `\b`  | बैकस्पेस            |
| `\\`  | बैकस्लैश            |
| `\t`  | आड़ा टैब       |
| `\n`  | लाइन फीड या नई लाइन |
| `\f`  | फॉर्म फीड |
| `\r`  | कैरिज रिटर्न      |
| `\v`  | खड़ा टैब         |
| `\'`  | सिंगल कोट         |
| `\"`  | डबल कोट         |

```go
fmt.Println("Joe\nWilliam\nJack\nAverell") 

// Output:
// Joe
// William
// Jack
// Averell
```

## रॉ स्ट्रिंग लिटरल

रॉ स्ट्रिंग लिटरल में डबल कोट की जगह बैकटिक (\`) डिलिमिटर की तरह इस्तेमाल होता है, और इसमें लिखा हर अक्षर जैसा है वैसा ही लिया जाता है। यानी अक्षरों या नई लाइन को एस्केप करने की ज़रूरत नहीं पड़ती।

यह एक मल्टीलाइन स्ट्रिंग का उदाहरण है:

```go
const daltons = `Joe
William
Jack
Averell`
```

इस स्ट्रिंग में कई लाइन हैं।
ठीक-ठीक कहें तो इसमें 3 `\n` हैं।
लेकिन चूँकि यह रॉ स्ट्रिंग लिटरल है, हमें स्ट्रिंग में `\n` साफ़-साफ़ लिखने की ज़रूरत नहीं पड़ती।
नई लाइनें जैसी हैं वैसी ही ली जाती हैं।

यहाँ रॉ स्ट्रिंग लिटरल की तुलना आम स्ट्रिंग लिटरल से करने वाले कुछ और उदाहरण हैं:

```go
`abc`
// same as "abc"

"\"" // regular string literal with 1 character: a double quote
// same as `"` a raw string literal with 1 character: a double quote

`\n
` // raw string literal with 3 character: a backslash, an 'n', and a newline
// same as "\\n\n"  a regular string literal with 3 characters: a backslash, an 'n', and a newline

"\t\n" // regular string literal with 2 characters: a tab and a newline
`\t\n`// raw string literal with 4 characters: two backslashes, a 't', and an 'n'
```
