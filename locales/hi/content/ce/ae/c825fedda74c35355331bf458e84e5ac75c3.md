# परिचय

छोटे वर्ड के लिए स्टैक को सँभालना ठीक रहता है। जब किसी वर्ड के कई इनपुट हों और आपको उन्हें नाम से इस्तेमाल करना हो, तो Factor *locals* देता है। ये नाम वाली बाइंडिंग होती हैं, जिन्हें `::` से (वर्ड बनाने के लिए) या `[| | ]` से (इनलाइन लैम्ब्डा के लिए) शुरू किया जाता है। दोनों [`locals`][locals] से आते हैं।

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

एक कोटेशन के अंदर, `[| inputs | body ]` नामित इनपुट वाला लैम्ब्डा होता है:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
