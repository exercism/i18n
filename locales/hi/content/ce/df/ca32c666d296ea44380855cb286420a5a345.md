# Exercism API

## विवरण

Exercism के ज़्यादातर भाषा ट्रैक अभ्यास लाने और सबमिट करने के लिए `exercism` कमांड लाइन टूल का इस्तेमाल करते हैं। यह टूल REST API के ज़रिए `exercism.io` से बात करता है। Pharo Smalltalk भाषा ट्रैक इसके बजाय वही REST API इस्तेमाल करता है, ताकि बिना किसी बिचौलिए टूल के अभ्यासों को Pharo इमेज में लाया जा सके और उससे बाहर निकाला जा सके। यह दस्तावेज़ Exercism API के बारे में विस्तार से बताता है, खास तौर पर इस बात पर ध्यान देते हुए कि Pharo Smalltalk भाषा ट्रैक इसका इस्तेमाल कैसे करता है। यह Pharo Smalltalk टूलिंग के मेंटेनरों के लिए लिखा गया है।

## हेडर

सभी एंडपॉइंट के लिए ज़रूरी है कि रिक्वेस्ट के हेडर इन वैल्यू पर सेट किए जाएँ:

```
Authorization: Bearer <token>
```

`<token>` की वैल्यू उस यूज़र का CLI ऑथेंटिकेशन टोकन है, जो `https://exercism.io/my/settings` पर मिलता है।

## अभ्यास लाना

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

ऊपर दिए URL में `<slug>` अभ्यास का नाम है, जैसे `hello-world`, और `<language>` भाषा ट्रैक है, जैसे `pharo-smalltalk`.

### रिस्पॉन्स

#### 200

सफल रिक्वेस्ट एक ऐसा रिस्पॉन्स भेजती है जिसमें एक JSON पेलोड होता है। इस JSON के अंदर अभ्यास की जानकारी और एक URL होता है, जहाँ से अभ्यास की फाइलें डाउनलोड की जा सकती हैं।

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

भाषा ट्रैक का नाम अस्पष्ट है, या सबमिट की गई अभ्यास फाइलें बदली नहीं हैं।

#### 403

यूज़र के लिए हल अनलॉक नहीं है, या भाषा ट्रैक जॉइन नहीं किया गया है।

#### 404

भाषा ट्रैक या अभ्यास नहीं मिल सका।

## अभ्यास सबमिट करना

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### रिस्पॉन्स

#### 201

सफल सबमिशन।

#### 400

सबमिट की गई कोई फाइल बहुत बड़ी है (एक मेगाबाइट से ज़्यादा), या हल डुप्लिकेट है।

#### 403

यूज़र के पास इस हल की पहुँच नहीं है। हल के यूज़र ID और वर्तमान यूज़र ID आपस में मेल नहीं खाते।

#### 404

हल की ID नहीं मिली।
