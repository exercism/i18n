# टेस्ट

Clojurescript REPL की मदद से आप आसानी से कोड चलाकर तुरंत प्रतिक्रिया पा सकते हैं। इस REPL का इस्तेमाल टेस्ट चलाने के लिए भी किया जा सकता है।

## Leiningen
Clojure CLI से REPL खोलने के लिए जिस डायरेक्टरी में अभ्यास है उसमें जाइए और यह चलाइए:
``` bash
$ clojure -m cljs.main -re node
```

ध्यान दीजिए कि आपके सिस्टम पर Node इंस्टॉल होना चाहिए।

जब आप किसी अभ्यास पर काम करने के लिए तैयार हों और अपने हल को रखने के लिए एक फाइल बना लें (जैसे `bob.cljs`), तो आप अपने टर्मिनल में `$ clojure -A:test` चलाकर टेस्ट चला सकते हैं।

सबसे पहले टेस्ट नेमस्पेस को `require` कीजिए:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

`ns` को टेस्ट नेमस्पेस में बदलिए:
```clojure
=> (ns bob-test)
nil
```

फिर `bob-test` पर `run-tests` कॉल कीजिए:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Clojure CLI से किसी अभ्यास के टेस्ट चलाने के लिए बस यह चलाइए:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
