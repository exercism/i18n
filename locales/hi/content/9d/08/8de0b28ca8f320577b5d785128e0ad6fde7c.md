# परिचय

हमने पिछले कॉन्सेप्ट में देखा था कि Julia में टाइप एक पदानुक्रम बनाते हैं, जिसमें `Any` सबसे ऊपर होता है।

`Number` जैसे एब्सट्रैक्ट टाइप के सबटाइप होते हैं, लेकिन इन्हें खुद इंस्टैंशिएट नहीं किया जा सकता।
किसी वेरिएबल को एब्सट्रैक्ट टाइप पर सेट करने से उस वेरिएबल की वैल्यू पर यह _बंधन_ लगता है कि वे उस एब्सट्रैक्ट टाइप का कोई भी सबटाइप हों।
उदाहरण के लिए:

```julia-repl
julia> x::Number = 3
3
julia> typeof(x)  # one subtype of Number
Int64
julia> x = 4.2
4.2
julia> typeof(x) # another subtype of Number
Float64
julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

इससे हमें एक तरह का लचीलापन मिलता है, जिससे हम तय कर सकते हैं कि कौन से इनपुट मान्य हैं।

लेकिन मान लीजिए कि हम चाहते हैं कि एक वेरिएबल पूर्णांक और स्ट्रिंग दोनों तरह की वैल्यू स्वीकार करे?
ये टाइप पदानुक्रम की एक ही शाखा में नहीं हैं।

हम टाइप को `Any` पर सेट कर सकते हैं, या उसे डिफ़ॉल्ट में `Any` ही रहने दे सकते हैं, लेकिन फिर हम अनुमत टाइप पर से अपना पूरा नियंत्रण खो देते हैं।

बेहतर तरीके के लिए हमारे पास `Union{ }` सिंटैक्स है, जिसमें ब्रैकेट के अंदर दो या अधिक टाइप लिखे होते हैं।

```julia-repl
julia> y::Union{Integer, String} = 4
4
julia> typeof(y)
Int64
julia> y = "works"
"works"
julia> typeof(y)
String
julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

एक और उदाहरण में वही टाइप यूनियन एक फंक्शन सिग्नेचर में इस्तेमाल होता है:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}
julia> f(z::IntOrString) = z^3
f (generic function with 1 method)
julia> f(2) # integers are cubed
8
julia> f("ab") # strings are repeated 3 times
"ababab"
```

यहाँ हमने टाइप को एक नाम दिया, जो सुविधाजनक शॉर्टहैंड दे सकता है, लेकिन यह पूरी तरह ज़रूरी नहीं है।
फंक्शन `g(z::Union{Integer, String}) = z^3` भी वही व्यवहार करता है।

मल्टीपल डिस्पैच कॉन्सेप्ट में फंक्शन सिग्नेचर के बारे में बहुत कुछ कहा जाएगा।

## `nothing` के साथ यूनियन

कई अन्य भाषाओं में ऐसे टाइप होते हैं जिनमें वैल्यू हो भी सकती है और नहीं भी, जैसे `Option`, `Nullable` या `Maybe`।

Julia में इसके लिए कोई खास सिंटैक्स नहीं है, लेकिन टाइप यूनियन इसी विचार का एक सामान्यीकरण हैं।

हमने `Nothingness` कॉन्सेप्ट में देखा था कि Julia में गैर-वैल्यू को दर्शाने के कई तरीके हैं, जिनमें `nothing` और `missing` शामिल हैं।
इनमें से कोई भी एक टाइप यूनियन में शामिल किया जा सकता है।

उदाहरण के लिए, किसी तरह की लिंक्ड लिस्ट बनाते समय, अगर और नोड नहीं हैं तो लिस्ट को समाप्त करने का तरीका चाहिए।
`Nothing` वह टाइप है जिसकी सिंगलटन वैल्यू `nothing` है, और यह Node परिभाषा शृंखला के अंत का संकेत देना संभव बनाती है:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

इसी तरह, `missing` का इस्तेमाल अनुपस्थित वैल्यू के लिए प्लेसहोल्डर के रूप में किया जा सकता है, खास तौर पर वेक्टर जैसे संग्रहों में।
नीचे दिया गया उदाहरण बहुत कृत्रिम है, लेकिन वास्तविक दुनिया के डेटा सेट में अनुपस्थित वैल्यू आम हैं।

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)
julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
