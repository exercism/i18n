# निर्देश

इस अभ्यास में आप अपने इलाके के आर्केड हॉल के सबसे लोकप्रिय खेल के हाई स्कोर का हिसाब रखने का तरीका बना रहे हैं।

## 1. हाई स्कोर बोर्ड में खिलाड़ी जोड़िए

हाई स्कोर बोर्ड में खिलाड़ी जोड़ने के लिए दो `add_player!` मेथड बनाइए, जो ये आर्गुमेंट लेते हैं:

- पहला आर्गुमेंट स्कोर की डिक्शनरी है।
- दूसरा आर्गुमेंट खिलाड़ी का नाम है, जो स्ट्रिंग के रूप में दिया जाता है।
- तीसरा आर्गुमेंट स्कोर है, जो पूर्णांक के रूप में दिया जाता है।
  यह आर्गुमेंट वैकल्पिक है: जब कोई वैल्यू न दी जाए, तो स्कोर 0 रखा जाना चाहिए।

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. स्कोर बोर्ड से खिलाड़ी हटाइए

हाई स्कोर बोर्ड से किसी खिलाड़ी को हटाने के लिए `remove_player!` बनाइए, जो 2 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर की डिक्शनरी है।
- दूसरा आर्गुमेंट खिलाड़ी का नाम है, जो स्ट्रिंग के रूप में दिया जाता है।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. खिलाड़ी का स्कोर बदलिए

किसी खिलाड़ी का स्कोर पिछले स्कोर की जगह नया स्कोर रखकर बदलने के लिए `update_score!` बनाइए, जो 3 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर की डिक्शनरी है।
- दूसरा आर्गुमेंट उस खिलाड़ी का नाम है, जो स्ट्रिंग के रूप में दिया जाता है और जिसका स्कोर आप बदलना चाहते हैं।
- तीसरा आर्गुमेंट वह स्कोर है, जिसे आप संग्रहीत हाई स्कोर के रूप में रखना चाहते हैं।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. खिलाड़ी का स्कोर रीसेट कीजिए

किसी खिलाड़ी का स्कोर रीसेट करने के लिए `reset_score!` बनाइए, जो 2 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर की डिक्शनरी है।
- दूसरा आर्गुमेंट उस खिलाड़ी का नाम है, जो स्ट्रिंग के रूप में दिया जाता है और जिसका स्कोर आप रीसेट करना चाहते हैं।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. खिलाड़ियों का ऐरे पाइए

खिलाड़ियों का ऐरे पाने के लिए `players` बनाइए, जो 1 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर की डिक्शनरी है।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
