# परिचय

## कास्टिंग

कास्टिंग और टाइप कन्वर्ज़न, किसी एक्सप्रेशन को एक डेटा टाइप से दूसरे डेटा टाइप में बदलने के दो अलग-अलग तरीके हैं।

किसी एक्सप्रेशन को कास्ट ऑपरेटर `(<type>)` की मदद से दूसरे टाइप में कास्ट किया जा सकता है।

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

अगर टाइप आपस में कंपैटिबल नहीं हैं, तो `InvalidCastException` का एक इंस्टेंस फेंका जाता है। संख्याओं के मामले में इसका मतलब है कि जिस टाइप में कास्ट किया जा रहा है, वह कास्ट की गई वैल्यू को दर्शा नहीं सकता। क्लास के मामले में, दोनों टाइप में से एक का दूसरे से व्युत्पन्न होना ज़रूरी है (यही बात स्ट्रक्ट पर भी सीधे लागू होती है)।

_कास्टिंग_ का एक विकल्प है _टाइप कन्वर्ज़न_, जिसमें `is` ऑपरेटर का इस्तेमाल किया जाता है। यह आमतौर पर रेफरेंस और नलएबल टाइप पर लागू होता है।

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

अगर आपको किसी ऑब्जेक्ट का ठीक-ठीक टाइप पता लगाना है, तो `is` ज़रूरत से ज़्यादा ढीला पड़ सकता है, क्योंकि यह किसी क्लास के लिए और उन सभी क्लासों तथा इंटरफेस के लिए भी सही लौटाता है जिनसे वह सीधे या परोक्ष रूप से व्युत्पन्न है। ऐसे मामलों में `typeof` और `Object.GetType()` ही हल हैं।

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
