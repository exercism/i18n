# परिचय

## JavaScript में रेगुलर एक्सप्रेशन

[रेगुलर एक्सप्रेशन][mdn-regular-expressions] (या रेगेक्स) अक्षरों का एक क्रम है, जिसकी मदद से हम स्ट्रिंग में मौजूद कुछ खास चीज़ों को निशाना बनाकर उनमें बदलाव कर सकते हैं। इस तरह हम ये कर सकते हैं:

- स्ट्रिंग में किसी टेक्स्ट को **खोजना**
- स्ट्रिंग के अंदर मौजूद सबस्ट्रिंग को **बदलना**
- स्ट्रिंग से जानकारी **निकालना**

> 💡 JavaScript का रेगेक्स फ्लेवर इस भाषा के ECMA-262 मानक का हिस्सा है। इसका मतलब है कि आपको ब्राउज़र-विशिष्ट कंपैटिबिलिटी की चिंता करने की ज़रूरत नहीं है।

## रेगुलर एक्सप्रेशन बनाने का तरीका

JavaScript में रेगुलर एक्सप्रेशन ज़्यादातर `/pattern/modifiers` के रूप में लिखा जाता है।

रेगुलर एक्सप्रेशन बनाने के दो तरीके हैं:

1. **रेगुलर एक्सप्रेशन लिटरल**:

```javascript
const regex = /[a-z]/;
```

2. कंस्ट्रक्टर **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

दोनों ही मामलों में JavaScript उस रेगेक्स से एक ऑब्जेक्ट बनाता है। सलाह यह है कि आप डिफ़ॉल्ट रूप से लिटरल के साथ अपरिवर्तनीय पैटर्न इस्तेमाल कीजिए।

RegExp कंस्ट्रक्टर उन मामलों में काम आता है जहाँ रेगेक्स बदलेगा, या जहाँ हमें अभी पता ही नहीं कि वह क्या होगा (जैसे किसी इनपुट में)।

## 🏴‍☠️ फ्लैग

रेगुलर एक्सप्रेशन के पास कुछ वैकल्पिक सुपरपावर होती हैं, जिन्हें [`flags`][mdn-flags] कहते हैं और जो कुछ अतिरिक्त सुविधाएँ देती हैं।

इनमें से कुछ सबसे ज़्यादा इस्तेमाल किए जाने वाले हैं:

- `/g` - ग्लोबल सर्च
- `/i` - केस इनसेंसिटिव
- `/m` - मल्टीलाइन सर्च

यहाँ एक आसान उदाहरण है:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

`g` अक्षर हमें स्ट्रिंग के सारे संभावित मैच निकालने देता है। अगर यह सुविधा न होती, तो JavaScript सिर्फ़ पहला `Home` मैच ही निकालता।

केस इनसेंसिटिव फ्लैग `/i` हमें पैटर्न ढूँढने में लचीला बनाता है। इससे फ़र्क नहीं पड़ता कि हम जो ढूँढ रहे हैं वह `UPPERCASE` में है या `lowercase` में।

`RegExp` कंस्ट्रक्टर इस्तेमाल करते समय फ्लैग जोड़ने का तरीका अलग होता है।

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## सबसे आम फंक्शन

जब रेगुलर एक्सप्रेशन को JavaScript के मौजूदा बिल्ट-इन फंक्शन के साथ मिलाया जाता है, तो हमारे पास स्ट्रिंग से डेटा निकालने और उसमें बदलाव करने के कुछ बहुत शक्तिशाली तरीके होते हैं।

ये कुछ ऐसे फंक्शन हैं जो रेगेक्स के साथ सबसे ज़्यादा इस्तेमाल होते हैं।

### टेस्ट

[test()][mdn-regex-test] मेथड एक रेगुलर एक्सप्रेशन और दी गई स्ट्रिंग के बीच मैच की खोज करता है। यह सही या गलत लौटाता है।

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### मैच

[match()][mdn-regex-match] मेथड से हमें एक काम का ऐरे मिलता है, जिसकी सामग्री इस पर निर्भर करती है कि मैच मिले हैं या नहीं।

इस तरह हम किसी भी स्ट्रिंग से जानकारी **खोज** भी सकते हैं और **निकाल** भी सकते हैं। उदाहरण के लिए:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

जब ग्लोबल सर्च फ्लैग `/g` मौजूद होता है, तो यह मेथड इंडेक्स या इनपुट जैसी काम की जानकारी के साथ सिर्फ़ एक ही मैच देने के बजाय ऐरे में दिखने वाले सारे मैच लौटाता है:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### रिप्लेस

JavaScript का [replace()][mdn-regex-replace] मेथड हमें किसी दी गई स्ट्रिंग में एक वैल्यू ढूँढकर उसे अपनी मनचाही नई वैल्यू से बदलने देता है।

```javascript
string.replace(searchValue, newValue);
```

खोज और बदलाव के लिए पैटर्न एक अकेली स्ट्रिंग भी हो सकती है और रेगुलर एक्सप्रेशन भी।

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

इसके अलावा, हम रिप्लेसमेंट की जगह एक फंक्शन भी लगा सकते हैं, ताकि हर वैल्यू में कुछ और बदलाव किए जा सकें।

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### स्प्लिट

JavaScript का [split()][mdn-regex-split] मेथड रेगुलर एक्सप्रेशन के साथ स्ट्रिंग इस्तेमाल करने और उनमें बदलाव करने का एक अलग तरीका है।

इसमें हम किसी दी गई स्ट्रिंग को पैटर्न पहचानकर बाँटने के लिए रेगेक्स इस्तेमाल करते हैं, जैसे `str.split(/[,.\s]/)`.

यही पैटर्न `separator` की तरह काम करता है।

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
