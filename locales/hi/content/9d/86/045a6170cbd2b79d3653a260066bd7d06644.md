# इंस्टॉलेशन

इन समस्याओं के लिए हम लोकप्रिय MIPS सिम्युलेटर [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html) का इस्तेमाल करते हैं। [GitHub](https://github.com/dpetersanderson/MARS/releases) से MARS का jar आर्काइव डाउनलोड कीजिए और उसे किसी ऐसी जगह रखिए जहाँ आप आसानी से पहुँच सकें। अगर आपके पास Java SDK पहले से नहीं है, तो उसे भी इंस्टॉल कर लीजिए।
