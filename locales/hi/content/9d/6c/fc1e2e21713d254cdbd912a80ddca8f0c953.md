# विवरण

[वर्बेटिम स्ट्रिंग][verbatim-strings] से कई लाइनों वाली स्ट्रिंग लिखी जा सकती है। इनकी शुरुआत @ से होती है। इनका इस्तेमाल स्ट्रिंग इंटरपोलेशन के साथ किया जा सकता है। बस शुरुआती कोट से पहले "\$" लगाइए।

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
