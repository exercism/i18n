# परिचय

## ऐरे

Java में ऐरे एक ही टाइप की कई वैल्यू को एक ही ढाँचे में रखने का तरीका हैं। दूसरे डेटा स्ट्रक्चर की तुलना में ऐरे का आकार बनने के बाद तय रहता है। इंडेक्स की मदद से ऐरे में एलिमेंट असाइन किए जा सकते हैं या ऐरे से एलिमेंट निकाले जा सकते हैं। Java के ऐरे शून्य-आधारित इंडेक्सिंग इस्तेमाल करते हैं: पहले एलिमेंट का इंडेक्स 0 होता है, दूसरे एलिमेंट का इंडेक्स 1 होता है, और इसी तरह।

ऐरे को इनिशियलाइज़ करने का मानक सिंटैक्स यह है:

```java
type[] variableName = new type[size];
```

यहाँ `type` ऐरे के एलिमेंट का टाइप है, जो कोई प्रिमिटिव टाइप (जैसे `int`) या कोई क्लास (जैसे `String`) हो सकता है।

`size` उन एलिमेंट की संख्या है जो यह ऐरे रखेगा (जिसे बाद में बदला नहीं जा सकता)। ऐरे बनने के बाद एलिमेंट को उनकी डिफॉल्ट वैल्यू पर इनिशियलाइज़ कर दिया जाता है (आम तौर पर `0`, `false` या `null`)।

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

ऐरे को एक शॉर्टकट नोटेशन की मदद से भी बनाया जा सकता है, जिससे आप एक साथ ऐरे बना भी सकते हैं और उसकी वैल्यू भी सेट कर सकते हैं:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

चूँकि अब कंपाइलर बता सकता है कि ऐरे में कितने एलिमेंट होंगे, इसलिए लंबाई छोड़ी जा सकती है।

ऐरे के एलिमेंट को ब्रैकेट वाले इंडेक्स नोटेशन की मदद से असाइन और एक्सेस किया जा सकता है:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

ऐरे के वैध इंडेक्स के बाहर का कोई इंडेक्स एक्सेस करने पर `IndexOutOfBoundsException` मिलता है।

ऐरे को उसके इंस्टेंस के मेथड या प्रॉपर्टी कॉल करके, या `Arrays` क्लास में बनाए गए स्टैटिक मेथड इस्तेमाल करके नियंत्रित किया जा सकता है (आम तौर पर इनका उपयोग सिर्फ जेनेरिक कोड में होता है)। `length` प्रॉपर्टी में ऐरे की लंबाई रहती है। इसे ऐसे एक्सेस किया जा सकता है:

```java
int arrayLength = someArray.length;
```

Java काम की एक यूटिलिटी क्लास [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) भी देता है, जिसमें ऐरे से जुड़े बहुत से उपयोगी मेथड हैं (जैसे `Arrays.equals`)।

Java [मल्टी-डाइमेंशनल ऐरे](https://www.programiz.com/java-programming/multidimensional-array) को भी सपोर्ट करता है, जैसे `int[][] arr = new int[3][4];`, जो बहुत काम के हो सकते हैं।

ऐरे एक _कलेक्शन_ भी होता है, और इसका मतलब है कि इंडेक्स से वैल्यू एक्सेस करने के अलावा आप `for-each` लूप की मदद से उसकी _सारी_ वैल्यू पर इटरेशन कर सकते हैं:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

अगर आप चाहते हैं कि किन वैल्यू पर इटरेशन हो, इस पर आपका ज़्यादा नियंत्रण रहे, तो `for` लूप इस्तेमाल किया जा सकता है:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
