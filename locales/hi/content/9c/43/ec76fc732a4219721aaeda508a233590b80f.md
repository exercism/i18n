# परिचय

ऐरे Factor का मुख्य निश्चित-लंबाई वाला सीक्वेंस टाइप हैं, जिन्हें `{ … }` लिखा जाता है: आप एलिमेंट बदल सकते हैं, लेकिन लंबाई नहीं बदल सकते।

`arrays` और `sequences` वोकैबुलरी मिलकर आपको छोटे कंस्ट्रक्टर देती हैं, जो स्टैक से वैल्यू लेते हैं। इसके साथ ही इनमें जोड़ने, उलटने और एलिमेंट ढूँढने जैसे रोज़मर्रा के ऑपरेशन भी मिलते हैं।

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
