# परिचय

Go में हर वेरिएबल की एक वैल्यू होती है।
अगर आप कोई वेरिएबल घोषित करते हैं और उसे कोई वैल्यू असाइन नहीं करते, तो वह अपने टाइप की ज़ीरो वैल्यू ले लेता है।

बुनियादी टाइप, जैसे `bool`, संख्यात्मक टाइप और `string`, इनमें से हर एक की एक तय ज़ीरो वैल्यू होती है:

| टाइप                   | ज़ीरो वैल्यू |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, आदि  | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

पॉइंटर, फंक्शन, इंटरफेस, स्लाइस, चैनल और मैप, इन सबकी ज़ीरो वैल्यू `nil` होती है।

ऐरे और स्ट्रक्चर कभी `nil` नहीं होते, क्योंकि ये डेटा सीधे रखते हैं, न कि उसका रेफरेंस।
ऐरे के हर एलिमेंट और स्ट्रक्चर के हर फील्ड को उसके अपने टाइप की ज़ीरो वैल्यू से इनिशियलाइज़ किया जाता है।
उदाहरण के लिए, `var a [3]int` ऐरे `[0, 0, 0]` बनाता है।

## ज़ीरो वैल्यू घोषित करना

घोषित करने के लिए `var` का इस्तेमाल कीजिए:

```go
var myBool bool   // false
var mySlice []int // nil
```

स्ट्रक्चर के लिए कंपोज़िट लिटरल `T{}` का इस्तेमाल कीजिए:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
