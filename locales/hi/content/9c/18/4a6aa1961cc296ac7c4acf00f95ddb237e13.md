# कोड इन्क्लूज़न

`circus-acts` ने `<` का इस्तेमाल यह बताने के लिए किया था कि एक क्लास वह सब *कर सकती है* जो एक एब्स्ट्रैक्ट क्लास बताती है। पर यह नहीं बताया कि यह कैसे होता है।

`include` इसका दूसरा हिस्सा है। यह किसी दूसरी क्लास से असली कोड लेता है और उसकी एक कॉपी इस क्लास में रख देता है।

```sather
class WARM_UP is

   count : INT is return 8; end;

   describe : STR is return count + " counts"; end;

end; -- class WARM_UP

class JAZZ_ROUTINE is

   include WARM_UP;

   -- count and describe are now here too, as though written out.

end; -- class JAZZ_ROUTINE
```

`JAZZ_ROUTINE::count` की वैल्यू 8 है, भले ही `JAZZ_ROUTINE` में इसका कोई उल्लेख नहीं है।

## ये दो अलग-अलग फैसले हैं

ज़्यादातर भाषाएँ इन दोनों को जोड़ देती हैं। एक ही `extends` कोड को आगे सौंप भी देता है और सबक्लास को वहाँ भी इस्तेमाल करने लायक बना देता है जहाँ सुपरक्लास की ज़रूरत होती है। Sather इन्हें अलग रखता है।

| कैसे लिखा जाता है | क्या बताता है |
| --- | --- |
| `class A < $B` | `A` का इस्तेमाल वहाँ किया जा सकता है जहाँ `$B` चाहिए |
| `class A is include B` | `A` की शुरुआत `B` के कोड की एक कॉपी से होती है |

इनमें से कोई एक अकेले भी हो सकता है, और दोनों भी। किसी क्लास को शामिल करने से वह क्लास सबटाइप **नहीं** बन जाती। `include WARM_UP` के बाद भी `JAZZ_ROUTINE` का इस्तेमाल वहाँ नहीं किया जा सकता जहाँ `WARM_UP` चाहिए, और ऐसा कोई दिखावा भी नहीं करता।

## नाम बदलना

किसी शामिल किए गए मेथड को दूसरे नाम से अंदर लाया जा सकता है:

```sather
   include WARM_UP count -> warm_up_count;
```

एक से ज़्यादा मेथड को कॉमा से अलग किया जाता है:

```sather
   include WARM_UP count -> warm_up_count, describe -> warm_up_describe;
```

## किसी एक को छोड़ देना

किसी मेथड का नाम *कुछ नहीं* रखने पर वह छूट जाता है, और यही उसे बदलने का तरीका है:

```sather
class TAP_ROUTINE is

   include WARM_UP describe -> ;

   describe : STR is return "Tap: " + count + " counts"; end;

end; -- class TAP_ROUTINE
```

`count` तो आम तौर पर अंदर आ जाता है; `describe` नहीं आता, इसलिए यहाँ इसे लिखना कोई टकराव नहीं है। `describe -> ;` के बिना कंपाइलर मना कर देता। वजह यह है कि एक ही क्लास में एक ही नाम और आर्गुमेंट वाले दो मेथड होना एक एरर है, और Sather यह अनुमान नहीं लगाएगा कि आपका मतलब कौन-सा था।

ज़्यादातर भाषाओं के ओवरराइड से यही अंतर है। यहाँ बदलाव की घोषणा की जाती है, उसे मान नहीं लिया जाता।
