# परिचय

टाइप डेफिनिशन एक नया नाम वाला टाइप बनाता है, जो बाकी हर टाइप से अलग होता है, भले ही उसका अंडरलाइंग टाइप वही हो।

## टाइप बनाना

टाइप डेफिनिशन की शुरुआत `type` कीवर्ड से होती है। इसके बाद नए टाइप का नाम और उसका अंडरलाइंग टाइप लिखा जाता है:

```go
type File []bool
```

यहाँ `File` शतरंज के बोर्ड के एक खड़े कॉलम को दर्शाता है। शतरंज में ऐसे कॉलमों के नाम A से H तक होते हैं।
इस कॉलम के हर खाने को एक बूलियन वैल्यू से दर्शाया जाता है, जो बताती है कि वह खाना भरा हुआ है या नहीं।
अब जब `File` बन चुका है, तो हम इसे दूसरे टाइप डेफिनिशन के अंदर इस्तेमाल कर सकते हैं:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` फाइल आइडेंटिफायर को `File` वैल्यू से जोड़ता है।
हर `File` बूलियन की एक स्लाइस होती है, जो शतरंज के एक फाइल के खानों को दर्शाती है।
इन टाइप डेफिनिशन के बिना `board` का टाइप `map[string][]bool` होता, जिससे यह समझना मुश्किल हो जाता कि हम क्या दर्शा रहे हैं।
