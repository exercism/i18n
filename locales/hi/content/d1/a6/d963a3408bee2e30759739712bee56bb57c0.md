# टेस्ट चलाना

`sbt` इंस्टॉल होने पर टेस्ट को कमांड लाइन से इस तरह चलाया जा सकता है:

```bash
$ sbt test
```

ध्यान दीजिए कि हर बार `sbt test` चलाना धीमा रहेगा, क्योंकि हर बार चलाने पर `sbt` फिर से इनिशियलाइज़ हो जाता है।

`sbt` एक शेल की तरह काम करता है; एक बार शुरू हो जाने के बाद आप उसके अंदर कमांड चला सकते हैं।

उदाहरण के लिए, जब भी सोर्स फाइलें बदलें, आप `sbt` की मदद से अपने टेस्ट दोबारा चला सकते हैं:
```bash
$ sbt
>~ test
```

ध्यान दीजिए कि आपके काम करने के लिए पहले टेस्ट को छोड़कर बाकी सभी टेस्ट बंद कर दिए गए हैं।
आगे बढ़ने के लिए, हर टेस्ट केस की शुरुआत से `pending` कीवर्ड हटा दीजिए।

`sbt` के बारे में और जानने के लिए [यहाँ](https://www.scala-sbt.org/) जाइए।


टेस्ट इन IDE में भी चलाए जा सकते हैं

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
