# विवरण

Gleam की मानक लाइब्रेरी में मौजूद `gleam/order` मॉड्यूल में `Order` टाइप होता है, जिसका उपयोग वैल्यू की तुलना करने के लिए किया जाता है।

`Order` की परिभाषा इस तरह दिखती है:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

इस टाइप के तीन वेरिएंट होते हैं, जो किसी वैल्यू और दूसरी वैल्यू के बीच का संबंध दर्शाते हैं:

- `Gt` - वैल्यू दूसरी वैल्यू से _बड़ी_ होती है।
- `Eq` - वैल्यू दूसरी वैल्यू के _बराबर_ होती है।
- `Lt` - वैल्यू दूसरी वैल्यू से _छोटी_ होती है।

अगर किसी डेटा टाइप की तुलना आकार के आधार पर की जा सकती है, तो आमतौर पर मॉड्यूल एक `compare` फंक्शन बनाता है जो एक `Order` वैल्यू लौटाता है। उदाहरण के लिए, `gleam/float` और `gleam/int` ऐसे `compare` फंक्शन बनाते हैं जो क्रमशः दशमलव संख्याओं और पूर्णांकों पर काम करते हैं।

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort` जैसे सॉर्टिंग फंक्शन आमतौर पर एक ऐसा फंक्शन लेते हैं जो `Order` वैल्यू लौटाता है, जिससे कॉल करने वाला तय कर सकता है कि ऐरे को किस तरह क्रम में लगाया जाए।

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
