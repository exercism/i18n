# निर्देशों का पूरक

## संकेत

आपको `responseFor` फंक्शन बनाना है, जो दिए गए इनपुट के लिए Bob का जवाब लौटाता है। अगर आपको टाइप के बारे में पक्का नहीं पता, तो आप दिए गए सिग्नेचर का इस्तेमाल कर सकते हैं, लेकिन इसे अपनी रचनात्मकता सीमित करने मत दीजिए:

```haskell
responseFor :: String -> String
```

इस अभ्यास को हल करने के लिए आप इनके बारे में पढ़ सकते हैं:

- [गार्ड][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

यह अभ्यास टेक्स्ट डेटा के साथ काम करता है। ऐतिहासिक कारणों से Haskell का `String` टाइप `[Char]` का पर्यायवाची है, यानी अक्षरों का एक ऐरे। टेक्स्ट डेटा को अधिक कुशलता से संभालने के लिए `Text` टाइप का उपयोग किया जा सकता है।

इस अभ्यास के एक वैकल्पिक विस्तार के तौर पर, आप ये कर सकते हैं:

- Haskell में [स्ट्रिंग टाइप](https://haskell-lang.org/tutorial/string-types) के बारे में पढ़िए।
- package.yaml में अपनी डिपेंडेंसी की सूची में `- text` जोड़ दीजिए।
- `Data.Text` को [इस तरीके से](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) इंपोर्ट कीजिए:

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- अब आप उदाहरण के लिए `responseFor :: Text -> Text` लिख सकते हैं और `Data.Text` के कॉम्बिनेटरों को, जैसे `T.isSuffixOf`, इस्तेमाल कर सकते हैं।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) का डॉक्युमेंटेशन देखिए,
- इसके बाद आप Bob.hs में हर जगह `String` की जगह `Text` लिख सकते हैं:

    ```haskell
    responseFor :: Text -> Text
    ```

यह हिस्सा पूरी तरह से वैकल्पिक है।
