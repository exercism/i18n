# परिचय

ऐरे Elixir भाषा में बिल्ट-इन होते हैं। इन्हें एक बुनियादी टाइप माना जाता है, जिन्हें चौकोर ब्रैकेट से दर्शाया जाता है। ऐरे खाली हो सकते हैं या किसी भी टाइप के कितने भी आइटम रख सकते हैं। उदाहरण के लिए:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir ऐरे को लिंक्ड लिस्ट के रूप में लागू करता है, जिसमें हर नोड दो वैल्यू रखता है: पहला आइटम और बाकी सारे आइटमों वाला एक और ऐरे। ऐरे के पहले आइटम को _हेड_ कहा जाता है और बाकी आइटमों वाले ऐरे को _टेल_ कहा जाता है। हम कोड में इस नोटेशन का इस्तेमाल कर सकते हैं:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

हम _`[head | tail]`_ नोटेशन का इस्तेमाल करके ऐरे में एलिमेंट शुरू में जोड़ सकते हैं:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

`Kernel` मॉड्यूल में ऐरे के साथ काम करने के लिए कई फंक्शन हैं, और पूरा `List` मॉड्यूल भी है।

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
