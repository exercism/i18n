# परिचय

कई भाषाओं में किसी अनुपस्थित वैल्यू को दिखाने के लिए `null` या `none` जैसा कोई तरीका होता है। Julia को बड़ी मात्रा में (अक्सर बेतरतीब) डेटा संभालने के लिए बनाया गया है, इसलिए इसमें कुछ न होने के कई रूप हैं।

इसका पूरा उद्देश्य यह है कि गायब या संदिग्ध वैल्यू सामने आते ही उन्हें चिह्नित किया जाए, और फिर बिना कोई एक्सेप्शन उठाए काम जारी रखा जाए।

## `nothing`

अगर कोई वैल्यू वाकई मौजूद नहीं है, तो उसे `nothing` से दिखाया जाता है। यह शायद उसके सबसे करीब है जो C (`NULL`) या Python (`None`) करते हैं।

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

तो `nothing`, `Nothing` टाइप की एक सिंगलटन वैल्यू है, और हम इसकी जाँच कर सकते हैं।

`nothing` का एक आम उपयोग ऐसे फंक्शनों के लिए रिटर्न वैल्यू (जो असल में कोई वैल्यू नहीं है) के रूप में होता है, जो सिर्फ अपने साइड इफेक्ट के लिए इस्तेमाल किए जाते हैं (प्रिंट करना, नेटवर्क कॉन्फ़िगर करना, या जो भी हो)।

## `missing`

ऐसी स्थितियों के लिए, जहाँ कोई वैल्यू सिद्धांत रूप में मौजूद है पर हमें पता नहीं कि वह क्या है, `missing` इस्तेमाल किया जाता है। जैसे, किसी सड़क पर चलने वाले वाहनों की गिनती करते समय हो सकता है कि मानव निरीक्षकों को विश्राम चाहिए हो या अपने आप चलने वाले सेंसर खराब हो जाएँ, लेकिन यातायात बहता रहता है।

इस तरह `missing` एक प्लेसहोल्डर है, जो मनुष्यों को चेतावनी देता है कि उन्हें तय करना है कि डेटा में इस कमी को कैसे संभाला जाए।

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

कुछ ही अन्य भाषाओं में यह सुविधा पहले से मौजूद है, लेकिन इसके करीबी समान हैं R में `NA` या SQL में `NULL`।

अगर `missing` वैल्यू मौजूद हैं, तो एक्सप्रेशन आम तौर पर डिफ़ॉल्ट रूप से `missing` लौटाते हैं। अगर आप चाहते हैं कि इन वैल्यूओं को नज़रअंदाज़ किया जाए, तो इसे स्पष्ट करने के लिए `skipmissing()` फंक्शन इस्तेमाल कीजिए:

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

चूँकि `skipmissing` एक इटरेटर बनाता है, अगर आपको वेक्टर चाहिए तो इसे `collect()` में लपेटिए।

कभी-कभी `missing` वैल्यूओं को किसी डिफ़ॉल्ट से बदलना काम का होता है। इसके लिए `@coalesce()` मैक्रो उपयोगी है, क्योंकि यह पहली गैर-`missing` वैल्यू लौटाता है (या `missing`, अगर और कुछ न हो)।

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

"Not a Number" का छोटा रूप, NaN उन स्थितियों में गणना की समस्या को चिह्नित करता है जहाँ एक संख्या की अपेक्षा थी।

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

NaN वाले डेटा पर किसी भी तरह की गणना का परिणाम `NaN` ही आएगा।

फ़िलहाल `NaN` वैल्यूओं को हटाने का कोई खास फंक्शन नहीं है, लेकिन मानक `filter()` फंक्शन यह बड़ी आसानी से कर सकता है। परिणाम वाले ऐरे में सिर्फ वही वैल्यू कॉपी की जाएँगी जिनके लिए दी गई शर्त `true` होती है:

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
