# परिचय

## क्यू

Gleam की स्टैंडर्ड लाइब्रेरी `gleam/queue` मॉड्यूल में एक `Queue` टाइप देती है। यह `List` टाइप जैसा ही है, लेकिन दोनों में कुछ खास अंतर हैं:

- `Queue` टाइप में ऐसा कोई लिटरल सिंटैक्स नहीं है जिससे क्यू बनाए जा सकें या उन पर पैटर्न मैच किया जा सके।
- `Queue` टाइप में एलिमेंट आगे और पीछे, दोनों तरफ से कुशलता से जोड़े और हटाए जा सकते हैं। `List` टाइप में यह सुविधा सिर्फ आगे से है।

ज़्यादातर मौकों पर आप `List` टाइप ही इस्तेमाल करना चाहेंगे। लेकिन जब आपको किसी कलेक्शन के अंत से एलिमेंट जोड़ने और हटाने की ज़रूरत पड़े, तो `Queue` टाइप अच्छा विकल्प है।

क्यू बनाने के लिए `queue.new` और `queue.from_list` फंक्शन इस्तेमाल किए जा सकते हैं:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

क्यू में एलिमेंट जोड़ने के लिए `queue.push_front` और `queue.push_back` फंक्शन इस्तेमाल किए जा सकते हैं:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

क्यू से एलिमेंट हटाने के लिए `queue.pop_front` और `queue.pop_back` फंक्शन इस्तेमाल किए जा सकते हैं:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

किसी क्यू को लिस्ट में बदलने के लिए `queue.to_list` फंक्शन इस्तेमाल किया जा सकता है:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### क्यू की समानता

क्यू को जिस तरह लागू किया गया है, उस वजह से ऐसा हो सकता है कि एक ही क्रम में एक ही एलिमेंट रखने वाले दो क्यू `==` ऑपरेटर के हिसाब से बराबर न हों। यह ऑपरेटर वैल्यू की संरचना के आधार पर तुलना करता है। उदाहरण:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

अगर आपको दो क्यू की समानता की तुलना करनी हो, तो `queue.is_logically_equal` फंक्शन इस्तेमाल कर सकते हैं।

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
