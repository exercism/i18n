# परिचय

Common Lisp में एक फंक्शन में नामित पैरामीटर हो सकते हैं (जिन्हें "कीवर्ड पैरामीटर" कहा जाता है)।
इन्हें लैम्ब्डा लिस्ट में `&key` लैम्ब्डा लिस्ट कीवर्ड द्वारा निर्दिष्ट किया जाता है।
कीवर्ड पैरामीटर आवश्यक पैरामीटर नहीं होते हैं।
वैकल्पिक पैरामीटर की तरह, इन्हें डिफॉल्ट वैल्यू दी जा सकती है और इनकी 'दिया गया है या नहीं' स्थिति को बाँधने के लिए सिंबल दिए जा सकते हैं।

कीवर्ड पैरामीटर वाले फंक्शन को कॉल करते समय पैरामीटर का नाम कीवर्ड के रूप में पैरामीटर वैल्यू के पहले लिखा जाता है।
फंक्शन को कॉल करने वाला कीवर्ड पैरामीटर किसी भी क्रम में दे सकता है।

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

वैकल्पिक और कीवर्ड पैरामीटर को मिलाते समय सावधानी बरतनी चाहिए, क्योंकि कीवर्ड नाम और आर्गुमेंट वैकल्पिक पैरामीटर द्वारा ले लिए जा सकते हैं:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
