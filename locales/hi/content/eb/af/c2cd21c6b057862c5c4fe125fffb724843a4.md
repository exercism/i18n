# बाइट्स के साथ रून इंडेक्स का उपयोग

इस मामले में `runes` पर इटरेशन करना और इंडेक्स से एक-एक `bytes` निकालना सुरक्षित है, क्योंकि इस इनपुट के सारे अक्षर ASCII हैं।

गैर-ASCII अक्षर इस्तेमाल करने पर क्या होता है, यह देखने के लिए यह टेस्ट केस जोड़िए:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
