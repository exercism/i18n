# अतिरिक्त निर्देश

## रजिस्टर

| रजिस्टर | उपयोग       | टाइप    | विवरण                                                 |
| -------- | ------------ | ------- | ----------------------------------------------------- |
| `$a0`    | इनपुट        | एड्रेस | null पर समाप्त होने वाली नाम स्ट्रिंग, या null पॉइंटर  |
| `$a1`    | इनपुट/आउटपुट | एड्रेस | null पर समाप्त होने वाली परिणाम स्ट्रिंग               |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए                                  |
