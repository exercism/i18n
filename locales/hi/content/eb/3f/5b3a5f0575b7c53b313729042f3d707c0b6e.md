# परिचय

Gleam में सही और गलत वैल्यू को `Bool` टाइप से दर्शाया जाता है। ऐसी सिर्फ़ दो वैल्यू हैं: `True` और `False`. इन वैल्यू को एक वेरिएबल में बाँधा जा सकता है:

```gleam
let true_variable = True
let false_variable = False
```

बूलियन वैल्यू पर काम करने के लिए `&&`, `||`, और `!` ऑपरेटरों का इस्तेमाल किया जा सकता है:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&` और `||` ऑपरेटर शॉर्ट सर्किट मूल्यांकन करते हैं, जिसका मतलब है कि ऑपरेटर के दाईं ओर वाला एक्सप्रेशन सिर्फ़ तभी मूल्यांकित किया जाता है जब उसकी ज़रूरत हो।

हर ऑपरेटर की प्राथमिकता अलग होती है: `!` का मूल्यांकन `&&` और `||` से पहले होता है। घुंघराले ब्रैकेट की मदद से एक्सप्रेशन के किसी एक हिस्से को बाकी हिस्सों से पहले मूल्यांकित किया जा सकता है:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
