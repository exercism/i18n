# इसके बारे में

Factor में अधिकांश इटरेशन कॉम्बिनेटर (`each`, `map`, `reduce`) से किया जाता है, लेकिन स्पष्ट रिकर्शन का भी अपना स्थान है: जब रिकर्शन ऐरे के आकार का न हो, जब बेस केस मामूली न हो, या जब आप खुद एक कॉम्बिनेटर बना रहे हों।

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

कुछ बातें जो जानना ज़रूरी है:

- साधारण `:` परिभाषाएँ बिना किसी खास सिंटैक्स के रिकर्शन कर सकती हैं। कंपाइलर रिकर्शन कॉल के आर-पार स्टैक इफेक्ट का अनुमान लगाता है।
- `loop ( quot -- )` आपको ऐसे कोटेशन का इटरेशन करने देता है जो बूलियन लौटाता है। जब तक बूलियन सही हो, तब तक चलते रहें।
- टेल कॉल को जंप में बदल दिया जाता है, इसलिए गहरे रिकर्शन वाले वर्ड स्टैक ओवरफ्लो नहीं करा देते।

`unclip` / `if-empty` जोड़ी मानक सीक्वेंस रिकर्शन आकार है। `cond` मानक बहु-केस डिस्पैच आकार है।
