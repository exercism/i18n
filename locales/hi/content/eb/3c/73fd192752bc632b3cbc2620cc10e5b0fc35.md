# परिचय

जब Elixir यह तय करता है कि किस फंक्शन को कॉल करना है, तो वह मॉड्यूल के नाम से खोज करता है। अगर मॉड्यूल का नाम किसी वेरिएबल से जुड़ा हो, तो यह खोज डायनामिक रूप से की जा सकती है।

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

अंदर से देखें तो मॉड्यूल का नाम एक ऐटम होता है। Elixir में हर मॉड्यूल ऐटम के आगे अपने आप `Elixir.` लग जाता है।

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
