# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप    | विवरण                                        |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | इनपुट सिक्कों की संख्या                       |
| `$a1`    | इनपुट        | पूर्णांक | लक्ष्य                                      |
| `$a2`    | इनपुट/आउटपुट | एड्रेस  | सिक्कों के शब्दों का ऐसा ऐरे जिसे बदला जा सके  |
| `$v0`    | आउटपुट       | पूर्णांक | आउटपुट सिक्कों की संख्या, इनपुट अमान्य होने पर -1 |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए इस्तेमाल होता है         |
