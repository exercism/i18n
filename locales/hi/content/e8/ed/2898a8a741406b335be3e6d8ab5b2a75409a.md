# परिचय

Factor में शर्तें **कोटेशन** के बीच चुनाव करती हैं। कोटेशन कोड के छोटे टुकड़े होते हैं, जो चौकोर ब्रैकेट में लिखे जाते हैं, `[ ... ]`। जब आप `[ ... ]` लिखते हैं, तो वह कोड चलने के बजाय स्टैक पर एक वैल्यू के रूप में रखा जाता है। इसके बाद शर्त तय करती है कि कौन-सा कोटेशन चलाना है। (कोटेशन के बारे में पूरी जानकारी आगे के एक अभ्यास में मिलेगी।)

`if` ([`kernel`][kernel] में) Factor की सबसे बुनियादी शर्त है। यह एक बूलियन और दो कोटेशन लेती है। अगर बूलियन सही है तो यह पहला कोटेशन चलाती है, और वरना दूसरा।

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` अपना कोटेशन तभी चलाता है जब बूलियन सही हो, और `unless` तभी जब वह गलत हो। कई शाखाओं वाले चुनाव के लिए `cond` है ([`combinators`][combinators] में):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
