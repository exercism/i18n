# निर्देश परिशिष्ट

## कार्यान्वयन

यदि ऐरे का अंतिम एलिमेंट `string` के बजाय `object` हो, तो उसमें एक क्वालिफायर होगा। यह क्वालिफायर कहावत की अंतिम पंक्ति को बदल देता है।

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
