# इसके बारे में

Rust में बूलियन को `bool` टाइप से दर्शाया जाता है, और इसकी वैल्यू या तो `true` हो सकती है या `false`।

Rust एक [बूलियन नेगेशन ऑपरेटर][negation operators] का समर्थन करता है: `!` (नहीं)।

Rust छह [तुलना ऑपरेटर][comparison operators] का समर्थन करता है: `==` (बराबर), `!=` (बराबर नहीं), `>` (से बड़ा), `<` (से छोटा), `>=`
(से बड़ा या बराबर), `<=` (से छोटा या बराबर)। इनकी मदद से गैर-बूलियन वैल्यूओं के आपसी संबंध का मूल्यांकन करके एक बूलियन वैल्यू पाई जा सकती है।

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

कुछ दूसरी भाषाओं के उलट, Rust में `0` का मतलब `false` नहीं है और शून्य के अलावा किसी संख्या का मतलब `true` नहीं होता।

Rust तीन [लॉजिकल बाइनरी ऑपरेटर][logical binary operators] का समर्थन करता है: `&` (लॉजिकल ऐंड), `|` (लॉजिकल ऑर), `^` (लॉजिकल एक्सऑर)।

Rust दो [बूलियन ऑपरेटर][lazy boolean operators] का समर्थन करता है: `||` (ऑर), `&&` (ऐंड)। ये `|` और `&` से इस तरह अलग हैं कि इनमें दाईं ओर के ऑपरेंड का मूल्यांकन तभी होता है जब बाईं ओर का ऑपरेंड एक्सप्रेशन का परिणाम पहले से तय न कर चुका हो। यानी `||` अपने दाईं ओर के ऑपरेंड का मूल्यांकन तभी करता है जब बाईं ओर के ऑपरेंड की वैल्यू `false` हो, और `&&` तभी करता है जब बाईं ओर के ऑपरेंड की वैल्यू `true` हो।

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
