# परिचय

## Try/Rescue/Else/After

एरर होने पर उन्हें पकड़ने के लिए `try..rescue` एक शक्तिशाली तरीका है। एरर पकड़ने से फंक्शन ज़रूरत पड़ने पर तय वैल्यू लौटा पाते हैं। `try..rescue` तरीका हमें दो और फीचर भी देता है, जिनका हम इस्तेमाल कर सकते हैं:

- `else` ब्लॉक
  - जब try ब्लॉक सफल होता है, तो उसका परिणाम इस ब्लॉक से मिलाया जाता है।
- `after` ब्लॉक
  - चाहे try ब्लॉक सफल हो या एरर उठाए, `after` ब्लॉक का कोड हमेशा चलाया जाता है, बशर्ते उस समय प्रोग्राम चल रहा हो।
  - `after` ब्लॉक का परिणाम कॉल करने वाले स्कोप को नहीं लौटाया जाता।

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## डायनैमिक डिस्पैच

जब Elixir तय करता है कि कौन-सा फंक्शन कॉल किया जाएगा, तो वह इसके लिए मॉड्यूल के नाम का इस्तेमाल करता है। अगर मॉड्यूल का नाम किसी वेरिएबल से जुड़ा हो, तो यह खोज डायनैमिक रूप से की जा सकती है।

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

अंदर से देखें तो मॉड्यूल का नाम एक एटम होता है। Elixir के सभी मॉड्यूल एटम के आगे अपने-आप `Elixir.` जुड़ जाता है।

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
