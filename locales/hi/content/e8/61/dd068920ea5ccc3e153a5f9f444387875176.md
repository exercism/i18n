# परिचय

एक [`while` लूप][while-loops] एक कंट्रोल फ्लो स्टेटमेंट है, जिसकी मदद से कोड तब तक चलाया जा सकता है जब तक कोई शर्त सही बनी रहती है।
Swift में दो तरह के लूप होते हैं: `while` लूप और `repeat-while` लूप।
`while` लूप की शर्त लूप के अंदर का कोड चलने से पहले जाँची जाती है। अगर शर्त गलत है, तो लूप के अंदर का कोड एक बार भी नहीं चलेगा।
Swift में `while` लूप की संरचना इस तरह होती है:

```swift
while <#condition#> {
  <#code#>
}
```

यहाँ लूप तब तक चलता रहेगा जब तक count 0 से बड़ा है, और इस तरह यह 2, 1 और "Liftoff!" छापेगा।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

एक [`repeat-while` लूप][while-loops] `while` लूप जैसा ही होता है, लेकिन इसमें शर्त लूप के अंदर का कोड चलने के बाद जाँची जाती है।
इसका मतलब है कि लूप के अंदर का कोड कम से कम एक बार तो चलेगा ही, भले ही शर्त गलत हो।
Swift में `repeat-while` लूप की संरचना इस तरह होती है:

```swift
repeat {
  <#code#>
} while <#condition#>
```

यहाँ शर्त गलत है, इसलिए लूप सिर्फ एक बार चलेगा।
चूँकि यह `repeat-while` लूप है, लूप के अंदर का कोड शर्त जाँचे जाने से पहले एक बार चलेगा।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## ऑप्शनल बाइंडिंग लूप

Swift में `while` लूप का एक आम रूप ऑप्शनल बाइंडिंग वाला `while` लूप है।
ऐसे लूप तब तक दोहराए जाते हैं जब तक किसी ऐसे फंक्शन को कॉल करने पर, जो ऑप्शनल वैल्यू लौटाता है, `nil` के अलावा कोई वैल्यू मिलती रहती है।
उस (गैर-ऑप्शनल) वैल्यू को फिर आप अपनी पसंद के नाम से बाँध सकते हैं और लूप के अंदर उसका उपयोग कर सकते हैं।

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
