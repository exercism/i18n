# निर्देश

IOU का हिसाब रखने के लिए एक RESTful API बनाइए।

एक ही कमरे में रहने वाले चार साथी अक्सर एक-दूसरे से पैसे उधार लेते रहते हैं और उन्हें यह याद रखने में परेशानी होती है कि कौन किसको कितना पैसा देना है।

आपको एक सरल [RESTful API][restful-wikipedia] बनाना है, जो POST रिक्वेस्ट के रूप में [IOU][iou] लेता है और GET रिक्वेस्ट के ज़रिए बताई गई जानकारी का सारांश दे सकता है।

## API स्पेसिफिकेशन

### यूज़र ऑब्जेक्ट

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### मेथड

| विवरण                    | HTTP मेथड  | URL    | पेलोड फॉर्मेट                                                             | पेलोड के बिना रिस्पॉन्स                | पेलोड के साथ रिस्पॉन्स                                                           |
| ------------------------ | ----------- | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| यूज़र जानकारी की सूची     | GET         | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| यूज़र बनाना               | POST        | /add   | `{"user":<name of new user (unique)>}`                                    | लागू नहीं                              | `<User object for new user>`                                                    |
| IOU बनाना                | POST        | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | लागू नहीं                              | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
