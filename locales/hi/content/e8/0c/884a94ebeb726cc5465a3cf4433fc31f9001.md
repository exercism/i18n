# परिचय

## शर्तें If

### लॉजिकल ऑपरेटर

Java तीन लॉजिकल ऑपरेटर का समर्थन करता है: `&&` (AND), `||` (OR) और `!` (NOT)।

### `if` स्टेटमेंट

किसी भी शर्त वाले ऑपरेशन का मूल डेटा टाइप `boolean` होता है, जिसकी वैल्यू `true` या `false` हो सकती है। शर्तों का इस्तेमाल अक्सर फ्लो कंट्रोल के लिए किया जाता है। इससे अलग-अलग शर्तों की जाँच की जा सकती है। किसी खास मामले की जाँच के लिए `if` स्टेटमेंट का इस्तेमाल किया जा सकता है। अगर अंदर की शर्त `true` हो, तो यह अपना कोड चलाता है, जैसे:

```java
int val;

if(val == 9) {
    // conditional code
}
```

जब एक से अधिक मामले सामने हों, तो कई `if` स्टेटमेंट को `else if` और `else` स्टेटमेंट की मदद से एक साथ जोड़ा जा सकता है।

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### `switch` स्टेटमेंट

Java में कई विकल्पों वाली स्थितियों के लिए `switch` स्टेटमेंट भी होता है।

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
