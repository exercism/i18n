# परिचय

## Agent

`Agent` मॉड्यूल [प्रोसेस और _रिसीव-सेंड_ लूप][exercism-processes] को शुरू करने के लिए एक एब्स्ट्रैक्शन देता है। आगे हम `Agent` मॉड्यूल से शुरू किए गए प्रोसेस को _'एजेंट प्रोसेस'_ कहेंगे। एक _एजेंट प्रोसेस_ को केंद्रीय साझा स्थिति दर्शाने के लिए चुना जा सकता है।

_एजेंट प्रोसेस_ शुरू करने के लिए `Agent` `start/2` फंक्शन देता है। `start` से _एजेंट प्रोसेस_ शुरू करते समय दिया गया फंक्शन प्रोसेस की आरंभिक स्थिति लौटाता है:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map` या `List` की तरह, `Agent` _एजेंट प्रोसेस_ के साथ काम करने के लिए कई फंक्शन देता है।

जिस डोमेन का मॉडल बनाया जा रहा है, उसके लिए `Agent` से जुड़ी सारी कार्यक्षमता को एक मॉड्यूल में व्यवस्थित करना और एनकैप्सुलेट करना आम बात है।

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
