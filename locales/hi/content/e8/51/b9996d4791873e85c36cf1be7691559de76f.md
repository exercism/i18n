# शेषफल

गणित में, किसी गणना को करने के बाद जो मात्रा "बच जाती" है, उसे **शेषफल** कहते हैं।
उदाहरण के लिए, `5 / 3` का शेषफल `2` है।

कई प्रोग्रामिंग भाषाएँ शेषफल निकालने के लिए प्रतिशत चिह्न (`%`) को एक ऑपरेटर की तरह इस्तेमाल करती हैं।
उदाहरण के लिए:
```javascript
5 % 3 == 2
```

शेषफल अक्सर पूर्णांक और दशमलव संख्याओं, दोनों पर निकाला जा सकता है।
उदाहरण के लिए,
```javascript
5.3 % 3 == 2.3
```

ऋणात्मक संख्याओं के साथ काम करते समय परिणाम का चिह्न हमेशा भाज्य के चिह्न जैसा ही होता है (भाज्य यानी बाईं ओर की वह संख्या जिसे भाग दिया जा रहा है)।
उदाहरण के लिए:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

कुछ भाषाएँ (जैसे Python) `%` ऑपरेटर का उपयोग शेषफल नहीं, बल्कि मॉड्यूलस निकालने के लिए करती हैं।
इसमें ऋणात्मक संख्याओं के साथ व्यवहार अलग होता है।
इस बारे में आप [Wikipedia पर](https://en.wikipedia.org/wiki/Modulo) और जान सकते हैं।
