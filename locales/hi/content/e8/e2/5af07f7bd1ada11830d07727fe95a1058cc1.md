# निर्देश

इस अभ्यास में आपको प्रोग्रामिंग भाषाओं के ऐरे पर काम करने वाले कुछ फंक्शन बनाने हैं।

## 1. भाषाओं का खाली ऐरे लौटाने वाला फंक्शन बनाइए

`new/0` फंक्शन बनाइए जो कोई आर्गुमेंट नहीं लेता और एक खाली ऐरे लौटाता है।

```elixir
LanguageList.new()
# => []
```

## 2. भाषाओं के ऐरे में एक भाषा जोड़ने वाला फंक्शन बनाइए

`add/2` फंक्शन बनाइए जो 2 आर्गुमेंट लेता है (एक _भाषाओं का ऐरे_ और _भाषा_ का स्ट्रिंग लिटरल)। इसे दिए गए ऐरे के सबसे आगे नई भाषा जोड़कर बनने वाला ऐरे लौटाना चाहिए।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. भाषाओं के ऐरे से एक भाषा हटाने वाला फंक्शन बनाइए

`remove/1` फंक्शन बनाइए जो 1 आर्गुमेंट (_भाषाओं का ऐरे_) लेता है। इसे पहले एलिमेंट के बिना वाला ऐरे लौटाना चाहिए। मान लीजिए कि ऐरे में हमेशा कम से कम एक एलिमेंट रहेगा।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. भाषाओं के ऐरे का पहला एलिमेंट लौटाने वाला फंक्शन बनाइए

`first/1` फंक्शन बनाइए जो 1 आर्गुमेंट (_भाषाओं का ऐरे_) लेता है। इसे ऐरे की पहली भाषा लौटानी चाहिए। मान लीजिए कि ऐरे में हमेशा कम से कम एक एलिमेंट रहेगा।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. भाषाओं के ऐरे में कितनी भाषाएँ हैं, यह लौटाने वाला फंक्शन बनाइए

`count/1` फंक्शन बनाइए जो 1 आर्गुमेंट (_भाषाओं का ऐरे_) लेता है। इसे ऐरे में मौजूद भाषाओं की संख्या लौटानी चाहिए।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. यह पता लगाने वाला फंक्शन बनाइए कि भाषाओं के ऐरे में कोई फंक्शनल भाषा है या नहीं

`functional_list?/1` फंक्शन बनाइए जो 1 आर्गुमेंट (_भाषाओं का ऐरे_) लेता है। इसे एक बूलियन वैल्यू लौटानी चाहिए। अगर _"Elixir"_ ऐरे की भाषाओं में से एक है, तो इसे सही लौटाना चाहिए।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
