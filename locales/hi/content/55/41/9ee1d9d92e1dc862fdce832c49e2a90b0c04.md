# परिचय

## नेस्टेड टाइप

C# टाइप को किसी क्लास या स्ट्रक्ट के स्कोप के अंदर परिभाषित किया जा सकता है। बाहरी टाइप एक तरह का नेमस्पेस प्रदान करता है। टाइप तक पहुँच बाहरी टाइप के माध्यम से डॉट सिंटैक्स के साथ होती है।

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

आप अंदरूनी टाइप के लिए एक्सेस लेवल सेट कर सकते हैं।

बाहरी टाइप के प्राइवेट मेंबर अंदरूनी टाइप के मेंबर के लिए स्कोप में होते हैं, लेकिन इसका उल्टा नहीं।
