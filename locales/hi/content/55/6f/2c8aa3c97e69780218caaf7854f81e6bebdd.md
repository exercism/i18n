# ऐरे

PHP में ऐरे क्रमबद्ध मैप होते हैं।
मैप एक ऐसी डेटा संरचना है जो हर की को एक वैल्यू से जोड़ती है।
ऐरे बहुत लचीले होते हैं और इन्हें एक रैखिक ऐरे (`C` या `Java` की तरह), लिस्ट [वेक्टर], हैश-टेबल, डिक्शनरी, कलेक्शन, स्टैक या क्यू के रूप में भी इस्तेमाल किया जा सकता है।

की देना ज़रूरी नहीं है, लेकिन अगर दी जाए तो वह `int` या `string` ही होनी चाहिए।
जब कोई की नहीं दी जाती, तो PHP अपने आप बढ़ते क्रम में पूर्णांक की बनाता है, जो `0` से शुरू होती हैं।

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

एक ऐरे हर तरह की वैल्यू रख सकता है।
हर वैल्यू का टाइप अलग हो सकता है।

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## ऐरे का उपयोग

ऐरे को लिटरल के रूप में घोषित किया जा सकता है (यानी कोड में सीधे लिखकर, जैसा ऊपर किया गया है), या फिर फंक्शन की मदद से बनाया और बदला जा सकता है।

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

इंडेक्स ऑपरेटर से वैल्यू ऐक्सेस कीजिए, असाइन कीजिए और ऐरे के अंत में जोड़िए:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

foreach की मदद से ऐरे पर इटरेशन कीजिए:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
