# परिचय

किसी मेथड के पैरामीटर को डिफॉल्ट वैल्यू असाइन करके वैकल्पिक बनाया जा सकता है। वैकल्पिक पैरामीटर वाले मेथड को कॉल करते समय कॉल करने वाले को उन पैरामीटर के लिए कोई वैल्यू पास करना ज़रूरी नहीं होता। अगर किसी वैकल्पिक पैरामीटर के लिए कोई वैल्यू पास नहीं की जाती, तो उसकी डिफॉल्ट वैल्यू इस्तेमाल की जाती है।

वैकल्पिक पैरामीटर _अवश्य_ पैरामीटर सूची के अंत में होने चाहिए। उनके बाद ऐसे पैरामीटर नहीं हो सकते जो वैकल्पिक न हों।

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
