# परिचय

Ruby एक डायनामिक [ऑब्जेक्ट-ओरिएंटेड भाषा][object-oriented-programming] है।
Ruby में हर चीज़ एक [ऑब्जेक्ट][object] है।

Ruby में किसी ऑब्जेक्ट को नाम देने के दो मुख्य तरीके हैं: वेरिएबल या स्थिरांक इस्तेमाल करना।
वेरिएबल हमेशा [स्नेक केस][snake-case] में लिखे जाते हैं।
एक वेरिएबल अपने जीवनकाल में अलग-अलग ऑब्जेक्ट को दर्शा सकता है।
उदाहरण के लिए, `=` ऑपरेटर की मदद से `my_first_variable` को कई बार बनाया और दोबारा बनाया जा सकता है:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

लेकिन स्थिरांक सिर्फ एक बार असाइन करने के लिए होते हैं।
इनकी शुरुआत बड़े अक्षरों से होनी चाहिए, और आम तौर पर इन्हें पूरी तरह बड़े अक्षरों में लिखा जाता है, जिसमें शब्दों को अंडरस्कोर से अलग किया जाता है।

उदाहरण के लिए:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby का कोड क्लासों में व्यवस्थित रहता है।
क्लास को `class` कीवर्ड से बनाया जाता है, जिसके बाद क्लास का नाम लिखा जाता है।
ऑब्जेक्ट आम तौर पर `.new` मेथड से क्लास का इंस्टेंस बनाकर तैयार किए जाते हैं।

उदाहरण के लिए:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

कार्यक्षमता की इकाइयों को मेथड में एनकैप्सुलेट किया जाता है, जो दूसरी भाषाओं के _फंक्शन_ जैसे होते हैं।
मेथड को चाहें तो पोज़िशनल आर्गुमेंट के साथ बनाया जा सकता है, और/या कीवर्ड आर्गुमेंट के साथ भी, जिन्हें `:` सिंटैक्स से बनाया और कॉल किया जाता है।
मेथड या तो सबसे अंत में मूल्यांकित हुए स्टेटमेंट का परिणाम अपने आप लौटा देता है, या `return` कीवर्ड से स्पष्ट रूप से कोई ऑब्जेक्ट लौटा सकता है।
मेथड को `.` सिंटैक्स से कॉल किया जाता है।

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
