# परिचय

फंक्शन में डिफॉल्ट रूप से एक्सटर्नल लिंकेज होता है। इन्हें प्रोजेक्ट की किसी भी दूसरी फाइल से कॉल किया जा सकता है।
लिंकेज के बारे में अधिक जानने के लिए [लिंकेज कॉन्सेप्ट](../linkage/introduction.md#Introduction) देखिए।
`static` फंक्शन को सिर्फ उसी सोर्स फाइल के अंदर कॉल किया जा सकता है जिसमें इसे बनाया गया है।

उदाहरण के लिए

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```

अगर किसी फंक्शन को हेडर में घोषित किया गया हो, तो भी अगर उसे `static` के रूप में बनाया गया हो, तो उसे उसकी सोर्स फाइल के बाहर से कॉल नहीं किया जा सकेगा।
एक सोर्स फाइल उस हेडर को शामिल कर सकती है, हेडर में घोषित उस `static` फंक्शन को कॉल कर सकती है, और कंपाइल भी हो सकती है। लेकिन लिंकर को `static` फंक्शन की परिभाषा नहीं मिल पाएगी।
किसी सोर्स फाइल में `static` के रूप में चिह्नित फंक्शन को उसकी हेडर फाइल में घोषित नहीं करना चाहिए।
