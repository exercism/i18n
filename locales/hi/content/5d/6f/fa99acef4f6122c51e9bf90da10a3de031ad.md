# टेस्ट चलाइए

## अभ्यास डाउनलोड कीजिए

जिस अभ्यास पर आप काम करना चाहते हैं, उसे डाउनलोड करने के लिए [Exercism CLI][cli] का इस्तेमाल कीजिए।

```sh
exercism download --track=dart --exercise=hello-world
```

इसके बाद अभ्यास की डायरेक्टरी में जाइए।

```sh
cd /path/to/exercism/dart/hello-world
```

## डिपेंडेंसी इंस्टॉल कीजिए

टेस्ट चलाने से पहले अभ्यास की डिपेंडेंसी डाउनलोड कीजिए।

```sh
dart pub get
```

## टेस्ट चलाइए

```sh
dart test
```

## टेस्ट के परिणाम समझिए

`dart test` डिफ़ॉल्ट रूप से कॉम्पैक्ट रिपोर्टर इस्तेमाल करता है, जो पास हुए, छोड़े गए और फेल हुए टेस्ट की चलती हुई गिनती एक ही लाइन में दिखाता है।

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
```

- `~9`, यानी 9 टेस्ट छोड़े गए

## टेस्ट एक-एक करके पूरे कीजिए

ज़्यादातर अभ्यासों में कई टेस्ट होते हैं, और पहले वाले को छोड़कर बाकी सब डिफ़ॉल्ट रूप से छोड़े हुए रहते हैं।

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

टेस्ट एक-एक करके पूरे करने के लिए, हर टेस्ट में `skip: true` को `skip: false` में बदलते जाइए।
या फिर, फाइल में कुछ बदले बिना सारे टेस्ट एक साथ चलाइए।

```sh
dart test --run-skipped
```

सबमिट करते समय ऑनलाइन टेस्ट रनर सारे टेस्ट चलाता है, छोड़े हुए टेस्ट भी।

## एरर "Could not find a command named frontend_server.dart.snapshot" को संभालना

मान लीजिए कि आपने कोई अभ्यास पहले ही हल करके सबमिट कर दिया है और कुछ समय बाद आप उस पर फिर लौट रहे हैं।
जब आप उसे टेस्ट करते हैं, तो आपको यह एरर मिल सकती है:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

इसका [समाधान][solution] यह है कि `pubspec.lock` फाइल हटा दीजिए।
इसके बाद dart कमांड फिर से चलाइए।

[solution]: https://stackoverflow.com/q/79247335/7552
