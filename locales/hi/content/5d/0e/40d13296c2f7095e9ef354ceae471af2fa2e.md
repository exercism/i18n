# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप    | विवरण                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | एड्रेस  | नल पर समाप्त होने वाला वाक्यांश |
| `$a1`    | इनपुट/आउटपुट | एड्रेस  | नल पर समाप्त होने वाली परिणाम स्ट्रिंग |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए          |
