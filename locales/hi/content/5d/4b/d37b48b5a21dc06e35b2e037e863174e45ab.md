# परिचय

JavaScript का ऐरे डिस्ट्रक्चरिंग सिंटैक्स ऐरे से वैल्यू निकालकर उन्हें अलग-अलग वेरिएबलो में असाइन करने का एक संक्षिप्त तरीका है।

इस उदाहरण में, `numberOfMoons` ऐरे की हर वैल्यू उससे जुड़े ग्रह को असाइन की जाती है:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
