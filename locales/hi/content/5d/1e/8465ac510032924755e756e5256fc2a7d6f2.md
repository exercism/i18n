# परिचय

PHP में कोवेरिएंस और कॉन्ट्रावेरिएंस की अवधारणाएँ महत्वपूर्ण हैं, क्योंकि क्लास या इंटरफेस का विस्तार करते समय PHP इन नियमों का पालन करवाता है।

कोवेरिएंस दो टाइप के बीच का संबंध बनाए रखता है, जबकि कॉन्ट्रावेरिएंस उस संबंध को उलट देता है। संक्षेप में, इसका मतलब यह है कि क्लास का विस्तार करते समय और फंक्शन ओवरराइड करते समय आप अपने मेथड के पैरामीटर के लिए अधिक या कम विशिष्ट टाइप की अनुमति दे सकते हैं। इसी तरह मेथड से आप कम या अधिक विशिष्ट टाइप लौटा सकते हैं।

## उदाहरण

इस क्लास को देखिए:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

अगर हम क्लास का विस्तार करें, तो हम मूल रूप से घोषित टाइप से अधिक पैरामीटर टाइप की अनुमति दे सकते हैं, लेकिन मूल रिटर्न टाइप के अलावा कुछ और लौटा नहीं सकते।

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

नीचे दी गई विस्तारित क्लास मान्य नहीं है, क्योंकि अतिरिक्त या अधिक व्यापक टाइप लौटाने की अनुमति नहीं है:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
