# परिचय

## टपल

Elixir में टपल एक डेटा स्ट्रक्चर है जो डेटा को व्यवस्थित करता है। इसमें किसी भी प्रकार की एक तय संख्या में चीज़ें रखी जा सकती हैं, लेकिन हर एलिमेंट के लिए कोई अलग नाम नहीं होता। Elixir में टपल का इस्तेमाल अक्सर ऐसे कामों के लिए किया जाता है जिनमें मेमोरी से बहुत पढ़ना पड़ता है, क्योंकि किसी एलिमेंट को पढ़ने में लगने वाला समय हर बार एक जैसा रहता है। इनका इस्तेमाल आम तौर पर ऐसे मामलों में नहीं होता जहाँ एलिमेंट जोड़ने या हटाने की ज़रूरत बार-बार पड़े, क्योंकि मौजूदा टपल को बदलने के बजाय एक नया टपल बनाया जाता है, और उसके लिए पहले से मेमोरी आवंटित करनी पड़ती है।

व्यवहार में, Elixir में टपल घुंघराले ब्रैकेट से बनाए जाते हैं। टपल के एलिमेंट को `elem/2` फंक्शन से अलग-अलग पढ़ा जा सकता है, जहाँ इंडेक्स 0 से शुरू होता है:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### समूहित जानकारी के रूप में टपल

व्यवहार में टपल का इस्तेमाल अक्सर जानकारी को एक समूह के रूप में दिखाने के लिए किया जाता है।

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## पैटर्न मैचिंग

Elixir में जो कोड आत्मविश्वास के साथ और भाषा की अपनी शैली में लिखा जाता है, उसमें पैटर्न मैचिंग का बहुत इस्तेमाल होता है। आपको याद होगा कि `=/2` को असाइनमेंट ऑपरेटर नहीं, बल्कि मैच ऑपरेटर कहा जाता है। मैच ऑपरेटर इस्तेमाल करते समय, अगर बाईं ओर का पैटर्न दाईं ओर से मेल खाता है, तो बाईं ओर के वेरिएबलो को बाँध दिया जाता है और दाईं ओर की वैल्यू लौटा दी जाती है। अगर मेल नहीं खाता, तो एक `MatchError` मिलती है।

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

याद रखिए, मैच दाईं ओर से बाईं ओर की तरफ होते हैं।

पिछले उदाहरण में, अगर पैटर्न मैच में किसी वेरिएबल की ज़रूरत नहीं है, तो हम `_` लिखकर उसे छोड़ सकते हैं। जो भी वेरिएबल `_` से शुरू होता है, रनटाइम उसका हिसाब नहीं रखता।

### नेम्ड फंक्शन में पैटर्न मैचिंग

कई फंक्शन क्लॉज़ बनाते समय पैटर्न मैचिंग भी बहुत काम की चीज़ है। पैटर्न मैचिंग का इस्तेमाल फंक्शन के आर्गुमेंट पर किया जा सकता है, और इससे तय होता है कि कौन-सा फंक्शन क्लॉज़ कॉल किया जाएगा। यह फाइल में सबसे ऊपर से शुरू होकर नीचे की ओर चलता है, जब तक पहला मैच न मिल जाए। वेरिएबलो को फंक्शन हेड में बाँधा जा सकता है और फंक्शन बॉडी में इस्तेमाल किया जा सकता है।

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
