# परिचय

## नेमस्पेस

कोड को व्यवस्थित करने का एक ज़रूरी तरीका नेमस्पेस का इस्तेमाल है।
दो फंक्शन के नाम टकरा सकते हैं। इसे उन्हें अलग-अलग नेमस्पेस में रखकर हल किया जा सकता है।
नेमस्पेस को नेस्टेड भी किया जा सकता है, जिससे बड़े कोड बेस को व्यवस्थित करने में मदद मिल सकती है।
नेमस्पेस तक पहुँचने के लिए स्कोप-रेज़ोल्यूशन ऑपरेटर `::` इस्तेमाल किया जाता है।

नीचे दिया गया उदाहरण दो अलग-अलग `foo` फंक्शन का इस्तेमाल दिखाता है।
इन्हें एक साथ इस्तेमाल करने के लिए हर फंक्शन के आगे उसका अपना नेमस्पेस लिखा जाता है।

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
