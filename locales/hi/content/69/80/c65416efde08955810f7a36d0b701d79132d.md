# इंस्टॉलेशन

Reason इंस्टॉल करने के लिए आपको Node Package Manager (npm) चाहिए। [यहाँ](https://www.npmjs.com/get-npm) दिए गए निर्देशों का पालन कीजिए।

npm इंस्टॉल हो जाने के बाद, Reason को इस तरह इंस्टॉल कीजिए:
```
npm install -g bs-platform
```

Reason कई एडिटर के साथ मिलकर काम करता है। [यहाँ](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors) देखिए।

कुछ कमांड लाइन टूल (जिनमें एक REPL भी शामिल है, जिससे आप शेल में Reason एक्सप्रेशन का मूल्यांकन कर सकते हैं) [यहाँ](https://github.com/reasonml/reason-cli) मिल जाएँगे।
