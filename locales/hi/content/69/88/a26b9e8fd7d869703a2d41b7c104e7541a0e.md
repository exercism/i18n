# `for` लूप के बारे में

[`for` लूप](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) एक ऐसा तरीका देता है जिससे स्टेटमेंट के एक समूह को बार-बार चलाया जा सकता है, जब तक कोई शर्त पूरी न हो जाए।
यह लूप चार हिस्सों से मिलकर बना होता है:

```java
for (initialization; test; update) {
    body;
}
```

`initialization` लूप की शुरुआती स्थिति तय करता है। यह लूप की शुरुआत में ठीक एक बार चलता है।
आम तौर पर यह वह वेरिएबल घोषित और असाइन करता है जिसका उपयोग `test` एक्सप्रेशन और `update` स्टेटमेंट में होता है।
उदाहरण:

```java
int i = 1
```

`test` एक्सप्रेशन जाँचता है कि लूप खत्म होना चाहिए या नहीं।
अगर यह सही निकलता है, तो पहले लूप के अंदर का कोड चलता है और उसके बाद `update` एक्सप्रेशन।
अगर यह गलत निकलता है, तो न लूप के अंदर का कोड चलता है और न ही `update` स्टेटमेंट, और लूप का ब्रैकेट बंद होने के बाद कोड फिर से चलने लगता है।
आम तौर पर यह उस वेरिएबल की जाँच करता है जिसे लूप की शुरुआत में असाइन किया गया था।
उदाहरण:

```java
i <= 10
```

लूप के अंदर का कोड चल जाने के बाद `update` एक्सप्रेशन चलता है।
आम तौर पर यह लूप वेरिएबल को किसी वैल्यू से बढ़ाता या घटाता है।
उदाहरण:

```java
i++
```

पहले चार वर्ग छापने वाला `for` लूप ऐसा दिखेगा:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

अगर किसी कलेक्शन के हर एलिमेंट पर एक-एक करके चलना हो, तो `for-each` लूप बेहतर रहता है, लेकिन यह काम `for` लूप से भी ऐसे किया जा सकता है:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for` लूप में `for-each` लूप की तुलना में कुछ फायदे भी होते हैं:

- आप अपनी पसंद के इंडेक्स से शुरू या बंद कर सकते हैं।
- आप कोई भी (बूलियन) खत्म करने वाली शर्त इस्तेमाल कर सकते हैं।
- लूप वेरिएबल को बढ़ाने का तरीका बदलकर आप कुछ एलिमेंट छोड़ सकते हैं।
- उलटी गिनती करके आप कलेक्शन के एलिमेंट पर पीछे से आगे की ओर काम कर सकते हैं।
- आप `for` लूप ऐसी जगहों पर भी इस्तेमाल कर सकते हैं जहाँ कलेक्शन नहीं होते।
