# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जिसे इस तरह लिखा जाता है: `"[<LEVEL>]: <MESSAGE>"`।

लॉग लेवल तीन तरह के होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके पास तीन काम हैं। हर काम एक लॉग लाइन लेता है और आपसे उसके साथ कुछ करने को कहता है।

## 1. लॉग लाइन से संदेश निकालिए

लॉग लाइन का संदेश लौटाने के लिए `message` फंक्शन बनाइए:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

शुरू और अंत का कोई भी व्हाइटस्पेस हटा देना चाहिए:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

लॉग लाइन का लॉग लेवल लौटाने के लिए `log_level` फंक्शन बनाइए। यह लॉग लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. लॉग लाइन का ढाँचा बदलिए

लॉग लाइन का ढाँचा बदलने वाला `reformat` फंक्शन बनाइए, जिसमें संदेश पहले आता है और उसके बाद लॉग लेवल कोष्ठक में दिया जाता है:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
