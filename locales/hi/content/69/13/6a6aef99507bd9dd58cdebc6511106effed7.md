# निर्देश

इस अभ्यास में आप कुछ कोड लिखेंगे जो Larry the Lisp Alien को लॉग स्ट्रिंग पार्स करने और फॉर्मैट करने में मदद करेगा। ये लॉग स्ट्रिंग अलग-अलग सिस्टम से आती हैं, और इन्हें इस तरह संसाधित करना होता है कि इनके संदेश किसी जानकारीपूर्ण मॉनिटरिंग डिस्प्ले पर दिखाए जा सकें।

लॉग स्ट्रिंग इस रूप में होती हैं: `"[<level>]: <message>"`. लेवल इनमें से कोई एक वैल्यू होता है: `info`, `warn`, या `ohno`.

## 1. संदेश निकालिए

एक फंक्शन `log-message` बनाइए जो एक लॉग स्ट्रिंग लेता है और उसमें मौजूद संदेश लौटाता है।

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. गंभीरता तय कीजिए

लॉग स्ट्रिंग का लेवल उसकी गंभीरता तय करता है।

- `info` लेवल का मतलब है `:everything-ok` गंभीरता
- `warn` लेवल का मतलब है `:getting-worried` गंभीरता
- `ohno` लेवल का मतलब है `:run-for-cover` गंभीरता

एक फंक्शन `log-severity` बनाइए जो एक लॉग स्ट्रिंग लेता है और सही गंभीरता लौटाता है।

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. वास्तविकता की अनिश्चितताओं से निपटना

दुर्भाग्य से कभी-कभी लॉग स्ट्रिंग हमेशा सही तरीके से फॉर्मैट नहीं होतीं। खास तौर पर, लॉग लेवल ऊपर बताए अनुसार पूरी तरह छोटे अक्षरों में नहीं भी हो सकता। इसे संभालने के लिए `log-severity` में बदलाव कीजिए।

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. लॉग की गंभीरता के अनुसार संदेश को फिर से फॉर्मैट करना

गंभीरता के अनुसार संदेश को अलग-अलग तरीकों से बदलना चाहिए:

- `:everything-ok` गंभीरता में संदेश को पूरी तरह छोटे अक्षरों में बदलना चाहिए।
- `:getting-worried` गंभीरता में संदेश के हर शब्द का पहला अक्षर बड़ा करना चाहिए।
- `:run-for-cover` गंभीरता में संदेश को पूरी तरह बड़े अक्षरों में बदलना चाहिए।

एक फंक्शन `log-format` बनाइए जो एक लॉग संदेश लेता है और उसे सही तरीके से फॉर्मैट करके लौटाता है।

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
