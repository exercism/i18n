## Z3 इंस्टॉल कीजिए

### Python डाउनलोड कीजिए (अगर पहले से इंस्टॉल न हो)

Python का नवीनतम संस्करण [यहाँ](https://python.org) से डाउनलोड किया जा सकता है।

* इंस्टॉल करते समय उस चेक बॉक्स को ज़रूर चुनिए जो Python को PATH में जोड़ता है

### Visual Studio डाउनलोड कीजिए (अगर पहले से इंस्टॉल न हो)

Visual Studio का नवीनतम संस्करण [यहाँ](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019) से डाउनलोड किया जा सकता है।

* इंस्टॉल करते समय **Python Development** वर्कलोड चुनिए
* दाईं ओर दिए गए सभी वैकल्पिक Python डेवलपमेंट पैकेज चेक बॉक्स चुन लीजिए

इंस्टॉल हो जाने के बाद Visual Studio खोलिए और अपनी शुरुआती प्राथमिकताएँ सेट कर लीजिए।

### Git कमांड इंस्टॉल कीजिए

Git इंस्टॉल करने के निर्देश [यहाँ](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) मिल जाएँगे।

* आपको [Git को अपने सिस्टम वेरिएबलो में जोड़ना](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command) होगा

### Z3 क्लोन कीजिए

प्रोजेक्ट देखने के लिए [Z3 Github रिपॉज़िटरी](https://github.com/Z3Prover/z3) पर जाइए।

अपने कंप्यूटर पर एक टर्मिनल खोलिए और उस जगह पर जाइए जहाँ आप Z3 रिपॉज़िटरी क्लोन करना चाहते हैं (उदाहरण: C:\Z3)।

उसी जगह से यह चलाइए:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Visual Studio Command Prompt की मदद से Windows पर Z3 बिल्ड कीजिए

**Developer Command Prompt for VS 2019** को स्टार्ट मेन्यू से खोलिए।

उस फोल्डर में जाइए जहाँ आपने Z3 रिपॉज़िटरी क्लोन की थी (उदाहरण: C:\Z3)।

32-बिट बिल्ड के लिए यह चलाइए:

```bash
python scripts/mk_make.py
```

64-बिट बिल्ड के लिए यह चलाइए:

```bash
python scripts/mk_make.py -x
```

इसके बाद यह चलाइए:

```bash
cd build
pip install z3-solver
```



अब आप Visual Studio खोलकर Z3 को उसके Python बाइंडिंग के ज़रिए चला पाएँगे।


जाँचने के लिए आप यह चला सकते हैं:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

अंतिम दो लाइनों का नतीजा `sat` और `[y = 4, x = 2]` होना चाहिए।
