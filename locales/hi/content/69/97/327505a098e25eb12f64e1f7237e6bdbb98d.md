# निर्देश

इस अभ्यास में आप एक लॉग रिपोर्ट की लाइनों पर काम करेंगे।
हर लॉग लाइन एक स्ट्रिंग होती है, जिसका फॉर्मेट कुछ इस तरह होता है: `"[<LEVEL>]: <MESSAGE>"`.

लॉग लेवल तीन तरह के होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके पास तीन काम हैं। हर काम में एक लॉग लाइन दी जाएगी, और आपको उसके साथ कुछ करना होगा।

## 1. लॉग लाइन से मैसेज निकालिए

`log_line::message` मेथड लागू कीजिए, जो लॉग लाइन का मैसेज लौटाए:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

`log_line::log_level` मेथड लागू कीजिए, जो लॉग लाइन का लॉग लेवल लौटाए। यह लेवल बड़े अक्षरों में लौटाया जाना चाहिए:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. लॉग लाइन का फॉर्मेट बदलिए

`log_line::reformat` मेथड लागू कीजिए, जो लॉग लाइन का फॉर्मेट ऐसे बदलता है कि पहले मैसेज आए और उसके बाद कोष्ठकों में लॉग लेवल:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
