# इसके बारे में

[मॉड्यूल अट्रिब्यूट][module-attr] को ["कॉन्स्टेंट"][attr-as-const] की तरह इस्तेमाल किया जा सकता है, जो कंपाइल के समय ही तय हो जाते हैं।

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

लेकिन वे पूरी तरह कॉन्स्टेंट जैसा व्यवहार नहीं करते, क्योंकि मॉड्यूल में उन्हें फिर से परिभाषित करके उन पर नई वैल्यू लिखी जा सकती है:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
