# परिचय

जैसे प्रॉपर्टी आपके स्ट्रक्चर और क्लास में डेटा संग्रहीत करती हैं, वैसे ही आप _मेथड_ भी बना सकते हैं, जो आपके स्ट्रक्चर या क्लास में फंक्शन रखते हैं।

मेथड किसी साधारण फंक्शन की तरह ही बनाए जाते हैं, बस ये स्ट्रक्चर या क्लास के अंदर बनते हैं। ध्यान दीजिए कि अगर कोई फंक्शन स्ट्रक्चर की किसी प्रॉपर्टी की वैल्यू बदलता है, तो उससे पहले `mutating` कीवर्ड लिखना ज़रूरी है। इसके अलावा, अगर कोई प्रॉपर्टी किसी मेथड से बदली जा सकती है, तो उस प्रॉपर्टी को `let` के बजाय `var` से बनाना ज़रूरी है, ठीक वैसे ही जैसे साधारण वेरिएबल बनाए जाते हैं।

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

इन मेथड को प्रॉपर्टी की तरह ही डॉट नोटेशन से कॉल किया जा सकता है।

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
