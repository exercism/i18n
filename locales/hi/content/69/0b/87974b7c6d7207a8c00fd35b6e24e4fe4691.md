# निर्देश परिशिष्ट

## शब्द

- `<bst> ( data-seq -- tree )`: `data-seq` का हर एलिमेंट क्रम से डालकर एक ट्री बनाता है।
- `sorted-data ( tree -- seq )`: ट्री के एलिमेंट बढ़ते क्रम में लौटाता है (इन-ऑर्डर ट्रैवर्सल)।

## टपल पदानुक्रम

बाइनरी सर्च ट्री में एक नोड या तो *खाली* होता है या उसके पास *डेटा और दो सबट्री* होते हैं। इसे एक छोटे इनहेरिटेंस पदानुक्रम के रूप में बनाइए:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` अमूर्त पैरेंट है। `leaf` खाली ट्री वाला केस है। `branch` एक वैल्यू और दो `bst` चाइल्ड नोड रखता है (हर चाइल्ड नोड खुद या तो `leaf` होता है या `branch`)।

## क्रम

डेटा की तुलना `before=?` से कीजिए (यह `math.order` में मिलता है)। यह संख्याओं के साथ-साथ स्ट्रिंग पर भी काम करता है। टेस्ट `"1"`, `"2"`, `"3"` जैसे स्ट्रिंग डेटा इस्तेमाल करते हैं।
