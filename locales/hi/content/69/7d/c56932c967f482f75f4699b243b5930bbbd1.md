# कंट्रोल फ्लो

`if` एक्सप्रेशन और लूप, Cairo में कोड के चलने के क्रम को इनके ज़रिए नियंत्रित करते हैं:
`

- **`if` एक्सप्रेशन** किसी शर्त के `true` होने पर ही कोड चलाते हैं।
- **लूप** (`loop`, `while` और `for` जैसे) किसी तय शर्त के `true` रहने तक या कोई रुकने वाली शर्त पूरी होने तक कोड को बार-बार चलाते हैं।

Cairo में लॉजिक और इटरेशन लागू करने के लिए ये चीज़ें आधारभूत हैं।

## `if` एक्सप्रेशन

Cairo में `if` एक्सप्रेशन आपको शर्तों के आधार पर कोड चलने का क्रम नियंत्रित करने देते हैं।
इनका ढाँचा ऐसा होता है कि कोड इस बात पर चलता है कि कोई बूलियन शर्त `true` है या `false`।

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

यह उदाहरण Cairo में एक साधारण `if` ब्लॉक दिखाता है।
संदेश `"It's hot outside!"` तभी प्रिंट होता है जब शर्त `temperature > 25` का मूल्यांकन `true` हो।
अगर शर्त `false` है, तो कोई कोड नहीं चलता और प्रोग्राम आगे बढ़ता रहता है।

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

यह कोड चलाने पर कंसोल में `"The number is less than 10."` प्रिंट होगा।

### `else if` से कई शर्तें संभालना

आप `if` और `else` को एक `else if` एक्सप्रेशन में मिलाकर कई शर्तें इस्तेमाल कर सकते हैं।

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

यह कोड चलाने पर कंसोल में `"Grade: B"` प्रिंट होगा।

### `let` स्टेटमेंट में `if` का इस्तेमाल

Cairo में `if` एक्सप्रेशन को `let` स्टेटमेंट के दाईं ओर इस्तेमाल करके उसका परिणाम किसी वेरिएबल में असाइन किया जा सकता है।

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## लूप

लूप कोड ब्लॉक को बार-बार चलाने का एक आधारभूत तरीका है, जिससे काम कुशलता और नियंत्रण के साथ पूरे किए जा सकते हैं।
लूप किसी सीक्वेंस पर इटरेशन कर सकते हैं या किसी शर्त के आधार पर कोड को बार-बार चला सकते हैं।
Cairo में मुख्य रूप से तीन तरह के लूप होते हैं:

- **loop**: एक साधारण लूप, जो `break` स्टेटमेंट से स्पष्ट रूप से रोके जाने तक लगातार चलता रहता है।
- **while**: जब तक कोई तय शर्त `true` बनी रहती है, तब तक कोड चलाता रहता है।
  शर्त `false` होते ही यह रुक जाता है।
- **for**: ऐरे जैसे किसी कलेक्शन के एलिमेंट पर इटरेशन करता है और हर एलिमेंट के लिए कोड चलाता है।

### `loop` से कोड दोहराना

`loop` कीवर्ड Cairo से कहता है कि वह कोड का एक ब्लॉक बार-बार, हमेशा के लिए चलाता रहे, या तब तक जब तक आप उसे स्पष्ट रूप से रुकने के लिए न कहें।

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

यह कोड चलाने पर कंसोल में `"again!"` बार-बार प्रिंट होता रहेगा, जब तक प्रोग्राम की गैस खत्म न हो जाए या हम उसे खुद न रोक दें।

> ध्यान दीजिए: Cairo एक गैस मीटर शामिल करके हमें अनंत लूप वाला प्रोग्राम चलाने से रोकता है।
> गैस मीटर एक ऐसा तंत्र है जो सीमित करता है कि किसी प्रोग्राम में कितनी गणना हो सकती है।
> गैस एक माप की इकाई है, जो किसी निर्देश पर लगने वाली गणना की लागत बताती है।
> जब गैस खत्म हो जाती है, तो प्रोग्राम रुक जाता है।

किसी लूप से बाहर निकलने के लिए लूप के अंदर `break` कीवर्ड लगाइए, जो प्रोग्राम को बताता है कि उसे चलना कब बंद करना है।

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

`continue` कीवर्ड प्रोग्राम को बताता है कि वह लूप के अगले इटरेशन पर चला जाए और इस इटरेशन का बाकी कोड छोड़ दे।

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

जब `i` की वैल्यू `5` के बराबर होती है, तब यह प्रोग्राम उसे प्रिंट नहीं करता।

#### `loop` से वैल्यू लौटाना

आप `break` कीवर्ड के बाद जो वैल्यू लौटाना चाहते हैं उसे लिखकर `loop` से वैल्यू लौटा सकते हैं।
इससे आप `loop` से बाहर निकल सकते हैं और उस परिणाम को अपने बाकी कोड तक पहुँचा सकते हैं।

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### `while` से शर्त वाले लूप

`while` तब तक कोड चलाता है जब तक कोई शर्त `true` रहती है, और शर्त `false` होते ही बाहर निकल जाता है।

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### `for` से किसी कलेक्शन पर लूप चलाना

`for` किसी कलेक्शन के हर आइटम पर इटरेशन करता है और हर आइटम के लिए कोड चलाता है।

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
