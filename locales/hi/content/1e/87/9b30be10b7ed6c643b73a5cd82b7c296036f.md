# निर्देश

इस अभ्यास में आप अलग-अलग तरह की रिमोट कंट्रोल कारों के बीच रेस का आयोजन करेंगे। हर कार की अपनी गति होती है और अपना बैटरी ड्रेन होता है।

कारें पूरी (100%) बैटरी के साथ शुरू होती हैं। जब भी आप रिमोट कंट्रोल से कार चलाते हैं, वह कार की गति के बराबर मीटर तय करती है और बची हुई बैटरी का प्रतिशत उसके बैटरी ड्रेन के बराबर घटा देती है।

अगर किसी कार की बैटरी उसके बैटरी ड्रेन प्रतिशत से कम रह गई हो, तो आप उस कार को और नहीं चला सकते।

हर रेस ट्रैक की अपनी दूरी होती है। कारों की जाँच यह देखकर की जाती है कि वे बैटरी खत्म हुए बिना ट्रैक पूरा कर पाती हैं या नहीं।

आपके पास छह कार्य हैं। हर कार्य में रिमोट कंट्रोल कार के इंस्टेंस के साथ काम करना है।

## 1. रिमोट कंट्रोल कार बनाना

`RemoteControlCar` क्लास के लिए ऐसा कंस्ट्रक्टर बनाइए जो कार की गति (मीटर में) और बैटरी ड्रेन प्रतिशत को अपने दो पैरामीटर के रूप में लेता है (दोनों का टाइप `int` है)। इस तरह आप रिमोट कंट्रोल कार बना सकेंगे:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. रेस ट्रैक बनाना

`RaceTrack` क्लास के लिए ऐसा कंस्ट्रक्टर बनाइए जो ट्रैक की दूरी (मीटर में) को अपना एकमात्र पैरामीटर लेता है (जिसका टाइप `int` है)। इस तरह आप रेस ट्रैक बना सकेंगे:

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. कार चलाना

`RemoteControlCar.Drive()` मेथड लागू कीजिए, जो कार की गति के आधार पर तय किए गए मीटरों की संख्या अपडेट करता है। साथ ही `RemoteControlCar.DistanceDriven()` मेथड लागू कीजिए, जो कार द्वारा तय किए गए मीटरों की संख्या लौटाता है:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. बैटरी खत्म होने की जाँच

`RemoteControlCar.Drive()` मेथड को ऐसे अपडेट कीजिए कि वह कार के बैटरी ड्रेन के अनुसार बैटरी भी घटा दे। साथ ही `RemoteControlCar.BatteryDrained()` मेथड लागू कीजिए, जो बताता है कि बैटरी खत्म हो चुकी है या नहीं:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Nitro रिमोट कंट्रोल कार बनाना

सबसे ज़्यादा बिकने वाली रिमोट कंट्रोल कार Nitro है, जिसकी शानदार अधिकतम गति 50 मीटर है और बैटरी ड्रेन 4% है। इस तरह की कार लौटाने के लिए (static) `RemoteControlCar.Nitro()` मेथड लागू कीजिए:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. देखिए कि कोई रिमोट कंट्रोल कार रेस पूरी कर सकती है या नहीं

रेस ट्रैक पूरा करने के लिए कार को ट्रैक की दूरी तय कर पाना ज़रूरी है। इसका मतलब है कि फिनिश लाइन पार करने से पहले उसकी बैटरी खत्म नहीं होनी चाहिए। `RaceTrack.TryFinishTrack()` मेथड लागू कीजिए, जो अपने पैरामीटर के रूप में एक `RemoteControlCar` इंस्टेंस लेता है और अगर कार यह रेस ट्रैक पूरा कर सकती है तो `true` लौटाता है, वरना `false` लौटाता है:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
