# एडिटर इंटीग्रेशन

Clojure में कोड लिखने का सबसे अच्छा तरीका एडिटर से जुड़ा REPL है। सबसे लोकप्रिय एडिटर और IDE के लिए प्लगइन उपलब्ध हैं:

- Emacs: [CIDER](https://cider.mx)
- IntelliJ: [Cursive](https://cursive-ide.com)
- VSCode: [Calva](https://calva.io)
- Vim: [Conjure](https://github.com/Olical/conjure)

अधिक जानकारी के लिए [आधिकारिक डॉक्स](https://clojure.org/guides/editors) देखिए।
