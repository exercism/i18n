`String` और `&str` Rust में टेक्स्ट डेटा के साथ काम करने के दो बुनियादी तरीके हैं।

`String` का स्वामित्व होता है, यह `u8` बाइट्स का वेक्टर है और म्यूटेबल है।
`&str` एक String स्लाइस का उधार लिया गया रेफरेंस है, इसलिए यह इम्यूटेबल है।

आप `String` बनाने और बदलने के लिए उसके कई मेथड में से कोई एक इस्तेमाल कर सकते हैं, जैसे `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

आप किसी `&str` को `String` में बदलकर भी एक `String` बना सकते हैं:
```rust
let a_string = "hello".to_string();
```
