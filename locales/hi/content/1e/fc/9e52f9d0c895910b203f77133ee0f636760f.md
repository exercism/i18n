# परिचय

R में सेट के लिए कोई अलग टाइप नहीं होता। इसके बजाय वेक्टर पर मिलते-जुलते काम करने के लिए कई तरह के फंक्शन इस्तेमाल किए जाते हैं।

`%in%` ऑपरेटर यह जाँचता है कि कोई वैल्यू किसी सेट का हिस्सा है या नहीं।
यह ऑपरेटर दो वैल्यू के बीच लिखा जाता है और `is.element()` फंक्शन का ही दूसरा रूप है।

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

इससे जुड़े कुछ फंक्शन ये हैं:

- [`unique()`][ref-unique] दोहराव हटाने के लिए।
- [`union()`][ref-sets] सेट जोड़ने के लिए (गणित में, `A ∪ B`)।
- [`intersect()`][ref-sets] दोनों सेट में साझा एलिमेंट ढूँढने के लिए (`A ∩ B`)।
- [`setdiff()`][ref-sets] एक सेट को दूसरे से घटाने के लिए (`A - B`)।
- [`setequal`][ref-sets] दोहराव और क्रम को छोड़कर सेट की बराबरी जाँचने के लिए।

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

हर मामले में फंक्शन एक कॉपी लौटाता है और आर्गुमेंट को जैसा था वैसा ही छोड़ देता है।

## हैश टेबल

ऊपर बताए गए वेक्टर ऑपरेशन R की बुनियादी सुविधाओं का हिस्सा हैं।
ये छोटी समस्याओं के लिए उपयोगी हैं, लेकिन बड़े सेट के लिए धीमे हो जाते हैं।

कई तीसरे पक्ष के पैकेज हैश टेबल लागू करते हैं, ताकि कुछ जगहों पर प्रदर्शन बेहतर हो सके।

उदाहरण के लिए, [`hashtable`][ref-hashtable] पैकेज `hashmap` और `hashset` के कार्यान्वयन देता है, जो बड़े पैमाने पर बेहतर काम करते हैं।
ज़्यादातर बाहरी पैकेज की तरह यह Exercism में उपलब्ध नहीं है, लेकिन वास्तविक दुनिया की समस्याओं के लिए इसे ज़रूर जाँचना चाहिए।
