# परिचय

## ओवरफ्लो

अंकगणितीय ओवरफ्लो तब होता है जब कोई गणना, जैसे कोई अंकगणितीय ऑपरेशन या टाइप कन्वर्ज़न, ऐसी वैल्यू देती है जो प्राप्त करने वाले टाइप की क्षमता से बड़ी होती है।

`int` और `long` टाइप के एक्सप्रेशन और उनके unsigned समकक्ष ऐसी स्थितियों में चुपचाप रैप हो जाते हैं।

पूर्णांक गणनाओं का व्यवहार `checked` कीवर्ड का उपयोग करके बदला जा सकता है। जब किसी `checked` ब्लॉक के अंदर ओवरफ्लो होता है, तो `OverflowException` का एक इंस्टेंस फेंका जाता है।

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

`float` और `double` टाइप के एक्सप्रेशन अनंत की एक विशेष वैल्यू ले लेंगे।

`decimal` टाइप के एक्सप्रेशन `OverflowException` का एक इंस्टेंस फेंकेंगे।
