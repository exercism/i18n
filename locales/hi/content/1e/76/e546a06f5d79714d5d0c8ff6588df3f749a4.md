# निर्देश परिशिष्ट

## एक्सेप्शन संदेश

कभी-कभी [एक्सेप्शन उठाना](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) ज़रूरी हो जाता है। ऐसा करते समय आपको हमेशा एक **अर्थपूर्ण एरर संदेश** देना चाहिए, जिससे पता चले कि एरर का स्रोत क्या है। इससे आपका कोड पढ़ने में आसान हो जाता है और डिबगिंग में काफी मदद मिलती है। जहाँ आप जानते हैं कि एरर का स्रोत एक तय टाइप का ही होगा, वहाँ आप [अंतर्निहित एरर टाइप](https://docs.python.org/3/library/exceptions.html#base-classes) में से किसी एक को चुनकर उठा सकते हैं, लेकिन संदेश फिर भी अर्थपूर्ण होना चाहिए।

इस अभ्यास में आपको [`raise` स्टेटमेंट](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) का उपयोग करके `ValueError` "फेंकना" है, अगर `slice()` फंक्शन को दिए गए सीरीज़ और/या लंबाई पैरामीटर खाली हों या सीमा से बाहर हों। टेस्ट तभी पास होंगे जब आप `raise` से `exception` उठाएँ और उसके साथ एक संदेश भी दें।

किसी संदेश के साथ `ValueError` उठाने के लिए, संदेश को `exception` टाइप के आर्गुमेंट के रूप में लिखिए:

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
