# परिचय

ऐसा कोड लिखिए जो सरल अंग्रेज़ी की तरह पढ़ा जाए।

Visual Basic उसी .NET रनटाइम पर चलता है जिस पर C# और F# चलते हैं।
आपको LINQ, जेनेरिक्स और async/await मिलते हैं, लेकिन यहाँ सिंटैक्स इस तरह बना है कि उसे पढ़ा जा सके, डिकोड न करना पड़े।

अगर आप C# या F# जानते हैं, तो .NET रनटाइम और लाइब्रेरी आपके लिए परिचित होंगे।
अगर आप VB6, VBA या VBScript जानते हैं, तो वह परिचित सिंटैक्स अब .NET के परखे हुए रनटाइम पर टिका है।

न कर्ली ब्रैकेट संतुलित करने की ज़रूरत, न सेमीकोलन ढूँढने की।
