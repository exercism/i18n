# परिचय

जब आपको `n` वैल्यू का ऐसा सीक्वेंस चाहिए जिसमें हर वैल्यू अपने इंडेक्स पर निर्भर करती हो, तो Factor आपको `<iota>` देता है, जो पूर्णांकों `0, 1, …, n-1` का एक वर्चुअल सीक्वेंस है, और साथ में `map` भी देता है:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` उन पूर्णांकों को पहले से नहीं बनाता; `map` उन पर क्रम से चलता है और हर एक पर कोटेशन लागू करता है।

अगर हर इंडेक्स पर मिलने वाला परिणाम एक अक्षर कोड हो, तो `>string` उस परिणाम को स्ट्रिंग में बदल देता है। इंडेक्स के आधार पर फैसले लेकर अक्षरों की एक पंक्ति बनाने का यही स्वाभाविक तरीका है:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```
