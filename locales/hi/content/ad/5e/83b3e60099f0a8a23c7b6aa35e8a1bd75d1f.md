# परिचय

## कस्टम टाइप

Gleam में नए डेटा टाइप बनाने का तरीका कस्टम टाइप है। इनके कई _वेरिएंट_ हो सकते हैं, और हर वेरिएंट का अपना नाम होता है।

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

कस्टम टाइप का हर केस चाहें तो कुछ डेटा भी रख सकता है, और अलग-अलग केस अलग-अलग तरह का डेटा रख सकते हैं। जब किसी वेरिएंट में डेटा होता है, तो उसे _रिकॉर्ड_ कहते हैं।

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

किसी खास केस के लिए वैल्यू बनाने के लिए, अगर उसमें कोई अतिरिक्त डेटा नहीं है तो सिर्फ उसका नाम लिखिए (`Spring`), और अगर डेटा है तो उसे फंक्शन की तरह कॉल कीजिए (`SomeInt(2)`)।

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Gleam में हर चीज़ की तरह कस्टम टाइप में भी _स्ट्रक्चरल इक्वलिटी_ होती है, यानी एक ही वेरिएंट की और एक ही डेटा वाली दो वैल्यू बराबर होती हैं।

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

कस्टम टाइप के वेरिएंट पर `case` एक्सप्रेशन की मदद से पैटर्न मैचिंग की जा सकती है।

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
