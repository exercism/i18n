# परिचय

C++ में बूलियन को `bool` टाइप से दर्शाया जाता है।
`bool` या तो `true` होता है या `false`।

## लॉजिकल ऑपरेटर

C++ तीन बूलियन ऑपरेटर का समर्थन करता है:  `!` (NOT), `&&` (AND), और `||` (OR)।
आप इनके वैकल्पिक रूप `not`, `and`, और `or` भी इस्तेमाल कर सकते हैं।

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## प्राथमिकता

तीनों बूलियन ऑपरेटरों की _ऑपरेटर प्राथमिकता_ अलग-अलग होती है।
इसलिए इनका मूल्यांकन इस क्रम में होता है: पहले `!`, फिर `&&`, और अंत में `||`।
अगर आप क्रम बदलना चाहते हैं, तो बूलियन एक्सप्रेशन को गोल ब्रैकेट (यानी `()`) में लिख सकते हैं, क्योंकि ब्रैकेट की ऑपरेटर प्राथमिकता इससे भी ज़्यादा होती है।

```cpp
!true && false   // => false
!(true and false) // => true
```

## रूपांतरण

अगर आप `true` या `false` को किसी ऐसी जगह इस्तेमाल करते हैं जहाँ संख्या की अपेक्षा होती है, तो वे क्रमशः `1` और `0` में बदल दिए जाते हैं।
अगर आप किसी बूलियन ऑपरेशन में संख्या इस्तेमाल करते हैं, तो `0` को छोड़कर हर चीज़ `true` मानी जाती है, ऋणात्मक वैल्यू भी।

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
