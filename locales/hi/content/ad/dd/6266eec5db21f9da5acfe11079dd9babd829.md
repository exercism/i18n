# परिचय

## स्ट्रक्ट

स्ट्रक्ट, [मैप][exercism-maps] के ऊपर बना एक एक्सटेंशन है, जो कंपाइल-टाइम जाँच और डिफॉल्ट वैल्यू देता है। स्ट्रक्ट का नाम उस मॉड्यूल के नाम पर रखा जाता है जिसमें इसे बनाया जाता है। स्ट्रक्ट बनाने के लिए `defstruct` कंस्ट्रक्ट का उपयोग कीजिए। यह कंस्ट्रक्ट आमतौर पर मॉड्यूल की परिभाषा के ठीक बाद लिखा जाता है। `defstruct` या तो एटम का ऐरे लेता है (`nil` डिफॉल्ट वैल्यू के लिए), या कीवर्ड ऐरे (तय की गई डिफॉल्ट वैल्यू के लिए)। जिन फील्ड की कोई डिफॉल्ट वैल्यू नहीं है, वे डिफॉल्ट वैल्यू वाले फील्ड से पहले आने चाहिए।

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### फील्ड पढ़ना और बदलना

चूँकि स्ट्रक्ट मैप के ऊपर बने होते हैं, हम वैल्यू पाने और बदलने के लिए ज़्यादातर मैप फंक्शन इस्तेमाल कर सकते हैं। स्ट्रक्ट के लिए _Access Behaviour_ **लागू नहीं** होता। इसकी जगह स्ट्रक्ट फील्ड पढ़ने के लिए _स्टैटिक एक्सेस ऑपरेटर_ `.` इस्तेमाल करना बेहतर है।

- फील्ड की वैल्यू पाना:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- फील्ड की वैल्यू बदलना:

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### पैटर्न मैचिंग

स्ट्रक्ट का पैटर्न मैचिंग में इस्तेमाल स्ट्रक्ट के नाम के साथ या उसके बिना किया जा सकता है।

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

पैटर्न में स्ट्रक्ट का नाम शामिल करने से आप यह पक्का कर सकते हैं कि बाईं और दाईं, दोनों तरफ एक ही तरह के स्ट्रक्ट हैं।

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### फील्ड की वैल्यू शुरू में देना ज़रूरी बनाना

स्ट्रक्ट बनाते समय वैल्यू ज़रूर शुरू हो जाएँ, यह पक्का करने के लिए हम फील्ड कीज़ के ऐरे के साथ `@enforce_keys` मॉड्यूल एट्रिब्यूट इस्तेमाल कर सकते हैं। अगर कोई की सूची में नहीं है, तो उसकी वैल्यू `nil` होगी, जैसा ऊपर के उदाहरण में दिख रहा है। अगर ज़रूरी बनाई गई कोई की शुरू में नहीं दी गई, तो एरर आती है।

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
