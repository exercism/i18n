# परिचय

## टाइप एलियस

Gleam में टाइप एलियस की मदद से किसी मौजूदा टाइप को एक सुविधाजनक नाम दिया जा सकता है, जिसे लिखना वरना मुश्किल होता।

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

जब इसे `pub type` के साथ लिखा जाता है, तो एलियस का इस्तेमाल उस मॉड्यूल के बाहर भी किया जा सकता है जिसमें इसे बनाया गया है। अगर `pub` हटा दिया जाए, तो एलियस निजी रहता है और दूसरे मॉड्यूल में उसका इस्तेमाल नहीं किया जा सकता।
