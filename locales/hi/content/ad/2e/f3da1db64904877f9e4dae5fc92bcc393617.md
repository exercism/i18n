# परिचय

## गणित के फंक्शन

वर्गमूल, कोण और बढ़ती हुई वक्र रेखाएँ, इन्हें सिर्फ `+`, `-`, `*` और `/` से निकालना मुश्किल है। [`math.functions`][math.functions] वोकैबुलरी में ऐसे शब्द हैं जो ये आपके लिए निकाल देते हैं, और [`math.constants`][math.constants] में π है। बाकी हर शब्द की तरह ये भी अपने इनपुट स्टैक से लेते हैं और अपना जवाब वहीं छोड़ देते हैं।

## वर्गमूल

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

5 मीटर लंबी एक सीढ़ी, जिसका पैर दीवार से 3 मीटर दूर है, दीवार पर 4 मीटर ऊँचाई तक पहुँचती है:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## पाई

`pi` (`math.constants` से) स्टैक पर π डालता है। π वह संख्या है जो बताती है कि किसी वृत्त का व्यास उसकी परिधि पर कितनी बार समाता है:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## कोण रेडियन में होते हैं

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` और `tan` कोण लेते हैं, लेकिन डिग्री में नहीं। ये **रेडियन** इस्तेमाल करते हैं, जिनमें आधा चक्कर 180 नहीं, π होता है। इन्हें डिग्री देना कोई एरर नहीं है: कोड बिना कुछ बताए गलत जवाब दे देता है।

`deg>rad` डिग्री को रेडियन में बदलता है, और `rad>deg` वापस डिग्री में। ये वही नतीजा देते हैं जो π से गुणा करके 180 से भाग देने पर मिलता है, या इसका उल्टा:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

`sin` को कॉल करने से पहले डिग्री को रेडियन में बदलिए:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

30 डिग्री पर 10 मीटर लंबा एक ढलान 5 मीटर ऊपर उठता है। जवाब `4.999999999999999` छपता है, क्योंकि गणित के फंक्शन सटीक वैल्यू नहीं, उसके सबसे नज़दीकी दशमलव संख्या देते हैं। बदलाव के बिना `30 sin` 30 को रेडियन मान लेता है (करीब पाँच पूरे चक्कर), और ढलान `-9.88` मीटर "ऊपर उठता"।

## कोण निकालना

`fatan2` उल्टी दिशा में काम करता है: कितना ऊपर और कितना आगे, यह बताने पर यह कोण रेडियन में लौटाता है। यह [`math.libm`][math.libm] में रहता है। *ऊपर* की दूरी पहले स्टैक पर जाती है, फिर *आगे* की दूरी:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

कोण धनात्मक *आगे* वाली दिशा से नापा जाता है। `fatan2` दोनों दूरियों के चिह्न देखता है, इसलिए यह −180 से 180 डिग्री तक कहीं भी जवाब दे सकता है।

## दस की घातें: 10^ और log10

`10^` दस को किसी घात तक उठाता है:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` उल्टी दिशा में जाता है। यह इस सवाल का जवाब देता है कि "10 की कौन सी घात इस संख्या को देती है?" वही जवाब संख्या का **लॉगरिदम** होता है:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ और log

`e^` और `log` वही जोड़ी हैं, बस 10 की जगह *e* (करीब 2.718) के साथ। `e^` *e* को किसी घात तक उठाता है, और `log` बताता है कि "*e* की कौन सी घात इस संख्या को देती है?"

```
e^  ( x -- y )
log ( x -- y )
```

गणितज्ञ *e* का उपयोग हर उस चीज़ के लिए करते हैं जो हर कदम पर एक ही अनुपात में बढ़ती या घटती है। ब्याज कमाता पैसा एक उदाहरण है, और ठंडा होता चाय का एक कप दूसरा:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log`, `e^` को उलट देता है। इससे सवाल उल्टी तरफ़ से हल होता है: कितने मिनट में यह अंतर 40 डिग्री रह जाएगा?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
