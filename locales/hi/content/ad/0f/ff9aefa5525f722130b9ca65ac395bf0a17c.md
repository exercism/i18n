# इंस्टॉलेशन

## क्या ज़रूरी है

Common Lisp में डेवलपमेंट के लिए ज़रूरी बुनियादी चीज़ें ये हैं:

- एक Lisp "इम्प्लीमेंटेशन", जिससे आप कोड कंपाइल और चला सकते हैं, और जो एक REPL भी देता है।
- एक टेक्स्ट एडिटर, जिसमें Lisp कोड लिखने की सुविधाएँ हों।
- (अच्छा होगा) Common Lisp भाषा के लिए अक्सर इस्तेमाल होने वाला संदर्भ, ["Common Lisp Hyperspec"][hyperspec]।

## Roswell

[Roswell][roswell] एक कमांड है, जिससे Common Lisp इम्प्लीमेंटेशन इंस्टॉल और मैनेज किए जा सकते हैं, और इसमें Lisp एप्लिकेशन बनाना और बाँटना आसान बनाने वाली कई सुविधाएँ हैं।
हम इसका इस्तेमाल इंस्टॉल और टेस्टिंग के स्टेप आसान बनाने के लिए कर रहे हैं।

### Roswell इंस्टॉल कीजिए

[इंस्टॉलेशन गाइड][ros-inst] देखिए और अपने प्लेटफॉर्म के लिए दिए गए निर्देशों का पालन कीजिए।
ज़्यादातर लोगों के लिए नीचे दिया गया तरीका काफी होगा:

* MacOS और Linux पर [Homebrew][brew] से यह आसान हो जाता है:
  ```sh
  brew install roswell
  ```
* Windows पर [Scoop][scoop] इस्तेमाल कीजिए:
  ```powershell
  scoop install roswell
  ```

पहली बार Roswell इस्तेमाल करने पर यह SBCL और Quicklisp डाउनलोड करके इंस्टॉल कर देगा।
बस यह चलाइए:
```sh
ros help
```

REPL में जाने के लिए यह चलाइए:
```sh
ros run
```

## अपना टेक्स्ट एडिटर कॉन्फ़िगर कीजिए

Common Lisp में नए लोगों को, खास तौर पर जिन्हें Emacs का पहले से अनुभव है, [Portacle, पोर्टेबल Common Lisp एनवायरनमेंट][portacle] इंस्टॉल करके जल्दी और आसान शुरुआत मिल सकती है।
यह मुफ्त है और इसमें भरपूर सुविधाएँ हैं, हर आम प्लेटफॉर्म पर काम करता है, और पहले से कॉन्फ़िगर होकर आता है। यह आपको ये चीज़ें देगा:

- एक Lisp इम्प्लीमेंटेशन: SBCL, जिसमें Quicklisp और ASDF शामिल हैं।
- एक टेक्स्ट एडिटर: Emacs

... जिसमें Lisp कोड लिखने के लिए बहुत सारे ऐड-ऑन हैं:
- SLIME, यानी "Emacs के लिए बेहतर Lisp इंटरैक्शन मोड", Emacs को एक Common Lisp IDE बना देता है
- ParEdit, जिससे गोल ब्रैकेट के साथ काम करना आसान हो जाता है।

सब कुछ पहले से कॉन्फ़िगर होकर आता है। Portacle को [मुख्य पेज][portacle] से डाउनलोड करके इंस्टॉल कीजिए।

ध्यान दें: अगर आप Emacs (टेक्स्ट एडिटर) के आदी नहीं हैं, तो यह शुरू में उलझन भरा लग सकता है। अच्छी बात यह है कि Emacs और SLIME पर ऑनलाइन कई शुरुआती गाइड उपलब्ध हैं।

## पारंपरिक शुरुआत

अगर आप ज़रूरी टूल अलग-अलग इंस्टॉल करना पसंद करते हैं, तो आपको ये इंस्टॉल और सेट अप करने होंगे:

- Lisp समझने वाला टेक्स्ट एडिटर: [Emacs][emacs] के साथ [Slime][slime] या [Sly][sly] पैकेज एक आम पसंद है, लेकिन [VIM][vim] के साथ [SLIMV][slimv], [Atom][atom] के साथ [SLIMA][slima], या [VSCode][vscode] के साथ [Common Lisp प्लगइन][vscode-plugin] भी अच्छे विकल्प हैं।
- एक Common Lisp इम्प्लीमेंटेशन: [SBCL][sbcl] एक "सुरक्षित" विकल्प है, जो Linux, MacOS और Windows पर काम करता है। चूँकि यह भाषा एक मानक पर आधारित है, इसलिए [मानक के अनुरूप बने अन्य इम्प्लीमेंटेशन][awesome-cl-implementations] भी काम करेंगे।
- लाइब्रेरी मैनेजमेंट के लिए [Quicklisp][quicklisp]. इसे डाउनलोड करने के बाद [निर्देशों][quicklisp-install] का पालन कीजिए ताकि यह आपके Common Lisp इम्प्लीमेंटेशन के साथ ठीक से जुड़ जाए।
