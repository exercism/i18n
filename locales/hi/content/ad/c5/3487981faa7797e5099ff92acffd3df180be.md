# निर्देश

आपको यह तय करना है कि अतिरिक्त कुकी बाँटते समय आप क्या कहेंगे।

अगर आपको उस व्यक्ति का नाम पता है (जैसे कि उसका नाम Do-yun है), तो आप कहेंगे:

```text
One for Do-yun, one for me.
```

अगर आपको उस व्यक्ति का नाम नहीं पता है, तो आप उसकी जगह _you_ कहेंगे।

```text
One for you, one for me.
```

यहाँ कुछ उदाहरण दिए गए हैं:

| नाम    | संवाद                      |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
