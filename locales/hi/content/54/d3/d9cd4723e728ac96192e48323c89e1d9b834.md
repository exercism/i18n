# परिचय

Gleam में `case` एक्सप्रेशन की मदद से शर्त के हिसाब से कोड चलाया जा सकता है। किसी `case` एक्सप्रेशन में एक वैल्यू की तुलना एक या अधिक _पैटर्न_ से की जा सकती है। ऐसे ही एक पैटर्न का उदाहरण है _लिटरल पैटर्न_, जिसमें किसी वैल्यू की तुलना किसी लिटरल वैल्यू (जैसे `1` या `"hello"`) से की जाती है।

`case` एक्सप्रेशन `case` कीवर्ड से लिखे जाते हैं:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

हालाँकि यह दूसरी भाषाओं के `switch` स्टेटमेंट जैसा लग सकता है, पर पैटर्न मैचिंग तब और काम की लगती है जब इसके साथ दूसरे पैटर्न भी इस्तेमाल किए जाएँ। ऐसा ही एक पैटर्न है _वेरिएबल पैटर्न_, जिससे किसी वेरिएबल को एक वैल्यू असाइन की जा सकती है। इस उदाहरण में अगर `number` की वैल्यू `0` नहीं है, तो वेरिएबल `i` को वह वैल्यू मिल जाती है:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

कुछ मामलों में आप किसी पैटर्न में एक और शर्त जोड़ना चाह सकते हैं। इसे _गार्ड_ (क्लॉज़) कहते हैं, और इसे `if` कीवर्ड से जोड़ा जा सकता है:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

परफॉर्मेंस के लिहाज से गार्ड में सिर्फ बुनियादी गणितीय और बूलियन ऑपरेटर ही इस्तेमाल किए जा सकते हैं। गार्ड में दूसरे फंक्शन इस्तेमाल नहीं किए जा सकते।

ऊपर के उदाहरण में हर संभव इनपुट के लिए मैच करता हुआ पैटर्न मौजूद नहीं है। कंपाइलर इसे पकड़ लेता है और एक एरर दिखाता है। इसे _एक्सहॉस्टिव चेकिंग_ कहते हैं। इस चेतावनी को दूर करने के लिए सभी मामलों को संभालना पड़ता है। इसके लिए _डिस्कार्ड पैटर्न_ इस्तेमाल किया जा सकता है, जो किसी भी वैल्यू से मैच कर जाता है:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

`case` एक्सप्रेशन किसी वैल्यू की तुलना ऊपर से नीचे तक हर पैटर्न से करता है, और जैसे ही कोई पैटर्न मैच हो जाता है, वह उस पैटर्न से जुड़ा कोड चला देता है। पैटर्न का क्रम महत्व रखता है!
