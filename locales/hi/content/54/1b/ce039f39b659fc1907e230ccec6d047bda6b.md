# विवरण

दशमलव संख्याएँ वे संख्याएँ होती हैं जिनमें दशमलव बिंदु के बाद एक या अधिक अंक होते हैं।

```gleam
let float = 3.45
// -> 3.45
```

दशमलव संख्याओं के अपने ऑपरेटर भी होते हैं।

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

स्पष्टता के लिए दशमलव संख्याओं में अंडरस्कोर भी जोड़ सकते हैं।

```gleam
1_000_000.0 // One million
```

दशमलव संख्याओं के साथ वैज्ञानिक संकेतन का भी उपयोग किया जा सकता है:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
