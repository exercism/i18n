# Bash शेल में अंकगणित का परिचय

Bash अंकगणित कर सकता है, लेकिन _सिर्फ पूर्णांकों के साथ_।
अगर आपको दशमलव संख्या वाला गणित करना है, तो आपको किसी बाहरी प्रोग्राम को कॉल करना पड़ेगा (जैसे [awk][awk] या [bc][bc])।

अंकगणितीय ऑपरेटर मैनुअल में (प्राथमिकता के क्रम में) दिए गए हैं: [शेल अंकगणित][arithmetic]।

इसके अलावा, Bash अंकगणित सिर्फ कुछ खास जगहों पर ही करता है (जिन्हें अंकगणितीय "संदर्भ" कहा जाता है)।

## अंकगणितीय एक्सपैंशन

अंकगणितीय एक्सपैंशन [कमांड सब्स्टिट्यूशन][cmd-sub] जैसा दिखता है, लेकिन इसमें दोहरे ब्रैकेट होते हैं।

```bash
$(( expression ))
```

इस सिंटैक्स की जगह एक्सप्रेशन को हल करने पर मिलने वाला परिणाम आ जाता है।
इसका इस्तेमाल आम तौर पर परिणाम को एक वेरिएबल में रखने के लिए किया जाता है:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
ब्रैकेटों के अंदर कितना स्पेस डालना है, यह आप पर निर्भर है।
यह आपकी स्टाइल और पढ़ने में आसानी का सवाल है।

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

आपका मिलनसार लेखक ब्रैकेटों के अंदर अंकगणितीय एक्सप्रेशन को और साफ दिखाने के लिए स्पेस जोड़ना पसंद करता है।
~~~~

## अंकगणितीय शर्त

अंकगणितीय शर्त दोहरे ब्रैकेट के अंदर _बिना_ शुरुआती `$` के लिखी जाती है:

```bash
(( expression ))
```

इसकी जगह परिणाम नहीं आता।
लेकिन यह एक _एग्ज़िट स्टेटस_ देता है।

* अगर एक्सप्रेशन का परिणाम **शून्य से अलग** हो, तो एग्ज़िट स्टेटस 0 (सफलता) होता है।
* अगर एक्सप्रेशन का परिणाम **शून्य** हो, तो एग्ज़िट स्टेटस 1 (विफलता) होता है।

~~~~exercism/note
`((` के अंदर Bash सही/गलत का वही अर्थ लेता है जो C भाषा लेती है: शून्य गलत है, शून्य से अलग सही है।
**यह Bash के एग्ज़िट स्टेटस जाँचने के तरीके का उल्टा है!**
~~~~

इस सिंटैक्स का इस्तेमाल आम तौर पर दो जगहों पर होता है:

1. किसी [`if` स्टेटमेंट][conditional-if] या [`while` लूप][looping-while] के कमांड वाले हिस्से के रूप में।

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. किसी वेरिएबल की वैल्यू बदलने के लिए एक अलग कमांड के रूप में।

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   इस तरह अंकगणित के साथ `set -e` का इस्तेमाल करते समय सावधान रहिए।
   अगर एक्सप्रेशन का मान शून्य आता है, तो एग्ज़िट स्टेटस शून्य से अलग होगा और Bash बंद हो जाएगा।

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   `++` ऑपरेटर के बारे में ज़्यादा विस्तार से जानने के लिए [Postincrement vs Preincrement][incr] वाला यह लेख देखिए।

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## अंकगणितीय संदर्भ वाली अन्य जगहें

कुछ और जगहें भी हैं जो अंकगणितीय संदर्भ हैं:

* [अंकगणितीय for लूप][looping-for]।

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* संख्यात्मक इंडेक्स वाले ऐरे के इंडेक्स भाग में।

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  ऐरे के बारे में ज़्यादा जानने के लिए [ऐरे][arrays] वाला कॉन्सेप्ट दस्तावेज़ पढ़िए।

* `${var:offset:length}` एक्सपैंशन के ऑफसेट और लंबाई वाले हिस्सों में।
* [`let` बिल्ट-इन कमांड][let] में।
  * ध्यान दीजिए कि `(( expression ))` को `let "expresson"` से बेहतर माना जाता है।
    अंकगणितीय शर्त वाले ढाँचे के उलट, `let` एक्सप्रेशन पर फाइलनेम एक्सपैंशन और वर्ड स्प्लिटिंग लागू होती है, और इसके लिए कोट लगाना ज़रूरी है।
* वेरिएबल असाइनमेंट भी, जब वेरिएबल में "पूर्णांक एट्रिब्यूट" हो।

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  लेखक का मानना है कि `declare -i` का इस्तेमाल सीमित है।
  इसका मुख्य फायदा यह है कि यह "सीधा" अंकगणित लिखने देता है (बिना अंकगणितीय एक्सप्रेशन सिंटैक्स के)।
  इससे आपका कोड पढ़ने वालों को उलझन हो सकती है, क्योंकि ऐसी जगहों पर भी अंकगणितीय एक्सप्रेशन हल होने लगते हैं जहाँ उम्मीद नहीं होती।
  ~~~~

## अंकगणितीय एक्सप्रेशन में वेरिएबल का इस्तेमाल

अंकगणितीय संदर्भों का एक पहलू ऐसा है जो पढ़ने में आसानी बढ़ाता है।

```bash
height=10
width=20
area=$(( height * width ))
```

क्या आपने ध्यान दिया कि अंकगणितीय एक्सप्रेशन में वेरिएबल से `$` डॉलर चिह्न गायब हैं?
Bash आपको ऐसा करने देता है।
इससे एक्सप्रेशन पढ़ना बहुत आसान हो जाता है।

मैनुअल कहता है,

> एक्सप्रेशन के अंदर शेल वेरिएबल को पैरामीटर एक्सपैंशन सिंटैक्स के बिना भी नाम से इस्तेमाल किया जा सकता है।

यह ऐरे के एलिमेंट के लिए भी काम करता है:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

लेकिन दूसरे पैरामीटर एक्सप्रेशन के लिए उनका खास सिंटैक्स इस्तेमाल करना पड़ता है।
उदाहरण के लिए, किसी स्ट्रिंग की लंबाई को दोगुना करना:

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

और पोज़िशनल पैरामीटर के लिए भी यही करना पड़ता है।
अगर पहले दो पोज़िशनल पैरामीटर चौड़ाई और ऊँचाई दर्शाते हैं:

```bash
area=$(( $1 * $2 ))
```
