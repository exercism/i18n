# परिचय

## तुलना ऑपरेटर

तुलना ऑपरेटर कई दूसरी भाषाओं की तरह ही होते हैं।

बराबरी के लिए `==` (बराबर) और `!=` (बराबर नहीं) ऑपरेटर होते हैं।

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

इससे बड़ा और इससे छोटा बताने वाले ऑपरेटर भी उसी सामान्य तरीके के होते हैं।

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if` के साथ निर्णय लेना

`if` एक्सप्रेशन का पूरा रूप ऐसा होता है:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- हर शर्त के चारों ओर गोल ब्रैकेट `()` लगाना ज़रूरी है।
- हर शर्त का परिणाम बूलियन `true` या `false` ही होना चाहिए। कुछ भाषाओं में जैसे ‘ट्रुथी’ और ‘फाल्सी’ होते हैं, वैसी कोई अवधारणा Kotlin में नहीं है।
- अगर सिर्फ एक ही एक्सप्रेशन हो, तो कर्ली ब्रैकेट `{}` लगाना ज़रूरी नहीं है।
- `else if` और `else`, दोनों वैकल्पिक हैं, और एक से ज़्यादा `else if` ब्लॉक भी हो सकते हैं।

`if` एक्सप्रेशन का उपयोग किसी वैल्यू को ‘चुनने’ के लिए भी किया जा सकता है:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## कोई और विकल्प?

जान-बूझकर लिए गए फैसले से Kotlin में Java वाला टर्नरी ऑपरेटर `? :` _नहीं_ रखा गया है। इसके बजाय `if ... else` का छोटा रूप पसंद किया जाता है:

```Kotlin
return if (isOK) goodValue else badValue
```
