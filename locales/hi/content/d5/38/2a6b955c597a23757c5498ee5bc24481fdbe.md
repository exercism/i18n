# परिचय

C एक स्टैटिक टाइप वाली भाषा है। इसका मतलब है कि कंपाइल होने के समय हर चीज़ का एक टाइप होता है।
किसी [वेरिएबल][variable] के लिए नाम चुनने और उसका टाइप तय करने को वेरिएबल घोषित करना कहा जाता है।

वेरिएबल को उसका टाइप स्पष्ट रूप से बताकर घोषित किया जाता है।
वेरिएबल के नाम को [कुछ नियमों का पालन करना पड़ता है][name-rules], जैसे कि उसकी शुरुआत किसी अक्षर या अंडरस्कोर से होनी चाहिए।
कुछ नाम इस्तेमाल नहीं किए जा सकते, क्योंकि वे [कीवर्ड][reserved-keywords] या [दूसरे आइडेंटिफायर][reserved-identifiers] के लिए आरक्षित हैं।

वेरिएबल को कोई वैल्यू देना या उसे बदलना वेरिएबल असाइनमेंट से किया जाता है।
वैल्यू सेट करने से वह वेरिएबल परिभाषित हो जाता है।
वेरिएबल को परिभाषित करने को इनिशियलाइज़ेशन भी कहते हैं।

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

किसी वेरिएबल की वैल्यू को [`=` सिंपल असाइनमेंट ऑपरेटर][assignment-operator] की मदद से असाइन और बदला जा सकता है।
एक बार परिभाषित होने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C एक [इम्पेरेटिव][imperative] [प्रोसीजरल][procedural] भाषा है।
यहाँ हर गणना [स्टेटमेंट][statements] की एक श्रृंखला के रूप में होती है, और ये स्टेटमेंट किसी एक [फंक्शन][function] या कई फंक्शनों का हिस्सा होते हैं।

हर फंक्शन में शून्य या उससे अधिक [पैरामीटर][parameters] हो सकते हैं।
फंक्शन बनाते समय सभी पैरामीटर और रिटर्न वैल्यू का टाइप स्पष्ट रूप से बताना पड़ता है।
फंक्शन से वैल्यू [`return` कीवर्ड][return-keyword] की मदद से लौटाई जाती हैं।
डिफ़ॉल्ट रूप से फंक्शन की स्टोरेज क्लास [एक्सटर्नल][storage_class] होती है, यानी वह प्रोग्राम के जीवनकाल तक बनी रहती है और फ़ाइल के बाहर से भी दिखाई दे सकती है।
इसे रोकने के लिए `static` कीवर्ड जोड़कर उसकी विज़िबिलिटी सिर्फ़ फ़ाइल के अंदर तक सीमित की जा सकती है।

```c
static int add(int x, int y) {
  return x + y;
}
```

ऊपर के उदाहरण में `x` और `y` वेरिएबल सिर्फ़ उसी फंक्शन के अंदर इस्तेमाल किए जा सकते हैं, यानी इनका स्कोप फंक्शन तक ही सीमित है।
[स्कोप][scope] का मतलब है कि किसी नाम (यानी प्रोग्राम के किसी हिस्से) से जुड़ी वैल्यू सिर्फ़ उसी कोड के "क्षेत्र" में पहुँच में रहती है जहाँ वह परिभाषित है।
C में मुख्य कोड क्षेत्र ये हैं:

- फ़ाइल
- फंक्शन
- कोड ब्लॉक (जैसे लूप और दूसरे कंस्ट्रक्ट के अंदर)

फंक्शन को कॉल करने के लिए उसका नाम लिखते हैं और उसके हर पैरामीटर के लिए आर्गुमेंट पास करते हैं।

```c
int sum = add(1, 2);
```

C दो तरह की [टिप्पणियों][comments] का समर्थन करता है।
सिंगल लाइन टिप्पणियों से पहले `//` लगाया जाता है (C99 से), और मल्टी-लाइन टिप्पणियाँ `/*` और `*/` के बीच लिखी जाती हैं।
