# परिचय

## रेगुलर एक्सप्रेशन

**रेगुलर एक्सप्रेशन** (रेगेक्स) अक्षरों के ऐसे क्रम होते हैं जो टेक्स्ट में खोजने का पैटर्न तय करते हैं।

रेगुलर एक्सप्रेशन का सिंटैक्स सीखना इस विषय के दायरे से बाहर है।
हम उन एक्सप्रेशनों पर ध्यान देंगे जो `jq` रेगेक्स इस्तेमाल करने के लिए उपलब्ध कराता है।

### रेगेक्स का प्रकार

हर टूल रेगुलर एक्सप्रेशन का अपना संस्करण लागू करता है।
`jq` में [Oniguruma][oniguruma] रेगेक्स लाइब्रेरी शामिल है, जो ज़्यादातर Perl v5.8 के रेगेक्स से मेल खाती है।

`jq` जो खास सिंटैक्स इस्तेमाल करता है, वह [Oniguruma के GitHub रेपो पर मिल सकता है][onig-syntax]।

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` में रेगुलर एक्सप्रेशन के लिए कोई खास सिंटैक्स नहीं है।
इन्हें सीधे स्ट्रिंग के रूप में लिखा जाता है।
इसका मतलब है कि रेगुलर एक्सप्रेशन में जो भी बैकस्लैश हों, उन्हें स्ट्रिंग में एस्केप करना पड़ता है।

जैसे, अंकों के लिए कैरेक्टर क्लास (`\d`) को `"\\d"` लिखना ज़रूरी है।
~~~~

<!-- prettier-ignore-end -->

### रेगेक्स फंक्शन

`jq` में रेगुलर एक्सप्रेशन [कुछ फिल्टरों तक ही सीमित हैं][jq-regex-funcs]।

#### साधारण मिलान

जब आपको यह जानना हो कि कोई स्ट्रिंग किसी पैटर्न से मेल खाती है या नहीं, तो `test` फिल्टर का इस्तेमाल कीजिए।

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

यह फिल्टर एक _बूलियन_ परिणाम देता है।

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

#### मिलान के बारे में जानकारी

जब आपको वह सबस्ट्रिंग निकालनी हो जो असल में पैटर्न से मेल खाई हो, तो `match` फिल्टर का इस्तेमाल कीजिए।

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

यह फिल्टर यह देता है:

- अगर कोई मिलान न हुआ हो, तो कुछ नहीं, या
- अगर मिलान हुआ हो, तो कई प्रॉपर्टी वाला एक ऑब्जेक्ट।

यह उदाहरण बैकरेफ सिंटैक्स `\1` से लगातार आने वाले दो एक जैसे स्वर ढूँढता है।

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match` फिल्टर _हर_ मिलान के लिए एक ऑब्जेक्ट लौटाता है।
यह उदाहरण सारे स्वर ढूँढने के लिए `"g"` फ्लैग को काम करते हुए दिखाता है।

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

#### कैप्चर की गई सबस्ट्रिंग

`match` फिल्टर की तरह, `capture` फिल्टर भी मिलान होने पर एक ऑब्जेक्ट लौटाता है।

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

जो ऑब्जेक्ट लौटता है, वह **नेम्ड कैप्चर** का मैप होता है।

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

#### सिर्फ सबस्ट्रिंग

`scan` फिल्टर `"g"` फ्लैग लगे `match` जैसा ही है।

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` सबस्ट्रिंग की एक _स्ट्रीम_ देता है।

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

सबस्ट्रिंग पकड़ने के लिए `[...]` ऐरे कंस्ट्रक्टर का इस्तेमाल कीजिए।

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

#### स्ट्रिंग को तोड़ना

अगर आपको पता है कि स्ट्रिंग के कौन-से हिस्से आप **रखना** चाहते हैं, तो `match` या `scan` का इस्तेमाल कीजिए।
और अगर आपको पता है कि कौन-से हिस्से आप **हटाना** चाहते हैं, तो `split` का इस्तेमाल कीजिए।

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
**एक आर्गुमेंट वाला** `split` फिल्टर अपने आर्गुमेंट को एक **तय स्ट्रिंग** मानता है।

`split` के साथ रेगेक्स इस्तेमाल करने के लिए दूसरा आर्गुमेंट **देना ही होगा**; खाली स्ट्रिंग देना भी ठीक है।
~~~~

<!-- prettier-ignore-end -->

यह उदाहरण एक स्ट्रिंग को किसी भी खाली स्थान पर तोड़ता है।

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

#### प्रतिस्थापन

`sub` और `gsub` फिल्टर इनपुट स्ट्रिंग को बदल सकते हैं। इनपुट के जो हिस्से मैच हुए हैं, उनकी जगह ये एक रिप्लेसमेंट स्ट्रिंग रख देते हैं।

सिर्फ पहला मिलान बदलने के लिए `sub` का इस्तेमाल कीजिए।
सारे मिलान बदलने के लिए `gsub` का इस्तेमाल कीजिए।

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

रिप्लेसमेंट टेक्स्ट मैच हुई सबस्ट्रिंग को भी संदर्भित कर सकता है; इसके लिए नेम्ड कैप्चर और [स्ट्रिंग इंटरपोलेशन][jq-interp] का इस्तेमाल कीजिए।

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

### फ्लैग

ऊपर के सभी फिल्टरों में FLAGS एक स्ट्रिंग है, जिसमें बताए गए फ्लैग शून्य या अधिक हो सकते हैं।

- `g` - वैश्विक खोज (सारे मिलान ढूँढता है, सिर्फ पहला नहीं)
- `i` - केस-असंवेदनशील खोज
- `m` - मल्टी लाइन मोड ('.' न्यूलाइन से भी मैच करेगा)
- `n` - खाली मिलान अनदेखा करें
- `p` - s और m, दोनों मोड चालू
- `s` - सिंगल लाइन मोड ('^' -> '\A', '$' -> '\Z')
- `l` - सबसे लंबे संभव मिलान ढूँढें
- `x` - एक्सटेंडेड रेगेक्स फॉर्मैट (खाली स्थान और कमेंट अनदेखा करें)

जैसे

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
