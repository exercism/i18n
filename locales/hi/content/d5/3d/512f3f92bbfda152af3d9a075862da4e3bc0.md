# कमांड लाइन पर टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
scarb cairo-test
```

पहले टेस्ट के अलावा बाकी सभी टेस्ट इग्नोर कर दिए गए हैं। पहला टेस्ट पास कर लेने के बाद `tests` डायरेक्टरी में मौजूद टेस्ट की सोर्स फाइल खोलिए, अगले टेस्ट से `#[ignore]` फ्लैग हटाइए और उसे पास कीजिए। हर अलग टेस्ट एक फंक्शन है, जिसके ऊपर `#[test]` फ्लैग लगा होता है। ऐसे ही आगे बढ़ते रहिए, जब तक हर टेस्ट पास न हो जाए।

अगर आप टेस्ट की सोर्स फाइल में बदलाव किए बिना _सभी_ टेस्ट चलाना चाहते हैं, तो यह चलाइए:

```bash
scarb cairo-test --include-ignored
```

किसी एक खास टेस्ट को चलाने के लिए, चाहे वह इग्नोर किया गया हो या नहीं, जैसे `some_test`, आप यह चला सकते हैं:

```bash
scarb cairo-test -f some_test
```

Cairo टेस्ट के बारे में अधिक जानने के लिए ऑनलाइन [टेस्ट डॉक्युमेंटेशन][cairo-tests] देखिए।

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
