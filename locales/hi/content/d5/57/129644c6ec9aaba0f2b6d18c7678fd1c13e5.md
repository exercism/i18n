# निर्देश

इस अभ्यास में आप न्यूयॉर्क के एक ब्यूटी सैलून के लिए अपॉइंटमेंट शेड्यूलर पर काम करेंगे, जो 15 सितंबर 2012 को खुला था।

आपके पास चार कार्य हैं, और इन सबमें अपॉइंटमेंट की तारीखों से ही काम पड़ेगा। तारीखें और समय इन तीन फॉर्मैट में से किसी एक में होंगे:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
टेस्ट अपने आप कल्चर को `en-US` पर सेट कर देंगे। आपको कल्चर खुद सेट करने या बताने की ज़रूरत नहीं है।
~~~~

## 1. अपॉइंटमेंट की तारीख पार्स कीजिए

ऐसा `schedule` फंक्शन बनाइए जो अपॉइंटमेंट की तारीख के लिखित रूप को पार्स करके उसे उससे मेल खाने वाले `DateTime` फॉर्मैट में बदल सके:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. जाँचिए कि अपॉइंटमेंट बीत चुका है या नहीं

ऐसा `hasPassed` फंक्शन बनाइए जो अपॉइंटमेंट की तारीख लेता है और जाँचता है कि वह अपॉइंटमेंट कहीं अतीत में रह गया है या नहीं:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. जाँचिए कि अपॉइंटमेंट दोपहर बाद का है या नहीं

ऐसा `isAfternoonAppointment` फंक्शन बनाइए जो अपॉइंटमेंट की तारीख लेता है और जाँचता है कि वह अपॉइंटमेंट दोपहर बाद का है या नहीं (12:00 बजे या उसके बाद, और 18:00 बजे से पहले):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. अपॉइंटमेंट का समय और तारीख बताइए

ऐसा `description` फंक्शन बनाइए जो अपॉइंटमेंट की तारीख लेता है और उस तारीख और समय का विवरण लौटाता है:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. सालगिरह की तारीख लौटाइए

ऐसा `anniversaryDate` फंक्शन बनाइए जो इस साल की सालगिरह की तारीख लौटाता है, यानी 15 सितंबर:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
