# परिचय

Gleam को Erlang वर्चुअल मशीन (BEAM) पर चलाया जा सकता है, और JavaScript रनटाइम पर भी। इन रनटाइम का उपयोग दूसरी कई भाषाएँ भी करती हैं, इसलिए इन भाषाओं में लिखे कोड को Gleam से कॉल कर पाना अक्सर बहुत काम आता है।

Gleam का _बाहरी फंक्शन_ फीचर आपको दूसरी भाषाओं के फंक्शन Gleam में इम्पोर्ट करने और बिना किसी रनटाइम ओवरहेड के कॉल करने की सुविधा देता है।

अगर आपका Gleam प्रोजेक्ट Erlang वर्चुअल मशीन पर चलता है और आप Erlang के `lists` मॉड्यूल से `reverse` फंक्शन कॉल करना चाहते हैं, तो आप Gleam के किसी फंक्शन की परिभाषा के ठीक ऊपर `@external` एट्रिब्यूट जोड़कर ऐसा कर सकते हैं:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

इसके बाद इसे किसी सामान्य Gleam फंक्शन की तरह कॉल किया जा सकता है:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

अगर आप इस कोड को JavaScript रनटाइम के लिए कंपाइल करने की कोशिश करेंगे, तो यह एक एरर मैसेज के साथ फेल हो जाएगा, क्योंकि JavaScript के लिए कोई इम्प्लीमेंटेशन मौजूद नहीं है। JavaScript रनटाइम के लिए दूसरा इम्प्लीमेंटेशन इस तरह दिया जा सकता है:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

ऐसा भी हो सकता है कि आप एक Gleam इम्प्लीमेंटेशन लिखें, जिसका उपयोग तब होगा जब मौजूदा कंपाइल टारगेट के लिए कोई बाहरी इम्प्लीमेंटेशन न हो:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
