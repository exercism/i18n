# परिचय

`Option` एक [enum][enum] है जिसका उपयोग फंक्शन के रिटर्न की वैधता जाँचने के लिए किया जाता है। इसे इस तरह परिभाषित किया गया है:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

यह [`haxe.ds`][haxeDs] पैकेज का हिस्सा है:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
