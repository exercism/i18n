# निर्देश

आप फिर से रसोई में हैं और [Leah's Luscious Lasagna][lasagna] की लसान्या रेसिपी को और निखार रहे हैं। यहाँ के काम आपसे एक साथ कई इनपुट सँभालने को कहते हैं, और ठीक ऐसे ही मौकों पर *लोकल्स* काम आते हैं, यानी Factor के नाम वाले बाइंडिंग।

## 1. पकाने का स्टेटस तय कीजिए

`cooking-status` बनाइए जो स्टैक से टाइमर की रीडिंग ले और एक स्टेटस स्ट्रिंग लौटाए।

- `0` → `"Lasagna is done."`
- `f` (टाइमर कभी सेट नहीं हुआ था) → `"You forgot to set the timer."`
- कोई भी अन्य संख्या → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. तैयारी के समय का अनुमान लगाइए

`preparation-time` बनाइए जो परतों के नामों का एक ऐरे और हर परत के लिए औसत मिनटों की संख्या ले, और तैयारी का कुल समय लौटाए।

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. ज़रूरी नूडल्स और सॉस निकालिए

`quantities` बनाइए जो परतों के नामों का एक ऐरे ले और *दो* वैल्यू लौटाए: ज़रूरी नूडल्स के ग्राम (हर नूडल परत के लिए 50 ग्राम) और ज़रूरी सॉस के लीटर (हर सॉस परत के लिए `1/5` लीटर)।

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. गुप्त सामग्री जोड़िए

आपका दोस्त सामग्री की एक सूची भेजता है; उसमें अंतिम चीज़ उसकी गुप्त सामग्री है। `add-secret-ingredient` बनाइए जो उसकी सूची और आपकी सूची ले, और आपकी सूची लौटाए जिसमें गुप्त सामग्री जोड़ दी गई हो।

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. रेसिपी को नाप के अनुसार बढ़ाइए

कुकबुक की रेसिपी से दो हिस्से बनते हैं। `scale-recipe` बनाइए जो एक रेसिपी (सामग्री के नाम से मात्रा तक का हैशटेबल) और हिस्सों की लक्ष्य संख्या ले, और नाप के अनुसार बढ़ी हुई नई रेसिपी लौटाए।

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
