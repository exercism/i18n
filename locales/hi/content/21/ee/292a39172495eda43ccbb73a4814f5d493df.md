# निर्देश

Astrid एक साहसी कीमियागर है, और वह अलग-अलग दुनियाओं से जुटाई गई जादुई माप की इकाइयों को मानकीकृत करने की कोशिश कर रही है।
कुछ दुनियाओं में चिह्नित माप मिलते हैं, जो ऋणात्मक भी हो सकते हैं, और कुछ में अचिह्नित, जो हमेशा धनात्मक होते हैं।
इसके अलावा, Astrid के पास कुछ दुर्लभ सामग्रियों के लिए दो कस्टम टाइप हैं, और उसे इन टाइपों के बीच आसानी से रूपांतरण करने का तरीका चाहिए।

आपको Astrid की मदद करनी है ताकि वह चिह्नित और अचिह्नित पूर्णांकों के बीच रूपांतरण कर सके, और Cairo के `Into` तथा `TryInto` ट्रेट की मदद से अपनी खास सामग्री के टाइपों के लिए कस्टम टाइप रूपांतरण बना सके।

## 1. जादुई इकाइयों को चिह्नित और अचिह्नित पूर्णांकों के बीच बदलिए

Astrid के पास कुछ माप ऐसे भी आते हैं जो धनात्मक या ऋणात्मक वैल्यू में होते हैं (चिह्नित पूर्णांक), लेकिन कुछ कामों के लिए उसे यह पक्का करना होता है कि वैल्यू हमेशा धनात्मक रहे (अचिह्नित पूर्णांक)।

एक फंक्शन लिखकर Astrid की मदद कीजिए जो यह रूपांतरण करता है:

1. एक चिह्नित पूर्णांक (`i32`) को अचिह्नित पूर्णांक (`u16`) में।
2. एक अचिह्नित पूर्णांक (`u16`) को चिह्नित पूर्णांक (`i32`) में।

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. कस्टम सामग्री टाइप का रूपांतरण कीजिए

Astrid दो दुर्लभ सामग्रियों, **Essence** और **Elixir**, के साथ काम करती है, जिन्हें कस्टम टाइप से दर्शाया जाता है।
वह **Essence** को **Elixir** में बदल पाना चाहती है, लेकिन उल्टा नहीं।

दो कस्टम टाइप, `Essence` और `Elixir`, बनाकर और `Essence` से `Elixir` में बदलने के लिए `Into` ट्रेट लागू करके Astrid की मदद कीजिए।

एक फंक्शन लिखिए जो एक `Essence` लेता है और `.into()` की मदद से उसे `Elixir` में बदल देता है।

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
