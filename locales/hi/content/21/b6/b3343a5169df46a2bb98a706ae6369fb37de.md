जादूगरनी बनने की राह पर चल रही Elyse को कुछ बुनियादी बातों का अभ्यास करना है।
उसके पास ताश की एक गड्डी है, जिसके साथ वह हेर-फेर करना चाहती है।

बातें थोड़ी आसान बनाने के लिए वह सिर्फ 1 से 10 तक के पत्ते इस्तेमाल करती है।

## 1. गड्डी से एक पत्ता निकालिए

दी गई गड्डी से `idx` स्थान पर मौजूद पत्ता लौटाइए।

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. गड्डी में एक पत्ता बदलिए

`idx` स्थान वाले पत्ते को दिए गए नए पत्ते से बदल दीजिए और बदली हुई गड्डी लौटाइए।
ध्यान रखिए कि इससे इनपुट वेक्टर बदल जाता है (म्यूटेट हो जाता है), और यह ठीक है।

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. गड्डी के ऊपर एक पत्ता डालिए

गड्डी के ऊपर नया पत्ता डालिए और गड्डी लौटाइए।

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. गड्डी से एक पत्ता हटाइए

गड्डी से `idx` स्थान वाला पत्ता हटाइए और गड्डी लौटाइए।

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. गड्डी का सबसे ऊपर वाला पत्ता हटाइए

गड्डी के सबसे ऊपर वाला पत्ता हटाइए और गड्डी लौटाइए।

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. गड्डी के नीचे एक पत्ता डालिए

गड्डी के सबसे नीचे नया पत्ता डालिए और गड्डी लौटाइए।

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. गड्डी के नीचे से एक पत्ता हटाइए

गड्डी के सबसे नीचे वाला पत्ता हटाइए और गड्डी लौटाइए।

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. गड्डी का आकार जाँचिए

जाँचिए कि गड्डी का आकार दिए गए `deck_size` के बराबर है या नहीं।

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
