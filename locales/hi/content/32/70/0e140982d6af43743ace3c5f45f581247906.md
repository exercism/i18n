# परिचय

Haskell में फंक्शन लिखते समय हम [पैटर्न मैचिंग][pattern-matching] का उपयोग कर सकते हैं। पैटर्न मैचिंग Haskell की एक बहुत शक्तिशाली सुविधा है, जिससे आप डेटा कंस्ट्रक्टर से मिलान कर सकते हैं और अंदर की वैल्यू से वेरिएबल बाँध सकते हैं। जैसा कि नाम से पता चलता है, हम वैल्यू को पैटर्न से मिलाते हैं, और अगर वैल्यू पैटर्न से मिल जाए, तो हम पैटर्न के अंदर की वैल्यू से वेरिएबल बाँध सकते हैं। पैटर्न मैचिंग मुख्य रूप से इन बातों से बनी है: वैल्यू को पहचानना, वेरिएबल बाँधना, और वैल्यू को तोड़कर अलग करना।

~~~~exercism/note
Elixir जैसी भाषाओं में पैटर्न मैचिंग, Haskell की पैटर्न मैचिंग से थोड़ी अलग होती है। उदाहरण के लिए Elixir एक ही पैटर्न में एक ही नाम को कई बार बाँधने की अनुमति देता है, जबकि Haskell नहीं देता।
~~~~


उदाहरण के लिए इस फंक्शन को देखिए:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

यहाँ हमारे पास एक फंक्शन `lucky` है, जो एक `Int` लेता है और एक `String` लौटाता है। हमने इस फंक्शन के लिए दो पैटर्न बनाए हैं, एक जो संख्या `7` से मिलता है और एक जो किसी भी दूसरी संख्या से मिलता है। नाम कुछ भी हो सकता है (बशर्ते वह Haskell के नामकरण नियम का पालन करे), लेकिन यहाँ हम `x` इस्तेमाल करते हैं। अगर संख्या `7` है, तो फंक्शन `"Lucky number seven!"` लौटाएगा, वरना वह `"Sorry, you're out of luck, pal!"` लौटाएगा। यहाँ ध्यान देने वाली बात यह है कि पैटर्न ऊपर से नीचे के क्रम में जाँचे जाते हैं, इसलिए अगर हम पैटर्न का क्रम बदल दें, तो फंक्शन हमेशा `"Lucky number seven!"` ही लौटाएगा।

## ऐरे पैटर्न

एक बहुत आम पैटर्न ऐरे पर मिलान करने का है, यानी ऐरे का सिर और पूँछ अलग कर लेना। ऐसा इसलिए है क्योंकि ऐरे की बनावट वास्तव में एक लिंक्ड ऐरे जैसी होती है। यहाँ एक ऐसे फंक्शन का उदाहरण है जो एक ऐरे का सिर और पूँछ लौटाता है:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

यहाँ हमारे पास दो पैटर्न हैं, एक जो खाली ऐरे से मिलता है और एक जो कम से कम एक एलिमेंट वाले ऐरे से मिलता है। ऐसा इसलिए है क्योंकि अगर ऐरे खाली है, तो हमें उसके लिए एक अलग केस लिखना पड़ता है, वरना हमें एक रनटाइम एरर मिलेगी। अगर ऐरे खाली नहीं है, तो हम ऐरे के सिर को `x` से और ऐरे की पूँछ को `xs` से मिला सकते हैं। यह `:` (कॉन्स) ऑपरेटर से किया जाता है, जिसका उपयोग ऐरे के शुरू में एक एलिमेंट जोड़ने के लिए किया जाता है। लेकिन पैटर्न मैचिंग में यह हमें ऐरे को उसके सिर और पूँछ में तोड़ने देता है, यानी किसी तरह उल्टा काम करता है।

`xs` ऐरे की पूँछ के लिए आम नाम है, यह दिखाता है कि यह एक ऐरे है, लेकिन अगर आप नेस्टेड ऐरे पर काम कर रहे हों, तो `xss` इस्तेमाल कर सकते हैं, जो दिखाता है कि यह ऐरे का ऐरे है।

## टपल पैटर्न

ऐरे की तरह हम टपल पर भी मिलान कर सकते हैं। यहाँ एक ऐसे फंक्शन का उदाहरण है जो एक टपल लेता है और उसका पहला और दूसरा एलिमेंट लौटाता है:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

यहाँ हमारे पास एक पैटर्न है जो दो एलिमेंट वाले टपल से मिलता है। पहला एलिमेंट `x` से बाँधा जाता है और दूसरा एलिमेंट `y` से बाँधा जाता है।

## वाइल्डकार्ड पैटर्न

कभी-कभी हमें किसी वेरिएबल की वैल्यू की परवाह नहीं होती, हमें सिर्फ पैटर्न से मिलान करना होता है। ऐसे में वाइल्डकार्ड पैटर्न काम आता है। इसे अंडरस्कोर `_` से दिखाया जाता है।

यहाँ एक ऐसे फंक्शन का उदाहरण है जो एक ऐरे का पहला एलिमेंट लौटाता है:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

यहाँ हम कह रहे हैं कि हमें ऐरे की पूँछ की ज़रूरत नहीं है, इसलिए हम उसे अनदेखा करने के लिए वाइल्डकार्ड पैटर्न इस्तेमाल करते हैं।

## टाइप पैटर्न

हम टाइप पर भी मिलान कर सकते हैं। यह उस टाइप के कंस्ट्रक्टर का उपयोग करके किया जाता है। हम टाइप से वैल्यू भी निकाल सकते हैं, जैसे हमने टपल के साथ किया था।

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

पहले पैटर्न में हम `Guest` कंस्ट्रक्टर से मिलान करते हैं, और दूसरे पैटर्न में हम `User` कंस्ट्रक्टर से मिलान करते हैं और उसके अंदर की वैल्यू को `name` से बाँध देते हैं।
