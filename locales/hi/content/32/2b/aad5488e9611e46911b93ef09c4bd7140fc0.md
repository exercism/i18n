# निर्देश परिशिष्ट

परिमेय संख्याओं को किसी वास्तविक संख्या की घात तक उठाने के लिए उस संख्या को गैर-पूर्णांक घात तक बढ़ाना पड़ता है। ऐसी सुविधा WebAssembly में मूल रूप से उपलब्ध नहीं है।

लेकिन आप `x ^ y` को `x ^ y = exp(y * ln(x))` के रूप में भी लिख सकते हैं।

और सौभाग्य से, एक्सपोनेंशियल तथा प्राकृतिक लघुगणक निकालने के लिए अलग-अलग श्रेणियों का उपयोग किया जा सकता है।

## एक्सपोनेंशियल फंक्शन

एक्सपोनेंशियल के लिए सबसे अच्छा तरीका एक [टेलर श्रेणी](https://en.wikipedia.org/wiki/Taylor_series) है:

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## लघुगणक फंक्शन (धनात्मक x के लिए)

प्राकृतिक लघुगणक को कुशलता से निकालने के कई तरीके हैं। इनमें से एक [इनवर्स हाइपरबोलिक टैंगेंट](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent) पर आधारित श्रेणी है:

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

प्राकृतिक लघुगणक निकालने की एक और टेलर श्रेणी भी है:

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

यह केवल 0 और 2 के बीच के `x` के लिए ही सटीक होती है। लेकिन हम `ln(x) = - ln(1 / x)` का उपयोग भी कर सकते हैं।

## पूर्णांक घात

पूर्णांक घात के लिए गुणा का उपयोग करना बेहतर है, और उसके साथ लूप या रिकर्शन भी, ताकि प्रदर्शन और परिशुद्धता दोनों बनी रहें। और भी बेहतर प्रदर्शन के लिए [हॉर्नर का तरीका](https://en.wikipedia.org/wiki/Horner%27s_method) अपनाकर गुणाओं की संख्या घटाई जा सकती है।
