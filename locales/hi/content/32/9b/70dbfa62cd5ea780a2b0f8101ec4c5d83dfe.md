# परिचय

if स्टेटमेंट के अलावा JavaScript में switch स्टेटमेंट भी होता है, जिससे शर्त के आधार पर लॉजिक चलाया जा सकता है।
इसका उपयोग तब किया जाता है जब एक ही वेरिएबल की तुलना कई अलग-अलग विकल्पों से करनी हो।
यह तुलना सख्त समानता (`===`) जाँचकर की जाती है, देखिए [तुलना][concept-comparison]।
किसी वेरिएबल `x` के लिए JavaScript में switch स्टेटमेंट का सिंटैक्स ऐसा होता है।

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default` केस ज़रूरी नहीं है। इसका उपयोग तब कीजिए जब बाकी कोई भी विकल्प वेरिएबल से मेल न खाए और आप कुछ कोड चलाना चाहते हों।

ऊपर दिए गए `break` स्टेटमेंट इसलिए ज़रूरी हैं क्योंकि JavaScript में डिफॉल्ट रूप से सारे केस "फॉलथ्रू" होते हैं।
इसका मतलब है कि अगर कोई `break` स्टेटमेंट न हो, तो पहले मेल खाने वाले विकल्प के नीचे लिखा सारा कोड भी चल जाएगा, भले ही `x` उन विकल्पों से मेल न खाता हो।
JavaScript में `switch` इस्तेमाल करते समय "डिफॉल्ट रूप से फॉलथ्रू" वाला यह व्यवहार एक आम गलती है।
किसी फंक्शन के अंदर इस समस्या से बचने के लिए `break` की जगह `return` भी इस्तेमाल किया जा सकता है।
