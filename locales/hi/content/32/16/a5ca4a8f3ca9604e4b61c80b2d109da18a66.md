# संकेत

## सामान्य

- कॉन्ट्रैक्ट रिटर्न टाइप के बाद और `is` से पहले आता है:

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- कॉन्ट्रैक्ट के अंदर आप आर्गुमेंट और ऑब्जेक्ट के एट्रिब्यूट इस्तेमाल कर सकते हैं, इसलिए
  `limit` भी उपलब्ध रहता है।
- टेस्ट `-chk` के बिना बनाए जाते हैं, इसलिए गलत कॉन्ट्रैक्ट से वे फेल नहीं होंगे। इन्हें
  पढ़ने वाले को ध्यान में रखकर लिखिए।

## 1. हैरनेस तैयार कीजिए

- `create` पर `pre kg > 0` लगाइए।
- बॉडी वही आम `new` ही है: एट्रिब्यूट सेट कीजिए और उसे लौटा दीजिए।

## 2. कितनी क्षमता बची है?

- `and` से जुड़ी दो शर्तें: `pre load >= 0 and load <= limit`.
- `post result >= 0`. यह `pre` से ही निकलता है, और यही इसे कहने लायक बनाता है: यह दर्ज
  करता है कि जवाब पर भरोसा क्यों किया जा सकता है।

## 3. यह कितना भरा है?

- `pre load >= 0` और `post result >= 0`.
- `load * 100 / limit`, इसी क्रम में। पहले भाग दिया तो सारी जानकारी खत्म हो जाएगी, ठीक
  वैसे ही जैसे `tuning-the-strings` में होता है।

## 4. क्या यह सुरक्षित है?

- कोई `pre` नहीं: पूरी बात यही है कि किसी भी लोड के बारे में पूछा जा सकता है।
- `post` सवाल को दोहराता है: `post result = (load <= limit)`.
  ब्रैकेट इसलिए, क्योंकि `=` यहाँ दो अलग-अलग कामों के लिए दो बार इस्तेमाल हो रहा है।
