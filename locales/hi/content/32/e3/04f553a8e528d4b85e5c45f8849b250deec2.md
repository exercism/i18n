# निर्देशों का परिशिष्ट

## एक्सेप्शन संदेश

कभी-कभी [एक्सेप्शन उठाना](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) ज़रूरी हो जाता है। ऐसा करते समय आपको हमेशा एक **अर्थपूर्ण एरर संदेश** शामिल करना चाहिए, जो बताए कि एरर का स्रोत क्या है। इससे आपका कोड पढ़ने में आसान होता है और डीबग करने में काफी मदद मिलती है। कई बार आपको पता होता है कि एरर का स्रोत किसी खास टाइप का होगा। ऐसी स्थितियों में आप [बिल्ट-इन एरर टाइपों](https://docs.python.org/3/library/exceptions.html#base-classes) में से कोई एक उठाना चुन सकते हैं, पर तब भी एक अर्थपूर्ण संदेश शामिल करना चाहिए।

इस अभ्यास में जब पास किया गया आर्गुमेंट कोई वैध बाइनरी लिटरल न हो, तब आपको [raise स्टेटमेंट](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) का उपयोग करके `ValueError` "फेंकना" होता है। टेस्ट तभी पास होंगे जब आप `exception` को `raise` करें और उसके साथ एक संदेश भी दें।

किसी संदेश के साथ `ValueError` उठाने के लिए संदेश को `exception` टाइप के आर्गुमेंट के रूप में लिखिए:

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
