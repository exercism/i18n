# परिचय

[`Rational numbers`][rational] ऐसी भिन्न होती हैं जिनमें एक पूर्णांक अंश को एक पूर्णांक हर से बाँटा जाता है।

उदाहरण के लिए, हम `2//3` को अनुमानित `Float64` वैल्यू `0.6666...` के बजाय एक सटीक भिन्न के रूप में संग्रहीत कर सकते हैं।

इसका फायदा यह है कि ([integer overflow][integer-overflow] जैसी चरम स्थिति को छोड़कर) एक परिमेय संख्या सटीक बनी रहती है, और ऐसी राउंडिंग एरर से बचती है जो फ्लोटिंग-पॉइंट संख्याओं के साथ अक्सर अपरिहार्य होती हैं।

कुछ और जानकारी Julia के [मैनुअल पेज][julia-rational] पर मिलेगी।

परिमेय संख्याएँ काफी सरल संख्यात्मक टाइप हैं और जैसा आप अपेक्षा करेंगे, वैसा ही काम करती हैं।
चूँकि शुरुआती संस्करणों से ही ये Julia में एक मानक टाइप रही हैं, इसलिए अधिकांश फंक्शन इन्हें पूर्णांकों और फ्लोट की तरह ही इनपुट के रूप में स्वीकार कर लेते हैं।

## परिमेय संख्याएँ बनाना

इन्हें बनाना दो पूर्णांकों के बीच `//` लगाने जितना ही आसान है।

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

सामान्य गुणनखंड अपने आप हट जाते हैं और भिन्न अपने ["न्यूनतम रूप"][lowest-terms] में बदल जाती है: वे सबसे छोटे पूर्णांक जो भिन्न को ठीक-ठीक दर्शाते हैं, और जिनका हर ऋणात्मक नहीं होता।

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

अनंत परिणाम स्वीकार किए जाते हैं, लेकिन [`NaN`][NaN] नहीं।

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## परिमेय संख्याओं के साथ अंकगणित

सामान्य [`arithmetic operators`][operators] `+ - * / ^ %` परिमेय संख्याओं के साथ काम करते हैं, बिल्कुल वैसे ही जैसे दूसरे संख्यात्मक टाइपों के साथ।

पूर्णांकों और दूसरी `Rational` संख्याओं को भी शामिल किया जा सकता है, और परिणाम एक `Rational` मिलता है।
एक्सप्रेशन में `float` शामिल करने पर आउटपुट `float` आता है, जिससे सटीकता में (संभवतः) कमी आ सकती है।

अगर `float` चाहिए, तो परिमेय संख्या को बदलने के लिए बस `float()` फंक्शन इस्तेमाल कीजिए।
यह बिल्कुल सामान्य है कि किसी लंबी गणना में सटीकता बनाए रखने के लिए परिमेय संख्याओं का उपयोग किया जाए और अंत में उन्हें `float` में बदल दिया जाए।

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

परिमेय संख्याओं को [सम्मिश्र संख्याओं][complex] के साथ भी जोड़ा जा सकता है।
सम्मिश्र संख्याओं की चर्चा एक [अलग अवधारणा][complex-concept] में की गई है।

## अन्य ऑपरेशन

Julia में परिमेय संख्याएँ बस संख्याएँ ही हैं।
कंपाइलर आम तौर पर आवश्यकतानुसार टाइप बदल देता है।

लेकिन ध्यान रखिए कि तुलनाएँ सिर्फ उन भिन्नों के लिए काम करती हैं जिनका दशमलव रूप सीमित होता है:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

वरना तुलना के लिए `Rational` को `Float` में बदलना चाहिए:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

गणितीय फंक्शन इनपुट के रूप में परिमेय संख्याएँ लेते हैं, लेकिन परिणाम फ्लोटिंग-पॉइंट में दे सकते हैं:

```julia-repl
julia> sqrt(9//16)
0.75
```
