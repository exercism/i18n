# निर्देश

एक नई जादूगर के तौर पर एलिस को अपनी गड्डी का विश्लेषण कई अलग-अलग तरीकों से करना पड़ता है। चीज़ों को आसान रखने के लिए वह सिर्फ 1 से 10 तक की वैल्यू वाले पत्ते इस्तेमाल करती है।

## 1. गड्डी में किसी एक खास तरह के कितने पत्ते हैं, यह पता कीजिए

एलिस जानना चाहती है कि उसकी गड्डी में एक खास तरह के कितने पत्ते हैं।

एक फंक्शन `cardTypeCheck` लिखिए जो दो पैरामीटर लेता है: पत्तों का एक ऐरे (एलिस की गड्डी) और उस पत्ते का टाइप जिसे गिनना है।

<!--prettier-ignore -->
~~~exercism/note
फंक्शन को `forEach` इस्तेमाल करना चाहिए और गड्डी में बताए गए टाइप के पत्तों की संख्या लौटानी चाहिए।
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. कितने विषम या सम पत्ते हैं, यह पता कीजिए

एक और करतब के लिए एलिस को जानना होता है कि उसकी गड्डी में कितने विषम या सम पत्ते हैं।

एक फंक्शन `determineOddEvenCards` बनाइए जो दो पैरामीटर लेता है: पत्तों का एक ऐरे (एलिस की गड्डी) और एक बूलियन (true का मतलब 'सम' होता है और false का मतलब 'विषम')।

यह फंक्शन सिर्फ एक संख्या लौटाना चाहिए: गड्डी में मौजूद विषम या सम पत्तों की संख्या, जो दूसरे आर्गुमेंट की वैल्यू पर निर्भर करती है।

<!--prettier-ignore -->
~~~exercism/note
अभ्यास के लिए इस बार फंक्शन के अंदर `for...of` लूप इस्तेमाल कीजिए।
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
