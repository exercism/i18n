# परिचय

## डिफ़ॉल्ट पैरामीटर वैल्यू

फंक्शन के किसी भी पैरामीटर के लिए [डिफ़ॉल्ट पैरामीटर वैल्यू][default-parameter-values] दी जा सकती है। इसके लिए पैरामीटर लिस्ट में उस पैरामीटर को, उसकी टाइप एनोटेशन के बाद, एक वैल्यू असाइन की जाती है। जब डिफ़ॉल्ट पैरामीटर वैल्यू तय की गई हो, तो फंक्शन को कॉल करते समय कॉलर वह पैरामीटर छोड़ सकता है, और तब उसकी जगह डिफ़ॉल्ट वैल्यू इस्तेमाल की जाती है।

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## वैरिएडिक पैरामीटर

Swift में [_वैरिएडिक पैरामीटर_][variadic-parameters] की मदद से एक फंक्शन के एक ही पैरामीटर में एक ही टाइप की शून्य या अधिक वैल्यू पास की जा सकती हैं। इसे पैरामीटर की टाइप एनोटेशन के अंत में `...` लगाकर दर्शाया जाता है।

ये वैल्यू अपने आप एक ऐरे में इकट्ठा कर दी जाती हैं, और उस ऐरे के एलिमेंट उसी टाइप के होते हैं जो वैरिएडिक पैरामीटर का टाइप होता है।

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

ध्यान दीजिए कि वैरिएडिक पैरामीटर इस्तेमाल करते समय Swift में एक सीमा है।
अगर किसी फंक्शन की परिभाषा में वैरिएडिक पैरामीटर के बाद और पैरामीटर आते हैं, तो वैरिएडिक पैरामीटर के बाद वाले पहले पैरामीटर के लिए आर्गुमेंट लेबल होना _ज़रूरी_ है।

## इन-आउट पैरामीटर

फंक्शन के बॉडी के अंदर पैरामीटर को कॉन्स्टेंट माना जाता है, वेरिएबल नहीं; किसी पैरामीटर की वैल्यू बदलने की कोशिश करने पर कंपाइल-टाइम एरर मिलती है।
अगर कोई फंक्शन किसी पैरामीटर की वैल्यू बदलना चाहता है, तो उसे इस बदलाव को स्पष्ट करने के लिए _इन-आउट पैरामीटर_ इस्तेमाल करना होगा।

इन-आउट पैरामीटर इस्तेमाल करने के लिए प्रोग्रामर को तीन बातों का ध्यान रखना होगा:

1. फंक्शन की परिभाषा में इन-आउट पैरामीटर को स्पष्ट रूप से चिह्नित करना होगा, यानी पैरामीटर की टाइप एनोटेशन में `:` और टाइप के नाम के बीच `inout` कीवर्ड लिखना होगा।
2. इन-आउट पैरामीटर में पास की जाने वाली वैल्यू को वेरिएबल घोषित किया जाना चाहिए, कॉन्स्टेंट नहीं। इसी तरह वह लिटरल भी नहीं हो सकती।
3. फंक्शन को कॉल करते समय वेरिएबल के नाम से पहले `&` लगाना होगा, जो साफ़ तौर पर बताता है कि इसे बदला जा सकता है।

ऐसा करने पर फंक्शन इन-आउट पैरामीटर की एक आंतरिक कॉपी बनाता है, फंक्शन के बॉडी में बताए अनुसार उसे बदलता है, और फिर फंक्शन के लौटने पर वह बदली हुई वैल्यू उसी वेरिएबल में वापस कॉपी कर देता है जो पास किया गया था।

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
इन-आउट पैरामीटर के बारे में कुछ और नियम भी हैं जिनका ध्यान रखना चाहिए।

1  इन-आउट पैरामीटर वाले फंक्शन के अंदर, जिस वेरिएबल को इन-आउट पैरामीटर के रूप में पास किया गया था, उसका इस्तेमाल आप नहीं कर सकते।
2. एक ही फंक्शन में एक ही वेरिएबल को कई इन-आउट पैरामीटर के रूप में पास नहीं किया जा सकता।
   उदाहरण के लिए, `inoutFunc(&mutVar, &mutVar)` पर कंपाइलर एरर देता है।
~~~~

## नेस्टेड फंक्शन

Swift में आप [दूसरे फंक्शन के अंदर भी फंक्शन][nested-functions] बना सकते हैं।
ऐसे फंक्शन **नेस्टेड फंक्शन** कहलाते हैं।

नेस्टेड फंक्शन आम तौर पर निजी हेल्पर की तरह इस्तेमाल होते हैं, जो बाहरी स्कोप को उलझाए बिना उन फंक्शन के लिए कुछ खास काम करते हैं जिनके अंदर वे लिखे गए होते हैं:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

नेस्टेड फंक्शन सामान्य फंक्शन की तरह ही व्यवहार करते हैं, लेकिन उनकी दृश्यता उसी फंक्शन के बॉडी तक सीमित रहती है जिनके अंदर वे बनाए गए हैं।
