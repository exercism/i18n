# निर्देश

आपके एक दोस्त की **Gross Store** नाम की एक पुरानी थोक दुकान है।
यह नाम उस मात्रा से आया है जिसमें यह दुकान सामान बेचती है: यहाँ सब कुछ [ग्रोस इकाई][gross-unit] में होता है।
आपके दोस्त ने आपसे अपनी दुकान के लिए एक पॉइंट ऑफ सेल (POS) सिस्टम बनाने को कहा है।
**पहले आप उसका एक प्रोटोटाइप बनाना चाहते हैं।**
**आपके प्रोटोटाइप में आपका सिस्टम सिर्फ मात्रा ही दर्ज करेगा।**
मदद के लिए आपके दोस्त ने आपको मापों की एक सूची दी है:

| इकाई               | संख्या |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. माप की इकाई को अपने प्रोग्राम में संग्रहीत कीजिए

इस माप का उपयोग करने के लिए आपको वह माप अपने प्रोग्राम में संग्रहीत करना होगा।

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. ग्राहक का नया बिल बनाइए

आपको एक ऐसा फंक्शन बनाना है जो ग्राहक के लिए नया (खाली) बिल बनाता है।

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. ग्राहक के बिल में कोई चीज़ जोड़िए

इसे बनाने के लिए आपको यह करना होगा:

- अगर दिया गया `unit` `units` मैप में न हो तो `false` लौटाइए।
- वरना उस चीज़ को चीज़ के नाम पर इंडेक्स करके ग्राहक के `bill` में जोड़िए, और फिर `true` लौटाइए।
- अगर वह चीज़ बिल में पहले से मौजूद है, तो उसकी मात्रा उतनी बढ़ाइए जितनी दिए गए `unit` की होती है।

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> ध्यान रखिए कि लौटाई गई वैल्यू का टाइप `bool` है।

## 4. ग्राहक के बिल से कोई चीज़ हटाइए

इसे बनाने के लिए आपको यह करना होगा:

- अगर दी गई चीज़ बिल में **नहीं** है तो `false` लौटाइए
- अगर दिया गया `unit` `units` मैप में न हो तो `false` लौटाइए।
- अगर नई मात्रा 0 से कम हो जाए तो `false` लौटाइए।
- अगर नई मात्रा 0 है, तो उस चीज़ को `bill` से पूरी तरह हटाइए और फिर `true` लौटाइए।
- वरना उस चीज़ की मात्रा घटाइए और `true` लौटाइए।

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> ध्यान रखिए कि लौटाई गई वैल्यू का टाइप `bool` है।

## 5. ग्राहक के बिल में मौजूद किसी खास चीज़ की मात्रा लौटाइए

इसे बनाने के लिए आपको यह करना होगा:

- अगर `item` बिल में नहीं है तो `0` और `false` लौटाइए।
- वरना बिल में उस चीज़ की मात्रा और `true` लौटाइए।

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> ध्यान रखिए कि लौटाई गई वैल्यू के टाइप `int` और `bool` हैं।

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
