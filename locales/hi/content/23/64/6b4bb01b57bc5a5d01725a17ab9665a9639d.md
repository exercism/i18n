# परिचय

C# का [`Attribute`][attribute-concept] एक ऐसा तरीका देता है जिससे आप किसी घोषणा को सजाकर उसके साथ मेटाडेटा जोड़ सकते हैं, चाहे वह घोषणा क्लास हो, मेथड हो, इनम हो, फील्ड हो, प्रॉपर्टी हो, या [समर्थित कोई अन्य][attribute-targets] घोषणा हो।

किसी घोषणा पर [एट्रिब्यूट][attribute] लगाने के लिए आप उसे घोषणा से पहले ब्रैकेट `[]` के बीच लिखते हैं। नीचे दिए उदाहरण में `ClassAttribute` और `FieldAttribute`, दोनों इस्तेमाल हुए हैं:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

घोषणा के रूप में दिया गया यह मेटाडेटा कोड के साथ सिर्फ अतिरिक्त संरचित जानकारी जोड़ता है, कोड का व्यवहार नहीं बदलता। लेकिन कोड का कोई दूसरा हिस्सा इस मेटाडेटा का उपयोग करके यह बदल सकता है कि उसका लक्ष्य कैसा व्यवहार करेगा, या उसमें कुछ कार्यक्षमताएँ जोड़ सकता है, बदल सकता है, हटा सकता है, या कुछ सीमित कर सकता है।

कई पहले से परिभाषित एट्रिब्यूट मौजूद हैं, जैसे `Flags`, `Obsolete` और `Conditional`। ध्यान दीजिए कि [`Flags` एट्रिब्यूट][flags-attribute] का पूरा नाम `FlagsAttribute` है, लेकिन एट्रिब्यूट के रूप में इस्तेमाल करते समय "Attribute" वाला प्रत्यय छोड़ा जा सकता है।

आगे दिए गए चार पहले से परिभाषित एट्रिब्यूट नियमित रूप से इस्तेमाल होते हैं:

- `[Flags]`: System नेमस्पेस में पहले से परिभाषित। यह बताता है कि इनम बिटवाइज़ ऑपरेशन और `Enum.HasFlag()` मेथड, दोनों का समर्थन करता है। इसके अलावा `ToString` सारे फ्लैग दिखाता है: [उदाहरण देखिए][flags-example]।
- `[Obsolete]`: System नेमस्पेस में पहले से परिभाषित। इससे आप एक संदेश जोड़ सकते हैं जिसमें बताया जाए कि कोड क्यों पुराना हो चुका है; इसका उपयोग कंपाइलर की चेतावनियाँ या एरर दिखाने के लिए किया जा सकता है।
- `[Conditional]`: System.Diagnostics नेमस्पेस में पहले से परिभाषित। डीबगिंग (डायग्नोस्टिक्स) के लिए कंपाइल के समय कुछ मेथड कॉल हटाने की सुविधा देता है।
- `[CallerMemberName]`: System.Runtime.CompilerServices नेमस्पेस में पहले से परिभाषित। इससे किसी मेथड को अपने कॉलर की जानकारी मिल सकती है।
