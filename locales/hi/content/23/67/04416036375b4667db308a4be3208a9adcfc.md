# परिचय

## बूलियन

Gleam में सही और गलत वैल्यू को `Bool` टाइप से दर्शाया जाता है। इसकी केवल दो वैल्यू होती हैं: `True` और `False`. इन वैल्यू को किसी वेरिएबल में बाँधा जा सकता है:

```gleam
let true_variable = True
let false_variable = False
```

बूलियन वैल्यू पर काम करने के लिए `&&`, `||` और `!` ऑपरेटरों का उपयोग किया जा सकता है:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&` और `||` ऑपरेटर शॉर्ट-सर्किट इवैल्यूएशन का उपयोग करते हैं। इसका मतलब है कि ऑपरेटर के दाईं ओर वाले एक्सप्रेशन का मूल्यांकन तभी किया जाता है जब ज़रूरत हो।

हर ऑपरेटर की प्राथमिकता अलग होती है: `!` का मूल्यांकन `&&` और `||` से पहले होता है। एक्सप्रेशन के एक हिस्से का मूल्यांकन बाकी हिस्सों से पहले करने के लिए घुंघराले ब्रैकेट का उपयोग किया जा सकता है:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
