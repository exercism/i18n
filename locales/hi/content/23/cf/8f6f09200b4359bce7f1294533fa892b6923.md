# टेस्ट

हर अभ्यास के लिए एक बार सेटअप करना पड़ता है, जिसमें कुछ मिनट लग सकते हैं:

```
npm install
```

दो शेल खोलिए। पहले शेल में बिल्ड की प्रक्रिया शुरू कीजिए।

```
npm start
```

दूसरे शेल में टेस्ट चलाना शुरू कीजिए।

```
npm test
```

जैसे-जैसे आप कोड में बदलाव करते हैं, ये दोनों प्रक्रियाएँ लगातार दोबारा बिल्ड करती रहेंगी और टेस्ट दोबारा चलाती रहेंगी।
