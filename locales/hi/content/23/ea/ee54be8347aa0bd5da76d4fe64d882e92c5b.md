# परिचय

[ऐरे][arrays-concept] में ऐरे की सामग्री का विश्लेषण करने के लिए पहले से मौजूद मेथड होते हैं।
इनमें से ज़्यादातर मेथड आर्गुमेंट के रूप में एक ऐसा फंक्शन लेते हैं जो सही या गलत लौटाता है।
ऐसे फंक्शन को [प्रेडिकेट][predicate_in_programming] कहते हैं।

ये पहले से मौजूद मेथड _`for` लूप_ या पहले से मौजूद `forEach` मेथड की जगह इस्तेमाल करने के लिए बने हैं:

`predicate` लूप से विश्लेषण करने का उदाहरण:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

पहले से मौजूद मेथड से विश्लेषण करने का उदाहरण:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

ऐरे का विश्लेषण करने के लिए उपलब्ध कुछ और उपयोगी पहले से मौजूद मेथड नीचे दिखाए गए हैं। ऐरे के सारे मेथड की पूरी सूची के लिए [MDN][mdn-array-methods] देखिए।

## `includes`

> includes() मेथड यह तय करता है कि ऐरे की प्रविष्टियों में कोई खास वैल्यू शामिल है या नहीं, और इसके अनुसार सही या गलत लौटाता है। [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> every() मेथड यह जाँचता है कि ऐरे के सारे एलिमेंट उस जाँच को पास करते हैं या नहीं जो दिया गया फंक्शन लागू करता है। यह एक बूलियन वैल्यू लौटाता है। [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> some() मेथड यह जाँचता है कि ऐरे में कम से कम एक एलिमेंट उस जाँच को पास करता है या नहीं जो दिया गया फंक्शन लागू करता है। [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> find() मेथड दिए गए ऐरे के उस पहले एलिमेंट की वैल्यू लौटाता है जो दिए गए जाँच फंक्शन को पूरा करता है। अगर कोई वैल्यू जाँच फंक्शन को पूरा नहीं करती, तो undefined लौटाया जाता है। [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> findIndex() मेथड ऐरे के उस पहले एलिमेंट का इंडेक्स लौटाता है जो दिए गए जाँच फंक्शन को पूरा करता है। वरना यह -1 लौटाता है, यानी कोई भी एलिमेंट जाँच में पास नहीं हुआ। [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
