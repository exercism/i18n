# परिचय

इनहेरिटेंस, OOP (ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग) की एक मूल अवधारणा है।
यह एक IS-A संबंध दर्शाता है।
प्रोग्रामिंग में इसका मतलब वही है जो अंग्रेज़ी में है: पैरेंट से फीचर विरासत में लेना (प्रोग्रामिंग में फीचर आम तौर पर फंक्शन और वेरिएबल होते हैं)।

जैसा कि नीचे दिखाया गया है, `Animal` नाम की एक क्लास देखिए,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` एक पैरेंट क्लास है, क्योंकि इस क्लास की प्रॉपर्टी को सामान्य रूप से सभी जानवरों तक विस्तारित किया जा सकता है।

`Lion` नाम के एक जानवर को लीजिए, जिसकी क्लास कुछ इस तरह है:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` एनोटेशन का इस्तेमाल यह बताने के लिए किया जाता है कि सबक्लास का कोई मेथड अपने सुपरक्लास के मेथड को ओवरराइड कर रहा है।
इसे इस्तेमाल करना ज़रूरी नहीं है, लेकिन यह करना बेहतर माना जाता है।
~~~~

अब जब भी हम यह करते हैं,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

ध्यान दीजिए: यहाँ `Animal` क्लास का ऑब्जेक्ट `Lion` से बनाया जा रहा है।
आउटपुट कुछ इस तरह होगा

```java
Lion here!!
```

OOP के अनुसार इनहेरिटेंस कई तरह के होते हैं, लेकिन Java इनमें से केवल कुछ ही को समर्थन करता है (मल्टी-लेवल और हायरार्किकल)।
इसके बारे में और पढ़ने के लिए [यहाँ][java-inheritance] पढ़िए।
