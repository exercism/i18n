# परिचय

[टपल][tuples] कई वैल्यू को मिलाकर एक कंपाउंड वैल्यू बनाते हैं।
ऐरे की तरह नहीं, टपल की सभी वैल्यू का एक ही टाइप होना ज़रूरी नहीं है, और टपल बनने के बाद उसका साइज़ तय रहता है।

टपल बनाने के लिए कॉमा से अलग की गई वैल्यू को गोल ब्रैकेट के अंदर लिखिए:

```swift
let order = ("biscuits", 2.99, 3)
```

आप टाइप एनोटेशन साफ़-साफ़ लिख भी सकते हैं:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

बिना नाम वाले टपल से अलग-अलग एलिमेंट निकालने के लिए शून्य से शुरू होने वाला इंडेक्स सिंटैक्स इस्तेमाल कीजिए (`.0`, `.1`, आदि):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## नाम वाले टपल

टपल बनाते समय आप उसके अलग-अलग एलिमेंट को नाम दे सकते हैं:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

एलिमेंट को नाम देने से कोड पढ़ने में आसान हो जाता है, और आप उनके लेबल के साथ डॉट नोटेशन इस्तेमाल करके एलिमेंट तक पहुँच सकते हैं:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

टाइप एनोटेशन में भी एलिमेंट के नाम लिख सकते हैं:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## टपल में बदलाव करना

अगर किसी टपल को वेरिएबल (`var`) के रूप में घोषित किया गया हो, तो आप उसके एलिमेंट बदल सकते हैं:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## एक से अधिक वैल्यू लौटाना

Swift के फंक्शन सिर्फ एक ही वैल्यू लौटा सकते हैं, लेकिन टपल लौटाने से आप कई वैल्यू को एक साथ पैक करके [फंक्शन से लौटा सकते हैं][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## टपल को खोलना

आप टपल की वैल्यू को अलग-अलग कॉन्स्टेंट या वेरिएबल में बाँट सकते हैं, यानी टपल को खोल सकते हैं:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

टपल को खोलना `for-in` लूप में भी सीधे काम करता है:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
