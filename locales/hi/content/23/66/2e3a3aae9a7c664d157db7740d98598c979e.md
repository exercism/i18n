# टेस्ट

## कमांड लाइन

कमांड लाइन से टेस्ट चलाने के लिए नीचे दिया गया कमांड इस्तेमाल किया जा सकता है:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>` के स्थान पर उस अभ्यास का नाम लिखिए जिसे आप बना रहे हैं।

## इंटरैक्टिव

Prolog को इंटरैक्टिव तरीके से चलाने के लिए पहले यह चलाइए:

```bash
swipl
```

Prolog का कंसोल शुरू हो जाने के बाद अपना इम्प्लीमेंटेशन लोड कीजिए और यह लिखकर टेस्ट चलाइए:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>` के स्थान पर उस अभ्यास का नाम लिखिए जिसे आप बना रहे हैं।

### बदलाव दोबारा लोड करना

ऊपर दी गई फाइलें लोड हो जाने के बाद, आपने जो भी बदलाव किए हैं उन्हें यह चलाकर लागू कर सकते हैं:

```
?- make.
```

## छोड़े गए टेस्ट

जब आप कोई अभ्यास पहली बार शुरू करते हैं, तो सिर्फ पहला टेस्ट ही चलता है। बाकी सारे टेस्ट, `test` गोल में `condition(pending)` जोड़कर छोड़ दिए गए हैं। पहला टेस्ट पास हो जाने के बाद, `condition(pending)` में `pending` को `true` में बदलकर अगला टेस्ट फिर से चालू कीजिए। हर टेस्ट के लिए यही दोहराइए, जब तक सारे टेस्ट चलने और पास होने न लगें।

### कमांड लाइन

बाकी बचे टेस्ट भी चलाने के लिए कमांड के अंत में `-- --all` आर्गुमेंट जोड़िए:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
