# Readonly क्लास और प्रॉपर्टी

Readonly क्लास और प्रॉपर्टी की मदद से क्लास ऐसी public प्रॉपर्टी बना सकती है जिन्हें आसानी से पढ़ा जा सके, पर बदला न जा सके। किसी प्रॉपर्टी को readonly घोषित करने के लिए उसके टाइप से पहले `readonly` लिखना ज़रूरी है। ऐसी प्रॉपर्टी में वैल्यू सिर्फ एक ही बार असाइन की जा सकती है। दोबारा असाइन करने या उस वैल्यू को बदलने की कोशिश करने पर एरर मिलती है।

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

Readonly क्लास इसी व्यवहार को आगे बढ़ाती हैं। किसी क्लास को `readonly` घोषित करने पर यही नियम उसकी हर प्रॉपर्टी पर लागू हो जाता है। इसके अलावा ऐसी क्लास में डायनैमिक प्रॉपर्टी जोड़ना भी संभव नहीं रहता।

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
