# विस्तृत जानकारी

## सामान्य सिंटैक्स

`for` लूप उन सबसे आम स्टेटमेंट में से एक है जिनका इस्तेमाल कुछ लॉजिक को बार-बार चलाने के लिए किया जाता है। Go में यह `for` कीवर्ड, एक हेडर और एक कोड ब्लॉक से मिलकर बनता है। कोड ब्लॉक में लूप के अंदर का कोड होता है, जो घुंघराले ब्रैकेट में लिखा जाता है। हेडर तीन हिस्सों से बना होता है, जिन्हें सेमीकोलन `;` से अलग किया जाता है: इनिट, शर्त और पोस्ट।

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **इनिट** हिस्सा वह कोड होता है जो लूप शुरू होने से पहले सिर्फ एक बार चलता है।
- **शर्त** हिस्सा एक ऐसा एक्सप्रेशन होना चाहिए जो बूलियन वैल्यू देता है और तय करता है कि लूप कब रुकना चाहिए।
  जब तक यह शर्त सही रहती है, लूप के अंदर का कोड चलता रहता है।
  जैसे ही यह एक्सप्रेशन गलत हो जाता है, लूप का कोई और इटरेशन नहीं चलता।
- **पोस्ट** हिस्सा वह कोड होता है जो हर इटरेशन के अंत में चलता है।

**ध्यान दें:** दूसरी भाषाओं के विपरीत, हेडर के इन तीन हिस्सों को कोई गोल ब्रैकेट `()` नहीं घेरता। असल में, ऐसा ब्रैकेट लगाने पर कंपाइलेशन एरर मिलती है। लेकिन लूप के अंदर के कोड को घेरने वाले घुंघराले ब्रैकेट `{ }` हमेशा ज़रूरी होते हैं।

## `for` लूप: एक उदाहरण

आम तौर पर इनिट हिस्सा एक काउंटर वेरिएबल तैयार करता है और शर्त जाँचती है कि लूप आगे चलना चाहिए या रुक जाना चाहिए। पोस्ट हिस्सा हर इटरेशन के अंत में काउंटर बढ़ा देता है।

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

यह लूप `1` से `9` तक की संख्याएँ प्रिंट करेगा (`9` समेत)। स्टेप तय करना अक्सर बढ़ाने या घटाने वाले स्टेटमेंट से किया जाता है, जैसा ऊपर के उदाहरण में दिखाया गया है।

## हेडर के वैकल्पिक हिस्से

हेडर के इनिट और पोस्ट हिस्से वैकल्पिक हैं:

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

ऊपर दिखाए गए तरीके से `for` लूप में इनिट और पोस्ट हिस्से छोड़ देने पर आप Go में `while` लूप बना लेते हैं। Go में `while` नाम का कोई कीवर्ड नहीं है। यह Go के इस सिद्धांत का उदाहरण है कि कॉन्सेप्ट एक-दूसरे से अलग और स्वतंत्र होने चाहिए। चूँकि `while` लूप जैसा व्यवहार पाने के लिए पहले से एक कॉन्सेप्ट मौजूद है, यानी `for` लूप, इसलिए `while` को एक अलग कॉन्सेप्ट के रूप में नहीं जोड़ा गया।

## `break` और `continue`

लूप के अंदर के कोड में आप `break` कीवर्ड का इस्तेमाल करके लूप को पूरी तरह रोक सकते हैं:

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

इसके उलट, `continue` कीवर्ड सिर्फ मौजूदा इटरेशन को रोकता है और अगले इटरेशन के साथ आगे बढ़ जाता है:

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## अनंत `for` लूप

लूप के हेडर का शर्त वाला हिस्सा भी वैकल्पिक है। असल में, आप बिना हेडर वाला लूप भी लिख सकते हैं:

```go
for {
  // Endless loop...
}
```

यह लूप सिर्फ तब खत्म होगा जब प्रोग्राम बंद हो जाए या इसके अंदर कहीं `break` हो।

## लेबल और `goto`

जब हम `break` इस्तेमाल करते हैं, तो Go सबसे अंदर वाला लूप चलाना बंद कर देता है। इसी तरह, जब हम `continue` इस्तेमाल करते हैं, तो Go सबसे अंदर वाले लूप का अगला इटरेशन चलाता है।

लेकिन हमेशा ऐसा होना ज़रूरी नहीं है। हम लेबल का इस्तेमाल `break` और `continue` के साथ करके यह ठीक-ठीक बता सकते हैं कि हम किस लूप से बाहर निकलना चाहते हैं और किस लूप में आगे बढ़ना चाहते हैं।

इस उदाहरण में हम `OuterLoop` नाम का एक लेबल बना रहे हैं, जो सबसे बाहर वाले लूप को दर्शाएगा। सबसे अंदर वाले लूप में यह बताने के लिए कि हम सबसे बाहर वाले लूप से बाहर निकलना चाहते हैं, हम `break` के बाद सबसे बाहर वाले लूप के लेबल का नाम लिखते हैं:

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

लेबल का इस्तेमाल `continue` के साथ भी काम करेगा, और ऐसी स्थिति में Go उस लूप के अगले इटरेशन पर आगे बढ़ेगा जिसे वह लेबल दर्शाता है।

Go में `goto` कीवर्ड भी है, जो इसी तरह काम करता है और हमें कोड के एक हिस्से से दूसरे लेबल वाले हिस्से तक कूदने देता है।

**चेतावनी:** Go भले ही लेबल लगे कोड के किसी हिस्से पर कूदने देता है, लेकिन भाषा के इस फीचर का इस्तेमाल करने से कोड बहुत जल्दी पढ़ने में कठिन हो सकता है। इसी वजह से लेबल का इस्तेमाल अक्सर करने की सलाह नहीं दी जाती।
