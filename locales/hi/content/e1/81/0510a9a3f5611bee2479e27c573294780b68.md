# परिचय

एक [`while` लूप][while-loops] एक कंट्रोल फ्लो स्टेटमेंट है, जिसकी मदद से कोड तब तक चलाया जा सकता है जब तक कोई शर्त सही बनी रहती है।
Swift में दो तरह के while लूप होते हैं: while लूप और repeat-while लूप।
while लूप की शर्त लूप के अंदर का कोड चलने से पहले जाँची जाती है। अगर शर्त गलत हो, तो लूप के अंदर का कोड एक बार भी नहीं चलेगा।
Swift में while लूप का ढाँचा इस तरह होता है:

```swift
while <#condition#> {
  <#code#>
}
```

यहाँ लूप तब तक चलेगा जब तक count 0 से बड़ा है, और इस तरह यह 2, 1 और "Liftoff!" प्रिंट करेगा।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

एक [repeat-while लूप][while-loops] while लूप जैसा ही होता है, लेकिन इसमें शर्त लूप के अंदर का कोड चलने के बाद जाँची जाती है।
इसका मतलब है कि लूप के अंदर का कोड कम से कम एक बार तो चलेगा ही, भले ही शर्त गलत हो।
Swift में repeat-while लूप का ढाँचा इस तरह होता है:

```swift
repeat {
  <#code#>
} while <#condition#>
```

यहाँ शर्त गलत होने की वजह से लूप सिर्फ एक बार चलेगा।
चूँकि यह repeat-while लूप है, शर्त जाँचने से पहले लूप के अंदर का कोड एक बार चल चुकेगा।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
