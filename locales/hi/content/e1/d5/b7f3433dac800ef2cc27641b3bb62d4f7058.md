# परिचय

कोड को व्यवस्थित करने का एक ज़रूरी तरीका नेमस्पेस है।
दो फंक्शन के नाम आपस में टकरा सकते हैं। इसे उन्हें अलग-अलग नेमस्पेस में रखकर सुलझाया जा सकता है।
नेमस्पेस नेस्टेड हो सकते हैं, जिससे बड़े कोडबेस को व्यवस्थित करने में मदद मिल सकती है।
नेमस्पेस तक पहुँच स्कोप-रेज़ोल्यूशन ऑपरेटर `::` से की जाती है।

नीचे दिया गया उदाहरण दो अलग-अलग `foo` फंक्शन का उपयोग दिखाता है।
इन्हें उनके अपने-अपने नेमस्पेस को आगे लगाकर एक साथ इस्तेमाल किया जाता है।

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
