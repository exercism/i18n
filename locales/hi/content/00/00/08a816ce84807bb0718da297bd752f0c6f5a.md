# परिचय

एक *रेगुलर एक्सप्रेशन* (रेगेक्स) एक छोटा-सा पैटर्न होता है, जो बताता है कि किसी टेक्स्ट का रूप कैसा होना चाहिए। Factor के रेगेक्स टूल [`regexp`][regexp] वोकेबुलरी में रहते हैं, और पैटर्न `R/ ` और `/` के बीच लिखा जाता है।

पैटर्न में अधिकतर अक्षर अपने आप को ही दर्शाते हैं। कुछ खास टुकड़े बताते हैं कि अक्षर किस *प्रकार* के होंगे, या *कितने* होंगे:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

तो `R/ [A-Z]{2}-\d{4}/` का मतलब है "दो बड़े अक्षर, एक डैश और चार अंक"।

`matches?` यह जाँचता है कि कोई *पूरी* स्ट्रिंग इस पैटर्न पर खरती है या नहीं:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

कुछ दूसरे शब्द स्ट्रिंग के *अंदर* झाँकते हैं: `all-matching-subseqs` हर मैच लौटाता है, `count-matches` उन्हें गिनता है, `re-contains?` बताता है कि कोई मैच है या नहीं, और `re-replace` हर मैच की जगह नया टेक्स्ट लगा देता है:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
