# परिचय

Go में `string` बाइट्स का एक अपरिवर्तनीय क्रम होती है। ज़रूरी नहीं है कि ये बाइट्स अक्षरों को ही दर्शाएँ।

स्ट्रिंग लिटरल दोहरे उद्धरण चिह्नों के बीच लिखा जाता है:

```go
const name = "Jane"
```

`+` ऑपरेटर की मदद से स्ट्रिंग को जोड़ा जा सकता है:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

कुछ खास अक्षरों को बैकस्लैश लगाकर लिखना पड़ता है, जैसे स्ट्रिंग में टैब के लिए `\t` और नई लाइन के लिए `\n`।

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings` पैकेज में स्ट्रिंग पर काम करने के लिए बहुत उपयोगी फंक्शन मौजूद हैं।
स्ट्रिंग फंक्शन के बारे में अधिक जानकारी के लिए [strings पैकेज का दस्तावेज़ीकरण](https://pkg.go.dev/strings) देखिए।
यहाँ कुछ उदाहरण दिए गए हैं:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
