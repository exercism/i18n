# निर्देश

आप _Instruments of Texas_ में काम करते हैं और आपको Elixir में लिखे एक प्रायोगिक रिवर्स पोलिश नोटेशन [RPN] कैलकुलेटर पर काम करना है। आपकी टीम को एक समस्या का सामना करना पड़ रहा है: कुछ ऑपरेशन एरर देते हैं और इससे पूरी प्रक्रिया क्रैश हो जाती है। आपको एक फंक्शन लिखना है जो ऑपरेशन फंक्शन को लपेट ले, ताकि एररों को Elixir की शैली के कोड से और बेहतर ढंग से संभाला जा सके।

## 1. टीम को चेतावनी दीजिए

ऐसा फंक्शन `calculate!/2` बनाइए जो ऑपरेशन फंक्शन को कॉल करे और उसे एकमात्र आर्गुमेंट के रूप में स्टैक दे। ऑपरेशन फंक्शन कहीं और बनाया गया है, लेकिन आप जानते हैं कि यह या तो सफलतापूर्वक पूरा हो सकता है या एरर दे सकता है।

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> जिस फंक्शन के नाम के अंत में `!` होता है, वह प्रोग्रामर के लिए चेतावनी है कि यह फंक्शन एरर दे सकता है

## 2. एरर को लपेटिए

आगे और खोज करने पर आप देखते हैं कि कई फंक्शन अपनी सफलता या विफलता बताने के लिए एटम और टपल का उपयोग करते हैं। इसी तरीके से `calculate/2` बनाइए।

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. संदेश आगे भेजिए

कुछ एररों में ऐसी ज़रूरी जानकारी होती है जो आपके साथ काम करने वालों के पास होनी चाहिए, ताकि सिस्टम ठीक से काम करता रहे। एरर का संदेश आगे भेजने के लिए `calculate_verbose/2` बनाइए। एरर एक स्ट्रक्ट है, जिसमें `:message` फील्ड होता है।

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
