# परिचय

कभी-कभी आपको किसी सीक्वेंस को एक-एक एलिमेंट के बजाय *टुकड़ों* की शृंखला के रूप में देखना पड़ता है। [`grouping`][grouping], [`splitting`][splitting] और [`splitting.monotonic`][splitting.monotonic] वोकेबुलरी आपको ऐसा करने के चार तरीके देती हैं।

## `group`: आकार *n* के अलग-अलग टुकड़े

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

अगर सीक्वेंस की लंबाई *n* का गुणज नहीं है, तो अंतिम समूह *n* से छोटा होता है।

## `clump`: आकार *n* की ओवरलैपिंग स्लाइडिंग विंडो

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

अगर सीक्वेंस *n* से छोटा है, तो परिणाम खाली होता है।

## `split-when`: जहाँ भी कोई प्रेडिकेट सही लौटाए, वहाँ तोड़िए

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

हर एलिमेंट के लिए प्रेडिकेट को अलग से कॉल किया जाता है; जो एलिमेंट सही लौटाते हैं वे *ब्रेक पॉइंट* होते हैं और परिणाम में नहीं रखे जाते।

## `monotonic-split`: जहाँ पड़ोसी जोड़ी की जाँच फेल हो, वहाँ रन तोड़िए

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

प्रेडिकेट *पड़ोसी जोड़ियों* पर चलता है। जब तक वह सही लौटाता है, रन जारी रहता है; जब वह `f` लौटाता है, तो नया टुकड़ा शुरू होता है। `[ = ]` के साथ आपको बराबर एलिमेंट के रन मिलते हैं; `[ <= ]` के साथ गैर-घटते रन मिलते हैं; और इसी तरह।

## कब किसे इस्तेमाल करें

- **`group`/`clump`**: आप जानते हैं कि *आकार* कितना चाहिए।
- **`split-when`**: आप जानते हैं कि *ब्रेक एलिमेंट* कैसा दिखता है।
- **`monotonic-split`**: आप जानते हैं कि दो पड़ोसी एलिमेंट को *एक साथ रखने* वाली बात क्या है।
