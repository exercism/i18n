# टेस्ट

टेस्ट रनर का इस्तेमाल करने के लिए आपको [Godot ठीक से इंस्टॉल][installation] करना होगा।

## टेस्ट चलाना

हल लोड करने और उनका टेस्ट करने के लिए [टेस्ट रनर][test runner] का इस्तेमाल किया जाता है। टेस्ट रनर चलाने के लिए उसे अपने कंप्यूटर पर डाउनलोड कीजिए और फिर `godot` से उसे चलाइए। आगे चलकर, जब आप `exercism download` इस्तेमाल करेंगे, तब टेस्ट रनर अभ्यासों के साथ अपने आप डाउनलोड हो जाएगा।

### टेस्ट रनर डाउनलोड करना

टेस्ट रनर डाउनलोड करने के लिए नीचे दिए गए शेल स्निपेट का इस्तेमाल किया जा सकता है।

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### टेस्ट रनर चलाना

टेस्ट रनर को `godot` से हैडलेस मोड (बिना IDE) में चलाया जाता है।
`-s` या `--script` Godot को टेस्ट रनर स्क्रिप्ट चलाने के लिए कहता है।
टेस्ट रनर को दो आर्गुमेंट चाहिए: स्लग और हल डायरेक्टरी का पाथ।

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

उदाहरण के लिए,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
