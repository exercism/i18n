# परिचय

टपल एक हल्का-फुल्का तरीका है, जिससे किसी भी तरह के डेटा के एक तय समूह को एक साथ रखा जा सकता है। टपल का कोई खास नाम नहीं होता। किसी डेटा स्ट्रक्चर को नाम दे दिया जाए, तो वह `struct` बन जाता है। टपल के फील्ड्स के नाम नहीं होते; उन तक डीस्ट्रक्चरिंग के ज़रिए या उनके स्थान के ज़रिए पहुँचा जाता है।

## सिंटैक्स

### बनाना

टपल हमेशा टपल एक्सप्रेशन से ही बनाए जाते हैं:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

टपल में किसी भी संख्या में एलिमेंट्स हो सकते हैं।

### डीस्ट्रक्चरिंग से पहुँचना

टपल के एलिमेंट्स तक डीस्ट्रक्चरिंग से पहुँचा जा सकता है। इसका मतलब बस इतना है कि टपल के हर एलिमेंट को एक वेरिएबल का नाम दिया जाता है, और ऐसा करने पर वह टपल खर्च हो जाता है।

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### स्थान से पहुँचना

टपल के एलिमेंट्स तक संख्यात्मक स्थान वाले इंडेक्स से भी पहुँचा जा सकता है। इंडेक्सिंग, हमेशा की तरह, 0 से शुरू होती है।

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## टपल स्ट्रक्ट

आपसे टपल स्ट्रक्ट के साथ भी काम करने को कहा जाएगा। सामान्य स्ट्रक्ट की तरह इनके भी नाम होते हैं; लेकिन सामान्य स्ट्रक्ट से अलग, इनके फील्ड्स बेनाम होते हैं। इनका सिंटैक्स सामान्य टपल सिंटैक्स से बहुत मिलता-जुलता है। इनमें डीस्ट्रक्चरिंग और स्थान से पहुँचना, दोनों का इस्तेमाल किया जा सकता है।

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### फील्ड्स की विज़िबिलिटी

बेनाम टपल के सारे फील्ड्स हमेशा पब्लिक होते हैं। लेकिन टपल स्ट्रक्ट के फील्ड्स की विज़िबिलिटी अलग-अलग होती है, जो डिफॉल्ट रूप से प्राइवेट रहती है, ठीक वैसे ही जैसे सामान्य स्ट्रक्ट के फील्ड्स की। आप `pub` मॉडिफायर से फील्ड्स को पब्लिक बना सकते हैं, ठीक वैसे ही जैसे सामान्य स्ट्रक्ट में।

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
