# बुनियादी बातें

एक Sather प्रोग्राम **क्लासों** से बना होता है। क्लास एक नाम वाला डिब्बा है जिसमें रूटीन होते हैं। **रूटीन** काम का एक नाम वाला हिस्सा होता है, जो एक जवाब देता है।

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

इसे ऊपर से पढ़िए:

- `class GREETER is` एक डिब्बा खोलता है और उसे नाम देता है। क्लास के नाम बड़े अक्षरों में लिखे जाते हैं।
- `hello : STR is` `hello` नाम का रूटीन शुरू करता है, जो एक `STR` देता है, यानी टेक्स्ट का एक टुकड़ा, जिसे *स्ट्रिंग* कहते हैं। `: STR` इस बात का वादा है कि जवाब किस तरह का वापस आएगा।
- `return "Hello!";` जवाब लौटाता है। टेक्स्ट दोहरे कोटेशन चिह्नों के बीच लिखा जाता है।
- `end;` रूटीन को बंद करता है, और दूसरा `end;` क्लास को बंद करता है।

किसी लाइन में `--` के बाद जो कुछ भी है, वह **कमेंट** होता है। Sather इसे अनदेखा करता है; यह लोगों के लिए होता है।

```sather
-- This line is for the reader, not the computer.
```

कहीं और से रूटीन इस्तेमाल करने के लिए क्लास का नाम, दो कोलन और रूटीन का नाम लिखिए:

```sather
GREETER::hello        -- this is "Hello!"
```

एक ही क्लास के अंदर आप क्लास का नाम छोड़ सकते हैं:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

जो रूटीन कोई आर्गुमेंट नहीं लेता, उसे ब्रैकेट के बिना कॉल किया जाता है, यानी `hello`, न कि `hello()`.
