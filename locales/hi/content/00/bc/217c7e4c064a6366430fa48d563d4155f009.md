# परिचय

JavaScript में लॉजिक को शर्त के आधार पर चलाने का एक आम तरीका `if` स्टेटमेंट है।
इसमें `if` कीवर्ड, गोल ब्रैकेट में लिखी एक शर्त, और कर्ली ब्रैकेट में लिखा एक कोड ब्लॉक होता है।
कोड ब्लॉक तभी चलाया जाएगा जब शर्त का मान `true` हो।

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

इसका इस्तेमाल अकेले भी किया जा सकता है और `else` कीवर्ड के साथ मिलाकर भी।

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

`else` स्टेटमेंट के अंदर एक और शर्त जोड़ने के लिए आप `else if` का इस्तेमाल कर सकते हैं।

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
