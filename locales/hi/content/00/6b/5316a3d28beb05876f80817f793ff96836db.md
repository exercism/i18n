# परिचय

Elixir में फंक्शन को गतिशील रूप से डिस्पैच किया जा सकता है।

सभी मॉड्यूल नाम एटम होते हैं। Elixir के सभी मॉड्यूल नामों से पहले कंपाइल करते समय अपने आप `Elixir.` लगा दिया जाता है।

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir मॉड्यूल के नाम से खोज करके रनटाइम पर कॉल होने वाले फंक्शन का पता लगा सकता है। अगर मॉड्यूल का नाम किसी वेरिएबल से जुड़ा हो, तो यह खोज गतिशील रूप से की जा सकती है।

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
