# अपने कंप्यूटर पर अभ्यास हल कीजिए

अपने कंप्यूटर पर अभ्यास हल करने से आप सारी कोडिंग ऐसे वातावरण में कर पाते हैं जिससे आप पहले से परिचित हैं।

## CLI इंस्टॉल कीजिए

अपने कंप्यूटर पर कोई अभ्यास हल करने के लिए सबसे पहले आपको [इन निर्देशों](https://exercism.org/cli-walkthrough) के अनुसार Exercism कमांड लाइन इंटरफेस (CLI) को इंस्टॉल और कॉन्फिगर करना होगा।

### कॉन्फिगरेशन

CLI को बताना ज़रूरी है कि आप कौन हैं, ताकि हम चीज़ें सही तरीके से डाउनलोड कर सकें।
आपको अपना टोकन अपने [सेटिंग्स पेज](/settings/api_cli) पर मिल जाएगा।
इसके बाद नीचे दिए तरीके से CLI को कॉन्फिगर कीजिए, और `<your-api-token>` की जगह सेटिंग्स पेज पर दी गई वैल्यू डालिए:

```
exercism configure --token=<your-api-token>
```

## अभ्यास डाउनलोड कीजिए

इंस्टॉल हो जाने के बाद आप नीचे दिए कमांड से अभ्यास को अपने कंप्यूटर पर डाउनलोड कर सकते हैं। इसमें `<exercise-slug>` और `<track-slug>` की जगह अपने अभ्यास और ट्रैक की वैल्यू डालिए:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

इस कमांड का ढाँचा याद रखने की ज़रूरत नहीं है, क्योंकि हर अभ्यास के पेज पर उस अभ्यास के लिए सही कमांड लिखा होता है।

डाउनलोड कमांड पूरा होने पर अभ्यास की सारी फाइलें आपके कंप्यूटर पर आ जाती हैं।

## अभ्यास हल कीजिए

हर अभ्यास का उद्देश्य ऐसा इम्प्लीमेंटेशन बनाना है जो सारे टेस्ट पास कर ले।
ऐसे इम्प्लीमेंटेशन को ही _हल_ कहा जाता है।

इसमें आपकी मदद के लिए हर अभ्यास में ये फाइलें होती हैं:

- README.md: इसमें वे निर्देश लिखे होते हैं जिनमें समझाया जाता है कि आपसे क्या अपेक्षित है।
- HELP.md: टेस्ट कैसे चलाएँ और अटक जाने पर मदद कैसे लें, इसकी जानकारी।
- HINTS.md (वैकल्पिक): अभ्यास हल करने में मदद देने वाले संकेत।
- टेस्ट फाइल: इनमें वे टेस्ट होते हैं जो जाँचते हैं कि आपका हल सही है।
- स्टब फाइल: ये आपको शुरुआत देती हैं, ताकि आप अपना इम्प्लीमेंटेशन बनाना शुरू कर सकें।

किसी-किसी ट्रैक में कुछ और फाइलें भी होती हैं, जो टेस्ट चलाने के लिए उस ट्रैक के टूल को चाहिए होती हैं।

## अपना हल जमा कीजिए

जब आपका हल सारे टेस्ट पास कर ले, तो नीचे दिए कमांड से अपना हल जमा कर सकते हैं:

```
exercism submit <implementation_file_paths>
```

यह कमांड आपका हल Exercism वेबसाइट पर अपलोड करता है और हल वाले पेज का URL दिखा देता है।

इस कमांड को भी याद रखने की ज़रूरत नहीं है, क्योंकि अभ्यास की `HELP.md` फाइल में सही कमांड लिखा होता है।

अधूरा हल भी जमा किया जा सकता है, जिससे आप:

- देख सकते हैं कि दूसरों ने यह अभ्यास कैसे पूरा किया
- मेंटर से मदद माँग सकते हैं

## CLI की अन्य सुविधाएँ

### सभी कमांड देखिए

उपलब्ध सारे कमांड की पूरी सूची देखने के लिए help सबकमांड चलाइए।

```bash
exercism help
```

### समस्या आने पर

ध्यान रखिए कि आपके पास नवीनतम वर्शन हो।

जाँचिए कि आपके पास कौन-सा वर्शन है:

```bash
exercism version
```

नवीनतम रिलीज़ से तुलना कीजिए और अगर आपका वर्शन सबसे नया नहीं है तो अपग्रेड कीजिए।

अपग्रेड करने के बाद वर्शन फिर से जाँचिए। अगर वर्शन नहीं बदला है, तो पक्का कीजिए कि आप अपग्रेड की गई बाइनरी ही चला रहे हैं।

```bash
which exercism
```

अगर फिर भी दिक्कत आ रही है, तो GitHub पर exercism/cli में एक इश्यू खोलिए और उसमें troubleshoot कमांड का आउटपुट भी दीजिए।

```bash
exercism troubleshoot
```

आप [हमारे इश्यू ट्रैकर](https://github.com/exercism/exercism/issues) पर इश्यू खोल सकते हैं, और कम्युनिटी आपकी मदद करने की कोशिश करेगी। **कोई भी इश्यू खोलने से पहले [इंटरैक्टिव वॉकथ्रू](https://exercism.org/cli-walkthrough) पूरा कर लीजिए।**
