# निर्देश

एक समुद्री डाकू छिपी खाड़ियों वाले नक्शे में रास्ता तय कर रहा है।
नक्शा एक हैशटेबल है जिसमें खाड़ी का नाम चाबी होता है। हर वैल्यू उन खाड़ियों का एक ऐरे है जहाँ आप उस खाड़ी से सीधे पहुँच सकते हैं।

## 1. ज्वार की कतार खाली कीजिए

`tide-queue` को ऐसे बनाइए कि वह चीज़ों का एक ऐरे ले, हर चीज़ को (क्रम में) एक नए डीक्यू में डाले, और फिर उन सबको वापस एक ऐरे में निकाले जो मूल क्रम बनाए रखता हो। यह FIFO का ढाँचा है: पीछे से डालिए, आगे से निकालिए।

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. पहुँचने योग्य खाड़ियाँ

`coves-reachable` को ऐसे बनाइए कि वह एक शुरुआती खाड़ी और एक नक्शा ले, और `start` से पहुँचने योग्य हर खाड़ी का हैश-सेट लौटाए, जिसमें `start` खुद भी शामिल हो।

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

BFS के फ्रंटियर के लिए `<dlist>` और जिन खाड़ियों को देखा जा चुका है उनके सेट के लिए `HS{ }` इस्तेमाल कीजिए।

## 3. छलाँगों की संख्या

`hop-count` को ऐसे बनाइए कि वह एक शुरुआती खाड़ी, एक लक्ष्य खाड़ी और एक नक्शा ले, और उनके बीच की सबसे कम छलाँगों की संख्या लौटाए, या `f` लौटाए अगर लक्ष्य तक पहुँच न हो।

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

डीक्यू में हर खाड़ी के साथ शुरुआत से उसकी दूरी भी रखिए (2 एलिमेंट वाला एक ऐरे काम करेगा)।

## 4. सोने की गिनती

स्टब `gold-count` को `:` के साथ घोषित करता है। इसे `:` में नहीं, `MEMO:` में बदलिए, ताकि हर खाड़ी का परिणाम एक ही बार निकाला जाए और कैश हो जाए। अभ्यास में दिए गए `gold-distribution` कॉन्स्टेंट में उस खाड़ी का सोना देखिए।
जो खाड़ी इस डिस्ट्रिब्यूशन में नहीं है, उसमें शून्य सोना होता है।

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. खज़ाने का रास्ता

`treasure-route` को ऐसे बनाइए कि वह एक शुरुआती खाड़ी और एक नक्शा ले, और सबसे ज़्यादा सोने वाली पहुँचने योग्य खाड़ी लौटाए। कार्य 2 के `coves-reachable` और कार्य 4 के `gold-count` का उपयोग कीजिए।

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

मेमोइज़्ड `gold-count` की वजह से बार-बार की गई खोजों पर कोई अतिरिक्त काम नहीं पड़ता, जो तब उपयोगी होता है जब एल्गोरिदम के कई हिस्से एक ही खाड़ी को देखते हैं।
