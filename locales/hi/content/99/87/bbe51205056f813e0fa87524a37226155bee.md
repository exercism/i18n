# Kotlin इंस्टॉल कीजिए

Kotlin में Exercism के अभ्यास करने के लिए, exercism CLI और अपने पसंदीदा टेक्स्ट एडिटर के अलावा ये चीज़ें भी ज़रूरी हैं:

* **Java Development Kit** (JDK): Kotlin, Java बाइटकोड में कंपाइल होता है, इसलिए आपको JDK इंस्टॉल करना होगा। JDK में एक Java Runtime *और* डेवलपमेंट टूल, दोनों शामिल होते हैं (सबसे खास तौर पर Java कंपाइलर)। और
* **Gradle**: एक बिल्ड टूल, जो खास तौर पर JVM आधारित प्रोजेक्ट के लिए बना है और Kotlin का समर्थन करता है।

अपना ऑपरेटिंग सिस्टम चुनिए:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... या ...

* अगर आप पैकेज मैनेजर का उपयोग नहीं करना पसंद करते हैं, तो आप [मैन्युअल तरीके से इंस्टॉल](#h-install-manually) कर सकते हैं।

चाहें तो आप [Java IDE](#h-java-ides) का भी उपयोग कर सकते हैं।

## Windows

एक एडमिनिस्ट्रेटिव कमांड प्रॉम्प्ट खोलिए। (अगर आपको एडमिनिस्ट्रेटिव प्रॉम्प्ट खोलने में मदद चाहिए, तो [Windows 8+ में एलिवेटेड प्रॉम्प्ट खोलें](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) देखिए (या [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/))।

1. अगर आपने Chocolatey इंस्टॉल नहीं किया है, तो अभी कीजिए:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  JDK इंस्टॉल कीजिए:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

हम सलाह देते हैं कि आप एडमिनिस्ट्रेटिव कमांड प्रॉम्प्ट बंद कर दें और एक नया कमांड प्रॉम्प्ट खोलें। Exercism के अभ्यास करने के लिए आपको एडमिनिस्ट्रेटर विशेषाधिकारों की ज़रूरत नहीं होती।

अब आप Exercism के Kotlin ट्रैक को शुरू करने के लिए तैयार हैं!

शुरू करने के लिए [टेस्ट चलाएँ](https://exercism.org/docs/tracks/kotlin/tests) देखिए।

## macOS

नीचे सबसे आम तरीके, यानी Homebrew का उपयोग करके इंस्टॉल करने के निर्देश दिए गए हैं। अगर आप चाहें, तो आप [Homebrew के बिना macOS पर इंस्टॉल](#h-installing-on-macos-without-homebrew) भी कर सकते हैं।

### इंस्टॉल कीजिए

1. अगर आपने अभी तक [Homebrew](http://brew.sh) इंस्टॉल नहीं किया है, तो अभी कीजिए:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. [Homebrew Cask](https://caskroom.github.io/) टैप कीजिए। इससे हम JDK जैसी पहले से बनी बाइनरी भी इंस्टॉल कर सकते हैं।

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  JDK इंस्टॉल कीजिए:

       ```
        $ brew install --cask adoptopenjdk11
       ```

शुरू करने के लिए [टेस्ट चलाएँ](https://exercism.org/docs/tracks/kotlin/tests) देखिए।

* [Debian](#h-debian)
* [दूसरे Linux डिस्ट्रीब्यूशन](#h-other-linux-distributions)

### Debian

अगर आप Debian या उससे बने डिस्ट्रीब्यूशन (जैसे Ubuntu या Linux Mint) उपयोग कर रहे हैं, तो APT का उपयोग कीजिए:

*(जाँचा गया: Ubuntu 14, 16 और 18)*

1. JDK इंस्टॉल कीजिए:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```

### दूसरे Linux डिस्ट्रीब्यूशन

Jdk 11 इंस्टॉल करने के बहुत से तरीके हैं, लेकिन सबसे आसान तरीकों में से एक है SDKMAN, जिसकी मदद से आप OpenJdk11 बड़ी आसानी से इंस्टॉल कर सकते हैं। इन चरणों का पालन कीजिए:

1. SDKMAN इंस्टॉल कीजिए:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (अगर यह काम न करे, तो यहाँ दिए गए निर्देश देखिए: https://sdkman.io/install )
1. openjdk11 इंस्टॉल कीजिए:
    ```
    $ sdk install java 11.0.2-open
    ```

### Windows पर मैन्युअल तरीके से इंस्टॉल कीजिए

*ध्यान दें: ये निर्देश अनुभवी Windows उपयोगकर्ताओं के लिए हैं। अगर आप पहले से नहीं जानते कि एनवायरनमेंट वेरिएबलो कैसे सेट करते हैं, या डायरेक्टरी संरचना को संभालना आपको सहज नहीं लगता, तो हमारी सलाह है कि आप [ऊपर](#h-windows) दिए गए Chocolatey वाले तरीके से इंस्टॉल कीजिए।*

1. JDK इंस्टॉल कीजिए:
   1. [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) से "**OpenJDK 11 (LTS)**" डाउनलोड कीजिए (**"Install JDK"** चुनिए)।
   -  इंस्टॉलर को सभी डिफॉल्ट विकल्पों के साथ चलाइए।

अब आप Exercism के Kotlin ट्रैक को शुरू करने के लिए तैयार हैं!

### Homebrew के बिना macOS पर इंस्टॉल कीजिए

*ध्यान दें: ये निर्देश अनुभवी macOS उपयोगकर्ताओं के लिए हैं। जब तक कि आप विशेष रूप से पैकेज मैनेजर का उपयोग न करना न चाहें, हमारी सलाह है कि आप [ऊपर](#h-macos) दिए गए Homebrew वाले निर्देशों का उपयोग कीजिए।*

1. JDK इंस्टॉल कीजिए:
   1. [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_mac) से "**OpenJDK 11 (LTS)**" डाउनलोड कीजिए (**"Install JDK"** चुनिए)।
   2. इंस्टॉलर को सभी डिफॉल्ट विकल्पों के साथ चलाइए।

## Java IDE

Java के लिए बहुत से IDE उपलब्ध हैं। सबसे लोकप्रिय तीन ये हैं:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) ("Community" संस्करण डाउनलोड कीजिए)
  - Kotlin के लेखकों का बनाया यह IDE इस भाषा के लिए सबसे अच्छा समर्थन देता है।
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) ("Java SE" बंडल डाउनलोड कीजिए)

और [कुछ और](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs) भी हैं।
