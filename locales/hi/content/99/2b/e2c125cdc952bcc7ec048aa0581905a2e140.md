# परिचय

**क्लोज़र** [Clojure में][clojure-guide-closures] प्रोग्रामिंग का एक तरीका हैं। इसकी मदद से बाहरी [लेक्सिकल स्कोप][wiki-lexical-scope] के वेरिएबल किसी फंक्शन के अंदर इस्तेमाल किए जा सकते हैं। Clojure क्लोज़र को अपने आप सपोर्ट करता है, और अक्सर लोग इनका इस्तेमाल यह जाने बिना ही करते हैं कि ये क्या हैं।

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## स्थिति सहेजने और वैल्यू आगे भेजने के लिए क्लोज़र

एटम के इस्तेमाल से कुछ स्थिति सहेजी जा सकती है:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

`increment` को हर बार कॉल करने पर उसका काउंटर एक बढ़ जाता है:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
