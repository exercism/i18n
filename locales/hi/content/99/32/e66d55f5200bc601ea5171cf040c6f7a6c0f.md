# परिचय

`Promise` क्लास के आने से पहले, एसिंक्रोनस कोड से निपटने का सिर्फ एक ही तरीका था: _कॉलबैक पैटर्न_।

कॉलबैक एक ऐसा फंक्शन है जिसे किसी दूसरे फंक्शन को आर्गुमेंट के रूप में दिया जाता है, और उस दूसरे फंक्शन में कोई काम पूरा हो जाने पर उसे कॉल किया जाता है। ऐसे कॉलबैक फंक्शन का एक आम पैटर्न यह है कि वे पहले पैरामीटर के रूप में एक "एरर" लेते हैं (नीचे उदाहरण देखिए)।

```javascript
function callback(error, arg2, arg3) {}
```

इसका एसिंक्रोनस कोड से क्या संबंध है?

पहले के समय में कॉलबैक इसलिए इस्तेमाल किए जाते थे कि कोई एसिंक्रोनस काम पूरा होने के बाद हम कुछ और कर सकें, और यह पूरे प्रोग्राम को रोके बिना हो।

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

ऊपर के उदाहरण में, `fetchProduct` फंक्शन (जो एसिंक्रोनस है) दूसरे आर्गुमेंट के रूप में एक कॉलबैक लेता है, जो यह तय करता है कि प्रोडक्ट का डेटा मिल जाने पर क्या करना है।
