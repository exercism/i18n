# परिचय

.NET की बेस क्लास लाइब्रेरीज़ रेगुलर एक्सप्रेशन प्रोसेस करने के लिए [`Regex`][regex] क्लास देती हैं।

C# की तुलना रेगुलर एक्सप्रेशन के दूसरे इंजनों से करने के लिए यह [लेख][regex-comparison] देखिए।

## कैप्चर ग्रुप

एक पहलू पर ध्यान देना ज़रूरी है, और वह है कैप्चर ग्रुप, जो टेक्स्ट के उन हिस्सों को लौटाते हैं जो रेगुलर एक्सप्रेशन पैटर्न के अलग-अलग हिस्सों से मैच करते हैं। कैप्चर ग्रुप के इस तरीके की आदत डालनी पड़ती है। यह [डॉक्युमेंटेशन][capture] देखिए।

ध्यान दीजिए कि जहाँ कैप्चर ग्रुप, `(?<capture-name>pattern)`, शामिल होते हैं, वहाँ एक पदानुक्रम होता है:

- जहाँ शून्य या अधिक मैच लौटाए जाते हैं (टेक्स्ट में मिले हर मैच के लिए एक)।
- हर मैच में कई कैप्चर ग्रुप होते हैं।
- हर ग्रुप में कई कैप्चर होते हैं।

इसके अलावा:

- `Match`, `Group` से व्युत्पन्न है।
- `Group`, `Capture` से व्युत्पन्न है।

सावधानियाँ:

- सबसे सुरक्षित तरीका नामित कैप्चर इस्तेमाल करना है।
- कैप्चर ग्रुप आम तौर पर `Groups` कलेक्शन में उसी क्रम में होते हैं जिस क्रम में वे टेक्स्ट में आते हैं।
- `Groups[0]` का संबंध पूरे मैच से लगता है।
- `Groups[<capture name>].Value` ही लगभग निश्चित रूप से वह चीज़ है जिसमें आपकी दिलचस्पी है। अलग-अलग कैप्चर (`Caputures[0]` के अलावा) अगर मौजूद हों, तो लगता है कि वे डायग्नोस्टिक कामों के लिए हैं।

## रेगुलर एक्सप्रेशन के विकल्प

[`RegexOptions`][regex-options] से परिचित हो जाइए।

आम `IgnoreCase` विकल्पों के अलावा `MultiLine` और `IgnorePatternWhitespace` के लिए भी विकल्प हैं। `MultiLine` एक साथ टेक्स्ट की कई लाइनें प्रोसेस करने में काम आता है, और `IgnorePatternWhitespace` वर्बेटिम स्ट्रिंग, स्ट्रिंग इंटरपोलेशन और कमेंट के साथ मिलकर बहुत अभिव्यक्तिपूर्ण हो सकता है, जैसा नीचे दिखाया गया है:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

एक और दिलचस्प विकल्प `RegexOptions.Compiled` है, जो [कंपाइल किए गए][regex-compilation] रेगुलर एक्सप्रेशन के लिए है।
