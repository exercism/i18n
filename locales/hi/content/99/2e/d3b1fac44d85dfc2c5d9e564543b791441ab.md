# निर्देशों का परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग       | टाइप     | विवरण                        |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | N, त्रिभुज की भुजाओं का योग  |
| `$a1`    | इनपुट/आउटपुट  | एड्रेस  | a की वैल्यू                  |
| `$a2`    | इनपुट/आउटपुट  | एड्रेस  | b की वैल्यू                  |
| `$a3`    | इनपुट/आउटपुट  | एड्रेस  | c की वैल्यू                  |
| `$v0`    | आउटपुट       | पूर्णांक | ट्रिपलेट की संख्या           |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी रूप से रखने के लिए    |
