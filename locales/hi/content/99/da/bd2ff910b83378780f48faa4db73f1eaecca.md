# डीबग

जब कोई टेस्ट फेल होता है, तो एक संदेश प्रदर्शित होता है जो बताता है कि क्या गलत हुआ और किस इनपुट के लिए। आप अपने प्रोग्राम की कोई भी वैल्यू `debug` मेथड को पास करके जाँच सकते हैं। यह उन वैल्यू को पकड़ लेता है और आपको आउटपुट दिखा देता है।

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
