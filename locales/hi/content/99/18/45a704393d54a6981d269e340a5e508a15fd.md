# निर्देश

आप अपनी छोटी बहन को उसका अंग्रेज़ी शब्दावली का होमवर्क करने में मदद कर रहे हैं, जो उसे बहुत उबाऊ लगता है। उसकी कक्षा शब्दों के आगे _उपसर्ग_ और अंत में _प्रत्यय_ जोड़कर नए शब्द बनाना सीख रही है। शब्दों का एक समूह देखकर शिक्षक ऐसे शब्द चाहते हैं जो सही ढंग से बदले गए हों और जिनकी वर्तनी भी सही हो, यानी ऐसे शब्द जिनके शुरू में उपसर्ग या अंत में प्रत्यय जोड़ा गया हो।

इस होमवर्क में चार गतिविधियाँ हैं, और हर गतिविधि में काम करने के लिए कुछ टेक्स्ट या शब्द दिए गए हैं।


## 1. किसी शब्द में उपसर्ग जोड़िए

अंग्रेज़ी के सबसे आम उपसर्गों में से एक है `un`, जिसका अर्थ है "नहीं"। इस गतिविधि में आपकी बहन को शब्दों के आगे `un` जोड़कर नकारात्मक यानी "नहीं" वाले शब्द बनाने हैं।

`add_prefix_un(<word>)` फंक्शन बनाइए जो `word` को पैरामीटर के रूप में लेता है और `un` उपसर्ग लगा हुआ एक नया शब्द लौटाता है:


```python
>>> add_prefix_un("happy")
'unhappy'

>>> add_prefix_un("manageable")
'unmanageable'
```


## 2. शब्द-समूहों में उपसर्ग जोड़िए

आपकी बहन की कक्षा चार और आम उपसर्ग सीख रही है: `en` (_यानी 'अंदर रखना' या 'ढक देना'_), `pre` (_यानी 'पहले' या 'आगे'_), `auto` (_यानी 'स्वयं' या 'समान'_), और `inter` (_यानी 'बीच में' या 'के बीच'_).

इस अभ्यास में कक्षा इन उपसर्गों की मदद से शब्दावली शब्दों के समूह बना रही है, ताकि उन्हें एक साथ पढ़ा जा सके। हर उपसर्ग एक सूची के साथ दिया गया है, जिसमें उसके साथ आमतौर पर आने वाले शब्द हैं। विद्यार्थियों को उपसर्ग लगाना है और ऐसी स्ट्रिंग बनानी है जिसमें हर शब्द पर वह उपसर्ग लगा हुआ दिखे।

`make_word_groups(<vocab_words>)` फंक्शन बनाइए जो इस रूप का `vocab_words` पैरामीटर लेता है: `[<prefix>, <word_1>, <word_2> .... <word_n>]`, और ऐसी स्ट्रिंग लौटाता है जिसमें हर शब्द पर उपसर्ग लगा हो और जो इस तरह दिखे: `'<prefix> :: <prefix><word_1> :: <prefix><word_2> :: <prefix><word_n>'`.

यहाँ इनपुट को संभालने के लिए `for` या `while` लूप बनाने की ज़रूरत नहीं है। ध्यान से सोचिए कि इसके बजाय आप कौन-कौन से स्ट्रिंग मेथड (और डिलिमिटर) इस्तेमाल कर सकते हैं।


```python
>>> make_word_groups(['en', 'close', 'joy', 'lighten'])
'en :: enclose :: enjoy :: enlighten'

>>> make_word_groups(['pre', 'serve', 'dispose', 'position'])
'pre :: preserve :: predispose :: preposition'

>> make_word_groups(['auto', 'didactic', 'graph', 'mate'])
'auto :: autodidactic :: autograph :: automate'

>>> make_word_groups(['inter', 'twine', 'connected', 'dependent'])
'inter :: intertwine :: interconnected :: interdependent'
```


## 3. किसी शब्द से प्रत्यय हटाइए

`ness` एक आम प्रत्यय है जिसका अर्थ है _'होने की अवस्था'_। इस गतिविधि में आपकी बहन को `ness` प्रत्यय हटाकर मूल शब्द ढूँढना है। लेकिन वर्तनी के कुछ झंझट भरे नियम भी हैं: अगर मूल शब्द के अंत में कोई व्यंजन और उसके बाद 'y' आता था, तो उस 'y' को 'i' में बदल दिया जाता था। ऐसे मूल शब्दों से 'ness' हटाते समय 'y' को वापस लाना पड़ता है। जैसे `happiness` --> `happi` --> `happy`.

`remove_suffix_ness(<word>)` फंक्शन बनाइए जो एक `word` लेता है और `ness` प्रत्यय हटाकर मूल शब्द लौटाता है।


```python
>>> remove_suffix_ness("heaviness")
'heavy'

>>> remove_suffix_ness("sadness")
'sad'
```

## 4. किसी शब्द को निकालिए और उसका रूप बदलिए

प्रत्यय अक्सर किसी शब्द का शब्द-भेद बदलने के लिए इस्तेमाल होते हैं। अंग्रेज़ी में एक आम चलन है "verbing" या "verbifying", जिसमें `en` प्रत्यय जोड़कर कोई विशेषण क्रिया _बन_ जाता है।

इस काम में आपकी बहन वाक्य से एक विशेषण निकालकर उसे क्रिया में बदलकर शब्दों की "verbing" का अभ्यास करेगी। अच्छी बात यह है कि यहाँ जिन शब्दों को बदलना है वे सब नियमित हैं, उनमें प्रत्यय जोड़ने के लिए वर्तनी बदलने की ज़रूरत नहीं पड़ती।

`adjective_to_verb(<sentence>, <index>)` फंक्शन बनाइए जो दो पैरामीटर लेता है। पहला एक `sentence` है, जिसमें वह शब्दावली शब्द इस्तेमाल हुआ हो, और दूसरा उस शब्द का `index` है, जब उस वाक्य को अलग-अलग हिस्सों में तोड़ा जाए। यह फंक्शन निकाले गए विशेषण को क्रिया के रूप में लौटाना चाहिए।


```python
>>> adjective_to_verb('I need to make that bright.', -1 )
'brighten'

>>> adjective_to_verb('It got dark as the sun set.', 2)
'darken'
```
