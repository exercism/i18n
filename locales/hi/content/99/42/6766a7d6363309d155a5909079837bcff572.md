# निर्देश परिशिष्ट

## सुझाव

*रिटर्न टाइप* वाला फंक्शन केवल उसी *टाइप* का डेटा और `null` लौटा सकता है।
लेकिन फंक्शन को कॉल करने वाला केवल एक ही डेटा टाइप की उम्मीद करता है।

उदाहरण:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
यह और स्पष्ट करने के लिए कि यह फंक्शन `null` या अन्य डेटा टाइप भी लौटा सकता है, `dynamic` का उपयोग कीजिए।
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
