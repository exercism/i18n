# निर्देश परिशिष्ट

## कॉलबल

PHP में [कॉलबल](https://www.php.net/manual/en/language.types.callable.php) की अवधारणा होती है।

ये कई रूपों में आ सकते हैं, लेकिन यहाँ हम [अनाम फंक्शन](https://www.php.net/manual/en/functions.anonymous.php) पर ध्यान देंगे।

किसी वेरिएबल में अनाम फंक्शन बनाकर उसे पैरामीटर के साथ कॉल किया जा सकता है:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
