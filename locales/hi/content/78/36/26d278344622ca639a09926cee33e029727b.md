# परिचय

ABAP में कई संख्यात्मक टाइप होते हैं। इस अभ्यास में आप उनमें से दो का उपयोग करेंगे:

- `i` पूर्णांक वैल्यू के लिए, जैसे किसी महीने में दिनों की संख्या।
- `p` पैक्ड दशमलव वैल्यू के लिए, जैसे प्रति घंटे की दर या छूट।

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

पैक्ड संख्याएँ अपनी अधिकतम लंबाई और दशमलव स्थानों की संख्या तय करती हैं। दशमलव लिटरल आम तौर पर टेक्स्ट वैल्यू के रूप में लिखे जाते हैं और कंपाइलर उन्हें लक्ष्य दशमलव टाइप में बदल देता है, या यह काम `CONV` से किया जाता है।

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP में राउंडिंग के लिए कुछ अंतर्निहित संख्यात्मक फंक्शन मिलते हैं। `floor` फंक्शन संख्या को नीचे की ओर निकटतम पूर्ण संख्या तक राउंड करता है, और `ceil` ऊपर की ओर निकटतम पूर्ण संख्या तक।

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
