# निर्देश परिशिष्ट

## इम्प्लीमेंटेशन

आइटम [रिकॉर्ड](https://lfe.gitbooks.io/reference-guide/content/16.html) के रूप में दर्शाए जाते हैं, जो `item.lfe` में परिभाषित हैं।
भार पाने के लिए `item-weight` का और वैल्यू पाने के लिए `item-value` का इस्तेमाल कीजिए।

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
