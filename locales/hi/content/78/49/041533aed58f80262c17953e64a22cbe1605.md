# इंस्टॉलेशन

अभ्यासों पर काम करने के लिए आपको इन सॉफ्टवेयर की जरूरत होगी:

1. [`OPAM`, OCaml पैकेज मैनेजर](https://opam.ocaml.org/)

   अपने ऑपरेटिंग सिस्टम पर `OPAM` इंस्टॉल और सेट कैसे करें, इसके लिए [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html) देखिए।

2. OCaml कंपाइलर

   उपलब्ध संस्करणों की सूची देखिए:

   ```bash
   opam switch
   ```

   अगर आपके पास OCaml 5.1 के लिए पहले से स्विच है, तो उसे `opam switch <switch-name>` चलाकर लोड कीजिए, या नया स्विच बनाने के लिए यह चलाइए:

   ```bash
   opam switch create exercism 5.4.0
   ```

   यहाँ `exercism` नाम जरूरी नहीं है, लेकिन अपने स्विच को नाम देना अच्छी आदत है।

3. विस्तारित स्टैंडर्ड लाइब्रेरी और टेस्ट लाइब्रेरी इंस्टॉल कीजिए

   इस ट्रैक के लिए जरूरी डिपेंडेंसी इंस्टॉल करने के लिए यह चलाइए:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   कुछ अभ्यास सिर्फ OCaml स्टैंडर्ड लाइब्रेरी इस्तेमाल करते हैं, और कुछ Jane Street की विस्तारित लाइब्रेरी Base और Core_kernel इस्तेमाल करते हैं।
   टेस्ट लाइब्रेरी का नाम OUnit है, और कुछ अभ्यास प्रॉपर्टी-बेस्ड टेस्ट के लिए QCheck लाइब्रेरी का भी इस्तेमाल करते हैं।
   ऊपर दिया गया कमांड चलाने से ये लाइब्रेरी इंस्टॉल हो जाएँगी।

4. इंटरैक्टिव शेल इंस्टॉल कीजिए और इस्तेमाल कीजिए (वैकल्पिक)

   [Setting up and using `utop`](https://dev.realworldocaml.org/install.html) का सारांश:

   ```bash
   opam install utop
   ```

   अपनी होम डायरेक्टरी में `.ocamlinit` नाम की एक नई फाइल बनाइए और उसमें ये लाइनें जोड़िए:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. VS Code में टूल इंस्टॉल कीजिए (वैकल्पिक)

   अगर आप VS Code इस्तेमाल करते हैं:
   - OCaml लैंग्वेज सर्वर [यहाँ](https://github.com/ocaml/ocaml-lsp) से इंस्टॉल कीजिए।
   - OCaml VS Code एक्सटेंशन [यहाँ](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform) से इंस्टॉल कीजिए, या Ocaml Labs द्वारा बनाए `OCaml Platform` को खोजिए।
