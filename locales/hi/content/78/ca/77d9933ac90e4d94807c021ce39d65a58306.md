# परिचय

## स्ट्रिंग

Gleam में स्ट्रिंग एक टेक्स्ट होती है जिसे बदला नहीं जा सकता और जिसे दोहरे कोट्स के अंदर लिखा जाता है। इनमें यूनिकोड अक्षर लिखे जा सकते हैं, और ये एक से ज़्यादा लाइनों में भी हो सकती हैं।

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

स्ट्रिंग को `<>` ऑपरेटर की मदद से जोड़ा जा सकता है:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

स्टैंडर्ड लाइब्रेरी का [`gleam/string`][stdlib] मॉड्यूल स्ट्रिंग के साथ काम करने के लिए फंक्शन देता है।

case एक्सप्रेशन में स्ट्रिंग का मिलान किया जा सकता है:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

अगर आप स्ट्रिंग की शुरुआत का मिलान करना चाहते हैं और बाकी हिस्से को किसी वेरिएबल में असाइन करना चाहते हैं, तो आप `<>` ऑपरेटर पैटर्न इस्तेमाल कर सकते हैं:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
