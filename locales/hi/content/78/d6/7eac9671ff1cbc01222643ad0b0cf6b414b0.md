# मदद

अगर आपको कोई दिक्कत आ रही है और मदद चाहिए, तो आप इनमें से किसी एक संसाधन का उपयोग कर सकते हैं:

- [The Emacs Wiki](http://emacswiki.org/) बहुत काम की चीज़ है। यहाँ खूब समय बिताइए।
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) GNU Emacs का आधिकारिक मैनुअल है।
- IRC - [Libera.Chat](https://libera.chat/) पर `#emacs`, `#org-mode` और Emacs के कई पैकेजों के लिए चैनल हैं, और वहाँ मदद करने वाले बहुत से लोग भी मिल जाते हैं। और Emacs में तो IRC बस `M-x erc` जितना ही दूर है।
- Matrix - [Matrix](https://matrix.org/) पर [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) और Emacs के दूसरे पैकेजों के लिए रूम हैं।
  उपलब्ध चैनलों का अवलोकन पाने के लिए आप [Emacs Matrix स्पेस से जुड़ सकते हैं](https://matrix.to/#/#emacs-space:matrix.org)।
  Emacs के अंदर से Matrix से जुड़ने के लिए आप [Ement.el](https://github.com/alphapapa/ement.el) पैकेज इस्तेमाल कर सकते हैं।
- [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) और [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) पर आप अपनी समस्या खोज सकते हैं और देख सकते हैं कि उसका जवाब पहले से दिया गया है या नहीं। आप सवाल पूछ भी सकते हैं और उनके जवाब भी दे सकते हैं।
