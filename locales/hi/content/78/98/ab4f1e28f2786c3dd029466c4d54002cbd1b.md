# परिचय

बहुत से प्रोग्राम को वास्तविक दुनिया की घटनाओं का अनुकरण करने के लिए (स्यूडो-)रैंडम वैल्यू की ज़रूरत होती है।

आम और परिचित उदाहरणों में शामिल हैं:

- सिक्का उछालना: ('H', 'T') में से एक रैंडम वैल्यू।
- पासा फेंकना: 1 से 6 तक का एक रैंडम पूर्णांक।
- ताश की गड्डी फेंटना: कार्ड की सूची का एक रैंडम क्रम।
- 3-D ग्राफिक्स सिमुलेशन में पेड़ और झाड़ियाँ बनाना।

कंप्यूटर से सचमुच रैंडम वैल्यू बनाना [आश्चर्यजनक रूप से कठिन तकनीकी चुनौती][why-randomness-is-hard] है, इसीलिए "स्यूडो-रैंडम" जनरेटर भी होते हैं।

~~~exercism/advanced
JavaScript के लिए [भाषा स्पेसिफिकेशन][spec] यह तय नहीं करता कि रैंडम संख्याएँ बनाने का काम कैसे होना चाहिए।
सभी प्रमुख ब्राउज़र और JavaScript रनटाइम एक PRNG (स्यूडो-रैंडम संख्या जनरेटर) लागू करते हैं।
ये संख्याएँ क्रिप्टोग्राफिक रूप से सुरक्षित नहीं होतीं, इसलिए इन्हें कभी भी ऐसी चीज़ों के लिए इस्तेमाल नहीं करना चाहिए जिनमें सचमुच रैंडम या कम से कम क्रिप्टोग्राफिक रूप से सुरक्षित संख्याएँ चाहिए, जैसे सर्टिफिकेट या पासवर्ड बनाना या ऐसे ऑपरेशन।

[Web Cryptography][rfc] नाम का एक स्टैंडर्ड है, जो JavaScript में क्रिप्टोग्राफी करने के लिए एक इंटरफेस तय करता है।
इसे [ब्राउज़रों][crypto-web] के साथ-साथ [Node.JS][crypto-node] और [Deno][crypto-deno] जैसे रनटाइम भी लागू करते हैं।

यह कॉन्सेप्ट Web Crypto के बारे में नहीं है और खुद को स्यूडो-रैंडम संख्या जनरेशन तक सीमित रखेगा।

[rfc]: https://www.w3.org/TR/webcrypto-2/
[spec]: https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-math.random
[crypto-web]: https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues
[crypto-node]: https://nodejs.org/api/webcrypto.html#cryptogetrandomvaluestypedarray
[crypto-deno]: https://docs.deno.com/api/web/~/Crypto
~~~

## रैंडम संख्याएँ बनाना

JavaScript में आप [`Math.random()`][Math.random] फंक्शन की मदद से स्यूडो-रैंडम संख्याएँ बना सकते हैं।
यह 0 से 1 के बीच एक स्यूडो-रैंडम दशमलव संख्या लौटाता है, जहाँ 0 शामिल है और 1 नहीं।

_min_ और _max_ के बीच एक रैंडम संख्या पाने के लिए, जिसमें _min_ शामिल हो पर _max_ नहीं, आप इस जैसा फंक्शन इस्तेमाल कर सकते हैं:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

[bias]: https://adammil.net/blog/v134_Efficiently_generating_random_numbers_without_bias.html

## रैंडम पूर्णांक बनाना

रैंडम पूर्णांक बनाने के लिए आप `Math.floor()` या `Math.ceil()` की मदद से रैंडम तरीके से बनी संख्या को पूर्णांक में बदल सकते हैं।

[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
