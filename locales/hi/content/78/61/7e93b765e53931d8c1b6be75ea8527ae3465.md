# परिचय

## संख्याएँ

C# में दो तरह की संख्याएँ होती हैं:

- पूर्णांक: ऐसी संख्याएँ जिनमें दशमलव चिह्न के बाद कोई अंक नहीं होता (पूर्ण संख्याएँ)। जैसे `-6`, `0`, `1`, `25`, `976` और `500000`।
- दशमलव संख्याएँ: ऐसी संख्याएँ जिनमें दशमलव चिह्न के बाद शून्य या उससे अधिक अंक होते हैं। जैसे `-2.4`, `0.1`, `3.14`, `16.984025` और `1024.0`।

C# में सबसे आम दो संख्यात्मक टाइप `int` और `double` हैं। `int` एक 32-बिट पूर्णांक है और `double` एक 64-बिट दशमलव संख्या।

अंकगणित के लिए मानक अंकगणितीय ऑपरेटर इस्तेमाल किए जाते हैं। संख्याओं की तुलना मानक संख्यात्मक तुलना ऑपरेटरों और समानता (`==`) तथा असमानता (`!=`) ऑपरेटरों से की जा सकती है।

C# में संख्यात्मक रूपांतरण दो तरह के होते हैं:

1. अंतर्निहित रूपांतरण: इसमें कोई डेटा नहीं खोता और किसी अतिरिक्त सिंटैक्स की ज़रूरत नहीं होती।
2. स्पष्ट रूपांतरण: इसमें डेटा खो सकता है, और इसके लिए _कास्ट_ के रूप में अतिरिक्त सिंटैक्स लिखना पड़ता है।

चूँकि एक `int` में `double` से कम परिशुद्धता होती है, इसलिए `int` से `double` में रूपांतरण सुरक्षित है और वह अंतर्निहित रूपांतरण है। लेकिन `double` से `int` में रूपांतरण का मतलब डेटा खोना हो सकता है, इसलिए उसके लिए स्पष्ट रूपांतरण ज़रूरी है।

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## if स्टेटमेंट

इस अभ्यास में आपको शर्त के अनुसार कोड चलाना है। C# में ऐसा करने का सबसे आम तरीका `if/else` स्टेटमेंट का इस्तेमाल है:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

किसी `if` स्टेटमेंट की शर्त का टाइप `bool` होना चाहिए। C# में _truthy_ वैल्यू की कोई अवधारणा नहीं होती।
