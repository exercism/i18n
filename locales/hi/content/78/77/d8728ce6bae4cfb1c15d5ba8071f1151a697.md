# निर्देश

इस अभ्यास में आप कोड लिखेंगे। इस कोड की मदद से आप उन प्रोग्रामिंग भाषाओं का हिसाब रख सकेंगे जिन्हें आप Exercism पर सीखना चाहते हैं।

आपके सामने छह टास्क हैं, और इन सभी में ऐरे से काम पड़ेगा।

## 1. एक नया ऐरे बनाइए

आप जिन भाषाओं को सीखना चाहते हैं, उनका हिसाब रखने के लिए आपको एक नया ऐरे बनाना होगा। ऐसी `newList` बाइंडिंग बनाइए जिसमें एक नया, खाली ऐरे हो।

```fsharp
newList
// => []
```

## 2. मौजूदा ऐरे बनाइए

इस समय आपके पास एक कागज़ का टुकड़ा है, जिस पर वे भाषाएँ लिखी हैं जो आप सीखना चाहते हैं: F#, Clojure और Haskell। इस ऐरे को दर्शाने के लिए `existingList` बाइंडिंग बनाइए।

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. ऐरे में एक नई भाषा जोड़िए

जैसे-जैसे आप Exercism पर घूमते हैं और नई रोचक भाषाएँ ढूँढते हैं, आप उन्हें अपने ऐरे में जोड़ना चाहते हैं। अपने ऐरे के शुरू में एक नई भाषा जोड़ने के लिए `addLanguage` फंक्शन बनाइए।

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. ऐरे में भाषाओं की गिनती कीजिए

भाषाओं को एक-एक करके गिनना सुविधाजनक नहीं है। अपने ऐरे में भाषाओं की संख्या गिनने के लिए `countLanguages` फंक्शन बनाइए।

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. ऐरे को उलटिए

किसी समय आपको पता चलता है कि आपका ऐरे वास्तव में उलटे क्रम में है! अपने ऐरे को उलटने के लिए `reverseList` फंक्शन बनाइए।

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. जाँचिए कि ऐरे रोमांचक है या नहीं

आपको सभी भाषाएँ पसंद हैं, लेकिन F# का स्थान आपके दिल में खास है। इसलिए भाषाओं का कोई ऐरे आपके लिए रोमांचक तब होता है, जब:

- ऐरे का पहला एलिमेंट F# हो।
- ऐरे का दूसरा एलिमेंट F# हो और ऐरे में दो या तीन भाषाएँ हों।

भाषाओं का ऐरे रोमांचक है या नहीं, यह जाँचने के लिए `excitingList` फंक्शन बनाइए:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
