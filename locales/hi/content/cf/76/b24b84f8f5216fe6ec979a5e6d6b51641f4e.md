# इंस्टॉलेशन

## PowerShell भाषा ट्रैक की आवश्यकताएँ

Exercism के PowerShell भाषा ट्रैक के लिए आपके सिस्टम पर ये चीज़ें इंस्टॉल होनी चाहिए:

- PowerShell या Windows PowerShell Core
- Pester टेस्ट और मॉक फ्रेमवर्क का मॉड्यूल इंस्टॉल होना चाहिए

(नोट: PowerShell के लिए मदद सिर्फ़ ज़रूरी सुधारों तक सीमित है। PowerShell Core का लगातार रखरखाव किया जाता है और यह क्रॉस-प्लेटफ़ॉर्म पर अधिक मदद देता है।)

### PowerShell इंस्टॉल करना

Windows 7 SP1 और उसके बाद के सभी Windows ऑपरेटिंग सिस्टम पर PowerShell पहले से इंस्टॉल आता है।

PowerShell का सबसे नया वर्शन और सभी प्लेटफ़ॉर्मों (Linux, macOS और Windows) के लिए इंस्टॉलेशन के निर्देश आप [यहाँ][installation] पा सकते हैं।

[PowerShell][source-code] का सोर्स कोड और मैनुअल इंस्टॉलेशन भी उपलब्ध है।

### Pester फ्रेमवर्क इंस्टॉल और अपडेट करना

[Pester][pester] PowerShell का टेस्टिंग फ्रेमवर्क है।
वर्शन 4.0.9 से यह Windows, Linux और MacOS पर PowerShell Core के साथ काम करता है (कुछ सीमाओं के साथ)

यह Windows 10 पर पहले से इंस्टॉल होता है, लेकिन सलाह दी जाती है कि आप नीचे दिया गया PowerShell कमांड चलाकर इसे अपडेट कर लें:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

इसके बाद के अपडेट के लिए यह चलाइए:

```PowerShell
Update-Module -Name Pester
```

अगर ज़रूरत पड़े तो इंस्टॉलेशन के और निर्देश यहाँ उपलब्ध हैं: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## IDE का इस्तेमाल करना

अगर आपको और भी ज़्यादा सुविधाओं वाला एडिटिंग अनुभव चाहिए, तो शायद आप IDE इस्तेमाल करना चाहेंगे।
ये सबसे लोकप्रिय IDE हैं जो PowerShell प्रोजेक्ट बनाने की सुविधा देते हैं:

### सभी प्लेटफ़ॉर्म

- [PowerShell ISE (इंटिग्रेटेड स्क्रिप्टिंग एनवायरनमेंट)][ise], यह PowerShell के साथ आने वाला बिल्ट-इन ग्राफ़िकल IDE है (सिर्फ़ Windows पर)।
  PowerShell ISE शुरू करने के लिए PowerShell कंसोल में `powershell_ise.exe` टाइप कीजिए।
- [Visual Studio Code][vsc] और उसके साथ [PowerShell एक्सटेंशन][vsc-extension]।
  Visual Studio Code की मदद से आप टेस्ट भी चला सकते हैं और अपने कोड को डीबग भी कर सकते हैं।
- [Sublime Text 3][sublime] और उसके साथ [PowerShell पैकेज][sublime-package]।
