# परिचय

फंक्शन की मदद से आप कोड को एक ऐसी इकाई में समेट सकते हैं जिसे बार-बार इस्तेमाल किया जा सकता है।
यह `func` कीवर्ड, फंक्शन का नाम, और गोल ब्रैकेट में शून्य या अधिक पैरामीटर तथा उनके टाइप की कॉमा से अलग की गई सूची से मिलकर बनता है।

## फंक्शन के पैरामीटर

हर पैरामीटर का टाइप साफ़-साफ़ लिखना ज़रूरी होता है; पैरामीटर के टाइप का अनुमान अपने आप नहीं लगाया जाता।
पैरामीटर के लिए कोई डिफ़ॉल्ट वैल्यू नहीं होती, इसलिए फंक्शन के सारे पैरामीटर देना ज़रूरी होता है।

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

एक ही टाइप के पैरामीटर साथ में घोषित किए जा सकते हैं, और उनके बाद एक ही टाइप लिखा जाता है।

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## पैरामीटर बनाम आर्गुमेंट

चलिए दो ऐसे शब्दों पर जल्दी से नज़र डालते हैं जिनमें अक्सर उलझन हो जाती है: `parameters` और `arguments`।
फंक्शन के पैरामीटर वे नाम होते हैं जो फंक्शन की सिग्नेचर में लिखे जाते हैं, जैसे ऊपर दिए गए फंक्शन `PrintGreetingName` में `greeting` और `name`।
फंक्शन के आर्गुमेंट वे वास्तविक वैल्यू होती हैं जो फंक्शन को कॉल करते समय उसके पैरामीटर को दी जाती हैं।
जैसे नीचे दिए गए उदाहरण में `"Hello"` और `"Katrina"` वे आर्गुमेंट हैं जो `greeting` और `name` पैरामीटर को दिए गए हैं:

```go
PrintGreetingName("Hello", "Katrina")
```

## रिटर्न वैल्यू

फंक्शन के पैरामीटर के बाद शून्य या अधिक रिटर्न वैल्यू आती हैं, जिनका टाइप भी साफ़-साफ़ लिखना ज़रूरी होता है।
एक ही रिटर्न वैल्यू हो तो उसे बिना कोष्ठक के लिखा जाता है, और कई रिटर्न वैल्यू हों तो उन्हें कोष्ठक में लपेटा जाता है।
फंक्शन `return` कीवर्ड की मदद से कॉल करने वाले कोड को वैल्यू लौटाता है।
एक फंक्शन में कई `return` स्टेटमेंट हो सकते हैं।
जैसे ही फंक्शन इनमें से किसी `return` स्टेटमेंट तक पहुँचता है, वह वहीं रुक जाता है।
अगर किसी फंक्शन से कई वैल्यू लौटानी हों, तो उन्हें कॉमा से अलग किया जाता है।

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## फंक्शन को कॉल करना

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और कोष्ठक में उसके हर पैरामीटर के लिए आर्गुमेंट दिए जाते हैं।

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## नामित रिटर्न वैल्यू और नेकेड रिटर्न

पैरामीटर की तरह रिटर्न वैल्यू को भी चाहें तो नाम दिया जा सकता है।
अगर रिटर्न वैल्यू को नाम दिया गया हो, तो बिना आर्गुमेंट वाला `return` स्टेटमेंट उन्हीं वैल्यू को लौटा देता है।
इसे 'नेकेड' रिटर्न कहा जाता है।

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
