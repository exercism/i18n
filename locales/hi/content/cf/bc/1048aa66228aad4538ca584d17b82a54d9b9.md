# निर्देश

आप एक छोटा-सा ऑनलाइन गेम बना रहे हैं जिसमें कोई दोस्त एक गुप्त संख्या का अनुमान लगा सकता है। आप कुछ प्रतिक्रिया देना चाहते हैं, लेकिन अनुमान लगाने वाले को सीधे उत्तर नहीं बता देना चाहते। आपको एक फंक्शन बनाना है जो अनुमान और गुप्त संख्या के बीच संबंध के अनुसार अलग-अलग प्रतिक्रियाएँ दे।

| शर्त                                                     | प्रतिक्रिया       |
| ------------------------------------------------------------- | -------------- |
| जब अनुमान गुप्त संख्या से मेल खाता है                      | "Correct"      |
| जब अनुमान गुप्त संख्या से एक अधिक या एक कम है | "So close"     |
| जब अनुमान गुप्त संख्या से बड़ा है              | "Too high"     |
| जब अनुमान गुप्त संख्या से छोटा है              | "Too low"      |
| जब कोई अनुमान नहीं लगाया जाता                                       | "Make a guess" |

सभी अनुमान और गुप्त संख्याएँ पूर्णांक होती हैं।

## 1. जब अनुमान गुप्त संख्या से मेल खाता है तो प्रतिक्रिया दीजिए

`compare/2` फंक्शन बनाइए जो दो आर्गुमेंट लेता है, `secret_number` और `guess`, और दोनों पूर्णांक होते हैं।

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. जब अनुमान गुप्त संख्या से बड़ा हो तो प्रतिक्रिया दीजिए

`compare` फंक्शन में बदलाव कीजिए ताकि यह उन अनुमानों पर प्रतिक्रिया दे जो गुप्त संख्या से बड़े हैं।

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. जब अनुमान गुप्त संख्या से छोटा हो तो प्रतिक्रिया दीजिए

`compare` फंक्शन में बदलाव कीजिए ताकि यह उन अनुमानों पर प्रतिक्रिया दे जो गुप्त संख्या से छोटे हैं।

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. जब अनुमान गुप्त संख्या से एक अधिक या एक कम हो तो प्रतिक्रियाएँ दीजिए

`compare` फंक्शन में बदलाव कीजिए ताकि यह गुप्त संख्या के करीब के अनुमानों पर प्रतिक्रिया दे।

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. जब कोई अनुमान न हो तो प्रतिक्रिया दीजिए

`compare` फंक्शन में बदलाव कीजिए ताकि कोई अनुमान न होने पर भी यह प्रतिक्रिया दे।

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
