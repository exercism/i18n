# परिचय

इस अभ्यास में आपको शर्त के अनुसार कोड चलाना है। C# में ऐसा करने का सबसे आम तरीका `if/else` स्टेटमेंट का इस्तेमाल करना है:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if` स्टेटमेंट की शर्त `bool` टाइप की होनी चाहिए। C# में _ट्रूथी_ वैल्यू की कोई अवधारणा नहीं है।
