# String के मेथड

`String` में कई मेथड हैं जिनसे स्ट्रिंग को बदला जा सकता है।
ये मेथड स्ट्रिंग पर ही कॉल किए जाते हैं और अक्सर एक ही स्ट्रिंग पर कई ऑपरेशन करने के लिए एक के बाद एक जोड़ दिए जाते हैं।

नीचे कुछ सबसे आम मेथड की सूची दी गई है।
सभी मेथड की पूरी सूची के लिए [`String` API दस्तावेज़][string-api] देखिए।

## String#upcase & String#downcase

[`upcase`][upcase] मेथड स्ट्रिंग के सभी अक्षरों को बड़े अक्षरों में बदलकर एक नई स्ट्रिंग लौटाता है।

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase] मेथड स्ट्रिंग के सभी अक्षरों को छोटे अक्षरों में बदलकर एक नई स्ट्रिंग लौटाता है।

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

कुछ मेथड और भी खास तरह के केस बदलाव कर सकते हैं।
यह तब काम आता है जब किसी स्ट्रिंग को किसी खास फॉर्मैट में बदलना हो।
नीचे कुछ सबसे आम मेथड की सूची दी गई है:

| मेथड                              | विवरण                                                                                                              | उदाहरण                                               |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | पहले अक्षर को बड़ा और बाकी को छोटा कर देता है                                                                       | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | अंडरस्कोर को कैमलकेस में बदल देता है                                                                                | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | `String#camelcase` जैसा ही, लेकिन पहला अक्षर छोटा ही रहने देता है                                                    | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | सभी अक्षरों को छोटा कर देता है और छोटे तथा बड़े अक्षर के बीच अंडरस्कोर लगा देता है                                    | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | हर शब्द के पहले अक्षर को बड़ा और बाकी को छोटा कर देता है                                                            | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal में स्ट्रिंग के कुछ हिस्सों को बदलने के मेथड हैं।
इन्हें [`sub`][sub] (_प्रतिस्थापन_) और [`gsub`][gsub] (_ग्लोबल प्रतिस्थापन_) कहते हैं।

ये मेथड पहले आर्गुमेंट के रूप में स्ट्रिंग, अक्षर या रेगेक्स ले सकते हैं और दूसरे आर्गुमेंट के रूप में स्ट्रिंग या अक्षर ले सकते हैं।
पहला आर्गुमेंट स्ट्रिंग का वह हिस्सा है जिसे बदला जाएगा, और दूसरा आर्गुमेंट उसकी जगह लगने वाला हिस्सा है।
`Char` और रेगेक्स को आगे के कॉन्सेप्ट में समझाया जाएगा।

`sub` मेथड पहले आर्गुमेंट के पहली बार आने वाले हिस्से को दूसरे आर्गुमेंट से बदल देता है।

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub` मेथड भी `sub` की तरह ही काम करता है, लेकिन यह पहले आर्गुमेंट के हर बार आने वाले हिस्से को दूसरे आर्गुमेंट से बदल देता है।

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

chomp और strip की मदद से स्ट्रिंग से अनचाहे अक्षर हटाए जा सकते हैं।

[`chomp`][chomp] मेथड डिफ़ॉल्ट रूप से स्ट्रिंग के अंत से आखिरी `\r`, `\n` या `\r\n` अक्षर हटा देता है।
अगर इस मेथड को किसी आर्गुमेंट के साथ कॉल किया जाए, तो यह स्ट्रिंग के अंत से दी गई वैल्यू हटा देता है,
बशर्ते वह वैल्यू स्ट्रिंग के अंत में मौजूद हो।

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

डिफ़ॉल्ट रूप से [`strip`][strip] मेथड स्ट्रिंग के शुरू और अंत से सारी व्हाइटस्पेस हटा देता है।
अगर इस मेथड को किसी आर्गुमेंट के साथ कॉल किया जाए, तो यह स्ट्रिंग के शुरू और अंत से उस आर्गुमेंट को हटा देता है,
बशर्ते वह स्ट्रिंग के शुरू या अंत में मौजूद हो।

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

स्ट्रिंग को उलटने के लिए आप [`reverse`][reverse] मेथड इस्तेमाल कर सकते हैं।
यह मेथड एक नई स्ट्रिंग लौटाता है जिसमें अक्षर उलटे क्रम में होते हैं।

```crystal
"hello".reverse
# => "olleh"
```

## String#index

[`index`][index] मेथड की मदद से स्ट्रिंग में किसी अक्षर का इंडेक्स ढूँढा जा सकता है।
`index` मेथड आर्गुमेंट के रूप में एक `String`, `Char` या रेगेक्स लेता है।
यह एक वैकल्पिक दूसरा आर्गुमेंट भी ले सकता है, जो बताता है कि किस इंडेक्स से खोज शुरू करनी है।
`index` मेथड आर्गुमेंट के पहली बार मिलने वाले इंडेक्स को लौटाता है।

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

स्ट्रिंग से कोई अक्षर हटाने के लिए आप [`delete_at`][delete_at] मेथड इस्तेमाल कर सकते हैं।
`delete_at` मेथड आर्गुमेंट के रूप में एक इंडेक्स लेता है और उस इंडेक्स पर मौजूद अक्षर को हटा देता है।

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

[`insert`][insert] मेथड की मदद से किसी खास इंडेक्स पर एक स्ट्रिंग डाली जा सकती है।
`insert` मेथड पहले आर्गुमेंट के रूप में एक इंडेक्स और दूसरे आर्गुमेंट के रूप में एक स्ट्रिंग लेता है।
`insert` मेथड एक नई स्ट्रिंग लौटाता है जिसमें दूसरा आर्गुमेंट उस इंडेक्स पर डाला गया होता है।

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
