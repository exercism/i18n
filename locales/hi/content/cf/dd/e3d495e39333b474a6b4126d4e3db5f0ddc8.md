# परिचय

## कंस्ट्रक्टर

किसी _क्लास_ का इंस्टेंस बनाने के लिए उसके _कंस्ट्रक्टर_ को `new` ऑपरेटर के ज़रिए कॉल किया जाता है। कंस्ट्रक्टर एक खास तरह का मेथड होता है, जिसका उद्देश्य नए बनाए गए इंस्टेंस को शुरुआती वैल्यू देना होता है। कंस्ट्रक्टर दिखते तो आम मेथड जैसे ही हैं। फर्क बस इतना है कि इनका कोई रिटर्न टाइप नहीं होता और इनका नाम क्लास के नाम से मिलता है।

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

आम मेथड की तरह कंस्ट्रक्टर में भी पैरामीटर हो सकते हैं। कंस्ट्रक्टर के पैरामीटर आम तौर पर (private) फील्ड में संग्रहीत कर लिए जाते हैं, ताकि बाद में उन्हें इस्तेमाल किया जा सके, या फिर किसी एक बार के हिसाब में काम आते हैं। कंस्ट्रक्टर को आर्गुमेंट भी उसी तरह भेजे जा सकते हैं जैसे आम मेथड को भेजे जाते हैं।

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
