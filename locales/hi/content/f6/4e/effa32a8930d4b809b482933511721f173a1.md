# परिचय

Elm में टेक्स्ट दिखाने का आधार अक्षर और स्ट्रिंग होते हैं। स्ट्रिंग को अक्षरों की ऐरे माना जा सकता है, और `List` के ज़्यादातर फंक्शनों के बराबर के फंक्शन `String` मॉड्यूल में मौजूद हैं।

## अक्षर

`Char` टाइप यूनिकोड के एक अकेले अक्षर को दर्शाता है, जिसे सिंगल कोट में लिखा जाता है, जैसे `'a'`। 
`Char` मॉड्यूल अक्षर के गुण जाँचने के लिए प्रेडिकेट फंक्शन (`Char -> Bool`) देता है: `isUpper`, `isLower`, `isAlpha` और `isAlphaNum`। 
यह मॉड्यूल अक्षर को बदलने के फंक्शन भी देता है: `toUpper`, `toLower`, `toLocaleUpper` और `toLocaleLower`। साथ ही, अक्षर और उसके संख्यात्मक यूनिकोड मान (`Int`) के बीच आने-जाने के लिए `toCode` और `fromCode` भी मिलते हैं।

## स्ट्रिंग

`String` टाइप स्ट्रिंग को कुशलता से संभालने का अंतर्निहित तरीका देता है, और यूनिकोड अक्षरों के किसी भी क्रम को दर्शा सकता है, जैसे "this is an Elm string."
कई लाइनों वाली स्ट्रिंग को तीन डबल कोट के बीच लिखा जाता है, और उसमें बिना एस्केप किए कोट तथा नई लाइनें हो सकती हैं।
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## स्ट्रिंग के फंक्शन

`String` मॉड्यूल में नीचे दी गई तालिका में बताए गए सारे फंक्शन मौजूद हैं।
सबसे ज़्यादा इस्तेमाल होने वाले कुछ फंक्शन ये हैं:

`cons : Char -> String -> String` स्ट्रिंग के शुरू में एक अक्षर जोड़ता है।
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` दो स्ट्रिंग जोड़ता है।
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` स्ट्रिंग को दिए गए सेपरेटर पर बाँटकर स्ट्रिंग की ऐरे बनाता है।
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` स्ट्रिंग की ऐरे को दिए गए सेपरेटर के साथ जोड़ता है।
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` दिए गए सबस्ट्रिंग की सभी जगहों को बदल देता है।
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` स्ट्रिंग में अक्षरों की संख्या लौटाता है।
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` स्ट्रिंग को `Just Int` में बदलने की कोशिश करता है, और गलत तरीके से लिखी गई स्ट्रिंग के लिए `Nothing` लौटाता है।
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` जाँचता है कि दूसरी स्ट्रिंग में पहली स्ट्रिंग मौजूद है या नहीं।
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` दिए गए फंक्शन को स्ट्रिंग के हर `Char` पर लागू करता है।
ध्यान दीजिए कि दिया गया फंक्शन `Char` से `Char` की ओर मैपिंग होना चाहिए।
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
