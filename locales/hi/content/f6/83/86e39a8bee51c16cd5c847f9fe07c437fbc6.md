# परिचय

## संख्याएँ

प्रोग्रामिंग की बहुत-सी भाषाओं में अलग-अलग तरह की संख्याओं के लिए अलग-अलग संख्या टाइप होते हैं, लेकिन JavaScript में सिर्फ दो हैं:

- `number`: एक संख्या वाला डेटा टाइप, जो डबल-प्रिसिज़न 64-बिट फ्लोटिंग-पॉइंट फॉर्मैट (IEEE 754) में होता है।
  इसके उदाहरण हैं `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` और `500000`।
- `bigint`: एक संख्या वाला डेटा टाइप, जो _पूर्णांकों_ को किसी भी परिशुद्धता वाले फॉर्मैट में दर्शा सकता है।
  इसके उदाहरण हैं `-12n`, `0n`, `4n` और `9007199254740991n`।

अगर आपको किसी भी परिशुद्धता की ज़रूरत हो या आप बहुत बड़ी संख्याओं पर काम कर रहे हों, तो `bigint` टाइप इस्तेमाल कीजिए। वरना `number` टाइप ही बेहतर विकल्प है।

### राउंडिंग

एक बिल्ट-इन ग्लोबल ऑब्जेक्ट है जिसका नाम `Math` है, और यह तरह-तरह के [राउंडिंग फंक्शन][ref-math-object-rounding] देता है।
उदाहरण के लिए, `floor` दशमलव संख्या को उसके नीचे की निकटतम पूर्ण संख्या में बदलता है और `ceil` उसे उसके ऊपर की निकटतम पूर्ण संख्या में।

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## अंकगणित के ऑपरेटर

JavaScript संख्याओं पर बुनियादी अंकगणितीय क्रियाएँ करने के लिए 6 अलग-अलग ऑपरेटर देता है।

- `+`: जोड़ का ऑपरेटर संख्याओं का योग निकालने के लिए इस्तेमाल होता है।
- `-`: घटाव का ऑपरेटर दो संख्याओं के बीच का अंतर निकालने के लिए इस्तेमाल होता है।
- `*`: गुणा का ऑपरेटर दो संख्याओं का गुणनफल निकालने के लिए इस्तेमाल होता है।
- `/`: भाग का ऑपरेटर दो संख्याओं को बाँटने के लिए इस्तेमाल होता है।

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: शेषफल का ऑपरेटर भाग देने के बाद बचने वाला शेषफल निकालने के लिए इस्तेमाल होता है।

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: घातांक का ऑपरेटर किसी संख्या की घात निकालने के लिए इस्तेमाल होता है।

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### क्रियाओं का क्रम

एक ही लाइन में कई ऑपरेटर इस्तेमाल करते समय JavaScript [इस प्राथमिकता तालिका][mdn-operator-precedence] में दिखाए गए क्रम का पालन करता है।
इसे अपने संदर्भ में सरल बनाकर कहें तो JavaScript वही PEDMAS (कोष्ठक, घात, भाग/गुणा, जोड़/घटाव) नियम इस्तेमाल करता है, जो हमने प्रारंभिक गणित की कक्षाओं में सीखा है।

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### संक्षिप्त असाइनमेंट ऑपरेटर

संक्षिप्त असाइनमेंट ऑपरेटर, किसी वेरिएबल पर अंकगणित की क्रिया करने और उसी वेरिएबल में नई वैल्यू असाइन करने वाले कोड को छोटे रूप में लिखने का तरीका हैं।
उदाहरण के लिए, दो वेरिएबल `x` और `y` लीजिए।
तब `x += y`, `x = x + y` के बराबर है।
अक्सर इसमें वेरिएबल `y` की जगह कोई संख्या इस्तेमाल की जाती है।
बाकी 5 क्रियाएँ भी इसी तरह की जा सकती हैं।

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
