# निर्देश

स्कूल के नाटक में हर किरदार का एक अंडरस्टडी होता है: कोई ऐसा व्यक्ति जो ज़रूरत पड़ने पर मंच पर आकर वह सब कर सके जो उस किरदार के लिए चाहिए, और स्टेज मैनेजर को पता भी न चले कि वह कौन है।

पाँचों कार्य `UNDERSTUDY` क्लास में लिखे जाएँगे। पहले दो साधारण रूटीन हैं, जिन्हें आगे के कार्यों में बाँधा जाएगा।

## 1. एक संवाद कहने के दो तरीके

`shout` लिखिए, जो संवाद को बड़े अक्षरों में लौटाता है, और `whisper` लिखिए, जो उसे छोटे अक्षरों में लौटाता है और उसके दोनों सिरों पर `"..."` लगाता है।

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. संवाद का अभ्यास कीजिए

`rehearse` एक संवाद और उसे कहने का तरीका लेता है, और परिणाम लौटाता है। इसका दूसरा आर्गुमेंट `ROUT{STR}:STR` टाइप का होता है।

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. पूरा दृश्य

`run_scene` संवादों का एक ऐरे और उन्हें कहने का तरीका लेता है, और उन सबको उसी तरीके से कहकर, `" "` से जोड़कर लौटाता है।

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

खाली दृश्य का परिणाम खाली स्ट्रिंग होता है।

## 4. कहने का तरीका लौटाइए

`understudy_for` एक स्टाइल का नाम लेता है, `"shout"` या कुछ और, और एक `ROUT{STR}:STR` लौटाता है। `"shout"` से चिल्लाने वाला तरीका मिलता है, और बाकी कुछ भी देने पर फुसफुसाने वाला।

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. एक आर्गुमेंट तय कीजिए

`repeat` लिखिए। यह एक संख्या, यानी कितनी बार, और एक संवाद लेता है, और उस संवाद को उतनी बार, बीच में कुछ भी न रखते हुए, लौटाता है:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

फिर `doubler` लिखिए। यह कोई आर्गुमेंट नहीं लेता और एक ऐसा `ROUT{STR}:STR` लौटाता है जो भी वैल्यू इसे दी जाए, उसे दो बार दोहराता है। इसके लिए `repeat` को बाँधिए और उसमें संख्या पहले से भर दीजिए।

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
