# निर्देश

Blorkemon™️ कार्डों के लिए आपकी पुरानी यादें कम होने का नाम ही नहीं ले रहीं। आपने तो उन्हें दोबारा इकट्ठा करना भी शुरू कर दिया है और अब अपने दोस्तों को भी साथ जोड़ रहे हैं।

इस अभ्यास में आप अपना संग्रह सँभालने के लिए `Set` इंटरफेस का उपयोग करेंगे, क्योंकि जब आपका लक्ष्य सभी मौजूद कार्ड इकट्ठा करना हो, तो डुप्लिकेट कार्ड मायने नहीं रखते।

## 1. संग्रह शुरू कीजिए

आपको अपना Blorkemon™️ कार्डों का पुराना भंडार अभी-अभी मिला है!
उस भंडार में बहुत सारे डुप्लिकेट कार्ड हैं, इसलिए अब डुप्लिकेट हटाकर एक नया संग्रह शुरू करने का समय है।

आप चाहते हैं कि आपके दोस्त भी आपके Blorkemon™️ के पागलपन में शामिल हों, और इसका सबसे अच्छा तरीका यह है कि आप उन्हें एक कार्ड देकर उनका संग्रह शुरू करा दें।

`newCollection` मेथड लागू कीजिए, जो कार्डों के ऐरे को बदलकर आपके नए संग्रह का `Set` बना देता है।

```java
GottaSnatchEmAll.newCollection(List.of("Newthree", "Newthree", "Newthree"));
// => {"Newthree"}
```

## 2. संग्रह बढ़ाइए

संग्रह बन जाने के बाद उसकी अपनी एक ज़िंदगी होती है और उसे बढ़ते रहना चाहिए।

`addCard` मेथड लागू कीजिए, जो एक नया कार्ड और आपके इकट्ठा किए गए कार्डों का मौजूदा सेट लेता है।
अगर वह नया कार्ड संग्रह में पहले से मौजूद नहीं है, तो यह मेथड उसे संग्रह में जोड़ देता है। साथ ही यह एक `boolean` लौटाता है, जो बताता है कि संग्रह अपडेट हुआ या नहीं।

```java
Set<String> collection = GottaSnatchEmAll.newCollection("Newthree");
GottaSnatchEmAll.addCard("Scientuna",collection);
// => true

collection.contains("Scientuna");
// => true
```

## 3. अदला-बदली शुरू कीजिए

आप चाहते हैं कि आपके दोस्त भी आपके Blorkemon™️ के पागलपन में शामिल हों, इसलिए अब अदला-बदली शुरू करने का समय है!

दोस्तों के साथ अदला-बदली करते समय हर सौदा करने लायक नहीं होता, या वह हो ही नहीं सकता।
आपको अदला-बदली तभी करनी चाहिए जब आपके और आपके दोस्त, दोनों के पास कोई ऐसा कार्ड हो जो दूसरे के पास न हो।

`canTrade` मेथड लागू कीजिए, जो आपका मौजूदा संग्रह और आपके किसी एक दोस्त का संग्रह लेता है।
ऊपर बताए नियमों के अनुसार यह एक `boolean` लौटाता है, जो बताता है कि अदला-बदली हो सकती है या नहीं।

```java
Set<String> myCollection = Set.of("Newthree");
Set<String> theirCollection = Set.of("Scientuna");
GottaSnatchEmAll.canTrade(myCollection, theirCollection);
// => true
```

## 4. साझा कार्ड पहचानिए

आप और Blorkemon™️ के शौकीन दोस्त एक साथ बैठते हैं और सोचते हैं कि सबसे ज़्यादा कौन-से कार्ड साझा हैं।

`commonCards` मेथड लागू कीजिए, जो संग्रहों का ऐरे लेता है और ऐसे कार्डों का संग्रह लौटाता है जो सभी संग्रहों में मौजूद हैं।

```java
GottaSnatchEmAll.commonCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Scientuna"}
```

## 5. सारे कार्ड

क्या आपके और आपके दोस्तों के पास मिलकर सारे Blorkemon™️ कार्ड हैं?

`allCards` मेथड लागू कीजिए, जो संग्रहों का ऐरे लेता है और सभी संग्रहों को मिलाकर उनमें मौजूद सारे अलग-अलग कार्डों का एक संग्रह लौटाता है।

```java
GottaSnatchEmAll.allCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Newthree", "Scientuna"}
```
