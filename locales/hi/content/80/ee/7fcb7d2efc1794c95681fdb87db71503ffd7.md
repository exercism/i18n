# Bash फूलों का खेत अभ्यास के लिए संकेत

इस अभ्यास में दो-आयामी ऐरे की ज़रूरत लगती है।
Bash में सिर्फ एक-आयामी इंडेक्स वाले ऐरे या असोसिएटिव [ऐरे][array] मिलते हैं।

बहु-आयामी ऐरे का अनुकरण असोसिएटिव ऐरे की मदद से किया जा सकता है: इंडेक्स को कॉमा से अलग की गई स्ट्रिंग में बदलिए और उसे ऐरे में की के रूप में इस्तेमाल कीजिए।

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
