# अक्षर

`CHAR` एक अक्षर होता है, जिसे सिंगल कोट के बीच लिखा जाता है।

```sather
   c : CHAR := 'M';
```

## विशेष अक्षर

कुछ अक्षर सीधे टाइप नहीं किए जा सकते, उन्हें बैकस्लैश के साथ लिखा जाता है:

| लिखा जाता है | क्या होता है |
| --- | --- |
| `'\n'` | नई लाइन |
| `'\t'` | एक टैब |
| `'\''` | सिंगल कोट |
| `'\\'` | बैकस्लैश |

## प्रश्न

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## केस

`.upper` और `.lower` किसी अक्षर का केस बदल देते हैं और बाकी सब कुछ वैसा ही छोड़ देते हैं, इसलिए आप इन्हें ऐसे अक्षर पर भी लगा सकते हैं जिसकी आपने जाँच नहीं की है।

## संख्याएँ

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` और `.char` एक-दूसरे के ठीक उल्टे हैं। इन अक्षरों को दिए गए नंबरों के बारे में जो बातें काम की हैं वे ये हैं: `'a'` से `'z'` तक के अक्षर लगातार आते हैं, `'A'` से `'Z'` तक लगातार आते हैं, और `'0'` से `'9'` तक लगातार आते हैं। इसलिए:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## गोल घूमकर वापस आना

सिफर का पहिया `z` से आगे निकलकर वापस `a` पर पहुँच जाता है। `%` ठीक यही करता है:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Sather का `%` तब कभी ऋणात्मक जवाब नहीं देता जब उसके दाईं ओर की संख्या धनात्मक हो, इसलिए यह पहिये को आगे की तरह पीछे की ओर घुमाने में भी काम आता है।

## अक्षर और स्ट्रिंग

`STR` बाइट्स की एक कतार होती है, और `CHAR` एक बाइट। अंग्रेज़ी टेक्स्ट में एक बाइट एक अक्षर होता है, इसलिए `"Marlowe".size` का मान 7 है और `"Marlowe"[0]` का मान `'M'` है। एक्सेंट या किसी दूसरी वर्णमाला वाले टेक्स्ट में एक अक्षर कई बाइट ले सकता है, और तब ये दोनों बातें लागू नहीं होतीं।
