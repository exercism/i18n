# निर्देश परिशिष्ट

## इम्प्लीमेंटेशन नोट्स

Cipher इंटरफेस की परिभाषा `cipher.go` में दी गई है।

आपके इम्प्लीमेंटेशन को Cipher इंटरफेस के अनुरूप होना चाहिए।

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

यह अपेक्षित है कि `Encode` स्ट्रिंग में मौजूद उन सभी वैल्यू को अनदेखा करेगा जो A-Za-z नहीं हैं; वे आउटपुट में नहीं दिखेंगी।
आउटपुट को भी छोटे अक्षरों में बदल दिया जाएगा।

सिफर पाने के लिए इस्तेमाल किए जाने वाले फंक्शन ये हैं:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

`NewShift` के लिए आर्गुमेंट 1 से 25 या -1 से -25 के बीच होना चाहिए।
शून्य की अनुमति नहीं है।
अमान्य आर्गुमेंट के लिए `NewShift` nil लौटाता है।
`NewVigenere` का आर्गुमेंट केवल छोटे अक्षरों a-z से बना होना चाहिए।
'a' अक्षर से पूरी तरह बनी वैल्यू की अनुमति नहीं है।
अमान्य आर्गुमेंट के लिए `NewVigenere` `nil` लौटाता है।
