# परिचय

`Rational numbers` ऐसी भिन्न होती हैं जिनमें एक पूर्णांक अंश को एक पूर्णांक हर से विभाजित किया जाता है।

उदाहरण के लिए, हम `2//3` को अनुमानित `Float64` वैल्यू `0.6666...` के बजाय एक सटीक भिन्न के रूप में संग्रहीत कर सकते हैं।

इसका फायदा यह है कि (*पूर्णांक ओवरफलो* जैसी चरम स्थिति को छोड़कर) परिमेय संख्या सटीक बनी रहती है, और ऐसी राउंडिंग एरर से बच जाती है जो दशमलव संख्याओं के साथ अक्सर अपरिहार्य होती हैं।

परिमेय संख्याएँ काफी सरल संख्या टाइप हैं और इनका व्यवहार लगभग वैसा ही है जैसा आप उम्मीद करेंगे। चूँकि शुरुआती वर्ज़न से ही Julia में ये एक मानक टाइप रही हैं, इसलिए ज़्यादातर फंक्शन इन्हें इनपुट के रूप में पूर्णांकों और दशमलव संख्याओं की ही तरह स्वीकार करते हैं।

## परिमेय संख्याएँ बनाना

बनाना उतना ही आसान है जितना दो पूर्णांकों के बीच `//` लगाना।

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

सामान्य गुणनखंड अपने आप हट जाते हैं और भिन्न अपने "न्यूनतम रूप" में आ जाती है: यानी उस भिन्न को सटीक रूप से दर्शाने वाले सबसे छोटे पूर्णांक, जिनका हर ऋणात्मक न हो।

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## परिमेय संख्याओं के साथ अंकगणित

सामान्य `arithmetic operators` `+ - * / ^ %` परिमेय संख्याओं के साथ काम करते हैं, लगभग उसी तरह जैसे अन्य संख्या टाइप के साथ।

पूर्णांक और दूसरी `Rational`s भी इसमें शामिल की जा सकती हैं, और परिणाम एक `Rational` ही मिलता है।
एक्सप्रेशन में `float` शामिल करने पर आउटपुट भी `float` ही मिलता है, और इससे सटीकता में (संभवतः) कमी आ सकती है।

अगर `float` चाहिए, तो किसी परिमेय संख्या को बदलने के लिए बस `float()` फंक्शन इस्तेमाल कीजिए।
यह काफी सामान्य बात है कि किसी लंबी गणना के दौरान सटीकता बनाए रखने के लिए परिमेय संख्याएँ इस्तेमाल की जाएँ, और अंत में उन्हें दशमलव संख्या में बदल दिया जाए।

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## अन्य ऑपरेशन

Julia में परिमेय संख्याएँ बस संख्याएँ ही होती हैं।
कंपाइलर ज़रूरत पड़ने पर टाइप आम तौर पर अपने आप बदल देता है।

लेकिन ध्यान रखिए कि तुलनाएँ उन भिन्नों के लिए ही ठीक से काम करती हैं जिनका दशमलव रूप सीमित होता है:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

लेकिन बाकी मामलों में तुलना के लिए `Rational` को `Float` में बदलना चाहिए:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

गणितीय फंक्शन परिमेय संख्याएँ इनपुट के रूप में लेते हैं, पर परिणाम दशमलव संख्या के रूप में दे सकते हैं:

```julia-repl
julia> sqrt(9//16)
0.75
```
