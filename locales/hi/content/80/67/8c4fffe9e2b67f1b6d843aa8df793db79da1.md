# परिचय

## R में बूलियन

सही या गलत वैल्यू को `logical` टाइप से दर्शाया जाता है।
इसमें केवल दो वैल्यू होती हैं: `TRUE` और `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## बूलियन ऑपरेटर

R में पाँच बूलियन ऑपरेटर हैं, लेकिन सिलेबस के इस चरण में केवल तीन ही प्रासंगिक हैं।
बाकी दो वेक्टर के साथ काम करते समय महत्वपूर्ण होंगे, जिन्हें आगे कई कॉन्सेप्ट में समझाया जाएगा।

`&&` बूलियन "और" है।
अगर `&&` के *दोनों* ओर के एक्सप्रेशन `TRUE` हैं, तो यह `TRUE` देता है।

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` बूलियन "या" है।
अगर `||` के *किसी एक* ओर का एक्सप्रेशन `TRUE` है, तो यह `TRUE` देता है।

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` बूलियन "नहीं" है।
यह `TRUE` और `FALSE` वैल्यू को आपस में बदल देता है।

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

लंबे और ज़्यादा जटिल एक्सप्रेशन के लिए बेहतर है कि आप अपना इरादा साफ़ रखने के लिए गोल ब्रैकेट का उपयोग कीजिए।

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
