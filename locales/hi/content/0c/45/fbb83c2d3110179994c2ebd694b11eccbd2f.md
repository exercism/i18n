# परिचय

Swift में कंट्रोल ट्रांसफर स्टेटमेंट होते हैं, जिनसे लूप और switch स्टेटमेंट के चलने का क्रम बदला जा सकता है। `return` के अलावा Swift में `continue`, `break`, लूप लेबल और `fallthrough` भी हैं।

## Continue

`continue` स्टेटमेंट लूप से कहता है कि वह मौजूदा इटरेशन चलाना बंद करके तुरंत अगला इटरेशन शुरू कर दे। `while` या `repeat-while` लूप में यह सीधे शर्त की जाँच पर पहुँच जाता है। `for-in` लूप में यह सीक्वेंस के अगले एलिमेंट पर चला जाता है।

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break` स्टेटमेंट पूरे लूप या switch स्टेटमेंट से तुरंत बाहर निकल जाता है। इसके बाद प्रोग्राम लूप या switch के बाद वाली कोड की पहली लाइन से आगे बढ़ता है।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## लेबल वाले स्टेटमेंट

नेस्टेड लूप में कभी-कभी ज़रूरत होती है कि `break` या `continue` सबसे अंदर वाले लूप के बजाय किसी बाहरी लूप पर लागू हो। आप लूप से पहले नाम और कोलन (`labelName:`) लगाकर उसे लेबल दे सकते हैं। फिर वही लेबल `break` या `continue` को दे सकते हैं:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
