# निर्देश

आप एक खास मूवी थिएटर चलाते हैं।
मूवी देखने के लिए लोगों को सालाना पास खरीदना पड़ता है, उसके बाद वे मुफ्त में मूवी देख सकते हैं।

आपका थिएटर प्रवेशों का रिकॉर्ड रखता है।
आप उस रिकॉर्ड का उपयोग यह देखने के लिए करना चाहते हैं कि इस महीने किन सदस्यों ने अपना सालाना पास इस्तेमाल किया।
आप अपने ग्राहकों के उम्र वर्ग की जानकारी भी पाना चाहते हैं।
आप समझ जाते हैं कि इन लक्ष्यों को पूरा करने के लिए आप सेट का उपयोग कर सकते हैं।

## सेट

इस तरह का डेटा रखने के लिए सेट बिलकुल सही डेटा टाइप है।

सेट एक ऐसा डेटा टाइप है जिसमें अलग-अलग, अनोखी वैल्यू बिना किसी खास क्रम के रखी जाती हैं।
अलग और अनोखा होने का मतलब है कि कोई एलिमेंट या तो सेट में है या नहीं है। ऐरे की तरह यह सेट में कई बार नहीं हो सकता।
सेट आमतौर पर बिना क्रम के होते हैं। अगर आप किसी सेट के एलिमेंट की सूची बनाएँ, तो जो क्रम आपको मिलेगा वह उस क्रम से अलग हो सकता है जिसमें उन्हें जोड़ा गया था, या पिछली बार की सूची में मिले क्रम से भी अलग हो सकता है!

सेट की एक बुनियादी विशेषता सदस्यता की जाँच है, यानी यह देख पाना कि किसी सेट में कोई एलिमेंट है या नहीं।
सेट के लगभग हर उपयोग में सदस्यता की जाँच बुनियादी होती है।

Go में पहले से बना हुआ सेट डेटा टाइप नहीं होता।
सेट की जगह `map[<type>]struct{}` या `map[<type>]bool` का उपयोग करना आम है। सेट की तरह ही `map` में भी अलग-अलग, अनोखे एलिमेंट जोड़े जा सकते हैं और सदस्यता की जाँच की जा सकती है।

## 1. उपस्थित लोगों की जानकारी रखने की जगह

उपस्थिति और उम्र वर्ग पर नज़र रखने के लिए आप सेट का उपयोग करना चाहते हैं।

आप नामों और उम्र के लिए अलग-अलग सेट नहीं लिखना चाहते। इसके बजाय आप दोनों के लिए एक जेनेरिक सेट का उपयोग कर सकते हैं।
उपस्थित लोगों को रखने के लिए `Set` टाइप को `map[T comparable]struct{}` के रूप में परिभाषित कीजिए।
एक `NewSet[T comparable]()` फंक्शन लिखिए जो खाली `Set[T]` लौटाता है।

```go
names := NewSet[string]()
```

## 2. उपस्थित लोगों पर नज़र रखना

अब आप उपस्थित लोगों की जानकारी दर्ज करने के लिए तैयार हैं।

एक `Add[T]()` मेथड लिखिए जो सेट में एक एलिमेंट जोड़ता है।

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. उपस्थित लोगों की जाँच

अब जब आपके पास उपस्थित लोगों का सेट है, तो आप देख सकते हैं कि कौन से सदस्य और कौन से उम्र वर्ग आए।
एक `Contains[T](element)` मेथड लिखिए जो बताता है कि कोई सदस्य या उम्र वर्ग `Set` में है या नहीं।

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. उपस्थित लोगों की तुलना

एक और महीना बीत गया और आपके पास उम्र वर्ग का एक नया `Set` है।
आपके मार्केटिंग मैनेजर जानना चाहते हैं कि इस महीने की नई फिल्मों से आने वाले लोगों के उम्र वर्ग बदले हैं या नहीं।
एक `Equals[T](other)` मेथड लिखिए जो बताता है कि दो सेट के एलिमेंट एक जैसे हैं या नहीं।

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
