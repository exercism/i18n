# परिचय

किसी क्लास का इंस्टेंस बनाने के लिए उसके कंस्ट्रक्टर को `new` ऑपरेटर के ज़रिए कॉल किया जाता है। कंस्ट्रक्टर क्लास के अंदर एक खास मेथड होता है, जिसका काम क्लास को शुरुआती वैल्यू देना है। Haxe में कंस्ट्रक्टर मेथड का नाम `new()` होता है।

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

सामान्य मेथड की तरह, कंस्ट्रक्टर में भी पैरामीटर हो सकते हैं। ये पैरामीटर आम तौर पर प्राइवेट फील्ड में रखे जाते हैं और बाद में उपयोग किए जाते हैं।

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
