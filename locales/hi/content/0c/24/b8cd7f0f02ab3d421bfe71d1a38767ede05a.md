# विवरण

[टर्नरी कंडीशनल ऑपरेटर][ternary-operator] `if-else` एक्सप्रेशन लिखने का एक संक्षिप्त रूप है।
यह एक शर्त का मूल्यांकन करता है और उस शर्त के `true` या `false` होने के आधार पर दो वैल्यू में से एक लौटाता है।

यह ऑपरेटर तीन भागों का उपयोग करता है: `condition ? trueExpression : falseExpression`.

अगर `condition` का मूल्यांकन `true` होता है, तो `trueExpression` का मूल्यांकन किया जाता है और उसे लौटाया जाता है; वरना `falseExpression` का मूल्यांकन किया जाता है और उसे लौटाया जाता है।

टर्नरी ऑपरेटर सरल, एक पंक्ति वाले निर्णयों के लिए आदर्श है:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

ऊपर दिया गया उदाहरण इसका संक्षिप्त समकक्ष है:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
