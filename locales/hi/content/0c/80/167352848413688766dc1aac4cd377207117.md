# परिचय

रिकर्शन एक फंक्शन के भीतर कोड दोहराने का तरीका है, जिसमें वह फंक्शन खुद को कॉल करता है।
यह लूप करने या दोहराने का एक और तरीका है। लूप की तरह, फंक्शन को यह जानने के लिए एक बूलियन एक्सप्रेशन जाँचना चाहिए कि कब रुकना है।
लूप के विपरीत, जो रिकर्शन कभी खत्म नहीं होता, वह अनंत तक नहीं चलेगा।
हर फंक्शन कॉल में इस्तेमाल की गई वैल्यू स्टैक पर अपने-अपने फ्रेम में रखी जा सकती हैं।
अगर फंक्शन कॉल की संख्या स्टैक में उपलब्ध जगह से ज़्यादा जगह ले लेती है, तो इससे स्टैक ओवरफ्लो एरर होगी।

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

यह प्रिंट करेगा

```
The number is 1
The number is 2
After recursion
```

कुछ स्थितियाँ ऐसी हो सकती हैं जिन्हें लूप की तुलना में रिकर्शन में व्यक्त करना ज़्यादा पठनीय और/या समझने में आसान लगे।


## टेल कॉल

टेल कॉल तब होता है जब किसी फंक्शन का अंतिम स्टेटमेंट केवल खुद को कॉल करता है और कुछ नहीं।

टेल कॉल रिकर्शन का एक विशेष रूप है, जिससे कंपाइलर कंपाइल किए गए कोड में रिकर्शन को लूप में ऑप्टिमाइज़ कर सकता है।
इससे दोनों दुनियाओं का सर्वश्रेष्ठ मिलता है: रिकर्शन की पठनीयता और लूप का प्रदर्शन।
रिकर्शन को लूप में कंपाइल करने को `tail call elimination` या `tail call optimization.` कहा जाता है।

जब किसी टेल कॉल को लूप में कंपाइल किया जाता है, तो हर फंक्शन कॉल के लिए नया स्टैक फ्रेम नहीं बनाया जाता।
मूल रूप से कॉल किए जाने पर फंक्शन के एड्रेस को अपडेट की गई वैल्यू पास की जाती हैं, जिससे स्टैक स्पेस बचता है और प्रदर्शन सुधरता है।

यह उदाहरण टेल कॉल नहीं है, क्योंकि फंक्शन खुद को कॉल करने के परिणाम में 1 जोड़ता है

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

यह प्रिंट करेगा

```
The number is 1
The number is 2
j is 3 after recursion
```

इसे टेल कॉल में बदलने के लिए, `j` को `printIncrement` का पैरामीटर बनाइए

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

आपको लग सकता है कि टेल कॉल को समझना उस रिकर्शन कॉल से ज़्यादा आसान है जो टेल कॉल नहीं है।
हालाँकि, कंपाइलर आमतौर पर गारंटी नहीं देते कि सभी टेल कॉल ऑप्टिमाइज़ किए जाएँगे।
रिकर्शन का उपयोग करते समय यह जानना हमेशा ज़रूरी है कि इतने इटरेशन न हों कि स्टैक ओवरफ्लो हो जाए।
