# परिचय

Go में, `struct` नामित एलिमेंट का एक क्रम होता है जिन्हें _फील्ड_ कहा जाता है, और हर फील्ड का एक नाम और टाइप होता है।
एक फील्ड का नाम स्ट्रक्चर के अंदर अद्वितीय होना चाहिए।
ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग पैराडाइम में स्ट्रक्चर की तुलना _क्लासों_ से की जा सकती है।

## स्ट्रक्चर को परिभाषित करना

आप `type` और `struct` कीवर्ड का उपयोग करके नया स्ट्रक्चर बनाते हैं, और फील्ड के नाम और टाइप को स्पष्ट रूप से परिभाषित करते हैं।
उदाहरण के लिए, यहाँ हम `Shape` स्ट्रक्चर परिभाषित करते हैं, जो किसी आकृति का नाम और उसका आकार रखता है:

```go
type Shape struct {
    name string
    size int
}
```

स्ट्रक्चर में फील्ड के नाम Go के कन्वेंशन का पालन करते हैं: जिन फील्ड के नाम छोटे अक्षर से शुरू होते हैं, वे केवल उसी पैकेज के कोड को दिखाई देते हैं, जबकि जिनके नाम बड़े अक्षर से शुरू होते हैं, वे दूसरे पैकेज में भी दिखाई देते हैं।

## स्ट्रक्चर के इंस्टेंस बनाना

एक बार जब आप `struct` को परिभाषित कर लेते हैं, तो आपको फील्ड के नाम का उपयोग करके किसी भी क्रम में फील्ड निर्धारित करते हुए नया इंस्टेंस बनाना होता है:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

इंस्टेंस के फील्ड को पढ़ने या बदलने के लिए, `.` नोटेशन का उपयोग कीजिए:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

जिन फील्ड को कोई शुरुआती वैल्यू असाइन नहीं की गई होती, उनकी ज़ीरो वैल्यू होती है।
उदाहरण के लिए:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

आप फील्ड के नाम का उपयोग किए बिना भी `struct` का इंस्टेंस बना सकते हैं, बशर्ते आप फील्ड को _क्रम में_ परिभाषित करें:

```go
s := Shape {
	"Oval",
	20,
}
```

हालाँकि, यह सिंटैक्स _भंगुर कोड_ माना जाता है, क्योंकि जब कोई फील्ड जोड़ा जाता है तो यह टूट सकता है, खासकर जब नया फील्ड अलग टाइप का हो।
नीचे के उदाहरण में हम `Shape` में एक अतिरिक्त फील्ड जोड़ते हैं:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## "New" फंक्शन

कभी-कभी ऐसे फंक्शन होना अच्छा लगता है जो हमें स्ट्रक्चर के इंस्टेंस बनाने में मदद करें।
कन्वेंशन के अनुसार, इन फंक्शन को आमतौर पर `New` कहा जाता है या उनके नाम `New` से शुरू होते हैं, लेकिन चूँकि ये सिर्फ साधारण फंक्शन हैं, आप इन्हें कोई भी नाम दे सकते हैं।
ये आपको दूसरी भाषाओं के कंस्ट्रक्टर की याद दिला सकते हैं, लेकिन Go में ये सिर्फ साधारण फंक्शन हैं।

नीचे के उदाहरण में, इनमें से एक `New` फंक्शन का उपयोग `Shape` का नया इंस्टेंस बनाने और आकृति के `size` के लिए अपने आप डिफॉल्ट वैल्यू सेट करने के लिए किया गया है:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New` फंक्शन का उपयोग करने के ये फायदे हो सकते हैं:

* दी गई वैल्यू की जाँच
* डिफॉल्ट वैल्यू को संभालना
* चूँकि `New` फंक्शन अक्सर उन स्ट्रक्चर के उसी पैकेज में घोषित होते हैं जिन्हें वे इनिशियलाइज़ करते हैं, इसलिए वे स्ट्रक्चर के प्राइवेट फील्ड को भी इनिशियलाइज़ कर सकते हैं

इस टाइप को और गहराई से समझने के लिए, आप इन संसाधनों को देख सकते हैं: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] या [Structures in Go (structs)][medium-structures-in-go]

## `new` बिल्टइन

स्ट्रक्चर का नया इंस्टेंस बनाने का एक और तरीका `new` बिल्टइन का उपयोग करना है:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

इस उदाहरण में, `new` स्ट्रक्चर `Shape` का एक इंस्टेंस बनाता है जिसमें सभी वैल्यू उनके टाइप की ज़ीरो वैल्यू पर इनिशियलाइज़ होती हैं, और उसका पॉइंटर लौटाता है।

~~~~exercism/note
अधिकतर मामलों में, आप `new` बिल्टइन का उपयोग करके बनाए गए स्ट्रक्चर के नए इंस्टेंस नहीं देखेंगे।
हमेशा स्ट्रक्चर लिटरल, कस्टम `New` फंक्शन या पैकेज द्वारा दिए गए किसी अन्य ऐसे फंक्शन को प्राथमिकता दीजिए जो आपको स्ट्रक्चर बनाने में मदद कर सके।
स्ट्रक्चर के नए इंस्टेंस बनाने के लिए `new` बिल्टइन को अंतिम विकल्प के रूप में इस्तेमाल कीजिए।
~~~~
