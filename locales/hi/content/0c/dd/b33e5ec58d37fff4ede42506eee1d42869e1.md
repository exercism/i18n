# दिए गए सिग्नेचर न बदलें

जैसा कि निर्देशों में बताया गया है, आपको `makeChest` और `makeTreasureChest` के सिग्नेचर नहीं बदलने चाहिए। ये बिल्कुल ऐसे ही रहने चाहिए:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
