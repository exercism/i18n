# निर्देश

Ozan एक बेहतरीन मिक्सटेप तैयार कर रहा है: पहले वह तय करता है कि उसमें *कौन से* गाने शामिल होंगे, और फिर यह कि वे किस *क्रम* में बजेंगे। आप उसकी इन पसंदों के पीछे काम करने वाले कॉम्बिनेटरिक्स के मददगार फंक्शन `mixtape-maker` वोकैबुलरी में बनाएँगे।

## 1. संचयों की गिनती कीजिए

`count-combinations` को ऐसे बनाइए कि वह क्रम को अनदेखा करते हुए `n` में से `k` चीज़ें चुनने के तरीकों की संख्या लौटाए।

```factor
5 2 count-combinations .
! => 10
```

## 2. क्रमचयों की गिनती कीजिए

`count-permutations` को ऐसे बनाइए कि वह उस समय `n` में से `k` चीज़ें चुनने के तरीकों की संख्या लौटाए जब क्रम महत्वपूर्ण हो।

```factor
5 2 count-permutations .
! => 20
```

## 3. संचयों की सूची बनाइए

`list-combinations` को ऐसे बनाइए कि वह किसी सीक्वेंस के सभी `k`-एलिमेंट वाले संचय लौटाए।

```factor
{ 1 2 3 } 2 list-combinations .
! => { { 1 2 } { 1 3 } { 2 3 } }
```

## 4. क्रमचयों की सूची बनाइए

`list-permutations` को ऐसे बनाइए कि वह किसी सीक्वेंस के सभी क्रमचय लौटाए।

```factor
{ 1 2 } list-permutations .
! => { { 1 2 } { 2 1 } }
```

## 5. लक्ष्य के बराबर जोड़ने वाले संचय

`combinations-summing-to` को ऐसे बनाइए कि वह किसी सीक्वेंस के केवल उन्हीं `k` संचयों को लौटाए जिनके एलिमेंट जोड़कर `target` बनाते हैं।

```factor
{ 1 2 3 4 } 2 5 combinations-summing-to .
! => { { 1 4 } { 2 3 } }
```
