# String

`String` डेटा टाइप UTF-8 में एन्कोड किए गए अक्षरों की एक रैखिक शृंखला है। यह टेक्स्ट डेटा संग्रहीत करने के लिए उपयोगी है।

## स्ट्रिंग बनाना

`String::new()` या `String::from()` असोसिएटेड फंक्शन की मदद से एक स्ट्रिंग बनाई जा सकती है। कई टाइप में एक `to_string` मेथड होता है, जिससे स्ट्रिंग बनाई जा सकती है, जैसे किसी संख्या से।

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### `format!` मैक्रो

छोटे-छोटे डेटा टाइप को मिलाकर एक बड़ी स्ट्रिंग बनाना आम बात है, इसलिए Rust में एक छोटा तरीका भी है जो `to_string` कॉल करने की बारीकियाँ छिपा देता है: `format!` मैक्रो। उदाहरण के लिए, ऊपर बनी मिश्रित स्ट्रिंग को हम इस तरह आसान बना सकते हैं:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## स्ट्रिंग स्लाइस

स्ट्रिंग का स्ट्रिंग स्लाइस के साथ गहरा संबंध है। स्ट्रिंग स्लाइस मेमोरी के एक ज्ञात आकार वाले हिस्से के अपरिवर्तनीय रेफरेंस होते हैं, जिसमें UTF-8 में एन्कोड किए गए अक्षरों की एक रैखिक शृंखला होती है। किसी भी स्ट्रिंग को डीरेफरेंस (`&`) ऑपरेटर से बॉरो करके एक स्ट्रिंग स्लाइस में बदला जा सकता है। किसी स्ट्रिंग स्लाइस को स्ट्रिंग में बदलने के लिए `to_string()` मेथड या `String::from`, दोनों ठीक हैं।

Rust कोड में एक लिटरल स्ट्रिंग को डबल कोट्स के अंदर लिखा जाता है। ये स्ट्रिंग लिटरल हमेशा स्ट्रिंग स्लाइस होते हैं, क्योंकि ये प्रोग्राम के एक्ज़ीक्यूटेबल के अंदर मेमोरी के एक अपरिवर्तनीय हिस्से की ओर इशारा करते हैं।

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## स्ट्रिंग में बदलाव करना

किसी स्ट्रिंग के अंत में एक अक्षर जोड़ने के लिए `push` मेथड का इस्तेमाल कीजिए। किसी स्ट्रिंग के अंत में एक स्ट्रिंग स्लाइस जोड़ने के लिए `push_str` मेथड या `+` ऑपरेटर का इस्तेमाल कीजिए।

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## स्ट्रिंग के अक्षरों तक पहुँचना

Rust की स्ट्रिंग UTF-8 में एन्कोड की जाती हैं, इसलिए सभी अक्षर एक ही आकार के नहीं होते। इस कारण `String` डेटा टाइप कोई इंडेक्सिंग ऑपरेटर (`[]`) नहीं देता। किसी स्ट्रिंग के सारे अक्षरों या किसी एक खास अक्षर तक पहुँचने के लिए `chars()` मेथड का इस्तेमाल किया जा सकता है। यह स्ट्रिंग के हर अक्षर पर क्रम से एक-एक करके चलता है।

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

## और जानकारी

String एक समृद्ध डेटा टाइप है, जिसके लिए कई मेथड और मैक्रो बनाए गए हैं। String के सभी मेंबर मेथड और सुविधाएँ जानने के लिए [स्टैंडर्ड लाइब्रेरी का डॉक्युमेंटेशन](https://doc.rust-lang.org/std/string/struct.String.html) देखिए।
