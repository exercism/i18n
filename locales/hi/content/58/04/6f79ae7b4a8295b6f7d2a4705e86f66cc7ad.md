# निर्देश

आपको एक ऐसी सेवा लिखने का काम दिया गया है जो ईवेंट लेती है। हर ईवेंट के साथ एक तारीख जुड़ी होती है, लेकिन आपका ध्यान जाता है कि आपकी सेवा के एंडपॉइंट पर 3 अलग-अलग फॉर्मैट में तारीखें भेजी जा रही हैं:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

आप देखते हैं कि इन सबमें कुछ समानताएँ हैं, और आप कुछ ऐसे रेगुलर एक्सप्रेशन पैटर्न बनाने का फैसला करते हैं जिन्हें आपस में जोड़कर इस्तेमाल किया जा सके।

## 1. किसी तारीख से दिन, महीना और साल का मिलान कीजिए

`day/0`, `month/0` और `year/0` बनाइए जो एक स्ट्रिंग पैटर्न लौटाएँ, जिसे कम्पाइल करने पर `"01/01/1970"` (`dd/mm/yyyy`) के संख्यात्मक हिस्सों से मिलान हो। दिन और महीना `1` या `01` (बाईं ओर शून्य लगाकर) के रूप में आ सकते हैं।

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. सप्ताह के दिन और साल के महीने का मिलान कीजिए

`day_names/0` और `month_names/0` बनाइए जो एक स्ट्रिंग पैटर्न लौटाएँ, जिसे कम्पाइल करने पर क्रमशः सप्ताह के दिन के नाम और साल के महीने के नाम से मिलान हो।

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. दिन, महीना और साल को कैप्चर कीजिए

`capture_day/0`, `capture_month/0`, `capture_year/0`, `capture_day_name/0`, `capture_month_name/0` बनाइए जो एक स्ट्रिंग पैटर्न लौटाएँ जो संबंधित हिस्सों को इन नामों के तहत कैप्चर करे: `"day"`, `"month"`, `"year"`, `"day_name"`, `"month_name"`

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. सारे कैप्चर जोड़कर पूरी तारीख कैप्चर कीजिए

`capture_numeric_date/0`, `capture_month_name_date()` और `capture_day_month_name_date/0` बनाइए जो एक स्ट्रिंग पैटर्न लौटाएँ जो भाग 3 के हिस्सों को संबंधित तारीख फॉर्मैट का उपयोग करके कैप्चर करे:

- संख्यात्मक तारीख - `"01/01/1970"`
- महीने के नाम वाली तारीख - `"January 1, 1970"`
- दिन और महीने के नाम वाली तारीख - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. कैप्चर को सीमित कीजिए ताकि वह सिर्फ तारीख से मिलान करे

`match_numeric_date/0`, `match_month_name_date/0` और `match_day_month_name_date/0` बनाइए जो एक कम्पाइल किया हुआ रेगुलर एक्सप्रेशन लौटाएँ जो सिर्फ तारीख से मिलान करे और उसके हिस्सों को भी कैप्चर कर सके।

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
