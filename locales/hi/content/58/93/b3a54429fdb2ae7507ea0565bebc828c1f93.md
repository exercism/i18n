# परिचय

[गार्ड्स][guards] का उपयोग [पैटर्न मैचिंग][exercism-pattern-matching] के पूरक के रूप में किया जाता है। जिसे हम आगे के किसी कॉन्सेप्ट में समझाएँगे। गार्ड्स हमें इनपुट की वैल्यू के आधार पर एक फंक्शन के अलग-अलग इम्प्लीमेंटेशन रखने की सुविधा देते हैं। ये अधिक जटिल जाँच की सुविधा देते हैं।

एक गार्ड स्टेटमेंट को पाइप `|` से परिभाषित किया जाता है, जिसके बाद एक बूलियन एक्सप्रेशन आता है, और अंत में बराबर का चिह्न `=` और फंक्शन की बॉडी होती है। एक ही फंक्शन के लिए कई गार्ड स्टेटमेंट हो सकते हैं। गार्ड स्टेटमेंट का मूल्यांकन ऊपर से नीचे किया जाता है, और जो पहला `True` देता है, वही निष्पादित होता है। एक गार्ड स्टेटमेंट में `otherwise` स्टेटमेंट की अनुमति होती है, जो उन सभी वैल्यू के लिए होता है जो पिछले गार्ड स्टेटमेंट से मेल नहीं खातीं।

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

हम अपना फंक्शन बना सकते हैं और उसे गार्ड स्टेटमेंट के अंदर इस्तेमाल कर सकते हैं।

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
