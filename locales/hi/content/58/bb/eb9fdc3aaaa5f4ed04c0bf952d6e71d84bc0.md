# परिचय

`math/rand` पैकेज स्यूडो-रैंडम संख्याएँ बनाने की सुविधा देता है।

यहाँ बताया गया है कि `0` और `99` के बीच एक रैंडम पूर्णांक कैसे बनाया जाए:

```go
import "math/rand"

n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

`rand.Float64` फंक्शन `0.0` और `1.0` के बीच एक रैंडम दशमलव संख्या लौटाता है:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

किसी स्लाइस (या किसी और डेटा स्ट्रक्चर) को शफल करने की सुविधा भी है:

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## सीड

`math/rand` पैकेज से बनने वाले संख्याओं के क्रम वास्तव में रैंडम नहीं होते। किसी खास "सीड" वैल्यू के लिए नतीजे पूरी तरह निर्धारित होते हैं।

Go 1.20 और उसके बाद के वर्शनों में सीड अपने आप रैंडम तरीके से चुना जाता है, इसलिए प्रोग्राम को हर बार चलाने पर आपको रैंडम संख्याओं का अलग क्रम दिखेगा।

Go के पहले के वर्शनों में सीड डिफ़ॉल्ट रूप से `1` था। इसलिए प्रोग्राम को अलग-अलग बार चलाने पर अलग-अलग क्रम पाने के लिए, कोई भी रैंडम संख्या लेने से पहले आपको रैंडम संख्या जनरेटर को खुद सीड करना पड़ता था, जैसे कि मौजूदा समय से।

```go
rand.Seed(time.Now().UnixNano())
```
