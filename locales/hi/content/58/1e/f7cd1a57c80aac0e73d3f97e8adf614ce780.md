# परिचय

प्रोग्रामिंग करते समय आम तौर पर पहिए का दोबारा आविष्कार करने की ज़रूरत नहीं होती। कई मानक एल्गोरिदम ऐसे हैं जिनका काम शायद किसी और ने पहले ही आपके लिए कर रखा हो।

## इन्क्लूड

दूसरी फाइलों की सामग्री शामिल करने के लिए C++ `include` डायरेक्टिव का उपयोग करता है। ये इन्क्लूड फाइल के सबसे ऊपर लिखे जाने चाहिए। कंपाइलेशन के दौरान डायरेक्टिव वाली लाइन की जगह उस फाइल की सामग्री रख दी जाती है। इन्क्लूड के बाद नेमस्पेस वैसे ही रहते हैं जैसे मूल फाइल में थे।

## मानक लाइब्रेरी

मानक लाइब्रेरी कई आम फंक्शन, एल्गोरिदम और डेटा स्ट्रक्चर देती है। मानक लाइब्रेरी `std` नेमस्पेस का उपयोग करती है।

इसका एक उदाहरण C की गणितीय लाइब्रेरी `cmath` है। यह कई आम गणितीय संक्रियाएँ देती है।

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
मानक लाइब्रेरी को डबल कोट्स `"` के बजाय एंगल ब्रैकेट `<>` के साथ शामिल किया जाता है। फर्क इस जगह में है कि कंपाइलर उन फाइलों को कहाँ ढूँढता है। एंगल ब्रैकेट वाले रूप में मौजूदा प्रोजेक्ट में खोज छोड़ दी जाती है, और कंपाइलर सीधे सिस्टम की इन्क्लूड डायरेक्टरियों से शुरू करता है। अगर आप लोकल फाइलें शामिल करना चाहें, तो डबल कोट्स का उपयोग कीजिए: `#include "myfile"`
~~~~
