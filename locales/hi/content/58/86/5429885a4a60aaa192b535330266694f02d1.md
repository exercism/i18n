# परिचय

## तुलना ऑपरेटर

R में भी वही ऑपरेटर हैं जो कई दूसरी भाषाओं में मिलते हैं:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## ब्रांचिंग

if-else का सामान्य रूप ऐसा होता है:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

इस स्थिति में बूलियन के चारों ओर गोल ब्रैकेट `()` और स्टेटमेंट के चारों ओर घुंघराले ब्रैकेट `{}`, दोनों ज़रूरी हैं।
एक साधारण `if` स्टेटमेंट को छोटा भी किया जा सकता है:

```R
if (x == 0) return("success")
```
