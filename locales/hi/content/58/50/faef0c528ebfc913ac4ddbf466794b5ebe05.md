# परिचय

Go में स्लाइस दूसरी भाषाओं के ऐरे जैसे होते हैं।
इनमें किसी एक खास टाइप (या इंटरफेस) के कई एलिमेंट रहते हैं।

Go में स्लाइस ऐरे पर आधारित होते हैं।
ऐरे का आकार तय होता है।
स्लाइस, इसके उलट, ऐरे के एलिमेंट्स को देखने का एक लचीला तरीका है, जिसका आकार गतिशील होता है।

स्लाइस को `[]T` की तरह लिखा जाता है, जहाँ `T` स्लाइस के एलिमेंट्स का टाइप होता है:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

किसी दिए गए शून्य-आधारित इंडेक्स पर एलिमेंट पाने या सेट करने के लिए चौकोर ब्रैकेट का इस्तेमाल कीजिए:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

किसी मौजूदा स्लाइस से एलिमेंट्स की एक रेंज लेकर आप नया स्लाइस बना सकते हैं।
यहाँ भी चौकोर ब्रैकेट का ही इस्तेमाल होता है, लेकिन अब शुरुआती (शामिल) और अंतिम (शामिल नहीं) दोनों इंडेक्स बताने पड़ते हैं।
अगर आप शुरुआती इंडेक्स नहीं बताते, तो वह अपने आप 0 मान लिया जाता है।
और अगर अंतिम इंडेक्स नहीं बताते, तो वह स्लाइस की लंबाई मान ली जाती है।

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

`append` फंक्शन की मदद से आप स्लाइस में एलिमेंट जोड़ सकते हैं।
नीचे हम स्लाइस `a` में `4` और `2` जोड़ रहे हैं।

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append` हमेशा एक नया स्लाइस लौटाता है। जब हमें किसी मौजूदा स्लाइस में ही एलिमेंट जोड़ने हों, तो आम तौर पर हम उसी स्लाइस वेरिएबल को नया स्लाइस दोबारा असाइन कर देते हैं, जिसे हम पहले आर्गुमेंट की तरह भेजते हैं, जैसा ऊपर किया गया है।

`append` की मदद से दो स्लाइस जोड़े भी जा सकते हैं:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## स्लाइस में इंडेक्स

स्लाइस के इंडेक्स के साथ काम करते समय हमेशा किसी जाँच से यह पक्का करना चाहिए कि वह इंडेक्स वाकई मौजूद है।
ऐसा न करने पर पूरा एप्लिकेशन क्रैश हो जाएगा।

## खाली स्लाइस

`nil` स्लाइस डिफ़ॉल्ट खाली स्लाइस होता है।
बिना कोई वैल्यू वाले स्लाइस की तुलना में इनमें कोई कमी नहीं होती।
`len` फंक्शन `nil` स्लाइस पर भी काम करता है, उसे इनिशियलाइज़ किए बिना भी उसमें आइटम जोड़े जा सकते हैं, और इसी तरह आगे भी।
नया स्लाइस बनाते समय `s := []int{}` (खाली, गैर-`nil` स्लाइस) के बजाय `var s []int` (`nil` स्लाइस) को प्राथमिकता दीजिए।

## परफॉर्मेंस

जब स्लाइस बार-बार एलिमेंट जोड़कर भरा जाना हो और स्लाइस का अंतिम आकार पता हो, तो परफॉर्मेंस सुधारने का एक आसान तरीका है।
असली बात यह है कि मेमोरी जितनी कम बार आवंटित करनी पड़े, उतना अच्छा है। मेमोरी आवंटित करना काफी महँगा पड़ता है, और ऐसा तब होता है जब स्लाइस अपनी आवंटित मेमोरी की जगह से आगे बढ़ जाता है।
इसे करने का सबसे सुरक्षित तरीका यह है कि आप स्लाइस की क्षमता `cap` पहले ही बता दें: `s := make([]int, 0, cap)`, और फिर आम तरह से स्लाइस में `append` करें।
इस तरह स्लाइस की लंबाई शून्य रहते हुए ही `cap` आइटम की जगह तुरंत आवंटित हो जाती है।
व्यवहार में `cap` अक्सर किसी दूसरे स्लाइस की लंबाई होती है: `s := make([]int, 0, len(otherSlice))`.

## append एक प्योर फंक्शन नहीं है

Go का `append` फंक्शन परफॉर्मेंस के लिए ऑप्टिमाइज़ किया गया है, इसलिए यह इनपुट स्लाइस की कॉपी नहीं बनाता।
इसका मतलब है कि कभी-कभी मूल स्लाइस (यानी `append` का पहला पैरामीटर) भी बदल जाता है।
