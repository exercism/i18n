# अनपेक्षित आवश्यक पैरामीटर

टेस्ट में पैरामीटर \`${'parameter.name'}\` को कहीं वैल्यू के साथ और कहीं बिना वैल्यू के कॉल किया जाता है, लेकिन इसे _ऑप्शनल नहीं बताया गया है_। इसका मतलब है कि टेस्ट पास नहीं होंगे। TypeScript में किसी पैरामीटर को उसके बाद `?` लगाकर स्पष्ट रूप से ऑप्शनल बनाया जा सकता है:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

या फिर उसे कोई डिफॉल्ट वैल्यू असाइन करके:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
