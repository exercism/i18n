इनमें उपयोगकर्ता के संदर्भ के हिसाब से टूलटिप भी दिखते हैं, जैसे यह:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

आप चाहें तो इन विजेट को खुद Markdown दस्तावेज़ों में भी दिखा सकते हैं, जैसे किसी दस्तावेज़ के अंत में, ताकि आगे पढ़ने के लिए या किसी चीज़ को सीखने के लिए अच्छे अभ्यास सुझाए जा सकें।

**ध्यान दें:** आप इनलाइन टेक्स्ट के लिए आम लिंक भी इस्तेमाल कर सकते हैं, जिनमें टूलटिप अपने आप जुड़ जाएँगे। ज़्यादा जानकारी के लिए [आंतरिक लिंकिंग का दस्तावेज़](/docs/building/markdown/internal-linking) देखिए।

## उपयोग

विजेट वहाँ भी इस्तेमाल किए जा सकते हैं जहाँ Markdown इस्तेमाल हो सकता है, जैसे दस्तावेज़ों, अप्रोच और छात्र/मेंटर चर्चाओं में।

इन्हें नीचे दिए गए फॉर्मेट में दिखाया जाता है:

```md
[<type>:<id>]()
```

`<type>` और `<id>` वाले हिस्से बदलते रहते हैं और यह इस पर निर्भर करता है कि कौन-सा विजेट इस्तेमाल हो रहा है।

लिंक रेफरेंस, यानी `()` के अंदर की सामग्री, को वेबसाइट नज़रअंदाज़ कर देती है। रखरखाव के लिए आप इन्हें जहाँ चाहें वहाँ पॉइंट कर सकते हैं।

## अभ्यास विजेट

लिंक फॉर्मेट: `[exercise:<track-slug>/<exercise-slug>]()`

### उदाहरण

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## कॉन्सेप्ट विजेट

लिंक फॉर्मेट: `[concept:<track-slug>/<concept-slug>]()`

### उदाहरण

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## अप्रोच विजेट

लिंक फॉर्मेट: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### उदाहरण

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## आर्टिकल विजेट

लिंक फॉर्मेट: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### उदाहरण

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
