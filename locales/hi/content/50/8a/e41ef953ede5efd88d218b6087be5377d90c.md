# अधिक जानकारी

Java एक स्टैटिकली-टाइप्ड भाषा है, जिसका अर्थ है कि कंपाइल के समय हर चीज़ का एक टाइप होता है।
किसी नाम को वैल्यू असाइन करना वेरिएबल बनाना कहलाता है।

```java
int explicitVar = 10; // Explicitly typed
```

किसी वेरिएबल की वैल्यू [`=` ऑपरेटर][assignment] से असाइन और अपडेट की जा सकती है।
एक बार वेरिएबल बन जाने के बाद उसका टाइप कभी नहीं बदल सकता।

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java एक ऑब्जेक्ट-ओरिएंटेड भाषा है। इसमें हर फंक्शन को किसी _क्लास_ के अंदर बनाना पड़ता है, और क्लास [`class` कीवर्ड][classes] से बनती है।
किसी क्लास के अंदर बनाए गए फंक्शन को _मेथड_ कहा जाता है।
हर [मेथड][methods] में शून्य या उससे अधिक पैरामीटर हो सकते हैं।
सभी पैरामीटर का टाइप साफ-साफ लिखना ज़रूरी है, पैरामीटर के टाइप का अनुमान नहीं लगाया जाता।
इसी तरह रिटर्न टाइप भी स्पष्ट रूप से लिखना पड़ता है।
फंक्शन से वैल्यू [`return` कीवर्ड][return] की मदद से लौटाई जाती है।
किसी मेथड को दूसरी क्लासों से कॉल करने की अनुमति देने के लिए `public` एक्सेस मॉडिफायर जोड़ना पड़ता है।

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

मेथड को कॉल करने के लिए उसकी क्लास और मेथड का नाम लिखा जाता है और मेथड के हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं।

```java
int sum = new Calculator().add(1, 2);
```

अगर कोई मेथड क्लास की किसी _स्थिति_ का उपयोग नहीं करता (जैसा कि इस अभ्यास में होता है), तो `static` मॉडिफायर लगाकर मेथड को _static_ बनाया जा सकता है।
इसी तरह, अगर किसी क्लास में सिर्फ static मेथड हों, तो उसे भी `static` मॉडिफायर से static बनाया जा सकता है।

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Java में स्कोप `{` और `}` अक्षरों के बीच तय होता है।

Java दो तरह के [कमेंट][comments] का समर्थन करता है।
एकल-पंक्ति कमेंट से पहले `//` लगाया जाता है और बहु-पंक्ति कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

पूर्णांक वैल्यू एक या अधिक (लगातार) अंकों के रूप में लिखी जाती हैं और [सामान्य गणितीय ऑपरेटरों][operators] का समर्थन करती हैं।
