# निर्देश

इस अभ्यास में आप अपने सबसे अच्छे दोस्तों के साथ "Wizard and Warriors" नाम का एक रोल-प्लेइंग गेम खेल रहे हैं। आप गेम मास्टर हैं, यानी वह व्यक्ति जिसका काम खिलाड़ियों के लिए गेम की दुनिया को जीवंत बनाना है। इसका एक खास पहलू यह है कि आप खिलाड़ियों को गेम का वर्णन करते हैं: किसी पात्र की स्थिति क्या है, वे जिस कस्बे में जा रहे हैं वह कैसा दिखता है, इत्यादि।

आपके पास पाँच काम हैं, जिनमें आपको खिलाड़ियों को गेम के अलग-अलग हिस्सों का वर्णन करना है।

## 1. पात्र का वर्णन कीजिए

हर पात्र के पास एक क्लास, एक लेवल और कुछ हिट पॉइंट होते हैं, और उसका वर्णन इस तरह है: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. एक (static) `GameMaster.Describe` मेथड लिखिए, जो अपने एकमात्र पैरामीटर के रूप में एक `Character` लेता है और उसका वर्णन लौटाता है।

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. गंतव्य का वर्णन कीजिए

हर गंतव्य का एक नाम और कुछ निवासी होते हैं, और उसका वर्णन इस तरह है: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. एक (static) `GameMaster.Describe` मेथड लिखिए, जो अपने एकमात्र पैरामीटर के रूप में एक `Destination` लेता है और उसका वर्णन लौटाता है।

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. यात्रा के तरीके का वर्णन कीजिए

पात्र दो तरीकों में से किसी एक से किसी गंतव्य तक यात्रा कर सकते हैं:

- पैदल चलना, जिसका वर्णन इस तरह है: `"You're traveling to your destination by walking."`
- घोड़े पर सवार होकर, जिसका वर्णन इस तरह है: `"You're traveling to your destination on horseback."`

एक (static) `GameMaster.Describe` मेथड लिखिए, जो अपने एकमात्र पैरामीटर के रूप में एक `TravelMethod` लेता है और उसका वर्णन लौटाता है।

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. किसी गंतव्य की ओर यात्रा करते पात्र का वर्णन कीजिए

जब कोई पात्र किसी गंतव्य की ओर यात्रा कर रहा हो, तो उसका वर्णन अलग-अलग वर्णनों को जोड़कर किया जाता है: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. एक (static) `GameMaster.Describe` मेथड लिखिए, जो अपने पैरामीटर के रूप में एक `Character`, एक `Destination` और एक `TravelMethod` लेता है और उसका वर्णन लौटाता है।

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. यात्रा का तरीका बताए बिना किसी गंतव्य की ओर यात्रा करते पात्र का वर्णन कीजिए

अधिकतर मामलों में पात्र पैदल ही किसी गंतव्य की ओर यात्रा करते हैं। सुविधा के लिए खिलाड़ी चाहें तो अपना यात्रा तरीका बताना छोड़ सकते हैं, और ऐसा करने पर पैदल यात्रा ही मान ली जाती है। एक (static) `GameMaster.Describe` मेथड लिखिए, जो अपने पैरामीटर के रूप में एक `Character` और एक `Destination` लेता है और उसका वर्णन लौटाता है।

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
