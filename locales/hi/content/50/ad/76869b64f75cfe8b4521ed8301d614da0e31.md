# परिचय

जैसा कि [`Nothingness`][concept-nothingness] कॉन्सेप्ट में बताया गया है, R में अनुपस्थित (`NULL`), अज्ञात (`NA`) या गणितीय रूप से अमान्य (`NaN`, `Inf`) डेटा को दर्शाने के कई तरीके हैं।
आम तौर पर R इनका उपयोग इन समस्याओं को वहीं चिह्नित करने के लिए करता है और बिना कोई एक्सेप्शन उठाए आगे बढ़ता रहता है।

## `stop()`

कुछ समस्याएँ इतनी बुनियादी होती हैं कि प्रोग्राम को आगे बढ़ने नहीं दिया जा सकता।
ऐसी स्थिति में `stop(msg)` का उपयोग कीजिए, जो प्रोग्राम को तुरंत एक `Error` के साथ रोक देता है और `msg` प्रिंट करता है।

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

अन्य भाषाओं के `assert` की तरह यह `stop()` के लिए एक सुविधाजनक रैपर है।
इसके पैरामीटर कॉमा से अलग की गई कितनी भी बूलियन शर्तें हो सकती हैं, और प्रोग्राम तभी आगे बढ़ेगा जब ये सभी `TRUE` हों।

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()` और `message()`

ये गैर-घातक स्थितियों के प्रति प्रतिक्रियाएँ हैं, जैसे:

- किसी ऐसी समस्या की चेतावनी देना जिससे प्रोग्राम कम से कम आंशिक रूप से उबर सके।
- किसी लंबे समय तक चलने वाले प्रोग्राम की प्रगति के बारे में उपयोगकर्ता को बताना।

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

Exercism के भीतर `suppressWarnings()` फंक्शन कभी-कभी उपयोगी हो सकता है, ताकि अनचाहे आउटपुट से टेस्ट रनर को भ्रमित न किया जाए।
