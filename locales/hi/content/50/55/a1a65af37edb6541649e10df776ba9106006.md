# टेस्ट

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
make
```

## छोड़े गए टेस्ट

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना।
आम तौर पर जब आप टेस्ट चलाते हैं, तो सिर्फ एक टेस्ट (पहला वाला) चलता है।
यह जानबूझकर ऐसा है, ताकि आप पूरा ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर लगा सकें।
जैसे ही वह पास हो जाए, आप `TEST_IGNORE()` लाइन हटाकर अगला टेस्ट चालू कर सकते हैं।
जब सारे टेस्ट चालू हो जाएँ और आपका कोड उन सबको पास करा दे, तब समझिए कि आपने अभ्यास हल कर लिया!

## डीबगिंग

डीबगिंग में मदद के लिए `debug.mac` फाइल में कई मैक्रो परिभाषित हैं।
इन्हें सही आकार के एक या अधिक आर्गुमेंट के साथ कॉल किया जा सकता है।
उदाहरण:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

इनमें से कोई भी मैक्रो इस्तेमाल करने के लिए `debug.mac` को हल वाली फाइल के सबसे ऊपर शामिल करना ज़रूरी है:

```x86asm
%include "debug.mac"
```
