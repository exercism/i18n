# इसके बारे में

लोकल स्टैक कोड की जगह नहीं लेते, वे उसके साथ ही रहते हैं। इन्हें तब इस्तेमाल कीजिए जब:

- एक ही इनपुट को एक से अधिक बार संदर्भित किया जाता है।
- ऑपरेशनों का स्वाभाविक क्रम स्टैक के क्रम से मेल नहीं खाता।
- आप किसी हायर-ऑर्डर वर्ड के अंदर हैं जो लैम्ब्डा को एक साथ कई वैल्यू देता है (`assoc-map` का `( key value -- newkey newvalue )`)।

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` किसी कोटेशन के अंदर या लिसनर पर लोकल बाइंडिंग बनाता है, जहाँ अन्यथा `:>` के पास बाइंड करने के लिए कोई लेक्सिकल स्कोप नहीं होता:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

`:>` म्यूटेशन प्रत्यय आपको किसी लोकल को फिर से बाइंड करने देता है, जो इम्परेटिव अंदाज़ वाले लूपों में काम आता है:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
