# विवरण

जिन वेरिएबलो को `var` की जगह `final` कीवर्ड से घोषित किया जाता है, उन्हें सिर्फ एक ही बार वैल्यू असाइन की जा सकती है।

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

ध्यान रखिए कि ऐरे या ऑब्जेक्ट जैसे बदले जा सकने वाले डेटा टाइपों के साथ `final` का असर वैसा नहीं हो सकता जैसा हम उम्मीद करते हैं:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
