# परिचय

याद कीजिए कि `jq` प्रोग्राम _एक्सप्रेशन की एक पाइपलाइन_ होता है।
**वेरिएबल असाइनमेंट** इस नियम का पालन करता है: _वेरिएबल असाइनमेंट_ एक ऐसा एक्सप्रेशन होता है जो इस तरह दिखता है:

```jq
... | expr as $varname | ...
```

## फिल्टर इनपुट को ही आउटपुट देता है

_आइडेंटिटी एक्सप्रेशन_ `.` की तरह, _वेरिएबल असाइनमेंट_ का आउटपुट भी उसके इनपुट जैसा ही होता है।
वेरिएबल की वैल्यू सेट करना एक साइड इफेक्ट है।

यह उदाहरण दिखाता है कि असाइनमेंट के बाद भी `.` का मान शुरुआती इनपुट जैसा ही रहता है:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## वेरिएबल का स्कोप

वेरिएबल का स्कोप "लेक्सिकल" होता है, यानी पाइपलाइन के बाकी हिस्से में यह वेरिएबल इस्तेमाल किया जा सकता है।
फंक्शन के अंदर बनाए गए वेरिएबल (फंक्शन पर बात हम आगे करेंगे) उस फंक्शन के अंदर ही सीमित रहते हैं।

## वेरिएबल के नाम

वेरिएबल का नाम `$` से शुरू होना चाहिए।
नाम का बाकी हिस्सा एक **आइडेंटिफायर** होता है: यह किसी अक्षर या अंडरस्कोर से शुरू होता है, और उसके बाद अक्षर, संख्याएँ या अंडरस्कोर आ सकते हैं।

## डिस्ट्रक्चरिंग असाइनमेंट

मैनुअल में लिखा है:

> एक ही `as` एक्सप्रेशन से कई वेरिएबल घोषित किए जा सकते हैं, अगर आप ऐसा पैटर्न दें जो _इनपुट के ढाँचे से मेल खाता हो_ (इसे "डिस्ट्रक्चरिंग" कहते हैं)।

उदाहरण:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

वेरिएबल का नाम _ऑब्जेक्ट की_ के अनुसार रखने से एक शॉर्टकट मिल जाता है:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## स्थिरांक

जैसा ऊपर के उदाहरण में दिखा, स्थिरांक संग्रहीत करने के लिए वेरिएबल काम आते हैं।
बेहतर यह है कि स्थिरांक को कोई नाम दे दें, बजाय इसके कि कोड में "मैजिक नंबर" दिखने लगें।

## अक्सर वेरिएबल की ज़रूरत नहीं पड़ती

अक्सर वेरिएबल छोड़ देने से कोड पढ़ने में ज़्यादा आसान हो जाता है।

मान लीजिए, आपको संख्याओं के एक ऐरे का औसत निकालना है:

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

इसकी तुलना में:

```jq
[2, 4, 8, 7] | add / length
```

यह `jq` की सबसे शक्तिशाली बातों में से एक को सामने रखता है: किसी फिल्टर को मिलने वाला इनपुट _हर_ सब-एक्सप्रेशन को दिया जाता है:

- इनपुट ऐरे `[2,4,8,7]` को `add` को भेजा जाता है (जो सभी एलिमेंट पर `+` ऑपरेटर लगाकर संख्याओं का जोड़ निकालता है)
- _साथ ही_, `[2,4,8,7]` को `length` को भी भेजा जाता है
- जब ये सब-एक्सप्रेशन पूरे हो जाते हैं, तो उनके परिणामों को आपस में भाग दिया जाता है, और इनपुट ऐरे की संख्याओं का औसत मिल जाता है।
