# इंस्टॉलेशन

## मेरे पास कौन-सा awk है?

Exercism के AWK ट्रैक में `gawk` इस्तेमाल होता है, जो GNU का AWK है।
हो सकता है यह आपके पास पहले से हो। जाँचने के लिए यह कमांड चलाइए
```sh
awk --version
```

अगर इसका नतीजा ऐसा आए:

* कुछ ऐसा: `GNU Awk 5.1.0 ...`
    - आपके पास पहले से GNU awk है और आप अभ्यास करते रह सकते हैं।

* कुछ ऐसा: `awk version 20200816`
    - यह `nawk` है, जिसे BWK awk (ब्रायन कर्निघन के नाम पर) या "one true awk" भी कहा जाता है।
    - यह MacOS और BSD सिस्टमों के साथ आता है।
    - इंस्टॉलेशन के निर्देश नीचे पढ़िए।

* यह एरर: `awk: not an option: --version`
    - आपके पास शायद `mawk` है।
    - पक्का करने के लिए यह चलाइए: `awk -W version`, जो शायद `mawk 1.3.4 20200120` देता है।
    - mawk एक बहुत अच्छा और तेज़ awk इम्प्लीमेंटेशन है, लेकिन इसमें gawk की कुछ खास सुविधाएँ नहीं हैं, जिनका इस्तेमाल हम इस ट्रैक में करेंगे।
    - इंस्टॉलेशन के निर्देश नीचे पढ़िए।

* यह एरर: `awk: unrecognized option: version`, और उसके बाद `BusyBox v1.35.0 ...`
    - हो सकता है आप Alpine Linux इस्तेमाल कर रहे हों।
    - इंस्टॉलेशन के निर्देश नीचे पढ़िए।

* यह एरर: "command not found"
    - तो या तो आपका PATH गड़बड़ है, या awk आपके सिस्टम पर इंस्टॉल ही नहीं है।
    - इंस्टॉलेशन के निर्देश नीचे पढ़िए।

### Linux

यह आपके डिस्ट्रो के पैकेज मैनेजर पर निर्भर करता है। आम तौर पर:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
उचित कमांड चलाने के लिए आपको `sudo` इस्तेमाल करना पड़ सकता है।

### MacOS

[Homebrew][brew] आपका दोस्त है। इसे इंस्टॉल करने के लिए लिंक पर जाइए और फिर यह चलाइए:
```sh
brew install gawk
```

### Windows

[WSL][wsl] के लिए ऊपर दिए गए Linux वाले निर्देश देखिए।
cygwin के लिए `gawk` पैकेज इंस्टॉल कीजिए।

### सोर्स से कंपाइल कीजिए

हिम्मत वालों के लिए, निर्देश [`gawk` मैनुअल में उपलब्ध][build] हैं।
