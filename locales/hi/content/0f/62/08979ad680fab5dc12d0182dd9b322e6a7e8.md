# निर्देश परिशिष्ट

## इनपुट प्रारूप

`board` पैरामीटर, जो खेल के बोर्ड को दर्शाता है, स्ट्रिंग के ऐरे के रूप में होता है।

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

स्ट्रिंग का हर अक्षर एक सेल को दर्शाता है।
किसी सेल के लिए मान्य वैल्यू ये हैं:

- ` ` एक स्पेस, जो एक खाली सेल को दर्शाता है
- `B` वह सेल जो काले खिलाड़ी के पास है
- `W` वह सेल जो सफेद खिलाड़ी के पास है

## आउटपुट प्रारूप

`getTerritory` फंक्शन से अपेक्षा है कि वह 2 प्रॉपर्टी वाला एक ऑब्जेक्ट लौटाए:

- `owner` क्षेत्र का मालिक (`NONE`, `BLACK` या `WHITE`)
- `territory` क्षेत्र के हर सेल को दर्शाने वाले निर्देशांकों का ऐरे।

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

`getTerritories` फंक्शन से अपेक्षा है कि वह 3 प्रॉपर्टी वाला एक ऑब्जेक्ट लौटाए:

- `territoryBlack` `BLACK` खिलाड़ी के पास मौजूद क्षेत्रों को दर्शाने वाले निर्देशांकों का ऐरे
- `territoryWhite` `WHITE` खिलाड़ी के पास मौजूद क्षेत्रों को दर्शाने वाले निर्देशांकों का ऐरे
- `territoryNone` किसी भी खिलाड़ी के पास न होने वाले क्षेत्रों को दर्शाने वाले निर्देशांकों का ऐरे

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
