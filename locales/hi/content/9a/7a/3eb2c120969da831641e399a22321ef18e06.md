# विस्तृत जानकारी

## `for` लूप

एक `for` स्टेटमेंट कोड के एक ब्लॉक को बार-बार चलाता है।
इसकी पहली लाइन तय करती है कि ब्लॉक कितनी बार दोहराया जाए:

```go
for init; condition; post {
    // loop body
}
```

- **इनिट** स्टेटमेंट पहले इटरेशन से पहले सिर्फ एक बार चलता है। लूप में इस्तेमाल होने वाले काउंटर वेरिएबल को घोषित करना और इनिशियलाइज़ करना आम बात है।
- **शर्त** एक बूलियन एक्सप्रेशन है जिसे हर इटरेशन से पहले जाँचा जाता है। जब इसका परिणाम `false` होता है, तो लूप रुक जाता है।
- **पोस्ट** स्टेटमेंट हर पूरे इटरेशन के बाद चलता है। इसका इस्तेमाल काउंटर को अपडेट करने के लिए किया जा सकता है।

`init; condition; post` के चारों ओर गोल ब्रैकेट न लगाइए।
लेकिन लूप के अंदर के कोड को घेरने वाले घुंघराले ब्रैकेट `{ }` हमेशा ज़रूरी होते हैं।

यह लूप `i` को `1` से शुरू करता है, `i` की मौजूदा वैल्यू प्रिंट करता है, अगले इटरेशन के लिए उसे बढ़ाता है, और तब रुक जाता है जब `i` `10` तक पहुँच जाता है:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## लूप के अन्य रूप

### सिर्फ शर्त वाला लूप

इनिट और पोस्ट स्टेटमेंट छोड़े जा सकते हैं।
सिर्फ शर्त वाला `for` स्टेटमेंट दूसरी भाषाओं के `while` लूप जैसा ही काम करता है।
Go में `while` नाम का कोई कीवर्ड नहीं है।

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### अनंत लूप

`for` स्टेटमेंट बिना शर्त के भी लिखा जा सकता है:

```go
for {
    // loop body
}
```

यह लूप अपने आप खत्म नहीं होता।
लूप से बाहर निकलने के लिए स्पष्ट रूप से कुछ करना पड़ता है, जैसे `break` या `return` का इस्तेमाल करना।

## लूप को नियंत्रित करना

### `break` और `continue`

इस लूप में `break` लूप से बाहर निकाल देता है:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` मौजूदा लूप के अंदर के बाकी कोड को छोड़ देता है और अगला इटरेशन शुरू कर देता है:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### लेबल वाले `break` और `continue`

नेस्टेड लूप में बिना लेबल वाला `break` या `continue` सबसे अंदर वाले लूप पर लागू होता है।
किसी बाहरी लूप को लेबल देने के लिए उसकी ठीक ऊपर वाली लाइन पर एक आइडेंटिफायर और उसके बाद कोलन लिखिए।
फिर उस लूप का लेबल `break` या `continue` के बाद लिखिए, ताकि यह कार्रवाई उसी लूप पर लागू हो:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
