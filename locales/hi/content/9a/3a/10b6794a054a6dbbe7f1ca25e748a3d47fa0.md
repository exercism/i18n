# इस बारे में

डिफ़ॉल्ट रूप से वेरिएबल उसी स्कोप तक सीमित रहते हैं जिसमें उन्हें बनाया जाता है। अगर किसी वेरिएबल को किसी फंक्शन या क्लास के बाहर किसी फाइल में बनाया जाए, तो वह उस फाइल के स्कोप तक सीमित रहता है। और अगर उसे किसी फंक्शन या क्लास के अंदर बनाया जाए, तो वह उस फंक्शन या क्लास के स्कोप तक सीमित रहता है।

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## ग्लोबल स्कोप

किसी वेरिएबल को असाइन करने से पहले `global` कीवर्ड लगाने से ग्लोबल स्कोप वाला वेरिएबल बनता है। इस तरीके को अक्सर हतोत्साहित किया जाता है, क्योंकि इससे [आपस में कसकर जुड़ा कोड](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>) बन जाता है।

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## स्टैटिक स्कोप

किसी वेरिएबल को असाइन करने या घोषित करने से पहले `static` कीवर्ड लगाने पर वेरिएबल का स्कोप तो वही रहता है, लेकिन उसकी वैल्यू अलग-अलग निष्पादन स्कोप के बीच भी बनी रहती है।

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

इस उदाहरण में `$count` वेरिएबल को 0 से इनिशियलाइज़ किया जाता है, वह भी _सिर्फ पहली बार फंक्शन कॉल करने पर_। इसके बाद की हर कॉल में यह वैल्यू अगली कॉल तक पहुँच जाती है। इसलिए फंक्शन को जितनी भी बार कॉल किया जाए, हर बार वह एक बढ़ता हुआ पूर्णांक लौटाता है।
