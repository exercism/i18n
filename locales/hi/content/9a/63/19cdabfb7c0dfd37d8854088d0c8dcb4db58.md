# परिचय

किसी मेथड के पैरामीटर को डिफ़ॉल्ट वैल्यू असाइन करके वैकल्पिक बनाया जा सकता है। जब कोई पैरामीटर वैकल्पिक होता है, तो कॉलर को उस पैरामीटर के लिए आर्गुमेंट देना ज़रूरी नहीं होता। ऐसी स्थिति में डिफ़ॉल्ट वैल्यू का इस्तेमाल किया जाता है। [वैकल्पिक पैरामीटर][optional-arguments] _अवश्य_ पैरामीटर लिस्ट के अंत में होने चाहिए। उनके बाद गैर-वैकल्पिक पैरामीटर नहीं हो सकते। यदि किसी मेथड में कई वैकल्पिक पैरामीटर हों, तो आप [नामित आर्गुमेंट][named-arguments] का इस्तेमाल करके उनमें से कुछ ही निर्दिष्ट कर सकते हैं।

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

एक वैकल्पिक पैरामीटर की वैल्यू निम्न में से एक होनी चाहिए:

- एक कॉन्स्टेंट एक्सप्रेशन (जैसे `"hi"`, `2`, `DayOfWeek.Friday`, `null` आदि)
- वैल्यू टाइप का एक `new` एक्सप्रेशन
- वैल्यू टाइप का एक `default` एक्सप्रेशन

[named-arguments]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#named-arguments
