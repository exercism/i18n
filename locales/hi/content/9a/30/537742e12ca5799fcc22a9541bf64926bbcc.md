# निर्देश परिशिष्ट

## आरक्षित मेमोरी

इनपुट स्ट्रिंग का बफर लीनियर मेमोरी के बाइट 64 से 191 तक इस्तेमाल करता है।


## आउटपुट फॉर्मेट

अपेक्षित है कि संख्याओं की श्रृंखला u8 संख्याओं का एक सतत ऐरे हो; डीसीरियलाइज़ेशन के समय इस ऐरे को लंबाई के अनुसार टुकड़ों में बाँटा जाएगा:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
