# निर्देश

आपके पास के एक स्थानीय स्कूल में छात्रों का संघ बहुत सक्रिय है।
इस छात्र संघ का संचालन एक अध्यक्ष करता है, और हर 2 साल में एक बार नया अध्यक्ष चुनने के लिए चुनाव कराए जाते हैं।

इस साल के चुनाव में यह तय हुआ कि वोट गिनने के लिए एक नया डिजिटल सिस्टम चाहिए। स्कूल को यह नया सिस्टम बनाने में आपकी मदद चाहिए।

## 1. एक `ElectionResult` से वोटों की संख्या प्राप्त कीजिए

नए सिस्टम को किसी काउंटर से वोटों की संख्या निकालने का तरीका चाहिए।

चुनाव परिणाम वाला स्ट्रक्चर आपके लिए पहले ही बना दिया गया है और इसे ऐसे परिभाषित किया गया है:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

चूँकि `struct` के सारे मेंबर public हैं, इसलिए `ElectionResult` ऑब्जेक्ट को इनिशियलाइज़ करने के लिए आपको `constructor` लिखने की ज़रूरत नहीं है।
इसके बजाय आप `initializer list` इस्तेमाल कर सकते हैं:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

एक फंक्शन `vote_count` बनाइए जो आर्गुमेंट के तौर पर एक `ElectionResult` का रेफरेंस लेता है और `ElectionResult` में मौजूद वोटों की संख्या लौटाता है।

```cpp
vote_count(hamilton);
// => 1804
```

## 2. एक `ElectionResult` के वोट बढ़ाइए

अब वोटों को प्रोसेस करने का समय आ गया है!
अब आपको `ElectionResult` के वोट बढ़ाने का तरीका चाहिए।

एक `void` फंक्शन `increment_vote_count` बनाइए, जो एक `ElectionResult` का रेफरेंस और वोटों की एक संख्या आर्गुमेंट के तौर पर लेगा और `ElectionResult` को उतने वोटों से बढ़ा देगा।

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. वोटों की गिनती और अध्यक्षता

स्कूल ने अपने वोट जमा कर दिए हैं, और अब परिणाम देखकर यह पता लगाने का समय है कि विजेता कौन है।

एक फंक्शन `determine_result` बनाइए जो अंतिम गिनती का रेफरेंस लेता है और नए अध्यक्ष के `ElectionResult` का रेफरेंस लौटाता है।
इसे विजेता के नाम के आगे "President" जोड़कर उसका नाम भी बदलना चाहिए।
अंतिम गिनती `std::vector<ElectionResult>` के `reference` के रूप में दी जाती है। इस वेक्टर में सभी भाग लेने वाले उम्मीदवारों के `ElectionResults` होते हैं।

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

चीज़ों को आसान रखने के लिए आप यह मान सकते हैं:
- `vector` में कम से कम एक एलिमेंट होगा।
- पहले स्थान के लिए कोई बराबरी नहीं होगी।
