# निर्देश

आप एक उत्साही पक्षी-निरीक्षक हैं और यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए।

आपके सामने छह कार्य हैं, और सब आपके बगीचे में आए पक्षियों की संख्याओं से जुड़े हैं।

## 1. देखिए कि पिछले सप्ताह की गिनतियाँ क्या थीं

तुलना के लिए आप पिछले सप्ताह की गिनतियों की एक प्रति हमेशा पास रखते हैं, जो ये थीं: 0, 2, 5, 3, 7, 8 और 4। `lastWeek` बाइंडिंग बनाइए जिसमें पिछले सप्ताह की गिनतियाँ हों:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. देखिए कि कल कितने पक्षी आए

`yesterday` फंक्शन बनाइए जो लौटाए कि कल आपके बगीचे में कितने पक्षी आए थे। पक्षियों की गिनतियाँ दिन के क्रम में लगी हैं: पहला एलिमेंट सबसे पुराने दिन की गिनती है और अंतिम एलिमेंट आज की गिनती।

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. आए कुल पक्षियों की संख्या निकालिए

`total` फंक्शन बनाइए जो लौटाए कि आपके बगीचे में कुल कितने पक्षी आए हैं:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. देखिए कि कोई ऐसा दिन था या नहीं जब एक भी पक्षी नहीं आया

`dayWithoutBirds` फंक्शन बनाइए जो `true` लौटाता है अगर कोई ऐसा दिन था जब बगीचे में शून्य पक्षी आए; वरना `false` लौटाइए:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. आज की गिनती बढ़ाइए

`incrementTodaysCount` फंक्शन बनाइए जो आज की गिनती बढ़ाए और अपडेट की गई गिनतियाँ लौटाए:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. असामान्य सप्ताह की जाँच कीजिए

पिछले एक साल में आपने पाया है कि कुछ सप्ताहों में एक जैसे असामान्य पैटर्न होते हैं:
- सप्ताह के हर सम दिन कोई पक्षी नहीं आया
- सप्ताह के हर सम दिन ठीक 10 पक्षी दिखे
- सप्ताह के हर विषम दिन ठीक 5 पक्षी दिखे

`unusualWeek` फंक्शन बनाइए जो `true` लौटाता है अगर इस सप्ताह का पक्षी-गिनती पैटर्न इनमें से किसी एक असामान्य पैटर्न से मेल खाता है:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(ध्यान दीजिए कि दिनों की समता का इंडेक्स 1 से शुरू होता है, 0 से नहीं, यानी ऐरे का पहला एलिमेंट विषम दिन के साथ जुड़ा है)
