# परिचय

`Option` टाइप F# भाषा का वह तरीका है जिससे ऐसी वैल्यूएँ संभाली जाती हैं जो हो भी सकती हैं और नहीं भी। यह `null` के इस्तेमाल का एक टाइप-सेफ विकल्प देता है। दूसरी भाषाओं में ऐसी वैल्यूएँ संभालने के लिए `null` का इस्तेमाल आम है। F# की कई स्टैंडर्ड लाइब्रेरी फंक्शनों में इसका उपयोग होता है, इसलिए F# की स्टैंडर्ड लाइब्रेरी का अच्छा उपयोग करने के लिए इसे समझना ज़रूरी है।

## उपयोग 

`Option` टाइप एक जेनेरिक टाइप है (जो किसी दूसरे टाइप पर आधारित होता है)।  
`Option` वैल्यू दो तरह की होती हैं: `Some value`, जो कोई खास वैल्यू दर्शाती है, या `None`, जो यह दर्शाती है कि कोई वैल्यू नहीं है।

नीचे दिया गया फंक्शन दिखाता है कि `Option` वैल्यू कैसे बनाई जाती है:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`, `Option<T>` का पोस्टफिक्स सिंटैक्स में बराबर रूप है; दोनों सिंटैक्स रूपों का इस्तेमाल एक-दूसरे की जगह किया जा सकता है।
लेकिन F# Style Guide के मुताबिक, Option टाइपों के लिए पोस्टफिक्स नोटेशन को प्राथमिकता दी जाती है (देखें [टाइपों की फॉर्मैटिंग और टाइप एनोटेशन पर F# Style Guide का सेक्शन](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions))। 
~~~~

## `Option` वैल्यू के अंदर की वैल्यू पढ़ना

`Option` वैल्यू पढ़ने का स्वाभाविक तरीका पैटर्न मैचिंग है, जैसा कि नीचे दिए गए उदाहरण में दिखाया गया है:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## डिफॉल्ट वैल्यू के साथ Option को अनरैप करना

`Option` को डिफॉल्ट वैल्यू देकर "अनरैप" किया जा सकता है, यानी उसे उसके अंदर वाले टाइप में बदला जा सकता है। इसके लिए `Option.defaultValue` फंक्शन का उपयोग किया जाता है। 
यह खास तौर पर तब काम आता है जब आप यह पक्का करना चाहते हैं कि वैल्यू `None` न हो।
उदाहरण के लिए:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
