# परिचय

## फंक्शन एक्सपोर्ट करना

फंक्शन एक्सपोर्ट करना पहले कॉन्सेप्ट में बताया जा चुका है। यहाँ उसका एक छोटा-सा दोहराव है।

Elm में हर फाइल एक मॉड्यूल है और उसमें बाकी सारे कोड से पहले एक `module` स्टेटमेंट होना ज़रूरी है।

मॉड्यूल के नाम उसकी फाइल के नाम से मेल खाने चाहिए, इसलिए `Calculator` मॉड्यूल Calculator.elm फाइल में होना चाहिए, और `Parser.Utils` मॉड्यूल Parser/Utils.elm फाइल में।

मॉड्यूल के अंदर बनाई गई कोई भी चीज़ उसी तक सीमित रहती है। जब तक उसे `exposing` में न लिखा जाए, उस मॉड्यूल के बाहर से उसका इस्तेमाल नहीं किया जा सकता।

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## दूसरे मॉड्यूल से फंक्शन इम्पोर्ट करना

दूसरे मॉड्यूल में बनाए गए फंक्शन इम्पोर्ट के ज़रिए इस्तेमाल किए जाते हैं।
जब आप उस मॉड्यूल को इम्पोर्ट करते हैं, तो उसके अंदर के वे सारे फंक्शन उपलब्ध हो जाते हैं जिन्हें उस मॉड्यूल ने एक्सपोर्ट किया था।
लेकिन उन तक पहुँचने का तरीका इस पर निर्भर करता है कि मॉड्यूल कैसे इम्पोर्ट किया गया है।

क्वालिफाइड इम्पोर्ट डिफ़ॉल्ट होते हैं। ऐसे मॉड्यूल के किसी फंक्शन (जैसे `List` मॉड्यूल का `map` फंक्शन) का इस्तेमाल करने के लिए उसके आगे मॉड्यूल का नाम लगाया जाता है (`List.map`)।

ओपन इम्पोर्ट उस मॉड्यूल के एक्सपोर्ट किए गए फंक्शनों तक सीधी पहुँच देते हैं, बिना नाम आगे लगाए। ये `exposing` कीवर्ड से किए जाते हैं, ठीक उस कीवर्ड की तरह जो एक्सपोर्ट में इस्तेमाल होता है। आप सभी उपलब्ध फंक्शन एक्सपोर्ट कर सकते हैं (`..` के साथ), या सिर्फ कुछ खास फंक्शन (जैसे `map`)।

आप दूसरे मॉड्यूल से टाइप और उनके कंस्ट्रक्टर भी इम्पोर्ट कर सकते हैं, जो आगे के कॉन्सेप्ट में आएगा।

स्पष्टता बनाए रखने और नामों के टकराव से बचने के लिए क्वालिफाइड इम्पोर्ट को प्राथमिकता दी जाती है।

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## टाइप एनोटेशन

टाइप एनोटेशन `name : parameter types -> return type` के रूप में लिखे जाते हैं; पैरामीटर के टाइप भी `->` से अलग किए जाते हैं।

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

फंक्शन के पैरामीटर लिखने के लिए कोष्ठकों का इस्तेमाल किया जा सकता है (ये पैरामीटर खुद भी इसी सिंटैक्स से लिखे जाते हैं, इसीलिए कोष्ठकों की ज़रूरत पड़ती है)।

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## संख्याएँ

Elm में दो तरह की संख्याएँ उपलब्ध हैं, जिन्हें `Int` और `Float` टाइप परिभाषित करते हैं।
`Int` धनात्मक और ऋणात्मक पूर्णांकों के समूह को दर्शाता है।
`Float` वास्तविक संख्याओं के समूह को दर्शाता है, जो कंप्यूटर की सटीकता से सीमित होता है।
संख्याओं पर लिखे ऑपरेशन आमतौर पर किसी एक ही टाइप पर काम करते हैं, दोनों को मिलाकर नहीं।
दोनों के बीच बदलने के लिए फंक्शन मौजूद हैं, जैसे `toFloat`, जो `Int` को `Float` में बदलता है, और `round`, `floor`, `ceiling` या `truncate`, जो एक `Float` को `Int` में बदलते हैं, पर हर एक का व्यवहार अलग होता है।

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## स्ट्रिंग ऑपरेशन

कोड में शब्दों और वाक्यों को लिखने के लिए Elm में अपना एक `String` टाइप होता है।
स्ट्रिंग लिटरल दोहरे उद्धरण चिह्नों के बीच लिखे जाते हैं, जैसे `"Hello World!"`।
स्ट्रिंग जोड़ने वाला ऑपरेटर `++` और बराबरी जाँचने वाला ऑपरेटर `==` डिफ़ॉल्ट रूप से उपलब्ध हैं।

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

बाकी ज़्यादातर स्ट्रिंग फंक्शन `String` मॉड्यूल में हैं, जिसे इम्पोर्ट करना पड़ता है।

https://package.elm-lang.org/packages/elm/core/latest/String
