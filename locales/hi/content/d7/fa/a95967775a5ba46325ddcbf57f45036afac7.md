# परिचय

Cairo में टाइप कन्वर्ज़न की मदद से आप डेटा को एक टाइप से दूसरे टाइप में बदल सकते हैं, जिससे डेटा को लचीले और सुरक्षित ढंग से संभालना संभव हो जाता है।

## बुनियादी बातें

Cairo में टाइप कन्वर्ज़न के लिए कई तरीके मौजूद हैं:

### सीधा कास्टिंग

जो संख्यात्मक टाइप आपस में मेल खाते हैं, उनके लिए आप सीधा कास्टिंग इस्तेमाल कर सकते हैं:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Into ट्रैट

`Into` ट्रैट एक टाइप से दूसरे टाइप में बदलने की सुविधा देता है:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### TryInto ट्रैट

जो कन्वर्ज़न असफल भी हो सकते हैं, उनके लिए `TryInto` इस्तेमाल कीजिए, जो एक `Option` लौटाता है:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## कस्टम टाइप कन्वर्ज़न

आप अपने खुद के टाइपों के लिए `Into` लागू कर सकते हैं:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## सुरक्षा से जुड़ी बातें

- जब कन्वर्ज़न असफल हो सकता हो (जैसे बड़े टाइप से छोटे टाइप में), तब `TryInto` इस्तेमाल कीजिए
- जब कन्वर्ज़न हमेशा सफल होता हो, तब `Into` इस्तेमाल कीजिए
- `TryInto` से मिलने वाले `Option::None` वाले मामलों को हमेशा संभालिए
- साइन वाले और बिना साइन वाले टाइपों के बीच कन्वर्ज़न करते समय ओवरफ्लो और अंडरफ्लो का ध्यान रखिए
