# परिचय

`LocalDate` और `LocalDateTime` जैसी क्लास समय के एक _बिंदु_ को दर्शाती हैं।
`java.time` पैकेज में दो ऐसी क्लास भी हैं जो समय की एक _मात्रा_ बताती हैं:

- `java.time.Period` साल, महीनों और दिनों में समय की मात्रा है, जैसे "2 महीने और 5 दिन"।
- `java.time.Duration` घंटों, मिनटों, सेकंडों, मिलीसेकंडों और नैनोसेकंडों में समय की मात्रा है, जैसे "1 घंटा और 30 मिनट"।

`Period` कैलेंडर का अनुसरण करता है, इसलिए इसका उपयोग तारीखों और तारीख-समय के साथ किया जाता है।
`Duration` सटीक समय नापता है, इसलिए इसका उपयोग समय और तारीख-समय के साथ होता है, तारीखों के साथ नहीं।

```exercism/note
`java.time` की दूसरी क्लास की तरह `Period` और `Duration` भी अपरिवर्तनीय हैं।
जो मेथड उन्हें बदलते दिखते हैं, वे असल में एक _नया_ इंस्टेंस लौटाते हैं।
```

## `Period`

`Period` को उसके किसी एक स्टैटिक फैक्टरी मेथड से बनाया जाता है:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()` का परिणाम [ISO-8601][iso-8601-durations] संकेतन का उपयोग करता है: `P` ("period" के लिए), उसके बाद सालों (`Y`), महीनों (`M`) और दिनों (`D`) की संख्या।

किसी तारीख में एक `Period` जोड़ा या घटाया जा सकता है:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

महीनों की लंबाई अलग-अलग होती है, इसलिए महीने जोड़ने पर कभी-कभी ऐसा दिन आ सकता है जिसका अस्तित्व ही नहीं है।
ऐसी स्थिति में परिणाम को उस महीने के अंतिम वैध दिन पर ले जाया जाता है:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` एक तारीख (वह भी शामिल) से दूसरी तारीख तक (वह शामिल नहीं) का `Period` लौटाता है:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## `ChronoUnit` से इकाइयाँ गिनना

`Period` अपने साल, महीने और दिन अलग-अलग रखता है।
इसलिए `getDays()` दिनों का केवल वह _हिस्सा_ लौटाता है जो `Period` में है, दिनों की कुल संख्या नहीं।
दो तारीखों के बीच किसी एक इकाई की कुल संख्या गिनने के लिए [`java.time.temporal.ChronoUnit`][chronounit-docs] का `between()` मेथड इस्तेमाल कीजिए:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

जब दूसरी तारीख पहली से पहले हो, तो परिणाम ऋणात्मक होता है:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration` भी स्टैटिक फैक्टरी मेथड से बनाया जाता है:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601 संकेतन में `T` तारीख वाले हिस्से को समय वाले हिस्से से अलग करता है, इसी कारण ड्यूरेशन `PT...` के रूप में लिखे जाते हैं।

किसी तारीख-समय में एक `Duration` जोड़ा या घटाया जा सकता है:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` दो तारीख-समय के बीच का सटीक समय लौटाता है:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

किसी ड्यूरेशन को `toHours()`, `toMinutes()` और `toSeconds()` जैसे मेथड से एक ही इकाई में बदला जा सकता है।
ये उस इकाई में _कुल_ मात्रा लौटाते हैं, जिसे नीचे की ओर पूर्णांकित किया गया होता है:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

किसी ड्यूरेशन को घड़ी की तरह उसके हिस्सों में बाँटने के लिए इसके बजाय `toXxxPart()` मेथड इस्तेमाल कीजिए:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
