# निर्देश

इस अभ्यास में आपको 1980 के दशक के क्लासिक आर्केड गेम [Pac-Man][Pac-Man] के कुछ नियम लागू करने हैं।

आपको चार नियम लागू करने हैं, और ये सभी गेम की स्थितियों से जुड़े हैं।

> _इस बात की चिंता न कीजिए कि आर्गुमेंट कहाँ से आते हैं, बस आर्गुमेंट को मिलाकर अपेक्षित परिणाम लौटाने पर ध्यान दीजिए।_

## 1. तय कीजिए कि Pac-Man भूत खाता है या नहीं

`eat_ghost()` फंक्शन बनाइए जो दो पैरामीटर लेता है (_Pac-Man के पास पावर पेलेट सक्रिय है या नहीं_ और _Pac-Man भूत को छू रहा है या नहीं_) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man भूत खा सकता है या नहीं। फंक्शन को `True` तभी लौटाना चाहिए जब Pac-Man के पास पावर पेलेट सक्रिय हो और वह भूत को छू रहा हो।

```python
>>> eat_ghost(False, True)
...
False
```

## 2. तय कीजिए कि Pac-Man को अंक मिलते हैं या नहीं

`score()` फंक्शन बनाइए जो दो पैरामीटर लेता है (_Pac-Man पावर पेलेट को छू रहा है या नहीं_ और _Pac-Man बिंदु को छू रहा है या नहीं_) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man को अंक मिले या नहीं। फंक्शन को `True` लौटाना चाहिए जब Pac-Man पावर पेलेट या बिंदु को छू रहा हो।

```python
>>> score(True, True)
...
True
```

## 3. तय कीजिए कि Pac-Man हारता है या नहीं

`lose()` फंक्शन बनाइए जो दो पैरामीटर लेता है (_Pac-Man के पास पावर पेलेट सक्रिय है या नहीं_ और _Pac-Man भूत को छू रहा है या नहीं_) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man हारता है या नहीं। फंक्शन को `True` लौटाना चाहिए जब Pac-Man भूत को छू रहा हो और उसके पास पावर पेलेट सक्रिय न हो।

```python
>>> lose(False, True)
...
True
```

## 4. तय कीजिए कि Pac-Man जीतता है या नहीं

`win()` फंक्शन बनाइए जो तीन पैरामीटर लेता है (_Pac-Man सारे बिंदु खा चुका है या नहीं_, _Pac-Man के पास पावर पेलेट सक्रिय है या नहीं_, और _Pac-Man भूत को छू रहा है या नहीं_) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man जीतता है या नहीं। फंक्शन को `True` लौटाना चाहिए जब Pac-Man सारे बिंदु खा चुका हो और भाग 3 में बताए नियमों के आधार पर वह न हारा हो।

```python
>>> win(False, True, False)
...
False
```
