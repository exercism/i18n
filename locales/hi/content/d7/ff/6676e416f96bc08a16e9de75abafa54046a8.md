# टेस्ट

## टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
make
```

## अभ्यास हल करना

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना। जब आप टेस्ट चलाते हैं, तो डिफॉल्ट रूप से सिर्फ एक टेस्ट (पहला टेस्ट) चलता है। यह जानबूझकर ऐसा है, ताकि आप अपना ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर लगा सकें। जब वह पास हो जाए, तो `TEST_IGNORE()` लाइन हटाकर आप अगला टेस्ट चालू कर सकते हैं। जब सारे टेस्ट चालू हो जाएँ और आपका कोड उन सबको पास करा दे, तो समझिए कि आपने अभ्यास हल कर लिया!
