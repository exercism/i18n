# Python इंस्टॉल करना

अगर आपके सिस्टम पर Python पहले से मौजूद नहीं है, तो हर प्लेटफॉर्म के लिए विस्तृत निर्देश आधिकारिक डाक्युमेंटेशन के [Python Setup and Usage][using python] हिस्से में मिल जाएँगे।
Real Python पर भी कई प्लेटफॉर्मों, जिनमें iOS और Android भी शामिल हैं, पर इंस्टॉल करने की एक [बढ़िया गाइड][helpful guide] है।

अंत में, Brett Cannon की ये दो पोस्टें, [A quick-and-dirty guide][quick-and-dirty] और [Why you should use `python -m pip`][python-m-pip], Python इंस्टॉल करने और पैकेज मैनेज करने के बारे में बहुत उपयोगी सलाह देती हैं।

**MacOS उपयोगकर्ताओं के लिए ध्यान दें:** MacOS Monterey (12.3) से पहले, ऑपरेटिंग सिस्टम के साथ `Python 2.7` पहले से इंस्टॉल आता था।
Exercism या ज़्यादातर दूसरे प्रोग्रामों के साथ `Python 2.7` का उपयोग समर्थित नहीं है।
इसके बजाय आपको नीचे बताए गए तरीकों में से किसी एक से [Python 3][Python-three downloads] इंस्टॉल करना चाहिए।
MacOS Monterey (12.3) से अब MacOS के साथ Python का कोई भी वर्ज़न पहले से इंस्टॉल नहीं आता।

ऑपरेटिंग सिस्टम के हिसाब से डाक्युमेंटेशन में सीधे जाने वाले कुछ लिंक:

-  [Windows][windows] इसके अलावा, Windows पर [Python इंस्टॉल करने][python-on-windows] वाला Microsoft का यह लेख भी काम का है।
-  [Unix और Linux सिस्टम][unix-and-linux] (_ये ज़्यादातर MacOS के लिए भी काम करते हैं_)
-  [MacOS][macos]

   हम यह भी सलाह देते हैं कि आप Real Python के लेख [Installing Python][installing-python] में बताए गए कुछ तरीकों को देखें, या ऊपर लिंक किए गए Brett Cannon के लेखों को।


Exercism के टेस्ट और टूलिंग इस समय `3.10` - `3.13.5` (_टेस्ट_) और [`Python 3.13.5`][313-new-features] (_टूलिंग_) का समर्थन करते हैं।
इस समर्थन से जुड़े अपवाद जहाँ भी मिलते हैं, वहीं दर्ज हैं।
ज़्यादातर अभ्यास `Python 3.6+`, या उससे भी पुराने वर्ज़नों के साथ काम करेंगे।
लेकिन [Active Python Releases][active-python-releases] में न दिए गए वर्ज़नों के समर्थन की हम गारंटी नहीं देते।


अभी क्या समर्थित है, यह जानने के लिए [Python 3.13.x documentation][3.13 docs] देखिए।
