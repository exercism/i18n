# निर्देश

सारा एक नया रोल-प्लेइंग गेम बना रही है और उसे खिलाड़ी से जुड़े नियम बनाने में आपकी मदद चाहिए।

## 1. `player` टपल बनाइए

चार स्लॉट और डिफॉल्ट वैल्यू वाला एक टपल क्लास `player` बनाइए:

| स्लॉट     | डिफॉल्ट |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

एक बार यह बन जाने के बाद, आप खिलाड़ी को लिटरल के रूप में लिख सकते हैं:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. खिलाड़ी का परिचय दीजिए

`introduce` बनाइए जो खिलाड़ी का नाम लौटाए। चुपके रहने वाले खिलाड़ी अपना नाम छिपा लेते हैं (`name` की वैल्यू `f` होती है), और उनका परिचय `"Mighty Magician"` के रूप में दिया जाना चाहिए।

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. गिरे हुए खिलाड़ी को ज़िंदा कीजिए

`revive` बनाइए जो एक *नया* खिलाड़ी लौटाए जिसमें `health` और `mana` दोनों 100 हों, लेकिन यह तभी हो जब खिलाड़ी की `health` की वैल्यू `0` हो। अगर खिलाड़ी अभी जीवित है, तो `f` लौटाइए।

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. नुकसान उठाइए

`take-damage` बनाइए जो एक *नया* खिलाड़ी लौटाए जिसमें `health` की वैल्यू दी गई मात्रा से घटाई गई हो, और जो कभी `0` से नीचे न गिरे।

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
