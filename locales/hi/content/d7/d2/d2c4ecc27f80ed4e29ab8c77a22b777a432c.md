# परिचय

Go में [`Time`][time] एक ऐसा टाइप है जो समय के किसी एक पल को बताता है।
इसकी तारीख और समय की जानकारी को इसके मेथड के ज़रिए देखा, तुलना की और बदला जा सकता है, लेकिन कुछ फंक्शन सीधे `time` पैकेज पर भी कॉल किए जाते हैं।
मौजूदा तारीख और समय [`time.Now`][now] फंक्शन से प्राप्त किया जा सकता है।

[`time.Parse`][parse] फंक्शन स्ट्रिंग को पार्स करके `Time` टाइप की वैल्यू बनाता है।
Go में यह तय करने का एक खास तरीका है कि पार्सिंग के लिए आप किस लेआउट की उम्मीद करते हैं।
इसके लिए आपको इस खास टाइमस्टैम्प की वैल्यू इस्तेमाल करके लेआउट का एक उदाहरण लिखना होता है:
`Mon Jan 2 15:04:05 -0700 MST 2006`।

उदाहरण के लिए:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

[`Time.Format()`][format] मेथड समय का स्ट्रिंग रूप लौटाता है।
`Parse` फंक्शन की तरह ही, यहाँ भी लक्ष्य लेआउट उसी खास टाइमस्टैम्प की वैल्यू वाले एक उदाहरण से परिभाषित किया जाता है।

उदाहरण के लिए:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## लेआउट के विकल्प

अपना लेआउट बनाने के लिए इन विकल्पों का मेल इस्तेमाल कीजिए।
Go में तारीख और टाइमस्टैम्प के पहले से तय [फॉर्मेट कॉन्स्टेंट][const] भी उपलब्ध हैं।

| समय        | विकल्प                                        |
| ----------- | ---------------------------------------------- |
| वर्ष        | 2006 ; 06                                      |
| महीना       | Jan ; January ; 01 ; 1                         |
| दिन         | 02 ; 2 ; \_2 (आगे 0 जोड़ने के लिए)              |
| वार         | Mon ; Monday                                   |
| घंटा        | 15 ( 24 घंटे का प्रारूप ) ; 3 ; 03 (AM या PM)   |
| मिनट        | 04 ; 4                                         |
| सेकंड       | 05 ; 5                                         |
| AM/PM चिह्न | PM                                             |
| वर्ष का दिन | 002 ; \_\_2                                    |

`time.Time` टाइप में किसी खास समय को देखने के लिए कई मेथड हैं। जैसे घंटा: [`Time.Hour()`][hour], महीना: [`Time.Month()`][month]।
यह कैसे काम करता है, इसके बारे में और जानकारी [आधिकारिक दस्तावेज़][time] में मिल सकती है।

`time` पैकेज में एक और टाइप भी शामिल है, [`Duration`][duration], जो बीते हुए समय को दर्शाता है। इसके साथ ही इसमें लोकेशन/टाइम ज़ोन, टाइमर और दूसरी जुड़ी सुविधाओं का समर्थन भी है, जिन्हें किसी और कॉन्सेप्ट में समझाया जाएगा।
