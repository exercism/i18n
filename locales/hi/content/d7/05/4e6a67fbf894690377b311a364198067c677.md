# परिचय

दूसरी भाषाओं की शब्दावली इस्तेमाल करें तो JSON का **ऑब्जेक्ट** एक "हैश", "मैप" या "डिक्शनरी" होता है।

JSON _ऑब्जेक्ट_ को इस तरह परिभाषित करता है:

> ऑब्जेक्ट **नाम**/**वैल्यू** जोड़ों का एक समूह होता है, जिसका कोई तय क्रम नहीं होता।
> ऑब्जेक्ट `{` बाएँ ब्रेस से शुरू होता है और `}` दाएँ ब्रेस पर समाप्त होता है।
> हर _नाम_ के बाद `:` कोलन आता है, और _नाम/वैल्यू_ जोड़ों को `,` कॉमा से अलग किया जाता है।

_नाम_ **स्ट्रिंग ही होना चाहिए**।
_नाम_ के लिए एक और शब्द _की_ है।

_वैल्यू_ किसी भी JSON टाइप की हो सकती है।
एक ही ऑब्जेक्ट की अलग-अलग _वैल्यू_ अलग-अलग टाइप की हो सकती हैं, जैसा इस उदाहरण में है।

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

ध्यान दीजिए कि _अंतिम_ की-वैल्यू जोड़े के बाद **कॉमा नहीं** होना चाहिए।

## ऑब्जेक्ट बनाना

नाम/वैल्यू जोड़ों को इकट्ठा करने के लिए ब्रेस का इस्तेमाल कीजिए।
नाम चाहे स्ट्रिंग ही होने चाहिए, लेकिन अगर नाम **आइडेंटिफायर जैसे** हों (अंग्रेज़ी के अक्षरों और अंकों तथा अंडरस्कोर से बने हों, और किसी अंक से शुरू न हों) तो उन्हें कोट्स में लिखने की ज़रूरत नहीं होती।

```jq
{name: "Jane", age: 42}
```

ऐसी की इस्तेमाल करना भी सही है जो _आइडेंटिफायर जैसी_ न हों।
ऐसी की को बस कोट्स में लिख दीजिए।

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

अगर नाम किसी एक्सप्रेशन का परिणाम है, तो वह एक्सप्रेशन **ज़रूर** गोल ब्रैकेट में होना चाहिए।

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## इंडेक्सिंग

ऑब्जेक्ट से वैल्यू **डॉट नोटेशन** से निकाली जाती हैं।

```jq
{name: "Jane", age: 42} | .age    # => 42
```

अगर आप किसी की को आइडेंटिफायर की तरह नहीं लिख सकते, तो **ब्रैकेट नोटेशन** इस्तेमाल कीजिए।

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## की-वैल्यू जोड़े जोड़ना या बदलना

किसी ऐरे में नया की-वैल्यू जोड़ा जोड़ने के लिए, या किसी मौजूदा की की वैल्यू बदलने के लिए, `=` असाइनमेंट ऑपरेटर इस्तेमाल कीजिए और उसके बाईं ओर एक इंडेक्स एक्सप्रेशन लिखिए।

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+` ऑपरेटर ऑब्जेक्टों को _मर्ज_ कर देता है।

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## किसी की को हटाना

किसी की को हटाने के लिए `del` फंक्शन इस्तेमाल कीजिए।
यह अपडेट किया गया ऑब्जेक्ट लौटाता है।

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

`del` को दिया जाने वाला पैरामीटर एक **इंडेक्स एक्सप्रेशन** होता है (डॉट या ब्रैकेट नोटेशन में), जो ऑब्जेक्ट की किसी की तक पहुँचता है।
`jq` इसे **पाथ एक्सप्रेशन** कहता है।
सिर्फ एक स्ट्रिंग देना काफी नहीं है।

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## सदस्यता

- यह जाँचने के लिए कि ऑब्जेक्ट में कोई की मौजूद है या नहीं, `has` फंक्शन इस्तेमाल कीजिए।

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- किसी की के ऑब्जेक्ट में होने की जाँच `in` से कीजिए।

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## सभी की निकालना

सारी की की सूची देखने के लिए `keys` फंक्शन इस्तेमाल कीजिए।

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

ध्यान दीजिए कि `keys` की को _सॉर्ट_ कर देता है।
की को मूल क्रम में पाने के लिए `keys_unsorted` इस्तेमाल कीजिए।

सारी _वैल्यू_ की सूची देने वाला कोई समान फंक्शन नहीं है।
लेकिन `.[]` फिल्टर ऑब्जेक्ट की वैल्यू को एक _स्ट्रीम_ की तरह देता है, और उस स्ट्रीम को `[...]` ऐरे कंस्ट्रक्टर से इकट्ठा किया जा सकता है।

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## इटरेशन करना

- `map_values(filter)` फंक्शन ऑब्जेक्ट की हर _वैल्यू_ पर फिल्टर लागू करता है।

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- किसी ऑब्जेक्ट पर इटरेशन करने के लिए पहले उसे की-वैल्यू ऑब्जेक्टों के ऐरे में बदलना होता है।
  `to_entries` फंक्शन यही करता है।

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  अब हम ऐरे पर इटरेशन करने वाले फंक्शन इस्तेमाल कर सकते हैं, जैसे `map`।

- `from_entries` फंक्शन इसका उल्टा काम करता है: की-वैल्यू ऑब्जेक्टों के ऐरे को ऑब्जेक्ट में बदल देता है।

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- ऑब्जेक्ट के _हर_ की-वैल्यू जोड़े पर फिल्टर लागू करने के लिए `with_entries(filter)` फंक्शन इस्तेमाल कीजिए।

  उदाहरण के लिए, मान लीजिए एक ऑब्जेक्ट है जो नाम को उम्र से जोड़ता है; उसकी की और वैल्यू इस तरह आपस में बदली जा सकती हैं।

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  आउटपुट:

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` इसके बराबर है:

  ```jq
  to_entries | map(filter) | from_entries
  ```
