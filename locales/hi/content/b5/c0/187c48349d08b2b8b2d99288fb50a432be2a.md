# निर्देश

आपको एक गेम के गोल करने वालों का ऐरे लेना है और गिनना है कि हर खिलाड़ी ने कितने गोल किए हैं।

`PlayerName`, `String` का एक टाइप एलियस है, ताकि कोड पढ़ने में आसान रहे और `String` के इस इस्तेमाल को `String` के बाकी इस्तेमालों से अलग पहचाना जा सके।

## 1. गोल करने वालों को इकट्ठा कीजिए

सबसे पहले `updateGoalCountForPlayer` बनाइए, जो किसी खिलाड़ी की गोल गिनती शुरू करे या बढ़ाए।
इसके बाद `updateGoalCountForPlayer` का इस्तेमाल करके `aggregateScorers` फंक्शन बनाइए, जो गिने कि हर खिलाड़ी ने कितने गोल किए हैं।
यह फंक्शन एक `List PlayerName` लेता है (उन खिलाड़ियों के नाम जिन्होंने गोल किए हैं, जिसमें एक ही खिलाड़ी का नाम कई बार हो सकता है) और एक `Dict PlayerName Int` लौटाता है, जिसमें ऐरे के सारे खिलाड़ी और उनके किए गोलों की संख्या होती है।

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. कम गोल करने वाले खिलाड़ियों को हटाइए

`removeInsignificantPlayers` फंक्शन बनाइए, जो उन खिलाड़ियों को छाँट दे जिन्होंने थ्रेशोल्ड से कम गोल किए हैं।

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. खिलाड़ी की गोल गिनती शून्य कीजिए

`resetPlayerGoalCount` फंक्शन बनाइए, जो किसी खिलाड़ी के किए गोलों की गिनती शून्य कर दे।

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. एक खिलाड़ी की गोल गिनती को स्ट्रिंग में बदलिए

`formatPlayer` फंक्शन बनाइए, जो एक खिलाड़ी की गोल गिनती को स्ट्रिंग के रूप में तैयार करे। अगर वह खिलाड़ी डिक्शनरी में मौजूद न हो, तो मान लीजिए कि उसकी गोल गिनती शून्य है।

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. सभी खिलाड़ियों की गोल गिनती को स्ट्रिंग में बदलिए

`formatPlayers` फंक्शन बनाइए, जो सभी खिलाड़ियों की गोल गिनती को स्ट्रिंग के रूप में तैयार करे। खिलाड़ियों का क्रम उनके नाम के अनुसार होना चाहिए।

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. दोनों गेम मिलाइए

`combineGames` फंक्शन बनाइए, जो गिने कि दोनों गेम में हर खिलाड़ी ने कुल कितने गोल किए हैं।

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
