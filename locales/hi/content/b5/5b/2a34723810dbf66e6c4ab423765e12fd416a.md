# विवरण

Gleam में स्ट्रिंग एक ऐसा अपरिवर्तनीय टेक्स्ट होती है जिसे दोहरे उद्धरण चिह्नों के बीच लिखा जाता है। इनमें यूनिकोड अक्षर भी हो सकते हैं, और ये कई पंक्तियों में भी लिखी जा सकती हैं।

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

स्ट्रिंग को `<>` ऑपरेटर से जोड़ा जा सकता है:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

स्टैंडर्ड लाइब्रेरी का [`gleam/string`][stdlib] मॉड्यूल स्ट्रिंग पर काम करने के फंक्शन देता है।

स्ट्रिंग का मिलान case एक्सप्रेशन में किया जा सकता है:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

अगर आप स्ट्रिंग की शुरुआत से मिलान करना चाहते हैं और बाकी हिस्से को किसी वेरिएबल में असाइन करना चाहते हैं, तो `<>` ऑपरेटर पैटर्न इस्तेमाल कर सकते हैं:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
