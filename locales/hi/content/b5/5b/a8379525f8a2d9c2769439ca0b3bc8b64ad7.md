# परिचय

Haxe टाइप और फील्ड के रनटाइम रिफ्लेक्शन का समर्थन करता है। रिफ्लेक्शन का सही तरीके से उपयोग करने के लिए यह समझना ज़रूरी है कि किस तरह के ऑपरेशन समर्थित हैं और कौन-कौन से नहीं। रिफ्लेक्शन की गतिशील प्रकृति को देखते हुए, यह हमेशा कंपाइल-टाइम पर तय नहीं किया जा सकता।

रिफ्लेक्शन API में दो क्लास हैं:

- `Reflect`: एक हल्का API जो अनाम स्ट्रक्चर पर सबसे अच्छा काम करता है, और क्लासों के लिए सीमित समर्थन देता है।
- `Type`: क्लास और एनम के साथ काम करने के लिए अधिक मज़बूत API।

उपलब्ध मेथड [Reflect][reflect] और [Type][type] के API में विस्तार से बताए गए हैं।

नीचे दिए गए उदाहरण में हम JavaScript टारगेट का उपयोग कर रहे हैं:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
