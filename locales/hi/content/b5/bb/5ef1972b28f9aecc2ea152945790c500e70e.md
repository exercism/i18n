# निर्देश

`classes` अभ्यास में आपने जो रिमोट कंट्रोल कार प्रोजेक्ट शुरू किया था, वह अच्छा चला (बधाई हो!), और हाल के कई स्पॉन्सरशिप सौदों की वजह से बजट में सुधार के लिए पैसे आ गए हैं।

बजट का एक हिस्सा कुछ टेलीमेट्री उपलब्ध कराने में लगाया जा रहा है।

स्पॉन्सरों को खुश रखने के लिए कार पर एक पैनल लगाया गया है, जो कार के ट्रैक पर चक्कर लगाते समय स्पॉन्सरों के नाम प्रदर्शित करता है।

आप देखेंगे कि इन नई फैंसी तकनीकों की शुरुआत से कार की बैटरी लाइफ बहुत कम हो गई है।

## 1. रिमोट कंट्रोल कार को स्पॉन्सरों के नाम प्रदर्शित करने में सक्षम बनाइए

`SetSponsors()` को इस तरह लागू कीजिए कि यह एक या अधिक स्पॉन्सरों के नाम ले और उन्हें कार पर संग्रहीत करे।

ध्यान रखें कि `SetSponsors()` मेथड का आर्गुमेंट नॉन-नल होना निश्चित है।

`DisplaySponsor()` को लागू कीजिए ताकि यह चुने गए स्पॉन्सर को प्रदर्शित करे। पहले पास किए गए स्पॉन्सर का `sponsorNum` 0 होता है, दूसरे का 1, और इसी तरह आगे।

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. कार का टेलीमेट्री डेटा प्राप्त कीजिए

`RemoteControlCar.GetTelemetryData()` मेथड को लागू कीजिए।

`GetTelemetryData()` को बैटरी प्रतिशत और मीटरों में तय की गई दूरी `out` पैरामीटरों के ज़रिए उपलब्ध करना चाहिए।

यदि serialNum आर्गुमेंट पहले प्राप्त वैल्यू से कम है, तो `GetTelemetryData()` को `false` लौटाना चाहिए। (कई टेलीमेट्री नोड्स शामिल होने की कोई समस्या रहती है)। ऐसी स्थिति में `serialNum` को पिछले सबसे बड़े `serialNum` पर सेट किया जाएगा, और बैटरी प्रतिशत तथा तय किए गए मीटर दोनों `-1` पर सेट हो जाएँगे। जहाँ कॉल सफल होती है, वहाँ `serialNum` अपरिवर्तित रहता है।

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. ऐसी सुविधा जोड़िए जिससे टेलीमेट्री सिस्टम प्रति मीटर बैटरी उपयोग पता कर सके

`TelemetryClient.GetBatteryUsagePerMeter()` मेथड को लागू कीजिए।

यह `RemoteControlCar.GetTelemetryData()` को कॉल करेगा। यदि `GetTelemetryData()` `false` लौटाता है या कार चलाई नहीं गई है, तो इस रूटीन को "no data" लौटाना चाहिए। यदि `GetTelemetryData()` `true` लौटाता है, तो निम्न रूप में एक संदेश लौटाया जाना चाहिए: "usage-per-meter=BATTERY-USAGE-PER-METER"। यहाँ गणना यह है: (100 में से वर्तमान बैटरी प्रतिशत घटाकर) को अब तक तय की गई मीटरों में दूरी से भाग देना।

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
