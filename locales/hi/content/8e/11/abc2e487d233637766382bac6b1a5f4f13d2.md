# परिचय

Swift में कुछ ऐसे स्टेटमेंट हैं जिनसे लूप के सामान्य कंट्रोल फ्लो को बदला जा सकता है। इन्हें कंट्रोल ट्रांसफर स्टेटमेंट कहते हैं। आप `return` तो देख चुके हैं; इस कॉन्सेप्ट में हम कुछ और स्टेटमेंट देखेंगे, जिनमें `continue`, `break` और लेबल शामिल हैं।

## Continue

कभी-कभी लूप के मौजूदा इटरेशन के बाकी स्टेटमेंट पूरे किए बिना सीधे अगले इटरेशन पर पहुँचना ज़रूरी होता है। इसके लिए `continue` कीवर्ड का उपयोग किया जा सकता है। जब `continue` चलता है, तो लूप सीधे अगली जाँच पर पहुँच जाता है: यह देखा जाता है कि लूप का अगला इटरेशन चलाया जा सकता है या नहीं। while और repeat-while लूप में यह जाँच `while` की जाँच होती है, और for-in लूप में यह देखा जाता है कि सीक्वेंस में कोई और एलिमेंट मौजूद है या नहीं।

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

`break` का उपयोग लूप से जल्दी बाहर निकलने के लिए किया जाता है। जब `break` चलता है, तो लूप तुरंत खत्म हो जाता है और प्रोग्राम लूप के बाद वाले पहले स्टेटमेंट से आगे बढ़ता है।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## लेबल

जब लूप नेस्टेड होते हैं, तो कई बार ऐसा होता है कि हम `break` या `continue` का उपयोग उन बाहरी लूप से बाहर निकलने या उन्हें दोबारा शुरू करने के लिए करना चाहते हैं जिनके अंदर वह लूप है जिसमें `break` या `continue` लिखा गया है। ऐसी स्थितियों में लेबल का उपयोग करके बताया जा सकता है कि किस लूप से बाहर निकलना है या किसे दोबारा शुरू करना है। किसी लूप पर लेबल लगाने के लिए उसके शुरू होने वाले `while`, `repeat` या `for` से पहले एक नाम और उसके बाद कोलन लगाइए।

इस तरह लेबल इस्तेमाल करने का असर देखने के लिए नीचे दिए गए लूप को देखिए।

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

`fallthrough` कीवर्ड का उपयोग switch स्टेटमेंट में अगले case तक पहुँचने के लिए किया जाता है। इसका मतलब है कि अगले case का कोड बिना उसकी शर्त जाँचे ही चल जाएगा। इससे switch स्टेटमेंट का व्यवहार उन दूसरी प्रोग्रामिंग भाषाओं जैसा हो जाता है जहाँ किसी case के मैच होने के बाद switch स्टेटमेंट से बाहर निकलने के लिए `break` स्टेटमेंट की ज़रूरत नहीं होती। `fallthrough` के बारे में अधिक जानने के लिए [Swift की किताब][fallthrough] पढ़िए।

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[control-transfer]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Control-Transfer-Statements
[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
