# टेस्ट

## Clojure CLI

Exercism के Clojure अभ्यासों के साथ एक `deps.edn` फाइल आती है। इसमें `:test` नाम का एक एलियस होता है, जिससे [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) चलाया जा सकता है:

``` bash
$ clj -X:test
```

## Leiningen

अभ्यास का टेस्ट चलाने के लिए Leiningen का भी उपयोग किया जा सकता है। इसके लिए अभ्यास की डायरेक्टरी से यह कमांड चलाइए:

```bash
lein test
```

## REPL

REPL की मदद से अभ्यास का टेस्ट चलाने के लिए अभ्यास की डायरेक्टरी से यह कमांड चलाइए:

```bash
$ clj
```

-या-

```bash
$ lein repl
```

फिर अभ्यास का टेस्ट नेमस्पेस और Clojure का टेस्ट नेमस्पेस `require` कीजिए:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

फिर `<exercise>-test` पर `run-tests` कॉल कीजिए:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
