# ऑपरेटर ओवरलोडिंग

ऑपरेटर ओवरलोडिंग कुछ प्रोग्रामिंग भाषाओं का एक फीचर है। इसकी मदद से जोड़ (`+`), घटाव (`-`), गुणा (`*`) और भाग (`/`) जैसे मानक ऑपरेटरों को फिर से परिभाषित किया जा सकता है, ताकि वे उपयोगकर्ता द्वारा बनाए गए टाइपों के साथ भी काम करें।

इससे कोड का सिंटैक्स अधिक सहज बन जाता है, क्योंकि उपयोगकर्ता द्वारा बनाए गए टाइपों पर ऑपरेशन उसी तरह लिखे जा सकते हैं जैसे प्रिमिटिव टाइपों पर।

Cairo में ऑपरेटर ओवरलोडिंग कुछ खास ट्रेटों के इम्प्लीमेंटेशन से होती है।

हर ऑपरेटर के साथ एक ट्रेट जुड़ा होता है, और किसी ऑपरेटर की ओवरलोडिंग का मतलब है कि किसी कस्टम टाइप के लिए उस ट्रेट का इम्प्लीमेंटेशन दिया जाए।
लेकिन ऑपरेटर ओवरलोडिंग का इस्तेमाल सोच-समझकर करना आवश्यक है।

गलत इस्तेमाल से भ्रम पैदा हो सकता है और कोड को बनाए रखना कठिन हो जाता है, खासकर जब ओवरलोड किए जा रहे ऑपरेटर का कोई अर्थ ही न बनता हो।

चलिए एक उदाहरण देखते हैं, जिसमें दो `Potions` को मिलाना है।

`Potions` में दो डेटा फील्ड होते हैं, mana और health.

दो `Potions` को मिलाने पर उनके अपने-अपने फील्ड जोड़े जाने चाहिए।

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

ऊपर के कोड में हम `Potion` टाइप के लिए `Add` ट्रेट का इम्प्लीमेंटेशन लिख रहे हैं।

add फंक्शन दो आर्गुमेंट लेता है: `lhs` और `rhs` (बाएँ और दाएँ पक्ष)।

फंक्शन के अंदर का कोड एक नया `Potion` इंस्टेंस लौटाता है, और उस इंस्टेंस के फील्ड की वैल्यू `lhs` और `rhs` को मिलाकर बनती हैं।

जैसा कि उदाहरण में दिखाया गया है, किसी ऑपरेटर की ओवरलोडिंग के लिए यह बताना आवश्यक है कि ओवरलोडिंग किस मूर्त टाइप पर की जा रही है।

ओवरलोड किया जाने वाला जेनेरिक ट्रेट `Add<T>` है, और हम `Add<Potion>` के ज़रिए `Potion` टाइप के लिए एक मूर्त इम्प्लीमेंटेशन बनाते हैं।
