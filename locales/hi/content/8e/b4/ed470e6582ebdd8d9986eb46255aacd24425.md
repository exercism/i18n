# निर्देश

नीचे दिए गए जैसे ASCII आरेख में आयत (rectangle) गिनिए।

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

ऊपर दिए गए आरेख में ये 6 आयत हैं:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

आप यह मान सकते हैं कि इनपुट हमेशा एक सही आयत होता है (यानी हर पंक्ति की लंबाई पहली पंक्ति की लंबाई के बराबर होती है)।
