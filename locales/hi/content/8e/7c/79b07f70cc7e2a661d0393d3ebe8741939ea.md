# परिचय

Haxe एक स्ट्रॉन्गली टाइप्ड भाषा है, लेकिन जहाँ ज़रूरत हो वहाँ टाइप सिस्टम को दरकिनार किया जा सकता है। किसी नाम को वैल्यू असाइन करने को ही वेरिएबल बनाना कहा जाता है। वेरिएबल बनाते समय आप या तो उसका टाइप साफ़-साफ़ लिख सकते हैं, या Haxe कंपाइलर को खुद टाइप का अनुमान लगाने दे सकते हैं। इसलिए वेरिएबल की नीचे दी गई दोनों परिभाषाएँ एक जैसी हैं:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

`=` ऑपरेटर की मदद से वेरिएबल की वैल्यू बदली जा सकती है:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

अगर किसी वेरिएबल को उसके टाइप से अलग टाइप की वैल्यू असाइन करने की कोशिश की जाए, तो कंपाइलर एरर देता है:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

क्लास के अंदर लिखे फंक्शन को _मेथड_ कहते हैं। किसी मेथड में शून्य या उससे अधिक पैरामीटर हो सकते हैं। हर पैरामीटर का टाइप साफ़-साफ़ लिखना ज़रूरी है। पैरामीटर की तरह ही मेथड का रिटर्न टाइप भी अनुमान से नहीं निकाला जा सकता, उसे भी लिखना पड़ता है। `return` कीवर्ड की मदद से मेथड से वैल्यू लौटाई जाती है:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

मेथड को कॉल करने के लिए उसकी क्लास और मेथड का नाम लिखा जाता है और आर्गुमेंट पास किए जाते हैं:

```haxe
var sum = add(1, 2) // sum = 3
```

Haxe में स्कोप `{` और `}` के बीच तय होता है।

Haxe में दो तरह के कमेंट होते हैं। सिंगल-लाइन कमेंट से पहले `//` लगाया जाता है, और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखे जाते हैं।
