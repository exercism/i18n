# निर्देश

Bob एक वित्तीय सलाहकार है और लोगों को उनका खर्च संभालने में मदद करता है।
Bob के ग्राहक उसे जाँचने के लिए खर्च के रिकॉर्ड भेजते हैं।
Bob के पास पिछली अवधियों के रिकॉर्ड हैं, ताकि वह खर्च में होने वाले बदलाव देख सके।
Bob को कैलेंडर पसंद नहीं हैं और वह तारीखों की जगह *Bob epoch* इस्तेमाल करता है।
Bob epoch उन दिनों की संख्या है जो Bob के ग्राहक के अपना काम शुरू करने के बाद बीते हैं।

इस अभ्यास में आप एक प्रोग्राम बनाएँगे जो Bob को उसके ग्राहकों का खर्च संभालने और उसका विश्लेषण करने में मदद करेगा।

Bob `Record` और `DaysPeriod` के साथ काम करता है।

एक `Record` खर्च के एक रिकॉर्ड को दर्शाता है। इसमें वह दिन शामिल होता है जिस दिन खर्च किया गया, खर्च की गई राशि, और खर्च की श्रेणी।

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

एक `DaysPeriod` दिनों की एक अवधि को दर्शाता है और `From` दिन से लेकर `To` दिन तक के सारे दिनों को शामिल करता है।
अवधि में दोनों छोर शामिल होते हैं।

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. रिकॉर्ड छाँटने का एक सामान्य फ़िल्टर बनाइए

Bob को हर दिन बहुत सारे रिकॉर्ड संभालने पड़ते हैं, लेकिन Bob जो विश्लेषण कर रहा है उसके हिसाब से उनमें से सब दिलचस्प नहीं होते।
चलिए Bob को रिकॉर्ड छाँटने का कुछ बुनियादी काम करने में मदद करते हैं।

`Filter` नाम का सामान्य फंक्शन बनाइए, जो किसी फंक्शन द्वारा दिए गए मानदंड के अनुसार रिकॉर्ड छाँटे।
यह फ़िल्टर फंक्शन रिकॉर्ड का एक संग्रह और एक प्रेडिकेट फंक्शन लेता है, और संग्रह में से सिर्फ़ वे रिकॉर्ड लौटाता है जो प्रेडिकेट की शर्त पूरी करते हैं।

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. समय की एक अवधि में रिकॉर्ड छाँटिए

Bob को अक्सर ऐसे रिकॉर्ड छाँटने की ज़रूरत पड़ती है जो किसी दी गई अवधि में हों।

`ByDaysPeriod` फंक्शन बनाइए, जो Bob को ऐसे फ़िल्टर बनाने में मदद करेगा।
यह फंक्शन एक `DaysPeriod` लेता है और एक फंक्शन लौटाता है, जो एक रिकॉर्ड लेकर बताता है कि वह रिकॉर्ड आर्गुमेंट के रूप में दिए गए `DaysPeriod` की बताई गई अवधि में है या नहीं।

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. श्रेणी के अनुसार रिकॉर्ड छाँटिए

समय की अवधि के अलावा, Bob को रिकॉर्ड उनकी श्रेणी के अनुसार भी छाँटने की ज़रूरत पड़ती है।

`ByCategory` फंक्शन बनाइए, जो Bob को ऐसे फ़िल्टर बनाने में मदद करेगा।
यह फंक्शन एक श्रेणी लेता है और एक फंक्शन लौटाता है, जो एक रिकॉर्ड लेकर बताता है कि उस रिकॉर्ड की श्रेणी आर्गुमेंट के रूप में दी गई श्रेणी जैसी ही है या नहीं।

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. किसी अवधि में खर्च की कुल राशि निकालिए

Bob यह भी जानना चाहता है कि किसी अवधि में कुल कितना खर्च हुआ।

`TotalByPeriod` फंक्शन बनाइए, जो दिनों की अवधि में खर्चों का जोड़ लौटाए।

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. किसी अवधि में एक श्रेणी के रिकॉर्ड का कुल खर्च निकालिए

अपने ग्राहकों के लिए बनाई जाने वाली सबसे जटिल रिपोर्टों के लिए Bob को एक ही समय पर श्रेणी और समय की अवधि, दोनों के अनुसार रिकॉर्ड छाँटने की ज़रूरत पड़ती है।
यानी Bob यह जानना चाहता है कि किसी दी गई अवधि में एक श्रेणी के रिकॉर्ड पर कुल कितना खर्च हुआ।

`CategoryExpenses` फंक्शन बनाइए, जो दिनों की एक दी गई अवधि में किसी एक श्रेणी में हुए खर्च की कुल राशि लौटाता है।
यह फंक्शन इन दो स्थितियों में फ़र्क भी करना चाहिए: जब दी गई श्रेणी खर्च के रिकॉर्ड में ही मौजूद न हो, और जब दी गई अवधि में उस श्रेणी का कोई खर्च न हो।
जब वह श्रेणी किसी भी रिकॉर्ड की श्रेणी न हो (समय की अवधि चाहे कुछ भी हो), तो फंक्शन को एक एरर लौटानी चाहिए।

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
