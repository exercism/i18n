# जेनरेटर

एक `generator` एक फंक्शन या एक्सप्रेशन है जो एक खास तरह का [इटरेटर][iterator] लौटाता है, जिसे [`generator iterator`][generator-iterator] कहते हैं।
`Generator-iterator` [आलसी][lazy iterator] होते हैं: वे अपनी `values` मेमोरी में संग्रहीत नहीं करते, बल्कि ज़रूरत पड़ने पर उन्हें _बनाते_ हैं।

एक जेनरेटर फंक्शन दिखने में किसी भी आम फंक्शन जैसा होता है, लेकिन उसमें एक या उससे अधिक [yield एक्सप्रेशन][yield expression] होते हैं।
हर `yield` कोड का निष्पादन रोक देता है और मौजूदा निष्पादन स्थिति को सहेज लेता है (_जिसमें सारे लोकल वेरिएबल और try स्टेटमेंट शामिल हैं_)।
जब जेनरेटर दोबारा चलना शुरू करता है, तो वह उसी रुकी हुई स्थिति से आगे बढ़ता है। आम फंक्शन ऐसा नहीं करते, वे हर कॉल पर शुरू से शुरू हो जाते हैं।


## जेनरेटर बनाना

जेनरेटर भी दूसरे लूप वाले या रिकर्सिव फंक्शन की तरह ही बनाए जाते हैं, लेकिन इनमें एक [`yield` एक्सप्रेशन](#the-yield-expression) ज़रूरी होता है, जिसे हम थोड़ी देर बाद विस्तार से देखेंगे।

एक उदाहरण देखिए: एक फंक्शन जो संख्याओं के दिए गए ऐरे से उनके _वर्ग_ लौटाता है।
जैसा यह अभी लिखा है, इसमें पहले पूरा इनपुट प्रोसेस करना पड़ता है, तभी कोई वैल्यू लौटाई जा सकती है:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

आप उस फंक्शन को इस तरह जेनरेटर में बदल सकते हैं:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

इसके पीछे वजह यह है कि जेनरेटर तब काम आता है जब आपको सारी वैल्यू _एक साथ_ नहीं चाहिए।
इससे मेमोरी और प्रोसेसिंग पावर बचती है, क्योंकि सिर्फ उसी वैल्यू की गणना होती है जिस पर आप _उसी समय काम कर रहे हैं_।


## जेनरेटर का उपयोग

Python में ज़्यादातर `iterables` की जगह जेनरेटर का इस्तेमाल किया जा सकता है।
इसमें वे _फंक्शन_ या _ऑब्जेक्ट_ भी शामिल हैं जिन्हें आर्गुमेंट के तौर पर एक `iterable`/`iterator` चाहिए।

`squares_generator()` जेनरेटर का उपयोग करने के लिए:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

`generator` के अंदर की वैल्यू भी `next()` फंक्शन से बनाई या पढ़ी जा सकती हैं।
`next()` जेनरेटर-इटरेटर ऑब्जेक्ट का `__next__()` मेथड कॉल करता है, जो कोड को उसके `yield` एक्सप्रेशन तक "आगे बढ़ाता" है यानी चलाता है, और फिर वह एक वैल्यू "देता" है यानी लौटाता है:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

जब किसी `generator-iterator` की सारी वैल्यू खत्म हो जाती हैं और लौटाने के लिए कुछ बचता नहीं, तो वह `StopIteration` एरर फेंकता है।

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

जेनरेटर-इटरेटर [इटरेटर][iterator] का एक खास उपसमूह हैं।
`Iterators` वह तंत्र या प्रोटोकॉल हैं जो _iterables_ पर लूप चलाना संभव बनाते हैं।
जेनरेटर-इटरेटर और Python के आम [`iterables`][iterables] से मिलने वाले इटरेटर लगभग एक जैसा व्यवहार करते हैं, लेकिन इनमें कुछ ज़रूरी अंतर ध्यान देने योग्य हैं:

- वे _[आलसी तरीके से मूल्यांकित][lazy evaluation]_ होते हैं; इटरेशन _एकतरफा_ होता है और किसी पिछली वैल्यू पर "वापस जाने" का कोई रास्ता नहीं है।
- लौटाई गई वैल्यू पर इटरेशन करने से वे _खर्च_ हो जाते हैं; मेमोरी में कोई रीसेट या सेव नहीं होता।
- इन्हें क्रम में नहीं लगाया जा सकता और न ही उलटा किया जा सकता है।
- ये सीक्वेंस टाइप नहीं हैं, और इनमें `indexes` _नहीं_ होते। 
  आप जोड़ या घटाव के ज़रिये किसी पिछली या आगे की वैल्यू को नहीं पा सकते, और न ही ब्रैकेट (`[]`) संकेतन या स्लाइसिंग का इस्तेमाल कर सकते हैं।
- इन्हें `len()` फंक्शन के साथ इस्तेमाल नहीं किया जा सकता, क्योंकि इनकी कोई लंबाई नहीं होती।
- ये _सीमित_ या _असीमित_ हो सकते हैं। एक _असीमित_ `generator-iterator` से सारी वैल्यू जमा करते समय सावधान रहिए!

## yield एक्सप्रेशन

yield एक्सप्रेशन [yield expression] बहुत कुछ `return` एक्सप्रेशन जैसा होता है।
`return` एक्सप्रेशन से _अलग_, `yield` कॉलर को वैल्यू एक _खास बिंदु_ पर सौंप देता है, और तब तक कोई अतिरिक्त वैल्यू नहीं लौटाता जब तक उनकी माँग न की जाए।
जब `yield` का मूल्यांकन होता है, तो यह अपने फंक्शन का निष्पादन रोक देता है और उस समय फंक्शन की जो भी वैल्यू हैं, उन्हें लौटा देता है।
इसके बाद फंक्शन _स्कोप में बना रहता है_, और जब `__next__()` कॉल होता है, तो निष्पादन तब तक आगे बढ़ता है जब तक `yield` दोबारा न मिल जाए।


~~~~exercism/note
फंक्शन के बाहर `yield` एक्सप्रेशन का इस्तेमाल करना मना है।
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## जेनरेटर क्यों बनाना चाहिए?

जेनरेटर कई जगहों पर काम आते हैं।

जब बहुत बड़ी संख्या में वैल्यू के साथ काम करना हो, तो आप शायद उन सबको मेमोरी में न रखना चाहें।
ऐसे में जेनरेटर की मदद से बड़े डेटा पर टुकड़े-टुकड़े करके काम किया जा सकता है, जिससे मेमोरी बचती है और परफॉर्मेंस सुधरती है।

जेनरेटर तब भी बहुत काम आते हैं जब कोई प्रक्रिया या गणना _जटिल_, _खर्चीली_, या _असीमित_ हो:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

अब जब भी `infinite_sequence` ऑब्जेक्ट पर `__next__()` कॉल होता है, यह _पिछली संख्या_ + 1 लौटाता है।
