# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग        | प्रकार    | विवरण                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | दी गई संख्या                  |
| `$a1`    | इनपुट/आउटपुट | एड्रेस | नल-टर्मिनेटेड परिणाम स्ट्रिंग |
| `$t0-9`  | अस्थायी    | कोई भी     | अस्थायी भंडारण के लिए         |
