# परिचय

जब कोई चीज़ खुद ही के आधार पर परिभाषित की जाती है, तो उसे रिकर्शन कहते हैं। Gleam में रिकर्शन सबसे अधिक रिकर्सिव फंक्शन में देखने को मिलता है, यानी ऐसे फंक्शन में जो खुद को कॉल करता है।

एक रिकर्सिव फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना चाहिए। _बेस केस_ ऐसा केस होता है जो फंक्शन को दोबारा कॉल किए बिना कोई वैल्यू लौटाता है। _रिकर्सिव केस_ फंक्शन को दोबारा कॉल करता है और इनपुट में ऐसा बदलाव करता है कि वह किसी बिंदु पर बेस केस से मेल खाने लगे।

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam में लूप के लिए कोई विशेष सिंटैक्स नहीं है, इसलिए हर तरह का लूप रिकर्शन से ही किया जाता है।

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam में रिकर्सिव कस्टम टाइप भी होते हैं। रिकर्सिव कस्टम टाइप के एक या अधिक वेरिएंट अपने अंदर रखे डेटा में उसी टाइप का इस्तेमाल करते हैं।

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
