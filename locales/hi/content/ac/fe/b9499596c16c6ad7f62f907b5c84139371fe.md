# निर्देश

आप एक हेल्थ-मॉनिटरिंग सिस्टम बनाने पर काम कर रहे हैं। उसी के एक हिस्से के तौर पर आपको उपयोगकर्ताओं के स्वास्थ्य आँकड़ों का हिसाब रखना है।

शुरुआत में आपको एक `impl` ब्लॉक में कुछ अधूरे फंक्शन मिलेंगे, और साथ में struct की यह परिभाषा भी:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

आपको `impl` ब्लॉक में परिभाषित `User` `struct` के अधूरे मेथड पूरे करने हैं।

उदाहरण के लिए, `new` मेथड को `User` struct का एक इंस्टेंस लौटाना चाहिए, जिसमें दिए गए नाम, उम्र और वजन की वैल्यू हों।

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

`weight` मेथड को `User` का वजन लौटाना चाहिए।

```rust
bob.weight();
// Returns: 72
```

`set_age` मेथड को `User` की उम्र तय करनी चाहिए।

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
