# निर्देश

इस अभ्यास में आप लॉग-लाइनों को संसाधित करेंगे।

हर लॉग लाइन इस प्रारूप में लिखी एक स्ट्रिंग होती है: `"[<LVL>]: <MESSAGE>"`.

ये अलग-अलग लॉग लेवल हैं:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

आपके पास तीन काम हैं, और आवश्यक कार्यक्षमता देने के लिए तीनों को पूरा करना होगा।

## 1. LogLevel एनम बनाइए

`LogLevel` नाम का एक एनम बनाइए जिसमें ऊपर दिए गए लॉग लेवलों के अनुरूप छह केस हों, साथ ही उन लेवलों के लिए एक अज्ञात केस भी हो जिनका लॉग लेवल मौजूद न हो या मानक से अलग हो।

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. लॉग लेवल पार्स कीजिए

इसके बाद, `LogLevel` इनिशियलाइज़र बनाइए जो एक लॉग लाइन का लॉग लेवल पार्स करता हो:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. लॉग लाइन को छोटे प्रारूप में बदलिए

लॉग लाइन का लॉग लेवल काफी लंबा होता है।
लॉग लाइनों को संग्रहीत करने के लिए ज़रूरी डिस्क स्थान कम करने के लिए, एक छोटा प्रारूप बनाया गया है: `"<ENCODED_LEVEL>:<MESSAGE>"`.

एन्कोड किया गया लॉग लेवल, लॉग लेवल को एक संख्या से जोड़ने का सीधा तरीका है:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

एक `shortFormat(message: String) -> String` मेथड बनाइए जो छोटा किया गया लॉग लाइन प्रारूप को एक `String` के रूप में दे सके:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
