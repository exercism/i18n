# ईंधन रूपांतरण JSON

## समस्या कथन

ABC Corp के हर कर्मचारी को असीमित ईंधन भत्ता मिलता है। कर्मचारियों को हर बार अपने वाहन में ईंधन भरवाने पर एक रिकॉर्ड भेजना आवश्यक है। ये रिकॉर्ड एक ही JSON फाइल में जोड़े जाते हैं और महीने के अंत में संसाधित किए जाते हैं।

डिजिटल ऑपरेशंस टीम के सदस्य के रूप में आपको इस JSON फाइल को पढ़ना है और परिणामों को दूसरी JSON फाइल में लिखना है। आउटपुट फाइल में हर कर्मचारी के लिए निम्नलिखित विवरण वाली एक एंट्री होनी चाहिए:

- कर्मचारी संख्या
- ईंधन भरने की संख्या
- कुल ईंधन लागत
- कुल गैलन
- कुल अर्जित मील

आपको दो `string` आर्गुमेंट दिए गए हैं।

1. इनपुट JSON फाइल का पाथ।
1. आउटपुट JSON फाइल का पाथ।

इनपुट JSON फाइल में JSON ऑब्जेक्ट का एक ऐरे होता है। हर JSON ऑब्जेक्ट का रूप निम्नलिखित होता है।


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

आपको JSON इनपुट को निम्नलिखित JSON प्रारूप में बदलना है और सामग्री को दिए गए पाथ पर लिखनी है। आउटपुट फाइल में हर कर्मचारी के लिए एक एंट्री होनी चाहिए, जो `employeeId` के आरोही क्रम में हों।

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## बाधाएँ

- इनपुट JSON फाइल में ईंधन भरने के रिकॉर्ड की संख्या `n`:  0 <= n <= 1000
- कंपनी में कर्मचारियों की संख्या: 97
- गैस की कीमत प्रति गैलन है
- कोई ईंधन भरने का रिकॉर्ड गायब नहीं है

## संकेत

- JSON फाइलों को पढ़ने और लिखने के लिए [`ballerina/io` मॉड्यूल](https://lib.ballerina.io/ballerina/io/latest) का उपयोग कीजिए।
- डेटा के साथ टाइप-सेफ तरीके से काम करने के लिए JSON वैल्यू को एप्लिकेशन-विशिष्ट टाइप में बदलिए। जानकारी के लिए Ballerina By Examples (BBE) में [उपयोगकर्ता-परिभाषित टाइप में बदलने का उदाहरण](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) देखिए।

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- कोड की अधिकता कम करने में [रिकॉर्ड्स को डीस्ट्रक्चर करना](https://ballerina.io/learn/by-example/destructure-records-using-query) उपयोगी हो सकता है।

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- एक ही एक्सप्रेशन वाले फंक्शन के लिए एक्सप्रेशन-बॉडीड फंक्शन इस्तेमाल कीजिए। जैसे, वे फंक्शन जिनमें सिर्फ रिटर्न स्टेटमेंट होता है।

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
