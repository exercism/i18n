# अनुशंसित सीखने के संसाधन

ColdFusion (CFML) सीखने में आपका स्वागत है! CFML एक डायनैमिक और ढीली टाइपिंग वाली JVM स्क्रिप्टिंग भाषा है। इसमें दो अलग-अलग तरह की फाइलें होती हैं। `.cfm` फाइलें (ColdFusion markup) पूरी तरह प्रोसीजरल होती हैं और HTML का टेंप्लेट बनाने के लिए टैग-आधारित सिंटैक्स इस्तेमाल करती हैं। अगर आप कोई वेबसाइट बना रहे हों, तो इन्हें व्यू के लिए इस्तेमाल करेंगे:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

दूसरी तरह की फाइल `.cfc` (ColdFusion Component) है, और इसी से आप एक क्लास घोषित करते हैं। कंपोनेंट का इस्तेमाल बिज़नेस लॉजिक, मॉडल और कंट्रोलर के लिए किया जाता है। ये आम तौर पर स्क्रिप्ट सिंटैक्स इस्तेमाल करते हैं, जो पढ़ने में JavaScript जैसा लगता है।

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
