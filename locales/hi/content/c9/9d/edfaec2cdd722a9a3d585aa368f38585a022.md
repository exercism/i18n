# अधिक जानकारी

Common Lisp ज़्यादातर कामों के लिए मानक अंकगणितीय ऑपरेटर इस्तेमाल करता है, लेकिन एक बात में यह कुछ अलग है: जाने-पहचाने "इन्फिक्स-नोटेशन" की जगह यह "प्रीफिक्स-नोटेशन" इस्तेमाल करता है।

और साफ़ तौर पर:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

प्रीफिक्स नोटेशन `2 + 2` जैसे कुछ कामों को कम पहचाने जाने वाले `(+ 2 2)` रूप में बदल देता है, लेकिन इससे एक साथ एक से ज़्यादा संख्याओं पर काम करना बहुत आसान हो जाता है।

## एक ही आर्गुमेंट वाले अंकगणितीय ऑपरेटर

एक छोटी सी खास बात यह है कि `-` और `/` ऑपरेटरों का एक खास मतलब होता है, जब उन्हें सिर्फ एक ही संख्या पर लगाया जाता है:

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## संख्याओं की तुलना

अंत में, अलग-अलग संख्याओं की तुलना करने के लिए आप `=` (बराबर), `/=` (बराबर नहीं) और `>=` (से बड़ा या बराबर) जैसे फंक्शन इस्तेमाल कर सकते हैं।
जब ये तुलनाएँ सही होती हैं (जैसे `(= 1 1)`), तो ये `T` लौटाती हैं, और जब सही नहीं होतीं (जैसे `(> 0 1)`), तो `NIL` लौटाती हैं।

## संख्यात्मक प्रेडिकेट

भाषा में `zerop`, `evenp` और `oddp` जैसे कुछ काम के प्रेडिकेट भी हैं, जो उन शर्तों की जाँच करते हैं जो उनके नाम से ही साफ़ हैं।

## संदर्भ

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
