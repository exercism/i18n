# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग     | टाइप    | विवरण                                            |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | इनपुट     | पूर्णांक | जाँचने के लिए वर्ष                                |
| `$v0`    | आउटपुट    | बूलियन   | इनपुट लीप वर्ष है (`0` = `false`, `1` = `true`)   |
| `$t0-9`  | अस्थायी   | कोई भी   | अस्थायी भंडारण के लिए इस्तेमाल होता है            |
