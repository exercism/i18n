# परिचय

Gleam में रेगुलर एक्सप्रेशन **PCRE** विनिर्देश का पालन करते हैं। PCRE का मतलब है Perl के साथ संगत रेगुलर एक्सप्रेशन। दूसरी लोकप्रिय भाषाएँ भी यही तरीका अपनाती हैं, जैसे Java, JavaScript और Ruby।

रेगुलर एक्सप्रेशन के साथ काम करने के लिए `gleam/regex` मॉड्यूल में कई फंक्शन दिए गए हैं।

~~~~exercism/note
इस अभ्यास में यह मान लिया गया है कि आप रेगुलर एक्सप्रेशन का सिंटैक्स पहले से जानते हैं, जिसमें कैरेक्टर क्लास, क्वांटिफायर, ग्रुप और कैप्चर शामिल हैं।

अगर आपको अपना रेगुलर एक्सप्रेशन ज्ञान ताज़ा करना है, तो इनमें से कोई एक स्रोत देखिए: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

रेगुलर एक्सप्रेशन बनाने का सबसे आम तरीका `regex.from_string` फंक्शन का इस्तेमाल करना है।

```gleam
let assert Ok(re) = regex.from_string("test")
```

अगर रेगुलर एक्सप्रेशन का सिंटैक्स गलत हो, तो `regex.from_string` फंक्शन `Error` लौटाता है, इसलिए यहाँ let-assertion का इस्तेमाल करके यह पक्का किया गया है कि रेगुलर एक्सप्रेशन सही है।

किसी स्ट्रिंग से रेगुलर एक्सप्रेशन का मेल होता है या नहीं, यह जाँचने के लिए `regex.check` फंक्शन का इस्तेमाल किया जा सकता है।

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## कैप्चर

अगर आप किसी रेगुलर एक्सप्रेशन से सबस्ट्रिंग कैप्चर करना चाहते हैं, तो `regex.scan` फंक्शन मैचों का ऐरे लौटा सकता है।

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## मॉडिफायर

रेगुलर एक्सप्रेशन का व्यवहार बदलने के लिए आप उसे `regex.compile` फंक्शन से बनाते हैं और साथ में ऑप्शन देते हैं।

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
