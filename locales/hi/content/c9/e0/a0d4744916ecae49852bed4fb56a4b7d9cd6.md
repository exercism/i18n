# फ्लोटिंग पॉइंट संख्याएँ

PHP में फ्लोटिंग पॉइंट संख्याओं का इस्तेमाल वास्तविक संख्याओं के एक उपसमुच्चय को दर्शाने के लिए किया जाता है। इनमें एक या अधिक अंक होते हैं, जिनके बीच एक दशमलव चिह्न होता है।

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## आम गलतियाँ

फ्लोटिंग पॉइंट संख्याओं की मदद से हर संख्या और हर अंकगणितीय संक्रिया नहीं की जा सकती। डॉलर और सेंट दर्शाने के लिए फ्लोटिंग पॉइंट संख्याओं का इस्तेमाल करने पर राउंडिंग एरर हो सकती है।

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
