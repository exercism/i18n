# परिचय

कुछ तर्क को बार-बार चलाने के लिए `for` लूप सबसे ज़्यादा इस्तेमाल किए जाने वाले स्टेटमेंट में से एक है।
JavaScript में यह `for` कीवर्ड, गोल ब्रैकेट के अंदर लिखे एक _हेडर_ और घुंघराले ब्रैकेट के अंदर लिखे एक कोड ब्लॉक से बनता है। इस कोड ब्लॉक में लूप की _बॉडी_ रहती है।

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

इनिशियलाइज़ेशन आम तौर पर एक काउंटर वेरिएबल तैयार करता है, शर्त यह जाँचती है कि लूप जारी रहना चाहिए या रुक जाना चाहिए, और स्टेप हर चक्कर के अंत में काउंटर को बढ़ाता है।
हेडर के अलग-अलग हिस्सों को सेमीकोलन से अलग किया जाता है।

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
