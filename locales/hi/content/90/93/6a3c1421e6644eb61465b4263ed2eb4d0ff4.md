# परिचय

[रिकॉर्ड][records] एक साथ रखे जाने वाले फील्ड का संग्रह होता है, जिनके टाइप अलग-अलग हो सकते हैं। [रिकॉर्ड बनाने][define] के लिए `type` कीवर्ड का उपयोग किया जाता है। रिकॉर्ड के फील्ड `{` और `}` के बीच लिखे जाते हैं, और हर फील्ड का एक नाम _और_ एक टाइप होता है।

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

[रिकॉर्ड बनाने][create] के लिए फील्ड के नाम लिखिए और उन्हें `{` और `}` के बीच एक वैल्यू असाइन कीजिए। रिकॉर्ड बनाते समय उसके सभी फील्ड को एक वैल्यू असाइन करना ज़रूरी है। फील्ड किसी भी क्रम में लिखे जा सकते हैं; उनका क्रम रिकॉर्ड टाइप की परिभाषा के क्रम से मेल खाना ज़रूरी नहीं है। किसी रिकॉर्ड इंस्टेंस के फील्ड की वैल्यू पढ़ने के लिए डॉट नोटेशन का उपयोग किया जाता है।

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

रिकॉर्ड बनाते समय हर फील्ड या तो अलग लाइन पर होना चाहिए, या एक ही लाइन पर होने पर सेमीकोलन (`;`) से अलग किया जाना चाहिए:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

अगर किसी रिकॉर्ड के फील्ड के नाम यूनीक हैं, तो टाइप एनोटेशन ज़रूरी नहीं हैं, क्योंकि कंपाइलर खुद टाइप का अनुमान लगा लेगा। अगर फील्ड के नामों का संयोजन _यूनीक नहीं_ है, तो आप कंपाइलर की मदद कर सकते हैं, ताकि वह सही रिकॉर्ड चुन सके: या तो रिकॉर्ड बाइंडिंग के लिए स्पष्ट टाइप लिखिए, या एक या अधिक फील्ड के आगे रिकॉर्ड का टाइप लगाइए।

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

रिकॉर्ड अपरिवर्तनीय होते हैं, इसलिए एक बार रिकॉर्ड बन जाने के बाद उसके फील्ड की वैल्यू कभी नहीं बदल सकती। अगर आप किसी रिकॉर्ड की वैल्यू बदलना चाहते हैं, तो `with` कीवर्ड आपको [किसी मौजूदा रिकॉर्ड की कॉपी बनाने देता है, जिसमें एक या अधिक फील्ड की वैल्यू नई होती है][create]।

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

रिकॉर्ड में [_संरचनात्मक समानता_][equality] होती है, यानी एक ही रिकॉर्ड के दो इंस्टेंस, जिनकी वैल्यू बिल्कुल समान हों, एक जैसे माने जाते हैं:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

रिकॉर्ड के फील्ड पढ़ने के लिए डॉट नोटेशन के अलावा, रिकॉर्ड को बाइंडिंग और पैटर्न मैचिंग में [रिकॉर्ड पैटर्न][record-patterns] की मदद से _डीकंस्ट्रक्ट_ भी किया जा सकता है:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
