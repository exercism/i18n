# परिचय

## टर्नरी ऑपरेटर

_टर्नरी ऑपरेटर_ सरल _if/else_ स्टेटमेंट के लिए एक हल्का और छोटा विकल्प है।
आम तौर पर इसका इस्तेमाल लौटाने वाले स्टेटमेंट में होता है, लेकिन यह सिर्फ उन्हीं तक सीमित नहीं है। निर्णय लेने के लिए इसे सिर्फ एक ही लाइन चाहिए। अगर एक्सप्रेशन `true` है तो यह बाईं ओर की वैल्यू लौटाता है, और अगर `false` है तो दाईं ओर की वैल्यू लौटाता है, जैसा कि नीचे दिखाया गया है:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

बहुत सारे सरल _if/else_ एक्सप्रेशन को _टर्नरी ऑपरेटर_ की मदद से और आसान बनाया जा सकता है।
