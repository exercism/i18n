# कमेंट के बारे में

Go में कमेंट लिखने के लिए [बेहतरीन दिशानिर्देश](https://golang.org/doc/effective_go.html) हैं। डॉक्यूमेंटेशन कमेंट के लिए एक मानक प्रारूप है, जिसे `godoc` टूल अपने आप सुंदर डॉक्यूमेंटेशन में बदल सकता है।

पैकेज कमेंट `Package` शब्द से शुरू होना चाहिए, और उसके बाद पैकेज का नाम आना चाहिए, जैसे:

```go
// Package cook provides handy conversion methods for units typically used in recipes.
package cook
```

एक्सपोर्ट किए गए फंक्शन, मेथड, कॉन्स्टेंट और पैकेज वेरिएबलो के लिए कमेंट नाम से शुरू होना चाहिए, और उसके बाद एक क्रिया वाक्यांश आना चाहिए:

```go
// TbsToMl converts tablespoons to milliliters.
func TbsToMl(tbs int) int {
	// ...
}
```

[CodeReviewComments](https://github.com/golang/go/wiki/CodeReviewComments#comment-sentences) विकी आगे बताती है कि डॉक कमेंट पूरे वाक्य होने चाहिए, और उनके अंत में पूर्ण विराम लगना चाहिए।

कोड को पढ़ने में आसान बनाने के अलावा, इन सिफारिशों का पालन करने से आपका कोड [Go के डॉक्यूमेंटेशन टूल](http://whipperstacker.com/2015/09/30/go-documentation-godoc-godoc-godoc-org-and-go-doc/) में भी बेहतर दिखता है, जैसे [godoc.org](http://godoc.org), `godoc` और `go doc`.

आधिकारिक स्टाइल गाइड [Effective Go](https://golang.org/doc/effective_go.html) में डॉक कमेंट पर दिया गया हिस्सा पढ़ने के लिए थोड़ा समय निकालिए। इससे आपको पता चलेगा कि इन चुनावों के पीछे क्या सोच है।
