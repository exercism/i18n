# विवरण

## C++ में `auto` कीवर्ड

C++ में `auto` कीवर्ड एक शक्तिशाली सुविधा है, जिसे C++11 में जोड़ा गया था। इसका उपयोग ऐसे वेरिएबल घोषित करने के लिए किया जाता है जिनका डेटा टाइप अनुमान से तय होता है। कंपाइलर वेरिएबल के इनिशियलाइज़र के आधार पर उसका टाइप अनुमान लगाता है। इससे कोड पढ़ने में आसान और बनाए रखने में सरल हो जाता है।

## उदाहरण

इस उदाहरण को देखिए, जिसमें `auto` से वेरिएबल घोषित किए गए हैं:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

हर मामले में वेरिएबल का टाइप उस वैल्यू से अनुमान लगाया जाता है जिससे उसे शुरू किया गया है।

## टाइप अनुमान

`auto` कीवर्ड स्पष्ट टाइप लिखने की लंबाई घटाकर कोड को छोटा और पढ़ने में आसान बनाता है।

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

इस उदाहरण में `auto` `purple_wedding_pie` का टाइप `std::vector<std::string>` मान लेता है, जिससे टाइप को दोबारा स्पष्ट रूप से लिखने की ज़रूरत नहीं पड़ती।

## कंपैटिबिलिटी

`auto` कीवर्ड C++ के कई तरह के कोड के साथ काम करता है, जिससे यह आधुनिक C++ प्रोग्रामिंग में कई कामों में आने वाला टूल बन जाता है।

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

आगे के कॉन्सेप्ट में हम `auto` कीवर्ड को अक्सर लैम्ब्डा एक्सप्रेशन, रेंज-आधारित `for` लूप और इटरेटर के साथ देखेंगे।

## उपयोग के मामले

- **जेनेरिक प्रोग्रामिंग**: जेनेरिक प्रोग्रामिंग में, जहाँ टाइप जटिल हो सकते हैं या टेम्पलेट से जुड़े होते हैं, वहाँ `auto` खास तौर पर उपयोगी होता है।
- **जटिल डेटा टाइप**: जटिल डेटा टाइप या लंबे टाइप नामों के साथ काम करते समय `auto` कोड में भीड़ घटाता है और कोड को बनाए रखना आसान बनाता है।
- **इटरेटर पर आधारित एल्गोरिदम**: यह एल्गोरिदम में इटरेटर के इस्तेमाल को आसान बनाता है और कोड पढ़ने में आसान रहता है।
