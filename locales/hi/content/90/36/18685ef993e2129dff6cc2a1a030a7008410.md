# परिचय

## बुनियादी बातें

### वेरिएबल

Elixir एक डायनामिक टाइपिंग वाली भाषा है, यानी किसी वेरिएबल का टाइप केवल रनटाइम पर जाँचा जाता है। मैच `=` ऑपरेटर की मदद से हम किसी भी टाइप की वैल्यू को एक वेरिएबल के नाम से बाँध सकते हैं:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### मॉड्यूल

Elixir एक [फंक्शनल प्रोग्रामिंग भाषा][functional-programming] है और इसमें सभी नेम्ड फंक्शन को किसी _मॉड्यूल_ के अंदर बनाना ज़रूरी होता है। मॉड्यूल बनाने के लिए `defmodule` कीवर्ड का उपयोग किया जाता है। रनटाइम पर सभी मॉड्यूल हर दूसरे मॉड्यूल के लिए उपलब्ध रहते हैं और प्रोग्राम के बाकी हिस्सों तक उन्हें दिखाने के लिए किसी _एक्सेस मॉडिफायर_ की ज़रूरत नहीं पड़ती। एक _मॉड्यूल_ दूसरी प्रोग्रामिंग भाषाओं की _क्लास_ जैसा होता है।

```elixir
defmodule Calculator do
  # ...
end
```

### नेम्ड फंक्शन

_नेम्ड फंक्शन_ को किसी मॉड्यूल के अंदर ही बनाना होता है। _पब्लिक_ नेम्ड फंक्शन बनाने के लिए `def` कीवर्ड का उपयोग किया जाता है।

हर फंक्शन में शून्य या उससे अधिक आर्गुमेंट हो सकते हैं। फंक्शन के अंदर अंतिम एक्सप्रेशन की वैल्यू हमेशा _अपने आप लौटा दी जाती है_।

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

किसी फंक्शन को कॉल करने के लिए उसका मॉड्यूल, फंक्शन का नाम, और फंक्शन के हर आर्गुमेंट के लिए एक वैल्यू लिखनी होती है।

```elixir
sum = Calculator.add(1, 2)
# => 3
```

_प्राइवेट_ फंक्शन बनाने के लिए `def` की जगह `defp` कीवर्ड का उपयोग किया जा सकता है। प्राइवेट फंक्शन का उपयोग केवल उसी मॉड्यूल के अंदर से किया जा सकता है जिसने उन्हें बनाया हो।

जब किसी फंक्शन को उसी मॉड्यूल के अंदर कॉल किया जाता है जिसमें वह बना है, तो मॉड्यूल का नाम छोड़ा जा सकता है।

आप छोटे फंक्शन एक लाइन वाले सिंटैक्स में भी लिख सकते हैं (ध्यान दीजिए कि कीवर्ड `do` के दोनों ओर कॉमा `,` और कोलन `:` हैं)।

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### फंक्शन की आरिटी

फंक्शन को उनकी _आरिटी_ के साथ बताना आम बात है। किसी फंक्शन की _आरिटी_ उन आर्गुमेंट की संख्या होती है जो वह लेता है।

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### नामकरण की परंपराएँ

मॉड्यूल के नाम में `PascalCase` इस्तेमाल करना चाहिए। मॉड्यूल के नाम की शुरुआत बड़े अक्षर `A-Z` से होनी चाहिए और उसमें अक्षर `a-zA-Z`, संख्याएँ `0-9`, और अंडरस्कोर `_` हो सकते हैं।

वेरिएबल और फंक्शन के नाम में `snake_case` इस्तेमाल करना चाहिए। वेरिएबल या फंक्शन के नाम की शुरुआत छोटे अक्षर `a-z` या अंडरस्कोर `_` से होनी चाहिए, उसमें अक्षर `a-zA-Z`, संख्याएँ `0-9`, और अंडरस्कोर `_` हो सकते हैं, और अंत में प्रश्नवाचक चिह्न `?` या विस्मयादिबोधक चिह्न `!` हो सकता है।

### स्टैंडर्ड लाइब्रेरी

Elixir की स्टैंडर्ड लाइब्रेरी बहुत विशाल और अच्छी तरह डॉक्युमेंटेड है। इसका डॉक्युमेंटेशन [hexdocs.pm/elixir][docs] पर ऑनलाइन उपलब्ध है। इस लिंक को कहीं सहेज लीजिए। आप इसका बहुत इस्तेमाल करेंगे!

ज़्यादातर बिल्ट-इन डेटा टाइप के लिए एक संबंधित मॉड्यूल होता है जिसमें उस डेटा टाइप पर काम करने वाले फंक्शन होते हैं, जैसे पूर्णांक के लिए `Integer` मॉड्यूल, स्ट्रिंग के लिए `String` मॉड्यूल, ऐरे के लिए `List` मॉड्यूल, इत्यादि।

एक खास मॉड्यूल `Kernel` मॉड्यूल है। यह वे बुनियादी क्षमताएँ देता है जिन पर बाकी पूरी स्टैंडर्ड लाइब्रेरी बनी है, जैसे अंकगणितीय ऑपरेटर, कंट्रोल-फ्लो मैक्रो, और बहुत कुछ। `Kernel` मॉड्यूल के फंक्शन अपने आप इंपोर्ट हो जाते हैं, इसलिए आप उन्हें `Kernel.` लिखे बिना इस्तेमाल कर सकते हैं।
