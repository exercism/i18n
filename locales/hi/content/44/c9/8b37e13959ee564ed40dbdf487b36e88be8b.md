# परिचय

Elixir [_बिहेवियर_][behaviours] का इस्तेमाल करके एक जैसे सामान्य इंटरफेस देता है, और साथ ही हर उस मॉड्यूल के लिए उसका अपना खास कार्यान्वयन लिखने की सुविधा भी देता है जो उस बिहेवियर को लागू करता है। इन्हीं बिहेवियर में से एक है _एक्सेस बिहेवियर_।

_एक्सेस बिहेवियर_ किसी डेटा स्ट्रक्चर से की के आधार पर डेटा निकालने के लिए एक सामान्य इंटरफेस देता है। इसे मैप और कीवर्ड लिस्ट के लिए लागू किया गया है।

[`Access`][access] मॉड्यूल उस इंटरफेस के लिए ज़रूरी कॉलबैक तय करता है। फिर [`Map`][map] और [`Keyword`][keyword] मॉड्यूल ज़रूरी कॉलबैक [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] और [`pop/2`][map-pop] लागू करते हैं।

इस बिहेवियर का उपयोग करने के लिए आप किसी बाउंड वेरिएबल के आगे _चौकोर ब्रैकेट_ लगाते हैं और फिर उस की से उससे जुड़ी वैल्यू निकाल लेते हैं। मैप में किसी भी टाइप की की हो सकती है, जबकि कीवर्ड लिस्ट में सिर्फ एटम की।

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

अगर डेटा स्ट्रक्चर में वह की मौजूद नहीं है, तो `nil` लौटाया जाता है। यह अनचाहे व्यवहार की वजह बन सकता है, क्योंकि इससे कोई एरर नहीं उठती।

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

ध्यान दीजिए कि `nil` खुद भी एक्सेस बिहेवियर लागू करता है और किसी भी की के लिए हमेशा `nil` ही लौटाता है।

```elixir
nil[:key]
# => nil
```

स्ट्रक्चर एक्सेस बिहेवियर लागू नहीं करते।
