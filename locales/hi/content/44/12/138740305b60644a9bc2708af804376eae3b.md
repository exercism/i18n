# परिचय

किसी क्लास का इंस्टेंस बनाने के लिए `new` ऑपरेटर के ज़रिए उसका [_कंस्ट्रक्टर_][constructor] कॉल किया जाता है। कंस्ट्रक्टर किसी क्लास के अंदर एक खास मेथड होता है, जिसका उद्देश्य क्लास को इनिशलाइज़ करना है। Haxe में कंस्ट्रक्टर मेथड का नाम `new()` होता है।

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

आम मेथड की तरह कंस्ट्रक्टर में भी पैरामीटर हो सकते हैं। ये पैरामीटर (आम तौर पर) प्राइवेट फील्ड में संग्रहीत किए जाते हैं और बाद में इस्तेमाल होते हैं।

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

अगर किसी क्लास में कंस्ट्रक्टर नहीं है, तो आप उसका नया इंस्टेंस **नहीं** बना सकते। इसलिए खाली कंस्ट्रक्टर इस्तेमाल करना ही एकमात्र तरीका है।

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```

[constructor]: https://haxe.org/manual/types-class-constructor.html
