# निर्देश

RNA के अनुक्रमों का प्रोटीन में अनुवाद कीजिए।

RNA को तीन न्यूक्लियोटाइड वाले अनुक्रमों में तोड़ा जा सकता है, जिन्हें कोडॉन कहते हैं। फिर इनका प्रोटीन में अनुवाद इस तरह होता है:

RNA: `"AUGUUUUCU"` => इसका अनुवाद होता है

कोडॉन: `"AUG", "UUU", "UCU"`
=> जिनसे निम्नलिखित अनुक्रम वाला प्रोटीन बनता है =>

प्रोटीन: `"Methionine", "Phenylalanine", "Serine"`

कुल 64 कोडॉन होते हैं, जो बदले में 20 अमीनो अम्लों से मेल खाते हैं। लेकिन इस अभ्यास में सभी कोडॉन अनुक्रम और उनसे बनने वाले सभी अमीनो अम्ल महत्वपूर्ण नहीं हैं।
अगर प्रोग्राम एक कोडॉन के लिए काम करता है, तो उसे सभी के लिए काम करना चाहिए।
लेकिन अगर आप चाहें, तो टेस्ट सूट की सूची बढ़ाकर उन सभी को शामिल कर सकते हैं।

तीन ऐसे कोडॉन भी होते हैं जो अनुवाद को समाप्त कर देते हैं (इन्हें 'STOP' कोडॉन भी कहा जाता है)। अगर इनमें से कोई भी कोडॉन सामने आ जाए (राइबोसोम के ज़रिए), तो पूरा अनुवाद वहीं रुक जाता है और प्रोटीन का निर्माण बंद हो जाता है।

इसके बाद आने वाले सभी कोडॉन अनदेखा कर दिए जाते हैं, जैसे:

RNA: `"AUGUUUUCUUAAAUG"` =>

कोडॉन: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

प्रोटीन: `"Methionine", "Phenylalanine", "Serine"`

ध्यान दीजिए कि STOP कोडॉन `"UAA"` अनुवाद को रोक देता है और अंतिम Methionine प्रोटीन अनुक्रम में शामिल नहीं होता।

नीचे इस अभ्यास के लिए आवश्यक कोडॉन और उनसे बनने वाले अमीनो अम्ल दिए गए हैं।

| कोडॉन              | अमीनो अम्ल    |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

[विकिपीडिया पर प्रोटीन अनुवाद][protein-translation] के बारे में और पढ़िए।
