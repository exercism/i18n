# निर्देश

इस अभ्यास में आप उन प्रोग्रामिंग भाषाओं के ऐरे को संसाधित करने के लिए कोड लिखेंगे जिनका अभ्यास आप Exercism प्लेटफॉर्म से करने की योजना बना रहे हैं।

आपके सामने छह काम हैं।

## 1. एक नया ऐरे बनाइए

भाषाएँ जोड़ने से पहले आपको एक नया ऐरे बनाकर शुरू करना होगा। ऐसा फंक्शन बनाइए जो एक खाली ऐरे लौटाता है।

```clojure
(new-list)
;; => ()
```

## 2. ऐरे में एक नई भाषा जोड़िए

जैसे-जैसे आप Exercism को खोजते हैं और ऐसी भाषाएँ ढूँढते हैं जो आप सीखना चाहते हैं, आपको उन्हें अपने ऐरे में जोड़ पाना होगा। अपने ऐरे के शुरू में एक नई भाषा जोड़ने के लिए एक फंक्शन बनाइए।

```clojure
(add-language '("Clojurescript") "JavaScript")
;; => '("JavaScript" "Clojurescript")
```

## 3. सबसे बाद में जोड़ी गई भाषा जाँचिए

आप जल्दी से जाँचना चाहेंगे कि आपने अभी-अभी कौन-सी भाषा जोड़ी। ऐसा फंक्शन बनाइए जो आपके ऐरे से पहली भाषा लौटाता है।

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. ऐरे से पहली भाषा हटाइए

कभी-कभी आप अपनी अभी जोड़ी गई भाषा के बारे में अपना मन बदल लेंगे। अपने ऐरे से पहली भाषा हटाने के लिए एक फंक्शन बनाइए।

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. ऐरे में भाषाओं की गिनती कीजिए

भाषाओं को एक-एक करके गिनना सुविधाजनक नहीं है। अपने ऐरे में भाषाओं की संख्या गिनने के लिए फंक्शन बनाइए।

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. सब कुछ एक साथ मिलाइए

एक `learning-list` फंक्शन बनाइए, जिसके अंदर आप ऊपर बनाए गए कुछ फंक्शन इस्तेमाल करेंगे।

- एक खाली ऐरे बनाइए
- ऐरे में 2 नई प्रोग्रामिंग भाषाएँ जोड़िए।

  - "Clojure"
  - "Lisp"

- ऐरे से "Lisp" हटा दीजिए, क्योंकि हो सकता है कि साल भर के लिए आपके पास पूरा समय न हो, और यह Clojure से काफी मिलती-जुलती है।
- ऐरे में 2 और प्रोग्रामिंग भाषाएँ जोड़िए।

  - "Java"
  - "JavaScript"

- भाषाओं की कुल संख्या लौटाइए। संकेत: यह 3 होनी चाहिए।

```clojure
(learning-list)
;; => 3
```
