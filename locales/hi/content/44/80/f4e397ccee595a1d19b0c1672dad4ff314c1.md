# इंस्टॉलेशन

अपने सिस्टम पर सब कुछ सेट करने के निर्देशों के लिए [System/Installation][install-link] देखिए।

~~~exercism/caution
अगर आपके सिस्टम पर Java Development Kit (JDK) इंस्टॉल है, तो `jconsole` एक्ज़ीक्यूटेबल का Java Console से टकराव हो सकता है, क्योंकि दोनों का नाम एक ही है।

इसके कुछ संभावित हल ये हैं:

- J प्रोग्रामिंग भाषा के `jconsole` एक्ज़ीक्यूटेबल का नाम बदलकर कुछ अनोखा रखिए (जैसे `jconsole-jlang`)।

- अपने सिस्टम के एनवायरनमेंट वेरिएबल या PATH को इस तरह बदलिए कि J प्रोग्रामिंग भाषा के `jconsole` को प्राथमिकता मिले।

- **Linux उपयोगकर्ताओं के लिए**, `bin/install.sh` पर एक bash स्क्रिप्ट मौजूद है, जो `/usr/` डायरेक्टरी में `ijconsole` नाम का एक **सिम्बॉलिक लिंक** बनाएगी। आप अपने टर्मिनल पर `ijconsole` टाइप करके इस लिंक का इस्तेमाल कर सकते हैं।
~~~

J इंस्टॉल हो जाने के बाद, अपने टर्मिनल पर एक J कंसोल खोलिए और यूनिट टेस्ट फ्रेमवर्क इंस्टॉल करने के लिए नीचे दिए गए कमांड दर्ज कीजिए:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
