# परिचय

Go में बूलियन को पहले से घोषित बूलियन टाइप `bool` से दर्शाया जाता है, और इसकी वैल्यू `true` या `false` हो सकती है।
यह एक परिभाषित टाइप है।

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go तीन लॉजिकल ऑपरेटर का समर्थन करता है। ये एक्सप्रेशन को जाँचकर बूलियन वैल्यू देते हैं, यानी `true` या `false` लौटाते हैं।

| ऑपरेटर    | इसका क्या मतलब है                                 |
| ----------- | --------------------------------------------- |
| `&&` (और)  | दोनों दावे सही हों, तभी यह सही होता है।       |
| `\|\|` (या) | कम से कम एक दावा सही हो, तो यह सही होता है। |
| `!` (नहीं)   | यह तभी सही होता है जब दावा गलत हो।    |
