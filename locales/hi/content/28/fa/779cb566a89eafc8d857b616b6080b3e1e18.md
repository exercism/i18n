# परिचय

Ruby में **ऐरे** किसी भी ऑब्जेक्ट का क्रमबद्ध संग्रह होते हैं, जिनके इंडेक्स पूर्णांक होते हैं।
ऐरे में इंडेक्स `0` से शुरू होता है।
ऋणात्मक इंडेक्स ऐरे के अंत के सापेक्ष माना जाता है। यानी इंडेक्स `-1` ऐरे के अंतिम एलिमेंट को दिखाता है, `-2` अंत से दूसरे एलिमेंट को, और इसी तरह आगे भी।
Ruby के ऐरे [Enumerable मॉड्यूल][enumerable-module] को अपने में शामिल कर लेते हैं। इससे ऐरे में हर एलिमेंट पर एक-एक करके चलने और खोजने के कई मेथड जुड़ जाते हैं, साथ ही ऐरे को सॉर्ट करने की सुविधा भी मिलती है।

## ऐरे बनाना

- Ruby के ऐरे में अलग-अलग टाइप के ऑब्जेक्ट रह सकते हैं।

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## एलिमेंट असाइन करना

इंडेक्स की मदद से एलिमेंट तक पहुँचा जा सकता है और उन्हें बदला भी जा सकता है।
शुरुआती इंडेक्स और साइज़ बताकर सब-ऐरे तक पहुँचा जा सकता है।

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- ऋणात्मक इंडेक्स ऐरे के अंत से उलटी दिशा में गिने जाते हैं।

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## एलिमेंट निकालना

- ऐरे के एलिमेंट #[] मेथड की मदद से निकाले जा सकते हैं।
- यह दिए गए इंडेक्स पर मौजूद एलिमेंट लौटाता है। अगर शुरुआती इंडेक्स और लंबाई दी जाए, तो यह उस इंडेक्स से शुरू होकर उतने एलिमेंट वाला सब-ऐरे लौटाता है।

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- ऋणात्मक इंडेक्स ऐरे के अंत से उलटी दिशा में गिने जाते हैं (-1 अंतिम एलिमेंट है)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## ऐरे के बारे में जानकारी लेना

ऐरे हर समय अपनी लंबाई का ध्यान रखते हैं।
ऐरे में कितने एलिमेंट हैं, यह पता करने के लिए length, count या size का इस्तेमाल कीजिए।

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## ऐरे में आइटम जोड़ना

आइटम ऐरे के अंत में `push` या `<<` की मदद से जोड़े जा सकते हैं:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## ऐरे से आइटम हटाना

pop मेथड ऐरे का अंतिम एलिमेंट हटाता है और उसे लौटा देता है:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
