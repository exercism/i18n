# निर्देश

आप जहाज़ के पर्सर हैं और पेंट्री की इन्वेंटरी संभालते हैं। इन्वेंटरी एक हैशटेबल है। इसमें हर की एक चीज़ का नाम होती है और उसकी वैल्यू बताती है कि भंडार में उस चीज़ की कितनी मात्रा मौजूद है।

## 1. एक सूची से इन्वेंटरी बनाइए

`create-inventory` बनाइए, जो चीज़ों के नामों का एक सीक्वेंस लेता है और एक हैशटेबल लौटाता है, जो हर अलग नाम को उसकी गिनती के साथ जोड़ता है।

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. और चीज़ें जोड़िए

`add-items` बनाइए, जो एक इन्वेंटरी और चीज़ों का एक सीक्वेंस लेता है और एक नई इन्वेंटरी लौटाता है, जिसमें सूची की हर चीज़ की गिनती बढ़ा दी गई हो। मूल इन्वेंटरी में कोई बदलाव नहीं होना चाहिए।

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. गिनती घटाइए

`decrement-items` बनाइए, जो एक इन्वेंटरी और चीज़ों का एक सीक्वेंस लेता है और एक नई इन्वेंटरी लौटाता है, जिसमें सूची की हर चीज़ की गिनती एक-एक कम कर दी गई हो। गिनती कभी भी शून्य से नीचे नहीं जानी चाहिए, और जो चीज़ें पहले से इन्वेंटरी में नहीं हैं उन्हें छोड़ देना चाहिए (ऋणात्मक प्रविष्टियाँ दर्ज नहीं की जाती हैं)।

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. किसी चीज़ को पूरी तरह हटाइए

`remove-item` बनाइए, जो एक इन्वेंटरी और एक चीज़ लेता है और उस चीज़ को हटाकर एक नई इन्वेंटरी लौटाता है। अगर वह चीज़ मौजूद न हो, तो बिना बदली हुई एक प्रति लौटाइए।

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. उपलब्ध चीज़ों की सूची बनाइए

`list-inventory` बनाइए, जो एक इन्वेंटरी लेता है और `{ name quantity }` जोड़ों का एक ऐरे लौटाता है। उसमें सिर्फ़ वे चीज़ें होंगी जिनकी मात्रा शून्य से अधिक है, और उसे नाम के अक्षर-क्रम में लगाया गया होगा।

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
