# परिचय

दशमलव संख्याएँ ऐसी संख्याएँ होती हैं जिनमें दशमलव चिह्न के बाद एक या अधिक अंक होते हैं।

```gleam
let float = 3.45
// -> 3.45
```

दशमलव संख्याओं के भी अपने ऑपरेटर होते हैं।

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```
