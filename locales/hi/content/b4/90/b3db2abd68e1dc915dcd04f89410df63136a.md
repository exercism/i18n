# परिचय

## प्रॉपर्टी

C# में प्रॉपर्टी क्लास का एक सदस्य होती है, जो उस क्लास के अंदर मौजूद डेटा तक पहुँच देती है। इसे कॉल करने वाला कोड उस डेटा को सेट कर सकता है या प्राप्त (get) कर सकता है। प्रॉपर्टी या तो ऑटो-इम्प्लीमेंटेड हो सकती है, या उसके पीछे एक बैकिंग फील्ड होता है। इनमें एक set एक्सेसर और/या एक get एक्सेसर होता है। कुछ अन्य भाषाओं में म्यूटेटर लगभग set एक्सेसर जैसा होता है और एक्सेसर लगभग get एक्सेसर जैसा, हालाँकि इन दोनों के सिंटैक्स की बनावट बिल्कुल अलग होती है।

किसी प्रॉपर्टी को सेट करते समय इनपुट वैल्यू की जाँच की जा सकती है, उसे फॉर्मेट किया जा सकता है, या किसी और तरीके से बदला जा सकता है। वास्तव में, क्लास के कोड के लिए उपलब्ध कोई भी प्रोग्रामेटिक काम किया जा सकता है।

इसी तरह, प्रॉपर्टी से डेटा प्राप्त करते समय डेटा की गणना या फॉर्मेटिंग की जा सकती है, और यहाँ भी क्लास के लिए उपलब्ध कोई भी प्रोग्रामेटिक काम किया जा सकता है।

प्रॉपर्टी में भी बाकी क्लास सदस्यों की तरह एक्सेस मॉडिफायर (`public`, `private` आदि) होते हैं, लेकिन set एक्सेसर का एक्सेस लेवल get एक्सेसर से स्वतंत्र हो सकता है, और इसका उलटा भी। यह ज़रूरी नहीं कि प्रॉपर्टी में दोनों एक्सेसर हों; उसमें सिर्फ एक भी हो सकता है (या get, या set)।

प्रॉपर्टी लिखने के लिए बुनियादी सिंटैक्स दो रूपों में हो सकता है:

### फील्ड/एक्सप्रेशन पर आधारित प्रॉपर्टी:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### ऑटो-इम्प्लीमेंटेड प्रॉपर्टी

```
public int MyProperty { get; private set; } = 42;
```

इनिशियलाइज़ेशन ज़रूरी नहीं है।
