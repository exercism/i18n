# अधिक जानकारी

Gleam में कॉन्स्टेंट वैल्यू को नाम देने का तरीका हैं। इन्हें `const` कीवर्ड से बनाया जाता है।

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

जब किसी मॉड्यूल कॉन्स्टेंट को `pub` कीवर्ड के साथ बनाया जाता है, तो उसे दूसरे मॉड्यूल से भी इस्तेमाल किया जा सकता है। अन्यथा उसे केवल उसी मॉड्यूल के अंदर इस्तेमाल किया जा सकता है जिसमें वह बनाया गया है।
