# विवरण

सेट एक अपरिवर्तनीय संग्रह है जिसमें हर वैल्यू अद्वितीय होती है और कोई क्रम नहीं होता। सेट के सभी एलिमेंट एक ही डेटा टाइप के होने चाहिए।

`gleam/set` मॉड्यूल `Set` टाइप को परिभाषित करता है और सेटों के साथ काम करने के लिए फंक्शन देता है।

आप `set.to_list` और `set.from_list` की मदद से ऐरे और सेटों को एक-दूसरे में बदल सकते हैं। सेट में एलिमेंट के क्रम की गारंटी नहीं होती।

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

आप `set.new`, `set.insert` और `set.delete` की मदद से सेट बना सकते हैं और उनमें एलिमेंट डाल सकते हैं।

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

आप `set.contains` और `set.size` फंक्शनों की मदद से सेट में क्या-क्या है और उसमें कितने एलिमेंट हैं, यह जान सकते हैं।

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

आप सेटों को `set.union` और `set.intersect` की मदद से मिला सकते हैं।

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

आप सेटों को फिल्टर कर सकते हैं।

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
