# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग     | टाइप    | विवरण                                                                                 |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | इनपुट     | पूर्णांक | संख्या                                                                                |
| `$v0`    | आउटपुट    | पूर्णांक | वर्गीकरण (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`)         |
| `$t0-9`  | अस्थायी   | कोई भी   | अस्थायी भंडारण के लिए इस्तेमाल किया जाता है                                             |
