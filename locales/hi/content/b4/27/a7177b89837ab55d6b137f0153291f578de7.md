## वेरिएबल

वेरिएबलो ऐसे प्रतीकात्मक नाम होते हैं जो या तो वैल्यू को या कंटेनर को दर्शाते हैं।
वेरिएबलो के नाम किसी विशेष चिह्न, जिसे [सिगिल][sigils] कहते हैं, से शुरू हो सकते हैं या उसके बिना, और उसके बाद एक आइडेंटिफायर आता है।
सिगिल के बाद एक [ट्विगिल][twigils] भी आ सकता है।

अलग-अलग सिगिल वाले वेरिएबल अलग-अलग तरह के डेटा स्ट्रक्चर रखते हैं।

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

आप अक्सर जिन ट्विगिल को देखेंगे, वे `^` और `:` हैं, जो कोड ब्लॉक सिग्नेचर के लिए शॉर्टकट का काम करते हैं।
`^` पोज़िशनल पैरामीटर के लिए है।
`:` नेम्ड पैरामीटर के लिए है।

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## कंटेनर

कंटेनर की वजह से ही किसी वेरिएबल को बदला जा सकता है।

`constant` से घोषित वेरिएबलो, और बिना सिगिल वाले वेरिएबलो (जिन्हें आइडेंटिफायर से पहले `\` लगाकर घोषित किया जाता है), इनके पास कंटेनर नहीं होते और ये सीधे वैल्यू को दर्शाते हैं।

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## टाइप

वेरिएबलो को टाइप कंस्ट्रेंट के साथ घोषित किया जा सकता है।
टाइप कंस्ट्रेंट में कोर्शन भी हो सकते हैं, जिसके लिए मनचाहे टाइप को आर्गुमेंट के रूप में एक स्वीकार्य टाइप दिया जाता है।

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

टाइप कंस्ट्रेंट इस्तेमाल करना मल्टी-डिस्पैच रूटीन का फायदा उठाने का एक तरीका है।

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Raku में टाइप भी एक और तरह के ऑब्जेक्ट ही होते हैं।
`class`, `role`, या `enum` घोषित करना अपने खुद के टाइप ऑब्जेक्ट बनाने के तरीके हैं।
उदाहरण के लिए, बिल्ट-इन टाइप `Bool` एक enum से बना है: `enum Bool <False True>`।

आप `subset` कीवर्ड की मदद से दूसरे टाइपों पर आधारित सरल टाइप कंस्ट्रेंट भी बना सकते हैं।
आप `where` क्लॉज़ इस्तेमाल करके इस नए टाइप को और सीमित कर सकते हैं।
`where` क्लॉज़ का इस्तेमाल सिग्नेचर में भी किया जा सकता है।

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
