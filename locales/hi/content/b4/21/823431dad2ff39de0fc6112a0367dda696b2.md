# निर्देश

आप एक छोटी कंपनी का हिसाब-किताब रखते हैं, और हर दिन के लेन-देन बेतरतीब लाइनों के रूप में आते हैं। रेगुलर एक्सप्रेशन की मदद से आप राशियों की जाँच करेंगे, संख्याओं के आगे लगे प्रतीक को पहचानकर उन्हें निकालेंगे, और ऐसी लाइनों को चिह्नित करेंगे जिन पर और ध्यान देने की ज़रूरत है।

## 1. राशि की जाँच कीजिए

एक सही ढंग से लिखी राशि में एक `$`, एक या अधिक अंक, और एक *वैकल्पिक* सेंट वाला हिस्सा होता है, जो एक बिंदु और ठीक दो अंकों से बनता है। जैसे `$100` या `$100.50` सही हैं, लेकिन `$100.5` नहीं। `valid-amount?` बनाइए, जो `t` लौटाता है जब *पूरी* स्ट्रिंग एक सही राशि हो।

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. डॉलर वाली संख्याएँ निकालिए

`dollar-amounts` बनाइए, जो लाइन में `$` के ठीक बाद आने वाली हर संख्या लौटाता है, यानी सिर्फ अंक, बिना `$` के, और उसी क्रम में।

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. प्रतिशत निकालिए

`percentages` बनाइए, जो हर उस संख्या को लौटाता है जिसके ठीक बाद `%` आता है।

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. किसी लाइन को चिह्नित कीजिए

`flagged?` बनाइए, जो `t` लौटाता है जब लाइन में `refund` या `chargeback` किसी भी तरह के बड़े-छोटे अक्षरों में लिखा हो।

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
