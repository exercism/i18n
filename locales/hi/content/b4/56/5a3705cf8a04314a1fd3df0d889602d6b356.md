# मदद

- StackOverflow पर `c++-faq` टैग
- isocpp.com से C++ FAQ
- CppReference, C++ भाषा और स्टैंडर्ड लाइब्रेरी के लिए एक विकी संदर्भ है
- C traps and pitfalls उनके लिए उपयोगी है जो C++ में नए हैं, लेकिन C में प्रोग्रामिंग करना जानते हैं
