# क्लास

क्लास PHP में कोड को व्यवस्थित करने की एक इकाई है।
किसी चीज़ का व्यवहार या किसी प्रक्रिया का व्यवहार दर्शाने वाले कोड को एक क्लास के रूप में एक साथ रखा जा सकता है।
किसी क्लास को सौंपे गए फंक्शन को परंपरा से `methods` कहा जाता है।

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

क्लास को `new` कीवर्ड से इंस्टैंशिएट किया जाता है। यह क्लास के इंस्टेंस के लिए मेमोरी आवंटित करता है और क्लास की कंस्ट्रक्टर मेथड को कॉल करता है।
इंस्टैंशिएट की गई क्लास को किसी वेरिएबल में रखा जा सकता है।
किसी क्लास इंस्टेंस की मेथड को कॉल करने के लिए हम `->` एक्सेस ऑपरेटर का उपयोग कर सकते हैं।

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

इंस्टैंशिएट की गई क्लास विशेष `$this` वेरिएबल की मदद से अपने ही इंस्टेंस को संदर्भित कर सकती है।
क्लास में प्रॉपर्टी भी हो सकती हैं। ये ऐसे वेरिएबल की तरह काम करती हैं जो क्लास ऑब्जेक्ट के इंस्टेंस से जुड़े रहते हैं।
इन प्रॉपर्टी को क्लास के अंदर से या बाहर से संदर्भित किया जा सकता है।

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
