# टेस्ट

## टेस्ट चलाना

टेस्ट चलाने के लिए यह कमांड चलाइए:

```bash
bats test-<exercise-slug>.bats
```

### bats, bash में लिखा गया है

bats फाइल एक bash स्क्रिप्ट है, जिसमें कुछ खास फंक्शन होते हैं जिन्हें `bats` कमांड पहचानता है।
आपको कुछ टेस्ट ऐसे दिखेंगे:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

यह `<<<` सिंटैक्स bash का *Here String* है।
यह दाईं ओर की स्ट्रिंग को बाईं ओर के प्रोग्राम के स्टैंडर्ड इनपुट में भेजता है।
यह लगभग इसके ही जैसा है:

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## स्किप किए गए टेस्ट

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना।
जब आप टेस्ट चलाते हैं, तो शुरू में सिर्फ एक ही टेस्ट (सबसे पहला) चलता है।
यह जानबूझकर ऐसा रखा गया है, ताकि आप अपना पूरा ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर लगा सकें।
वह पास हो जाए, तो आप अगला टेस्ट चालू कर सकते हैं। इसके लिए बाकी टेस्ट के आगे लगे इन एनोटेशन को कॉमेंट कर दीजिए या हटा दीजिए:

    [[ $BATS_RUN_SKIPPED == true ]] || skip

## स्किप को ओवरराइड करना

`skip` एनोटेशन वाले टेस्ट समेत सारे टेस्ट चलाने के लिए आप यह कमांड चला सकते हैं:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

या फिर टेस्ट फाइल से इस लाइन को कॉमेंट कर दीजिए या हटा दीजिए:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```
