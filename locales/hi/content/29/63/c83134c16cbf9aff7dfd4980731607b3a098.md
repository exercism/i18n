# परिचय

अन्य भाषाओं की तरह C++ में भी `switch` स्टेटमेंट होता है।
लंबे `if ... else if` स्टेटमेंट लिखने का छोटा तरीका `switch` स्टेटमेंट है।
switch बनाने के लिए हम `switch` कीवर्ड से शुरू करते हैं और उसके बाद एक पूर्णांक लिखते हैं।
फिर हम हर शर्त को `case` कीवर्ड से घोषित करते हैं।
हम एक `default` केस भी घोषित कर सकते हैं, जो तब चलेगा जब पहले की कोई भी `case` शर्त मेल नहीं खाती।
हर केस का अंत `break` (या `return`) स्टेटमेंट से होना चाहिए।

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## फॉल-थ्रू

switch कंस्ट्रक्ट की एक ज़रूरी बात यह है कि कोड तब तक चलता रहता है जब तक कोई `break` (या `return`) स्टेटमेंट उसे रोक न दे।
इससे अनपेक्षित व्यवहार हो सकता है।

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

कोड के इस तरह चलते रहने की सुविधा का मुख्य उपयोग ऐसे स्टेटमेंट में होता है जिस पर कई लेबल लगे हों।
कई switch परिणामों के लिए एक ही कोड चलाया जा सकता है।
इस तरह, उदाहरण के लिए किसी बुकिंग ऐप में, ग्रुप साइज़ 2 और 3 के लिए कॉल किया जाने वाला फंक्शन एक ही हो सकता है:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
