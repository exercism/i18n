# परिचय

## व्याख्या

JavaScript में `number` और `string` जैसे प्रिमिटिव डेटा टाइप के अलावा एक और ज़रूरी डेटा टाइप होता है, जिसे `object` कहते हैं।
ऑब्जेक्ट की-वैल्यू जोड़ों के संग्रह होते हैं।
दूसरी भाषाओं में इन्हें अक्सर मैप या डिक्शनरी कहा जाता है, और इनका इस्तेमाल भी वैसे ही किया जा सकता है।

दूसरी भाषाओं में मैप की सारी वैल्यू का डेटा टाइप अक्सर एक ही होना चाहिए।
JavaScript में सिर्फ की का टाइप बँधा हुआ है: वह `string` ही होनी चाहिए।
एक ही ऑब्जेक्ट के अंदर की वैल्यू अलग-अलग टाइप की हो सकती हैं।
ये संख्याओं जैसे प्रिमिटिव टाइप की हो सकती हैं, और ऐरे, दूसरे ऑब्जेक्ट या फंक्शन भी हो सकती हैं।
इसी वजह से ऑब्जेक्ट बहुत बहुमुखी होते हैं, और JavaScript में [ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग][oop] (OOP) की मुख्य इकाइयाँ भी हैं।

आगे हम ऑब्जेक्ट को संग्रह या मैप के रूप में देखेंगे।
ऑब्जेक्ट के बाकी उपयोग दूसरे कॉन्सेप्ट में बताए जाएँगे, जैसे [क्लास][concept-classes] देखिए।

## ऑब्जेक्ट बनाना

आप घुंघराले ब्रैकेट इस्तेमाल करके ऑब्जेक्ट बनाते हैं।
आप सीधे कुछ एंट्री भी शामिल कर सकते हैं।
इसके लिए पहले की लिखिए, फिर कोलन और उसके बाद वैल्यू।

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

आखिरी एंट्री के बाद लगने वाला कोमा JavaScript में ज़रूरी नहीं है।

आपके मन में सवाल आ सकता है कि जब की को स्ट्रिंग होना चाहिए, तो उनके चारों ओर उद्धरण चिह्न क्यों नहीं लगाए जाते।
यह एक संक्षिप्त रूप है।
अगर की JavaScript के [आइडेंटिफायर][mdn-identifier] के नामकरण नियमों का पालन करती है, तो आप उद्धरण चिह्न छोड़ सकते हैं।
जिन की के नाम में खास अक्षर हों, उनके लिए सामान्य स्ट्रिंग वाला तरीका इस्तेमाल करना पड़ता है।

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## वैल्यू निकालना

किसी दी गई की की वैल्यू निकालने के दो तरीके हैं: डॉट नोटेशन और ब्रैकेट नोटेशन।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

संक्षिप्त रूप के तौर पर डॉट नोटेशन इस्तेमाल करने पर वही पाबंदी लगती है जो उद्धरण चिह्न छोड़ने पर लगती है।
यह सिर्फ तब काम करता है जब की आइडेंटिफायर के नामकरण नियमों का पालन करती हो।

## वैल्यू जोड़ना या बदलना

आप असाइनमेंट ऑपरेटर `=` की मदद से वैल्यू जोड़ या बदल सकते हैं।
यहाँ भी डॉट और ब्रैकेट नोटेशन मौजूद हैं।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## एंट्री हटाना

आप `delete` कीवर्ड की मदद से ऑब्जेक्ट से कोई की-वैल्यू जोड़ा हटा सकते हैं।

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## कोई की मौजूद है या नहीं, यह जाँचना

आप `hasOwnProperty` मेथड से जाँच सकते हैं कि ऑब्जेक्ट में कोई की मौजूद है या नहीं।

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## ऑब्जेक्ट पर लूप चलाना

ऑब्जेक्ट की सारी की पर चलने के लिए एक खास `for...in` लूप होता है।

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

बारीक गलतियों से बचने के लिए आपको हमेशा यह मानना चाहिए कि `for...in` लूप की पर किसी भी क्रम में पहुँच सकता है।
यह भी ध्यान रखिए कि `for...in` अपने इटरेशन में [विरासत में मिली की][concept-inheritance] को भी शामिल करता है।
