# निर्देश

इस अभ्यास में आप अलग-अलग तरह की रिमोट कंट्रोल कारों के बीच दौड़ का आयोजन करेंगे। हर कार की अपनी गति और अपनी बैटरी ड्रेन होती है।

कारें पूरी (100%) बैटरी के साथ शुरू होती हैं। जितनी बार आप रिमोट कंट्रोल से कार चलाते हैं, कार अपनी गति के बराबर मीटर तय करती है और बची हुई बैटरी का प्रतिशत अपनी बैटरी ड्रेन के बराबर घट जाता है।

अगर किसी कार की बैटरी उसके बैटरी ड्रेन प्रतिशत से कम हो, तो आप उस कार को और नहीं चला सकते।

हर रेस ट्रैक की अपनी दूरी होती है। कारों की जाँच यह देखकर की जाती है कि वे बैटरी खत्म हुए बिना ट्रैक पूरा कर पाती हैं या नहीं।

आपके पास छह काम हैं, और हर काम में आप रिमोट कंट्रोल कार के इंस्टेंस के साथ काम करेंगे।

## 1. रिमोट कंट्रोल कार बनाइए

रिमोट कंट्रोल कार बनाने के लिए `NeedForSpeed` क्लास का एक कंस्ट्रक्टर बनाइए। यह कंस्ट्रक्टर अपने दो पैरामीटर के रूप में कार की गति (मीटर में) और बैटरी ड्रेन का प्रतिशत लेता है (दोनों `int` टाइप के):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. रेस ट्रैक बनाइए

रेस ट्रैक बनाने के लिए `RaceTrack` क्लास का एक कंस्ट्रक्टर बनाइए। यह कंस्ट्रक्टर अपने एकमात्र पैरामीटर के रूप में ट्रैक की दूरी (मीटर में) लेता है (जिसका टाइप `int` है):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. कार को चलाइए

`NeedForSpeed.drive()` मेथड लागू कीजिए, जो कार की गति के अनुसार तय किए गए मीटरों की संख्या बदलता है। साथ ही `NeedForSpeed.distanceDriven()` मेथड भी लागू कीजिए, जो कार द्वारा तय किए गए मीटरों की संख्या लौटाता है:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. बैटरी ड्रेन होने की जाँच कीजिए

`NeedForSpeed.drive()` मेथड को ऐसे बदलिए कि वह कार की बैटरी ड्रेन के अनुसार बैटरी खत्म करे। साथ ही `NeedForSpeed.batteryDrained()` मेथड लागू कीजिए, जो बताता है कि बैटरी इतनी खत्म हो चुकी है कि कार चलाई नहीं जा सकती:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. नाइट्रो रिमोट कंट्रोल कार बनाइए

सबसे ज़्यादा बिकने वाली रिमोट कंट्रोल कार नाइट्रो है, जिसकी कमाल की अधिकतम गति 50 मीटर है और बैटरी ड्रेन 4% है। इस तरह की कार लौटाने के लिए (स्टैटिक) `NeedForSpeed.nitro()` मेथड लागू कीजिए:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. यह जाँचिए कि रिमोट कंट्रोल कार दौड़ पूरी कर सकती है या नहीं

दौड़ पूरी करने के लिए कार को दौड़ की दूरी चल पाना ज़रूरी है। यानी फिनिश लाइन पार करने से पहले उसकी बैटरी खत्म नहीं होनी चाहिए। `RaceTrack.canFinishRace()` मेथड लागू कीजिए। यह मेथड अपने पैरामीटर के रूप में एक `NeedForSpeed` इंस्टेंस लेता है और `true` लौटाता है अगर कार दौड़ पूरी कर सकती हो; वरना `false` लौटाता है:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
