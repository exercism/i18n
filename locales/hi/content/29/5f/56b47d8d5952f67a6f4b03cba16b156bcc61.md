# इसके बारे में

F# में स्ट्रिंग एक अपरिवर्तनीय ऑब्जेक्ट है, जो टेक्स्ट को यूनिकोड अक्षरों (अक्षर, अंक, विराम चिह्न आदि) के क्रम के रूप में दर्शाती है। एक `string` इंस्टेंस बनाने के लिए दोहरे उद्धरण चिह्नों का उपयोग किया जाता है:

```fsharp
let fruit = "Apple"
```

स्ट्रिंग में बदलाव करने के लिए आप उसके किसी [मेथड][methods] या [प्रॉपर्टी][properties] को कॉल कर सकते हैं, या [`String` मॉड्यूल][string-module] के किसी फंक्शन का उपयोग कर सकते हैं। चूँकि किसी स्ट्रिंग वैल्यू को बनाने के बाद उसे बदला नहीं जा सकता, इसलिए स्ट्रिंग बदलने वाला हर मेथड और फंक्शन एक नई स्ट्रिंग लौटाता है।

स्ट्रिंग को दोहरे उद्धरण चिह्न (`"`) से घेरा जाता है। कुछ खास अक्षरों को बैकस्लैश (`\`) अक्षर की मदद से [एस्केप][escaping] करना पड़ता है। स्ट्रिंग से पहले एट (`@`) चिह्न भी लगाया जा सकता है। इससे वह एक [वर्बेटिम स्ट्रिंग][verbatim] बन जाती है, जिसमें एस्केप अक्षरों का कोई असर नहीं होता।

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

दूसरा तरीका यह है कि स्ट्रिंग को [ट्रिपल कोट्स][triple-quoted] (`"""`) से बनाया जाए, जिससे स्ट्रिंग के अंदर दोहरे उद्धरण चिह्न को बिना एस्केप किए इस्तेमाल किया जा सकता है।

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

अंत में, स्ट्रिंग जोड़ने का काम [`+` ऑपरेटर][plus-operator] से होता है:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
