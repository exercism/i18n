# निर्देश परिशिष्ट

## संकेत

आपको `convert` फंक्शन बनाना है, जो एक संख्या को बारिश की बूँदों की ध्वनि में बदलकर लौटाता है। अगर आपको टाइप को लेकर संदेह हो, तो दी गई सिग्नेचर इस्तेमाल कर सकते हैं, लेकिन इससे अपनी रचनात्मकता को सीमित न कीजिए:

```haskell
convert :: Int -> String
```

यह अभ्यास टेक्स्ट वाले डेटा के साथ काम करता है। ऐतिहासिक कारणों से Haskell का `String` टाइप `[Char]` का पर्यायवाची है, यानी अक्षरों का ऐरे। टेक्स्ट डेटा को और बेहतर तरीके से संभालने के लिए `Text` टाइप इस्तेमाल किया जा सकता है।

इस अभ्यास के वैकल्पिक विस्तार के तौर पर आप ये चीज़ें कर सकते हैं:

- Haskell में [स्ट्रिंग टाइप](https://haskell-lang.org/tutorial/string-types) के बारे में पढ़िए।
- package.yaml में अपनी डिपेंडेंसी की सूची में `- text` जोड़िए।
- `Data.Text` को [इस तरीके से](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) इम्पोर्ट कीजिए:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- अब आप उदाहरण के लिए `convert :: Int -> Text` लिख सकते हैं और `Data.Text` के कॉम्बिनेटरों को `T.pack` जैसे नाम से इस्तेमाल कर सकते हैं।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) का डॉक्युमेंटेशन देखिए,
- इसके बाद आप Raindrops.hs में `String` की सभी जगहों पर `Text` रख सकते हैं:

```haskell
convert :: Int -> Text
```

यह हिस्सा पूरी तरह वैकल्पिक है।
