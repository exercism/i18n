# इटरेशन

प्रोग्रामिंग में [इटरेशन][iteration] का मतलब है कोड के एक ब्लॉक को कई बार दोहराने की प्रक्रिया।
यह `while` लूप और `until` लूप जैसी चीज़ों की मदद से किया जा सकता है।
यह रिकर्सन से भी किया जा सकता है, यानी ऐसे फंक्शन से जो खुद को कॉल करता है।

लेकिन अक्सर आपको चीज़ों के किसी संग्रह पर इटरेशन करना होता है, जैसे `Array`, `Range` या `String` पर।
Crystal में `Array` और `Range` दोनों क्लास में [`Enumerable`][enumerable] मॉड्यूल शामिल है, जो एलिमेंट पर इटरेशन करने के लिए कई मेथड देता है।
वहीं, `String` क्लास में अक्षरों पर इटरेशन करने के लिए अपने अलग मेथड हैं।

Crystal में दूसरी भाषाओं जैसा `for` स्टेटमेंट भी नहीं है।
इसकी जगह यहाँ कई मेथड हैं जिनसे इटरेशन किया जा सकता है।

## इटरेशन करना

किसी संग्रह पर इटरेशन करने का सबसे आम तरीका [`each`][each] मेथड है, जो संग्रह का हर एलिमेंट ब्लॉक को देता है।
यह `Range` के साथ आसानी से किया जा सकता है।
मान लीजिए आप 1 से 3 के बीच लूप चलाना चाहते हैं, तो आप `each` मेथड से इस रेंज पर इटरेशन कर सकते हैं।

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

और भी आसान तरीका: अगर आपको बस कुछ तय संख्या में इटरेशन करना है, तो `Int` क्लास का [`times`][times] मेथड इस्तेमाल कर सकते हैं।

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## `String` पर इटरेशन करना

`String` अक्षरों का एक क्रम है और यह `Enumerable` मॉड्यूल में शामिल नहीं है, इसलिए अक्षरों पर इटरेशन करने के लिए इसके अपने मेथड हैं।
`String` पर इटरेशन करने का सबसे आम तरीका [`each_char`][each_char] मेथड है, जो `String` का हर अक्षर ब्लॉक को देता है।

~~~~exercism/note
`each_char` मेथड ब्लॉक को `Char` ऑब्जेक्ट देता है, `String` ऑब्जेक्ट नहीं।
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String` पर इटरेशन करने का एक और तरीका [`each_line`][each_line] मेथड है।
यह मेथड ज़्यादातर तब इस्तेमाल होता है जब किसी फाइल को एक-एक लाइन पढ़ना हो।

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## ऐसे ऑब्जेक्ट पर इटरेशन करना जिसमें `Enumerable` मॉड्यूल शामिल हो

[`Enumerable`][enumerable] मॉड्यूल किसी संग्रह के एलिमेंट पर इटरेशन करने के लिए कई मेथड देता है।
जिन संग्रहों में `Enumerable` मॉड्यूल शामिल होता है, वे हैं `Array`, `Range`, `Hash`, `Set` और कुछ और; इनमें से बाद वाले आगे के कॉन्सेप्ट में समझाए जाएँगे।

`Array` पर इटरेशन करने का सबसे आम तरीका [`each`][each] मेथड है, जो `Array` का हर एलिमेंट ब्लॉक को देता है।

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map] मेथड `Array` पर इटरेशन करने का एक और तरीका है। यह एक नया `Array` लौटाता है जिसमें हर एलिमेंट पर ब्लॉक लगाने के परिणाम होते हैं।
यह `each` मेथड जैसा ही है, पर यह बदले हुए एलिमेंट वाला नया `Array` लौटाता है।
किसी संग्रह के हर एलिमेंट पर फंक्शन लगाना आम बात है, और ऐसे में यह बदलाव बहुत काम आता है।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if` जैसी शर्त लगाकर आप यह भी तय कर सकते हैं कि किन एलिमेंट को बदलना है।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### इंडेक्स के साथ

कभी-कभी आपको यह जानना होता है कि जिस एलिमेंट पर इटरेशन कर रहे हैं उसका इंडेक्स क्या है। इसके लिए आप [`each_with_index`][each_with_index] या [`map_with_index`][map_with_index] मेथड इस्तेमाल कर सकते हैं।
यह ब्लॉक को हर एलिमेंट और उसका इंडेक्स देता है। यह मेथड शुरुआती इंडेक्स बताने के लिए एक वैकल्पिक आर्गुमेंट भी लेता है।

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

ध्यान दीजिए कि [`each_char_with_index`][each_char_with_index] मेथड `String` ऑब्जेक्ट के लिए भी उपलब्ध है।

### sum

[`sum`][sum] मेथड संग्रह के सारे एलिमेंट का जोड़ लौटाता है। यह जोड़ने से पहले एलिमेंट बदलने के लिए एक वैकल्पिक ब्लॉक भी लेता है।
यह जोड़ की शुरुआती वैल्यू बताने के लिए एक वैकल्पिक आर्गुमेंट भी लेता है।

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce] या दूसरी भाषाओं में जिसे fold कहा जाता है, ऐसा मेथड है जो एक जोड़ने वाले तरीके और एक शुरुआती वैल्यू के साथ संग्रह के सारे एलिमेंट को मिला देता है।
`reduce` मेथड में एक एक्युमुलेटर होता है जो ब्लॉक को दिया जाता है, और यह एक्युमुलेटर पिछले इटरेशन का परिणाम होता है।
इस तरह यह एक रिकर्सिव प्रक्रिया बन जाती है जो संग्रह के सारे एलिमेंट को मिला देती है।

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` `sum` जैसा लग सकता है, लेकिन `reduce` ज़्यादा लचीला है क्योंकि इसमें आप एक्युमुलेटर की शुरुआती वैल्यू और जोड़ने का तरीका खुद तय कर सकते हैं।
`reduce` की मदद से `sum`, `count` और दूसरे मेथड बनाए जा सकते हैं।
