# परिचय

## संख्याएँ

ABAP में कई संख्यात्मक टाइप होते हैं। इस अभ्यास में आप इनमें से दो का उपयोग करेंगे:

- `i` पूर्णांक वैल्यू के लिए, जैसे दिनों की संख्या।
- `p` पैक्ड दशमलव वैल्यू के लिए, जैसे प्रति घंटा दर या छूट।

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

पैक्ड संख्याएँ अपनी अधिकतम लंबाई और दशमलव स्थानों की संख्या तय करती हैं।
दशमलव लिटरल आमतौर पर टेक्स्ट वैल्यू के रूप में लिखे जाते हैं, और कंपाइलर उन्हें लक्ष्य दशमलव टाइप में या तो खुद बदल देता है या `CONV` की मदद से बदल दिया जाता है।

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### राउंडिंग

ABAP राउंडिंग के लिए अंतर्निहित संख्यात्मक फंक्शन देता है।
`floor` फंक्शन किसी संख्या को नीचे की ओर निकटतम पूर्ण संख्या तक राउंड करता है, और `ceil` उसे ऊपर की ओर निकटतम पूर्ण संख्या तक राउंड करता है।

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## अंकगणितीय ऑपरेटर

ABAP संख्यात्मक वैल्यू के साथ गणना करने के लिए अंकगणितीय ऑपरेटर का समर्थन करता है।

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

बुनियादी ऑपरेटर ये हैं:

- जोड़ के लिए `+`.
- घटाव के लिए `-`.
- गुणा के लिए `*`.
- भाग के लिए `/`.
- पूर्णांक विभाजन के शेषफल के लिए `MOD`.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP पहले गुणा और भाग करता है, फिर जोड़ और घटाव।
गोल ब्रैकेट लगाकर यह स्पष्ट किया जा सकता है कि गणना किस क्रम में हो।

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
