# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग        | प्रकार    | विवरण                                  |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | इनपुट अंकों की संख्या                       |
| `$a1`    | इनपुट        | पूर्णांक | इनपुट अंकों का आधार                        |
| `$a2`    | इनपुट        | पूर्णांक | आउटपुट अंकों का आधार                       |
| `$a3`    | इनपुट/आउटपुट | पता | अंकों वाले शब्दों का ऐसा ऐरे जिसे बदला जा सकता है |
| `$v0`    | आउटपुट       | पूर्णांक | आउटपुट अंकों की संख्या, इनपुट अमान्य हो तो -1 |
| `$t0-9`  | अस्थायी      | कोई भी     | अस्थायी भंडारण के लिए इस्तेमाल किए जाते हैं   |
