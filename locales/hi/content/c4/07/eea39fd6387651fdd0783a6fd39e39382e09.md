# परिचय

## मैप

**मैप** एक डेटा स्ट्रक्चर है जो की-वैल्यू जोड़ों को संग्रहीत करता है।
यह दूसरी प्रोग्रामिंग भाषाओं में मौजूद डिक्शनरी जैसा होता है।
[मैप][map-javadoc] इंटरफेस बताता है कि मैप पर कौन-कौन से काम किए जा सकते हैं।

Java में मैप के कई अलग-अलग इम्प्लीमेंटेशन होते हैं।
[हैशमैप][hashmap-javadoc] सबसे ज़्यादा इस्तेमाल किए जाने वाले इम्प्लीमेंटेशन में से एक है।

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

मैप में एंट्री जोड़ने के लिए [put][map-put-javadoc] का उपयोग कीजिए।

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

हर की के साथ सिर्फ एक ही वैल्यू जुड़ सकती है।
उसी की के साथ `put` कॉल करने पर उस की की वैल्यू बदल जाती है।

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

किसी की की वैल्यू निकालने के लिए [get][map-get-javadoc] का उपयोग कीजिए।

```java
fruitPrices.get("apple"); // => 100
```

यह देखने के लिए कि मैप में कोई खास की मौजूद है या नहीं, [containsKey][map-containskey-javadoc] का उपयोग कीजिए।

```java
fruitPrices.containsKey("apple");  // => true
fruitPrices.containsKey("orange"); // => false
```

एंट्री हटाने के लिए [remove][map-remove-javadoc] का उपयोग कीजिए।

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc] मेथड मैप में मौजूद एंट्री की संख्या लौटाता है।

```java
fruitPrices.size();  // Returns 2
```

मैप में मौजूद की या वैल्यू निकालने के लिए आप [keySet][map-keyset-javadoc] या [values][map-values-javadoc] मेथड का उपयोग कर सकते हैं। keySet की को एक सेट के रूप में लौटाता है और values वैल्यू को एक कलेक्शन के रूप में लौटाता है।

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
