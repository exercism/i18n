# टेस्ट

टेस्ट इन कमांड से चलाइए:

```shell
corepack pnpm test
```

ध्यान रखिए कि आपका कोड बेस्ट प्रैक्टिस और कोडिंग स्टाइल का पालन करता हो, जैसा बाकी यूज़र करते हैं। इसके लिए ESLint इस्तेमाल कीजिए, जो आपके कोड पर स्टैटिक एनालिसिस करने वाला टूल है। कभी-कभी ऐसे टूल आपके JavaScript कोड में टाइपो या छोटी-मोटी गलतियाँ ढूँढने में आपका समय बचा देते हैं:

```shell
corepack pnpm lint
```

आप Jest को "watch" मोड में भी चला सकते हैं, जो कोड या टेस्ट मॉड्यूल में बदलाव सेव करने पर आपके टेस्ट अपने आप दोबारा चला देगा:

```shell
corepack pnpm watch
```

## स्किप किए गए टेस्ट को समझिए

स्किप मेथड टेस्ट सूट को बताता है कि किसी टेस्ट को न चलाए। यह फंक्शन इन उपनामों से भी इस्तेमाल किया जा सकता है: `it.skip(name, fn)` या `xit(name, fn)` या `xtest(name, fn)`

- इन्हें स्किप क्यों किया जाता है?

ताकि यूज़र एक समय में एक टेस्ट पर ध्यान दे सकें और जैसे-जैसे वे अपने हल को आगे बढ़ाते हैं, टेस्ट एक-एक करके चालू कर सकें।

- इन्हें कैसे चालू करें?

`xtest` को `test` में बदल दीजिए।

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## अपना पहला JavaScript 2015 मॉड्यूल बनाइए

आम तौर पर इस ट्रैक के टेस्ट आपके इम्प्लीमेंटेशन को JavaScript मॉड्यूल के रूप में इम्पोर्ट करके लोड करते हैं: `import { Bob } from './bob.js';`.
आपको बस अपने इम्प्लीमेंटेशन को बताई गई फाइल `bob.js` से एक्सपोर्ट करना है:

```javascript
export function hey(message) {}
```

मॉड्यूल के बारे में अधिक जानकारी आप [Babel के डॉक्युमेंटेशन](https://babeljs.io/docs/learn-es2015/#modules) में पा सकते हैं।
शुरुआत करना आसान बनाने के लिए, डायरेक्टरी में एक _स्केलेटन_ JavaScript फाइल मौजूद है।
