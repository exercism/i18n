# मेथड सिंटैक्स

Cairo में मेथड फंक्शन की तरह होते हैं, लेकिन ट्रेट के ज़रिए किसी खास टाइप से जुड़े होते हैं।

उनका पहला पैरामीटर हमेशा `self` होता है, जो उस इंस्टेंस को दर्शाता है जिस पर मेथड कॉल किया जाता है।

Cairo में किसी टाइप पर सीधे मेथड बनाना संभव नहीं है, लेकिन आप एक ट्रेट बनाकर और उसे उस टाइप के लिए लागू करके वही कार्यक्षमता पा सकते हैं।

यहाँ एक `Rectangle` टाइप पर ट्रेट की मदद से मेथड बनाने का उदाहरण है:

```rust
#[derive(Copy, Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[generate_trait]
impl RectangleImpl of RectangleTrait {
    fn area(self: @Rectangle) -> u64 {
        (*self.width) * (*self.height)
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };
    println!("Area is {}", rect.area());
}
```

ऊपर के उदाहरण में, `area` मेथड एक आयत का क्षेत्रफल निकालता है।

`#[generate_trait]` एट्रिब्यूट का इस्तेमाल करने से प्रक्रिया आसान हो जाती है, क्योंकि यह आपके लिए ज़रूरी ट्रेट अपने आप बना देता है।

इससे आपका कोड साफ़-सुथरा रहता है, और मेथड को खास टाइप से जोड़े रखना भी संभव रहता है।

## एसोसिएटेड फंक्शन

एसोसिएटेड फंक्शन मेथड की तरह होते हैं, लेकिन किसी टाइप के इंस्टेंस पर काम नहीं करते। वे `self` को पैरामीटर के रूप में नहीं लेते।

ये फंक्शन अक्सर कंस्ट्रक्टर या टाइप से जुड़े यूटिलिटी फंक्शन के रूप में इस्तेमाल होते हैं।

```rust
#[generate_trait]
impl RectangleImpl of RectangleTrait {
    fn square(size: u64) -> Rectangle {
        Rectangle { width: size, height: size }
    }
}

fn main() {
    let square = RectangleTrait::square(10);
    println!("Square dimensions: {}x{}", square.width, square.height);
}
```

`Rectangle::square` जैसे एसोसिएटेड फंक्शन `::` सिंटैक्स का इस्तेमाल करते हैं और टाइप के नेमस्पेस में रखे जाते हैं।

इनकी मदद से मौजूदा ऑब्जेक्ट की ज़रूरत के बिना इंस्टेंस बनाना या उन पर काम करना आसान हो जाता है।

संबंधित कार्यक्षमता को ट्रेट और इम्प्लीमेंटेशन में व्यवस्थित करके, Cairo साफ़, मॉड्यूलर और एक्स्टेंसिबल कोड संरचनाएँ संभव बनाता है।
