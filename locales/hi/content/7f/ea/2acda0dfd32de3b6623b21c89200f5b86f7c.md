# निर्देश

इस अभ्यास में आप ऐसा तरीका बना रहे हैं जिससे आपके इलाके के आर्केड हॉल के सबसे लोकप्रिय खेल के हाई स्कोर पर नज़र रखी जा सके।

आपको 5 फंक्शन बनाने हैं। इनमें से ज़्यादातर उस ऑब्जेक्ट को बदलने से जुड़े हैं जिसमें हाई स्कोर रखे जाते हैं।

## 1. नया हाई स्कोर बोर्ड बनाइए

`createScoreBoard` नाम का फंक्शन बनाइए। यह एक ऑब्जेक्ट बनाता है, जो हाई स्कोर बोर्ड की तरह काम करता है।
इस ऑब्जेक्ट की कीज़ खिलाड़ियों के नाम होंगी और वैल्यूज़ उनके स्कोर होंगी।
टेस्ट करने के लिए आप ऑब्जेक्ट में सीधे एक एंट्री शामिल करना चाहते हैं।
इस शुरुआती एंट्री में खिलाड़ी का नाम `The Best Ever` और स्कोर `1000000` होना चाहिए।

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. स्कोर बोर्ड में खिलाड़ी जोड़िए

हाई स्कोर बोर्ड में कोई खिलाड़ी जोड़ने के लिए `addPlayer` फंक्शन बनाइए।
यह 3 पैरामीटर लेता है:

- पहला पैरामीटर एक मौजूदा स्कोर बोर्ड ऑब्जेक्ट है।
- दूसरा पैरामीटर खिलाड़ी का नाम है, जो एक स्ट्रिंग होती है।
- तीसरा पैरामीटर स्कोर है, जो एक संख्या होती है।

नया खिलाड़ी जोड़ने के बाद फंक्शन वही स्कोर बोर्ड ऑब्जेक्ट लौटाता है जो उसे दिया गया था।

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. स्कोर बोर्ड से खिलाड़ी हटाइए

अगर कोई खिलाड़ी आर्केड हॉल के नियम तोड़ता है, तो उसे हाई स्कोर बोर्ड से हाथ से हटा दिया जाता है।
`removePlayer` बनाइए, जो 2 पैरामीटर लेता है:

- पहला पैरामीटर एक मौजूदा स्कोर बोर्ड ऑब्जेक्ट है।
- दूसरा पैरामीटर खिलाड़ी का नाम है, जो एक स्ट्रिंग होती है।

इस फंक्शन को बोर्ड से उस खिलाड़ी की एंट्री हटानी चाहिए और फिर बोर्ड लौटाना चाहिए।
अगर वह खिलाड़ी बोर्ड पर था ही नहीं, तो बोर्ड में कोई बदलाव नहीं होना चाहिए।
बोर्ड जैसा है वैसा ही लौटा दिया जाना चाहिए।

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. किसी खिलाड़ी का स्कोर बढ़ाइए

अगर कोई खिलाड़ी आर्केड हॉल में एक और खेल पूरा करता है, तो बोर्ड पर उसके पिछले स्कोर में कुछ अंक जोड़ दिए जाते हैं।
`updateScore` बनाइए, जो 3 पैरामीटर लेता है:

- पहला पैरामीटर एक मौजूदा स्कोर बोर्ड ऑब्जेक्ट है।
- दूसरा पैरामीटर उस खिलाड़ी का नाम है जिसका स्कोर बढ़ाया जाना है।
- तीसरा पैरामीटर वह स्कोर है जिसे बोर्ड पर रखे हाई स्कोर में **जोड़ना** है।

अपडेट हो जाने के बाद फंक्शन को स्कोर बोर्ड लौटाना चाहिए।

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. सोमवार के बोनस अंक लगाइए

आर्केड हॉल सोमवार को एक अलग स्कोर बोर्ड रखता है।
दिन के अंत में उस बोर्ड पर मौजूद हर खिलाड़ी को 100 अतिरिक्त अंक मिलते हैं।

`applyMondayBonus` फंक्शन बनाइए, जो एक स्कोर बोर्ड लेता है।
यह फंक्शन उस बोर्ड पर दर्ज हर खिलाड़ी के लिए बोनस अंक जोड़ता है।
इसके बाद बोर्ड लौटा दिया जाता है।

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
