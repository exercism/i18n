# निर्देश

आपके एक दोस्त ने अभी-अभी आपको एक ज़रूरी राज़ वाला संदेश भेजा है।
दूसरों के लिए उसे पढ़ना आसान न हो, इसलिए संदेश को बिट्स पर कई बदलाव करके एन्क्रिप्ट किया गया था।
संदेश को डिक्रिप्ट करने में मदद के लिए आपको कुछ फंक्शन लिखने होंगे।

## 1. बिट्स को वापस शिफ्ट कीजिए

संदेश को डिक्रिप्ट करने का पहला कदम यह है कि एन्क्रिप्शन के दौरान हुई शिफ्टिंग को उलट दिया जाए और बिट्स को दाईं ओर वापस शिफ्ट कर दिया जाए।
डिक्रिप्शन की आगे की प्रक्रियाओं में यह माना गया है कि बाईं ओर से 0 डाले जाते हैं।

`shift_back()` फंक्शन बनाइए जो एक वैल्यू और शिफ्ट करने के लिए जगहों की संख्या लेता है और शिफ्ट करता है।

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. कुछ बिट्स सेट कीजिए

इसके बाद, कुछ बिट्स ऐसे हैं जिन्हें 1 पर सेट करना होता है।

`set_bits()` फंक्शन बनाइए जो एक वैल्यू और एक मास्क लेता है और वैल्यू के बिट्स को 1 पर सेट करने का परिणाम लौटाता है।
`value` का कोई बिट वहाँ 1 पर सेट होना चाहिए जहाँ `mask` का बिट भी 1 हो।
बाकी सभी बिट्स जैसे हैं वैसे ही रहने चाहिए।

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. खास बिट्स पलटिए

एन्क्रिप्शन के दौरान कुछ बिट्स पलट दिए जाते हैं।
संदेश को डिक्रिप्ट करने के लिए इन्हें वापस पलटना होगा।

`flip_bits()` फंक्शन बनाइए जो एक वैल्यू और मास्क लेता है।
मास्क बताता है कि वैल्यू के कौन-से बिट्स पलटने हैं।
अगर `mask` में कोई बिट 1 है, तो `value` में वह बिट पलट दिया जाता है।
बाकी सभी बिट्स जैसे हैं वैसे ही रहते हैं।

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. कुछ खास बिट्स साफ़ कीजिए

अंत में, कुछ ऐसे बिट्स भी हैं जो हमेशा 0 पर ही डिक्रिप्ट होते हैं।

`clear_bits()` फंक्शन बनाइए जो एक वैल्यू और एक मास्क लेता है।
जहाँ मास्क का बिट 1 है, वहाँ `value` के बिट्स 0 पर सेट होने चाहिए।
बाकी सभी बिट्स जैसे हैं वैसे ही रहने चाहिए।

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
