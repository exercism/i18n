# टेस्ट चलाना

टर्मिनल से अभ्यास की बेस डायरेक्टरी में जाइए और फिर इस कमांड से टेस्ट चलाइए:

```bash
$ gleam test
```

इससे `test` सबफोल्डर में मौजूद टेस्ट फाइल चलेगी, यानी वह फाइल जिसका नाम `_test.gleam` पर खत्म होता है।

## टेस्ट फंक्शन

ये टेस्ट एक [कस्टम टेस्ट फ्रेमवर्क](https://github.com/exercism/gleam-test-runner/tree/main/runner) इस्तेमाल करते हैं।
`test` डायरेक्टरी में मौजूद कोई भी पब्लिक फंक्शन, जिसके नाम के अंत में `_test` हो, टेस्ट फ्रेमवर्क की नज़र में एक टेस्ट माना जाता है।

उदाहरण के लिए:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
