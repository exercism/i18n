Haxe में स्ट्रिंग को हाथ से जोड़ना संभव है, लेकिन Haxe [स्ट्रिंग इंटरपोलेशन][string-interpolation] का समर्थन करता है, जो एक छोटा और ज़्यादा सुविधाजनक सिंटैक्स देता है:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

जैसा कि ऊपर दिखाया गया है, सामान्य [स्ट्रिंग][strings] से अलग, इंटरपोलेट किए गए स्ट्रिंग सिंगल कोट (`'`) के अंदर लिखे जाते हैं। इनमें डॉलर चिह्न (`$`) से दिखाए गए खास आइडेंटिफायर भी हो सकते हैं, जो इंटरपोलेशन शुरू करते हैं।

`${expr}` लिखकर पूरे एक्सप्रेशन भी शामिल किए जा सकते हैं, जहाँ `expr` कोई भी मान्य Haxe एक्सप्रेशन हो सकता है:

```haxe
trace('the next number is ${x + 1}');
```

जहाँ असली डॉलर चिह्न चाहिए, वहाँ इंटरपोलेशन रोकने के लिए `$$` इस्तेमाल किया जा सकता है:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

अंत में ध्यान दीजिए कि स्ट्रिंग इंटरपोलेशन एक कंपाइल-टाइम फीचर है, जिसका रनटाइम परफॉर्मेंस पर कोई असर नहीं पड़ता। भीतर से Haxe कंपाइलर वही कोड बनाता है जो हाथ से जोड़ने पर बनता है।

[strings]: https://haxe.org/manual/std-String.html
