# परिचय

Python में लूप बनाने के दो तरीके हैं।
`while` लूप _अनिश्चित_ (बिना गिने जाने वाले) इटरेशन के लिए हैं और `for` लूप _निश्चित_ (गिने जाने वाले) इटरेशन के लिए।
`break`, `continue` और `else` कीवर्ड लूप के व्यवहार को अपनी ज़रूरत के हिसाब से बदलने में मदद करते हैं।
`range(<length of sequence>)` और `enumerate(<iterable>)` फंक्शन लूप गिनने और इंडेक्स देने में मदद करते हैं।


`while` लूप में यह पहले से तय नहीं होता कि वह कितनी बार चलेगा, और जब तक `loop` एक्सप्रेशन या "जाँच" का मान `True` रहता है, यह चलता रहता है।
जब लूप एक्सप्रेशन का मान `False` हो जाता है, तब लूप रुक जाता है।

```python
while expression:
    set_of_statements
```

`for` लूप किसी भी सीक्वेंस की हर वैल्यू पर एक-एक करके चलता है और तब रुक जाता है जब लौटाने के लिए और कोई वैल्यू नहीं बचती।
जब लूप करने के लिए कोई डेटा स्ट्रक्चर या कोई दूसरा इटरेबल न हो, तब `range(<length of sequence>)` फंक्शन `loop` काउंटर या सीक्वेंस देता है।

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
