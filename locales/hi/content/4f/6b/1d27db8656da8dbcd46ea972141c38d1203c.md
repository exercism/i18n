# Debug

डीबगिंग में मदद के लिए, [debug.mac फाइल][debug] में कई मैक्रो परिभाषित हैं।
इन्हें उचित टाइप और आकार के एक या अधिक आर्गुमेंट के साथ कॉल किया जा सकता है।
उदाहरण के लिए:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

इनमें से किसी भी मैक्रो का उपयोग करने के लिए `debug.mac` को हल फाइल के सबसे ऊपर शामिल करना होगा:

```x86asm
%include "debug.mac"
```

ध्यान रखिए कि सभी मैक्रो `rsp` को अस्थायी रूप से बदल देते हैं।
स्टैक पर मौजूद किसी वैल्यू को डीबग करने के लिए पहले उसे या उसका एड्रेस किसी दूसरे रजिस्टर में लोड कीजिए।
