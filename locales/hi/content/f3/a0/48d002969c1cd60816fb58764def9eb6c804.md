# निर्देश

कार्ल Exercism की वेबसाइट पर सीखने के लिए भाषाओं का ऐरे बनाए रखना चाहता है। कार्ल को नई भाषाएँ जोड़ने, पुरानी भाषाएँ हटाने और यह जाँचने की ज़रूरत है कि कौन-सी भाषाएँ ऐरे में हैं। अगर कार्ल Java या Kotlin सीखना चाहता है, तो यह बहुत रोमांचक होगा!

## 1. यह जाँचने के लिए फंक्शन बनाइए कि भाषाओं का ऐरे खाली है या नहीं

कार्ल को जानना है कि उसका भाषाओं का ऐरे कभी खाली हो जाता है या नहीं, ताकि वह सीखने के लिए और भाषाएँ ढूँढ सके! `isEmpty` नाम का मेथड बनाइए, जो ऐरे में कोई भाषा न होने पर `true` लौटाता है।

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. ऐरे में भाषा जोड़ने के लिए फंक्शन बनाइए

कार्ल Kotlin और Python सीखने को उत्सुक है! `addLanguage` नाम का मेथड बनाकर कार्ल को शुरुआत करने में मदद कीजिए। यह मेथड वह भाषा लेता है जिसे कार्ल सीखना चाहता है और उसे ऐरे में जोड़ देता है।

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. ऐरे से भाषा हटाने के लिए फंक्शन बनाइए

कार्ल ने तय किया कि वह अभी Scala नहीं सीखना चाहता। `removeLanguage` नाम का मेथड बनाकर कार्ल को यह भाषा ऐरे से हटाने में मदद कीजिए। यह मेथड वह भाषा लेता है जिसे हटाना है और उसे ऐरे से हटा देता है।

```java
languageList.removeLanguage("Scala");
```

## 4. ऐरे का पहला एलिमेंट लौटाने के लिए फंक्शन बनाइए

कार्ल उस पहली भाषा को याद रखना चाहता है जो उसने ऐरे में सबसे पहले जोड़ी थी (और जो अब भी ऐरे में है)। `firstLanguage` नाम का मेथड बनाइए, जो ऐरे की पहली भाषा लौटाता है।

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. ऐरे में कितनी भाषाएँ हैं, यह लौटाने के लिए फंक्शन बनाइए

कार्ल को जानना है कि वह कितनी भाषाएँ सीखने की कोशिश कर रहा है। `count` नाम का मेथड बनाकर कार्ल को इसका जवाब ढूँढने में मदद कीजिए। यह मेथड ऐरे में मौजूद भाषाओं की संख्या लौटाता है।

```java
int two = languageList.count(); // 2
```

## 6. यह पता लगाने के लिए फंक्शन बनाइए कि कोई भाषा ऐरे में है या नहीं

कार्ल यह याद करने की कोशिश कर रहा है कि वह Python सीखना चाहता था या Ruby। `containsLanguage` नाम का मेथड बनाइए, जो वह भाषा लेता है जिसके बारे में कार्ल पूछ रहा है, ताकि कार्ल को पता चल सके!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. यह तय करने के लिए फंक्शन बनाइए कि ऐरे रोमांचक है या नहीं

अगर कार्ल Java या Kotlin सीखना चाहता है, तो यह बहुत रोमांचक है! `isExciting` नाम का मेथड बनाइए, जो true लौटाता है अगर कार्ल Java या Kotlin सीखना चाहता है।

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
