# क्लास के static कीवर्ड

PHP में क्लास कोड को व्यवस्थित करने की एक इकाई है, जो अक्सर किसी चीज़, सेवा या प्रक्रिया के एक उदाहरण को दर्शाती है।

`static` और `self` कीवर्ड की मदद से प्रॉपर्टी और मेथड किसी एक ऑब्जेक्ट के बजाय पूरी क्लास से जुड़े हो सकते हैं। ऐसी प्रॉपर्टी और मेथड क्लास के सभी उदाहरणों के लिए मौजूद रहते हैं, और तब भी जब क्लास का कोई उदाहरण बना ही न हो।

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## सीमा

क्लास का एक `static` मेथड केवल अपनी ही क्लास की `static` प्रॉपर्टी या `static` मेथड को कॉल कर सकता है।
