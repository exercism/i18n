# परिचय

Rust में एक अकेले अक्षर को दर्शाने के लिए [char][char type] टाइप होता है। `char` लिटरल को अकेले उद्धरण चिह्नों के बीच लिखा जाता है, जैसे `'a'`। हर `char` का आकार चार बाइट का होता है और यह एक अकेली [Unicode स्केलर वैल्यू][unicode scalar] को दर्शाता है।

लेकिन [`char`][character type] हमेशा वह नहीं होता जिसे हम अक्षर मानते हैं। कुछ भाषाएँ, जैसे हिंदी, [डायक्रिटिक][diacritics] का इस्तेमाल करती हैं, जो ऐसे खास चिह्न होते हैं जो अपने साथ जुड़े अक्षर को बदल देते हैं। Rust में डायक्रिटिक एक अलग `char` होता है, लेकिन हम आम तौर पर डायक्रिटिक और उसके साथ जुड़े अक्षर को मिलाकर ही एक अक्षर मानते हैं।

किसी अक्षर और उसके डायक्रिटिक को मिलाकर [ग्राफीम क्लस्टर][grapheme cluster] कहा जाता है। ग्राफीम क्लस्टर को संसाधित करने के लिए बाहरी क्रेट इस्तेमाल किए जा सकते हैं, जैसे [unicode-segmentation][unicode-segmentation]।

उदाहरण

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

प्रिंट होता है

```rust
2
'u'
'\u{308}'
```

'\u{308}' एक `char` लिटरल लिखने का दूसरा तरीका है। `\u` बताता है कि यह एक Unicode `char` है, जिसमें `{308}` उस अक्षर या डायक्रिटिक की अद्वितीय Unicode संख्या है।
