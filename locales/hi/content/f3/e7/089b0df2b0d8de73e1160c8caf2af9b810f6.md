# निर्देश

आपके दोस्त ने अभी-अभी आपको एक ज़रूरी राज़ वाला संदेश भेजा है।
दूसरों के लिए उसे पढ़ना आसान न बने, इसलिए संदेश को बिट्स पर कई तरह के बदलाव करके एन्क्रिप्ट किया गया था।
संदेश को डिक्रिप्ट करने में मदद के लिए आपको कुछ मेथड लिखने होंगे।

## 1. बिट्स को वापस शिफ्ट कीजिए

संदेश को डिक्रिप्ट करने का पहला चरण है एन्क्रिप्शन के दौरान हुई शिफ्टिंग को उलटना, यानी बिट्स को वापस दाईं ओर शिफ्ट करना।
डिक्रिप्शन के आगे के चरण यह मानकर चलते हैं कि बाईं ओर से 0 डाले जाते हैं।

`Secrets.shiftBack` मेथड बनाइए, जो एक वैल्यू और शिफ्ट करने के लिए स्थानों की संख्या लेता है और शिफ्ट पूरी करता है।

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. कुछ बिट्स सेट कीजिए

अब कुछ बिट्स ऐसी हैं जिन्हें 1 पर सेट करना है।

`Secrets.setBits` मेथड बनाइए, जो एक वैल्यू और एक मास्क लेता है और वैल्यू की बिट्स को 1 पर सेट करने का परिणाम लौटाता है।
वैल्यू की कोई बिट वहाँ 1 पर सेट होनी चाहिए जहाँ मास्क की बिट भी 1 हो।
बाकी सभी बिट्स जैसी हैं वैसी ही रहनी चाहिए।

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. खास बिट्स पलटिए

एन्क्रिप्शन के दौरान कुछ बिट्स पलट दी जाती हैं।
संदेश को डिक्रिप्ट करने के लिए इन्हें वापस पलटना होगा।

`Secrets.flipBits` मेथड बनाइए, जो एक वैल्यू और मास्क लेता है।
मास्क बताता है कि वैल्यू की कौन-सी बिट्स पलटनी हैं।
अगर मास्क में बिट 1 है, तो वैल्यू में वह बिट पलट दी जाती है।
बाकी सभी बिट्स जैसी हैं वैसी ही रहती हैं।

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. खास बिट्स साफ़ कीजिए

अंत में, कुछ ऐसी बिट्स भी हैं जो हमेशा 0 पर डिक्रिप्ट होती हैं।

`Secrets.clearBits` मेथड बनाइए, जो एक वैल्यू और एक मास्क लेता है।
जहाँ मास्क की बिट 1 है, वहाँ `value` की बिट्स 0 पर सेट होनी चाहिए।
बाकी सभी बिट्स जैसी हैं वैसी ही रहनी चाहिए।

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
