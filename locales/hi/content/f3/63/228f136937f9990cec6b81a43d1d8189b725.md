# निर्देश

इस अभ्यास में आप एक साधारण पूर्णांक कैलकुलेटर के लिए एरर हैंडलिंग बनाएँगे।
कैलकुलेटर में जोड़, गुणा और भाग के ऑपरेशन होने चाहिए। वह परिणाम एक फॉर्मेटेड स्ट्रिंग के रूप में लौटाता है।
आपको अवैध ऑपरेशनों और शून्य से भाग जैसी स्थितियों से निपटने के लिए एरर हैंडलिंग भी लागू करनी होगी।

उद्देश्य यह है कि आपके पास एक ऐसा कैलकुलेटर हो जो ठीक से काम करे और नीचे दिए गए फॉर्मेट में स्ट्रिंग लौटाए:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. कैलकुलेटर के ऑपरेशन लागू कीजिए

इस काम के लिए मुख्य फंक्शन `SimpleCalculator::calculate` होगा, जो तीन आर्गुमेंट लेता है: दो पूर्णांक और एक `ByteArray`, जो ऑपरेशन को दर्शाता है।
ये ऑपरेशन लागू कीजिए:

- **जोड़**, `+` सिंबल के साथ
- **गुणा**, `*` सिंबल के साथ
- **भाग**, `/` सिंबल के साथ

## 2. अवैध ऑपरेशन संभालिए

अगर ऑपरेशन सिंबल `+`, `*` या `/` के अलावा कुछ और है, तो कैलकुलेटर को या तो पैनिक करना चाहिए या एरर लौटाना चाहिए:

- अगर ऑपरेशन एक खाली स्ट्रिंग है, तो `ByteArray` एरर संदेश `"Operation cannot be an empty string"` के साथ पैनिक करना चाहिए।
- बाकी किसी भी अमान्य ऑपरेशन के लिए `Result::Err("Operation is out of range")` लौटाइए।

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. शून्य से भाग देते समय आने वाली एरर संभालिए

जब `0` से भाग देने की कोशिश की जाती है, तो कैलकुलेटर को पैनिक करना चाहिए और एक एरर संदेश देना चाहिए जिससे पता चले कि शून्य से भाग देना मान्य नहीं है।
जो परिणाम लौटाया जाए, वह `'Division by zero is not allowed'` वाली `felt252` वैल्यू होनी चाहिए।

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
