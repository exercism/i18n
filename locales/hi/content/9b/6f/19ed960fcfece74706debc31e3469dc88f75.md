# परिचय

PHP में, किसी वेरिएबल पर ब्रैकेट [`()`] लगाकर उसे फंक्शन की तरह कॉल किया जा सकता है। जब PHP उस फंक्शन को कॉल करने की कोशिश करता है, तो वह ऐसा फंक्शन ढूँढता है जिसका नाम वेरिएबल की वैल्यू के समान हो।

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## स्टैटिक क्लास फंक्शन को कॉल करना

स्टैटिक क्लास फंक्शन भी इसी तरह कॉल किए जा सकते हैं:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## इंस्टेंस क्लास फंक्शन को कॉल करना

किसी क्लास इंस्टेंस के फंक्शन को कॉल करना भी संभव है:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
