# परिचय

Go में ऐसे बुनियादी संख्यात्मक टाइप होते हैं, जो पूर्णांक या दशमलव संख्या वाली वैल्यू के समूह दर्शा सकते हैं।

इस अवधारणा में हम दो संख्या टाइपों पर ध्यान देंगे:

- `int`: जैसे `0`, `255`, `2147483647`.
   एक चिह्नित पूर्णांक, जिसका आकार कम से कम 32 बिट का होता है (वैल्यू का दायरा: -2147483648 से 2147483647 तक)।
   लेकिन यह सिस्टम के आर्किटेक्चर पर निर्भर करता है।
   अधिकांश आधुनिक कंप्यूटर 64 बिट के होते हैं, इसलिए `int` का आकार 64 बिट का होगा (वैल्यू का दायरा: -9223372036854775808 से 9223372036854775807 तक)।

- `float64`: जैसे `0.0`, `3.14`.
   इसमें सभी 64-बिट दशमलव संख्याओं का समूह शामिल है।

Go मानक अंकगणितीय ऑपरेटरों का समर्थन करता है: `+`, `-`, `*`, `/` और `%` (शेष, मॉड्यूलो नहीं)।

Go में एक टाइप की वैल्यू को दूसरे टाइप में असाइन करने के लिए स्पष्ट रूपांतरण ज़रूरी होता है।
उदाहरण के लिए, किसी `int` को `float64` में बदलने के लिए आपको यह करना होगा:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
