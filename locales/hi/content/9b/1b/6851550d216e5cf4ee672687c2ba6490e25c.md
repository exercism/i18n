# परिचय

C# टाइप को किसी क्लास या स्ट्रक्चर के स्कोप के अंदर परिभाषित किया जा सकता है। यह बाहरी टाइप एक तरह का नेमस्पेस देता है। टाइप तक पहुँच उस बाहरी टाइप के ज़रिए डॉट सिंटैक्स से होती है।

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

आप आंतरिक टाइप के लिए एक्सेस लेवल सेट कर सकते हैं।

बाहरी टाइप के private सदस्य आंतरिक टाइप के सदस्यों के स्कोप में होते हैं, लेकिन इसका उल्टा नहीं।
