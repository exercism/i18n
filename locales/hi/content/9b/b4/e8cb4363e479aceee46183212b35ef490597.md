# परिचय

## अंकगणितीय ऑपरेटर

JavaScript संख्याओं पर बुनियादी अंकगणितीय ऑपरेशन करने के लिए 6 अलग-अलग ऑपरेटर देती है।

- `+`: जोड़ ऑपरेटर का उपयोग संख्याओं का जोड़ निकालने के लिए किया जाता है।

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: घटाव ऑपरेटर का उपयोग दो संख्याओं के बीच का अंतर निकालने के लिए किया जाता है।

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: गुणा ऑपरेटर का उपयोग दो संख्याओं का गुणनफल निकालने के लिए किया जाता है।

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: भाग ऑपरेटर का उपयोग दो संख्याओं को भाग देने के लिए किया जाता है।
  चूँकि JavaScript की संख्याएँ हमेशा दशमलव संख्याएँ होती हैं, पूर्णांक भाग जैसा कुछ नहीं होता।

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: शेष ऑपरेटर का उपयोग भाग देने पर बचे शेष को निकालने के लिए किया जाता है।

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: घात ऑपरेटर का उपयोग किसी संख्या को किसी घात तक बढ़ाने के लिए किया जाता है।
  यह [`Math.pow()`][mdn-math-pow] इस्तेमाल करने के बराबर है।

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## ऑपरेशन का क्रम

जब एक ही लाइन में कई ऑपरेटर इस्तेमाल किए जाते हैं, तब JavaScript प्राथमिकता के एक क्रम का पालन करती है, जैसा कि [इस प्राथमिकता तालिका][mdn-operator-precedence] में दिखाया गया है।
इसे अपने संदर्भ में आसान बनाने के लिए, JavaScript वही PEDMAS (कोष्ठक, घात, भाग/गुणा, जोड़/घटाव) नियम इस्तेमाल करती है जो हमने प्राथमिक गणित की कक्षाओं में सीखा है।

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## शॉर्टहैंड असाइनमेंट ऑपरेटर

शॉर्टहैंड असाइनमेंट ऑपरेटर किसी वेरिएबल पर अंकगणितीय ऑपरेशन करने वाला कोड लिखने और नई वैल्यू को उसी वेरिएबल में असाइन करने का छोटा तरीका हैं।
उदाहरण के लिए, दो वेरिएबल `x` और `y` लीजिए।
तब `x += y`, `x = x + y` के बराबर है।
अक्सर इसमें वेरिएबल `y` की जगह कोई संख्या इस्तेमाल की जाती है।
बाकी 5 ऑपरेशन भी इसी तरह किए जा सकते हैं।

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
