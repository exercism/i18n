# निर्देश

स्थानीय कविता क्लब एक नया सीज़न शुरू कर रहा है। कवि इस क्लब से जुड़ते हैं, और जब भी उनमें से दो मिलकर कोई कविता लिखते हैं, वे एक ही *लेखन मंडल* का हिस्सा बन जाते हैं। क्लब यह दर्ज रखना चाहता है कि कौन किसके साथ एक मंडल में है, और आपसे यह काम दिया गया है कि आप वे शब्द लिखें जो इसे सँभालें।

एक डिसजॉइंट सेट इसके लिए एकदम सही है: हर कवि एक परमाणु है, और हर लेखन मंडल एक समूह।

## 1. क्लब खोलिए

`new-club` बनाइए। यह कवियों का एक सीक्वेंस लेता है और एक नया डिसजॉइंट सेट लौटाता है जिसमें हर कवि पंजीकृत होता है। हर कवि अपने ही लेखन मंडल से शुरुआत करता है।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. सहयोग दर्ज कीजिए

`collaborate` बनाइए। यह दो कवियों और एक क्लब को लेता है। यह दोनों कवियों के लेखन मंडलों को जोड़ देता है और क्लब लौटाता है, ताकि सहयोग एक के बाद एक दर्ज किए जा सकें।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. कवि का लेखन मंडल ढूँढिए

`circle-of` बनाइए। यह एक कवि और एक क्लब को लेता है और उस कवि के लेखन मंडल का प्रतिनिधि लौटाता है। जो दो कवि एक ही मंडल में रहते हैं, उनके लिए यह हमेशा वही प्रतिनिधि लौटाता है।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. एक ही मंडल?

`same-circle?` बनाइए। यह दो कवियों और एक क्लब को लेता है और तब `t` लौटाता है जब दोनों कवि एक ही लेखन मंडल में हों, वरना `f` लौटाता है। कवियों के प्रतिनिधियों की आपस में तुलना कीजिए, भाषा में पहले से मौजूद किसी समतुल्यता जाँच का उपयोग न कीजिए।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
