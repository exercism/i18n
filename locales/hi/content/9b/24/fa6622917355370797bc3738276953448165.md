# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग     | टाइप    | विवरण                        |
| -------- | --------- | ------- | ---------------------------- |
| `$a0`    | इनपुट     | पता     | null पर खत्म होने वाली इनपुट स्ट्रिंग |
| `$v0`    | आउटपुट    | पूर्णांक | Scrabble स्कोर               |
| `$t0-9`  | अस्थायी   | कोई भी  | अस्थायी भंडारण के लिए         |
