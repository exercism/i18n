## MacOS

सबसे पहले [Homebrew][1] की मदद से Lua और [Luarocks][2] इंस्टॉल कीजिए:

```shell
$ brew install lua luarocks
```

इसके बाद Lua के लिए [Busted][3] टेस्टिंग फ्रेमवर्क इंस्टॉल कीजिए:

```shell
$ luarocks install --local busted
```

`~/.luarocks/bin` को अपने सिस्टम के `$PATH` में जोड़िए

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

ध्यान दीजिए कि यह सिर्फ अस्थायी है।
इसे अपने `$PATH` में हमेशा के लिए जोड़ने के लिए आपको इसे अपने `.bashrc`, `.zshrc` या `config.fish` में जोड़ना होगा, यह इस पर निर्भर करता है कि आप कौन-सा शेल इस्तेमाल कर रहे हैं।

इसके बाद अपनी टेस्ट चलाइए:

```shell
$ busted
```

## Windows 10: WSL

सबसे पहले आपको [PowerShell][8] (Administrator) की मदद से [WSL (Windows Subsystem for Linux)][7] चालू करना होगा:

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

इसके लिए कंप्यूटर को दोबारा शुरू करना ज़रूरी है।

इसके बाद [Microsoft Store][9] से Ubuntu इंस्टॉल कीजिए, **या** PowerShell से डाउनलोड करके इंस्टॉल कीजिए:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

फिर अपनी पैकेज सूची अपडेट कीजिए:

```shell
PS> wsl
$ sudo apt-get update
```

अब आप ऊपर दिए गए [Ubuntu निर्देशों](#ubuntu) का पालन करके [LuaRocks][2] और [Busted][3] इंस्टॉल करने के लिए तैयार हैं।

यह हो जाने के बाद आप किसी भी Windows कमांड लाइन से सीधे अपनी टेस्ट चला सकते हैं:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Gitbash इंस्टॉल कीजिए

यह चरण वैकल्पिक है। अगर आप Windows का अपना CLI या कोई और CLI इस्तेमाल करना पसंद करते हैं, तो आपको नीचे दिए गए चरणों में थोड़ा बदलाव करना पड़ सकता है।

[यहाँ][10] से डाउनलोड कीजिए।
इंस्टॉल करने के निर्देश [यहाँ][11] हैं।

### Docker इंस्टॉल कीजिए

[Docker for Windows][12] इंस्टॉल करने के निर्देशों का पालन कीजिए।
इंस्टॉल कर लेने के बाद, यह पक्का करने के लिए कि यह ठीक से इंस्टॉल हुआ है, आप नीचे दिया गया कमांड चला सकते हैं।

```shell
$ docker --version
```

_पहली बार Docker चलाने की कोशिश में आपको एक एरर मिल सकती है।_

`cannot enable hyper-v service`

_अगर ऐसा होता है, तो आप [Hyper V चालू करने][13] के लिए इन निर्देशों का पालन कर सकते हैं। हो सकता है आपको सेटिंग बंद करनी पड़े, कंप्यूटर को दोबारा शुरू करना पड़े और बूट होने के बाद उसे फिर चालू करना पड़े।_

### busted इंस्टॉल कीजिए

Gitbash और Docker इंस्टॉल हो जाने के बाद, आप एक busted 'कंटेनर' इंस्टॉल कर सकेंगे।

Gitbash में यह चलाइए:

यह व्यापक रूप से इस्तेमाल होने वाला Docker कंटेनर नीचे दिया गया कमांड चलाकर डाउनलोड कीजिए:

```shell
$ docker pull imega/busted
```

एक फंक्शन बनाइए ताकि आपको हर बार पूरा कमांड टाइप न करना पड़े।
इसे अपने `.bashrc` में जोड़िए:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

अब अपने CLI में उस डायरेक्टरी तक पहुँचिए जिसमें आप अपनी टेस्ट चलाना चाहते हैं। नीचे दिया गया कमांड चलाइए:

```shell
$ dbusted $PWD
```

आपको अपनी busted टेस्ट का आउटपुट दिखना चाहिए।
