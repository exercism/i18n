# निर्देश

स्कूल के खोई हुई वस्तुओं के कार्यालय में हर चीज़ डिब्बों में रखी जाती है। डिब्बे में कुछ भी हो सकता है: कोई स्वेटर, कई चीज़ें, कोई नाम।

एक `LOST_BOX{T}` क्लास लिखिए। स्टब आपको क्लास हेडर देता है।

## 1. कोई चीज़ अंदर लीजिए

`create` उस चीज़ को और उसे जमा करने वाले का नाम लेता है, और एक डिब्बा देता है। डिब्बा शुरू में बिना दावे का होता है।

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. उस पर दावा कीजिए

`claim` डिब्बे को दावा किया गया चिह्नित करता है। यह कुछ नहीं लौटाता।

```sather
box.claim;
box.claimed
-- => true
```

## 3. क्या यह अब भी बिना दावे का है?

`waiting` बताता है कि डिब्बा अभी बिना दावे का है या नहीं।

```sather
box.waiting
-- => false
```

## 4. अंदर की चीज़ बदलिए

`replace` एक नई चीज़ लेता है, उसे डिब्बे में रखता है, और लौटाता है कि पहले वहाँ क्या था। अंदर जाने वाली चीज़ और बाहर आने वाली चीज़, दोनों `T` हैं।

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. विवरण लिखिए

`describe` डिब्बे के बारे में एक पंक्ति लौटाता है, जैसे `"blue jumper, handed in by Mia"`.

चीज़ को स्ट्रिंग में डालने के लिए क्लास को यह जानना ज़रूरी है कि `T` को स्ट्रिंग में बदला जा सकता है। पैरामीटर पर बंधन लगाइए: क्लास हेडर `class LOST_BOX{T < $STR}` लिखिए, तब `item.str` की अनुमति मिलती है।

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
