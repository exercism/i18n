# परिचय

Gleam में ओपेक टाइप एक तरह के कस्टम टाइप होते हैं। ऐसे टाइप की वैल्यू सिर्फ वही मॉड्यूल बना सकता है या उन पर पैटर्न मैच कर सकता है, जो उस टाइप को परिभाषित करता है। यह ऐसे टाइप बनाने में काम आता है जिनका इस्तेमाल सिर्फ एक खास तरीके से होना चाहिए।

ओपेक टाइप `opaque` कीवर्ड से परिभाषित किए जाते हैं।

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

यह `PositiveInt` टाइप ऐसी जगहों पर इस्तेमाल होता है जहाँ पूर्णांक चाहिए, लेकिन वह शून्य या उससे बड़ा होना चाहिए। साधारण Gleam `Int` का इस्तेमाल नहीं किया जा सकता, क्योंकि वे ऋणात्मक भी हो सकते हैं।

जो मॉड्यूल इस टाइप को परिभाषित करता है, वह अंदर की पूर्णांक वैल्यू निकालने के लिए एक फंक्शन बना सकता है। साथ ही वह `PositiveInt` टाइप बनाने के लिए एक फंक्शन बना सकता है, जो वैल्यू धनात्मक न होने पर एरर लौटाएगा।

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

इस API की मदद से दूसरे मॉड्यूल ऋणात्मक वैल्यू वाला `PositiveInt` नहीं बना सकते। इसलिए जो भी फंक्शन `PositiveInt` लेता है, वह निश्चित हो सकता है कि वैल्यू धनात्मक है।
