# इसके बारे में

कैरेक्टर क्लास और क्वांटिफायर से आगे बढ़कर, रेगुलर एक्सप्रेशन टेक्स्ट की *संरचना* और *संदर्भ* का भी वर्णन कर सकते हैं। ये सब उसी [`regexp`][regexp] वोकैबुलरी में रहते हैं, और `R/ /` लिटरल के रूप में लिखे जाते हैं।

## ग्रुपिंग और अल्टरनेशन

गोल ब्रैकेट `( )` पैटर्न के किसी हिस्से को एक ग्रुप बनाते हैं, ताकि कोई क्वांटिफायर या `|` ("यह या वह") पूरे ग्रुप पर लागू हो। किसी ग्रुप के बाद लगा `?` उसे वैकल्पिक बना देता है:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## एंकर

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

*वर्ड बाउंड्री* (`\b`) वह जगह है जहाँ कोई वर्ड कैरेक्टर (कोई अक्षर, अंक या अंडरस्कोर) किसी गैर-वर्ड कैरेक्टर से मिलता है, और स्ट्रिंग के सिरे भी इसमें शामिल हैं। इसलिए `\bcat\b` `cat` से तभी मैच करता है जब वह अकेला खड़ा हो:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## लुकअराउंड

एक *लुकअराउंड* यह जाँचता है कि किसी जगह से ठीक पहले या ठीक बाद में क्या आता है, लेकिन उन अक्षरों को मैच का हिस्सा नहीं बनाता। यह शून्य चौड़ाई का होता है:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## ऑप्शन

बंद करने वाले `/` के बाद लिखा ऑप्शन अक्षर पूरे पैटर्न को बदल देता है। `i` इसे केस-इनसेंसिटिव बनाता है:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## हर मैच को बदलना

`map-matches` हर मैच पर एक कोटेशन चलाता है और नतीजे इकट्ठा करता है; `each-match` यही काम सिर्फ साइड इफेक्ट के लिए करता है। दोनों कोटेशन को मैच का `start` इंडेक्स, `end` इंडेक्स और पूरी स्ट्रिंग देते हैं, इसलिए `subseq` मैच हुए टेक्स्ट को वापस निकाल लेता है:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Factor किन चीज़ों का समर्थन नहीं करता

Factor के रेगुलर एक्सप्रेशन इंजन में **कैप्चर-ग्रुप एक्सट्रैक्शन** नहीं है (ग्रुप `( )` पैटर्न को व्यवस्थित तो करता है, पर जिस टेक्स्ट से वह मैच करता है उसे आप वापस नहीं पढ़ सकते), न **बैक-रेफरेंस** (`\1`) हैं, और न **लेज़ी/नॉन-ग्रीडी** क्वांटिफायर (`*?`, `+?`)। कैप्चर ग्रुप की जगह लुकअराउंड ही सहज विकल्प है: जो हिस्सा आप चाहते हैं उससे मैच कीजिए, और उसकी पहचान उसके आसपास के संदर्भ से होती है।
