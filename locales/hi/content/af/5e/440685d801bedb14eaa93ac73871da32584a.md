# निर्देश परिशिष्ट

## एक्सेप्शन संदेश

कभी-कभी [एक्सेप्शन रेज़ करना](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) ज़रूरी होता है। ऐसा करते समय आपको हमेशा एक **सार्थक एरर संदेश** देना चाहिए, जो बताए कि एरर की जड़ कहाँ है। इससे आपका कोड पढ़ने में आसान हो जाता है और डिबगिंग में काफी मदद मिलती है। जहाँ आपको पता हो कि एरर की जड़ एक तय तरह की होगी, वहाँ आप [अंतर्निहित एरर टाइप](https://docs.python.org/3/library/exceptions.html#base-classes) में से कोई एक रेज़ कर सकते हैं, लेकिन संदेश तब भी सार्थक होना चाहिए।

इस खास अभ्यास में आपको अलग-अलग इनपुट और आउटपुट आधारों के लिए [raise स्टेटमेंट](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) का उपयोग करके एक `ValueError` "फेंकना" है। टेस्ट तभी पास होंगे जब आप `exception` को `raise` करेंगे और उसके साथ एक सार्थक संदेश भी देंगे।

संदेश के साथ `ValueError` रेज़ करने के लिए, संदेश को `exception` टाइप के आर्गुमेंट के रूप में लिखिए:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
