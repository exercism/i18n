# प्लेसहोल्डर

## List के ऑपरेशन लागू करना

इस अभ्यास का उद्देश्य यह है कि आप List के कुछ मेथड खुद लागू करें।
डेटा रखने के लिए अंदर ही अंदर एक List ऑब्जेक्ट इस्तेमाल करना स्वाभाविक है।
List के मेथड पर हाथ मत लगाइए (जैसे `where`, `map`, आदि)।

कुछ ऐसे "आधारभूत" List ऑपरेशन हैं जिनसे बचा नहीं जा सकता, जैसे:

* स्लाइसिंग: `list[from..to]`
* जोड़ना: `list.add(item)`

## इटरेटर प्रोटोकॉल

जो List ऑपरेशन आपको लागू करने हैं, वे सब अलग-अलग तरीकों से इटरेशन करने से जुड़े हैं।
[इटरेटर प्रोटोकॉल][iter] के बारे में पढ़िए।
तब आप ऐसा कर पाएँगे:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
