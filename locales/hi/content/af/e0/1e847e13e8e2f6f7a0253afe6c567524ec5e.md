# परिचय

प्रॉपर्टी के दो मुख्य प्रकार होते हैं:

1. ऑटो-इम्प्लीमेंटेड प्रॉपर्टी, जिनमें `get` और `set` एक्सेसर की कोई बॉडी नहीं होती। इन्हें स्पष्ट रूप से इनिशियलाइज़ किया भी जा सकता है और नहीं भी। उदाहरण:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. वे प्रॉपर्टी, जिनके एक्सेसर एक्सप्रेशन का मूल्यांकन करते हैं और स्टेटमेंट चलाते हैं। कोड बस बैकिंग फील्ड लौटाने या उसमें वैल्यू असाइन करने जितना सरल हो सकता है। उदाहरण:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

प्रॉपर्टी और मेथड, दोनों का व्यवहार और उनकी क्षमता काफी हद तक एक जैसी होती है। जब प्रॉपर्टी ऑटो-इम्प्लीमेंटेड नहीं होतीं, तो उनमें कोई भी ऐसा स्टेटमेंट या एक्सप्रेशन रखा जा सकता है, जो क्लास के स्कोप में आ सकता हो। आम तौर पर कहा जाता है कि ऐसी प्रॉपर्टी बैकिंग फील्ड के चारों ओर एक परत बना देती हैं। ज़्यादातर मामलों में यह साफ रहता है कि किसी खास स्थिति में व्यवहार को प्रॉपर्टी के रूप में लिखा जाए या मेथड के रूप में, फिर भी यह फैसला काफी हद तक कोड लिखने वाले पर छोड़ा जाता है। खास तौर पर यह तय करना कि एक्सेसर के अंदर कितना कोड चले। आम तौर पर `set` एक्सेसर में जाँच और `get` एक्सेसर में साधारण गणना या फॉर्मैटिंग देखने को मिलती है:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

क्लास के बाकी सदस्यों की तरह प्रॉपर्टी के भी एक्सेस लेवल हो सकते हैं। ज़्यादातर प्रॉपर्टी का एक्सेस लेवल नॉन-प्राइवेट होता है, क्योंकि उनका मुख्य उद्देश्य यही होता है। कभी-कभी प्रॉपर्टी के किसी एक एक्सेसर का एक्सेस लेवल प्रॉपर्टी से अलग होता है। `TareWeight` के मामले में, उस बनावटी "सुरक्षा" बाधा के कारण यह मौका था कि प्रॉपर्टी पब्लिक हो, लेकिन उसका गेटर प्राइवेट। इसका मतलब है कि क्लास के बाहर का कोड प्रॉपर्टी की वैल्यू सेट कर सकता है, लेकिन उसे पढ़ा (गेट) सिर्फ क्लास के अंदर का कोड ही सकता है।

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

नॉन-पब्लिक `set` एक्सेसर भी समर्थित हैं, लेकिन इससे ज़्यादा आम बात यह है कि `set` एक्सेसर को पूरी तरह छोड़ दिया जाए। ऐसा शायद इसलिए होता है कि प्रॉपर्टी की वैल्यू क्लास के कंस्ट्रक्टर में सेट की जाती है।

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

इस अभ्यास में प्रॉपर्टी के बुनियादी उपयोग पर बात की गई है। और आगे के विषय आपको दूसरे अभ्यासों में मिलेंगे:

- एक्सप्रेशन-बॉडी प्रॉपर्टी, get एक्सेसर और set एक्सेसर (देखिए: एक्सप्रेशन-बॉडी सदस्य)
- इंटरफेस पर प्रॉपर्टी (देखिए: इंटरफेस)
- एब्स्ट्रैक्ट क्लास पर प्रॉपर्टी/एब्स्ट्रैक्ट प्रॉपर्टी (देखिए: इनहेरिटेंस)
- प्रॉपर्टी के साथ `readonly` कीवर्ड का उपयोग (देखिए: इम्यूटेबिलिटी)
- स्टैटिक प्रॉपर्टी (देखिए: स्टैटिक्स)
- इंडेक्सर (देखिए: इंडेक्सर)
