# परिचय

Elixir में स्ट्रिंग दोहरे उद्धरण चिह्नों के बीच लिखी जाती हैं, और वे UTF-8 में एन्कोड की जाती हैं:

```elixir
"Hi!"
```

`<>/2` ऑपरेटर की मदद से स्ट्रिंग को जोड़ा जा सकता है:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir में `#{}` सिंटैक्स से स्ट्रिंग के अंदर इंटरपोलेशन किया जाता है:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

स्ट्रिंग में न्यूलाइन अक्षर डालने के लिए `\n` एस्केप कोड का उपयोग कीजिए:

```elixir
"1\n2\n3\n"
```

बहुत सारे न्यूलाइन वाले टेक्स्ट के साथ आराम से काम करने के लिए इसके बजाय तीन दोहरे उद्धरण चिह्नों वाले हेरिडॉक सिंटैक्स का उपयोग कीजिए:

```elixir
"""
1
2
3
"""
```

Elixir में स्ट्रिंग के साथ काम करने के लिए `String` मॉड्यूल में कई फंक्शन दिए गए हैं।
