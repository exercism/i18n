# परिचय

एक [हायर-ऑर्डर फंक्शन](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) ऐसा फंक्शन होता है जो या तो:

- एक फंक्शन को आर्गुमेंट के रूप में लेता है
- एक फंक्शन लौटाता है

फंक्शन आर्गुमेंट भी एक सामान्य आर्गुमेंट ही होता है, बस आप उसे कॉल कर सकते हैं।

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
