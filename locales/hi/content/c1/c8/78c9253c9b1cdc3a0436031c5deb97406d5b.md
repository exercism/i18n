# परिचय

लिंकेज बताता है कि कोड में किसी आइडेंटिफायर को कहाँ से एक्सेस किया जा सकता है।
ब्लॉक स्कोप, फंक्शन स्कोप या फंक्शन प्रोटोटाइप स्कोप वाली वैल्यू का कोई लिंकेज नहीं होता।
इसका मतलब है कि उन्हें उनके स्कोप के बाहर से एक्सेस नहीं किया जा सकता।
स्कोप के बारे में अधिक जानने के लिए [स्कोप कॉन्सेप्ट](../scope/introduction.md#Introduction) देखिए।

## बाहरी लिंकेज

फाइल स्कोप वाले आइडेंटिफायर में डिफॉल्ट रूप से बाहरी लिंकेज होता है।
बाहरी लिंकेज वाले आइडेंटिफायर को प्रोग्राम की किसी भी फाइल से कॉल किया जा सकता है।

## आंतरिक लिंकेज

`static` स्पेसिफायर इस्तेमाल करके फाइल स्कोप वाले आइडेंटिफायर को आंतरिक लिंकेज वाला बनाया जा सकता है।
आंतरिक लिंकेज वाले आइडेंटिफायर का इस्तेमाल सिर्फ उसकी अपनी फाइल के अंदर ही किया जा सकता है।

उदाहरण के लिए

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

स्टैटिक लिंकेज को स्टैटिक स्टोरेज ड्यूरेशन के साथ गलत नहीं समझना चाहिए।
स्टैटिक स्टोरेज ड्यूरेशन के बारे में अधिक जानने के लिए [स्टोरेज ड्यूरेशन कॉन्सेप्ट](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type) देखिए।
