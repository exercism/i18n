# परिचय

डिस्क्रिमिनेटेड यूनियन टाइप नामित केसों की एक निश्चित संख्या दर्शाता है। डिस्क्रिमिनेटेड यूनियन की हर वैल्यू ठीक एक नामित केस से मेल खाती है।

डिस्क्रिमिनेटेड यूनियन को `type` कीवर्ड से बनाया जाता है, और इसके केसों को पाइप (`|`) अक्षरों से अलग किया जाता है:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

डिस्क्रिमिनेटेड यूनियन के हर केस के साथ वैकल्पिक रूप से डेटा जुड़ा हो सकता है, और अलग-अलग केसों में अलग-अलग टाइप का डेटा हो सकता है। अगर किसी भी केस के साथ डेटा नहीं जुड़ा है, तो यह डिस्क्रिमिनेटेड यूनियन वैसी ही होती है जिसे दूसरी भाषाएँ आम तौर पर _एन्यूमरेशन_ (या _एनम_) कहती हैं।

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

किसी खास केस की वैल्यू बनाने के लिए उसका नाम लिखा जाता है (जैसे, `Success`)। चूँकि केस के नाम बस कंस्ट्रक्टर फंक्शन होते हैं, इसलिए जुड़ा हुआ डेटा सामान्य फंक्शन आर्गुमेंट की तरह पास किया जा सकता है। अगर किसी दूसरी डिस्क्रिमिनेटेड यूनियन ने उसी नाम का कोई केस बनाया है, तो आपको उसका पूरा नाम इस्तेमाल करना होगा (जैसे, `Result.Success`)।

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

डिस्क्रिमिनेटेड यूनियनों में _स्ट्रक्चरल इक्वालिटी_ होती है, जिसका मतलब है कि एक ही केस की और एक ही (वैकल्पिक) डेटा वाली दो वैल्यू समान होती हैं।

हालाँकि डिस्क्रिमिनेटेड यूनियनों के साथ काम करने के लिए `if/elif/else` एक्सप्रेशन इस्तेमाल किए जा सकते हैं, लेकिन इनके साथ काम करने का सुझाया गया तरीका _आइडेंटिफायर पैटर्न_ का इस्तेमाल करके पैटर्न मैचिंग है:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
