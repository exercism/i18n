# निर्देश

इस अभ्यास में आप लॉग लाइनों को प्रोसेस करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जिसका फॉर्मेट इस तरह होता है: `"[<LVL>]: <MESSAGE>"`.

लॉग लेवल ये हैं:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

आपको तीन काम करने हैं।

## 1. लॉग लेवल पार्स कीजिए

ऊपर दिए गए लॉग लेवल के अनुरूप छह एलिमेंट वाला एक `LogLevel` एनम बनाइए।

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

इसके बाद वह `LogLine.getLogLevel()` मेथड लागू कीजिए जो किसी लॉग लाइन का पार्स किया गया लॉग लेवल लौटाता है:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. अज्ञात लॉग लेवल को संभालिए

लेकिन कभी-कभी कुछ लॉग लाइनों का लॉग लेवल अज्ञात होता है।
ऐसी लॉग लाइनों को ठीक से संभालने के लिए `LogLevel` एनम में एक `UNKNOWN` एलिमेंट जोड़िए। जब कोई अज्ञात लॉग लेवल पार्स किया जाए, तो यही एलिमेंट लौटाया जाना चाहिए:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. लॉग लाइन को छोटे फॉर्मेट में बदलिए

किसी लॉग लाइन का लॉग लेवल काफी लंबा होता है।
लॉग लाइनों को संग्रहीत करने के लिए ज़रूरी डिस्क जगह कम करने के लिए एक छोटा फॉर्मेट बनाया गया है: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

एनकोड किया गया लॉग लेवल, लॉग लेवल को एक संख्या से जोड़ने का सीधा तरीका है:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

`LogLine.getOutputForShortLog()` मेथड लागू कीजिए, जो छोटा किया गया लॉग लाइन फॉर्मेट दे सके:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
