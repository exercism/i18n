# निर्देश परिशिष्ट

## कार्यान्वयन

इस अभ्यास में आपको एक प्रोसीजर लागू करना है। इस प्रोसीजर का उद्देश्य जो स्ट्रिंग वह लौटाता है उसे आवंटित करना है। स्ट्रिंग को मुक्त करना प्रोसीजर को कॉल करने वाले की ज़िम्मेदारी है।

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
