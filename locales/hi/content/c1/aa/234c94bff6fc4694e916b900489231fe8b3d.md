# परिचय

[ट्यूपल][tuples] कई वैल्यू को मिलाकर एक संयुक्त वैल्यू बनाते हैं।
ऐरे की तरह यहाँ ज़रूरी नहीं कि सारी वैल्यू एक ही टाइप की हों, और ट्यूपल का आकार एक बार बन जाने के बाद तय रहता है।

ट्यूपल बनाने के लिए कॉमा से अलग की गई वैल्यू को गोल ब्रैकेट में लिखिए:

```swift
let order = ("biscuits", 2.99, 3)
```

आप टाइप एनोटेशन साफ़-साफ़ भी लिख सकते हैं:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

बिना नाम वाले ट्यूपल से अलग-अलग एलिमेंट निकालने के लिए शून्य से शुरू होने वाले इंडेक्स का सिंटैक्स (`.0`, `.1`, वगैरह) इस्तेमाल कीजिए:

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## नामित ट्यूपल

ट्यूपल बनाते समय आप उसके अलग-अलग एलिमेंट को नाम दे सकते हैं:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

एलिमेंट को नाम देने से कोड पढ़ने में आसान हो जाता है, और आप उन लेबल के साथ डॉट नोटेशन का इस्तेमाल करके एलिमेंट तक पहुँच सकते हैं:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

टाइप एनोटेशन में भी एलिमेंट के नाम लिखे जा सकते हैं:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## ट्यूपल में बदलाव

अगर किसी ट्यूपल को वेरिएबल (`var`) के रूप में घोषित किया गया है, तो आप उसके एलिमेंट बदल सकते हैं:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## कई वैल्यू लौटाना

Swift के फंक्शन एक बार में सिर्फ़ एक ही वैल्यू लौटा सकते हैं, लेकिन अगर वे ट्यूपल लौटाएँ, तो आप एक ही फंक्शन से [कई वैल्यू लौटा सकते हैं][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## ट्यूपल को अलग-अलग करना

आप ट्यूपल की वैल्यू को अलग-अलग कॉन्स्टेंट या वेरिएबल में बाँट (अनपैक) सकते हैं:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

ट्यूपल को इसी तरह सीधे `for-in` लूप में भी अलग-अलग किया जा सकता है:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
