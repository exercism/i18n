# निर्देश परिशिष्ट

## सॉर्टिंग पैकेज

इस अभ्यास में आपको एक ऐरे को सॉर्ट करना है, लेकिन यह स्टैंडर्ड लाइब्रेरी का हिस्सा नहीं है। आप अपनी खुद की सॉर्टिंग लाइब्रेरी लिख सकते हैं, लेकिन इससे बेहतर विकल्प है [sorts पैकेज](https://github.com/diku-dk/sorts) का इस्तेमाल करना।

अपने हल में इस पैकेज का इस्तेमाल करने के लिए हल वाली डायरेक्टरी में यह कमांड चलाइए:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

इसके बाद अपने [पसंदीदा सॉर्टिंग एल्गोरिदम](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) इस तरह अपने कोड में शामिल कीजिए:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
