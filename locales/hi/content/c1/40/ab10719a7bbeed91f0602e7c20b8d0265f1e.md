# परिचय

## पैटर्न मैचिंग

किसी शर्त के आधार पर लॉजिक चलाने के लिए `if/elif/else` एक्सप्रेशन इस्तेमाल किया जा सकता है। F# में शर्त के आधार पर लॉजिक चलाने का एक और, ज़्यादा शक्तिशाली तरीका भी है: पैटर्न मैचिंग। पैटर्न मैचिंग में किसी वैल्यू की तुलना एक या अधिक _पैटर्न_ से की जाती है। ऐसे पैटर्न का एक उदाहरण _कॉन्स्टेंट पैटर्न_ है, जो किसी वैल्यू की तुलना एक कॉन्स्टेंट (जैसे `1` या `"hello"`) से करता है।

F# में पैटर्न मैचिंग `match` कीवर्ड से की जाती है:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

यह दूसरी भाषाओं के `switch` स्टेटमेंट जैसा लग सकता है, लेकिन पैटर्न मैचिंग की शक्ति तब दिखती है जब आप दूसरे पैटर्न भी इस्तेमाल करते हैं। ऐसा ही एक पैटर्न _वेरिएबल पैटर्न_ है, जिससे किसी वैल्यू को पकड़ा जा सकता है:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

कुछ मामलों में आप किसी पैटर्न में एक और शर्त जोड़ना चाह सकते हैं। इसे _गार्ड_ (क्लॉज़) कहते हैं, और इसे `when` कीवर्ड की मदद से जोड़ा जा सकता है:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

ऊपर के उदाहरण में हर संभव इनपुट के लिए मेल खाता पैटर्न मौजूद नहीं होगा। कंपाइलर इसे पहचान लेता है और एक चेतावनी देता है। इसे _एक्सहॉस्टिव चेकिंग_ कहते हैं। इस चेतावनी को दूर करने के लिए सभी मामलों को संभालना पड़ता है। इसके लिए _वाइल्डकार्ड पैटर्न_ इस्तेमाल किया जा सकता है, जो किसी भी वैल्यू से मेल खाता है:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

पैटर्न मैचिंग किसी वैल्यू को ऊपर से नीचे तक हर पैटर्न से मिलाती है, जब तक कोई मेल खाता पैटर्न न मिल जाए और उस पैटर्न से जुड़ा लॉजिक चल न जाए। पैटर्न का क्रम बहुत ज़रूरी है!
