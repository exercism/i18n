# परिचय

## फंक्शन टाइप

हम पहले देख चुके हैं कि फंक्शन सिग्नेचर कैसे बनाए जाते हैं: पहले फंक्शन का नाम, उसके बाद कॉमा से अलग किए गए पैरामीटर लेबल और उनके टाइप, और अंत में `->` तथा फंक्शन जो वैल्यू लौटाता है उसका टाइप।

अगर इस सिग्नेचर से सारे नाम और लेबल हटा दिए जाएँ, तो जो बचता है वह [फंक्शन का टाइप][function-types] होता है।

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

ध्यान दीजिए कि पहले दो फंक्शन के टाइप एक ही हैं, `(String, Int) -> String`, भले ही ये दोनों फंक्शन बिल्कुल अलग-अलग तरह से काम करते हैं। दोनों इनपुट के रूप में एक `String` और एक `Int` लेते हैं और एक `String` लौटाते हैं। और तीसरे फंक्शन के टाइप से पता चलता है कि भले ही वह कुछ लौटाता न दिखे, असल में वह `()` लौटाता है, जो `Void` टाइप की एकमात्र वैल्यू है। ध्यान रखिए कि टाइप नाम के तौर पर `()` और `Void` एक-दूसरे की जगह इस्तेमाल किए जा सकते हैं, इसलिए `printString` का टाइप `String) -> Void` भी लिखा जा सकता है।

इन टाइप का इस्तेमाल Swift में किसी भी दूसरे टाइप की तरह ही किया जा सकता है। जैसे, इन्हें वेरिएबल या कॉन्स्टेंट घोषित करने में इस्तेमाल किया जा सकता है। और चूँकि Swift में फंक्शन भी वैल्यू हैं, पहले से मौजूद फंक्शन इन कॉन्स्टेंट/वेरिएबल को असाइन किए जा सकते हैं:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

दूसरे वेरिएबल/कॉन्स्टेंट की तरह ही, जो वैल्यू आप इसमें असाइन करते हैं वह सही टाइप की होनी चाहिए:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## पैरामीटर टाइप के रूप में फंक्शन टाइप

चूँकि फंक्शन टाइप का इस्तेमाल वहीं किया जा सकता है जहाँ किसी भी दूसरे टाइप का किया जा सकता है, इसलिए [इन्हें पैरामीटर टाइप के रूप में इस्तेमाल किया जा सकता है][functions-as-parameters]। इन्हें दूसरे फंक्शन में पास किया जा सकता है और उन फंक्शन के अंदर से कॉल किया जा सकता है।

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## रिटर्न टाइप के रूप में फंक्शन टाइप

इसी तरह, [फंक्शन टाइप को फंक्शन के रिटर्न टाइप के रूप में इस्तेमाल किया जा सकता है][functions-as-returns]। दूसरे शब्दों में, आप ऐसे फंक्शन लिख सकते हैं जो दूसरे फंक्शन बनाकर लौटाते हैं। ऐसे फंक्शन बनाते समय, जो फंक्शन लौटाया जाता है वह फंक्शन को पास किए गए दूसरे पैरामीटर या बाहरी फंक्शन के अंदर बनाए गए लोकल वेरिएबल इस्तेमाल कर सकता है।

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## वैल्यू कैप्चर करना

जैसा ऊपर `makeAdder(base:)` फंक्शन में देखा, नेस्टेड फंक्शन अपने आसपास के फंक्शन के पैरामीटर और वेरिएबल तक पहुँच सकते हैं। इसके अलावा, बाहरी फंक्शन के खत्म हो जाने के बाद भी ये उन वैल्यू तक पहुँच बनाए रख सकते हैं। पहुँच पाने और उसे बनाए रखने की इस क्रिया को [_कैप्चर करना_][capturing-values] कहते हैं।

## हायर-ऑर्डर फंक्शन

जो फंक्शन पैरामीटर के रूप में फंक्शन लेते हैं और/या फंक्शन लौटाते हैं, उन्हें हायर-ऑर्डर फंक्शन कहते हैं। Swift की अलग-अलग लाइब्रेरी में ऐसे कई हायर-ऑर्डर फंक्शन मौजूद हैं। जैसे, `Array` जैसे Swift कलेक्शन पर उपलब्ध `sorted(by:)` मेथड। `T` टाइप के एलिमेंट वाले ऐरे के लिए यह `(T, T) -> Bool` टाइप का फंक्शन लेता है। यह फंक्शन तय करता है कि सॉर्ट किए गए ऐरे में दो वैल्यू में से कौन पहले आनी चाहिए। अगर बाईं ओर की वैल्यू पहले आनी चाहिए तो यह `true` लौटाता है, और अगर दाईं ओर की वैल्यू पहले आनी चाहिए तो `false`।

एक और उदाहरण कलेक्शन पर मौजूद `contains(where:)` मेथड है। `T` टाइप के एलिमेंट वाले कलेक्शन के लिए यह `(T) -> Bool` टाइप का फंक्शन लेता है। यह फंक्शन `true` लौटाता है अगर एलिमेंट कोई प्रॉपर्टी पूरी करता है, और वरना `false`। फिर `contains(where:)` `true` लौटाता है अगर कलेक्शन का कोई एलिमेंट यह प्रॉपर्टी पूरी करता है।

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
