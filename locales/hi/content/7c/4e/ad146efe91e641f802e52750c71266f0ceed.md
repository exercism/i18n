# मेंटेनर के लिए

## टेस्ट बनाना: `bin/generate_tests.py`

टेस्ट फाइलें [exercism/problem-specifications](https://github.com/exercism/problem-specifications) के कैनॉनिकल डेटा से बनाई जाती हैं। इसके लिए हर अभ्यास में `.meta/template.j2` पर रखा गया एक Jinja टेम्पलेट इस्तेमाल होता है।

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

यह स्क्रिप्ट problem-specifications को configlet के कैश (`~/.cache/exercism/configlet/problem-specifications`, जिसे `bin/configlet sync` भरता है) से पढ़ती है, या `problem-specifications` नाम की पैरेंट डायरेक्टरी से पढ़ती है।
सिर्फ वही केस बनाए जाते हैं जो `.meta/tests.toml` में शामिल हैं।

Fortran के स्ट्रिंग लिटरल में `\n` और `\t` जैसे एस्केप नहीं हो सकते।
टेम्पलेट फिल्टर `escape_quote_whitespace` इन्हें `" // NEWLINE // "`, `" // TAB // "` और `" // CARRIAGE_RETURN // "` में बदल देता है, इसलिए टेम्पलेट को ये कॉन्स्टेंट घोषित करने पड़ते हैं (देखिए `exercises/practice/bob/.meta/template.j2`)।

### पूर्वापेक्षाएँ

- काम करने वाले CMake और Fortran कंपाइलर
- `jinja2` के साथ Python 3.12 या उससे नया
- git

### नया अभ्यास जोड़ने का वर्कफ्लो

उदाहरण के लिए `bob` को लीजिए:

- नई ब्रांच बनाइए, जैसे `git checkout -b exercise-bob`
- `bin/add-exercise bob` चलाइए (इसके लिए `jq` और `curl` चाहिए)। यह:
  - configlet फेच करके `configlet create` चलाता है, जो अभ्यास को `config.json` में जोड़ता है और problem-specifications से उसके डॉक्स, मेटाडेटा और `tests.toml` सिंक करता है
  - `bin/reorder-exercises` से `config.json` को क्रम में लगाता है
  - `exercises/shared/CMakeLists.txt` को अभ्यास की डायरेक्टरी में कॉपी करता है
  - एक स्टब हल, एक स्टब `.meta/example.f90` और एक शुरुआती `.meta/template.j2` लिखता है (`exercises/shared/template.j2` से)

  यह आपसे आपका GitHub यूज़रनेम पूछता है, जब तक आप `-a <username>` न दें, और कठिनाई 1 सेट करता है, जब तक आप `-d <difficulty>` न दें।

- `.meta/template.j2` में बदलाव कीजिए ताकि हर केस सही इनपुट के साथ सही फंक्शन को कॉल करे, फिर टेस्ट बनाइए:

  ```bash
  bin/generate_tests.py bob
  ```

- `.meta/example.f90` में एक ऐसा हल लिखिए जो चल जाए। विद्यार्थी की फाइल (जैसे `bob.f90`) की जगह उन फंक्शन या सबरूटीन का ढाँचा रखिए जिन्हें टेस्ट कॉल करते हैं, ताकि विद्यार्थी को शुरुआत करने में मदद मिले
- पक्का कीजिए कि सारे टेस्ट पास हों। इसके लिए रिपॉज़िटरी की मुख्य डायरेक्टरी से पूरा बिल्ड चलाइए:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- `bin/reorder-exercises` और `bin/configlet lint` चलाइए
- अगर सब कुछ पास हो जाए, तो अपने बदलावों के साथ एक पुल रिक्वेस्ट खोलिए

### `CMakeLists.txt` बदलना

जब आप cmake फाइल बदलें, तो `exercises/shared/` में मौजूद मास्टर कॉपी अपडेट कीजिए और `bin/update-cmake-files` से उसे हर अभ्यास की डायरेक्टरी में कॉपी कीजिए।
