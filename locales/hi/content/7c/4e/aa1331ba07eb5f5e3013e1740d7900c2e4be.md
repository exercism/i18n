# परिचय

C# एक स्टैटिकली टाइप्ड भाषा है, जिसका मतलब है कि कंपाइल-टाइम पर हर चीज़ का एक टाइप होता है। किसी [वेरिएबल][variable] के लिए नाम चुनने को वेरिएबल बनाना कहा जाता है। एक बार वेरिएबल बन जाने के बाद उसमें वैल्यू रखने या बदलने को वेरिएबल असाइनमेंट कहते हैं। वेरिएबल को या तो उसका टाइप साफ़-साफ़ बताकर बनाया जा सकता है, या [`var` कीवर्ड][var] की मदद से C# कंपाइलर से असाइन की गई वैल्यू के आधार पर उसका टाइप निकलवाया जा सकता है। `var` के इस इस्तेमाल को _टाइप इन्फरेंस_ कहते हैं।

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

वेरिएबल की वैल्यू को [`=` ऑपरेटर][assignment] से असाइन और अपडेट किया जा सकता है। एक बार बन जाने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# एक ऑब्जेक्ट-ओरिएंटेड भाषा है और इसमें हर [फंक्शन][function] को एक _क्लास_ के अंदर बनाना ज़रूरी होता है। क्लास [`class` कीवर्ड][classes] से बनाई जाती हैं। ऑब्जेक्ट (या _इंस्टेंस_) `new` कीवर्ड से बनाए जाते हैं।

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

क्लास के अंदर बने फंक्शन को _मेथड_ कहा जाता है। हर [मेथड][methods] में शून्य या उससे अधिक पैरामीटर हो सकते हैं। सभी पैरामीटर का टाइप साफ़-साफ़ बताना ज़रूरी है, पैरामीटर के लिए कोई टाइप इन्फरेंस नहीं होता। इसी तरह रिटर्न टाइप भी साफ़-साफ़ बताना पड़ता है। मेथड से वैल्यू [`return` कीवर्ड][return] से लौटाई जाती हैं। किसी मेथड को दूसरी फाइलों के कोड से कॉल करने की अनुमति देने के लिए `public` एक्सेस मॉडिफायर जोड़ना ज़रूरी है।

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

मेथड को इंस्टेंस पर डॉट (`.`) सिंटैक्स से कॉल किया जाता है, जिसमें कॉल करने वाले मेथड का नाम लिखा जाता है और मेथड के हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं। आर्गुमेंट में वैकल्पिक रूप से उसके संगत पैरामीटर का नाम भी लिखा जा सकता है।

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

अगर कॉल किए जाने वाला मेथड उसी क्लास में बना है जिसमें उसे कॉल करने वाला मेथड है, तो क्लास का नाम छोड़ा जा सकता है।

अगर कोई मेथड किसी ऑब्जेक्ट की _स्थिति_ का इस्तेमाल नहीं करता, तो `static` मॉडिफायर से उसे _स्टैटिक_ बनाया जा सकता है। स्टैटिक मेथड भी डॉट (`.`) सिंटैक्स से कॉल किए जाते हैं, लेकिन क्लास के इंस्टेंस पर नहीं, बल्कि खुद क्लास पर कॉल किए जाते हैं।

अगर क्लास में सिर्फ स्टैटिक मेथड हैं, तो `static` मॉडिफायर से उस क्लास को भी स्टैटिक बनाया जा सकता है। यह क्लास के उद्देश्य को ज़ाहिर करता है।

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

C# में स्कोप `{` और `}` अक्षरों के बीच तय होता है।

C# दो तरह की [कमेंट][comments] सपोर्ट करता है। सिंगल लाइन कमेंट से पहले `//` लगता है और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखी जाती है।

पूर्णांक वैल्यू एक या उससे अधिक (लगातार) अंकों से लिखी जाती हैं और ये [डिफ़ॉल्ट गणितीय ऑपरेटर][operators] सपोर्ट करती हैं।

वेरिएबल के नाम के लिए [कुछ नियमों का पालन करना ज़रूरी है][identifier-names], जैसे नाम की शुरुआत या तो किसी अक्षर से हो या अंडरस्कोर से, और [C# की नेमिंग कन्वेंशन का पालन होना चाहिए][naming-guidelines]। अगर वेरिएबल का नाम किसी आरक्षित [C# कीवर्ड][csharp-keywords] से टकराता है, तो उसे `@` से एस्केप करना पड़ता है। इस तरीके का इस्तेमाल करने की सलाह नहीं दी जाती, लेकिन कुछ खास मामलों में यह देखने को मिल सकता है, जैसे: `var @this`, `var @class` या `var @var`।

कुछ कॉन्सेप्ट C# जैसी C-फैमिली की भाषा के लिए इतने बुनियादी हैं कि लगभग हर गैर-तुच्छ कोड में वे अपने आप आ जाते हैं। ये हैं [म्यूटेशन][mutation] और [स्कोप][scope]। म्यूटेशन का मतलब है कि किसी वेरिएबल की वैल्यू प्रोग्राम के चलने के दौरान बदल सकती है। स्कोप का मतलब है कि किसी नाम (किसी प्रोग्राम एलिमेंट के) से जुड़ी वैल्यू सिर्फ उसी कोड के "हिस्से" में पहुँच सकती है जहाँ वह बनाई गई है। C# में मुख्य कोड हिस्से _क्लास/स्ट्रक्ट_ और _फंक्शन_ (आम तौर पर मेथड) हैं, लेकिन इनमें लूप और दूसरे कंस्ट्रक्ट के बॉडी भी शामिल हो सकते हैं।
