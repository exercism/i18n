# विवरण

एक स्टैटिक एक्सटेंशन मौजूदा टाइप को उनके सोर्स को बदले बिना छद्म रूप से विस्तारित करने की सुविधा देता है। यह `using` स्टेटमेंट के इस्तेमाल से किया जाता है। स्टैटिक एक्सटेंशन एक शक्तिशाली टूल हो सकते हैं जो टाइप को वास्तव में बदले बिना उन्हें बढ़ाने की सुविधा देते हैं।

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
