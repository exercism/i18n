# परिचय

## ऑप्शनल

Swift में प्रोग्रामर [_ऑप्शनल_][optionals] की मदद से यह दर्शा सकते हैं कि कोई वैल्यू मौजूद नहीं भी हो सकती है।
ऑप्शनल एक ऐसा टाइप है जो या तो कोई वैल्यू रखता है या [`nil`][nil] होता है, और `nil` किसी वैल्यू के न होने को दर्शाता है।
किसी ऑप्शनल का इस्तेमाल करने के लिए ज़रूरी है कि प्रोग्राम पहले यह जाँच ले कि कोई वैल्यू मौजूद है या नहीं, और उसे अनरैप करने के बाद ही इस्तेमाल करे।

किसी भी टाइप को उसके नाम के अंत में `?` जोड़कर ऑप्शनल बनाया जा सकता है।
तो एक ऑप्शनल पूर्णांक का टाइप `Int?` होगा और एक ऑप्शनल स्ट्रिंग का टाइप `String?` होगा।
ऑप्शनल टाइप के कॉन्स्टेंट या वेरिएबल बनाना और उन्हें वैल्यू असाइन करना वैसा ही होता है जैसा नॉन-ऑप्शनल टाइप की वैल्यू के लिए किया जाता है।

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

किसी ऑप्शनल टाइप के वेरिएबल को खास वैल्यू `nil` असाइन करके आप यह दर्शा सकते हैं कि उसमें कोई वैल्यू नहीं है।
`nil` का इस्तेमाल हर ऑप्शनल टाइप के साथ किया जा सकता है, लेकिन दो अलग-अलग ऑप्शनल टाइप को दिए गए `nil` का टाइप एक जैसा नहीं होता, इसलिए उन्हें आपस में बदला भी नहीं जा सकता और तुलना भी नहीं की जा सकती।

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

यह भी ध्यान दीजिए कि `nil` को भले ही किसी भी ऑप्शनल टाइप को असाइन किया जा सकता है, लेकिन इसे किसी नॉन-ऑप्शनल टाइप को असाइन नहीं किया जा सकता, भले ही उसमें वास्तव में `nil` न हो।
और जिस मेथड को नॉन-ऑप्शनल टाइप की उम्मीद होती है, उसे पहले अनरैप किए बिना ऑप्शनल टाइप नहीं दिया जा सकता।

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## ऑप्शनल का इस्तेमाल

चूँकि ऑप्शनल टाइप अपने बेस टाइप से अलग टाइप होते हैं, इसलिए इन दोनों टाइप का इस्तेमाल एक ही तरह से नहीं किया जा सकता।
जैसे: `Int("123") + 1` से कंपाइलर एरर मिलती है: "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'"।
ऐसा इसलिए होता है क्योंकि `Int("123")` एक ऑप्शनल `Int?` टाइप लौटाता है, `Int` टाइप नहीं; क्योंकि अगर स्ट्रिंग को पूर्णांक में नहीं बदला जा सकता, तो नतीजा `nil` होगा।
उस कन्वर्ज़न से मिले `Int` तक पहुँचने के लिए पहले उसे "अनरैप" करना पड़ता है।

Swift में यह काम आम तौर पर `if-let` और `guard-let` जैसी रचनाओं से किया जाता है, जो [_ऑप्शनल बाइंडिंग_][optional-binding] के लिए इस्तेमाल होती हैं।
ये `nil` की जाँच करती हैं: अगर कोई वैल्यू मौजूद होती है, तो अनरैप की गई वैल्यू एक दिए गए नाम से बँध जाती है और कोड एक रास्ते पर चलता है, और अगर `nil` मिलता है, तो कोड दूसरे रास्ते पर चलता है।

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

यह ध्यान देने योग्य है कि `safeNum` वेरिएबल का टाइप `Int` है, `Int?` नहीं।
नीचे दिए उदाहरण में `num` का टाइप `Int?` है और `safeNum` का टाइप `Int` है।

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

यह _ऑप्शनल बाइंडिंग_ इसलिए ज़रूरी है क्योंकि यह वैल्यू से ऑप्शनल टाइप को अनरैप (यानी "हटा") देती है, जिससे उसे नॉन-ऑप्शनल वैल्यू की तरह इस्तेमाल किया जा सकता है।
अगर आप सिर्फ यह शर्त जाँचें कि वैल्यू `nil` है या नहीं, तो भी वैल्यू का टाइप ऑप्शनल ही रहेगा:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

जहाँ जल्दी लौटना ज़रूरी हो, वहाँ `guard-let` का इस्तेमाल भी किया जा सकता है:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## ऑप्शनल की तुलना

ध्यान दीजिए कि भले ही ऑप्शनल के एक जोड़े के बेस टाइप की तुलना मानक तुलना ऑपरेटर से की जा सकती है, लेकिन खुद ऑप्शनल की तुलना नहीं की जा सकती।
उनकी सिर्फ समानता जाँची जा सकती है।
दो ऑप्शनल तब बराबर होते हैं जब वे दोनों `nil` हों, या जब उनके अंदर लिपटी वैल्यू अपने बेस टाइप में बराबर हों।

लेकिन दो ऑप्शनल वैल्यू की अपनी तरह से तुलना करने के लिए कोड लिखा जा सकता है।
नीचे एक `switch` स्टेटमेंट का उदाहरण है जो `true` सिर्फ तभी लौटाएगा जब दोनों ऑप्शनल वैल्यू नॉन-`nil` हों और पहली वैल्यू दूसरी से छोटी हो।
ऐसा करने के लिए यह _ऑप्शनल पैटर्न_ `varName?` का इस्तेमाल करता है, जो सिर्फ नॉन-`nil` ऑप्शनल से मेल खाता है और ऑप्शनल के अंदर की वैल्यू को `varName` नाम से बाँध देता है।

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
