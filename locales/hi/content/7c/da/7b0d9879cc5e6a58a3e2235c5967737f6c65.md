# परिचय

मेथड के पैरामीटर को एक डिफॉल्ट वैल्यू असाइन करके वैकल्पिक बनाया जा सकता है। जब वैकल्पिक पैरामीटर वाले मेथड को कॉल किया जाता है, तो कॉल करने वाले को उनके लिए कोई वैल्यू पास करने की आवश्यकता नहीं होती। यदि किसी वैकल्पिक पैरामीटर के लिए कोई वैल्यू पास नहीं की जाती है, तो उसकी डिफॉल्ट वैल्यू इस्तेमाल की जाएगी।

वैकल्पिक पैरामीटर पैरामीटर सूची के अंत में होने चाहिए; उनके बाद गैर-वैकल्पिक पैरामीटर नहीं हो सकते।

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

वैकल्पिक पैरामीटर को वेरिएबल के नाम से पहले `?` ऑपरेटर का उपयोग करके `null` पर सेट किया जा सकता है:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
