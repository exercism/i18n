# निर्देश

लेस्ली नाम के एक Lisp एलियन को खरीदारी करनी है। खरीदारी का ऐरे होना बहुत ज़रूरी है। उसमें चीज़ें जोड़नी पड़ती हैं और उससे चीज़ें हटानी पड़ती हैं।

बेशक, कागज़-कलम से किसी Lisp एलियन का काम नहीं चलेगा। "List" तो "Lisp" शब्द का ही ज़्यादातर हिस्सा है! खरीदारी का हिसाब रखने के लिए कुछ फंक्शन तो लिखने ही पड़ेंगे।

क्या आप लेस्ली की मदद कर सकते हैं ताकि वे खरीदारी के ऐरे का हिसाब रख सकें?

## 1. नया ऐरे बनाना

सबसे पहले लेस्ली को एक खाली ऐरे बनाना है। इसके लिए `new-list` नाम का फंक्शन एकदम सही रहेगा।

```lisp
(new-list) ; => ()
```

अरे नहीं... लेस्ली के मन में पहले से कुछ चीज़ें हैं। इसलिए उन्हें एक ऐसा फंक्शन चाहिए जो तीन चीज़ें ले (अच्छी बात है कि लेस्ली तीन चीज़ों का ही ऐरे बनाते हैं। न ज़्यादा, न कम!) और उन चीज़ों से एक नया खरीदारी का ऐरे बना दे। `list-of-things` नाम का फंक्शन लिखिए, जो तीन चीज़ें लेता है और उनका ऐरे लौटाता है।

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. ऐरे में चीज़ें जोड़ना

दुकान पर जाने से पहले लेस्ली भंडार में देखते हैं कि उन्हें क्या चाहिए। `add-to-list` फंक्शन लिखकर उनकी मदद कीजिए, जो किसी ऐरे के शुरू में एक चीज़ जोड़ता है।

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. ऐरे में अगली चीज़ें कौन-सी हैं?

खरीदारी करते समय लेस्ली जानना चाहते हैं कि अगली बार क्या ढूँढना है। वे ऐरे में आगे झाँककर दूसरी, तीसरी या 23वीं चीज़ (उनका भाग्यशाली अंक) भी देखना पसंद करते हैं।

- `first-thing` का मान ऐरे की पहली चीज़ होगा।
- `second-thing` का मान दूसरी चीज़ होगा।
- `third-thing` का मान तीसरी चीज़ होगा।
- `twenty-third-thing` का मान तेईसवीं चीज़ होगा।

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. ऐरे से एक चीज़ हटाना

लेस्ली ऐरे की पहली चीज़ ढूँढकर उसे शेल्फ से हटाना चाहते हैं। `remove-first-item` फंक्शन लिखकर उनकी मदद कीजिए, जो इनपुट ऐरे की पहली चीज़ के अलावा बाकी सब चीज़ों वाला ऐरे देता है।

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. छोटे ऐरे से बड़ा ऐरे बनाना

लेस्ली को पता चला कि उन्होंने गलती से एक नहीं, दो खरीदारी के ऐरे बना लिए हैं! `list-append` नाम का फंक्शन लिखिए, जो एक ऐसा ऐरे लौटाता है जिसमें पहले ऐरे के एलिमेंट पहले आते हैं और उनके बाद दूसरे ऐरे के एलिमेंट।

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. कितना लंबा?

लेस्ली को चिंता हो रही है कि इस खरीदारी में काफी समय लगेगा। इस ऐरे में कितनी चीज़ें हैं? `just-how-long` फंक्शन लिखिए, जो बताए कि उनका ऐरे कितना लंबा है।

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
