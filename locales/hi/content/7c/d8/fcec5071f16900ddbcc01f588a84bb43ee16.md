# निर्देश

इस अभ्यास में आप अपनी पसंदीदा कुकबुक की बेहतरीन लसान्या तैयार करने और पकाने से जुड़ा कुछ और कोड लिखेंगे।

आपके पास पाँच काम हैं।
पहला काम पकाने से जुड़ा है, और बाकी चार बढ़िया तैयारी के बारे में हैं।

## 1. पता कीजिए कि लसान्या पक गया है या नहीं

जब लसान्या ओवन में होता है, तो आप जानना चाहते हैं कि उसे अब बाहर निकाल सकते हैं या नहीं।
लसान्या ओवन में न जले, इसके लिए आप आमतौर पर एक टाइमर लगाते हैं।
लेकिन कभी-कभी आप यह करना भूल जाते हैं।

एक फंक्शन `cookingStatus` लिखिए जो पैरामीटर के तौर पर टाइमर में बचा हुआ समय मिनटों में लेता है।
इस फंक्शन के तीन संभावित परिणाम हो सकते हैं।

- अगर टाइमर `0` दिखाता है, तो यह `'Lasagna is done.'` लौटाता है.
- अगर टाइमर कोई और संख्या दिखाता है, तो परिणाम `'Not done, please wait.'` होना चाहिए.
- अगर फंक्शन बिना टाइमर वैल्यू के कॉल किया जाता है, तो परिणाम `'You forgot to set the timer.'` होना चाहिए.

टाइमर कभी भी 0 से कम वैल्यू नहीं दिखाएगा।

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. तैयारी के समय का अनुमान लगाइए

अगली बार जो लसान्या आप बनाएँगे, उसके लिए आप यह सुनिश्चित करना चाहते हैं कि पकाने का मज़ा लेने लायक पर्याप्त समय आपने निकाल रखा हो।
आपने पहले ही योजना बना ली है कि आपकी लसान्या में कौन-कौन सी परतें होंगी।
अब आप उसी के आधार पर अंदाज़ा लगाना चाहते हैं कि तैयारी में कितना समय लगेगा।

एक फंक्शन `preparationTime` बनाइए जो परतों का एक ऐरे और हर परत के लिए औसत तैयारी समय मिनटों में लेता है।
फंक्शन को परतों की संख्या के आधार पर कुल तैयारी समय का अनुमान लौटाना चाहिए।
अगर फंक्शन को औसत तैयारी समय दिए बिना कॉल किया जाता है, तो `2` मिनट मान लिए जाने चाहिए।

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. ज़रूरी नूडल्स और सॉस की मात्रा निकालिए

समय निकालने के अलावा, आप यह भी सुनिश्चित करना चाहते हैं कि सपनों वाली लसान्या पकाने के लिए आपके पास पर्याप्त सॉस और नूडल्स हों।
आपकी लसान्या में नूडल्स की हर परत के लिए 50 ग्राम नूडल्स चाहिए होंगे।
सॉस की हर परत के लिए 0.2 लीटर सॉस चाहिए होगा।

फंक्शन `quantities` बनाइए जो पैरामीटर के तौर पर परतों का एक ऐरे लेता है।
इसके बाद फंक्शन यह तय करेगा कि आपका खाना बनाने के लिए कितने नूडल्स और कितना सॉस चाहिए।
परिणाम को `noodles` और `sauce` कीज़ वाले एक ऑब्जेक्ट के रूप में लौटाना चाहिए।

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. गुप्त सामग्री जोड़िए

कुछ समय पहले आप एक दोस्त के घर गए और वहाँ लसान्या खाया।
वह बहुत शानदार था और उसमें कुछ खास था।
दोस्त ने आपको सामग्री की सूची भेजी और बताया कि सूची की अंतिम चीज़ ही वह "गुप्त सामग्री" है जिसने खाने को इतना खास बनाया।
अब आप उस गुप्त सामग्री को अपनी रेसिपी में भी जोड़ना चाहते हैं।

एक फंक्शन `addSecretIngredient` लिखिए जो पैरामीटर के तौर पर सामग्री के दो ऐरे लेता है।
पहला पैरामीटर वह सूची है जो आपके दोस्त ने भेजी थी, और दूसरा आपकी अपनी रेसिपी की सामग्री सूची है।
फंक्शन को अपने दोस्त की सूची की अंतिम चीज़ आपकी सूची के अंत में जोड़नी चाहिए।
जो ऐरे आपकी रेसिपी दर्शाता है, उसे सीधे बदला जाना चाहिए, और फंक्शन को कुछ भी नहीं लौटाना चाहिए।
लेकिन पहला आर्गुमेंट नहीं बदलना चाहिए।

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. रेसिपी की मात्राएँ बढ़ाइए

आपकी कुकबुक में दी गई मात्राओं से सिर्फ दो हिस्सों की लसान्या बनती है।
चूँकि अगली बार आप और लोगों के लिए पकाना चाहते हैं, इसलिए आप अलग-अलग संख्या के हिस्सों के लिए मात्राएँ निकालना चाहते हैं।

एक फंक्शन `scaleRecipe` बनाइए जो दो पैरामीटर लेता है।

- एक रेसिपी ऑब्जेक्ट, जिसमें 2 हिस्सों के लिए ज़रूरी मात्राएँ होती हैं।
  ऑब्जेक्ट का फॉर्मेट नीचे दिए उदाहरण में देखा जा सकता है।
- आप जितने हिस्से बनाना चाहते हैं, उनकी संख्या।

फंक्शन को एक रेसिपी ऑब्जेक्ट लौटाना चाहिए, जिसमें चाही गई संख्या के हिस्सों के लिए ज़रूरी मात्राएँ हों।
लेकिन आप मूल रेसिपी बनाए रखना चाहते हैं।
इसका मतलब है कि इस काम में रेसिपी वाला आर्गुमेंट नहीं बदलना चाहिए।

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
