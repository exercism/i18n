# परिचय

जिन वेरिएबलो को `var` के बजाय `final` कीवर्ड से घोषित किया जाता है, उन्हें वैल्यू सिर्फ एक बार ही असाइन की जा सकती है।

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
