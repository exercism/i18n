# Introduction

Clojure में `string` एक Java स्ट्रिंग होती है। यह एक ऑब्जेक्ट है जो अपरिवर्तनीय टेक्स्ट को यूनिकोड अक्षरों के क्रम के रूप में दर्शाता है (अक्षर, अंक, विराम चिह्न आदि)।

`clojure.string` लाइब्रेरी स्ट्रिंग को बदलने और प्रोसेस करने के लिए कई मानक फंक्शन देती है। इसके अलावा, स्ट्रिंग पर काम करने वाले Java के सारे सामान्य मेथड इंटरऑप के ज़रिए उपलब्ध रहते हैं।
