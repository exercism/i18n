# परिचय

Elm जैसी प्योर फंक्शनल भाषा में, किसी फंक्शन को एक ही आर्गुमेंट के साथ कॉल करने पर हमेशा वही वैल्यू लौटनी चाहिए।
इसलिए `rand : Int` जैसे टाइप सिग्नेचर वाले फंक्शन को (`rand = 4`)[xkcd-random] के रूप में ही लिखा जा सकता है। रैंडम पूर्णांक बनाने के लिए यह कोई अच्छी खबर नहीं है।

तो Elm में हम रैंडम वैल्यू कैसे बनाते हैं?
हम समस्या को दो हिस्सों में बाँटते हैं: पहले हम `Random.Generator a` की मदद से बताते हैं कि हमें कौन-सी वैल्यू बनानी है, और फिर उस वैल्यू को बनाते हैं।

वैल्यू बनाने का पहला तरीका है `initialSeed : Int -> Seed` की मदद से एक `Random.Seed` बनाना।
`Seed` एक अपारदर्शी टाइप है जिसके अंदर एक पूर्णांक रहता है, और वह उस पूर्णांक को इस तरह बदलना जानता है कि नतीजा रैंडम लगे (इसे स्यूडोरैंडम कहते हैं)।
एक बार आपके पास `Seed` आ जाए, तो आप उससे `Generator a` की मदद से वैल्यू बना सकते हैं।
`Generator a` भी एक अपारदर्शी टाइप है। यह जानता है कि सीड के अंदर वाले पूर्णांक का इस्तेमाल करके `a` टाइप की स्यूडोरैंडम वैल्यू कैसे बनाई जाए, और साथ ही एक नया सीड भी कैसे बनाया जाए जिसमें पूर्णांक बदल चुका हो।

वैल्यू बनाने के लिए हम `step : Generator a -> Seed -> ( a, Seed )` का इस्तेमाल कर सकते हैं। यह एक वैल्यू और एक नया सीड लौटाता है, जिससे हम आगे और वैल्यू बना सकते हैं।

चलिए इन फंक्शनों की मदद से एक जनरेटर से `n` रैंडम वैल्यू निकालते हैं:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

ध्यान दीजिए कि ये सारे फंक्शन प्योर हैं। इसलिए इन्हें एक ही आर्गुमेंट के साथ दो बार कॉल करने पर वही वैल्यू मिलेंगी।

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

वैल्यू बनाने का दूसरा तरीका है `Random.generate : (a -> msg) -> Generator a -> Cmd msg` का इस्तेमाल। लेकिन यह सिर्फ किसी Elm एप्लिकेशन के अंदर ही किया जा सकता है।
ऐसे में Elm का रनटाइम सीड बनाने के लिए `step` के साथ-साथ बाहरी, गैर-प्योर संसाधनों का भी इस्तेमाल कर सकता है। और फिर एक ही फंक्शन को दो बार कॉल करने पर अलग-अलग नतीजे मिलेंगे।

आगे हम सिर्फ जनरेटर पर ध्यान देंगे।

`Random` मॉड्यूल एक तय रेंज के अंदर पूर्णांक और दशमलव संख्याएँ बनाने के लिए दो बुनियादी जनरेटर देता है:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

इन वैल्यू को ट्यूपल में या वैल्यू के ऐरे में जोड़ा जा सकता है:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

(`elm-community/random-extra`)[random-extra] पैकेज अलग-अलग डेटा संरचनाओं के लिए और भी बहुत जनरेटर देता है: स्ट्रिंग, तारीखें, डिक्शनरी, ऐरे, सेट, आदि।

`Random.constant` की मदद से हम ऐसे जनरेटर बना सकते हैं जो हमेशा एक ही वैल्यू लौटाएँ:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform` की मदद से हम दिए गए एलिमेंट में से बराबर संभावना के साथ कोई एक चुन सकते हैं:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` दो आर्गुमेंट लेता है (`Red` और `[Green, Blue]`), ताकि यह पक्का हो कि चुनने के लिए कम से कम एक वैल्यू तो रहे ही। वजह यह है कि एक अकेला ऐरे खाली भी हो सकता है।

`Random.weighted` की मदद से हम संभावनाओं को भी बदल सकते हैं:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

वैल्यू का जोड़ 100 होना ज़रूरी नहीं है, इन्हें वैसे भी दोबारा नॉर्मलाइज़ कर दिया जाएगा।

`Random.map` की मदद से हम जनरेटर के अंदर तक पहुँच सकते हैं:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

हम और जनरेटर जोड़ने के लिए `Random.map2` से लेकर `Random.map5` तक का भी इस्तेमाल कर सकते हैं:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

और जटिल कामों के लिए हमारे पास `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` है। यह एक जनरेटर से बनी वैल्यू का इस्तेमाल करके दूसरा जनरेटर बना सकता है:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

कभी-कभी जनरेटर को खुद के भीतर दोहराते हुए बनाना काम आता है।
ऐसे मामलों में कंपाइलर जनरेटर को अनंत तक खोलता न चला जाए, इसके लिए आपको `Random.lazy` का इस्तेमाल करना पड़ सकता है।

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

यह उदाहरण थोड़ा भारी है, तो चलिए इसे टुकड़ों में समझते हैं।

`Peano` एक ऐसा टाइप है जो धनात्मक पूर्णांक दिखाता है: `Zero` यानी 0, `Next(Zero)` यानी 1, `Next(Next(Zero))` यानी 2, आदि।
हम `peano` को इस तरह बनाते हैं कि यह हमें एक रैंडम `Peano` संख्या दे।

सबसे पहले ध्यान दीजिए कि `Random.lazy` तर्क में कुछ नहीं जोड़ता। यह सिर्फ कंपाइलर को `peano` को `peano` के भीतर अनंत तक लिखते जाने से रोकता है।

हम `Random.uniform` का इस्तेमाल करके शून्य (50% संभावना के साथ) और किसी अन्य `Peano` संख्या में एक जोड़ने पर बनी संख्या (50% संभावना के साथ) के बीच चुनाव करते हैं।
लेकिन पिछले उदाहरण से अलग, यहाँ `Random.uniform` वैल्यू में से नहीं (जैसे `Zero`), बल्कि जनरेटर में से चुन रहा है (जैसे `Random.constant Zero`), क्योंकि हमें खुद `peano` का इस्तेमाल करना है।
इसका मतलब है कि `Random.uniform` `Generator (Generator Peano)` टाइप की वैल्यू लौटाएगा, जो हमें नहीं चाहिए।

जनरेटर को "समतल" करने के लिए हम उसे `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` में पाइप करते हैं, जहाँ हम चाहते हैं कि `b` यानी `Peano` हो।
चूँकि `Generator a` यानी `Generator (Generator Peano)` है, इसलिए `a` को `Generator Peano` होना चाहिए, और फंक्शन `(a -> Generator b)` का टाइप `(Generator Peano -> Generator Peano)` होना चाहिए।
हम कुछ बदलना नहीं चाहते, इसलिए `identity` सही चुनाव है।

अंत में, `peano` किस तरह की संख्याएँ बनाएगा?
हम जानते हैं कि यह 50% बार 0 बनाएगा, और 50% बार खुद को एक बार और दोहराकर उसमें एक जोड़कर बनी संख्या बनाएगा।
यानी संख्याएँ होंगी: 0 (50% बार), 1 (25% बार), 2 (12% बार), 3 (6% बार), आदि।
`peano` कितनी भी बड़ी संख्याएँ बना सकता है, लेकिन उनकी संभावना घातीय रूप से घटती जाती है।
