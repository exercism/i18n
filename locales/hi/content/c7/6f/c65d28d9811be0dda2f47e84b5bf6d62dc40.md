# परिचय

[concept:csharp/resource-cleanup]() में `IDispose` इंटरफ़ेस इस बात का संकेत देने के लिए उपयोग होता है कि जब किसी ऑब्जेक्ट की ज़रूरत नहीं रहती, तो उसका संसाधन मुक्त करना या प्रोग्राम की स्थिति को फिर से पहले जैसा करना ज़रूरी होता है। यह काम गार्बेज कलेक्टर पर भरोसा करने से नहीं होगा, और न ही उससे ज़रूरी स्तर का नियंत्रण मिलेगा। ऐसे सफाई के कामों के लिए `IDisposable.Dispose()` मेथड ही स्वाभाविक जगह थी।

इसके अलावा `using` ब्लॉक भी है, जो कॉल करने वाले की दृष्टि से संसाधन के पूरे जीवनकाल का प्रबंधन एक ही स्टेटमेंट में समेट देता है।

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

ऊपर के उदाहरण में, जैसे ही `using` ब्लॉक से बाहर निकला जाता है, `file` से जुड़े फाइल सिस्टम के संसाधन ऑपरेटिंग सिस्टम को वापस लौटा दिए जाते हैं।

इस पैटर्न के काम करने के लिए ज़रूरी है कि using स्टेटमेंट वाला वेरिएबल ऐसा रेफ़रेंस टाइप हो जो `IDisposable` इंटरफ़ेस को लागू करता हो, और अपने `Dispose()` मेथड में संसाधनों को मुक्त करे या प्रोग्राम की स्थिति को फिर से पहले जैसा बना दे।

C# 8 इस पैटर्न में एक सुधार लाता है। using स्टेटमेंट को ब्लॉक के शुरू में भी लिखा जा सकता है।

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java के डेवलपर इसे Java 7 में शुरू की गई *स्वचालित संसाधन प्रबंधन* व्यवस्था जैसा ही मान सकते हैं।
