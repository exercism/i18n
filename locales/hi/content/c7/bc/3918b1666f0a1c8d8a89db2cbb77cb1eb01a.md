# परिचय

Java में, मेथड ओवरलोडिंग एक ऐसा फीचर है जिससे एक क्लास में एक ही नाम के एक से अधिक मेथड रखे जा सकते हैं, बशर्ते उनकी पैरामीटर सूची अलग हो।
यह कंपाइल-टाइम (या स्टैटिक) पॉलिमॉर्फिज़्म से जुड़ी है।
यह कॉन्सेप्ट ऐसे मेथड बनाने के लिए महत्वपूर्ण है जो समान काम करते हैं लेकिन अलग-अलग इनपुट के साथ।

## मेथड ओवरलोड क्यों करें?

मेथड ओवरलोडिंग प्रोग्राम को पढ़ने में आसान बनाती है।
अलग-अलग मेथड को एक ही नाम दिया जा सकता है, लेकिन अलग-अलग पैरामीटर के साथ।
पैरामीटर की संख्या या पैरामीटर के टाइप के आधार पर, संबंधित मेथड को कॉल किया जाता है।

## मेथड ओवरलोड कैसे करें?

मेथड ओवरलोडिंग का मुख्य आधार मेथड का सिग्नेचर है।
दो मेथड को अलग माना जाएगा यदि उनके सिग्नेचर अलग हों।
मेथड ओवरलोड करने के दो तरीके हैं:

1. **पैरामीटर की अलग संख्या**: मेथड का नाम एक ही हो सकता है, लेकिन पैरामीटर की संख्या अलग हो सकती है।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **पैरामीटर के अलग टाइप**: मेथड का नाम एक ही हो सकता है और पैरामीटर की संख्या भी एक ही हो सकती है, लेकिन टाइप अलग हो सकते हैं।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## याद रखने योग्य बातें

- ओवरलोडेड मेथड में आर्गुमेंट सूची बदलनी ज़रूरी है।
- ओवरलोडेड मेथड रिटर्न टाइप भी बदल सकते हैं, लेकिन सिर्फ रिटर्न टाइप बदलने से मेथड ओवरलोडिंग नहीं होती।
- मेथड को एक ही क्लास में या सबक्लास में ओवरलोड किया जा सकता है।

इस कॉन्सेप्ट में, हम Java में मेथड ओवरलोडिंग के विभिन्न उदाहरणों और बारीकियों का पता लगाएँगे।
