Raku में कोड ब्लॉक का इस्तेमाल खूब होता है।
ये फंक्शन के लिए तो बुनियादी हैं ही। `grep` और `map` जैसे टूल में भी ये काम आते हैं, `if`, `for`, `while` और `given` स्टेटमेंट के ब्लॉक के रूप में, और ऐरे सबस्क्रिप्ट में भी।

## रूटीन

Raku में `Subs` और `Methods`, `Routines` के प्रकार हैं।

`return` कीवर्ड की मदद से रूटीन किसी भी समय वैल्यू लौटाकर खत्म हो सकता है, जो फंक्शन बनाने का एक उपयोगी साधन है।
अगर `return` नहीं दिया गया है, तो रूटीन का अंतिम स्टेटमेंट ही उसकी अंतर्निहित रिटर्न वैल्यू होती है।

रूटीन में कोड ब्लॉक से पहले ब्रैकेट के अंदर एक `Signature` हो सकता है।

`Routine`, `Block` की सबक्लास है।

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

मेथड को क्लास और ऑब्जेक्ट से जुड़े एक अलग कॉन्सेप्ट में समझाया जाएगा।

## ब्लॉक

`Block` एक दोबारा इस्तेमाल हो सकने वाला कोड ऑब्जेक्ट है, जिसका इस्तेमाल आम तौर पर लैम्डा बनाने के लिए होता है।

किसी ब्लॉक का अंतिम स्टेटमेंट ही उसकी अंतर्निहित रिटर्न वैल्यू होती है।

ब्लॉक में कोड ब्लॉक से पहले `->` के साथ एक `Signature` हो सकता है।

`Block`, `Code` की सबक्लास है, और `Code` Raku में सभी कोड ऑब्जेक्ट की सबसे बुनियादी बेस क्लास है।

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## सिग्नेचर

एक `Signature` शून्य या अधिक `Parameters` से बनता है, जिन्हें कॉमा से अलग किया जाता है।

सिग्नेचर के अंत में [रिटर्न टाइप ऐरो][signatures-return-type-arrow] `-->` की मदद से रिटर्न टाइप बताया जा सकता है।

किसी सिग्नेचर से यह बताया जा सकता है कि एक `Block` कौन-कौन से आर्गुमेंट लेगा।

इस कॉन्सेप्ट में सिग्नेचर सरल ही रखे जाएँगे: सिर्फ पोज़िशनल पैरामीटर, स्केलर सिगिल वाले वेरिएबलो के साथ, और एक रिटर्न टाइप।
इन्हें दूसरे कॉन्सेप्ट में और विस्तार से समझाया जाएगा।

## मल्टी-डिस्पैच

Raku में `multi` कीवर्ड की मदद से एक ही नाम के, लेकिन अलग-अलग सिग्नेचर वाले कई रूटीन लिखे जा सकते हैं।
इस फीचर को [मल्टी-डिस्पैच][multi-dispatch] कहते हैं।
जब रूटीन को नाम से कॉल किया जाता है, तो रनटाइम एनवायरनमेंट सही कैंडिडेट तय करता है और उसे चलाता है।

इसे टाइप से जुड़े एक कॉन्सेप्ट में और विस्तार से समझाया जाएगा।

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

जब `Whatever` स्टार `*` का इस्तेमाल अधिकांश ऑपरेटर के साथ मिलाकर किया जाता है, तो एक `WhateverCode` ऑब्जेक्ट बनता है।
इससे आप अधिक सरल सिंटैक्स में ब्लॉक बना सकते हैं।

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
