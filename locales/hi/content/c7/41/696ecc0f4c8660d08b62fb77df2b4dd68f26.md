# ऐरे

PHP में ऐरे क्रमबद्ध मैप होते हैं।
मैप एक ऐसा डेटा स्ट्रक्चर है जो किसी की को किसी वैल्यू से जोड़ता है।
ऐरे बहुमुखी होते हैं और इन्हें रैखिक ऐरे (जैसे `C` या `Java` में), लिस्ट [वेक्टर], हैश-टेबल, डिक्शनरी, कलेक्शन, स्टैक या क्यू की तरह इस्तेमाल किया जा सकता है।

की वैकल्पिक होती है, लेकिन अगर दी जाए तो वह `int` या `string` ही होनी चाहिए।
जब कोई की नहीं दी जाती, तो PHP डिफ़ॉल्ट रूप से पूर्णांक की बनाता है, जो `0` से शुरू होकर बढ़ते क्रम में चलती हैं।

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

एक ऐरे सभी प्रकार की वैल्यू संग्रहीत कर सकता है।
हर वैल्यू का टाइप अलग हो सकता है।

## ऐरे का उपयोग

ऐरे को लिटरल के रूप में घोषित किया जा सकता है (यानी कोड में सीधे लिखकर, जैसा ऊपर किया गया है), या फंक्शनों की मदद से बनाया और बदला जा सकता है।
इंडेक्स ऑपरेटर से वैल्यू एक्सेस कीजिए, असाइन कीजिए और जोड़िए:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
