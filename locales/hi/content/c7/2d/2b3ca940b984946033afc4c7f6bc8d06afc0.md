# निर्देश परिशिष्ट

Python ट्रैक के लिए यह अभ्यास आपसे कहता है कि आप एक `SpaceAge` _क्लास_ (_[concept:python/classes]()_) बनाइए, जिसमें सौरमंडल के सभी ग्रहों के लिए मेथड हों।
मेथड के नाम `on_<planet name>` तरीके से रखे जाने चाहिए।

हर मेथड को उस ग्रह पर की आयु वर्षों में `return` करनी चाहिए, जो दो दशमलव स्थानों तक पूर्णांकित हो:

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
