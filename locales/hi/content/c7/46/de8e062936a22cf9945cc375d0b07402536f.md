## एडिटर

### मुफ्त/ओपन-सोर्स

- [VS Code](https://code.visualstudio.com)

  VS Code एक ओपन-सोर्स कोड एडिटर है। TypeScript को सेट अप करने की जानकारी आपको [यहाँ](https://code.visualstudio.com/docs/languages/typescript) मिल सकती है। VS Code TypeScript के लिए एक लोकप्रिय एडिटर है, क्योंकि Microsoft VS Code और TypeScript दोनों को बनाए रखता है, इसलिए यह इस भाषा के साथ अच्छी तरह काम करता है; VS Code बिना किसी अतिरिक्त कॉन्फ़िगरेशन के TS को सपोर्ट करता है। दरअसल, VS Code खुद TypeScript में लिखा गया था!

  VS Code और TS के साथ एक आम समस्या तब होती है जब आपके एडिटर और प्रोजेक्ट के वर्ज़न अलग-अलग हों, जिससे VS Code एक ऐसा एरर मैसेज दिखा सकता है जो भ्रमित कर सकता है। इस एरर को संभालने के निर्देश [यहाँ](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions) हैं।

### लाइसेंस वाले

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text एक लोकप्रिय कोड एडिटर है, जो इंस्टॉल करने योग्य प्लगइन के ज़रिए ज़्यादातर भाषाओं को सपोर्ट करता है। इसे आज़माना मुफ्त है, लेकिन आपसे नियमित रूप से लाइसेंस खरीदने के लिए कहा जाएगा, जिसकी कीमत इस समय \$70 USD है।

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm एक पूरी सुविधाओं वाला JavaScript/TypeScript IDE (इंटीग्रेटेड डेवलपमेंट एनवायरनमेंट) है। यह बिना किसी अतिरिक्त कॉन्फ़िगरेशन के TypeScript को सपोर्ट करता है और इसमें टेस्टिंग, डीबगिंग और कोड एनालिसिस जुड़े हुए हैं। इसे 30 दिनों तक मुफ्त आज़माया जा सकता है, जिसके बाद पहले साल के लिए सालाना लाइसेंस की कीमत \$129 USD है।
