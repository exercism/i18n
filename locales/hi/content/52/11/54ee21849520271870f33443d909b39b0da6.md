# परिचय

लूप का इस्तेमाल किसी लॉजिक को बार-बार चलाने के लिए किया जाता है।
सबसे आम दो तरह हैं `while loop` (अनिश्चित लूपिंग) और `for loop` (निश्चित, यानी गिनी हुई लूपिंग)।
एक `for each` लूप भी होता है, जो आगे किसी कॉन्सेप्ट में आएगा।


## सामान्य सिंटैक्स

`for loop` एक हेडर और एक कोड ब्लॉक से बना होता है, जिसमें लूप के अंदर का कोड कर्ली ब्रैकेट में लपेटा रहता है।
हेडर में 3 कंपोनेंट होते हैं, जिन्हें सेमीकोलन `;` अलग करता है: इनिट-स्टेटमेंट, शर्त और एक और एक्सप्रेशन।
इनमें से हर एक खाली भी हो सकता है।

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- **इनिट** कंपोनेंट वह कोड होता है जो लूप शुरू होने से पहले सिर्फ एक बार चलता है।
- **शर्त** कंपोनेंट कोई ऐसा एक्सप्रेशन होना चाहिए जो बूलियन का मान देता हो और तय करता हो कि लूप कब रुकना चाहिए।
जब तक यह शर्त सही रहती है, लूप के अंदर का कोड चलता रहता है।
जैसे ही यह एक्सप्रेशन गलत होता है, लूप का कोई और इटरेशन नहीं चलता।
- **एक्सप्रेशन** कंपोनेंट वह कोड होता है जो हर इटरेशन के अंत में चलता है।


`while loop` जब तक उसकी शर्त जाँच सही रहती है, अपने अंदर का कोड चलाता रहता है।
नीचे दिया गया कोड स्निपेट दिखाता है कि for लूप को while लूप में कैसे बदला जाए।

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## बीच में: इंक्रीमेंट और डिक्रीमेंट

लूप के साथ काम करते समय अक्सर किसी काउंटर वेरिएबल में 1 जोड़ना या उसमें से 1 घटाना पड़ता है।
यह इतना आम है कि इस काम के लिए खास ऑपरेटर मौजूद हैं: `++` और `--`।

इनके प्रीफिक्स और पोस्टफिक्स, दो रूप होते हैं।
प्रीफिक्स रूप स्टेटमेंट में इस्तेमाल से पहले वेरिएबल को बदल देता है और पोस्टफिक्स रूप उसके बाद।
ज़्यादातर मौकों पर आपको प्रीफिक्स रूप ही चाहिए होगा।

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## for लूप - एक उदाहरण

इनिट कंपोनेंट आम तौर पर एक काउंटर वेरिएबल तैयार करता है, शर्त जाँचती है कि लूप आगे चलना चाहिए या रुकना, और पोस्ट कंपोनेंट हर बार दोहराने के अंत में काउंटर को बढ़ा देता है।

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

यह लूप `1` से `9` तक की संख्याओं का जोड़ देता है (`9` भी शामिल है)।

## break और continue

लूप के अंदर के कोड में आप `break` कीवर्ड का इस्तेमाल करके लूप को पूरी तरह रोक सकते हैं:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

इसके उलट, `continue` कीवर्ड सिर्फ मौजूदा इटरेशन को रोकता है और अगले इटरेशन के साथ आगे बढ़ जाता है:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> ध्यान दें: लूप का लॉजिक समझना आम तौर पर तब ज़्यादा आसान होता है, जब `break` और `continue` का इस्तेमाल कम से कम हो या बिलकुल न हो।
