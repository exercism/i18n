# विवरण

`Option` टाइप F# भाषा में ऐसी वैल्यू से निपटने का तरीका है जो हो भी सकती है और नहीं भी। यह `null` के इस्तेमाल का एक टाइप-सुरक्षित विकल्प देता है; दूसरी भाषाओं में ऐसी वैल्यू से निपटने के लिए `null` का इस्तेमाल आम है। यह कई मानक F# लाइब्रेरी फंक्शनों में इस्तेमाल होता है, इसलिए मानक F# लाइब्रेरी का प्रभावी ढंग से उपयोग करने के लिए ऑप्शन को समझना ज़रूरी है।

## `Option` टाइप का उपयोग करने के लाभ

* __कंपाइल-टाइम सुरक्षा__: किसी वैल्यू की मौजूदगी या गैरमौजूदगी को टाइप सिस्टम में स्पष्ट करके, कंपाइलर यह सुनिश्चित कर सकता है कि आप "वैल्यू न होने" वाले केस को संभालें, और इस तरह null के कारण हो सकने वाली बड़ी श्रेणी के बग रोक देता है।

* __रन-टाइम सुरक्षा__: `null` इस्तेमाल करने के बजाय F# वैल्यू न होने को दर्शाने के लिए `None` इस्तेमाल करता है, जिससे `NullReferenceException` आना असंभव हो जाता है।

* __स्पष्ट रूप से संभालने पर मजबूर करता है__: टाइप सिस्टम कोड से माँग करता है कि वह `Some value` और `None` दोनों केस स्पष्ट रूप से संभाले, जिससे आपका कोड ज़्यादा मजबूत और पूर्वानुमान योग्य बनता है।

* __पैटर्न मैचिंग के साथ काम करता है__: `Option` वैल्यू F# की पैटर्न मैचिंग शैली के साथ बिना किसी अड़चन के काम करती हैं, और वैल्यू मौजूद हो तो उसे खोलकर संभालने का साफ और सुरक्षित तरीका देती हैं, या न हो तो कोई दूसरी कार्रवाई करती हैं।

## उपयोग

`Option` टाइप एक जेनेरिक टाइप है (जिसका एक अंतर्निहित टाइप होता है)।  
`Option` वैल्यू या तो `Some value` होती हैं, जो कोई विशिष्ट वैल्यू दर्शाती हैं, या `None`, जो कोई वैल्यू न होना दर्शाती हैं।

अगला फंक्शन दिखाता है कि `Option` वैल्यू कैसे बनाई जाती है:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` पोस्टफिक्स सिंटैक्स में `Option<T>` का बराबर रूप है; दोनों सिंटैक्स रूपों को एक-दूसरे की जगह इस्तेमाल किया जा सकता है। हालाँकि, F# Style Guide के अनुसार, ऑप्शन टाइप के लिए पोस्टफिक्स नोटेशन को प्राथमिकता दी जाती है (देखिए [टाइप और टाइप एनोटेशन की फॉर्मेटिंग पर F# Style Guide का सेक्शन](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions))।
~~~~

`Option` का एक आम उपयोग खोज फंक्शनों में होता है।  
उदाहरण के लिए, `List.tryFind` फंक्शन `Some index` लौटाता है जब आइटम ऐरे में होता है (जहाँ `index` ऐरे में माँगी गई वैल्यू की स्थिति है), या `None` जब आइटम ऐरे में नहीं होता।

## ऑप्शन वैल्यू का कंटेंट पढ़ना

`Option` वैल्यू पढ़ने का सहज तरीका पैटर्न मैचिंग है, जैसा कि अगले उदाहरण में दिखाया गया है:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## डिफाल्ट वैल्यू के साथ ऑप्शन को अनरैप करना

`Option` को `Option.defaultValue` फंक्शन से डिफाल्ट वैल्यू देकर "अनरैप" किया जा सकता है (यानी उसे उसके अंदर वाले टाइप में बदला जा सकता है)।  
यह खास तौर पर तब काम आता है जब आप सुनिश्चित करना चाहते हैं कि वैल्यू `None` न हो।
उदाहरण के लिए:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## `Option` मॉड्यूल में और फंक्शन

`Option` मॉड्यूल में ऐसे फंक्शन भी हैं जो उन फंक्शनों से मेल खाते हैं जो लिस्ट, ऐरे, सीक्वेंस और दूसरे कलेक्शन टाइप के लिए उपलब्ध हैं, जैसे `Option.map`, `Option.iter`, `Option.forall`, `Option.count`।  
ये फंक्शन `Option` को शून्य या एक एलिमेंट वाले कलेक्शन की तरह मानने देते हैं।
