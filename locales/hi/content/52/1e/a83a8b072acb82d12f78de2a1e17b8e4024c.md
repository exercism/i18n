# टेस्ट

टेस्ट `exercism test` या `eutest` से चलाइए। सभी टेस्ट अपने आप चलते हैं।

## टेस्ट छोड़ना

शुरू करने का एक अच्छा तरीका यह है कि `t_<exercise>.e` में पहले टेस्ट के अलावा बाकी सभी टेस्ट कमेंट कर दीजिए।

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

इन्हें एक-एक करके कीजिए। जब चालू टेस्ट पास हो जाए, तो अगले टेस्ट से कमेंट हटा दीजिए। जब सभी टेस्ट पास हो जाएँ, तो समझिए कि आपने अभ्यास पूरा कर लिया है।
