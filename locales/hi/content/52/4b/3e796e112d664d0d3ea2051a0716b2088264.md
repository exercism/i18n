# निर्देश परिशिष्ट

# इनपुट

इस अभ्यास के लिए इनपुट ये हैं:

- `target`: एक स्ट्रिंग (जैसे `'stone'`) जो _बायाँ आर्गुमेंट_ होगी।
- `candidates`: बॉक्स में रखी स्ट्रिंगों की सूची (जैसे `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) जो _दायाँ आर्गुमेंट_ होगी।

आपका वर्ब ऐसे कॉल किया जाएगा:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## आउटपुट

आपका वर्ब बॉक्स की एक _सूची_ लौटाना चाहिए, जिसमें वे स्ट्रिंगें हों जो target के एनाग्राम हैं। अगर कोई एनाग्राम न हो, तो परिणाम `empty` होना चाहिए।
