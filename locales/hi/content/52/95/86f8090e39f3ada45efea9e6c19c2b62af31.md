# शर्तें

Ruby में फ्लो कंट्रोल एक्सप्रेशन होते हैं। इनकी मदद से यह तय किया जाता है कि प्रोग्राम किस तरह चलेगा, और ये सही या गलत वैल्यू लेते हैं।
कुछ ऑपरेटर ऐसी सही या गलत वैल्यू बनाने के काम आते हैं, इन्हें [तुलना ऑपरेटर][comparison-operators] कहा जाता है।

दो मुख्य कंट्रोल एक्सप्रेशन हैं जो तय करते हैं कि कौन-सा कोड चलेगा और कौन-सा नहीं।
यानी यह तय होता है कि कौन-सी शाखा चलेगी।

ये दो हैं: `if` और `unless` एक्सप्रेशन।

## तुलना ऑपरेटर

[तुलना ऑपरेटर][comparison-operators] वैल्यू की तुलना करने के लिए इस्तेमाल होते हैं और `true` या `false` वैल्यू लौटाते हैं।
नीचे दिए गए ऑपरेटरों को तुलना करने के लिए एक ही टाइप की दो वैल्यू चाहिए।
अगर वैल्यू एक ही टाइप की न हों, तो कंपाइलर एक एरर देगा।
यहाँ ऑपरेटरों की सूची दी गई है, साथ में एक उदाहरण कि वे कब `true` वैल्यू देते हैं:

| ऑपरेटर | विवरण                 | उदाहरण  |
| ------ | --------------------- | ------- |
| <      | से कम                 | 4 < 5   |
| <=     | से कम या बराबर        | 4 <= 4  |
| >      | से अधिक               | 3 > 1   |
| >=     | से अधिक या बराबर      | 2 >= 2  |

बराबर और बराबर नहीं वाले ऑपरेटर ऊपर बताए गए ऑपरेटरों के उलट किसी भी टाइप की वैल्यू की तुलना कर सकते हैं।
`==` ऑपरेटर से यह जाँचा जाता है कि दो वैल्यू बराबर हैं या नहीं, और इसमें वैल्यू का टाइप भी जाँचा जाता है।
`!=` भी इसी तरह काम करता है, लेकिन यह `true` लौटाता है अगर वैल्यू बराबर न हों और `false` अगर वे बराबर हों।
यहाँ बराबर और बराबर नहीं वाले ऑपरेटरों की सूची दी गई है, साथ में एक उदाहरण कि वे कब `true` वैल्यू देते हैं:

| ऑपरेटर | विवरण   | उदाहरण  |
| ------ | ------- | ------- |
| ==     | बराबर   | 4 == 4  |
| !=     | बराबर नहीं | 5 != 4  |

## if स्टेटमेंट

[`if`][if] स्टेटमेंट से यह जाँचा जाता है कि दी गई शर्त सही है या गलत।
अगर शर्त सही हो, तो if स्टेटमेंट के अंदर का कोड चलता है।
एक `if` स्टेटमेंट `end` कीवर्ड पर खत्म होता है।

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## unless स्टेटमेंट

`unless` स्टेटमेंट `if` स्टेटमेंट की तरह ही काम करता है, लेकिन अगर शर्त गलत हो, तो यह `unless` स्टेटमेंट के अंदर का कोड चलाता है।

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## else स्टेटमेंट

`else` स्टेटमेंट को `if` स्टेटमेंट के साथ इस्तेमाल किया जा सकता है।
अगर `if` शाखा नहीं चलती, तो `else` स्टेटमेंट चलता है।

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## "कैस्केडिंग-if" स्टेटमेंट

`elsif` स्टेटमेंट को if स्टेटमेंट के साथ इस्तेमाल किया जा सकता है।
अगर if शाखा नहीं चलती और elsif स्टेटमेंट की शर्त सही हो, तो `elsif` स्टेटमेंट चलता है।
elsif स्टेटमेंट एक के बाद एक जोड़े जा सकते हैं, और पहली सही शर्त वाला स्टेटमेंट चलेगा।
if स्टेटमेंट के अंत में एक else स्टेटमेंट भी हो सकता है, जो तब चलेगा जब पहले का कोई भी स्टेटमेंट सही न हुआ हो।

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
