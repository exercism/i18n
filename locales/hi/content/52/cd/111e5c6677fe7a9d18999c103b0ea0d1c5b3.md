# परिचय

## लूप

किसी लॉजिक को बार-बार चलाने के लिए लूप का उपयोग किया जाता है।
सबसे आम दो प्रकार हैं `while loop` (जो अनिश्चित बार चलता है) और `for loop` (जो निश्चित, यानी गिनकर तय की गई बार चलता है)।
एक `for each` लूप भी होता है, जो आगे के किसी कॉन्सेप्ट में आएगा।

### सामान्य सिंटैक्स

`for loop` एक हेडर और एक कोड ब्लॉक से बना होता है। कोड ब्लॉक में लूप के अंदर का कोड होता है, जो कर्ली ब्रैकेट में लपेटा रहता है।
हेडर में 3 हिस्से होते हैं, जो सेमीकोलन `;` से अलग किए जाते हैं: इनिट-स्टेटमेंट, शर्त, और एक और एक्सप्रेशन।
इनमें से हर एक खाली भी हो सकता है।

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- **init_statement** वाला हिस्सा ऐसा कोड है जो लूप शुरू होने से पहले सिर्फ एक बार चलता है।
- **शर्त** वाला हिस्सा एक ऐसा एक्सप्रेशन होना चाहिए जिसका परिणाम `boolean` हो, और जो यह तय करता हो कि लूप कब रुकना चाहिए।
  जब तक इस शर्त का परिणाम `true` रहता है, लूप के अंदर का कोड चलता रहता है।
  जैसे ही इस एक्सप्रेशन का परिणाम `false` होता है, लूप का कोई और इटरेशन नहीं चलता।
- **एक्सप्रेशन** वाला हिस्सा ऐसा कोड है जो हर इटरेशन के अंत में चलता है।

`while loop` तब तक अपने अंदर का कोड चलाता रहता है जब तक उसकी **शर्त** की जाँच का परिणाम `true` रहता है।
नीचे दिया गया कोड दिखाता है कि `for` को `while loop` में कैसे बदला जाए।

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### बीच में: बढ़ाना और घटाना

लूप के साथ काम करते समय अक्सर काउंटर वेरिएबल में 1 जोड़ना या 1 घटाना पड़ता है, जो इटरेशन का हिसाब रखता है।
यह इतना आम है कि बढ़ाने और घटाने की क्रियाओं के लिए खास ऑपरेटर हैं: `++` और `--`।

ये **प्रीफिक्स** और **पोस्टफिक्स** दो रूपों में आते हैं।
प्रीफिक्स रूप स्टेटमेंट में इस्तेमाल से पहले वेरिएबल को बदल देता है, और पोस्टफिक्स रूप उसके बाद।
ज़्यादातर मौकों पर आपको प्रीफिक्स रूप ही चाहिए होगा।

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### for लूप: एक उदाहरण

_इनिट कंपोनेंट_ आम तौर पर एक काउंटर वेरिएबल सेट करता है और _शर्त_ यह जाँचती है कि लूप जारी रहना चाहिए या रुकना चाहिए।
_पोस्ट कंपोनेंट_ आम तौर पर हर इटरेशन के अंत में काउंटर बढ़ा देता है।

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

यह लूप `1` से `9` तक की संख्याओं का जोड़ करता है (`9` भी शामिल है)।

### break और continue

लूप के अंदर के कोड में आप `break` कीवर्ड का उपयोग करके लूप को पूरी तरह रोक सकते हैं:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

इसके उलट, `continue` कीवर्ड सिर्फ मौजूदा इटरेशन को रोकता है और अगले इटरेशन के साथ आगे बढ़ जाता है:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
लूप का लॉजिक समझना आम तौर पर तब आसान होता है जब `break` और `continue` का इस्तेमाल कम से कम हो या बिल्कुल न हो।
दोनों कीवर्ड कोड के कुछ हिस्सों को छोड़ देते हैं, जिससे कोड को समझते चलना अक्सर और मुश्किल हो जाता है।
~~~~
