# निर्देश

इस अभ्यास में आप फैक्ट्री के कर्मचारियों के लिए नेम बैज बनाने का कोड लिखेंगे।
कर्मचारियों के पास एक ID, नाम और विभाग का नाम होता है।
कर्मचारी बैज के लेबल इस तरह बनाए जाते हैं: `"[id] - name - DEPARTMENT"`.

## 1. एक कर्मचारी के लिए बैज बनाइए

`print_name_badge` फंक्शन बनाइए। यह एक ID, नाम और विभाग लेता है।
यह बैज का लेबल लौटाता है, जिसमें विभाग का नाम बड़े अक्षरों में होता है।

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. नए कर्मचारी के लिए बैज बनाइए

कंप्यूटर सिस्टम की एक खास बात की वजह से, नए कर्मचारियों के पास फैक्ट्री में काम शुरू करते समय कभी-कभी ID नहीं होती।
चूँकि बैज ज़रूरी होते हैं, इसलिए उन्हें ID प्रीफिक्स के बिना एक अस्थायी बैज मिलेगा।

`print_name_badge` फंक्शन को बढ़ाइए। जब ID न हो, तो यह उसके बिना बैज लौटाता है।

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. मालिक के लिए बैज बनाइए

फैक्ट्री के मालिक को भी हर समय बैज पहनना पड़ता है।
लेकिन मालिक का कोई विभाग नहीं होता और कभी होगा भी नहीं: वह सभी विभागों से ऊपर है।
ऐसी स्थिति में लेबल में विभाग के नाम की जगह `"OWNER"` लौटाया जाना चाहिए।

`print_name_badge` फंक्शन को बढ़ाइए। जब विभाग `NULL` हो, तो मान लीजिए कि बैज कंपनी के मालिक का है।

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

ध्यान दीजिए कि हो सकता है मालिक भी एक नया कर्मचारी हो।

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. बिना ID वाले कर्मचारियों का कुल वेतन निकालिए

यह देखने के लिए कि ID जारी करने का काम कैसा चल रहा है, आप बिना ID वाले कर्मचारियों का कुल वेतन देखना चाहते हैं।
बड़ी वैल्यू का मतलब है कि बहुत सारे ID अभी जारी होने बाकी हैं, या यह समस्या वरिष्ठ लोगों को भी प्रभावित कर रही है: दोनों ही बातें खराब हैं।

`salaries_no_id` फंक्शन बनाइए। यह ID का एक वेक्टर और उसी के अनुसार वेतन का एक वेक्टर लेता है, और उन लोगों के वेतन का जोड़ लौटाता है जिनके पास अभी ID नहीं है।
दोनों वेक्टर की लंबाई समान होती है।

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_एक अतिरिक्त सीख, जिसकी जाँच नहीं होगी:_ अगर ऐसा कोई कर्मचारी नहीं है जिसके पास ID न हो, तो वह "खाली वेक्टर" क्या होगा जिसका आप जोड़ निकाल रहे हैं?
