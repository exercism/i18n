# निर्देश

आप सामुदायिक कला केंद्र में स्वयंसेवा कर रहे हैं। वहाँ सामने के प्रवेश द्वार के ऊपर सिरेमिक टाइलों वाला एक लंबा मोज़ेक लगाया जा रहा है। डिज़ाइन टीम ने यह काम **पंक्ति दर पंक्ति** तैयार किया है: हर पंक्ति टाइल के रंगों का एक ऐरे है, और पूरा मोज़ेक पंक्तियों का एक ऐरे है।

जैसे-जैसे स्वयंसेवक टाइलें काटते, रखते और इधर-उधर करते हैं, आप छोटे-छोटे ऐसे शब्द लिख रहे हैं जिन्हें दोबारा इस्तेमाल किया जा सके और जो डिज़ाइन के टुकड़ों को बनाते हैं, जोड़ते हैं और ढूँढ़ते हैं।

## 1. एक ही टाइल की पट्टी

`tile-strip` बनाइए, जो एक रंग ले और उसी रंग वाली एक-एलिमेंट की पंक्ति लौटाए।

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. तीन टाइलों की एक पंक्ति

`row-of-three` बनाइए, जो स्टैक से तीन रंग ले और तीन एलिमेंट की एक पंक्ति लौटाए।

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. पंक्तियों को एक ही टाइल सूची में मिलाइए

डिज़ाइन टीम को यह जाँचना है कि मोज़ेक की सभी पंक्तियों में रंगों का कुल योग सही बैठता है। `combine-rows` बनाइए, जो पंक्तियों का एक ऐरे ले और क्रम में सभी टाइलों की एक ही सूची लौटाए।

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. एक पंक्ति का प्रतिबिंब बनाइए

सममित पैनलों के लिए टीम पंक्ति को दर्पण की तरह पलट देती है, और फिर उसकी नकल दूसरी तरफ रख देती है। `mirror-row` बनाइए, जो पंक्ति को उलटे क्रम में लौटाए।

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. यह रंग पंक्ति में कहाँ है?

`tile-position` बनाइए, जो एक पंक्ति और एक रंग ले और पंक्ति में उस रंग वाली पहली टाइल का इंडेक्स (0 से शुरू) लौटाए। अगर वह रंग पंक्ति में न हो, तो `f` लौटाइए।

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. क्या इस पंक्ति में यह रंग है?

`has-colour?` बनाइए, जो एक पंक्ति और एक रंग ले और अगर वह रंग पंक्ति में कहीं भी हो तो `t` लौटाए, वरना `f`।

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
