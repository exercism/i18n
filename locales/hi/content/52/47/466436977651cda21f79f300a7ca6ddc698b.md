## इस्तेमाल कैसे करें

### बिल्ड

`npx blueprint build` या `yarn blueprint build`

### टेस्ट

`npx blueprint test` या `yarn blueprint test`

### डिप्लॉय कीजिए या कोई और स्क्रिप्ट चलाइए

`npx blueprint run` या `yarn blueprint run`

### नया कॉन्ट्रैक्ट जोड़िए

`npx blueprint create ContractName` या `yarn blueprint create ContractName`
