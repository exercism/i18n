# टेस्ट

PureScript अभ्यासों के टेस्ट सूट spago टूल की मदद से अभ्यास वाली डायरेक्टरी से चलाए जा सकते हैं:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

जहाँ <exercism-workspace> CLI की वर्कस्पेस डायरेक्टरी है।

उदाहरण के लिए:

    cd ~/exercism/purescript/accumulate
    spago test
