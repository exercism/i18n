# निर्देश

आप खाली बफर बनाएँगे और फिबोनाची अनुक्रम की पहली पाँच संख्याएँ, यानी एलिमेंट, लिखेंगे।

फिबोनाची अनुक्रम संख्याओं का एक समूह है जिसमें हर अगला एलिमेंट पिछले दो का जोड़ होता है। हम इस अनुक्रम की शुरुआत 1 से करते हैं। इसलिए पहले दो एलिमेंट 1 और 1 होते हैं।

## 1. `count` शून्यों का बफर बनाइए

एक ऐसा फंक्शन बनाइए जो `count` शून्यों का बफर बनाता है।

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. फिबोनाची अनुक्रम के पहले पाँच एलिमेंट लिखिए

एक ऐसा फंक्शन बनाइए जो फिबोनाची अनुक्रम की पहली पाँच संख्याएँ लौटाता है।
इसके पहले पाँच एलिमेंट `1, 1, 2, 3, 5` हैं।

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
