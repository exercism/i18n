# निर्देश

आप एक रोल-प्लेइंग गेम बनाने पर काम कर रहे हैं। खिलाड़ी के पात्र को इस तरह दर्शाया गया है:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

इस गेम में खिलाड़ियों को जादू करना शुरू करने से पहले लेवल 10 तक पहुँचना होता है, तभी उनका माना पूल खुलता है। उससे पहले Player का माना `None` होता है।

आप इस गेम में दो चीज़ों पर काम कर रहे हैं, फिर से ज़िंदा करने की सुविधा और जादू करने की सुविधा।

`revive` मेथड को यह जाँचना चाहिए कि Player वाकई मर चुका है (उसकी हेल्थ 0 तक पहुँच गई है), और अगर ऐसा है, तो मेथड को 100 हेल्थ वाली एक नई Player इंस्टेंस लौटानी चाहिए।
अगर Player का लेवल 10 या उससे अधिक है, तो उसे 100 माना के साथ भी ज़िंदा किया जाना चाहिए।
अगर Player का लेवल 10 से कम है, तो उसका माना `None` होना चाहिए। `revive` मेथड को Player का लेवल बनाए रखना चाहिए।

```rust
let dead_player = Player { health: 0, mana: None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: None, level: 2 }
```

अगर `revive` मेथड को ऐसे Player पर कॉल किया जाए जिसकी हेल्थ 1 या उससे अधिक है, तो मेथड को `None` लौटाना चाहिए।

```rust
let alive_player = Player { health: 1, mana: Some(15), level: 11 };
alive_player.revive()
// Returns None
```

`cast_spell` मेथड Player का एक म्यूटेबल रेफरेंस लेता है, और साथ में एक `mana_cost` पैरामीटर भी, जो बताता है कि इस जादू पर कितना माना लगता है। यह उस नुकसान की मात्रा लौटाता है जो जादू चलने पर होता है, और अगर जादू सफलतापूर्वक चलता है, तो यह मात्रा हमेशा जादू के माना खर्च की दोगुनी होती है।

- अगर खिलाड़ी के पास माना पूल नहीं है, तो जादू करने की कोशिश करने पर उसकी हेल्थ जादू के माना खर्च जितनी घटनी चाहिए। लौटाया गया नुकसान 0 होना चाहिए।

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, None);
  ```

- अगर खिलाड़ी के पास माना पूल है लेकिन माना काफी नहीं है, तो मेथड को पूल पर कोई असर नहीं डालना चाहिए, बल्कि 0 लौटाना चाहिए।

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Some(3));
  ```

- वरना Player के माना पूल से `mana_cost` घटाया जाना चाहिए और उतना ही नुकसान लौटाया जाना चाहिए।

  ```rust
  let wizard = Player { health: 123, mana: Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Some(20));
  ```
