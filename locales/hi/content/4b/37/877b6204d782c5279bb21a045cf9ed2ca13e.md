# परिचय

## Julia में बूलियन

सही या गलत वैल्यू को `Bool` टाइप से दर्शाया जाता है।
`Bool` टाइप में केवल दो वैल्यू होती हैं: `true` और `false`.

```julia-repl
julia> true
true

julia> false
false
```

## बूलियन ऑपरेटर

Julia में तीन बूलियन ऑपरेटर हैं।

`&&` बूलियन "और" है।
अगर `&&` के *दोनों* ओर के एक्सप्रेशन `true` हों, तो इसका परिणाम `true` होता है।

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` बूलियन "या" है।
अगर `||` के *किसी भी एक* ओर का एक्सप्रेशन `true` हो, तो इसका परिणाम `true` होता है।

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` बूलियन "नहीं" है।
यह `true` और `false` वैल्यू को आपस में बदल देता है।

```julia-repl
julia> !true
false

julia> !false
true
```

जब एक्सप्रेशन लंबे और जटिल हों, तो अपना इरादा साफ रखने के लिए ब्रैकेट का उपयोग करना सबसे अच्छा है।

```julia-repl
julia> (true || false) && (false && true)
false
```
