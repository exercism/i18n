# टाइप कन्वर्ज़न के बारे में

Go में अलग-अलग टाइप के बीच स्पष्ट कन्वर्ज़न ज़रूरी होता है।
उदाहरण के लिए, इससे कंपाइलर एरर मिलती है:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

टाइप के बीच कन्वर्ज़न (जिसे **टाइप कास्टिंग** भी कहा जाता है) उस टाइप के नाम वाले फंक्शन से किया जाता है जिसमें बदलना होता है।
किसी वैल्यू `v` को टाइप `T` में `T(v)` लिखकर बदला जाता है।
उदाहरण के लिए, किसी `int` को `float64` में बदलने के लिए आपको यह करना होगा:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

यही बात किसी भी कस्टम टाइप पर लागू होती है:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## प्रिमिटिव टाइप और स्ट्रिंग के बीच कन्वर्ज़न

प्रिमिटिव टाइप (जैसे `int`) और `string` के बीच बदलने के लिए एक `strconv` पैकेज होता है।

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

चेतावनी: स्टैंडर्ड कास्टिंग तरीका इस्तेमाल करने पर यह व्यवहार नहीं मिलता।
उदाहरण के लिए:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

यहाँ कुछ और आम कन्वर्ज़न मेथड दिए गए हैं:

| मेथड        | उद्देश्य                     |
| ----------- | --------------------------- |
| ParseBool   | `string` को `bool` में बदलें  |
| FormatBool  | `bool` को `string` में बदलें  |
| ParseFloat  | `string` को `float` में बदलें |
| FormatFloat | `float` को `string` में बदलें |
| ParseInt    | `string` को `int` में बदलें   |
| FormatInt   | `int` को `string` में बदलें   |
