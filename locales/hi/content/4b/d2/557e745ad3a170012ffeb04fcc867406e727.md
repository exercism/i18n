# इंस्टॉलेशन

## Windows उपयोगकर्ता

कृपया [Windows Subsystem for Linux][wsl-link] इंस्टॉल कीजिए और अगला भाग देखिए।

## Linux/Mac उपयोगकर्ता

### brew की मदद से इंस्टॉल करना

Chapel इंस्टॉल करने का यह सबसे आसान तरीका है।
इससे आपको एक बुनियादी काम करने वाला इंस्टॉलेशन मिलेगा, जो Exercism ट्रैक पर काम करने के लिए उपयुक्त है।
अधिक अनुभवी उपयोगकर्ता Chapel को सोर्स कोड से बनाना चाह सकते हैं (अगला भाग)।

0. अगर आपने पहले नहीं किया है, तो [brew][brew-link] पैकेज मैनेजर इंस्टॉल कीजिए।
1. सबसे पहले `brew update` चलाकर यह पक्का कीजिए कि brew अप-टू-डेट है।
2. `brew install chapel` चलाकर Chapel इंस्टॉल कीजिए।
3. `chpl --version` चलाकर जाँचिए कि इंस्टॉलेशन सफल रहा।

इससे Chapel कंपाइलर (`chpl`), पैकेज मैनेजर `mason` और डॉक्यूमेंटेशन बनाने वाला टूल `chpldoc` इंस्टॉल हो जाएगा। हम `mason` का इस्तेमाल टेस्ट चलाने के लिए करेंगे। Exercism के लिए `chpldoc` की ज़रूरत नहीं है, लेकिन अगर (जब :) ) आप Chapel में अपनी लाइब्रेरी बनाना चाहें, तो इसका होना अच्छा रहता है।

### सोर्स कोड से Chapel बनाना

अधिक अनुभवी उपयोगकर्ता Chapel को खुद सोर्स कोड से बनाना चाह सकते हैं। इसके लिए,

1. [आवश्यक चीज़ें][prereqs-link] इंस्टॉल कीजिए।
2. Chapel के नवीनतम रिलीज़ का आर्काइव [डाउनलोड][download-link] कीजिए और उसे खोल लीजिए।
3. सबसे पहले आपको यह तय करना है कि Chapel कहाँ इंस्टॉल करना है और उस जगह की तैयारी करनी है।
यह दिए गए `configure` स्क्रिप्ट को चलाकर किया जा सकता है।
सिर्फ़ इसे चलाने से

```
./configure
```

बाइनरी, लाइब्रेरी और शेयर्ड फाइलें `/usr/local/` में इंस्टॉल हो जाएँगी। आप `--prefix` ऑप्शन से इसे बदल सकते हैं।
उदाहरण के लिए, अगर आप Chapel को `~/.chapel` में इंस्टॉल करना चाहते हैं, तो आप यह कर सकते हैं

```
./configure --prefix=~/.chapel
```

4. कंपाइलर और टूल इंस्टॉल करने के लिए, यह चलाइए

```
make
make mason
make chpldoc
make install
```

5. यह पक्का कीजिए कि `/dir/for/install/bin` फोल्डर आपके `PATH` वेरिएबल में है।

Chapel इंस्टॉल करने और सोर्स कोड से काम करने के अलग-अलग तरीकों के बारे में अधिक जानकारी के लिए डॉक्यूमेंटेशन में [Chapel बनाना][building-link] पेज देखिए।
