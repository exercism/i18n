# परिचय

## सही और गलत

Ruby में `true` और `false` से सही और गलत तार्किक स्थितियाँ व्यक्त की जाती हैं।

```ruby
happy = true
sad = false
```

## समानता और तुलना

Ruby आपको सामान्य समानता चिह्नों की मदद से ऑब्जेक्ट की आपस में तुलना करने देता है:

- `==` से देखिए कि दो ऑब्जेक्ट बराबर हैं या नहीं
- `>` से देखिए कि बाईं ओर का ऑब्जेक्ट दाईं ओर के ऑब्जेक्ट से **बड़ा** है या नहीं
- `<` से देखिए कि बाईं ओर का ऑब्जेक्ट दाईं ओर के ऑब्जेक्ट से **छोटा** है या नहीं।
- `>=` या `<=` से क्रमशः "बड़ा या बराबर" और "छोटा या बराबर" की जाँच कीजिए।

आप सामान्य ऑपरेटरों के साथ बूलियन लॉजिक भी इस्तेमाल कर सकते हैं:

- `&&` या `and` से जाँचिए कि `x and y` सही हैं
- `||` या `or` से जाँचिए कि `x or y` सही है।
- `!` या `not` से समानता उलट दीजिए, जैसे `x != y` (x, y के बराबर नहीं है)

यहाँ कुछ उदाहरण हैं:

```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
