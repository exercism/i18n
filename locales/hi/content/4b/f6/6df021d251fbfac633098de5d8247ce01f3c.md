# वेरिएडिक पैरामीटर

Swift में [_वेरिएडिक पैरामीटर_][variadic-parameters] किसी फंक्शन के एक ही पैरामीटर में एक जैसे टाइप की शून्य या अधिक वैल्यू लेने देते हैं।
यह पैरामीटर के टाइप एनोटेशन के आगे `...` जोड़कर लिखा जाता है।

ये वैल्यू अपने आप एक ऐरे में समूहित हो जाती हैं, जिनके एलिमेंट उसी टाइप के होते हैं जो वेरिएडिक पैरामीटर का टाइप होता है।

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

वेरिएडिक पैरामीटर इस्तेमाल करते समय Swift में दो सीमाएँ हैं:

1. Swift किसी फंक्शन में सिर्फ एक ही वेरिएडिक पैरामीटर रखने देता है। यह तय किया गया है कि Swift के आने वाले रिलीज़ में यह प्रतिबंध हटा दिया जाएगा, लेकिन फिलहाल यह अब भी लागू है।
2. अगर किसी फंक्शन की परिभाषा में वेरिएडिक पैरामीटर के बाद भी पैरामीटर आते हैं, तो वेरिएडिक पैरामीटर के बाद वाले पहले पैरामीटर के लिए आर्गुमेंट लेबल होना _ज़रूरी_ है।
