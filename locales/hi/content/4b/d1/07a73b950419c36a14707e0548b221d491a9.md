# इसके बारे में

PHP अंकगणितीय गणनाओं के लिए कई ऑपरेटर देती है। गणित में ऑपरेशनों का जो मानक क्रम होता है, PHP अपने अंकगणितीय ऑपरेटरों के लिए उसी का पालन करती है। PHP जो ऑपरेटर देती है, वे ये हैं:

* आइडेंटिटी (+)
* नेगेशन (-)
* जोड़ (+)
* घटाव (-)
* गुणा (*)
* भाग (/)
* मॉड्यूलो (%)
* घात (**)

चलिए देखते हैं कि इनमें से हर एक क्या करता है और इनका इस्तेमाल कैसे किया जा सकता है:

## आइडेंटिटी (+)

आइडेंटिटी ऑपरेटर (+) एक ही वैल्यू पर काम करता है (यूनरी ऑपरेटर)। इसका परिणाम वेरिएबल की `float` या `int` वैल्यू होता है।

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## नेगेशन (-)

नेगेशन ऑपरेटर एक ही वैल्यू पर काम करता है (यूनरी ऑपरेटर) और उस संख्या की विपरीत वैल्यू लौटाता है।

```php
$forward = 65;
$reverse = -$forward; // -65
```

## जोड़ (+) और घटाव (-)

जोड़ ऑपरेटर अपने दोनों ओर की दो वैल्यू जोड़ देता है, जबकि घटाव ऑपरेटर बाईं वैल्यू में से दाईं वैल्यू घटा देता है।

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## भाग (/)

भाग ऑपरेटर बाईं वैल्यू को दाईं वैल्यू से भाग देने का परिणाम देता है। अगर दाईं वैल्यू 0 हो, तो इससे `DivisionByZeroError` एरर मिलती है।

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## गुणा (*)

गुणा ऑपरेटर बाईं और दाईं वैल्यू को आपस में गुणा करने का परिणाम लौटाता है।

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## मॉड्यूलो (%)

मॉड्यूलो ऑपरेटर वह शेषफल लौटाता है जो बाईं वैल्यू को दाईं वैल्यू से भाग देने पर बचता है। यह ऑपरेटर यह पता लगाने में बहुत काम आता है कि कोई संख्या किसी दूसरी संख्या में पूरी तरह बँटती है या नहीं, कोई वैल्यू सम है या विषम, और भी बहुत कुछ।

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## घात (**)

घात ऑपरेटर का उपयोग बाईं वैल्यू को दाईं वैल्यू की घात तक बढ़ाने के लिए किया जाता है। PHP 5.6 से पहले यही काम करने के लिए आपको `pow` फंक्शन इस्तेमाल करना पड़ता था।

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

घात ऑपरेटर दोनों ओर पूर्णांक और दशमलव संख्याएँ स्वीकार करता है, इसलिए आप इससे वर्गमूल (या दूसरे मूल) या और जटिल घातीय वैल्यू निकाल सकते हैं।

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## ऑपरेशनों का क्रम

PHP गणित में ऑपरेशनों के मानक क्रम का पालन करती है। इसका मतलब है कि ऑपरेशन बाएँ से दाएँ करने के बजाय हर ऑपरेटर की एक प्राथमिकता होती है, और ऑपरेशन उनकी प्राथमिकता के अनुसार पूरे किए जाते हैं। ऑपरेशनों का क्रम यह है:

* कोष्ठक
* घात
* गुणा, भाग
* जोड़, घटाव

गुणा और भाग दोनों की प्राथमिकता एक ही स्तर की है। इसी तरह जोड़ और घटाव की प्राथमिकता भी एक ही स्तर की है।

इसका मतलब है कि नीचे दी गई वैल्यू 10 नहीं, 17 होगी, क्योंकि गुणा की प्राथमिकता जोड़ से अधिक होती है:

```php
$value = 2 + 3 * 5;
```

PHP कई काम के असाइनमेंट ऑपरेटर भी देती है, जो अंकगणितीय ऑपरेटरों को असाइनमेंट के साथ जोड़ देते हैं: यानी जब आप किसी वेरिएबल पर कोई ऑपरेशन करते हैं और परिणाम को वापस उसी वेरिएबल में रख देते हैं। इन पर `Assignment Operators` अवधारणा में चर्चा की जाएगी।
