# विवरण

ऐसे डेटा स्ट्रक्चर जिनमें शून्य या उससे अधिक एलिमेंट रखे जा सकते हैं, _कलेक्शन_ कहलाते हैं।
Ruby में **ऐरे** एक ऐसा कलेक्शन है जो उस क्रम को बनाए रखता है जिसमें उसके ऑब्जेक्ट जोड़े जाते हैं।
ऐरे में कोई भी ऑब्जेक्ट रखा जा सकता है।
ऐरे में ऑब्जेक्ट जोड़े जा सकते हैं, और इंडेक्स की मदद से उन्हें ऐरे से निकाला जा सकता है।
Ruby में ऐरे की इंडेक्सिंग शून्य से शुरू होती है, यानी पहले एलिमेंट का इंडेक्स हमेशा शून्य होता है:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Ruby में ऐरे बनाने के कई तरीके हैं:

- लिटरल कंस्ट्रक्टर `[]` का इस्तेमाल करके _(सबसे आम)_
- सीधे `Array.new` को कॉल करके
- Kernel का `Array()` मेथड कॉल करके

`Array.new` मेथड दो वैकल्पिक आर्गुमेंट लेता है: ऐरे का शुरुआती साइज़, और एक डिफॉल्ट ऑब्जेक्ट।

जब साइज़ और डिफॉल्ट दोनों दिए जाते हैं, तो ऐरे में उस डिफॉल्ट ऑब्जेक्ट की `size` प्रतियाँ भर दी जाती हैं।

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

चूँकि ऐरे के सारे एलिमेंट एक ही हैश रखते हैं, इसलिए उनमें से किसी एक में किया गया बदलाव बाकी सब पर भी असर डालेगा।

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

अगर आपको अलग-अलग प्रतियाँ चाहिए, तो ब्लॉक वाला रूप इस्तेमाल कीजिए, जो हर बार ऐरे के एलिमेंट को इनिशलाइज़ करते समय उस ब्लॉक का परिणाम लेता है:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ruby के ऐरे की एक और विशेषता यह है कि वे [Enumerable][enumerable-module] मॉड्यूल को मिला लेते हैं, जो ऐरे के एलिमेंट पर इटरेशन करने, उन्हें ढूँढने, छाँटने और फिल्टर करने जैसे कामों के लिए बहुत सारे काम के मेथड जोड़ देता है।

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
[for-loop]: https://launchschool.com/books/ruby/read/loops_iterators#forloops
