# परिचय

मेथड एक ऐसा फंक्शन होता है जिसमें एक खास _रिसीवर_ आर्गुमेंट होता है।
रिसीवर अपनी अलग आर्गुमेंट लिस्ट में `func` कीवर्ड और मेथड के नाम के बीच आता है।

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

आप ऐसा मेथड ही बना सकते हैं जिसका रिसीवर ऐसे टाइप का हो जो मेथड वाले ही पैकेज में परिभाषित हो।

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

स्ट्रक्ट पर बने मेथड को डॉट नोटेशन से कॉल किया जा सकता है।

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

ध्यान दीजिए कि हमने `Person` इंस्टेंस `p` पर `Greetings()` मेथड कैसे कॉल किया।
यह बिल्कुल वैसे ही है जैसे आप किसी ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग भाषा में मेथड कॉल करते हैं।

याद रखिए: मेथड बस एक रिसीवर आर्गुमेंट वाला फंक्शन ही है।
मेथड नामों के टकराव से बचने में मदद करते हैं। चूँकि मेथड किसी एक खास रिसीवर टाइप से जुड़ा होता है, इसलिए अलग-अलग टाइप पर एक ही मेथड नाम रखा जा सकता है।

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

रिसीवर दो तरह के होते हैं: वैल्यू रिसीवर और पॉइंटर रिसीवर।

अब तक हमने जो भी मेथड देखे, वे सब वैल्यू रिसीवर वाले थे। इसका मतलब है कि उन्हें मेथड को दी गई वैल्यू की एक कॉपी मिलती है, यानी मेथड के अंदर रिसीवर में किया गया कोई भी बदलाव कॉल करने वाले को दिखाई नहीं देता।

रिसीवर जिस वैल्यू की ओर इशारा करता है उसे बदलने के लिए आप पॉइंटर रिसीवर वाले मेथड घोषित कर सकते हैं।
इसके लिए टाइप के नाम से पहले एक `*` लगाया जाता है।
जैसे `rect` टाइप के लिए पॉइंटर रिसीवर `*rect` घोषित किया जाएगा।
ऐसे बदलाव मेथड को कॉल करने वाले को भी दिखाई देते हैं।

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
