# परिचय

`let` एक्सप्रेशन से एक लोकल स्कोप बनाया जाता है। यह कुछ खास परिस्थितियों में काम आता है:

- एक्सप्रेशन को सरल बनाने के लिए
- बीच के एक्सप्रेशनों के परिणामों को नाम देने के लिए
- किसी एक्सप्रेशन के बड़ा हो जाने पर उसे छोटे-छोटे हिस्सों में बाँटने के लिए

`let` एक्सप्रेशन के अंदर आप लगभग सारी चीज़ें कर सकते हैं, डीस्ट्रक्चरिंग भी (इस पर और जानकारी आगे के अभ्यासों में मिलेगी)। लेकिन इसके अंदर नया Custom Type या Type Alias बनाना संभव नहीं है।

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
