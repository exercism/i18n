# परिचय

ऑब्जेक्ट अपनी स्थिति खुद रख सकते हैं। इसके लिए वे _इंस्टेंस वेरिएबल_ बनाते हैं, जो वेरिएबल के नाम से पहले `@` लगाकर बनाए जाते हैं।

```ruby
@name = 2
```

ऑब्जेक्ट आम तौर पर अपनी शुरुआती स्थिति `initialize` मेथड में तय करते हैं। यह मेथड तब अपने आप कॉल होता है जब किसी क्लास पर `new` कॉल किया जाता है।

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

`initialize` मेथड आर्गुमेंट भी ले सकता है, ताकि हर इंस्टेंस अपनी अलग शुरुआती स्थिति के साथ शुरू हो सके:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

_इंस्टेंस_ वेरिएबल को बाहर से पढ़ने और लिखने से निजी मानिए। इंस्टेंस वेरिएबल पढ़ने और बदलने के लिए _इंस्टेंस_ मेथड का इस्तेमाल करना चाहिए:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
