# परिचय

## रिकर्शन

रिकर्शन वाले फंक्शन ऐसे फंक्शन होते हैं जो खुद को कॉल करते हैं।

एक रिकर्शन वाले फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्सिव केस_ होना चाहिए।

बेस केस फंक्शन को दोबारा कॉल किए बिना एक वैल्यू लौटाता है। रिकर्सिव केस फंक्शन को दोबारा कॉल करता है और इनपुट को इस तरह बदल देता है कि वह किसी समय बेस केस से मेल खाने लगे।

बहुत बार हर केस को उसके अपने फंक्शन क्लॉज़ में लिखा जाता है।

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
