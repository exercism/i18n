# परिचय

## तुलना ऑपरेटर

Julia में तुलना ऑपरेटर बहुत-सी दूसरी भाषाओं जैसे ही हैं, हालाँकि गणित पसंद करने वालों के लिए इनमें कुछ अतिरिक्त विकल्प भी हैं।

समानता के लिए ऑपरेटर `==` (बराबर) और `!=` या `≠` (बराबर नहीं) हैं।

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

इसके अलावा बड़ा/छोटा बताने वाले कई ऑपरेटर भी हैं।

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

जैसा Julia में अक्सर होता है, उपयुक्त एडिटर में गणितीय चिह्न का इस्तेमाल करना आसान हो जाता है। `≠`, `≤` या `≥` पाने के लिए `\ne`, `\le` या `\ge` लिखकर `TAB` दबाइए।

पिछले उदाहरण में सिर्फ संख्याएँ हैं, लेकिन पाठ्यक्रम के दूसरे हिस्सों में हम देखेंगे कि कई और डेटा टाइप में भी क्रम का अर्थ होता है और उन्हें बड़ा/छोटा जाँचने के लिए तुलना किया जा सकता है।

तुलना ऑपरेटरों को एक के बाद एक जोड़ा जा सकता है, जिससे साफ़ और संक्षिप्त सिंटैक्स लिखना संभव होता है:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

पिछला उदाहरण `1 ≤ n && n ≤ 5` का ही दूसरा रूप है।

## `if` के साथ शाखाएँ बनाना

`if` स्टेटमेंट का पूरा रूप ऐसा होता है:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

यहाँ गोल ब्रैकेट `()` या घुंघराले ब्रैकेट `{}` की ज़रूरत नहीं पड़ती, और इंडेंटेशन "सिर्फ" कोड पढ़ने में आसानी के लिए है _(लेकिन पढ़ने में आसानी बहुत ज़रूरी है!)_।

`elseif` और `else` दोनों वैकल्पिक हैं, और एक से ज़्यादा `elseif` ब्लॉक भी हो सकते हैं।
लेकिन `end` लिखना ज़रूरी है।

`if` स्टेटमेंट को एक के अंदर एक (नेस्टेड) भी रखा जा सकता है, हालाँकि कोड पढ़ने में आसानी के लिए ब्रैकेट, इंडेंटेशन और कमेंट का सोच-समझकर इस्तेमाल करना बेहतर होता है।

`if` स्टेटमेंट का सबसे छोटा रूप कुछ ऐसा होगा:

```julia
if n < 0
    n = 0
end
```

याद रखिए: शर्त की जगह सिर्फ वे एक्सप्रेशन इस्तेमाल किए जा सकते हैं जो `true` या `false` देते हैं।
Julia जानबूझकर "ट्रुथीनेस" जैसी किसी धारणा से बचती है, इसलिए शून्य वैल्यू, खाली स्ट्रिंग और खाली ऐरे `false` के बराबर _नहीं_ होते।

## टर्नरी ऑपरेटर

एक आम और सीधी स्थिति यह है कि किसी शर्त के आधार पर दो वैल्यू में से एक चुननी होती है।

बहुत-सी भाषाओं की तरह Julia में भी टर्नरी ऑपरेटर है, जो इसे और संक्षिप्त बना देता है।

इसका सिंटैक्स `conditional ? value_if_true : value_if_false` है।

तो पिछला उदाहरण ऐसे लिखा जा सकता है:

```julia
n = n < 0 ? 0 : n
```

कंपाइलर को गोल ब्रैकेट की ज़रूरत नहीं होती, लेकिन इससे कोड पढ़ने में आसानी हो सकती है।
