# परिचय

Go में आप `for` और एक इंडेक्स की मदद से `slice` पर इटरेशन कर सकते हैं, या `range` का इस्तेमाल कर सकते हैं।
`range` की मदद से आप `map` पर भी इटरेशन कर सकते हैं।

हर इटरेशन दो वैल्यू लौटाता है: इंडेक्स/की, और उस इंडेक्स/की पर मौजूद एलिमेंट की एक प्रति।

## स्लाइस पर इटरेशन कीजिए

स्लाइस पर लूप चलाना बहुत आसान है, और एलिमेंट उसी क्रम में आते हैं जिसकी अपेक्षा की जाती है।

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## मैप पर इटरेशन कीजिए

मैप पर इटरेशन करने से एक नई समस्या खड़ी होती है।
अब क्रम यादृच्छिक होता है।

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
ऊपर दिया गया आउटपुट गलत लग सकता है, क्योंकि कोई यह अपेक्षा करेगा कि मैप की घोषणा में सबसे पहला की/वैल्यू जोड़ा `9 10` सबसे पहले प्रिंट हो, सबसे अंत में नहीं।
लेकिन मैप स्वभाव से क्रमरहित होते हैं, यानी इनमें कोई पहला या अंतिम की/वैल्यू जोड़ा नहीं होता।
इसलिए जब आप मैप की एंट्री पर इटरेशन करते हैं, तो जिस क्रम में वे एंट्री देखी जाएँगी वह यादृच्छिक होगा और किसी तय पैटर्न का पालन नहीं करेगा।
इसका मतलब है कि ऊपर दिया गया आउटपुट संभव है, लेकिन जब आप इसे खुद चलाएँगे तो आपको कुछ और मिल सकता है।
इस बारे में और जानने के लिए [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause) देखिए।
~~~~

## की या वैल्यू छोड़कर इटरेशन

Go में अगर किसी वेरिएबल का इस्तेमाल न किया जाए, तो बिल्ड के समय एरर मिलती है।
कभी-कभी आपको सिर्फ वैल्यू की ज़रूरत होती है, जैसा पहले उदाहरण में दिखाया गया है:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

आप `i` की जगह `_` लिख सकते हैं, जो कंपाइलर को बताता है कि हम उस वैल्यू का उपयोग नहीं करते:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

अगर आप सिर्फ इंडेक्स प्रिंट करना चाहते हैं, तो आप `x` की जगह `_` लिख सकते हैं, या घोषणा को बिल्कुल छोड़ सकते हैं:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## टाइप बनाना

टाइप की परिभाषा से एक नया नामित टाइप बनता है, जो हर दूसरे टाइप से अलग होता है। यह अंतर तब भी रहता है जब दोनों का अंतर्निहित टाइप एक ही हो।

```go
type File []bool
```

यहाँ `File` शतरंज के बोर्ड के एक खड़े कॉलम को दर्शाता है, जिसे आमतौर पर A से H तक नाम दिया जाता है।
इस कॉलम के हर खाने को एक बूलियन वैल्यू से दर्शाया जाता है, जो बताती है कि वह खाना भरा हुआ है या नहीं।
अब जब `File` बन चुका है, तो हम इसे दूसरी परिभाषाओं के अंदर भी इस्तेमाल कर सकते हैं:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` फाइल के नामों को `File` वैल्यू से जोड़ता है।
हर `File` बूलियन की एक स्लाइस होती है, जो एक शतरंज फाइल के खानों को दर्शाती है।
इन टाइप परिभाषाओं के बिना `board` का टाइप `map[string][]bool` होता, जिससे यह समझना मुश्किल हो जाता कि हम किस चीज़ को दर्शा रहे हैं।
