# जानकारी

संग्रह की परिभाषा में आम तौर पर कोणीय ब्रैकेट के अंदर एक प्लेसहोल्डर रखा जाता है, जिसे परंपरा से अक्सर T कहा जाता है। ऐसे संग्रह को जेनेरिक टाइप कहा जाता है। इससे संग्रह का उपयोग करने वाला व्यक्ति यह तय कर सकता है कि संग्रह में किस टाइप की चीज़ें रखी जाएँ। ऊपर दिए गए उदाहरण कोड में हम स्ट्रिंग का एक ऐरे बना रहे हैं।

किसी क्लास या फंक्शन को `@:generic` एट्रिब्यूट की मदद से **जेनेरिक** बनाया जाता है। इससे कंपाइलर उस क्लास या फंक्शन को जेनेरिक के रूप में पहचान लेता है:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
