# परिचय

[कंप्रिहेंशन][for] _एन्यूमरेबल_ को आसानी से और घोषणात्मक ढंग से बदलने की सुविधा देते हैं। Elixir में एन्यूमरेबल पर इटरेशन करने के लिए ये एक तरह की _सिंटैक्टिक शुगर_ हैं।

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

कंप्रिहेंशन के तीन हिस्से होते हैं:

1. _जनरेटर_:
   - ऐसे स्ट्रक्चर से एन्यूमरेट की गई वैल्यूएँ जो [_Enumerable_][enumerable] प्रोटोकॉल लागू करते हैं।
   - एन्यूमरेट की गई वैल्यूओं के अंदरूनी हिस्से निकालने वाले पैटर्न मैचिंग एक्सप्रेशन।
2. _फिल्टर_: बूलियन शर्तें, जिनसे यह तय होता है कि नई वैल्यू बनाते समय किन एन्यूमरेट की गई वैल्यूओं का इस्तेमाल करना है।
3. _कलेक्टेबल_: एक स्ट्रक्चर जो [_Collectable_][collectable] प्रोटोकॉल लागू करता है और नई वैल्यूओं को इकट्ठा करने के काम आता है।

कंप्रिहेंशन एक लाइन में भी लिखे जा सकते हैं और कई लाइनों में भी। जब एक से अधिक जनरेटर इस्तेमाल होते हैं, तो जनरेट की गई वैल्यूओं का [कार्तीय गुणनफल][cartesian-product] बनाया जाता है। इसका मतलब है कि पहले जनरेटर से जनरेट हुई हर वैल्यू को दूसरे जनरेटर से जनरेट हुई हर वैल्यू के साथ एक-एक बार जोड़ा जाता है।

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

do-ब्लॉक में दी गई वैल्यू _कलेक्टेबल_ में **एन्यूमरेबल से जनरेट हुई हर वैल्यू के लिए** डाली जाती है।

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

कंप्रिहेंशन में पैटर्न मैचिंग हो सकती है, चाहे `<-` के बाईं ओर, चाहे अपनी अलग लाइन पर।

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
