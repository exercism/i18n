# अपरिवर्तनीय क्लास

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## क्या बदलता है

| | साधारण क्लास | अपरिवर्तनीय क्लास |
| --- | --- | --- |
| असाइनमेंट | ऑब्जेक्ट साझा करता है | वैल्यू की नकल करता है |
| `void` हो सकता है | हाँ | नहीं |
| `attr` राइटर | `x.a := v` | `x := x.a(v)` |
| `new` | हाँ | नहीं; `x : SAME` पहले से मौजूद है |

एक अपरिवर्तनीय ऑब्जेक्ट `void` नहीं हो सकता, इसलिए `void(b)` हमेशा false होता है, और ऐसे
ऑब्जेक्ट का कोई भी रूटीन ऑब्जेक्ट के अभाव में विफल नहीं हो सकता। इससे एक तरह की सारी
गलतियाँ हट जाती हैं, पर कीमत यह है कि आप कभी यह नहीं कह सकते कि "अभी तक कोई बेयरिंग नहीं है"।

## वैल्यू कहाँ रहती है

वैल्यू वहीं रखी जाती है जहाँ वेरिएबल होता है, यानी किसी दूसरे ऑब्जेक्ट के अंदर या स्टैक पर,
न कि किसी रेफरेंस से पहुँचकर। इसलिए एक `ARRAY{BEARING}` में खुद बेयरिंग रखी जाती हैं,
उनके पॉइंटर नहीं। इससे ऐरे छोटा रहता है और उसमें चलना तेज़ होता है।

इसकी कीमत है कॉपी करना: किसी बड़े अपरिवर्तनीय ऑब्जेक्ट को पास करने पर वह हर बार कॉपी
हो जाता है। इसलिए इन्हें छोटा ही रखना बेहतर है।

## एट्रिब्यूट रूटीन

`readonly attr degrees : INT` दो रूटीन देता है:

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

दूसरा रूटीन `readonly` के अंदर भी मौजूद रहता है, क्योंकि वह कुछ बदलता ही नहीं, बल्कि एक नई
वैल्यू बनाता है। साधारण `attr` के साथ वह public रहता है, पर `private attr` के साथ नहीं।

## is_eq और str

इनमें से कोई भी पहले से नहीं मिलता। `=` के लिए `is_eq` लिखिए, और `str` इसलिए लिखिए ताकि
ऑब्जेक्ट को प्रिंट किया जा सके और स्ट्रिंग से जोड़ा जा सके:

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

`str` लिखने से क्लास `$STR` के अनुरूप हो जाती है, और यही वजह है कि `+` और `#OUT` उसे
स्वीकार कर लेते हैं।

## बिल्ट-इन क्लास

`INT`, `BOOL`, `CHAR`, `FLTD` और `TUP`, ये सभी अपरिवर्तनीय क्लास हैं। इनमें कुछ भी खास नहीं
है: लाइब्रेरी में ये भी उसी तरह Sather में लिखी गई हैं, और ऊपर बताई गई वजहों से ही वैसा ही
व्यवहार करती हैं।
