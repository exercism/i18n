# निर्देश

जादूगर बनने की राह पर चल रही एलिस को कुछ बुनियादी बातों का अभ्यास करना है। उसके पास कार्डों का एक ढेर है, जिसके साथ वह कुछ करना चाहती है।

चीज़ें थोड़ी आसान बनाने के लिए वह सिर्फ 1 से 10 तक के कार्ड इस्तेमाल करती है, इसलिए उसके कार्डों के ढेर को संख्याओं के ऐरे से दर्शाया जा सकता है। किसी कार्ड की जगह ऐरे के इंडेक्स से मेल खाती है। यानी जगह 0 पहले कार्ड को दर्शाती है, जगह 1 दूसरे कार्ड को, और इसी तरह आगे भी।

दो अपवाद हैं: `getItem`, जिसे दी गई जगह वाला कार्ड लौटाना चाहिए, और `checkSizeOfStack`, जिसे `true` लौटाना चाहिए जब दिया गया आकार मेल खाता हो।

## 1. ढेर से एक कार्ड निकालिए

एक कार्ड उठाने के लिए दिए गए ढेर से इंडेक्स `position` पर मौजूद कार्ड लौटाइए।

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. ढेर में एक कार्ड बदलिए

हाथ की सफाई दिखाइए और इंडेक्स `position` पर मौजूद कार्ड को दिए गए नए कार्ड से बदल दीजिए।
बदला हुआ ढेर लौटाइए।

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. ढेर के ऊपर एक कार्ड डालिए

ढेर के ऊपर एक नया कार्ड डालकर एक कार्ड प्रकट कीजिए।
बदला हुआ ढेर लौटाइए।

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. ढेर से एक कार्ड हटाइए

ढेर से दी गई `position` पर मौजूद कार्ड हटाकर एक कार्ड गायब कीजिए।
बदला हुआ ढेर लौटाइए।

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. ढेर के ऊपर का कार्ड हटाइए

ढेर के ऊपर वाला कार्ड हटाकर एक कार्ड गायब कीजिए।
बदला हुआ ढेर लौटाइए।

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. ढेर के नीचे एक कार्ड डालिए

ढेर के नीचे एक नया कार्ड डालकर एक कार्ड प्रकट कीजिए।
बदला हुआ ढेर लौटाइए।

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. ढेर के नीचे से एक कार्ड हटाइए

ढेर के नीचे वाला कार्ड हटाकर एक कार्ड गायब कीजिए।
बदला हुआ ढेर लौटाइए।

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. ढेर का आकार जाँचिए

जाँचिए कि ढेर का आकार `stackSize` के बराबर है या नहीं।

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
