# निर्देश.append

## आउटपुट फॉर्मेट

`solve()` मेथड से अपेक्षा है कि वह एक ऑब्जेक्ट लौटाए जिसमें ये प्रॉपर्टी हों:

- `moves` - लक्ष्य तक पहुँचने के लिए ज़रूरी बाल्टी क्रियाओं की संख्या
  (इसमें शुरुआती बाल्टी भरना भी शामिल है),
- `goalBucket` - जिस बाल्टी में लक्ष्य मात्रा पूरी हुई, उसका नाम,
- `otherBucket` - दूसरी बाल्टी में मौजूद मात्रा।

उदाहरण:

```json
{
  "moves": 5,
  "goalBucket": "one",
  "otherBucket": 2
}
```
