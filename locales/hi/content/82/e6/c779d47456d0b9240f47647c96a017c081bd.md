# परिचय

पैटर्न मैचिंग वह प्रक्रिया है जिसमें किसी वैल्यू के दिए गए, संभवतः गहरे, पैटर्न से मेल खाने के आधार पर अलग-अलग शाखाओं में जाया जाता है। Haxe में **पैटर्न मैचिंग** `switch` एक्सप्रेशन और अलग-अलग `case` एक्सप्रेशनों की मदद से की जाती है।

इस डेटा स्ट्रक्चर को देखिए:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- पैटर्न हमेशा ऊपर से नीचे के क्रम में मैच किए जाते हैं।
- सबसे ऊपर वाला पैटर्न जो इनपुट वैल्यू से मेल खाता है, उसका एक्सप्रेशन चलाया जाता है।
- `_` पैटर्न किसी भी चीज़ से मेल खाता है, इसलिए `case _:` और `default:` बराबर हैं।

## एनम मैचिंग

एनम को उनके कंस्ट्रक्टर के ज़रिए स्वाभाविक रूप से मैच किया जा सकता है:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
