# निर्देश

इस अभ्यास में आप छह गंभीरता लेवल वाले लॉग संदेशों को प्रोसेस करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है जिसका प्रारूप इस तरह है: `"[<LVL>]: <MESSAGE>"`।

ये अलग-अलग लॉग लेवल हैं:

| लेवल     | संक्षिप्त रूप   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. लॉग लेवल पार्स कीजिए

ऊपर दिए गए लॉग लेवल के अनुरूप छह एलिमेंट वाला एक `LogLevel` एनम बनाइए।
इसके बाद `parse_log_level` फंक्शन बनाइए, जो लॉग संदेश को पैरामीटर के रूप में लेता है और उसके लेवल का एनम सदस्य लौटाता है।

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. अज्ञात लॉग लेवल को संभालिए

दुर्भाग्य से, कुछ लॉग संदेश कभी-कभी _अज्ञात_ गंभीरता के साथ आते हैं। `parse_log_level` फंक्शन में इन 'रहस्यमय' लॉग संदेशों को सहजता से संभालने के लिए, `LogLevel` एनम में एक `Unknown` सदस्य जोड़िए जो अज्ञात लॉग लेवल पार्स करते समय लौटाया जाता है:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. लॉग संदेश को छोटे प्रारूप में बदलिए

लॉग लाइन का लॉग लेवल काफी लंबा होता है। लॉग संदेशों को संग्रहीत करने के लिए ज़रूरी डिस्क स्पेस कम करने के लिए, एक छोटा प्रारूप परिभाषित किया गया है: `"[<CODE_LEVEL>]:<MESSAGE>"`।

लॉग लेवल कोड की सीधी मैपिंग यह है:

| लेवल     | कोड |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

`convert_to_short_log()` फंक्शन बनाइए, जो दो पैरामीटर लेता है:

1. लॉग लेवल - भेजे गए लॉग का लॉग लेवल। उदा: `LogLevel.Error`।
2. लॉग संदेश - `str` टाइप का संदेश।

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. एक उपनाम बनाइए

ऐसा लगता है कि उपयोगकर्ता ने `LogLevel.Warning` के बजाय `LogLevel.Warn` के लिए लॉग बनाए हैं। `LogLevel.Warning` के लिए एक `alias` बनाइए और `get_warn_alias` फंक्शन में नया उपनाम सदस्य लौटाइए।

यह उसी एनम क्लास `LogLevel` पर किया जा सकता है जो फाइल के ऊपर पहले से परिभाषित है। दोनों सदस्यों का मान समान होना चाहिए: `"WRN"`।

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. सभी सदस्य नाम और वैल्यू

`get_members()` फंक्शन बनाइए।

इस फंक्शन को `(name, value)` टुपलों का एक ऐरे लौटाना चाहिए जिसमें एनम `LogLevel` के सभी सदस्य हों।

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
