# अतिरिक्त निर्देश

## कार्यान्वयन

मान्यताएँ:

1. आउटपुट में शून्य को हमेशा [] के बजाय [0] के रूप में दर्शाया जाता है।
2. किसी और स्थिति में आउटपुट में शुरुआती शून्य नहीं होते।
3. इनपुट में शुरुआती शून्य स्वीकार किए जाते हैं।
4. इनपुट अंकों के खाली क्रम को एरर नहीं, बल्कि शून्य माना जाता है।

समस्या वाले मामलों को संभालने के लिए एक एरर लौटाइए जिसका Error() मेथड इनमें से कोई एक संदेश लौटाता है:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
