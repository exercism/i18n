# परिचय

## मेथड ओवरलोडिंग

_मेथड ओवरलोडिंग_ से एक ही क्लास में एक ही नाम के कई मेथड बनाए जा सकते हैं। ओवरलोड किए गए मेथड में इनमें से किसी एक बात का फर्क होना चाहिए:

- पैरामीटर की संख्या
- पैरामीटर का टाइप

रिटर्न टाइप के आधार पर मेथड ओवरलोडिंग नहीं होती।

कंपाइलर पैरामीटर की संख्या और उनके टाइप के आधार पर खुद तय कर लेता है कि कौन-सा ओवरलोड किया गया मेथड कॉल करना है।

## नामित आर्गुमेंट

अब तक हमने देखा है कि मेथड को दिए गए आर्गुमेंट उनके क्रम के आधार पर मेथड के घोषित पैरामीटर से मिलाए जाते हैं। एक दूसरा तरीका भी है। खास तौर पर जब किसी रूटीन को बहुत सारे आर्गुमेंट देने हों, तो कॉल करने वाला घोषित पैरामीटर का नाम लिखकर आर्गुमेंट मिला सकता है।

नीचे दिया गया उदाहरण यह सिंटैक्स दिखाता है:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## वैकल्पिक पैरामीटर

किसी मेथड के पैरामीटर को डिफॉल्ट वैल्यू देकर वैकल्पिक बनाया जा सकता है। वैकल्पिक पैरामीटर वाले मेथड को कॉल करते समय कॉल करने वाले को उनके लिए कोई वैल्यू देना ज़रूरी नहीं होता। अगर किसी वैकल्पिक पैरामीटर के लिए कोई वैल्यू नहीं दी जाती, तो उसकी डिफॉल्ट वैल्यू इस्तेमाल होती है।

वैकल्पिक पैरामीटर _पैरामीटर की सूची_ में सबसे अंत में ही होने चाहिए। इनके बाद गैर-वैकल्पिक पैरामीटर नहीं हो सकते।

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
