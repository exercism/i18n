# स्टैक के रूप में वेक्टर

स्टैक एक रैखिक डेटा स्ट्रक्चर है, जिसे एक ही सिरे से चीज़ें डालने और निकालने के लिए बनाया गया है। इसे समझने का एक अच्छा तरीका है एक सीधी कील पर लगे कागज़ों का ढेर: नया कागज़ हमेशा उसी सिरे पर लगाया जाता है, और कागज़ उसी उलटे क्रम में हटाए जाते हैं जिस क्रम में लगाए गए थे। जो कागज़ पहले लगाए गए थे, वे सबसे बाद में हटते हैं, और जो सबसे बाद में लगे थे, वे सबसे पहले हटते हैं।

Rust का `Vec` डेटा स्ट्रक्चर स्टैक की तरह इस्तेमाल करने के लिए बिल्कुल ठीक है। [`push` मेथड](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) वेक्टर के अंत में एलिमेंट जोड़ता है। [`pop` मेथड](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) वेक्टर से अंतिम एलिमेंट हटाता है। `push` और `pop` दोनों को केवल एमॉर्टाइज़्ड `O(1)` समय ही लगता है।

## उदाहरण

इस उदाहरण में हम एक वेक्टर को स्टैक की तरह इस्तेमाल करके एक साधारण [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) कैलकुलेटर बनाते हैं। पूरा सोर्स कोड [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736) पर देखा जा सकता है।

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
