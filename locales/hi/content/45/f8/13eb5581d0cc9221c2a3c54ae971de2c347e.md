# टेस्ट

## सेटअप

ज़रूरी डिपेंडेंसी इंस्टॉल करने के लिए [JavaScript के लिए सेटअप निर्देश][docs-exercism-javascript] देखिए।

## आवश्यकताएँ

अभ्यास की डिपेंडेंसी इंस्टॉल कीजिए:

```shell
corepack pnpm install
```

अगर `corepack` कहता है कि यह चालू नहीं है, तो आप इसे यह चलाकर चालू कर सकते हैं:

```bash
corepack enable pnpm
```

## टेस्ट सूट पास करना

हर अभ्यास के साथ एक टेस्ट सूट आता है, जो आपको सबमिट करने से पहले अपना हल जाँचने में मदद करता है।
आप अभ्यास वाली डायरेक्टरी में कमांड प्रॉम्प्ट खोलकर ये टेस्ट चला सकते हैं:

```bash
corepack pnpm test
```

कुछ टेस्ट सूट में पहले टेस्ट के अलावा बाकी सारे टेस्ट छोड़ दिए गए होते हैं।

एक टेस्ट पास हो जाने के बाद आप `xtest` को `test` में बदलकर अगला टेस्ट चालू कर सकते हैं।

## खुद के टेस्ट लिखना

अगर आप अपने कुछ अतिरिक्त टेस्ट लिखना चाहें, तो `custom.spec.js` नाम की एक नई फाइल बनाइए और उस नई फाइल को अपने हल के साथ सबमिट कीजिए:

```shell
exercism submit numbers.js custom.spec.js
```
