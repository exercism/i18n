# परिचय

Go में फंक्शन फर्स्ट-क्लास वैल्यू होते हैं।
इसका मतलब है कि फंक्शन के साथ आप वही सब कर सकते हैं जो आप बाकी सभी वैल्यू के साथ कर सकते हैं: फंक्शन को वेरिएबल में असाइन करना, उन्हें दूसरे फंक्शन को आर्गुमेंट के रूप में देना, या दूसरे फंक्शन से फंक्शन लौटाना भी।

नीचे हम दो फंक्शन बना रहे हैं, `engGreeting` और `espGreeting`, और उन्हें `greeting` वेरिएबल में असाइन कर रहे हैं:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

फंक्शन वैल्यू हमें यह मौका देती हैं कि हम फंक्शन को सिर्फ डेटा ही नहीं, बल्कि व्यवहार भी पैरामीटर के रूप में दें।
अगले उदाहरण में हम `dialog` फंक्शन को `greetingFunc` पैरामीटर के रूप में व्यवहार दे रहे हैं:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

फंक्शन टाइप वाले किसी ऐसे वेरिएबल की वैल्यू `nil` होती है जिसे शुरू में कोई वैल्यू नहीं दी गई हो।
इसलिए किसी `nil` फंक्शन वैल्यू को कॉल करने पर पैनिक हो जाता है।

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

फंक्शन वैल्यू की तुलना `nil` से की जा सकती है।
यह प्रोग्राम में अनचाहे पैनिक से बचने के लिए काम आ सकता है।

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## फंक्शन टाइप

Go में फंक्शन वैल्यू का इस्तेमाल फंक्शन टाइप के कारण ही संभव है।
फंक्शन टाइप उन सभी फंक्शनों के समूह को दर्शाता है जिनके पैरामीटर टाइपों का क्रम और रिज़ल्ट टाइपों का क्रम एक जैसा होता है।
फंक्शन टाइप के ऊपर आप अपने बनाए हुए टाइप भी घोषित कर सकते हैं।
जैसे, पिछले उदाहरणों वाले `dialog` फंक्शन को इस तरह बदला जा सकता है:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## अनाम फंक्शन

फर्स्ट-क्लास फंक्शन के समर्थन से एक और काम की चीज़ मिलती है: अनाम फंक्शन।
अनाम फंक्शन वहीं बनाए जाते हैं जहाँ उनका इस्तेमाल होता है, और `func` कीवर्ड के बाद कोई नाम नहीं लिखा जाता।
ऐसे फंक्शन उस फंक्शन के वेरिएबलो तक पहुँच सकते हैं जिसके अंदर वे लिखे गए हैं।

उदाहरण के लिए:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib` को कॉल करने पर `n1` और `n2` वेरिएबल घोषित होते हैं और एक अनाम फंक्शन लौटता है। यह अनाम फंक्शन बदले में हर बार कॉल किए जाने पर इन वेरिएबलो की वैल्यू बदल देता है।
अनाम फंक्शन को N-वीं बार कॉल करने पर फिबोनाची श्रेणी की N-वीं संख्या मिलती है, जो 0 से शुरू होती है। अंदर वाला अनाम फंक्शन बाहरी फंक्शन `fib` के लोकल वेरिएबलो (`n1` और `n2`) तक पहुँच सकता है।
फंक्शन वैल्यू अपनी अलग-अलग कॉलों के बीच स्थिति बनाए रख सकें, इसका यह बहुत अच्छा तरीका है।
हम कहते हैं कि यह अनाम फंक्शन `n1` और `n2` वेरिएबलो का क्लोज़र है।
[क्लोज़र][closure] का इस्तेमाल प्रोग्रामिंग में बहुत होता है, और हो सकता है आप दूसरी भाषाओं में भी इन्हें सपोर्ट होते देखें।

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
