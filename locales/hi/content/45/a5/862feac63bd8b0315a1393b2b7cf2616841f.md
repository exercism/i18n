# ऐरे के बारे में

Java में ऐरे एक ही टाइप की कई वैल्यू एक ही ढाँचे में रखने का तरीका हैं।
दूसरी डेटा संरचनाओं की तुलना में ऐरे का आकार बनने के बाद तय रहता है।
एलिमेंट को इंडेक्स की मदद से ऐरे में असाइन किया जा सकता है या ऐरे से निकाला जा सकता है।
Java के ऐरे में इंडेक्स 0 से शुरू होता है: पहले एलिमेंट का इंडेक्स 0 होता है, दूसरे एलिमेंट का 1, और आगे भी इसी तरह।

ऐरे को शुरुआती वैल्यू देने का मानक सिंटैक्स यह है:

```java
type[] variableName = new type[size];
```

यहाँ `type` ऐरे के एलिमेंट का टाइप है, जो कोई प्रिमिटिव टाइप (जैसे `int`) या कोई क्लास (जैसे `String`) हो सकता है।

`size` उन एलिमेंट की संख्या है जो यह ऐरे रखेगा (जिसे बाद में बदला नहीं जा सकता)।
ऐरे बनने के बाद एलिमेंट को उनकी डिफॉल्ट वैल्यू मिल जाती हैं (आम तौर पर `0`, `false` या `null`)।

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

ऐरे को छोटे रूप में भी लिखा जा सकता है, जिससे आप एक ही बार में ऐरे बना भी सकते हैं और उसकी वैल्यू भी तय कर सकते हैं:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

अब कंपाइलर खुद बता सकता है कि ऐरे में कितने एलिमेंट होंगे, इसलिए लंबाई लिखने की ज़रूरत नहीं पड़ती।

ऐरे के एलिमेंट को चौकोर ब्रैकेट में इंडेक्स लिखकर असाइन भी किया जा सकता है और पढ़ा भी जा सकता है:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

ऐरे के मान्य इंडेक्स से बाहर का कोई इंडेक्स एक्सेस करने पर `IndexOutOfBoundsException` आता है।

ऐरे के साथ काम करने के लिए आप या तो उस इंस्टेंस के मेथड या प्रॉपर्टी कॉल कर सकते हैं, या `Arrays` क्लास में बने स्टैटिक मेथड इस्तेमाल कर सकते हैं (आम तौर पर इनका उपयोग सिर्फ जेनेरिक कोड में होता है)।
`length` प्रॉपर्टी में ऐरे की लंबाई रहती है।
इसे इस तरह पढ़ा जा सकता है:

```java
int arrayLength = someArray.length;
```

Java में एक काम की यूटिलिटी क्लास [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) भी है, जिसमें ऐरे से जुड़े बहुत से उपयोगी मेथड हैं (जैसे `Arrays.equals`)।

Java [मल्टी-डाइमेंशनल ऐरे](https://www.programiz.com/java-programming/multidimensional-array) को भी सपोर्ट करता है, जैसे `int[][] arr = new int[3][4];`। ये बहुत काम के हो सकते हैं।

ऐरे एक _कलेक्शन_ भी है, इसलिए इंडेक्स से वैल्यू पढ़ने के अलावा आप `for-each` लूप की मदद से इसकी _सभी_ वैल्यू पर एक-एक करके चल सकते हैं:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

अगर आपको यह तय करना है कि किन वैल्यू पर चलना है, तो `for` लूप इस्तेमाल किया जा सकता है:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
