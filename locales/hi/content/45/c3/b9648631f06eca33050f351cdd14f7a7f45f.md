# निर्देश

दो ऐरे दिए गए हैं। तय कीजिए कि पहला ऐरे दूसरे ऐरे के अंदर है या नहीं, दूसरा ऐरे पहले ऐरे के अंदर है या नहीं, दोनों ऐरे एक-दूसरे के अंदर हैं, या इनमें से कोई भी बात सही नहीं है।

अधिक स्पष्ट रूप से कहें तो, ऐरे A, ऐरे B का sublist तब कहलाता है जब आप B के आगे से 0 या उससे अधिक एलिमेंट हटा दें और B के पीछे से भी 0 या उससे अधिक एलिमेंट हटा दें, और जो ऐरे बचे वह पूरी तरह A जैसा ही हो।

उदाहरण:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A, B का sublist है
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A, B का sublist है
 * A = [3, 4], B = [1, 2, 3, 4, 5], A, B का sublist है
 * A = [1, 2, 3], B = [1, 2, 3], A और B equal हैं
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A, B का superlist है
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A, B का superlist, sublist या equal नहीं है
