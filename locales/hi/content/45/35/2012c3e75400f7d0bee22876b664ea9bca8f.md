# टाइप घोषणा

PHP एक डायनैमिक टाइप वाली भाषा है, यानी एक वेरिएबल में किसी भी तरह की जानकारी रखी जा सकती है।
PHP में क्लास की प्रॉपर्टी, फंक्शन के आर्गुमेंट और फंक्शन की रिटर्न वैल्यू के लिए _वैकल्पिक_ सख्त टाइप घोषणा की सुविधा भी है।
PHP में सख्त टाइप घोषणाएँ रन टाइम पर टाइप की पुष्टि करती हैं, लेकिन अगर संभव हो तो PHP स्केलर टाइप को घोषणा के अनुसार ढालने की कोशिश करता है।
फाइल के शुरू में `strict_types` घोषणा देकर इस ढालने के व्यवहार को बंद किया जा सकता है।

```php
<?php
declare(strict_types=1);
```

इसके अलावा फंक्शन यह बताने के लिए कि उससे कोई वैल्यू नहीं लौटाई जाएगी, रिटर्न टाइप के तौर पर `void` दे सकते हैं।

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## टाइप यूनियन

अगर किसी फंक्शन के आर्गुमेंट, रिटर्न वैल्यू या क्लास की प्रॉपर्टी में एक से अधिक टाइप हो सकते हैं, तो टाइप यूनियन घोषित किया जा सकता है।

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## मिक्स्ड टाइप

कोड लिखते समय कभी-कभी हमें टाइप तय करने का मौका नहीं मिलता।
PHP 8.0 से `mixed` नाम का एक टाइप मिलता है, जो बच निकलने का रास्ता देता है।
`mixed` इन सबके टाइप यूनियन के बराबर है: `object|resource|array|string|float|int|bool|null`.
