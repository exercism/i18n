# परिचय

## पैकेज

Go में एक एप्लिकेशन पैकेजों में बँटा होता है।
पैकेज एक ही फोल्डर में रखी सोर्स फाइलों का समूह होता है।
किसी फोल्डर की सभी सोर्स फाइलों में सबसे ऊपर एक ही पैकेज का नाम लिखा होना चाहिए।
परंपरा से पैकेजों का नाम उसी फोल्डर जैसा रखा जाता है जिसमें वे रखे होते हैं।

```go
package greeting
```

Go पैकेजों की एक बहुत बड़ी स्टैंडर्ड लाइब्रेरी देता है। इन पैकेजों को आप अपने प्रोग्राम में `import` कीवर्ड से इस्तेमाल कर सकते हैं।
स्टैंडर्ड लाइब्रेरी के पैकेजों को उनके नाम से ही इम्पोर्ट किया जाता है।

```go
package greeting

import "fmt"
```

इसके बाद इम्पोर्ट किए गए पैकेज को पैकेज के नाम से ही इस्तेमाल किया जाता है:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

कोई चीज़ दूसरे पैकेजों के कोड से कॉल की जा सकती है या नहीं, यह Go उसके घोषित करने के तरीके से तय करता है।
किसी फंक्शन, टाइप, वेरिएबल, कॉन्स्टेंट या स्ट्रक्ट फील्ड को बाहर से दिखाई देने वाला (जिसे _exported_ कहते हैं) बनाने के लिए ज़रूरी है कि नाम की शुरुआत बड़े अक्षर से हो।

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## स्ट्रिंग फॉर्मैटिंग

Go में एक बिल्ट-इन पैकेज है जिसका नाम `fmt` (फॉर्मैट पैकेज) है। यह इनपुट और आउटपुट का फॉर्मैट बदलने के लिए कई तरह के फंक्शन देता है।
सबसे ज़्यादा इस्तेमाल होने वाला फंक्शन `Sprintf` है, जो `%s` जैसे वर्ब की मदद से वैल्यू को स्ट्रिंग में जोड़ता है और वह स्ट्रिंग लौटाता है।

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Go में दशमलव संख्याओं को Sprintf के वर्ब से आसानी से फॉर्मैट किया जा सकता है: `%g` (संक्षिप्त रूप), `%e` (घातांक) या `%f` (घातांक रहित)।
इन तीनों वर्ब के ज़रिए फील्ड की चौड़ाई और संख्या की स्थिति नियंत्रित की जा सकती है।

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

उपलब्ध सभी वर्ब की पूरी सूची आप [फॉर्मैट पैकेज के डॉक्यूमेंटेशन][fmt-docs] में देख सकते हैं।

`fmt` में स्ट्रिंग पर काम करने वाले और भी फंक्शन हैं, जैसे `Println`, जो अपने आर्गुमेंट को सिर्फ कंसोल पर प्रिंट करता है, और `Printf`, जो इनपुट को `Sprintf` की तरह फॉर्मैट करने के बाद प्रिंट करता है।

[fmt-docs]: https://pkg.go.dev/fmt
