# परिचय

दशमलव संख्याएँ ऐसी संख्याएँ होती हैं जिनमें दशमलव विभाजक के बाद एक या अधिक अंक होते हैं। ये 64-बिट डबल प्रिसिजन फ्लोटिंग-पॉइंट फॉर्मेट का उपयोग करती हैं।

```elixir
float = 3.45
# => 3.45
```

## संख्याओं के साथ काम करना

[`Integer`][integer-functions] और [`Float`][float-functions] मॉड्यूल में आपको इन टाइपों के साथ काम करने के लिए कुछ उपयोगी फंक्शन मिलेंगे। बुनियादी अंकगणितीय ऑपरेटर [`Kernel`][kernel-arithmetic-operators] मॉड्यूल में परिभाषित हैं।

## रूपांतरण

पूर्णांक और दशमलव संख्याएँ एक ही अंकगणितीय एक्सप्रेशन में मिलाई जा सकती हैं। किसी एक्सप्रेशन में दशमलव संख्या इस्तेमाल करने पर यह पक्का रहता है कि परिणाम भी दशमलव संख्या ही होगा।

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

लेकिन भाग देने पर परिणाम हमेशा दशमलव संख्या ही होगा, भले ही केवल पूर्णांक इस्तेमाल किए गए हों।

```elixir
6 / 2
# => 3.0
```

किसी दशमलव संख्या को पूर्णांक में बदलने के लिए, आप [`trunc/1`][trunc-1] की मदद से उसका दशमलव भाग हटा सकते हैं।
