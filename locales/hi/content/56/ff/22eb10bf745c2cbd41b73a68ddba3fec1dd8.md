# अधिक जानकारी

ऐरे Factor का निश्चित लंबाई वाला सीक्वेंस टाइप है: आप इसके एलिमेंट बदल सकते हैं, लेकिन लंबाई नहीं। लिटरल में `{ … }` लिखा जाता है और एलिमेंट के बीच स्पेस छोड़ा जाता है; `arrays` वोकैबुलरी कुछ छोटे कंस्ट्रक्टर जोड़ती है जो स्टैक से वैल्यू निकाल लेते हैं:

| शब्द     | प्रभाव                              |
|----------|-------------------------------------|
| `1array` | `( a     -- { a } )`                |
| `2array` | `( a b   -- { a b } )`              |
| `3array` | `( a b c -- { a b c } )`            |
| `<array>`| `( n elt -- array )`, यानी `elt` की `n` प्रतियाँ |
| `array?` | `( obj   -- ? )`, यानी टाइप प्रेडिकेट   |

`sequences` के कुछ [प्रोटोकॉल][sequence-protocol] शब्द ऐरे के साथ इतनी बार आते हैं कि उन्हें एक इकाई के रूप में जानना काम का है:

| शब्द      | प्रभाव                                                |
|-----------|-------------------------------------------------------|
| `concat`  | `( seqs -- seq )` — सीक्वेंस के सीक्वेंस को समतल करना   |
| `join`    | `( seqs glue -- seq )` — किसी सेपरेटर के साथ समतल करना |
| `reverse` | `( seq -- newseq )`                                   |
| `index`   | `( elt seq -- i/f )` — एलिमेंट का इंडेक्स, या `f`       |
| `member?` | `( elt seq -- ? )` — सदस्यता की जाँच                  |

```factor
USING: arrays sequences ;

3 4 2array .                       ! => { 3 4 }
{ { 1 2 } { 3 4 } } concat .       ! => { 1 2 3 4 }
{ 1 2 3 4 } reverse .              ! => { 4 3 2 1 }
"b" { "a" "b" "c" } index .        ! => 1
"b" { "a" "b" "c" } member? .      ! => t
```

`sets` से `all-unique?` और `members` भी किसी भी सीक्वेंस को स्वीकार करते हैं। यह तब काम आता है जब ऐरे के एलिमेंट्स में से डुप्लिकेट हटाने हों या डुप्लिकेट की जाँच करनी हो, और पहले उसे हैश-सेट में बदलने की ज़रूरत न पड़े।
