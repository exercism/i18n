# निर्देश परिशिष्ट

## `Print` स्ट्रिंग वैल्यू पर कोटेशन नहीं लगाता

इस अभ्यास में संख्यात्मक स्कोर के साथ काम करना है।
#[a: 1]` and `#[a: "1"]` एक जैसे नहीं होते:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

डीबग करते समय वैल्यू को `print` करना एक आम तरीका है।
लेकिन आउटपुट स्ट्रिंग के चारों ओर कोटेशन के निशान नहीं जोड़ता।
इसलिए `"1"` जैसी संख्यात्मक स्ट्रिंग प्रिंट होने पर पूर्णांक `1` जैसी ही दिखती है।

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
इस अभ्यास के टेस्ट आउटपुट में आपको `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]` जैसा परिणाम दिख सकता है।
प्रिंट होने पर तुलना की जा रही दोनों डिक्शनरियाँ एक जैसी दिखती हैं।
लेकिन पहली डिक्शनरी में संख्यात्मक स्ट्रिंग वैल्यू हैं और दूसरी में पूर्णांक वैल्यू, इसलिए वे एक जैसी नहीं हैं।
डीबग करते समय आप अपनी डिक्शनरी की सामग्री जाँचने के लिए `inspect` का उपयोग कर सकते हैं।

## `Express` स्ट्रिंग वैल्यू पर कोटेशन ज़रूर लगाता है

`express` किसी वैल्यू को Arturo कोड में बदलता है और उस कोड का रूप दर्शाने वाली स्ट्रिंग लौटाता है।
उस परिणाम में सभी स्ट्रिंग वैल्यू पर कोटेशन लगे होते हैं।
इसलिए `express "1"` `1` नहीं, बल्कि `"1"` लौटाता है।

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
