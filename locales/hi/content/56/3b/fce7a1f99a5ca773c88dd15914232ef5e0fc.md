# परिचय

[ऐरे][list] Haskell में वैल्यू के संग्रह को रखने के लिए एक बुनियादी डेटा टाइप हैं।
ऐरे _अपरिवर्तनीय_ होते हैं, यानी उन्हें बदला नहीं जा सकता।
कोई भी ऑपरेशन जो किसी ऐरे को बदलता है, एक नया ऐरे लौटाता है।
Prelude में कई मेथड हैं जो आपको ऐरे के साथ काम करने देते हैं।

Haskell में ऐरे [लिंक्ड लिस्ट][linked-list-wiki] के रूप में बनाए जाते हैं, न कि लगातार मेमोरी लोकेशन वाले ऐरे के रूप में।
इसलिए ऐरे के किसी एलिमेंट तक पहुँचने में ऐरे की लंबाई के हिसाब से रैखिक समय लगता है।

ऐरे को लिटरल रूप में, हेड-टेल नोटेशन में (जिसमें `cons` ऑपरेटर `:` इस्तेमाल होता है), या इन दोनों के मेल में लिखा जा सकता है:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

हेड-टेल नोटेशन का इस्तेमाल ऐरे के अंत में आइटम जोड़ने के लिए किया जा सकता है।

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

इटरेशन के दौरान ऐरे में एलिमेंट जोड़ना एक एंटी-पैटर्न माना जाता है।
एक एलिमेंट जोड़ने के लिए पूरे ऐरे से गुज़रना पड़ता है और उसे अंत में जोड़ना पड़ता है। इसलिए हर इटरेशन में नया एलिमेंट जोड़ने पर हर बार पूरे ऐरे से गुज़रना पड़ेगा।

हम यही नतीजा उलटे हुए ऐरे के आगे एलिमेंट जोड़कर और फिर नतीजे को उलटकर पा सकते हैं। आगे जोड़ना एक तेज़ ऑपरेशन है और इसमें स्थिर समय लगता है।

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

ऐरे के लिए Prelude में कई आम फंक्शन हैं:

- [`head`][head] ऐरे का _हेड_ लौटाता है, यानी ऐरे का _पहला_ आइटम।
- [`tail`][tail] ऐरे का _टेल_ लौटाता है, यानी ऐरे से _पहला_ आइटम हटाकर जो बचता है।
- [`length`][length] ऐरे में आइटम की संख्या लौटाता है।
- [`elem`][elem] एक बूलियन वैल्यू लौटाता है जो बताती है कि कोई आइटम ऐरे में है या नहीं।

ऐरे के लिए [`Data.List` मॉड्यूल][list] भी है।

## ऐरे के प्रकार

Haskell में ऐरे **समरूप** होते हैं।
इसका मतलब है कि एक ऐरे के सारे एलिमेंट एक ही टाइप के होते हैं।
जब आप अलग-अलग टाइप के एलिमेंट एक ही ऐरे में डालने की कोशिश करते हैं, तो आपको एक टाइप एरर मिलती है।

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

ऐरे का टाइप एनोटेशन `[a]` होता है, जहाँ a वह टाइप है जो ऐरे रखता है, जैसे `String` या `Int`।

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
