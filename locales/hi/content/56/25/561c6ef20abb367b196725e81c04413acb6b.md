# इंस्टॉलेशन

अपने प्लेटफॉर्म के लिए सुझाए गए इंस्टॉलेशन निर्देश पाने के लिए [Rust की आधिकारिक वेबसाइट][the official Rust website] पर जाइए।

टूलचेन इंस्टॉल कर लेना ही सब कुछ नहीं है! IDE का सपोर्ट उत्पादकता में बड़ी बढ़ोतरी करता है, और ज़्यादातर डेवलपर अब इसकी अपेक्षा करते हैं। अगर आप Visual Studio Code इस्तेमाल करते हैं, तो [Rust सपोर्ट के लिए इसका डॉक्युमेंटेशन][vscode] देखिए। हम पूरे दिल से यह भी सलाह देंगे कि आप [clippy के साथ लिंटिंग][vscode-linting] चालू कीजिए!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
