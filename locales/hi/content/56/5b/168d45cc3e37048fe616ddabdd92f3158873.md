# परिचय

Go में स्टैटिक टाइपिंग होती है, इसलिए हर वेरिएबल का टाइप कोड कंपाइल होते समय ही ज्ञात होता है।
एक बार घोषित होने के बाद वेरिएबल का टाइप बदला नहीं जा सकता।

## वेरिएबल बनाना

`var` स्टेटमेंट किसी नए वेरिएबल का टाइप घोषित कर सकता है, उसकी वैल्यू सेट कर सकता है, या दोनों काम एक साथ कर सकता है:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

किसी फंक्शन के अंदर `:=` शॉर्ट असाइनमेंट स्टेटमेंट का भी इस्तेमाल किया जा सकता है।

```go
count := 1 // Type implictly declared, value explicitly set
```

Go में हर वेरिएबल की एक वैल्यू होती है।
अगर घोषित करते समय कोई वैल्यू सेट नहीं की जाती, तो Go वेरिएबल के टाइप के आधार पर एक वैल्यू [देता है, जिसे ज़ीरो वैल्यू कहते हैं][zero-values]।

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## वेरिएबल को बदलना

किसी फंक्शन के अंदर `=` असाइनमेंट ऑपरेटर किसी मौजूदा वेरिएबल के लिए नई वैल्यू सेट कर सकता है:

```go
count := 1
count = 2
```

नई वैल्यू का टाइप वेरिएबल के टाइप जैसा ही होना चाहिए:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
