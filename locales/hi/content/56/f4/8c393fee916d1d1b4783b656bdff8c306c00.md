# निर्देश

इस अभ्यास में आप फैक्ट्री के कर्मचारियों के लिए नाम बैज छापने का कोड लिखेंगे। हर कर्मचारी के पास एक ID, नाम और विभाग का नाम होता है। कर्मचारी के बैज लेबल का प्रारूप इस तरह होता है: `"[id] - name - DEPARTMENT"`.

## 1. कर्मचारी के लिए बैज छापिए

`NameBadge.print/3` फंक्शन बनाइए। यह एक ID, नाम और विभाग लेता है। यह बैज लेबल लौटाता है, जिसमें विभाग का नाम बड़े अक्षरों में होता है।

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. नए कर्मचारी के लिए बैज छापिए

कंप्यूटर सिस्टम की एक खास बात के कारण, नए कर्मचारियों के पास फैक्ट्री में काम शुरू करते समय कभी-कभी अभी ID नहीं होती। चूँकि बैज ज़रूरी होते हैं, उन्हें ID प्रीफिक्स के बिना एक अस्थायी बैज मिल जाता है।

`NameBadge.print/3` फंक्शन को आगे बढ़ाइए। जब ID मौजूद न हो, तो यह उसके बिना बैज छापता है।

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. मालिक के लिए बैज छापिए

फैक्ट्री के मालिक को भी हर समय बैज पहनना पड़ता है। लेकिन मालिक का कोई विभाग नहीं होता। ऐसे में लेबल विभाग के नाम की जगह `"OWNER"` छापता है।

`NameBadge.print/3` फंक्शन को आगे बढ़ाइए। जब विभाग मौजूद न हो, तो मान लीजिए कि यह बैज कंपनी के मालिक का है।

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

ध्यान दीजिए कि हो सकता है कि मालिक खुद भी एक नया कर्मचारी हो।

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
