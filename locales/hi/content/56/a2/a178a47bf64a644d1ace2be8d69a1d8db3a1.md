# पूरी जानकारी

Haxe में एक्सेप्शन, कोड चलाते समय होने वाली एरर को संभालने का एक सुरक्षित तरीका हैं। हर एक्सेप्शन में एरर का वर्णन करने वाला एक संदेश होना चाहिए। हम `throw` कीवर्ड की मदद से एक्सेप्शन _फेंक_ सकते हैं:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

जब कोई एक्सेप्शन फेंका जाता है, तो कोड ऐसे हिस्से को ढूँढता है जिसे एरर संभालने के लिए तय किया गया हो। अगर ऐसा हिस्सा नहीं मिलता, तो कोड एरर संदेश प्रदर्शित करता है और साथ ही प्रोग्राम का चलना भी रोक देता है।

Haxe में एक्सेप्शन संभालने के लिए हम `try-catch` ब्लॉक का उपयोग करते हैं। इस ब्लॉक स्टेटमेंट में एक `try` ब्लॉक और एक या अधिक `catch` ब्लॉक होते हैं। `try` ब्लॉक कोड का एक हिस्सा चलाने की _कोशिश_ करता है, जबकि `catch` ब्लॉक तैयार बैठा रहता है, ताकि कोई एक्सेप्शन फेंका जाए तो वह उसे _पकड़_ ले और प्रोग्राम का चलना रुके नहीं। जब `catch` ब्लॉक कोई एक्सेप्शन पकड़ता है, तो वह अपने अंदर लिखा सारा कोड भी चलाता है:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch` ब्लॉक के आर्गुमेंट का टाइप छोड़ देना चाहिए।

यह ध्यान रखना ज़रूरी है कि एक्सेप्शन का उपयोग तभी होना चाहिए जब कुछ असामान्य हो, ऐसी एरर जिसे खास तरीके से संभालने की ज़रूरत पड़े। इसका उपयोग प्रोग्राम के कंट्रोल-फ्लो के लिए नहीं करना चाहिए, क्योंकि इसे खराब डिज़ाइन माना जाता है, जिससे अक्सर परफॉर्मेंस खराब होती है और कोड का रखरखाव मुश्किल हो जाता है।
