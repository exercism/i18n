# निर्देश

इस अभ्यास में आप [गो के खेल के नियमों](https://matmoore.github.io/learngo/) को लागू करेंगे। नियम तो पहले से लिखे हुए हैं। आपको बस उन्हें लागू करना है, ताकि Game को अपडेट किया जा सके और नियमों के किसी भी उल्लंघन या एरर को संभाला जा सके।

खेल को इस तरह दर्शाया गया है:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

खेल में 4 नियम हैं:

- हर पॉइंट पर सिर्फ एक ही स्टोन रखा जा सकता है।
- विरोधी के स्टोन पकड़े जा सकते हैं।
- आप किसी स्टोन को ऐसी जगह नहीं रख सकते जहाँ वह खुद को ही पकड़ ले।
- आप एक ही पॉइंट का दो बार उपयोग नहीं कर सकते।

## 1. नियम लागू कीजिए

`apply_rules` फंक्शन का कोड लिखिए। यह एक शुरुआती `Game` और नियमों का एक सेट लेता है, और नियम लागू हो जाने के बाद नया `Game` लौटाता है।

इनमें से तीन नियम नियमों के उल्लंघन की जाँच करते हैं और एरर लौटा सकते हैं, इसलिए उनका रिटर्न टाइप `Result(Game, String)` है। अगर इनमें से कोई भी नियम फेल हो जाए, तो मूल खेल ही लौटाया जाना चाहिए, लेकिन उसके `error` फील्ड में संबंधित एरर डाल दी जानी चाहिए।

बाकी एक नियम उल्लंघन की जाँच नहीं करता, इसलिए वह फेल नहीं हो सकता (हालाँकि वह बदला हुआ `Game` लौटा सकता है)। इस कारण उसका रिटर्न टाइप `Game` है।

अगर सारे नियम पास हो जाएँ, तो नियमों से `Game` में जो भी बदलाव हुए हों उन्हें रखा जाना चाहिए, और खिलाड़ी बदल दिया जाना चाहिए।

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
