# परिचय

बूलियन एक्सप्रेशन एक ऐसा सवाल है, जो एक या अधिक वैल्यू पर पूछा जाता है और जिसका जवाब `true` या `false` में दिया जा सकता है।
सही एक्सप्रेशन `1` लौटाता है; गलत एक्सप्रेशन `0` लौटाता है।
साथ ही, संख्याओं की भी सही/गलत वैल्यू होती है। शून्य `false` होता है; शून्य के अलावा कोई भी संख्या `true` होती है।

पुराने C कोड में या तो बूलियन वैल्यू के लिए सीधे `int` टाइप इस्तेमाल किया जाता है, या फिर प्रोग्रामर ने `TRUE` और `FALSE` जैसे कॉन्स्टेंट बनाए होते हैं, जो `1` और `0` को बूलियन रूप में बदल देते हैं।

C99 वर्ज़न में `_Bool` टाइप जोड़ा गया।
`stdbool.h` हेडर फाइल तीन नए बूलियन सिंबल परिभाषित करती है: `bool`; `true` और `false`।
`true` का अर्थ `1` है; `false` का अर्थ `0` है; और `bool` का अर्थ `_Bool` है।
तो अब प्रोग्रामर सीधे `int` इस्तेमाल करने या अपनी खुद की बूलियन मैपिंग बनाने के बजाय `stdbool.h` शामिल कर सकते हैं और अपने कोड में बूलियन सिंबल अपने आप पा सकते हैं।

## तुलना ऑपरेटर

C में छह तुलना ऑपरेटर हैं: `==` (बराबर), `!=` (बराबर नहीं), `>` (से बड़ा), `<` (से छोटा), `>=` (से बड़ा या बराबर), `<=` (से छोटा या बराबर)।
ये ऑपरेटर वैल्यू के बीच के संबंधों की तुलना करते हैं और उन्हें बूलियन वैल्यू में बदल देते हैं।

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## बूलियन ऑपरेटर

C में तीन बूलियन ऑपरेटर हैं: `||` (या), `&&` (और), और `!` (नहीं)।

`!` एक ही ऑपरेंड के साथ इस्तेमाल होता है।
यह ऑपरेंड की बूलियन वैल्यू उलट देता है।
जैसे, `0` `false` है, लेकिन `!0` `true` है।

`||` और `&&` दो ऑपरेंड के साथ इस्तेमाल होते हैं।
दाईं ओर वाले ऑपरेंड का मूल्यांकन तभी होता है जब बाईं ओर वाला ऑपरेंड एक्सप्रेशन का परिणाम पहले ही तय न कर चुका हो।
यानी, `||` दाईं ओर वाले ऑपरेंड का मूल्यांकन तभी करता है जब बाईं ओर वाले ऑपरेंड की वैल्यू `false` हो।
`&&` दाईं ओर वाले ऑपरेंड का मूल्यांकन तभी करता है जब बाईं ओर वाले ऑपरेंड की वैल्यू `true` हो।
