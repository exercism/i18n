# परिचय

## बूलियन

Elixir सही और गलत वैल्यू को बूलियन टाइप से दर्शाता है। ऐसी वैल्यू केवल दो होती हैं: `true` और `false`. इन वैल्यू को एक वेरिएबल में बाँधा जा सकता है:

```elixir
true_variable = true
false_variable = false
```

हम `and/2`, `or/2` और `not/1` ऑपरेटरों की मदद से सख्त बूलियन एक्सप्रेशन का मूल्यांकन कर सकते हैं।

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

जब कोई फंक्शन बूलियन वैल्यू लौटाता है, तो उस फंक्शन के नाम के अंत में `?` लगाना आम बात है। यही तरीका उन वेरिएबलो के लिए भी अपनाया जा सकता है जिनमें बूलियन वैल्यू रखी जाती हैं।

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
