# परिचय

Go के फंक्शन और मेथड एक से अधिक वैल्यू लौटा सकते हैं:

```go
func GetCard() (Card, error) { ... }
```

हर रिटर्न वैल्यू को क्रम से असाइन करना ज़रूरी है और उनके बीच कॉमा लगाना होता है:

```go
card, err := GetCard()
```

असाइनमेंट में हर जगह एक वेरिएबल घोषित होता है।
अगर घोषित किया गया कोई भी वेरिएबल कहीं इस्तेमाल नहीं होता, तो Go कंपाइल नहीं होगा।
ब्लैंक आइडेंटिफायर `_` उस रिटर्न वैल्यू को छोड़ने के लिए वेरिएबल के नाम की जगह लेता है:

```go
card, _ := GetCard()
```

`error` एक बिल्ट-इन इंटरफेस है।
`nil` एरर का मतलब है कि कोई एरर नहीं हुई; कोई भी non-nil वैल्यू बताती है कि कुछ गड़बड़ हुई।
परंपरा के अनुसार, जो फंक्शन विफल हो सकते हैं, उन्हें अपनी अंतिम वैल्यू के रूप में एक `error` लौटाना चाहिए।
कॉल करने वाले को बाकी कोई भी रिटर्न वैल्यू इस्तेमाल करने से पहले उसकी जाँच करनी चाहिए:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
