# परिचय

## ऐरे और वेक्टर

C++ एक ही टाइप के एलिमेंट को क्रमबद्ध तरीके से रखने के लिए अलग-अलग कंटेनर देता है।
एक तय आकार वाले कंटेनर के लिए `std::array` है, और डायनैमिक रीसाइज़िंग की सुविधा वाला `std::vector` है।

### बनाना

जब आप कोई ऐरे या वेक्टर घोषित करते हैं, तो आपको उन एलिमेंट का टाइप बताना होता है जिन्हें वह कंटेनर रखेगा।
ऐरे के लिए आकार भी बताना होता है।
इन दोनों कंटेनर टाइप के इनिशियलाइज़ेशन देखने के लिए इन उदाहरणों पर नज़र डालिए:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

वेक्टर को आम तौर पर अधिक जगह चाहिए होती है, क्योंकि वे आगे बढ़ने के लिए मेमोरी आवंटित करते हैं।
आपको आकार बताने की ज़रूरत नहीं है:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> ध्यान दें: टेम्पलेट की अवधारणा के पीछे का सटीक तरीका आपको अभी जानने की ज़रूरत नहीं है, सिलेबस में आगे इसका अपना कॉन्सेप्ट आएगा।

### एलिमेंट एक्सेस

वेक्टर और ऐरे अपने एलिमेंट एक्सेस करने के लिए एक जैसे फंक्शन इस्तेमाल करते हैं।
कंटेनर के पहले और अंतिम एलिमेंट पाने के लिए आप मेम्बर फंक्शन `front` और `back` इस्तेमाल कर सकते हैं।
किसी खास एलिमेंट तक पहुँचने के लिए `at` और `[]` ऑपरेटर भी हैं।

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> ध्यान दें: अगर आप ऐसी स्थिति चुनते हैं जो आपके कंटेनर की रेंज में नहीं है, तो `[]` अपरिभाषित व्यवहार तक ले जा सकता है।
> `at` फंक्शन एक एक्सेप्शन उठाएगा, जो लंबे समय में आपका काम आसान बना सकता है।

### वेक्टर मॉडिफायर

चूँकि `vector` का आकार तय नहीं होता, इसलिए इसमें एलिमेंट जोड़े या हटाए जा सकते हैं।
इस काम के लिए दो आम फंक्शन हैं, `emplace_back` और `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### क्षमता

आप मेम्बर फंक्शन `empty` की मदद से देख सकते हैं कि कंटेनर खाली है या नहीं।
अगर आप एलिमेंट की संख्या जानना चाहते हैं, तो `size` इस्तेमाल कर सकते हैं।
