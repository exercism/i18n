# टेस्ट चलाना

SWI Prolog को आप इंटरैक्टिव तरीके से चला सकते हैं, या सीधे कमांड लाइन पर चला सकते हैं।

## कमांड लाइन

कमांड लाइन से टेस्ट चलाने के लिए यह कमांड इस्तेमाल की जा सकती है:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>` की जगह उस अभ्यास का नाम लिखिए जिसे आप इम्प्लीमेंट कर रहे हैं।

## इंटरैक्टिव

Prolog को इंटरैक्टिव तरीके से चलाने के लिए पहले यह चलाइए:

```bash
swipl
```

Prolog कंसोल शुरू होने के बाद, अपना इम्प्लीमेंटेशन लोड कीजिए और इनसे टेस्ट चलाइए:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>` की जगह उस अभ्यास का नाम लिखिए जिसे आप इम्प्लीमेंट कर रहे हैं।

### बदलाव दोबारा लोड करना

ऊपर दी गई फाइलें लोड हो जाने के बाद, आप जो भी बदलाव करें उन्हें यह चलाकर लागू कर सकते हैं:

```
?- make.
```

## छोड़े गए टेस्ट

जब आप कोई अभ्यास पहली बार शुरू करते हैं, तब सिर्फ पहला टेस्ट चलता है। बाकी सारे टेस्ट `test` गोल में `condition(pending)` जोड़कर छोड़ दिए गए हैं।
पहला टेस्ट पास हो जाने पर, `condition(pending)` में `pending` को `true` में बदलकर अगला टेस्ट चालू कीजिए।
हर टेस्ट के लिए यही कीजिए, जब तक सारे टेस्ट चलने और पास होने न लगें।

### कमांड लाइन

कमांड के अंत में `-- --all` आर्गुमेंट जोड़िए, ताकि बाकी बचे टेस्ट भी चल जाएँ:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
