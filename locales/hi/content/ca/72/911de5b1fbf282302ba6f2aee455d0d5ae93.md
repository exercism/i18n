# परिचय

## एन्यूमरेशन

अब तक हमने ज़्यादातर संख्याओं और स्ट्रिंग के साथ काम किया है।
वास्तविक दुनिया का मॉडल बनाने के लिए हमें कभी-कभी एक सीमित संख्या में ऐसी वैल्यू चाहिए होती हैं जो कोई वेरिएबल ले सकता है।
आप एक ऐसा अलग टाइप चाह सकते हैं जिसमें कुछ अलग-अलग नामों वाली कुछ अलग वैल्यू हों।
उदाहरण के लिए, स्केटबोर्ड बनाने की फैक्ट्री में डेक का मटेरियल सिर्फ maple, bamboo या plastic में से कोई एक हो सकता है।

आप इन वैल्यू को पूर्णांक में एन्कोड कर सकते हैं, लेकिन तब आपको अतिरिक्त कोड लिखकर यह जाँचना पड़ेगा कि मटेरियल के लिए सिस्टम से कोई अमान्य वैल्यू तो नहीं आ रही है।
उन [_जादुई संख्याओं_][magic numbers] का अर्थ सोर्स कोड में ढूँढ़ना मुश्किल होता है, और उनमें गलतियाँ होने की आशंका बनी रहती है।
`enumerations` की मदद से ऐसा कोड लिखा जा सकता है जिसका मतलब साफ़ हो, और अनजाने में की गई तुलना की गलतियों को रोका जा सकता है।

## उदाहरण

इस तरह के एन्यूमरेशन का खास नाम `scoped enumeration` है।
नीचे दिया गया कोड दिखाता है कि `DeckMaterial` `enumeration` कैसे लिखा जाता है।
परिभाषा में `enum class` कीवर्ड और अंत में लगे `;` पर ध्यान दीजिए:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
अब स्केट की दुकान में दाम तय करने वाले फंक्शन को देखिए, और उस स्कोप रिज़ॉल्यूशन ऑपरेटर (`::`) पर ध्यान दीजिए जो बताता है कि `enumerator` किस `enumeration` का है:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## स्कोप

सोचिए, आपके पास पहियों के मटेरियल के लिए एक और `enumeration` है:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
पहिए और डेक, दोनों _plastic_ के बने हो सकते हैं, फिर भी इन दोनों में उलझन नहीं हो सकती।
ये दो अलग _टाइप_ हैं: `DeckMaterial` वाला plastic और `WheelMaterial` वाला plastic।
हर `enumeration` के अपने `enumerators` अपने ही स्कोप में रहते हैं, यानी अपने ही `namespace` में।
इसी वजह से इन्हें `scoped enumerations` कहा जाता है।

## अनस्कोप्ड एन्यूमरेशन
आप सोच रहे होंगे कि जब नाम `scoped` है, तो _`unscoped`_ एन्यूमरेशन भी होंगे, और यह सही है।
`Unscoped enumerations` की लोकप्रियता घटती जा रही है, क्योंकि ये सब एक ही ग्लोबल नेमस्पेस साझा करते हैं।
इसी साझेदारी की वजह से ऊपर के उदाहरण में दिए _plastic_ जैसे एक ही `enumerators` वाले दो `unscoped enumerations` नहीं बना सकते।

इसके अलावा, `unscoped enumerations` अपने आप पूर्णांक में बदल जाते हैं।
नीचे दिए उदाहरण में एक चौंकाने वाला नतीजा देखिए:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

अगर आप `scoped enumerations` को पूर्णांक में बदलना चाहते हैं, तो `static_cast<int>` इस्तेमाल कर सकते हैं।

## `switch` स्टेटमेंट

दूसरी भाषाओं की तरह C++ में भी `switch` स्टेटमेंट होता है।
`switch` स्टेटमेंट लंबे `if ... else if` स्टेटमेंट लिखने का छोटा तरीका है।
स्विच बनाने के लिए सबसे पहले `switch` कीवर्ड लिखते हैं, और उसके बाद एक पूर्णांक।
इसके बाद हम हर शर्त को `case` कीवर्ड से घोषित करते हैं।
हम एक `default` केस भी लिख सकते हैं, जो तब चलेगा जब ऊपर की `case` शर्तों में से कोई भी न मिले।
हर केस का अंत `break` (या `return`) स्टेटमेंट से होना चाहिए।

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## फॉल-थ्रू

स्विच की बनावट में एक ज़रूरी बात यह है कि कोड तब तक चलता रहता है जब तक कोई `break` (या `return`) स्टेटमेंट उसे रोक न दे।
इससे ऐसा व्यवहार मिल सकता है जिसकी उम्मीद आपने नहीं की होगी।

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

कोड के इस तरह चलते रहने का सबसे बड़ा इस्तेमाल वह स्टेटमेंट है जिस पर कई लेबल लगे हों।
कई स्विच नतीजों के लिए एक ही कोड चलाया जा सकता है।
इस तरह, मान लीजिए किसी बुकिंग ऐप में, ग्रुप साइज़ 2 और 3 के लिए कॉल किया जाने वाला फंक्शन एक ही हो सकता है:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
