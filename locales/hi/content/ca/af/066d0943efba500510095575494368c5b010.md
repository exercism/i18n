# विवरण

शर्त वाले एक्सप्रेशन कोड को इस आधार पर चलाने के लिए इस्तेमाल होते हैं कि कोई शर्त **सही** है या **गलत**। ये एक्सप्रेशन इस तरह लिखे जाते हैं:

```haxe
if (condition) {
  expressions
};
```

शर्त का आउटपुट `Bool` टाइप का होता है, इसलिए जब आउटपुट `true` होता है, तब एक्सप्रेशन चलाए जाते हैं।

कभी-कभी, जब शर्त वास्तव में `false` होती है, तो हम चाहते हैं कि कोड का कोई और हिस्सा चले। यहीं `else` एक्सप्रेशन काम आता है। `else` तब एक्सप्रेशन चलाता है जब शुरुआती शर्त `false` होती है। लेकिन अगर हमें शर्त को कई संभावनाओं के लिए जाँचना हो, तो क्या करें? ऐसे में हम `else if (condition)` इस्तेमाल करते हैं। यहाँ एक पूरा उदाहरण है:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
