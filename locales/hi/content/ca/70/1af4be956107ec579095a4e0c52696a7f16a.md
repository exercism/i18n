# निर्देश

आप एक अम्यूज़मेंट पार्क के साथ काम कर रहे हैं और आपको एक ऐसा सिस्टम डिज़ाइन करने का स्पेसिफिकेशन दिया गया है जो पार्क में आने वालों और राइड्स को संभाले। आपको `Attendee` को मॉडल करना है, यानी पार्क में आने वाले व्यक्ति को।

## 1. नए अटेंडी बनाइए

`Attendee` क्लास का `Attendee#initialize` मेथड बनाइए। यह ऊँचाई (सेंटीमीटर में) लेता है और उसे एक इंस्टेंस वेरिएबल में संग्रहीत करता है

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. अटेंडी की ऊँचाई कितनी है

`Attendee` क्लास का `Attendee#height` गेटर बनाइए। यह इंस्टेंस की ऊँचाई लौटाता है

```ruby
Attendee.new(106).height
# => 106
```

## 3. राइड पास आईडी क्या है

सभी अटेंडी ने राइड पास नहीं खरीदा होता, लेकिन हमें पता होना चाहिए कि किसी के पास पास है या नहीं। `Attendee` क्लास के लिए `Attendee#pass_id` गेटर बनाइए। यह इंस्टेंस का pass_id लौटाता है, और अगर अटेंडी के पास राइड पास नहीं है तो `nil` लौटाता है।

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. लोगों को राइड पास खरीदने दीजिए

`Attendee#issue_pass!` बनाइए, जो इंस्टेंस की स्थिति बदल दे और pass id वाले इंस्टेंस वेरिएबल में आर्गुमेंट रख दे। यह pass id लौटाता है।

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. पास वापस लीजिए

कुछ मेहमान असुरक्षित तरीके से पेश आकर नियम तोड़ देते हैं, इसलिए पार्क पास वापस ले सकना चाहता है। `Attendee#revoke_pass!` बनाइए, जो इंस्टेंस की स्थिति बदल दे और pass id को `nil` कर दे

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
