# निर्देश परिशिष्ट

## Prolog में तारीखों के साथ काम करना

तारीखों के लिए Prolog की बिल्ट-इन सुविधा [काफी बुनियादी][built-in-dates-support] है। हालाँकि आप यह अभ्यास उसी से हल कर सकते हैं जो Prolog में पहले से मौजूद है, लेकिन तारीखों के साथ काम करने का इससे कहीं बेहतर तरीका [date_time पैकेज][date-time-package] है।

### date_time पैकेज इंस्टॉल करना

अगर आपका इंस्टॉल किया हुआ Swipl वर्शन काफी नया है, तो आप यह पैकेज इस तरह इंस्टॉल कर सकते हैं:

```bash
swipl pack install date_time
```

अगर इससे काम न चले, तो आप यह चला सकते हैं:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
अगर आप ऑनलाइन एडिटर इस्तेमाल कर रहे हैं, तो आपको कुछ भी खुद इंस्टॉल करने की ज़रूरत नहीं है।
~~~~

### date_time पैकेज का उपयोग करना

`date_time` पैकेज इस्तेमाल करने के लिए अपने हल की फाइल में सबसे ऊपर यह कोड जोड़िए:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
सुझाव: [date_time पैकेज का सोर्स][date-time-package-source] अच्छी तरह डॉक्युमेंट किया गया है और इससे आपको बहुत मदद मिलेगी!
