# विवरण

[concept:csharp/enumerables]() पर [`foreach` लूप][foreach-statement] का इस्तेमाल करके इटरेशन किया जा सकता है:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

एक `foreach` लूप के तीन हिस्से होते हैं:

1. घोषणा: वह वेरिएबल घोषित करना जिसमें इटरेशन से मिली वैल्यू रखी जाएगी। इस वेरिएबल का इस्तेमाल सिर्फ लूप के अंदर ही किया जा सकता है।
2. इटरेबल ऑब्जेक्ट: वह ऑब्जेक्ट जिस पर इटरेशन किया जा सकता है।
3. लूप के अंदर का कोड।

## `for` और `foreach` लूप में अंतर

लेकिन आम तौर पर एक `foreach` लूप को `for` लूप से बेहतर माना जाता है, और इसकी वजहें ये हैं:

- `foreach` लूप _सभी_ वैल्यू पर इटरेशन करता है, इसकी गारंटी होती है। `for` लूप में एलिमेंट छूट जाना आसान है, जैसे ऑफ-बाय-वन एरर की वजह से।
- `foreach` लूप अधिक _डिक्लेरेटिव_ होता है, आपका कोड बताता है कि आप _क्या_ करवाना चाहते हैं, जबकि `for` लूप बताता है कि आप यह _कैसे_ करना चाहते हैं।
- `foreach` लूप में गलती की गुंजाइश नहीं रहती, जबकि `for` लूप में ऑफ-बाय-वन एरर हो जाना आसान है।
- `foreach` लूप हर तरह के कलेक्शन पर काम करता है, उन पर भी जो एलिमेंट तक पहुँचने के लिए इंडेक्सर के इस्तेमाल का समर्थन नहीं करते।

यह गारंटी देने के लिए कि `foreach` लूप _सभी_ वैल्यू पर इटरेशन करेगा, कंपाइलर `foreach` लूप के अंदर कलेक्शन को बदलने की इजाजत नहीं देता:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for` लूप में `foreach` लूप के मुकाबले कुछ फायदे भी हैं:

- आप जिस इंडेक्स से चाहें, वहाँ से शुरू या रुक सकते हैं।
- आप अपनी मर्ज़ी की कोई भी (बूलियन) समाप्ति शर्त इस्तेमाल कर सकते हैं।
- लूप वेरिएबल को बढ़ाने का तरीका बदलकर आप एलिमेंट छोड़ सकते हैं।
- उलटी गिनती करके आप कलेक्शन पर पीछे से आगे की ओर काम कर सकते हैं।
- आप ऐसी स्थितियों में भी `for` लूप इस्तेमाल कर सकते हैं जिनमें कलेक्शन शामिल नहीं होते।

संबंधित विषय:

- आपको यह जानना चाहिए कि C# [बहुआयामी ऐरे][multi-dimensional-arrays] का समर्थन करता है, जैसे `int[,] arr = new int[10, 5]`, जो बहुत काम के हो सकते हैं।
- आपको यह भी जानना चाहिए कि आप `Array.CreateInstance` से [`System.Array`][system-array-object] टाइप के ऑब्जेक्ट बना सकते हैं। ऐसे ऑब्जेक्ट बहुत काम के नहीं होते। ये मुख्य रूप से VB.NET कोड के साथ इंटरऑप के लिए होते हैं। इन्हें सामान्य ऐरे (`T[]`) के बदले इस्तेमाल नहीं किया जा सकता। इनकी निचली सीमा शून्य के अलावा कुछ और भी हो सकती है।
