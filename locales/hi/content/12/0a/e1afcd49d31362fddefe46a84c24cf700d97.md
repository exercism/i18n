# परिचय

Perl एक प्रोग्रामिंग भाषा है, जिसे Larry Wall ने बनाया था। यह पहली बार 1987 में जारी हुई थी।

## पैकेज और मॉड्यूल

पैकेज कोड का एक संग्रह होता है, जो अक्सर उसी नाम की मॉड्यूल फाइल में रखा जाता है और उसका एक्सटेंशन `.pm` होता है।
इसके बाद उस मॉड्यूल को किसी दूसरी फाइल में इम्पोर्ट किया जा सकता है, आमतौर पर `use` कीवर्ड की मदद से।

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## वेरिएबल

वेरिएबल तीन तरह के होते हैं: स्केलर (`$foo`), ऐरे (`@bar`) और हैश (`%baz`)।
चीज़ों को आसान रखने के लिए यहाँ सिर्फ स्केलर वेरिएबलो का इस्तेमाल किया जाएगा।
एक स्केलर वैल्यू ये चीज़ें हो सकती है: एक स्ट्रिंग, एक संख्या, एक बूलियन, या किसी चीज़ का [रेफरेंस][perlreftut]।
वैल्यू का न होना `undef` है।


`my` और `our` कीवर्ड किसी वेरिएबल को लेक्सिकल स्कोप में घोषित करते हैं, जैसे `my $foo;`।
`our` लगाने पर वह वेरिएबल उसी नाम के पैकेज वेरिएबल से भी जुड़ जाता है।
वेरिएबल घोषित करने के और भी तरीके हैं, जिन्हें यहाँ नहीं समझाया जाएगा।

आप `=` ऑपरेटर से किसी वेरिएबल को असाइन कर सकते हैं, जैसे `$foo = 1;`। यह काम वेरिएबल घोषित करने के साथ ही किया जा सकता है, जैसे `my $foo = 1;`।

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## सबरूटीन

`sub` कीवर्ड एक [सबरूटीन][perlsub] घोषित करता है।
`return` कीवर्ड सबरूटीन से बाहर निकलता है और दी गई वैल्यू लौटाता है, या अगर कुछ नहीं दिया गया हो तो खाली ऐरे लौटाता है।
अगर `return` नहीं लिखा गया हो, तो लौटाई जाने वाली वैल्यू इस बात से तय होती है कि सबरूटीन किस संदर्भ में इस्तेमाल हुआ है (स्केलर, ऐरे या void) और उसका अंतिम स्टेटमेंट क्या है।

```perl
sub hello () {
    return 'Hello, World!';
}
```

Perl के नए वर्शन में आप [सिग्नेचर][perlsubsig] में औपचारिक पैरामीटर लिख सकते हैं।
पैरामीटर लिस्ट में स्केलर, ऐरे या हैश वेरिएबल हो सकते हैं।
खाली पैरामीटर लिस्ट का मतलब है कि सबरूटीन शून्य आर्गुमेंट लेता है।
Perl के पुराने वर्शन में आर्गुमेंट `@_` नाम के खास वेरिएबल से निकालने पड़ते थे, जिसे यहाँ नहीं समझाया जाएगा।

## कमेंट

Perl में कमेंट `#` से शुरू होता है और लाइन के अंत में खत्म हो जाता है। हालाँकि, वह `#` किसी स्ट्रिंग का हिस्सा नहीं होना चाहिए।
