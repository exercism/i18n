# कंडीशनल

**कंडीशनल** किसी बात के सही होने या न होने के आधार पर दो रास्तों में से एक चुनता है।

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

इसे पढ़िए: पहले `if`, फिर एक सवाल जिसका जवाब `true` या `false` में आता है, और फिर `then`। जब जवाब सही हो, तब `then` के बाद की लाइनें चलती हैं, और जब जवाब गलत हो, तब `else` के बाद की लाइनें चलती हैं। `end;` पूरी चीज़ को बंद कर देता है।

## दो से ज़्यादा रास्ते

`elsif` एक और सवाल जोड़ता है, जो तभी पूछा जाता है जब उसके ऊपर वाले सवालों का जवाब गलत निकला हो।

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

यहाँ क्रम मायने रखता है। `9` का स्कोर पहले ही सवाल में पकड़ लिया जाता है और दूसरे तक पहुँचता ही नहीं, हालाँकि `9 >= 5` भी सही है। सवालों को गलत क्रम में लिखना ही इसमें गलती करने का आम तरीका है।

इसे `elsif` लिखा जाता है, न कि `elseif`, और न ही `else if`।

## `else` को छोड़ना

जब उस स्थिति में करने के लिए कुछ न हो, तो `else` छोड़ा जा सकता है।

```sather
   if late then
      apologise;
   end;
```

जिस रूटीन को कुछ लौटाना ही होता है, उसमें हर रास्ते से कुछ लौटना ज़रूरी होता है। इसलिए इस अभ्यास में हर `if` के साथ उसका `else` बना रहता है।
