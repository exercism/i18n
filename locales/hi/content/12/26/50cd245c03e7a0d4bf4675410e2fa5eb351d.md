# स्ट्रिंग कॉन्कैटिनेशन

Ruby में स्ट्रिंग कॉन्कैटिनेशन बिल्कुल सही है, लेकिन स्ट्रिंग बनाने का ज़्यादा आम तरीका [स्ट्रिंग इंटरपोलेशन](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) है। उदाहरण के लिए:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
