# टपल टाइप

टपल Cairo में एक बहुमुखी और कुशल संयुक्त डेटा टाइप है, जिससे आप अलग-अलग टाइप की कई वैल्यू को एक इकाई में समूहित कर सकते हैं।
टपल की लंबाई निश्चित होती है, यानी एक बार घोषित होने के बाद उसका आकार नहीं बदल सकता।

## टपल बनाना

टपल बनाने के लिए, आप ब्रैकेट के अंदर अल्पविराम से अलग की गई वैल्यू की सूची लिखते हैं।
टपल में प्रत्येक स्थान का एक विशिष्ट टाइप होता है, और ये टाइप एक-दूसरे से भिन्न हो सकते हैं।

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

एक टपल अलग-अलग डेटा टाइप की कई वैल्यू रख सकता है, जिनमें अन्य टपल भी शामिल हैं।
उदाहरण के लिए:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

यहाँ, `nested_tup` वेरिएबल एक टपल है जिसमें दो टपल हैं, जो दर्शाता है कि टपल अन्य टपल को एलिमेंट के रूप में रख सकते हैं।

## टपल को टुकड़ों में बाँटना

टपल के अंदर की अलग-अलग वैल्यू निकालने के लिए, आप पैटर्न मैचिंग का उपयोग करके टपल को उसके घटक भागों में बाँट सकते हैं।
यह टपल को उसके घटक भागों में बाँट देता है।

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## एक साथ घोषित करना और टुकड़ों में बाँटना

आप एक टपल को एक साथ घोषित और टुकड़ों में बाँट सकते हैं।

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## यूनिट टाइप `()`

यूनिट टाइप Cairo में एक विशेष टाइप है जिसका केवल एक ही वैल्यू होती है: `()`।
इसे बिना किसी एलिमेंट वाले टपल से दर्शाया जाता है।
यूनिट टाइप का आकार हमेशा शून्य होता है, और यह निश्चित है कि यह कंपाइल किए गए कोड में मौजूद नहीं होता।

Cairo में, प्रत्येक एक्सप्रेशन एक वैल्यू लौटाता है, और जब कोई एक्सप्रेशन कुछ नहीं लौटाता, तो वह अंतर्निहित रूप से `()` लौटाता है।
यह उन फंक्शन के लिए उपयोगी हो सकता है जिन्हें कोई वैल्यू लौटानी होती है लेकिन लौटाने के लिए कोई अर्थपूर्ण वैल्यू नहीं होती।

## नामित टपल टाइप घोषणा

एक नामित टपल आपको टपल के लिए एक अधिक वर्णनात्मक टाइप एलियस बनाने की सुविधा देता है, जिससे कोड की पठनीयता बढ़ती है।

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

इस उदाहरण में, `Point` एक नामित टपल टाइप है जो अहस्ताक्षरित 32-बिट पूर्णांकों की एक जोड़ी को दर्शाता है, जिससे कोड और अधिक अभिव्यक्तिपूर्ण बन जाता है।
