# परिचय

Go में एक एप्लिकेशन को पैकेजों में व्यवस्थित किया जाता है।
पैकेज एक ही फोल्डर में रखी गई सोर्स फाइलों का समूह होता है।
एक फोल्डर की सभी सोर्स फाइलों में फाइल के सबसे ऊपर एक ही पैकेज नाम होना चाहिए।
प्रथा के अनुसार पैकेजों के नाम उसी फोल्डर के समान रखे जाते हैं जिसमें वे स्थित होते हैं।

```go
package greeting
```

Go पैकेजों की एक व्यापक स्टैंडर्ड लाइब्रेरी देता है, जिसका उपयोग आप अपने प्रोग्राम में `import` कीवर्ड से कर सकते हैं।
स्टैंडर्ड लाइब्रेरी के पैकेजों को उनके नाम से इम्पोर्ट किया जाता है।

```go
package greeting

import "fmt"
```

इम्पोर्ट किए गए पैकेज को फिर पैकेज के नाम से संबोधित किया जाता है:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go यह तय करता है कि दूसरे पैकेजों का कोड किसी आइटम का उपयोग कर सकता है या नहीं। यह इस पर निर्भर करता है कि उसे कैसे घोषित किया गया है।
किसी फंक्शन, टाइप, वेरिएबल, कॉन्स्टेंट या स्ट्रक्ट फील्ड को बाहर से दिखाई देने योग्य बनाने के लिए (जिसे _एक्सपोर्टेड_ कहते हैं), नाम बड़े अक्षर से शुरू होना चाहिए।
यह उसी तरह है जैसे Java जैसी अन्य प्रोग्रामिंग भाषाएँ `public` और `private` जैसे एक्सेस मॉडिफायर इस्तेमाल करती हैं।

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
