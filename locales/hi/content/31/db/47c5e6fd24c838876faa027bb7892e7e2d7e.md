# निर्देश

एलेन बच्चों के लिए एक नया गेम बना रही हैं, जिसमें जानवर और जादुई छड़ियाँ हैं। अब उन फंक्शन को लिखने का समय है जो पासा फेंकते हैं, छड़ी की रैंडम एनर्जी बनाते हैं और स्लाइस को शफल करते हैं।

## 1. पासा फेंकिए

एक `RollADie` फंक्शन बनाइए।

यह पारंपरिक बीस फलकों वाला पासा होगा, जिस पर 1 से 20 तक की संख्याएँ होती हैं।

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. छड़ी की एनर्जी तैयार कीजिए

एक `GenerateWandEnergy` फंक्शन बनाइए।
छड़ी की एनर्जी एक रैंडम दशमलव संख्या होनी चाहिए, जो 0.0 के बराबर या उससे अधिक हो और 12.0 से कम हो।

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. स्लाइस को शफल कीजिए

गेम में आठ अलग-अलग जानवर हैं:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

एक `ShuffleAnimals` फंक्शन लिखिए, जो इन आठ जानवरों वाली एक स्लाइस रैंडम क्रम में लौटाता है।
