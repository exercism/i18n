# इंस्टॉलेशन

## Node.js इंस्टॉल कीजिए

**Windows और OS X के उपयोगकर्ता**: [Node.js][node] को [पैकेज मैनेजर के ज़रिए][node-download] इंस्टॉल कीजिए।

**Linux के उपयोगकर्ता**: अपने डिस्ट्रिब्यूशन के लिए [Node.js पैकेज मैनेजर][linstall] पर दिए गए निर्देशों के ज़रिए [Node.js][node] इंस्टॉल कीजिए।

## `jasmine-node` और `coffeescript` इंस्टॉल कीजिए

अधिकांश उपयोगकर्ताओं के लिए यह नीचे दी गई कमांड चलाने जितना ही आसान होगा:

```bash
$ npm install -g jasmine-node coffeescript
```

आपके सेटअप के अनुसार, किसी `npm` मॉड्यूल को ग्लोबली इंस्टॉल करने के लिए आपको सुपर यूज़र अधिकारों की ज़रूरत पड़ सकती है।
ऐसा तब होता है जब आपने ऊपर दिए गए आधिकारिक इंस्टॉलर का उपयोग किया हो।
अगर NPM आपको यह कहते हुए कोई एरर देता है कि आपके पास एक्सेस नहीं है, तो ऊपर दी गई कमांड में `sudo` जोड़ दीजिए:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

अगर आपने आधिकारिक इंस्टॉलर का उपयोग किया है, तो आपका `PATH` अपने आप कॉन्फ़िगर हो जाना चाहिए था। लेकिन अगर आपकी शेल को ग्लोबली इंस्टॉल किए गए मॉड्यूल ढूँढने में समस्या हो रही है, या आपने Node.js को सोर्स से बनाया है।
तो `~/.bash_profile` या `~/.zshrc` में नीचे दी गई पंक्ति जोड़कर अपने `PATH` को अपडेट कीजिए, ताकि उसमें `npm` बाइनरी भी शामिल हो जाए:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
