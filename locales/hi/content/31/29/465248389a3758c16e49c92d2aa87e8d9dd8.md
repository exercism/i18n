# प्रिंट स्टेटमेंट से बचिए

अपने कोड से `System.out.println()` जैसे स्टेटमेंट हटाने की कोशिश कीजिए।
अभ्यास के टेस्ट यह चाहते हैं कि हल मेथड से वैल्यू प्रिंट करने के बजाय _लौटाए_।

आम तौर पर ऐसे स्टेटमेंट कोड को डीबग करने में मदद के लिए जोड़े जाते हैं।
लेकिन इससे बेहतर तरीका यह है कि कोड को एक या एक से अधिक यूनिट टेस्ट चलाते समय डीबग किया जाए।
इसका एक और फायदा यह है कि किसी एक खास टेस्ट केस को डीबग करने पर ध्यान दिया जा सकता है।

यहाँ कुछ लिंक दिए गए हैं जिनमें बताया गया है कि अलग-अलग IDE में यूनिट टेस्ट चलाते समय Java कोड को कैसे डीबग किया जाए:

- [Visual Studio Code में Java टेस्ट चलाना और डीबग करना](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [IntelliJ IDEA में टेस्ट डीबग करना](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
