# परिचय

## एक्सेप्शन फिल्टर करना

`when` कीवर्ड एक्सेप्शन फिल्टर करने के लिए इस्तेमाल होता है। यह `catch` स्टेटमेंट के बाद लिखा जाता है और इसमें कोई भी बूलियन एक्सप्रेशन दे सकते हैं, जिसमें उस समय स्कोप में मौजूद कोई भी वैल्यू शामिल हो सकती है। अगर एक्सप्रेशन का मान सही होता है, तो उस `catch` स्टेटमेंट से जुड़ा ब्लॉक चलाया जाता है, वरना अगला `catch` स्टेटमेंट (अगर कोई हो) जाँचा जाता है।

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## उपयोगकर्ता द्वारा बनाए गए एक्सेप्शन

उपयोगकर्ता द्वारा बनाया गया एक्सेप्शन वह क्लास होती है जिसे आप अपने कोड में बनाते हैं और जो `System.Exception` से बनी होती है। ऐसी क्लास पर क्लास इनहेरिटेंस के सारे नियम लागू होते हैं। इसके अलावा कंपाइलर और भाषा का रनटाइम ऐसी क्लासों के साथ एक खास तरीके से व्यवहार करते हैं, जिससे उनके इंस्टेंस को सामान्य कंट्रोल फ्लो से बाहर भी थ्रो और कैच किया जा सकता है, जैसा कि `exceptions` अभ्यास में बताया गया है।

उपयोगकर्ता द्वारा बनाए गए एक्सेप्शन अक्सर अतिरिक्त जानकारी ले जाने के लिए इस्तेमाल होते हैं, जैसे कोई संदेश और दूसरा ज़रूरी डेटा, ताकि कैच करने वाले कोड को यह जानकारी उपलब्ध हो सके।
