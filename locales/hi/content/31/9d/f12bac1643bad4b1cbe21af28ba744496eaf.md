# तुलना ऑपरेटर

PHP में दस तुलना ऑपरेटर पहले से बने हुए हैं:

| नाम  | उदाहरण    | परिणाम                                             |
| ----- | ---------- | -------------------------------------------------- |
| बराबर | `$a == $b` | सही, अगर टाइप जगलिंग के बाद `$a` `$b` के बराबर है। |
| समान | `$a === $b` | सही, अगर `$a` `$b` के बराबर है और दोनों का टाइप भी एक ही है। |
| बराबर नहीं | `$a != $b` | सही, अगर टाइप जगलिंग के बाद `$a` `$b` के बराबर नहीं है। |
| बराबर नहीं | `$a <> $b` | सही, अगर टाइप जगलिंग के बाद `$a` `$b` के बराबर नहीं है। |
| समान नहीं | `$a !== $b` | सही, अगर `$a` `$b` के बराबर नहीं है या दोनों का टाइप एक ही नहीं है। |
| से कम | `$a < $b` | सही, अगर `$a` `$b` से सख्ती से कम है। |
| से अधिक | `$a > $b` | सही, अगर `$a` `$b` से सख्ती से अधिक है। |
| से कम या बराबर | `$a <= $b` | सही, अगर `$a` `$b` से कम या बराबर है। |
| से अधिक या बराबर | `$a >= $b` | सही, अगर `$a` `$b` से अधिक या बराबर है। |
| स्पेसशिप | `$a <=> $b` | एक पूर्णांक लौटाता है जो `0`i से कम, बराबर या अधिक होता है, जब `$a`। |

PHP में अलग-अलग परिभाषाएँ हैं, जो `equal` और `identical` के बीच अंतर करती हैं। कभी-कभी `identical` को `strictly equal` भी कहा जाता है।

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
