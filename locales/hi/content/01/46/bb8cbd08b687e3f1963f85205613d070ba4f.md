# परिचय

कंडीशनल वे स्टेटमेंट होते हैं जो यह देखकर अलग-अलग कोड चलाते हैं कि कोई शर्त `true` है या `false`।

`if` स्टेटमेंट अपने अंदर का कोड तभी चलाता है जब उसकी शर्त `true` हो।
Go में किसी भी वैल्यू को अपने आप सही या गलत मान लेने जैसी कोई अवधारणा नहीं होती, इसलिए शर्त `bool` टाइप की ही होनी चाहिए।
`if mySlice { ... }` या `if 1 { ... }` जैसे एक्सप्रेशन कंपाइल एरर देते हैं।

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

अतिरिक्त शर्तें जाँचने के लिए `else if` इस्तेमाल कीजिए, और अगर इनमें से कोई भी शर्त न मिले तो अंतिम विकल्प के तौर पर `else`।
शर्तों की जाँच ऊपर से नीचे के क्रम में होती है, और सिर्फ वही ब्रांच चलेगी जिसकी शर्त सबसे पहले सही निकलती है।

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if` स्टेटमेंट में एक छोटा इनिशियलाइज़ेशन स्टेटमेंट भी हो सकता है।
इस तरह घोषित किए गए वेरिएबलो का स्कोप सिर्फ पूरी `if`/`else` चेन तक ही रहता है।

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
