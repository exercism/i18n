# फंक्शन

Cairo में फंक्शन सबसे बुनियादी चीज़ें हैं।

एक परंपरा के तौर पर, Cairo फंक्शन और वेरिएबल के नामों के लिए **स्नेक केस** इस्तेमाल करता है, जिसमें शब्द लोअरकेस में लिखे जाते हैं और उनके बीच अंडरस्कोर लगाया जाता है।

यहाँ एक उदाहरण है:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

फंक्शन `fn` से बनाए जाते हैं। इसके बाद नाम, पैरामीटर के लिए ब्रैकेट (अगर कोई हों), और कर्ली ब्रैकेट के अंदर बंद बॉडी आती है।

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखिए और उसके बाद ब्रैकेट लगाइए।

जब तक फंक्शन स्कोप में रहते हैं, उनका क्रम कोई मायने नहीं रखता।

## पैरामीटर

फंक्शन **पैरामीटर** ले सकते हैं। ये पैरामीटर फंक्शन सिग्नेचर में घोषित वेरिएबल होते हैं।

फंक्शन को कॉल करते समय आप **आर्गुमेंट** देते हैं, यानी वे वैल्यू जो इन पैरामीटर को दी जाती हैं।

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

यहाँ `x`, `felt252` टाइप का पैरामीटर है।

इसे `5` के साथ कॉल करने पर फंक्शन "The value of x is: 5" प्रिंट करता है।

एक से अधिक पैरामीटर कोमा से अलग किए जाते हैं:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

यह प्रिंट करता है: `The measurement is: 5h`.

## स्टेटमेंट और एक्सप्रेशन

Cairo के फंक्शन **स्टेटमेंट** और **एक्सप्रेशन** से मिलकर बने होते हैं:

- **स्टेटमेंट** कोई काम करते हैं, लेकिन कोई वैल्यू नहीं लौटाते।
जैसे, `let x = 3;` एक स्टेटमेंट है।
- **एक्सप्रेशन** का परिणाम एक वैल्यू होता है।
जैसे, `5 + 6` का परिणाम `11` होता है।

कर्ली ब्रैकेट के अंदर बंद ब्लॉक भी एक्सप्रेशन होते हैं, और उनकी अंतिम वैल्यू लौटा दी जाती है:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

यहाँ `y` को `4` वैल्यू असाइन की जाती है।

## रिटर्न वैल्यू

फंक्शन `->` सिंटैक्स की मदद से वैल्यू लौटा सकते हैं, जिससे रिटर्न टाइप बताया जाता है।

डिफॉल्ट रूप से फंक्शन अपने अंतिम एक्सप्रेशन की वैल्यू लौटाता है:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

यह आउटपुट देता है: `The value of x is: 5`.

अधिक जटिल मामलों के लिए:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

यह प्रिंट करता है: `The value of x is: 6`.

ध्यान रखिए, अंतिम एक्सप्रेशन के अंत में सेमीकोलन न लगाइए। ऐसा करने से वह एक्सप्रेशन एक स्टेटमेंट बन जाता है, और फंक्शन अपेक्षित वैल्यू के बजाय `()` (यूनिट टाइप) लौटाने लगता है।
