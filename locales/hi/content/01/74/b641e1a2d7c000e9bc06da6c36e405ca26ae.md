# टेल कॉल रिकर्शन का उपयोग कीजिए

इस अभ्यास का उद्देश्य आपको टेल कॉल रिकर्शन सिखाना है। इसे ऐसे रिकर्शन फंक्शन इस्तेमाल किए बिना हल कीजिए जो टेल रिकर्शन नहीं हैं।

आपके हल में मिले टेल-रिकर्शन वाले फंक्शन: %{tail_call_recursive_functions}। आपके हल में मिले अन्य रिकर्शन वाले फंक्शन: %{non_tail_call_recursive_functions}।

याद रखिए, टेल कॉल रिकर्शन तब होता है जब किसी फंक्शन का मूल्यांकन किया जाने वाला _अंतिम_ एक्सप्रेशन उसी फंक्शन को कॉल करता हो।

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
