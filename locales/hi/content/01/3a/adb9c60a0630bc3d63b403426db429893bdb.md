# परिचय

इंटरफेस को किसी क्लास का सिग्नेचर समझा जा सकता है, क्योंकि यह क्लास के public फील्ड बताता है। कोई क्लास `implments` कीवर्ड के ज़रिए `interface` को _implements_ करती है।

इसका सिंटैक्स किसी क्लास के सिंटैक्स से बहुत मिलता-जुलता है, फर्क सिर्फ इतना है कि यहाँ मेथड बिना बॉडी के सिग्नेचर के रूप में दिखते हैं:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

जो फील्ड किसी इंटरफेस से लागू किए जाते हैं, उनमें हमेशा वही विज़िबिलिटी मॉडिफायर इस्तेमाल होना **ज़रूरी** है। जैसे, अगर किसी इंटरफेस में वेरिएबल `a` `public` है, तो उसके इम्प्लीमेंटेशन में भी `public` होना चाहिए।
