# Debug

फेल होने वाले टेस्ट के साथ संदेश जोड़ने के लिए आप [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) का उपयोग कर सकते हैं, जैसे:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

टेस्ट फेल होने पर जुड़ा हुआ लॉग `secondsInOneHour: 3600` होगा।

एक बात ध्यान में रखिए: टॉप-लेवल कॉन्स्टेंट की गणना टेस्ट चलना शुरू होने से पहले केवल एक बार होती है, इसलिए टेस्ट उनके लॉग संदेशों को नहीं पकड़ पाते। उदाहरण:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

टेस्ट के दौरान यह कुछ भी लॉग नहीं करेगा, क्योंकि `secondsInOneHour` से जुड़े JavaScript वेरिएबल की गणना पहले ही हो चुकी है और उसकी वैल्यू 3600 है।
