# परिचय

Rust में बूलियन को `bool` टाइप से दर्शाया जाता है, जिसकी वैल्यू `true` या `false` हो सकती है।

Rust छह तुलना ऑपरेटर का समर्थन करता है: `==` (बराबर), `!=` (बराबर नहीं), `>` (से बड़ा), `<` (से छोटा), `>=` (से बड़ा या बराबर), `<=` (से छोटा या बराबर)। इनका उपयोग गैर-बूलियन वैल्यू के आपसी संबंध को जाँचकर उसे बूलियन वैल्यू में बदलने के लिए किया जा सकता है।

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

कुछ अन्य भाषाओं के विपरीत, `0` का अर्थ `false` नहीं है और शून्य के अतिरिक्त कोई भी संख्या `true` नहीं है।

Rust दो बूलियन ऑपरेटर का समर्थन करता है: `||` (या) और `&&` (और)। इनका मूल्यांकन तभी होता है जब बाएँ ओर का ऑपरेंड एक्सप्रेशन का परिणाम पहले से तय न कर चुका हो। यानी `||` अपने दाएँ ओर के ऑपरेंड का मूल्यांकन तभी करता है जब बाएँ ओर का ऑपरेंड `false` देता है, और `&&` तभी करता है जब वह `true` देता है।
