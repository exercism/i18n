# संकेत

## 1. अपना परिचय दीजिए

- `introduce` फंक्शन को `player.Name` में रखी वैल्यू "खोलनी" होती है। जब `player.Name` का मान `Some` हो, तो [`Options.defaultValue` फंक्शन][defaultvalue] की मदद से उसे उसकी "रैप की गई" वैल्यू में बदलने पर विचार कीजिए, और जब वह `None` हो, तो उसे आवश्यक डिफॉल्ट वैल्यू में बदलने पर विचार कीजिए।

## 2. revive मैकेनिक लागू कीजिए

- `revive` फंक्शन को `Some <player>` या `None` लौटाना होता है, जहाँ `<player>` एक `Player` रिकॉर्ड है जिसमें कुछ फील्ड बदले हुए हो सकते हैं।

## 3. स्पेल कास्टिंग मैकेनिक लागू कीजिए

- `Some` और `None` दोनों केसों को संभालने के लिए `match` एक्सप्रेशन इस्तेमाल करने पर विचार कीजिए, जैसा कि नीचे दिए गए उदाहरण में है:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
