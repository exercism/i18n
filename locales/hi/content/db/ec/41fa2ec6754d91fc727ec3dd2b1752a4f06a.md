# टाइप डिक्लेरेशन

PHP में टाइप डिक्लेरेशन से फंक्शन के आर्गुमेंट, रिटर्न वैल्यू और क्लास प्रॉपर्टी के टाइप की जाँच रन टाइम पर होती है।
फंक्शन पर `void` रिटर्न टाइप जोड़ा जा सकता है। यह बताता है कि वह फंक्शन कोई वैल्यू नहीं लौटाता।
घोषित टाइप रन टाइम पर यह भी जाँचते हैं कि फंक्शन उचित टाइप वाली वैल्यू ही लौटा रहे हैं।

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## टाइप यूनियन

अगर किसी फंक्शन के आर्गुमेंट, रिटर्न वैल्यू या क्लास प्रॉपर्टी का टाइप एक से अधिक हो सकता है, तो टाइप यूनियन घोषित की जा सकती है।

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## मिश्रित टाइप

कोड के साथ काम करते समय कई बार हम टाइप तय नहीं कर पाते।
PHP 8.0 से `mixed` नाम का एक ऐसा टाइप मिलता है, जिसका सहारा ऐसी ही स्थितियों में लिया जा सकता है।
mixed टाइप, `object|resource|array|string|float|int|bool|null` वाली टाइप यूनियन के बराबर होता है।
