# निर्देश परिशिष्ट

## शब्द

एक `stopwatch` टपल और एक कंस्ट्रक्टर `<stopwatch> ( -- stopwatch )` परिभाषित कीजिए, जो `"ready"` स्थिति में एक नया स्टॉपवॉच लौटाता है, जिसमें न बीता हुआ समय होता है और न पिछले लैप।

एक स्टॉपवॉच पर काम करने वाले ये शब्द दीजिए:

- `state ( stopwatch -- str )`: `"ready"`, `"running"`, या `"stopped"`.
- `current-lap ( stopwatch -- str )`: मौजूदा लैप का बीता हुआ समय, `"HH:MM:SS"` स्ट्रिंग के रूप में।
- `total ( stopwatch -- str )`: मौजूदा लैप और उससे पहले के सारे लैपों के बीते हुए समय का कुल जोड़, `"HH:MM:SS"` स्ट्रिंग के रूप में।
- `previous-laps ( stopwatch -- seq )`: पहले दर्ज किए गए लैपों का एक ऐरे, जिसमें हर लैप `"HH:MM:SS"` स्ट्रिंग हो।
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )`, और `lap ( stopwatch -- )`: ऊपर दी गई टेबल के चार कमांड। इनमें से किसी एक को ऐसी स्थिति से कॉल करने पर, जो इसकी अनुमति नहीं देती, एक एरर `throw` होनी चाहिए।

समय इनसे आगे बढ़ता है:

- `advance-time ( str stopwatch -- )`: मौजूदा लैप में `"HH:MM:SS"` अवधि जोड़िए। इसका असर सिर्फ तब होता है, जब स्टॉपवॉच चल रहा हो।
