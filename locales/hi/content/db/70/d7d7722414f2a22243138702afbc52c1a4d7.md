# निर्देश

इस अभ्यास में आप किलोग्राम को इकाई मानकर एक वेइंग मशीन का मॉडल बनाएँगे।

आपके सामने छह काम हैं, और हर काम में आपको एक या उससे अधिक प्रॉपर्टी लागू करनी है:

## 1. वेइंग मशीन में प्रिसिज़न रखने की सुविधा दीजिए

अलग-अलग ज़रूरतों को पूरा करने के लिए हम हर वेइंग मशीन को उसकी अपनी प्रिसिज़न देने की सुविधा देते हैं (प्रिसिज़न यानी दशमलव चिह्न के बाद अंकों की संख्या)।
`WeighingMachine` क्लास में एक सिर्फ पढ़ने वाली `Precision` प्रॉपर्टी लागू कीजिए, जो कंस्ट्रक्टर के `precision` आर्गुमेंट से सेट होती है:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. वेइंग मशीन पर वज़न सेट करने की सुविधा दीजिए

`WeighingMachine.Weight` प्रॉपर्टी को ऐसे लागू कीजिए कि वज़न पढ़ा भी जा सके _और_ सेट भी किया जा सके:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. ऋणात्मक वज़न अस्वीकार हो, यह सुनिश्चित कीजिए

साफ है, किसी व्यक्ति का वज़न ऋणात्मक नहीं हो सकता।
`WeighingMachine.Weight` प्रॉपर्टी में वैलिडेशन जोड़िए, ताकि उसमें ऋणात्मक वज़न सेट करने की कोशिश करने पर `ArgumentOutOfRangeException` फेंका जाए:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. वेइंग मशीन पर टेयर एडजस्टमेंट लागू करने की सुविधा दीजिए

टेयर एडजस्टमेंट की वैल्यू कुछ भी हो सकती है, ऋणात्मक भी, या ऐसी भी जिससे प्रदर्शित होने वाला वज़न ऋणात्मक हो जाए।
`WeighingMachine.TareAdjustment` प्रॉपर्टी लागू कीजिए, ताकि टेयर एडजस्टमेंट सेट किया जा सके:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. वेइंग मशीन में डिफॉल्ट टेयर एडजस्टमेंट हो, यह सुनिश्चित कीजिए

पूरी तरह जाँच करने पर पता चला कि निर्माण की किसी खामी के कारण हर वेइंग मशीन वज़न को `5` अधिक बताती है।
`WeighingMachine.TareAdjustment` प्रॉपर्टी की डिफॉल्ट वैल्यू `5` कर दीजिए।

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. वज़न प्राप्त करने की सुविधा दीजिए

`WeighingMachine.DisplayWeight` प्रॉपर्टी लागू कीजिए। यह एक स्ट्रिंग लौटाती है जिसमें टेयर एडजस्टमेंट लगाने के बाद का वज़न, सही प्रिसिज़न के साथ और इकाई जोड़कर दिखाया जाता है।
ध्यान दीजिए:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
