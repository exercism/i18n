# परिचय

## ऐरे

Cairo की कोर लाइब्रेरी में एक `Array` टाइप होता है।

यह दूसरी प्रोग्रामिंग भाषाओं में मिलने वाले सामान्य ऐरे टाइप जैसा ही है, लेकिन इसमें कुछ खास अंतर हैं:

- एलिमेंट को कुशलता से सिर्फ `Array` टाइप के पीछे ही जोड़ा जा सकता है, और उन्हें कुशलता से सिर्फ सामने से ही हटाया जा सकता है।
- ऐरे इंडेक्स की मदद से किसी एलिमेंट को मैन्युअली सेट करना संभव नहीं है।

ऐरे बनाने के लिए `ArrayTrait::new` फंक्शन और `array!` मैक्रो, दोनों का इस्तेमाल किया जा सकता है:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

`ArrayTrait::append` फंक्शन से ऐरे में एलिमेंट जोड़े जा सकते हैं:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

`ArrayTrait::pop_front` फंक्शन से ऐरे से एलिमेंट हटाए जा सकते हैं:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo में एक `Span` टाइप भी है, जो `Array` के "स्नैपशॉट" की तरह काम करता है।

हर `Array` को `ToSpanTrait::span` फंक्शन से `Span` में बदला जा सकता है:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

ऐरे को `Span` में बदलना बहुत कुशल होता है। `Span` बस एक डेटा स्ट्रक्चर है जो Cairo को ऐरे के एक हिस्से को "देखने" देता है, और स्पैन ऐरे में कोई बदलाव नहीं करता।

ऐरे को `Span` में बदलने से Cairo ऐसे और भी ऑपरेशन कर पाता है जो सीधे `Array` पर नहीं किए जा सकते, जैसे स्पैन के सामने से कोई एलिमेंट हटाना।

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

ध्यान दीजिए कि `pop_back` को कॉल करने के लिए हमें `one_to_four_span` को `mut` कीवर्ड से म्यूटेबल बनाना पड़ा। `pop_back` स्पैन को बदल देता है, क्योंकि यह ऐरे के उस हिस्से को छोटा कर देता है जिसे स्पैन "देख" रहा है।
