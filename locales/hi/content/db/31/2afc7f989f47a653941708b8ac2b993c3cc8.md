# निर्देश

इस अभ्यास में आपको एक एन्क्रिप्शन डिवाइस का सॉफ्टवेयर लिखना है, जो डेटा पर तरह-तरह के बदलाव करके काम करता है। आपको ऐसा तरीका चाहिए जिससे आसान फंक्शनों को मिलाकर जटिल फंक्शन लचीले ढंग से बनाए जा सकें।

हर कार्य के लिए एक अनाम फंक्शन लौटाइए जिसे कॉल करने वाले स्कोप से कॉल किया जा सके।

हर फंक्शन को पूर्णांक आर्गुमेंट लेना चाहिए। Elixir में बिटवाइज़ ऑपरेशन करने के लिए भी पूर्णांक उपयुक्त होते हैं।

## 1. जोड़ने वाला फंक्शन बनाइए

`Secrets.secret_add/1` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उसमें `secret_add` को दिए गए आर्गुमेंट को जोड़ देता है।

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. घटाने वाला फंक्शन बनाइए

`Secrets.secret_subtract/1` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उस आर्गुमेंट में से `secret_subtract` को दिए गए सीक्रेट को घटा देता है।

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. गुणा करने वाला फंक्शन बनाइए

`Secrets.secret_multiply/1` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उसे `secret_multiply` को दिए गए सीक्रेट से गुणा कर देता है।

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. भाग देने वाला फंक्शन बनाइए

`Secrets.secret_divide/1` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उसे `secret_divide` को दिए गए सीक्रेट से भाग देता है।

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

पूर्णांक विभाजन का उपयोग कीजिए ताकि आउटपुट अन्य फंक्शनों के अपेक्षित इनपुट से मेल खाए।

## 5. "and" करने वाला फंक्शन बनाइए

`Secrets.secret_and/1` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उस आर्गुमेंट तथा `secret_and` को दिए गए सीक्रेट पर बिटवाइज़ _and_ ऑपरेशन करता है।

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. "xor" करने वाला फंक्शन बनाइए

`Secrets.secret_xor/1` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उस आर्गुमेंट तथा `secret_xor` को दिए गए सीक्रेट पर बिटवाइज़ _xor_ ऑपरेशन करता है।

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. फंक्शनों को जोड़ने वाला फंक्शन बनाइए

`Secrets.secret_combine/2` बनाइए। इसे एक ऐसा फंक्शन लौटाना चाहिए जो एक आर्गुमेंट लेता है और उस पर `secret_combine` को दिए गए दोनों फंक्शन क्रम से लागू कर देता है।

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
