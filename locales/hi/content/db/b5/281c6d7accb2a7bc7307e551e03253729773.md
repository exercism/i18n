# टेस्ट

टेस्ट कई तरीकों से चलाए जा सकते हैं।

## Emacs के अंदर से, इंटरैक्टिव ढंग से

1. टेस्ट फाइल खोलिए, `M-x eval-buffer RET`
2. इंटरैक्टिव ढंग से और एक-एक करके, `M-x ert RET test-name RET` के साथ
3. इंटरैक्टिव ढंग से और सब एक साथ, `M-x ert RET t RET` के साथ
   ध्यान रखिए कि इससे Emacs में इस समय लोड किए गए सारे टेस्ट चलेंगे!
4. जब भी आप बदलाव करें, टेस्ट करने से पहले `M-x eval-buffer RET` दोबारा चलाइए

अगर आपको सिर्फ मौजूदा बफर के टेस्ट चलाने हैं, तो आप इसे अपनी `.emacs` या `init.el` फाइल में जोड़ सकते हैं:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Emacs को दोबारा शुरू करने के बाद:

1. टेस्ट फाइल खोलिए
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## टर्मिनल से

टर्मिनल से बैच मोड में सारे टेस्ट चलाने के लिए, यह चलाइए: `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`

ऊपर दिया गया कमांड थोड़ा भारी-भरकम है, तो अगर आप चाहें:

1. अपने `$PATH` में एक फाइल बनाइए (शायद `~/bin` में), जिसका नाम `ert-run` हो
2. फाइल की सामग्री इस तरह होनी चाहिए:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. `chmod +x ert-run` से फाइल को एक्ज़ीक्यूटेबल बनाइए

अब आप आसानी से `ert-run *-test.el` कॉल करके बैच मोड में टेस्ट चला पाएँगे।

## अन्य विकल्प

अन्य विकल्प दस्तावेज़ों में मिलेंगे, `C-h i m ert RET`।
