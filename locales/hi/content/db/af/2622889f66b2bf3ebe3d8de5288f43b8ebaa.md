# निर्देश

बहुत ऊँची दैनिक दर के लालच में आप हाइपीरिया (जहाँ महँगाई ऊँची है) वापस आ गए हैं।

केंद्रीय बैंक दूसरी मुद्रा के रूप में अमेरिकी डॉलर लाने पर विचार कर रहा है। इसलिए सभी लेखा प्रणालियों को कई मुद्राओं को संभालने के लिए बदलना पड़ेगा।

आपसे करेंसी अमाउंट ऑब्जेक्ट बनाने को कहा गया है।

## 1. करेंसी अमाउंट को समानता के लिए जाँचने योग्य बनाइए

कृपया `CurrencyAmount` struct को बदलिए ताकि वह समानता संभाल सके। अगर दोनों करेंसी अमाउंट struct की मुद्रा एक जैसी न हो ("USD" या "HD"), तो `ArgumentException` का एक इंस्टेंस फेंका जाना चाहिए।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. करेंसी अमाउंट की तुलना कीजिए

कृपया `CurrencyAmount` struct को बदलिए ताकि वह तुलना (सिर्फ `>` और `<`) संभाल सके। अगर दोनों करेंसी अमाउंट struct की मुद्रा एक जैसी न हो ("USD" या "HD"), तो `ArgumentException` का एक इंस्टेंस फेंका जाना चाहिए।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. करेंसी अमाउंट जोड़िए और घटाइए

कृपया `CurrencyAmount` struct को बदलिए ताकि वह अंकगणितीय जोड़ और घटाव (सिर्फ `+` और `-`) संभाल सके। अगर दोनों करेंसी अमाउंट struct की मुद्रा एक जैसी न हो ("USD" या "HD"), तो `ArgumentException` का एक इंस्टेंस फेंका जाना चाहिए।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. करेंसी अमाउंट का गुणा और भाग कीजिए

कृपया `CurrencyAmount` struct को बदलिए ताकि वह अंकगणितीय गुणा और भाग (सिर्फ `*` और `/`) संभाल सके।

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. करेंसी अमाउंट को `double` में बदलिए

कृपया `CurrencyAmount` struct को इस तरह बदलिए कि उसके किसी इंस्टेंस को स्पष्ट रूप से `double` में कास्ट किया जा सके।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. करेंसी अमाउंट को `decimal` में बदलिए

कृपया `CurrencyAmount` struct को इस तरह बदलिए कि उसके किसी इंस्टेंस को अपने आप `decimal` में बदला जा सके।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
