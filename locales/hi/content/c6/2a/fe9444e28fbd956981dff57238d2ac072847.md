# परिचय

## एक्सटेंशन मेथड

एक्सटेंशन मेथड की मदद से आप पहले से मौजूद टाइप में नए मेथड जोड़ सकते हैं। इसके लिए नया डेराइव्ड टाइप बनाने, दोबारा कंपाइल करने या मूल टाइप में कोई और बदलाव करने की ज़रूरत नहीं पड़ती। इन्हें स्टैटिक मेथड के रूप में परिभाषित किया जाता है, पर कॉल इंस्टेंस मेथड सिंटैक्स से किया जाता है। इनके पहले पैरामीटर के आगे `this` मॉडिफायर लगाया जाता है, जो बताता है कि मेथड किस टाइप पर काम करता है। इन्हें नेमस्पेस के लेवल पर स्कोप में लाया जाता है।

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
