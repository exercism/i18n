# परिचय

एक कीवर्ड लिस्ट `{key, value}` [टपल][exercism-tuples] का एक ऐरे होती है। कीवर्ड लिस्ट लिखने के दो तरीके हैं:

```elixir
# concise
[month: "April", year: 2018]

# explicit
[{:month, "April"}, {:year, 2018}]
```

## की एटम होनी चाहिए

हर 2-टपल का ऐरे कीवर्ड लिस्ट नहीं होता। इसकी सभी की एटम होनी चाहिए:

```elixir
Keyword.keyword?([{"month", "April"}])
# => false
```

अगर आप की में अक्षरों, संख्याओं और `_` के अलावा कोई और अक्षर इस्तेमाल करना चाहते हैं, तो उसे कोटेशन में लपेटना पड़ेगा। लेकिन इससे वह स्ट्रिंग नहीं बन जाता, वह फिर भी एक एटम ही रहता है।

[//]: # (elixir-formatter-disable-next-block)

```elixir
Keyword.keyword?(["day of week": "Monday"])
# => true
```

## की दोहराई जा सकती हैं

कीवर्ड लिस्ट में की दोहराई जा सकती हैं, और [की-वैल्यू जोड़े क्रम में रहते हैं][keyword-duplicate-keys-and-ordering]। किसी एक की के नीचे एक ही वैल्यू निकालने की कोशिश करने पर आपको पहली वैल्यू मिलेगी, और उसी की के नीचे आने वाली बाकी वैल्यू चुपचाप छोड़ दी जाएँगी।

```elixir
list = [month: "April", month: "May"]

Keyword.get_values(list, :month)
# => ["April", "May"]

Keyword.get(list, :month)
# => "April"
```

कीवर्ड लिस्ट में [_एक्सेस बिहेवियर_][access-behaviour] का भी इस्तेमाल किया जा सकता है।

```elixir
list[:month]
# => "April"
```

## विकल्पों के रूप में कीवर्ड लिस्ट

कीवर्ड लिस्ट की खासियतों की वजह से Elixir में फंक्शन को विकल्प देने का डिफ़ॉल्ट तरीका यही बन गया।

जब आप `if` के बारे में सीख रहे थे, तो आपने एक खास छोटा सिंटैक्स देखा था:

```elixir
if age >= 16, do: "beer", else: "no beer"
```

ऐसा लग सकता है कि `if` दो आर्गुमेंट लेता है, लेकिन `do:` और `else:` वास्तव में एक ही आर्गुमेंट हैं, यानी एक कीवर्ड लिस्ट। वही कोड इस तरह भी लिखा जा सकता है:

[//]: # (elixir-formatter-disable-next-block)

```elixir
if age >= 16, [do: "beer", else: "no beer"]
# or
if age >= 16, [{:do, "beer"}, {:else, "no beer"}]
```

फंक्शन के विकल्प के रूप में कीवर्ड लिस्ट का इस्तेमाल इतना आम है कि जब कीवर्ड लिस्ट फंक्शन को दिया जाने वाला अंतिम आर्गुमेंट हो, तो Elixir आपको [चौकोर ब्रैकेट छोड़ने देता है][keyword-call-syntax]।

चूँकि Elixir के सिंटैक्स में टपल, ऐरे, मैप और दूसरी चीज़ों को फंक्शन कॉल की तरह ही देखा जाता है, इसलिए यह सुविधा उनके लिए भी काम करती है।

```elixir
[1, 2, three: 3]
# => [1, 2, {:three, 3}]
```

## पैटर्न मैचिंग

छोटे सिंटैक्स से किसी कीवर्ड लिस्ट पर सफलतापूर्वक पैटर्न मैच करने के लिए आपको सारी की सही क्रम में लिखनी पड़ेंगी। इस वजह से कीवर्ड लिस्ट के साथ काम करते समय पैटर्न मैचिंग का इस्तेमाल शायद ही किया जाता है। इसके बजाय [`Keyword`][keyword] मॉड्यूल या [_एक्सेस बिहेवियर_][access-behaviour] का इस्तेमाल कीजिए।

```elixir
[month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]

[year: year, month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]
```

## कीवर्ड लिस्ट बनाम मैप

|                  | कीवर्ड लिस्ट                  | मैप                                 |
| ---------------- | ----------------------------- | ----------------------------------- |
| की का टाइप       | एटम                           | कोई भी, एक ही मैप में अलग-अलग टाइप मिलाए जा सकते हैं |
| एक जैसी की       | हाँ                           | नहीं                                |
| की का क्रम       | हाँ                           | नहीं                                |
| एक्सेस           | `list[:key]`, `Keyword.get/2` | `map.key`, `map[:key]`, `Map.get/2` |
| एक्सेस का समय    | रैखिक                         | लघुगणकीय                            |
| पैटर्न मैचिंग    | बहुत उपयोगी नहीं              | उपयोगी                              |

तेज़ एक्सेस समय, लचीले की टाइप और उपयोगी पैटर्न मैचिंग की वजह से अधिकतर मामलों में मैप ही डिफ़ॉल्ट पसंद बनते हैं।

जब आपके पास डेटा कम हो, लेकिन आपको एक जैसी की या की किसी खास क्रम में चाहिए, तो कीवर्ड लिस्ट इस्तेमाल कीजिए।
