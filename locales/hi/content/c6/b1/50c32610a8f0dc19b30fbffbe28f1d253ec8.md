# परिचय

JavaScript में _टेम्पलेट स्ट्रिंग_ की मदद से स्ट्रिंग के अंदर एक्सप्रेशन डाले जा सकते हैं। इसे स्ट्रिंग इंटरपोलेशन भी कहते हैं। यह सुविधा बिल्ट-इन [`String`][string-reference] ग्लोबल ऑब्जेक्ट की क्षमता को आगे बढ़ाती है।

JavaScript में टेम्पलेट स्ट्रिंग बनाने के लिए टेक्स्ट को बैकटिक के अंदर लिखिए। इससे टेक्स्ट में नई लाइनें और दूसरे खास अक्षर तो आ ही सकते हैं, आप वेरिएबल और दूसरे एक्सप्रेशन भी डाल सकते हैं।

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

ऊपर के उदाहरण में टेम्पलेट स्ट्रिंग दिखाने के लिए बैकटिक, यानी (<code>\`\`</code>), इस्तेमाल होते हैं। `${...}` वह प्लेसहोल्डर है जिसकी जगह पर असली वैल्यू रखी जाती है। जो डेटा स्ट्रिंग नहीं होता, वह _अपने आप_ स्ट्रिंग में बदल जाता है। इस विषय के बारे में [टाइप कन्वर्ज़न][type-conversion-concept] कॉन्सेप्ट में बताया गया है। टेम्पलेट स्ट्रिंग के साथ हर तरह के एक्सप्रेशन इस्तेमाल किए जा सकते हैं।

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

जब आपको स्ट्रिंग को कई लाइनों में लिखना हो:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

स्ट्रिंग में वैल्यू रखने की जो सुविधाएँ मिलती हैं, उनकी मदद से आप अपने कोड में तर्क भी जोड़ सकते हैं, जिससे तय होता है कि आउटपुट स्ट्रिंग क्या होनी चाहिए।

इसका एक उदाहरण है [टर्नरी ऑपरेटर][ternary-operator] डालना। यह ऑपरेटर `if/else` स्टेटमेंट लिखने का छोटा रूप है। इसका सिंटैक्स ऐसा है: `condition ? consequent-expression : alternative-expression`। अगर शर्त सही होती है, तो कोलन के बाईं ओर वाला ऑपरेंड लौटाया जाता है। वरना टर्नरी एक्सप्रेशन का परिणाम कोलन के दाईं ओर वाला ऑपरेंड होता है।

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
