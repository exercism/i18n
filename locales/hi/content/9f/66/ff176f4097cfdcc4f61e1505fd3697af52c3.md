# निर्देश

इस अभ्यास में आप लॉग लाइनों पर काम करेंगे।

हर लॉग लाइन एक स्ट्रिंग होती है, जो इस तरह बनी होती है: `"[<LEVEL>]: <MESSAGE>"`।

लॉग लेवल तीन तरह के होते हैं:

- `INFO`
- `WARNING`
- `ERROR`

आपके सामने तीन काम हैं। हर काम में एक लॉग लाइन दी जाएगी और आपको उसके साथ कुछ करना होगा।

## 1. लॉग लाइन से संदेश निकालिए

लॉग लाइन का संदेश लौटाने के लिए (_static_) `LogLevels.message()` मेथड लागू कीजिए:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

आगे या पीछे की कोई भी खाली जगह हटा दी जानी चाहिए:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. लॉग लाइन से लॉग लेवल निकालिए

लॉग लाइन का लॉग लेवल लौटाने के लिए (_static_) `LogLevels.logLevel()` मेथड लागू कीजिए। यह लेवल छोटे अक्षरों में लौटाया जाना चाहिए:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. लॉग लाइन को नए रूप में लिखिए

ऐसा (_static_) `LogLevels.reformat()` मेथड लागू कीजिए जो लॉग लाइन को नए रूप में लिखता है। इसमें संदेश पहले आता है और उसके बाद लॉग लेवल गोल ब्रैकेट में:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
