# निर्देश

इस अभ्यास में आप एक ब्यूटी पार्लर के लिए अपॉइंटमेंट शेड्यूलर पर काम करेंगे, जो 15 सितंबर 2012 को खुला था।

आपके पास पाँच काम हैं, और इन सबमें अपॉइंटमेंट की तारीखों से जुड़ा काम करना है।

## 1. अपॉइंटमेंट की तारीख पार्स कीजिए

`Schedule` फंक्शन बनाइए, जो अपॉइंटमेंट की तारीख के टेक्स्ट रूप को उसके मुताबिक `time.Time` फॉर्मैट में पार्स करे:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. जाँचिए कि अपॉइंटमेंट पहले ही बीत चुकी है या नहीं

`HasPassed` फंक्शन बनाइए, जो अपॉइंटमेंट की तारीख लेता है और जाँचता है कि अपॉइंटमेंट कहीं अतीत में थी या नहीं:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. जाँचिए कि अपॉइंटमेंट दोपहर बाद है या नहीं

`IsAfternoonAppointment` फंक्शन बनाइए, जो अपॉइंटमेंट की तारीख लेता है और जाँचता है कि अपॉइंटमेंट दोपहर बाद का समय है या नहीं (>= 12:00 और < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. अपॉइंटमेंट का समय और तारीख बताइए

`Description` फंक्शन बनाइए, जो अपॉइंटमेंट की तारीख लेता है और उस तारीख और समय का विवरण लौटाता है:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. पार्लर के खुलने की सालगिरह की तारीख लौटाइए

`AnniversaryDate` फंक्शन बनाइए, जो वर्तमान वर्ष के लिए UTC में पार्लर के खुलने की सालगिरह की तारीख लौटाता है।

मान लीजिए कि वर्तमान वर्ष 2020 है:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**ध्यान दें:** रिटर्न वैल्यू एक `time.Time` है और दिन का समय मायने नहीं रखता।
