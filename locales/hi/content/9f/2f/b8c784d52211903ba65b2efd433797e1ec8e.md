# परिचय

Factor की I/O *स्ट्रीम* पर बनी है। स्ट्रीम ऐसे ऑब्जेक्ट हैं जिनसे आप बाइट या अक्षर पढ़ते हैं, या जिनमें लिखते हैं। [`io`][io] वोकैबुलरी आपको एक ही [प्रोटोकॉल][stream-protocol] के दो नज़रिए देती है।

## दो नज़रिए

**एक्सप्लिसिट स्ट्रीम** वर्ड स्ट्रीम को आर्गुमेंट के रूप में लेते हैं। इन सबके नाम `stream-` से शुरू होते हैं:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

**एम्बिएंट स्ट्रीम** वर्ड उसी स्ट्रीम से पढ़ते हैं या उसमें लिखते हैं जो *इस समय बाइंड* है, यानी पूरे प्रोग्राम में मौजूद डायनामिक वेरिएबल `input-stream` या `output-stream`। इनके नाम छोटे होते हैं:

```
read1 read readln write write1 print flush
```

रोज़मर्रा का ज़्यादातर कोड एम्बिएंट रूप का ही इस्तेमाल करता है। एक्सप्लिसिट रूप तब काम आता है जब आपके पास कोई खास स्ट्रीम हो और आप एम्बिएंट स्ट्रीम को बदलना नहीं चाहते।

## मेमोरी में रहने वाली स्ट्रीम

इस अभ्यास में आप [`io.streams.string`][io.streams.string] की स्ट्रिंग पर आधारित स्ट्रीम के साथ काम करेंगे:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

एक `<string-reader>` किसी लिटरल स्ट्रिंग से वैसे ही पढ़ता है जैसे वह कोई फाइल हो; एक `<string-writer>` उसमें लिखी हर चीज़ इकट्ठा करता है ताकि आप उसे बाद में वापस पढ़ सकें। दोनों फाइल स्ट्रीम जैसा ही प्रोटोकॉल लागू करते हैं, इसलिए यही पाठ सीधे `<file-reader>` / `<file-writer>` पर भी लागू होते हैं।

## `with-…` से स्कोप बनाना

किसी कोटेशन के लिए एक्सप्लिसिट स्ट्रीम को एम्बिएंट स्ट्रीम के रूप में बाइंड करने और बाद में उसे मुक्त करने के लिए `with-…` कॉम्बिनेटर इस्तेमाल कीजिए:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] "इस कोटेशन जो भी प्रिंट करता है उसे इकट्ठा करो" के लिए सुविधाजनक रूप है। यह राइटर बनाता है, कोटेशन को उस राइटर के साथ एम्बिएंट आउटपुट के रूप में चलाता है, और पकड़ी गई स्ट्रिंग लौटाता है:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

सभी `with-…` कॉम्बिनेटर डिस्ट्रक्टर कॉम्बिनेटर हैं ([`boatswains-bilge`][boatswains-bilge] के `with-disposal` और `with-destructors` वाले परिवार के)। बाहर निकलते समय स्ट्रीम मुक्त कर दी जाती है, चाहे कोटेशन एक्सेप्शन ही क्यों न फेंके।
