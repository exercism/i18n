# अधिक जानकारी

Lambda क्लास में ऐसे फंक्शनल मेथड इकट्ठे हैं जिनकी मदद से Haxe में फंक्शनल स्टाइल की प्रोग्रामिंग की जा सकती है। इसकी मदद से हम पूरे Iterable पर एक साथ काम कर सकते हैं। लूप वाली रूटीन के मुकाबले यह अक्सर बेहतर रहता है, क्योंकि इसमें एरर की गुंजाइश कम होती है और इसे पढ़ना आसान होता है। सुविधा के लिए, Array और List क्लास में `Lambda` क्लास के कुछ बार-बार इस्तेमाल होने वाले मेथड भी मौजूद हैं।

`Lambda` क्लास के कुछ फंक्शन ये हैं:

- `Lambda.array`, `Lambda.list` — Iterable को Array या List में बदलते हैं। यह हमेशा एक नया इंस्टेंस लौटाता है।
- `Lambda.count` — एलिमेंट की संख्या गिनता है। अगर Iterable कोई Array या List है, तो उसकी length प्रॉपर्टी इस्तेमाल करना अधिक तेज़ होता है।
- `Lambda.has` — यह पता लगाता है कि दिया गया एलिमेंट Iterable में मौजूद है या नहीं।
- `Lambda.indexOf` — दिए गए एलिमेंट का इंडेक्स पता करता है।
- `Lambda.find` — दिए गए सर्च फंक्शन के हिसाब से पहला एलिमेंट ढूँढता है।
- `Lambda.concat` — दो Iterable जोड़ता है और एक नया List लौटाता है।
- `Lambda.filter` — वे एलिमेंट ढूँढता है जो किसी मानदंड को पूरा करते हैं, और एक नया List लौटाता है।

कुछ फंक्शन दिखाने वाला एक उदाहरण:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
