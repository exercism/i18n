# स्ट्रक्ट

स्ट्रक्ट कस्टम डेटा टाइप होते हैं। इनकी मदद से आप कई जुड़ी हुई वैल्यू को एक साथ रख सकते हैं और उन्हें नाम दे सकते हैं। ये ट्यूपल जैसे होते हैं, लेकिन ज़्यादा लचीले होते हैं। इनमें आप डेटा के हर टुकड़े को नाम दे सकते हैं, जिससे आपका कोड ज़्यादा साफ़ हो जाता है। Cairo में स्ट्रक्ट की ये विशेषताएँ होती हैं:

- हर स्ट्रक्ट टाइप का अपना एक नाम होता है।
- स्ट्रक्ट के हर सदस्य को **फील्ड** कहा जाता है।
- स्ट्रक्ट के हर फील्ड का अपना एक नाम होता है।
- विज़िबिलिटी फील्ड के लेवल पर देखी जाती है: हर फील्ड अलग से पब्लिक या प्राइवेट हो सकता है।

## स्ट्रक्ट को परिभाषित करना और उसका इंस्टेंस बनाना

स्ट्रक्ट परिभाषित करने के लिए `struct` कीवर्ड लिखिए, उसके बाद एक नाम और फिर घुंघराले ब्रैकेट, जिनके अंदर उनके नाम और टाइप के साथ फील्ड होते हैं:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

किसी स्ट्रक्ट का इंस्टेंस बनाने के लिए उसका नाम लिखिए और घुंघराले ब्रैकेट के अंदर फील्ड के लिए की-वैल्यू जोड़े दीजिए। ध्यान रखिए कि इंस्टेंस बनाते समय आप फील्ड किसी भी क्रम में लिख सकते हैं:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## स्ट्रक्ट के इंस्टेंस के साथ काम करना

स्ट्रक्ट इंस्टेंस के फील्ड को देखने या बदलने के लिए डॉट नोटेशन का इस्तेमाल कीजिए। ध्यान रखिए कि किसी फील्ड को बदलने के लिए इंस्टेंस म्यूटेबल होना चाहिए:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

किसी भी एक्सप्रेशन की तरह, हम फंक्शन के अंदर अंतिम एक्सप्रेशन के रूप में स्ट्रक्ट का नया इंस्टेंस बना सकते हैं। ऐसा करने पर वह नया इंस्टेंस अपने आप लौट जाता है:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## फील्ड इनिशियलाइज़ करने का शॉर्टहैंड

पिछले उदाहरण में `email` और `username` फंक्शन पैरामीटर के नाम स्ट्रक्ट के फील्ड के नामों जैसे रखना ठीक था, लेकिन स्ट्रक्ट के फील्ड में असाइन करते समय उन्हें दोबारा लिखना थोड़ा उबाऊ लगता है। अच्छी बात यह है कि एक ही नाम वाले वेरिएबल से स्ट्रक्ट के फील्ड इनिशियलाइज़ करने के लिए एक आसान शॉर्टहैंड मौजूद है:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## स्ट्रक्ट अपडेट सिंटैक्स से दूसरे इंस्टेंस की मदद से नया इंस्टेंस बनाना

किसी मौजूदा इंस्टेंस से नया इंस्टेंस बनाने के लिए स्ट्रक्ट अपडेट सिंटैक्स का इस्तेमाल कीजिए। इसमें कुछ फील्ड बदल जाते हैं और बाकी वैसे ही रहते हैं। यह `..` ऑपरेटर की मदद से किया जाता है।

अपडेट सिंटैक्स के बिना:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

अपडेट सिंटैक्स के साथ:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

`..user1` सिंटैक्स `user1` के बाकी फील्ड `user2` में कॉपी कर देता है। ध्यान रखिए कि इससे डेटा `user1` से `user2` में चला जाता है। इसलिए अगर `user1` में ऐसे टाइप हैं जिनकी कॉपी नहीं बन सकती, तो उसके बाद `user1` का इस्तेमाल नहीं किया जा सकता।
