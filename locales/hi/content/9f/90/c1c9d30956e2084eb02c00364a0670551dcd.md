# परिचय

[math/rand][mathrand] पैकेज छद्म-यादृच्छिक संख्याएँ बनाने की सुविधा देता है।

`0` से `99` के बीच एक यादृच्छिक पूर्णांक बनाने का तरीका यह है:

```go
n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

फंक्शन `rand.Float64` `0.0` और `1.0` के बीच एक यादृच्छिक दशमलव संख्या लौटाता है:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

स्लाइस (या दूसरे डेटा स्ट्रक्चर) को शफल करने की सुविधा भी है:

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## सीड

`math/rand` पैकेज से बनी संख्या-श्रृंखलाएँ वास्तव में यादृच्छिक नहीं होतीं।
किसी एक खास "सीड" वैल्यू के लिए परिणाम पूरी तरह निर्धारित होते हैं।

Go 1.20+ में सीड अपने आप यादृच्छिक तरीके से चुना जाता है, इसलिए हर बार प्रोग्राम चलाने पर आपको यादृच्छिक संख्याओं का अलग क्रम दिखेगा।

Go के पहले के वर्ज़न में सीड डिफ़ॉल्ट रूप से `1` था।
इसलिए प्रोग्राम को अलग-अलग बार चलाने पर अलग क्रम पाने के लिए, कोई भी यादृच्छिक संख्या निकालने से पहले आपको यादृच्छिक संख्या जनरेटर को खुद से सीड करना पड़ता था, जैसे मौजूदा समय से।

```go
rand.Seed(time.Now().UnixNano())
```

[mathrand]: https://pkg.go.dev/math/rand
