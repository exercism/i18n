# परिचय

Factor की सीक्वेंस लाइब्रेरी इटरेशन को पैरामीटर देने के लिए *क्वोटेशन* पर बहुत निर्भर करती है। क्वोटेशन यानी `[ ]` ब्रैकेट में लिखा कोड। तरीका हमेशा एक ही रहता है: एक सीक्वेंस और एक क्वोटेशन दीजिए, और हायर-ऑर्डर शब्द उस क्वोटेशन को हर एलिमेंट पर चलाता है।

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

आम तौर पर काम आने वाले शब्द ये हैं:

| शब्द         | आकार                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

जब *आपका* शब्द किसी रनटाइम क्वोटेशन को इन कॉम्बिनेटरों में से किसी एक को आगे भेजता है, तो अपने शब्द को `; inline` के साथ घोषित कीजिए, ताकि कॉम्बिनेटर का इफेक्ट इन्फरेंस कॉल साइट पर क्वोटेशन का आकार देख सके। जो शब्द सिर्फ लिटरल क्वोटेशन से बने होते हैं, उन्हें इसकी ज़रूरत नहीं पड़ती।

मुख्य सीक्वेंस ऑपरेशनों के अलावा:

| वोकैब              | क्या देता है                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

जोड़े (`bi`, `tri`) और एन-आरी कॉम्बिनेटर (`2map`, `2each`, `zip`) उसी तरीके को आगे बढ़ाते हैं, जब क्वोटेशन को एक से अधिक इनपुट चाहिए हों।
