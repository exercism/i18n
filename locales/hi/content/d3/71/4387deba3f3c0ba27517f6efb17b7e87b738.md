# परिचय

Pyret में `true` और `false` नाम के दो अलग-अलग बूलियन प्राइमिटिव हैं।
ये दोनों वैल्यू बताती हैं कि कोई दावा या शर्त मान्य है या नहीं।

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret में `and` और `or` ऑपरेटर हैं, जो बूलियन वैल्यू को आपस में मिला सकते हैं।

and ऑपरेटर तब सही लौटाता है जब दोनों तरफ सही हो। बाकी सभी मामलों में यह गलत लौटाता है।

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

or ऑपरेटर तब सही लौटाता है जब कम से कम एक तरफ सही हो। अगर दोनों तरफ गलत हो, तो यह गलत लौटाता है।

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` एक बिल्ट-इन फंक्शन है जो सही को गलत में और गलत को सही में बदल देता है।

```pyret
not(true) # false
not(false) # true
```
