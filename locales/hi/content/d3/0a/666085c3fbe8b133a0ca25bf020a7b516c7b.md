# विवरण

Lua में बूलियन टाइप की दो पारंपरिक बूलियन वैल्यू होती हैं: `true` और `false`। इन वैल्यू को किसी वेरिएबल में असाइन किया जा सकता है, लॉजिकल ऑपरेटरों (`and`, `or`, `not`) के साथ जोड़ा जा सकता है, और शर्त की जाँच में (जैसे कंट्रोल स्ट्रक्चर में) भी इस्तेमाल किया जा सकता है।

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

शर्त की जाँच में और लॉजिकल ऑपरेटरों में बूलियन `false` और `nil`, दोनों गलत माने जाते हैं, और बाकी हर चीज़ सही।
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and` और `or`, दोनों *शॉर्ट-सर्किट इवैल्यूएशन* का इस्तेमाल करते हैं। इसका मतलब है कि वे अपने दूसरे ऑपरेंड का मूल्यांकन तभी करते हैं जब ज़रूरत हो। सभी ऑपरेशन [ऑपरेटर की प्राथमिकता](https://www.lua.org/manual/5.4/manual.html#3.4.8) के अनुसार मूल्यांकित होते हैं, जिसमें `not` का मूल्यांकन `and` और `or` से पहले होता है।

चूँकि केवल `false` और `nil` गलत माने जाते हैं और बाकी सब कुछ सही, Lua में एक आम तरीका यह है:
```lua
x = x or y
```

यह इसके बराबर है:
```lua
if not x then
  x = y
end
```

फंक्शन में यह बहुत आम है कि अगर किसी पैरामीटर की कोई वैल्यू न हो (यानी वह `nil` हो), तो उसे डिफाल्ट वैल्यू असाइन कर दी जाए:
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
