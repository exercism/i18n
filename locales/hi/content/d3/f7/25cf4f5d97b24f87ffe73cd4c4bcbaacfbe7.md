# परिचय

ColdFusion (CFML) एक JVM स्क्रिप्टिंग भाषा है, जिसका सिंटैक्स C या JavaScript जैसा है। यह JIT कंपाइल होकर ऐसे बाइट कोड में बदल जाती है जो JVM पर चलता है, लेकिन यह डायनामिक और लूज़ली टाइप्ड है। इससे इसमें डेवलप करना तेज़ और आसान हो जाता है। CF एक मल्टी-पैराडाइम्ड भाषा है, जो क्लासिकल OO और फंक्शनल प्रोग्रामिंग को सपोर्ट करती है।

CFML में एक बिल्ट-इन टैग-आधारित टेम्पलेटिंग भाषा भी है, जो इसे वेब ऐप्स के लिए आदर्श बनाती है। यह एक J2EE कंटेनर में चलती है, जिसमें कई लाइब्रेरी पहले से बंडल होती हैं। इनकी वजह से कई पैकेज इंस्टॉल किए बिना ही इसके साथ बहुत उत्पादक तरीके से काम किया जा सकता है। CFML में ज़िप फाइलों, PDF और Excel जनरेशन, ईमेल, FTP, HTTP, S3 फाइल सिस्टम, ESAPI सुरक्षा लाइब्रेरी, JDBC ड्राइवर, JSON और REST API के लिए नेटिव सपोर्ट है।

CFML किसी भी Java प्रोजेक्ट का फायदा उठा सकती है: आप प्रोजेक्ट में JAR फाइलें डालकर अपने कोड में सीधे Java ऑब्जेक्ट बना सकते हैं। आप बेसिक सिंटैक्स और फर्स्ट-क्लास डेटा टाइप के बारे में इस गाइड में और जान सकते हैं: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
