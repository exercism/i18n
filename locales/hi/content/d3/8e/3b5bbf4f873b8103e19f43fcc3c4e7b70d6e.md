# निर्देश

एक त्रिनरी संख्या को मूल सिद्धांतों से उसके दशमलव रूप में बदलिए। यह संख्या स्ट्रिंग के रूप में दी जाती है, जैसे '102012'।

अगर कोई स्ट्रिंग अमान्य त्रिनरी बताती है, तो प्रोग्राम उसे वैल्यू 0 माने।

त्रिनरी संख्याओं में तीन चिह्न होते हैं: 0, 1 और 2।

त्रिनरी संख्या में सबसे अंतिम स्थान 1 का होता है। उससे पहले वाला स्थान 3 का, उससे पहले वाला 9 का, और इसी तरह आगे।

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

अगर आपकी भाषा की स्टैंडर्ड लाइब्रेरी में यह रूपांतरण करने वाला कोई मेथड है, तो मान लीजिए कि वह मौजूद ही नहीं है और इसे खुद लागू कीजिए।
