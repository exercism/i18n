# निर्देश

अपने दोस्तों के लिए कुकीज़ बनाने की तैयारी करते समय आपको पता चला कि रेसिपी में इस्तेमाल हुई कुछ मात्राएँ बदलनी पड़ेंगी। आप मीट्रिक प्रणाली से ही परिचित हैं, इसलिए अपनी सुविधा के लिए आपको बेकिंग में इस्तेमाल होने वाली आम अमेरिकी मात्राओं को मिलीलीटर (mL) में बदलने का तरीका निकालना है।

अपने हल के लिए इस रूपांतरण चार्ट का उपयोग कीजिए:

| बदलने वाली इकाई | मात्रा | मिलीलीटर (mL) में |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| अमेरिकी कप       | 1      | 240                 |
| अमेरिकी द्रव औंस  | 1      | 30                  |
| अमेरिकी छोटा चम्मच | 1    | 5                   |
| अमेरिकी बड़ा चम्मच | 1     | 15                  |

आप एक होनहार प्रशिक्षु प्रोग्रामर हैं, इसलिए आप मिलीलीटर को बीच की इकाई बनाने का तरीका चुनते हैं। इससे सूची में दी गई किसी भी इकाई से किसी भी दूसरी इकाई में, यहाँ तक कि उसी इकाई में भी, बदलना आसान हो जाता है।

## 1. मात्रा जोड़ी से संख्यात्मक भाग निकालिए

`KitchenCalculator.get_volume/1` फंक्शन बनाइए। इसे मात्रा जोड़ी वाला एक टपल मिलता है, और इसे सिर्फ संख्यात्मक भाग लौटाना चाहिए।

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. मात्रा जोड़ी को मिलीलीटर में बदलिए

`KitchenCalculator.to_milliliter/1` फंक्शन बनाइए। इसे मात्रा जोड़ी वाला एक टपल मिलता है, और इसे रूपांतरण चार्ट का उपयोग करके उस मात्रा को मिलीलीटर में बदलना चाहिए।

हर इकाई के लिए अलग फंक्शन बनाने के लिए कई फंक्शन क्लॉज़ और पैटर्न मैचिंग का उपयोग कीजिए। हर इकाई को दर्शाने वाले एटम ये हैं: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. बदलाव के नतीजे को एक टपल में लपेटकर लौटाइए।

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. मिलीलीटर वाली मात्रा जोड़ी को दूसरी इकाई में बदलिए

`KitchenCalculator.from_milliliter/2` फंक्शन बनाइए। इसे मात्रा जोड़ी वाला एक टपल और मनचाही इकाई मिलती है, और इसे रूपांतरण चार्ट का उपयोग करके उस मात्रा को मनचाही इकाई में बदलना चाहिए।

हर इकाई के लिए अलग फंक्शन बनाने के लिए कई फंक्शन क्लॉज़ और पैटर्न मैचिंग का उपयोग कीजिए। हर इकाई को दर्शाने वाले एटम ये हैं: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. किसी भी इकाई से किसी भी इकाई में बदलिए

`KitchenCalculator.convert/2` फंक्शन बनाइए। इसे मात्रा जोड़ी वाला एक टपल और मनचाही इकाई मिलती है, और इसे दी गई मात्रा को मनचाही इकाई में बदलना चाहिए।

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
