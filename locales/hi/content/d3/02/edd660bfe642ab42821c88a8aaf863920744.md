# परिचय

मेथड में एक वरआर्ग्स पैरामीटर हो सकता है, जो कॉल करने वाले को शून्य या अधिक आर्गुमेंट देने की सुविधा देता है, जैसे वे सामान्य पैरामीटर हों। मेथड को ये आर्गुमेंट एक ही ऐरे में मिलते हैं।

किसी पैरामीटर को वरआर्ग्स पैरामीटर बनाने के लिए, पैरामीटर की घोषणा में `params` कीवर्ड जोड़िए:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
