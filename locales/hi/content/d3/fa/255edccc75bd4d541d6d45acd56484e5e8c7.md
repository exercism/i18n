# इंस्टॉलेशन

## Windows (अनुशंसित)

क्या आप Windows ऑपरेटिंग सिस्टम इस्तेमाल कर रहे हैं?

`Windows Key` दबाइए, `cmd` टाइप कीजिए और `enter` दबाइए।

> अगर आपका ऑपरेटिंग सिस्टम Windows है, तो Batch आपके सिस्टम पर पहले से इंस्टॉल है।

अगर आप कोई दूसरा ऑपरेटिंग सिस्टम इस्तेमाल कर रहे हैं, तो नीचे दिए गए निर्देशों का पालन करके Batch इंस्टॉल कर सकते हैं।

## Mac OS

1. Gatekeeper को इस तरह सेट नहीं होना चाहिए कि वह बिना साइन किए पैकेजों को रोक दे।
2. Terminal ऐप खोलिए।
3. Batch इंस्टॉल करने के लिए यह कमांड चलाइए:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. अगर आपका सिस्टम 64 बिट का है, तो 32 बिट आर्किटेक्चर चालू कीजिए (अगर अभी तक चालू नहीं किया है):

```bash
sudo dpkg --add-architecture i386
```

2. WineHQ रिपॉज़िटरी जोड़िए:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. WineHQ इंस्टॉल कीजिए:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Wine रिपॉज़िटरी चालू कीजिए:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. WineHQ इंस्टॉल कीजिए:

```bash
dnf install winehq-stable
```
