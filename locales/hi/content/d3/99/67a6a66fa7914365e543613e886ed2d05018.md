# परिचय

## use एक्सप्रेशन

Gleam में हायर ऑर्डर फंक्शन लिखना और इस्तेमाल करना आम बात है, यानी ऐसे फंक्शन जो दूसरे फंक्शन को आर्गुमेंट के रूप में लेते हैं। कभी-कभी एक साथ कई हायर ऑर्डर फंक्शन इस्तेमाल करने पर कोड में इंडेंटेशन की कई परतें हो जाती हैं और उसे पढ़ना मुश्किल हो जाता है।

उदाहरण के लिए, यहाँ एक फंक्शन है जो ऐसे कई फंक्शन कॉल करता है जो `Result(Int, Nil)` लौटाते हैं, और अगर चारों सफल होते हैं तो उन वैल्यू को जोड़ देता है।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam के `use` एक्सप्रेशन की मदद से हम यह कोड बिना इंडेंटेशन के लिख सकते हैं, जिससे यह अक्सर पढ़ने में आसान हो जाता है।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

एक `use` एक्सप्रेशन ब्लॉक के बाद आने वाले सारे स्टेटमेंट इकट्ठा करता है और उन्हें कॉलबैक फंक्शन के रूप में फंक्शन कॉल के अंतिम आर्गुमेंट की तरह भेज देता है। `use` कीवर्ड और `<-` चिह्न के बीच लिखे गए वेरिएबलो ही उन आर्गुमेंट के नाम होते हैं जो कॉलबैक फंक्शन को भेजे जाएँगे।

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

कॉलबैक फंक्शन कितने भी आर्गुमेंट ले सकता है, या एक भी नहीं।

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

`use` एक्सप्रेशन की मदद से कॉल की जा सकने वाली फंक्शन बनाने के लिए कोई खास शर्त नहीं है, बस अंतिम आर्गुमेंट के रूप में एक कॉलबैक फंक्शन लेना ज़रूरी है।

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam के `use` एक्सप्रेशन एक बहुत शक्तिशाली फीचर हैं जिन्हें ढेर सारी समस्याओं पर लागू किया जा सकता है, लेकिन ज़रूरत से ज़्यादा इस्तेमाल करने पर ये कोड को पढ़ना मुश्किल बना सकते हैं। आम तौर पर सामान्य फंक्शन कॉल सिंटैक्स ही इस्तेमाल करना बेहतर होता है, और `use` एक्सप्रेशन तभी उठाना चाहिए जब वे कोड को पढ़ने में आसान बनाते हों।
