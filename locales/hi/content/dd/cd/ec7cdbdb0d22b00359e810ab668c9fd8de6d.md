# निर्देश

इस अभ्यास में आपको प्रोग्रामिंग भाषाओं के ऐरे पर काम करने के लिए कुछ फंक्शन बनाने हैं।

## 1. खाली भाषाओं का ऐरे लौटाने वाला फंक्शन बनाइए

`new` फंक्शन बनाइए जो कोई आर्गुमेंट नहीं लेता और एक खाली ऐरे लौटाता है।

```haskell
new
-- -> []
```

## 2. ऐरे में भाषा जोड़ने वाला फंक्शन बनाइए

`add/2` फंक्शन बनाइए जो 2 आर्गुमेंट लेता है (एक _भाषाओं का ऐरे_ और एक _भाषा_ का स्ट्रिंग लिटरल)।
इसे दिए गए ऐरे के आगे नई भाषा जोड़कर परिणामी ऐरे लौटाना चाहिए।

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. ऐरे से भाषा हटाने वाला फंक्शन बनाइए

`remove` फंक्शन बनाइए जो 1 आर्गुमेंट लेता है (एक _भाषाओं का ऐरे_)।
इसे पहले एलिमेंट के बिना ऐरे लौटाना चाहिए। मान लीजिए कि ऐरे में हमेशा कम से कम एक एलिमेंट रहेगा।

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. ऐरे का पहला एलिमेंट लौटाने वाला फंक्शन बनाइए

`first` फंक्शन बनाइए जो 1 आर्गुमेंट लेता है (एक _भाषाओं का ऐरे_)।
इसे ऐरे की पहली भाषा लौटानी चाहिए।
मान लीजिए कि ऐरे में हमेशा कम से कम एक एलिमेंट रहेगा।

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. ऐरे में कितनी भाषाएँ हैं, यह लौटाने वाला फंक्शन बनाइए

`count` फंक्शन बनाइए जो 1 आर्गुमेंट लेता है (एक _भाषाओं का ऐरे_)।
इसे ऐरे में मौजूद भाषाओं की संख्या लौटानी चाहिए।

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. यह पता लगाने वाला फंक्शन बनाइए कि ऐरे में कोई फंक्शनल भाषा शामिल है या नहीं

`isFunctionalList` फंक्शन बनाइए जो 1 आर्गुमेंट लेता है (एक _भाषाओं का ऐरे_)।
इसे एक बूलियन वैल्यू लौटानी चाहिए।
इसे `True` लौटाना चाहिए यदि _"Haskell"_ ऐरे की भाषाओं में से एक है।

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
