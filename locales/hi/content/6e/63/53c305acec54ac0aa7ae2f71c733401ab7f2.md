# निर्देश

इस अभ्यास में आप डेवलपर की मदद के लिए आइडेंटिफायर नाम साफ करने वाले कुछ यूटिलिटी रूटीन बनाएँगे।

इस अभ्यास के 6 कार्यों में आप धीरे-धीरे दो फंक्शन बनाएँगे: `transform`, जो अकेले अक्षरों को बदलता है, और `clean`, जो स्ट्रिंग को बदलता है।

एक मान्य आइडेंटिफायर में शून्य या अधिक अक्षर, अंडरस्कोर, हाइफन, प्रश्नचिह्न और इमोजी हो सकते हैं।

अगर `clean` फंक्शन को खाली स्ट्रिंग दी जाए, तो उसे भी खाली स्ट्रिंग लौटानी चाहिए।

## 1. जो भी हाइफन मिलें उन्हें अंडरस्कोर से बदलिए

`transform` फंक्शन बनाइए, जो हर हाइफन को अंडरस्कोर से बदल दे।

```fsharp
transform '-'  // => "_"
```

## 2. सारा व्हाइटस्पेस हटाइए

व्हाइटस्पेस वाले सारे अक्षर हटा दीजिए।
इसमें शुरू और अंत के व्हाइटस्पेस भी शामिल हैं।

```fsharp
transform ' '  // => ""
```

## 3. camelCase को kebab-case में बदलिए

`transform` फंक्शन को ऐसे बदलिए कि वह camelCase को kebab-case में बदल दे।

```fsharp
transform 'D'  // => "-d"
```

## 4. जो अक्षर अंक हैं उन्हें छोड़ दीजिए

`transform` फंक्शन को ऐसे बदलिए कि वह संख्यात्मक अक्षरों को छोड़ दे।

```fsharp
transform '7'  // => ""
```

## 5. यूनानी छोटे अक्षरों को प्रश्नचिह्न से बदलिए

`transform` फंक्शन को ऐसे बदलिए कि वह 'α' से 'ω' तक के यूनानी अक्षरों को बदल दे।

```fsharp
transform 'β' // => "?"
```

## 6. इन कामों को मिलाकर एक स्ट्रिंग पर लागू कीजिए

`clean` फंक्शन बनाइए, जो इन कामों को पूरी स्ट्रिंग पर लागू करे।

जो अक्षर इन नियमों से बाहर हैं, वे बिना बदले जैसे हैं वैसे ही रहने चाहिए।

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## अक्षरों से स्ट्रिंग जोड़ना

यह विषय सिलेबस में आगे विस्तार से बताया जाएगा।

फिलहाल यह जानना उपयोगी हो सकता है कि एक [हायर ऑर्डर फंक्शन][higher-order-function] होता है जिसका नाम [`String.collect`][string-collect] है। यह `char` के संग्रह को स्ट्रिंग में बदलता है, और इसके लिए आपके दिए हुए फंक्शन का इस्तेमाल करता है।

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```

[higher-order-function]: https://exercism.org/tracks/fsharp/concepts/higher-order-functions
[string-collect]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-stringmodule.html#collect
