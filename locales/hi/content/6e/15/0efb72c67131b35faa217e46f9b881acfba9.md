# परिचय

JavaScript में वैल्यू अलग-अलग टाइप की हो सकती हैं। किसी वेरिएबल का टाइप बदलने के लिए स्पष्ट _टाइप कन्वर्ज़न_ किया जा सकता है।
इसके अलावा, जब संदर्भ को ज़रूरत होती है, तब JavaScript _टाइप कोर्शन_ (अंतर्निहित टाइप कन्वर्ज़न) भी करता है।

## टाइप कन्वर्ज़न

बहुत सी दूसरी भाषाओं की तरह JavaScript में किसी (दूसरे) टाइप में कास्ट करने का कोई तरीका नहीं है, लेकिन इसके बजाय कुछ बिल्ट-इन हेल्पर इस्तेमाल किए जा सकते हैं।
सबसे खास बात यह है कि `Boolean`, `Number` और `String` को फंक्शन की तरह इस्तेमाल करके किसी वैल्यू को उसी से जुड़े टाइप में बदला जा सकता है।

### बूलियन में बदलना (ट्रूथी/फॉल्सी वैल्यू)

`Boolean(value)` की मदद से आप किसी भी वैल्यू को बूलियन में बदल सकते हैं।
वैल्यू का एक तय समूह है, जिन्हें _फॉल्सी_ वैल्यू कहते हैं, जो `false` में बदल जाती हैं।
सबसे ज़रूरी बात, `false`, `0`, खाली स्ट्रिंग, `null`, `undefined` और `NaN` फॉल्सी होती हैं।

बाकी सभी वैल्यू के लिए `Boolean` `true` लौटाता है।
ऐसी वैल्यू को _ट्रूथी_ कहते हैं।

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

ध्यान दीजिए कि बताए गए नियमों के कारण JavaScript में `'0'`, `'false'`, `[]` और `{}` **ट्रूथी** होते हैं।

### संख्या में बदलना

किसी वैल्यू को संख्या में बदलने के लिए `Number(value)` इस्तेमाल किया जा सकता है।
स्ट्रिंग के शुरू और अंत की खाली जगहें नज़रअंदाज़ की जाती हैं, और खाली स्ट्रिंग `0` में बदल जाती है।
अगर आप किसी नॉन-प्रिमिटिव वैल्यू या ऐसी स्ट्रिंग को बदलने की कोशिश करते हैं जो किसी संख्या को नहीं दर्शाती, तो परिणाम `NaN` होता है ([संख्या नहीं][mdn-nan])।

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### स्ट्रिंग में बदलना

`String(value)` की मदद से आप किसी वैल्यू को स्ट्रिंग में बदल सकते हैं।
प्रिमिटिव वैल्यू के लिए परिणाम वही होता है जिसकी आप अपेक्षा करेंगे।

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

ऐरे के लिए, `String` फंक्शन हर एलिमेंट पर स्ट्रिंग कन्वर्ज़न लागू करता है और नतीजों को कॉमा से जोड़ देता है।
आप खुद भी [`join` मेथड][mdn-join] लागू कर सकते हैं, जैसे सेपरेटर को अपनी पसंद के मुताबिक बदलने के लिए।
ध्यान दीजिए कि इन मामलों में `null` और `undefined` खाली स्ट्रिंग में बदल जाते हैं।

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

ऑब्जेक्ट के लिए, `String` डिफॉल्ट रूप से एक ऐसा टेक्स्ट लौटाता है जिससे कोई खास मदद नहीं मिलती।

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## टाइप कोर्शन

कुछ संदर्भों में, JavaScript किसी स्टेटमेंट का मूल्यांकन करने से पहले किसी वैल्यू को अपने आप दूसरे डेटा टाइप में बदल देता है।
इस अंतर्निहित कन्वर्ज़न को _टाइप कोर्शन_ कहते हैं।

### बूलियन संदर्भ

जब किसी बूलियन संदर्भ में कोई गैर-बूलियन वैल्यू इस्तेमाल होती है, तो JavaScript उस वैल्यू को अपने आप बदलने के लिए `Boolean` फंक्शन जैसे ही नियम लागू करता है।

बूलियन में कोर्शन आम तौर पर इन जगहों पर होता है

- [`if` स्टेटमेंट][concept-conditionals] की शर्त
- [टर्नरी ऑपरेटर][mdn-ternary] `?` का पहला ऑपरेंड
- लॉजिकल नॉट ऑपरेटर `!` का ऑपरेंड
- लॉजिकल ऐंड `&&` और ऑर `||` ऑपरेटर के ऑपरेंड (एक्सप्रेशन का परिणाम उन ऑपरेंड में से एक होता है, ज़रूरी नहीं कि वह बूलियन हो)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### स्ट्रिंग संदर्भ

अगर जोड़ने वाला ऑपरेटर `+` प्रिमिटिव वैल्यू पर इस्तेमाल होता है और एक ऑपरेंड स्ट्रिंग है, तो दूसरा ऑपरेंड भी स्ट्रिंग में बदल दिया जाता है।
कन्वर्ज़न का तरीका वही है जो `String` फंक्शन इस्तेमाल करने पर होता है।
इसके बाद, दोनों स्ट्रिंग जोड़ दी जाती हैं।

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### संख्यात्मक संदर्भ

बहुत से ऑपरेटर ऊपर बताए गए `Number` फंक्शन के तरीके के मुताबिक ऑपरेंड को (ज़रूरत पड़ने पर) संख्याओं में बदल देते हैं।

- गणितीय ऑपरेटर: `+` (अगर कोई स्ट्रिंग शामिल न हो), `-`, `*`, `/`, `%`, `**`
- यूनरी प्लस और यूनरी निगेशन ऑपरेटर: `+`, `-`
- तुलना ऑपरेटर (गैर-स्ट्रिंग ऑपरेंड के लिए): `>`, `>=`, `<`, `<=`
- बिटवाइज़ ऑपरेटर: `|`, `&`, `^`, `~`

इनमें से किसी भी ऑपरेटर के बारे में ज़्यादा जानकारी के लिए [MDN ऑपरेटर सूची][mdn-operators] देखिए।

गलतियों से बचने के लिए यह अच्छी आदत है कि इन ऑपरेटरों को लगाने से पहले हमेशा `Number` को स्पष्ट रूप से कॉल कीजिए।
