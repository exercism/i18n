# परिचय

## नलएबल टाइप

C# में `null` लिटरल का इस्तेमाल किसी वैल्यू के न होने को दर्शाने के लिए किया जाता है। _नलएबल_ टाइप वह टाइप होता है जिसमें `null` वैल्यू रखी जा सकती है।

C# 8.0 से पहले रेफरेंस टाइप हमेशा नलएबल होते थे और वैल्यू टाइप नहीं। किसी वैल्यू टाइप के आगे प्रश्न चिह्न (`?`) लगाकर उसे नलएबल बनाया जा सकता है।

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

किसी null वेरिएबल के मेंबर तक पहुँचने पर कंपाइल एरर नहीं मिलती, बल्कि रनटाइम पर `NullReferenceException` फेंका जाता है:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

इस आम गलती से बचने के लिए C# 8 में आप ऐसा फीचर चुन सकते हैं जो रेफरेंस टाइप को डिफॉल्ट रूप से नॉन-नलएबल बना देता है:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

नलएबल वैल्यू के साथ सुरक्षित तरीके से काम करने के लिए उनका इस्तेमाल करने से पहले जाँच लीजिए कि वे `null` हैं या नहीं:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }

    // Value is not null at this point, so no compile warning
    // and no runtime NullReferenceException being thrown
    return name.ToUpper();
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

`??` ऑपरेटर की मदद से आप तब डिफॉल्ट वैल्यू लौटा सकते हैं जब वैल्यू `null` हो:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

`?.` ऑपरेटर की मदद से आप किसी ऐसी वैल्यू पर सुरक्षित तरीके से मेंबर कॉल कर सकते हैं जो `null` हो सकती है:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
