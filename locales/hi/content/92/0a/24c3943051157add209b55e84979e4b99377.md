# निर्देश

इस अभ्यास में आप Cairo के कंट्रोल फ्लो की संरचनाओं का उपयोग करके एक छोटी बेकरी के रोज़मर्रा के काम संभालने में मदद करेंगे।

## 1. ऑर्डर का कुल योग निकालिए

`calculate_total` बनाइए, जो पेस्ट्री के प्रकार और मात्रा के आधार पर ऑर्डर की कीमत निकालता है:

- क्रोइसां: 3 सिक्के प्रति
- मफिन: 2 सिक्के प्रति
- कुकी: 1 सिक्का प्रति

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. थोक छूट लागू कीजिए

`apply_discount` बनाइए, जो ऑर्डर के कुल योग के आधार पर छूट लागू करता है।
कुल योग पर प्रतिशत छूट लागू कीजिए, और फिर निकटतम पूर्ण सिक्के तक नीचे की ओर पूर्णांकित कीजिए (floor)।

- 20 सिक्के या अधिक के ऑर्डर: 10% छूट
- 10 सिक्के या अधिक के ऑर्डर: 5% छूट
- 10 सिक्के से कम के ऑर्डर: कोई छूट नहीं

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. बेकिंग शेड्यूल बनाइए

`baking_schedule` बनाइए, जो एक दिन के बेकिंग का प्लान बनाता है।
बेकरी हर घंटे 5 ऑर्डर के बैच में बेक करती है:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

हर समस्या को कुशलता से हल करने के लिए उपयुक्त कंट्रोल फ्लो संरचनाओं (`if`/`else`, `loop`) का उपयोग कीजिए।
