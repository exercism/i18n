# परिचय

## सेट

[`Set`][set-docs] एक ऐसा संग्रह है जिसमें कोई क्रम नहीं होता और जिसमें `List` के विपरीत निश्चित रूप से कोई डुप्लिकेट वैल्यू नहीं होती।

`Set` इंटरफ़ेस का जेनेरिक टाइप पैरामीटर बताता है कि उस `Set` में रखे गए एलिमेंट किस टाइप के होंगे:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

ध्यान दीजिए कि `Set.of()` मेथड एक ऐसा `Set` इंस्टेंस बनाता है [जिसे बदला नहीं जा सकता][unmodifiable-set-docs]।
इस इंस्टेंस पर `add` और `remove` जैसे मेथड कॉल करने की कोशिश की तो प्रोग्राम चलने के समय एक एक्सेप्शन मिलेगा।

ऐसा `Set` बनाने के लिए जिसे बदला जा सके, आपको ऐसी क्लास का एक इंस्टेंस बनाना होगा जो `Set` इंटरफ़ेस को लागू करती है।
इस इंटरफ़ेस को लागू करने वाली सबसे अधिक इस्तेमाल होने वाली बिल्ट-इन क्लास [`HashSet`][hashset-docs] क्लास है।

```java
Set<Integer> ints = new HashSet<>();
```

`Set` इंटरफ़ेस [`Collection`][collection-docs] और [`Iterable`][iterable-docs] इंटरफ़ेस को विस्तारित करता है, इसलिए यह अन्य प्रकार के संग्रहों के साथ बहुत से मेथड साझा करता है।
लेकिन `Collection` इंटरफ़ेस से एक खास फ़र्क यह है कि `add` और `remove` जैसे मेथड `void` के बजाय एक `boolean` लौटाते हैं, जो बताता है कि जब वह मेथड कॉल किया गया था, तब वह आइटम सेट में मौजूद था या नहीं:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
