# निर्देश

इस अभ्यास में आपको क्लासिक गेम Pac-Man के कुछ नियमों को Gleam फंक्शन में बदलना है।

आपको चार नियम बदलने हैं, और ये सभी गेम की स्थितियों से जुड़े हैं।

> इस बात की चिंता न कीजिए कि ये आर्गुमेंट कहाँ से आते हैं; बस इन्हें मिलाकर वह परिणाम लौटाने पर ध्यान दीजिए जो चाहिए।

## 1. तय कीजिए कि Pac-Man भूत खाता है या नहीं

`eat_ghost` फंक्शन बनाइए। यह दो आर्गुमेंट लेता है (_Pac-Man के पास पावर पेलेट चालू है या नहीं_ और _Pac-Man किसी भूत को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man भूत खा सकता है या नहीं। यह फंक्शन केवल तभी `True` लौटाना चाहिए, जब Pac-Man के पास पावर पेलेट चालू हो और वह किसी भूत को छू रहा हो।

```gleam
eat_ghost(False, True)
// -> False
```

## 2. तय कीजिए कि Pac-Man अंक पाता है या नहीं

`score` फंक्शन बनाइए। यह दो आर्गुमेंट लेता है (_Pac-Man किसी पावर पेलेट को छू रहा है या नहीं_ और _Pac-Man किसी डॉट को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man को अंक मिले या नहीं। यह फंक्शन तब `True` लौटाना चाहिए, जब Pac-Man किसी पावर पेलेट या डॉट को छू रहा हो।

```gleam
score(True, True)
// -> True
```

## 3. तय कीजिए कि Pac-Man हारता है या नहीं

`lose` फंक्शन बनाइए। यह दो आर्गुमेंट लेता है (_Pac-Man के पास पावर पेलेट चालू है या नहीं_ और _Pac-Man किसी भूत को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man हारता है या नहीं। यह फंक्शन तब `True` लौटाना चाहिए, जब Pac-Man किसी भूत को छू रहा हो और उसके पास पावर पेलेट चालू न हो।

```gleam
lose(False, True)
// -> True
```

## 4. तय कीजिए कि Pac-Man जीतता है या नहीं

`win` फंक्शन बनाइए। यह तीन आर्गुमेंट लेता है (_Pac-Man ने सारे डॉट खा लिए हैं या नहीं_, _Pac-Man के पास पावर पेलेट चालू है या नहीं_, और _Pac-Man किसी भूत को छू रहा है या नहीं_) और एक बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man जीतता है या नहीं। यह फंक्शन तब `True` लौटाना चाहिए, जब Pac-Man ने सारे डॉट खा लिए हों और भाग 3 में बताए गए आर्गुमेंट के आधार पर वह न हारा हो।

```gleam
win(False, True, False)
// -> False
```
