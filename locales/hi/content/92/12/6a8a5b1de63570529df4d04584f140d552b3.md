# अतिरिक्त निर्देश

## स्टब

`src/TreeBuilding.hs` में पहले से एक ऐसा हल मौजूद है जो सारे टेस्ट पास कर देता है। वह हल धीमा है और पढ़ने में कठिन है। आपको उसे बेहतर बनाना है, बिना टेस्ट तोड़े।

जब रिकॉर्ड किसी मान्य ट्री का रूप नहीं देते, तब `buildTree` `Nothing` लौटाता है।

## रिप्रेजेंटेशन बदलना

टेस्ट `Tree` के कंस्ट्रक्टर सीधे कभी इस्तेमाल नहीं करते। इसके बजाय वे अपेक्षित ट्री इस फंक्शन से बनाते हैं:

```haskell
node :: Int -> [Tree] -> Tree
```

यहाँ `node i children` से वह नोड बनता है जिसका id `i` है और जिसके चिल्ड्रन वही हैं जो दिए गए हैं। चिल्ड्रन id के बढ़ते क्रम में रहते हैं।

इसका मतलब है कि `Tree` को किस तरह रिप्रेजेंट किया जाता है, आप उसे अपनी इच्छा से बदल सकते हैं। जैसे:

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

बस शर्त यह है कि `Tree` में `Eq` और `Show` के इंस्टेंस अब भी हों और `node` का अर्थ वही रहे। अगर आप `containers` जैसी कोई लाइब्रेरी इस्तेमाल करते हैं, तो उसे `package.yaml` के `dependencies` में जोड़ना न भूलिए।
