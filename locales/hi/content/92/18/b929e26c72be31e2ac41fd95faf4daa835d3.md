# निर्देश

आप फिर से उस ORM (Object Relationship Mapping) सिस्टम पर काम कर रहे हैं, जिससे [exercise:csharp/object-relational-mapping]() में परिचय कराया गया था।

हमारे ORM के उपयोग के विश्लेषण से पता चलता है कि 95% ट्रांज़ैक्शन किसी एक ही मेथड से चलाए जाते हैं। इसलिए यह तय किया गया कि ट्रांज़ैक्शन खोलने, लिखने और कमिट करने वाला एक ही ORM मेथड होना ज़्यादा उपयुक्त रहेगा।

डेटाबेस में ये इंस्टेंस मेथड हैं:

- `Database.BeginTransaction()` डेटाबेस पर एक ट्रांज़ैक्शन शुरू करता है।
- `Database.Write(string data)` ट्रांज़ैक्शन के अंदर डेटाबेस में डेटा लिखता है। अगर इसे खराब डेटा मिलता है, तो एक एक्सेप्शन फेंका जाएगा। अगर `BeginTransaction()` कॉल किए बिना इस मेथड को कॉल करने की कोशिश की जाए, तो भी एक एक्सेप्शन फेंका जाएगा। सफल होने पर डेटाबेस की आंतरिक स्थिति `DataWritten` हो जाएगी।
- `Database.EndTransaction()` ट्रांज़ैक्शन को डेटाबेस में कमिट करता है। अगर यह ट्रांज़ैक्शन बंद नहीं कर पाता, या `Database.BeginTransaction()` कॉल नहीं किया गया था, तो यह एक एक्सेप्शन फेंक सकता है।
- अगर ट्रांज़ैक्शन के दौरान कोई एक्सेप्शन फेंका जाता है, तो `Database.Dispose()` को कॉल करने से डेटाबेस साफ हो जाता है। इससे डेटाबेस की स्थिति `Closed` हो जाती है।

## 1. डेटाबेस में लिखिए

`Orm.Write()` मेथड बनाइए, जो डेटाबेस ट्रांज़ैक्शन शुरू करे, उसमें पास किया गया डेटा लिखे और ट्रांज़ैक्शन कमिट करे। `InvalidOperationException` सहित सभी एक्सेप्शन को बिना लॉग किए और बिना किसी और हस्तक्षेप के कॉलर तक जाने देना चाहिए।

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. डेटाबेस में लिखिए और कॉलर को यह बताइए कि लिखना सफल रहा या नहीं

`Orm.Write()` आए कुछ महीने हो गए हैं और टीम में मतभेद है। कई डेवलपर चाहते हैं कि एक्सेप्शन फेंके जाने पर _ORM_ खुद एरर संभाले और कॉलर को बस सफलता का संकेत लौटा दे।

कृपया `Orm.WriteSafely()` मेथड बनाइए, जो डेटाबेस ट्रांज़ैक्शन शुरू करे, पास किया गया डेटा लिखे और ट्रांज़ैक्शन कमिट करे (जैसा ऊपर बताया गया है)। अगर _लिखना_ सफल रहा हो, तो इसे `true` लौटाना चाहिए, वरना `false`। एक्सेप्शन को लॉग करने की कोशिश न कीजिए।

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
