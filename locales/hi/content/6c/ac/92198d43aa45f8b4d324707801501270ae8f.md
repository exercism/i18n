# निर्देश

इस अभ्यास में आप फैक्ट्री के कर्मचारियों के लिए नाम बैज छापने का कोड लिखेंगे।

## 1. एक कर्मचारी का बैज छापिए

कर्मचारियों के पास आईडी, नाम और विभाग का नाम होता है। कर्मचारी के बैज लेबल इस तरह बनाए जाते हैं: `"[id] - name - DEPARTMENT"`। कर्मचारी का बैज लेबल लौटाने के लिए (_static_) `Badge.Print()` मेथड को लागू कीजिए:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

ध्यान दीजिए कि लेबल पर विभाग का नाम बड़े अक्षरों में होना चाहिए।

## 2. नए कर्मचारी का बैज छापिए

कंप्यूटर सिस्टम की एक अजीब बात के कारण, नए कर्मचारियों के पास फैक्ट्री में काम शुरू करते समय कभी-कभी अभी आईडी नहीं होती। चूँकि बैज ज़रूरी होते हैं, उन्हें आईडी प्रीफिक्स के बिना एक अस्थायी बैज मिलेगा। अभी आईडी न रखने वाले नए कर्मचारियों को संभालने के लिए (_static_) `Badge.Print()` मेथड को बदलिए:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. मालिक का बैज छापिए

फैक्ट्री के मालिक को भी हर समय बैज पहनना पड़ता है। लेकिन मालिक का कोई विभाग नहीं होता। ऐसी स्थिति में लेबल पर विभाग के नाम की जगह `"OWNER"` छपना चाहिए। मालिक का लेबल छापने के लिए (_static_) `Badge.Print()` मेथड को बदलिए:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

ध्यान दीजिए कि मालिक भी नया कर्मचारी हो सकता है:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
