# रेंज

[रेंज][range] दो वैल्यू के बीच के अंतराल को दर्शाती है।
रेंज का इस्तेमाल सबसे आम तौर पर `Integer` और `String` टाइप के साथ होता है।
रेंज से कई तरह के काम किए जा सकते हैं, जैसे झटपट कोई संग्रह बनाना, स्ट्रिंग को काटना, यह जाँचना कि कोई वैल्यू रेंज में है या नहीं, और इटरेशन।
रेंज ऑपरेटर `..` या `...` से रेंज बनाई जाती है (क्रमशः अंतिम मान को शामिल करने वाला और उसे बाहर रखने वाला)।

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

दो रेंज ऑपरेटर रखने की वजह यह है कि आप ऐसी रेंज बना सकें जिनमें अंतिम वैल्यू शामिल हो या न हो। यह तब काम आता है, जब आप शून्य से शुरू होने वाले इंडेक्स के साथ काम कर रहे हों।

रेंज को `Range` कंस्ट्रक्टर, यानी `new`, की मदद से भी बनाया जा सकता है।

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Ruby में जब आप रेंज ऑपरेटर `..` या `...` से कोई रेंज बनाते हैं और उस रेंज पर कोई मेथड कॉल करना चाहते हैं, तो रेंज को ब्रैकेट में लपेटना ज़रूरी है।
ऐसा न करने पर वह मेथड रेंज ऑपरेटर के दूसरे आर्गुमेंट पर कॉल हो जाता है।

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## सबस्ट्रिंग निकालना

किसी स्ट्रिंग का कोई हिस्सा निकालना हो, तो आप रेंज ऑपरेटर की मदद से सबस्ट्रिंग निकाल सकते हैं। इसके लिए सबस्ट्रिंग के शुरुआती और अंतिम इंडेक्स से एक रेंज बनाइए।

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

स्ट्रिंग के अंत से सबस्ट्रिंग निकालने के लिए आप ऋणात्मक इंडेक्स का भी इस्तेमाल कर सकते हैं।

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## रेंज के मेथड

रेंज के साथ काम करने के लिए उनमें कई मेथड होते हैं। जैसे, इन मेथड की मदद से आप रेंज की सभी वैल्यू का जोड़ निकाल सकते हैं या यह जाँच सकते हैं कि कोई वैल्यू रेंज में शामिल है या नहीं।

| मेथड                  | विवरण                                                             | उदाहरण                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | रेंज की सभी वैल्यू का जोड़ लौटाता है                          | `(1..5).sum # => 15`            |
| [`size`][size]          | रेंज का आकार लौटाता है                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | अगर रेंज में दी गई वैल्यू शामिल है तो `true` लौटाता है, वरना `false` | `(1..5).include?(3) # => true` |

## बिना अंत और बिना शुरू वाली रेंज

एक रेंज अनंत भी हो सकती है और बिना शुरू वाली भी। ऐसी रेंज में शुरुआती या अंतिम वैल्यू `nil` होती है, लेकिन रेंज तय करते समय `nil` लिखने की ज़रूरत नहीं होती।

बिना शुरू और बिना अंत वाली रेंज तब काम आती हैं जब आपको, मान लीजिए, किसी स्ट्रिंग का कुछ हिस्सा शुरू से या अंत तक निकालना हो।

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
अगर रेंज का इस्तेमाल किसी संग्रह पर न किया जाए, तो बिना अंत वाली रेंज एक अनंत क्रम बना सकती है। इसलिए इसे सावधानी से ही इस्तेमाल कीजिए।
~~~~

## स्ट्रिंग रेंज

रेंज में स्ट्रिंग का भी इस्तेमाल किया जा सकता है, और इससे दो स्ट्रिंग के बीच आने वाली सारी स्ट्रिंग का एक अंतराल मिलता है। कुछ खास स्ट्रिंग के साथ इसका व्यवहार थोड़ा अप्रत्याशित हो सकता है, इसलिए इसे सावधानी से इस्तेमाल कीजिए।

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
