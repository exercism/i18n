# निर्देश

आपकी DNA रिसर्च लैब में आप स्टोरेज की जगह बचाने के लिए अपने रिसर्च डेटा को छोटा करने के अलग-अलग तरीके आज़माते रहे हैं। आपके एक साथी सुझाव देते हैं कि DNA डेटा को बाइनरी रूप में बदल दिया जाए:

| न्यूक्लिक अम्ल | कोड   |
| ------------ | ------ |
| स्पेस      | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

आप इस पर सोचते हैं। इससे ज़रूरी डेटा स्टोरेज की लागत संभवतः आधी हो सकती है, हालाँकि इससे इंसानों के लिए डेटा पढ़ना कठिन हो जाएगा। अपनी बचत का आकलन करने के लिए आप एक ऐसा मॉड्यूल लिखने का फैसला करते हैं जो आपके डेटा को एनकोड और डिकोड करे।

## 1. न्यूक्लिक अम्ल को बाइनरी वैल्यू में एनकोड कीजिए

`encode_nucleotide/1` लागू कीजिए। यह न्यूक्लिक अम्ल का कोड पॉइंट लेकर एनकोड किए गए कोड की पूर्णांक वैल्यू लौटाता है।

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. बाइनरी वैल्यू को न्यूक्लिक अम्ल में डिकोड कीजिए

अब `decode_nucleotide/1` लागू कीजिए। यह एनकोड किए गए कोड की पूर्णांक वैल्यू लेकर न्यूक्लिक अम्ल का कोड पॉइंट लौटाता है।

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. DNA चारलिस्ट को एनकोड कीजिए

`encode/1` लागू कीजिए, जो न्यूक्लिक अम्लों और गैपों की चारलिस्ट लेकर एनकोड किए गए डेटा की बिटस्ट्रिंग लौटाए।

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. DNA बिटस्ट्रिंग को डिकोड कीजिए

अंत में `decode/1` लागू कीजिए। यह न्यूक्लिक अम्लों और गैपों की बिटस्ट्रिंग लेकर डिकोड किए गए डेटा को चारलिस्ट के रूप में लौटाता है।

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
