# परिचय

## एनम

C# का `enum` टाइप नामित कॉन्स्टेंट का एक निश्चित सेट दर्शाता है (एक एन्यूमरेशन)। इसका मुख्य उद्देश्य संख्यात्मक कॉन्स्टेंट के साथ काम करने का टाइप-सेफ तरीका देना है, जो उपलब्ध वैल्यू को पहले से तय सेट तक सीमित करता है। एक साधारण एनम इस तरह बनाया जा सकता है:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

अगर स्पष्ट रूप से परिभाषित न किया जाए, तो एनम के सदस्यों को अपने आप बढ़ती हुई पूर्णांक वैल्यू असाइन हो जाती हैं, जिनमें पहली वैल्यू शून्य होती है। वैल्यू को स्पष्ट रूप से असाइन करना भी संभव है:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
