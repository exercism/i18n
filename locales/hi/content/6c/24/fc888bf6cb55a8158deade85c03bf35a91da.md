# परिचय

## स्ट्रक्चर और क्लास

स्ट्रक्चर और क्लास Swift प्रोग्रामिंग के दो मुख्य निर्माण खंड हैं। दोनों ही संबंधित डेटा और फंक्शन को जोड़कर अपने आप में पूरी इकाइयाँ बनाने के तरीके हैं। और जब आप कोई स्ट्रक्चर या क्लास परिभाषित करते हैं, तो आप Swift के अंदर इस्तेमाल होने के लिए एक नया टाइप परिभाषित करते हैं, ठीक उसी तरह जैसे आपने पहले से काम किए टाइप इस्तेमाल किए हैं, जैसे `Int` और `String`.
There are many similarities between structs and classes in Swift.

Swift में स्ट्रक्चर और क्लास के बीच कई समानताएँ हैं। इनमें यह भी शामिल है कि दोनों _प्रॉपर्टी_ में वैल्यू रख सकते हैं और _मेथड_ के ज़रिए काम करने की सुविधा देते हैं।

दोनों ही कुछ अतिरिक्त सुविधाएँ भी देते हैं, जो इस अभ्यास के दायरे से बाहर हैं।

### स्ट्रक्चर और क्लास परिभाषित करना

स्ट्रक्चर और क्लास दोनों लगभग एक ही तरह परिभाषित किए जाते हैं। शुरुआत उचित कीवर्ड से होती है, उसके बाद परिभाषित किए जा रहे टाइप का नाम आता है, और फिर स्ट्रक्चर/क्लास का बॉडी कर्ली ब्रैकेट के बीच लिखा जाता है।

बॉडी में संग्रहीत प्रॉपर्टी हो सकती हैं, जिन्हें सामान्य कॉन्स्टेंट या वेरिएबल की तरह ही परिभाषित किया जाता है और जो उन्हीं की तरह व्यवहार करती हैं।

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### इंस्टेंस

जैसा ऊपर बताया गया, किसी स्ट्रक्चर या क्लास को परिभाषित करना सिर्फ एक नया _टाइप_ परिभाषित करना है। यह सिर्फ इस बात का खाका है कि उस टाइप की वैल्यू कैसी दिखेंगी, लेकिन यह आपके काम करने के लिए उस टाइप की कोई वैल्यू बनाता नहीं है।

उस टाइप का _इंस्टेंस_ बनाने के लिए आपको टाइप का नाम लिखना होता है और उसके बाद ब्रैकेट का एक जोड़ा लगाना होता है।

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

इससे इन टाइप की वैल्यू बनती हैं, और इनमें प्रॉपर्टी परिभाषा में दी गई डिफॉल्ट वैल्यू से भर दी जाती हैं। ध्यान दीजिए कि GameCharacter की `name` प्रॉपर्टी जैसे ऑप्शनल मामलों में, अगर कोई वैल्यू न दी जाए, तो प्रॉपर्टी डिफॉल्ट रूप से nil हो जाएगी, ठीक वैसे ही जैसे सामान्य ऑप्शनल टाइप परिभाषित करने पर, जहाँ कोई वैल्यू तुरंत नहीं दी जाती।

स्ट्रक्चर के मामले में Swift अपने आप एक _मेम्बरवाइज़ इनिशियलाइज़र_ देता है, जिसमें स्ट्रक्चर की प्रॉपर्टी की वैल्यू ब्रैकेट के अंदर दी जा सकती हैं, और ये परिभाषा में दी गई डिफॉल्ट वैल्यू को बदल देती हैं।

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### प्रॉपर्टी एक्सेस करना

स्ट्रक्चर और क्लास की प्रॉपर्टी को _डॉट नोटेशन_ से एक्सेस किया जा सकता है, जिसमें वैल्यू का नाम लिखने के बाद एक डॉट (`.`) और फिर प्रॉपर्टी का नाम आता है। अगर किसी स्ट्रक्चर या क्लास की प्रॉपर्टी की अपनी प्रॉपर्टी हों, तो इस डॉट नोटेशन से इन नेस्टेड प्रॉपर्टी को भी एक्सेस किया जा सकता है।

इस नोटेशन का इस्तेमाल प्रॉपर्टी की वैल्यू पाने के लिए, और जहाँ अनुमति हो वहाँ उसे बदलने के लिए भी किया जा सकता है।

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### मेथड

प्रॉपर्टी की तरह, जो आपके स्ट्रक्चर और क्लास में डेटा रखती हैं, आप _मेथड_ भी परिभाषित कर सकते हैं, जो आपके स्ट्रक्चर या क्लास में फंक्शन रखते हैं।

मेथड उसी तरह परिभाषित किए जाते हैं जैसे एक सामान्य फंक्शन, बस वे स्ट्रक्चर या क्लास के बॉडी के अंदर होते हैं। ध्यान दीजिए कि अगर कोई फंक्शन स्ट्रक्चर में किसी प्रॉपर्टी की वैल्यू बदलता है, तो उससे पहले `mutating` कीवर्ड लिखना ज़रूरी है। इसके अलावा, अगर कोई प्रॉपर्टी किसी मेथड से बदली जा सकती है, तो उस प्रॉपर्टी को `let` की जगह `var` से परिभाषित करना होगा, ठीक सामान्य वेरिएबल की तरह।

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

इन मेथड को प्रॉपर्टी की तरह ही डॉट नोटेशन से कॉल किया जा सकता है।

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

स्ट्रक्चर या क्लास के हर इंस्टेंस में एक अंतर्निहित प्रॉपर्टी होती है जिसका नाम `self` है, जो उस इंस्टेंस को ही दर्शाती है।
`self` का सबसे आम इस्तेमाल इंस्टेंस प्रॉपर्टी और उसी नाम वाले पैरामीटर के बीच फर्क साफ करना है:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift के टाइप एक बड़े अक्षर वाला `Self` कीवर्ड भी देते हैं, जो खुद इंस्टेंस की जगह उस इंस्टेंस के _टाइप_ को दर्शाता है।
