# GitHub के ज़रिए योगदान

Exercism के कोड बेस में योगदान [GitHub][github] के ज़रिए दिया जाता है।

जैसा कि नाम से ही पता चलता है, GitHub अपने वर्ज़न कंट्रोल सिस्टम के तौर पर [git][git] का उपयोग करता है।
अगर आप Git से परिचित नहीं हैं, तो ऑनलाइन सबसे अच्छा संसाधन [Pro Git][pro-git] है।

अगर आप GitHub और योगदान की वर्कफ्लो से परिचित नहीं हैं, तो यहाँ कुछ संसाधन हैं जो आपको शुरुआत करने में मदद कर सकते हैं:

- [GitHub का परिचय - इंटरैक्टिव कोर्स][github-course]
- [GitHub पर पुल रिक्वेस्ट कैसे बनाइए - ट्यूटोरियल][pr-tutorial]
- [GitHub पर एक आसान PR कैसे बनाइए - anthonywritescode का वीडियो][anthonywritescode]

## गाइड

आप यह कैसे सुनिश्चित करें कि आपका योगदान सराहा जाए, इसके बारे में [बेहतरीन पुल रिक्वेस्ट बनाने का तरीका][great-pr] गाइड में और पढ़ सकते हैं।

हमारे पास Exercism के लिए खास कुछ पुल रिक्वेस्ट गाइड भी हैं:

- [बेहतरीन पुल रिक्वेस्ट कैसे बनाइए][how-to-make-a-great-pr]
- [पुल रिक्वेस्ट के लिए योगदानकर्ताओं की गाइड][contributors-pr-guide]
- [पुल रिक्वेस्ट के लिए मेंटेनर की गाइड][maintainers-pr-guide]
- [मेंटेनर रेपो अनुमतियाँ][maintainers-repo-permissions]
