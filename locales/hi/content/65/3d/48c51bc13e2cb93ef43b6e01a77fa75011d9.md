# सीखना

क्या आप Groovy शुरू करना चाहते हैं, या अभ्यास करते हुए और सीखना चाहते हैं?

Groovy को इन तरीकों से आज़माइए:

* [किसी ब्राउज़र में ऑनलाइन इंटरप्रेटर के साथ](https://www.jdoodle.com/execute-groovy-online)
* कमांड लाइन पर `groovyConsole` टाइप करके [Groovy Console](http://groovy-lang.org/groovyconsole.html)
* कमांड लाइन पर `groovysh` टाइप करके [Groovy Shell](http://groovy-lang.org/groovyconsole.html)

Groovy का छोटा-सा परिचय पाने के लिए इन्हें देखिए:

* टिम रोज़ का [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) Java न जानने वाले डेवलपर के लिए भी उतना ही अच्छा है।
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* SmartThings का [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html)
* JDriven के कुछ [ऑनलाइन Groovy Koans](http://www.groovy-koans.org/)

और गहराई में जाने के लिए देखिए:

* [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), Groovy की _असली किताब_
* केन कौसेन की [Making Java Groovy](https://www.manning.com/books/making-java-groovy)
