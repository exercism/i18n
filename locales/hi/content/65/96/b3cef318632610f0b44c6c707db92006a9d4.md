# परिचय

एक `:` परिभाषा खुद को सीधे कॉल कर सकती है। Factor का कंपाइलर बाकी सब की तरह रिकर्सिव वर्ड का स्टैक इफेक्ट भी खुद अनुमान लगा लेता है। सामान्य रिकर्सन के लिए किसी खास घोषणा की ज़रूरत नहीं होती।

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

रिकर्सन के दो हिस्से होते हैं। पहला है *बेस केस*, यानी वह स्थिति जहाँ खाली सीक्वेंस का जोड़ `0` होता है, और दूसरा है *रिकर्सिव स्टेप*, जिसमें एक एलिमेंट अलग किया जाता है, बाकी पर फिर से रिकर्सन होता है, और अंत में परिणामों को मिलाया जाता है।

सीक्वेंस रिकर्सन के लिए सबसे आम साथी हैं `if-empty` और `unclip`। `if-empty ( seq emptyquot nonemptyquot -- )` सीक्वेंस के अनुसार दो कोटेशन में से एक चलाता है। `unclip` पहला एलिमेंट अलग कर देता है, ताकि रिकर्सिव स्टेप को कुछ आसान मिले।
