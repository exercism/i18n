# परिचय

F# में ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग करने की मुख्य इकाई क्लास है।

F# में क्लास अपने फील्ड और मेथड से बनती है। क्लास के फील्ड और मेथड को उसके _सदस्य_ कहा जाता है।

F# में क्लास बनाने के लिए `type` कीवर्ड का इस्तेमाल किया जाता है। मेथड को `member` कीवर्ड से बनाया जाता है और वे हमेशा public होते हैं। फील्ड (private) बनाने के लिए `let` बाइंडिंग का इस्तेमाल किया जा सकता है।

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

क्लास एक टेम्पलेट होती है जिससे ऑब्जेक्ट बनाए जाते हैं। किसी क्लास का इंस्टेंस बनाने के लिए उस क्लास के नाम को फंक्शन की तरह कॉल कीजिए। क्लास के इंस्टेंस को _ऑब्जेक्ट_ भी कहा जाता है।

ऑब्जेक्ट के सदस्यों तक डॉट नोटेशन से पहुँचा जा सकता है।

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
