# परिचय

## एक्सेस बिहेवियर

Elixir में कोड को सामान्य और जेनेरिक इंटरफेस देने के लिए _बिहेवियर_ का उपयोग होता है। साथ ही, जो भी मॉड्यूल किसी बिहेवियर को लागू करता है, वह अपनी अलग इम्प्लीमेंटेशन बना सकता है। ऐसा ही एक आम उदाहरण _एक्सेस बिहेवियर_ है।

_एक्सेस बिहेवियर_ एक सामान्य इंटरफेस देता है, जिससे की पर आधारित डेटा स्ट्रक्चर से डेटा निकाला जा सकता है। इसे मैप और कीवर्ड लिस्ट के लिए लागू किया गया है। अब चलिए देखते हैं कि मैप के साथ इसका उपयोग कैसे होता है, ताकि इसे समझना आसान हो जाए। _एक्सेस बिहेवियर_ कहता है कि जब आपके पास कोई मैप हो, तो आप उसके बाद _चौकोर ब्रैकेट_ लगा सकते हैं और फिर उस की का उपयोग करके उस की से जुड़ी वैल्यू निकाल सकते हैं।

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

अगर डेटा स्ट्रक्चर में वह की मौजूद नहीं है, तो आपको `nil` मिलता है। यह अनचाहे व्यवहार का कारण बन सकता है, क्योंकि इसमें कोई एरर नहीं आती। ध्यान दीजिए कि `nil` खुद भी एक्सेस बिहेवियर लागू करता है और किसी भी की के लिए हमेशा `nil` लौटाता है।
