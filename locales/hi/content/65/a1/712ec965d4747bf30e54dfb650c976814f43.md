# रीडओनली क्लास और प्रॉपर्टी

रीडओनली क्लास और प्रॉपर्टी क्लास को ऐसी public प्रॉपर्टी तय करने देती हैं जिन्हें आसानी से पढ़ा जा सके, लेकिन जिन्हें बदला न जा सके।

किसी प्रॉपर्टी को रीडओनली घोषित करने के लिए उसके टाइप से पहले `readonly` जोड़ना ज़रूरी है। प्रॉपर्टी में एक बार वैल्यू असाइन करने की अनुमति होती है, लेकिन उसे दोबारा असाइन करने या वैल्यू बदलने की कोशिश करने पर एरर मिलती है।

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

रीडओनली क्लास इसी व्यवहार पर आधारित होती हैं। किसी क्लास को `readonly` घोषित करने पर यह हर प्रॉपर्टी पर रीडओनली घोषणा लागू कर देती है। इसके अलावा यह डायनामिक प्रॉपर्टी जोड़ने से रोकती है।

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
