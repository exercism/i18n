# परिचय

एक टाइप डेफिनिशन एक नया नाम वाला टाइप बनाता है, जो हर दूसरे टाइप से अलग होता है, चाहे उनका अंडरलाइंग टाइप एक जैसा ही क्यों न हो।

## टाइप को परिभाषित करना

टाइप डेफिनिशन `type` कीवर्ड से शुरू होता है। उसके बाद नए टाइप का नाम और उसका अंडरलाइंग टाइप लिखा जाता है:

```go
type File []bool
```

यहाँ `File` शतरंज के बोर्ड के एक खड़े स्तंभ को दिखाता है, जिसे आमतौर पर A से H तक नाम दिया जाता है।
इस स्तंभ के हर खाने को एक बूलियन वैल्यू से दिखाया जाता है, जो बताती है कि वह खाना भरा हुआ है या नहीं।
अब जब `File` परिभाषित हो गया है, तो हम इसे दूसरे डेफिनिशन के अंदर इस्तेमाल कर सकते हैं:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` हर फाइल के नाम को उसकी `File` वैल्यू से जोड़ता है।
हर `File` बूलियन की एक स्लाइस है, जो शतरंज की एक फाइल के खानों को दिखाती है।
इन टाइप डेफिनिशन के बिना `board` एक `map[string][]bool` होता, जिससे यह समझना मुश्किल हो जाता कि हम क्या दिखा रहे हैं।

## परिभाषित टाइप अलग होते हैं

हालाँकि `Score` और `int` दोनों पूर्णांक वैल्यू रखते हैं, फिर भी एक से दूसरे में बदलने के लिए स्पष्ट कन्वर्ज़न लिखना पड़ता है:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` एक अनटाइप्ड कॉन्स्टेंट है, इसलिए इसे सीधे एक `Score` वेरिएबल में असाइन किया जा सकता है।

परिभाषित टाइप में मेथड भी हो सकते हैं, जिनकी चर्चा मेथड कॉन्सेप्ट में की गई है।

## स्ट्रक्ट टाइप

स्ट्रक्ट डेफिनिशन में भी वही `type` कीवर्ड इस्तेमाल होता है:

```go
type Player struct {
    Name  string
    Score Score
}
```

स्ट्रक्ट टाइप की चर्चा स्ट्रक्ट कॉन्सेप्ट में की गई है।

## टाइप एलियस

टाइप एलियस किसी मौजूदा टाइप के लिए एक और नाम बनाता है, नया टाइप नहीं।
चूँकि एलियस और उसका मूल टाइप एक ही होते हैं, इसलिए उनकी वैल्यू को एक-दूसरे की जगह इस्तेमाल किया जा सकता है।
एलियस को `type` कीवर्ड, एलियस का नाम, बराबर का चिह्न (`=`) और मौजूदा टाइप लिखकर घोषित किया जाता है।

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
