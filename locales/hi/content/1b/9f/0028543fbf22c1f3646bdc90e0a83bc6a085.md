# परिचय

Elixir में रेगुलर एक्सप्रेशन **PCRE** स्पेसिफिकेशन (**P**erl **C**ompatible **R**egular **E**xpressions) का पालन करते हैं, ठीक वैसे ही जैसे Java, JavaScript या Ruby जैसी दूसरी लोकप्रिय भाषाएँ करती हैं।

`Regex` मॉड्यूल में रेगुलर एक्सप्रेशन के साथ काम करने के लिए फंक्शन हैं। `String` मॉड्यूल के कुछ फंक्शन भी आर्गुमेंट के तौर पर रेगुलर एक्सप्रेशन लेते हैं।

~~~~exercism/note
इस अभ्यास में यह माना गया है कि आप रेगुलर एक्सप्रेशन का सिंटैक्स पहले से जानते हैं, जिसमें अक्षर क्लास, क्वांटिफायर, ग्रुप और कैप्चर शामिल हैं।

अगर आपको अपने रेगुलर एक्सप्रेशन के ज्ञान को ताज़ा करना है, तो इनमें से कोई एक स्रोत देखिए: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

## सिगिल

रेगुलर एक्सप्रेशन बनाने का सबसे आम तरीका `~r` सिगिल का इस्तेमाल करना है।

```elixir
~r/test/
```

ध्यान दीजिए कि Elixir के सारे सिगिल [अलग-अलग तरह के डिलिमिटर][sigils] इस्तेमाल कर सकते हैं, सिर्फ `/` ही नहीं।

## मिलान

`=~/2` ऑपरेटर से ऐसा रेगुलर एक्सप्रेशन मिलान किया जा सकता है जो `boolean` परिणाम लौटाता है। इसके अलावा `Regex` मॉड्यूल के साथ-साथ `String` मॉड्यूल में भी `match?/2` फंक्शन हैं।

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## कैप्चर करना

अगर सिर्फ बूलियन जाँच से काम नहीं चलता, तो `Regex.run/3` फंक्शन इस्तेमाल कीजिए, जो सारे कैप्चर का एक ऐरे लौटाता है (और अगर कोई मिलान नहीं हुआ, तो `nil`)। लौटाए गए ऐरे का पहला एलिमेंट हमेशा पूरे रेगुलर एक्सप्रेशन का मिलान होता है, और उसके बाद वाले एलिमेंट मिलाए गए ग्रुप होते हैं।

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## मॉडिफायर

रेगुलर एक्सप्रेशन का व्यवहार खास फ्लैग जोड़कर बदला जा सकता है। सिगिल से रेगुलर एक्सप्रेशन बनाते समय मॉडिफायर दूसरे डिलिमिटर के बाद लगाइए।

आम मॉडिफायर ये हैं:
- `i` - मिलान करते समय बड़े और छोटे अक्षरों में फर्क नहीं करता।
- `u` - `\p` जैसे यूनिकोड के खास पैटर्न चालू करता है और `\w`, `\s` जैसी अक्षर क्लासों से यूनिकोड अक्षरों का मिलान भी कराता है।

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
