# क्लास

क्लास, [ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग][object-oriented-programming] का एक केंद्रीय कॉन्सेप्ट है।
[Crystal में सब कुछ एक ऑब्जेक्ट होता है][everything-is-an-object], हर ऑब्जेक्ट का एक टाइप होता है, और उस पर कुछ मेथड कॉल किए जा सकते हैं।
क्लासें ऑब्जेक्ट बनाने के खाके होती हैं। ये स्थिति के लिए शुरुआती वैल्यू देती हैं, जैसे वेरिएबल, और व्यवहार के लिए कार्यान्वयन देती हैं, जैसे मेथड।
ऑब्जेक्ट क्लास के इंस्टेंस होते हैं, जो सारे इंस्टेंस वेरिएबल और स्थितियाँ अपने अंदर रखते हैं।

## क्लास की परिभाषा

क्लास को `class` कीवर्ड से परिभाषित किया जाता है। कीवर्ड के बाद क्लास का नाम आता है, जो `UpperCamelCase` में लिखा जाता है।

```crystal
class Account
end
```

## इंस्टेंस बनाना

किसी क्लास का [इंस्टेंस बनाने][new-initialize] के लिए उस क्लास के नाम पर `new` मेथड कॉल कीजिए।

```crystal
class Account
end

account = Account.new
```

ऊपर के उदाहरण में वेरिएबल `account`, क्लास `Account` का एक इंस्टेंस है।

इंस्टेंस बनाते समय, `initialize` नाम का एक खास मेथड कंस्ट्रक्टर का काम करता है।
इसे तब कॉल किया जाता है जब कोई इंस्टेंस बनाया जाता है।
कंस्ट्रक्टर आपको इंस्टेंस की शुरुआती स्थिति तय करने देता है।
`initialize` मेथड आर्गुमेंट ले सकता है, जो इंस्टेंस बनाते समय पास किए जाते हैं।

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize` मेथड खुद से कोई वैल्यू नहीं लौटा सकता; इसके बजाय `new` नए बने इंस्टेंस को लौटाता है।

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## इंस्टेंस मेथड

इंस्टेंस मेथड ऐसा मेथड होता है जो क्लास के किसी इंस्टेंस के लिए उपलब्ध होता है, और उस इंस्टेंस पर कॉल किया जा सकता है।
इंस्टेंस मेथड को `def` कीवर्ड से परिभाषित किया जाता है, जिसके बाद मेथड का नाम आता है।
इन्हें क्लास की परिभाषा के अंदर परिभाषित किया जाता है।

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## इंस्टेंस वेरिएबल

[इंस्टेंस वेरिएबल][instance-variable] ऐसे वेरिएबल होते हैं जो इंस्टेंस के सभी मेथड में उपलब्ध रहते हैं।
किसी इंस्टेंस वेरिएबल तक पहुँचने के लिए आपको एक इंस्टेंस मेथड बनाना होता है।
इनकी शुरुआती वैल्यू `initialize` मेथड में तय की जा सकती है।
इन्हें `@` प्रीफिक्स के साथ परिभाषित किया जाता है।

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

इंस्टेंस वेरिएबल क्लास की परिभाषा के अंदर भी परिभाषित किए जा सकते हैं।

```crystal
class Account
  @age = 0
end
```

### शुरुआती वैल्यू के साथ इंस्टेंस वेरिएबल

इंस्टेंस वेरिएबल को `initialize` मेथड को पास किए गए आर्गुमेंट से शुरुआती वैल्यू दी जा सकती है।
चूँकि Crystal शुरुआती वैल्यू देते समय इस्तेमाल किए गए आर्गुमेंट के टाइप का अनुमान नहीं लगा सकता, इसलिए टाइप बताना ज़रूरी होता है।
अगर आप इसके बारे में और पढ़ना चाहते हैं, तो [टाइप इन्फरेंस][type-inference] पढ़ सकते हैं।
वेरिएबल का टाइप बताने के लिए आप `:` चिह्न का इस्तेमाल कर सकते हैं, और उसके बाद टाइप लिख सकते हैं।
उदाहरण के लिए, अगर आप `Int32` टाइप का `balance` नाम का इंस्टेंस वेरिएबल बनाना चाहते हैं, तो आप ऐसा लिख सकते हैं: `@balance : Int32`।
या अगर आप `Bool` टाइप का `raining` नाम का इंस्टेंस वेरिएबल बनाना चाहते हैं, तो आप ऐसा लिख सकते हैं: `@raining : Bool`।

इसे लागू करने के कई तरीके हैं। एक तरीका यह है कि `initialize` मेथड में आर्गुमेंट को टाइप के साथ घोषित किया जाए, और फिर इंस्टेंस वेरिएबल को उस आर्गुमेंट के बराबर असाइन किया जाए, जैसे इस उदाहरण में:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

दूसरा तरीका यह है कि इंस्टेंस वेरिएबल का टाइप क्लास की परिभाषा में `@<variable> : <Type>` रूप में घोषित किया जाए, जैसे इस उदाहरण में:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### इंस्टेंस वेरिएबल को शुरुआती वैल्यू देने का छोटा तरीका

`initialize` मेथड के आर्गुमेंट में इंस्टेंस वेरिएबल को शुरुआती वैल्यू देने का एक छोटा तरीका है, जिसमें वही सिंटैक्स `@<variable> : <Type>` इस्तेमाल होता है।
यह इंस्टेंस वेरिएबल को आर्गुमेंट के बराबर असाइन करने और इंस्टेंस वेरिएबल का टाइप घोषित करने, दोनों को एक साथ कर देता है।

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## इंस्टेंस वेरिएबल बदलना

मेथड इंस्टेंस वेरिएबल को बदल सकते हैं।
इन मेथड को क्लास के इंस्टेंस पर कॉल किया जा सकता है।
जब कोई मेथड किसी इंस्टेंस वेरिएबल को बदलता है, तो वह बदलाव सिर्फ उसी इंस्टेंस में दिखता है जिस पर आपने उस मेथड को कॉल किया था।

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## क्लास मेथड

[क्लास मेथड][class-methods] ऐसे मेथड होते हैं जो किसी क्लास के लिए परिभाषित होते हैं, उसके इंस्टेंस के लिए नहीं।
ये ऐसे मेथड बनाने का तरीका देते हैं जो इंस्टेंस की स्थिति पर निर्भर नहीं होते।
इन्हें `def` कीवर्ड से परिभाषित किया जाता है, जिसके बाद `self.<method name>` आता है।
`self` उस नेमस्पेस का संदर्भ है जहाँ से उसे कॉल किया जा रहा है।
यहाँ यह क्लास `Account` की ओर इशारा करता है।
यह वैसा ही होगा जैसे आपने `Account.` लिखा हो, लेकिन `self.` लिखना बेहतर तरीका माना जाता है।

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
