# टेस्ट

अपना मौजूदा ऑपरेटिंग सिस्टम चुनिए:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# टेस्ट चलाना

## Windows

1. Command Prompt खोलिए।

2. पहला अभ्यास डाउनलोड कीजिए:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. अभ्यास फोल्डर में जाइए:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. टेस्ट चलाइए:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(अगर पहली बार चलाने पर टेस्ट फेल हों तो चिंता न कीजिए, हर अभ्यास की शुरुआत ऐसे ही होती है।)*

5. अभ्यास हल कीजिए। 
    `instructions.md` को पढ़िए और देखिए कि अभ्यास कैसे हल करना है ([GitHub पर देखिए](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


शुभकामनाएँ, मज़े कीजिए और COBOL ट्रैक में आपका स्वागत है!

----

## macOS

1. Terminal विंडो खोलिए।

2. पहला अभ्यास डाउनलोड कीजिए:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. अभ्यास फोल्डर में जाइए:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. टेस्ट चलाइए:

    ```
     $ bash test.sh
    ```
    *(अगर पहली बार चलाने पर टेस्ट फेल हों तो चिंता न कीजिए, हर अभ्यास की शुरुआत ऐसे ही होती है।)*

    संकेत: अगर आपको ऐसा संदेश मिले कि `basename` मौजूद नहीं है, तो आप coreutils इंस्टॉल करने के लिए [brew](https://brew.sh/) का उपयोग कर सकते हैं। (`brew install coreutils`)

5. अभ्यास हल कीजिए। 

    `instructions.md` को पढ़िए और देखिए कि अभ्यास कैसे हल करना है ([GitHub पर देखिए](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


शुभकामनाएँ, मज़े कीजिए और COBOL ट्रैक में आपका स्वागत है!
