# परिचय

कॉन्स्टेंट ऐसी वैल्यू होते हैं जो कंपाइल समय पर तय किए जाते हैं और इन्हें दोबारा असाइन नहीं किया जा सकता। एक अकेला कॉन्स्टेंट घोषित करने के लिए `const` कीवर्ड का उपयोग कीजिए:

```go
const greeting = "hello"
```

एक ही ब्लॉक में कई कॉन्स्टेंट घोषित किए जा सकते हैं। ब्लॉक के अंदर, जिस कॉन्स्टेंट की वैल्यू स्पष्ट रूप से नहीं दी गई हो, वह पिछले एक्सप्रेशन को ही दोहरा देता है:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

कॉन्स्टेंट आम तौर पर पैकेज लेवल पर घोषित किए जाते हैं, हालाँकि इन्हें किसी फंक्शन के अंदर भी घोषित किया जा सकता है।

## टाइप्ड और अनटाइप्ड कॉन्स्टेंट

किसी कॉन्स्टेंट को बिना टाइप बताए घोषित करने पर वह अनटाइप्ड हो जाता है। अनटाइप्ड कॉन्स्टेंट का कोई तय टाइप नहीं होता; उसकी वैल्यू ही तय करती है कि वह किन टाइप के साथ काम कर सकता है। जब तक अंदर की वैल्यू मेल खाती है, कंपाइलर हर उपयोग पर उसे ज़रूरी टाइप में बदल देता है:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

टाइप्ड कॉन्स्टेंट घोषित करते समय ही टाइप तय कर देता है:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## कॉन्स्टेंट क्या-क्या हो सकता है

कॉन्स्टेंट में सिर्फ बूलियन, संख्याएँ, स्ट्रिंग और रून ही रखे जा सकते हैं। चूँकि वैल्यू कंपाइल समय पर ही तय हो जाती हैं, इसलिए किसी फंक्शन कॉल के परिणाम को कॉन्स्टेंट के लिए इस्तेमाल नहीं किया जा सकता।

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

कॉन्स्टेंट के एक ब्लॉक में, `iota` ब्लॉक के अंदर कॉन्स्टेंट की स्थिति को दर्शाता है:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

पहले के बाद आने वाला हर कॉन्स्टेंट वही एक्सप्रेशन ले लेता है, और `iota` हर बार एक-एक बढ़ता जाता है।

`iota` एक्सप्रेशन के अंदर भी काम करता है।

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```

Go में कॉन्स्टेंट को गहराई से समझने के लिए [The Go Blog][const-blog] और [Effective Go][effective-go] देखिए।
