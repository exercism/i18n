# Break और Continue

जब आप किसी लूप या इटरेशन वाली कंट्रोल स्ट्रक्चर का उपयोग करते हैं, तो `break` और `continue` कीवर्ड किसी प्रोग्राम का फ्लो नियंत्रित करने में मदद करते हैं।
`break` कीवर्ड लूप के कॉन्टेक्स्ट से बाहर निकलकर बाहरी स्कोप में चला जाता है, और इस तरह लूप समाप्त हो जाता है।
`continue` कीवर्ड मौजूदा इटरेशन का बाकी हिस्सा छोड़ देता है और लूप को अगले इटरेशन की शुरुआत से दोबारा शुरू कर देता है।
ऐसा होता कम है, लेकिन कीवर्ड के साथ एक संख्या भी दी जा सकती है, जो तय करती है कि कितने कॉन्टेक्स्ट से बाहर निकलना है या कितनों को छोड़कर अगले इटरेशन पर जाना है।

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

पिछले उदाहरण में `continue` पाँच (5) बार चलता है, लेकिन छठे (6) इटरेशन पर `break` चलता है, जिससे कोड लूप से बाहर निकल जाता है।
