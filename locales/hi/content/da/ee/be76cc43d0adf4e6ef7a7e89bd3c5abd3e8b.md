# निर्देश

नेटबॉल का सीज़न खत्म हो गया है और फाइनल कौन खेलेगा, यह लैडर तय करता है।

स्टब आपको एक `TEAM` क्लास देता है। उसके नीचे `FINALS_LADDER` लिखिए।

## 1. कौन किसके ऊपर है?

`higher` दो टीमें लेता है और बताता है कि पहली टीम दूसरी के ऊपर होनी चाहिए या नहीं। जिसके अंक अधिक हैं, वह पहले आती है। जिन टीमों के अंक बराबर हैं, उनका फैसला गोल अंतर से होता है; जिसका गोल अंतर अधिक है, वह पहले आती है।

```sather
FINALS_LADDER::higher(#TEAM("Vixens", 24, 40), #TEAM("Magpies", 20, 90))
-- => true
```

## 2. लैडर

`ladder` टीमों को किसी भी क्रम में लेता है और उन्हें रैंक करके लौटाता है। जो ऐरे दिया गया है, उसे जैसा था वैसा ही छोड़ना है।

```sather
FINALS_LADDER::ladder(teams)
-- => the same teams, best first
```

## 3. लैडर पढ़कर सुनाइए

`names` टीमों का एक ऐरे लेता है और उनके नाम `", "` से जोड़कर लौटाता है।

```sather
FINALS_LADDER::names(FINALS_LADDER::ladder(teams))
-- => "Vixens, Magpies, Swifts"
```

## 4. विजेता

`premiers` टीमों को किसी भी क्रम में लेता है और सबसे ऊपर वाली टीम का नाम लौटाता है। अगर एक भी टीम न हो, तो जवाब `""` होता है।

```sather
FINALS_LADDER::premiers(teams)
-- => "Vixens"
```

## 5. बिल्कुल अलग क्रम

`shortest_first` स्ट्रिंग्स का एक ऐरे लेता है और उन्हें लंबाई के क्रम में लौटाता है, सबसे छोटी स्ट्रिंग पहले। जिन स्ट्रिंग्स की लंबाई बराबर है, वे वर्णक्रम के अनुसार आती हैं।

```sather
FINALS_LADDER::shortest_first(|"Magpies", "Vixens", "Swifts"|)
-- => "Swifts", "Vixens", "Magpies"
```

बराबरी तोड़ने वाला नियम यहाँ कोई सजावट नहीं है। यह सॉर्ट स्थिर नहीं है, इसलिए इसके बिना एक ही लंबाई के दो नाम किसी भी क्रम में आ सकते हैं।

यह काम 2 वाली ही सॉर्टिंग रूटीन है, बस इसे अलग नियम दिया गया है। यही इस अभ्यास का उद्देश्य है।
