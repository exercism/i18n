# परिचय

Factor का `<iota>` पूर्णांकों `0, 1, …, n-1` का एक *वर्चुअल* क्रम बनाता है। इसे `map` के साथ चलाने पर एक टैब्युलेटेड क्रम मिलता है, जिसमें हर एलिमेंट अपनी स्थिति का फंक्शन होता है:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

दो चीज़ों की मदद से आप पूर्णांक कोड के क्रम को स्ट्रिंग में बदल सकते हैं:

| शब्द      | भूमिका                                                  |
|-----------|---------------------------------------------------------|
| `CHAR:`   | पार्स के समय बनने वाला लिटरल, जो किसी अक्षर का कोड पॉइंट पुश करता है |
| `>string` | कोड पॉइंटों के क्रम को स्ट्रिंग में बदलता है            |

मिलकर ये वह मानक तरीका बनाते हैं जिससे स्थिति के अनुसार क्रम में रखे अक्षरों की एक पंक्ति बनाई जाती है:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

कोटेशन के अंदर `if` (या `?`) से अक्षर चुनने पर हर स्थिति का फैसला उसी इंडेक्स के पास रहता है, जिस पर वह निर्भर करता है।
