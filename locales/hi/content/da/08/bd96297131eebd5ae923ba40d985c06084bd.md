# संसाधन

## सीखने के लिए सुझाए गए संसाधन

Clojurescript, Clojure की सोच-समझकर बनाई गई बोली है। Clojurescript में आपका Clojure का ज्ञान (भाषा का ज्ञान, न कि होस्ट प्लेटफ़ॉर्म JVM का) काम आता है।

- [ClojureScript API](http://cljs.github.io/api/) आधिकारिक API दस्तावेज़।
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet), एक आधिकारिक चीट-शीट।
- [Learn Clojurescript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes) एक GitHub रिपॉज़िटरी, जो आपको इस भाषा का सिंटैक्स सिखाती है।
