# इंस्टॉलेशन

आपको एक माउंट किए हुए Oracle DB तक पहुँच की ज़रूरत होगी। अगर आपके पास पहले से इंस्टॉल किया हुआ कोई Oracle DB नहीं है, तो यहाँ कुछ विकल्प दिए गए हैं:
* https://apex.oracle.com पर एक मुफ्त वर्कस्पेस ले लीजिए।
* Oracle से VirtualBox डाउनलोड कीजिए और उसमें उपलब्ध मुफ्त इमेज में से कोई एक चलाइए। इस समय शुरुआत करने के लिए सबसे आसान _Database App Development VM_ हो सकती है। यह इमेज काफी बड़ी है...
* Oracle DB का ही कोई संस्करण डाउनलोड करके इंस्टॉल कीजिए। डेवलपर लाइसेंस मुफ्त होते हैं।
