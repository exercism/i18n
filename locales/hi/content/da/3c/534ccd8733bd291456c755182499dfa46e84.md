# परिचय

Cairo में फंक्शन की मदद से आप कोड को एक ऐसी इकाई में बाँध सकते हैं जिसका दोबारा इस्तेमाल किया जा सके। इससे आपके प्रोग्राम और मॉड्यूलर बन जाते हैं और समझने में आसान हो जाते हैं।
Cairo में फंक्शन कई चीज़ों से मिलकर बनता है: `fn` कीवर्ड, उसके बाद फंक्शन का नाम, ब्रैकेट में दी गई पैरामीटर की सूची, और एक कोड ब्लॉक जो बताता है कि फंक्शन क्या करता है।

## फंक्शन के पैरामीटर

Cairo में हर फंक्शन पैरामीटर का टाइप स्पष्ट रूप से लिखना ज़रूरी है।
कुछ भाषाओं के उलट, Cairo टाइप का अंदाज़ा नहीं लगाता, और यहाँ पैरामीटर के लिए कोई पहले से तय वैल्यू नहीं होती। इसलिए हर पैरामीटर देना ज़रूरी है।

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## पैरामीटर और आर्गुमेंट में अंतर

`parameters` और `arguments` के बीच अंतर समझना ज़रूरी है:

- **पैरामीटर** वे वेरिएबल के नाम होते हैं जो फंक्शन बनाते समय इस्तेमाल किए जाते हैं, जैसे `print_greeting_name` फंक्शन में `greeting` और `name`।
- **आर्गुमेंट** वे वास्तविक वैल्यू होती हैं जो फंक्शन को कॉल करते समय उसे दी जाती हैं।

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## स्टेटमेंट और एक्सप्रेशन

फंक्शन के अंदर का कोड कई स्टेटमेंट से मिलकर बनता है, और अंत में चाहें तो एक एक्सप्रेशन भी आ सकता है।

- स्टेटमेंट ऐसे निर्देश होते हैं जो कोई काम करते हैं और कोई वैल्यू नहीं लौटाते।
- एक्सप्रेशन का मूल्यांकन होने पर एक वैल्यू मिलती है।

`let` कीवर्ड से एक वेरिएबल बनाना और उसमें कोई वैल्यू असाइन करना एक स्टेटमेंट है।

```rust
let y = 6;
```

लेकिन ऊपर के स्टेटमेंट में `6` एक एक्सप्रेशन है, जिसका मूल्यांकन करने पर वैल्यू `6` मिलती है।

किसी फंक्शन को कॉल करना भी एक एक्सप्रेशन है, क्योंकि उससे हमेशा एक वैल्यू मिलती है: फंक्शन की स्पष्ट रिटर्न वैल्यू, अगर दी गई हो, वरना 'unit' टाइप `()`।

## रिटर्न वैल्यू

Cairo के फंक्शन उस कोड को वैल्यू लौटा सकते हैं जो उन्हें कॉल करता है।
रिटर्न वैल्यू पैरामीटर के बाद लिखी जाती हैं, और उन्हें एक तीर `->` से अलग किया जाता है।
Cairo में फंक्शन की रिटर्न वैल्यू और फंक्शन के अंदर के कोड ब्लॉक के अंतिम एक्सप्रेशन की वैल्यू, दोनों एक ही चीज़ हैं।
`return` कीवर्ड का उपयोग करके और कोई वैल्यू देकर आप फंक्शन से बीच में ही लौट सकते हैं।

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## फंक्शन को कॉल करना

Cairo में किसी फंक्शन को कॉल करने के लिए आप बस फंक्शन का नाम लिखते हैं और उसके बाद ब्रैकेट में आर्गुमेंट देते हैं।

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
