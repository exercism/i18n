# निर्देश

बुनियादी Take-A-Number मशीन खूब बिक रही थी, लेकिन कुछ उपयोगकर्ता शिकायत कर रहे थे कि बाज़ार में उपलब्ध दूसरे मॉडलों के मुकाबले इस मशीन में एडवांस्ड फीचर कम हैं।

निर्माता ने उपयोगकर्ताओं की बात सुनी और ज़्यादा फीचर वाला एक डीलक्स मॉडल निकालने का फैसला किया। इस मशीन का सॉफ्टवेयर लिखने का काम एक बार फिर आपको सौंपा गया।

डीलक्स मॉडल में जोड़े गए नए फीचर ये हैं:
- अभी क्यू में लगे नंबरों पर नज़र रखना।
- न्यूनतम और अधिकतम संख्या तय करना। इससे एक ही जगह के अलग-अलग विभागों में ग्राहकों की क्यू लगाने के लिए कई डीलक्स Take-A-Number मशीनें इस्तेमाल की जा सकेंगी, और नंबरों की रेंज से विभागों को अलग-अलग पहचाना जा सकेगा।
- कुछ नंबरों को क्यू छोड़ने की सुविधा देना, ताकि गर्भवती महिलाओं और बुज़ुर्गों को प्राथमिकता से सेवा दी जा सके।
- ऑटो शटडाउन, ताकि गलती से मशीन पूरे वीकेंड चालू न छूट जाए और बिजली बर्बाद न हो।

मशीन का बिज़नेस लॉजिक आपके सहकर्मी ने पहले ही लागू कर दिया है, और वह `TakeANumberDeluxe.State` मॉड्यूल में मौजूद है। अब आपको इसे एक `GenServer` में लपेटना है।

## 1. मशीन शुरू कीजिए

`TakeANumberDeluxe` मॉड्यूल में `GenServer` बिहेवियर इस्तेमाल कीजिए।

`start_link/1` फंक्शन और उसके लिए ज़रूरी `GenServer` कॉलबैक लागू कीजिए।

`start_link/1` को दिया जाने वाला आर्गुमेंट एक कीवर्ड लिस्ट होता है। इसमें `:min_number` और `:max_number` कीज़ होती हैं। इन कीज़ के नीचे की वैल्यूज़ `TakeANumberDeluxe.State.new/2` फंक्शन को देनी होंगी।

अगर `TakeANumberDeluxe.State.new/2` एक `{:ok, state}` टपल लौटाता है, तो मशीन शुरू हो जानी चाहिए और लौटाई गई स्थिति को ही अपनी स्थिति बनाना चाहिए। इसके बजाय अगर वह `{:error, error}` टपल लौटाता है, तो मशीन को रुक जाना चाहिए और रुकने का कारण वही लौटाई गई एरर होनी चाहिए।

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

आपने देखा होगा कि `TakeANumberDeluxe.State.new/2` फंक्शन एक वैकल्पिक तीसरा आर्गुमेंट `auto_shutdown_timeout` भी लेता है। हम इसका इस्तेमाल इस अभ्यास के अंतिम चरण में करेंगे।

## 2. मशीन की स्थिति बताइए

`report_state/1` फंक्शन और उसके लिए ज़रूरी `GenServer` कॉलबैक लागू कीजिए। मशीन को कॉल करने वाले को अपनी वर्तमान स्थिति के साथ जवाब देना चाहिए।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. नए नंबर क्यू में जोड़िए

`queue_new_number/1` फंक्शन और उसके लिए ज़रूरी `GenServer` कॉलबैक लागू कीजिए।

इसे मशीन की वर्तमान स्थिति के साथ `TakeANumberDeluxe.State.queue_new_number/1` फंक्शन को कॉल करना चाहिए।

अगर `TakeANumberDeluxe.State.queue_new_number/1` एक `{:ok, new_number, new_state}` टपल लौटाता है, तो मशीन को कॉल करने वाले को नया नंबर लौटाना चाहिए और नई स्थिति को अपनी स्थिति बना लेना चाहिए। इसके बजाय अगर वह `{:error, error}` टपल लौटाता है, तो मशीन को कॉल करने वाले को वही एरर लौटानी चाहिए और अपनी स्थिति नहीं बदलनी चाहिए।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. क्यू में से अगला नंबर दीजिए

`serve_next_queued_number/2` फंक्शन और उसके लिए ज़रूरी `GenServer` कॉलबैक लागू कीजिए।

इसे मशीन की वर्तमान स्थिति और अपने दूसरे वैकल्पिक आर्गुमेंट `priority_number` के साथ `TakeANumberDeluxe.State.serve_next_queued_number/2` फंक्शन को कॉल करना चाहिए।

अगर `TakeANumberDeluxe.State.serve_next_queued_number/2` एक `{:ok, next_number, new_state}` टपल लौटाता है, तो मशीन को कॉल करने वाले को अगला नंबर लौटाना चाहिए और नई स्थिति को अपनी स्थिति बना लेना चाहिए। इसके बजाय अगर वह `{:error, error}` टपल लौटाता है, तो मशीन को कॉल करने वाले को वही एरर लौटानी चाहिए और अपनी स्थिति नहीं बदलनी चाहिए।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. स्थिति रीसेट कीजिए

`reset_state/1` फंक्शन और उसके लिए ज़रूरी `GenServer` कॉलबैक लागू कीजिए।

इसे `TakeANumberDeluxe.State.new/2` फंक्शन को कॉल करना चाहिए और वर्तमान स्थिति के `min_number` तथा `max_number` इस्तेमाल करके एक नई स्थिति बनानी चाहिए। मशीन को नई स्थिति को ही अपनी स्थिति बना लेना चाहिए। इसे कॉल करने वाले को कोई जवाब नहीं देना चाहिए।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. ऑटो शटडाउन लागू कीजिए

मशीन शुरू करने का तरीका बदलिए। इसे `init_arg` के रूप में दी गई कीवर्ड लिस्ट में `:auto_shutdown_timeout` कीज़ के नीचे की वैल्यू पढ़नी चाहिए और उसे `TakeANumberDeluxe.State.new/3` को तीसरे आर्गुमेंट के रूप में देना चाहिए। अगर `:auto_shutdown_timeout` नहीं दिया गया हो, तो `:infinity` डिफॉल्ट वैल्यू इस्तेमाल कीजिए।

मशीन की स्थिति रीसेट करने का तरीका भी बदलिए, ताकि `auto_shutdown_timeout` भी `TakeANumberDeluxe.State.new/3` को दिया जाए।

लागू किए गए सभी कॉलबैक (`init/1` और सभी `handle_*` कॉलबैक) की रिटर्न वैल्यू इस तरह बदलिए कि वे टाइमआउट सेट करें। इसके लिए वर्तमान मशीन स्थिति में `:auto_shutdown_timeout` कीज़ के नीचे की वैल्यू इस्तेमाल कीजिए। `init/1` की `{:stop, reason}` रिटर्न वैल्यू में टाइमआउट न जोड़ें, क्योंकि टाइमआउट तभी लागू होते हैं जब सर्वर अपना रिसीव लूप शुरू कर चुका हो।

एक `GenServer` कॉलबैक लागू कीजिए, जो `:timeout` संदेश को संभाले। यह संदेश मशीन को तब भेजा जाता है जब उसे दिए गए टाइमआउट के भीतर कोई और संदेश नहीं मिलता। इसे प्रोसेस को `:normal` कारण के साथ समाप्त कर देना चाहिए।

यह भी ध्यान रखिए कि कोई भी अनपेक्षित संदेश आ जाए तो उसे अनदेखा कर दें।

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
