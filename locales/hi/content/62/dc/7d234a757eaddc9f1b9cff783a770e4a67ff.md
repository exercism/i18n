# परिचय

## यादृच्छिकता

Java में यादृच्छिक संख्याएँ बनाने के लिए `java.util.Random` क्लास के एक इंस्टेंस का उपयोग किया जा सकता है।

### यादृच्छिक पूर्णांक

`nextInt()` मेथड की मदद से एक यादृच्छिक पूर्णांक बनाया जा सकता है।
यह `Integer.MIN_VALUE` से `Integer.MAX_VALUE` तक की कोई भी वैल्यू बनाता है।

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

बनाई जाने वाली वैल्यूओं की सीमा तय करने के लिए `nextInt(int)` का उपयोग कीजिए।
यह `0` (शामिल) से लेकर दी गई ऊपरी सीमा (शामिल नहीं) तक एक वैल्यू बनाता है।

उदाहरण के लिए, यह `0` से `9` तक की एक यादृच्छिक संख्या बनाता है।

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

और यह `10` से `19` तक की एक यादृच्छिक संख्या बनाता है।

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### यादृच्छिक दशमलव संख्याएँ

`nextDouble()` मेथड की मदद से एक यादृच्छिक दशमलव संख्या बनाई जा सकती है।
यह `0.0` से `1.0` तक एक वैल्यू बनाता है।

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

और यह `100.0` से `200.0` तक एक यादृच्छिक संख्या बनाता है।

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
