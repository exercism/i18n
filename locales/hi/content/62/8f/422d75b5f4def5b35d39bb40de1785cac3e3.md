# निर्देश

इस अभ्यास में आप कुछ सहायक रूटीन बनाएँगे, जो एक डेवलपर को आइडेंटिफायर के नाम साफ़ करने में मदद करेंगे।
इन 5 कार्यों में आप धीरे-धीरे `Clean` रूटीन बनाएँगे।
एक मान्य आइडेंटिफायर में शून्य या अधिक अक्षर और अंडरस्कोर होते हैं।
हर मामले में, इनपुट स्ट्रिंग का null न होना तय है।
अगर `Clean` फंक्शन को एक खाली स्ट्रिंग दी जाए, तो खाली स्ट्रिंग ही लौटाई जानी चाहिए।
ध्यान दीजिए कि कॉल करने वाले को `Clean` रूटीन को खाली आइडेंटिफायर के साथ कॉल करने से बचना चाहिए, क्योंकि ऐसे आइडेंटिफायर काम के नहीं होते।

## 1. मिलने वाले रिक्त स्थान को अंडरस्कोर से बदलिए

मिलने वाले हर रिक्त स्थान को अंडरस्कोर से बदलने के लिए (_static_) `Identifier.Clean()` मेथड बनाइए।
यह शुरू और अंत के रिक्त स्थानों पर भी लागू होता है।

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. कंट्रोल कैरेक्टरों को अपर केस स्ट्रिंग "CTRL" से बदलिए

(_static_) `Identifier.Clean()` मेथड को इस तरह बदलिए कि वह कंट्रोल कैरेक्टरों को अपर केस स्ट्रिंग `"CTRL"` से बदल दे।

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. केबाब-केस को कैमलकेस में बदलिए

(_static_) `Identifier.Clean()` मेथड को इस तरह बदलिए कि वह केबाब-केस को कैमलकेस में बदल दे।

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. वे कैरेक्टर हटाइए जो अक्षर नहीं हैं

(_static_) `Identifier.Clean()` मेथड को इस तरह बदलिए कि वह ऐसे सभी कैरेक्टर हटा दे जो अक्षर नहीं हैं।

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. ग्रीक के लोअर केस अक्षर हटाइए

(_static_) `Identifier.Clean()` मेथड को इस तरह बदलिए कि वह 'α' से 'ω' के बीच के सभी ग्रीक अक्षर हटा दे।

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
