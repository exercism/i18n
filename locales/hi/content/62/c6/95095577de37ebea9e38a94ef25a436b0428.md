# परिचय

## टेम्पोरल एडजस्टर

`LocalDate` जैसे `java.time` ऑब्जेक्ट के साथ काम करते समय आपको अक्सर तारीखों में जटिल बदलाव करने पड़ते हैं, जैसे "महीने का दूसरा मंगलवार" ढूँढना। इन्हें हाथ से निकालने के बजाय आप **`TemporalAdjusters`** का उपयोग कर सकते हैं।

`java.time.temporal.TemporalAdjusters` (ध्यान दीजिए, अंत में बहुवचन का 's' है) यूटिलिटी क्लास कई आम तारीख बदलावों के लिए स्टैटिक मेथड देती है। इन बदलावों को आप किसी टेम्पोरल ऑब्जेक्ट (जैसे `LocalDate`) पर `.with()` मेथड से लागू करते हैं।

```exercism/note
Using `with(TemporalAdjuster)` returns a _new_ instance and does not update the existing instance, as `java.time` objects are immutable.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

यहाँ कुछ ऐसे प्रमुख एडजस्टर दिए गए हैं जो शेड्यूलिंग की गणनाओं में काम आते हैं:

### सप्ताह के किसी दिन का क्रमांक ढूँढना

सप्ताह के किसी दिन की nवीं बार आने वाली तारीख ढूँढने के लिए `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` का उपयोग कीजिए।

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### महीने में सप्ताह का पहला/अंतिम दिन ढूँढना

`firstInMonth(DayOfWeek dayOfWeek)` या `lastInMonth(DayOfWeek dayOfWeek)` का उपयोग कीजिए।

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### सापेक्ष बदलाव (अगला/पिछला)

`next()`, `previous()`, `nextOrSame()` और `previousOrSame()` जैसे एडजस्टर वर्तमान तारीख के सापेक्ष सप्ताह के किसी दिए गए दिन की अगली या पिछली बार आने वाली तारीख ढूँढते हैं।

- `next()`/`previous()`: अगर वर्तमान तारीख वही दिन है तो उसे छोड़ देते हैं।
- `nextOrSame()`/`previousOrSame()`: अगर वर्तमान तारीख वही दिन है तो उसे भी शामिल करते हैं।

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### अपने खुद के एडजस्टर

`TemporalAdjuster` एक फंक्शनल इंटरफेस है, इसलिए आप अपना खुद का एडजस्टर एक लैम्ब्डा के रूप में लिख सकते हैं, जो बदलने के लिए टेम्पोरल लेता है और बदला हुआ टेम्पोरल लौटाता है। इसे भी पहले से मौजूद एडजस्टरों की तरह `.with()` से लागू किया जाता है, और यह अंदर से उनका उपयोग कर सकता है।

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

`TemporalAdjusters` क्लास के इन एडजस्टरों का उपयोग करने से तारीखों से जुड़े काम बहुत आसान हो सकते हैं।
