# निर्देश

इस अभ्यास में आप एक दोस्त के साथ संख्या अनुमान लगाने का खेल खेल रहे हैं। नियम आसान हैं: आप चुपके से `1` और `100` के बीच एक संख्या चुनते हैं और आपका दोस्त अनुमान लगाने की कोशिश करता है कि आपने कौन-सी संख्या चुनी है। अपने दोस्त की मदद के लिए आप हर अनुमान का जवाब अलग तरह से देते हैं, यह देखकर कि वह अनुमान आपकी चुनी हुई संख्या (`42`) के कितना करीब है। अलग-अलग जवाबों के नियम ये हैं:

- अगर अनुमान `42` है: "Correct"
- अगर अनुमान `41` या `43` है: "So close"
- अगर अनुमान `41` से कम है: "Too low"
- अगर अनुमान `43` से ज़्यादा है: "Too high"

इन अनुमानों के जवाब देने के लिए आपको चार काम करने हैं।

## 1. सही अनुमान का जवाब दीजिए

सही अनुमान का जवाब देने के लिए `reply` फंक्शन बनाइए:

```fsharp
reply 42
// => "Correct"
```

## 2. करीबी अनुमान का जवाब दीजिए

करीबी अनुमानों का जवाब देने के लिए `reply` फंक्शन में बदलाव कीजिए:

```fsharp
reply 41
// => "So close"
```

## 3. बहुत कम अनुमान का जवाब दीजिए

बहुत कम अनुमानों का जवाब देने के लिए `reply` फंक्शन में बदलाव कीजिए:

```fsharp
reply 25
// => "Too low"
```

## 4. बहुत ज़्यादा अनुमान का जवाब दीजिए

बहुत ज़्यादा अनुमानों का जवाब देने के लिए `reply` फंक्शन में बदलाव कीजिए:

```fsharp
reply 88
// => "Too high"
```
