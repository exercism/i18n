# टेस्ट

## अभ्यास की फाइलें

डाउनलोड किए गए अभ्यास में आपके हल को बिल्ड करने और टेस्ट करने के लिए ये फाइलें शामिल होती हैं:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

फाइलों के नाम हर अभ्यास में अलग होते हैं।
अपना हल उस `.vb` फाइल में लिखिए जिसके नाम के अंत में `Tests` नहीं आता।
जिस फाइल का नाम `Tests.vb` पर खत्म होता है, वह xUnit टेस्ट सूट है। आम तौर पर आपको उसमें सिर्फ `Skip` आर्गुमेंट हटाने के लिए बदलाव करना चाहिए।
आम तौर पर आपको प्रोजेक्ट फाइल या लॉक फाइल में बदलाव करने की ज़रूरत नहीं होती।

## टेस्ट चलाइए

अभ्यास की डायरेक्टरी में एक टर्मिनल खोलिए और यह चलाइए:

```bash
dotnet test
```

यह कमांड प्रोजेक्ट की डिपेंडेंसी रीस्टोर करता है, प्रोजेक्ट को बिल्ड करता है और उसके टेस्ट चलाता है।
आप `dotnet watch test` का इस्तेमाल भी कर सकते हैं, ताकि कोई भी सोर्स फाइल बदलते ही टेस्ट दोबारा चल जाएँ।

## छोड़े गए टेस्ट

अभ्यासों में शुरू में सिर्फ पहला ही टेस्ट चालू रहता है, ताकि आप बाकी टेस्ट एक-एक करके हल कर सकें।
टेस्ट देखने के लिए `Tests.vb` पर खत्म होने वाली फाइल खोलिए।
हर टेस्ट एक `Sub` सबरूटीन होता है, जिस पर xUnit का `<Fact>` एट्रिब्यूट लगा होता है।
जब तक किसी टेस्ट के `<Fact>` एट्रिब्यूट में `Skip` आर्गुमेंट रहता है, तब तक वह टेस्ट छोड़ दिया जाता है:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

टेस्ट चालू करने के लिए बस `Skip` आर्गुमेंट हटा दीजिए:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

नया चालू किया गया टेस्ट पास हो जाने के बाद यही तरीका अगले छोड़े गए टेस्ट के साथ दोहराइए।
जब हर टेस्ट चालू हो और पास हो जाए, तो आपका काम पूरा हो गया।
