# इंस्टॉलेशन

## आवश्यकताएँ

* 64-बिट x86 CPU
* आधुनिक C कंपाइलर
* Make बिल्ड टूल
* Netwide Assembler (NASM)

ध्यान दीजिए कि यह ट्रैक केवल System V AMD64 ABI के कॉलिंग कन्वेंशन का समर्थन करता है। Windows उपयोगकर्ताओं को Windows Subsystem for Linux (WSL) इंस्टॉल करना होगा, या एक Linux वर्चुअल मशीन सेट अप करनी होगी।

## Linux

अपने सिस्टम के पैकेज मैनेजर से ज़रूरी सॉफ्टवेयर इंस्टॉल कीजिए:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Xcode Command Line Tools इंस्टॉल कीजिए:

```bash
$ xcode-select --install
```

NASM को [Homebrew](http://brew.sh/) की मदद से इंस्टॉल कीजिए:

```bash
$ brew install nasm
```

## Windows

WSL इंस्टॉल करने के लिए https://docs.microsoft.com/en-us/windows/wsl/install-win10 देखिए।
