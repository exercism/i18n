# परिचय

## बूलियन

Java में बूलियन को `boolean` टाइप से दर्शाया जाता है। इस टाइप की वैल्यू या तो `true` होती है या `false`।

Java तीन बूलियन ऑपरेटरों का समर्थन करता है:  

- `!` (नॉट): बूलियन को उलट देता है।  
- `&&` (ऐंड): दो बूलियन लेता है और अगर दोनों `true` हैं तो `true` लौटाता है।  
- `||` (ऑर): अगर दोनों बूलियन में से कोई एक `true` है तो `true` लौटाता है।

### उदाहरण

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
