# इंस्टॉलेशन

## .NET इंस्टॉल करना

F# ट्रैक [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) प्लेटफॉर्म पर आधारित है, जो Windows, Linux और macOS पर चलता है। .NET प्रोजेक्ट बनाने के लिए आप .NET Command Line Interface (CLI) इस्तेमाल कर सकते हैं। यह CLI .NET SDK का हिस्सा है, जिसे [इंस्टॉलेशन निर्देशों](https://dotnet.microsoft.com/download) का पालन करके इंस्टॉल किया जा सकता है। ध्यान दें: F# ट्रैक के लिए SDK वर्शन 8.0 या उससे अधिक ज़रूरी है।

इंस्टॉलेशन पूरा करने के बाद, आप टर्मिनल में यह कमांड चलाकर जाँच सकते हैं कि CLI सही तरीके से इंस्टॉल हुआ है या नहीं:

```bash
dotnet --version
```

अगर आउटपुट `8.0.100` के बराबर या उससे अधिक कोई वर्शन है, तो .NET SDK सही तरीके से इंस्टॉल हो गया है।

## IDE का उपयोग करना

अगर आप संपादन का ज़्यादा सुविधाओं वाला अनुभव चाहते हैं, तो शायद आप एक IDE इस्तेमाल करना चाहेंगे। ये सबसे लोकप्रिय IDE हैं जो .NET प्रोजेक्ट बनाने का समर्थन करते हैं:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download), [Ionide-fsharp एक्सटेंशन](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp) के साथ
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

ध्यान दें: चूँकि .NET प्रोजेक्ट का फॉर्मैट पुराने वर्शनों से काफी अलग है, पुराने IDE (जैसे Visual Studio 2015) समर्थित नहीं हैं।
