# परिचय

JavaScript में ऐरे एक सूची जैसी संरचना होता है जिसकी लंबाई तय नहीं होती। इसमें किसी भी तरह के प्रिमिटिव या ऑब्जेक्ट रखे जा सकते हैं, मिली-जुली किस्में भी।

ऐरे बनाने के लिए चौकोर ब्रैकेट `[]` के बीच एलिमेंट जोड़िए।
ऐरे से पढ़ने के लिए आइडेंटिफायर के बाद चौकोर ब्रैकेट `[]` में इंडेक्स लिखिए।
ऐरे के इंडेक्स शून्य से शुरू होते हैं।

उदाहरण के लिए:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

ऐरे में कितने एलिमेंट हैं, यह पता करने के लिए `length` प्रॉपर्टी इस्तेमाल कीजिए:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

ऐरे के किसी एलिमेंट को बदलने के लिए आप उस इंडेक्स पर एक वैल्यू असाइन करते हैं:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## मेथड

हर ऐरे ऑब्जेक्ट पर उपलब्ध कुछ [मेथड][mdn-array] ऐरे में जोड़ने या हटाने के लिए इस्तेमाल किए जा सकते हैं।
इस अभ्यास पर काम करते समय इनमें से कुछ पर ध्यान दीजिए:

### push

`.push(value)` इस्तेमाल करके ऐरे के अंत में एक `value` _जोड़ी_ जा सकती है।
यह मेथड ऐरे की नई लंबाई लौटाता है।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

`.pop()` इस्तेमाल करके ऐरे से _अंतिम_ `value` _हटाई_ जा सकती है।
यह मेथड हटाई गई वैल्यू लौटाता है।
इस बदलाव से ऐरे की लंबाई घट जाती है।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

`.shift()` इस्तेमाल करके ऐरे से _पहली_ `value` _हटाई_ जा सकती है।
यह मेथड हटाई गई वैल्यू लौटाता है।
इस बदलाव से ऐरे की लंबाई घट जाती है।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

`.unshift(value)` इस्तेमाल करके ऐरे के शुरू में एक `value` _जोड़ी_ जा सकती है।
यह मेथड ऐरे की नई लंबाई लौटाता है।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

`.splice(index, 1)` इस्तेमाल करके ऐरे से किसी खास `index` पर मौजूद `value` _हटाई_ जा सकती है।
यह मेथड हटाए गए एलिमेंट लौटाता है।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

ये मेथड यहाँ बताए गए तरीकों से ज़्यादा काम के हैं:

- `push` और `unshift` दोनों में आप एक साथ कई वैल्यू जोड़ सकते हैं, इसके लिए बस और आर्गुमेंट देने होते हैं।
  इस अभ्यास को पूरा करने के लिए यह ज़रूरी नहीं है।
- Splice दूसरा आर्गुमेंट बढ़ाकर कई वैल्यू हटा सकता है।
  इस अभ्यास को पूरा करने के लिए यह ज़रूरी नहीं है।
- Splice `deleteCount` के बाद कई वैल्यू को आर्गुमेंट के रूप में जोड़कर वैल्यू जोड़ भी सकता है।
  इसका इस्तेमाल वैल्यू बदलने के लिए, या ऐरे के बीच में वैल्यू डालने के लिए किया जा सकता है (जैसे 0 एलिमेंट हटाकर)।
  इस अभ्यास को पूरा करने के लिए यह ज़रूरी नहीं है।
