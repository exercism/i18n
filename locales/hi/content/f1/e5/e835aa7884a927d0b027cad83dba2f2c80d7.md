# कॉन्स्टेंट को टॉप लेवल स्कोप में निकालना बेहतर है

कॉन्स्टेंट को टॉप लेवल स्कोप में ले जाने पर विचार कीजिए:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

बाहर से सिर्फ वे फंक्शन, क्लास और कॉन्स्टेंट दिखाई देते हैं और उन तक पहुँचा जा सकता है जो `export` किए गए हों।
ये कॉन्स्टेंट दूसरे कोड के सामने आए बिना उसी फाइल में रह सकते हैं।
साथ ही, कॉन्स्टेंट को बाहर निकालने से मेमोरी भी बचती है, क्योंकि जब वही कॉन्स्टेंट दोबारा इस्तेमाल होते हैं, तो फंक्शन के अंदर उन्हें बार-बार आवंटित करने की ज़रूरत नहीं पड़ती।
