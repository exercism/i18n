# परिचय

[Java](https://go.java/index.html) अपनी विविध उपयोगिता और अनुकूलता के कारण उपलब्ध सबसे लोकप्रिय प्रोग्रामिंग भाषाओं में से एक है। सॉफ्टवेयर डेवलपमेंट, मोबाइल ऐप्लिकेशन और बड़े सिस्टम बनाने में इसका बहुत उपयोग होता है।

Java का जन्म 1995 में हुआ था और इसका रखरखाव [Oracle](https://www.oracle.com/index.html) करता है। यह सच है कि यह बाज़ार में मौजूद कुछ नई भाषाओं जितनी नई नहीं है, फिर भी Java बहुत लोकप्रिय है। इसे इस तरह बनाया गया था कि यह तेज़, सुरक्षित, भरोसेमंद, शुरुआत करने वालों के लिए आसान और आसानी से एक प्लेटफॉर्म से दूसरे पर ले जाने लायक हो। पोर्टेबल होने का यह फायदा इसलिए मिलता है क्योंकि Java एक क्रॉस-प्लेटफॉर्म [Java Virtual Machine - JVM](https://en.wikipedia.org/wiki/Java_virtual_machine) पर चलती है। Android के ऐप्लिकेशन भी Java से बनाए जाते हैं, क्योंकि [Android Operating System](<https://en.wikipedia.org/wiki/Android_(operating_system)>) Java भाषा के वातावरण पर चलता है।

Java का समुदाय बहुत बड़ा है! उदाहरण के लिए, GitHub पर 15 लाख से अधिक Java प्रोजेक्ट हैं। यह भी ज़िक्र करने योग्य है कि [StackOverflow](https://stackoverflow.com/questions/tagged/java) पर Java का समुदाय दूसरा सबसे बड़ा समुदाय है! यह इसलिए महत्वपूर्ण है क्योंकि किसी प्रोग्रामिंग भाषा का समुदाय जितना बड़ा होगा, आपको उतनी ही ज़्यादा मदद मिलने की संभावना रहेगी।

Java में शक्तिशाली और अच्छी तरह डिज़ाइन किए गए बिल्ट-इन [APIs - Application Programming Interfaces](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) भी हैं, जिनका इस्तेमाल डेटाबेस कनेक्शन, नेटवर्किंग, I/O, XML पार्सिंग, यूटिलिटी जैसे कई कामों के लिए किया जा सकता है, और भी बहुत कुछ।

लैपटॉप से लेकर डेटा सेंटर तक, गेम कंसोल से लेकर वैज्ञानिक सुपर कंप्यूटर तक, मोबाइल फोन से लेकर इंटरनेट तक, [Java हर जगह है](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
