# निर्देशों का परिशिष्ट

JavaScript अपनी प्रकृति से सिंगल-थ्रेडेड है, इसलिए उसमें भाषा की वे कई सुविधाएँ नहीं हैं जो दूसरी भाषाओं में समानांतर कोड निष्पादन संभालने के लिए होती हैं। सच तो यह है कि "असली" समानांतर कोड निष्पादन का एक ही रास्ता है: `Worker threads` (जिन्हें `Web Workers` भी कहा जाता है)।

लगभग हमेशा, जो कोड समानांतर रूप से चलता दिखता है, जैसे `async functions` या `Promises`, वह असल में समवर्ती रूप से ही चलता है। यह अक्सर बेहतर होता है, क्योंकि आधुनिक JavaScript इसी तरह के उपयोग के लिए अनुकूलित है, और आप अक्सर ऐसा कोड देखेंगे जो `Promise.all()` तथा समवर्ती निष्पादन के दूसरे तरीकों की मदद से समानांतर निष्पादन की "नकल" (या "चालाकी") करता है।

## समवर्तिता बनाम समानांतरता

दोनों के बीच का अंतर साफ़ करने के लिए, इन दोनों की संक्षिप्त परिभाषा यह है:

- समवर्तिता तब होती है जब दो या अधिक कार्य ऐसे समय-खंडों में शुरू हो सकते हैं, चल सकते हैं और पूरे हो सकते हैं जो एक-दूसरे पर आ जाते हैं, और इन्हें एक ही प्रोसेसिंग यूनिट चलाती है।
- समानांतरता तब होती है जब दो या अधिक कार्य एक ही समय पर शुरू और चल सकते हैं, और अलग-अलग प्रोसेसिंग यूनिट इन्हें एक-दूसरे से स्वतंत्र रूप से चलाती हैं।

पूर्णता के लिए, सिंक्रोनस निष्पादन की परिभाषा भी देखिए:

- सिंक्रोनस निष्पादन तब होता है जब किसी कार्य को शुरू होने से पहले किसी दूसरे चल रहे कार्य के पूरा होने का इंतज़ार करना पड़ता है।

## JavaScript में समानांतरता

JavaScript डिफ़ॉल्ट रूप से सिंगल-थ्रेडेड है, फिर भी कोड को समानांतर ढंग से चलाने का एक तरीका मौजूद है।

अगर आप JavaScript को ब्राउज़र में चला रहे हैं (जैसे किसी वेब ऐप में), तो समानांतरता पाने का तरीका [Web Worker API][mdn-demo] है। MDN के अनुसार:

> Web Workers की मदद से किसी स्क्रिप्ट को ऐप्लिकेशन के मुख्य निष्पादन थ्रेड से अलग, बैकग्राउंड थ्रेड में चलाया जा सकता है।

दूसरी ओर, अगर आपकी JavaScript Node.js में चल रही है, जो Exercism का लक्ष्य रनटाइम है, तो यही कॉन्सेप्ट [Worker threads][node] के नाम से जाना जाता है।

यहाँ `Web Worker API` का एक सरल डेमो है (जो [Medium][medium-demo] से लिया गया है)

```js
// main.js
const myWorker = new Worker('worker.js');

myWorker.postMessage(5);

myWorker.onmessage = function (event) {
  console.log('Received result from worker:', event.data);
};
```

```js
// worker.js
onmessage = function (event) {
  console.log('Received number from main thread:', event.data);

  // Perform computation
  const result = event.data * 2;

  // Send result back to the main thread
  postMessage(result);
};
```

और यहाँ `Worker threads API` का एक डेमो है (जो [docs][node] से लिया गया है)

```js
const {
  Worker,
  isMainThread,
  parentPort,
  workerData,
} = require('node:worker_threads');

if (isMainThread) {
  module.exports = function parseJSAsync(script) {
    return new Promise((resolve, reject) => {
      const worker = new Worker(__filename, {
        workerData: script,
      });
      worker.on('message', resolve);
      worker.on('error', reject);
      worker.on('exit', (code) => {
        if (code !== 0)
          reject(new Error(`Worker stopped with exit code ${code}`));
      });
    });
  };
} else {
  const { parse } = require('some-js-parsing-library');
  const script = workerData;
  parentPort.postMessage(parse(script));
}
```
