# परिचय

बाकी कई भाषाओं से उलट, JavaScript में दो अलग-अलग चीज़ें हैं जो किसी (अर्थपूर्ण) वैल्यू के न होने को दर्शाती हैं।
ये हैं `null` और `undefined`.

## Null

प्रिमिटिव वैल्यू `null` का इस्तेमाल किसी भी टाइप के वेरिएबल के लिए जान-बूझकर "खाली वैल्यू" के तौर पर किया जाता है।

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

आप [सख्त समानता ऑपरेटर][mdn-strict-equality] `===` इस्तेमाल करके देख सकते हैं कि कोई वेरिएबल null है या नहीं।

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> जिस वेरिएबल को कोई वैल्यू असाइन नहीं किया गया है, उसका टाइप `undefined` होता है।[^1]

इसका मतलब है कि `null` एक खाली वैल्यू दर्शाता है (लेकिन फिर भी एक वैल्यू है), जबकि `undefined` वैल्यू के पूरी तरह न होने को दर्शाता है। 🤯

`undefined` अलग-अलग जगहों पर आता है।

- अगर किसी वेरिएबल को बिना कोई वैल्यू दिए घोषित किया जाए (इनिशियलाइज़ेशन), तो वह `undefined` होता है।

  ```js
  let name;
  console.log(name); // => undefined
  ```

- अगर आप किसी ऑब्जेक्ट में ऐसी की एक्सेस करने की कोशिश करते हैं जो मौजूद नहीं है, तो आपको `undefined` मिलता है।

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- अगर कोई फंक्शन कोई वैल्यू नहीं लौटाता, तो नतीजा `undefined` होता है।

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- अगर किसी फंक्शन को कोई आर्गुमेंट नहीं दिया जाता, तो वह `undefined` होता है, सिवाय इसके कि उस आर्गुमेंट की कोई डिफ़ॉल्ट वैल्यू हो।

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

आप सख्त समानता ऑपरेटर `===` की मदद से देख सकते हैं कि कोई वेरिएबल undefined है या नहीं।

```javascript
let name;

name === undefined;
// => true
```

## ऑप्शनल चेनिंग

अगर आप किसी ऑब्जेक्ट में कोई नेस्टेड वैल्यू निकालने की कोशिश करते हैं, लेकिन उसकी पैरेंट की मौजूद नहीं है, तो JavaScript एरर देता है।
इससे आसानी से बचने के लिए 2020 में भाषा के स्पेसिफिकेशन में ऑप्शनल चेनिंग जोड़ी गई।
ऑप्शनल चेनिंग ऑपरेटर `?.` की मदद से आप यह पक्का कर सकते हैं कि JavaScript नेस्टेड की को तभी एक्सेस करने की कोशिश करे जब उसका पैरेंट `null` या `undefined` न हो।
वरना `undefined` लौटाया जाता है।

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## नलिश कोएलसिंग

कुछ स्थितियों में आप चाहते हैं कि अगर कोई वेरिएबल null या undefined हो (और सिर्फ तभी), तो कोई डिफ़ॉल्ट वैल्यू लागू हो जाए।
इसे हल करने के लिए 2020 में नलिश कोएलसिंग ऑपरेटर `??` पेश किया गया।
यह दाएँ तरफ के ऑपरेंड को तभी लौटाता है जब बाएँ तरफ का ऑपरेंड `null` या `undefined` हो।
वरना बाएँ तरफ का ऑपरेंड ही लौटाया जाता है।

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
