# इंस्टॉलेशन

## R रनटाइम इंस्टॉल कीजिए
[CRAN होमपेज](https://cran.r-project.org/) पर जाइए। वहाँ आपको Linux, Mac OSX और Windows के लिए डाउनलोड लिंक मिलेंगे। अपने ऑपरेटिंग सिस्टम के लिए इंस्टॉलर डाउनलोड कीजिए और चलाइए।

## RStudio IDE इंस्टॉल कीजिए (अनुशंसित)
RStudio एक लोकप्रिय क्रॉस-प्लेटफॉर्म इंटीग्रेटेड डेवलपमेंट एनवायरनमेंट (IDE) है, जिसमें R की प्रोग्रामिंग की जाती है (यह Python, JavaScript और Markdown जैसी दूसरी भाषाओं को भी सपोर्ट करता है)। RStudio इस्तेमाल करने से आपके कोड के हल लिखना और टेस्ट चलाना आसान हो जाएगा।

[RStudio का मौजूदा स्टेबल वर्ज़न](https://www.rstudio.com/products/rstudio/download/) डाउनलोड कीजिए और इंस्टॉल कीजिए। या फिर, आने वाले रिलीज़ का [प्रीव्यू वर्ज़न](https://www.rstudio.com/products/rstudio/download/preview/) ले लीजिए।

## Visual Studio Code के लिए R एक्सटेंशन इंस्टॉल कीजिए (विकल्प)
Visual Studio Code के लिए R एक्सटेंशन कई चीज़ों में मदद करता है: सिंटैक्स हाइलाइटिंग, कोड कम्पलीशन, लिंटिंग, फॉर्मेटिंग, R टर्मिनल से बातचीत, डेटा, प्लॉट, वर्कस्पेस वेरिएबल और हेल्प पेज देखना, पैकेज मैनेज करना, और R Markdown डॉक्युमेंट्स के साथ काम करना।

[R एक्सटेंशन का मौजूदा वर्ज़न](https://code.visualstudio.com/docs/languages/r) डाउनलोड कीजिए और इंस्टॉल कीजिए

## टेस्ट चलाने के लिए R पैकेज इंस्टॉल कीजिए
स्पेक्स के लिए टेस्ट रनर Hadley Wickham की [`testthat`](https://github.com/hadley/testthat) लाइब्रेरी है, जो R पैकेज लिखने वालों में काफी लोकप्रिय है।

इस लाइब्रेरी को इंस्टॉल करने के लिए अपने RStudio कंसोल में (या जहाँ भी आप R इस्तेमाल कर रहे हैं) यह टाइप कीजिए।

```{R}
install.packages("testthat")
```

हालाँकि ऐसा कम ही होगा कि Exercism के अभ्यास हल करने के लिए आपको पैकेज इंस्टॉल करने की _ज़रूरत_ पड़े, लेकिन हो सकता है कि आप [`tidyverse`](https://github.com/tidyverse/tidyverse) जैसा कोई सामान्य काम का पैकेज लेना चाहें, जो आपकी प्रोग्रामिंग शैली से मेल खाता हो। `tidyverse` जैसा पैकेज इंस्टॉल करने और लोड करने के लिए:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
