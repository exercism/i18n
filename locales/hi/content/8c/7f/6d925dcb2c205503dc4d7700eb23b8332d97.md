# परिचय

`call` ([`kernel`][kernel] में) एक क्वोटेशन चलाता है। जब क्वोटेशन के स्टैक इफेक्ट का अनुमान नहीं लगाया जा सकता, आम तौर पर इसलिए कि क्वोटेशन कहीं और से आया है, तो `call` पर स्टैक इफेक्ट स्पष्ट रूप से घोषित कीजिए:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

क्योंकि क्वोटेशन वैल्यू होते हैं, एक ऐरे संख्याओं और क्वोटेशन का मिश्रण रख सकता है, जिससे "एक प्रोग्राम" बस एक और सीक्वेंस बन जाता है:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
