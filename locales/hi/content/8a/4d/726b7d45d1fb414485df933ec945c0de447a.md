# JavaScript में रिकर्शन को समझना

रिकर्शन प्रोग्रामिंग का एक शक्तिशाली कॉन्सेप्ट है, जिसमें एक फंक्शन खुद को कॉल करता है।
पहली बार में इसे समझना थोड़ा मुश्किल लग सकता है, लेकिन जब आप इसकी बुनियादी बातें समझ लेते हैं, तो यह जटिल समस्याओं को हल करने का एक बहुत काम का टूल बन जाता है।
इस ट्यूटोरियल में हम आसान उदाहरणों की मदद से JavaScript में रिकर्शन को समझेंगे।

## रिकर्शन क्या है?

रिकर्शन तब होता है जब कोई फंक्शन खुद को कॉल करता है, चाहे सीधे तौर पर हो या किसी और के ज़रिए।
यह लूप जैसा ही है, लेकिन इसमें किसी समस्या को तोड़कर छोटी और आसानी से संभाली जा सकने वाली उप-समस्याओं में बाँटा जाता है।

### उदाहरण 1: उलटी गिनती

चलिए एक आसान उदाहरण से शुरू करते हैं: एक उलटी गिनती वाला फंक्शन।

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

इस उदाहरण में:

- **बेस केस**: जब `num` 0 से छोटा या उसके बराबर हो जाता है, तो फंक्शन "Blastoff!" दिखाता है और खुद को कॉल करना बंद कर देता है।
- **रिकर्शन केस**: फंक्शन मौजूदा `num` दिखाता है और खुद को `num - 1` के साथ कॉल करता है।

### उदाहरण 2: फैक्टोरियल

अब रिकर्शन का एक क्लासिक उदाहरण देखते हैं: किसी संख्या का फैक्टोरियल निकालना।

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

इस उदाहरण में:

- **बेस केस**: जब `n` 0 या 1 होता है, तो फंक्शन 1 लौटाता है।
- **रिकर्शन केस**: फंक्शन `n` को `n - 1` के फैक्टोरियल से गुणा करता है।

## मुख्य कॉन्सेप्ट

### बेस केस

हर रिकर्शन वाले फंक्शन में कम से कम एक बेस केस होना चाहिए, यानी ऐसी शर्त जहाँ फंक्शन खुद को कॉल करना बंद कर देता है।
बेस केस के बिना रिकर्शन अनंत तक चलता रहेगा, जिससे स्टैक ओवरफ्लो हो जाता है।

### रिकर्शन केस

रिकर्शन केस बताता है कि फंक्शन खुद को समस्या के किसी छोटे या आसान रूप के साथ कैसे कॉल करता है।

## रिकर्शन के फायदे और नुकसान

**फायदे:**

- कुछ खास समस्याओं के लिए बहुत साफ-सुथरा हल।
- गणितीय आगमन के कॉन्सेप्ट जैसा काम करता है।

**नुकसान:**

- इटरेशन वाले हलों की तुलना में कम कुशल हो सकता है।
- गहरे रिकर्शन में स्टैक ओवरफ्लो हो सकता है।

## निष्कर्ष

रिकर्शन एक बहुत काम की तकनीक है, जो जटिल समस्याओं को तोड़कर छोटी और आसानी से संभाली जा सकने वाली उप-समस्याओं में बदल देती है।
JavaScript में अच्छे रिकर्शन वाले हल लिखने के लिए बेस केस और रिकर्शन केस को समझना बहुत ज़रूरी है।
