# विवरण

किसी लॉजिक को बार-बार चलाने के लिए लूप का इस्तेमाल किया जा सकता है। अगर किसी लूप का कोड कम से कम एक बार चलना ज़रूरी हो, तो `do`/`while` लूप का इस्तेमाल किया जा सकता है:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

`do`/`while` लूप का इस्तेमाल `while` लूप से कम होता है, लेकिन कुछ मामलों में इससे कोड ज़्यादा स्वाभाविक दिखता है।
