# टेस्ट

हर अभ्यास में एक टेस्ट फाइल होती है।
`bats` प्रोग्राम से टेस्ट चलाइए।

```bash
bats hello_world.bats
```

अगर स्थानीय रूप से टेस्ट चलाते समय आपको डीबग आउटपुट छापना हो, तो [स्थानीय रूप से डीबग करना][debugging] देखिए।

`bats` इंस्टॉल करना होगा।
अपने सिस्टम पर `bats` इंस्टॉल करने के निर्देशों के लिए [Bash ट्रैक पर टेस्टिंग][tests] पेज देखिए।

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## assert फंक्शन के लिए मदद

टेस्ट [bats-assert][bats-assert] लाइब्रेरी के फंक्शन इस्तेमाल करते हैं।
अलग-अलग `assert*` फंक्शन की मदद वहीं मिल जाएगी।

[bats-assert]: https://github.com/bats-core/bats-assert

## छोड़े गए टेस्ट

किसी अभ्यास को हल करने का मतलब है उसके सारे टेस्ट पास कराना।
डिफॉल्ट रूप से, जब आप टेस्ट चलाते हैं तो सिर्फ एक टेस्ट (पहला टेस्ट) चलता है।
यह जानबूझकर ऐसा है, ताकि आपका ध्यान सिर्फ उसी एक टेस्ट को पास कराने पर रहे।
वह पास हो जाने के बाद, अगली एनोटेशन को कॉमेंट करके या हटाकर आप अगला टेस्ट चालू कर सकते हैं:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## स्किप को अनदेखा करना

`skip` एनोटेशन वाले टेस्ट समेत सारे टेस्ट चलाने के लिए आप यह चला सकते हैं:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

टाइपिंग कम करने के लिए रैपर फंक्शन बनाना सुविधाजनक हो सकता है:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

फिर टेस्ट चलाने के लिए सिर्फ यह लिखिए:

```bash
bats
```
