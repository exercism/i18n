# परिचय

यह अभ्यास [Leah's Luscious Lasagna][lasagna] वाले पूर्णांक गणित पर आगे बढ़ता है। यहाँ आप दशमलव संख्याओं के साथ काम करेंगे और यह तय करेंगे कि किस काम के लिए भाग देने वाला कौन-सा शब्द सही है।

## पूर्णांक और दशमलव संख्याएँ

Factor पूर्णांकों (`1`, `42`, `1_000_000`) को दशमलव संख्याओं (`1.0`, `3.14`, `6.02e23`) से अलग पहचानता है। अगर आप एक ही गणना में पूर्णांक और दशमलव संख्या मिला दें, तो परिणाम दशमलव संख्या के रूप में आता है:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

अंकों को समूहों में बाँटने के लिए आप किसी संख्या के अंदर अंडरस्कोर लगा सकते हैं, जैसे `1_000_000`, और Factor उन्हें बस नज़रअंदाज़ कर देता है।

## भाग देने वाले शब्द

Factor में भाग देने के लिए अलग-अलग शब्द हैं। ये सभी [`math`][math] वोकैबुलरी में रहते हैं।

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` दो पूर्णांकों के लिए एक `ratio` बनाता है (Factor का सटीक परिमेय प्रकार), और अगर इनपुट में से कोई एक दशमलव संख्या हो तो `float` बनाता है। `/f` दो पूर्णांकों के लिए भी दशमलव परिणाम निकालता है। `/i` हमेशा शून्य की ओर काटता है।

## जाँच

[`math`][math], [`math.functions`][math.functions] और [`math.primes`][math.primes] से संख्या जाँचने वाले प्रेडिकेट:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## दशमलव से पूर्णांक

[`math.functions`][math.functions] वोकैबुलरी के `floor`, `ceiling` और `round` सभी दशमलव संख्या लौटाते हैं (`3.0`, `3` नहीं)। असली पूर्णांक पाने के लिए `>integer` जोड़िए:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## घात और निरपेक्ष मान

`sq`, `^` और `abs` ([`math.functions`][math.functions] में) वर्ग, मनचाही घात और निरपेक्ष मान निकालते हैं:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## न्यूनतम और अधिकतम

`min ( x y -- z )` और `max ( x y -- z )` ([`math.order`][math.order] में) दो संख्याओं में से छोटी या बड़ी लौटाते हैं:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

सबसे आम उपयोग *क्लैम्पिंग* है, यानी किसी वैल्यू को `max` की मदद से निचली सीमा पर रोकना (जैसे `0 max` किसी वैल्यू को ऋणात्मक होने से रोकता है) या `min` की मदद से ऊपरी सीमा पर रोकना।

## क्रम तय करने वाले प्रेडिकेट

`math.order` तुलना वाले प्रेडिकेट `before?`, `after?`, `before=?` और `after=?` भी देता है, जो किसी भी क्रम में रखी जा सकने वाली चीज़ पर काम करते हैं: संख्याओं, स्ट्रिंग और अक्षरों पर।

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

जब वैल्यू स्ट्रिंग हो सकती हों तो `<`/`<=` की जगह इन्हीं का उपयोग कीजिए, क्योंकि गणित वाले ऑपरेटर स्ट्रिंग पर लागू नहीं होते।
