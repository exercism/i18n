# विवरण

Factor के कंडीशनल अपनी शाखाओं के तौर पर **क्वोटेशन** लेते हैं। क्वोटेशन चौकोर ब्रैकेट, `[ ... ]`, में लिखा गया कोड होता है, जिसे कंडीशनल के उसे चुनने तक चलाया नहीं जाता, बल्कि एक वैल्यू की तरह पुश किया जाता है। (क्वोटेशन के बारे में पूरी बात किसी बाद वाले अभ्यास में बताई गई है।)

तीन सबसे बुनियादी कंडीशनल `kernel` में मौजूद हैं:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

दो स्टार वाले वेरिएंट बूलियन को एक ऐसी वैल्यू की तरह लेते हैं जिसका इस्तेमाल तब किया जाता है जब वह ट्रूथी हो। यही मानक "वैल्यू-या-`f`" जोड़ा है:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

दो से ज़्यादा शाखाओं के लिए `combinators` में मौजूद `cond` `{ predicate body }` जोड़ों के ऐरे को एक-एक करके देखता है और जो पहला प्रेडिकेट सही निकलता है उसका बॉडी चला देता है। आम तरीके में हर प्रेडिकेट के अंदर `dup` लगाया जाता है ताकि इनपुट बचा रहे, और बॉडी की शुरुआत में एक `drop` लगता है, जो नतीजा पुश करने से पहले उस इनपुट को हटा देता है:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

अंत में बिना प्रेडिकेट वाला जोड़ा डिफॉल्ट शाखा होता है।
