# परिचय

जो टाइप [`IEnumerable<T>`][IEnumerable] इंटरफेस को लागू करते हैं, उन्हें _एन्यूमरेबल_ कहा जाता है।
सभी बिल्ट-इन कलेक्शन टाइप इस इंटरफेस को लागू करते हैं।

किसी एन्यूमरेबल टाइप पर `foreach` लूप की मदद से इटरेशन किया जा सकता है:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>` को लागू करने के लिए किसी टाइप को एक मेथड लागू करना होता है: `IEnumerator<T> GetEnumerator()`।
जैसा कि देखा गया, एक एन्यूमरेबल कलेक्शन पर वास्तविक इटरेशन का काम `IEnumerator<T>` टाइप को सौंप देता है।
इस इंटरफेस में लागू करने के लिए एक प्रॉपर्टी और तीन मेथड हैं:

- `public T Current { get; }`: वर्तमान एलिमेंट प्राप्त करता है।
- `public bool MoveNext ();`: अगले एलिमेंट पर जाता है, और अगर अगले एलिमेंट पर जाना सफल रहा तो `true` लौटाता है, और अगर नहीं (और एलिमेंट नहीं बचे) तो `false` लौटाता है।
- `public void Reset ();`: एन्यूमरेटर को उसकी शुरुआती स्थिति में फिर से ले आता है (पहले एलिमेंट से पहले)।

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
