# निर्देश

दो वायलिन वादक एक डुएट की तैयारी कर रहे हैं। हर पार्ट एक ऐरे है जिसमें हर बार के स्वरों की संख्या रखी जाती है, और सभी पार्ट की लंबाई हमेशा एक जैसी नहीं होती।

चारों कार्य `DUET_PRACTICE` क्लास में रखे जाते हैं।

## 1. वे कितने बार साथ बजाते हैं?

जब तक दोनों पार्ट में एक भी बार बचा है, वे साथ बजाते हैं।

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. कितने बार मेल खाते हैं?

उन बार को गिनिए जिनमें दोनों पार्ट में स्वरों की संख्या एक जैसी होती है। सिर्फ वही बार मेल खा सकते हैं जो दोनों पार्ट में मौजूद हैं।

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. कौन ज़्यादा व्यस्त है?

उन बार को गिनिए जिनमें पहले पार्ट में दूसरे पार्ट से ज़्यादा स्वर होते हैं।

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. बार को भार दीजिए

बाद वाले बार ज़्यादा कठिन होते हैं, इसलिए हर बार की गिनती उसके स्थान के बराबर होती है: पहले बार की गिनती एक, दूसरे की दो और तीसरे की तीन होती है। हर बार के स्वरों की संख्या को उस बार के नंबर से गुणा कीजिए और सबको जोड़ दीजिए।

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

यह 1×4 + 2×4 + 3×8 है। बार की गिनती एक से शुरू होती है, शून्य से नहीं।
