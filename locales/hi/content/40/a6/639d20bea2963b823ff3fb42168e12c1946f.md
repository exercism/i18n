# निर्देश परिशिष्ट

## Python ट्रैक पर यह अभ्यास किस तरह बनाया गया है

इस अभ्यास के टेस्ट यह अपेक्षा करते हैं कि आप एक Matrix `class` बनाइए (_साथ ही [concept:python/classes]() भी देखिए_)।
यह किसी तीसरे पक्ष की लाइब्रेरी, जैसे [Numpy][numpy-matrix], के Matrix ऑब्जेक्ट को _इस्तेमाल_ करने से अलग है, और ऐसा करने का समर्थन नहीं है।
 _चिंता न कीजिए, यह उतना मुश्किल नहीं है जितना आप सोचते हैं!_
 `classes` और डेटा स्ट्रक्चर के बारे में और भी जानने और शुरुआत करने के लिए, नीचे दिए गए संसाधन देखिए:


-   [**क्लासेस पर पहली नज़र**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) Python 3 के डॉक्युमेंटेशन से।
-   [**Python में क्लास कैसे बनाएँ**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) Real Python वेबसाइट से।
-   [**Python में डेटा स्ट्रक्चर**](https://docs.python.org/3/tutorial/datastructures.html) Python 3 के डॉक्युमेंटेशन से।

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
