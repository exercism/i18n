# इंस्टॉलेशन

## कौन सा वर्शन चुनना चाहिए?

हम सलाह देते हैं कि आप सक्रिय समर्थन वाली कोई स्थिर PHP रिलीज़ इस्तेमाल कीजिए। फिलहाल ये **PHP 8.2, 8.3 और 8.4** हैं। मौजूदा रिलीज़ और उनके टाइमलाइन की जानकारी [PHP के आधिकारिक डॉक्युमेंटेशन](https://www.php.net/supported-versions.php) में मिलेगी।

## PHP इंस्टॉल कीजिए

Linux / macOS के ज़्यादातर पैकेज मैनेजर पहले से बने पैकेज देते हैं। PHP को [php.net/downloads.php](https://php.net/downloads.php) या [windows.php.net/download](https://windows.php.net/download) से डाउनलोड करके सोर्स से बनाया जा सकता है।

~~~~exercism/note
अभ्यास पूरे करने के लिए nginx या Apache HTTP सर्वर जैसे वेब सर्वर की ज़रूरत नहीं है।
~~~~

### Linux

अलग-अलग डिस्ट्रिब्यूशन के तरीके अलग-अलग होते हैं। आपके पैकेज मैनेजर के हिसाब से आपको इनमें से कोई एक चलाना चाहिए:

```shell
yum install php
```

या

```shell
apt-get install php
```

यह आपके पैकेज मैनेजर पर निर्भर करता है।

आगे के निर्देशों के लिए [Unix सिस्टम पर इंस्टॉलेशन](https://www.php.net/manual/en/install.unix.php) पर PHP मैनुअल पढ़िए।

### macOS

macOS के साथ PHP अक्सर पहले से आता है, लेकिन वह अक्सर पुराना होता है। हम PHP को [Homebrew](https://brew.sh/) से इंस्टॉल करने की सलाह देते हैं। Homebrew को [उनके होमपेज](https://brew.sh/#install) पर दिए निर्देशों का पालन करके इंस्टॉल कीजिए।

इंस्टॉलेशन की पुष्टि करने के लिए यह कमांड चलाकर देखिए। इसके लिखे जाने के समय यह Homebrew `4.5.x` दिखाना चाहिए।

```shell
brew --version 
```

Homebrew से PHP इंस्टॉल कीजिए

```shell
brew install php@8.4
```

इससे अब इंस्टॉल हुए PHP का वर्शन दिखना चाहिए, जो कम से कम `8.2.0` होना चाहिए।

```shell
php -v
```

आगे के निर्देशों के लिए [macOS पर इंस्टॉलेशन](https://www.php.net/manual/en/install.macosx.php) पर मैनुअल पढ़िए।

### Windows

Windows के लिए आधिकारिक PHP बाइनरी [windows.php.net/download](https://windows.php.net/download) से डाउनलोड की जा सकती हैं।

पहले से बने स्टैक भी मौजूद हैं, जिनमें [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) और [XAMPP](https://www.apachefriends.org/de/index.html) शामिल हैं।

आगे के निर्देशों के लिए [Windows सिस्टम पर इंस्टॉलेशन](https://www.php.net/manual/en/install.windows.php) पर मैनुअल पढ़िए।

### Docker

अगर आप कंटेनर वाले तरीके पसंद करते हैं, तो [Docker Hub से आधिकारिक PHP इमेज](https://hub.docker.com/_/php) डाउनलोड कर सकते हैं। आपको [Docker](https://docs.docker.com/engine/install/) भी चाहिए होगा।

### अन्य

अगर आप कोई और OS इस्तेमाल करना चाहते हैं, तो [php.net/manual/en/install](https://www.php.net/manual/en/install.php) पर निर्देश देखिए।

### PHP आर्काइव (PHAR) के ज़रिए

Exercism के अभ्यासों के लिए PHPUnit इस्तेमाल करने का सबसे आसान तरीका यह है कि आप PHP आर्काइव (PHAR) के रूप में पैक किया गया डिस्ट्रिब्यूशन डाउनलोड कीजिए, जो PHPUnit इस्तेमाल करने का सुझाया गया तरीका भी है। PHAR को वहीं रखिए जहाँ आपने `exercism` CLI रखी थी, ताकि आप कहीं से भी PHPUnit चला सकें।

आप PHPUnit पैकेज की कोई रिलीज़ PHP आर्काइव के रूप में डाउनलोड कर सकते हैं:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

फिर डाउनलोड की गई फाइल को एक्ज़ीक्यूटेबल बनाइए:

```shell
chmod +x phpunit.phar
```

और इसे उसी जगह ले जाइए जहाँ आपने `exercism` CLI ले जाया था, और कमांड का नाम `phpunit` रखिए:

```shell
mv phpunit.phar ~/bin/phpunit
```

अब आप कहीं से भी `phpunit` चला सकते हैं, जैसा कि [PHP ट्रैक के टेस्टिंग डॉक्स](https://exercism.org/docs/tracks/php/tests) में दिखाया गया है:

```shell
phpunit --version
```

आउटपुट कुछ इस तरह दिखना चाहिए:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

आप PHPUnit इंस्टॉल करने के लिए आधिकारिक [PHPUnit इंस्टॉल करने के निर्देश](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) का पालन भी कर सकते हैं।

### Composer के ज़रिए

PHPUnit वर्शन 11 को [Composer](https://getcomposer.org) से भी इंस्टॉल किया जा सकता है।

#### Composer इंस्टॉल कीजिए

अपने डिवाइस के OS के [इंस्टॉलेशन निर्देशों](https://getcomposer.org/doc/00-intro.md) का पालन करके [Composer](https://getcomposer.org) इंस्टॉल कीजिए। इस्तेमाल में आसानी के लिए हम इसे ग्लोबली इंस्टॉल करने की सलाह देते हैं।

#### PHPUnit को ग्लोबल टूल के रूप में जोड़िए

यह कमांड इस्तेमाल कीजिए:

```shell
composer global require phpunit/phpunit ^11.5
```

कृपया ध्यान रखिए कि आप वर्शन 11.5 या उससे नया इंस्टॉल करें।
