# परिचय

Factor में अधिकांश डेटा *सीक्वेंस* में रहता है। ऐरे (`{ … }`), वेक्टर
(`V{ … }`) और स्ट्रिंग, ये सब [`sequences`][sequences] से मिलने वाला एक ही
[प्रोटोकॉल][sequence-protocol] साझा करते हैं।

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

एग्रीगेशन (`sum`, `count`, `any?`, `all?`) और `empty?` व `member?` जैसी
जाँचें हर सीक्वेंस टाइप पर एक जैसी काम करती हैं।
मूल सीक्वेंस को बदले बिना नए सीक्वेंस बनाना: `prefix`, `suffix`,
`append`, `unclip`, `unclip-last`.

कभी-कभी किसी सामान्य ऑपरेशन से आपको कोई खास ठोस सीक्वेंस टाइप वापस चाहिए
होता है। तब `>array`, `>vector` और `>string` (जो
[`arrays`][arrays] और उससे जुड़ी वोकैबुलरी में मिलते हैं) एक सीक्वेंस टाइप को
दूसरे में बदल देते हैं।

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
