# परिचय

## पैटर्न के बारे में अधिक जानकारी

Fundamentals कॉन्सेप्ट से याद कीजिए कि एक AWK प्रोग्राम **पैटर्न-एक्शन जोड़ों** से बना होता है।

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### "पैटर्न" से हमारा क्या मतलब है?

"पैटर्न" कोई भी AWK एक्सप्रेशन हो सकता है।
एक्सप्रेशन के परिणाम की सत्यता तय करती है कि एक्शन चलेगा या नहीं।

### खाली पैटर्न

पैटर्न छोड़ा जा सकता है।
ऐसी स्थिति में हर रिकॉर्ड के लिए एक्शन चलाया जाता है।

हम passwd फाइल में मौजूद सभी यूज़रनेम प्रिंट कर सकते हैं।

```sh
awk -F: '{print $1}' /etc/passwd
```

### रेगुलर एक्सप्रेशन

AWK स्ट्रिंग की तुलना रेगुलर एक्सप्रेशन से करके बूलियन परिणाम दे सकता है।

किसी खास फील्ड का मिलान करने के लिए `~` रेगेक्स-मिलान ऑपरेटर का उपयोग कीजिए। 
इस ऑपरेटर का बायाँ ऑपरेंड एक स्ट्रिंग होता है और दायाँ ऑपरेंड एक रेगुलर एक्सप्रेशन।
रेगुलर एक्सप्रेशन लिटरल को `/` स्लैश के बीच लिखा जाता है।

passwd फाइल में उन यूज़रों को ढूँढने के लिए जो bash से लॉग इन करते हैं:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` "रेगेक्स का मिलान **नहीं** होता" वाला ऑपरेटर है।

मौजूदा रिकॉर्ड से रेगेक्स का मिलान करने के लिए आप `$0 ~ /regex/` लिख सकते हैं।
यह इतना आम है कि इसका छोटा रूप भी है: आप `$0` और `~` हटाकर सीधे `/regex/` लिख सकते हैं

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
उस AWK वन-लाइनर की तुलना उसके बराबर वाले grep कमांड से कीजिए

```sh
grep 'regex' data.txt
```

AWK आपको संक्षिप्तता से समझौता किए बिना एक पूरी प्रोग्रामिंग भाषा दे देता है।
~~~~

GNU AWK के रेगुलर एक्सप्रेशन के इस रूप के बारे में हम आगे किसी कॉन्सेप्ट में और जानेंगे।

### एक्सप्रेशन

AWK के एक्सप्रेशन (गणितीय, तार्किक या किसी भी तरह के) पैटर्न के रूप में इस्तेमाल किए जा सकते हैं।

UID 1000 या उससे अधिक वाले सभी यूज़र निकालने के लिए:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

याद रखिए कि AWK में गलत मान संख्या शून्य और खाली स्ट्रिंग होते हैं, और बाकी सभी संख्याएँ या स्ट्रिंग सही होती हैं।
कोई भी एक्सप्रेशन जिसका मान संख्या या स्ट्रिंग हो, पैटर्न के रूप में इस्तेमाल किया जा सकता है।

### फंक्शन

कोई भी [बिल्ट-इन][builtins] या [यूज़र-डिफ़ाइंड][user-defined] फंक्शन एक्सप्रेशन में, और इसलिए पैटर्न में भी, इस्तेमाल किया जा सकता है।
कुछ उदाहरण:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### स्थिर पैटर्न

AWK में एक आम तरीका यह है:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` एक सही मान वाला पैटर्न है जिससे कोई एक्शन जुड़ा नहीं है।
इसका अर्थ है "मौजूदा रिकॉर्ड प्रिंट कीजिए"।
