# परिचय

## तुलना ऑपरेटर

[तुलना ऑपरेटर][comparison-operators] एक ही टाइप की दो वैल्यू की तुलना करते हैं और एक `Bool` वैल्यू (`true` या `false`) लौटाते हैं।
अगर आप अलग-अलग टाइप की वैल्यू की तुलना करने की कोशिश करते हैं, तो कंपाइलर एक एरर देता है।

Swift में मानक तुलना ऑपरेटर ये हैं:

| ऑपरेटर | विवरण                    | उदाहरण           |
| -------- | ------------------------ | --------------- |
| `==`     | बराबर                    | `1 == 1` (सही)  |
| `!=`     | बराबर नहीं                | `1 != 2` (सही)  |
| `<`      | से छोटा                  | `4 < 5`  (सही)  |
| `<=`     | से छोटा या बराबर          | `4 <= 4` (सही)  |
| `>`      | से बड़ा                  | `3 > 1`  (सही)  |
| `>=`     | से बड़ा या बराबर          | `2 >= 2` (सही)  |

## `if` और `else` स्टेटमेंट

[कंडीशनल स्टेटमेंट][conditional-statement] किसी शर्त के `true` या `false` होने के आधार पर कोड चलाता है।
सबसे आम कंडीशनल स्टेटमेंट [`if` स्टेटमेंट][if] है, जो कोड के एक ब्लॉक को तभी चलाता है जब उसकी शर्त `true` हो।
`if` स्टेटमेंट लिखने के लिए `if` कीवर्ड लिखिए, उसके बाद शर्त और कर्ली ब्रैकेट में बंद कोड ब्लॉक लिखिए:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

जब शर्त `false` हो, तब वैकल्पिक कोड चलाने के लिए आप `if` के साथ एक `else` क्लॉज़ जोड़ सकते हैं:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

कई शर्तों को एक के बाद एक जाँचने के लिए, `else if` की मदद से स्टेटमेंट को एक-दूसरे से जोड़िए।
`if` स्टेटमेंट के लिए `else` शाखा ज़रूरी नहीं है, लेकिन जब कोई भी शर्त पूरी न हो, तो उन स्थितियों को सँभालने के लिए आप इसे शामिल कर सकते हैं:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if` एक्सप्रेशन

आधुनिक Swift में, `if` स्टेटमेंट का उपयोग एक्सप्रेशन के रूप में भी किया जा सकता है, जो एक वैल्यू देते हैं।
हर शाखा एक वैल्यू देती है, जिससे नतीजों को शर्त के आधार पर असाइन करना आसान हो जाता है:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## टर्नरी ऑपरेटर

[टर्नरी कंडीशनल ऑपरेटर][ternary-operator] `if-else` एक्सप्रेशन का एक संक्षिप्त रूप है।
यह एक शर्त को जाँचता है और उस शर्त के `true` या `false` होने के आधार पर दो वैल्यू में से एक लौटाता है।

यह ऑपरेटर तीन हिस्सों का उपयोग करता है: `condition ? trueExpression : falseExpression`.
अगर `condition` का मान `true` निकलता है, तो `trueExpression` का मान निकालकर लौटाया जाता है; वरना `falseExpression` का मान निकालकर लौटाया जाता है।

टर्नरी ऑपरेटर सरल, एक लाइन वाले चुनावों के लिए आदर्श है:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

ऊपर दिया गया उदाहरण इसके बराबर है, बस छोटे रूप में:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
