# संकेत

यह अभ्यास ऐसी परिवर्तनशील स्थिति की जाँच करता है जिसे कई थ्रेड से सुरक्षित रूप से एक्सेस किया जा सकता है। Scala में परिवर्तनशील स्थिति को सुरक्षित रखने के कई तरीके हैं। जो डेवलपर Java की कॉन्करेंसी से पहले से परिचित हैं, वे Scala में Java की कॉन्करेंसी सुविधाएँ इस्तेमाल कर सकते हैं, जैसे Java का synchronized ब्लॉक।

## आम गलतियाँ

Scala में परिवर्तनशील स्थिति पाने के दो तरीके हैं: किसी "var" का उपयोग कीजिए, या किसी परिवर्तनशील ऑब्जेक्ट का।
यहाँ दो आम गलतियाँ होती हैं:
- ऐसे "var" का उपयोग न कीजिए जो खुद भी एक परिवर्तनशील ऑब्जेक्ट हो। दोनों में से एक काफी है, पर दोनों एक साथ नहीं।
- "var" या परिवर्तनशील ऑब्जेक्ट को बाहरी दुनिया के सामने न रखिए। इसलिए उन्हें "private" बनाइए और वैल्यू लौटाने से पहले परिवर्तनशील ऑब्जेक्ट को अपरिवर्तनीय बना दीजिए।
