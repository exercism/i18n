# परिचय

Factor में ज़्यादातर डेटा *सीक्वेंस* में रहता है। ऐरे, वेक्टर और स्ट्रिंग सभी सीक्वेंस हैं, और इन सबके लिए [`sequences`][sequences] वोकैबुलरी में शब्दों का एक साझा सेट है।

## ऐरे लिटरल

एक लिटरल ऐरे में `{ }` लिखा जाता है, जिसमें एलिमेंट के बीच स्पेस छोड़ी जाती है:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

ऐरे की लंबाई तय होती है, इसलिए `suffix` और `remove-nth` जैसे शब्द, जो एलिमेंट की संख्या बदल देते हैं, मूल ऐरे को बढ़ाने के बजाय एक *नया* सीक्वेंस लौटाते हैं।

## लंबाई और इंडेक्सिंग

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` सीमा के प्रति सुरक्षित वर्शन है: पहले लंबाई जाँचे बिना भी आप किसी पोज़िशन को परख सकते हैं।

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## स्लाइसिंग

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

अगर `n` सीक्वेंस से बड़ा है, तो दोनों एरर देते हैं। अगर `n` बहुत बड़ा है, तो `index-or-length` उसे घटाकर सीक्वेंस की लंबाई तक ले आता है, ताकि उसके बाद वाला स्लाइस सीक्वेंस से आगे न निकल जाए:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

तारे वाले वेरिएंट `head*` और `tail*` अंत से गिनती करते हैं: `head*` आखिरी `n` एलिमेंट हटा देता है, और `tail*` आखिरी `n` एलिमेंट रखता है:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

दो इंडेक्स के बीच किसी भी स्लाइस के लिए, `subseq` *शुरुआत* (शामिल) और *अंत* (शामिल नहीं) लेता है:

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

जब आपके पास *शुरुआत और लंबाई* हो, तो उन्हें जोड़कर अंत निकालिए:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(यह इंडेक्स रेंज `[2, 5)` है, यानी पोज़िशन 2 से शुरू होने वाले तीन अक्षर।)

उलटा सवाल, यानी कोई सबसीक्वेंस *कहाँ* आता है, इसका जवाब `subseq-index` देता है। यह पहले मैच का शुरुआती इंडेक्स लौटाता है, और अगर कोई मैच न हो तो `f` लौटाता है:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## पैडिंग

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

दोनों `seq` को तब तक बढ़ाते हैं जब तक उसकी लंबाई कम से कम `n` न हो जाए। अगर `seq` पहले से ही इतना लंबा है, तो उसे बिना बदले लौटा दिया जाता है।

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## यही शब्द स्ट्रिंग पर भी काम करते हैं

स्ट्रिंग अक्षरों का एक सीक्वेंस है, इसलिए ऊपर बताई गई हर चीज़ स्ट्रिंग पर भी काम करती है। फर्क सिर्फ़ इतना है कि नतीजा ऐरे के बजाय एक और स्ट्रिंग होता है:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## एकत्र करना

`sum` और `product` ([`sequences`][sequences] में) किसी संख्यात्मक सीक्वेंस के एलिमेंट को जोड़ते या गुणा करते हैं:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` सीक्वेंस पर एक प्रेडिकेट चलाता है और बताता है कि कितने एलिमेंट के लिए वह सही निकला:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## पूरे सीक्वेंस पर प्रेडिकेट

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## नया सीक्वेंस बनाना

`suffix` सीक्वेंस के अंत में एक एलिमेंट जोड़ता है और `prefix` शुरुआत में एक जोड़ता है। `unclip` पहला एलिमेंट अलग करता है और `unclip-last` आखिरी:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

`unclip-last` और `suffix` को मिलाकर आखिरी एलिमेंट को बिना नष्ट किए बदला जा सकता है (`unclip` + `prefix` पहले एलिमेंट के लिए यही करता है):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## सीक्वेंस टाइप के बीच कन्वर्ज़न

`>array`, `>vector` और `>string` ([`arrays`][arrays] और उससे जुड़ी वोकैबुलरी में) किसी सीक्वेंस को ज़बरदस्ती एक खास ठोस टाइप में बदल देते हैं। यह तब काम आता है जब कोई ऑपरेशन स्लाइस या जेनेरिक सीक्वेंस लौटाए और आपको वापस ऐरे (या स्ट्रिंग) चाहिए।

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
