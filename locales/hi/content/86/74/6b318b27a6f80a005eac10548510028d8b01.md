# निर्देश

इस अभ्यास में आप न्यू यॉर्क के एक ब्यूटी सैलून के लिए अपॉइंटमेंट शेड्यूलर पर काम करेंगे। यह सैलून 15 सितंबर 2012 को खुला था।

आपको चार कार्य करने हैं, और इन सभी में अपॉइंटमेंट की तारीखें आएँगी। तारीखें और समय इन तीन में से किसी एक रूप में लिखे जाएँगे:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

टेस्ट अपने आप कल्चर को `en-US` पर सेट कर देते हैं। आपको कल्चर खुद सेट करने या बताने की ज़रूरत नहीं है।

## 1. अपॉइंटमेंट की तारीख पार्स कीजिए

(_static_) `Appointment.Schedule()` मेथड लागू कीजिए, जो अपॉइंटमेंट की तारीख के टेक्स्ट रूप को पार्स करके उसे उसी के मुताबिक `DateTime` रूप में बदल दे:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. जाँचिए कि अपॉइंटमेंट बीत चुका है या नहीं

(_static_) `Appointment.HasPassed()` मेथड लागू कीजिए, जो एक अपॉइंटमेंट की तारीख लेता है और जाँचता है कि वह अपॉइंटमेंट अतीत में कहीं हुआ था या नहीं:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. जाँचिए कि अपॉइंटमेंट दोपहर में है या नहीं

(_static_) `Appointment.IsAfternoonAppointment()` मेथड लागू कीजिए, जो एक अपॉइंटमेंट की तारीख लेता है और जाँचता है कि वह अपॉइंटमेंट दोपहर में है या नहीं (>= 12:00 और < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. अपॉइंटमेंट की तारीख और समय का वर्णन कीजिए

(_static_) `Appointment.Description()` मेथड लागू कीजिए, जो एक अपॉइंटमेंट की तारीख लेता है और उस तारीख और समय का विवरण लौटाता है:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. सालगिरह की तारीख लौटाइए

(_static_) `Appointment.AnniversaryDate()` मेथड लागू कीजिए, जो इस साल की सालगिरह की तारीख लौटाता है, यानी 15 सितंबर:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
