# टेस्ट

टेस्ट चलाने के लिए यह कमांड चलाइए:

```shell
phpunit test_file.php
```

उदाहरण के लिए, Hello World अभ्यास के टेस्ट चलाने के लिए यह कमांड इस्तेमाल कीजिए:

```shell
phpunit HelloWorldTest.php
```
