# निर्देश

न्यूयॉर्क का वह ब्यूटी सैलून, जिसकी मदद आपने बुकिंग अप फ़ॉर ब्यूटी अभ्यास में की थी, अच्छा चल रहा है और उसके कई ग्राहक अब नियमित हो गए हैं।
हर बार अलग से बुकिंग करने के बजाय नियमित ग्राहक का एक स्थायी इंतज़ाम होता है: "हर दूसरा मंगलवार", "महीने का अंतिम शुक्रवार" और इसी तरह के और भी।
सैलून के मालिक ने आपसे एक ऐसा हेल्पर बनाने को कहा है जो इन इंतज़ामों के पीछे की तारीखें निकालता है, और साथ ही सैलून के हर महीने के अपने काम की तारीखें भी।

## 1. नियमित ग्राहक की स्थायी अपॉइंटमेंट ढूँढिए

`SalonCalendar.standingAppointment()` मेथड लागू कीजिए, जो एक साल, एक महीना, कौन-सी बार (`1` पहली बार के लिए, `2` दूसरी बार के लिए, और इसी तरह) और सप्ताह का एक दिन लेता है।
यह उस महीने में सप्ताह के उस दिन की उसी बार की तारीख लौटाता है:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. नियमित ग्राहक की महीने की अंतिम अपॉइंटमेंट ढूँढिए

कुछ नियमित ग्राहक महीने में अपने दिन की अंतिम बार पसंद करते हैं।
`SalonCalendar.lastAppointment()` मेथड लागू कीजिए, जो एक साल, एक महीना और सप्ताह का एक दिन लेता है और उस महीने में सप्ताह के उस दिन की अंतिम बार की तारीख लौटाता है:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. बिना अपॉइंटमेंट आने वाले ग्राहक के लिए अगला उपलब्ध दिन ढूँढिए

फ्रंट डेस्क पर कोई ग्राहक "अगला शनिवार" माँगता है।
अगर जिस दिन वे पूछते हैं वह दिन खुद शनिवार है, तो उनका मतलब उसी दिन से है।
`SalonCalendar.nextAvailable()` मेथड लागू कीजिए, जो एक तारीख और सप्ताह का एक दिन लेता है और दी गई तारीख को या उसके बाद की पहली ऐसी तारीख लौटाता है जो सप्ताह के उस दिन पड़ती है:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. हिसाब-किताब का दिन ढूँढिए

सैलून हर महीने के अंतिम दिन अपना हिसाब-किताब बंद करता है।
लेकिन सैलून सप्ताहांत में बंद रहता है, इसलिए जब महीने का अंतिम दिन शनिवार या रविवार को पड़ता है, तो हिसाब-किताब उससे पहले वाले शुक्रवार को बंद होता है।
`SalonCalendar.bookkeepingDay()` मेथड लागू कीजिए, जो एक साल और एक महीना लेता है और उस महीने का हिसाब-किताब वाला दिन लौटाता है:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. वेतन के दिन के लिए सप्ताहांत वाला नियम दोबारा इस्तेमाल कीजिए

कर्मचारियों को हर महीने की 15 तारीख को वेतन मिलता है, उसी सप्ताहांत वाले नियम के साथ: जब 15 तारीख शनिवार या रविवार को पड़ती है, तो वेतन उससे पहले वाले शुक्रवार को मिलता है।
इस नियम को दूसरी बार लिखने के बजाय इसे एक ऐसा एडजस्टर बना दीजिए जिसे दोबारा इस्तेमाल किया जा सके।

`SalonCalendar.precedingWorkday()` मेथड लागू कीजिए, जो एक `TemporalAdjuster` लौटाता है। यह कार्यदिवस को जैसा है वैसा ही छोड़ देता है और शनिवार या रविवार को उससे पहले वाले शुक्रवार पर ले जाता है।
इसके बाद उसी एडजस्टर का इस्तेमाल करते हुए `SalonCalendar.payday()` मेथड लागू कीजिए, जो एक साल और एक महीना लेता है:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

आप चाहें तो वापस जाकर `bookkeepingDay()` में भी इस एडजस्टर का इस्तेमाल कर सकते हैं।
