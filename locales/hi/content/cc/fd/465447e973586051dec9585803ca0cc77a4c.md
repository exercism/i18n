# निर्देश परिशिष्ट

## शब्द

एक `game` ट्यूपल और एक कंस्ट्रक्टर `<game> ( -- game )` बनाइए। यह कंस्ट्रक्टर बिना किसी रोल वाला नया गेम लौटाता है।

गेम पर काम करने वाले ये शब्द दीजिए:

- `roll ( pins game -- )`: यह दर्ज करता है कि `pins` पिन गिर गए। रोल अमान्य होने पर एरर फेंकिए:
  - पिन की संख्या ऋणात्मक होने पर `"Negative roll is invalid"`।
  - जब सारे दस फ्रेम (और कोई भी फिल बॉल) रोल हो चुके हों, तब `"Cannot roll after game is over"`।
  - जब लेन पर खड़े पिनों से अधिक पिन गिर जाएँ, तब `"Pin count exceeds pins on the lane"`।
- `score ( game -- n )`: गेम का कुल स्कोर। जब गेम अभी पूरा न हुआ हो, तब `"Score cannot be taken until the end of the game"` फेंकिए।

ध्यान दीजिए कि यहाँ `roll` नाम `kernel` शब्दावली के `roll` शफल शब्द को छिपा देता है। टेस्ट सूट `FROM: bowling => roll ;` लिखकर यह स्पष्ट करता है कि किस `roll` का इस्तेमाल करना है।
