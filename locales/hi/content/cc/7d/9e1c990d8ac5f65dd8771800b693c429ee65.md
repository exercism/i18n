# निर्देशों का परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग        | टाइप    | विवरण                                   |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | इनपुट        | एड्रेस  | नल पर समाप्त होने वाली इनपुट स्ट्रिंग     |
| `$a1`    | इनपुट/आउटपुट  | एड्रेस  | अंतिम न्यूक्लियोटाइड गणनाओं वाला वर्ड ऐरे |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए                    |
