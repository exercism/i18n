# परिचय

PowerShell, Microsoft की एक स्क्रिप्टिंग भाषा है जो डायनामिक रूप से इम्प्लिसिट टाइपिंग करती है (स्ट्रांग टाइप वाले वेरिएबल भी समर्थित हैं)। यह मुख्य रूप से कामों को अपने आप चलाने और कॉन्फ़िगरेशन प्रबंधन पर केंद्रित है।

PowerShell इम्परेटिव, फंक्शनल और ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग का समर्थन करता है, और पाइपलाइन शैली का भी।

PowerShell को .NET प्लेटफ़ॉर्म पर बनाया गया था और इसे पहली बार 2006 में जारी किया गया था।
यह सभी आधुनिक Windows OS में डिफ़ॉल्ट रूप से शामिल रहा है, और इसे Mac तथा Linux पर इंस्टॉल किया जा सकता है।


## वेरिएबल

PowerShell में वेरिएबल बनाने के दो आम तरीके हैं।

PowerShell में वेरिएबल के नाम की शुरुआत `$` से होनी चाहिए, और असाइनमेंट ऑपरेटर `=` की मदद से वेरिएबल के नाम को एक वैल्यू से जोड़ा जाता है।

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

अगर आप किसी खास [टाइप][strong typed] को लागू करना चाहते हैं, तो आप वेरिएबल का टाइप साफ़-साफ़ बता भी सकते हैं।
अगर संभव हो, तो PowerShell वैल्यू को एक टाइप से दूसरे टाइप में बदलने की पूरी कोशिश करता है।

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### कॉन्स्टेंट

PowerShell में कॉन्स्टेंट ऐसे रीड-ओनली वेरिएबल होते हैं जिन्हें बनाए जाने के बाद **हटाया** नहीं जा सकता।
यही हमें वेरिएबल बनाने का दूसरा तरीका दिखाता है, जिसमें हम `New-Variable` कमांडलेट का उपयोग करते हैं।

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

अलग-अलग विकल्पों के साथ नया वेरिएबल बनाने के ज़्यादा विस्तृत और उन्नत तरीके के लिए [New-Variable][New-Variable] कमांडलेट देखिए।


## फंक्शन

PowerShell में [फंक्शन][functions] `function` कीवर्ड की मदद से बनाए जाते हैं।
हर फंक्शन में `()` कोष्ठकों के अंदर शून्य या उससे अधिक औपचारिक [पैरामीटर][parameters] हो सकते हैं, और उसके बाद उसका अपना [स्कोप][scope] होता है जो `{` से शुरू होकर `}` पर खत्म होता है।

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell में फंक्शन को `FuncName $Arg` सिंटैक्स से कॉल करने के बाद, `return` कीवर्ड की मदद से वैल्यू साफ़ तौर पर लौटाई जा सकती है।

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

विस्तृत फंक्शन परिभाषा कैसे लिखें, और फंक्शन वैल्यू को इम्प्लिसिट रूप से कैसे लौटाते हैं, इस पर एक उन्नत नज़र `Functions` कॉन्सेप्ट मॉड्यूल में डाली जाएगी।


## कमेंट

PowerShell में सिंगल कमेंट `#` से शुरू होता है और लाइन खत्म होने पर समाप्त हो जाता है।
PowerShell में कमेंट ब्लॉक `<#` से शुरू होता है और `#>` पर खत्म होता है।
कमेंट ब्लॉक से Comment-Based Help बनाने का एक उन्नत उदाहरण `Functions` कॉन्सेप्ट मॉड्यूल में दिया जाएगा।

```powershell
function Main() {
    #This is a comment
}
```
