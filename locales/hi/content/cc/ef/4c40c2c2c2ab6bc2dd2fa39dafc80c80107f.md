# आर्मस्ट्रांग संख्याओं की अवधारणाएँ

> एक [आर्मस्ट्रांग संख्या](https://en.wikipedia.org/wiki/Narcissistic_number) वह संख्या होती है जो अपने हर अंक को अंकों की संख्या की घात तक उठाकर जोड़ने पर मिलने वाले जोड़ के बराबर होती है।

## उदाहरण हल

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## अवधारणाएँ

- फंक्शन: हल जाँचने और लॉजिक परिभाषित करने के लिए आवश्यक
- टेस्ट सुइट: हल जाँचने के लिए आवश्यक
- पूर्णांक: आर्गुमेंट और समानता की जाँच के लिए u32
- `&str`: संख्या की लंबाई गिनने के लिए आवश्यक, क्योंकि Rust में टाइप की कड़ी जाँच होती है
- `Option<T>`: `char::to_digit` की असली वैल्यू तक पहुँचने के लिए आवश्यक
- टाइप कास्टिंग: अंकगणितीय संक्रियाएँ करने के लिए आवश्यक
- इटरेटर की सुविधाएँ:
  - टर्बोफिश, ताकि हल एक ही एक्सप्रेशन में लिखा जा सके
  - `map` और `sum`, जिनसे एक्सप्रेशन को आसानी से उस वैल्यू तक लाया जा सके जिस पर हमें जाँच करनी है
