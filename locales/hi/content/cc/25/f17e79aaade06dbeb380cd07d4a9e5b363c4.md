# निर्देश

हाल ही में आपने जो रिमोट कंट्रोल कार खरीदी थी, वह अब एक नए शौक में बदल गई है। आप रिमोट कंट्रोल कारों की रेसें आयोजित करते आ रहे हैं।

आप एक ऐसा प्रोग्राम लिखने ही वाले थे जिससे रेस के सिमुलेशन चलाए जा सकें, तभी आपकी बिल्ली कीबोर्ड पर कूद पड़ी और कोड की कुछ लाइनें मिटा दीं। अब आपका प्रोग्राम कंपाइल ही नहीं होता...

## 1. कंपाइल एरर ठीक कीजिए `Race.__struct__/0 is undefined`

एक alias जोड़िए ताकि मॉड्यूल `NeedForSpeed.Race` को छोटे नाम `Race` से संदर्भित किया जा सके।

## 2. कंपाइल एरर ठीक कीजिए `Car.__struct__/0 is undefined`

एक alias जोड़िए ताकि मॉड्यूल `NeedForSpeed.RemoteControlCar` को छोटे नाम `Car` से संदर्भित किया जा सके।

## 3. कंपाइल एरर ठीक कीजिए `undefined function puts/1`

फंक्शन `puts/1` मॉड्यूल `IO` से आता है। इसे import कीजिए ताकि मॉड्यूल का नाम लिए बिना इसका उपयोग किया जा सके।

## 4. कंपाइल एरर ठीक कीजिए `undefined function default_color/0`

फंक्शन `default_color/0`, `red/0`, `cyan/0` और `green/0` सभी मॉड्यूल `IO.ANSI` से आते हैं। आप कार के दूसरे रंगों के लिए समर्थन जोड़ने की योजना बना रहे हैं, इसलिए आप पूरा मॉड्यूल import करना चाहते हैं। दुर्भाग्य से, मॉड्यूल `IO.ANSI` का फंक्शन `color/1` आपके किसी स्थानीय फंक्शन से टकराता है। उस एक फंक्शन को छोड़कर पूरा `IO.ANSI` मॉड्यूल import कीजिए।
