# परिचय

C++ में बूलियन को `bool` टाइप से दर्शाया जाता है।
एक `bool` या तो `true` होता है या `false`।

## तार्किक ऑपरेटर

C++ तीन बूलियन ऑपरेटरों का समर्थन करता है: `!` (NOT), `&&` (AND), और `||` (OR)।
आप इनके वैकल्पिक रूप `not`, `and` और `or` भी इस्तेमाल कर सकते हैं।

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## प्राथमिकता

तीनों बूलियन ऑपरेटरों की _ऑपरेटर प्राथमिकता_ अलग-अलग होती है।
इसका नतीजा यह है कि इनका मूल्यांकन इस क्रम में होता है: पहले `!`, फिर `&&`, और अंत में `||`।
अगर आप क्रम बदलना चाहते हैं, तो किसी बूलियन एक्सप्रेशन को गोल ब्रैकेट (यानी `()`) में बंद कर सकते हैं, क्योंकि ब्रैकेट की ऑपरेटर प्राथमिकता इनसे भी ऊँची होती है।

```cpp
!true && false   // => false
!(true and false) // => true
```

## रूपांतरण

अगर आप `true` या `false` का इस्तेमाल ऐसी जगह करते हैं जहाँ संख्या की उम्मीद होती है, तो इन्हें क्रमशः `1` और `0` में बदल दिया जाता है।
अगर आप किसी बूलियन ऑपरेशन में कोई संख्या इस्तेमाल करते हैं, तो `0` को छोड़कर बाकी सब कुछ `true` माना जाता है, ऋणात्मक वैल्यू भी।

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
