# निर्देश

इस अभ्यास में आप अपॉइंटमेंट संभालने के लिए कुछ फंक्शन पर काम करेंगे। यह सिस्टम हर चीज़ को ISO 8601 फॉर्मेट की स्ट्रिंग में रखता है, लेकिन लोग कैलेंडर का इस्तेमाल इस तरह नहीं करते। अलग-अलग फॉर्मेट के बीच बदलने के लिए कई फंक्शन ज़रूरी हैं।

## 1. अपॉइंटमेंट बनाइए

अभी से `n` दिन बाद, वर्तमान समय पर एक अपॉइंटमेंट बनाइए। यह फंक्शन `n` दिन लेता है और अभी से `n` दिन बाद का अपॉइंटमेंट समय लौटाता है।

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

अगर दूसरा पैरामीटर `now` इस्तेमाल नहीं किया गया है, तो उसकी जगह वर्तमान समय लिया जाना चाहिए।

## 2. तारीख को टाइमस्टैम्प में बदलिए

कई टूल सिर्फ अंतरराष्ट्रीय स्तर पर मानकीकृत ISO 8601 फॉर्मेट के साथ ही काम करते हैं। `getAppointmentTimestamp` फंक्शन लिखिए, जो एक तारीख ले और उस फॉर्मेट में एक स्ट्रिंग लौटाए।

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. अपॉइंटमेंट की जानकारी निकालिए

टाइमस्टैम्प पढ़ना मुश्किल होता है, इसलिए अपॉइंटमेंट की जानकारी निकालने वाला फंक्शन इसमें मदद करेगा। `getAppointmentDetails` फंक्शन ISO 8601 फॉर्मेट का एक टाइमस्टैम्प लेता है और वर्ष, महीना, तारीख, घंटा और मिनट लौटाता है।

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. दिए गए विकल्पों के अनुसार अपॉइंटमेंट बदलिए

यह फंक्शन पहले आर्गुमेंट के रूप में अपॉइंटमेंट का समय लेगा और दूसरे आर्गुमेंट के रूप में कुछ विकल्पों का ऑब्जेक्ट। आपको ऑब्जेक्ट में दिए गए विकल्पों के अनुसार अपॉइंटमेंट बदलना है और उसकी नई तारीख लौटानी है। विकल्पों के ऑब्जेक्ट में एक से अधिक विकल्प हो सकते हैं।

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. दो अपॉइंटमेंट के बीच उपलब्ध समय निकालिए

यह फंक्शन आर्गुमेंट के रूप में दो अपॉइंटमेंट (टाइमस्टैम्प) लेगा। आपको उन दोनों समयों के बीच का अंतर सेकंड में लौटाना है।

आधा सेकंड लगभग बेमानी है, इसलिए संख्या को लौटाने से पहले पूर्णांकित कर दीजिए।

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. जाँचिए कि अपॉइंटमेंट अभी मान्य है या नहीं

अंत में, अपॉइंटमेंट बन जाने के बाद सिस्टम को जाँचना होता है कि वह मान्य है या नहीं। दूसरे शब्दों में, अपॉइंटमेंट भविष्य में होना चाहिए, बीते समय में नहीं।

`isValid` फंक्शन लिखिए, जो दो आर्गुमेंट लेता है: अपॉइंटमेंट का टाइमस्टैम्प (स्ट्रिंग) और वर्तमान समय का टाइमस्टैम्प (स्ट्रिंग)। अगर वर्तमान समय के हिसाब से अपॉइंटमेंट भविष्य में है, तो यह `true` लौटाता है।

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
