# परिचय

[गार्ड][guards] [पैटर्न मैचिंग][exercism-pattern-matching] के पूरक के रूप में इस्तेमाल किए जाते हैं। इनसे और भी जटिल जाँच संभव हो जाती है। जहाँ पैटर्न मैचिंग इस्तेमाल की जा सकती है, वहाँ गार्ड भी [कुछ स्थितियों में, पर सभी में नहीं][where-guards-can-be-used], इस्तेमाल किए जा सकते हैं। जैसे फंक्शन क्लॉज़ या केस क्लॉज़ में।

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- गार्ड `when` कीवर्ड से शुरू होते हैं, और उसके बाद एक बूलियन एक्सप्रेशन आता है।
- गार्ड एक्सप्रेशन कुछ खास फंक्शन होते हैं, जो:
  - इन्हें [प्योर][pure-function] होना चाहिए और किसी भी ग्लोबल स्थिति को नहीं बदलना चाहिए।
  - इन्हें सख्त `true` या `false` वैल्यू ही लौटानी चाहिए।
- आम गार्ड की सूची [Elixir के डॉक्युमेंटेशन][kernel-guards] में मिलती है। इनमें ये शामिल हैं:
  - टाइप जाँच: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] आदि।
  - अंकगणितीय ऑपरेटर: [`+/2`][guard-plus], [`-/2`][guard-minus] आदि।
  - तुलना: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] आदि।
  - बूलियन ऑपरेटर: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - सदस्यता ऑपरेटर: [`in/2`][guard-in]
- आप [`defguard`][defguard] की मदद से अपने खुद के गार्ड बना सकते हैं।

  - Elixir के [नेमिंग कन्वेंशन][naming] के अनुसार, गार्ड के नाम `is_` से शुरू होने चाहिए।

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
