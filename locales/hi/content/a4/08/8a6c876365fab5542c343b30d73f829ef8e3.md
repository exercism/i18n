# एनम

एनम Cairo का एक डेटा टाइप है जिसका उपयोग पहले से तय किए गए वेरिएंट के समूह को परिभाषित करने के लिए किया जाता है, ताकि कोड पढ़ने में आसान और सुरक्षित बना रहे।
Cairo में `enum` के वेरिएंट को अलग-अलग डेटा टाइप रखने के लिए घोषित किया जा सकता है (पूर्णांक, स्ट्रक्ट, टपल, अन्य एनम, आदि)।

नीचे दिया गया कोड दिखाता है कि एनम को कैसे परिभाषित किया जा सकता है:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

ऊपर घोषित किया गया `Direction` एनम एक सरल एनम है जिसमें चार वेरिएंट हैं: `North`, `East`, `South` और `West`.
एनम के वेरिएंट के लिए नाम रखने का तरीका यह है कि PascalCase का उपयोग किया जाए।
हर वेरिएंट `Direction` एनम टाइप की एक अलग वैल्यू दर्शाता है।
इस एनम के उदाहरण में हर वेरिएंट की कोई जुड़ी हुई वैल्यू नहीं है, और इसे इस सिंटैक्स से बनाया जा सकता है:

```rust
let direction = Direction::North;
```

नीचे वही `Direction` एनम है, लेकिन इसके वेरिएंट के साथ वैल्यू जुड़ी हुई हैं, जो दिशा की सटीक डिग्री रखती हैं:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

इस उदाहरण से साफ है कि `Direction` एनम के हर वेरिएंट के साथ `u128` की वैल्यू जुड़ी हुई है।
इस तरह के एनम को इस तरह बनाया जा सकता है:

```rust
let direction = Direction::North(10);
```

## कस्टम टाइप के साथ जटिल एनम का उदाहरण

किसी एनम को उसके वेरिएंट के रूप में अलग-अलग डेटा टाइप के मेल के साथ घोषित किया जा सकता है।
नीचे दिए गए उदाहरण में `Action` एक जटिल एनम है जिसके वेरिएंट `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` और `ProfileState` हैं।

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## एनम के लिए ट्रेट इम्प्लीमेंटेशन

Cairo में कस्टम एनम के लिए ट्रेट परिभाषित किए जा सकते हैं और उन्हें लागू किया जा सकता है।
इससे आप किसी एनम से जुड़े मेथड और एट्रिब्यूट परिभाषित कर सकते हैं।
नीचे इसका एक उदाहरण है, जिसमें हम एक `Message` एनम बनाते हैं और उसके लिए `Processing` ट्रेट लागू करते हैं:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

इस ट्रेट का उपयोग करके `Quit` संदेश को कैसे प्रोसेस किया जा सकता है, वह यहाँ दिखाया गया है:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

कई जगहों पर एनम बहुत काम आते हैं, खासकर तब जब इन्हें `match` फ्लो के साथ इस्तेमाल किया जाए, जैसा ऊपर ट्रेट के इम्प्लीमेंटेशन में किया गया है।
`match` फ्लो के बारे में और पढ़ने के लिए [The Cairo Book][match] देखिए।
