# परिचय

Elm भरोसेमंद वेब एप्लिकेशन बनाने के लिए एक आनंददायक भाषा है।
इसमें एरर संदेश दोस्ताना होते हैं, परफॉर्मेंस शानदार है, एसेट छोटे होते हैं, और रनटाइम एक्सेप्शन नहीं होते।

Elm का शायद सबसे प्रसिद्ध और सबसे ज़्यादा अपनाया गया हिस्सा The Elm Architecture है। यह वेब एप्लिकेशन को व्यवस्थित करने का एक आसान तरीका है, और सभी Elm वेब एप्लिकेशन इसी तरीके से लिखे जाते हैं।

मूल विचार यह है कि आपका कोड तीन चीज़ों के इर्द-गिर्द बनता है: आपके एप्लिकेशन की स्थिति का एक `Model`, अपने मॉडल को `update` करने का एक तरीका, और अपने मॉडल को `view` करने का एक तरीका।

`Model` में एप्लिकेशन की स्थिति होती है, यानी वह सारा डेटा जो एप्लिकेशन को चाहिए।
यह किसी भी टाइप का हो सकता है, लेकिन किसी भी काम के एप्लिकेशन में यह आमतौर पर एक [record][record] होता है।
मान लीजिए आप एक आसान एप्लिकेशन की कल्पना करते हैं जिसमें एक टेक्स्ट बॉक्स होता है, और एक टेक्स्ट होता है जो उस टेक्स्ट को उल्टा दिखाता है। ऐसे में मॉडल कुछ इस तरह दिखेगा।
आप यह उदाहरण [Elm Guide][elm-guide-text-fields] पर भी देख सकते हैं।

```elm
type alias Model =
  { text : String
  }
```

`update` एक फंक्शन है। जब कोई बदलाव होता है (जैसे उपयोगकर्ता किसी बटन पर क्लिक करता है), तो इसे एक `Msg` के साथ कॉल किया जाता है।
यह `Msg` और मौजूदा `Model` लेता है, और एक नया `Model` लौटाता है।
`Msg` किसी भी टाइप का हो सकता है, लेकिन आमतौर पर यह एक [custom type][custom-type] होता है।

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

सभी custom type की तरह, `Msg` के अलग-अलग वेरिएंट जितनी मनमानी जानकारी चाहें उतनी अपने अंदर रख सकते हैं।
ऊपर के उदाहरण में `TextChanged` वेरिएंट के अंदर एक `String` है।

`view` एक फंक्शन है जो उपयोगकर्ता को ब्राउज़र में दिखाने के लिए HTML लौटाता है।
यह मौजूदा `Model` लेता है और एक `Html Msg` लौटाता है (वह टाइप जिसका इस्तेमाल Elm HTML को दर्शाने के लिए करता है)।
हर HTML एलिमेंट (जैसे `<div>`) के लिए `Html` पैकेज में उससे जुड़ा एक Elm फंक्शन होता है (`Html.div`).
इनमें से हर फंक्शन दो पैरामीटर लेता है। पहला एट्रिब्यूट का एक ऐरे है (`Html.Attributes` और `Html.Events` पैकेज से), और दूसरा चाइल्ड एलिमेंट का एक ऐरे है (`Html` पैकेज के फंक्शन)।
एक `text` फंक्शन भी है जो HTML स्ट्रिंग कॉन्टेंट को दर्शाता है। यह सिर्फ एक स्ट्रिंग पैरामीटर लेता है, लेकिन बाकी सब तरह से `Html` पैकेज के अन्य सभी फंक्शन या एलिमेंट की तरह ही इस्तेमाल होता है।

`view` फंक्शन यह बता सकता है कि कुछ इवेंट, जैसे किसी बटन पर क्लिक करना या टेक्स्ट बॉक्स में टेक्स्ट बदलना, एक `Msg` बनाते हैं। Elm Runtime इस `Msg` का इस्तेमाल करके `update` फंक्शन को कॉल करता है, `Model` को बदलता है और अपडेट किया हुआ HTML बनाता है।
नीचे दिए गए कोड में यह `Html.Events.onInput TextChanged` से होता है।

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

`Html.Events.onInput` को एक फंक्शन (`String -> Msg`) दिया जाना चाहिए, जिसका इस्तेमाल वह `Msg` बनाने के लिए करता है।
अलग-अलग इवेंट अलग-अलग फंक्शन चाहते हैं, यह इस पर निर्भर करता है कि वे कौन-सी जानकारी दे सकते हैं। जैसे `Html.Events.onCheck` (चेकबॉक्स के लिए) `Bool -> Msg` चाहता है, और `Html.Events.onClick` सिर्फ एक `Msg` चाहता है।

Elm भाषा प्योर और फंक्शनल है, और इसमें कुछ भी बदला नहीं जा सकता। इसलिए बदलने वाली सारी चीज़ें Elm Runtime खुद संभालता है।
Elm पैकेज रजिस्ट्री पर आप अलग-अलग [HTML Elements][html-elements], [Element Attributes][element-attributes] और [HTML Events][html-events] देख सकते हैं।

Elm में आप वेब एप्लिकेशन के चार "लेवल" लिख सकते हैं, जो क्रमशः ज़्यादा शक्तिशाली और ज़्यादा जटिल होते जाते हैं (हालाँकि Elm आज भी एक बहुत ही सरल भाषा और इकोसिस्टम बना हुआ है)।
ये सभी [Browser package][browser-package] में परिभाषित हैं:

- [sandbox][browser-sandbox]: उपयोगकर्ता के इनपुट, जैसे बटन और चेकबॉक्स, पर प्रतिक्रिया देना
- [element][browser-element]: HTTP और JavaScript इंटरऑप की मदद से बाहरी दुनिया से बात करना
- [document][browser-document]: वेब पेज के `<title>` और `<body>` को नियंत्रित करना
- [application][browser-application]: राउटिंग या यूआरएल बदलाव संभालने वाले पूरे सिंगल-पेज एप्लिकेशन बनाना

यह कॉन्सेप्ट [sandbox][browser-sandbox] का इस्तेमाल करता है, क्योंकि यह सबसे आसान है (और चूँकि यह एक sandbox है, इसके साथ Exercism के ऑनलाइन एडिटर में काम करना काफी आसान है)।
Elm प्रोग्राम का एंट्री मॉड्यूल `Main` कहलाना चाहिए, और एप्लिकेशन बनाने वाले फंक्शन का नाम `main` होना चाहिए, जैसा नीचे दिखाया गया है।

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

हम `update` और `view` फंक्शन पहले ही देख चुके हैं। [sandbox][browser-sandbox] को इसके अलावा एक `init` फंक्शन भी चाहिए, जो `Model` की शुरुआती स्थिति लौटाता है।
