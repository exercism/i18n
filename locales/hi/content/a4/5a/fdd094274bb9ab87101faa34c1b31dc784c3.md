# नल

नल एक प्रिमिटिव वैल्यू टाइप है, जिसमें केवल एक ही वैल्यू होती है: `null`।
नल का उपयोग अक्सर कुछ न होने को दर्शाने के लिए किया जाता है।
इसे "फॉल्सी" माना जाता है, लेकिन यह `false` और अन्य फॉल्सी वैल्यू से अलग है।

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## नल वैल्यू के साथ काम करना

PHP में, नल वैल्यू अक्सर एरर का एक आम कारण हो सकती हैं, क्योंकि इन्हें अक्सर एरर की स्थिति के बदले या कुछ न होने को दर्शाने के लिए लौटाया जाता है।

एरर उत्पन्न होने से रोकने के लिए अक्सर "नल-जाँच" की ज़रूरत होती है, ताकि किसी वैल्यू पर काम करने से पहले यह सुनिश्चित किया जा सके कि वह नल नहीं है।

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

बार-बार नल-जाँच करना एरर होने की संभावना वाला हो सकता है, इसलिए PHP नल वैल्यू के साथ काम करने के लिए दो ऑपरेटर प्रदान करता है: नल-सेफ एक्सेस `?->` ऑपरेटर और नल कोलेसिंग `??` ऑपरेटर।

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
