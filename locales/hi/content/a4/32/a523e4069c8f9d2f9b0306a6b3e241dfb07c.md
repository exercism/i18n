# परिचय

## टाइप अलियास

Gleam में टाइप अलियास की मदद से किसी ऐसे मौजूदा टाइप को सुविधाजनक नाम दिया जा सकता है, जिसे वरना लिखना बोझिल होता है।

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

जब इसे `pub type` के साथ लिखा जाता है, तो अलियास उस मॉड्यूल के बाहर भी इस्तेमाल किया जा सकता है जिसमें इसे बनाया गया है। अगर `pub` हटा दिया जाए, तो अलियास निजी रहता है और दूसरे मॉड्यूल में उसका संदर्भ नहीं दिया जा सकता।
