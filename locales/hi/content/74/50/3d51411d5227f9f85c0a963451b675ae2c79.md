# विवरण

जो डेटा स्ट्रक्चर शून्य या उससे अधिक एलिमेंट रख सकते हैं, उन्हें _कलेक्शन_ कहा जाता है। **ऐरे** एक ऐसा कलेक्शन है जिसका आकार या लंबाई तय होती है और जिसके सारे एलिमेंट एक ही टाइप के होने चाहिए। इंडेक्स की मदद से एलिमेंट को ऐरे में असाइन किया जा सकता है या ऐरे से निकाला जा सकता है। C# के ऐरे ज़ीरो-बेस्ड होते हैं, यानी पहले एलिमेंट का इंडेक्स हमेशा शून्य होता है:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

ऐरे को एक शॉर्टकट नोटेशन की मदद से भी बनाया जा सकता है, जिससे आप ऐरे बनाने के साथ-साथ उसकी वैल्यू भी तय कर सकते हैं। चूँकि अब कंपाइलर बता सकता है कि ऐरे में कितने एलिमेंट होंगे, इसलिए लंबाई लिखना छोड़ा जा सकता है:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

ऐरे पर काम करने के लिए आप ऐरे इंस्टेंस के [मेथड][array-methods] या [प्रॉपर्टी][array-properties] कॉल कर सकते हैं, या [`Array` क्लास][array-class] में बने स्टैटिक मेथड इस्तेमाल कर सकते हैं।

## इटरेशन

ऐरे एक _कलेक्शन_ भी है, यानी आप एक [`foreach` लूप][foreach-statement] की मदद से उसकी _सारी_ वैल्यू पर इटरेशन कर सकते हैं:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

ऐरे पर इटरेशन करने के लिए [`for` लूप][for-statement] भी इस्तेमाल किया जा सकता है:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

लेकिन आम तौर पर नीचे दिए कारणों से `for` लूप की जगह `foreach` लूप बेहतर रहता है:

- `foreach` लूप _सारी_ वैल्यू पर इटरेशन करता है, इसकी गारंटी होती है। `for` लूप में एलिमेंट छूट जाना आसान है, जैसे ऑफ-बाय-वन एरर की वजह से।
- `foreach` लूप ज़्यादा _डिक्लेरेटिव_ होता है, यानी आपका कोड बताता है कि आप उससे _क्या_ करवाना चाहते हैं, वहीं `for` लूप बताता है कि आप यह _कैसे_ करना चाहते हैं।
- `foreach` लूप में गलती की गुंजाइश नहीं होती, जबकि `for` लूप में ऑफ-बाय-वन एरर हो जाना आसान है।
- `foreach` लूप हर तरह के कलेक्शन पर काम करता है, उन पर भी जो एलिमेंट तक पहुँचने के लिए इंडेक्सर के इस्तेमाल का समर्थन नहीं करते।

यह गारंटी देने के लिए कि `foreach` लूप _सारी_ वैल्यू पर इटरेशन करेगा, कंपाइलर `foreach` लूप के अंदर कलेक्शन को अपडेट करने की अनुमति नहीं देता:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

कुछ जगहों पर `for` लूप `foreach` लूप से बेहतर होता है:

- आप जिस इंडेक्स से चाहें, वहीं से शुरू या बंद कर सकते हैं।
- लूप को रोकने के लिए आप जो चाहें (बूलियन) शर्त इस्तेमाल कर सकते हैं।
- लूप वेरिएबल को बढ़ाने का तरीका बदलकर आप कुछ एलिमेंट छोड़ सकते हैं।
- उलटी गिनती करके आप कलेक्शन को पीछे से आगे की ओर प्रोसेस कर सकते हैं।
- ऐसी जगहों पर भी, जहाँ कलेक्शन शामिल नहीं होते, आप `for` लूप इस्तेमाल कर सकते हैं।

संबंधित विषय:

- आपको यह जानना चाहिए कि C# [मल्टी-डायमेंशनल ऐरे][multi-dimensional-arrays] का समर्थन करता है, जैसे `int[,] arr = new int[10, 5]`, जो बहुत काम के हो सकते हैं।
- आपको यह भी जानना चाहिए कि `Array.CreateInstance` की मदद से [`System.Array`][system-array-object] टाइप के ऑब्जेक्ट बनाए जा सकते हैं। ऐसे ऑब्जेक्ट ज़्यादा काम के नहीं होते, ये मुख्य रूप से VB.NET कोड के साथ इंटरॉप के लिए होते हैं। इन्हें सामान्य ऐरे (`T[]`) के बदले इस्तेमाल नहीं किया जा सकता। इनकी निचली सीमा शून्य के अलावा भी हो सकती है।
