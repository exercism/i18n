# निर्देश

इस अभ्यास में आपको क्लासिक गेम Pac-Man के कुछ नियमों को C++ फंक्शन में बदलना है।

आपको चार नियम बदलने हैं, और ये सभी गेम की स्थितियों से जुड़े हैं।

> इस बात की चिंता न कीजिए कि ये आर्गुमेंट कैसे निकाले जाते हैं। बस इन आर्गुमेंट को मिलाकर अपेक्षित परिणाम लौटाने पर ध्यान दीजिए।

## 1. तय कीजिए कि Pac-Man भूत खाता है या नहीं

`can_eat_ghost` फंक्शन बनाइए। यह दो आर्गुमेंट लेता है (अगर Pac-Man का कोई पावर पेलेट सक्रिय है, और अगर Pac-Man किसी भूत को छू रहा है) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man भूत खा सकता है या नहीं। यह फंक्शन सही तभी लौटाना चाहिए जब Pac-Man का कोई पावर पेलेट सक्रिय हो और वह किसी भूत को छू रहा हो।

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. तय कीजिए कि Pac-Man स्कोर करता है या नहीं

`scored` फंक्शन बनाइए। यह दो आर्गुमेंट लेता है (अगर Pac-Man किसी पावर पेलेट को छू रहा है, और अगर Pac-Man किसी बिंदु को छू रहा है) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man ने स्कोर किया या नहीं। यह फंक्शन सही तब लौटाना चाहिए जब Pac-Man किसी पावर पेलेट या किसी बिंदु को छू रहा हो।

```cpp
scored(true, true);
// => true
```

## 3. तय कीजिए कि Pac-Man हारता है या नहीं

`lost` फंक्शन बनाइए। यह दो आर्गुमेंट लेता है (अगर Pac-Man का कोई पावर पेलेट सक्रिय है, और अगर Pac-Man किसी भूत को छू रहा है) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man हारता है या नहीं। यह फंक्शन सही तब लौटाना चाहिए जब Pac-Man किसी भूत को छू रहा हो और उसका कोई पावर पेलेट सक्रिय न हो।

```cpp
lost(false, true);
// => true
```

## 4. तय कीजिए कि Pac-Man जीतता है या नहीं

`won` फंक्शन बनाइए। यह तीन आर्गुमेंट लेता है (अगर Pac-Man सारे बिंदु खा चुका है, अगर Pac-Man का कोई पावर पेलेट सक्रिय है, और अगर Pac-Man किसी भूत को छू रहा है) और बूलियन वैल्यू लौटाता है, जो बताती है कि Pac-Man जीतता है या नहीं। यह फंक्शन सही तब लौटाना चाहिए जब Pac-Man सारे बिंदु खा चुका हो और भाग 3 में बताए गए आर्गुमेंट के आधार पर वह हारा न हो।

```cpp
won(false, true, false);
// => false
```
