# परिचय

प्रोग्रामिंग में टेक्स्ट के साथ काम करना आम बात है।
Swift, Foundation फ्रेमवर्क के साथ, स्ट्रिंग को जाँचने, बदलने और संभालने के लिए कई सुविधाजनक मेथड और प्रॉपर्टी देता है।

## `components(separatedBy:)` से स्ट्रिंग को बाँटना

किसी स्ट्रिंग को डेलिमिटर के आधार पर सबस्ट्रिंग के ऐरे में बाँटने के लिए `components(separatedBy:)` का इस्तेमाल कीजिए (इसके लिए Foundation इम्पोर्ट करना आवश्यक है):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## `hasPrefix(_:)` और `hasSuffix(_:)` से प्रीफिक्स और सफिक्स जाँचना

यह जाँचने के लिए कि कोई स्ट्रिंग किसी खास अक्षर-क्रम से शुरू होती है या उस पर खत्म होती है, `hasPrefix(_:)` और `hasSuffix(_:)` का इस्तेमाल कीजिए:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## केस बदलना

आप इन स्टैंडर्ड मेथड और प्रॉपर्टी की मदद से स्ट्रिंग का केस बदल सकते हैं:

- `lowercased()`: स्ट्रिंग की लोअरकेस कॉपी लौटाता है।
- `uppercased()`: स्ट्रिंग की अपरकेस कॉपी लौटाता है।
- `capitalized`: ऐसी कॉपी देता है जिसमें हर शब्द का पहला अक्षर कैपिटल होता है (Foundation से)।

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## `replacingOccurrences(of:with:)` से सबस्ट्रिंग बदलना

किसी लक्ष्य सबस्ट्रिंग को हर जगह दूसरी स्ट्रिंग से बदलने के लिए `replacingOccurrences(of:with:)` का इस्तेमाल कीजिए (Foundation से):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## `joined(separator:)` से स्ट्रिंग जोड़ना

`joined(separator:)` मेथड स्ट्रिंग के कलेक्शन पर काम करता है, जैसे `[String]`।
यह सभी एलिमेंट को सेपरेटर की मदद से जोड़कर एक ही स्ट्रिंग बना देता है:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
