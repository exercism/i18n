# PaySwitch - वेतन कन्वर्टर

## समस्या विवरण

**Insure Everyone** नाम की एक कंपनी अपने कर्मचारियों को विदेशी मुद्राओं में वेतन देती है। लेकिन कानूनी ज़रूरतों की वजह से वेतन को स्थानीय मुद्रा में बदलना ज़रूरी है। इसके कर्मचारी दुनिया भर में फैले हुए हैं।
Insure Everyone का मानव संसाधन विभाग एक प्रतिभाशाली डेवलपर से मदद माँग रहा है, ताकि एक ऐसा प्रोग्राम बनाया जा सके जो हर कर्मचारी के वेतन को उसकी संबंधित स्थानीय मुद्रा में बदल दे। Insure Everyone किसी बाहरी API से मिलने वाली विनिमय दरों पर निर्भर करती है।

बाहरी विनिमय दर API को देखते हुए, आपको एक फंक्शन लिखना है। यह फंक्शन `source currency`, `salary` (स्रोत मुद्रा में) और कर्मचारी की `local currency` लेता है, और वेतन को स्थानीय मुद्रा में लौटाता है।

## प्रतिबंध

* 500 <= `salary` <= 10000
* `sourceCurrency` और `targetCurrency` [ISO मुद्रा कोड (वर्णानुक्रमिक)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) हैं। टेस्ट इनपुट में अमान्य मुद्रा कोड भी हो सकते हैं।
* लौटाई गई दर की सटीकता `5` दशमलव स्थानों तक मापी जाएगी।

* लक्ष्य मुद्रा: GBP

#### आउटपुट:

मान लीजिए कि बाहरी मुद्रा विनिमय ने यह रूपांतरण दरों वाला जवाब दिया (छोड़ा गया):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

फंक्शन को `735.84000` लौटाना चाहिए
