# निर्देश

इस अभ्यास में आप [गो के खेल के नियम](https://matmoore.github.io/learngo/) लागू करेंगे। नियम तो पहले से लिखे हुए हैं। आपको बस उन्हें लागू करना है, ताकि आप `Game` को अपडेट कर सकें और नियमों के किसी भी एरर या उल्लंघन को संभाल सकें।

खेल को इस तरह दर्शाया गया है:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

खेल में 4 नियम हैं:

- हर पॉइंट पर सिर्फ एक ही पत्थर रखा जा सकता है (`oneStonePerPointRule`)
- विरोधी के पत्थर पकड़े जा सकते हैं! (`captureRule`)
- आप ऐसी जगह पत्थर नहीं रख सकते जहाँ वह खुद ही पकड़ा जाए (`libertyRule`)
- आप एक ही पॉइंट का इस्तेमाल दो बार नहीं कर सकते (`koRule`)

## 1. नियम लागू कीजिए

`applyRules` फंक्शन का कोड लिखिए। यह फंक्शन शुरुआती एक `Game` और नियमों का एक समूह लेता है, और नियम लागू होने के बाद नया `Game` लौटाता है।

`oneStonePerPointRule`, `libertyRule` और `koRule` तीनों नियमों के उल्लंघन की जाँच करते हैं, और एरर भी लौटा सकते हैं। इसलिए इनका रिटर्न टाइप `Result String Game` है। अगर इनमें से कोई नियम विफल हो जाए, तो मूल खेल ही लौटाया जाना चाहिए, बस `error` फील्ड में संबंधित एरर डाल देनी चाहिए।

`captureRule` उल्लंघनों की जाँच नहीं करता, इसलिए यह विफल नहीं हो सकता (हालाँकि यह बदला हुआ `Game` लौटा सकता है), और इसका रिटर्न टाइप `Game` है।

अगर सभी नियम पास हो जाएँ, तो नियमों से `Game` में जो भी बदलाव हुए हैं वे बने रहने चाहिए, और खिलाड़ी बदल दिया जाना चाहिए। यह काम करने के लिए `changePlayer` फंक्शन दिया गया है।

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
