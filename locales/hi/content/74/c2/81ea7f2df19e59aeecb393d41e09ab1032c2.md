# JavaScript में रिकर्शन को समझना

रिकर्शन प्रोग्रामिंग का एक शक्तिशाली कॉन्सेप्ट है, जिसमें एक फंक्शन खुद को कॉल करता है।
शुरू में इसे समझना थोड़ा मुश्किल लग सकता है, लेकिन एक बार मूल बातें समझ में आ जाएँ, तो यह जटिल समस्याओं को हल करने में बहुत काम का टूल बन जाता है।
आइए JavaScript में रिकर्शन को आसान उदाहरणों के साथ समझते हैं।

## रिकर्शन क्या है?

रिकर्शन तब होता है जब कोई फंक्शन खुद को सीधे या अप्रत्यक्ष रूप से कॉल करता है।
यह लूप जैसा ही है, बस इसमें बड़ी समस्या को छोटे-छोटे हिस्सों में तोड़ा जाता है, जिन्हें सँभालना आसान होता है।

### उदाहरण 1: उलटी गिनती

चलिए एक आसान उदाहरण से शुरू करते हैं: उलटी गिनती करने वाला एक फंक्शन।

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

इस उदाहरण में:

- **बेस केस**: जब `num` की वैल्यू 0 से छोटी या उसके बराबर हो जाती है, तब फंक्शन "Blastoff!" प्रिंट करता है और खुद को कॉल करना बंद कर देता है।
- **रिकर्सिव केस**: फंक्शन `num` की मौजूदा वैल्यू प्रिंट करता है और खुद को `num - 1` के साथ कॉल करता है।

### उदाहरण 2: फैक्टोरियल

अब रिकर्शन का एक क्लासिक उदाहरण देखते हैं: किसी संख्या का फैक्टोरियल निकालना।

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

इस उदाहरण में:

- **बेस केस**: जब `n` की वैल्यू 0 या 1 होती है, तब फंक्शन 1 लौटाता है।
- **रिकर्सिव केस**: फंक्शन `n` को `n - 1` के फैक्टोरियल से गुणा करता है।

## मुख्य कॉन्सेप्ट

### बेस केस

हर रिकर्सिव फंक्शन में कम से कम एक बेस केस होना चाहिए, यानी ऐसी शर्त जहाँ फंक्शन खुद को कॉल करना बंद कर देता है।
बेस केस के बिना रिकर्शन अनंत तक चलता रहेगा, जिससे स्टैक ओवरफ्लो हो जाएगा।

### रिकर्सिव केस

रिकर्सिव केस बताता है कि फंक्शन खुद को समस्या के किसी छोटे या आसान रूप के साथ कैसे कॉल करता है।

## रिकर्शन के लाभ और हानि

**लाभ:**

- कुछ समस्याओं के लिए बहुत सुंदर हल।
- यह गणितीय इंडक्शन जैसा ही तरीका अपनाता है।

**हानि:**

- यह इटरेटिव हल से कम कुशल हो सकता है।
- गहरे रिकर्शन में स्टैक ओवरफ्लो हो सकता है।

## निष्कर्ष

रिकर्शन एक बहुत काम की तकनीक है, जो जटिल समस्याओं को छोटे-छोटे और आसान हिस्सों में तोड़कर आसान बना देती है।
JavaScript में अच्छे रिकर्सिव हल लिखने के लिए बेस केस और रिकर्सिव केस को समझना बहुत ज़रूरी है।
