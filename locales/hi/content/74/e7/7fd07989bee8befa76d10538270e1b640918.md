# HTTP का अरब डॉलर वाला सवाल

## समस्या कथन

आपको दिए गए देशों के समूह (देशों की संख्या = `N`) में से कुल संपत्ति के आधार पर शीर्ष `x` अरबपतियों को ढूँढ़ना है। इसके लिए आपको एक API तक पहुँच दी गई है, जो देश के हिसाब से अरबपतियों का विवरण लौटाता है।

API तक पहुँचना आसान बनाने के लिए आप [`ims/billionairehub` क्लाइंट](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) कनेक्टर की मदद से उस API से जुड़ सकते हैं, जो देश के हिसाब से अरबपतियों का विवरण लौटाता है।

## सीमाएँ

* 1 <= N <= 5
* 1 <= x <= 10

## परीक्षण वातावरण

* अरबपति API से जुड़ने के लिए Client ID और Client Secret आपको `tests/Config.toml` में दिए गए हैं। इनकी मदद से आप क्लाइंट को इनिशियलाइज़ कर सकते हैं।
* अपना कोड चलाने और जाँचने के लिए `bal test` का उपयोग कीजिए।

## संकेत

* `ims/billionairehub` पैकेज के [क्लाइंट](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) की मदद से get billionaires by country API को कॉल किया जा सकता है। आप इसमें खास तौर पर `getBillionaires("<country>")` रिमोट मेथड का इस्तेमाल कर सकते हैं।
* आप पहले हर देश के सबसे अमीर लोगों को ढूँढ़ सकते हैं और फिर उन्हें मिलाकर शीर्ष `x` लोगों को निकाल सकते हैं।
* छानने और क्रम में लगाने के लिए [क्वेरी एक्सप्रेशन](https://ballerina.io/learn/by-example/query-expressions/) काम आएँगे।
