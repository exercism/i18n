# निर्देश

इस अभ्यास में आप एक रिमोट कंट्रोल कार से खेलेंगे। इसे खरीदने के लिए आपने अब तक पर्याप्त पैसा बचा लिया है।

कार की बैटरी शुरू में पूरी (100%) रहती है। जब भी आप रिमोट कंट्रोल से कार चलाते हैं, वह 20 मीटर चलती है और बैटरी का एक प्रतिशत खत्म हो जाता है।

रिमोट कंट्रोल कार में एक शानदार LED डिस्प्ले है, जो दो जानकारियाँ दिखाता है:

- अब तक तय की गई कुल दूरी, जिसे इस तरह दिखाया जाता है: `"Driven <METERS> meters"`.
- बैटरी का बचा हुआ चार्ज, जिसे इस तरह दिखाया जाता है: `"Battery at <PERCENTAGE>%"`.

अगर बैटरी 0% पर हो, तो आप कार को और नहीं चला सकते, और बैटरी डिस्प्ले `"Battery empty"` दिखाएगा।

आपके सामने छह कार्य हैं, और हर कार्य में रिमोट कंट्रोल कार के इंस्टेंस के साथ काम करना है।

## 1. बिल्कुल नई रिमोट कंट्रोल कार खरीदिए

एक बिल्कुल नई रिमोट कंट्रोल कार इंस्टेंस लौटाने के लिए (_static_) `JedliksToyCar.buy()` मेथड लागू कीजिए:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. तय की गई दूरी दिखाइए

LED डिस्प्ले पर दिखाई जाने वाली दूरी लौटाने के लिए `JedliksToyCar.distanceDisplay()` मेथड लागू कीजिए:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. बैटरी का प्रतिशत दिखाइए

LED डिस्प्ले पर दिखाया जाने वाला बैटरी प्रतिशत लौटाने के लिए `JedliksToyCar.batteryDisplay()` मेथड लागू कीजिए:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. चलाते समय तय किए गए मीटर की संख्या अपडेट कीजिए

वह `JedliksToyCar.drive()` मेथड लागू कीजिए जो तय किए गए मीटर की संख्या अपडेट करता है:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. चलाते समय बैटरी का प्रतिशत अपडेट कीजिए

बैटरी का प्रतिशत अपडेट करने के लिए `JedliksToyCar.drive()` मेथड को अपडेट कीजिए:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. बैटरी खत्म होने पर कार चलने से रोकिए

जब बैटरी खत्म हो जाए (0% पर), तो तय की गई दूरी न बढ़े और बैटरी का प्रतिशत न घटे, इसके लिए `JedliksToyCar.drive()` मेथड को अपडेट कीजिए:

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
