# निर्देश

इस अभ्यास में आपको एक बैंक के संचालन में इस्तेमाल होने वाले कुछ कॉन्स्टेंट बनाने हैं।

आपको पाँच काम करने हैं:

## 1. ऋण पर निश्चित ब्याज दर दर्शाइए

`FixedInterestRate` नाम का बिना टाइप वाला संख्यात्मक कॉन्स्टेंट बनाइए, जिसमें 5% (5/100) की वैल्यू रखी जाए। फिर `GetFixedInterestRate` फंक्शन लागू कीजिए, जो यह वैल्यू लौटाए:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. एक वर्ष में दिनों की संख्या दर्शाइए

365 की वैल्यू रखने के लिए `int` टाइप का `DaysPerYear` कॉन्स्टेंट बनाइए। फिर `GetDaysPerYear` फंक्शन लागू कीजिए, जो यह वैल्यू लौटाए:

```go
GetDaysPerYear()
// => 365
```

## 3. वर्ष के महीने दर्शाइए

एक ब्लॉक में Go के एन्युमरेटर की मदद से बिना टाइप वाले बारह संख्यात्मक कॉन्स्टेंट बनाइए, जिनमें वर्ष के महीनों के लिए 1 से 12 तक की वैल्यू रखी जाए। इनके नाम `Jan`, `Feb`, `Mar` आदि रखिए। फिर `GetMonth` फंक्शन लागू कीजिए, जो दिए गए महीने की वैल्यू लौटाए:

```go
GetMonth(Jan)
// => 1
```

## 4. खाता संख्या दर्शाइए

XF348IJ की वैल्यू रखने के लिए `AccountNo` नाम का बिना टाइप वाला स्ट्रिंग कॉन्स्टेंट बनाइए। फिर `GetAccountNumber` फंक्शन लागू कीजिए, जो यह वैल्यू लौटाए:

```go
GetAccountNumber()
// => "XF348IJ"
```
