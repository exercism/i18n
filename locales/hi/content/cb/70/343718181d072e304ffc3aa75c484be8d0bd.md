# निर्देश

मैरी टीवी सीरीज़ Star Trek: The Next Generation की बहुत बड़ी प्रशंसक हैं।
वह अक्सर कागज़-कलम वाले रोल-प्लेइंग गेम खेलती हैं, जिनमें वह और उसके दोस्त Starship Enterprise के क्रू का अभिनय करते हैं।
मैरी का किरदार Captain Picard है, इसलिए उसे कैप्टन का लॉग रखना पड़ता है।
खेल का रचनात्मक हिस्सा उसे बहुत पसंद है, लेकिन मौके पर ही रैंडम डेटा बनाना उसे पसंद नहीं है।

मैरी की मदद कीजिए: कैप्टन के लॉग में आम तौर पर आने वाले डेटा के लिए रैंडम जनरेटर बनाइए।

## 1. एक रैंडम स्टारशिप रजिस्ट्री नंबर बनाइए

Enterprise (रजिस्ट्री नंबर NCC-1701) अकेला उड़ता हुआ स्टारशिप नहीं है!
जब वह किसी दूसरे स्टारशिप से मिलती है, तो मैरी को उस स्टारशिप का रजिस्ट्री नंबर लॉग करना पड़ता है।

रजिस्ट्री नंबर "NCC-" उपसर्ग से शुरू होते हैं, जिसके बाद 1000 से 9999 तक (दोनों शामिल) की संख्या आती है।

`randomShipRegistryNumber()` नाम का फंक्शन बनाइए जो एक रैंडम स्टारशिप रजिस्ट्री नंबर लौटाता है।

```javascript
randomShipRegistryNumber();
// => "NCC-1947"
```

## 2. एक रैंडम स्टारडेट बनाइए

अगर लॉग में तारीखें न हों तो उसका क्या फायदा?

स्टारडेट एक दशमलव संख्या होती है।
The Next Generation के पहले सीज़न में Starship Enterprise के रोमांच स्टारडेट 41000.0 और 42000.0 के बीच होते हैं।
"4" चौबीसवीं सदी को दर्शाता है और "1" पहले सीज़न को।

`randomStardate` फंक्शन बनाइए जो 41000.0 (शामिल) से 42000.0 (शामिल नहीं) के बीच एक दशमलव संख्या लौटाता है।

```javascript
randomStardate();
// => 41458.15721310934
```

## 3. एक रैंडम ग्रह बनाइए

Starship Enterprise को अपनी यात्राओं में कई ग्रह मिलते हैं।
Star Trek ब्रह्मांड के ग्रह उनके गुणों के आधार पर अलग-अलग श्रेणियों में बाँटे गए हैं।
जैसे पृथ्वी M क्लास का ग्रह है।
सभी संभव ग्रह क्लास ये हैं: D, H, J, K, L, M, N, R, T और Y।

`randomPlanetClass()` फंक्शन बनाइए।
यह इनमें से कोई एक ग्रह क्लास रैंडम रूप से लौटाता है।

```javascript
randomPlanetClass();
// => "K"
```
