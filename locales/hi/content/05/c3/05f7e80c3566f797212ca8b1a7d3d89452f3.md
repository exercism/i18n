# परिचय

## टाइप घोषणा

PHP में टाइप घोषणाएँ कोड चलने के समय फंक्शन के आर्गुमेंट, रिटर्न वैल्यू और क्लास प्रॉपर्टी के टाइप की जाँच करती हैं।
फंक्शन में `void` रिटर्न टाइप जोड़कर यह बताया जा सकता है कि उस फंक्शन से कोई वैल्यू नहीं लौटती।
घोषित टाइप यह जाँचने का काम भी करते हैं कि फंक्शन उचित टाइप वाली वैल्यू ही लौटा रहे हैं।

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### टाइप यूनियन

अगर किसी फंक्शन के आर्गुमेंट, रिटर्न वैल्यू या क्लास प्रॉपर्टी का टाइप एक से अधिक हो सकता है, तो आप टाइप यूनियन घोषित कर सकते हैं।

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### मिक्स्ड टाइप

कोड लिखते समय कभी-कभी हम टाइप बता नहीं पाते।
PHP 8.0 से `mixed` नाम का एक टाइप उपलब्ध है, जो एक तरह का बचाव रास्ता है।
`mixed`, `object|resource|array|string|float|int|bool|null` टाइप यूनियन के बराबर है।
