# निर्देश

इस अभ्यास में आप कुछ कोड लिखेंगे, जिससे अपनी पसंदीदा रेसिपी की किताब से एक शानदार लसैगना बनाने में आपको मदद मिलेगी।

आपके सामने चार काम हैं, और सब लसैगना पकाने में लगने वाले समय से जुड़े हैं।

## 1. मिनटों में ओवन का अपेक्षित समय तय कीजिए

`$expected_minutes_in_oven` नाम का एक कॉन्स्टेंट बनाइए।
रेसिपी की किताब के अनुसार, ओवन में लगने वाला अपेक्षित समय 40 मिनट है:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. मिनटों में ओवन का बाकी बचा समय निकालिए

यह वैल्यू इनपुट में लसैगना के ओवन में अब तक बिताए असल मिनट लेती है। फिर पिछले काम में दिए गए अपेक्षित ओवन समय के आधार पर यह बताती है कि लसैगना को ओवन में अभी और कितने मिनट रुकना है।

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. मिनटों में तैयारी का समय निकालिए

तैयारी का समय यह बताता है कि लसैगना को ओवन में रखने से पहले तैयार करने में कितना समय लगता है।
हर परत तैयार करने में 2 मिनट लगते हैं।

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. मिनटों में कुल काम का समय निकालिए

लसैगना पकाने में आपने कुल कितने मिनट काम किया, यह निकालिए।
यह तैयारी के समय और इस समय ओवन में लसैगना के बिताए समय का जोड़ है।

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
