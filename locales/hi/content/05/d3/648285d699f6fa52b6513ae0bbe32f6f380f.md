# अतिरिक्त

## GNU awk और मनमानी परिशुद्धता का अंकगणित

डिफॉल्ट रूप से `awk` में संख्याएँ डबल-प्रिसिज़न फ्लोटिंग पॉइंट संख्याओं के रूप में रखी जाती हैं। इससे 53 बिट की परिशुद्धता मिलती है (मैनुअल में [तालिका 16.3][table-16.3] देखिए)। दुर्भाग्य से, यह इस अभ्यास को पूरा करने के लिए अपर्याप्त है (स्पॉइलर अलर्ट: एक टेस्ट के लिए 63 बिट की परिशुद्धता चाहिए)।

"अपर्याप्त परिशुद्धता" ऐसी दिखती है:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

अगर संबंधित लाइब्रेरीज़ `awk` एक्ज़ीक्यूटेबल में कंपाइल कर दी गई हों, तो GNU `awk` मनमानी परिशुद्धता वाली संख्याएँ इस्तेमाल कर सकता है। अपने awk का वर्ज़न जाँचिए और देखिए कि "GNU MPFR" मौजूद है या नहीं:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

अगर यह मौजूद है, तो `-M` ऑप्शन इस्तेमाल करके इस सुविधा को चालू कीजिए:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

अगर मेरे `awk` में `-M` नहीं है, तो क्या करें? तब आपको कोई बाहरी प्रोग्राम कॉल करना पड़ेगा जो मनमानी परिशुद्धता का अंकगणित कर सके, जैसे `bc`. यह कैसे करें, इसका एक उदाहरण [किसी पाइप से getline को वेरिएबल में लेने][getline-pipe] वाले हिस्से में देखिए।
