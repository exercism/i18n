# इंस्टॉलेशन

- macOS: `brew install futhark` चलाइए
- linux: `brew install futhark` चलाइए
- Windows: या तो WSL इस्तेमाल कीजिए या [Windows के लिए दिए गए निर्देशों][windows-specific-instructions] का पालन कीजिए

इंस्टॉलेशन के दूसरे तरीके [आधिकारिक इंस्टॉलेशन निर्देशों][instructions] में देखे जा सकते हैं।

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
