# परिचय

क्लास Swift प्रोग्राम की बुनियादी इकाइयाँ होती हैं। इनकी मदद से आप आपस में जुड़ी प्रॉपर्टी (डेटा) और मेथड (फंक्शन) को ऐसी इकाइयों में समेट सकते हैं जो अपने आप में पूरी हों।

### क्लास बनाना

क्लास बनाने के लिए `class` कीवर्ड लिखिए, उसके बाद क्लास का नाम लिखिए, और क्लास की परिभाषा को घुंघराले ब्रैकेट के बीच रखिए:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

क्लास के अंदर संग्रहीत प्रॉपर्टी हो सकती हैं, जिन्हें आम कॉन्स्टेंट (`let`) या वेरिएबल (`var`) की तरह बनाया जाता है, और उनका व्यवहार भी वैसा ही होता है।

### इंस्टेंस

क्लास की परिभाषा एक खाके की तरह काम करती है: यह एक नया टाइप बनाती है और बताती है कि उसकी वैल्यू कैसी दिखेंगी, लेकिन अपने आप कोई इंस्टेंस नहीं बनाती।

क्लास का *इंस्टेंस* बनाने के लिए उसका इनिशियलाइज़र कॉल कीजिए: क्लास का नाम लिखिए और उसके बाद गोल ब्रैकेट लगाइए:

```swift
let someCharacter = GameCharacter()
```

इससे एक नया इंस्टेंस बनता है, जिसकी प्रॉपर्टी क्लास की परिभाषा में दी गई डिफ़ॉल्ट वैल्यू से इनिशियलाइज़ होती हैं।
जिन ऑप्शनल प्रॉपर्टी के लिए कोई डिफ़ॉल्ट वैल्यू साफ़ तौर पर नहीं दी गई हो (जैसे `name`), उन्हें Swift `nil` बना देता है।

### प्रॉपर्टी तक पहुँचना

किसी इंस्टेंस की प्रॉपर्टी तक पहुँचने के लिए *डॉट नोटेशन* इस्तेमाल होता है: इंस्टेंस का नाम लिखिए, फिर एक बिंदु (`.`), और फिर प्रॉपर्टी का नाम।
डॉट नोटेशन नेस्टेड प्रॉपर्टी पर भी काम करता है।

डॉट नोटेशन से आप वैल्यू पढ़ सकते हैं और, अगर प्रॉपर्टी बदलने लायक हो (`var`), तो नई वैल्यू असाइन कर सकते हैं:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### मेथड

प्रॉपर्टी के अलावा, क्लास *मेथड* भी बना सकती है, यानी ऐसे फंक्शन जो उस क्लास से जुड़े होते हैं।

मेथड को क्लास के अंदर आम `func` सिंटैक्स से बनाइए।
अगर कोई मेथड किसी प्रॉपर्टी को बदलता है, तो उस प्रॉपर्टी को `var` से घोषित करना ज़रूरी है:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

प्रॉपर्टी की तरह ही, डॉट नोटेशन से किसी इंस्टेंस पर मेथड कॉल कीजिए:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

क्लास के हर इंस्टेंस में `self` नाम की एक अंतर्निहित प्रॉपर्टी होती है, जो उस इंस्टेंस को ही दिखाती है।
प्रॉपर्टी या मेथड का ज़िक्र करते समय इसे अक्सर छोड़ दिया जाता है, लेकिन जब किसी प्रॉपर्टी और मेथड के पैरामीटर का नाम एक जैसा हो, तब `self` का इस्तेमाल आम तौर पर दोनों में फ़र्क करने के लिए किया जाता है।
