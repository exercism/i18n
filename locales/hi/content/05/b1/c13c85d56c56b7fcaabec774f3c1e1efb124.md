# परिचय

`bit` कंप्यूटिंग में सबसे बारीक वैल्यू है।
`bit` शब्द दरअसल "बाइनरी डिजिट" का छोटा रूप है।
प्रोग्राम के चलने के वातावरण में यह डेटा संग्रहीत करने की एक ऐसी इकाई है जो इतनी बड़ी होती है कि उसमें दो में से कोई भी एक वैल्यू रखने वाला ऑब्जेक्ट समा जाए।
इसलिए इसकी बाइनरी वैल्यू या तो `1` होती है या `0`।
बाकी सभी डेटा टाइप कई `bits` से मिलकर बने होते हैं।
उदाहरण के लिए, एक `byte` आमतौर पर आठ `bits` से बनता है।

## बिट मास्क

बिट मास्क कोई भी ऐसी वैल्यू हो सकती है जिसका इस्तेमाल अलग-अलग बिट सेट करने के लिए किया जाता है।
उदाहरण के लिए, अंग्रेज़ी वर्णमाला में छब्बीस अक्षर हैं।
कम से कम छब्बीस बिट की कोई वैल्यू, जैसे कि एक अनसाइन्ड 32-बिट पूर्णांक, हर अंग्रेज़ी अक्षर के लिए `true` या `false` शर्त सेट करने के लिए बिट मास्क की तरह इस्तेमाल की जा सकती है।
जिस भी वैल्यू में ज़रूरी `true` या `false` शर्तों के समूह को संभालने लायक बिट हों, वह बिट मास्क का काम कर सकती है।
अलग-अलग बिट सेट करना और पढ़ना बिटवाइज़ ऑपरेटरों की मदद से किया जाता है।

## बिटवाइज़ ऑपरेटर

मान लीजिए हम यह ध्यान रखना चाहते हैं कि एक `string` में कौन-कौन से अक्षर आते हैं।
अपने उदाहरण में हम सिर्फ अंग्रेज़ी वर्णमाला के छब्बीस अक्षर इस्तेमाल करेंगे।
हमारा बिट मास्क एक अनसाइन्ड 32-बिट पूर्णांक होगा।
`0` यह दिखाएगा कि वह अक्षर नहीं आता।
`1` यह दिखाएगा कि वह अक्षर एक या उससे अधिक बार आता है।
शुरू में हमारे बिट मास्क का बिट रूप एक पंक्ति में 32 `0s` होगा: `00000000000000000000000000000000`।
सबसे दाईं ओर की जगह `A` के लिए होगी।
बाईं ओर से दूसरी जगह `B` के लिए होगी, और इसी तरह आगे।
मान लीजिए हम एक लूप में स्ट्रिंग के सारे अक्षरों को प्रोसेस कर रहे हैं, तो हम कोड की ऐसी एक लाइन चाहते हैं जो किसी भी अक्षर को सेट करने के लिए काम करे।

### बिटवाइज़ शिफ्ट लेफ्ट ऑपरेटर: किसी बिट को जगह देने का तरीका

`<<` बाईं ओर शिफ्ट करने वाला बिटवाइज़ ऑपरेटर है।

अगर हमारा अक्षर `A` है तो हमें बाईं ओर शिफ्ट नहीं करना है, लेकिन अगर अक्षर `B` है तो हमें एक जगह बाईं ओर शिफ्ट करना है, और अगर अक्षर `C` है तो दो जगह बाईं ओर शिफ्ट करना है, और इसी तरह आगे।
हालाँकि हम `chars` को `A` या `B` जैसे अक्षरों की तरह देखते हैं, मेमोरी में एक `char` पूर्णांक टाइप के रूप में लागू किया जाता है, इसलिए हम एक `char` के साथ आसान गणित कर सकते हैं।
मान लीजिए हमारे पास `letter` नाम का एक वेरिएबल है, जो उस `char` को दिखाता है जिसे हम प्रोसेस कर रहे हैं। तब हम `1` को `letter` और `A` `char` के अंतर के बराबर बाईं ओर शिफ्ट करके जितनी जगह चाहिए उतनी बाईं ओर शिफ्ट कर सकते हैं, इस तरह: `1 << letter - 'A'`।
`A` - `A` का मान `0` है, इसलिए अगर `letter` `A` है तो यह `0` जगह बाईं ओर शिफ्ट होगा।
`B` - `A` का मान `1` है, इसलिए अगर `letter` `B` है तो यह `1` जगह बाईं ओर शिफ्ट होगा, और इसी तरह आगे।

### बिटवाइज़ इन्क्लूसिव OR ऑपरेटर: किसी बिट को सेट करने का तरीका

एक बार हमें पता चल जाए कि हमें बिट _कहाँ_ सेट करना है, तो हम उसे बिटवाइज़ इन्क्लूसिव OR ऑपरेटर से सेट कर सकते हैं, जो `|` है।
`|` ऑपरेटर का परिणाम हर उस जगह `1` होगा जहाँ बाएँ या दाएँ ऑपरेंड में से किसी एक का बिट सेट हो।
इसलिए `0010 | 0001` का परिणाम `0011` होगा।
(यह ध्यान रखना ज़रूरी है कि यह वैल्यू बाइनरी में `11` है, लेकिन दशमलव में `3` है।)
नतीजे को किसी वैल्यू में असाइन करने के लिए `|` ऑपरेटर को असाइनमेंट ऑपरेटर के साथ जोड़कर बिट इस तरह सेट किए जा सकते हैं: `|=`।
इसे आसान रखने के लिए, नीचे का उदाहरण लूप का इस्तेमाल नहीं करता, लेकिन यह दिखाता है कि हम `ABA` अक्षरों को एक बिट मास्क में कैसे प्रोसेस कर सकते हैं।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

हम अपने मास्क का सबसे दाईं ओर वाला हिस्सा `A` के लिए `0001` कर देते हैं, और फिर `B` के लिए मास्क को `0011` कर देते हैं।
दोबारा `A` सेट करने पर मौजूदा मास्क में कोई बदलाव नहीं होता।
हम यह देखकर कि `A` पहले ही सेट है या नहीं, उस बिट को दोबारा सेट करने से बच सकते थे।

### बिटवाइज़ AND ऑपरेटर: किसी बिट को पढ़ने का तरीका

`&` बिटवाइज़ AND ऑपरेटर है।
`&` ऑपरेटर का परिणाम हर उस जगह `1` होगा जहाँ बाएँ और दाएँ दोनों ऑपरेंड का बिट सेट हो।
इसलिए `0011 & 0001` का परिणाम `0001` होगा।
इसे नीचे के उदाहरण में काम करते हुए देख सकते हैं।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### बिटवाइज़ एक्सक्लूसिव OR ऑपरेटर: किसी बिट को पलटने का तरीका

`^` बिटवाइज़ एक्सक्लूसिव OR ऑपरेटर है।
_इन्क्लूसिव_ OR ऑपरेटर होने से यह भी पता चलता है कि एक _एक्सक्लूसिव_ OR ऑपरेटर भी है, जिसका व्यवहार अलग है।
`^` ऑपरेटर का परिणाम हर उस जगह `1` होगा जहाँ बाएँ या दाएँ ऑपरेंड में से _सिर्फ एक_ का बिट सेट हो।
इसलिए `0001 ^ 0011` का परिणाम `0010` होगा।
सबसे दाईं ओर का बिट सेट नहीं होगा, क्योंकि _दोनों_ ऑपरेंड की सबसे दाईं जगह पर `1` है।
एक्सक्लूसिव OR ऑपरेशन को कभी-कभी XOR लिखा जाता है।
अगर किसी वैल्यू को XOR करने से जो नतीजा मिला, उसी पर दोबारा XOR किया जाए, तो मूल वैल्यू वापस मिल जाती है।
इसका इस्तेमाल एक बहुत आसान एन्क्रिप्शन के लिए किया जा सकता है, जिसमें डेटा को एन्क्रिप्ट और डिक्रिप्ट, दोनों के लिए एक ही की इस्तेमाल होती है।
उदाहरण के लिए

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## बिट फ़ील्ड

हमने देखा कि एक आसान डेटा टाइप में भरे हुए बिट को उनकी जगह के हिसाब से कैसे पहचाना जा सकता है।
एक `struct` में भरे हुए बिट को नाम से पहचाना जा सकता है।
ऐसे डेटा टाइप को `bit field` कहते हैं।
`bit fields` का एक इस्तेमाल तब हो सकता है जब चालू/बंद फ़्लैग का एक समूह चाहिए और मेमोरी का इस्तेमाल कम से कम करना हो।

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;` का सिंटैक्स struct के अंदर रखे एक `unsigned int` में `1` बिट का फ़ील्ड बनाता है।
`unsigned int` की जगह `signed int` भी इस्तेमाल किया जा सकता है, या C99 से आगे के संस्करणों में `bool` टाइप इस्तेमाल किया जा सकता है।
बिट फ़ील्ड रखने वाले struct में दूसरे डेटा टाइप के फ़ील्ड भी हो सकते हैं, जैसे ऊपर के उदाहरण में `number_of_lights`।
