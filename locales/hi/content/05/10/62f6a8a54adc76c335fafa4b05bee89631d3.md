# बेसिक्स का परिचय

[Go](https://golang.org) एक स्टैटिकली टाइप्ड प्रोग्रामिंग भाषा है, जिसे कंपाइल करके चलाया जाता है।
Go का सिंटैक्स C से मिलता-जुलता है।
पहले इसका डोमेन नाम golang.org था, इसलिए इस भाषा को अक्सर Golang कहा जाता है, लेकिन इसका सही नाम Go है।

बेसिक्स कॉन्सेप्ट में हम भाषा की तीन बड़ी विशेषताओं को देखेंगे: पैकेज, फंक्शन और वेरिएबल।

## पैकेज

Go के एप्लिकेशन पैकेजों में व्यवस्थित रहते हैं।
पैकेज एक ही डायरेक्टरी में रखी गई सोर्स फाइलों का समूह होता है।
एक डायरेक्टरी की सभी सोर्स फाइलों का पैकेज नाम एक ही होना चाहिए।
आम तौर पर पैकेज का नाम इंपोर्ट पाथ की अंतिम डायरेक्टरी होता है।
जैसे ["math/rand" पैकेज](https://golang.org/src/math/rand/) की फाइलें `package rand` स्टेटमेंट से शुरू होती हैं।
जब कोई पैकेज इंपोर्ट किया जाता है, तो उसमें से सिर्फ वे चीज़ें (फंक्शन, टाइप, वेरिएबल, कॉन्स्टेंट) इस्तेमाल की जा सकती हैं जिनके नाम बड़े अक्षर से शुरू होते हैं।
Go में नाम रखने का सुझाया गया तरीका यह है कि आइडेंटिफायर `camelCase` में लिखे जाएँ। हाँ, जिन आइडेंटिफायर को सभी पैकेजों से इस्तेमाल करना है, वे `PascalCase` में लिखे जाते हैं।

```go
package lasagna
```

## वेरिएबल

Go स्टैटिकली टाइप्ड है, यानी कंपाइल के समय हर वेरिएबल का [टाइप तय होना ज़रूरी होता है](https://en.wikipedia.org/wiki/Type_system)।

वेरिएबल को टाइप साफ़-साफ़ बताकर भी बनाया जा सकता है:

```go
var explicit int // Explicitly typed
```

आप इनिशियलाइज़र का इस्तेमाल भी कर सकते हैं, और कंपाइलर वेरिएबल का टाइप इनिशियलाइज़र के टाइप के मुताबिक तय कर देगा।

```go
implicit := 10   // Implicitly typed as an int
```

एक बार घोषित होने के बाद वेरिएबल में `=` ऑपरेटर की मदद से वैल्यू असाइन की जा सकती है।
और एक बार घोषित होने के बाद वेरिएबल का टाइप कभी नहीं बदल सकता।

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## कॉन्स्टेंट

कॉन्स्टेंट भी वेरिएबल की तरह ही एक डेटा रखते हैं, लेकिन प्रोग्राम चलने के दौरान उनकी वैल्यू नहीं बदल सकती।

कॉन्स्टेंट `const` कीवर्ड से बनाए जाते हैं और संख्या, अक्षर, स्ट्रिंग या बूलियन हो सकते हैं:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## फंक्शन

Go के फंक्शन शून्य या उससे अधिक पैरामीटर लेते हैं।
पैरामीटर का टाइप साफ़-साफ़ लिखना ज़रूरी होता है, यहाँ टाइप का अनुमान नहीं लगाया जाता।

फंक्शन `return` कीवर्ड की मदद से वैल्यू लौटाते हैं।

किसी फंक्शन को कॉल करने के लिए उसका नाम लिखा जाता है और उसके हर पैरामीटर के लिए आर्गुमेंट पास किए जाते हैं।

ध्यान दीजिए कि Go दो तरह के कमेंट का समर्थन करता है।
सिंगल लाइन कमेंट से पहले `//` लगता है, और मल्टीलाइन कमेंट `/*` और `*/` के बीच लिखे जाते हैं।

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
