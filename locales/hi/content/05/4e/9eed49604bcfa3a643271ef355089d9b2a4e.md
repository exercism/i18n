# परिचय

[टर्नरी कंडीशनल ऑपरेटर][ternary-operator] `if-else` एक्सप्रेशन लिखने का एक संक्षिप्त तरीका है।
यह किसी शर्त का मूल्यांकन करता है और उस शर्त के `true` या `false` होने के अनुसार दो वैल्यू में से एक लौटाता है।

इस ऑपरेटर के तीन हिस्से होते हैं: `condition ? trueExpression : falseExpression`।
अगर `condition` से `true` मिलता है, तो `trueExpression` का मूल्यांकन होता है और वही लौटाया जाता है। वरना `falseExpression` का मूल्यांकन होता है और वह लौटाया जाता है।

टर्नरी ऑपरेटर सरल, एक ही लाइन वाले चुनावों के लिए बहुत उपयुक्त है:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

ऊपर दिया गया उदाहरण नीचे लिखे कोड जैसा ही है, बस छोटे रूप में:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
