# JavaScript में रिकर्शन को समझना

रिकर्शन प्रोग्रामिंग की एक शक्तिशाली अवधारणा है, जिसमें एक फंक्शन खुद को कॉल करता है।
इसे शुरू में समझना थोड़ा मुश्किल लग सकता है, लेकिन बुनियादी बातें समझ में आने के बाद यह जटिल समस्याओं को हल करने का बहुत काम का टूल बन जाता है।
चलिए, आसान उदाहरणों के साथ JavaScript में रिकर्शन को समझते हैं।

## रिकर्शन क्या है?

रिकर्शन तब होता है जब कोई फंक्शन खुद को कॉल करता है, चाहे सीधे तौर पर, चाहे अप्रत्यक्ष रूप से।
यह लूप जैसा ही है, बस इसमें समस्या को छोटे और आसान उप-समस्याओं में बाँटना पड़ सकता है।

### उदाहरण 1: उलटी गिनती

चलिए एक आसान उदाहरण से शुरू करते हैं: उलटी गिनती करने वाला फंक्शन।

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

इस उदाहरण में:

- **बेस केस**: जब `num` की वैल्यू 0 से छोटी या उसके बराबर हो जाती है, तो फंक्शन "Blastoff!" प्रिंट करता है और खुद को कॉल करना बंद कर देता है।
- **रिकर्शन केस**: फंक्शन मौजूदा `num` प्रिंट करता है और खुद को `num - 1` देकर कॉल करता है।

### उदाहरण 2: फैक्टोरियल

अब रिकर्शन का एक क्लासिक उदाहरण देखते हैं: किसी संख्या का फैक्टोरियल निकालना।

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

इस उदाहरण में:

- **बेस केस**: जब `n` की वैल्यू 0 या 1 होती है, तो फंक्शन 1 लौटाता है।
- **रिकर्शन केस**: फंक्शन `n` को `n - 1` के फैक्टोरियल से गुणा करता है।

## मुख्य अवधारणाएँ

### बेस केस

हर रिकर्शन वाले फंक्शन में कम से कम एक बेस केस होना चाहिए। बेस केस वह शर्त होती है जहाँ फंक्शन खुद को कॉल करना बंद कर देता है।
बेस केस के बिना रिकर्शन अनंत तक चलता रहेगा, जिससे स्टैक ओवरफ्लो हो जाता है।

### रिकर्शन केस

रिकर्शन केस तय करता है कि फंक्शन खुद को समस्या के छोटे या सरल रूप के साथ कैसे कॉल करता है।

## रिकर्शन के फायदे और नुकसान

**फायदे:**

- कुछ खास समस्याओं के लिए सरल और सुंदर हल।
- गणितीय इंडक्शन की तरह काम करता है।

**नुकसान:**

- इटरेशन वाले हलों की तुलना में कम कुशल हो सकता है।
- गहरे रिकर्शन में स्टैक ओवरफ्लो हो सकता है।

## निष्कर्ष

रिकर्शन एक बहुत काम की तकनीक है, जो जटिल समस्याओं को छोटे और आसान उप-समस्याओं में बाँटकर सरल बना देती है।
JavaScript में कारगर रिकर्शन वाले हल लिखने के लिए बेस केस और रिकर्शन केस को समझना बहुत ज़रूरी है।
