# परिचय

आम तौर पर फंक्शन सिर्फ एक तय संख्या में आर्गुमेंट लेते हैं।
लेकिन अगर आप अंतिम पैरामीटर के टाइप से पहले `...` लगाते हैं, तो फंक्शन अंत में आने वाले कितने भी आर्गुमेंट ले सकता है।
इससे अंतिम पैरामीटर एक _वेरिएडिक पैरामीटर_ बन जाता है।

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

फंक्शन के अंदर वेरिएडिक पैरामीटर एक स्लाइस होता है:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

किसी फंक्शन में वेरिएडिक पैरामीटर से पहले गैर-वेरिएडिक पैरामीटर भी हो सकते हैं।
किसी फंक्शन में ज़्यादा से ज़्यादा एक वेरिएडिक पैरामीटर हो सकता है, और वह अंतिम पैरामीटर ही होना चाहिए।

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## स्लाइस फैलाना

किसी स्लाइस को वेरिएडिक पैरामीटर में भेजने के लिए उसके बाद `...` लगाइए:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...` सिर्फ तभी मान्य है जब किसी स्लाइस को वेरिएडिक पैरामीटर में भेजा जा रहा हो।
