# परिचय

## शर्त वाले स्टेटमेंट

शर्त वाले स्टेटमेंट फैसले लेने वाले स्टेटमेंट होते हैं, जो या तो साइड इफेक्ट कर सकते हैं या किसी प्रोग्राम में निष्पादन का प्रवाह नियंत्रित कर सकते हैं।
शर्त वाले स्टेटमेंट में `if`, `if/else`, `switch` और `ternary` स्टेटमेंट शामिल हैं।

शर्त वाले स्टेटमेंट का इस्तेमाल किसी वैल्यू या वैल्यू के आपसी संबंध के बारे में सवाल पूछने के लिए किया जाता है।
इस सवाल का जवाब बूलियन में निकलता है, लेकिन `if` स्टेटमेंट खुद कोई भी वैल्यू लौटा सकता है, या सिर्फ एक साइड इफेक्ट कर सकता है।

## `if` स्टेटमेंट

सबसे आसान `if` स्टेटमेंट एक एक्सप्रेशन का मूल्यांकन करता है और एक लाइन निष्पादित करता है।
जिस एक्सप्रेशन की जाँच की जाती है, वह हमेशा ब्रैकेट में लिखा जाता है।

यह एक साइड इफेक्ट कर सकता है

```c
if (count > 10)
    printf("count is greater than 10");
```

या यह निष्पादन का प्रवाह बदल सकता है


```c
if (count > 10)
    return sum;
```

अगर किसी `if` स्टेटमेंट को एक से ज़्यादा लाइन निष्पादित करनी हैं, तो उसे उन लाइनों को कर्ली ब्रैकेट के अंदर रखना होगा

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

कुछ कोडिंग टीमें यह नियम बना सकती हैं कि `if` स्टेटमेंट में हमेशा कर्ली ब्रैकेट इस्तेमाल हों, चाहे लाइन एक ही हो।


## `if` और `else`

एक `if` स्टेटमेंट को `else` के साथ जोड़ा जा सकता है

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`, `else if`


`else` को दूसरे `if` के साथ जोड़कर वह बनाया जा सकता है जिसे `if-else-if ladder` कहते हैं।

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


कभी-कभी किसी `if-else-if ladder` को `switch` से बेहतर ढंग से दिखाया जा सकता है।
`if` की तरह, जाँचे जाने वाले एक्सप्रेशन को हमेशा ब्रैकेट में रखा जाता है।

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default` केस तब चलता है जब जाँची जा रही वैल्यू पिछले किसी भी केस से मेल नहीं खाती।

अगर कोई `switch` केस लौटता नहीं है, तो हर केस को खत्म करने के लिए आम तौर पर `break` डाला जाता है; वरना लॉजिक अगले केस में "फॉल थ्रू" कर जाता है।
कभी-कभी फॉलथ्रू जान-बूझकर इस्तेमाल किया जाता है

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

जब फॉलथ्रू अनजाने में हो जाए, तो वह एक बग है।

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

जब किसी वैल्यू की रेंज की जगह खास वैल्यू से तुलना करनी हो, तो `switch` फायदेमंद हो सकता है।
यह `if-else-if ladder` से तेज़ हो सकता है, क्योंकि कंपाइलर `switch` स्टेटमेंट को ऐसे तरीकों से ऑप्टिमाइज़ कर सकता है जो लैडर के साथ संभव नहीं हैं।
कभी-कभी `switch` लैडर से ज़्यादा पढ़ने योग्य लग सकता है।

## टर्नरी (यानी शर्त वाला) ऑपरेटर

टर्नरी ऑपरेटर एक तीन हिस्सों वाला शर्त स्टेटमेंट है, जिसका इस्तेमाल अक्सर कोई वैल्यू सेट करने के लिए किया जाता है।
जिस एक्सप्रेशन की जाँच करनी है वह प्रश्न चिह्न से पहले आता है और उसे ब्रैकेट में रखना ज़रूरी नहीं है।
सही होने पर लौटाई जाने वाली वैल्यू कोलन से पहले आती है, और गलत होने पर लौटाई जाने वाली वैल्यू कोलन के बाद।
लौटाई जाने वाली वैल्यू कोई वैल्यू लिटरल या वेरिएबल, दोनों में से कोई भी हो सकती है।

```c
int i = j > 5 ? 5: j;
```

सिंटैक्स की भीड़ कम करने के लिए टर्नरी ऑपरेटरों को एक के अंदर एक रखा जा सकता है।

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## दशमलव वैल्यू की तुलना करते समय शर्त

दशमलव संख्याएँ जिस तरह लागू की जाती हैं, उसके कारण एक साधारण गणितीय क्रिया में राउंडिंग एरर आ सकती है, जिससे समानता की जाँच करने पर अपेक्षित परिणाम नहीं मिलता।

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

एक टॉलरेंस वैल्यू, जिसे `epsilon` कहा जाता है, यह तय करने के लिए इस्तेमाल की जा सकती है कि कोई वैल्यू किस रेंज में हो तो दूसरी वैल्यू से तुलना करने पर भी बराबर मानी जाए।
कुछ प्लेटफॉर्म में float और double के एप्सिलॉन के लिए बिल्ट-इन कॉन्स्टेंट होते हैं।
ज़्यादा जानने के लिए अपने कंपाइलर के डॉक्युमेंटेशन देखिए।
एप्सिलॉन निकालना जटिल हो सकता है और यह अलग-अलग प्लेटफॉर्म पर अलग हो सकता है, यहाँ तक कि अलग-अलग मशीनों पर भी।
यहाँ एक साधारण तुलना का इस्तेमाल करने वाला एक उदाहरण प्रोग्राम दिया गया है।

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

`float` या `double` की समानता की तुलना करते समय सावधान रहिए!
