# विवरण

C++ में `string` एक ऐसा ऑब्जेक्ट है जिसे बदला जा सकता है। यह टेक्स्ट को अक्षरों के एक क्रम के रूप में रखता है, जिसमें अक्षर, अंक, विराम चिह्न वगैरह शामिल होते हैं। स्ट्रिंग पर काम करने के लिए उसके मेथड कॉल किए जाते हैं।

## स्ट्रिंग लाइब्रेरी

C++ में स्ट्रिंग टाइप और उससे जुड़े फंक्शन इस्तेमाल करने से पहले स्ट्रिंग लाइब्रेरी से शामिल करने पड़ते हैं। इसके लिए अपनी फाइल के सबसे ऊपर `#include <string>` जोड़ दीजिए। इसके बाद ये सब `std` नेमस्पेस में उपलब्ध हो जाते हैं। स्ट्रिंग लिटरल में डबल कोट अक्षर `"` इस्तेमाल होता है।

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## स्ट्रिंग के आम ऑपरेशन

स्ट्रिंग जोड़ने के लिए आप `+` ऑपरेटर इस्तेमाल कर सकते हैं:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

स्ट्रिंग लाइब्रेरी इस्तेमाल करने के लिए यह जानना ज़रूरी है कि किसी ऑब्जेक्ट से जुड़े फंक्शन को कॉल किया जा सकता है। ऐसे फंक्शनों को मेंबर फंक्शन कहते हैं। सिलेबस में आगे आप मेंबर फंक्शनों और उनसे जुड़े क्लास कॉन्सेप्ट के बारे में और सीखेंगे।

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


`find` फंक्शन भी बहुत काम का है। इसे स्ट्रिंग पर मेंबर फंक्शन की तरह कॉल किया जाता है और यह आर्गुमेंट के रूप में एक स्ट्रिंग लेता है। `find` स्ट्रिंग में पहली बार मिलने वाले अक्षर की जगह लौटाता है, और यह जगह शून्य से गिनी जाती है।

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

`to_string` फंक्शन भी है, जिसका इस्तेमाल पूर्णांक और दशमलव संख्याओं को स्ट्रिंग में बदलने के लिए किया जा सकता है। `to_string` एक स्ट्रिंग लौटाता है।

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
