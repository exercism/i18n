# Emacs इंस्टॉल कीजिए

चूँकि Emacs Lisp (elisp) Emacs की एक्सटेंशन भाषा है, इसलिए आपको पहले [GNU Emacs](http://www.gnu.org/software/emacs/) इंस्टॉल करना होगा।

बेहतर है कि आप सबसे नया Emacs लें, लेकिन अभ्यासों के लिए 28.1 या उससे ऊपर का वर्शन ही लक्ष्य माना गया है।
अगर Emacs पहले से इंस्टॉल है, तो आप `M-x emacs-version RET` से Emacs का वर्शन देख सकते हैं।

## OS X पर
सबसे आसान तरीका यह है कि [Emacs For Mac OS X](http://emacsformacosx.com/) पर जाकर dmg डाउनलोड कीजिए, जो
GNU Emacs को एक पैकेज्ड OS X ऐप के रूप में इंस्टॉल कर देगा।

और भी विकल्प हैं, जैसे Aquamacs (जिसकी सलाह नहीं दी जाती), या अगर आप चाहें तो
[Homebrew](https://formulae.brew.sh/formula/emacs) से इंस्टॉल करना।

## Linux पर
कुछ डिस्ट्रो में Emacs पहले से इंस्टॉल होता है, क्योंकि यह GNU का हिस्सा है।

### Ubuntu
फिलहाल सबसे नए Emacs को इंस्टॉल करने का सुझाया गया तरीका [snap](https://snapcraft.io/emacs) है:

```
sudo snap install emacs --classic
```

अगर आप snap इस्तेमाल नहीं करना चाहते, तो भी snap से Emacs इंस्टॉल कर सकते हैं, लेकिन Ubuntu रिपॉज़िटरी में उपलब्ध वर्शन अक्सर पुराना होता है।
अगर आप apt से Emacs का और नया वर्शन इंस्टॉल करना चाहते हैं, तो आपको [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) इस्तेमाल करना होगा या [सोर्स से बिल्ड करना](https://www.emacswiki.org/emacs/BuildingEmacs) होगा।

अगर आपको सबसे नया वर्शन इंस्टॉल करने की चिंता नहीं है, तो यह इतना ही आसान है:

```
sudo apt-get install emacs
```

### Arch
Arch में आमतौर पर Emacs का सबसे नया वर्शन ही मिलता है, इसलिए यह चलाइए:

```
sudo pacman -S emacs
```

और बस, आप तैयार हैं।

### अन्य डिस्ट्रो
अपने डिस्ट्रो में देख लीजिए कि कौन-सा वर्शन मौजूद है, और उसी हिसाब से अपना पैकेज
मैनेजर इस्तेमाल कीजिए या सोर्स से बिल्ड कीजिए।

### Windows
Windows पर Emacs इंस्टॉल करने के लिए अपने सबसे नज़दीकी
[FTP archive mirror](https://ftpmirror.gnu.org/emacs/windows) पर जाइए, इंस्टॉलर (=emacs-XX.X-installer.exe=) ले लीजिए, और उसे चलाइए।
अगर आप Emacs को इंस्टॉल किए बिना इस्तेमाल करना चाहते हैं, तो =emacs-XX.x.zip= पैटर्न वाली फाइल ले लीजिए, उसे अनपैक कीजिए और `bin\runemacs.exe` चलाइए।

अगर आप [MSYS2](https://www.msys2.org/) इस्तेमाल कर रहे हैं, तो Emacs का 64-बिट बिल्ड इस तरह इंस्टॉल कर सकते हैं:

```
pacman -S mingw-w64-x86_64-emacs
```

या 32-बिट बिल्ड इस तरह:

```
pacman -S mingw-w64-i686-emacs
```
