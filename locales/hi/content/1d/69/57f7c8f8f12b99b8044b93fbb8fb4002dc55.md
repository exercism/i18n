# परिचय

पैटर्न मैचिंग एक ऐसी प्रक्रिया है जिसमें यह तय होता है कि कोड किस रास्ते पर चलेगा, और यह इस पर निर्भर करता है कि कोई वैल्यू दिए गए पैटर्न से मेल खाती है या नहीं। ये पैटर्न गहरे भी हो सकते हैं। Haxe में **पैटर्न मैचिंग** `switch` एक्सप्रेशन और अलग-अलग `case` एक्सप्रेशन की मदद से की जाती है।

इस डेटा स्ट्रक्चर को देखिए:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- पैटर्न हमेशा ऊपर से नीचे के क्रम में मिलाए जाते हैं।
- जो पैटर्न सबसे ऊपर है और इनपुट वैल्यू से मेल खाता है, उसी का एक्सप्रेशन चलाया जाता है।
- `_` पैटर्न किसी भी चीज़ से मेल खाता है, इसलिए `case _:` और `default:` एक ही बात हैं।

## एनम मैचिंग

एनम को उनके कंस्ट्रक्टर से सीधे मैच किया जा सकता है:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
