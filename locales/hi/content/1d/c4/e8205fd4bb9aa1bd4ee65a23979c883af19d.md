# परिचय

Java की स्ट्रिंग के बारे में याद रखने वाली सबसे ज़रूरी बात यह है कि वे ऐसे ऑब्जेक्ट होते हैं जिन्हें बदला नहीं जा सकता। ये ऑब्जेक्ट किसी टेक्स्ट को Unicode अक्षरों (अक्षर, अंक, विराम चिह्न आदि) के क्रम के रूप में दर्शाते हैं।
किसी `String` इंस्टेंस को परिभाषित करने के लिए दोहरे कोट्स का उपयोग किया जाता है:

```java
String fruit = "Apple";
```

स्ट्रिंग में बदलाव करने के लिए [`String`][string-class] क्लास के मेथड का उपयोग किया जा सकता है।
चूँकि स्ट्रिंग की वैल्यू को एक बार परिभाषित करने के बाद कभी बदला नहीं जा सकता, इसलिए स्ट्रिंग में बदलाव करने वाले सभी मेथड एक नई स्ट्रिंग लौटाते हैं।

स्ट्रिंग को दोहरे कोट (`"`) अक्षरों के बीच रखा जाता है।
कुछ खास अक्षरों को बैकस्लैश (`\`) अक्षर की मदद से एस्केप करना पड़ता है।
Java में इन अक्षरों को एस्केप करना पड़ता है:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

अंत में, स्ट्रिंग जोड़ने के कई तरीके हैं।
सबसे आसान तरीका `+` ऑपरेटर है:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

साधारण जोड़ने से ज़्यादा जटिल किसी भी स्ट्रिंग फॉर्मेटिंग के लिए `String.format` मेथड का उपयोग करना बेहतर माना जाता है।

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

अन्य विकल्प भी हैं:

- [`StringBuilder` क्लास][string-builder] का उपयोग कीजिए
- [`String.concat` मेथड][string-concat] का उपयोग कीजिए
