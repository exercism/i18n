# अक्षर

**अक्षर** एक ही वर्ण, अंक, खाली जगह या चिह्न होता है। Sather में इसके लिए टाइप
`CHAR` होता है, और अक्षर को सिंगल कोट्स के बीच लिखा जाता है।

```sather
   initial : CHAR is
      return 'M';
   end;
```

एक अक्षर के लिए सिंगल कोट, और स्ट्रिंग के लिए डबल कोट। `'M'` और
`"M"` अलग-अलग टाइप हैं और इन्हें बदला नहीं जा सकता।

## स्ट्रिंग से अक्षर निकालना

स्ट्रिंग अक्षरों की एक पंक्ति होती है, और चौकोर ब्रैकेट की मदद से हम स्थिति के
हिसाब से किसी एक अक्षर तक पहुँच सकते हैं। गिनती शून्य से शुरू होती है, बिल्कुल
ऐरे की तरह।

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## अक्षर के बारे में पूछना

| कॉल | जवाब |
| --- | --- |
| `c.is_alpha` | क्या यह वर्ण है? |
| `c.is_digit` | क्या यह `0`–`9` में से एक है? |
| `c.is_upper` | क्या यह बड़ा वर्ण है? |
| `c.is_lower` | क्या यह छोटा वर्ण है? |

हर एक का जवाब `true` या `false` होता है।

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## केस बदलना

`.upper` किसी वर्ण का बड़ा रूप देता है, और `.lower` छोटा रूप।
जो चीज़ वर्ण नहीं है, वह जैसी थी वैसी ही वापस मिल जाती है।

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## अक्षर, संख्याओं के रूप में

हर अक्षर की एक संख्या होती है। `.int` वह संख्या देता है, और `.char` किसी
संख्या को वापस अक्षर में बदल देता है।

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

इन संख्याओं के सटीक मान कम ही मायने रखते हैं। जो मायने रखता है वह यह है कि वर्ण
`a` से `z` तक क्रम में और एक-दूसरे के पास होते हैं। इसीलिए
`'c'.int - 'a'.int` का मान 2 होता है, यानी `c` वर्णमाला में कितना आगे है।
एक सिफर व्हील इसी वजह से काम करता है।
