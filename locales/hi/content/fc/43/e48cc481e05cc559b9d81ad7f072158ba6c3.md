# परिचय

Swift में `guard` स्टेटमेंट का उपयोग Swift फंक्शन से जल्दी लौटने के लिए किया जाता है, जब आगे की प्रक्रिया जारी रखने के लिए ज़रूरी कोई शर्त पूरी नहीं होती। उदाहरण के लिए:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

यहाँ `guard` जाँचता है कि `guard` कीवर्ड के बाद वाला बूलियन एक्सप्रेशन सही के रूप में मूल्यांकित होता है या नहीं। अगर ऐसा होता है, तो प्रक्रिया guard स्टेटमेंट के बाद वाले कोड से जारी रहती है (यहाँ `let root = myValue.squareRoot()`. अन्यथा यह else क्लॉज़ में दिए गए कोड को चलाएगा। `if` स्टेटमेंट के विपरीत, `guard` स्टेटमेंट में else क्लॉज़ _होना ही चाहिए_, और if-else के else क्लॉज़ के विपरीत, guard के else क्लॉज़ को guard स्टेटमेंट के स्कोप से बाहर _निकलना ही चाहिए_। यानी उसे `return`, `continue` या `break` जैसा कंट्रोल ट्रांसफर स्टेटमेंट इस्तेमाल करना चाहिए, या एरर फेंकना चाहिए या प्रोग्राम से बाहर निकलना चाहिए।
