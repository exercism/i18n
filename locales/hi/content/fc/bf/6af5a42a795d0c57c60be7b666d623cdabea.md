# Char

`Char` Crystal में एक डेटा टाइप है, जो 32-बिट [Unicode][unicode] कोड पॉइंट को दर्शाता है।
इनका आकार इन्हें मेमोरी की दृष्टि से कुशल बनाता है और इन्हें कुछ ऐसी खास विशेषताएँ देता है जो स्ट्रिंग में नहीं होतीं।
इन्हें सिंगल कोट्स (`'`) से बनाया जाता है और इनके अंदर सिर्फ एक Unicode कोड पॉइंट ही रखा जा सकता है।

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystal में स्ट्रिंग के साथ काम करते समय Char के साथ काम करना काफी आम है, क्योंकि स्ट्रिंग क्लास के कई मेथड Char लौटाते हैं या आर्गुमेंट के रूप में Char लेते हैं।
जैसे [`String#[]`][index] मेथड एक Char लौटाता है, और [`String#chars`][chars] मेथड Char का एक संग्रह लौटाता है।

## बढ़ाना / घटाना

Char चूँकि एक 32-बिट Unicode कोड पॉइंट है, यह बढ़ाने और घटाने का समर्थन करता है। इसी वजह से अगर आपके पास `'a'` है, तो उसमें एक जोड़कर आप `'b'` पा सकते हैं।

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

[`Char#succ`][succ] नाम का एक मेथड भी है, जो Unicode टेबल में अगला Char लौटाता है, और [`Char#pred`][pred] भी, जो Unicode टेबल में पिछला Char लौटाता है।

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## जोड़ना

चूँकि Char का उद्देश्य सिर्फ 32-बिट Unicode को दर्शाना है, दो Char आपस में जोड़े नहीं जा सकते। इसलिए Char को सिर्फ स्ट्रिंग के साथ जोड़ा जा सकता है।

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## विशेषताएँ बताने वाले मेथड

Crystal में किसी अक्षर के बारे में जानकारी पाने के लिए कुछ मेथड हैं। जैसे, वह संख्या है या अक्षर, या वह छोटे अक्षर में लिखा है या बड़े अक्षर में। यहाँ ऐसे कुछ मेथड की सूची दी गई है, पूरी सूची के लिए [Char API][char-api] देखिए:

| मेथड                             | विवरण                                                    |
| -------------------------------- | -------------------------------------------------------- |
| [`Char#number?`][number]         | अगर Char संख्या है तो `true` लौटाता है                   |
| [`Char#letter?`][letter]         | अगर Char अक्षर है तो `true` लौटाता है                    |
| [`Char#lowercase?`][lowercase]   | अगर Char छोटे अक्षर में है तो `true` लौटाता है            |
| [`Char#uppercase?`][uppercase]   | अगर Char बड़े अक्षर में है तो `true` लौटाता है            |
| [`Char#ascii?`][ascii]           | अगर Char एक ASCII अक्षर है तो `true` लौटाता है           |
| [`Char#whitespace?`][whitespace] | अगर Char एक व्हाइटस्पेस अक्षर है तो `true` लौटाता है      |

## बदलना

### कोड पॉइंट और Char के बीच बदलना

चूँकि Char एक 32-बिट Unicode कोड पॉइंट है, आप Char और कोड पॉइंट (Int) के बीच बदल सकते हैं। यह [`Char#ord`][ord] मेथड से किया जा सकता है, जो Char का कोड पॉइंट लौटाता है, या [`Int#chr`][chr] मेथड से, जो कोड पॉइंट का Char लौटाता है।

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### टाइप के बीच बदलना

दूसरे डेटा टाइप की तरह Char में भी टाइप बदलने के लिए कुछ मेथड हैं। सबसे आम है `Char#to_s` मेथड, जो Char को स्ट्रिंग में बदलता है। इसके अलावा `Char#to_i` मेथड भी है, जो Char को Int में बदलता है, और `Char#to_f` मेथड, जो Char को Float में बदलता है।

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
