# परिचय

## बुनियादी बातें

### फंक्शन

Gleam में फंक्शन `pub fn` सिंटैक्स से बनाए जाते हैं।

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

यह फंक्शन दो आर्गुमेंट लेता है, दोनों `Int` टाइप के, और `Int` टाइप की एक वैल्यू लौटाता है। Gleam में `return` कीवर्ड नहीं होता, फंक्शन के अंदर लिखे अंतिम एक्सप्रेशन की वैल्यू हमेशा _अपने आप लौटा दी जाती है_।

आर्गुमेंट के टाइप एनोटेशन और रिटर्न टाइप लिखना ज़रूरी नहीं है, और Gleam आपके कोड का पूरा टाइप चेक हमेशा करता है। आम तौर पर Gleam प्रोग्रामर स्पष्टता के लिए अपने फंक्शनों पर टाइप एनोटेशन लिखते हैं, लेकिन आप चाहें तो इन्हें छोड़ सकते हैं।

```gleam
pub fn add(x, y) {
  x + y
}
```

किसी फंक्शन को `function_name(argument1, argument2)` सिंटैक्स से कॉल किया जा सकता है।

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### वेरिएबल

Gleam में वेरिएबल `let name = expression` सिंटैक्स से बनाए जाते हैं।

```gleam
pub fn main() {
  let count = 1
}
```

वेरिएबल को टाइप एनोटेशन के साथ भी घोषित किया जा सकता है। फंक्शन के आर्गुमेंट की तरह ये भी वैकल्पिक हैं, हालाँकि संक्षिप्तता के लिए अधिकांश Gleam प्रोग्रामर वेरिएबल के टाइप एनोटेशन छोड़ देते हैं।

```gleam
pub fn main() {
  let count: Int = 1
}
```

### स्ट्रिंग लिटरल

Gleam में स्ट्रिंग डबल कोट्स के बीच लिखी जाती हैं।

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### कोड कमेंट

कमेंट की मदद से सोर्स कोड पढ़ रहे दूसरे डेवलपर के लिए नोट छोड़े जा सकते हैं। Gleam में कमेंट एक ही लाइन के होते हैं, जिनसे पहले `//` लगाया जाता है।

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
