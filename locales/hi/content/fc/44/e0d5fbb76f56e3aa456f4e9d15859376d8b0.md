# परिचय

[Groovy](http://www.groovy-lang.org/) Apache Foundation की एक शक्तिशाली, वैकल्पिक रूप से टाइप की जाने वाली डायनामिक भाषा है, जिसमें स्टैटिक टाइपिंग और स्टैटिक कंपाइलेशन की क्षमताएँ भी हैं।

Groovy का उद्देश्य संक्षिप्त और सीखने में आसान सिंटैक्स की मदद से डेवलपर की उत्पादकता बढ़ाना है।
यह स्क्रिप्टिंग, डोमेन-स्पेसिफिक भाषा लिखने, रनटाइम और कंपाइल-टाइम मेटा-प्रोग्रामिंग, और फंक्शनल प्रोग्रामिंग को आसान बनाती है।

यह Java लाइब्रेरीज़ की पूरी दुनिया तक पहुँच देती है, और Java एप्लीकेशन के साथ बिना किसी अड़चन के जुड़ जाती है।

इसे एक आसान स्क्रिप्टिंग भाषा की तरह इस्तेमाल किया जा सकता है, या जटिल Java फ्रेमवर्क में जोड़ा जा सकता है।
यह कई तकनीकों को चलाती है, जैसे:
* Gradle,
* Spock,
* Ratpack,
* Grails,
* और Jenkins में स्क्रिप्टिंग।

इसके अलावा, यह मज़ेदार भी है।
