# निर्देश

नृत्य मंडली का हर रूटीन एक ही वार्म-अप पर बनता है। उसके बाद हर रूटीन अपने-अपने ढंग से आगे बढ़ता है।

स्टब आपको `WARM_UP` देता है। उसके नीचे तीन और क्लास लिखिए।

## 1. जैज़ रूटीन

`JAZZ_ROUTINE` `WARM_UP` से सब कुछ जैसा है वैसा ही लेता है और उसमें कुछ नहीं जोड़ता।

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. टैप रूटीन

`TAP_ROUTINE` `counts` को `WARM_UP` से लेता है, लेकिन अपने बारे में अपने ढंग से बताता है। इंक्लूड में `describe` को छोड़ दीजिए और एक नया `describe` लिखिए।

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. फिनाले

`FINALE` `counts` को `WARM_UP` से `warm_up_counts` नाम से लेता है और `describe` को छोड़ देता है। इसके बाद इसका अपना `counts` होता है, जो वार्म-अप के `counts` से दोगुना है, और अपना `describe` भी।

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

ध्यान दीजिए कि यह क्या दिखाता है: `FINALE::counts` और `WARM_UP::counts` एक जैसे नहीं हैं, और दोनों एक ही क्लास में अलग-अलग नामों से उपलब्ध हैं।
