# एक से अधिक क्लॉज़ वाले फंक्शन इस्तेमाल कीजिए

[comment]: # (The intention behind this comment is to tell people to use multiple clause functons, but because it's very hard to write good analysis for that, it instead checks for usages of if, case, and cond)

इस अभ्यास का उद्देश्य एक से अधिक क्लॉज़ वाले फंक्शन सिखाना है। इस अभ्यास को `if`, `case` या `cond` इस्तेमाल किए बिना हल कीजिए। इसके बजाय `compare` फंक्शन के एक से अधिक क्लॉज़ बनाइए।
