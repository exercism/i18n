# निर्देश

आप रख रहे हैं रोज़ का हिसाब कि आपके बगीचे में कितने पक्षी आते हैं। यह डेटा पूर्णांकों के एक ऐरे में संग्रहीत होता है, जिसमें **सबसे पहले आज की गिनती** होती है।

## 1. आज की गिनती

`today` को इस तरह बनाइए कि वह स्टैक से रोज़ की गिनतियों का एक ऐरे ले और आज की गिनती लौटाए। अगर ऐरे खाली है, तो वह `f` लौटाए।

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. आज की गिनती बढ़ाइए

`increment-day-count` को ऐसा बनाइए जो एक नया ऐरे लौटाए, जिसमें आज की गिनती एक से बढ़ी हुई हो। अगर इनपुट खाली है, तो `{ 1 }` लौटाइए।

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. क्या कोई ऐसा दिन था जब कोई पक्षी नहीं आया?

`has-day-without-birds?` को ऐसा बनाइए जो `t` लौटाए, अगर कम से कम एक दिन में शून्य पक्षी दर्ज हुए हों, वरना `f`।

`any?` या दूसरे हायर-ऑर्डर सीक्वेंस शब्दों के बजाय **रिकर्शन का इस्तेमाल कीजिए**।

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. शुरू करने के बाद से कुल पक्षी

`total` को ऐसा बनाइए जो हर गिनती का जोड़ लौटाए।

`sum` के बजाय **रिकर्शन का इस्तेमाल कीजिए**।

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. व्यस्त दिन

व्यस्त दिन वह होता है जिसमें पाँच या उससे अधिक पक्षी हों। `busy-days` को ऐसा बनाइए जो व्यस्त दिनों की संख्या लौटाए।

`count` के बजाय **रिकर्शन का इस्तेमाल कीजिए**।

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
