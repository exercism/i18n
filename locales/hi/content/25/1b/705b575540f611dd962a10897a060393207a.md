# परिचय

एक [टपल](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) बिना नाम की, पर एक तय क्रम में रखी वैल्यू का _अपरिवर्तनीय_ समूह है।
टपल में किसी भी डेटा टाइप की एक या अधिक वैल्यू रखी जा सकती हैं, यहाँ तक कि दूसरे टपल भी।

टपल को `(` और `)` के बीच कॉमा से अलग की गई वैल्यू के रूप में लिखा जाता है: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

सिर्फ वे टपल आपस में तुलना किए जा सकते हैं जिनकी लंबाई और टाइप (उसी क्रम में) एक जैसे हों।
टपल में संरचनात्मक समानता होती है। इसका मतलब है कि दो टपल _सिर्फ_ तभी बराबर होते हैं जब उनकी सभी वैल्यू बराबर हों।

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

टपल से वैल्यू निकालने के [तीन तरीके](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) हैं:

- `fst` और `snd` फंक्शन
- टपल डिकंस्ट्रक्शन
- पैटर्न मैचिंग

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
तकनीकी रूप से आप किसी टपल की वैल्यू उसकी `.Item1`, `.Item2`, ... प्रॉपर्टी की मदद से निकाल सकते हैं, लेकिन ऐसा करने की सलाह नहीं दी जाती और इससे कंपाइलर चेतावनी मिलती है।
~~~~

## टपल के बारे में मुख्य बातें

टपल के बारे में कुछ मुख्य बातें ये हैं:

- किसी टपल टाइप की एक खास वैल्यू अपने आप में एक ही ऑब्जेक्ट होती है, जैसे मान लीजिए C# में दो एलिमेंट वाला ऐरे। फंक्शन में इस्तेमाल करने पर टपल एक ही पैरामीटर के रूप में गिना जाता है। इसका एक ही अपवाद है: जब F# से बाहर के कोड को कई पैरामीटर के साथ कॉल किया जाता है, तो आप एक टपल देते हैं और उसकी वैल्यू अपने आप निकलकर उससे मेल खाते पैरामीटर की वैल्यू बन जाती हैं।
- टपल टाइप को कोई स्पष्ट नाम नहीं दिया जा सकता। टपल टाइप का “नाम” उन टाइपों के मेल से तय होता है जो आपस में मिलकर उस टाइप को बनाते हैं।
- टपल को बनाने वाला असली चिह्न ब्रैकेट नहीं, कॉमा है। आप ब्रैकेट के बिना भी टपल बना सकते हैं, हालाँकि कभी-कभी इससे उलझन हो सकती है। F# में अगर कहीं कॉमा दिखे, तो वह शायद किसी टपल का हिस्सा है।
- टपल को फंक्शन के आर्गुमेंट के रूप में और फंक्शन की रिटर्न वैल्यू के रूप में इस्तेमाल किया जा सकता है।
