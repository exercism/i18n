# परिचय

C# स्ट्रिंग्स के बारे में सबसे ज़रूरी बात यह है कि वे अपरिवर्तनीय ऑब्जेक्ट हैं, जो टेक्स्ट को Unicode अक्षरों के क्रम के रूप में दर्शाते हैं (अक्षर, अंक, विराम चिह्न, इत्यादि)। किसी `string` इंस्टेंस को बनाने के लिए डबल कोट का उपयोग किया जाता है:

```csharp
string fruit = "Apple";
```

किसी स्ट्रिंग में बदलाव उसके किसी [मेथड][methods] या [प्रॉपर्टी][properties] को कॉल करके किया जा सकता है। चूँकि स्ट्रिंग वैल्यू एक बार परिभाषित होने के बाद कभी नहीं बदल सकतीं, इसलिए स्ट्रिंग बदलने वाले सभी मेथड एक नई स्ट्रिंग लौटाते हैं।

स्ट्रिंग को डबल कोट (`"`) अक्षरों से सीमित किया जाता है। कुछ खास अक्षरों को बैकस्लैश (`\`) अक्षर का उपयोग करके [एस्केप करना][escaping] पड़ता है। स्ट्रिंग्स के आगे ऐट (`@`) चिह्न भी लगाया जा सकता है, जो उसे [वर्बेटिम स्ट्रिंग][verbatim] बना देता है, जिसमें एस्केप किए गए अक्षरों को नज़रअंदाज किया जाता है।

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

अगर आपको स्ट्रिंग का सिर्फ एक हिस्सा चाहिए, तो सिर्फ उसी हिस्से को निकालने के लिए आप [`Substring()` मेथड][substring] का उपयोग कर सकते हैं:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

किसी `string` के अंदर किसी `string` की पहली मौजूदगी का इंडेक्स ढूँढने के लिए [`IndexOf`() मेथड][indexof] का उपयोग किया जा सकता है। अगर दी गई वैल्यू न मिले तो यह `-1` लौटाता है:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

अंत में, [स्ट्रिंग जोड़ने के कई तरीके][concatenation] हैं। सबसे आसान तरीका [`+` ऑपरेटर][plus-operator] का उपयोग करना है।

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

साधारण जोड़ने से ज़्यादा जटिल किसी भी स्ट्रिंग फॉर्मेटिंग के लिए [स्ट्रिंग इंटरपोलेशन][interpolation] को प्राथमिकता दी जाती है। किसी स्ट्रिंग में इंटरपोलेशन चालू करने के लिए उसके आगे डॉलर (`$`) चिह्न लगाइए।

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
