# परिचय

## इंस्टेंस वेरिएबल

ऑब्जेक्ट _इंस्टेंस वेरिएबल_ सेट करके अपनी स्थिति खुद रख सकते हैं।
ये वेरिएबलो ऑब्जेक्ट के अंदर रहते हैं और आम तौर पर कुछ आंतरिक स्थिति संग्रहीत करने के लिए इस्तेमाल होते हैं।

इंस्टेंस वेरिएबल हमेशा `@` से शुरू होते हैं।
आप `@` से शुरू होने वाला वेरिएबल सेट करके नया इंस्टेंस वेरिएबल बना सकते हैं।
उदाहरण के लिए:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

ऑब्जेक्ट आम तौर पर अपनी शुरुआती स्थिति `initialize` मेथड में सेट करते हैं। किसी क्लास पर `new` कॉल करते समय इस मेथड को अपने आप कॉल किया जाता है।

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

`initialize` मेथड आर्गुमेंट भी ले सकता है, ताकि हर इंस्टेंस किसी अपनी अलग स्थिति से शुरू हो सके:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

इंस्टेंस वेरिएबलो को बाहर से पढ़ने और लिखने के लिए निजी मानना अच्छा तरीका है।
इसके बजाय हम उनकी वैल्यू पाने और सेट करने के लिए मेथड बनाते हैं।
उदाहरण के लिए:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] एक अंग्रेज़ी शब्द है जिसका मतलब "कुछ नहीं" या "शून्य" होता है।
Ruby में `nil` का इस्तेमाल किसी ऑब्जेक्ट की _अनुपस्थिति_ बताने के लिए किया जाता है।
दूसरी प्रोग्रामिंग भाषाओं में `null` या `none` वैल्यू भी वही भूमिका निभा सकती हैं।

```ruby
# I do not have a favorite color
favorite_color = nil
```

जब कोई इंस्टेंस वेरिएबल पहली बार सामने आता है, तो Ruby उसे डिफॉल्ट रूप से `nil` वैल्यू दे देता है, जब तक कि उसे कोई दूसरी वैल्यू न दी जाए।

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
