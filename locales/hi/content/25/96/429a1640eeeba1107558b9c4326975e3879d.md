# विस्तृत विवरण

जब कोई फंक्शन किसी दूसरे फंक्शन (या क्लोज़र) को पैरामीटर के रूप में लेता है, तो उस तरह पास किए गए क्लोज़र को डिफॉल्ट रूप से *नॉन-एस्केपिंग* कहा जाता है।
किसी क्लोज़र को किसी फंक्शन से *एस्केप करने वाला* तब कहा जाता है जब उसे उस फंक्शन के पहले ही लौट जाने के बाद कॉल किया जाता है।

यह स्थिति आम तौर पर तब बनती है जब:

- किसी क्लोज़र को किसी बाहरी वेरिएबल या प्रॉपर्टी में संग्रहीत किया जाता है।
- किसी क्लोज़र को कोई काम पूरा होने के बाद अतुल्यकालिक रूप से चलाया जाता है।
- किसी क्लोज़र को फंक्शन से लौटाया जाता है ताकि उसे बाद में कॉल किया जा सके।

इस उदाहरण को देखिए:

```swift
func emptyKitchen(_ order: String) -> String {
    "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}
```

इस कोड में `prepare` `kitchen` नाम का एक फंक्शन लेता है और उससे `newKitchen` नाम का नया फंक्शन बनाता है, जो `kitchen` को कॉल करता है।
अंत में `prepare` उसी `newKitchen` को लौटा देता है।
इस कोड को कंपाइल करने की कोशिश करने पर एक एरर मिलती है: `Escaping local function captures non-escaping parameter 'kitchen'`.

चूँकि `newKitchen` `prepare` के लौटने के बाद भी बना रहता है, इसलिए `kitchen` क्लोज़र एस्केप कर जाता है।
इसकी अनुमति देने के लिए पैरामीटर के टाइप पर `@escaping` एट्रिब्यूट लगाइए।

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}

let restaurant = prepare(
    order: "sandwich",
    kitchen: prepare(
        order: "chicken",
        kitchen: prepare(order: "steak", kitchen: emptyKitchen)
    )
)

print(restaurant("pork chop"))
// Prints "Sorry, we're all out of pork chop."

print(restaurant("chicken"))
// Prints "One chicken coming up!"
```

`@escaping` एट्रिब्यूट Swift कंपाइलर को बताता है कि यह क्लोज़र उस फंक्शन कॉल से ज़्यादा समय तक रहेगा जिसमें वह पास किया गया है।
इससे Swift मेमोरी और कैप्चर किए गए रेफरेंस दोनों का ठीक से प्रबंधन कर पाता है।
