# निर्देश

आप आईटी हेल्पडेस्क की टीम का हिस्सा हैं और अपने टिकटिंग सिस्टम को ज़्यादा कुशल बनाना चाहते हैं, ताकि यह तेज़ी से काम करे और आपकी मैनेजर के लिए आँकड़े भी दे सके।

हर टिकट का एक स्टेटस होता है (नया, प्रगति पर...), एक बनाने वाला होता है (जिसकी पहचान यूज़रनेम और कर्मचारी आईडी से होती है), उसे किसी आईटी कर्मचारी को असाइन किया जा सकता है, और उसमें टिप्पणियों का इतिहास रहता है।

यहाँ चार काम दिए गए हैं, जो आपके मौजूदा टिकटिंग सिस्टम को बेहतर बनाएँगे।

## 1. खाली टिप्पणियाँ पहचानिए

खाली टिप्पणियाँ इंटरफेस को भर देती हैं और कोई जानकारी नहीं देतीं। आप इन्हें छाँटकर हटाना चाहते हैं।

एक हेल्पर फंक्शन `emptyComment` बनाइए, जो यूज़र और टिप्पणी की जोड़ी लेता है और खाली टिप्पणियों के लिए `True` लौटाता है।

यूज़र और टिप्पणी को सीधे फंक्शन के आर्गुमेंट में निकालने के लिए डीस्ट्रक्चरिंग का इस्तेमाल कीजिए। यूज़र को अनदेखा कीजिए, क्योंकि आपको उस जानकारी की ज़रूरत नहीं है।

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. बनाने वाले की टिप्पणियों की संख्या गिनिए

आपकी मैनेजर टिकट प्रक्रिया में यूज़र की भागीदारी के आँकड़े चाहती हैं। वे आपसे जाँचने को कहती हैं कि टिकट बनाने वाले ने कितनी टिप्पणियाँ जोड़ी हैं।

`numberOfCreatorComments` बनाइए, जो एक टिकट लेता है और टिकट बनाने वाले की जोड़ी गई टिप्पणियों की संख्या लौटाता है।

फंक्शन के आर्गुमेंट में डीस्ट्रक्चरिंग का इस्तेमाल करके `Ticket` टाइप से रिकॉर्ड निकालिए, और साथ ही रिकॉर्ड से अपने ज़रूरी फील्ड भी निकालिए।
इसके बाद `createdBy` को एक `let` बाइंडिंग में डीस्ट्रक्चर कीजिए, ताकि आप संबंधित टिप्पणियाँ गिन सकें।
गिनती करने के लिए `List` के फंक्शन इस्तेमाल कीजिए, और एनोनिमस फंक्शन के आर्गुमेंट में डीस्ट्रक्चरिंग का इस्तेमाल करके यूज़र और टिप्पणी की जोड़ी अलग कीजिए।

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. डेव टीम को असाइन किए गए टिकट पहचानिए

कुछ टिकट डेव टीम के Alice, Bob या Charlie तक भेजने पड़ते हैं। ऐसे टिकटों पर नज़र रखना ज़रूरी है, ताकि पक्का किया जा सके कि उन पर काम आगे बढ़ रहा है।

एक हेल्पर फंक्शन `assignedToDevTeam` बनाइए, जो जाँचता है कि कोई टिकट डेव टीम के किसी सदस्य को असाइन किया गया है या नहीं।

फंक्शन के आर्गुमेंट में डीस्ट्रक्चरिंग का इस्तेमाल करके `Ticket` टाइप से रिकॉर्ड और अपना ज़रूरी फील्ड निकालिए।
इसके बाद एक ही `case` स्टेटमेंट से जाँचिए कि टिकट Alice, Bob या Charlie को असाइन है या नहीं, जिसमें रिकर्सिव पैटर्न मैचिंग से उनके यूज़रनेम निकालिए और लिटरल पैटर्न मैचिंग से उन्हें मैच कीजिए।

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. टिकट आईटी कर्मचारियों को असाइन कीजिए

कभी-कभी कई सारे टिकट दूसरे आईटी कर्मचारियों को दोबारा असाइन करने पड़ते हैं।

इसमें मदद के लिए एक फंक्शन `assignTicketTo` बनाइए। यह फंक्शन दो आर्गुमेंट लेता है: वह यूज़र, जिसे टिकट असाइन करना है, और एक टिकट।
अगर टिकट का स्टेटस `New` है, तो उसे नए यूज़र को असाइन कीजिए और स्टेटस बदलकर `InProgress` कर दीजिए।
बाकी स्टेटस के लिए टिकट को बस नए यूज़र को दोबारा असाइन कर दीजिए, लेकिन `Archived` स्टेटस वाले टिकटों को बिल्कुल भी नहीं बदलना चाहिए।

फंक्शन के आर्गुमेंट में डीस्ट्रक्चरिंग का इस्तेमाल करके `Ticket` टाइप से रिकॉर्ड और अपना ज़रूरी फील्ड निकालिए, और `as` कीवर्ड से पूरा रिकॉर्ड जैसा है वैसा ही पकड़िए।
एक ही `case` स्टेटमेंट से स्टेटस पर पैटर्न मैचिंग कीजिए और उचित टिकट लौटाइए, जो `as` कीवर्ड से पकड़े गए मूल रिकॉर्ड में बदलाव करके बनाया गया हो।

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
--        { status = InProgress
--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
