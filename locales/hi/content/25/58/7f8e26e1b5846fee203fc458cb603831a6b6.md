# निर्देश

आप एक स्थानीय बास्केटबॉल टीम की वेबसाइट बनाए रखने के लिए एक वेब डेवलपमेंट टीम के साथ काम कर रहे हैं। वेब डेवलपमेंट टीम Elixir से कम परिचित है और तेज़ विकास को सुविधाजनक बनाने के लिए नेस्टेड मैप की श्रृंखला से डेटा निकालने वाला एक फंक्शन माँग रही है।

## 1. नेस्टेड मैप संरचना से डेटा निकालिए

`extract_from_path/2` फंक्शन को बनाइए, जो दो आर्गुमेंट लेता है:

- `data`: बास्केटबॉल टीम के बारे में डेटा वाली एक नेस्टेड मैप संरचना।
- `path`: एक स्ट्रिंग, जिसमें डॉट से अलग कीज़ होती हैं और जिससे अंतिम की से जुड़ी वैल्यू प्राप्त की जाती है।

यदि पथ में किसी भी बिंदु पर वैल्यू या की मौजूद न हो, तो `nil` लौटाया जाना चाहिए।

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

इस फंक्शन को बनाते समय _Access Behaviour_ का उपयोग कीजिए।

नेस्टेड मैप डेटा संरचना के साथ काम करने के लिए `Map` या `Kernel` मॉड्यूल के किसी भी फंक्शन का उपयोग न कीजिए।

## 2. शामिल फंक्शनों का उपयोग करके रीफैक्टर कीजिए

आपके कोड की समीक्षा करने वाला आपका सहकर्मी आपको `Kernel` मॉड्यूल के एक फंक्शन के बारे में बताता है, जो आपके कार्यान्वयन से बहुत मिलता-जुलता काम करता है।

इस `Kernel` मॉड्यूल फंक्शन का उपयोग करने के लिए `get_in_path/2` बनाइए।

अपेक्षित आर्गुमेंट वही हैं जो भाग 1 में हैं।

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
