# इसके बारे में

`when` एक्सेप्शन फिल्टर करने का कीवर्ड है। इसे `catch` स्टेटमेंट के बाद रखा जाता है और यह कोई भी बूलियन एक्सप्रेशन ले सकता है, जिसमें उस समय स्कोप में मौजूद कोई भी वैल्यू आ सकती है। ज़रूरी नहीं कि ये वैल्यू सिर्फ एक्सेप्शन के अपने सदस्य ही हों। अगर एक्सेप्शन का टाइप मेल खाता है और एक्सप्रेशन का मान सही होता है, तो उस `catch` स्टेटमेंट से जुड़ा ब्लॉक चलाया जाता है। अगर ऐसा नहीं है, तो अगला `catch` स्टेटमेंट, अगर कोई हो, जाँचा जाता है।

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- यह [एक्सेप्शन फिल्टर][exception-filters] लेख दिखाता है कि एक्सेप्शन को कैसे फिल्टर किया जाता है।

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
