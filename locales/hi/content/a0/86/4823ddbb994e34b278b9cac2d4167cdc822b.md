# निर्देशों का पूरक

## Prolog में तारीखों के साथ काम करना

Prolog में तारीखों के लिए अंतर्निहित समर्थन [काफी बुनियादी है][built-in-dates-support]।
तारीखों के साथ काम करने का एक कहीं बेहतर तरीका [date_time पैकेज][date_time-package] है।

### date_time पैकेज इंस्टॉल करना

अगर आपका इंस्टॉल किया हुआ Swipl वर्ज़न काफी नया है, तो आप यह पैकेज इस तरह इंस्टॉल कर सकते हैं:

```bash
swipl pack install date_time
```

अगर वह काम न करे, तो आप यह चला सकते हैं:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
अगर आप ऑनलाइन एडिटर इस्तेमाल कर रहे हैं, तो आपको कुछ भी खुद इंस्टॉल करने की ज़रूरत नहीं है।
~~~~

### date_time पैकेज का उपयोग करना

`date_time` पैकेज इस्तेमाल करने के लिए अपनी हल फाइल के सबसे ऊपर यह कोड जोड़िए:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
सुझाव: [date_time पैकेज का सोर्स][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] का डॉक्यूमेंटेशन बहुत अच्छा है और वह आपके बहुत काम आएगा!
~~~~
