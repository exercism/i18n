# इसके बारे में

**क्लोज़र** [Clojure में][clojure-guide-closures] एक प्रोग्रामिंग पैटर्न है जो बाहरी [लेक्सिकल स्कोप][wiki-lexical-scope] से वेरिएबलो को किसी फंक्शन के अंदर इस्तेमाल करने की अनुमति देता है। Clojure क्लोज़र को पारदर्शी ढंग से समर्थन देता है, और अक्सर इन्हें यह जाने बिना इस्तेमाल किया जाता है कि ये वास्तव में क्या हैं।

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## स्थिति सहेजने और वैल्यू आगे पहुँचाने के लिए क्लोज़र

एक एटम इस्तेमाल करने से कुछ स्थिति सुरक्षित रखी जा सकती है:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

`increment` को हर बार कॉल करने पर उसका काउंटर बढ़ता है:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
