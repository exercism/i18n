# परिचय

कई भाषाओं में `null` या `none` जैसा कोई तरीका होता है, जो बताता है कि कोई वैल्यू मौजूद ही नहीं है। चूँकि R को बड़ी मात्रा में (और अक्सर बिखरा हुआ) डेटा संभालने के लिए बनाया गया है, इसलिए इसमें "कुछ न होने" के कई रूप हैं।

इसका मुख्य उद्देश्य यह है कि जब भी कोई गायब या संदिग्ध वैल्यू सामने आए, उसे चिह्नित कर दिया जाए और फिर बिना कोई एक्सेप्शन उठाए काम आगे चलता रहे।

## NULL

अगर कोई वैल्यू सचमुच मौजूद ही नहीं है, तो उसे `NULL` से दर्शाया जाता है। यह शायद C या Python के तरीके के सबसे करीब है।

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

कई जगहों पर `NULL` वैल्यू को बस अनदेखा कर दिया जाता है:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

ऐसी स्थितियों के लिए, जहाँ वैल्यू मौजूद तो है पर हमें पता नहीं कि वह क्या है, `NA` का उपयोग किया जाता है। उदाहरण के लिए, सड़क पर चलने वाले वाहनों की गिनती करते समय हो सकता है कि गिनती करने वाले लोग बीमार पड़ जाएँ या स्वचालित सेंसर खराब हो जाएँ, लेकिन यातायात बहता रहता है।

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

इस तरह `NA` एक प्लेसहोल्डर है, जो लोगों को चेतावनी देता है कि उन्हें तय करना है कि इस स्थिति को कैसे संभालना है।

## NaN

`NaN` "Not a Number" का छोटा रूप है और उन स्थितियों में गणना की समस्या बताता है जहाँ किसी संख्या की अपेक्षा थी।

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

"अमान्य" गणनाओं के लिए यही एकमात्र संभावना नहीं है।
अगर अंश शून्य न हो, तो शून्य से भाग देने पर बिना कोई एरर उठाए `Inf` या `-Inf` लौटता है।

```R
1 / 0
#> [1] Inf
```

## खाली वेक्टर

शायद हैरानी की बात है कि R में खालीपन जाँचने का कोई मानक तरीका नहीं है।

यहाँ तक कि खाली वेक्टर बनाना भी पूरी तरह स्पष्ट नहीं है।
हमने पिछले एक भाग में देखा था कि बिना किसी आर्गुमेंट के `c()` कोई वेक्टर नहीं, बल्कि `NULL` लौटाता है।

```R
is.vector(c())
#> [1] FALSE
```

`logical()` या `integer()` जैसे फंक्शन एक आर्गुमेंट लेते हैं जो मनचाही लंबाई बताता है, और यह लंबाई शून्य भी हो सकती है।

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

हम एक वेक्टर बनाकर उसका हर एलिमेंट हटा भी सकते हैं, जैसा [वेक्टर कॉन्सेप्ट][concept-vectors] में बताया गया है।
इससे उपयुक्त टाइप का लंबाई-0 वाला वेक्टर मिलता है।

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
