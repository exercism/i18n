# परिचय

Haxe में **ऐरे** एलिमेंट्स का एक संग्रह होता है, जो (आम तौर पर) एक ही टाइप के होते हैं। Haxe में ऐरे बनाने के तीन तरीके हैं, या तो कंस्ट्रक्टर से या डिक्लेरेशन सिंटैक्स से। Haxe में ऐरे के पहले एलिमेंट का इंडेक्स शून्य होता है:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

कंस्ट्रक्टर की मदद से ऐरे बनाने के लिए आपको उन एलिमेंट्स का टाइप देना होगा जो ऐरे में शामिल किए जाएँगे:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

अगर हम चाहते हैं कि एक ऐरे में अलग-अलग टाइप के एलिमेंट्स रहें, तो हम टाइप इंडिकेटर में `Dynamic` टाइप जोड़ देते हैं:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
