# निर्देश

आप एक उत्साही पक्षी-निरीक्षक हैं, जो यह हिसाब रखते हैं कि आपके बगीचे में कितने पक्षी आए हैं। आम तौर पर आप पक्षियों को गिनने के लिए नोटबुक में गिनती का हिसाब रखते हैं, लेकिन अब आप अपने डेटा के साथ बेहतर तरीके से काम करना चाहते हैं। पिछले कुछ सप्ताहों की रोज़ की पक्षी-गिनती, जो आपने नोटबुक में रखी थी, आप पहले ही डिजिटल रूप में दर्ज कर चुके हैं।

अब आप यह पता करना चाहते हैं कि आपने कुल कितने पक्षी गिने, किसी खास सप्ताह की पक्षी-गिनती निकालनी है और गिनती की एक गलती सुधारनी है।

## 1. अब तक गिने गए पक्षियों की कुल संख्या ज्ञात कीजिए

चलिए, पहले समग्र रूप से देखकर डेटा का विश्लेषण शुरू करते हैं। पता कीजिए कि जब से आपने अपने रिकॉर्ड रखना शुरू किया, आपने कुल कितने पक्षी गिने।

एक फंक्शन `totalBirdCount` बनाइए, जो एक ऐरे जैसा ऑब्जेक्ट लेता है जिसमें हर दिन की पक्षी-गिनती होती है। इसे आपके गिने गए पक्षियों की कुल संख्या लौटानी चाहिए।

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. किसी खास सप्ताह में आने वाले पक्षियों की संख्या निकालिए

अब जब आपको अपनी पक्षी-गिनती के आंकड़ों की सामान्य समझ हो गई है, तो आप और बारीक विश्लेषण करना चाहते हैं।

एक फंक्शन `birdsInWeek` बनाइए, जो हर दिन की पक्षी-गिनती वाला ऐरे जैसा ऑब्जेक्ट और सप्ताह की संख्या लेता है। यह उस खास सप्ताह में गिने गए पक्षियों की कुल संख्या लौटाता है। आप यह मान सकते हैं कि हर सप्ताह का हिसाब हमेशा पूरा रखा जाता है।

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. गिनती की एक गलती सुधारिए

आपको पता चला कि जब-जब आप पक्षियों का हिसाब रखने की कोशिश कर रहे थे, तब एक पक्षी बगीचे के एक दूर कोने में छिपा रहता था। आपने पता लगाया कि यह पक्षी हर दूसरे दिन आपके बगीचे में रहता था। आपको ठीक-ठीक पता नहीं है कि वह पक्षी उन दिनों के बीच कहाँ रहता था, लेकिन निश्चित रूप से आपके बगीचे में नहीं था। पक्षी-निरीक्षक के रूप में आपका अंतर्ज्ञान यह भी बताता है कि जिस पहले दिन का आपने अपने रिकॉर्ड में हिसाब रखा, उस दिन वह पक्षी आपके बगीचे में था।

इस नई जानकारी के आधार पर एक फंक्शन `fixBirdCountLog` लिखिए, जो आर्गुमेंट के रूप में हर दिन गिने गए पक्षियों वाला ऐरे जैसा ऑब्जेक्ट लेता है। इसे दिए गए ऐरे को बदलकर गिनती की गलती सुधारनी चाहिए।

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
