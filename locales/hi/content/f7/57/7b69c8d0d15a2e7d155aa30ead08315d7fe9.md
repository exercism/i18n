# निर्देश

आपका एक ऑनलाइन फैशन बुटीक है। आपकी इन्वेंट्री में हर आइटम दो एलिमेंट का एक ऐरे होता है, `{ name price }`, और पूरी इन्वेंट्री इन आइटमों का एक ऐरे होती है।

जिस आइटम का कोई मूल्य नहीं होता, उसके लिए `f` लिखा जाता है।

## 1. इन्वेंट्री को मूल्य के अनुसार क्रम में लगाइए

`sort-by-price` बनाइए जो आइटमों को मूल्य के बढ़ते क्रम में लगाकर एक नया ऐरे लौटाता है।

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. वे आइटम ढूँढिए जिनका मूल्य तय नहीं है

`with-missing-price` बनाइए जो केवल उन आइटमों का एक ऐरे लौटाता है जिनका मूल्य `f` है।

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. महँगे आइटम गिनिए

`expensive-items` बनाइए जो एक इन्वेंट्री और एक मूल्य सीमा लेता है, और उन आइटमों की संख्या लौटाता है जिनका मूल्य सीमा से अधिक है।

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. सबसे सस्ता आइटम ढूँढिए

`cheapest-item` बनाइए जो सबसे कम मूल्य वाला आइटम लौटाता है। जिन आइटमों का कोई मूल्य नहीं है (`f`), वे इनपुट में नहीं आएँगे।

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. सभी मूल्यों का जोड़ निकालिए

`total-price` बनाइए जो सभी मूल्यों का जोड़ लौटाता है। जिन आइटमों का कोई मूल्य नहीं है (`f`), वे इनपुट में नहीं आएँगे।

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. किसी आइटम का मूल्य टैग बनाइए

`format-price-tag` बनाइए जो किसी आइटम के लिए `"name: $price"` के रूप की एक स्ट्रिंग लौटाता है। जिन आइटमों का कोई मूल्य नहीं है (`f`), वे यहाँ नहीं आएँगे।

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
