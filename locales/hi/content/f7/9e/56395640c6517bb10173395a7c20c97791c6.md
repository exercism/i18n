# वर्कफ्लो

GitHub Actions में _वर्कफ्लो_ की अवधारणा इस्तेमाल होती है: ये ऐसी स्क्रिप्ट हैं जो कोई खास घटना होने पर अपने आप चलती हैं (जैसे कि कोई कमिट पुश करना)।

GitHub Actions का हर वर्कफ्लो `.github/workflows` डायरेक्टरी में एक `.yml` फ़ाइल में परिभाषित होता है।
वर्कफ्लो के बारे में जानकारी के लिए, इन दस्तावेज़ों को देखिए:

- [वर्कफ्लो सिंटैक्स](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)
- [आपका वर्कफ्लो कब चलता है, यह चुनना](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/triggering-a-workflow)
- [आपका वर्कफ्लो कहाँ चलता है, यह चुनना](https://docs.github.com/en/actions/writing-workflows/choosing-where-your-workflow-runs)
- [आपका वर्कफ्लो क्या करता है, यह चुनिए](https://docs.github.com/en/actions/writing-workflows/choosing-what-your-workflow-does)
- [वर्कफ्लो लिखना](https://docs.github.com/en/actions/writing-workflows)
- [सर्वोत्तम प्रथाएँ](/docs/building/github/gha-best-practices)

## साझा वर्कफ्लो

कुछ वर्कफ्लो कई रिपॉज़िटरी में साझा किए जाते हैं।

```exercism/caution
साझा वर्कफ्लो अपने आप सिंक किए जाते हैं ([org-wide-files रिपॉज़िटरी](https://github.com/exercism/org-wide-files/) से)।
इसलिए आपको उनकी सामग्री मैन्युअल रूप से नहीं बदलनी चाहिए।
```

### सामान्य वर्कफ्लो

- [लेबल सिंक करना](/docs/building/tracks/ci/workflows/sync-labels): रिपॉज़िटरी के लेबल फ़ाइल से सिंक करता है।

### ट्रैक-विशिष्ट वर्कफ्लो

- [configlet](/docs/building/tracks/ci/workflows/configlet): जाँचता है कि ट्रैक की (कॉन्फ़िगरेशन) फ़ाइलें सिंटैक्स और अर्थ, दोनों दृष्टियों से ठीक से संरचित हैं या नहीं।
- [कोई ज़रूरी फ़ाइल नहीं बदली](/docs/building/tracks/ci/workflows/no-important-files-changed): ऐसे पुल रिक्वेस्ट पर कमेंट करता है जिनसे मौजूदा हल फिर से टेस्ट हो सकते हैं।
- [टेस्ट](/docs/building/tracks/new/setup-continuous-integration#h-test-workflow): ट्रैक के अभ्यासों की जाँच करता है।

### टूल-विशिष्ट वर्कफ्लो

- [डिप्लॉय करना](/docs/building/tracks/ci/workflows/deploy): ट्रैक टूल की Docker इमेज को Docker Hub और ECR पर डिप्लॉय करता है।

### वैकल्पिक वर्कफ्लो

कुछ ऐसे वर्कफ्लो भी हैं जिन्हें ट्रैक चुन सकते हैं:

- [कम्युनिटी योगदान रोकना](/docs/building/tracks/ci/workflows/pause-community-contributions): Exercism GitHub संगठन के सदस्य नहीं हैं, ऐसे उपयोगकर्ताओं द्वारा बनाए गए नए इश्यू और PR पर अपने आप कमेंट करता है।
