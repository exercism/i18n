# टेस्ट

टेस्ट चलाने के लिए इन चरणों का पालन कीजिए:

- अभ्यास की डायरेक्टरी में जाइए (जैसे `~/Exercism/hello-world`)।
- टर्मिनल में `jconsole` सेशन शुरू कीजिए (जैसे `jconsole` या `ijconsole` टाइप करके)।
- अपने हल की फाइल लोड कीजिए (जैसे `load 'hello-world.ijs'`)।
- `load  'general/unittest'` टाइप करके यूनिट टेस्ट फ्रेमवर्क लोड कीजिए।
- `unittest 'test.ijs'` टाइप करके अपने हल की जाँच कीजिए।
<br></br>
- इसके अलावा, आप सारे टेस्ट एक ही लाइन में इस तरह भी चला सकते हैं: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## छोड़े गए टेस्ट

शुरू में सिर्फ पहला टेस्ट ही सक्रिय रहेगा।
यह तरीका आपको अभ्यास को चरण-दर-चरण हल करने के लिए प्रोत्साहित करता है।
हर टेस्ट की परिभाषा के ऊपर उसका एक नाम दिया होता है, जिसके अंत में _'\_ignore'_ आता है।
उस टेस्ट को चलाने के लिए उसकी वैल्यू बदलकर 0 कर दीजिए।

### उदाहरण:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
