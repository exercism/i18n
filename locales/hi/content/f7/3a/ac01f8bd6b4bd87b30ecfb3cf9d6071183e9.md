# परिचय

C# का [`enum` टाइप](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) नामित कॉन्स्टेंट के एक निश्चित समूह को दर्शाता है (एक एन्यूमरेशन)।

सामान्यतः, `enum` का एक मेंबर उन नामित कॉन्स्टेंट में से केवल ठीक एक को ही संदर्भित कर सकता है। हालाँकि, कभी-कभी एक से अधिक कॉन्स्टेंट को संदर्भित करना उपयोगी होता है। ऐसा करने के लिए, `enum` पर [`Flags` एट्रिब्यूट](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) लगाया जा सकता है।

एक फ्लैग्स एनम को इस प्रकार परिभाषित किया जा सकता है (बाइनरी पूर्णांक संकेतन `0b` का उपयोग करके):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

`PhoneFeatures` के एक ऐसे इंस्टेंस में जिसकी वैल्यू `0b00000011` है, `Call` _और_ `Text` दोनों फ्लैग सेट होते हैं।

डिफॉल्ट रूप से, एनम मेंबर की वैल्यू के लिए `int` टाइप का उपयोग किया जाता है। एनम की घोषणा में टाइप निर्दिष्ट करके एक अलग पूर्णांक टाइप का उपयोग किया जा सकता है:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
