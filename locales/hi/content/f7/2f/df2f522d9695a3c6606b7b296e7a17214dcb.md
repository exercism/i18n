# परिचय

## JSON

JSON (JavaScript Object Notation) एक ऐसा डेटा और फाइल फॉर्मेट है जिसे इंसान पढ़ सकते हैं। इसका उपयोग आमतौर पर डेटा के आदान-प्रदान के लिए होता है, खासकर वेब ऐप्लिकेशन में। इसलिए यह कोई आश्चर्य की बात नहीं है कि Elm भाषा में इसका एक खास स्थान है।

Elm में मुख्य मॉड्यूल `Json.Decode` और `Json.Encode` दिए गए हैं, जिनसे JSON डेटा पढ़ा और लिखा जा सकता है। JSON डिकोडर एक तरीका है जिससे आप _घोषित_ करते हैं कि किस तरह का डेटा अपेक्षित है और डेटा को किस डेटा स्ट्रक्चर में ढालना है।

चलिए इन मॉड्यूल से कुछ एलियस और टाइप इंपोर्ट करते हैं:

```elm
import Json.Decode as Decode exposing (Decoder, Error)
import Json.Encode as Encode exposing (Value)
```

किसी डिकोडर और एक JSON स्ट्रिंग के साथ `Decode.decodeString : Decoder a -> String -> Result Error a` का उपयोग करने पर, अगर स्ट्रिंग डिकोडर की शर्तों के अनुरूप है तो परिणाम सफल होगा, वरना वह विफल हो जाएगा। डिकोडर बनाते समय कच्चे JSON डेटा को देखने का कोई तरीका नहीं है, जो इम्परेटिव भाषाओं से आने वाले किसी व्यक्ति को असामान्य लग सकता है।

## बुनियादी डेटा टाइप के डिकोडर

JSON में थोड़े ही मुख्य डेटा टाइप होते हैं:

- स्ट्रिंग: डबल कोट्स के अंदर लिखी जाती है `"hello world"`
- बूलियन: या तो `true` या `false`
- संख्या: जैसे `34` या `0.12`
- Null: डेटा का न होना, `null`

इनमें से हर एक के लिए `Decode` का एक फंक्शन है:

```elm
Decode.decodeString Decode.string """\"hello\""""
    --> Ok "hello"

Decode.decodeString Decode.string """null"""
    --> Err ...

Decode.decodeString Decode.bool """true"""
    --> Ok True

Decode.decodeString Decode.bool """0"""
    --> Err ...

Decode.decodeString Decode.int """12"""
    --> Ok 12

Decode.decodeString Decode.float """3.14"""
    --> Ok 3.14

Decode.decodeString (Decode.null AnyValue) """null"""
    --> Ok AnyValue

Decode.decodeString (Decode.null AnyValue) """true"""
    --> Err ...
```

ध्यान दीजिए कि `Decode.null` आपको यह तय करने देता है कि अपने प्रोग्राम में `null` को कैसे ढालें, क्योंकि इसे आर्गुमेंट के तौर पर कोई भी वैल्यू देनी पड़ती है (शायद `()`, `Nothing`, या आपके प्रोग्राम के लिए उपयुक्त कोई भी चीज़)।

## डिकोडर को जोड़ना

JSON में दो और डेटा स्ट्रक्चर भी तय किए गए हैं, जो मुख्य डेटा टाइप को इकट्ठा करते हैं:

- ऐरे: दूसरे डेटा टाइप का संग्रह `[0, null, "none", []]`
- ऑब्जेक्ट: की-वैल्यू जोड़ों का संग्रह `{"id": 1, "is_admin": false, "more_info": {}}`

`Decode` इन्हें डिकोड करने के लिए भी फंक्शन देता है:

```elm
Decode.decodeString (Decode.list Decode.int) """[1, 2, 3]"""
    --> Ok [1, 2, 3]

Decode.decodeString (Decode.list Decode.int) """[1, 2, 3, "not an int"]"""
    --> Err ...

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": 71 }"""
    --> Ok (Dict.fromList [("key1", 17), ("key2", 71)])

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": "seventy-one" }"""
    --> Err ...
```

ये दोनों फंक्शन, `Decode.list : Decoder a -> Decoder (List a)` और `Decode.dict : Decoder a -> Decoder (Dict String a)`, आर्गुमेंट के तौर पर एक डिकोडर लेते हैं, और वह डिकोडर डेटा स्ट्रक्चर के हर एक एलिमेंट को डिकोड करता है। अगर आर्गुमेंट वाला डिकोडर ऐरे या ऑब्जेक्ट वैल्यू के किसी भी एलिमेंट को डिकोड नहीं कर पाता, तो पूरा डिकोडर विफल हो जाता है। यह एक आम पैटर्न है।

सरल डिकोडर को जोड़कर ज़्यादा जटिल डिकोडर बनाना ही इस तकनीक का मूल विचार है। हम एक उदाहरण के ज़रिए कुछ और फंक्शन बताएँगे, जिनसे असली दुनिया के किसी भी जटिल डेटा के डिकोडर बनाए जा सकते हैं।

## GeoJSON

बुनियादी डिकोडर को जोड़कर जटिल JSON डेटा पढ़ने का अभ्यास करने के लिए, चलिए GeoJSON डेटा (के एक हिस्से) को पढ़ने वाले डिकोडर बनाते हैं। GeoJSON एक खास तरह का JSON आधारित डेटा फॉर्मेट है। इसका उपयोग भौगोलिक विशेषताएँ दर्शाने के लिए होता है, जैसे स्थान, रास्ते या क्षेत्र। इन्हें 2D या 3D भौगोलिक निर्देशांकों से बताया जाता है, और साथ में अन्य प्रॉपर्टी भी दी जाती हैं।

### ज्यामिति ऑब्जेक्ट

GeoJSON का ज्यामिति ऑब्जेक्ट एक ऑब्जेक्ट होता है। इसमें `type` नाम का एक फील्ड होता है जिसकी वैल्यू एक स्ट्रिंग होती है (टाइप की 7 संभावित वैल्यू होती हैं), और `coordinates` नाम का एक फील्ड होता है जिसमें भौगोलिक निर्देशांक होते हैं (ये एक ऐसे स्ट्रक्चर में इकट्ठा किए जाते हैं जो टाइप पर निर्भर करता है)। उदाहरण के लिए,

```json
{
  "type": "Point",
  "coordinates": [127.831, 26.461]
}
```

या

```json
{
  "type": "LineString",
  "coordinates": [
    [127.831, 26.461],
    [127.829, 26.465],
    [127.829, 26.469],
    [127.83, 26.47]
  ]
}
```

Elm में ज्यामिति ऑब्जेक्ट को इस टाइप से दर्शाया जा सकता है

```elm
type Geometry
  = Point (List Float)
  | LineString (List (List Float))
  | ...
```

किसी खास फील्ड की वैल्यू जाँचने के लिए हम `Decode.field : String -> Decoder a -> Decoder a` का उपयोग कर सकते हैं, जो किसी ऑब्जेक्ट की एक खास की की वैल्यू डिकोड करता है।

```elm
decodePointCoordinates : Decoder (List Float)
decodePointCoordinates =
    Decode.field "coordinates" (Decode.list Decode.float)

decodeLineStringCoordinates : Decoder (List (List Float))
decodeLineStringCoordinates =
    Decode.field "coordinates" (Decode.list (Decode.list Decode.float))
```

किसी डिकोडर द्वारा सफलतापूर्वक पढ़ी गई वैल्यू को बदलने के लिए हम `Decode.map : (a -> value) -> Decoder a -> Decoder value` का उपयोग कर सकते हैं, या इसके भाई-बहनों में से किसी का भी, `Decode.map2  (a -> b -> value) -> Decoder a -> Decoder b -> Decoder value` से लेकर `Decode.map8` तक।

यहाँ हमें `type` फील्ड की वैल्यू के आधार पर तय करना है कि कौन-सा निर्देशांक डिकोडर उपयोग करना है। इसके लिए `Decode.andThen : (a -> Decoder b) -> Decoder a -> Decoder b` और उसके साथी `Decode.succeed : a -> Decoder a` तथा `Decode.fail : String -> Decoder a` एकदम सही हैं।

```elm
decodeGeometry : Decoder Geometry
decodeGeometry =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                case value of
                    "Point" ->
                        decodePointCoordinates |> Decode.map Point

                    "LineString" ->
                        decodeLineStringCoordinates |> Decode.map LineString

                    _ ->
                        Decode.fail "Geometry not implemented yet, or invalid type value"
            )
```

यहाँ ध्यान दीजिए कि हम निर्देशांकों की जाँच करने के लिए भी `Decode.andThen` का उपयोग कर सकते हैं (यह देखना कि निर्देशांक जोड़ों या तिकड़ियों में आते हैं, और यह जाँचना कि निर्देशांकों की वैल्यू भौगोलिक रूप से तर्कसंगत हैं)।

```elm
Decode.decodeString decodeGeometry """{"type": "Point", "coordinates": [127.831, 26.461]}"""
    --> Ok (Point [127.831, 26.461])

Decode.decodeString decodeGeometry """{"type": "LineString", "coordinates": [127.831, 26.461]}"""
    --> Err ...
```

### फीचर ऑब्जेक्ट

GeoJSON का फीचर ऑब्जेक्ट किसी ऐसी चीज़ को दर्शाता है जो स्थान में सीमित है: इसमें एक `type` फील्ड होता है जिसकी वैल्यू `"Feature"` होती है, एक `geometry` फील्ड होता है जिसमें ज्यामिति ऑब्जेक्ट या `null` होता है, एक `properties` फील्ड होता है जिसमें कोई भी JSON ऑब्जेक्ट या `null` हो सकता है, और एक वैकल्पिक `id` फील्ड होता है जिसकी वैल्यू JSON स्ट्रिंग या संख्या होती है।

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": null
}
```

या

```json
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
```

चलिए पहले `id` फील्ड को देखते हैं। अगर यह मौजूद है, तो इसमें स्ट्रिंग या संख्या दोनों हो सकती हैं, इसलिए हम या तो वैल्यू के लिए एक कस्टम टाइप बना सकते हैं, या उसे हमेशा स्ट्रिंग के रूप में ही रख सकते हैं।

दो संभावित डिकोडर में से चुनने के लिए हम `Decode.oneOf : List (Decoder a) -> Decoder a` का उपयोग कर सकते हैं।

```elm
decodeFeatureId : Decoder String
decodeFeatureId =
    Decode.oneOf
        [ Decode.string
        , Decode.int |> Decode.map String.fromInt
        , Decode.float |> Decode.map String.fromFloat
        ]
        |> Decode.field "id"

Decode.decodeString decodeFeatureId """{"id": "seventeen"}"""
    --> Ok "seventeen"

Decode.decodeString decodeFeatureId """{"id": 17}"""
    --> Ok "17"

Decode.decodeString decodeFeatureId """{"type": "Point"}"""
    --> Er ...
```

यह बताने के लिए कि फील्ड वैकल्पिक है, हम वही तरीका उपयोग कर सकते हैं

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.oneOf
        [ decodeFeatureId |> Decode.map Just
        , Decode.succeed Nothing
        ]
```

लेकिन इसके बजाय हम `Decode.maybe : Decoder a -> Decoder (Maybe a)` का उपयोग कर सकते हैं

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.maybe decodeFeatureId

Decode.decodeString decodeMaybeFeatureId """{"id": 17}"""
    --> Ok (Just "17")

Decode.decodeString decodeMaybeFeatureId """{"type": "Point"}"""
    --> Ok Nothing
```

ध्यान दीजिए कि `decodeMaybeFeatureId` (या `Decode.maybe` में लिपटा कोई भी डिकोडर) हमेशा सफल होगा, क्योंकि वह हमेशा `Ok Nothing` पर लौट सकता है। हालाँकि, जो डिकोडर उसका उपयोग करता है वह अब भी विफल हो सकता है

```elm
Decode.decodeString (Decode.list decodeMaybeFeatureId) """{"id": 17}"""
    --> Err ...
```

अब चलिए `geometry` फील्ड पर ध्यान देते हैं, जिसमें या तो ज्यामिति ऑब्जेक्ट हो सकता है या `null`। हम एक बार फिर `Decode.oneOf` का उपयोग कर सकते हैं, लेकिन इससे बेहतर एक और विकल्प है: `Decode.nullable : Decoder a -> Decoder (Maybe a)`।

```elm
decodeFeatureGeometry : Decoder (Maybe Geometry)
decodeFeatureGeometry =
    Decode.nullable decodeGeometry
        |> Decode.field "geometry"

Decode.decodeString decodeFeatureGeometry """{"geometry": {"type": "Point", "coordinates": [127.831, 26.461]}}"""
    --> Ok (Just (Point [127.831, 26.461]))

Decode.decodeString decodeFeatureGeometry """{"geometry": null}"""
    --> Ok Nothing

Decode.decodeString decodeFeatureGeometry """{"geometry": {}}"""
    --> Err ...
```

`Decode.maybe` और `Decode.nullable` का सिग्नेचर एक जैसा है, लेकिन इनका व्यवहार अलग है, क्योंकि `Decode.nullable` का `OK Nothing` परिणाम सिर्फ तभी आएगा जब JSON वैल्यू ठीक `null` हो।

अंत में, `properties` फील्ड में कोई भी JSON ऑब्जेक्ट या `null` हो सकता है, और इसके लिए `Decode.value : Decoder Value` सही है।

```elm
decodeProperties : Decoder (Maybe (Dict String Value))
decodeProperties =
    Decode.nullable (Decode.dict Decode.value)
        |> Decode.field "properties"


Decode.decodeString decodeProperties """{"properties": null}"""
    --> Ok Nothing

Decode.decodeString decodeProperties """{"properties": {"country": "Japan"}}"""
    --> Ok (Just (Dict.fromList [("country", <internals>)]))

Decode.decodeString decodeProperties """{"properties": 17}"""
    --> Err ...
```

ध्यान दीजिए कि `Value` एक ऑपेक टाइप है, यानी आप उसकी सामग्री को आसानी से नहीं देख सकते। इसका उपयोग करने के लिए, आप या तो इसके लिए एक डिकोडर लिखकर उसे `Decode.decodeValue : Decoder a -> Value -> Result Error a` से चला सकते हैं, या इसे किसी पोर्ट के ज़रिए सीधे JavaScript को भेज सकते हैं।

अब हम फीचर ऑब्जेक्ट पढ़ने के लिए तैयार हैं:

```elm
type alias Feature =
    { id : Maybe String
    , geometry : Maybe Geometry
    , properties : Maybe (Dict String Value)
    }

decodeFeature : Decoder Feature
decodeFeature =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                if value /= "Feature" then
                    Decode.fail "not a Feature"

                else
                    Decode.map3 Feature
                        decodeMaybeFeatureId
                        decodeFeatureGeometry
                        decodeProperties
            )

Decode.decodeString decodeFeature """{"type": "Feature", "geometry": null, "properties": null}"""
    --> Ok { geometry = Nothing, id = Nothing, properties = Nothing }

"""
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
"""
  |> Decode.decodeString decodeFeature
    --> Ok { geometry = Just (Point [127.831,26.461]), id = Just "0157", properties = Just (Dict.fromList [("country",<internals>)]) }
```

## JSON एनकोडर

एनकोडर की मदद से Elm की वैल्यू से मान्य JSON लिखा जा सकता है। इसके लिए `Encode.encode : Int -> Value -> String` फंक्शन का उपयोग होता है। पहला आर्गुमेंट बताता है कि अंतिम परिणाम में कितनी इंडेंटेशन होगी, और दूसरा आर्गुमेंट वह JSON वैल्यू है जिसे लिखना है।

कोई `Value` या तो `Decode.value` से मिल सकती है, या किसी एक एनकोडर से बनाई जा सकती है:

```elm
Encode.encode 0 (Encode.string "hello")
    --> "hello"

Encode.encode 0 (Encode.bool True)
    --> "true"

Encode.encode 0 (Encode.int 12)
    --> "12"

Encode.encode 0 (Encode.float 3.14)
    --> "3.14"

Encode.encode 0 Encode.null
    --> "null"

Encode.encode 0 (Encode.list Encode.int [1, 2, 3])
    --> "[1,2,3]"

Encode.encode 4 (Encode.list Encode.int [1, 2, 3])
    --> "[\n    1,\n    2,\n    3\n]"

Encode.encode 0 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\"key1\":17,\"key2\":71}"

Encode.encode 4 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\n    \"key1\": 17,\n    \"key2\": 71\n}"
```

और `Encode.object : List ( String, Value ) -> Value` से भी:

```elm
Encode.object
    [ ( "key1", Encode.int 17 )
    , ( "key2", Encode.int 71 )
    ]
    |> Encode.encode 0
    --> "{\"key1\":17,\"key2\":71}"
```

चलिए पहले बनाए गए GeoJSON डिकोडर के लिए एनकोडर बनाते हैं

```elm
encodeGeometry : Geometry -> Value
encodeGeometry geometry =
    case geometry of
        Point coord ->
            Encode.object
                [ ( "type", Encode.string "Point" )
                , ( "coordinates", Encode.list Encode.float coord )
                ]

        LineString coord ->
            Encode.object
                [ ( "type", Encode.string "LineString" )
                , ( "coordinates", Encode.list (Encode.list Encode.float) coord )
                ]

encodeFeature : Feature -> Value
encodeFeature feature =
    let
        maybeId =
            case feature.id of
                Nothing ->
                    []

                Just id ->
                    [ ( "id", Encode.string id ) ]
    in
    Encode.object
        (maybeId
            ++ [ ( "type", Encode.string "Feature" )
               , ( "geometry"
                 , case feature.geometry of
                    Nothing ->
                        Encode.null

                    Just geometry ->
                        encodeGeometry geometry
                 )
               , ( "properties"
                 , case feature.properties of
                    Nothing ->
                        Encode.null

                    Just dict ->
                        Encode.dict identity identity dict
                 )
               ]
        )
```

सामान्य तौर पर, अपने डिकोडर-एनकोडर जोड़ों की जाँच का एक अच्छा तरीका यह है कि आप देखें कि `elmValue |> encoder |> decoder == elmValue` सही उतरता है।
