# परिचय

## JavaScript में रेगुलर एक्सप्रेशन

[रेगुलर एक्सप्रेशन][mdn-regular-expressions] (या रेगेक्स) अक्षरों का एक ऐसा क्रम है, जिसकी मदद से हम स्ट्रिंग में मौजूद खास चीज़ों को चुनकर उन पर काम कर सकते हैं। इसलिए हम यह सब कर सकते हैं:

- स्ट्रिंग में किसी टेक्स्ट को **खोजना**
- स्ट्रिंग के अंदर मौजूद सबस्ट्रिंग को **बदलना**
- स्ट्रिंग से जानकारी **निकालना**

> 💡 JavaScript का रेगेक्स स्वरूप भाषा के ECMA-262 मानक का हिस्सा है। इसका मतलब है कि आपको ब्राउज़र के हिसाब से अनुकूलता की चिंता करने की ज़रूरत नहीं है।

## रेगुलर एक्सप्रेशन बनाने का तरीका

JavaScript में रेगुलर एक्सप्रेशन अधिकतर `/pattern/modifiers` के रूप में लिखा जाता है।

रेगुलर एक्सप्रेशन बनाने के हमारे पास दो तरीके हैं:

1. **रेगुलर एक्सप्रेशन लिटरल**:

```javascript
const regex = /[a-z]/;
```

2. कंस्ट्रक्टर **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

दोनों ही मामलों में JavaScript इस रेगेक्स से एक ऑब्जेक्ट बनाता है। सलाह यह है कि डिफ़ॉल्ट के तौर पर लिटरल के साथ अपरिवर्तनीय पैटर्न इस्तेमाल किए जाएँ।

RegExp कंस्ट्रक्टर का इस्तेमाल उन मामलों में किया जा सकता है जहाँ रेगेक्स बदलेगा या हमें अभी उसका पता नहीं है (जैसे किसी इनपुट में)।

## 🏴‍☠️ फ्लैग

रेगुलर एक्सप्रेशन में कुछ वैकल्पिक सुपरपावर होती हैं, जिन्हें [`flags`][mdn-flags] कहते हैं और जो अतिरिक्त फीचर की सुविधा देती हैं।

इनमें से कुछ बहुत इस्तेमाल होने वाले फ्लैग ये हैं:

- `/g` - ग्लोबल खोज
- `/i` - केस की परवाह न करना
- `/m` - मल्टीलाइन खोज

यहाँ एक आसान उदाहरण है:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

`g` अक्षर की मदद से हम किसी स्ट्रिंग के सारे संभावित मैच निकाल सकते हैं। इस फीचर के बिना JavaScript सिर्फ पहला `Home` मैच ही निकाल पाता।

केस की परवाह न करने वाला `/i` फ्लैग पैटर्न ढूँढते समय हमें लचीला बनाता है। इससे फर्क नहीं पड़ता कि हम जो ढूँढ रहे हैं वह `UPPERCASE` में है या `lowercase` में।

`RegExp` कंस्ट्रक्टर इस्तेमाल करते समय फ्लैग जोड़ने का तरीका अलग होता है।

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## सबसे आम फंक्शन

जब रेगुलर एक्सप्रेशन को JavaScript के मौजूदा अंतर्निहित फंक्शन के साथ मिलाया जाता है, तो स्ट्रिंग से डेटा निकालने और उस पर काम करने के कुछ बहुत काम के तरीके हमारे पास होते हैं।

रेगेक्स के साथ इस्तेमाल होने वाले कुछ सबसे आम फंक्शन ये हैं।

### टेस्ट

[test()][mdn-regex-test]] मेथड एक रेगुलर एक्सप्रेशन और दी गई स्ट्रिंग के बीच मैच की खोज करता है। यह सही या गलत लौटाता है।

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### मैच

[match()][mdn-regex-match] मेथड की मदद से हमें एक काम का ऐरे मिलता है, जिसकी सामग्री इस पर निर्भर करती है कि मैच मिले हैं या नहीं।

इस तरह हम किसी भी स्ट्रिंग से जानकारी **खोज** भी सकते हैं और **निकाल** भी सकते हैं। उदाहरण के लिए:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

जब ग्लोबल खोज फ्लैग `/g` मौजूद होता है, तो यह मेथड इंडेक्स या इनपुट जैसी काम की जानकारी के साथ सिर्फ एक ही मैच देने के बजाय ऐरे में दिखने वाले सारे मैच लौटाता है:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### रीप्लेस

JavaScript में [replace()][mdn-regex-replace] मेथड की मदद से हम किसी दी गई स्ट्रिंग के अंदर एक वैल्यू ढूँढ सकते हैं और उसे अपनी मनचाही नई वैल्यू से बदल सकते हैं।

```javascript
string.replace(searchValue, newValue);
```

इस बदलाव को ढूँढने वाला पैटर्न एक अकेली स्ट्रिंग भी हो सकता है और एक रेगुलर एक्सप्रेशन भी।

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

इसके अलावा, हर वैल्यू में अतिरिक्त बदलाव करने के लिए हम बदलाव वाली जगह पर एक फंक्शन भी लगा सकते हैं।

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### स्प्लिट

JavaScript में [split()][mdn-regex-split] मेथड रेगुलर एक्सप्रेशन के साथ स्ट्रिंग इस्तेमाल करने और उन पर काम करने का एक अलग तरीका है।

इस तरह हम किसी पैटर्न को पहचानकर दी गई स्ट्रिंग को बाँटने के लिए रेगेक्स इस्तेमाल करेंगे, जैसे `str.split(/[,.\s]/)`। यही पैटर्न `separator` की तरह काम करेगा।

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
