# परिचय

## रिकर्शन

किसी चीज़ को खुद के संदर्भ में परिभाषित करने की क्षमता को रिकर्शन कहते हैं। F# में रिकर्शन सबसे आम तौर पर रिकर्शन फंक्शन में मिलता है, यानी ऐसे फंक्शन जो खुद को कॉल करते हैं।

एक रिकर्शन फंक्शन में कम से कम एक _बेस केस_ और कम से कम एक _रिकर्शन केस_ होना चाहिए। _बेस केस_ फंक्शन को फिर से कॉल किए बिना एक वैल्यू लौटाता है। _रिकर्शन केस_ फंक्शन को फिर से कॉल करता है और इनपुट में बदलाव करता है ताकि वह किसी समय बेस केस से मेल खाए।

रिकर्शन फंक्शन सामान्य फंक्शन की तरह ही बनाए जाते हैं, लेकिन `rec` मॉडिफायर के साथ। इस मॉडिफायर के बिना फंक्शन खुद को कॉल नहीं कर पाएगा, और ऐसा करने की कोशिश करने पर कंपाइलेशन एरर मिलेगी। इसलिए रिकर्शन को स्पष्ट रूप से चुनना ज़रूरी है।

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# डिस्क्रिमिनेटेड यूनियन टाइप के ज़रिए रिकर्शन टाइप को भी सपोर्ट करता है। रिकर्शन डिस्क्रिमिनेटेड यूनियन टाइप में एक या अधिक केस अपने डेटा में उसी डिस्क्रिमिनेटेड यूनियन टाइप का संदर्भ देते हैं। रिकर्शन फंक्शन की तरह रिकर्शन टाइप में भी एक बेस केस होना चाहिए। रिकर्शन फंक्शन के विपरीत रिकर्शन टाइप `rec` कीवर्ड का इस्तेमाल नहीं करते।

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
