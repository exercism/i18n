# डेटाबेस में बड़े खर्च

## समस्या कथन

ABC Corp चाहता है कि आप ऐसे कर्मचारियों के नाम और विभाग ढूँढें जिनकी पेमेंट एंट्री दी गई राशि (जैसे `3000.00`) से बड़ी हो।

ज़रूरी डेटा लौटाने के लिए `HighPayment` नाम का एक रिकॉर्ड बनाइए। रिकॉर्ड की परिभाषा इस प्रकार है।

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

डेटाबेस से ज़रूरी डेटा लेने के लिए JDBC क्लाइंट के `query` ऑपरेशन का इस्तेमाल कीजिए।

> ध्यान दें: परिणाम को `payment_id` के आधार पर बढ़ते क्रम में लगाइए।

## डेटाबेस का विवरण

इस समस्या के लिए दिया गया H2 डेटाबेस इस्तेमाल कीजिए।

> सैंपल डेटाबेस फाइल `gofigure.mv.db` है और डेटाबेस का नाम `gofigure` है। यह `db` फोल्डर के अंदर दी गई है।

सैंपल H2 डेटाबेस में नीचे दी गई टेबलें पहले से मौजूद हैं और उनमें कुछ सैंपल डेटा भी है। कॉलम के नाम और डेटा टाइप नीचे दिए गए हैं।

**टेबल का नाम** : `Employee`

| **कॉलम:**      | टाइप |
| -----------       | ----------- |
| `employee_id`     | पूर्णांक, ऑटो-इंक्रीमेंट होने वाली प्राइमरी की       |
| `name`            | स्ट्रिंग        |
| `city`            | स्ट्रिंग        |
| `department`      | स्ट्रिंग        |
| `age`             | पूर्णांक        |

**टेबल का नाम**: `Payment`

| **कॉलम:**      | टाइप |
| -----------       | ----------- |
| `payment_id`      | पूर्णांक, ऑटो-इंक्रीमेंट होने वाली प्राइमरी की       |
| `date`            | दिनांक        |
| `amount`          | दशमलव संख्या        |
| `employee_id`     | पूर्णांक        |
| `reason`          | स्ट्रिंग        |

* डेटाबेस फाइल `gofigure.mv.db` है। JDBC URL इस तरह इस्तेमाल कीजिए: `jdbc:h2:file:/path/to/db/file`
* यूज़रनेम: `root`
* पासवर्ड: `root`

## बाधाएँ

* क्वेरी और Ballerina सैंपल जाँचने के लिए `db` फोल्डर में दी गई H2 डेटाबेस फाइल इस्तेमाल कीजिए।
* अपने Ballerina.toml में H2 डेटाबेस ड्राइवर को प्लेटफॉर्म डिपेंडेंसी के रूप में जोड़ने के लिए maven डिपेंडेंसी पैराम्स वाला तरीका इस्तेमाल कीजिए।

## टेस्ट एनवायरनमेंट

* आप `bal test` से टेस्ट चला सकते हैं, जो दिए गए सैंपल डेटाबेस के साथ चलेंगे।

## संकेत

* डेटाबेस के साथ काम करने के लिए [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) मॉड्यूल इस्तेमाल कीजिए।
* JDBC ड्राइवर को डिपेंडेंसी के रूप में जोड़ने के चरणों के लिए [पूर्वापेक्षाएँ](https://lib.ballerina.io/ballerinax/java.jdbc/latest) वाले हिस्से को देखिए।
* डेटाबेस से डेटा क्वेरी करने के लिए [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) रिमोट मेथड इस्तेमाल कीजिए।
* [सरल क्वेरी](https://ballerina.io/learn/by-example/mysql-query-operation) वाला उदाहरण देखिए।
* डेटा एक्सेस करने के लिए Ballerina का [stream](https://ballerina.io/learn/by-example/stream-type) टाइप इस्तेमाल कीजिए।
* डेटाबेस से ज़रूरी डेटासेट ढूँढने के लिए SQL जॉइन इस्तेमाल कीजिए।
