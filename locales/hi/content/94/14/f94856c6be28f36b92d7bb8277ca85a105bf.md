# परिचय

## `for` लूप

`for` स्टेटमेंट एक कोड ब्लॉक को बार-बार चलाता है।
इसकी पहली लाइन तय करती है कि यह ब्लॉक कितनी बार दोहराया जाएगा:

```go
for init; condition; post {
    // loop body
}
```

- **init** स्टेटमेंट पहले इटरेशन से पहले सिर्फ एक बार चलता है। लूप में इस्तेमाल होने वाला काउंटर वेरिएबल घोषित करना और उसे शुरुआती वैल्यू देना आम बात है।
- **condition** एक बूलियन एक्सप्रेशन है, जिसे हर इटरेशन से पहले जाँचा जाता है। जब यह `false` हो जाता है, लूप रुक जाता है।
- **post** स्टेटमेंट हर पूरा हुए इटरेशन के बाद चलता है। इससे काउंटर अपडेट किया जा सकता है।

`init; condition; post` के चारों ओर गोल ब्रैकेट मत लगाइए।
लेकिन लूप के अंदर के कोड के चारों ओर घुंघराले ब्रैकेट हमेशा ज़रूरी होते हैं।

यह लूप `i` को `1` से शुरू करता है, `i` की मौजूदा वैल्यू प्रिंट करता है, अगले इटरेशन के लिए उसे बढ़ा देता है, और जब `i` `10` तक पहुँचता है तो रुक जाता है:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
