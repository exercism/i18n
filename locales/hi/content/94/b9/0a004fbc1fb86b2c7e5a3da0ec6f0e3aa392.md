# परिचय

Cairo में बूलियन को पहले से घोषित बूलियन टाइप `bool` से दर्शाया जाता है, जिसकी वैल्यू `true` या `false` हो सकती है।

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo तीन लॉजिकल ऑपरेटर सपोर्ट करता है, जो किसी एक्सप्रेशन का मूल्यांकन करके बूलियन वैल्यू निकालते हैं, यानी `true` या `false`।

| ऑपरेटर    | इसका मतलब                                     |
| ----------- | --------------------------------------------- |
| `&&` (और)  | यह सही होता है जब दोनों दावे सही हों।          |
| `\|\|` (या) | यह सही होता है जब कम से कम एक दावा सही हो।    |
| `!` (नहीं)  | यह तभी सही होता है जब दावा गलत हो।            |
