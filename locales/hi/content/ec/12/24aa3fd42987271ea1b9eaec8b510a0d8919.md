# परिचय

याद कीजिए कि `jq` भी JSON की तरह ही डेटा टाइप का समर्थन करता है।
JSON **स्ट्रिंग** को इस तरह परिभाषित करता है:

> स्ट्रिंग शून्य या अधिक यूनिकोड अक्षरों का एक क्रम होती है, जो डबल कोट्स में लिपटी होती है और बैकस्लैश एस्केप का उपयोग करती है।

## एस्केप सीक्वेंस

स्ट्रिंग के अंदर, "विशेष" अक्षरों को एम्बेड करने के लिए बैकस्लैश अक्षर का उपयोग कीजिए:

- `\"` एक शाब्दिक उद्धरण चिह्न,
- `\\` एक शाब्दिक बैकस्लैश,
- व्हाइटस्पेस अक्षर `\n`, `\t`, `\r`, `\f`, `\b`
- यूनिकोड अक्षर `\uAAAA`, जहाँ `A` एक हेक्स अंक है

## स्ट्रिंग की लंबाई

अक्षरों की संख्या जानने के लिए `length` फंक्शन का उपयोग कीजिए।

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## सबस्ट्रिंग

सबस्ट्रिंग निकालने के लिए **स्लाइस** नोटेशन का उपयोग किया जा सकता है।
इसका सिंटैक्स `.[i:j]` है।
लौटाई गई सबस्ट्रिंग की लंबाई `j - i` होती है, और यह इंडेक्स `i` (शामिल) से इंडेक्स `j` (शामिल नहीं) तक के अक्षर लौटाती है।
कोई भी इंडेक्स ऋणात्मक हो सकता है; ऐसी स्थिति में वह स्ट्रिंग के अंत से पीछे की ओर गिनता है।
कोई भी इंडेक्स छोड़ा जा सकता है; ऐसी स्थिति में वह स्ट्रिंग के शुरू या अंत को दर्शाता है।
इंडेक्स 0 से शुरू होते हैं।

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## संयोजन

स्ट्रिंग जोड़ने के लिए `+` का उपयोग कीजिए:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

जब स्ट्रिंग का ऐरे दिया हो, तो `add` का उपयोग कीजिए:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## विभाजन और जोड़

विभाजन के लिए `split/1` फंक्शन या `/` ऑपरेटर का उपयोग किया जाता है:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1` का उल्टा `join/1` है।

स्ट्रिंग को अक्षरों के ऐरे में बदलने की ज़रूरत अक्सर पड़ती है।
इसे करने के दो तरीके हैं:

1. खाली स्ट्रिंग पर विभाजन कीजिए

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` द्वारा _कोडपॉइंट_ के ऐरे में बदलिए

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` `explode` का उल्टा है।

## सबस्ट्रिंग का इंडेक्स ढूँढना

`index/1` फंक्शन इस्तेमाल कीजिए; इंडेक्स 0 से शुरू होता है।

```jq
"hello" | index("el")'   # => 1
```

अगर सबस्ट्रिंग स्ट्रिंग में नहीं है, तो परिणाम `null` होता है।

```jq
"hello" | index("elk")   # => null
```

## स्ट्रिंग इंटरपोलेशन

स्ट्रिंग के अंदर, `\(expression)` क्रम उस एक्सप्रेशन के _परिणाम_ को [स्ट्रिंग में][interpolate] एम्बेड कर देगा:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## केस बदलना

`ascii_downcase` और `ascii_upcase` फंक्शन इस्तेमाल कीजिए।

## रेगुलर एक्सप्रेशन

`jq` में रेगुलर एक्सप्रेशन के लिए व्यापक समर्थन है: यह आगे के पाठ का विषय होगा।

[interpolate]: https://jqlang.org/manual/#string-interpolation
