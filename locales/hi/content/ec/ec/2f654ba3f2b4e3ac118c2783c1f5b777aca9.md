# परिचय

## स्ट्रक्ट टाइप

हम स्ट्रक्ट टाइप पहले ही देख चुके हैं। याद दिला दें कि `struct` नाम वाले एलिमेंट का एक क्रम होता है, जिन्हें _फील्ड_ कहा जाता है, और हर फील्ड का एक नाम और टाइप होता है।
एक ही स्ट्रक्ट के भीतर हर फील्ड का नाम अलग होना चाहिए।
`Structs` को ऑब्जेक्ट ओरिएंटेड प्रोग्रामिंग की _क्लास_ से तुलना की जा सकती है।

आप `type` और `struct` कीवर्ड इस्तेमाल करके नया स्ट्रक्ट बनाते हैं और फिर नीचे दिए उदाहरण की तरह फील्ड के नाम और टाइप साफ़-साफ़ लिखते हैं।

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## गैर-स्ट्रक्ट टाइप

गैर-स्ट्रक्ट टाइप भी बनाए जा सकते हैं, जिन्हें किसी बिल्ट-इन टाइप के दूसरे नाम की तरह इस्तेमाल किया जा सकता है।

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

आप ऐरे और मैप से बने गैर-स्ट्रक्ट टाइप भी बना सकते हैं।

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
