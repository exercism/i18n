# परिचय

C++ में आप तुलना करने वाले ऑपरेटरों की मदद से वैल्यू की तुलना कर सकते हैं।

| तुलना             | ऑपरेटर    |
| ------------------| --------- |
| बराबर             | `==`      |
| बराबर नहीं         | `!=`      |
| कम                | `<`       |
| कम या बराबर       | `<=`      |
| अधिक              | `>`       |
| अधिक या बराबर     | `>=`      |

इन तुलनाओं का परिणाम हमेशा एक बूलियन वैल्यू होता है:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

ऑपरेटर `==` और `!=` क्रमशः यह जाँचते हैं कि कोई वैल्यू किसी दूसरी वैल्यू के बराबर है या नहीं।
यहाँ कुछ आम उदाहरण दिए गए हैं:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

बाकी ऑपरेटर जाँचते हैं कि कोई वैल्यू किसी दूसरी वैल्यू से अधिक (`>`) है, उसके बराबर या अधिक (`>=`) है, उससे कम (`<`) है, या उसके बराबर या कम (`<=`) है।
इस तरह की तुलना संख्याओं और स्ट्रिंग के लिए उपलब्ध है।
स्ट्रिंग की तुलना करते समय शब्दकोश क्रम (जिसे लेक्सिकोग्राफिक क्रम भी कहते हैं) का पालन किया जाता है।

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
