# Break, Continue

लूप चलाने या इटरेशन करने वाली कंट्रोल स्ट्रक्चर का इस्तेमाल करते समय `break` और `continue` कीवर्ड किसी प्रोग्राम के फ्लो को नियंत्रित करने में मदद कर सकते हैं।
`break` कीवर्ड लूप के दायरे से बाहर निकलकर बाहरी स्कोप में चला जाता है और इस तरह लूप समाप्त कर देता है।
`continue` कीवर्ड मौजूदा इटरेशन का बाकी हिस्सा छोड़ देता है और लूप के दायरे को अगले इटरेशन की शुरुआत से दोबारा शुरू कर देता है।
हालाँकि यह कम ही देखने को मिलता है, कीवर्ड के साथ एक संख्या भी दी जा सकती है, जो यह तय करती है कि कितने दायरों से बाहर निकलना है या कितने दायरों को छोड़कर अगले इटरेशन पर पहुँचना है।

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

पिछले उदाहरण में `continue` पाँच (5) बार चलता है, लेकिन छठे (6) इटरेशन पर `break` चलता है, जिससे कोड लूप से बाहर निकल जाता है।
