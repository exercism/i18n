# परिचय

## मैप

Elixir में मैप वह डेटा स्ट्रक्चर है जिसमें जानकारी की-वैल्यू जोड़ों के रूप में रखी जाती है। दूसरी भाषाओं में इन्हें associative arrays (PHP), hashes (Perl 5, Raku) या dictionaries (Python) जैसे नामों से भी जाना जाता है।

की और वैल्यू किसी भी डेटा टाइप की हो सकती हैं, लेकिन अगर की एक एटम है, तो हम संक्षिप्त रूप इस्तेमाल कर सकते हैं। मैप इस बात की गारंटी नहीं देते कि उनकी प्रविष्टियाँ पढ़ने या लौटाने पर किस क्रम में मिलेंगी।

### लिटरल रूप

खाली मैप को सिर्फ `%{}` से घोषित किया जाता है। अगर हमें मैप लिटरल में चीज़ें जोड़नी हैं, तो हम दो रूप इस्तेमाल कर सकते हैं:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

हालाँकि कोई एक तय मानक रूप नहीं है, फिर भी की-वैल्यू लिटरल जोड़ों को लिखने का एक तरीका चुनिए और उसे हर जगह एक जैसा अपनाइए।

### Map मॉड्यूल के फंक्शन

Elixir, _Map मॉड्यूल_ में मैप के साथ काम करने के लिए कई फंक्शन देता है। Map मॉड्यूल के कुछ फंक्शन ऐसे हैं जिनमें मैप में बदलाव करने के लिए आपको एक _अनाम_ फंक्शन देना होता है।

## स्थिरांक के रूप में मॉड्यूल एट्रिब्यूट

Elixir में हम मॉड्यूल एट्रिब्यूट बना सकते हैं, जिन्हें अपने फंक्शन में स्थिरांक की तरह इस्तेमाल किया जा सकता है।

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

मॉड्यूल स्थिरांक बनाने के लिए इस्तेमाल करने पर एट्रिब्यूट कोई भी एक्सप्रेशन हो सकता है, जिसका मूल्यांकन कंपाइल होते समय किया जा सके। कंपाइल होने के बाद मॉड्यूल एट्रिब्यूट उपलब्ध नहीं रहते, क्योंकि वे कंपाइल होते समय ही एक्सपैंड हो जाते हैं, ठीक वैसे ही जैसे C जैसी भाषाओं में परिभाषित मैक्रो।
