# परिचय

डिक्शनरी एलिमेंट का एक संग्रह है, जिसमें हर एलिमेंट में एक की और एक वैल्यू होती है। डिक्शनरी के किसी मेथड को कोई की दिया जाए, तो वह उससे जुड़ी वैल्यू लौटाता है। दूसरी भाषाओं में मैप या असोसिएटिव ऐरे जो काम करते हैं, इस डिक्शनरी का काम भी वही है।

डिक्शनरी इस तरह बनाई जा सकती है:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

या

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

ध्यान दीजिए कि की और वैल्यू के टाइप भी डिक्शनरी की परिभाषा का हिस्सा होते हैं।

एक बार बन जाने के बाद, डिक्शनरी में उसके अपने मेथड `Add` और `Remove` की मदद से एंट्री जोड़ी या हटाई जा सकती है।

डिक्शनरी से कोई वैल्यू निकालने या उसे बदलने के लिए डिक्शनरी में एक की से इंडेक्स किया जाता है:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

आप यह जाँच सकते हैं कि डिक्शनरी में कोई वैल्यू मौजूद है या नहीं:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

डिक्शनरी पर एन्यूमरेट करने से उसके की-वैल्यू जोड़ों पर एक-एक करके चला जाता है। डिक्शनरी में ऐसी प्रॉपर्टी भी होती हैं जिनकी मदद से केवल की या केवल वैल्यू पर एन्यूमरेट किया जा सकता है।
