# निर्देश परिशिष्ट

## रजिस्टर

| रजिस्टर | उपयोग       | टाइप    | विवरण                        |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | इनपुट        | पूर्णांक | त्रिभुज की पंक्तियों की संख्या      |
| `$a1`    | इनपुट/आउटपुट | एड्रेस  | वर्ड का ऐरे                    |
| `$v0`    | आउटपुट       | पूर्णांक | आउटपुट वर्ड की संख्या           |
| `$t0-9`  | अस्थायी      | कोई भी  | अस्थायी भंडारण के लिए           |
