# निर्देश

आप पक्षी देखने के शौकीन हैं और यह हिसाब रखते हैं कि पिछले सात दिनों में आपके बगीचे में कितने पक्षी आए।

आपके सामने छह काम हैं, और सभी आपके बगीचे में आए पक्षियों की संख्याओं से जुड़े हैं।

## 1. देखिए कि पिछले हफ्ते की गिनती क्या थी

तुलना के लिए आप हमेशा पिछले हफ्ते की गिनती की एक कॉपी अपने पास रखते हैं, जो थी: 0, 2, 5, 3, 7, 8 और 4। (_static_) `BirdCount.LastWeek()` मेथड बनाइए जो पिछले हफ्ते की गिनती लौटाता है:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. देखिए कि आज कितने पक्षी आए

`BirdCount.Today()` मेथड बनाइए, जो यह लौटाता है कि आज आपके बगीचे में कितने पक्षी आए। पक्षियों की गिनती दिन के क्रम में रखी गई है: पहला एलिमेंट सबसे पुराने दिन की गिनती है और अंतिम एलिमेंट आज की गिनती।

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. आज की गिनती बढ़ाइए

`BirdCount.IncrementTodaysCount()` मेथड बनाइए जो आज की गिनती बढ़ाता है:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. देखिए कि कोई ऐसा दिन था या नहीं जब एक भी पक्षी नहीं आया

`BirdCount.HasDayWithoutBirds()` मेथड बनाइए जो `true` लौटाता है अगर कोई ऐसा दिन था जिस दिन बगीचे में एक भी पक्षी नहीं आया; वरना `false` लौटाइए:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. हफ्ते की शुरुआत के पहले कुछ दिनों में आए पक्षियों की संख्या निकालिए

`BirdCount.CountForFirstDays()` मेथड बनाइए जो हफ्ते की शुरुआत से आपके बगीचे में आए पक्षियों की संख्या लौटाता है, लेकिन यह गिनती हफ्ते की शुरुआत से दिए गए दिनों की संख्या तक ही सीमित रहनी चाहिए।

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. व्यस्त दिनों की संख्या निकालिए

कुछ दिन दूसरों की तुलना में ज़्यादा व्यस्त होते हैं। व्यस्त दिन वह होता है जब आपके बगीचे में पाँच या उससे ज़्यादा पक्षी आए हों।
`BirdCount.BusyDays()` मेथड बनाइए जो व्यस्त दिनों की संख्या लौटाता है:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
