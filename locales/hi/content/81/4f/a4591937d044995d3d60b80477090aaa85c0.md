# परिचय

## पूर्णांक

Elixir में संख्याएँ दो तरह की होती हैं - पूर्णांक और दशमलव संख्याएँ।

पूर्णांक पूरी संख्याएँ होती हैं।

```elixir
integer = 3
# => 3
```

## दशमलव संख्याएँ

दशमलव संख्याओं में दशमलव चिह्न के बाद एक या अधिक अंक होते हैं। ये 64-बिट डबल प्रिसिज़न फ्लोटिंग-पॉइंट फॉर्मैट का उपयोग करती हैं।

```elixir
float = 3.45
# => 3.45
```

### संख्याओं के साथ काम करना

[`Integer`][integer-functions] और [`Float`][float-functions] मॉड्यूल में आपको इन टाइपों के साथ काम करने के लिए कुछ उपयोगी फंक्शन मिलते हैं। बुनियादी अंकगणितीय ऑपरेटर [`Kernel`][kernel-arithmetic-operators] मॉड्यूल में परिभाषित हैं।

### रूपांतरण

एक ही अंकगणितीय एक्सप्रेशन में पूर्णांक और दशमलव संख्याएँ मिलाई जा सकती हैं। किसी एक्सप्रेशन में दशमलव संख्या इस्तेमाल करने पर परिणाम भी दशमलव संख्या ही होता है।

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

लेकिन भाग देने पर परिणाम हमेशा दशमलव संख्या ही होता है, भले ही सिर्फ पूर्णांक इस्तेमाल किए गए हों।

```elixir
6 / 2
# => 3.0
```

किसी दशमलव संख्या को पूर्णांक में बदलने के लिए आप [`trunc/1`][trunc-1] की मदद से उसका दशमलव वाला भाग हटा सकते हैं।
