# परिचय

`do-while` लूप, `while` लूप का एक विकल्प है, और दोनों में बस एक ही अंतर है कि `do-while` को कम से कम एक बार चलाया जाता है:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

`do-while` लूप का उपयोग करने की स्थितियाँ बहुत कम होती हैं, इसलिए इसके बजाय सामान्य `while` लूप इस्तेमाल किया जाता है।
