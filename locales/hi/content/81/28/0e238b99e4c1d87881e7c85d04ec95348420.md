# विवरण

Rust में मेथड ऐसे फंक्शन होते हैं जो किसी स्ट्रक्ट (या `enum` या `trait` ऑब्जेक्ट) के लिए बनाए जाते हैं। इससे कॉल करने का तरीका बदल जाता है: `frobnicate(foo)` की जगह मेथड को `foo.frobnicate()` की तरह कॉल किया जाता है।

मेथड फंक्शन की तरह ही होते हैं: इन्हें `fn` कीवर्ड से घोषित किया जाता है, इनका एक नाम होता है, और इनमें पैरामीटर तथा रिटर्न वैल्यू हो सकती हैं।

फंक्शन से अलग, मेथड का पहला पैरामीटर हमेशा `self` (या उसका कोई रूप) होता है। यह उस स्ट्रक्ट के इंस्टेंस को दर्शाता है जिस पर मेथड को कॉल किया जा रहा है (इसका विस्तार नीचे है)।

चलिए Hogwarts के हाउसों के लिए एक `enum` और ऐसा `struct` बनाते हैं जो किसी जादूगर की `age` और `house` बताता है:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## मेथड बनाना

स्ट्रक्ट `Wizard` के लिए मेथड बनाने के लिए हम `Wizard` का एक `impl` ब्लॉक शुरू करते हैं (`impl`, यानी इम्प्लीमेंटेशन का छोटा रूप)।

```rust
impl Wizard { }
```

इस `impl` ब्लॉक के अंदर की हर चीज़ `Wizard` टाइप से जुड़ी होती है। ध्यान दीजिए कि एक स्ट्रक्ट में एक से अधिक `impl` ब्लॉक हो सकते हैं।

### `self` का उपयोग

मेथड का पहला पैरामीटर `Self` टाइप का होना चाहिए और उसका नाम `self` होना चाहिए। `Self` टाइप उस टाइप का दूसरा नाम है जिसके लिए `impl` ब्लॉक लिखा गया है। हमारे उदाहरण में `Self` का मतलब `Wizard` है।

सुविधा के लिए Rust हमें इसे छोटा करके पहले पैरामीटर की जगह सिर्फ `self` लिखने की अनुमति देता है। मेथड में `self` के आम रूप ये हैं:

- `self`: `self: Self` का छोटा रूप। सिर्फ `self` वाला सिग्नेचर इंस्टेंस को उपभोग कर लेता है।
- `&self`: `self: &Self` का छोटा रूप। यह इंस्टेंस को अपरिवर्तनीय रूप से उधार लेता है।
- `&mut self`: `self: &mut Self` का छोटा रूप। यह इंस्टेंस को परिवर्तनीय रूप से उधार लेता है।

कुछ और उन्नत कोड में आपको `self: Pin<&self>`, `self: Rc<Self>` जैसे सिग्नेचर भी मिल सकते हैं। लेकिन यह इस ट्यूटोरियल के दायरे से बाहर है।

### `&self` के साथ मेथड बनाना

अगर हम जादूगर की बुनियादी जानकारी प्रदर्शित करने के लिए एक `info` मेथड बनाना चाहते हैं, तो हम इसे `Wizard` के `impl` ब्लॉक के अंदर बना सकते हैं:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

ध्यान दीजिए कि `info` के सिग्नेचर में हम इंस्टेंस को `&self` के साथ अपरिवर्तनीय रूप से उधार लेते हैं। इस तरह हम `Wizard` इंस्टेंस की `age` और `house` फील्ड बिना बदले पढ़ सकते हैं। अगर हम उधार लेने की जगह उपभोग करने वाला `self` इस्तेमाल करते, तो मेथड कॉल होने के बाद वह इंस्टेंस पहुँच से बाहर हो जाता।

`info` मेथड बन जाने पर हम जादूगर की बुनियादी जानकारी छाप सकते हैं:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### `&mut self` के साथ मेथड बनाना

अगर हम ऐसा मेथड बनाना चाहते हैं जो किसी स्ट्रक्ट इंस्टेंस की फील्ड बदलता है, तो मेथड के सिग्नेचर में हम इंस्टेंस को `&mut self` के साथ परिवर्तनीय रूप से उधार लेते हैं।

मान लीजिए हम Hogwarts में एक नया नियम बनाना चाहते हैं, जिससे विद्यार्थी अपना हाउस बदल सकें। तब हम `switch_house` नाम का मेथड ऐसे बना सकते हैं:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

अब हम Hogwarts में पढ़ने वाले जादूगर का हाउस बदल सकते हैं:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## एक से अधिक 'impl' ब्लॉक

Rust में हर आइटम में एक से अधिक `impl` ब्लॉक हो सकते हैं। इसलिए हम सारे मेथड एक ही `impl` ब्लॉक में रख सकते हैं, या मेथड के अलग-अलग समूहों के लिए अलग-अलग `impl` ब्लॉक बना सकते हैं। दोनों तरीके मान्य सिंटैक्स हैं, लेकिन आम प्रोजेक्ट में `impl` के लेवल वाले `where` बाउंड के हर अलग सेट के लिए एक ही `impl` ब्लॉक रखा जाता है।

## असोसिएटेड फंक्शन

`impl` ब्लॉक के अंदर ऐसे फंक्शन भी बनाए जा सकते हैं जिनमें `self` पैरामीटर नहीं होता। चूँकि उनमें `self` पैरामीटर नहीं होता, वे मेथड नहीं हैं। फिर भी वे उस टाइप से जुड़े रहते हैं जिसके लिए `impl` लिखा गया है, और उन्हें उसी टाइप का नाम लेकर कॉल किया जाता है। इसीलिए उन्हें असोसिएटेड फंक्शन (या टाइप-असोसिएटेड फंक्शन) कहते हैं।

आप ऐसे कुछ असोसिएटेड फंक्शन पहले ही देख चुके हैं, जैसे `String::from()`:

```rust
let some_string = String::from("This is an associated function but not a method");
```

कंस्ट्रक्टर अक्सर असोसिएटेड फंक्शन के रूप में ही बनाए जाते हैं। चलिए `Wizard` टाइप से जुड़ा एक `new` फंक्शन बनाते हैं:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

ध्यान दीजिए कि फंक्शन से जो टाइप लौटेगा उसे बताने के लिए हम `Wizard` की जगह `Self` लिख सकते हैं। `Self` जैसे दूसरे नाम को इस तरह इस्तेमाल करना ज़रूरी नहीं है, लेकिन इससे ऐसे टाइप का इम्प्लीमेंटेशन आसान हो जाता है जिनके नाम लंबे या जटिल हों। अब हम यह चला सकते हैं:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
