# मैच की मूल बातें

`match` एक्सप्रेशन से किसी वैल्यू की तुलना पैटर्न की एक श्रृंखला से आसानी से की जा सकती है, और उसके बाद मिले हुए पैटर्न के आधार पर कोड चलाया जा सकता है। एक पैटर्न लिटरल वैल्यू, वेरिएबल के नाम, वाइल्डकार्ड और कई और चीज़ों से मिलकर बनता है।

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

अगर किसी शाखा में एक से ज़्यादा लाइन का कोड लिखना हो, तो उसे कर्ली ब्रैकेट `{}` में लपेटना चाहिए:

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

`match` एक्सप्रेशन में यह सुविधा भी है कि वह पैटर्न से मेल खाने वाली वैल्यू को अपने साथ बाँध लेता है। इसी वजह से इनम के किसी वेरिएंट से उससे जुड़ी हुई वैल्यू निकाली जा सकती है।

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

यहाँ `Color` इनम के `Red` वेरिएंट को बढ़ाकर उसमें एक और इनम जोड़ा गया है। `match` एक्सप्रेशन की मदद से हम उससे जुड़ी हुई वैल्यू निकाल सकते हैं, जिसे यहाँ `state` कहा गया है। `state` बस एक वेरिएबल का नाम है, जिसे आगे उस शाखा के कोड में इस्तेमाल किया जा सकता है।

## `Option` इनम टाइप से मिलान

बिल्ट-इन `Option` इनम को भी `match` एक्सप्रेशन से संभाला जा सकता है।

आइए एक ऐसा फंक्शन बनाते हैं जो `Option<u8>` पैरामीटर लेता है। अगर दिए गए पैरामीटर में कोई वैल्यू मौजूद है, तो उस वैल्यू में एक जोड़िए, वरना फंक्शन को बिना कुछ किए `None` वैल्यू लौटानी चाहिए।

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> ध्यान दें: `{:?}` एक खास फॉर्मेटिंग सिंटैक्स है, जिससे `println!` मैक्रो को दिए गए पैरामीटर का डीबग रूप प्रिंट किया जा सकता है।
> इसके बारे में ज़्यादा जानकारी आप [The Cairo Book][debugging] में देख सकते हैं।

`match` कंट्रोल फ्लो का एक लाभ यह है कि यह हर संभावना को कवर करता है: हर शाखा के पैटर्न को _सभी_ संभावनाएँ कवर करनी पड़ती हैं। अब पिछले उदाहरण का वह रूप देखिए जिसमें `None` की स्थिति संभाली नहीं गई है:

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## `_` वाइल्डकार्ड से बाकी सब पकड़ने वाला पैटर्न

इनम की मदद से हम कुछ खास वैल्यू के लिए अलग काम भी कर सकते हैं, और बाकी सारी वैल्यू के लिए एक ही डिफॉल्ट काम कर सकते हैं। इसके लिए `match` एक्सप्रेशन की अंतिम शाखा में `_` पैटर्न वाली एक नई शाखा जोड़ दीजिए। `_` एक खास पैटर्न है, जो किसी भी वैल्यू से मेल खाता है और उस वैल्यू को किसी नाम से नहीं बाँधता।

`is_red` फंक्शन एक पैरामीटर लेता है और अगर रंग `Red` है तो `true` लौटाता है, और बाकी किसी भी रंग के लिए `false` लौटाता है:

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## `|` ऑपरेटर से पैटर्न मिलान

Cairo के `match` कंट्रोल फ्लो की मदद से किसी वैल्यू का मिलान `|` (_या_) ऑपरेटर से कई पैटर्न के साथ किया जा सकता है। इससे कोड आसान बन जाता है।

उदाहरण के लिए, `Color` इनम का इस्तेमाल करके हम एक ऐसा फंक्शन लिखना चाहते हैं, जो `Red` या `Green` रंगों के लिए `true` लौटाए और बाकी रंगों के लिए `false`:

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## `felt252` और पूर्णांक वेरिएबलो से पैटर्न मिलान

`felt252` और पूर्णांक वेरिएबल की तुलना वैल्यू के एक समूह से की जा सकती है। लेकिन इसकी कुछ सीमाएँ हैं;

- सिर्फ वे पूर्णांक इस्तेमाल हो सकते हैं जो एक ही `felt252` में समा जाएँ (`u256` समर्थित नहीं है)।
- 0 पहली शाखा में होना चाहिए।
- हर शाखा बाकी शाखाओं से जुड़े हुए एक लगातार हिस्से के रूप में होनी चाहिए।

आइए छह फलकों वाले पासे का एक खेल बनाते हैं। जब यह पासा फेंका जाता है, तो 0 से 5 के बीच कोई संख्या मिलती है। अगर पासा 0, 1 या 2 देता है, तो आप जीत जाते हैं। 3 आने पर आप फिर से पासा फेंक सकते हैं। बाकी वैल्यू आने पर आप हार जाते हैं:

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## टपल से मिलान

टपल का मिलान भी पैटर्न के एक समूह से किया जा सकता है। ये पैटर्न भी टपल की तरह ही लिखे जाते हैं।

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

अंतिम शाखा में किसी भी दिन और रंग के जोड़े से मिलान के लिए हम `(_, _)` लिखें या सिर्फ `_` वाइल्डकार्ड, इससे कोई अंतर नहीं पड़ता, क्योंकि दोनों काम एक ही तरह करते हैं।
