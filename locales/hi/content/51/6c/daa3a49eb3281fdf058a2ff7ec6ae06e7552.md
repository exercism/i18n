# परिचय

## पेयर

एक `Pair` बस दो चीज़ों का जोड़ा होता है।
इन चीज़ों को फिर बड़े कल्पनाशील ढंग से `first` और `second` कहा जाता है।

इन्हें या तो `=>` ऑपरेटर से बनाइए, या `Pair()` कंस्ट्रक्टर से।

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## डिक्ट

पेयर का एक वेक्टर किसी भी दूसरे ऐरे की तरह होता है: इसमें क्रम तय रहता है, सारे एलिमेंट एक ही टाइप के होते हैं, और वे मेमोरी में एक के बाद एक संग्रहीत होते हैं।

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

ऊपर से देखने पर एक `Dict` भी वैसा ही लगता है, लेकिन इसमें संग्रहण ऐसे तरीके से लागू किया गया है कि एंट्री की संख्या बहुत बड़ी हो जाने पर भी की के ज़रिए वैल्यू तेज़ी से निकाली जा सकती है।

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

दूसरी भाषाओं में `Dict` जैसी ही चीज़ को डिक्शनरी (Python), Hash (Ruby) या HashMap (Java) कहा जाता है।

पेयर के मामले में, चाहे वे अकेले हों या किसी वेक्टर में, हर हिस्से के टाइप पर बहुत कम बंधन होते हैं।

`Dict` में मान्य होने के लिए `Pair` को `key => value` पेयर होना चाहिए, जहाँ `key` "हैश करने योग्य" हो।
सबसे ज़रूरी बात यह है कि `key` _इम्यूटेबल_ होना चाहिए। इसलिए `Char`, `Int`, `String`, `Symbol` और `Tuple` तो ठीक हैं, लेकिन `Vector` की अनुमति नहीं है।

### डिक्ट में बदलाव करना

एंट्री जोड़ी भी जा सकती है और बदली भी जा सकती है। नई की डालने पर नई एंट्री जुड़ जाती है, और पहले से मौजूद की पर नई वैल्यू असाइन करने पर वह एंट्री बदल जाती है।

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

किसी एंट्री को हटाने के लिए `delete!()` फंक्शन इस्तेमाल कीजिए। अगर की मौजूद है तो यह डिक्ट को बदल देता है, और अगर नहीं है तो चुपचाप कुछ नहीं करता।

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### की या वैल्यू मौजूद है या नहीं, यह जाँचना

इसे जाँचने के अलग-अलग तरीके हैं। किसी की की जाँच के लिए `haskey()` फंक्शन है:

```julia-repl
julia> haskey(pd, 'b')
true
```

या फिर आप की में और वैल्यू में, दोनों में से किसी में भी खोज सकते हैं:

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
