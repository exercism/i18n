# परिचय

`Agent` मॉड्यूल एक एब्रैक्शन उपलब्ध कराता है, जिससे [प्रोसेस और _receive-send_ लूप][exercism-processes] शुरू किए जा सकते हैं। आगे हम `Agent` मॉड्यूल से शुरू किए गए प्रोसेस को _'एजेंट प्रोसेस'_ कहेंगे। किसी _एजेंट प्रोसेस_ को एक केंद्रीय साझा स्थिति दर्शाने के लिए चुना जा सकता है।

_एजेंट प्रोसेस_ शुरू करने के लिए `Agent` में `start/2` फंक्शन है। `start` से _एजेंट प्रोसेस_ शुरू करते समय जो फंक्शन दिया जाता है, वह प्रोसेस की शुरुआती स्थिति लौटाता है:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map` या `List` की तरह ही `Agent` में भी _एजेंट प्रोसेस_ के साथ काम करने के लिए कई फंक्शन हैं।

आम तौर पर ऐसा किया जाता है कि `Agent` से जुड़ी सारी कार्यक्षमता को एक ही मॉड्यूल में रखा जाए और एनकैप्सुलेट किया जाए। यह मॉड्यूल उस डोमेन का होता है जिसका हम मॉडल बना रहे होते हैं।
