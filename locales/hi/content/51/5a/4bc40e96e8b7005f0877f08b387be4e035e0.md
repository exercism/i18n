# निर्देश

इस अभ्यास में आप कारखाने के कर्मचारियों के लिए नाम बैज छापने का कोड लिखेंगे।

## 1. कर्मचारी के लिए बैज छापिए

हर कर्मचारी के पास एक ID, एक नाम और एक विभाग का नाम होता है। 
कर्मचारी के बैज का लेबल इस तरह होता है: `"[id] - name - DEPARTMENT"`.
कर्मचारी के बैज का लेबल लौटाने के लिए `printBadge()` मेथड लागू कीजिए:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
ध्यान दीजिए कि लेबल पर विभाग का नाम बड़े अक्षरों में लिखा जाना चाहिए।
~~~~

## 2. नए कर्मचारी के लिए बैज छापिए

कंप्यूटर सिस्टम में एक अजीब बात है, जिसकी वजह से कारखाने में काम शुरू करते समय नए कर्मचारियों के पास कभी-कभी ID नहीं होती।
चूँकि बैज ज़रूरी होते हैं, इसलिए उन्हें ID के प्रीफिक्स के बिना एक अस्थायी बैज मिलेगा। 
`printBadge()` मेथड को ऐसे बदलिए कि वह उन नए कर्मचारियों के लिए भी काम करे जिनके पास अभी ID नहीं है:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. मालिक के लिए बैज छापिए

कारखाने के मालिक को भी हर समय बैज पहनना पड़ता है।
लेकिन मालिक का कोई विभाग नहीं होता। 
ऐसी स्थिति में लेबल पर विभाग के नाम की जगह `"OWNER"` छपना चाहिए।
मालिक के लिए लेबल छापने के लिए `printBadge()` मेथड बदलिए:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
ध्यान दीजिए कि हो सकता है कि मालिक भी कोई नया कर्मचारी हो:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
