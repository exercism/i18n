# परिचय

## `null` होने की क्षमता

Java में `null` लिटरल का उपयोग किसी वैल्यू के न होने को दर्शाने के लिए किया जाता है।

Java में सभी प्रिमिटिव डेटा टाइप की एक डिफॉल्ट वैल्यू होती है, इसलिए ये कभी `null` नहीं हो सकते। परंपरा के अनुसार इनके नाम छोटे अक्षर से शुरू होते हैं, जैसे `int`।

रेफरेंस टाइप में किसी ऑब्जेक्ट का मेमोरी एड्रेस रहता है और इनकी वैल्यू `null` हो सकती है। ये आम तौर पर बड़े अक्षर से शुरू होते हैं, जैसे `String`।

किसी प्रिमिटिव वेरिएबल को `null` वैल्यू असाइन करने की कोशिश करने पर कंपाइल टाइम एरर मिलती है, क्योंकि वह वेरिएबल हमेशा उसी टाइप की प्रिमिटिव वैल्यू रखता है जो उसे दी गई हो।

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

किसी रेफरेंस वेरिएबल को `null` वैल्यू असाइन करने पर कंपाइल टाइम एरर नहीं मिलती, क्योंकि रेफरेंस वेरिएबल `null` हो सकते हैं।

```java
//No error will occur as the String variable str is nullable
String str = null;
```
