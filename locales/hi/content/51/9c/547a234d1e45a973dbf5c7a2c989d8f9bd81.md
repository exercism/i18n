# निर्देश

इस अभ्यास में आप एक रिमोट कंट्रोल कार के साथ खेलेंगे, जिसे खरीदने के लिए आपने अंततः पर्याप्त पैसे बचा लिए हैं।

कार की बैटरी शुरू में पूरी (100%) रहती है। हर बार जब आप रिमोट कंट्रोल से कार चलाते हैं, तो वह 20 मीटर चलती है और बैटरी का एक प्रतिशत कम हो जाता है।

इस रिमोट कंट्रोल कार में एक शानदार LED डिस्प्ले है, जो दो जानकारियाँ दिखाता है:

- अब तक तय की गई कुल दूरी, जो इस तरह दिखाई जाती है: `"Driven <METERS> meters"`.
- बची हुई बैटरी, जो इस तरह दिखाई जाती है: `"Battery at <PERCENTAGE>%"`.

अगर बैटरी 0% पर पहुँच जाए, तो आप कार आगे नहीं चला सकते और बैटरी का डिस्प्ले `"Battery empty"` दिखाएगा।

आपके सामने छह कार्य हैं, और हर कार्य में आप रिमोट कंट्रोल कार के इंस्टेंस के साथ काम करेंगे।

## 1. बिल्कुल नई रिमोट कंट्रोल कार खरीदिए

एक बिल्कुल नई रिमोट कंट्रोल कार इंस्टेंस लौटाने के लिए (_static_) `RemoteControlCar.Buy()` मेथड लागू कीजिए:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. तय की गई दूरी दिखाइए

LED डिस्प्ले पर दिखाई जाने वाली दूरी लौटाने के लिए `RemoteControlCar.DistanceDisplay()` मेथड लागू कीजिए:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. बैटरी का प्रतिशत दिखाइए

LED डिस्प्ले पर दिखाया जाने वाला बैटरी प्रतिशत लौटाने के लिए `RemoteControlCar.BatteryDisplay()` मेथड लागू कीजिए:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. कार चलते समय तय किए गए मीटर बदलिए

तय किए गए मीटर बदलने वाला `RemoteControlCar.Drive()` मेथड लागू कीजिए:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. कार चलते समय बैटरी का प्रतिशत बदलिए

बैटरी का प्रतिशत बदलने के लिए `RemoteControlCar.Drive()` मेथड को बदलिए:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. बैटरी खत्म होने पर कार चलने से रोकिए

जब बैटरी खत्म (0% पर) हो जाए, तब न तय की गई दूरी बढ़े और न बैटरी का प्रतिशत घटे, इसके लिए `RemoteControlCar.Drive()` मेथड को बदलिए:

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
