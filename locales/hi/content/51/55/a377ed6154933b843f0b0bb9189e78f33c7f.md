# परिचय

लूप एक ऐसा तरीका है जिसमें एक या अधिक स्टेटमेंट को एक बैच में बार-बार चलाया जाता है।
स्टेटमेंट के एक बैच को हर बार चलाना एक इटरेशन कहलाता है।

## `while` लूप

`while` लूप स्टेटमेंट के एक बैच को तब तक चलाता है जब तक लूप के शुरू में लिखा बूलियन एक्सप्रेशन सही रहता है।
जब वह बूलियन एक्सप्रेशन गलत हो जाता है, तो लूप चलना बंद कर देता है और कोड लूप के बाद वाली अगली लाइन से आगे बढ़ जाता है।

अगर बूलियन एक्सप्रेशन शुरू से ही गलत निकलता है, तो `while` लूप एक बार भी नहीं चलेगा और कोड सीधे लूप के बाद वाली अगली लाइन पर चला जाएगा।

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

लूप को खत्म करने के लिए एक शर्त होना ज़रूरी है। अगर ऐसी शर्त न हो, तो यह एक अनंत लूप बन जाता है, जो कोड को आगे बढ़ने ही नहीं देगा।
अगर ऊपर के कोड में `i` से `++` हटा दिया जाए, तो यह अनंत लूप बन जाएगा।

## `do` लूप

`do` लूप में बूलियन एक्सप्रेशन की जाँच लूप के अंत में होती है।
`do` लूप हमेशा कम से कम एक बार चलता है, जैसा कि नीचे दिए उदाहरण में है:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

`while` लूप इस्तेमाल करने पर यही काम ज़्यादा लंबा हो जाता।

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` लूप

अक्सर लूप एक वेरिएबल की वैल्यू बदलता रहता है और तब खत्म होता है जब वह वेरिएबल एक तय वैल्यू तक पहुँच जाता है।
`for` लूप एक तरीका है जिसमें ब्रैकेट के अंदर एक ही लाइन में एक या अधिक वेरिएबल को शुरुआती वैल्यू देना, उनकी जाँच करना और उनकी वैल्यू बदलना, तीनों काम किए जाते हैं।
पहला हिस्सा वेरिएबल को शुरुआती वैल्यू देने के लिए है, दूसरा वेरिएबल की जाँच करने के लिए, और तीसरा वेरिएबल की वैल्यू बदलने के लिए।

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

यह `while` लूप वाले तरीके से कम लंबा है, फिर भी पढ़ने में आसान है।
