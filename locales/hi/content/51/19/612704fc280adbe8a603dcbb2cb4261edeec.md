# इसके बारे में

जब आपको Factor के सीक्वेंस को *बदलना* होता है, तो वे दो तरह के होते हैं:

- **ऐरे** (`{ … }`) की लंबाई निश्चित होती है। आप `set-nth` / `change-nth` की मदद से हर स्थान *पर* मौजूद चीज़ को बदल सकते हैं, लेकिन उन्हें बढ़ा या छोटा नहीं कर सकते।
- **वेक्टर** (`V{ … }`) की लंबाई परिवर्तनशील होती है। `push` अंत में जोड़ता है, `pop` अंतिम एलिमेंट को हटाकर लौटाता है।

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| वर्ड            | प्रभाव                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: `elt` की `n` कॉपियों का ऐरे |
| `<vector>`      | `( n -- vector )`: `n` क्षमता वाला खाली वेक्टर |
| `V{ }`          | खाली वेक्टर लिटरल                           |
| `set-nth`       | `( elt n seq -- )`: इंडेक्स `n` पर एलिमेंट असाइन करता है |
| `change-nth`    | `( i seq quot -- )`: `i` पर मौजूद एलिमेंट पर `quot` लागू करता है |
| `push`          | `( elt seq -- )`: वेक्टर के अंत में जोड़ता है          |
| `suffix!`       | `( seq elt -- seq )`: मौजूदा वेक्टर में ही जोड़ता है, वेक्टर लौटाता है |
| `pop`           | `( seq -- elt )`: अंतिम एलिमेंट हटाकर लौटाता है      |
| `pop*`          | `( seq -- )`: अंतिम एलिमेंट हटाता है और उसे छोड़ देता है |
| `clone`         | `( obj -- copy )`: नई स्वतंत्र कॉपी     |
| `new-sequence`  | `( n exemplar -- newseq )`: `exemplar` के समान क्लास का नया सीक्वेंस |
| `new-resizable` | `( n exemplar -- newseq )`: नया रीसाइज़ेबल वेरिएंट |

जब आप किसी ऐसे सीक्वेंस में बदलाव करते हैं जो कॉल करने वाले कोड ने पास किया था, तो वह बदलाव कॉल करने वाले कोड को दिखता है, क्योंकि उसके पास वही ऑब्जेक्ट है। अगर आप यह नहीं चाहते, तो पहले `clone` करके एक स्वतंत्र कॉपी बनाइए।
