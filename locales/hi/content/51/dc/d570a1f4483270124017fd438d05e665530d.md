# परिचय

चारलिस्ट `~c` सिगिल की मदद से बनाई जाती हैं।

```elixir
~c"hello"
```

~~~~exercism/note
ध्यान दीजिए कि Elixir के पुराने वर्ज़न में चारलिस्ट को सिंगल कोट्स के साथ `'hello'` के रूप में लिखा जाता था।
~~~~

हालाँकि ये देखने में स्ट्रिंग जैसी लगती हैं, फिर भी ये दोनों डेटा टाइप एक-दूसरे से बिल्कुल अलग हैं। चारलिस्ट पूर्णांकों का एक ऐरे होती है। ये पूर्णांक किसी अक्षर की यूनिकोड वैल्यू दर्शाते हैं, जिन्हें कोड पॉइंट भी कहा जाता है।

```elixir
[65, 66, 67]
# => ~c"ABC"
```

किसी अक्षर के आगे `?` लगाकर आप उसका कोड पॉइंट पा सकते हैं।

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

चूँकि चारलिस्ट ऐरे होती हैं, आप इनके साथ किसी भी दूसरे ऐरे की तरह, यानी रिकर्शन और पैटर्न मैचिंग की मदद से, काम कर सकते हैं।

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

आप `++` की मदद से दो ऐरे जोड़ सकते हैं।

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

पहला ऐरे जितना लंबा होगा, जोड़ना उतना ही धीमा होगा। इसलिए किसी भी लंबाई के ऐरे में बार-बार जोड़ते रहने से बचिए।
