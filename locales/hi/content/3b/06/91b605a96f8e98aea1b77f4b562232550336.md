# केस स्टेटमेंट

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## मिलान कैसे होता है

`case` के बाद लिखी वैल्यू की तुलना ऊपर से नीचे तक हर `when` वैल्यू से `=` की मदद से की जाती है। सबसे पहला मिलान चलता है, और सिर्फ वही। बाकी `when` वाले हिस्से छोड़ दिए जाते हैं, और कोड `end` के बाद से आगे चलता रहता है।

जो भी टाइप `=` के साथ काम करता है, उसका उपयोग किया जा सकता है: `INT`, `CHAR`, `STR`, `BOOL`.

## `else` वाला भाग

बिना मिलान वाला `case` जिसमें `else` न हो, वह प्रोग्राम चलते समय एक घातक एरर देता है। `else` हमेशा लिखिए। जब बाकी केस वास्तव में होने ही नहीं चाहिए, तो उसे छोड़ने के बजाय वहीं यह बात लिख दीजिए:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` की बात आगे चलकर आएगी; तब तक कोई उचित डिफ़ॉल्ट वैल्यू लौटाना ठीक है।

## `if` कब बेहतर है

`case` एक वैल्यू की तुलना कॉन्स्टेंट से करता है। बाकी किसी भी स्थिति के लिए `if` चाहिए:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

किसी रेंज को ज़बरदस्ती `case` में डालने से जो नतीजा मिलता है, वह उस `if` से ज़्यादा लंबा और खराब होता है जिसकी जगह उसने ली थी।

## `case` एक एक्सप्रेशन के रूप में

`case` एक स्टेटमेंट है, एक्सप्रेशन नहीं, इसलिए यह Sather नहीं है:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

हर हिस्से के अंदर से लौटाइए, या हर हिस्से के अंदर ही किसी वेरिएबल को वैल्यू असाइन कीजिए।
