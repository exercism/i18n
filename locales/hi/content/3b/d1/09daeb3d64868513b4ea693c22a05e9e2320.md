# परिचय

C# में संख्याओं के साथ काम करने के मुख्य पहलुओं में से एक है पूर्णांकों (वे संख्याएँ जिनमें दशमलव चिह्न के बाद कोई अंक नहीं होते) और फ्लोटिंग-पॉइंट संख्याओं (वे संख्याएँ जिनमें दशमलव चिह्न के बाद शून्य या अधिक अंक होते हैं) के बीच का अंतर।

C# में सबसे अधिक इस्तेमाल होने वाले दो संख्यात्मक टाइप `int` (एक 32-बिट पूर्णांक) और `double` (एक 64-बिट फ्लोटिंग-पॉइंट संख्या) हैं।

```csharp
int i = 123;
double d = 54.29;
```

पूर्णांक और फ्लोटिंग-पॉइंट संख्याएँ दोनों `_` अक्षर को _अंक विभाजक_ के रूप में इस्तेमाल कर सकते हैं, जिससे बड़ी संख्याएँ लिखते समय मदद मिलती है:

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

अंकगणित मानक [अंकगणितीय ऑपरेटरों][arithmetic-operators] (`+`, `-`, `*`, आदि) की मदद से किया जाता है। संख्याओं की तुलना मानक [तुलना ऑपरेटरों][comparison-operators] (`<`, `>=`, आदि) और [समानता][equality-operators] ऑपरेटर (`==`) तथा [असमानता][equality-operators] ऑपरेटर (`!=`) की मदद से की जा सकती है।

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

संख्यात्मक टाइपों के बीच बदलते समय दो तरह के संख्यात्मक रूपांतरण होते हैं:

1. अंतर्निहित रूपांतरण: कोई डेटा नष्ट नहीं होगा और किसी अतिरिक्त सिंटैक्स की आवश्यकता नहीं होती।
2. स्पष्ट रूपांतरण: डेटा नष्ट हो सकता है और _कास्ट_ के रूप में अतिरिक्त सिंटैक्स आवश्यक होता है।

चूँकि `int` में `double` से कम परिशुद्धता होती है, `int` से `double` में बदलना सुरक्षित है और इसलिए यह अंतर्निहित रूपांतरण है। लेकिन `double` से `int` में बदलने पर डेटा नष्ट हो सकता है, इसलिए उसके लिए स्पष्ट रूपांतरण आवश्यक होता है।

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
