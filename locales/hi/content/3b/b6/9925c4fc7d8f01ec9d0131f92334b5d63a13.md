# सीखने के लिए सुझाए गए संसाधन

Exercism अभ्यास और प्रतिक्रिया देता है, लेकिन जो लोग पहली बार ABAP सीख रहे हैं, उनके लिए इसकी शुरुआत करना मुश्किल लग सकता है। ये मुफ्त संसाधन आपको शुरुआत करने में मदद कर सकते हैं:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

अगर आप ABAP में नए हैं, तो हमारा सुझाव है कि आप SAP Learning Journey की ये इकाइयाँ पूरी कीजिए:

- Getting Started
- ABAP Language Basics
- Local Classes 

इसके बाद आप Exercism पर ABAP के अभ्यास हल करने के लिए तैयार हो जाएँगे।

अगर आप और जटिल अभ्यासों तक पहुँचते हैं, तो हमारा सुझाव है कि आप ये इकाइयाँ भी देख लीजिए:

- Structures
- Complex Internal Tables

Exercism पर कठिन अभ्यास हल करने में ये विषय मददगार हो सकते हैं।
