# निर्देश

जादूगर बनने की तैयारी कर रही एलिस को कुछ बुनियादी बातों का अभ्यास करना है।

उसके पास कार्डों का एक ढेर है, जिसके साथ वह तरह-तरह के काम करना चाहती है।

इसे थोड़ा आसान बनाने के लिए वह सिर्फ 1 से 10 तक के कार्ड इस्तेमाल करती है।

कार्डों के इस ढेर को एक `Array` से दर्शाया जाता है। ढेर का सबसे नीचे वाला कार्ड ऐरे में सबसे आगे होता है और सबसे ऊपर वाला कार्ड सबसे पीछे।

## 1. ढेर के ऊपर एक कार्ड डालिए

फंक्शन `insert_top` बनाइए, जो ढेर की एक कॉपी लौटाता है जिसमें दिया गया नया कार्ड ढेर के ऊपर जोड़ दिया गया हो।

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. ढेर से सबसे ऊपर वाला कार्ड हटाइए

फंक्शन `remove_top_card` बनाइए, जो ढेर की एक ऐसी कॉपी लौटाता है जिसमें से सबसे ऊपर वाला कार्ड हटा दिया गया हो।

अगर दिया गया ढेर खाली हो, तो आपको मूल ढेर बिना किसी बदलाव के ही लौटाना है।

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. ढेर के नीचे एक कार्ड डालिए

फंक्शन `insert_bottom` बनाइए, जो ढेर की एक कॉपी लौटाता है जिसमें दिया गया नया कार्ड ढेर के नीचे जोड़ दिया गया हो।

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. ढेर के नीचे से एक कार्ड हटाइए

फंक्शन `remove_bottom_card` बनाइए, जो ढेर की एक ऐसी कॉपी लौटाता है जिसमें से सबसे नीचे वाला कार्ड हटा दिया गया हो।

अगर दिया गया ढेर खाली हो, तो आपको मूल ढेर बिना किसी बदलाव के ही लौटाना है।

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. ढेर का आकार जाँचिए

फंक्शन `check_size_of_stack` बनाइए, जो जाँचता है कि ढेर का आकार दिए गए `stack_size` के बराबर है या नहीं।

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
