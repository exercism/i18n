# परिचय

## स्ट्रिंग

याद कीजिए कि `jq` में भी वही डेटा टाइप होते हैं जो JSON में होते हैं।
JSON **स्ट्रिंग** को इस तरह बताता है:

> स्ट्रिंग शून्य या अधिक यूनिकोड अक्षरों का एक क्रम होती है, जिसे दोहरे उद्धरण चिह्नों में रखा जाता है और जिसमें बैकस्लैश एस्केप का उपयोग होता है।

### एस्केप सीक्वेंस

स्ट्रिंग के अंदर "खास" अक्षर डालने के लिए बैकस्लैश अक्षर का उपयोग कीजिए:

- `\"` एक वास्तविक उद्धरण चिह्न,
- `\\` एक वास्तविक बैकस्लैश,
- व्हाइटस्पेस अक्षर `\n`, `\t`, `\r`, `\f`, `\b`
- यूनिकोड अक्षर `\uAAAA`, जहाँ `A` एक हेक्स अंक है

### स्ट्रिंग की लंबाई

अक्षरों की संख्या जानने के लिए `length` फंक्शन का उपयोग कीजिए।

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### सबस्ट्रिंग

सबस्ट्रिंग निकालने के लिए **स्लाइस** नोटेशन का उपयोग किया जा सकता है।
इसका सिंटैक्स `.[i:j]` है।
जो सबस्ट्रिंग लौटती है, उसकी लंबाई `j - i` होती है। यह इंडेक्स `i` से (जो शामिल है) इंडेक्स `j` तक (जो शामिल नहीं है) के अक्षर लौटाती है।
कोई भी इंडेक्स ऋणात्मक हो सकता है, और ऐसा होने पर वह स्ट्रिंग के अंत से पीछे की ओर गिना जाता है।
कोई भी इंडेक्स छोड़ा जा सकता है, और ऐसा होने पर उसका अर्थ स्ट्रिंग का शुरू या अंत होता है।
इंडेक्स शून्य से गिने जाते हैं।

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### जोड़ना

स्ट्रिंग जोड़ने के लिए `+` का उपयोग कीजिए:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

जब स्ट्रिंग का ऐरे दिया हो, तो `add` का उपयोग कीजिए:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### अलग करना और जोड़ना

अलग करने के लिए `split/1` फंक्शन या `/` ऑपरेटर का उपयोग होता है:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1` का उल्टा `join/1` है।

किसी स्ट्रिंग को अक्षरों के ऐरे में बदलने की ज़रूरत अक्सर पड़ती है।
यह करने के दो तरीके हैं:

1. खाली स्ट्रिंग पर अलग करना

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. _कोडपॉइंट_ के ऐरे में `explode` करना

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode`, `explode` का उल्टा है।

### सबस्ट्रिंग का इंडेक्स ढूँढना

`index/1` फंक्शन का उपयोग कीजिए; इंडेक्स शून्य से शुरू होता है।

```jq
"hello" | index("el")'   # => 1
```

अगर सबस्ट्रिंग स्ट्रिंग में नहीं है, तो परिणाम `null` होता है

```jq
"hello" | index("elk")   # => null
```

### स्ट्रिंग इंटरपोलेशन

स्ट्रिंग के अंदर `\(expression)` क्रम उस एक्सप्रेशन का _परिणाम_ [स्ट्रिंग में][interpolate] डाल देता है:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### केस बदलना

`ascii_downcase` और `ascii_upcase` फंक्शन का उपयोग कीजिए।

### रेगुलर एक्सप्रेशन

`jq` में रेगुलर एक्सप्रेशन के लिए भरपूर समर्थन है: यह आगे के किसी पाठ का विषय होगा।

[interpolate]: https://jqlang.org/manual/#string-interpolation
