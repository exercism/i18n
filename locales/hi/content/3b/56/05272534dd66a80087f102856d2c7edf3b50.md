# परिवर्तनशीलता

Cairo का डिज़ाइन ब्लॉकचेन को ध्यान में रखकर बनाया गया है, इसलिए यह डिफॉल्ट रूप से अपरिवर्तनीय मेमोरी मॉडल अपनाता है।
इसका मतलब है कि एक बार मेमोरी में लिखी गई वैल्यू को बदला नहीं जा सकता, उसे सिर्फ पढ़ा जा सकता है।
लेकिन Cairo में `mut` कीवर्ड की मदद से परिवर्तनीय वेरिएबल बनाने का तरीका मौजूद है।
जब किसी वेरिएबल को परिवर्तनीय घोषित किया जाता है और उसकी वैल्यू बदली जाती है, तो नई वैल्यू एक नई मेमोरी सेल में लिखी जाती है और वेरिएबल अब उस नई सेल की ओर इशारा करने लगता है।
यह तरीका लचीलापन देता है, और साथ ही अपरिवर्तनीयता के लाभ भी बनाए रखता है।

नीचे दिए गए उदाहरण में `x` को अपरिवर्तनीय वेरिएबल घोषित किया गया है।
अगर `x` की वैल्यू बदलने की कोशिश की जाए, तो कंपाइलर एक एरर देगा।

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

`mut` कीवर्ड की मदद से हम `x` को परिवर्तनीय वेरिएबल घोषित कर सकते हैं।
ऐसा करने पर घोषित होने के बाद भी `x` की वैल्यू बदली जा सकती है।

```rust
let mut x = 5;
x = 10;
```

अंततः यह तय करना आप पर है कि परिवर्तनशीलता इस्तेमाल करनी है या नहीं। यह इस बात पर भी निर्भर करता है कि उस खास स्थिति में आपको क्या सबसे साफ लगता है।

## स्थिरांक

अपरिवर्तनीय वेरिएबल की तरह स्थिरांक भी ऐसी वैल्यू होते हैं जो एक नाम से बँधी होती हैं और बदली नहीं जा सकतीं। लेकिन स्थिरांक और वेरिएबल में कुछ अंतर हैं:

- स्थिरांक `const` कीवर्ड से घोषित किए जाते हैं
- स्थिरांक के साथ `mut` इस्तेमाल नहीं किया जा सकता
- वैल्यू का टाइप हमेशा स्पष्ट रूप से बताना ज़रूरी होता है
- स्थिरांक सिर्फ ग्लोबल स्कोप में ही घोषित किए जा सकते हैं
- स्थिरांक को सिर्फ स्थिर एक्सप्रेशन ही असाइन किए जा सकते हैं, रनटाइम में गणना किए गए परिणाम को नहीं

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

`consteval_int!` मैक्रो की मदद से ऐसा `const` वेरिएबल बनाया जा सकता है जिसमें किसी गणना का परिणाम होता है।

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## शैडोइंग

किसी वैल्यू में बदलाव के साथ-साथ उसी वेरिएबल के नाम को दोबारा इस्तेमाल करना संभव है, और अक्सर यही स्वाभाविक तरीका भी होता है। इसके लिए `let` को एक के बाद एक कई बार लिखकर वेरिएबल दोबारा घोषित किया जाता है।
इसी को _शैडोइंग_ कहते हैं।
वास्तव में दूसरा वेरिएबल पहले वाले पर भारी पड़ जाता है और वेरिएबल के नाम का हर इस्तेमाल अपने ऊपर ले लेता है। यह तब तक चलता है जब तक कि वह खुद शैडो न हो जाए या स्कोप खत्म न हो जाए।

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

शैडोइंग की मदद से हम वेरिएबल का नाम वही रखते हुए उसका टाइप भी बदल सकते हैं।

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
