# परिचय

एक *रेगुलर एक्सप्रेशन* (रेगेक्स) एक छोटा पैटर्न होता है, जो बताता है कि किसी टेक्स्ट का रूप कैसा होना चाहिए। स्ट्रिंग को एक-एक अक्षर करके खुद जाँचने के बजाय, आप जो रूप चाहते हैं उसे एक बार लिख देते हैं और मैच करने का काम Factor को सौंप देते हैं। Factor के रेगेक्स टूल [`regexp`][regexp] वोकैबुलरी में रहते हैं।

## पैटर्न लिखना

Factor में आप रेगेक्स को `R/ ` और `/` के बीच लिखते हैं:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

पैटर्न के ज़्यादातर अक्षर अपने आप में ही अपना मतलब रखते हैं, यानी `R/ cat/` टेक्स्ट `cat` से मैच करता है। असली शक्ति कुछ खास टुकड़ों से आती है, जो अक्षरों की *किस्में* या उनकी *संख्या* बताते हैं।

### अक्षर क्लास: "एक सेट से एक अक्षर"

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

एक क्लास ठीक *एक* ही अक्षर से मैच करती है। `[A-Z]` `Q` से मैच करती है, पर `QQ` से नहीं।

### क्वांटिफायर: "कितनी बार"

किसी टुकड़े के *बाद* इनमें से एक लगाइए, ताकि पता चले कि वह कितनी बार दोहराया जा सकता है:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

तो `\d{4}` का मतलब है लगातार चार अंक, और `[A-Z]+` का मतलब है एक या उससे अधिक बड़े अक्षर। सब मिलाकर, `R/ [A-Z]+-\d+/` यह बताता है: "एक या उससे अधिक बड़े अक्षर, फिर एक डैश, और फिर एक या उससे अधिक अंक", यानी `SALE-2024` जैसा टेक्स्ट। यहाँ `-` एक साधारण अक्षर है: `[ ]` के बाहर डैश सिर्फ डैश से मैच करता है (`[A-Z]` की तरह किसी क्लास के अंदर यह रेंज बताता है)।

## पूरी स्ट्रिंग से मैच करना

`matches?` यह बताता है कि "क्या यह *पूरी* स्ट्रिंग पैटर्न में फिट बैठती है?" पैटर्न को शुरू से अंत तक हर अक्षर का हिसाब रखना पड़ता है:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

हालाँकि `SALE-2024` , `"GET SALE-2024"` के अंदर मौजूद है, फिर भी `matches?` `f` ही कहता है: अतिरिक्त अक्षर भी स्ट्रिंग का हिस्सा हैं, और वे पैटर्न में फिट नहीं बैठते। जब आपको सिर्फ यह देखना हो कि पैटर्न *कहीं* मौजूद है या नहीं, तो `re-contains?` इस्तेमाल कीजिए। यह ठीक वहीं `t` लौटाता है जहाँ `matches?` ने `f` लौटाया था:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## लंबे टेक्स्ट के अंदर मैच ढूँढना

`re-contains?` सिर्फ यह बताता है कि पैटर्न उसमें है या नहीं। अगले शब्द अंदर झाँककर यह बताते हैं कि *क्या* मैच हुआ: `all-matching-subseqs` हर उस जगह को लौटाता है जहाँ पैटर्न मैच करता है, स्ट्रिंग के सीक्वेंस के रूप में, और `count-matches` सिर्फ उनकी गिनती करता है:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## मैच बदलना

`re-replace` हर मैच को रिप्लेसमेंट टेक्स्ट से बदल देता है और नई स्ट्रिंग लौटाता है:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

`regexp` वोकैबुलरी में जानने लायक और भी शब्द हैं। जानकारी के लिए लिंक पर जाइए: [`first-match`][first-match] (सिर्फ पहला मैच) और [`re-split`][re-split] (स्ट्रिंग को वहाँ-वहाँ तोड़ना जहाँ-जहाँ पैटर्न मैच करता है)।
