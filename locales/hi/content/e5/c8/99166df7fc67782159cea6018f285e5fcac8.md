# इसके बारे में

लिंकेज बताता है कि कोड में किसी आइडेंटिफायर को कहाँ से एक्सेस किया जा सकता है।
जिन वैल्यू का स्कोप ब्लॉक, फंक्शन या फंक्शन प्रोटोटाइप होता है, उनका कोई लिंकेज नहीं होता।
यानी ऐसी वैल्यू को उसके स्कोप के बाहर से एक्सेस नहीं किया जा सकता।
स्कोप के बारे में अधिक जानने के लिए [स्कोप की अवधारणा](../scope/introduction.md#Introduction) देखिए।

## बाहरी लिंकेज

फाइल स्कोप वाले आइडेंटिफायर का लिंकेज डिफॉल्ट रूप से बाहरी होता है।
बाहरी लिंकेज वाले आइडेंटिफायर को प्रोग्राम की किसी भी फाइल से कॉल किया जा सकता है।

## आंतरिक लिंकेज

फाइल स्कोप वाले आइडेंटिफायर को `static` स्पेसिफायर का इस्तेमाल करके आंतरिक लिंकेज दिया जा सकता है।
आंतरिक लिंकेज वाले आइडेंटिफायर का इस्तेमाल सिर्फ उसी फाइल में किया जा सकता है।

उदाहरण के लिए

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

स्टैटिक लिंकेज को स्टैटिक स्टोरेज ड्यूरेशन के साथ भ्रमित नहीं करना चाहिए।
स्टैटिक स्टोरेज ड्यूरेशन के बारे में अधिक जानने के लिए [स्टोरेज ड्यूरेशन की अवधारणा](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type) देखिए।

अगर कोई वैल्यू (फंक्शन के बजाय) हेडर में घोषित है, पर उसे सोर्स फाइल में `static` फाइल-स्कोप आइडेंटिफायर के रूप में इनिशियलाइज़्ड वैल्यू के साथ परिभाषित किया गया है, तो उसकी इनिशियलाइज़्ड वैल्यू सोर्स फाइल के बाहर से एक्सेस नहीं की जा सकेगी।
ऐसा कोड बिना किसी एरर के कंपाइल और लिंक हो सकता है और चल भी सकता है, लेकिन उस आइडेंटिफायर की वैल्यू शून्य ही रहेगी, चाहे वह वैल्यू `extern` के साथ घोषित की गई हो।
(`extern` के बारे में अधिक जानने के लिए [extern की अवधारणा](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit) देखिए।)
सोर्स फाइल में `static` के रूप में चिह्नित फाइल-स्कोप आइडेंटिफायर को उसकी हेडर फाइल में घोषित नहीं करना चाहिए।
