# टेस्ट

टेस्ट इनसे चलाइए:

```shell
npm run test
```

आप Jest को "watch" मोड में भी चला सकते हैं, जिसमें कोड या टेस्ट मॉड्यूल में बदलाव सेव करते ही आपके टेस्ट अपने आप दोबारा चल जाएँगे:

```shell
npm run watch
```

## स्किप किए गए टेस्ट को समझना

स्किप मेथड टेस्ट सूट को बताता है कि किसी टेस्ट को न चलाए, और यह फंक्शन इन उपनामों से भी इस्तेमाल किया जा सकता है: `it.skip(name, fn)` या `xit(name, fn)` या `xtest(name, fn)`

- ये स्किप क्यों किए जाते हैं?

ताकि उपयोगकर्ता एक समय में एक टेस्ट पर ध्यान दे सकें और जैसे-जैसे वे हल आगे बढ़ाते हैं, उन्हें एक-एक करके चालू कर सकें।

- इन्हें चालू कैसे करें?

`xtest` को `test` में बदल दीजिए।

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
