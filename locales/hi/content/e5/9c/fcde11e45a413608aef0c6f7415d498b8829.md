# परिचय

Go में फंक्शन फर्स्ट-क्लास वैल्यू होते हैं।
इसका मतलब है कि फंक्शन के साथ आप वही सब कर सकते हैं जो आप बाकी सभी वैल्यू के साथ कर सकते हैं: फंक्शन को वेरिएबल में असाइन करना, उन्हें दूसरे फंक्शन को आर्गुमेंट के रूप में भेजना, या किसी दूसरे फंक्शन से फंक्शन लौटाना।

नीचे हम दो फंक्शन बना रहे हैं, `engGreeting` और `espGreeting`, और उन्हें `greeting` वेरिएबल में असाइन कर रहे हैं:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

फंक्शन वैल्यू हमें मौका देती हैं कि हम फंक्शन को केवल डेटा ही नहीं, बल्कि व्यवहार भी दें।
अगले उदाहरण में हम `dialog` फंक्शन को `greetingFunc` पैरामीटर के ज़रिए व्यवहार भेज रहे हैं:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

जिस फंक्शन-टाइप वेरिएबल को कोई शुरुआती वैल्यू नहीं दी जाती, उसकी वैल्यू `nil` होती है।
इसलिए `nil` फंक्शन वैल्यू को कॉल करने पर पैनिक होता है।

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

फंक्शन वैल्यू की तुलना `nil` से की जा सकती है।
यह प्रोग्राम में होने वाले अनावश्यक पैनिक से बचने में काम आ सकता है।

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## फंक्शन टाइप

Go में फंक्शन वैल्यू के साथ काम करना फंक्शन टाइप की वजह से संभव होता है।
एक फंक्शन टाइप उन सभी फंक्शनों के समूह को बताता है जिनके पैरामीटर टाइप का क्रम और परिणाम टाइप का क्रम एक जैसा होता है।
फंक्शन टाइप के ऊपर उपयोगकर्ता द्वारा बनाए गए टाइप भी घोषित किए जा सकते हैं।
उदाहरण के लिए, पिछले उदाहरणों वाले `dialog` फंक्शन को इस तरह बदला जा सकता है:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## अनाम फंक्शन

फर्स्ट-क्लास फंक्शन के कारण एक और शक्तिशाली औज़ार उपलब्ध है, और वह है अनाम फंक्शन।
अनाम फंक्शन वहीं बनाए जाते हैं जहाँ उनका उपयोग होता है, और `func` कीवर्ड के बाद कोई नाम नहीं लिखा जाता।
ऐसे फंक्शन अपने बाहरी फंक्शन के वेरिएबलो तक पहुँच सकते हैं।

उदाहरण के लिए:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib` को कॉल करने पर वेरिएबल `n1` और `n2` घोषित होते हैं और एक अनाम फंक्शन लौटता है, जो बदले में हर कॉल पर इन वेरिएबलो की वैल्यू बदल देता है।
अनाम फंक्शन को N बार कॉल करने पर 0 से शुरू होने वाले फिबोनाची क्रम की Nवीं संख्या मिलती है। अंदर वाला अनाम फंक्शन अपने बाहरी फंक्शन `fib` के लोकल वेरिएबलो (`n1` और `n2`) तक पहुँच सकता है।
कॉल के बीच फंक्शन वैल्यू की स्थिति बनाए रखने का यह बहुत अच्छा तरीका है।
हम कहते हैं कि यह अनाम फंक्शन `n1` और `n2` वेरिएबलो का क्लोज़र है।
[क्लोज़र][closure] प्रोग्रामिंग में बहुत जगह इस्तेमाल होते हैं, और हो सकता है आप दूसरी भाषाओं में भी इनका उपयोग देखें।
