# टेस्ट

हर उदाहरण के लिए आम तौर पर ये चरण अपनाने होते हैं।

सबसे पहले उस अभ्यास की डायरेक्टरी में जाइए जिसे आप करना चाहते हैं, यहाँ इस मामले में `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

इसके बाद टेस्ट चलाइए। `test` नाम का make टार्गेट `compile` पर निर्भर करता है, इसलिए `make test` चलाने पर आपका सोर्स पहले कंपाइल हो जाएगा, और उसके बाद टेस्ट चलेंगे।

```bash
$ make test
```

बधाई हो! आपके टेस्ट फेल हो रहे हैं!!!

अब `README.md` पढ़िए और जानिए कि सारे टेस्ट पास कराने के लिए आपको क्या करना है।

टेस्ट जो पहली एरर बताता है उसे ठीक कीजिए, और फिर टेस्ट दोबारा चलाइए।

```bash
$ make test
```

अब अपने सोर्स कोड में अगला फेल होने वाला टेस्ट ठीक कीजिए और तब तक टेस्ट चलाते रहिए जब तक सारे टेस्ट पास न हो जाएँ।

जब सारे टेस्ट पास हो जाएँ, तो `src` डायरेक्टरी में अपने कोड पर एक अंतिम नज़र डालिए, यह देखने के लिए कि आप अपने कोड से खुश हैं, और फिर उसे रिव्यू के लिए जमा कीजिए।

फीडबैक लीजिए, अपने हल में सुधार कीजिए, जमा कीजिए, अगला अभ्यास कीजिए, और यही सिलसिला तब तक दोहराते रहिए जब तक LFE का ज्ञानोदय न हो जाए।
