# परिचय

## सामान्य सिंटैक्स

किसी लॉजिक को बार-बार चलाने के लिए `for` लूप सबसे आम स्टेटमेंट में से एक है।
Go में इसमें `for` कीवर्ड, एक हेडर और एक कोड ब्लॉक होता है, जिसके अंदर लूप का कोड घुंघराले ब्रैकेट में लिपटा रहता है।
हेडर में तीन हिस्से होते हैं, जिन्हें सेमीकोलन `;` से अलग किया जाता है: init, condition और post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init** हिस्सा वह कोड है जो लूप शुरू होने से पहले सिर्फ एक बार चलता है।
- **condition** हिस्सा एक ऐसा एक्सप्रेशन होना चाहिए जो बूलियन वैल्यू देता है और तय करता है कि लूप कब रुकना चाहिए।
  लूप के अंदर का कोड तब तक चलता रहेगा जब तक यह शर्त सही रहती है।
  जैसे ही यह एक्सप्रेशन गलत होता है, लूप का कोई और इटरेशन नहीं चलेगा।
- **post** हिस्सा वह कोड है जो हर इटरेशन के अंत में चलता है।

**ध्यान दें:** दूसरी भाषाओं के उलट, हेडर के तीनों हिस्सों के चारों ओर कोई गोल ब्रैकेट `()` नहीं होते।
वास्तव में ऐसा ब्रैकेट लगाना कंपाइलेशन एरर देता है।
लेकिन लूप के अंदर के कोड के चारों ओर घुंघराले ब्रैकेट `{ }` हमेशा ज़रूरी होते हैं।

## `for` लूप - एक उदाहरण

**init** हिस्सा आम तौर पर एक काउंटर वेरिएबल तैयार करता है, **condition** हिस्सा जाँचता है कि लूप जारी रहना चाहिए या रुकना चाहिए, और **post** हिस्सा आम तौर पर हर इटरेशन के अंत में काउंटर बढ़ा देता है।

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

यह लूप `1` से `9` तक की संख्याएँ प्रिंट करेगा (`9` समेत)।
स्टेप तय करना अक्सर बढ़ाने या घटाने वाले स्टेटमेंट से किया जाता है, जैसा ऊपर के उदाहरण में दिखाया गया है।
