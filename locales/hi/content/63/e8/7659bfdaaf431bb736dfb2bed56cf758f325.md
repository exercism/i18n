# निर्देश

इस अभ्यास में आपको क्लासिक खेल Pac-Man के कुछ नियमों को Haskell फंक्शन में बदलना है।

आपको चार नियम बदलने हैं, और ये सभी खेल की स्थितियों से जुड़े हैं।

> इस बात की चिंता न कीजिए कि आर्गुमेंट कहाँ से आते हैं। बस उन्हें मिलाकर वह परिणाम लौटाने पर ध्यान दीजिए जो आप चाहते हैं।

## 1. तय कीजिए कि Pac-Man भूत खाता है या नहीं

`eatsGhost` फंक्शन बनाइए, जो दो आर्गुमेंट लेता है (_क्या Pac-Man का पावर पेलेट सक्रिय है_ और _Pac-Man भूत को छू रहा है_) और जब Pac-Man भूत को खा सकता है तब एक `Bool` वैल्यू लौटाता है।
यह फंक्शन `True` तभी लौटाना चाहिए जब Pac-Man का पावर पेलेट सक्रिय हो और वह भूत को छू रहा हो।

```haskell
eatsGhost False True
-- -> False
```

## 2. तय कीजिए कि Pac-Man ने स्कोर किया या नहीं

`scores` फंक्शन बनाइए, जो दो आर्गुमेंट लेता है (_क्या Pac-Man पावर पेलेट को छू रहा है_ और _Pac-Man बिंदु को छू रहा है_) और अगर Pac-Man ने स्कोर किया हो तो एक `Bool` वैल्यू लौटाता है।
यह फंक्शन `True` तब लौटाना चाहिए जब Pac-Man पावर पेलेट या बिंदु को छू रहा हो।

```haskell
scores True True
-- -> True
```

## 3. तय कीजिए कि Pac-Man हारता है या नहीं

`loses` फंक्शन बनाइए, जो दो आर्गुमेंट लेता है (_क्या Pac-Man का पावर पेलेट सक्रिय है_ और _Pac-Man भूत को छू रहा है_) और अगर Pac-Man हारता हो तो एक `Bool` वैल्यू लौटाता है।
यह फंक्शन `True` तब लौटाना चाहिए जब Pac-Man भूत को छू रहा हो और उसका पावर पेलेट सक्रिय न हो।

```haskell
loses False True
-- -> True
```

## 4. तय कीजिए कि Pac-Man जीतता है या नहीं

`wins` फंक्शन बनाइए, जो तीन आर्गुमेंट लेता है (_क्या Pac-Man सारे बिंदु खा चुका है_, _Pac-Man का पावर पेलेट सक्रिय है_, और _Pac-Man भूत को छू रहा है_) और अगर Pac-Man जीतता हो तो एक `Bool` वैल्यू लौटाता है।
यह फंक्शन `True` तब लौटाना चाहिए जब Pac-Man सारे बिंदु खा चुका हो _और_ भाग 3 में बताए गए आर्गुमेंट के आधार पर वह न हारा हो।

```haskell
wins False True False
-- -> False
```
