# संसाधन

## मदद कैसे लें

1. [The Emacs Wiki](http://emacswiki.org/) बहुत काम की चीज़ है। यहाँ खूब समय बिताइए।
2. [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) GNU Emacs की आधिकारिक मैनुअल है।
3. IRC - [Libera.Chat](https://libera.chat/) पर `#emacs`, `#org-mode` और कई Emacs पैकेजों के चैनल हैं, और आसपास बहुत से मददगार लोग मिल जाते हैं। और Emacs में IRC बस `M-x erc` भर दूर है।
4. Matrix - [Matrix](https://matrix.org/) पर [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) और दूसरे Emacs पैकेजों के लिए रूम हैं।
   उपलब्ध चैनलों का अवलोकन पाने के लिए आप [Emacs Matrix स्पेस से जुड़ सकते हैं](https://matrix.to/#/#emacs-space:matrix.org)।
   Emacs के अंदर से Matrix से जुड़ने के लिए आप [Ement.el](https://github.com/alphapapa/ement.el) पैकेज इस्तेमाल कर सकते हैं।
5. [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) और [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) की मदद से आप अपनी समस्या खोज सकते हैं और देख सकते हैं कि उसका जवाब पहले ही दिया जा चुका है या नहीं। आप सवाल पूछ भी सकते हैं और जवाब भी दे सकते हैं।
