# बूलियन

कुछ सवालों के सिर्फ दो जवाब होते हैं: हाँ या नहीं। ऐसे जवाब के लिए Sather का टाइप `BOOL` है, और दोनों जवाब `true` और `false` लिखे जाते हैं।

```sather
   ready : BOOL is
      return true;
   end;
```

## तुलना

दो संख्याओं की तुलना करने पर एक `BOOL` मिलता है।

| ऑपरेटर | क्या पूछता है |
| --- | --- |
| `=` | क्या दोनों एक जैसी हैं? |
| `/=` | क्या दोनों अलग हैं? |
| `<` | क्या बाईं संख्या छोटी है? |
| `<=` | छोटी, या बराबर? |
| `>` | क्या बाईं संख्या बड़ी है? |
| `>=` | बड़ी, या बराबर? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

ध्यान दीजिए कि `=` एक सवाल पूछता है। किसी चीज़ के *अंदर* वैल्यू रखना `:=` है, जिसे आप पहले देख चुके हैं। ये दोनों एक जैसे नहीं हैं।

## जोड़ना

तीन ऑपरेटर छोटे सवालों से बड़े सवाल बनाते हैं।

`and` तब सही होता है जब **दोनों** तरफ सही हों।

```sather
harness_on and rope_checked
```

`or` तब सही होता है जब **कोई एक** तरफ सही हो, या दोनों।

```sather
mat_below or net_below
```

`~` जवाब को उलट देता है: यह सही को गलत और गलत को सही बना देता है।

```sather
~ready       -- true exactly when ready is false
```

`and` और `or` दो जवाबों के बीच आते हैं; `~` एक जवाब के आगे आता है।
