# निर्देश

आप एक फील्ड गाइड बना रहे हैं: हर जानवर के नाम के सामने उसका निवास स्थान दर्ज रहता है।

पाँचों काम आपको `FIELD_GUIDE` क्लास में लिखने हैं।

## 1. क्या यह गाइड में शामिल है?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. यह कहाँ रहता है?

किसी जानवर के लिए दर्ज निवास स्थान लौटाइए। अगर गाइड में उस जानवर का उल्लेख ही न हो, तो `"Unknown"` लौटाइए।

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. एक प्रविष्टि जोड़िए

ऐसी गाइड लौटाइए जिसमें एक जानवर और जुड़ा हो। अगर जानवर पहले से सूची में है, तो उसका निवास स्थान बदल दिया जाता है।

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

यह जो भी लौटाता है, आगे से वही गाइड इस्तेमाल करनी है। बिल्कुल खाली गाइड में जोड़ना भी काम करता है और इससे एक जानवर वाली गाइड मिलती है।

## 4. कितने जानवर हैं?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. कौन-कौन से निवास स्थान?

गाइड में बताए गए निवास स्थानों का सेट लौटाइए। कई जानवर एक ही निवास स्थान में रह सकते हैं, और वह निवास स्थान सेट में एक ही बार दिखना चाहिए।

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
