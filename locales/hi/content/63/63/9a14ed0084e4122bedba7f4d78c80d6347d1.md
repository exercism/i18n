# Elm सिंटैक्स की मूल बातें 2

## फंक्शन एक्सपोर्ट करना

पहले कॉन्सेप्ट में हम फंक्शन एक्सपोर्ट करना देख चुके हैं, तो चलिए इसे जल्दी से दोहरा लेते हैं।

Elm में हर फाइल एक मॉड्यूल होती है और उसमें बाकी सारे कोड से पहले एक `module` स्टेटमेंट होना ज़रूरी है।

मॉड्यूल के नाम उसकी फाइल के नाम से मेल खाने चाहिए, यानी मॉड्यूल `Calculator` का फाइल Calculator.elm में होना ज़रूरी है, और मॉड्यूल `Parser.Utils` का फाइल Parser/Utils.elm में।

मॉड्यूल के अंदर बनाई गई कोई भी चीज़ उसी तक सीमित रहती है और `exposing` में लिखे जाने से पहले इस मॉड्यूल के बाहर से इस्तेमाल नहीं की जा सकती।

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## दूसरे मॉड्यूल से फंक्शन इंपोर्ट करना

दूसरे मॉड्यूल में परिभाषित फंक्शन तक पहुँचने का काम इंपोर्ट से होता है।
जब आप किसी मॉड्यूल को इंपोर्ट करते हैं, तो उस मॉड्यूल के अंदर के वे सारे फंक्शन इस्तेमाल के लिए उपलब्ध हो जाते हैं जिन्हें उसने एक्सपोज़ किया था।
लेकिन उन्हें इस्तेमाल करने का तरीका इस पर निर्भर करता है कि मॉड्यूल कैसे इंपोर्ट किया गया है।

क्वालिफाइड इंपोर्ट डिफ़ॉल्ट तरीका है, और ऐसे मॉड्यूल के किसी फंक्शन (जैसे `List` मॉड्यूल का `map` फंक्शन) का इस्तेमाल करने के लिए मॉड्यूल का नाम आगे लगाया जाता है (`List.map`)।

ओपन इंपोर्ट उस मॉड्यूल के एक्सपोज़ किए गए फंक्शन तक सीधी पहुँच देते हैं, बिना नाम आगे लगाए। ये `exposing` कीवर्ड से किए जाते हैं, जो एक्सपोर्ट में इस्तेमाल होने वाले कीवर्ड का ही उल्टा रूप है। आप सारे उपलब्ध फंक्शन एक्सपोज़ कर सकते हैं (`..` के साथ), या सिर्फ कुछ खास फंक्शन (जैसे `map`)।

आप दूसरे मॉड्यूल से टाइप और उनके कंस्ट्रक्टर भी इंपोर्ट कर सकते हैं, लेकिन यह आगे के कॉन्सेप्ट में आता है।

साफ़-साफ़ समझ आए और नामों के टकराव से बचा जाए, इसलिए क्वालिफाइड इंपोर्ट को प्राथमिकता दी जाती है।

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## टाइप एनोटेशन

टाइप एनोटेशन `name : parameter types -> return type` के रूप में लिखे जाते हैं, जिसमें अलग-अलग पैरामीटर के टाइप भी `->` से अलग किए जाते हैं।

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

फंक्शन के पैरामीटर बताने के लिए ब्रैकेट का इस्तेमाल किया जा सकता है (ये पैरामीटर भी इसी सिंटैक्स से लिखे जाते हैं, इसलिए इन ब्रैकेट की ज़रूरत पड़ती है)।

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## संख्याएँ

Elm में दो तरह की संख्याएँ उपलब्ध हैं, जो `Int` और `Float` टाइप से तय होती हैं।
`Int` धनात्मक और ऋणात्मक पूर्णांकों के समूह को दर्शाता है।
`Float` वास्तविक संख्याओं के समूह को दर्शाता है, जो कंप्यूटर की परिशुद्धता तक सीमित होती हैं।
संख्याओं पर बने ऑपरेशन आमतौर पर एक ही टाइप पर काम करते हैं, दोनों को मिलाकर नहीं।
दोनों के बीच बदलने के लिए फंक्शन मौजूद हैं, जैसे `toFloat`, जो `Int` को `Float` में बदलता है, और `round`, `floor`, `ceiling` या `truncate`, जो अलग-अलग तरीकों से एक `Float` को `Int` में बदलते हैं।

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## स्ट्रिंग ऑपरेशन

कोड में शब्दों और वाक्यों को लिखने के लिए Elm में एक मूल `String` टाइप होता है।
स्ट्रिंग लिटरल डबल कोट्स के बीच लिखे जाते हैं, जैसे `"Hello World!"`.
स्ट्रिंग जोड़ने वाला ऑपरेटर `++` और बराबरी जाँचने वाला ऑपरेटर `==` डिफ़ॉल्ट रूप से उपलब्ध हैं।

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

बाकी ज़्यादातर स्ट्रिंग फंक्शन `String` मॉड्यूल में हैं, जिसे इंपोर्ट करना पड़ता है।

https://package.elm-lang.org/packages/elm/core/latest/String
