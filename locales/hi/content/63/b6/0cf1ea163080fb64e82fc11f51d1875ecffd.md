# परिचय

`Result` टाइप की मदद से एक फंक्शन एक ही वैल्यू लौटा सकता है, जो ये सारी बातें बताती है:
- ऑपरेशन सफल रहा या नहीं
- सफल होने पर ऑपरेशन से मिली वैल्यू
- असफल होने पर असफलता का कारण

## उपयोग

`Result` टाइप एक जेनेरिक टाइप है, जिसके भीतर दो और टाइप होते हैं:
- सफल ऑपरेशन पर मिलने वाली वैल्यू का टाइप
- असफल होने पर मिलने वाली एरर का टाइप

`Result` टाइप एक [डिस्क्रिमिनेटेड यूनियन][discriminated-union] भी है, जिसमें ये केस हो सकते हैं:
* `Ok <value>`, जो सफल परिणाम को दर्शाता है
* `Error <reason>`, जो असफलता को दर्शाता है

नीचे दिया गया फंक्शन दिखाता है कि `Result` वैल्यू कैसे बनाई जाती है:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

इस उदाहरण में `Ok` वैल्यू एक स्ट्रिंग है (दिया गया नाम), और `Error` वैल्यू भी एक स्ट्रिंग है (एरर का कारण, इंसान के पढ़ने लायक रूप में)।

## `Result` वैल्यू के अंदर की जानकारी पढ़ना

इस टाइप डेफिनिशन और फंक्शन सिग्नेचर पर ध्यान दीजिए:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

जो कोड `openFile` फंक्शन को कॉल करता है, वह पैटर्न मैचिंग की मदद से सफलता और असफलता दोनों केस संभाल सकता है, जैसा कि इस उदाहरण में दिखाया गया है:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
