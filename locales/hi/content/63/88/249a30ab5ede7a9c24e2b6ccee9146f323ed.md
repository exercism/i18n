# परिचय

`PHP 8.0.0` से उपलब्ध **यूनियन टाइप घोषणाएँ** एक ही टाइप की जगह कई अलग-अलग टाइप की वैल्यू ले सकती हैं। यूनियन टाइप परिभाषित करते समय टाइपों को अलग करने के लिए पाइप (`|`) का इस्तेमाल किया जाता है।

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

स्ट्रिक्ट मोड में, अगर फंक्शन को मिलने वाले पैरामीटर `float` या `int` में से कोई एक न हों, तो PHP एक `TypeError` फेंकता है। नॉन-स्ट्रिक्ट मोड में, अगर उन पैरामीटरों को `float` या `int` में बदला न जा सके, तो एक टाइप एरर फेंकी जाती है।

इसी तरह, अगर फंक्शन घोषित टाइपों में से कोई एक टाइप नहीं लौटाता, तो PHP रनटाइम पर एक `TypeError` फेंकता है।
