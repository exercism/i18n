# परिचय

## ओपेक टाइप

Gleam में ओपेक टाइप एक तरह के कस्टम टाइप होते हैं। इन टाइप की वैल्यू सिर्फ वही मॉड्यूल बना सकता है या उनसे पैटर्न मैच कर सकता है, जो उस टाइप को परिभाषित करता है। यह उन टाइप को बनाने में काम आता है जिनका इस्तेमाल सिर्फ एक खास तरीके से होना चाहिए।

ओपेक टाइप `opaque` कीवर्ड से परिभाषित किए जाते हैं।

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

`PositiveInt` टाइप ऐसी जगहों पर इस्तेमाल किया जाता है जहाँ एक पूर्णांक चाहिए, लेकिन उसका शून्य या उससे बड़ा होना ज़रूरी है। Gleam का साधारण `Int` यहाँ काम नहीं आ सकता, क्योंकि वह ऋणात्मक भी हो सकता है।

जो मॉड्यूल इस टाइप को परिभाषित करता है, वह अंदर रखी पूर्णांक वैल्यू निकालने के लिए एक फंक्शन बना सकता है, और `PositiveInt` टाइप बनाने के लिए भी एक फंक्शन, जो वैल्यू धनात्मक न होने पर एरर लौटाता है।

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

इस API की मदद से दूसरे मॉड्यूल ऋणात्मक वैल्यू वाला `PositiveInt` नहीं बना सकते। इसलिए जो भी फंक्शन `PositiveInt` लेता है, वह निश्चित रह सकता है कि वैल्यू धनात्मक है।
