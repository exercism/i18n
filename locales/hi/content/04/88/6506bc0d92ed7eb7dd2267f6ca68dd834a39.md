# Instructions

इस अभ्यास में आप अपने इलाके के आर्केड हॉल के सबसे लोकप्रिय खेल के हाई स्कोर का हिसाब रखने का तरीका बनाएँगे।

## 1. एक नया हाई स्कोर मैप बनाइए

नया हाई स्कोर मैप बनाने के लिए `HighScore.new/0` फंक्शन बनाइए, जो कोई आर्गुमेंट नहीं लेता और हाई स्कोर का एक नया, खाली मैप लौटाता है।

```elixir
HighScore.new()
# => %{}
```

## 2. हाई स्कोर मैप में खिलाड़ी जोड़िए

हाई स्कोर मैप में कोई खिलाड़ी जोड़ने के लिए `HighScore.add_player/3` बनाइए, जो एक ऐसा फंक्शन है जो 3 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर का मैप है।
- दूसरा आर्गुमेंट खिलाड़ी का नाम है, जो एक स्ट्रिंग के रूप में दिया जाता है।
- तीसरा आर्गुमेंट स्कोर है, जो एक पूर्णांक के रूप में दिया जाता है। यह आर्गुमेंट वैकल्पिक है, इसलिए तीसरे आर्गुमेंट को डिफॉल्ट वैल्यू 0 के साथ बनाइए।

डिफॉल्ट शुरुआती स्कोर को एक मॉड्यूल एट्रिब्यूट में रखिए। इसकी ज़रूरत आगे फिर पड़ेगी।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. स्कोर मैप से खिलाड़ी हटाइए

हाई स्कोर मैप से किसी खिलाड़ी को हटाने के लिए `HighScore.remove_player/2` बनाइए, जो 2 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर का मैप है।
- दूसरा आर्गुमेंट खिलाड़ी का नाम है, जो एक स्ट्रिंग के रूप में दिया जाता है।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. किसी खिलाड़ी का स्कोर रीसेट कीजिए

किसी खिलाड़ी का स्कोर रीसेट करने के लिए `HighScore.reset_score/2` बनाइए, जो 2 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर का मैप है।
- दूसरा आर्गुमेंट खिलाड़ी का नाम है, जो एक स्ट्रिंग के रूप में दिया जाता है और जिसका स्कोर आप रीसेट करना चाहते हैं।

अगर खिलाड़ी का कोई स्कोर न हो, तब भी यह फंक्शन काम करना चाहिए।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. किसी खिलाड़ी का स्कोर अपडेट कीजिए

किसी खिलाड़ी के स्कोर को पिछले स्कोर में जोड़कर अपडेट करने के लिए `HighScore.update_score/3` बनाइए, जो 3 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर का मैप है।
- दूसरा आर्गुमेंट खिलाड़ी का नाम है, जो एक स्ट्रिंग के रूप में दिया जाता है और जिसका स्कोर आप अपडेट करना चाहते हैं।
- तीसरा आर्गुमेंट वह स्कोर है जिसे आप संग्रहीत हाई स्कोर में **जोड़ना** चाहते हैं।

अगर खिलाड़ी का कोई पिछला स्कोर न हो, तब भी यह फंक्शन काम करना चाहिए। ऐसी स्थिति में मान लीजिए कि पिछला स्कोर 0 है।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. खिलाड़ियों का ऐरे पाइए

खिलाड़ियों का ऐरे पाने के लिए `HighScore.get_players/1` बनाइए, जो 1 आर्गुमेंट लेता है:

- पहला आर्गुमेंट स्कोर का मैप है।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
