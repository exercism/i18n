# डमी हेडर

## फंक्शन की लाइब्रेरी

यह पहला ऐसा अभ्यास है जिसमें हम जो हल लिख रहे हैं, वह कोई "main" स्क्रिप्ट नहीं है। हम एक लाइब्रेरी लिख रहे हैं, जिसे दूसरी स्क्रिप्ट में "source" किया जाएगा, और वे स्क्रिप्ट हमारे फंक्शन को कॉल करेंगी।

### Bash नेमरेफ

इस अभ्यास में `nameref` वेरिएबल का उपयोग करना ज़रूरी है। इसके लिए bash का कम से कम वर्शन 4.0 चाहिए। अगर आप MacOS पर डिफॉल्ट bash इस्तेमाल कर रहे हैं, तो आपको कोई दूसरा वर्शन इंस्टॉल करना होगा: देखिए [Bash इंस्टॉल करना](https://exercism.io/tracks/bash/installation)

नेमरेफ की मदद से हम किसी वेरिएबल को किसी फंक्शन को _रेफरेंस के ज़रिए_ भेज सकते हैं। इस तरह वह वेरिएबल फंक्शन के अंदर बदला जा सकता है, और बदली हुई वैल्यू उस स्कोप में भी उपलब्ध रहती है जहाँ से फंक्शन कॉल किया गया था। यहाँ एक उदाहरण है:
```bash
prependElements() {
    local -n __array=$1
    shift
    __array=( "$@" "${__array[@]}" )
}

my_array=( a b c )
echo "before: ${my_array[*]}"    # => before: a b c

prependElements my_array d e f
echo "after: ${my_array[*]}"     # => after: d e f a b c
```
