# परिचय

## तुलना के ऑपरेटर

R में ऐसे ऑपरेटर हैं जो कई दूसरी भाषाओं में भी मिलते हैं:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## शर्त के अनुसार चुनाव

if-else का मूल रूप यह है:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

इस उदाहरण में बूलियन के चारों ओर गोल ब्रैकेट `()` और बॉडी के चारों ओर घुंघराले ब्रैकेट `{}`, दोनों लगाना ज़रूरी है।

एक साधारण `if` स्टेटमेंट को छोटा किया जा सकता है:

```R
if (x == 0) return("success")
```
