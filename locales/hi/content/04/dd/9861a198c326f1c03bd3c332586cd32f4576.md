# संख्याएँ

`INT` में एक पूर्ण संख्या रखी जाती है। इस Sather में यह ठीक 32 बिट का होता है, इसलिए इसमें -2147483648 से 2147483647 तक की संख्याएँ आती हैं।

```sather
   goals : INT is
      return 42;
   end;
```

## आर्गुमेंट

कोई रूटीन ब्रैकेट में आर्गुमेंट लेता है, और हर आर्गुमेंट का एक टाइप होता है:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

जिन आर्गुमेंट का टाइप एक ही हो, उन्हें एक ही घोषणा में लिखा जा सकता है, और आम तौर पर यही तरीका अपनाया जाता है:

```sather
   total(first, second : INT) : INT is
```

## अंकगणित

| ऑपरेटर | अर्थ |
| --- | --- |
| `+` | जोड़ना |
| `-` | घटाना, और ऋणात्मक बनाना |
| `*` | गुणा करना |
| `/` | भाग देना, और शेष छोड़ देना |
| `%` | उस भाग का शेष |

दो `INT` के बीच `/` कभी भिन्न नहीं बनाता:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

अगर आपको भिन्न चाहिए तो `FLTD` की ज़रूरत पड़ेगी, जिससे हम आगे मिलेंगे।

गुणा और भाग की प्राथमिकता जोड़ और घटाव से ज़्यादा होती है, ठीक वैसे ही जैसे आम अंकगणित में। जब आपको कुछ और चाहिए हो, तब ब्रैकेट समूह बना देते हैं:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## INT पर उपयोगी रूटीन

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

एक बार जब आप स्ट्रिंग सीख लेते हैं, तो `.str` की मदद से कोई संख्या वाक्य का हिस्सा बन जाती है।
