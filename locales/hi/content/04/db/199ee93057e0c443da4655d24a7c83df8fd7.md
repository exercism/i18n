# परिचय

## समानता

Elm में यह जाँचा जा सकता है कि दो टाइप "एक जैसे" हैं या नहीं, और इसके लिए [समानता ऑपरेटर][equality-operator] `(==)` इस्तेमाल किया जाता है।
असमानता ऑपरेटर `(/=)` है (कई भाषाओं की तरह `!=` *नहीं*)।

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

जिन दो वैल्यू की तुलना हो रही है, उन दोनों का टाइप एक ही होना चाहिए।
समानता ऑपरेटर लिटरल, टपल, रिकॉर्ड और कस्टम टाइप पर काम करता है।
यह ऑपरेटर संरचनात्मक समानता की जाँच करता है। इसका मतलब है कि बराबर वैल्यू का कंटेंट और गहरी संरचना भी बराबर होती है, चाहे टाइप एनोटेशन कुछ भी हो या वे मेमोरी में कहाँ मौजूद हों।

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

ध्यान दीजिए कि आपको फंक्शन की तुलना *कभी नहीं* करनी चाहिए, क्योंकि ऐसा करने पर प्रोग्राम रनटाइम पर क्रैश हो जाएगा।
इस सीमा के बारे में अधिक जानकारी [यहाँ][equality-operator] है।

## तुलनाएँ

[तुलना ऑपरेटर][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` और फंक्शन `min`, `max`, `compare` `comparable` टाइप पर काम करते हैं।
`comparable` एक विशेष टाइप है जो उन सभी बिल्ट-इन टाइप को एक साथ रखता है जिनकी तुलना हो सकती है: संख्याएँ, अक्षर, स्ट्रिंग, comparable चीज़ों के ऐरे और comparable चीज़ों के टपल।
अक्षरों की तुलना उनके [यूनिकोड कोडपॉइंट][unicode-codepoint] के आधार पर की जाती है।

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

अनुक्रम जैसे टाइप (स्ट्रिंग, ऐरे और टपल) की तुलना [शब्दकोशीय क्रम][lexicographic-order] में की जाती है।
संक्षेप में, अनुक्रम के एलिमेंट की एक-एक करके जोड़ी बनाकर तुलना की जाती है, जब तक कि कोई एलिमेंट छोटा न मिल जाए या अनुक्रम समाप्त न हो जाए।

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

रिकॉर्ड या कस्टम टाइप जैसे अन्य टाइप की वैल्यू की सीधे तुलना नहीं की जा सकती।

कुछ बिल्ट-इन टाइप के लिए यह ज़रूरी है कि उनका कंटेंट `comparable` हो, जैसे `Set` या `Dict` की कुंजियाँ, क्योंकि उनकी संरचना भीतरी क्रम पर निर्भर करती है।
इसका मतलब है कि कस्टम टाइप को `Set` में संग्रहीत नहीं किया जा सकता, हालाँकि समुदाय के पास इसके विकल्प मौजूद हैं: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] और अन्य।

`comparable` वैल्यू के ऐरे को `List.sort` से क्रमबद्ध किया जा सकता है, और ऐसी वैल्यू के ऐरे जिन्हें comparable वैल्यू में बदला जा सकता है, `List.sortBy` से क्रमबद्ध किए जा सकते हैं।
अगर आपको किसी चीज़ को एक से अधिक स्तरों पर क्रमबद्ध करना है (पहले एक प्रॉपर्टी के आधार पर, और बराबर होने पर दूसरी के आधार पर), तो `List.sortBy` के साथ टपल या ऐरे इस्तेमाल किए जा सकते हैं ([अन्य विकल्पों][sort-by] के साथ-साथ), क्योंकि टपल और ऐरे शब्दकोशीय क्रम में क्रमबद्ध होते हैं।


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

फंक्शन `compare` दो `comparable` वैल्यू लेता है और एक `Order` लौटाता है।
`Order` एक ऐसा टाइप है जो एक ही काम में बताता है कि कोई वैल्यू दूसरी से बड़ी (`GT`), बराबर (`EQ`) या छोटी (`LT`) है।

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

किसी भी टाइप के लिए तुलना करने वाले फंक्शन बनाए जा सकते हैं, और उनका उपयोग किया जा सकता है, उदाहरण के लिए `List.sortWith` से क्रमबद्ध करने के लिए:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
