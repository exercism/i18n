# دستورالعمل‌ها

در این تمرین کمی بیشتر روی خودروهای کنترل از راه دور کار می‌کنید.

یک خودروی آزمایشی ساخته شده است و پیست آزمایش باید طوری تغییر کند که بتواند هم مدل‌های تولیدی و هم مدل‌های آزمایشی را پشتیبانی کند.
هر دو نوع خودرو قبلاً ساخته شده‌اند و باید راهی پیدا کنید که در پیست آزمایش با هر دوی آن‌ها کار کنید.

علاوه بر این، خودروهای تولیدی کم‌کم موفقیت‌هایی به دست می‌آورند.
رئیس تیم مشتاق است با انتشار رتبه‌بندی خودروهای تولیدی، روحیه‌ی رقابتی را حفظ کند.

## 1. پیاده‌سازی «رابط»

لطفاً دو متد به رابط `RemoteControlCar` اضافه کنید:

- `drive()` که چیزی برنمی‌گرداند،
- و `getDistanceTravelled()` که یک `int` برمی‌گرداند.

سپس کاری کنید که `ProductionRemoteControlCar` و `ExperimentalRemoteControlCar` رابط `RemoteControlCar` را پیاده‌سازی کنند.
این کار شامل پیاده‌سازی همه‌ی متدهایی است که رابط نیاز دارد.

## 2. رانندگی

هر بار فراخوانی `.drive()` باید باعث شود خودرو مسافت مشخصی را طی کند:

- یک `ProductionRemoteControlCar` به اندازه‌ی ۱۰ واحد حرکت می‌کند،
- یک `ExperimentalRemoteControlCar` به اندازه‌ی ۲۰ واحد حرکت می‌کند.

متد `.getDistanceTravelled()` باید تعداد واحدهایی را برگرداند که خودرو در طول عمر خود طی کرده است.

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. مسابقه

متد `TestTrack.race(RemoteControlCar car)` را پیاده‌سازی کنید که در آن `car`ها `drive()` می‌کنند.

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. امکان مرتب‌سازی خودروهای تولیدی

لطفاً رابط `Comparable<T>` را در کلاس `ProductionRemoteControlCar` پیاده‌سازی کنید.
ترتیب مرتب‌سازی پیش‌فرض خودروها باید نزولی بر اساس تعداد پیروزی‌ها باشد.

متد ایستا `TestTrack.getRankedCars()` را پیاده‌سازی کنید تا خودروهای ورودی را به ترتیب نزولی تعداد پیروزی‌ها برگرداند.

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
