# مقدمه

## chars

نوع اولیه‌ی `char` در جاوا نمایشی ۱۶ بیتی از یک کاراکتر است.
چندین `char` می‌توانند یک رشته را تشکیل دهند، مانند `"word"`، یا می‌توان `char`ها را به‌طور مستقل پردازش کرد.
یک مقدار ثابت `char` بین گیومه‌های تک قرار می‌گیرد (مثلاً `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## به دست آوردن `char`های یک `String`

متد `String.toCharArray` کاراکترهای یک `String` را به‌صورت یک آرایه برمی‌گرداند.
همان‌طور که در مبحث آرایه اشاره شد، می‌توانید برای پیمایش آرایه از یک حلقه‌ی `for` استفاده کنید.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## کلاس `Character`

متدهای کتابخانه‌ای توکار زیادی برای بررسی و دستکاری `char`ها وجود دارد.
این متدها را می‌توان به‌صورت متدهای ایستای کلاس `java.lang.Character` یافت.
در ادامه چند نمونه می‌آید:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## افزودن یک `char` به یک `String`

از عملگر `+` می‌توان برای افزودن یک `char` به یک `String` استفاده کرد.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
مراقب باشید که برای به هم چسباندن دو `char` و ساختن یک `String` از `+` استفاده _نکنید_!
جمع کردن دو `char` به این شکل یک `int` به دست می‌دهد، _نه_ یک `String`!
برای مثال:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

این به این دلیل است که جاوا `char` را به `int` ارتقا می‌دهد (به بخش [4.2 Primitive Types and Values ][jls-primitives] از [Java Language Specification][jls-main] مراجعه کنید).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

اما وقتی کاراکترهای زیادی برای افزودن وجود دارد، استفاده از یک `StringBuilder` می‌تواند کارآمدتر باشد:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
