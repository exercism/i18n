# کلاس دارای وضعیت

هر کلاسی که تا اینجا دیدهاید، جعبهای از روالها بوده است. هر کدام آرگومانهایش را می‌گرفت، پاسخی به دست می‌آورد و بعد همه چیز را فراموش می‌کرد.

کلاس می‌تواند به‌جای این، اطلاعات را به خاطر بسپارد. تخته امتیاز ناچار است چنین باشد: امتیاز اکنون به همه‌ی گل‌هایی بستگی دارد که از شروع بازی زده شده‌اند.

## خصیصه

`attr` به کلاس این امکان را می‌دهد که مقداری را به خاطر بسپارد.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

هر `attr` به روالی تبدیل می‌شود که مقدار را می‌خواند، و به روالی که آن را تغییر می‌دهد:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

خصیصه‌های هم‌نوع می‌توانند یک اعلان مشترک داشته باشند، همان‌طور که آرگومان‌ها می‌توانند:

```sather
   attr home_score, away_score : INT;
```

## شیء

کلاسی که خصیصه دارد، الگویی برای ساختن **شیء** است. هر شیء نسخه‌های خودش از خصیصه‌ها را دارد، پس دو تخته امتیاز، دو امتیاز جدا نگه می‌دارند.

`new` یک شیء می‌سازد. این کار درون روالی به اسم `create` انجام می‌شود که شیء را پر می‌کند و برمی‌گرداند:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` یعنی «همین کلاس». اگر آنجا `SCOREBOARD` بنویسید، همین را می‌گوید، اما اگر اسم کلاس عوض شود، `SAME` همچنان کار می‌کند.

## ساختن یک شیء

`#` روال `create` را فراخوانی می‌کند:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

شما از `rehearsal-script` به این سو از `#` استفاده کرده‌اید. `#FSTR` دقیقاً همین است.

## روال‌هایی که شیء را تغییر می‌دهند

درون کلاس، خصیصه را با اسمش به کار می‌برید، بدون اینکه شیئی جلوی آن باشد. منظور، شیئی است که روال روی آن فراخوانی شده است.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` هیچ نوع بازگشتی اعلان نمی‌کند، چون جوابی نمی‌دهد. در عوض، شیء را تغییر می‌دهد. آن را به شکل یک دستور فراخوانی کنید:

```sather
   board.home_goal;
```

## خصیصه‌ها در آغاز خالی‌اند

خصیصه‌ای که کسی مقدارش را تنظیم نکرده باشد، برای `INT` مقدار صفر، برای `BOOL` مقدار `false` و برای رشته یا شیء مقدار تهی دارد. پس تخته امتیاز تازه، بدون اینکه کسی چیزی بگوید، ۰ به ۰ را نشان می‌دهد.
