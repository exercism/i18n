# دستورالعمل‌ها

این تمرین به تجزیه‌ی فایل‌های لاگ می‌پردازد.

پس از یک بازبینی امنیتی اخیر، از شما خواسته شده است که فایل‌های لاگ بایگانی‌شده‌ی سازمان را پاک‌سازی کنید.

همه‌ی رشته‌هایی که به متدها داده می‌شوند تضمین شده است که `null` نباشند و فاصله‌ی ابتدایی و انتهایی نداشته باشند.

## 1. شناسایی خطوط لاگ مخدوش

باید تصوری داشته باشید از این‌که چند خط لاگ در بایگانی‌تان با استانداردهای فعلی مطابقت ندارند. فکر می‌کنید یک آزمون ساده نشان می‌دهد که آیا یک خط لاگ معتبر است یا نه. برای این‌که خطی معتبر به حساب بیاید، باید با یکی از رشته‌های زیر شروع شود:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

متد `LogParser.IsValidLine()` را پیاده‌سازی کنید تا اگر رشته‌ای معتبر نیست `false` برگرداند و در غیر این صورت `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. تقسیم خط لاگ

تیم تازه‌ای به سازمان پیوسته است و می‌بینید که فایل‌های لاگشان از یک جداکننده‌ی عجیب برای «فیلدها» استفاده می‌کنند. آن‌ها به‌جای چیزی معقول مانند دونقطه `:`، از رشته‌ای مانند `<--->` یا `<=>` استفاده می‌کنند (چون قشنگ‌تر است)؛ در واقع هر رشته‌ای که اولین کاراکترش `<` و آخرین کاراکترش `>` باشد و در میانشان هر ترکیبی از کاراکترهای `^`، `*`، `=` و `-` قرار بگیرد.

متد `LogParser.SplitLogLine()` را پیاده‌سازی کنید که یک خط می‌گیرد و آرایه‌ای از رشته‌ها برمی‌گرداند که هر کدام یک فیلد را در خود دارد.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. شمارش خطوطی که گذرواژه‌ی نقل‌قول‌شده دارند

تیم باید از گذرواژه‌هایی که در متن نقل‌قول‌شده ظاهر می‌شوند مطلع شود تا بتوان آن‌ها را به‌صورت دستی بررسی کرد.

متد `LogParser.CountQuotedPasswords()` را پیاده‌سازی کنید تا تصویری از مقیاس احتمالی این بررسی دستی به دست آید.

خطوط لاگی را شناسایی کنید که در آن‌ها رشته‌ی تحت‌اللفظی `password`، که می‌تواند با هر ترکیبی از حروف بزرگ یا کوچک باشد، میان علامت‌های نقل‌قول قرار گرفته است.
باید احتمال وجود محتوای اضافی میان علامت‌های نقل‌قول، پیش و پس از `password`، را هم در نظر بگیرید.

خطوطی که به این رویه داده می‌شوند ممکن است طبق آنچه در وظیفه‌ی ۱ تعریف شد معتبر باشند یا نباشند. ما آن‌ها را به یک شکل پردازش می‌کنیم، چه معتبر باشند و چه نباشند.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. حذف باقی‌مانده‌ها از لاگ

متوجه شده‌اید که برخی پردازش‌های بالادستی لاگ‌ها، متن `end-of-line` را که پس از آن یک شماره‌ی خط می‌آید (بدون فاصله‌ی میانشان) در سراسر لاگ‌ها پخش کرده است.

متد `LogParser.RemoveEndOfLineText()` را پیاده‌سازی کنید تا رشته‌ای بگیرد و متن `end-of-line` را حذف کند و رشته‌ای «پاک» برگرداند.

خطوطی که متن `end-of-line` ندارند باید بدون تغییر برگردانده شوند.

فقط رشته‌ی پایان خط را حذف کنید. سعی نکنید فاصله‌های سفید را تنظیم کنید.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. فهرست کردن خطوطی با گذرواژه‌های بسیار ضعیف تا مقصران مجازات شوند

پیش از پاک کردن گذرواژه‌ها از فایل، باید هر موردی را که گذرواژه‌اش با متن `password` شروع می‌شود فهرست کنیم.

متد `LogParser.ListLinesWithPasswords()` را پیاده‌سازی کنید تا گذرواژه‌ی خاطی را چاپ کند و پس از آن خط کامل را.

خطوطی که گذرواژه‌ی نقل‌قول‌شده دارند پیش‌تر حذف شده‌اند و شما خطوط را بدون توجه به این‌که معتبر باشند یا نه پردازش می‌کنید (طبق وظیفه‌ی ۱).

خطوطی که گذرواژه‌ی خاطی دارند باید با پیشوند `<password>: ` برگردانده شوند.

خطوطی که گذرواژه‌ی خاطی ندارند باید با پیشوند `--------: ` برگردانده شوند.

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
