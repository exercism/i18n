# راهنمایی‌ها

## کلی

- شاید داشتن فهرستی از همه‌ی [عملگرهای حسابی][arithmetic-operations] در PHP برایتان مفید باشد.

## 1. نسبت خمیر

- می‌توانید این کار را با عملگرهای پایه‌ی حسابی برای جمع و ضرب حل کنید.

## 2. کمی سس

- برای اینکه تعداد قوطی‌ها عدد صحیح باشد، باید به سمت بالا گرد کنید.
- PHP [توابع عددی][numeric-functions] را ارائه می‌دهد که می‌توانند به شما کمک کنند.

## 3. کمی پنیر، لطفاً

- می‌توانید یک عدد را با استفاده از [عملگر توان‌رسانی][arithmetic-operations] به توان سه برسانید.
- برای اینکه تعداد پیتزاها عدد صحیح باشد، باید به سمت پایین گرد کنید.
- PHP [توابع عددی][numeric-functions] را ارائه می‌دهد که می‌توانند به شما کمک کنند.
- PHP یک [ثابت داخلی][pi-constant] برای عدد پی (π) دارد.

## 4. سهم عادلانه

- برای به دست آوردن باقیمانده‌ی تقسیم، از [عملگر باقیمانده][arithmetic-operations] (`%`) استفاده کنید.

[arithmetic-operations]: https://www.php.net/manual/en/language.operators.arithmetic.php
[pi-constant]: https://www.php.net/manual/en/function.pi.php
[numeric-functions]: https://www.php.net/manual/en/ref.math.php
