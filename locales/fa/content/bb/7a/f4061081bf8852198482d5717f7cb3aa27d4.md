# دستورالعمل‌ها

تیم طراحی شما برای بخشی از کارهای چیدمانش از CSS transforms به Factor روی آورده است. برای اینکه بقیه‌ی اعضای تیم راضی بمانند، شما تبدیل‌های کوچک و قابل استفاده‌ی مجددی به شکل «quotation» می‌سازید که یک نقطه‌ی دوبعدی می‌گیرند و یک نقطه‌ی دوبعدی برمی‌گردانند.

نقطه یک آرایه‌ی دو عنصری به شکل `{ x y }` است.

## 1. مختصات را انتقال دهید

تابع `translate-2d` را طوری تعریف کنید که دو مقدار `dx` و `dy` را از پشته بردارد و quotationی برگرداند که نقطه را به اندازه‌ی `(dx, dy)` انتقال می‌دهد.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. مقیاس مختصات را تغییر دهید

تابع `scale-2d` را به همین شکل تعریف کنید، با این تفاوت که quotation برگشتی نقطه را به اندازه‌ی `(sx, sy)` مقیاس می‌کند.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. دو تبدیل را با هم ترکیب کنید

تابع `compose-transformations` را تعریف کنید تا دو quotation تبدیل `f` و `g` بگیرد و یک quotation واحد برگرداند که اول `f` و سپس `g` را اعمال می‌کند.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. یک تبدیل را اعمال کنید

تابع `apply-transformation` را تعریف کنید تا یک نقطه و یک quotation تبدیل را از پشته بردارد و نقطه‌ی تبدیل‌شده را برگرداند.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. تبدیل چند نقطه به‌طور هم‌زمان

تابع `transform-points` را تعریف کنید تا یک آرایه از نقطه‌ها و یک quotation تبدیل بگیرد و آرایه‌ی نقطه‌های تبدیل‌شده را برگرداند.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
