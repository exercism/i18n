# درباره

انواع C# را می‌توان در محدوده‌ی یک کلاس یا ساختار تعریف کرد. «نوع دربرگیرنده» نوعی «فضای نام» فراهم می‌کند. دسترسی به نوع از طریق نوع دربرگیرنده و با نگارش نقطه انجام می‌شود.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## سطوح دسترسی

سطوح دسترسی را می‌توان به «انواع داخلی» اعمال کرد. برای مثال، اگر یک کلاس `private` باشد، از بیرون محدوده‌ی نوع دربرگیرنده دیده نمی‌شود و طبیعتاً نمونه‌ها هم خارج از آن محدوده دیده یا استفاده نمی‌شوند.

اعضای `private` کلاس بیرونی برای همه‌ی اعضای کلاس داخلی در محدوده هستند، اما فقط اعضای غیر `private` کلاس داخلی برای اعضای کلاس بیرونی در محدوده قرار دارند. برای دسترسی به اعضای کلاس بیرونی، باید یک نمونه از کلاس بیرونی به کلاس داخلی داده شود.

این را می‌توان در مثال زیر دید:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## جلوگیری از نمونه‌سازی مستقل

الگویی وجود دارد که مانع می‌شود نوعی که قابل نمونه‌سازی است، خارج از نوع دربرگیرنده ایجاد شود. شما یک «رابط» `public` را در معرض دید قرار می‌دهید اما کلاس پیاده‌ساز را `private` نگه می‌دارید.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## نکته برای توسعه‌دهندگان Java

کلاس‌های تودرتوی C# ترکیبی از کلاس‌های تودرتوی ایستا و کلاس‌های داخلی Java هستند. در C# اعضای `private` کلاس دربرگیرنده برای اعضای کلاس تودرتو در محدوده هستند، اما هیچ نحوه‌ی نگارش ویژه‌ای برای نمونه‌سازی آن‌ها و پیوند دادنشان به یک نمونه از کلاس دربرگیرنده وجود ندارد. باید از گونه‌ای از الگوی نشان‌داده‌شده در مثال‌های بالا استفاده کنید.

C# کلاس‌های تودرتوی ایستا هم دارد، اما این‌ها صرفاً کلاس‌های محصورشده‌ای با رفتار ایستا هستند.
