# دستورالعمل‌ها

توری روزنامه‌نگار حوزه‌ی اقلیم است و می‌خواهد مقاله‌ای درباره‌ی آب‌وهوای شهرهای مختلف بنویسد. او داده‌هایی درباره‌ی آب‌وهوای شهرهای مختلف دارد و می‌خواهد آن‌ها را بر اساس دمایشان رتبه‌بندی کند، اما بعضی از دماها بر حسب فارنهایت و بعضی بر حسب سلسیوس هستند. او به کمک شما نیاز دارد تا دماها را به واحد یکسان تبدیل کنید و آن‌ها را رتبه‌بندی کنید.

## 1. تبدیل فارنهایت به سلسیوس

تابع `fahrenheit_to_celsius` را تعریف کنید که دمایی بر حسب فارنهایت را به عنوان آرگومان می‌گیرد و همان دما را بر حسب سلسیوس برمی‌گرداند.

برای تبدیل فارنهایت به سلسیوس، ۳۲ را از مقدار فارنهایت کم کنید و سپس نتیجه را بر ۱٫۸ تقسیم کنید.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. مقایسه‌ی دو دما

تابع `compare_temperature` را تعریف کنید که دو دما می‌گیرد و یک مقدار `Order` برمی‌گرداند که نشان می‌دهد دمای اول کمتر از دمای دوم است، با آن برابر است یا بیشتر از آن است.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. مرتب‌سازی شهرها بر اساس دما

تابع `sort_cities_by_temperature` را تعریف کنید که فهرستی از شهرها می‌گیرد و آن‌ها را از سردترین به گرم‌ترین برمی‌گرداند.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
