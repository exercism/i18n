# درباره

علاوه بر `cond`، الیكسیر ماکروی [`if/2`][getting-started-if] را هم ارائه می‌دهد که وقتی می‌خواهید فقط یک شرط را بررسی کنید مفید است.

[`if/2`][kernel-if] یک شرط و دو گزینه می‌پذیرد. اگر شرط _truthy_ باشد گزینه‌ی اول را برمی‌گرداند و اگر شرط _falsy_ باشد گزینه‌ی دوم را برمی‌گرداند.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

اگر گزینه‌ی دوم داده نشود، `nil` برگردانده می‌شود.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

می‌توان یک عبارت `if` را در یک خط هم نوشت. به کاما بعد از شرط توجه کنید.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

این نحوه‌ی نگارش برای عبارت‌های خیلی کوتاه مفید است، اما اگر عبارت در یک خط جا نشود، باید از آن پرهیز کرد.

## _Truthy_ و _falsy_

در الیكسیر، همه‌ی نوع‌های داده وقتی در «بافت منطقی» (مانند یک عبارت `if`) قرار می‌گیرند، به یک مقدار _truthy_ یا _falsy_ ارزیابی می‌شوند. همه‌ی داده‌ها _truthy_ در نظر گرفته می‌شوند، **به‌جز** `false` و `nil`. به‌ویژه، رشته‌های خالی، عدد صحیح `0` و لیست‌های خالی در الیكسیر همگی _truthy_ در نظر گرفته می‌شوند. از این نظر، [الیكسیر شبیه Ruby است اما با JavaScript، Python یا PHP تفاوت دارد][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and]، [`||/2`][kernel-or] و [`!/1`][kernel-not] عملگرهای منطقی _truthy_ هستند که با هر مقداری کار می‌کنند و مکمل عملگرهای منطقی _سخت‌گیرانه‌ی_ [`and/2`][kernel-boolean-and]، [`or/2`][kernel-boolean-or] و [`not/1`][kernel-boolean-not] هستند.

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
