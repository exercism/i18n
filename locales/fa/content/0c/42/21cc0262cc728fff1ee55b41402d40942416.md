# مقدمه

در Go، یک `struct` دنباله‌ای از عناصر نام‌داری است که _فیلد_ نامیده می‌شوند؛ هر فیلد یک اسم و یک نوع دارد.
اسم یک فیلد باید درون `struct` یکتا باشد.
می‌توان `struct`ها را با _کلاس‌ها_ در پارادایم برنامه‌نویسی شیءگرا مقایسه کرد.

## تعریف یک `struct`

شما با استفاده از کلیدواژه‌های `type` و `struct` یک `struct` جدید می‌سازید و اسم و نوع فیلدها را به‌صراحت تعریف می‌کنید.
برای مثال، در اینجا `struct`ای به نام `Shape` تعریف می‌کنیم که اسم یک شکل و اندازه‌ی آن را نگه می‌دارد:

```go
type Shape struct {
    name string
    size int
}
```

اسم فیلدها در `struct`ها از قرارداد Go پیروی می‌کند: فیلدهایی که اسمشان با حرف کوچک شروع می‌شود، فقط برای کدهای همان پکیج قابل مشاهده‌اند، در حالی که فیلدهایی که اسمشان با حرف بزرگ شروع می‌شود، در پکیج‌های دیگر هم قابل مشاهده‌اند.

## ساختن نمونه‌هایی از یک `struct`

پس از اینکه `struct` را تعریف کردید، باید یک نمونه‌ی جدید بسازید و فیلدها را با اسمشان و به هر ترتیبی که می‌خواهید تعریف کنید:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

برای خواندن یا تغییر فیلدهای یک نمونه، از نشانه‌گذاری `.` استفاده کنید:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

فیلدهایی که مقدار اولیه‌ای به آن‌ها اختصاص داده نشده باشد، مقدار صفر نوعشان را می‌گیرند.
برای مثال:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

می‌توانید نمونه‌ای از یک `struct` را بدون استفاده از اسم فیلدها بسازید، به شرطی که فیلدها را _به ترتیب_ تعریف کنید:

```go
s := Shape {
	"Oval",
	20,
}
```

با این حال، این نحوه‌ی نگارش _کد شکننده_ در نظر گرفته می‌شود، چون با اضافه شدن یک فیلد ممکن است از کار بیفتد، به‌ویژه وقتی فیلد جدید از نوع دیگری باشد.
در مثال زیر یک فیلد اضافه به `Shape` اضافه می‌کنیم:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## توابع «New»

گاهی داشتن توابعی که به ما در ساختن نمونه‌های `struct` کمک می‌کنند، می‌تواند خوب باشد.
طبق قرارداد، این توابع معمولاً `New` نامیده می‌شوند یا اسمشان با `New` شروع می‌شود، اما چون توابعی معمولی‌اند، می‌توانید هر اسمی که می‌خواهید به آن‌ها بدهید.
ممکن است شما را به یاد سازنده‌ها در زبان‌های دیگر بیندازند، اما در Go آن‌ها فقط تابع‌های معمولی هستند.

در مثال زیر، یکی از این توابع `New` برای ساختن نمونه‌ی جدیدی از `Shape` استفاده می‌شود و به‌طور خودکار مقدار پیش‌فرضی برای `size` شکل تعیین می‌کند:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

استفاده از توابع `New` می‌تواند مزایای زیر را داشته باشد:

* اعتبارسنجی مقادیر داده‌شده
* مدیریت مقادیر پیش‌فرض
* چون توابع `New` اغلب در همان پکیجِ `struct`هایی که آن‌ها را مقداردهی اولیه می‌کنند اعلام می‌شوند، می‌توانند حتی فیلدهای خصوصی آن `struct` را هم مقداردهی اولیه کنند

برای عمیق‌تر شدن در این نوع، می‌توانید این منابع را ببینید: [Go by Example: Structs][go-by-example-structs]، [A Tour of Go: Structs][tour-of-go-structs] یا [Structures in Go (structs)][medium-structures-in-go]

## `new` توکار

روش دیگری برای ساختن یک نمونه‌ی جدید از `struct` استفاده از `new` توکار است:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

در این مثال، `new` یک نمونه از `struct`ای به نام `Shape` می‌سازد که همه‌ی مقادیرش به مقدار صفر نوعشان مقداردهی اولیه شده‌اند و اشاره‌گری به آن برمی‌گرداند.

~~~~exercism/note
در بیشتر مواقع، نمونه‌های جدید `struct`ها را نخواهید دید که با `new` توکار ساخته شده باشند.
همیشه استفاده از یک struct literal، یک تابع سفارشی `New` یا هر تابع دیگری که پکیج برای ساختن `struct` در اختیارتان می‌گذارد را ترجیح دهید.
از `new` توکار برای ساختن نمونه‌های جدید `struct` فقط به عنوان آخرین راه‌حل استفاده کنید.
~~~~
