# مقدمه

Swift دستورهای انتقال کنترل را فراهم می‌کند تا جریان اجرای حلقه‌ها و دستورهای `switch` را تغییر دهد.
Swift علاوه بر `return`، شامل `continue`، `break`، «برچسب‌های حلقه» و `fallthrough` هم هست.

## Continue

دستور `continue` به حلقه می‌گوید که اجرای تکرار جاری را متوقف کند و بی‌درنگ تکرار بعدی را آغاز کند.
در حلقه‌ی `while` یا `repeat-while`، مستقیم به بررسی شرط می‌رود.
در حلقه‌ی `for-in`، به عنصر بعدی دنباله پیش می‌رود.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

دستور `break` بی‌درنگ از کل یک حلقه یا دستور `switch` خارج می‌شود.
اجرا از اولین خط کد پس از حلقه یا `switch` ادامه می‌یابد.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## دستورهای برچسب‌دار

در حلقه‌های تودرتو، ممکن است بخواهید `break` یا `continue` روی یک حلقه‌ی بیرونی اثر بگذارد، نه روی درونی‌ترین حلقه.
می‌توانید با قرار دادن اسمی و پس از آن دو نقطه (`labelName:`) در ابتدای حلقه، آن را برچسب‌گذاری کنید.
سپس می‌توانید آن برچسب را به `break` یا `continue` بدهید:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
