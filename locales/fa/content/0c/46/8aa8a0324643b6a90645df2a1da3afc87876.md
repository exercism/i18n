# دستورالعمل‌ها

شما مدیریت یک سینمای اختصاصی را بر عهده دارید.
برای تماشای فیلم، افراد باید بلیت سالانه بخرند و بعد می‌توانند به‌صورت رایگان فیلم ببینند.

سینمای شما سوابق ورود تماشاگران را نگه می‌دارد.
می‌خواهید از این سوابق استفاده کنید تا پیگیری کنید کدام اعضا این ماه از بلیت سالانه‌شان استفاده کرده‌اند.
همچنین می‌خواهید درباره‌ی ترکیب سنی مشتریانتان اطلاعاتی به دست آورید.
متوجه می‌شوید که می‌توانید این هدف‌ها را با کمک مجموعه‌ها به دست آورید.

## مجموعه

یک «مجموعه» نوع داده‌ی کاملی برای ذخیره‌ی این نوع داده است.

مجموعه نوع داده‌ای است که برای ذخیره‌ی مقادیر متمایز و یکتا، بدون ترتیب خاصی، به کار می‌رود.
متمایز و یکتا یعنی یک عنصر یا در مجموعه هست یا نیست؛ برخلاف آرایه، نمی‌تواند چند بار در مجموعه باشد.
مجموعه‌ها معمولاً بدون ترتیب‌اند؛ اگر عناصر یک مجموعه را فهرست کنید، ترتیبی که می‌گیرید ممکن است با ترتیبی که آن‌ها اضافه شده‌اند فرق کند، یا حتی با ترتیبی که در فهرست قبلی گرفتید فرق داشته باشد!

یکی از ویژگی‌های بنیادین مجموعه‌ها، بررسی عضویت است: توانایی بررسی این‌که آیا مجموعه عنصری را در خود دارد یا نه.
بررسی عضویت در تقریباً همه‌ی کاربردهای یک مجموعه نقشی اساسی دارد.

زبان Go نوع داده‌ی مجموعه‌ی از پیش ساخته‌شده‌ای ارائه نمی‌دهد.
رایج است که به جای مجموعه از `map[<type>]struct{}` یا `map[<type>]bool` استفاده شود؛ `map` هم مانند مجموعه امکان افزودن عناصر متمایز و یکتا را فراهم می‌کند و از بررسی عضویت پشتیبانی می‌کند.

## 1. جایی برای ذخیره‌ی اطلاعات شرکت‌کنندگان

برای پیگیری حضور و ترکیب سنی، می‌خواهید از یک مجموعه استفاده کنید.

نمی‌خواهید برای اسم‌ها و سن‌ها مجموعه‌های جداگانه بنویسید؛ در عوض، می‌توانید برای هر دو از یک مجموعه‌ی جنریک استفاده کنید.
یک نوع `Set` را به‌صورت `map[T comparable]struct{}` تعریف کنید تا شرکت‌کنندگان را در آن ذخیره کنید.
تابعی به اسم `NewSet[T comparable]()` بنویسید که یک `Set[T]` خالی برمی‌گرداند.

```go
names := NewSet[string]()
```

## 2. پیگیری شرکت‌کنندگان

حالا آماده‌اید اطلاعات شرکت‌کنندگان را ثبت کنید.

متدی به اسم `Add[T]()` بنویسید که یک عنصر را به مجموعه اضافه می‌کند.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. بررسی شرکت‌کنندگان

حالا که مجموعه‌ای از شرکت‌کنندگان دارید، می‌توانید بررسی کنید که کدام اعضا و کدام گروه‌های سنی حاضر شده‌اند.
متدی به اسم `Contains[T](element)` بنویسید که برمی‌گرداند آیا یک عضو یا یک گروه سنی در `Set` هست یا نه.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. مقایسه‌ی شرکت‌کنندگان

یک ماه دیگر گذشته و شما `Set` تازه‌ای از گروه‌های سنی دارید.
مدیر بازاریابی شما می‌خواهد بداند آیا فیلم‌های جدید این ماه ترکیب سنی حاضران را تغییر داده‌اند یا نه.
متدی به اسم `Equals[T](other)` بنویسید که تعیین می‌کند آیا دو مجموعه عناصر یکسانی دارند یا نه.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
