# مقدمه

ساخت یک نمونه از یک کلاس با فراخوانی «سازنده»ی آن از طریق عملگر `new` انجام می‌شود. سازنده یک متد ویژه درون یک کلاس است که هدفش مقداردهی اولیهی کلاس است. در Haxe، متد سازنده اسم `new()` را دارد.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

سازنده‌ها هم درست مثل متدهای عادی می‌توانند پارامتر داشته باشند. این پارامترها (معمولاً) در فیلدهای خصوصی ذخیره می‌شوند و بعداً به آن‌ها دسترسی پیدا می‌شود.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
