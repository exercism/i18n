# درباره

«بازگشت» روشی برای تکرار کد درون یک تابع است، به این صورت که تابع خودش را فراخوانی می‌کند.
این روش دیگری برای حلقه زدن و تکرار کردن است. مانند حلقه زدن، تابع باید یک عبارت «منطقی» را بررسی کند تا بداند چه زمانی باید پایان یابد.
برخلاف حلقه زدن، بازگشتی که هرگز تمام نمی‌شود، تا بی‌نهایت اجرا نخواهد شد.
مقدارهایی که در هر فراخوانی تابع استفاده می‌شوند، ممکن است هر کدام در قاب مخصوص خود روی «پشته» قرار بگیرند.
اگر تعداد فراخوانی‌های تابع فضای بیشتری از آنچه پشته در اختیار دارد اشغال کند، به خطای سرریز پشته منجر می‌شود.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

این کد این خروجی را چاپ می‌کند:

```
The number is 1
The number is 2
After recursion
```

ممکن است موقعیت‌هایی وجود داشته باشد که وقتی با بازگشت بیان می‌شوند، خواناتر و/یا استدلال درباره‌شان آسان‌تر از زمانی باشد که با حلقه زدن بیان می‌شوند.


## فراخوانی دمی

«فراخوانی دمی» زمانی است که آخرین دستور یک تابع فقط خودش را فراخوانی می‌کند و بس.

فراخوانی دمی شکل خاصی از بازگشت است که ممکن است به کامپایلر اجازه دهد بازگشت را در کد کامپایل‌شده به یک حلقه تبدیل کند.
این کار بهترین حالت هر دو جهان را فراهم می‌کند: خوانایی بازگشت همراه با کارایی یک حلقه.
تبدیل بازگشت به حلقه را `tail call elimination` یا `tail call optimization.` می‌نامند.

وقتی یک فراخوانی دمی به حلقه کامپایل می‌شود، برای هر فراخوانی تابع قاب پشته‌ی جدیدی ساخته نمی‌شود.
به آدرس تابعی که در ابتدا فراخوانی شده بود، مقدارهای به‌روزشده داده می‌شود؛ به این ترتیب در فضای پشته صرفه‌جویی می‌شود و کارایی بهبود می‌یابد.

این مثال یک فراخوانی دمی نیست، چون تابع ۱ را به نتیجه‌ی فراخوانی خودش اضافه می‌کند

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

این کد این خروجی را چاپ می‌کند:

```
The number is 1
The number is 2
j is 3 after recursion
```

برای بازنویسی آن به‌صورت یک فراخوانی دمی، `j` را به پارامتری از `printIncrement` تبدیل کنید

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

ممکن است ببینید استدلال درباره‌ی یک فراخوانی دمی آسان‌تر از فراخوانی بازگشتی‌ای است که فراخوانی دمی نیست.
با این حال، کامپایلرها معمولاً تضمین نمی‌کنند که همه‌ی فراخوانی‌های دمی بهینه‌سازی شوند.
هنگام استفاده از بازگشت، همیشه مهم است که بدانید تعداد تکرارها آن‌قدر زیاد نخواهد شد که پشته سرریز کند.
