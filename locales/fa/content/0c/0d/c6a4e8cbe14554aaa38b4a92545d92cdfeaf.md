# Debug

وقتی یک test شکست می‌خورد، پیامی نمایش داده می‌شود که توضیح می‌دهد چه چیزی اشتباه رفته و ورودی کدام بوده است. همچنین می‌توانید به این نکته تکیه کنید که هر [خروجی کنسول][dotnetperls.com-console-vbnet] هم نمایش داده می‌شود. می‌توانید با این روش در کنسول بنویسید:

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
