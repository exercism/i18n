# امضاهای داده‌شده را تغییر ندهید

همان‌طور که در دستورالعمل‌ها اشاره شده است، نباید امضاهای `makeChest` و `makeTreasureChest` را تغییر دهید.
این امضاها باید دقیقاً به این شکل باقی بمانند:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
