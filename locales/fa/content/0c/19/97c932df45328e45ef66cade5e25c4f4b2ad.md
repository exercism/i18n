Raku یک زبان برنامه‌نویسی فوق‌العاده غنی، انعطاف‌پذیر و قدرتمند است.
این انعطاف‌پذیری به برنامه‌نویسان اجازه می‌دهد کدی گویا و متناسب با سبک خودشان بنویسند.

Raku زبانی بزرگ است و ژرفای فراوانی برای یادگیری، کاوش و آزمایش دارد.
این سرفصل می‌کوشد مبانی لازم را پوشش دهد تا شما کار را شروع کنید.

برنامه‌نویسی شیءگرا در قلب Raku جای دارد، اما شیوه‌های برنامه‌نویسی شیءگرا را بر شما تحمیل نمی‌کند.
به دلیل ماهیت شیءگرای آن، این سرفصل اغلب به [اشیاء، کلاس‌ها و متدها][object-orientation] ارجاع می‌دهد.

## متغیرها

برای اینکه همه‌چیز ساده بماند، در مبانی فقط از [متغیرهای][variables] «اسکالر» استفاده می‌کنیم.

متغیرهای اسکالر [شناسه‌هایی][identifiers] هستند که با نشانه‌ی `$` شروع می‌شوند.

متغیرهای اسکالر تقریباً هر مقداری را می‌توانند در خود نگه دارند و نوع پیش‌فرضشان [`Any`][Any] است.

بیشتر متغیرهایی که استفاده می‌کنید به یک [اعلان][variable-declarator] نیاز دارند.
فعلاً به [`my`][my] و [`constant`][constant] بسنده کنید.

```raku
my $foo;
constant $BAR;
```

## زیرروال‌ها

یک زیرروال با اعلان‌گر [`sub`][sub-declarator] اعلان می‌شود.

پس از اعلان `sub` یک [شناسه][identifiers] اختیاری می‌آید، سپس یک [امضا][signatures] اختیاری و در نهایت یک [بلوک][blocks].

زیرروال‌ها را می‌توان (در کنار موارد دیگر) با افزودن ویژگی [`is export`][exporting] صادر کرد.

یک زیرروال را می‌توان با عملگر [پسوندیِ `( )`][postcircumfix-()] روی شناسه فراخوانی کرد.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## عملگرها

Raku انواع بسیار متنوعی از [عملگرها][operators] دارد.
در تمرین‌های مفهوم مبانی، از چند عملگر ریاضی پایه در Raku مانند `+` و `-` استفاده خواهیم کرد.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

اگر بخواهید، به‌راحتی می‌توانید عملگرهای خودتان را در Raku تعریف کنید.
بیشتر عملگرهای داخلی به‌صورت زیرروال هم در دسترس‌اند.

## بسته‌ها و پودمان‌ها

در Raku چند نوع [بسته][package-declarator] وجود دارد. در مبانی فقط از `module` استفاده می‌کنیم.

برای اینکه یک فایل کامل را به‌عنوان `module` اعلان کنید، پیش از اعلان پودمان `unit` می‌آید.

```raku
unit module Foo;

sub bar () { ... }
```

## کامنت‌ها

Raku [کامنت‌های تک‌خطی][single-line-comments] و [چندخطی/جاسازی‌شده][multi-line-comments] دارد.

کامنت‌های تک‌خطی با `#` شروع می‌شوند و تا پایان خط ادامه می‌یابند.

کامنت‌های چندخطی/جاسازی‌شده با یک هش شروع می‌شوند که پس از آن یک بک‌تیک و یک نویسه‌ی نقطه‌گذاری باز یونیکد می‌آید.
این کامنت‌ها با نویسه‌ی بسته‌ی متناظرشان پایان می‌یابند.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## قواعد سبک

[شناسه‌های][identifiers] متغیر و زیرروال در Raku به سبک `kebab-case` نوشته می‌شوند.
ثابت‌ها به سبک `ALL-CAPS` نوشته می‌شوند.
اسم بسته‌ها به سبک `PascalCase` نوشته می‌شوند.
