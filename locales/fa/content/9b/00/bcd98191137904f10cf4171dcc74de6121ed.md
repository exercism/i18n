# دستورالعمل‌ها

باشگاه شعر محلی فصل تازه‌ای را آغاز می‌کند. شاعران به باشگاه می‌پیوندند و هر بار که دو نفرشان با هم شعری بنویسند، بخشی از یک «حلقه‌ی نوشتن» مشترک می‌شوند. باشگاه می‌خواهد بداند چه کسی حلقه‌اش را با چه کسی شریک است و از شما خواسته شده است واژه‌هایی را بنویسید که این کار را مدیریت می‌کنند.

یک «مجموعه‌ی مجزا» دقیقاً همان چیزی است که به کار می‌آید: هر شاعر یک اتم است و هر حلقه‌ی نوشتن یک گروه.

## 1. باشگاه را باز کنید

`new-club` را تعریف کنید؛ این واژه دنباله‌ای از شاعران می‌گیرد و یک مجموعه‌ی مجزای تازه برمی‌گرداند که هر شاعر در آن ثبت شده است. هر شاعر کار را در حلقه‌ی نوشتن خودش آغاز می‌کند.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. یک همکاری را ثبت کنید

`collaborate` را تعریف کنید؛ این واژه دو شاعر و یک باشگاه می‌گیرد. حلقه‌های نوشتن آن دو شاعر را در هم ادغام می‌کند و باشگاه را برمی‌گرداند، تا همکاری‌ها یکی پس از دیگری ثبت شوند.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. حلقه‌ی یک شاعر را پیدا کنید

`circle-of` را تعریف کنید؛ این واژه یک شاعر و یک باشگاه می‌گیرد و نماینده‌ی حلقه‌ی نوشتن آن شاعر را برمی‌گرداند. دو شاعری که در یک حلقه‌اند همیشه نماینده‌ی یکسانی را گزارش می‌کنند.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. حلقه‌ی مشترک؟

`same-circle?` را تعریف کنید؛ این واژه دو شاعر و یک باشگاه می‌گیرد و اگر هر دو شاعر به یک حلقه‌ی نوشتن تعلق داشته باشند `t` و در غیر این صورت `f` را برمی‌گرداند. به‌جای استفاده از آزمون هم‌ارزی توکار، نماینده‌های شاعران را با هم مقایسه کنید.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
