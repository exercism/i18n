# مقدمه

Go انواع عددی پایه‌ای دارد که می‌توانند مجموعه‌هایی از مقادیر صحیح یا اعشاری را نمایش دهند.

این مفهوم بر دو نوع عدد تمرکز می‌کند:

- `int`: مثلاً `0`، `255`، `2147483647`.
   یک عدد صحیح علامت‌دار که اندازه‌ی آن حداقل ۳۲ بیت است (بازه‌ی مقدار: از -۲۱۴۷۴۸۳۶۴۸ تا ۲۱۴۷۴۸۳۶۴۷).
   اما این به معماری سیستم بستگی دارد.
   بیشتر رایانه‌های امروزی ۶۴ بیتی هستند، بنابراین `int` اندازه‌ی ۶۴ بیت خواهد داشت (بازه‌ی مقدار: از -۹۲۲۳۳۷۲۰۳۶۸۵۴۷۷۵۸۰۸ تا ۹۲۲۳۳۷۲۰۳۶۸۵۴۷۷۵۸۰۷).

- `float64`: مثلاً `0.0`، `3.14`.
   شامل مجموعه‌ی همه‌ی اعداد اعشاری ۶۴ بیتی است.

Go از مجموعه‌ی استاندارد عملگرهای حسابی `+`، `-`، `*`، `/` و `%` پشتیبانی می‌کند (باقیمانده، نه پیمانه).

در Go، انتساب یک مقدار بین انواع مختلف نیازمند تبدیل صریح است.
برای مثال، برای تبدیل یک `int` به `float64` باید کار زیر را انجام دهید:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
