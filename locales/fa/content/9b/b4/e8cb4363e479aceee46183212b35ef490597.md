# درباره

## عملگرهای حسابی

JavaScript شش عملگر مختلف در اختیارتان می‌گذارد تا عملیات حسابی پایه را روی اعداد انجام دهید.

- `+`: عملگر جمع برای یافتن مجموع اعداد به کار می‌رود.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: عملگر تفریق برای یافتن تفاضل دو عدد به کار می‌رود

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: عملگر ضرب برای یافتن حاصل‌ضرب دو عدد به کار می‌رود

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: عملگر تقسیم برای تقسیم دو عدد به کار می‌رود.
  چون اعداد JavaScript همیشه اعشاری‌اند، تقسیم صحیح وجود ندارد.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: عملگر باقی‌مانده برای یافتن باقی‌مانده‌ی یک تقسیم به کار می‌رود.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: عملگر توان برای رساندن یک عدد به توان به کار می‌رود.
  معادل استفاده از [`Math.pow()`][mdn-math-pow] است

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## ترتیب عملیات

وقتی در یک خط از چند عملگر استفاده می‌کنید، JavaScript از یک ترتیب اولویت پیروی می‌کند، همان‌طور که در [این جدول اولویت][mdn-operator-precedence] نشان داده شده است.
برای ساده کردن ماجرا با توجه به بافت ما، JavaScript از قاعده‌ی PEDMAS (پرانتز، توان، تقسیم/ضرب، جمع/تفریق) استفاده می‌کند، همان قاعده‌ای که در کلاس‌های ریاضی دبستان یاد گرفته‌ایم.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## عملگرهای انتساب کوتاه

عملگرهای انتساب کوتاه، روش کوتاه‌تری برای نوشتن کدی هستند که عملیات حسابی را روی یک متغیر انجام می‌دهد و مقدار جدید را به همان متغیر نسبت می‌دهد.
برای مثال، دو متغیر `x` و `y` را در نظر بگیرید.
در این صورت، `x += y` همان `x = x + y` است.
اغلب این شکل با یک عدد به‌جای متغیر `y` به کار می‌رود.
پنج عملیات دیگر هم به سبک مشابهی انجام می‌شوند.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
