## MacOS

ابتدا Lua و [Luarocks][2] را با استفاده از [Homebrew][1] نصب کنید:

```shell
$ brew install lua luarocks
```

سپس framework تست [Busted][3] را برای Lua نصب کنید:

```shell
$ luarocks install --local busted
```

`~/.luarocks/bin` را به `$PATH` سیستم خود اضافه کنید

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

توجه کنید که این کار فقط موقتی است.
برای افزودن دائمی به `$PATH`، باید آن را بسته به shellی که استفاده می‌کنید به `.bashrc`، `.zshrc` یا `config.fish` اضافه کنید.

سپس تست‌هایتان را اجرا کنید:

```shell
$ busted
```

## Ubuntu

ابتدا Lua و [Luarocks][2] را با استفاده از [Apt][6] نصب کنید:


## Windows 10: WSL

ابتدا باید [WSL (Windows Subsystem for Linux)][7] را با استفاده از [PowerShell][8] (با دسترسی Administrator) فعال کنید:

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

این کار به راه‌اندازی مجدد نیاز دارد.

سپس Ubuntu را از [Microsoft Store][9] نصب کنید، **یا** آن را دانلود و بعد با PowerShell نصب کنید:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

سپس فهرست بسته‌های خود را به‌روزرسانی کنید:

```shell
PS> wsl
$ sudo apt-get update
```

حالا آماده‌اید تا با دنبال کردن [دستورهای Ubuntu](#ubuntu) در بالا، [LuaRocks][2] و [Busted][3] را نصب کنید.

پس از انجام این کار، می‌توانید تست‌هایتان را مستقیماً از هر خط فرمان ویندوز اجرا کنید:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### نصب Gitbash

این مرحله اختیاری است. اگر ترجیح می‌دهید از CLI بومی ویندوز یا CLI دیگری استفاده کنید، ممکن است لازم باشد مراحل زیر را کمی تغییر دهید.

از [اینجا][10] دانلود کنید.
دستورهای نصب [اینجا][11].

### نصب Docker

برای نصب [Docker for Windows][12]، دستورها را دنبال کنید.
پس از پایان نصب، می‌توانید دستور زیر را اجرا کنید تا مطمئن شوید درست نصب شده است.

```shell
$ docker --version
```

_ممکن است هنگام اجرای Docker برای اولین بار با خطایی روبه‌رو شوید._

`cannot enable hyper-v service`

_اگر این اتفاق افتاد، می‌توانید این دستورها را برای [فعال کردن Hyper V][13] دنبال کنید. ممکن است لازم باشد این تنظیم را غیرفعال کنید، کامپیوترتان را دوباره راه‌اندازی کنید و پس از بوت دوباره آن را فعال کنید._

### نصب busted

پس از نصب Gitbash و Docker، می‌توانید یک کانتینر مخصوص busted را نصب کنید.

در Gitbash موارد زیر را اجرا کنید:

این کانتینر Docker پرکاربرد را با اجرای دستور زیر دریافت کنید:

```shell
$ docker pull imega/busted
```

یک تابع ایجاد کنید تا هر بار مجبور نباشید کل دستور را تایپ کنید.
این را به `.bashrc` خود اضافه کنید:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

حالا در CLI خود می‌توانید به پوشه‌ای که می‌خواهید تست‌ها را در آن اجرا کنید بروید. دستور زیر را اجرا کنید:

```shell
$ dbusted $PWD
```

باید خروجی تست‌های busted خود را ببینید.
