# دستورالعمل‌ها

یک تجزیه‌گر Markdown را بازآرایی کنید.

تمرین Markdown یک تمرین بازآرایی است.
code‌ای وجود دارد که یک رشته‌ی ورودی را با [نحوه‌ی نگارش Markdown][markdown] تجزیه می‌کند و HTML متناظر با آن رشته را برمی‌گرداند.
با اینکه این code گیج‌کننده نوشته شده و دنبال کردنش سخت است، اما به نحوی کار می‌کند و همه‌ی test‌ها موفق می‌شوند!
چالش شما این است که این code را بازنویسی کنید تا خواندن و نگهداری‌اش آسان‌تر شود و در همان حال مطمئن شوید که همه‌ی test‌ها همچنان موفق می‌مانند.

کمک‌کننده خواهد بود اگر کارهایی را که در جریان بازآرایی انجام داده‌اید در قالب کامنت‌ها یادداشت کنید تا بازبینی‌کنندگان بتوانند آن را ببینند، اما این کار الزامی نیست.
مهم‌ترین نکته این است که code را بهتر کنید!

[markdown]: https://guides.github.com/features/mastering-markdown/
