# مقدمه

انواع C# را می‌توان در محدوده‌ی یک کلاس یا ساختار تعریف کرد. نوع دربرگیرنده نوعی فضای نام فراهم می‌کند. دسترسی به نوع از طریق نوع دربرگیرنده و با نحوه‌ی نگارش نقطه‌ای انجام می‌شود.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

می‌توانید سطوح دسترسی را برای انواع داخلی تنظیم کنید.

اعضای خصوصی نوع بیرونی برای اعضای نوع داخلی در محدوده هستند، اما نه برعکس.
