# دستورالعملها

ادارهی اشیای گمشدهی مدرسه همهچیز را در جعبهها نگه میدارد و هر چیزی ممکن است در یک جعبه باشد: یک پلیور، چند مورد، یک اسم.

یک کلاس `LOST_BOX{T}` بنویسید. اسکلت کد، سرآیند کلاس را به شما میدهد.

## 1. چیزی را دریافت کنید

`create` شیء و اسم کسی را که آن را تحویل داده است میگیرد و یک جعبه برمیگرداند. جعبه در آغاز ادعانشده نیست.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. آن را ادعا کنید

`claim` جعبه را ادعاشده علامت میزند. چیزی برنمیگرداند.

```sather
box.claim;
box.claimed
-- => true
```

## 3. آیا هنوز در انتظار است؟

`waiting` میگوید که آیا جعبه ادعا نشده است یا نه.

```sather
box.waiting
-- => false
```

## 4. محتوا را عوض کنید

`replace` یک شیء تازه میگیرد، آن را در جعبه میگذارد و آنچه پیشتر آنجا بود را برمیگرداند. شیئی که داخل میرود و شیئی که بیرون میآید هر دو از نوع `T` هستند.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. آن را بنویسید

`describe` خطی دربارهی جعبه برمیگرداند، مانند `"blue jumper, handed in by Mia"`.

برای گذاشتن عنصر در یک رشته، کلاس باید بداند که `T` را میتوان به رشته تبدیل کرد. پارامتر را محدود کنید: سرآیند کلاس را به شکل `class LOST_BOX{T < $STR}` بنویسید؛ آنگاه `item.str` مجاز است.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
