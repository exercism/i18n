# درباره

در PHP، یک متغیر را می‌توان با قرار دادن پرانتز [`()`] بعد از آن به‌عنوان تابع فراخوانی کرد. وقتی PHP تلاش می‌کند تابع را فراخوانی کند، به دنبال تابعی می‌گردد که اسمش با مقدار متغیر یکسان باشد.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## فراخوانی توابع استاتیک کلاس

توابع استاتیک کلاس را هم می‌توان به همین روش فراخوانی کرد:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## فراخوانی توابع نمونه‌ای کلاس

فراخوانی تابعِ یک نمونه‌ی کلاس هم ممکن است:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
