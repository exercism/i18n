# افزودنی دستورالعمل‌ها

## قالب خروجی

یک رشته‌ی مختوم به نول خروجی بدهید که اجزای آن با یک ویرگول و یک فاصله از هم جدا می‌شوند.

یک نمونه خروجی چنین است: `"491, 914, 142"`

اگر ورودی نامعتبر باشد، یک رشته‌ی خالی خروجی بدهید.

## ثبات‌ها

| ثبات  | کاربرد       | نوع     | توضیح                          |
| ----- | ------------ | ------- | ------------------------------ |
| `$a0` | ورودی        | آدرس    | رشته‌ی سری مختوم به نول         |
| `$a1` | ورودی        | عدد صحیح | طول برش                        |
| `$a2` | ورودی/خروجی  | آدرس    | رشته‌ی خروجی مختوم به نول       |
| `$t0-9` | موقت       | هر نوع  | برای ذخیره‌سازی موقت استفاده می‌شود |
