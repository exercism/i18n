# یادگیری Visual Basic

## وبسایت

Visual Basic در طول سال‌ها تغییرات چشمگیری داشته است و بسیاری از آموزش‌های شخص ثالث به ابزارها یا قابلیت‌های قدیمی اشاره می‌کنند.
[مستندات رسمی Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) به‌روزترین و قابل‌اعتمادترین جایی است که می‌توانید سفرتان را از آن شروع کنید.

## اکوسیستم .NET

Visual Basic روی محیط اجرای .NET اجرا می‌شود و بخش زیادی از قابلیت‌های اصلی را با C# و F# به اشتراک می‌گذارد.
بنابراین، درک نحوه‌ی کار .NET شما را به برنامه‌نویس Visual Basic قوی‌تری تبدیل می‌کند.

- [.NET چیست؟](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [واژه‌نامه‌ی .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [سیستم نوع مشترک (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
