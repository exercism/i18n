# کلاس‌های انتزاعی

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class JUGGLING < $ACT is
   name : STR is return "Juggling"; end;
   minutes : INT is return 5; end;
   create : SAME is return new; end;
end;
```

## $ بخشی از اسم است

هر کلاس انتزاعی با یک `$` در ابتدای اسمش نام‌گذاری می‌شود و فقط کلاس‌های انتزاعی این‌گونه‌اند. پس نوعی که با `$` شروع می‌شود، نوعی است که نمی‌توانید از آن شیء بسازید، و این موضوع هر جایی که اسم ظاهر شود دیده می‌شود.

## چه چیزی می‌تواند درونش قرار بگیرد

امضاهای روال و تکرارگر، که به نقطه‌ویرگول ختم می‌شوند. بدون بدنه، بدون صفت، بدون `create`. یک کلاس انتزاعی توصیف می‌کند که می‌توان چه چیزی را از یک شیء *پرسید*، نه اینکه آن شیء چه چیزی در خود نگه می‌دارد.

## انطباق

```sather
class TRAPEZE < $ACT is
```

کلاس باید هر روالی را که فهرست شده، با انواع آرگومان و نوع بازگشتی یکسان، تعریف کند. این مورد هنگام کامپایل بررسی می‌شود.

یک کلاس می‌تواند به چند مورد انطباق داشته باشد:

```sather
class TRAPEZE < $ACT, $RISKY is
```

و کلاس‌های انتزاعی می‌توانند یکدیگر را گسترش دهند:

```sather
abstract class $TIMED_ACT < $ACT is
   overrun : INT;
end;
```

## اعزام در کجا رخ می‌دهد

یک متغیر از نوع انتزاعی، ارجاعی به یک شیء منطبق را در خود نگه می‌دارد. فراخوانی یک روال روی آن، در زمان اجرا نسخه‌ای را انتخاب می‌کند که به کلاس واقعی شیء تعلق دارد.

این تنها جایی است که Sather در زمان اجرا تصمیمی می‌گیرد. فراخوانی روی یک متغیر از نوع مشخص، هنگام کامپایل قطعی می‌شود.

## typecase

گاهی واقعاً نوع اهمیت دارد. `typecase` می‌پرسد:

```sather
   typecase act
   when TRAPEZE then #OUT + "rig the net";
   else            #OUT + "nothing to rig";
   end;
```

درون هر شاخه، متغیر نوع باریک‌تری دارد. کم به سراغش بروید: یک `typecase` روی هر نوعی از act، معمولاً روالی است که از همان ابتدا باید در کلاس انتزاعی می‌بود.

## $OB

`$OB` کلاس انتزاعی‌ای است که هر شیء با آن منطبق است. گه‌گاه مفید است و بیشتر نشانه‌ی آن است که نوعی در طول مسیر از دست رفته است.

## چرا وراثت نه؟

Sather دو موضوع را از هم جدا می‌کند که بیشتر زبان‌ها آن‌ها را یکی می‌کنند. `<` فقط می‌گوید یک کلاس چه کاری می‌تواند *انجام دهد*. گرفتن پیاده‌سازی از جایی دیگر با `include` انجام می‌شود، که دو تمرین بعدتر می‌آید و تصمیمی جداگانه است.
