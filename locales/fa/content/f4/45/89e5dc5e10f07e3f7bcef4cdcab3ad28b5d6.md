# گردش کار «هیچ فایل مهمی تغییر نکرده است»

وقتی PR مربوط به یک مسیر که یک تمرین را تغییر می‌دهد ادغام می‌شود، باعث می‌شود _همه‌ی_ آخرین نسخه‌های منتشرشده‌ی راه‌حل‌های دانش‌آموزان دوباره تست شوند.
برای تمرین‌های پرطرفدار، این یک عملیات _بسیار_ پرهزینه است (برای تمرین «سلام دنیا» در Python، ۷۰٬۰۰۰ اجرای تست، به‌عنوان یک نمونه‌ی افراطی!).

این گردش کار بررسی می‌کند که آیا تغییرات یک PR باعث تست دوباره‌ی راه‌حل‌ها می‌شوند یا نه، و اگر چنین باشد، کامنتی اضافه می‌کند که خطر ادغام PR را _همان‌طور که هست_ توضیح می‌دهد.
همچنین توضیح می‌دهد که چطور PR را بدون تست دوباره‌ی راه‌حل‌ها ادغام کنید.

برای اطلاعات بیشتر، مستندات [اجتناب از ایجاد اجراهای تست غیرضروری](https://exercism.org/docs/building/tracks#h-avoiding-triggering-unnecessary-test-runs) را ببینید.

## منبع

این گردش کار در فایل `.github/workflows/no-important-files-changed.yml` تعریف شده است.
