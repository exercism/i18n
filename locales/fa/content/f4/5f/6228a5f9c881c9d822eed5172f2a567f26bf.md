# مقدمه

آرایه‌های انجمنی Factor، یعنی جدول‌های درهم‌سازی و مانند آن، یک [پروتکل][assoc-protocol] مشترک از [`assocs`][assocs] دارند. جدول درهم‌سازی به‌صورت `H{ }` نوشته می‌شود:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

عملیات‌های رایج:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

جدول‌های درهم‌سازی *تغییرپذیر* هستند؛ پیش از تغییر دادن، یک `H{ }` را `clone` کنید تا آن مقدار میان فراخوانی‌ها مشترک نماند.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
