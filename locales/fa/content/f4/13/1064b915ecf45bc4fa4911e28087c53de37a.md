# مقدمه

«تاپل» نوع رکورد/ساختار/کلاس در Factor است. هر کلاس تاپل مجموعه‌ای ثابت از جایگاه‌های نام‌گذاری‌شده دارد و Factor به‌طور خودکار توابع خواندن و نوشتن آن‌ها را می‌سازد.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` («به ترتیب آرگومان‌ها») جایگاه‌ها را به ترتیب اعلان از پشته پر می‌کند. `new` نمونه‌ای می‌سازد که هر جایگاه آن مقدار اعلان‌شده‌ی `initial:` را دارد (یا اگر `initial:` نداشته باشد، `f`).

تابع خواندن هر جایگاه `slot>>` است و تابع نوشتن آن `>>slot`. تابع نوشتن *در جا تغییر می‌دهد*، پس اگر به‌روزرسانی غیرمخرب می‌خواهید، اول `clone` کنید:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

مقدار پیش‌فرض هر جایگاه با `{ name initial: value }` تعیین می‌شود؛ بدون `initial:` مقدار پیش‌فرض `f` است.
