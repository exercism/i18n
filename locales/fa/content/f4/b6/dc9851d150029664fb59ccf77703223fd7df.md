# قالب‌بندی Kernel

علاوه بر متد `format`، یکی از روش‌های رایج ساخت رشته در Ruby استفاده از [درج رشته](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) است. برای نمونه:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
