# درباره

«بلوک‌ها» گروه‌های کوچکی از دستورها هستند که می‌توان آن‌ها را چندین بار اجرا کرد. می‌توان به آن‌ها مثل بستارها یا توابع بی‌نام نگاه کرد. بلوک‌ها با نحوه‌ی نگارش `do...end` (بالا) یا `{}` (پایین) تعریف می‌شوند. این دو سبک جایگزین‌پذیرند و درباره‌ی اینکه هر کدام چه زمانی باید استفاده شوند، نظرهای متفاوتی وجود دارد.

## نحوه‌ی نگارش کوتاه
در موقعیت‌هایی که یک بلوک تنها یک متد را فراخوانی می‌کند، می‌توانید بلوک را با `&:` و بعد از آن اسم متد جایگزین کنید. برای مثال، این دو خط با هم هم‌معنا هستند:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
