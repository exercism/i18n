# دستورالعمل

در این تمرین برنامه‌ی مفیدی می‌سازید تا دیگر لازم نباشد مقدار نوارها را به خاطر بسپارید.
برنامه ۱، ۴ یا ۵ رنگ را به‌عنوان ورودی می‌گیرد و مقدار درست را بر حسب اهم خروجی می‌دهد.
نوارهای رنگی به این صورت کدگذاری می‌شوند:

| رنگ    | مقدار |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

در [`Resistor Color Trio`][resistor-color-trio-exercise] سه نوار رنگی نخست را رمزگشایی کردید.
برای نمونه: orange-orange-brown به مقدار اصلی `330` تبدیل می‌شد.
در این تمرین باید «تلورانس» را هم به ماجرا اضافه کنید.
تلورانس بیشترین مقداری است که یک مقدار می‌تواند بالاتر یا پایین‌تر از مقدار اصلی باشد.
برای نمونه، اگر نوار آخر green باشد، بیشترین تلورانس `±0.5%` خواهد بود.

نوار تلورانس یکی از این مقادیر را دارد:

| رنگ    | تلورانس  |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

مقاومت چهارنواری این‌طور ساخته می‌شود:

| نوار_۱  | نوار_۲  | نوار_۳  | نوار_۴   |
| ------- | ------- | ------- | --------- |
| مقدار_۱ | مقدار_۲ | ضریب    | تلورانس   |

نمونه‌ها:

- orange-orange-brown-green برابر `330` اهم با تلورانس `±0.5%` می‌شود.
- orange-orange-red-grey برابر `3300` اهم با تلورانس `±0.05%` می‌شود.

تفاوت مقاومت چهارنواری و پنج‌نواری در این است که مقاومت پنج‌نواری یک نوار اضافه دارد که مقدار دقیق‌تری را نشان می‌دهد.

| نوار_۱  | نوار_۲  | نوار_۳  | نوار_۴   | نوار_۵   |
| ------- | ------- | ------- | --------- | --------- |
| مقدار_۱ | مقدار_۲ | مقدار_۳ | ضریب      | تلورانس   |

نمونه‌ها:

- orange-orange-orange-black-green برابر `333` اهم با تلورانس `±0.5%` می‌شود.
- orange-red-orange-blue-violet برابر `323 million` اهم با تلورانس `±0.1%` می‌شود.

مقاومت‌های تک‌نواری هم وجود دارند.
مقاومت تک‌نواری فقط رنگ black را دارد، با مقدار ۰.

برنامه‌ی شما باید یک `list` ورودی از رنگ نوارهای مقاومت را به یک برچسب تبدیل کند:

"... ohms ±...%"

پس یک `list` ورودی به شکل `["orange", "orange", "black", "green"]` باید این را برگرداند:

"33 ohms ±0.5%"

وقتی مقدار بر حسب هزار اهم است، می‌گوییم «kiloohms».
این شبیه به گفتن «kilometer» برای ۱۰۰۰ متر و «kilograms» برای ۱۰۰۰ گرم است.

پس یک `list` ورودی به شکل `["orange", "orange", "orange", "grey"]` باید این را برگرداند:

"33 kiloohms ±0.05%"

وقتی مقدار بر حسب میلیون اهم است، می‌گوییم «megaohms».

پس یک `list` ورودی به شکل `["orange", "orange", "blue", "red"]` باید این را برگرداند:

"33 megaohms ±2%"
