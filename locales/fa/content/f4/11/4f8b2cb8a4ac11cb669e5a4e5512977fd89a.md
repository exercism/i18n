# کمک

در ادامه چند منبع برای دریافت کمک، در صورتی که به مشکل برخوردید، آورده شده است:

- [PSF](https://www.python.org) میزبان دانلودهای Python، مستندات و منابع جامعه است.
- [انجمن‌های جامعه‌ی Python](https://discuss.python.org/) برای کمک، بحث درباره‌ی PEP، توسعه‌دهندگان اصلی Python و موارد دیگر.
- [جامعه‌ی Exercism در Discord](https://exercism.org/r/discord)
- [انجمن‌های گفت‌وگوی جامعه‌ی Exercism](https://forum.exercsim.org)
- [جامعه‌ی Python در Discord](https://pythondiscord.com/) جامعه‌ای بسیار مفید و فعال است.
- [/r/learnpython/](https://www.reddit.com/r/learnpython/) یک ساب‌ردیت است که برای یادگیرندگان Python درست شده است.
- [#python در Libera.chat](https://www.python.org/community/irc/) اینجا جایی است که توسعه‌دهندگان اصلی زبان دور هم جمع می‌شوند و کارها را پیش می‌برند.
- [انجمن‌های جامعه‌ی Free Code Camp](https://forum.freecodecamp.org/)
- [Pythontutor](http://pythontutor.com/) برای مرور گام‌به‌گام قطعه‌کدهای کوچک به صورت بصری.

علاوه بر این، [StackOverflow](http://stackoverflow.com/questions/tagged/python) جای خوبی است برای جست‌وجوی مشکل یا پرسش خود تا ببینید آیا پیش‌تر به آن پاسخ داده شده است یا نه. اگر نه، همیشه می‌توانید [بپرسید](https://stackoverflow.com/help/how-to-ask) یا به پرسش فرد دیگری [پاسخ دهید](https://stackoverflow.com/help/how-to-answer).
