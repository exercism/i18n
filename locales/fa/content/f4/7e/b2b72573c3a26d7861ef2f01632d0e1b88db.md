# دستورالعمل‌ها

در سیرک، تا وقتی بررسی‌های ایمنی قبول نشوند، هیچ‌کس روی تراپز نمی‌رود.
شما این بررسی‌ها را می‌نویسید تا قواعد یکسانی برای همه اعمال شود.

هر پنج تمرین در کلاس `SAFETY_CHECK` قرار می‌گیرند.

## 1. آیا تشک آماده است؟

تشک تنها زمانی آماده است که هم پهن شده باشد و هم تمیز.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. آیا جایی برای فرود آمدن هست؟

باید یک تشک در پایین باشد، یا یک تور در پایین. هر کدام کافی است و داشتن
هر دو هم اشکالی ندارد.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. چه کسی هنوز به توجیه نیاز دارد؟

هر کسی که توجیه نشده باشد، به توجیه نیاز دارد.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. آیا این هنرمند به اندازه‌ی کافی بزرگ است؟

تراپز برای هنرمندان ۱۳ ساله و بالاتر است.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. همه را کنار هم بگذارید

یک هنرمند در صورتی برای تراپز مجاز است که به اندازه‌ی کافی بزرگ باشد،
توجیه شده باشد و تشک آماده باشد.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

این چهار آرگومان عبارت‌اند از سن، اینکه توجیه شده‌اند یا نه، اینکه تشک
پهن شده است یا نه و اینکه تشک تمیز است یا نه.
