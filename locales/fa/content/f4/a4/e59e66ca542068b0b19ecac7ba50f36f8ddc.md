# تخریب ساختار

«تخریب ساختار» فرایندی است که در آن هر مورد به اجزای تشکیل‌دهنده‌اش شکسته می‌شود و هر جزء به متغیری کوچکتر مقید می‌شود.

## تخریب ساختار چندتایی‌ها

تخریب ساختار چندتایی‌ها ساده است: کافی است به هر فیلد چندتایی، اسم متغیری تازه نسبت دهید:

```rust
let (first, second) = (1, 2);
```

## تخریب ساختارِ ساختارهای چندتایی

تخریب ساختار ساختارهای چندتایی دقیقاً مانند تخریب ساختار چندتایی‌هاست، با این تفاوت که اسم ساختار هم اضافه می‌شود:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## تخریب ساختار ساختارها

تخریب ساختار ساختارها مانند تخریب ساختار ساختارهای چندتایی است. فقط کافی است از اسم فیلدها استفاده کنید:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## تخریب ساختار جزئی

هنگام تخریب ساختار می‌توان از عملگر `..` برای نادیده گرفتن برخی فیلدها استفاده کرد:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## تخریب ساختار شرطی

تخریب ساختار ساختارها و چندتایی‌ها خطاناپذیر است. با این حال، می‌توان «شمارشی» را هم تخریب ساختار کرد، با استفاده از سازه‌های زبانی `if let`، `while let` و `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
