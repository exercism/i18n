# مقدمه

تاپل یک ظرف از مقدارهاست که ترتیب در آن مهم است. مثل همه‌ی انواع داده‌ی Gleam، تاپل‌ها تغییرناپذیرند. هر عنصر تاپل می‌تواند نوع متفاوتی داشته باشد، حتی می‌تواند تاپل‌های دیگری باشد.

تاپل‌ها به‌صورت مقدارهایی تعریف می‌شوند که با کاما از هم جدا شده‌اند و بین `#(` و `)` قرار می‌گیرند: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

تاپل‌هایی با طول یکسان و نوع‌های یکسان (به همان ترتیب) را می‌توان برای برابری مقایسه کرد.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

سه راه برای بیرون آوردن مقدارهای موجود در یک تاپل وجود دارد:

- اندیس‌گذاری.
- تطبیق الگو با `let`.
- تطبیق الگو با `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
