# دستورالعمل‌ها

در نیوزیلند پیاده‌روی می‌کنید و با قطب‌نما سمت می‌گیرید. یک «سمت»، یک عدد صحیح درجه است و یک مقدار به شمار می‌رود: چرخش به اندازه‌ی ۲۰ درجه سمتی را که گرفته‌اید تغییر نمی‌دهد، بلکه سمت دیگری به شما می‌دهد.

یک `immutable class BEARING` بنویسید. کد اولیه سرآیند کلاس و ویژگی آن را به شما می‌دهد.

## 1. سمت بگیرید

`create` تعدادی درجه می‌گیرد و یک سمت برمی‌گرداند. درجه‌ها از ۰ تا ۳۵۹ هستند، بنابراین هر مقداری خارج از این بازه، دور می‌خورد و برمی‌گردد: ۳۷۰ برابر ۱۰ است و منفی ۱۰ برابر ۳۵۰.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. بچرخانید

`turned` تعدادی درجه برای چرخش می‌گیرد و سمت جدید را برمی‌گرداند. چرخش با یک عدد منفی، در جهت مخالف انجام می‌شود. سمتی که روی آن فراخوانی شده تغییر نمی‌کند.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. مقایسه کنید

`is_eq` یک سمت دیگر می‌گیرد و پاسخ می‌دهد که آیا آن دو یکسان هستند. وقتی وجود داشته باشد، `=` روی سمت‌ها کار می‌کند.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. نام نقطه را بگویید

`point` نزدیک‌ترین «نقطه‌ی قطب‌نما» به سمت را برمی‌گرداند، به‌صورت یکی از `"N"`، `"NE"`، `"E"`، `"SE"`، `"S"`، `"SW"`، `"W"`، `"NW"`.

هر نقطه ۴۵ درجه را پوشش می‌دهد و بر سمت دقیق خود متمرکز است: شمال از ۳۳۷٫۵ آغاز می‌شود، از ۰ می‌گذرد و تا ۲۲٫۵ ادامه دارد، شمال‌شرق از ۲۲٫۵ تا ۶۷٫۵ و به همین ترتیب. چون سمت‌ها اینجا اعداد صحیح هستند، سمت ۲۲ برابر `"N"` است و ۲۳ برابر `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. آن را بنویسید

`str` درجه‌ها و نقطه را برمی‌گرداند، مانند `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
