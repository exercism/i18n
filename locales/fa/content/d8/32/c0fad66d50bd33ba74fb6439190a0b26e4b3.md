# دستورالعمل‌ها

در این تمرین شما یک بازی نقش‌آفرینی انجام می‌دهید که در آن انواع مختلف مبارزان می‌توانند با یکدیگر بجنگند.
بازی برای هر نوع مبارز قوانین متفاوتی دارد.
ما روی دو نوع خاص تمرکز می‌کنیم: Wizard و Warrior.

قوانین مربوط به Warrior به این صورت است:

- یک Warrior هرگز آسیب‌پذیر نیست.
- یک Warrior اگر مبارزی که به آن حمله می‌کند آسیب‌پذیر نباشد، `6` واحد آسیب وارد می‌کند.
- یک Warrior اگر مبارزی که به آن حمله می‌کند آسیب‌پذیر باشد، `10` واحد آسیب وارد می‌کند.

قوانین مربوط به Wizard به این صورت است:

- یک Wizard می‌تواند از قبل طلسمی آماده کند.
- یک Wizard آسیب‌پذیر است، مگر اینکه از قبل طلسمی آماده کرده باشد.
- یک Wizard اگر از قبل طلسمی آماده کرده باشد، `12` واحد آسیب وارد می‌کند.
- یک Wizard اگر از قبل طلسمی آماده نکرده باشد، `3` واحد آسیب وارد می‌کند.

## 1. کلاس Warrior را بسازید

یک کلاس جدید به اسم `Warrior` بسازید.
این کلاس باید از کلاس موجود `Fighter` ارث‌بری کند.

## 2. توصیف Warrior

کلاس `Warrior` را طوری به‌روزرسانی کنید که متد `toString()` آن توصیف کند که این مبارز از چه نوعی است.
این متد باید رشته‌ی `"Fighter is a Warrior"` را برگرداند.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Warriorها را آسیب‌ناپذیر کنید

کلاس `Warrior` را طوری به‌روزرسانی کنید که متد `isVulnerable()` آن همیشه `false` را برگرداند.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. محاسبه‌ی واحدهای آسیب یک Warrior

کلاس `Warrior` را طوری به‌روزرسانی کنید که متد `getDamagePoints(Fighter)` آن، آسیبی را که یک Warrior طبق قوانین بالا وارد می‌کند محاسبه کند.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. کلاس Wizard را بسازید

یک کلاس جدید دیگر به اسم `Wizard` بسازید.
این کلاس هم باید از کلاس موجود `Fighter` ارث‌بری کند.

## 6. توصیف Wizard

کلاس `Wizard` را طوری به‌روزرسانی کنید که متد `toString()` آن توصیف کند که این مبارز از چه نوعی است.
این متد باید رشته‌ی `"Fighter is a Wizard"` را برگرداند.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. به Wizardها اجازه دهید طلسم آماده کنند و اگر طلسمی آماده نکرده‌اند، آسیب‌پذیر باشند

کلاس `Wizard` را به‌روزرسانی کنید و متدی به اسم `prepareSpell()` به آن اضافه کنید.
این کلاس باید به خاطر بسپارد که چه زمانی این متد فراخوانی شده است و مطمئن شود که متد `isVulnerable()` آن فقط وقتی طلسمی آماده شده باشد `false` را برمی‌گرداند.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. محاسبه‌ی واحدهای آسیب یک Wizard

کلاس `Wizard` را طوری به‌روزرسانی کنید که متد `getDamagePoints(Fighter)` آن، آسیبی را که یک Wizard طبق قوانین بالا وارد می‌کند محاسبه کند.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
