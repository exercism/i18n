# مقدمه

Common Lisp چندین عبارت شرطی مختلف در اختیار شما می‌گذارد که تفاوت اصلی‌شان در تعداد شاخه‌هایی است که پشتیبانی می‌کنند.

- `when` و `unless` تنها یک شاخه می‌پذیرند:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

بخش پس از عبارت آزمون می‌تواند بیش از یک عبارت باشد.

- `if` ساختار کلاسیک اگر-آنگاه-وگرنه را فراهم می‌کند:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

توجه کنید که هر دو بند آنگاه و وگرنه تنها می‌توانند یک عبارت باشند.

- `cond` راهی برای داشتن چندین شاخه بدون تودرتو کردن عبارت‌های `if` فراهم می‌کند:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

توجه کنید که هیچ محدودیتی در تعداد عبارت‌های پس از عبارت آزمون وجود ندارد.

- `case` یک ساختار کلاسیک به سبک «switch» فراهم می‌کند: یک مقدار واحد را در برابر تعدادی شاخه بررسی می‌کند:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

توجه کنید که مانند `cond` هیچ محدودیتی در تعداد عبارت‌های پس از عبارت آزمون وجود ندارد.
