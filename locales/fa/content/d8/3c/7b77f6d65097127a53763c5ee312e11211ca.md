# مقدمه

## توضیحات

Common Lisp به برنامه‌نویس اجازه می‌دهد «توضیحات» بنویسد که کامپیوتر آن‌ها را نادیده می‌گیرد.
توضیحات تک‌خطی با یک یا چند نقطه‌ویرگول (`;`) شروع می‌شوند و گاهی ممکن است شکل زیر را ببینید:

```lisp
(code...) ; => value
```

در این نمونه از توضیح استفاده شده است تا نشان دهد Common Lisp پس از اجرای کد آن خط چه مقداری را برمی‌گرداند.

مرسوم است که برای یک توضیح کوتاه در پایان خط از یک نقطه‌ویرگول، برای توضیحی بلندتر بالای بخشی از کد از دو نقطه‌ویرگول، برای توضیحی بلند که چیزی مانند یک تابع را توصیف می‌کند از سه نقطه‌ویرگول و برای توضیحی مانند سرصفحه در بالای یک فایل منبع از چهار نقطه‌ویرگول استفاده شود.

## کنس

همه‌ی اشیاء Common Lisp یا «اتم» هستند (مقدارهایی یگانه و تجزیه‌ناپذیر) یا «کنس» (که با تابع سازنده‌ی `cons` ساخته می‌شوند).
هر کنس از دو بخش تشکیل می‌شود: عنصر اول و بقیه‌ی عنصرها.
به دلایل تاریخی، به این دو بخش `car` و `cdr` می‌گویند.
وقتی این کنس‌ها به‌عنوان کد ارزیابی می‌شوند، عنصر اول (`car`) تابعی را نشان می‌دهد که فراخوانی می‌شود و بقیه‌ی عنصرها (`cdr`) آرگومان‌های آن تابع هستند:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## عبارات

تمام کد Common Lisp از S-Expressions (Symbolic Expressions) تشکیل شده است. به اختصار به آن‌ها «sexpr» می‌گویند. هر sexpr یا یک اتم است یا یک کنس. وقتی S-Expressions ارزیابی می‌شوند، به‌طور خودکار مقداری را برمی‌گردانند که جای آن عبارت را می‌گیرد. وقتی توابع خودتان را می‌نویسید (با استفاده از `defun`)، آخرین مقدار در بدنه‌ی `defun` به‌طور خودکار برگردانده می‌شود:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## نمادها

نمادها در Common Lisp مقدارهای ویژه‌ای هستند که می‌توانند به مقدارهای دیگر اشاره کنند یا، در مورد _کلیدواژه‌ها_، به خودشان.
وقتی Lisp نمادها را ارزیابی می‌کند، آن‌ها با مقدارهایی که به آن‌ها اشاره می‌کنند جایگزین می‌شوند:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

توجه کنید که کلیدواژه‌ها با یک دونقطه (`:`) در ابتدا نشان داده می‌شوند.

نقل‌قول، یعنی افزودن `'` پیش از یک S-Expression، به Lisp می‌گوید که آن عبارت را ارزیابی نکند.
با نقل‌قول کردن `'foo` در مثال `defun`مان، کاری کردیم که Lisp به‌جای تلاش برای یافتن آنچه `FOO` قرار بود به آن اشاره کند (و ناکامی در یافتنش)، خودِ مقدار `FOO` را برگرداند.
اگر `FOO` هیچ‌جای برنامه تعریف نشده باشد:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

فعلاً می‌توانید این را صرفاً راهی برای برگرداندن نمادها از یک تابع در نظر بگیرید، اما در تمرین‌های مفهومی آینده دوباره به نقل‌قول برمی‌گردیم و پیامدهای آن را بیشتر بررسی می‌کنیم.
