# یادگیری

Vim از پیش مستندات عالی و کاملی همراه خود دارد. راه دسترسی به این مستندات، دستور `:help` است.

برای یک معرفی، به `:h user-manual` نگاهی بیندازید.

تقریباً همه‌ی نصب‌های Vim یک آموزش تعاملی هم دارند:

```
$ vimtutor
```

Vim چند دهه قدمت دارد و همچنان محبوب است. منابع زیادی درباره‌ی آن در وب پیدا می‌کنید که برخی از برخی دیگر بهترند. منابع خوب [اینجا](https://exercism.org/docs/tracks/vimscript/resources) فهرست شده‌اند.
