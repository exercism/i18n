# مقدمه


## مقادیر منطقی

PowerShell نوع [`bool`][booleans] را دارد تا مقادیر منطقی «درست» و «غلط» را نمایش دهد.
در این نوع فقط دو مقدار وجود دارد: `True` و `False`.
می‌توانید این مقادیر را با پیشوند `$` به متغیرها نسبت دهید:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

می‌توانیم از [عملگرهای منطقی][logical-operators] مانند `-and`، `-or` و `-not` برای ترکیب و ارزیابی عبارت‌های منطقی استفاده کنیم.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## راهنمای مبتنی بر توضیحات

قابلیت [`Comment-based help`][comment-based help] در PowerShell به شما کمک می‌کند تا اطلاعات دقیقی را برای توابع و اسکریپت‌ها، در قالب توضیحات، بنویسید.
این قابلیت برای مشخص کردن موضوع‌های موردنظر از «کلیدواژه»های ویژه‌ی راهنما استفاده می‌کند، مانند `.SYNOPSIS`، `.EXAMPLE` یا `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

می‌توانید اطلاعات راهنمای مبتنی بر توضیحات را با cmdlet `Get-Help` نمایش دهید.

```powershell
> Get-Help -Name "ExampleFunction"
```
