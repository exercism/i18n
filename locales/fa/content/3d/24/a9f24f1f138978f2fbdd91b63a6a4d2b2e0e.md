# مقدمه

## مبانی

در F#، اختصاص دادن یک مقدار به یک اسم را «اتصال» می‌گویند. اتصال‌ها تغییرناپذیرند و همین آن‌ها را شبیه ثابت‌های زبان‌های دیگر می‌کند. از آنجا که F# زبانی با نوع ایستاست، هر اتصال در زمان کامپایل یک نوع دارد.

اتصال‌ها با کلیدواژه‌ی `let` تعریف می‌شوند. مشخص کردن نوع یک اتصال برای بیشتر اتصال‌ها اختیاری است، چون «استنتاج نوع» در F# معمولاً می‌تواند نوع را بر اساس مقدار آن استنباط کند. یک اتصال به این شکل است:

```fsharp
// Automatically inferred type
let fingers = 10
```

توابع هم اتصال‌های معمولی‌اند، اما با یک یا چند پارامتر. یک تابع به‌طور خودکار آخرین عبارت خود را برمی‌گرداند. استنتاج نوع برای بیشتر توابع هم کار می‌کند، با تحلیل اینکه تابع با چه مقادیری فراخوانی می‌شود و چه مقداری برمی‌گرداند.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

فراخوانی یک تابع با نوشتن اسم آن و فرستادن آرگومان برای هر یک از پارامترهای تابع انجام می‌شود.

```fsharp
let five = add 2 3
```

اگر نوع یک اتصال قابل استنباط نباشد، کامپایلر یک خطا گزارش می‌دهد. برای رفع این مشکل، یک حاشیه‌نویسی نوع صریح به اتصال اضافه کنید.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

اتصال‌ها در F# فقط پس از تعریف شدن قابل استفاده‌اند. استفاده از یک اتصال پیش از تعریف شدن آن به خطای کامپایل منجر می‌شود.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# برای مشخص کردن محدوده از فضای خالی معنادار استفاده می‌کند. یعنی محدوده با تورفتگی کد به کمک فاصله‌ها، نسبت به خطی که اتصال را تعریف می‌کند، مشخص می‌شود. قرارداد پیش‌فرض این است که برای تورفتگی از چهار فاصله استفاده شود:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

اتصال‌های F# (که توابع را هم شامل می‌شوند) معمولاً در ماژول‌ها سازمان‌دهی می‌شوند. یک ماژول عملکردهای مرتبط را کنار هم جمع می‌کند و با کلیدواژه‌ی `module` تعریف می‌شود. تعریف ماژول باید پیش از اتصال‌هایش بیاید:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# از دو نوع توضیح پشتیبانی می‌کند. توضیحات تک‌خطی با `//` شروع می‌شوند و توضیحات چندخطی بین `(*` و `*)` قرار می‌گیرند.
