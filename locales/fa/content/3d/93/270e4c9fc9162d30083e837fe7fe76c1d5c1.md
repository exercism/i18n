# دستورالعمل‌ها

شما پرنده‌نگری پرشور هستید که پیگیری می‌کنید در هفت روز گذشته چند پرنده به باغتان آمده‌اند.

پنج وظیفه دارید که همه‌شان به شمار پرنده‌هایی مربوط می‌شوند که به باغتان آمده‌اند.

## 1. بررسی کنید شمارش‌های هفته‌ی گذشته چه بوده‌اند

برای مقایسه، همیشه نسخه‌ای از شمارش‌های هفته‌ی گذشته را کنار دستتان نگه می‌دارید که عبارت‌اند از: 0، 2، 5، 3، 7، 8 و 4. متد `BirdCount.last_week` را پیاده‌سازی کنید که شمارش‌های هفته‌ی گذشته را برمی‌گرداند:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. بررسی کنید دیروز چند پرنده آمده است

متد `BirdCount#yesterday` را پیاده‌سازی کنید تا برگرداند که دیروز چند پرنده به باغتان آمده است. شمارش پرنده‌ها بر اساس روز مرتب شده است؛ اولین عنصر شمارش قدیمی‌ترین روز است و آخرین عنصر شمارش امروز.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. محاسبه‌ی شمار کل پرنده‌های بازدیدکننده

متد `BirdCount#total` را پیاده‌سازی کنید تا شمار کل پرنده‌هایی را برگرداند که به باغتان آمده‌اند:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. محاسبه‌ی تعداد روزهای پرمشغله

بعضی روزها پرمشغله‌تر از بقیه‌اند. روزی که پنج پرنده یا بیشتر به باغتان آمده باشد، «روز پرمشغله» نامیده می‌شود.
متد `BirdCount#busy_days` را پیاده‌سازی کنید تا تعداد روزهای پرمشغله را برگرداند:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. بررسی کنید روزی بوده است که هیچ پرنده‌ای به باغ نیامده باشد

متد `BirdCount#day_without_birds?` را پیاده‌سازی کنید که اگر روزی بوده است که هیچ پرنده‌ای به باغ نیامده باشد `true` برمی‌گرداند؛ در غیر این صورت `false` را برگردانید:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
