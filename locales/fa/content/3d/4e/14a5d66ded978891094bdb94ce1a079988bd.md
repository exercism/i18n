# Tests

## clojure.test

Babashka همراه با clojure.test ارائه می‌شود. وقتی آماده شدید که روی یک تمرین کار کنید و فایلی برای نگه داشتن راه‌حل خود ساخته باشید (مثل `bob.clj`)، می‌توانید تست‌ها را با `clojure.test/run-tests` [همان‌طور که اینجا توضیح داده شده است](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests) اجرا کنید.


REPL به شما امکان می‌دهد کد را به‌راحتی اجرا کنید و بازخورد فوری بگیرید و می‌توان از آن برای اجرای تست‌ها هم استفاده کرد. توصیه می‌شود از `rlwrap` استفاده کنید تا ویرایش خط و تاریخچه‌ی دستورها با کلیدهای بالا/پایین فعال شود. برای تست یک تمرین، به پوشه‌ی آن بروید و یک socket REPL باز کنید و پوشه‌های `src` و `test` را به classpath اضافه کنید:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

اول، فضای‌نام تست را `require` کنید:
``` clojure
=> (require 'bob-test)
nil
```

سپس `run-tests` را روی `bob-test` فراخوانی کنید:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

برای ساختن یک اسکریپت اجراکننده‌ی تست:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
