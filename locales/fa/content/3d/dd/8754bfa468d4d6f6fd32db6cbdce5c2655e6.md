# دستورالعمل‌ها

دفتر یادداشت کارآگاه با پیش رفتن پرونده پر می‌شود و با کنار گذاشتن مسیرهای تحقیق دوباره خالی می‌شود.

همه‌ی پنج کار در کلاس `CASE_NOTES` قرار می‌گیرند.

## 1. یک پرونده را باز کنید

یک دفتر یادداشت تازه و خالی برگردانید.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. یک سرنخ را یادداشت کنید

یک سرنخ را به انتهای دفتر یادداشت اضافه کنید. این کار هیچ مقداری برنمی‌گرداند؛ دفتر یادداشتی را که به آن داده شده تغییر می‌دهد.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. چند سرنخ؟

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. یک سرنخ را کنار بگذارید

سرنخ را از یک موقعیت در دفتر یادداشت بیرون بیاورید. همه‌ی سرنخ‌های بعد از آن یک خانه بالا می‌آیند. این کار هم مقداری برنمی‌گرداند.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. پرونده را بازخوانی کنید

همه‌ی سرنخ‌های دفتر یادداشت را برگردانید، در حالی که با `"; "` به هم پیوسته‌اند. دفتر یادداشت خالی، به‌عنوان رشته‌ی خالی خوانده می‌شود.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
