# مقدمه

Haxe از «بازتاب» نوع‌ها و فیلدها در زمان اجرا پشتیبانی می‌کند. برای استفاده‌ی درست از بازتاب، باید بدانید چه نوع عملیاتی پشتیبانی می‌شود و چه نوعی نمی‌شود. با توجه به ماهیت پویای بازتاب، همیشه نمی‌توان این را در زمان کامپایل تعیین کرد.

API بازتاب از دو کلاس تشکیل شده است:

- `Reflect`: یک API سبک‌وزن که روی ساختارهای بینام بهترین عملکرد را دارد و پشتیبانی محدودی از کلاس‌ها ارائه می‌دهد.
- `Type`: یک API قوی‌تر برای کار با کلاس‌ها و `enum`ها.

در مثال زیر، از هدف JavaScript استفاده می‌کنیم:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
