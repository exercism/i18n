# مقدمه

## ماژول

تا اینجا همه‌ی تمرین‌هایی که دیده‌اید از کلاس استفاده کرده‌اند.
گاهی نیازی به سربار ساختن یک شیء دارای وضعیت نداریم، بنابراین به‌جای آن از `module` استفاده می‌کنیم.

یک «ماژول» بسیار شبیه کلاس است (در واقع، `Module` والد `Class` در سلسله‌مراتب شیء است). تفاوت اصلی این است که به‌جای متدهای نمونه‌ای، از متدهای کلاس استفاده می‌کنیم.
متدهای کلاس با `self.` شروع می‌شوند و مستقیماً روی یک ماژول فراخوانی می‌شوند.

برای مثال:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## حلقه

روش‌های مختلفی برای نوشتن «حلقه» در Ruby وجود دارد، اما چون به‌طور کلی به‌جای حلقه‌زنی، بیشتر از شمارش استفاده می‌کنیم، شاید رایج‌ترین حلقه‌ای که دیده می‌شود حلقه‌ی `while` باشد:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

همچنین می‌توانید از حلقه‌ی همزادش `until` استفاده کنید

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
