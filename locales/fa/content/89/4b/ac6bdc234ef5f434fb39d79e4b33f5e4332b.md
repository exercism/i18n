# درباره

یک «مجموعه‌ی مجزا» (ساختار یونیون-فایند) مجموعه‌ای از مقدارها را نگه می‌دارد که به گروه‌های بدون هم‌پوشانی تقسیم شده‌اند و به‌سرعت به یک پرسش پاسخ می‌دهد: آیا این دو مقدار در یک گروه قرار دارند؟ این ساختار در واژگان [`disjoint-sets`][disjoint-sets] قرار دارد.

`<disjoint-set>` یک ساختار خالی می‌سازد. مقدارها، یعنی «اتم‌ها»، با `add-atom` اضافه می‌شوند، یا به‌صورت دسته‌ای با `add-atoms`؛ هر کدام در ابتدا در گروه خودش قرار می‌گیرد:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` گروه‌های شامل دو اتم را با هم متحد می‌کند. اتحاد خاصیت تعدی دارد: وقتی `equate` روی `a` و `b` و سپس روی `b` و `c` اجرا شود، هر سه در یک گروه مشترک قرار می‌گیرند.

```
equate ( atom1 atom2 disjoint-set -- )
```

هر گروه با یک عضو متعارف به نام «نماینده» مشخص می‌شود. `representative` آن را برمی‌گرداند، و دو اتم دقیقاً وقتی در یک گروه قرار دارند که نماینده‌هایشان برابر باشند. `equiv?` این بررسی را مستقیماً انجام می‌دهد:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

این‌که کدام اتم به عنوان نماینده‌ی یک گروه انتخاب می‌شود، یک جزئیات داخلی است؛ می‌تواند هر عضوی از گروه باشد و با ادغام گروه‌ها تغییر کند. هرگز به این‌که اتم خاصی نماینده باشد وابسته نشوید؛ فقط به این‌که دو اتم در یک گروه نماینده‌ی یکسان داشته باشند.

`disjoint-set-members` هر اتمی را که اضافه شده است برمی‌گرداند.

این ساختار «تغییرپذیر» است: `equate` و `add-atom` مجموعه‌ی مجزا را درجا تغییر می‌دهند، نه این‌که نسخه‌ی جدیدی برگردانند. پیاده‌سازی از اتحاد بر اساس رتبه همراه با فشرده‌سازی مسیر استفاده می‌کند، بنابراین زنجیره‌ی طولانی فراخوانی‌های `equate` و `representative` عملاً هر کدام زمان ثابت است.
