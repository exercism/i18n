# درباره

[Closures][closures] در Swift بلوک‌های کدی مستقل هستند که می‌توان پارامترهایی به آن‌ها داد تا محاسباتشان را انجام دهند و مقداری برگردانند.
closureها همچنین مقادیری را از محیط خود برمی‌دارند و در محاسباتشان به کار می‌گیرند.
چون مستقل‌اند، می‌توان آن‌ها را در برنامه مانند سایر مقادیر جابه‌جا کرد یا به ثابت‌ها و متغیرها اختصاص داد.

closureها ممکن است بسیار شبیه توابع Swift به نظر برسند؛ واقعاً همین‌طور است و دلیل خوبی هم دارد.
توابع در Swift حالت خاصی از closureها هستند که داشتن اسم برایشان الزامی است و با نحوه‌ی نگارش کمی متفاوت تعریف می‌شوند.

هرچند توابع در Swift از نظر فنی closure محسوب می‌شوند، وقتی مردم در Swift از «closureها» حرف می‌زنند، منظورشان [عبارت‌های closure][closure-expressions] است.
عبارت‌های closure به این شکل نوشته می‌شوند: فهرست پارامترها، سپس نوع بازگشتی، بعد کلیدواژه‌ی `in` و در پایان بدنه‌ی closure، که همه‌ی این‌ها داخل یک جفت آکولاد قرار می‌گیرند:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

این قطعه یک عبارت closure از نوع `(Double, Double) -> Double` تعریف می‌کند و می‌توان آن را همانند تابعی از همین نوع، با اعمال آن روی پارامترهایی از نوع مناسب، اجرا کرد:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

از آنجا که نوشتن کل عبارت closure هر بار که می‌خواهیم آن را اجرا کنیم چندان راحت نیست، می‌توان closureها را مانند هر مقدار دیگری در Swift به یک اسم اختصاص داد.
بعد می‌توان آن‌ها را با اعمال آن اسم روی پارامترها فراخوانی کرد:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

همان‌طور که در بالا دیدیم، closureها هم مانند توابع معمولی می‌توانند کلیدواژه‌ی `return` را حذف کنند، اگر بدنه‌ی closure تنها یک عبارت باشد.

بیشتر اوقات، closureها همراه با توابع مرتبه بالاتر به کار می‌روند: یا به عنوان پارامتر به آن‌ها داده می‌شوند یا به عنوان نتیجه برگردانده می‌شوند:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
