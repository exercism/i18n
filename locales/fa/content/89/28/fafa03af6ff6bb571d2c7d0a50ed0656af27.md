# مقدمه

در Swift، بستارها و توابع می‌توانند به ثابت‌ها و متغیرهای حوزه‌ی پیرامون خود دسترسی داشته باشند.
همچنین می‌توانند این دسترسی را حتی پس از پایان اجرای حوزه‌ی پیرامون حفظ کنند.
به این رفتار [«تسخیر مقادیر»][capturing-values] می‌گویند.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
    func adder(_ i: Int) -> Int {
        base + i
    }
    return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15

func makeLogger(logLevel: String) -> (String) -> Void {
    let logHeader = "[\(logLevel)]: "
    return { msg in print(logHeader, msg) }
}
// makeLogger: (String) -> (String) -> Void

let infoLogger = makeLogger(logLevel: "info")
// infoLogger: (String) -> Void

infoLogger("This is a log message")
// prints "[info]: This is a log message"
```

در مثال‌های بالا، هر دو `makeAdder(base:)` و `makeLogger(logLevel:)` توابع یا بستارهایی برمی‌گردانند که مقادیری را از حوزه‌ی پیرامون خود تسخیر می‌کنند.
توابع برگردانده‌شده همچنان به `base` و `logHeader` ارجاع می‌دهند، حتی پس از آنکه `makeAdder(base:)` و `makeLogger(logLevel:)` برگشته‌اند.

[capturing-values]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID103
