# راهنمایی‌ها

## کلی

- از لنزها در Roc زیاد استفاده نمی‌شود، چون نحوه‌ی نگارش به‌روزرسانی رکورد بیشتر موارد کاربرد را به‌خوبی پوشش می‌دهد.
  برای نمونه، این رکورد تودرتو را در نظر بگیرید:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  حالا بیایید به باب کوتاهی مو بدهیم:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  به هیچ لنزی نیاز نیست!

- با این حال، هرچند لنزها در Roc به‌ندرت به کار می‌روند، در زبان‌های دیگری مثل Haskell و Scala رایج‌اند؛ پس ممکن است کنجکاو باشید بدانید چطور می‌توان آن‌ها را در Roc پیاده‌سازی کرد.
  این همچنین راه خوبی برای تمرین برخی قابلیت‌های پیشرفته‌ی Roc است، مثل نوع‌های پارامتری و رکوردهایی که تابع در خود دارند.
  در واقع، یک روش برای نمایش یک لنز در Roc این است:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  این یک نوع پارامتری است: `whole` و `part` می‌توانند هر نوعی باشند.
  `whole` معمولاً یک رکورد است و `part` می‌تواند هر نوع فیلدی باشد.
  فیلد `get` تابعی را در خود دارد که یک `part` مشخص از `whole` داده‌شده را برمی‌گرداند و فیلد `set` تابعی را در خود دارد که نسخه‌ای از `whole` داده‌شده را برمی‌گرداند، با این تفاوت که یک `part` مشخص با `part` داده‌شده جایگزین شده است.

  برای نمونه، این لنزی است برای دریافت یا تنظیم موی یک فرد:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  می‌توانیم با این لنز روی موی باب تمرکز کنیم، به این شکل:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  و می‌توانیم موهایش را این‌طور تغییر دهیم:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- توجه: پرانتزهای دور `hair_lens.set` الزامی‌اند: بدون آن‌ها، Roc تابعی به اسم `set` را در نوع `hair_lens` جست‌وجو می‌کند.

- لنزها وقتی شروع به ترکیب کردن آن‌ها می‌کنید به‌ویژه سودمند می‌شوند و به شما اجازه می‌دهند بخش‌های عمیقاً تودرتو را دریافت و تنظیم کنید.
  این کار با پیاده‌سازی تابعی مثل این انجام می‌شود:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  وقتی این تابع پیاده‌سازی شد، می‌توانید با آن لنزی برای طول مو به این شکل بسازید:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  حالا می‌توانید یک کوتاهی موی دیگر به باب بدهید:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- شاید بخواهید تابعی هم پیاده‌سازی کنید که به شما اجازه دهد هر تبدیلی را روی یک بخش تودرتو اعمال کنید:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  پس از پیاده‌سازی، می‌توانید از `over` به این شکل استفاده کنید:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- پیشنهاد می‌کنیم اول تست‌ها را با نحوه‌ی نگارش به‌روزرسانی رکورد در Roc پاس کنید، بعد استفاده از لنزها را امتحان کنید.
