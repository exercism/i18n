# تست‌ها

از آنجا که OCaml یک زبان کامپایل‌شونده است، برای اجرای تست‌ها ابتدا باید پاسخ خود و کد تست را کامپایل کنید.
ما برای ساخت از [`dune`](https://dune.build/) استفاده می‌کنیم.
هر پوشه یک فایل `dune` دارد که نحوه‌ی ساخت را مشخص می‌کند و همچنین یک `Makefile` که کار ساخت را به dune واگذار می‌کند.

برای کامپایل و اجرای تست‌ها، کافی است از پوشه‌ی تمرین این دستور را بزنید:

```bash
make
```
