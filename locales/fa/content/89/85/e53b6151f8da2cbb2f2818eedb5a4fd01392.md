# مقدمه

در JavaScript، آرایه ساختاری شبیه به فهرست است که طول ثابتی ندارد و می‌تواند هر نوعی از مقادیر اولیه یا اشیاء را در خود نگه دارد، حتی ترکیبی از انواع مختلف.

برای ساختن آرایه، عنصرها را بین کروشه‌ها `[]` قرار دهید.
برای خواندن از آرایه، اندیس را داخل کروشه‌ها `[]` و بعد از شناسه قرار دهید.
اندیس‌های آرایه از صفر شروع می‌شوند.

برای مثال:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

برای به دست آوردن تعداد عنصرهایی که در یک آرایه هستند، از ویژگی `length` استفاده کنید:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

برای تغییر یک عنصر در آرایه، مقداری را در آن اندیس قرار می‌دهید:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## متدها

برخی از [متدها][array_methods] را که روی هر شیء `Array` در دسترس‌اند، می‌توان برای افزودن عنصر به آرایه یا حذف عنصر از آن به کار برد.

### push

> متد `push()` یک یا چند عنصر را به انتهای آرایه اضافه می‌کند و طول جدید آرایه را برمی‌گرداند.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> متد `pop()` آخرین عنصر آرایه را حذف می‌کند و همان عنصر را برمی‌گرداند.
> این متد طول آرایه را تغییر می‌دهد.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> متد `shift()` اولین عنصر آرایه را حذف می‌کند و آن عنصر حذف‌شده را برمی‌گرداند.
> این متد طول آرایه را تغییر می‌دهد.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> متد `unshift()` یک یا چند عنصر را به ابتدای آرایه اضافه می‌کند و طول جدید آرایه را برمی‌گرداند.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> متد `splice()` محتوای آرایه را با حذف یا جایگزینی عنصرهای موجود و/یا افزودن عنصرهای جدید در همان‌جا تغییر می‌دهد. این متد آرایه‌ای را برمی‌گرداند که شامل عنصرهای حذف‌شده است.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
