# دستورالعمل‌ها

الیس به‌عنوان یک شعبده‌باز تازه‌کار باید چند مقدمه را تمرین کند.
او یک دسته کارت دارد که می‌خواهد آن‌ها را دست‌کاری کند.

برای اینکه کار کمی ساده‌تر شود، فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند، بنابراین دسته‌ی کارت‌هایش را می‌توان با یک بردار از اعداد نمایش داد.
موقعیت یک کارت مشخص با اندیس آن در بردار متناظر است.

## 1. برداشتن یک کارت از دسته

برای برداشتن یک کارت، کارت واقع در اندیس `position` را از دسته‌ی داده‌شده برگردانید.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. تعویض یک کارت در دسته

کمی تردستی کنید و کارت واقع در اندیس `position` را با کارت جایگزینی که داده شده است عوض کنید.
دسته‌ی تغییرداده‌شده را برگردانید.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. درج یک کارت در بالای دسته

با درج یک کارت جدید در بالای دسته، کارتی را ظاهر کنید.
دسته‌ی تغییرداده‌شده را برگردانید.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. حذف یک کارت از دسته

با حذف کارت واقع در `position` داده‌شده از دسته، کارتی را ناپدید کنید.
دسته‌ی تغییرداده‌شده را برگردانید.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. حذف کارت بالای دسته

با حذف کارت بالای دسته، کارتی را ناپدید کنید.
دسته‌ی تغییرداده‌شده را برگردانید.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. درج یک کارت در پایین دسته

با درج یک کارت جدید در پایین دسته، کارتی را ظاهر کنید.
دسته‌ی تغییرداده‌شده را برگردانید.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. حذف یک کارت از پایین دسته

با حذف کارت پایین دسته، کارتی را ناپدید کنید.
دسته‌ی تغییرداده‌شده را برگردانید.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. بررسی اندازه‌ی دسته

بررسی کنید که اندازه‌ی دسته با `stack_size` برابر است یا نه.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
