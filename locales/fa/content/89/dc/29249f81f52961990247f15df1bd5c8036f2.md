# رشته

یک «رشته» مجموعه‌ای از نویسه‌ها است که بین دو گیومه قرار می‌گیرد.
از هر دو گیومه‌ی تک و دوتایی پشتیبانی می‌شود.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## درج متغیر در رشته

در رشته‌های داخل گیومه‌ی دوتایی، اگر به متغیری ارجاع داده شود که در محدوده‌ی دید قرار دارد، مقدار آن داخل رشته درج می‌شود.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## پشتیبانی از کدگذاری نویسه‌ها

از نظر تاریخی، توابع رشته در PHP فقط از نویسه‌های ASCII پشتیبانی می‌کردند و از کدگذاری‌های مدرن یونیکد پشتیبانی نمی‌کردند.
هر نویسه‌ی ASCII یک بایت است، در حالی که طول نویسه‌های یونیکد می‌تواند بین ۱ تا ۴ بایت باشد.
اگر لازم است رشته‌های یونیکد را به‌شکل ایمن دست‌کاری کنید، به [نسخه‌های چندبایتی][multi-byte-fns] همان توابع قدیمی مراجعه کنید.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
