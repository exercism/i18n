# پیوست توضیحات

## دستور `apply` در Tcl

ممکن است موارد آزمون گیج‌کننده به نظر برسند.
انتظار می‌رود این را پیاده‌سازی کنید:

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

چرا آن آخرین آرگومان این‌قدر آکولاد دارد؟

به یاد بیاورید که دستور `proc` این‌گونه تعریف می‌شود:

```tcl
proc procName argList body
```

Tcl یک دستور `apply` دارد:

```tcl
apply func ?arg1 arg2 ...?
```

این «func» یک فهرست دو عضوی `{argList body}` است که در اصل یک `proc` بی‌نام (یا «lambda») به شمار می‌رود.
دستور `apply` آن `proc` بی‌نام را فراخوانی می‌کند و آرگومان‌های موردنیازش را به آن می‌فرستد.

برای نمونه، این‌ها معادل هم هستند:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

استفاده از `apply` جابه‌جایی بلوک‌های کد را ساده‌تر می‌کند.

مرجع: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm)، [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
