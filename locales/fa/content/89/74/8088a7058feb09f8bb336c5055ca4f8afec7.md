# درباره

## اصطلاحات

شما پیش‌تر در چند مفهوم، توابع C++ را هم استفاده کرده‌اید و هم نوشته‌اید.
حالا وقت آن است که فنی شویم.
قطعه‌کد زیر پرکاربردترین اصطلاحات را برای مراجعه‌ی آسان نشان می‌دهد.
از آنجا که C++ فضای سفید را نادیده می‌گیرد، قالب‌بندی تغییر کرده تا هر عنصر در یک خط قرار بگیرد.

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
اعلان مانند یادداشتی برای کامپایلر عمل می‌کند که تابعی با آن اسم، آن نوع بازگشتی و آن فهرست پارامترها وجود دارد.
اگر تعریف نباشد، کد کار نخواهد کرد.
اعلان‌ها اختیاری‌اند؛ اگر تابع را پیش از تعریفش استفاده کنید، به آن‌ها نیاز دارید.
اعلان‌ها می‌توانند مسائلی مانند ارجاع‌های چرخه‌ای را حل کنند و می‌توان از آن‌ها برای جدا کردن رابط از پیاده‌سازی استفاده کرد.
~~~~

## قید `const`

گاهی می‌خواهید مطمئن شوید که مقادیر پس از مقداردهی اولیه قابل تغییر نیستند.
C++ از «کلیدواژه»ی `const` به‌عنوان قیدی برای ثابت‌ها استفاده می‌کند.

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
اغلب خواهید دید که ثابت‌ها را با قالب _UPPER_SNAKE_CASE_ می‌نویسند.
اگر قرارداد دیگری وجود نداشته باشد، توصیه می‌شود این قالب حروف را برای ماکروها نگه دارید.
~~~~

اگر بخواهید متغیر ثابتی را پس از تنظیم شدن تغییر دهید، کد شما کامپایل نخواهد شد.
این کار به جلوگیری از تغییرات ناخواسته کمک می‌کند و همچنین امکان‌های بهینه‌سازی را برای کامپایلر فراهم می‌کند.
به‌عنوان یک انسان هم، اگر بدانید که بخش‌های خاصی تحت تأثیر قرار نمی‌گیرند، استدلال درباره‌ی کد آسان‌تر است.

می‌توانید `const` را به‌عنوان قید برای پارامترهای تابع هم داشته باشید.

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

وقتی یک ارجاع `const` را به تابع می‌دهید، می‌توانید مطمئن باشید که بدون تغییر باقی می‌ماند.
اغلب ارجاع‌های `const` را برای اشیائی خواهید دید که کپی کردنشان ممکن است پرهزینه باشد، مثل رشته‌های طولانی‌تر.
سومین مورد استفاده‌ی قید `const` هم توابع عضو هستند که نمونه‌ی یک کلاس را تغییر نمی‌دهند.

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return "";}
        return response;
    }
    private:
    string response{};
};
```

تابع عضو `answer` در `Stubborn` از یک ارجاع `const string&` به‌عنوان پارامتر استفاده می‌کند.
این کار از یک عملیات کپی از شیء اصلی که به تابع داده شده بود جلوگیری می‌کند.

## بارگذاری بیش‌ازحد تابع

چندین تابع می‌توانند اسم یکسان داشته باشند، به شرطی که فهرست پارامترهایشان متفاوت باشد.
به این کار بارگذاری بیش‌ازحد تابع می‌گویند و معمولاً وقتی انجام می‌شود که این توابع کارهای بسیار مشابهی انجام دهند.

سرآیند تابع بدون نوع بازگشتی، __امضای نوع__ تابع است.
تغییر در امضای نوع، به تابعی جدید منجر می‌شود.

مثال `play_sound` شش بارگذاری بیش‌ازحد متفاوت دارد تا سناریوهای مختلف را پوشش دهد:

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
امضای نوع با اسم تابع، تعداد پارامترها، نوع‌هایشان و قیدهایشان تعریف می‌شود (اما نه اسم‌هایشان).
نوع بازگشتی صراحتاً بخشی از امضای نوع نیست و اگر دو تابع داشته باشید که فقط در نوع بازگشتی تفاوت دارند، خطاهای کامپایل خواهید گرفت.
کامپایلر شکایت می‌کند، چون روشن نیست کدام‌یک از آن دو باید استفاده شود.
~~~~

## آرگومان‌های پیش‌فرض

بعضی توابع می‌توانند بسیار طولانی شوند و ممکن است بسیاری از فراخوانی‌هایشان برای بیشتر پارامترها از مقادیر یکسان استفاده کنند.
با آرگومان‌های پیش‌فرض می‌توان از تکرار در آن فراخوانی‌ها جلوگیری کرد.

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

از آنجا که اعلان تابع اغلب پیش از تعریف خوانده می‌شود، جای بهتری برای تنظیم آرگومان‌های پیش‌فرض است.
اگر یک پارامتر اعلان پیش‌فرض داشته باشد، همه‌ی پارامترهای سمت راست آن هم باید اعلان پیش‌فرض داشته باشند.
گاهی می‌توان بارگذاری‌های بیش‌ازحد پیچیده‌ی تابع را به توابع کمتری با آرگومان‌های پیش‌فرض بازآرایی کرد تا نگهداری‌پذیری بهبود یابد.
