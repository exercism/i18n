# درباره‌ی شرط‌ها

## عملگرهای مقایسه

[عملگرهای مقایسه][operators] شبیه بسیاری از زبان‌های دیگرند، با چند تفاوت.

برای برابری، عملگرها `==` (برابر) و `!=` (نابرابر) هستند.

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

علاوه بر این، عملگرهای `===` و `!==` [«برابری ارجاعی»][referential-equality] را بررسی می‌کنند: `a === b` اگر و تنها اگر `a` و `b` به یک شیء یکسان اشاره کنند.
این موضوع بعداً در سرفصل‌ها بیشتر روشن می‌شود.

عملگرهای بزرگ‌تر و کوچک‌تر هم قراردادی هستند.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## انشعاب با `if`

این شکل کامل یک [`if` expression][if-else] است:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- پرانتزهای `()` دور هر شرط الزامی‌اند.
- یک شرط باید به یک مقدار «منطقی» یعنی `true` یا `false` ارزیابی شود.
  Kotlin مفهومی به نام «truthy» و «falsy» که در برخی زبان‌ها هست، ندارد.
- اگر تنها یک عبارت وجود داشته باشد، آکولادهای `{}` اختیاری‌اند.
- هم `else if` و هم `else` اختیاری‌اند و می‌توان چندین بلوک `else if` داشت.

از عبارت `if` می‌توان برای «انتخاب» یک مقدار هم استفاده کرد:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## راه‌های جایگزین؟

به شکلی آگاهانه، Kotlin عملگر سه‌گانه‌ی `? :` را که در Java وجود دارد، _ندارد_.
شکل مختصر `if ... else` ترجیح داده می‌شود:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

برخلاف Ruby، شکل مختصر `if ... else` *همیشه* به یک `else` نیاز دارد و بنابراین نمی‌توان از آن به عنوان دستور محافظ استفاده کرد:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

توجه کنید که در Kotlin، `if` یک [_عبارت_][expression] است که مقداری برمی‌گرداند.
این یک [_دستور_][statement] نیست، آن‌گونه که در Java هست.

در یکی از مفهوم‌های بعدی خواهیم دید که Kotlin ساختار قدرتمند [`when`][when] را دارد که برای جایگزین کردن زنجیره‌های بلند بندهای `else if` با تطبیق الگو در نظر گرفته شده است.
