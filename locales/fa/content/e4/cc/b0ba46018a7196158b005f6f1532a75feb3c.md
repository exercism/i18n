# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به یک شرکت تابلوهای تبلیغاتی کمک می‌کند پیام‌های سفارشی برای تابلوهایش بسازد.

## 1. ساخت تابلوی مناسبتی

تابع `buildSign(occasion, name)` را پیاده‌سازی کنید که یک رشته را به عنوان پارامتر `occasion` و رشته‌ای را که اسم یک شخص در خود دارد به عنوان پارامتر `name` می‌پذیرد.
این دو پارامتر در یک رشته‌ی قالبی جای می‌گیرند تا پیام روی تابلو تولید شود.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. ساخت تابلوی تولد

تابع `buildBirthdaySign(age)` را پیاده‌سازی کنید که یک سن را می‌پذیرد و بر اساس آن سن، بخشی از پیام روی تابلو را مشخص می‌کند.
اگر سن ۵۰ یا بیشتر باشد، تابلو کاربر را _mature_ خطاب می‌کند؛ در غیر این صورت او را _young_ خطاب می‌کند.
خروجی دقیق مورد انتظار در زیر نشان داده شده است:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. ساخت تابلوی فارغ‌التحصیلی

تابع `graduationFor(name, year)` را پیاده‌سازی کنید که یک اسم را به عنوان پارامتر رشته‌ای و یک سال را به عنوان پارامتر عددی می‌گیرد و با درج مقادیر در رشته، عبارتی برای تابلو می‌سازد. این عبارت از یک خط جدید برای جدا کردن دو خط پیام استفاده می‌کند.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. محاسبه‌ی هزینه‌ی تابلو

تابع `costOf(sign, currency)` را پیاده‌سازی کنید که محتوای تابلو را در قالب یک رشته و واحد پول را در قالب رشته‌ای دیگر می‌گیرد.
قیمت پایه‌ی تابلو، ۲۰ واحد از واحد پول داده‌شده است. علاوه بر آن، هر حرف ۲ هزینه دارد. (فاصله‌ها نیز در محاسبه لحاظ می‌شوند.)
عبارتی که برگردانده می‌شود، هزینه‌ی ساخت تابلو را در بر می‌گیرد که با دو رقم اعشار نوشته می‌شود و پس از آن رشته‌ی واحد پول می‌آید.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
