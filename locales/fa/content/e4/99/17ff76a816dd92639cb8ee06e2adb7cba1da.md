# مقدمه

«آرایه» دنباله‌ای با طول ثابت در Factor است: می‌توانید عناصر آن را تغییر دهید، اما طول آن را نه. شما پیش‌تر می‌دانید چطور یک آرایه‌ی تحت‌اللفظی بنویسید، یعنی `{ … }`، و چطور یک آرایه را برش دهید و تجمیع کنید. این تمرین مجموعه‌ی کوچکی از ابزارها را پوشش می‌دهد که هنگام ساختن آرایه از مقادیر روی پشته و سپس جست‌وجو یا بازچینش محتویات آن به کار می‌آید.

## ساختن از روی پشته

`1array`، `2array`، `3array` و `4array` (در [`arrays`][arrays]) ۱، ۲، ۳ یا ۴ مقدار را از بالای پشته برمی‌دارند و آن‌ها را در یک بسته جمع می‌کنند:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## به هم پیوستن

`concat` (در [`sequences`][sequences]) دنباله‌ای را می‌گیرد که عناصر آن خودشان دنباله‌اند و آن‌ها را به اندازه‌ی ۱ سطح صاف می‌کند. `join` همین کار را می‌کند، با این تفاوت که میان هر دو عنصر پشت‌سرهم یک جداکننده می‌گذارد:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## معکوس کردن

`reverse` دنباله‌ی جدیدی برمی‌گرداند که عناصر آن در ترتیب معکوس قرار دارند:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## آیا آرایه است؟

`array?` (در [`arrays`][arrays]) گزاره‌ی نوع است. برای هر مقداری که با `<array>`، `1array`/`2array`/... یا یک آرایه‌ی تحت‌اللفظی `{ … }` ساخته شده باشد «درست» است و برای هر مورد دیگری (از جمله بردارها، رشته‌ها و سایر دنباله‌ها) «غلط»:

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## جست‌وجو کردن

`index` موقعیت نخستین عنصر برابر با مقدار ورودی را برمی‌گرداند و اگر آن مقدار وجود نداشته باشد، `f` را برمی‌گرداند. `member?` فقط یک «مقدار منطقی» را برمی‌گرداند. هر دو ابتدا **عنصر** و بعد **دنباله** را می‌گیرند. `members` (در [`sets`][sets]) عناصر *یکتا*ی یک دنباله را برمی‌گرداند (همان عملیات حذف تکراری‌ها) و `all-unique?` (همچنین در `sets`) بررسی می‌کند که آیا دنباله از پیش عناصر تکراری ندارد:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
