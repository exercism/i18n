# درباره

`case` در Factor یک انتخاب چندشاخه‌ای مبتنی بر برابری است. ابزار درست برای زمانی است که انتخاب به برابر بودن یک مقدار *تک* با یکی از چند گزینه بستگی دارد، نه زمانی که هر شاخه به آزمون متفاوتی نیاز دارد (برای آن از `cond` استفاده کنید).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

چند نکته که خوب است در ذهن داشته باشید:

- برابری همان `=` است. هر چیزی که با `=` کار کند می‌تواند به‌عنوان کلید به کار برود: عددها، رشته‌ها، کاراکترها، نمادها و حتی تاپل‌ها.
- شاخه‌های *منطبق‌شده* پشته را *بدون* مقدار ورودی می‌بینند. شاخه‌های *پیش‌فرض* آن را همچنان در بالای پشته می‌بینند.
- یک `case` بدون شاخه‌ی پیش‌فرض که هیچ بند منطبقی هم نداشته باشد، خطا پرتاب می‌کند.

`case` در صورت امکان به یک جدول پرش کامپایل می‌شود، بنابراین فقط شکر نحوی برای یک زنجیره‌ی `if` نیست؛ سریع هم هست.
