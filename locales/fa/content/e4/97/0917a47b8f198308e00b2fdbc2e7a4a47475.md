# درباره

هاکس دو نوع عدد دارد: اعداد صحیح و اعداد اعشاری:

- `Int`: یک عدد صحیح را نمایش می‌دهد.
- `Float`: یک عدد اعشاری ۶۴بیتی با دقت مضاعف را نمایش می‌دهد.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

هر `Int` را می‌توان در جایی به کار برد که `Float` انتظار می‌رود (یعنی `Int` **قابل انتساب به** `Float` است یا **با `Float` یکی می‌شود`)، اما عکس آن درست نیست: انتساب یک `Float` به `Int` ممکن است باعث از دست رفتن دقت شود و بنابراین به‌صورت ضمنی مجاز نیست.

## مقایسه

اعداد در صورتی برابرند که مقدار یکسانی داشته باشند.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```
