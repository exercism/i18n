# مقدمه

Kotlin یک زبان برنامه‌نویسی **ایستا نوع‌بندی‌شده** است که توسط JetBrains توسعه یافته است. این یعنی نوع متغیرها در زمان کامپایل تعیین می‌شود.

## متغیرها

مشابه دیگر زبان‌های برنامه‌نویسی ایستا نوع‌بندی‌شده، نوع هر متغیر باید در زمان کامپایل تعیین شود. هرجا کامپایلر بتواند نوع را از بافت خودش استنتاج کند، می‌توانید از اعلان صریح نوع خودداری کنید.

Kotlin متغیرهای تغییرناپذیر (`val`) و تغییرپذیر (`var`) دارد. پس از اینکه مقدار اولیه‌ی یک متغیر تغییرناپذیر تعیین شد، مقدارش دیگر قابل تغییر نیست. بیشتر اوقات از همین نوع متغیر استفاده خواهید کرد.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

مقدار یک متغیر تغییرپذیر می‌تواند یک یا چند بار تغییر کند:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

نقطه‌ویرگول‌ها در Kotlin اختیاری هستند، به‌جز چند مورد خاص که بعداً به آن‌ها می‌پردازیم.

## توابع

توابع در Kotlin با کلیدواژه‌ی `fun` تعریف می‌شوند و _شهروندان درجه‌یک_ هستند (ربطی به برنامه‌نویسی شی‌گرا ندارند). یعنی می‌توانید آن‌ها را مستقیماً در فایل‌ها اعلان کنید (به این‌ها `top-level functions` می‌گویند). مثلاً در Java می‌توانید متدها را فقط در کلاس‌ها تعریف کنید، نه در فایل‌ها:

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

توابع می‌توانند آرگومان دریافت کنند. هر آرگومان یک اسم و یک نوع دارد. برخلاف متغیرها، نوع آرگومان‌ها قابل استنتاج نیست. توابع می‌توانند صفر یا چند آرگومان داشته باشند:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

توابع Kotlin ممکن است مقداری برگردانند یا برنگردانند:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

برای برگرداندن یک مقدار از یک تابع، از کلیدواژه‌ی `return` استفاده می‌شود:

```kotlin
fun getName(): String {
    return "Alice"
}
```

توابع می‌توانند پارامترهایی با مقدار پیش‌فرض داشته باشند. اگر هنگام فراخوانی تابع این پارامترها حذف شوند، از همین مقادیر استفاده می‌شود:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## کامنت‌ها

برای تعریف کامنت تک‌خطی از `//` استفاده کنید:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

یا برای تعریف کامنت‌های چندخطی از `/*` و `*/` استفاده کنید:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
