# درباره

JavaScript زبانی پویا و مبتنی بر نمونه‌ی اولیه است. چند [«مقدار اولیه»][mdn-primitive] دارد و بقیه شیء در نظر گرفته می‌شوند.

هرچند بیشتر به عنوان زبان اسکریپت‌نویسی صفحات وب شناخته می‌شود، محیط‌های غیرمرورگری بسیاری هم از آن استفاده می‌کنند، مثلاً Node.js. این زبان فعالانه در حال توسعه است و چون چندپارادایمی است، سبک‌های برنامه‌نویسی گوناگونی را ممکن می‌کند. JavaScript زبانی پویاست که سبک‌های شیءگرا، دستوری و اعلانی (مثلاً برنامه‌نویسی تابعی) را پشتیبانی می‌کند.

## انتساب (و انتساب مجدد)

راه‌های اصلی چندی برای انتساب مقدار به اسم در JavaScript وجود دارد: استفاده از متغیر یا ثابت. در Exercism، متغیرها همیشه به شکل [camelCase][wiki-camel-case] نوشته می‌شوند؛ ثابت‌ها به شکل [SCREAMING_SNAKE_CASE][wiki-snake-case]. راهنمای رسمی‌ای برای پیروی وجود ندارد و شرکت‌ها و سازمان‌های مختلف راهنمای سبک متفاوتی دارند. _راحت باشید و متغیرها را هر طور که می‌خواهید بنویسید_. مزیت نوشتن آن‌ها به همان شکلی که تمرین‌ها آماده شده‌اند این است که در رابط وب و بیشتر IDEها به شکل متفاوتی برجسته می‌شوند.

متغیرها در JavaScript را می‌توان با «کلیدواژه»ی [`const`][mdn-const]، [`let`][mdn-let] یا [`var`][mdn-var] تعریف کرد.

یک متغیر هنگام استفاده از `let` یا `var` می‌تواند در طول عمرش به مقدارهای متفاوتی اشاره کند. برای مثال، `myFirstVariable` را می‌توان با عملگر انتساب `=` بارها تعریف و بازتعریف کرد:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

برخلاف `let` و `var`، متغیرهایی که با `const` تعریف می‌شوند فقط یک بار می‌توانند مقدار بگیرند. از این ویژگی برای تعریف ثابت‌ها در JavaScript استفاده می‌شود.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

### انتساب ثابت

کلیدواژه‌ی `const` _هم_ برای متغیرها و هم برای ثابت‌ها به کار می‌رود. مفهوم دیگری که در کنار ثابت‌ها زیاد مطرح می‌شود [(نا)تغییرپذیری][wiki-mutability] است.

کلیدواژه‌ی `const` فقط _اتصال_ را تغییرناپذیر می‌کند، یعنی به یک متغیر `const` فقط یک بار می‌توان مقدار انتساب داد. در JavaScript تنها [مقدارهای اولیه][mdn-primitive] تغییرناپذیرند. با این حال، [مقدارهای غیراولیه][mdn-primitive] هنوز می‌توانند تغییر کنند.

```javascript
const MY_MUTABLE_VALUE_CONSTANT = { food: 'apple' };

// This is possible
MY_MUTABLE_VALUE_CONSTANT.food = 'pear';

MY_MUTABLE_VALUE_CONSTANT;
// => { food: "pear" }
```

### مقدار ثابت (تغییرناپذیری)

به عنوان یک قاعده، در Exercism و بسیاری از سازمان‌ها و راهنماهای سبک پروژه‌ها، مقدارهایی را که به شکل `const SCREAMING_SNAKE_CASE` هستند تغییر ندهید. از نظر فنی _می‌توان_ این مقدارها را تغییر داد، اما برای شفافیت و مدیریت انتظارها در Exercism این کار توصیه نمی‌شود. وقتی _باید_ این کار اعمال شود، از [`Object.freeze(value)`][mdn-object-freeze] استفاده کنید.

```javascript
const MY_VALUE_CONSTANT = Object.freeze({ food: 'apple' });

// This silently fails
MY_VALUE_CONSTANT.food = 'pear';

MY_VALUE_CONSTANT;
// => { food: "apple" }
```

در عمل، بعید است `Object.freeze` را در سراسر یک کدبیس ببینید، اما این قاعده که هرگز مقدار `SCREAMING_SNAKE_CASE` را تغییر ندهید قاعده‌ی خوبی است و اغلب با تحلیل خودکار مانند linter اعمال می‌شود.

## اعلان توابع

در JavaScript، واحدهای کارکرد در _توابع_ کپسوله می‌شوند و معمولاً اگر توابع به هم مربوط باشند در یک فایل کنار هم قرار می‌گیرند. این توابع می‌توانند پارامتر (آرگومان) بگیرند و با کلیدواژه‌ی `return` مقداری را _برگردانند_. توابع با نحوه‌ی نگارش `()` فراخوانی می‌شوند.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 در JavaScript _راه‌های_ متفاوت زیادی برای اعلان یک تابع وجود دارد. این راه‌های دیگر با استفاده از کلیدواژه‌ی `function` متفاوت به نظر می‌رسند. این ترک تلاش می‌کند آن‌ها را به تدریج معرفی کند، اما اگر از قبل با آن‌ها آشنا هستید، راحت باشید و از هر کدامشان استفاده کنید. در بیشتر موارد، استفاده از یکی یا دیگری بهتر یا بدتر نیست.

## صادر کردن و وارد کردن

کلیدواژه‌های `export` و `import` ابزارهای قدرتمندی هستند که یک فایل معمولی JavaScript را به یک [ماژول JavaScript][mdn-module] تبدیل می‌کنند. علاوه بر اینکه به کد اجازه می‌دهند اجزایی مانند توابع، کلاس‌ها، متغیرها و ثابت‌ها را به صورت انتخابی در معرض دید بگذارد، طیف کاملی از ویژگی‌های دیگر را نیز ممکن می‌کنند، از جمله:

- [تغییر نام صادرات‌ها و واردات‌ها][mdn-renaming-modules] که به شما امکان می‌دهد از تضاد نام‌ها جلوگیری کنید،
- [واردات پویا][mdn-dynamic-imports] که کد را در صورت نیاز بارگذاری می‌کند،
- [Tree shaking][blog-tree-shaking] که با حذف ماژول‌های بدون عارضه‌ی جانبی و حتی محتوای ماژول‌هایی _که استفاده نمی‌شوند_ اندازه‌ی کد نهایی را کاهش می‌دهد،
- صادر کردن [_اتصال‌های زنده_][blog-live-bindings] که به شما امکان می‌دهد مقداری را صادر کنید که در صورت تغییر مقدار اصلی، هر جا وارد شده باشد تغییر می‌کند.

یک مثال عینی نحوه‌ی کار تست‌ها در ترک JavaScript در Exercism است. هر تمرین دست‌کم یک فایل پیاده‌سازی دارد، مثلاً `lasagna.js`، و هر تمرین دست‌کم یک فایل تست دارد، مثلاً `lasagna.spec.js`. فایل پیاده‌سازی از `export` برای در معرض دید گذاشتن API عمومی استفاده می‌کند و فایل تست از `import` برای دسترسی به آن‌ها استفاده می‌کند و به این ترتیب می‌تواند نتایج پیاده‌سازی را بیازماید.

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
