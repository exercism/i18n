# حلقه‌ی For

حلقه‌زنی مفهومی بنیادین در برنامه‌نویسی است که به شما امکان می‌دهد یک بلوک کد را چندین بار اجرا کنید.
در Swift دو نوع حلقه وجود دارد: [حلقه‌های `for-in`][for-loops] و حلقه‌های `while`.
در این فصل، با حلقه‌های `for-in` آشنا می‌شوید.

حلقه‌های For به شما امکان می‌دهند روی دنباله‌ای از مقادیر پیمایش کنید، هر عنصر را به نوبت بردارید و آن را به متغیری که خودتان انتخاب می‌کنید مقید کنید.
Swift به شما امکان می‌دهد روی انواع گوناگونی از دنباله‌ها پیمایش کنید، مانند بازه‌ها، آرایه‌ها و رشته‌ها (و انواع دیگری که بعداً به آن‌ها می‌پردازیم).
وقتی روی همه‌ی عناصر دنباله پیمایش شد، حلقه پایان می‌یابد.

حلقه‌های For با استفاده از «کلیدواژه»ی `for` اعلان می‌شوند؛ پس از آن اسم یک متغیر، کلیدواژه‌ی `in` و یک دنباله از مقادیر برای پیمایش می‌آید.
متغیری که در حلقه‌ی `for-in` داده می‌شود تغییرناپذیر است، یعنی نمی‌توانید مقدارش را درون حلقه تغییر دهید.
در ادامه نمونه‌ای از یک حلقه‌ی `for-in` را می‌بینید که روی آرایه‌ای از اعداد پیمایش می‌کند:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
متغیر `number` در حلقه‌ی `for-in` اعلان می‌شود و فقط در محدوده‌ی همان حلقه در دسترس است.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## پیمایش روی یک بازه

می‌توانید با یک حلقه‌ی `for-in` روی بازه‌ای از اعداد هم پیمایش کنید.
این کار به شما امکان می‌دهد یک بلوک کد را به تعداد مشخصی بار اجرا کنید؛ برای مثال، بازه‌ی `1...5` روی اعداد ۱، ۲، ۳، ۴ و ۵ پیمایش می‌کند، پس حلقه ۵ بار اجرا می‌شود.
گاهی ممکن است بخواهید روی اندیس‌ها در ساختار داده‌ای مانند آرایه پیمایش کنید؛ در این صورت می‌توانید از بازه‌ی `0..<array.count` استفاده کنید.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## پیمایش روی یک رشته

می‌توانید با یک حلقه‌ی `for-in` روی یک رشته هم پیمایش کنید.
این کار به شما امکان می‌دهد روی هر نویسه در رشته پیمایش کنید؛ و توجه کنید که نوع داده‌ی داده‌شده در حلقه `Character` است.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift همچنین تابعی به نام `stride` ارائه می‌دهد که به شما امکان می‌دهد دنباله‌ای روی یک بازه با گام مشخص بسازید.
که سپس می‌توان با یک حلقه‌ی `for-in` روی آن پیمایش کرد.
`stride` به‌صورت [`stride(from:to:by:)`][stride-to] یا [`stride(from:through:by:)`][stride-through] تعریف شده است؛ اولی انحصاری است و دومی شامل.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

توجه کنید که پارامتر `to` انحصاری است، بنابراین حلقه تا عدد پیش از پارامتر `to` پیمایش می‌کند؛ در حالی که پارامتر `through` شامل است، پس در این حالت عدد `10` را هم در بر می‌گیرد.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
