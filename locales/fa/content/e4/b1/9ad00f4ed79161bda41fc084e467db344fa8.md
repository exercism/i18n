# منابع

## ماژول‌ها

Perl همراه با مجموعه‌ای از ماژول‌های هسته عرضه می‌شود که فهرستشان را می‌توانید در [perldoc](https://perldoc.perl.org/modules) ببینید. معمولاً می‌توانید هر یک از این ماژول‌ها را بلافاصله به کار ببرید. (بعضی از توزیع‌ها ممکن است لازم باشد ماژول‌های هسته را جداگانه نصب کنید.)

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) فهرستی گزیده از ماژول‌های مفید است و به مجموعه‌ای از فهرست‌های پیشنهادی دیگر هم اشاره می‌کند.

چندین نصب‌کننده‌ی ماژول برای Perl در دسترس است که به شما امکان می‌دهند طیف گسترده‌ای از ماژول‌های موجود در [CPAN](https://metacpan.org/) را نصب کنید.

### App::cpm
یک نصب‌کننده‌ی ماژول بسیار سریع و سرراست.
آموزشی هم در [CPAN](https://metacpan.org/pod/App::cpm::Tutorial) در دسترس است.

اگر دستورهای `local::lib` را از [مستندات نصب](https://exercism.org/tracks/perl5/installation) دنبال کرده باشید، این ابزار از قبل نصب شده است.

کافی است `cpm install` را اجرا کنید تا ماژول‌های موردنیاز از یک `cpanfile` نصب شوند. برای نصب ماژول‌های توصیه‌شده یا پیشنهادی هم به‌ترتیب از `--with-recommends` یا `--with-suggested` استفاده کنید.

برای نصب محلی یک ماژول مشخص، `cpm install Module::Name` را اجرا کنید، یا برای نصب سراسری، `cpm install -g Module::Name` را اجرا کنید.

### App::cpanminus
شناخته‌شده‌ترین و پرکاربردترین نصب‌کننده‌ی ماژولی که در دسترس است.
دستورهای نصب را می‌توانید در [CPAN](https://metacpan.org/pod/App::cpanminus) پیدا کنید.

برای نصب ماژول‌های موردنیاز از یک `cpanfile`، `cpanm -L local --installdeps .` را اجرا کنید.
برای نصب محلی یک ماژول مشخص، `cpanm -L local Module::Name` را اجرا کنید، یا برای نصب سراسری `cpanm Module::Name` را اجرا کنید.

## سبک کد و لینت

اگر دنبال توصیه‌های کلی خوب درباره‌ی کدنویسی به زبان Perl هستید، کتاب [Perl Best Practices][PBP] نوشته‌ی Damian Conway مرجع خوبی است.

برای زیباتر کردن کدتان می‌توانید از ماژول [Perl::Tidy][PerlTidy] استفاده کنید.

سپس می‌توانید با برنامه‌ی کمکی `perltidy` که همراه آن ارائه می‌شود کدتان را دوباره قالب‌بندی کنید.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy` گزینه‌های پیکربندی *بسیار زیادی* دارد که هر سلیقه‌ای را پوشش می‌دهد. مستنداتشان [اینجا][perltidyDocs] آمده است.

همچنین [tidyview] یک رابط بصری است که به شما اجازه می‌دهد گزینه‌های مختلف را تنظیم کنید و نتیجه را بیدرنگ ببینید.

اگر می‌خواهید شیوه‌های کدنویسی را الزامی کنید، [Perl::Critic][perlcritic] هم هست. این ابزار قواعدی را که در کتاب *Perl Best Practices* پیش‌تر اشاره شد در خود دارد، اما افزونه‌های زیادی برایش وجود دارد و می‌توان آن را برای هر مجموعه‌قواعد درون‌سازمانی سفارشی کرد.

برای استفاده:

    $ perlcritic some_script.pl

این ابزار تنظیمات پیکربندی بسیار زیادی دارد؛ برای اطلاع کامل از آن‌ها [مستندات][perlcriticdocs] آن را ببینید.
