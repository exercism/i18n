# مقدمه

فرض کنید همه‌ی اعداد صحیح نامنفی تا ۱۰۰۰ را می‌خواهید.
اگر مجبور بودید همه‌ی آن‌ها را در یک آرایه تایپ کنید، واقعاً مسخره می‌شد.

برای همین، نوع `range` را داریم:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

بازه‌ها بسیار رایج‌اند: نه فقط برای اینکه در تایپ کردن صرفه‌جویی شود، بلکه به عنوان نوع بازگشتی توابع هم به کار می‌روند.

توجه کنید که بازه‌ها _بردار_ نیستند.
آن‌ها فقط مجموعه‌ای از دستورها برای تولید یک دنباله‌اند («ارزیابی تنبل»، یا یک «تکرارگر»).

اگر به یک بازه به شکل بردار نیاز دارید، از تابع `collect()` برای تبدیل استفاده کنید:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

اندازه‌ی گام را هم می‌توان مشخص کرد، که در این حالت ۰٫۳ است:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

پس نحوه‌ی نگارش چنین است: `start:stepsize:stop`.
هر دو کران پایانی _شامل_ هستند، همان‌طور که در مثال اعداد صحیح دیدید.
اگر اندازه‌ی گام دقیقاً بر `stop - start` بخش‌پذیر نباشد، آخرین عنصر از `stop` فراتر نمی‌رود.

## بازه‌ی حرفی

دنباله‌های غیرعددی را هم می‌توان در بازه‌ها به کار برد.
ساده‌ترین مثال، حروف ASCII است:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

نوع `Char` در مفهوم دیگری با جزئیات بیشتری بررسی می‌شود.
فعلاً با آن‌ها مثل کاراکترهای تکی داخل علامت نقل‌قول تکی رفتار کنید.

## توابع و عملگرها برای بازه‌ها

کران‌های یک بازه را با `first()` و `last()` بررسی کنید.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## بیشتر درباره‌ی نمایه‌گذاری بردار

از بازه‌های صحیح و بردارها می‌توان در نمایه‌گذاری بردار استفاده کرد:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
