# درباره

نوع سفارشی همان روشی است که با آن نوع‌های داده‌ی تازه در Gleam تعریف می‌شوند. یک نوع سفارشی می‌تواند چندین _گونه_ داشته باشد که هر یک اسم خودش را دارد.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

هر گونه از یک نوع سفارشی می‌تواند به‌طور اختیاری داده‌ای را نگه دارد و گونه‌های مختلف می‌توانند داده‌هایی از نوع‌های متفاوت داشته باشند. وقتی گونه‌ای داده نگه می‌دارد، به آن _رکورد_ می‌گویند.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

برای ساختن یک مقدار برای یک گونه‌ی مشخص، اگر آن گونه داده‌ی اضافی نداشته باشد می‌توان اسم آن را نوشت (`Spring`)، و اگر داده‌ی اضافی داشته باشد، می‌توان آن را مانند یک تابع فراخوانی کرد (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

نوع سفارشی، مانند همه‌چیز در Gleam، _تساوی ساختاری_ دارد؛ یعنی دو مقداری که از یک گونه‌اند و داده‌ی یکسانی دارند، با هم معادل‌اند.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

می‌توان روی گونه‌های نوع سفارشی با عبارت‌های `case` تطبیق الگو انجام داد.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
