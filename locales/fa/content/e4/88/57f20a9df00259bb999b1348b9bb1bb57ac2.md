# مقدمه

در Python، یک [تاپل][tuple] مجموعه‌ای _تغییرناپذیر_ از عنصرها به‌صورت _دنباله‌ای_ است.
مانند بیشتر مجموعه‌ها، `tuples` می‌توانند هر نوع داده‌ای (یا چند نوع داده) را در خود نگه دارند، از جمله `tuples`های دیگر.
تاپل‌ها همه‌ی [عملیات رایج دنباله][common sequence operations] را پشتیبانی می‌کنند، اما [عملیات دنباله‌ی تغییرپذیر][mutable sequence operations] را پشتیبانی **نمی‌کنند**.

می‌توان روی عنصرهای یک تاپل با ساختار `for item in <tuple>` پیمایش کرد.
اگر هم اندیس عنصر و هم مقدار آن لازم باشد، می‌توان از `for index, item in enumerate(<tuple>)` استفاده کرد.
مانند هر دنباله، می‌توان به عنصرهای داخل `tuples` با _نماد کروشه_ و با یک شماره‌ی `0-based index` از سمت چپ یا یک شماره‌ی `-1-based index` از سمت راست دسترسی پیدا کرد.
همچنین می‌توان تاپل‌ها را به‌طور کامل یا بخشی با نماد برش (_`<tuple>[<start>:<stop>:<step>]`_) کپی کرد.


## ساخت تاپل

تاپل‌ها را می‌توان به روش‌های گوناگون ساخت، یا با سازنده‌ی کلاس `tuple(<iterable>)` یا با اعلان تحت‌اللفظی `tuple`.

### استفاده از سازنده‌ی `tuple()` به‌صورت خالی یا با یک _تکرارپذیر_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

رشته‌ها تکرارپذیرند، بنابراین استفاده از یک `str` تنها به‌عنوان آرگومان سازنده‌ی `tuple()` می‌تواند نتیجه‌های غافلگیرکننده‌ای داشته باشد:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

عنصرهای یک تکرارپذیر یکی‌یکی اضافه می‌شوند:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### اعلان یک تاپل به‌صورت _تحت‌اللفظی_:

از آنجا که سازنده‌ی `tuple(<iterable>)` تنها _تکرارپذیرها_ (یا هیچ چیز) را به‌عنوان آرگومان می‌پذیرد، ساختن یک تاپل تک‌عنصری با روش تحت‌اللفظی بسیار آسان‌تر است.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

ساختارهای داده‌ی تودرتو را می‌توان به‌عنوان عنصرهای `tuple` گنجاند، از جمله `tuples`های دیگر:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## به هم چسباندن تاپل‌ها

می‌توان تاپل‌ها را با عملگر به‌علاوه‌ی `+` به هم چسباند؛ این عملگر هر `tuple` را باز می‌کند و یک `tuple` تازه‌ی ترکیب‌شده می‌سازد.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## دسترسی به عنصرهای داخل یک تاپل

می‌توان به عنصرهای داخل یک `tuple` با _نماد کروشه_ و با یک شماره‌ی `0-based index` از سمت چپ یا یک شماره‌ی `-1-based index` از سمت راست دسترسی پیدا کرد.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## پیمایش عنصرهای یک تاپل

می‌توان عنصرهای داخل یک `tuple` را در یک حلقه با ساختار `for item in <tuple>` _پیمایش_ کرد.
اگر هم اندیس‌ها و هم مقادیر لازم باشند، می‌توان از `for index, item in enumerate(<tuple>)` استفاده کرد.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## بررسی عضویت در یک تاپل

می‌توان از عملگر `in` برای بررسی عضویت در یک `tuple` استفاده کرد.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
