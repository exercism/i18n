# رشته

`STR` متن را نگه می‌دارد. رشته میان دو علامت `"` نوشته می‌شود.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

`STR` پس از ایجاد هرگز تغییر نمی‌کند. همه‌ی آنچه در ادامه می‌آید، به‌جای تغییر دادن رشته‌ای که درباره‌ی آن پرسیده شده، با یک رشته‌ی *جدید* پاسخ می‌دهد.

## به هم چسباندن

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` همچنین یک عدد را به رشته می‌چسباند و به این ترتیب عدد وارد جمله می‌شود:

```sather
"Opus " + 27           -- "Opus 27"
```

## طول

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` نویسه‌ها را می‌شمارد و پاسخ یک `INT` است.

## تکه‌ها

| فراخوانی | پاسخ |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

اگر بیش از مقدار موجود درخواست کنید، به‌جای شکست خوردن، همان مقدار موجود را برمی‌گرداند.

## مقایسه

`=` بررسی می‌کند که آیا دو رشته یک متن هستند یا نه و `/=` بررسی می‌کند که آیا با هم تفاوت دارند.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

بزرگی و کوچکی حروف مهم است. `.upper` و `.lower` نسخه‌ای با حروف بزرگ یا کوچک برمی‌گردانند که روش معمول مقایسه‌ی بی‌توجه به بزرگی و کوچکی حروف است:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## نکته‌ای درباره‌ی اندازه

`STR` ردیفی از بایت‌هاست و `.size` بایت‌ها را می‌شمارد. برای متن انگلیسی، این کار با شمردن حروف یکی است. اما برای متنی که اکسنت یا الفبای دیگری دارد، یکی نیست؛ زیرا هر یک از آن حروف بیش از یک بایت فضا می‌گیرد.
