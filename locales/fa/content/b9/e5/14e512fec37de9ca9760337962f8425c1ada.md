اما اوضاع کمی به‌هم‌ریخته است: به نظر می‌رسد مختصات آزارا با مختصات رویی متفاوت قالب‌بندی و مرتب شده‌اند و آنها باید مدام از یک فهرست به فهرست دیگر نگاه کنند تا بفهمند کدام گنج‌ها با کدام مکان‌ها جور درمی‌آیند.
از آنجا که پایتونیست‌های تازه‌کار هستند، برای کمک در نوشتن یک برنامه‌ی کوچک (در واقع مجموعه‌ای از توابع) به سراغ شما آمده‌اند تا اطلاعات شکارشان را بهتر سازمان‌دهی کنند.


## 1. استخراج مختصات

تابع `get_coordinate()` را پیاده‌سازی کنید که یک جفت `(treasure, coordinate)` از فهرست آزارا می‌گیرد و فقط مختصات نقشه‌ی استخراج‌شده را برمی‌گرداند.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. قالب‌بندی مختصات

تابع `convert_coordinate()` را پیاده‌سازی کنید که مختصاتی در قالب "2A" می‌گیرد و یک تاپل در قالب `("2", "A")` برمی‌گرداند.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. تطبیق مختصات

تابع `compare_records()` را پیاده‌سازی کنید که یک جفت `(treasure, coordinate)` و یک رکورد `(location, coordinate, quadrant)` می‌گیرد و مختصات هرکدام را با هم مقایسه می‌کند.
اگر مختصات جور دربیایند **`True`** را برگردانید و اگر جور درنیایند **`False`** را برگردانید.
برای مقایسه‌ی دقیق، مختصات را در صورت نیاز دوباره قالب‌بندی کنید.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. ترکیب رکوردهای منطبق

تابع `create_record()` را پیاده‌سازی کنید که یک جفت `(treasure, coordinate)` از فهرست آزارا و یک رکورد `(location, coordinate, quadrant)` از فهرست رویی می‌گیرد و **اگر مختصات جور دربیایند** `(treasure, coordinate, location, coordinate, quadrant)` را برمی‌گرداند.
اگر مختصات _جور درنیایند_، رشته‌ی **«not a match»** را برگردانید.
مختصات را در صورت نیاز دوباره قالب‌بندی کنید تا مقایسه دقیق باشد.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```

## 5. «مرتب‌سازی» و تهیه‌ی گزارشی از همه‌ی رکوردها

رکوردهای ترکیب‌شده‌ی آزارا و رویی را مرتب کنید تا برای هر رکورد فقط یک مجموعه مختصات بماند. گزارشی تهیه کنید تا بتوانند فهرست واحدی از همه‌ی آنچه را که باید روی نقشه‌هایشان بگذارند ببینند.
تابع `clean_up()` را پیاده‌سازی کنید که یک تاپل از تاپل‌ها (_همه‌ی داده‌های هر دو فهرست_) می‌گیرد، تاپل _بیرونی_ را پیمایش می‌کند، مختصات ناخواسته را از هر تاپل _داخلی_ حذف می‌کند و هرکدام را به یک «گزارش» اضافه می‌کند.
«گزارش» را طوری قالب‌بندی و برگردانید که در هر خط یک رکورد مرتب‌شده قرار بگیرد.
