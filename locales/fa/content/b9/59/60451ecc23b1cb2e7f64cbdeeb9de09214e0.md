# مقدمه

## مدت‌ها و دوره‌های زمانی

کلاس‌هایی مانند `LocalDate` و `LocalDateTime` یک _نقطه_ در زمان را توصیف می‌کنند.
بسته‌ی `java.time` هم دو کلاس دارد که یک _مقدار_ از زمان را توصیف می‌کنند:

- `java.time.Period` مقداری از زمان بر حسب سال، ماه و روز است، مانند «۲ ماه و ۵ روز».
- `java.time.Duration` مقداری از زمان بر حسب ساعت، دقیقه، ثانیه، میلی‌ثانیه و نانوثانیه است، مانند «۱ ساعت و ۳۰ دقیقه».

`Period` از تقویم پیروی می‌کند، بنابراین با تاریخ‌ها و تاریخ-زمان‌ها به کار می‌رود.
`Duration` زمان دقیق را اندازه می‌گیرد، بنابراین با زمان‌ها و تاریخ-زمان‌ها به کار می‌رود، اما نه با تاریخ‌ها.

```exercism/note
مانند دیگر کلاس‌های `java.time`، کلاس‌های `Period` و `Duration` تغییرناپذیرند.
متدهایی که به نظر می‌رسد آن‌ها را تغییر می‌دهند، در عوض یک نمونه‌ی _جدید_ برمی‌گردانند.
```

### `Period`

یک `Period` با یکی از متدهای کارخانه‌ای ایستای خود ساخته می‌شود:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

نتیجه‌ی `toString()` از نشانه‌گذاری [ISO-8601][iso-8601-durations] استفاده می‌کند: `P` (برای «period») و پس از آن تعداد سال‌ها (`Y`)، ماه‌ها (`M`) و روزها (`D`) می‌آید.

می‌توان یک دوره‌ی زمانی را به یک تاریخ افزود یا از آن کم کرد:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

چون ماه‌ها طول‌های متفاوتی دارند، افزودن ماه می‌تواند به روزی برسد که وجود ندارد.
در این حالت نتیجه به آخرین روز معتبر ماه برگردانده می‌شود:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` دوره‌ی زمانی از یک تاریخ (با احتساب آن) تا تاریخی دیگر (بدون احتساب آن) را برمی‌گرداند:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### شمارش واحدها با `ChronoUnit`

`Period` سال‌ها، ماه‌ها و روزهایش را جدا از هم نگه می‌دارد.
بنابراین `getDays()` فقط _بخش_ روزها را برمی‌گرداند، نه تعداد کل روزها.
برای شمردن تعداد کل یک واحد میان دو تاریخ، از متد `between()` در [`java.time.temporal.ChronoUnit`][chronounit-docs] استفاده کنید:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

اگر تاریخ دوم پیش از تاریخ اول باشد، نتیجه منفی است:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

یک `Duration` هم با متدهای کارخانه‌ای ایستا ساخته می‌شود:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

در نشانه‌گذاری ISO-8601، حرف `T` بخش تاریخ را از بخش زمان جدا می‌کند و به همین دلیل مدت‌ها به شکل `PT...` نوشته می‌شوند.

می‌توان یک مدت را به یک تاریخ-زمان افزود یا از آن کم کرد:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` مقدار دقیق زمان میان دو تاریخ-زمان را برمی‌گرداند:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

می‌توان یک مدت را با متدهایی مانند `toHours()`، `toMinutes()` و `toSeconds()` به یک واحد تبدیل کرد.
این متدها مقدار _کل_ را در آن واحد برمی‌گردانند، با گرد کردن به پایین:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

برای تقسیم یک مدت به اجزایش، مانند آنچه روی ساعت می‌بینید، به‌جای آن از متدهای `toXxxPart()` استفاده کنید:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
