# معرفی

«کامنت‌ها» به شما اجازه می‌دهند بدون اینکه بر نحوه‌ی اجرای کد تأثیری بگذارند، در آن یادداشت بگذارید.
کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

کامنت‌ها بسته به اینکه کجا ظاهر می‌شوند، کاربردهای متفاوتی دارند.

## کامنت‌های کد

کامنت‌های کد توضیح می‌دهند که چرا کاری انجام می‌شود، نه اینکه چه کاری انجام می‌شود.
از آن‌ها زمانی استفاده کنید که دلیل پشت یک تصمیم، از خود کد آشکار نیست:

```go
results = results[1:] // skipping the header row
```

## کامنت‌های مستندسازی

کامنت‌های مستندسازی درست پیش از یک اعلان قرار می‌گیرند، بدون هیچ خط خالی میان کامنت و اعلان.
[`godoc`][godoc] آن‌ها را تجزیه می‌کند تا مستندات بسته را تولید کند.
یک کامنت مستندسازی باید یک جمله‌ی کامل باشد که با اسم شناسه شروع می‌شود و با نقطه پایان می‌یابد.

کامنت‌های بسته با اسم بسته شروع می‌شوند:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

کامنت‌های تابع با اسم تابع شروع می‌شوند:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
