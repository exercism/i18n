# درباره

یک مقدار «منطقی» نشان می‌دهد که یک شرط `true` است یا `false`.
در Go، نوع `bool` فقط می‌تواند یکی از آن دو مقدار باشد.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## عملگرهای منطقی

عملگرهای منطقی روی یک یا دو مقدار منطقی کار می‌کنند و یک نتیجه‌ی منطقی تولید می‌کنند.

| عملگر | اسم | رفتار |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | عکس یک مقدار منطقی را برمی‌گرداند |
| `&&`     | AND  | فقط وقتی هر دو طرف `true` باشند، `true` را برمی‌گرداند |
| `\|\|`   | OR   | اگر هر یک از طرف‌ها `true` باشد، `true` را برمی‌گرداند |

وقتی به عکس یک مقدار منطقی نیاز دارید، از `!` (NOT) استفاده کنید:

```go
!isDoorLocked // false
```

وقتی هر دو شرط باید `true` باشند، از `&&` (AND) استفاده کنید:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

وقتی حداقل یکی از شرط‌ها باید `true` باشد، از `||` (OR) استفاده کنید:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

عملگرهای منطقی به این ترتیب ارزیابی می‌شوند: اول `!`، سپس `&&`، سپس `||`.
برای گروه‌بندی کد و کنترل اینکه کدام عملیات اول انجام می‌شود، از پرانتز استفاده کنید:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
