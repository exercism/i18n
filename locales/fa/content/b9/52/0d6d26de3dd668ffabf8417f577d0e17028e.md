## کلی

`struct` `SimpleLinkedList` را به عنوان پوششی دور یک `Vec` پیاده‌سازی نکنید. در عوض، گره‌ها را روی heap تخصیص دهید.

می‌توان آن را این‌گونه پیاده‌سازی کرد:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

فیلد `head` به اولین عنصر (Node) این لیست پیوندی اشاره می‌کند.

این پیاده‌سازی به یک `struct` به اسم `Node` هم نیاز دارد که فیلدهای زیر را داشته باشد:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` داده‌ی ذخیره‌شده را در خود نگه می‌دارد و `next` به گره‌ی بعدی اشاره می‌کند (اگر وجود داشته باشد) یا به None.

## چرا `Option<Box<Node<T>>>` و نه فقط `Option<Node<T>>`؟

خودتان امتحان کنید. با خطای زیر روبه‌رو می‌شوید.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

مشکل اینجاست که در زمان کامپایل باید اندازه‌ی `next` مشخص باشد.
چون `next` بازگشتی است («یک گره، گرهی دارد که خودش گرهی دارد...»)، کامپایلر نمی‌داند چه مقدار حافظه باید تخصیص داده شود.
در مقابل، [Box](https://doc.rust-lang.org/std/boxed/) یک اشاره‌گر heap با اندازه‌ی مشخص است.
