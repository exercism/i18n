# مقدمه

Common Lisp برای بیشتر عملیات از عملگرهای حسابی استاندارد استفاده می‌کند، اما در یک نکته تا حدی بی‌همتاست: از «نمادگذاری پیشوندی» بهره می‌برد، نه از «نمادگذاری میانوندی» که آشناتر است.

به شکل تصویری:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

نمادگذاری پیشوندی هرچند بعضی عملیات مثل `2 + 2` را به شکل تا حدی ناآشنای `(+ 2 2)` درمی‌آورد، اما کار کردن با بیش از یک عدد را در یک زمان بسیار آسان‌تر می‌کند.

## ریاضیات پایه

Common Lisp همه‌ی توابع معمول را دارد: `+`، `-`، `*` و `/` برای جمع، تفریق، ضرب و تقسیم.

وقتی با تقسیم سر و کار دارید، ممکن است بخواهید باقی‌مانده‌ی تقسیم را بدانید. این کار با تابع `mod` (به معنی modulo) انجام می‌شود که یک عدد و یک مقسوم‌علیه را به عنوان آرگومان می‌گیرد:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## مقایسه‌ی اعداد

در پایان، ممکن است مقایسه‌ی اعداد مختلف با توابعی مثل `=` (برابر)، `/=` (نابرابر) و `>=` (بزرگ‌تر یا مساوی) برایتان مفید باشد.
وقتی نتیجه‌ی این مقایسه‌ها درست باشد (مثل `(= 1 1)`)، `T` را برمی‌گردانند و وقتی درست نباشد (مثل `(> 0 1)`)، `NIL` را برمی‌گردانند.
