# تست

## اجرای تست‌ها

وقتی در پوشه‌ی یک تمرین هستید، باید دو زیرپوشه ببینید:

* `src` شامل راه‌حل شما برای تمرین است
* `spec` شامل تست‌هایی است که برای تمرین اجرا می‌شوند

اگر در پوشه‌ی درست هستید (یعنی همان پوشه‌ای که `src` و `spec` را در خود دارد)، می‌توانید تست‌های آن تمرین را با اجرای `crystal spec` اجرا کنید:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

این دستور همه‌ی فایل‌های تست را در پوشه‌ی `spec` اجرا می‌کند.

در هر فایل تست، همه‌ی تست‌ها به‌جز تست اول نادیده گرفته شده‌اند.

وقتی یک تست را با موفقیت گذراندید، می‌توانید تست بعدی را با تغییر `pending` به `it` از حالت نادیده خارج کنید.

## قالب‌بندی Crystal

پیش از ارسال راه‌حل، توصیه می‌شود `crystal tool format` را روی راه‌حل خود اجرا کنید.

می‌توانید همه‌ی فایل‌های پوشه‌ی فعلی خود را با این دستور قالب‌بندی کنید:

```bash
$ crystal tool format ./
```

یا می‌توانید فایل‌های خاصی را به‌صورت گزینشی قالب‌بندی کنید:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## ارسال راه‌حل

هنگام ارسال راه‌حل، حتماً فایل منبع موجود در پوشه‌ی `src` را ارسال کنید:

```bash
$ exercism submit src/<exercise>.cr
```
