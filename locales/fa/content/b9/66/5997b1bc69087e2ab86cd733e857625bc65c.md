# تست‌ها

## راه‌اندازی

دستورالعمل‌های [راه‌اندازی WebAssembly][docs-exercism-wasm] را دنبال کنید تا وابستگی‌های لازم را نصب کنید.

## پیش‌نیازها

وابستگی‌های تمرین را نصب کنید:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## موفق کردن مجموعه‌ی تست

همه‌ی تمرین‌ها با یک مجموعه‌ی تست ارائه می‌شوند تا به شما کمک کنند پیش از ارسال، راه‌حل‌تان را بررسی کنید.
می‌توانید این تست‌ها را با باز کردن یک خط فرمان در پوشه‌ی تمرین و سپس اجرای دستور زیر اجرا کنید:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

در برخی از مجموعه‌های تست، همه‌ی تست‌ها به‌جز اولین تست نادیده گرفته شده‌اند.

وقتی یک تست را با موفقیت پشت سر گذاشتید، می‌توانید با تغییر دادن `xtest` به `test` تست بعدی را فعال کنید.

## نوشتن تست‌های سفارشی

اگر می‌خواهید تست‌های سفارشی و بیشتری بنویسید، یک فایل جدید به اسم `custom.spec.js` بسازید و آن را همراه با راه‌حل‌تان و همین فایل جدید ارسال کنید:

```shell
exercism submit numbers.wat custom.spec.js
```
