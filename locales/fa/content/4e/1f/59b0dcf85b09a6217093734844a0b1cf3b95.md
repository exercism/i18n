# دستورالعمل‌ها

وظیفه‌ی شما این است که رشته‌ای با قالب Smart Game Format (SGF) را تجزیه کنید و ساختار داده‌ی درختی‌ای برگردانید که بازی را نمایش می‌دهد.

یک رشته‌ی SGF درختی از گره‌ها را نمایش می‌دهد. کل درخت داخل پرانتز `()` قرار می‌گیرد.
هر گره در درخت با یک نقطه‌ویرگول `;` مشخص می‌شود که پس از آن دنباله‌ای از ویژگی‌ها می‌آید.
یک ویژگی شامل یک شناسه است که همه‌ی حروفش بزرگ‌اند (مثلاً `AB`) و پس از آن یک یا چند مقدار داخل براکت `[]` می‌آید.

برای مثال، رشته‌ی `(;FF[4]C[root])` درختی با یک گره‌ی ریشه‌ی واحد را نمایش می‌دهد. آن گره دو ویژگی دارد:
- ویژگی `FF` با مقدار `4`
- ویژگی `C` با مقدار `root`

**گونه‌های بازی (درخت‌ها و شاخه‌ها)**
SGF با تودرتو کردن درخت‌ها از گونه‌های بازی پشتیبانی می‌کند. یک درخت می‌تواند چندین درخت فرزند داشته باشد که آن‌ها هم داخل پرانتز قرار می‌گیرند.
برای مثال، `(;A[B](;C[D])(;E[F]))` یک گره‌ی ریشه با ویژگی `A` را نشان می‌دهد که دو شاخه‌ی فرزند دارد:
1. یک گره با ویژگی `C` و مقدار `D`
2. یک گره با ویژگی `E` و مقدار `F`

**قالب‌بندی و گریز**
مقادیر داخل براکت‌ها می‌توانند شامل نویسه‌های گریز باشند. یک بک‌اسلش `\` که بعد از آن هر نویسه‌ای بیاید، نشان‌دهنده‌ی همان نویسه به‌شکل لفظی است (مثلاً `\]` باید به‌صورت یک `]` لفظی تجزیه شود). علاوه بر این، اگر پیش از یک خط جدید بک‌اسلش آمده باشد، به‌عنوان ادامه‌ی خط عمل می‌کند و باید از مقدار حذف شود. همه‌ی خط‌های جدید دیگر درون یک مقدار باید حفظ شوند.

**مدیریت خطا**
برای رشته‌های SGF نامعتبر باید خطا پرتاب کنید. موارد زیر نمونه‌هایی از SGF نامعتبر هستند:
- درختی که با پرانتز `()` شروع نمی‌شود.
- گره‌ای که با نقطه‌ویرگول `;` شروع نمی‌شود.
- شناسه‌های ویژگی که کاملاً از حروف بزرگ تشکیل نشده‌اند.
- براکت‌های جاافتاده یا پرانتزهای جفت‌نشده.

### ساختار داده

تابع تجزیه‌ی شما باید نمایشی از درخت برگرداند. یک رویکرد رایج این است که هر درخت را به‌صورت شیئی با دو فیلد نمایش دهید:
- `properties`: یک شیء (یا `Map`) که کلیدهایش شناسه‌های ویژگی (رشته‌ها) و مقادیرش آرایه‌هایی از رشته‌ها هستند (چون یک ویژگی می‌تواند چند مقدار داشته باشد).
- `children`: آرایه‌ای شامل درخت‌های فرزند.


مثال:

ورودی: `(;FF[4]C[root])`
خروجی: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

ورودی: `(;A[B](;C[D])(;E[F]))`
خروجی: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
