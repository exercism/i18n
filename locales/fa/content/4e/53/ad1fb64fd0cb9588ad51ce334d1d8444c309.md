# معرفی

در تمرین قبلی دیدیم که دو روش برای نوشتن «کامنت» در Go وجود دارد: کامنت‌های تک‌خطی که پیش از آن‌ها `//` می‌آید و بلوک‌های کامنت چندخطی که با `/*` و `*/` احاطه می‌شوند.

## کامنت‌های مستندسازی

در Go، کامنت‌ها نقش مهمی در مستندسازی کد دارند.
از آن‌ها در دستور `godoc` استفاده می‌شود؛ این دستور آن کامنت‌ها را استخراج می‌کند تا مستندات مربوط به بسته‌های Go را بسازد.
یک کامنت مستندسازی باید یک جمله‌ی کامل باشد که با اسم آنچه توصیف می‌شود شروع شود و با نقطه تمام شود.

کامنت‌ها باید پیش از بسته‌ها و همچنین شناسه‌های صادرشده قرار بگیرند؛ برای مثال توابع صادرشده، متدها، متغیرهای بسته، ثابت‌ها و ساختارها، که در تمرین‌های بعدی بیشتر درباره‌ی آن‌ها یاد خواهید گرفت.

یک متغیر سطح بسته می‌تواند به این شکل باشد:

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## کامنت‌های بسته

کامنت‌های بسته باید مستقیماً پیش از عبارت بسته (`package x`) نوشته شوند و مانند زیر با `Package x ...` شروع شوند:

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## کامنت‌های تابع

کامنت تابع باید مستقیماً پیش از اعلان تابع نوشته شود.
باید یک جمله‌ی کامل باشد که با اسم تابع شروع شود.
برای مثال، کامنت یک تابع صادرشده به اسم `Calculate` باید به شکل `Calculate  ...` باشد.
همچنین باید توضیح دهد که تابع چه آرگومان‌هایی می‌گیرد، با آن‌ها چه می‌کند و مقادیر بازگشتی‌اش چه معنایی دارند و در پایان با نقطه تمام شود):

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
