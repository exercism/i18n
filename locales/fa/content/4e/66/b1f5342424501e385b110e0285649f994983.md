# دستورالعمل‌ها

شما در حال نگهداری از جعبه‌ابزار تولید کدِ یک ایستگاه سیگنال هستید.
هر ماکرو یک «شابلون» است، یعنی قالبی کوچک که کامپایلر با آن در هر
نقطه‌ی فراخوانی، کد تخصص‌یافته تولید می‌کند.

شما فقط چهار ماکرو را می‌نویسید. فایل تست، واژه‌های پوششی کوچکی
تعریف می‌کند که ماکروهای شما را *فراخوانی* می‌کنند (ماکرو را تنها از
راه کدی که تولید می‌کند می‌توان مشاهده کرد)، و سپس نتایج زمان اجرای
این پوشش‌ها را بررسی می‌کند. پوشش‌ها را همان‌طور که هستند رها کنید.

در هر تمرین، بدنه ورودی‌های لیترالِ نقطه‌ی فراخوانی را روی پشته
دریافت می‌کند و باید **یک کوتیشن** را برجای بگذارد. خطوطِ
«کامپایل می‌شود به» کد خطی‌ای را نشان می‌دهند که کوتیشن شما باید
تولید کند.

## 1. دو بار

`twice` یک کوتیشن لیترال می‌گیرد و کوتیشنی برمی‌گرداند که کوتیشن
اصلی را دو بار پشت سر هم اجرا می‌کند.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. تکرار N بار

`repeat-quot` یک کوتیشن لیترال و یک تعداد لیترال `n` می‌گیرد و
کوتیشنی برمی‌گرداند که کوتیشن اصلی را `n` بار پشت سر هم اجرا می‌کند.
حالت `n = 0` کوتیشن خالی `[ ]` را برمی‌گرداند.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. ترکیب چندگانه

`compose-many` یک آرایه‌ی لیترال از کوتیشن‌ها می‌گیرد و یک کوتیشن
واحد برمی‌گرداند که هرکدام را به نوبت اجرا می‌کند. آرایه‌ی خالی،
کوتیشن خالی را برمی‌گرداند.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. پیمایش بازشده

`each-literal` یک دنباله‌ی لیترال و یک کوتیشن می‌گیرد. کوتیشنی
برمی‌گرداند که برای هر عنصر دنباله، آن عنصر را روی پشته می‌گذارد و
سپس کوتیشن را اجرا می‌کند؛ پیمایشی که در زمان کامپایل رخ می‌دهد،
بنابراین کد تولیدشده خطی است.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

این مورد از میان آن چهار، ساختاری‌ترین است: هم طول دنباله *و* هم
مقادیر عناصر آن، کد تولیدشده را شکل می‌دهند. راهنمایی‌ها گام‌به‌گام
نحوه‌ی ساخت آن را توضیح می‌دهند.
