# مقدمه

## متغیرها و مقداردهی

R یک زبان با نوع‌دهی پویا است، بنابراین به‌طور کلی لازم نیست نوع یک متغیر را مشخص کنید. عملگر ترجیحی برای مقداردهی `<-` است.

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

استفاده از `=` به‌جای `<-` اغلب کار می‌کند، هرچند نه همیشه، و به‌عنوان سبکی نامناسب توصیه نمی‌شود.
اگر در RStudio کار می‌کنید، می‌توانید آن را با میان‌بر صفحه‌کلید `Alt-minus` وارد کنید.

عملگرها بیشتر متعارف‌اند، اما به `%/%` و `%%` توجه کنید:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

در R، `#` یک توضیح یک‌خطی را شروع می‌کند.
برای توضیحات چندخطی، نحوه‌ی نگارش جداگانه‌ای وجود ندارد.

## توابع

برای تعریف یک تابع:

```R
squareit <- function(x) {
    x * x
}
```

توابع می‌توانند صفر یا چند آرگومان داشته باشند که با کاما از هم جدا می‌شوند.
پرانتزهای `()` همراه با `function()` لازم‌اند، حتی اگر پارامتری وجود نداشته باشد.

می‌توان برای آرگومان‌های تابع مقادیر پیش‌فرض تعیین کرد، اما این مقادیر باید بعد از هر آرگومانی که پیش‌فرض ندارد بیایند و برای مقداردهی مقدار پیش‌فرض، از `=` استفاده شود نه از `<-`.
به‌عنوان مثالی نسبتاً بی‌فایده:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

آکولادهای `{ }` برای بدنه‌ی توابع یک‌خطی به‌طور دقیق لازم نیستند، اما گنجاندنشان سبک خوبی به شمار می‌آید.

R به‌طور خودکار مقدار نهایی یک تابع را برمی‌گرداند، همان‌طور که در مثال‌های بالا آمده است.

می‌توان از `return()` در هر جای بدنه‌ی تابع استفاده کرد تا مقدار بازگشتی صریح شود.

فراخوانی یک تابع مانند بسیاری از زبان‌های دیگر است:

```R
squareit(3)
#> [1] 9
```
