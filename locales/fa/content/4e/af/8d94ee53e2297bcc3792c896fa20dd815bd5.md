# مقدمه

## رابط

«رابط» یک نوع است که اعضایی را در خود دارد که گروهی از کارکردهای مرتبط را تعریف می‌کنند. این نوع، نحوه‌ی استفاده از یک کلاس را از پیاده‌سازی آن جدا می‌کند و امکان چندین پیاده‌سازی متفاوت یا پشتیبانی از رفتارهای عمومی مانند قالب‌بندی، مقایسه یا تبدیل را فراهم می‌آورد.

نحوه‌ی نگارش یک رابط شبیه به نحوه‌ی نگارش یک کلاس یا ساختار است، با این تفاوت که متدها و ویژگی‌ها فقط به‌صورت امضا ظاهر می‌شوند و بدنه‌ای برایشان ارائه نمی‌شود.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

همه‌ی عملیات تعریف‌شده در رابط باید پیاده‌سازی شوند.

رابط‌ها می‌توانند علاوه بر دیگر اعضا، متدها و ویژگی‌های نمونه‌ای هم داشته باشند

## ترتیب

برای اینکه بتوان یک شیء را با شیء دیگری مقایسه کرد، باید رابط `IComparable<T>` را پیاده‌سازی کند.
این رابط یک متد دارد که باید پیاده‌سازی شود: `int CompareTo(T other)`.

مقدار بازگشتی متد `CompareTo` می‌تواند یکی از سه حالت زیر باشد:

- مقداری کوچک‌تر از صفر: شیء جاری کوچک‌تر از شیء دیگر است.
- مقداری بزرگ‌تر از صفر: شیء جاری بزرگ‌تر از شیء دیگر است.
- مقدار برابر صفر: شیء جاری برابر شیء دیگر است.
