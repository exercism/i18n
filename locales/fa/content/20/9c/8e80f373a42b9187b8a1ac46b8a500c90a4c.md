# دستورالعمل‌ها

در این تمرین، سطرهای لاگ را پردازش می‌کنید.

هر سطر لاگ رشته‌ای است با این قالب: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه تمرین دارید؛ هرکدام یک سطر لاگ می‌گیرد و از شما می‌خواهد کاری روی آن انجام دهید.
راه‌های زیادی برای حل این تمرین‌ها وجود دارد؛ تکنیک‌های موردعلاقه‌تان را از مثال‌های بالا انتخاب کنید و ببینید به چه نتیجه‌ای می‌رسید.

## 1. گرفتن پیام از یک سطر لاگ

تابع `message` را پیاده‌سازی کنید تا پیام یک سطر لاگ را برگرداند:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

هر فضای سفید ابتدایی یا انتهایی باید حذف شود:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. گرفتن سطح لاگ از یک سطر لاگ

تابع `log_level` را پیاده‌سازی کنید تا سطح لاگ یک سطر لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. قالب‌بندی مجدد یک سطر لاگ

تابع `reformat` را پیاده‌سازی کنید که سطر لاگ را دوباره قالب‌بندی می‌کند؛ به این صورت که پیام را اول می‌گذارد و سطح لاگ را بعد از آن، داخل پرانتز:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
