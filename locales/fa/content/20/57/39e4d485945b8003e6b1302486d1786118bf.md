# درباره

واژگان [`sequences`][sequences] یک [پروتکل][sequence-protocol] یکتا تعریف می‌کند که آرایه‌ها (`{ … }`)، بردارها (`V{ … }`)، رشته‌ها، بازه‌ها و برش‌ها همگی آن را پیاده‌سازی می‌کنند. هر کاری که با یکی از آن‌ها بتوانید انجام دهید، با بقیه هم می‌توانید.

| واژه        | کارکرد                            |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (از صفر)      |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (همه به‌جز `n` عنصر آخر) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (`n` عنصر آخر)   |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (در صورت نبود، طول) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

آرایه‌ها طول ثابتی دارند، بنابراین عملیات `prefix`/`suffix`/`append`/`prepend` همگی به‌جای بزرگ کردن آرایه‌ی اصلی، دنباله‌های جدیدی برمی‌گردانند. بردارها قابل تغییر اندازه‌اند (`push` و `pop` درجا کار می‌کنند)، اما اگر کپی تازه‌ای می‌خواهید، `clone` نقطه‌ی شروع درستی است.

## تبدیل‌ها

`>array`، `>string` و `>vector` (هر کدام در واژگان مربوط به خودش) هر دنباله‌ای را به نوع مشخصِ نام‌برده تبدیل می‌کنند. از آن‌ها استفاده کنید وقتی که فراخوان یک نمایش مشخص می‌خواهد، یا برای اینکه یک برش یا دنباله‌ی تنبل دیگری را به مقدار واقعی تبدیل کنید.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
