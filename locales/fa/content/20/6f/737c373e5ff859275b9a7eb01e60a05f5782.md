# دستورالعمل‌ها

گروه رقص در ردیف‌هایی می‌ایستد و شما باید بدانید هر کس کجا ایستاده است.

هر پنج کار در کلاس `DANCE_FORMATION` قرار می‌گیرند.

## 1. در هر ردیف چند نفر هستند؟

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. چه کسی رهبری می‌کند؟

رهبر کسی است که در ابتدای ردیف می‌ایستد.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. چه کسی در انتهای ردیف است؟

آخرین نفر کسی است که در انتهای ردیف می‌ایستد، هر چقدر هم که ردیف طولانی باشد.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. آرایش شروع

گروه همیشه با ترتیب یکسان شروع می‌کند: Mia، Ana، Ben. همان ردیف را برگردانید.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

این روال هیچ آرگومانی نمی‌گیرد.

## 5. شمارش قدم‌ها

هر رقصنده تعدادی قدم برای برداشتن دارد. این تعدادها را با هم جمع کنید.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

ردیف خالی یعنی ۰ قدم.
