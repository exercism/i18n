# مقدمه

الکسیر مقادیر «درست» و «غلط» را با نوع «منطقی» نمایش می‌دهد. فقط دو مقدار وجود دارد: `true` و `false`. این مقادیر را می‌توان به یک متغیر نسبت داد:

```elixir
true_variable = true
false_variable = false
```

می‌توانیم عبارت‌های منطقی سخت‌گیرانه را با عملگرهای `and/2`، `or/2` و `not/1` ارزیابی کنیم.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

وقتی تابعی می‌نویسید که یک مقدار منطقی برمی‌گرداند، مرسوم است که اسم تابع را با یک `?` به پایان برسانید. همین قرارداد را می‌توان برای متغیرهایی هم به کار برد که مقادیر منطقی را ذخیره می‌کنند.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
