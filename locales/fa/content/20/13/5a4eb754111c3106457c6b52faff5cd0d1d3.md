# مقدمه

وقتی چند مقدار گسسته‌ی ممکن دارید که باید بر اساس هرکدام تصمیم بگیرید، `case` (در [`combinators`][combinators]) انتخاب تمیزتری است از زنجیره‌ای از `if`.

## `case`

```
case ( obj assoc -- )
```

`case` مقدار را از بالای پشته برمی‌دارد، همراه با یک *assoc* از بندها. هر بند به شکل `{ value [ body ] }` است. اولین بندی که مقدارش با ورودی برابر باشد برنده است؛ بدنه‌ی آن در حالی اجرا می‌شود که مقدار ورودی *از قبل مصرف شده است*. ورودی انتهایی که فقط `[ body ]` باشد، پیش‌فرض است: هنگام اجرا، ورودی *هنوز روی پشته است*.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

برابری بر پایه‌ی `=` سنجیده می‌شود، پس هر مقداری که در مقایسه برابر شود می‌تواند به عنوان کلید به کار رود؛ اعداد، رشته‌ها و نمادها همه به کار می‌آیند.

## `cond` برای شاخه‌های شرطی

وقتی انتخاب، به‌جای برابری، به یک محمول بستگی دارد (مثلاً `x > 11`)، ابزار مناسب `cond` است. شما `cond` را در [Cars, Assemble!][cars-assemble] دیده‌اید.

## نمادها

`SYMBOL:` واژه‌ای را تعریف می‌کند که خودش را روی پشته می‌گذارد، یعنی یک مقدار برچسبی که خودش را ارزیابی می‌کند. `SYMBOLS:` چند تا را با هم تعریف می‌کند:

```factor
SYMBOLS: yes no maybe ;
```

حالا `yes` مقداری است که با `=` مقایسه می‌شود و می‌توانید از آن به عنوان کلید `case` استفاده کنید:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
