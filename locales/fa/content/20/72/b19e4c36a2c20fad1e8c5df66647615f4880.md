# مقدمه

برخی از حلقه‌ها را نمی‌توان به شکل «این کار را برای هر عنصر از یک دنباله انجام بده» نوشت؛ باید ادامه دهید تا زمانی که شرطی تغییر کند. کامبیناتور `while` در Factor ابزار همین کار است: یک نقل‌قول محمول می‌گوید «ادامه بدهم؟»، یک نقل‌قول بدنه کار یک گام را انجام می‌دهد، و `while` تکرار می‌شود تا محمول مقدار `f` را بدهد.

## `while` و `until`

```
while ( pred body -- )
until ( pred body -- )
```

`pred` و `body` هر دو نقل‌قول‌هایی هستند که روی پشته‌ی داده عمل می‌کنند. `while` تا زمانی به حلقه زدن ادامه می‌دهد که `pred` یک مقدار درست باقی بگذارد؛ `until` برعکس است: *تا زمانی که* `pred` درست شود به حلقه زدن ادامه می‌دهد (یعنی تا وقتی که `pred` مقدار `f` باقی می‌گذارد).

یک تکه وضعیت می‌تواند روی پشته میان محمول و بدنه جریان یابد:

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

ردیابی: محمول `dup 0 >` نگاهی به شمارنده‌ی در حال اجرا می‌اندازد؛ بدنه‌ی `dup . 1 -` آن را چاپ می‌کند و یکی کم می‌کند؛ حلقه وقتی شمارنده به `0` برسد متوقف می‌شود. `drop` پایانی همان `0` آخر را از پشته دور می‌ریزد.

## `while*`: حفظ مقدار محمول

```
while* ( pred body -- )
```

`while` فقط اهمیت می‌دهد که محمولش مقدار درستی باقی گذاشته باشد؛ خود مقدار را پیش از اجرای بدنه دور می‌ریزد. `while*` در عوض *آن مقدار را به بدنه می‌سپارد*. هر جا که آزمون و بدنه هر دو همان مقدار تازه‌محاسبه‌شده را بخواهند، سراغش بروید: یک جست‌وجو، یک تطبیق، یک توکن تجزیه‌شده.

اینجا هر اسم به اسم بعدی در یک زنجیره اشاره می‌کند. محمول اسم جاری را جست‌وجو می‌کند؛ تا وقتی اسم بعدی وجود دارد، `while*` آن را به بدنه می‌سپارد، و بدنه آن را چاپ می‌کند و از همان‌جا ادامه می‌دهد:

```factor
USING: assocs kernel locals prettyprint ;

:: print-chain ( start links -- )
    start [ links at ] [ dup . ] while* ;

"a" H{ { "a" "b" } { "b" "c" } } print-chain
! prints "b" then "c"
```

`links at` اسم بعدی را برمی‌گرداند، یا وقتی که اسمی ورودی نداشته باشد `f` را. تا وقتی اسمی برمی‌گرداند، `while*` آن اسم را به `dup .` می‌دهد، که آن را چاپ می‌کند و به‌عنوان کلید جست‌وجوی بعدی باقی می‌گذارد. اولین `f` حلقه را متوقف می‌کند؛ `while*` آن را دور می‌ریزد، پس چیزی باقی نمی‌ماند.

## چند مقدار وضعیت با متغیرهای محلی

وقتی حلقه بیش از یک مقدار را حمل می‌کند، مثلاً یک فهرست باقی‌مانده و یک مجموع در حال اجرا، دستکاری پشته پرسروصدا می‌شود. تمیزترین الگو این است که *متغیرهای محلی* را با `::` تعریف کنید:

```
:: word ( inputs -- outputs ) ... ;
```

درون بدنه، `:> name!` یک متغیر محلی تغییرپذیر اضافه می‌کند؛ خواندن‌ها از `name` استفاده می‌کنند و نوشتن‌ها از `name!` (که مقدار جدید را از پشته مصرف می‌کند و آن را تخصیص می‌دهد).

```factor
USING: kernel locals math sequences ;

! Walk a sequence from the front, summing as we go
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0   :> running!
    [ rest empty? ] [
        rest unclip [ rest! ] dip
        running + running!
    ] until
    running ;
```

دو متغیر محلی اینجا (`rest` و `running`) کل وضعیت حلقه را پوشش می‌دهند: محمول آن‌ها را بررسی می‌کند، بدنه آن‌ها را به‌روزرسانی می‌کند، و مقدار نهایی در پایان برگردانده می‌شود.

`unclip ( seq -- rest first )` اولین عنصر یک دنباله را جدا می‌کند؛ وقتی حلقه می‌خواهد در هر تکرار یک عنصر از فهرست را مصرف کند، مفید است. شکل `[ rest! ] dip` مقدار `rest` را به دنباله‌ی باقی‌مانده به‌روزرسانی می‌کند و در همان حال عنصر تازه‌بیرون‌کشیده‌شده را برای استفاده‌ی بدنه روی پشته باقی می‌گذارد.
