# مقدمه

PHP اجازه می‌دهد توابع را درون توابع دیگر تعریف کنید. این توابع نیازی ندارند اسم داشته باشند، اما می‌توان آن‌ها را به متغیرها اختصاص داد یا حتی مستقیماً به تابع دیگری که به یک پارامتر تابع نیاز دارد فرستاد.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
