# دیکشنری

دیکشنری‌ها در Cairo مخزن کلید-مقدار هستند، مانند نگاشت یا جدول درهم‌سازی در زبان‌های دیگر.

با این حال، به دلیل مدل حافظه‌ی تغییرناپذیر Cairo، ویژگی‌های خاصی دارند.

## مفهوم اصلی

نوع `Felt252Dict<T>` امکان کار با دیکشنری را در Cairo فراهم می‌کند، با `felt252` به عنوان نوع کلید و هر نوع پشتیبانی‌شده‌ی `T` به عنوان نوع مقدار.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## ویژگی‌های مهم

برخلاف دیکشنری‌ها در زبان‌های دیگر، دیکشنری‌های Cairo چند ویژگی ویژه دارند:

1. کلیدها باید مقادیری از نوع `felt252` باشند.
2. همه‌ی کلیدها به‌طور ضمنی با مقدار صفر شروع می‌شوند.
3. نمی‌توانید درایه‌ها را حذف کنید، فقط می‌توانید مقدارها را به‌روزرسانی کنید.
4. مقدارها باید صفت `Felt252DictValue` را پیاده‌سازی کنند.

## نکته‌ی کارایی

به دلیل مدل حافظه‌ی تغییرناپذیر Cairo، عملیات دیکشنری پیچیدگی $O(n)$ دارد، که در آن $n$ تعداد عملیات انجام‌شده روی دیکشنری است.

هر عملیات یک درایه‌ی تازه می‌سازد که تغییر را ثبت می‌کند.

## کار با انواع داده‌ی پیچیده

برای نوع‌هایی که صفت `Felt252DictValue` را پیاده‌سازی نمی‌کنند (مانند آرایه یا ساختار)، می‌توانید آن‌ها را در `Nullable<T>` بپیچید:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## مدیریت حافظه

دیکشنری‌ها صفت `Destruct` را پیاده‌سازی می‌کنند؛ یعنی وقتی از حوزه‌ی دید خارج می‌شوند، به‌طور خودکار «فشرده» می‌شوند (اعتبارسنجی و بهینه‌سازی).

این بخشی از سیستم اثبات Cairo است و در پشت‌صحنه اتفاق می‌افتد.

به یاد داشته باشید: هرچند دیکشنری‌ها ممکن است در مقایسه با زبان‌های دیگر کم‌کارآمدتر به نظر برسند، اما به این شکل طراحی شده‌اند تا با مدل حافظه‌ی ویژه و الزامات سیستم اثبات Cairo کار کنند.
