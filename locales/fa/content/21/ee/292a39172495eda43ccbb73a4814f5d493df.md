# دستورالعمل‌ها

آسترید، یک کیمیاگر ماجراجو، در تلاش است واحدهای جادویی اندازه‌گیری را که از قلمروهای مختلف جمع‌آوری می‌کند استانداردسازی کند.
برخی قلمروها از اندازه‌گیری‌های علامت‌دار استفاده می‌کنند (که می‌توانند منفی باشند) و برخی دیگر از اندازه‌گیری‌های بدون علامت (که همیشه مثبت‌اند).
علاوه بر این، آسترید برای بعضی مواد اولیه‌ی کمیاب دو نوع سفارشی دارد و به راهی نیاز دارد که به‌سادگی بین این نوع‌ها تبدیل انجام دهد.

مأموریت شما این است که به آسترید کمک کنید بین اعداد صحیح علامت‌دار و بدون علامت تبدیل انجام دهد و با استفاده از دو `trait` به نام‌های `Into` و `TryInto` در Cairo، تبدیل‌های نوع سفارشی برای انواع مواد اولیه‌ی خاص او بسازد.

## 1. تبدیل واحدهای جادویی بین اعداد علامت‌دار و بدون علامت

آسترید اندازه‌گیری‌هایی دارد که گاهی با مقادیر مثبت یا منفی می‌آیند (اعداد صحیح علامت‌دار)، اما برای بعضی کارها باید مطمئن شود که مقادیر همیشه مثبت باشند (اعداد صحیح بدون علامت).

با نوشتن تابعی به آسترید کمک کنید که این‌ها را تبدیل کند:

1. یک عدد صحیح علامت‌دار (`i32`) را به یک عدد صحیح بدون علامت (`u16`).
2. یک عدد صحیح بدون علامت (`u16`) را به یک عدد صحیح علامت‌دار (`i32`).

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. تبدیل انواع سفارشی مواد اولیه

آسترید با دو ماده‌ی اولیه‌ی کمیاب کار می‌کند، **Essence** و **Elixir**، که با انواع سفارشی نمایش داده می‌شوند.
او می‌خواهد بتواند **Essence** را به **Elixir** تبدیل کند، اما نه برعکس.

با ساختن دو نوع سفارشی، `Essence` و `Elixir`، و پیاده‌سازی `trait` `Into` برای تبدیل `Essence` به `Elixir` به آسترید کمک کنید.

تابعی بنویسید که یک `Essence` می‌گیرد و با استفاده از `.into()` آن را به یک `Elixir` تبدیل می‌کند.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
