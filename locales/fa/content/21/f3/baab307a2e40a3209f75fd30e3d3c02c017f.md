# مقدمه

Gleam می‌تواند روی ماشین مجازی Erlang (همان BEAM) یا روی رانتایم‌های JavaScript اجرا شود. زبان‌های بسیار دیگری هم از این رانتایم‌ها استفاده می‌کنند و اغلب مفید است که بتوان کد نوشته‌شده به این زبان‌ها را از داخل Gleam فراخوانی کرد.

ویژگی «توابع خارجی» در Gleam اجازه می‌دهد توابعی که به زبان‌های دیگر نوشته شده‌اند به Gleam وارد شوند و بدون هیچ سرباری در زمان اجرا فراخوانی شوند.

اگر پروژه‌ی Gleam شما روی ماشین مجازی Erlang اجرا می‌شود و می‌خواهید تابع `reverse` را از ماژول `lists` در Erlang فراخوانی کنید، می‌توانید با افزودن ویژگی `@external` به سر تعریف یک تابع Gleam این کار را انجام دهید:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

سپس می‌توان آن را مانند یک تابع معمولی Gleam فراخوانی کرد:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

اگر بخواهید این کد را برای رانتایم‌های JavaScript کامپایل کنید، شکست می‌خورد و پیام خطا می‌دهد، چون پیاده‌سازی‌ای برای JavaScript وجود ندارد. می‌توان پیاده‌سازی دیگری را برای رانتایم‌های JavaScript این‌طور مشخص کرد:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

همچنین می‌توانید پیاده‌سازی‌ای به زبان Gleam بنویسید که وقتی برای هدف کامپایل فعلی پیاده‌سازی خارجی وجود ندارد، به کار برود:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
