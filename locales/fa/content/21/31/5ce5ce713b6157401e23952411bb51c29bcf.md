# دستورالعمل‌ها

شما به آشپزخانه برگشته‌اید و دارید دستور لازانیا را از [لازانیای خوشمزه‌ی لی][lasagna] بهتر می‌کنید. کارهای اینجا از شما می‌خواهند چند ورودی را هم‌زمان مدیریت کنید و این دقیقاً همان جایی است که «متغیرهای محلی»، یعنی اتصال‌های بانامِ Factor، به کار می‌آیند.

## 1. تعیین وضعیت پخت

تابع `cooking-status` را تعریف کنید تا یک مقدار تایمر را از پشته بردارد و یک رشته‌ی وضعیت برگرداند.

- `0` → `"Lasagna is done."`
- `f` (تایمر هرگز تنظیم نشده است) → `"You forgot to set the timer."`
- هر عدد دیگری → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. تخمین زمان آماده‌سازی

تابع `preparation-time` را تعریف کنید تا آرایه‌ای از اسم لایه‌ها و میانگین تعداد دقیقه به ازای هر لایه را بگیرد و زمان کل آماده‌سازی را برگرداند.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. محاسبه‌ی رشته‌فرنگی و سس لازم

تابع `quantities` را تعریف کنید تا آرایه‌ای از اسم لایه‌ها بگیرد و *دو* مقدار برگرداند: گرم رشته‌فرنگی لازم (۵۰ گرم برای هر لایه‌ی رشته‌فرنگی) و لیتر سس لازم (`1/5` لیتر برای هر لایه‌ی سس).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. افزودن ماده‌ی اولیه‌ی مخفی

دوستتان فهرستی از مواد اولیه می‌فرستد؛ *آخرین* عنصر، ماده‌ی مخفی اوست. تابع `add-secret-ingredient` را تعریف کنید تا فهرست او و فهرست شما را بگیرد و فهرست شما را با ماده‌ی مخفیِ افزوده‌شده به انتهایش برگرداند.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. تغییر مقیاس دستور پخت

دستور پختِ کتاب آشپزی برای دو وعده کافی است. تابع `scale-recipe` را تعریف کنید تا یک دستور پخت (یک جدول هش که اسم ماده‌ی اولیه را به مقدار آن نگاشت می‌کند) و تعداد وعده‌های هدف را بگیرد و دستور پختی تازه و متناسب با آن برگرداند.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
