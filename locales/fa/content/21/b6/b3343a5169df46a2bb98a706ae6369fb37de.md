الیز به عنوان یک جادوگر تازه‌کار باید چند تکنیک پایه را تمرین کند.
او یک دسته کارت دارد که می‌خواهد آن را دست‌کاری کند.

برای اینکه کار کمی راحت‌تر شود، فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

## 1. بازیابی یک کارت از دسته

کارت واقع در موقعیت `idx` را از دسته‌ی داده‌شده برگردانید.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. تعویض یک کارت در دسته

کارت واقع در موقعیت `idx` را با کارت جدید ارائه‌شده تعویض کنید و دسته‌ی تنظیم‌شده را برگردانید.
توجه داشته باشید که این کار بردار ورودی را دست‌کاری می‌کند (تغییر می‌دهد) و این اشکالی ندارد.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. درج یک کارت در بالای دسته

کارت جدید را در بالای دسته درج کنید و دسته را برگردانید.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. حذف یک کارت از دسته

کارت واقع در موقعیت `idx` را از دسته حذف کنید و دسته را برگردانید.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. حذف کارت بالای دسته

کارت بالای دسته را حذف کنید و دسته را برگردانید.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. درج یک کارت در پایین دسته

کارت جدیدی را در پایین دسته درج کنید و دسته را برگردانید.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. حذف یک کارت از پایین دسته

کارت پایین دسته را حذف کنید و دسته را برگردانید.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. بررسی اندازه‌ی دسته

بررسی کنید که آیا اندازه‌ی دسته با `deck_size` داده‌شده برابر است یا نه.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
