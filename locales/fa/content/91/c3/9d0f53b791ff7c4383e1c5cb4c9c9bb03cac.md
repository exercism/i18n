# دستورالعمل‌ها

الیس، شعبده‌باز آینده، آموزشش را ادامه می‌دهد.
چند دسته‌کارت به او داده می‌شود که برای اجرای تردستی‌هایش به آن‌ها نیاز دارد.
برای اینکه کار کمی ساده‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.
از هر کارت فقط یکی دارد و در دسته‌کارت‌هایش کارت تکراری وجود ندارد.

در این تمرین، برای تحلیل محتویات یک آرایه از متدهای کتابخانه‌ی Base در Julia استفاده کنید.

## 1. تعیین کنید که یک کارت در دسته هست یا نه

الیس می‌خواهد بداند آیا کارتی در دسته وجود دارد؛ به بیان دیگر، آیا دسته شامل یک عدد مشخص هست یا نه.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. جایگاه یک کارت را پیدا کنید

الیس می‌خواهد جایگاه (اندیس) یک کارت را در دسته بداند.
اگر کارت در دسته نباشد، `nothing` را برگردانید.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. تعیین کنید که هر کارت زوج است یا نه

الیس می‌خواهد بداند آیا همه‌ی کارت‌ها زوج هستند؛ به بیان دیگر، آیا هر عدد در دسته زوج است.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. بررسی کنید که دسته کارت فرد دارد یا نه

الیس می‌خواهد بداند آیا عددی فرد در دسته وجود دارد.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. جایگاه اولین کارت زوج را تعیین کنید

الیس می‌خواهد جایگاه اولین کارت زوج را بداند.
اگر در دسته کارت زوجی وجود ندارد، `nothing` را برگردانید.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. اولین کارت فرد دسته را به دست آورید

الیس می‌خواهد مقدار اولین کارت فرد را بداند.
اگر در دسته کارت فردی وجود ندارد، `nothing` را برگردانید.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
