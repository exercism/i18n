# درباره

یک `SYMBOL:` یک مقدار را *در خود نگه نمی‌دارد*؛ فقط یک اسم است. مقدار در یک فضای نام زندگی می‌کند و اسم، کلید ورود به آن است.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

دو دامنه وجود دارد:

- **سراسری**: با `set-global`، `get-global` و `change-global` نوشته و خوانده می‌شود. مقادیر تا پایان عمر فرایند باقی می‌مانند.
- **پویا**: با `set`، `get` و `change` نوشته و خوانده می‌شود. اتصال‌ها به مدت اجرای یک قالب `with-variable` زنده می‌مانند و به کد بیرونی اجازه می‌دهند مقداری را که کد درونی می‌بیند، بدون تغییر دادن همه‌ی امضاهای میانی، «تزریق» کند.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` و `SYMBOLS:` نمادها را در زمان بارگذاری واژگان اعلان می‌کنند و آن‌ها را به ارجاع‌هایی تبدیل می‌کنند که میان فایل‌ها قابل اشتراک‌اند.
