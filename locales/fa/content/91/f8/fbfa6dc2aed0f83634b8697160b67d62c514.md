# درباره

«اعداد اعشاری» اعدادی کسری یا صحیح هستند که یک ممیز اعشاری دارند (مانند `3.14`، `-1.7`، `99.99` و `2048.0`).

نوع `float` در Common Lisp به چند زیرنوع تقسیم می‌شود که هرکدام ویژگی‌ها و دقت خاص خود را دارند: `short-float`، `single-float`، `double-float` و `long-float`.

زیرنوع `short-float` معمولاً کمترین مقدار حافظه را اشغال می‌کند و در میان این چهار زیرنوع کمترین دقت را دارد. این زیرنوع برای موقعیت‌هایی مناسب است که مقدار حافظه اهمیت دارد، اما دقت کمتر قابل‌قبول است.

زیرنوع `single-float` تعادلی میان مصرف حافظه و دقت برقرار می‌کند. معمولاً از آن برای محاسبات اعشاری عمومی استفاده می‌شود.

زیرنوع `double-float` در مقایسه با `single-float` دقت بالاتری ارائه می‌دهد و برای برنامه‌هایی مناسب است که به محاسبات دقیق‌تری نیاز دارند، مانند محاسبات علمی و شبیه‌سازی‌های عددی.

زیرنوع `long-float` بالاترین دقت را در میان این چهار زیرنوع ارائه می‌دهد، اما ممکن است در مقایسه با بقیه به حافظه‌ی بیشتری نیاز داشته باشد. معمولاً از آن برای برنامه‌های تخصصی استفاده می‌شود که به محاسبات بسیار دقیق نیاز دارند.

این زیرنوع‌ها به برنامه‌نویسان Common Lisp اجازه می‌دهند سطح مناسب دقت و مصرف حافظه را بر اساس نیازهای برنامه‌ی خاص خودشان انتخاب کنند.

به‌طور کلی، اگر فقط با اعداد صحیح کار می‌کنید، بهتر است همین نوع صحیح را انتخاب کنید، چون در محاسبات متعدد، برخلاف اعداد اعشاری، دقت خود را از دست نمی‌دهند.

## مراجع

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
