# دستورالعمل‌ها

به عنوان یک علاقه‌مند به شطرنج، می‌خواهید نسخه‌ی خودتان از این بازی را بنویسید.
درست است که شاید همین حالا پیاده‌سازی‌های زیادی از شطرنج به صورت آنلاین در دسترس باشد، اما نسخه‌ی شما یگانه خواهد بود!

شما کار را با پیاده‌سازی یک سیستم حرکت پایه برای مهره‌ها شروع می‌کنید.

بازی شطرنج روی صفحه‌ای به عرض هشت خانه و طول هشت خانه انجام می‌شود.
خانه‌ها با یک حرف و یک عدد مشخص می‌شوند.

## 1. تعریف بازه‌ی رتبه و فایل

بازی باید رتبه‌های صفحه را نگه دارد.
رتبه‌ها همان سطرهای صفحه هستند و از ۱ تا ۸ شماره‌گذاری می‌شوند.

بازی همچنین باید فایل‌های صفحه را نگه دارد.
فایل‌ها همان ستون‌های صفحه هستند و با حروف A تا H مشخص می‌شوند.

ثابت‌های `Chess::RANKS` و `Chess::FILES` را تعریف کنید که به ترتیب بازه‌ی رتبه‌ها و فایل‌ها را نگه می‌دارند.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. بررسی معتبر بودن خانه

بازی باید بررسی کند که آیا یک خانه معتبر است.
یک خانه زمانی معتبر است که رتبه و فایل آن در محدوده‌ی رتبه‌ها و فایل‌ها باشند.

متد `Chess.valid_square?` را تعریف کنید که دو آرگومان می‌گیرد: `rank` که عددی صحیح از رتبه را نگه می‌دارد و `file` که کاراکتری از فایل را نگه می‌دارد.
متد باید اگر رتبه و فایل در محدوده‌ی رتبه‌ها و فایل‌ها باشند `true` را برگرداند و در غیر این صورت `false` را.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. گرفتن اسم مستعار بازیکن

بازی باید اسم مستعار بازیکن را به دست آورد.
اسم مستعار از دو کاراکتر اول اسم کوچک بازیکن و دو کاراکتر آخر اسم خانوادگی او ساخته می‌شود.
اسم مستعار باید با حروف بزرگ نوشته شود.

متد `Chess.nickname` را تعریف کنید که دو آرگومان می‌گیرد: `first_name` که رشته‌ای از اسم کوچک بازیکن را نگه می‌دارد و `last_name` که رشته‌ای از اسم خانوادگی بازیکن را نگه می‌دارد.
متد باید اسم مستعار بازیکن را به صورت یک رشته با حروف بزرگ برگرداند.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. ساختن پیام حرکت

بازی باید برای هر حرکت پیامی بسازد تا بگوید کدام بازیکن به کدام خانه حرکت کرده است.
این پیام باید از اسم مستعار بازیکن و خانه‌ای که به آن حرکت کرده استفاده کند.
بازی همچنین باید با بررسی اینکه آیا فایل و رتبه‌ی خانه در محدوده‌ی فایل‌ها و رتبه‌ها هستند یا نه، معتبر بودن حرکت را مشخص کند.

اگر حرکت معتبر باشد، پیام باید این باشد: `"{nickname} moved to {square}"`
اگر حرکت معتبر نباشد، پیام باید این باشد: `"{nickname} attempted to move to {square}, but that is not a valid square"`

متد `Chess.move_message` را تعریف کنید که سه آرگومان می‌گیرد: `first_name` که رشته‌ای از اسم کوچک بازیکن را نگه می‌دارد، `last_name` که رشته‌ای از اسم خانوادگی بازیکن را نگه می‌دارد و `square` که رشته‌ای از خانه‌ای را نگه می‌دارد که بازیکن به آن حرکت کرده است.
متد باید پیام حرکت را به صورت یک رشته برگرداند.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
