# آرایه

آرایه‌ها در PHP نقشه‌های مرتب‌شده هستند.
نقشه یک ساختار داده است که یک کلید را به یک مقدار نسبت می‌دهد.
آرایه‌ها انعطاف‌پذیرند و می‌توان آن‌ها را مانند یک آرایه‌ی خطی (مثل `C` یا `Java`)، لیست [بردار]، جدول درهم‌سازی، دیکشنری، مجموعه، پشته یا صف در نظر گرفت و به کار برد.

کلید اختیاری است، اما اگر مشخص شود باید یا `int` باشد یا `string`.
وقتی کلیدی ارائه نشود، PHP به‌طور پیش‌فرض از کلیدهای عددی صحیح و به ترتیب صعودی، با شروع از `0`، استفاده می‌کند.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

آرایه می‌تواند مقادیری از همه‌ی نوع‌ها را در خود نگه دارد.
هر مقدار می‌تواند نوع متفاوتی داشته باشد.

## استفاده از آرایه‌ها

می‌توان آرایه‌ها را به‌صورت لیترال تعریف کرد (مستقیم در کد نوشت، همان‌طور که در بالا دیدیم) یا آن‌ها را با توابع ایجاد و دستکاری کرد.
با عملگر اندیس می‌توانید به مقادیر دسترسی بگیرید، مقداری اختصاص دهید یا مقداری را به انتهای آرایه اضافه کنید:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
