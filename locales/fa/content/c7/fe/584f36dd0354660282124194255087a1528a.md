# درباره

در یک زبان تابعی خالص مانند Elm، تابعی که با آرگومان‌های یکسان فراخوانی شود باید همیشه همان مقدار را برگرداند.
بنابراین تابعی با امضای نوع `rand : Int` را فقط می‌توان به‌صورت (`rand = 4`)[xkcd-random] پیاده‌سازی کرد، که برای تولید اعداد صحیح تصادفی چندان امیدوارکننده نیست.

حالا چطور در Elm مقادیر تصادفی تولید کنیم؟
مسئله را به دو بخش تقسیم می‌کنیم: اول مقداری را که می‌خواهیم تولید کنیم با یک `Random.Generator a` توصیف می‌کنیم، سپس مقداری تولید می‌کنیم.

اولین راه برای تولید یک مقدار این است که با `initialSeed : Int -> Seed` یک `Random.Seed` بسازیم.
`Seed` نوعی مبهم است که یک عدد صحیح در خود دارد و می‌داند چطور آن عدد صحیح را به‌گونه‌ای تغییر دهد که تصادفی به نظر برسد (که به آن «شبه‌تصادفی» می‌گویند).
وقتی یک `Seed` داشته باشید، می‌توانید با یک `Generator a` مقدار تولید کنید.
`Generator a` نوعی مبهم است که می‌داند چطور از عدد صحیح داخل یک `Seed` برای ساختن یک مقدار شبه‌تصادفی از نوع `a` و همچنین یک `Seed` جدید با عدد صحیح به‌روزشده استفاده کند.

برای تولید یک مقدار می‌توانیم از `step : Generator a -> Seed -> ( a, Seed )` استفاده کنیم، که یک مقدار و یک `Seed` جدید برمی‌گرداند که می‌توانیم با آن مقادیر بیشتری تولید کنیم.

بیایید با این توابع، `n` مقدار تصادفی را از یک مولد بیرون بکشیم:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

توجه کنید که همه‌ی این توابع خالص هستند، بنابراین اگر دو بار با آرگومان‌های یکسان فراخوانی شوند، همان مقادیر را تولید می‌کنند.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

دومین راه برای تولید یک مقدار استفاده از `Random.generate : (a -> msg) -> Generator a -> Cmd msg` است، اما این کار فقط داخل یک برنامه‌ی Elm امکان‌پذیر است.
در آن صورت، محیط اجرای Elm ممکن است علاوه بر `step` از منابع بیرونی و ناخالص هم برای تولید `Seed`ها استفاده کند، و فراخوانی دو باره‌ی یک تابع نتایج متفاوتی به دست می‌دهد.

از این پس روی مولدها تمرکز می‌کنیم.

ماژول `Random` دو مولد پایه برای ساختن اعداد صحیح و اعشاری در یک بازه‌ی مشخص فراهم می‌کند:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

این مقادیر را می‌توان در تاپل‌ها یا در فهرست‌هایی از مقادیر ترکیب کرد:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

بسته‌ی (`elm-community/random-extra`)[random-extra] مولدهای بسیار بیشتری برای ساختمان‌های داده‌ی مختلف فراهم می‌کند: رشته‌ها، تاریخ‌ها، دیکشنری‌ها، آرایه‌ها، مجموعه‌ها و غیره.

می‌توانیم با `Random.constant` مولدهایی بسازیم که فقط یک مقدار واحد برمی‌گردانند:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

می‌توانیم با `Random.uniform` به‌صورت تصادفی و با احتمال برابر از میان عناصر داده‌شده انتخاب کنیم:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` دو آرگومان می‌گیرد (`Red` و `[Green, Blue]`) تا تضمین شود حداقل یک مقدار برای انتخاب وجود دارد، چون یک فهرست تکی می‌تواند خالی باشد.

همچنین می‌توانیم با `Random.weighted` احتمال‌ها را تنظیم کنیم:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

مقادیر لازم نیست به ۱۰۰ برسند، در هر حال دوباره نرمال می‌شوند.

می‌توانیم با `Random.map` به داخل یک مولد دست پیدا کنیم:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

همچنین می‌توانیم از `Random.map2` تا `Random.map5` برای ترکیب مولدهای بیشتر استفاده کنیم:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

برای کاربردهای پیچیده‌تر، `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` را داریم که می‌تواند از مقدار تولیدشده توسط یک مولد برای ساختن مولد دیگری استفاده کند:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

گاهی اوقات تعریف یک مولد به‌صورت خودبازگشتی مفید است.
در این موارد، ممکن است لازم باشد از `Random.lazy` استفاده کنید تا کامپایلر مولد را بی‌نهایت بازگشایی نکند.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

این مثال کمی سنگین است، پس بیایید آن را جزءبه‌جزء بررسی کنیم.

`Peano` نوعی است که اعداد صحیح مثبت را نمایش می‌دهد: `Zero` همان ۰ است، `Next(Zero)` همان ۱ است، `Next(Next(Zero))` همان ۲ است و به همین ترتیب.
`peano` را تعریف می‌کنیم تا یک عدد `Peano` تصادفی به ما بدهد.

پیش از هر چیز، توجه کنید که `Random.lazy` چیزی به منطق اضافه نمی‌کند و فقط جلوی کامپایلر را می‌گیرد که `peano` را بی‌پایان در `peano` ننویسد.

از `Random.uniform` استفاده می‌کنیم تا بین صفر (با احتمال ۵۰٪) و عدد `Peano` دیگری به‌علاوه‌ی یک (با احتمال ۵۰٪) انتخاب کنیم.
اما برخلاف مثال قبلی، `Random.uniform` از میان مقادیر (مانند `Zero`) انتخاب نمی‌کند، بلکه از میان مولدها (مانند `Random.constant Zero`) انتخاب می‌کند، چون می‌خواهیم از خود `peano` استفاده کنیم.
این یعنی `Random.uniform` مقداری از نوع `Generator (Generator Peano)` برمی‌گرداند، که آن چیزی نیست که لازم داریم.

برای «مسطح کردن» مولد، آن را به `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` می‌فرستیم، جایی که می‌خواهیم `b` همان `Peano` باشد.
چون `Generator a` همان `Generator (Generator Peano)` است، `a` باید `Generator Peano` باشد و تابع `(a -> Generator b)` باید از نوع `(Generator Peano -> Generator Peano)` باشد.
نمی‌خواهیم چیزی را تغییر دهیم، بنابراین `identity` انتخاب درستی است.

در پایان، `peano` چه نوع اعدادی تولید می‌کند؟
می‌دانیم که در ۵۰٪ مواقع صفر تولید می‌کند، یا در ۵۰٪ مواقع تکرار دیگری از خودش به‌علاوه‌ی یک تولید می‌کند.
یعنی اعداد ۰ (در ۵۰٪ مواقع)، ۱ (در ۲۵٪ مواقع)، ۲ (در ۱۲٪ مواقع)، ۳ (در ۶٪ مواقع) و به همین ترتیب خواهند بود.
`peano` می‌تواند اعداد دلخواه بزرگی تولید کند، اما با احتمالی که به‌صورت نمایی کاهش می‌یابد.
