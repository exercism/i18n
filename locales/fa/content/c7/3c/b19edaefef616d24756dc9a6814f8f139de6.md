## تاپل

از [تاپل ها][tuple] معمولاً برای گروه بندی اطلاعات استفاده می شود؛ آن ها با لیست ها این تفاوت را دارند که اندازه شان ثابت است و می توانند انواع داده ای متفاوتی را در خود نگه دارند.
تاپل ها با پرانتز `()` ساخته می شوند و اغلب برای برگرداندن چند مقدار از یک تابع به کار می روند.

```haskell
tuple = (1, "abc", False)
```

این می تواند مفید باشد، مثلاً وقتی می خواهید مختصاتی را در فضای دوبعدی ذخیره کنید؛ آن وقت می دانید که تاپل همیشه دو عنصر خواهد داشت: مختصات x و y.

```haskell
coordinate = (3, 4)
```

### دسترسی به عنصرها

اغلب با تاپل های کوتاه کار می کنید و می توانید با توابع `fst` و `snd` به عنصرهای آن ها دسترسی داشته باشید.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## تطبیق الگو

هنگام نوشتن توابع Haskell می توانیم از یک [سبک قاطعانه][assertive-style] همراه با [تطبیق الگو][pattern-match-doc] استفاده کنیم:
تطبیق الگو یکی از قابلیت های بسیار قدرتمند Haskell است که به شما امکان می دهد روی سازنده های داده تطبیق بزنید و متغیرها را به مقادیر درون آن ها متصل کنید.
همان طور که از نامش پیداست، کاری که می کنیم تطبیق مقادیر با الگوهاست؛ اگر مقدار با الگو تطبیق پیدا کند، می توانیم متغیرها را به مقادیر درون الگو متصل کنیم.
تطبیق الگو عمدتاً از این مفاهیم ساخته شده است: تشخیص مقادیر، اتصال متغیرها و تجزیه ی مقادیر.

برای مثال، این تابع را در نظر بگیرید:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

اینجا تابعی به اسم `lucky` داریم که یک `Int` می گیرد و یک `String` برمی گرداند.
برای این تابع دو الگو تعریف کرده ایم: یکی که با عدد `7` تطبیق می کند و یکی که با هر عدد دیگری تطبیق می کند. اسم می تواند هرچه باشد (تا زمانی که از قرارداد نام گذاری Haskell پیروی کند)، اما اینجا از `x` استفاده می کنیم.
اگر عدد `7` باشد، تابع `"Lucky number seven!"` را برمی گرداند؛ در غیر این صورت `"Sorry, you're out of luck, pal!"` را برمی گرداند.
نکته ی مهم اینجاست که الگوها از بالا به پایین بررسی می شوند؛ پس اگر ترتیب الگوها را جابه جا کرده بودیم، تابع همیشه `"Lucky number seven!"` را برمی گرداند.

### الگوهای لیست

یکی از الگوهای بسیار رایج، تطبیق روی لیست هاست که همان گرفتن سر و دنباله ی لیست است.
این به دلیل ماهیت لیست ها به عنوان یک لیست پیوندی است.
اینجا نمونه ای از تابعی است که سر و دنباله ی یک لیست را برمی گرداند:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

اینجا دو الگو داریم: یکی که با یک لیست خالی تطبیق می کند و یکی که با لیستی با حداقل یک عنصر تطبیق می کند.
چون اگر لیست خالی باشد، باید برای آن یک حالت داشته باشیم؛ در غیر این صورت با خطای زمان اجرا روبه رو می شویم.
اگر لیست خالی نباشد، می توانیم سر لیست را با `x` و دنباله ی لیست را با `xs` تطبیق دهیم.
این کار با عملگر `:` (cons) انجام می شود که برای افزودن یک عنصر به ابتدای لیست به کار می رود.
اما در تطبیق الگو به ما اجازه می دهد لیست را به سر و دنباله اش تجزیه کنیم؛ یعنی به نوعی برعکس عمل می کند.

اسم `xs` برای دنباله ی لیست رایج است و نشان می دهد که یک لیست است؛ اما اگر با یک لیست تودرتو کار کنید، می توانید از `xss` استفاده کنید تا نشان دهید که لیستی از لیست هاست.

### الگوهای تاپل

همانند لیست ها، می توانیم روی تاپل ها هم تطبیق کنیم.
اینجا نمونه ای از تابعی است که یک تاپل می گیرد و عنصر اول و دوم را برمی گرداند:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

اینجا الگویی داریم که با تاپلی با دو عنصر تطبیق می کند؛ عنصر اول به `x` و عنصر دوم به `y` متصل می شود.

### الگوهای عام

گاهی به مقدار یک متغیر اهمیتی نمی دهیم و فقط می خواهیم روی الگو تطبیق بزنیم.
اینجاست که الگوی عام به کار می آید؛ این الگو با زیرخط `_` نشان داده می شود.

اینجا نمونه ای از تابعی است که اولین عنصر یک لیست را برمی گرداند:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

اینجا می گوییم که به دنباله ی لیست نیازی نداریم، پس از الگوی عام استفاده می کنیم تا آن را نادیده بگیریم.

### الگوهای نوع

می توانیم روی نوع ها هم تطبیق کنیم؛ این کار با استفاده از سازنده ی همان نوع انجام می شود.
همچنین می توانیم مقادیر را از نوع استخراج کنیم، همان طور که با تاپل ها انجام دادیم.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

در الگوی اول با سازنده ی `Guest` تطبیق می کنیم و در الگوی دوم با سازنده ی `User` تطبیق می کنیم و مقدار درون آن را به `name` متصل می کنیم.

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
