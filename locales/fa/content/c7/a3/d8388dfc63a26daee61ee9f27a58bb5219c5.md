# درباره

«[نقشه][maps]» یک ساختار داده است که جفت‌های کلید-مقدار را نگه می‌دارد.

- کلیدها می‌توانند از هر نوعی باشند، اما باید یکتا باشند.
- مقدارها می‌توانند از هر نوعی باشند و لازم نیست یکتا باشند.
- نقشه ترتیب محتویات خود را تضمین نمی‌کند، هرچند چنین به نظر می‌رسد.
  - پیاده‌سازی زیربنایی آن این تصور اشتباه را ایجاد می‌کند:
    - در اندازه‌های کوچک (حداکثر ۳۲ عضو)، به صورت یک «[لیست کلیدواژه][keyword-list]» که مرتب است پیاده‌سازی می‌شود.
    - در اندازه‌های بزرگ‌تر (بیش از ۳۲ عضو)، به صورت یک «[درخت پیشوندی نگاشت‌شده با آرایه‌ی هش][hamt]» پیاده‌سازی می‌شود &#91;[۱][stackoverflow]&#93;.
- نقشه را می‌توان با شکل نوشتاری تعریف کرد:

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- نقشه را می‌توان با استفاده از [`Map.new`][map-new] از [ماژول `Map`][map-module] نیز نمونه‌سازی کرد. این کار ممکن است زمانی استفاده شود که از قبل یک مجموعه‌ی قابل شمارش دارید که می‌خواهید به لیست تبدیل کنید:

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- به مقدارهای داخل یک نقشه می‌توان به روش‌های مختلفی دسترسی پیدا کرد:

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- [ماژول `Map`][map-module] که همراه کتابخانه‌ی استاندارد ارائه می‌شود، توابع مفید زیادی برای استفاده از نقشه دارد.

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- نقشه پروتکل [`Enumerable`][enumerable] را پیاده‌سازی می‌کند و امکان استفاده از توابع [ماژول `Enum`][enum] را فراهم می‌کند.
- [توابع بی‌نام][anon-fn] یا [ارجاع‌های تابع گرفته‌شده][captured-fn] اغلب به عنوان آرگومان برای توابع [`Map`][map-module] و [ماژول `Enum`][enum] لازم هستند

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
