بلوک‌های کد در Raku به‌وفور استفاده می‌شوند.
هم برای توابع ضروری‌اند و هم در ابزارهایی مانند `grep` و `map`، در قالب بلوک‌های دستورهای `if`، `for`، `while` و `given` و نیز در اندیس‌های آرایه به کار می‌روند.

## روتین

[`Subs`][type/Sub] و [`Methods`][type/Method] در Raku نوع‌هایی از [`Routines`][type/Routine] هستند.

یک روتین می‌تواند هر زمان با استفاده از کلیدواژه‌ی [`return`][control-return] و همراه با یک مقدار بازگشتی پایان یابد؛ ابزاری مفید برای ساختن توابع.
اگر هیچ `return` مشخص نشود، آخرین دستور روتین، مقدار بازگشتی ضمنی آن خواهد بود.

یک روتین می‌تواند پیش از بلوک کد، یک [`Signature`][language/signatures] داخل پرانتز داشته باشد.

[`Routine`][type/Routine] زیرکلاسی از [`Block`][type/Block] است.

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

متدها در مفهوم جداگانه‌ای درباره‌ی کلاس‌ها و اشیا بررسی خواهند شد.

## بلوک

[`Block`][type/Block] یک شیء کد قابل استفاده‌ی مجدد است که معمولاً برای ساختن لامبدا به کار می‌رود.

آخرین دستور یک بلوک، مقدار بازگشتی ضمنی آن است.

یک بلوک می‌تواند یک [`Signature`][language/signatures] داشته باشد که پیش از بلوک کد با `->` می‌آید.

[`Block`][type/Block] زیرکلاسی از [`Code`][type/Code] است که خودْ کلاس پایه‌ی نهایی همه‌ی اشیای کد در Raku به شمار می‌رود.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## امضا

یک [`Signature`][language/signatures] از صفر یا چند [`Parameters`][type/Parameter] تشکیل می‌شود که با کاما از هم جدا می‌شوند.

در پایان یک امضا می‌توان نوع بازگشتی را با [پیکان نوع بازگشتی][signatures-return-type-arrow] `-->` مشخص کرد.

از یک امضا می‌توان برای مشخص کردن آرگومان‌هایی که یک `Block` می‌پذیرد استفاده کرد.

در این مفهوم، امضاها ساده نگه داشته می‌شوند و تنها از پارامترهای مکانی با متغیرهای دارای سیگیل اسکالر و یک نوع بازگشتی استفاده می‌شود.
این موارد در مفاهیم دیگر بیشتر بسط داده می‌شوند.

## Multi-Dispatch

Raku با استفاده از کلیدواژه‌ی `multi` امکان نوشتن چندین روتین با اسم یکسان ولی امضاهای متفاوت را فراهم می‌کند.
این ویژگی با نام [multi-dispatch][multi-dispatch] شناخته می‌شود.
وقتی روتین با اسمش فراخوانی می‌شود، محیط زمان اجرا نامزد مناسب را تعیین و آن را فراخوانی می‌کند.

این موضوع در مفهومی درباره‌ی انواع با جزئیات بیشتری بررسی می‌شود.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

وقتی ستاره‌ی [`Whatever`][type/Whatever] یعنی `*` در ترکیب با بیشتر عملگرها به کار رود، یک شیء [`WhateverCode`][type/WhateverCode] ساخته می‌شود.
این کار به شما امکان می‌دهد بلوک‌هایی با نحوه‌ی نگارش ساده‌تر بسازید.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
