# مقدمه

در Java، «سربارگذاری متد» ویژگی‌ای است که به یک کلاس اجازه می‌دهد بیش از یک متد با اسم یکسان داشته باشد، به شرط آنکه فهرست پارامترهایشان متفاوت باشد.
این مفهوم با «چندریختی» زمان کامپایل (یا ایستا) مرتبط است.
این مفهوم برای ساختن متدهایی حیاتی است که کارهای مشابهی انجام می‌دهند، اما با ورودی‌های متفاوت.

## چرا متدها را سربارگذاری کنیم؟

سربارگذاری متد خوانایی برنامه را افزایش می‌دهد.
می‌توان به متدهای مختلف اسم یکسان داد، اما با پارامترهای متفاوت.
بسته به تعداد یا نوع پارامترها، متد متناظر فراخوانی می‌شود.

## چگونه متدها را سربارگذاری کنیم؟

کلید سربارگذاری متد، «امضای متد» است.
دو متد در صورتی متفاوت به حساب می‌آیند که امضاهای متفاوتی داشته باشند.
دو راه برای سربارگذاری یک متد وجود دارد:

1. **تعداد متفاوت پارامترها**: متدها می‌توانند اسم یکسان داشته باشند، اما تعداد پارامترهایشان متفاوت باشد.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **انواع متفاوت پارامترها**: متدها می‌توانند اسم یکسان و تعداد پارامترهای یکسانی داشته باشند، اما با انواع متفاوت.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## نکاتی که باید به خاطر بسپارید

- متدهای سربارگذاری‌شده باید فهرست آرگومان‌ها را تغییر دهند.
- متدهای سربارگذاری‌شده می‌توانند نوع بازگشتی را هم تغییر دهند، اما تغییر دادن تنها نوع بازگشتی، سربارگذاری متد به حساب نمی‌آید.
- متدها را می‌توان در همان کلاس یا در یک «زیرکلاس» سربارگذاری کرد.

در این مفهوم، مثال‌ها و نکات ظریف گوناگون سربارگذاری متد در Java را بررسی خواهیم کرد.
