## ویرایشگرها

### رایگان/متن‌باز

- [VS Code](https://code.visualstudio.com)

  VS Code یک ویرایشگر کد متن‌باز است. می‌توانید اطلاعات مربوط به نحوه‌ی راه‌اندازی TypeScript را [اینجا](https://code.visualstudio.com/docs/languages/typescript) پیدا کنید. VS Code ویرایشگر محبوبی برای TypeScript است، چون مایکروسافت هم VS Code و هم TypeScript را نگهداری می‌کند و به همین دلیل به‌خوبی با این زبان کار می‌کند؛ VS Code بدون هیچ تنظیمات اضافه‌ای از TS پشتیبانی می‌کند. در واقع، خود VS Code با TypeScript نوشته شده است!

  یک مشکل رایج در VS Code و TS زمانی رخ می‌دهد که نسخه‌ی ویرایشگر و نسخه‌ی پروژه‌تان با هم متفاوت باشند، و این می‌تواند باعث شود VS Code پیام خطایی نمایش دهد که ممکن است گیج‌کننده باشد. راهنمای نحوه‌ی برخورد با این خطا [اینجا](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions) است.

### نیازمند مجوز

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text ویرایشگر کد محبوبی است که از طریق افزونه‌های قابل نصب از بیشتر زبان‌ها پشتیبانی می‌کند. امتحان کردنش رایگان است، اما مرتب از شما خواسته می‌شود مجوز بخرید، که در حال حاضر ۷۰ دلار آمریکا هزینه دارد.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm یک IDE پرامکانات (محیط توسعه‌ی یکپارچه) برای JavaScript/TypeScript است. بدون هیچ تنظیمات اضافه‌ای از TypeScript پشتیبانی می‌کند و تست، دیباگ و تحلیل کد را به‌صورت یکپارچه در خود دارد. ۳۰ روز رایگان می‌توانید امتحانش کنید، سپس هزینه‌ی مجوز سالانه در سال اول ۱۲۹ دلار آمریکا است.
