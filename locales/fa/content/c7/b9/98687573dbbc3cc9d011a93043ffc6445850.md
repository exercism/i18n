# راهنمایی‌ها

## کلی

- برای تولید اعداد تصادفی می‌توانید از [کلاس `Random`][random-class] استفاده کنید.
- برای اطلاعات بیشتر این مقاله را بخوانید: [مولدهای اعداد تصادفی در Java 17][random-number-generators].

## تولید هزارتو

برای تولید یک هزارتوی کامل می‌توانید از هر الگوریتمی استفاده کنید. [پسگرد بازگشتی][recursive-backtracker] گزینه‌ی خوبی است.
