# اجرای تست‌ها

سیستم‌عامل خود را انتخاب کنید:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. یک Command Prompt باز کنید.
2. اولین تمرین را دریافت کنید:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. دایرکتوری جاری را به پوشه‌ی تمرین تغییر دهید:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. تست‌ها را اجرا کنید:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(نگران شکست خوردن تست‌ها در ابتدا نباشید؛ هر تمرین را این‌گونه شروع می‌کنید.)_

5. تمرین را حل کنید. راهنمای `instructions.append.md` را پیدا کنید و آن را دنبال کنید ([مشاهده در GitHub][hello-world-tutorial]).

موفق باشید! خوش بگذرانید!

1. در پنجره‌ی ترمینال، اولین تمرین را دریافت کنید:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. دایرکتوری جاری را به پوشه‌ی تمرین تغییر دهید:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```


   _(نگران شکست خوردن تست‌ها در ابتدا نباشید؛ هر تمرین را این‌گونه شروع می‌کنید.)_

4. تمرین را حل کنید. راهنمای `instructions.append.md` را پیدا کنید و آن را دنبال کنید ([مشاهده در GitHub][hello-world-tutorial]).

موفق باشید! خوش بگذرانید!

## Linux

1. در پنجره‌ی ترمینال، اولین تمرین را دریافت کنید:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. دایرکتوری جاری را به پوشه‌ی تمرین تغییر دهید:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. تست‌ها را اجرا کنید:

   ```sh
   ./gradlew test
   ```

   _(نگران شکست خوردن تست‌ها در ابتدا نباشید؛ هر تمرین را این‌گونه شروع می‌کنید.)_

   اگر خطای زیر را دریافت کردید:

   ```sh
   ./gradlew: Permission denied
   ```

   یعنی فایل مجوز اجرا ندارد. برای رفع این مشکل، این دستور را اجرا کنید:

   ```sh
   chmod +x ./gradlew
   ```

   و حالا باید بتوانید دستور قبلی را اجرا کنید.

4. تمرین را حل کنید. راهنمای `instructions.append.md` را پیدا کنید و آن را دنبال کنید ([مشاهده در GitHub][hello-world-tutorial]).

موفق باشید! خوش بگذرانید!
