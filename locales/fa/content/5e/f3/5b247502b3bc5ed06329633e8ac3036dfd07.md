# درباره

یک [دستور `switch`][switch] یک مقدار را با چند الگوی ممکنِ منطبق مقایسه می‌کند. این دستور جایگزینی تمیزتر و خواناتر برای زنجیره کردن چند دستور `if-else` است.

دستور `switch` با «کلیدواژه»ی `switch` شروع می‌شود و پس از آن مقداری می‌آید که باید بررسی شود. هر منطبق ممکن با کلیدواژه‌ی `case` معرفی می‌شود. کلیدواژه‌ی `default` حالت جایگزینی را تعریف می‌کند که اگر هیچ‌یک از حالت‌های صریح منطبق نشوند اجرا می‌شود. دستور `switch` مانند زنجیره‌های `if-else` فقط بلوک کدی را اجرا می‌کند که به نخستین حالت منطبق مربوط است.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

زنجیره‌ی `if-else` زیر را در نظر بگیرید:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

می‌توان همین را با یک دستور `switch` شفاف‌تر نوشت:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## اتصال مقدارها به اسم و بندهای `where`

هر حالت در دستور `switch` می‌تواند مقدارهای منطبق را به ثابت‌ها یا متغیرهای موقت اتصال دهد تا در بدنه‌ی همان حالت استفاده شوند. حالت‌ها می‌توانند بند `where` هم داشته باشند تا پیش از منطبق شدن، شرط‌های «منطقی» بیشتری بررسی شود:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
