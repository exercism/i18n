# دستورالعمل‌ها

شما پرنده‌نگری پرشور هستید که شمارش روزانه‌ی پرنده‌هایی را که به باغتان می‌آیند نگه می‌دارید. این شمارش‌ها در یک «آرایه» ذخیره می‌شوند و قدیمی‌ترین روز در ابتدای آن قرار دارد.

## 1. شمارش امروز

تابع `today` را طوری تعریف کنید که آرایه‌ی شمارش‌های روزانه را از «پشته» بردارد و شمارش امروز را برگرداند.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. افزایش شمارش امروز

تابع `increment-todays-count` را طوری تعریف کنید که آرایه‌ی جدیدی برگرداند که در آن شمارش امروز یک واحد افزایش یافته است. آرایه‌ی اصلی نباید تغییر کند.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. آیا روزی بدون پرنده وجود داشت؟

تابع `has-day-without-birds?` را طوری تعریف کنید که اگر دست‌کم در یک روز صفر پرنده ثبت شده باشد `t` و در غیر این صورت `f` را برگرداند.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. مجموع چند روز نخست

تابع `count-for-first-days` را طوری تعریف کنید که یک آرایه‌ی شمارش‌ها و یک عدد `n` بگیرد و مجموع `n` شمارش نخست را برگرداند.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. شمارش روزهای پرمشغله

روز پرمشغله روزی است که پنج پرنده یا بیشتر داشته باشد. تابع `busy-days` را طوری تعریف کنید که تعداد روزهای پرمشغله در آرایه را برگرداند.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. پر کردن روزهای جاافتاده

اگر در همه‌ی روزهای یک بازه‌ی `n` روزه پرنده‌نگری نکرده‌اید، روزهای انتهایی جاافتاده را با `0` پر کنید. تابع `pad-missing-days` را طوری تعریف کنید که یک آرایه‌ی شمارش‌ها و یک طول هدف `n` بگیرد و آرایه‌ای با طول دست‌کم `n` برگرداند که خانه‌های اضافی‌اش `0` باشند. شمارش‌های موجود باید بدون تغییر حفظ شوند؛ اگر طول ورودی از قبل دست‌کم `n` باشد، آن را بدون تغییر برگردانید.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
