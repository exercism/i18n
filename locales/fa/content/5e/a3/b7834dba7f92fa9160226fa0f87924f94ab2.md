# راهنما

## کلی

- [مرجع زبان آرایه][ref-arrays] را مرور کنید.
- [مرجع توابع آرایه][ref-array-functions] را مرور کنید.

## 1. تعریف تابعی که یک فهرست خالی زبان برگرداند

- [مرجع زبان][ref-arrays] را مرور کنید.
- می‌توانید یک آرایه‌ی خالی برگردانید.

## 2. تغییر تابع برای ساختن فهرستی از هر تعداد زبان

- برای [آرگومان‌هایی با طول متغیر][variable-arguments] به مرجع توابع مراجعه کنید.

## 3. تعریف تابعی برای افزودن یک زبان به فهرست

- یک تابع جدید برای انجام این کار بسازید.
- از یک [تابع موجود][ref-array-functions] دوباره استفاده کنید یا از [نحوه‌ی نگارش درج][square-bracket-syntax] بهره ببرید.

## 4. تعریف تابعی برای حذف یک عنصر از فهرست زبان

- یک تابع جدید برای انجام این کار بسازید.
- برای انجام این کار از یک [تابع موجود][ref-array-functions] دوباره استفاده کنید.

## 5. تعریف تابعی برای گرفتن اولین عنصر فهرست

- یک تابع جدید برای انجام این کار بسازید.
- از [نحوه‌ی نگارش اندیس][index-syntax] استفاده کنید تا اولین عنصر را به دست آورید.

## 6. تعریف تابعی برای برگرداندن تعداد زبان‌های موجود در فهرست

- یک تابع جدید برای انجام این کار بسازید.
- برای انجام این کار از یک [تابع موجود][ref-array-functions] دوباره استفاده کنید.
