# مقدمه

`when` کلیدواژه‌ی فیلتر کردن استثناهاست. این کلیدواژه بعد از دستور `catch` قرار می‌گیرد و می‌تواند یک عبارت «منطقی» بگیرد که هر مقداری را که در آن لحظه در محدوده باشد، در بر می‌گیرد. اگر نتیجه‌ی این عبارت «درست» باشد، بلوک مربوط به همان دستور `catch` اجرا می‌شود؛ در غیر این صورت دستور `catch` بعدی، اگر وجود داشته باشد، بررسی می‌شود.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
