# دستورالعمل

[عدد آرمسترانگ][armstrong-number] عددی است که برابر مجموع رقم‌های خود است، به این صورت که هر رقم به توان تعداد رقم‌ها می‌رسد.

برای مثال:

- ۹ عدد آرمسترانگ است، چون `9 = 9^1 = 9`
- ۱۰ عدد آرمسترانگ _نیست_، چون `10 != 1^2 + 0^2 = 1`
- ۱۵۳ عدد آرمسترانگ است، چون: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- ۱۵۴ عدد آرمسترانگ _نیست_، چون: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

کدی بنویسید که تشخیص دهد آیا یک عدد، عدد آرمسترانگ است یا نه.

[armstrong-number]: https://en.wikipedia.org/wiki/Narcissistic_number
