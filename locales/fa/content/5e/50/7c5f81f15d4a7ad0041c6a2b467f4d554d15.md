# درباره

[`fold`][fold] یک [مبدل تکرارکننده‌ی مصرفی][consuming iterator adaptor] است که یک تابع را به هر عنصر تکرار اعمال می‌کند و نتیجه را در یک مقدار جدید انباشته می‌کند.

هر تکرار `fold` دو آرگومان می‌گیرد. اولی مقدار اولیه‌ای برای «انباشته‌گر» است. دومی یک «بستار» است که خودش دو آرگومان می‌گیرد: انباشته‌گر و یک عنصر. مقدار بازگشتی بستار، مقدار بعدی انباشته‌گر است. وقتی تکرارکننده به پایان می‌رسد، مقدار نهایی انباشته‌گر بازگردانده می‌شود.

از `fold` می‌توان استفاده کرد وقتی می‌خواهیم یک مجموعه را به یک مقدار واحد تبدیل کنیم. برای مثال، اگر مجموع همه‌ی اعداد زوج را بخواهیم

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

`30` چاپ می‌شود.

کاری که می‌توان در `fold` انجام داد، اغلب می‌توان با یک تابع یا چند تابع دیگر هم انجام داد. برای مثال بالا، [`filter`][filter] روی `(1..=10)` و سپس [`sum`][sum] کم‌حجم‌تر خواهد بود و همان نتیجه را می‌دهد، به این شکل

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

توابع دیگری که بیش از `fold` رایج‌اند شامل [`product`][product] و [`collect`][collect] هستند.

می‌توان از انباشته‌گر برای مقادیری غیر از اعداد هم استفاده کرد. برای مثال

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

`FeeFiFoFum` چاپ می‌شود.
