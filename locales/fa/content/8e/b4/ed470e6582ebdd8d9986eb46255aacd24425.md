# دستورالعمل‌ها

تعداد مستطیل‌ها را در یک نمودار ASCII مانند نمونه‌ی زیر بشمارید.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

نمودار بالا شامل این ۶ مستطیل است:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

می‌توانید فرض کنید که ورودی همیشه یک مستطیل درست است (یعنی طول هر خط با طول خط اول برابر است).
