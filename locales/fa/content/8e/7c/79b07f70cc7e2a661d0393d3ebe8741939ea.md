# مقدمه

Haxe زبانی است با نوع‌بندی قوی، اما در صورت نیاز می‌توان قواعد آن را نقض کرد. به انتساب یک مقدار به یک اسم، تعریف متغیر می‌گوییم. متغیر را می‌توان یا با مشخص کردن صریح نوعش تعریف کرد یا با واگذاری استنتاج نوع به کامپایلر Haxe. بنابراین، دو تعریف متغیر زیر معادل یکدیگرند:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

برای به‌روزرسانی متغیر می‌توان از عملگر `=` استفاده کرد:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

کامپایلر هنگام تلاش برای انتساب مقداری که نوعش با نوع متغیر متفاوت است، خطا می‌دهد:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

تابعی که داخل یک کلاس قرار دارد، «متد» نامیده می‌شود. متدها می‌توانند صفر یا چند پارامتر داشته باشند. نوع همه‌ی پارامترها باید صریحاً مشخص شود. نوع بازگشتی متد نیز مانند پارامترها قابل استنتاج نیست و باید مشخص شود. مقدارها با کلیدواژه‌ی `return` از متد بازگردانده می‌شوند:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

فراخوانی متد با مشخص کردن کلاس و نام متد و ارسال آرگومان‌ها انجام می‌شود:

```haxe
var sum = add(1, 2) // sum = 3
```

«محدوده» در Haxe بین کاراکترهای `{` و `}` تعریف می‌شود.

Haxe از دو نوع کامنت پشتیبانی می‌کند. کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.
