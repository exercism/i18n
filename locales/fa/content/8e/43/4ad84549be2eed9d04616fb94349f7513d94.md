# Testها

برای اجرای Testها، دستور `bal test --offline` را از داخل پوشه‌ی تمرین اجرا کنید.

## Testهای نادیده‌گرفته‌شده

در ابتدا فقط اولین Test فعال خواهد بود.
هدف این است که شما را تشویق کند تمرین را قدم‌به‌قدم حل کنید.
پس از اینکه اولین Test را پاس کردید، ویژگی `enable: false` را از Test بعدی حذف کنید و آن Test را هم پاس کنید.
