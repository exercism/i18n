# بارگذاری عملگر

«بارگذاری عملگر» ویژگی‌ای در برخی زبان‌های برنامه‌نویسی است که امکان بازتعریف عملگرهای استاندارد، مانند جمع (`+`)، تفریق (`-`)، ضرب (`*`) و تقسیم (`/`)، را فراهم می‌کند تا با انواع تعریف‌شده توسط کاربر کار کنند.

این کار می‌تواند نحوه‌ی نگارش کد را شهودی‌تر کند، چون به کمک آن می‌توان عملیات روی انواع تعریف‌شده توسط کاربر را همانند عملیات روی انواع پایه بیان کرد.

در Cairo، بارگذاری عملگر از طریق پیاده‌سازی traitهای مشخص انجام می‌شود.

هر عملگر یک trait متناظر دارد و بارگذاری آن عملگر به معنای ارائه‌ی یک پیاده‌سازی از آن trait برای یک نوع سفارشی است.
اما ضروری است که بارگذاری عملگر را با احتیاط به کار ببرید.

استفاده‌ی نادرست می‌تواند باعث سردرگمی شود و نگهداری کد را دشوارتر کند؛ برای نمونه، جایی که عملگر بارگذاری‌شده معنای معنایی روشنی ندارد.

مثالی را در نظر بگیرید که در آن دو `Potions` باید با هم ترکیب شوند.

`Potions` دو فیلد داده دارد: مانا و سلامتی.

ترکیب دو `Potions` باید فیلدهای متناظرشان را جمع کند.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

در کد بالا، در حال پیاده‌سازی trait `Add` برای نوع `Potion` هستیم.

تابع `add` دو آرگومان می‌گیرد: `lhs` و `rhs` (سمت چپ و سمت راست).

بدنه‌ی تابع یک نمونه‌ی جدید از `Potion` برمی‌گرداند که مقادیر فیلدهایش ترکیبی از `lhs` و `rhs` است.

همان‌طور که در مثال دیدید، برای بارگذاری یک عملگر باید نوع مشخصی را که این بارگذاری روی آن انجام می‌شود تعیین کنید.

trait عمومی‌ای که بارگذاری می‌شود `Add<T>` است و ما پیاده‌سازی مشخصی از آن را برای نوع `Potion` به شکل `Add<Potion>` تعریف می‌کنیم.
