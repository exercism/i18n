# Tests

## Clojure CLI

تمرین‌های Clojure در Exercism با یک فایل `deps.edn` همراه هستند که یک نام مستعار `:test` دارد و از آن برای فراخوانی [test-runner cognitect-labs](https://github.com/cognitect-labs/test-runner) استفاده می‌شود:

``` bash
$ clj -X:test
```

## Leiningen

از Leiningen هم می‌توانید برای اجرای تست تمرین استفاده کنید. برای این کار، دستور زیر را از پوشه‌ی تمرین اجرا کنید:

```bash
lein test
```

## REPL

برای اجرای تست تمرین با REPL، دستور زیر را از پوشه‌ی تمرین اجرا کنید:

```bash
$ clj
```

یا

```bash
$ lein repl
```

سپس فضای نام تست تمرین و فضای نام تست Clojure را با `require` بارگذاری کنید):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

سپس `run-tests` را روی `<exercise>-test` فراخوانی کنید:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
