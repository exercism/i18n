# مقدمه

Swift مجموعه‌ای از دستورها دارد که می‌توان از آن‌ها برای تغییر جریان عادی کنترل حلقه‌ها استفاده کرد.
به این‌ها دستورهای انتقال کنترل می‌گویند.
شما پیش‌تر `return` را دیده‌اید؛ این مفهوم موارد دیگری را معرفی می‌کند که شامل `continue`، `break` و برچسب است.

## Continue

گاهی لازم است بدون کامل کردن بقیه‌ی دستورهای تکرار فعلی حلقه، زودتر به تکرار بعدی آن بپرید.
برای این کار می‌توان از کلیدواژه‌ی `continue` استفاده کرد.
وقتی `continue` اجرا می‌شود، حلقه به بررسی بعدی می‌رود تا ببیند آیا می‌توان تکرار بعدی حلقه را اجرا کرد یا نه؛ یعنی `while` در حلقه‌های while و repeat-while، یا بررسی این‌که عنصر دیگری در دنباله هست یا نه در حلقه‌های for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

از `break` برای خروج زودهنگام از یک حلقه استفاده می‌شود.
وقتی `break` اجرا شود، حلقه بی‌درنگ پایان می‌یابد و برنامه با اولین دستور بعد از حلقه ادامه پیدا می‌کند.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## برچسب

وقتی حلقه‌ها تودرتو می‌شوند، گاهی ممکن است بخواهید با `break` یا `continue` از حلقه‌های بیرونی خارج شوید یا آن‌ها را از نو شروع کنید. حلقه‌های بیرونی همان حلقه‌هایی هستند که حلقه‌ی محل استفاده از `break` یا `continue` را در خود دارند.
در چنین مواردی می‌توان از برچسب استفاده کرد تا مشخص شود از کدام حلقه باید خارج شد یا کدام حلقه را از نو شروع کرد.
برای برچسب زدن به یک حلقه، یک اسم و سپس یک دونقطه را پیش از `while`، `repeat` یا `for`ی که حلقه را شروع می‌کند قرار دهید.

برای دیدن اثر استفاده از برچسب به این شکل، حلقه‌ی زیر را در نظر بگیرید.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

از کلیدواژه‌ی `fallthrough` برای رفتن به `case` بعدی در یک دستور `switch` استفاده می‌شود.
یعنی کد درون `case` بعدی بدون بررسی شرط‌های آن اجرا می‌شود.
این باعث می‌شود دستور `switch` مثل زبان‌های برنامه‌نویسی دیگری رفتار کند که در آن‌ها پس از تطبیق یک `case`، برای خروج از دستور `switch` نیازی به دستور `break` نیست.
می‌توانید درباره‌ی `fallthrough` در [کتاب Swift][fallthrough] بیشتر بخوانید.

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[control-transfer]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Control-Transfer-Statements
[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
