# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که به یک فریلنسر کمک می‌کند درباره‌ی قیمت پروژه‌های مشخصی با مشتریانش گفت‌وگو کند.
چند متد کمکی می‌نویسید تا هزینه‌ها را سریع برای مشتریان محاسبه کنید.

```exercism/note
The `rate_per_hour` parameter and the `day_rate` method are related to money.
The units of measurement are money for a unit of time: hours and days respectively.
```

## 1. محاسبه‌ی نرخ روزانه با داشتن نرخ ساعتی

مشتری‌ای با فریلنسر تماس می‌گیرد تا درباره‌ی نرخ‌هایش پرس‌وجو کند.
فریلنسر توضیح می‌دهد که **_روزی ۸ ساعت کار می‌کند._**
اما فریلنسر فقط نرخ ساعتی خود را برای پروژه می‌داند.
کمک کنید نرخ روزانه را با داشتن نرخ ساعتی تخمین بزند.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

نرخ روزانه نیازی به گرد شدن یا تغییر یافتن به دقت «ثابت» ندارد.

## 2. محاسبه‌ی تعداد روزهای کاری با داشتن بودجه‌ی ثابت

روزی دیگر، مدیر پروژه‌ای به فریلنسر پیشنهاد می‌دهد روی پروژه‌ای با بودجه‌ی ثابت کار کند.
با داشتن بودجه‌ی ثابت و نرخ ساعتی فریلنسر، کمک کنید محاسبه کند تا تمام شدن بودجه چند روز کار خواهد کرد.
نتیجه _باید_ **به سمت پایین** به نزدیک‌ترین عدد صحیح گرد شود.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. محاسبه‌ی نرخ تخفیف‌خورده برای پروژه‌های بزرگ

اغلب مشتریان فریلنسر او را برای پروژه‌هایی استخدام می‌کنند که چند ماه طول می‌کشند.
در این موارد، فریلنسر تصمیم می‌گیرد برای هر ماه کامل تخفیف بدهد و روزهای باقی‌مانده با نرخ روزانه حساب می‌شوند.
تعادل عالی شما میان کار و زندگی یعنی در هر ماه تقویمی فقط ۲۲ روز کار می‌کنید، پس **_هر ماه ۲۲ روز قابل صورت‌حساب دارد._**
کمک کنید هزینه‌ی او را برای چنین پروژه‌هایی تخمین بزند، با داشتن نرخ ساعتی، تعداد روزهای قابل صورت‌حساب پروژه و نرخ تخفیف ماهانه.
تخفیف همیشه به‌صورت یک عدد داده می‌شود، جایی که `42%` به `0.42` تبدیل می‌شود. نتیجه _باید_ **به سمت بالا** به نزدیک‌ترین عدد صحیح گرد شود.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
