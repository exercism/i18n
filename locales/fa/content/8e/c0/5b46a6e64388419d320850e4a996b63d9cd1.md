# پیوست دستورالعمل

## پیاده‌سازی

ممکن است اسم‌های ربات تمام شود؛ وقتی همه‌ی اسم‌های ممکن ربات تخصیص داده شد، باید یک خطا برگردانده شود.

## Test امتیاز

وقتی `go test` را با موفقیت اجرا کردید، می‌بینید که در مجموعه‌ی Test، یک Test با اسم `TestCollisions` وجود دارد که به‌طور پیش‌فرض نادیده گرفته می‌شود، چون ممکن است زمان زیادی طول بکشد.
این Test ربات‌های جدید می‌سازد تا زمانی که دیگر نتوان اسم تازه‌ای به ربات تخصیص داد.

برای اینکه Test اجرا شود، این خط را حذف کنید:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

برای اینکه این Test موفق شود، باید مطمئن شوید که اسم ربات پیش‌تر استفاده نشده است و اینکه می‌توان اسم‌ها را به‌شکل کارآمدی تخصیص داد.
