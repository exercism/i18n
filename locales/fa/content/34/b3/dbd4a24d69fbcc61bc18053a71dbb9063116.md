# پیوست دستورالعمل‌ها

## نکات پیاده‌سازی

شیء درخت دو ویژگی دارد:

- برچسب از نوع `String`
- فرزندان از نوع `List<Tree>`

برنامه‌ی آزمون درخت‌ها را با فراخوانی مکرر تابع سازنده‌ی `Tree.of` می‌سازد. برای مثال، دستور

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

درخت زیر را می‌سازد:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

می‌توانید فرض کنید که در درخت‌های آزمون مقدار تکراری وجود ندارد.

---

متدهای `FromPov` و `PathTo` بخش جالب این تمرین هستند.

متد `FromPov` یک آرگومان رشته‌ای به اسم `from` می‌گیرد که گرهی در درخت را بر اساس مقدارش مشخص می‌کند. باید درختی برگرداند که مقدار `from` در ریشه‌ی آن قرار دارد. می‌توانید درخت اصلی را تغییر دهید و همان را برگردانید، یا درخت تازه‌ای بسازید و آن را برگردانید. اگر درخت تازه‌ای برگردانید، آزادید درخت اصلی را مصرف یا نابود کنید. البته بهتر است آن را بدون تغییر بگذارید.

متد `PathTo` دو آرگومان رشته‌ای `from` و `to` می‌گیرد که دو گره در درخت را بر اساس مقدارشان مشخص می‌کنند. باید کوتاه‌ترین مسیر درخت از گره‌ی اول تا گره‌ی دوم را برگرداند.

## پیام‌های استثنا

گاهی لازم است که [استثنا پرتاب کنید](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html). وقتی این کار را می‌کنید، باید همیشه **پیام خطای گویایی** بگنجانید که نشان دهد منبع خطا چیست. این کار کد شما را خواناتر می‌کند و به‌طور چشمگیری به Debug کمک می‌کند.

این تمرین خاص می‌خواهد که از [کلیدواژه‌ی throw](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html) استفاده کنید و اگر کلاس `Tree()` درختی بگیرد که نمی‌توان دوباره جهت‌دهی‌اش کرد، یا مسیری بین یک `start node` و یک `end node` پیدا نشود، چندین `UnsupportedOperationException` را «پرتاب» کنید. آزمون‌ها تنها در صورتی قبول می‌شوند که هم `exception` را `throw` کنید و هم پیامی همراه آن بگنجانید.

برای پرتاب یک `UnsupportedOperationException` همراه با پیام، پیام را به‌عنوان آرگومان به نوع `exception` بدهید:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
