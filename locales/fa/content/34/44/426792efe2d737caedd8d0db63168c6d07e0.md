# مقدمه

## Nil

`Nil` در Gleam نوعی است با یک مقدار واحد، که به آن `Nil` هم می‌گویند. این نوع شبیه `void` در زبان‌های دیگر است، از این جهت که وقتی یک تابع مقدار مناسب دیگری برای برگرداندن ندارد از آن استفاده می‌شود.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

مقادیر در Gleam مانند برخی زبان‌های دیگر نمی‌توانند تهی باشند. یک مقدار تنها زمانی می‌تواند `Nil` باشد که نوعش `Nil` باشد، و یک مقدار از هر نوع دیگری هرگز نمی‌تواند `Nil` باشد.

## ورودی/خروجی

مانند بیشتر زبان‌های برنامه‌نویسی، Gleam هم «اثرات جانبی» دارد، بنابراین توابع می‌توانند وضعیت جهان را بخوانند و تغییر دهند، و همچنین مقداری را برگردانند.

ماژول `gleam/io` در کتابخانه‌ی استاندارد Gleam توابعی برای چاپ رشته‌ها در کنسول فراهم می‌کند.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

بسته‌های دیگر ممکن است توابع ورودی/خروجی دیگری ارائه دهند، مانند `simplifile`، بسته‌ای که توابعی برای خواندن و نوشتن فایل‌ها فراهم می‌کند.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
