# معرفی

«مقدار منطقی» در Java با نوع `boolean` نمایش داده می‌شود که مقدارش می‌تواند `true` یا `false` باشد.

Java از سه عملگر منطقی پشتیبانی می‌کند:

- `!` (NOT): مقدار منطقی را نقیض می‌کند
- `&&` (AND): دو مقدار منطقی می‌گیرد و اگر هر دو «درست» باشند، نتیجه «درست» است
- `||` (OR): اگر یکی از آن دو مقدار منطقی «درست» باشد، نتیجه «درست» است

## مثال‌ها

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
