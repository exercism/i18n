# دستورالعمل‌ها

شما به کار روی سیستم مدیریت موجودی‌ای که پیش‌تر ساخته‌اید ادامه می‌دهید.
از زمانی که `OpenStruct` و میانبرهای بلوک را کشف کرده‌اید، تصمیم گرفته‌اید کد را کمی بازنویسی کنید.
به‌جای ذخیره کردن عناصر به‌صورت هش، از مهارت‌های تازه‌ی خود استفاده می‌کنید.

## 1. امکان بازیابی عناصر

می‌خواهید همچنان فهرست عناصر موجود در انبار را بازیابی کنید، اما این بار آن‌ها باید اشیایی باشند که بتوان متدهایی را رویشان فراخوانی کرد.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. بازنویسی `item_names`

`item_names` را بازنویسی کنید تا به‌جای هش‌ها از میانبر بلوک تازه‌ای که یاد گرفته‌اید استفاده کند.
یادآوری: متد باید این را برگرداند:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. بازنویسی `total_stock`

`total_stock` را بازنویسی کنید تا از متد `OpenStruct` استفاده کند، نه از ارجاع به یک هش.
یادآوری: متد باید این را برگرداند:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
