# دستورالعمل‌ها

در این تمرین کدی می‌نویسید تا تولید یک خط مونتاژ در یک کارخانه‌ی خودروسازی را تحلیل کنید.
سرعت خط مونتاژ می‌تواند از `0` (خاموش) تا `10` (حداکثر) متغیر باشد.

در کمترین سرعت (`1`)، هر ساعت `221` خودرو تولید می‌شود.
تولید به‌صورت خطی با سرعت افزایش می‌یابد.
بنابراین اگر سرعت روی `4` تنظیم شود، باید هر ساعت `4 * 221 = 884` خودرو تولید کند.
اما سرعت‌های بالاتر احتمال تولید خودروهای معیوب را افزایش می‌دهند، خودروهایی که در آن صورت باید دور ریخته شوند. 

سه وظیفه دارید.

## 1. محاسبه‌ی نرخ موفقیت

متد `AssemblyLine.SuccessRate()` (که _static_ است) را پیاده‌سازی کنید تا نسبت تولید بدون خطای یک قطعه را برای یک سرعت مشخص محاسبه کنید.
جدول زیر نشان می‌دهد که سرعت چگونه بر نرخ موفقیت اثر می‌گذارد:

- `0`: نرخ موفقیت ۰٪.
- `1` تا `4`: نرخ موفقیت ۱۰۰٪.
- `5` تا `8`: نرخ موفقیت ۹۰٪.
- `9`: نرخ موفقیت ۸۰٪.
- `10`: نرخ موفقیت ۷۷٪.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. محاسبه‌ی نرخ تولید در ساعت

متد `AssemblyLine.ProductionRatePerHour()` (که _static_ است) را پیاده‌سازی کنید تا نرخ تولید خط مونتاژ در ساعت را با در نظر گرفتن نرخ موفقیت آن محاسبه کنید:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

توجه کنید که مقدار برگشتی یک `double` است.

## 3. محاسبه‌ی تعداد قطعات سالم تولیدشده در دقیقه

متد `AssemblyLine.WorkingItemsPerMinute()` (که _static_ است) را پیاده‌سازی کنید تا محاسبه کنید هر دقیقه چند خودروی سالم تولید می‌شود:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

توجه کنید که مقدار برگشتی یک `int` است.
