# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است [یک استثنا ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، باید همیشه یک **پیام خطای معنادار** هم بیاورید تا نشان دهید منشأ خطا چیست. این کار خوانایی code شما را بیشتر می‌کند و کمک چشمگیری به debugging می‌کند. در مواردی که می‌دانید منشأ خطا نوع مشخصی خواهد بود، می‌توانید یکی از [انواع خطای داخلی](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما باز هم باید پیام معناداری بیاورید.

این تمرین خاص می‌خواهد که با [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) وقتی رشته‌های در حال بررسی طول یکسانی ندارند، یک `ValueError` را «پرتاب» کنید. tests تنها زمانی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بیاورید.

برای اینکه یک `ValueError` را همراه با پیام ایجاد کنید، پیام را به‌عنوان آرگومان به نوع `exception` بنویسید:

```python
# When the sequences being passed are not the same length.
raise ValueError("Strands must be of equal length.")
```
