# نصب

## نصب محیط اجرای R
از [صفحه‌ی اصلی CRAN](https://cran.r-project.org/) بازدید کنید. آنجا پیوندهای دانلود برای Linux، Mac OSX و Windows را پیدا می‌کنید. نصب‌کننده‌ی مربوط به سیستم‌عامل خود را دانلود و اجرا کنید.

## نصب محیط توسعه‌ی یکپارچه‌ی RStudio (توصیه می‌شود)
RStudio یک محیط توسعه‌ی یکپارچه‌ی محبوب و چندسکویی برای برنامه‌نویسی به زبان R است (و از زبان‌های دیگری مانند Python، JavaScript و Markdown هم پشتیبانی می‌کند). استفاده از RStudio نوشتن راه‌حل‌های کد و اجرای تست‌ها را آسان‌تر می‌کند.

[نسخه‌ی پایدار فعلی RStudio](https://www.rstudio.com/products/rstudio/download/) را دانلود و نصب کنید. یا در عوض، [نسخه‌ی پیش‌نمایش](https://www.rstudio.com/products/rstudio/download/preview/) انتشار آینده را تهیه کنید.

## نصب افزونه‌ی R برای Visual Studio Code (به‌عنوان جایگزین)
افزونه‌ی R برای Visual Studio Code از برجسته‌سازی نحوه‌ی نگارش کد، تکمیل کد، لینت کردن، قالب‌بندی، تعامل با ترمینال‌های R، مشاهده‌ی داده‌ها، نمودارها، متغیرهای فضای کاری، صفحه‌های راهنما، مدیریت بسته‌ها و کار با اسناد R Markdown پشتیبانی می‌کند.

[نسخه‌ی فعلی افزونه‌ی R](https://code.visualstudio.com/docs/languages/r) را دانلود و نصب کنید.

## نصب بسته‌های R برای اجرای تست‌ها
اجرای تست‌های تمرین‌ها بر عهده‌ی کتابخانه‌ی [`testthat`](https://github.com/hadley/testthat) از Hadley Wickham است، که انتخاب محبوبی میان نویسندگان بسته‌های R به شمار می‌رود.

برای نصب این کتابخانه، دستور زیر را در کنسول RStudio (یا هر جای دیگری که از R استفاده می‌کنید) تایپ کنید.

```{R}
install.packages("testthat")
```

اگرچه بعید است که برای حل مسائل Exercism به نصب بسته‌ها _نیاز_ داشته باشید، ممکن است بخواهید بسته‌ی کاربردی همه‌کاره‌ای مانند [`tidyverse`](https://github.com/tidyverse/tidyverse) را که با سبک برنامه‌نویسی شما سازگار است به کار بگیرید. برای نصب و بارگذاری بسته‌ای مانند `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
