# مقدمه

## اعداد

Haskell نوعی به اسم `Num` دارد که نوع پایه برای همه‌ی انواع عددی است.
درون این نوع عددی چهار زیرنوع اصلی وجود دارد: [`Int`][int]، [`Integer`][integer]، [`Double`][double] و [`Float`][float].

Haskell دو نوع عدد صحیح دارد که اعداد کامل را نمایش می‌دهند.
`Int` یک عدد صحیح با اندازه‌ی ثابت است، در حالی که `Integer` یک عدد صحیح با دقت دلخواه است.
یک `Integer` هر عددی را نگه می‌دارد، هر چقدر هم بزرگ باشد، تا حد حافظه‌ی ماشین شما؛ اما `Int` متناظر با مجموعه‌ی اعداد صحیح مثبت و منفی است که می‌توانند در ۳۲ یا ۶۴ بیت بیان شوند (که حداقل از -۲^۲۹ تا ۲^۲۹ - ۱ تضمین شده است).

توجه کنید که هنگام نوشتن اعداد منفی، برای جلوگیری از ابهام باید از پرانتز استفاده کنید.

```haskell
1

(-1)
```

`Float` متناظر با مجموعه‌ی اعداد حقیقی است و با دقت کامپیوتر محدود می‌شود.
عملیات‌هایی که روی اعداد تعریف می‌شوند معمولاً روی یک نوع کار می‌کنند یا نوع دیگر، اما نه روی هر دو.
`Double` یک عدد اعشاری با دقت مضاعف است.

```haskell
10.5
```

### تبدیل بین اعداد صحیح و اعشاری

با استفاده از تابع `toFloat` می‌توانید یک `Int` یا `Integer` را به یک `Float` تبدیل کنید.

```haskell
toFloat 1
-- -> 1.0
```

تابع `fromIntegral` هم وجود دارد که هر نوع عددی را به نوع عددی استنتاج‌شده‌ی مورد نیاز تبدیل می‌کند.

```haskell
fromIntegral 1
-- -> 1.0
```

برای تبدیل یک `Float` به `Int` می‌توانید از توابع [`round`][round]، [`floor`][floor] یا [`ceiling`][ceiling] استفاده کنید.
تابع `round` به نزدیک‌ترین عدد صحیح گرد می‌کند، `floor` به پایین گرد می‌کند و `ceiling` به بالا.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### عملگرهای حسابی

می‌توانید از [عملگرهای حسابی پایه][math] روی انواع عددی استفاده کنید.
این عملگرها عبارت‌اند از `+`، `-`، `*`، `/` و `%`.
هنگام استفاده از این عملگرها، نوع اعداد باید یکسان باشد.
تابع `fromIntegral` تبدیل را طوری انجام می‌دهد که نوع‌ها یکسان شوند.

#### جمع، تفریق و ضرب

عملگر `+` برای جمع، عملگر `-` برای تفریق و عملگر `*` برای ضرب به کار می‌رود.

| عملگر | مثال        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### تقسیم

از تقسیم برای بخش کردن اعداد استفاده می‌شود.
عملگر `/` برای تقسیم به کار می‌رود.
نتیجه همیشه یک عدد اعشاری خواهد بود.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
در برخی زبان‌های برنامه‌نویسی، وقتی بر صفر تقسیم می‌کنید، نتیجه یک خطا خواهد بود.

در Haskell، وقتی بر صفر تقسیم می‌کنید، نتیجه `Infinity` یا `-Infinity` است.
تنها استثنا تقسیم صفر بر صفر است که نتیجه‌اش `NaN` (یعنی عدد نیست) می‌شود.

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### تقسیم صحیح

تقسیم صحیح برای تقسیم اعداد صحیح و به دست آوردن بخش کامل نتیجه به کار می‌رود.
Haskell دو تابع تقسیم صحیح دارد که وقتی نتیجه منفی است، در نحوه‌ی گرد کردن با هم تفاوت دارند:

- `div` به پایین، یعنی به سمت منفی بی‌نهایت، گرد می‌کند.
- `quot` به سمت صفر گرد می‌کند.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
اگر هنگام استفاده از تقسیم صحیح بر صفر تقسیم کنید، نتیجه یک استثنا خواهد بود.
این با تقسیم معمولی فرق دارد.
~~~~

#### باقی‌مانده

باقی‌مانده‌ی یک تقسیم صحیح را می‌توان با `mod` یا `rem` به دست آورد.
این دو وقتی یکی از اعداد منفی باشد، در علامت نتیجه با هم تفاوت دارند:

- `mod` همراه با `div` می‌آید و علامت نتیجه‌اش مثل علامت مقسوم‌علیه است.
- `rem` همراه با `quot` می‌آید و علامت نتیجه‌اش مثل علامت مقسوم است.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

برای هر `x` و `y` (که `y` صفر نباشد)، این قوانین برقرار است:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
وقتی هر دو عدد مثبت باشند، `div` و `quot` نتیجه‌ی یکسانی می‌دهند و `mod` و `rem` هم همین‌طور.
در این حالت `quot` و `rem` می‌توانند کمی کارآمدتر باشند، چون `div` و `mod` برای رسیدگی به اعداد منفی به مراحل اضافی نیاز دارند.
~~~~

~~~~exercism/caution
تقسیم بر صفر در استفاده از `mod` یا `rem` به یک استثنا منجر می‌شود.
این با تقسیم معمولی فرق دارد.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### توان‌رسانی

Haskell سه عملگر «به توان رساندن» دارد که هر کدام طور متفاوتی کار می‌کنند و نوع آرگومان متفاوتی می‌گیرند.

- `**` دو **عدد اعشاری** می‌گیرد و برای محاسبه‌ی توان از لگاریتم استفاده می‌کند.
- `^^` یک **عدد اعشاری** می‌گیرد و آن را به توان یک **عدد صحیح** مثبت یا منفی می‌رساند.
- `^` **هر نوع عددی** را می‌گیرد و آن را به توان یک **عدد صحیح** مثبت می‌رساند.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### اولویت و پرانتزها

Haskell اجازه می‌دهد از پرانتز (`()`) استفاده کنید که برای گروه‌بندی عبارت‌ها به کار می‌رود.
این وقتی مفید است که بخواهید ترتیب عملیات را تغییر دهید.

وقتی از چند عملگر حسابی استفاده می‌کنید، ترتیب عملیات همانند ریاضیات است که به آن [PEMDAS][pemdas] هم می‌گویند.
این ترتیب عبارت است از پرانتز (`()`)، توان (`**`)، ضرب (`*`) و تقسیم (`/`)، و جمع (`+`) و تفریق (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
