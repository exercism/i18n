# پیوست دستورالعمل‌ها

## پیاده‌سازی

پیش از شروع، مطمئن شوید که می‌دانید چطور باید codeای بنویسید که در موردهای test موفق شود.
برای اطلاعات بیشتر، این [آموزش][tutorial] را ببینید.

بیشتر تمرین‌های Java چندین مورد test دارند.
این موردها طوری ساختار یافته‌اند که از یک فرایند مفید به اسم [توسعه‌ی آزمون‌محور (TDD)][tdd] پشتیبانی کنند.
این چرخه را می‌توان این‌طور توصیف کرد:

1. یک test اضافه کنید که بخشی از قابلیت موردنظر را توصیف می‌کند و code شما در حال حاضر ندارد.
2. testها را اجرا کنید تا بررسی کنید که این test تازه‌اضافه‌شده شکست می‌خورد.
3. code موجودتان را به‌روزرسانی کنید تا:
    - همه‌ی testهای قبلی همچنان موفق شوند؛
    - test جدید هم موفق شود.
4. code خود را [تمیز کنید][refactoring] و مطمئن شوید که همه‌ی testها همچنان موفق می‌شوند.
   این کار معمولاً شامل تغییر اسم متغیرها، حذف تکه‌های تکراری منطق، حذف لاگ‌های جامانده و از این قبیل است.
5. به گام ۱ برگردید تا همه‌ی قابلیت‌های موردنظر ساخته شوند!

فایل‌های test در این مسیر شامل _همه‌ی_ testهایی است که راه‌حل شما برای معتبر شمرده شدن باید در آن‌ها موفق شود.
در ظاهر، این با چرخه‌ای که بالا توصیف شد سازگار نیست؛ چرخه‌ای که در آن testها یکی‌یکی نوشته می‌شوند.
با این حال، ابزاری که برای نوشتن testهایمان به کار می‌بریم، یعنی [JUnit][junit]، [حاشیه‌نویسی][java-annotation] [@Disabled][junit-disabled] را در اختیار می‌گذارد که می‌توان با آن یک test نوشته‌شده را موقتاً نادیده گرفت.
با استفاده از این حاشیه‌نویسی، مطمئن می‌شویم که فایل‌های testی که به شما تحویل می‌دهیم این قواعد را رعایت می‌کنند:

- اولین test در هر فایل test به‌طور پیش‌فرض نادیده گرفته _نمی‌شود_.
- همه‌ی testهای هر فایل test به‌جز اولین test به‌طور پیش‌فرض نادیده گرفته _می‌شوند_.

این به شما امکان می‌دهد با پیگیری این گام‌های کمی تغییریافته، چرخه‌ی TDD را شبیه‌سازی کنید:

1. testها را اجرا کنید تا بررسی کنید که در حال حاضر _حداکثر یک_ test شکست می‌خورد.
2. code موجودتان را به‌روزرسانی کنید تا همه‌ی testهای نادیده‌گرفته‌نشده موفق شوند.
3. code خود را تمیز کنید و مطمئن شوید که همه‌ی testهای نادیده‌گرفته‌نشده همچنان موفق می‌شوند.
4. بالاترین حاشیه‌نویسی `@Disabled` را در فایل test حذف کنید.
5. به گام ۱ برگردید تا دیگر هیچ testی نادیده گرفته نشود و همه‌ی testها موفق شوند!
