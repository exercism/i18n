# مقدمه

`call` (در [`kernel`][kernel]) یک «نقل‌قول» را اجرا می‌کند. وقتی نمی‌توان اثر پشته‌ی نقل‌قول را استنباط کرد (معمولاً به این دلیل که نقل‌قول از جای دیگری آمده است)، اثر را به‌صراحت روی `call` اعلام کنید:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

چون نقل‌قول‌ها مقدار هستند، یک آرایه می‌تواند ترکیبی از عددها و نقل‌قول‌ها را در خود جای دهد؛ به این ترتیب، «یک برنامه» فقط یک دنباله‌ی دیگر می‌شود:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
