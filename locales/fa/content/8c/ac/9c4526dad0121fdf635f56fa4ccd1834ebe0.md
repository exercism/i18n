# سرصفحه‌ی ساختگی

## `grep` کنیم یا `grep` نکنیم، مسئله این است

هرچند می‌توان این تمرین را به‌سادگی و فقط با دادن آرگومان‌ها به `grep` حل کرد، این تمرین را تنها با bash پیاده‌سازی کنید. هدف این track در Exercism یادگیری نحوه‌ی استفاده از دستورهای داخلی bash برای حل مسئله است.

برای حل این تمرین، باید این کارها را انجام دهید:

* تجزیه‌ی آرگومان‌های خط فرمان: برای این کار [`getopts`](https://stackoverflow.com/tags/getopts/info) مفید است.
* پیمایش خطوط یک فایل: این همان [پرسش‌های متداول bash شماره‌ی ۱](https://mywiki.wooledge.org/BashFAQ/001) است
* استفاده از تطبیق عبارت باقاعده: bash می‌تواند این کار را با عملگر `=~` درون [`[[ ... ]]`](https://www.gnu.org/software/bash/manual/bash.html#index-_005b_005b) انجام دهد.
