### صادر کردن توابع

صادر کردن توابع در مفهوم اول بررسی شد؛ اینجا یک مرور سریع داریم.

هر فایل در Elm یک ماژول است و باید پیش از همه‌ی کدهای دیگر یک دستور `module` داشته باشد.

نام ماژول‌ها باید با نام فایلشان مطابقت داشته باشد؛ بنابراین ماژول `Calculator` باید در فایل `Calculator.elm` باشد و ماژول `Parser.Utils` باید در فایل `Parser/Utils.elm` قرار گیرد.

هرچه درون یک ماژول تعریف شود، به‌صورت خصوصی در محدوده‌ی همان ماژول قرار دارد و از بیرون آن قابل دسترسی نیست، مگر اینکه در `exposing` فهرست شده باشد.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### وارد کردن توابع از ماژول‌های دیگر

دسترسی به توابعی که در ماژول‌های دیگر تعریف شده‌اند، از طریق وارد کردن آن ماژول‌ها انجام می‌شود.
هنگام وارد کردن یک ماژول، همه‌ی توابعی که آن ماژول آشکار کرده است در دسترس قرار می‌گیرند.
اما شیوه‌ی دسترسی به آن‌ها بسته به نحوه‌ی وارد کردن ماژول متفاوت است.

وارد کردن مقید حالت پیش‌فرض است و دسترسی به یک تابع در چنین ماژولی (مثلاً تابع `map` در ماژول `List`) با آوردن نام ماژول به‌عنوان پیشوند (`List.map`) انجام می‌شود.

وارد کردن باز امکان دسترسی مستقیم به توابع آشکارشده در آن ماژول را بدون پیشوند فراهم می‌کند. این کار با کلیدواژه‌ی `exposing` انجام می‌شود، که آینه‌ی همان کلیدواژه‌ای است که در صادر کردن به کار می‌رود. می‌توانید همه‌ی توابع در دسترس را (با `..`) یا فقط توابع مشخصی را (مثلاً `map`) آشکار کنید.

همچنین می‌توانید نوع‌ها و سازنده‌هایشان را از ماژول‌های دیگر وارد کنید، که مفهومی است که بعداً بررسی می‌شود.

وارد کردن مقید ترجیح داده می‌شود تا به وضوح کمک کند و از تداخل نام‌ها جلوگیری شود.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### حاشیه‌نویسی نوع

حاشیه‌نویسی‌های نوع با `name : parameter types -> return type` تعریف می‌شوند، که در آن‌ها نوع‌های پارامتر هم با `->` از هم جدا می‌شوند.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

می‌توان از پرانتز برای تعریف پارامترهای تابع استفاده کرد (پارامترها خودشان با همان نحوه‌ی نگارش تعریف می‌شوند، و همین باعث نیاز به پرانتز است).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### عدد

در Elm دو نوع عدد وجود دارد که با نوع‌های `Int` و `Float` تعریف می‌شوند.
`Int` متناظر با مجموعه‌ی عددهای صحیح مثبت و منفی است.
`Float` متناظر با مجموعه‌ی عددهای حقیقی است که با دقت کامپیوتر محدود می‌شود.
عملیات تعریف‌شده روی عددها معمولاً روی یکی از این دو نوع کار می‌کنند، نه با ترکیب آن دو.
توابعی برای تبدیل این دو به هم وجود دارد؛ مانند `toFloat` که `Int` را به `Float` تبدیل می‌کند، و `round`، `floor`، `ceiling` یا `truncate` که یک `Float` را با معناشناسی‌های متفاوت به `Int` تبدیل می‌کنند.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### عملیات رشته

برای توصیف واژه‌ها و جمله‌ها در کد، Elm یک نوع بومی `String` دارد.
لیترال‌های رشته‌ای بین دو کوتیشن دوتایی نوشته می‌شوند، مانند `"Hello World!"`.
عملگر الحاق رشته `++` و عملگر برابری `==` به‌صورت پیش‌فرض در دسترس هستند.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

بیشتر توابع دیگر رشته در ماژول `String` قرار دارند که باید وارد شود.

https://package.elm-lang.org/packages/elm/core/latest/String
