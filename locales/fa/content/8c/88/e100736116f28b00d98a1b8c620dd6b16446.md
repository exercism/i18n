# دستورالعمل‌ها

اگر بخواهید با Raspberry Pi چیزی بسازید، احتمالاً از _مقاومت‌ها_ استفاده می‌کنید.
برای این تمرین، باید دو نکته را درباره‌ی آن‌ها بدانید:

- هر مقاومت یک مقدار مقاومت دارد.
- مقاومت‌ها کوچک‌اند، آن‌قدر کوچک که اگر مقدار مقاومت را روی‌شان چاپ کنید، خواندنش سخت می‌شود.

برای حل این مشکل، تولیدکنندگان نوارهایی با کد رنگی را روی مقاومت‌ها چاپ می‌کنند تا مقدار مقاومت‌شان را نشان دهند.
هر نوار یک موقعیت و یک مقدار عددی دارد.

دو نوار اول یک مقاومت طرح رمزگذاری ساده‌ای دارند: هر رنگ به یک عدد نگاشت می‌شود.

نوار سوم یک ضریب است.

در این تمرین برنامه‌ای مفید می‌سازید تا مجبور نباشید مقدار نوارها را به خاطر بسپارید.

اطلاعات بیشتر درباره‌ی رمزگذاری رنگی مقاومت‌ها را می‌توانید در [مقاله‌ی ویکی‌پدیای کد رنگ الکترونیکی][e-color-code] پیدا کنید.

## 1. تعریف یک بردار نامدار

رنگ‌ها به این صورت رمزگذاری می‌شوند:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

بردار نامدار `resistor_bands` را بسازید که باید رنگ‌ها را به عنوان اسم و اعداد را به عنوان مقدار داشته باشد.

## 2. برگرداندن مقدار مرتبط با یک نوار

ابتدا می‌خواهید بتوانید مقدار منفرد هر نوار رنگی را پیدا کنید.

تابعی به نام `band_value(band)` تعریف کنید که یک `string` از رنگ یک نوار می‌گیرد.
این تابع مقدار مرتبط با آن رنگ را برمی‌گرداند.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. برگرداندن مقدار مرتبط با دو نوار

دو نوار اول یک مقاومت با هم ترکیب می‌شوند و یک عدد واحد می‌سازند.
اگر دو نوار اول به ترتیب اعداد `m` و `n` باشند، با هم ترکیب می‌شوند و عدد واحد `mn` را می‌سازند.

تابعی به نام `two_band_value(bands)` تعریف کنید که یک `vector` از `string`ها با دو رنگ نوار می‌گیرد.
این تابع مقدار مرتبط با ترکیب آن دو رنگ را برمی‌گرداند.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. برگرداندن مقدار اهم مرتبط با هر سه نوار

در پایان، باید مقدار کامل اهم را با استفاده از دو نوار اول در کنار نوار سوم پیدا کنید.
برای این کار باید مقدار دو نوار و یک ضریب را پیدا کنید.
ضریب را می‌توان به این صورت در نظر گرفت که چند صفر به مقدار دو نوار اضافه می‌شود.

تابعی به نام `ohms(bands)` تعریف کنید که یک `vector` از `string`ها با سه رنگ نوار می‌گیرد.
این تابع مقدار اهم مرتبط با ترکیب آن سه رنگ را برمی‌گرداند.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
