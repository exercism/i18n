# ضمیمه‌ی دستورالعمل

## منسوخ شدن `String.lowercase`

بسته به نسخه‌ی OCaml که نصب کرده‌اید، استفاده از `String.lowercase` چندان پسندیده نیست.
از نسخه‌ی ۴.۰۳.۰ به بعد، `String.lowercase` به نفع `String.lowercase_ascii` منسوخ شده است.
بنابراین به‌جای نوشتن

```ocaml
String.lowercase "Hello, World!"
```

از این استفاده کنید:

```ocaml
String.lowercase_ascii "Hello, World!"
```

برای توابع مفیدتر، به [مستندات `String`][string] مراجعه کنید.

[string]: http://caml.inria.fr/pub/docs/manual-ocaml/libref/String.html
