# مقدمه

ویژگی `Flags` اجازه می‌دهد مقادیر تعریف‌شده در یک «اتحاد تفکیک‌شده» به‌صورت جایگاه‌های بیت (یعنی «پرچم») نمایش داده شوند.
چنین مقادیری به‌عنوان پرچم قابل ترکیب هستند و این امکان را فراهم می‌کنند که چندین شرط «منطقی» در یک مقدار واحد نمایش داده شوند.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

یک پرچم را می‌توان با عملگر OR بیتی (`|||`) تنظیم کرد؛ برای پاک کردن یک پرچم هم می‌توان از ترکیبی از عملگر AND بیتی (`&&&`) و عملگر نقیض بیتی (`~~~`) استفاده کرد.
بررسی وضعیت یک پرچم را نیز می‌توان با عملگر AND بیتی انجام داد، اما از متد `HasFlag()` هم می‌توان استفاده کرد.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

برای مشاهده‌ی فهرست کامل عملگرهای بیتی موجود در زبان F#، به [خلاصه‌ی عملگرهای بیتی][bitwise-operators] نگاه کنید.
