# جای‌نگهدار

## نکته‌هایی برای `jq`

هدف این تمرین این است که یک شیء ورودی بگیرید و آن را به شیء جدیدی تبدیل کنید.
چند تابع توکار هم هست که ممکن است کمکتان کند:

- [`to_entries`][x_entries]
  - این تابع یک شیء را به عنوان ورودی می‌گیرد
  - خروجی آن یک _آرایه_ است؛ هر عنصر آرایه یک شیء است: `{"key": "K", "value": V}`
    - هر `K` یک کلید از شیء ورودی است
    - هر `V` مقدار متناظر با `K` است.
- [`from_entries`][x_entries]
  - عملیات معکوس
  - یک آرایه از شیءهای `{"key": K, "value": V}` می‌گیرد و یک شیء می‌سازد

یک مثال:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

خروجی:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
