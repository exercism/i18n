# Tests

## اجرای Tests

1. یک تمرین دریافت کنید:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. به پوشه‌ی تمرین بروید:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Tests را اجرا کنید:

    ```bash
    $ ./gradlew test
    ```

در بیشتر تمرین‌ها، به‌طور پیش‌فرض فقط اولین Test اجرا می‌شود.  
سایر Tests با `@Ignore` علامت‌گذاری شده‌اند تا نادیده گرفته شوند.  
همان‌طور که هر Test را حل می‌کنید، برای پیشرفت، `@Ignore` را از Test بعدی بردارید.

این روشی رایج در توسعه‌ی مبتنی بر Test (یا به اختصار TDD) است.
از این روش استفاده می‌شود تا مطمئن شوید که هر بار روی یک مسئله کار می‌کنید.
