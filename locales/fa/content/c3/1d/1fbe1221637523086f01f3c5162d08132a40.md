# مقدمه

کلاس Lambda مجموعه‌ای از متدهای تابعی است تا بتوان با Haxe به سبک تابعی برنامه‌نویسی کرد. این کلاس به ما امکان می‌دهد یک‌باره روی یک Iterable کامل کار کنیم. این کار اغلب به نوشتن حلقه ترجیح داده می‌شود، چون احتمال خطا را کم می‌کند و خواندنش آسان‌تر است. برای راحتی کار، کلاس Array و List برخی از متدهای پرکاربرد کلاس Lambda را در خود دارند.

برخی از توابع کلاس `Lambda` عبارت‌اند از:

- `Lambda.array` و `Lambda.list`: تبدیل Iterable به Array یا List. همیشه یک نمونه‌ی جدید برمی‌گرداند.
- `Lambda.count`: شمارش تعداد عنصرها. اگر Iterable یک Array یا List باشد، استفاده از خاصیت length آن سریع‌تر است.
- `Lambda.has`: تعیین این‌که آیا عنصر مشخص‌شده در Iterable هست یا نه.
- `Lambda.indexOf`: یافتن اندیس عنصر مشخص‌شده.
- `Lambda.find`: یافتن اولین عنصر بر اساس تابع جست‌وجوی داده‌شده.
- `Lambda.concat`: ادغام دو Iterable و برگرداندن یک List جدید.
- `Lambda.filter`: یافتن عنصرهایی که یک معیار را برآورده می‌کنند و برگرداندن یک List جدید.

مثالی که چند تابع را نشان می‌دهد:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
