# نصب

## نصب Clojure CLI
Clojure ابزارهای خط فرمانی در اختیار شما می‌گذارد که با آن‌ها می‌توانید یک REPL کلوژر را راه بیندازید، از کتابخانه‌های Clojure و Java استفاده کنید و برنامه‌های Clojure را اجرا کنید.

اگر لازم است Java را نصب کنید، [Adoptium Temurin 17](https://adoptium.net/) را به شما پیشنهاد می‌کنیم.

### لینوکس
مطمئن شوید این پیش‌نیازها نصب شده باشند: `bash`، `curl`، `rlwrap` و `Java`.
می‌توانید Clojure را به یکی از این ۲ روش نصب کنید:

1. LinuxBrew؛ به [Homebrew](https://brew.sh/) نیاز دارد.

```bash
brew install clojure/tools/clojure
```

2. نصب‌کننده‌ی اسکریپت

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew برای Mac OS X
ابزارهای خط فرمان را با brew از tapِ [clojure/tools](https://github.com/clojure/homebrew-tools) نصب کنید:

```bash
brew install clojure/tools/clojure
```

#### Java

هر توزیعی از Java کار می‌کند. اگر لازم بود، می‌توانید Temurin را با brew نصب کنید:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### ویندوز

Clojure روی ویندوز اخیراً پیشرفت چشمگیری داشته است. پیش‌تر استفاده از WSL2 را توصیه می‌کردیم که خوب هم کار می‌کند، اما حالا یک نصب‌کننده‌ی PowerShell هم هست. Clojure روی ویندوز فعلاً در وضعیت آلفا است؛ فهرست مشکلات شناخته‌شده را در [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) ببینید.

مطمئن شوید Java نصب است و متغیر محیطی `JAVA_HOME` تنظیم شده باشد، سپس اجرا کنید:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

روش دیگری برای نصب Clojure روی ویندوز، استفاده از مدیر بسته‌ی [Scoop](https://scoop.sh/) است. برای نصب scoop، PowerShell را باز کنید و این ۲ دستور را یکی پس از دیگری اجرا کنید:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

برای نصب Clojure با Scoop، اول باید دو bucket مهم را اضافه کنید:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

حالا آماده‌ایم Java و Clojure را با دستورهای زیر نصب کنیم:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

پس از اجرای موفق مراحل بالا، باید بتوانید Clojure را با دستور زیر اجرا کنید:

```sh
clj
```

## نصب Leiningen (اختیاری)

هرچند دیگر ضروری نیست، هنوز از [Leiningen](https://leiningen.org/) پشتیبانی می‌کنیم، ابزار کامل مدیریت پروژه. این ابزار کارهای مفید متنوعی ارائه می‌دهد، مثل تست راحت، ساخت پروژه و یک REPL بهتر.

1. [اسکریپت lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) یا [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) را دانلود کنید (ویندوز)
2. آن را در `$PATH` خودتان قرار دهید تا شل بتواند پیدایش کند (مثلاً `/usr/local/bin/`)
3. آن را قابل اجرا کنید (`sudo chmod a+x /usr/local/bin/lein`)
4. `lein` را اجرا کنید.
