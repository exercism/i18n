# مقدمه

نوع `char` در F# مقداری ۱۶ بیتی است که کوچک‌ترین اجزای آدرس‌پذیر متن را نمایش می‌دهد و به‌طور پیش‌فرض تغییرناپذیر است.

می‌توان `char`ها را با نقل‌قول تکی به‌صورت لیترال تعریف کرد:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

رشته‌ها دنباله‌ای از `char`ها هستند.

می‌توان یک `char` تکی را با نمایه‌گذاری (از صفر) از یک رشته به دست آورد:

```fsharp
"Exercism"[4] //  =>  'c'
```

پیمایش یک رشته در هر گام یک `char` برمی‌گرداند.

مثال بعدی برای راحتی از یک تابع مرتبه‌بالا و یک تابع بی‌نام استفاده می‌کند.
این‌ها بعداً در برنامه‌ی درسی به‌طور کامل پوشش داده می‌شوند، اما در حال حاضر اساساً روشی مختصر برای نوشتن یک حلقه روی کاراکترهای یک رشته‌اند.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

همان‌طور که در بالا نشان داده شد، می‌توان یک `char` را به مقدار `int` آن تبدیل کرد.
این کار (*حداقل بعضی وقت‌ها*) برای سایر خط‌های نوشتاری هم انجام می‌شود:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

هنگام مقایسه‌ی کاراکترها از Int16 زیربنایی استفاده می‌شود:

```fsharp
'A' < 'D'  // =>  true
```

همچنین می‌توان یک `int` را به `char` تبدیل کرد:

```fsharp
char 77  // => 'M'
```

کتابخانه‌ی `System.Char` شامل مجموعه‌ی کاملی از متدهایی است که از یک زبان .NET انتظار می‌رود، مانند تبدیل به حروف بزرگ/کوچک:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
