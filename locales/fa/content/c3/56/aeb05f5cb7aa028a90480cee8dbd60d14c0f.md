# Tests

## خلاصه

- به پوشه‌ی مسئله بروید (مثلاً `~/Exercism/hello-world`).
- یک نشست `jconsole` را در ترمینال شروع کنید.
- فایل راه‌حل خود را بارگذاری کنید (مثلاً `load 'hello-world.ijs'`).
- unit test framework را با تایپ `load  'general/unittest'` بارگذاری کنید.
- راه‌حل خود را با تایپ `unittest 'test.ijs'` آزمایش کنید.
<br></br>
- همچنین می‌توانید test‌ها را در یک خط به این شکل اجرا کنید: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## نشست Jconsole

امیدواریم روش چیدمان test‌های این track تا حد امکان ساده باشد.
اگر روی یک تمرین کار می‌کنید، مثلاً `hamming.ijs`، روند کار باید این‌گونه باشد.
فایل `hamming.ijs` را ویرایش کنید و راه‌حل خود را در آن بنویسید.
به‌صورت تعاملی آن را بسازید؛ ابتدا این دستور را تایپ کنید:

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

سپس از داخل کنسول J، با تایپ دستور زیر آن را دوباره بارگذاری کنید:

```j
load 'hamming.ijs'
```

مرحله‌ی بعد، بارگذاری unit test framework است. دستور زیر را تایپ کنید:

```j
load 'general/unittest'
```

برای اجرای test‌ها، پس از بارگذاری راه‌حل خود، این دستور را تایپ کنید:

```j
unittest 'test.ijs'
```

و سپس نتایج را ببینید.

## خط فرمان

می‌توانید test‌ها را با یک دستور تک‌خطی در ترمینال و با استفاده از پرچم `-js` اجرا کنید:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
که هر آرگومان آن نماینده‌ی دستوری است که به‌صورت متوالی اجرا می‌شود.
