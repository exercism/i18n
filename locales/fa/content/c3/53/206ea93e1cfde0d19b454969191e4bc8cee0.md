# عدد صحیح

عدد صحیح، عددی بدون جزء اعشاری است که به مجموعه‌ی `{..., -2, -1, 0, 1, 2, ...}` تعلق دارد.
بیشینه و کمینه‌ی مقدار یک عدد صحیح، به سیستمی بستگی دارد که PHP در آن اجرا می‌شود.
معمولاً در بیشتر سیستم‌های امروزی، عدد صحیح مقداری ۶۴ بیتی است؛ یعنی می‌تواند از `-9_223_372_036_854_775_808` تا `9_223_372_036_854_775_807` (به‌همراه خود این دو مقدار) را نمایش دهد.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

می‌توانید مقدارهای ثابت عدد صحیح را در مبنایی جز ۱۰ و با استفاده از پیشوند مبنا بنویسید:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
