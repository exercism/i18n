# راهنمایی‌ها

## کلی

- فضای نام `clojure.string` توابع مفید زیادی برای [دستکاری رشته][string-ns] دارد.

## 1. گرفتن پیام از یک خط لاگ

- تابع [`split`][split] را می‌توان برای تقسیم یک رشته بر اساس یک عبارت باقاعده استفاده کرد.
- تابع [`trim`][trim] را می‌توان برای حذف فضای سفید از دو سر یک رشته استفاده کرد.

## 2. گرفتن سطح لاگ از یک خط لاگ

- با استفاده از [`lower-case`][lower-case] می‌توان یک `string` را به حروف کوچک تبدیل کرد.

## 3. قالب‌بندی مجدد یک خط لاگ

- تابع [`str`][str] را می‌توان برای به هم چسباندن رشته‌ها استفاده کرد.
