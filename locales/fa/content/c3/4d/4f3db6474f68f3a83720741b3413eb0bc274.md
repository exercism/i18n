# مقدمه

## نوع جنریک

«**نوع جنریک**» یک کلاس یا رابط جنریک است که روی انواع پارامتری شده است. این کار به کامپایلر اجازه می‌دهد ایمنی نوع را روی کلاس یا رابط اعمال کند.

این رابط غیرجنریک `Container` را در نظر بگیرید:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

چون انواع `Object` را می‌پذیرد و برمی‌گرداند، با هر نوع غیراولیه کار می‌کند. اما این کار هزینه هم دارد: ممکن است بخشی از کد `get` را با انتظار `Integer` فراخوانی کند، در حالی که بخشی دیگر `set` را برای افزودن `String` فراخوانی می‌کند. نتیجه، یک استثنای زمان اجرا است.

یک «**کلاس جنریک**» و «**رابط جنریک**» قالب زیر را دارند:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

بخش پارامترهای نوع که با علامت‌های کوچک‌تر و بزرگ‌تر (`<>`) مشخص می‌شود و بعد از اسم کلاس یا رابط می‌آید، پارامترهای نوع را تعیین می‌کند: `T1`، `T2`، ... و `Tn` (به این‌ها متغیرهای نوع هم می‌گویند). می‌توان از این پارامترها در بدنه‌ی کلاس یا رابط استفاده کرد تا ایمنی نوع جنریک به دست آید.

این هم نسخه‌ی جنریک `Container` است:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

هنگام ساختن آن، حالا باید اعلام کنیم چه نوعی را نگه می‌دارد و کامپایلر همان محدودیت را اعمال می‌کند:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```

## لیست

**لیست**ها در جاوا مجموعه‌ای هستند که عناصر را به‌صورت دنباله‌ای مرتب نگه می‌دارند. برخلاف آرایه‌ها، یک [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) می‌تواند بزرگ‌تر شود تا هر تعداد عنصر را در خود جای دهد. یکی از پیاده‌سازی‌های استاندارد، `ArrayList` است که بر پایه‌ی یک آرایه‌ی قابل تغییر اندازه ساخته شده است. پیاده‌سازی استاندارد دیگر، کلاس `LinkedList` است که بر پایه‌ی یک لیست پیوندی دوطرفه ساخته شده است.

`List`ها می‌توانند خالی باشند یا هر تعداد عنصری را نگه دارند (حتی عناصر تکراری). `List`ها یک **رابط جنریک** هستند که نوعشان نشان می‌دهد چه نوع اشیایی را می‌توانند در خود داشته باشند. برای مثال:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`ها متدهای مفیدی برای افزودن، حذف کردن، گرفتن و بررسی حضور یک عنصر دارند:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
