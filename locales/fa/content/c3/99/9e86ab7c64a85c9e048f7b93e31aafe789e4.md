# دستورالعمل‌ها

اختلاف بین مربع مجموع و مجموع مربع‌های اولین `N` عدد طبیعی را پیدا کنید.

مربع مجموع ده عدد طبیعی اول برابر است با
(۱ + ۲ + ... + ۱۰)² = ۵۵² = ۳۰۲۵.

مجموع مربع‌های ده عدد طبیعی اول برابر است با
۱² + ۲² + ... + ۱۰² = ۳۸۵.

بنابراین اختلاف بین مربع مجموع ده عدد طبیعی اول و مجموع مربع‌های ده عدد طبیعی اول برابر است با ۳۰۲۵ - ۳۸۵ = ۲۶۴۰.

انتظار نمی‌رود که خودتان از اصول اولیه راه‌حل کارآمدی برای این مسئله پیدا کنید؛ پژوهش مجاز است و حتی تشویق هم می‌شود. یافتن بهترین الگوریتم برای این مسئله مهارتی کلیدی در مهندسی نرم‌افزار است.
