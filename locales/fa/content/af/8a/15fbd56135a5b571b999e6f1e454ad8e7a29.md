# مقدمه

این تمرین بلوک‌های سازنده‌ی بنیادین Ruby را به شما آموزش می‌دهد.
موضوعات زیادی را پوشش می‌دهد، اما اگر فکر می‌کنید طاقت‌فرسا است نگران نباشید؛ در ادامه‌ی مسیر، همه‌چیز را بسیار عمیق‌تر بررسی خواهیم کرد.

یکی از نکات کلیدی درباره‌ی Ruby این است که Ruby یک [زبان شیءگرا][object-oriented-programming] است و **همه‌چیز در Ruby یک [شیء][object] است**. عدد، رشته، آرایه؛ همه‌شان شیء هستند.

## متغیر و ثابت

ما معمولاً با اختصاص دادن اسم به اشیاء از آن‌ها استفاده می‌کنیم، چه از طریق متغیر و چه از طریق ثابت.

متغیرها همیشه با نگارش snake case نوشته می‌شوند.
یک متغیر می‌تواند در طول عمرش به اشیاء متفاوتی اشاره کند.
برای مثال، می‌توان `my_first_variable` را بارها با عملگر `=` تعریف و بازتعریف کرد:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

اما ثابت‌ها قرار است فقط یک بار مقدار بگیرند.
آن‌ها باید با حرف بزرگ شروع شوند و معمولاً به‌صورت تمام‌حروف‌بزرگ نوشته می‌شوند، با جداسازی کلمات به‌وسیله‌ی زیرخط.
برای مثال:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## کلاس

Ruby به‌صورت کلاس‌ها سازمان‌دهی شده است.
کلاس‌ها با کلیدواژه‌ی `class` تعریف می‌شوند که اسم کلاس بعد از آن می‌آید.
اشیاء معمولاً با نمونه‌سازی از کلاس‌ها به‌کمک متد `.new` ساخته می‌شوند.
برای مثال:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## متد

واحدهای کارکردی در متدها کپسوله می‌شوند، مشابه _تابع_ در زبان‌های دیگر.

یک متد را می‌توان با آرگومان‌های مکانی، با آرگومان‌های کلیدواژه‌ای (که با نحوه‌ی نگارش `:` تعریف و فراخوانی می‌شوند) یا بدون هیچ آرگومانی تعریف کرد.

متدها یا نتیجه‌ی آخرین دستور ارزیابی‌شده را به‌صورت ضمنی برمی‌گردانند، یا می‌توانند به‌صورت صریح یک شیء را با کلیدواژه‌ی `return` برگردانند.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

متدها با نحوه‌ی نگارش `.` فراخوانی می‌شوند:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
