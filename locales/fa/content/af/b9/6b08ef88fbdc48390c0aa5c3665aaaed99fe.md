# مقدمه

زبان Haxe از «عبارت‌های باقاعده» پشتیبانی داخلی دارد. از این عبارت‌ها می‌توان برای بررسی قالب یک رشته، تبدیل یک رشته یا استخراج داده‌های مورد نظر از یک متن مشخص استفاده کرد.

برای ساختن یک عبارت باقاعده، آن را بین `~/` و `/` بنویسید:

```haxe
var r = ~/haxe/i;
```

روش دیگری برای انجام این کار، استفاده از نمونه‌ی `EReg()` است:

```haxe
var r = new EReg("haxe", "i");
```

در اینجا `i` یک نشانه است که باعث می‌شود الگو به بزرگی و کوچکی حروف حساس نباشد. نشانه‌های دیگری هم وجود دارد، از جمله:

- `g`: جایگزینی سراسری.
- `m`: تطبیق چندخطی

بین `~/` و `/` الگوهای عبارت باقاعده را می‌نویسید. برای نمونه، می‌خواهید رشته‌ای را پیدا کنید که حروف A تا Z را در خود داشته باشد. در اینجا می‌توانیم از الگوی بازه‌ی `[A-Z]` استفاده کنیم. الگوهای زیادی وجود دارد، از جمله:

- `.`: هر نویسه
- `*`: تکرار صفر بار یا بیشتر
- `+`: تکرار یک بار یا بیشتر
- `[A-Z0-9]`: بازه‌های نویسه
