# درباره

عبارات باقاعده، فراتر از کلاس‌های کاراکتر و کمیت‌سازها، می‌توانند *ساختار* و *بافت* متن را توصیف کنند. این قابلیت‌ها در همان واژگان [`regexp`][regexp] قرار دارند و با `R/ /` نوشته می‌شوند.

## گروه‌بندی و جانشینی

پرانتزهای گرد `( )` بخشی از الگو را گروه‌بندی می‌کنند تا یک کمیت‌ساز یا `|` («این یا آن») روی کل گروه اعمال شود. `?` بعد از یک گروه، آن را اختیاری می‌کند:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## لنگرها

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

یک *مرز واژه* (`\b`) جایی است که یک کاراکتر واژه (یک حرف، رقم یا زیرخط) به یک کاراکتر غیرواژه می‌رسد، از جمله در دو انتهای رشته. پس `\bcat\b` تنها زمانی با `cat` مطابقت می‌کند که خودش به‌تنهایی آمده باشد:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## پیرامون‌نگری

*پیرامون‌نگری* بررسی می‌کند چه چیزی درست پیش یا پس از یک نقطه می‌آید، بدون اینکه آن کاراکترها بخشی از مطابقت شوند؛ یعنی صفرعرض است:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## گزینه‌ها

یک حرف گزینه بعد از `/` پایانی، کل الگو را تغییر می‌دهد. `i` یعنی تطبیق بدون توجه به بزرگی و کوچکی حروف:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## تبدیل هر مطابقت

`map-matches` روی هر مطابقت یک نقل‌قول اجرا می‌کند و نتیجه‌ها را جمع می‌کند؛ `each-match` همین کار را فقط برای عوارض جانبی انجام می‌دهد. هر دو، اندیس `start` و اندیس `end` مطابقت و کل رشته را به نقل‌قول می‌دهند؛ بنابراین `subseq` متن مطابقت‌شده را بازیابی می‌کند:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## آنچه Factor پشتیبانی نمی‌کند

موتور عبارات باقاعده‌ی Factor نه **استخراج گروه ضبط** دارد (گروه `( )` الگو را ساختار می‌دهد، اما نمی‌توانید متنی را که با آن مطابقت کرده است بازخوانی کنید)، نه **ارجاع به عقب** (`\1`) و نه **کمیت‌سازهای تنبل/غیرحریص** (`*?`، `+?`). پیرامون‌نگری جایگزین اصطلاحی گروه‌های ضبط است: همان بخشی را مطابقت دهید که می‌خواهید؛ بخشی که بافت اطرافش آن را مشخص می‌کند.
