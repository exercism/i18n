# مقدمه

«نوع داده‌ی مات» در Gleam نوع داده‌ی سفارشی‌ای است که فقط ماژولی که آن نوع را تعریف می‌کند می‌تواند مقادیر آن را بسازد یا با آن‌ها تطبیق الگو انجام دهد. این کار برای ساختن نوع‌هایی مفید است که باید فقط به یک شیوه‌ی خاص استفاده شوند.

نوع داده‌ی مات با کلیدواژه‌ی `opaque` تعریف می‌شود.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

این نوع `PositiveInt` برای موقعیت‌هایی است که یک عدد صحیح لازم است، اما باید صفر یا بزرگ‌تر باشد. نمی‌توان از یک `Int` معمولی Gleam استفاده کرد، چون می‌تواند منفی هم باشد.

ماژولی که این نوع را تعریف می‌کند می‌تواند تابعی برای گرفتن مقدار عدد صحیح درونی تعریف کند و تابعی برای ساختن نوع `PositiveInt` که اگر مقدار مثبت نباشد، خطا برمی‌گرداند.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

با این API، ماژول‌های دیگر نمی‌توانند یک `PositiveInt` با مقدار منفی بسازند، بنابراین هر تابعی که یک `PositiveInt` می‌گیرد می‌تواند مطمئن باشد که مقدارش مثبت است.
