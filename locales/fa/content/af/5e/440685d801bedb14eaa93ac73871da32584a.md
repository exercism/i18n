# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است [استثنایی ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** بگنجانید تا مشخص شود منبع خطا چیست. این کار کد شما را خواناتر می‌کند و در اشکال‌زدایی کمک زیادی می‌کند. اگر می‌دانید منبع خطا نوع مشخصی دارد، می‌توانید یکی از [انواع خطای توکار](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما باز هم باید پیامی معنادار همراه آن بگنجانید.

این تمرین خاص می‌خواهد که از [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) استفاده کنید تا برای پایه‌های ورودی و خروجی متفاوت، یک `ValueError` «پرتاب» کنید. آزمون‌ها فقط وقتی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی معنادار همراه آن بگنجانید.

برای پرتاب یک `ValueError` همراه با پیام، پیام را به‌عنوان آرگومان به نوع `exception` بدهید:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
