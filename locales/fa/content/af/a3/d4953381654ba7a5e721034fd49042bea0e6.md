# جاینگهدار

## پیاده‌سازی عملیات‌های `List`

هدف این تمرین این است که خودتان برخی از متدهای `List` را پیاده‌سازی کنید.
طبیعی است که در پشت‌صحنه از یک شیء `List` برای نگهداری داده‌ها استفاده کنید.
به متدهای `List` (مانند `where`، `map` و غیره) دست نزنید.

چند عملیات «ابتدایی» `List` وجود دارد که نمی‌توان از آن‌ها اجتناب کرد، مانند:

* برش: `list[from..to]`
* افزودن: `list.add(item)`

## پروتکل پیمایشگر

عملیات‌های `List` که باید پیاده‌سازی شوند، همگی به پیمایش کردن به روش‌های مختلف مربوط‌اند.
درباره‌ی [پروتکل پیمایشگر][iter] بخوانید.
سپس می‌توانید این کار را انجام دهید:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
