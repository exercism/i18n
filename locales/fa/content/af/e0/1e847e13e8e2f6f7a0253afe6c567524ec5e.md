# درباره

«خاصیت» دو نوع اصلی دارد:

1. خاصیت‌های خودکار، که دسترسگرهای `get` و `set` در آن‌ها بدنه ندارند.
   این خاصیت‌ها ممکن است به‌صورت صریح مقداردهی اولیه شوند یا نشوند. برای مثال:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. خاصیت‌هایی که دسترسگرهایشان عبارت‌ها را ارزیابی می‌کنند و دستورها را اجرا می‌کنند. کد می‌تواند
   به‌سادگی بازگرداندن یا مقداردهی یک فیلد پشتیبان باشد. برای مثال:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

میان خاصیت‌ها و متدها هم‌پوشانی چشمگیری در رفتار و توانایی وجود دارد.
خاصیتی که خودکار نباشد می‌تواند هر دستور یا عبارتی را در خود جای دهد که می‌تواند در محدوده‌ی کلاس ظاهر شود. در حالت رایج، اغلب گفته می‌شود که این خاصیت‌ها یک فیلد پشتیبان را در بر می‌گیرند.
هرچند بیشتر اوقات معلوم است که در یک موقعیت خاص باید رفتار را به‌صورت خاصیت نوشت یا متد، اما این کار اغلب به قضاوت خود برنامه‌نویس بستگی دارد، به‌ویژه در اینکه چه مقدار کد باید درون دسترسگرها اجرا شود. اعتبارسنجی در دسترسگر `set` و محاسبه یا قالب‌بندی ساده در دسترسگر `get` بسیار رایج‌اند:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

خاصیت‌ها هم مانند دیگر اعضای کلاس می‌توانند سطح دسترسی داشته باشند.
بیشتر اوقات خاصیت سطح دسترسی غیرخصوصی دارد، هم‌سو با هدف اصلی‌اش. گاهی یکی از دسترسگرها
سطح دسترسی متفاوتی با خود خاصیت دارد. در مورد `TareWeight` و آن قید نسبتاً تصنعی «امنیت»، این فرصت
وجود داشت که خاصیتی عمومی با دسترسگر `get` خصوصی داشته باشیم. یعنی کدی بیرون
از کلاس می‌تواند مقدار خاصیت را تنظیم کند، اما فقط کدی درون کلاس می‌تواند آن را بخواند (get کند).

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

دسترسگرهای `set` غیرعمومی هم پشتیبانی می‌شوند، اما حالت رایج‌تر این است که
دسترسگر `set` به‌کلی حذف شود. علتش شاید این باشد که
مقدار خاصیت در سازنده‌ی کلاس تنظیم می‌شود.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

این تمرین به کاربرد پایه‌ی خاصیت‌ها پرداخته است. موضوع‌های پیشرفته‌تر را در تمرین‌های دیگر پیدا می‌کنید:

- خاصیت‌های با بدنه‌ی عبارت، دسترسگرهای `get` و دسترسگرهای `set` (در تمرین «اعضای با بدنه‌ی عبارت» پوشش داده شده است)
- خاصیت‌ها روی رابط‌ها (در تمرین «رابط» پوشش داده شده است)
- خاصیت‌ها/خاصیت‌های انتزاعی روی کلاس‌های انتزاعی (در تمرین «وراثت» پوشش داده شده است)
- استفاده از کلیدواژه‌ی `readonly` همراه با خاصیت‌ها (در تمرین «تغییرناپذیری» پوشش داده شده است)
- خاصیت‌های ایستا (در تمرین «اعضای ایستا» پوشش داده شده است)
- اندیس‌گذارها (در تمرین «اندیس‌گذار» پوشش داده شده است)
