# پیوست دستورالعمل

اگر ورودی نامعتبر باشد، یک طول خالی برگردانید.

## آدرس‌های رزروشده

بافر رشته‌ی اول از بایت‌های 1024 تا 2047 حافظه‌ی خطی استفاده می‌کند.
بافر رشته‌ی دوم از بایت‌های 2048 تا 3071 حافظه‌ی خطی استفاده می‌کند.
بافر رشته‌ی سوم از بایت‌های 3072 تا 4095 حافظه‌ی خطی استفاده می‌کند.

بخش اول بایت‌های 0 تا 1023 حافظه‌ی خطی آزاد است و می‌توانید از آن استفاده کنید.
