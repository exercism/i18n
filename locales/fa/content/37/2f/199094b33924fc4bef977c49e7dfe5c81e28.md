# دستورالعمل‌ها

سلام، مأمور Double-Null0111.

مأموریت شما، در صورتی که تصمیم بگیرید آن را بپذیرید، این است که چند ابزار بنویسید تا به مقر UMBRA (United Minions Being Really Awful) نفوذ کنید و نقشه‌های آخرین حیله‌ی واقعاً افتضاحشان را به دست آورید.
برای انجام این مأموریت به سه ابزار نیاز دارید.

## 1. تولید یک شماره‌ی شناسه

هر دست‌نشانده یک شناسه‌ی یکتا دارد که هر روز تغییر می‌کند و به تعداد اسرارش و تعداد ساعت‌هایی که می‌خوابد بستگی دارد.
باید تابعی بنویسید که روز را (به‌صورت `Int`) می‌گیرد و یک تابع تولید شناسه برای آن روز می‌سازد.
تابع تولید شناسه دو پارامتر می‌گیرد:

1. تعداد اسرارش
2. تعداد ساعت‌هایی که دست‌نشانده می‌خوابد

شناسه این‌گونه محاسبه می‌شود:

1. تعداد اسرارش را در تعداد ساعت‌هایی که می‌خوابد ضرب کنید
2. روز را (به‌صورت `Int`) به نتیجه اضافه کنید

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. محافظت از نقشه‌های سری کشف‌شده با یک گذرواژه‌ی سری

وقتی نقشه‌های سری را به دست آوردید، باید از آن‌ها محافظت کنید تا فقط کسانی که گذرواژه را می‌دانند بتوانند آن‌ها را بازیابی کنند.
برای این کار، باید تابع `protectSecret(secret: String, password: String) : (String) -> String` را پیاده‌سازی کنید.
این تابع تابع دیگری برمی‌گرداند که رشته‌های گذرواژه‌ی ممکن را به‌عنوان ورودی می‌گیرد.
اگر گذرواژه‌ی واردشده درست باشد، تابع جدید سری پنهان را برمی‌گرداند؛ اما اگر گذرواژه نادرست باشد، تابع «Sorry. No hidden secrets here.» را برمی‌گرداند.

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. پیدا کردن گذرواژه‌ی سری

پایگاه UMBRA تعدادی اتاق دارد که یک نگهبان از آن‌ها محافظت می‌کند و گذرواژه‌ی سری را از شما می‌پرسد.
گذرواژه‌ی سری به شماره‌ی اتاق بستگی دارد.
متأسفانه ما فقط نیمی از الگوریتم محاسبه‌ی گذرواژه را می‌دانیم.
نیمه‌ی دیگر را می‌توان با پرسیدن از یکی از دست‌نشانده‌ها پیدا کرد.

تابع `getPassword` را پیاده‌سازی کنید که ورودی‌های زیر را می‌گیرد و گذرواژه را برمی‌گرداند:

1. شماره‌ی اتاق
2. تابع دست‌نشانده، و در پایان گذرواژه‌ی سری را برمی‌گرداند

گذرواژه‌ی سری با فراخوانی تابع دست‌نشانده و دادن یک تابع دیگر به آن که نمایانگر الگوریتم معلوم ما است، به دست می‌آید.
بخش مربوط به ما در الگوریتم:

1. دو عدد می‌گیرد و آن‌ها را با هم جمع می‌کند
2. نتیجه را در شناسه‌ی اتاق ضرب می‌کند

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
