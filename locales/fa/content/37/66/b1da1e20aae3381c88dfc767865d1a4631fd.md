# ضمیمه‌ی دستورالعمل

## دستورالعمل‌های ویژه‌ی این ترک

تابع‌ها باید حاصل‌ضرب و همچنین آفست و طول آرایه‌ی عامل‌ها را برگردانند. عامل‌ها فقط به‌صورت جفت‌هایی از `i32` در حافظه نوشته می‌شوند:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

برای بزرگ‌ترین حاصل‌ضرب پالیندروم یک‌رقمی، به این شکل خواهد بود:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
