# پیوست دستورالعمل‌ها

## چاپ درخت

این تمرین چند متد کلاس از پیش تعریف‌شده دارد که به چاپ درخت در قالبی مرتب کمک می‌کنند. هدف اصلی‌شان کمک به Debug و روشن‌تر شدن موضوع است. اگر بقیه‌ی کلاس را درست پیاده‌سازی کنید، درخت را برایتان چاپ می‌کند.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
