# مقدمه

در برنامه‌نویسی، مدیریت ماهرانه‌ی خطاها ضروری است تا اطمینان حاصل شود که موقعیت‌های غیرمنتظره باعث از کار افتادن برنامه یا رفتار غیرقابل‌پیش‌بینی آن نمی‌شوند.
Cairo دو سازوکار اصلی برای مدیریت خطا در اختیار می‌گذارد:

۱. **خطاهای غیرقابل بازیابی** با `panic` که بلافاصله برنامه را متوقف می‌کنند.
۲. **خطاهای قابل بازیابی** با `Result` که به برنامه اجازه می‌دهند خطاها را مدیریت کند و به آن‌ها واکنش نشان دهد.

## خطاهای غیرقابل بازیابی با `panic`

گاهی برنامه با خطایی چنان جدی روبه‌رو می‌شود که نمی‌تواند ادامه دهد.
Cairo در چنین مواردی از تابع `panic` استفاده می‌کند تا اجرا را بلافاصله متوقف کند.
این کار زمانی مفید است که یک خطا، مثلاً تلاش برای دسترسی به اندیسی خارج از محدوده، ادامه‌ی منطقی برنامه را ناممکن کند.
تابع `panic` یک پیام از نوع `ByteArray` می‌پذیرد که دلیل خطا را توصیف می‌کند.

برای مثال، در Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

این مثال یک `panic` اجباری را نشان می‌دهد که برنامه را بلافاصله همراه با یک پیام متوقف می‌کند.

### ماکروی `assert!`

ماکروی `assert!` ابزار مفیدی برای اعمال شرط‌های مشخص در کدتان است.
اگر شرط داخل `assert!` به `false` ارزیابی شود، برنامه با یک پیام خطای `ByteArray` دچار `panic` می‌شود.
این کار اغلب برای بررسی فرض‌ها هنگام توسعه و اطمینان از برآورده شدن معیارهای مشخص توسط مقادیر استفاده می‌شود.

برای مثال:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

اگر `x` بزرگ‌تر از صفر نباشد، برنامه با پیام `"x must be greater than zero"` دچار `panic` می‌شود. `assert!` برای بررسی ناورداها و پیش‌شرط‌ها بدون نوشتن دستی کد مدیریت خطا مفید است.

## خطاهای قابل بازیابی با `Result`

همه‌ی خطاها لازم نیست برنامه را متوقف کنند.
بعضی از آن‌ها را می‌توان ماهرانه مدیریت کرد تا برنامه بتواند ادامه دهد.
شمارشی `Result` در Cairo نماینده‌ی این خطاهای قابل بازیابی است و دو گونه دارد:

- `Result::Ok` نشان‌دهنده‌ی موفقیت است.
- `Result::Err` نشان‌دهنده‌ی یک خطا است.

با استفاده از `Result`، یک تابع می‌تواند یا یک مقدار موفقیت برگرداند یا یک خطا، و این به تابع فراخوان‌کننده اجازه می‌دهد تصمیم بگیرد قدم بعدی چیست.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

در این مثال، اگر `b` صفر باشد، یک خطا برگردانده می‌شود؛ در غیر این صورت، نتیجه‌ی تقسیم برگردانده می‌شود.
