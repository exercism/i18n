# دستورالعمل‌ها

[نقاشی با شماره][paint-by-number] (که با اسم _رنگ‌آمیزی با شماره_ هم شناخته می‌شود) تصاویری سیاه‌وسفید برای رنگ‌آمیزی است.
روی بخش‌های مختلف تصویر شماره‌های متفاوتی نوشته می‌شود و این شماره‌ها به رنگ‌های مشخصی در یک پالت رنگ از پیش تعریف‌شده اشاره می‌کنند.
هدف این است که بخش‌ها را با رنگ‌های درست پر کنید تا در پایان تصویری زیبا و رنگارنگ نمایان شود.
این یک فعالیت آرام‌بخش برای کودکان و بزرگسالان است.

قرار است یک برنامه‌ی نقاشی با شماره به زبان Elixir بنویسید.
می‌خواهید برنامه‌تان بتواند تصاویر را در یک قالب داده‌ای سفارشی وارد و صادر کند.
تصمیم گرفته‌اید داده‌های تصویرتان را در [فایل‌های دودویی][binary-file] ذخیره کنید.

~~~~exercism/note
این تمرین فرض می‌کند که با [اعداد دودویی](https://en.wikipedia.org/wiki/Binary_number) آشنا هستید و اصول تبدیل اعداد دودویی به اعداد دهدهی و اعداد دهدهی به اعداد دودویی را می‌دانید.
~~~~

تصور کنید تصویری از یک شکلک لبخند دارید، مثل تصویری که در ادامه می‌بینید.
پس‌زمینه‌ی تصویر سفید است. شکلک یک حاشیه‌ی سیاه و یک رنگ پرکننده‌ی زرد دارد.

این تصویر از ۳ رنگ استفاده می‌کند.
فرض کنید به این رنگ‌ها اندیس نسبت می‌دهیم:
- `0` (دودویی: `0b00`) برای سفید،
- `1` (دودویی: `0b01`) برای سیاه،
- `2` (دودویی: `0b10`) برای زرد.

حالا می‌توانیم با این اندیس‌های رنگ، رنگ هر پیکسل را نمایش دهیم.

## 1. محاسبه‌ی اندازه‌ی بیت پالت

تابع `PaintByNumber.palette_bit_size/1` را پیاده‌سازی کنید. این تابع باید تعداد رنگ‌های پالت را بگیرد و برگرداند که برای نمایش این تعداد اندیس رنگ به‌صورت اعداد دودویی، چند بیت لازم است. اندیس‌های رنگ همیشه از ۰ شروع می‌شوند و اعداد صحیحی صعودی و پیوسته‌اند.

برای مثال، نمایش ۱۳ رنگ متفاوت به ۴ بیت نیاز دارد. ۴ بیت می‌تواند تا ۱۶ اندیس رنگ (۲ به توان ۴) را ذخیره کند. ۳ بیت کافی نیست، چون ۳ بیت فقط می‌تواند تا ۸ اندیس رنگ (۲ به توان ۳) را ذخیره کند.

```elixir
PaintByNumber.palette_bit_size(13)
# => 4
```

توجه: در کتابخانه‌ی استاندارد Elixir تابع `log2` وجود ندارد. بعداً یاد می‌گیرید که چطور در Elixir از [کتابخانه‌های Erlang][erlang-libraries] استفاده کنید، جایی که می‌توانید این تابع را پیدا کنید. فعلاً این کار را به‌جای آن، با بازگشت و [عملگر توان `**`][power-operator] حل کنید.

## 2. ساختن یک تصویر خالی

تابع `PaintByNumber.empty_picture/0` را پیاده‌سازی کنید. این تابع باید یک رشته‌ی بیتی خالی برگرداند.

## 3. ساختن یک تصویر آزمایشی

برای آزمون دستی قابلیت‌های پایه‌ی برنامه‌تان از یک تصویر آزمایشی از پیش تعریف‌شده استفاده می‌شود.
تصویر آزمایشی از ۴ پیکسل با ۴ رنگ متفاوت تشکیل شده است.

تابع `PaintByNumber.test_picture/0` را پیاده‌سازی کنید. این تابع باید رشته‌ی بیتی‌ای برگرداند که از ۴ بخش تشکیل شده است. اندازه‌ی بیت هر بخش باید ۲ باشد. مقدار بخش‌ها باید ۰، ۱، ۲ و ۳ باشد.

## 4. افزودن یک پیکسل به ابتدای تصویر

تابع `PaintByNumber.prepend_pixel/3` را پیاده‌سازی کنید. این تابع باید سه ورودی بگیرد: یک رشته‌ی بیتی از تصویری که می‌خواهیم به ابتدای آن چیزی اضافه کنیم، تعداد رنگ‌های پالت، و اندیس رنگ پیکسل جدید. خروجی آن باید رشته‌ی بیتی‌ای باشد که پیکسل جدید به ابتدای تصویرش اضافه شده است.

```elixir
picture = <<2::4, 0::4>>
color_count = 13
pixel_color_index = 11

PaintByNumber.prepend_pixel(picture, color_count, pixel_color_index)
# => <<178, 0::size(4)>>
# (which is equal to <<11::4, 2::4, 0::4>>)
```

## 5. گرفتن پیکسل اول از یک تصویر

تابع `PaintByNumber.get_first_pixel/2` را پیاده‌سازی کنید. این تابع باید دو ورودی بگیرد: یک رشته‌ی بیتی از تصویری که از آن می‌خوانیم، و تعداد رنگ‌های پالت. باید اندیس رنگ پیکسل اول تصویر داده‌شده را برگرداند. اگر تصویر خالی به آن داده شود، باید `nil` را برگرداند.

```elixir
picture = <<19::5, 2::5, 18::5>>
color_count = 20

PaintByNumber.get_first_pixel(picture, color_count)
# => 19
```

## 6. حذف پیکسل اول از یک تصویر

تابع `PaintByNumber.drop_first_pixel/2` را پیاده‌سازی کنید. این تابع باید دو ورودی بگیرد: یک رشته‌ی بیتی از تصویری که می‌خواهیم پیکسلی را از آن حذف کنیم، و تعداد رنگ‌های پالت. باید تصویر را بدون پیکسل اول برگرداند. اگر تصویر خالی به آن داده شود، باید یک تصویر خالی برگرداند.

```elixir
picture = <<2::3, 5::3, 5::3, 0::3>>
color_count = 6

PaintByNumber.drop_first_pixel(picture, color_count)
# => <<180, 0::size(1)>>
# (which is equal to <<5::3, 5::3, 0::3>>)
```

## 7. به هم پیوستن دو تصویر

تابع `PaintByNumber.concat_pictures/2` را پیاده‌سازی کنید. این تابع باید دو ورودی، یعنی دو رشته‌ی بیتی، بگیرد. باید رشته‌ی بیتی‌ای برگرداند که حاصل افزودن ورودی اول به ابتدای ورودی دوم است.

```elixir
picture1 = <<52::6, 51::6>>
picture2 = <<0::6, 34::6, 12::6>>

PaintByNumber.concat_pictures(picture1, picture2)
# => <<211, 48, 34, 12::size(6)>>
# (which is equal to <<52::6, 51::6, 0::6, 34::6, 12::6>>)
```
