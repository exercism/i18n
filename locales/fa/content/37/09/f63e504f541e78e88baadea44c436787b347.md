# رشته

Crystal نوعی به نام [`String`][strings] دارد که برای نمایش متن استفاده می‌شود.
رشته‌های Crystal دنباله‌هایی از نویسه‌های یونیکد هستند.
رشته‌ها تغییرناپذیرند، یعنی پس از ساخته‌شدن نمی‌توان آن‌ها را تغییر داد.
این یعنی هر بار که یک رشته را تغییر می‌دهید، یک رشته‌ی جدید ساخته می‌شود؛ در نتیجه، رشته‌ی اصلی تغییر نمی‌کند.

برای تعریف یک رشته از گیومه‌ی دوتایی `"` استفاده می‌کنید.

```crystal
"Hello World"
```

## الحاق

برای الحاق دو رشته، از عملگر `+` استفاده کنید.
عملگر `+` یک رشته‌ی جدید برمی‌گرداند که دو رشته را با هم ترکیب می‌کند.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## تبدیل بین رشته‌ها و اعداد

متد `to_i` یک رشته را به عدد صحیح تبدیل می‌کند.
در عوض، می‌توان از متد `to_f` برای برگرداندن یک عدد اعشاری استفاده کرد.
اگر رشته به عدد تبدیل نشود، یک `ArgumentError` رخ می‌دهد.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

یک عدد صحیح یا اعشاری را می‌توان با استفاده از متد `to_s` به رشته تبدیل کرد.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## درج

درج روشی راحت برای ترکیب رشته‌ها و جای‌گذاری عبارت‌ها در رشته‌ها است.
برای درج یک رشته، می‌توانید از نویسه‌ی `#` و بعد از آن آکولادهای `{}` با عبارت داخل آکولادها استفاده کنید.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal به‌طور خودکار نتیجه‌ی عبارت را به رشته تبدیل می‌کند.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## اندازه

وقتی می‌خواهید تعداد نویسه‌های یک رشته را بدانید، می‌توانید از متد `size` استفاده کنید که طول رشته را به‌صورت یک عدد صحیح برمی‌گرداند.
اندازه‌ی یک رشته یک ویژگی ذخیره‌شده‌ی رشته است، بنابراین لازم نیست هر بار که متد را فراخوانی می‌کنید اندازه را محاسبه کند و همین آن را بسیار سریع می‌کند.

```crystal
"Hello World".size
# => 11
```

## اندیس‌گذاری

اندیس‌گذاری یعنی وقتی می‌خواهید یک نویسه‌ی مشخص را از یک رشته بگیرید.
برای گرفتن یک نویسه از `String` می‌توانید از نماد کروشه‌ی آشنا استفاده کنید.

~~~~exercism/note
`[]` به‌صورت یک متد نمونه‌ی `String` پیاده‌سازی شده است، که اندیس آرگومان متد است.
~~~~

در Crystal، نخستین نویسه‌ی یک رشته در اندیس ۰ قرار دارد.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

برای گرفتن یک نویسه از انتهای رشته، می‌توانید طول رشته منهای ۱ را بگیرید تا اندیس آخرین نویسه به دست آید؛ و برای گرفتن نویسه‌ی یکی‌به‌آخر، طول رشته منهای ۲ را بگیرید و به همین ترتیب.
یک میانبر هم وجود دارد و آن این است که به‌سادگی از اندیس منفی استفاده کنید: آخرین نویسه در اندیس منفی ۱ است، نویسه‌ی یکی‌به‌آخر در اندیس منفی ۲ و به همین ترتیب.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### آزمون زیررشته

Crystal با استفاده از اندیس‌گذاری از آزمایش اینکه یک رشته شامل زیررشته است پشتیبانی می‌کند.
همان نماد کروشه این کار را انجام می‌دهد، اما به‌جای اندیس، یک زیررشته داده می‌شود.
اگر زیررشته در رشته پیدا شود، همان زیررشته برگردانده می‌شود؛ در غیر این صورت یک `NilAssertionError` رخ می‌دهد.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

اگر می‌خواهید یک مقدار `Bool` نشان دهد که زیررشته پیدا شده است یا نه، می‌توانید از متد `includes?` استفاده کنید.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## escape کردن

برخی نویسه‌ها را نمی‌توان مستقیماً در یک رشته نوشت؛ به‌جای آن باید از یک دنباله‌ی escape استفاده کنید.
برای مثال، اگر بخواهید از گیومه‌ی دوتایی در یک رشته استفاده کنید، باید گیومه‌های دوتایی را escape کنید.
می‌توانید از نویسه‌ی `\` برای نوشتن یک دنباله‌ی escape استفاده کنید و بعد از آن نویسه‌ی موردنظر برای escape را بنویسید.

این‌ها نویسه‌های ویژه در Crystal هستند:

| مقدار    | توضیح                         |
| -------- | ----------------------------- |
| `\a`     | هشدار                         |
| `\b`     | پاک‌کن                         |
| `\e`     | فرار                          |
| `\f`     | تغذیه‌ی فرم                    |
| `\n`     | خط جدید                       |
| `\r`     | بازگشت به ابتدای خط           |
| `\t`     | تب افقی                       |
| `\v`     | تب عمودی                      |
| `\\`     | بک‌اسلش                       |
| `\'`     | گیومه‌ی تکی                    |
| `\"`     | گیومه‌ی دوتایی                 |
| `\377`   | نویسه‌ی ASCII در مبنای هشت     |
| `\xFF`   | نویسه‌ی ASCII در مبنای شانزده  |
| `\uFFFF` | نویسه‌ی یونیکد در مبنای شانزده |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## رشته‌های چندخطی

برای نوشتن یک رشته‌ی چندخطی، از همان نحوه‌ی نگارش رشته‌ی تک‌خطی استفاده می‌کنید، اما برای هر خطی که می‌خواهید در رشته باشد یک خط جدید ایجاد می‌کنید.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## یونیکد

[یونیکد][unicode] استانداردی برای رمزگذاری، نمایش و پردازش متن در سیستم‌های نوشتاری مختلف است.
یونیکد از بیش از ۱۰۰٬۰۰۰ نویسه، شامل حروف، نشانه‌های سجاوندی، نمادها و ایموجی پشتیبانی می‌کند.

از آنجا که Crystal برای رشته‌ها از یونیکد استفاده می‌کند، می‌توانید برای مثال ایموجی‌ها را در رشته‌ها قرار دهید.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

گاهی می‌خواهید از نویسه‌ای استفاده کنید که مثلاً در ویرایشگر یا سیستم شما موجود نیست.
در این صورت، می‌توانید از دنباله‌ی escape یونیکد برای نوشتن آن نویسه استفاده کنید.

```crystal
"\u{1F310}"
# => "🌐"
```
