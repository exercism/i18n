# مقدمه

زبان Go مفهومی به نام «خالی»، «null» یا «undefined» برای مقادیر متغیرها ندارد.
متغیرهایی که بدون مقدار اولیه‌ی صریح اعلام می‌شوند، به‌صورت پیش‌فرض مقدار صفر نوع خودشان را می‌گیرند.

مقدار صفر برای انواع اولیه مانند «منطقی»، انواع عددی و رشته‌ها به ترتیب `false`، `0` و `""` است.

شناسه‌ی `nil` که به معنای صفر است، مقدار صفر برای انواع پیچیده‌تری مانند اشاره‌گرها، توابع، رابط‌ها، برش‌ها، کانال‌ها و نقشه‌هاست.

جدول زیر مقدار صفر را برای انواع Go نشان می‌دهد.

| نوع       | مقدار صفر |
| --------- | ---------- |
| منطقی     | `false`    |
| عددی      | `0`        |
| رشته      | `""`       |
| اشاره‌گر  | `nil`      |
| تابع      | `nil`      |
| رابط      | `nil`      |
| برش       | `nil`      |
| کانال     | `nil`      |
| نقشه      | `nil`      |

شاید متوجه شده باشید که انواع ساختار در جدول بالا نیامده‌اند.
دلیلش این است که مقدار صفر برای یک نوع ساختار به فیلدهای آن بستگی دارد.
یک ساختار زمانی به مقدار صفر خود می‌رسد که همه‌ی فیلدهایش به مقدار صفر مربوط به خودشان تنظیم شده باشند.
