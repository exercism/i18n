# درباره

در Haxe، یک «نوع انتزاعی» نوعی است که در زمان اجرا نوع دیگری است. این یک ویژگی زمان کامپایل است که نوع‌هایی را روی «نوع‌های مشخص» تعریف می‌کند تا رفتارشان را تغییر دهد یا گسترش دهد:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

در اینجا نوع `AbstractInt` را با کلیدواژه‌ی `abstract` تعریف می‌کنیم. نحوه‌ی نگارش آن بسیار شبیه نحوه‌ی نگارش `class` است. و درست مثل کلاس‌ها، نوع‌های انتزاعی می‌توانند متد داشته باشند. همچنین می‌توان آن‌ها را نمونه‌سازی کرد و درست مثل کلاس‌ها به کار برد:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

همان‌طور که در بالا اشاره شد، نوع‌های انتزاعی یک ویژگی زمان کامپایل هستند. اگر مثال بالا را به JavaScript کامپایل کنیم، خروجی زیر به دست می‌آید:

```javascript
var a = 12;
console.log(a)
```

نوع انتزاعی `AbstractInt` کاملاً از خروجی ناپدید می‌شود. دلیلش این است که سازنده‌ی `Abstract` [درون‌خط][inline] می‌شود، موضوعی که بعداً خواهیم دید.

[inline]: https://haxe.org/manual/class-field-inline.html
