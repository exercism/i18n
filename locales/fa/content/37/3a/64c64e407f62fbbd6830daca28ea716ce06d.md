# درباره

## بستار دنباله‌دار

Swift هنگام کار با بستارها یک گونه‌ی دیگر از نحوه‌ی نگارش خود را هم ارائه می‌دهد که به آن [بستار دنباله‌دار][trailing-closures] می‌گویند. بستار دنباله‌دار زمانی پیش می‌آید که آخرین پارامتر در فهرست پارامترهای یک تابع، نوع تابع داشته باشد. در این حالت، اگر بخواهید بستاری را پاس بدهید، می‌توانید آن را _بعد_ از پرانتز بسته بنویسید و برچسب آرگومان حذف می‌شود. توجه کنید که اگر تابع فقط یک پارامتر داشته باشد، می‌توان پرانتزها را به‌کلی حذف کرد.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## چند بستار دنباله‌دار

نسخه‌های پیشین Swift فقط از یک بستار دنباله‌دار پشتیبانی می‌کردند، اما Swift از نسخه‌ی 5.2.4 به بعد از چند بستار دنباله‌دار هم پشتیبانی می‌کند.

اگر تابعی در پایان فهرست پارامترهایش بیش از یک بستار داشته باشد، می‌توان از نحوه‌ی نگارش بستار دنباله‌دار استفاده کرد تا همه‌ی آن‌ها را بیرون از پرانتزها آورد. اما تنها برچسب آرگومان اول حذف می‌شود و بقیه باید برچسب داشته باشند:

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```

[trailing-closures]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID102
