# درباره

[«عملگرهای سه‌گانه»][ternary-operators] امکان تعریف شرط‌های `if` را در قالب عبارت، به‌جای بلوک‌های دستور، فراهم می‌کنند. این رویکرد با شیوه‌های برنامه‌نویسی تابعی هم‌خوانی دارد و اغلب می‌تواند کد را گویاتر و کم‌خطاتر کند.

عملگر سه‌گانه سه عبارت را با هم ترکیب می‌کند: یک شرط و پس از آن عبارتی که اگر شرط «درست» باشد ارزیابی و برگردانده می‌شود (بخش `if` که با `?` معرفی می‌شود) و عبارتی که اگر شرط «غلط» باشد ارزیابی و برگردانده می‌شود (بخش `else` که با `:` معرفی می‌شود).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
