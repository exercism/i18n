# نصب

## Linux

Bash، به‌عنوان پوسته‌ی GNU، روی هر سیستم GNU/Linux پیدا می‌شود.
BSD و سایر مشتقات UNIX احتمالاً باید توسط کاربر نصب شوند.
اگر از BSD، AIX یا توزیع لینوکسی استفاده می‌کنید که bash همراه ندارد، برای نصب بسته‌های غیرهسته‌ای به منابع سیستم‌عامل خود مراجعه کنید.

در محیط گرافیکی موردنظرتان، دنبال برنامه‌ای با نام «Terminal» بگردید: ممکن است آن را زیر بخش «Administrative/System Tools» پیدا کنید.

برای بررسی نسخه‌ی Bash موجود، از خط فرمان یا ترمینال این را اجرا کنید:

    echo $BASH_VERSION

اگر پوسته‌تان `bash` باشد، باید چیزی شبیه این نشان دهد:

    4.4.19(1)-release

در این مرحله نباید لازم باشد کار دیگری انجام دهید؛ bash باید نصب شده و در مسیر شما باشد، چون پوسته‌ی فعلی شماست.

اگر پوسته‌تان bash نیست، دلیلی برای تغییر آن وجود ندارد.
می‌توانید بدون اینکه در پوسته‌ی bash باشید، اسکریپت‌های bash بنویسید و اجرا کنید.

برای بررسی نسخه‌ی bash نصب‌شده، این را اجرا کنید:

```plain
bash --version
```

چیزی شبیه این نشان می‌دهد:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

اگر این‌طور نبود، ممکن است bash را نصب نکرده باشید.
باید آن را با استفاده از مدیر بسته‌ی توزیع‌تان نصب کنید.

## Windows

برای Windows ۱۰ می‌توانید [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) را نصب کنید.
این کار یک توزیع کامل لینوکس (خب، بخش‌های بدون رابط گرافیکی آن) را نصب می‌کند که به‌صورت بومی در Windows اجرا می‌شود.

در غیر این صورت، می‌توانید این‌ها را نصب کنید:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* یک توزیع کامل لینوکس در [یک ماشین مجازی](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

برای Apple OSX:

* Finder را باز کنید،
* پوشه‌ی Applications را باز کنید،
* پوشه‌ی Utilities را باز کنید،
* و در نهایت برنامه‌ی `Terminal` را باز کنید.

توجه کنید که نسخه‌ی bash نصب‌شده روی MacOS بسیار قدیمی است، نسخه‌ی ۳.۲.
دلیلش این است که (۱) نسخه‌های جدیدتر bash تحت GPLv3 منتشر می‌شوند و (۲) Apple نمی‌خواهد مجبور شود شرایط آن مجوز را رعایت کند.
علاوه بر این، Apple اعلام کرده است که bash از MacOS حذف خواهد شد: پوسته‌ی ورود پیش‌فرض به‌تازگی [از bash به zsh تغییر کرده است](https://support.apple.com/en-us/HT208050).

برای دریافت یک bash به‌روز روی مک خود:

1. [Homebrew](https://brew.sh) را نصب کنید.
1. در یک ترمینال، این را وارد کنید: `brew install bash`

این کار یک bash به‌روز را در (به گمانم) `/usr/local/bin/bash` نصب می‌کند (تا bash پیش‌فرض سیستم بازنویسی نشود، چون ابزارهای دیگری ممکن است به /bin/bash وابسته باشند).

اگر می‌خواهید وقتی `bash` را تایپ می‌کنید، bash مربوط به Homebrew اجرا شود، فایل ‎~/.bash_profile (یا ‎~/.profile) خود را ویرایش کنید تا /usr/local/bin را در PATH *جلوتر* از /bin قرار دهید:

    PATH=/usr/local/bin:$PATH
