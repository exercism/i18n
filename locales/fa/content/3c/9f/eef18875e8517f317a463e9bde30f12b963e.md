# مقدمه

«هش‌مپ» یک مجموعه است که برای ذخیره‌ی جفت‌های کلید-مقدار استفاده می‌شود. هش‌مپ به انواع دلخواه اجازه می‌دهد که به‌عنوان کلید و مقدار استفاده شوند. هش‌مپ توابع درج و بازیابی سریع دارد و برای مثال در انجام شمارش فراوانی، ذخیره‌ی روابط و غیره بسیار مفید است. هش‌مپ همچنین API `entry` قدرتمند را ارائه می‌دهد که استفاده از آن را راحت می‌کند.
