# مقدمه

## بازگشت

توابع بازگشتی توابعی هستند که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید دست‌کم یک «حالت پایه» و دست‌کم یک «حالت بازگشتی» داشته باشد.

«حالت پایه» مقداری را برمی‌گرداند بدون اینکه تابع را دوباره فراخوانی کند. «حالت بازگشتی» تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت پیدا کند.

بسیار پیش می‌آید که هر حالت در «بند تابع» خودش نوشته می‌شود.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
