# درباره

یک «بافر `String`» روشی کارآمد برای ساختن یک رشته‌ی بزرگ با افزودن عناصر کوچک به هم است. برخلاف `String`، یک نمونه از `StringBuf` تغییرناپذیر نیست، به این معنا که می‌توان آن را به‌عنوان آرگومان به توابعی داد که با افزودن مقادیر بیشتر آن را تغییر می‌دهند.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
