# مقدمه

شیءها می‌توانند با تعیین «متغیرهای نمونه» وضعیت خودشان را نگه دارند. متغیر نمونه با گذاشتن `@` پیش از اسم یک متغیر ساخته می‌شود.

```ruby
@name = 2
```

شیءها معمولاً وضعیت اولیه‌ی خود را در متد `initialize` تعیین می‌کنند، متدی که وقتی `new` را روی یک کلاس فراخوانی می‌کنید، به‌طور خودکار فراخوانی می‌شود.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

متد `initialize` می‌تواند آرگومان هم بگیرد تا هر نمونه بتواند با یک وضعیت دلخواه شروع کند:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

متغیرهای نمونه را خصوصی در نظر بگیرید، طوری که خواندن و نوشتن از بیرون به آن‌ها دسترسی نداشته باشد. برای خواندن و تعیین متغیرهای نمونه باید از متدهای نمونه استفاده کنید:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
