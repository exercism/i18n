# مقدمه

متد تابعی است که یک آرگومان خاص به اسم «گیرنده» دارد.
گیرنده در فهرست آرگومان‌های خودش، بین کلیدواژه‌ی `func` و اسم متد ظاهر می‌شود.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

شما فقط می‌توانید متدی را با گیرنده‌ای تعریف کنید که نوعش در همان «پکیجی» تعریف شده باشد که متد در آن قرار دارد.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

متدی که روی ساختار تعریف شده را می‌توان با نشانه‌گذاری نقطه‌ای فراخوانی کرد.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

به نحوه‌ی فراخوانی متد `Greetings()` روی نمونه‌ی `Person` به اسم `p` توجه کنید.
این دقیقاً مثل همان روشی است که در یک زبان برنامه‌نویسی شیءگرا متدها را فراخوانی می‌کنید.

یادتان باشد: متد فقط یک تابع با آرگومان گیرنده است.
متدها به جلوگیری از تضاد نام‌ها کمک می‌کنند. چون متد به نوع گیرنده‌ی مشخصی گره خورده است، می‌توانید اسم متد یکسانی روی نوع‌های مختلف داشته باشید.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

دو نوع گیرنده وجود دارد: گیرنده‌ی «مقداری» و گیرنده‌ی «اشاره‌گر».

همه‌ی متدهایی که تا اینجا دیده‌ایم گیرنده‌ی مقداری دارند، یعنی کپی‌ای از مقداری را دریافت می‌کنند که به متد پاس داده شده است. به این معنا که هر تغییری که داخل متد روی گیرنده انجام شود، برای فراخواننده قابل مشاهده نیست.

می‌توانید متدهایی با گیرنده‌ی اشاره‌گر تعریف کنید تا مقداری را که گیرنده به آن اشاره می‌کند تغییر دهید.
این کار با گذاشتن یک `*` پیش از اسم نوع انجام می‌شود.
برای مثال برای نوع `rect`، گیرنده‌ی اشاره‌گر به‌صورت `*rect` تعریف می‌شود.
چنین تغییراتی برای فراخواننده‌ی متد هم قابل مشاهده هستند.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
