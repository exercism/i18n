# مقدمه

عبارت `let` برای ایجاد یک دامنه محلی به کار می‌رود و در چند موقعیت مفید است:

- برای ساده‌سازی عبارات
- برای نام‌گذاری نتایج عبارات میانی
- برای تقسیم یک عبارت به بخش‌های کوچک‌تر در صورت بزرگ شدن

شما می‌توانید بیشتر کارها را درون یک عبارت `let` انجام دهید، از جمله «تخریب ساختار» (جزئیات بیشتر در این مورد در تمرین‌های بعدی)، اما امکان تعریف یک «نوع سفارشی» یا «نام مستعار نوع» جدید وجود ندارد.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
