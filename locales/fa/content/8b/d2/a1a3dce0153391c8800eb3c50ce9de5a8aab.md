# مقدمه

در Elixir، برای انتخاب یک عنصر تصادفی از یک ساختار داده‌ی قابل شمارش (مثلاً لیست، بازه)، از `Enum.random` استفاده می‌کنیم. این تابع یک عنصر را انتخاب می‌کند و احتمال انتخاب هر عنصر برابر است.

Elixir توابع خود را برای انتخاب یک عدد اعشاری تصادفی ندارد. برای این کار، باید مستقیماً از Erlang استفاده کنیم.
