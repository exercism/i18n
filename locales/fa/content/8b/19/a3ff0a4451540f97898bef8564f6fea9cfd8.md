# راهنمایی‌ها

## 1. دریافت پیام از یک خط لاگ

- متنی را که بعد از _اولین_ دونقطه می‌آید استخراج کنید.
  - می‌توانید از `index/1` و نحوه‌ی نگارش برش استفاده کنید.
  - یا استفاده از توابع عبارت باقاعده را بررسی کنید.
- از تابع `trim` که در اختیارتان قرار داده شده استفاده کنید.

## 2. دریافت سطح لاگ از یک خط لاگ

- متن داخل اولین جفت کروشه را استخراج کنید.
- نتیجه را با حروف کوچک خروجی بدهید.

## 3. قالب‌بندی مجدد یک خط لاگ

- از توابع موجود دوباره استفاده کنید.
- دو روش برای این کار، استفاده از درج مقدار در رشته یا به هم چسباندن رشته‌ها است.
