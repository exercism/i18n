# مقدمه

## بازگشت

توابع بازگشتی توابعی هستند که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید حداقل یک _حالت پایه_ و حداقل یک _حالت بازگشتی_ داشته باشد.

یک _حالت پایه_ بدون فراخوانی دوباره‌ی تابع، یک مقدار برمی‌گرداند.
یک _حالت بازگشتی_ تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت کند.

در Elm، توابع بازگشتی معمولاً با استفاده از «تطبیق الگو» همراه با عبارت‌های `case` یا چند بند تابع تعریف می‌شوند.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### حلقه از طریق بازگشت

به دلیل «تغییرناپذیری»، حلقه در Elm به شکلی متفاوت از زبان‌های امری نوشته می‌شود.
برای مثال، حلقه معمولاً به این شکل است:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

در یک زبان تابعی مانند Elm، تغییر دادن متغیرها ممکن نیست.
بنابراین، حلقه باید با استفاده از بازگشت پیاده‌سازی شود.

معادل حلقه‌ی `for` در Elm چیزی شبیه این می‌شود:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

در عمل، پیمایش لیست‌ها و سایر ساختارهای داده در Elm اغلب با استفاده از توابعی از ماژول `List` انجام می‌شود، مانند `List.map`، `List.filter` و `List.foldl`.
این توابع در پشت صحنه با استفاده از بازگشت پیاده‌سازی شده‌اند.
