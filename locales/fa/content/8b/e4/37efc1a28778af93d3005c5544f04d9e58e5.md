# Debug

وقتی یک Test شکست می‌خورد، پیامی نمایش داده می‌شود که توضیح می‌دهد چه چیزی اشتباه پیش رفته و برای کدام ورودی. همچنین می‌توانید از این موضوع استفاده کنید که هر [خروجی کنسول][programiz.com-basic-input-output] نیز نمایش داده می‌شود. می‌توانید با استفاده از این دستور در کنسول بنویسید:

```csharp
Console.WriteLine("Debug message");
```
