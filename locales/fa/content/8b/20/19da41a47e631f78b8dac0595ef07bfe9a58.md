# دستورالعمل‌های مخصوص SQLite

ستون **result** باید شامل یک شیءِ کدشده با JSON از اشیاء باشد، که هر واژه در آن به عنوان کلید و تعداد به صورت عدد صحیح قرار می‌گیرد.

برای نمونه، به جمله‌ی بالا توجه کنید: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
**result** برای این ورودی باید به این شکل باشد:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## طرح جدول

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
