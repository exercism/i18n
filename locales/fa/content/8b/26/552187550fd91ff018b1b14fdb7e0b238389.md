# دستورالعمل‌ها

پس از یک بازبینی امنیتی اخیر، از شما خواسته شده است که فایل‌های لاگ آرشیوشده‌ی سازمان را پاک‌سازی کنید.

## 1. شناسایی خطوط لاگ به‌هم‌ریخته

لازم است تصوری داشته باشید از اینکه چند خط لاگ در آرشیو شما با استانداردهای کنونی مطابقت نمی‌کند.
شما بر این باورید که یک آزمون ساده نشان می‌دهد آیا یک خط لاگ معتبر است یا نه.
برای اینکه خطی معتبر به شمار بیاید، باید با یکی از رشته‌های زیر شروع شود:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

تابع `is_valid_line` را طوری پیاده‌سازی کنید که اگر خط لاگ معتبر بود، `True` را برگرداند.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. تقسیم خط لاگ

کمی پس از شروع پروژه‌ی تجزیه‌ی لاگ متوجه می‌شوید که لاگ‌های یکی از برنامه‌ها مانند بقیه به خطوط تقسیم نشده‌اند. در این پروژه، آنچه باید خطوط جداگانه باشد، در عوض در یک خط واحد قرار دارد و با فلش‌های عجیب‌وغریبی مانند `<--->` یا `<*~*~>` به هم وصل شده است.

در واقع، هر رشته‌ای که اولین نویسه‌اش `<`، آخرین نویسه‌اش `>` و در میان آن‌ها صفر یا چند نویسه از نویسه‌های `~`، `*`، `=` و `-` باشد، می‌تواند به عنوان جداکننده در لاگ‌های این پروژه به کار برود.

تابع `split_line` را پیاده‌سازی کنید که یک خط می‌گیرد و فهرستی از رشته‌ها برمی‌گرداند.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. برچسب‌گذاری خطوط با اسم کاربران

متوجه شده‌اید که برخی از خطوط لاگ جمله‌هایی دارند که به کاربران اشاره می‌کنند.
این جمله‌ها همیشه رشته‌ی `"User"` را دارند که پس از آن یک یا چند نویسه‌ی فاصله و سپس اسم یک کاربر می‌آید.
تصمیم می‌گیرید چنین خطوطی را برچسب بزنید.

تابع `tag_with_user_name` را پیاده‌سازی کنید که خطوط لاگ را پردازش می‌کند:

- خطوطی که رشته‌ی `"User"` را ندارند، بدون تغییر می‌مانند.
- برای خطوطی که رشته‌ی `"User"` را دارند، `[USER]` و سپس اسم کاربر را به ابتدای خط اضافه کنید.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

می‌توانید فرض کنید که:

- هر بار که رشته‌ی `"User"` می‌آید، پس از آن یک یا چند نویسه‌ی فاصله و سپس اسم کاربر قرار دارد.
- در هر خط حداکثر یک بار رشته‌ی `"User"` می‌آید.
- اسم‌های کاربر رشته‌هایی ناتهی هستند که فاصله ندارند.
