# مقدمه

در Gleam دو نوع مختلف عدد وجود دارد: عدد صحیح و عدد اعشاری.

عدد صحیح، عددی است بدون بخش اعشاری.

```gleam
let integer = 3
// -> 3
```

برای خوانایی بیشتر می‌توانید زیرخط هم به اعداد صحیح اضافه کنید.

```gleam
1_000_000 // One million
```

Gleam چندین عملگر دارد که با اعداد صحیح کار می‌کنند.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
