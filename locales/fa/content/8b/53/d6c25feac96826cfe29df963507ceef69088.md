# مقدمه

## نوع شمارشی

یک _نوع شمارشی_ یک نوع داده‌ی ویژه است که اجازه می‌دهد یک متغیر مجموعه‌ای از ثابت‌های از پیش تعریف‌شده باشد.
متغیر باید با یکی از مقادیری که برایش از پیش تعریف شده‌اند برابر باشد.
نمونه‌های رایج شامل جهت‌های قطب‌نما (مقادیر `NORTH`، `SOUTH`، `EAST` و `WEST`) و روزهای هفته است.

چون ثابت هستند، اسم فیلدهای یک نوع شمارشی با حروف بزرگ نوشته می‌شود.

### تعریف یک نوع شمارشی

در زبان برنامه‌نویسی Java، یک نوع شمارشی را با استفاده از کلیدواژه‌ی `enum` تعریف می‌کنید.
برای مثال، یک نوع شمارشی روزهای هفته را این‌گونه تعریف می‌کنید:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

هر زمان که بخواهید مجموعه‌ی مشخصی از ثابت‌ها را نمایش دهید، باید از نوع شمارشی استفاده کنید.
این شامل انواع شمارشی طبیعی مانند سیاره‌های منظومه‌ی شمسی و مجموعه‌داده‌هایی است که همه‌ی مقادیر ممکنشان را در زمان کامپایل می‌دانید؛ برای مثال گزینه‌های یک منو، پرچم‌های خط فرمان و غیره.

### استفاده از یک نوع شمارشی

این کد نشان می‌دهد چطور از نوع شمارشی `DayOfWeek` که بالا تعریف شد استفاده کنید:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### افزودن متد و فیلد

انواع شمارشی زبان برنامه‌نویسی Java بسیار قدرتمندتر از همتایانشان در زبان‌های دیگر هستند.
اعلان `enum` یک _کلاس_ را تعریف می‌کند (که _نوع شمارشی_ نامیده می‌شود).
بدنه‌ی کلاس شمارشی می‌تواند شامل متدها و فیلدهای دیگر باشد:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

فراخوانی متد `getNumberOfStars` روی یکی از اعضای نوع شمارشی `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
