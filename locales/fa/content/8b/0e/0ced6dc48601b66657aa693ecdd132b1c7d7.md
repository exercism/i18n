# دستورالعمل‌ها

شما در حال توسعه‌ی بازی جدید و بسیار محبوب **Crystal Hunter** هستید.
در این بازی، شما شخصیتی هستید که این‌طرف و آن‌طرف حرکت می‌کند و کریستال‌ها را جمع می‌کند.
بازیکن با برداشتن همه‌ی کریستال‌ها برنده می‌شود.
اگر بازیکن با یک راهزن تماس پیدا کند، همه‌ی کریستال‌هایش را از دست می‌دهد و بازی را می‌بازد.
یک استثنا هم برای این قاعده وجود دارد: بازیکن می‌تواند یک پاورآپ فعال داشته باشد که او را برای راهزن‌ها نامرئی می‌کند.

هدف شما نوشتن قواعدی است که در بازی به کار می‌روند.

## 1. تعیین کنید که شخصیت امتیاز جایزه می‌گیرد یا نه

در بازی، اگر شخصیت در حالی که پاورآپ دارد با یک راهزن تماس پیدا کند، امتیاز جایزه می‌گیرد.

متد `Rules#bonus_points?` را تعریف کنید که دو آرگومان می‌گیرد (اینکه شخصیت پاورآپ فعال دارد و اینکه شخصیت با یک راهزن تماس دارد) و یک مقدار منطقی برمی‌گرداند که مشخص می‌کند آیا شخصیت امتیاز جایزه می‌گیرد یا نه.
این متد باید فقط زمانی `true` را برگرداند که شخصیت پاورآپ فعال داشته باشد و با یک راهزن تماس داشته باشد و در غیر این صورت `false` را برگرداند.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. تعیین کنید که شخصیت امتیاز کسب می‌کند یا نه

بازیکن در این بازی وقتی کریستالی یا پاورآپی برمی‌دارد، امتیاز می‌گیرد.

متد `Rules#score?` را تعریف کنید که دو آرگومان می‌گیرد (اینکه شخصیت با یک پاورآپ تماس دارد و اینکه شخصیت با یک کریستال تماس دارد) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد شخصیت امتیاز گرفته است یا نه.
این متد باید اگر شخصیت با یک پاورآپ یا یک کریستال تماس داشته باشد `true` را برگرداند و در غیر این صورت `false` را برگرداند.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. تعیین کنید که شخصیت می‌بازد یا نه

متد `Rules#lose?` را تعریف کنید که دو آرگومان می‌گیرد (اینکه شخصیت پاورآپ فعال دارد و اینکه شخصیت با یک راهزن تماس دارد) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد شخصیت می‌بازد یا نه.
این متد باید اگر شخصیت با یک راهزن تماس داشته باشد و پاورآپ فعال نداشته باشد `true` را برگرداند و در غیر این صورت `false` را برگرداند.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. تعیین کنید که شخصیت برنده می‌شود یا نه

متد `Rules#win?` را تعریف کنید که سه آرگومان می‌گیرد (اینکه شخصیت همه‌ی کریستال‌ها را برداشته است، اینکه شخصیت پاورآپ فعال دارد و اینکه شخصیت با یک راهزن تماس دارد) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد شخصیت برنده می‌شود یا نه.
این متد باید اگر شخصیت همه‌ی کریستال‌ها را جمع کرده باشد و بر اساس آرگومان‌های تعریف‌شده در بخش ۳ باخته نباشد `true` را برگرداند و در غیر این صورت `false` را برگرداند.

```crystal
Rules.new.win?(false, true, false)
# => false
```
