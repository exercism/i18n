# دستورالعمل‌ها

شما در حال نوشتن یک سیستم نهفته برای یک دستگاه نوبت‌دهی هستید. مدل بسیار ساده‌ای است. می‌تواند شماره‌های متوالی بدهد و گزارش کند که آخرین شماره‌ی داده‌شده چه بوده است.

## 1. دستگاه را راه‌اندازی کنید

تابع `start/0` را پیاده‌سازی کنید. باید یک فرایند جدید ایجاد کند و PID آن فرایند را برگرداند. فرایند جدید فعلاً لازم نیست کاری انجام دهد.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

توجه کنید که هر بار این کد را اجرا می‌کنید، ممکن است PID متفاوت باشد.

## 2. وضعیت دستگاه را گزارش دهید

دستگاه را طوری تغییر دهید که فرایند تازه ایجادشده، با وضعیت اولیه‌ی `0`، آماده‌ی دریافت پیام‌ها باشد (یک _حلقه‌ی دریافت_ راه بیندازد). باید بتواند پیام‌های `{:report_state, sender_pid}` را دریافت کند. در پاسخ به این پیام‌ها، باید وضعیت فعلی خود (آخرین شماره‌ی بلیت داده‌شده) را به `sender_pid` بفرستد و سپس منتظر پیام‌های بیشتر بماند.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. شماره بدهید

دستگاه را طوری تغییر دهید که بتواند پیام‌های `{:take_a_number, sender_pid}` را دریافت کند. باید وضعیتش را ۱ واحد افزایش دهد، وضعیت جدید را به `sender_pid` بفرستد و سپس منتظر پیام‌های بیشتر بماند.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. دستگاه را متوقف کنید

دستگاه را طوری تغییر دهید که بتواند پیام `:stop` را دریافت کند. باید انتظار برای پیام‌های بیشتر را متوقف کند.

## 5. پیام‌های غیرمنتظره را نادیده بگیرید

دستگاه را طوری تغییر دهید که وقتی پیامی غیرمنتظره دریافت می‌کند، آن را نادیده بگیرد و همچنان منتظر پیام‌های بیشتر بماند.
