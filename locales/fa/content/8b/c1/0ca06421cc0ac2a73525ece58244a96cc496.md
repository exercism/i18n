# مقدمه

برخلاف بسیاری از زبان‌های دیگر، در JavaScript دو موجودیت متفاوت وجود دارد که نبودِ یک مقدار (معنادار) را نشان می‌دهند: یکی `null` و دیگری `undefined`.

## Null

مقدار اولیه‌ی `null` به‌عنوان یک «مقدار خالی» عمدی برای متغیرهایی از هر نوع به کار می‌رود.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

می‌توانید با استفاده از [«عملگر تساوی سخت‌گیرانه»][mdn-strict-equality] `===` بررسی کنید که آیا یک متغیر `null` است یا نه.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> متغیری که مقداری به آن اختصاص داده نشده باشد، از نوع `undefined` است.<sup>۱</sup>

یعنی در حالی که `null` یک مقدار خالی (اما همچنان یک مقدار) را نشان می‌دهد، `undefined` نشان‌دهنده‌ی نبود کامل مقدار است. 🤯

`undefined` در موقعیت‌های مختلفی ظاهر می‌شود.

- اگر متغیری بدون مقدار (مقداردهی اولیه) اعلام شود، `undefined` است.
- اگر بخواهید به مقدار یک کلید ناموجود در یک شیء دسترسی پیدا کنید، `undefined` دریافت می‌کنید.
- اگر یک تابع مقداری برنگرداند، نتیجه `undefined` است.
- اگر آرگومانی به یک تابع پاس داده نشود، `undefined` است، مگر اینکه آن آرگومان مقدار پیش‌فرض داشته باشد.

```javascript
let name;
console.log(name);
// => undefined
```

می‌توانید با استفاده از عملگر تساوی سخت‌گیرانه‌ی `===` بررسی کنید که آیا یک متغیر `undefined` است یا نه.

```javascript
let name;

name === undefined;
// => true
```

## زنجیره‌سازی اختیاری

اگر بخواهید مقدار تودرتویی را در یک شیء بازیابی کنید اما کلید والد وجود نداشته باشد، JavaScript یک خطا پرتاب می‌کند.
برای اینکه به‌سادگی از این وضعیت جلوگیری شود، «زنجیره‌سازی اختیاری» در سال ۲۰۲۰ به مشخصات زبان اضافه شد.
با عملگر زنجیره‌سازی اختیاری `?.` می‌توانید مطمئن شوید که JavaScript فقط وقتی تلاش می‌کند به کلید تودرتو دسترسی پیدا کند که والد `null` یا `undefined` نباشد.
در غیر این صورت، `undefined` برگردانده می‌شود.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## ادغام تهی‌گونه

موقعیت‌هایی وجود دارد که می‌خواهید یک مقدار پیش‌فرض اعمال کنید، در صورتی که متغیر `null` یا `undefined` باشد (و فقط در همین حالت).
برای این کار، عملگر «ادغام تهی‌گونه» `??` در سال ۲۰۲۰ معرفی شد.
این عملگر تنها زمانی عملوند سمت راست را برمی‌گرداند که عملوند سمت چپ `null` یا `undefined` باشد.
در غیر این صورت، عملوند سمت چپ برگردانده می‌شود.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
