# Tests

ما در وب‌سایت خود از [pytest][pytest: Getting Started Guide] به عنوان ابزار اجرای Tests استفاده می‌کنیم.
اگر می‌خواهید Tests مربوط به مسیر Python را به‌صورت محلی اجرا کنید، لازم است `pytest` را روی دستگاه توسعه‌ی خود نصب کنید.
همچنین بهتر است افزونه‌های زیر را هم برای `pytest` نصب کنید:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

اطلاعات بیشتر را می‌توانید در [راهنمای Test در Python][Python track tests page] در وب‌سایت ما پیدا کنید.


### اجرای Tests

برای اجرای Tests موجود، با استفاده از `cd` در ترمینال خود به پوشه‌ای بروید که تمرین در آن ذخیره شده است (_در دستورهای زیر `<exercise-folder-location>` را با مسیر خودتان جایگزین کنید_).
فایل‌های Test معمولاً به `_test.py` ختم می‌شوند و همان Testsهایی هستند که هنگام بارگذاری یک راه‌حل در وب‌سایت اجرا می‌شوند.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

سپس، دستور `pytest` را در ترمینال خود اجرا کنید و `<exercise_test.py>` را با اسم فایل Test جایگزین کنید:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### گزینه‌های رایج
- `-o` : بازنویسی `pytest.ini` پیش‌فرض (_می‌توانید از این گزینه برای جلوگیری از هشدارهای marker استفاده کنید_)
- `-v` : فعال کردن خروجی کامل.
- `-x` : توقف اجرای Tests هنگام نخستین مورد ناموفق.
- `--ff` : اجرای موارد ناموفق Test قبلی پیش از اجرای سایر موارد Test.

برای گزینه‌های بیشتر، از `python3 -m pytest -h` یا `py -m pytest -h` استفاده کنید.


### رفع هشدارها

اگر هنگام فراخوانی `pytest` از `pytest -o markers=task` استفاده نکنید، ممکن است برای Testsهایی که از نحوه‌ی نگارش جدید ما استفاده می‌کنند هشدار `PytestUnknownMarkWarning` دریافت کنید:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

برای اینکه برای هر Test که اجرا می‌کنید لازم نباشد `pytest -o markers=task` را تایپ کنید، می‌توانید از یک فایل پیکربندی `pytest.ini` استفاده کنید.
ما یکی از این فایل‌ها را ساخته‌ایم که می‌توانید آن را از سطح بالای پوشه‌ی مسیر Python دانلود کنید: [pytest.ini][pytest.ini].

همچنین می‌توانید فایل `pytest.ini` خودتان را با محتوای زیر بسازید:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

اگر فایل `pytest.ini` را در پوشه‌ی _root_ یا _working_ تمرین‌های مسیر Python خود قرار دهید، markها ثبت می‌شوند و هشدارها متوقف می‌شوند.
اطلاعات بیشتر درباره‌ی pytest marks را می‌توانید در مستندات `pytest` درباره‌ی [mark کردن توابع Test][pytest: marking test functions with attributes] و مستندات `pytest` درباره‌ی [کار با markerهای سفارشی][pytest: working with custom markers] پیدا کنید.

اطلاعات درباره‌ی سفارشی‌سازی پیکربندی‌های `pytest` را می‌توانید در مستندات `pytest` درباره‌ی [قالب‌های فایل پیکربندی][pytest: configuration file formats] پیدا کنید.
