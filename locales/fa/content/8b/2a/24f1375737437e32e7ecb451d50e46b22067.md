# مقدمه

«فیلتر کردن» فرایندی است که طی آن دنباله‌ای تازه از دل دنباله‌ای دیگر ساخته می‌شود، با کپی کردن همه‌ی عناصر آن به‌جز برخی عناصر مشخص.
اینکه کدام عناصر در دنباله‌ی تازه قرار بگیرند را می‌توان با یک «تابع محمول» (تابعی که به یک «مقدار منطقی» ارزیابی می‌شود) تعیین کرد، یا با برابری با یک شیء مشخص.

## حذف با محمول

`remove-if` تابعی است که یک تابع محمول و یک دنباله را به‌عنوان آرگومان می‌گیرد و دنباله‌ای برمی‌گرداند که فقط شامل عناصری است که محمول برایشان «غلط» ارزیابی شده است.
به بیان دیگر، این تابع همه‌ی عناصری را که محمول برایشان «درست» ارزیابی می‌شود از دنباله «حذف» می‌کند. با این حال، توجه کنید که این تابع دنباله‌ی اصلی را تغییر نمی‌دهد!
در عوض، دنباله‌ای تازه را بدون آن عناصر برمی‌گرداند. اگر محمول برای همه‌ی مقادیر «درست» بوده باشد، دنباله‌ای خالی برگردانده می‌شود.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## حذف یک عنصر مشخص

اگر بخواهید عنصر مشخصی را از یک دنباله حذف کنید، می‌توانید از `remove` استفاده کنید که عنصر موردنظر برای حذف و یک دنباله را می‌گیرد.
همه‌ی مقادیری از دنباله که با عنصر مورد حذف برابر نیستند برگردانده می‌شوند.
توجه: برابری به‌طور پیش‌فرض با `eql` که همان [محمول برابری عمومی][concept-equality] است، بررسی می‌شود.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
