# دستورالعمل‌ها

وظیفه‌ی شما ساختن یک بررسی‌کننده‌ی رمز عبور است.
بررسی‌کننده‌ی رمز عبور، رمز عبور پیشنهادی کاربر را اعتبارسنجی می‌کند تا مطمئن شود که آن رمز مجموعه الزاماتی را برآورده می‌کند که سازمان کنترل‌کننده‌ی دسترسی به منبع موردنظر تعریف کرده است.

برای این تمرین، الزامات رمز عبور عبارت‌اند از:
* باید ۱۲ کاراکتر یا بیشتر داشته باشد
* باید حداقل یک حرف بزرگ داشته باشد
* باید حداقل یک حرف کوچک داشته باشد
* باید حداقل یک رقم داشته باشد
* باید حداقل یک نماد از مجموعه‌ی !@#$%^&* داشته باشد

راه‌حل شما باید از یک `Result` برای کپسوله‌کردن وضعیت موفقیت یا شکست استفاده کند.
در حالت موفقیت، `Result` باید رمز عبور اعتبارسنجی‌شده را به‌صورت یک رشته منتقل کند.
در حالت شکست، `Result` باید قاعده‌ای را که نقض شده است منتقل کند.

~~~~exercism/note
برای این تمرین، بررسی‌کننده‌ی رمز عبور بسیار ساده خواهد بود؛ فقط نشان می‌دهد که یک قاعده‌ی واحد نقض شده است.
تمرین بعدی یک بررسی‌کننده‌ی رمز عبور واقع‌گرایانه‌تر را بررسی می‌کند که می‌تواند نشان دهد چند قاعده همزمان نقض شده‌اند.
~~~~

## 1. پیاده‌سازی تابع `checkPassword`

تابع `checkPassword` رمز عبور داده‌شده را با قواعد یادشده بررسی می‌کند. در صورت شکست، قاعد‌ه‌ای را که نقض شده است با کپسوله‌کردن یکی از مقادیر `PasswordRule` در مقدار نتیجه نشان می‌دهد.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. پیاده‌سازی تابع ``getStatusMessage`

تابع `getStatusMessage` رشته‌ای را برمی‌گرداند که حاوی پیامی خوانا برای انسان است و معنای نتیجه‌ی برگشتی از `checkPassword` را نشان می‌دهد.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
