# درباره

ABAP چندین نوع عددی دارد. رایج‌ترین آن‌ها برای تمرین‌های مقدماتی کوچک عبارت‌اند از `i` برای مقادیر صحیح و `p` برای مقادیر «اعشاری بسته‌بندی‌شده».

از `i` استفاده کنید وقتی مقدار باید یک عدد صحیح باشد، مثلاً تعداد روزها. از یک نوع اعشاری استفاده کنید وقتی مقدار می‌تواند ارقام اعشاری داشته باشد، مثلاً نرخ ساعتی.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

وقتی تعداد ثابتی از ارقام اعشاری لازم است، اغلب از اعداد بسته‌بندی‌شده در برنامه‌های کاربردی تجاری استفاده می‌شود. ABAP همچنین اعداد شناور اعشاری (`decfloat16` و `decfloat34`) و اعداد شناور دودویی (`f`) دارد. اعداد شناور دودویی می‌توانند برای محاسبات علمی مفید باشند، اما پیش‌فرض خوبی برای مثال‌های شبیه پول نیستند، زیرا بسیاری از کسرهای اعشاری را نمی‌توان دقیق نمایش داد.
