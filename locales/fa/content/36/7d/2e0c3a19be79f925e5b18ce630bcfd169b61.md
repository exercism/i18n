# Tests

## اجرای تست‌ها

برای اجرای تست‌ها، فرمان زیر را اجرا کنید:

```bash
call {slug}Test.bat
```

## حل تمرین

حل کردن یک تمرین یعنی کاری کنید که همه‌ی تست‌هایش پاس شوند.
وقتی همه‌ی تست‌ها پاس شدند، تمرین را حل کرده‌اید!

برای اینکه راحت‌تر شروع کنید، هر تمرین با یک فایل پیاده‌سازی اولیه همراه است.
می‌توانید از این فایل به‌عنوان نقطه‌ی شروع برای ساختن راه‌حل خودتان استفاده کنید.
اگر فکر می‌کنید کار درستی است، راحت این فایل را حذف کنید یا تغییر دهید.
