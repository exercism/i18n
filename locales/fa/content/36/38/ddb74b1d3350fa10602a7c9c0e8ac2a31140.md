# دستورالعمل‌ها

یک عدد سه‌گانه را که به‌صورت رشته نمایش داده می‌شود (مثلاً «102012») با استفاده از اصول اولیه به معادل ده‌دهی‌اش تبدیل کنید.

برنامه باید رشته‌هایی را که یک عدد سه‌گانه‌ی نامعتبر را مشخص می‌کنند، معادل مقدار ۰ در نظر بگیرد.

اعداد سه‌گانه شامل سه نماد هستند: 0، 1 و 2.

آخرین مرتبه در یک عدد سه‌گانه، مرتبه‌ی یک‌هاست. مرتبه‌ی دوم از آخر، مرتبه‌ی سه‌هاست و مرتبه‌ی سوم از آخر، مرتبه‌ی نه‌هاست. به همین ترتیب ادامه می‌یابد.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

اگر زبان برنامه‌نویسی شما روشی در کتابخانه‌ی استاندارد برای انجام این تبدیل ارائه می‌دهد، فرض کنید وجود ندارد و خودتان آن را پیاده‌سازی کنید.
