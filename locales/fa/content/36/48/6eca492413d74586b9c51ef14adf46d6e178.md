# درباره

نوع `Maybe` راه‌حل زبان Elm برای مقادیر اختیاری است. به همین دلیل در امضای نوع شمار زیادی از توابع اصلی Elm حضور دارد و درک آن ضروری است.

## تعریف و متغیر نوع

نوع `Maybe` به شکل زیر تعریف می‌شود:

```elm
type Maybe a = Nothing | Just a
```

این در اصطلاحات Elm به تعریف «نوع سفارشی» معروف است. انواع سفارشی با جزئیات در مفهوم دیگری از این مسیر معرفی می‌شوند، اما برای درک خود `Maybe` به آن نیازی نداریم. `a` در `Maybe a` و `Just a` نماینده‌ی یک «متغیر نوع» است، یعنی می‌تواند هر نوعی باشد، مثل `Int`، `Bool` یا `String`. بر همین اساس، `Maybe String` متغیری است که به‌صورت اختیاری یک `String` نگه می‌دارد، در حالی که `Maybe Int` به‌صورت اختیاری یک `Int` نگه می‌دارد.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

خط عمودی `|` در تعریف نوع `Maybe` به معنای «یا» است. این نشان می‌دهد که یک مقدار از این نوع یا می‌تواند `Nothing` باشد یا `Just` مقداری از نوع `a`. حالا فرض کنید که آن شخص اسم و سن را پر نکرده بود. در آن صورت به نتیجه‌ی زیر می‌رسیدیم.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## خواندن محتوای یک مقدار `Maybe`

خواندن محتوای یک مقدار `Maybe` از طریق «تطبیق الگو» انجام می‌شود. تطبیق الگو هم با جزئیات بیشتری در مفهوم دیگری معرفی می‌شود، پس فقط روی این تمرکز می‌کنیم که تطبیق الگو روی یک `Maybe` چگونه کار می‌کند.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

هر بار که از یک مقدار `Maybe` استفاده می‌کنید، کامپایلر Elm بررسی می‌کند که کد شما همه‌ی حالت‌ها را پوشش می‌دهد؛ بنابراین هرگز نمی‌توانید یک `Maybe` را تطبیق الگو کنید و فقط حالتی را پوشش دهید که `Just someValue` وجود دارد. این ممکن است در ابتدا آزاردهنده به نظر برسد، اما یکی از بزرگ‌ترین نقاط قوت زبان Elm است. این کار از صدها باگ جلوگیری می‌کند و بازآرایی با راهنمایی کامپایلر را به تجربه‌ای بی‌دغدغه و لذت‌بخش تبدیل می‌کند.

## توابع بیشتری برای دستکاری `Maybe`

توابع مفید دیگری هم در ماژول `Maybe` برای دستکاری انواع `Maybe` وجود دارد.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
