# پیوست دستورالعمل‌ها

## ثبات

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | --------------------------------------- |
| `$a0`    | ورودی     | آدرس | رشته‌ی پایان‌بندی‌شده با `null` از کاراکترهای سه‌گانه |
| `$v0`    | خروجی    | عدد صحیح | مقدار ده‌دهی رشته‌ی ورودی           |
| `$t0-9`  | موقت | هر نوعی     | برای ذخیره‌سازی موقت استفاده می‌شود              |
