# مقدمه

اگر بتوان نوع پارامترها را استنباط کرد، Swift همچنین اجازه می‌دهد نام پارامترها و کلیدواژه‌ی `in` از تعریف «کلوژر» حذف شوند. در عوض می‌توان با یک روش نوشتن اختصاری ویژه به پارامترها اشاره کرد که در آن `$0` به پارامتر اول اشاره می‌کند، `$1` به پارامتر دوم و به همین ترتیب.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
