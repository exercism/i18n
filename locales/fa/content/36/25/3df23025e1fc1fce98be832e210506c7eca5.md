# دستورالعمل

در این تمرین، شما همراه با بهترین دوستانتان یک بازی نقش‌آفرینی به نام «Wizard and Warriors» انجام می‌دهید.
شما «استاد بازی» هستید، همان کسی که وظیفه دارد دنیای بازی را برای بازیکنان زنده کند.
یک جنبه‌ی کلیدی این کار، توصیف بازی برای بازیکنان است: وضعیت یک شخصیت چیست، شهری که به آن سفر می‌کنند چه شکلی است و غیره.

پنج وظیفه دارید که در آن‌ها بخش‌هایی از بازی را برای بازیکنان توصیف می‌کنید.

## 1. توصیف یک شخصیت

هر شخصیت یک کلاس، سطح و تعداد امتیاز جان دارد و به این شکل توصیف می‌شود: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.
متد `GameMaster.describe` را پیاده‌سازی کنید که یک `Character` را به عنوان تنها پارامترش می‌گیرد و توصیف آن را برمی‌گرداند.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. توصیف یک مقصد

هر مقصد یک اسم و تعدادی ساکن دارد و به این شکل توصیف می‌شود: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.
متد `GameMaster.describe` را پیاده‌سازی کنید که یک `Destination` را به عنوان تنها پارامترش می‌گیرد و توصیف آن را برمی‌گرداند.

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. توصیف روش سفر

شخصیت‌ها می‌توانند با یکی از دو گزینه به مقصدی سفر کنند:

- پیاده‌روی، به این شکل توصیف می‌شود: `"You're traveling to your destination by walking."`
- سوار بر اسب، به این شکل توصیف می‌شود: `"You're traveling to your destination on horseback."`

متد `GameMaster.describe` را پیاده‌سازی کنید که یک `TravelMethod` را به عنوان تنها پارامترش می‌گیرد و توصیف آن را برمی‌گرداند.

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. توصیف سفر یک شخصیت به یک مقصد

وقتی یک شخصیت به مقصدی سفر می‌کند، این سفر به شکل ترکیبی از توصیف‌های جداگانه توصیف می‌شود: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.
متد `GameMaster.describe` را پیاده‌سازی کنید که یک `Character`، یک `Destination` و یک `TravelMethod` را به عنوان پارامترهایش می‌گیرد و توصیف آن را برمی‌گرداند.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. توصیف سفر یک شخصیت به یک مقصد بدون تعیین روش سفر

در بیشتر موارد، شخصیت‌ها پیاده به مقصد سفر می‌کنند.
برای راحتی کار، بازیکنان می‌توانند روش سفرشان را ذکر نکنند. در این صورت فرض می‌شود که پیاده‌روی روش سفر است.
متد `GameMaster.describe` را پیاده‌سازی کنید که یک `Character` و یک `Destination` را به عنوان پارامترهایش می‌گیرد و توصیف آن را برمی‌گرداند.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
