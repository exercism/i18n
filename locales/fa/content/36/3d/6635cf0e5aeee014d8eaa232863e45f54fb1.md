# دستورالعمل‌ها

در این تمرین قرار است کدی بنویسید که به شما کمک کند از کتاب آشپزی محبوب‌تان یک لازانیای عالی بپزید.

چهار کار پیش رو دارید که همگی به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار پخت در فر را بر حسب دقیقه تعریف کنید

ثابت `OvenTime` را با تعداد دقیقه‌هایی که لازانیا باید در فر بماند تعریف کنید. طبق کتاب آشپزی، زمان مورد انتظار پخت در فر ۴۰ دقیقه است:

```go
OvenTime
// => 40
```

## 2. زمان باقی‌مانده‌ی پخت در فر را بر حسب دقیقه محاسبه کنید

تابع `RemainingOvenTime()` را تعریف کنید که تعداد دقیقه‌هایی را که لازانیا تا این لحظه در فر بوده است به عنوان پارامتر می‌گیرد و بر اساس زمان مورد انتظار پخت در فر که در تمرین قبلی تعریف کردید، برمی‌گرداند که لازانیا چند دقیقه‌ی دیگر باید در فر بماند.

```go
func RemainingOvenTime(actual int) int {
    // TODO
}

RemainingOvenTime(30)
// => 10
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

تابع `PreparationTime` را تعریف کنید که تعداد لایه‌هایی را که به لازانیا اضافه کرده‌اید به عنوان پارامتر می‌گیرد و برمی‌گرداند که چند دقیقه صرف آماده‌سازی لازانیا کرده‌اید، با این فرض که آماده‌سازی هر لایه ۲ دقیقه طول می‌کشد.

```go
func PreparationTime(numberOfLayers int) int {
    // TODO
}

PreparationTime(2)
// => 4
```

## 4. زمان سپری‌شده‌ی کار را بر حسب دقیقه محاسبه کنید

تابع `ElapsedTime` را تعریف کنید که دو پارامتر می‌گیرد: پارامتر اول تعداد لایه‌هایی است که به لازانیا اضافه کرده‌اید و پارامتر دوم تعداد دقیقه‌هایی است که لازانیا در فر بوده است.
تابع باید برگرداند که در مجموع چند دقیقه روی پخت لازانیا کار کرده‌اید؛ این مقدار برابر است با مجموع زمان آماده‌سازی بر حسب دقیقه و زمانی که لازانیا تا این لحظه در فر سپری کرده است.

```go
func ElapsedTime(numberOfLayers, actualMinutesInOven int) int {
    // TODO
}

ElapsedTime(3, 20)
// => 26
```
