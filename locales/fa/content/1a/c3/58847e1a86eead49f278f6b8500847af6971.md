# راهنمایی‌ها

## عمومی

- `MACRO:` در [`macros`][macros] قرار دارد. بلوک‌های سازنده در
  `kernel` (`dup`، `curry`)، `sequences` (`append`، `concat`،
  `<repetition>`، `map`) و `quotations` (`>quotation`) قرار دارند.
- بدنه‌ی یک ماکرو باید **یک «کوتیشن»** را روی پشته باقی بگذارد. اگر
  بدنه‌تان آرایه‌ای از کد تولید می‌کند، کار را با `>quotation` تمام کنید.
- برای بررسی درستی فکرتان، واژه‌های بدنه را روی یک مقدار ثابت در
  listener اجرا کنید و کوتیشنی را که پس گرفته می‌شود ببینید؛ باید همان
  کد خط‌به‌خطی باشد که در خط «compiles to» تمرین آمده است.

## 1. دو بار

- شما `[ A ]` را دریافت می‌کنید و `[ A A ]` را می‌خواهید. یک کپی
  بسازید و آن‌ها را به هم بپیوندید: `dup append`.

## 2. N بار تکرار

- شما `[ A ] n` را دریافت می‌کنید و می‌خواهید `n` کپی به هم پیوسته
  داشته باشید.
- `<repetition>` کپی‌ها را می‌سازد، اما اثرش
  `( length elt -- repetition )` است؛ یعنی تعداد باید در بالای پشته باشد، پس
  اول `swap` را انجام دهید.
- سپس مسطحش کنید و تبدیل کنید: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. ترکیب چند مورد

- آرایه‌ی کوتیشن‌ها را از قبل دریافت می‌کنید؛ فقط باید آن را در یک
  کوتیشن مسطح کنید. `concat >quotation` تمام بدنه است.

## 4. تکرار بازشده

یک دنباله و یک کوتیشن دریافت می‌کنید، مثلاً `{ 10 20 30 } [ + ]`،
و `[ 10 + 20 + 30 + ]` را می‌خواهید. آن را در سه مرحله بسازید.

**یک عنصر.** گنجاندن یک عنصر درون کوتیشن دقیقاً همان کاری است که
`curry` انجام می‌دهد:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**هر عنصر.** می‌خواهید آن را با `map` روی دنباله اعمال کنید، اما
`map` فقط یک ورودی (همان عنصر) به کوتیشن نگاشت می‌دهد، در حالی که
شما هر بار به `[ + ]` هم نیاز دارید. پس اول `[ + ]` را با `curry`
درون کوتیشن نگاشت می‌گنجانید:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` این‌طور خوانده می‌شود که «کوتیشن کوچک `[ curry ]` را
روی پشته بگذار، بعد `[ + ]` را درونش `curry` کن» و نتیجه
`[ [ + ] curry ]` می‌شود. نگاشت آن روی یک عنصر `e` دستور
`e [ + ] curry` را اجرا می‌کند که همان `[ e + ]` است.

**به هم بپیوندید.** همان پایان کار سایر تمرین‌ها:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- کل بدنه: `[ curry ] curry map concat >quotation`.
