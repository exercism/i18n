# Debugging

برای کمک به Debug کردن، می‌توانید از این نکته استفاده کنید که تمام خروجی کنسول ضبط می‌شود و در پنجره‌ی نتایج Test به نمایش درمی‌آید.
هر مقداری را می‌توانید با پاس دادن آن به `@show` چاپ کنید.

`@show` یک عبارت و نتیجه‌اش را نمایش می‌دهد و در همان حال نتیجه‌اش را هم برمی‌گرداند.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

همچنین می‌توانید از [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) یا هر روش دیگری که خروجی را به [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)) می‌نویسد استفاده کنید.
