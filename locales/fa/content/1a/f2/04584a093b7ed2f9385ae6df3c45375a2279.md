# دستورالعمل‌ها

در این تمرین کدی می‌نویسید تا لیست زبان‌های برنامه‌نویسی را که می‌خواهید در Exercism یاد بگیرید، پیگیری کنید.
شش وظیفه دارید و همه‌ی آن‌ها به کار با لیست‌ها مربوط می‌شوند.

## 1. ساختن یک لیست جدید

برای پیگیری زبان‌هایی که می‌خواهید یاد بگیرید، باید یک لیست جدید بسازید.
ثابت `newList` را تعریف کنید که شامل یک لیست جدید و خالی است.

```elm
newList
    --> []
```

## 2. تعریف یک لیست موجود

در حال حاضر، تکه‌کاغذی دارید که زبان‌هایی را که می‌خواهید یاد بگیرید روی آن نوشته شده است: Elm، Clojure و Haskell.
ثابت `existingList` را تعریف کنید تا این لیست را نشان دهد.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. افزودن یک زبان جدید به لیست

همان‌طور که Exercism را کاوش می‌کنید و زبان‌های جالب‌تری پیدا می‌کنید، می‌خواهید آن‌ها را به لیستتان اضافه کنید.
تابع `addLanguage` را پیاده‌سازی کنید تا یک زبان جدید را به ابتدای لیستتان اضافه کند.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. شمردن زبان‌های لیست

شمردن زبان‌ها به‌صورت دستی چندان راحت نیست.
تابع `countLanguages` را پیاده‌سازی کنید تا تعداد زبان‌های روی لیستتان را بشمارد.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. برعکس کردن لیست

یک جا متوجه می‌شوید که لیستتان در واقع برعکس مرتب شده است!
تابع `reverseList` را پیاده‌سازی کنید تا لیستتان را برعکس کند.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. بررسی کنید که لیست هیجان‌انگیز است یا نه

با اینکه همه‌ی زبان‌ها را دوست دارید، Elm جایگاه ویژه‌ای در قلب شما دارد.
به همین دلیل، از یک لیست زبان واقعاً هیجان‌زده می‌شوید اگر:

- اولین عنصر لیست Elm باشد.
- یا دومین عنصر لیست Elm باشد و لیست سه زبان یا کمتر داشته باشد.

تابع `excitingList` را پیاده‌سازی کنید تا بررسی کند که آیا یک لیست زبان هیجان‌انگیز است:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
