# مقدمه

## Switch

یک [دستور switch][switch] به شما امکان می‌دهد یک مقدار را با چندین مقدار منطبق ممکن مقایسه کنید.
این دستور به شما امکان می‌دهد کدی موجزتر از استفاده از چندین دستور `else-if` بنویسید.
یک دستور switch با کلیدواژه‌ی `switch` آغاز می‌شود و پس از آن مقداری می‌آید که باید مقایسه شود.
سپس می‌توانید حالت‌ها را با کلیدواژه‌ی `case` تعریف کنید و پس از آن مقداری می‌آید که باید با آن مقایسه شود.
کلیدواژه‌ی `default` برای تعریف حالت پیش‌فرض به کار می‌رود، یعنی زمانی که هیچ‌یک از حالت‌ها مطابقت نداشته باشند.
مانند دستورهای `else-if`، دستورهای switch تنها بلوک کدی را اجرا می‌کنند که با نخستین حالت منطبق مرتبط است.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

مثال زیر را در نظر بگیرید:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

در عوض می‌توان این را چنین نوشت:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## حلقه‌های while

یک [حلقه‌ی while][while-loops] یک دستور جریان کنترل است که امکان می‌دهد کد تا زمانی که یک شرط خاص «درست» است اجرا شود.
Swift دو نوع حلقه‌ی while ارائه می‌دهد: حلقه‌های while و repeat-while.
شرط حلقه‌ی while پیش از اجرای بدنه‌ی حلقه ارزیابی می‌شود؛ اگر شرط «غلط» باشد، بدنه‌ی حلقه به‌کلی اجرا نخواهد شد.
حلقه‌های while در Swift ساختار زیر را دارند:

```swift
while <#condition#> {
  <#code#>
}
```

در اینجا حلقه تا زمانی که `count` بزرگ‌تر از ۰ باشد اجرا می‌شود و در نتیجه اعداد ۲، ۱ و «Liftoff!» را چاپ می‌کند.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

یک [حلقه‌ی repeat-while][while-loops] شبیه حلقه‌ی while است، اما شرط پس از اجرای بدنه‌ی حلقه ارزیابی می‌شود.
این یعنی بدنه‌ی حلقه همیشه دست‌کم یک بار اجرا می‌شود، حتی اگر شرط «غلط» باشد.
حلقه‌های repeat-while در Swift ساختار زیر را دارند:

```swift
repeat {
  <#code#>
} while <#condition#>
```

در اینجا حلقه فقط یک بار اجرا می‌شود، چون شرط «غلط» است.
چون این یک حلقه‌ی repeat-while است، بدنه‌ی حلقه پیش از ارزیابی شرط یک بار اجرا می‌شود.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## انتقال کنترل

Swift مجموعه‌ای از دستورها دارد که می‌توان از آن‌ها برای تغییر جریان کنترل عادی حلقه‌ها استفاده کرد.
به این‌ها دستورهای انتقال کنترل می‌گویند.
شما پیش‌تر `return` را دیده‌اید؛ این مفهوم موارد دیگری را معرفی می‌کند که شامل `continue`، `break` و برچسب‌هاست.
در این مفهوم به `fallthrough` نمی‌پردازیم، اما می‌توانید درباره‌ی آن در [کتاب Swift][fallthrough] بخوانید.

### Continue

گاهی لازم است زودتر به تکرار بعدی حلقه بپرید، بدون آنکه بقیه‌ی دستورهای تکرار کنونی حلقه را کامل کنید.
کلیدواژه‌ی `continue` برای این کار به کار می‌رود.
وقتی `continue` اجرا می‌شود، حلقه به بررسی بعدی می‌پرد تا ببیند آیا تکرار بعدی حلقه قابل اجراست یا نه، یعنی `while` در حلقه‌های while و repeat-while، یا بررسی این‌که آیا عنصر دیگری در دنباله هست یا نه در حلقه‌های for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

از `break` برای خروج زودتر از حلقه استفاده می‌شود.
وقتی `break` اجرا می‌شود، حلقه بی‌درنگ خارج می‌شود و برنامه با نخستین دستور پس از حلقه ادامه می‌یابد.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### برچسب‌ها

وقتی حلقه‌ها تودرتو هستند، گاهی ممکن است بخواهید از `break` یا `continue` استفاده کنید تا از حلقه‌های بیرونی‌ای که حلقه‌ی به‌کارگیرنده‌ی `break` یا `continue` را در خود دارند خارج شوید یا آن‌ها را از نو شروع کنید.
در چنین مواردی می‌توان از برچسب‌ها استفاده کرد تا مشخص شود کدام حلقه باید خارج شود یا از نو شروع شود.
می‌توان یک حلقه را با قرار دادن یک اسم و سپس یک دونقطه پیش از `while`، `repeat` یا `for` که حلقه را آغاز می‌کند، برچسب‌گذاری کرد.

برای دیدن اثر استفاده از برچسب‌ها به این شکل، حلقه‌ی زیر را در نظر بگیرید.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
