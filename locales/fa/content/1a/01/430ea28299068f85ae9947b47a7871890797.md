# مقادیر منطقی را با «درست» یا «غلط» مقایسه نکنید

مقایسه‌ی مقادیر منطقی با «درست» یا «غلط» کاری اضافی است.
استفاده از `==` خودش یک مقدار منطقی تولید می‌کند، پس مقایسه‌ی آن با یک مقدار منطقی دیگر که مستقیم در کد نوشته شده، لازم نیست.
اگر می‌خواهید مقدار منطقی را معکوس کنید، از عملگر `!` استفاده کنید.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
