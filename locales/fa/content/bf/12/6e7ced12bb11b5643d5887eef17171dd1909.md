# دستورالعمل‌ها

الیس به‌عنوان یک شعبده‌باز تازه‌کار باید چند تکنیک پایه را تمرین کند. او یک دسته کارت دارد که می‌خواهد آن‌ها را دستکاری کند.

برای اینکه کار کمی ساده‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

دسته‌ی کارت‌ها با یک `queue` نمایش داده می‌شود؛ پایین دسته در جلوی صف و بالای دسته در انتهای صف قرار دارد.

## 1. درج کارت در بالای دسته

تابع `insert_top` را پیاده‌سازی کنید که نسخه‌ای از دسته را برمی‌گرداند که کارت جدید داده‌شده به بالای دسته اضافه شده است.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. حذف کارت بالای دسته

تابع `remove_top_card` را پیاده‌سازی کنید که نسخه‌ای از دسته را برمی‌گرداند که کارت بالای آن حذف شده است. اگر دسته‌ی داده‌شده خالی باشد، باید همان دسته‌ی اولیه بدون تغییر برگردانده شود.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. درج کارت در پایین دسته

تابع `insert_bottom` را پیاده‌سازی کنید که نسخه‌ای از دسته را برمی‌گرداند که کارت جدید داده‌شده به پایین دسته اضافه شده است.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. حذف کارت از پایین دسته

تابع `remove_bottom_card` را پیاده‌سازی کنید که نسخه‌ای از دسته را برمی‌گرداند که کارت پایین آن حذف شده است. اگر دسته‌ی داده‌شده خالی باشد، باید همان دسته‌ی اولیه بدون تغییر برگردانده شود.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. بررسی اندازه‌ی دسته

تابع `check_size_of_stack` را پیاده‌سازی کنید که بررسی می‌کند آیا اندازه‌ی دسته با `stack_size` داده‌شده برابر است یا نه.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
