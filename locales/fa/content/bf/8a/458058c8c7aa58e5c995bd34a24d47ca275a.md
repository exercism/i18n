# مقدمه

تا اینجا دیده‌ایم که آرگومان‌هایی که به یک متد داده می‌شوند، بر اساس موقعیت با پارامترهای اعلام‌شده‌ی متد تطبیق داده می‌شوند. یک روش جایگزین، به‌ویژه زمانی که یک روال تعداد زیادی آرگومان می‌گیرد، این امکان را به فراخواننده می‌دهد که آرگومان‌ها را با مشخص کردن شناسه‌ی پارامتر اعلام‌شده تطبیق دهد.

مثال زیر نحوه‌ی نگارش را نشان می‌دهد:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
