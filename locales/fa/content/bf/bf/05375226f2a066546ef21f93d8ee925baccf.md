# مقدمه

[`list`][list] یک مجموعه‌ی تغییرپذیر از عنصرهاست که در یک _دنباله_ قرار می‌گیرند.
 مانند بیشتر مجموعه‌ها (به انواع درونی [`tuple`][tuple]، [`dict`][dict] و [`set`][set] نگاه کنید)، «لیست»ها می‌توانند ارجاع به هر نوع داده‌ای (یا چند نوع داده) داشته باشند، از جمله لیست‌های دیگر.
 لیست‌ها را می‌توان به‌صورت کامل یا بخشی، با [نشانه‌گذاری برش][slice notation] یا با استفاده از `<list>.copy()` کپی کرد.
 مانند هر [نوع دنباله][sequence type] دیگری، عناصر داخل `lists` با شماره‌ی `0-based index` از سمت چپ، یا شماره‌ی `-1-based index` از سمت راست ارجاع داده می‌شوند.

لیست‌ها هم از عملیات دنباله‌ای [عمومی][common sequence operations] و هم از عملیات دنباله‌ای [تغییرپذیر][mutable sequence operations] پشتیبانی می‌کنند، مانند `min(<list>)`/`max(<list>)`، `<list>.index()`، `<list>.append()` و `<list>.reverse()`.
 عناصر داخل یک `list` را می‌توان با ساختار `for item in <list>` پیمایش کرد.
 وقتی هم به اندیس عنصر و هم به مقدار آن نیاز باشد، می‌توان از `for index, item in enumerate(<list>)` استفاده کرد.

پایتون همچنین [متدهای لیست][list-methods] مفید زیادی برای کار با لیست‌ها فراهم می‌کند.
 در ادامه بخشی از این `list methods` را بررسی می‌کنیم.


توجه داشته باشید که وقتی یک `list` را با یک `list-method` دستکاری می‌کنید، **شیء لیستی** را تغییر می‌دهید که پاس داده شده است.
 اگر نمی‌خواهید `list` اصلی تغییر کند، باید حداقل یک `shallow copy` از آن، از طریق برش یا `<list>.copy()`، بسازید.


## افزودن عنصرها

برای افزودن یک عنصر به انتها یا «سمت راست» یک لیست موجود، از `<list>.append(<item>)` استفاده کنید:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

به‌جای _افزودن به انتها_، `<list>.insert()` این امکان را به شما می‌دهد که عنصر را در یک _اندیس مشخص_ در لیست اضافه کنید.
این متد ۲ پارامتر می‌گیرد:

1. `<index>`ای که می‌خواهید عنصر در آن درج شود.
2. `<item>`ای که باید درج شود.

**توجه**: اگر `index` داده‌شده ۰ باشد، عنصر به ابتدای `list` («سمت چپ») اضافه می‌شود.
 اگر `index` داده‌شده بزرگ‌تر از آخرین `index` در `list` باشد، عنصر در جایگاه آخر اضافه می‌شود، یعنی معادل استفاده از `<list>.append(<item>)`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


از `<list>.extend(<item>)` می‌توان برای ترکیب یک لیست موجود با عناصر یک شیء قابل‌پیمایش دیگر (مثلاً یک `set`، `tuple`، `str` یا `list`) استفاده کرد.
  شیء قابل‌پیمایش _باز می‌شود_ و عناصر آن به ترتیب اضافه می‌شوند (_استفاده از `<list>.append(<item>)` در این حالت، کل شیء قابل‌پیمایش را به‌صورت یک **عنصر واحد** اضافه می‌کند._).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## حذف عنصرها

برای حذف یک عنصر از لیست از `<list>.remove(<item>)` استفاده کنید و عنصری را که باید حذف شود به‌عنوان آرگومان بدهید.
 اگر عنصر در `list` موجود نباشد، `<list>.remove(<item>)` یک `ValueError` ایجاد می‌کند.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


در روشی دیگر، استفاده از متد `<list>.pop(<index>)` هم عنصر را حذف می‌کند **و** هم آن را برای استفاده `return` می‌کند.


`<list>.pop(<index>)` یک پارامتر اختیاری می‌گیرد: `index` عنصری که باید حذف و برگردانده شود.
 اگر آرگومان (اختیاری) `index` مشخص نشود، آخرین عنصر `list` حذف و برگردانده می‌شود.
 اگر `index` مشخص‌شده بزرگ‌تر از آخرین `index` عنصرها باشد، یک `IndexError` ایجاد می‌شود.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

همه‌ی عناصر یک `list` را می‌توان با `list.clear()` حذف کرد. این متد هیچ پارامتری نمی‌گیرد.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## معکوس کردن و مرتب‌سازی مجدد

متد `<list>.reverse()` ترتیب عناصر را **درجا** معکوس می‌کند.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


با کمک [`<list>.sort()`][sort] می‌توان ترتیب یک لیست را _**درجا**_ تغییر داد.
ترتیب پیش‌فرض مرتب‌سازی از سمت چپ _صعودی_ است.
مستندات پایتون [نکات و تکنیک‌های بیشتری برای مرتب‌سازی][sorting how to] ارائه می‌دهد.

~~~~exercism/note
 از سال ۲۰۰۲ تا ۲۰۲۲، پایتون به‌صورت داخلی از الگوریتمی به اسم [`Timsort`][timsort] برای مرتب‌کردن لیست‌ها استفاده می‌کرد، اما از `Python 3.11` به بعد به [`Powersort`][powersort] روی آورد.

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

اگر ترتیب _نزولی_ مورد نظر باشد، آرگومان `reverse=True` را پاس بدهید:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

در مواردی که تغییر دادن لیست اصلی مطلوب نیست، می‌توان از تابع درونی [`sorted(<iterable>)`][sorted] استفاده کرد تا یک **کپی** مرتب برگردانده شود.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## تعداد وقوع یک عنصر در یک لیست

تعداد وقوع یک عنصر در یک لیست را می‌توان با کمک `list.count(<item>)` محاسبه کرد.
 این متد `item` مورد شمارش را به‌عنوان آرگومان می‌گیرد و تعداد کل دفعاتی را برمی‌گرداند که آن عنصر در `list` ظاهر می‌شود.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## یافتن اندیس عنصرها

`<list>.index(<item>)` شماره‌ی `index` _نخستین وقوع_ عنصری را که پاس داده شده برمی‌گرداند.
 اگر هیچ وقوعی نباشد، یک `ValueError` ایجاد می‌شود.
 اگر به موقعیت دقیق یک عنصر نیاز نباشد، عملگر درونی `in` برای بررسی وجود یک مقدار مشخص در یک لیست کارآمدتر است.


اندیس‌گذاری از سمت چپ مبتنی بر صفر است، بنابراین موقعیت عنصر «اول» عدد `0` است.
اندیس‌گذاری از سمت راست هم کار می‌کند و از `-1` شروع می‌شود.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

می‌توان اندیس‌های `start` و `end` را هم ارائه داد تا جست‌وجو به بخشی مشخص از `list` محدود شود:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
