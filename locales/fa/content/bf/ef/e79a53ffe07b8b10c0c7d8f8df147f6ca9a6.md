# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که به یک فریلنسر کمک می‌کند با یک مدیر پروژه ارتباط برقرار کند؛ این کار را با ساختن چند ابزار انجام می‌دهید که نرخ‌های روزانه و ماهانه را سریع محاسبه می‌کنند، و در صورت نیاز تخفیف داده‌شده را هم در نظر می‌گیرند.

ابتدا چند قاعده بین فریلنسر و مدیر پروژه تعیین می‌کنیم:

- نرخ روزانه ۸ برابر نرخ ساعتی است.
- هر ماه ۲۲ روز قابل‌صورت‌حساب دارد.

گاهی فریلنسر پیشنهاد می‌دهد که روی نرخ روزانه‌اش تخفیف بگذارد (برای نمونه برای وفادارترین مشتریانش یا برای مشتریان غیرانتفاعی).

تخفیف‌ها به شکل اعداد اعشاری مدل می‌شوند که درصد را نشان می‌دهند؛ برای نمونه `25.0` یعنی ۲۵ درصد.

## 1. محاسبه‌ی نرخ روزانه بر اساس نرخ ساعتی

تابعی پیاده‌سازی کنید که نرخ روزانه را بر اساس نرخ ساعتی محاسبه کند:

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

نرخ روزانه‌ی برگشتی باید یک عدد اعشاری باشد.

## 2. محاسبه‌ی قیمت پس از تخفیف

تابعی پیاده‌سازی کنید که قیمت را پس از اعمال تخفیف محاسبه کند.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

مقدار برگشتی همیشه باید یک عدد اعشاری باشد و به هیچ شکلی گرد نشود.

## 3. محاسبه‌ی نرخ ماهانه بر اساس نرخ ساعتی و تخفیف

تابعی پیاده‌سازی کنید که نرخ ماهانه را محاسبه کند و تخفیف را هم اعمال کند:

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

نرخ ماهانه‌ی برگشتی باید به نزدیک‌ترین عدد صحیح و به سمت بالا (سقف) گرد شود.

## 4. محاسبه‌ی تعداد روزهای کاری بر اساس بودجه، نرخ ساعتی و تخفیف

تابعی پیاده‌سازی کنید که بودجه، نرخ ساعتی و تخفیف را می‌گیرد و محاسبه می‌کند که این مبلغ پوشش چند روز کار را می‌دهد.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

تعداد روزهای برگشتی باید به سمت پایین (کف) و تا یک رقم اعشار گرد شود.
