# مقدمه

در Python، [یک `enum`][enum-docs] مجموعه‌ای از اسم‌هاست که به مقادیر یکتای `literal` یا `constant` مقید شده‌اند.
`Enum`ها با ارث‌بری از یک کلاس `Enum` تعریف می‌شوند.
انواع توکار `enum` در ماژول `enum` در دسترس‌اند و کلاس `Enum` را می‌توان با `from enum import Enum` ایمپورت کرد.

```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

توجه کنید که مقادیر اعضای `enum` می‌توانند هر نوع داده‌ای باشند، مثل `str`، `tuple`، `float` و غیره.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

وقتی مقدار یکسانی به دو عضو یک `enum` اختصاص داده می‌شود، عضوی که بعداً مقدار می‌گیرد، نام مستعار عضو اول خواهد بود. استفاده از یک اسم برای دو عضو متفاوت یک `enum` مجاز نیست.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

پیمایش اعضای `enum` را می‌توان با «نحوه‌ی نگارش» استاندارد `for member in` انجام داد:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

اعضای `Enums` را می‌توان با [`is` (عملگر _هویت_)][identity-keyword] یا `is not` مقایسه کرد. `==` یا `!=` (عملگرهای _برابری_) هم به همین شکل کار می‌کنند:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

برای دسترسی به یک عضو `enum` با یک مقدار مشخص، می‌توان از `<EnumName>(<value>)` استفاده کرد:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
