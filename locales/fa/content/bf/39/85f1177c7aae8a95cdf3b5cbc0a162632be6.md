# CLI

## راه‌اندازی

ساده‌ترین راه نصب Purescript از طریق Node.js و NPM است.

اگر هنوز Node.js را روی رایانه‌تان نصب نکرده‌اید، می‌توانید آن را از [وب‌سایت Node.js][nodejs-website] دانلود کنید. وقتی Node.js روی رایانه‌تان راه افتاد، برای نصب کامپایلر PureScript و Spago، که ابزار مدیریت بسته و ساخت است، این فرمان را در ترمینال وارد کنید:

```shell
npm install -g purescript spago
```

اطلاعات بیشتر را می‌توانید در [مخزن PureScript][purescript-repository] پیدا کنید.

## پیش‌نیازها

وابستگی‌های تمرین را نصب کنید:

```shell
spago install
spago build
```

## پاس کردن مجموعه‌ی تست‌ها

تست‌ها را با این فرمان اجرا کنید:

```shell
spago test
```

در مجموعه‌های تست، همه‌ی تست‌ها به‌جز اولین تست رد شده‌اند. این کار برای تشویق شماست که تمرین را قدم‌به‌قدم حل کنید.

وقتی یک تست را پاس کردید، می‌توانید با تغییر `xit` به `it` تست بعدی را فعال کنید.

## ارسال راه‌حل

وقتی هیچ تستی رد نشده باشد و همه پاس شده باشند، می‌توانید راه‌حل خود را با این فرمان ارسال کنید:

```shell
exercism submit src/<NAME>.purs
```

## نوشتن تست‌های سفارشی

اگر می‌خواهید تست‌های سفارشی بیشتری بنویسید، یک فایل جدید به اسم `test/Custom.purs` بسازید و آن را همراه با راه‌حل خود و این فایل جدید ارسال کنید:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
