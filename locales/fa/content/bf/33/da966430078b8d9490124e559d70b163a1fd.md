# راهنما

## کلی

- توابع «کالبک» توابعی‌اند که به‌عنوان آرگومان به تابع فراخواننده پاس داده می‌شوند.
- توابع کالبک باید مشخصات تابع فراخواننده را برآورده کنند.

## 1. اطلاع‌رسانی با پیام موفقیت

- از تابع `notify` که از API وارد شده است، در تابع خودتان استفاده کنید.
- یک شیء را به `notify` پاس دهید. این شیء باید ویژگی‌ای به اسم `message` داشته باشد. به این فکر کنید که مقدار `message` چه باید باشد.
- به راهنمای نوع JSDoc توجه کنید: تابع نباید مقداری برگرداند.

## 2. اطلاع‌رسانی با پیام خطا

- از تابع `notify` که از API وارد شده است، در تابع خودتان استفاده کنید.
- یک شیء دیگر را به `notify` پاس دهید. این شیء هم باید ویژگی‌ای به اسم `message` داشته باشد. مقدار `message` باید با بخش قبلی متفاوت باشد.
- به نظرات [JSDoc] بالای تعریف تابع توجه کنید:
  - تابع نباید مقداری برگرداند.

## 3. ثبت سفارش برای خرید میوه

- از تابع `order` که از قبل وارد شده است، استفاده کنید.
- به راهنماهای نوع JSDoc توجه کنید: تابع باید ۳ آرگومان دریافت کند و مقداری برنگرداند.
- از کالبک‌هایی که قبلاً ساخته‌اید، به‌عنوان آرگومان تابع `order` استفاده کنید.

## 4. بازآرایی کارتان در قالب تابعی مختصرتر

- از توابع کارهای قبلی دوباره استفاده کنید.
- به راهنماهای نوع JSDoc توجه کنید: تابع باید ۲ آرگومان دریافت کند و مقداری برنگرداند.
- آرگومان‌ها را در قالب یک شیء ترکیب کنید که درخواست ثبت سفارش از بقال را نشان می‌دهد.
