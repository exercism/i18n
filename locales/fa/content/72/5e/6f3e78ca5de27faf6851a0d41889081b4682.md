# نصب Swift

Swift روی macOS، Linux و Windows در دسترس است.
فرایند نصب بسته به سیستم‌عاملی که استفاده می‌کنید متفاوت است.
نکته‌ای که درباره‌ی پشتیبانی Linux باید در نظر گرفت این است که Swift فقط (به‌طور رسمی) روی توزیع‌های زیر پشتیبانی می‌شود:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

اگر از توزیع دیگری از Linux استفاده می‌کنید، باید خودتان راهی برای نصب Swift پیدا کنید.

## Xcode (macOS)

Swift همراه Xcode عرضه می‌شود، محیط توسعه‌ی یکپارچه‌ی اپل برای توسعه‌ی macOS و iOS.
برای track زبان Swift در Exercism باید Xcode نسخه‌ی 16.0 یا بالاتر نصب باشد.
Xcode به‌صورت رایگان در [Mac App Store][xcode] در دسترس است.
نسخه‌های دیگر Xcode (از جمله جدیدترین نسخه‌ی بتا) در [مرکز توسعه‌دهندگان اپل][apple-developer-center] در دسترس است.

## macOS و Linux

برای macOS و Linux، مدیر نصب Swift وجود دارد به اسم [swiftly][swiftly].
این یک ابزار خط فرمان است که به شما امکان می‌دهد چندین نسخه‌ی Swift را روی سیستم خودتان نصب و مدیریت کنید.
دستور نصب swiftly روی macOS را می‌توانید [اینجا][swiftly-macos] ببینید و برای linux [اینجا][swiftly-linux].

روش‌های نصب دیگر برای macOS شامل [Homebrew][homebrew] است.
برای Linux، می‌توانید با استفاده از tarball از [وب‌سایت رسمی Swift][tarball] نصب کنید.

## Windows

روش پیشنهادی نصب Swift روی Windows استفاده از [نصب‌کننده‌ی WinGet][winget-windows] است.
همچنین می‌توانید Swift را با مدیر بسته‌ی Scoop یا با نصب دستی نصب کنید.
برای دیدن همه‌ی گزینه‌ها، صفحه‌ی [نصب Swift برای Windows][swift-windows] را ببینید.
