# مقدمه

## بازگشت دمی

وقتی با [بازگشت][exercism-recursion] روی داده‌های قابل شمارش (فهرست‌ها، بیت‌استرینگ‌ها، رشته‌ها) کار می‌کنید، معمولاً دو دغدغه وجود دارد:

- چه مقدار حافظه برای نگه‌داشتن ردِ فراخوانی‌های بازگشتی تابع لازم است
- چگونه راه‌حل را به‌شکل کارآمد بسازیم

برای رسیدگی به این دغدغه‌ها می‌توان از یک _انباره_ استفاده کرد.

انباره متغیری است که علاوه بر خود داده‌ها منتقل می‌شود. از آن برای انتقال وضعیت جاری اجرای تابع، از یک فراخوانی به فراخوانی بعدی، تا رسیدن به _حالت پایه_ استفاده می‌شود. در حالت پایه، از انباره برای برگرداندن مقدار نهایی فراخوانی بازگشتی تابع استفاده می‌شود.

انباره را باید نویسنده‌ی تابع مقداردهی اولیه کند، نه کاربر تابع. برای این کار دو تابع تعریف کنید: یک تابع عمومی که فقط داده‌های لازم را به‌عنوان ورودی می‌گیرد و انباره را مقداردهی اولیه می‌کند و یک تابع خصوصی که انباره را هم می‌گیرد. در Elixir، الگوی رایجی است که نام تابع خصوصی را با `do_` شروع کنند.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

استفاده از انباره به ما اجازه می‌دهد توابع بازگشتی را به توابع _بازگشتی دمی_ تبدیل کنیم. تابع زمانی بازگشتی دمی است که _آخرین_ عملیاتی که اجرا می‌کند، فراخوانی خودش باشد.
