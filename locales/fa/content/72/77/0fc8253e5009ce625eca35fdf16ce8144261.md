# دستورالعمل‌ها

شما در سالن بازی کنار دریا، بازی‌های شانسی را اداره می‌کنید. مشتری‌ها تاس می‌اندازند، دستگاه چنگک یک جایزه را برمی‌دارد و میز کارت هم باید دسته‌کارتش بُر بخورد و دست‌ها پخش شوند. همه‌ی این‌ها با تصادف کار می‌کنند. آخر شب هم می‌خواهید قابلیت «بازپخش» را داشته باشید تا بتوان یک بازی مورد اختلاف را با همان دانه دوباره اجرا کرد.

## 1. انداختن یک تاس

`roll-die` را تعریف کنید تا تعداد وجه‌ها را بگیرد و عددی در بازه‌ی `1` تا `sides` (شامل هر دو سر) برگرداند.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. برداشتن یک جایزه

`pick-prize` را تعریف کنید تا یک دنباله از جایزه‌ها بگیرد و یکی از آن‌ها را به‌صورت تصادفی برگرداند.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. بُر زدن دسته‌کارت

`shuffle-deck` را تعریف کنید تا یک دسته‌کارت (یک دنباله) بگیرد و آن را با کارت‌هایی در ترتیب تصادفی برگرداند.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. پخش کردن یک دست

`deal-hand` را تعریف کنید تا یک دسته‌کارت و یک تعداد `n` بگیرد و `n` کارت *متمایز* را از دسته‌کارت برگرداند.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. بازپخش با یک دانه

`play-seeded` را تعریف کنید تا یک دانه و یک quotation بگیرد و quotation را با مولدی اجرا کند که با آن عدد صحیح دانه‌بندی شده است، تا همان دانه همیشه همان نتیجه را تولید کند. نتیجه‌ی quotation باید به فراخوان‌کننده برگردانده شود.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
