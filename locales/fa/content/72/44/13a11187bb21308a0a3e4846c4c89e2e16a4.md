# مقدمه

در Python، از `None` اغلب برای نشان دادن نبود یک مقدار استفاده می‌شود: جای‌نگهیی برای تعریف یک متغیر، شیء یا آرگومان `null` (خالی).

اگر درباره‌ی نوع `NULL` یا `nil` در زبان برنامه‌نویسی دیگری شنیده باشید یا از آن استفاده کرده باشید، این کاربرد `None` در Python برایتان آشنا خواهد بود. `None` به شما کمک می‌کند متغیرها یا آرگومان‌های تابعی را تعریف کنید که هنوز مقداری برایشان ندارید. بعداً می‌توانید در صورت نیاز مقدار مشخصی به آن‌ها نسبت دهید.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

وقتی از `None` در یک بررسی شرطی استفاده شود، به `False` ارزیابی می‌شود؛ بنابراین برای اعتبارسنجی «وجود» یا «نبود» یک مقدار، _هر_ مقداری، مفید است؛ الگویی که اغلب زمانی به کار می‌رود که یک تابع یا فرایند ممکن است یک شیء یا پیام خطا برگرداند.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
