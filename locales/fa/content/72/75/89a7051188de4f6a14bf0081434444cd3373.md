# دستورالعمل‌ها

شرکت طراحی شما تا به حال بیشتر با تبدیل‌های CSS برای ساخت صفحات وب کار می‌کرده است. پس از گفت‌وگوهایی، تصمیم گرفته می‌شود که از این پس از JavaScript برای انجام برخی محاسبات به‌صورت پویا استفاده شود. برخی از هم‌تیمی‌های شما تجربه‌ی کمتری با JavaScript دارند، بنابراین تصمیم می‌گیرید از یک «بستار» تابع استفاده کنید تا تبدیلی قابل استفاده‌ی مجدد برای جفت‌های مختصات `{x, y}` بسازید.

## 1. مختصات را انتقال دهید

تابع `translate2d` را پیاده‌سازی کنید که تابعی را برمی‌گرداند که با استفاده از یک بستار، انتقال دوبعدی تکرارپذیر یک جفت مختصات را انجام می‌دهد.

> در هندسه، [انتقال][wiki-translate] به جابه‌جا کردن نقاط، بردارها یا شکل‌ها به یک فاصله در یک جهت گفته می‌شود.
> می‌توان آن را افزودن یک مقدار ثابت به هر نقطه تفسیر کرد.

```javascript
const moveCoordinatesRight2Px = translate2d(2, 0);
const result = moveCoordinatesRight2Px(4, 8);
// result => [6, 8]
```

## 2. مختصات را مقیاس کنید

تابع `scale2d` را پیاده‌سازی کنید که تابعی را برمی‌گرداند که با استفاده از یک بستار، مقیاس دوبعدی تکرارپذیر یک جفت مختصات را انجام می‌دهد.

> در هندسه، [مقیاس‌کردن][wiki-scale] یکنواخت به بزرگ یا کوچک کردن بردارها یا شکل‌ها در یک جهت گفته می‌شود.
> می‌توان آن را ضرب هر نقطه در یک مقدار ثابت (ضریب مقیاس) تفسیر کرد.
>
> در این تمرین، فرض کنید مقادیر مقیاس فقط مثبت‌اند.

```javascript
const doubleScale = scale2d(2, 2);
const result = doubleScale(6, -3);
// result => [12, -6]
```

## 3. توابع تبدیل را ترکیب کنید

دو تابع تبدیل را ترکیب کنید تا تبدیلی تکرارپذیر انجام دهید. به این کار اغلب _ترکیب توابع_ می‌گویند؛ در آن، نتیجه‌ی تابع اول _'f(x)'_ به‌عنوان ورودی تابع دوم _'g(x)'_ استفاده می‌شود.

```javascript
const moveCoordinatesRight2Px = translate2d(2, 0);
const doubleCoordinates = scale2d(2, 2);
const composedTransformations = composeTransform(
  moveCoordinatesRight2Px,
  doubleCoordinates,
);
const result = composedTransformations(0, 1);
// result => [4, 2]
```

## 4. نتایج توابع را ذخیره کنید

تابع `memoizeTransform` را پیاده‌سازی کنید. این تابع، تابعی را برای _حافظه‌سپاری_ می‌گیرد و سپس تابع جدیدی برمی‌گرداند که ورودی‌های تابع داده‌شده را به خاطر می‌سپارد، به این ترتیب آخرین مقدار بازگشتی «به خاطر سپرده می‌شود» و اگر با همان آرگومان‌ها دوباره فراخوانی شود، فقط یک‌بار محاسبه می‌شود.

> حافظه‌سپاری گاهی در _برنامه‌نویسی پویا_ استفاده می‌شود.
> این کار اجازه می‌دهد عملیات پرهزینه فقط یک‌بار انجام شوند، چون نتایجشان به خاطر سپرده می‌شوند.
> **توجه** کنید که در این تمرین فقط آخرین نتیجه به خاطر سپرده می‌شود، برخلاف برخی راه‌حل‌ها در برنامه‌نویسی پویا که _همه‌ی_ نتایج را حافظه‌سپاری می‌کنند.

```javascript
const tripleScale = scale2d(3, 3);
const memoizedScale = memoizeTransform(tripleScale);

memoizedScale(4, 3); // => [12, 9], this is computed since it hasn't been computed before for the arguments
memoizedScale(4, 3); // => [12, 9], this is remembered, since it was computed already
```
