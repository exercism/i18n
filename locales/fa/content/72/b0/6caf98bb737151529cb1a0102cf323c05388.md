# Tests

برای اجرای test تمرین با CLI، دستور زیر را از پوشه‌ی تمرین اجرا کنید:

```bash
clojure -M:test
```

## REPL

برای اجرای test تمرین با REPL، دستور زیر را از پوشه‌ی تمرین اجرا کنید:

```bash
$ clojure -m cljs.main -re node
```

سپس فضای نام test تمرین و فضای نام test در Clojure را `require` کنید):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

حالا `ns` را به فضای نام test تغییر دهید:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

سپس `run-tests` را فراخوانی کنید:

```clojure
=> (cljs.test/run-tests)
```
