# دستورالعمل

در این تمرین با حساب‌های پس‌انداز کار می‌کنید.
هر سال، موجودی حساب پس‌انداز شما بر اساس نرخ سود آن به‌روزرسانی می‌شود.
نرخ سودی که بانک به شما می‌دهد به مقدار پول موجود در حساب شما (یعنی موجودی آن) بستگی دارد:

- 3.213٪ برای موجودی کمتر از `0` دلار (موجودی منفی‌تر می‌شود).
- 0.5٪ برای موجودی بزرگ‌تر یا مساوی `0` دلار و کمتر از `1000` دلار.
- 1.621٪ برای موجودی بزرگ‌تر یا مساوی `1000` دلار و کمتر از `5000` دلار.
- 2.475٪ برای موجودی بزرگ‌تر یا مساوی `5000` دلار.

شما چهار وظیفه دارید که هر کدام به موجودی و نرخ سود آن می‌پردازد.

## 1. محاسبه‌ی نرخ سود

تابع `InterestRate()` را پیاده‌سازی کنید تا نرخ سود را بر اساس موجودی داده‌شده محاسبه کند:

```go
InterestRate(200.75)
// => 0.5
```

توجه کنید که مقدار برگشتی از نوع `float32` است.

## 2. محاسبه‌ی سود

تابع `Interest()` را پیاده‌سازی کنید تا سود را بر اساس موجودی داده‌شده محاسبه کند:

```go
Interest(200.75)
// => 1.003750
```

توجه کنید که مقدار برگشتی از نوع `float64` است.

## 3. محاسبه‌ی به‌روزرسانی سالانه‌ی موجودی

تابع `AnnualBalanceUpdate()` را پیاده‌سازی کنید تا به‌روزرسانی سالانه‌ی موجودی را با در نظر گرفتن نرخ سود محاسبه کند:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

توجه کنید که مقدار برگشتی از نوع `float64` است.

## 4. محاسبه‌ی تعداد سال‌های لازم برای رسیدن به موجودی موردنظر

تابع `YearsBeforeDesiredBalance()` را پیاده‌سازی کنید تا کمترین تعداد سال‌های لازم برای رسیدن به موجودی موردنظر را محاسبه کند، با در نظر گرفتن این که هر سال سود به موجودی اضافه می‌شود.
یعنی موجودی پس از یک سال برابر است با: موجودی اولیه + سود موجودی اولیه.
موجودی پس از سال دوم برابر است با: موجودی پس از یک سال + سود موجودی پس از یک سال.
و همین‌طور ادامه می‌یابد تا وقتی که موجودی سال جاری بزرگ‌تر یا مساوی موجودی هدف شود.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

توجه کنید که مقدار برگشتی از نوع `int` است.
