# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به شما کمک می‌کند برای خرید خودرو آماده شوید.

سه کار در پیش دارید: یکی برای تعیین اینکه آیا از عهده‌ی پرداخت‌های ماهانه برمی‌آیید، یکی برای تعیین اینکه به چه گواهینامه‌ای نیاز دارید و یکی برای تخمین قیمت مناسب یک خودروی دست‌دوم.

## 1. محاسبه کنید که آیا از عهده‌ی پرداخت‌های ماهانه‌ی یک خودروی مشخص برمی‌آیید یا نه

همه‌ی نمایندگی‌های خودرو در شهر شما یک طرح تشویقی پنج‌ساله با سود ۰٪ اجرا می‌کنند و شما می‌خواهید از آن استفاده کنید.
اما مطمئن نیستید که از عهده‌ی پرداخت‌های ماهانه‌ی خودروی موردنظرتان بربیایید.

پرداخت ماهانه برابر است با قیمت کل خودرو تقسیم بر تعداد ماه‌های این دوره‌ی پنج‌ساله.

تابع `canIBuy(vehicle:price:monthlyBudget:)` را پیاده‌سازی کنید که این پارامترها را می‌گیرد:
- `vehicle` - اسم خودرویی که می‌خواهید بخرید.
- `price` - قیمت خودرویی که می‌خواهید بخرید.
- `monthlyBudget` - مبلغی که می‌توانید هر ماه بپردازید.

تابع باید بسته به شرط‌های زیر، پیام مربوطه را برگرداند:
- اگر پرداخت ماهانه‌ی خودرو کمتر از یا برابر با بودجه‌ی ماهانه باشد، پیام `"Yes! I'm getting a <vehicle>"` را برگردانید.
- اگر پرداخت ماهانه‌ی خودرو تا ۱۰٪ (با احتساب خود ۱۰٪) بیشتر از بودجه‌ی ماهانه‌ی شما باشد، پیام `"I'll have to be frugal if I want a <vehicle>"` را برگردانید.
- اگر پرداخت ماهانه‌ی خودرو بیش از ۱۰٪ بالاتر از بودجه‌ی ماهانه‌ی شما باشد، پیام `"Darn! No <vehicle> for me"` را برگردانید.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. تعیین کنید که به چه نوع گواهینامه‌ای نیاز دارید

تصمیم گرفته‌اید یک خودروی دست‌دوم بخرید و باید تعیین کنید برای راندن آن به چه نوع گواهینامه‌ای نیاز دارید.

تابع `licenseType(numberOfWheels:)` را پیاده‌سازی کنید که پارامتر `numberOfWheels` را می‌گیرد؛ این پارامتر تعداد چرخ‌های خودرویی است که می‌خواهید بخرید.

تابع باید بسته به شرط‌های زیر، پیام مربوطه را برگرداند:
- اگر تعداد چرخ‌ها ۲ یا ۳ باشد، پیام `"You will need a motorcycle license for your vehicle"` را برگردانید.
- اگر تعداد چرخ‌ها ۴ یا ۶ باشد، پیام `"You will need an automobile license for your vehicle"` را برگردانید.
- اگر تعداد چرخ‌ها ۱۸ باشد، پیام `"You will need a commercial trucking license for your vehicle"` را برگردانید.
- اگر تعداد چرخ‌ها هر عدد دیگری باشد، پیام `"We do not issue licenses for those types of vehicles"` را برگردانید.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. تخمینی از قیمت یک خودروی دست‌دوم محاسبه کنید

حالا که تصمیمتان را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی قیمت منصفانه‌ای می‌پردازید.
چون می‌خواهید یک خودروی دست‌دوم بخرید، قیمت به سن خودرو بستگی دارد.
برای یک تخمین تقریبی، فرض کنید اگر خودرو کمتر از ۳ سال سن داشته باشد، ۸۰٪ قیمتی را هزینه دارد که هنگام نو بودن داشت.
اگر حداقل ۱۰ سال سن داشته باشد، ۵۰٪ قیمت را هزینه دارد.
اگر خودرو حداقل ۳ سال سن داشته باشد اما بیش از ۱۰ سال نداشته باشد، ۷۰٪ قیمت اولیه را هزینه دارد.

تابع `calculateResellPrice(originalPrice:yearsOld:)` را پیاده‌سازی کنید که پارامتر `originalPrice`، یعنی قیمت اولیه‌ی خودرو، و پارامتر `yearsOld`، یعنی سن خودرو بر حسب سال، را می‌گیرد.
تابع باید قیمت فروش مجدد خودرو را برگرداند.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
