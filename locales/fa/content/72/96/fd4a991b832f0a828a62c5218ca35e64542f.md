# درباره

## عملگرهای مقایسه

[عملگرهای مقایسه][comparison-operators] دو مقدار از یک نوع را با هم مقایسه می‌کنند و یک مقدار `Bool` (یعنی `true` یا `false`) برمی‌گردانند.
اگر بخواهید مقادیری با نوع‌های متفاوت را مقایسه کنید، کامپایلر خطا می‌دهد.

عملگرهای مقایسه‌ی استاندارد در Swift عبارت‌اند از:

| عملگر | توضیح | مثال |
| -------- | ------------------------ | --------------- |
| `==`     | برابر با                 | `1 == 1` («درست») |
| `!=`     | نابرابر با                 | `1 != 2` («درست») |
| `<`      | کمتر از                | `4 < 5`  («درست») |
| `<=`     | کمتر از یا برابر با    | `4 <= 4` («درست») |
| `>`      | بزرگ‌تر از                 | `3 > 1`  («درست») |
| `>=`     | بزرگ‌تر از یا برابر با | `2 >= 2` («درست») |

## دستورهای if و else

یک [دستور شرطی][conditional-statement] بسته به اینکه یک شرط به `true` یا `false` ارزیابی شود، کدی را اجرا می‌کند.
رایج‌ترین دستور شرطی، [دستور if][if] است که یک بلوک کد را فقط وقتی اجرا می‌کند که شرطش `true` باشد.
یک دستور `if` را با کلیدواژه‌ی `if` بنویسید؛ بعد از آن شرط می‌آید و سپس بلوک کد که داخل آکولاد قرار می‌گیرد:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

می‌توانید `if` را با یک بند `else` جفت کنید تا وقتی شرط `false` است، کد دیگری اجرا شود:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

برای بررسی چند شرط پشت سر هم، دستورها را با `else if` به هم زنجیر کنید.
یک دستور `if` به شاخه‌ی `else` نیاز ندارد، اما می‌توانید یکی اضافه کنید تا مواردی را پوشش دهید که هیچ‌کدام از شرط‌ها برقرار نیستند:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## عبارت‌های if

در Swift مدرن، دستورهای `if` را می‌توان به عنوان عبارت‌هایی هم به کار برد که یک مقدار تولید می‌کنند.
هر شاخه به یک مقدار ارزیابی می‌شود و همین کار، مقداردهی شرطی نتیجه‌ها را آسان می‌کند:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
