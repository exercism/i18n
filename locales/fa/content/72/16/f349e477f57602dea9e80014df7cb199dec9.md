# نصب

## گزینه‌های نصب

نسخه‌ی فعلی Unison برای کاربران Mac OS X، لینوکس ۶۴بیتی و Windows در دسترس است! امیدواریم اگر در حال امتحان کردن Unison هستید، بیایید و در انجمن Exercism یا در [Unison Discord](https://unison-lang.org/discord) با ما صحبت کنید. سؤال‌هایتان را بپرسید و مشکلاتی را که ممکن است ببینید گزارش دهید! می‌خواهیم هنگام شروع کار، تجربه‌ای گرم و مثبت داشته باشید! 😊

Unison را می‌توانید با [homebrew](https://brew.sh/)، [Nix](https://github.com/ceedubs/unison-nix/#usage) یا مستقیماً با بسته‌های باینری دانلود کنید. همه‌ی این گزینه‌های دانلود در [صفحه‌ی دستورهای نصب وب‌سایت ما](https://www.unison-lang.org/learn/quickstart/#installation-options) توضیح داده شده‌اند. بعد از اینکه UCM را نصب کردید، به اینجا برگردید!

### گزینه ۱: استفاده از Homebrew

اگر هنوز [homebrew را نصب نکرده‌اید](https://brew.sh/)، اول آن را نصب کنید.

سپس از خط فرمان این دستورها را وارد کنید:

```
brew tap unisonweb/unison
brew install unison-language
```

با این کار فایل اجرایی مدیر پایگاه کد Unison، یعنی `ucm`، نصب می‌شود. اگر از نسخه‌ی قبلی ارتقا می‌دهید، کافی است این کار را انجام دهید:

```
brew upgrade unison-language.
```

توجه: اگر در این مرحله از شما نام کاربری و رمز عبور GitHub خواسته شد، مطمئن شوید که unisonweb/unison را درست نوشته‌اید.

### گزینه ۲: نصب دستی برای کاربران Mac و Linux

[پیوندهای نصب دستی Linux و Mac اینجا ارائه شده‌اند](https://www.unison-lang.org/learn/quickstart/#installation-options) زیر بخش دانلود دستی مربوط به Linux و Mac.

شما در شل خود دستوری مانند این اجرا خواهید کرد، اما پیوند بالا به‌روزترین فایل باینری را در خود دارد:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### گزینه ۳: نصب دستی برای کاربران Windows

1. برای گرفتن بهترین نتیجه، برنامه‌ی ترمینال پیش‌فرض خود را روی «Windows Terminal» تنظیم کنید. در تنظیمات عبارت «Terminal» را جست‌وجو کنید، یا [این راهنما.](https://bit.ly/3IXwdlY) را دنبال کنید.
2. اگر مطمئن نیستید که از قبل آن را دارید، Git را نصب کنید:
  * با winget: `winget install --id Git.Git -e --source winget`
  * اگر از Windows 10 استفاده می‌کنید و winget ندارید، می‌توانید آن را از [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) نصب کنید و سپس دستور بالا را اجرا کنید.
3. [UCM را با پیوند داده‌شده در اینجا دانلود کنید](https://www.unison-lang.org/learn/quickstart/#installation-options) و آن را در جایی که خودتان انتخاب می‌کنید از حالت فشرده خارج کنید.
4. `ucm.exe` را اجرا کنید.

### گزینه ۴: نصب با Nix
به [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) بروید و دستورهای موجود در readme آنجا را دنبال کنید.

## پایگاه کد Unison خود را بسازید

برای راه‌اندازی یک پایگاه کد Unison در `$HOME/.unison` دستور `ucm` را اجرا کنید. Unison تعریف‌های تابع، نوع‌ها، فضای نام‌ها و غیره را همین‌جا ذخیره می‌کند. به‌طور پیش‌فرض، مدیر پایگاه کد Unison (که به اختصار «UCM» نامیده می‌شود) شروع به دانلود کتابخانه‌ی استاندارد به اسم `base` می‌کند که شما با آن کد Unison می‌نویسید. ممکن است کمی طول بکشد! 🕰

## گردش کار Unison

وقتی می‌خواهید کد Unison بنویسید، دستور `ucm` را اجرا می‌کنید تا مدیر پایگاه کد آغاز به کار کند. سپس UCM تغییرات هر فایلی با پسوند `.u` را در پوشه‌ای که از آن فراخوانی می‌شود رصد می‌کند. برای مثال، ممکن است توابعی را در فایلی به اسم `scratch.u` در پوشه‌ای به اسم `~/exercism/unison/my-exercise/` پیاده‌سازی کنید. باید با `cd` به `~/exercism/unison/my-exercise/` بروید و `ucm` را اجرا کنید. این کار تضمین می‌کند که UCM فایل `scratch.u` شما را برای تغییرات زیر نظر دارد.

اگر برایتان سؤال شد که `ucm` کدام پوشه را برای تغییرات فایل زیر نظر دارد، این موضوع هنگام شروع CLI در صفحه‌ی خوش‌آمد چاپ می‌شود.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[نکته‌های بیشتر درباره‌ی گردش کار را اینجا ببینید!](https://exercism.org/docs/tracks/unison/workflow)

## پشتیبانی ویرایشگر

برای نوشتن فایل‌های `.u` می‌توانید از هر ویرایشگر متنی استفاده کنید. Unison از [پشتیبانی از LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown) برخوردار است، بنابراین IDE محبوب شما می‌تواند در کارهایی مانند نمایش نوع‌ها هنگام نگه‌داشتن نشانگر و تکمیل خودکار کمک‌تان کند. چند ویرایشگر محبوب که از Unison پشتیبانی می‌کنند در ادامه آمده‌اند:

### Vim

با استفاده از [vim-plug](https://github.com/junegunn/vim-plug):

1. اگر هنوز [`vim-plug`](https://github.com/junegunn/vim-plug) را نصب نکرده‌اید، آن را نصب کنید.
2. مورد زیر را به فایل .vimrc خود اضافه کنید: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. دستور vim یعنی `:PlugInstall` را اجرا کنید.

برای اطلاعات بیشتر، از داخل vim دستور `:help unison` را اجرا کنید
یا [سند راهنمای آنلاین](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt) را ببینید.

### Atom
از کنسول، این را اجرا کنید:

```
apm install unisonweb/atom-unison
```

### VS Code

1. نمای Extensions را با کلیک روی نماد Extensions در Activity Bar کنار VS Code، یا با ⇧⌘X باز کنید.
2. عبارت «unison» را جست‌وجو کنید
3. [افزونه‌ی Unison برای VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison) را نصب کنید

### Emacs
[`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs) را نصب کنید.
