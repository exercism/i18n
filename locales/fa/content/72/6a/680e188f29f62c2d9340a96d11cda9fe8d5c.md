# اجرای testها

برای اجرای testهای یک تمرین، اسکریپت `<exercise>.test` را در پوشه‌ی تمرین اجرا کنید:

```bash
tclsh <exercise>.test
```

در بیشتر تمرین‌ها، همه‌ی testها به‌جز اولین test «skipped» می‌شوند.
این کار به شما، به‌عنوان توسعه‌دهنده، اجازه می‌دهد که از Test-Driven Development استفاده کنید: فقط به همان اندازه که برای گذراندن هر test یکی‌یکی لازم است، برنامه‌نویسی کنید.
برای بی‌اثر کردن دستورهای skip، متغیر محیطی `RUN_ALL` را پیش از اجرای مجموعه‌ی test روی یک مقدار معتبرِ «درست» در Tcl تنظیم کنید \[۱\]:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[۱\]: مقادیر «درست» و «غلط» در Tcl در صفحه‌ی man مربوط به تابع کتابخانه‌ی C با نام [Tcl_GetBoolean][bool] مستند شده‌اند.

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
