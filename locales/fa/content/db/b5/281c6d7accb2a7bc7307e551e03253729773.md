# Tests

tests را به چند روش می‌توان اجرا کرد.

## به‌صورت تعاملی از داخل Emacs

۱. فایل tests را باز کنید، `M-x eval-buffer RET`
۲. به‌صورت تعاملی و یکی‌یکی، با `M-x ert RET test-name RET`
۳. به‌صورت تعاملی و همه با هم، با `M-x ert RET t RET`
   توجه کنید که این دستور همه‌ی tests بارگذاری‌شده در Emacs را اجرا می‌کند!
۴. هر بار که تغییری دادید، پیش از اجرای tests دوباره `M-x eval-buffer RET` را اجرا کنید

اگر می‌خواهید فقط tests موجود در «بافر» جاری را اجرا کنید، می‌توانید این را به فایل `.emacs` یا `init.el` خود اضافه کنید:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

پس از راه‌اندازی مجدد Emacs:

۱. فایل tests را باز کنید
۲. `M-x my-eval-and-run-all-tests-in-buffer RET`

## از ترمینال

برای اجرای همه‌ی tests از ترمینال، در حالت batch، دستور `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit` را اجرا کنید.

دستور بالا کمی دست‌وپاگیر است، پس اگر دوست دارید:

۱. روی `$PATH` خود (احتمالاً در `~/bin`) فایلی به اسم `ert-run` بسازید
۲. محتوای فایل باید به این صورت باشد:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
۳. با `chmod +x ert-run` فایل را قابل اجرا کنید

باید بتوانید به‌سادگی `ert-run *-test.el` را فراخوانی کنید و tests را در حالت batch اجرا کنید.

## گزینه‌های دیگر

گزینه‌های دیگر را می‌توانید در مستندات بیابید: `C-h i m ert RET`.
