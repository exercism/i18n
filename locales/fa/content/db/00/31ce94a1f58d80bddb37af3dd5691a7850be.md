# مقدمه

مقادیر «منطقی» در Rust با نوع `bool` نمایش داده می‌شوند و مقدارشان می‌تواند `true` یا `false` باشد.

Rust از شش عملگر مقایسه پشتیبانی می‌کند: `==` (برابر)، `!=` (نابرابر)، `>` (بزرگ‌تر از)، `<` (کوچک‌تر از)، `>=` (بزرگ‌تر یا مساوی)، `<=` (کوچک‌تر یا مساوی). از آن‌ها می‌توان برای ارزیابی رابطه‌ی مقادیر غیرمنطقی به یک مقدار منطقی استفاده کرد.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

برخلاف برخی زبان‌های دیگر، `0` به معنای `false` نیست و مقدار غیرصفر به معنای `true` نیست.

Rust از دو عملگر منطقی پشتیبانی می‌کند: `||` (یا)، `&&` (و). این عملگرها تنها زمانی ارزیابی می‌شوند که عملوند سمت چپ از قبل نتیجه‌ی عبارت را تعیین نکرده باشد. یعنی `||` عملوند سمت راست خود را تنها زمانی ارزیابی می‌کند که عملوند سمت چپ به مقدار `false` ارزیابی شود و `&&` تنها زمانی که به مقدار `true` ارزیابی شود.
