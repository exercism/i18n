# مقدمه

## آرایه

کتابخانه‌ی هسته‌ی Cairo نوعی `Array` را پیاده‌سازی می‌کند.

این نوع شبیه آرایه‌های معمول در دیگر زبان‌های برنامه‌نویسی است، اما چند تفاوت کلیدی دارد:

- عنصرها را فقط می‌توان به‌طور کارآمد به انتهای نوع `Array` افزود و فقط می‌توان آن‌ها را به‌طور کارآمد از ابتدای آن حذف کرد.
- تنظیم دستی یک عنصر با استفاده از اندیس آرایه ممکن نیست.

می‌توان آرایه‌ها را با تابع `ArrayTrait::new` و همچنین ماکروی `array!` ساخت:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

می‌توان عنصرها را با تابع `ArrayTrait::append` به آرایه افزود:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

می‌توان عنصرها را با تابع `ArrayTrait::pop_front` از آرایه حذف کرد:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo همچنین نوع `Span` را معرفی می‌کند که مانند یک «عکس فوری» از `Array` عمل می‌کند.

هر `Array` را می‌توان با تابع `ToSpanTrait::span` به یک `Span` تبدیل کرد:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

تبدیل یک آرایه به `Span` بسیار کارآمد است، چون `Span` فقط یک ساختار داده است که به Cairo اجازه می‌دهد بخشی از آرایه را «ببیند» و به هیچ وجه آن را تغییر نمی‌دهد.

Cairo با تبدیل آرایه به `Span` اجازه می‌دهد عملیات بیشتری نسبت به آنچه مستقیماً روی `Array` مجاز است انجام شود، مثلاً حذف یک عنصر از ابتدای `Span`.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

توجه کنید که برای فراخوانی `pop_back` باید `one_to_four_span` را با کلیدواژه‌ی `mut` تغییرپذیر می‌کردیم؛ این فراخوانی `Span` را تغییر می‌دهد، چون بخشی از آرایه را که `Span` «می‌بیند» کوتاه‌تر می‌کند.
