# دستورالعمل‌ها

در این تمرین، وظیفه‌ی شما نوشتن نرم‌افزار یک دستگاه رمزنگاری است که با انجام تبدیل‌ها روی داده‌ها کار می‌کند. شما به روشی نیاز دارید که با آن بتوانید با ترکیب توابع ساده‌تر، توابع پیچیده را به‌صورت انعطاف‌پذیر بسازید.

برای هر وظیفه، یک «تابع بی‌نام» برگردانید که بتوان آن را از «حوزه‌ی فراخوانی» فراخوانی کرد.

همه‌ی توابع باید آرگومان‌هایی از نوع عدد صحیح بگیرند. اعداد صحیح برای انجام عملیات بیتی در Elixir هم مناسب‌اند.

## 1. یک جمع‌کننده بسازید

تابع `Secrets.secret_add/1` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و آرگومانِ داده‌شده به `secret_add` را به آن اضافه می‌کند.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. یک تفریق‌کننده بسازید

تابع `Secrets.secret_subtract/1` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و مقدار محرمانه‌ی داده‌شده به `secret_subtract` را از آن آرگومان کم می‌کند.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. یک ضرب‌کننده بسازید

تابع `Secrets.secret_multiply/1` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و آن را در مقدار محرمانه‌ی داده‌شده به `secret_multiply` ضرب می‌کند.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. یک تقسیم‌کننده بسازید

تابع `Secrets.secret_divide/1` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و آن را بر مقدار محرمانه‌ی داده‌شده به `secret_divide` تقسیم می‌کند.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

از تقسیم صحیح استفاده کنید تا خروجی با ورودی موردانتظار سایر توابع سازگار باشد.

## 5. یک تابع `and` بسازید

تابع `Secrets.secret_and/1` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و یک عملیات بیتی `and` را روی آن و مقدار محرمانه‌ی داده‌شده به `secret_and` انجام می‌دهد.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. یک تابع `xor` بسازید

تابع `Secrets.secret_xor/1` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و یک عملیات بیتی `xor` را روی آن و مقدار محرمانه‌ی داده‌شده به `secret_xor` انجام می‌دهد.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. یک ترکیب‌کننده‌ی توابع بسازید

تابع `Secrets.secret_combine/2` را پیاده‌سازی کنید. این تابع باید تابعی برگرداند که یک آرگومان می‌گیرد و دو تابعِ داده‌شده به `secret_combine` را به ترتیب روی آن اعمال می‌کند.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
