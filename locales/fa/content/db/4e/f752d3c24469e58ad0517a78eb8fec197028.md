# مقدمه

## اسم مستعار نوع

### اسم مستعار نوع

در Gleam می‌توان از اسم مستعار نوع استفاده کرد تا برای یک نوع موجود که در غیر این صورت نوشتنش دشوار است، اسمی مناسب در نظر گرفت.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

وقتی با `pub type` نوشته شود، این اسم مستعار بیرون از ماژولی که در آن تعریف شده هم قابل استفاده است. اگر `pub` حذف شود، اسم مستعار خصوصی می‌شود و نمی‌توان در ماژول‌های دیگر به آن ارجاع داد.

## دیکشنری‌ها

دیکشنری‌ها در Gleam ساختار داده‌ای برای ذخیره‌ی اطلاعات در قالب جفت‌های کلید-مقدار هستند. در زبان‌های دیگر، این ساختار ممکن است با اسم آرایه‌های انجمنی، هش یا دیکشنری هم شناخته شود.

برای کلیدها و مقدارهای یک دیکشنری می‌توان از هر نوعی استفاده کرد. دیکشنری‌ها هم ترتیب درایه‌هایشان را هنگام دسترسی یا بازگرداندن تضمین نمی‌کنند.

### کار با دیکشنری‌ها

دیکشنری‌ها با استفاده از توابع ماژول `gleam/dict` ساخته و دستکاری می‌شوند.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
