# درباره

[بیت‌استرینگ‌ها][bitstring] به برنامه‌نویسان امکان می‌دهند تا به‌طور مؤثر با داده‌های دودویی کار کنند.

- می‌توانید بیت‌استرینگ‌ها را به‌شکلی زیبا و با استفاده از [شکل خاص `<<>>`][bitstring-form] بسازید.

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- می‌توانید با استفاده از شکل `<<>>` تطبیق دهید و از همان تطبیق برای [تجزیه‌ی داده‌های دودویی][bitstring-matching] استفاده کنید.

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- می‌توانید با استفاده از `::bitstring` روی باقی‌مانده‌ی بیت‌استرینگ تطبیق دهید.

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- *نوع* داده‌ی دودویی نوع خاصی از بیت‌استرینگ است که تعداد بیت‌های آن بر ۸ بخش‌پذیر است.
  - همه‌ی داده‌های دودویی بیت‌استرینگ هستند، اما همه‌ی بیت‌استرینگ‌ها داده‌ی دودویی نیستند.
- Elixir برای کار با [لیترال‌های عدد صحیح][integer-literal] در شکل‌های مختلف شکر نحوی فراهم می‌کند:
  - `0b1000001 = ?A = 65`

[bitstring]: https://hexdocs.pm/elixir/binaries-strings-and-charlists.html#bitstrings
