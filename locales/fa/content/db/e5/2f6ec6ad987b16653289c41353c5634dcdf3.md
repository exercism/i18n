# راهنمایی‌ها

## 1. خودتان را معرفی کنید

تابع `introduce` باید مقدار موجود در `player.Name` را از حالت «پوشیده» خارج کند.
بهتر است از [تابع `Options.defaultValue`][defaultvalue] استفاده کنید تا `player.Name` را زمانی که `Some` است به مقدار «پوشیده»اش تبدیل کنید و زمانی که `None` است به مقدار پیش‌فرض مورد نیاز.

## 2. سازوکار احیا را پیاده‌سازی کنید

تابع `revive` باید یا `Some <player>` برگرداند یا `None`؛ در اینجا `<player>` یک رکورد `Player` است که ممکن است برخی فیلدهایش تغییر کرده باشند.

## 3. سازوکار اجرای طلسم را پیاده‌سازی کنید

بهتر است از یک عبارت `match` استفاده کنید تا هر دو حالت `Some` و `None` را پوشش دهید، همان‌طور که در مثال زیر آمده است:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
