# دستورالعمل‌ها

در این تمرین، یک ترازو را با کیلوگرم به عنوان یکا مدل‌سازی می‌کنید.

شما ۶ وظیفه دارید که هر کدام مستلزم پیاده‌سازی یک یا چند ویژگی است:

## 1. امکان تعیین دقت برای ترازو

برای پاسخ به نیازهای مختلف، اجازه می‌دهیم هر ترازو با یک دقت سفارشی‌سازی شود (تعداد ارقام بعد از جداکننده‌ی اعشار).
کلاس `WeighingMachine` را طوری پیاده‌سازی کنید که یک ویژگی `Precision` فقط‌خواندنی داشته باشد که با آرگومان `precision` سازنده مقداردهی می‌شود:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. امکان تنظیم وزن روی ترازو

ویژگی `WeighingMachine.Weight` را طوری پیاده‌سازی کنید که وزن هم قابل خواندن _و_ هم قابل تنظیم باشد:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. اطمینان از رد شدن وزن ورودی منفی

واضح است که وزن کسی نمی‌تواند منفی باشد.
به ویژگی `WeighingMachine.Weight` اعتبارسنجی اضافه کنید تا هنگام تلاش برای تنظیم آن روی یک وزن منفی، `ArgumentOutOfRangeException` پرتاب شود:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. امکان اعمال «تنظیم تار» روی ترازو

تنظیم تار می‌تواند هر مقداری باشد (حتی منفی، یا مقداری که وزن نمایش‌داده‌شده را منفی کند).
ویژگی `WeighingMachine.TareAdjustment` را پیاده‌سازی کنید تا تنظیم تار قابل تنظیم باشد:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. اطمینان از داشتن تنظیم تار پیش‌فرض در ترازو

پس از آزمایش‌های کامل، مشخص شد که به دلیل یک مشکل در تولید، همه‌ی ترازوها تمایل دارند وزن را به اندازه‌ی `5` بیش از واقع تخمین بزنند.
ویژگی `WeighingMachine.TareAdjustment` را طوری تغییر دهید که مقدار پیش‌فرضش `5` باشد.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. امکان بازیابی وزن

ویژگی `WeighingMachine.DisplayWeight` را پیاده‌سازی کنید که باید رشته‌ای برگرداند که وزن را پس از اعمال تنظیم تار، با دقت درست و همراه با یکا نشان دهد.
توجه کنید که:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
