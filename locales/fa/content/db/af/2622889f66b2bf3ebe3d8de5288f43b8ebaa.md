# دستورالعمل‌ها

با یک نرخ روزانه‌ی سرسام‌آور وسوسه شده‌اید که دوباره به Hyperia (با آن تورم بالا) برگردید.

بانک مرکزی در فکر آن است که دلار آمریکا را به‌عنوان واحد پول دوم معرفی کند، بنابراین همه‌ی سیستم‌های حسابداری باید طوری تطبیق داده شوند که چند واحد پول را پشتیبانی کنند.

از شما خواسته شده است که شیء مقدار ارز را پیاده‌سازی کنید.

## 1. امکان آزمودن برابری مقدار ارز را فراهم کنید

لطفاً ساختار `CurrencyAmount` را طوری تغییر دهید که برابری را پشتیبانی کند. اگر دو ساختار مقدار ارز واحد پول یکسانی نداشته باشند («USD» یا «HD»)، باید یک نمونه از `ArgumentException` پرتاب شود.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. مقادیر ارز را مقایسه کنید

لطفاً ساختار `CurrencyAmount` را طوری تغییر دهید که مقایسه‌ها (`>` و `<` فقط) را پشتیبانی کند. اگر دو ساختار مقدار ارز واحد پول یکسانی نداشته باشند («USD» یا «HD»)، باید یک نمونه از `ArgumentException` پرتاب شود.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. مقادیر ارز را جمع و تفریق کنید

لطفاً ساختار `CurrencyAmount` را طوری تغییر دهید که جمع و تفریق حسابی (`+` و `-` فقط) را پشتیبانی کند. اگر دو ساختار مقدار ارز واحد پول یکسانی نداشته باشند («USD» یا «HD»)، باید یک نمونه از `ArgumentException` پرتاب شود.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. مقادیر ارز را ضرب و تقسیم کنید

لطفاً ساختار `CurrencyAmount` را طوری تغییر دهید که ضرب و تقسیم حسابی (`*` و `/` فقط) را پشتیبانی کند.

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. مقدار ارز را به `double` تبدیل کنید

لطفاً ساختار `CurrencyAmount` را طوری تغییر دهید که بتوان یک نمونه را به‌صورت صریح به `double` تبدیل نوع کرد.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. مقدار ارز را به `decimal` تبدیل کنید

لطفاً ساختار `CurrencyAmount` را طوری تغییر دهید که یک نمونه به‌صورت ضمنی به `decimal` تبدیل شود.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
