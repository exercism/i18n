# اعلان نوع

اعلان نوع در PHP در زمان اجرا برای آرگومان‌های تابع، مقادیر بازگشتی و ویژگی‌های کلاس تأیید نوع فراهم می‌کند.
روی توابع می‌توان نوع بازگشتی `void` را اضافه کرد تا نشان دهد هیچ مقداری از تابع بازگشت داده نمی‌شود.
انواع اعلان‌شده همچنین به‌عنوان تأییدهایی در زمان اجرا عمل می‌کنند که نشان می‌دهند تابع پاسخی با نوع مناسب برمی‌گرداند.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## اجتماع نوع‌ها

اگر آرگومان تابع، مقدار بازگشتی یا ویژگی کلاس بتواند بیش از یک نوع باشد، می‌توان یک «اجتماع نوع» اعلان کرد.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## انواع مختلط

هنگام کار با کد، گاهی نمی‌توان نوع را مشخص کرد.
از PHP ۸.۰ به بعد، نوعی راه فرار به نام `mixed` فراهم شده است.
`mixed` معادل یک اجتماع نوع متشکل از `object|resource|array|string|float|int|bool|null` است.
