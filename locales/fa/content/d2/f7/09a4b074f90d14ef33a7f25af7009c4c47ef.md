# راهنمایی‌ها

## کلی

- سخنرانی [عالی][phantom-builder-pattern] یِرون اِنگلز را درباره‌ی الگوی سازنده‌ی فانتوم ببینید

## 1. یک جانگهدار برای صندوق‌های گنج فراهم کنید

- `Chest` می‌تواند همان `TreasureChest` باشد؛ یک واریانت تکی که یک نوع فانتوم به آن اضافه شده است
- جانگهدار `Chest todo` آرگومان‌های نوع کافی ندارد و نوع فانتوم آن جا افتاده است
- نوع فانتوم باید یک رکورد باشد تا بتوان آن را گسترش داد
- نوع شروع، `Chest treasure {}` بدون قید است و نوع نهایی، `Chest treasure { conditions | securePassword : (), uniqueTreasure : () }` است که کاملاً وارسی شده است
- برای رسیدن از نوع شروع به نوع دیگر، شرط‌های `securePassword : ()` و `uniqueTreasure : ()` به‌طور مستقل توسط `secureChest` و `uniqueTreasures` اضافه می‌شوند

## 2. صندوق‌های امن را انتخاب کنید

- می‌توانید روی `Chest` در آرگومان تابع تطبیق الگو انجام دهید
- می‌توانید از تابع [`String.length`][string-length] برای اعتبارسنجی گذرواژه استفاده کنید
- شرط `securePassword : ()` از امضای نوع اضافه می‌شود، نه از بدنه‌ی تابع
- نمی‌توانید یک `Chest` بدون قید را داخل `Just` بگذارید و انتظار داشته باشید نوعش تغییر کند. باید با سازنده‌ی `Chest` یک مقدار جدید بسازید

## 3. گنج‌های یکتا را انتخاب کنید

- هیچ تابع `List.unique`ای وجود ندارد که بتوانید از آن استفاده کنید؛ باید تابع خودتان را بسازید
- یک رویکرد ممکن این است که از `List.filterMap` همراه با یک تابع کمکی با نوعی مشابه `secureChest` استفاده کنید
- شرط `uniqueTreasure : ()` از امضای نوع اضافه می‌شود، نه از بدنه‌ی تابع
- نمی‌توانید یک `Chest` بدون قید را داخل `Just` بگذارید و انتظار داشته باشید نوعش تغییر کند. باید با سازنده‌ی `Chest` یک مقدار جدید بسازید

## 4. از محصول نهایی لذت ببرید

- `makeTreasureChest` باید از سازنده‌ی نوع `TreasureChest` استفاده کند
