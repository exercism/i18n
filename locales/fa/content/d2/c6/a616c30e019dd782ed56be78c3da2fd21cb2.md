# عملگر سه‌گانه

عملگر سه‌گانه نحوه‌ی نگارش جایگزینی برای انجام یک مقایسه‌ی `if..else..` و برگرداندن یک مقدار فراهم می‌کند.

## نحوه‌ی نگارش

PHP یک دستور `if` فراهم می‌کند که می‌توان بر اساس «درست‌بودن» یک شرط، یک کار را ارزیابی کرد.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

در عوض، عملگر سه‌گانه می‌تواند همان عملیات را نمایش دهد:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

نحوه‌ی نگارش این مقایسه کوتاه است و به صورت `(condition) ? (evaluate if true) : (evaluate if false);` نمایش داده می‌شود.

## مزایا

مزیت آشکار استفاده از عملگر سه‌گانه کوتاهی است؛ نوشتن عبارت شرطی در مقایسه با یک دستور `if..else..` کوتاه است، اما مزایای دیگری هم وجود دارد:

- یک عبارت است که می‌توان از آن درون عبارت دیگری استفاده کرد
- امکان «ارزیابی تنبل» را برای هر شاخه فراهم می‌کند.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  در این مثال، اگر پاسخ دقیق لازم نباشد، محاسبه‌ی پرهزینه فراخوانی نمی‌شود.

## معایب

عملگرهای سه‌گانه چندین عیب دارند که باعث می‌شود توجه به استفاده از آن‌ها مهم باشد:

- خواندن یک عملگر سه‌گانه می‌تواند دشوارتر باشد، چون به تفسیر نمادها وابسته است نه استفاده از «کلیدواژه‌ها».
- ممکن است یک عملگر سه‌گانه به‌طور ناخواسته باعث ایجاد باگ شود، چون عملگر سه‌گانه در PHP برخلاف بیشتر زبان‌های امروزی (مثلاً C، Java، JavaScript) چپ‌شرکت‌پذیر است.
- عبارت ارزیابی‌شده در شاخه‌های «درست» یا «غلط» باید مقداری برگرداند.

## حتی کوتاه‌تر

نحوه‌ی نگارش عملگر سه‌گانه را می‌توان بیشتر کوتاه کرد: `(condition) ?: (evaluate if falsey)`.
یکی از این کاربردها، فراهم کردن یک مقدار جایگزین در یک عبارت است:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

این گاهی با نام _عملگر الویس_ (`?:`) نیز شناخته می‌شود.
