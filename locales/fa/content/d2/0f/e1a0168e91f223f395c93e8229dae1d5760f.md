# مقدمه

یک `Iterator` در Gleam از این نظر شبیه لیست است که مجموعه‌ای مرتب از مقدارهاست و همه‌ی مقدارهایش از یک نوع‌اند. تفاوتش با لیست در این است که تنبل است، یعنی همه‌ی مقدارهایش را یکجا در حافظه نگه نمی‌دارد و به‌جایش آن‌ها را همان موقع که لازم شد محاسبه می‌کند.

این وقتی مفید است که با دنباله‌هایی سروکار داشته باشیم که بسیار بزرگ‌اند یا حتی بینهایت‌اند، چون اجازه می‌دهد حتی وقتی حافظه‌ی آزاد کافی برای نگه‌داشتن همه‌شان در یک لحظه نداریم هم با آن‌ها کار کنیم.

ماژول `gleam/iterator` هم نوع `Iterator` را تعریف می‌کند و هم توابع کار با تکرارگرها را.

بسیاری از توابع لیست‌ها برای تکرارگرها هم وجود دارند، مثل `map`، `filter` و `take`. این توابع، تکرارگر برمی‌گردانند، پس تا وقتی تکرارگر مصرف نشده باشد، هیچ کاری واقعاً انجام نمی‌شود.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

از تابع `unfold` می‌توان برای ساختن تکرارگر از تابعی استفاده کرد که مکرراً فراخوانی می‌شود تا مقدار بعدی دنباله را تولید کند.

اینجا از تابع `unfold` برای ساختن تکرارگری استفاده شده که دنباله‌ی فیبوناچی را تولید می‌کند:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

دنباله‌ی اینجا بینهایت است، پس پیش از جمع‌آوری مقدارها در یک لیست، از تابع `take` استفاده می‌شود تا آن را متناهی کند. اگر `to_list` روی یک تکرارگر بینهایت فراخوانی شود، برنامه آن‌قدر اجرا می‌شود تا حافظه تمام شود و از کار بیفتد.
