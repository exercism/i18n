# ماشین‌حساب آشپزخانه

## داستان

این داستان به کاوش در [تاپل‌ها][type-tuple] در یک زبان کمک می‌کند.

فرض اصلی این است که مواد اولیه‌ی آشپزخانه اغلب به شکل‌های نامأنوسی اندازه‌گیری می‌شوند و بسته به مقدار یا ابزارهای در دسترس، به تبدیل‌های متفاوتی نیاز دارند. از تاپل‌ها استفاده می‌شود تا به بخش عددی اندازه‌گیری [تایپ اردکی][concept-duck-typing] بدهند.

این داستان تبدیل پایه‌ی مقادیر را با استفاده از اعداد ممیز شناور بررسی می‌کند.

### تبدیل‌ها

| From               | To      |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 cup              | 240mL   |
| 1 fluid ounce (US) | 29.57mL |
| 1 teaspoon         | 5 mL    |
| 1 tablespoon       | 15 mL   |

## کارها

این بخش باید به دانش‌آموزان نشان دهد که چگونه از موارد زیر استفاده کنند:

- تاپل
- تاپل به عنوان اطلاعات گروه‌بندی‌شده
- گرفتن مقدار از یک تاپل با استفاده از اندیس عنصر
- گرفتن مقدار از یک تاپل با استفاده از تطبیق الگو
- ساختن تاپل‌های جدید
