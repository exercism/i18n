# راهنمایی

## کلی

- مستندات بسته‌ی `Random` را می‌توانید [اینجا][random-module] پیدا کنید

## 1. از پایان شروع کنید

- از تابع [`Random.constant`][random-constant] استفاده کنید

## 2. با سرکه نمی‌توان مگس گرفت

- برای تولید گنج‌ها از تابع [`Random.uniform`][random-uniform] استفاده کنید
- برای بسته‌بندی گنج از تابع [`Random.map`][random-map] استفاده کنید

## 3. شاخه زدن

- برای تولید مقداری بین ۲ و ۴ از تابع [`Random.int`][random-int] استفاده کنید
- می‌توانید به این مقدار دسترسی داشته باشید و با تابع [`Random.andThen`][random-andThen] یک `Branch` بسازید
- برای تولید شاخه‌ها از تابع [`Random.list`][random-list] استفاده کنید
- برای بسته‌بندی شاخه‌ها از تابع [`Random.map`][random-map] استفاده کنید

## 4. هزارتوهای شگفت‌انگیز

- برای تولید توزیع نامتوازنی از نتایج، از تابع [`Random.weighted`][random-weighted] استفاده کنید
- برای استفاده‌ی بازگشتی از یک مولد، از تابع [`Random.lazy`][random-lazy] استفاده کنید
- درباره‌ی تعریف ساختارهای داده‌ی بازگشتی بیشتر [اینجا][bad-recursion] بخوانید
- اگر در نهایت یک مولد تودرتوی `Generator (Generator Maze)` تعریف کردید، می‌توانید از [`Random.andThen`][random-andThen] همراه با تابع `identity` برای تخت کردن آن استفاده کنید

## 5. باید عمیق‌تر برویم

- برای تولید بن‌بست‌ها یا اتاق‌ها در عمق `0` از تابع [`Random.uniform`][random-uniform] استفاده کنید
- اگر در نهایت یک مولد تودرتوی `Generator (Generator Maze)` تعریف کردید، می‌توانید از [`Random.andThen`][random-andThen] همراه با تابع `identity` برای تخت کردن آن استفاده کنید
- برای استفاده‌ی بازگشتی از یک مولد، از تابع [`Random.lazy`][random-lazy] استفاده کنید
- درباره‌ی تعریف ساختارهای داده‌ی بازگشتی بیشتر [اینجا][bad-recursion] بخوانید
