# مقدمه

## ماژول

کد Gleam در قالب «ماژول» سازماندهی می‌شود، و هر فایل یک ماژول Gleam است.

تا اینجا توابع را با نحوه‌ی نگارش `pub fn` نوشته‌ایم، که تابعی را تعریف می‌کند که به‌صورت عمومی برای ماژول‌های دیگر در دسترس است. توابعی که با `fn` تعریف می‌شوند، نسبت به ماژولی که در آن تعریف شده‌اند خصوصی هستند و ماژول‌های دیگر نمی‌توانند از آن‌ها استفاده کنند.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

ماژول‌های Gleam اسم دارند، و اسم آن‌ها بر اساس مسیر فایلشان درون پوشه‌ی `src` یا `test` تعیین می‌شود.

برای مثال، ماژولی که در `src\geometry\rectangle.gleam` (در Windows) یا `src/geometry/rectangle.gleam` (در سیستم‌عامل‌های شبیه UNIX) تعریف شود، اسمش `geometry/rectangle` خواهد بود.

## وارد کردن توابع از ماژول‌های دیگر

دسترسی به توابع تعریف‌شده در ماژول‌های دیگر از طریق «وارد کردن» انجام می‌شود.
وقتی آن ماژول را وارد می‌کنید، همه‌ی توابعی که آن ماژول در دسترس قرار داده است قابل دسترسی می‌شوند.
اما نحوه‌ی دسترسی به آن‌ها بسته به این که ماژول چگونه وارد شود فرق می‌کند.

وارد کردن با پیشوند، حالت پیش‌فرض است، و دسترسی به تابعی در چنین ماژولی (برای مثال تابع `map` در ماژول `gleam/list`) با قرار دادن اسم ماژول به‌عنوان پیشوند انجام می‌شود (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

به‌طور پیش‌فرض، اسمی که برای اشاره به ماژول به کار می‌رود آخرین بخش اسم ماژول است، در این مورد `int`، اما می‌توان این را با استفاده از کلیدواژه‌ی `as` تغییر داد.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

وارد کردن بدون پیشوند، دسترسی مستقیم به توابع در دسترس قرار گرفته در آن ماژول را بدون پیشوند گذاشتن ممکن می‌کند.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

وارد کردن با پیشوند ترجیح داده می‌شود، چون برای خواننده روشن‌تر می‌کند که تابع از کجا می‌آید و از تداخل اسم‌ها جلوگیری می‌کند.


## کتابخانه‌ی استاندارد

Gleam یک «کتابخانه‌ی استاندارد» غنی و خوب‌مستند دارد. مستندات به‌صورت آنلاین در [hexdocs.pm/gleam_stdlib][docs] در دسترس است. این لینک را یک جایی ذخیره کنید؛ از آن زیاد استفاده خواهید کرد!

بیشتر انواع داده‌ی توکار ماژول متناظری دارند که توابعی برای کار با آن نوع داده ارائه می‌دهد؛ مثلاً ماژول `gleam/int` برای اعداد صحیح، ماژول `gleam/string` برای رشته‌ها، ماژول `gleam/list` برای لیست‌ها و به همین ترتیب.

[docs]: https://hexdocs.pm/gleam_stdlib/
