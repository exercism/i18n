# راهنما

## کلی

- یک [مقدار صحیح][integers] را می‌توان به‌صورت یک یا چند رقم پشت‌سرهم تعریف کرد.
- مقدارهای [رشته][string] دنباله‌ای از کاراکترها هستند که بین دو علامت نقل‌قول دوتایی قرار می‌گیرند.

## 1. زمان مورد انتظار فر را بر حسب دقیقه تعریف کنید

- باید یک [تابع][functions] بدون هیچ آرگومانی تعریف کنید.
- باید یک [عدد صحیح][integers] برگردانید.

## 2. زمان باقی‌مانده‌ی فر را بر حسب دقیقه محاسبه کنید

- باید یک [تابع][functions] با یک آرگومان تعریف کنید.
- باید از داخل تابع مقداری برگردانید.
- آرگومان تابع یک [عدد صحیح][integers] است.
- می‌توانید از [عملگر ریاضی تفریق][operators] برای کم کردن مقادیر استفاده کنید.

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

- باید یک [تابع][functions] با یک آرگومان تعریف کنید.
- باید از داخل تابع مقداری برگردانید.
- آرگومان تابع یک [عدد صحیح][integers] است.
- می‌توانید از [عملگر ریاضی ضرب][operators] برای ضرب کردن مقادیر استفاده کنید.

## 4. زمان کل کار را بر حسب دقیقه محاسبه کنید

- باید یک [تابع][functions] با دو آرگومان تعریف کنید.
- باید یک عدد صحیح را از داخل تابع برگردانید.
- آرگومان تابع یک [عدد صحیح][integers] است.
- می‌توانید یکی از توابع دیگری را که قبلاً تعریف کرده‌اید فراخوانی کنید.
- می‌توانید از [عملگر ریاضی جمع][operators] برای جمع کردن مقادیر استفاده کنید.

## 5. اعلانی بسازید که اعلام کند لازانیا آماده است

- باید یک [تابع][functions] بدون هیچ آرگومانی تعریف کنید.
- باید یک [رشته][string] برگردانید.
