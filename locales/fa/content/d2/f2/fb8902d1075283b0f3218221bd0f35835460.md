# درباره

در Gleam توابع درجه‌یک داریم، یعنی توابع مقادیر معمولی هستند که می‌توان آن‌ها را به متغیرها نسبت داد، به‌عنوان آرگومان به تابع دیگری پاس داد و از توابع دیگر بازگرداند.

یک تابع نام‌دار که در یک ماژول تعریف شده باشد را می‌توان با اسمش صدا زد.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam توابع بی‌نام هم دارد، یعنی توابعی که داخل توابع دیگر تعریف می‌شوند.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

نوع یک تابع با نحوه‌ی نگارشی مشابه توابع بی‌نام نوشته می‌شود. نوع تابعی که یک `Int` و یک `Float` می‌گیرد و یک `Int` برمی‌گرداند، این‌طور نوشته می‌شود:

```gleam
fn(Int, Float) -> Int
```

توابع بی‌نام می‌توانند به متغیرهایی ارجاع دهند که هنگام تعریف‌شدنشان در حوزه‌ی دید بوده‌اند؛ همین ویژگی آن‌ها را به یک _بستار_ تبدیل می‌کند.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

نحوه‌ی نگارش _گرفتن تابع_ یک کوتاه‌نویسی راحت برای ساختن توابع بی‌نامی است که یک آرگومان را به یک تابع می‌دهند. این دو عبارت معادل هم هستند:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
