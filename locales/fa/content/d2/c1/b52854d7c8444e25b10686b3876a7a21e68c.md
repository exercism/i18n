# مقدمه

## اعداد صحیح

اعداد صحیح اعدادی کاملاند که به مجموعه‌ی `{..., -2, -1, 0, 1, 2, ...}` تعلق دارند.
بیشینه و کمینه‌ی مقدار یک عدد صحیح به سیستمی بستگی دارد که PHP در آن اجرا می‌شود.
معمولاً در بیشتر سیستم‌های مدرن، عدد صحیح یک مقدار ۶۴ بیتی است، یعنی می‌تواند از `-9_223_372_036_854_775_808` تا `9_223_372_036_854_775_807` را، با احتساب دو سر بازه، نمایش دهد.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

می‌توانید مقادیر صحیح ثابت را به مبنایی جز ۱۰ و با استفاده از یک پیشوند مبنا بنویسید:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> برگرفته از [مستندات][syntax] PHP

## اعداد ممیز شناور

از اعداد ممیز شناور در PHP برای نمایش زیرمجموعه‌ای از اعداد حقیقی استفاده می‌شود.
این اعداد با یک یا چند رقم شروع می‌شوند که با یک جداکننده‌ی اعشار از یکدیگر جدا شده‌اند.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### دام‌های رایج

همه‌ی اعداد و عملیات حسابی را نمی‌توان با اعداد ممیز شناور انجام داد.
استفاده از اعداد ممیز شناور برای نمایش دلار و سنت می‌تواند به خطاهای گرد کردن منجر شود.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## عملگرهای حسابی

PHP تعدادی عملگر برای انجام عملیات حسابی فراهم می‌کند. PHP در عملگرهای حسابی خود از ترتیب استاندارد ریاضی عملیات پیروی می‌کند. عملگرهایی که PHP فراهم می‌کند عبارت‌اند از:

* اتحاد (+)
* نقیض (-)
* جمع (+)
* تفریق (-)
* ضرب (*)
* تقسیم (/)
* باقیمانده (%)
* توان (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
