# مقدمه

«تطبیق الگو» فرایندی است که در آن بر اساس مطابقت یک مقدار با الگوهای داده‌شده و احتمالاً تودرتو، شاخه‌بندی می‌کنیم. در Haxe، **تطبیق الگو** با استفاده از عبارت `switch` و عبارت‌های `case` انجام می‌شود.

به این ساختار داده توجه کنید:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- الگوها همیشه از بالا به پایین مطابقت داده می‌شوند.
- بالاترین الگویی که با مقدار ورودی مطابقت داشته باشد، عبارت آن اجرا می‌شود.
- الگوی `_` با هر مقداری مطابقت دارد، بنابراین `case _:` معادل `default:` است.

## تطبیق enum

enumها را می‌توان به‌طور طبیعی با سازنده‌شان تطبیق داد:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
