# درباره

Scala یک زبان برنامه‌نویسی است که همراه شما رشد می‌کند: از اسکریپت‌های کوچک تا برنامه‌های بزرگ چندسکویی.

Scala برنامه‌نویسی شیءگرا و تابعی را در یک زبان مختصر و سطح‌بالا با هم ترکیب می‌کند. انواع ایستای Scala به پیشگیری از باگ در برنامه‌های پیچیده کمک می‌کنند و محیط‌های اجرایی JVM، JavaScript و Native آن به شما امکان می‌دهند سیستم‌هایی با کارایی بالا بسازید، با دسترسی آسان به اکوسیستم‌های عظیم کتابخانه‌ها.

* ویژگی‌ها
    * قابلیت همکاری با JVM: Scala روی JVM اجرا می‌شود، بنابراین پشته‌های Java و Scala را می‌توان برای یکپارچگی یکدست با هم ترکیب کرد.
    * قابلیت همکاری با JS و Native: Scala به لطف [Scala.js](https://www.scala-js.org/) و [Scala Native](https://github.com/scala-native/scala-native) می‌تواند در مرورگر و روی دستگاه‌های بومی اجرا شود.
    * استنتاج نوع: Scala به صورت ایستا نوع‌دهی شده است. با این حال، Scala استنتاج نوع را فراهم می‌کند تا بار یک سیستم نوعی پیشرفته را سبک کند.
    * شیءگرا: Scala از این نظر یک زبان کاملاً شیءگرا است که هر مقدار یک شیء است. انواع داده و رفتارهای اشیا با کلاس‌ها و صفت‌ها توصیف می‌شوند. انتزاع‌های کلاس از طریق زیرکلاس‌بندی و از طریق سازوکاری انعطاف‌پذیر مبتنی بر mixin گسترش می‌یابند تا از مشکلات وراثت چندگانه پرهیز شود.
    * تابعی: Scala از این نظر یک زبان تابعی هم هست که هر تابع یک مقدار است. Scala نحوه‌ی نگارشی سبک برای تعریف توابع بی‌نام فراهم می‌کند، از توابع مرتبه‌بالا پشتیبانی می‌کند، امکان تودرتویی توابع را می‌دهد و از کارینگ پشتیبانی می‌کند. کلاس‌های case اسکالا و پشتیبانی درون‌ساخت آن از تطبیق الگو، انواع جبری را که در بسیاری از زبان‌های برنامه‌نویسی تابعی به کار می‌روند مدل‌سازی می‌کنند. اشیای تک‌نمونه راهی راحت برای گروه‌بندی توابعی فراهم می‌کنند که عضو یک کلاس نیستند.
    * هم‌روندی و توزیع: از عملیات داده‌موازی روی مجموعه‌ها استفاده کنید، از اکتورها برای هم‌روندی و توزیع، یا از Futureها برای برنامه‌نویسی ناهمگام.
