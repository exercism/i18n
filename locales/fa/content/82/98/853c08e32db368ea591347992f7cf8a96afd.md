# دستورالعمل‌ها

الیس به‌عنوان یک جادوگر تازه‌کار باید چند مبنای اولیه را تمرین کند. او یک دسته کارت دارد که می‌خواهد با آن‌ها کار کند.

برای اینکه کارها کمی راحت‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند، بنابراین دسته‌ی کارت‌هایش را می‌توان با یک آرایه از اعداد نمایش داد. موقعیت یک کارت مشخص با اندیس آن در آرایه متناظر است. یعنی موقعیت ۰ به کارت اول اشاره دارد، موقعیت ۱ به کارت دوم و به همین ترتیب.

<!-- prettier-ignore-start -->
~~~~exercism/note
همه‌ی توابع به‌جز دو تابع باید آرایه‌ی کارت‌ها را به‌روزرسانی کنند و سپس آرایه‌ی تغییر‌یافته را برگردانند. این روشی رایج برای کار کردن است که به الگوی Builder معروف است و به شما امکان می‌دهد توابع را به‌خوبی به‌صورت زنجیره‌ای به هم وصل کنید.

دو استثنا عبارتند از `getItem` که باید کارت موجود در موقعیت داده‌شده را برگرداند و `checkSizeOfStack` که اگر اندازه‌ی داده‌شده مطابقت داشته باشد باید `true` را برگرداند.
~~~~

## 1. یک کارت را از دسته بیرون بیاورید

برای برداشتن یک کارت، کارت موجود در اندیس `position` را از دسته‌ی داده‌شده برگردانید.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. یک کارت را در دسته تعویض کنید

کمی تردستی کنید و کارت موجود در اندیس `position` را با کارت جایگزین داده‌شده عوض کنید.
دسته‌ی تنظیم‌شده را برگردانید.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. یک کارت را در بالای دسته درج کنید

با درج یک کارت جدید در بالای دسته، کاری کنید که یک کارت ظاهر شود.
دسته‌ی تنظیم‌شده را برگردانید.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. یک کارت را از دسته حذف کنید

با حذف کارت موجود در `position` داده‌شده از دسته، کاری کنید که یک کارت ناپدید شود.
دسته‌ی تنظیم‌شده را برگردانید.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. کارت بالای دسته را حذف کنید

با حذف کارت بالای دسته، کاری کنید که یک کارت ناپدید شود.
دسته‌ی تنظیم‌شده را برگردانید.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. یک کارت را در پایین دسته درج کنید

با درج یک کارت جدید در پایین دسته، کاری کنید که یک کارت ظاهر شود.
دسته‌ی تنظیم‌شده را برگردانید.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. یک کارت را از پایین دسته حذف کنید

با حذف کارت پایین دسته، کاری کنید که یک کارت ناپدید شود.
دسته‌ی تنظیم‌شده را برگردانید.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. اندازه‌ی دسته را بررسی کنید

بررسی کنید که اندازه‌ی دسته با `stackSize` برابر است یا نه.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
