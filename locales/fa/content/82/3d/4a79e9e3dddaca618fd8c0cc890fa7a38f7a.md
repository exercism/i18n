# معرفی

## سربارگذاری متد

«سربارگذاری متد» اجازه می‌دهد چند متد در یک کلاس نام یکسانی داشته باشند. متدهای سربارگذاری‌شده باید از نظر یکی از این دو مورد با هم تفاوت داشته باشند:

- تعداد پارامترها
- نوع پارامترها

سربارگذاری متد بر اساس نوع بازگشتی وجود ندارد.

کامپایلر به‌طور خودکار تشخیص می‌دهد که بر اساس تعداد پارامترها و نوع آن‌ها، کدام متد سربارگذاری‌شده را فراخوانی کند.

## آرگومان‌های نام‌دار

تا اینجا دیده‌ایم که آرگومان‌های فرستاده‌شده به یک متد، بر اساس ترتیب موقعیت با پارامترهای اعلام‌شده‌ی متد تطبیق داده می‌شوند. روشی دیگر، به‌ویژه جایی که یک روال تعداد زیادی آرگومان می‌گیرد، این است که فراخوان بتواند آرگومان‌ها را با مشخص کردن شناسه‌ی پارامتر اعلام‌شده تطبیق دهد.

مثال زیر نحوه‌ی نگارش را نشان می‌دهد:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## پارامترهای اختیاری

یک پارامتر متد را می‌توان با اختصاص دادن یک مقدار پیش‌فرض، اختیاری کرد. وقتی متدی با پارامترهای اختیاری فراخوانی می‌شود، فراخوان لازم نیست مقداری برای آن‌ها بفرستد. اگر مقداری برای یک پارامتر اختیاری فرستاده نشود، مقدار پیش‌فرض آن استفاده می‌شود.

پارامترهای اختیاری _باید_ در انتهای فهرست پارامترها باشند؛ نمی‌توانند بعد از خودشان پارامترهای غیراختیاری داشته باشند.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
