# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | ورودی     | آدرس | رنگ اول به‌صورت رشته‌ی پایان‌یافته با پوچ                  |
| `$a1`    | ورودی     | آدرس | رنگ دوم به‌صورت رشته‌ی پایان‌یافته با پوچ                 |
| `$a2`    | ورودی     | آدرس | رنگ سوم به‌صورت رشته‌ی پایان‌یافته با پوچ (که ممکن است خالی باشد) |
| `$v0`    | خروجی     | عدد صحیح | مقدار مقاومت                                         |
| `$t0-9`  | موقت | هر نوع     | برای ذخیره‌سازی موقت                                  |
