# کلاس تغییرناپذیر

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## چه چیزی تغییر می‌کند

|  | کلاس معمولی | کلاس تغییرناپذیر |
| --- | --- | --- |
| انتساب | شیء را به اشتراک می‌گذارد | مقدار را کپی می‌کند |
| می‌تواند `void` باشد | بله | خیر |
| روال نوشتن `attr` | `x.a := v` | `x := x.a(v)` |
| `new` | بله | خیر؛ `x : SAME` از قبل وجود دارد |

یک شیء تغییرناپذیر نمی‌تواند `void` باشد، بنابراین `void(b)` همیشه «غلط» است و هیچ روالی روی چنین شیئی نمی‌تواند به‌خاطر نبود شیء شکست بخورد. این کار یک رده‌ی کامل از اشتباه را حذف می‌کند، به بهای این‌که هرگز نتوانید بگویید: «هنوز هیچ `BEARING` نداریم».

## مقدار کجا نگهداری می‌شود

مقدار همان‌جایی که متغیر هست نگهداری می‌شود، درون شیء دیگری یا روی پشته، نه این‌که از راه یک مرجع به آن دسترسی داشته باشیم. بنابراین یک `ARRAY{BEARING}` خودِ اشیای `BEARING` را نگه می‌دارد، نه اشاره‌گرهایی به آن‌ها؛ که هم کوچک‌تر است و هم پیمایشش سریع‌تر.

بهایش کپی کردن است: پاس دادن یک شیء تغییرناپذیر بزرگ، هر بار آن را کپی می‌کند. بهتر است این اشیا کوچک نگه داشته شوند.

## روال‌های صفت

`readonly attr degrees : INT` دو روال می‌دهد:

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

دومی حتی تحت `readonly` هم وجود دارد، چون هیچ چیزی را تغییر نمی‌دهد؛ یک مقدار تازه می‌سازد. تحت یک `attr` ساده عمومی است؛ تحت `private attr` این‌طور نیست.

## `is_eq` و `str`

هیچ‌کدام از این دو ارائه نشده است. برای `=` یک `is_eq` بنویسید، و یک `str` بنویسید تا بتوان شیء را چاپ کرد و به رشته‌ها الحاق کرد:

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

نوشتن `str` کلاس را با `$STR` منطبق می‌کند، و همین باعث می‌شود `+` و `#OUT` آن را بپذیرند.

## موارد توکار

`INT`، `BOOL`، `CHAR`، `FLTD` و `TUP` همه‌شان کلاس تغییرناپذیر هستند. هیچ ویژگی خاصی درباره‌شان وجود ندارد: در کتابخانه، به همان شیوه و با زبان Sather نوشته شده‌اند و به دلایلی که بالاتر گفتیم همان‌طور که هستند رفتار می‌کنند.
