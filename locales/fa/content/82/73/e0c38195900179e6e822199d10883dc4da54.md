## راه‌اندازی

برای شروع، [راهنمای نصب Common Lisp][track-install] را ببینید یا نگاهی به راهنماهای موجود در [صفحه‌های مستندات این مسیر][track-docs] بیندازید.

## از کجا کمک بگیریم

هر یک از منابعی که در فهرست [منابع مفید Common Lisp][track-resources] آمده است، جای خوبی برای پیدا کردن اطلاعات است.

همچنین [انجمن‌های آنلاین][awesome-cl-communities] هم وجود دارند که می‌توانند جای خوبی برای گرفتن کمک باشند.

## قالب‌بندی

هرچند Common Lisp به تورفتگی و چیدمان کد اهمیتی نمی‌دهد و برایش فرقی نمی‌کند که از فاصله استفاده کنید یا تب، برای ارسال راه‌حل به Exercism این موضوع مهم است.
ابزار کد Exercism.org نمی‌تواند ترکیب تب و فاصله را به خوبی مدیریت کند، بنابراین توصیه می‌شود فقط از فاصله استفاده کنید تا کد برای بازبین‌های انسانی خواناتر باشد.
لطفاً تنظیمات ویرایشگر خود را بررسی کنید تا ببینید این کار چگونه انجام می‌شود.
در ادامه دستورالعمل‌هایی برای ویرایشگرهای محبوب Common Lisp آمده است.

### VIM

برای اینکه VIM فقط از فاصله برای تورفتگی استفاده کند، از دستورهای زیر استفاده کنید:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(یا به‌صورت یک‌خطی `:set tabstop=2 shiftwidth=2 expandtab`). می‌توانید این را به فایل `~/.vimrc` خود اضافه کنید تا همیشه از آن استفاده شود.

### Emacs

Emacs برای ویرایش Common Lisp بسیار مناسب است و بسته‌های افزودنی قدرتمند زیادی دارد. تنها کاری که باید با یک Emacs پیش‌فرض انجام دهید تا با exercism.org خوب کار کند، ارزیابی کد زیر است:

`(setq-default indent-tabs-mode nil)`

می‌توانید این را در `~/.emacs` (یا `~/.emacs.d/init.el`) قرار دهید تا هر بار که Emacs اجرا می‌شود، تنظیم شود.

یکی از افزونه‌های پیشنهادی برای Emacs و Common Lisp، [SLIME][slime] است که یکپارچگی تنگاتنگی با REPL فراهم می‌کند و کدنویسی و آزمون تکراری را بسیار آسان می‌سازد.
