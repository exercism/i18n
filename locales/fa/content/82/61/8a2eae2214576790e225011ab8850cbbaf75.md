# بردار به‌عنوان پشته

پشته یک ساختار داده‌ی خطی است که برای دسترسی از یک سر بهینه شده است. استعاره‌ی مناسب برای آن، دسته‌ای کاغذ روی یک میله است: کاغذهای تازه همیشه به همان سر اضافه می‌شوند و کاغذها به ترتیب معکوسِ افزودن برداشته می‌شوند. کاغذهایی که اول اضافه شده‌اند آخر برداشته می‌شوند و آن‌هایی که آخر اضافه شده‌اند اول برداشته می‌شوند.

ساختار داده‌ی `Vec` در Rust برای استفاده به‌عنوان پشته مناسب است. [متد `push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) عنصرها را به انتهای بردار اضافه می‌کند. [متد `pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) آخرین عنصر را از بردار حذف می‌کند. هر دو `push` و `pop` تنها به زمان سرشکن `O(1)` نیاز دارند.

## مثال

در این مثال، از یک بردار به‌عنوان پشته برای یک ماشین‌حساب ساده‌ی [نمادگذاری لهستانی معکوس (RPN)](https://en.wikipedia.org/wiki/Reverse_Polish_notation) استفاده می‌کنیم. کد کامل را می‌توانید در [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736) پیدا کنید.

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
