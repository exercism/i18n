# پیوست دستورالعمل

## قالب خروجی

انتظار می‌رود متد `solve()` شیئی با این ویژگی‌ها برگرداند:

- `moves` - تعداد کنش‌های سطلی لازم برای رسیدن به هدف
  (شامل پر کردن سطل شروع)،
- `goalBucket` - اسم سطلی که به مقدار هدف رسید،
- `otherBucket` - مقداری که در سطل دیگر قرار دارد.

مثال:

```json
{
  "moves": 5,
  "goalBucket": "one",
  "otherBucket": 2
}
```
