# پیوست دستورالعمل‌ها

## پیاده‌سازی

فرض‌ها:

1. صفر همیشه در خروجی‌ها به‌صورت [0] نمایش داده می‌شود، نه [].
2. در هیچ مورد دیگری صفرهای ابتدایی در خروجی‌ها وجود ندارند.
3. صفرهای ابتدایی در ورودی‌ها پذیرفته می‌شوند.
4. یک دنباله‌ی خالی از رقم‌های ورودی به‌جای خطا، صفر در نظر گرفته می‌شود.

موارد مسئله‌دار را با برگرداندن خطایی مدیریت کنید که متد `Error()` آن یکی از پیام‌های زیر را برمی‌گرداند:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
