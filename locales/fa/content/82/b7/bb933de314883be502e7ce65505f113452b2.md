# دستورالعمل‌ها

در این تمرین، پیام‌های لاگ را با شش سطح شدت پردازش می‌کنید.

هر خط لاگ رشته‌ای است که به این شکل قالب‌بندی شده است: `"[<LVL>]: <MESSAGE>"`.

سطح‌های مختلف لاگ عبارت‌اند از:

| سطح | مخفف |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. تجزیه سطح لاگ

یک `enum` به اسم `LogLevel` تعریف کنید که شش عضو متناظر با سطح‌های لاگ تعریف‌شده در بالا دارد.
سپس تابع `parse_log_level` را تعریف کنید که پیام لاگ را به عنوان پارامتر می‌گیرد و عضو `enum` متناظر با سطح آن را برمی‌گرداند.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. پشتیبانی از سطح لاگ ناشناخته

متأسفانه، گاهی بعضی پیام‌های لاگ با یک شدتِ _ناشناخته_ ظاهر می‌شوند. برای اینکه در تابع `parse_log_level` این پیام‌های لاگ «مرموز» را به شکلی روان مدیریت کنید، عضوی به اسم `Unknown` به `enum` `LogLevel` اضافه کنید که هنگام تجزیه‌ی یک سطح لاگ ناشناخته برگردانده می‌شود:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. تبدیل پیام لاگ به قالب کوتاه

سطح لاگ یک خط لاگ بسیار پرحرف است. برای کاهش فضای دیسکی که برای ذخیره‌ی پیام‌های لاگ لازم است، یک قالب کوتاه تعریف شده است: `"[<CODE_LEVEL>]:<MESSAGE>"`.

کدهای سطح لاگ از یک نگاشت سرراست پیروی می‌کنند:

| سطح | کد |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

تابع `convert_to_short_log()` را تعریف کنید که دو پارامتر می‌گیرد:

1. سطح لاگ: سطح لاگِ لاگِ ارسال‌شده. مثال: `LogLevel.Error`.
2. پیام لاگ: پیامی از نوع `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. ساختن یک نام مستعار

به نظر می‌رسد کاربر به جای `LogLevel.Warning` لاگ‌هایی برای `LogLevel.Warn` ساخته است. برای `LogLevel.Warning` یک `alias` بسازید و عضو نام مستعار جدید را در تابع `get_warn_alias` برگردانید.

این کار را می‌توان روی همان کلاس `enum` یعنی `LogLevel` انجام داد که قبلاً در بالای فایل تعریف شده است. هر دو `LogLevel` باید به یک مقدار اشاره کنند: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. همه‌ی اسم‌های اعضا و مقادیر

تابع `get_members()` را تعریف کنید.

این تابع باید فهرستی از تاپل‌های `(name, value)` را برگرداند که شامل همه‌ی اعضای `enum` `LogLevel` است.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
