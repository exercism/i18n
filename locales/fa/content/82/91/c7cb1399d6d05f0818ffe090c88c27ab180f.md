# درباره

[Comprehension][for] ابزاری فراهم می‌کند که با آن می‌توان _Enumerable_ها را به شکلی آسان و اعلانی دگرگون کرد. آنها نوعی «شکر نحوی» برای پیمایش enumerableها در Elixir هستند.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

یک comprehension سه بخش دارد:

1. _مولدها_:
   - مقادیری که از ساختارهایی پیمایش می‌شوند که پروتکل [_Enumerable_][enumerable] را پیاده‌سازی می‌کنند.
   - عبارت‌های تطبیق الگو برای ساختارشکنی مقادیر پیمایش‌شده.
2. _فیلترها_: شرط‌هایی از نوع «منطقی» که تعیین می‌کنند هنگام ساختن مقادیر جدید، کدام مقادیر پیمایش‌شده به کار روند.
3. _جمع‌کننده‌ها_: ساختاری که پروتکل [_Collectable_][collectable] را پیاده‌سازی می‌کند و مقادیر جدید را در خود جمع می‌کند.

comprehensionها هم تک‌خطی‌اند و هم چندخطی. وقتی بیش از یک مولد به کار برود، [ضرب دکارتی][cartesian-product] مقادیر تولیدشده پیمایش می‌شود. یعنی هر مقداری که مولد اول تولید می‌کند، یک‌بار با هر مقداری که مولد دوم تولید می‌کند جفت می‌شود.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

مقداری که در بلوک do نوشته می‌شود، **به ازای هر مقدار تولیدشده** از _enumerable_، به درون _collectable_ درج می‌شود.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

تطبیق الگو می‌تواند در comprehension رخ دهد، چه در سمت چپ `<-` و چه در خطی جداگانه.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
