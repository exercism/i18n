# تست در خط فرمان

تست‌ها را با این دستور اجرا کنید:

```bash
$ cargo test
```

همه‌ی تست‌ها به‌جز تست اول نادیده گرفته شده‌اند. پس از این که اولین تست را پاس کردید، فایل مبدأ تست‌ها را که در پوشه‌ی `tests` قرار دارد باز کنید و پرچم `#[ignore]` را از تست بعدی بردارید و آن تست را هم پاس کنید. هر تست جداگانه یک تابع است که پرچم `#[test]` بالای آن نوشته شده است. همین کار را ادامه دهید تا همه‌ی تست‌ها را پاس کنید.

اگر می‌خواهید بدون ویرایش فایل مبدأ تست‌ها _فقط تست‌های نادیده‌گرفته‌شده_ را اجرا کنید، از این دستور استفاده کنید:

```bash
$ cargo test -- --ignored
```

اگر از Rust نسخه‌ی ۱.۵۱ یا جدیدتر استفاده می‌کنید، می‌توانید _همه‌ی_ تست‌ها را با این دستور اجرا کنید:

```bash
$ cargo test -- --include-ignored
```

برای اجرای یک تست مشخص، برای مثال `some_test`، می‌توانید از این دستور استفاده کنید:

```bash
$ cargo test some_test
```

اگر همان تست مشخص نادیده گرفته شده باشد، از این دستور استفاده کنید:

```bash
$ cargo test some_test -- --ignored
```

برای آشنایی بیشتر با تست‌های Rust به [مستندات تست][rust-tests] آنلاین مراجعه کنید.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
