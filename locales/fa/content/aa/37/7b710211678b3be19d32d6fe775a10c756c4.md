# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات  | کاربرد | نوع       | توضیحات                                           |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | ورودی     | عدد صحیح | عدد شروع                                          |
| `$v0`    | خروجی     | عدد صحیح | تعداد مورد انتظار گام‌ها، و -1 اگر عدد نامعتبر باشد |
| `$t0-9`  | موقت      | هر نوع   | برای ذخیره‌سازی موقت استفاده می‌شود                |
