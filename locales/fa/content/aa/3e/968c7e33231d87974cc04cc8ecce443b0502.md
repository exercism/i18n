# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد     | نوع    | توضیح                                               |
| -------- | --------- | ------- | --------------------------------------------------------- |
| `$a0`    | ورودی     | نشانی | رشته‌ی ورودی پایان‌یافته با نال                              |
| `$v0`    | خروجی     | «منطقی» | براکت‌های ورودی با هم تطابق دارند (`0` = `false`، `1` = `true`) |
| `$t0-9`  | موقت | هر نوع     | برای ذخیره‌سازی موقت استفاده می‌شود                                |
