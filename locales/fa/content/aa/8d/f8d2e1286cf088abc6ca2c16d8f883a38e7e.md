# پیوست دستورالعمل

## ثبات

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | ورودی     | آدرس | رشته‌ی ورودی پایان‌یافته با پوچ                     |
| `$v0`    | خروجی     | منطقی | ورودی یک پانگرام است (`0` = `false`، `1` = `true`) |
| `$t0-9`  | موقت | هر | برای ذخیره‌سازی موقت استفاده می‌شود                       |
