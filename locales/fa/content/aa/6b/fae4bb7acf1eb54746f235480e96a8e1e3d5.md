# درباره

«دستورهای شرطی» بسته به اینکه یک شرط `true` باشد یا `false`، کد متفاوتی را اجرا می‌کنند.

یک [دستور شرطی `if`][if_statement] بدنه‌ی خود را تنها زمانی اجرا می‌کند که شرطش `true` باشد.
در Go مفهومی به اسم «درست» یا «غلط» بودنِ یک مقدار وجود ندارد؛ پس شرط باید از نوع `bool` باشد.
عبارت‌هایی مانند `if mySlice { ... }` یا `if 1 { ... }` خطای کامپایل هستند.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

برای بررسی شرط‌های بیشتر از `else if` و برای حالتی که هیچ‌کدام برقرار نبودند، از `else` به عنوان حالت جایگزین استفاده کنید.
شرط‌ها از بالا به پایین ارزیابی می‌شوند و تنها اولین شاخه‌ای که شرطش «درست» است اجرا می‌شود.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

به طور کلی، Go ترجیح می‌دهد در حالت استثنایی زودهنگام بازگردد و از `else` پرهیز کند.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

یک دستور شرطی `if` می‌تواند یک دستور کوتاه مقداردهی اولیه هم داشته باشد.
این کار معمولاً برای بررسی خطا بلافاصله پس از یک فراخوانی انجام می‌شود:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

متغیرهایی که در دستور مقداردهی اولیه تعریف می‌شوند، فقط در محدوده‌ی کل زنجیره‌ی `if`/`else` قابل دسترسی‌اند.
نکته‌ی قابل توجه اینکه Go عملگر سه‌تایی ندارد؛ این انتخابی آگاهانه در طراحی است تا خواندن کد آسان بماند.
