# راهنمایی‌ها

## کلی

- برای اینکه بتوانید روی `enum`ها پیمایش کنید، از crate به نام `enum-iterator` استفاده کنید. برای آشنایی با روش کار، [مستندات](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) را ببینید.

- برای تبدیل `int` به `enum`، از crate به نام `int-enum` استفاده کنید. برای جزئیات، [مستندات](https://docs.rs/int-enum/0.5.0/int_enum/) را ببینید.

- trait `Debug` وجود دارد چون احتمالاً به آن نیاز پیدا می‌کنید.

- باید فهرست traitهای `derive`شده را روی `enum` رنگ‌هایتان گسترش دهید.
