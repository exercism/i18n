# درباره

در C#، نوع `bool` نماینده‌ی مقادیر «منطقی» است و مقادیر آن می‌توانند `true` یا `false` باشند.

C# از چهار [عملگر منطقی][operators] پشتیبانی می‌کند: `!` (NOT)، `&&` (AND)، `||` (OR) و `^` (XOR). عملگرهای `&&` و `||` از _ارزیابی اتصال کوتاه_ استفاده می‌کنند، یعنی سمت راست عملگر فقط زمانی ارزیابی می‌شود که لازم باشد.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

هر یک از این سه عملگر منطقی [_اولویت عملگر_][precedence] متفاوتی دارد. در نتیجه، به این ترتیب ارزیابی می‌شوند: اول `not`، دوم `&&`، سوم `^` و در نهایت `||`. اگر بخواهید از این قواعد «فرار» کنید، می‌توانید یک عبارت منطقی را داخل پرانتز (`()`) بگذارید، چون پرانتزها اولویت عملگری حتی بالاتری دارند.

```csharp
!true && false   // => false
!(true && false) // => true
```
