# درباره

[توابع بی‌نام][anon-fns] در سراسر الیکسیر به‌طور معمول به‌تنهایی، به‌عنوان مقدار بازگشتی، و به‌عنوان آرگومان در توابع مرتبه بالاتر مانند `Enum.map/2` به کار می‌روند:

```elixir
Enum.map([1, 2, 3], fn n -> n + 1 end)
# => [2, 3, 4]
```

با توابع در الیکسیر مانند شهروندان درجه‌یک رفتار می‌شود:

- توابع نام‌دار و بی‌نام را می‌توان به متغیرها نسبت داد.
- توابع نام‌دار و بی‌نام را می‌توان مانند داده، به‌عنوان آرگومان و مقدار بازگشتی، جابه‌جا کرد.
- توابع بی‌نام را می‌توان به‌صورت پویا ساخت.

توابع بی‌نام با کلیدواژه‌ی [`fn`][kernel-fn] ساخته و با یک نقطه (`.`) فراخوانی می‌شوند:

```elixir
function_variable = fn n -> n + 1 end

function_variable.(1)
# => 2
```

توابع بی‌نام را می‌توان با [نحو اختصاری ضبط `&`][kernel-capture] هم ساخت.

- `&` ابتدایی، آغاز عبارت ضبط را اعلام می‌کند.
- `&1`، `&2` و به همین ترتیب به آرگومان‌های موقعیتی تابع بی‌نام اشاره می‌کنند.

  ```elixir
  # Instead of:
  fn x, y -> abs(x) + abs(y) end

  # We can write:
  &(abs(&1) + abs(&2))
  ```

- از عملگر ضبط `&` می‌توان برای [_ضبط_ یک تابع نام‌دار موجود][capture] هم استفاده کرد:

  ```elixir
  # Instead of:
  fn a, b -> a <= b end

  # We can capture the function using its name and arity:
  &<=/2
  ```

توابع بی‌نام در الیکسیر [«بستار»][closure] هستند. آن‌ها می‌توانند به متغیرهایی دسترسی داشته باشند که هنگام تعریف تابع در محدوده قرار دارند. متغیرهایی که داخل یک تابع بی‌نام مقدار می‌گیرند، از بیرون آن قابل دسترسی نیستند:

```elixir
y = 2

square = fn ->
  x = 3
  x * y
end

square.()
# => 6

x
# => ** (CompileError): undefined function x/0
```
