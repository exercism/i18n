# مقدمه

در Elixir می‌توانیم «ویژگی‌های ماژول» را تعریف کنیم و از آن‌ها به عنوان ثابت در توابعمان استفاده کنیم.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

وقتی از ویژگی‌ها برای تعریف ثابت‌های ماژول استفاده می‌کنیم، می‌توانند هر عبارتی باشند که در زمان کامپایل قابل ارزیابی است. پس از کامپایل، ویژگی‌های ماژول دیگر در دسترس نیستند، چون در حین کامپایل بسط داده می‌شوند. این موضوع مشابه ماکروهای تعریف‌شده در زبان‌هایی مانند C است.
