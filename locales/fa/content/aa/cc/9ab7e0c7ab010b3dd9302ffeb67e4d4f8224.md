# درباره

از انواع خارجی می‌توان برای اشاره به انواع داده‌ای استفاده کرد که در زبان‌های دیگری مانند Erlang یا JavaScript تعریف شده‌اند.

برای تعریف یک نوع خارجی، یک نوع اعلام کنید اما هیچ سازنده‌ای ارائه نکنید. سپس می‌توان از آن مانند هر نوع دیگری استفاده کرد.

```gleam
pub type OrderedDictionary(element)
```
