# درباره

ABAP از «عملگرهای حسابی» معمول برای مقادیر عددی پشتیبانی می‌کند:

- `+` مقادیر را جمع می‌کند.
- `-` مقادیر را تفریق می‌کند.
- `*` مقادیر را ضرب می‌کند.
- `/` مقادیر را تقسیم می‌کند.
- `MOD` باقی‌مانده‌ی یک تقسیم صحیح را برمی‌گرداند.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

ضرب و تقسیم پیش از جمع و تفریق ارزیابی می‌شوند. وقتی می‌خواهید محاسبه‌ای به‌صراحت گروه‌بندی شود، از پرانتز استفاده کنید.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
