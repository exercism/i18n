# مقدمه

## متغیرها

به یاد بیاورید که یک برنامه‌ی `jq` یک _خط لوله‌ی عبارت‌ها_ است.
**تخصیص متغیر** از این قاعده پیروی می‌کند: یک _تخصیص متغیر_ عبارتی است که به این شکل است:

```jq
... | expr as $varname | ...
```

### خروجی فیلتر همان ورودی است

مانند _عبارت همانی_ `.`، خروجی _تخصیص متغیر_ هم همان ورودی آن است.
تنظیم مقدار متغیر یک «عارضه‌ی جانبی» است.

مثال، که نشان می‌دهد `.` بعد از تخصیص همان ورودی اولیه است:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### دامنه‌ی متغیر

دامنه‌ی متغیر «واژگانی» است؛ یعنی متغیر تا پایان خط لوله در دامنه می‌ماند.
متغیرهایی که در توابع تعریف می‌شوند (بعداً به توابع می‌رسیم) نسبت به آن تابع «محلی» هستند.

### اسم‌های متغیر

اسم متغیر باید با `$` شروع شود.
بقیه‌ی اسم متغیر یک **شناسه** است: با یک حرف یا زیرخط شروع می‌شود و پس از آن حرف، عدد یا زیرخط می‌آید.

### تخصیص با ساختارشکنی

از کتاب راهنما:

> چندین متغیر را می‌توان با یک عبارت `as` واحد اعلام کرد، به شرط آن‌که الگویی بدهید که _با ساختار ورودی مطابقت داشته باشد_ (به این کار «ساختارشکنی» می‌گویند).

مثال‌ها:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

تطبیق دادن اسم متغیر با _کلید شیء_ یک میان‌بر به دست می‌دهد:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### ثابت‌ها

همان‌طور که در مثال بالا دیدید، متغیرها برای نگه داشتن ثابت‌ها به کار می‌آیند.
بهتر است برای ثابت‌ها یک اسم بگذارید تا این‌که «اعداد جادویی» در کد ظاهر شوند.

### اغلب نیازی به متغیرها نیست

اغلب خواناتر است که متغیرها را حذف کنید.

محاسبه‌ی میانگین یک فهرست از اعداد را در نظر بگیرید

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

در مقایسه با

```jq
[2, 4, 8, 7] | add / length
```

این یکی از قدرتمندترین ویژگی‌های `jq` را نشان می‌دهد: ورودی یک فیلتر در اختیار _هر_ زیرعبارت قرار می‌گیرد:

- آرایه‌ی ورودی `[2,4,8,7]` به `add` داده می‌شود (که با اعمال عملگر `+` روی همه‌ی عناصر، اعداد را جمع می‌کند)
- _به‌صورت موازی_، `[2,4,8,7]` به `length` هم داده می‌شود
- وقتی این زیرعبارت‌ها کامل شدند، نتیجه‌هایشان بر هم تقسیم می‌شود و میانگین اعداد آرایه‌ی ورودی به دست می‌آید.

### عملگرهای `jq` که در تمرین یادگیری به آن‌ها نیاز دارید

#### عملگر جایگزین: `//`

عبارت `a // b` اگر `a` «غلط» یا `null` باشد، `b` را خروجی می‌دهد؛ در غیر این صورت `a` را خروجی می‌دهد.
در بافت تنظیم یک متغیر، این برای فراهم کردن یک مقدار پیش‌فرض خیلی به کار می‌آید:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### عملگرهای حسابی

- `+`، `-` و `*` عملگرهای معمول جمع، تفریق و ضرب عددی هستند.
