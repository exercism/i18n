# اعداد اعشاری

در PHP از اعداد اعشاری برای نمایش زیرمجموعه‌ای از اعداد حقیقی استفاده می‌شود.
این اعداد با یک یا چند رقم شروع می‌شوند که یک جداکننده‌ی اعشار آن‌ها را از هم جدا می‌کند.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## دام‌های رایج

با اعداد اعشاری نمی‌توان همه‌ی اعداد و عملیات حسابی را انجام داد.
استفاده از اعداد اعشاری برای نمایش دلار و سنت اغلب به خطاهای گردکردن منجر می‌شود.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
