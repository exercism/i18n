# راهنمایی‌ها

## کلی

- [آموزش Python][the python tutorial] می‌تواند یک مقدمه‌ی بسیار خوب باشد.
- [PEP 8][pep8] راهنمای سبک نگارش Python است.
- [PEP 257][PEP257] جزئیات قراردادهای داک‌استرینگ در Python را شرح می‌دهد.
- [اعداد][numbers] در Python می‌توانند صحیح، اعشاری یا مختلط باشند.


## 1. زمان پخت مورد انتظار را بر حسب دقیقه تعریف کنید

- باید به یک [ثابت][constants] [اسم بدهید][naming] و یک [مقدار صحیح][numbers] به آن [اختصاص دهید][assignment].
  این ثابت باید اولین مورد بعد از داک‌استرینگی باشد که در بالای فایل قرار دارد.
  یادتان باشد بعد از تعریف ثابت، کامنت `#TODO` را حذف کنید.

## 2. زمان پخت باقی‌مانده را بر حسب دقیقه محاسبه کنید

- باید یک [تابع][defining functions] با یک پارامتر تعریف کنید که زمان سپری‌شده تا این لحظه را نشان می‌دهد.
- برای کم کردن مقادیر، از [عملگر ریاضی تفریق][numbers] استفاده کنید.
- این تابع باید [یک مقدار برگرداند][return].

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

- باید یک [تابع][defining functions] با یک پارامتر تعریف کنید که تعداد لایه‌ها را نشان می‌دهد.
- برای ضرب مقادیر، از [عملگر ریاضی ضرب][numbers] استفاده کنید.
- می‌توانید به‌جای استفاده از یک [«عدد جادویی»][magic-numbers] در کد، یک _ثابت_ به اسم `PREPARATION_TIME` برای زمان هر لایه بر حسب دقیقه تعریف کنید.
- این تابع باید [یک مقدار برگرداند][return].

## 4. زمان کل سپری‌شده‌ی پخت (آماده‌سازی + پخت) را بر حسب دقیقه محاسبه کنید

- باید یک [تابع][defining functions] با دو پارامتر تعریف کنید.
- یادتان باشد: همیشه می‌توانید تابعی را که قبلاً تعریف کرده‌اید _فراخوانی_ کنید.
- می‌توانید برای جمع مقادیر از [عملگر ریاضی جمع][python as a calculator] استفاده کنید.
- این تابع باید [یک مقدار برگرداند][return].

## 5. دستور پخت را با یادداشت‌ها به‌روزرسانی کنید

- همیشه توصیه می‌شود طبق [PEP257][pep257]، کد خود را به‌روشنی [کامنت‌گذاری][comments] و [مستندسازی][docstrings] کنید.
- چند نمونه از داک‌استرینگ‌های به سبک Google را می‌توانید در مستندات Sphinx برای [ماژول napoleon][napoleon] پیدا کنید.
