# دستورالعمل‌ها

در این تمرین، روشی را پیاده‌سازی می‌کنید که با آن می‌توانید امتیازهای بالای محبوب‌ترین بازی سالن بازی محلی‌تان را پیگیری کنید.

شما ۶ تابع برای پیاده‌سازی دارید که بیشترشان به کار با شیئی مربوط می‌شوند که امتیازهای بالا را نگه می‌دارد.

## 1. یک تخته‌ی امتیازات جدید بسازید

تابعی به اسم `create_score_board` بنویسید که شیئی می‌سازد و نقش تخته‌ی امتیازات را ایفا می‌کند.
کلیدهای این شیء اسم بازیکن‌ها خواهند بود و مقدارها امتیاز آن‌ها.
برای آزمایش، می‌خواهید یک جفت را مستقیماً در شیء بگنجانید.
این جفت اولیه باید از `"The Best Ever"` به عنوان اسم بازیکن و `1000000` به عنوان امتیاز تشکیل شده باشد.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. بازیکن‌ها را به تخته‌ی امتیازات اضافه کنید

برای افزودن بازیکن به تخته‌ی امتیازات، تابع `add_player` را پیاده‌سازی کنید.
این تابع یک تخته‌ی امتیازات را به عنوان ورودی می‌گیرد و به دو پارامتر نیاز دارد: اسم بازیکن و امتیاز بازیکن.
تابع شیء تخته‌ی امتیازات را همراه با بازیکن جدید به عنوان خروجی برمی‌گرداند.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

اگر بازیکن از قبل روی تخته باشد، تخته را بدون تغییر برگردانید.

## 3. بازیکن‌ها را از تخته‌ی امتیازات حذف کنید

اگر بازیکن‌ها قوانین سالن بازی را زیر پا بگذارند، به‌صورت دستی از تخته‌ی امتیازات حذف می‌شوند.
تابع `remove_player` را پیاده‌سازی کنید که یک تخته را به عنوان ورودی و یک پارامتر، یعنی اسم بازیکنی که باید حذف شود، می‌گیرد.
این تابع باید جفت مربوط به بازیکن داده‌شده را از تخته حذف کند و تخته‌ی جدید را برگرداند.
اگر بازیکن از ابتدا روی تخته نبود، نباید هیچ اتفاقی برای تخته بیفتد؛ باید همان‌طور که هست برگردانده شود.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. امتیاز یک بازیکن را افزایش دهید

وقتی بازیکنی بازی دیگری را در سالن بازی به پایان می‌برد، مقدار مشخصی امتیاز به امتیاز قبلی روی تخته اضافه می‌شود.
تابع `update_score` را پیاده‌سازی کنید که یک تخته‌ی امتیازات را به عنوان ورودی می‌گیرد و به دو پارامتر نیاز دارد: اسم بازیکن و مقدار امتیازی که باید اضافه شود.
تابع باید تخته‌ی امتیازات را پس از انجام به‌روزرسانی برگرداند.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

اگر بازیکن از قبل روی تخته نبود، این تابع باید او را به تخته اضافه کند.

## 5. امتیاز جایزه‌ی دوشنبه را اعمال کنید

سالن بازی دوشنبه‌ها یک تخته‌ی امتیازات جداگانه نگه می‌دارد.
در پایان روز، هر بازیکنی که روی آن تخته باشد ۱۰۰ امتیاز اضافه می‌گیرد.

تابع `apply_monday_bonus` را پیاده‌سازی کنید.
این تابع امتیاز جایزه را برای هر بازیکنی که در آن تخته فهرست شده است اضافه می‌کند.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. امتیاز کل را پیدا کنید

سالن‌های بازی مختلف با هم رقابت می‌کنند تا مشخص شود کدام‌یک بهترین بازیکن‌ها را دارد.
سالنی که بالاترین امتیاز کل را داشته باشد، این افتخار را از آن خود می‌کند.

تابعی به اسم `total_score` بنویسید.
این تابع یک تخته‌ی امتیازات را به عنوان ورودی می‌گیرد و مجموع امتیاز همه‌ی بازیکن‌ها را برمی‌گرداند.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
