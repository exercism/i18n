# مقدمه

Lua برای اعداد دو نمایش دارد: عدد صحیح ۶۴ بیتی و عدد اعشاری با دقت دوگانه. این زبان مجموعه‌ی معمول عملگرهای حساب را پشتیبانی می‌کند: جمع، تفریق، ضرب، تقسیم و منفی کردن. علاوه بر این، تقسیم صحیح، باقیمانده و توان‌رسانی را هم پشتیبانی می‌کند.

| عملگر | مثال                |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
