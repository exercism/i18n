# دستورالعمل‌ها

با داشتن یک کلمه، امتیاز Scrabble آن کلمه را محاسبه کنید.

## ارزش حروف

به این‌ها نیاز دارید:

```text
Letter                           Value
A, E, I, O, U, L, N, R, S, T       1
D, G                               2
B, C, M, P                         3
F, H, V, W, Y                      4
K                                  5
J, X                               8
Q, Z                               10
```

## مثال‌ها

کلمه‌ی «cabbage» باید ۱۴ امتیاز بگیرد:

- ۳ امتیاز برای C
- ۱ امتیاز برای A، دو بار
- ۳ امتیاز برای B، دو بار
- ۲ امتیاز برای G
- ۱ امتیاز برای E

و جمع کل:

- `3 + 2*1 + 2*3 + 2 + 1`
- = `3 + 2 + 6 + 3`
- = `5 + 9`
- = ۱۴

## بسط‌ها

- می‌توانید از حرف دوبرابر یا سه‌برابر استفاده کنید.
- می‌توانید از کلمه‌ی دوبرابر یا سه‌برابر استفاده کنید.
