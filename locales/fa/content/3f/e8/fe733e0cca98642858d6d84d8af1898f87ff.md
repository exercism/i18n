# راهنمایی

## 1. توصیف اعداد ساده

- از `fmt.Sprintf` برای قالب‌بندی استفاده کنید

## 2. توصیف جعبه‌ی عدد

- نتیجه را از متد `Number()` بگیرید
- از `fmt.Sprintf` برای قالب‌بندی استفاده کنید

## 3. پیاده‌سازی متدی که عدد را از یک جعبه‌ی عدد فانتزی استخراج می‌کند

- از یک اظهار نوع استفاده کنید تا بررسی کنید که آیا این یک `FancyNumber` است
- `string` را از متد `Value()` بگیرید
- از `strconv.Atoi` استفاده کنید تا `string` را به `int` تبدیل کنید (می‌توانیم خطا را نادیده بگیریم، چون اگر نتوان آن را به `int` تبدیل کرد، ۰ را می‌خواهیم)

## 4. توصیف یک جعبه‌ی عدد فانتزی

- از `ExtractFancyNumber` استفاده کنید تا مقدار `int` را بگیرید
- `int` را به `float64` تبدیل کنید
- از `fmt.Sprintf` برای قالب‌بندی استفاده کنید

## 5. پیاده‌سازی `DescribeAnything` که از همه‌ی آن‌ها استفاده می‌کند

- یا از اظهارهای نوع استفاده کنید (مثلاً `i.(someType)`) یا از یک سوئیچ نوع (`switch v := i.(type)`)
- یادتان باشد که `int` را به `float64` تبدیل کنید
