# مقدمه

## توابع بی‌نام

در الیکسیر با توابع به‌عنوان شهروندان درجه‌یک رفتار می‌شود. یعنی:

- توابع نام‌دار و بی‌نام را می‌توان به متغیرها نسبت داد.
- توابع نام‌دار و بی‌نام را می‌توان مثل داده، به‌عنوان آرگومان و مقدار بازگشتی جابه‌جا کرد.
- توابع بی‌نام را می‌توان به‌صورت پویا ساخت.

توابع بی‌نام، برخلاف توابع نام‌دار، مرجع ثابتی ندارند که در دسترسشان باشد؛ فقط زمانی در دسترس‌اند که به یک متغیر نسبت داده شوند یا بلافاصله فراخوانی شوند.

ممکن است از توابع بی‌نام برای این کارها استفاده کنیم:

- پنهان کردن داده‌ها با استفاده از حوزه‌ی واژگانی (که به آن «کلوژر» هم می‌گویند).
- ساختن پویای توابع در زمان اجرا.

توابع بی‌نام با کلمه‌ی رزروشده‌ی `fn` شروع می‌شوند، آرگومان‌ها با نشانه‌ی `->` از بدنه‌ی تابع جدا می‌شوند و با یک `end` پایان می‌یابند. مثل توابع نام‌دار، آخرین عبارت در تابع _به‌صورت ضمنی_ به تابع فراخوان‌کننده برگردانده می‌شود.

برای فراخوانی یک مرجع تابع، باید بین متغیر مرجع و فهرست آرگومان‌ها از یک `.` استفاده کنید:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

حتی می‌توانید از نشانه‌گذاری کوتاه «capture» استفاده کنید تا این کار فشرده‌تر شود:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## دستکاری بیت

الیکسیر توابع زیادی برای کار با بیت‌ها دارد که در ماژول `Bitwise` قرار دارند.

- `band/2`: AND بیتی
- `bsl/2`: شیفت چپ بیتی
- `bsr/2`: شیفت راست بیتی
- `bxor/2`: XOR بیتی
- `bor/2`: OR بیتی
- `bnot/1`: NOT بیتی

در ادامه مثالی از نحوه‌ی استفاده از یک تابع بیتی را می‌بینید:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

همه‌ی توابع بیتی فقط روی اعداد صحیح کار می‌کنند.

اگر از نسخه‌ی ۱.۹ الیکسیر یا پایین‌تر استفاده می‌کنید، برای اینکه بتوانید از ماژول `Bitwise` استفاده کنید، باید در ابتدای تعریف ماژول، `require Bitwise` را فراخوانی کنید.
