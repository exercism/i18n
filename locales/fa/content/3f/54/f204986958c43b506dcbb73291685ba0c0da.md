# مقدمه

## پارامترها

این تمرین برخی از جزئیات پارامترهای متد و کاربرد آن‌ها در C# را بررسی می‌کند.

پارامترها اطلاعات را از یک متد فراخوانی‌کننده به یک متد فراخوانی‌شده منتقل می‌کنند.

- رفتار پارامترها را می‌توان با استفاده از اصلاح‌کننده‌هایی مانند `ref` و `out` تغییر داد.

- پارامتری که اصلاح‌کننده‌ی `out` دارد، یک مقدار را از متد فراخوانی‌شده به فراخوان بازمی‌گرداند. این پارامتر را می‌توان بدون مقداردهی اولیه به متد فراخوانی‌شده پاس داد و در هر صورت، درون متد فراخوانی‌شده طوری با آن رفتار می‌شود که گویی هنگام ورود، مقداردهی اولیه نشده است. برای درک رفتار و قواعد مربوط به اصلاح‌کننده‌های پارامتر، آسان‌ترین راه، مثال‌ها (پایین را ببینید) و پیام‌های کامپایلر است.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- پارامترهای `out` باید درون متد فراخوانی‌شده مقداردهی شوند.

- پارامتری که اصلاح‌کننده‌ی `ref` دارد، یک مقدار را به متد فراخوانی‌شده پاس می‌دهد. وقتی متد بازمی‌گردد، فراخوان هر به‌روزرسانی‌ای را که متد فراخوانی‌شده در آن پارامتر انجام داده است، می‌بیند.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- پارامترهای `ref` باید متغیر باشند، زیرا متد فراخوانی‌شده مستقیماً روی همان پارامتری کار می‌کند که فراخوان می‌بیند.
- اصلاح‌کننده‌های `out` و `ref` هم در امضای متد فراخوانی‌شده و هم در محل فراخوانی لازم هستند.
