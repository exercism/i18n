# دستورالعمل‌ها

صاحب پیتزافروشی محله‌تان از شما خواسته است که به او در محاسبه‌ی زمان پخت پیتزاهای مختلف کمک کنید. در این تمرین چند تابع می‌نویسید که این محاسبه‌ها را انجام می‌دهند.

سه کار پیش رو دارید.

## 1. محاسبه‌ی زمان باقی‌مانده‌ی پخت در فر بر حسب دقیقه

تابع `remainingMinutesInOven()` را تعریف و پیاده‌سازی کنید که می‌شمارد چند دقیقه‌ی دیگر باید پیتزا را در فر نگه دارید.

تابع باید یک پارامتر **اختیاری** (با مقدار پیش‌فرض) بپذیرد که تعداد دقیقه‌هایی است که از شروع پخت پیتزا گذشته است. اگر پارامتر داده نشده باشد، فرض کنید همین حالا پیتزا را در فر گذاشته‌اید و **۰ (صفر)** دقیقه گذشته است.

برای سادگی فرض کنیم همه‌ی پیتزاها برای آماده شدن دقیقاً به ۴۰ دقیقه پخت در فر نیاز دارند.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. محاسبه‌ی زمان آماده‌سازی بر حسب دقیقه

پیش از پخت پیتزا، باید خمیر را آماده کنید، آن را پهن کنید و مواد را روی آن بگذارید.

تابع `preparationTimeInMinutes()` را تعریف و پیاده‌سازی کنید که می‌شمارد آماده کردن پیتزا پیش از گذاشتنش در فر چند دقیقه طول می‌کشد.

تابع باید یک پارامتر **الزامی** (`numberOfIngredientTypes`) بپذیرد که تعداد نوع‌های مواد روی پیتزا است.

فرض کنید برای درست کردن و پهن کردن خمیر ۵ دقیقه و برای استفاده از **هر** نوع مواد ۲ دقیقه لازم است.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. محاسبه‌ی زمان سپری‌شده بر حسب دقیقه

تابع `elapsedCookingTimeInMinutes()` را تعریف و پیاده‌سازی کنید که می‌شمارد آماده کردن، پختن و سرو کردن پیتزا در مجموع چند دقیقه طول می‌کشد. برای انجام محاسبه‌ها از توابع مراحل قبلی استفاده کنید.

تابع باید دو پارامتر بپذیرد. پارامتر اول **الزامی** است و تعداد نوع‌های مواد روی پیتزا را نشان می‌دهد. پارامتر دوم **اختیاری** است و زمان سرو کردن بر حسب دقیقه است (اگر داده نشده باشد، فرض کنید صفر است).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
