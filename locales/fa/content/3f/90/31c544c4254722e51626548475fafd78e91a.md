# مقدمه

## کلاس

سازه‌ی اصلی شیءگرا در Java، «کلاس» است؛ ترکیبی از داده («فیلد») و رفتار («متد»).
به فیلدها و متدهای یک کلاس، «اعضای» آن گفته می‌شود.

دسترسی به اعضا را می‌توان با اصلاح‌کننده‌های دسترسی کنترل کرد که دو مورد از رایج‌ترین‌شان این‌ها هستند:

- `public`: هر کدی می‌تواند به این عضو دسترسی داشته باشد (بدون محدودیت).
- `private`: فقط کدی که در همان کلاس است می‌تواند به این عضو دسترسی داشته باشد.

می‌توانید کلاس را به‌عنوان قالبی برای ساختن نمونه‌هایی از آن در نظر بگیرید.
برای ساختن یک نمونه از کلاس (که به آن «شیء» هم می‌گویند)، از کلیدواژه‌ی `new` استفاده می‌شود:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

فیلدها یک نوع و یک اسم دارند (به‌صورت camelCase نوشته می‌شوند) و می‌توان آن‌ها را در هر جای کلاس تعریف کرد (بر اساس قرارداد، اسم کلاس‌ها به‌صورت PascalCase نوشته می‌شود):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

می‌توان به‌صورت اختیاری یک مقدار اولیه به یک فیلد اختصاص داد.
اگر فیلدی مقدار اولیه‌ای تعیین نکند، روی مقدار پیش‌فرض نوعش تنظیم می‌شود.
می‌توان با نشانه‌گذاری نقطه‌ای به مقدار فیلدهای یک نمونه دسترسی داشت و آن‌ها را به‌روزرسانی کرد.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

فیلدهای خصوصی معمولاً به‌عنوان اثر جانبی فراخوانی یک متد به‌روزرسانی می‌شوند.
این متدها معمولاً مقداری برنمی‌گردانند؛ در این صورت نوع بازگشتی باید `void` باشد:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
