# مقدمه

در Ruby، **آرایه‌ها** مجموعه‌هایی مرتب و اندیس‌گذاری‌شده با اعداد صحیح هستند که می‌توانند هر شیئی را در خود داشته باشند.
اندیس‌گذاری آرایه از `0` شروع می‌شود.
اندیس منفی نسبت به انتهای آرایه شمرده می‌شود، یعنی اندیس `-1` به آخرین عنصر آرایه اشاره دارد، `-2` به عنصر یکی‌به‌آخر، و به همین ترتیب.
آرایه‌های Ruby ماژول [ماژول Enumerable][enumerable-module] را در خود می‌گنجانند که چندین متد پیمایش و جست‌وجو را به آن اضافه می‌کند و امکان مرتب‌سازی را هم فراهم می‌سازد.

## ساخت آرایه

- یک آرایه در Ruby می‌تواند انواع مختلفی از اشیاء را در خود داشته باشد.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## تخصیص به عناصر

می‌توان با استفاده از اندیس‌ها به عناصر دسترسی داشت یا آن‌ها را تغییر داد.
با مشخص کردن اندیس شروع و اندازه می‌توان به زیرآرایه‌ها دسترسی داشت.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- اندیس‌های منفی از انتهای آرایه به عقب شمرده می‌شوند.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## ارجاع به عناصر

- می‌توان عناصر یک آرایه را با متد `#[]` بازیابی کرد.
- این متد عنصر موجود در آن اندیس را برمی‌گرداند، یا زیرآرایه‌ای را برمی‌گرداند که از اندیس شروع آغاز می‌شود و به اندازه‌ی `length` عنصر ادامه می‌یابد.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- اندیس‌های منفی از انتهای آرایه به عقب شمرده می‌شوند (`-1` آخرین عنصر است)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## گرفتن اطلاعات درباره‌ی یک آرایه

آرایه‌ها در هر لحظه طول خودشان را می‌دانند.
برای پرسیدن تعداد عناصر یک آرایه، از `length`، `count` یا `size` استفاده کنید.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## افزودن عنصر به آرایه

می‌توان با استفاده از `push` یا `<<` عنصر را به انتهای آرایه اضافه کرد:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## حذف عنصر از آرایه

متد `pop` آخرین عنصر آرایه را حذف می‌کند و آن را برمی‌گرداند:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
