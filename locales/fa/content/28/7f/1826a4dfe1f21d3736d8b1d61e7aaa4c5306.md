# درباره

در Kotlin، مقادیر «منطقی» با نوع `Boolean` نمایش داده می‌شوند و مقدارشان می‌تواند `true` یا `false` باشد.

Kotlin از سه [عملگر منطقی][reference] توکار پشتیبانی می‌کند: `!` (نقیض، که به آن NOT می‌گویند)، `&&` (عطف با ارزیابی تنبل، که به آن AND می‌گویند) و `||` (فصل با ارزیابی تنبل، که به آن OR می‌گویند). عملگرهای `&&` و `||` از _ارزیابی اتصال کوتاه_ استفاده می‌کنند، یعنی سمت راست عملگر تنها زمانی ارزیابی می‌شود که لازم باشد.

```kotlin
true || false // => true
true && false // => false
```

این سه عملگر منطقی هر کدام [_تقدم عملگر_][precedence] متفاوتی دارند. در نتیجه، به این ترتیب ارزیابی می‌شوند: اول `!`، سپس `&&` و در پایان `||`. اگر بخواهید از این قواعد «فرار» کنید، می‌توانید یک عبارت منطقی را درون پرانتز (`()`) بگذارید، چون پرانتزها تقدم عملگر حتی بالاتری دارند.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
