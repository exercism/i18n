# دستورالعمل‌ها

در این تمرین، شما در حال بازی یک بازی نقش‌آفرینی به نام «جادوگران و جنگجویان» هستید. برای انجام این بازی، به یک متد همه‌کاره برای انداختن تاس نیاز دارید تا نتایج مختلف را مشخص کنید. این تاس همان تاس سنتی ۱۸ وجهی با اعداد ۱ تا ۱۸ خواهد بود. بازیکن‌ها همچنین باید یک قدرت جادوی تصادفی تولید کنند.

## 1. به بازیکنِ _جادوگران و جنگجویان_ امکان بدهید تاس بیندازد

متد `RollDie()` را روی کلاس `Player` پیاده‌سازی کنید.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. بازیکن‌ها به قدرتشان نیاز دارند. راهی برای تولید قدرت جادو فراهم کنید

متد `GenerateSpellStrength()` را روی کلاس بازیکن پیاده‌سازی کنید.
قدرت جادو بین 0.0 و 100.0 است، اما خود 100.0 شامل نمی‌شود.

توجه کنید که قدرت جادو باید یک عدد اعشاری باشد (نه یک عدد صحیح) تا احتمال مساوی شدن هنگام مقایسه‌ی قدرت دو حریف کمتر شود.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
