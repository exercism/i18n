# Debugging

برخلاف بسیاری از زبان‌ها، کد WebAssembly به‌طور خودکار به منابع سراسری مثل کنسول دسترسی ندارد. در عوض، چنین قابلیتی باید به‌صورت واردکردنی فراهم شود.

برای فراهم کردن قابلیتی شبیه `console.log` و چند امکان جانبی دیگر، track مربوط به WebAssembly در Exercism یک کتابخانه‌ی استاندارد از توابع را در اختیار همه‌ی تمرین‌ها می‌گذارد.

این توابع باید در بالای ماژول WebAssembly شما وارد شوند و بعد می‌توانید آن‌ها را از داخل کد WebAssembly خودتان فراخوانی کنید.

توابع `log_mem_*` انتظار دارند که به حافظه‌ی خطی ماژول WebAssembly شما دسترسی داشته باشند. به‌طور پیش‌فرض، این یک وضعیت خصوصی است؛ پس برای اینکه در دسترس قرار گیرد، باید حافظه‌ی خطی خود را با اسم خروجی `mem` خروجی بگیرید. این کار به شکل زیر انجام می‌شود:

```wasm
(memory (export "mem") 1)
```

# لاگ کردن متغیرهای محلی و سراسری

ما برای هر یک از انواع اولیه‌ی WebAssembly تابع‌های لاگ فراهم کرده‌ایم. این کار برای لاگ کردن متغیرهای سراسری و محلی مفید است.

## log_i32_s - لاگ کردن یک عدد صحیح علامت‌دار ۳۲ بیتی در کنسول

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```


# لاگ کردن از حافظه‌ی خطی

حافظه‌ی خطی WebAssembly یک آرایه‌ی مقدار است که آدرس‌دهی آن بایتی انجام می‌شود. این حافظه معادل حافظه‌ی مجازی برای برنامه‌های WebAssembly است.

ما تابع‌های لاگی فراهم کرده‌ایم که یک بازه از آدرس‌ها را در حافظه‌ی خطی، به‌عنوان آرایه‌های ایستا از نوع‌های مشخص تفسیر می‌کنند. این کار شبیه TypedArrayهای JavaScript عمل می‌کند. پارامترهای طول بر حسب بایت اندازه‌گیری نمی‌شوند؛ آن‌ها بر حسب تعداد عنصرهای پشت‌سرهم از نوع متناظر با تابع سنجیده می‌شوند.

**برای اینکه این تابع‌ها کار کنند، ماژول WebAssembly شما باید حافظه‌ی خطی خود را با اسم خروجی «mem» اعلام و خروجی‌گیری کند**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - لاگ کردن دنباله‌ای از نویسه‌های UTF8 در کنسول

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - لاگ کردن دنباله‌ای از عددهای صحیح علامت‌دار ۸ بیتی در کنسول

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
