# دستورالعمل‌ها

شیفت شب در اسکله‌ی هال است. کشتی باری *Olwen* کنار اسکله پهلو گرفته است و گروهی از کارگران اسکله به‌صورت موازی روی مانیفست کار می‌کنند. هر صندوق باید پیش از سوار شدن به کشتی وزن شود و رئیس بندر تنها یک **شمارش تناژ جاری** نگه می‌دارد که هر بالاکشیدن آن را به‌روزرسانی می‌کند. اما یک نکته هست: در اسکله فقط یک جرثقیل وجود دارد، پس شمارش نباید با به‌روزرسانی همزمانِ دو کارگر اسکله پاره شود.

هر صندوق یک آرایه از وزن عنصرهاست. وزن صندوق برابر مجموع همان عنصرهاست.

## 1. وزن کردن یک صندوق

تابع `weigh-crate` را طوری تعریف کنید که یک صندوق بگیرد و وزن کل آن را برگرداند. این کار ترتیبی ساده است: یک صندوق، یک عدد خروجی.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. وزن کردن کل مانیفست به‌صورت موازی

تابع `weigh-all` را طوری تعریف کنید که آرایه‌ای از صندوق‌ها بگیرد و آرایه‌ی وزن آن‌ها را با همان ترتیب برگرداند. از `parallel-map` استفاده کنید تا کار مربوط به هر صندوق همزمان انجام شود.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. ساختن یک جرثقیل تازه

تابع `<crane>` را طوری تعریف کنید که یک جرثقیل تازه بسازد: یک تاپل با یک `<lock>` تازه و تناژ `0`. جرثقیل همان منبع مشترکی است که کارهای بعدی از آن محافظت خواهند کرد.

```factor
<crane> tonnage>> .
! => 0
```

## 4. بالاکشیدن یک صندوق و افزودنش به شمارش جاری

تابع `hoist-crate` را طوری تعریف کنید که یک `weight` و یک `crane` بگیرد و آن وزن را **تحت قفل جرثقیل** به تناژ جرثقیل اضافه کند، تا عمل خواندن-جمع‌کردن-نوشتن در برابر بالاکشیدن همزمان سایر کارگران اسکله اتمی باشد.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. خواندن تناژ جاری

تابع `crane-tonnage` را طوری تعریف کنید که تناژ فعلی جرثقیل را برگرداند، آن هم تحت قفل، تا خواندن در میانه‌ی بالاکشیدن مقدار پاره نبینند.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. بارگیری محموله

تابع `load-cargo` را طوری تعریف کنید که آرایه‌ای از صندوق‌ها و یک جرثقیل بگیرد و **برای هر صندوق، یک رشته‌ی کارگر اسکله ایجاد کند** که آن صندوق را وزن می‌کند و وزنش را روی جرثقیل بالا می‌کشد. این تابع تنها زمانی برمی‌گردد که همه‌ی کارگران اسکله کارشان تمام شده باشد. برای هماهنگ‌کردن پیوستن آن‌ها از `<promise>` و `?promise` استفاده کنید.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
