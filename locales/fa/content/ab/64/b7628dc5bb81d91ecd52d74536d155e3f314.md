# مقدمه

در JavaScript، کلاس `Array` متدهای توکار قدرتمند زیادی برای تبدیل آرایه‌ها دارد.
این متدها تبدیل یک آرایه به آرایه‌ی دیگر را بسیار ساده‌تر از انجام آن با یک حلقه‌ی For ساده یا دستکاری مستقیم‌تر می‌کنند.

برخی از این متدها [_خالص_][pure-function-definition] هستند، یعنی آرایه‌ی اصلی را تغییر نمی‌دهند و در عوض آرایه‌ی تازه‌ای برمی‌گردانند.
اما متدهای دیگری آرایه‌ای را که روی آن فراخوانی می‌شوند دستکاری می‌کنند و آرایه‌ی تغییریافته را **برنمی‌گردانند**.

در ادامه برخی از پرکاربردترین متدهای تبدیل آرایه‌ها معرفی شده‌اند.
فهرست کامل متدهای موجود را می‌توانید در [مستندات MDN][array-methods] ببینید.

### map (خالص)

با تبدیل هر عنصر بر اساس تابعی که به‌عنوان آرگومان داده می‌شود، آرایه‌ی تازه‌ای بسازید.
این توابع callback اغلب به شکل [توابع پیکانی][concept-arrow-functions] نوشته می‌شوند.

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

لازم به ذکر است که آرایه‌ی حاصل همیشه هماندازه‌ی آرایه‌ی اصلی خواهد بود.

### filter (خالص)

با فیلتر کردن آرایه‌ی فعلی و به کمک یک تابع فیلترکننده، آرایه‌ی تازه‌ای می‌سازد (تابعی که اگر عنصر باید نگه داشته شود «درست» و اگر باید حذف شود «غلط» برمی‌گرداند).

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (خالص)

آرایه را با استفاده از تابعی که یک _انباشتگر_ و عنصر فعلی آرایه را به‌عنوان پارامتر می‌گیرد، به یک مقدار واحد کاهش می‌دهد.
این تابع مشخص می‌کند که عنصر فعلی چگونه باید در انباشتگر ادغام شود و انباشتگری را برمی‌گرداند که در تکرار بعدی استفاده خواهد شد.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

عناصر یک آرایه را معکوس می‌کند.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

این متد آرایه‌ای را که روی آن فراخوانی می‌شود تغییر می‌دهد.

### slice (خالص)

با گرفتن اندیس شروع و اندیس پایان، زیرآرایه‌ای از آرایه‌ای که روی آن فراخوانی می‌شود می‌سازد.

عنصر واقع در اندیس پایان در نظر گرفته نمی‌شود.
همچنین همه‌ی پارامترها اختیاری‌اند:
اندیس شروع به‌طور پیش‌فرض `0` است و اندیس پایان به‌طور پیش‌فرض طول آرایه.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

عناصری از یک آرایه را حذف یا جایگزین می‌کند و/یا عناصری تازه به آن اضافه می‌کند.

این متد پارامترهای زیر را می‌گیرد:

- اندیس عنصری که تغییر آرایه از آنجا شروع می‌شود
- تعداد عناصری که باید حذف شوند
- عناصری که باید در آرایه درج شوند (اختیاری)

`splice` عناصری را که حذف شده‌اند برمی‌گرداند.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

به‌طور پیش‌فرض، `sort` عناصر آرایه را ابتدا به رشته تبدیل می‌کند و سپس مقایسه‌ی رشته‌ای را اعمال می‌کند (به [مفهوم مقایسه][concept-comparison] نگاه کنید).
مرتب‌سازی _درجا_ انجام می‌شود، یعنی آرایه‌ی اصلی تغییر می‌کند.
`sort` آن آرایه‌ی تغییریافته را هم برمی‌گرداند که اگر بخواهید متدهای دیگری را به آن زنجیره کنید، راحت است.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

برای سفارشی کردن رفتار مرتب‌سازی، می‌توانید یک تابع مقایسه به‌عنوان آرگومان بدهید.
خود تابع مقایسه با ۲ آرگومان فراخوانی می‌شود که همان ۲ عنصر آرایه‌اند.
سپس باید موارد زیر را برگرداند:

- یک عدد منفی اگر آرگومان اول باید پیش از آرگومان دوم مرتب شود
- یک عدد مثبت اگر آرگومان اول باید پس از آرگومان دوم مرتب شود
- `0` اگر ترتیب عناصر باید ثابت بماند

برای نمونه، برای مرتب‌سازی اعداد می‌توان از تابع مقایسه‌ی زیر استفاده کرد.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
