# پیوست دستورالعمل‌ها

## دستورالعمل‌های ویژه‌ی مسیر

برای تنوع، می‌توانید راه‌حلی با تابع `unfold` را هم امتحان کنید.
احتمالاً از قبل با `foldLeft/Right` آشنا هستید: یک مجموعه‌ی کامل را به چیزی دیگر «نگاشت» می‌کنید که معمولاً مجموعه نیست.
`unfold` عملیات «معکوس» است: چیزی را که معمولاً مجموعه نیست به یک مجموعه «نگاشت» می‌کند.
پس `unfold` کردن افزوده‌ای منطقی به مجموعه‌ی استاندارد برنامه‌نویسی تابعی است و بخشی از آن به شمار می‌رود.

این تمرین را می‌توان نمونه‌ای از کاربرد `unfold` کردن دانست: یک `Int` را به یک `String` «نگاشت» می‌کنید (که البته به‌طور ضمنی یک `Seq[Char]` است).

مجموعه‌های Scala از نسخه‌ی ۲.۱۳ آن را دارند، برای مثال [`List.unfold`][list] و `Iterator.unfold`.
این تابع یک حالت آغازین و تابعی می‌گیرد که عنصر بعدی و حالت بعدی را برمی‌گرداند، یا برای توقف `None` برمی‌گرداند:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
