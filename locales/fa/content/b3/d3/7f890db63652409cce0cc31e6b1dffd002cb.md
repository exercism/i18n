# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به شما کمک می‌کند برای خرید خودرو آماده شوید.

سه کار پیش رو دارید: یکی برای تعیین اینکه آیا به گواهینامه نیاز دارید یا نه، یکی برای اینکه میان دو خودرو یکی را انتخاب کنید و یکی برای برآورد قیمت مناسب یک خودروی دست‌دوم.

## 1. تعیین کنید که آیا به گواهینامه‌ی رانندگی نیاز دارید

رانندگی با برخی از انواع خودرو به گواهینامه نیاز دارد.
فرض کنید فقط دو نوع `car` و `truck` به گواهینامه نیاز دارند و بقیه را می‌توان بدون گواهینامه راند.

تابع `needs_license(kind)` را پیاده‌سازی کنید؛ این تابع نوع خودرو را می‌گیرد و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا برای آن نوع خودرو به گواهینامه نیاز دارید یا نه.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. انتخاب میان دو خودروی بالقوه برای خرید

شما گزینه‌های خودروهای موجود را بررسی می‌کنید.
توانسته‌اید گزینه‌ها را به دو مورد محدود کنید اما برای گرفتن تصمیم نهایی به کمک نیاز دارید.
برای این کار تابع `choose_vehicle(option1, option2)` را پیاده‌سازی کنید؛ این تابع دو خودرو را به عنوان ورودی می‌گیرد و تصمیمی برمی‌گرداند که به سادگی همان گزینه‌ای است که در ترتیب الفبایی جلوتر می‌آید.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. محاسبه‌ی یک برآورد برای قیمت خودروی دست‌دوم

حالا که تصمیم خود را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی قیمت منصفانه‌ای می‌پردازید.
چون می‌خواهید خودروی دست‌دومی بخرید، قیمت به سن خودرو بستگی دارد.
برای یک برآورد تقریبی، فرض کنید اگر سن خودرو کمتر از ۳ سال باشد، قیمت آن ۸۰٪ قیمت اصلی‌اش در زمان نو بودن است.
اگر سن آن بیش از ۱۰ سال باشد، ۵۰٪ قیمت اصلی است.
اگر سن خودرو دست‌کم ۳ سال باشد اما بیشتر از ۱۰ سال نباشد، ۷۰٪ قیمت اصلی است.

تابع `calculate_resale_price(original_price, age)` را پیاده‌سازی کنید.
این تابع قیمت اصلی و سن خودرو را به عنوان ورودی می‌گیرد و قیمت برآوردشده در نمایندگی را برمی‌گرداند.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
