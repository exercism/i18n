# درباره

حوزه‌ی یک مقدار به این مربوط است که در کدام قسمت برنامه می‌توان به آن مقدار دسترسی داشت.

## چهار نوع حوزه: بلوک؛ تابع؛ پروتوتایپ تابع؛ فایل

### حوزه‌ی بلوکی

مقداری که حوزه‌ی بلوکی دارد، فقط از درون بلوکی که در آن تعریف شده قابل دسترسی است. برای اطلاعات بیشتر درباره‌ی بلوک‌ها، [مفهوم بلوک](../blocks/introduction.md#Introduction) را ببینید.

### حوزه‌ی تابعی

حوزه‌ی تابعی نوع خاصی از حوزه است که به برچسب‌هایی اعمال می‌شود که همراه دستورهای `goto` به کار می‌روند. دو برچسب با اسم یکسان را نمی‌توان در یک تابع به کار برد، حتی اگر آن برچسب‌ها در بلوک‌های جداگانه‌ای درون همان تابع تعریف شده باشند.

### حوزه‌ی پروتوتایپ تابع

حوزه‌ی پروتوتایپ تابع نوع خاص دیگری از حوزه است که فقط به پارامترهایی اعمال می‌شود که درون پروتوتایپ نام‌گذاری می‌شوند (به آن اعلان هم می‌گویند؛ البته در نظر داشته باشید که همه‌ی اعلان‌ها پروتوتایپ نیستند.)
اسم پارامتر در اعلان یک تابع معمولاً اختیاری است.
حوزه‌ی یک اسم فقط درون همان اعلان معنا دارد.
در مثال زیر، شناسه‌ی `len` تعریف می‌شود و بعداً در همان اعلان تابع به آن ارجاع داده می‌شود.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

توجه کنید که درون یک اعلان، وقتی به یک متغیر یکسان ارجاع داده می‌شود، اسم‌ها باید با هم مطابقت داشته باشند.
اگر `my_func` به‌صورت `void my_func(int len, int numbers[length]);` اعلان می‌شد، خطای کامپایلی تولید می‌شد شبیه به این:

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

تعریف یک تابع لازم نیست برای یک پارامتر از همان اسمی استفاده کند که در اعلان تابع به کار رفته بود.
در مثال بالا، در اعلان از `len` استفاده شده بود و در تعریف از `length`؛ که نشان می‌دهد حوزه‌ی شناسه‌ی `len` فقط درون اعلان تابع بوده است.

### حوزه‌ی فایل

مقداری که حوزه‌ی فایل دارد، از هر جای فایل قابل دسترسی است.
هر مقداری از این نوع، بیرون از یک تابع تعریف می‌شود.
