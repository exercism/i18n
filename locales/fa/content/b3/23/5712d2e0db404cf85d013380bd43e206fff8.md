# مقدمه

## برابری

انواع Elm را می‌توان با عملگر برابری `(==)` از نظر «یکسان بودن» بررسی کرد.
عملگر نابرابری `(/=)` است (*نه* `!=` مانند بسیاری از زبان‌ها).
عملگر برابری روی مقدارهای ثابت، تاپل‌ها، رکوردها و انواع سفارشی کار می‌کند.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

توجه کنید که *هرگز نباید* توابع را با هم مقایسه کنید، چون این کار باعث می‌شود برنامه در زمان اجرا از کار بیفتد.

## مقایسه‌ها

عملگرهای مقایسه `(<)`، `(<=)`، `(>)`، `(>=)` و توابع `min`، `max`، `compare` روی نوع‌های `comparable` کار می‌کنند.
نوع `comparable` یک نوع ویژه است که همه‌ی انواع داخلی را که می‌توان مقایسه کرد در خود جمع می‌کند: عددها، کاراکترها، رشته‌ها، لیست‌هایی از مقادیر `comparable` و تاپل‌هایی از مقادیر `comparable`.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

مقادیر انواع دیگر، مانند رکوردها یا انواع سفارشی، را نمی‌توان مستقیماً مقایسه کرد.

برخی از انواع داخلی نیاز دارند که محتوایشان `comparable` باشد، مانند کلیدهای `Set` یا `Dict`، چون ساختارشان به یک ترتیب داخلی وابسته است.

لیست‌هایی از مقادیر `comparable` را می‌توان با `List.sort` مرتب کرد و لیست‌هایی از مقادیری را که می‌توان به مقادیر `comparable` نگاشت، می‌توان با `List.sortBy` مرتب کرد.
اگر به یک مرتب‌سازی سلسله‌مراتبی نیاز دارید (مرتب‌سازی بر اساس یک ویژگی و شکستن تساوی‌ها با ویژگی دیگر)، می‌توان از تاپل‌ها یا لیست‌ها هم با `List.sortBy` استفاده کرد، چون تاپل‌ها و لیست‌ها به ترتیب واژه‌نامه‌ای مرتب می‌شوند.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

تابع `compare` دو مقدار `comparable` می‌گیرد و یک `Order` برمی‌گرداند.
یک `Order` نوعی است که در یک عملیات واحد بررسی می‌کند آیا یک مقدار از دیگری بزرگ‌تر (`GT`)، مساوی (`EQ`) یا کوچک‌تر (`LT`) است.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

می‌توان توابع مقایسه را برای انواع دلخواه ساخت و مثلاً از آن‌ها برای مرتب‌سازی با `List.sortWith` استفاده کرد:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
