# حلقه‌های For

«حلقه‌زدن» مفهومی بنیادی در برنامه‌نویسی است که به شما امکان می‌دهد یک «بلوک کد» را چندین بار اجرا کنید.
در Swift دو نوع حلقه وجود دارد: [حلقه‌های `for-in`][for-loops] و حلقه‌های `while`.
در این فصل، درباره‌ی حلقه‌های `for-in` یاد می‌گیرید.

حلقه‌های For به شما امکان می‌دهند روی دنباله‌ای از مقادیر پیمایش کنید، هر عنصر را به ترتیب بردارید و آن را به متغیری به انتخاب خودتان متصل کنید.
Swift به شما امکان می‌دهد روی انواع گوناگونی از دنباله‌ها پیمایش کنید، مانند بازه‌ها، آرایه‌ها و رشته‌ها (و انواع دیگری که بعداً بررسی می‌شوند).
وقتی روی همه‌ی عنصرهای دنباله پیمایش شد، حلقه پایان می‌یابد.

حلقه‌های For با استفاده از کلیدواژه‌ی `for` تعریف می‌شوند، سپس اسم یک متغیر، کلیدواژه‌ی `in` و دنباله‌ای از مقادیر که روی‌شان پیمایش می‌شود.
متغیری که در حلقه‌ی `for-in` داده می‌شود تغییرناپذیر است، یعنی نمی‌توانید مقدارش را درون حلقه تغییر دهید.
در ادامه نمونه‌ای از یک حلقه‌ی `for-in` را می‌بینید که روی آرایه‌ای از اعداد پیمایش می‌کند:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
متغیر `number` در حلقه‌ی `for-in` تعریف می‌شود و فقط درون حوزه‌ی دید آن حلقه در دسترس است.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## پیمایش روی یک بازه

همچنین می‌توانید با یک حلقه‌ی `for-in` روی بازه‌ای از اعداد پیمایش کنید.
این کار به شما امکان می‌دهد یک بلوک کد را تعداد مشخصی بار اجرا کنید؛ برای نمونه، بازه‌ی `1...5` روی اعداد ۱، ۲، ۳، ۴ و ۵ پیمایش می‌کند، بنابراین حلقه ۵ بار اجرا می‌شود.
گاهی ممکن است بخواهید روی اندیس‌ها در یک ساختمان داده مانند آرایه پیمایش کنید؛ در این صورت می‌توانید از بازه‌ی `0..<array.count` استفاده کنید.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## پیمایش روی یک رشته

همچنین می‌توانید با یک حلقه‌ی `for-in` روی یک رشته پیمایش کنید.
این کار به شما امکان می‌دهد روی هر نویسه در رشته پیمایش کنید؛ و توجه کنید که نوع داده‌ی داده‌شده در حلقه `Character` است.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift همچنین تابعی به اسم `stride` ارائه می‌دهد که به شما امکان می‌دهد دنباله‌ای روی یک بازه با گام مشخص بسازید.
که سپس می‌توان با یک حلقه‌ی `for-in` روی آن پیمایش کرد.
`stride` به‌صورت [`stride(from:to:by:)`][stride-to] یا [`stride(from:through:by:)`][stride-through] تعریف می‌شود؛ اولی کرانه‌ی پایان را شامل نمی‌شود و دومی آن را در بر می‌گیرد.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

توجه کنید که پارامتر `to` مقدار پایانی را شامل نمی‌شود، بنابراین حلقه تا عدد پیش از پارامتر `to` پیمایش می‌کند، در حالی که پارامتر `through` مقدار پایانی را هم در بر می‌گیرد، پس در این حالت `10` را نیز شامل می‌شود.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
