# درباره

Gleam مقادیر «درست» و «غلط» را با نوع `Bool` نمایش می‌دهد. فقط دو مقدار وجود دارد: `True` و `False`. این مقادیر را می‌توان به یک متغیر مقید کرد:

```gleam
let true_variable = True
let false_variable = False
```

عملگرهای `&&`، `||` و `!` را می‌توان برای دست‌کاری مقادیر «منطقی» استفاده کرد:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

عملگرهای `&&` و `||` از «ارزیابی اتصال کوتاه» استفاده می‌کنند، یعنی عبارت سمت راست عملگر فقط در صورت نیاز ارزیابی می‌شود.

هر یک از این عملگرها اولویت متفاوتی دارد، به‌طوری‌که `!` پیش از `&&` و `||` ارزیابی می‌شود. می‌توان از «آکولادها» استفاده کرد تا یک بخش از عبارت پیش از بخش‌های دیگر ارزیابی شود:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
