# مقدمه

در Common Lisp، مانند زبان‌های دیگر، «آرایه» مجموعه‌ای از عنصرهاست که با اندیس‌های صحیح به آن‌ها دسترسی پیدا می‌کنید.
نوع عنصرها می‌تواند ناهمگون باشد.
آرایه می‌تواند چندبعدی باشد (نه صرفاً یک‌بعدی).

## ساختن

`make-array` به شما امکان می‌دهد آرایه بسازید.
این تابع گزینه‌های زیادی دارد، اما شکل‌های ساده‌ترش به شما این امکان را می‌دهند که آرایه‌ای چندبعدی بسازید که همه‌ی عنصرهایش با یک مقدار واحد مقداردهی اولیه شده باشند، یا اینکه آرایه با مقدارهای یک دنباله‌ی دیگر (مثل یک لیست) مقداردهی اولیه شود.
اولین آرگومان آن لیستی از اندازه‌ی هر بُعد است.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(توجه کنید که آرایه‌های چندبعدی همراه با تعداد ابعادشان چاپ می‌شوند.)

آرایه‌ها را همچنین می‌توان با همان قالبی ساخت که در آن چاپ می‌شوند:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## دسترسی به عنصرها

برای دسترسی به عنصرهای یک بردار از `aref` استفاده کنید؛ اندیس‌ها از صفر شروع می‌شوند.
تعداد اندیس‌هایی که ارائه می‌دهید باید با رتبه‌ی آرایه هم‌خوانی داشته باشد.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
