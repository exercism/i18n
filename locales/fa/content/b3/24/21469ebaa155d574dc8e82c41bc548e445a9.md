# درباره

یک **«word»** در Factor نامی است برای یک تابع. شما «پشتهی داده» و
wordهای جابهجایی را در `basics` دیدهاید؛ اینجا wordهای خودتان را تعریف میکنید که
با ورودیهایشان محاسبه میکنند.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

یک تعریف شامل `:`، یک «اثر پشتهای»، بدنه و سپس `;` است. نامهای
داخل `( … -- … )` برای خوانندهاند؛ چیزی که کامپایلر بررسی میکند
*تعداد* ورودیها و خروجیهاست. عدم تطابق یک «خطای زمان کامپایل» است،
که دستهای از باگها را میگیرد که در یک «زبان با نوعپویا» و بدون این نوع اعلان، «خطای زمان اجرا» میشدند.

wordهای محاسبات اعداد صحیح `+`، `-` و `*` از «واژگان» `math` میآیند و هرکدام دو عدد را از بالای پشته مصرف میکنند. بالای پشته «عملوند» سمت راست است، بنابراین `8 3 -` مقدار `8 - 3` را محاسبه میکند.

`CONSTANT:` نامی برای یک «مقدار ثابت» تعریف میکند؛ فراخوانی آن نام مقدار را روی پشته میگذارد، دقیقاً مانند هر word دیگری. «ثابتها» را بالای فایل قرار دهید، پیش از هر wordی که از آنها استفاده میکند.

بدنهی یک word میتواند هر wordی را که در «محدوده» است فراخوانی کند، یعنی تعریفهای قبلی در همان فایل، wordهای واژگان واردشده و ثابتهایی که اعلام کردهاید. ترکیب wordهای کوچک و تکمنظوره روش معمول ساخت یک برنامه است.

بر اساس قرارداد:

- wordها و ثابتها از `lowercase-kebab-case` استفاده میکنند.
- «محمولها» به `?` ختم میشوند و یک «مقدار منطقی» تولید میکنند (`even?`، `empty?`).
- wordهایی که ورودیشان را تغییر میدهند اغلب نامشان با نسخهی بدون تغییر مشترک است و فقط از روی زمینه تشخیص داده میشوند.
