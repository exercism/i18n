# دستورالعمل‌ها

در این تمرین قرار است کدی بنویسید که به شما کمک کند از کتاب آشپزی محبوب‌تان یک لازانیای عالی بپزید.

پنج وظیفه دارید که همه به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار پخت در فر را بر حسب دقیقه تعریف کنید

متغیر تغییرناپذیر `expectedMinutesInOven` را تعریف کنید؛ این متغیر برمی‌گرداند که لازانیا باید چند دقیقه در فر بماند.
باید صادر شود.
بر اساس کتاب آشپزی، زمان مورد انتظار پخت در فر 40 دقیقه است:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. زمان باقی‌مانده‌ی پخت در فر را بر حسب دقیقه محاسبه کنید

رویه‌ی `remainingMinutesInOven` را پیاده‌سازی کنید. این رویه، تعداد دقایقی را که لازانیا تا این لحظه در فر بوده به عنوان پارامتر می‌گیرد و بر اساس زمان مورد انتظار پخت در فر از وظیفه‌ی قبلی، برمی‌گرداند که لازانیا باید چند دقیقه‌ی دیگر در فر بماند.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

رویه‌ی `preparationTimeInMinutes` را پیاده‌سازی کنید. این رویه تعداد لایه‌هایی را که به لازانیا اضافه کرده‌اید به عنوان پارامتر می‌گیرد و برمی‌گرداند که چند دقیقه صرف آماده‌سازی لازانیا کرده‌اید، با این فرض که آماده‌سازی هر لایه 2 دقیقه طول می‌کشد.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. زمان کل کار را بر حسب دقیقه محاسبه کنید

رویه‌ی `totalTimeInMinutes` را پیاده‌سازی کنید که دو پارامتر می‌گیرد: پارامتر `numberOfLayers` تعداد لایه‌هایی است که به لازانیا اضافه کرده‌اید و پارامتر `actualMinutesInOven` تعداد دقایقی است که لازانیا در فر بوده.
این رویه باید برگرداند که در کل چند دقیقه روی پخت لازانیا کار کرده‌اید، یعنی مجموع زمان آماده‌سازی، بر حسب دقیقه، و زمانی که لازانیا تا این لحظه در فر گذرانده است.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
