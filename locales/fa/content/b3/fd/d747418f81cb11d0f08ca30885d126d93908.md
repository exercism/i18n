# پیوست دستورالعمل

## ساختار این تمرین در Python

ما یک توصیفگر هفته‌ی دیگر (`fifth`) هم اضافه کرده‌ایم که به پنجمین روز هفته در ماه اشاره می‌کند، به شرط آنکه وجود داشته باشد.  
اگر پنجمین روز هفته در یک ماه وجود نداشته باشد، باید یک «استثنا» پرتاب کنید.

## سفارشی‌سازی و پرتاب استثناها

گاهی لازم است در code خودتان، استثناها را هم [سفارشی‌سازی](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) کنید و هم [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) کنید. وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** را بگنجانید تا نشان دهد منبع خطا چیست. این کار code شما را خواناتر می‌کند و کمک چشمگیری به debug می‌کند.

استثناهای سفارشی را می‌توان از طریق کلاس‌های استثنای تازه ساخت (برای جزئیات بیشتر [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) را ببینید.) که معمولاً زیرکلاس‌های [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) هستند.

در موقعیت‌هایی که می‌دانید منبع خطا مشتق‌شده از یک نوع استثنای خاص خواهد بود، می‌توانید انتخاب کنید که از یکی از [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) زیر کلاس _Exception_ ارث‌بری کنید. هنگام پرتاب خطا هم همچنان باید یک پیام معنادار را بگنجانید.

این تمرین خاص می‌خواهد که شما یک _استثنای سفارشی_ بسازید تا وقتی تابع `meetup()` شما ترکیب نامعتبری از اسم روز هفته و شماره دریافت می‌کند، [پرتاب](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/«thrown» شود. تست‌ها تنها در صورتی پاس می‌شوند که استثناهای مناسب را سفارشی‌سازی کنید، آن استثناها را `raise` کنید و پیام‌های خطای مناسب را هم بگنجانید.

برای سفارشی‌سازی یک `built-in exception`، یک `class` بسازید که از آن استثنا ارث‌بری می‌کند. وقتی استثنای سفارشی را همراه با یک پیام پرتاب می‌کنید، پیام را به‌عنوان آرگومان برای نوع `exception` بنویسید:

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
