# مقدمه

این که یک «آرایه» هم یک «مجموعه» است یعنی می‌توانید علاوه بر دسترسی به مقدارها با اندیس، روی همه‌ی مقدارهای آن هم با یک حلقه‌ی `foreach` پیمایش کنید:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
