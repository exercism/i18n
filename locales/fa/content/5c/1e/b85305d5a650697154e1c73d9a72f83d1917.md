# دستورالعمل‌ها

در این تمرین با یک ماشین کنترلی سر و کار دارید؛ ماشینی که بالاخره پول کافی برای خریدنش را پس‌انداز کرده‌اید.

ماشین‌ها با باتری کاملاً پر (۱۰۰٪) شروع می‌کنند.
هر بار که ماشین را با کنترل از راه دور می‌رانید، ۲۰ متر جلو می‌رود و یک درصد از باتری را مصرف می‌کند.
اسم مستعار ماشین تا زمانی که ساخته نشود، معلوم نیست.

ماشین کنترلی یک نمایشگر LED شیک دارد که دو بخش اطلاعات را نشان می‌دهد:

- مسافت کل طی‌شده که به این شکل نمایش داده می‌شود: `"<METERS> meters"`.
- شارژ باقی‌مانده‌ی باتری که به این شکل نمایش داده می‌شود: `"Battery at <PERCENTAGE>%"`.

اگر باتری به ۰٪ برسد، دیگر نمی‌توانید ماشین را برانید و نمایشگر باتری `"Battery empty"` را نشان می‌دهد.

## 1. ساخت یک ماشین کنترلی کاملاً نو

تابع `new_remote_control_car/0` را پیاده‌سازی کنید تا یک شیء ماشین کنترلی کاملاً نو برگرداند:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. ساخت یک ماشین کنترلی کاملاً نو با اسم مستعار

تابع `new_remote_control_car/1` را پیاده‌سازی کنید تا یک شیء ماشین کنترلی کاملاً نو با اسم مستعار داده‌شده برگرداند:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. نمایش مسافت

تابع `display_distance/0` را پیاده‌سازی کنید که یک شیء ماشین را به عنوان ورودی می‌گیرد و رشته‌ی مسافت را همان‌طور که روی نمایشگر LED نشان داده می‌شود، خروجی می‌دهد:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. نمایش درصد باتری

تابع `display_battery/0` را پیاده‌سازی کنید که یک شیء ماشین را به عنوان ورودی می‌گیرد و رشته‌ی درصد باتری را همان‌طور که روی نمایشگر LED نشان داده می‌شود، خروجی می‌دهد:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

اگر باتری به ۰٪ برسد، نمایشگر باتری «Battery empty» را نشان می‌دهد.

## 5. رانندگی باتری و مسافت طی‌شده را تغییر می‌دهد

تابع `drive/0` را پیاده‌سازی کنید که:

- یک شیء ماشین را به عنوان ورودی می‌گیرد
- تعداد مترهای طی‌شده را ۲۰ واحد افزایش می‌دهد
- یک درصد از باتری را مصرف می‌کند
- شیء ماشین تغییر‌یافته را خروجی می‌دهد

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. در نظر گرفتن رانندگی با باتری خالی

تابع `drive/0` را طوری به‌روزرسانی کنید که وقتی باتری خالی است (۰٪)، نه مسافت طی‌شده افزایش یابد و نه درصد باتری کاهش پیدا کند:

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
