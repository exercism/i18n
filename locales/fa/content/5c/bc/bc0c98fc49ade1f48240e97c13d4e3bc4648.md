# مقدمه

## Result

نوع `Result` در زبان Elm راه‌حلِ گزارش خطا و امکان‌بخش بازیابی از خطاست. تا حدی شبیه نوع `Maybe` است، اما `Maybe` را می‌توان از توابعی برگرداند که ممکن است شکست بخورند، در حالی که هیچ چیزی درباره‌ی دلیل شکست به شما نمی‌گوید. `Result` همین زمینه درباره‌ی دلیل شکست را در خود دارد.

نوع `Result` به این صورت تعریف می‌شود:

```elm
type Result error value
  = Ok value
  | Err error
```

این در اصطلاحات Elm به تعریف «نوع سفارشی» معروف است.
`error` و `value` در `OK value` و `Error error` یک متغیر نوع را نشان می‌دهند، یعنی می‌توانند هر نوعی باشند، مانند `Int`، `Bool` یا `String`.
بر همین اساس، `Result String Int` متغیری است که انتظار می‌رود یک `Int` در خود داشته باشد و اگر خطایی رخ دهد، به‌صورت `String` نمایش داده می‌شود.
یک [ماژول Result](https://package.elm-lang.org/packages/elm/core/latest/Result) وجود دارد که پر از توابع کمکی مفید برای Result است.
