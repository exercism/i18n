# دستورالعمل

در این تمرین، مدیریت خطا را برای یک ماشین‌حساب ساده‌ی اعداد صحیح پیاده‌سازی می‌کنید.
برای اینکه کار ساده‌تر شود، متدهایی برای محاسبه‌ی جمع، ضرب و تقسیم در اختیار شما قرار داده شده است.

هدف این است که یک ماشین‌حساب کارآمد داشته باشید که با دریافت آرگومان‌های `16`، `51` و `+`، یک `String` با الگوی زیر برگرداند: `16 + 51 = 67`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. پیاده‌سازی متد `calculate` برای پشتیبانی از چند عملیات پایه

متد اصلی که در این تمرین باید پیاده‌سازی کنید، متد `CalculatorConundrum.calculate()` است.
این متد سه آرگومان می‌گیرد.
دو آرگومان اول یعنی `operand1` و `operand2` اعداد صحیحی هستند که عملیات روی آن‌ها انجام می‌شود.
آرگومان سوم یعنی `operation` از نوع `String` است و در این تمرین باید عملیات زیر را پیاده‌سازی کنید:

- جمع با استفاده از رشته‌ای که `+` است
- ضرب با استفاده از رشته‌ای که `*` است
- تقسیم با استفاده از رشته‌ای که `/` است

## 2. مدیریت عملیات غیرمجاز

متد `CalculatorConundrum.calculate()` را به‌روزرسانی کنید تا عملیات غیرمجاز را مدیریت کند:

- وقتی آرگومان `operation` برابر `null` باشد، باید یک `IllegalArgumentException` با پیام `Operation cannot be null` پرتاب شود.
- وقتی آرگومان `operation` برابر `""` باشد، باید یک `IllegalArgumentException` با پیام `Operation cannot be empty` پرتاب شود.
- وقتی آرگومان `operation` هر عملیاتی به‌جز `+`، `*` یا `/` باشد، باید یک `IllegalOperationException` با پیام `Operation '{operation}' does not exist` پرتاب شود.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. مدیریت استثنایی که هنگام تقسیم بر صفر پرتاب می‌شود

در Java، تلاش برای تقسیم بر صفر یک `ArithmeticException` پرتاب می‌کند.
متد `CalculatorConundrum.calculate()` را به‌روزرسانی کنید تا این استثنا را بگیرد و سپس یک `IllegalOperationException` با پیام `Division by zero is not allowed` و `ArithmeticException` گرفته‌شده به‌عنوان علت آن پرتاب کند.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
