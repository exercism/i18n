# مقدمه

یک [`List`][lists] در Elm مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار هم‌نوع است.

لیست‌ها را می‌توان به صورت زیر تعریف کرد:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

رایج‌ترین راه برای افزودن یک عنصر به لیست، استفاده از عملگر `::` (cons) است:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

لیست‌ها با توابع و عملگرهای تعریف‌شده در [ماژول `List`][list-module] یا با [تطبیق الگو][list-destructuring] دستکاری می‌شوند.

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
