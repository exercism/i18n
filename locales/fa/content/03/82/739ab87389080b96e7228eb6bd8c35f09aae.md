# دستورالعمل‌ها

الن در حال ساختن بازی‌ای است که در آن بازیکن باید با موجودات فضایی بجنگد.
او تازه با «برنامه‌نویسی شیءگرا» (OOP) آشنا شده و مشتاق است از آنچه استفاده از `classes` می‌تواند برای برنامه‌اش فراهم کند بهره ببرد.

الن خوشحال شد که شما پیشنهاد کمک داده‌اید و او وظیفه‌ی برنامه‌نویسی موجودات فضایی‌ای را که بازیکن باید با آن‌ها بجنگد به شما سپرده است.


## 1. ساخت کلاس `Alien`

کلاس `Alien` را با یک سازنده تعریف کنید که دو پارامتر `int` به نام‌های `x` و `y` می‌گیرد و آن‌ها را در متغیرهای عضو `x_coordinate` و `y_coordinate` قرار می‌دهد.
هر موجود فضایی هم با سطح جان `3` شروع می‌کند، بنابراین متغیر عضو `health` هم باید مقداردهی اولیه شود.

`health` باید یک متغیر عضو خصوصی باشد.
الن می‌خواهد برای اینکه بخش‌های دیگر برنامه بتوانند اطلاعات جان را بخوانند، یک متد `public` به نام `get_health()` داشته باشد که یک `int` برمی‌گرداند.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

حالا هر موجود فضایی باید بتواند موقعیت و جان خودش را به‌صورت داخلی ردیابی کند.

## 2. تابع `hit`

الن می‌خواهد `class` مربوط به Alien یک متد `hit` داشته باشد که هنگام فراخوانی، جان یک شیء موجود فضایی را به اندازه‌ی `1` کاهش می‌دهد.
به این ترتیب، او می‌تواند به‌سادگی `some_alien_instance.hit()` را فراخوانی کند، به‌جای اینکه جان یک موجود فضایی را دستی تغییر دهد.
مطمئن شوید که نقاط جان زیر صفر نیفتند.
این تابع باید `true` برگرداند.
الن می‌خواهد بعداً سپرهایی معرفی کند که در آن صورت اگر سپر فعال باشد، `false` گزارش می‌دهند.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. تابع `is_alive`

متوجه می‌شوید که اگر جان مدام کم شود، احتمالاً در نقطه‌ای به `0` می‌رسد.
ایده‌ی خوبی است که یک متد `is_alive` اضافه کنید تا الن بتواند سریع آن را فراخوانی کند و بررسی کند آیا موجود فضایی... خب... زنده است. 😉
`some_alien_instance.is_alive()` باید یک «مقدار منطقی» برگرداند.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. تابع `teleport`

در بازی الن، موجودات فضایی می‌توانند تلپورت کنند!
باید یک متد `teleport` بنویسید که مقادیر `x_new` و `y_new` را می‌گیرد و مختصات موجود فضایی را بر همان اساس تغییر می‌دهد.
فعلاً این تابع باید `true` برگرداند.
الن می‌خواهد در مراحل بعدی بمب‌هایی اضافه کند که جلوی تلپورت را می‌گیرند و در آن صورت برای تلاش‌های ناموفق تلپورت، `false` گزارش می‌دهند.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. تابع `collision_detection`

اگر ممکن است موجودات فضایی مورد اصابت چیزی قرار بگیرند، آن‌ها باید بتوانند تشخیص دهند چنین برخوردی چه زمانی ممکن است رخ دهد.
الن باید بداند آیا دو موجود فضایی مختصات یکسانی را اشغال می‌کنند یا نه.
تابع `collision_detection()` یک شیء موجود فضایی دیگر را به‌عنوان آرگومان می‌گیرد و یک `bool` برمی‌گرداند.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
