# نرمال‌سازی‌های representer

[representer زبان F#][representer] نرمال‌سازی‌های زیر را اعمال می‌کند:

## حذف توضیحات

همه‌ی توضیحات حذف می‌شوند.

### قبل

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### بعد

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## حذف اعلان‌های import

همه‌ی اعلان‌های import حذف می‌شوند.

### قبل

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### بعد

```fsharp
module Fake

let message = "Hi"
```

## قالب‌بندی کد

کد با استفاده از [کتابخانه‌ی fantomas][fantomas] قالب‌بندی می‌شود.
این کار کد را بر اساس راهنمای سبک F# قالب‌بندی می‌کند.
فهرست کامل تغییراتی که fantomas اعمال می‌کند را می‌توانید [اینجا][fantomas-formatting] ببینید.

### قبل

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### بعد

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## نرمال‌سازی شناسه‌ها

شناسه‌ها به یک مقدار جانگهدار نرمال‌سازی می‌شوند.

### قبل

```fsharp
module Fake

let foo x = x + 1
```

### بعد

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
