# مقدمه

## مبانی

[Lua](https://lua.org) یک زبان اسکریپت‌نویسی ساده اما قدرتمند، کارا، سبک و قابل جاسازی است. این زبان از سال ۱۹۹۳ در [PUC-RIO](https://www.puc-rio.br/) در برزیل، توسط تیم روبرتو ایروسالیمسکی، والدمار سلس و لوئیز هنریکه د فیگوئیردو طراحی، پیاده‌سازی و نگهداری می‌شود.

### کامنت‌ها

کامنت‌های تک‌خطی در Lua با `--` شروع می‌شوند و کامنت‌های چندخطی با `--[[` شروع شده و با `]]` پایان می‌یابند.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### متغیرها

در Lua سه نوع متغیر وجود دارد: متغیرهای سراسری، متغیرهای محلی و فیلدهای جدول. برای ساده نگه داشتن ماجرا، در اینجا فقط متغیرهای محلی توضیح داده می‌شوند. به‌طور پیش‌فرض همه‌ی متغیرها سراسری هستند، بنابراین باید متغیرهای محلی را با کلیدواژه‌ی `local` به همین شکل تعریف کنیم.
```lua
local x
```

می‌توان با عملگر `=` به یک متغیر مقدار داد.
```lua
local x = 1
```

محدوده‌ی یک متغیر `local` به بلوکی محدود است که در آن تعریف شده است. یک «بلوک» می‌تواند بدنه‌ی یک ساختار کنترلی، بدنه‌ی یک تابع، یا فایل یا رشته‌ای باشد که متغیر در آن تعریف شده است.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### توابع

یک تابع با کلیدواژه‌ی `function` تعریف می‌شود و مانند متغیرها به‌طور پیش‌فرض سراسری است. تعریف یک تابع یک اسم، فهرستی از پارامترها و یک بدنه دارد. تابع هنگامی که به کلیدواژه‌ی `return` برسد از آن خارج می‌شود و همه‌ی مقادیری را که پس از آن فهرست شده‌اند برمی‌گرداند. بدون مشخص کردن `return`، تابع `nil` را برمی‌گرداند.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### جدول‌ها

جدول‌ها تنها سازوکار ساختاردهی داده در Lua هستند و بسیار قدرتمندند. از آن‌ها برای نمایش آرایه‌ها، مجموعه‌ها، شیءها، ماژول‌ها و موارد بسیار دیگری استفاده می‌شود. در واقع، یک جدول در Lua یک آرایه‌ی انجمنی است.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

این فقط نگاهی بسیار کوچک است که برای بخش بعدی لازم است. بعداً با جزئیات به این موضوع برمی‌گردیم.

### ماژول‌ها

ماژول مجموعه‌ای از کد است که در یک فایل منبع `.lua` ذخیره می‌شود. هر چیزی که ماژول صادر می‌کند در یک جدول ذخیره می‌شود و این جدول در پایان فایل برگردانده می‌شود. بنابراین جدول اساساً به‌عنوان نوعی فضای نام عمل می‌کند.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

سپس آن ماژول می‌تواند از طریق تابع `require` که همان جدول را برمی‌گرداند، در فایل دیگری بارگذاری شود.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

وقتی `say.hello` را می‌بینیم، به ذهنمان می‌آید که «تابع `hello` از ماژول `say`» است. اما با دانستن اینکه `say-hello.lua` ما یک جدول برمی‌گرداند و با نگاهی دوباره به بخش جدول‌ها، متوجه می‌شویم که در Lua این عبارت یعنی «نمایه‌گیری جدول `say` با استفاده از رشته‌ی `hello` به‌عنوان کلید».

اگرچه برگرداندن یک جدول از سوی ماژول روش خوبی است، اما برگرداندن هر نوع دیگری، مانند یک تابع، هم به همان اندازه ممکن است.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
