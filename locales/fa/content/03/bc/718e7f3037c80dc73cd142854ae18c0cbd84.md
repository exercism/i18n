# مقدمه

در مفهوم `Vectors` دیدیم که می‌توان از یک بردار در یک عبارت شرطی استفاده کرد که نتیجه‌اش یک «بردار منطقی» است.
خود این بردار هم می‌تواند در توابعی مانند `all()` و `any()` به کار رود.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

این تکنیک بسیار قدرتمندتر از این است.

## زیرمجموعه‌های بردار

می‌توان عناصر برگزیده‌ی یک بردار را با یک شماره‌ی اندیس یا با برداری از اندیس‌ها بیرون کشید:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

راه دیگر این است که با یک بردار منطقی، بردار اصلی را فیلتر کنید تا زیرمجموعه‌ای از عناصر برگردانده شود که با مقدار `TRUE` مطابقت دارند:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

از اینجا تا ساختن یک بردار منطقی با عبارت شرطی، فاصله‌ی چندانی نیست:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## پیدا کردن اندیس‌ها

تابع `which()` یک آرگومان منطقی می‌گیرد و برداری از اندیس‌ها را برمی‌گرداند که مقدار `TRUE` می‌دهند.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## بررسی وجود یک عنصر

بخش‌های پیشین درباره‌ی پیدا کردن عناصری بود که با معیاری مطابقت دارند.

اگر فقط می‌خواهید بدانید که بردار عنصر مشخصی را در خود دارد یا نه، از عملگر `%in%` استفاده کنید.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

این از نظر کارکرد با کد زیر هم‌ارز است، اما بسیار راحت‌تر:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
