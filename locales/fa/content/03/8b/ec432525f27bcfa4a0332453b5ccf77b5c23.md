# مقدمه

در Go، توابع «مقادیر درجه‌یک» هستند.
یعنی همان کارهایی را می‌توانید با توابع انجام دهید که با سایر مقادیر انجام می‌دهید: توابع را به متغیرها تخصیص دهید، آن‌ها را به‌عنوان آرگومان به توابع دیگر بدهید یا حتی توابعی را از توابع دیگر برگردانید.

در ادامه دو تابع `engGreeting` و `espGreeting` می‌سازیم و آن‌ها را به متغیر `greeting` تخصیص می‌دهیم:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

مقادیر تابعی این امکان را فراهم می‌کنند که توابع را نه‌فقط با داده، بلکه با رفتار نیز پارامتری کنید.
در مثال زیر، رفتار را از طریق پارامتر `greetingFunc` به تابع `dialog` می‌دهیم:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

مقدار یک متغیر مقداردهی‌نشده‌ی نوع تابع، `nil` است.
بنابراین، فراخوانی یک مقدار تابعی `nil` باعث بروز panic می‌شود.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

مقادیر تابعی را می‌توان با `nil` مقایسه کرد.
این می‌تواند برای جلوگیری از بروز panicهای غیرضروری در برنامه مفید باشد.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## نوع‌های تابع

استفاده از مقادیر تابعی به لطف «نوع‌های تابع» در Go ممکن است.
یک نوع تابع به مجموعه‌ی همه‌ی توابعی اشاره دارد که دنباله‌ی نوع پارامترها و دنباله‌ی نوع نتیجه‌ی یکسانی دارند.
نوع‌های تعریف‌شده توسط کاربر را می‌توان روی نوع‌های تابع اعلان کرد.
برای نمونه، تابع `dialog` از مثال‌های قبلی را می‌توان به‌صورت زیر به‌روزرسانی کرد:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## توابع بی‌نام

ابزار قدرتمند دیگری که به لطف پشتیبانی از توابع درجه‌یک در دسترس است، «توابع بی‌نام» هستند.
توابع بی‌نام در همان نقطه‌ی استفاده تعریف می‌شوند، بدون اسمی که پس از کلیدواژه‌ی `func` بیاید.
چنین توابعی به متغیرهای تابع دربرگیرنده دسترسی دارند.

برای مثال:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

فراخوانی `fib` متغیرهای `n1` و `n2` را اعلان می‌کند و یک تابع بی‌نام برمی‌گرداند که به‌نوبه‌ی خود، هر بار که تابع فراخوانی می‌شود مقدار این متغیرها را تغییر می‌دهد.
فراخوانی nاُم تابع بی‌نام، عدد nاُم دنباله‌ی فیبوناچی را با شروع از ۰ برمی‌گرداند. تابع بی‌نام درونی به متغیرهای محلی (`n1` و `n2`) تابع دربرگیرنده‌ی `fib` دسترسی دارد.
این روش خوبی است تا مقادیر تابعی وضعیت را بین فراخوانی‌ها حفظ کنند.
می‌گوییم که تابع بی‌نام یک «بستار» روی متغیرهای `n1` و `n2` است. [بستارها][closure] در برنامه‌نویسی به‌طور گسترده استفاده می‌شوند و ممکن است ببینید زبان‌های دیگر هم از آن‌ها پشتیبانی می‌کنند.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
