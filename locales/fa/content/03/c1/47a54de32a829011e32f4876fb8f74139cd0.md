# بازه

[بازه][range] فاصله‌ای بین دو مقدار را نشان می‌دهد.
رایج‌ترین نوع‌هایی که از بازه پشتیبانی می‌کنند `Int`، `Char` و `String` هستند.
از بازه‌ها می‌توان برای کارهای زیادی استفاده کرد، مثل ساختن سریع یک مجموعه، برش رشته‌ها، بررسی اینکه مقداری درون بازه هست یا نه، و پیمایش.
بازه‌ها با عملگر بازه‌ی `..` یا `...` ساخته می‌شوند (به‌ترتیب شامل مقدار پایانی و غیرشامل آن).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

دلیل وجود دو عملگر بازه این است که بتوان بازه‌ای ساخت که مقدار پایانی را شامل شود یا نه؛ این کار مثلاً هنگام کار با اندیس‌هایی که از صفر شروع می‌شوند به کار می‌آید.

بازه‌ها را می‌توان با سازنده‌ی `Range` هم ساخت.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
وقتی در Crystal با عملگرهای بازه‌ی `..` یا `...` بازه‌ای می‌سازید و می‌خواهید متدی روی آن فراخوانی کنید، باید بازه را داخل پرانتز بگذارید.
دلیلش این است که در غیر این صورت، متد روی آرگومان دوم عملگر بازه فراخوانی می‌شود.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## گرفتن زیررشته

وقتی می‌خواهید رشته‌ای را برش دهید، می‌توانید با عملگر بازه زیررشته را به دست آورید.
یعنی با ساختن بازه‌ای از اندیس شروع تا اندیس پایان زیررشته.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

همچنین می‌توانید از اندیس‌های منفی استفاده کنید تا زیررشته را از انتهای رشته بگیرید.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## متدهای بازه

بازه‌ها مجموعه‌ای از متدها دارند که می‌توان برای کار با آن‌ها به کار برد.
مثلاً با این متدها می‌توان مجموع همه‌ی مقادیر بازه را گرفت یا بررسی کرد که آیا بازه مقداری را در بر می‌گیرد.

| متد                     | توضیح                                                                   | مثال                            |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | مجموع همه‌ی مقادیر بازه را برمی‌گرداند                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | اندازه‌ی بازه را برمی‌گرداند                                            | `(1..5).size # => 5`            |
| [`includes?`][indludes] | اگر بازه مقدار داده‌شده را در بر بگیرد `true` و در غیر این صورت `false` برمی‌گرداند | `(1..5).includes?(3) # => true` |

## بازه‌های بی‌پایان و بی‌آغاز

یک بازه می‌تواند بی‌پایان یا بی‌آغاز باشد.
در بازه‌ی بی‌پایان یا بی‌آغاز، مقدار شروع یا پایان `nil` است، اما هنگام تعریف بازه می‌توان `nil` را حذف کرد.

استفاده از بازه‌های بی‌آغاز و بی‌پایان وقتی به کار می‌آید که مثلاً بخواهید رشته‌ای را از ابتدا یا تا انتها برش دهید.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
اگر روی یک مجموعه استفاده نشود، بازه‌ی بی‌پایان می‌تواند به یک توالی بی‌پایان منجر شود؛ پس با احتیاط از آن استفاده کنید.
~~~~

## بازه‌های `Char`

از کاراکترها می‌توان در بازه‌ها استفاده کرد و بازه‌ای از کاراکترها بین دو کاراکتر به دست آورد.
مثلاً این کار وقتی بخواهید الفبا را به دست آورید مفید است.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## بازه‌های رشته

از رشته‌ها هم می‌توان در بازه‌ها استفاده کرد و بازه‌ای از رشته‌ها بین دو رشته به دست آورد.
اما رفتارش وقتی چند کاراکتر در بازه‌ی رشته‌ای به کار می‌رود کمی با `Char` فرق دارد.
رفتارش در بازه‌های رشته‌ای پیچیده‌تر می‌تواند گیج‌کننده شود، پس احتیاط کنید.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## شیءهای سفارشی در بازه‌ها

~~~~exercism/advanced
Crystal به شما اجازه می‌دهد از شیءهای سفارشی در بازه‌ها استفاده کنید.
شرطش این است که شیء موارد زیر را پیاده‌سازی کند:

- ماژول `Comparable` را `include` کند
- متد `succ`
- متد `<=>`

این متدها باعث می‌شوند که بازه بتواند روی شیء پیمایش کند و شیءهای درون بازه را با هم مقایسه کند.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
