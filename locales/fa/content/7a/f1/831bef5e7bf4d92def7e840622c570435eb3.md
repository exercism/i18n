# مقدمه

یک `list` در R مجموعه‌ی مرتبی از عناصر است که از چند جهت با `vectors` تفاوت دارد:

- عناصر می‌توانند انواع مختلفی داشته باشند (مثلاً ترکیب `numeric` با `character`).
- عناصر می‌توانند ساختارهای پیچیده باشند (مثلاً بردارها، لیست‌های دیگر و غیره).
- نحوه‌ی نگارش دسترسی به عناصر کمی متفاوت است.

قیاس با زبان‌های دیگر چندان دقیق نیست.
`list` در R تا حدی شبیه دیکشنری Python است، اما `list` مرتب است و می‌توان با اندیس عددی به آن دسترسی داشت.
تا حدی شبیه `struct` در C است، با این تفاوت که `list` را می‌توان به‌راحتی در زمان اجرا گسترش داد.

## ساختن لیست

گذاشتن اسم روی عناصر (که اغلب «برچسب» نامیده می‌شود) در لیست‌ها بیش از بردارها رایج است:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

اما برچسب‌ها اختیاری‌اند و در آن صورت R فقط از شماره‌های اندیس استفاده می‌کند:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## دسترسی به عناصر لیست

سه راه برای انجام این کار وجود دارد که هر کدام در موقعیت‌های مختلفی به کار می‌آید.

### ۱. با نگارش `$tag`

اگر اسم برچسب‌ها از قبل معلوم باشد، بسیار رایج است.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### ۲. با نگارش `[[tag]]`

مزیتش این است که اسم برچسب را می‌توان در زمان اجرا انتخاب کرد.
به دو کروشه دقت کنید.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### ۳. با اندیس موقعیت

این روش چه لیست برچسب داشته باشد چه نداشته باشد کار می‌کند.
باز هم کروشه‌ها دوتایی‌اند.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## افزودن و حذف عناصر

ساده است: مقداردهی به یک عنصر، اگر از قبل وجود داشته باشد آن را تغییر می‌دهد و اگر تازه باشد آن را درج می‌کند.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

برای حذف، مقدار `NULL` را به عنصر ناخواسته بدهید.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
