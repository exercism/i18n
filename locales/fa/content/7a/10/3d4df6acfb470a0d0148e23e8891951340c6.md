# دستورالعمل‌ها

دوستتان چندلر قصد دارد به کشورهای عجیب و غریب در سراسر جهان سفر کند. متأسفانه مهارت‌های ریاضی چندلر خوب نیست. او نگران است که در طول سفرش سر صرافی‌ها کلاه سرش برود، و می‌خواهد شما یک ماشین‌حساب تبدیل ارز برایش بسازید. این هم مشخصات موردنظر او برای این برنامه است:

## 1. برآورد ارزش پس از تبدیل

تابع `exchange_money()` را بسازید که ۲ پارامتر می‌گیرد:

1. `budget` : مبلغی که قصد دارید تبدیل کنید.
2. `exchange_rate` : مقدار پول داخلی که معادل یک واحد ارز خارجی است.

این تابع باید ارزش ارز تبدیل‌شده را برگرداند.

**نکته:** اگر واحد پول شما USD است و می‌خواهید USD را با نرخ تبدیل `1.20` به EUR تبدیل کنید، آنگاه `1.20 USD == 1 EUR`.

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. محاسبه‌ی پول باقی‌مانده پس از تبدیل

تابع `get_change()` را بسازید که ۲ پارامتر می‌گیرد:

1. `budget` : مبلغ پول پیش از تبدیل.
2. `exchanging_value` : مبلغی که برای تبدیل از بودجه *برداشت* می‌شود.

این تابع باید مبلغی را برگرداند که از بودجه *باقی می‌ماند*.

```python
>>> get_change(127.5, 120)
7.5
```

## 3. محاسبه‌ی ارزش اسکناس‌ها

تابع `get_value_of_bills()` را بسازید که ۲ پارامتر می‌گیرد:

1. `denomination` : ارزش یک اسکناس.
2. `number_of_bills` : تعداد کل اسکناس‌ها.

این باجه‌ی تبدیل فقط با پول نقد در مضرب‌های مشخصی سر و کار دارد.
مبلغی که دریافت می‌کنید باید بر ارزش یک «اسکناس» یا واحد بخش‌پذیر باشد؛ این تقسیم ممکن است کسری یا باقی‌مانده داشته باشد.
تابع شما باید فقط ارزش کل اسکناس‌هایی را که باجه پس می‌دهد برگرداند (_بدون احتساب مبالغ کسری_).
متأسفانه باجه باقی‌مانده/پول خرد را به‌عنوان یک امتیاز اضافی برای خودش نگه می‌دارد.

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. محاسبه‌ی تعداد اسکناس‌ها

تابع `get_number_of_bills()` را بسازید که پارامترهای `amount` و `denomination` را می‌گیرد.

این تابع باید _تعداد اسکناس‌های ارز_ را برگرداند که می‌توانید در _مبلغ_ داده‌شده دریافت کنید.
به عبارت دیگر: چند _اسکناس کامل_ در مبلغ اولیه جا می‌شود؟
یادتان باشد که فقط _اسکناس‌های کامل_ دریافت می‌کنید، نه کسری از اسکناس، پس تقسیم را بر همین اساس انجام دهید.
در واقع دارید به نزدیک‌ترین اسکناس/واحد کامل _به سمت پایین_ گرد می‌کنید.

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. محاسبه‌ی باقی‌مانده پس از تبدیل به اسکناس

تابع `get_leftover_of_bills()` را بسازید که پارامترهای `amount` و `denomination` را می‌گیرد.

این تابع باید _مبلغ باقی‌مانده_ را برگرداند که با توجه به واحد اسکناس‌ها نمی‌توان آن را از _مبلغ_ اولیه‌ی شما بازگرداند.
خیلی مهم است که بدانید باجه دقیقاً چقدر برای خودش نگه می‌دارد.

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. محاسبه‌ی ارزش پس از تبدیل

تابع `exchangeable_value()` را بسازید که پارامترهای `budget`، `exchange_rate`، `spread` و `denomination` را می‌گیرد.

پارامتر `spread` همان *درصدی* است که به‌عنوان کارمزد تبدیل *گرفته می‌شود* و به‌صورت یک عدد صحیح نوشته می‌شود.
برای تبدیل آن به عدد اعشاری باید آن را بر ۱۰۰ تقسیم کنید.
اگر `1.00 EUR == 1.20 USD` و *spread* برابر `10` باشد، نرخ تبدیل واقعی این می‌شود: `1.00 EUR == 1.32 USD`، چون ۱۰٪ از ۱٫۲۰ برابر ۰٫۱۲ است و این کارمزد اضافی به تبدیل اضافه می‌شود.

این تابع باید بیشترین مقدار ارز جدید را پس از محاسبه‌ی *نرخ تبدیل* به‌علاوه‌ی *spread* برگرداند.
یادتان باشد که *واحد* ارز یک عدد کامل است و نمی‌توان آن را به بخش‌های کوچک‌تر تقسیم کرد.

**نکته:** مقدار برگشتی باید از نوع `int` باشد.

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
