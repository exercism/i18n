# test

برای اجرای مجموعه‌ی test:
```bash
tclsh exercise.test
```

## testهای نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی اینکه همه‌ی testهای آن موفق شوند. به‌طور پیش‌فرض، وقتی testها را اجرا می‌کنید فقط یک test (اولین test) اجرا می‌شود. این کار عمدی است، چون به شما اجازه می‌دهد فقط روی موفق کردن همان یک test تمرکز کنید. وقتی آن test موفق شد، می‌توانید test بعدی را با کامنت کردن یا حذف کردن دستور `skip` که پیش از آن آمده فعال کنید.

از طرف دیگر، برای اجرای همه‌ی testها بدون توجه به وضعیت «نادیده‌گرفته‌شده»ی آن‌ها:
```bash
RUN_ALL=1 tclsh exercise.test
```
