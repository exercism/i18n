# درباره

Chapel یک زبان برنامه‌نویسی است که برای محاسبات موازی پربازده در مقیاس بزرگ طراحی شده است.
این زبان طوری طراحی شده است که به پژوهشگران و متخصصان صنعت امکان دهد به‌راحتی از توان محاسبات با کارایی بالا بهره ببرند، بدون آنکه بهره‌وری و خوانایی را فدا کنند.

### ویژگی‌های اصلی

- **پربازده**: کد معمولاً به همان اندازه‌ی Python خوانا و نوشتنی است
- **مقیاس‌پذیر**: روی لپ‌تاپ‌ها، خوشه‌ها، ابر و سیستم‌های محاسبات با کارایی بالا (HPC) اجرا می‌شود
- **سریع**: کارایی آن با C/C++، MPI و OpenMP رقابت می‌کند یا از آن‌ها بهتر است
- **قابل حمل**: در تقریباً هر محیط \*nix کامپایل و اجرا می‌شود
- **متن‌باز**: روی GitHub میزبانی می‌شود و با مجوزی سهل‌گیرانه ارائه شده است.
