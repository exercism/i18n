# دودویی، هشت‌هشتی و شانزده‌شانزدهی

«دودویی»، «هشت‌هشتی» و «شانزده‌شانزدهی» (_که به آن hex هم گفته می‌شود_) دستگاه‌های عددی مختلفی هستند که مبناهای متفاوتی دارند.
دودویی مبنای ۲، هشت‌هشتی مبنای ۸ و شانزده‌شانزدهی مبنای ۱۶ است.
عددهای صحیح معمولی در Crystal مبنای ۱۰ دارند.
دودویی، هشت‌هشتی و شانزده‌شانزدهی همگی نمایش‌هایی از عددهای صحیح هستند.
یعنی عددهای مثبت و منفی (_از جمله صفر_) را بدون کسر یا اعشار نمایش می‌دهند و همه‌ی عملیات‌هایی را که می‌توان با عددهای صحیح انجام داد پشتیبانی می‌کنند.

## دودویی

[دودویی][binary] یک دستگاه عددی با مبنای ۲ است که فقط از رقم‌های ۰ و ۱ استفاده می‌کند.
این دستگاه معمولاً حالت‌های ۰ («خاموش») و ۱ («روشن») جریان الکتریکی در ترانزیستورها و کلیدها در رایانه‌ها را نشان می‌دهد، و همچنین بارهای مثبت و منفی در رسانه‌های ذخیره‌سازی مغناطیسی را.
دودویی می‌تواند همه‌ی عددهای صحیحی را که در مبنای ۱۰ به کار می‌روند نمایش دهد.

بخشی از دستگاه مبنای ۲ این‌گونه است، هرچند تا بی‌نهایت ادامه دارد و در ۱۲۸ متوقف نمی‌شود:

| ۱۲۸      | ۶۴       | ۳۲       | ۱۶       | ۸        | ۴        | ۲        | ۱        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| ۲ \*\* ۷ | ۲ \*\* ۶ | ۲ \*\* ۵ | ۲ \*\* ۴ | ۲ \*\* ۳ | ۲ \*\* ۲ | ۲ \*\* ۱ | ۲ \*\* ۰ |

پس اگر بخواهیم عدد ۶ را نمایش دهیم، در دودویی چنین می‌شود: ۱۱۰

| ارزش مکانی   | ۴   | ۲   | ۱   |
| ------------- | --- | --- | --- |
| عدد دودویی | ۱   | ۱   | ۰   |

و عملیات چنین می‌شود: `4 + 2 + 0 = 6`

مثال دیگر: ۱۹

| ارزش مکانی   | ۱۶  | ۸   | ۴   | ۲   | ۱   |
| ------------- | --- | --- | --- | --- | --- |
| عدد دودویی | ۱   | ۰   | ۰   | ۱   | ۱   |

عدد دودویی چنین می‌شود: ۱۰۰۱۱
و عملیات چنین می‌شود: `16 + 0 + 0 + 2 + 1 = 19`

## دودویی در Crystal

در Crystal می‌توانیم عددهای دودویی را با پیشوند `0b` بنویسیم.
اگر `0b10011` را بنویسیم، Crystal آن را یک عدد دودویی در نظر می‌گیرد و به مبنای ۱۰ تبدیل می‌کند.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

اگر عددی را با پیشوند `0b` بنویسید که در دستگاه دودویی نیست، خطای کامپایل ایجاد می‌شود.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### عملیات با عددهای دودویی

چون عددهای دودویی عدد صحیح هستند، می‌توان همه‌ی عملیات‌هایی را که با عددهای صحیح انجام می‌دهیم روی آن‌ها هم انجام داد.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### تبدیل به نمایش دودویی و از آن

Crystal به‌طور خودکار یک عدد دودویی را به `Int32` تبدیل می‌کند.
برای تبدیل یک `Int32` به نمایش دودویی، از متد [`<int>.to_s(base)`][to_s] استفاده کنید و آرگومان مبنا را برابر ۲ بگذارید.
این متد نمایش رشته‌ای عدد دودویی را برمی‌گرداند:

```crystal
19.to_s(2)
# => "10011"
```

برای تبدیل نمایش رشته‌ای یک عدد دودویی به عدد صحیح، می‌توانیم از متد [`<int>.to_i(base)`][to_i] استفاده کنیم و مبنا (۲) را به عنوان آرگومان بدهیم:

```crystal
"10011".to_i(2)
# => 19
```

دادن مبنای اشتباه (_یا یک نمایش دودویی نامعتبر_) خطای `ArgumentError` ایجاد می‌کند:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### متدهای دودویی

متدهای خاصی وجود دارند که می‌توان روی عددهای صحیح به کار برد تا اطلاعاتی درباره‌ی نمایش دودویی عدد به دست آورد.

[`<int>.bit_length`][bit_length] تعداد بیت‌های لازم برای نمایش عدد را برمی‌گرداند:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] بیت موجود در اندیس داده‌شده را برمی‌گرداند، با شمردن از سمت راست (_کم‌ارزش‌ترین بیت_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## هشت‌هشتی

[هشت‌هشتی][octal] یک دستگاه عددی با مبنای ۸ است.
از رقم‌های ۰، ۱، ۲، ۳، ۴، ۵، ۶ و ۷ استفاده می‌کند.

در Crystal می‌توانیم عددهای هشت‌هشتی را با پیشوند `0o` بنویسیم.
مانند دودویی، Crystal به‌طور خودکار نمایش هشت‌هشتی را به `Int32` تبدیل می‌کند.

```crystal
0o123
# => 83
```

اگر پیشوند `0o` را به عددی بدهید که در دستگاه هشت‌هشتی نیست، خطای کامپایل ایجاد می‌شود.

### تبدیل به نمایش هشت‌هشتی و از آن 

مانند دودویی، می‌توانیم از متد [`<int>.to_s(base)`][to_s] برای تبدیل یک `Int32` به نمایش هشت‌هشتی استفاده کنیم.
و می‌توانیم از متد [`<int>.to_i(base)`][to_s] برای تبدیل نمایش هشت‌هشتی به `Int32` استفاده کنیم.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

مانند دودویی، دادن مبنای اشتباه خطای `ArgumentError` ایجاد می‌کند.

## شانزده‌شانزدهی

[شانزده‌شانزدهی][hexadecimal] یک دستگاه عددی با مبنای ۱۶ است.
از رقم‌های ۰ تا ۹ و حروف A، B، C، D، E و F استفاده می‌کند.
A یعنی ۱۰، B یعنی ۱۱، C یعنی ۱۲، D یعنی ۱۳، E یعنی ۱۴ و F یعنی ۱۵.

می‌توانیم عددهای شانزده‌شانزدهی را در Crystal با پیشوند `0x` بنویسیم.
مانند دودویی و هشت‌هشتی، Crystal عددهای شانزده‌شانزدهی را به‌طور خودکار به `Int32` تبدیل می‌کند.

```crystal
#=> 0x123
291
```
 
اگر پیشوند `0x` را به عددی بدهید که شانزده‌شانزدهی نیست، خطای کامپایل ایجاد می‌شود.

###  تبدیل به نمایش شانزده‌شانزدهی و از آن

مانند دودویی، می‌توانیم از متد [`<int>.to_s(base)`][to_i] برای تبدیل یک `Int32` به نمایش شانزده‌شانزدهی استفاده کنیم.
و می‌توانیم از متد [`<int>.to_i(base)`][to_s] برای تبدیل نمایش شانزده‌شانزدهی به `Int32` استفاده کنیم.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

مانند دودویی و هشت‌هشتی، دادن مبنای اشتباه خطای `ArgumentError` ایجاد می‌کند.

## دقت

هنگام تبدیل یک عدد به نمایش رشته‌ای، می‌توانیم دقت عدد را مشخص کنیم.
یعنی **کمترین** تعداد رقم‌هایی که برای نمایش عدد به کار می‌رود.
اگر عدد رقم‌های کمتری از دقت داشته باشد، صفرهای ابتدایی به نمایش رشته‌ای اضافه می‌شوند.
این کار با فرستادن آرگومان `precision` به متد [`<int>.to_s(<base>, precision: <value>)`][to_s] انجام می‌شود.

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## حروف بزرگ

هنگام تبدیل یک عدد به نمایش رشته‌ای، می‌توانیم مشخص کنیم که می‌خواهیم حروف رشته با حروف بزرگ نوشته شوند یا نه.
این کار با فرستادن آرگومان `upcase` به متد [`<int>.to_s(<base>, upcase: <value>)`][to_s] انجام می‌شود.

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
