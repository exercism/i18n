# راهنمایی‌ها

## کلی

- اگر لازم است، [مفهوم اشیاء][concept-class-basics] را دوباره ببینید تا مبانی را مرور کنید.
- دستورالعمل‌ها را برای ترتیب قرار گرفتن پارامترهای `x`، `y`، `width` و `height` با دقت بخوانید. این‌ها به‌راحتی با هم اشتباه گرفته می‌شوند.

## 1. تعریف یک کلاس ProgramWindow

- یادتان باشد که برای این تمرین از [نحوه‌ی نگارش کلاس][php-class] استفاده کنید.
- برای تعریف [ویژگی‌ها][php-properties]، آن‌ها را به اعلان کلاس اضافه کنید.

## 2. تعریف تابع سازنده برای کلاس ProgramWindow

- بررسی کنید که تابع سازنده‌ی شما هیچ آرگومانی نمی‌پذیرد.
- بررسی کنید که هر ویژگی روی مقدار صحیح مورد انتظار تنظیم می‌شود.

## 3. افزودن متدی برای تغییر اندازه‌ی پنجره

- یادتان باشد که برای این تمرین از یک [کلاس][php-class] جدید در فایل `Size.php` استفاده کنید.
  - طبق قرارداد، فایل‌ها معمولاً فقط یک کلاس دارند.
- سازنده‌ی `Size` باید آرگومان‌هایی برای مقادیر اولیه‌ی [ویژگی‌های][php-properties] کلاس بپذیرد.
- یک متد `resize` برای شیء `ProgramWindow` بسازید تا تغییر را با استفاده از یک نمونه از `Size` اعمال کنید.

## 4. افزودن متدی برای جابه‌جایی پنجره

- یادتان باشد که برای این تمرین از یک [کلاس][php-class] جدید در فایل `Position.php` استفاده کنید.
  - طبق قرارداد، فایل‌ها معمولاً فقط یک کلاس دارند.
- سازنده‌ی `Position` باید آرگومان‌هایی برای مقادیر اولیه‌ی [ویژگی‌های][php-properties] کلاس بپذیرد.
- یک متد `move` برای شیء `ProgramWindow` بسازید تا تغییر را با استفاده از یک نمونه از `Position` اعمال کنید.
