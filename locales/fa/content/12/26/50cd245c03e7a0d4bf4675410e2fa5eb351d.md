# الحاق رشته

الحاق رشته در Ruby کاملاً بی‌اشکال است، اما روش رایج‌تری برای ساختن یک رشته، استفاده از [درج رشته](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) است. برای نمونه:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
