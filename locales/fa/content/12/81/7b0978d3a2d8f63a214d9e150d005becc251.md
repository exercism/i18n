# به جای `if-else` از `||` استفاده کنید

وقتی می‌خواهید مقدار یک متغیر را در صورتی تغییر دهید که مقدارش `nil` یا هر مقدار نادرست دیگری باشد، به جای دستور `if-else` از عملگر `||` استفاده کنید.
این کار اصطلاحی‌تر و موجزتر است و عملکرد بهتری هم دارد.

عملگر `||` اگر مقداری که در سمت چپ آن قرار دارد «درست» باشد، همان مقدار را برمی‌گرداند؛ در غیر این صورت، مقدار سمت راست عملگر را برمی‌گرداند.

برای مثال:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
