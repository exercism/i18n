# درباره

[concept:csharp/enumerables]() را می‌توان با یک حلقه‌ی [`foreach`][foreach-statement] پیمایش کرد:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

یک حلقه‌ی `foreach` از سه بخش تشکیل شده است:

۱. تعریف: متغیری را تعریف کنید که مقدار پیمایش‌شده را در خود نگه می‌دارد. این متغیر را می‌توان (فقط) درون حلقه استفاده کرد.
۲. شیء قابل پیمایش: شیئی که می‌توان آن را پیمایش کرد.
۳. بدنه‌ی حلقه.

## حلقه‌ی `for` در برابر حلقه‌ی `foreach`

با این حال، به‌طور کلی یک حلقه‌ی `foreach` به دلایل زیر به حلقه‌ی `for` ترجیح داده می‌شود:

- یک حلقه‌ی `foreach` تضمین می‌کند که _همه‌ی_ مقادیر را پیمایش کند. در حلقه‌ی `for` به‌راحتی ممکن است برخی عناصر از قلم بیفتند، برای مثال به دلیل خطای یک واحد.
- یک حلقه‌ی `foreach` _اعلانی‌تر_ است؛ کد شما بیان می‌کند که _چه کاری_ می‌خواهید انجام شود، در حالی که یک حلقه‌ی `for` بیان می‌کند _چگونه_ می‌خواهید آن را انجام دهید.
- یک حلقه‌ی `foreach` خطاناپذیر است، در حالی که در حلقه‌های `for` به‌راحتی خطای یک واحد رخ می‌دهد.
- یک حلقه‌ی `foreach` روی همه‌ی انواع مجموعه کار می‌کند، از جمله مجموعه‌هایی که از اندیس‌گذار برای دسترسی به عناصر پشتیبانی نمی‌کنند.

برای اینکه تضمین شود یک حلقه‌ی `foreach` _همه‌ی_ مقادیر را پیمایش می‌کند، کامپایلر اجازه نمی‌دهد مجموعه‌ای درون حلقه‌ی `foreach` به‌روزرسانی شود:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

یک حلقه‌ی `for` هم چند مزیت نسبت به یک حلقه‌ی `foreach` دارد:

- می‌توانید از اندیسی که می‌خواهید شروع کنید یا در آن متوقف شوید.
- می‌توانید هر شرط پایان «منطقی» را که می‌خواهید به کار ببرید.
- می‌توانید با سفارشی‌سازی افزایش متغیر حلقه، از برخی عناصر صرف‌نظر کنید.
- می‌توانید مجموعه‌ها را با شمارش نزولی از انتها به ابتدا پردازش کنید.
- می‌توانید از حلقه‌های `for` در موقعیت‌هایی که مجموعه‌ای در کار نیست استفاده کنید.

موضوعات مرتبط:

- باید بدانید که C# از [آرایه‌های چندبعدی][multi-dimensional-arrays] مانند `int[,] arr = new int[10, 5]` پشتیبانی می‌کند که می‌تواند بسیار مفید باشد.
- همچنین باید بدانید که می‌توانید اشیائی از نوع [`System.Array`][system-array-object] را با `Array.CreateInstance` نمونه‌سازی کنید. چنین اشیائی کاربرد چندانی ندارند، عمدتاً برای تعامل با کد VB.NET. این اشیاء با آرایه‌های استاندارد (`T[]`) قابل جابه‌جایی نیستند. می‌توانند حد پایین ناصفر داشته باشند.
