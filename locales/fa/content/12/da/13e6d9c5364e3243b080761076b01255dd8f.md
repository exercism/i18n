# نوع تاپل

«تاپل» یک نوع داده‌ی ترکیبی انعطاف‌پذیر و کارآمد در Cairo است که به شما اجازه می‌دهد چندین مقدار از انواع مختلف را در یک موجودیت واحد کنار هم بگذارید.
تاپل طول ثابتی دارد؛ یعنی وقتی آن را تعریف می‌کنید، اندازه‌اش دیگر نمی‌تواند تغییر کند.

## ساختن تاپل

برای ساختن یک تاپل، فهرستی از مقادیر را که با کاما از هم جدا شده‌اند، داخل پرانتز می‌نویسید.
هر جایگاه در تاپل یک نوع مشخص دارد و این نوع‌ها می‌توانند با یکدیگر متفاوت باشند.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

یک تاپل می‌تواند چندین مقدار از انواع داده‌ی مختلف را در خود نگه دارد، از جمله تاپل‌های دیگر.
برای مثال:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

در اینجا متغیر `nested_tup` تاپلی است که دو تاپل را در خود دارد و نشان می‌دهد تاپل‌ها می‌توانند تاپل‌های دیگر را به‌عنوان عنصر نگه دارند.

## تجزیه‌ی تاپل

برای دسترسی به مقادیر تک‌تک داخل یک تاپل، می‌توانید با «تطبیق الگو» آن را تجزیه کنید.
این کار تاپل را به اجزای تشکیل‌دهنده‌اش تجزیه می‌کند.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## تعریف و تجزیه‌ی همزمان

همچنین می‌توانید یک تاپل را به‌طور همزمان تعریف و تجزیه کنید.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## نوع واحد `()`

«نوع واحد» یک نوع ویژه در Cairo است که تنها یک مقدار دارد: `()`.
این نوع با یک تاپل بدون عنصر نمایش داده می‌شود.
اندازه‌ی نوع واحد همیشه صفر است و تضمین شده است که در کد کامپایل‌شده وجود نداشته باشد.

در Cairo هر عبارت یک مقدار برمی‌گرداند و وقتی عبارتی چیزی برنگرداند، به‌طور ضمنی `()` را برمی‌گرداند.
این موضوع می‌تواند برای توابعی مفید باشد که باید مقداری برگردانند اما مقدار معناداری برای برگرداندن ندارند.

## تعریف نوع تاپل نامدار

یک تاپل نامدار به شما اجازه می‌دهد یک نام مستعار نوع توصیفی‌تر برای یک تاپل بسازید و خوانایی کد را بهبود دهید.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

در این مثال، `Point` یک نوع تاپل نامدار است که نماینده‌ی جفتی از اعداد صحیح ۳۲ بیتی بدون علامت است و کد را گویاتر می‌کند.
