# دستورالعمل‌ها

شما یک پرنده‌نگر پرشور هستید که پیگیری می‌کنید در هفت روز گذشته چند پرنده از باغتان بازدید کرده‌اند.

شش وظیفه دارید که همه به تعداد پرندگانی مربوط می‌شوند که از باغ شما بازدید کرده‌اند.

## 1. بررسی کنید شمارش‌های هفته‌ی گذشته چه بوده‌اند

برای مقایسه، همیشه نسخه‌ای از شمارش‌های هفته‌ی گذشته را کنار دستتان نگه می‌دارید: 0، 2، 5، 3، 7، 8 و 4. یک بردار از شمارش‌های هفته‌ی گذشته بسازید:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. بررسی کنید امروز چند پرنده بازدید کرده است

تابع `today` را پیاده‌سازی کنید تا تعداد پرندگانی را برگرداند که امروز از باغ شما بازدید کرده‌اند. شمارش پرنده‌ها بر اساس روز مرتب شده است؛ اولین عنصر شمارش قدیمی‌ترین روز و آخرین عنصر شمارش امروز است.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. شمارش امروز را یک واحد افزایش دهید

تابع `inc-bird` را پیاده‌سازی کنید تا شمارش امروز را یک واحد افزایش دهد:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. بررسی کنید آیا روزی بدون بازدید پرنده وجود داشته است

تابع شرطی `day-without-birds?` را پیاده‌سازی کنید که اگر روزی وجود داشته باشد که صفر پرنده از باغ بازدید کرده باشد، `true` را برمی‌گرداند؛ در غیر این صورت، `false` را برمی‌گرداند:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. محاسبه‌ی تعداد پرندگان بازدیدکننده در چند روز نخست هفته

تابع `n-days-count` را پیاده‌سازی کنید که تعداد پرندگانی را برمی‌گرداند که از ابتدای هفته از باغ شما بازدید کرده‌اند، اما شمارش را به تعداد روزهای مشخص‌شده از ابتدای هفته محدود می‌کند.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. محاسبه‌ی تعداد روزهای شلوغ

بعضی روزها شلوغ‌تر از بقیه هستند. روز شلوغ روزی است که پنج پرنده یا بیشتر از باغ شما بازدید کرده باشند.
تابع `busy-days` را پیاده‌سازی کنید تا تعداد روزهای شلوغ را برگرداند:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. بررسی هفته‌ی فرد

در طول یک سال گذشته متوجه شده‌اید که بعضی هفته‌ها الگوی فرد یکسانی دارند، طوری که شمارش‌ها بین یک و صفر پرنده‌ی بازدیدکننده در نوسان است. تابع `odd-week?` را پیاده‌سازی کنید که اگر الگوی شمارش پرنده‌های این هفته با الگوی فرد مطابقت داشته باشد، `true` را برمی‌گرداند:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
