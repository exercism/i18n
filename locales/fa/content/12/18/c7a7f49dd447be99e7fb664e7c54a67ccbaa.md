# دستور شرطی

یک **«دستور شرطی»** بسته به اینکه چیزی «درست» باشد یا نه، بین دو کار یکی را انتخاب می‌کند.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

این را این‌طور بخوانید: `if`، سپس پرسشی که با `true` یا `false` پاسخ داده می‌شود، سپس `then`. خطوط بعد از `then` وقتی اجرا می‌شوند که پاسخ «درست» باشد، و خطوط بعد از `else` وقتی اجرا می‌شوند که «غلط» باشد. `end;` کل ساختار را می‌بندد.

## بیش از دو راه

`elsif` پرسش دیگری اضافه می‌کند که فقط زمانی پرسیده می‌شود که پرسش‌های بالای آن «غلط» از آب درآمده باشند.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

ترتیب اهمیت دارد. امتیاز `9` توسط پرسش اول گرفته می‌شود و هرگز به پرسش دوم نمی‌رسد، حتی اگر `9 >= 5` نیز «درست» باشد. نوشتن شرط‌ها به ترتیب اشتباه، معمول‌ترین راه برای اشتباه کردن در این مورد است.

املای آن `elsif` است، نه `elseif` و نه `else if`.

## حذف کردن `else`

`else` را می‌توان حذف کرد وقتی در آن حالت کاری برای انجام دادن نیست.

```sather
   if late then
      apologise;
   end;
```

یک روال که باید چیزی برگرداند، باید در هر مسیر چیزی برگرداند. بنابراین در این تمرین هر `if` قسمت `else` خود را نگه می‌دارد.
