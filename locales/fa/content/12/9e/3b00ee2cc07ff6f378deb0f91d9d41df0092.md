# معرفی

`String` در Java یک شیء است که متن تغییرناپذیر را به‌صورت دنباله‌ای از کاراکترهای یونیکد (حروف، ارقام، علائم نگارشی و غیره) نمایش می‌دهد.
برای تعریف یک نمونه از `String` از گیومه‌های دوتایی استفاده می‌شود:

```java
String fruit = "Apple";
```

رشته‌ها با فراخوانی متدهایشان دستکاری می‌شوند.
وقتی رشته‌ای ساخته شد، مقدارش دیگر هرگز تغییر نمی‌کند.
هر متدی که به نظر می‌رسد رشته‌ای را تغییر می‌دهد، در واقع رشته‌ی جدیدی برمی‌گرداند.
کلاس `String` چند متد _static_ برای تبدیل رشته‌ها فراهم می‌کند.
