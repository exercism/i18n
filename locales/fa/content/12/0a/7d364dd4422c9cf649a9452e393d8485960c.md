# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | ورودی        | عدد صحیح | حد |
| `$a1`    | ورودی/خروجی | آدرس | آرایه‌ی مقصد برای اعداد اول |
| `$v0`    | خروجی       | عدد صحیح | تعداد اعداد اول |
| `$t0-9`  | موقت    | هر نوع | برای ذخیره‌سازی موقت استفاده می‌شود |
