# مقدمه

Perl یک زبان برنامه‌نویسی است که لری وال آن را ساخت و نخستین بار در سال ۱۹۸۷ منتشر شد.

## بسته و پیمانه

بسته مجموعه‌ای از کد است که اغلب درون یک فایل پیمانه‌ی هم‌نام با پسوند `.pm` قرار می‌گیرد.
سپس می‌توان پیمانه را، معمولاً با کلیدواژه‌ی `use`، به فایل دیگری وارد کرد.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## متغیر

سه نوع متغیر داریم: اسکالر (`$foo`)، آرایه (`@bar`) و هش (`%baz`).
برای سادگی، در اینجا فقط از متغیرهای اسکالر استفاده می‌شود.
یک مقدار اسکالر می‌تواند یکی از این‌ها باشد: یک رشته، یک عدد، یک مقدار «منطقی»، یا یک [ارجاع][perlreftut] به یک داده‌ی دیگر.
نبودِ مقدار همان `undef` است.


کلیدواژه‌های `my` و `our` متغیری را در حوزه‌ی واژگانی اعلام می‌کنند، مثلاً `my $foo;`.
با `our`، متغیر با یک متغیر بسته‌ای هم‌نام هم یکی می‌شود.
راه‌های دیگری هم برای اعلام متغیر وجود دارد که در اینجا به آن‌ها نمی‌پردازیم.

می‌توانید با عملگر `=` به متغیر مقدار بدهید، مثلاً `$foo = 1;`؛ این کار را می‌توان هم‌زمان با اعلام متغیر انجام داد، مثلاً `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## زیرروال

کلیدواژه‌ی `sub` یک [زیرروال][perlsub] اعلام می‌کند.
کلیدواژه‌ی `return` از زیرروال خارج می‌شود و مقادیر مشخص‌شده را برمی‌گرداند، یا اگر مقداری داده نشده باشد، یک فهرست خالی.
اگر `return` مشخص نشده باشد، مقدار بازگشتی بر اساس بافتی که زیرروال در آن فراخوانی شده (اسکالر، فهرست یا تهی) و آخرین دستور آن تعیین می‌شود.

```perl
sub hello () {
    return 'Hello, World!';
}
```

نسخه‌های تازه‌ی Perl به شما اجازه می‌دهند پارامترهای صوری را در قالب یک [امضا][perlsubsig] مشخص کنید.
فهرست پارامترها می‌تواند شامل متغیرهای اسکالر، آرایه یا هش باشد.
فهرست پارامتر خالی یعنی زیرروال هیچ آرگومانی نمی‌پذیرد.
در نسخه‌های قدیمی‌تر Perl باید آرگومان‌ها را از متغیر ویژه‌ی `@_` بیرون می‌کشیدید، که در اینجا به آن نمی‌پردازیم.
