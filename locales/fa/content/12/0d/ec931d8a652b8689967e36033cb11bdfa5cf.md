# مقدمه

فرض می‌کنیم که با نحوه‌ی نگارش و انواع داده‌ی JSON آشنا هستید.

‏jq با عبور دادن داده‌ی JSON ورودی از یک _عبارت واحد_ (که به‌صورت _خط لوله‌ای از فیلترها_ نوشته می‌شود) کار می‌کند تا به داده‌ی تبدیل‌شده‌ی دلخواه برسد.

<!-- prettier-ignore -->
~~~~exercism/note
زبان `jq` توسط _برنامه‌ی_ `jq` پیاده‌سازی شده است.
این برنامه چندین گزینه‌ی کاربردی خط فرمان ارائه می‌دهد که کنترل می‌کنند ورودی چگونه مصرف شود و خروجی چگونه نمایش داده شود.

در مثال‌های زیر با این‌ها روبه‌رو می‌شوید:

- `-n` یا `--null-input`

    معمولاً به برنامه‌ی `jq` یک فایل برای خواندن داده می‌شود، یا شما داده را به ورودی آن می‌فرستید.
    گزینه‌ی `--null-input` به شما امکان می‌دهد بدون هیچ ورودی‌ای داده‌ی JSON تولید کنید.

- `-c` یا `--compact-output`

    ‏`jq` به‌طور پیش‌فرض خروجی خود را با قالبی زیبا چاپ می‌کند.
    وقتی داده مرتب قالب‌بندی شده باشد، دیدنش برای انسان‌ها بسیار مفید است.
    اما این کار برای ماشین‌ها لازم نیست: گزینه‌ی `--compact-output` فاصله‌های قالب‌بندی را حذف می‌کند تا حجم JSON حاصل کمینه شود.

- `-f filename` یا `--from-file filename`

    برنامه‌ی `jq` را از `filename` بخوانید به‌جای اینکه آن را روی خط فرمان بنویسید.
    هر دو `sed` و `awk` برای همین منظور از گزینه‌ی `-f` استفاده می‌کنند.
    این را در اسکریپت‌های آزمون تمرین‌های عملی خواهید دید.

بقیه‌ی این درس بر _زبان_ `jq` تمرکز خواهد کرد.
~~~~

## فیلتر و لوله

به **فیلترها** **عبارت** هم می‌گویند.

یک _فیلتر_ ورودی می‌گیرد و خروجی تولید می‌کند.
همان‌طور که در پوسته‌ی یونیکس کار می‌کنید، می‌توانید _فیلترها_ را با یک لوله `|` به هم بپیوندید تا خروجی یک _فیلتر_ به ورودی فیلتر دیگر وصل شود.

## فیلتر همانی: `.`

این ساده‌ترین _فیلتر_ است.
فقط ورودی خود را به خروجی‌اش می‌فرستد.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## آرایه

این مقدمه‌ای کوتاه برای کار با **آرایه** است.
این موضوع را بعداً با جزئیات بیشتری بررسی خواهیم کرد.

به عنصرهای _آرایه_ با براکت دسترسی پیدا می‌کنید و شماره‌گذاری آن‌ها از صفر شروع می‌شود.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

یک _فیلتر_ می‌تواند با گذاشتن یک عبارت میان `[` و `]` یک _آرایه_ بسازد

- با فهرستی معلوم از عناصر:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- برای گردآوری جریانی از عناصر: برای مثال،
  `range` تابعی است که جریانی از اعداد خروجی می‌دهد

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  استفاده از `[]` نتیجه‌های عبارت را در یک آرایه گرد می‌آورد

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## ویرگول یک عملگر است

_ویرگول_ فقط یک نشانه‌ی نگارشی برای جدا کردن عنصرهای _آرایه_ نیست.
**ویرگول** یک **عملگر** است که جریان‌ها را به هم می‌پیوندد.

برای مثال `[1, 2, 3]` یک _فیلتر_ است که از سازنده‌ی _آرایه_ یعنی `[]` استفاده می‌کند تا نتیجه‌ی پیوند سه عبارت `1`، `2` و `3` را گرد آورد.

آیا نقطه‌ویرگول‌های `range(10; 70; 15)` را در بالا متوجه شدید؟
چون _ویرگول‌ها_ در زبان `jq` کاربرد مشخصی دارند، توابعی که چند آرگومان می‌گیرند برای جدا کردن آرگومان‌ها از نقطه‌ویرگول استفاده می‌کنند.

## شیء

مقدمه‌ای کوتاه بر **شیءها**.

مانند بسیاری از زبان‌های برنامه‌نویسی، برای دسترسی به ویژگی‌های _شیء_ از نقطه استفاده کنید

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
می‌توان از براکت برای _شیءها_ هم استفاده کرد، اما در آن صورت برای مقدارهای ثابت رشته‌ای به گیومه نیاز دارید.
این یکی از روش‌های کار با کلیدهایی است که فاصله دارند.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

می‌توانید با `{}` و جفت‌های `key: value` یک _شیء_ بسازید.
دور _کلیدهایی_ که رشته‌های «ساده» هستند، گیومه لازم نیست.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

خروجی می‌دهد

```none
{
  "question": 54,
  "answer": 42
}
```

برای اینکه با _کلید_ مانند یک _عبارت_ رفتار شود، باید آن را در پرانتز بگذارید (مورد زیر هم همان خروجی بالا را تولید می‌کند).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## خط لوله

برای مثال، با فرض اینکه `file.json` شامل این باشد

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

بیایید طول _آرایه‌ی_ key2 را حساب کنیم:

```sh
$ jq '.key2 | length' file.json
3
```

ما خروجی عبارت `.key2` را با لوله به‌عنوان ورودی به `length` می‌فرستیم، که طبعاً تعداد عنصرهای _آرایه_ را خروجی می‌دهد.

## فیلتر می‌تواند ورودی خود را نادیده بگیرد

در این مثال، داده‌ی JSON ورودی نادیده گرفته می‌شود و هیچ تأثیری بر خروجی ندارد:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## فیلتر می‌تواند جریان‌هایی از داده تولید کند

یک _فیلتر_ می‌تواند بیش از یک مقدار خروجی بدهد.
برای مثال، _فیلتر_ `.[]` هر عنصر از _آرایه_ را به‌صورت مقداری جداگانه خروجی می‌دهد:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

اگر چنین _فیلتری_ را با لوله به فیلتر دیگری وصل کنید، _فیلتر_ دوم **_برای هر مقدار_** اجرا می‌شود:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

این مانند تکرار ضمنی است.
وقتی این تکنیک را بفهمید، متوجه می‌شوید که _فیلترهای_ بسیار قدرتمند `jq` می‌توانند بسیار فشرده باشند.

## پرانتز

از **پرانتزها** برای گروه‌بندی زیرعبارت‌ها در کنار هم استفاده می‌شود تا ترتیب انجام عملیات تحمیل شود، درست مانند زبان‌های دیگر.
در `jq`، نیاز به آن‌ها ممکن است تا حدی غافلگیرکننده به نظر برسد.

برای مثال، فرض کنید می‌خواهیم _آرایه‌ای_ با ۲ عنصر بسازیم: جذر ۹؛ و _e_ به توان ۱.
دو عبارت تکی `9 | sqrt` و `1 | exp` هستند.
انتظار داریم خروجی _آرایه‌ی_ `[3, 2.7...]` باشد.

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

چرا آنچه انتظار داشتیم را به دست نیاوردیم؟ `jq` آن را این‌گونه تفسیر می‌کند:

```jq
[ ((9|sqrt), 1) | exp ]
```

‏`jq` جریانی از دو عنصر (`3` و `1`) می‌سازد که هر یک به `exp` داده می‌شوند.

باید مطمئن شویم که `exp` فقط یک عدد را به‌عنوان ورودی می‌گیرد.
به عبارت دیگر، باید تحمیل کنیم که لوله پیش از ویرگول ارزیابی شود.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## تابع و عملگر

بدون اینکه زیاد به عمق مطلب برویم (توابع موضوع یک تمرین دیگر خواهند بود)، در اینجا چند تابع توکار مفید آورده شده است:

- `length`

  با گرفتن یک آرایه به‌عنوان ورودی، تعداد عنصرهای آرایه را خروجی می‌دهد.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  این عملگر بسته به نوع عملوندهایش کارهای متفاوتی انجام می‌دهد:
  اعداد را جمع می‌کند،
  رشته‌ها را به هم می‌چسباند،
  آرایه‌ها را به هم می‌افزاید،
  شیءها را ادغام می‌کند.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  ‏`add` تابعی است که یک آرایه می‌گیرد و عنصری برمی‌گرداند که همه‌ی عناصر آن با قواعد `+` با هم جمع شده‌اند.
  ‏`[1, 2, 3] | add` مقدار `6` را خروجی می‌دهد.

- `map`

  با گرفتن یک آرایه به‌عنوان ورودی و یک فیلتر به‌عنوان آرگومان، آرایه‌ای خروجی می‌دهد که فیلتر روی هر عنصر آن اعمال شده است

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  با گرفتن _یک_ ورودی و یک فیلتر به‌عنوان آرگومان:
  - اگر فیلتری که روی آرگومان اعمال می‌شود به مقدار _«درست»_ برسد، ورودی را بدون تغییر خروجی می‌دهد
  - در غیر این صورت، _هیچ_ خروجی نمی‌دهد (یعنی نه مقدار `null`، بلکه واقعاً هیچ خروجی‌ای)

  برای مثال، با گرفتن چند عدد، آن‌هایی را که بر ۳ بخش‌پذیرند انتخاب کنید

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  به یاد داشته باشید که `range` یک _جریان_ از اعداد خروجی می‌دهد.
  ‏`select` یک بار برای هر عدد فراخوانی می‌شود.
  تنها اعدادی خروجی داده می‌شوند که از این عبارت «عبور می‌کنند».

  اغلب لازم است عنصرهای یک آرایه را انتخاب کنید.
  چند راه برای انجام این کار وجود دارد.

  با ورودی `["Anne", "Bob", "Cathy", "Dave"]`، اسم‌هایی را انتخاب کنید که طولشان ۴ است.
  - از `map` و `select` با هم استفاده کنید

    ```jq
    map(select(length == 4))
    ```

  - آرایه را به عنصرها باز کنید، روی آن جریان `select` اعمال کنید و نتیجه‌ها را گرد آورید

    ```jq
    [ .[] | select(length == 4) ]
    ```
