# مقدمه

«عملگر سه‌گانه» به شما اجازه می‌دهد شرط‌های `if` را به‌جای بلوک‌های دستور، درون عبارت‌ها تعریف کنید. این کار با رویکردهای برنامه‌نویسی تابعی هم‌خوانی دارد و اغلب می‌تواند کد را رساتر و کم‌خطاتر کند.

عملگر سه‌گانه سه عبارت را با هم ترکیب می‌کند: یک شرط، سپس عبارتی که اگر شرط «درست» باشد ارزیابی و برگردانده می‌شود (بخش `if` که با `?` معرفی می‌شود) و در پایان عبارتی که اگر شرط «غلط» باشد ارزیابی و برگردانده می‌شود (بخش `else` که با `:` معرفی می‌شود).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
