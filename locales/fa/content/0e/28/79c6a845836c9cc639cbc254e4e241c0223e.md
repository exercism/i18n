# مقدمه

«فضای نام» روشی برای گروه‌بندی کدهای مرتبط و جلوگیری از تداخل اسم‌هاست و معمولاً در همه‌ی پایگاه‌های کد، جز ساده‌ترین‌شان، وجود دارد.

نحوه‌ی نگارش آن به این صورت است:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

نوع‌هایی که درون یک فضای نام قرار می‌گیرند، از بیرون از محدوده‌ی آن، با پیشوند کردن نام نوع همراه با نقطه ارجاع داده می‌شوند. به‌طور جایگزین، و معمولاً رایج‌تر، می‌توانید یک دستور `using` را در بالای فایل (یا درون یک فضای نام) قرار دهید تا بتوانید نوع را بدون پیشوند به کار ببرید. درون یک فضای نام یکسان، نیازی به کامل نوشتن نام نوع‌ها نیست.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

می‌توانید با نحوه‌ی نگارشِ `using MyAlias = MySpace;` برای یک فضای نام یک نام مستعار تعریف کنید و سپس از آن نام مستعار هر جایی که آن فضای نام قابل استفاده باشد، به کار ببرید.
