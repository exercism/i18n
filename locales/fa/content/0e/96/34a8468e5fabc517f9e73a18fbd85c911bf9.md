# درباره

[حلقه‌ی `for`][for-statement] این امکان را فراهم می‌کند که کدی را به‌صورت مکرر در یک حلقه اجرا کنید تا زمانی که یک شرط برقرار شود.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

یک حلقه‌ی `for` از چهار بخش تشکیل شده است:

1. مقداردهی اولیه: یک بار پیش از ورود به حلقه اجرا می‌شود. معمولاً برای تعریف متغیرهایی به کار می‌رود که درون حلقه استفاده می‌شوند.
2. شرط: پیش از هر تکرار حلقه اجرا می‌شود. تا زمانی که این شرط `true` ارزیابی شود، حلقه به اجرا ادامه می‌دهد.
3. گام: پس از هر تکرار حلقه اجرا می‌شود. معمولاً برای تغییر دادن متغیر(های) حلقه به کار می‌رود (اغلب: افزایش یا کاهش).
4. بدنه: کدی که در هر تکرار حلقه اجرا می‌شود.

## مقایسه‌ی حلقه‌های `for` و `foreach`

به‌طور کلی، [concept:csharp/foreach-loops]() به دلایل زیر به حلقه‌های `for` ترجیح داده می‌شوند:

- یک حلقه‌ی `foreach` تضمین می‌کند که روی _همه‌ی_ مقادیر پیمایش شود. با یک حلقه‌ی `for`، نادیده گرفتن عناصر آسان است، مثلاً به دلیل خطای یک واحد.
- یک حلقه‌ی `foreach` _اعلانی‌تر_ است؛ کد شما بیان می‌کند که _چه کاری_ می‌خواهید انجام دهد، در حالی که یک حلقه‌ی `for` بیان می‌کند که _چگونه_ می‌خواهید آن را انجام دهید.
- یک حلقه‌ی `foreach` خطاناپذیر است، در حالی که با حلقه‌های `for` به‌راحتی ممکن است خطای یک واحد رخ دهد.
- یک حلقه‌ی `foreach` روی همه‌ی انواع مجموعه کار می‌کند، از جمله آن‌هایی که از استفاده از ایندکسر برای دسترسی به عناصر پشتیبانی نمی‌کنند.

برای تضمین اینکه یک حلقه‌ی `foreach` روی _همه‌ی_ مقادیر پیمایش کند، کامپایلر اجازه نمی‌دهد که مجموعه‌ای درون یک حلقه‌ی `foreach` به‌روزرسانی شود:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

یک حلقه‌ی `for` مزایایی نسبت به حلقه‌ی `foreach` دارد:

- می‌توانید از اندیس دلخواه شروع کنید یا در آن متوقف شوید.
- می‌توانید از هر شرط پایان «منطقی» که می‌خواهید استفاده کنید.
- می‌توانید با تغییر دادن نحوه‌ی افزایش متغیر حلقه، از برخی عناصر بگذرید.
- می‌توانید با شمارش نزولی، مجموعه‌ها را از آخر به اول پردازش کنید.
- می‌توانید از حلقه‌های `for` در موقعیت‌هایی استفاده کنید که به مجموعه‌ها مربوط نمی‌شوند.
