# بازی با نوع

بازی با نوع را ممکن است با نام تبدیل نوع هم بشناسند.
بازی با نوع زمانی رخ می‌دهد که دو مقدار از نوع‌های متفاوت برای انجام یک عمل، به یک نوع یکسان تبدیل می‌شوند.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

این کار می‌تواند به‌صورت ضمنی انجام شود (به مثال بالا نگاه کنید)، یا به‌صورت صریح با ریخته‌گری نوع به سبک `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

نوع‌های مجاز برای ریخته‌گری نوع دستی عبارت‌اند از: `bool`، `int`، `float`، `string`، `array`، `object`.
در بیشتر موارد، از ریخته‌گری نوع برای تغییر یک عدد صحیح (`int`) به یک عدد اعشاری (`float`) یا برعکس استفاده می‌شود.
