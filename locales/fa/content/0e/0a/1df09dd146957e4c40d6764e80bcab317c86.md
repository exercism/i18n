# مقدمه

یک «تاپل» چندین مقدار نام‌گذاری‌شده را در یک شیء جمع می‌کند، چیزی که زبان‌های دیگر آن را رکورد، ساختار یا کلاس می‌نامند. هر کلاس تاپل مجموعه‌ی ثابتی از جایگاه‌های نام‌گذاری‌شده دارد و Factor به‌طور خودکار گیرنده‌ها و تنظیم‌کننده‌ها را برای آن‌ها تولید می‌کند.

## تعریف یک تاپل

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

هر جایگاه با `{ name initial: default-value }` اعلام می‌شود. بدون عبارت `initial:` مقدار پیش‌فرض `f` است.

## ساختن یک تاپل

ساده‌ترین سازنده `new` است:

```factor
point new .
! => T{ point }
```

`boa` (به معنی «بر اساس ترتیب آرگومان‌ها») جایگاه‌ها را به ترتیب اعلام از پشته‌ی داده پر می‌کند:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

نحوه‌ی نگارش مقدار ثابت `T{ class { slot value } … }` به شما اجازه می‌دهد تاپلی بسازید که زیرمجموعه‌ای از جایگاه‌هایش مقداردهی شده‌اند و به همان شکل چاپ می‌شود:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

وقتی مقدار یک جایگاه با مقدار پیش‌فرضش یکسان باشد، چاپگر آن را حذف می‌کند.

## خواندن یک جایگاه

Factor برای هر جایگاه یک گیرنده‌ی `slot>>` تولید می‌کند. گیرنده‌ها در [`accessors`][accessors] قرار دارند:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## به‌روزرسانی یک جایگاه

تنظیم‌کننده‌ها به شکل `>>slot` نوشته می‌شوند و تاپل را در جای خود *تغییر می‌دهند*:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

برای اینکه اصل دست‌نخورده بماند، اول `clone` کنید:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` یک «نقل‌قول» می‌گیرد که مقدار فعلی را به مقدار جدید نگاشت می‌کند:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` هم تغییردهنده است، پس اگر می‌خواهید اصل حفظ شود، قبل از فراخوانی آن `clone` کنید.
