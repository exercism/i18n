# درباره

عدد اعشاری عددی است که صفر یا چند رقم بعد از ممیز دارد.
مثال‌ها عبارتند از `4.0`، `0.1`، `3.14`، `-6.4` `16.984025` و `1024.0`.
در Ruby، عدد اعشاری از طریق کلاس [Float][Float] پیاده‌سازی می‌شود.

می‌توانید یک معرفی کوتاه از اعداد اعشاری را در [0.30000000000000004.com][0.30000000000000004.com] پیدا کنید.

صفحه‌ی [Float Toy][evanw.github.io-float-toy] توضیح گرافیکی خوبی دارد از اینکه چگونه بیت‌های یک عدد اعشاری به یک مقدار اعشاری واقعی تبدیل می‌شوند.

برای اجرای مکرر منطق، می‌توان از «حلقه» استفاده کرد.
در این مثال، حلقه‌ی `while` مفید است زیرا _تا زمانی که_ یک «شرط» به یک مقدار درست ارزیابی شود (یعنی نه `false` و نه `nil`) به حلقه زدن ادامه می‌دهد.
Ruby حلقه‌ای مشابه حلقه‌ی `while` پیاده‌سازی می‌کند.
به آن حلقه‌ی `until` می‌گویند، و احتمالاً حدس زده‌اید که چه کار می‌کند.
تا زمانی که یک شرط «منطقی» به `true` ارزیابی شود به حلقه زدن ادامه می‌دهد.
در برخی زبان‌ها، برای اینکه یک تکه کد تعداد نامحدودی بار اجرا شود، از ساختارهایی مانند `while true` استفاده می‌شود.
در Ruby، حلقه‌ی `loop` برای این منظور وجود دارد.
حتی اگر حلقه‌ی `loop` به یک شرط واحد وابسته نباشد، می‌توان آن را با استفاده از «کلیدواژه»ی `return` یا `break` لغو کرد.

«متد» `#years_before_desired_balance` از تمرین قبلی می‌توانست با استفاده از هر یک از سه حلقه‌ی ذکر شده نوشته شود:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

همانطور که احتمالاً متوجه شده‌اید، Ruby مانند برخی زبان‌های دیگر عملگر افزایش (`i++`) ندارد.
در عوض، می‌توان از ساختارهایی مانند `i += 1` (که معادل `i = i + 1` است) استفاده کرد.
