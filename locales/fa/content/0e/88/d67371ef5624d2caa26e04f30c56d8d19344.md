# راهنما

استفاده از اعداد مختلط برای دوران‌ها در فضای دوبعدی می‌تواند نتیجه را بسیار تمیزتر و از نظر عددی دقیق‌تر کند.

## 1. ساختن یک عدد مختلط از مختصات دکارتی

- متد توکار [`complex(x, y)`][complex] از مقداردهی `x + im*y` کارآمدتر است.
- برای مرور، به مقدمه مراجعه کنید.

## 2. ساختن یک عدد مختلط از مختصات قطبی

- چند روش معادل برای این کار وجود دارد (مثلاً `exp`، `cis`، `cispi`).
- برای مرور بیشتر، به مقدمه و دستورالعمل‌ها مراجعه کنید.

## 3. انجام دوران یک بردار دوبعدی

- [فرمول اویلر][euler] اینجا به کارتان می‌آید و می‌توانید از تابع `euler` خود استفاده کنید.
- متدهایی برای بازیابی بخش [حقیقی][real] و بخش [مجازی][imaginary] یک عدد مختلط وجود دارد، یا هر دو با هم!

## 4. انجام جابه‌جایی شعاعی

- تابع `euler` شما می‌تواند به کار بیاید، یا نه…
- می‌توان از متد توکار [`angle`][angle] برای یافتن سریع آرگومان یک عدد مختلط استفاده کرد.
- می‌توان از متد [`abs`][abs] برای یافتن اندازه‌ی یک عدد مختلط استفاده کرد.

## 5. یافتن آهنگ موردنظر

- این فرصت خوبی است تا توابع `rotate` و `rdisplace` خود را با هم ترکیب کنید.
