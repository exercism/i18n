# مقدمه

از `Map` برای ذخیره‌ی جفت‌های **کلید** و **مقدار** استفاده می‌شود. `Maps` هم درست مثل آرایه مقداردهی اولیه می‌شوند، اما از عملگر ساخت نگاشت `=>` استفاده می‌کنند. همچنین می‌توان انواع کلید و مقدار آن‌ها را به‌صراحت تعریف کرد، یا نوع آن‌ها را به‌طور خودکار استنتاج کرد. کلیدها باید یکتا باشند، وگرنه خطایی پرتاب می‌شود.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

می‌توان یک `Map` را با یک حلقه‌ی `for` پیمایش کرد. می‌توانید روی مقدارها پیمایش کنید یا روی کلیدها:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
