# مقدمه

ویژگی در C# عضوی از یک کلاس است که دسترسی به داده‌های درون آن کلاس را فراهم می‌کند.
فراخوان‌ها می‌توانند داده را تنظیم کنند یا آن را بازیابی کنند (`get`). ویژگی‌ها می‌توانند
یا خودکار باشند یا فیلد پشتیبان داشته باشند. آن‌ها شامل یک دسترسی‌گیر `set` و/یا یک
دسترسی‌گیر `get` هستند.
در برخی زبان‌های دیگر، یک «mutator» تقریباً معادل یک دسترسی‌گیر `set` است و یک «accessor»
تقریباً معادل یک دسترسی‌گیر `get` است، هرچند ساختار نحوه‌ی نگارش آن‌ها کاملاً متفاوت است.

هنگام تنظیم یک ویژگی، می‌توان مقدار ورودی را اعتبارسنجی، قالب‌بندی یا به شکل دیگری
دستکاری کرد؛ در واقع هر عملیات برنامه‌ای که کد داخل کلاس به آن دسترسی دارد، می‌تواند اجرا
شود.

به‌طور مشابه، هنگام دریافت یک ویژگی، می‌توان داده را محاسبه یا قالب‌بندی کرد و باز هم هر
عملیات برنامه‌ای که برای کلاس در دسترس است، می‌تواند اجرا شود.

ویژگی‌ها اصلاح‌کننده‌های دسترسی (`public`، `private` و غیره) را مانند سایر اعضای
کلاس دارند، اما دسترسی‌گیر `set` می‌تواند سطح دسترسی‌ای مستقل از دسترسی‌گیر `get`
داشته باشد و برعکس. یک ویژگی لازم نیست هر دو دسترسی‌گیر را داشته باشد؛ می‌تواند فقط یکی را
داشته باشد (یا `get` یا `set`).

نحوه‌ی نگارش پایه برای بیان ویژگی‌ها می‌تواند دو شکل داشته باشد:

## ویژگی‌های مبتنی بر فیلد/عبارت:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## ویژگی‌های خودکار

```
public int MyProperty { get; private set; } = 42;
```

مقداردهی اولیه اختیاری است.
