# مقدمه

به کاراکترهای تکی در یک `String` می‌توان با همان روش «اندیس‌گذاری» که برای آرایه‌ها به کار می‌رود، دسترسی پیدا کرد.
اما [اندیس‌ها][string-indices]یی که برای رشته‌ها استفاده می‌شوند _عدد صحیح_ نیستند و نمی‌توان مستقیماً با آن‌ها کار کرد.
در عوض باید آن‌ها را بر پایه‌ی اندیس شناخته‌شده‌ی دیگری محاسبه کنید، مانند `startIndex` که به موقعیت نخستین کاراکتر در یک رشته‌ی ناتهی اشاره می‌کند، با استفاده از متدهای موجود در کتابخانه‌های [`String`][string-docs] و [`NSString`][nsstring-docs] (وقتی ماژول `Foundation` وارد شود، رشته‌ها در Swift به همه‌ی ویژگی‌ها و متدهای NSString دسترسی پیدا می‌کنند).

برای مثال، رشته‌ی زیر را در نظر بگیرید:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

نمی‌توان `csv[21]` را نوشت تا «g» در «orange» را به دست آورد؛ در عوض باید مقداری از نوع `String.Index` محاسبه کنید و همان اندیس را در اختیار بگذارید.
توجه کنید که این اندیس‌ها به‌خودی‌خود برای مصرف انسان در نظر گرفته نشده‌اند.
به آن‌ها _اندیس‌های مات_ می‌گویند، چون انسان‌ها نیازی ندارند بدانند درونشان چیست.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

اما توجه کنید که اگر آفست یک اندیس معتبر نباشد، یعنی اگر اندیسی پیش از `startIndex` یا پس از `endIndex` بازگرداند، عملیات خطا می‌دهد و برنامه کرش می‌کند.
برای جلوگیری از این مشکل، می‌توانید یک اندیس محدودکننده مشخص کنید.
این کار یک اندیس اختیاری بازمی‌گرداند و برای اندیس‌های نامعتبر دیگر، nil برمی‌گرداند.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

علاوه بر این، اندیس‌ها را نمی‌توان بین رشته‌ها به اشتراک گذاشت.
برای مثال، اگر از `index` مربوط به «g» در «orange» که بالا محاسبه شد برای اندیس‌گیری در رشته‌ی `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` استفاده کنید، یعنی `fam[index]`، برنامه‌تان کرش می‌کند.

دلایل زیادی برای همه‌ی این‌ها وجود دارد، اما همه‌شان در نهایت به این خلاصه می‌شوند که «یونیکد پیچیده است».

به‌طور کلی، اگر به دسترسی تصادفی به کاراکترهای تکی نیاز دارید، احتمالاً بهتر است از یک ساختار داده‌ی دیگر مانند `Array<Character>` استفاده کنید.

## چند متد مفید

Swift متدهای `first` و `last` را دارد تا نخستین و آخرین کاراکتر یک رشته را به دست آورید.
این متدها یک کاراکتر اختیاری بازمی‌گردانند، بنابراین اگر رشته خالی باشد، nil برمی‌گردانند.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

همچنین می‌توانید از متدهای `prefix` و `suffix` استفاده کنید تا زیررشته‌ای از یک رشته به دست آورید.
این متدها یک عدد صحیح به عنوان آرگومان می‌گیرند و زیررشته‌ای بازمی‌گردانند که n کاراکتر نخست یا پایانی رشته را در بر دارد.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
