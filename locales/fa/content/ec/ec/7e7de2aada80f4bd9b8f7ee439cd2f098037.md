# عدد ممیز شناور

`INT` فقط اعداد صحیح را نگه می‌دارد و تقسیم دو عدد از آنها باقی‌مانده را دور می‌ریزد:

```sather
7 / 2        -- 3, not 3.5
```

وقتی بخش اعشاری مهم باشد، نوع داده `FLTD` است: یک عدد **ممیز شناور** که می‌تواند مقادیری میان اعداد صحیح را در خود نگه دارد.

## نوشتن یک عدد ممیز شناور

هر مقدار ثابت ممیز شناور یک ممیز اعشاری و یک `d` در انتهای خود دارد.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

`d` اختیاری نیست. `440.0` به‌تنهایی نوع دیگری است با دقت کمتر؛ `d` همان نوعی را می‌خواهد که این مسیر در همه‌جا از آن استفاده می‌کند.

`2.0d` بنویسید، نه `2d`؛ ممیز اعشاری هم باید وجود داشته باشد.

## عملیات حسابی

`+`، `-`، `*` و `/` همه کار می‌کنند و `/` این بار بخش اعشاری را نگه می‌دارد:

```sather
7.0d / 2.0d      -- 3.5
```

هر دو طرف باید `FLTD` باشند. Sather دو نوع را بی‌سروصدا با هم مخلوط نمی‌کند، بنابراین `7 / 2.0d` یک خطا است، نه یک غافلگیری.

## تبدیل از عدد صحیح

`.fltd` یک `INT` را به `FLTD` تبدیل می‌کند:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` برابر `3.5` است. توجه کنید تبدیل کجا انجام می‌شود: `(7 / 2).fltd` برابر `3.0` می‌شد، چون تقسیم تا آن لحظه نیم را دور انداخته بود. **پیش از** تقسیم تبدیل کنید، نه پس از آن.

## چه‌قدر از هم فاصله دارند؟

`.abs` علامت منفی را دور می‌ریزد و همین راهی است برای پرسیدن فاصله‌ی دو مقدار از هم، بی‌آنکه مهم باشد کدام بزرگ‌تر است:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
