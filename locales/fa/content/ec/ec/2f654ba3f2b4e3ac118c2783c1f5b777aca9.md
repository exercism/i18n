# درباره

## انواع `struct`

انواع `struct` را قبلاً دیده‌ایم؛ برای یادآوری، `struct` دنباله‌ای از عناصر نام‌گذاری‌شده است که به آن‌ها _فیلد_ می‌گویند.
هر فیلد یک اسم و یک نوع دارد.
اسم هر فیلد باید درون `struct` یکتا باشد.
`Structs` را می‌توان با _class_ در پارادایم برنامه‌نویسی شیءگرا مقایسه کرد.

شما با استفاده از کلیدواژه‌های `type` و `struct` یک `struct` جدید می‌سازید و سپس اسم و نوع فیلدها را همان‌طور که در مثال زیر نشان داده شده است، به‌صورت صریح تعریف می‌کنید.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## انواع غیر از `struct`

می‌توانید انواعی غیر از `struct` هم تعریف کنید و از آن‌ها به عنوان نامی مستعار برای تعریف نوع‌های درون‌ساخته استفاده کنید.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

همچنین می‌توانید انواعی غیر از `struct` تعریف کنید که از آرایه و `map` تشکیل شده‌اند.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
