# مقدمه

دیکشنری مجموعه‌ای از عنصرها است که هر عنصر آن از یک کلید و یک مقدار تشکیل می‌شود؛ به‌طوری که اگر کلیدی به یکی از متدهای دیکشنری داده شود، مقدار متناظر با آن برگردانده می‌شود. نقش آن همان نقش `map` یا آرایه‌های انجمنی در زبان‌های دیگر است.

می‌توان دیکشنری را به این صورت ساخت:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

یا

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

توجه کنید که نوع کلید و مقدار، بخشی از تعریف دیکشنری است.

پس از ساخته‌شدن دیکشنری، می‌توان با استفاده از متدهای توکار `Add` و `Remove` آن، ورودی‌هایی به دیکشنری افزود یا از آن حذف کرد.

بازیابی یا به‌روزرسانی مقدارها در دیکشنری با ایندکس کردن آن به کمک یک کلید انجام می‌شود:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

می‌توانید وجود یک مقدار در دیکشنری را به این صورت بررسی کنید:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

اگر روی یک دیکشنری پیمایش کنید، در واقع روی جفت‌های کلید/مقدار آن پیمایش می‌کنید. دیکشنری‌ها ویژگی‌هایی هم دارند که با آن‌ها می‌توان کلیدها یا مقدارها را پیمایش کرد.
