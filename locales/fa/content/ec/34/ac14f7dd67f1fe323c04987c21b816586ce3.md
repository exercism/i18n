# درباره

در C++ می‌توانید مقادیر را با استفاده از عملگرهای مقایسه مقایسه کنید.

| مقایسه            | عملگر    |
| ------------------| --------- |
| برابر             | `==`      |
| نابرابر           | `!=`      |
| کوچک‌تر           | `<`       |
| کوچک‌تر یا برابر  | `<=`      |
| بزرگ‌تر           | `>`       |
| بزرگ‌تر یا برابر  | `>=`      |

نتیجه‌ی این مقایسه‌ها همیشه یک «مقدار منطقی» است:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

عملگرهای `==` و `!=` به ترتیب بررسی می‌کنند که یک مقدار با مقدار دیگری برابر است یا نه.
در ادامه چند مثال رایج آورده شده است:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

سایر عملگرها بررسی می‌کنند که یک مقدار از مقدار دیگری بزرگ‌تر است (`>`)، بزرگ‌تر یا برابر آن است (`>=`)، کوچک‌تر است (`<`) یا کوچک‌تر یا برابر آن است (`<=`).
این نوع مقایسه برای اعداد و رشته‌ها در دسترس است.
هنگام مقایسه‌ی رشته‌ها، ترتیب فرهنگ‌نامه‌ای (که با نام ترتیب واژه‌نامه‌ای هم شناخته می‌شود) رعایت می‌شود.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
