# مقدمه

## برابری

Common Lisp «محمول»های برابری گوناگونی دارد.
این با سایر زبان‌های برنامه‌نویسی فرق می‌کند، چون آن‌ها ممکن است فقط یکی یا دو تا داشته باشند (مثلاً `==` و `===`).
بعضی از این محمول‌ها در Common Lisp مخصوص نوع‌های خاص‌اند و بعضی دیگر عمومی.
در اینجا به دسته‌ی دوم می‌پردازیم.

چهار محمول برابری عمومی وجود دارد که در میزان سختگیری نسبت به آنچه «برابر» در نظر می‌گیرند با هم فرق دارند.
این‌ها به ترتیب از سخت‌گیرترین تا کم‌سخت‌گیرترین عبارت‌اند از: `eq`، `eql`، `equal` و `equalp`.

تعریف‌های فشرده‌ی زیر (که چند جزئیات را نادیده می‌گیرد) به این شکل‌اند:

- `eq`: برابری را چنین تعریف می‌کند که دو شیء یکسان باشند.
  _مثلاً_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: برابری را چنین تعریف می‌کند: دو عدد با نوع و مقدار یکسان، یا دو کاراکتری که یکسان‌اند، و برای هر چیز دیگری اگر `eq` باشند.
  _مثلاً_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: برابری را چنین تعریف می‌کند: دو لیست `equal` هستند اگر هر عنصرشان هم `equal` باشد؛ دو رشته `equal` هستند اگر هر عنصرشان `eql` باشد؛ دو آرایه `equal` هستند اگر `eq` باشند؛ هر چیز دیگری `equal` است اگر `eql` باشد.
  _مثلاً_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: برابری را چنین تعریف می‌کند: رشته‌ها و کاراکترها بدون در نظر گرفتن بزرگی و کوچکی حروف مقایسه می‌شوند؛ اعداد با مقداری تبدیل نوع مقایسه می‌شوند؛ لیست‌ها و آرایه‌ها `equalp` هستند اگر هر عنصرشان هم `equalp` باشد، ساختارها اگر از یک نوع باشند و همه‌ی اسلات‌هایشان `equalp` باشد، و جدول‌های هش اگر کلیدها و مقدارهایشان `equalp` باشند.
  _مثلاً_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
