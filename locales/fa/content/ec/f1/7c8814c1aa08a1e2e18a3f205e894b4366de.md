# `break` و `continue`

هنگام استفاده از یک ساختار کنترلی حلقه‌ای یا تکرارشونده، کلیدواژه‌های `break` و `continue` می‌توانند به کنترل جریان برنامه کمک کنند.
کلیدواژه‌ی `break` از بافت حلقه بیرون می‌زند و به حوزه‌ی بیرونی می‌رود و در نتیجه حلقه را پایان می‌دهد.
کلیدواژه‌ی `continue` بقیه‌ی تکرار جاری را نادیده می‌گیرد و بافت حلقه را از ابتدای تکرار بعدی از سر می‌گیرد.
اگرچه چندان رایج نیست، می‌توان همراه این کلیدواژه یک عدد آورد تا مشخص شود که از چند بافت باید بیرون بزند یا به تکرار بعدی بجهد.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

در مثال قبلی، `continue` پنج (۵) بار اجرا می‌شود، اما در تکرار ششم (۶) `break` اجرا می‌شود و باعث می‌شود کد از حلقه خارج شود.
