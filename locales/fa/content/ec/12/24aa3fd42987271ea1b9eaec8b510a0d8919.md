# مقدمه

به یاد بیاورید که `jq` از همان انواع داده‌ی JSON پشتیبانی می‌کند.
JSON **رشته** را این‌گونه توصیف می‌کند:

> رشته دنباله‌ای از صفر یا بیشتر کاراکتر یونیکد است که داخل گیومه‌ی دوتایی قرار می‌گیرد و از دنباله‌های فرار بک‌اسلش استفاده می‌کند.

## دنباله‌های فرار

درون یک رشته، برای جای دادن کاراکترهای «خاص» از کاراکتر بک‌اسلش استفاده کنید:

- `\"` خودِ علامت گیومه،
- `\\` خودِ بک‌اسلش،
- کاراکترهای فضای خالی `\n`، `\t`، `\r`، `\f`، `\b`
- کاراکترهای یونیکد `\uAAAA` که در آن `A` یک رقم هگز است

## طول رشته

برای یافتن تعداد کاراکترها، از تابع `length` استفاده کنید.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## زیررشته

برای استخراج زیررشته‌ها می‌توان از نشانه‌گذاری **«برش»** استفاده کرد.
نحوه‌ی نگارش آن `.[i:j]` است.
زیررشته‌ی برگردانده‌شده طولی برابر `j - i` دارد و کاراکترها را از اندیس `i` (شامل) تا اندیس `j` (غیرشامل) برمی‌گرداند.
هر کدام از اندیس‌ها می‌تواند منفی باشد؛ در این صورت از انتهای رشته به عقب شمرده می‌شود.
هر اندیسی را می‌توان حذف کرد؛ در آن صورت به ابتدا یا انتهای رشته اشاره می‌کند.
اندیس‌ها از صفر شروع می‌شوند.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## الحاق

برای پیوند دادن رشته‌ها از `+` استفاده کنید:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

وقتی آرایه‌ای از رشته‌ها دارید، از `add` استفاده کنید:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## جداسازی و پیوند

برای جداسازی از تابع `split/1` یا عملگر `/` استفاده کنید:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

معکوس `split/1`، `join/1` است.

تبدیل یک رشته به آرایه‌ای از کاراکترها بارها لازم می‌شود.
برای این کار دو روش وجود دارد:

1. جداسازی با یک رشته‌ی خالی

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` برای تبدیل به آرایه‌ای از _کدپوینت‌ها_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` معکوس `explode` است.

## یافتن اندیس یک زیررشته

از تابع `index/1` استفاده کنید؛ اندیس از صفر شروع می‌شود.

```jq
"hello" | index("el")'   # => 1
```

اگر زیررشته در رشته نباشد، نتیجه `null` است

```jq
"hello" | index("elk")   # => null
```

## درج در رشته

درون یک رشته، دنباله‌ی `\(expression)` _نتیجه‌ی_ آن عبارت را [درون رشته][interpolate] جای می‌دهد:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## تبدیل حروف بزرگ و کوچک

از توابع `ascii_downcase` و `ascii_upcase` استفاده کنید.

## عبارت‌های باقاعده

`jq` پشتیبانی گسترده‌ای از «عبارت‌های باقاعده» دارد؛ این موضوع در یک درس بعدی بررسی می‌شود.

[interpolate]: https://jqlang.org/manual/#string-interpolation
