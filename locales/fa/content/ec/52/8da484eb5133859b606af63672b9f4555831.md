# مقدمه

## عملگرهای مقایسه

[عملگرهای مقایسه][comparison-operators] دو مقدار از یک نوع را با هم مقایسه می‌کنند و یک مقدار `Bool` (که `true` یا `false` است) برمی‌گردانند.
اگر بخواهید مقادیری از نوع‌های مختلف را با هم مقایسه کنید، کامپایلر خطا می‌دهد.

عملگرهای مقایسه‌ی استاندارد در Swift عبارت‌اند از:

| عملگر | توضیح | مثال |
| -------- | ------------------------ | --------------- |
| `==`     | برابر با                 | `1 == 1` («درست») |
| `!=`     | برابر نیست با             | `1 != 2` («درست») |
| `<`      | کوچک‌تر از                | `4 < 5`  («درست») |
| `<=`     | کوچک‌تر یا برابر با        | `4 <= 4` («درست») |
| `>`      | بزرگ‌تر از                | `3 > 1`  («درست») |
| `>=`     | بزرگ‌تر یا برابر با        | `2 >= 2` («درست») |

## دستورهای if و else

یک [دستور شرطی][conditional-statement] کدی را بر اساس اینکه یک شرط به `true` یا `false` ارزیابی شود یا نه اجرا می‌کند.
رایج‌ترین شرطی یک [دستور if][if] است که یک «بلوک کد» را فقط زمانی اجرا می‌کند که شرطش `true` باشد.
یک دستور `if` را با کلیدواژه‌ی `if` بنویسید، سپس شرط و بلوک کدی را که داخل آکولاد قرار می‌گیرد بیاورید:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

می‌توانید `if` را با یک بند `else` جفت کنید تا وقتی شرط `false` است، کد جایگزینی اجرا شود:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

برای بررسی چند شرط پشت سر هم، دستورها را با `else if` به هم زنجیر کنید.
یک دستور `if` به شاخه‌ی `else` نیاز ندارد، اما می‌توانید یکی را بگنجانید تا مواردی را پوشش دهید که هیچ‌کدام از شرط‌ها برقرار نیستند:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## عبارت if

در Swift جدید، دستورهای `if` را می‌توان به‌صورت عباراتی هم به کار برد که یک مقدار تولید می‌کنند.
هر شاخه به یک مقدار ارزیابی می‌شود و همین کار را برای مقداردهی شرطی نتیجه‌ها آسان می‌کند:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
