# مقدمه

## «مپ»

مپ‌ها در Elixir ساختار داده‌ای برای ذخیره‌ی اطلاعات در قالب جفت‌های کلید-مقدار هستند. در زبان‌های دیگر، این ساختار ممکن است با نام‌هایی مثل آرایه‌های انجمنی (PHP)، هش‌ها (Perl 5، Raku) یا دیکشنری‌ها (Python) شناخته شود.

کلیدها و مقدارها می‌توانند از هر نوع داده‌ای باشند، اما اگر کلید یک اتم باشد می‌توانیم آن را به شکل کوتاه‌تری بنویسیم. مپ‌ها ترتیب ورودی‌هایشان را هنگام دسترسی یا بازگرداندن تضمین نمی‌کنند.

### شکل‌های لیترال

یک مپ خالی به‌سادگی با `%{}` تعریف می‌شود. اگر بخواهیم عنصری به یک مپ لیترال اضافه کنیم، می‌توانیم از دو شکل استفاده کنیم:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

هرچند قالب استاندارد و یگانه‌ای وجود ندارد، روشی یکدست برای نمایش جفت‌های کلید-مقدار انتخاب کنید.

### توابع ماژول Map

Elixir توابع زیادی برای کار با مپ‌ها در _ماژول Map_ ارائه می‌دهد. بعضی از توابع _ماژول Map_ نیاز دارند یک تابع _بی‌نام_ به آن‌ها داده شود تا به تبدیل مپ کمک کند.

## ویژگی‌های ماژول به‌عنوان ثابت

در Elixir می‌توانیم ویژگی‌های ماژول را تعریف کنیم که می‌توانند به‌عنوان ثابت در توابعمان استفاده شوند.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

وقتی ویژگی‌ها برای تعریف ثابت‌های ماژول به کار می‌روند، می‌توانند هر عبارتی باشند که در زمان کامپایل ارزیابی می‌شود. پس از کامپایل، ویژگی‌های ماژول قابل دسترسی نیستند، چون در هنگام کامپایل بسط داده می‌شوند؛ درست مثل ماکروهای تعریف‌شده در زبان‌هایی مانند C.
