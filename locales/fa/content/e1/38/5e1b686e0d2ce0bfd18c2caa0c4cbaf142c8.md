# درباره

## نحوه‌ی نگارش کلی

«حلقه‌ی for» یکی از پرکاربردترین دستورها برای اجرای مکرر یک منطق است.
در Go، این حلقه از «کلیدواژه»ی `for`، یک «هدر» و یک «بلوک کد» تشکیل شده است که بدنه‌ی حلقه را درون «آکولادها» جای می‌دهد.
این هدر از ۳ جزء تشکیل شده است که با نقطه‌ویرگول `;` از هم جدا می‌شوند: `init`، `condition` و `post`.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- جزء **`init`** کدی است که فقط یک بار، پیش از شروع حلقه، اجرا می‌شود.
- جزء **`condition`** باید عبارتی باشد که به یک «مقدار منطقی» ارزیابی می‌شود و کنترل می‌کند حلقه چه زمانی باید بایستد.
  کد داخل حلقه تا زمانی اجرا می‌شود که این شرط به «درست» ارزیابی شود.
  به محض اینکه این عبارت به «غلط» ارزیابی شود، دیگر تکراری از حلقه اجرا نمی‌شود.
- جزء **`post`** کدی است که در پایان هر تکرار اجرا می‌شود.

**نکته:** برخلاف زبان‌های دیگر، هیچ پرانتزی `()` دور سه جزء هدر وجود ندارد.
در واقع، افزودن چنین پرانتزی خطای کامپایل است.
اما آکولادهای `{ }` که بدنه‌ی حلقه را در بر می‌گیرند همیشه الزامی‌اند.

## حلقه‌ی For: یک مثال

جزء `init` معمولاً یک متغیر شمارنده را آماده می‌کند، جزء `condition` بررسی می‌کند که حلقه باید ادامه یابد یا بایستد و جزء `post` معمولاً شمارنده را در پایان هر تکرار یک واحد افزایش می‌دهد.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

این حلقه اعداد `1` تا `9` را چاپ می‌کند (شامل `9`).
تعریف گام معمولاً با یک دستور افزایش یا کاهش انجام می‌شود، همان‌طور که در مثال بالا نشان داده شده است.

## اجزای اختیاری هدر

اجزای `init` و `post` هدر اختیاری هستند:

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

با حذف اجزای `init` و `post` در یک حلقه‌ی for مانند آنچه در بالا نشان داده شد، یک حلقه‌ی while در Go می‌سازید.
کلیدواژه‌ی `while` وجود ندارد.
این نمونه‌ای از اصل Go است که مفاهیم باید «متعامد» باشند.
از آنجا که پیش‌تر مفهومی برای دستیابی به رفتار یک حلقه‌ی while وجود دارد، یعنی حلقه‌ی for، `while` به‌عنوان یک مفهوم اضافی افزوده نشد.

## `break` و `continue`

درون بدنه‌ی حلقه می‌توانید از کلیدواژه‌ی `break` برای توقف کامل اجرای حلقه استفاده کنید:

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

در مقابل، کلیدواژه‌ی `continue` فقط اجرای تکرار جاری را متوقف می‌کند و با تکرار بعدی ادامه می‌دهد:

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## حلقه‌ی for بی‌نهایت

بخش شرط در هدر حلقه هم اختیاری است.
در واقع، می‌توانید حلقه‌ای بدون هدر بنویسید:

```go
for {
  // Endless loop...
}
```

این حلقه تنها زمانی پایان می‌یابد که برنامه خاتمه یابد یا در بدنه‌اش یک `break` داشته باشد.

## برچسب‌ها و `goto`

وقتی از `break` استفاده می‌کنیم، Go اجرای درونی‌ترین حلقه را متوقف می‌کند.
به همین ترتیب، وقتی از `continue` استفاده می‌کنیم، Go تکرار بعدی درونی‌ترین حلقه را اجرا می‌کند.

با این حال، این همیشه مطلوب نیست.
می‌توانیم از برچسب‌ها همراه با `break` و `continue` استفاده کنیم تا دقیقاً مشخص کنیم می‌خواهیم به‌ترتیب از کدام حلقه خارج شویم یا در کدام حلقه ادامه دهیم.

در این مثال یک برچسب به نام `OuterLoop` می‌سازیم که به بیرونی‌ترین حلقه اشاره خواهد کرد.
در درونی‌ترین حلقه، برای اینکه بگوییم می‌خواهیم از بیرونی‌ترین حلقه خارج شویم، از `break` و به‌دنبال آن نام برچسب بیرونی‌ترین حلقه استفاده می‌کنیم:

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

استفاده از برچسب‌ها همراه با `continue` هم کار می‌کند، که در این صورت Go در تکرار بعدی حلقه‌ای که برچسب به آن اشاره دارد ادامه می‌دهد.

Go همچنین کلیدواژه‌ی `goto` را دارد که به روشی مشابه کار می‌کند و به ما امکان می‌دهد از یک قطعه کد به قطعه کد دیگری که برچسب دارد بپریم.

**هشدار:** با اینکه Go اجازه می‌دهد به یک قطعه کد که با برچسب مشخص شده بپریم، استفاده از این ویژگی زبان می‌تواند به‌راحتی خواندن کد را بسیار دشوار کند.
به همین دلیل، استفاده از برچسب‌ها اغلب توصیه نمی‌شود.
