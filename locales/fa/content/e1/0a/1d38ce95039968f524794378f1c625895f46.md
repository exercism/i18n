# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که به یک شرکت تابلو‌سازی کمک می‌کند پیام‌های سفارشی برای تابلوهایش بسازد.

## 1. ساخت یک تابلوی مناسبت

متد `build_sign( )` را پیاده‌سازی کنید که یک رشته را به‌عنوان پارامتر `occasion` و رشته‌ای که اسم یک نفر را نگه می‌دارد به‌عنوان پارامتر `name` می‌پذیرد. این دو پارامتر در یک قالب رشته قرار می‌گیرند تا پیام روی تابلو تولید شود.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. ساخت یک تابلوی تولد

متد `build_birthday_sign( )` را پیاده‌سازی کنید که یک سن می‌پذیرد و بر اساس آن بخشی از پیام روی تابلو را تعیین می‌کند. اگر سن ۵۰ یا بیشتر باشد، تابلو کلمه‌ی _mature_ را شامل می‌شود، در غیر این صورت تابلو کلمه‌ی _young_ را در بر می‌گیرد.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. ساخت یک تابلوی فارغ‌التحصیلی

متد `graduation_for( )` را پیاده‌سازی کنید که یک اسم را به‌عنوان پارامتر رشته‌ای و یک سال را به‌عنوان پارامتر عددی می‌گیرد و با استفاده از قالب‌های رشته، عبارتی برای تابلو می‌سازد که با یک خط جدید دو خط پیام را از هم جدا می‌کند.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. محاسبه‌ی هزینه‌ی یک تابلو

تابع `cost_of( sign currency )` را پیاده‌سازی کنید که یک رشته که محتوای تابلو را نگه می‌دارد و رشته‌ای که واحد پول را نشان می‌دهد می‌گیرد.
قیمت پایه‌ی تابلو ۲۰ واحد از آن پول است. علاوه بر این، هر حرف ۲ هزینه دارد. (فاصله‌ها هم در محاسبه لحاظ می‌شوند.)
عبارت برگشتی شامل هزینه‌ی ساخت تابلو است که با دو رقم بعد از نقطه‌ی اعشار نوشته می‌شود و پس از آن رشته‌ی واحد پول می‌آید.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
