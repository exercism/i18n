# مقدمه

«فضای نام» یکی از روش‌های مهم برای سازمان‌دهی کد است.
ممکن است نام دو تابع با هم تداخل داشته باشد که می‌توان این تداخل را با قرار دادن آن‌ها در فضاهای نام متفاوت برطرف کرد.
فضاهای نام می‌توانند تودرتو باشند که ممکن است به ساختاردهی به پایگاه‌های کد بزرگ کمک کند.
دسترسی به فضاهای نام از طریق عملگر تفکیک دامنه‌ی `::` انجام می‌شود.

مثال زیر استفاده از دو تابع متفاوت `foo` را نشان می‌دهد.
این دو تابع با پیشوند کردن فضای نام هرکدام، در کنار هم به کار می‌روند.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
