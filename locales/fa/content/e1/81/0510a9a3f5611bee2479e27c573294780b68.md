# درباره

یک [حلقه‌ی While][while-loops] یک دستور کنترل جریان است که اجازه می‌دهد کد تا زمانی که شرط خاصی «درست» باشد اجرا شود.
Swift دو نوع حلقه ارائه می‌دهد: حلقه‌ی While و حلقه‌ی Repeat-While.
شرط حلقه‌ی While پیش از اجرای بدنه‌ی حلقه ارزیابی می‌شود؛ اگر شرط «غلط» باشد، بدنه‌ی حلقه اصلاً اجرا نمی‌شود.
حلقه‌ی While در Swift ساختار زیر را دارد:

```swift
while <#condition#> {
  <#code#>
}
```

در اینجا حلقه تا زمانی که `count` بزرگ‌تر از ۰ باشد اجرا می‌شود و در نتیجه اعداد ۲، ۱ و `Liftoff!` را چاپ می‌کند.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

یک [حلقه‌ی Repeat-While][while-loops] شبیه حلقه‌ی While است، اما شرط پس از اجرای بدنه‌ی حلقه ارزیابی می‌شود.
این یعنی بدنه‌ی حلقه همیشه حداقل یک بار اجرا می‌شود، حتی اگر شرط «غلط» باشد.
حلقه‌ی Repeat-While در Swift ساختار زیر را دارد:

```swift
repeat {
  <#code#>
} while <#condition#>
```

در اینجا حلقه فقط یک بار اجرا می‌شود، چون شرط «غلط» است.
چون یک حلقه‌ی Repeat-While است، بدنه‌ی حلقه یک بار پیش از ارزیابی شرط اجرا می‌شود.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
