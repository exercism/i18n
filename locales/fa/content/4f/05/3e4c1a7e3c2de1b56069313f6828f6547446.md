هرچند به‌هم‌چسباندن دستی رشته‌ها در Haxe امکان‌پذیر است، Haxe از [درج مقدار در رشته][string-interpolation] پشتیبانی می‌کند که نحوه‌ی نگارشی کوتاه‌تر و راحت‌تر فراهم می‌کند:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

همان‌طور که در بالا می‌بینید، رشته‌های درج‌شده میان نویسه‌های تک‌کوتیشن (`'`) قرار می‌گیرند، برخلاف [رشته‌های][strings] معمولی، و می‌توانند شناسه‌های ویژه‌ای داشته باشند که با علامت دلار (`$`) مشخص می‌شوند و درج مقدار را فعال می‌کنند.

می‌توان کل عبارت را هم با `${expr}` گنجاند، که در آن `expr` هر عبارت معتبر Haxe است:

```haxe
trace('the next number is ${x + 1}');
```

برای جلوگیری از درج مقدار در جایی که یک علامت دلار واقعی لازم دارید، می‌توانید از `$$` استفاده کنید:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

در پایان توجه داشته باشید که درج مقدار در رشته ویژگی‌ای مربوط به زمان کامپایل است و هیچ تأثیری بر کارایی زمان اجرا ندارد. در درون خود، کامپایلر Haxe کدی معادل با به‌هم‌چسباندن دستی تولید می‌کند.
