# مقدمه

Python دو ساختار حلقه دارد.
حلقه‌های `while` برای تکرار _نامعین_ (بدون شمارش) و حلقه‌های `for` برای تکرار _معین_ (با شمارش).
کلیدواژه‌های `break`، `continue` و `else` به سفارشی‌سازی رفتار حلقه کمک می‌کنند.
توابع `range(<length of sequence>)` و `enumerate(<iterable>)` در شمارش حلقه و ایندکس‌گذاری کمک می‌کنند.


حلقه‌های `while` تعداد مشخصی از تکرار برای اجرا ندارند و تا زمانی ادامه می‌یابند که عبارت `loop` یا «آزمون» مقدارش `True` شود.
حلقه زمانی خاتمه می‌یابد که عبارت حلقه مقدارش `False` شود.

```python
while expression:
    set_of_statements
```

حلقه‌های `for` روی مقادیر هر دنباله‌ای می‌چرخند و زمانی پایان می‌یابند که دیگر مقداری برای بازگرداندن نمانده باشد.
تابع `range(<length of sequence>)` وقتی ساختار داده یا مورد قابل‌پیمایش دیگری برای حلقه‌زدن وجود ندارد، یک شمارنده یا دنباله‌ی `loop` فراهم می‌کند.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
