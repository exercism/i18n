# اجرای Tests

از ترمینال، به دایرکتوری پایهی تمرین بروید و سپس tests را با این دستور اجرا کنید:

```bash
$ gleam test
```

این دستور فایل test موجود در زیرپوشهی `test` را اجرا می‌کند؛ فایلی که به `_test.gleam` ختم می‌شود.

## توابع Test

این tests از یک [چارچوب test سفارشی](https://github.com/exercism/gleam-test-runner/tree/main/runner) استفاده می‌کنند.
هر تابع عمومی در دایرکتوری `test` که اسمش به `_test` ختم می‌شود، توسط چارچوب test به عنوان یک test در نظر گرفته می‌شود.

برای مثال:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
