# دستورالعمل‌ها

شما یک بوتیک مد آنلاین را اداره می‌کنید. فروش بزرگ سالانه‌تان نزدیک است، بنابراین می‌خواهید قابلیت‌هایی بسازید تا به شما کمک کند موجودی انبارتان را بررسی کنید و مطمئن شوید که آماده‌اید.

هر عنصر از موجودی با یک هش نمایش داده می‌شود و کل موجودی آرایه‌ای از این هش‌ها است.

```ruby
[
  {
    name: "White Shirt",
    price: 40,
    quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}
  },
  { ... }
]
```

## 1. فهرستی از اسم عنصرها را برگردانید

`BoutiqueInventory.item_names` را پیاده‌سازی کنید؛ این متد باید فهرستی از اسم عنصرها را به ترتیب الفبایی برگرداند.

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

#=> ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 2. عنصرهایی را که ارزان هستند برگردانید

`BoutiqueInventory.cheap` را پیاده‌سازی کنید؛ این متد باید هر عنصری را که کمتر از ۳۰ دلار قیمت دارد برگرداند.

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).cheap

# => [
#      {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
#      {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
#    ]
```

## 3. عنصرهایی را که ناموجود هستند برگردانید

`BoutiqueInventory.out_of_stock` را پیاده‌سازی کنید؛ این متد باید هر عنصری را که موجودی ندارد برگرداند (یعنی `quantity_by_size` آن خالی است).

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).out_of_stock

#=> [{price: 50.00, name: "Red Short Skirt", quantity_by_size: {}}]
```

## 4. موجودی یک عنصر را برگردانید

`BoutiqueInventory.stock_for_item(name)` را پیاده‌سازی کنید تا موجودی یک عنصر را با اسمش برگردانید:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).stock_for_item("Black Short Skirt")

#=> {s: 1, xl: 4}
```

## 5. موجودی کل را برگردانید

`BoutiqueInventory.total_stock` را پیاده‌سازی کنید تا مقدار کل عنصرهای انبارتان را محاسبه کنید:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

#=> 36
```
