# درباره

با [ReScript][rescript-lang] بنویسید و JavaScript را عرضه کنید.
[ReScript][rescript-lang] بر پایه‌ی سیستم نوع قدرتمند OCaml ساخته شده و جانشین مدرن BuckleScript و ReasonML است. این زبان تطبیق الگوی جامع و تضمین‌های زمان کامپایل را در اکوسیستم JavaScript ارائه می‌دهد.
یکپارچگی درجه‌یک آن با React، این زبان را به گزینه‌ای جذاب در برابر TypeScript برای توسعه‌دهندگانی تبدیل می‌کند که به‌جای JavaScript حاشیه‌نویسی‌شده، ایمنی نوع واقعی می‌خواهند.
بدون `any`، بدون `undefined` غافلگیرکننده.

[rescript-lang]: https://rescript-lang.org
