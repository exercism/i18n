# مقدمه

## تابع

تابع‌ها در Gleam با نحوه‌ی نگارش `pub fn` تعریف می‌شوند.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

این تابع دو آرگومان می‌گیرد که هر دو از نوع `Int` هستند و مقداری از نوع `Int` برمی‌گرداند. در Gleam کلیدواژه‌ی `return` وجود ندارد؛ مقدار آخرین عبارت در یک تابع همیشه _به‌صورت ضمنی برگردانده می‌شود_.

«حاشیه‌نویسی نوع» برای آرگومان‌ها و نوع بازگشتی اختیاری است و Gleam همیشه کد شما را به‌طور کامل از نظر نوع بررسی می‌کند. معمولاً برنامه‌نویسان Gleam برای شفافیت به توابع خود حاشیه‌نویسی نوع می‌دهند، اما اگر بخواهید می‌توانید آن‌ها را نادیده بگیرید.

```gleam
pub fn add(x, y) {
  x + y
}
```

می‌توان تابع را با نحوه‌ی نگارش `function_name(argument1, argument2)` فراخوانی کرد.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## متغیر

متغیرها در Gleam با نحوه‌ی نگارش `let name = expression` تعریف می‌شوند.

```gleam
pub fn main() {
  let count = 1
}
```

متغیرها را می‌توان همراه با حاشیه‌نویسی نوع اعلان کرد. این‌ها مانند آرگومان‌های تابع اختیاری‌اند، هرچند بیشتر برنامه‌نویسان Gleam برای اختصار حاشیه‌نویسی نوع متغیرها را نادیده می‌گیرند.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## مقدار ثابت رشته‌ای

در Gleam رشته‌ها با علامت نقل‌قول دوتایی نوشته می‌شوند.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## توضیحات کد

می‌توان از توضیحات برای گذاشتن یادداشت برای سایر توسعه‌دهندگانی که کد مبدأ را می‌خوانند استفاده کرد. توضیحات در Gleam تک‌خطی هستند و با `//` شروع می‌شوند.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
