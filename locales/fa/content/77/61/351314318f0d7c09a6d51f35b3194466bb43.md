# دستورالعمل‌ها

در این تمرین به خواهر کوچک‌ترتان کمک می‌کنید تا مقاله‌اش را برای مدرسه ویرایش کند. معلم دنبال نقطه‌گذاری درست، دستور زبان صحیح و انتخاب واژه‌های عالی است.

چهار کار برای پاک‌سازی و تغییر رشته‌ها پیش رو دارید.

## 1. بزرگ کردن حروف عنوان مقاله

هر مقاله‌ی خوب به عنوانی با قالب‌بندی درست نیاز دارد.
تابع `capitalize_title(<title>)` را پیاده‌سازی کنید که یک عنوان `str` را به عنوان پارامتر می‌گیرد و حرف اول هر واژه را بزرگ می‌کند.
این تابع باید یک `str` در حالت عنوان برگرداند.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. بررسی پایان یافتن هر جمله با نقطه

می‌خواهید مطمئن شوید که نقطه‌گذاری مقاله بی‌عیب و نقص است.
تابع `check_sentence_ending()` را پیاده‌سازی کنید که `sentence` را به عنوان پارامتر می‌گیرد. این تابع باید یک `bool` برگرداند.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. مرتب کردن فاصله‌ها

برای اینکه مقاله حرفه‌ای به نظر برسد، باید فاصله‌های اضافی حذف شوند.
تابع `clean_up_spacing()` را پیاده‌سازی کنید که `sentence` را به عنوان پارامتر می‌گیرد.
این تابع باید فاصله‌های سفید اضافی را از ابتدا و انتهای جمله حذف کند و یک `str` جدید و به‌روز شده از جمله برگرداند.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. جایگزین کردن واژه‌ها با مترادف

برای اینکه مقاله را _حتی بهتر_ کنید، می‌توانید برخی از صفت‌ها را با مترادف‌هایشان جایگزین کنید.
تابع `replace_word_choice()` را بنویسید که `sentence`، `old_word` و `new_word` را به عنوان پارامتر می‌گیرد.
این تابع باید همه‌ی نمونه‌های `old_word` را با `new_word` جایگزین کند و یک `str` جدید با جمله‌ی به‌روز شده برگرداند.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
