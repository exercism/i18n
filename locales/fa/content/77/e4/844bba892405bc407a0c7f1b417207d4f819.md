# مقدمه

ثابت‌ها در Gleam راهی هستند برای اینکه به مقدارها اسم بدهیم. آن‌ها با کلیدواژه‌ی `const` تعریف می‌شوند.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

وقتی ثابت‌های ماژول با کلیدواژه‌ی `pub` تعریف شوند، از ماژول‌های دیگر هم می‌توان به آن‌ها دسترسی داشت؛ در غیر این صورت، فقط از داخل ماژولی که در آن تعریف شده‌اند می‌توان به آن‌ها دسترسی داشت.
