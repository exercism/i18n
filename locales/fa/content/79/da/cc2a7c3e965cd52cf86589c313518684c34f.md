# مقدمه

در C#، عبارت `null` برای نشان دادن نبود مقدار به کار می‌رود. نوع _nullable_ نوعی است که مقادیر `null` را می‌پذیرد.

پیش از C# 8.0، انواع ارجاعی همیشه nullable بودند و انواع مقداری نه. با این حال می‌توان با افزودن یک علامت سؤال (`?`) به یک نوع مقداری، آن را nullable کرد.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

دسترسی به عضوی از یک متغیر که مقدارش `null` است، بدون مشکل کامپایل می‌شود، اما در زمان اجرا باعث پرتاب استثنای `NullReferenceException` می‌شود:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

برای مقابله با این نوع اشتباه رایج، در C# 8 می‌توانید قابلیتی را فعال کنید که به‌طور پیش‌فرض اجازه نمی‌دهد انواع ارجاعی مقدار `null` بگیرند:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

برای کار ایمن با مقادیر nullable، پیش از کار کردن با آن‌ها باید بررسی کنید که `null` هستند یا نه:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

عملگر `??` به شما امکان می‌دهد وقتی مقدار `null` است، یک مقدار پیش‌فرض برگردانید:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

عملگر `?.` به شما امکان می‌دهد اعضای یک مقدار را که ممکن است `null` باشد، به‌طور ایمن فراخوانی کنید:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
