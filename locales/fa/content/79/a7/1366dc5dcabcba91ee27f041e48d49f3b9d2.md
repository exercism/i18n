# دستورالعمل‌ها

در این تمرین، مسابقه‌هایی بین انواع مختلف ماشین‌های کنترلی برگزار می‌کنید. هر ماشین ویژگی‌های خودش را دارد و در طول فصل مسابقات، در پیست‌های مختلف مسابقه می‌دهد.

~~~~exercism/note
توابع این تمرین در یک فایل منبع C با امضاهای ارائه‌شده اعلام شده‌اند.
کد اسمبلی x86-64 شما باید این مشخصات را رعایت کند.
~~~~

## 1. ساخت یک ماشین کنترلی

یک struct به اسم `car_t` تعریف کرده‌اید تا یک ماشین کنترلی را نمایش دهد:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

با تعریف یک تابع به اسم `new_car` در اسمبلی x86-64، امکان ساخت یک ماشین کنترلی را فراهم کنید.
فیلد `battery` همیشه با مقدار `100.0` شروع می‌شود.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. ساخت پیست جدید

پیست‌ها با یک struct به اسم `track_t` نمایش داده می‌شوند:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t` انواع سطح‌های مختلف یک پیست را مشخص می‌کند:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

با تعریف یک تابع به اسم `new_track` در اسمبلی x86-64، امکان ساخت یک پیست جدید را فراهم کنید.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. ساخت یک رویداد مسابقه

در هر مسابقه حداکثر ۶ ماشین شرکت می‌کنند و تعداد مشخصی دور را در یک پیست می‌رانند.
مسابقه‌ها با یک struct به اسم `race_t` نمایش داده می‌شوند:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

یک تابع به اسم `new_race` در اسمبلی x86-64 تعریف کنید.
در ابتدا، هیچ ماشین شرکت‌کننده‌ای برای مسابقه تأیید نشده است:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. تأیید یک ماشین برای مسابقه

وقتی صاحب یک ماشین درخواست می‌کند که آن ماشین در مسابقه‌ای شرکت کند، شرکتش فقط در صورتی تأیید می‌شود که فهرست از قبل پر نباشد.

یک تابع به اسم `add_participant` در اسمبلی x86-64 تعریف کنید.
اگر جای یک شرکت‌کننده‌ی دیگر در مسابقه وجود داشته باشد، ماشین به فهرست اضافه می‌شود، شمارنده به‌روزرسانی می‌شود و شرکت آن تأیید می‌گردد.
در غیر این صورت، برگزارکنندگان مسابقه باید به صاحب ماشین اطلاع دهند که این بار نمی‌تواند شرکت کند.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. ساخت یک تورنمنت

مسابقه‌های برنامه‌ریزی‌شده برای فصل را در یک struct به اسم `tournament_t` نگه می‌دارید:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

یک تابع به اسم `add_race` در اسمبلی x86 تعریف کنید تا یک مسابقه را به آرایه‌ی تورنمنت اضافه کند و شمارنده‌ی آن را هم به‌روزرسانی کند.
می‌توانید فرض کنید که همیشه فضای کافی در آرایه‌ی `races` برای مسابقه‌ی جدید وجود دارد.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
