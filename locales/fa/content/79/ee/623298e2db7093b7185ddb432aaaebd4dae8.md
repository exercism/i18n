# افزودنی دستورالعمل‌ها

## قالب‌های خروجی

انتظار می‌رود تابع `treeFromTraversals` شیئی را برگرداند که ۳ ویژگی دارد:

- `value` مقدار گره‌ی فعلی
- `left` شیئی که فرزند چپ گره را در خود دارد
- `right` شیئی که فرزند راست گره را در خود دارد

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

اگر درخت خالی باشد، باید یک شیء خالی برگردانده شود.
