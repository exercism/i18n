# درباره

در Common Lisp، مقدارهای «غلط» با لیست خالی (`()`) یا نماد `nil` نشان داده می‌شوند.
این مقدارها را می‌توان به‌صورت نقل‌قول‌شده یا نقل‌قول‌نشده نوشت.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

همه‌ی مقادیر دیگر در Lisp، «درست» به شمار می‌آیند.
همچنین نماد ثابت ویژه‌ای به نام `t` وجود دارد که همیشه با `t` برابر است (و بنابراین همیشه «درست» است).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
