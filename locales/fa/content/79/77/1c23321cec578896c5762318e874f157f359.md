# مقدمه

## مقایسه‌ی اعداد

در JavaScript می‌توان اعداد را با استفاده از عملگرهای رابطه‌ای و برابری زیر مقایسه کرد.

| مقایسه                 | عملگر     |
| ---------------------- | --------- |
| بزرگ‌تر از             | `a > b`   |
| بزرگ‌تر یا مساوی       | `a >= b`  |
| کوچک‌تر از             | `a < b`   |
| کوچک‌تر یا مساوی       | `a <= b`  |
| برابر (دقیق)           | `a === b` |
| نابرابر (دقیق)         | `a !== b` |

نتیجه‌ی مقایسه همیشه یک «مقدار منطقی» است، یعنی یا `true` یا `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## مقایسه‌ی رشته‌ها

در JavaScript، از عملگرهای مقایسه‌ی بالا هم می‌توان برای مقایسه‌ی رشته‌ها استفاده کرد. در این حالت، ترتیب فرهنگ‌نامه‌ای (واژه‌نگاری) اعمال می‌شود. فهرستی از ترتیب دقیق همه‌ی کاراکترها را می‌توانید [اینجا][utf-16-list] پیدا کنید.

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## برابری دقیق

شاید برایتان جالب باشد که سه علامت مساوی برای بررسی برابری در JavaScript چه معنایی دارد. `===` بررسی «برابری دقیق» را نشان می‌دهد، یعنی هیچ تبدیل نوعی انجام نمی‌شود و مقادیری که نوعشان متفاوت است همیشه نابرابرند.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

استفاده از `===` و `!==` روش توصیه‌شده برای بررسی برابری در JavaScript است.

همچنین `==` و `!=` هم وجود دارند که بررسی «برابری غیردقیق» را نشان می‌دهند. باید از آن پرهیز کنید، چون پیش از انجام مقایسه تبدیل نوع ضمنی را اعمال می‌کند. نتیجه در این حالت‌ها به‌سختی قابل پیش‌بینی است و گاهی آن چیزی نیست که انتظار دارید.

```javascript
0 == false;
// => true
```
