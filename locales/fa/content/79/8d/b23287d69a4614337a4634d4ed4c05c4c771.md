# راهنما

## کلی

- شاید بخواهید یک DSL بر پایه‌ی فهرست‌هایی از برچسب‌ها و رکوردها بسازید، مثل این:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- یا شاید DSL‌ای بر پایه‌ی زنجیره‌ای از فراخوانی‌های تابع را ترجیح دهید، مثل این:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  یا شاید برنامه‌ی کاملاً متفاوتی در سر دارید؟
  پس بروید دنبالش!

- با این حال، DSL معمولاً وقتی بهتر است که روشن، موجز و چندان غافلگیرکننده نباشد (مثلاً تابع `minus` برای تفریق است، نه برای ساختن یال بین دو گره، مانند `node("a") - node("b")`).
