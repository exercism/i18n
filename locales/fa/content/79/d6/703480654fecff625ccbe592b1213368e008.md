# دستورالعمل‌ها

سلام دوباره، مأمور Double-Null0111.

نیروهای UMBRA دوباره دست به کار شده‌اند و خنثی‌کردن نقشه‌ی جدیدشان به عهده‌ی شماست.
واحد اطلاعات ما خبر داده است که آن مینیون‌ها قصد دارند در مهمانی فرماندار یک بمب بدبو منفجر کنند.

چون مینیون‌ها بسیار دست‌وپاچلفتی‌اند، اغلب به‌طور تصادفی بمب‌های بدبو را در آزمایشگاه‌ها و دفترهایشان مسلح می‌کنند.
و چون مدام فراموش می‌کنند چطور بمب‌های بدبو را خنثی کنند، سامانه‌ای راه انداخته‌اند که دستورالعمل‌های خنثی‌سازی را تولید می‌کند؛ دستورالعمل‌هایی که ترتیب بریدن سیم‌ها را بر پایه‌ی شماره‌ی شناسایی بمب فهرست می‌کنند.

کار شما این است که کدی بنویسید تا بتوانید بمب بدبو را در مهمانی، پیش از آنکه منفجر شود، خنثی کنید.

## 1. یک closure بنویسید که دو سیم را جابه‌جا کند

روی هر بمب بدبو سه سیم با رنگ‌های متفاوت وجود دارد.
یک closure بنویسید که یک «تاپل» `(String, String, String)` می‌گیرد و همان تاپل را با جابه‌جاشدن ترتیب دو عنصر اولش برمی‌گرداند.
این closure را به اسم `flip` تخصیص دهید.

نکته‌ی مهم این است که نوع آن باید `ChangeClosure` باشد (یا یک نوع Sendable)؛ تعریف این نوع در فایل اولیه آمده است.
در غیر این صورت کد کامپایل نمی‌شود.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. یک closure بنویسید که سیم‌ها را بچرخاند

یک closure بنویسید که یک تاپل `(String, String, String)` می‌گیرد و همان تاپل را با چرخش ترتیب سیم‌ها به سمت چپ برمی‌گرداند.
این closure را به اسم `rotate` تخصیص دهید.

نکته‌ی مهم این است که نوع آن باید `ChangeClosure` باشد (یا یک نوع Sendable)؛ تعریف این نوع در فایل اولیه آمده است.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. یک مولد درهم‌ریزی سیم‌ها پیاده‌سازی کنید

برای اینکه بفهمید سیم‌های بمب بدبو را به چه ترتیبی باید ببرید، باید تابعی پیاده‌سازی کنید که بر اساس شماره‌ی شناسایی بمب بدبو، تابع درهم‌ریزی مناسب را تولید می‌کند.

این تابع را پیاده‌سازی کنید:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

این تابع به‌عنوان ورودی یک closure می‌گیرد که دو سیم را جابه‌جا می‌کند و یک closure که سه سیم را می‌چرخاند، و در نهایت یک closure برمی‌گرداند.
closure بازگردانده‌شده شماره‌ی شناسایی بمب بدبو و ترتیب سه سیم را می‌گیرد و سپس ترتیبی را محاسبه می‌کند که سیم‌ها باید بر اساس آن بریده شوند.
شماره‌ی شناسایی از ۸ بیت تشکیل شده است و هر بیت تعیین می‌کند که سیم‌ها جابه‌جا شوند یا بچرخند.

برای هر بیت در شماره‌ی شناسایی، با شروع از راست‌ترین بیت، اگر بیت 0 باشد closure `flipper` را روی تاپل سیم‌ها اعمال می‌کنید و اگر 1 باشد closure `rotator` را اعمال می‌کنید تا حالت جدید سیم‌ها به دست آید.
پس از آنکه closureهای مناسب برای همه‌ی ۸ بیت شماره‌ی شناسایی اعمال شدند، حالت نهایی سیم‌ها همان ترتیبی است که باید بریده شوند.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
