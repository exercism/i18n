# آشنایی با بازگشت در JavaScript

«بازگشت» مفهومی قدرتمند در برنامه‌نویسی است که در آن یک تابع خودش را فراخوانی می‌کند.
شاید در ابتدا کمی سخت به نظر برسد، اما وقتی اصول پایه را بفهمید، به ابزاری ارزشمند برای حل مسائل پیچیده تبدیل می‌شود.
در این آموزش، بازگشت را در JavaScript با مثال‌هایی ساده و قابل‌فهم بررسی می‌کنیم.

## بازگشت چیست؟

بازگشت زمانی رخ می‌دهد که یک تابع، به‌طور مستقیم یا غیرمستقیم، خودش را فراخوانی کند.
این شبیه «حلقه» است، اما در آن یک مسئله به زیرمسئله‌های کوچک‌تر و قابل‌مدیریت‌تری شکسته می‌شود.

### مثال ۱: شمارش معکوس

بیایید با یک مثال ساده شروع کنیم: یک تابع شمارش معکوس.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

در این مثال:

- **حالت پایه**: وقتی `num` کوچک‌تر یا مساوی ۰ می‌شود، تابع «Blastoff!» را چاپ می‌کند و دیگر خودش را فراخوانی نمی‌کند.
- **حالت بازگشتی**: تابع مقدار فعلی `num` را چاپ می‌کند و خودش را با `num - 1` فراخوانی می‌کند.

### مثال ۲: فاکتوریل

حالا بیایید به یک مثال کلاسیک از بازگشت نگاه کنیم: محاسبه‌ی فاکتوریل یک عدد.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

در این مثال:

- **حالت پایه**: وقتی `n` برابر ۰ یا ۱ باشد، تابع ۱ را برمی‌گرداند.
- **حالت بازگشتی**: تابع `n` را در فاکتوریل `n - 1` ضرب می‌کند.

## مفاهیم کلیدی

### حالت پایه

هر تابع بازگشتی باید حداقل یک حالت پایه داشته باشد؛ شرطی که در آن تابع فراخوانی خود را متوقف می‌کند.
بدون حالت پایه، بازگشت بی‌پایان ادامه می‌یابد و به سرریز پشته می‌انجامد.

### حالت بازگشتی

حالت بازگشتی مشخص می‌کند که تابع چگونه خودش را با نسخه‌ی کوچک‌تر یا ساده‌تر مسئله فراخوانی می‌کند.

## مزایا و معایب بازگشت

**مزایا:**

- راه‌حلی زیبا برای برخی مسائل.
- همانند مفهوم استقرای ریاضی است.

**معایب:**

- می‌تواند از راه‌حل‌های تکراری کم‌بازده‌تر باشد.
- در بازگشت‌های عمیق ممکن است به سرریز پشته منجر شود.

## نتیجه‌گیری

بازگشت تکنیکی ارزشمند است که می‌تواند مسائل پیچیده را با شکستن آن‌ها به زیرمسئله‌های کوچک‌تر و قابل‌مدیریت‌تر ساده کند.
درک حالت‌های پایه و حالت‌های بازگشتی برای پیاده‌سازی راه‌حل‌های بازگشتی مؤثر در JavaScript ضروری است.
