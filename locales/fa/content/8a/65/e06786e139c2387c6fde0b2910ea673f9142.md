# درباره

برای اجرای مکرر منطق، می‌توانید از «حلقه» استفاده کنید. اگر قرار است کد داخل یک حلقه همیشه دست‌کم یک بار اجرا شود، می‌توانید از حلقه‌ی `do`/`while` استفاده کنید:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

این حلقه کمتر از حلقه‌ی `while` به کار می‌رود، اما در برخی موارد کدی طبیعی‌تر به دست می‌دهد.
