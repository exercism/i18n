# درباره

همه‌ی شرطی‌های Factor **«quotation»** را به‌عنوان شاخه‌های خود می‌گیرند، یعنی کدی که داخل کروشه‌ها، `[ ... ]`، نوشته می‌شود و به‌جای اجرا شدن، به‌عنوان یک مقدار روی پشته گذاشته می‌شود و اجرا نمی‌شود تا وقتی که شرطی آن را انتخاب کند. (خود quotationها در تمرین بعدی به‌طور کامل بررسی می‌شوند.)

سه مورد پایه در `kernel` قرار دارند:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

دو گونه‌ی ستاره‌دار، مقدار منطقی را زمانی که درست به شمار می‌آید به‌عنوان مقداری ارزشمند برای استفاده در نظر می‌گیرند؛ همان جفت متعارف «مقدار یا `f`»:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

برای بیش از دو شاخه، `cond` (در `combinators`) آرایه‌ای از جفت‌های `{ predicate body }` را پیمایش می‌کند و بدنه‌ی نخستین شرطی را که برقرار می‌شود اجرا می‌کند. الگوی متعارف در هر شرط از `dup` استفاده می‌کند تا ورودی باقی بماند، و بدنه با یک `drop` آغاز می‌شود تا آن را پیش از قرار دادن نتیجه دور بریزد:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

آخرین عضو که شرطی ندارد، شاخه‌ی پیش‌فرض است.
