# Tests

هر تمرین شامل یک فایل test است.
با استفاده از برنامه‌ی `bats` testها را اجرا کنید.

```bash
bats hello_world.bats
```

اگر لازم است هنگام اجرای testها به‌صورت محلی خروجی debug چاپ کنید، به [debug به‌صورت محلی][debugging] نگاه کنید.

`bats` باید نصب شود.
برای دستورالعمل‌های نصب `bats` روی سیستم خود، صفحه‌ی [test کردن در مسیر Bash][tests] را ببینید.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Help for assert functions

testها از توابع کتابخانه‌ی [bats-assert][bats-assert] استفاده می‌کنند.
راهنمای توابع گوناگون `assert*` را همان‌جا می‌توانید پیدا کنید.

[bats-assert]: https://github.com/bats-core/bats-assert

## Skipped tests

حل کردن یک تمرین یعنی اینکه همه‌ی testهای آن پاس شوند.
به‌طور پیش‌فرض، وقتی testها را اجرا می‌کنید فقط یک test (اولین test) اجرا می‌شود.
این کار عمدی است، چون به شما اجازه می‌دهد فقط روی پاس کردن همان یک test تمرکز کنید.
وقتی پاس شد، می‌توانید test بعدی را با کامنت کردن یا برداشتن حاشیه‌نویسی بعدی فعال کنید:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Overriding skips

برای اجرای همه‌ی testها، از جمله آن‌هایی که حاشیه‌نویسی `skip` دارند، می‌توانید این را اجرا کنید:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

استفاده از یک تابع پوششی می‌تواند راحت باشد و در تایپ کردن صرفه‌جویی کند:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

بعد testها را فقط با این اجرا کنید:

```bash
bats
```
