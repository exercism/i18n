# مقدمه

این تمرین بر پایه‌ی محاسبات اعداد صحیح در [لازانیای لذیذ لیا][lasagna] ساخته شده است. در اینجا با اعداد شناور کار می‌کنید و واژه‌ی تقسیم مناسب برای هر کار را انتخاب می‌کنید.

## اعداد صحیح و شناور

Factor اعداد صحیح (`1`، `42`، `1_000_000`) را از اعداد شناور (`1.0`، `3.14`، `6.02e23`) تشخیص می‌دهد. اگر یک عدد صحیح و یک عدد شناور را در یک محاسبه با هم ترکیب کنید، نتیجه به‌صورت یک عدد شناور درمی‌آید:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

می‌توانید داخل یک عدد زیرخط بگذارید تا ارقام را گروه‌بندی کنید (مانند `1_000_000`) و Factor به‌سادگی آن‌ها را نادیده می‌گیرد.

## واژه‌های تقسیم

Factor واژه‌های تقسیم جداگانه‌ای دارد. همه‌ی آن‌ها در واژگان [`math`][math] قرار دارند.

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` برای دو عدد صحیح یک `ratio` تولید می‌کند (نوع گویای دقیق در Factor)، یا اگر هر یک از ورودی‌ها شناور باشد، یک `float`. `/f` نتیجه را حتی برای دو عدد صحیح به یک شناور تبدیل می‌کند. `/i` همیشه به سمت صفر گرد می‌کند.

## بررسی

محمول‌های عددی از [`math`][math]، [`math.functions`][math.functions] و [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## تبدیل شناور به عدد صحیح

`floor`، `ceiling` و `round` از واژگان [`math.functions`][math.functions] همه یک شناور برمی‌گردانند (`3.0`، نه `3`). برای رسیدن به یک عدد صحیح واقعی، `>integer` را زنجیره کنید:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## توان و قدر مطلق

`sq`، `^` و `abs` (در [`math.functions`][math.functions]) مربع، توان دلخواه و قدر مطلق را محاسبه می‌کنند:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## کمینه و بیشینه

`min ( x y -- z )` و `max ( x y -- z )` (در [`math.order`][math.order]) کوچک‌تر یا بزرگ‌تر از دو عدد را برمی‌گردانند:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

رایج‌ترین کاربرد، *محدود کردن* است: با `max` یک مقدار را به یک کف می‌چسبانید (مثلاً `0 max` یک مقدار را نامنفی نگه می‌دارد) یا با `min` آن را به یک سقف.

## محمول‌های ترتیب

`math.order` همچنین `before?`، `after?`، `before=?` و `after=?` را برای محمول‌های مقایسه‌ای فراهم می‌کند که روی هر نوع قابل ترتیب کار می‌کنند: اعداد، رشته‌ها، نویسه‌ها:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

وقتی ممکن است مقادیر رشته باشند، از این‌ها به‌جای `<`/`<=` استفاده کنید؛ عملگرهای حسابی روی رشته‌ها اعزام نمی‌شوند.
