# پیوست دستورالعمل‌ها

دنبال جایی برای شروع می‌گردید؟ چند مورد هست که ممکن است بخواهید سر و سامانی به آن‌ها بدهید:

- یک تابع همه‌ی کارها را انجام می‌دهد
- منطق تکرارشده و کارهای تکراری
- تودرتویی عمیق
- اسم‌های مبهم
- قواعد قالب‌بندی پراکنده
- ثابت‌های بدون توضیح
- وضعیت قابل‌تغییر غیرضروری
- پیش‌فرض‌های ضمنی `enum`
- توابع کمکی با مسئولیت‌های نامرتبط
- رشته‌های خالی به‌جای خطاها
- تجزیه و قالب‌بندی دستی تاریخ (به‌جای آن، import کردن و استفاده از `isodate.Date` را امتحان کنید)
- پردازش دستی یونیکد (به‌جای آن، import کردن و استفاده از `unicode.Grapheme` را امتحان کنید)

هر کدام را که به چشمتان می‌آید انتخاب کنید و تست‌ها را سبز نگه دارید!
