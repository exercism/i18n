# مقدمه

## نوع تابع

اگر همه‌ی اسم‌ها و برچسب‌ها را از امضای یک تابع Swift حذف کنیم، آنچه باقی می‌ماند نوع آن تابع است.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

دقت کنید که نوع دو تابع اول یکسان است، `(String, Int) -> String`، هرچند امضای آن دو متفاوت است و این دو تابع بسیار متفاوت کار می‌کنند. هر دو یک `String` و یک `Int` به عنوان ورودی می‌گیرند و یک `String` برمی‌گردانند. و همان‌طور که از نوع تابع سوم پیداست، هرچند به نظر می‌رسد بدنه‌ی تابع چیزی برنمی‌گرداند، در واقع به‌طور ضمنی `()` را برمی‌گرداند، که تنها مقدار نوع `Void` است.

این نوع‌های تابع را می‌توان دقیقاً مانند هر نوع دیگری در Swift به کار برد؛ مثلاً می‌توان از آن‌ها در اعلان متغیرها یا ثابت‌ها استفاده کرد. و چون توابع در Swift مقدار هستند، می‌توان توابع موجود را به این ثابت‌ها/متغیرها نسبت داد:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

مانند سایر متغیرها/ثابت‌ها، مقداری که به آن نسبت می‌دهید باید از نوع درست باشد:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## نوع تابع به عنوان نوع پارامتر

چون نوع تابع را می‌توان هر جایی به کار برد که انواع دیگر به کار می‌روند، نتیجه می‌شود که می‌توان از آن به عنوان نوع پارامتر استفاده کرد، آن را به توابع دیگر پاس داد و از داخل همان توابع فراخوانی کرد.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## نوع تابع به عنوان نوع بازگشتی

به همین ترتیب، می‌توان از نوع تابع به عنوان نوع بازگشتی تابع استفاده کرد. به بیان دیگر، می‌توان توابعی نوشت که توابع دیگری می‌سازند و برمی‌گردانند. هنگام ساختن این توابع، تابعی که برگردانده می‌شود می‌تواند از پارامترهای دیگرِ پاس‌داده‌شده به تابع یا از متغیرهای محلی‌ای که داخل تابع والد ساخته شده‌اند استفاده کند.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
