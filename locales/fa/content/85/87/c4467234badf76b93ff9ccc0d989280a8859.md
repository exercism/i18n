# مقدمه

«disposable» هر چیزی است که یک منبع سیستمی را در خود نگه می‌دارد (یک فایل باز، یک سوکت، یک قفل مبتنی بر جدول درهم‌سازی) و وقتی کارتان با آن تمام شد باید آزاد شود. واژگان `destructors` در Factor این‌ها را در چارچوبی کوچک می‌گنجاند تا پاک‌سازی حتی وقتی یک استثنا پشته را باز می‌کند هم انجام شود.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` یک قطعه‌کد را با آن منبع اجرا می‌کند و هنگام خروج منبع را آزاد می‌کند. اگر بیش از یک منبع دارید، با `with-destructors` یک محدوده باز کنید و هر کدام را با `&dispose` (آزادسازی هنگام خروج عادی *و* هنگام خطا) یا `|dispose` (آزادسازی فقط هنگام خطا) ثبت کنید.

یک کلاس با ارث‌بری از `disposable` و پیاده‌سازی جنریک `dispose*` به این چارچوب می‌پیوندد؛ چارچوب آن را برای هر شیء یک بار و فقط یک بار فراخوانی می‌کند. کلمه‌ی عمومی که فراخوان‌ها به کار می‌برند `dispose` است.
