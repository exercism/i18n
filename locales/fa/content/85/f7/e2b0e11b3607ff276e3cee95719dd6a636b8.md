# Test

## اجرای Test

برای اجرای Test، دستور زیر را اجرا کنید:

```bash
dotnet test
```

## حل تمرین

حل یک تمرین یعنی کاری کنید که همه‌ی Testهای آن قبول شوند. به‌صورت پیش‌فرض، وقتی Testها را اجرا می‌کنید فقط یک Test (اولین Test) اجرا می‌شود. این کار عمدی است، چون به شما امکان می‌دهد تمرکزتان را فقط روی قبول شدن همان یک Test بگذارید. وقتی همان Test قبول شد، می‌توانید با حذف `Skip = "Remove this Skip property to run this test"` از ویژگی `[<Fact>]` یا `[<Theory>]` آن Test، Test بعدی را فعال کنید. وقتی همه‌ی Testها را فعال کنید و پیاده‌سازی‌تان کاری کند که همه‌ی آن‌ها قبول شوند، تمرین را حل کرده‌اید!

برای اینکه راحت‌تر شروع کنید، هر تمرین با یک فایل پیاده‌سازی اولیه همراه است. می‌توانید از این فایل به‌عنوان نقطه‌ی شروع برای ساختن راه‌حل خودتان استفاده کنید. اگر فکر می‌کنید کار درستی است، می‌توانید این فایل را حذف یا تغییر دهید.

## استفاده از بسته‌ها

باید بتوانید بیشتر تمرین‌ها را بدون استفاده از هیچ بسته‌ی بیرونی حل کنید. اما در تمرین‌هایی که واقعاً می‌خواهید از یک بسته‌ی بیرونی استفاده کنید، می‌توانید با اجرای دستور زیر آن را به پروژه‌تان اضافه کنید:

```bash
dotnet add package [package-name]
```
