# دستورالعمل‌ها

در این تمرین می‌خواهید کدی بنویسید که کمکتان کند از روی کتاب آشپزی محبوبتان یک لازانیای درجه‌یک بپزید.
چهار وظیفه دارید که همه به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار پخت در فر را بر حسب دقیقه تعریف کنید

ثابت `expectedMinutesInOven` را تعریف کنید که نگه می‌دارد لازانیا باید چند دقیقه در فر بماند.
بر اساس کتاب آشپزی، زمان مورد انتظار پخت در فر ۴۰ دقیقه است:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. زمان باقی‌مانده‌ی پخت در فر را بر حسب دقیقه محاسبه کنید

تابع `remainingMinutesInOven(elapsedMinutes:)` را تعریف کنید که آرگومان `elapsedMinutes` را می‌گیرد و شمار دقیقه‌هایی را نگه می‌دارد که لازانیا تا الآن در فر بوده است.
تابع باید برگرداند که لازانیا بر اساس زمان مورد انتظار پخت در فر از وظیفه‌ی قبلی، چند دقیقه‌ی دیگر باید در فر بماند.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

تابع `preparationTimeInMinutes(layers:)` را تعریف کنید که آرگومان `layers` را می‌گیرد و شمار لایه‌هایی را نگه می‌دارد که به لازانیا اضافه کرده‌اید.
تابع باید برگرداند که چند دقیقه صرف آماده‌سازی لازانیا کرده‌اید، با این فرض که آماده کردن هر لایه ۲ دقیقه از شما وقت می‌گیرد.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. مجموع زمان کار را بر حسب دقیقه محاسبه کنید

تابع `totalTimeInMinutes(layers:elapsedMinutes:)` را تعریف کنید که دو آرگومان می‌گیرد: پارامتر `layers` شمار لایه‌هایی است که به لازانیا اضافه کرده‌اید، و پارامتر `elapsedMinutes` شمار دقیقه‌هایی است که لازانیا در فر بوده است.
تابع باید برگرداند که در کل چند دقیقه روی پخت لازانیا کار کرده‌اید، یعنی مجموع زمان آماده‌سازی بر حسب دقیقه و زمانی که لازانیا تا این لحظه در فر گذرانده است.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
