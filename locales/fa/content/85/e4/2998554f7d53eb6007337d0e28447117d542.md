# دستورالعمل‌ها

شما مسئول میز امنیت در یک ایستگاه تحقیقاتی هستید. کارکنان *نشان*هایی همراه دارند که کدهایشان از یک قالب سخت‌گیرانه پیروی می‌کند، گزارش ورود پر از همین کدهاست که میان متن معمولی مخلوط شده‌اند، و باید پیش از اشتراک‌گذاری، گزارش پاکسازی شود. «عبارات باقاعده» ابزار درست برای هر یک از این کارها هستند.

یک کد نشان معتبر **دو حرف بزرگ، یک خط تیره و سپس چهار رقم** است، برای نمونه `NS-1024`.

## 1. بررسی یک کد نشان

تابعی به اسم `valid-badge?` تعریف کنید که یک رشته‌ی نشان می‌گیرد و وقتی *کل* رشته یک کد نشان معتبر باشد `t` و در غیر این صورت `f` برمی‌گرداند.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. بیرون کشیدن هر کد از یک خط گزارش

تابعی به اسم `badge-codes` تعریف کنید که یک خط از گزارش ورود می‌گیرد و دنباله‌ای از همه‌ی کدهای نشانی را که در آن ظاهر می‌شوند، به ترتیب، برمی‌گرداند.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. شمارش رقم‌های یک کد

تابعی به اسم `digit-count` تعریف کنید که یک رشته می‌گیرد و تعداد رقم‌هایی را که در آن وجود دارد برمی‌گرداند.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. پنهان‌سازی گذرواژه‌ها

خط‌های گزارش گاهی یک گذرواژه را به شکل `pass=` و سپس رشته‌ی محرمانه ثبت می‌کنند (هر توالی پشت‌سرهمی از نویسه‌های غیرفاصله). تابعی به اسم `redact` تعریف کنید که یک خط می‌گیرد و همان خط را برمی‌گرداند، با این تغییر که هر گذرواژه‌ی از این دست با `pass=****` جایگزین شده است.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
