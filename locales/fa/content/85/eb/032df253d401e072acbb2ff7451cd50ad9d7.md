# مقدمه

پایتون مقادیر «درست» و «غلط» را با نوع [`bool`][bools] نمایش می‌دهد که زیرکلاسی از `int` است.
 تنها دو مقدار در این نوع وجود دارد: `True` و `False`.
  این مقادیر را می‌توان به یک متغیر نسبت داد:

```python
>>> true_variable = True
>>> false_variable = False
```

می‌توانیم عبارت‌های «منطقی» را با عملگرهای `and`، `or` و `not` ارزیابی کنیم.

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
