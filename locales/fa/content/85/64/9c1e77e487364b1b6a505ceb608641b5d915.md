# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که به یک فریلنسر کمک می‌کند درباره‌ی قیمت پروژه‌های مشخصی با مشتریانش گفت‌وگو کند.
چند تابع کمکی می‌نویسید تا هزینه‌ها را برای مشتریان سریع محاسبه کنید.

```exercism/note
متغیر `ratePerHour` و تابع `dayRate` به پول مربوط هستند.
واحد اندازه‌گیری، پول در ازای یک واحد زمان است: به‌ترتیب ساعت و روز.
```

## 1. محاسبه‌ی نرخ روزانه با داشتن نرخ ساعتی

مشتری‌ای با فریلنسر تماس می‌گیرد تا درباره‌ی نرخ‌هایش پرس‌وجو کند.
فریلنسر توضیح می‌دهد که **_روزی ۸ ساعت کار می‌کند._**
اما فریلنسر فقط نرخ ساعتی خود را برای پروژه می‌داند.
به او کمک کنید تا با داشتن نرخ ساعتی، نرخ روزانه را تخمین بزند.

```javascript
dayRate(89);
// => 712
```

نرخ روزانه نیازی به گرد کردن یا تبدیل شدن به دقت «ثابت» ندارد.

## 2. محاسبه‌ی تعداد روزهای کاری با داشتن بودجه‌ی ثابت

روزی دیگر، مدیر پروژه‌ای به فریلنسر پیشنهاد می‌دهد روی پروژه‌ای با بودجه‌ی ثابت کار کند.
با داشتن بودجه‌ی ثابت و نرخ ساعتی فریلنسر، کمکش کنید تعداد روزهایی را که تا تمام شدن بودجه کار می‌کند حساب کند.
نتیجه _باید_ به نزدیک‌ترین عدد صحیح **به پایین گرد شود**.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. محاسبه‌ی نرخ تخفیف‌خورده برای پروژه‌های بزرگ

اغلب مشتریان فریلنسر او را برای پروژه‌هایی استخدام می‌کنند که چند ماه طول می‌کشند.
در این موارد، فریلنسر تصمیم می‌گیرد برای هر ماه کامل تخفیف بدهد و روزهای باقی‌مانده با نرخ روزانه حساب شوند.
تعادل عالی شما میان کار و زندگی یعنی در هر ماه تقویمی فقط ۲۲ روز کار می‌کنید، پس **_هر ماه ۲۲ روز قابل صورتحساب دارد._**
به او کمک کنید هزینه‌ی چنین پروژه‌هایی را تخمین بزند، با داشتن نرخ ساعتی، تعداد روزهای قابل صورتحساب پروژه و نرخ تخفیف ماهانه.
تخفیف همیشه به‌صورت یک عدد داده می‌شود، جایی که `42%` به `0.42` تبدیل می‌شود. نتیجه _باید_ به نزدیک‌ترین عدد صحیح **به بالا گرد شود**.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
