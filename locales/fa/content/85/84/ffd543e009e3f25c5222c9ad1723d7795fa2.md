# اجرای تست‌ها

برای اجرای مجموعه‌تست، دستور زیر را اجرا کنید:

```bash
stack test
```

#### اگر پیام خطایی مثل این دریافت کردید…

```
No .cabal file found in directory
```

یا

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

احتمالاً نسخه‌ی قدیمی stack را اجرا می‌کنید و باید آن را ارتقا دهید. این دستور را امتحان کنید:

```bash
stack upgrade
```

یا گزینه‌های دیگر برای ارتقا را در [مستندات Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade) ببینید.

#### در غیر این صورت، اگر پیام خطایی مثل این دریافت کردید…

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

فقط همان کاری را بکنید که می‌گوید؛ نسخه‌ی درست کامپایلر را دانلود و نصب می‌کند:

```bash
stack setup
```

# اجرای *GHCi*

اگر می‌خواهید راه‌حل خود را در GHCi امتحان کنید، فقط این دستور را اجرا کنید:

```bash
stack ghci
```
