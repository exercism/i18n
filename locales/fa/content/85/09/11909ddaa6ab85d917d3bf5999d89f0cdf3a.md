# درباره

برای ساختن یک «چارلیست» از «سیگیل» `~c` استفاده می‌شود.

```elixir
~c"hello"
```

~~~~exercism/note
توجه کنید که در نسخه‌های قدیمی‌تر Elixir، چارلیست‌ها به‌صورت `'hello'` با کوتیشن تک نمایش داده می‌شوند.
~~~~

چارلیست یک «لیست» از اعداد صحیح است. این اعداد نشان‌دهنده‌ی مقدار یونیکد یک نویسه‌ی مشخص هستند، که به آن «نقطه‌ی کد» نیز می‌گویند.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## چارلیست‌ها _لیست_ هستند

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

چون چارلیست‌ها لیست هستند، می‌توانید با آن‌ها درست مثل هر لیست دیگری کار کنید: با بازگشت و تطبیق الگو، یا با ماژول [`List`][list].

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

می‌توانید دو لیست را با [`++`][kernel-concat-list] به هم بچسبانید.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

هرچه لیست اول طولانی‌تر باشد، چسباندن کندتر انجام می‌شود؛ پس از افزودن پیاپی به لیست‌هایی با طول دلخواه بپرهیزید.

## قابلیت چاپ

اگر یک لیست از اعداد صحیح فقط شامل اعدادی باشد که نقطه‌ی کد یک نویسه‌ی قابل چاپ هستند، به‌صورت چارلیست نمایش داده می‌شود، حتی اگر با نحوه‌ی نگارش `[]` تعریف شده باشد.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

اگر یک لیست از اعداد صحیح حتی یک نقطه‌ی کد از یک نویسه‌ی غیرقابل چاپ داشته باشد (مثلاً `0-6`، `14-26`، `28-31`)، به‌صورت لیست نمایش داده می‌شود، حتی اگر با نحوه‌ی نگارش `~c""` تعریف شده باشد.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

قابلیت چاپ را می‌توان با [`List.ascii_printable?`][list-ascii-printable] بررسی کرد.

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

به خاطر داشته باشید که این‌ها دو روش متفاوت برای _نمایش_ داده‌ی یکسان هستند. مقادیر دقیقاً برابرند.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

وقتی لیستی را با [`IO.inspect`][io-inspect] چاپ می‌کنید، می‌توانید از گزینه‌ی [`:charlists`][inspect-opts] استفاده کنید تا کنترل کنید لیست‌ها چطور چاپ می‌شوند.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## نقطه‌ی کد

می‌توانید `?` را قبل از یک نویسه بگذارید تا نقطه‌ی کد آن را به دست آورید.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## چارلیست در برابر رشته

چارلیست‌ها و رشته‌هایی که از نویسه‌های یکسانی تشکیل شده‌اند، برابر در نظر گرفته نمی‌شوند.

```elixir
~c"hello" == "hello"
false
```

هر مقدار در یک چارلیست، [نقطه‌ی کد یونیکد یک نویسه][unicode-table] است، در حالی که در یک رشته، نقطه‌های کد به‌صورت [UTF-8][utf8] کدگذاری می‌شوند.

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

توجه کنید که `ü` با نقطه‌ی کد `252`، در UTF-8 به‌صورت `195` و `188` کدگذاری می‌شود.

**در عمل، چارلیست‌ها به‌ندرت استفاده می‌شوند**. کاربرد اصلی آن‌ها برقراری ارتباط با Erlang است، به‌ویژه هنگام استفاده از کتابخانه‌های قدیمی‌تری که باینری‌ها را به‌عنوان آرگومان نمی‌پذیرند.

وقتی با Elixir کار می‌کنید، **برای ذخیره‌ی متن از رشته استفاده کنید**. ماژول `String` انتخاب گسترده‌ای از توابع برای پردازش متن ارائه می‌دهد، توابعی که برای چارلیست‌ها در دسترس نیستند.

چارلیست‌ها را می‌توان با [`to_string`][kernel-to-string] به رشته تبدیل کرد.

```elixir
to_string(~c"hello")
# => "hello"
```
