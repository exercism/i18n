# مقدمه

## اعداد

در Java دو نوع متفاوت عدد وجود دارد:

- اعداد صحیح: اعدادی که هیچ رقمی پشت جداکننده‌ی اعشار ندارند (اعداد کامل).
  مثال‌هایی از آن‌ها `-6`، `0`، `1`، `25`، `976` و `-500000` است.
- اعداد اعشاری: اعدادی با صفر یا چند رقم پشت جداکننده‌ی اعشار.
  مثال‌هایی از آن‌ها `-20.4`، `0.1`، `2.72`، `16.984025` و `1024.0` است.

دو نوع عددی رایج در Java، `int` و `double` هستند.
یک `int` عدد صحیحی ۳۲ بیتی است و یک `double` عددی اعشاری ۶۴ بیتی.

محاسبات با عملگرهای حسابی استاندارد انجام می‌شود.
اعداد را می‌توان با عملگرهای استاندارد مقایسه‌ی عددی (مثلاً `5 > 4` و `4 <= 5`) و عملگرهای تساوی (`==`) و نامساوی (`!=`) مقایسه کرد.

Java دو نوع تبدیل عددی دارد:

1. تبدیل‌های ضمنی: هیچ داده‌ای از دست نمی‌رود و نیازی به نگارش اضافی نیست.
2. تبدیل‌های صریح: ممکن است داده از دست برود و به نگارش اضافی به شکل یک «تبدیل نوع» نیاز است.

چون `int` دقت کمتری از `double` دارد، تبدیل از `int` به `double` ایمن است و در نتیجه یک تبدیل ضمنی به شمار می‌رود.
اما تبدیل از `double` به `int` ممکن است به از دست رفتن داده منجر شود، پس به یک تبدیل صریح نیاز دارد.

## دستور if-else

### دستور «if-then»

پایه‌ای‌ترین دستور کنترل جریان در Java، دستور if-then است.
از این دستور استفاده می‌شود تا بخشی از کد فقط در صورتی اجرا شود که شرط خاصی `true` باشد.
یک دستور if-then با بند `if` تعریف می‌شود:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

در مثال بالا، اگر خودرو سوخت نداشته باشد، فراخوانی متد `Car.drive` هیچ کاری انجام نمی‌دهد.

### دستور «if-then-else»

دستور if-then-else مسیر اجرای جایگزینی را برای زمانی فراهم می‌کند که شرط موجود در بند `if` به `false` ارزیابی شود.
این مسیر اجرای جایگزین پس از یک بند `if` می‌آید و با بند `else` تعریف می‌شود:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

در مثال بالا، اگر خودرو سوخت نداشته باشد، فراخوانی متد `Car.drive` متد دیگری را برای متوقف کردن خودرو فراخوانی می‌کند.

دستور if-then-else با استفاده از بند `else if` از چندین شرط هم پشتیبانی می‌کند:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

در مثال بالا، راندن خودرو زمانی که سوخت کمتر یا مساوی `5` باشد، خودرو را به حرکت درمی‌آورد، اما چراغ سوخت را روشن می‌کند.
وقتی سوخت به `0` برسد، خودرو از حرکت می‌ایستد.
