# پیوست دستورالعمل

## ثبات

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | ورودی        | آدرس | رنگ اول به صورت رشته‌ی مختوم به null  |
| `$a1`    | ورودی        | آدرس | رنگ دوم به صورت رشته‌ی مختوم به null |
| `$a2`    | ورودی        | آدرس | رنگ سوم به صورت رشته‌ی مختوم به null  |
| `$a3`    | ورودی/خروجی | آدرس | رشته‌ی خروجی مختوم به null          |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت استفاده می‌شود             |
