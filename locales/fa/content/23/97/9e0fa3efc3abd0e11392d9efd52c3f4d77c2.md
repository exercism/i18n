# دستورالعمل‌ها

الیس که یک شعبده‌باز تازه‌کار است، باید دست کارت‌هایش را به روش‌های مختلفی بررسی کند.
برای اینکه کار ساده بماند، او فقط از کارت‌هایی با مقدار ۱ تا ۱۰ استفاده می‌کند.

## 1. تعیین کنید چند کارت از یک نوع خاص در دست وجود دارد

الیس می‌خواهد بداند چند کارت از یک نوع خاص در دستش دارد.

تابعی به اسم `cardTypeCheck` بنویسید که دو پارامتر می‌گیرد: یک آرایه از کارت‌ها (دست الیز) و نوع کارتی که باید شمرده شود.

<!--prettier-ignore -->
~~~exercism/note
تابع باید از `forEach` استفاده کند و تعداد کارت‌های آن نوع مشخص را در دست برگرداند.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. تعیین کنید چند کارت فرد یا زوج وجود دارد

برای یک ترفند دیگر، الیس باید بداند چند کارت فرد یا زوج در دستش وجود دارد.

تابعی به اسم `determineOddEvenCards` پیاده‌سازی کنید که دو پارامتر می‌گیرد: یک آرایه از کارت‌ها (دست الیز) و یک «مقدار منطقی» (`true` معادلِ «زوج» و `false` معادلِ «فرد» است).

این تابع باید یک عدد برگرداند: تعداد کارت‌های فرد یا زوج (بسته به مقدار پارامتر دوم) در دست.

<!--prettier-ignore -->
~~~exercism/note
برای تمرین، این بار در پیاده‌سازی تابع از یک حلقه‌ی `for...of` استفاده کنید.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
