# دستورالعمل‌ها

یکی از دوستانتان یک فروشگاه عمده‌فروشی قدیمی به اسم **Gross Store** دارد.
این اسم از مقدار کالایی می‌آید که فروشگاه می‌فروشد: همه‌شان بر حسب [واحد گروس][gross-unit] هستند.
دوستتان از شما خواسته است برای فروشگاهش یک سیستم نقطه‌ی فروش (POS) پیاده‌سازی کنید.
**اول می‌خواهید یک نمونه‌ی اولیه برای آن بسازید.**
**در نمونه‌ی اولیه‌تان، سیستم شما فقط مقدار را ثبت می‌کند.**
دوستتان برای کمک به شما فهرستی از واحدهای اندازه‌گیری در اختیارتان گذاشته است:

| واحد               | مقدار |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. واحد اندازه‌گیری را در برنامه‌تان ذخیره کنید

برای استفاده از واحد اندازه‌گیری، باید آن را در برنامه‌تان ذخیره کنید.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. یک صورتحساب جدید برای مشتری بسازید

باید تابعی پیاده‌سازی کنید که یک صورتحساب جدید (و خالی) برای مشتری می‌سازد.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. یک قلم کالا به صورتحساب مشتری اضافه کنید

برای پیاده‌سازی این مورد، باید این کارها را انجام دهید:

- اگر `unit` داده‌شده در نگاشت `units` نباشد، `false` را برگردانید.
- در غیر این صورت کالا را با کلید اسم کالا به `bill` مشتری اضافه کنید و سپس `true` را برگردانید.
- اگر کالا از قبل در صورتحساب موجود باشد، مقدار آن را به اندازه‌ی مقداری که به `unit` داده‌شده مربوط است افزایش دهید.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> در نظر داشته باشید که نوع مقدار برگشتی `bool` است.

## 4. یک قلم کالا را از صورتحساب مشتری حذف کنید

برای پیاده‌سازی این مورد، باید این کارها را انجام دهید:

- اگر کالای داده‌شده در صورتحساب **نباشد**، `false` را برگردانید.
- اگر `unit` داده‌شده در نگاشت `units` نباشد، `false` را برگردانید.
- اگر مقدار جدید کمتر از 0 شود، `false` را برگردانید.
- اگر مقدار جدید 0 باشد، کالا را کاملاً از `bill` حذف کنید و سپس `true` را برگردانید.
- در غیر این صورت، مقدار کالا را کاهش دهید و `true` را برگردانید.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> در نظر داشته باشید که نوع مقدار برگشتی `bool` است.

## 5. مقدار یک کالای مشخص را که در صورتحساب مشتری است برگردانید

برای پیاده‌سازی این مورد، باید این کارها را انجام دهید:

- اگر `item` در صورتحساب نباشد، `0` و `false` را برگردانید.
- در غیر این صورت، مقدار کالا در `bill` و `true` را برگردانید.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> در نظر داشته باشید که مقادیر برگشتی از نوع `int` و `bool` هستند.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
