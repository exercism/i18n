# مقدمه

وراثت یکی از مفاهیم اصلی برنامه‌نویسی شیءگرا (OOP) است.
این مفهوم بیانگر یک رابطه‌ی IS-A است.
معنای آن در برنامه‌نویسی دقیقاً همان معنای آن در زبان انگلیسی است: به ارث بردن ویژگی‌ها از والد (در برنامه‌نویسی، این ویژگی‌ها معمولاً توابع و متغیرها هستند).

کلاس `Animal` را در نظر بگیرید، همان‌طور که در ادامه آمده است:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` یک کلاس والد است، چون ویژگی‌های این کلاس را می‌توان به‌طور کلی به همه‌ی حیوانات تعمیم داد.

حالا حیوانی به اسم `Lion` را در نظر بگیرید که کلاسی به این شکل دارد:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
از حاشیه‌نویسی `Override` برای نشان دادن این استفاده می‌شود که متدی در یک زیرکلاس، متدی از ابرکلاس خود را بازنویسی می‌کند.
استفاده از آن الزامی نیست، اما رعایتش یک رویه‌ی پسندیده است.
~~~~

حالا هر وقت که این کار را انجام می‌دهیم:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

توجه: مقداردهی اولیه‌ی کلاس `Animal` با `Lion`.
خروجی چنین چیزی خواهد بود:

```java
Lion here!!
```

طبق اصول OOP، انواع مختلفی از وراثت وجود دارد، اما Java فقط از برخی از آن‌ها پشتیبانی می‌کند (چندسطحی و سلسله‌مراتبی).
برای مطالعه‌ی بیشتر درباره‌ی آن، [این مطلب][java-inheritance] را بخوانید.
