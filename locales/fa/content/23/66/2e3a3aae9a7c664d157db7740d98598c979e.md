# Testها

## خط فرمان

برای اجرای Testها از خط فرمان، می‌توانید از دستور زیر استفاده کنید:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>` را با اسم تمرینی که در حال پیاده‌سازی آن هستید جایگزین کنید.

## تعاملی

برای اجرای Prolog به‌صورت تعاملی، ابتدا این دستور را اجرا کنید:

```bash
swipl
```

پس از اینکه کنسول Prolog شروع به کار کرد، پیاده‌سازی خود را بارگذاری کنید و Testها را با این دستور اجرا کنید:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>` را با اسم تمرینی که در حال پیاده‌سازی آن هستید جایگزین کنید.

### بارگذاری مجدد تغییرات

پس از اینکه فایل‌های بالا بارگذاری شدند، می‌توانید هر تغییری را که ایجاد کرده‌اید با اجرای این دستور اعمال کنید:

```
?- make.
```

## Testهای نادیده‌گرفته‌شده

وقتی برای اولین بار یک تمرین را شروع می‌کنید، فقط اولین Test اجرا می‌شود. بقیه با افزودن `condition(pending)` به هدف `test` نادیده گرفته شده‌اند. پس از اینکه اولین Test موفق شود، Test بعدی را با تغییر `pending` در `condition(pending)` به `true` از حالت نادیده‌گرفته‌شده خارج کنید. این کار را برای هر Test تکرار کنید تا همه اجرا شوند و موفق شوند.

### خط فرمان

برای اجرای Testهای در انتظار نیز، آرگومان `-- --all` را به انتهای دستور اضافه کنید:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
