# کلاس‌ها و ویژگی‌های فقط‌خواندنی

کلاس‌ها و ویژگی‌های فقط‌خواندنی به کلاس‌ها این امکان را می‌دهند که ویژگی‌های عمومی را برای دسترسی آسان تعریف کنند، اما از تغییر آن‌ها جلوگیری می‌کنند. برای اعلام یک ویژگی به‌عنوان «فقط‌خواندنی»، باید `readonly` را پیش از مشخص‌کردن نوع بیاورید. به این ویژگی تنها یک بار می‌توان مقدار داد. هر تلاش برای مقداردهی دوباره یا تغییر مقدار به `Error` منجر می‌شود.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

کلاس‌های فقط‌خواندنی بر همین رفتار بنا شده‌اند: اگر کلاس را `readonly` اعلام کنید، این اعلان فقط‌خواندنی به هر ویژگی اعمال می‌شود. علاوه بر این، از افزودن ویژگی‌های پویا جلوگیری می‌کند.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
