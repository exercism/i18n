# مقدمه

## مقدار منطقی

زبان Gleam مقادیر «درست» و «غلط» را با نوع `Bool` نمایش می‌دهد. این نوع فقط دو مقدار دارد: `True` و `False`. می‌توان این مقادیر را به یک متغیر نسبت داد:

```gleam
let true_variable = True
let false_variable = False
```

می‌توان از عملگرهای `&&`، `||` و `!` برای کار با مقادیر منطقی استفاده کرد:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

عملگرهای `&&` و `||` از «ارزیابی اتصال کوتاه» استفاده می‌کنند؛ یعنی عبارت سمت راست عملگر فقط در صورت نیاز ارزیابی می‌شود.

هر یک از این عملگرها اولویت متفاوتی دارد؛ `!` پیش از `&&` و `||` ارزیابی می‌شود. از آکولادها می‌توان استفاده کرد تا بخشی از عبارت پیش از بخش‌های دیگر ارزیابی شود:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
