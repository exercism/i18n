# مقدمه

[«تاپل»][tuples] چندین مقدار را در یک مقدار ترکیبی واحد کنار هم می‌گذارد.
برخلاف آرایه، مقادیر یک تاپل لازم نیست از یک نوع باشند و اندازه‌ی تاپل پس از ساخته شدن ثابت است.

برای ساختن تاپل، مقادیر جدا‌شده با کاما را داخل پرانتز قرار دهید:

```swift
let order = ("biscuits", 2.99, 3)
```

می‌توانید حاشیه‌نویسی نوع را هم به‌صورت صریح بنویسید:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

برای بیرون کشیدن عناصر تک‌تک از یک تاپل بی‌اسم، از نحوه‌ی نگارش اندیس صفرمبنا (`.0`، `.1` و به همین ترتیب) استفاده کنید:

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## تاپل‌های دارای اسم

وقتی تاپل را تعریف می‌کنید، می‌توانید به هر یک از عناصر آن اسم بدهید:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

اس‌م‌دادن به عناصر، کد را خواناتر می‌کند و اجازه می‌دهد با نگارش نقطه‌ای و با استفاده از برچسب‌ها به عناصر دسترسی داشته باشید:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

می‌توانید اسم عناصر را در حاشیه‌نویسی نوع هم بگنجانید:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## تغییر تاپل‌ها

اگر تاپلی به‌عنوان متغیر (`var`) تعریف شده باشد، می‌توانید عناصر آن را به‌روزرسانی کنید:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## برگرداندن چندین مقدار

توابع Swift فقط می‌توانند یک مقدار واحد را برگردانند، اما با برگرداندن یک تاپل می‌توانید چندین مقدار را در کنار هم بسته‌بندی کنید و [از یک تابع برگردانید][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## تجزیه‌ی تاپل

می‌توانید مقادیر یک تاپل را به ثابت‌های جداگانه یا متغیرهای جداگانه تجزیه (باز) کنید:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

تجزیه‌ی تاپل در حلقه‌های `for-in` هم به‌صورت مستقیم کار می‌کند:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
