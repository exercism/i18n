# درباره

[`Rational numbers`][rational] کسرهایی هستند که صورت و مخرجشان عدد صحیح است.

برای مثال، می‌توانیم `2//3` را به‌صورت یک کسر دقیق ذخیره کنیم، نه به‌صورت مقدار تقریبی `Float64` که `0.6666...` است.

مزیت این کار آن است که (جز در حالت حاد [سرریز عدد صحیح][integer-overflow]) یک عدد گویا دقیق باقی می‌ماند و از خطاهای گرد کردن که معمولاً در اعداد ممیز شناور گریزناپذیرند، جلوگیری می‌کند.

جزئیات بیشتر را می‌توانید در [صفحه‌ی راهنمای][julia-rational] Julia ببینید.

اعداد گویا نوع عددی نسبتاً ساده‌ای هستند و هدفشان این است که همان‌طور که انتظار دارید کار کنند.
چون از همان نسخه‌های اولیه یک نوع استاندارد در Julia بوده‌اند، بیشتر توابع آن‌ها را به‌عنوان ورودی می‌پذیرند، درست مثل اعداد صحیح و اعداد ممیز شناور.

## ساختن اعداد گویا

ساختن آن‌ها به همین سادگی است: `//` را بین دو عدد صحیح قرار دهید.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

عامل‌های مشترک به‌طور خودکار حذف می‌شوند و کسر به ["lowest terms"][lowest-terms] خود تبدیل می‌شود: کوچک‌ترین اعداد صحیحی که آن کسر را با دقت نشان می‌دهند و مخرجشان نامنفی است.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

نتایج بی‌نهایت پذیرفته می‌شوند، اما `NaN` پذیرفته نمی‌شود.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## محاسبات با اعداد گویا

[`arithmetic operators`][operators] معمول `+ - * / ^ %` با اعداد گویا کار می‌کنند، عملاً همان‌طور که با سایر انواع عددی کار می‌کنند.

می‌توان اعداد صحیح و `Rational`های دیگر را هم در عبارت به کار برد و نتیجه یک `Rational` خواهد بود.
به کار بردن `float` در عبارت، به خروجی `float` می‌انجامد و در نتیجه ممکن است دقت از دست برود.

اگر `float` می‌خواهید، کافی است با تابع `float()` یک عدد گویا را تبدیل کنید.
کاملاً معمول است که از اعداد گویا برای حفظ دقت در طول یک محاسبه‌ی طولانی استفاده کنید و در پایان نتیجه را به یک عدد ممیز شناور تبدیل کنید.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

می‌توان اعداد گویا و [اعداد مختلط][complex] را هم با هم ترکیب کرد.
درباره‌ی اعداد مختلط در یک [مفهوم جداگانه][complex-concept] بحث شده است.

## سایر عملیات

در Julia، اعداد گویا فقط عدد هستند.
کامپایلر معمولاً در صورت لزوم نوع‌ها را تبدیل می‌کند.

اما حواستان باشد که مقایسه‌ها فقط برای کسرهایی کار می‌کنند که نمایش اعشاری متناهی دارند:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

ولی در غیر این صورت، برای مقایسه باید یک `Rational` را به `Float` تبدیل کرد:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

توابع ریاضی اعداد گویا را به‌عنوان ورودی می‌گیرند، اما ممکن است نتیجه‌ی ممیز شناور بدهند:

```julia-repl
julia> sqrt(9//16)
0.75
```
