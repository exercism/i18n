# درباره

`jq` ابزاری برای تجزیه و تبدیل داده‌های JSON است.
`jq` مثل `sed` برای داده‌های JSON است؛ می‌توانید با آن داده‌های ساخت‌یافته را با همان آسانی‌ای تکه‌تکه، فیلتر، نقشه‌برداری و تبدیل کنید که `sed`، `awk`، `grep` و همکارانشان به شما اجازه می‌دهند با متن بازی کنید.

`jq` یک زبان برنامه‌نویسی تابعی با نوع‌دهی پویا است.
همه‌ی مقادیر تغییرناپذیرند.

برنامه‌های `jq` از خطوط لوله‌ی «فیلترها» ساخته شده‌اند: هر فیلتر یک عنصر را به عنوان ورودی می‌گیرد، روی آن عمل می‌کند و صفر یا چند عنصر تبدیل‌شده بیرون می‌دهد.
به «فیلتر» می‌توان «عبارت» هم گفت.

خروجی (یا خروجی‌های) یک عبارت را می‌توان با عملگر `|` به عبارت دیگری سپرد.
`expressionA | expressionB` ابتدا `expressionA` را روی ورودی اعمال می‌کند و سپس `expressionB` برای هر یک از خروجی‌های `expressionA` به‌طور مکرر اجرا می‌شود.

به ورودی یک عبارت می‌توان به‌صراحت با `.` اشاره کرد.
عبارتی که `1` را به ورودی خود اضافه می‌کند این‌طور نوشته می‌شود: `. + 1` (یا `1 + .`).

## `jq` (برنامه) در برابر `jq` (زبان)

`jq` برنامه‌ای است که می‌توانید آن را به شکل بسته روی سیستم‌عامل‌های گوناگون نصب کنید، یا از سورس بسازید (با زبان C نوشته شده است).
چند [گزینه‌ی خط فرمان][cli-options] مفید دارد و بسیار سریع است.

برنامه‌ی `jq` همچنین یک _زبان_ را پیاده‌سازی می‌کند که دستکاری داده‌های ورودی را با هر پیچیدگی‌ای ممکن می‌سازد.

این مسیر Exercism روی زبان تمرکز خواهد کرد.
استفاده از برنامه‌ی `jq` را در تست‌ها خواهید دید.

## JSON

از [json.org][json]:

> JSON (JavaScript Object Notation) یک قالب سبک برای تبادل داده است.
> خواندن و نوشتن آن برای انسان آسان است.
> تجزیه و تولید آن برای ماشین آسان است.
> این قالب بر پایه‌ی زیرمجموعه‌ای از استاندارد ECMA-262 ویرایش سوم، دسامبر ۱۹۹۹، از زبان برنامه‌نویسی JavaScript بنا شده است.
> JSON قالبی متنی است که کاملاً مستقل از زبان است، اما از قراردادهایی استفاده می‌کند که برای برنامه‌نویسان خانواده‌ی زبان‌های C، از جمله C، C++، C#، Java، JavaScript، Perl، Python و بسیاری دیگر، آشناست.
> همین ویژگی‌ها JSON را به زبانی آرمانی برای تبادل داده تبدیل کرده است.

این مسیر درباره‌ی `jq` است، نه JSON.
فرض می‌کنیم با [نحوه‌ی نگارش و انواع داده‌ی JSON][wiki-json] آشنا هستید.
