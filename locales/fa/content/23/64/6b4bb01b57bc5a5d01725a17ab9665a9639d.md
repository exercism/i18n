# درباره

[`Attribute` در C#][attribute-concept] راهی فراهم می‌کند تا با تزئین یک اعلان، فراداده‌هایی به آن پیوند دهید: یک کلاس، یک متد، یک نوع شمارشی، یک فیلد، یک خاصیت، یا هر اعلان پشتیبانی‌شده‌ی دیگر.

می‌توانید [یک ویژگی][attribute] را با قرار دادن آن میان کروشه‌های `[]` پیش از اعلان، به آن اعمال کنید. مثال زیر هم از یک `ClassAttribute` و هم از یک `FieldAttribute` استفاده می‌کند:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

فراداده‌ی اعلانی تنها اطلاعات ساخت‌یافته‌ی بیشتری را به کد پیوند می‌زند و رفتار آن را تغییر نمی‌دهد، اما بخش‌های دیگر کد از این فراداده استفاده می‌کنند تا رفتار هدفش را تغییر دهند یا برخی از قابلیت‌های آن را اضافه، تغییر، حذف یا محدود کنند.

چندین ویژگی از پیش تعریف‌شده وجود دارد، مانند `Flags`، `Obsolete` و `Conditional`. توجه کنید که نام کامل [ویژگی `Flags`][flags-attribute] در واقع `FlagsAttribute` است، اما هنگام استفاده از این ویژگی می‌توان پسوند `Attribute` را حذف کرد.

چهار ویژگی از پیش تعریف‌شده‌ی زیر به‌طور مرتب استفاده می‌شوند:

- `[Flags]`: در فضای‌نام System از پیش تعریف شده است. نشان می‌دهد که آن نوع شمارشی هم از عملیات بیتی و هم از متد `Enum.HasFlag()` پشتیبانی می‌کند؛ به‌علاوه، `ToString` همه‌ی پرچم‌ها را نمایش می‌دهد: [مثالی را ببینید][flags-example].
- `[Obsolete]`: در فضای‌نام System از پیش تعریف شده است. امکان افزودن پیامی درباره‌ی دلیل منسوخ بودن کد را فراهم می‌کند و می‌توان از آن برای نمایش هشدارها یا خطاهای کامپایلر استفاده کرد.
- `[Conditional]`: در فضای‌نام System.Diagnostics از پیش تعریف شده است. امکان حذف برخی فراخوانی‌های متد را در زمان کامپایل و برای مقاصد Debug (عیب‌یابی) فراهم می‌کند.
- `[CallerMemberName]`: در فضای‌نام System.Runtime.CompilerServices از پیش تعریف شده است. به یک متد امکان می‌دهد اطلاعاتی درباره‌ی فراخوان‌کننده‌ی خود به دست آورد.
