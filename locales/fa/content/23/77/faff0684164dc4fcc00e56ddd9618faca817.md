# مقدمه

## مقادیر پیش‌فرض پارامتر

[مقادیر پیش‌فرض پارامتر][default-parameter-values] را می‌توان برای هر یک از پارامترهای یک تابع تعیین کرد؛ به این شکل که در فهرست پارامترها و پس از تعیین نوع پارامتر، مقداری را به آن پارامتر نسبت می‌دهید. وقتی مقدار پیش‌فرضی برای پارامتری تعیین شده باشد، فراخوانی‌کننده‌ی تابع می‌تواند هنگام فراخوانی آن پارامتر را حذف کند و در عوض مقدار پیش‌فرض به کار می‌رود.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## پارامترهای متغیر

[_پارامترهای متغیر_][variadic-parameters] در Swift این امکان را می‌دهند که صفر یا چند مقدار از یک نوع یکسان به یک پارامتر واحد در تابع فرستاده شود. این کار با افزودن `...` به نوع پارامتر مشخص می‌شود.

این مقادیر به‌طور خودکار در یک آرایه گروه‌بندی می‌شوند؛ آرایه‌ای که عناصر آن از همان نوعِ پارامتر متغیر هستند.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

توجه کنید که Swift هنگام استفاده از پارامترهای متغیر یک محدودیت دارد.
اگر تابعی در تعریف خود پارامترهایی بعد از پارامتر متغیر داشته باشد، نخستین پارامتری که بعد از پارامتر متغیر می‌آید _باید_ یک «برچسب آرگومان» داشته باشد.

## پارامترهای in-out

در بدنه‌ی یک تابع، با پارامترها مانند ثابت رفتار می‌شود، نه مانند متغیر؛ تلاش برای تغییر مقدار یک پارامتر، خطای زمان کامپایل ایجاد می‌کند.
اگر تابعی بخواهد مقدار یک پارامتر را تغییر دهد، باید از [_پارامترهای in-out_][in-out-parameters] استفاده کند تا این تغییرپذیری را صریح مشخص کند.

برای استفاده از پارامترهای in-out، برنامه‌نویس باید سه نکته را رعایت کند:

1. تعریف تابع باید پارامترهای in-out را به‌صراحت مشخص کند؛ به این شکل که در نوع پارامتر، «کلیدواژه»ی `inout` را بین `:` و نام نوع بنویسید.
2. مقداری که به پارامتر in-out فرستاده می‌شود باید به‌عنوان یک متغیر اعلام شده باشد، نه به‌عنوان یک ثابت. به همین شکل، نمی‌تواند مقداری باشد که مستقیماً در کد نوشته شده است.
3. در فراخوانی تابع، پیش از نام متغیر باید یک `&` بیاید تا صریحاً به‌عنوان قابل‌تغییر علامت‌گذاری شود.

وقتی این کارها انجام شد، تابع یک نسخه‌ی داخلی از پارامتر in-out می‌سازد، آن را مطابق آنچه در بدنه‌ی تابع گفته شده تغییر می‌دهد و سپس هنگام بازگشت تابع، مقدار تغییر‌یافته را دوباره در همان متغیری کپی می‌کند که هنگام فراخوانی فرستاده شده بود.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
درباره‌ی پارامترهای in-out، چند قاعده‌ی دیگر هم وجود دارد که بهتر است از آن‌ها آگاه باشید.

1  درون تابعی که پارامتر in-out دارد، اجازه ندارید به متغیری که به‌عنوان پارامتر in-out فرستاده شده ارجاع دهید.
2. یک متغیر را نمی‌توان در همان تابع به‌عنوان چند پارامتر in-out فرستاد.
   برای نمونه، `inoutFunc(&mutVar, &mutVar)` خطای کامپایلر ایجاد می‌کند.
~~~~

## توابع تودرتو

در Swift می‌توانید [توابعی را درون توابع دیگر][nested-functions] تعریف کنید.
به این‌ها **تابع تودرتو** می‌گویند.

معمولاً از توابع تودرتو به‌عنوان توابع کمکی خصوصی استفاده می‌شود که کارهای مشخصی را برای تابع دربرگیرنده انجام می‌دهند، بدون آنکه دامنه‌ی بیرونی را شلوغ کنند:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

توابع تودرتو مانند توابع معمولی رفتار می‌کنند، اما دیدپذیری آن‌ها به بدنه‌ی تابع دربرگیرنده محدود است.
