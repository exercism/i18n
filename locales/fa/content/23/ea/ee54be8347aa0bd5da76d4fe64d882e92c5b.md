# مقدمه

[آرایه‌ها][arrays-concept] متدهای داخلی‌ای برای تحلیل محتوای آرایه دارند.
بیشتر این متدها تابعی را به عنوان آرگومان می‌گیرند که «درست» یا «غلط» برمی‌گرداند.
به چنین تابعی [`predicate`][predicate_in_programming] می‌گویند.

این متدهای داخلی قرار است _به‌جای یک حلقه‌ی `for`_ یا متد داخلی `forEach` استفاده شوند:

نمونه‌ای از تحلیل با یک حلقه‌ی `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

نمونه‌ای از تحلیل با یک متد داخلی:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

چند متد داخلی مفید دیگر هم که برای تحلیل یک آرایه در دسترس‌اند، در ادامه آمده است. برای دیدن فهرست کامل متدهای آرایه، [MDN][mdn-array-methods] را ببینید.

## `includes`

> متد `includes()` تعیین می‌کند که آیا آرایه مقدار مشخصی را میان عناصر خود دارد یا نه و بر همین اساس «درست» یا «غلط» را برمی‌گرداند. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> متد `every()` بررسی می‌کند که آیا همه‌ی عناصر آرایه در آزمونی که تابع داده‌شده پیاده‌سازی کرده است قبول می‌شوند یا نه. یک «مقدار منطقی» برمی‌گرداند. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> متد `some()` بررسی می‌کند که آیا دست‌کم یک عنصر در آرایه در آزمونی که تابع داده‌شده پیاده‌سازی کرده است قبول می‌شود یا نه. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> متد `find()` مقدار نخستین عنصری را در آرایه‌ی داده‌شده برمی‌گرداند که تابع آزمون داده‌شده را برآورده کند. اگر هیچ مقداری تابع آزمون را برآورده نکند، `undefined` برگردانده می‌شود. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> متد `findIndex()` اندیس نخستین عنصری را در آرایه برمی‌گرداند که تابع آزمون داده‌شده را برآورده کند. در غیر این صورت، `-1` را برمی‌گرداند که نشان می‌دهد هیچ عنصری در آزمون قبول نشد. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
