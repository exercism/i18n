# آزمون

برای هر تمرین یک بار راه‌اندازی اولیه انجام می‌شود که ممکن است چند دقیقه طول بکشد:

```
npm install
```

دو پنجره‌ی ترمینال باز کنید و در ترمینال اول، فرایند ساخت را شروع کنید.

```
npm start
```

در ترمینال دوم، اجرای آزمون‌ها را شروع کنید.

```
npm test
```

همان‌طور که کد را ویرایش می‌کنید، این دو فرایند پیوسته کد را دوباره می‌سازند و آزمون‌ها را دوباره اجرا می‌کنند.
