# حسابرسی پرداخت‌های پایگاه داده

## بیان مسئله

شرکت ABC Corp از شما می‌خواهد که همه‌ی داده‌ها را از پایگاه داده‌ی SQL به یک [جدول Ballerina](https://ballerina.io/learn/by-example/table-syntax/) بارگذاری کنید تا پردازش‌های بعدی روی آن انجام شود. سپس باید با پرس‌وجو از جدول Ballerina بارگذاری‌شده، اسم کارمندانی را پیدا کنید که رکوردهای پرداخت‌شان از مبلغ داده‌شده (مثلاً ۳۰۰۰٫۰۰) بیشتر است.

**گام ۱:**

یک جدول Ballerina با ستون‌های زیر بسازید.

`payment_id` - عدد صحیح

`amount` - عدد اعشاری

`employee_name` - رشته

**گام ۲:**

جدول Ballerina بالا را با بارگذاری کل مجموعه‌داده‌ی متناظر در پایگاه داده‌ی H2 پر کنید. از `payment_id` به‌عنوان کلید اصلی جدول استفاده کنید.

**گام ۳**

با استفاده از عبارات پرس‌وجوی Ballerina، جدول Ballerina را پرس‌وجو کنید تا اسم کارمندانی را پیدا کنید که رکوردهای پرداخت‌شان از مبلغ داده‌شده بیشتر است. نتیجه را بر اساس اسم کارمند به ترتیب صعودی مرتب کنید. پیش از برگرداندن نتیجه، اسم‌های تکراری را از آن حذف کنید.

> توجه: استفاده از جدول Ballerina برای پیاده‌سازی راه‌حل الزامی است.

## جزئیات پایگاه داده

برای این مسئله از پایگاه داده‌ی H2 ارائه‌شده استفاده کنید.

> فایل پایگاه داده‌ی نمونه `gofigure.mv.db` است و اسم پایگاه داده `gofigure` است. این فایل در پوشه‌ی `db` قرار دارد.

جدول‌های زیر از قبل در پایگاه داده‌ی نمونه‌ی H2 همراه با مقداری داده‌ی نمونه وجود دارند. اسم ستون‌ها و نوع داده‌ها در ادامه آمده است.

**اسم جدول** : `Employee`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحیح، کلید اصلی با افزایش خودکار       |
| `name`            | رشته        |
| `city`            | رشته        |
| `department`      | رشته        |
| `age`             | عدد صحیح        |

**اسم جدول**: `Payment`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحیح، کلید اصلی با افزایش خودکار       |
| `date`            | تاریخ        |
| `amount`          | عدد اعشاری        |
| `employee_id`     | عدد صحیح        |
| `reason`          | رشته        |

* فایل پایگاه داده `gofigure.mv.db` است. از URL مربوط به JDBC به شکل `jdbc:h2:file:/path/to/db/file` استفاده کنید
* اسم کاربر: `root`
* گذرواژه: `root`

## محدودیت‌ها

* برای اعتبارسنجی پرس‌وجوها و نمونه‌ی Ballerina، از فایل پایگاه داده‌ی H2 که در پوشه‌ی `db` ارائه شده است استفاده کنید
* برای افزودن درایور پایگاه داده‌ی H2 به‌عنوان یک وابستگی پلتفرم در `Ballerina.toml`، از روش پارامترهای وابستگی maven استفاده کنید

## محیط Test

* می‌توانید Test را با `bal test` اجرا کنید؛ این دستور Test را روی پایگاه داده‌ی نمونه‌ی داده‌شده اجرا می‌کند.

## راهنمایی‌ها

* برای کار با پایگاه داده از ماژول [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) استفاده کنید
* برای گام‌های افزودن درایور JDBC به‌عنوان یک وابستگی، به بخش [پیش‌نیاز](https://lib.ballerina.io/ballerinax/java.jdbc/latest) مراجعه کنید
* برای پرس‌وجو گرفتن داده از پایگاه داده، از متد remote با نام [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) استفاده کنید
* به نمونه‌ی [پرس‌وجوی ساده](https://ballerina.io/learn/by-example/mysql-query-operation) نگاهی بیندازید
* به نمونه‌ی [نحوه‌ی نگارش جدول](https://ballerina.io/learn/by-example/table) نگاهی بیندازید
* برای یافتن داده‌های موردنیاز از جدول Ballerina، از [پرس‌وجو از جدول‌ها](https://ballerina.io/learn/by-example/querying-tables) استفاده کنید
