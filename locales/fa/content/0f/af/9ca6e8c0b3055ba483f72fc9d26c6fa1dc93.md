# راهنمایی‌ها

## 1. چاپ یک نشان برای کارمند

- برای ساختن رشته‌های توصیفی می‌توانید از [درج متغیر در رشته][string-interpolation] استفاده کنید.
- یک [متد داخلی برای تبدیل رشته به حروف بزرگ][to-upper-case] وجود دارد.

## 2. چاپ یک نشان برای کارمند جدید

- پیش از استفاده، باید بررسی کنید که آیا `ID` برابر `null` است یا نه.
- می‌توانید از [عملگرهای برابری][equality-operators] برای مقایسه‌ی مقدار با `null` استفاده کنید

## 3. چاپ یک نشان برای مالک

- پیش از استفاده، باید بررسی کنید که آیا واحد برابر `null` است یا نه.
- می‌توانید از [عملگرهای برابری][equality-operators] برای مقایسه‌ی مقدار با `null` استفاده کنید
