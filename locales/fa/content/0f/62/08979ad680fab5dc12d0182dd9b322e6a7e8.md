# نکات تکمیلی دستورالعمل

## قالب ورودی

پارامتر `board` که نماینده‌ی تخته‌ی بازی است، در قالب آرایه‌ای از رشته‌ها ارائه می‌شود.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

هر نویسه از یک رشته نماینده‌ی یک خانه است.
مقادیر معتبر برای یک خانه عبارت‌اند از:

- ` ` یک فاصله که متناظر با یک خانه‌ی خالی است
- `B` خانه‌ای که متعلق به بازیکن سیاه است
- `W` خانه‌ای که متعلق به بازیکن سفید است

## قالب‌های خروجی

انتظار می‌رود تابع `getTerritory` شیءای با ۲ ویژگی برگرداند:

- `owner` مالک قلمرو (`NONE`، `BLACK` یا `WHITE`)
- `territory` آرایه‌ای از مختصات که هر خانه در قلمرو را نمایش می‌دهد.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

انتظار می‌رود تابع `getTerritories` شیءای با ۳ ویژگی برگرداند:

- `territoryBlack` آرایه‌ای از مختصات که قلمروهای متعلق به بازیکن `BLACK` را نمایش می‌دهد
- `territoryWhite` آرایه‌ای از مختصات که قلمروهای متعلق به بازیکن `WHITE` را نمایش می‌دهد
- `territoryNone` آرایه‌ای از مختصات که قلمروهای متعلق به هیچ‌یک از دو بازیکن را نمایش می‌دهد

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
