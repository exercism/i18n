# نصب

## کدام `awk` را دارم؟

مسیر AWK در Exercism از `gawk` استفاده می‌کند، که همان پیاده‌سازی GNU از AWK است.
ممکن است از قبل آن را داشته باشید؛ برای بررسی، این دستور را اجرا کنید:
```sh
awk --version
```

اگر خروجی این باشد:

* چیزی شبیه به `GNU Awk 5.1.0 ...`
    - از قبل GNU awk را دارید و می‌توانید تمرین‌ها را ادامه دهید.

* چیزی شبیه به `awk version 20200816`
    - این `nawk` است، که با نام‌های BWK awk (به نام برایان کرنیگان) یا «one true awk» هم شناخته می‌شود.
    - همین است که همراه MacOS و سیستم‌های BSD ارائه می‌شود.
    - برای دستورهای نصب، پایین‌تر را بخوانید.

* خطای `awk: not an option: --version`
    - احتمالاً `mawk` دارید.
    - برای اطمینان این را اجرا کنید: `awk -W version` که ممکن است `mawk 1.3.4 20200120` را برگرداند.
    - `mawk` یک پیاده‌سازی `awk` بسیار خوب و سریع است، اما بعضی از ویژگی‌های مخصوص `gawk` را که در این مسیر از آن‌ها استفاده می‌کنیم ندارد.
    - برای دستورهای نصب، پایین‌تر را بخوانید.

* خطای `awk: unrecognized option: version` و پس از آن `BusyBox v1.35.0 ...`
    - ممکن است از Alpine Linux استفاده می‌کنید.
    - برای دستورهای نصب، پایین‌تر را بخوانید.

* خطای «command not found»
    - در این صورت یا `PATH` شما به هم ریخته است یا هنوز `awk` را نصب نکرده‌اید.
    - برای دستورهای نصب، پایین‌تر را بخوانید.

### لینوکس

بسته به مدیر بسته‌ی توزیع‌تان فرق می‌کند. معمولاً:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
ممکن است لازم باشد برای اجرای دستور مناسب از `sudo` استفاده کنید.

### MacOS

[Homebrew][brew] کارتان را راه می‌اندازد. پیوند را دنبال کنید تا آن را نصب کنید و بعد این را اجرا کنید:
```sh
brew install gawk
```

### ویندوز

برای [WSL][wsl]، دستورهای بخش لینوکس را در بالا ببینید.
برای cygwin، بسته‌ی `gawk` را نصب کنید.

### کامپایل از کد منبع

اگر اهل ماجراجویی هستید، دستورها [در دفترچه‌ی `gawk` موجود است][build].
