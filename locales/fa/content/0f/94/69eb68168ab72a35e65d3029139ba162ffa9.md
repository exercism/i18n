# مقدمه

«تابع» بلوکی از کد سازمان‌یافته و قابل‌استفاده‌ی مجدد است که برای انجام کاری به کار می‌رود.
در JavaScript چندین روش برای تعریف تابع وجود دارد.
در اینجا «اعلان تابع» و «عبارت تابع» را بررسی می‌کنیم.
امکان‌های دیگری مانند [توابع پیکانی][concept-arrow-functions] در مفاهیم دیگر بررسی می‌شوند.

## اعلان تابع

روش استاندارد تعریف تابع در JavaScript، اعلان تابع است که به آن تعریف تابع یا دستور تابع هم می‌گویند.

این ساختار شامل کلیدواژه‌ی `function`، اسم تابع و فهرستی از پارامترهاست که با ویرگول از هم جدا شده‌اند و داخل پرانتز قرار می‌گیرند.
پس از آن بدنه‌ی تابع می‌آید (مجموعه‌ای از دستورها که مشخص می‌کند تابع چه کاری انجام می‌دهد) که داخل آکولاد قرار گرفته است.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

در JavaScript، تابع با نوشتن اسم تابع و سپس پرانتزهایی که آرگومان‌ها را در خود دارند، فراخوانی (صدا زده) می‌شود.

```javascript
someName(arg1, arg2, arg3);
```

## پارامترها

هنگام کار با پارامترها در بدنه‌ی تابع، مراقب «اثرهای جانبی» احتمالی باشید.

- مقدارهای [انواع داده‌های اولیه][mdn-primitives] «تغییرناپذیر» هستند.
  مقدار اصلی هرگز از آنچه در بدنه‌ی تابع بر سر آرگومان می‌آید تأثیر نمی‌گیرد.
- برای همه‌ی مقدارهای دیگر (شیءها، آرایه‌ها، توابع)، انتساب دوباره بر مقدار اصلی تأثیری ندارد.
  اما اگر چنین آرگومانی را تغییر بدهید (مثلاً کلیدی به یک شیء اضافه کنید)، مقدار اصلی‌ای هم که پاس داده شده بود تغییر می‌کند.

به‌طور پیش‌فرض، همه‌ی پارامترهایی که در اعلان تابع تعریف می‌شوند در JavaScript اختیاری‌اند.
اگر آرگومان‌های کمتری از تعداد پارامترها بدهید، آرگومان‌های جاافتاده درون تابع `undefined` خواهند بود؛ به [Null و Undefined][concept-null-undefined] نگاه کنید.
در بسیاری از موارد، منطقی است که مقدار پیش‌فرض مناسب‌تری به‌جای `undefined` در نظر بگیریم.
این کار با مشخص کردن «پارامترهای پیش‌فرض» به‌طور مستقیم در تعریف تابع انجام می‌شود.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## دستور `return`

یک دستور `return` اجرای تابع را پایان می‌دهد و مقداری را تعیین می‌کند که باید به فراخواننده‌ی تابع برگردانده شود. یک تابع می‌تواند چندین دستور `return` داشته باشد.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

مقدار بازگشتی یک تابع را می‌توان در یک متغیر ذخیره کرد.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

نتیجه‌ی تابعی که مقداری را `return` نمی‌کند یا دستور `return` ندارد، `undefined` است.
در JavaScript هیچ `return` ضمنی وجود ندارد.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

در JavaScript فقط می‌توانید دقیقاً یک مقدار را برگردانید.
اگر می‌خواهید اطلاعات بیشتری منتقل کنید، باید ابتدا آن‌ها را در یک موجودیت واحد ترکیب کنید، معمولاً یک [شیء][concept-objects] یا یک [آرایه][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## عبارت تابع

اعلان تابع یک دستور مستقل است.
اما گاهی کمک‌کننده است که تابع را به‌عنوان بخشی از یک عبارت دیگر تعریف کنید، مثلاً در یک انتساب، به‌عنوان پارامتر یک تابع ([تابع فراخوان][concept-callbacks]) یا به‌عنوان مقداری در یک [شیء][concept-objects].
این کار با یک عبارت تابع انجام می‌شود.
نحوه‌ی نگارش آن مانند اعلان تابع است، فقط با این تفاوت که می‌توان اسم تابع را حذف کرد تا یک «تابع بی‌نام» ساخت.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
