# راهنمایی‌ها

## کلیات

- مستندات [عملگرهای مقایسه][comparison-operators] را بخوانید
- مستندات [مرتب‌سازی فهرست‌ها][list-sort] را بخوانید
- به یاد داشته باشید که چطور می‌توانید [به رکوردها دسترسی پیدا کنید یا با آن‌ها تطبیق الگو انجام دهید][records]

## 1. مقایسه‌ی سطح‌های قدرت

- از [عملگر `(>)`][greater] استفاده کنید

## 2. یافتن بالاترین قدرت

- از [تابع `max`][max] استفاده کنید

## 3. مرتب کردن کارت‌ها

- از [تابع `List.sortBy`][sort-by] استفاده کنید

## 4. اول خنک‌ترین کارت‌ها

- از توابع [`List.sortBy`][sort-by] یا [`List.sortWith`][sort-with] استفاده کنید
- می‌توانید برای مرتب‌سازی‌های سلسله‌مراتبی از تاپل‌ها استفاده کنید

## 5. قدرت درخشان

- می‌توانید صریحاً یک ترتیب تعریف کنید یا از [تابع `compare`][compare] همراه با یک مقدار مشخص استفاده کنید
- می‌توانید برای مرتب‌سازی‌های سلسله‌مراتبی از تاپل‌ها استفاده کنید

## 6. شرط‌بندی کنید

- در `expectedWinner` از `compareShinyPower` استفاده کنید
- از یک `case` برای [تطبیق الگو با ترتیب][pattern-match] استفاده کنید
