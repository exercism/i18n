# مقدمه

از یک عبارت `if/elif/else` می‌توان برای اجرای شرطی منطق استفاده کرد. F# روش دیگری هم برای اجرای شرطی منطق دارد که قدرتمندتر است: تطبیق الگو. با تطبیق الگو می‌توان یک مقدار را در برابر یک یا چند _الگو_ آزمود. نمونه‌ای از چنین الگویی، _الگوی ثابت_ است که یک مقدار را با یک ثابت (مثلاً `1` یا `"hello"`) تطبیق می‌دهد.

در F#، تطبیق الگو با کلیدواژه‌ی `match` انجام می‌شود:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

اگرچه ممکن است این شبیه دستورهای `switch` در زبان‌های دیگر به نظر برسد، تطبیق الگو زمانی به اوج توانایی خود می‌رسد که الگوهای دیگری هم به کار گرفته شوند. یکی از این الگوها _الگوی متغیر_ است که امکان ثبت یک مقدار را فراهم می‌کند:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

در برخی موارد ممکن است بخواهید شرط دیگری به یک الگو اضافه کنید. به این کار _نگهبان_ (بند نگهبان) می‌گویند که می‌توان آن را با کلیدواژه‌ی `when` اضافه کرد:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

در مثال بالا، همه‌ی ورودی‌های ممکن الگوی منطبق ندارند. کامپایلر این موضوع را تشخیص می‌دهد و یک هشدار نمایش می‌دهد. به این کار _بررسی جامعیت_ می‌گویند. برای رفع این هشدار، باید همه‌ی حالت‌ها پوشش داده شوند. برای این کار می‌توان از _الگوی عام_ استفاده کرد که الگویی است که با هر مقداری تطبیق می‌یابد:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

تطبیق الگو یک مقدار را از بالا به پایین با هر الگو می‌آزماید تا الگوی منطبق را پیدا کند و منطق مرتبط با آن الگو را اجرا کند. ترتیب الگوها مهم است!
