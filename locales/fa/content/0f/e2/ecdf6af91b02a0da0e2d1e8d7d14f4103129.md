# مقدمه

به یاد آورید که یک برنامه‌ی `jq` یک _زنجیره‌ی عبارات_ است.
**انتساب متغیر** از این قاعده پیروی می‌کند: یک _انتساب متغیر_ عبارتی است که به این شکل است:

```jq
... | expr as $varname | ...
```

## خروجی فیلتر همان ورودی است

مانند _عبارت همانی_ `.`، خروجی _انتساب متغیر_ همان ورودی آن است.
تنظیم مقدار متغیر یک اثر جانبی است.

مثال، نشان می‌دهد که `.` بعد از انتساب همان ورودی اولیه است:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## محدوده‌ی متغیر

محدوده‌ی متغیر «واژگانی» است؛ متغیر برای بقیه‌ی زنجیره در محدوده خواهد بود.
متغیرهای تعریف‌شده در توابع (بعداً به توابع می‌رسیم) برای تابع «محلی» هستند.

## اسم متغیر

متغیر باید با `$` شروع شود.
بقیه‌ی اسم متغیر یک **شناسه** است: با یک حرف یا زیرخط شروع می‌شود و پس از آن حروف، اعداد یا زیرخط می‌آید.

## انتساب ساختارشکن

از کتابچه:

> چندین متغیر را می‌توان با یک عبارت `as` و با ارائه‌ی الگویی که _با ساختار ورودی مطابقت دارد_ اعلام کرد (به این کار «ساختارشکنی» می‌گویند).

مثال‌ها:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

تطبیق اسم متغیر با _کلید شیء_ یک میانبر ارائه می‌دهد:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## ثابت‌ها

همان‌طور که در مثال بالا نشان داده شد، متغیرها برای ذخیره‌ی ثابت‌ها مفید هستند.
بهتر است به ثابت‌ها یک اسم بدهیم تا اینکه «اعداد جادویی» در کد ظاهر شوند.

## اغلب نیازی به متغیرها نیست

اغلب خواناتر است که متغیرها را حذف کنیم.

محاسبه‌ی میانگین یک فهرست از اعداد را در نظر بگیرید

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

در مقایسه با

```jq
[2, 4, 8, 7] | add / length
```

این یکی از قدرتمندترین جنبه‌های `jq` را برجسته می‌کند: ورودی یک فیلتر به _هر_ زیرعبارت ارائه می‌شود:

- آرایه‌ی ورودی `[2,4,8,7]` به `add` پاس داده می‌شود (که اعداد را با اعمال عملگر `+` روی همه‌ی عنصرها جمع می‌کند)
- _به‌طور موازی_، `[2,4,8,7]` نیز به `length` پاس داده می‌شود
- وقتی این زیرعبارت‌ها کامل شدند، نتایج آن‌ها تقسیم می‌شوند و مقدار میانگین اعداد را در آرایه‌ی ورودی برمی‌گردانند.
