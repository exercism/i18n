# دستورالعمل‌ها

در این تمرین، راهی را پیاده‌سازی می‌کنید که با آن بتوانید امتیازهای برتر محبوب‌ترین بازی سالن بازی محلی‌تان را پیگیری کنید.

باید ۵ تابع را پیاده‌سازی کنید که بیشترشان به دستکاری شیئی مربوط می‌شوند که امتیازهای برتر را نگه می‌دارد.

## 1. یک تخته امتیازهای برتر جدید بسازید

تابعی به اسم `createScoreBoard` بسازید که شیئی را می‌سازد و نقش تخته امتیازهای برتر را ایفا می‌کند.
کلیدهای این شیء اسم بازیکنان خواهند بود و مقدارها امتیاز آنان.
برای اهداف Test، می‌خواهید یک ورودی را مستقیماً در شیء بگنجانید.
این ورودی اولیه باید از `The Best Ever` به عنوان اسم بازیکن و `1000000` به عنوان امتیاز تشکیل شده باشد.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. بازیکنان را به تخته امتیاز اضافه کنید

برای افزودن بازیکن به تخته امتیازهای برتر، تابع `addPlayer` را تعریف کنید.
این تابع ۳ پارامتر می‌پذیرد:

- پارامتر اول یک شیء تخته امتیاز موجود است.
- پارامتر دوم اسم بازیکن به صورت رشته است.
- پارامتر سوم امتیاز به صورت عدد است.

تابع پس از افزودن بازیکن جدید، همان شیء تخته امتیازی را که به آن پاس داده شده بود برمی‌گرداند.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. بازیکنان را از تخته امتیاز حذف کنید

اگر بازیکنان قوانین سالن بازی را زیر پا بگذارند، به صورت دستی از تخته امتیازهای برتر حذف می‌شوند.
تابع `removePlayer` را تعریف کنید که ۲ پارامتر می‌گیرد:

- پارامتر اول یک شیء تخته امتیاز موجود است.
- پارامتر دوم اسم بازیکن به صورت رشته است.

این تابع باید ورودی مربوط به بازیکن داده‌شده را از تخته حذف کند و سپس تخته را برگرداند.
اگر بازیکن از ابتدا روی تخته نبود، نباید هیچ اتفاقی برای تخته بیفتد.
باید همان‌طور که هست برگردانده شود.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. امتیاز یک بازیکن را افزایش دهید

اگر بازیکنی بازی دیگری را در سالن بازی تمام کند، مقدار مشخصی امتیاز به امتیاز قبلی روی تخته اضافه می‌شود.
تابع `updateScore` را پیاده‌سازی کنید که ۳ پارامتر می‌گیرد:

- پارامتر اول یک شیء تخته امتیاز موجود است.
- پارامتر دوم اسم بازیکنی است که امتیازش باید افزایش یابد.
- پارامتر سوم امتیازی است که می‌خواهید به امتیاز برتر ذخیره‌شده **اضافه** کنید.

تابع باید پس از انجام به‌روزرسانی، تخته امتیاز را برگرداند.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. امتیازهای پاداش دوشنبه را اعمال کنید

سالن بازی روزهای دوشنبه یک تخته امتیاز جداگانه دارد.
در پایان روز، هر بازیکنی که در آن تخته فهرست شده است، ۱۰۰ امتیاز اضافه می‌گیرد.

تابع `applyMondayBonus` را پیاده‌سازی کنید که یک تخته امتیاز می‌پذیرد.
این تابع امتیازهای پاداش را برای هر بازیکنی که در آن تخته فهرست شده است اضافه می‌کند.
سپس تخته برگردانده می‌شود.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
