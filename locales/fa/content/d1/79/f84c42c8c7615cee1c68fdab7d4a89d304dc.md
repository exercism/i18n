# درباره

ماژول `gleam/order` در کتابخانه‌ی استاندارد Gleam شامل نوع `Order` است که برای مقایسه‌ی مقدارها به کار می‌رود.

تعریف `Order` به این شکل است:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

این نوع سه حالت دارد و هر کدام برای نشان دادن رابطه‌ی بین یک مقدار و مقداری دیگر به کار می‌رود:

- `Gt` - مقدار _بزرگ‌تر_ از مقدار دیگر است.
- `Eq` - مقدار _برابر_ مقدار دیگر است.
- `Lt` - مقدار _کوچک‌تر_ از مقدار دیگر است.

اگر بتوان یک نوع داده را بر اساس اندازه مقایسه کرد، معمولاً ماژول یک تابع `compare` تعریف می‌کند که یک مقدار `Order` برمی‌گرداند. برای مثال، `gleam/float` و `gleam/int` توابع `compare` را تعریف می‌کنند که به ترتیب روی اعداد اعشاری و اعداد صحیح کار می‌کنند.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

توابع مرتب‌سازی مانند `list.sort` معمولاً تابعی می‌گیرند که یک مقدار `Order` برمی‌گرداند و به فراخوان اجازه می‌دهند تعیین کند که لیست چگونه مرتب شود.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
