# مقدمه

در Common Lisp یک تابع می‌تواند پارامترهای نام‌دار داشته باشد (که به آن‌ها «پارامترهای کلیدواژه» می‌گویند).
این پارامترها در فهرست لامبدا با کلیدواژه‌ی فهرست لامبدای `&key` مشخص می‌شوند.
پارامترهای کلیدواژه پارامترهای اجباری نیستند.
مانند پارامترهای اختیاری، می‌توان برای آن‌ها مقدار پیش‌فرض تعیین کرد و نمادهایی به وضعیت «ارائه‌شده یا ارائه‌نشده»شان گره زد.

هنگام فراخوانی تابعی که پارامترهای کلیدواژه دارد، اسم پارامتر به‌صورت یک کلیدواژه پیش از مقدار پارامتر می‌آید.
فراخوان تابع می‌تواند پارامترهای کلیدواژه را به هر ترتیبی مشخص کند.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

هنگام ترکیب پارامترهای اختیاری و کلیدواژه باید دقت کرد، چون ممکن است پارامترهای اختیاری اسم کلیدواژه و آرگومان آن را مصرف کنند:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
