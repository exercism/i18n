# مقدمه

لیست‌ها بخشی توکار از خود زبان Elixir هستند. آن‌ها یک نوع داده‌ی پایه در نظر گرفته می‌شوند که با کروشه نشان داده می‌شود. لیست می‌تواند خالی باشد یا هر تعداد عنصر از هر نوعی را در خود جای دهد. برای مثال:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir لیست‌ها را به‌صورت لیست پیوندی پیاده‌سازی می‌کند که در آن هر گره دو مقدار را ذخیره می‌کند: عنصر اول و لیست دیگری که همه‌ی عناصر باقی‌مانده را در خود دارد. به عنصر اول لیست «سر» و به لیست باقی‌مانده‌ی عناصر «دم» گفته می‌شود. می‌توانیم از این نماد در کد استفاده کنیم:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

می‌توانیم از نماد _`[head | tail]`_ برای افزودن عنصر به ابتدای لیست استفاده کنیم:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

برای کار با لیست‌ها چندین تابع در ماژول `Kernel` وجود دارد و کل ماژول `List` هم در دسترس است.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
