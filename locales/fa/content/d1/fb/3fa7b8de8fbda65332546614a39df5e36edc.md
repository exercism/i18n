# پیوست دستورالعمل‌ها

## راهنمایی‌ها

شما باید تابع `responseFor` را پیاده‌سازی کنید که پاسخ Bob را برای یک ورودی مشخص برمی‌گرداند. اگر درباره‌ی نوع‌ها مطمئن نیستید، می‌توانید از امضای ارائه‌شده استفاده کنید، اما نگذارید خلاقیت شما را محدود کند:

```haskell
responseFor :: String -> String
```

برای حل این تمرین می‌توانید درباره‌ی این مورد مطالعه کنید:

- [«گاردها»][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

این تمرین با داده‌های متنی کار می‌کند. به دلایل تاریخی، نوع `String` در Haskell با `[Char]`، یعنی لیستی از کاراکترها، هم‌معنی است. برای پردازش کارآمدتر داده‌های متنی، می‌توان از نوع `Text` استفاده کرد.

به‌عنوان یک افزونه‌ی اختیاری برای این تمرین، می‌توانید:

- درباره‌ی [«نوع‌های رشته»](https://haskell-lang.org/tutorial/string-types) در Haskell بخوانید.
- `- text` را به فهرست وابستگی‌های خودتان در `package.yaml` اضافه کنید.
- `Data.Text` را [به روش زیر](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) وارد کنید:

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- اکنون می‌توانید مثلاً `responseFor :: Text -> Text` بنویسید و به ترکیب‌کننده‌های `Data.Text` مثلاً با `T.isSuffixOf` ارجاع دهید.
- مستندات [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) را ببینید،
- سپس می‌توانید همه‌ی موارد `String` را در `Bob.hs` با `Text` جایگزین کنید:

    ```haskell
    responseFor :: Text -> Text
    ```

این بخش کاملاً اختیاری است.
