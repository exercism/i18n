# مقدمه

بسیاری از زبان‌ها روشی مثل `null` یا `none` دارند تا مقداری را که وجود ندارد نشان دهند. چون جولیا برای کار با حجم انبوهی از داده‌ها (که اغلب به‌هم‌ریخته‌اند) طراحی شده است، چندین شکل مختلف از نبودِ مقدار دارد.

هدف کلی این است که مقادیر گمشده یا مشکوک را همان لحظه که با آن‌ها روبه‌رو می‌شویم علامت بزنیم و سپس بدون بروز استثنا به کار ادامه دهیم.

## `nothing`

اگر مقداری واقعاً وجود نداشته باشد، با `nothing` نمایش داده می‌شود. این احتمالاً نزدیک‌ترین حالت به کاری است که C (با `NULL`) یا پایتون (با `None`) انجام می‌دهد.

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

پس `nothing` یک مقدار یگانه از نوع `Nothing` است و می‌توانیم آن را بررسی کنیم.

یکی از کاربردهای رایج `nothing` این است که به‌عنوان مقدار بازگشتی (یا نبودِ مقدار بازگشتی) توابعی به کار می‌رود که فقط برای عوارض جانبی خود استفاده می‌شوند (چاپ کردن، پیکربندی شبکه و مواردی از این دست).

## `missing`

در موقعیت‌هایی که مقداری در تئوری وجود دارد اما نمی‌دانیم چیست، از `missing` استفاده می‌شود. برای مثال، هنگام شمارش خودروهایی که در جاده‌ای در حال حرکت‌اند، ممکن است ناظران انسانی به استراحت نیاز پیدا کنند یا حسگرهای خودکار از کار بیفتند، اما ترافیک همچنان در جریان است.

بنابراین `missing` در واقع جای خالی را نگه می‌دارد و به انسان‌ها هشدار می‌دهد که باید تصمیم بگیرند با این شکاف در داده‌ها چگونه رفتار کنند.

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

زبان‌های دیگری کم پیش می‌آید این ویژگی را به‌صورت داخلی داشته باشند، اما معادل‌های نزدیک آن `NA` در R یا `NULL` در SQL است.

عبارت‌ها معمولاً اگر مقادیر `missing` حضور داشته باشند، به‌صورت پیش‌فرض `missing` برمی‌گردانند.
اگر می‌خواهید این مقادیر نادیده گرفته شوند، از تابع `skipmissing()` استفاده کنید تا این موضوع را صریح بیان کنید:

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

چون `skipmissing` یک تکرارگر می‌سازد، اگر به یک بردار نیاز دارید آن را در `collect()` بپیچید.

گاهی جایگزین کردن مقادیر `missing` با یک مقدار پیش‌فرض مفید است.
ماکروی `@coalesce()` برای این کار به کار می‌آید، چون اولین مقدار غیر `missing` را برمی‌گرداند (یا اگر مقدار دیگری نباشد، `missing` را).

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

NaN که کوتاه‌شده‌ی Not a Number است، در موقعیت‌هایی که انتظار یک عدد می‌رود، وجود مشکلی در محاسبه را علامت می‌زند.

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

هر نوع محاسبه‌ای روی داده‌ای که شامل NaN باشد، نتیجه‌ی `NaN` می‌دهد.

در حال حاضر تابع ویژه‌ای برای حذف مقادیر `NaN` وجود ندارد، اما تابع استاندارد `filter()` این کار را به‌سادگی انجام می‌دهد.
فقط مقادیری که شرط داده‌شده برای آن‌ها `true` باشد، در آرایه‌ی نتیجه کپی می‌شوند:

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
