# مقدمه

## صف

کتابخانه‌ی استاندارد Gleam نوع `Queue` را در ماژول `gleam/queue` پیاده‌سازی می‌کند. این نوع شبیه به نوع `List` است، اما چند تفاوت مهم دارد:

- نوع `Queue` نحوه‌ی نگارشی ندارد که بتوان با آن «صف» ساخت یا روی آن تطبیق الگو انجام داد.
- می‌توان عنصرها را به‌شکل کارآمد از جلوی نوع `Queue` و از انتهای آن هم اضافه و هم حذف کرد، در حالی که نوع `List` فقط می‌تواند عنصرها را به‌شکل کارآمد از جلوی خودش اضافه و حذف کند.

بیشتر اوقات می‌خواهید از نوع `List` استفاده کنید، اما وقتی لازم است بتوانید از انتهای یک مجموعه هم عنصر اضافه و حذف کنید، نوع `Queue` گزینه‌ی خوبی است.

صف را می‌توان با استفاده از توابع `queue.new` و `queue.from_list` ساخت:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

عنصرها را می‌توان با استفاده از توابع `queue.push_front` و `queue.push_back` به صف اضافه کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

عنصرها را می‌توان با استفاده از توابع `queue.pop_front` و `queue.pop_back` از صف حذف کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

صف را می‌توان با استفاده از تابع `queue.to_list` به لیست تبدیل کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### برابری صف

به‌دلیل نحوه‌ی پیاده‌سازی صف‌ها، ممکن است دو صف با عنصرهای یکسان در ترتیب یکسان، بر اساس عملگر `==` که مقادیر را ساختاری مقایسه می‌کند، با هم برابر نباشند. برای مثال:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

اگر لازم است دو صف را از نظر برابری مقایسه کنید، می‌توانید از تابع `queue.is_logically_equal` استفاده کنید.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
