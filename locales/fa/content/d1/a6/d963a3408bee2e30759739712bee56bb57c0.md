# اجرای Testها

اگر `sbt` نصب شده باشد، می‌توانید Testها را از خط فرمان با این دستور اجرا کنید:

```bash
$ sbt test
```

توجه کنید که اجرای `sbt test` در هر بار کند خواهد بود، چون هر بار `sbt` را دوباره راه‌اندازی می‌کند.

`sbt` مثل یک shell کار می‌کند؛ بعد از اینکه راه‌اندازی شد، می‌توانید دستورها را درونش اجرا کنید.

برای مثال، می‌توانید از `sbt` استفاده کنید تا هر وقت فایل‌های منبع تغییر کردند، Testهای خود را دوباره اجرا کنید:
```bash
$ sbt
>~ test
```

توجه کنید که همه‌ی Testها غیرفعال شده‌اند و تنها اولین Test برای کار شما باقی مانده است.
برای ادامه، فقط کلیدواژه‌ی `pending` را از ابتدای هر مورد Test حذف کنید.

برای یادگیری بیشتر درباره‌ی `sbt` [اینجا](https://www.scala-sbt.org/) بروید.


Testها را می‌توان در محیط‌های توسعه‌ی یکپارچه‌ی زیر هم اجرا کرد:

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA با افزونه‌ی Scala](https://www.jetbrains.com/idea/)
