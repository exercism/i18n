# Case

[`case`][case] (که در زبان‌های دیگر اغلب با نام switch شناخته می‌شود) گونه‌ای از عبارت کنترلی است، مانند if-else.
`case` امکان زنجیره‌کردن چندین دستور if-else-if را می‌دهد، می‌تواند خوانایی بیشتری داشته باشد و ساختارهای قدرتمندی را ممکن می‌سازد.

یک `case` با کلیدواژه‌ی `case` تعریف می‌شود که پس از آن یک عبارت اختیاری می‌آید.
سپس برای هر مورد، کلیدواژه‌ی `when` به کار می‌رود که پس از آن عبارتی می‌آید که با عبارت `case` مقایسه می‌شود.
کلیدواژه‌ی `when` نباید نسبت به کلیدواژه‌ی `case` تو‌رفتگی داشته باشد.
پس از کلیدواژه‌ی `when`، کدی می‌آید که اگر عبارت `case` با عبارت `when` مطابقت داشته باشد باید اجرا شود.
`case` امکان یک دستور `else` اختیاری را می‌دهد که اگر هیچ مورد دیگری مطابقت نکند اجرا می‌شود.

عبارت `case` ارزیابی می‌شود و سپس با هر عبارت `when` مقایسه می‌شود.
مقایسه‌ی عبارت با استفاده از [عملگر شمول `case` (`===`)][case-subsumption] انجام می‌شود.

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## عملگر شمول `case` (`===`)

عملگر شمول `case` (`===`) کمی با عملگر برابری (`==`) تفاوت دارد.
این عملگر بررسی می‌کند که آیا سمت راست عضوی از مجموعه‌ای است که سمت چپ توصیف می‌کند یا نه.
این یعنی جای قرار گرفتن هر عملوند اهمیت دارد.
نحوه‌ی کارکرد آن به نوع سمت چپ بستگی دارد؛ برای نمونه، یک `Range` بررسی می‌کند که آیا سمت راست در آن بازه قرار دارد، یا یک `Object` بررسی می‌کند که آیا سمت راست نمونه‌ای از `Object` است.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` با چند عبارت

`case` امکان مطابقت با چندین عبارت را در یک `case` واحد می‌دهد، به‌طوری که هر مقدار ممکن با یک کاما از دیگری جدا می‌شود.
اگر هر یک از عبارت‌ها مطابقت داشته باشد، کد اجرا می‌شود.
این می‌تواند برای یک `case` واحد با چند مقدار ممکن مفید باشد.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## `case` با بازه‌ها

`case` همچنین می‌تواند بررسی کند که آیا یک مقدار در یک بازه قرار دارد یا نه.
این کار با قرار دادن یک بازه به‌عنوان عبارت `when` انجام می‌شود.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case` بدون عبارت `case`

وقتی نیازی به عبارت `case` نباشد، می‌توان آن را حذف کرد.
با این کار، هر عبارت `when` از نظر درست بودن ارزیابی می‌شود.
و باعث می‌شود مانند دستورهای if-else-if رفتار کنند.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## `when` تک‌خطی

Crystal امکان دستورهای `case` تک‌خطی را فراهم می‌کند.
این زمانی به کار می‌آید که یک دستور ساده و تک‌خطی دارید.
دستور تک‌خطی `when` به‌صورت `when <expression> then <statement>.` نوشته می‌شود.
و وقتی در دستور `else` به کار می‌رود، به‌صورت `else <statement>` نوشته می‌شود.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## `case` با نوع‌ها

`case` امکان مطابقت با نوع‌ها را فراهم می‌کند.
مقایسه از عملگر `is_a?` برای بررسی نوع متغیر استفاده می‌کند.
برای نمونه، این امکان می‌دهد که در یک نوع union برای هر نوع یک شاخه داشته باشیم.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## شیء ضمنی

`case` امکان استفاده از یک شیء ضمنی را فراهم می‌کند.
برای نمونه، این می‌تواند باعث شود یک عبارت `when` یک فراخوانی متد روی عبارت `case` باشد.
بسته به اینکه متد مقداری «درست» یا «غلط» برگرداند، `case` مطابقت داده می‌شود یا نه.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
