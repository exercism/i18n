# مقدمه

کار با داده‌های دودویی مفهومی مهم در هر زبانی است و Elixir نحوه‌ی نگارشی زیبا برای نوشتن، تطبیق دادن و ساختن داده‌های دودویی فراهم می‌کند.

در Elixir به داده‌های دودویی، نوع bitstring گفته می‌شود. _نوع_ داده‌ی دودویی (که نباید آن را با داده‌های دودویی به‌طور کلی اشتباه گرفت) شکل خاصی از bitstring است که در تمرینی دیگر به آن می‌پردازیم.

لیترال‌های bitstring با استفاده از فرم ویژه‌ی bitstring یعنی `<<>>` تعریف می‌شوند. هنگام تعریف یک لیترال bitstring، آن را در قالب قطعه‌هایی تعریف می‌کنید. هر قطعه یک مقدار و یک نوع دارد که با عملگر `::` از هم جدا می‌شوند. نوع مشخص می‌کند که برای رمزگذاری مقدار از چند بیت استفاده می‌شود. می‌توان نوع را کاملاً حذف کرد که در این صورت به‌طور پیش‌فرض یک مقدار عدد صحیح ۸ بیتی خواهد بود.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

نوشتن نوع به‌صورت `::1` شکل کوتاهِ نوشتن `::size(1)` است. اگر اندازه‌ی بیت از یک متغیر می‌آید، باید از نگارش طولانی‌تر استفاده کنید.

## دودویی

وقتی لیترال‌های عدد صحیح دودویی را می‌نویسیم، می‌توانیم آن‌ها را مستقیماً در مبنای ۲ بنویسیم و برای این کار پیشوند `0b` را به لیترال اضافه کنیم. توجه داشته باشید که در هر صورت هنگام چاپ در نتایج تست‌ها یا هنگام استفاده از iex، به‌صورت اعداد دهدهی نمایش داده می‌شوند.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## کوتاه‌سازی

اگر مقدار قطعه از ظرفیت نوع آن قطعه فراتر برود، از سمت چپ کوتاه می‌شود.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## افزودن از ابتدا و از انتها

می‌توانید با استفاده از فرم ویژه، هم به ابتدای یک bitstring موجود چیزی اضافه کنید و هم به انتهای آن. اگر bitstring موجود اندازه‌ی نامعلومی داشته باشد، باید از نوع `::bitstring` برای آن استفاده کنید.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## به‌هم‌چسباندن

می‌توانیم bitstring‌های ذخیره‌شده در متغیرها را با استفاده از فرم ویژه به هم بچسبانیم. هنگام به‌هم‌چسباندن دو bitstring با اندازه‌های نامعلوم، باید از نوع `::bitstring` استفاده کنید.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## تطبیق الگو

از تطبیق الگو هم می‌توان برای به دست آوردن مقادیر از فرم ویژه استفاده کرد. باید تعداد بیت‌های هر قطعه‌ای را که می‌خواهید بگیرید بدانید، با یک استثنا: می‌توان از نوع `::bitstring` برای تطبیق الگو روی یک bitstring با اندازه‌ی نامعلوم استفاده کرد، اما این کار فقط برای آخرین قطعه امکان‌پذیر است.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## بررسی bitstring‌ها

~~~~exercism/note
ممکن است bitstring‌ها (توسط test runner یا در iex) در قالبی متفاوت از قالبی که برای ساختن‌شان به کار رفته، چاپ شوند. این موضوع هنگام یادگیری bitstring‌ها اغلب باعث سردرگمی می‌شود.
~~~~

به‌طور پیش‌فرض، bitstring‌ها در قطعه‌های ۸ بیتی (یک بایت) نمایش داده می‌شوند، حتی اگر آن‌ها را با قطعه‌هایی با اندازه‌ی متفاوت ساخته باشید.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

اگر bitstringی بسازید که نماینده‌ی یک رشته‌ی قابل‌چاپ با کدگذاری UTF-8 باشد، به‌صورت یک رشته نمایش داده می‌شود.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
