# مقدمه

این تمرین بر آنچه در [پرنده‌نگر حیاط خلوت][backyard-birdwatcher] دیدید بنا می‌شود و واژه‌های مرتبه‌بالایی را معرفی می‌کند که برای هدایت عملیات، یک «نقل‌قول» (تکه‌کدی در کروشه‌های `[ ]`) می‌گیرند.

## نقل‌قول به‌عنوان مقدار

نقل‌قول فقط یک تکه‌کد تحت‌اللفظی است. می‌توانید آن را به‌عنوان داده به واژه‌ی دیگری بدهید:

```factor
{ 1 2 3 4 5 } [ 2 > ] count .   ! => 3
```

در اینجا `[ 2 > ]` یک نقل‌قول است که یک عدد می‌گیرد و یک «مقدار منطقی» روی پشته برجای می‌گذارد. `count` آن را روی هر عنصر اجرا می‌کند و نتایج درست را می‌شمارد.

## پالایش و رد کردن

```
find      ( seq quot    -- i/f elt/f ) ! first match: index and element, or f f
find-last ( seq quot    -- i/f elt/f ) ! same, but searches from the end
filter    ( seq quot    -- newseq )    ! keep elements where quot is truthy
reject    ( seq quot    -- newseq )    ! drop them instead
without   ( seq exclude -- newseq )    ! drop every element that's in `exclude`
sift      ( seq         -- newseq )    ! drop every `f`, keep the rest
```

```factor
{ 1 2 3 4 5 } [ 3 > ] find .s
! => 3            (index)
! => 4            (element)
{ 1 2 3 4 5 } [ 3 > ] find-last .s
! => 4            (index)
! => 5            (element)
{ 1 2 3 4 5 } [ even? ] filter .    ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .    ! => { 1 3 5 }
"hello world" " ld" without .       ! => "heowor"
{ 1 f 2 f 3 } sift .                ! => { 1 2 3 }
```

`without` آرگومان دومش را به‌عنوان یک مجموعه در نظر می‌گیرد: هر عنصری از `seq` که با *هر* عنصری از `exclude` برابر (`=`) باشد، حذف می‌شود. `sift` حالت خاصِ بدون‌نقل‌قولِ `reject` است: هر عنصر به‌جز `f` را نگه می‌دارد و برای پاک کردن جاهای خالی‌ای که یک `map` پیشین بر جای گذاشته، به کار می‌آید.

### نگه داشتن نتیجه‌ی تست

`find` *عنصر* منطبق را برمی‌گرداند. وقتی تست، مقداری را که واقعاً می‌خواهید *محاسبه* می‌کند، `map-find` شما را از یک پیمایش دوم بی‌نیاز می‌کند: نقل‌قول را روی هر عنصر اجرا می‌کند و نخستین نتیجه‌ی غیرِ `f` را **همراه با** عنصری که آن را تولید کرده برمی‌گرداند.

```
map-find ( seq quot: ( elt -- result/f ) -- result elt )
```

```factor
USING: kernel math sequences ;

! First multiple of 3, paired with that multiple divided by 3.
{ 11 13 15 17 } [ dup 3 mod 0 = [ 3 /i ] [ drop f ] if ] map-find .s
! => 5            (result: 15/3)
! => 15           (element)
```

نقل‌قول برای عناصری که واجد شرط نیستند `f` برمی‌گرداند و برای عنصری که واجد شرط است، نتیجه‌ای را که می‌خواهید نگه دارید. اگر هیچ عنصری واجد شرط نباشد، `map-find` هم مانند `find`، `f f` را روی پشته برجای می‌گذارد.

### پالایش رکوردها بر اساس یک اسلات

وقتی عناصر *تاپل* هستند، محمول معمولاً یک اسلات را از طریق خواننده‌ی خودکارِ `slot>>` استخراج می‌کند و روی آن تست می‌کند:

```factor
USING: accessors sequences ;

TUPLE: customer name vip? ;

{
    T{ customer { name "Alice" } { vip? t } }
    T{ customer { name "Bob"   } { vip? f } }
    T{ customer { name "Carol" } { vip? t } }
}
[ vip?>> ] filter [ name>> ] map .
! => { "Alice" "Carol" }
```

## عبور دادن یک مقدار ثابت با `with`

گاهی محمول به مقداری نیاز دارد که در هر فراخوانی یکسان است: یک آستانه، یک مقسوم‌علیه، یک رشته‌ی هدف. `with` (در [`kernel`][kernel]) آن مقدار ثابت را درون نقل‌قول جاسازی می‌کند و نقل‌قول دوآرگومانی `( value elt -- ? )` را به نقل‌قول تک‌آرگومانی‌ای تبدیل می‌کند که `filter`، `count`، `map` و `each` انتظار دارند:

```
with ( value seq quot -- seq curry )
```

هر فراخوانی برای هر عنصر `( value elt )` را روی پشته می‌بیند: اول مقدار ثابت، دوم عنصر جاری.

```factor
USING: kernel sequences ;

! Count elements greater than 5 — value=5 is threaded in
5 { 2 7 4 9 1 8 } [ < ] with count .   ! => 3
```

## نگاشت و تکرار

`map` (در [`sequences`][sequences]) یک نقل‌قول را روی هر عنصر اعمال می‌کند و آرایه‌ی نتایج را برمی‌گرداند. `each` همین پیمایش را انجام می‌دهد اما نتایج را دور می‌ریزد؛ این وقتی به کار می‌آید که نقل‌قول صرفاً برای عوارض جانبی‌اش اجرا شود. `2map` *دو* دنباله را هم‌گام می‌پیماید و عناصر متناظر را با هم ترکیب می‌کند؛ `2each` و `2reduce` پسرعموهای فقط‌عوارض‌جانبی و تاشوی آن‌اند؛ `zip` کوتاه‌نویسی «جفت‌کردن آن‌ها بدون ترکیب» است:

```
map     ( seq       quot           -- newseq )
map-as  ( seq       quot exemplar  -- newseq )
each    ( seq       quot           -- )
2map    ( seq1 seq2 quot           -- newseq )
2each   ( seq1 seq2 quot           -- )
2reduce ( seq1 seq2 identity quot  -- result )
zip     ( seq1 seq2                -- pairs )
```

`2reduce` یک انباشتگر را به‌طور هم‌زمان از میان هر دو دنباله عبور می‌دهد؛ نقل‌قولش `( accumulator elt1 elt2 -- accumulator' )` را می‌گیرد. در اینجا یک ضرب داخلی را انباشته می‌کند: هر جفت در هم ضرب می‌شود و حاصل‌ضرب‌ها جمع می‌شوند (`1*10 + 2*20 + 3*30`):

```factor
{ 1 2 3 } { 10 20 30 } 0 [ * + ] 2reduce .   ! => 140
```

`map-as` پسرعموی `map` است که نوع دنباله‌ی خروجی را تحمیل می‌کند؛ یک `{ }` یا `V{ }` خالی را به‌عنوان الگو بدهید تا پیش‌فرضِ نوع ورودی را بازنویسی کنید (در غیر این صورت، وقتی Factor بخواهد نتایج را دوباره در یک رشته بسته‌بندی کند، نگاشت یک رشته به عناصر غیرنویسه‌ای خطا می‌دهد).

```factor
USING: formatting math sequences ;

{ 1 2 3 } [ sq ] map .                         ! => { 1 4 9 }
{ 1 2 3 } [ . ] each                           ! prints 1, then 2, then 3
{ 1 2 3 } { 10 20 30 } [ + ] 2map .            ! => { 11 22 33 }
{ "x" "y" } { 1 2 } [ "%s%d" sprintf ] 2map .  ! => { "x1" "y2" }
{ 1 2 3 } { 10 20 30 } [ + . ] 2each           ! prints 11, then 22, then 33
{ "a" "b" "c" } { 1 2 3 } zip .                ! => { { "a" 1 } { "b" 2 } { "c" 3 } }
```

هر دو شکل دودنباله‌ای در طول ورودی کوتاه‌تر متوقف می‌شوند. `zip` همان `[ 2array ] 2map` است: نگه‌داشتن جفت‌ها به‌جای فروپاشاندن آن‌ها.

## مرتب‌سازی

`sort` یک رونوشت مرتب‌شده به ترتیب طبیعی برمی‌گرداند؛ `sort-by` (در [`sorting`][sorting]) بر اساس کلیدی که از هر عنصر استخراج می‌شود مرتب می‌کند:

```
sort    ( seq      -- sortedseq )
sort-by ( seq quot -- sortedseq )
```

```factor
{ 3 1 4 1 5 9 2 6 } sort .
! => { 1 1 2 3 4 5 6 9 }

{ -3 5 -1 4 } [ abs ] sort-by .
! => { -1 -3 4 5 }
```

## تجمیع

`map-sum` (در [`sequences`][sequences]) یک نقل‌قول را روی دنباله نگاشت می‌کند و نتایج را در یک پیمایش جمع می‌کند:

```
map-sum ( seq quot -- n )
```

```factor
{ 1 2 3 4 } [ sq ] map-sum .   ! => 30
```

## کمینه و بیشینه

`minimum` و `maximum` مستقیماً کوچک‌ترین یا بزرگ‌ترین عنصر یک دنباله را برمی‌گردانند. `minimum-by` و `maximum-by` (همه در [`sequences`][sequences]) عنصری را برمی‌گردانند که کلید استخراج‌شده‌اش کوچک‌ترین یا بزرگ‌ترین است:

```
minimum     ( seq      -- elt )
maximum     ( seq      -- elt )
minimum-by  ( seq quot -- elt )
maximum-by  ( seq quot -- elt )
```

```factor
{ 3 1 4 1 5 9 2 6 } minimum .       ! => 1
{ 3 1 4 1 5 9 2 6 } maximum .       ! => 9

{ -3 5 -1 4 } [ abs ] minimum-by .
! => -1
```

## نوشتن واژه‌ی مرتبه‌بالای خودتان

وقتی *واژه‌ی شما* یک نقل‌قول را به‌عنوان آرگومان زمان اجرا می‌گیرد و آن را به `map`، `filter`، `each` و مانند این‌ها می‌فرستد، واژه‌تان را با `; inline` اعلان کنید. این به کامپایلر می‌گوید واژه‌ی شما را در هر محل فراخوانی، جایی که نقل‌قول یک مقدار تحت‌اللفظی شناخته‌شده است، درون‌خطی کند؛ بدون آن، کامپایلر راهی ندارد که اثر پشته‌ای نقل‌قول را بداند.

```factor
USING: math sequences ;

: tax-on ( inventory quot -- total )
    map-sum ; inline

{ { "shirt" 20 } { "hat" 15 } } [ second 1/10 * ] tax-on .
! => 3+1/2
```

واژه‌هایی که فقط از نقل‌قول‌های تحت‌اللفظی ساخته شده‌اند به `inline` نیازی ندارند؛ فقط آن‌هایی که یک نقل‌قول *ورودی* را عبور می‌دهند.

اگر چنین واژه‌ی `inline`‌ای روزی *خودش* را فراخوانی کند (یک ترکیب‌گر بازگشتی)، در عوض آن را `; inline recursive` اعلان کنید. بدون آن واژه‌ی اضافه، کامپایلر با پیام «The inline recursive word ... must be declared recursive» متوقف می‌شود، که دقیقاً می‌گوید چه چیزی را باید اضافه کنید.

## بیرون کشیدن عنصر دوم

برای یک آرایه‌ی دو‌عنصری، `second` عنصر دومش را برمی‌گرداند. `first` عنصر اول را برمی‌گرداند. هر دو در [`sequences`][sequences] هستند.

## تبدیل عدد به رشته

`number>string ( n -- str )` (در [`math.parser`][math.parser]) یک عدد را به شکل رشته‌ی ده‌دهی‌اش تبدیل می‌کند:

```factor
42 number>string .     ! => "42"
3.5 number>string .    ! => "3.5"
```
