# درباره

کتابخانه‌ی استاندارد Gleam نوعی به اسم `Queue` را در ماژول `gleam/queue` پیاده‌سازی می‌کند. این نوع شبیه نوع `List` است، اما چند تفاوت کلیدی دارد:

- نوع `Queue` نحوه‌ی نگارشی ندارد که بتوان با آن صف ساخت یا روی آن تطابق الگو انجام داد.
- می‌توان عنصرها را به‌طور کارآمد هم به ابتدا و هم به انتهای نوع `Queue` اضافه و از آن حذف کرد، در حالی که نوع `List` فقط می‌تواند عنصرها را به‌طور کارآمد از ابتدا اضافه و حذف کند.

بیشتر وقت‌ها می‌خواهید از نوع `List` استفاده کنید، اما وقتی لازم دارید بتوانید از انتهای یک مجموعه اضافه و حذف کنید، نوع `Queue` گزینه‌ی خوبی است.

می‌توان صف را به کمک تابع‌های `queue.new` و `queue.from_list` ساخت:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

می‌توان عنصرها را به کمک تابع‌های `queue.push_front` و `queue.push_back` به صف اضافه کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

می‌توان عنصرها را به کمک تابع‌های `queue.pop_front` و `queue.pop_back` از صف حذف کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

می‌توان صف را به کمک تابع `queue.to_list` به یک لیست تبدیل کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## برابری صف

به‌دلیل نحوه‌ی پیاده‌سازی صف‌ها، ممکن است دو صف با عنصرهای یکسان و در ترتیب یکسان، طبق عملگر `==` که مقدارها را ساختاری مقایسه می‌کند، برابر نباشند. برای مثال:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

اگر لازم دارید دو صف را از نظر برابری مقایسه کنید، می‌توانید از تابع `queue.is_logically_equal` استفاده کنید.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
