# پیوست دستورالعمل‌ها

## ثبات

| ثبات   | کاربرد    | نوع         | توضیح                                          |
| ------ | --------- | ----------- | ---------------------------------------------- |
| `$a0`  | ورودی     | آدرس        | رشته‌ی خاتمه‌یافته با `null` از نویسه‌های مبنای ۱۶ |
| `$v0`  | خروجی     | عدد صحیح    | مقدار دهدهی رشته‌ی ورودی                        |
| `$t0-9`| موقت      | هر نوع      | برای ذخیره‌سازی موقت استفاده می‌شود             |
