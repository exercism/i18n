# پیوست دستورالعمل‌ها

## واژه‌ها

- `tick ( matrix cols -- matrix' )` شبکه را یک نسل جلو می‌برد و شبکه‌ی جدید را برمی‌گرداند.

هر سطر از شبکه به‌صورت یک عدد صحیح ۶۴ بیتی نمایش داده می‌شود؛ `cols` تعداد ستون‌هاست (حداکثر ۶۴). برای مثال،

```
    0 1 0
    1 0 0
    1 1 0
```

به این صورت نمایش داده می‌شود:

```
0b010
0b100
0b110
```
