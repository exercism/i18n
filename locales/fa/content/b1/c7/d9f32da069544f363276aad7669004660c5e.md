# راهنمایی‌ها

## کلیات

- همه‌ی واژه‌های خواندن و نوشتن در [`io.files`][io.files] قرار دارند؛ کدگذاری `utf8` که همه‌ی آن‌ها می‌پذیرند از [`io.encodings.utf8`][utf8] می‌آید.

## 1. هر خوانش را بخوانید

- `file-lines` آرایه‌ای از خط‌ها را برمی‌گرداند که خط‌های جدید از آن‌ها حذف شده‌اند.

## 2. آخرین خوانش را پیدا کنید

- خط‌ها را با `file-lines` بخوانید، سپس آخرین عنصر را (با `last` از `sequences`) بگیرید.

## 3. لاگ خام را بخوانید

- `file-contents` فایل را به‌صورت یک رشته‌ی واحد برمی‌گرداند، همراه با خط‌های جدید و هر چیز دیگری که در آن است.

## 4. یک خوانش را ثبت کنید

- فایل را در حالت افزودن باز کنید و خوانش را داخل نقل‌قول `print` کنید:
  `with-file-appender ( path encoding quot -- )`. خوانش داخل نقل‌قول استفاده می‌شود، در حالی که مسیر پیش از اجرای نقل‌قول مصرف می‌شود؛ بنابراین متغیرهای محلی `::` بدنه را خوانا نگه می‌دارند:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. لاگ را بازنویسی کنید

- `set-file-lines` هر عنصر از یک دنباله را در خط خودش می‌نویسد و خط‌های جدید را به‌جای شما اضافه می‌کند.
