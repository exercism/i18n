# دستورالعمل‌ها

در این تمرین، یک `TranslationService` ارائه می‌دهید که خدمات ترجمه‌ی پایه را به اعضای رایگان و ترجمه‌ی پیشرفته را همراه با تضمین کیفیت به اعضای ویژه می‌دهد.

**API**

شما یک API ترجمه‌ی فضایی پیدا کرده‌اید که هر `request` ترجمه را در زمانی معقول انجام می‌دهد.
می‌خواهید از این فرصت استفاده کنید.
مترجم‌های فضایی بسیار دمدمی‌مزاج‌اند و از افزونگی بیزارند، بنابراین ماهواره‌های _ذخیره‌گاه API_ را هم فراهم کرده‌اند که می‌توانید ترجمه‌های پیشین را بدون مزاحمت برای آن‌ها `fetch` کنید.

**_واکشی یک ترجمه_**

`api.fetch(text)` ترجمه‌ی `text` را از _ذخیره‌گاه API_ واکشی می‌کند و یک `promise` برمی‌گرداند که دو مقدار ارائه می‌دهد:

- `translation`: خود ترجمه
- `quality`: کیفیت که به‌صورت یک عدد بیان می‌شود

اگر ترجمه‌ای در _ذخیره‌گاه API_ پیدا نشود، API یک خطای `NotAvailable` پرتاب می‌کند.
ترجمه‌ها را می‌توان با متد `api.request` اضافه کرد.
اگر `text` قابل ترجمه نباشد، API یک خطای `Untranslatable` پرتاب می‌کند.

```javascript
api.fetch('jIyaj');
// => Promise({ resolved: 'I understand' })
```

**_درخواست یک ترجمه_**

برخی ترجمه‌ها قطعاً وجود دارند، اما هنوز به _ذخیره‌گاه API_ افزوده نشده‌اند. این همان تفاوت میان `NotAvailable` (در ذخیره‌گاه نیست، اما می‌توان درخواستش کرد) و `Untranslatable` (قابل ترجمه نیست) است.

`api.request(text, callback)` درخواست می‌کند که ترجمه‌ی `text` انجام شود و به _ذخیره‌گاه API_ افزوده گردد.
پس از تکمیل، تابع `callback` فراخوانی می‌شود.

- در صورت موفقیت، به `callback` مقدار `undefined` داده می‌شود: این یعنی ترجمه موفق بوده و با متد `api.fetch` قابل دسترسی است.
- در صورت شکست، به `callback` یک `error` داده می‌شود: این یعنی مشکلی پیش آمده است.
  API فضایی _ناپایدار_ است، یعنی اغلب شکست می‌خورد.
  اگر چنین شد، اشکالی ندارد که دوباره `api.request` کنید.

```javascript
api.request('majQa’', callback);
// => undefined
//
// later: the passed callback is called with undefined
//        because it was successful.
```

**⚠ هشدار! ⚠**

~~~~exercism/caution
API جادویش را با تله‌پورت کردن مترجم‌های مختلف انجام می‌دهد، هر وقت که یک `request` برسد.
این کار بسیار پرهزینه است، بنابراین وقتی ترجمه‌ای *موجود* است نباید فراخوانی شود.
متأسفانه همه دفترچه‌ی راهنما را نمی‌خوانند، بنابراین سامانه‌ای هست که افراد متخلف را بیرون می‌اندازد.

اگر `api.request` برای `text`ی فراخوانی شود که موجود است، API برای این فراخوانی یک `AbusiveClientError` پرتاب می‌کند، **و برای هر فراخوانی پس از آن**.
مطمئن شوید که اگر چیزی قبلاً ترجمه شده، *هرگز* درخواست ترجمه نکنید.
~~~~

## 1. واکشی یک ترجمه، بدون توجه به کیفیت

سرویس رایگان فقط ترجمه‌هایی را ارائه می‌دهد که در حال حاضر در _ذخیره‌گاه API_ هستند.

متدی به نام `free(text)` پیاده‌سازی کنید که به اعضای رایگان ترجمه‌هایی را ارائه می‌دهد که از قبل در _ذخیره‌گاه API_ وجود دارند.
کیفیت را نادیده بگیرید و هر خطایی که API پرتاب می‌کند را منتقل کنید.

- اگر ترجمه قابل بازیابی باشد، آن را برمی‌گرداند، بدون توجه به کیفیتش
- هر خطای API ترجمه را منتقل می‌کند
- از متد `api.fetch` استفاده می‌کند (`api.fetch` یک `promise` برمی‌گرداند)

```javascript
service.free('jIyaj');
// => Promise<...> resolves "I understand."

service.free("jIyajbe'");
// => Promise<...> rejects Error("Not yet translated")
```

## 2. واکشی دسته‌ای از ترجمه‌ها، همه یا هیچ

متدی به نام `batch([text, text, ...])` برای اعضای رایگان پیاده‌سازی کنید که آرایه‌ای از متن‌ها را با سرویس رایگان ترجمه می‌کند و همه‌ی ترجمه‌ها یا یک خطای واحد را برمی‌گرداند.

- اگر همه‌ی ترجمه‌ها موجود باشند، با همه‌ی آن‌ها (به همان ترتیب) resolve می‌شود
- با نخستین خطایی که رخ دهد reject می‌شود
- اگر هیچ متنی داده نشود، با یک خطای `BatchIsEmpty` reject می‌شود

```javascript
service.batch(['jIyaj', "majQa'"]);
// => Promise<...> resolves ["I understand.", "Well done!"]

service.batch(['jIyaj', "jIyajbe'"]);
// => Promise<...> rejects new Error("Not yet translated")

service.batch([]);
// => Promise<...> rejects BatchIsEmpty()
```

## 3. درخواست یک ترجمه، با حداکثر ۲ بار تلاش مجدد

متدی برای کاربران ویژه به نام `request(text)` پیاده‌سازی کنید که _درخواست_ می‌کند ترجمه‌ای به _ذخیره‌گاه API_ افزوده شود.
درخواست باید در صورت بروز خطا به‌طور خودکار دوباره تلاش کند.
برای یک درخواست یکسان، نباید بیشتر از **۳ بار فراخوانی** انجام دهد (_مترجم‌های فضایی را عصبانی نکنید!!!_).

- اگر `api.request` خطایی برنگرداند، با `undefined` resolve کنید
- اگر `api.request` خطایی برگرداند، حداکثر دو بار دوباره تلاش کنید
- اگر تلاش‌های مجدد تمام شد، با آخرین خطای دریافت‌شده reject کنید

```javascript
service.request("jIyajbe'");
// => Promise<...> resolves (with nothing), can now be retrieved using the fetch API
```

## 4. واکشی یک ترجمه، بررسی کیفیت، یا درخواست آن

متدی برای کاربران ویژه به نام `premium(text, quality)` پیاده‌سازی کنید که یک ترجمه را واکشی می‌کند.
اگر ترجمه‌ای `NotAvailable` باشد، ترجمه را درخواست کنید و پس از افزوده شدنش به _ذخیره‌گاه API_ واکشی‌اش کنید.
متد باید ترجمه را فقط در صورتی برگرداند که آستانه‌ی مشخصی از `quality` را برآورده کند.

- اگر `api.fetch` resolve شود، پیش از resolve کردن کیفیت را بررسی کنید
- اگر `api.fetch` reject شود، به‌جایش ترجمه را _درخواست_ کنید
- اگر `api.request` reject شود، خطا را منتقل کنید

```javascript
service.premium("jIyajbe'", 100);
// => Promise<...> resolves "I don't understand."

service.premium("'arlogh Qoylu'pu'?", 100);
// => Promise<...> rejects QualityThresholdNotMet()

service.premium("'arlogh Qoylu'pu'?", 40);
// => Promise<...> resolves "What time is it?"
```
