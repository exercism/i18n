# درباره

[رشته‌ها][strings] در Haxe اشیاء تغییرناپذیری هستند که متن را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، نشانه‌های نگارشی و غیره) نمایش می‌دهند. برای تعریف یک نمونه‌ی `string` از گیومه‌های دوتایی استفاده می‌شود:

```haxe
var fruit:String = "Apple";
```

می‌توانید یک رشته را با فراخوانی یکی از [متدها یا ویژگی‌های][string-api] آن تغییر دهید. از آنجا که مقدار رشته‌ها پس از تعریف هرگز تغییر نمی‌کند، همه‌ی متدهای دستکاری رشته یک رشته‌ی جدید برمی‌گردانند.

یک رشته با نویسه‌های گیومه‌ی دوتایی (`"`) محدود می‌شود. بعضی از نویسه‌های خاص نیاز به [فرار][escaping] با نویسه‌ی بک‌اسلش (`\`) دارند. علاوه بر این، رشته‌های Haxe چندخطی هستند و می‌توان به‌سادگی رشته‌های بلند را در کد نوشت:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

ساده‌ترین راه برای به‌هم‌چسباندن رشته‌ها استفاده از [عملگر `+`][plus-operator] است.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

برای قالب‌بندی پیچیده‌تر رشته‌ها، [درج متغیر در رشته][interpolation] ترجیح داده می‌شود. این کار با قرار دادن رشته داخل نویسه‌های تک‌گیومه (`'`) و استفاده از علامت دلار (`$`) برای فعال‌کردن درج متغیر انجام می‌شود. همچنین می‌توان کل عبارت‌ها را با `${expr}` ارزیابی کرد، که در آن `expr` هر عبارت معتبر Haxe است:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
