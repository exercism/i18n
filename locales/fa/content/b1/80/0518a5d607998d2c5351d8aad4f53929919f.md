# دستورالعمل‌ها

لیلی، فضاییِ لیسپ، قطعاً با کمک شما لازانیای زیادی درست کرده است. او می‌خواهد با دادن مقداری از غذای باقی‌مانده از شما تشکر کند. اما اول می‌خواهد درباره‌ی یکی از توابعی که در نوشتنش به او کمک کردید بازخوردی بدهد.

در این تمرین چند تابع دیگر می‌نویسید تا به لیلی در پخت لازانیا کمک کنید و همچنین به او کمک کنید غذای باقی‌مانده را با شما تقسیم کند.

شش کار پیش رو دارید: سه کار درباره‌ی بهبود توابع کنونی پخت لازانیا و سه کار درباره‌ی تقسیم غذای باقی‌مانده.

## 1. استفاده از `preparation-time-in-minutes` را ساده‌تر کنید

لیلی می‌گوید استفاده از `preparation-time-in-minutes` کمی برایش دشوار بوده، چون باید پیش از استفاده از تابع همه‌ی لایه‌ها را می‌شمرد. لیلی می‌پرسد آیا می‌توانید نسخه‌ای از تابع بسازید که لایه‌ها (هر تعداد از آن‌ها) را به عنوان «آرگومان» بگیرد و سپس زمان آماده‌سازی را بر اساس تعداد لایه‌ها محاسبه کند؟ یادآوری می‌کنیم که آماده کردن هر لایه ۱۹ دقیقه طول می‌کشد.

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. امکان تغییر زمان مورد انتظار در فر

اگرچه والدین لیلی همیشه لازانیای خودشان را ۳۳۷ دقیقه می‌پختند، لیلی می‌پذیرد که فضایی‌های لیسپ دیگری هم هستند که لازانیایشان را بیشتر یا کمتر می‌پزند.

پس خوب است که `remaining-minutes-in-oven` از `expected-minutes-in-oven` استفاده نکند و به‌جایش بتواند یک پارامتر _اختیاری_ بگیرد که مشخص کند زمان باید طولانی‌تر، خیلی طولانی، کوتاه‌تر یا خیلی کوتاه باشد. طولانی‌تر یا کوتاه‌تر یعنی ۱۰۰ به زمان پیش‌فرض ۳۳۷ اضافه یا از آن کم شود. خیلی طولانی یا خیلی کوتاه یعنی ۲۰۰ اضافه یا کم شود. اگر پارامتری داده نشود، یا آرگومان «normal» باشد، باید مقدار پیش‌فرض ۳۳۷ برگردانده شود.

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. لیلی سبک پخت دلخواه دیگری را به یاد می‌آورد

درست بعد از اینکه آن تغییر را تمام کردید، لیلی به یاد می‌آورد که فضایی‌های لیسپی هم هستند که زمان پخت _واقعاً کوتاه_ را دوست دارند. عملاً می‌خواهند لازانیا خام بماند. پس حالا تابع باید اگر آرگومان `NIL` بود ۰ برگرداند و در بقیه‌ی موارد همان مقادیر کار قبلی را.

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. تقسیم غذای باقی‌مانده

حالا که به بهبود توابع پخت لازانیا کمک کرده‌اید، _کلی لازانیا_ داریم! لیلی می‌خواهد در ازای همه‌ی کمک‌هایتان، غذای باقی‌مانده را با شما تقسیم کند. باید تابعی بنویسید که سه پارامتر بگیرد: مقدار کل غذای باقی‌مانده، تعداد ظرف‌هایی که لیلی برای باقی‌مانده‌ها در کابینت‌هایش پیدا کرده و همین تعداد برای شما. چون گشتن برای ظرف‌های باقی‌مانده ممکن است زمان‌های متفاوتی ببرد و مقدار دقیق غذای باقی‌مانده ممکن است همان موقعی مشخص شود که شما و لیلی مشغول گشتن در کابینت‌ها هستید، هر دو توافق می‌کنید که تابع آرگومان‌ها را به هر ترتیبی بپذیرد، تا هر عددی که مشخص شد همان لحظه آن را بنویسید. وقتی هر سه عدد را داشتید، کافی است پرانتز فراخوانی تابع را ببندید و آن را ارزیابی کنید.

تابع باید مقدار غذای باقی‌مانده‌ای را برگرداند که باقی می‌ماند، یعنی تفاوت بین وزن غذای باقی‌مانده و تعداد کل ظرف‌هایی که شما و لیلی پیدا کرده‌اید.

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. فرض گرفتن

پس از چند بار رفت‌وآمد به کابینت‌های یکدیگر، هر دو توافق می‌کنید که خوب است اگر تابع فقط _فرض کند_ که شما یا لیلی... مثلاً ۱۰ ظرف دارید، در صورتی که این مقدار مشخص نشده باشد.

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. مقدار استاندارد غذای باقی‌مانده

حتی بهتر، تابع می‌تواند _فرض کند_ که غذای باقی‌مانده به‌اندازه‌ی کافی هست تا در ظرف‌ها جا شود. پس اگر وزن داده نشود، تابع باید `:just-split-it` را برگرداند. _اما_ اگر وزن داده شود و `nil` باشد، باید `:looks-like-someone-was-hungry` را برگرداند.

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
