# الحاق رشته

الحاق رشته در Crystal کاملاً معتبر است، اما روش رایج‌تری که برای ساختن یک رشته به کار می‌رود [درج رشته][interpolation] است.
برای مثال:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
