# پیوست دستورالعمل‌ها

## حافظه‌ی رزروشده

بافرِ رشته‌ی ورودی از بایت‌های ۶۴ تا ۱۹۱ حافظه‌ی خطی استفاده می‌کند.

## قالب ورودی

ورودی به‌صورت یک رشته‌ی واحد شامل سه خط است که در پایان هر خط یک شکست خط دارد. علامت‌های ضربدر و دایره همیشه حروف بزرگ `X` و `O` هستند.

بنابراین صفحه‌ی

```
X··
OXO
XOX
```
به این صورت کدگذاری می‌شود:

```
"X  \nOXO\nXOX\n"
```
