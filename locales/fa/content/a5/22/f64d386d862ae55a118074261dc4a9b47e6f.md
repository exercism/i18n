# Tests

## نصب تست‌رانر ترک GDScript در Exercism

برای استفاده از تست‌رانر، به [نصب صحیح Godot][installation] نیاز دارید.

برای ساخت و تست اسکریپت‌های GDScript در Exercism، Godot در حالت «headless» و از طریق CLI اجرا می‌شود.
این دستورالعمل‌ها در حال حاضر به Linux و bash نیاز دارند.

### گام ۱: نصب زیرساخت کلی تست‌رانر

برای آماده‌سازی تست، [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] را کلون کنید و محتوای آن را به `/opt/test-runner/` منتقل کنید:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### گام ۲: دانلود اسکریپت تست‌رانر یک تمرین

اگر ابزار `exercism` را راه‌اندازی کرده باشید و حداقل یک تمرین GDScript را دانلود کرده باشید، باید پوشه‌ی `exercism/gdscript` را برای نگهداری تمرین‌ها ساخته باشد.
[تست‌رانر][test-local-gdscript-solution] را در این پوشه ذخیره کنید و فایل را اجرایی علامت بزنید، یا فقط یک پیوند به آن بسازید:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## اجرای تست‌ها

وقتی گام‌های نصب انجام شد، باید بتوانید از هر پوشه‌ی تمرین (مثلاً `~/exercism/gdscript/two-fer`) شروع کنید و اسکریپت را (که یک سطح بالاتر، در `../` قرار دارد) اجرا کنید تا راه‌حل محلی خودتان را برای آن تمرین تست کنید:

```sh
../test-local-gdscript-solution.sh
```
