# دستورالعمل‌ها

یک چاپگر دفتر کل را بازآرایی کنید.

تمرین دفتر کل یک تمرین بازآرایی است.
یک code وجود دارد که با گرفتن زبان و منطقه (آمریکایی یا هلندی) و یک واحد پول (دلار آمریکا یا یورو)، دفتر کلی با قالب‌بندی زیبا چاپ می‌کند.
اما این code نسبتاً بد نوشته شده است، هرچند (تا حدی جای تعجب دارد) به‌طور پیوسته در مجموعه‌ی testها قبول می‌شود.

این code را بازنویسی کنید.
یادتان باشد که در بازآرایی، ترفند این است که قدم‌های کوچکی بردارید تا testها همچنان قبول بمانند.
این‌طور همیشه می‌توانید سریع به نسخه‌ای برگردید که کار می‌کند.
ابزارهای کنترل نسخه مثل git هم می‌توانند اینجا به شما کمک کنند.

لطفاً از تغییراتی که داده‌اید یک گزارش نگه دارید و آن گزارش را در قالب یک نظر روی تمرین بنویسید؛ این کار به بازبین‌ها کمک می‌کند.
