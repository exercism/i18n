# مقدمه

JavaScript یک زبان پویاست که از سبک‌های شی‌گرا، دستوری و اعلانی (مثلاً برنامه‌نویسی تابعی) پشتیبانی می‌کند.

## انتساب (و تجدیدِ انتساب)

در JavaScript چند روش اصلی برای انتساب مقدار به اسم وجود دارد: استفاده از متغیرها یا ثابت‌ها. در Exercism، متغیرها همیشه به شکل [camelCase][wiki-camel-case] نوشته می‌شوند و ثابت‌ها به شکل [SCREAMING_SNAKE_CASE][wiki-snake-case]. راهنمای رسمی‌ای برای پیروی وجود ندارد و شرکت‌ها و سازمان‌های مختلف، راهنماهای سبک متفاوتی دارند. _متغیرها را به هر شکلی که دوست دارید بنویسید._ مزیت نوشتن آن‌ها به همان شکلی که تمرین‌ها آماده شده‌اند، این است که در رابط وب و بیشتر IDEها به شکل متفاوتی برجسته می‌شوند.

متغیرها در JavaScript را می‌توان با کلیدواژه‌ی [`const`][mdn-const]، [`let`][mdn-let] یا [`var`][mdn-var] تعریف کرد.

هنگامی که از `let` یا `var` استفاده می‌کنید، متغیر می‌تواند در طول عمر خود به مقادیر مختلفی اشاره کند. برای نمونه، `myFirstVariable` را می‌توان با عملگر انتساب `=` بارها تعریف و بازتعریف کرد:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

برخلاف `let` و `var`، متغیرهایی که با `const` تعریف می‌شوند فقط یک بار قابل انتساب‌اند. از این ویژگی برای تعریف ثابت‌ها در JavaScript استفاده می‌شود.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 در یکی از تمرین‌های یادگیری بعدی، تفاوت میان انتساب/اتصال _ثابت_ و مقدار _ثابت_ بررسی و توضیح داده می‌شود.

## اعلان تابع

در JavaScript، واحدهای عملکردی در _تابع_ها کپسوله می‌شوند و معمولاً اگر تابع‌ها به هم مربوط باشند، در یک فایل کنار هم قرار می‌گیرند. این تابع‌ها می‌توانند پارامتر (آرگومان) بگیرند و با کلیدواژه‌ی `return` مقداری را _برگردانند_. تابع‌ها با نوشتن `()` فراخوانی می‌شوند.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 در JavaScript راه‌های _بسیار_ متفاوتی برای اعلان یک تابع وجود دارد. این راه‌های دیگر با استفاده از کلیدواژه‌ی `function` فرق دارند. این مسیر تلاش می‌کند آن‌ها را به‌تدریج معرفی کند، اما اگر از قبل درباره‌ی آن‌ها می‌دانید، با خیال راحت از هر کدام استفاده کنید. در بیشتر موارد، استفاده از یکی یا دیگری بهتر یا بدتر نیست.

## در دسترس قرار دادن برای فایل‌های دیگر

برای اینکه یک `function`، یک ثابت یا یک متغیر در _فایل‌های دیگر_ در دسترس باشد، باید با کلیدواژه‌ی `export` [صادر شود][mdn-export]. سپس یک فایل دیگر می‌تواند آن‌ها را با کلیدواژه‌ی `import` [وارد کند][mdn-import]. به این کار «سیستم ماژول» هم می‌گویند. نمونه‌ی عالی‌ای از این، شیوه‌ی کار همه‌ی تست‌هاست. هر تمرین دست‌کم یک فایل دارد، مثلاً `lasagna.js`، که شامل _پیاده‌سازی_ است. علاوه بر این، دست‌کم یک فایل دیگر هم وجود دارد، مثلاً `lasagna.spec.js`، که شامل _تست‌ها_ است. این فایل موجودیت‌های عمومی (یعنی صادرشده) را _وارد می‌کند_ تا پیاده‌سازی را تست کند:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
