# مقدمه

کاراکترهای Factor اعداد صحیح‌اند، یعنی کدپوینت‌های یونیکد، بنابراین عملگرهای عددی `<`، `>` و `=` مستقیماً یک ترتیب حساس به بزرگی و کوچکی حروف به شما می‌دهند. واژگان [`unicode`][unicode] نیز «محمول»های آگاه به یونیکد و تبدیل بزرگی و کوچکی یک کاراکتر را اضافه می‌کند.

## محمول‌های کاراکتری

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## تبدیل بزرگی و کوچکی حروف

`ch>upper` و `ch>lower` یک کاراکتر را تبدیل می‌کنند. `>upper` و `>lower` که در سطح رشته کار می‌کنند، آن‌ها را روی تمام کاراکترهای یک رشته اعمال می‌کنند.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` ابتدا تمام یک رشته را به حروف کوچک تبدیل می‌کند و سپس اولین کاراکتر آن را به حرف بزرگ تبدیل می‌کند؛ یعنی همان شکل عنوان برای یک کلمهی واحد:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## لیترال‌های کاراکتری

`CHAR: A` به کدپوینت عددی `A` تفسیر می‌شود. برای کاراکترهای نام‌دار، از نام‌هایی مانند `space`، `tab`، `\n` و غیره استفاده کنید:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## نمادها

هنگامی که یک واژه باید به‌جای یک مقدار، یک برچسب برگرداند، مثلاً `yes`/`no`/`maybe` به‌جای یک «مقدار منطقی»، هر برچسب را به‌صورت یک *«نماد»* تعریف کنید. نماد واژه‌ای است که هنگام فراخوانی، خودش را روی پشته قرار می‌دهد و دو نماد تنها زمانی برابر مقایسه می‌شوند که اسمشان یکسان باشد.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` یک نماد را تعریف می‌کند؛ `SYMBOLS: a b c ;` چند نماد را تعریف می‌کند.
