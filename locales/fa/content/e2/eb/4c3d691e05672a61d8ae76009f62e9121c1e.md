# مقدمه

## بازی با نوع

بازی با نوع را با نام «تبدیل اجباری نوع» هم می‌شناسند.
بازی با نوع به این معناست که دو مقدار از دو نوع متفاوت برای انجام یک عملیات به یک نوع واحد تبدیل اجباری می‌شوند.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

این کار می‌تواند به‌صورت ضمنی انجام شود (به مثال بالا نگاه کنید)، یا به‌صورت صریح با «تبدیل نوع» به سبک `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

نوع‌های مجاز برای تبدیل نوع دستی عبارت‌اند از: `bool`، `int`، `float`، `string`، `array`، `object`.
بیشتر از همه، از تبدیل نوع برای تغییر یک عدد صحیح (`int`) به یک عدد اعشاری (`float`) یا برعکس استفاده می‌شود.
