# مقدمه

[ساختارها][structs-and-classes] (که معمولاً *structs* نامیده می‌شوند) یکی از بلوک‌های اصلی سازنده‌ی برنامه‌های Swift هستند.
ساختارها به شما امکان می‌دهند نوع‌های سفارشی بسازید که «ویژگی‌های» (داده) و «متدهای» (رفتار) مرتبط را کنار هم جمع می‌کنند.
در واقع، نوع‌های استاندارد Swift، از جمله `Int`، `Double`، `Bool`، `String`، `Array` و `Dictionary`، همه به‌صورت ساختار پیاده‌سازی شده‌اند.

## تعریف ساختار

یک ساختار را با کلیدواژه‌ی `struct` تعریف کنید؛ بعد از آن، اسم نوع و آکولادهایی می‌آید که تعریف آن را در بر می‌گیرند.
بر اساس قرارداد Swift، اسم ساختار با `UpperCamelCase` نوشته می‌شود:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## ساخت نمونه

تعریف یک ساختار، نقشه‌ی اولیه است.
برای ساختن *نمونه* از یک ساختار، سازنده‌ی آن را فراخوانی کنید؛ کافی است اسم نوع را بنویسید و بعد از آن پرانتز بگذارید:

```swift
var someStats = CharacterStats()
```

این کار نمونه‌ای می‌سازد که با مقادیر پیش‌فرض ویژگی‌های تعریف، پر شده است.

Swift همچنین یک **سازنده‌ی عضو‌به‌عضو** را به‌طور خودکار برای ساختارها تولید می‌کند که به شما امکان می‌دهد ویژگی‌ها را با اسم مقداردهی اولیه کنید:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## دسترسی به ویژگی‌ها و تغییر آن‌ها

با *نقطه‌گذاری* به ویژگی‌های یک نمونه دسترسی پیدا می‌کنید و آن‌ها را تغییر می‌دهید:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

چون ساختارها «نوع مقدار» هستند، برای تغییر ویژگی‌های یک نمونه باید خودِ نمونه با `var` اعلان شده باشد.
اگر نمونه با `let` اعلان شده باشد، همه‌ی ویژگی‌های آن تغییرناپذیر می‌شوند.
