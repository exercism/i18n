# پیوست دستورالعمل‌ها

## واژه‌ها

یک «تاپل» `cmplx` با اسلات‌های `real` و `imaginary` تعریف کنید. دسترس‌گرهای اسلات `real>>` و `imaginary>>` همراه با تعریف تاپل به‌طور خودکار در اختیار شما قرار می‌گیرند. تست‌ها هم برای خواندن مؤلفه‌ها از همین دسترس‌گرها استفاده می‌کنند.

- `<cmplx> ( real imag -- cmplx )`، ساخت یک عدد مختلط.
- `>cmplx ( pair -- cmplx )`، ساختن یک `cmplx` از `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`، برگرداندن `{ real imaginary }`.
- `c+ ( a b -- c )`، `c- ( a b -- c )`، `c* ( a b -- c )`، `c/ ( a b -- c )`، عملیات حسابی روی دو عدد مختلط.
- `c-abs ( a -- |a| )`، قدر مطلق (یک عدد حقیقی).
- `c-conj ( a -- a* )`، مزدوج مختلط.
- `c-exp ( z -- e^z )`، نمایی مختلط.

جنریک‌های `MATH:` در Factor (یعنی `+`، `-`، `*`، `/`) فقط روی سلسله‌مراتب ریاضی توکار اعمال می‌شوند، بنابراین این تمرین به‌جای متدهایی روی آن جنریک‌ها از نام‌های اختصاصی واژه استفاده می‌کند.

تست‌های مربوط به عملیات حسابی‌ای که اعداد حقیقی را با اعداد مختلط ترکیب می‌کند حذف شده‌اند؛ هر عملیاتی که اینجا انجام می‌شود بین دو مقدار `cmplx` است.
