# درباره

هش‌ها یک نوع داده در Perl هستند که مجموعه‌ای نامرتب از کلیدهای رشته‌ای را در خود دارند که با مقادیر اسکالر جفت شده‌اند.

یک متغیر هش معمولاً با تخصیص یک فهرست به آن پر می‌شود، مثلاً `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

فهرست‌ها معمولاً با کاما از هم جدا می‌شوند، اما اغلب چیزی را می‌بینید که به آن «کامای چاق» `=>` می‌گویند و برای جدا کردن کلیدها و مقادیر در یک فهرست به کار می‌رود.
رفتارش تقریباً با کاما یکسان است، اما این مزیت را هم دارد که عنصر سمت چپ را به‌صورت یک رشته تفسیر می‌کند.

هش‌ها را می‌توان با تخصیص به کلیدهای تک‌تک نیز پر کرد، مثلاً `$scores{Alice} = 10;`.

مقادیر یک هش را می‌توان با مشخص کردن کلیدها از طریق اندیس به دست آورد، مثلاً `$scores{Bob} # 15`.

کلیدهای یک هش یکتا هستند.
اگر یک کلید چند بار داده شود، فقط آخرین مقدار داده‌شده نگه داشته می‌شود.

## توابع

توابع کار با هش‌ها شامل [keys][keys] و [values][values] است که آن بخش‌های مربوطه از یک هش را به‌صورت یک فهرست بازیابی می‌کنند.
فهرست‌هایی که توابع [keys][keys] و [values][values] برمی‌گردانند می‌توانند برای توابع فهرست مانند [grep][grep]، [map][map] و [sort][sort] و همچنین حلقه‌های [for][for] مفید باشند.

از دیگر توابع هش می‌توان به [exists][exists] برای بررسی وجود یک کلید در هش (حتی اگر مقدارش `undef` باشد) و [delete][delete] برای حذف یک کلید از هش اشاره کرد.

## تفاوت سیگیل

هنگام گرفتن مقادیر یک هش، سیگیل داده‌شده نتیجه را تعیین می‌کند.
اندیس `{}` در انتهای نام متغیر است که به Perl می‌گوید شما دارید با آن نام به یک هش دسترسی پیدا می‌کنید.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

هرچند این کار مجاز است، اما برای خوانایی بهتر توصیه می‌شود که متغیرهای با نوع متفاوت نام یکسانی نداشته باشند.
