# درباره‌ی بیت‌ها

ارقام دودویی در نهایت مستقیماً به ترانزیستورهای CPU یا RAM شما نگاشت می‌شوند و به اینکه هر کدام «روشن» است یا «خاموش».

دستکاری سطح پایین، که به‌طور غیررسمی «بازی با بیت» نامیده می‌شود، در زبان‌های سیستمی اهمیت ویژه‌ای دارد.

زبان‌های سطح بالاتر مانند Kotlin معمولاً بیشتر این جزئیات را انتزاع می‌کنند.
با این حال، طیف پایه‌ای از عملیات بیتی [در دسترس است][ref-bitwise].

~~~~exercism/note
برای دیدن خروجی دودویی خوانا برای انسان، تقریباً همه‌ی مثال‌های زیر باید در تابع [`Integer.toBinaryString()`][web-binstring] پیچیده شوند، یا با `toString(radix = 2)` تبدیل شوند.
 
این کار از نظر بصری حواس‌پرتی ایجاد می‌کند، بنابراین بیشتر موارد استفاده از این تابع حذف شده‌اند و نتایج با نماد `0b` نمایش داده شده‌اند.

[web-binstring]: https://www.baeldung.com/kotlin/int-binary-representation
~~~~

## عملیات جابه‌جایی بیت

انواع `Int` یا `Long`، چه علامت‌دار و چه بدون علامت، را می‌توان به‌صورت یک `String` متشکل از یک‌ها و صفرها نمایش داد و به‌عنوان دنباله‌ای از بیت‌ها دستکاری کرد.

شاید شگفت‌آور باشد که انواع `Byte` یا `Short` با بیشتر عملیات بیتی در Kotlin سازگار نیستند.
همه‌ی مثال‌های زیر از اعداد صحیح ۳۲ بیتی (`Int` یا `UInt`) استفاده می‌کنند.

```kotlin
val ns = 0b111  // 7 decimal
Integer.toBinaryString(ns)  // => "111"
```

جابه‌جایی‌های بیتی همه چیز را به اندازه‌ی تعداد مشخصی موقعیت به چپ یا راست می‌برند.
بعضی بیت‌ها از یک سر می‌افتند و سر دیگر با صفر یا یک پر می‌شود.

- جابه‌جایی به چپ با `shl`: پر شدن با صفر.
- جابه‌جایی به راست با `shr` یا `ushr`: پر شدن با صفر برای اعداد مثبت (برای اعداد منفی بخش بعدی را ببینید).

```kotlin
val ns = 0b111  // 7 decimal
ns shl 1  // => 0b1110, decimal 14
ns shr 1  // => 0b11, decimal 3
ns ushr 1  // => 0b11

val nu: UInt = 0b111u  // 7 unsigned
nu shr 1  //  => 0b11
```

هر جابه‌جایی به چپ مقدار را دو برابر می‌کند و هر جابه‌جایی به راست آن را نصف می‌کند (با احتمال برش).
این موضوع در نمایش دهدهی واضح‌تر است:

```kotlin
3 shl 2  // => 12
24 shr 3 // => 3
```

چنین جابه‌جایی بیتی بسیار سریع‌تر از حساب «معمول» است و همین این تکنیک را در کدنویسی سطح پایین بسیار محبوب کرده است.

### جابه‌جایی بیتی اعداد صحیح منفی

با _اعداد صحیح منفی_ باید کمی دقیق‌تر باشیم.

مقادیر منفی به شکل [مکمل دو][wiki-2complement] ذخیره می‌شوند، یعنی چپ‌ترین بیت ۱ است.
برای جابه‌جایی به چپ مشکلی نیست، اما هنگام جابه‌جایی به راست چطور بیت‌های چپ را پر می‌کنیم؟

```kotlin
val ns = -0b111  // => 0b11111111111111111111111111111001

// shift left: simple
ns shl 1  // => 0b11111111111111111111111111110010, decimal -14

// shift right: preserves sign bit
ns shr 1  // => 0b11111111111111111111111111111100, decimal -4

// unsigned shift right: left-pads with zeros
ns ushr 1 // => 0b01111111111111111111111111111100, decimal 2147483644
```

عملگر [`shr`][ref-shr] [جابه‌جایی حسابی][wiki-arithmetic] را انجام می‌دهد و بیت علامت را حفظ می‌کند.

عملگر [`ushr`][ref-ushr] [جابه‌جایی منطقی][wiki-logical] را انجام می‌دهد و با صفر پر می‌کند، چنان که گویی عدد بدون علامت است.

## منطق بیتی

در [مفهوم منطقی][concept-booleans] دیدیم که عملگرهای `&&` (و)، `||` (یا) و `!` (نه) با مقادیر منطقی به کار می‌روند.

عملگرهای معادلی وجود دارند، `and`، `or`، `xor` ([یا انحصاری][wiki-xor])، برای مقایسه‌ی بیت‌های دو عدد صحیح، و یک تابع `inv` (وارون‌سازی) برای وارونه کردن همه‌ی بیت‌ها.

```kotlin
0b1011 and 0b0010 //  bit is 1 in both numbers
// => 0b0010

0b1011 or 0b0010 // bit is 1 in at least one number
// => 0b1011

0b1011 xor 0b0010 // bit is 1 in exactly one number, not both
// => 0b1001

0b1011.inv() // flip all bits (in a 32-bit signed Int)
// => 0b11111111111111111111111111110100
```
