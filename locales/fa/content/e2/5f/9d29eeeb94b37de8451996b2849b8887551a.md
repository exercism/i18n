# Debug

همه‌ی خروجی اسکریپت Red شما هنگام اجرای هر Test در کنسول دیده می‌شود. می‌توانید هرچه می‌خواهید را با `print` چاپ کنید، مثلاً مقدار کلمات:

```red
print ["x =" x]
```

همچنین، تابع `probe` بسیار مفید است. وقتی ارزیابی می‌شود، ورودی خود را ارزیابی می‌کند، نتیجه را به شکلی چاپ می‌کند که نوعش را بازتاب می‌دهد و آن را برمی‌گرداند. بنابراین در بیشتر موارد «شفاف» است و می‌توانید آن را داخل عبارت‌ها قرار دهید:

```red
x: 10
y: probe x + 5
```

گاهی تابعی به اسم `type?` (بله، در اسمش علامت سؤال دارد!) می‌تواند برای بررسی نوع مقدار مفید باشد:

```red
print ["x type:" type? x]
```

تکنیک‌های پیشرفته‌تری برای Debug هم [در ویکی Red فهرست شده‌اند](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
