# دستورالعمل‌ها

در این تمرین، شما یک هوادار پرشور ورزش هستید و تازه شوق بسکتبال NBA را کشف کرده‌اید.
از آنجا که در بسکتبال NBA تازه‌کار هستید، در تاریخ NBA عمیقاً کاوش می‌کنید، تیم‌ها و مربی‌ها و آمار برد و باختشان را دنبال می‌کنید و آن‌ها را با یکدیگر مقایسه می‌کنید.

چون هنوز تیم محبوبی ندارید، الگوریتمی هم می‌نویسید تا مشخص کنید طرفدار یک تیم خاص باشید یا نه.
هفت کار پیش رو دارید که به شما کمک می‌کند الگوریتم اختصاصی خودتان را برای _طرفداری از یک تیم_ بسازید.

## 1. مدل را تعریف کنید

نام مستعار نوع `Coach` را برای یک رکورد با دو فیلد زیر، به ترتیب زیر تعریف کنید:

- `name`: اسم مربی، از نوع `String`.
- `formerPlayer`: نشان می‌دهد که آیا مربی بازیکن پیشین بوده است، از نوع `Bool`.

نام مستعار نوع `Stats` را برای یک رکورد با دو فیلد زیر، به ترتیب زیر تعریف کنید:

- `wins`: تعداد بردها، از نوع `Int`.
- `losses`: تعداد باخت‌ها، از نوع `Int`.

نام مستعار نوع `Team` را برای یک رکورد با سه فیلد زیر، به ترتیب زیر تعریف کنید:

- `name`: اسم تیم، از نوع `String`.
- `coach`: مربی تیم، از نوع `Coach`.
- `stats`: آمار تیم، از نوع `Stats`.

## 2. یک تیم بسازید

می‌خواهید با کد یک شخص ثالث تعامل کنید که مفهوم تیم را دارد، اما کد شما را با ترتیب متفاوتی از پارامترها فراخوانی می‌کند. تابعی به اسم `createTeam` با امضای `String -> Stats -> Coach -> Team` اضافه کنید.

## 3. مربی را عوض کنید

چون مالکان NBA بی‌حوصله‌اند، متوجه شدید که نتایج بد تیم اغلب به جایگزینی مربی می‌انجامد.
تابع `replaceCoach` را پیاده‌سازی کنید که مربی جدید و تیم را به عنوان پارامتر می‌گیرد و تیم را همراه با مربی جدید برمی‌گرداند:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. بررسی کنید که باید طرفدار یک تیم باشید یا نه

در آینده قصد دارید الگوریتم پیچیده‌ای طراحی کنید که تعیین کند طرفدار یک تیم باشید یا نه، اما در نخستین تلاش تصمیم گرفته‌اید طرفدار هر تیمی باشید که بردهایش از باخت‌هایش بیشتر است.

می‌خواهید این تابع در بافت‌های دیگر هم قابل استفاده باشد، پس در امضای نوع از یک رکورد قابل گسترش استفاده کنید تا هر رکوردی را که فیلدهای مربوط را دارد بپذیرد.
برای این که تابع تا حد امکان مختصر بماند، می‌خواهید با تطبیق الگو `stats` را از پارامتر تابع بیرون بکشید.
تابع `rootForTeam` را پیاده‌سازی کنید که یک تیم می‌گیرد و اگر باید طرفدار آن تیم باشید `True` برمی‌گرداند؛ در غیر این صورت `False` را برگردانید.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
