# درباره

[متدهای الحاقی][extension-methods] امکان افزودن متد به انواع موجود را فراهم می‌کنند، بدون اینکه نوع مشتق‌شده‌ی جدیدی بسازید، کد را دوباره کامپایل کنید یا به شکل دیگری نوع اصلی را تغییر دهید.

متدهای الحاقی متدهای استاتیک هستند، اما طوری فراخوانی می‌شوند که گویی متدهای نمونه‌ای روی نوع گسترش‌یافته‌اند. این کار با قرار دادن `this` پیش از نوع انجام می‌شود؛ یعنی نمونه‌ای که `.` را روی آن گذاشته‌ایم، به عنوان پارامتر اول پاس داده می‌شود. برای کد کلاینت، تفاوت آشکاری میان فراخوانی یک متد الحاقی و متدهای تعریف‌شده در یک نوع وجود ندارد.

```csharp
namespace MyExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split().Length;
    }
}

"Hello World".WordCount();
// => 2
```

متدهای الحاقی در سطح «فضای نام» در دسترس قرار می‌گیرند. یعنی اگر در فضای نامی متفاوت از فضای نامی باشید که متد الحاقی در آن تعریف شده است، ابتدا باید فضای نام آن را در یک دستور `using` بیاورید؛ برای نمونه، اگر بخواهیم از مثال بالا در کدمان استفاده کنیم، نخست به یک دستور `using MyExtensions` نیاز داریم. اگر در همان فضای نامی باشید که متد الحاقی در آن تعریف شده است، می‌توانید بدون دستور `using` از متدهای الحاقی استفاده کنید.

نمونه‌ی شناخته‌شده‌ای از متدهای الحاقی، عملگرهای پرس‌وجوی استاندارد [LINQ][linq] هستند که قابلیت پرس‌وجو را به انواع موجود `IEnumerable` اضافه می‌کنند. برای اینکه این‌ها در دسترس قرار بگیرند، به یک دستور `using System.Linq;` نیاز داریم.
