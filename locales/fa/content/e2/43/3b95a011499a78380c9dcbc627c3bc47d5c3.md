# Nil

Crystal نوعی به نام [`Nil`][nil] دارد که تنها می‌تواند یک مقدار داشته باشد: `nil`.
از آن برای نشان دادن نبودِ مقدار استفاده می‌شود و شبیه به `null` یا `None` در زبان‌های دیگر است.

مقدارهای Nil را می‌توان از متدهای مختلفی برگرداند؛ برای نمونه [`String#[]?`][string-index] که اگر اندیس خارج از محدوده باشد `nil` برمی‌گرداند.

```crystal
"foo"[10]? # => nil
```

Crystal چیزی دارد که به آن **بررسی ارجاع پوچ** می‌گویند؛ یعنی همه‌ی نوع‌ها به‌طور پیش‌فرض نمی‌توانند nil باشند.
یعنی نمی‌توانید به یک متغیر `nil` نسبت دهید، مگر آنکه آن را صریحاً از نوع `Nil` اعلام کنید.
این هم به نوبه‌ی خود یعنی اینکه کامپایلر به‌طور خودکار ارجاع‌های پوچ را بررسی می‌کند.

## مقدار کاذب

برای کار با مقدارهای `nil` می‌توان رویکردهای متفاوتی در پیش گرفت.
`nil` یک مقدار [کاذب][truthy-falsey] است، همان‌طور که `false` هم چنین است.
یعنی در دستورها و جاهای دیگری که یک مقدار کاذب یا صادق انتظار می‌رود، با `nil` همان‌طور رفتار می‌شود که با `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

یعنی اگر متغیری که می‌تواند nil باشد مقدارش `nil` باشد، شاخه‌ی صادق اجرا نمی‌شود.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## بررسی nil

Crystal متدی دارد که با آن می‌توان بررسی کرد آیا یک مقدار `nil` است.
اسم آن [`nil?`][nil?] است و روی همه‌ی اشیاء در دسترس است.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

وقتی فقط از خود مقدار در یک دستور if استفاده می‌کنید، ماجرا کمی فرق می‌کند؛ چون در مثال‌های پیشین، هم false و هم nil کاذب به شمار می‌آمدند.
اینجا فقط `nil` کاذب به حساب می‌آید، چون اگر مقدار `false` بود دیگر `nil` نبود و در نتیجه صادق می‌شد.

## عملگر or

ساده‌ترین راه برای کار با مقدارهای `nil` این است که کاری کنید همان ابتدا هرگز `nil` نشوند.
عملگر or ([`||`][or]) بیشتر هنگام کار با `Bools` به کار می‌رود، اما اگر درست فهمیده شود، می‌توان از آن برای کار با مقدارهای `nil` هم استفاده کرد.
عملگر or بررسی می‌کند که آیا مقدار اول صادق است؛ اگر نباشد، مقدار دوم به کار می‌رود.
این کار باعث می‌شود که اگر مقدار `nil` باشد، کاذب به حساب بیاید و در نتیجه مقدار دوم استفاده شود.

```crystal
"foo"[10]? || "bar" # => "bar"
```
