# پیوست دستورالعمل‌ها

## قالب خروجی

هر ملیت با یک حرف مشخص می‌شود. (`E` = `Englishman`، `J` = `Japanese`، `N` = `Norwegian`، `S` = `Spaniard`، `U` = `Ukrainian`)

## رجیستر

| رجیستر | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | خروجی    | بایت    | ملیت کسی که آب می‌نوشد |
| `$v1`    | خروجی    | بایت    | ملیت کسی که گورخر دارد   |
| `$t0-9`  | موقت | هر نوع     | برای ذخیره‌سازی موقت        |
