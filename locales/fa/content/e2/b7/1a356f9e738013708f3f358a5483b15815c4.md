# راهنمایی‌ها

## عمومی

- اسلایس‌ها در Go از اندیس صفر شروع می‌شوند.
  اولین اندیس در یک اسلایس `0` است.
- تابع توکار [`append`][append-builtin] از نوع [`variadic`][variadic-gobyexample] است
- می‌توانید عناصر یک اسلایس را با استفاده از نشانه‌ی سه‌نقطه به اسلایس دیگری اضافه کنید:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. ساختن یک اسلایس با چند کارت مشخص

- برای ساختن اسلایسی که از پیش با چند داده پر شده است، از نگارش لیترال اسلایس استفاده کنید: `s := []T{x1, x2, ..., xn}`.

## 2. گرفتن یک کارت از پشته

- برای گرفتن عنصر `n`اُم یک اسلایس، [از یک اندیس استفاده کنید][go-slices].
- برای بررسی وجود یک عنصر در اسلایس، از یک دستور شرطی استفاده کنید و اندیس را با [طول اسلایس][len-builtin] مقایسه کنید.

## 3. تعویض یک کارت در پشته

- برای تعیین عنصر `n`اُم در یک اسلایس، [از یک اندیس استفاده کنید][go-slices] و مقدار جدیدی به آن نسبت دهید.
- برای افزودن عنصر جدیدی به انتهای اسلایس، از تابع `append` استفاده کنید.

## 4. افزودن کارت به بالای پشته

- برای افزودن عناصر به ابتدای یک اسلایس، می‌توانید عناصر اسلایس اصلی را به اسلایس آرگومان `value` اضافه کنید.

## 5. حذف یک کارت از پشته

- حذف یک عنصر از یک اسلایس را می‌توان با اضافه کردن بخش پس از `index` به بخش پیش از آن انجام داد.
