# دستورالعمل‌ها

در حال آماده‌شدن برای پختن کوکی برای دوستانتان بودید که متوجه شدید باید بعضی از اندازه‌های به‌کاررفته در دستور را تبدیل کنید.
چون فقط با دستگاه متریک آشنایید، باید راهی بیابید که اندازه‌های رایج پخت آمریکایی را برای راحتی خودتان به میلی‌لیتر (mL) تبدیل کند.

از این جدول تبدیل برای حل خود استفاده کنید:

| واحد برای تبدیل | حجم | بر حسب میلی‌لیتر (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| پیمانه‌ی آمریکایی | 1 | 240 |
| اونس مایع آمریکایی | 1 | 30 |
| قاشق چای‌خوری آمریکایی | 1 | 5 |
| قاشق غذاخوری آمریکایی | 1 | 15 |

چون برنامه‌نویس مستعدی هستید که تازه در حال یادگیری است، تصمیم می‌گیرید از میلی‌لیتر به عنوان واحد واسط استفاده کنید تا تبدیل از هر واحد فهرست‌شده به واحد دیگر (حتی خودش) آسان‌تر شود.

## 1. مؤلفه‌ی عددی را از یک جفت حجم به دست آورید

تابع `getVolume` را پیاده‌سازی کنید. این تابع یک چندتایی جفت حجم می‌گیرد و باید فقط مؤلفه‌ی عددی را برگرداند.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. جفت حجم را به میلی‌لیتر تبدیل کنید

تابع `toMilliliter` را پیاده‌سازی کنید. این تابع یک چندتایی جفت حجم می‌گیرد و باید حجم را با استفاده از جدول تبدیل به میلی‌لیتر تبدیل کند.

برای هر واحد، تابع مربوط به آن را با کمک چند بند تابع و تطبیق الگو بسازید. اتم‌هایی که برای نشان دادن هر واحد به کار می‌روند عبارت‌اند از: `Cup`، `FluidOunce`، `Teaspoon`، `Tablespoon` و `Milliliter`.
نتیجه‌ی تبدیل را درون یک چندتایی برگردانید.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. جفت حجم میلی‌لیتری را به واحد دیگری تبدیل کنید

تابع `fromMilliliter` را پیاده‌سازی کنید. این تابع یک چندتایی جفت حجم و واحد دلخواه را می‌گیرد و باید حجم را با استفاده از جدول تبدیل به واحد دلخواه تبدیل کند.

برای هر واحد، تابع مربوط به آن را با کمک چند بند تابع و تطبیق الگو بسازید. اتم‌هایی که برای نشان دادن هر واحد به کار می‌روند عبارت‌اند از: `Cup`، `FluidOunce`، `Teaspoon`، `Tablespoon` و `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. از هر واحدی به هر واحد دیگر تبدیل کنید

تابع `convert` را پیاده‌سازی کنید. این تابع یک چندتایی جفت حجم و واحد دلخواه را می‌گیرد و باید حجم داده‌شده را به واحد دلخواه تبدیل کند.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
