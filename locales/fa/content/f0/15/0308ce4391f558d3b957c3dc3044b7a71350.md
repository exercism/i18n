# درباره

## عدد و عملگرهای عددی

همه‌ی **عددها**، چه صحیح و چه غیرصحیح، عددهای ممیز شناور با دقت مضاعف IEEE754 هستند.
پیاده‌سازی `jq` از نوع `double` در زبان C استفاده می‌کند.
این ما را به دقت ۵۳ بیت محدود می‌کند.

عملگرهای معمول برای کار با عددها در دسترس‌اند:

- حسابی: `+`، `-`، `*`، `/`، `%`
- مقایسه: `==`، `!=`، `<`، `<=`، `>=`، `>`
- [توابع ریاضی][man-math] استاندارد

  برای توابع یک‌ورودی، مقدار را به تابع پایپ کنید

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  برای توابع دو‌ورودی، تابع ورودی را نادیده می‌گیرد و انتظار دارد ورودی‌ها را به‌عنوان پارامتر بدهید

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  جداکننده‌ی آرگومان‌های تابع، نقطه‌ویرگول است، نه کاما.

```sh
  9007199254740992,

```

این عددها نباید برابر باشند.

## عبارت‌های شرطی

`jq` برای **عبارت‌های شرطی** از یک [عبارت `if-then-else`][if-then-else] استفاده می‌کند.
از آنجا که یک _عبارت_ است، در یک پایپ‌لاین قرار می‌گیرد.

نحوه‌ی نگارش چنین است: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

بخش `else` اختیاری است.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

شرط‌های بیشتر از `elif` استفاده می‌کنند

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
