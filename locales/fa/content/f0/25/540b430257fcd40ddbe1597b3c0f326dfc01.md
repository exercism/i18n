# درباره

[`List`][lists] در Elm مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار از یک نوع است.
چون لیست‌ها تغییرناپذیرند، مقدار یک لیست پس از ساخته‌شدن هرگز تغییر نمی‌کند.
لیست‌های Elm یک «سر» (اولین عنصر) و یک «دم» (همه‌ی عناصر پس از عنصر اول) دارند.
دم یک لیست، خودش یک لیست است.

حاشیه‌نویسی نوع برای لیست‌ها را می‌توان به این شکل تعریف کرد:

```elm
List String --> a list of String
List Int --> a list of Int
```

لیست‌ها را می‌توان به این شکل تعریف کرد:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

رایج‌ترین راه برای افزودن یک عنصر به لیست، عملگر `::` (cons) است:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

می‌توان یک لیست را با عملگر `++` یا `List.append` الحاق کرد:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

لیست‌ها با توابع و عملگرهایی که در [ماژول `List`][list-module] تعریف شده‌اند، دستکاری می‌شوند.

```elm
List.length [ 7, 8 ] --> 2
```

هر تابع یا عملگری که به نظر برسد لیست را تغییر می‌دهد (مثل افزودن یک عنصر)، در واقع یک لیست جدید برمی‌گرداند.
با این حال، کارایی معمولاً مشکلی ایجاد نمی‌کند، چون پیاده‌سازی لیست‌ها از تخصیص و کپی غیرضروری جلوگیری می‌کند.

لیست‌ها را همچنین می‌توان با [تطبیق الگو][list-destructuring] پردازش کرد.

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
