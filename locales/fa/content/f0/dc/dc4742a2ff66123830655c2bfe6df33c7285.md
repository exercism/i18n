# مقدمه

در Factor، یک واژه‌ی جدید را با `: name ( stack-effect ) body ;` تعریف می‌کنید. بدنه دنباله‌ای از واژه‌هاست؛ فراخوانی کردن واژه‌ی جدیدتان آن‌ها را به ترتیب اجرا می‌کند.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

وقتی یک رویه بزرگ می‌شود، می‌توانید (و باید) آن را *فاکتور* کنید: گروه‌هایی از واژه‌ها را جدا کنید و به واژه‌های کوچک‌تر و نام‌دار تبدیل کنید، هر کدام با یک وظیفه. نام این زبان هم از همین گرفته شده است.

## واژگان

هر فایل `.factor` با `IN:` یک «واژگان» اعلام می‌کند. واژه‌های یک واژگان می‌توانند با فهرست کردن واژگان دیگر در `USING:`، واژه‌های آن را فراخوانی کنند.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

چیدمان پوشه‌ها از نام نقطه‌دار واژگان پیروی می‌کند: واژگان `my-vocab` در `my-vocab/my-vocab.factor` قرار دارد؛ واژگان `my-vocab.helpers` در `my-vocab/helpers/helpers.factor` قرار دارد. بارگذارِ Factor اعلان‌های `USING:` را به‌صورت زنجیره‌ای دنبال می‌کند و هر واژگان را هنگام نیاز بارگذاری می‌کند.
