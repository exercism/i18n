# درباره

اگر بتوان نوع پارامترها را استنباط کرد، سویفت همچنین اجازه می‌دهد که اسم پارامترها و «کلیدواژه‌ی `in`» از تعریف «کلوژر» حذف شوند. در عوض می‌توان با [«نحوه‌ی نگارش کوتاه و ویژه»][shorthand-argument-names] به پارامترها ارجاع داد، که در آن `$0` به پارامتر اول اشاره دارد، `$1` به پارامتر دوم و به همین ترتیب.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

این سبک بیشتر زمانی به کار می‌رود که کلوژرها را به «توابع مرتبه‌بالا» پاس می‌دهیم و کوتاه بودن ارزش دارد.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
