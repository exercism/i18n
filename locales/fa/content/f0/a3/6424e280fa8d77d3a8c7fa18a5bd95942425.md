# درباره

## نوع اختیاری

سوییفت از [_انواع اختیاری_][optionals] استفاده می‌کند تا برنامه‌نویسان بتوانند نبودِ احتمالی یک مقدار را نشان دهند.
نوع اختیاری نوعی است که می‌تواند یک مقدار در خود نگه دارد یا `nil` باشد؛ `nil` نشان‌دهنده‌ی نبود یک مقدار است.
برای استفاده از یک نوع اختیاری، برنامه باید نخست بررسی کند که مقداری وجود دارد، سپس آن را بازگشایی کند و به کار ببرد.

هر نوعی را می‌توان با افزودن یک `?` به انتهای اسم نوع، به نوعی اختیاری تبدیل کرد.
بنابراین یک عدد صحیح اختیاری نوع `Int?` خواهد داشت و یک رشته‌ی اختیاری نوع `String?`.
تعریف ثابت یا متغیر از نوع اختیاری و مقداردهی به آن‌ها، همانند مقادیر انواع غیراختیاری انجام می‌شود.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

می‌توانید با نسبت دادن مقدار ویژه‌ی `nil` به یک متغیر از نوع اختیاری، نبود یک مقدار را به آن نسبت دهید.
`nil` را می‌توان با همه‌ی انواع اختیاری به کار برد، اما `nil`هایی که به دو نوع اختیاری متفاوت نسبت داده می‌شوند، نوع یکسانی ندارند و نمی‌توان آن‌ها را جابه‌جا کرد یا حتی مقایسه کرد.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

همچنین توجه داشته باشید که با اینکه `nil` را می‌توان به هر نوع اختیاری نسبت داد، نمی‌توان آن را به یک نوع غیراختیاری نسبت داد (حتی اگر آن مقدار در واقع `nil` نباشد).
و نمی‌توان یک نوع اختیاری را بدون بازگشایی آن، به متدهایی که انتظار نوع غیراختیاری دارند، فرستاد.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## استفاده از انواع اختیاری

چون انواع اختیاری با انواع پایه‌ی خود یکسان نیستند، نمی‌توان این دو نوع را به یک شکل به کار برد.
برای مثال، `Int("123") + 1` به خطای کامپایلر «Value of optional type 'Int?' must be unwrapped to a value of type 'Int'» منجر می‌شود.
دلیلش این است که `Int("123")` یک نوع اختیاری `Int?` برمی‌گرداند، نه نوع `Int`؛ چون اگر رشته به عدد صحیح تبدیل نشود، نتیجه `nil` خواهد بود.
برای دسترسی به `Int` حاصل از این تبدیل، باید ابتدا آن را «بازگشایی» کرد.

این کار در سوییفت بیشتر با ساختارهای `if-let` و `guard-let` برای [_پیوند اختیاری_][optional-binding] انجام می‌شود که بررسی می‌کنند آیا مقدار `nil` است یا نه؛ اگر مقداری وجود داشته باشد، یک مسیر کد را در پیش می‌گیرند و مقدار بازگشایی‌شده را به اسمی که ارائه شده است می‌بندند، و اگر `nil` باشد، مسیر کد دیگری را در پیش می‌گیرند.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

شایان ذکر است که متغیر `safeNum` نوع `Int` دارد، نه `Int?`.
در مثال زیر، `num` از نوع `Int?` است و `safeNum` از نوع `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

این پیوند اختیاری مهم است، چون نوع اختیاری را از مقدار بازگشایی (یا «حذف») می‌کند و اجازه می‌دهد از آن به عنوان یک مقدار غیراختیاری استفاده شود.
اگر فقط یک بررسی شرطی انجام دهید که آیا مقدار `nil` است یا نه، مقدار همچنان از نوع اختیاری خواهد بود:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

از گزینه‌ی `guard-let` هم می‌توان در مواردی که بازگشت زودهنگام مورد نظر است، استفاده کرد:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## مقایسه‌ی انواع اختیاری

توجه داشته باشید که حتی اگر بتوان نوع پایه‌ی یک جفت نوع اختیاری را با عملگرهای مقایسه‌ی استاندارد مقایسه کرد، خودِ انواع اختیاری را نمی‌توان مقایسه کرد.
تنها می‌توان آن‌ها را از نظر برابری بررسی کرد.
دو نوع اختیاری برابرند اگر هر دو `nil` باشند یا اگر مقدارهایی که در خود می‌پیچند، در نوع پایه‌ی خود برابر باشند.

با این حال، می‌توان کدی نوشت که مقایسه‌ای سفارشی میان دو مقدار اختیاری انجام دهد.
در ادامه، مثالی از یک دستور `switch` آمده است که تنها در صورتی `true` برمی‌گرداند که هر دو مقدار اختیاری غیر `nil` باشند و مقدار اول از مقدار دوم کمتر باشد.
برای این کار از «الگوی اختیاری» `varName?` استفاده می‌کند که تنها با انواع اختیاری غیر `nil` تطبیق پیدا می‌کند و مقدار درون نوع اختیاری را به اسم `varName` می‌بندد.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```

## ادغام `nil`

گزینه‌ی دیگری برای بازگشایی وجود دارد که در آن، اگر `nil` حاضر باشد، می‌توان از یک [مقدار جانشین][fallback] استفاده کرد.
این کار با استفاده از «عملگر ادغام `nil`»، یعنی `??`، انجام می‌شود.
با فرض اینکه `x` از نوع `Int?` باشد، اگر `let y = x ?? 0` را بنویسید، سوییفت بررسی می‌کند که آیا مقدار آن `nil` است.
اگر `nil` نباشد، `x` را بازگشایی می‌کند و مقدار بازگشایی‌شده را به `y` نسبت می‌دهد و اگر `x` واقعاً `nil` باشد، ۰ را به `y` نسبت می‌دهد.

از آنجا که `x ?? y` صرفاً شکل کوتاه `x != nil ? x! : y` است، اگر `x` برابر `nil` نباشد، عبارت `y` اصلاً ارزیابی نمی‌شود.

در پایان، باید توجه داشت که عملگر ادغام `nil` از راست شرکت‌پذیر است و این می‌تواند برای افراد ناآشنا نتایج غافلگیرکننده‌ای در پی داشته باشد.

```swift
let k = 42 ?? 0 + 1    // returns 42
let j = nil ?? 0 + 1   // returns 1
```
