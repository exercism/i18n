# بازگشت

در Crystal، آخرین عبارت در یک متد مقدار خود را برمی‌گرداند.
اما گاهی لازم است پیش از آخرین عبارت مقداری را برگردانید.
برای این کار می‌توانید از کلیدواژه‌ی `return` استفاده کنید که مقدار عبارت بعدی را برمی‌گرداند.
کدی که پس از کلیدواژه‌ی `return` نوشته شود، اجرا نمی‌شود.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
وقتی آخرین عبارت در یک متد همان مقداری است که باید برگردانده شود، باید کلیدواژه‌ی `return` را حذف کرد.
~~~~
