# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] یک عبارت است که یک مقدار برمی‌گرداند.
Pyret فقط یک عبارت را در یک بلوک کد مشخص مجاز می‌داند، مگر اینکه بلوک بیرونی با `block` علامت‌گذاری شده باشد.
در مثال دوم، افزودن `block` به اعلان تابع به ما اجازه می‌دهد تا ۴۲ را پیش از برگرداندن آن چاپ کنیم.

## جاسوس‌ها

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

دستور `spy` یک برچسب اختیاری، یک یا چند متغیر می‌گیرد و هر متغیر و مقدار آن را گزارش می‌دهد.
چون یک عبارت نیست، می‌توان از `spy` در یک بلوک استفاده کرد بدون آنکه لازم باشد بلوک بیرونی با `block` علامت‌گذاری شود.
