# اجرای testها

در ترمینال، به پوشه‌ی اصلی تمرین بروید و سپس testها را با دستور زیر اجرا کنید:

```bash
$ mix test
```

این دستور، فایل test موجود در زیرپوشه‌ی `test` را اجرا می‌کند؛ فایلی که نامش به `_test.exs` ختم می‌شود.

مستندات:

* [`mix test`، ابزار اجرای test در Elixir](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit`، کتابخانه‌ی test واحد در Elixir](https://hexdocs.pm/ex_unit/ExUnit.html)

## testهای در انتظار

در مجموعه testهای تمرین‌های عملی، همه‌ی testها به‌جز test اول طوری برچسب‌گذاری شده‌اند که نادیده گرفته شوند.

وقتی توانستید یک test را با موفقیت پاس کنید، می‌توانید نادیده‌گرفتن test بعدی را لغو کنید؛ کافی است `@tag :pending` مربوط را با نماد `#` کامنت کنید.

برای نمونه:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

اگر می‌خواهید همه‌ی testها را یکجا اجرا کنید، می‌توانید با استفاده از گزینه‌ی `--include` در دستور `mix test` همه‌ی testهای نادیده‌گرفته‌شده را هم به اجرا اضافه کنید:

```bash
$ mix test --include pending
```

یا می‌توانید همه‌ی testها را با کامنت‌کردن خط `ExUnit.configure` در فایل `test/test_helper.exs` فعال کنید.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## گزینه‌های کاربردی `mix test`

* `test/<FILE>.exs:LINENUM`: فقط یک test را اجرا می‌کند؛ یعنی همان test موجود در `<FILE>.exs` که تعریفش در خط `LINENUM` قرار دارد
* `--failed`: فقط testهایی را اجرا می‌کند که در آخرین اجرا شکست خورده‌اند
* `--max-failures`: وقتی تعداد شکست‌ها به این عدد برسد، مجموعه اجرای testها را متوقف می‌کند
* `--seed 0`: تصادفی‌سازی را غیرفعال می‌کند تا testهای یک فایل همیشه به همان ترتیبی اجرا شوند که تعریف شده‌اند
