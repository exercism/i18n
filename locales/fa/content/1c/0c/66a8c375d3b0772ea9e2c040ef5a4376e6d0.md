# مقدمه

در Factor، واژه‌ها را فقط با نوشتن پشت سر هم ترکیب می‌کنید؛ ترتیبی که آن‌ها را می‌نویسید *خودش* شیوه‌ی به هم پیوستن‌شان است. (برنامه‌نویسان به این کار *ترکیب توابع* می‌گویند.) بدنه‌ی یک واژه، خودش توالی‌ای از واژه‌هاست: هر کدام چند مقدار را از پشته مصرف می‌کند و نتیجه‌اش را روی پشته می‌گذارد. واژه‌ی بعدی هم از همان‌جایی ادامه می‌دهد که واژه‌ی قبلی رها کرده بود. پس تعریفِ

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

از پیش *همان* ترکیب `cleanupname`، `first` و `1string` است.

این تمرین همچنین **نقل‌قول** را معرفی می‌کند: قطعه‌ای از کد که می‌توانید آن را به‌عنوان یک مقدار ذخیره کنید و بعداً اجرا کنید، به‌جای اینکه همان‌جا اجرایش کنید.

## نقل‌قول

نقل‌قول قطعه‌کدی است که داخل کروشه قرار می‌گیرد. وقتی نوشته می‌شود اجرا نمی‌شود؛ به‌عنوان یک مقدار روی پشته می‌نشیند:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call` یک نقل‌قول را اجرا می‌کند:

```factor
3 [ 2 * ] call .    ! => 6
```

شما نقل‌قول را وقتی می‌نویسید که لازم باشد کد را به‌عنوان داده بفرستید: تا بعداً اجرا شود، یا به یک *ترکیب‌گر* سپرده شود. ترکیب‌گر واژه‌ای است که یک نقل‌قول را به‌عنوان ورودی می‌گیرد.

## `compose`

`compose ( quot1 quot2 -- combined )` دو نقل‌قول را به هم می‌چسباند و آن‌ها را به همان ترتیبی که نوشته شده‌اند اجرا می‌کند:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

معمولاً می‌بینید که تعریف یک واژه‌ی کوچک با `:` ... `;` خواناتر از `compose` است، اما `compose` وقتی به کار می‌آید که بخواهید نقل‌قول‌ها را همان‌جا بسازید. وقتی اجزای سازنده از قبل نقل‌قول نیستند، `>quotation ( seq -- quot )` (از [`quotations`][quotations]) یک توالی از مقدارها و ارجاع‌های واژه را به یک نقل‌قول قابل فراخوانی تبدیل می‌کند:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## اعمال یک نقل‌قول روی دو ورودی

`bi@ ( x y quot -- ... )` نقل‌قول را روی `x` و دوباره روی `y` اجرا می‌کند و هر دو نتیجه را روی پشته باقی می‌گذارد:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

وظیفه‌ی `couple` در این تمرین دو اسم می‌گیرد؛ `bi@` طبیعی‌ترین راه برای اعمال `initial` روی هرکدام است.

## چند واژه‌ی رشته‌ای

این تمرین به چند واژه‌ی کوچک رشته‌ای نیاز دارد که از سه واژگان [`sequences`][sequences]، [`ascii`][ascii] و [`strings`][strings] می‌آیند:

- `replace ( seq old new -- new-seq )` (در `splitting`): جایگزینی زیررشته.
- `[ blank? ] trim` (`trim` در `sequences`، `blank?` در `ascii`): حذف فاصله‌های ابتدایی و انتهایی.
- `1string ( char -- str )` (در `strings`): درآوردن یک کاراکتر به‌صورت یک رشته.
- `>upper ( str -- upper )` (در `ascii`): تبدیل یک رشته به حروف بزرگ.
- `append ( s1 s2 -- s )` (در `sequences`): به هم چسباندن دو رشته.
- `prepend ( s1 s2 -- s )` (در `sequences`): به هم چسباندن `s2` و سپس `s1` (`append` با ورودی‌هایی در ترتیب برعکس).
- `glue ( s1 s2 sep -- s )` (در `sequences`): به هم چسباندن دو رشته با یک جداکننده میان آن‌ها.
- `surround ( seq pre post -- new )` (در `sequences`): پیچیدن یک رشته در یک پیشوند و یک پسوند.

کاراکترهای یونیکد را می‌توان داخل یک رشته به‌صورت `\u{XXXX}` نوشت، که در آن `XXXX` کدپوینت به مبنای ۱۶ است. قلب `\u{2764}` (❤) در این تمرین ظاهر می‌شود.

## خروجی قالب‌بندی‌شده

وقتی `append`/`glue`/`surround` به‌اندازه‌ی کافی رسا نیستند، [`formatting`][formatting] یک `sprintf` به سبک printf را فراهم می‌کند:

```
sprintf ( inputs... format-string -- str )
```

`%s` یک رشته را جای‌گذاری می‌کند، `%d` یک عدد صحیح، `%f` یک عدد اعشاری؛ اصلاح‌کننده‌های اختیاری عرض، دقت و پرکردن بین `%` و حرف نوع می‌آیند:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

برای تبدیل رفت‌وبرگشتی میان اعداد و رشته‌ها، [`math.parser`][math.parser] دو واژه‌ی `number>string` و `string>number` را دارد:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
