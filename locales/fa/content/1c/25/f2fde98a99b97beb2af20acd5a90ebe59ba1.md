# مقدمه

اغلب مفید است که مجموعه‌ای از عنصرها را کنار هم گروه‌بندی کنیم و با این گروه‌ها به‌عنوان واحدهایی یکپارچه برخورد کنیم.
در Cairo، به چنین گروهی `struct` می‌گوییم و به هر عنصر، یکی از «فیلد»های آن `struct`.
یک `struct` مجموعه‌ی کلی فیلدهای موجود را تعریف می‌کند، اما به یک نمونه‌ی مشخص از آن، «نمونه» می‌گوییم.

علاوه بر این، می‌توان روی `struct`ها «متد»هایی تعریف کرد که به فیلدها دسترسی دارند.
در این حالت، خودِ `struct` با نام `self` شناخته می‌شود.
وقتی یک متد از `ref self: SomeStruct` استفاده می‌کند، فیلدها قابل تغییرند، یعنی می‌توان آن‌ها را تغییر داد.
وقتی یک متد از `self: SomeStruct` یا `self: @SomeStruct` استفاده می‌کند، فیلدها قابل تغییر نیستند: آن‌ها تغییرناپذیرند.
کنترل تغییرپذیری به borrow-checker کمک می‌کند تا مطمئن شود که کلاس‌های کاملی از باگ‌های هم‌روندی در Cairo اصلاً رخ نمی‌دهند.

در این تمرین، دو نوع متد را روی یک `struct` پیاده‌سازی می‌کنید.
نوع اول که معمولاً «گیرنده» نامیده می‌شود، فیلدهای `struct` را در دسترس دیگران قرار می‌دهد، بدون اینکه بگذارد کس دیگری آن مقدار را تغییر دهد.

همچنین متدهایی از نوع دیگر را پیاده‌سازی می‌کنید که معمولاً «تنظیم‌کننده» نامیده می‌شوند.
این‌ها مقدار فیلد را تغییر می‌دهند.
تنظیم‌کننده‌ها در Cairo چندان رایج نیستند؛ اگر بتوان فیلدی را آزادانه تغییر داد، معمولاً آن را عمومی می‌کنیم.
اما اگر به‌روزرسانی فیلد باید عوارض جانبی داشته باشد، این متدها مفیدند.

`struct`ها با «کلیدواژه»ی `struct` تعریف می‌شوند و پس از آن، نام نوعی می‌آید که این `struct` توصیف می‌کند، با حرف اول بزرگ:

```rust
struct Item {}
```

سپس انواع دیگری به‌عنوان _فیلدهای_ `struct` به بدنه‌ی آن آورده می‌شوند، هرکدام با نوع خودشان:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

یک `trait` مجموعه‌ای از متدها را تعریف می‌کند که یک نوع می‌تواند پیاده‌سازی‌شان کند (اینجا روی `struct`ها تمرکز می‌کنیم، اما `trait`ها را می‌توان روی `enum`ها هم پیاده‌سازی کرد).
وقتی این `trait` پیاده‌سازی شد، می‌توان این متدها را روی نمونه‌های آن نوع فراخوانی کرد.
`trait`ها با کلیدواژه‌ی `trait` تعریف می‌شوند و درون آن‌ها امضای متدهایی را تعریف می‌کنیم که می‌خواهیم نوع‌مان پیاده‌سازی کند.

```rust
trait ImplTrait {
    // Define the method signature
    fn new() -> Item;
}
```

در پایان، می‌توان متدها را روی `struct`ها درون یک «بلوک» `impl` تعریف کرد که `trait` تعریف‌شده را پیاده‌سازی می‌کند:

```rust
impl ItemImpl of ImplTrait {
    // initializes and returns a new instance of our Item struct
    fn new() -> Item {
        Item {}
    }
}
```
