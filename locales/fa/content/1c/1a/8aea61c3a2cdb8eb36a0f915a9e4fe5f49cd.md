# دستورالعمل‌ها

یک «سه‌گانه‌ی فیثاغورسی» مجموعه‌ای از سه عدد طبیعی است، {a, b, c}، که در آن

```text
a² + b² = c²
```

و به گونه‌ای که

```text
a < b < c
```

برای مثال،

```text
3² + 4² = 5².
```

اگر یک عدد صحیح ورودی مانند `N` داده شود، همه‌ی سه‌گانه‌های فیثاغورسی را پیدا کنید که در آن‌ها `a + b + c = N` باشد.

برای مثال، با `N` برابر با ۱۰۰۰، دقیقاً یک سه‌گانه‌ی فیثاغورسی وجود دارد که در آن `a + b + c = 1000` است: `{200, 375, 425}`.
