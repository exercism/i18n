# دستورالعمل‌ها

شما یک پرنده‌نگر مشتاق هستید و پیگیری می‌کنید که در هفت روز گذشته چند پرنده از باغ‌تان بازدید کرده‌اند.

شما پنج کار دارید که همه‌شان به تعداد پرنده‌هایی مربوط می‌شوند که از باغ‌تان بازدید کرده‌اند.

## 1. بررسی کنید شمارش‌های هفته‌ی گذشته چه بوده‌اند

شمارش‌های پرنده‌هایتان را در قالب JSON ذخیره می‌کنید.
یک آرایه‌ی «اصلی» آرایه‌هایی از شمارش‌های هفتگی را در خود جای می‌دهد.
هر شمارش هفتگی آرایه‌ای از هفت عدد صحیح است؛ یک عدد برای هر روز هفته.
شما همیشه هفته‌های جدید را به انتهای آرایه‌ی اصلی اضافه می‌کنید.
یک «فیلتر» پیاده‌سازی کنید که شمارش‌های هفته‌ی گذشته را برمی‌گرداند.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. بررسی کنید دیروز چند پرنده بازدید کرده‌اند

فیلتر را طوری پیاده‌سازی کنید که تعداد پرنده‌هایی را که دیروز از باغ‌تان بازدید کرده‌اند برگرداند.
شمارش‌های پرنده‌ها بر اساس روز مرتب شده‌اند؛ اولین عنصر شمارش قدیمی‌ترین روز است و آخرین عنصر شمارش امروز.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. تعداد کل پرنده‌های بازدیدکننده را محاسبه کنید

فیلتر را طوری پیاده‌سازی کنید که تعداد کل پرنده‌هایی را که این هفته از باغ‌تان بازدید کرده‌اند برگرداند.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. تعداد روزهای شلوغ را محاسبه کنید

بعضی روزها شلوغ‌تر از بقیه هستند.
روز شلوغ روزی است که پنج پرنده یا بیشتر از باغ‌تان بازدید کرده باشند.
فیلتر را طوری پیاده‌سازی کنید که تعداد روزهای شلوغ این هفته را برگرداند.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. بررسی کنید آیا روزی بوده است که هیچ پرنده‌ای بازدید نکرده باشد

فیلتر را طوری پیاده‌سازی کنید که اگر این هفته روزی بوده باشد که هیچ پرنده‌ای از باغ بازدید نکرده است، `true` را برگرداند؛ در غیر این صورت، `false` را برگرداند.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
