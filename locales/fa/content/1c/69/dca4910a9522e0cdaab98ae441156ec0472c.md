# مقدمه

نوع `char` در F# مقداری ۱۶ بیتی است که کوچک‌ترین اجزای آدرس‌پذیر متن را نمایش می‌دهد و به‌طور پیش‌فرض تغییرناپذیر است.

`char`ها را می‌توان با گیومه‌ی تک به‌صورت مقدار ثابت تعریف کرد:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

رشته‌ها دنباله‌ای از `char`ها هستند.

یک `char` تکی را می‌توان با اندیس‌گذاری (که از صفر شروع می‌شود) از یک رشته بیرون کشید:

```fsharp
"Exercism"[4] //  =>  'c'
```

پیمایش یک رشته در هر گام یک `char` برمی‌گرداند.

مثال بعدی برای راحتی از یک تابع مرتبه‌بالا و یک تابع بی‌نام استفاده می‌کند.
این‌ها بعداً در برنامه‌ی درسی به‌طور کامل بررسی می‌شوند، اما فعلاً روشی مختصر برای نوشتن حلقه‌ای روی `char`های یک رشته به دست می‌دهند.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

همان‌طور که در بالا نشان داده شد، می‌توان یک `char` را به مقدار `int` آن تبدیل کرد.
این کار (*حداقل در برخی موارد*) برای سایر سیستم‌های نوشتاری هم صدق می‌کند:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

هنگام مقایسه‌ی `char`ها از Int16 زیربنایی استفاده می‌شود:

```fsharp
'A' < 'D'  // =>  true
```

همچنین می‌توان یک `int` را به `char` تبدیل کرد:

```fsharp
char 77  // => 'M'
```

کتابخانه‌ی `System.Char` مجموعه‌ی کاملی از متدها را دارد که از یک زبان .NET انتظار می‌رود، مانند تبدیل به حروف بزرگ/کوچک:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
