# مقدمه

**توابع بازگشتی** توابعی هستند که خودشان را فراخوانی می‌کنند.

یک _تابع بازگشتی_ باید حداقل یک _حالت پایه_ و حداقل یک _حالت بازگشتی_ داشته باشد.

**حالت پایه** مقداری را بدون فراخوانی دوباره‌ی تابع برمی‌گرداند.
**حالت بازگشتی** تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت کند.

مثالی می‌آوریم که عناصر یک آرایه را می‌شمارد.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

یک _تابع بازگشتی_ می‌تواند چندین _حالت پایه_ و/یا چندین _حالت بازگشتی_ داشته باشد.
برای نمونه [دنباله‌ی فیبوناچی][wiki-fibonacci] یک دنباله‌ی بازگشتی با دو _حالت پایه_ است.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

شمردن تعداد تکرارهای یک مقدار مشخص مانند `x` در یک فهرست، دو _حالت بازگشتی_ دارد.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

در عمل، پیمایش فهرست‌ها و دیگر ساختارهای داده‌ی قابل شمارش بیشتر با توابع داخلی انجام می‌شود،
مانند `map` و `reduce`، یا با [استفاده از جریان‌ها][map-implementation] مثل `[.[] | select(...)]`.
در پشت‌صحنه، برخی از این توابع داخلی [با استفاده از بازگشت پیاده‌سازی شده‌اند][walk-implementation].
