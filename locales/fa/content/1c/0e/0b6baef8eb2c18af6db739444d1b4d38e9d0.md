# درباره

[Nil][nil-dictionary] واژه‌ای است در زبان انگلیسی، به معنای «هیچ» یا «صفر». در Elixir، `nil` یک مقدار ویژه است که نشان‌دهنده‌ی _نبودِ_ یک مقدار است.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` یک «اتم» است، اما معمولاً به صورت `nil` نوشته می‌شود، نه `:nil`. مقادیر منطقی `true` و `false` هم اتم هستند.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

می‌توانید بررسی کنید که آیا مقدار یک متغیر `nil` است یا نه، با استفاده از [`==`][kernel-equal]، یا با تطبیق الگو، یا با استفاده از [گارد `is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
