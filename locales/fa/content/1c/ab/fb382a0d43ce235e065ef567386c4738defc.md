# پیوست دستورالعمل‌ها

## صبر کنید، غیرممکن است!

پیاده‌سازی این عملیات فهرست بدون استفاده از _هیچ_ تابع توکاری در Roc عملاً غیرممکن است، چون باید راهی داشته باشید که با آن عناصر را به انتهای یک فهرست یا ابتدای آن اضافه کنید.
در زبان‌های دیگر ممکن است از عملگرهایی مانند `:` در Haskell یا `+=` در Python استفاده کنید، اما در Roc باید از [توابع `List`](https://www.roc-lang.org/builtins/main/#Builtin.List) استفاده کنید.

پس برای این تمرین اجازه دارید از `List.append` استفاده کنید (اما از به کار بردن هر تابع توکار دیگری خودداری کنید).

بسیاری از زبان‌های برنامه‌نویسی تابعی از «فهرست‌های پیوندی» به عنوان نوع مجموعه‌ی اصلی استفاده می‌کنند.
افزودن یک عنصر به ابتدای یک فهرست پیوندی یا برداشتن اولین عنصر از آن کارآمد است، بنابراین در آن زبان‌ها عملیات فهرست را با `List.prepend` پیاده‌سازی می‌کنید.
اما در Roc، یک `List` یک «آرایه» است (تکه‌ای پیوسته از بایت‌ها).
آرایه‌ها ویژگی‌هایی متفاوت از فهرست‌های پیوندی دارند، مانند توانایی دسترسی کارآمد به عناصر از طریق اندیس و افزودن عناصر جدید.
به همین دلیل، در Roc اغلب از `List.append` استفاده می‌کنیم و به ندرت از `List.prepend` استفاده می‌کنیم.

## اسم‌گذاری

Roc از اسم‌هایی استفاده می‌کند که کمی با اسم‌های آمده در دستورالعمل‌های کلی تفاوت دارند:

- `concat` به جای `append`
- `join` به جای `concatenate`
- `len` به جای `length`
- `fold` به جای `foldl`
- `fold_rev` به جای `foldr`

با این حال، اسم‌های توابع زیر در Roc استاندارد هستند:
- `filter`
- `map`
- `reverse`

## راهنمایی

این را امتحان کنید:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

یا

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
