# پیوست دستورالعمل‌ها

## امتیاز

تابع‌تان را روی این رشته امتحان کنید: `uüu` و ببینید چه اتفاقی می‌افتد.
سعی کنید تابعی بنویسید که این رشته را به‌درستی معکوس کند.
راهنمایی: خوشه‌های گرافیمی

برای اینکه تست امتیاز اجرا شود، پرچم نادیده‌گرفتن (`#[ignore]`) را از آخرین تست بردارید و تست‌ها را با این دستور اجرا کنید:

```bash
cargo test --features grapheme
```

برای انجام این بخش امتیاز، باید از کتابخانه‌های خارجی (در اصطلاح Rust، یک `crate`) استفاده کنید.
جای خوبی برای جست‌وجوی آن‌ها [crates.io](https://crates.io/) است، مخزن رسمی crateها.
لطفاً به یاد داشته باشید که تست‌رانر ما فقط از مجموعه‌ی محدودی از crateها پشتیبانی می‌کند.
فهرست کامل در [این فایل](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) زیر بخش `[dependencies]` آمده است.

برای دستورالعمل‌های استفاده از crateهای خارجی در پروژه‌هایتان، [مستندات را ببینید](https://doc.rust-lang.org/cargo/guide/dependencies.html).
