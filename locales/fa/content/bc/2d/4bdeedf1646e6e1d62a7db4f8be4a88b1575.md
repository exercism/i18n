# راهنمایی

## کلیات

- سه عملگر «منطقی» برای کار با مقادیر منطقی وجود دارد: `not`، `&&` و `||`.
- می‌توان چند عملگر را در یک عبارت با هم ترکیب کرد.

## 1. تعیین کنید که آیا پکمن می‌تواند یک روح را بخورد

- تابع باید یک مقدار `Bool` برگرداند.
- می‌توانید از عملگر منطقی `&&` برای ترکیب آرگومان‌ها و رسیدن به نتیجه استفاده کنید.

## 2. تعیین کنید که آیا پکمن امتیاز می‌گیرد

- تابع باید یک مقدار `Bool` برگرداند.
- می‌توانید از عملگر منطقی `||` برای ترکیب آرگومان‌ها و رسیدن به نتیجه استفاده کنید.

## 3. تعیین کنید که آیا پکمن می‌بازد

- تابع باید یک مقدار `Bool` برگرداند.
- می‌توانید از عملگرهای منطقی `&&` و `not` برای ترکیب آرگومان‌ها و رسیدن به نتیجه استفاده کنید.

## 4. تعیین کنید که آیا پکمن می‌برد

- تابع باید یک مقدار `Bool` برگرداند.
- می‌توانید از عملگرهای منطقی `&&` و `not` برای ترکیب آرگومان‌ها و نتیجه‌ی یکی از توابعی که قبلاً پیاده‌سازی کرده‌اید استفاده کنید.
