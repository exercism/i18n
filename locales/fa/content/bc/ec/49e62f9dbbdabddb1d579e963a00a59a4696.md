# کمک

اگر در کاری به مشکل خوردید و به کمک نیاز داشتید، می‌توانید از یکی از منابع زیر استفاده کنید:

- [TypeScript QuickStart](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [ECMAScript 2015 Language Specification](https://www.ecma-international.org/wp-content/uploads/ECMA-262_6th_edition_june_2015.pdf) (pdf)
- [Mozilla JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
- [/r/typescript](https://www.reddit.com/r/typescript) ساب‌ردیت TypeScript است.
- از [StackOverflow](https://stackoverflow.com/questions/tagged/typescript) می‌توانید برای جست‌وجوی مشکلتان و دیدن اینکه پیش‌تر به آن پاسخ داده شده است یا نه استفاده کنید. همچنین می‌توانید پرسش بپرسید و به پرسش‌ها پاسخ دهید.
