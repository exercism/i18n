# مقدمه

«تاپل» دسته‌بندی _تغییرناپذیری_ از مقادیر بی‌نام اما مرتب است.
تاپل‌ها می‌توانند هر نوع داده (یا چند نوع داده) را در خود نگه دارند؛ از جمله تاپل‌های دیگر.

تاپل‌ها به‌صورت مقادیری جداشده با کاما بین نویسه‌های `(` و `)` تعریف می‌شوند: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

فقط تاپل‌هایی را می‌توان مقایسه کرد که طول یکسان و نوع‌های یکسان (با ترتیب یکسان) داشته باشند.
تاپل‌ها برابری ساختاری دارند، یعنی _تنها_ وقتی برابرند که همه‌ی مقدارهایشان برابر باشند.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

سه راه برای استخراج مقدارها از یک تاپل وجود دارد:

- توابع `fst` و `snd`
- ساختارشکنی تاپل
- تطبیق الگو

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
