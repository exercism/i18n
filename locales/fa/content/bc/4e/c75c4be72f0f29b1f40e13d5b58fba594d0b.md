# ترازو

## داستان

در این تمرین یک ترازو را مدل‌سازی می‌کنید.

وزن را می‌توان بر حسب پوند یا کیلوگرم تنظیم و بازیابی کرد و این وزن نمی‌تواند منفی باشد.

وزن را می‌توان بر حسب یکاهای SI یا یکاهای آمریکایی، یعنی پوند و اونس، نمایش داد.

می‌توان روی وزن یک تنظیم تار اعمال کرد (مثلاً برای کسر کردن وزن یک ظرف). این مقدار می‌تواند هر مقداری باشد (حتی منفی، یا مقداری که وزن نمایش‌داده‌شده را منفی می‌کند)، چون در دقت ترازو تردید وجود دارد. به دلایل امنیتی، این مقدار قابل بازیابی نیست.

توجه کنید که:

```
display-weight = input-weight - tare-adjustment
```

نسبت‌های تبدیل از این قرارند:

- ۱۶ اونس برابر یک پوند
- ۲٫۲۰۴۶۲ کیلوگرم برابر یک پوند

برای نمونه:

- ۶۰ کیلوگرم == ۱۳۲٫۲۷۷۲ پوند
- ۱۳۲٫۲۷۷۲ پوند == ۱۳۲ پوند و ۴ اونس

## کارها

این‌ها نمونه‌ی کارهایی هستند که در تمرین ترازو جا می‌گیرند:

- امکان تنظیم وزن روی ترازو را فراهم کنید
- مطمئن شوید که وزن ورودی منفی رد می‌شود
- امکان بازیابی وزن بر حسب یکاهای آمریکایی را فراهم کنید
- امکان تنظیم یکاهای ترازو روی پوند را فراهم کنید
- امکان اعمال تنظیم تار روی ترازو را فراهم کنید
