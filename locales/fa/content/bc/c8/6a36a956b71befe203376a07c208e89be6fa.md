# مقدمه

Unison مقادیر «درست» و «غلط» را با نوع `Boolean` نمایش می‌دهد. فقط دو مقدار وجود دارد: `true` و `false`.

```unison
trueVariable = true
falseVariable = false
```

می‌توانیم عبارت‌های منطقی را با عملگرهای and که با `&&` نمایش داده می‌شود، or که با `||` نمایش داده می‌شود، و not که با `not` نمایش داده می‌شود ارزیابی کنیم.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

عبارت‌های منطقی در Unison از ارزیابی کوتاه پشتیبانی می‌کنند: اگر اولین آرگومان یک عبارت `&&` برابر `false` باشد، دلیلی برای ادامه‌ی ارزیابی آرگومان دوم وجود ندارد. به همین ترتیب، اگر اولین آرگومان یک عبارت `||` برابر `true` باشد، عبارت بلافاصله `true` را برمی‌گرداند.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
