# مقدمه

## توابع بی‌نام

Gleam «توابع درجه‌اول» دارد؛ یعنی توابع مقادیر معمولی‌اند که می‌توان آن‌ها را به متغیرها اختصاص داد، به‌عنوان آرگومان پاس داد و از توابع دیگر برگرداند.

می‌توان به تابعی که در یک ماژول تعریف شده و اسم دارد، با اسمش ارجاع داد.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam همچنین توابع بی‌نام دارد که درون توابع دیگر تعریف می‌شوند.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

نوع یک تابع با نحوه‌ی نگارشی مشابه توابع بی‌نام نوشته می‌شود. نوع تابعی که یک `Int` و یک `Float` می‌گیرد و یک `Int` برمی‌گرداند، به این شکل نوشته می‌شود:

```gleam
fn(Int, Float) -> Int
```

توابع بی‌نام می‌توانند به متغیرهایی ارجاع دهند که هنگام تعریف آن‌ها در محدوده بودند و همین آن‌ها را به _«بستار»_ تبدیل می‌کند.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

نحوه‌ی نگارش _«گرفتن تابع»_ شکل کوتاه مناسبی برای ساختن توابع بی‌نامی فراهم می‌کند که یک آرگومان را به یک تابع پاس می‌دهند. این دو عبارت معادل هستند:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
