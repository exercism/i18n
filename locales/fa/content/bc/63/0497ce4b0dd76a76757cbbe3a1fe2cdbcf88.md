# پیوست دستورالعمل‌ها

## پیاده‌سازی

فهرست شما باید این «رابط» را نیز پیاده‌سازی کند:

- `delete` (حذف اولین وقوع یک مقدار مشخص)
- `count` (شمارش تعداد عنصرهای فهرست)

**توجه**: برای پیاده‌سازی این تمرین از یک کتابخانه استفاده _نکنید_. برای پیاده‌سازی این تمرین از یک آرایه‌ی پشتیبان استفاده _نکنید_.
