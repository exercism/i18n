# درباره

در Elixir دو نوع متفاوت عدد وجود دارد: «عدد صحیح» و «عدد اعشاری».

عدد صحیح، عددی کامل است.

```elixir
integer = 3
# => 3
```

چند تابع مفید برای کار با اعداد صحیح در ماژول [`Integer`][integer] وجود دارد.

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

اعداد صحیح بزرگ (و همچنین اعداد اعشاری) معمولاً با جدا کردن هر ۳ رقم در گروه‌هایی که با زیرخط از هم جدا شده‌اند قالب‌بندی می‌شوند.

```elixir
1_000_000
# => 1000000
```

حداکثر اندازه‌ی اعداد در Elixir فقط با حافظه‌ی موجود روی سیستم محدود می‌شود، چون Elixir از [محاسبات با دقت دلخواه][arbitrary-precision-arithmetic] استفاده می‌کند.

Elixir همچنین از شکل‌های کوتاه برای نوشتن [اعداد صحیح دودویی، هشت‌دهی و شانزده‌دهی][integers-in-other-bases] پشتیبانی می‌کند.

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## مقایسه

اگر اعداد صحیح و اعشاری مقدار یکسانی داشته باشند، می‌توان آن‌ها را برابر ([`==`][kernel-equal]) در نظر گرفت. اما چون از دو نوع متفاوت‌اند، هرگز به‌طور دقیق برابر ([`===`][kernel-strictly-equal]) نیستند.

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
