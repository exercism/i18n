# مقدمه

یک عبارت `switch` می‌تواند یک مقدار را با یک «حالت» در مجموعه‌ای از «الگوها» تطبیق دهد و مقدار مرتبط را برگرداند یا اقدام مرتبط را انجام دهد. این ارتباط با نماد `=>` نشان داده می‌شود. علاوه بر این، هر الگو می‌تواند یک «محافظ حالت» اختیاری داشته باشد که با کلیدواژه‌ی `when` معرفی می‌شود. عبارت محافظ حالت باید به «درست» ارزیابی شود تا آن «بازو» از `switch` انتخاب شود. حالت‌ها (که با نام _«بازوهای `switch`»_ هم شناخته می‌شوند) به ترتیب متن ارزیابی می‌شوند و به محض یافتن تطابق، فرایند متوقف می‌شود و مقدار مرتبط برگردانده می‌شود.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
