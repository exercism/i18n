# مجوزهای مخزن نگهدارندگان

نگهدارنده‌ی track به کسی گفته می‌شود که عضو تیم GitHub آن track باشد.
عضو شدن در تیم یک track _تنها با دعوت_ امکان‌پذیر است.

```exercism/note
اگر می‌خواهید نگهدارنده‌ی یک track شوید، لطفاً موضوعی را در [انجمن](https://forum.exercism.org/c/exercism/building-exercism/125) باز کنید.
```

## دسته‌بندی نگهداری

پنج دسته‌بندی نگهداری وجود دارد:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

دسته‌بندی نگهداری یک track با سه متغیر تعیین می‌شود:

1. این که track فعال باشد یا نه (یعنی دانش‌آموزان بتوانند در وب‌سایت به آن track بپیوندند)
2. تعداد نگهدارندگان track
3. تعداد نگهدارندگانی که در تیم GitHub `cross-track-maintainers` هم عضو هستند

برای تعیین دسته‌بندی نگهداری، اولین دسته‌بندی‌ای را که در جدول زیر با آن track مطابقت دارد پیدا کنید:

| دسته‌بندی            | فعال؟ | تعداد نگهدارندگان | تعداد نگهدارندگان cross-track |
| --------------------- | ------- | --------------------- | --------------------------------- |
| wip-track             | خیر     | هر تعداد              | هر تعداد                          |
| unmaintained          | بله     | ۰                     | ۰                                 |
| maintained-autonomous | بله     | بیشتر از ۰            | برابر با تعداد نگهدارندگان        |
| maintained-solitary   | بله     | ۱                     | ۰                                 |
| maintained            | بله     | بیشتر از ۱            | کمتر از تعداد نگهدارندگان         |

## مجوزهای مخزن

از دسته‌بندی نگهداری برای تعیین مجوز مخزن‌های GitHub مربوط به track استفاده می‌شود.

| دسته‌بندی            | نیاز به PR | نیاز به تأیید PR | بازبینی تیم cross-track |
| --------------------- | ----------- | -------------------- | ------------------------ |
| wip-track             | خیر         | خیر                  | خیر                      |
| unmaintained          | بله         | بله                  | بله                      |
| maintained-solitary   | بله         | بله                  | بله                      |
| maintained-autonomous | بله         | خیر                  | خیر                      |
| maintained            | بله         | خیر                  | خیر                      |

```exercism/caution
دسته‌بندی `wip-track` تنها دسته‌بندی‌ای است که به نگهدارندگان اجازه می‌دهد روی `main` پوش کنند.
```

```exercism/caution
مخزن‌های ابزاری _همیشه_ به تأیید PR نیاز دارند، زیرا محتوای آن‌ها با یک [فایل CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) محافظت می‌شود.
```
