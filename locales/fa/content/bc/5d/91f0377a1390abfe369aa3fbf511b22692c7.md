# رشته

**«رشته»** تکه‌ای از متن است. نوع سادر برای آن `STR` است و رشته را بین دو گیومه می‌نویسند.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## به هم چسباندن رشته‌ها

`+` دو رشته را پشت سر هم به هم می‌چسباند.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

بین آن دو هیچ چیزی گذاشته نمی‌شود، پس فاصله را باید جداگانه درخواست کرد. اگر آن را جا بیندازید، `"JeanSibelius"` به دست می‌آید.

## طول آن چقدر است؟

`.size` تعداد نویسه‌هایی است که یک رشته در خود جا می‌دهد. این یک عدد صحیح است، پس نوع آن `INT` است.

```sather
"Sibelius".size      -- 8
```

بعد از `.size` پرانتزی نمی‌آید، درست مثل روالی که هیچ آرگومانی نمی‌گیرد.

## برداشتن یک تکه

`.head(n)` اولین `n` نویسه است. `.tail(n)` آخرین `n` نویسه است.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` از ابتدا می‌شمارد و `tail` از انتها. هر دو رشته‌ی اصلی را دست‌نخورده رها می‌کنند و یک رشته‌ی تازه برمی‌گردانند.
