# معرفی

در Haxe میتوان یک سلسلهمراتب کلاس را با «ارثبری» تعریف کرد. ارثبری به یک کلاس مشتقشده (`Car`) اجازه میدهد رفتار و دادههای کلاس والدش (`Vehicle`) را به ارث ببرد.

در کلاس والد میتوانید:

- متدهایی تعریف کنید که میتوان آنها را `override` کرد
- متدهای `abstract` را تعریف کنید که کلاسهای مشتقشده باید پیادهسازی کنند

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

اگر کلاس والد سازنده داشته باشد، برای فراخوانی آن از `super()` استفاده میکنیم:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
