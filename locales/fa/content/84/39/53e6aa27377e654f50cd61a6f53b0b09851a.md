# دستورالعمل‌ها

در این تمرین قرار است به دلدادگان دبیرستانی کمک کنید تا عشقشان را در شبکه‌های اجتماعی ابراز کنند و با حرف اول اسمشان یک قلب ASCII بسازند:

```
❤ J.  +  M. ❤
```

## 1. پاک‌سازی اسم

متد `HighSchoolSweetheart.clean_up_name` را پیاده‌سازی کنید.
این متد باید یک اسم بگیرد و همه‌ی کاراکترهای `-` را از آن حذف کند و با یک فاصله جایگزین کند.
همچنین باید فضای خالی ابتدا و انتهای اسم را هم حذف کند.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. گرفتن حرف اول اسم

متد `HighSchoolSweetheart.first_letter` را پیاده‌سازی کنید.
این متد باید یک اسم بگیرد و حرف اول آن را برگرداند.
حتماً از `HighSchoolSweetheart.clean_up_name` که در مرحله‌ی قبلی تعریف کردید دوباره استفاده کنید.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. قالب‌بندی حرف اول به شکل سرواژه

متد `HighSchoolSweetheart.initial` را پیاده‌سازی کنید.
این متد باید یک اسم بگیرد و حرف اول آن را بزرگ و همراه با یک نقطه در ادامه‌اش برگرداند.
حتماً از `HighSchoolSweetheart.first_letter` که در مرحله‌ی قبلی تعریف کردید دوباره استفاده کنید.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. قرار دادن سرواژه‌ها داخل قلب

متد `HighSchoolSweetheart.pair` را پیاده‌سازی کنید.
این متد باید دو اسم بگیرد و سرواژه‌ها را همراه با قلب‌های ایموجی در اطرافش برگرداند.
حتماً از `HighSchoolSweetheart.initial` که در مرحله‌ی قبلی تعریف کردید دوباره استفاده کنید.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
