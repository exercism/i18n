# مبانی

## شروع به کار

### متغیر

برای تعریف [متغیر][variables] از عملگر انتساب `=` استفاده کنید.
در Crystal، متغیر باید از قالب [snake_case][snake-case] پیروی کند.

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### ثابت

[ثابت][constants] با همان عملگر انتساب `=` تعریف می‌شود، اما از حروف بزرگی استفاده می‌کند که با نام SCREAMING_SNAKE_CASE شناخته می‌شود.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

انتساب یک مقدار به ثابتی که قبلاً تعریف شده است، به خطای زمان کامپایل منجر می‌شود.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### نوع داده

Crystal یک زبان کامپایل‌شده است، یعنی به هر متغیر یا آرگومان متد در زمان کامپایل یک نوع داده نسبت داده می‌شود.
کامپایلر می‌تواند نوع یک متغیر یا آرگومان متد را استنتاج کند.
اما در برخی موارد، مشخص کردن نوع داده لازم است.
مواردی که نیاز به تعیین نوع داده دارند، در مفاهیم بعدی توضیح داده می‌شوند.

### متد

[متد][methods] روشی برای گروه‌بندی مجموعه‌ای از دستورهاست که می‌توان دوباره از آن استفاده کرد.
در Crystal، متدها معمولاً درون یک کلاس، ماژول یا ساختار تعریف می‌شوند.
اما متد می‌تواند بیرون از یک کلاس، ماژول یا ساختار هم تعریف شود.
متدها با کلیدواژه‌ی `def` و سپس اسم متد تعریف می‌شوند.
در Crystal، متد باید با snake_case نوشته شود.
وقتی متد هیچ آرگومانی ندارد، می‌توانید پرانتز را حذف کنید.
برای مشخص کردن پایان متد، باید از کلیدواژه‌ی `end` استفاده کنید.

```crystal
def hello
  puts "Hello World!"
end
```

استفاده از متدی که برای نوع متغیر یا آرگومان متد وجود ندارد، به خطای زمان کامپایل منجر می‌شود.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### آرگومان

متد می‌تواند [آرگومان][arguments] داشته باشد.
آرگومان‌ها داده‌هایی هستند که به متد داده می‌شوند.
برای اینکه بتوانید به متد آرگومان بدهید، باید اسم آرگومان را مشخص کنید.
در Crystal، آرگومان باید با snake_case نوشته شود.
یک متد می‌تواند چندین آرگومان داشته باشد، اما باید آرگومان‌ها را با ویرگول از هم جدا کنید.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

متد می‌تواند چندین آرگومان داشته باشد.
در این حالت، آرگومان‌ها باید با ویرگول از هم جدا شوند.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### فراخوانی متد

وقتی متدی را فراخوانی می‌کنید که به یک کلاس، ماژول یا ساختار تعلق دارد، باید از عملگر نقطه (`.`) استفاده کنید.
قالب آن باید به این صورت باشد: `<ClassName>.<method_name>`.
وقتی متدی به کلاس، ماژول یا ساختاری تعلق ندارد، کافی است آن را با نوشتن اسمش فراخوانی کنید.
متدها همیشه به‌صورت ضمنی مقدار آخرین عبارت را برمی‌گردانند.

وقتی متد آرگومان دارد، می‌توانید هنگام مشخص کردن آرگومان‌ها در فراخوانی و تعریف متد از پرانتز استفاده کنید، به این صورت: `<method_name>(<argument_1>, <argument_2>, ...)`.
وقتی متد هیچ آرگومانی ندارد، باید پرانتز را حذف کنید.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

وقتی متدی را با چندین آرگومان فراخوانی می‌کنید، باید آرگومان‌ها را با ویرگول از هم جدا کنید.
آرگومان‌ها باید به همان ترتیبی داده شوند که در تعریف متد آمده‌اند.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

فراخوانی متد با تعداد نادرست آرگومان به خطای زمان کامپایل منجر می‌شود.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### جمع، تفریق و ضرب

در Crystal، می‌توانید با عملگر `+` دو عدد را با هم جمع کنید.
همچنین می‌توانید با عملگر `-` دو عدد را از هم کم کنید.
و می‌توانید با عملگر `*` دو عدد را در هم ضرب کنید.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### توضیح

در Crystal، [توضیحات][comments] با نویسه‌ی `#` نوشته می‌شوند، که پس از آن یک فاصله و سپس متن توضیح می‌آید.
از توضیحات برای مستندسازی کد استفاده می‌شود.
کامپایلر توضیحات را اجرا نمی‌کند.

```crystal
# This is a comment
```
