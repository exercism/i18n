# پیوست دستورالعمل‌ها

## قالب ورودی

هر دومینو به‌صورت یک بایت ذخیره می‌شود، به‌طوری‌که نیمه‌ی چپ در [nibble] بالا و نیمه‌ی راست در [nibble] پایین قرار می‌گیرد. برای مثال، سنگ‌های `[2|1]`، `[2|3]` و `[1|3]` به‌صورت بایت‌های `0x21 0x23 0x13` نمایش داده می‌شوند.

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | ورودی | آدرس | آرایه‌ای از بایت‌های سنگ |
| `$a1`    | ورودی | عدد صحیح | تعداد سنگ‌ها |
| `$v0`    | خروجی | «منطقی» | دومینوها می‌توانند زنجیره شوند (`0` = `false`، `1` = `true`) |
| `$t0-9`  | موقت | هر نوع | برای ذخیره‌سازی موقت استفاده می‌شود |


[nibble]: https://en.wikipedia.org/wiki/Nibble
