# مقدمه

وقتی Elixir تعیین می‌کند که کدام تابع باید فراخوانی شود، از اسم ماژول برای جست‌وجو استفاده می‌کند. اگر اسم ماژول به یک متغیر متصل باشد، این جست‌وجو می‌تواند به‌صورت پویا انجام شود.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

به‌طور داخلی، اسم ماژول یک «اتم» است. همه‌ی اتم‌های ماژول‌های Elixir به‌طور خودکار با `Elixir.` پیشوند می‌گیرند.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
