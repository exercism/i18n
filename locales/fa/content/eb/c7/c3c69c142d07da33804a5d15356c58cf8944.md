# پیوست دستورالعمل‌ها

## رجیسترها

| رجیستر | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | ورودی        | عدد صحیح | تعداد سکه‌های ورودی                       |
| `$a1`    | ورودی        | عدد صحیح | هدف                                      |
| `$a2`    | ورودی/خروجی | آدرس | آرایه‌ای از واژه‌های سکه که قابل بازنویسی است            |
| `$v0`    | خروجی       | عدد صحیح | تعداد سکه‌های خروجی، و 1- اگر ورودی نامعتبر باشد |
| `$t0-9`  | موقت    | هریک     | برای ذخیره‌سازی موقت استفاده می‌شود                  |
