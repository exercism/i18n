# درباره

بیشتر تکرار در Factor با «ترکیب‌گرها» (`each`، `map`، `reduce`) بیان می‌شود، اما بازگشت صریح هم همچنان جای خودش را دارد: زمانی که بازگشت شکل فهرستی ندارد، زمانی که حالت پایه سرراست نیست، یا زمانی که خودتان دارید یک ترکیب‌گر را پیاده‌سازی می‌کنید.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

چند نکته که باید بدانید:

- تعریف‌های معمولی با `:` می‌توانند بدون نیاز به نحوه‌ی نگارش خاصی بازگشت کنند. کامپایلر اثرهای پشته را در سراسر فراخوانی بازگشتی استنتاج می‌کند.
- `loop ( quot -- )` به شما امکان می‌دهد یک `quotation` را که مقدار «منطقی» برمی‌گرداند، تکرار کنید. تا زمانی که مقدارش «درست» باشد، ادامه دهید.
- فراخوانی‌های پایانی به پرش کامپایل می‌شوند، پس واژه‌های عمیقاً بازگشتی باعث سرریز شدن پشته نمی‌شوند.

جفت `unclip` / `if-empty` شکل استاندارد بازگشت روی دنباله است؛ `cond` هم شکل استاندارد توزیع چندحالته است.
