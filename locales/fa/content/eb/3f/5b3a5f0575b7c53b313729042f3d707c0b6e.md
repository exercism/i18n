# مقدمه

Gleam مقادیر «درست» و «غلط» را با نوع `Bool` نمایش می‌دهد. فقط دو مقدار وجود دارد: `True` و `False`. این مقادیر را می‌توان به یک متغیر نسبت داد:

```gleam
let true_variable = True
let false_variable = False
```

از عملگرهای `&&`، `||` و `!` می‌توان برای دستکاری مقادیر «منطقی» استفاده کرد:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

عملگرهای `&&` و `||` از «ارزیابی اتصال کوتاه» استفاده می‌کنند، یعنی عبارت سمت راست عملگر فقط در صورت نیاز ارزیابی می‌شود.

هر یک از این عملگرها اولویت متفاوتی دارد؛ به این صورت که `!` پیش از `&&` و `||` ارزیابی می‌شود. با آکولاد می‌توان بخشی از عبارت را پیش از بخش‌های دیگر ارزیابی کرد:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
