# دستورالعمل

در این تمرین می‌خواهید کدی بنویسید که به شما کمک کند از کتاب آشپزی محبوب‌تان یک لازانیای عالی بپزید.

چهار کار پیش رو دارید که همه به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار در فر را بر حسب دقیقه تعریف کنید

متد `Lasagna.expectedMinutesInOven()` را تعریف کنید که هیچ پارامتری نمی‌گیرد و برمی‌گرداند که لازانیا چند دقیقه باید در فر بماند. طبق کتاب آشپزی، زمان مورد انتظار در فر ۴۰ دقیقه است:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. زمان باقی‌مانده در فر را بر حسب دقیقه محاسبه کنید

متد `Lasagna.remainingMinutesInOven()` را تعریف کنید که تعداد دقیقه‌هایی را که لازانیا تا الآن در فر بوده به عنوان پارامتر می‌گیرد و بر اساس زمان مورد انتظار در فر از کار قبلی برمی‌گرداند که لازانیا چند دقیقه‌ی دیگر باید در فر بماند.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

متد `Lasagna.preparationTimeInMinutes()` را تعریف کنید که تعداد لایه‌هایی را که به لازانیا اضافه کرده‌اید به عنوان پارامتر می‌گیرد و برمی‌گرداند که چند دقیقه صرف آماده‌سازی لازانیا کرده‌اید، با این فرض که آماده کردن هر لایه ۲ دقیقه وقت می‌برد.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. زمان سپری‌شده را بر حسب دقیقه محاسبه کنید

متد `Lasagna.elapsedTimeInMinutes()` را تعریف کنید که دو پارامتر می‌گیرد: پارامتر اول تعداد لایه‌هایی است که به لازانیا اضافه کرده‌اید و پارامتر دوم تعداد دقیقه‌هایی است که لازانیا در فر بوده است. این تابع باید برمی‌گرداند که چند دقیقه روی پخت لازانیا کار کرده‌اید، یعنی مجموع زمان آماده‌سازی و زمانی که لازانیا تا این لحظه در فر گذرانده است.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
