# درباره

`bit` ریزدانه‌ترین مقدار در رایانش است.
واژه‌ی `bit` مخفف «رقم دودویی» است.
یکایی از ذخیره‌سازی داده در محیط اجرا است که به‌اندازه‌ای بزرگ است که بتواند شیئی را در خود جای دهد که ممکن است یکی از دو مقدار را داشته باشد.
بنابراین، یک مقدار دودویی دارد که یا `1` است یا `0`.
همه‌ی انواع داده‌ی دیگر از چندین `bits` تشکیل شده‌اند.
برای نمونه، یک `byte` معمولاً از ۸ `bits` تشکیل می‌شود.

## چگونه مقادیر بیت را بنویسیم

`Bits` یک دستگاه شمارش مبنای ۲ را می‌سازند.
هر مضرب `2` در جایی قرار می‌گیرد که ما آن را جای دهگان/صدگان/هزارگان/و غیره می‌پنداریم، با این تفاوت که «دهگان» اینجا «دو» می‌شود، «صدگان» «چهار» و «هزارگان» «هشت»، و به همین ترتیب.
بنابراین، مقدار دهدهی `2` همان مقدار دودویی `10` خواهد بود، `4` می‌شود `100` و `8` می‌شود `1000`.
مانند اعداد دهدهی، با حرکت از راست به چپ مقدارها بزرگ‌تر می‌شوند.
می‌توانیم مقدار دهدهی `5` را نمایانده‌شده با `101` در دودویی در نظر بگیریم، با یک `1` در جای «یک‌ها» و یک `1` در جای «چهارها».
با این حال، لیترال‌های دودویی بخشی از استاندارد زبان C نیستند.
تنها مقدارهای دودویی پشتیبانی‌شده در استاندارد زبان C، یک `1` یا `0` تک است.
لیترال‌های دودویی را بعضی افزونه‌های غیراستاندارد کامپایلر، مانند کامپایلر gnu، _پشتیبانی می‌کنند_، با گذاشتن `0b` در ابتدای لیترال.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

به یاد داشتن این نکته مهم است که چنین نشانه‌ای در همه‌ی کامپایلرها پشتیبانی نمی‌شود و می‌تواند مانعی برای قابلیت انتقال کد میان کامپایلرهای مختلف باشد.

روش رایج برای نوشتن مقدارهای دودویی، استفاده از نشانه‌گذاری هگزادسیمال است که یک دستگاه شمارش مبنای ۱۶ است.
نشانه‌گذاری هگزادسیمال در زبان C با `0x` یا `0X` در ابتدای لیترال می‌آید.
از آنجا که مقدار دهدهی `16` به‌صورت `1` در جای دهگان نمایش داده می‌شود، مقدار دهدهی `10` در هگزادسیمال به‌صورت `0xA` نمایش داده می‌شود، `11` به‌صورت `0xB`، `12` به‌صورت `0xC`، `13` به‌صورت `0xD`، `14` به‌صورت `0xE` و `15` به‌صورت `0xF`.
برای نمونه، مقدار دهدهی `42` به‌صورت `0x2A` نوشته می‌شود: `2` ضرب در `16` (= `32`) به‌علاوه‌ی `10` (= `42`).

در دودویی، می‌توانیم `42` را به‌صورت `00101010` در نظر بگیریم: `32` به‌علاوه‌ی `8` به‌علاوه‌ی `2`.
می‌گوییم بیت‌های دوم، چهارم و ششم از سمت راست «تنظیم‌شده» هستند، یعنی به‌جای `0` مقدار `1` دارند.
بیت دوم `2` است، بیت چهارم `8` و بیت ششم `32`.
تنظیم این سه بیت مقداری برابر با `42` پدید می‌آورد.

## ماسک بیت

ماسک بیت می‌تواند هر مقداری باشد که برای تنظیم بیت‌های تک‌تک به کار می‌رود.
برای نمونه، الفبای انگلیسی ۲۶ حرف دارد.
مقداری با دست‌کم ۲۶ بیت، مانند یک عدد صحیح ۳۲ بیتی بدون علامت، می‌تواند به‌عنوان ماسک بیت به کار رود تا برای هر حرف انگلیسی شرطی `true` یا `false` تنظیم کند.
هر مقداری که بیت‌های کافی برای پوشش مجموعه‌ای از شرط‌های `true` یا `false` داشته باشد، می‌تواند به‌عنوان ماسک بیت عمل کند.
تنظیم و خواندن بیت‌های تک‌تک با استفاده از عملگرهای بیتی انجام می‌شود.

## عملگر بیتی

فرض کنید می‌خواهیم پیگیری کنیم که چه حروفی در یک `string` ظاهر می‌شوند.
در مثال ما، تنها از ۲۶ حرف الفبای انگلیسی استفاده می‌کنیم.
ماسک بیت ما یک عدد صحیح ۳۲ بیتی بدون علامت خواهد بود.
`0` نشان‌دهنده‌ی این خواهد بود که آن حرف رخ نمی‌دهد.
`1` نشان‌دهنده‌ی این خواهد بود که آن حرف یک بار یا بیشتر رخ می‌دهد.
در آغاز، نمایش بیتی ماسک بیت ما ۳۲ تا `0s` پشت سر هم خواهد بود: `00000000000000000000000000000000`.
راست‌ترین جایگاه برای `A` خواهد بود.
دومین جایگاه از سمت چپ برای `B` خواهد بود و به همین ترتیب.
فرض کنید همه‌ی حروف رشته را در یک حلقه پردازش می‌کنیم، بنابراین یک خط کد می‌خواهیم که برای تنظیم هر حرفی کار کند.

### عملگر شیفت به چپ بیتی: راهی برای جای‌گذاری یک بیت

`<<` عملگر بیتی برای شیفت به چپ است.

اگر حرف ما `A` باشد نمی‌خواهیم به چپ شیفت دهیم، اما اگر حرف ما `B` باشد می‌خواهیم یک جایگاه به چپ شیفت دهیم و اگر حرف ما `C` باشد می‌خواهیم دو جایگاه به چپ شیفت دهیم و به همین ترتیب.
هرچند می‌توانیم `chars` را به‌صورت حروفی مانند `A` یا `B` درک کنیم، `char` در حافظه به‌صورت یک نوع صحیح پیاده‌سازی می‌شود، بنابراین می‌توانیم با یک `char` حساب ساده انجام دهیم.
اگر متغیری به اسم `letter` داشته باشیم که نماینده‌ی `char` در حال پردازش است، می‌توانیم به تعداد جایگاه‌های لازم به چپ شیفت دهیم؛ کافی است `1` را به اندازه‌ی اختلاف میان `letter` و `char` مربوط به `A` به چپ شیفت دهیم: `1 << letter - 'A'`.
`A` - `A` برابر `0` است، بنابراین اگر `letter` برابر `A` باشد، صفر جایگاه به چپ شیفت می‌دهد.
`B` - `A` برابر `1` است، بنابراین اگر `letter` برابر `B` باشد، یک جایگاه به چپ شیفت می‌دهد و به همین ترتیب.

### عملگر OR فراگیر بیتی: راهی برای تنظیم یک بیت

وقتی بدانیم _کجا_ می‌خواهیم بیتی را تنظیم کنیم، می‌توانیم آن را با استفاده از عملگر OR فراگیر بیتی، که `|` است، واقعاً تنظیم کنیم.
نتیجه‌ی عملگر `|` در هر جایگاهی که عملوند چپ یا راست بیتی تنظیم‌شده داشته باشد، `1` خواهد بود.
بنابراین، نتیجه‌ی `0010 | 0001` برابر `0011` خواهد بود.
(به یاد داشتن این نکته مهم است که این مقدار در دودویی `11` و در دهدهی `3` است.)
برای نسبت دادن نتیجه به یک مقدار، می‌توان عملگر `|` را با عملگر انتساب ترکیب کرد و بیت‌ها را چنین تنظیم کرد: `|=`.
برای ساده نگه داشتن مطلب، مثال زیر از حلقه استفاده نمی‌کند، اما نشان می‌دهد چگونه می‌توانیم حروف `ABA` را در یک ماسک بیت پردازش کنیم.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

بخش راست‌ترین ماسک را برای `A` روی `0001` تنظیم می‌کنیم و سپس ماسک را برای `B` روی `0011` تنظیم می‌کنیم.
تنظیم دوباره‌ی `A` تغییری در ماسک موجود پدید نمی‌آورد.
می‌توانستیم با بررسی اینکه آیا `A` پیش‌تر تنظیم شده است یا نه، از تنظیم دوباره‌ی آن بیت پرهیز کنیم.

### عملگر AND بیتی: راهی برای خواندن یک بیت

`&` عملگر AND بیتی است.
نتیجه‌ی عملگر `&` در هر جایگاهی که هم عملوند چپ و هم عملوند راست بیت تنظیم‌شده داشته باشند `1` خواهد بود.
بنابراین، نتیجه‌ی `0011 & 0001` برابر `0001` خواهد بود.
می‌توانیم این را در مثال زیر در عمل ببینیم.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### عملگر OR انحصاری بیتی: راهی برای وارونه کردن یک بیت

`^` عملگر OR انحصاری بیتی است.
عملگر OR _فراگیر_ دلالت بر وجود عملگر OR _انحصاری_ با رفتار متفاوت دارد.
نتیجه‌ی عملگر `^` در هر جایگاهی که _تنها یکی_ از عملوندهای چپ یا راست بیت تنظیم‌شده داشته باشد `1` خواهد بود.
بنابراین، نتیجه‌ی `0001 ^ 0011` برابر `0010` خواهد بود.
راست‌ترین بیت تنظیم نمی‌شود چون _هر دو_ عملوند در راست‌ترین جایگاه `1` دارند.
عملیات OR انحصاری را گاهی XOR می‌نویسند.
اگر نتیجه‌ی XOR شدن یک مقدار دوباره XOR شود، مقدار اصلی بازگردانده می‌شود.
این می‌تواند برای رمزنگاری بسیار ساده‌ای به کار رود که در آن از کلید یکسان برای رمزگذاری و رمزگشایی داده استفاده می‌شود.
برای نمونه

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### عملگر شیفت به راست بیتی: راهی برای نصف کردن یک مقدار

`>>` عملگر بیتی برای شیفت به راست است.
معمولاً به ازای هر جایگاهی که بیت‌های یک مقدار به راست شیفت داده می‌شوند، نتیجه برابر مقدار تقسیم بر دو است.
برای نمونه

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

اگر مقدار عملوند راست منفی باشد یا بزرگ‌تر از یا مساوی عرض عملوند چپ ارتقایافته باشد، رفتار تعریف‌نشده است.
این موضوع درباره‌ی عملگر شیفت به چپ نیز صدق می‌کند.
وقتی به‌جای عدد صحیح بدون علامت از عدد صحیح علامت‌دار استفاده می‌شود، علامت‌داری نیز ممکن است تأثیر بگذارد.
مثال زیر رفتار یک سامانه را هنگام شیفت دادن بیش از حد به چپ یا راست برای یک عدد صحیح علامت‌دار نشان می‌دهد.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

از آنجا که رفتار تعریف‌نشده است، سامانه‌ای متفاوت ممکن است نتایج متفاوتی به دست دهد.
هنگام شیفت دادن بیت‌ها، درک محدوده‌های نوع داده‌ی به‌کاررفته مهم است.

## فیلد بیت

دیده‌ایم که بیت‌های بسته‌بندی‌شده در یک نوع داده‌ی ساده را می‌توان با موقعیتشان آدرس‌دهی کرد.
بیت‌های بسته‌بندی‌شده در یک `struct` را می‌توان با اسم آدرس‌دهی کرد.
به چنین نوع داده‌ای `bit field` می‌گویند.
یک کاربرد `bit fields` می‌تواند جایی باشد که به مجموعه‌ای از پرچم‌های ON/OFF نیاز است و کمینه کردن مصرف حافظه مورد نظر است.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

نحوه‌ی نگارش `unsigned int variable_name : 1;` فیلدی به اندازه‌ی `1` بیت درون یک `unsigned int` می‌سازد که درون ساختار جای گرفته است.
به‌جای `unsigned int` می‌توان از `signed int` استفاده کرد، یا، از C99 به بعد، می‌توان از نوع `bool` استفاده کرد.
یک ساختار دارای فیلد بیت می‌تواند فیلدهایی از انواع داده‌ی دیگر نیز داشته باشد، مانند `number_of_lights` در مثال بالا.
