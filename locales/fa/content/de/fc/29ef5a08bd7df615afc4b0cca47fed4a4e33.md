# مقدمه

چاپ در Cairo به شما امکان می‌دهد تا هنگام اجرای برنامه پیام‌ها یا اطلاعات Debug را نمایش دهید.

## مبانی

Cairo دو ماکرو برای چاپ در اختیار شما می‌گذارد:

- `println!`: یک پیام را به همراه یک خط جدید چاپ می‌کند.
- `print!`: یک پیام را بدون خط جدید چاپ می‌کند.

```rust
println!("Hello, Cairo!"); 
println!("x = {}, y = {}", 10, 20); 
```

جانگهدارهای `{}` با مقادیر ارائه‌شده جایگزین می‌شوند.

## قالب‌بندی رشته‌ها

برای ساختن یک `ByteArray` بدون چاپ فوری، از `format!` استفاده کنید:

```rust
let result = format!("{}-{}-{}", "tic", "tac", "toe");
println!("{}", result); // Output: tic-tac-toe
```

## انواع داده‌ی سفارشی

برای انواع سفارشی، برای چاپ یا `Display` را پیاده‌سازی کنید یا `Debug` را مشتق کنید:

```rust
#[derive(Debug)]
struct Point { x: u8, y: u8 }

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Debug output: Point { x: 3, y: 4 }
```

## چاپ هگزادسیمال

برای چاپ اعداد صحیح به صورت هگزادسیمال، از `{:x}` استفاده کنید:

```rust
println!("{:x}", 255); // Output: ff
```
