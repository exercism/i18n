# معرفی

«ژنریک» به شما امکان می‌دهد کدی بنویسید که با چندین نوع کار کند، بدون تکرار.

نوع‌های ژنریک را با استفاده از پرانتزهای زاویه‌دار `<T>` تعریف کنید، که در آن `T` «جاینگهدارِ» هر نوعی است.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo برای مشخص‌کردن اینکه نوع ژنریک باید از چه عملیاتی پشتیبانی کند، به قیدهای `trait` نیاز دارد. می‌توانید با `+` این قیدها را اضافه کنید:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

ساختارها هم می‌توانند ژنریک باشند:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

`trait`ها هم می‌توانند ژنریک باشند تا با انواع مختلف کار کنند:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

توابع می‌توانند پارامترهای ژنریک همراه با قیدهای `trait` بپذیرند تا با هر نوعی که `trait` لازم را پیاده‌سازی می‌کند کار کنند:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
