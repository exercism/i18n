# کامنت قالب اولیه

به نظر می‌رسد چند کامنت «Please implement ...» را در code خودتان جا گذاشته‌اید که بخشی از قالب اولیه‌ی راه‌حل بوده‌اند.

code شما از پس testها برمی‌آید، یعنی دیگر آن کامنت‌ها درست نیستند: شما پیش‌تر همه‌ی توابع لازم را پیاده‌سازی کرده‌اید.

حتماً همیشه کامنت‌های قدیمی را از code خودتان پاک کنید.
