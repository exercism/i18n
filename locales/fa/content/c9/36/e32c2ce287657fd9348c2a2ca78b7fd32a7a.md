# مقدمه

`vector` در R مجموعه‌ای از مقادیر با `type` یکسان است: `numeric`، `character` و غیره. اگر ورودی‌های ترکیبی به آن بدهید، R بی‌سروصدا همه را به یک نوع مشترک تبدیل می‌کند، معمولاً `character`، که می‌تواند به نتایج غیرمنتظره‌ای منجر شود.

```R
v <- c(2, 5.4, "txt")
v
#> [1] "2"   "5.4" "txt"
typeof(v)
#> [1] "character"
```

## ساختن بردارها

اگر همه‌ی مقادیر را از قبل دارید، از `c()` استفاده کنید (مخفف «به‌هم‌چسباندن» یا «ترکیب کردن»):

```R
x <- 10
v <- c(4, 7, x)
```

تابع `c()` بسیار انعطاف‌پذیر است و ورودی‌ها می‌توانند شامل بردارها و بازه‌های دیگر باشند.
`c()` هر تعداد و هر نوع ورودی را می‌پذیرد و آن‌ها را به یک بردار واحد تبدیل می‌کند.

## بازه‌ها، دنباله‌ها، تکرارها

برای بازه‌ای از مقادیر متوالی (افزایشی یا کاهشی) می‌توانید از نشانه‌گذاری `:` استفاده کنید

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

تابع `seq()` کنترل دقیق‌تری ارائه می‌دهد:

```R
# specify step size
seq(2, 11, by = 3) # c(2, 5, 8, 11)

# specify number of values, evenly-spaced
seq(2.5, 4, length.out = 5) # c(2.500, 2.875, 3.250, 3.625, 4.000) 
```

چند بازه به‌عنوان ثابت‌های توکار از پیش تعریف شده‌اند:

```R
letters  # LETTERS is the UPPERCASE equivalent
#> [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q" "r" "s" "t" "u" "v" "w" "x" "y" "z"

month.name
#> [1] "January"   "February"  "March"     "April"     "May"       "June"      "July"      "August"   
#> [9] "September" "October"   "November"  "December" 

month.abb
#> [1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

## عملیات حسابی

عملیات به‌طور خودکار عنصر‌به‌عنصر روی بردار اعمال می‌شوند. 
حلقه‌ها، درک‌های فهرست و بازگشت‌هایی که در زبان‌های دیگر رایج‌اند لازم نیستند و (*به دلایل کارایی*) معمولاً باید از آن‌ها پرهیز کرد.

```R
2 + 1:3 # c(3, 4, 5)
2 * 1:3 # c(2, 4, 6)
12 / 1:3 # c(12  6  4)
2 ^ (1:3) # c(2, 4, 8) : exponentiation, precedence order here needs ()
```

جفت‌های بردارها هم عنصر‌به‌عنصر کار می‌کنند:

```R
v <- 1:3
w <- 5:7

v + w
#> [1]  6  8 10

v * w
#> [1]  5 12 21

v ^ w
#> [1]    1   64 2187
```

## دسترسی به عناصر بردار

مثل بسیاری از زبان‌ها، می‌توانیم از اندیس داخل کروشه استفاده کنیم:

```R
v <- 4:7
v[2]
#> [1] 5
v[2:4]
#> [1] 5 6 7
```

اما توجه داشته باشید: ***R به‌طور پیش‌فرض از اندیس‌گذاری یک‌مبنا استفاده می‌کند***. 

این در زبان‌های علمی (Fortran، Matlab، Julia) رایج است، اما با اندیس‌گذاری صفر‌مبنای C و جانشینان پرشمارش تفاوت دارد.

می‌توان از بازه‌ها استفاده کرد، همان‌طور که در مثال بالا دیدید و همچنین در تابع بسیار انعطاف‌پذیر `c()`:

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors` (مثل بیشتر موارد در R) را می‌توان تغییرپذیر در نظر گرفت و با نحوه‌ی نگارش انعطاف‌پذیر مشابهی در یک عنصر یا چندین عنصر نوشت:

```R
v <- 1:10
v[2] <- 42
v[4:6] <- c(11, 12, 13)
v
#> [1]  1 42  3 11 12 13  7  8  9 10
```

## اندیس‌های منفی

برنامه‌نویسان آشنا با زبان‌های دیگر ممکن است حدس بزنند که `v[-1]` راهی برای دسترسی به آخرین عنصر یک بردار است.
*اشتباه!*
برای این کار از `tail(v, n=1)` استفاده کنید.

اندیس‌های منفی در واقع راهی برای ***حذف*** یک عنصر هستند و برداری کوتاه‌تر برمی‌گردانند:

```R
v <- c(2, 4, 6)
v[-2]
#> [1] 2 6  # second element gone
```

## شرط‌های برداری

اعمال مقایسه‌ها روی یک بردار، برداری با طول برابر از مقادیر منطقی برمی‌گرداند.
این می‌تواند در توابعی مثل `all()` و `any()` بسیار مفید باشد:

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

برای عبارات منطقی پیچیده‌تر، مهم است که از عملگرهای `&` و `|` استفاده کنید، چون این‌ها روی بردارها کار می‌کنند.
عملگرهای دوحرفی `&&` و `||` فقط برای مقایسه‌ی مقدارهای تکی در نظر گرفته شده‌اند.

```R
v %% 2 == 0 & v > 5
#> [1] FALSE FALSE  TRUE
```
