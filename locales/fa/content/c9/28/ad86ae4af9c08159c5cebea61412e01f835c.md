## واردکردن

یک «ماژول» معمولاً با «کلیدواژهی» `use` بارگذاری می‌شود. این کار هم آن را بارگذاری می‌کند و هم متد `import` را روی آن فراخوانی می‌کند و هر «نماد» صادرشده‌ای را وارد می‌کند.

نمادهای موجود در آرایه‌ی `@EXPORT` بسته به‌صورت پیش‌فرض وارد می‌شوند. نمادهای موجود در آرایه‌ی `@EXPORT_OK` بسته باید به‌صراحت وارد شوند.

پیش از نسخه‌ی `v5.37` زبان Perl، ماژول باید با یک مقدار درست (معمولاً `1`) پایان می‌یافت تا نشان دهد ماژول با موفقیت بارگذاری شده است. با استفاده از ویژگی [`module_true`][module_true] این کار لازم نیست.

## صادرکردن

برای اینکه یک نماد وارد شود، ابتدا باید صادر شده باشد. ماژول [Exporter][Exporter] همراه با Perl عرضه می‌شود و یکی از راحت‌ترین گزینه‌ها برای صادرکردن است.

تعریف ماژول:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

استفاده از ماژول:
```perl
use Foo ('bar');

bar();
```

## پراگما

«پراگما» ماژولی است که بر جنبه‌ای از رفتار Perl تأثیر می‌گذارد.

پراگماهای [`strict`][strict] و [`warnings`][warnings] معمولاً توصیه می‌شوند تا به‌ترتیب ساختارهای ناایمن را محدود کنند و مشکلات احتمالی را علامت بزنند. پراگمای `strict` همراه با `use v5.12` یا بالاتر فعال می‌شود. پراگمای `warnings` همراه با `use v5.35` یا بالاتر فعال می‌شود.

پراگمای [`feature`][feature] به شما امکان می‌دهد ویژگی‌های جدیدتر و آزمایشی Perl را فعال کنید. وقتی به کلیدواژه‌ی `use` نسخه‌ی مشخصی از Perl داده شود، مجموعه‌ی ویژگی‌های آن نسخه را فعال می‌کند.

## ماژول‌های هسته

در کنار [Exporter][Exporter]، Perl مجموعه‌ی گسترده‌ای از [ماژول‌های هسته][perl-core-modules] را برای استفاده در اختیار دارد. چند نمونه که برای تمرین‌هایی که ممکن است اینجا با آن‌ها روبه‌رو شوید مفیدند عبارت‌اند از [List::Util][List::Util]، [Time::Piece][Time::Piece] و [Math::BigRat][Math::BigRat].

## CPAN

علاوه بر ماژول‌های هسته، [CPAN][metacpan] هزاران ماژول دیگر را که جامعه‌ی Perl ساخته‌اند برای نصب در اختیار دارد. مسیر Perl از یک [cpanfile][test-runner-cpanfile] برای نصب مجموعه‌ای از ماژول‌ها استفاده می‌کند که می‌توان از آن‌ها در کنار test runner زبان Perl در Exercism بهره برد.
