# test

## اجرای testها

برای اجرای testها، دستور زیر را اجرا کنید:

```bash
dotnet test
```

برای اجرای خودکار testها هر بار که یکی از فایل‌های منبع تغییر می‌کند، دستور زیر را اجرا کنید:

```bash
dotnet watch test
```

## حل تمرین

حل یک تمرین یعنی همه‌ی testهای آن را پاس کنید. به‌صورت پیش‌فرض، وقتی testها را اجرا می‌کنید، فقط یک test (اولین test) اجرا می‌شود. این کار عمدی است، چون به شما امکان می‌دهد فقط روی پاس کردن همان یک test تمرکز کنید. وقتی آن test پاس شد، می‌توانید با حذف `Skip = "Remove this Skip property to run this test"` از خصیصه‌ی `[Fact]` یا `[Theory]` آن test، test بعدی را فعال کنید. وقتی همه‌ی testها فعال شدند و پیاده‌سازی شما همه‌ی آن‌ها را پاس کرد، تمرین را حل کرده‌اید!

برای اینکه راحت‌تر شروع کنید، هر تمرین با یک فایل پیاده‌سازی اولیه همراه است. می‌توانید از این فایل به‌عنوان نقطه‌ی شروعی برای ساختن راه‌حل خود استفاده کنید. اگر صلاح می‌دانید، با خیال راحت این فایل را حذف کنید یا تغییر دهید.

## استفاده از بسته‌ها

باید بتوانید بیشتر تمرین‌ها را بدون استفاده از هیچ بسته‌ی خارجی حل کنید. با این حال، برای تمرین‌هایی که می‌خواهید از یک بسته‌ی خارجی استفاده کنید، می‌توانید با اجرای دستور زیر آن را به پروژه‌تان اضافه کنید:

```bash
dotnet add package [package-name]
```
