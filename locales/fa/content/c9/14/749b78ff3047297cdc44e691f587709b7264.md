# منابع یادگیری پیشنهادی

به یادگیری ColdFusion (CFML) خوش آمدید! CFML یک زبان اسکریپتی پویا با نوع‌دهی آزاد است که روی ماشین مجازی جاوا (JVM) اجرا می‌شود. این زبان دو نوع فایل متفاوت دارد. فایل‌های `.cfm` (نشانه‌گذاری ColdFusion) صرفاً رویه‌ای هستند و برای قالب‌بندی HTML از روش نوشتن تگ‌محور استفاده می‌کنند. اگر یک وب‌سایت می‌سازید، از این فایل‌ها برای نماها استفاده می‌کنید:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

نوع دیگر فایل، `.cfc` (کامپوننت ColdFusion) است و با آن یک کلاس تعریف می‌کنید. کامپوننت‌ها برای منطق کسب‌وکار، مدل‌ها و کنترلرها استفاده می‌شوند. این فایل‌ها معمولاً از روش نوشتن اسکریپتی استفاده می‌کنند که خواندنش شبیه JavaScript است.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
