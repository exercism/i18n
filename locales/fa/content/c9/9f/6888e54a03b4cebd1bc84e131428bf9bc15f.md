# تبدیل JSON سوخت

## صورت مسئله

هر کارمند شرکت ABC Corp سهمیه‌ی سوخت نامحدودی دریافت می‌کند. کارمندان باید هر بار که خودروی خود را سوخت‌گیری می‌کنند، یک سابقه ارسال کنند. این سابقه‌ها به همان فایل JSON افزوده می‌شوند و در پایان ماه پردازش می‌شوند.

شما به‌عنوان عضوی از تیم عملیات دیجیتال، وظیفه دارید این فایل JSON را بخوانید و نتایج را در فایل JSON دیگری بنویسید. فایل خروجی باید برای هر کارمند یک ورودی داشته باشد که شامل جزئیات زیر است:

- شماره‌ی کارمند
- تعداد سوخت‌گیری‌ها
- هزینه‌ی کل سوخت
- مجموع گالن‌ها
- مجموع مایل‌های پیموده‌شده

دو آرگومان از نوع `string` به شما داده می‌شود.

1. مسیر فایل JSON ورودی.
1. مسیر فایل JSON خروجی.

فایل JSON ورودی شامل آرایه‌ای از اشیای JSON است. هر شیء JSON به شکل زیر است.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

وظیفه‌ی شما این است که ورودی JSON را به قالب JSON زیر تبدیل کنید و محتوا را در مسیر داده‌شده بنویسید. فایل خروجی باید برای هر کارمند یک ورودی داشته باشد که بر اساس `employeeId` به ترتیب صعودی مرتب شده است.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## محدودیت‌ها

- تعداد سابقه‌های سوخت‌گیری `n` در فایل JSON ورودی: ۰ <= n <= ۱۰۰۰
- تعداد کارمندان شرکت: ۹۷
- قیمت سوخت به ازای هر گالن محاسبه می‌شود
- هیچ سابقه‌ی سوخت‌گیری‌ای جا نیفتاده است

## راهنمایی‌ها

- برای خواندن و نوشتن فایل‌های JSON از [ماژول `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) استفاده کنید.
- مقادیر JSON را به نوع‌های مخصوص برنامه تبدیل کنید تا بتوانید به شکلی امن از نظر نوع با داده‌ها کار کنید. برای اطلاعات بیشتر، به [مثال تبدیل به نوع تعریف‌شده توسط کاربر](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) در Ballerina By Examples (BBE) مراجعه کنید.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [از هم باز کردن رکوردها](https://ballerina.io/learn/by-example/destructure-records-using-query) می‌تواند در کاهش پرگویی کد مفید باشد.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- برای توابعی که تنها یک عبارت دارند، از توابع با بدنه‌ی عبارتی استفاده کنید. برای مثال، توابعی که فقط دستور `return` را دارند.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
