# مقدمه

«حلقه‌ی For» یکی از پرکاربردترین دستورها برای اجرای مکرر یک منطق است.
در JavaScript، حلقه‌ی For از کلیدواژه‌ی `for`، یک _سرآیند_ که درون پرانتز قرار می‌گیرد و یک بلوک کد که _بدنه‌ی_ حلقه را درون آکولاد جای می‌دهد، تشکیل شده است.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

مقداردهی اولیه معمولاً یک متغیر شمارنده را تنظیم می‌کند. شرط بررسی می‌کند که آیا حلقه باید ادامه پیدا کند یا متوقف شود و گام در پایان هر تکرار، شمارنده را یک واحد افزایش می‌دهد.
بخش‌های مختلف سرآیند با نقطه‌ویرگول از هم جدا می‌شوند.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
