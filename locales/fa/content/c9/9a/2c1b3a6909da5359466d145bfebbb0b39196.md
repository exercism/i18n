# مقدمه

## `let`

عبارت `let` برای ساختن یک «دامنه‌ی محلی» به کار می‌رود و در چند موقعیت کاربرد دارد:

- برای ساده‌کردن عبارت‌ها
- برای اسم‌گذاری نتیجه‌ی عبارت‌های میانی
- برای شکستن یک عبارت به بخش‌های کوچک‌تر، اگر دارد بزرگ می‌شود

می‌توانید بیشتر کارها را داخل یک عبارت `let` انجام دهید، از جمله «تجزیه‌ی ساختاری» (جزئیات بیشتر در تمرین‌های بعدی)، اما تعریف یک «نوع سفارشی» یا «اسم مستعار نوع» جدید ممکن نیست.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
