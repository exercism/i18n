# درباره

«عبارت‌های باقاعده» در Gleam از مشخصات **PCRE** (عبارات باقاعده‌ی سازگار با Perl) پیروی می‌کنند، مشابه زبان‌های محبوب دیگری مانند Java، JavaScript یا Ruby.

ماژول `gleam/regex` توابعی برای کار با عبارت‌های باقاعده ارائه می‌دهد.

~~~~exercism/note
این تمرین فرض می‌کند که شما از قبل نحوه‌ی نگارش عبارت‌های باقاعده را می‌دانید، از جمله کلاس‌های نویسه، کمیت‌سازها، گروه‌ها و گروه‌های گرفته‌شده.

اگر لازم است دانش خود را درباره‌ی عبارت‌های باقاعده تازه کنید، به یکی از این منابع سر بزنید: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

رایج‌ترین راه برای ساختن عبارت‌های باقاعده استفاده از تابع `regex.from_string` است.

```gleam
let assert Ok(re) = regex.from_string("test")
```

تابع `regex.from_string` اگر نحوه‌ی نگارش عبارت باقاعده نامعتبر باشد یک `Error` برمی‌گرداند، بنابراین در اینجا از یک تأیید let استفاده شده است تا معتبر بودن عبارت باقاعده تضمین شود.

از تابع `regex.check` می‌توان برای بررسی اینکه آیا یک عبارت باقاعده با یک رشته مطابقت دارد استفاده کرد.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## گروه‌های گرفته‌شده

اگر می‌خواهید زیررشته‌هایی را با یک عبارت باقاعده بگیرید، می‌توان از تابع `regex.scan` برای برگرداندن فهرستی از مطابقت‌ها استفاده کرد.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## اصلاح‌کننده‌ها

رفتار یک عبارت باقاعده را می‌توان با ساختن آن به کمک تابع `regex.compile` و دادن گزینه‌ها تغییر داد.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
