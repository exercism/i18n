# عدد ممیز شناور

اعداد ممیز شناور در PHP برای نمایش زیرمجموعه‌ای از اعداد حقیقی استفاده می‌شوند.
این اعداد با یک یا چند رقم شروع می‌شوند که با جداکننده‌ی اعشار از هم جدا شده‌اند.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## دام‌های رایج

با اعداد ممیز شناور نمی‌توان همه‌ی اعداد و عملیات حسابی را انجام داد.
استفاده از اعداد ممیز شناور برای نمایش دلار و سنت می‌تواند به خطاهای گرد کردن منجر شود.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
