# PaySwitch - مبدل حقوق

## صورت مسئله

شرکتی به نام **Insure Everyone** حقوق کارمندانش را به ارزهای خارجی پرداخت می‌کند. اما به دلیل الزامات قانونی، حقوق باید به ارز محلی تبدیل شود. کارمندان این شرکت در سراسر جهان پراکنده‌اند.
بخش منابع انسانی Insure Everyone به دنبال کمک از یک توسعه‌دهنده‌ی ماهر است تا برنامه‌ای بسازد که حقوق هر کارمند را به ارز محلی مربوط به خودش تبدیل کند. این شرکت برای نرخ‌های تبدیل به یک API خارجی تکیه می‌کند.

با توجه به API خارجی نرخ تبدیل، باید تابعی بنویسید که یک `source currency`، یک `salary` (به ارز مبدأ) و `local currency` کارمند را بگیرد و حقوق را به ارز محلی برگرداند.

## محدودیت‌ها

* 500 <= `salary` <= 10000
* `sourceCurrency` و `targetCurrency` کدهای ارز [ISO (الفبایی)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) هستند. ورودی تست ممکن است کدهای ارز نامعتبر داشته باشد.
* دقت نرخ بازگردانده‌شده تا `5` رقم اعشار سنجیده می‌شود.

## مثال

### مثال ۱

#### ورودی:
* حقوق: 1000
* ارز مبدأ: USD
* ارز مقصد: GBP

#### خروجی:

با فرض اینکه تبادل ارز خارجی پاسخ نرخ‌های تبدیل زیر را برگردانده باشد (ناقص):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

تابع باید `735.84000` را برگرداند
