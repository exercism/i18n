# درباره

ساختارهای داده‌ای که می‌توانند صفر یا چند عنصر را در خود نگه دارند، با نام «مجموعه» شناخته می‌شوند. یک **آرایه** مجموعه‌ای است که اندازه/طول ثابتی دارد و عناصر آن باید همگی از یک نوع باشند. عنصرها را می‌توان با استفاده از یک اندیس در آرایه قرار داد یا از آن بازیابی کرد. آرایه‌های C# صفرمبنا هستند، یعنی اندیس اولین عنصر همیشه صفر است:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

آرایه‌ها را می‌توان با یک نگارش مختصر هم تعریف کرد که به شما امکان می‌دهد هم آرایه را بسازید و هم مقدارش را تعیین کنید. از آنجا که کامپایلر اکنون می‌تواند بگوید آرایه چند عنصر خواهد داشت، می‌توان طول را حذف کرد:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

می‌توان آرایه‌ها را با فراخوانی [متدها][array-methods] یا [ویژگی‌های][array-properties] یک نمونه‌ی آرایه، یا با استفاده از متدهای استاتیکی که در [کلاس `Array`][array-class] تعریف شده‌اند، دست‌کاری کرد.

## پیمایش

آرایه یک _مجموعه_ هم هست، یعنی می‌توانید همه‌ی مقدارهای آن را با یک [حلقه‌ی `foreach`][foreach-statement] پیمایش کنید:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

می‌توان برای پیمایش یک آرایه از [حلقه‌ی `for`][for-statement] استفاده کرد:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

با این حال، به طور کلی حلقه‌ی `foreach` به دلایل زیر بر حلقه‌ی `for` ترجیح دارد:

- حلقه‌ی `foreach` تضمین می‌کند که همه‌ی مقدارها پیمایش شوند. با حلقه‌ی `for`، به‌راحتی ممکن است عنصرها از قلم بیفتند، مثلاً به دلیل خطای یک واحد اختلاف.
- حلقه‌ی `foreach` _اعلامی‌تر_ است؛ کد شما بیان می‌کند که _چه کاری_ می‌خواهید انجام شود، در حالی که حلقه‌ی `for` بیان می‌کند که _چگونه_ می‌خواهید آن را انجام دهید.
- حلقه‌ی `foreach` خطاناپذیر است، در حالی که با حلقه‌های `for` به‌راحتی ممکن است خطای یک واحد اختلاف رخ دهد.
- حلقه‌ی `foreach` روی همه‌ی انواع مجموعه کار می‌کند، از جمله آن‌هایی که از اندیس‌گذار برای دسترسی به عنصرها پشتیبانی نمی‌کنند.

برای اینکه تضمین شود حلقه‌ی `foreach` همه‌ی مقدارها را پیمایش می‌کند، کامپایلر اجازه نمی‌دهد که یک مجموعه درون حلقه‌ی `foreach` به‌روزرسانی شود:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

حلقه‌ی `for` مزایایی هم نسبت به حلقه‌ی `foreach` دارد:

- می‌توانید از هر اندیسی که می‌خواهید شروع کنید یا در آن متوقف شوید.
- می‌توانید از هر شرط پایانِ «منطقی» که می‌خواهید استفاده کنید.
- می‌توانید با سفارشی‌سازی افزایش متغیر حلقه، از برخی عنصرها بگذرید.
- می‌توانید مجموعه‌ها را با شمارش نزولی از آخر به اول پردازش کنید.
- می‌توانید از حلقه‌های `for` در موقعیت‌هایی که به مجموعه‌ها مربوط نیستند استفاده کنید.

مباحث مرتبط:

- خوب است بدانید که C# از [آرایه‌های چندبعدی][multi-dimensional-arrays] مانند `int[,] arr = new int[10, 5]` پشتیبانی می‌کند که می‌توانند بسیار مفید باشند.
- همچنین خوب است بدانید که می‌توانید نمونه‌هایی از نوع [`System.Array`][system-array-object] را با `Array.CreateInstance` بسازید. چنین اشیایی کاربرد چندانی ندارند، بیشتر برای تعامل با کد VB.NET. این‌ها با آرایه‌های استاندارد (`T[]`) قابل جابه‌جایی نیستند. می‌توانند کران پایین غیرصفر داشته باشند.

هر دو مبحث بالا به طور کامل‌تری در تمرینی بعدی بررسی می‌شوند.
