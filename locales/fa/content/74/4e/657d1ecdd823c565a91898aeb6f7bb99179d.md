# دستورالعمل

در این تمرین، باید چند قانون از بازی کلاسیک Pac-Man را به توابع C++ تبدیل کنید.

چهار قانون برای تبدیل دارید که همه به وضعیت‌های بازی مربوط‌اند.

> نگران نحوه‌ی به‌دست آمدن آرگومان‌ها نباشید؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید.

## 1. تعریف کنید که آیا Pac-Man یک شبح را می‌خورد

تابع `can_eat_ghost` را تعریف کنید که دو آرگومان می‌گیرد (_اینکه Pac-Man یک قرص قدرت فعال داشته باشد_ و _اینکه Pac-Man با یک شبح تماس داشته باشد_) و یک مقدار «منطقی» برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌تواند شبح را بخورد. تابع باید فقط در صورتی «درست» را برگرداند که Pac-Man یک قرص قدرت فعال داشته باشد و با یک شبح تماس داشته باشد.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. تعریف کنید که آیا Pac-Man امتیاز می‌گیرد

تابع `scored` را تعریف کنید که دو آرگومان می‌گیرد (_اینکه Pac-Man با یک قرص قدرت تماس دارد_ و _اینکه Pac-Man با یک نقطه تماس دارد_) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man امتیاز گرفته است. تابع باید اگر Pac-Man با یک قرص قدرت یا یک نقطه تماس داشته باشد، «درست» را برگرداند.

```cpp
scored(true, true);
// => true
```

## 3. تعریف کنید که آیا Pac-Man می‌بازد

تابع `lost` را تعریف کنید که دو آرگومان می‌گیرد (_اینکه Pac-Man یک قرص قدرت فعال داشته باشد_ و _اینکه Pac-Man با یک شبح تماس داشته باشد_) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌بازد. تابع باید اگر Pac-Man با یک شبح تماس داشته باشد و قرص قدرت فعالی نداشته باشد، «درست» را برگرداند.

```cpp
lost(false, true);
// => true
```

## 4. تعریف کنید که آیا Pac-Man می‌برد

تابع `won` را تعریف کنید که سه آرگومان می‌گیرد (_اینکه Pac-Man همه‌ی نقطه‌ها را خورده باشد_، _اینکه Pac-Man یک قرص قدرت فعال داشته باشد_ و _اینکه Pac-Man با یک شبح تماس داشته باشد_) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌برد. تابع باید اگر Pac-Man همه‌ی نقطه‌ها را خورده باشد و بر اساس آرگومان‌های تعریف‌شده در بخش ۳ نباخته باشد، «درست» را برگرداند.

```cpp
won(false, true, false);
// => false
```
