# مقدمه

کار با متن یکی از کارهای رایج در برنامه‌نویسی است.
Swift به همراه چارچوب Foundation، متدها و ویژگی‌های راحت بسیاری برای بررسی، تبدیل و دست‌کاری رشته‌ها در اختیارتان می‌گذارد.

## تقسیم رشته‌ها با `components(separatedBy:)`

برای تقسیم یک رشته به آرایه‌ای از «زیررشته‌ها» بر اساس یک «جداکننده»، از `components(separatedBy:)` استفاده کنید (نیازمند وارد کردن Foundation است):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## بررسی پیشوند و پسوند با `hasPrefix(_:)` و `hasSuffix(_:)`

برای بررسی اینکه رشته‌ای با دنباله‌ی خاصی از نویسه‌ها آغاز می‌شود یا پایان می‌یابد، از `hasPrefix(_:)` و `hasSuffix(_:)` استفاده کنید:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## تغییر بزرگی و کوچکی حروف

می‌توانید بزرگی و کوچکی حروف یک رشته را با این متدها و ویژگی‌های استاندارد تغییر دهید:

- `lowercased()`: یک نسخه‌ی حروف‌کوچک از رشته را برمی‌گرداند.
- `uppercased()`: یک نسخه‌ی حروف‌بزرگ از رشته را برمی‌گرداند.
- `capitalized`: نسخه‌ای را برمی‌گرداند که حرف اول هر واژه در آن بزرگ نوشته شده است (از Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## جایگزینی زیررشته‌ها با `replacingOccurrences(of:with:)`

برای جایگزینی همه‌ی موارد یک زیررشته‌ی هدف با رشته‌ای دیگر، از `replacingOccurrences(of:with:)` استفاده کنید (از Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## اتصال رشته‌ها با `joined(separator:)`

متد `joined(separator:)` متعلق به مجموعه‌هایی از رشته‌ها است، مانند `[String]`.
این متد عنصرها را با استفاده از یک جداکننده به هم می‌پیوندد و به یک رشته‌ی واحد تبدیل می‌کند:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
