# دستورالعمل‌ها

در این تمرین، [قوانین بازی Go](https://matmoore.github.io/learngo/) را به کار می‌برید. خود قوانین از قبل نوشته شده‌اند؛ فقط باید آن‌ها را به کار ببرید تا `Game` را به‌روزرسانی کنید و هر خطا یا نقض قوانین را مدیریت کنید.

بازی به این شکل نمایش داده می‌شود:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

در این بازی ۴ قانون وجود دارد:

- هر نقطه فقط می‌تواند یک سنگ داشته باشد (`oneStonePerPointRule`)
- می‌توان سنگ‌های حریف را اسیر کرد! (`captureRule`)
- نمی‌توانید سنگی را جایی بگذارید که خودش را اسیر کند (`libertyRule`)
- نمی‌توانید از یک نقطه دو بار استفاده کنید (`koRule`)

## 1. قوانین را اعمال کنید

محتوای تابع `applyRules` را بنویسید؛ این تابع یک `Game` اولیه و مجموعه‌ای از قوانین را می‌گیرد و `Game` جدید را پس از اعمال قوانین برمی‌گرداند.

`oneStonePerPointRule`، `libertyRule` و `koRule` هر سه نقض قوانین را بررسی می‌کنند و ممکن است خطا برگردانند، بنابراین نوع بازگشتی آن‌ها `Result String Game` است. اگر هر یک از این قوانین شکست بخورد، باید بازی اصلی برگردانده شود، اما با فیلد `error` که با خطای مربوطه به‌روزرسانی شده است.

`captureRule` نقض قوانین را بررسی نمی‌کند و بنابراین نمی‌تواند شکست بخورد (هرچند می‌تواند یک `Game` تغییر‌یافته برگرداند)، پس نوع بازگشتی آن `Game` است.

اگر همه‌ی قوانین با موفقیت بگذرند، هر تغییری که قوانین در `Game` ایجاد کرده‌اند باید حفظ شود و بازیکن باید عوض شود. تابع `changePlayer` برای همین در اختیار شما قرار داده شده است.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
