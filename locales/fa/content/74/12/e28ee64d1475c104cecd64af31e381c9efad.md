# مقدمه‌ای بر حلقه‌ی For

[حلقه‌ی For](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) راهی در اختیار شما می‌گذارد تا گروهی از دستورها را بارها اجرا کنید تا زمانی که شرطی برآورده شود.
این حلقه از چهار بخش تشکیل شده است:

```java
for (initialization; test; update) {
    body;
}
```

بخش `initialization` یک حالت اولیه برای حلقه تعیین می‌کند و دقیقاً یک بار در ابتدای حلقه اجرا می‌شود.
معمولاً متغیری را اعلام و مقداردهی می‌کند که در عبارت test و دستور update استفاده می‌شود.
برای مثال:

```java
int i = 1
```

عبارت `test` بررسی می‌کند که آیا حلقه باید پایان یابد.
اگر مقدارش `true` شود، ابتدا بدنه و سپس عبارت update اجرا می‌شود.
اگر مقدارش `false` شود، نه بدنه و نه دستور update اجرا نمی‌شوند و اجرا پس از آکولاد بسته‌ی حلقه ادامه می‌یابد.
معمولاً متغیری را بررسی می‌کند که در بخش initialization مقدار گرفته است.
برای مثال:

```java
i <= 10
```

پس از اجرای بدنه‌ی حلقه، عبارت `update` اجرا می‌شود.
معمولاً مقدار متغیر حلقه را به اندازه‌ی مقداری افزایش یا کاهش می‌دهد.
برای مثال:

```java
i++
```

یک حلقه‌ی `for` که چهار مجذور اول را چاپ می‌کند، چنین شکلی دارد:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

خروجی چنین خواهد بود:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

اگر بخواهید روی همه‌ی عناصر یک مجموعه پیمایش کنید، حلقه‌ی `for-each` ترجیح داده می‌شود، اما می‌توان این کار را با یک حلقه‌ی `for` هم به این شکل انجام داد:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

حلقه‌ی `for` در مقایسه با حلقه‌ی `for-each` چند مزیت دارد:

- می‌توانید از اندیس دلخواه خود شروع کنید یا در آن متوقف شوید.
- می‌توانید از هر شرط پایان «منطقی» که می‌خواهید استفاده کنید.
- می‌توانید با تغییر نحوه‌ی افزایش متغیر حلقه، از روی برخی عناصر بپرید.
- می‌توانید با شمارش معکوس، مجموعه‌ها را از آخر به اول پردازش کنید.
- می‌توانید از حلقه‌های `for` در موقعیت‌هایی استفاده کنید که در آن‌ها مجموعه‌ای در کار نیست.
