# درک بازگشت در JavaScript

بازگشت مفهومی قدرتمند در برنامه‌نویسی است که با فراخوانی یک تابع توسط خودش سر و کار دارد.
درک آن در ابتدا کمی دشوار است، اما وقتی مبانی آن را بفهمید، به ابزاری ارزشمند برای حل مسائل پیچیده تبدیل می‌شود.
ما بازگشت را در JavaScript با مثال‌هایی ساده و قابل‌فهم بررسی می‌کنیم.

## بازگشت چیست؟

بازگشت زمانی رخ می‌دهد که یک تابع، چه مستقیم و چه غیرمستقیم، خودش را فراخوانی کند.
این شبیه حلقه است، اما شامل شکستن یک مسئله به زیرمسئله‌های کوچک‌تر و قابل‌مدیریت‌تر می‌شود.

### مثال ۱: شمارش معکوس

بیایید با یک مثال ساده شروع کنیم: یک تابع شمارش معکوس.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

در این مثال:

- **حالت پایه**: وقتی مقدار `num` کوچک‌تر یا مساوی ۰ می‌شود، تابع «Blastoff!» را چاپ می‌کند و فراخوانی خودش را متوقف می‌کند.
- **حالت بازگشتی**: تابع مقدار فعلی `num` را چاپ می‌کند و خودش را با `num - 1` فراخوانی می‌کند.

### مثال ۲: فاکتوریل

حالا بیایید به یک مثال کلاسیک از بازگشت نگاه کنیم: محاسبه‌ی فاکتوریل یک عدد.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

در این مثال:

- **حالت پایه**: وقتی `n` برابر ۰ یا ۱ باشد، تابع ۱ را برمی‌گرداند.
- **حالت بازگشتی**: تابع `n` را در فاکتوریل `n - 1` ضرب می‌کند.

## مفاهیم کلیدی

### حالت پایه

هر تابع بازگشتی باید حداقل یک حالت پایه داشته باشد؛ شرطی که در آن تابع دیگر خودش را فراخوانی نمی‌کند.
بدون حالت پایه، بازگشت تا بی‌نهایت ادامه می‌یابد و به سرریز پشته می‌انجامد.

### حالت بازگشتی

حالت بازگشتی تعیین می‌کند که تابع چگونه خودش را با نسخه‌ی کوچک‌تر یا ساده‌تر مسئله فراخوانی می‌کند.

## مزایا و معایب بازگشت

**مزایا:**

- راه‌حل زیبا برای برخی مسائل.
- مانند مفهوم استقرای ریاضی عمل می‌کند.

**معایب:**

- می‌تواند نسبت به راه‌حل‌های تکراری کم‌بازده‌تر باشد.
- ممکن است در بازگشت‌های عمیق به سرریز پشته منجر شود.

## نتیجه‌گیری

بازگشت تکنیکی ارزشمند است که مسائل پیچیده را با شکستن آن‌ها به زیرمسئله‌های کوچک‌تر و قابل‌مدیریت‌تر ساده می‌کند.
درک حالت‌های پایه و حالت‌های بازگشتی برای پیاده‌سازی راه‌حل‌های بازگشتی مؤثر در JavaScript حیاتی است.
