# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | ورودی        | آدرس | آرایه‌ای از کلمه‌ها شامل ظرفیت سطل‌ها              |
| `$a1`    | ورودی        | عدد صحیح | سطل شروع (1 یا 2)                          |
| `$a2`    | ورودی        | عدد صحیح | حجم هدف                                  |
| `$a3`    | ورودی/خروجی | آدرس | آرایه‌ای از کلمه‌ها شامل محتوای نهایی سطل‌ها          |
| `$v0`    | خروجی       | عدد صحیح | تعداد عملیات لازم، و -1 اگر ممکن نباشد |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت استفاده می‌شود                     |
