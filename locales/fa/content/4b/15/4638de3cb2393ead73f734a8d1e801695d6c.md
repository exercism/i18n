# درباره‌ی تبدیل نوع

Go تبدیل صریح میان انواع مختلف را الزامی می‌کند.
برای مثال، این کد خطای کامپایلر ایجاد می‌کند:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

تبدیل میان انواع (که با نام «**type casting**» نیز شناخته می‌شود) با تابعی به نام نوع مقصد انجام می‌شود.
مقدار `v` با `T(v)` به نوع `T` تبدیل می‌شود.
برای مثال، برای تبدیل یک `int` به `float64` باید به این شکل عمل کنید:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

همین موضوع برای انواع سفارشی هم صادق است:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## تبدیل میان انواع اولیه و رشته

بسته‌ای به نام `strconv` برای تبدیل میان انواع اولیه (مانند `int`) و `string` وجود دارد.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

هشدار: استفاده از روش تبدیل استاندارد این رفتار را ندارد.
برای مثال:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

در ادامه چند مورد از دیگر روش‌های رایج تبدیل آمده است:

| روش         | کاربرد                       |
| ----------- | --------------------------- |
| ParseBool   | تبدیل `string` به `bool`     |
| FormatBool  | تبدیل `bool` به `string`     |
| ParseFloat  | تبدیل `string` به `float`    |
| FormatFloat | تبدیل `float` به `string`    |
| ParseInt    | تبدیل `string` به `int`      |
| FormatInt   | تبدیل `int` به `string`      |
