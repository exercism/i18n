# مقدمه

## «درست» و «غلط»

حالت‌های «منطقی» در Ruby با `true` و `false` نمایش داده می‌شوند. این دو حالت، «درست» و «غلط» هستند.

```ruby
happy = true
sad = false
```

## برابری و مقایسه

در Ruby می‌توانید شیءها را با نمادهای معمول برابری با یکدیگر مقایسه کنید:

- از `==` استفاده کنید تا ببینید آیا دو شیء با هم برابرند
- از `>` استفاده کنید تا ببینید آیا شیء سمت چپ **بزرگ‌تر از** شیء سمت راست است
- از `<` استفاده کنید تا ببینید آیا شیء سمت چپ **کوچک‌تر از** شیء سمت راست است.
- از `>=` یا `<=` برای بررسی «بزرگ‌تر یا مساوی» و «کوچک‌تر یا مساوی» به ترتیب استفاده کنید.

همچنین می‌توانید با عملگرهای معمول، عملیات منطقی انجام دهید:

- از `&&` یا `and` استفاده کنید تا ببینید آیا `x and y` «درست» است
- از `||` یا `or` استفاده کنید تا ببینید آیا `x or y` «درست» است.
- از `!` یا `not` برای معکوس کردن برابری استفاده کنید، مثلاً `x != y` (x با y برابر نیست)

چند نمونه:

```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
