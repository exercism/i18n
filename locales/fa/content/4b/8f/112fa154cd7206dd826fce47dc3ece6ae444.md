# درباره

ساختارهای داده که می‌توانند صفر یا چند عنصر را در خود نگه دارند، _مجموعه_ نامیده می‌شوند.
یک **آرایه** در Ruby مجموعه‌ای است که ترتیبی را که اشیاء در آن اضافه می‌شوند، حفظ می‌کند.
آرایه‌ها می‌توانند هر شیئی را در خود نگه دارند.
با استفاده از اندیس می‌توان شیءهایی به آرایه اضافه کرد یا آن‌ها را از آرایه بازیابی کرد.
اندیس‌گذاری آرایه در Ruby از صفر شروع می‌شود؛ یعنی اندیس اولین عنصر همیشه صفر است:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

در Ruby راه‌های متعددی برای ساختن آرایه وجود دارد:

- استفاده از سازنده‌ی لیترال `[]` _(رایج‌ترین)_
- فراخوانی صریح `Array.new`
- فراخوانی متد `Array()` در `Kernel`

متد `Array.new` دو آرگومان اختیاری می‌پذیرد: اندازه‌ی اولیه‌ی آرایه و یک شیء پیش‌فرض.

وقتی اندازه و شیء پیش‌فرض داده شوند، آرایه با `size` نسخه از شیء پیش‌فرض پر می‌شود.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

چون همه‌ی عناصر آرایه همان هش را ذخیره می‌کنند، تغییر در یکی از آن‌ها روی همه‌شان اثر می‌گذارد.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

اگر چند نسخه‌ی مستقل می‌خواهید، باید از نسخه‌ی بلوکی استفاده کنید؛ این نسخه هر بار که لازم باشد عنصری از آرایه مقداردهی اولیه شود، نتیجه‌ی آن بلوک را به کار می‌گیرد:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

ویژگی دیگر آرایه‌های Ruby این است که ماژول [Enumerable][enumerable-module] را در خود جای می‌دهند که متدهای مفید زیادی برای پیمایش، جست‌وجو، مرتب‌سازی، فیلتر کردن و کارهای مشابه روی عناصر آرایه اضافه می‌کند.
