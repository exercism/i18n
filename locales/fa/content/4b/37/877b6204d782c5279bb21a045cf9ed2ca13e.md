# مقدمه

## مقادیر «منطقی» در Julia

مقادیر «درست» یا «غلط» با نوع `Bool` نمایش داده می‌شوند.
این نوع فقط دو مقدار دارد: `true` و `false`.

```julia-repl
julia> true
true

julia> false
false
```

## عملگرهای منطقی

سه عملگر منطقی در Julia وجود دارد.

`&&` عملگر منطقی «و» است.
اگر عبارات در *هر دو* طرف `&&` مقدار `true` داشته باشند، نتیجه `true` خواهد بود.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` عملگر منطقی «یا» است.
اگر عبارت در *هر یک* از دو طرف `||` مقدار `true` داشته باشد، نتیجه `true` خواهد بود.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` عملگر منطقی «نقیض» است.
مقادیر `true` و `false` را جابه‌جا می‌کند.

```julia-repl
julia> !true
false

julia> !false
true
```

برای عبارات طولانی‌تر و پیچیده‌تر، بهتر است برای روشن شدن منظورتان از پرانتز استفاده کنید.

```julia-repl
julia> (true || false) && (false && true)
false
```
