# دستورالعمل‌ها

قرار است بافرهایی خالی ایجاد کنید و پنج عدد، یا پنج عنصر، اول دنباله‌ی فیبوناچی را فهرست کنید.

دنباله‌ی فیبوناچی مجموعه‌ای از اعداد است که در آن هر عنصر بعدی برابر با مجموع دو عنصر قبلی است. این دنباله را از عدد ۱ شروع می‌کنیم. بنابراین دو عنصر اول آن ۱ و ۱ هستند.

## 1. بافری از `count` صفر ایجاد کنید.

تابعی بنویسید که بافری از `count` صفر ایجاد می‌کند.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. پنج عنصر اول دنباله‌ی فیبوناچی را فهرست کنید

تابعی بنویسید که پنج عدد اول دنباله‌ی فیبوناچی را برمی‌گرداند.
پنج عنصر اول آن `1, 1, 2, 3, 5` هستند.

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
