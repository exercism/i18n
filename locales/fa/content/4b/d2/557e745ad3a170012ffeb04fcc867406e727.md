# نصب

## کاربران Windows

لطفاً [Windows Subsystem for Linux][wsl-link] را نصب کنید و بخش بعدی را ببینید.

## کاربران Linux/Mac

### نصب با brew

این ساده‌ترین راه برای نصب Chapel است.
یک نصب پایه‌ی کارآمد به شما می‌دهد که برای کار روی مسیر Exercism مناسب است.
کاربران پیشرفته‌تر ممکن است بخواهند Chapel را از کد منبع بسازند (بخش بعدی).

0. اگر تا الآن این کار را نکرده‌اید، مدیر بسته‌ی [brew][brew-link] را نصب کنید.
1. اول، مطمئن شوید که brew به‌روز است؛ این کار را با اجرای `brew update` انجام دهید.
2. Chapel را با اجرای `brew install chapel` نصب کنید.
3. با اجرای `chpl --version` بررسی کنید که نصب موفق بوده است.

این کار کامپایلر Chapel (`chpl`)، مدیر بسته‌ی `mason` که برای اجرای آزمون‌ها از آن استفاده خواهیم کرد، و ابزار تولید مستندات `chpldoc` را نصب می‌کند؛ این ابزار برای Exercism لازم نیست، اما خوب است که آن را داشته باشید، اگر (وقتی :) ) بخواهید کتابخانه‌های خودتان را در Chapel توسعه دهید.

### ساخت Chapel از کد منبع

کاربران پیشرفته‌تر ممکن است بخواهند خودشان Chapel را از کد منبع بسازند. برای این کار،

1. [پیش‌نیازها][prereqs-link] را نصب کنید.
2. بایگانی آخرین نسخه‌ی Chapel را [دانلود][download-link] کنید و آن را استخراج کنید.
3. اول باید نصب و راه‌اندازی را در جایی که می‌خواهید Chapel را نصب کنید آماده کنید.
این کار با اجرای اسکریپت `configure` که ارائه شده انجام می‌شود.
تنها با اجرای این دستور انجام می‌شود:

```
./configure
```

فایل‌های اجرایی، کتابخانه‌ها و فایل‌های اشتراکی را در `/usr/local/` نصب می‌کند؛ می‌توانید این مسیر را با گزینه‌ی `--prefix` تغییر دهید.
برای مثال، اگر می‌خواهید Chapel را در `~/.chapel` نصب کنید، می‌توانید این کار را انجام دهید:

```
./configure --prefix=~/.chapel
```

4. برای نصب کامپایلر و ابزارها، این دستور را اجرا کنید:

```
make
make mason
make chpldoc
make install
```

5. مطمئن شوید که پوشه‌ی `/dir/for/install/bin` در متغیر `PATH` شما قرار دارد.

برای اطلاعات بیشتر درباره‌ی روش‌های مختلف نصب Chapel و کار با کد منبع، صفحه‌ی [Building Chapel][building-link] را در مستندات ببینید.
