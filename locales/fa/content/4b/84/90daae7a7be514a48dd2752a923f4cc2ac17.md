# دستورالعمل‌ها

شما در حال پیاده‌سازی یک بازی نقش‌آفرینی هستید. شخصیت بازیکن با ساختار زیر نمایش داده می‌شود:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

بازیکن‌ها در این بازی باید به سطح ۱۰ برسند تا «مخزن مانا» برایشان باز شود و بتوانند پرتاب طلسم را شروع کنند. پیش از آن، مانای `Player` برابر `None` است.

شما روی دو بخش از قابلیت‌های این بازی کار می‌کنید: سازوکار احیا و سازوکار پرتاب طلسم.

متد `revive` باید بررسی کند که `Player` واقعاً مرده است (جانش به ۰ رسیده است) و اگر چنین بود، باید نمونه‌ای تازه از `Player` با ۱۰۰ جان برگرداند.
اگر سطح `Player` برابر ۱۰ یا بیشتر باشد، باید با ۱۰۰ مانا احیا شود.
اگر سطح `Player` کمتر از ۱۰ باشد، مانای آن باید `None` باشد. متد `revive` باید سطح `Player` را حفظ کند.

```rust
let dead_player = Player { health: 0, mana: None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: None, level: 2 }
```

اگر متد `revive` روی یک `Player` فراخوانی شود که جانش ۱ یا بیشتر است، متد باید `None` را برگرداند.

```rust
let alive_player = Player { health: 1, mana: Some(15), level: 11 };
alive_player.revive()
// Returns None
```

متد `cast_spell` یک ارجاع تغییرپذیر به `Player` و همچنین پارامتر `mana_cost` را می‌گیرد که نشان می‌دهد طلسم چقدر مانا هزینه دارد. این متد مقدار آسیبی را برمی‌گرداند که طلسم پرتاب‌شده وارد می‌کند؛ اگر طلسم با موفقیت پرتاب شود، این مقدار همیشه دو برابر هزینه‌ی مانای طلسم خواهد بود.

- اگر بازیکن به مخزن مانا دسترسی نداشته باشد، تلاش برای پرتاب طلسم باید جانش را به اندازه‌ی هزینه‌ی مانای طلسم کاهش دهد. مقدار آسیبی که برگردانده می‌شود باید ۰ باشد.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, None);
  ```

- اگر بازیکن مخزن مانا داشته باشد اما مانای کافی نداشته باشد، متد نباید اثری روی مخزن بگذارد و به‌جای آن باید ۰ برگرداند.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Some(3));
  ```

- در غیر این صورت، `mana_cost` باید از مخزن مانای `Player` کسر شود و مقدار مناسب آسیب برگردانده شود.

  ```rust
  let wizard = Player { health: 123, mana: Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Some(20));
  ```
