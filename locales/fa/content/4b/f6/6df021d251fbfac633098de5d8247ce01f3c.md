# پارامترهای متغیر

[_پارامترهای متغیر_][variadic-parameters] در Swift این امکان را می‌دهند که صفر یا چند مقدار از یک نوع یکسان به یک پارامتر واحد در یک تابع فرستاده شوند.
این ویژگی با افزودن `...` به حاشیه‌نویسی نوع پارامتر مشخص می‌شود.

این مقادیر به‌طور خودکار در یک آرایه گروه‌بندی می‌شوند که عناصر آن از همان نوع پارامتر متغیر هستند.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

هنگام استفاده از پارامترهای متغیر، Swift دو محدودیت دارد:

1. Swift اجازه می‌دهد هر تابع فقط یک پارامتر متغیر داشته باشد. تصمیم گرفته شده است که این محدودیت در نسخه‌ای از Swift در آینده برداشته شود، ولی در حال حاضر هنوز برقرار است.
2. اگر تابعی در تعریف خود پارامترهایی بعد از پارامتر متغیر داشته باشد، نخستین پارامتری که پس از پارامتر متغیر می‌آید _الزاماً_ باید برچسب آرگومان داشته باشد.
