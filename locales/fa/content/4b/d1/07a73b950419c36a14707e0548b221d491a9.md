# درباره

PHP تعدادی عملگر برای انجام عملیات حسابی در اختیار شما می‌گذارد. PHP در عملگرهای حسابی خود از ترتیب استاندارد عملیات ریاضی پیروی می‌کند. عملگرهایی که PHP فراهم می‌کند عبارت‌اند از:

* «همانی» (+)
* «نقیض» (-)
* «جمع» (+)
* «تفریق» (-)
* «ضرب» (*)
* «تقسیم» (/)
* «باقیمانده» (%)
* «توان» (**)

بیایید نگاهی به هرکدام بیندازیم و ببینیم چگونه می‌توان از آن‌ها استفاده کرد:

## همانی (+)

عملگر همانی (+) روی یک مقدار واحد کار می‌کند (عملگر یکانی). نتیجه‌ی آن، مقدار `float` یا `int` متغیر است.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## نقیض (-)

عملگر نقیض روی یک مقدار واحد کار می‌کند (عملگر یکانی) و قرینه‌ی مقدار عددی را برمی‌گرداند.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## جمع (+) و تفریق (-)

عملگر جمع، دو مقدار دو طرف خود را با هم جمع می‌کند و عملگر تفریق، مقدار سمت راست را از مقدار سمت چپ کم می‌کند.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## تقسیم (/)

عملگر تقسیم، نتیجه‌ی تقسیم مقدار سمت چپ بر مقدار سمت راست را می‌دهد. اگر مقدار سمت راست ۰ باشد، خطای `DivisionByZeroError` رخ می‌دهد.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## ضرب (*)

عملگر ضرب، نتیجه‌ی ضرب مقدارهای سمت چپ و راست در هم را برمی‌گرداند.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## باقیمانده (%)

عملگر باقیمانده، باقیمانده‌ی تقسیم مقدار سمت چپ بر مقدار سمت راست را برمی‌گرداند. این عملگر برای تشخیص بخش‌پذیری یک عدد بر عددی دیگر، تعیین زوج یا فرد بودن یک مقدار و بسیاری کارهای دیگر بسیار سودمند است.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## توان (**)

از عملگر توان برای رساندن مقدار سمت چپ به توان مقدار سمت راست استفاده می‌شود. پیش از PHP 5.6 برای انجام همین کار باید از تابع `pow` استفاده می‌کردید.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

عملگر توان از اعداد صحیح و اعشاری برای هر دو طرف پشتیبانی می‌کند؛ بنابراین می‌توانید از آن برای محاسبه‌ی ریشه‌ی دوم (یا ریشه‌های دیگر) یا مقدارهای نمایی پیچیده‌تر استفاده کنید.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## ترتیب عملیات

PHP از ترتیب استاندارد عملیات در ریاضی پیروی می‌کند. یعنی به‌جای این‌که عملیات را از چپ به راست انجام دهد، هر عملگر یک اولویت دارد و عملیات بر اساس اولویت آن‌ها انجام می‌شوند. ترتیب عملیات چنین است:

* پرانتز
* توان
* ضرب، تقسیم
* جمع، تفریق

ضرب و تقسیم هم‌سطح یکدیگرند. به همین ترتیب، جمع و تفریق نیز هم‌سطح هستند.

یعنی مقدار زیر به‌جای ۱۰ برابر ۱۷ می‌شود، چون ضرب اولویت بالاتری از جمع دارد:

```php
$value = 2 + 3 * 5;
```

PHP همچنین تعدادی عملگر انتساب مفید در اختیار شما می‌گذارد که وقتی عملیاتی را روی یک متغیر انجام می‌دهید و نتیجه را دوباره به خودش نسبت می‌دهید، عملگرهای حسابی را با انتساب ترکیب می‌کنند. به این‌ها در مفهوم `Assignment Operators` می‌پردازیم.
