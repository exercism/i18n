# کلاس تغییرناپذیر

یک `SCOREBOARD` موجودی است که تغییر می‌کند. دو اسم برای یک تابلو امتیازات، همان امتیاز را می‌بینند، چون فقط یک تابلو وجود دارد و هر دو اسم به آن اشاره می‌کنند.

یک جهت این‌طور نیست. `350 degrees` چیز دیگری نمی‌شود؛ فقط *هست*. اعداد این‌طور رفتار می‌کنند، رشته‌ها هم همین‌طور، و کلاس‌های خودتان هم می‌توانند این‌طور باشند.

## تغییرناپذیر

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

دو کلمه همه‌چیز را تغییر می‌دهند. شیء یک کلاس تغییرناپذیر یک **مقدار** است، نه شیئی که به آن اشاره می‌شود:

- هنگام انتساب یا ارسال کپی می‌شود، پس هیچ‌کس دیگری نمی‌تواند مال شما را تغییر دهد؛
- هرگز نمی‌تواند `void` باشد؛
- و نمی‌توان به ویژگی‌هایش مقدار تخصیص داد.

## تغییر یک شیء با ساختن شیء دیگر

از آنجا که `degrees := 90` مجاز نیست، `attr` چیز دیگری می‌دهد: روالی که مقدار جدید را می‌گیرد و **شیء جدیدی** را با مقدار تغییر یافته بازمی‌گرداند.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

اصل دست‌نخورده باقی می‌ماند. کل شیوه همین است، و `create` هم همین‌طور نوشته می‌شود:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

اینجا `new` وجود ندارد. یک شیء تغییرناپذیر همیشه وجود دارد، پس `b : SAME` از قبل یکی است، با همه‌ی ویژگی‌ها در مقدار خالی خود.

بنابراین روالی که یک جهت را «تغییر می‌دهد» یکی جدید بازمی‌گرداند:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## مقایسه

مقدارها بر اساس آنچه در خود دارند مقایسه می‌شوند، نه بر اساس اینکه کدام شیء هستند؛ اما باید بگویید چگونه. `is_eq` را بنویسید، و `=` از آن استفاده خواهد کرد:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

بدون آن، `=` روی دو جهت کامپایل نمی‌شود.

## کدام را انتخاب کنیم

وقتی شیء هویت ندارد و هیچ جنبه‌ای از آن به‌طور معقول تغییر نمی‌کند، از یک کلاس تغییرناپذیر استفاده کنید: یک جهت، یک نقطه، یک تاریخ، یک طول. وقتی شیء یک شیء مشخص است که اتفاق‌ها برایش می‌افتند، از یک کلاس معمولی استفاده کنید: یک تابلو امتیازات، یک هارنس، یک فایل.

آزمون این است که آیا «همان» به معنی «برابر» است یا «همان یکی».
