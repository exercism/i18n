# درباره

فهرست‌ها در C# مجموعه‌هایی از مقادیر اولیه یا نمونه‌هایی از `struct` یا کلاس‌ها هستند. این‌ها در کتابخانه‌ی پایه به صورت [`List<T>`][lists-docs] پیاده‌سازی شده‌اند، که در آن `T` نوع عنصر موجود در فهرست است. API مجموعه‌ای غنی از متدها را برای ساختن و دستکاری فهرست‌ها در اختیارتان می‌گذارد.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

تعریف یک مجموعه معمولاً شامل یک جای‌نگهدار میان علامت‌های کوچک‌تر و بزرگ‌تر است که بنا بر قرارداد اغلب `T` نام دارد. این کار به کاربر مجموعه اجازه می‌دهد مشخص کند چه نوع عناصری باید در مجموعه ذخیره شوند.

برخلاف [concept:csharp/arrays]()، فهرست‌ها می‌توانند اندازه‌ی خود را به‌صورت پویا تغییر دهند.

## LINQ

API توکار `List<T>` غنی است (شامل نگاشت‌ها و فیلترهایی مانند `ConvertAll`، `FindAll` و `Foreach`) و [نحوه‌ی نگارش حلقه][for-each] آن هم بسیار روشن است. آشنایی با این API قطعاً لازم است. اما برای بسیاری از کارها، پرس‌وجوی یکپارچه‌ی زبان ([LINQ][linq]) هم در دسترس است که قدرتمندتر است، کاربرد گسترده‌تری دارد و این مزیت را دارد که در سراسر مجموعه‌های کتابخانه‌ای، مجموعه‌های شخص ثالث و کلاس‌های خودتان یک رابط یکدست فراهم می‌کند.
