# راهنما

## 1. چاپ کارت شناسایی برای یک کارمند

- از [قالب رشته][string-template] می‌توان برای ساختن رشته‌های توصیفی استفاده کرد.
- یک [متد توکار برای تبدیل رشته به حروف بزرگ][to-upper-case] وجود دارد.

## 2. چاپ کارت شناسایی برای یک کارمند جدید

- قبل از استفاده از `ID`، باید بررسی کنید که `null` است یا نه.
- برای بررسی `null` بودن یک مقدار، می‌توانید از [عملگر تساوی][kotlin-operators] استفاده کنید.

## 3. چاپ کارت شناسایی برای مالک

- می‌توانید از [عملگر الویس][elvis-operator] استفاده کنید تا زمانی که یک متغیر `null` است، مقدار جایگزینی به کار ببرید.
