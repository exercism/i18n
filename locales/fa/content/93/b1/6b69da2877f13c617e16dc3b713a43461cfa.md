# مقدمه

## توابع کال‌بک

«توابع کال‌بک» توابعی هستند که به‌عنوان آرگومان ارسال می‌شوند. این الگوی برنامه‌نویسی دنباله‌ای از فراخوانی توابع را در برنامه‌نویسی همزمان و ناهمزمان ایجاد می‌کند. نوشتن یک تابع کال‌بک هیچ تفاوتی با نوشتن یک تابع ندارد؛ اما تابع کال‌بک باید با امضایی که تابع فراخوانی‌کننده تعریف کرده است مطابقت داشته باشد.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

شما همچنین می‌توانید کال‌بک‌ها را به‌صورت یک عبارت تابع بنویسید:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
