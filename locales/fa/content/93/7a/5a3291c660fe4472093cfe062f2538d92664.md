# مقدمه

«struct» نوعی افزونه است که روی [نقشه‌ها][exercism-maps] ساخته شده است و بررسی‌های زمان کامپایل و مقادیر پیش‌فرض را فراهم می‌کند. اسم یک struct از روی ماژولی که در آن تعریف شده گرفته می‌شود. برای تعریف struct از سازه‌ی `defstruct` استفاده کنید. این سازه معمولاً بلافاصله پس از تعریف ماژول می‌آید. `defstruct` یا لیستی از «اتم»ها را می‌پذیرد (برای مقادیر پیش‌فرض `nil`) و یا یک «لیست کلیدواژه» (برای مقادیر پیش‌فرض مشخص‌شده). فیلدهای بدون مقدار پیش‌فرض باید پیش از فیلدهای دارای مقدار پیش‌فرض بیایند.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## دسترسی به فیلدها و به‌روزرسانی

از آنجا که structها بر پایه‌ی نقشه‌ها ساخته شده‌اند، می‌توانیم از بیشتر توابع نقشه برای گرفتن و دستکاری مقادیر استفاده کنیم. _رفتار دسترسی_ برای structها پیاده‌سازی **نشده** است. در عوض، توصیه می‌شود برای دسترسی به فیلدهای struct از _عملگر دسترسی ایستا_ `.` استفاده کنید.

- گرفتن/واکشی مقادیر فیلد:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- به‌روزرسانی مقادیر فیلد

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## تطبیق الگو

از structها می‌توان در تطبیق الگو با اسم struct یا بدون آن استفاده کرد.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

با قرار دادن اسم struct در الگو، می‌توانید مطمئن شوید که هر دو طرف چپ و راست، structهایی از یک نوع هستند.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## الزام به مقداردهی اولیه‌ی مقادیر فیلد

می‌توانیم از ویژگی ماژول `@enforce_keys` همراه با لیستی از کلیدهای فیلد استفاده کنیم تا مطمئن شویم مقادیر هنگام ساخت struct مقداردهی اولیه می‌شوند. اگر کلیدی در این لیست نباشد، مقدارش همان‌طور که در مثال بالا دیدید `nil` خواهد بود. اگر کلید الزامی‌ای مقداردهی اولیه نشود، خطایی رخ می‌دهد.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
