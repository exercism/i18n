# مقدمه

مقدار `null` برای نشان‌دادن _نبود_ یک مقدار به کار می‌رود. نوع **تهی‌پذیر** نوعی است که به یک متغیر اجازه می‌دهد مقدار `null` را بگیرد. برای اینکه هر نوعی را تهی‌پذیر کنیم، آن را در `Null<T>` قرار می‌دهیم:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

برای بررسی اینکه یک مقدار در حال حاضر `null` است، کافی است از یک عبارت `if` استفاده کنید:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
