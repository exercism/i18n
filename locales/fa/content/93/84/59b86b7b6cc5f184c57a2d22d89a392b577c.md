# مقدمه‌ای بر تأیید نوع

«رابط‌ها» در Go می‌توانند درباره‌ی نوع زیرین ابهام ایجاد کنند.
«تأیید نوع» به ما اجازه می‌دهد که مقدار مشخص زیرینِ مقدار رابط را با استفاده از این نحوه‌ی نگارش استخراج کنیم: `interfaceVariable.(concreteType)`.

برای مثال:

```go
var input interface{} = 12
number := input.(int)
```

توجه: اگر متغیر رابط مقداری از آن نوع مشخص نداشته باشد، این کار باعث پنیک می‌شود.

می‌توانیم با استفاده از هر دو مقدار بازگشتیِ تأیید نوع بررسی کنیم که آیا مقدار رابط یک نوع مشخص خاص را در خود دارد: مقدار زیرین و یک مقدار «منطقی» که گزارش می‌دهد آیا تأیید موفق بوده است یا نه.
برای مثال:

```go
str, ok := input.(string) // no panic if input is not a string
```

اگر `input` یک `string` در خود داشته باشد، آنگاه `str` همان مقدار زیرین خواهد بود و `ok` «درست» خواهد بود.
اگر `input` یک `string` نداشته باشد، آنگاه `str` مقدار صفرِ نوع `string` خواهد بود (یعنی `""`، همان رشته‌ی خالی) و `ok` «غلط» خواهد بود.
در هیچ حالتی پنیک رخ نمی‌دهد.

## سوییچ نوع

یک **سوییچ نوع** می‌تواند چندین تأیید نوع را پشت سر هم انجام دهد.
نحوه‌ی نگارش آن همانند تأیید نوع است (`interfaceVariable.(concreteType)`)، اما به‌جای `concreteType` از «کلیدواژه»ی `type` استفاده می‌شود.
در ادامه یک مثال آمده است:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
