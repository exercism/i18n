# بازی با نوع

بازی با نوع را ممکن است با نام تبدیل اجباری نوع هم بشناسند.
بازی با نوع زمانی رخ می‌دهد که دو مقدار از انواع مختلف برای انجام یک عملیات به یک نوع یکسان تبدیل اجباری شوند.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

وقتی عبارت ارزیابی می‌شود، مقدار رشته‌ای به‌طور ضمنی به یک `int` تبدیل می‌شود تا با انتظار عملگر `*` همخوانی داشته باشد.
اینکه کدام نوع تبدیل اجباری شود، PHP بر اساس قواعد همان عملیات تصمیم می‌گیرد و این قواعد بسیار متنوع‌اند.

تبدیل اجباری نوع هنگام فراخوانی توابع و متدها هم رخ می‌دهد:

```php
strlen(12321);
# => 5
```

## قالب‌گیری نوع

به‌جای تکیه بر تبدیل اجباری ضمنی، می‌توانیم با استفاده از قالب‌گیری نوع به سبک `C` به‌صورت صریح مقدار را وادار کنیم که به‌عنوان نوع خاصی ارزیابی شود:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

این کار مقدار را به نوعی تبدیل می‌کند که داخل پرانتز `(...)` مشخص شده است.
همه‌ی انواع اولیه می‌توانند به‌عنوان نوع مقصد استفاده شوند: `bool`، `int`، `float`، `string`، `array`، `object`.

## تبدیل فقط موقت

بازی با نوع یا قالب‌گیری **نوع مقدار را که در یک متغیر ذخیره شده است تغییر نمی‌دهد**.
فقط ورودی عملیات تبدیل می‌شود.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## از دست رفتن اطلاعات

وقتی مقداری به نوع دیگری تبدیل اجباری می‌شود، ممکن است در این مسیر اطلاعاتی از دست برود:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

تکیه بر قالب‌گیری، چه صریح و چه ضمنی، می‌تواند در یک سیستم بزرگ‌تر خطا ایجاد کند.

## قالب‌گیری صریح نوع به `array` و `object`

مقادیر را می‌توان به انواع `array` و `object` هم قالب‌گیری کرد.
اگر مقداری که آرایه یا شیء نیست به `array` قالب‌گیری شود، به یک عنصر واحد تبدیل می‌شود که درون یک آرایه قرار می‌گیرد:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

وقتی به `object` قالب‌گیری شود، مقدار در یک ویژگی عمومی به اسم `scalar` قرار داده می‌شود:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` نوع کلاسی بی‌نام است که به‌صورت توکار در PHP وجود دارد.
