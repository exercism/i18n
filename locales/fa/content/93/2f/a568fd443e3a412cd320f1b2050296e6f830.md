# درباره

Perl یک زبان برنامه‌نویسی است که لری وال آن را ساخت و نخستین بار در سال ۱۹۸۷ منتشر شد.

## بسته و ماژول

بسته مجموعه‌ای از کد است که معمولاً درون یک فایل ماژول هم‌نام با پسوند `.pm` قرار می‌گیرد.
سپس می‌توان ماژول را در فایل دیگری وارد کرد، معمولاً با کلیدواژه‌ی `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## متغیر

سه نوع متغیر وجود دارد: اسکالر (`$foo`)، آرایه (`@bar`) و هش (`%baz`).
برای ساده ماندن مطلب، در اینجا فقط از متغیرهای اسکالر استفاده می‌شود.
یک مقدار اسکالر می‌تواند یکی از این‌ها باشد: یک رشته، یک عدد، یک مقدار «منطقی»، یا یک [ارجاع][perlreftut] به چیزی.
نبودِ مقدار هم `undef` است.


کلیدواژه‌های `my` و `our` یک متغیر را در حوزه‌ی واژگانی اعلام می‌کنند، مثلاً `my $foo;`.
با `our`، این متغیر به یک متغیر بسته با همان اسم نیز پیوند داده می‌شود.
روش‌های دیگری هم برای اعلام متغیرها وجود دارد که در اینجا به آن‌ها نمی‌پردازیم.

می‌توانید با عملگر `=` به یک متغیر مقدار بدهید، مثلاً `$foo = 1;`، که می‌توان آن را همزمان با اعلام متغیر انجام داد، مثلاً `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## زیرروال

کلیدواژه‌ی `sub` یک [زیرروال][perlsub] اعلام می‌کند.
کلیدواژه‌ی `return` از زیرروال خارج می‌شود و مقادیر مشخص‌شده را برمی‌گرداند، یا اگر چیزی داده نشده باشد یک فهرست خالی را برمی‌گرداند.
بدون `return` مشخص، مقدار بازگشتی بر اساس بافت (اسکالر، فهرست یا تهی) زیرروال مورد استفاده و آخرین دستور آن تعیین می‌شود.

```perl
sub hello () {
    return 'Hello, World!';
}
```

نسخه‌های اخیر Perl به شما اجازه می‌دهند پارامترهای صوری را در یک [امضا][perlsubsig] مشخص کنید.
فهرست پارامترها می‌تواند شامل متغیرهای اسکالر، آرایه یا هش باشد.
فهرست پارامتر خالی یعنی زیرروال هیچ آرگومانی نمی‌پذیرد.
نسخه‌های قدیمی‌تر Perl برای گرفتن آرگومان‌ها به متغیر ویژه‌ی `@_` نیاز داشتند که در اینجا به آن نمی‌پردازیم.
