# مقدمه

## لیست

`list` در F# مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار است. همه‌ی مقدارهای یک لیست باید نوع یکسانی داشته باشند. چون لیست تغییرناپذیر است، پس از ساخته شدنش، مقدارش هرگز تغییر نمی‌کند. هر تابع یا عملگری که به نظر برسد لیست را تغییر می‌دهد (مثلاً افزودن یک عنصر)، در واقع لیست جدیدی برمی‌گرداند.

لیست را می‌توان به این صورت تعریف کرد:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

رایج‌ترین راه افزودن یک عنصر به لیست، استفاده از عملگر `::` (cons) است:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

هر لیست در F# یک _سر_ (اولین عنصر) و یک _دم_ (همه‌ی عنصرهای پس از عنصر اول) دارد. دم یک لیست خودش یک لیست است.

لیست یا با تابع‌ها و عملگرهای تعریف‌شده در ماژول `List` دستکاری می‌شود، یا به‌صورت دستی با تطبیق الگو با الگوهای _list_ و _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

همچنین می‌توانید هنگام تطبیق الگو یک مقدار را _نادیده_ بگیرید؛ وقتی در یک حالت خاص به مقداری اهمیت نمی‌دهید (یعنی نمی‌خواهید از آن مقدار _استفاده_ کنید)، می‌توانید برای نشان دادن این موضوع از زیرخط (`'_'`) استفاده کنید:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

`'_'` به‌تنهایی باید هنگام تطبیق الگو همیشه _آخرین_ مورد باشد؛ هر مقداری که با هیچ‌یک از سایر حالت‌ها مطابقت نکند، با این حالت مدیریت می‌شود.
