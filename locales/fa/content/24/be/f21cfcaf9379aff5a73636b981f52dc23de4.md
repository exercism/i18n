# عدد

Crystal یک نوع داده به نام `Number` دارد که نوع پایه‌ی همه‌ی انواع عددی است.
درون نوع `Number` دو زیرنوع اصلی وجود دارد: [`Int`][int] و [`Float`][float].

`Int` کوتاه‌شده‌ی integer است و اعداد صحیح را نمایش می‌دهد.
`Int` می‌تواند هم منفی باشد و هم مثبت، بدون هیچ ممیز اعشاری.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` اعدادی را نمایش می‌دهد که ممیز اعشاری دارند.
مقادیر `Float` می‌توانند هم منفی باشند و هم مثبت.

```crystal
10.5.class
# => Float64
```

## تبدیل بین `Int` و `Float`

با استفاده از متدهای `to_i` و `to_f` می‌توانید بین `Int` و `Float` تبدیل انجام دهید.
هنگام تبدیل از `Float` به `Int`، عدد به پایین گرد می‌شود.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## عملگرهای حسابی

می‌توانید [عملگرهای حسابی پایه][math] را روی `Int` و `Float` به کار ببرید.
این عملگرها عبارت‌اند از `+`، `-`، `*`، `/` و `%`.
هنگام استفاده از این عملگرها می‌توانید `Int` و `Float` را با هم ترکیب کنید.

### جمع، تفریق و ضرب

عملگر `+` برای جمع، عملگر `-` برای تفریق و عملگر `*` برای ضرب به کار می‌رود.

| عملگر | مثال           |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### تقسیم

تقسیم برای بخش کردن اعداد به کار می‌رود.
عملگر `/` برای تقسیم به کار می‌رود.
نتیجه همیشه یک `Float` خواهد بود.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
در برخی زبان‌های برنامه‌نویسی، تقسیم بر صفر به خطا منجر می‌شود.

در Crystal، تقسیم بر صفر نتیجه‌اش `Infinity` یا `-Infinity` است.
تنها استثنا تقسیم صفر بر صفر است که به `NaN` (نه یک عدد) منجر می‌شود.
`Infinity` و `NaN` مقادیر خاصی در نوع `Float` به شمار می‌روند.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## تقسیم صحیح

تقسیم صحیح برای تقسیم اعداد و به دست آوردن بخش صحیح نتیجه به کار می‌رود.
نتیجه همیشه به پایین گرد شده و به یک `Int` تبدیل می‌شود.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
تقسیم بر صفر در تقسیم صحیح به خطای `DivisionByZeroError` منجر می‌شود.
این با تقسیم معمولی تفاوت دارد.
~~~~

### باقیمانده

باقیمانده برای به دست آوردن باقیمانده‌ی یک تقسیم به کار می‌رود.
عملگر `%` برای باقیمانده به کار می‌رود.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
تقسیم بر صفر در باقیمانده به خطای `DivisionByZeroError` منجر می‌شود.
این با تقسیم معمولی تفاوت دارد.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## توان

توان برای رساندن یک عدد به یک توان به کار می‌رود.
عملگر `**` برای توان به کار می‌رود.
نتیجه‌ی عملیاتی که با یک `Float` و یک `Int` انجام شود، یک `Float` خواهد بود.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## گرد کردن

متد `round` یک آرگومان اختیاری می‌گیرد: تعداد رقم‌های اعشاری که باید به آن گرد شود.
تعداد پیش‌فرض رقم‌های اعشاری ۰ است.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### گرد کردن به بالا و پایین

همچنین می‌توانید با متدهای `ceil` و `floor` به بالا یا پایین به یک `Int` گرد کنید.
متد `ceil` به بالا و متد `floor` به پایین گرد می‌کند.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## اولویت و پرانتزها

Crystal پرانتز (`()`) را مجاز می‌داند که می‌توان از آن برای گروه‌بندی عبارت‌ها استفاده کرد.
این زمانی مفید است که بخواهید ترتیب عملیات را تغییر دهید.

هنگام استفاده از چند عملگر حسابی، ترتیب عملیات همانند ریاضیات است که به [PEMDAS][pemdas] معروف است.
این ترتیب عبارت است از پرانتز (`()`)، توان (`**`)، ضرب (`*`) و تقسیم (`/`) و جمع (`+`) و تفریق (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
