# مقدمه

Clojure زبانی تابعی است و توابع در آن جایگاه «شهروندان درجه‌یک» را دارند. یعنی می‌توان آن‌ها را درست مانند داده به توابع دیگر پاس داد یا به‌وسیله‌ی توابع دیگر ساخت. به‌ویژه، Clojure مجموعه‌ی غنی‌ای از توابع مرتبه‌بالا را همراه دارد که توابع تازه‌ای را بر پایه‌ی توابع موجود می‌سازند. در اینجا چهار مورد مهم را بررسی می‌کنیم: `partial`، `comp`، `memoize` و `juxt`. این توابع تابع‌ساز در دسته‌ی گسترده‌تری از توابع مرتبه‌بالا جای می‌گیرند، مانند `map`، `reduce`، `apply` و `complement` که فقط چند نمونه از آن‌ها هستند. این توابع روی توابع موجود عمل می‌کنند.

## partial

به‌طور کلی، اگر تابعی موجود مانند `my-function` با پارامترهای `p1, p2, ..., pN` داشته باشیم، می‌توانیم برخی از پارامترهای آن را، یعنی `p1, p2, ..., pM`، با مقادیر ثابت `v1, v2, ..., vM` تثبیت کنیم. این کار را با اعمال `partial` به‌صورت زیر انجام می‌دهیم: `(partial my-function v1 v2 ... vM)`.

نتیجه یک تابع تازه است که تابع اصلی `my-function` را با تثبیت `p1=v1, p2=v2, ..., pM=vM` اعمال می‌کند. تابع تازه‌ی ما پارامترهای باقی‌مانده را، یعنی `pM+1, pM+2, ..., pN`، به‌عنوان ورودی می‌گیرد؛ مقادیر این پارامترها هنگام اعمال `partial` مشخص نشده‌اند:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

به‌عنوان یک مثال ساده، بیایید تابعی به اسم `inc-by-9` تعریف کنیم که هر مقدار ورودی را به اندازه‌ی ثابت ۹ افزایش می‌دهد. می‌توان چنین تابعی را به‌صورت زیر پیاده‌سازی کرد:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

به‌عنوان مثال دوم، تابعی به اسم `generic-greetings` داریم که اسم شخصی را که می‌خواهیم به او خوش‌آمد بگوییم، همراه با یک پیام متنی آغازین و یک پیام متنی پایانی به کار می‌برد:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

و با استفاده از `partial` همیشه یک پیام خوش‌آمد مشخص به کار می‌بریم:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

از `comp` می‌توان برای ساختن ترکیبی از هر تعداد تابعی که بخواهیم استفاده کرد. به‌طور کلی، ترکیب `N` تابع `f1, f2, ..., fN` یعنی اعمال آن توابع به ترتیب پشت‌سرهم، به این شکل که خروجی تابع پیشین به تابع بعدی پاس داده می‌شود. در نمادگذاری ریاضی، این‌گونه بیان می‌شود:

```
f1 (f2 (... fN(x)))
```

در Clojure، این معادل انجام کار زیر است:

```clojure
(f1 (f2 (... (fN x))))
```

با استفاده از `comp` می‌توانیم تابع تازه‌ای بسازیم که این ترکیب را برایمان انجام می‌دهد:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

به‌عنوان مثال، فرض کنید می‌خواهیم مجموعه‌ای از اعداد را با هم جمع کنیم و بعد نتیجه را در ۶ ضرب کنیم. می‌توانیم این کار را به‌صورت زیر انجام دهیم:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` امکان استفاده‌ی دوباره از نتایج محاسبه‌شده‌ی پیشین را که به یک ورودی مشخص مربوط‌اند فراهم می‌کند. تابع *مموایز‌شده* با گرفتن همان ورودی، همان نتیجه را برمی‌گرداند، بدون اینکه لازم باشد دوباره آن را محاسبه کند. این کار از این واقعیت بهره می‌برد که توابع `clojure` به‌طور پیش‌فرض *شفافیت ارجاعی* دارند: با گرفتن همان ورودی، همیشه همان خروجی را تولید می‌کنند و همین باعث می‌شود استفاده‌ی دوباره از محاسبات پیشین به‌سادگی ممکن باشد.

برای اینکه ببینیم این چگونه کار می‌کند، بیایید از یک نمونه‌ی ساختگی استفاده کنیم که در آن تابع پیش از تولید خروجی دو ثانیه به خواب می‌رود، تا بتوانیم *زمان محاسبه* را پیش و پس از استفاده از `memoize` به‌سادگی مقایسه کنیم.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` تابعی می‌سازد که توابع پاس‌داده‌شده به آن را به ترتیب از چپ به راست اعمال می‌کند. نتیجه یک بردار است که نتیجه‌ی هر تابع به‌تنهایی، یکی از مؤلفه‌های این بردار می‌شود:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

به‌عنوان یک مثال ساده، تابعی می‌سازیم که حاصل‌ضرب `x` در عامل‌های پی‌درپی (از ۲ تا ۵) را محاسبه می‌کند:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
