# مقدمه

اعداد صحیح را می‌توان نه فقط به‌عنوان مقدارهای عددی، بلکه به‌عنوان الگوهایی از بیت‌ها دید. واژگان [`math`][math] در Factor عملیات استاندارد سطح پایین روی این الگوهای بیت را دارد و واژگان [`math.bitwise`][bitwise] چند ابزار کمکی برای کار با مقدارهای با عرض ثابت به آن اضافه می‌کند.

## شیفت بیت‌ها

`shift ( m n -- m' )` بیت‌های `m` را شیفت می‌دهد. یک `n` «مثبت» به چپ شیفت می‌دهد (در هر مرحله در ۲ ضرب می‌شود) و یک `n` «منفی» به راست (در هر مرحله بر ۲ تقسیم می‌شود):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

برای اعداد صحیح مثبت، شیفت راست بیت‌ها را از پایین بیرون می‌ریزد و با صفر پر می‌کند. برای اعداد صحیح «منفی»، `shift` در Factor حسابی است: بیت علامت را حفظ می‌کند و به‌طور مفهومی از سمت چپ با نسخه‌های همان بیت علامت پر می‌کند. (اعداد صحیح Factor دقت دلخواه دارند، بنابراین «سمت چپ» تا هرجا که لازم باشد ادامه می‌یابد.)

## منطق بیتی

چهار عملیات منطقی پایه عبارت‌اند از:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`bitnot` روی `0b1011` برابر `-12` است، چون اعداد صحیح Factor دقت دلخواه دارند: وارونه کردن بیت‌های `0b1011` به‌طور مفهومی یعنی «همه یک، با چهار بیت پایین که به `0100` وارونه شده‌اند»، که اگر به‌عنوان یک عدد بزرگ علامت‌دار خوانده شود `-12` است.

## در نظر گرفتن یک مقدار به‌عنوان N بیت

`bits ( x n -- y )` از `math.bitwise`، `x` را روی `n` بیت پایینش ماسک می‌کند. این روش Factor برای «تفسیر دوباره‌ی یک مقدار به‌عنوان یک عدد صحیح بدون علامت N بیتی» است:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

مثال دوم برای این تمرین مهم است. اگر با یک مقدار منفی Int32 با مکمل دو شروع کنید و بخواهید آن را به‌اندازه‌ی `amount` به‌شکل «منطقی» به راست شیفت دهید (پر کردن از سمت چپ با صفر)، اصطلاح Factor این است:

```
( value -- shifted )
32 bits  amount neg  shift
```

اول روی ۳۲ بیت ماسک کنید تا به تفسیر بدون علامت بروید، بعد شیفت دهید. چون مقدار ماسک‌شده منفی نیست، `shift` به‌سادگی بیت‌ها را از پایین بیرون می‌ریزد و با صفر پر می‌کند.
