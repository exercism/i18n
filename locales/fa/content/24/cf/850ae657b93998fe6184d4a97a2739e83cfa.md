# مقدمه

حافظه‌ی پویا با توابع کتابخانه‌ای پیاده‌سازی می‌شود که برنامه‌نویس از آن‌ها برای تخصیص و آزادسازی حافظه در زمان اجرا استفاده می‌کند.
از آنجا که برنامه‌نویس تخصیص و آزادسازی حافظه را کنترل می‌کند، «حافظه‌ی پویا» تنها تا جایی ایمن است که برنامه‌نویس از خطای انسانی در امان باشد.
به همین دلیل، حافظه‌ی پویا یکی از منابع اصلی باگ‌های برنامه‌نویسی و یکی از اهداف اصلی حملات هکری است.

## malloc

`malloc` تابعی است که در `stdlib.h` اعلان شده است و برای تخصیص حافظه‌ی پویا به کار می‌رود.
اگر تخصیص موفق باشد، اشاره‌گری برگردانده می‌شود که به آدرس اولین بایت حافظه‌ی تخصیص‌یافته اشاره می‌کند.
اگر تخصیص موفق نباشد، `NULL` برگردانده می‌شود.
احتیاط حکم می‌کند که نتیجه‌ی `malloc` را برای `NULL` بررسی کنید و اگر شکست خورد، به‌شکلی مناسب با آن برخورد کنید.
اشاره‌گر برگردانده‌شده از نوع `pointer-to-void` است که تقریباً می‌توان آن را یک اشاره‌گر «عمومی» در نظر گرفت که می‌تواند به نوع مشخصی که آن حافظه به کار می‌برد تبدیل شود.
`malloc` یک پارامتر دارد که اندازه‌ی حافظه‌ی موردنظر بر حسب بایت است.
اندازه‌ی کل برای تخصیص یک آرایه، اندازه‌ی نوع داده‌ی هر عنصر ضرب در تعداد عناصر است.
عملگر `sizeof` معمولاً برای به دست آوردن اندازه‌ی نوع داده‌ی هر عنصر به کار می‌رود.
مثال زیر این موضوع را نشان می‌دهد

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

مهم است به یاد داشته باشید که حافظه‌ای که تازه توسط `malloc` تخصیص می‌یابد، مقداردهی اولیه نمی‌شود و ممکن است مقادیر زائد در آن باشد.
توجه کنید که `sizeof` اشاره‌گر `numbers` نه تعداد عناصر آرایه است و نه مقدار کل حافظه‌ی تخصیص‌یافته.
اندازه‌ی اشاره‌گری که `malloc` برمی‌گرداند، اندازه‌ی هر اشاره‌گر در همان سیستم خاص است.
کد نمونه روی یک سیستم ۶۴ بیتی اجرا شد، بنابراین اندازه‌ی اشاره‌گر ۸ بایت بود (ضرب در ۸ بیت در هر بایت، برابر با ۶۴ بیت).
نوع اشاره‌گر به‌طور ضمنی از `pointer-to-void` به `pointer-to-int` تبدیل شد.
می‌شد آن را به‌طور صریح هم تبدیل کرد، مانند این: `int * numbers = (int *) malloc(sizeof(int) * count);`.
اگر قرار است مقدار (یا مقادیر) قطعاً پیش از خوانده شدن نوشته شود، استفاده از `malloc` می‌تواند روشی کارآمد برای تخصیص حافظه باشد.
اما اگر احتمال دارد که مقدار (یا مقادیر) پیش از مقداردهی اولیه خوانده شوند، استفاده از `malloc` پرخطر است.
روش ایمن‌تر برای تخصیص حافظه استفاده از `calloc` است که حافظه‌ی تازه تخصیص‌یافته را به صفر مقداردهی اولیه می‌کند.

توجه کنید که در مثال‌های بالا از `free(numbers)` استفاده شده است.

## free

`free` تابعی است که در `stdlib.h` اعلان شده است و برای آزادسازی حافظه‌ای به کار می‌رود که به‌صورت پویا تخصیص یافته است.
حافظه‌ای که به‌صورت پویا تخصیص یافته است، تا زمانی که `free` آن را آزاد نکند، در حافظه اشغال‌شده باقی می‌ماند.
برخی سیستم‌های عامل ممکن است هنگام پایان برنامه، حافظه‌ی پویای تخصیص‌یافته را به‌طور خودکار آزاد کنند، اما بهترین روش این است که به آن تکیه نکنید.
`free` یک پارامتر دارد که اشاره‌گری به حافظه‌ای است که به‌صورت پویا تخصیص یافته است.
اشاره‌گری که پس از آزاد شدن روی `NULL` تنظیم نشده باشد، «اشاره‌گر معلق» نامیده می‌شود.
اشاره‌گر معلق ممکن است به حافظه‌ای جز آنچه برایش در نظر گرفته شده بود اشاره کند.
بنابراین، اشاره‌گر معلق می‌تواند به خرابی داده‌ها و جایگزینی و اجرای کد دلخواه منجر شود.
اشاره‌گر به حافظه‌ی تخصیص‌یافته‌ای که با تنظیم روی `NULL` پاک نشده باشد، می‌تواند برای هک کردن برنامه به کار رود.
بهترین روش این است که اشاره‌گر را پس از سپردن به `free` روی `NULL` تنظیم کنید.

## calloc

`calloc` تابعی است که در `stdlib.h` اعلان شده است و هم برای تخصیص حافظه‌ی پویا و هم برای مقداردهی اولیه‌ی حافظه‌ی تازه تخصیص‌یافته به صفر به کار می‌رود.
اگر تخصیص موفق باشد، اشاره‌گری برگردانده می‌شود که به آدرس اولین بایت حافظه‌ی تخصیص‌یافته اشاره می‌کند.
اگر تخصیص موفق نباشد، `NULL` برگردانده می‌شود.
احتیاط حکم می‌کند که نتیجه‌ی `calloc` را برای `NULL` بررسی کنید و اگر شکست خورد، به‌شکلی مناسب با آن برخورد کنید.
اشاره‌گر برگردانده‌شده از نوع `pointer-to-void` است که تقریباً می‌توان آن را یک اشاره‌گر «عمومی» در نظر گرفت که می‌تواند به نوع مشخصی که آن حافظه به کار می‌برد تبدیل شود.
`calloc` دو پارامتر دارد.
پارامتر اول تعداد عناصری از نوع داده‌ی مشخص است که باید تخصیص یابد.
پارامتر دوم اندازه‌ی نوع داده‌ی مشخصی است که باید تخصیص یابد.

در مثال زیر همه‌ی دستورهای `printf` باید همیشه `0` را نشان دهند، زیرا `calloc` تضمین می‌کند که مقادیر تازه تخصیص‌یافته صفر شوند.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` تابعی است که در `stdlib.h` اعلان شده است و برای بزرگ یا کوچک کردن حافظه‌ی تخصیص‌یافته‌ی موجود به کار می‌رود.
اگر تخصیص دوباره موفق باشد، اشاره‌گری برگردانده می‌شود که به آدرس اولین بایت حافظه‌ی دوباره تخصیص‌یافته اشاره می‌کند.
اگر تخصیص دوباره موفق نباشد، `NULL` برگردانده می‌شود.
احتیاط حکم می‌کند که نتیجه‌ی `realloc` را برای `NULL` بررسی کنید و اگر شکست خورد، به‌شکلی مناسب با آن برخورد کنید.
`realloc` دو پارامتر دارد.
پارامتر اول اشاره‌گری به حافظه‌ی موجود است که باید دوباره تخصیص یابد.
پارامتر دوم اندازه‌ی حافظه‌ی دوباره تخصیص‌یافته بر حسب بایت است.
مقادیری که پیش از گسترش حافظه تنظیم شده‌اند، حفظ می‌شوند.
مهم است به یاد داشته باشید که حافظه‌ای که هنگام گسترش حافظه اضافه می‌شود، به صفر مقداردهی اولیه نمی‌شود و مقدار (یا مقادیر) آن می‌تواند هر چیزی باشد.
همچنین، حافظه‌ای که هنگام کوچک کردن حافظه حذف می‌شود نیز مقداردهی اولیه نمی‌شود و ممکن است مقدار (یا مقادیر) را حفظ کند.
مثال زیر گسترش و کوچک کردن یک آرایه را نشان می‌دهد

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
