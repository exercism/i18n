# دستورالعمل‌ها

لری یک موجود فضایی لیسپ است که دوست دارد برای بازی کردن کد بنویسد.
امروز می‌خواهد چند تابع بنویسد تا در بازی‌ای که بسیار شبیه «دوز» است به او کمک کنند.

این بازی هم مثل «دوز» روی یک تخته انجام می‌شود که یک شبکه‌ی ۳×۳ است.

## 1. شروع از صفر

اول، لری به تابعی به اسم `make-empty-board` نیاز دارد که یک تخته‌ی خالی بسازد.
همه‌ی خانه‌های تخته باید `NIL` باشند.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. شروع از یک تخته‌ی موجود

سپس لری به تابعی نیاز دارد که از فهرستی از ردیف‌ها یک تخته بسازد.
برای مثال:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. شرط برد

اگر حالتی پیش بیاید که در آن سه نماد یکسان در یک ردیف قرار گرفته باشند، آن بازیکن برنده شده است.
لری به تابعی به اسم `all-the-same-p` نیاز خواهد داشت که یک آرایه‌ی ۳ عنصری می‌گیرد و اگر همه‌ی عنصرهای آن نماد یکسان باشند، به `T` ارزیابی می‌شود.
(از `eq` می‌توان برای تشخیص یکسان بودن دو نماد استفاده کرد.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. در یک ردیف

حالا لری به راهی نیاز دارد که عنصرهای یک ردیف را به دست آورد.
تابع `row` یک تخته و یک شماره‌ی ردیف می‌گیرد و باید آرایه‌ای از عنصرهای آن ردیف را برگرداند.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. در یک ستون

در نهایت، لری به راهی نیاز دارد که عنصرهای یک ستون را به دست آورد.
تابع `column` یک تخته و یک شماره‌ی ستون می‌گیرد و باید آرایه‌ای از عنصرهای آن ستون را برگرداند.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
