# مقدمه

## ساختارشکنی آرایه

نحوه‌ی نگارش «ساختارشکنی» آرایه در JavaScript روشی کوتاه است برای بیرون کشیدن مقدارها از یک آرایه و نسبت دادن آن‌ها به متغیرهای جداگانه.

در این مثال، هر مقدار در آرایه‌ی `numberOfMoons` به سیاره‌ی متناظرش نسبت داده می‌شود:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

به‌طور خلاصه:

- این نحوه‌ی نگارش امکان می‌دهد عنصرهای _موقعیت‌دار_ در یک آرایه را اسم‌گذاری کنیم و همچنین متغیرها را با انتساب دوباره جابه‌جا کنیم.
- نحوه‌ی نگارش ساختارشکنی هم داخل پارامترهای تابع در دسترس است و هم روی هر مقدار قابل پیمایشی.
- اگر موقعیتی را بی‌اسم بگذارید (با ننوشتن _هیچ_ اسم متغیری)، آن موقعیت بی‌صدا نادیده گرفته می‌شود.

## ساختارشکنی شیء

در JavaScript، نحوه‌ی نگارش ساختارشکنی دیگری هم هست که ویژگی‌ها را از یک شیء استخراج می‌کند و آن‌ها را به متغیرهای جداگانه نسبت می‌دهد.

در این مثال، نمادهای آب‌وهوا از شیء `weather` استخراج می‌شوند:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

به‌طور خلاصه:

- این نحوه‌ی نگارش هم امکان استخراج ویژگی‌ها را می‌دهد و هم استخراج و تغییر اسم آن‌ها.
- نحوه‌ی نگارش ساختارشکنی داخل پارامترهای تابع در دسترس است.
