# درباره

از مقدار `null` برای نشان دادن _نبودِ_ یک مقدار استفاده می‌شود. نوع **nullable** نوعی است که اجازه می‌دهد یک متغیر مقدار `null` را بپذیرد. برای اینکه هر نوعی را nullable کنیم، آن را در `Null<T>` می‌پیچیم:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

برای بررسی اینکه آیا یک مقدار در حال حاضر `null` است، کافی است از یک عبارت `if` استفاده کنید:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
