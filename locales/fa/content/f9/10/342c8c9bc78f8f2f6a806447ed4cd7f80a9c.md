# مقدمه

یک «quotation» قطعه‌ای کد در کروشه‌های `[ ]` است. یک مقدار است: می‌توانید آن را روی پشته قرار دهید، به یک واژه‌ی دیگر پاس دهید یا در یک آرایه ذخیره کنید.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

بیشتر واژه‌های مرتبه‌بالا یک quotation را به‌عنوان دومین آرگومان خود می‌گیرند:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

بدنه‌ی یک quotation فقط کد معمولی Factor است؛ همان عملگرها و اثرهای پشته که در همه‌جای دیگر استفاده می‌کنید.

وقتی از داده‌ها کد می‌سازید، مثلاً قطعه‌ها را به هم می‌چسبانید یا توکن‌ها را به عملیات نگاشت می‌کنید، نتیجه یک دنباله است؛ آن را از `>quotation` عبور دهید تا قابل فراخوانی شود:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
