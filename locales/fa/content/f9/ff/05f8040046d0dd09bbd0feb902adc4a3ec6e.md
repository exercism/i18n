# درباره

یک عبارت «منطقی»، پرسشی است که از یک یا چند مقدار پرسیده می‌شود و می‌توان با `true` یا `false` به آن پاسخ داد.
یک عبارت درست `1` را برمی‌گرداند و یک عبارت نادرست `0` را.
همچنین عددها هم مقدار درست یا نادرست دارند. صفر `false` است و غیرصفر `true`.

کد C قدیمی یا مستقیماً از نوع `int` برای مقادیر منطقی استفاده می‌کند، یا برنامه‌نویس ممکن است ثابت‌هایی مثل `TRUE` و `FALSE` تعریف کرده باشد تا `1` و `0` را به یک نمایش منطقی نگاشت کند.

با نسخه‌ی C99 نوع `_Bool` اضافه شد.
فایل هدر `stdbool.h` سه نماد منطقی جدید تعریف می‌کند: `bool`، `true` و `false`.
`true` به `1` نگاشت می‌شود، `false` به `0` و `bool` به `_Bool`.
حالا دیگر برنامه‌نویس‌ها به‌جای اینکه مستقیماً از `int` استفاده کنند یا نگاشت‌های منطقی خودشان را بسازند، می‌توانند `stdbool.h` را وارد کنند و به‌طور خودکار نمادهای منطقی را در کدشان داشته باشند.

## عملگرهای مقایسه

زبان C شش عملگر مقایسه را پشتیبانی می‌کند: `==` (برابر)، `!=` (نابرابر)، `>` (بزرگ‌تر از)، `<` (کوچک‌تر از)، `>=`(بزرگ‌تر یا مساوی)، `<=` (کوچک‌تر یا مساوی).
این عملگرها رابطه‌ی بین مقدارها را مقایسه می‌کنند و آن را به یک مقدار منطقی تبدیل می‌کنند.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## عملگرهای منطقی

زبان C سه عملگر منطقی را پشتیبانی می‌کند: `||` (یا)، `&&` (و) و `!` (نه).

`!` با یک عملوند استفاده می‌شود.
مقدار منطقی عملوند را معکوس می‌کند.
برای نمونه، `0` همان `false` است، اما `!0` همان `true` است.

`||` و `&&` با دو عملوند استفاده می‌شوند.
عملوند سمت راست تنها زمانی ارزیابی می‌شود که عملوند سمت چپ از قبل نتیجه‌ی عبارت را تعیین نکرده باشد.
یعنی `||` عملوند سمت راستش را تنها زمانی ارزیابی می‌کند که عملوند سمت چپش به `false` ارزیابی شود.
`&&` عملوند سمت راستش را تنها زمانی ارزیابی می‌کند که عملوند سمت چپش به `true` ارزیابی شود.


## اتصال کوتاه

اینکه همه‌ی عملوندها ارزیابی نشوند، «اتصال کوتاه» نام دارد.
اتصال کوتاه روشی موجز و قدرتمند برای مدیریت موقعیت‌های خاص است.
برای نمونه، یک روش رایج این است که بررسی کنید آیا اشاره‌گر `NULL` نیست و (&&)، اگر `NULL` نبود، آن را ارجاع‌زدایی کنید. به این ترتیب، از ارجاع‌زدایی یک اشاره‌گر `NULL` جلوگیری می‌شود.
اما اتصال کوتاه می‌تواند به باگ هم منجر شود.
گاهی برنامه‌نویس فراموش می‌کند که ممکن است عملوند سمت راست `||` یا `&&` همیشه ارزیابی نشود.
اگر عملوند سمت راست عبارتی با اثر جانبی باشد که انتظار می‌رود همیشه رخ دهد، بسته به مقدار منطقی عملوند سمت چپ، به یک باگ تبدیل می‌شود.


## برگرداندن یک عبارت منطقی

نتیجه‌ی یک عبارت منطقی را می‌توان مستقیماً برگرداند.
برای نمونه، این دستور `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

را می‌توان با این جایگزین کرد

```c
return count > 0;
```
