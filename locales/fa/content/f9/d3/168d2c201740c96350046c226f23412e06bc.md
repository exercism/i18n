# درباره

در Go، رشته‌ها تغییرناپذیرند.
به هم چسباندن رشته‌ها با `+` در یک حلقه باعث تخصیص حافظه‌ی مکرر می‌شود و داده‌ها چندین بار کپی می‌شوند.
بسته‌ی [`strings`](https://pkg.go.dev/strings) نوع [`Builder`](https://pkg.go.dev/strings#Builder) را ارائه می‌دهد تا با سرهم‌کردن کارآمد رشته‌ها، سربار حافظه را به کمترین مقدار برساند.

## ساختن رشته

مقدار صفرِ `strings.Builder` بی‌درنگ آماده‌ی استفاده است، بدون هیچ مقداردهی اولیه یا تخصیص صریح حافظه.
می‌توانید داده‌های تازه را با متدهای نوشتنِ مشخص به `Builder` اضافه کنید.
هر متد نوشتن یک مقدار خطا برمی‌گرداند تا اینترفیس‌های استاندارد Go را برآورده کند، اما تضمین شده است که همیشه `nil` باشد و در کد روزمره معمولاً نادیده گرفته می‌شود.

پرتکرارترین متدها این‌ها هستند:

- `WriteString(s string) (int, error)`: یک رشته را به بافر اضافه می‌کند.
- `WriteRune(r rune) (int, error)`: کدگذاری UTF-8 یک `rune` را اضافه می‌کند.
- `WriteByte(c byte) error`: یک بایت منفرد را اضافه می‌کند.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## دریافت و بازنشانی

وقتی سرهم‌کردن متن تمام شد، می‌توانید با فراخوانی متد `String()` محتوای انباشته‌شده را به‌صورت یک رشته‌ی استاندارد Go به دست آورید.
فراخوانی `String()` عملیاتی بسیار کم‌هزینه است، چون اسلایس بایتی زیرین را بدون کپی کردن داده‌های انباشته‌شده، مستقیم به‌صورت رشته برمی‌گرداند.

اگر لازم است از همان نمونه‌ی `Builder` برای ساختن رشته‌ای تازه دوباره استفاده کنید (مثلاً داخل یک حلقه)، می‌توانید متد `Reset()` را فراخوانی کنید.
این کار بافر داخلی را خالی می‌کند تا بتوانید از نو شروع کنید و رشته‌ی بعدی را بسازید، در حالی که ظرفیت حافظه‌ی از پیش تخصیص‌یافته در پس‌زمینه حفظ می‌شود.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
