# مقدمه

مانند دستور _if/else_، یک دستور `switch` به شما امکان می‌دهد با اجرای شرطی کد، جریان برنامه را تغییر دهید.
تفاوت در این است که یک دستور `switch` فقط می‌تواند مقدار یک عبارت اولیه یا رشته‌ای را با مقادیر ثابت از پیش تعریف‌شده مقایسه کند.

هنگام استفاده از دستور switch، چند کلیدواژه به کارتان می‌آید.

- `switch`: این کلیدواژه به شما امکان می‌دهد ساختار switch را تعریف کنید.
  بعد از آن، عبارت یا متغیری می‌آید که نتیجه را تغییر می‌دهد.
- `case`: از این کلیدواژه برای تعریف حالت‌های مختلف نتیجه استفاده می‌کنید.
- `break`: کلیدواژه‌ی `break` برای متوقف کردن اجرای switch در پایان جریان مورد نظر بسیار کاربردی است.
  اگر آن را فراموش کنید، برنامه ادامه می‌یابد و ممکن است به نتایج غیرمنتظره‌ای منجر شود.
- `default`: همان‌طور که از اسمش پیداست، از آن به عنوان نتیجه‌ی پیش‌فرض استفاده کنید، برای زمانی که هیچ case دیگری با نتیجه‌ی عبارت شما مطابقت ندارد.

در ساده‌ترین حالت، آن‌ها یک عبارت اولیه یا رشته‌ای را آزمایش می‌کنند و بر اساس مقدارش تصمیمی می‌گیرند.
برای مثال:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
