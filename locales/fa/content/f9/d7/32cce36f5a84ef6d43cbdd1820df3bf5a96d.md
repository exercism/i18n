# راهنمایی‌ها

## 1. تعریف محدوده‌ی رتبه و ستون

- باید دو [ثابت][constants] تعریف کنید که یک [محدوده][range] از رتبه‌ها و ستون‌ها را در خود نگه دارند.
- رتبه‌ها باید یک محدوده‌ی [عدد صحیح][integers] از ۱ تا ۸ باشند.
- ستون‌ها باید یک محدوده‌ی [کاراکتر][characters] از 'A' تا 'H' باشند.
- این ثابت باید در [ماژول][module] `Chess` تعریف شود.

## 2. بررسی معتبر بودن خانه

- باید بررسی کنید که آیا یک مقدار درون یک محدوده قرار دارد یا نه.
- [متدی][include] وجود دارد که می‌توان از آن برای بررسی قرار داشتن یک مقدار درون یک محدوده استفاده کرد.

## 3. گرفتن اسم مستعار بازیکن

- می‌توانید با استفاده از [عملگر محدوده][range-operator] به‌عنوان اندیس، یک زیررشته به‌دست آورید.
- [متدی][upcase] وجود دارد که می‌توان از آن برای بزرگ‌کردن حروف یک رشته استفاده کرد.

## 4. ساختن پیام حرکت

- می‌توانید رشته‌ی خانه را اندیس‌گذاری کنید تا رتبه و ستون را به‌دست آورید.
- می‌توانید از متدهای تعریف‌شده استفاده کنید تا اسم مستعار بازیکن را به‌دست آورید و بررسی کنید که آیا حرکت معتبر است یا نه.
