# درباره

در Elixir، برای انتخاب یک عنصر تصادفی از یک ساختار داده‌ی قابل شمارش (مثلاً یک لیست یا بازه)، از [`Enum.random/1`][enum-random] استفاده می‌کنیم. این تابع یک عنصر را انتخاب می‌کند، به‌گونه‌ای که احتمال انتخاب همه‌ی عنصرها یکسان است. انتخاب یک مقدار تصادفی از یک بازه، در زمان ثابت انجام می‌شود، بدون اینکه کل بازه پیمایش شود.

## اعداد صحیح و حروف تصادفی

- انتخاب یک عدد صحیح تصادفی
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- انتخاب یک حرف تصادفی به‌صورت رشته
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- انتخاب یک حرف تصادفی به‌صورت چارلیست
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

برای انتخاب بیش از یک عنصر از یک ساختار داده‌ی قابل شمارش، از [`Enum.take_random/2`][enum-take-random] استفاده کنید. برای مرتب کردن یک ساختار داده‌ی قابل شمارش به ترتیبی تصادفی، از [`Enum.shuffle/1`][enum-shuffle] استفاده کنید.

## اعداد اعشاری تصادفی

Elixir توابع خودش را برای انتخاب یک عدد اعشاری تصادفی ندارد. برای این کار باید از ماژول [`rand`][erl-rand] در Erlang استفاده کنیم، که در واقع `Enum.random` هم در پشت صحنه از همان استفاده می‌کند.

- انتخاب یک عدد اعشاری تصادفی (برابر یا بزرگ‌تر از ۰٫۰ و کوچک‌تر از ۱٫۰):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- انتخاب یک عدد اعشاری تصادفی (برابر یا بزرگ‌تر از `a` و کوچک‌تر از `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## توزیع نرمال

همه‌ی توابعی که تا اینجا نام برده شد، یک مقدار تصادفی را طوری انتخاب می‌کنند که احتمال انتخاب هر مقدار ممکن یکسان باشد. به این حالت «توزیع یکنواخت» می‌گویند. ماژول `rand` همچنین توابع [`normal/0`][erl-rand-normal-0] و [`normal/2`][erl-rand-normal-2] را ارائه می‌دهد که یک عدد اعشاری تصادفی با [توزیع نرمال][normal-distribution] انتخاب می‌کنند.

## بذر

مهم است بدانید که مقادیر «تصادفی» توسط یک [«تولیدکننده‌ی اعداد شبه‌تصادفی»][prng] تولید می‌شوند. تولیدکننده‌ی اعداد شبه‌تصادفی یک الگوریتم است که با گرفتن یک مقدار اولیه به نام «بذر»، دنباله‌ای از اعداد را تولید می‌کند که تصادفی به نظر می‌رسد، اما اصلاً تصادفی نیست.

این نکته ممکن است برای debug مفید باشد. می‌توانید با بازنشانی بذر آن به کمک [`:rand.seed/2`][rand-seed-2]، تولیدکننده‌ی اعداد شبه‌تصادفی Erlang (و در نتیجه Elixir) را وادار کنید همان دنباله‌ی مقادیر را تولید کند. آرگومان اول یک الگوریتم مشخص برای تولیدکننده‌ی اعداد شبه‌تصادفی است و آرگومان دوم یک تاپل سه‌عددی، که همان بذر است.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## رمزنگاری

مقادیر تصادفی‌ای که `Enum.random` و ماژول `rand` در Erlang برمی‌گردانند، [از نظر رمزنگاری امن][cryptographically-secure-rng] نیستند. از آن‌ها برای تولید کلیدهای رمزنگاری، گذرواژه‌ها یا nonce استفاده نکنید. برای این کار، [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] در Erlang وجود دارد.
