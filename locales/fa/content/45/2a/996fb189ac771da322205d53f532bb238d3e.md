# دستورالعمل‌ها

[عدد آرمسترانگ](https://en.wikipedia.org/wiki/Narcissistic_number) عددی است که اگر هر یک از رقم‌هایش را به توان تعداد رقم‌های آن عدد برسانید و همه را با هم جمع کنید، حاصل برابر خودِ عدد شود.

برای مثال:

- ۹ عدد آرمسترانگ است، چون `9 = 9^1 = 9`
- ۱۰ عدد آرمسترانگ *نیست*، چون `10 != 1^2 + 0^2 = 1`
- ۱۵۳ عدد آرمسترانگ است، چون: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- ۱۵۴ عدد آرمسترانگ *نیست*، چون: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

کدی بنویسید که تعیین کند آیا یک عدد، عدد آرمسترانگ است یا نه.
