# اعلان نوع

PHP یک زبان _با نوع‌بندی پویا_ است؛ یعنی یک متغیر می‌تواند هر نوع اطلاعاتی را در خود نگه دارد.
PHP امکان اعلان نوع قوی _اختیاری_ را برای ویژگی‌های کلاس، آرگومان‌های تابع و مقادیر بازگشتی تابع فراهم می‌کند.
اعلان‌های نوع قوی در PHP در زمان اجرا نوع را بررسی می‌کنند، اما PHP در صورت امکان تلاش می‌کند انواع اسکالر را طوری تبدیل کند که با اعلان بخوانند.
می‌توان رفتار تبدیل اجباری را با اعلان `strict_types` در بالای فایل غیرفعال کرد.

```php
<?php
declare(strict_types=1);
```

علاوه بر این، توابع می‌توانند نوع بازگشتی `void` داشته باشند تا نشان دهند هیچ مقداری از تابع بازگردانده نمی‌شود.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## اتحاد نوع

اگر یک آرگومان تابع، مقدار بازگشتی یا ویژگی کلاس بتواند بیش از یک نوع داشته باشد، می‌توان یک اتحاد نوع اعلان کرد.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## نوع مخلوط

هنگام کار با کد، ممکن است نتوانیم نوع را مشخص کنیم.
از PHP ۸.۰ به بعد، نوعی «دریچه‌ی فرار» به نام `mixed` در اختیار شما قرار گرفته است.
نوع مخلوط معادل یک اتحاد نوع از `object|resource|array|string|float|int|bool|null` است.
