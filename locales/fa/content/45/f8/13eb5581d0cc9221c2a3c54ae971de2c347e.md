# Tests

## راه‌اندازی

برای نصب وابستگی‌های لازم، [راهنمای راه‌اندازی JavaScript][docs-exercism-javascript] را دنبال کنید.

## پیش‌نیازها

وابستگی‌های تمرین را نصب کنید:

```shell
corepack pnpm install
```

اگر `corepack` از فعال‌نبودن خود شکایت کرد، می‌توانید با اجرای این دستور آن را فعال کنید:

```bash
corepack enable pnpm
```

## پاس کردن مجموعه‌ی تست

همه‌ی تمرین‌ها یک مجموعه‌ی تست دارند که به شما کمک می‌کند پیش از ارسال، راه‌حل خود را بررسی کنید.
می‌توانید این تست‌ها را با باز کردن یک خط فرمان در پوشه‌ی تمرین و سپس اجرای این دستور اجرا کنید:

```bash
corepack pnpm test
```

در برخی مجموعه‌های تست، همه‌ی تست‌ها به جز اولین تست نادیده گرفته شده‌اند.

وقتی یک تست را پاس کردید، می‌توانید تست بعدی را با تغییر `xtest` به `test` فعال کنید.

## نوشتن تست‌های سفارشی

اگر می‌خواهید تست‌های سفارشی بیشتری بنویسید، یک فایل جدید به اسم `custom.spec.js` بسازید و آن را همراه با فایل جدید و راه‌حل خود ارسال کنید:

```shell
exercism submit numbers.js custom.spec.js
```
