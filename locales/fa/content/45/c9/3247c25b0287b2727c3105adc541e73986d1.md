# مقدمه

## پکیج

در Go، یک برنامه در قالب پکیج‌ها سازمان‌دهی می‌شود.
«پکیج» مجموعه‌ای از فایل‌های منبع است که در یک پوشه‌ی یکسان قرار دارند.
همه‌ی فایل‌های منبع در یک پوشه باید در بالای فایل، نام پکیج یکسانی داشته باشند.
طبق قرارداد، نام پکیج‌ها همان نام پوشه‌ای است که در آن قرار دارند.

```go
package greeting
```

Go یک کتابخانه‌ی استاندارد گسترده از پکیج‌ها ارائه می‌دهد که می‌توانید با استفاده از کلیدواژه‌ی `import` در برنامه‌تان به کار ببرید.
پکیج‌های کتابخانه‌ی استاندارد با نامشان وارد می‌شوند.

```go
package greeting

import "fmt"
```

سپس به پکیج واردشده با نام پکیج ارجاع داده می‌شود:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go بر اساس نحوه‌ی اعلان یک مورد تعیین می‌کند که آیا کد موجود در پکیج‌های دیگر می‌تواند آن را فراخوانی کند یا نه.
برای اینکه یک تابع، نوع، متغیر، ثابت یا فیلد `struct` از بیرون قابل مشاهده باشد (که به آن «صادرشده» می‌گویند)، نام باید با حرف بزرگ شروع شود.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## قالب‌بندی رشته

Go پکیجی داخلی به نام `fmt` (پکیج قالب‌بندی) ارائه می‌دهد که توابع متنوعی برای دستکاری قالب ورودی و خروجی در اختیار می‌گذارد.
پرکاربردترین تابع `Sprintf` است که با استفاده از فعل‌هایی مانند `%s` مقادیر را درون یک رشته جای‌گذاری می‌کند و همان رشته را برمی‌گرداند.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

در Go، مقادیر اعشاری به‌راحتی با فعل‌های Sprintf قالب‌بندی می‌شوند: `%g` (نمایش فشرده)، `%e` (نمایی) یا `%f` (غیرنمایی).
هر سه فعل امکان کنترل عرض میدان و موقعیت عددی را فراهم می‌کنند.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

فهرست کامل فعل‌های موجود را می‌توانید در [مستندات پکیج قالب‌بندی][fmt-docs] ببینید.

`fmt` توابع دیگری هم برای کار با رشته‌ها دارد، مانند `Println` که صرفاً آرگومان‌های دریافتی را در کنسول چاپ می‌کند و `Printf` که ورودی را پیش از چاپ، همانند `Sprintf` قالب‌بندی می‌کند.

[fmt-docs]: https://pkg.go.dev/fmt
