# testها

مسیر Factor از **Factor 0.101** استفاده می‌کند. هر تمرین همراه با یک واژگان `exercism-tools` ارائه می‌شود که واژه‌های تجزیه‌کننده‌ی `STOP-HERE` و `TASK:` و همچنین یک اجراکننده‌ی test را تعریف می‌کند. از دایرکتوری تمرین، این را اجرا کنید:

```
factor -roots=. -run=exercism-tools <exercise>
```

برای مثال، برای تمرین `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

اجراکننده وقتی همه‌ی testها پاس شوند با وضعیت ۰ خارج می‌شود، و وقتی هر testی شکست بخورد با وضعیت غیرصفر و خروجی تشخیصی.

## testهای نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی اینکه همه‌ی testهای آن را پاس کنید.
به‌صورت پیش‌فرض، وقتی testها را اجرا می‌کنید فقط یک test (اولین test) اجرا می‌شود.
این کار عمدی است، چون به شما امکان می‌دهد فقط روی پاس کردن همان یک test تمرکز کنید.

سازوکار این کار، خط `STOP-HERE` در فایل test است: در زمان تجزیه به Factor می‌گوید هر چیزی را که پایین‌تر از آن است نادیده بگیرد، بنابراین اجراکننده فقط testهای بالای آن را می‌بیند. وقتی test اولتان پاس شد، می‌توانید testهای بیشتری را به دو روش فعال کنید:

- **خط `STOP-HERE` را حذف کنید** تا همه‌ی testهای باقی‌مانده یک‌جا فعال شوند.
- **خط `STOP-HERE` را پایین‌تر ببرید** تا testها را یکی‌یکی، یا هر تسک را جداگانه فعال کنید. تمرین‌های مفهومی، testها را زیر نشانگرهای `TASK:` گروه‌بندی می‌کنند؛ بردن `STOP-HERE` به دقیقاً پیش از `TASK:` بعدی یک گام طبیعی است.

وقتی همه‌ی testها فعال شدند و پیاده‌سازی شما همه‌ی آن‌ها را پاس کرد، تمرین را حل کرده‌اید!
