# مقدمه

در Go، توابع مقادیر «درجه‌یک» هستند.
یعنی می‌توانید با توابع همان کارهایی را بکنید که با سایر مقادیر می‌کنید: تابعی را به متغیر نسبت دهید، آن را به عنوان آرگومان به تابعی دیگر بدهید یا حتی تابعی را از تابعی دیگر برگردانید.

در ادامه دو تابع به اسم `engGreeting` و `espGreeting` می‌سازیم و آن‌ها را به متغیر `greeting` نسبت می‌دهیم:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

مقادیر تابعی این فرصت را فراهم می‌کنند که توابع را نه فقط با داده، بلکه با رفتار هم پارامتری کنید.
در مثال زیر، رفتار را از طریق پارامتر `greetingFunc` به تابع `dialog` می‌دهیم:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

مقدار یک متغیر مقداردهی‌نشده از نوع تابع، `nil` است.
بنابراین فراخوانی یک مقدار تابعیِ `nil` باعث بروز یک `panic` می‌شود.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

مقادیر تابعی را می‌توان با `nil` مقایسه کرد.
این کار می‌تواند برای جلوگیری از بروز `panic`های بی‌مورد در برنامه مفید باشد.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## نوع تابع

استفاده از مقادیر تابعی به لطف نوع تابع در Go ممکن شده است.
نوع تابع به مجموعه‌ی همه‌ی توابعی اشاره دارد که ترتیب نوع پارامترها و ترتیب نوع نتیجه‌ها در آن‌ها یکسان است.
می‌توان نوع‌های تعریف‌شده‌ی کاربر را بر پایه‌ی نوع تابع اعلان کرد.
برای نمونه، تابع `dialog` از مثال‌های قبلی را می‌توان به شکل زیر به‌روزرسانی کرد:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## توابع بی‌نام

ابزار قدرتمند دیگری که به لطف پشتیبانی از توابع درجه‌یک در دسترس است، توابع بی‌نام هستند.
توابع بی‌نام در همان جایی که استفاده می‌شوند تعریف می‌شوند، بدون اینکه اسمی پس از کلیدواژه‌ی `func` بیاید.
چنین توابعی به متغیرهای تابع دربرگیرنده دسترسی دارند.

برای مثال:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

فراخوانی `fib` متغیرهای `n1` و `n2` را اعلان می‌کند و تابعی بی‌نام برمی‌گرداند که به نوبه‌ی خود، هر بار که فراخوانی شود مقدار این متغیرها را تغییر می‌دهد.
فراخوانی Nاُم تابع بی‌نام، Nاُمین عدد دنباله‌ی فیبوناچی را که از ۰ شروع می‌شود برمی‌گرداند. تابع بی‌نام درونی به متغیرهای محلی (`n1` و `n2`) تابع دربرگیرنده‌ی `fib` دسترسی دارد.
این روش خوبی است تا مقادیر تابعی بتوانند میان فراخوانی‌ها وضعیت خود را حفظ کنند.
می‌گوییم که تابع بی‌نام «بستار» متغیرهای `n1` و `n2` است.
[بستارها][closure] در برنامه‌نویسی کاربرد گسترده‌ای دارند و ممکن است ببینید زبان‌های دیگر نیز از آن‌ها پشتیبانی می‌کنند.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
