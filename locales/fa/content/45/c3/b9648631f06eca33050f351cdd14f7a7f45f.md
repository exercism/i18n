# دستورالعمل‌ها

دو فهرست داده شده‌اند. مشخص کنید که آیا فهرست اول درون فهرست دوم قرار دارد، آیا فهرست دوم درون فهرست اول قرار دارد، آیا هر دو درون یکدیگر قرار دارند، یا هیچ‌یک از این حالت‌ها درست نیست.

به‌طور مشخص، فهرست A «زیرفهرست»ی از فهرست B است اگر با حذف ۰ عنصر یا بیشتر از ابتدای B و ۰ عنصر یا بیشتر از انتهای B، فهرستی به دست بیاید که کاملاً با A برابر باشد.

مثال‌ها:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A زیرفهرستی از B است
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A زیرفهرستی از B است
 * A = [3, 4], B = [1, 2, 3, 4, 5], A زیرفهرستی از B است
 * A = [1, 2, 3], B = [1, 2, 3], A با B برابر است
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A «ابرفهرست»ی از B است
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A نه ابرفهرستی از B است، نه زیرفهرستی از B و نه برابر با B
