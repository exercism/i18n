# دستورالعمل‌ها

در این تمرین روی یک زمان‌بند نوبت برای یک سالن زیبایی کار می‌کنید که در ۱۵ سپتامبر ۲۰۱۲ افتتاح شد.

پنج کار پیش رو دارید که همه‌شان به تاریخ‌های نوبت مربوط می‌شوند.

## 1. تجزیه‌ی تاریخ نوبت

تابع `Schedule` را پیاده‌سازی کنید تا نمایش متنی یک تاریخ نوبت را به قالب متناظر `time.Time` تجزیه کند:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. بررسی اینکه آیا نوبت قبلاً گذشته است

تابع `HasPassed` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و بررسی می‌کند که آیا نوبت جایی در گذشته بوده است:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. بررسی اینکه آیا نوبت بعدازظهر است

تابع `IsAfternoonAppointment` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و بررسی می‌کند که آیا نوبت در بعدازظهر است (یعنی ساعت ۱۲:۰۰ یا بعد از آن و پیش از ۱۸:۰۰):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. توصیف زمان و تاریخ نوبت

تابع `Description` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و توصیفی از آن تاریخ و زمان را برمی‌گرداند:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. برگرداندن تاریخ سالگرد افتتاح سالن

تابع `AnniversaryDate` را پیاده‌سازی کنید که تاریخ سالگرد افتتاح سالن را برای سال جاری به وقت UTC برمی‌گرداند.

با فرض اینکه سال جاری ۲۰۲۰ است:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**توجه:** مقدار بازگشتی یک `time.Time` است و ساعت روز اهمیتی ندارد.
