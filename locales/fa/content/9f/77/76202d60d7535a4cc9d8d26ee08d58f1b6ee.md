# درباره

کلاس `Lambda` مجموعه‌ای از متدهای تابعی است تا بتوان با Haxe به سبک برنامه‌نویسی تابعی نوشت. این کلاس به ما امکان می‌دهد یک `Iterable` کامل را یک‌جا مورد عملیات قرار دهیم. این کار اغلب از روتین‌های حلقه‌زنی بهتر است، چون احتمال خطا در آن کمتر و خواندنش آسان‌تر است. برای راحتی کار، کلاس‌های `Array` و `List` برخی از متدهای پرکاربرد کلاس `Lambda` را در خود دارند.

برخی از توابع کلاس `Lambda` عبارت‌اند از:

- `Lambda.array`، `Lambda.list` یک `Iterable` را به `Array` یا `List` تبدیل می‌کند. همیشه یک نمونه‌ی جدید برمی‌گرداند.
- `Lambda.count` تعداد عنصرها را می‌شمارد. اگر `Iterable` یک `Array` یا `List` باشد، استفاده از ویژگی `length` آن سریع‌تر است.
- `Lambda.has` تعیین می‌کند که آیا عنصر مشخص‌شده در `Iterable` هست یا نه.
- `Lambda.indexOf` اندیس عنصر مشخص‌شده را پیدا می‌کند.
- `Lambda.find` اولین عنصر را بر اساس تابع جست‌وجوی داده‌شده پیدا می‌کند.
- `Lambda.concat` دو `Iterable` را ادغام می‌کند و یک `List` جدید برمی‌گرداند.
- `Lambda.filter` عنصرهایی را پیدا می‌کند که یک معیار را برآورده می‌کنند و یک `List` جدید برمی‌گرداند.

مثالی که چند مورد از این توابع را نشان می‌دهد:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
