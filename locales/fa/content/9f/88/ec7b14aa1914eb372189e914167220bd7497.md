# تکرارگر سفارشی

شما از زمان `bird-survey` از تکرارگرها استفاده کرده‌اید. حالا خودتان یکی می‌نویسید.

## yield

یک تکرارگر شبیه یک روال است، با دو تفاوت: اسمش به `!` ختم می‌شود و مقادیر را به‌جای `return` با `yield` تحویل می‌دهد.

```sather
   markers!(count : INT) : INT is
      loop
         yield 100 * 1.upto!(count);
      end;
   end;
```

`yield` یک مقدار به حلقه‌ای می‌دهد که تکرارگر را فراخوانی کرده است و بعد **منتظر می‌ماند**. وقتی آن حلقه به دور بعدی می‌رسد، تکرارگر از درست بعد از `yield` ادامه می‌دهد، با همه‌چیز دقیقاً همان‌طور که رهایش کرده بود: متغیرهایش، حلقه‌ی خودش، جایش.

تکرارگر همین است: روالی که می‌تواند در میانه متوقف شود و بعد ادامه پیدا کند.

```sather
   loop
      #OUT + TRAIL::markers!(3) + " ";      -- 100 200 300
   end;
```

## پایان

یک تکرارگر به یکی از دو روش پایان می‌یابد.

**تمام شدن.** وقتی حلقه‌ی خود تکرارگر به پایان می‌رسد، یا روال به انتهایش می‌رسد، کارش تمام است و حلقه‌ای که آن را فراخوانی کرده بود، بی‌درنگ پایان می‌یابد.

**quit.** `quit` آن را همان‌جا و بی‌درنگ پایان می‌دهد، بدون اینکه مقداری تحویل دهد.

```sather
   named!(names : ARRAY{STR}) : STR is
      loop
         name ::= names.elt!;
         if name = "" then quit; end;
         yield name;
      end;
   end;
```

این اسم‌ها را تحویل می‌دهد تا به یک اسم خالی برسد، و بعد می‌ایستد. `quit` برای یک تکرارگر همان کاری را می‌کند که `return` برای یک روال، با این تفاوت که هیچ مقداری همراه ندارد: چیزی نمانده که تحویل داده شود.

## once

آرگومانی که با `once` علامت خورده است، فقط یک بار محاسبه می‌شود، همان هنگام که حلقه شروع می‌شود، نه در هر دور:

```sather
   markers!(once count : INT) : INT is
```

از آن برای هر آرگومانی استفاده کنید که بین دورها تغییر نمی‌کند؛ بیشتر آرگومان‌ها هم همین‌طورند. تکرارگرهای خود کتابخانه نیز چنین می‌کنند: `upto!(once i : SAME)`.

## تکرارگر بدون مقدار

یک تکرارگر لازم نیست هیچ مقداری تحویل دهد. `times!` یکی از همین‌هاست:

```sather
   steps!(once count : INT) is
      loop
         ignored ::= 1.upto!(count);
         yield;
      end;
   end;
```

یک `yield` بدون مقدار هیچ مقداری تحویل نمی‌دهد و تنها می‌گذارد حلقه دور بزند.

## موقعیت کجا نگه داشته می‌شود

هر *جایی در برنامه* که یک تکرارگر را فراخوانی می‌کند، موقعیت خودش را نگه می‌دارد. به همین دلیل است که فراخوانی همان تکرارگر دو بار در یک بدنه‌ی حلقه، آن را دو بار می‌پیماید. حالا می‌بینید چرا: این دو فراخوانی، دو روال جداگانه‌ی متوقف‌شده‌اند.
