# مقدمه

ورودی/خروجی در Factor بر پایه‌ی «جریان‌ها» ساخته شده است: اشیایی که بایت‌ها یا کاراکترها را از آن‌ها می‌خوانید یا در آن‌ها می‌نویسید. واژگان [`io`][io] دو دیدگاه متفاوت به یک [پروتکل][stream-protocol] یکسان را در اختیارتان می‌گذارد.

## دو دیدگاه

**واژه‌های صریح** جریان را به‌عنوان یک آرگومان می‌گیرند. همه‌ی آن‌ها با `stream-` شروع می‌شوند:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

**واژه‌های محیطی** از هر جریانی که *در حال حاضر مقید شده است* می‌خوانند یا در آن می‌نویسند: متغیر پویای سراسری برنامه، یعنی `input-stream` یا `output-stream`. اسم‌هایشان کوتاه است:

```
read1 read readln write write1 print flush
```

شکل محیطی همان است که بیشتر کدهای روزمره از آن استفاده می‌کنند. شکل صریح را وقتی به کار می‌برید که جریان مشخصی در دست دارید و نمی‌خواهید جریان محیطی را با آن عوض کنید.

## جریان‌های درون‌حافظه‌ای

برای این تمرین با جریان‌های رشته‌محور از [`io.streams.string`][io.streams.string] کار می‌کنید:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

یک `<string-reader>` از یک رشته‌ی متنی می‌خواند، درست مثل اینکه یک فایل باشد؛ یک `<string-writer>` هر چیزی را که در آن نوشته شود جمع می‌کند تا بعداً بتوانید آن را بازخوانی کنید. هر دو همان پروتکلی را پیاده‌سازی می‌کنند که جریان‌های فایل دارند، بنابراین آنچه اینجا یاد می‌گیرید مستقیماً به `<file-reader>` / `<file-writer>` هم منتقل می‌شود.

## دامنه‌بندی با `with-…`

برای اینکه یک جریان صریح را به‌عنوان جریان محیطی برای یک quotation مقید کنید و بعد از آن آزادش کنید، از ترکیب‌گر `with-…` استفاده کنید:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] شکل راحت‌تری برای «جمع‌آوری آنچه این quotation چاپ می‌کند» است: نویسنده را می‌سازد، quotation را با آن نویسنده به‌عنوان خروجی محیطی اجرا می‌کند و رشته‌ی ثبت‌شده را برمی‌گرداند:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

همه‌ی ترکیب‌گرهای `with-…` از نوع ترکیب‌گرهای آزادساز هستند (همان خانواده‌ی `with-disposal` و `with-destructors` در [`boatswains-bilge`][boatswains-bilge])؛ جریان هنگام خروج آزاد می‌شود، حتی اگر quotation خطا بدهد.
