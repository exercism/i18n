# دستورالعمل‌ها

در ادامه‌ی کار خود در پارک تفریحی، قرار است چند متد کمکی بنویسید تا بررسی اینکه یک بازدیدکننده می‌تواند از وسیله‌ی بازی استفاده کند یا نه، آسان‌تر شود.

## 1. بررسی کنید که آیا بازدیدکننده بلیت وسیله‌ی بازی دارد

متد `Attendee#has_pass?` را طوری پیاده‌سازی کنید که بر اساس وجود بلیت وسیله‌ی بازی، یک «مقدار منطقی» (`true`/`false`) برگرداند.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. بررسی کنید که آیا بازدیدکننده برای یک وسیله‌ی بازی مناسب است

متد `Attendee#fits_ride?` را پیاده‌سازی کنید تا بر اساس قد، بررسی شود که آیا بازدیدکننده برای یک وسیله‌ی بازی مناسب است.
حداقل قد مورد نیاز وسیله‌ی بازی به‌عنوان آرگومان داده می‌شود.
قد بازدیدکننده باید بزرگ‌تر یا مساوی حداقل قد مورد نیاز وسیله‌ی بازی باشد.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. بررسی کنید که آیا بازدیدکننده اجازه‌ی سوار شدن دارد

متد `Attendee#allowed_to_ride?` را پیاده‌سازی کنید تا ببینید آیا بازدیدکننده اجازه دارد سوار یک وسیله‌ی بازی شود. حداقل قد مورد نیاز وسیله‌ی بازی به‌عنوان آرگومان داده می‌شود. بازدیدکننده باید بلیت وسیله‌ی بازی داشته باشد و برای آن وسیله‌ی بازی مناسب باشد.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
