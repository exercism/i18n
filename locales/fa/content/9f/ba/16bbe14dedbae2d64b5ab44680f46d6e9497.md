# درباره

کتابخانه‌ی دنباله‌های Factor به‌شدت بر «quotation»ها، یعنی کدی که داخل `[ ]` نوشته می‌شود، تکیه می‌کند تا تکرار را پارامتربندی کند. شکل کار همیشه یکی است: یک دنباله و یک quotation بدهید؛ آن‌گاه واژه‌ی مرتبه‌بالا آن quotation را روی هر عنصر اجرا می‌کند.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

مجموعه‌ی کامل واژه‌های پرکاربرد:

| واژه         | شکل                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

وقتی واژه‌ی *خودتان* یک quotation زمان اجرا را به یکی از این ترکیب‌گرها می‌فرستد، واژه‌ی خود را با `; inline` تعریف کنید تا استنتاج اثر ترکیب‌گر بتواند شکل quotation را در محل فراخوانی ببیند. واژه‌هایی که فقط از quotationهای ثابت ساخته شده‌اند به آن نیازی ندارند.

فراتر از عملیات‌های اصلی دنباله:

| واژگان              | فراهم می‌کند                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

ترکیب‌گرهای جفتی (`bi`، `tri`) و ترکیب‌گرهای «n-ary» (`2map`، `2each`، `zip`) همین الگو را بسط می‌دهند، وقتی که quotation به بیش از یک ورودی نیاز دارد.
