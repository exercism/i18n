# ساختار

«ساختار» نوع داده‌ی سفارشی است که به شما اجازه می‌دهد چندین مقدار مرتبط را نام‌گذاری و با هم بسته‌بندی کنید.
آن‌ها شبیه «تاپل» هستند، اما انعطاف‌پذیرترند و به شما اجازه می‌دهند هر قطعه داده را نام‌گذاری کنید، که کد شما را خواناتر می‌کند.
ساختار در Cairo این ویژگی‌ها را دارد:

- هر نوع ساختار یک نام خاص دارد.
- به هر عضو یک ساختار، «**فیلد**» می‌گویند.
- هر فیلد یک ساختار یک نام خاص دارد.
- قابلیت مشاهده در سطح فیلد پیگیری می‌شود: هر فیلد می‌تواند به طور مستقل عمومی یا خصوصی باشد.

## تعریف و نمونه‌سازی ساختار

برای تعریف یک ساختار، از کلیدواژه‌ی `struct` استفاده کنید و پس از آن یک نام و آکولادها را بیاورید که شامل فیلدها با نام‌ها و نوع‌هایشان است:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

برای ایجاد یک نمونه از `struct`، نام `struct` را مشخص کنید و از آکولادها با جفت‌های کلید-مقدار برای فیلدها استفاده کنید.
توجه داشته باشید که می‌توانید فیلدها را به هر ترتیبی هنگام ایجاد یک نمونه فهرست کنید:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## تعامل با یک نمونه از ساختار

برای دسترسی یا تغییر فیلدهای یک نمونه‌ی `struct` از «نشانه‌گذاری نقطه» استفاده کنید.
توجه داشته باشید که برای تغییر یک فیلد، نمونه باید «تغییرپذیر» باشد:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

مانند هر عبارت دیگری، می‌توانیم یک نمونه‌ی جدید از `struct` را به عنوان آخرین عبارت در بدنه‌ی تابع بسازیم تا آن نمونه‌ی جدید به طور ضمنی برگردانده شود:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## خلاصه‌نویسی مقداردهی اولیه‌ی فیلد

در مثال قبلی، نام‌گذاری پارامترهای تابع `email` و `username` با همان نام‌های فیلدهای `struct` منطقی بود، اما تکرار آن‌ها هنگام نسبت دادن به فیلدهای ساختار کمی خسته‌کننده است.
خوشبختانه، یک «خلاصه‌نویسی» راحت برای مقداردهی اولیه‌ی فیلدهای ساختار از متغیرهایی با همان نام‌ها وجود دارد:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## ایجاد نمونه از نمونه‌های دیگر با نحوه‌ی نگارش به‌روزرسانی ساختار

از «نحوه‌ی نگارش به‌روزرسانی ساختار» برای ایجاد یک نمونه‌ی جدید از یک نمونه‌ی موجود استفاده کنید، در حالی که برخی فیلدها را تغییر می‌دهید و بقیه را یکسان نگه می‌دارید.
این کار با استفاده از عملگر `..` انجام می‌شود.

بدون نحوه‌ی نگارش به‌روزرسانی:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

با نحوه‌ی نگارش به‌روزرسانی:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

نحوه‌ی نگارش `..user1` فیلدهای باقی‌مانده را از `user1` به `user2` کپی می‌کند.
توجه داشته باشید که این کار داده را از `user1` به `user2` منتقل می‌کند، بنابراین `user1` پس از آن قابل استفاده نیست اگر شامل نوع‌های غیرقابل‌کپی باشد.
