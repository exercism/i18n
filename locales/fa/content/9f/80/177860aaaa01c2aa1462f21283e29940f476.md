# دستورالعمل‌ها

شما به دوستی کمک می‌کنید تا از خوانش‌هایی که او از گوشه‌های مختلف باغش گرفته است، گزارشی تهیه کند.
متأسفانه، دوست شما داده‌ها را در قالبی عجیب ذخیره کرده است.
هر خوانش مجموعه‌ای از فیلدهای جداشده با کاما است.
با این حال، او اعداد دو رقمی را در دو ستون ذخیره کرده است.

| شماره‌ی فیلد | معنا |
| --- | --- |
| ۱ | شماره‌ی شناسه |
| ۲ | مکان |
| ۳ | خوانش اول، رقم دهگان |
| ۴ | خوانش اول، رقم یکان |
| ۵ | خوانش دوم، رقم دهگان |
| ۶ | خوانش دوم، رقم یکان |

برای یک سطر ورودی مانند `101,house,4,2,5,4`
- خوانش اول `42` است،
- خوانش دوم `54` است.

## وظیفه ۱: تهیه‌ی گزارش

وظیفه‌ی شما این است که میانگین دو خوانش را پیدا کنید و نتیجه‌ی هر سطر را در قالب زیر خروجی دهید

```none
#<id>, <label> = <average>
```

از آنجا که میانگین ۴۲ و ۵۴ برابر ۴۸ است، خروجی برای سطر نمونه باید به این صورت باشد:

```none
#101, house = 48
```
