# دستورالعمل‌ها

در این تمرین، خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با این قالب: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

شما سه وظیفه دارید و هر وظیفه یک خط لاگ می‌گیرد و از شما می‌خواهد کاری با آن انجام دهید.

## 1. گرفتن پیام از یک خط لاگ

متد (_static_) `LogLevels.message()` را پیاده‌سازی کنید تا پیام یک خط لاگ را برگرداند:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

هر فاصله‌ی سفید ابتدایی یا انتهایی باید حذف شود:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. گرفتن سطح لاگ از یک خط لاگ

متد (_static_) `LogLevels.logLevel()` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را برگرداند؛ این سطح باید با حروف کوچک برگردانده شود:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. قالب‌بندی مجدد یک خط لاگ

متد (_static_) `LogLevels.reformat()` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند: پیام را اول می‌آورد و بعد از آن، سطح لاگ را داخل پرانتز قرار می‌دهد:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
