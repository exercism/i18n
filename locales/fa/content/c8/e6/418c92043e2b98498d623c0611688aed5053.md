# راهنمایی‌ها

## 1. استخراج خطاها

- می‌توانید خطاها را با استفاده از روش نگارش الگوی `Error(value)` تطبیق دهید.

## 2. حذف پیشوند تیم

- می‌توانید پیشوندهای رشته را با استفاده از روش نگارش الگوی `"prefix" <> rest` تطبیق دهید.

## 3. جدا کردن منطقه و تیم

- می‌توانید رشته‌ها را با استفاده از [تابع `string.split`][split] روی یک کاراکتر جدا کنید.
- می‌توانید فهرست‌ها را با استفاده از روش نگارش الگوی `[a, b, c]` تطبیق دهید.

[split]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#split
