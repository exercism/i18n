# مبانی

یک برنامه‌ی Sather از **کلاس‌هایی** ساخته شده است که **روال‌ها** را در خود جای می‌دهند.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## کلاس

اسم یک کلاس با حروف بزرگ نوشته می‌شود و بین کلمات آن زیرخط می‌آید: `GREETER`، `STAGE_DIRECTIONS`. اسم فایل هم معمولاً با آن مطابقت دارد، با حروف کوچک: `stage_directions.sa`.

هر روال درون یک کلاس قرار دارد. هیچ کدی بیرون از کلاس وجود ندارد.

## روال

روالی که پاسخی تولید می‌کند، نوع آن پاسخ را بعد از دونقطه اعلام می‌کند:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` نوع متن است. روالی که آرگومان نمی‌گیرد، بدون پرانتز نوشته و فراخوانی می‌شود.

روال می‌تواند آرگومان بگیرد که در پرانتز بعد از اسم نوشته می‌شوند:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` پاسخ را برمی‌گرداند و همان‌جا روال را متوقف می‌کند، بنابراین هر خطی که زیر آن باشد نادیده گرفته می‌شود.

## فراخوانی

از بیرون کلاس، اسم کلاس را بنویسید، بعد `::` و بعد روال:

```sather
GREETER::hello
```

از درون همان کلاس، می‌توان اسم کلاس را حذف کرد. این روش معمول برای این است که یک روال از روال دیگری استفاده کند:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## توضیح

دو خط تیره یک توضیح را شروع می‌کنند که تا پایان خط ادامه دارد.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

طبق قرارداد، یک کلاس با توضیحی پایان می‌یابد که اسم آن را می‌گوید. روال‌ها، حلقه‌ها و کلاس‌ها همه با `end;` بسته می‌شوند، بنابراین توضیح می‌گوید این `end;` به کدام‌یک تعلق دارد:

```sather
end; -- class GREETER
```

## نقطه‌ویرگول

دستورها با نقطه‌ویرگول پایان می‌یابند. نقطه‌ویرگول بعد از آخرین دستور در یک روال اختیاری است، اما نوشتن آن هر دفعه یعنی یک مورد کمتر که باید به آن فکر کنید.
