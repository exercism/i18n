# دستورالعمل‌ها

جاش در حال کار روی یک بازی نقش‌آفرینی جدید است و برای پیاده‌سازی بخشی از مکانیک‌های آن به کمک شما نیاز دارد.

## 1. اتحادهای نوع را تعریف کنید

یک اتحاد نوع از `String` و `Missing` با اسم `StringOrMissing` تعریف کنید که بتوان در کدهای بعدی از آن استفاده کرد.
یک اتحاد نوع از `Int64` و `Nothing` با اسم `IntOrNothing` تعریف کنید که بتوان در کدهای بعدی از آن استفاده کرد.

## 2. نوع ترکیبی `Player` را پیاده‌سازی کنید

نوع ترکیبی `Player` باید شامل چهار فیلد باشد که هر کدام یک حاشیه‌نویسی نوع و یک مقدار پیش‌فرض دارند:
- `name` از نوع `StringOrMissing` است و مقدار پیش‌فرضش `missing` است
- `level` از نوع `Int64` است و مقدار پیش‌فرضش `0` است
- `health` از نوع `Int64` است و مقدار پیش‌فرضش `100` است
- `mana` از نوع `IntOrNothing` است و مقدار پیش‌فرضش `nothing` است

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. خودتان را معرفی کنید

تابع `introduce` را پیاده‌سازی کنید.

بازیکنان مخفی‌کار ممکن است اسمشان را پنهان کرده باشند؛ این‌ها با `"Mighty Magician"` معرفی می‌شوند. در غیر این صورت، برای معرفی فقط از اسم بازیکن استفاده کنید.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. متدهای `increment` را پیاده‌سازی کنید

تابع کمکی `increment` دو متد دارد که هر کدام امضای تابع متفاوتی دارند. آرگومان هر یک به یک حاشیه‌نویسی نوع نیاز دارد تا امضا صریح شود.

متد `increment` برای اسم‌ها باید `name` بازیکن را بگیرد.
- اگر اسم `missing` باشد، عنوان «The Great» را برگردانید.
- در غیر این صورت، عنوان « the Great» به اسم اضافه می‌شود.

این متد `increment` اسم جدید را برمی‌گرداند.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

متد `increment` برای مانا باید `mana` بازیکن را بگیرد.
- اگر مانای بازیکن `missing` باشد، مقدار `50` را برگردانید.
- در غیر این صورت، مانا باید به میزان `100` افزایش یابد.

این متد `increment` مانای به‌روزشده را برمی‌گرداند.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. تابع `title!` را پیاده‌سازی کنید

بالاترین سطح در بازی `42` است. برای پاسداشت دستاورد بازیکنانی که به این سطح می‌رسند، عنوانی به اسمشان اضافه می‌شود. تابع `title!` اسم بازیکن را به این صورت به‌روزرسانی می‌کند:

- اگر سطح بازیکن 42 باشد، اسم با استفاده از تابع `increment` به‌روزرسانی می‌شود.
- در غیر این صورت، اسم بدون تغییر می‌ماند.

در هر دو حالت، تابع `title!` اسم بازیکن را برمی‌گرداند.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. تابع `revive!` را پیاده‌سازی کنید

تابع `revive!` باید بررسی کند که شخصیت بازیکن واقعاً مرده است (جانش به `0` رسیده است).

اگر بازیکن مرده باشد:
- بازیکن باید با `100` جان احیا شود.
- مانای بازیکن باید با استفاده از تابع `increment` افزایش یابد.

اگر بازیکن زنده باشد، هیچ اتفاقی برایش نمی‌افتد

تابع `revive!` باید بازیکن را برگرداند.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
