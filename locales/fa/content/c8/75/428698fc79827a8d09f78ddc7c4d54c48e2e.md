# مقدمه

«بردار» یک آرایه‌ی یک‌بعدی است.
بردارها می‌توانند عناصری از انواع مختلف داشته باشند.

## ساختن بردار

بردارها را می‌توان با تابع `vector` یا با استفاده از شکل خواننده‌ی `#()` ساخت.

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## دسترسی به عناصر

برای دسترسی به عناصر یک بردار از `aref` استفاده کنید، اندیس‌ها از صفر شروع می‌شوند:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
