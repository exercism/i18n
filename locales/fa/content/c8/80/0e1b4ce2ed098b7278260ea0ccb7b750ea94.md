# متدهای رشته

`String` چندین «متد» دارد که با آنها می‌توان رشته‌ها را دستکاری کرد.
این متدها روی خود رشته فراخوانی می‌شوند و اغلب به‌صورت زنجیره‌ای پشت سر هم قرار می‌گیرند تا چند عملیات روی یک رشته انجام دهند.

در ادامه فهرستی از رایج‌ترین متدها آمده است.
برای دیدن فهرست کامل متدها، [مستندات API مربوط به `String`][string-api] را ببینید.

## String#upcase & String#downcase

متد [`upcase`][upcase] یک رشته‌ی جدید برمی‌گرداند که در آن همه‌ی «کاراکتر»ها به حروف بزرگ تبدیل شده‌اند.

```crystal
"hello".upcase
# => "HELLO"
```

متد [`downcase`][downcase] یک رشته‌ی جدید برمی‌گرداند که همه‌ی کاراکترهایش به حروف کوچک تبدیل شده‌اند.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

Crystal متدهایی برای جایگزین کردن بخش‌هایی از یک رشته دارد.
به اینها [`sub`][sub] (_«جانشانی»_) و [`gsub`][gsub] (_جانشانی سراسری_) می‌گویند.

این متدها می‌توانند یک رشته، کاراکتر یا «عبارت باقاعده» را به‌عنوان آرگومان اول و یک رشته یا کاراکتر را به‌عنوان آرگومان دوم بگیرند.
آرگومان اول بخشی از رشته است که جایگزین می‌شود و آرگومان دوم جایگزین‌کننده است.
`Char` و عبارت باقاعده در مفاهیم بعدی توضیح داده می‌شوند.

متد `sub` اولین رخداد آرگومان اول را با آرگومان دوم جایگزین می‌کند.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

متد `gsub` مثل `sub` کار می‌کند، با این تفاوت که همه‌ی رخدادهای آرگومان اول را با آرگومان دوم جایگزین می‌کند.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

از chomp و strip می‌توان برای حذف کاراکترهای ناخواسته از یک رشته استفاده کرد.

متد [`chomp`][chomp] به‌طور پیش‌فرض آخرین کاراکترهای `\r`، `\n` یا `\r\n` را از یک رشته حذف می‌کند.
اگر این متد با یک آرگومان فراخوانی شود، مقدار داده‌شده را از انتهای رشته حذف می‌کند، البته اگر آن مقدار واقعاً در انتهای رشته وجود داشته باشد.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

متد [`strip`][strip] به‌طور پیش‌فرض همه‌ی فضای سفید را از ابتدا و انتهای یک رشته حذف می‌کند.
اگر این متد با یک آرگومان فراخوانی شود، آن آرگومان را از ابتدا و انتهای رشته حذف می‌کند، البته اگر آن آرگومان واقعاً در ابتدا یا انتهای رشته وجود داشته باشد.

```crystal
" hello ".strip
# => "hello"
```

## String#index

از متد [`index`][index] می‌توان برای یافتن «اندیس» یک کاراکتر در یک رشته استفاده کرد.
متد `index` یک `String`، `Char` یا عبارت باقاعده را به‌عنوان آرگومان می‌گیرد.
می‌تواند یک آرگومان دوم اختیاری هم بگیرد تا اندیسی که جست‌وجو از آن شروع می‌شود را مشخص کند.
متد `index` اندیس اولین رخداد آرگومان را برمی‌گرداند.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

می‌توانید از متد [`delete_at`][delete_at] برای حذف یک کاراکتر از یک رشته استفاده کنید.
متد `delete_at` یک اندیس را به‌عنوان آرگومان می‌گیرد و کاراکتر موجود در آن اندیس را حذف می‌کند.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

از متد [`insert`][insert] می‌توان برای درج یک رشته در اندیسی مشخص استفاده کرد.
متد `insert` یک اندیس را به‌عنوان آرگومان اول و یک رشته را به‌عنوان آرگومان دوم می‌گیرد.
متد `insert` یک رشته‌ی جدید برمی‌گرداند که آرگومان دوم در آن اندیس درج شده است.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
