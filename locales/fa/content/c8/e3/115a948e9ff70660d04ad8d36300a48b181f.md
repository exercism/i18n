# پیوست دستورالعمل‌ها

## DSL خودتان را بسازید

در این تمرین، کاملاً آزاد هستید که DSL گرافِ دلخواه خودتان را طراحی کنید.

شاید بخواهید DSL‌ای بر پایه‌ی فهرست‌هایی از برچسب‌ها و رکوردها بسازید، مثل این:

```roc
my_graph =
    Graph.create([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

یا شاید DSL‌ای را ترجیح می‌دهید که بر پایه‌ی زنجیره‌ای از فراخوانی توابع بنا شده باشد، مثل این:

```roc
my_graph =
    Graph.create()
        .with_title("My Graph")
        .add_node("a", Attr.create().with_color(Green))
        ...
```

یا شاید برنامه‌ی کاملاً متفاوتی دارید؟ بفرمایید! Testها فقط می‌خواهند چند گراف مشخص بسازید؛ اینکه چطور آن‌ها را بسازید کاملاً به خودتان بستگی دارد.

با این حال، یک DSL معمولاً وقتی بهتر است که روشن، مختصر و چندان غافلگیرکننده نباشد (مثلاً تابع `minus` برای تفریق در نظر گرفته شده، نه برای ساختن یالی بین دو گره، مثل `node("a") - node("b")`).

برای اینکه سرگرمی دو برابر شود، می‌توانید به‌صورت اختیاری تابع `to_dot` را پیاده‌سازی کنید که گراف شما را به قالب DOT تبدیل می‌کند!
