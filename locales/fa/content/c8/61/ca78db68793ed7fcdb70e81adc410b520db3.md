# درباره

یکی از جنبه‌های کلیدی کار با اعداد در F#، تمایز میان اعداد صحیح (اعدادی که هیچ رقمی بعد از ممیز ندارند) و اعداد ممیز شناور (اعدادی با صفر یا چند رقم بعد از ممیز) است.

دو نوع عددی پرکاربردتر در F#، `int` (یک عدد صحیح ۳۲ بیتی) و `float` (یک عدد ممیز شناور ۶۴ بیتی) هستند.

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

هم اعداد صحیح و هم اعداد ممیز شناور می‌توانند از نویسه‌ی `_` به عنوان _جداکننده‌ی رقم_ استفاده کنند، که هنگام تعریف اعداد بزرگ می‌تواند کمک کند:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

محاسبات ریاضی با [عملگرهای حسابی][arithmetic-operators] استاندارد (`+`، `-`، `*` و غیره) انجام می‌شود. اعداد را می‌توان با [عملگرهای مقایسه][comparison-operators] استاندارد (`<`، `>=` و غیره) و عملگرهای تساوی (`=`) و نامساوی (`<>`) مقایسه کرد.

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

برای تبدیل میان انواع عددی، باید از [عملگر تبدیل][conversion-operators] داخلی استفاده کرد. اسم این عملگرها برگرفته از نوعی است که به آن تبدیل می‌کنند.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

هنگام تبدیل میان انواع، همیشه احتیاط کنید. اگر یک مقدار نتواند با نوع مقصد نمایش داده شود، آن مقدار _سرریز_ می‌شود.
