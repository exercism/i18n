# مقدمه

اساساً دو نوع «حلقه» وجود دارد:

1. حلقه‌ای که تا برآورده شدن یک شرط ادامه پیدا می‌کند.
2. حلقه‌ای که روی عناصر یک مجموعه می‌گردد.

هر دو در Julia امکان‌پذیرند، هرچند دومی ممکن است رایج‌تر باشد.

## حلقه‌ی `while`

برای مسائل بازی که تعداد دورهای حلقه از پیش معلوم نیست، Julia حلقه‌ی `while` را دارد.

شکل پایه‌ای آن نسبتاً ساده است:

```julia
while condition
    do_something()
end
```

در این حالت، برنامه آن‌قدر دور حلقه ادامه می‌دهد تا `condition` دیگر `true` نباشد.

دو راه برای خروج زودهنگام از حلقه وجود دارد:

- یک `break` باعث خروج از حلقه می‌شود و اجرا از خط بعدی پس از `end` حلقه ادامه می‌یابد.
- یک `return x` اجرای تابع جاری را متوقف می‌کند و مقدار بازگشتی `x` را به فراخوان‌کننده برمی‌گرداند.

با وجود این گزینه‌ها، گاهی راحت است که یک حلقه‌ی «بی‌نهایت» با `while true ... end` بسازید و سپس با یافتن شرطی برای توقف در بدنه‌ی حلقه، یک `break` یا `return` را فعال کنید.

## حلقه زدن روی یک مجموعه

ساده‌ترین مثال، حلقه زدن روی یک بازه است.

اگر بخواهیم کاری را ۱۰ بار انجام دهیم:

```julia
for n in 1:10
    do_something(n)
end
```

اگر تکرار جاری شرطی را برآورده نکند، می‌توان با یک `continue` بی‌درنگ به تکرار بعدی پرید:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

در شکلی کوتاه‌تر، می‌توان بلوک `if` را با `is_useless(n) && continue` جایگزین کرد.

می‌توان روی انواع دیگری از مجموعه‌ها هم حلقه زد: عناصر یک آرایه، کاراکترهای یک رشته، کلیدهای یک دیکشنری...

مثال‌های تا اینجا روی بازه‌ی `1:10` حلقه می‌زنند، که در آن مقدار همان اندیس حلقه هم هست.

به‌طور کلی‌تر، ممکن است به اندیس نیاز باشد و نه فقط به مقدار.
برای این کار از تابع `eachindex()` استفاده می‌شود، مثلاً `for i in eachindex(my_array) ... end`.
