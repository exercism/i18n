# درباره

«عملگر سه‌تایی شرطی» برای نوشتن یک عبارت فشرده به کار می‌رود که بر اساس یک شرط، یکی از دو مقدار جایگزین را برمی‌گرداند.
اغلب به آن «عملگر سه‌تایی» می‌گویند.
این اسم از آنجا می‌آید که عملگر سه عملوند دارد: `predicate ? consequent-expression : alternative-expression`
می‌توان از آن به عنوان جایگزینی برای دستورهای کوتاه `if-else` استفاده کرد.

مانند دستورهای `if`، JavaScript برای ارزیابی شرط تبدیل نوع ضمنی انجام می‌دهد.
اگر شرط درست ارزیابی شود، عملوند سمت چپ دونقطه برگردانده می‌شود.
در غیر این صورت، نتیجه‌ی عبارت سه‌تایی، عملوند سمت راست دونقطه است.

```javascript
const year = 2020;

year > 2000 ? 'in the past years' : 'a long time ago';
// => 'in the past years'
```
