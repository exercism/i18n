# دستورالعمل‌ها

در این تمرین باید چند تابع پیاده‌سازی کنید تا لیستی از زبان‌های برنامه‌نویسی را دستکاری کنید.

## 1. یک تابع تعریف کنید که یک لیست زبان خالی برگرداند

تابع `language_list` را تعریف کنید که هیچ آرگومانی نمی‌گیرد و یک لیست خالی برمی‌گرداند.

```php
<?php

language_list();
// => []
```

## 2. تابع را طوری تغییر دهید که از هر تعداد زبان یک لیست بسازد

تابع `language_list` را طوری تغییر دهید که یک آرگومان متغیر از زبان‌ها (رشته‌ها) بگیرد. باید لیست حاصل را که شامل زبان‌هاست برگرداند.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. یک تابع تعریف کنید که زبانی به لیست اضافه کند

تابع `add_to_language_list` را تعریف کنید که ۲ آرگومان می‌گیرد: آرایه‌ای از زبان‌ها و زبان جدید.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. یک تابع تعریف کنید که یک عنصر را از لیست زبان حذف کند

تابع `prune_language_list` را تعریف کنید تا اولین زبان را از آرایه‌ی زبان‌ها حذف کند.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. یک تابع تعریف کنید که اولین عنصر لیست را بگیرد

تابع `current_language` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _لیست زبان_). باید اولین زبان موجود در لیست را برگرداند. فرض کنید لیست همیشه حداقل یک عنصر دارد.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. یک تابع تعریف کنید که تعداد زبان‌های موجود در لیست را برگرداند

تابع `language_list_length` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _لیست زبان_). باید تعداد زبان‌های موجود در لیست را برگرداند.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
