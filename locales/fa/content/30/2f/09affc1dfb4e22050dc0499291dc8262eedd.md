# درباره

`assocs` یک [«پروتکل»][assoc-protocol] است، نه یک نوع داده‌ی واحد. «جدول‌های درهم‌سازی» (`H{ }`)، «لیست‌های انجمنی» (دنباله‌هایی از جفت‌های `{ key value }`)، و «نقشه‌های درختی» همگی آن را پیاده‌سازی می‌کنند، و بیشتر واژه‌های مربوط به `assocs` بین آن‌ها قابل‌تعویض هستند.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

سطح کامل آن گسترده است (پیمایش مرتب، نگاشت، پالایش)، اما بیشتر کارهای سطح «exercise» شامل مجموعه‌ی کوچکی می‌شود:

| واژه        | اثر                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` مقدار `f` را از نبودن کلید تشخیص می‌دهد |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`، تغییر می‌دهد            |
| `change-at` | `( key assoc quot -- )`، `quot` برابر است با `( old -- new )` |
| `inc-at`    | `( key assoc -- )`، `+1`، اگر نبود `1` را درج می‌کند |
| `delete-at` | `( key assoc -- )`، تغییر می‌دهد                  |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` و `sort-values` (در `sorting`) یک لیست انجمنی را بر اساس فیلد انتخاب‌شده مرتب می‌کنند.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
