# تست

می‌توانید تست‌های ارائه‌شده را از طریق DrRacket یا از طریق خط فرمان اجرا کنید.

برای اجرای تست از طریق DrRacket، کافی است فایل تست را باز کنید و روی دکمه‌ی «Run» در بالا سمت راست کلیک کنید.

برای اجرای تست از خط فرمان، کافی است تست را از پوشه‌ی تمرین اجرا کنید. برای مثال، اگر مجموعه تست به اسم `hello-world-test.rkt` باشد، می‌توانید فرمان زیر را اجرا کنید:

```
raco test hello-world-test.rkt
```

که خروجی زیر را نمایش می‌دهد:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
