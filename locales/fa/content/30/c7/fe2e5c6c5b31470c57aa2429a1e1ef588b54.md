# مقدمه
انواع عددی داخلی در C++ را می‌توان به اعداد صحیح و اعداد اعشاری تقسیم کرد.
اعداد صحیح، اعداد کامل هستند، مانند `0`، `691` یا `-2`.
اعداد اعشاری اعدادی هستند که ممیز دارند، مانند `6.02214076`، `0.1` یا `-1.616`.

## اعداد صحیح
مثال زیر اعلان و مقداردهی اولیه‌ی چهار متغیر متفاوت را نشان می‌دهد

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

وقتی مقداری را به یک متغیر `int` نسبت می‌دهید، می‌توانید این کار را مستقیماً با یک مقدار ثابت انجام دهید.
مقدار ثابت، عددی است که به‌صورت مستقیم در کد نوشته شده است، مانند `9241`.
برای پایه‌های مختلف نمایش، مقادیر ثابت صحیح متفاوتی وجود دارد.
مقادیر ثابت صحیح دهدهی رایج‌ترین هستند و از ارقام `0` تا `9` استفاده می‌کنند.
با افزودن یک پیشوند ویژه، مانند `0x`، می‌توان از پایه‌های دیگر استفاده کرد.
مثال بالا عدد `9421` را در چهار نمایش و پیشوند آن نشان می‌دهد.
همه‌ی متغیرها به مقدار یکسانی مقداردهی اولیه می‌شوند.

برای جزئیات بیشتر درباره‌ی سیستم‌های نمایش مختلف، نگاهی به [یک آموزش کوچک][cpp_numerical_bases] بیندازید.

می‌توانید برای خوانایی راحت‌تر، ارقام را با یک آپاستروف از هم جدا کنید.
`9'241` همان `0b0100'100'0001'1001` یا `92'4'1` است.

## اعداد اعشاری

مقادیر ثابت اعشاری به دو شکل وجود دارند.
علاوه بر شکل شهودی `0.0024`، می‌توان از نمایش علمی آن `2.4e-3` نیز استفاده کرد.
رایج‌ترین نوع اعشاری `double` است.

## عملیات حسابی

C++ از `+`، `-`، `*`، `/`، `(` و `)` و `%` برای ساختن عبارت‌ها پشتیبانی می‌کند.
نتیجه‌ی عملیات بین دو عدد صحیح نیز یک عدد صحیح است.
`5 / 2` مقدار `2` را برمی‌گرداند.
وقتی یکی از انواع درگیر از نوع اعشاری باشد، نتیجه نیز اعشاری خواهد بود.
`5.0 / 2` و `5 / 2.0` مقدار `2.5` را برمی‌گردانند.
`%` عملگر باقیمانده است و باقیمانده‌ی تقسیم صحیح را برمی‌گرداند: `5%3` برابر `2` است.

## عملگر انتساب

عملگر انتساب، یک مقدار ثابت را به متغیر نسبت می‌دهد.
همیشه از راست به چپ انجام می‌شود و هرگز برعکس.

```cpp
int length = 5;
int width = 2;
length = width;
```

در اینجا مقدار صحیح `5` به متغیر `length` نسبت داده می‌شود.
سپس مقدار صحیح `2` به متغیر `width` نسبت داده می‌شود.
در پایان، مقدار `width` در متغیر `length` کپی می‌شود و مقدار پیشین `5` از بین می‌رود.
همچنین در نظر بگیرید که ما فقط در لحظه‌ی عمل انتساب، مقدار `width` را به `length` نسبت می‌دهیم.
بنابراین، اگر مقدار `width` در لحظه‌ای بعدتر تغییر کند، بر مقداری که `length` گرفته است تأثیری نخواهد داشت.

عملگر انتساب را می‌توان با سایر عملگرها (حسابی و بیتی) ترکیب کرد که به آن‌ها عملگرهای `compound assignment` می‌گویند: `+=`، `-=`، `*=`، `/=`، `%=`.
این عملگرها با انجام یک عملیات روی مقدار فعلی متغیر، آن را تغییر می‌دهند.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

متغیرهای `people` و `eggs` با `0` مقداردهی اولیه می‌شوند.
سپس مقدار صحیح `2` را به مقدار موجود `0` متغیر `people` اضافه می‌کنیم و نتیجه را به `people` نسبت می‌دهیم.
اکنون `people` برابر `2` می‌شود.
بعدتر، برای هر نفر `3` تخم‌مرغ اضافه می‌کنیم که در کل `6` تخم‌مرغ می‌شود.
حالا این `6` را به مقدار موجود `0` متغیر `eggs` اضافه می‌کنیم و نتیجه را به `eggs` نسبت می‌دهیم.
`eggs` اکنون `6` خواهد بود.
عبارت معادل آن `people = people + 2` و `eggs = eggs + (3 * people)` خواهد بود.
