# مقدمه

## انواع تابع

اگر همه‌ی اسم‌ها و برچسب‌ها را از امضای یک تابع Swift حذف کنید، چیزی که باقی می‌ماند نوع آن تابع است.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

دقت کنید که نوع دو تابع اول یکسان است، `(String, Int) -> String`، هرچند امضای این دو با هم فرق دارد و این دو تابع به شکل کاملاً متفاوتی کار می‌کنند. هر دوی آن‌ها یک `String` و یک `Int` را به‌عنوان ورودی می‌گیرند و یک `String` برمی‌گردانند. و همان‌طور که از نوع تابع سوم پیداست، با اینکه به نظر می‌رسد بدنه‌ی تابع چیزی برنمی‌گرداند، در واقع به‌طور ضمنی `()` را برمی‌گرداند، که تنها مقدار نوع `Void` است.

می‌توان از این انواع تابع دقیقاً مانند هر نوع دیگری در Swift استفاده کرد؛ برای مثال، می‌توان آن‌ها را در اعلان متغیرها یا ثابت‌ها به کار برد. و چون توابع در Swift مقدار هستند، می‌توان توابع موجود را به این ثابت‌ها/متغیرها نسبت داد:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

مانند سایر متغیرها/ثابت‌ها، مقداری که به آن نسبت می‌دهید باید از نوع درست باشد:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

### انواع تابع به‌عنوان نوع پارامتر

از آنجا که می‌توان انواع تابع را هر جایی که سایر انواع به کار می‌روند استفاده کرد، نتیجه می‌شود که می‌توان از آن‌ها به‌عنوان نوع پارامتر استفاده کرد، آن‌ها را به توابع دیگر پاس داد و از داخل همان توابع فراخوانی کرد.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## انواع تابع به‌عنوان نوع بازگشتی

به همین ترتیب، می‌توان از انواع تابع به‌عنوان نوع بازگشتی توابع استفاده کرد. به عبارت دیگر، می‌توان توابعی نوشت که توابع دیگری می‌سازند و برمی‌گردانند. هنگام ساختن این توابع، تابعی که برگردانده می‌شود می‌تواند از سایر پارامترهایی که به تابع پاس داده شده‌اند یا از متغیرهای محلی‌ای که درون تابع والد ساخته شده‌اند استفاده کند.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
