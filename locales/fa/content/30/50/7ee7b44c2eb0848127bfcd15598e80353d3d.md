# پیوست دستورالعمل‌ها

## راهنمایی‌ها

برای تکمیل این تمرین باید تابع `score` را پیاده‌سازی کنید که دنباله‌ای از *پرتاب‌های* بولینگ را می‌گیرد و امتیاز نهایی یا خطای مناسب را برمی‌گرداند:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

این تعاریف از قبل در جای خود قرار دارند، اما تعریف تابع به عهده‌ی خودتان است.

به خاطر داشته باشید که مجموعه‌ی test انتظار دارد پرتاب‌ها از صفر شماره‌گذاری شوند.
