# درباره

«مقدارساز شیء» جایگزینی برای سازنده‌هاست. نحوه‌ی نگارش آن فهرستی است جداشده با کاما از جفت‌های اسم=مقدار فیلد، که در ادامه نشان داده شده است:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

مجموعه‌ها را هم می‌توان به این روش مقداردهی کرد. معمولاً این کار با فهرست‌های جداشده با کاما انجام می‌شود، همان‌طور که در ادامه می‌بینید:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

این روش (و نحوه‌ی نگارش آن) را می‌توان با هر کلاسی به کار برد که `IEnumerable` را پیاده‌سازی می‌کند و متد `Add()` دارد.

فیلدها را می‌توان به هر ترتیبی آورد یا به‌کلی حذف کرد.

دیکشنری‌ها از نحوه‌ی نگارش زیر استفاده می‌کنند:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

فیلدهای مقداردهی‌شده باید برای فراخواننده قابل دسترسی باشند. معمولاً یعنی باید `public` یا `internal` باشند.

میان طراحان زبان و متخصصان برجسته، گرایشی قوی به ترویج تغییرناپذیری وجود دارد؛ به همین دلیل، تغییرپذیری اشیایی که به این روش مقداردهی می‌شوند یک نقطه‌ضعف به شمار می‌آید. پیشنهادهایی مطرح شده است که در نسخه‌ی پیش‌روی این زبان، یعنی C# ۹، بندی `init` معرفی شود که ممکن است این مسئله را حل کند.

- مستندات [مقدارساز شیء][object-initializers] نحوه‌ی استفاده از مقدارسازها را شرح می‌دهد.
- مستندات [مقدارساز مجموعه][collection-initializers] پیش‌نمایشی از نحوه‌ی استفاده از مقدارسازها با مجموعه‌هایی مانند دیکشنری‌ها و لیست‌ها ارائه می‌دهد.

[collection-initializers]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/object-and-collection-initializers#collection-initializers
