# مقدمه

در یک زبان تابعی خالص مانند Elm، تابعی که با آرگومان‌های یکسان فراخوانی می‌شود باید همیشه همان مقدار را برگرداند.
بنابراین تابعی با امضای نوع `rand : Int` فقط می‌تواند به‌صورت `rand = 4` پیاده‌سازی شود، که برای تولید اعداد صحیح تصادفی چندان امیدوارکننده نیست.

حالا چطور مقادیر تصادفی را در Elm تولید می‌کنیم؟
مسئله را به دو بخش تقسیم می‌کنیم: اول، مقداری را که می‌خواهیم تولید کنیم با یک `Random.Generator a` توصیف می‌کنیم، سپس یک مقدار تولید می‌کنیم.

روش اول تولید یک مقدار این است که یک `Random.Seed` را از طریق `initialSeed : Int -> Seed` بسازیم و سپس از `step : Generator a -> Seed -> ( a, Seed )` استفاده کنیم، که یک مقدار و یک دانه‌ی جدید برمی‌گرداند.
توجه کنید که هر دوی این توابع خالص هستند، بنابراین فراخوانی آن‌ها دو بار با آرگومان‌های یکسان، مقادیر یکسانی تولید می‌کند.

روش دوم تولید یک مقدار استفاده از `generate : (a -> msg) -> Generator a -> Cmd msg` است، اما این کار فقط داخل یک برنامه‌ی Elm امکان‌پذیر است.
در آن صورت، زمان اجرای Elm ممکن است از `step` و همچنین منابع خارجی و ناخالص برای تولید دانه‌ها استفاده کند.

از این پس، روی مولدها تمرکز می‌کنیم.

بیایید برای نشان دادن مثال‌ها فرض کنیم که با `initialSeed` و `step` تابعی به صورت `generate : Int -> Generator a -> List a` تعریف کرده‌ایم که تعدادی مقدار را از یک مولد تولید می‌کند.

ماژول `Random` دو مولد پایه برای تولید اعداد صحیح و اعشاری در یک بازه‌ی مشخص فراهم می‌کند:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

این مقادیر را می‌توان در قالب تاپل‌ها یا لیست‌هایی از مقادیر ترکیب کرد:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

بسته‌ی `elm-community/random-extra` مولدهای بسیار بیشتری برای ساختارهای داده‌ی گوناگون فراهم می‌کند: رشته، تاریخ، دیکشنری، آرایه، مجموعه و غیره.

می‌توانیم با `Random.constant` مولدهایی بسازیم که فقط یک مقدار ثابت برمی‌گردانند:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

می‌توانیم با `Random.uniform` به‌صورت تصادفی و با احتمال برابر از میان عناصر داده‌شده انتخاب کنیم:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` دو آرگومان (`Red` و `[Green, Blue]`) می‌گیرد تا تضمین شود حداقل یک مقدار برای انتخاب وجود دارد، چون یک لیست واحد می‌تواند خالی باشد.

همچنین می‌توانیم با `Random.weighted` احتمال‌ها را تنظیم کنیم:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

لازم نیست مقادیر به ۱۰۰ برسند، در هر حال دوباره نرمال‌سازی می‌شوند.

می‌توانیم با `Random.map` به داخل یک مولد برسیم:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

همچنین می‌توانیم از `Random.map2` تا `Random.map5` برای ترکیب مولدهای بیشتر استفاده کنیم:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

برای کاربردهای پیچیده‌تر، `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` را داریم که می‌تواند از مقدار تولیدشده توسط یک مولد برای ساختن مولد دیگر استفاده کند:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

گاهی مفید است که یک مولد را به‌صورت بازگشتی تعریف کنیم.
در آن موارد، ممکن است لازم باشد از `Random.lazy` استفاده کنید تا مانع از بازگشایی بی‌نهایت مولد توسط کامپایلر شوید.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

این مثال کمی سنگین است، پس بیایید آن را تجزیه کنیم.

`Peano` نوعی است که اعداد صحیح مثبت را نشان می‌دهد: `Zero` معادل ۰ است، `Next(Zero)` معادل ۱، `Next(Next(Zero))` معادل ۲ و غیره.
`peano` را تعریف می‌کنیم تا یک عدد `Peano` تصادفی به ما بدهد.

پیش از هر چیز، توجه کنید که `Random.lazy` چیزی به منطق اضافه نمی‌کند، فقط مانع می‌شود کامپایلر `peano` را به‌طور نامحدود در `peano` بنویسد.

ما از `Random.uniform` استفاده می‌کنیم تا بین صفر (با احتمال ۵۰٪) و یک عدد `Peano` دیگر به‌اضافه‌ی یک (با احتمال ۵۰٪) انتخاب کنیم.
اما برخلاف مثال قبلی، `Random.uniform` از میان مقادیر (مثل `Zero`) انتخاب نمی‌کند، بلکه از میان مولدها (مثل `Random.constant Zero`) انتخاب می‌کند، چون می‌خواهیم از خود `peano` استفاده کنیم.
این یعنی `Random.uniform` مقداری از نوع `Generator (Generator Peano)` برمی‌گرداند، که آن چیزی نیست که ما نیاز داریم.

برای «مسطح کردن» مولد، آن را به `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` می‌فرستیم، جایی که می‌خواهیم `b` برابر `Peano` باشد.
از آنجا که `Generator a` همان `Generator (Generator Peano)` است، `a` باید `Generator Peano` باشد، و تابع `(a -> Generator b)` باید از نوع `(Generator Peano -> Generator Peano)` باشد.
ما نمی‌خواهیم چیزی را تغییر دهیم، بنابراین `identity` انتخاب درستی است.

در نهایت، `peano` چه نوع اعدادی تولید می‌کند؟
می‌دانیم که در ۵۰٪ مواقع ۰ تولید می‌کند، یا در ۵۰٪ مواقع، تکرار دیگری از خودش به‌اضافه‌ی یک را تولید می‌کند.
یعنی اعداد به این ترتیب خواهند بود: ۰ (۵۰٪ مواقع)، ۱ (۲۵٪ مواقع)، ۲ (۱۲٪ مواقع)، ۳ (۶٪ مواقع) و غیره.
`peano` می‌تواند اعداد بزرگ دلخواه تولید کند، اما با احتمالی که به‌صورت نمایی کاهش می‌یابد.
