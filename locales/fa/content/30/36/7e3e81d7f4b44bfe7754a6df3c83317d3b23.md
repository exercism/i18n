# پیوست دستورالعمل‌ها

## قالب میدان مین

میدان مین به‌صورت یک رشته‌ی پایان‌نول نمایش داده می‌شود که در پایان هر سطر یک نویسه‌ی سطر جدید دارد.

یک نمونه می‌تواند `"   \n * \n   \n"` باشد.

## ثبات

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | آدرس | رشته‌ی ورودی پایان‌نول  |
| `$a1`    | ورودی/خروجی | آدرس | رشته‌ی خروجی پایان‌نول |
| `$t0-9`  | موقت    | دلخواه     | برای ذخیره‌سازی موقت         |
