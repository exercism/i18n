# دستورالعمل‌ها

در این تمرین شما روی یک برنامه‌ریز قرار ملاقات برای یک سالن زیبایی در نیویورک کار خواهید کرد که در ۱۵ سپتامبر ۲۰۱۲ افتتاح شد.

شما پنج تسک دارید که همه‌ی آن‌ها به تاریخ‌های قرار ملاقات مربوط می‌شوند.
زمان‌ها در قالب ۲۴ ساعته هستند (بدون ق.ظ/ب.ظ).

## 1. تاریخ قرار ملاقات تمام‌عددی را تجزیه کنید

تابع `schedule_appointment()` را پیاده‌سازی کنید تا یک نمایش متنی از تاریخ قرار ملاقات را به قالب `DateTime` متناظر تجزیه کند.

توجه داشته باشید که ورودی به ترتیب ماه/روز/سال آمریکایی است.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. بررسی کنید که آیا قرار ملاقات قبلاً گذشته است

تابع `has_passed()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و بررسی می‌کند که آیا قرار ملاقات در جایی در گذشته بوده است:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. بررسی کنید که آیا قرار ملاقات در بعدازظهر است

تابع `is_afternoon_appointment()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و بررسی می‌کند که آیا قرار ملاقات در بعدازظهر است (>= ۱۲:۰۰ و < ۱۸:۰۰):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. زمان و تاریخ قرار ملاقات را توصیف کنید

تابع `description()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و توصیفی از آن تاریخ و زمان برمی‌گرداند:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. تاریخ سالگرد را برگردانید

تابع `anniversary_date()` را پیاده‌سازی کنید که تاریخ سالگرد امسال را برمی‌گرداند، که ۱۵ سپتامبر است:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
