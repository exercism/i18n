# مبانی نحو Elm ۱

## ثابت‌ها و توابع

برنامه‌های Elm از «تعریف»ها و «عبارت»ها تشکیل شده‌اند. هر چیزی در Elm یا یک تعریف است یا یک عبارت.

یک «مقدار ثابت» با `name = expression` تعریف می‌شود.

```elm
five = 5

six = 3 + 3
```

توابع با `name parameters... = expression` تعریف می‌شوند و پارامترها فقط با فاصله از هم جدا می‌شوند.

```elm
add number1 number2 = number1 + number2
```

فراخوانی کردن یک تابع هم خودش یک عبارت است و با نوشتن اسم تابع و دادن آرگومان برای هر یک از پارامترهای آن انجام می‌شود؛ آرگومان‌ها مانند تعریف تابع فقط با فاصله از هم جدا می‌شوند.

```elm
five = add 2 3
```

می‌توان از پرانتز برای تعیین ترتیب ارزیابی یک عبارت استفاده کرد.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## تورفتگی / فاصله‌های معنادار

Elm از نشانه‌های نحوی مانند آکولاد، پرانتز یا نقطه‌ویرگول برای مشخص کردن مرزهای کد استفاده نمی‌کند. در عوض از فاصله‌ها و تورفتگی‌ها استفاده می‌کند.

- تعریف‌های ماژول، import و توابع سطح بالا باید از چپ‌ترین ستون شروع شوند.
- اگر یک عبارت به چند خط تقسیم شود، کدی که بخشی از آن عبارت است باید با حداقل یک فاصله زیر آن عبارت تورفته باشد.
- بخش‌هایی از عبارت که با هم گروه‌بندی شده‌اند باید با تعداد برابری فاصله تورفته باشند.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## ماژول‌ها

هر فایل در Elm یک ماژول است و باید پیش از هر کد دیگری یک دستور `module` داشته باشد.
اسم ماژول‌ها باید با اسم فایلشان مطابقت داشته باشد، پس ماژول `Calculator` باید در فایل Calculator.elm باشد.
هر چیزی که داخل یک ماژول تعریف شود، محدوده‌ی دسترسی‌اش خصوصی است و از بیرون این ماژول قابل دسترسی نیست، مگر اینکه در `exposing` فهرست شده باشد.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## توضیحات

توضیح متنی است درون فایل Elm که به عنوان کد تفسیر نمی‌شود.
عمدتاً برای این در نظر گرفته شده که خودتان و برنامه‌نویسان دیگر آن را بخوانید.
برای توضیح‌های یک‌خطی یک نحوه‌ی نگارش سبک بر پایه‌ی دو خط تیره وجود دارد.
توضیح‌های چندخطی هم با جفت `{-` و `-}` به عنوان جداکننده‌های باز و بسته ممکن است.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
