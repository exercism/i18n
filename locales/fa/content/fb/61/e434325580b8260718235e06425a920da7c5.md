# شرط‌های غیرضروری

در این راه‌حل از [شرط‌ها][conditionals] به‌صورت غیرضروری استفاده شده است.
استفاده از [آرگومان پیش‌فرض][default argument] در کنار [str.format][str.format] یا [f-strings][f-strings] (_که با نام‌های «formatted string literals» یا «interpolated strings» هم شناخته می‌شوند_) می‌تواند کد را خواناتر و کم‌حجم‌تر کند.

برای جزئیات بیشتر، این مطلب را درباره‌ی [آرگومان‌های پیش‌فرض پایتون][python default arguments] ببینید.
پست وبلاگی [قالب‌بندی رشته در پایتون][string formatting in python] هم می‌تواند نقطه‌ی شروع خوبی برای یادگیری گزینه‌های قالب‌بندی رشته در پایتون باشد.
