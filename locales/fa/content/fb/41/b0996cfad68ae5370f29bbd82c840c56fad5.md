# نسخه‌ی استاندارد

نسخه‌ی استاندارد Exercism طوری طراحی شده است که افراد از آن برای یادگیری شخصی خود استفاده کنند و در این مسیر، از طریق سیستم‌های انجمن ما به یکدیگر کمک کنند.

این نسخه برای اینکه سازمان‌ها از آن برای آموزش کارکنان یا برگزاری بوت‌کمپ‌ها استفاده کنند، طراحی یا در نظر گرفته نشده است.
برای اینکه بدانید چطور می‌توانید به این اهداف برسید، [نسخه‌ی تیم‌ها](/docs/editions/teams) را ببینید.
