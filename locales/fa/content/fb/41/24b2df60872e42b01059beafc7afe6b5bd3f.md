# مقدمه

همانطور که می‌توان اشاره‌گری به `int` یا دیگر انواع داده‌ی پایه ساخت، می‌توان اشاره‌گری هم به یک تابع ساخت.
از «اشاره‌گر تابع» می‌توان برای پاس دادن یک تابع به تابع دیگر استفاده کرد.
تابعی که به عنوان مقدار پارامتر به تابع دیگری پاس داده می‌شود، «تابع درجه اول» نامیده می‌شود.
تابعی که یک یا چند تابع را به عنوان پارامتر می‌گیرد، یا تابعی بازمی‌گرداند، «تابع مرتبه بالاتر» نامیده می‌شود.

در مثال زیر، `is_even` و `is_odd` توابع درجه اول هستند.
تابع مرتبه بالاتر `test_number` است.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
امضای تابع `bool (*func) (int)` برای آرگومان اول `test_number` با امضای توابعی که پاس داده شده‌اند مطابقت دارد.
هم `is_even` و هم `is_odd` یک پارامتر `int` می‌گیرند و یک `bool` برمی‌گردانند.
در `(*func)`، `func` اسم تابعی را نشان می‌دهد که باید استفاده شود.
اگر `(*fn)` استفاده می‌شد، آنگاه به این شکل فراخوانی می‌شد: `printf(text, number, fn(number)? "true": "false");`.
برای برآورده کردن پارامتر از نوع اشاره‌گر تابع، وقتی `test_number` را فراخوانی می‌کنیم، اسم تابعی را پاس می‌دهیم که امضای مورد انتظار را دارد.
بنابراین می‌بینیم که اسم یک تابع به آدرس همان تابع اشاره می‌کند.
