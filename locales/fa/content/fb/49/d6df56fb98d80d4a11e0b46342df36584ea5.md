# درباره

دستور `guard` در Swift برای بازگشت زودهنگام از توابع Swift به کار می‌رود؛ آن هم وقتی شرط ضروری‌ای که برای ادامه‌ی پردازش باید برآورده شود، برآورده نشده باشد. برای مثال:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

در اینجا، `guard` بررسی می‌کند که آیا عبارت منطقی پس از کلیدواژه‌ی `guard` برابر با «درست» ارزیابی می‌شود یا نه. اگر چنین باشد، پردازش با کدی ادامه می‌یابد که پس از دستور guard می‌آید (در اینجا `let root = myValue.squareRoot()`). در غیر این صورت، کد موجود در بخش else اجرا می‌شود. برخلاف دستور `if`، دستور `guard` _باید_ یک بخش else داشته باشد، و برخلاف بخش else در if-else، بخش else در guard _باید_ از حوزه‌ی دستور guard خارج شود. یعنی باید از یک دستور انتقال کنترل مانند `return`، `continue` یا `break` استفاده کند، یا خطایی پرتاب کند یا برنامه را خاتمه دهد.

یک نمونه از کاربرد آن، تابع sinc است که برابر با sin(x)/x است و در آن sinc(0) برابر با ۱ تعریف شده تا از مشکلات تقسیم بر صفر جلوگیری شود. این تابع را می‌توان در Swift و با استفاده از `guard` چنین نوشت:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
