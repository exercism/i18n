# دستورالعمل‌ها

یک‌دفعه هوس پنکیک کرده‌اید.
به عنوان یک آدم مدرن و اهل فناوری، فهرست خرید مواد اولیه‌ی پنکیک را در قالب JSON می‌نویسید.
ساختار این فهرست چنین است:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

هر ماده‌ی اولیه به شکل یک شیء JSON نمایش داده می‌شود، مانند:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

هر ماده‌ی اولیه یک ویژگی اختیاری به اسم `"substitute"` دارد که رشته‌ای از نام ماده‌ای دیگر را نگه می‌دارد تا بتوان به‌جای آن از آن استفاده کرد.

بیایید ببینیم چطور می‌توانیم فهرست خرید را با `jq` بررسی کنیم

## 1. استخراج اسم فهرست خرید

عبارتی بنویسید که عنصر "name" فهرست خرید را خروجی بدهد.

## 2. شمارش تعداد مواد اولیه‌ی لازم

فقط مواد اولیه‌ی "required" را بشمارید. مواد اولیه‌ی اختیاری را حساب نکنید.

## 3. چقدر شکر؟

عبارتی بنویسید که مقدار شکر را خروجی بدهد.
فقط بخش عددی مورد نظر است.

## 4. نگاشت مواد اولیه‌ای که می‌توان جایگزین کرد

برخی از مواد اولیه را می‌توان جایگزین کرد (اگر ماده‌ی اولیه‌ی X را ندارید، می‌توانید از Y استفاده کنید).
یک شیء JSON خروجی بدهید که ماده‌ی اولیه‌ی پیشنهادی را به جایگزینش نگاشت می‌کند.
مواد اولیه‌ی اختیاری را هم در این نگاشت بگنجانید.
