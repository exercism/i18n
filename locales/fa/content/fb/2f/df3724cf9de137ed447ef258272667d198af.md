# تابع کمکی خصوصی

[comment]: # (به ۲ پارامتر نیاز دارد:)
[comment]: # (- expected: تعریف اصلاح‌شده‌ی تابع)
[comment]: # (- actual: تعریف نادرست تابعی که دانشجو استفاده کرده است)

رابط عمومی یک پایگاه کد را باید با دقت بررسی کرد، چون هر تابع عمومی هزینه‌های نگهداری بلندمدت را افزایش می‌دهد و بازآرایی را دشوارتر می‌کند.

در هر تمرین Exercism، رابط عمومی را مجموعه‌ی تست‌ها تعیین می‌کند.
اگر تابعی تست شود، باید عمومی باشد.
بقیه‌ی توابع باید خصوصی باشند، از جمله توابعی که اسم یکسان اما آریتی متفاوت دارند.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
توجه کنید که آرگومان‌های پیش‌فرض، آریتی یک تابع را تغییر می‌دهند.

وقتی کتابخانه‌ای می‌نویسید، اغلب لازم است توابع را برای استفاده میان ماژول‌ها عمومی کنید.
برای پنهان کردن چنین توابعی از مستندات، نویسندگان کتابخانه پیش از تعریف توابع `@doc false` را اضافه می‌کنند یا `@moduledoc false` را می‌آورند تا کل ماژول را پنهان کنند.
