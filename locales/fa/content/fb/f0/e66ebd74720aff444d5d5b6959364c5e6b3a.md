# پیوست دستورالعمل

## راهنمایی‌ها

این تمرین با داده‌های متنی کار می‌کند. به دلایل تاریخی، نوع `String` در Haskell با `[Char]`، یعنی فهرستی از نویسه‌ها، هم‌معناست. برای پردازش کارآمدتر داده‌های متنی، می‌توان از نوع `Text` استفاده کرد.

به‌عنوان یک افزودنی اختیاری به این تمرین، می‌توانید

- در Haskell درباره‌ی [انواع رشته](https://haskell-lang.org/tutorial/string-types) بخوانید.
- `- text` را به فهرست وابستگی‌هایتان در package.yaml اضافه کنید.
- `Data.Text` را به [روش زیر](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) وارد کنید:

        import qualified Data.Text as T
        import           Data.Text (Text)

- حالا می‌توانید مثلاً `transform :: Map Int Text -> Map Char Int` را بنویسید و به ترکیب‌کننده‌های `Data.Text` مثلاً با `T.toLower` ارجاع دهید.
- مستندات [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) را جست‌وجو کنید.

این بخش کاملاً اختیاری است.
