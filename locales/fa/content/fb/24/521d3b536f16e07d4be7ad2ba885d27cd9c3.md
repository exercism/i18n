# درباره

فیلتر کردن فرایندی است که در آن با کپی کردن همه‌ی عنصرها به‌جز برخی عنصرهای مشخص از دنباله‌ی اصلی، دنباله‌ای تازه ساخته می‌شود. انتخاب اینکه کدام عنصرها در دنباله‌ی تازه گنجانده شوند، می‌تواند با یک «تابع محمول» (تابعی که به یک مقدار «منطقی» ارزیابی می‌شود) یا با برابری با یک شیء مشخص انجام شود.

## حذف با محمول

`remove-if` تابعی است که یک تابع محمول و یک دنباله را به‌عنوان آرگومان می‌گیرد و دنباله‌ای برمی‌گرداند که تنها شامل عنصرهایی است که محمول برای آن‌ها مقدار «غلط» را ارزیابی کرده است. به عبارت دیگر، این تابع همه‌ی عنصرهای دنباله را که محمول برای آن‌ها «درست» ارزیابی می‌شود «حذف» می‌کند. با این حال، توجه کنید که این تابع دنباله‌ی اصلی را تغییر نمی‌دهد! در عوض، دنباله‌ای تازه بدون آن عنصرها برمی‌گرداند. اگر محمول برای همه‌ی مقادیر «درست» ارزیابی شده باشد، دنباله‌ی خالی برگردانده می‌شود.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## نگه داشتن عنصرها با محمول

تابعی به اسم `remove-if-not` وجود دارد که دقیقاً مثل `remove-if` است، با این تفاوت که عنصری را که محمول برای آن «درست» ارزیابی می‌شود *نگه می‌دارد*.

به‌عنوان یک جایگزین می‌توان از `complement` استفاده کرد تا یک محمول را به «معکوس» آن تبدیل کرد.

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## حذف یک عنصر مشخص

اگر بخواهید یک عنصر مشخص را از یک دنباله حذف کنید، می‌توانید از `remove` استفاده کنید که عنصر موردنظر برای حذف و یک دنباله را می‌گیرد. همه‌ی مقادیر دنباله که با عنصر موردنظر برای حذف برابر نیستند، برگردانده می‌شوند.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

تابعی که برای برابری به کار می‌رود را می‌توان با [پارامتر کلیدواژه][concept-keyword-parameters] `:test` مشخص کرد.

توجه کنید که `remove` را می‌توان با `remove-if` پیاده‌سازی کرد، به این ترتیب که محمولی بنویسید که برابری یک شیء با یک عنصر مشخص را بررسی کند.

## گزینه‌های فراوان

هر یک از این توابع [پارامترهای کلیدواژه][concept-keyword-parameters] دیگری هم می‌گیرد که به آن‌ها امکان می‌دهد فقط روی زیردنباله‌ها کار کنند، فقط تعداد مشخصی بار اعمال شوند و موارد دیگر. برای جزئیات کامل به [مستندات Hyperspec][hyperspec-remove] نگاه کنید.


## گزینه‌های مخرب

علاوه بر `remove`، `remove-if` و `remove-if-not`، توابع `delete`، `delete-if` و `delete-if-not` هم وجود دارند که اثر معادل دارند، با این تفاوت که ممکن است دنباله‌ای را که به آن‌ها داده شده است تغییر دهند.
