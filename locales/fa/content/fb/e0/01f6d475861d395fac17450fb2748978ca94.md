# مقدمه

در Swift نمی‌توانید با یک عدد صحیح (مثل `string[3]`) یک رشته را ایندکس کنید.
چون رشته‌های Swift از نویسه‌های یونیکد با طول متغیر ساخته شده‌اند، برای یافتن یک نویسه باید از نویسه‌های پیش از آن عبور کنید.

برای دسترسی به یک نویسه در موقعیت مشخص، باید یک ایندکس از نوع `String.Index` محاسبه کنید.
به این ایندکس‌ها «ایندکس‌های غیرشفاف» می‌گویند، چون ساختار درونی‌شان را Swift مدیریت می‌کند و مستقیماً به‌صورت عدد صحیح خام دست‌کاری نمی‌شوند:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
