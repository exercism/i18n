# دستورالعمل‌ها

در این تمرین، خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است که به این شکل قالب‌بندی شده است: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح مختلف لاگ وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

چند وظیفه دارید که هر کدام یک خط لاگ می‌گیرد و از شما می‌خواهد کاری با آن انجام دهید.

## 1. بازیابی رشته‌ی پس از یک زیررشته‌ی مشخص

با نگاهی به لاگ‌های ماه گذشته می‌بینید که پیام تست همیشه بعد از یک زیررشته‌ی مشخص قرار دارد. چون پیش‌بینی می‌کنید که در آینده‌ی نزدیک لازم شود پیام تست را استخراج کنید، تصمیم می‌گیرید یک متد کمکی بسازید که در این کار به شما کمک کند.

متد الحاقی `LogAnalysis.SubstringAfter()` (به‌صورت _static_) را پیاده‌سازی کنید که یک جداکننده‌ی رشته‌ای می‌گیرد و زیررشته‌ی بعد از جداکننده را برمی‌گرداند.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. بازیابی رشته‌ی بین دو زیررشته

با بررسی بیشتر می‌بینید که سطح لاگ همیشه بین کروشه‌ها (`[` و `]`) قرار دارد. چون همچنین پیش‌بینی می‌کنید که در آینده‌ی نزدیک لازم شود سطح لاگ را استخراج کنید، تصمیم می‌گیرید متد کمکی دیگری بسازید که در این کار به شما کمک کند.

متد الحاقی `LogAnalysis.SubstringBetween()` (به‌صورت _static_) را پیاده‌سازی کنید که دو جداکننده‌ی رشته‌ای می‌گیرد و زیررشته‌ای را برمی‌گرداند که بین آن دو جداکننده قرار دارد.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. تجزیه‌ی پیام یک لاگ

متد الحاقی `LogAnalysis.Message()` (به‌صورت _static_) را پیاده‌سازی کنید تا پیام موجود در یک لاگ را برگرداند.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. تجزیه‌ی سطح لاگ در یک لاگ

متد الحاقی `LogAnalysis.LogLevel()` (به‌صورت _static_) را پیاده‌سازی کنید تا سطح لاگ یک لاگ را برگرداند.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
