# تست در خط فرمان

تست‌ها را با این دستور اجرا کنید:

```bash
scarb cairo-test
```

همه‌ی تست‌ها به‌جز اولین تست نادیده گرفته شده‌اند. بعد از اینکه اولین تست را با موفقیت پاس کردید، فایل منبع تست‌ها را که در پوشه‌ی `tests` قرار دارد باز کنید و `#[ignore]` را از تست بعدی بردارید و دوباره تست‌ها را پاس کنید. هر تست جداگانه یک تابع است که `#[test]` بالای آن نوشته شده است. این کار را ادامه دهید تا همه‌ی تست‌ها را پاس کنید.

اگر می‌خواهید _همه‌ی_ تست‌ها را بدون ویرایش فایل منبع تست‌ها اجرا کنید، از این دستور استفاده کنید:

```bash
scarb cairo-test --include-ignored
```

برای اجرای یک تست مشخص، فارغ از اینکه نادیده گرفته شده باشد یا نه، مثلاً `some_test`، می‌توانید از این دستور استفاده کنید:

```bash
scarb cairo-test -f some_test
```

برای آشنایی بیشتر با تست‌های Cairo به [مستندات تست][cairo-tests] آنلاین مراجعه کنید.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
