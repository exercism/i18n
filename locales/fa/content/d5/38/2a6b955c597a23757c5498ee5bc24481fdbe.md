# درباره

زبان C زبانی با نوع‌بندی ایستا است، یعنی همه‌چیز در زمان کامپایل نوع دارد. انتخاب یک اسم برای یک [متغیر][variable] و تعیین نوع آن، اعلان متغیر نامیده می‌شود.

یک متغیر با تعیین صریح نوعش اعلان می‌شود. اسم متغیر [باید از قواعدی پیروی کند][name-rules]، مثلاً با یک حرف یا یک زیرخط شروع شود. برخی اسم‌ها را نمی‌توان به کار برد، چون [برای کلیدواژه‌ها][reserved-keywords] یا [شناسه‌های دیگر][reserved-identifiers] رزرو شده‌اند.

تعیین یا به‌روزرسانی متغیر با انتساب متغیر انجام می‌شود. تعیین مقدار، آن متغیر را تعریف می‌کند. تعریف متغیر را مقداردهی اولیه هم می‌نامند.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

مقدار یک متغیر را می‌توان با [عملگر انتساب سادهٔ `=`][assignment-operator] تعیین و به‌روزرسانی کرد. پس از تعریف، نوع متغیر هرگز تغییر نمی‌کند.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C یک زبان [دستوری][imperative] [رویه‌ای][procedural] است. همه‌ی محاسبات به‌صورت مجموعه‌ای از [دستورها][statements] انجام می‌شود که بخشی از یک [تابع][function] یا چندین تابع هستند.

هر تابع می‌تواند صفر یا چند [پارامتر][parameters] داشته باشد. هنگام تعریف یک تابع، نوع همه‌ی پارامترها و مقدار بازگشتی باید صریحاً مشخص شود. مقادیر با استفاده از [کلیدواژه‌ی `return`][return-keyword] از توابع بازگردانده می‌شوند. توابع به‌طور پیش‌فرض [کلاس ذخیره‌سازی][storage_class] خارجی دارند، یعنی در طول عمر برنامه وجود دارند و می‌توانند از بیرون فایل هم دیده شوند. برای جلوگیری از این، می‌توان کلیدواژه‌ی `static` را افزود تا دیدپذیری داخلی مشخص شود.

```c
static int add(int x, int y) {
  return x + y;
}
```

در مثال بالا، متغیرهای `x` و `y` فقط درون همان تابع قابل استفاده‌اند، یعنی دامنه‌ی تابعی دارند. [دامنه][scope] به این معناست که مقدار مرتبط با یک اسم (از یک عنصر برنامه) تنها درون «ناحیه‌ی» کدی که در آن تعریف شده قابل دسترسی است. ناحیه‌های اصلی کد در C عبارت‌اند از:

- فایل
- تابع
- بلوک (مثلاً درون حلقه‌ها و سایر ساختارها)

توابع با مشخص کردن اسم تابع و فرستادن آرگومان برای هر یک از پارامترهای تابع فراخوانی می‌شوند.

```c
int sum = add(1, 2);
```

C از دو نوع [کامنت][comments] پشتیبانی می‌کند. کامنت‌های تک‌خطی با `//` شروع می‌شوند (از C99 به بعد) و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.
