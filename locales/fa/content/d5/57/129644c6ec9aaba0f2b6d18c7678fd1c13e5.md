# دستورالعمل‌ها

در این تمرین روی یک برنامه‌ریز نوبت‌دهی برای یک سالن زیبایی در نیویورک کار می‌کنید که در ۱۵ سپتامبر ۲۰۱۲ افتتاح شد.

چهار وظیفه دارید که همه‌ی آن‌ها به تاریخ‌های نوبت مربوط می‌شوند. تاریخ‌ها و زمان‌ها از یکی از این سه قالب زیر استفاده می‌کنند:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
تست‌ها به‌طور خودکار فرهنگ را روی `en-US` تنظیم می‌کنند. لازم نیست خودتان فرهنگ را تنظیم یا مشخص کنید.
~~~~

## 1. تجزیه‌ی تاریخ نوبت

تابع `schedule` را پیاده‌سازی کنید که می‌تواند نمایش متنی یک تاریخ نوبت را به قالب متناظر `DateTime` تجزیه کند:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. بررسی اینکه نوبت قبلاً گذشته است

تابع `hasPassed` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و بررسی می‌کند آیا آن نوبت جایی در گذشته بوده است:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. بررسی اینکه نوبت در بعدازظهر است

تابع `isAfternoonAppointment` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و بررسی می‌کند آیا نوبت در بعدازظهر است (بزرگ‌تر یا مساوی ۱۲:۰۰ و کوچک‌تر از ۱۸:۰۰):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. توصیف زمان و تاریخ نوبت

تابع `description` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و توصیفی از آن تاریخ و زمان برمی‌گرداند:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. برگرداندن تاریخ سالگرد

تابع `anniversaryDate` را پیاده‌سازی کنید که تاریخ سالگرد امسال را برمی‌گرداند، یعنی ۱۵ سپتامبر:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
