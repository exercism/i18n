# مقدمه

ساختن یک نمونه از «کلاس» با فراخوانی «سازنده»ی آن از طریق عملگر `new` انجام می‌شود. سازنده نوع ویژه‌ای از متد است که هدفش مقداردهی اولیه به نمونه‌ای است که تازه ساخته شده. سازنده‌ها مثل متدهای معمولی به نظر می‌رسند، اما نوع بازگشتی ندارند و اسمشان با اسم کلاس یکسان است.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

مانند متدهای معمولی، سازنده‌ها می‌توانند پارامتر داشته باشند. پارامترهای سازنده معمولاً به‌صورت فیلدهای (خصوصی) ذخیره می‌شوند تا بعداً به آن‌ها دسترسی پیدا کرد، یا در یک محاسبه‌ی یک‌باره به کار می‌روند. آرگومان‌ها را می‌توان به سازنده‌ها پاس داد، درست مثل پاس دادن آرگومان به متدهای معمولی.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
