# روال مقید

تا اینجا همه‌چیز *مقدارها* را جابه‌جا می‌کرده است: عددها، رشته‌ها، شیءها. یک **«روال مقید»** به شما اجازه می‌دهد خودِ یک روال را جابه‌جا کنید، تا بعداً کدی که نمی‌داند آن چیست آن را فراخوانی کند.

جانشین دقیقاً همین ایده است: مدیر صحنه راهی برای بازی کردن نقش در دست دارد، بدون اینکه بداند او کیست یا چه کار خواهد کرد.

## ساختن یک روال مقید

`bind` یک فراخوانی با جاهای خالی می‌گیرد که با `_` نوشته می‌شود:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

`part` اکنون مقداری مثل هر مقدار دیگری است. فراخوانی آن بعداً انجام می‌شود:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## نوع

نوع یک روال مقید `ROUT` است، با نوع آرگومان‌ها داخل آکولاد و نوع بازگشتی بعد از دونقطه:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

`ROUT{STR}:STR` را این‌طور بخوانید: «روالی که یک `STR` می‌گیرد و یک `STR` پاسخ می‌دهد».

| نوشته | معنی |
| --- | --- |
| `ROUT{STR}:STR` | یک `STR` می‌گیرد، یک `STR` پاسخ می‌دهد |
| `ROUT{INT,INT}:BOOL` | دو `INT` می‌گیرد، یک `BOOL` پاسخ می‌دهد |
| `ROUT{STR}` | یک `STR` می‌گیرد، پاسخی نمی‌دهد |
| `ROUT:INT` | آرگومانی نمی‌گیرد، یک `INT` پاسخ می‌دهد |

چون یک نوع است، می‌تواند به‌عنوان آرگومان به کار رود:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse` هیچ ایده‌ای ندارد که `part` چه کار می‌کند. نکته همین است: می‌توان `shout` یا `whisper` یا هر روال دیگری با همان شکل را به آن سپرد.

## پر کردن برخی از آرگومان‌ها

لازم نیست هر آرگومان یک جای خالی باشد. هر موردی که نوشته شود، هنگام انجام `bind` ثابت می‌شود:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice` فقط خط را می‌گیرد، چون `2` از قبل تعیین شده است. مقدار در لحظه‌ی مقیدسازی محاسبه و نگه داشته می‌شود، بنابراین تغییر دادن متغیری که از آن آمده، بعداً هیچ تفاوتی ایجاد نمی‌کند.

این‌گونه است که یک روال کلی به روال‌های مشخص متعددی تبدیل می‌شود.

## مقید کردن شیء هم

برای یک روال روی یک شیء، شیء اولین مورد در فراخوانی است و می‌تواند ثابت شود یا به‌صورت یک جای خالی رها شود:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
