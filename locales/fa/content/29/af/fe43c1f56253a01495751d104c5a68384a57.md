# تکرار

در برنامه‌نویسی، [تکرار][iteration] به فرایند تکرار یک «بلوک کد» چندین بار اشاره دارد. این کار را می‌توان با استفاده از مفاهیمی مانند «حلقه‌های while» و «حلقه‌های until» انجام داد. همچنین می‌توان از «بازگشتی» استفاده کرد، که تابعی است که خودش را فراخوانی می‌کند.

اما بیشتر اوقات می‌خواهید روی مجموعه‌ای از عنصرها تکرار کنید، مانند `Array`، `Range` یا `String`. هر دو کلاس `Array` و `Range` در Crystal ماژول [`Enumerable`][enumerable] را شامل می‌شوند که روش‌های متعددی برای تکرار روی عنصرها فراهم می‌کند. در همین حال، کلاس `String` مجموعه‌ی روش‌های مخصوص خود را برای تکرار روی کاراکترها دارد.

Crystal همچنین هیچ دستور for مانند سایر زبان‌ها ندارد. در عوض، چندین روش دارد که می‌توان برای تکرار از آن‌ها استفاده کرد.

## تکرار کردن

رایج‌ترین روش برای تکرار روی یک مجموعه، استفاده از روش [`each`][each] است که هر عنصر مجموعه را به یک بلوک می‌دهد.
این کار را به‌راحتی می‌توان با یک `Range` انجام داد.
فرض کنید می‌خواهید بین ۱ و ۳ حلقه بزنید؛ می‌توانید از روش `each` برای تکرار روی آن استفاده کنید.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

و حتی ساده‌تر، اگر فقط می‌خواهید تعداد مشخصی بار تکرار کنید، می‌توانید از روش [`times`][times] استفاده کنید که روی کلاس `Int` وجود دارد.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## تکرار روی یک `String`

یک `String` دنباله‌ای از کاراکترهاست و به ماژول `Enumerable` تعلق ندارد؛ یعنی مجموعه‌ی روش‌های مخصوص خود را برای تکرار روی کاراکترها دارد.
رایج‌ترین روش برای تکرار روی یک `String` استفاده از روش [`each_char`][each_char] است که هر کاراکتر موجود در `String` را به یک بلوک می‌دهد.

~~~~exercism/note
روش `each_char` یک شیء `Char` را به بلوک می‌دهد، نه یک شیء `String`.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

روش دیگری برای تکرار روی یک `String` استفاده از روش [`each_line`][each_line] است.
این روش بیشتر هنگام خواندن یک فایل خط‌به‌خط استفاده می‌شود.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## تکرار روی شیئی که ماژول `Enumerable` را شامل می‌شود

ماژول [`Enumerable`][enumerable] روش‌های متعددی برای تکرار روی عنصرهای یک مجموعه فراهم می‌کند.
مجموعه‌هایی که ماژول `Enumerable` را شامل می‌شوند عبارت‌اند از `Array`، `Range`، `Hash`، `Set` و موارد دیگر؛ موارد بعدی در مفاهیم بعدی پوشش داده خواهند شد.

رایج‌ترین روش برای تکرار روی یک `Array` استفاده از روش [`each`][each] است که هر عنصر موجود در `Array` را به یک بلوک می‌دهد.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

روش [`map`][map] روش دیگری برای تکرار روی یک `Array` است؛ آرایه‌ی جدیدی برمی‌گرداند که نتیجه‌ی اعمال بلوک روی هر عنصر را در خود دارد.
این روش شبیه `each` است، اما یک `Array` جدید با عنصرهای تبدیل‌شده برمی‌گرداند.
تبدیل زمانی بسیار مفید است که بخواهید تابعی را روی هر عنصر مجموعه اعمال کنید، که عملیاتی رایج است.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

با یک کنترل جریان مانند `if` می‌توانید فیلتر کنید که کدام عنصرها تبدیل شوند.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### با ایندکس

گاهی لازم است ایندکس عنصری را که روی آن تکرار می‌کنید بدانید؛ برای این کار می‌توانید از روش [`each_with_index`][each_with_index] یا [`map_with_index`][map_with_index] استفاده کنید.
این روش هر عنصر و ایندکس آن را به یک بلوک می‌دهد و همچنین یک آرگومان اختیاری می‌پذیرد تا ایندکس شروع را مشخص کنید.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

توجه کنید که روش [`each_char_with_index`][each_char_with_index] نیز برای اشیاء `String` در دسترس است.

### sum

روش [`sum`][sum] مجموع همه‌ی عنصرهای مجموعه را برمی‌گرداند؛ همچنین یک بلوک اختیاری می‌پذیرد تا عنصرها را پیش از جمع کردن تبدیل کند و یک آرگومان اختیاری برای تعیین مقدار اولیه‌ی مجموع.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce] یا همان fold که در زبان‌های دیگر به این اسم شناخته می‌شود، روشی است که با یک روش ترکیب و یک مقدار اولیه، همه‌ی عنصرهای مجموعه را با هم ترکیب می‌کند.
روش `reduce` یک «انباره» دارد که به بلوک داده می‌شود؛ این انباره نتیجه‌ی تکرار قبلی است.
این فرایند به یک روند بازگشتی تبدیل می‌شود که همه‌ی عنصرهای مجموعه را با هم ترکیب می‌کند.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` ممکن است شبیه `sum` به نظر برسد، اما `reduce` انعطاف‌پذیرتر است، چون به شما اجازه می‌دهد مقدار اولیه‌ی انباره و روش ترکیب را مشخص کنید.
می‌توان از `reduce` برای پیاده‌سازی `sum`، `count` و روش‌های دیگر استفاده کرد.
