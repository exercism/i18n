# پیوست دستورالعمل‌ها

## نکته‌ها

شما باید تابع `convert` را پیاده‌سازی کنید که عددِ تبدیل‌شده به صدای قطره‌ی باران را برمی‌گرداند. اگر درباره‌ی نوع‌ها مطمئن نیستید، می‌توانید از امضای داده‌شده استفاده کنید، اما نگذارید خلاقیت شما را محدود کند:

```haskell
convert :: Int -> String
```

این تمرین با داده‌های متنی کار می‌کند. به دلایل تاریخی، نوع `String` در Haskell با `[Char]`، یعنی فهرستی از نویسه‌ها، هم‌معناست. برای پردازش کارآمدتر داده‌های متنی می‌توان از نوع `Text` استفاده کرد.

به عنوان یک گسترش اختیاری برای این تمرین، می‌توانید

- درباره‌ی [نوع‌های رشته](https://haskell-lang.org/tutorial/string-types) در Haskell بخوانید.
- `- text` را به فهرست وابستگی‌های خود در package.yaml اضافه کنید.
- `Data.Text` را به [روش زیر](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) وارد کنید:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- حالا می‌توانید مثلاً `convert :: Int -> Text` بنویسید و به ترکیب‌گرهای `Data.Text` مثلاً با `T.pack` ارجاع دهید.
- مستندات [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) را ببینید،
- سپس می‌توانید همه‌ی موارد `String` را در Raindrops.hs با `Text` جایگزین کنید:

```haskell
convert :: Int -> Text
```

این بخش کاملاً اختیاری است.
