# درباره

رشته‌های F# اشیائی تغییرناپذیرند که متن را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، نشانه‌های نگارشی و غیره) نمایش می‌دهند. برای تعریف یک نمونه از `string` از گیومه‌ی دوگانه استفاده می‌شود:

```fsharp
let fruit = "Apple"
```

برای دستکاری یک رشته می‌توانید یکی از [متدها][methods] یا [ویژگی‌ها][properties] آن را فراخوانی کنید، یا از یکی از توابع موجود در [`String` module][string-module] استفاده کنید. از آنجا که مقدار یک رشته هرگز پس از تعریف تغییر نمی‌کند، همه‌ی متدها و توابع دستکاری رشته یک رشته‌ی جدید برمی‌گردانند.

هر رشته با نویسه‌های گیومه‌ی دوگانه (`"`) محدود می‌شود. بعضی نویسه‌های خاص باید با نویسه‌ی بک‌اسلش (`\`) [اسکیپ شوند][escaping]. همچنین می‌توان پیش از رشته نماد ات (`@`) را قرار داد؛ این کار آن را به یک [رشته‌ی تحت‌اللفظی][verbatim] تبدیل می‌کند که هیچ نویسه‌ی اسکیپی را در نظر نمی‌گیرد.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

به شکل دیگری می‌توان رشته‌ها را با [گیومه‌های سه‌گانه][triple-quoted] (`"""`) تعریف کرد که امکان استفاده از گیومه‌ی دوگانه در رشته را بدون اسکیپ کردن آن فراهم می‌کند.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

در پایان، می‌توان رشته‌ها را با [عملگر `+`][plus-operator] به هم متصل کرد:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
