# مقدمه

مانند دیگر زبان‌ها، C++ هم دستور `switch` را ارائه می‌دهد. دستورهای `switch` روشی کوتاه‌تر برای نوشتن دستورهای طولانی `if ... else if` هستند. برای ساختن یک `switch`، ابتدا از «کلیدواژه»ی `switch` استفاده می‌کنیم و بعد از آن یک عدد صحیح می‌نویسیم. سپس هر یک از شرط‌ها را با کلیدواژه‌ی `case` اعلام می‌کنیم. همچنین می‌توانیم یک `case` به نام `default` اعلام کنیم که وقتی هیچ‌یک از شرط‌های `case` قبلی مطابقت نداشت اجرا می‌شود. هر `case` باید با یک دستور `break` (یا `return`) پایان یابد.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## ادامه‌ی اجرا در حالت‌های بعدی

یک نکته‌ی مهم درباره‌ی ساختار `switch` این است که کد تا وقتی با یک دستور `break` (یا `return`) متوقف نشود، به اجرا ادامه می‌دهد. این می‌تواند به رفتار غیرمنتظره‌ای منجر شود.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

کاربرد اصلی این ویژگی ادامه‌ی اجرا، دستوری است که چند برچسب دارد. چندین نتیجه‌ی `switch` می‌توانند به یک قطعه‌ی کد یکسان برای اجرا نگاشت شوند. به این ترتیب، برای مثال در یک اپلیکیشن رزرو، تابعی که برای اندازه‌های گروه ۲ و ۳ فراخوانی می‌شود می‌تواند یکی باشد:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
