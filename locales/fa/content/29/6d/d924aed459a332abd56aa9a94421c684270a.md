# Tests

## Running Tests

برای اجرای تست‌ها، دستور زیر را اجرا کنید:

```bash
bats test-<exercise-slug>.bats
```

### bats با bash پیاده‌سازی شده است

فایل bats یک اسکریپت bash است، با چند تابع ویژه که دستور `bats` آن‌ها را تشخیص می‌دهد.
تست‌هایی می‌بینید که چنین شکلی دارند:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

آن نحوه‌ی نگارش `<<<` یک *Here String* در bash است.
رشته‌ی سمت راست را به ورودی استانداردِ برنامه‌ی سمت چپ می‌فرستد.
تقریباً معادل این است:

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## تست‌های غیرفعال

حل کردن یک تمرین یعنی کاری کنید که همه‌ی تست‌های آن پاس شوند.
به‌طور پیش‌فرض، وقتی تست‌ها را اجرا می‌کنید، فقط یک تست (اولین تست) اجرا می‌شود.
این کار عمدی است، چون به شما اجازه می‌دهد تمرکزتان را فقط روی پاس کردن همان یک تست بگذارید.
وقتی آن تست پاس شد، می‌توانید تست بعدی را با کامنت کردن یا حذف کردنِ

    [[ $BATS_RUN_SKIPPED == true ]] || skip

نشانه‌هایی که پیش از سایر تست‌ها آمده‌اند، فعال کنید.

## لغو غیرفعال بودن تست‌ها

برای اجرای همه‌ی تست‌ها، از جمله تست‌هایی که نشانه‌ی `skip` دارند، می‌توانید این دستور را اجرا کنید:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

یا می‌توانید این خط را کامنت کنید یا حذف کنید:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

از فایل تست.
