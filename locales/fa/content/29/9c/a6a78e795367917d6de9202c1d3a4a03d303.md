# مقدمه

## توضیح

علاوه بر انواع داده‌ی اولیه مثل `number` و `string`، یک نوع داده‌ی مهم دیگر هم در JavaScript وجود دارد که به آن `object` می‌گویند.
«شیءها» مجموعه‌هایی از جفت‌های کلید-مقدار هستند.
به همین دلیل، می‌توان از آن‌ها به همان شکلی استفاده کرد که از آنچه در زبان‌های دیگر معمولاً «نقشه» یا «دیکشنری» نامیده می‌شود.

در زبان‌های دیگر، معمولاً همه‌ی مقدارهای یک نقشه باید نوع داده‌ی یکسانی داشته باشند.
در JavaScript فقط نوع کلید محدود است: باید `string` باشد.
مقدارهای داخل یک شیء می‌توانند نوع‌های متفاوتی داشته باشند.
این مقدارها می‌توانند انواع اولیه مثل عدد باشند، اما می‌توانند آرایه، شیءهای دیگر یا حتی تابع هم باشند.
همین ویژگی شیءها را بسیار انعطاف‌پذیر می‌کند، تا جایی که در JavaScript به یکی از موجودیت‌های کلیدی [برنامه‌نویسی شیءگرا][oop] (OOP) تبدیل می‌شوند.

در ادامه، روی شیءها به عنوان مجموعه یا نقشه تمرکز می‌کنیم.
کاربردهای دیگر شیءها در مفاهیم دیگر بررسی می‌شوند، برای نمونه [کلاس][concept-classes].

## ساختن یک شیء

برای ساختن یک شیء از «آکولاد» استفاده می‌کنید.
می‌توانید چند مورد را هم مستقیم داخل آن بگذارید.
برای این کار، اول کلید را بنویسید، بعد از آن دونقطه و سپس مقدار را.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

کامای انتهایی بعد از آخرین مورد در JavaScript اختیاری است.

شاید برایتان سؤال پیش بیاید که چرا کلیدها داخل گیومه قرار نگرفته‌اند، هرچند قرار است رشته باشند.
این یک شکل کوتاه‌نویسی است.
اگر کلید از قواعد نام‌گذاری [شناسه][mdn-identifier] در JavaScript پیروی کند، می‌توانید گیومه‌ها را حذف کنید.
برای کلیدهایی که در اسمشان نویسه‌های خاص دارند، باید از همان نوشتار معمول رشته استفاده کنید.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## بازیابی یک مقدار

برای گرفتن مقدار یک کلید مشخص، دو راه وجود دارد: «نوشتار نقطه‌ای» و «نوشتار کروشه‌ای».

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

استفاده از نوشتار نقطه‌ای به شکل کوتاه، همان محدودیت حذف گیومه‌ها را دارد.
این روش فقط وقتی کار می‌کند که کلید از قواعد نام‌گذاری شناسه پیروی کند.

## افزودن یا تغییر یک مقدار

می‌توانید با عملگر انتساب `=` یک مقدار را اضافه یا تغییر دهید.
باز هم نوشتار نقطه‌ای و کروشه‌ای در دسترس هستند.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## حذف یک مورد

می‌توانید با کلیدواژه‌ی `delete` یک جفت کلید-مقدار را از یک شیء حذف کنید.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## بررسی وجود یک کلید

می‌توانید با متد `hasOwnProperty` بررسی کنید که آیا کلید خاصی در یک شیء وجود دارد یا نه.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## پیمایش یک شیء

یک «حلقه‌ی ویژه» به اسم `for...in` وجود دارد که روی همه‌ی کلیدهای یک شیء پیمایش می‌کند.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

برای جلوگیری از خطاهای ظریف، همیشه باید فرض کنید که حلقه‌ی `for...in` کلیدها را با ترتیب دلخواهی پیمایش می‌کند.
همچنین توجه داشته باشید که `for...in` [کلیدهای ارث‌بری‌شده][concept-inheritance] را هم در پیمایش خود لحاظ می‌کند.
