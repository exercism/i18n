# معرفی

## استثنا

استثنا در C# روشی ساختاریافته، یکنواخت و ایمن از نظر نوع برای مدیریت شرایط خطایی فراهم می‌کند که در زمان اجرا رخ می‌دهند. مدیریت درست استثنا و خطا، وقتی می‌خواهید از از کار افتادن برنامه جلوگیری کنید، اهمیت دارد.

در C#، نوع پایه‌ی همه‌ی استثناها کلاس `System.Exception` است. این کلاس ویژگی‌های مهمی مانند `Message` را در خود دارد که توضیحی قابل‌فهم برای انسان از دلیل پرتاب شدن استثنا را در بر می‌گیرد.

برای اعلام اینکه در بخش خاصی از کد باید خطایی وجود داشته باشد، باید یک شیء استثنای جدید ساخت و سپس آن را با استفاده از کلیدواژه‌ی `throw` پرتاب کرد:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

وقتی استثنایی پرتاب می‌شود، وظیفه‌ی زمان اجرا این است که قطعه‌ای از کد را بیابد که مسئول مدیریت آن استثناست. اگر مدیریت‌کننده‌ی مناسبی پیدا نشود، زمان اجرا علاوه بر متوقف کردن اجرای برنامه، پیام استثنای مدیریت‌نشده را نیز نمایش می‌دهد.

برای ساختن یک مدیریت‌کننده برای استثنا، C# از دستور try-catch استفاده می‌کند که از یک بلوک `try` و یک یا چند بند `catch` تشکیل شده است. بلوک `try` باید حاوی کدی باشد که ممکن است به پرتاب استثنا منجر شود و از آن محافظت کند. بندهای `catch` باید حاوی کدی باشند که رفتار برنامه را پس از رخ دادن خطا مدیریت می‌کند. توجه به این نکته مهم است که پس از بلوک `try`، ترتیب استثناها اهمیت دارد؛ زیرا وقتی چند استثنا فهرست می‌شوند، نخستین بند `catch` که مطابقت داشته باشد اجرا می‌شود.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
