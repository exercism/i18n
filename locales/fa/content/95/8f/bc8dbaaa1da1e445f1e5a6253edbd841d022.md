# درباره

تعریف یک مجموعه معمولاً یک جای‌نگهدار درون علامت‌های کوچک‌تر و بزرگ‌تر دارد که طبق قرارداد اغلب T نام دارد. به چنین مجموعه‌ای «نوع جنریک» می‌گویند. این کار به کسی که از مجموعه استفاده می‌کند اجازه می‌دهد تعیین کند چه نوع عنصرهایی در مجموعه ذخیره شود. در کد مثال بالا، لیستی از رشته‌ها را نمونه‌سازی می‌کنیم.

یک کلاس یا تابع با استفاده از ویژگی `@:generic` **جنریک** می‌شود. این باعث می‌شود کامپایلر کلاس یا تابع را به عنوان جنریک شناسایی کند:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
