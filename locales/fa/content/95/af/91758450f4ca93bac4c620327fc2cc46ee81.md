# راهنمایی

## کلی

- در راهنمای شروع به کار درباره‌ی [رشته‌های بیت][bitstring] بخوانید.
- مستندات [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] را مرور کنید.
- [نحوه‌ی تبدیل اعداد دهدهی به اعداد دودویی][decimal-to-binary-youtube] را مرور کنید.
- Elixir از [روش‌های مختلف نوشتن اعداد صحیح][integer-literal] پشتیبانی می‌کند، از جمله نمادگذاری دودویی.

## 1. محاسبه‌ی اندازه‌ی بیت پالت

- این کار از نوع داده‌ی رشته‌ی بیت استفاده نمی‌کند.
- کوچک‌ترین عدد مثبت `n` را پیدا کنید که ۲ به توان `n` بزرگ‌تر یا مساوی تعداد رنگ‌هایی باشد که باید نمایش دهیم.
- برای این کار یک تابع بازگشتی بسازید.
- اندازه‌ی بیت آغازین را ۱ انتخاب کنید. اگر ۲ به توان اندازه‌ی بیت بزرگ‌تر یا مساوی تعداد رنگ‌ها باشد، اندازه‌ی بیت مورد نظر را پیدا کرده‌ایم. اگر نه، ۱ را به اندازه‌ی بیت اضافه کنید و دوباره بررسی کنید (بازگشت).
- از [عملگر توان `**`][power-operator] استفاده کنید تا ۲ را به یک توان مشخص برسانید.

## 2. ساختن یک تصویر خالی

- از [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] استفاده کنید تا یک رشته‌ی بیت تازه بسازید.

## 3. ساختن یک تصویر آزمایشی

- از [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] استفاده کنید تا یک رشته‌ی بیت تازه بسازید.
- از [عملگر نوع][type-operator] استفاده کنید تا اندازه‌ی بیت هر قطعه را مشخص کنید.

## 4. افزودن یک پیکسل به ابتدای یک تصویر

- از [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] می‌توان استفاده کرد تا یک قطعه‌ی تازه به یک رشته‌ی بیت موجود اضافه شود.
- از [عملگر نوع][type-operator] استفاده کنید تا اندازه‌ی بیت قطعه‌ی تازه و همچنین رشته‌ی بیت موجود را مشخص کنید.
- از تابع `PaintByNumber.palette_bit_size/1` که پیش‌تر پیاده‌سازی کردید استفاده کنید تا اندازه‌ی بیت قطعه‌ی تازه را به دست آورید.
- از نوع ویژه‌ی `::bitstring` استفاده کنید تا مشخص کنید اندازه‌ی قطعه‌ی قدیمی نامعلوم است.

## 5. گرفتن اولین پیکسل از یک تصویر

- از [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] می‌توان استفاده کرد تا [روی رشته‌های بیت تطبیق الگو انجام شود][bitstring-matching].
- از تابع `PaintByNumber.palette_bit_size/1` که پیش‌تر پیاده‌سازی کردید استفاده کنید تا اندازه‌ی بیت یک پیکسل را به دست آورید.
- از نوع ویژه‌ی `::bitstring` استفاده کنید تا مشخص کنید اندازه‌ی بقیه‌ی رشته‌ی بیت نامعلوم است.

## 6. حذف اولین پیکسل از یک تصویر

- از [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] می‌توان استفاده کرد تا [روی رشته‌های بیت تطبیق الگو انجام شود][bitstring-matching].
- از تابع `PaintByNumber.palette_bit_size/1` که پیش‌تر پیاده‌سازی کردید استفاده کنید تا اندازه‌ی بیت یک پیکسل را به دست آورید.
- از نوع ویژه‌ی `::bitstring` استفاده کنید تا مشخص کنید اندازه‌ی بقیه‌ی رشته‌ی بیت نامعلوم است.

## 7. به هم چسباندن دو تصویر

- از [فرم ویژه‌ی رشته‌ی بیت][bitstring-form] می‌توان استفاده کرد تا دو رشته‌ی بیت را به هم بچسبانید.
- از نوع ویژه‌ی `::bitstring` استفاده کنید تا مشخص کنید اندازه‌ی هر یک از قطعه‌های رشته‌ی بیت نامعلوم است.
