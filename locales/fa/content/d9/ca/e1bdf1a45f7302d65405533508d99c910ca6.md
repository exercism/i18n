# مقدمه

یک «واژه‌ی جنریک» عملیاتی را تعریف می‌کند که بسته به کلاس آرگومانش می‌تواند پیاده‌سازی‌های متفاوتی داشته باشد. متدها با `M:` اضافه می‌شوند.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` واژه و اثر پشته‌ای آن را تعریف می‌کند. `M:` متدی را روی یک کلاس مشخص تعریف می‌کند؛ Factor در زمان اجرا بر اساس کلاس بالاترین آرگومان، متد مناسب را انتخاب می‌کند.

می‌توانید از جنریک بپرسید که برای کدام کلاس‌ها متد دارد و بعدها متد اضافه یا حذف کنید. نحوه‌ی نگارش خاصی برای وراثت وجود ندارد: هر کلاس تاپل به‌طور خودکار واجد شرایط است که متد روی آن تعریف شود.
