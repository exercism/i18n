# مقدمه

در PHP، می‌توان با گذاشتن پرانتز [`()`] بعد از یک متغیر، آن را مانند یک تابع فراخوانی کرد. وقتی PHP تلاش می‌کند تابع را فراخوانی کند، به دنبال تابعی با همان اسمِ مقدار متغیر می‌گردد.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
