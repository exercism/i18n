# مقدمه

در Go می‌توانید با استفاده از `for` و یک اندیس، روی یک `slice` پیمایش کنید، یا می‌توانید از `range` استفاده کنید. `range` همچنین به شما اجازه می‌دهد روی یک `map` هم پیمایش کنید.

هر تکرار دو مقدار برمی‌گرداند: اندیس/کلید و یک کپی از عنصر موجود در آن اندیس/کلید.

## پیمایش روی یک `slice`

خیلی ساده است: حلقه زدن روی یک `slice`، به همان ترتیبی که انتظار دارید.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## پیمایش روی یک `map`

پیمایش روی یک `map` مسئله‌ی تازه‌ای به وجود می‌آورد.
حالا ترتیب تصادفی است.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
ممکن است به نظر برسد که خروجی بالا نادرست است، چون انتظار می‌رود اولین جفت کلید/مقدار در اعلان `map`، یعنی `9 10`، اولین مورد چاپ‌شده باشد و نه آخری.
با این حال، `map`ها ذاتاً بی‌ترتیب هستند؛ جفت کلید/مقدار اول و آخری وجود ندارد.
به همین دلیل، وقتی روی ورودی‌های یک `map` پیمایش می‌کنید، ترتیبی که این ورودی‌ها بازدید می‌شوند تصادفی است و از هیچ الگوی مشخصی پیروی نمی‌کند.
یعنی خروجی بالا ممکن است، اما شاید با آنچه خودتان در صورت اجرای این کد می‌بینید متفاوت باشد.
برای آشنایی بیشتر با این موضوع، [مشخصات زبان Go: بند range](https://go.dev/ref/spec#RangeClause) را ببینید.
~~~~

## تکرار با حذف کلید یا مقدار

در Go، یک متغیر استفاده‌نشده هنگام ساخت خطا ایجاد می‌کند.
گاهی فقط به مقدار نیاز دارید، مثل مثال اول:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

می‌توانید `i` را با `_` جایگزین کنید تا به کامپایلر بگویید که ما از آن مقدار استفاده نمی‌کنیم:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

اگر می‌خواهید فقط اندیس را چاپ کنید، می‌توانید `x` را با `_` جایگزین کنید،
یا به‌سادگی اعلان را حذف کنید:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## انواع غیر از struct

پیش‌تر تعریف انواع struct را دیده‌اید.
همچنین می‌توانید انواع غیر از struct تعریف کنید که می‌توانید به‌عنوان نام مستعار برای اعلان یک نوع توکار به کار ببرید، و می‌توانید توابع گیرنده روی آن‌ها تعریف کنید تا به همان شیوه‌ی انواع struct گسترش‌شان دهید.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

همچنین می‌توانید انواع غیر از struct تعریف کنید که از آرایه‌ها و `map`ها تشکیل شده باشند.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
