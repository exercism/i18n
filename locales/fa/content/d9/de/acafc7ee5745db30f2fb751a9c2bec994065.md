# معرفی

## ثابت

ثابت‌ها در Gleam راهی برای گذاشتن اسم روی مقدارها هستند. آن‌ها با کلیدواژه‌ی `const` تعریف می‌شوند.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

وقتی ثابت‌های یک ماژول با کلیدواژه‌ی `pub` تعریف شوند، می‌توان از ماژول‌های دیگر به آن‌ها دسترسی داشت؛ در غیر این صورت، دسترسی به آن‌ها فقط از داخل همان ماژولی ممکن است که در آن تعریف شده‌اند.

## ترتیب

ماژول `gleam/order` در کتابخانه‌ی استاندارد Gleam شامل نوع `Order` است که برای مقایسه‌ی مقدارها به کار می‌رود.

تعریف `Order` به این شکل است:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

این نوع سه گونه دارد و هر گونه برای نشان دادن رابطه‌ی بین یک مقدار و مقداری دیگر به کار می‌رود:

- `Gt`: مقدار _بزرگ‌تر از_ مقدار دیگر است.
- `Eq`: مقدار _برابر با_ مقدار دیگر است.
- `Lt`: مقدار _کوچک‌تر از_ مقدار دیگر است.

اگر بتوان یک نوع داده را از نظر بزرگی مقایسه کرد، معمولاً ماژول یک تابع `compare` تعریف می‌کند که یک مقدار `Order` برمی‌گرداند. برای نمونه، `gleam/float` و `gleam/int` توابع `compare` را تعریف می‌کنند که به‌ترتیب روی `float`ها و `int`ها کار می‌کنند.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

توابع مرتب‌سازی مانند `list.sort` معمولاً تابعی می‌گیرند که یک مقدار `Order` برمی‌گرداند؛ به این ترتیب فراخوان می‌تواند تعیین کند که لیست چگونه باید مرتب شود.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
