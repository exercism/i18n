# دستورالعمل‌ها

شما یک کوکتل‌ساز حرفه‌ای هستید و نوشیدنی‌های خوشمزه‌ای برای مردم درست می‌کنید تا در شب‌گردی‌هایشان از آن‌ها لذت ببرند.
اما به این فکر افتادید که می‌توانید با نوشتن کمی کد کارتان را راحت‌تر کنید تا در شغلتان کمکتان کند.

## 1. تعیین کنید که آماده کردن یک سفارش چقدر طول می‌کشد

نوشیدنی‌های مختلف زمان آماده‌سازی متفاوتی دارند:

- `"beer"`، `"soda"` و `"water"` هر کدام ۰٫۵ دقیقه زمان می‌برند.
- `"shot"` ۱٫۰ دقیقه، `"mixed drink"` ۱٫۵ دقیقه،
- `"fancy drink"` ۲٫۵ دقیقه،
- `"frozen drink"` ۳٫۰ دقیقه.

تابع `timeToPrepare(drinks:)` را پیاده‌سازی کنید که آرگومان `drinks` را می‌گیرد؛ این آرگومان آرایه‌ای از رشته‌هاست که نوشیدنی‌های نیازمند آماده‌سازی را نشان می‌دهد.
تابع باید کل زمانی را برگرداند که آماده‌سازی همه‌ی نوشیدنی‌های داخل آرایه طول می‌کشد.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. ذخیره‌ی قاچ لایم خود را دوباره پر کنید

یکی از اولین کارهایی که هنگام شروع شیفت باید انجام دهید این است که مطمئن شوید سبد کوچک قاچ‌های لایمتان برای شیفت پیش رو پر است.
لایم‌ها اندازه‌های مختلفی دارند و هر اندازه تعداد متفاوتی قاچ می‌دهد؛ از یک لایم `"small"` ۶ قاچ، از یک لایم `"medium"` ۸ قاچ و از یک لایم `"large"` ۱۰ قاچ به دست می‌آید.

تا زمانی که هنوز به قاچ بیشتری نیاز دارید و هنوز لایم بیشتری برای بریدن دارید، اولین لایم را از آرایه بیرون بیاورید و تعداد مناسب قاچ را از مقداری که نیاز دارید کم کنید.
این کار را ادامه دهید تا دیگر به قاچ بیشتری نیاز نداشته باشید یا لایم‌هایتان تمام شود.

تابع `makeWedges(needed:limes:)` را پیاده‌سازی کنید که آرگومان‌های `needed` و `limes` را می‌گیرد؛ `needed` تعداد قاچ‌هایی را نگه می‌دارد که باید ببرید و `limes` آرایه‌ای از رشته‌هاست که اندازه‌های لایم‌های در دسترس برای بریدن را نشان می‌دهد.
تابع باید تعداد لایم‌هایی را که بریده‌اید برگرداند.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. شیفت خود را به پایان برسانید

تبریک! روز کاری طولانی‌تان تقریباً تمام شده و به‌زودی به خانه می‌روید تا روی اپلیکیشن جدیدتان کار کنید.
اما هنوز ردیفی از سفارش‌های نوشیدنی دارید که باید آماده کنید تا بتوانید سفارش‌ها را به شیفت بعدی تحویل دهید و بروید.

تا زمانی که هنوز در شیفتتان زمان باقی است، باید اولین سفارش در آرایه را آماده کنید و سپس همان سفارش را از آرایه حذف کنید.
سپس می‌توانید مدت زمانی را که آماده‌سازی آن سفارش طول کشید، بر اساس تابع `timeToPrepare(drinks:)`، از زمان باقی‌مانده‌ی شیفتتان کم کنید.

تابع `finishShift(minutesLeft:remainingOrders:)` را پیاده‌سازی کنید که تعداد دقیقه‌های باقی‌مانده از شیفتتان (که تضمین شده بزرگ‌تر از ۰ است) و یک آرایه‌ی غیرخالی از سفارش‌های نوشیدنی را می‌گیرد.
تابع باید آرایه‌ی سفارش‌هایی را برگرداند که تا پایان شیفتتان به آن‌ها نرسیده‌اید.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. سفارش‌های خاص را ردیابی کنید

برای اینکه مطمئن شوید آبجو و نوشابه تازه می‌مانند، باید سفارش‌های آن‌ها را همراه با زمان ثبت هر سفارش پیگیری کنید.

تابع `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)` را پیاده‌سازی کنید. این تابع وقتی فهرستی از سفارش‌ها و زمان‌ها را می‌گیرد، یک جفت تاپل اختیاری برمی‌گرداند که زمان اولین و آخرین سفارش آبجو و نوشابه و نیز تعداد کل سفارش‌های هر یک را در بر دارد، و اگر هیچ سفارشی برای آن نوشیدنی‌ها ثبت نشده باشد، `nil` برمی‌گرداند. لازم نیست نوشیدنی دیگری را ردیابی کنید.

تابع `orderTracker(orders:)` را پیاده‌سازی کنید که آرایه‌ای از تاپل‌ها را می‌گیرد؛ هر تاپل، نوشیدنی سفارش‌شده و زمان ثبت سفارش را نگه می‌دارد.
تابع باید تاپلی برگرداند که شامل زمان اولین و آخرین سفارش آبجو، تعداد کل سفارش‌های آبجو، زمان اولین و آخرین سفارش نوشابه و تعداد کل سفارش‌های نوشابه است.
این مقدار باید به صورت تاپلی با این قالب برگردانده شود: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
