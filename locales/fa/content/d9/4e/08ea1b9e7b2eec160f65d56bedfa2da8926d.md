# مقدمه

بردار یک آرایهی یکبعدی است.
بردارها ممکن است عناصری از انواع مختلف را در خود داشته باشند.

## ساختن بردار

بردارها را میتوان با تابع `vector` یا با استفاده از شکل خوانندهی آن `#()` ساخت.

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

چون آرایه هستند، میتوان آنها را با `make-array` هم ساخت:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## محمول بردار

برای بررسی اینکه یک شیء بردار است، کافی است از محمول `vectorp` استفاده کنید.

## دسترسی به عناصر

برای دسترسی به عناصر یک بردار از `aref` استفاده کنید؛ اندیسها از صفر شروع میشوند:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
