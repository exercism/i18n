# نصب

برای انجام تمرین‌ها به [Vim](http://www.vim.org) نیاز دارید:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [کد منبع](#source)

## macOS

سیستم‌عامل به‌طور پیش‌فرض همراه با Vim عرضه می‌شود، اما نسخه‌ی آن به‌شدت قدیمی است.

احتمالاً برای نصب نرم‌افزار از [MacPorts](https://www.macports.org) یا
[Homebrew](https://brew.sh) استفاده می‌کنید.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

اگر رابط گرافیکی می‌خواهید، به‌جای آن نگاهی به
[MacVim](https://macvim-dev.github.io/macvim) بیندازید.

## Ubuntu / Debian

یک Vim تمام‌عیار با پشتیبانی از رابط گرافیکی (`gvim`) نصب کنید:

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

با استفاده از [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

یا مستقیماً از [اینجا](http://www.vim.org/download.php#pc) دانلود و نصب کنید.

## کد منبع

اگر می‌خواهید آخرین نسخه‌ی Vim را خودتان کامپایل کنید، نگاهی به [مخزن رسمی
روی GitHub](https://github.com/vim/vim) بیندازید.
