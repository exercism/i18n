# درباره

## الحاق

برای الحاق محتوای فایل‌های دیگر، C++ از دستورالعمل `include` استفاده می‌کند.
این الحاق‌ها باید در بالای فایل نوشته شوند.
هنگام کامپایل، خطی که دستورالعمل در آن آمده، با محتوای فایل مربوطه جایگزین می‌شود.
فضای‌نام‌ها پس از الحاق، همان‌طور که در فایل اصلی بودند، حفظ می‌شوند.

## کتابخانه‌ی استاندارد

کتابخانه‌ی استاندارد توابع، الگوریتم‌ها و ساختارهای داده‌ی رایج بسیاری ارائه می‌دهد.
کتابخانه‌ی استاندارد از فضای‌نام `std` استفاده می‌کند.

یک نمونه، کتابخانه‌ی عددی C یعنی `cmath` است.
این کتابخانه عملیات ریاضی رایج بسیاری ارائه می‌دهد.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
کتابخانه‌های استاندارد با براکت‌های زاویه‌دار `<>` الحاق می‌شوند، نه با گیومه‌های دوتایی `"`.
تفاوت در محل جست‌وجوی کامپایلر برای فایل‌های مربوطه است.
در نسخه‌ی براکت زاویه‌دار، جست‌وجو در پروژه‌ی فعلی انجام نمی‌شود و مستقیماً از پوشه‌های الحاق سیستم آغاز می‌شود.
اگر بخواهید فایل‌های محلی را الحاق کنید، از گیومه‌ی دوتایی استفاده می‌کنید: `#include "myfile"`
~~~~
