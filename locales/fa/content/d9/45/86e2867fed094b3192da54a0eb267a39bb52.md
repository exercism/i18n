# راهنمایی‌ها

## 1. تعریف «نام مستعار نوع»

- [این صفحه][record-types] نشان می‌دهد چگونه برای یک «رکورد» نام مستعار نوع بسازید.

## 2. ساخت مربی یک تیم

- [این صفحه][create] نشان می‌دهد چگونه نمونه‌ای از یک رکورد بسازید.

## 3. ساخت آمار یک تیم

- [این صفحه][create] نشان می‌دهد چگونه نمونه‌ای از یک رکورد بسازید.

## 4. ساخت یک تیم

- [این صفحه][create] نشان می‌دهد چگونه نمونه‌ای از یک رکورد بسازید.

## 5. جایگزینی مربی

- [نحوه‌ی نگارش][update] ویژه‌ای وجود دارد که نسخه‌ای از یک رکورد را برمی‌گرداند، اما با یک یا چند فیلد که مقدار جدیدی دارند.

## 6. بررسی یکسان بودن تیم

- Elm از برابری ساختاری استفاده می‌کند؛ یعنی رکوردهایی که مقادیر یکسانی دارند با هم برابرند.

## 7. بررسی اینکه آیا باید از یک تیم طرفداری کنید

- بهترین راه برای اجرای منطق بر اساس مقدار تیم، استفاده از [تطبیق الگو][pattern-matching] است.
