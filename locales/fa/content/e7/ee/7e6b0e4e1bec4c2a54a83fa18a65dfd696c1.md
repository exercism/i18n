# مقدمه

در Julia سه «دستور شرطی» اصلی وجود دارد:

- «عبارت‌های `if`»
- «عملگر سه‌تایی»
- «ارزیابی اتصال کوتاه»

## عبارت‌های `if`

عبارت‌های `if` در Julia مشابه آن‌هایی هستند که در زبان‌های دیگر دیده می‌شوند:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

اگر «عبارت منطقی» پس از `if` به `true` ارزیابی شود، «بلوک کد» اول اجرا می‌شود و بلوک دوم نادیده گرفته می‌شود.
اگر عبارت منطقی پس از `if` به `false` ارزیابی شود، بلوک کد اول نادیده گرفته می‌شود و بلوک دوم اجرا می‌شود.
برنامه از اولین خط کد پس از «کلیدواژه‌ی `end`» به اجرا ادامه می‌دهد.

~~~~exercism/note
در Julia، کلیدواژه‌ی `end` پایان همه‌ی عبارت‌های بلوکی را نشان می‌دهد.
این نحوه‌ی نگارش ویژه‌ی عبارت‌های `if` یا تعریف توابع نیست.
~~~~

در مواردی که بلوک دوم کد فقط یک عبارت `if` دیگر باشد، `elseif` به ما امکان می‌دهد از تودرتوی عبارت‌های `if` درون بلوک پرهیز کنیم:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

اگر یک عبارت `if` فقط برای یکی از حالت‌ها نیاز به اجرای کد داشته باشد، نیازی به نوشتن شاخه‌ی `else` نیست.

## عملگر سه‌تایی

دستورهای ساده‌ی `if-else` را می‌توان با عملگر سه‌تایی `a ? b : c` هم نوشت.
اگر `a` درست باشد، آنگاه `b` ارزیابی می‌شود.
در غیر این صورت `c` ارزیابی می‌شود.

برای مثال، تابع زیر

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

را می‌توان به این شکل هم نوشت:

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

این موضوع به‌ویژه زمانی مفید است که بخواهید بسته به یک شرط، مقدار متفاوتی را به یک متغیر نسبت دهید.
`x = a ? b : c` اگر `a` برابر `true` باشد، `b` را به `x` نسبت می‌دهد و در غیر این صورت `c` را به `x` نسبت می‌دهد.
برای مثال:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## ارزیابی اتصال کوتاه

اگر چند عبارت منطقی با عملگرهای `&&` و `||` به هم زنجیر شوند، Julia تنها کمترین تعداد عبارتی را ارزیابی می‌کند که برای تعیین مقدار کل زنجیره لازم است.

برای نمونه، زنجیره‌ی عبارت `n > 0 && k > 10` را در نظر بگیرید.
اگر `n` برابر `5` باشد، بخش اول زنجیره، یعنی `n > 0`، برابر `true` است و برای تعیین اینکه کل عبارت `true` است باید عبارت دوم، `k > 10`، ارزیابی شود.
اما اگر `n` برابر `-5` باشد، می‌دانیم که کل زنجیره **نمی‌تواند** `true` باشد، چون عبارت اولش `false` است.

اگر به جای آن `n > 0 || k > 10` را در نظر بگیریم، عکس این اتفاق می‌افتد.
اگر `n` برابر `5` باشد، بخش اول زنجیره، `n > 0`، برابر `true` است و می‌دانیم که کل زنجیره بدون توجه به عبارت دوم `true` خواهد بود.
اما اگر `n` برابر `-5` باشد، ارزیابی عبارت دوم لازم است.

می‌توان از این رفتار برای نوشتن دستورهای `if` بسیار کوتاه استفاده کرد:

```julia
if a
    b
end
```

معادل این است:

```julia
a && b
```

آخرین عبارت در زنجیره‌ای از `&&` و `||` لازم نیست یک عبارت منطقی باشد.
اغلب می‌بینید که از این ویژگی برای خطاها یا بازگشت‌های زودهنگام استفاده می‌شود.
برای مثال، با استفاده از تابع `dessert(fruit)` که در بالا دیدیم:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
