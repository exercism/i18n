# مقدمه

## تطبیق الگو روی لیترال

عبارت‌های `if/else` را می‌توان برای اجرای منطق شرطی به کار برد، اما Haskell روش قدرتمندتری هم برای اجرای منطق شرطی دارد: [«تطبیق الگو»][pattern-matching].
با تطبیق الگو می‌توان یک مقدار را در برابر یک یا چند «الگو» آزمود.
نمونه‌ای از چنین الگویی، «الگوی ثابت» است که یک مقدار را با یک مقدار ثابت (مثلاً `1` یا `"hello"`) تطبیق می‌دهد.

هنگام تعریف توابع می‌توانید برای الگوهای مختلف، بدنه‌های تابع جداگانه تعریف کنید.
این کار به کدی تمیز، ساده و خوانا می‌انجامد.
می‌توانید روی هر نوع داده‌ای تطبیق الگو انجام دهید: اعداد، کاراکترها، لیست‌ها، تاپل‌ها و غیره.

برای مثال، تابعی ساده که یک عدد صحیح (`Int`) می‌گیرد و آن را _۱_ واحد به _۰_ نزدیک‌تر می‌کند، می‌تواند این‌گونه بیان شود:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

تطبیق الگو زمانی بهتر جلوه می‌کند که همراه با الگوهای دیگر به کار رود؛ برای نمونه «الگوی متغیر»:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

مثال بالا همه‌ی ورودی‌های جز _۰_ را یکسان در نظر می‌گیرد و برای اعداد منفی نتیجه‌ی نادرست تولید می‌کند.
این مشکل را می‌توان با الگوهای شرطی، معروف به «گارد»، حل کرد که با نماد `|` بیان می‌شوند:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

در مثال‌های بالا، همه‌ی ورودی‌های ممکن الگوی متناظر ندارند.
کامپایلر این را تشخیص می‌دهد و یک هشدار صادر می‌کند.
این یکی از ویژگی‌های بسیار مفید Haskell است که کمک می‌کند همه‌ی مسیرهای ممکن پوشش داده شوند تا از بروز خطاهای زمان اجرا جلوگیری شود.
به این کار «بررسی جامع» می‌گویند.
برای رفع این هشدار، باید همه‌ی حالت‌ها را پوشش دهید.
درون گاردها می‌توانید از عبارت `otherwise` به‌عنوان شکر نحوی برای `True` استفاده کنید تا همه‌ی الگوهای باقی‌مانده را هم در بر بگیرید.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

تطبیق الگو یک مقدار را از بالا به پایین در برابر هر الگو می‌آزماید، تا الگویی متناظر را پیدا کند و منطق مربوط به آن الگو را اجرا کند.
**ترتیب الگوها مهم است!**
