# درباره

خصیصه‌ی `Flags` این امکان را می‌دهد که مقادیر تعریف‌شده در یک «اتحادیه‌ی تفکیک‌شده» به‌صورت موقعیت‌های بیت (یعنی «پرچم») نمایش داده شوند.
وقتی این مقادیر به شکل پرچم در نظر گرفته می‌شوند، می‌توان آن‌ها را با هم ترکیب کرد و به این ترتیب چندین شرط «منطقی» را در یک مقدار واحد نمایش داد.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

برای تنظیم یک پرچم می‌توان از عملگر OR بیتی (`|||`) استفاده کرد؛ برای لغو یک پرچم هم می‌توان عملگر AND بیتی (`&&&`) را با عملگر نقیض بیتی (`~~~`) ترکیب کرد.
بررسی وضعیت یک پرچم را نیز می‌توان با عملگر AND بیتی انجام داد، اما می‌توان از متد `HasFlag()` هم استفاده کرد.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

فهرست کامل عملگرهای بیتی موجود در زبان F# را در [خلاصه‌ی عملگرهای بیتی][bitwise-operators] ببینید.

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
