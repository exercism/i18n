# دستورالعمل‌ها

در این تمرین قرار است کد بیشتری بنویسید تا به شما کمک کند لازانیای بی‌نظیرتان را از کتاب آشپزی محبوبتان بپزید.

پنج کار در پیش دارید که همه به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. امکان تغییر زمان مورد انتظار در فر

می‌خواهید نسخه‌ی بهبودیافته‌ای از تابع `remainingMinutesInOven` بنویسید که تعداد دقیقه‌های سپری‌شده از حضور لازانیا در فر را به عنوان پارامتر می‌گیرد و بر اساس زمان مورد انتظار پخت در فر (به دقیقه) از تمرین قبلی برمی‌گرداند که لازانیا باید چند دقیقه‌ی دیگر در فر بماند.
پیش‌تر به یک مقدار ثابت به نام `expectedMinutesInOven` تکیه کرده بودید که از بیرون تابع `remainingMinutesInOven` می‌آمد.
این کار هم به سلیقه‌ی شما کمی شلوغ بود و هم به‌اندازه‌ی کافی انعطاف نداشت، چون اجازه نمی‌داد زمان مورد انتظار در فر را تغییر دهید.

برای مرتب کردن اوضاع، تابع `remainingMinutesInOven` را تعریف کنید که تعداد دقیقه‌های سپری‌شده از حضور لازانیا در فر را به عنوان پارامتر می‌گیرد، و همچنین پارامتری به نام `expectedMinutesInOven` که مقدار پیش‌فرضش ۴۰ است.
تابع شما باید بر اساس زمان مورد انتظار پخت در فر (به دقیقه) از تمرین قبلی برگرداند که لازانیا باید چند دقیقه‌ی دیگر در فر بماند.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. امکان تعداد متفاوت لایه‌ها

پیش‌تر تابعی به نام `preparationTimeInMinutes` نوشته بودید که تعداد لایه‌هایی را که به لازانیا اضافه کرده‌اید به عنوان پارامتر می‌گیرد و برمی‌گرداند که چند دقیقه صرف آماده کردن لازانیا کرده‌اید، با این فرض که آماده کردن هر لایه ۲ دقیقه طول می‌کشد.
اما چندان از این تابع راضی نیستید، چون باید پیش از فراخوانی آن، خودتان تعداد لایه‌های لازانیایتان را بشمارید، و چه کسی وقت این کارها را دارد؟

برای اینکه کار را برای خودتان راحت‌تر کنید، تابعی به نام `preparationTimeInMinutes` بنویسید که پارامتری متغیر از نوع `String` به نام `layers` می‌گیرد و در آن لایه‌های مختلف لازانیایتان را فهرست می‌کنید.
سپس تابع تعداد لایه‌های لازانیایتان را می‌شمارد و مقدار زمان آماده‌سازی مورد نیاز را برمی‌گرداند.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. محاسبه‌ی مقدار رشته و سس

پیش از آنکه شروع به چیدن لازانیا کنید، می‌خواهید مطمئن شوید سس و رشته‌ی کافی برای ساختن لازانیای رؤیایی‌تان دارید.
برای هر لایه‌ی رشته در لازانیایتان، به ۳ رشته نیاز دارید.
برای هر لایه‌ی سس در لازانیایتان، به ۰٫۲ لیتر سس نیاز دارید.

تابع `quantities` را تعریف کنید که پارامتری متغیر از نوع `String` به نام `layers` می‌گیرد و در آن لایه‌های مختلف لازانیایتان را فهرست می‌کنید.
سپس تابع مقدار رشته و سس لازم برای درست کردن غذایتان را تعیین می‌کند. نتیجه باید در یک تاپل از نوع `(noodles: Int, sauce: Double)` برگردانده شود.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. تبدیل لیتر به اونس مایع به‌صورت درجا

متأسفانه حجم سسی که در دسترس دارید، به‌جای لیتر بر حسب اونس مایع نوشته شده است.
برای اینکه بدانید سس کافی در دسترس دارید یا نه، تابعی به نام `toOz` بنویسید که پارامتری تاپلی و درجایی از نوع `(noodles: Int, sauce: Double)` می‌گیرد و مقدار سس را به اونس مایع تبدیل می‌کند.
در نظر داشته باشید که هر لیتر ۳۳٫۸۱۴ اونس مایع است.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. تعیین بهترین شرابی که باید سرو شود

در نهایت، می‌خواهید بدانید چه نوع شرابی را باید همراه لازانیا سرو کنید.
شنیده‌اید که اگر مقدار موزارلا، ریکوتا و بشامل در لازانیا بیشتر از مقدار گوشت و سس باشد، باید شراب سفید سرو کنید و در غیر این صورت شراب قرمز.
تابعی به نام `redWine` بنویسید که پارامتری متغیر از نوع `String` به نام `layers` می‌گیرد و در آن لایه‌های مختلف لازانیایتان را فهرست می‌کنید.
این تابع از پنج تابع تودرتو استفاده می‌کند تا تعداد لایه‌های موزارلا، ریکوتا، بشامل، سس و گوشت را در لازانیا تعیین کند و با مقایسه‌ی تعداد لایه‌ها مشخص کند که آیا باید شراب قرمز سرو شود یا نه، و اگر آری `true` و در غیر این صورت `false` را برمی‌گرداند.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
