# دستورالعمل‌ها

شما در حال پیاده‌سازی یک بازی نقش‌آفرینی هستید.
شخصیت بازیکن با ساختار زیر نمایش داده می‌شود:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

بازیکن‌های این بازی باید به سطح ۱۰ برسند تا استخر مانا را باز کنند و بتوانند از آن برای اجرای طلسم استفاده کنند.
پیش از آن، مانای بازیکن `Option::None` است.

شما روی دو بخش از قابلیت‌های این بازی کار می‌کنید: سازوکار احیا و سازوکار اجرای طلسم.

متد `revive` باید بررسی کند که بازیکن واقعاً مرده است (سلامتش به ۰ رسیده باشد) و اگر چنین باشد، متد باید یک نمونه‌ی جدید از بازیکن با ۱۰۰ سلامت برگرداند.
متد `revive` باید سطح بازیکن را حفظ کند.
اگر سطح بازیکن ۱۰ یا بیشتر باشد، باید با ۱۰۰ مانا احیا شود.
اگر سطح بازیکن کمتر از ۱۰ باشد، مانای او باید `Option::None` باشد.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

اگر متد `revive` روی بازیکنی فراخوانی شود که سلامت او ۱ یا بیشتر است، متد باید `Option::None` برگرداند.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

متد `cast_spell` یک ارجاع تغییرپذیر به بازیکن و همچنین پارامتر `mana_cost` را می‌گیرد که نشان می‌دهد طلسم چقدر مانا هزینه دارد.
این متد مقدار آسیبی را که طلسم اجراشده وارد می‌کند برمی‌گرداند.

- اگر بازیکن به استخر مانا دسترسی نداشته باشد، تلاش برای اجرای طلسم باید سلامت او را به اندازه‌ی هزینه‌ی مانای طلسم کاهش دهد.
  آسیب برگردانده‌شده باید ۰ باشد.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- اگر بازیکن استخر مانا دارد اما مانای کافی ندارد، متد نباید روی استخر تأثیری بگذارد.
آسیب برگردانده‌شده باید ۰ باشد.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- در غیر این صورت، طلسم با موفقیت اجرا می‌شود.
  مقدار `mana_cost` باید از استخر مانای بازیکن کسر شود.
  آسیب برگردانده‌شده باید دو برابر هزینه‌ی مانای طلسم باشد.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```
