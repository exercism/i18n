# پیوست دستورالعمل‌ها

## راهنمایی‌ها

برای اینکه آزمون را پاس کنید، باید چند نوع بسازید تا کدتان روی آن‌ها کار کند. به یک شیء برای `School` نیاز دارید که دنباله‌ای از نوع `Student` را در خود نگه دارد؛ این نوع یک تاپل از `string` و `int` است که اسم و پایه‌ی دانش‌آموزان را نگه می‌دارد.

در ادامه کدی برای این نوع‌ها آمده است که می‌تواند هنگام شروع کار مفید باشد.

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
