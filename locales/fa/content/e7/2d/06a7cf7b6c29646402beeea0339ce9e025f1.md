# صادرات نام‌دار وجود ندارد

هیچ [صادرات](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)ی با اسم `%{export.name}` پیدا نشد. تست‌ها بدون آن پاس نمی‌شوند.

مطمئن شوید `%{export.name}` وجود دارد و `export` را جلوی آن اضافه کنید:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
