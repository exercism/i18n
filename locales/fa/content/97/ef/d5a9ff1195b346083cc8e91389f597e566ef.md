## ابزارهای تعاملی jq

ورودی‌ای وارد کنید و فیلترهای مختلف jq را آزمایش کنید تا ببینید چه نتیجه‌ای به دست می‌آید.

- [زمین بازی jq][jqplay]، تجربه‌ای برای «آنلاین امتحان کردن».
- [ijq][ijq]، ابزار تعاملی jq، چیزی شبیه jqplay برای خط فرمان.
- [jqp][jqp] ابزار خط فرمان دیگری است؛ این ابزار از gojq به عنوان backend استفاده می‌کند که ۱۰۰٪ با jq اصلی سازگار نیست.

## ابزارهای دیگر پردازش JSON

- [gron][gron]: JSON را به دنباله‌ای از تخصیص‌های جداگانه «تخت» می‌کند، که این امکان را فراهم می‌آورد تا از ابزارهای خط‌محور (grep و غیره) برای پردازش آن استفاده شود.
- [jo][jo]: ابزار کوچکی برای ساختن شیءهای JSON از متغیرهای پوسته.
- [jello][jello]: jello شبیه jq است، با این تفاوت که از نحوه‌ی نگارش استاندارد dict و list در python استفاده می‌کند.
