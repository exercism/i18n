# پیوست دستورالعمل‌ها

## اطلاعات مخصوص Arturo

در این تمرین، انتظار می‌رود سن‌ها را با یک [کمیت فیزیکی][physical-quantities] برگردانید که یکای سفارشی آن، طول یک سال را در آن سیاره نشان می‌دهد.
در Arturo، یک کمیت از یک مقدار عددی و یک [یکای اندازه‌گیری][unit-of-measurement] مرتبط تشکیل می‌شود.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
یکای `yr توکار Arturo معادل ۳۱۵۵۶۹۵۲ ثانیه است.
بنابراین لازم است یکای سال خودتان را بر پایه‌ی همان تعداد ثانیه‌ای که پیش‌تر در دستورالعمل‌ها به آن اشاره شد تعریف کنید و از آن استفاده کنید.
~~~~

کمیت‌ها را می‌توان به یکای سازگار دیگری [تبدیل][convert] کرد.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
به دلیل محدودیت‌های دقت در اعداد اعشاری شناور، Arturo گاهی مقدار اسکالر را به‌صورت یک عدد گویا ذخیره می‌کند.
می‌توانید از [تابع `to`][to] استفاده کنید تا به‌جای آن، مقدار را به‌صورت یک عدد اعشاری شناور تقریبی به دست آورید.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo همچنین به ما اجازه می‌دهد تا یکاهای خودمان را برای کمیت‌ها [مشخص کنیم][specify].

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
