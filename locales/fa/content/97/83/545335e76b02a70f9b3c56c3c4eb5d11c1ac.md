# دستورالعمل‌ها

در این تمرین، قرار است کدی بنویسید که به شما در آماده شدن برای خرید یک خودرو کمک کند.

شما سه کار دارید: یکی برای تعیین اینکه آیا به گواهینامه نیاز دارید، یکی برای کمک به انتخاب بین دو خودرو و یکی برای تخمین قیمت مناسب یک خودروی دست‌دوم.

## 1. تعیین کنید که آیا به گواهینامه‌ی رانندگی نیاز دارید

برخی از انواع خودرو برای راندن به گواهینامه‌ی رانندگی نیاز دارند.
فرض کنید فقط انواع `"car"` و `"truck"` به گواهینامه نیاز دارند و هر مورد دیگری را می‌توان بدون گواهینامه راند.

تابع `needs_license(kind)` را پیاده‌سازی کنید که نوع خودرو را به‌صورت یک رشته می‌گیرد و یک «مقدار منطقی» برمی‌گرداند که نشان می‌دهد آیا برای آن نوع خودرو به گواهینامه نیاز دارید یا نه.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. انتخاب بین دو خودروی بالقوه برای خرید

شما گزینه‌های خودروهای موجود را بررسی می‌کنید.
موفق می‌شوید آن‌ها را به دو گزینه محدود کنید، اما برای گرفتن تصمیم نهایی به کمک نیاز دارید.
برای این کار، تابع `choose_vehicle(option1, option2)` را پیاده‌سازی کنید که دو خودرو را به‌عنوان آرگومان می‌گیرد و تصمیمی برمی‌گرداند که شامل گزینه‌ای است که به ترتیب لغوی اول می‌آید.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

رشته‌ی برگردانده‌شده باید از الگوی «<CHOSEN_VEHICLE> is clearly the better choice.» پیروی کند، که در آن `<CHOSEN_VEHICLE>` گزینه‌ای است که از میان آرگومان‌های داده‌شده انتخاب شده است.

## 3. محاسبه‌ی تخمینی از قیمت یک خودروی دست‌دوم

حالا که تصمیم خود را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی قیمت منصفانه‌ای می‌پردازید.
از آنجا که می‌خواهید یک خودروی دست‌دوم بخرید، قیمت به سن خودرو بستگی دارد.
برای تخمینی تقریبی، فرض کنید اگر خودرو کمتر از ۳ سال سن داشته باشد، قیمتش ۸۰٪ قیمت اصلی آن هنگام نو بودن است.
اگر حداقل ۱۰ سال سن داشته باشد، ۵۰٪.
اگر خودرو حداقل ۳ سال سن داشته باشد اما کمتر از ۱۰ سال، ۷۰٪ قیمت اصلی.

تابع `calculate_resell_price(original_price, age)` را پیاده‌سازی کنید که این منطق را با استفاده از `if`، `else if` و `else` اعمال می‌کند (اگر می‌خواهید تمرین کنید، راه‌های دیگری هم وجود دارد).
این تابع قیمت اصلی و سن خودرو را به‌عنوان آرگومان می‌گیرد و قیمت تخمینی در نمایندگی را برمی‌گرداند.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> نکته: مقدار برگردانده‌شده از نوع `double` است.
