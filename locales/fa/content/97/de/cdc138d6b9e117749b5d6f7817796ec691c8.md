# مقدمه

فراتر از «کلاس نویسه» و «کمیساز»، عبارات باقاعده می‌توانند *ساختار* و *بافت* را توصیف کنند. این قابلیت‌ها در همان واژگان [`regexp`][regexp] و همان مقدار ثابت `R/ /` جای می‌گیرند.

پرانتزها `( )` بخشی از یک «الگو» را گروه‌بندی می‌کنند تا یک «کمیساز» یا یک `|` («این یا آن») روی کل گروه اعمال شود؛ `?` پس از یک گروه آن را اختیاری می‌کند:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

«لنگر»ها یک الگو را به یک موقعیت مقید می‌کنند: `^` (شروع)، `$` (پایان) و `\b` (یک «مرز واژه»).

یک *پیرامون‌نگری* بر مبنای آنچه یک نقطه را در بر گرفته تطبیق می‌یابد، بدون آنکه آن نقطه را مصرف کند:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

یک حرف گزینه پس از `/` پایانی، کل الگو را تغییر می‌دهد؛ `i` آن را به بزرگی و کوچکی حروف غیرحساس می‌کند:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor به‌جای «گروه ثبت» از پیرامون‌نگری استفاده می‌کند: هیچ استخراج گروه ثبت، «بازارجاع» یا «کمیساز تنبل» ندارد.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
