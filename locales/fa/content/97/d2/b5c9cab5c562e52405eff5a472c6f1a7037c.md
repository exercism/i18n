# دستورالعمل‌ها

در این تمرین، مسابقه‌هایی بین انواع مختلف خودروهای کنترل از راه دور ترتیب می‌دهید.
هر خودرو سرعت و ویژگی‌های تخلیه‌ی باتری مخصوص به خود را دارد.

خودروها با باتری کاملاً پر (۱۰۰٪) شروع می‌کنند. هر بار که خودرو را با کنترل از راه دور می‌رانید، به اندازه‌ی سرعت خودرو متر جلو می‌رود و درصد باتری باقی‌مانده را به اندازه‌ی تخلیه‌ی باتری‌اش کاهش می‌دهد.

اگر باتری خودرو کمتر از درصد تخلیه‌ی باتری‌اش باشد، دیگر نمی‌توانید خودرو را برانید.

هر پیست مسابقه طول مخصوص به خود را دارد. خودروها با بررسی این که آیا می‌توانند بدون تمام شدن باتری پیست را تمام کنند آزمایش می‌شوند.

## 1. یک خودروی کنترل از راه دور بسازید

یک لیست `car` با عناصر زیر تعریف کنید:

- speed
- battery_drain
- battery
- distance_traveled

برای ساخت یک خودروی کنترل از راه دور، تابعی به اسم `new_car` تعریف کنید که سرعت خودرو بر حسب متر و درصد تخلیه‌ی باتری را به عنوان دو پارامترش می‌گیرد و یک لیست `car` برمی‌گرداند.

برای یک خودروی جدید، باتری روی ۱۰۰٪ است و مسافت پیموده‌شده صفر است.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. یک پیست مسابقه بسازید

لیست دیگری به اسم `track` با تنها عنصر `track_length` تعریف کنید.
برای ساخت یک پیست مسابقه، تابعی به اسم `new_track` تعریف کنید که فاصله‌ی پیست را بر حسب متر می‌گیرد:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. بررسی خالی شدن باتری

تابع `battery_drained()` را پیاده‌سازی کنید که نشان می‌دهد آیا باتری خالی شده است یا نه.
باتری زمانی خالی در نظر گرفته می‌شود که برای یک بار دیگر حرکت کافی نباشد.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. خودرو را برانید

تابع `drive` را پیاده‌سازی کنید که تعداد مترهای پیموده‌شده را بر اساس سرعت خودرو به‌روزرسانی می‌کند و باتری را مطابق با تخلیه‌ی باتری کاهش می‌دهد.
اگر باتری برای یک بار دیگر رانندگی کافی نباشد، خودرو حرکت نمی‌کند.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. بررسی این که آیا یک خودروی کنترل از راه دور می‌تواند مسابقه را تمام کند

برای تمام کردن یک مسابقه، خودرو باید بتواند طول مسابقه را رانندگی کند. این یعنی باتری‌اش را پیش از عبور از خط پایان تخلیه نکند.

تابع `can_finish` را پیاده‌سازی کنید که یک `car` و یک `track` را به عنوان پارامترش می‌گیرد و اگر خودرو بتواند مسابقه را تمام کند `TRUE` برمی‌گرداند؛ در غیر این صورت `FALSE` برمی‌گرداند.

فرض کنید همین حالا در خط شروع مسابقه هستید و موتور خودرو را برای مسابقه روشن می‌کنید. در نظر بگیرید که ممکن است باتری خودرو هنگام شروع مسابقه لزوماً کاملاً شارژ نباشد.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. ذخیره کنید که آیا خودرو می‌تواند یک پیست را با باتری پر تمام کند

شما چندین پیست با طول‌های مختلف ساخته‌اید و باید ذخیره کنید که آیا خودرویتان می‌تواند آن‌ها را در صورت شارژ کامل تمام کند یا نه.

تابع `store_track` را پیاده‌سازی کنید که یک خودرو، یک پیست و یک اسم پیست می‌گیرد و خودروی به‌روزشده‌ای با یک عنصر اضافه برمی‌گرداند.
این عنصر باید `name` پیست را داشته باشد و مقدارش باید یک زیرلیست باشد که `track_length` و این که آیا خودرو می‌تواند آن را `complete` کند در آن قرار دارد.

خودرویی که در آرگومان داده می‌شود ممکن است کاملاً شارژ نباشد، پس مطمئن شوید که پیش از استفاده از آن، باتری و مسافت پیموده‌شده را بازنشانی می‌کنید.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
