# مقدمه

## اعداد ممیز شناور

عدد ممیز شناور عددی است که صفر یا چند رقم پس از جداکننده‌ی اعشار دارد. نمونه‌ها عبارت‌اند از `-2.4`، `0.1`، `3.14`، `16.984025` و `1024.0`.

انواع مختلف ممیز شناور می‌توانند تعداد متفاوتی رقم را پس از جداکننده ذخیره کنند؛ به این ویژگی، دقت می‌گویند.

C# سه نوع ممیز شناور دارد:

- `float`: ۴ بایت (حدود ۶ تا ۹ رقم دقت). به‌صورت `2.45f` نوشته می‌شود.
- `double`: ۸ بایت (حدود ۱۵ تا ۱۷ رقم دقت). این رایج‌ترین نوع است. به‌صورت `2.45` یا `2.45d` نوشته می‌شود.
- `decimal`: ۱۶ بایت (۲۸ تا ۲۹ رقم دقت). معمولاً هنگام کار با داده‌های پولی استفاده می‌شود، چون دقت آن احتمال خطاهای گرد کردن را کاهش می‌دهد. به‌صورت `2.45m` نوشته می‌شود.

همان‌طور که می‌بینید، هر نوع می‌تواند تعداد متفاوتی رقم ذخیره کند. برای مثال، اگر عدد پی را در یک `float` ذخیره کنید، تنها ۶ رقم اعشار اول ذخیره می‌شود (و آخرین رقم ذخیره‌شده گرد می‌شود).

## حلقه‌ی While

در این تمرین ممکن است بخواهید از یک حلقه استفاده کنید. راه‌های مختلفی برای نوشتن حلقه در C# وجود دارد، اما حلقه‌ی `while` در اینجا مناسب‌تر است:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## حلقه‌ی Do While

اگر باید کد داخل حلقه دست‌کم یک بار اجرا شود، می‌توان از حلقه‌ی `do`/`while` استفاده کرد:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
