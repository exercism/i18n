# Debug

وقتی یک test شکست می‌خورد، پیامی نمایش داده می‌شود که توضیح می‌دهد چه اشکالی پیش آمده و برای کدام ورودی. همچنین می‌توانید از این موضوع استفاده کنید که هر خروجی `console` هم نمایش داده می‌شود. می‌توانید با استفاده از این دستور در `console` بنویسید:

```javascript
console.log('Debug message');
```
