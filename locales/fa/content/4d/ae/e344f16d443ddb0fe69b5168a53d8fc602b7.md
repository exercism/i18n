# مقدمه

## توابع بازگشتی

«توابع بازگشتی» توابعی هستند که به عنوان آرگومان پاس داده می‌شوند.
این الگوی برنامه‌نویسی دنباله‌ای از فراخوانی توابع را در برنامه‌نویسی همگام و ناهمگام ایجاد می‌کند.
نوشتن یک تابع بازگشتی هیچ تفاوتی با نوشتن یک تابع ندارد؛ با این حال، تابع بازگشتی باید با امضایی که تابع فراخوان تعریف کرده است مطابقت داشته باشد.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

همچنین می‌توانید توابع بازگشتی را به صورت عبارت تابعی، عبارت تابعی بی‌نام، یا عبارت تابعی پیکانی بنویسید:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
