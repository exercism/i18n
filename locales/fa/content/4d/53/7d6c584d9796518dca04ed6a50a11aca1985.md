# نصب

## اوبونتو (و بیشتر توزیع‌های مبتنی بر دبیان)

برای ساخت کد به‌صورت محلی، به `gcc` و `make` نیاز دارید که می‌توانید با این دستور نصب کنید:

```shell
sudo apt install gcc make
```

اگر روی سخت‌افزار ARM64 اجرا نمی‌کنید، شبیه‌ساز [QEMU][] و زنجیره‌ی ابزار متقابل GCC ARM64 را با این دستور نصب کنید:

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## ویندوز

از [Windows Subsystem for Linux][] همراه با یک توزیع مبتنی بر دبیان استفاده کنید و دستورهای اوبونتو را که در بالا آمد دنبال کنید. در عوض، می‌توانید یک ماشین مجازی لینوکس راه‌اندازی کنید.

## macOS

می‌توانید با هر راهکار مجازی‌سازی مناسب (مثلاً [Lima][]) یک ماشین مجازی لینوکس راه‌اندازی کنید.

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
