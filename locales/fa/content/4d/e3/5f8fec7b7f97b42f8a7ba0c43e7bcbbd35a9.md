# راهنمایی‌ها

## 1. گرفتن اولین حرف عنوان

- [متدی][index] وجود دارد که یک `Char` را از یک `String` در اندیس مشخص برمی‌گرداند.

## 2. گرفتن حروف اول نویسندگان

- می‌توانید از متدهایی که پیش‌تر پیاده‌سازی شده‌اند برای گرفتن اولین حرف یک `String` استفاده کنید.
- برای ترکیب مقادیر در یک `String` می‌توانید از [درج رشته][string-interpolation] استفاده کنید.

## 3. رمزگشایی حرف

- [متدی][uppercase] وجود دارد که مشخص می‌کند آیا یک `Char` حرف بزرگ است یا نه.
- [متدی][ord] وجود دارد که کدپوینت یک `Char` را برمی‌گرداند.

## 4. رمزگشایی متن

- می‌توانید از [حلقه‌زدن][while] برای اجرای کد چندین بار استفاده کنید.
