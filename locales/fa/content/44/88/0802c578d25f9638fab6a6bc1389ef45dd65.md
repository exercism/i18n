# دستورالعمل‌ها

توالی‌های RNA را به پروتئین ترجمه کنید.

RNA را می‌توان به توالی‌های سه‌نوکلئوتیدی به نام «کدون» شکست و سپس مانند زیر به پروتئین ترجمه کرد:

RNA: `"AUGUUUUCU"` => ترجمه می‌شود به

کدون‌ها: `"AUG", "UUU", "UCU"`
=> که تبدیل می‌شوند به پروتئینی با توالی زیر =>

پروتئین: `"Methionine", "Phenylalanine", "Serine"`

۶۴ کدون وجود دارد که هر یک به یکی از ۲۰ اسید آمینه مربوط می‌شود؛ اما همه‌ی توالی‌های کدون و اسیدهای آمینه‌ی حاصل در این تمرین مهم نیستند.
اگر برای یک کدون کار کند، برنامه باید برای همه‌ی آن‌ها کار کند.
با این حال، می‌توانید با خیال راحت فهرست موجود در مجموعه‌ی آزمون را گسترش دهید تا همه‌ی آن‌ها را هم در بر بگیرد.

همچنین سه کدون پایان‌دهنده هم وجود دارد (که با نام کدون‌های «STOP» هم شناخته می‌شوند)؛ اگر به هر یک از این کدون‌ها برخورد شود (توسط ریبوزوم)، ترجمه پایان می‌یابد و پروتئین خاتمه پیدا می‌کند.

همه‌ی کدون‌های بعدی نادیده گرفته می‌شوند، مانند زیر:

RNA: `"AUGUUUUCUUAAAUG"` =>

کدون‌ها: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

پروتئین: `"Methionine", "Phenylalanine", "Serine"`

توجه کنید که کدون توقف `"UAA"` ترجمه را پایان می‌دهد و متیونین آخر به توالی پروتئین ترجمه نمی‌شود.

در زیر کدون‌ها و اسیدهای آمینه‌ی حاصل که برای این تمرین لازم است آمده است.

| Codon              | Amino Acid    |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

درباره‌ی [ترجمه‌ی پروتئین در ویکی‌پدیا][protein-translation] بیشتر بدانید.
