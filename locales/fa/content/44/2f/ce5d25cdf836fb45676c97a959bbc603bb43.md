# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که فهرستی از زبان‌های برنامه‌نویسی را که قصد دارید از پلتفرم Exercism تمرین کنید، پردازش می‌کند.

شش کار دارید.

## 1. یک فهرست جدید بسازید

پیش از آنکه بتوانید زبانی اضافه کنید، باید کار را با ساختن یک فهرست جدید شروع کنید. تابعی تعریف کنید که یک فهرست خالی برمی‌گرداند.

```clojure
(new-list)
;; => ()
```

## 2. یک زبان جدید به فهرست اضافه کنید

وقتی Exercism را کاوش می‌کنید و زبان‌هایی را پیدا می‌کنید که می‌خواهید یاد بگیرید، باید بتوانید آن‌ها را به فهرستتان اضافه کنید. تابعی تعریف کنید که یک زبان جدید را به ابتدای فهرستتان اضافه کند.

```clojure
(add-language '("Clojurescript") "JavaScript")
;; => '("JavaScript" "Clojurescript")
```

## 3. آخرین زبان اضافه‌شده را بررسی کنید

می‌خواهید به‌سرعت بررسی کنید کدام زبان را همین الان اضافه کرده‌اید. تابعی تعریف کنید که اولین زبان فهرستتان را برمی‌گرداند.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. اولین زبان را از فهرست حذف کنید

گاهی درباره‌ی زبانی که همین الان اضافه کرده‌اید نظرتان عوض می‌شود. تابعی تعریف کنید که اولین زبان را از فهرستتان حذف کند.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. زبان‌های فهرست را بشمارید

شمردن زبان‌ها یکی‌یکی کار دشواری است. تابعی تعریف کنید که تعداد زبان‌های فهرستتان را بشمارد.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. همه را کنار هم بگذارید

تابعی به اسم `learning-list` تعریف کنید و در آن از برخی از توابعی که در بالا تعریف کردید استفاده کنید.

- یک فهرست خالی بسازید.
- ۲ زبان برنامه‌نویسی جدید به فهرست اضافه کنید.

  - «Clojure»
  - «Lisp»

- «Lisp» را از فهرست حذف کنید، چون ممکن است امسال وقت کافی برایش نداشته باشید و شباهت زیادی به Clojure دارد.
- ۲ زبان برنامه‌نویسی دیگر به فهرست اضافه کنید.

  - «Java»
  - «JavaScript»

- تعداد کل زبان‌ها را برگردانید. راهنما: باید ۳ باشد.

```clojure
(learning-list)
;; => 3
```
