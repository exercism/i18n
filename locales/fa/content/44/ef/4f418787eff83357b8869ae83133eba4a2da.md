# درباره

یک `vector` در Clojure یک مجموعه‌ی ترتیبی، ایندکس‌دار و تغییرناپذیر از صفر یا چند مقدار است. این یعنی وقتی یک بردار ساخته شد، دیگر نمی‌توان آن را تغییر داد. توابعی که روی بردارها کار می‌کنند یک بردار جدید برمی‌گردانند، در حالی که بردار اصلی بدون تغییر باقی می‌ماند. مقدارهای داخل یک بردار می‌توانند از انواع گوناگون باشند. بردارها را می‌توان به این صورت تعریف کرد:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

می‌توان عنصرها را با استفاده از ایندکس از یک بردار بازیابی کرد. بردارهای Clojure بر پایه‌ی صفر هستند، یعنی ایندکس اولین عنصر همیشه صفر است:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

بردار اصلی بدون تغییر می‌ماند:

```clojure
numbers
;;=> [2 3 5]
```

برای اینکه مقدار به‌روزشده را به خاطر بسپاریم، باید آن را همراه ببریم یا در یک var ذخیره کنیم:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
