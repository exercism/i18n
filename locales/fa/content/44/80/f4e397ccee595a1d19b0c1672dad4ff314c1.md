# نصب

برای اینکه بدانید چطور باید همه‌چیز را روی سیستم خودتان راه‌اندازی کنید، به [System/Installation][install-link] مراجعه کنید.

~~~exercism/caution
اگر کیت توسعه‌ی Java (JDK) روی سیستم شما نصب باشد، ممکن است فایل اجرایی `jconsole` با Java Console که اسم یکسانی دارد، تداخل پیدا کند.

راه‌حل‌های ممکن عبارت‌اند از:

- فایل اجرایی `jconsole` مربوط به زبان برنامه‌نویسی J را به اسمی یکتا تغییر بدهید (برای مثال، `jconsole-jlang`).

- متغیرهای محیطی سیستم یا PATH را طوری تنظیم کنید که `jconsole` مربوط به زبان برنامه‌نویسی J در اولویت قرار بگیرد.

- **اگر کاربر Linux هستید**، اسکریپتی bash در `bin/install.sh` وجود دارد که یک **پیوند نمادین** به اسم `ijconsole` در شاخه‌ی `/usr/` می‌سازد. برای استفاده از این پیوند کافی است در ترمینال `ijconsole` را تایپ کنید.
~~~

پس از نصب J، یک کنسول J در ترمینال باز کنید و دستورهای زیر را برای نصب چارچوب تست واحد وارد کنید:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
