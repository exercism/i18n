# مقدمه

مقادیر «منطقی» در Go با نوع منطقی از پیش تعریف‌شده‌ی `bool` نمایش داده می‌شوند که مقادیر آن می‌تواند `true` یا `false` باشد.
این یک نوع تعریف‌شده است.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go از سه عملگر منطقی پشتیبانی می‌کند که می‌توانند عبارت‌ها را به مقادیر منطقی تبدیل کنند و `true` یا `false` برگردانند.

| عملگر      | معنی                                            |
| ----------- | --------------------------------------------- |
| `&&` (و)    | اگر هر دو گزاره «درست» باشند، نتیجه «درست» است. |
| `\|\|` (یا) | اگر حداقل یکی از گزاره‌ها «درست» باشد، نتیجه «درست» است. |
| `!` (نقیض)  | فقط اگر گزاره «غلط» باشد، نتیجه «درست» است.     |
