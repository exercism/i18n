# دستورالعمل‌ها

در این تمرین روی یک برنامه‌ریز نوبت‌دهی برای یک سالن زیبایی در نیویورک کار می‌کنید که در ۱۵ سپتامبر ۲۰۱۲ افتتاح شد.

پنج کار دارید که همه‌ی آن‌ها به تاریخ‌های نوبت مربوط می‌شوند.
زمان‌ها در قالب ۲۴ ساعته هستند (بدون AM/PM).
برای اینکه مسائل مربوط به منطقه‌ی زمانی تا حد امکان ساده بماند، فرض کنید همه‌چیز از UTC استفاده می‌کند.

## 1. تجزیه‌ی تاریخ نوبت به‌صورت تمام‌عددی

تابع `schedule_appointment()` را پیاده‌سازی کنید تا نمایش متنی یک تاریخ نوبت را به قالب `DateTime` متناظر با آن تجزیه کند.

توجه کنید که ورودی به سبک آمریکایی، یعنی به ترتیب ماه/روز/سال است.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. بررسی اینکه آیا نوبت گذشته است

تابع `has_passed()` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و بررسی می‌کند آیا آن نوبت جایی در گذشته بوده است:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. بررسی اینکه نوبت در بعدازظهر است

تابع `is_afternoon_appointment()` را پیاده‌سازی کنید که یک تاریخ نوبت می‌گیرد و بررسی می‌کند آیا آن نوبت در بعدازظهر است (از ساعت ۱۲:۰۰ به بعد و پیش از ۱۸:۰۰):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. بررسی روز هفته برای یک نوبت

تابع `day_of_week()` را پیاده‌سازی کنید که روز هفته را به‌صورت _عددی_ برمی‌گرداند.
سالن یکشنبه‌ها تعطیل است، پس دوشنبه روز ۱ است و شنبه روز ۶.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. تغییر زمان یک نوبت

وقتی مشتری بخواهد زمان یک نوبت را تغییر دهد، این کار به‌طور خودکار برای جمعه‌ی بعد در همان ساعت از روز انجام می‌شود (چون این روز کم‌رونق‌ترین روز هفته است).

تابع `reschedule()` را پیاده‌سازی کنید که نوبت اصلی را (به‌صورت یک رشته‌ی متنی به ترتیب ماه/روز/سال) می‌گیرد و نوبتی را با زمان تغییر یافته برمی‌گرداند.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

اگر نوبت اصلی برای دوشنبه تا پنجشنبه باشد، آن را به جمعه‌ی _همین_ هفته منتقل کنید.
برای نوبت‌های جمعه یا شنبه، آن را به جمعه‌ی _هفته‌ی بعد_ منتقل کنید.
