# درباره

الیکسیر از [_«رفتارها»_][behaviours] استفاده می‌کند تا رابط‌های عمومی مشترکی فراهم کند و در همان حال، پیاده‌سازی اختصاصی هر ماژولی را که آن رفتار را پیاده‌سازی می‌کند ممکن سازد. یکی از این رفتارها، _«رفتار دسترسی»_ است.

«رفتار دسترسی» یک رابط مشترک برای بازیابی داده‌های مبتنی بر کلید از یک ساختار داده فراهم می‌کند. این رفتار برای نقشه‌ها و فهرست‌های کلیدواژه پیاده‌سازی شده است.

ماژول [`Access`][access] توابع موردنیاز این رابط را تعریف می‌کند. سپس ماژول‌های [`Map`][map] و [`Keyword`][keyword] توابع موردنیاز [`fetch/2`][map-fetch]، [`get_and_update/3`][map-get-and-update] و [`pop/2`][map-pop] را پیاده‌سازی می‌کنند.

برای استفاده از این رفتار، می‌توانید پس از یک متغیر مقیدشده _«کروشه»_ بگذارید و سپس با آن کلید، مقدار وابسته به کلید را بازیابی کنید. نقشه‌ها از کلیدهایی با هر نوعی پشتیبانی می‌کنند، اما فهرست‌های کلیدواژه فقط از کلیدهای اتم پشتیبانی می‌کنند.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

اگر کلید در ساختار داده وجود نداشته باشد، `nil` برگردانده می‌شود. این می‌تواند منشأ رفتار ناخواسته باشد، چون خطایی ایجاد نمی‌کند.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

توجه کنید که خود `nil` هم رفتار دسترسی را پیاده‌سازی می‌کند و برای هر کلیدی همیشه `nil` برمی‌گرداند.

```elixir
nil[:key]
# => nil
```

ساختارها رفتار دسترسی را پیاده‌سازی نمی‌کنند.
