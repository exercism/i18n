# مقدمه

یک نمونه از یک کلاس با فراخوانی [_«سازنده»_][constructor] آن به کمک عملگر `new` ساخته می‌شود. سازنده متدی ویژه درون یک کلاس است که هدفش مقداردهی اولیه‌ی همان کلاس است. در Haxe، اسم متد سازنده `new()` است.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

درست مثل متدهای معمولی، متدهای سازنده هم می‌توانند پارامتر داشته باشند. این پارامترها (معمولاً) در فیلدهای `private` ذخیره می‌شوند و بعداً به آن‌ها دسترسی پیدا می‌کنیم.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

اگر یک کلاس سازنده نداشته باشد، **نمی‌توانید** نمونه‌ی جدیدی از آن بسازید. پس تنها راه، استفاده از یک سازنده‌ی خالی است.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
