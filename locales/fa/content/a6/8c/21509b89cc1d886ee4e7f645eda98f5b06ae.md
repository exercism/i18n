# مقدمه

رایج‌ترین راه برای اجرای کد به‌صورت شرطی در F#، استفاده از یک عبارت `if/elif/else` است:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

شرط یا شرط‌هایی که در یک عبارت `if/elif/else` استفاده می‌شوند باید از نوع `bool` باشند. در F# مفهومی به اسم مقادیر _truthy_ وجود ندارد.
