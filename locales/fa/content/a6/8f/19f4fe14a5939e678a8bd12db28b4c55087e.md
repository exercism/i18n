# راهنمایی‌ها

## کلی

- مستندات رسمی [تایپ‌اسپک‌ها][typespecs] را بخوانید.
- مستندات رسمی درباره‌ی [نوشتن مستندات][writing-documentation] را بخوانید.
- درباره‌ی استفاده از ویژگی‌های ماژول به‌عنوان حاشیه‌نویسی، در [راهنمای رسمی شروع به کار][getting-started-module-attributes] بخوانید.
- درباره‌ی استفاده از تایپ‌اسپک‌ها در [راهنمای رسمی شروع به کار][getting-started-typespecs] بخوانید.

## 1. مستندسازی هدف ابزارهای فرم

- از ویژگی ماژول `@moduledoc` می‌توان برای نوشتن مستندات یک ماژول استفاده کرد.

## 2. مستندسازی پر کردن فیلدها با مقادیر خالی

- از ویژگی ماژول `@doc` می‌توان برای نوشتن مستندات یک تابع استفاده کرد.
- از ویژگی ماژول `@spec` می‌توان برای نوشتن یک تایپ‌اسپک برای یک تابع استفاده کرد.
- ویژگی‌های `@doc` و `@spec` را درست پیش از نخستین بند تابعی که این ویژگی‌ها توصیفش می‌کنند قرار دهید.
- برای دیدن فهرست همه‌ی نوع‌های موجود، به [مستندات تایپ‌اسپک‌ها][typespecs-types] مراجعه کنید.
- نوع درست برای رشته‌ها [در ماژول `String` تعریف شده است][string-t].

## 3. مستندسازی تقسیم مقادیر به لیست‌هایی از حروف بزرگ

- از ویژگی ماژول `@doc` می‌توان برای نوشتن مستندات یک تابع استفاده کرد.
- از ویژگی ماژول `@spec` می‌توان برای نوشتن یک تایپ‌اسپک برای یک تابع استفاده کرد.
- ویژگی‌های `@doc` و `@spec` را درست پیش از نخستین بند تابعی که این ویژگی‌ها توصیفش می‌کنند قرار دهید.
- برای دیدن فهرست همه‌ی نوع‌های موجود، به [مستندات تایپ‌اسپک‌ها][typespecs-types] مراجعه کنید.
- نوع درست برای رشته‌ها [در ماژول `String` تعریف شده است][string-t].
- لیست یک نوع پارامتری‌شده است.

## 4. مستندسازی بررسی اینکه آیا یک مقدار در فیلدی با حداکثر طول جا می‌گیرد

- از ویژگی ماژول `@doc` می‌توان برای نوشتن مستندات یک تابع استفاده کرد.
- از ویژگی ماژول `@spec` می‌توان برای نوشتن یک تایپ‌اسپک برای یک تابع استفاده کرد.
- ویژگی‌های `@doc` و `@spec` را درست پیش از نخستین بند تابعی که این ویژگی‌ها توصیفش می‌کنند قرار دهید.
- برای دیدن فهرست همه‌ی نوع‌های موجود، به [مستندات تایپ‌اسپک‌ها][typespecs-types] مراجعه کنید.
- نوع درست برای رشته‌ها [در ماژول `String` تعریف شده است][string-t].
- می‌توان از مقادیر تحت‌اللفظی در یک تایپ‌اسپک استفاده کرد.
- از خط عمودی `|` می‌توان برای نمایش اجتماع نوع‌ها استفاده کرد.

## 5. مستندسازی قالب‌های مختلف آدرس

- از ویژگی ماژول `@type` می‌توان برای تعریف یک نوع عمومی سفارشی استفاده کرد.
- نوع‌ها می‌توانند ترکیبی باشند؛ مثلاً وقتی نوعی را مشخص می‌کنید که یک نقشه است، می‌توانید نوع مقادیر زیر کلیدهای مشخص را هم تعیین کنید.
- [عملگر نوع `::`][type-operator] را هم می‌توان برای افزودن اسم متغیر به ابتدای یک نوع به کار برد.
- از نوع‌های سفارشی می‌توان برای تعریف نوع‌های سفارشی دیگر استفاده کرد.

## 6. مستندسازی قالب‌بندی آدرس

- از ویژگی ماژول `@doc` می‌توان برای نوشتن مستندات یک تابع استفاده کرد.
- از ویژگی ماژول `@spec` می‌توان برای نوشتن یک تایپ‌اسپک برای یک تابع استفاده کرد.
- ویژگی‌های `@doc` و `@spec` را درست پیش از نخستین بند تابعی که این ویژگی‌ها توصیفش می‌کنند قرار دهید.
- برای دیدن فهرست همه‌ی نوع‌های موجود، به [مستندات تایپ‌اسپک‌ها][typespecs-types] مراجعه کنید.
- نوع درست برای رشته‌ها [در ماژول `String` تعریف شده است][string-t].
- می‌توان از نوع‌های سفارشی در یک تایپ‌اسپک استفاده کرد.
