# درباره

زبان Go به‌صورت ایستا نوع‌بندی شده است، بنابراین هر متغیر نوعی خواهد داشت که در زمان کامپایل مشخص است.
پس از اعلام، نوع متغیر نمی‌تواند تغییر کند.

## ساختن یک متغیر

دستور `var` می‌تواند نوع یک متغیر تازه را اعلام کند، مقدار آن را تعیین کند، یا هر دو را همزمان انجام دهد:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

درون یک تابع، می‌توان از دستور انتساب کوتاه `:=` هم استفاده کرد.

```go
count := 1 // Type implictly declared, value explicitly set
```

هر متغیر در Go همیشه یک مقدار دارد.
اگر هنگام اعلام مقداری تعیین نشود، Go بر اساس نوع متغیر مقداری [به اسم مقدار صفر][zero-values] برای آن در نظر می‌گیرد.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## به‌روزرسانی یک متغیر

درون یک تابع، عملگر انتساب `=` می‌تواند مقدار تازه‌ای برای یک متغیر موجود تعیین کند:

```go
count := 1
count = 2
```

مقدار تازه باید همان نوع متغیر را داشته باشد:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
