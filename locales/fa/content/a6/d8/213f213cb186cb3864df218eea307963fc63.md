# مقدمه

یک «خاصیت» در Haxe عضوی از یک کلاس است که دسترسی به داده‌های درون آن کلاس را فراهم می‌کند. فراخوان‌ها می‌توانند داده را تنظیم یا بازیابی (get) کنند. خاصیت از یک دسترسگر تنظیم و/یا یک دسترسگر خواندن تشکیل شده است.

خاصیت‌ها، مانند سایر اعضای کلاس، تعدیل‌کننده‌های دسترسی (از قبیل `public`، `private` و غیره) دارند، اما دسترسگر تنظیم می‌تواند سطح دسترسی‌ای مستقل از دسترسگر خواندن (get) داشته باشد و برعکس. یک خاصیت لازم نیست هر دو دسترسگر را داشته باشد، می‌تواند فقط یکی از آن‌ها را داشته باشد (یعنی `get` یا `set`).

دسترسی خواندن و دسترسی نوشتن مستقیماً در نحوه‌ی نگارش کد بازتاب می‌یابند، همان‌طور که مثال زیر نشان می‌دهد:

```haxe
class Main {
  public var x(default, null):Int;
}
```

هر دو `default` و `null` **شناسه‌های دسترسی** ویژه‌اند. شناسه‌های دسترسی رفتار را برای زمانی که فیلد خوانده می‌شود (شناسه‌ی اول) و زمانی که فیلد نوشته می‌شود (شناسه‌ی دوم) تعیین می‌کنند. مقادیر پذیرفته‌شده عبارت‌اند از:

- `default`: اگر فیلد `public` باشد، دسترسی معمولی به فیلد را مجاز می‌کند.
- `null`: دسترسی را فقط از داخل کلاس تعریف‌کننده مجاز می‌کند.
- `get/set`: دسترسی به‌صورت فراخوانی یک متد دسترسگر (`get_x()`) تولید می‌شود.
- `dynamic`: مانند `get/set` است، اما وجود متد دسترسگر قابل بررسی نیست.
- `never`: هیچ دسترسی‌ای را مجاز نمی‌داند.

در ادامه یک مثال کامل می‌بینید:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
