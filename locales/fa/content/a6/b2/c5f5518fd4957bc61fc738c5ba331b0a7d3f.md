# مقدمه

## درست‌نما و نادرست‌نما

در Common Lisp همه‌ی مقدارها «درست» هستند، به‌جز `()` که «نادرست» است.
دو نماد ثابت ویژه به اسم `t` و `nil` وجود دارد که مقدارشان به‌ترتیب درست و نادرست است.

## شرط‌ها

Common Lisp چندین عبارت شرطی متفاوت ارائه می‌دهد؛ تفاوت اصلی‌شان در تعداد شاخه‌هایی است که پشتیبانی می‌کنند.

- `when` و `unless` فقط از یک شاخه پشتیبانی می‌کنند:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

بخشی که بعد از «عبارت آزمون» می‌آید می‌تواند بیش از یک عبارت باشد.

- `if` ساختار کلاسیک شرط-آنگاه-وگرنه را فراهم می‌کند:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

توجه کنید که هر دو بخش آنگاه و وگرنه فقط می‌توانند یک عبارت باشند.

- `cond` راهی فراهم می‌کند که بدون تودرتو کردن عبارت‌های `if` چندین شاخه داشته باشید:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

توجه کنید که تعداد عبارت‌هایی که بعد از عبارت آزمون می‌آیند هیچ محدودیتی ندارد.

- `case` ساختاری کلاسیک به سبک switch فراهم می‌کند: یک مقدار را با چندین شاخه مقایسه می‌کند:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

توجه کنید که مانند `cond` هیچ محدودیتی در تعداد عبارت‌هایی که بعد از عبارت آزمون می‌آیند وجود ندارد.
