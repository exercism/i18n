# تکرار

در برنامه‌نویسی، [تکرار][iteration] به فرایند اجرای چندباره‌ی یک بلوک کد اشاره دارد.
این کار را می‌توان با مفاهیمی مانند حلقه‌های While و Until انجام داد.
همچنین می‌توان از «بازگشت» استفاده کرد، که تابعی است که خودش را فراخوانی می‌کند.

اما بیشتر اوقات می‌خواهید روی مجموعه‌ای از عناصر پیمایش کنید، مانند یک `Array`، `Range` یا `String`.
هر دو کلاس `Array` و `Range` در Crystal ماژول [`Enumerable`][enumerable] را شامل می‌شوند که روش‌های متعددی برای پیمایش عناصر فراهم می‌کند.
در همین حال، کلاس `String` مجموعه‌ی روش‌های خودش را برای پیمایش کاراکترها دارد.

Crystal نیز مانند زبان‌های دیگر دستور `for` ندارد.
در عوض، چندین روش دارد که می‌توان برای پیمایش از آن‌ها استفاده کرد.

## پیمایش

رایج‌ترین راه برای پیمایش روی یک مجموعه استفاده از روش [`each`][each] است، که هر عنصر مجموعه را به یک بلوک می‌دهد.
این کار را به‌راحتی می‌توان با یک `Range` انجام داد.
فرض کنید می‌خواهید از ۱ تا ۳ حلقه بزنید؛ می‌توانید از روش `each` برای پیمایش روی این بازه استفاده کنید.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

حتی ساده‌تر، اگر فقط می‌خواهید چند بار تکرار کنید می‌توانید از روش [`times`][times] استفاده کنید که روی کلاس `Int` وجود دارد.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## پیمایش روی یک `String`

یک `String` دنباله‌ای از کاراکترهاست و به ماژول `Enumerable` تعلق ندارد، یعنی مجموعه‌ی روش‌های خودش را برای پیمایش روی کاراکترها دارد.
رایج‌ترین راه برای پیمایش روی یک `String` استفاده از روش [`each_char`][each_char] است، که هر کاراکتر `String` را به یک بلوک می‌دهد.

~~~~exercism/note
روش `each_char` یک شیء `Char` را به بلوک می‌دهد، نه یک شیء `String`.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

راه دیگری برای پیمایش روی یک `String` استفاده از روش [`each_line`][each_line] است.
این روش بیشتر هنگام خواندن یک فایل خط به خط به کار می‌رود.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## پیمایش روی شیئی که ماژول `Enumerable` را شامل می‌شود

ماژول [`Enumerable`][enumerable] روش‌های متعددی برای پیمایش روی عناصر یک مجموعه فراهم می‌کند.
مجموعه‌هایی که ماژول `Enumerable` را شامل می‌شوند عبارت‌اند از `Array`، `Range`، `Hash`، `Set` و دیگران؛ آن‌های بعدی در مفاهیم بعدی پوشش داده می‌شوند.

رایج‌ترین راه برای پیمایش روی یک `Array` استفاده از روش [`each`][each] است، که هر عنصر `Array` را به یک بلوک می‌دهد.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

روش [`map`][map] راه دیگری برای پیمایش روی یک `Array` است؛ آرایه‌ی جدیدی برمی‌گرداند که شامل نتایج اعمال بلوک روی هر عنصر است.
این روش شبیه `each` است، اما یک `Array` جدید با عناصر تبدیل‌شده برمی‌گرداند.
تبدیل زمانی بسیار مفید است که بخواهید تابعی را روی هر عنصر مجموعه اعمال کنید، که عملیاتی رایج است.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

با ساختار کنترل جریانی مانند `if` می‌توانید فیلتر کنید که کدام عناصر تبدیل شوند.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## خلاصه‌نویسی

در Crystal یک نگارش خلاصه برای پیمایش و اعمال یک روش روی هر عنصر مجموعه وجود دارد.
این زمانی مفید است که با منطق ساده‌ای کار می‌کنید که فقط باید با یک روش تبدیل شود.
این کار با استفاده از نگارش `&.` و سپس اسم روش انجام می‌شود.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### همراه با اندیس

گاهی لازم است بدانید اندیس عنصری که روی آن پیمایش می‌کنید چیست؛ برای این کار می‌توانید از روش [`each_with_index`][each_with_index] یا [`map_with_index`][map_with_index] استفاده کنید.
این روش هر عنصر و اندیس آن را به یک بلوک می‌دهد، و آرگومان اختیاری‌ای هم می‌پذیرد تا اندیس شروع را مشخص کنید.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

توجه کنید که روش [`each_char_with_index`][each_char_with_index] هم برای اشیاء `String` در دسترس است.

### sum

روش [`sum`][sum] مجموع همه‌ی عناصر مجموعه را برمی‌گرداند؛ یک بلوک اختیاری هم می‌پذیرد تا عناصر را پیش از جمع کردن تبدیل کند.
همچنین آرگومان اختیاری‌ای می‌پذیرد که مقدار اولیه‌ی مجموع را مشخص می‌کند.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

روش [`reduce`][reduce]، یا همان fold که در زبان‌های دیگر با این اسم شناخته می‌شود، روشی است که با یک روش ترکیب و یک مقدار اولیه، همه‌ی عناصر مجموعه را با هم ترکیب می‌کند.
روش `reduce` یک «انباشته‌گر» دارد که به بلوک داده می‌شود؛ انباشته‌گر نتیجه‌ی دور قبلی است.
این فرایندی بازگشتی می‌شود که همه‌ی عناصر مجموعه را با هم ترکیب می‌کند.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` ممکن است شبیه `sum` به نظر برسد، اما `reduce` انعطاف‌پذیرتر است چون به شما اجازه می‌دهد مقدار اولیه‌ی انباشته‌گر و روش ترکیب را مشخص کنید.
می‌توان از `reduce` برای پیاده‌سازی `sum`، `count` و روش‌های دیگر استفاده کرد.
