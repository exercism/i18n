# راهنمایی

برای همه‌ی این کارها به دستور `print` نیاز دارید:
```awk
{print "something", "something else"}
```

## 1. نام‌های کاربری را فهرست کنید

* برای تعریف جداکننده‌ی فیلد از [متغیر `FS`][var-fs] استفاده کنید.

## 2. شماره‌ی خط‌ها را چاپ کنید

* برای گرفتن شماره‌ی خط از [متغیر توکار `NR`][var-nr] استفاده کنید.

## 3. رکوردهایی را که دایرکتوری خانگی نامعتبر دارند چاپ کنید.

* دایرکتوری خانگی همان فیلد ششم است.
* از تابع `startsWith` که در اختیارتان قرار گرفته استفاده کنید.
* از [«عملگرهای منطقی»][boolean-ops] استفاده کنید: `&&`، `||`، `!`.

## 4. تعداد کاربران معتبری را که از bash استفاده می‌کنند چاپ کنید

* پوسته‌ی ورود همان فیلد آخر است؛ می‌توانید از [متغیر `NF`][var-nf] استفاده کنید.
