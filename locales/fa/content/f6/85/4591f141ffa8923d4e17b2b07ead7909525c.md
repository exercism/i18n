# راهنمایی

## کلی

- به یاد داشته باشید که انتساب متغیر درون یک pipeline یک عبارت است و همان مقداری را خروجی می‌دهد که ورودی‌اش بوده است.
- برای تعیین مقادیر پیش‌فرض، از [عملگر جایگزین `//`][alternative] استفاده کنید.

## 1. زمان مورد انتظار در فر را بر حسب دقیقه تعریف کنید

- متغیری تعریف کنید که مقدار زمان مورد انتظار را نگه دارد.
- مقدار را در شیء خروجی، برای کلید `"expected_minutes_in_oven"` قرار دهید.
- میان‌بر ساخت شیء `{$foo}` همان `{foo: $foo}` است

## 2. زمان باقی‌مانده در فر را بر حسب دقیقه محاسبه کنید

- مقدار محاسبه‌شده را در شیء خروجی، برای کلید `"remaining_minutes_in_oven"` قرار دهید.
- از [عملگر `-`][subtraction] برای تفریق حسابی روی اعداد استفاده می‌شود.

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

- مقدار محاسبه‌شده را در شیء خروجی، برای کلید `"preparation_time"` قرار دهید.
- از [عملگر `*`][multiplication] برای ضرب حسابی روی اعداد استفاده می‌شود.
- سبک خوب پیشنهاد می‌کند برای نام‌گذاری «مقدار جادویی» زمان صرف‌شده در هر لایه، از یک متغیر استفاده کنید.

## 4. مجموع زمان کار را بر حسب دقیقه محاسبه کنید

- مقدار محاسبه‌شده را در شیء خروجی، برای کلید `"total_time"` قرار دهید.
- از [عملگر `+`][addition] برای جمع حسابی روی اعداد استفاده می‌شود.

[subtraction]: https://jqlang.org/manual/#subtraction
[multiplication]: https://jqlang.org/manual/#multiplication-division-modulo
[addition]: https://jqlang.org/manual/#addition
[alternative]: https://jqlang.org/manual/#alternative-operator
