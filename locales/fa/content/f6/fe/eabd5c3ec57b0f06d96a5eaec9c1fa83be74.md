# مقدمه

## اعداد صحیح

‏#C، مانند بسیاری از زبان‌های ایستا، تعدادی نوع ارائه می‌دهد که اعداد صحیح را نمایش می‌دهند و هرکدام بازه‌ی مقادیر خودش را دارد. در پایین‌ترین حد، نوع `sbyte` حداقل مقدار -۱۲۸ و حداکثر مقدار ۱۲۷ را دارد. مانند همه‌ی نوع‌های صحیح، این مقادیر به شکل `<type>.MinValue` و `<type>.MaxValue` در دسترس هستند. در بالاترین حد، نوع `long` حداقل مقدار -۹,۲۲۳,۳۷۲,۰۳۶,۸۵۴,۷۷۵,۸۰۸ و حداکثر مقدار ۹,۲۲۳,۳۷۲,۰۳۶,۸۵۴,۷۷۵,۸۰۷ را دارد. در این میان، نوع‌های `short` و `int` قرار دارند.

این بازه‌ها بر اساس عرض ذخیره‌سازیِ نوع که سیستم تخصیص می‌دهد، تعیین می‌شوند. برای مثال، یک `byte` از ۸ بیت و یک `long` از ۶۴ بیت استفاده می‌کند.

هر یک از نوع‌های بالا با یک معادل بدون علامت جفت شده است: `sbyte`/`byte`، `short`/`ushort`، `int`/`uint` و `long`/`ulong`. در همه‌ی موارد، بازه‌ی مقادیر از ۰ تا منفیِ حداکثرِ علامت‌دار ضربدر ۲ به‌علاوه‌ی ۱ است.

| نوع    | عرض    | حداقل                      | حداکثر                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | ۸ بیت  | -۱۲۸                       | +۱۲۷                        |
| short  | ۱۶ بیت | -۳۲_۷۶۸                    | +۳۲_۷۶۷                     |
| int    | ۳۲ بیت | -۲_۱۴۷_۴۸۳_۶۴۸            | +۲_۱۴۷_۴۸۳_۶۴۷              |
| long   | ۶۴ بیت | -۹_۲۲۳_۳۷۲_۰۳۶_۸۵۴_۷۷۵_۸۰۸ | +۹_۲۲۳_۳۷۲_۰۳۶_۸۵۴_۷۷۵_۸۰۷ |
| byte   | ۸ بیت  | ۰                          | +۲۵۵                        |
| ushort | ۱۶ بیت | ۰                          | +۶۵_۵۳۵                     |
| uint   | ۳۲ بیت | ۰                          | +۴_۲۹۴_۹۶۷_۲۹۵              |
| ulong  | ۶۴ بیت | ۰                          | +۱۸_۴۴۶_۷۴۴_۰۷۳_۷۰۹_۵۵۱_۶۱۵ |

یک متغیر (یا عبارت) از یک نوع را می‌توان به‌سادگی به نوع دیگری تبدیل کرد. برای نمونه، در یک عملیات انتساب، اگر نوع مقداری که انتساب داده می‌شود (lhs) تضمین کند که مقدار در بازه‌ی نوعی که به آن انتساب داده می‌شود (rhs) قرار می‌گیرد، آنگاه انتساب ساده است:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

از سوی دیگر، اگر بازه‌ی نوعِ مبدأ زیرمجموعه‌ای از بازه‌ی مقادیر نوعِ مقصد نباشد، آنگاه حتی اگر مقدار خاص در بازه‌ی مقصد قرار داشته باشد، به یک تبدیل نوع، یعنی عملگر `()`، نیاز است:

```csharp
short s = 42;
uint ui = (uint)s;
```

### تبدیل بیت

کلاس `BitConverter` روشی راحت برای تبدیل نوع‌های صحیح به آرایه‌های بایت و برعکس فراهم می‌کند.
