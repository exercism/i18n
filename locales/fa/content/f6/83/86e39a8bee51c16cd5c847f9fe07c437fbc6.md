# مقدمه

## اعداد

بسیاری از زبان‌های برنامه‌نویسی نوع‌های عددی مشخصی برای نمایش انواع مختلف اعداد دارند، اما JavaScript فقط دو نوع دارد:

- `number`: یک «نوع داده‌ی عددی» در قالب ممیز شناور دقت مضاعف ۶۴ بیتی (IEEE 754).
  نمونه‌هایی از آن `-6`، `-2.4`، `0`، `0.1`، `1`، `3.14`، `16.984025`، `25`، `976`، `1024.0` و `500000` هستند.
- `bigint`: یک نوع داده‌ی عددی که می‌تواند _اعداد صحیح_ را در قالب دقت دلخواه نمایش دهد.
  نمونه‌هایی از آن `-12n`، `0n`، `4n` و `9007199254740991n` هستند.

اگر به دقت دلخواه نیاز دارید یا با اعداد بسیار بزرگ کار می‌کنید، از نوع `bigint` استفاده کنید.
در غیر این صورت، نوع `number` احتمالاً گزینه‌ی بهتری است.

### گرد کردن

یک شیء سراسری توکار به اسم `Math` وجود دارد که [توابع گرد کردن][ref-math-object-rounding] مختلفی را در اختیار شما می‌گذارد.
برای مثال، می‌توانید اعداد اعشاری را به سمت پایین (`floor`) یا به سمت بالا (`ceil`) به نزدیک‌ترین عدد صحیح گرد کنید.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## عملگرهای حسابی

JavaScript ۶ «عملگر» مختلف برای انجام عملیات حسابی پایه روی اعداد در اختیار شما می‌گذارد.

- `+`: عملگر جمع برای یافتن مجموع اعداد به کار می‌رود.
- `-`: عملگر تفریق برای یافتن تفاضل دو عدد به کار می‌رود
- `*`: عملگر ضرب برای یافتن حاصل‌ضرب دو عدد به کار می‌رود.
- `/`: عملگر تقسیم برای تقسیم دو عدد به کار می‌رود.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: عملگر باقی‌مانده برای یافتن باقی‌مانده‌ی یک تقسیم به کار می‌رود.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: عملگر توان برای به توان رساندن یک عدد به کار می‌رود.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### ترتیب انجام عملیات

وقتی چند عملگر در یک خط به کار می‌رود، JavaScript از ترتیبی برای اولویت پیروی می‌کند که در [این جدول اولویت][mdn-operator-precedence] نشان داده شده است.
برای ساده کردن ماجرا در بحث ما، JavaScript از قاعده‌ی PEDMAS (پرانتز، توان، تقسیم/ضرب، جمع/تفریق) استفاده می‌کند که در کلاس‌های ریاضی دبستان یاد گرفته‌ایم.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### عملگرهای انتساب کوتاه

عملگرهای انتساب کوتاه، روش کوتاه‌تری برای نوشتن کدی هستند که یک عملیات حسابی را روی یک متغیر انجام می‌دهد و مقدار جدید را به همان متغیر نسبت می‌دهد.
برای مثال، دو متغیر `x` و `y` را در نظر بگیرید.
در این صورت، `x += y` معادل `x = x + y` است.
اغلب به‌جای متغیر `y` از یک عدد استفاده می‌شود.
۵ عملیات دیگر هم می‌توانند به روشی مشابه انجام شوند.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
