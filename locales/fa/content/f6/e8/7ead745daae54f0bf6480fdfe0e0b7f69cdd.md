# دستورالعمل‌ها

به نظر نمی‌رسد نوستالژی شما برای کارت‌های Blorkemon™️ فروکش کند. حتی دوباره شروع به جمع‌آوری آن‌ها کرده‌اید و دوستانتان را هم دارید با خودتان همراه می‌کنید.

در این تمرین، از اینترفیس `Set` استفاده می‌کنید تا مجموعه‌تان را مدیریت کنید، چون وقتی هدف‌تان به‌دست‌آوردن همه‌ی کارت‌های موجود باشد، کارت‌های تکراری اهمیتی ندارند.

## 1. شروع یک مجموعه

تازه انبار قدیمی کارت‌های Blorkemon™️ خودتان را پیدا کرده‌اید!
این انبار پر از کارت‌های تکراری است، پس وقت آن رسیده که با حذف تکراری‌ها یک مجموعه‌ی جدید شروع کنید.

دلتان می‌خواهد دوستانتان هم به شور و شوق Blorkemon™️ شما بپیوندند و بهترین راه این است که با دادن یک کارت، مجموعه‌شان را راه بیندازید.

متد `newCollection` را پیاده‌سازی کنید که یک فهرست از کارت‌ها را به یک `Set` تبدیل می‌کند که نماینده‌ی مجموعه‌ی جدید شماست.

```java
GottaSnatchEmAll.newCollection(List.of("Newthree", "Newthree", "Newthree"));
// => {"Newthree"}
```

## 2. بزرگ‌کردن مجموعه

وقتی مجموعه‌ای داشته باشید، به‌نوعی زندگی خودش را پیدا می‌کند و باید رشد کند.

متد `addCard` را پیاده‌سازی کنید که یک کارت جدید و مجموعه‌ی فعلی کارت‌های جمع‌آوری‌شده‌ی شما را می‌گیرد.
این متد باید کارت جدید را، در صورتی که از قبل وجود نداشته باشد، به مجموعه اضافه کند و یک `boolean` برگرداند که نشان می‌دهد مجموعه به‌روزرسانی شده است یا نه.

```java
Set<String> collection = GottaSnatchEmAll.newCollection("Newthree");
GottaSnatchEmAll.addCard("Scientuna",collection);
// => true

collection.contains("Scientuna");
// => true
```

## 3. شروع معامله

دلتان می‌خواهد دوستانتان هم به شور و شوق Blorkemon™️ شما بپیوندند، پس وقت آن رسیده که معامله را شروع کنید!

وقتی با دوستانتان معامله می‌کنید، هر معامله‌ای ارزش انجام دادن ندارد، یا اصلاً امکان انجام ندارد.
فقط در صورتی باید معامله کنید که هم شما و هم دوستتان کارتی داشته باشید که دیگری ندارد.

متد `canTrade` را پیاده‌سازی کنید که مجموعه‌ی فعلی شما و مجموعه‌ی یکی از دوستانتان را می‌گیرد.
این متد باید بر اساس قواعد بالا یک `boolean` برگرداند که نشان می‌دهد معامله ممکن است یا نه.

```java
Set<String> myCollection = Set.of("Newthree");
Set<String> theirCollection = Set.of("Scientuna");
GottaSnatchEmAll.canTrade(myCollection, theirCollection);
// => true
```

## 4. شناسایی کارت‌های مشترک

شما و دوستان علاقه‌مندتان به Blorkemon™️ جمع می‌شوید و از خودتان می‌پرسید کدام کارت‌ها از همه رایج‌ترند.

متد `commonCards` را پیاده‌سازی کنید که فهرستی از مجموعه‌ها را می‌گیرد و مجموعه‌ای از کارت‌ها را برمی‌گرداند که همه‌ی مجموعه‌ها آن را دارند.

```java
GottaSnatchEmAll.commonCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Scientuna"}
```

## 5. همه‌ی کارت‌ها

آیا شما و دوستانتان روی هم همه‌ی کارت‌های Blorkemon™️ را دارید؟

متد `allCards` را پیاده‌سازی کنید که فهرستی از مجموعه‌ها را می‌گیرد و مجموعه‌ای از همه‌ی کارت‌های متفاوت موجود در همه‌ی مجموعه‌ها را با هم برمی‌گرداند.

```java
GottaSnatchEmAll.allCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Newthree", "Scientuna"}
```
