# دستورالعمل‌ها

هر نقشی در نمایش مدرسه یک جانشین دارد: کسی که می‌تواند به‌جای او روی صحنه برود و کاری را که نقش می‌خواهد انجام دهد، بی‌آنکه مدیر صحنه بداند او کیست.

هر پنج وظیفه در کلاس `UNDERSTUDY` قرار می‌گیرند. دو تای اول روال‌هایی معمولی‌اند که وظیفه‌های بعدی مقیدشان می‌کنند.

## 1. دو روش برای گفتن یک دیالوگ

`shout` را بنویسید که دیالوگ را با حروف بزرگ برمی‌گرداند و `whisper` را بنویسید که آن را با حروف کوچک و با `"..."` در دو سرش برمی‌گرداند.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. یک دیالوگ را تمرین کنید

`rehearse` یک دیالوگ و یک روش برای گفتن آن می‌گیرد و نتیجه را برمی‌گرداند. آرگومان دومش از نوع `ROUT{STR}:STR` است.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. کل صحنه

`run_scene` آرایه‌ای از دیالوگ‌ها و یک روش برای گفتنشان می‌گیرد و همه‌ی آن‌ها را که به آن روش گفته شده‌اند و با `" "` به هم پیوسته‌اند برمی‌گرداند.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

صحنه‌ی خالی، رشته‌ی خالی است.

## 4. برگرداندن روشی برای گفتن دیالوگ‌ها

`understudy_for` اسم یک سبک را می‌گیرد (‏`"shout"` یا هر چیز دیگری) و یک `ROUT{STR}:STR` برمی‌گرداند. `"shout"` روش فریادزدن را می‌دهد و هر چیز دیگری روش نجواکردن را.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. تثبیت یک آرگومان

`repeat` را بنویسید که تعداد دفعات و یک دیالوگ می‌گیرد و دیالوگ را آن تعداد بار، پشت سر هم و بدون هیچ فاصله‌ای برمی‌گرداند:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

سپس `doubler` را بنویسید که هیچ آرگومانی نمی‌گیرد و یک `ROUT{STR}:STR` برمی‌گرداند که هر چه به آن بدهند را دو بار تکرار می‌کند؛ این کار با مقید کردن `repeat` انجام می‌شود، در حالی که تعداد از قبل پر شده است.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
