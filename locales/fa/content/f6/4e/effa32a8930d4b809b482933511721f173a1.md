# مقدمه

کاراکترها و رشته‌ها پایه‌ی نمایش متن در Elm را تشکیل می‌دهند.
می‌توان به رشته‌ها به چشم فهرست‌هایی از کاراکترها نگاه کرد و بیشتر توابع `List` معادل خود را در ماژول `String` دارند.

## کاراکتر

نوع `Char` یک کاراکتر یونیکد تکی را با کوتیشن تکی نشان می‌دهد، مانند `'a'`. 
ماژول `Char` توابع محمولی (`Char -> Bool`) را برای آزمودن ویژگی‌های یک کاراکتر فراهم می‌کند: `isUpper`، `isLower`، `isAlpha` و `isAlphaNum`
ماژول `Char` همچنین توابعی برای تبدیل یک کاراکتر فراهم می‌کند: `toUpper`، `toLower`، `toLocaleUpper` و `toLocaleLower`، و نیز تبدیل به/از مقدار عددی یونیکد آن (`Int`) با `toCode` و `fromCode`.

## رشته

نوع `String` نمایشی توکار برای دستکاری کارآمد رشته‌ها فراهم می‌کند و می‌تواند هر دنباله‌ای از کاراکترهای یونیکد را نمایش دهد، مانند «this is an Elm string.»
رشته‌های چندخطی با سه کوتیشن دوتایی نوشته می‌شوند و می‌توانند کوتیشن‌ها و خطوط جدیدِ escapeنشده داشته باشند.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## توابع رشته

ماژول `String` شامل همه‌ی توابعی است که در جدول زیر خلاصه شده‌اند.
برخی از پرکاربردترین این توابع عبارت‌اند از:

`cons : Char -> String -> String` یک کاراکتر را به ابتدای یک رشته اضافه می‌کند.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` دو رشته را به هم می‌چسباند.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` یک رشته را در جداکننده‌ی داده‌شده به فهرستی از رشته‌ها تقسیم می‌کند.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` فهرستی از رشته‌ها را با جداکننده‌ی داده‌شده به هم می‌چسباند.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` همه‌ی رخدادهای یک زیررشته‌ی داده‌شده را جایگزین می‌کند.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` تعداد کاراکترهای یک رشته را برمی‌گرداند.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` می‌کوشد یک رشته را به `Just Int` تبدیل کند و برای رشته‌هایی که قالب درستی ندارند `Nothing` برمی‌گرداند.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` بررسی می‌کند که آیا رشته‌ی دوم رشته‌ی اول را در خود دارد یا نه.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` یک تابع داده‌شده را به هر `Char` در رشته اعمال می‌کند.
توجه کنید که تابع ارائه‌شده باید نگاشتی از `Char` به `Char` باشد.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
