# دستورالعمل‌ها

در این تمرین، شما یک هوادار پروپاقرص ورزش هستید و تازه شور و شوق بسکتبال NBA را در خود کشف کرده‌اید. چون تازه با بسکتبال NBA آشنا شده‌اید، در تاریخ NBA عمیق می‌شوید، تیم‌ها و مربی‌ها و آمار برد و باختشان را دنبال می‌کنید و آن‌ها را با هم مقایسه می‌کنید.

چون هنوز تیم محبوبی ندارید، الگوریتمی هم می‌سازید که مشخص کند آیا باید از یک تیم خاص هواداری کنید یا نه.

هفت کار پیش رو دارید که به شما کمک می‌کنند الگوریتم اختصاصی _هواداری کردن از یک تیم_ خودتان را بسازید.

## 1. مدل را تعریف کنید

رکورد `Coach` را با دو فیلد زیر تعریف کنید:

- `Name`: اسم مربی، از نوع `string`.
- `FormerPlayer`: نشان می‌دهد که مربی بازیکن پیشین بوده است یا نه، از نوع `bool`.

رکورد `Stats` را با دو فیلد زیر تعریف کنید:

- `Wins`: تعداد بردها، از نوع `int`.
- `Losses`: تعداد باخت‌ها، از نوع `int`.

رکورد `Team` را با سه فیلد زیر تعریف کنید:

- `Name`: اسم تیم، از نوع `string`.
- `Coach`: مربی تیم، از نوع `Coach`.
- `Stats`: آمار تیم، از نوع `Stats`.

## 2. مربی یک تیم را بسازید

تابع `createCoach` را پیاده‌سازی کنید که اسم مربی و وضعیت بازیکن پیشین بودن او را به‌عنوان پارامتر می‌گیرد و رکورد `Coach` آن را برمی‌گرداند:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. آمار یک تیم را بسازید

تابع `createStats` را پیاده‌سازی کنید که تعداد بردها و تعداد باخت‌ها را به‌عنوان پارامتر می‌گیرد و رکورد `Stats` آن را برمی‌گرداند:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. یک تیم بسازید

تابع `createTeam` را پیاده‌سازی کنید که اسم تیم، مربی و رکورد را به‌عنوان پارامتر می‌گیرد و رکورد `Team` آن را برمی‌گرداند:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. مربی را عوض کنید

چون مالکان NBA بی‌حوصله‌اند، متوجه شده‌اید که نتایج بد یک تیم اغلب به برکناری مربی می‌انجامد. تابع `replaceCoach` را پیاده‌سازی کنید که تیم و مربی جدیدش را به‌عنوان پارامتر می‌گیرد و همان تیم را با مربی جدید برمی‌گرداند:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. یکسان بودن تیم را بررسی کنید

وقتی در آمارها کاوش می‌کنید، فهرست‌هایی از تیم‌ها و رکوردهایشان نگه می‌دارید. گاهی اشتباه می‌کنید و ورودی‌های تکراری در فهرستتان پیدا می‌شود. تابع `isSameTeam` را پیاده‌سازی کنید که دو تیم می‌گیرد و اگر تیم یکسانی باشند `true` برمی‌گرداند؛ در غیر این صورت `false` برمی‌گرداند:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. بررسی کنید که آیا باید از یک تیم هواداری کنید

پس از بررسی تیم‌ها و مسابقه‌های زیادی، الگوریتمی ساخته‌اید. اگر یکی از موارد زیر درست باشد، از آن تیم هواداری می‌کنید:

- اسم مربی «Gregg Popovich» است
- مربی بازیکن پیشین بوده است
- اسم تیم «Chicago Bulls» است
- تیم ۶۰ بازی یا بیشتر برده است
- تیم باخت‌هایش بیشتر از بردهایش است

تابع `rootForTeam` را پیاده‌سازی کنید که یک تیم می‌گیرد و اگر باید از آن تیم هواداری کنید `true` برمی‌گرداند؛ در غیر این صورت، `false` را `return` کنید:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
