# پیوست دستورالعمل‌ها

## افزودن متدها به کلاس Array

این تمرین بر افزودن متدها به کلاس `Array` در Crystal تمرکز دارد.
برای این کار باید کلاسی با اسم `Array(T)` تعریف کنید.
و متدها را داخل این کلاس قرار دهید.

```crystal
class Array(T)
  # your solution here
end
```

کلاس آرایه یک کلاس [generic][] است و همچنین [indexable][] و [enumerable][] است.
کد منبع کلاس `Array` را می‌توان [اینجا][array] پیدا کرد.

[array]: https://github.com/crystal-lang/crystal/blob/7aa5cdd86/src/array.cr#L48
[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
