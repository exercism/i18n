# درباره

«کمبیناتور»ها الگوهای جابه‌جایی پشته را به «واژه»های نام‌گذاری‌شده و ترکیب‌پذیر تبدیل می‌کنند. وقتی به‌قدر کافی با Factor کد نوشته باشید، دیگر به این فکر نمی‌کنید که «باید `dup` کنم، بعد `F` را اجرا کنم و در آخر مقدار اصلی را نگه دارم»؛ در عوض فقط `[ F ] keep` را می‌نویسید.

| الگو                            | جابه‌جایی‌ها                      | کمبیناتور      |
|------------------------------------|-------------------------------|-----------------|
| اعمال `F` و حفظ ورودی            | `dup F swap`                  | `[ F ] keep`    |
| دو تابع روی یک ورودی         | `dup F swap G`                | `[ F ] [ G ] bi`|
| سه تابع روی یک ورودی       | پیچیده                         | `[ F ] [ G ] [ H ] tri` |
| چندین تابع روی یک ورودی    | خیلی پیچیده                    | `{ Fs … } cleave`|
| کار کردن روی مقادیر *زیر* بالای پشته  | `swap F swap`                 | `[ F ] dip`     |
| عملیات یکسان روی دو مقدار              | `swap F swap F`               | `[ F ] bi@`     |
| عملیات متفاوت روی دو مقدار        | `swap F swap G`               | `[ F ] [ G ] bi*`|

خانواده‌ی با پیشوند `2` (`2bi`، `2dip`، `2tri`، `2dup`، `2drop`، `2nip`، `2swap`) وقتی هر عملیات به *دو* ورودی نیاز دارد همین کار را انجام می‌دهد؛ `3dup` و `4dup` این الگوی تکرار را به سه یا چهار مقدار بالای پشته گسترش می‌دهند.

علاوه بر خانواده‌ی `cleave`/`dip`/`bi`، [`kernel`][kernel] هم گونه‌های کنترل جریان را ارائه می‌دهد که `f` را به‌تمیزی منتشر می‌کنند:

| واژه        | اثر                                              |
|-------------|-----------------------------------------------------|
| `if*`       | شاخه‌ی «درست» مقدار را می‌بیند، شاخه‌ی «غلط» آن را نمی‌بیند    |
| `?last`     | آخرین عنصر یک دنباله، یا `f` اگر خالی باشد         |
| `pop*`      | نسخه‌ی دوراندازِ `pop` (یک بردار را تغییر می‌دهد)      |
| `dupd`      | از دومین عنصر از بالای پشته یک نسخه برمی‌دارد                     |
| `pick`      | سومین عنصر از بالای پشته را به بالای پشته کپی می‌کند                |
| `swapd`     | دومین و سومین عنصر از بالای پشته را جابه‌جا می‌کند            |
| `rotd`      | سه عنصر پایینیِ یک پشته‌ی چهارعنصری را می‌چرخاند        |
| `tuck`      | بالاترین عنصر را زیر دومین عنصر از بالا کپی می‌کند              |
| `with`      | یک مقدار ثابت را برای HOS درون یک «نقل‌قول» جای می‌دهد         |
| `while`     | تا زمانی که یک «گزاره» برقرار است حلقه می‌زند                        |
| `until`     | حلقه می‌زند تا زمانی که یک «گزاره» برقرار شود                        |

انتخاب کمبیناتور مناسب خودش یک مهارت است. قاعده‌ی کلی این است: وقتی بدنه‌ی یک تعریف بیش از یک «واژه‌ی جابه‌جایی» پشت سر هم داشته باشد، معمولاً کمبیناتوری هست که منظور را بهتر بیان می‌کند.
