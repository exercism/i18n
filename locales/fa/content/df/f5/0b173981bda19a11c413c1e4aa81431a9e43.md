# مقدمه

## اعداد

در Python سه نوع مختلف از اعداد توکار وجود دارد: `ints`، `floats` و `complex`. اما در این تمرین فقط با `ints` و `floats` سر و کار خواهید داشت.

### ints

`ints` اعداد صحیح هستند. مثلاً `1234`، `-10` و `20201278`.

اعداد صحیح در Python دارای [دقت دلخواه][arbitrary-precision] هستند؛ تعداد ارقام تنها به حافظه‌ی در دسترس سیستم میزبان محدود می‌شود.

### floats

`floats` اعدادی هستند که نقطه‌ی اعشار دارند. مثلاً `0.0`، `3.14` و `-9.01`.

اعداد ممیز شناور معمولاً در Python با استفاده از `double` در C پیاده‌سازی می‌شوند (_۱۵ رقم اعشار دقت_)، اما نمایش آن‌ها بسته به سیستم میزبان و سایر جزئیات پیاده‌سازی متفاوت است. این موضوع هنگام کار با اعداد اعشاری می‌تواند غافلگیرکننده باشد، اما برای بیشتر موقعیت‌ها «به‌قدر کافی خوب» است.

## محاسبات

Python از محاسبات میان `ints` و `floats` به‌طور کامل پشتیبانی می‌کند. وقتی این اعداد با عملگرهای دودویی حساب (`+`، `-`، `*`، `/`، `//` و `%`) به کار می‌روند، اعداد باریک‌تر را به همتای پهن‌ترشان تبدیل می‌کند.

Python اعداد `ints` را باریک‌تر از `floats` در نظر می‌گیرد. بنابراین استفاده از یک عدد اعشاری در یک عبارت تضمین می‌کند که نتیجه هم اعشاری باشد. اما هنگام تقسیم، نتیجه همیشه اعشاری خواهد بود، حتی اگر فقط از اعداد صحیح استفاده شود.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

اگر به نتیجه‌ی صحیح نیاز دارید، می‌توانید از `//` برای حذف بخش اعشاری نتیجه استفاده کنید.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

برای تبدیل یک عدد اعشاری به عدد صحیح می‌توانید از `int()` استفاده کنید و برای تبدیل یک عدد صحیح به عدد اعشاری از `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
