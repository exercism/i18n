# دستورالعمل‌ها

شما یک پرنده‌نگر مشتاق هستید که تعداد پرندگانی را که در هفت روز گذشته به باغ‌تان آمده‌اند پیگیری می‌کنید.

شش کار دارید که همه‌شان به تعداد پرندگانی مربوط می‌شوند که به باغ‌تان آمده‌اند.

## 1. بررسی کنید تعداد پرندگان هفته‌ی گذشته چقدر بوده است

برای مقایسه، همیشه یک نسخه از تعداد پرندگان هفته‌ی گذشته را کنار دست‌تان نگه می‌دارید که عبارت بودند از: ۰، ۲، ۵، ۳، ۷، ۸ و ۴. متد `BirdWatcher.getLastWeek()` را پیاده‌سازی کنید که تعداد پرندگان هفته‌ی گذشته را برمی‌گرداند:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. بررسی کنید امروز چند پرنده آمده است

متد `BirdWatcher.getToday()` را پیاده‌سازی کنید تا تعداد پرندگانی را که امروز به باغ‌تان آمده‌اند برگرداند. تعداد پرندگان بر اساس روز مرتب شده است؛ اولین عنصر مربوط به قدیمی‌ترین روز است و آخرین عنصر تعداد امروز.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. تعداد امروز را افزایش دهید

متد `BirdWatcher.incrementTodaysCount()` را پیاده‌سازی کنید تا تعداد امروز را افزایش دهد:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. بررسی کنید آیا روزی بدون پرنده وجود داشته است

متد `BirdWatcher.hasDayWithoutBirds()` را پیاده‌سازی کنید که اگر روزی بوده است که هیچ پرنده‌ای به باغ نیامده باشد، `true` را برمی‌گرداند؛ در غیر این صورت `false` را برگردانید:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. محاسبه‌ی تعداد پرندگان بازدیدکننده در چند روز نخست

متد `BirdWatcher.getCountForFirstDays()` را پیاده‌سازی کنید که تعداد پرندگانی را برمی‌گرداند که از ابتدای هفته به باغ‌تان آمده‌اند، با این محدودیت که شمارش فقط برای تعداد مشخص‌شده از روزهای ابتدای هفته انجام شود.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. محاسبه‌ی تعداد روزهای شلوغ

بعضی روزها شلوغ‌تر از بقیه هستند. روز شلوغ روزی است که پنج پرنده یا بیشتر به باغ‌تان آمده باشند.
متد `BirdWatcher.getBusyDays()` را پیاده‌سازی کنید تا تعداد روزهای شلوغ را برگرداند:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
