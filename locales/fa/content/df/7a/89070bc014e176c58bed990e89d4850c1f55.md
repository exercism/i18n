# دستورالعمل

شما یک معلم هستید.
در پایان سال، برای هر یک از دانش‌آموزانتان یک نمره‌ی عددی ثبت کرده‌اید.
حالا باید آن را به نمره‌ی حرفی تبدیل کنید و بشمارید که چند دانش‌آموز هر نمره‌ی حرفی را گرفته‌اند

## 1. تبدیل نمره‌ی عددی به نمره‌ی حرفی

تابع `letter_grade` یک نمره‌ی عددی را به عنوان ورودی می‌گیرد و حرف را به عنوان خروجی برمی‌گرداند.
از این بازه‌ها استفاده کنید:

| حرف |      نمره |
| :----: | ---------: |
|   A    | ۹۰٪ - ۱۰۰٪ |
|   B    |  ۸۰٪ - ۸۹٪ |
|   C    |  ۷۰٪ - ۷۹٪ |
|   D    |  ۶۰٪ - ۶۹٪ |
|   F    |   ۰٪ - ۵۹٪ |

مثال:

```jq
75 | letter_grade   # => "C"
```

## 2. شمارش تعداد دانش‌آموزان برای هر نمره‌ی حرفی

تابع `count_letter_grades` یک شیء می‌گیرد که اسم دانش‌آموزان را به نمره‌هایشان نگاشت می‌کند.
خروجی یک شیء خواهد بود که هر نمره‌ی حرفی را به تعداد دانش‌آموزانی با آن نمره نگاشت می‌کند.

مثال:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

راه‌های متفاوتی برای حل این مسئله وجود دارد.
برای تمرین از فیلتر `reduce` استفاده کنید.
