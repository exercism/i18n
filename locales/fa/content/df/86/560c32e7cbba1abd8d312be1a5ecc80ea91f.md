# دستورالعمل‌ها

در آزمایشگاه تحقیقاتی DNA خود، راه‌های گوناگونی را برای فشرده‌سازی داده‌های پژوهش‌تان بررسی کرده‌اید تا فضای ذخیره‌سازی کمتری مصرف کنید. یکی از هم‌تیمی‌هایتان پیشنهاد می‌کند که داده‌های DNA را به نمایشی دودویی تبدیل کنید:

| Nucleic Acid | Code  |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

شما در این باره فکر می‌کنید، چون این کار به‌طور بالقوه هزینه‌ی ذخیره‌سازی داده‌ها را کم می‌کند، اما به بهای خوانایی کمتر برای انسان. تصمیم می‌گیرید ماژولی بنویسید که داده‌هایتان را رمزگذاری و رمزگشایی کند تا میزان صرفه‌جویی‌تان را بسنجید.

## 1. رمزگذاری اسید نوکلئیک به مقدار دودویی

تابع `encode_nucleotide` را پیاده‌سازی کنید تا یک نوکلئوتید بگیرد و مقدار صحیح کد رمزگذاری‌شده را برگرداند.

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. رمزگشایی مقدار دودویی به اسید نوکلئیک

تابع `decode_nucleotide` را پیاده‌سازی کنید تا مقدار صحیح کد رمزگذاری‌شده را بگیرد و نوکلئوتید را برگرداند.

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. رمزگذاری یک فهرست DNA

تابع `encode` را پیاده‌سازی کنید تا فهرستی از نوکلئوتیدها را بگیرد و آرایه‌ی بیتی داده‌های رمزگذاری‌شده را برگرداند.

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. رمزگشایی یک آرایه‌ی بیتی DNA

تابع `decode` را پیاده‌سازی کنید تا آرایه‌ی بیتی‌ای را که اسید نوکلئیک را نمایش می‌دهد بگیرد و داده‌های رمزگشایی‌شده را به‌صورت فهرستی از نوکلئوتیدها برگرداند.

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
