# مقدمه

کاراکتر و رشته، پایه‌ی نمایش متن در Elm هستند.
می‌توان به رشته‌ها به چشم لیستی از کاراکترها نگاه کرد و بیشتر توابع `List` معادل خود را در ماژول `String` دارند.

## کاراکتر

نوع `Char` یک کاراکتر یونیکد را با یک کوتیشن تک نشان می‌دهد، مثلاً `'a'`.
ماژول `Char` توابع محمولی (`Char -> Bool`) برای بررسی ویژگی‌های یک کاراکتر فراهم می‌کند: `isUpper`، `isLower`، `isAlpha` و `isAlphaNum`.
این ماژول همچنین توابعی برای تبدیل یک کاراکتر فراهم می‌کند: `toUpper`، `toLower`، `toLocaleUpper` و `toLocaleLower`، و نیز تبدیل به مقدار عددی یونیکد آن (`Int`) و از آن، با `toCode` و `fromCode`.

## رشته

نوع `String` یک نمایش توکار برای دستکاری کارآمد رشته فراهم می‌کند و می‌تواند هر دنباله‌ای از کاراکترهای یونیکد را نمایش دهد.
رشته‌ها با کوتیشن دوتایی نمایش داده می‌شوند: `"this is a string"`.
رشته‌های چندخطی با سه کوتیشن دوتایی نمایش داده می‌شوند و در آن‌ها می‌توان کوتیشن و خط جدید را بدون escape نوشت.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## دستکاری رشته

`reverse : String -> String` رشته را برعکس می‌کند.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` یک رشته را n بار تکرار می‌کند.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` همه‌ی رخدادهای یک زیررشته‌ی داده‌شده را جایگزین می‌کند.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` دو رشته را به هم می‌چسباند.
عملگر `++` هم می‌تواند همین کار را انجام دهد.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` یک لیست از رشته‌ها را به یک رشته‌ی واحد به هم می‌چسباند.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` یک رشته را در محل جداکننده‌ی داده‌شده به لیستی از رشته‌ها تقسیم می‌کند.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` یک لیست از رشته‌ها را با جداکننده‌ی داده‌شده به هم می‌چسباند.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` یک رشته را بر اساس تکه‌های فضای خالی به چند رشته تقسیم می‌کند.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` یک رشته را بر اساس خطوط جدید به خط‌ها تقسیم می‌کند.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` یک کاراکتر به ابتدای یک رشته اضافه می‌کند.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` یک رشته‌ی غیرخالی را به سر و ته آن تقسیم می‌کند.
این کار به شما امکان می‌دهد دقیقاً همان‌طور که با لیست‌ها عمل می‌کنید، روی رشته‌ها هم تطبیق الگو انجام دهید.
رشته‌های خالی `Nothing` برمی‌گردانند.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## استخراج زیررشته

`slice : Int -> Int -> String -> String` با داشتن اندیس شروع و پایان، یک زیررشته برمی‌گرداند.
اندیس‌های منفی از انتهای لیست شمرده می‌شوند.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` و `right : Int -> String -> String` به ترتیب n کاراکتر از سمت چپ یا راست رشته برمی‌دارند.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` و `dropRight : Int -> String -> String` به ترتیب n کاراکتر از سمت چپ یا راست یک رشته حذف می‌کنند.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## بررسی ویژگی‌های رشته

`length : String -> Int` تعداد کاراکترهای یک رشته را برمی‌گرداند.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` مشخص می‌کند که آیا یک رشته خالی است یا نه.
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` بررسی می‌کند که آیا رشته‌ی دوم رشته‌ی اول را در خود دارد یا نه.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` و `endsWith : String -> String -> Bool` بررسی می‌کنند که آیا رشته‌ی دوم با یک زیررشته‌ی داده‌شده شروع یا تمام می‌شود یا نه.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` لیستی از همه‌ی اندیس‌های شروع یک زیررشته در رشته‌ای دیگر را به دست می‌آورد.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## تبدیل رشته
`toInt : String -> Maybe Int` تلاش می‌کند یک رشته را به `Just Int` تبدیل کند و برای رشته‌های با قالب نادرست `Nothing` برمی‌گرداند.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` یک عدد صحیح را به رشته تبدیل می‌کند.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` تلاش می‌کند یک رشته را به یک عدد اعشاری تبدیل کند و برای رشته‌های با قالب نادرست شکست می‌خورد.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` یک عدد اعشاری را به رشته تبدیل می‌کند.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` و `fromList : List Char -> String` به ترتیب یک رشته را به لیستی از کاراکترها و برعکس تبدیل می‌کنند.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` یک کاراکتر را به رشته تبدیل می‌کند.
```elm
fromChar 'a' 
    --> "a"
```

## قالب‌بندی رشته

`toUpper : String -> String` و `toLower : String -> String` به ترتیب رشته‌ها را به همه‌حروف بزرگ یا همه‌حروف کوچک تبدیل می‌کنند.
برای مقایسه‌های بدون حساسیت به بزرگی و کوچکی حروف مفیدند.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` یک رشته را از دو طرف با `Char` داده‌شده پر می‌کند تا به طول داده‌شده برسد.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
به همین ترتیب، `padLeft` و `padRight` یک رشته را از هر طرف پر می‌کنند تا به طول داده‌شده برسد.

`trim : String -> String` فضای خالی دو طرف یک رشته را حذف می‌کند.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` و `trimRight` فضای خالی هر طرف یک رشته را حذف می‌کنند.

## توابع مرتبه‌بالا

`map : (Char -> Char) -> String -> String` هر کاراکتر یک رشته را با تابع داده‌شده تغییر می‌دهد.
توجه کنید که تابع ارائه‌شده باید نگاشتی از `Char` به `Char` باشد.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` فقط کاراکترهایی را نگه می‌دارد که آزمون را با موفقیت پشت سر می‌گذارند.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` یک رشته را از سمت چپ کاهش می‌دهد.
این تابع با اولین کاراکتر به‌عنوان پارامتر اول و یک مقدار اولیه‌ی داده‌شده به‌عنوان پارامتر دوم فراخوانی می‌شود.
نتیجه‌ی تابع باید هم‌نوع با مقدار اولیه‌ی داده‌شده باشد و به ترتیب روی هر کاراکتر اعمال می‌شود.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` همین کار را انجام می‌دهد، اما از سمت راست رشته شروع می‌کند.

`any : (Char -> Bool) -> String -> Bool` مشخص می‌کند که آیا کاراکتری وجود دارد که به محمول داده‌شده `True` برگرداند.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` مشخص می‌کند که آیا همه‌ی کاراکترهای یک رشته به محمول داده‌شده `True` برمی‌گردانند.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
