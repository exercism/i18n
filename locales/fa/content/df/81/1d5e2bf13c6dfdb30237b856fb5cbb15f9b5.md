# درباره

Common Lisp Printer امکانی برای خروجی دادن داده به «جریان»هاست. یک تابع رایج در این امکان `format` است.

`format` دو پارامتر ضروری می‌گیرد: یک جریان برای نوشتن و یک رشته‌ی کنترلی. محتوای رشته‌ی کنترلی تعیین می‌کند که آرگومان‌های بعدی چگونه استفاده می‌شوند.

پارامتر اول دو مقدار ویژه دارد: `t` و `nil`. `t` نشان می‌دهد که باید از جریانی که به `*standard-output*` متصل است استفاده شود و `nil` نشان می‌دهد که باید رشته‌ای ایجاد و بازگردانده شود. `format` به `nil` ارزیابی می‌شود مگر اینکه پارامتر جریان `nil` باشد.

رشته‌ی کنترلی می‌تواند شامل دستورهای قالب باشد که با یک `~` و سپس یک کاراکتر مشخص می‌شوند (بزرگ یا کوچک بودن حرف مهم نیست). دستور قالب تعیین می‌کند که آیا آرگومانی مصرف می‌شود و چگونه به جریان قالب‌بندی می‌شود.

دستورهای قالب پایه‌ی مهم عبارت‌اند از:

* `~A` - _زیبایی‌شناسانه_ قالب‌بندی می‌کند به شکلی «قابل خواندن برای انسان».
* `~S` - به شکل _استاندارد_ قالب‌بندی می‌کند تا «قابل خواندن برای ماشین» باشد.
* `~%` - یک خط جدید تولید می‌کند.
* `~&` - یک خط جدید تولید می‌کند مگر اینکه از قبل در ابتدای خط باشیم.
* `~~` - یک تیلدا تولید می‌کند.

مثال‌ها:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
