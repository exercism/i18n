# دستورالعمل‌ها

در این تمرین، یک سیستم موجودی را مدیریت می‌کنید.

موجودی باید بر اساس اسم کالا سازمان‌دهی شود و تعداد کالاهای موجود را پیگیری کند.

باید افزودن کالا به موجودی را مدیریت کنید.
هر بار که یک کالا در بردار داده‌شده ظاهر می‌شود، تعداد آن کالا در موجودی باید `1` واحد افزایش یابد.
همچنین باید حذف کالا از موجودی را مدیریت کنید، به این صورت که وقتی درخواست می‌شود، تعدادها `1` واحد کاهش یابند.

در پایان، باید تابعی پیاده‌سازی کنید که همه‌ی جفت‌های کلید-مقدار یک موجودی داده‌شده را به صورت یک `vector` از `pair`ها برگرداند.

~~~~exercism/note
آزمون‌های این تمرین به اینکه داده‌ها را تغییر بدهید یا نه کاری ندارند، اما اسم توابع نشان می‌دهد که نباید داده‌ها را تغییر دهند.
اگر می‌خواهید از توابعی که در مقدمه آمده استفاده کنید و در همان حال ورودی را تغییر ندهید، تابع `copy()` به کارتان می‌آید.
~~~~

## 1. ساخت یک موجودی بر پایه‌ی یک بردار

تابع `create_inventory(<input vector>)` را پیاده‌سازی کنید که یک «موجودی» از یک بردار ورودی از کالاها می‌سازد.
این تابع باید یک `dict` برگرداند که در آن اسم هر کالا همراه با تعداد مربوط به آن آمده است.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. افزودن کالاها از یک بردار به یک دیکشنری موجود

تابع `add_items(<inventory dict>, <item vector>)` را پیاده‌سازی کنید که برداری از کالاها را به موجودی داده‌شده اضافه می‌کند:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. کاهش تعداد کالاها در موجودی

تابع `decrement_items(<inventory dict>, <items vector>)` را پیاده‌سازی کنید که یک `vector` از کالاها می‌گیرد.
تابع شما باید برای هر بار که یک کالا در `vector` ظاهر می‌شود، `1` واحد از تعداد آن کالا کم کند:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

تعداد کالاها در موجودی نباید اجازه داشته باشد که به کمتر از ۰ برسد.
اگر تعداد دفعاتی که یک کالا در `vector` ورودی ظاهر می‌شود از تعداد موجود بیشتر باشد، مقدار ثبت‌شده برای آن کالا باید ۰ بماند.
وقتی تعداد به صفر رسید، درخواست‌های بعدی برای کم کردن تعداد نادیده گرفته می‌شود.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. حذف کامل یک عضو از موجودی

تابع `remove_item(<inventory dict>, <item>)` را پیاده‌سازی کنید که یک کالا و تعدادش را به طور کامل از موجودی حذف می‌کند:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

اگر کالا در موجودی پیدا نشود، تابع باید موجودی اصلی را بدون تغییر برگرداند.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. برگرداندن کل محتوای موجودی

تابع `list_inventory(<inventory dict>)` را پیاده‌سازی کنید که یک موجودی می‌گیرد و برداری از جفت‌های `(item, quantity)` برمی‌گرداند.

این بردار باید فقط شامل کالاهای _موجود_ (_یعنی کالاهایی با تعدادی بیشتر از صفر_) باشد و بر اساس ترتیب الفبایی کالاها مرتب شود:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
