# نصب

## پیش‌نیازها

مسیر زبان C++ نیازمند آن است که نرم‌افزارهای زیر روی سیستم شما نصب باشند:
* یک کامپایلر مدرن C++14
* سیستم ساخت چندسکویی CMake

ما برای تست از [Catch2](https://github.com/catchorg/Catch2) استفاده می‌کنیم که یک کتابخانه‌ی header-only است و همراه تمرین‌ها ارائه می‌شود.

این مجموعه از وابستگی‌ها برای پروژه‌های C++ بسیار رایج است، بنابراین اگر در راه‌اندازی آن به مشکلی برخوردید، منابع مفید زیادی را به‌صورت آنلاین پیدا خواهید کرد.

بسیاری از IDEها، از جمله Visual Studio مایکروسافت، Xcode اپل و CLion جت‌برینز، یک کامپایلر و CMake را با هم ارائه می‌دهند، بنابراین باید فقط خود IDE را نصب کنید.

### یک کامپایلر مدرن C++14

این مسیر زبان به کامپایلری نیاز دارد که از [C++14](http://en.wikipedia.org/wiki/C%2B%2B14) پشتیبانی کند؛ این نسخه در سال ۲۰۱۴ منتشر شد. همه‌ی کامپایلرهای اصلی که در چند سال گذشته منتشر شده‌اند باید سازگار باشند، بنابراین تا زمانی که از نسخه‌ی نسبتاً جدیدی استفاده می‌کنید مشکلی نخواهید داشت. به‌طور مشخص، GCC نسخه‌ی ۷ یا جدیدتر، Clang نسخه‌ی ۶ یا جدیدتر، یا Visual Studio 2017 یا جدیدتر.

### CMake

CMake یک سیستم ساخت متن‌باز و چندسکویی است که اسکریپت‌های ساخت را برای سیستم ساخت بومی شما (`make`، Visual Studio، Xcode و غیره) تولید می‌کند. مسیر C++ در Exercism از CMake استفاده می‌کند تا یک ساخت آماده در اختیارتان بگذارد که:

* تست‌ها را کامپایل می‌کند
* راه‌حل شما را کامپایل می‌کند
* فایل اجرایی تست را پیوند می‌دهد
* تست‌ها را به‌طور خودکار به‌عنوان بخشی از هر ساخت اجرا می‌کند
* اگر هر یک از تست‌ها شکست بخورد، ساخت را با شکست مواجه می‌کند

استفاده از CMake به Exercism امکان می‌دهد اسکریپت ساخت چندسکویی ارائه دهد که می‌تواند فایل‌های پروژه را برای محیط‌های توسعه‌ی یکپارچه مانند Visual Studio و Xcode تولید کند. این به شما امکان می‌دهد روی مسئله تمرکز کنید و نگران راه‌اندازی ساخت برای هر تمرین نباشید.

داشتن یک ساخت قابل انتقال آسان نیست و نیازمند دسترسی به انواع مختلفی از سیستم‌هاست. اگر با مجموعه‌ی ساخت CMake ارائه‌شده به مشکلی برخوردید، لطفاً [این مشکل را گزارش دهید](https://github.com/exercism/cpp/issues) تا بتوانیم پشتیبانی از CMake را بهبود دهیم.

برای استفاده از مجموعه‌ی ساخت ارائه‌شده، [CMake 3.5.1 یا جدیدتر](http://www.cmake.org/) لازم است.

## ویندوز

کاربران ویندوز می‌توانند [Visual Studio Community](https://www.visualstudio.com/vs/community/) را دریافت کنند؛ دانلودی رایگان که IDE ویژوال استودیو و آخرین نسخه‌ی کامپایلر Microsoft Visual C++ را در اختیارتان می‌گذارد.

1. برای راه‌اندازی CMake، [دستورالعمل‌های اینجا](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) را دنبال کنید.
1. تمرین را با ابزار [exercism cli](https://exercism.io/cli-walkthrough) دانلود کنید.
1. Visual Studio 2017 یا بالاتر را باز کنید (با ابزارهای Visual C++ برای CMake که طبق توضیح لینک بالا نصب شده‌اند).
1. پوشه‌ی تمرین را در VS باز کنید.
1. گزینه‌ی «Build->Build the solution» را اجرا کنید. تست‌ها همراه با ساخت اجرا می‌شوند و خروجی به پنجره‌ی ساخت می‌رود. چون تست‌ها در حین ساخت اجرا می‌شوند، اگر یکی از تست‌ها شکست بخورد، VS آن را به‌عنوان شکست ساخت گزارش می‌دهد و پیام‌های شکست تست در پنجره‌ی خروجی ساخت نمایش داده می‌شوند.

باید بتوانید سایر IDEهای یکپارچه مانند CLion جت‌برینز را نیز به روشی مشابه استفاده کنید.

### نصب Boost روی ویندوز

تمرین‌های `meetup` و `gigasecond` به کتابخانه‌های [Boost][boost-website] وابسته‌اند. مراحل زیر نحوه‌ی راه‌اندازی آن را توضیح می‌دهد.

1. [کتابخانه‌های پیش‌ساخته‌ی ویندوز][sourceforge-boost-binaries] را برای Boost دانلود کنید.
   - تمرین‌ها حداقل نسخه‌ی 1.58 از Boost را لازم دارند.
   - می‌توانید با کلیک روی «Modify» در Visual Studio Installer نسخه‌ی MSVC را پیدا کنید.
1. کتابخانه‌ها را در یک پوشه‌ی محلی استخراج کنید.
1. متغیر محیطی `BOOST_ROOT` را روی پوشه‌ای تنظیم کنید که کتابخانه‌های Boost را در آن نصب کرده‌اید.
1. اگر در حین این کار Visual Studio باز بود، آن را ببندید تا مطمئن شوید مقدار `BOOST_ROOT` خوانده می‌شود.
1. Visual Studio را اجرا کنید و پوشه‌ی حاوی تمرین `gigasecond` یا `meetup` را باز کنید.
1. «Startup Item» باید `gigasecond.exe` یا `meetup.exe` باشد و باید خطاهای ساخت را در `gigasecond_test.cpp` یا `meetup_test.cpp` ببینید که به شما می‌گویند موارد پیاده‌سازی‌نشده را پیاده‌سازی کنید، مشابه سایر تمرین‌ها.

## لینوکس

همه‌ی نسخه‌های اخیر توزیع‌های لینوکس کامپایلرهای سازگار با C++14 دارند؛ باید بتوانید آن را با مدیر بسته‌ی خودتان نصب کنید. نسخه‌هایی که ما پشتیبانی می‌کنیم، نسخه‌های نصب‌شده‌ی پیش‌فرض در Ubuntu LTS 18.04 هستند.

برای مثال، روی Ubuntu از دستور زیر برای نصب gcc استفاده می‌کنید.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

اگر از یک توزیع قدیمی‌تر استفاده می‌کنید، ممکن است کامپایلری نداشته باشید که از C++14 پشتیبانی کند. در این صورت، باید با توزیع خود کار کنید تا بفهمید چگونه حداقل نسخه‌ی کامپایلر را نصب کنید.

## MacOS

کاربران MacOS می‌توانند GCC را با [Homebrew](http://brew.sh/) از طریق `brew install gcc` نصب کنند.
