# مقدمه‌ای بر حلقه‌ها

Bash دو شکل حلقه دارد:

* تکرار چند دستور _برای هر عنصر در فهرستی از عناصر_،
* تکرار چند دستور _تا زمانی که شرطی «درست» (یا «غلط») باشد_.

## حلقه‌های For

برای پیمایش فهرستی از عناصر، از حلقه‌ی `for` استفاده می‌کنیم.

```bash
for varname in words; do COMMANDS; done
```

`words` با تقسیم‌بندی واژه‌ها و بسط نام فایل باز می‌شود (همان‌هایی که در [مفهوم Quoting][quoting] با آن‌ها آشنا شدیم).
هر واژه به‌نوبت به `varname` نسبت داده می‌شود و COMMANDS اجرا می‌شوند.

در ادامه چند مثال می‌آوریم که نشان می‌دهد حلقه‌ی For کجا می‌تواند مفید باشد

* اجرای چند دستور روی گروهی از فایل‌ها.

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* اجرای دستوری روی هر یک از پارامترهای یک اسکریپت یا تابع.

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* اجرای دستوری برای هر واژه‌ی جداشده با فضای سفید در خروجی یک دستور.

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    در ادامه درباره‌ی این سبک هشدارهایی خواهیم دید.

### حلقه‌ی For حسابی

Bash یک حلقه‌ی حسابی هم دارد.
این شکل برای کسانی که با زبان‌های برنامه‌نویسی دیگر آشنا هستند تا حدی آشنا به نظر می‌رسد.

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

پرانتزهای دوتایی در bash یک بافت حسابی را نشان می‌دهند (در مفهومی دیگر درباره‌ی حساب در bash بیشتر خواهیم دید).
مثال بالا با `seq` را می‌توان این‌گونه نوشت

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### چه زمانی از For استفاده نکنیم

[خطوط را با `for` نخوانید][bashfaq1].

این یک «ضدالگو» است که زیاد می‌بینید: پیمایش روی خروجی `cat`.

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

این کار از ۲ نظر نادرست است.

1. جانشینی دستور بدون کوتیشن است، پس مشمول تقسیم‌بندی واژه‌ها می‌شود.
   تقسیم‌بندی واژه‌ها به‌طور پیش‌فرض روی _فضای سفید_ انجام می‌شود و نه فقط روی خطوط جدید.
   این حلقه‌ی For روی **واژه‌های** فایل پیمایش می‌کند، نه خطوط آن.
2. جانشینی دستور بدون کوتیشن است، پس مشمول بسط نام فایل می‌شود.
   هر واژه در فایل به‌عنوان یک الگوی glob تطبیق داده می‌شود.

همان‌طور که در [مفهوم Quoting][quoting] یاد گرفتیم، می‌توان تقسیم‌بندی واژه‌ها را با متغیر `IFS` کنترل کرد و بسط نام فایل را غیرفعال کرد.
اما این معمولاً راه‌حل شکننده‌ای است.
`for` روش نادرستی برای پیمایش خطوط یک فایل است.
روش اصطلاحی خواندن یک فایل، استفاده از حلقه‌ی `while` است.

## حلقه‌های While

برای تکرار دنباله‌ای از دستورها _تا زمانی که_ شرطی «درست» باشد، از `while` استفاده کنید.

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

مانند `if` (همان‌طور که در [مفهوم Conditionals][conditionals] یاد گرفتیم)، برای CONDITION_COMMANDS نگارش خاصی وجود ندارد.
وضعیت خروج فهرست دستورها مشخص می‌کند «درست» است یا «غلط».

## کنترل حلقه‌ها

دستور `break` از حلقه بیرون می‌پرد.
اجرا از دستوری که بعد از پایان‌دهنده‌ی `done` حلقه می‌آید ادامه پیدا می‌کند.

دستور `continue` به تکرار بعدی حلقه می‌پرد.

## خواندن خطوط یک فایل

همان‌طور که اشاره شد، حلقه‌ی while روش اصطلاحی خواندن یک فایل است. 

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* محتوای فایل با تغییرمسیر `<` به‌عنوان ورودی به حلقه داده می‌شود.
* دستور `read` اگر بتواند یک خط کامل را از ورودی‌اش بخواند، «درست» برمی‌گرداند.
  وقتی ورودی تمام شود، یا اگر آخرین خط بدون خط جدید پایانی تمام شود، read «غلط» را برمی‌گرداند.
  * روش _واقعاً_ اصطلاحی خواندن خطوط یک فایل، حتی وقتی آخرین خط با خط جدید پایان نمی‌یابد، این است

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* گزینه‌ی `-r` به `read` می‌گوید که دنباله‌های بک‌اسلش را جایگزین نکند: بک‌اسلش فقط یک نویسه‌ی معمولی است.
* `IFS=` رشته‌ی خالی را فقط برای مدت اجرای دستور read به IFS نسبت می‌دهد.
  این کار تقسیم‌بندی واژه‌ها را موقتاً خاموش می‌کند تا هر فضای سفید ابتدا یا انتهای خط ورودی حفظ شود.

## حلقه‌ی Until

ساختار `until` دنباله‌ای از دستورها را تا زمانی که شرطی **«غلط»** باشد تکرار می‌کند.
حلقه _تا زمانی که_ شرط «درست» شود تکرار می‌شود.

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

استفاده از `until` کم پیش می‌آید.
استفاده از حلقه‌ی «while not» رایج‌تر است.

```bash
while ! CONDITION_COMANDS; do ...
```

## حلقه‌های بی‌نهایت

بعضی وقت‌ها می‌خواهید تا بی‌نهایت حلقه بزنید.
۲ راه برای این کار وجود دارد.

1. یک حلقه‌ی while با شرطی که همیشه وضعیت خروج موفق دارد

    ```bash
    while true; do ...
    ```

2.  یک حلقه‌ی For حسابی با عبارت‌های خالی

    ```bash
    for ((;;)); do ...
    ```

## حلقه‌ی Do-While

ساختار صریحی برای do-while وجود ندارد، اما می‌توانید همان اثر را به دست آورید:

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
