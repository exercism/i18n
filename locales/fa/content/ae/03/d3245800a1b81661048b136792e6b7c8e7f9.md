[مقادیر «منطقی»][booleans] در Haxe با نوع `Bool` نمایش داده می‌شوند که مقادیر آن می‌تواند `true` یا `false` باشد.

Haxe از سه [عملگر منطقی][operators] پشتیبانی می‌کند: `!` (نقیض یکانی)، `&&` (و دوتایی) و `||` (یا دوتایی).

عبارت‌های منطقی ترکیبی (`&&` و `||`) از ارزیابی _اتصال کوتاه_ استفاده می‌کنند، که در آن عبارت‌ها از چپ به راست ارزیابی می‌شوند، اما فقط تا جایی که لازم است. این موضوع در مواردی مانند مورد زیر اهمیت دارد:

```haxe
object != null && object.field == x
```

اولین بررسی منطقی تضمین می‌کند که `object.field` تنها در صورتی مورد دسترسی قرار می‌گیرد که `object` برابر `null` نباشد و این کار از بروز خطای زمان اجرا جلوگیری می‌کند.

سه عملگر منطقی تقدم متفاوتی دارند و به این ترتیب ارزیابی می‌شوند: `!` -> `&&` -> `||`.

قرار دادن عبارت‌ها در پرانتز `()` امکان نادیده گرفتن این قواعد تقدم را فراهم می‌کند، چون پرانتز تقدم بالاتری دارد.

```haxe
!true && false   // => false
!(true && false) // => true
```
