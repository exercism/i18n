# مقدمه

در Haxe از `Iterator` برای پیمایش یک مقدار با یک «حلقه‌ی `for`» استفاده می‌شود. دو نوع `Iterator` وجود دارد:

- `Iterator` که روی یک مقدار پیمایش می‌کند.
- داده‌ی `Iterable` که امکان پیمایش روی یک نوع داده را فراهم می‌کند.

هر دوی این مفاهیم با `Iterator<T>` و `Iterable<T>` نمایش داده می‌شوند:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

هر کلاسی که با یکی از این نوع‌ها همخوانی داشته باشد، می‌توان با یک حلقه‌ی `for` روی آن پیمایش کرد. اگر کلاسی متدهای `hasNext` و `next` را تعریف کند، یک `Iterator` در نظر گرفته می‌شود؛ در غیر این صورت، اگر متد `iterator` را تعریف کند، یک نوع `Iterable` در نظر گرفته می‌شود.
