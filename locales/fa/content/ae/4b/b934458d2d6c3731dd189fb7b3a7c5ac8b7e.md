# مقدمه

دستورهای شرطی در C++ مشابه دستورهای شرطی در زبان‌های دیگر هستند.
نوع زیربنایی هر عملیات شرطی، نوع `bool` است که می‌تواند مقدار `true` یا `false` داشته باشد.
از دستورهای شرطی اغلب به‌عنوان سازوکارهای کنترل جریان برای بررسی شرط‌های مختلف استفاده می‌شود.

می‌توان از دستور `if` استفاده کرد که اگر شرط زیربنایی `true` باشد، کدش را اجرا می‌کند، مثل این:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

در موقعیت‌هایی که بیش از یک حالت درگیر است، می‌توان چندین دستور `if` را با استفاده از دستورهای `else if` و `else` به هم زنجیر کرد.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

از C++17 به بعد، دستورهای `if` می‌توانند یک دستور مقداردهی اولیه‌ی کوتاه هم داشته باشند که با آن می‌توان یک یا چند متغیر را برای دستور `if` مقداردهی اولیه کرد.
برای مثال:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> نکته: هیچ‌یک از متغیرهایی که در مقداردهی اولیه ساخته می‌شوند، پس از پایان دستور `if` قابل دسترسی نیستند.
