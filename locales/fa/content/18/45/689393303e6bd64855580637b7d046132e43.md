# Debugging به‌صورت محلی

وقتی Testهای مسیر Bash را با [Bats](https://github.com/bats-core/bats-core) اجرا می‌کنید، Bats هم STDOUT و هم STDERR را برای ادعاهای خروجی ثبت می‌کند.

```exercism/caution
این کار به‌صورت محلی با `bats` انجام می‌شود، اما در ویرایشگر آنلاین Exercism **کار نمی‌کند**.
```

اگر می‌خواهید خروجی Debug را بدون تأثیر گذاشتن بر نتیجه‌ی Test چاپ کنید، آن را در توصیف‌گر فایل (fd) ۳ بنویسید.

```bash
echo 'debug message' >&3
```

Bats خروجی نوشته‌شده در fd ۳ را در طول اجرای Test نشان می‌دهد، اما آن خروجی را در ادعاهایی مانند `assert_output` لحاظ نمی‌کند.

نمونه‌ی اجرا:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

این زمانی مفید است که Testها را به‌صورت محلی اجرا می‌کنید.
