# درباره

[_پارامترهای متغیر_][variadic-parameters] به یک تابع اجازه می‌دهند تا صفر یا چند مقدار از یک نوع مشخص را برای یک پارامتر واحد بپذیرد.
پارامتر متغیر را با افزودن سه نقطه (`...`) به اعلان نوع پارامتر تعریف می‌کنید.

در بدنه‌ی تابع، Swift این مقادیر را به‌صورت یک «آرایه» از نوع مشخص در دسترس قرار می‌دهد:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
اگر یک تابع بعد از یک پارامتر متغیر پارامترهای دیگری داشته باشد، اولین پارامتری که بعد از پارامتر متغیر می‌آید **باید** یک «برچسب آرگومان» صریح داشته باشد تا Swift بداند فهرست آرگومان‌های متغیر کجا تمام می‌شود.
~~~~
