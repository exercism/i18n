# دستورالعمل‌ها

شما در یک فروشگاه اینترنتی پوشاک مد کار می‌کنید.
ایده‌ی یک قابلیت برای وب‌سایت به ذهنتان می‌رسد که در آن ست‌های لباس به کاربر پیشنهاد می‌شود.
آنچه برایتان مهم است، ست‌های بالقوه، قیمت آن‌ها و حذف گزینه‌های ناهماهنگ است.

## 1. ساختن قطعه‌ی لباس


تابع `clothingitem()` را پیاده‌سازی کنید تا دو `Tuple` بگیرد، یکی از `categories` و دیگری از `qualities` متناظرشان.
تابع باید یک `Dict` برگرداند که `categories` کلیدهای آن و `qualities` مقادیر آن هستند.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

تابع شما باید بتواند هر تعداد `categories` را مدیریت کند.

## 2. پیشنهاد ترکیب‌ها

تابع `get_combinations()` را پیاده‌سازی کنید تا یک `Tuple` از بالاتنه‌ها و یک `Tuple` از پایین‌تنه‌ها بگیرد.
تابع باید `cartesian product` این `Tuple`ها را به‌صورت یک آرایه‌ی دوبعدی (یعنی `Matrix`) برگرداند.
هر عنصر یک ترکیب `(top, bottom)` از نوع `Tuple` است.
بالاتنه‌ها در سطرها و پایین‌تنه‌ها در ستون‌ها تغییر می‌کنند.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. جمع زدن قیمت ست‌ها

هر قطعه‌ی لباس یک فیلد `price` دارد، بنابراین ممکن است مفید باشد که بتوان قیمت کامل ست‌ها را با هم مقایسه کرد.
تابع `get_prices()` را پیاده‌سازی کنید که یک آرایه از ترکیب‌های لباس می‌گیرد.
تابع باید آرایه‌ای با همان شکل برگرداند که قیمت هر ست در جایگاه مربوط به خودش قرار دارد.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. حذف ست‌های ناهماهنگ

هر قطعه‌ی لباس یک فیلد `base_color` دارد.
از این فیلد استفاده کنید تا همه‌ی ترکیب‌هایی را حذف کنید که بالاتنه و پایین‌تنه‌ی آن‌ها رنگ پایه‌ی یکسان دارند.
تابع `filter_clashing()` را پیاده‌سازی کنید تا یک آرایه از ترکیب‌های لباس بگیرد.
یک آرایه‌ی یک‌بعدی (یعنی `Vector`) از ترکیب‌های منطبق برگردانید.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
