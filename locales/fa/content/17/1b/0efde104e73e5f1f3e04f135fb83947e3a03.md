# مقدمه

«رابط» نوعی است که اعضای آن، مجموعه‌ای از قابلیت‌های مرتبط را تعریف می‌کنند.
رابط، استفاده از یک کلاس را از پیاده‌سازی آن جدا می‌کند و به این ترتیب امکان چند پیاده‌سازی متفاوت، یا پشتیبانی از رفتاری جنریک مانند قالب‌بندی، مقایسه یا تبدیل را فراهم می‌آورد.

نحوه‌ی نگارش یک رابط شبیه نحوه‌ی نگارش یک کلاس است، با این تفاوت که متدها فقط در قالب امضا ظاهر می‌شوند و بدنه‌ی آن‌ها ارائه نمی‌شود.

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

کلاسی که یک رابط را پیاده‌سازی می‌کند، باید همه‌ی عملیات تعریف‌شده در آن را پیاده‌سازی کند.

رابط‌ها معمولاً متدهای نمونه‌ای دارند.

نمونه‌ای دیگر از یک رابط در کتابخانه‌ی کلاس‌های Java، جدا از `Cloneable` که در بالا دیدیم، `Comparable<T>` است.
رابط `Comparable<T>` را می‌توان در جایی پیاده‌سازی کرد که به یک ترتیب مرتب‌سازی جنریک پیش‌فرض در مجموعه‌ها نیاز باشد.
