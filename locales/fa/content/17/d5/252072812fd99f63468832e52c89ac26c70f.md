# پیوست دستورالعمل

## پیاده‌سازی

استفاده از قابلیت‌های اصلی زبان برای ساختن و از هم باز کردن آرایه‌ها از طریق `destructuring`، و همچنین استفاده از لیترال آرایه‌ی `[]` مجاز است، اما نباید از هیچ‌یک از توابع `Array.prototype` استفاده کنید.

برای اینکه بتوانید راه‌حل خود را تست کنید، مطمئن شوید که `forEach` پیاده‌سازی شده است.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
