# دستورالعمل‌ها

در حال پیاده‌سازی یک سیستم پایش سلامت هستید. به‌عنوان بخشی از این کار، باید آمار سلامت کاربران را پیگیری کنید.

کار را با چند تابع ناتمام در یک بلوک `impl` و همچنین تعریف `struct` زیر آغاز می‌کنید:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

هدف شما پیاده‌سازی متدهای ناتمام `struct`ی به اسم `User` است که در بلوک `impl` تعریف شده است.

برای مثال، متد `new` باید نمونه‌ای از `struct` به اسم `User` را با اسم، سن و وزن مشخص‌شده برگرداند.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

متد `weight` باید وزن `User` را برگرداند.

```rust
bob.weight();
// Returns: 155.2
```

متد `set_age` باید سن `User` را تنظیم کند.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

خوش بگذرانید!
