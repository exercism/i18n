# دستورالعمل‌های مخصوص SQLite

ستون‌های **list_one** و **list_two** شامل فهرستی از اعداد صحیح کدگذاری‌شده با JSON هستند.

مثال:

```json
[1, 2, 3]
```

## ساختار جدول

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
