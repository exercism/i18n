# درباره

متدها می‌توانند پارامتری varargs داشته باشند که به فراخوان اجازه می‌دهد صفر یا چند آرگومان را مثل پارامترهای معمولی مشخص کند. متد این آرگومان‌ها را به‌صورت یک آرایه دریافت می‌کند.

برای اینکه یک پارامتر را به پارامتر varargs تبدیل کنید، [«کلیدواژه‌ی `params`»](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) را به اعلان پارامتر اضافه کنید:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
