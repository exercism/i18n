# مقدمه

تابع `switch()` می‌تواند جایگزینی مختصر برای مجموعه‌ای طولانی از شرط‌های `if` ... `else if` باشد.
متغیری که روی آن سوئیچ انجام می‌شود معمولاً یک رشته است و در این صورت می‌توان کوتیشن‌ها را از انتخابگر حذف کرد.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

توجه کنید که گزینه‌ها فقط زمانی به گزینه‌ی بعدی می‌رسند که مقدار خالی گذاشته شده باشد، مانند `M` در مثال بالا.
لازم نیست دستورهای `break` را مانند برخی زبان‌های دیگر بگنجانید.

وقتی روی نوع‌های `character` سوئیچ می‌کنید، مقدار نهایی یک پیش‌فرض است، همان‌طور که اینجا می‌بینید.
با نوع‌های عدد صحیح، هیچ پیش‌فرضی نمی‌توان داد.

## توابع در `dplyr`

`switch` در R پایه نسبتاً محدود است: فقط تطبیق دقیق با یک ورودی واحد را انجام می‌دهد.
این در سال ۱۹۹۳ که R برای اولین بار منتشر شد معقول به نظر می‌رسید، اما برای استفاده‌ی مدرن نیاز به بهبود دارد.

~~~~exercism/note
همان‌طور که در مفهوم [`Conditionals`][concept-conditionals] اشاره شد، مجموعه‌ی بسته‌های `tidyverse` طوری طراحی شده است که قابلیت‌های R پایه را تکمیل کند (و گاهی جایگزین آن شود) بدون اینکه سازگاری با نسخه‌های قبلی را تحت تأثیر قرار دهد.

بسته‌ی `dplyr` را می‌توان با افزودن `library(dplyr)` (برای همان بسته) یا `library(tidyverse)` (برای کل مجموعه) به بالای کدتان در دسترس قرار داد.

کتابخانه‌ی `dplyr` دو تابع اضافی مرتبط با `switch` ارائه می‌دهد.

### توابع `recode_values` و `replace_values`

این دو تابع مرتبط امکان نگاشت برداری شبیه به `switch` را از مقادیر قدیمی به مقادیر جدید فراهم می‌کنند.

تفاوت اصلی آن‌ها این است که `recode_values()` یک بردار کاملاً جدید می‌سازد، در حالی که `replace_values()` به‌روزرسانی جزئی یک بردار موجود را ممکن می‌کند.

تطبیق همچنان دقیق است، اما:

- گزینه‌های سمت چپ می‌توانند بردار باشند و اگر هر عنصری تطبیق کند، ورودی تطبیق داده می‌شود.
- گزینه‌های سمت چپ و نتایج سمت راست با `~` به جای `=` به هم مرتبط می‌شوند.
- در همه‌ی حالت‌ها می‌توان یک پیش‌فرض مشخص کرد.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### تابع `case_when`

`case_when` نحوه‌ی نگارش `case_match` را یک مرحله فراتر می‌برد و اجازه می‌دهد هر عبارت منطقی در سمت چپ `~` قرار بگیرد.

بردار ورودی (`x` در مثال زیر) به عنوان آرگومان ارائه نمی‌شود؛ فقط باید از قبل تعریف شده باشد.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

تابع `between()` نیز بخشی از `dplyr` است.
