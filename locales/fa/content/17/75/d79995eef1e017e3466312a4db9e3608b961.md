# مقدمه

بازگشت روشی است برای تکرار کد درون یک تابع، به این صورت که تابع خودش را فراخوانی می‌کند.
می‌توان به آن به‌عنوان روشی دیگر برای حلقه‌زدن یا تکرار کردن نگاه کرد.
مانند حلقه‌زدن، برای تعیین زمان توقف اجرای بازگشتی از یک «عبارت منطقی» یا آزمون `True`/`False` استفاده می‌شود.
*برخلاف* حلقه‌زدن، بازگشت بدون شرط پایان در پایتون نمی‌تواند بی‌نهایت اجرا شود.
مقادیری که در هر فراخوانی تابع به کار می‌روند، در فریم مخصوص خودشان روی [پشته‌ی مفسر][what-is-the-call-stack] پایتون قرار می‌گیرند.
اگر مجموع تعداد فراخوانی‌های تابع بیشتر از فضایی باشد که پشته در اختیار دارد، منجر به خطا می‌شود.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

این کد این را چاپ می‌کند

```
The step is 1
The step is 2
After recursion
```

ممکن است موقعیت‌هایی وجود داشته باشد که وقتی با بازگشت بیان می‌شوند، خواناتر و/یا استدلال درباره‌شان آسان‌تر باشد تا وقتی با حلقه بیان می‌شوند.
