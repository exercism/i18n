# دستورالعمل‌ها

شرکت شما مأمور شده است تا رکوردهای CSV را از ورودی کاربر تولید کند.

ما به یک سازنده برای رکورد CSV بر اساس استانداردی که در [RFC 4180](https://tools.ietf.org/html/rfc4180) تعریف شده است نیاز داریم.

هرچند یک مشخصات رسمی وجود دارد، شرکت شما فقط باید قابلیت‌های زیر را پیاده‌سازی کند:
- ساخت یک سازنده‌ی رکورد جدید
- افزودن یک فیلد جداگانه به رکورد
- سریال‌سازی رکورد با گریز پایه

منظور از گریز پایه این است:

- فیلدهایی که شامل شکست خط، گیومه‌ی دوگانه و ویرگول هستند باید در گیومه‌ی دوگانه محصور شوند.

- اگر برای محصور کردن فیلدها از گیومه‌ی دوگانه استفاده می‌شود، گیومه‌ی دوگانه‌ای که داخل یک فیلد ظاهر می‌شود باید با قرار دادن یک گیومه‌ی دوگانه‌ی دیگر پیش از آن گریز داده شود.


## 1. Create a new builder

برای ساخت یک سازنده‌ی جدید باید متد `new` را پیاده‌سازی کنید.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Add individual fields to the record

برای افزودن فیلدها به سازنده‌ی رکورد خودتان باید متد `add` را پیاده‌سازی کنید.
`add` برش‌های رشته‌ای تغییرناپذیر، یعنی `&str`، را به عنوان آرگومان می‌گیرد.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Serialize the record with basic escaping

باید متد `build` را پیاده‌سازی کنید.
`build` سازنده را مصرف می‌کند و یک رکورد CSV برمی‌گرداند.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
