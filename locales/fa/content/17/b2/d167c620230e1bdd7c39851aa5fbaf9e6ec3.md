# دستورالعمل‌ها

شما مخابره‌چیِ یک شناور گشت ساحلی هستید. کیف امروز باید پیش از آغاز نگهبانی صبحگاهی پنج واژه‌ی کوچک آماده داشته باشد.

## 1. یک مقدار را نقل‌قول کنید

دفتر وقایع هر مشاهده را به *شکل مبدأ Factor* ثبت می‌کند، یعنی همان متنی که تجزیه‌گر بعداً بازخوانی می‌کند. تابع `quote-value` را تعریف کنید تا هر مقدار را به رشته‌ی شکل مبدأِ آن تبدیل کند.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. چارچوب پرچم را حذف کنید

پرچم‌های علامتیِ ورودی در هر دو سر با یک نویسه‌ی نشانه قاب شده‌اند. تابع `flag-body` را تعریف کنید تا هر چیزی را که *بین* آن دو نشانه است برگرداند: نویسه‌ی اول را حذف کنید و نویسه‌ی آخر را هم.

به‌جای رونوشت‌برداری، یک برش (یک نما) برگردانید.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. یک پرچم را تقسیم کنید

هر پرچم یک کد پیشوند کوتاه دارد که بار مفید بعد از آن می‌آید. تابع `split-flag` را تعریف کنید تا یک پرچم و طول سرآیند را بگیرد و *هر دو* برش سرآیند و بدنه را برگرداند.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. مثلث‌یابی با دو خوانش

دو خوانش پشت‌سرهم علامت، سه اندازه‌ی مشتق‌شده به دست می‌دهند: *تفاضل* آن‌ها `a - b`، *نقطه‌ی میانی* آن‌ها `(a + b) / 2` و *نسبت* آن‌ها `a / b`. هر اندازه‌گیری از هر دو خوانش استفاده می‌کند.

تابع `triangulate` را تعریف کنید تا هر سه را از یک جفت خوانش برگرداند.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. سه خوانش را خلاصه کنید

سه خوانش پشت‌سرهم به‌صورت **جمع**، **ضرب** و **بیشینه‌ی** آن‌ها خلاصه می‌شوند. هر آماره از هر سه خوانش استفاده می‌کند.

تابع `triangle-stats` را تعریف کنید تا هر سه را برگرداند.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
