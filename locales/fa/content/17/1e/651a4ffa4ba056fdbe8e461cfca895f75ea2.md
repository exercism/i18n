# مقدمه

`string` در C++ یک شیء تغییرپذیر است که متن را به‌صورت دنباله‌ای از نویسه‌ها (حروف، رقم‌ها، نشانه‌های نگارشی و غیره) نمایش می‌دهد.
رشته‌ها با فراخوانی متدهای رشته دستکاری می‌شوند.

## کتابخانه‌ی رشته

در C++، نوع رشته و توابع مربوط به آن باید پیش از استفاده از کتابخانه‌ی رشته وارد شوند.
برای این کار می‌توانید `#include <string>` را به ابتدای فایل خود اضافه کنید.
در نتیجه، این‌ها در فضای نام `std` قرار می‌گیرند.
نام کامل نوع رشته `std::string` است.
لیترال رشته از نویسه‌ی نقل‌قول دوگانه استفاده می‌کند: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## عملیات رایج روی رشته

برای به هم چسباندن رشته‌ها می‌توانید از عملگر `+` استفاده کنید:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

برای استفاده از کتابخانه‌ی رشته، باید بدانید که می‌توان تابعی را فراخوانی کرد که به یک شیء تعلق دارد.
به این‌ها «تابع عضو» می‌گویند.
در ادامه‌ی سرفصل‌ها، درباره‌ی توابع عضو و مفهوم «کلاس» که با آن در ارتباط است بیشتر یاد می‌گیرید.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


تابع `find` هم بسیار کارآمد است.
این تابع به‌عنوان یک تابع عضو روی رشته فراخوانی می‌شود و یک رشته را به‌عنوان آرگومان می‌گیرد.
تابع `find` موقعیت _اولین_ وقوع در رشته را، با شمارش از صفر، برمی‌گرداند.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

تابع `std::to_string` هم وجود دارد که می‌توان از آن برای تبدیل اعداد صحیح و مقادیر اعشاری به رشته استفاده کرد.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
