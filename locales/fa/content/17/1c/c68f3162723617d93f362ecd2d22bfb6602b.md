# مقدمه

## عدد

سوئیفت دو دسته‌ی اصلی از عددها را ارائه می‌دهد: عددهای صحیح و عددهای ممیز شناور.

- [عددهای صحیح][integers] عددهای کامل بدون بخش اعشاری‌اند، مانند `0`، `1`، `-1`، `42` و `-273`.
- [عددهای ممیز شناور][floatingpoint] عددهایی دارای بخش اعشاری‌اند، مانند `0.0`، `3.14` و `-1.36969e-10`.

می‌توانید برای خوانایی بیشتر، در عددهای نوشته‌شده در کد زیرخط بگذارید: `1_000_000` دقیقاً همان `1000000` است.
عددهای ممیز شناور را می‌توان در نماد اعشاری یا نمایی نوشت.

در بیشتر موارد، برای عددهای صحیح از [`Int`][int] و برای عددهای ممیز شناور از [`Double`][double] استفاده می‌کنید:

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## عملگرهای حساب

سوئیفت [عملگرهای حساب][arithmetic-operators] استانداردی برای محاسبه‌های عددی ارائه می‌دهد:

| عملگر | توضیح | مثال |
| ------ | -------------- | ------- |
| `+`      | جمع       | `4 + 6` برابر است با `10` |
| `-`      | تفریق    | `15 - 10` برابر است با `5` |
| `*`      | ضرب | `2 * 3` برابر است با `6`  |

~~~~exercism/caution
سوئیفت از نظر نوع ایمن است و اجازه نمی‌دهد نوع‌های عددی متفاوت در عملیات حسابی با هم ترکیب شوند.
نمی‌توانید یک `Int` و یک `Double` را مستقیماً با هم جمع یا ضرب کنید؛ ابتدا باید یکی از این دو نوع را به نوع دیگر تبدیل کنید.
~~~~

### تقسیم

عملگر `/` تقسیم را انجام می‌دهد.
وقتی هر دو عملوند عدد صحیح باشند، تقسیم صحیح بخش اعشاری را حذف می‌کند:

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

تقسیم یک عدد ممیز شناور ناصفر بر صفر به `inf` یا `-inf` می‌انجامد.
تقسیم `0.0` بر `0.0` مقدار `nan` را تولید می‌کند (عدد نیست).
در مقابل، تقسیم یک عدد صحیح بر صفر باعث خطای زمان کامپایل یا زمان اجرا می‌شود:

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### عملگر باقیمانده

[عملگر باقیمانده][remainder-operator] (`%`) باقیمانده‌ی حاصل از تقسیم دو عدد صحیح را محاسبه می‌کند:

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
در سوئیفت، `%` یک عملگر واقعی *باقیمانده* است، نه یک عملگر پیمانه.
نتیجه همیشه علامت عملوند اول (مقسوم) را می‌گیرد، بدون توجه به علامت عملوند دوم:

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## گرد کردن عددهای ممیز شناور

می‌توانید یک عدد ممیز شناور را با متد `rounded()` گرد کنید.
به‌طور پیش‌فرض، `rounded()` به نزدیک‌ترین عدد صحیح گرد می‌کند.
همچنین می‌توانید یک [قاعده‌ی گرد کردن][rounding-rule] مشخص، مانند `.up` یا `.down`، تعیین کنید:

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## استنتاج نوع

وقتی یک ثابت یا متغیر عددی را بدون تعیین نوع اعلام می‌کنید، سوئیفت نوع آن را استنتاج می‌کند:

- عددهای کامل به‌طور پیش‌فرض `Int` در نظر گرفته می‌شوند.
- عددهای دارای نقطه‌ی اعشاری به‌طور پیش‌فرض `Double` در نظر گرفته می‌شوند.

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## تبدیل نوع

برای انجام عملیات بین مقدارهایی با نوع‌های متفاوت، یکی از مقدارها را با سازنده‌های نوع مانند `Double(_:)` یا `Int(_:)` تبدیل کنید:

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
