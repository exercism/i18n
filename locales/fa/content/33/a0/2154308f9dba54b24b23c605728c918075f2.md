# مقدمه

## لیست

یک لیست در Gleam مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار است. مقدارهای یک لیست باید همگی یک نوع داشته باشند. چون لیست‌ها تغییرناپذیرند، پس از ساخته‌شدن یک لیست، مقدارش هرگز تغییر نمی‌کند. هر تابع یا عملگری که به نظر می‌رسد لیست را تغییر می‌دهد (مثل افزودن یک عنصر)، در واقع یک لیست تازه برمی‌گرداند.

لیست‌ها را می‌توان چنین تعریف کرد:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

رایج‌ترین راه برای افزودن یک عنصر به لیست، استفاده از «نحوه‌ی نگارش `spread`» است:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

ماژول [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) در کتابخانه‌ی استاندارد Gleam توابع مفید زیادی برای کار با لیست‌ها دارد. این ماژول در کدهای Gleam بسیار پرکاربرد است، پس خوب است که با آن آشنا باشید.

از الگوهای لیست می‌توان در عبارت‌های `case` استفاده کرد تا با لیست‌ها تطبیق داده شوند و مقدارهای درونشان به متغیرها نسبت داده شوند:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

علاوه بر تطبیق با لیست‌هایی با طول دقیق، می‌توان از نحوه‌ی نگارش `spread` برای تطبیق با لیست‌هایی استفاده کرد که دست‌کم طول مشخصی دارند:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

از نحوه‌ی نگارش `spread` همچنین می‌توان برای نسبت دادن بقیه‌ی لیست به یک متغیر استفاده کرد:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

عبارت‌های `case` باید برای هر مقدار ممکن از نوعی که روی آن تطبیق داده می‌شود یک الگو داشته باشند، بنابراین اغلب از یک الگوی نادیده‌گرفتن نهایی (`_`) برای رسیدگی به مقدارهای باقی‌مانده استفاده می‌شود.
