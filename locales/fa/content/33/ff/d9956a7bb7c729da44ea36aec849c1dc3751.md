# Tests

برای دانلود یک تمرین، مثلاً `hello-world`، یک ترمینال باز کنید و این دستور را اجرا کنید:

```bash
exercism download --track roc --exercise hello-world
```

سپس به پوشه‌ی تمرین بروید و کد را ویرایش کنید تا تمرین را حل کنید. برای مثال:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

هر تمرین یک مجموعه تست دارد. می‌توانید تست‌ها را با دستور `roc test` اجرا کنید، برای مثال:

```
roc test hello-world-test.roc
```

اگر تمرین را حل کرده باشید، باید ۰ تست شکست‌خورده ببینید، برای مثال:

```
All (5) tests passed in 123.4 ms.
```

اما اگر کدتان خطایی داشته باشد، به این شکل خواهد بود:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

این باید به شما کمک کند کدتان را درست کنید. وقتی کدتان کار کرد، می‌توانید آن را با دستور `exercism submit` ارسال کنید (برای جزئیات بیشتر، `HELP.md` را در پوشه‌ی تمرین ببینید).
