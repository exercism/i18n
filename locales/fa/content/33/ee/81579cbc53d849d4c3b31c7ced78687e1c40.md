# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که فهرستی از زبان‌های برنامه‌نویسی را که می‌خواهید در Exercism یاد بگیرید، پیگیری کند.

نه کار در پیش دارید که همه‌شان با فهرست‌ها سر و کار دارند.

## 1. یک فهرست جدید بسازید

برای پیگیری زبان‌هایی که می‌خواهید یاد بگیرید، باید یک فهرست جدید بسازید.

متد استاتیک `Languages.NewList()` را پیاده‌سازی کنید که یک فهرست جدید و خالی برمی‌گرداند.

```csharp
Languages.NewList()
// => empty list
```

## 2. یک فهرست موجود را تعریف کنید

در حال حاضر، تکه کاغذی دارید که زبان‌هایی را که می‌خواهید یاد بگیرید فهرست کرده است: C#، Clojure و Elm.

لطفاً متد استاتیک `Languages.GetExistingLanguages()` را پیاده‌سازی کنید تا این فهرست را برگرداند.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. یک زبان جدید به فهرست اضافه کنید

همان‌طور که Exercism را کاوش می‌کنید و زبان‌های جالب‌تری پیدا می‌کنید، می‌خواهید آن‌ها را به فهرستتان اضافه کنید.

تابع استاتیک `Languages.AddLanguage()` را پیاده‌سازی کنید تا یک زبان جدید به انتهای فهرستتان اضافه کنید.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. زبان‌های فهرست را بشمارید

شمردن زبان‌ها یکی‌یکی دردسر دارد.

متد استاتیک `Languages.CountLanguages()` را پیاده‌سازی کنید تا تعداد زبان‌های فهرستتان را بشمارید.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. بررسی کنید که آیا زبانی در فهرست هست

متد استاتیک `Languages.HasLanguage()` را پیاده‌سازی کنید تا بررسی کنید آیا زبانی وجود دارد.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. فهرست را برعکس کنید

یک جایی متوجه می‌شوید که فهرستتان در واقع برعکس مرتب شده است!

متد استاتیک `Languages.ReverseList()` را پیاده‌سازی کنید تا فهرستتان را برعکس کنید.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. بررسی کنید که فهرست هیجان‌انگیز است یا نه

با اینکه همه‌ی زبان‌ها را دوست دارید، C# جایگاه ویژه‌ای در قلب شما دارد. به همین دلیل، اگر یکی از شرط‌های زیر برقرار باشد، از یک فهرست زبان واقعاً هیجان‌زده می‌شوید:

- اولین عنصر فهرست C# است.
- دومین عنصر فهرست C# است و فهرست شامل دو یا سه زبان است.

متد استاتیک `Languages.IsExciting()` را پیاده‌سازی کنید تا بررسی کنید که یک فهرست زبان هیجان‌انگیز است یا نه:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.حذف زبان

لطفاً متد استاتیک `Languages.RemoveLanguage()` را پیاده‌سازی کنید تا زبانی مشخص را از فهرست حذف کنید.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. بررسی کنید که همه‌ی زبان‌های فهرست یکتا هستند

لطفاً متد استاتیک `Languages.IsUnique()` را پیاده‌سازی کنید تا بررسی کنید که آیا هیچ‌یک از زبان‌ها در فهرست تکرار شده است.

تضمین می‌شود که فهرست زبان‌ها (یعنی پارامتر) هنگام فراخوانی این متد خالی نباشد و تغییر فهرست اهمیتی ندارد.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
