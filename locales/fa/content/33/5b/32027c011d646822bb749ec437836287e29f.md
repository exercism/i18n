# Import

[فرم ویژه‌ی `import`][import] به شما امکان می‌دهد از توابع و ماکروهای یک ماژول بیرونی استفاده کنید، بدون آنکه اسم ماژول را به کار ببرید.

ممکن است import کردن یک ماژول بیرونی به‌طور کامل، با توابع محلی موجود تعارض ایجاد کند. برای جلوگیری از این کار، دو گزینه در دسترس است: `:except` و `:only`. هر دو یک «لیست کلیدواژه» می‌گیرند که کلیدش اسم تابع و مقدارش تعداد آرگومان‌های آن تابع است.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

معمولاً importها در ابتدای تعریف ماژول اضافه می‌شوند اما می‌توان آن‌ها را در هر جایی اضافه کرد. این‌ها «دامنه‌ی لغوی» دارند، یعنی importی که داخل تعریف یک تابع اضافه می‌شود، در تابع دیگری در دسترس نیست.

importهای استفاده‌نشده باعث هشدارهای کامپایلر می‌شوند.
