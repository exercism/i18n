# دستورالعمل‌ها

فصل پایانی در باشگاه محلی است. شما در خط پایان، جدول رده‌بندی را اداره می‌کنید: مسابقه‌دهندگان به‌ترتیب عبور می‌کنند، خطوط به برچسب نیاز دارند و دفتر رسمی باید پیش از دور بعدی حاشیه‌نویسی شود.

اسم مسابقه‌دهندگان به‌صورت یک آرایه و به ترتیب رسیدن می‌رسد: اسم صفرم برنده است، اسم یکم نفر دوم و به همین ترتیب.

## 1. شماره‌های مسابقه را اختصاص دهید

تابع `assign-bibs` را طوری تعریف کنید که یک آرایه از اسم مسابقه‌دهندگان بگیرد و آرایه‌ای از جفت‌های `{ position name }` برگرداند، به‌طوری‌که اول موقعیت بیاید.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. برچسب‌های خط

تابع `lane-labels` را طوری تعریف کنید که یک آرایه از اسم مسابقه‌دهندگان بگیرد و رشته‌هایی مانند `"Lane 0: Bolt"` برگرداند.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. مسابقه‌دهندگان را برچسب بزنید

تابع `tag-racers` را طوری تعریف کنید که یک آرایه از اسم مسابقه‌دهندگان *و* یک رشته‌ی برچسب بگیرد و برچسب‌هایی به شکل `"<tag>/<index>: <name>"` برگرداند. همان برچسب در همه‌ی خروجی‌ها گنجانده می‌شود.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. خط پایان‌ها را ثبت کنید

تابع `record-finishes` را طوری تعریف کنید که یک آرایه از اسم مسابقه‌دهندگان و یک دفتر (یک بردار) بگیرد. برای هر مسابقه‌دهنده، رشته‌ای به شکل `"<index>: <name>"` را به‌صورت درجا به دفتر اضافه کنید. چیزی برنمی‌گرداند.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. زنگ‌های دور

تابع `lap-bells` را طوری تعریف کنید که یک عدد `laps` بگیرد و رشته‌ای برگرداند که از تکرار `"ding "` به تعداد `laps` بار ساخته شده است.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
