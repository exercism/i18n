# درباره

یک [`list`][lists] در F# مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار است. مقادیر موجود در یک لیست همگی باید از یک نوع باشند. چون لیست‌ها تغییرناپذیرند، پس از ساخته‌شدن یک لیست، مقدارش هرگز تغییر نمی‌کند. لیست در F# دارای یک _«سر»_ (اولین عنصر) و یک _«دُم»_ (همه‌ی آنچه پس از عنصر اول می‌آید) است. دُم یک لیست، خودش یک لیست است.

لیست‌ها را می‌توان به این صورت تعریف کرد:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

رایج‌ترین روش افزودن یک عنصر به لیست، استفاده از عملگر `::` (cons) است:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

لیست‌ها را می‌توان با عملگر `@` یا `List.append` الحاق کرد:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

کار با لیست‌ها به کمک توابع و عملگرهای تعریف‌شده در [ماژول `List`][list-module] انجام می‌شود. برخی از این توابع به‌صورت [ویژگی‌ها][list-properties] یک نمونه‌ی `list` هم در دسترس‌اند:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

اینجا گزینه‌ی درست یا غلطی وجود ندارد. به‌طور کلی، توابع موجود در ماژول `List` با استنتاج نوع سازگاری بهتری دارند، در حالی که ویژگی‌ها امکان کد مختصرتر را فراهم می‌کنند.

هر تابع یا عملگری که به نظر برسد لیست را تغییر می‌دهد (مثل افزودن یک عنصر)، در واقع یک لیست جدید برمی‌گرداند. با این حال، کارایی معمولاً مشکل بزرگی نیست، چون پیاده‌سازی لیست‌ها جلوی تخصیص‌ها یا رونوشت‌های غیرضروری را می‌گیرد.

چون لیست‌ها به‌صورت لیست‌های پیوندی تک‌جهته پیاده‌سازی می‌شوند، افزودن یک عنصر به ابتدای لیست (با عملگر `::`) بسیار سریع است، در حالی که دسترسی به عنصر با اندیس ممکن است نسبتاً کند باشد.

همچنین می‌توان لیست‌ها را با استفاده از تطبیق الگو و از طریق الگوهای [_لیست_][list-pattern] و [_cons_][cons-pattern] پردازش کرد:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

هنگام تطبیق الگو می‌توانید یک مقدار را هم _نادیده بگیرید_؛ وقتی در یک حالت خاص به یک مقدار اهمیت نمی‌دهید (یعنی نمی‌خواهید از آن مقدار _استفاده_ کنید)، می‌توانید از زیرخط (`'_'`) برای نشان دادن این موضوع استفاده کنید:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

این `'_'` تکی همیشه هنگام تطبیق الگو باید _آخر_ بیاید؛ هر مقداری که با هیچ‌یک از حالت‌های دیگر مطابقت نداشته باشد، توسط این حالت مدیریت می‌شود.
