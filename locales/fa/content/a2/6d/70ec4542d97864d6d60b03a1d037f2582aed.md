# معرفی

## رشته

کاراکترها و رشته‌ها پایه‌ی نمایش متن در Elm را تشکیل می‌دهند.
می‌توان رشته‌ها را به‌صورت فهرستی از کاراکترها در نظر گرفت و بیشتر توابع `List` معادلشان را در ماژول `String` دارند.

### کاراکترها

نوع `Char` یک کاراکتر یونیکد را با کوتیشن تکی نمایش می‌دهد، مثلاً `'a'`.
ماژول `Char` توابع محمولی (`Char -> Bool`) برای بررسی ویژگی‌های یک کاراکتر در اختیار می‌گذارد: `isUpper`، `isLower`، `isAlpha` و `isAlphaNum`.
این ماژول همچنین توابعی برای تبدیل یک کاراکتر به بزرگ یا کوچک (`toUpper`، `toLower`، `toLocaleUpper`، `toLocaleLower`) و نیز تبدیل به مقدار عددی یونیکد آن (`Int`) و از آن، با `toCode` و `fromCode` ارائه می‌دهد.

### رشته

نوع `String` نمایشی درون‌ساخت برای دستکاری کارآمد رشته‌ها فراهم می‌کند و می‌تواند هر دنباله‌ای از کاراکترهای یونیکد را نشان دهد، مثلاً "this is an Elm string."
رشته‌های چندخطی با سه کوتیشن دوتایی نوشته می‌شوند و می‌توانند کوتیشن‌های بدون escape و خطوط جدید داشته باشند.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### توابع رشته

ماژول `String` همه‌ی توابعی را در خود دارد که در جدول زیر خلاصه شده‌اند.
از پرکاربردترین این توابع می‌توان به موارد زیر اشاره کرد:

`cons : Char -> String -> String` یک کاراکتر را به ابتدای یک رشته اضافه می‌کند.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` دو رشته را به هم می‌چسباند.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` یک رشته را از محل جداکننده‌ی داده‌شده به فهرستی از رشته‌ها تقسیم می‌کند.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` فهرستی از رشته‌ها را با جداکننده‌ی داده‌شده به هم می‌چسباند.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` همه‌ی رخدادهای یک زیررشته‌ی داده‌شده را جایگزین می‌کند.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` تعداد کاراکترهای یک رشته را برمی‌گرداند.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` تلاش می‌کند یک رشته را به `Just Int` تبدیل کند و برای رشته‌های بدقالب `Nothing` برمی‌گرداند.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` بررسی می‌کند که آیا رشته‌ی دوم رشته‌ی اول را در خود دارد یا نه.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` یک تابع داده‌شده را روی هر `Char` در رشته اعمال می‌کند.
توجه کنید تابعی که می‌دهید باید نگاشتی از `Char` به `Char` باشد.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
