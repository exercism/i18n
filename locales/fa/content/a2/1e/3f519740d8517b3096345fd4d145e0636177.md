# مقدمه

«تاپل»ها روشی سبک برای گروه‌بندی مجموعه‌ای ثابت از داده‌هایی با نوع دلخواه در کنار هم هستند.
یک تاپل اسم خاصی ندارد؛ نام‌گذاری یک ساختار داده آن را به `struct` تبدیل می‌کند.
فیلدهای یک تاپل اسم ندارند؛ دسترسی به آن‌ها از طریق تخریب ساختار یا بر اساس موقعیت انجام می‌شود.

## ساخت

تاپل‌ها همیشه با یک عبارت تاپل ساخته می‌شوند:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

تاپل‌ها می‌توانند هر تعداد دلخواهی عنصر داشته باشند.

## دسترسی با تخریب ساختار

می‌توان با تخریب ساختار به عناصر یک تاپل دسترسی پیدا کرد.
این کار فقط یعنی به هر یک از عناصر تاپل یک اسم متغیر اختصاص دهیم، که آن را مصرف می‌کند.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
