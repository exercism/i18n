# درباره

PowerShell یک زبان اسکریپت‌نویسی پویا و با نوع‌دهی ضمنی (_که البته از [متغیرهای نوع‌دار قوی][strong typed] هم پشتیبانی می‌کند_) و ساخته‌ی مایکروسافت است؛ تمرکز اصلی آن بر خودکارسازی کارها و مدیریت پیکربندی است.

PowerShell از سبک‌های برنامه‌نویسی امری، تابعی، شیءگرا و حتی خط لوله پشتیبانی می‌کند.

PowerShell بر پایه‌ی پلتفرم .NET ساخته شد و نخستین بار در سال ۲۰۰۶ منتشر شد.
این زبان به‌صورت پیش‌فرض در همه‌ی نسخه‌های جدید ویندوز گنجانده شده است و می‌توان آن را روی Mac و Linux هم نصب کرد.


## متغیرها

دو روش رایج برای تعریف متغیر در PowerShell وجود دارد.

اسم متغیر در PowerShell باید با `$` شروع شود و برای اتصال اسم متغیر به یک مقدار، از عملگر انتساب `=` استفاده می‌شود.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

همچنین می‌توانید نوع متغیر را به‌صورت صریح مشخص کنید، اگر می‌خواهید مقدار حتماً از نوع خاصی باشد.
اگر بشود، PowerShell تمام تلاش خود را می‌کند تا مقدار را از یک نوع به نوع دیگر تبدیل کند.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### ثابت‌ها

ثابت‌ها در PowerShell متغیرهایی هستند که پس از تعریف، نه می‌توان **تغییرشان** داد و نه **حذفشان** کرد.
این ما را به روش دوم تعریف متغیر می‌رساند: استفاده از cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## توابع

توابع در PowerShell با کلیدواژه‌ی `function` تعریف می‌شوند.
هر تابع می‌تواند صفر یا چند پارامتر صوری داخل پرانتز `()` داشته باشد و پس از آن محدوده‌ی تابع قرار می‌گیرد که با `{` شروع می‌شود و با `}` تمام می‌شود.

```powershell
function Greeting {
    return "Hello!"
}
```

توابع در PowerShell می‌توانند مقادیر را به‌صورت صریح و با کلیدواژه‌ی `return` بازگردانند، پس از آنکه با نحوه‌ی نگارش `FuncName $Arg` فراخوانی شوند.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## کامنت‌ها

کامنت‌های تکی در PowerShell با `#` شروع می‌شوند و در پایان خط تمام می‌شوند.
بلوک‌های کامنت در PowerShell با `<#` شروع و با `#>` تمام می‌شوند.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
