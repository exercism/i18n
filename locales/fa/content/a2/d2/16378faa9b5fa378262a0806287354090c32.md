# درباره

`Enum` ماژولی بسیار کاربردی است که مجموعه‌ای از الگوریتم‌ها را برای کار با شمارش‌پذیرها فراهم می‌کند. امکانات زیر را ارائه می‌دهد:

- مرتب‌سازی ([`sort/2`][enum-sort/2]، [`sort_by/2`][enum-sort_by/2])،
- پالایش ([`filter/2`][enum-filter/2])،
- گروه‌بندی ([`group_by/3`][enum-group_by/3])،
- شمارش ([`count/2`][enum-count/2])
- جست‌وجو ([`find/3`][enum-find/3])،
- یافتن کمینه/بیشینه ([`min/3`][enum-min/3]، [`max/3`][enum-max/3])،
- کاهش دادن ([`reduce/3`][enum-reduce/3]، [`reduce_while/3`][enum-reduce_while/3])،

و بسیاری موارد دیگر! برای فهرست کامل، به [مستندات ماژول `Enum`][enum-functions] مراجعه کنید.

## شمارش‌پذیر

به‌طور کلی، _شمارش‌پذیر_ به هر داده‌ای گفته می‌شود که بتوان روی آن پیمایش کرد، یعنی یک مجموعه. در Elixir، شمارش‌پذیر هر نوع داده‌ای است که [پروتکل][exercism-protocols] `Enumerable` را پیاده‌سازی کند. این‌ها عبارت‌اند از:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

اگر هنوز همه‌ی آن‌ها را نمی‌شناسید، نگران نباشید.

هر کسی می‌تواند پروتکل `Enumerable` را برای ساختار داده‌ی سفارشی خود پیاده‌سازی کند.

## کاهش

`Enum.reduce/2` به شما امکان می‌دهد کل شمارش‌پذیر را به یک مقدار واحد _کاهش_ دهید. برای این کار، از متغیری ویژه به نام _انباشتگر_ استفاده می‌شود. انباشتگر وضعیت میانی کاهش را بین تکرارها نگه می‌دارد. همین آن را به یکی از قدرتمندترین توابع برای شمارش‌پذیرها تبدیل می‌کند. بسیاری از توابع تخصصی دیگر را می‌توان با `reduce` که عمومی‌تر است جایگزین کرد. برای مثال...

یافتن بیشینه:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

و حتی نگاشت (اما لازم است نتیجه را بعد از آن معکوس کنید):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## نگاشت نقشه‌ها

- با [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- با [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- با [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
