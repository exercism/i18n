# دستورالعمل‌ها

به عنوان یک علاقه‌مند به شطرنج، دوست دارید نسخه‌ی خودتان از این بازی را بنویسید. بله، شاید همین حالا هم پیاده‌سازی‌های زیادی از شطرنج به صورت آنلاین در دسترس باشد، اما نسخه‌ی شما منحصربه‌فرد خواهد بود!

اما پیش از آن‌که بتوانید افسار تخیل‌تان را رها کنید، باید به اصول اولیه بپردازید. بیایید با ساختن صفحه‌ی شطرنج شروع کنیم.

هر خانه از صفحه‌ی شطرنج با یک جفت حرف و عدد مشخص می‌شود. ستون‌های عمودی خانه‌ها، که به آن‌ها «ستون» می‌گویند، با حروف A تا H برچسب‌گذاری شده‌اند. ردیف‌های افقی خانه‌ها، که به آن‌ها «ردیف» می‌گویند، از ۱ تا ۸ شماره‌گذاری شده‌اند.

## 1. بازه‌ی ردیف‌ها را تعریف کنید

تابع `rank_range()` را پیاده‌سازی کنید. این تابع باید یک بازه از اعداد صحیح را برگرداند، از ۱ تا ۸.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. بازه‌ی ستون‌ها را تعریف کنید

تابع `file_range()` را پیاده‌سازی کنید.
این تابع باید یک بازه از کاراکترها را برگرداند، از حرف بزرگ A تا حرف بزرگ H.

```julia-repl
julia> file_range()
# output omitted
```

## 3. بازه‌ی ردیف‌ها را به بردار ردیف‌ها تبدیل کنید

تابع `ranks()` را پیاده‌سازی کنید. این تابع باید یک بردار از اعداد صحیح را برگرداند، از ۱ تا ۸.
این بردار را دستی ننویسید و آن را از بازه‌ای که تابع `rank_range()` برمی‌گرداند بسازید.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. بازه‌ی ستون‌ها را به بردار ستون‌ها تبدیل کنید

تابع `files` را پیاده‌سازی کنید. این تابع باید یک بردار از کاراکترها را برگرداند، از 'A' تا 'H'.
این بردار را دستی ننویسید و آن را از بازه‌ای که تابع `file_range()` برمی‌گرداند بسازید.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
