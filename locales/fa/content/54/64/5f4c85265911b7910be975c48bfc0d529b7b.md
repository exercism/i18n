# درباره

یک [`array`][arrays] در F# مجموعه‌ای قابل تغییر از صفر یا چند مقدار با طول ثابت است. یعنی وقتی یک «آرایه» ساخته شد، اندازه‌اش دیگر نمی‌تواند تغییر کند، اما مقدارهایش می‌توانند. همه‌ی مقدارهای یک آرایه باید نوع یکسانی داشته باشند. [آرایه‌ها را می‌توان به این شکل تعریف کرد][creating-arrays]:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

می‌توان با [استفاده از یک اندیس][array-indexer] عنصری را در آرایه مقداردهی کرد یا آن را از آرایه بازیابی کرد. آرایه‌های F# از صفر شروع می‌شوند، یعنی اندیس اولین عنصر همیشه صفر است:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

آرایه‌ها با توابع و عملگرهایی که در [ماژول `Array`][array-module] تعریف شده‌اند دستکاری می‌شوند. برخی از این توابع به‌صورت [ویژگی‌های][array-properties] یک نمونه‌ی `array` هم در دسترس هستند:

```fsharp
Array.length [| 7; 8 |] // => 2
[| 7; 8 |].Length       // => 2
```

اینجا هیچ گزینه‌ی درست یا غلطی وجود ندارد. به‌طور کلی، توابع موجود در ماژول `Array` سازگاری بهتری با استنتاج نوع دارند، در حالی که ویژگی‌ها امکان نوشتن کد مختصرتری را فراهم می‌کنند.

[_الگوی آرایه_][array-pattern] امکان «تطبیق الگو» روی آرایه‌ها را فراهم می‌کند:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

همچنین می‌توانید هنگام تطبیق الگو مقداری را _نادیده بگیرید_؛ وقتی در یک حالت خاص به مقداری _اهمیت نمی‌دهید_ (یعنی قرار نیست از آن مقدار _استفاده کنید_) می‌توانید برای نشان دادن این موضوع از کاراکتر زیرخط (`'_'`) استفاده کنید:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

`'_'` به‌تنهایی باید هنگام تطبیق الگو همیشه در _آخر_ بیاید. هر مقداری که با هیچ‌یک از حالت‌های دیگر _تطبیق نکند_، توسط همین حالت رسیدگی می‌شود.
