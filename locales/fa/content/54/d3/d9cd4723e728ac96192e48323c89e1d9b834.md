# درباره

در Gleam می‌توان از یک عبارت `case` برای اجرای شرطی کد استفاده کرد. با یک عبارت `case` می‌توان یک مقدار را با یک یا چند _الگو_ سنجید. نمونه‌ای از چنین الگویی _الگوی مقدار ثابت_ است که یک مقدار را با یک مقدار ثابت مطابقت می‌دهد (مثلاً `1` یا `"hello"`).

عبارت‌های `case` با کلیدواژه‌ی `case` نوشته می‌شوند:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

گرچه این ممکن است شبیه دستورهای `switch` در زبان‌های دیگر به نظر برسد، اما وقتی از الگوهای دیگر هم استفاده کنید، تطبیق الگو تازه خودش را نشان می‌دهد. یکی از این الگوها _الگوی متغیر_ است که امکان می‌دهد مقداری به یک متغیر نسبت داده شود. در این مثال، اگر `number` برابر `0` نباشد، مقدارش به متغیر `i` نسبت داده می‌شود:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

در برخی موارد، ممکن است بخواهید شرط دیگری به یک الگو اضافه کنید. به این _گارد_ (بند) می‌گویند که می‌توان آن را با کلیدواژه‌ی `if` اضافه کرد:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

به دلایل کارایی، در گاردها فقط عملگرهای پایه‌ی ریاضی و «منطقی» مجاز هستند و توابع دیگر را نمی‌توان در گاردها به کار برد.

در مثال بالا، برای همه‌ی ورودی‌های ممکن الگوی منطبقی وجود ندارد. کامپایلر این را تشخیص می‌دهد و خطایی نمایش می‌دهد. به این کار _بررسی جامع_ می‌گویند. برای رفع این هشدار، باید همه‌ی حالت‌ها را مدیریت کرد. برای این کار می‌توان از _الگوی نادیده‌گرفتن_ استفاده کرد که با هر مقداری مطابقت می‌کند:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

عبارت‌های `case` یک مقدار را از بالا به پایین با هر الگو می‌سنجند تا الگویی منطبق پیدا شود و منطق مربوط به آن الگو اجرا شود. ترتیب الگوها مهم است!
