# درباره

هرچند `readonly` به عنوان تغییردهنده جلوی بازنویسی مقدار یا ارجاع یک فیلد را می‌گیرد، اما از اعضای «نوع ارجاعی» محافظت نمی‌کند.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

برای اینکه از همه‌ی اعضای نوع ارجاعی محافظت شود، می‌توان فیلدها را `readonly` کرد و «ویژگی‌های خودکار» را بدون دسترس‌گر `set` تعریف کرد.

کتابخانه‌ی کلاس‌های پایه (BCL) هم برای مواقعی که باید جلوی به‌روزرسانی اعضای یک مجموعه گرفته شود، نسخه‌های فقط‌خواندنی برخی از مجموعه‌ها را فراهم می‌کند. این‌ها در قالب پوشش‌هایی ارائه می‌شوند:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
