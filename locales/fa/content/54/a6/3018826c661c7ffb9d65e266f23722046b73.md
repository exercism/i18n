# مقدمه‌ای بر محاسبات در پوسته‌ی Bash

Bash می‌تواند محاسبات انجام دهد، اما _فقط با اعداد صحیح_.
اگر لازم است محاسبات اعشاری انجام دهید، باید برنامه‌ای بیرونی را فراخوانی کنید (مثل [awk][awk] یا [bc][bc]).

عملگرهای محاسباتی به ترتیب اولویت در دفترچه‌ی راهنما فهرست شده‌اند: [Shell Arithmetic][arithmetic].

علاوه بر این، Bash فقط در جاهای خاصی محاسبات انجام می‌دهد (که به آن‌ها «بسترهای محاسباتی» می‌گویند).

## بسط محاسباتی

بسط محاسباتی شبیه [جانشینی دستور][cmd-sub] است، اما با دو پرانتز.

```bash
$(( expression ))
```

این نحوه‌ی نگارش به نتیجه‌ی ارزیابی عبارت بسط می‌یابد.
معمولاً از آن برای ذخیره‌ی نتیجه در یک متغیر استفاده می‌شود:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
میزان فاصله‌ی خالی داخل پرانتزها به خودتان بستگی دارد.
این موضوعی مربوط به سبک و خوانایی است.

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

نویسنده‌ی مهربان شما دوست دارد فاصله اضافه کند تا عبارت محاسباتی درون پرانتزها بهتر دیده شود.
~~~~

## شرط محاسباتی

شرط محاسباتی درون دو پرانتز و _بدون_ `$` ابتدایی اجرا می‌شود:

```bash
(( expression ))
```

این به نتیجه بسط نمی‌یابد.
اما یک _وضعیت خروج_ تولید می‌کند.

* اگر نتیجه‌ی عبارت **غیرصفر** باشد، وضعیت خروج ۰ (موفقیت) است.
* اگر نتیجه‌ی عبارت **صفر** باشد، وضعیت خروج ۱ (شکست) است.

~~~~exercism/note
درون `((`، Bash همان برداشت درست/غلط زبان C را دارد: صفر «غلط» است و غیرصفر «درست».
**این دقیقاً برعکس روشی است که Bash وضعیت‌های خروج را ارزیابی می‌کند!**
~~~~

از این نحوه‌ی نگارش معمولاً در دو جا استفاده می‌شود:

1. به‌عنوان بخش COMMAND یک [دستور شرطی `if`][conditional-if] یا یک [حلقه‌ی `while`][looping-while].

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. به‌عنوان یک دستور مستقل برای تغییر مقدار یک متغیر.

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   در استفاده‌ی این‌چنینی از محاسبات همراه با `set -e` احتیاط کنید.
   اگر عبارت به صفر ارزیابی شود، وضعیت خروج غیرصفر خواهد بود و Bash خاتمه می‌یابد.

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   برای بحث مفصل‌تر درباره‌ی عملگر `++`، این مقاله را ببینید: [Postincrement vs Preincrement][incr]

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## جاهای دیگری که بستر محاسباتی دارند

چند جای دیگر هم هست که بستر محاسباتی به شمار می‌آیند:

* [حلقه‌ی For محاسباتی][looping-for].

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* بخش اندیس یک آرایه با اندیس عددی.

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  برای اطلاعات بیشتر درباره‌ی آرایه‌ها، سند مفهوم [آرایه][arrays] را بخوانید.

* بخش‌های آفست و طولِ بسط `${var:offset:length}`.
* [دستور توکار `let`][let].
  * توجه کنید که `(( expression ))` بر `let "expresson"` ترجیح دارد.
    برخلاف ساختار شرط محاسباتی، عبارت `let` در معرض بسط نام فایل و شکستن کلمه است و باید در نقل‌قول قرار گیرد.
* انتساب متغیر، وقتی که متغیر «ویژگی عدد صحیح» را دارد.

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  به نظر نویسنده، کاربرد `declare -i` محدود است.
  مزیت اصلی آن این است که اجازه‌ی محاسبات «بی‌واسطه» را می‌دهد (بدون نحوه‌ی نگارش عبارت محاسباتی).
  این می‌تواند خوانندگان کد شما را گیج کند، چون عبارت‌های محاسباتی در جاهایی غیرمنتظره ارزیابی می‌شوند.
  ~~~~

## استفاده از متغیرها در عبارت‌های محاسباتی

یک جنبه از بسترهای محاسباتی وجود دارد که خوانایی را بهتر می‌کند.

```bash
height=10
width=20
area=$(( height * width ))
```

آیا توجه کردید که در عبارت محاسباتی، علامت دلار `$` از متغیرها حذف شده است؟
Bash این کار را برایتان ممکن می‌کند.
این باعث می‌شود خواندن عبارت‌ها بسیار آسان‌تر شود.

دفترچه‌ی راهنما می‌گوید:

> درون یک عبارت، می‌توان به متغیرهای پوسته با اسمشان ارجاع داد، بدون اینکه از نحوه‌ی نگارش بسط پارامتر استفاده شود.

حتی برای عناصر آرایه هم کار می‌کند:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

اما سایر عبارت‌های پارامتری باید از نحوه‌ی نگارش خاص خودشان استفاده کنند.
برای مثال، دو برابر کردن طول یک رشته:

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

و پارامترهای موقعیتی هم باید همین کار را بکنند.
اگر دو پارامتر موقعیتی اول نشان‌دهنده‌ی عرض و ارتفاع باشند:

```bash
area=$(( $1 * $2 ))
```
