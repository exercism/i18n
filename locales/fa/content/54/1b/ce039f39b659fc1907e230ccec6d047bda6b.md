# درباره

اعداد اعشاری اعدادی‌اند که بعد از جداکننده‌ی اعشار یک یا چند رقم دارند.

```gleam
let float = 3.45
// -> 3.45
```

اعداد اعشاری مجموعه‌ی عملگرهای مخصوص خودشان را هم دارند.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

برای خوانایی بیشتر می‌توان به اعداد اعشاری زیرخط هم اضافه کرد.

```gleam
1_000_000.0 // One million
```

نماد علمی را هم می‌توان برای اعداد اعشاری به کار برد:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
