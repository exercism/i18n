# یادگیری

زبان برنامه‌نویسی Pascal پیشینه‌ی طولانی دارد و بخش بزرگی از مستندات آنلاین آن برای مبتدی‌ها نوشته شده است. بیشتر این آموزش‌ها به برنامه‌های کنسولی می‌پردازند؛ برنامه‌هایی که در آن‌ها اطلاعات را روی صفحه چاپ می‌کنید و/یا ورودی کاربر را می‌خوانید. برای مثال، یکی از رایج‌ترین آموزش‌های مبتدی، برنامه‌ای است که عبارت «Hello World» را روی صفحه چاپ می‌کند:

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

وقتی این برنامه را از یک کنسول/ترمینال اجرا کنید، عبارت «Hello World» را روی صفحه چاپ می‌کند.

ما اینجا در Exercism از Test خودکار استفاده می‌کنیم تا مطمئن شویم راه‌حل‌هایتان درست هستند و به همین دلیل باید به جای یک **program** از یک **unit** استفاده کنیم. تفاوت اصلی این است که باید از یک تابع مقداری برگردانید، نه اینکه چیزی را در ترمینال چاپ کنید:

```pascal
writeln('Hello World!');
```

به این تبدیل شد

```pascal
result := 'Hello World!'
```

دستورهای `write`/`writeln` هنوز برای نمایش اطلاعات یا به دست آوردن نمایش متنی خروجی یک دستور، یک عملیات ریاضی و غیره مفید هستند.
