# مقدمه

## عملگرهای مقایسه

عملگرهای مقایسه شبیه بسیاری از زبان‌های دیگر هستند.

برای بررسی برابری، عملگرها `==` (برابر) و `!=` (نابرابر) هستند.

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

عملگرهای بزرگ‌تر و کوچک‌تر هم مرسوم هستند.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## انشعاب با `if`

این شکل کامل یک عبارت `if` است:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- پرانتزهای `()` دور هر شرط الزامی است.
- هر شرط باید به یک مقدار منطقی `true` یا `false` ارزیابی شود.
  Kotlin مفهومی به اسم «truthy» و «falsy» که در برخی زبان‌ها دیده می‌شود، ندارد.
- آکولادهای `{}` اختیاری‌اند، اگر فقط یک عبارت وجود داشته باشد.
- هم `else if` و هم `else` اختیاری‌اند و می‌توان چندین «بلوک» `else if` داشت.

از عبارت `if` می‌توان برای «انتخاب» یک مقدار هم استفاده کرد:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## جایگزین‌ها؟

Kotlin به شکلی عامدانه عملگر سه‌تایی `? :` را که در Java وجود دارد _ندارد_.
شکل مختصر `if ... else` ترجیح داده می‌شود:

```Kotlin
return if (isOK) goodValue else badValue
```
