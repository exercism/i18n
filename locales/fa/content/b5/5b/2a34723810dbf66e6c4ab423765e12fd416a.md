# درباره

«رشته» در Gleam متنی تغییرناپذیر است که درون دو علامت نقل‌قول دوتایی قرار می‌گیرد. رشته‌ها از نویسه‌های یونیکد پشتیبانی می‌کنند و می‌توانند چندخطی باشند.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

برای پیوند دادن رشته‌ها به هم می‌توان از عملگر `<>` استفاده کرد:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

ماژول [`gleam/string`][stdlib] در کتابخانه‌ی استاندارد، توابعی برای کار با رشته‌ها فراهم می‌کند.

می‌توان رشته‌ها را در عبارت‌های `case` تطبیق داد:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

اگر می‌خواهید ابتدای یک رشته را تطبیق دهید و بقیه را به یک متغیر اختصاص دهید، می‌توانید از الگوی عملگر `<>` استفاده کنید:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
