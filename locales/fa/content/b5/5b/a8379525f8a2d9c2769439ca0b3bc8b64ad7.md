# درباره

Haxe از «بازتاب» زمان اجرا برای نوع‌ها و فیلدها پشتیبانی می‌کند. برای استفاده‌ی درست از بازتاب، لازم است بدانید چه نوع عملیاتی پشتیبانی می‌شود و چه نوع عملیاتی پشتیبانی نمی‌شود. با توجه به ماهیت پویای بازتاب، همیشه نمی‌توان این موضوع را در زمان کامپایل مشخص کرد.

API بازتاب از دو کلاس تشکیل شده است:

- `Reflect`: یک API سبک که بهترین عملکرد را روی ساختارهای بی‌نام دارد، با پشتیبانی محدود از کلاس‌ها.
- `Type`: یک API قوی‌تر برای کار با کلاس‌ها و «شمارشی‌ها».

متدهای موجود در API برای [Reflect][reflect] و [Type][type] به تفصیل آمده است.

برای مثال زیر، از هدف JavaScript استفاده می‌کنیم:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
