# مقدمه

## شیء

یک **شیء** JSON، اگر از اصطلاحات زبان‌های دیگر استفاده کنیم، همان «hash»، «map» یا «dictionary» است.

JSON یک _شیء_ را این‌گونه تعریف می‌کند:

> یک شیء مجموعه‌ای بدون ترتیب از جفت‌های **name**/**value** است.
> هر شیء با `{` که همان آکولاد چپ است شروع می‌شود و با `}` که همان آکولاد راست است پایان می‌یابد.
> هر _name_ با `:` که همان دونقطه است دنبال می‌شود و جفت‌های _name/value_ با `,` که همان ویرگول است از هم جدا می‌شوند.

_name_ **باید یک رشته باشد**.
واژه‌ی دیگری برای _name_، _key_ است.

_value_ می‌تواند از هر نوع JSON باشد.
_value_های مختلف در یک شیء یکسان می‌توانند انواع مختلفی داشته باشند، مانند این مثال.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

توجه کنید که پس از _آخرین_ جفت کلید-مقدار **نباید** ویرگولی بیاید.

### ساختن اشیاء

برای جمع‌آوری جفت‌های name/value از آکولاد استفاده کنید.
هرچند نام‌ها باید رشته باشند، اگر نام‌ها **شبیه شناسه** باشند (از نویسه‌های الفبایی-عددی و زیرخط تشکیل شده باشند و با رقم شروع نشوند) نیازی نیست داخل گیومه قرار بگیرند.

```jq
{name: "Jane", age: 42}
```

استفاده از کلیدهایی که _شبیه شناسه_ نیستند هم مجاز است.
کافی است آن‌ها را داخل گیومه بگذارید.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

اگر نام نتیجه‌ی یک عبارت باشد، آن عبارت **باید** داخل پرانتز قرار بگیرد.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### نمایه‌سازی

مقادیر با **نقطه‌نگاری** از یک شیء بازیابی می‌شوند.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

اگر نتوانید کلید را به‌عنوان یک شناسه ارجاع دهید، از **کروشه‌نگاری** استفاده کنید.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### افزودن یا تغییر جفت‌های کلید-مقدار

برای افزودن یک جفت کلید-مقدار جدید به یک آرایه، یا به‌روزرسانی مقدار یک کلید موجود، از عملگر انتساب `=` استفاده کنید، با یک عبارت نمایه در سمت چپ.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

عملگر `+` اشیاء را _ادغام_ می‌کند.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### حذف یک کلید

برای حذف یک کلید از تابع `del` استفاده کنید.
این تابع شیء به‌روزرسانی‌شده را برمی‌گرداند.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

پارامتر `del` یک **عبارت نمایه** است (با نقطه‌نگاری یا کروشه‌نگاری) که به یک کلید در شیء اشاره می‌کند.
`jq` به آن **عبارت مسیر** می‌گوید.
فقط دادن یک رشته کافی نیست.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### عضویت

- برای بررسی اینکه آیا شیء یک کلید دارد، از تابع `has` استفاده کنید.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- برای بررسی اینکه آیا یک کلید در شیء هست، از `in` استفاده کنید.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### فهرست کردن همه‌ی کلیدها

برای خروجی گرفتن فهرستی از همه‌ی کلیدها، از تابع `keys` استفاده کنید.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

توجه کنید که `keys` کلیدها را _مرتب_ می‌کند.
برای بازیابی کلیدها به ترتیب اصلی، از `keys_unsorted` استفاده کنید.

تابع معادلی برای فهرست کردن همه‌ی _value_ها وجود ندارد.
با این حال، فیلتر `.[]` مقادیر شیء را به‌صورت یک _stream_ خروجی می‌دهد و آن stream را می‌توان با سازنده‌ی آرایه‌ی `[...]` ثبت کرد.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### پیمایش

- تابع `map_values(filter)` فیلتر را روی هر _value_ در شیء اعمال می‌کند.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- برای پیمایش روی یک شیء، ابتدا باید آن را به آرایه‌ای از اشیاء کلید-مقدار تبدیل کنیم.
  تابع `to_entries` همین کار را انجام می‌دهد.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  در این مرحله می‌توانیم از توابع پیمایش آرایه، مانند `map`، استفاده کنیم.

- تابع `from_entries` عکس این کار است: آرایه‌ای از اشیاء کلید-مقدار را به یک شیء تبدیل می‌کند.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- برای اعمال یک فیلتر روی _هر_ جفت کلید-مقدار در یک شیء، از تابع `with_entries(filter)` استفاده کنید.

  برای مثال، اگر شیئی داشته باشیم که اسم را به سن نگاشت می‌کند، می‌توان کلیدها و مقادیر را به‌صورت زیر جابه‌جا کرد.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  خروجی می‌دهد

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` معادل این است:

  ```jq
  to_entries | map(filter) | from_entries
  ```
