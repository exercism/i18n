# مقدمه

## آرایه

JSON یک **آرایه** را این‌گونه تعریف می‌کند:

> آرایه مجموعه‌ای مرتب از مقادیر است.
> آرایه با `[` (براکت چپ) شروع می‌شود و با `]` (براکت راست) پایان می‌یابد.
> مقادیر با `,` (کاما) از هم جدا می‌شوند.

آرایه‌ها می‌توانند صفر یا چند مقدار از _هر نوعی_ از مقادیر JSON را در خود داشته باشند.
نیازی نیست عناصر آرایه همه از یک نوع باشند.

### ساختن آرایه‌ها

برای گردآوردن عناصر در یک آرایه از براکت استفاده کنید.

```jq
[1, 2, 3]
```

عناصر یک _جریان_ را می‌توان با گذاشتن آن میان براکت در یک آرایه جمع کرد.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### اندازه

تابع `length` تعداد عناصر یک آرایه را برمی‌گرداند.

### اندیس‌گذاری و برش

اندیس‌گذاری آرایه‌ها از صفر شروع می‌شود.

یک عنصر را با یک عبارت براکتی از آرایه به‌دست آورید:
`.[2]` عنصر سوم را می‌گیرد.

اندیس‌های منفی از انتهای آرایه به عقب شمرده می‌شوند:
`.[-1]` آخرین عنصر را می‌گیرد و `.[-2]` دومین عنصر از انتها است.

یک **برش** زیردنباله‌ای از آرایه است.
`.[10:15]` پنج عنصر را از اندیس ۱۰ به بعد برمی‌گرداند؛ اندیس پایان _لحاظ نمی‌شود_.

چند تابع کمکی هم وجود دارد:

- `first` اولین عنصر را می‌گیرد.
- `last` آخرین عنصر را می‌گیرد.
- `nth(n)` عنصر موجود در اندیس `n` را می‌گیرد.

### پیمایش

`jq` توابع زیادی برای پوشش کارکردهای رایج پیمایش فراهم می‌کند:

- `map(expr)` یک آرایه‌ی جدید برمی‌گرداند که در آن `expr` به نوبت روی هر عنصر اعمال می‌شود.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` تابعی است که `expr` را روی یک _مقدار تکی_ اعمال می‌کند؛
  اگر نتیجه‌ی عبارت «درست» باشد، آن مقدار برگردانده می‌شود؛
  اگر نتیجه «غلط» باشد، _هیچ‌چیز_ برگردانده نمی‌شود، نه `null`، بلکه واقعاً هیچ.

  برای اعمال آن روی یک آرایه، آن را با `map` ترکیب کنید.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  به‌طور جایگزین، `select` را روی یک _جریان_ اعمال کنید و نتایج را جمع کنید.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` و `all(condition)` یک مقدار منطقی برمی‌گردانند که آیا هیچ‌کدام یا همه‌ی عناصر آرایه شرط را برآورده می‌کنند یا نه.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
