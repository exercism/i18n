# تست‌ها

برای اجرای تست‌ها، دستور زیر را در پوشه‌ی تمرین اجرا کنید:

```shell
make
```

## تست‌های نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی کاری کنید که همه‌ی تست‌هایش موفق شوند.
به‌طور پیش‌فرض، وقتی تست‌ها را اجرا می‌کنید فقط یک تست (اولین تست) اجرا می‌شود.
این کار عمدی است، چون به شما اجازه می‌دهد فقط روی موفق کردن همان یک تست تمرکز کنید.
وقتی آن تست موفق شد، می‌توانید تست بعدی را با حذف خط `TEST_IGNORE();` فعال کنید.
وقتی همه‌ی تست‌ها فعال شدند و پیاده‌سازی شما همه‌شان را موفق کرد، تمرین را حل کرده‌اید!
