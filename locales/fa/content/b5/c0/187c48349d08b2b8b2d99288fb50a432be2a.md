# دستورالعمل‌ها

وظیفه‌ی شما این است که فهرستی از گل‌زنان یک بازی را بگیرید و بشمارید که هر بازیکن چند گل زده است.

`PlayerName` یک نام مستعار نوع برای `String` است تا کد خواناتر شود و این کاربرد `String` از کاربردهای دیگرش متمایز شود.

## 1. تجمیع گل‌زنان

ابتدا `updateGoalCountForPlayer` را پیاده‌سازی کنید تا تعداد گل‌های یک بازیکن را مقداردهی اولیه کند یا یک واحد افزایش دهد.
سپس تابع `aggregateScorers` را پیاده‌سازی کنید تا با استفاده از `updateGoalCountForPlayer` بشمارید که هر بازیکن چند گل زده است.
این تابع یک `List PlayerName` می‌گیرد (اسم بازیکنانی که گل زده‌اند و می‌تواند شامل اسم‌های تکراری باشد) و یک `Dict PlayerName Int` برمی‌گرداند که شامل همه‌ی بازیکنان فهرست به همراه تعداد گل‌هایشان است.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. حذف بازیکنان کم‌اهمیت

تابع `removeInsignificantPlayers` را پیاده‌سازی کنید تا بازیکنانی را که کمتر از آستانه گل زده‌اند حذف کنید.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. بازنشانی تعداد گل بازیکن

تابع `resetPlayerGoalCount` را پیاده‌سازی کنید تا تعداد گل‌های زده‌شده‌ی یک بازیکن را به صفر بازنشانی کند.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. قالب‌بندی تعداد گل یک بازیکن

تابع `formatPlayer` را پیاده‌سازی کنید تا تعداد گل یک بازیکن را به‌صورت رشته قالب‌بندی کند. اگر بازیکن در دیکشنری وجود ندارد، فرض کنید تعداد گلش صفر است.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. قالب‌بندی تعداد گل همه‌ی بازیکنان

تابع `formatPlayers` را پیاده‌سازی کنید تا تعداد گل همه‌ی بازیکنان را به‌صورت رشته قالب‌بندی کند. بازیکنان باید بر اساس اسم بازیکن مرتب شوند.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. ترکیب بازی‌ها

تابع `combineGames` را پیاده‌سازی کنید و تعداد کل گل‌هایی را که هر بازیکن در هر دو بازی زده است، بشمارید.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
