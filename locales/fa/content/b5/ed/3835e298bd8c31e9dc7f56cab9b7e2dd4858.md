# مقدمه

## تاپل

تاپل‌ها در Elm می‌توانند دو یا سه مقدار را در خود نگه دارند و هر مقدار می‌تواند هر نوعی داشته باشد.
در Elm، تاپل‌ها بیشتر برای انواع گذرای ساده به کار می‌روند.
به همین دلیل تاپل‌ها حداکثر ۳ مقدار را نگه می‌دارند و برای تشویق بیشتر، توابع کمکی فقط برای ۲ مقدار ارائه شده‌اند.
برای داده‌های پیچیده‌تر، بهتر است به رکوردها روی بیاورید.

```elm
type alias IntStringTuple = (Int, String)

aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")

anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")

Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

می‌توان تاپل‌ها را در اتصال‌ها با استفاده از تطبیق الگوی تاپل _ساختارشکنی_ کرد.
ساختارشکنی را می‌توان در عبارت‌های `let`، اعلان‌های تابع و دستورهای `case` انجام داد.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString

has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
