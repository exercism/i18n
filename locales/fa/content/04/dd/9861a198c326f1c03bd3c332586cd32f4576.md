# عدد

`INT` یک «عدد صحیح» را در خود نگه می‌دارد. در Sather این عدد دقیقاً ۳۲ بیت است، پس از -۲۱۴۷۴۸۳۶۴۸ تا ۲۱۴۷۴۸۳۶۴۷ می‌شمارد.

```sather
   goals : INT is
      return 42;
   end;
```

## آرگومان‌ها

یک «روال»، آرگومان‌ها را داخل پرانتز می‌گیرد و هر کدام یک نوع دارند:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

آرگومان‌هایی که نوع مشترک دارند می‌توانند اعلان را هم مشترک کنند، که سبک معمول است:

```sather
   total(first, second : INT) : INT is
```

## محاسبات

| عملگر | معنی |
| --- | --- |
| `+` | جمع |
| `-` | تفریق، و منفی کردن |
| `*` | ضرب |
| `/` | تقسیم، با دور انداختن باقی‌مانده |
| `%` | باقی‌مانده‌ی همان تقسیم |

`/` بین دو `INT` هرگز کسر تولید نمی‌کند:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

اگر کسر می‌خواهید به `FLTD` نیاز دارید که بعداً به آن می‌رسیم.

ضرب و تقسیم، درست مثل حساب معمولی، از جمع و تفریق اولویت بالاتری دارند. وقتی نتیجه‌ی دیگری می‌خواهید، پرانتزها گروه‌بندی را انجام می‌دهند:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## روال‌های مفید روی INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str` روشی است که یک عدد با آن بخشی از یک جمله می‌شود، آن هم بعد از آشنایی با رشته‌ها.
