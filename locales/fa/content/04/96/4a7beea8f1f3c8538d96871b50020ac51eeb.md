# از آرگومان‌های پیش‌فرض استفاده نشده است

در تعریف تابع این راه‌حل از [آرگومان پیش‌فرض][default argument] استفاده نشده است.
[آرگومان‌های پیش‌فرض در Python][default arguments in python] می‌توانند کمک کنند تا وقتی یک تابع بدون آرگومان موردانتظار فراخوانی می‌شود یا آرگومانی برای پاس دادن در دسترس نیست، مشکلی پیش نیاید.
`Default arguments` همچنین می‌توانند به جلوگیری از کدهای شرطی یا بررسی‌های غیرضروری درون یک تابع کمک کنند.

می‌توان این راه‌حل را با استفاده از یک `default argument` همراه با [str.format][str.format] یا [f-strings][f-strings] (_که با نام‌های «formatted string literals» یا «interpolated strings» هم شناخته می‌شوند_) بهبود داد.

[قالب‌بندی رشته در Python][string formatting in python] از Real Python می‌تواند نقطه‌ی شروع خوبی برای یادگیری گزینه‌های قالب‌بندی رشته در Python باشد.
