# مقدمه

## عملگرهای مقایسه

R مجموعه‌ای از عملگرها دارد که با بسیاری از زبان‌های دیگر یکسان است:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## انشعاب

شکل پایه‌ی if-else چنین است:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

در این حالت، هم پرانتزهای `()` دور «مقدار منطقی» و هم آکولادهای `{}` دور بدنه الزامی هستند.

یک دستور `if` ساده را می‌توان کوتاه کرد:

```R
if (x == 0) return("success")
```
