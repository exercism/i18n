# import کردن ANSI با `:except`

در دستورالعمل‌ها آمده است: «قصد دارید پشتیبانی از رنگ‌های دیگر خودروها را اضافه کنید، پس می‌خواهید کل ماژول را `import` کنید»، به‌جز تابع `color` که تداخل ایجاد می‌کند. برای این کار، از گزینه‌ی `:except` به این شکل استفاده کنید:

```elixir
import IO.ANSI, except: [color: 1]
```
