# دستورالعمل‌ها

در این تمرین، روشی را پیاده‌سازی می‌کنید که با آن امتیازهای برتر محبوب‌ترین بازی سالن آرکید محله‌تان را پیگیری کنید.

## 1. یک نقشه‌ی تازه از امتیازهای برتر تعریف کنید

برای ساختن یک نقشه‌ی تازه از امتیازهای برتر، تابع `HighScore.new/0` را تعریف کنید که هیچ آرگومانی نمی‌گیرد و یک نقشه‌ی تازه و خالی از امتیازهای برتر برمی‌گرداند.

```elixir
HighScore.new()
# => %{}
```

## 2. بازیکن‌ها را به نقشه‌ی امتیازهای برتر اضافه کنید

برای افزودن یک بازیکن به نقشه‌ی امتیازهای برتر، تابع `HighScore.add_player/3` را تعریف کنید؛ این تابع ۳ آرگومان می‌گیرد:

- آرگومان اول، نقشه‌ی امتیازها است.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است.
- آرگومان سوم، امتیاز به‌صورت عدد صحیح است. این آرگومان اختیاری است؛ آرگومان سوم را با مقدار پیش‌فرض ۰ پیاده‌سازی کنید.

امتیاز اولیه‌ی پیش‌فرض را در یک ویژگی ماژول ذخیره کنید. بعداً دوباره به آن نیاز پیدا خواهید کرد.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. بازیکن‌ها را از نقشه‌ی امتیازها حذف کنید

برای حذف یک بازیکن از نقشه‌ی امتیازهای برتر، تابع `HighScore.remove_player/2` را تعریف کنید؛ این تابع ۲ آرگومان می‌گیرد:

- آرگومان اول، نقشه‌ی امتیازها است.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. امتیاز یک بازیکن را بازنشانی کنید

برای بازنشانی امتیاز یک بازیکن، تابع `HighScore.reset_score/2` را تعریف کنید؛ این تابع ۲ آرگومان می‌گیرد:

- آرگومان اول، نقشه‌ی امتیازها است.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است؛ همان بازیکنی که می‌خواهید امتیازش را بازنشانی کنید.

تابع باید در حالتی هم کار کند که بازیکن امتیازی نداشته باشد.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. امتیاز یک بازیکن را به‌روزرسانی کنید

برای به‌روزرسانی امتیاز یک بازیکن با افزودن به امتیاز قبلی، تابع `HighScore.update_score/3` را تعریف کنید؛ این تابع ۳ آرگومان می‌گیرد:

- آرگومان اول، نقشه‌ی امتیازها است.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است؛ همان بازیکنی که می‌خواهید امتیازش را به‌روزرسانی کنید.
- آرگومان سوم، امتیازی است که می‌خواهید به امتیاز برتر ذخیره‌شده **اضافه** کنید.

تابع باید در حالتی هم کار کند که بازیکن امتیاز قبلی نداشته باشد؛ فرض کنید امتیاز قبلی ۰ است.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. فهرست بازیکن‌ها را دریافت کنید

برای گرفتن فهرست بازیکن‌ها، تابع `HighScore.get_players/1` را تعریف کنید؛ این تابع ۱ آرگومان می‌گیرد:

- آرگومان اول، نقشه‌ی امتیازها است.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
