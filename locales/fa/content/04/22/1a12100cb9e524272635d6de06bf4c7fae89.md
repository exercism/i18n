# دستورالعمل‌ها

شما بوسان یک کشتی باری ساحلی هستید. بیلج، پایین‌ترین بخش بدنه‌ی کشتی، پساب جمع می‌کند و در هر نوبت کاری، تجهیزات بیلج باید باز شود، به کار بیفتد و دوباره جمع شود. هر اتفاقی هم که وسط پمپاژ رخ بدهد، تجهیزات *باید* در پایان دوباره در حالت جمع‌شده‌ی خود قرار بگیرد.

testها `<test-pump>` را در اختیار شما می‌گذارند تا پمپ‌های تازه تهیه کنید. هر پمپ جایگاهی به نام `opened>>` دارد که تا وقتی باز است `t` و پس از دور انداخته شدن `f` می‌خواند.

## 1. آبگیر را تخلیه کنید

`drain-bilge` را طوری تعریف کنید که یک پمپ را آزاد کند. فراخوانی `drain-bilge` روی یک پمپ دو بار باید بی‌ضرر باشد؛ framework خودش این کار را برای شما انجام می‌دهد.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. روتین تخلیه

`pump-out` را طوری تعریف کنید که یک پمپ و یک «نقل‌قول» بگیرد، پمپ را برای استفاده‌ی نقل‌قول روی «پشته» بگذارد و سپس پمپ را آزاد کند، *حتی اگر نقل‌قول استثنا پرتاب کند*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. روتین یک نوبت کاری کامل

`shift-routine` را طوری تعریف کنید که دو پمپ و یک نقل‌قول بگیرد. یک «حوزه‌ی نابودگر» باز کنید، *هر دو* پمپ را برای آزادسازی بدون قید و شرط ثبت کنید و سپس نقل‌قول را فراخوانی کنید. چه نقل‌قول به‌طور عادی تمام شود و چه استثنا پرتاب کند، در پایان هر دو پمپ آزاد می‌شوند.

نقل‌قول هر دو پمپ را به عنوان ورودی روی پشته دریافت می‌کند.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. تخلیه‌ی پرخطر

گاهی یک پمپ امانتی است؛ آن را فقط زمانی می‌خواهید دور بیندازید که مشکلی پیش بیاید، وگرنه نگهبان بعدی لازم دارد که پمپ باز بماند. `risky-pump-out` را طوری تعریف کنید که یک پمپ و یک نقل‌قول بگیرد، پمپ را برای آزادسازی **فقط در صورت شکست** ثبت کند و نقل‌قول را با پمپ روی پشته فراخوانی کند.

اگر نقل‌قول با موفقیت تمام شود، پمپ باز می‌ماند. اگر نقل‌قول استثنا پرتاب کند، پمپ آزاد می‌شود و استثنا منتشر می‌شود.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. یک دورانداختنی سفارشی: شیر

جعبه‌ابزار را با یک «دورانداختنی» کاملاً تازه کامل کنید: یک `valve`. «تاپل» برای شما اعلام شده است:

```factor
TUPLE: valve < disposable is-open ;
```

- `<valve> ( -- valve )` را طوری تعریف کنید که با `new-disposable` یک شیر تازه بسازد و `is-open` آن `t` باشد.
- `M: valve dispose*` را پیاده‌سازی کنید تا `is-open` را به `f` برگرداند.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
