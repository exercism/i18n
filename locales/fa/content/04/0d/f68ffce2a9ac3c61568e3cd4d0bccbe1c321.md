# سرصفحه‌ی ساختگی

## کتابخانه‌ای از توابع

این نخستین تمرینی است که می‌بینیم و در آن راه‌حلی که می‌نویسیم یک اسکریپت `main` نیست. ما یک کتابخانه می‌نویسیم تا درون اسکریپت‌های دیگری که توابع ما را فراخوانی می‌کنند `source` شود.

### `nameref`ها در Bash

این تمرین مستلزم استفاده از متغیرهای `nameref` است. این کار به نسخه‌ی حداقل ۴.۰ از bash نیاز دارد. اگر از bash پیش‌فرض روی MacOS استفاده می‌کنید، باید نسخه‌ی دیگری نصب کنید: به [نصب Bash](https://exercism.io/tracks/bash/installation) نگاه کنید.

`nameref`ها راهی برای ارسال یک متغیر به یک تابع _به‌صورت ارجاعی_ هستند. به این ترتیب، متغیر می‌تواند درون تابع تغییر کند و مقدار به‌روزشده در حوزه‌ی فراخوانی‌کننده در دسترس باشد. این هم یک مثال:
```bash
prependElements() {
    local -n __array=$1
    shift
    __array=( "$@" "${__array[@]}" )
}

my_array=( a b c )
echo "before: ${my_array[*]}"    # => before: a b c

prependElements my_array d e f
echo "after: ${my_array[*]}"     # => after: d e f a b c
```
