# مرا نادیده بگیرید

## ورودی

اسکریپت شما معمای آلفامتیک را به صورت یک رشته‌ی واحد از طریق ورودی استاندارد (stdin) دریافت می‌کند. قالب رشته‌ی معما به شکل `WORD1 + WORD2 + ... == RESULT` است.

برای مثال:

```text
SEND + MORE == MONEY
```

## خروجی

اگر معما جواب داشته باشد، یک خط چاپ کنید که از جفت‌های `LETTER=DIGIT` جداشده با فاصله تشکیل شده است و بر حسب حرف، به ترتیب الفبا مرتب شده‌اند.

برای مثال بالا، خروجی باید این باشد:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

اگر معما چندین جواب معتبر داشته باشد، چاپ هر یک از آن‌ها پذیرفتنی است.

اگر معما جوابی نداشته باشد، چیزی چاپ نکنید (یک خط خالی).
