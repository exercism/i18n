# پیوست دستورالعمل‌ها

## سفارشی‌سازی و ایجاد استثناها

گاهی لازم است در کد خود، استثناها را هم [سفارشی‌سازی](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) کنید و هم [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) کنید. وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** بگنجانید تا مشخص شود منشأ خطا چیست. این کار کد شما را خواناتر می‌کند و به‌شکل چشمگیری به اشکال‌زدایی کمک می‌کند.

استثناهای سفارشی را می‌توان از طریق کلاس‌های استثنای جدید ساخت (برای جزئیات بیشتر [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) را ببینید) که معمولاً زیرکلاس‌هایی از [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) هستند.

در موقعیت‌هایی که می‌دانید منشأ خطا از نوع خاصی از استثنا مشتق می‌شود، می‌توانید انتخاب کنید که از یکی از [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) زیر کلاس _Exception_ ارث‌بری کنید. هنگام ایجاد خطا هم باز باید یک پیام معنادار بگنجانید.

این تمرین خاص از شما می‌خواهد که دو _استثنای سفارشی_ بسازید. یک استثنا برای وقتی که بافر حلقوی شما **پر** است و باید [ایجاد](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) («پرتاب») شود، و یکی برای وقتی که **خالی** است. تست‌ها فقط در صورتی قبول می‌شوند که استثناهای مناسب را سفارشی‌سازی کنید، همان استثناها را `raise` کنید و پیام‌های خطای مناسب را بگنجانید.

برای سفارشی‌سازی یک `built-in exception`، یک `class` بسازید که از آن استثنا ارث‌بری می‌کند. وقتی استثنای سفارشی را همراه با یک پیام ایجاد می‌کنید، پیام را به‌صورت آرگومان به نوع `exception` بنویسید:

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
