# مقدمه

`when` در Kotlin یک عبارت شرطی است برای انتخاب میان چند گزینه. این ساختار شبیه `switch` در Java است و از زنجیره‌ای از `if` ... `else if` ... `else` انعطاف‌پذیرتر است.

مانند `if`، از `when` هم می‌توان به‌عنوان عبارتی استفاده کرد که مقداری تولید می‌کند.

## تطبیق یک مقدار

مقداری را که می‌خواهید با آن تطبیق دهید در پرانتز به `when` بدهید. هر شاخه آن مقدار را مقایسه می‌کند تا یکی مطابقت پیدا کند:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- هر شاخه به شکل `pattern -> result` نوشته می‌شود.
- شاخه‌ها از بالا به پایین امتحان می‌شوند تا یکی مطابقت پیدا کند. فقط اولین شاخه اجرا می‌شود.
- برای هر مقداری که در بالا نیامده است از `else` استفاده کنید (شبیه `else` پایانی در زنجیره‌ی `if`).

این کار شبیه [تطبیق الگو][pattern-matching] است. `pattern` می‌تواند مقداری برای تطبیق باشد، یا با `is` بر اساس نوع تطبیق دهد:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

یا از `in` استفاده کنید تا بررسی کنید که مقدار در یک محدوده، مجموعه، رشته یا هر چیز دیگری که متد `contains` دارد قرار گرفته است یا نه:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## شرط‌های محافظ

هنگام تطبیق یک مقدار، می‌توانید شرط‌های بیشتری را در یک `if` بعد از الگو قرار دهید. به این شرط‌ها «شرط‌های محافظ» می‌گویند.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

حتی از `else if` هم می‌توان استفاده کرد.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## تطبیق شرط‌ها

در روشی دیگر، می‌توان مقدار را حذف کرد و روی هر شاخه شرط‌های منطقی گذاشت:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

باز هم شاخه‌ها از بالا به پایین بررسی می‌شوند و فقط اولین شاخه‌ای که شرطش `true` است اجرا می‌شود.

## استفاده از `when` به‌عنوان عبارت

وقتی از `when` برای نتیجه‌اش استفاده می‌کنید (اختصاص دادن به یک متغیر، برگرداندن از یک تابع و غیره)، باید همه‌ی حالت‌های ممکن پوشش داده شوند.

- هنگام تطبیق با یک مقدار، `else` را اضافه کنید، مگر اینکه همه‌ی مقادیر ممکن از قبل پوشش داده شده باشند (برای نمونه، همه‌ی مقادیر یک `Boolean` یا یک `enum`).
- هنگام تطبیق شرط‌ها، شاخه‌ی `else` الزامی است، چون کامپایلر نمی‌تواند بداند که شرط‌های شما همه‌ی حالت‌ها را پوشش می‌دهند.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
