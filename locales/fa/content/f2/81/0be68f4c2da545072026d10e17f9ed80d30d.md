# دستورالعمل

در این تمرین، مسابقه‌هایی بین انواع مختلف خودروهای کنترلی برگزار می‌کنید.
هر خودرو سرعت و ویژگی‌های مصرف باتری خودش را دارد.

خودروها با باتری کاملاً پر (۱۰۰٪) شروع می‌کنند.
هر بار که خودرو را با کنترل از راه دور می‌رانید،
به اندازه‌ی سرعت خودرو متر می‌پیماید و درصد باقی‌مانده‌ی باتری را به اندازه‌ی مصرف باتری‌اش کاهش می‌دهد.

اگر شارژ باتری خودرو کمتر از درصد مصرف باتری آن باشد، دیگر نمی‌توانید خودرو را برانید.

هر پیست مسابقه مسافت خودش را دارد.
خودروها با بررسی اینکه آیا می‌توانند بدون تمام شدن باتری پیست را به پایان برسانند آزمایش می‌شوند.

## 1. ساخت یک خودروی کنترلی

یک ساختار `Car` با فیلدهای زیر از نوع `int` تعریف کنید:

- battery
- batteryDrain
- speed
- distance

با تعریف تابع `NewCar` امکان ساخت یک خودروی کنترلی را فراهم کنید؛ این تابع سرعت خودرو بر حسب متر
و درصد مصرف باتری را به عنوان دو پارامتر خود (هر دو از نوع `int`) می‌گیرد و یک نمونه `Car` برمی‌گرداند:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. ساخت یک پیست مسابقه

یک ساختار دیگر به نام `Track` با فیلد `distance` از نوع عدد صحیح تعریف کنید.
با تعریف تابع `NewTrack` امکان ساخت یک پیست مسابقه را فراهم کنید؛ این تابع مسافت پیست بر حسب متر را به عنوان تنها پارامتر خود (که از نوع `int` است) می‌گیرد:

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. راندن خودرو

تابع `Drive` را پیاده‌سازی کنید که تعداد مترهای پیموده‌شده را بر اساس سرعت خودرو به‌روزرسانی می‌کند و باتری را به اندازه‌ی مصرف باتری کاهش می‌دهد.
اگر باتری برای یک بار رانندگی دیگر کافی نباشد، خودرو حرکت نمی‌کند:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. بررسی اینکه آیا یک خودروی کنترلی می‌تواند مسابقه را به پایان برساند

برای به پایان رساندن یک مسابقه، خودرو باید بتواند مسافت مسابقه را بپیماید.
یعنی نباید باتری‌اش پیش از عبور از خط پایان خالی شود.
تابع `CanFinish` را پیاده‌سازی کنید که یک نمونه `Car` و یک نمونه `Track` را به عنوان پارامترهایش می‌گیرد و اگر خودرو بتواند مسابقه را به پایان برساند `true` و در غیر این صورت `false` برمی‌گرداند.

فرض کنید هم‌اکنون در خط شروع مسابقه هستید و موتور خودرو را برای مسابقه روشن می‌کنید.
در نظر بگیرید که ممکن است باتری خودرو هنگام شروع مسابقه لزوماً کاملاً شارژ نباشد:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
