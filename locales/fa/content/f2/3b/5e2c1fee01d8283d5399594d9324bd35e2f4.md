# دستورالعمل‌ها

اگر سنی بر حسب ثانیه داده شود، حساب کنید که آن شخص در هر سیاره‌ای از منظومه‌ی شمسی ما چند ساله خواهد بود.

یک سال زمینی برابر است با ۳۶۵٫۲۵ روز زمینی، یا ۳۱٬۵۵۷٬۶۰۰ ثانیه.
اگر به شما بگویند سن کسی ۱٬۰۰۰٬۰۰۰٬۰۰۰ ثانیه است، سن او ۳۱٫۶۹ سال زمینی خواهد بود.

برای سیاره‌های دیگر باید دوره‌ی مداری آن‌ها را بر حسب سال زمینی در نظر بگیرید:

| سیاره  | دوره‌ی مداری بر حسب سال زمینی |
| ------- | ----------------------------- |
| عطارد | 0.2408467                     |
| زهره   | 0.61519726                    |
| زمین   | 1.0                           |
| مریخ    | 1.8808158                     |
| مشتری | 11.862615                     |
| کیوان  | 29.447498                     |
| اورانوس | 84.016846                     |
| نپتون | 164.79132                     |

~~~~exercism/note
طول واقعی یک دور کامل گردش زمین به دور خورشید به ۳۶۵٫۲۵۶ روز (یک سال نجومی) نزدیک‌تر است.
تقویم میلادی به‌طور میانگین ۳۶۵٫۲۴۲۵ روز دارد.
اگرچه این مقدار کاملاً دقیق نیست، در این تمرین از ۳۶۵٫۲۵ استفاده می‌شود.
برای آشنایی با روش‌های دیگر اندازه‌گیری سال، [سال در ویکی‌پدیا][year] را ببینید.

[year]: https://en.wikipedia.org/wiki/Year#Summary
