# مقدمه

یک [`Set`][set-docs] مجموعه‌ای است نامرتب که (برخلاف `List`) تضمین می‌شود هیچ مقدار تکراری‌ای در خود ندارد.

پارامتر نوع جنریکِ رابط `Set` نوع عنصرهای درون `Set` را مشخص می‌کند:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

توجه کنید که متد `Set.of()` یک نمونه‌ی `Set` [تغییرناپذیر][unmodifiable-set-docs] می‌سازد.
اگر بخواهید متدهایی مانند `add` و `remove` را روی این نمونه فراخوانی کنید، در زمان اجرا با یک استثنا روبه‌رو می‌شوید.

برای ساختن یک `Set` قابل‌تغییر، باید نمونه‌ای از کلاسی بسازید که رابط `Set` را پیاده‌سازی می‌کند.
پرکاربردترین کلاس توکاری که این رابط را پیاده‌سازی می‌کند، کلاس [`HashSet`][hashset-docs] است.

```java
Set<Integer> ints = new HashSet<>();
```

رابط `Set` از رابط‌های [`Collection`][collection-docs] و [`Iterable`][iterable-docs] ارث می‌برد و بنابراین متدهای زیادی را با انواع دیگر مجموعه‌ها مشترک دارد.
اما یک تفاوت قابل‌توجه با رابط `Collection` این است که متدهایی مانند `add` و `remove` به‌جای `void` یک `boolean` برمی‌گردانند که نشان می‌دهد آیا در لحظه‌ی فراخوانی آن متد، عنصر در مجموعه وجود داشته است یا نه:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
