# دستورالعمل‌ها

شما یک پرنده‌نگر مشتاق هستید که شمار پرنده‌هایی که به باغتان آمده‌اند را ثبت می‌کند.
معمولاً برای شمردن پرنده‌ها به‌جای چوب‌خط در دفترچه‌ی یادداشت، آن‌ها را می‌شمردید، اما برای اینکه بهتر با داده‌هایتان کار کنید، شمار پرنده‌های هفته‌های گذشته را دیجیتالی کرده‌اید.

## 1. تعیین تعداد کل پرنده‌هایی که تا اینجا شمرده‌اید

بیایید تحلیل داده‌ها را با یک نمای کلی شروع کنیم.
بفهمید از زمانی که ثبت گزارش‌هایتان را شروع کرده‌اید، در کل چند پرنده شمرده‌اید.

تابعی به اسم `totalBirdCount` پیاده‌سازی کنید که آرایه‌ای از `Int`ها را می‌پذیرد و شمار پرنده‌های هر روز را در خود دارد.
این تابع باید تعداد کل پرنده‌هایی که شمرده‌اید را برگرداند.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. محاسبه‌ی تعداد پرنده‌های بازدیدکننده در یک هفته‌ی مشخص

حالا که درک کلی‌ای از اعداد شمارش پرنده‌هایتان پیدا کرده‌اید، می‌خواهید تحلیلی دقیق‌تر انجام دهید.

تابعی به اسم `birdsInWeek` پیاده‌سازی کنید که آرایه‌ای از شمار پرنده‌های هر روز و شماره‌ی یک هفته را می‌پذیرد.

این تابع تعداد کل پرنده‌هایی را برمی‌گرداند که در آن هفته‌ی مشخص شمرده‌اید.
می‌توانید فرض کنید هفته‌ها همیشه به‌طور کامل ثبت می‌شوند.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. اصلاح یک اشتباه در شمارش

متوجه شده‌اید که در تمام مدتی که می‌خواستید پرنده‌ها را ثبت کنید، پرنده‌ای در گوشه‌ی دورافتاده‌ی باغ پنهان شده بود.

فهمیده‌اید که این پرنده همیشه یک روز در میان در باغ شما می‌گذراند.

نمی‌دانید در فاصله‌ی بین آن روزها دقیقاً کجا بوده، اما قطعاً در باغ شما نبوده است.

شهود پرنده‌نگری‌تان هم به شما می‌گوید که این پرنده در نخستین روزی که در فهرست‌تان ثبت کرده‌اید، در باغ شما بوده است.

با توجه به این اطلاعات تازه، تابعی به اسم `fixBirdCountLog` بنویسید که آرایه‌ای از پرنده‌های شمرده‌شده در هر روز را به‌عنوان آرگومان می‌گیرد و آرایه را پس از اصلاح اشتباه شمارش برمی‌گرداند.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
