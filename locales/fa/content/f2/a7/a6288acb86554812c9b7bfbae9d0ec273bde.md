# مقدمه

وقتی تعداد تکرارهای یک حلقه از پیش معلوم نیست، یعنی «تا وقتی که یک شرط دیگر برقرار نماند ادامه بده»، Factor از ترکیب‌کننده‌ی `while` در [`kernel`][kernel] استفاده می‌کند:

```
while ( pred body -- )
```

`pred` و `body` هر دو quotation هستند که روی پشته‌ی داده عمل می‌کنند. `while`، `pred` را فراخوانی می‌کند؛ اگر `pred` روی بالای پشته مقداری «درست» باقی بگذارد، `while`، `body` را اجرا می‌کند و همین کار را تکرار می‌کند؛ در غیر این صورت متوقف می‌شود. وضعیتی که از یک تکرار به تکرار بعدی منتقل می‌شود، بین فراخوانی‌ها روی پشته باقی می‌ماند (یا اگر بیش از یک بخش وضعیت وجود داشته باشد، در متغیرهای محلی نام‌دار).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` شکل متقارن آن است: آن‌قدر ادامه می‌دهد *تا* که شرط «درست» شود.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
