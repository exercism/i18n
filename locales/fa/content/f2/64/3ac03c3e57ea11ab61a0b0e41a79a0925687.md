# مقدمه

«کست کردن» و «تبدیل نوع»، دو روش متفاوت برای تغییر دادن یک عبارت از یک نوع داده به نوع دیگر هستند.

می‌توان یک عبارت را با عملگر کست `(<type>)` به نوع دیگری کست کرد.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

اگر نوع‌ها با هم سازگار نباشند، نمونه‌ای از `InvalidCastException` پرتاب می‌شود. در مورد اعداد، این یعنی نوع گیرنده نمی‌تواند مقدار کست‌شده را نمایش دهد. در مورد کلاس‌ها، یکی از دو نوع باید از دیگری مشتق شده باشد (این موضوع در مورد `struct`ها هم به‌سادگی صدق می‌کند).

جایگزینی برای _کست کردن_، _تبدیل نوع_ با استفاده از عملگر `is` است. این روش معمولاً برای نوع‌های ارجاعی و nullable به کار می‌رود.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

اگر لازم است نوع دقیق یک شیء را تشخیص دهید، ممکن است `is` کمی بیش از حد سهل‌گیرانه باشد، چون برای یک کلاس و هر کلاس و واسطی که به‌طور مستقیم یا غیرمستقیم از آن مشتق شده‌اند، «درست» را برمی‌گرداند. `typeof` و `Object.GetType()` در این حالت راه‌حل هستند.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
