# ترجیح `Number` بر `parse`

اگر ندانید ورودی عدد است یا نه، خانواده‌ی `parseXXX` برای تبدیل یک ورودی به عدد _عالی_ است؛ اما وقتی می‌دانید، بهتر است از تابع سختگیرانه‌ترِ [`Number(...)`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number#Convert_numeric_strings_and_null_to_numbers ) استفاده کنید.
