# دستورالعمل‌ها

Elyse قرار است جادوگر شود و باید چند مقدمه‌ی ساده را تمرین کند.
او یک دسته کارت دارد که می‌خواهد با آن‌ها کار کند.

برای اینکه کارها کمی ساده‌تر شود، فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند، بنابراین دسته‌ی کارت‌هایش را می‌توان با یک «آرایه» از اعداد نمایش داد.
موقعیت هر کارت با «اندیس» آن در آرایه متناظر است.
یعنی موقعیت ۰ به کارت اول اشاره دارد، موقعیت ۱ به کارت دوم و به همین ترتیب.

~~~~exercism/note
همه‌ی توابع باید آرایه‌ی کارت‌ها را به‌روزرسانی کنند و سپس آرایه‌ی تغییر‌یافته را برگردانند. این روشی رایج در کار است که به الگوی Builder معروف است و به شما امکان می‌دهد توابع را به‌شکلی زیبا پشت سر هم زنجیر کنید.
~~~~

## 1. برداشتن یک کارت از دسته

برای برداشتن یک کارت، کارت موجود در اندیس `position` را از دسته‌ی داده‌شده برگردانید.

تابع `getCard(at:from:)` را پیاده‌سازی کنید که دو آرگومان می‌گیرد: `at` که موقعیت کارت در دسته است و `from` که دسته‌ی کارت‌ها است.
تابع باید کارت موجود در موقعیت `index` را از دسته‌ی داده‌شده برگرداند.

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. تغییر یک کارت در دسته

با کمی شعبده‌بازی، کارت موجود در اندیس `position` را با کارت جانشینی که داده شده است عوض کنید.

تابع `setCard(at:in:to)` را پیاده‌سازی کنید که سه آرگومان می‌گیرد: `at` که موقعیت کارت در دسته است، `in` که دسته‌ی کارت‌ها است و `to` که کارت جدیدی است که جای کارت موجود در موقعیت `index` را می‌گیرد.
تابع باید یک رونوشت از دسته برگرداند که در آن کارت موجود در موقعیت `index` با کارت جدید جایگزین شده است.
اگر `index` داده‌شده اندیس معتبری در دسته نباشد، باید دسته‌ی اصلی بدون تغییر برگردانده شود.

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. درج یک کارت در بالای دسته

با درج یک کارت جدید در بالای دسته، کارتی را ظاهر کنید.

تابع `insert(_:atTopOf:)` را پیاده‌سازی کنید که دو آرگومان می‌گیرد: کارت جدیدی که باید درج شود و دسته‌ی کارت‌ها.
تابع باید یک رونوشت از دسته برگرداند که کارت جدید داده‌شده به بالای دسته اضافه شده است.

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. حذف یک کارت از دسته

با حذف کارت موجود در `position` داده‌شده از دسته، کارتی را ناپدید کنید.

تابع `removeCard(at:from:)` را پیاده‌سازی کنید که دو آرگومان می‌گیرد: `at` که موقعیت کارت در دسته است و `from` که دسته‌ی کارت‌ها است.
تابع باید رونوشتی از دسته برگرداند که کارت موجود در موقعیت `index` از آن حذف شده است.
اگر `index` داده‌شده اندیس معتبری در دسته نباشد، باید دسته‌ی اصلی بدون تغییر برگردانده شود.

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. درج یک کارت در دسته

با درج یک کارت جدید در `position` داده‌شده در دسته، کارتی را ظاهر کنید.

تابع `insert(_:at:from:)` را پیاده‌سازی کنید که سه آرگومان می‌گیرد: کارت جدیدی که باید درج شود، موقعیتی که کارت جدید باید در آن درج شود و دسته‌ی کارت‌ها.
تابع باید رونوشتی از دسته برگرداند که کارت جدید داده‌شده در موقعیت داده‌شده به آن اضافه شده است.
اگر `index` داده‌شده اندیس معتبری در دسته نباشد، باید دسته‌ی اصلی بدون تغییر برگردانده شود.

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. بررسی اندازه‌ی دسته

بررسی کنید که آیا اندازه‌ی دسته با `stackSize` برابر است یا نه.

تابع `checkSizeOfStack(_:_:)` را پیاده‌سازی کنید که دو آرگومان می‌گیرد: `stack` که دسته‌ی کارت‌ها است و `stackSize` که اندازه‌ی دسته است.
تابع باید اگر اندازه‌ی دسته با `stackSize` برابر باشد `true` و در غیر این صورت `false` برگرداند.

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
