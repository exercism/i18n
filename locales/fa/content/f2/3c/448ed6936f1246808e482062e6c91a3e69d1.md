## گزینه‌های اضافی خط فرمان jq

خواهید دید که در tests گزینه‌های اضافی برای `jq` وجود دارد.

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

این گزینه‌ها چه هستند؟

- `-s`

  این حالت «slurp» است.
  به‌جای در نظر گرفتن ورودی به‌صورت جریانی از اشیای JSON،
  کل ورودی در یک آرایه جمع می‌شود.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  ممکن است قبلاً `-r` را دیده باشید، که رشته‌های «خام» را (بدون کوتیشن) به خروجی می‌دهد.
  این گزینه دقیقاً برعکس آن است.
  هر خط از ورودی به‌عنوان یک رشته در نظر گرفته می‌شود.

  دو مثال:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

وقتی این دو گزینه را با هم به کار می‌برید، آرایه‌ای از رشته‌ها به دست نمی‌آورید؛ بلکه کل ورودی را به‌صورت یک رشته‌ی واحد دریافت می‌کنید، از جمله کاراکترهای خط جدید انتهای خطوط.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

مدیریت این ورودی بخشی از چالش این تمرین است.
