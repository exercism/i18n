# مقدمه

یک «نوع داده‌ی جبری» (ADT) تعداد ثابتی از حالت‌های نام‌دار را نمایش می‌دهد.
هر مقدار از یک نوع داده‌ی جبری دقیقاً با یکی از حالت‌های نام‌دار متناظر است.

یک نوع داده‌ی جبری با کلیدواژه‌ی `data` تعریف می‌شود و حالت‌های آن با کاراکتر خط عمودی (`|`) از هم جدا می‌شوند.
اگر هیچ‌یک از حالت‌ها داده‌ی وابسته‌ای نداشته باشند، این نوع داده‌ی جبری شبیه چیزی است که در زبان‌های دیگر معمولاً به آن «برشماری» (یا «enum») می‌گویند.

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

هر حالت از یک نوع داده‌ی جبری می‌تواند به‌صورت اختیاری داده‌ی وابسته‌ای داشته باشد و حالت‌های مختلف می‌توانند انواع متفاوتی از داده داشته باشند.
وقتی یک حالت داده‌ی وابسته دارد، به یک «سازنده» نیاز است.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

ساخت یک مقدار برای یک حالت مشخص با اشاره به اسم آن انجام می‌شود (مثلاً `NInt 22`).
چون اسم حالت‌ها صرفاً توابع سازنده هستند، داده‌ی وابسته را می‌توان مانند یک آرگومان معمولی تابع پاس داد.

نوع‌های داده‌ی جبری «برابری ساختاری» دارند؛ یعنی دو مقدار برای یک حالت و با داده‌ی یکسان (اختیاری) معادل‌اند.

هرچند می‌توان با عبارات `if/else` با نوع‌های داده‌ی جبری کار کرد، روش توصیه‌شده برای کار با آن‌ها استفاده از «تطبیق الگو» به کمک دستور `case` است:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
