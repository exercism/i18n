# دستورالعمل‌ها

در این تمرین قصد دارید برخی از قواعد [بلک‌جک][blackjack] را پیاده‌سازی کنید، مانند شیوه‌ی انجام و امتیازدهی بازی.

**نکته**: در این تمرین، حرف _`A`_ یعنی آس، حرف _`J`_ یعنی سرباز، حرف _`Q`_ یعنی بی‌بی و حرف _`K`_ یعنی شاه.
جوکرها کنار گذاشته می‌شوند.
یک [دسته‌ی کارت ۵۲تایی استاندارد با خال‌های فرانسوی][standard_deck] در نظر گرفته می‌شود، اما در بیشتر نسخه‌ها، برای بازی چند دسته کارت را با هم مخلوط می‌کنند.

## 1. محاسبه‌ی ارزش یک کارت

در بلک‌جک، اینکه آس ۱ امتیاز ارزش داشته باشد یا ۱۱، به خودِ بازیکن بستگی دارد (_بعداً بیشتر درباره‌ی این صحبت می‌کنیم_).
کارت‌های تصویری (`J`، `Q`، `K`) ۱۰ امتیاز دارند و ارزش هر کارت دیگری برابر با عدد روی آن (_مقدار عددی_) است.

تابع `value_of_card(<card>)` را با پارامتر `card` تعریف کنید.
تابع باید _ارزش عددی_ رشته‌ی کارتِ ورودی را برگرداند.
از آنجا که یک آس می‌تواند چند مقدار بگیرد (۱ **یا** ۱۱)، این تابع باید فعلاً ارزش کارت آس را ۱ در نظر بگیرد.
بعداً تابعی پیاده‌سازی خواهید کرد که با در نظر گرفتن دستِ موجود، ارزش کارت آس را مشخص می‌کند.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. تعیین اینکه کدام کارت ارزش بیشتری دارد

تابع `higher_card(<card_one>, <card_two>)` را با پارامترهای `card_one` و `card_two` تعریف کنید.
برای امتیازدهی، ارزش `J`، `Q` یا `K` برابر ۱۰ است.
تابع باید برگرداند کدام کارت از نظر امتیازدهی ارزش بیشتری دارد.
اگر ارزش هر دو کارت برابر باشد، هر دو را برگردانید.
برگرداندن هر دو کارت با استفاده از یک کاما در دستور `return` انجام می‌شود:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

آس می‌تواند چند مقدار بگیرد، بنابراین در این تمرین کارت‌های `A` را با ارزش ۱ در نظر می‌گیریم.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. محاسبه‌ی ارزش یک آس

همان‌طور که پیش‌تر گفتیم، یک آس می‌تواند _یا_ ۱ امتیاز ارزش داشته باشد **یا** ۱۱ امتیاز.
بازیکنان تلاش می‌کنند تا حد امکان به امتیاز ۲۱ نزدیک شوند، بدون آنکه از ۲۱ _فراتر_ بروند (_«سوختن»_).

تابع `value_of_ace(<card_one>, <card_two>)` را با پارامترهای `card_one` و `card_two` تعریف کنید؛ این‌ها جفتی از کارت‌های موجود در دست، _پیش از_ گرفتن کارت آس هستند.
تابع شما باید تصمیم بگیرد که آسِ بعدی ارزش ۱ می‌گیرد یا ۱۱، و همان مقدار را برگرداند.
یادتان باشد: ارزش دست همراه با آس باید تا حد امکان بالا باشد، _بدون آنکه_ از ۲۱ فراتر برود.

**راهنما**: اگر از قبل آسی در دست داشته باشیم، ارزش آسِ بعدی ۱ خواهد بود.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. تشخیص دستِ «نچرال» یا «بلک‌جک»

اگر در دو کارت اول، یک آس (`A`) و یک کارت ده (10، `K`، `Q` یا `J`) به بازیکن داده شود، بازیکن امتیاز ۲۱ دارد.
به این دست، دستِ **بلک‌جک** می‌گویند.


تابع `is_blackjack(<card_one>, <card_two>)` را با پارامترهای `card_one` و `card_two` تعریف کنید که جفتی از کارت‌ها هستند.
مشخص کنید که آیا این دستِ دوکارتی یک **بلک‌جک** است و اگر هست، مقدار «منطقی» `True` و در غیر این صورت `False` را برگردانید.

**نکته**: محاسبه‌ی امتیاز را می‌توان به روش‌های زیادی انجام داد.
اما اگر ممکن باشد، ترجیح می‌دهیم بررسی کنید که آیا یک آس و یک کارت ده **_در_** دست وجود دارند (_یا در موقعیت مشخصی قرار دارند_)، نه اینکه ارزش‌های دست را _جمع_ کنید.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. تقسیم جفت‌ها

اگر دو کارت اول یک دست ارزش یکسانی داشته باشند (_مثلاً دو شش، یا یک `Q` و `K`_)، بازیکن می‌تواند آن‌ها را به‌عنوان دو دست جداگانه در نظر بگیرد.
به این کار «تقسیم جفت‌ها» می‌گویند.

تابع `can_split_pairs(<card_one>, <card_two>)` را با پارامترهای `card_one` و `card_two` تعریف کنید که جفتی از کارت‌ها هستند.
مشخص کنید که آیا این دستِ دوکارتی می‌تواند به دو جفت تقسیم شود.
اگر این دست قابل تقسیم باشد، مقدار منطقی `True` و در غیر این صورت `False` را برگردانید.

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. دو برابر کردن شرط

وقتی مجموع دو کارت اولیه‌ای که داده می‌شود ۹، ۱۰ یا ۱۱ امتیاز باشد، بازیکن می‌تواند شرطی اضافی به اندازه‌ی شرط اولیه‌ی خود بگذارد.
به این کار «دو برابر کردن شرط» می‌گویند.

تابع `can_double_down(<card_one>, <card_two>)` را با پارامترهای `card_one` و `card_two` تعریف کنید که جفتی از کارت‌ها هستند.
مشخص کنید که آیا این دستِ دوکارتی می‌تواند «دو برابر» شود و اگر می‌تواند، مقدار منطقی `True` و در غیر این صورت `False` را برگردانید.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
