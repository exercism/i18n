# درباره

دستورهای شرطی در C++ شبیه دستورهای شرطی در زبان‌های دیگر هستند.
نوع زیربنایی هر عملیات شرطی، نوع `bool` است که می‌تواند مقدار `true` یا `false` را داشته باشد.
شرط‌ها معمولاً به عنوان سازوکارهای کنترل جریان برای بررسی شرط‌های مختلف به کار می‌روند.

می‌توان از دستور `if` استفاده کرد که اگر شرط زیربنایی `true` باشد، کدش را اجرا می‌کند:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

در موقعیت‌هایی که بیش از یک حالت درگیر است، می‌توان چندین دستور `if` را با استفاده از دستورهای `else if` و `else` به هم زنجیر کرد.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

از C++17 به بعد، دستورهای `if` می‌توانند شامل یک دستور مقداردهی کوتاه هم باشند که می‌توان از آن برای مقداردهی اولیه‌ی یک یا چند متغیر برای دستور `if` استفاده کرد.
برای مثال:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> نکته: به هیچ‌یک از متغیرهایی که در بخش مقداردهی ساخته می‌شوند، پس از پایان دستور `if` نمی‌توان دسترسی داشت.
