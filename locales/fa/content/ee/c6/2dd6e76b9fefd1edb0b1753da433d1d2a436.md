# حلقه‌ی `for-in`

حلقه‌زدن مفهومی بنیادی در برنامه‌نویسی است که به شما امکان می‌دهد یک بلوک کد را چندین بار اجرا کنید.
در Swift دو نوع حلقه وجود دارد: [حلقه‌های `for-in`][for-loops] و حلقه‌های `while`.
در این فصل با حلقه‌های `for-in` آشنا می‌شوید.

حلقه‌های `for-in` به شما امکان می‌دهند روی دنباله‌ای از مقادیر پیمایش کنید، هر عنصر را به نوبت بردارید و آن را به متغیری به انتخاب خودتان نسبت دهید.
Swift به شما امکان می‌دهد روی انواع گوناگونی از دنباله‌ها پیمایش کنید، مانند بازه‌ها، آرایه‌ها و رشته‌ها (و انواع دیگری که بعداً بررسی می‌شوند).
وقتی روی همه‌ی عناصر دنباله پیمایش شد، حلقه پایان می‌یابد.

حلقه‌های `for-in` با کلیدواژه‌ی `for` تعریف می‌شوند، سپس یک اسم متغیر، کلیدواژه‌ی `in` و دنباله‌ای از مقادیر که روی آن پیمایش می‌شود.
متغیری که در حلقه‌ی `for-in` داده می‌شود تغییرناپذیر است؛ یعنی نمی‌توانید مقدارش را داخل حلقه تغییر دهید.
اینجا نمونه‌ای از یک حلقه‌ی `for-in` را می‌بینید که روی آرایه‌ای از اعداد پیمایش می‌کند:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
متغیر `number` در حلقه‌ی `for-in` تعریف می‌شود و فقط در محدوده‌ی همان حلقه در دسترس است.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## پیمایش روی یک بازه

همچنین می‌توانید با یک حلقه‌ی `for-in` روی بازه‌ای از اعداد پیمایش کنید.
این کار به شما امکان می‌دهد یک بلوک کد را تعداد مشخصی بار اجرا کنید؛ برای نمونه، بازه‌ی `1...5` روی اعداد ۱، ۲، ۳، ۴ و ۵ پیمایش می‌کند، بنابراین حلقه ۵ بار اجرا می‌شود.
گاهی ممکن است بخواهید روی اندیس‌ها در ساختاری داده‌ای مانند آرایه پیمایش کنید؛ در این صورت می‌توانید از بازه‌ی `0..<array.count` استفاده کنید.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## پیمایش روی یک رشته

همچنین می‌توانید با یک حلقه‌ی `for-in` روی یک رشته پیمایش کنید.
این کار به شما امکان می‌دهد روی هر کاراکتر رشته پیمایش کنید؛ به‌طور خاص توجه کنید که نوع داده‌شده در حلقه `Character` است.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## متغیرهای استفاده‌نشده

اگر به مقدار متغیر در حلقه نیازی ندارید، می‌توانید از زیرخط `_` استفاده کنید تا آن را نادیده بگیرید.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift همچنین تابع `stride` را فراهم می‌کند که به شما امکان می‌دهد دنباله‌ای روی یک بازه با گام مشخص بسازید.
سپس می‌توان با یک حلقه‌ی `for-in` روی آن پیمایش کرد.
`stride` به دو شکل [`stride(from:to:by:)`][stride-to] یا [`stride(from:through:by:)`][stride-through] تعریف می‌شود؛ اولی عدد پایانی را در بر نمی‌گیرد و دومی آن را هم در بر می‌گیرد.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

توجه کنید که پارامتر `to` انحصاری است، بنابراین حلقه تا عدد پیش از پارامتر `to` پیمایش می‌کند، در حالی که پارامتر `through` فراگیر است، پس در این حالت عدد `10` را هم در بر می‌گیرد.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
