# مقدمه

در مفهوم [`Vectors`][vectors] گفتیم که «آرایه‌ها در قلب زبان Julia قرار دارند» و بردار یک آرایه‌ی تک‌بعدی است.

با این حساب، می‌توان امیدوار بود که این زبان راه‌های متنوع و قدرتمند زیادی برای _انجام کارها_ با بردارها در اختیارمان بگذارد، هر معنایی که این جمله داشته باشد.

## توابعی که ورودی بردار می‌گیرند

بعضی توابع بسیار ساده ورودی بردار می‌گیرند و خروجی اسکالر برمی‌گردانند.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## محاسبات

فرض کنید یک بردار عددی دارید و می‌خواهید ۰٫۵ را از هر مقدار کم کنید.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

این کار شکست می‌خورد؛ پس کم کردن یک بردار دیگر چطور؟

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

این هم موفق بود، اما هرچه بردارها بلندتر می‌شوند، خسته‌کننده و پرمصرف می‌شود.

خوشبختانه Julia یک نقطه‌ی «جادویی» دارد که این مشکل را خیلی ساده حل می‌کند: تنها کاری که لازم است انجام دهید، `v .- 0.5` است.

بخش بعدی دلیلش را توضیح می‌دهد.

## پخش

خب، `v - 0.5` شکست می‌خورد اما `v .- 0.5` موفق می‌شود و باید بفهمیم این نقطه چه کاری انجام می‌دهد.

دو مورد که با هم نتیجه‌ی مطلوب را به دست می‌دهند.

### ۱. اعمال عنصربه‌عنصر

نخست، اضافه کردن یک نقطه _پیش از_ هر عملگر میان‌وندی یعنی «این عمل را جداگانه روی هر عنصر اعمال کن».

به همین ترتیب، اضافه کردن یک نقطه _بعد از_ اسم یک تابع، آن را «برداری» می‌کند، حتی اگر آن تابع برای ورودی‌های اسکالر نوشته شده باشد.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### ۲. بسط تک‌عضوی

در مثال قبلی دیدیم که می‌توانیم بردارهایی با طول برابر را از هم کم کنیم؛ اما لطفاً بدانید که `.-` با مشخص کردن قصد عنصربه‌عنصر، عملگری _امن‌تر_ از `-` است.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

بردارهایی با طول نابرابر چه؟

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

به‌طور کلی، طول‌های نابرابر خطا هستند، _مگر_ وقتی یکی از آن‌ها طول ۱ داشته باشد (به بیان دقیق‌تر، یک بعد «تک‌عضوی»).

مقادیر تک‌عضوی مانند `[0.5,]` یا خود `0.5` به‌طور خودکار با تکرار به طول لازم گسترش می‌یابند.
این در قلب `broadcasting` قرار دارد.

### پخش درجا

اگر مصرف حافظه مهم باشد، عملیات درجا راهی رایج برای کاهش تخصیص‌ها هستند.

اما عملیات پخش در مثال‌های بالا، به‌جای تغییر `Vector` اصلی، یک `Vector` جدید می‌سازند.

برای تغییر درجای `Vector` اصلی، باید تغییر را پخش کرد.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## اندیس‌گذاری

انتخاب عناصر یک بردار با شماره‌ی اندیس در مفاهیم قبلی بحث شده است.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### اندیس‌گذاری منطقی

همچنین می‌توان عناصری را انتخاب کرد که در یک عبارت «منطقی» صدق می‌کنند (به بیان دقیق‌تر، یک «گزاره»).
این کار معمولاً به پخش نیاز دارد.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

در عبارت‌های پیچیده‌تر، معمولاً تعداد نقطه‌ها زیاد می‌شود (اما کوچک‌اند و تایپ کردنشان آسان است).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

یادآوری: «بردار» در واقع می‌تواند هر تکرارپذیر مرتب مناسب باشد، مانند یک بازه:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
