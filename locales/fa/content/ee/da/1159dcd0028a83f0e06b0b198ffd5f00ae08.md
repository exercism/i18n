# یادگیری

اگر تازه با SQLite آشنا شده‌اید و می‌خواهید اصول نحوه‌ی نگارش SQL و مدیریت پایگاه داده را یاد بگیرید، چند منبع عالی که مخصوص مبتدی‌ها تهیه شده‌اند در ادامه آمده است:

- **آشنایی با SQL در یوتیوب**: ویدیوی [What is SQL?][sql-youtube] را ببینید؛ ویدیویی ۴ دقیقه‌ای برای مبتدی‌ها از Danielle Thé.

- **آموزش‌های SQLite**: [SQLite Tutorials][sqlite-tutorial] آشنایی دوستانه‌ای با SQLite برای مبتدی‌ها فراهم می‌کند و مفاهیم بنیادین مثل ساخت پایگاه داده، پرس‌وجو و دست‌کاری داده را پوشش می‌دهد.

- **SQLZoo**: مهارت‌های SQL خود را با تمرین‌ها و آموزش‌های تعاملی [SQLZoo][sqlzoo] تمرین کنید، از جمله محتوای ویژه‌ی SQLite که برای مبتدی‌ها مناسب است.

این منابع پایه‌ای برای یادگیری SQLite و نحوه‌ی نگارش SQL فراهم می‌کنند و به مبتدی‌ها کمک می‌کنند مفاهیم پایگاه داده را بفهمند و با پایگاه‌های داده‌ی SQLite تجربه‌ی عملی به دست آورند.

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
