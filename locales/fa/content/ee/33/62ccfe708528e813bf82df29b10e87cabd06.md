# راهنمایی‌ها

## کلی

- برای ساختن متدهای `getter` و `setter` باید از ماکروهای `getter`، `setter` و `property` استفاده کنید.

## 1. ایجاد یک حالت اولیه برای ترازو

- برای مقداردهی اولیه به ترازو باید از متد `initialize` استفاده کنید.
- این متد باید دو آرگومان بگیرد: `precision` و `metric` که به ترتیب از نوع `Int32` و `Bool` هستند.
  باید از این دو برای تنظیم متغیرهای نمونه‌ی `@precision` و `@metric` استفاده کنید.
- مقدار متغیر نمونه‌ی `@weight` باید برابر `0.0` تنظیم شود.

## 2. امکان داشتن دقت برای ترازو

- ماکروی `getter` به شما امکان می‌دهد متدی تعریف کنید که مقدار یک متغیر نمونه را برمی‌گرداند.

## 3. امکان تنظیم وزن روی ترازو

- ماکروی `property` به شما امکان می‌دهد متدی تعریف کنید که مقدار یک متغیر نمونه را می‌گیرد و تنظیم می‌کند.

## 4. امکان تغییر ترازو میان واحدهای متریک و امپریال

- ماکروی `setter` به شما امکان می‌دهد متدی تعریف کنید که مقدار یک متغیر نمونه را تنظیم می‌کند.
