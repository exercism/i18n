# راهنمایی‌ها

## کلی

- [صفحه‌ی گرامر بند معین در ویکی‌پدیا](https://en.wikipedia.org/wiki/Definite_clause_grammar) نمای کلی خوبی از DCGها ارائه می‌دهد
- [مقدمه‌ی DCG در Prolog](https://www.metalevel.at/prolog/dcg) مقدمه‌ای بسیار مفید درباره‌ی DCGهای Prolog دارد
- [مستندات dcg/basics در SWIPL](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) توابع اولیه‌ی داخلی‌ای را فهرست می‌کند که می‌توانید از آن‌ها استفاده کنید

## 3. پشتیبانی از همه‌ی فاصله‌ها (به‌جز خط‌های جدید)

- یک [تابع اولیه‌ی داخلی](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) هست که می‌توانید برای این کار از آن استفاده کنید

## 4. تجزیه‌ی نیم‌کره‌ی عرض جغرافیایی

- قواعد DCG می‌توانند مانند واقعیت‌ها یا قواعد معمولی متغیر داشته باشند
- قواعد DCG می‌توانند مانند واقعیت‌ها یا قواعد معمولی چند اعلان داشته باشند

## 5. تجزیه‌ی نیم‌کره‌ی طول جغرافیایی

- قواعد DCG می‌توانند مانند واقعیت‌ها یا قواعد معمولی متغیر داشته باشند
- قواعد DCG می‌توانند مانند واقعیت‌ها یا قواعد معمولی چند اعلان داشته باشند

## 6. تجزیه‌ی درجه‌ها

- یک [تابع اولیه‌ی داخلی](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) هست که می‌توانید برای این کار از آن استفاده کنید

## 7. تجزیه‌ی درجه‌های عرض جغرافیایی

- می‌توانید از قاعده‌ی `degrees` دوباره استفاده کنید
- از ساختار زبانی `{}//1` می‌توان برای فراخوانی گزاره‌های Prolog از داخل یک قاعده استفاده کرد

## 9. تجزیه‌ی عرض جغرافیایی

- قالب یک عرض جغرافیایی چنین است: `<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>`
- از قواعدی که تا حالا پیاده‌سازی کرده‌اید دوباره استفاده کنید

## 10. تجزیه‌ی طول جغرافیایی

- قالب یک طول جغرافیایی چنین است: `<LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>`
- از قواعدی که تا حالا پیاده‌سازی کرده‌اید دوباره استفاده کنید

## 11. تجزیه‌ی مختصات

- قالب یک مختصات چنین است: `<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>`
- از قواعدی که تا حالا پیاده‌سازی کرده‌اید دوباره استفاده کنید
