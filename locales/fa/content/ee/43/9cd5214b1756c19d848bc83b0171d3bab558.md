# انواع عدد

Crystal برای کاربردهای گوناگون، نوع‌های عددی مختلفی دارد.
برای مثال، بعضی از نوع‌ها سریع‌ترند اما بازه‌ی مقادیر ممکن‌شان از بقیه کوچک‌تر است.
بعضی دیگر بازه‌ی گسترده‌تری از مقادیر ممکن دارند اما کندترند.

در Crystal هم نوع‌های عدد صحیح علامت‌دار وجود دارد و هم نوع‌های عدد صحیح بدون علامت.
نوع‌های عدد صحیح علامت‌دار می‌توانند مثبت یا منفی باشند.
نوع‌های عدد صحیح بدون علامت فقط می‌توانند مثبت باشند.

## نوع‌های عدد صحیح علامت‌دار

این‌ها [نوع‌های عدد صحیح علامت‌دار][int] در Crystal هستند:

| نوع      | اندازه (بیت) | بازه                                                                                                        |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | ۸           | از -۱۲۸ تا ۱۲۷                                                                                              |
| `Int16`  | ۱۶          | از -۳۲_۷۶۸ تا ۳۲_۷۶۷                                                                                        |
| `Int32`  | ۳۲          | از -۲_۱۴۷_۴۸۳_۶۴۸ تا ۲_۱۴۷_۴۸۳_۶۴۷                                                                         |
| `Int64`  | ۶۴          | از -۹_۲۲۳_۳۷۲_۰۳۶_۸۵۴_۷۷۵_۸۰۸ تا ۹_۲۲۳_۳۷۲_۰۳۶_۸۵۴_۷۷۵_۸۰۷                                                 |
| `Int128` | ۱۲۸         | از -۱۷۰_۱۴۱_۱۸۳_۴۶۰_۴۶۹_۲۳۱_۷۳۱_۶۸۷_۳۰۳_۷۱۵_۸۸۴_۱۰۵_۷۲۸ تا ۱۷۰_۱۴۱_۱۸۳_۴۶۰_۴۶۹_۲۳۱_۷۳۱_۶۸۷_۳۰۳_۷۱۵_۸۸۴_۱۰۵_۷۲۷ |

نوع‌های کوچک‌تر حافظه‌ی کمتری مصرف می‌کنند و از نوع‌های بزرگ‌تر سریع‌ترند، اما بازه‌ی کوچک‌تری از مقادیر ممکن دارند.

اگر بدانید که مقادیر در بازه‌ی مشخصی قرار می‌گیرند، بهترین کار استفاده از کوچک‌ترین نوع ممکن است تا در حافظه صرفه‌جویی شود و کارایی بهبود یابد.

نوع پیش‌فرض عدد صحیح `Int32` است.
برای تعریف یک عدد صحیح با نوع مشخص، می‌توانید نام نوع را به‌عنوان پسوند به کار ببرید و `<number>_I <bit>` را به عدد اضافه کنید.

```crystal
1_i8.class
# => Int8
```

می‌توانید از متد `to_i<bit>` برای تبدیل میان نوع‌های مختلف عدد صحیح استفاده کنید.
متد `to_i` به نوع پیش‌فرض عدد صحیح، `Int32`، تبدیل می‌کند.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## نوع‌های عدد صحیح بدون علامت

این‌ها [نوع‌های عدد صحیح بدون علامت][uint] در Crystal هستند:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

تنها تفاوت میان عددهای صحیح علامت‌دار و بدون علامت این است که عددهای صحیح بدون علامت فقط می‌توانند مثبت باشند.
برای تعریف یک عدد صحیح بدون علامت با نوع مشخص، می‌توانید نام نوع را به‌عنوان پسوند به کار ببرید و `<number>_u<bit>` را به عدد اضافه کنید.
می‌توانید از متد `to_u<bit>` برای تبدیل میان نوع‌های مختلف عدد صحیح بدون علامت استفاده کنید.
متد `to_u` به نوع پیش‌فرض عدد صحیح بدون علامت، `UInt32`، تبدیل می‌کند.

```crystal
1_u8.to_u16.class
# => UInt16
```

## نوع‌های ممیز شناور

این‌ها نوع‌های ممیز شناور در Crystal هستند:

| نوع       | اندازه (بیت) | بازه                 |
| --------- | ----------- | -------------------- |
| `Float32` | ۳۲          | از ۱.۲E-۳۸ تا ۳.۴E+۳۸ |
| `Float64` | ۶۴          | از ۲.۳E-۳۰۸ تا ۱.۷E+۳۰۸ |

دو [نوع ممیز شناور][float] متفاوت وجود دارد که یکی از دیگری دقیق‌تر است.

نوع پیش‌فرض ممیز شناور `Float64` است.

می‌توانید از متد `to_f<bit>` برای تبدیل میان نوع‌های مختلف ممیز شناور استفاده کنید.
متد `to_f` به نوع پیش‌فرض ممیز شناور، `Float64`، تبدیل می‌کند.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
