# راهنمایی‌ها

## 1. نسبت موفقیت‌ها به آزمایش‌ها را به دست آورید

- اعداد `Rational` را با استفاده از موفقیت‌ها به عنوان صورت و آزمایش‌ها به عنوان مخرج بسازید.
- برای ساختن آرایه‌ی جدید می‌توان از حلقه‌ها، درک‌های فهرستی یا عملیات برداری استفاده کرد.

## 2. احتمال‌های حقیقی متناظر با نسبت موفقیت‌ها به آزمایش‌ها را پیدا کنید

- اعداد `Float` را با استفاده از موفقیت‌ها به عنوان صورت و آزمایش‌ها به عنوان مخرج بسازید.
- برای ساختن آرایه‌ی جدید می‌توان از حلقه‌ها، درک‌های فهرستی یا عملیات برداری استفاده کرد.

## 3. میانگین احتمال‌ها را بررسی کنید

- میانگین با جمع کردن داده‌ها و تقسیم بر تعداد رویدادها به دست می‌آید.
- از توابع `rationalize` و `probabilities` خودتان استفاده کنید.
- اگر بین استفاده از اعداد اعشاری و اعداد گویا ناهمخوانی‌ای پیدا شد، عدد گویا را برگردانید.
- ممکن است در مقایسه به تابع `float()` نیاز داشته باشید (به مقدمه نگاه کنید).
- می‌توان از حلقه‌ها یا عملیات برداری استفاده کرد.

## 4. احتمال مستقل را بررسی کنید

- احتمال رویدادهای مستقل را می‌توان در هم ضرب کرد تا احتمال کل رخ دادن همزمان آن رویدادها به دست آید.
- از توابع `rationalize` و `probabilities` خودتان استفاده کنید.
- اگر بین استفاده از اعداد اعشاری و اعداد گویا ناهمخوانی‌ای پیدا شد، عدد گویا را برگردانید.
- ممکن است در مقایسه به تابع `float()` نیاز داشته باشید (به مقدمه نگاه کنید).
- می‌توان از حلقه‌ها یا عملیات برداری استفاده کرد.
