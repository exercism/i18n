# Tests

تست‌ها را با این دستور اجرا کنید:

```shell
npm run test
```

همچنین می‌توانید Jest را در حالت «watch» اجرا کنید؛ این حالت وقتی تغییرات کد یا ماژول تست را ذخیره می‌کنید، تست‌ها را به‌طور خودکار دوباره اجرا می‌کند:

```shell
npm run watch
```

## آشنایی با تست‌های غیرفعال

متد `skip` به مجموعه‌ی تست می‌گوید که یک تست را اجرا نکند. این تابع با نام‌های مستعار `it.skip(name, fn)` یا `xit(name, fn)` یا `xtest(name, fn)` هم می‌تواند به کار برود.

- چرا غیرفعال می‌شوند؟

تا کاربران بتوانند هر بار روی یک تست تمرکز کنند و همراه با پیشرفت راه‌حل، آن‌ها را یکی‌یکی فعال کنند.

- چگونه آن‌ها را فعال کنیم؟

`xtest` را به `test` تغییر دهید.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
