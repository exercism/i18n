# پیوست دستورالعمل‌ها

## راهنمایی‌ها

برای اینکه میزان چالش اینجا مناسب باشد، فقط باید از قابلیت‌های موجود در `Prelude` استفاده کنید. سعی کنید از `Data.List`، `Data.Char`، `Data.Bits` یا `Numeric` استفاده نکنید.

سعی کنید از `seq`، `$!` یا `BangPatterns` به‌شکل مناسب استفاده کنید تا مطمئن شوید راه‌حل کارآمد است.

لازم نیست ورودی نامعتبر را مدیریت کنید.

اگر تمرین اکتال را انجام داده‌اید، شاید بهتر است آن را تعمیم دهید.
