# Tests

برای هر نمونه، این مراحل کلی لازم است.

اول، به پوشه‌ی تمرینی که می‌خواهید تمرین کنید بروید، در این مورد `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

سپس testها را اجرا کنید. هدف `test` در make به `compile` وابسته است، پس اجرای `make test` مطمئن می‌شود که کد منبع شما کامپایل شود و بعد testها اجرا شوند.

```bash
$ make test
```

تبریک! testهای ناموفق دارید!!!

حالا `README.md` را بخوانید تا بفهمید برای موفق شدن همه‌ی testهایتان چه باید بکنید.

اولین خطا را که test گزارش می‌دهد برطرف کنید و دوباره testها را اجرا کنید.

```bash
$ make test
```

ادامه دهید و test ناموفق بعدی را در کد منبع خود برطرف کنید و test خود را اجرا کنید تا همه‌ی testها موفق شوند.

وقتی همه‌ی testها موفق شدند، نگاهی نهایی به کدتان در پوشه‌ی `src` بیندازید تا مطمئن شوید از کدتان راضی هستید و آن را برای بازبینی ارسال کنید.

بازخورد بگیرید، راه‌حل را بازنگری کنید، ارسال کنید، تمرین بعدی را امتحان کنید و همین روند را تکرار کنید تا به روشنگری LFE برسید.
