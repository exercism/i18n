# مقدمه

## نحوه‌ی نگارش کلی

«حلقه‌ی For» یکی از رایج‌ترین دستورها برای اجرای مکرر یک منطق است. در Go از کلیدواژه‌ی `for`، یک هدر و یک «بلوک کد» تشکیل شده است که بدنه‌ی حلقه را در بر می‌گیرد و داخل آکولاد قرار می‌دهد.
هدر از ۳ مؤلفه تشکیل شده است که با نقطه‌ویرگول `;` از هم جدا می‌شوند: مقداردهی اولیه، شرط و پسین.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- مؤلفه‌ی **مقداردهی اولیه** کدی است که فقط یک بار پیش از شروع حلقه اجرا می‌شود.
- مؤلفه‌ی **شرط** باید عبارتی باشد که به یک «مقدار منطقی» ارزیابی می‌شود و کنترل می‌کند که حلقه چه زمانی باید متوقف شود.
  کد داخل حلقه تا زمانی که این شرط به «درست» ارزیابی شود اجرا می‌شود.
  به محض اینکه این عبارت به «غلط» ارزیابی شود، دیگر هیچ تکرار دیگری از حلقه اجرا نمی‌شود.
- مؤلفه‌ی **پسین** کدی است که در پایان هر تکرار اجرا می‌شود.

**توجه:** برخلاف زبان‌های دیگر، هیچ پرانتزی `()` دور سه مؤلفه‌ی هدر وجود ندارد.
در واقع، قرار دادن چنین پرانتزی یک خطای کامپایل است.
با این حال، آکولادهای `{ }` که بدنه‌ی حلقه را در بر می‌گیرند همیشه لازم هستند.

## حلقه‌ی For: یک مثال

مؤلفه‌ی مقداردهی اولیه معمولاً یک متغیر شمارنده را آماده می‌کند.
شرط بررسی می‌کند که حلقه باید ادامه یابد یا متوقف شود.
مؤلفه‌ی پسین هم معمولاً شمارنده را در پایان هر تکرار افزایش می‌دهد.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

این حلقه اعداد `1` تا `9` (شامل `9`) را چاپ می‌کند.
تعریف گام معمولاً با یک دستور افزایش یا کاهش انجام می‌شود، همان‌طور که در مثال بالا نشان داده شده است.
