# درباره

در Go، توابع «مقادیر درجه‌یک» هستند.
یعنی می‌توانید با توابع همان کارهایی را بکنید که با سایر مقادیر می‌کنید: تابع را به یک متغیر نسبت دهید، آن را به‌عنوان آرگومان به تابع دیگری بدهید یا حتی تابعی را از تابع دیگری برگردانید.

در ادامه دو تابع `engGreeting` و `espGreeting` می‌سازیم و آن‌ها را به متغیر `greeting` نسبت می‌دهیم:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

مقادیر تابعی این امکان را می‌دهند که توابع را نه‌فقط با داده، بلکه با رفتار هم پارامتری کنید.
در مثال زیر، رفتار را از طریق پارامتر `greetingFunc` به تابع `dialog` می‌دهیم:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

مقدار یک متغیر مقداردهی‌نشده از نوع تابع، `nil` است.
بنابراین فراخوانی یک مقدار تابعی `nil` باعث «پنیک» می‌شود.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

مقادیر تابعی را می‌توان با `nil` مقایسه کرد.
این کار می‌تواند برای پرهیز از پنیک‌های بی‌مورد برنامه مفید باشد.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## انواع تابع

استفاده از مقادیر تابعی به لطف انواع تابع در Go ممکن است.
یک نوع تابع، مجموعه‌ی همه‌ی توابعی را مشخص می‌کند که ترتیب یکسانی از نوع پارامترها و ترتیب یکسانی از نوع نتیجه‌ها دارند.
می‌توان انواع تعریف‌شده به دست کاربر را بر پایه‌ی انواع تابع اعلام کرد.
برای نمونه، تابع `dialog` از مثال‌های قبلی را می‌توان به‌شکل زیر به‌روزرسانی کرد:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## توابع بی‌نام

ابزار قدرتمند دیگری که به لطف پشتیبانی از توابع درجه‌یک در دسترس است، توابع بی‌نام هستند.
توابع بی‌نام در همان نقطه‌ای که استفاده می‌شوند تعریف می‌شوند، بدون اسمی که بعد از کلیدواژه‌ی `func` بیاید.
چنین توابعی به متغیرهای تابع دربرگیرنده دسترسی دارند.

برای مثال:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

فراخوانی `fib` متغیرهای `n1` و `n2` را اعلام می‌کند و یک تابع بی‌نام برمی‌گرداند که به‌نوبه‌ی خود، هر بار که فراخوانی می‌شود مقدار این متغیرها را تغییر می‌دهد.
nاُمین فراخوانی تابع بی‌نام، nاُمین عدد دنباله‌ی فیبوناچی را که از ۰ شروع می‌شود برمی‌گرداند. تابع بی‌نام درونی به متغیرهای محلی (`n1` و `n2`) تابع دربرگیرنده‌ی `fib` دسترسی دارد.
این روش خوبی است تا مقادیر تابعی وضعیت را بین فراخوانی‌ها نگه دارند.
می‌گوییم که تابع بی‌نام، بستارِ متغیرهای `n1` و `n2` است.
[بستارها][closure] در برنامه‌نویسی بسیار پرکاربردند و ممکن است ببینید که زبان‌های دیگر هم از آن‌ها پشتیبانی می‌کنند.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
