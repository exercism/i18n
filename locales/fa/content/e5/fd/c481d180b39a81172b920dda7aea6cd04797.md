# دستورالعمل‌ها

در این تمرین، منطق مأموریت یک بازی نقش‌آفرینی جدید را پیاده‌سازی می‌کنید که یکی از دوستانتان در حال ساخت آن است. شخصیت اصلی بازی آنالین است، دختری شجاع با یک سگ خانگی وحشی و وفادار. متأسفانه فاجعه‌ای رخ می‌دهد: بهترین دوستش هنگام جست‌وجوی توت در جنگل دزدیده شده است. آنالین تلاش می‌کند بهترین دوستش را پیدا و آزاد کند و در این مأموریت می‌تواند سگش را هم با خود ببرد.

پس از مدتی که رد بهترین دوستش را دنبال می‌کند، اردوگاهی را پیدا می‌کند که بهترین دوستش در آن زندانی است. معلوم می‌شود دو آدم‌ربا وجود دارد: یک شوالیه‌ی قدرتمند و یک کماندار حیله‌گر.

آنالین پس از یافتن آدم‌رباها بررسی می‌کند که می‌تواند کدام‌یک از کارهای زیر را انجام دهد:

- حمله‌ی سریع: حمله‌ی سریع را می‌توان انجام داد اگر شوالیه خواب باشد؛ چون پوشیدن زره برایش وقت می‌گیرد و در نتیجه آسیب‌پذیر خواهد بود.
- جاسوسی: اگر دست‌کم یکی از آنان بیدار باشد، می‌توان از گروه جاسوسی کرد. در غیر این صورت، جاسوسی اتلاف وقت است.
- علامت دادن به زندانی: اگر زندانی بیدار و کماندار خواب باشد، می‌توان با صداهای پرندگان به زندانی علامت داد؛ چون کماندارها در علامت‌دهی با پرندگان آموزش دیده‌اند و ممکن است پیام را رهگیری کنند.
- _آزاد کردن زندانی_: آنالین می‌تواند تلاش کند دزدکی وارد اردوگاه شود تا زندانی را آزاد کند.
  این کار پرخطر است و تنها به یکی از دو روش می‌تواند موفق شود:
  - اگر آنالین سگش را همراه داشته باشد، در صورتی می‌تواند زندانی را نجات دهد که کماندار خواب باشد.
    شوالیه از سگ می‌ترسد و کماندار فرصت نمی‌کند آماده شود، پیش از آنکه آنالین و زندانی فرار کنند.
  - اگر آنالین سگش را همراه نداشته باشد، باید خودش و زندانی بسیار دزدکی عمل کنند!
    آنالین می‌تواند زندانی را آزاد کند اگر زندانی بیدار باشد و هم شوالیه و هم کماندار خواب باشند؛ اما اگر زندانی خواب باشد، نمی‌توان نجاتش داد: آنالین به‌طور ناگهانی سر می‌رسد، زندانی جا می‌خورد و شوالیه و کماندار را بیدار می‌کند.

شما چهار وظیفه دارید: پیاده‌سازی منطقی که بر اساس وضعیت سه شخصیتی که در جنگل پیدا می‌شوند و همچنین حضور یا عدم حضور سگ آنالین مشخص کند که کارهای بالا در دسترس هستند یا نه.

## 1. بررسی امکان انجام حمله‌ی سریع

متد `canFastAttack()` را پیاده‌سازی کنید که یک مقدار «منطقی» می‌گیرد و مشخص می‌کند آیا شوالیه بیدار است یا نه. این متد اگر بر اساس وضعیت شوالیه بتوان حمله‌ی سریع انجام داد، `true` را برمی‌گرداند. در غیر این صورت، `false` را برمی‌گرداند:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. بررسی امکان جاسوسی از گروه

متد `canSpy()` را پیاده‌سازی کنید که سه مقدار منطقی می‌گیرد و به ترتیب مشخص می‌کند آیا شوالیه، کماندار و زندانی بیدار هستند یا نه. این متد اگر بر اساس وضعیت این سه شخصیت بتوان از گروه جاسوسی کرد، `true` را برمی‌گرداند. در غیر این صورت، `false` را برمی‌گرداند:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. بررسی امکان علامت دادن به زندانی

متد `canSignalPrisoner()` را پیاده‌سازی کنید که دو مقدار منطقی می‌گیرد و به ترتیب مشخص می‌کند آیا کماندار و زندانی بیدار هستند یا نه. این متد اگر بر اساس وضعیت این دو شخصیت بتوان به زندانی علامت داد، `true` را برمی‌گرداند. در غیر این صورت، `false` را برمی‌گرداند:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. بررسی امکان آزاد کردن زندانی

متد `canFreePrisoner()` را پیاده‌سازی کنید که چهار مقدار منطقی می‌گیرد. سه پارامتر اول به ترتیب مشخص می‌کنند آیا شوالیه، کماندار و زندانی بیدار هستند یا نه. پارامتر آخر مشخص می‌کند آیا سگ آنالین همراه او هست یا نه. این متد اگر بر اساس وضعیت این سه شخصیت و حضور سگ آنالین بتوان زندانی را آزاد کرد، `true` را برمی‌گرداند. در غیر این صورت، `false` را برمی‌گرداند:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
