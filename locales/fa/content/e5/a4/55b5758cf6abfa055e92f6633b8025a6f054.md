# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | -------------------------------------- |
| `$a0`    | ورودی     | آدرس | رشته‌ی پایان‌یافته با نال از کاراکترهای دودویی |
| `$v0`    | خروجی     | عدد صحیح | مقدار دهدهی رشته‌ی ورودی |
| `$t0-9`  | موقت      | هر | برای ذخیره‌سازی موقت به کار می‌رود |
