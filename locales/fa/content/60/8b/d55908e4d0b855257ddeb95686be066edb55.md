# مقدمه

یک [`Attribute` در C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) راهی است برای تزئین یک اعلان، تا فراداده‌ای به آن پیوند داده شود: به یک class، یک method، یک enum، یک field، یک property یا هر یک از [اعلان‌های پشتیبانی‌شده‌ی دیگر](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

می‌توانید یک Attribute را با افزودن آن در خط پیش از اعلان اعمال کنید، با استفاده از یک `ClassAttribute` و یک `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

این فراداده‌ی اعلانی تنها اطلاعات ساخت‌یافته‌ی بیشتری را به کد نسبت می‌دهد و رفتار آن را تغییر نمی‌دهد؛ اما بخش‌های دیگر کد از این فراداده استفاده می‌کنند تا رفتار هدفش را تغییر دهند، یا قابلیت‌هایی به آن بیفزایند، تغییر دهند، حذف کنند یا محدود سازند.

[Attributeهای از پیش تعریف‌شده و رزروشده‌ی](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) بسیاری وجود دارند، برای مثال `Flags`، `Obsolete` و `Conditional`؛ هر کدام کارکرد خاص خود را دارند که می‌توان آن را در مستندات C# جست‌وجو کرد. توجه کنید که نام کامل یک Attribute مانند [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) طبق قرارداد `FlagsAttribute` است، اما پسوند _Attribute_ را می‌توان هنگام اعمال روی یک اعلان حذف کرد.
