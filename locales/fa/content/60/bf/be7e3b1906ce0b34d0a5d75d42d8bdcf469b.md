# مقدمه

**Map** یک ساختار داده برای ذخیره‌ی جفت‌های کلید-مقدار است.
این ساختار مشابه دیکشنری‌ها در سایر زبان‌های برنامه‌نویسی است.
رابط [Map][map-javadoc] عملیات‌های روی یک مپ را تعریف می‌کند.

Java چندین پیاده‌سازی مختلف از `Map` دارد.
[HashMap][hashmap-javadoc] یکی از پرکاربردترین آن‌هاست.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

با استفاده از [put][map-put-javadoc] ورودی‌هایی به مپ اضافه کنید.

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

به هر کلید فقط یک مقدار می‌تواند نسبت داده شود.
فراخوانی `put` با همان کلید، مقدار آن کلید را به‌روزرسانی می‌کند.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

برای گرفتن مقدار یک کلید از [get][map-get-javadoc] استفاده کنید.

```java
fruitPrices.get("apple"); // => 100
```

برای اینکه ببینید آیا مپ کلید مشخصی دارد یا نه، از [containsKey][map-containskey-javadoc] استفاده کنید.

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

با [remove][map-remove-javadoc] ورودی‌ها را حذف کنید.

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

متد [size][map-size-javadoc] تعداد ورودی‌ها را برمی‌گرداند.

```java
fruitPrices.size();  // Returns 2
```

می‌توانید از متدهای [keySet][map-keyset-javadoc] یا [values][map-values-javadoc] استفاده کنید تا کلیدها یا مقادیر یک `Map` را به‌ترتیب به‌صورت یک `Set` یا یک مجموعه به دست آورید.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
