# مقدمه

## مقایسه

در Go می‌توان اعداد را با عملگرهای رابطه‌ای و برابری زیر مقایسه کرد.

| Comparison        | Operator  |
| ------------------| --------- |
| برابر             | `==`      |
| نابرابر           | `!=`      |
| کوچک‌تر           | `<`       |
| کوچک‌تر یا برابر  | `<=`      |
| بزرگ‌تر           | `>`       |
| بزرگ‌تر یا برابر  | `>=`      |

نتیجه‌ی مقایسه همیشه یک مقدار منطقی است، یعنی یا `true` یا `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

عملگرهای مقایسه‌ی بالا را می‌توان برای مقایسه‌ی رشته‌ها هم به کار برد.
در این حالت یک ترتیب واژه‌نامه‌ای (مانند فرهنگ لغت) اعمال می‌شود.
برای مثال:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## دستورهای شرطی

دستورهای شرطی در Go مانند دستورهای شرطی در زبان‌های دیگر هستند.
نوع زیرین هر عملیات شرطی، نوع `bool` است که می‌تواند مقدار `true` یا `false` داشته باشد.
دستورهای شرطی اغلب به عنوان سازوکارهای کنترل جریان برای بررسی شرط‌های مختلف به کار می‌روند.

برای بررسی یک حالت خاص می‌توان از دستور `if` استفاده کرد که اگر شرط زیرین `true` باشد، کدش را اجرا می‌کند، به این شکل:

```go
var value string

if value == "val" {
    return "was val"
}
```

در موقعیت‌هایی که بیش از یک حالت درگیر است، می‌توان چندین دستور `if` را با استفاده از دستورهای `else if` و `else` به هم زنجیره کرد.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

دستورهای شرطی می‌توانند یک دستور مقداردهی اولیه‌ی کوتاه هم داشته باشند که با آن می‌توان یک یا چند متغیر را برای دستور `if` مقداردهی اولیه کرد.
برای مثال:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> نکته: هر متغیری که در دستور مقداردهی اولیه ساخته شود، پس از پایان دستور `if` از حوزه‌ی دسترس خارج می‌شود.
