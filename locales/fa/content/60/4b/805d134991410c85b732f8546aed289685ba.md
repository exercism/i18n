# درباره

شمارش، عمل پیمایش یک مجموعه (مثل `Array`، `Hash` و غیره) و انجام دادن کاری روی هر شیء آن است.

شمارش مفهومی کلیدی در Ruby است و برای مرتب‌سازی (`sort_by`)، گروه‌بندی (`group_by`)، نگاشت (`map`)، کاهش (`reduce`) و موارد بسیار بیشتری به کار می‌رود.
بیشتر اوقات شمارش را به‌عنوان روش طبیعی پیمایش مجموعه‌ها به‌جای استفاده از «حلقه»ها می‌بینید.

یک شمارش ساده برای چاپ هر کلمه در یک آرایه به این شکل است:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

در این مثال، متد `Array#each` را فراخوانی کرده‌ایم و یک _«بلوک»_ به آن داده‌ایم که یک پارامتر (`word`) می‌گیرد و آن را چاپ می‌کند.

می‌توانیم متدهای شمارشی را هم به‌صورت زنجیره‌ای به هم بچسبانیم.
برای مثال، می‌توانیم `.with_index` را به `each` زنجیره کنیم تا هم اندیس یک شیء و هم مقدارش را چاپ کنیم:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

شمارش اشیاء `Hash` دقیقاً همانند شمارش اشیاء `Array` است، با این تفاوت که بلوک دو آرگومان می‌گیرد: کلید و مقدار:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

متدهای توضیح‌داده‌شده در بالا بخشی از [ماژول `Enumerable`][enumerable-module] هستند که در `Array`، `Hash` و دیگر کلاس‌هایی که به توانایی شمارش نیاز دارند گنجانده شده است.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
