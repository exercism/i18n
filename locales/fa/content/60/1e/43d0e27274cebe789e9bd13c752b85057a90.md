# عملگر مقایسه

PHP ده عملگر مقایسه‌ای درون‌ساخته دارد:

| اسم | مثال | نتیجه |
| ----- | ---------- | -------------------------------------------------- |
| برابر | `$a == $b` | اگر `$a` پس از جابه‌جایی نوع برابر با `$b` باشد، «درست» است. |
| یکسان | `$a === $b` | اگر `$a` برابر با `$b` و از همان نوع باشد، «درست» است. |
| نابرابر | `$a != $b` | اگر `$a` پس از جابه‌جایی نوع برابر با `$b` نباشد، «درست» است. |
| نابرابر | `$a <> $b` | اگر `$a` پس از جابه‌جایی نوع برابر با `$b` نباشد، «درست» است. |
| غیریکسان | `$a !== $b` | اگر `$a` برابر با `$b` نباشد یا از همان نوع نباشد، «درست» است. |
| کوچک‌تر از | `$a < $b` | اگر `$a` اکیداً کوچک‌تر از `$b` باشد، «درست» است. |
| بزرگ‌تر از | `$a > $b` | اگر `$a` اکیداً بزرگ‌تر از `$b` باشد، «درست» است. |
| کوچک‌تر از یا برابر با | `$a <= $b` | اگر `$a` کوچک‌تر از یا برابر با `$b` باشد، «درست» است. |
| بزرگ‌تر از یا برابر با | `$a >= $b` | اگر `$a` بزرگ‌تر از یا برابر با `$b` باشد، «درست» است. |
| Spaceship | `$a <=> $b` | وقتی `$a` کوچک‌تر از، برابر با یا بزرگ‌تر از `$b` باشد، یک عدد صحیح کوچک‌تر از، برابر با یا بزرگ‌تر از `0` برمی‌گرداند. |

PHP تعریف‌های متمایزی دارد که میان `equal` و `identical` تفاوت می‌گذارد. گاهی به `identical`، `strictly equal` هم گفته می‌شود.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
