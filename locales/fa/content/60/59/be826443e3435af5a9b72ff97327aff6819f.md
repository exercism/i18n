# تست‌ها

اگر باینری phix در مسیر شما قرار دارد، این دستور را وارد کنید:

```bash
p test 
```

با این کار فایل تست (`test.exw`) اجرا می‌شود.

اگر باینری phix در `PATH` نباشد، در ویندوز این را وارد کنید:

```cmd
\path\to\p.exe test
```

لینوکس:

```bash
/path/to/p test
```

## تست‌های نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی اینکه همه‌ی تست‌های آن موفق شوند.
به‌طور پیش‌فرض، همه‌ی تست‌های موجود در فایل `test.exw` اجرا می‌شوند.
برای نادیده گرفتن یک تست، دو خط تیره (نشانگر استاندارد کامنت در Phix) را به ابتدای خط اضافه کنید.

توجه کنید که تست‌ها هیچ پرچم `include=false` را در `tests.toml` رعایت نمی‌کنند؛ در عوض، این مسئولیت نویسنده‌ی `test.exw` است که آن‌ها را به‌صورت دستی در آن فایل نگه دارد تا واقعیت را به نفع سایت Exercism بازتاب دهد (مثلاً برای جمع‌آوری آمار ترک)، اما هیچ چیز در خود ترک از آن‌ها استفاده نمی‌کند؛ به‌طور خاص مولد تست و اجراکننده‌ی تست.
