# کلیدواژههای `static` در کلاس

کلاس واحدی برای سازماندهی کد در PHP است و غالباً نمایندهی نمونهای از یک موجودیت/سرویس/رویه است.
با استفاده از کلیدواژههای `static` و `self`، ویژگیها و متدها میتوانند به کلاس تعلق داشته باشند و برای همهی نمونهها (یا بدون هیچ نمونهای) وجود داشته باشند.

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## محدودیت

متدهای `static` کلاس فقط میتوانند سایر ویژگیهای `static` یا متدهای کلاس را از کلاس خود فراخوانی کنند.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
