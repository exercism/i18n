# راهنمایی

## کلی

- توابع خواندن در [`io`][io] قرار دارند؛ سازنده‌های جریان رشته‌ای و
  `with-string-writer` در
  [`io.streams.string`][io.streams.string] قرار دارند.
- در وظیفه‌ی تخلیه‌ی نویسنده، متغیرهای محلی (`::` و `:>`) وقتی لازم است
  دو بار به همان جریان دست بزنید، بدنه را خوانا نگه می‌دارند.

## 1. همه را بشنوید

- یک تابع: `stream-contents`.

## 2. پیام‌ها را بشمارید

- `stream-lines` جریان را به آرایه‌ای از خطوط تقسیم می‌کند؛
  `length` تعداد را برمی‌گرداند.

## 3. آخرین فراخوانی را پس بفرستید

- همان `stream-lines` بالا، بعد `last` و سپس `>upper` (از
  `ascii`).

## 4. یک پیام را پخش کنید

- `stream-write` پیام را می‌نویسد و `stream-flush` آن را بیرون می‌فرستد. نویسنده
  دو بار استفاده می‌شود، پس از متغیرهای محلی `::` استفاده کنید:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. خروجی یک نقل‌قول را ثبت کنید

- یک تابع: `with-string-writer`. بعد از `;` پایانی `inline` را اضافه کنید
  تا کامپایلر بتواند داخل آرگومان نقل‌قول را ببیند:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
