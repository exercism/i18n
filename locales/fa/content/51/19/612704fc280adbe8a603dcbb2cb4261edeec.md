# درباره

وقتی می‌خواهید دنباله‌های Factor را *تغییر دهید*، با دو گونه روبه‌رو می‌شوید:

- **آرایه‌ها** (`{ … }`) طول ثابتی دارند. می‌توانید آنچه را که *در* هر موقعیت قرار دارد با `set-nth` / `change-nth` تغییر دهید، اما نمی‌توانید آن‌ها را بزرگ‌تر یا کوچک‌تر کنید.
- **وکتورها** (`V{ … }`) طول متغیری دارند. `push` به انتها اضافه می‌کند و `pop` آخرین عنصر را حذف می‌کند و برمی‌گرداند.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| واژه            | اثر                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )` ، آرایه‌ای شامل `n` رونوشت از `elt` |
| `<vector>`      | `( n -- vector )` ، وکتور خالی با ظرفیت `n` |
| `V{ }`          | لیترال وکتور خالی                           |
| `set-nth`       | `( elt n seq -- )` ، عنصر را در اندیس `n` قرار می‌دهد |
| `change-nth`    | `( i seq quot -- )` ، `quot` را روی عنصر اندیس `i` اعمال می‌کند |
| `push`          | `( elt seq -- )` ، به انتهای یک وکتور اضافه می‌کند |
| `suffix!`       | `( seq elt -- seq )` ، درجا اضافه می‌کند و وکتور را برمی‌گرداند |
| `pop`           | `( seq -- elt )` ، آخرین عنصر را حذف می‌کند و برمی‌گرداند |
| `pop*`          | `( seq -- )` ، آخرین عنصر را حذف می‌کند و دور می‌اندازد |
| `clone`         | `( obj -- copy )` ، یک رونوشت تازه و مستقل |
| `new-sequence`  | `( n exemplar -- newseq )` ، دنباله‌ای تازه از همان کلاس `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )` ، گونه‌ی تازه‌ی قابل تغییر اندازه |

وقتی دنباله‌ای را که فراخوانی‌کننده پاس داده است تغییر می‌دهید، این تغییر برای فراخوانی‌کننده قابل مشاهده است؛ چون هر دو همان شیء را در دست دارند. اگر این چیزی نیست که می‌خواهید، اول `clone` کنید تا یک رونوشت مستقل به دست آورید.
