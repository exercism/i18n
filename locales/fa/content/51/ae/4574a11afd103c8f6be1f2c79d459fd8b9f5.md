# مقدمه

## nullپذیری

در Java، از مقدار ثابت `null` برای نشان دادن نبودِ یک مقدار استفاده می‌شود.

انواع داده‌ی اولیه در Java همه مقدار پیش‌فرض دارند و بنابراین هرگز نمی‌توانند `null` باشند.
طبق قرارداد، با حرف کوچک شروع می‌شوند، مثلاً `int`.

انواع ارجاعی حاوی نشانی حافظه‌ی یک شیء هستند و می‌توانند مقدار `null` داشته باشند.
آن‌ها معمولاً با حرف بزرگ شروع می‌شوند، مثلاً `String`.

اگر بخواهید به یک متغیر اولیه مقدار `null` اختصاص دهید، خطای زمان کامپایل رخ می‌دهد، چون متغیر همیشه مقداری اولیه از نوعی را نگه می‌دارد که به آن اختصاص داده شده است.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

اختصاص دادن مقدار `null` به یک متغیر ارجاعی منجر به خطای زمان کامپایل نمی‌شود، چون متغیرهای ارجاعی nullپذیر هستند.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
