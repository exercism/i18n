# مقدمه

ماژول `Agent` انتزاعی را برای ایجاد [فرایندها و حلقه‌ی _receive-send_][exercism-processes] فراهم می‌کند. از این پس، فرایندهایی را که با استفاده از ماژول `Agent` شروع می‌شوند، «فرایند عامل» می‌نامیم. ممکن است یک فرایند عامل برای نمایش یک حالت اشتراکی مرکزی انتخاب شود.

برای شروع یک فرایند عامل، `Agent` تابع `start/2` را در اختیار شما می‌گذارد. تابعی که هنگام `start` کردن فرایند عامل داده می‌شود، حالت اولیه‌ی فرایند را برمی‌گرداند:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Agent` هم درست مثل `Map` یا `List` توابع زیادی برای کار با فرایندهای عامل ارائه می‌دهد.

مرسوم است که همه‌ی قابلیت‌های مربوط به `Agent` را در ماژولی برای دامنه‌ای که مدل‌سازی می‌شود، سازماندهی و کپسوله کنید.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
