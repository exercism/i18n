# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که برچسب اسم کارکنان کارخانه را چاپ می‌کند.

## 1. چاپ یک برچسب برای یک کارمند

هر کارمند یک شناسه، یک اسم و یک اسم دپارتمان دارد.
برچسب کارکنان به این شکل قالب‌بندی می‌شود: `"[id] - name - DEPARTMENT"`.
متد `printBadge()` را پیاده‌سازی کنید تا برچسب یک کارمند را برگرداند:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
توجه کنید که دپارتمان روی برچسب باید با حروف بزرگ نوشته شود.
~~~~

## 2. چاپ یک برچسب برای یک کارمند جدید

به دلیل یک نقص عجیب در سیستم کامپیوتری، کارمندان جدید گاهی وقتی کارشان را در کارخانه شروع می‌کنند هنوز شناسه ندارند.
چون داشتن برچسب الزامی است، یک برچسب موقت بدون پیشوند شناسه دریافت می‌کنند.
متد `printBadge()` را طوری تغییر دهید که از کارمندان جدیدی که هنوز شناسه ندارند پشتیبانی کند:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. چاپ یک برچسب برای مالک

حتی مالک کارخانه هم باید همیشه برچسب داشته باشد.
اما مالک دپارتمان ندارد.
در این حالت، برچسب باید به‌جای اسم دپارتمان، `"OWNER"` را چاپ کند.
متد `printBadge()` را طوری تغییر دهید که برچسب مالک را چاپ کند:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
توجه کنید که ممکن است مالک هم یک کارمند جدید باشد:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
