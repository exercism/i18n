# مقدمه

«حلقه» روشی است برای فراخوانی مکرر یک یا چند دستور در قالب یک دسته. هر بار اجرای یک دسته دستور، یک «تکرار» نامیده می‌شود.

## حلقه‌ی While

حلقه‌ی `while` یک دسته دستور را تا زمانی اجرا می‌کند که یک عبارت «منطقی» در بالای حلقه «درست» باشد.
وقتی عبارت منطقی «غلط» شود، حلقه از اجرا بازمی‌ایستد و اجرا به خط بعدی code پس از حلقه می‌رسد.

اگر عبارت منطقی از همان ابتدا «غلط» ارزیابی شود، حلقه‌ی `while` اصلاً اجرا نمی‌شود و اجرا به خط بعدی code پس از حلقه می‌رسد.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

مهم است که شرطی برای پایان دادن به حلقه وجود داشته باشد؛ در غیر این صورت با یک حلقه‌ی بینهایت روبه‌رو می‌شویم که جلوی پیشرفت code را می‌گیرد.
اگر در code بالا عملگر `++` از `i` برداشته می‌شد، حلقه به یک حلقه‌ی بینهایت تبدیل می‌شد.

## حلقه‌ی Do

در حلقه‌ی `do` عبارت منطقی در پایین حلقه بررسی می‌شود.
حلقه‌ی `do` همیشه دست‌کم یک بار اجرا می‌شود، مانند مثال زیر:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

اگر همین کار را با حلقه‌ی `while` انجام می‌دادیم، پرحرف‌تر می‌شد:

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## حلقه‌ی For

اغلب یک حلقه یک متغیر را به‌روزرسانی می‌کند و زمانی پایان می‌یابد که متغیر به مقدار مشخصی برسد.
حلقه‌ی `for` روشی است برای مقداردهی اولیه، به‌روزرسانی و بررسی یک یا چند متغیر، همه در یک خط داخل پرانتز.
بخش اول برای مقداردهی اولیه‌ی متغیر است، بخش دوم برای بررسی متغیر و بخش سوم برای به‌روزرسانی مقدار متغیر.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

این کد از معادلش با حلقه‌ی `while` کم‌حرف‌تر است، اما همچنان خوانا می‌ماند.
