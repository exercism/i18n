# درباره

در Clojure، به اتصال یک مقدار به یک اسم، [_var_][vars] گفته می‌شود. varهای سطح بالا (سراسری) شبیه ثابت‌ها در زبان‌های دیگر هستند، اما معمولاً دوباره تعریف می‌شوند تا توسعه‌ی پویا را تسهیل کنند.

varهای سطح بالا با [`def`][def] تعریف می‌شوند:

```clojure
(def fingers 10)
```

می‌توانید از توابع اصلی برای [عملیات روی اعداد][operators] استفاده کنید تا روی مقادیر عملیات حسابی انجام دهید.

از ماکروی `defn` می‌توان برای تعریف یک [تابع][functions] استفاده کرد که صفر یا چند آرگومان می‌گیرد. یک تابع همیشه نتیجه‌ی آخرین عبارت در بدنه‌اش را برمی‌گرداند.

```clojure
(defn add [x y]
  (+ x y))
```

تابع را با نوشتن اسم آن و فرستادن آرگومان برای هر یک از پارامترهایش فراخوانی می‌کنید.

```clojure
(def five (add 2 3))
```

توابع و مقادیر را در Clojure فقط _پس از_ تعریف شدنشان می‌توان استفاده کرد. استفاده از آن‌ها پیش از تعریف شدنشان به خطای کامپایل منجر می‌شود.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

در Clojure، فضای خالی هیچ اهمیتی جز قالب‌بندی ندارد.

توابع و varهای Clojure در فضاهای نام سازمان‌دهی می‌شوند. یک فضای نام قابلیت‌های مرتبط را کنار هم جمع می‌کند و با ماکروی `ns` تعریف می‌شود:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure از دو نوع کامنت پشتیبانی می‌کند. کامنت‌های تک‌خطی با `;` شروع می‌شوند و از فرم `comment` استفاده می‌شود تا هر چه بین `(comment` و `)` است ارزیابی نشود.
