# مقدمه

## جفت

یک `Pair` صرفاً دو عنصر است که به هم پیوند خورده‌اند.
سپس به این دو عنصر با کمی تخیل `first` و `second` می‌گویند.

آن‌ها را یا با عملگر `=>` یا با سازنده‌ی `Pair()` بسازید.

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## دیکت

یک `Vector` از جفت‌ها مثل هر آرایه‌ی دیگری است: دارای ترتیب، از نظر نوع همگن و به‌صورت پشت‌سرهم در حافظه ذخیره می‌شود.

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

یک `Dict` در ظاهر شبیه به آن است، اما ذخیره‌سازی به شکلی پیاده‌سازی شده است که بازیابی سریع با کلید را ممکن می‌کند، حتی وقتی تعداد عضوها زیاد شود.

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

در زبان‌های دیگر، چیزی بسیار شبیه به `Dict` ممکن است «دیکشنری» (Python)، «Hash» (Ruby) یا «HashMap» (Java) نامیده شود.

برای `Pair`ها، چه به‌تنهایی و چه درون یک `Vector`، محدودیت‌های کمی روی نوع هر جزء وجود دارد.

برای آنکه یک `Pair` در `Dict` معتبر باشد، باید یک جفت `key => value` باشد که در آن `key` «قابل هش شدن» است.
از همه مهم‌تر، این یعنی `key` باید _تغییرناپذیر_ باشد؛ بنابراین `Char`، `Int`، `String`، `Symbol` و `Tuple` همگی مشکلی ندارند، اما `Vector` مجاز نیست.

### تغییر دادن یک دیکت

می‌توان عضوهایی با کلید جدید اضافه کرد، یا عضوهایی با کلید موجود را بازنویسی کرد.

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

برای حذف یک عضو، از تابع `delete!()` استفاده کنید؛ این تابع اگر کلید وجود داشته باشد `Dict` را تغییر می‌دهد و در غیر این صورت بی‌صدا هیچ کاری انجام نمی‌دهد.

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### بررسی وجود یک کلید یا مقدار

روش‌های مختلفی وجود دارد.
برای بررسی یک کلید، تابع `haskey()` وجود دارد:

```julia-repl
julia> haskey(pd, 'b')
true
```

یا می‌توان کلیدها یا مقدارها را جست‌وجو کرد:

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
