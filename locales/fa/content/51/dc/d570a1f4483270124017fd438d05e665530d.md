# مقدمه

«لیست نویسه» با استفاده از «سیگیل» `~c` ساخته می‌شود.

```elixir
~c"hello"
```

~~~~exercism/note
توجه کنید که در نسخه‌های قدیمی‌تر Elixir، لیست نویسه به صورت `'hello'` و با گیومه‌های تکی نمایش داده می‌شود.
~~~~

اگرچه ظاهر لیست نویسه بسیار شبیه رشته‌ها است، این دو نوع داده کاملاً با هم تفاوت دارند. لیست نویسه، لیستی از اعداد صحیح است. این اعداد صحیح، مقدارهای یونیکد یک نویسه‌ی مشخص را نشان می‌دهند، همان که به آن «کدپوینت» می‌گویند.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

می‌توانید یک `?` پیش از یک نویسه بگذارید تا کدپوینت آن را به دست آورید.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

چون لیست نویسه در واقع یک لیست است، می‌توانید درست مثل هر لیست دیگری با آن کار کنید، با بازگشت و تطبیق الگو.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

می‌توانید دو لیست را با `++` به هم بچسبانید.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

هرچه لیست اول طولانی‌تر باشد، عمل چسباندن کندتر انجام می‌شود؛ پس از افزودن پشت‌سرهم به لیست‌هایی با طول دلخواه پرهیز کنید.
