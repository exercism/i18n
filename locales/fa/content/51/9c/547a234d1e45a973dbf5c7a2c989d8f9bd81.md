# دستورالعمل‌ها

در این تمرین با یک ماشین کنترل از راه دور سر و کار دارید که بالاخره پول کافی برای خریدنش را جمع کرده‌اید.

هر ماشین با باتری کاملاً پر (۱۰۰٪) شروع می‌کند. هر بار که ماشین را با کنترل از راه دور می‌رانید، ۲۰ متر را طی می‌کند و یک درصد از شارژ باتری کم می‌شود.

ماشین کنترل از راه دور یک نمایشگر LED شیک دارد که دو مورد را نشان می‌دهد:

- مسافت کل طی‌شده، که به این شکل نمایش داده می‌شود: `"Driven <METERS> meters"`.
- شارژ باقی‌مانده‌ی باتری، که به این شکل نمایش داده می‌شود: `"Battery at <PERCENTAGE>%"`.

اگر شارژ باتری ۰٪ باشد، دیگر نمی‌توانید ماشین را برانید و نمایشگر باتری `"Battery empty"` را نشان می‌دهد.

شش وظیفه دارید که هر کدام با نمونه‌هایی از ماشین کنترل از راه دور کار می‌کنند.

## 1. یک ماشین کنترل از راه دور کاملاً نو بخرید

متد (_static_) `RemoteControlCar.Buy()` را پیاده‌سازی کنید تا یک نمونه‌ی کاملاً نو از ماشین کنترل از راه دور برگرداند:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. مسافت طی‌شده را نمایش دهید

متد `RemoteControlCar.DistanceDisplay()` را پیاده‌سازی کنید تا مسافت را همان‌طور که روی نمایشگر LED نمایش داده می‌شود برگرداند:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. درصد شارژ باتری را نمایش دهید

متد `RemoteControlCar.BatteryDisplay()` را پیاده‌سازی کنید تا درصد شارژ باتری را همان‌طور که روی نمایشگر LED نمایش داده می‌شود برگرداند:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. هنگام رانندگی، تعداد مترهای طی‌شده را به‌روزرسانی کنید

متد `RemoteControlCar.Drive()` را پیاده‌سازی کنید که تعداد مترهای طی‌شده را به‌روزرسانی می‌کند:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. هنگام رانندگی، درصد شارژ باتری را به‌روزرسانی کنید

متد `RemoteControlCar.Drive()` را به‌روزرسانی کنید تا درصد شارژ باتری را به‌روزرسانی کند:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. وقتی باتری خالی شد، جلوی رانندگی را بگیرید

متد `RemoteControlCar.Drive()` را طوری به‌روزرسانی کنید که وقتی باتری خالی (۰٪) است، نه مسافت طی‌شده افزایش یابد و نه درصد شارژ باتری کاهش یابد:

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
