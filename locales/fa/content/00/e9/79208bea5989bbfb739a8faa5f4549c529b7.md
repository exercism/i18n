# نکته‌ها

کد شما باید یک تابع `frequency :: Int -> [Text] -> Map Char Int` داشته باشد که تعداد کارگرها برای اجرای موازی و فهرستی از متن‌ها را می‌گیرد و فراوانی کل هر حرف را در متن برمی‌گرداند.

## بنچمارک

با اجرای بنچمارک بررسی کنید که تغییر تعداد کارگرها چه تأثیری بر عملکرد راه‌حل شما دارد. برای اجرای آن از `stack bench` استفاده کنید. با خیال راحت `bench/Benchmark.hs` را تغییر دهید تا عملکرد راه‌حل خود را روی ورودی‌های مختلف بررسی کنید.
