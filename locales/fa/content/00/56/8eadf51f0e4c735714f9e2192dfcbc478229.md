# مقدمه

گاهی لازم است به یک دنباله نه به‌صورت عنصر به عنصر، بلکه به‌صورت مجموعه‌ای از *تکه‌ها* نگاه کنید. واژگان [`grouping`][grouping]، [`splitting`][splitting] و [`splitting.monotonic`][splitting.monotonic] چهار روش برای این کار در اختیارتان می‌گذارند.

## `group`، تکه‌های جدا از هم به اندازه‌ی *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

اگر طول دنباله مضربی از *n* نباشد، تکه‌ی آخر کوتاه‌تر از *n* خواهد بود.

## `clump`، پنجره‌ی لغزان هم‌پوشان به اندازه‌ی *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

اگر دنباله کوتاه‌تر از *n* باشد، نتیجه خالی است.

## `split-when`، شکستن در هر جایی که یک محمول صادق می‌شود

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

به هر عنصر یک فراخوانی جداگانه‌ی محمول تعلق می‌گیرد؛ عنصرهایی که محمول برایشان «درست» برمی‌گرداند، *نقاط شکست* هستند و در نتیجه نگه داشته نمی‌شوند.

## `monotonic-split`، شکستن بخش‌های پیوسته در جایی که بررسی یک جفت مجاور شکست می‌خورد

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

محمول روی *جفت‌های مجاور* اجرا می‌شود. تا وقتی که نتیجه‌ی درست برگرداند، بخش پیوسته ادامه پیدا می‌کند؛ وقتی `f` برگرداند، تکه‌ی تازه‌ای آغاز می‌شود. با `[ = ]` بخش‌های پیوسته‌ی عنصرهای برابر را می‌گیرید؛ با `[ <= ]` بخش‌های پیوسته‌ی غیرنزولی؛ و به همین ترتیب.

## چه زمانی سراغ کدام برویم

- **`group`/`clump`**: می‌دانید چه *اندازه‌ای* می‌خواهید.
- **`split-when`**: می‌دانید یک *عنصر شکست* چه شکلی است.
- **`monotonic-split`**: می‌دانید چه چیزی باعث می‌شود دو عنصر مجاور *هنوز به هم تعلق داشته باشند*.
