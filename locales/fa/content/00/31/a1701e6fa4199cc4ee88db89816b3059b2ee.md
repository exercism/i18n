# مقدمه

یک `string` در Go دنباله‌ای تغییرناپذیر از بایت‌هاست که لزوماً نباید کاراکترها را نمایش دهند.

یک «لیترال رشته‌ای» بین دو کوتیشن تعریف می‌شود:

```go
const name = "Jane"
```

رشته‌ها را می‌توان با «عملگر» `+` الحاق کرد:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

برخی کاراکترهای خاص باید با یک بک‌اسلش در ابتدا فرار داده شوند، مانند `\t` برای تب و `\n` برای خط جدید در رشته‌ها.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

پکیج `strings` شامل توابع مفید زیادی برای کار روی رشته‌هاست.
برای اطلاعات بیشتر درباره‌ی توابع رشته، [مستندات پکیج strings](https://pkg.go.dev/strings) را ببینید.
در ادامه چند مثال می‌بینید:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
