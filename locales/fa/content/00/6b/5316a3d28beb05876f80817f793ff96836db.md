# درباره

توابع در Elixir می‌توانند به‌صورت پویا فراخوانی شوند.

همه‌ی اسم‌های ماژول‌ها اتم هستند. همه‌ی اسم‌های ماژول‌های Elixir هنگام کامپایل به‌طور خودکار با `Elixir.` پیشوند می‌گیرند.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir می‌تواند یک تابع را برای فراخوانی در زمان اجرا تعیین کند و برای انجام جستجو از اسم ماژول استفاده کند. اگر اسم ماژول به یک متغیر مقید شده باشد، جستجو می‌تواند به‌صورت پویا انجام شود.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
