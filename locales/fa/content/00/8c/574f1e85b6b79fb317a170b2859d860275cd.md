# مبانی

یک برنامه‌ی Sather از **کلاس‌ها** ساخته می‌شود. کلاس جعبه‌ای است که اسم دارد و رویه‌ها را در خود نگه می‌دارد. یک **رویه** بخشی از کار است که اسم دارد و پاسخی تولید می‌کند.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

اگر این را از بالا بخوانیم:

- `class GREETER is` جعبه را باز می‌کند و به آن اسم می‌دهد. اسم کلاس‌ها با حروف بزرگ نوشته می‌شود.
- `hello : STR is` رویه‌ای را شروع می‌کند به اسم `hello` که یک `STR` تولید می‌کند؛ یعنی یک تکه متن که «رشته» نامیده می‌شود. `: STR` قولی است درباره‌ی اینکه چه نوع پاسخی برمی‌گردد.
- `return "Hello!";` پاسخ را برمی‌گرداند. متن بین دو نقل‌قول نوشته می‌شود.
- `end;` رویه را می‌بندد و `end;` دوم کلاس را می‌بندد.

هر چیزی که در یک خط بعد از `--` بیاید یک **توضیح** است. Sather آن را نادیده می‌گیرد؛ این توضیح برای خود آدم‌هاست.

```sather
-- This line is for the reader, not the computer.
```

برای استفاده از یک رویه در جای دیگری، اسم کلاس، دو دونقطه و اسم رویه را بنویسید:

```sather
GREETER::hello        -- this is "Hello!"
```

داخل همان کلاس می‌توانید اسم کلاس را حذف کنید:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

رویه‌ای که هیچ آرگومانی نمی‌گیرد، بدون پرانتز فراخوانی می‌شود: `hello` و نه `hello()`.
