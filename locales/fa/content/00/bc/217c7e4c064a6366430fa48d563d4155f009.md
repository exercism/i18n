# مقدمه

یکی از روش‌های رایج برای اجرای منطق به‌صورت شرطی در JavaScript، دستور `if` است.
این دستور از کلیدواژه‌ی `if`، یک شرط که داخل پرانتز قرار می‌گیرد و یک بلوک کد که داخل آکولاد قرار می‌گیرد تشکیل شده است.
بلوک کد تنها زمانی اجرا می‌شود که حاصل ارزیابی شرط `true` باشد.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

می‌توان از آن به‌تنهایی استفاده کرد یا آن را با کلیدواژه‌ی `else` ترکیب کرد.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

برای قرار دادن شرطی دیگر درون دستور `else` می‌توانید از `else if` استفاده کنید.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
