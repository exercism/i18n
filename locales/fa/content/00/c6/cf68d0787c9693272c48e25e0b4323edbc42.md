# مقدمه

«تاپل» روشی سبک برای گروه‌کردن مجموعه‌ای ثابت از انواع دلخواه داده در کنار هم است. تاپل اسم خاصی ندارد؛ وقتی به یک ساختار داده اسم می‌دهید، به `struct` تبدیل می‌شود. فیلدهای تاپل هم اسم ندارند؛ به آن‌ها از طریق «تجزیه» یا بر اساس موقعیت دسترسی پیدا می‌کنید.

## نحوه‌ی نگارش

### ساخت

تاپل‌ها همیشه با یک عبارت تاپل ساخته می‌شوند:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

تاپل‌ها می‌توانند تعداد دلخواهی عنصر داشته باشند.

### دسترسی با تجزیه

می‌توان با تجزیه به عنصرهای یک تاپل دسترسی پیدا کرد. این یعنی نام متغیرهایی به تک‌تک عنصرهای تاپل نسبت می‌دهیم و در این فرآیند تاپل مصرف می‌شود.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### دسترسی بر اساس موقعیت

با اندیس موقعیتی عددی هم می‌توان به عنصرهای یک تاپل دسترسی پیدا کرد. اندیس‌گذاری، مثل همیشه، از ۰ شروع می‌شود.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## ساختارهای تاپلی

از شما خواسته می‌شود با ساختارهای تاپلی هم کار کنید. این‌ها مثل ساختارهای معمولی نوع‌های نام‌دار هستند؛ اما برخلاف ساختارهای معمولی، فیلدهای بی‌نام دارند. نحوه‌ی نگارششان بسیار شبیه به نحوه‌ی نگارش تاپل‌های معمولی است. استفاده از هر دو روش تجزیه و دسترسی موقعیتی مجاز است.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### دیدپذیری فیلدها

همه‌ی فیلدهای تاپل‌های بی‌نام همیشه عمومی هستند. اما فیلدهای ساختارهای تاپلی هرکدام دیدپذیری جداگانه‌ای دارند که به‌طور پیش‌فرض خصوصی است، درست مثل فیلدهای ساختارهای استاندارد. می‌توانید فیلدها را مثل یک ساختار استاندارد با اصلاح‌کننده‌ی `pub` عمومی کنید.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
