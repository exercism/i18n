# دستورالعمل‌ها

در حین کار در _Instruments of Texas_، به شما سپرده شده است که روی یک ماشین‌حساب آزمایشی با نمادگذاری لهستانی معکوس [RPN] کار کنید که با Elixir نوشته شده است. تیم شما با مشکلی روبه‌روست: بعضی از عملیات‌ها خطا می‌دهند و فرایند را از کار می‌اندازند. به شما سپرده شده است تابعی بنویسید که دور تابع عملیات را می‌گیرد تا بتوان خطاها را با کد اصطلاحی Elixir به شکلی شایسته‌تر مدیریت کرد.

## 1. به تیم هشدار دهید

تابع `calculate!/2` را طوری پیاده‌سازی کنید که تابع عملیات را با پشته به عنوان تنها آرگومان فراخوانی کند. تابع عملیات جای دیگری تعریف شده است، اما می‌دانید که یا با موفقیت به پایان می‌رسد یا خطا ایجاد می‌کند.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> اسم توابعی که به `!` ختم می‌شوند، هشداری برای برنامه‌نویسان است که این تابع ممکن است خطا ایجاد کند

## 2. خطا را مهار کنید

وقتی بیشتر تحقیق می‌کنید، متوجه می‌شوید که بسیاری از توابع از اتم‌ها و تاپل‌ها برای نشان دادن موفقیت یا شکست خود استفاده می‌کنند. `calculate/2` را با همین راهکار پیاده‌سازی کنید.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. پیام را منتقل کنید

بعضی از خطاها حاوی اطلاعات مهمی هستند که همکارانتان برای تضمین کارکرد درست سیستم به آن‌ها نیاز دارند. `calculate_verbose/2` را پیاده‌سازی کنید تا پیام خطا را منتقل کند. خطا یک ساختار است که فیلد `:message` را دارد.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
