# مقدمه

## کلاس

کلاس در PHP یک واحد سازماندهی کد است.
کدی که رفتار یک شیء یا رفتار یک فرایند را نشان می‌دهد می‌تواند به صورت یک کلاس کنار هم گروه‌بندی شود.
تابع‌هایی که به یک کلاس نسبت داده می‌شوند، طبق قرارداد `methods` نامیده می‌شوند.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

کلاس با کلیدواژه‌ی `new` نمونه‌سازی می‌شود. این کار حافظه را برای نمونه‌ی کلاس تخصیص می‌دهد و متد سازنده‌ی کلاس را فراخوانی می‌کند.
کلاس نمونه‌سازی‌شده را می‌توان به یک متغیر اختصاص داد.
برای فراخوانی متدهای یک نمونه‌ی کلاس می‌توانیم از عملگر دسترسی `->` استفاده کنیم.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

یک کلاس نمونه‌سازی‌شده می‌تواند با استفاده از متغیر ویژه‌ی `$this` به نمونه‌ی خودش ارجاع دهد.
کلاس می‌تواند «ویژگی» هم داشته باشد. این ویژگی‌ها مانند متغیرهایی عمل می‌کنند که به نمونه‌ی شیء کلاس وابسته‌اند.
می‌توان از داخل یا خارج به این ویژگی‌ها ارجاع داد.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
