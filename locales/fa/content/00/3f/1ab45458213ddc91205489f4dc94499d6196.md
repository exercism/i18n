# مقدمه

یک `Tuple` از بسیاری جهات شبیه یک `Vector` (یک `array` یک‌بعدی) است. اما چند تفاوت مهم وجود دارد.

- «چندتایی» با پرانتز `( )` نوشته می‌شود، نه با کروشه `[ ]`؛ هرچند در مواردی که معنا مبهم نباشد، می‌توان پرانتزها را حذف کرد.
- لازم نیست چندتایی‌ها هم‌جنس باشند: نوع هر عنصر مستقل ذخیره می‌شود.
- چندتایی‌ها تغییرناپذیرند.

تغییرناپذیری به کامپایلر امکان بهینه‌سازی‌های بیشتری می‌دهد و باعث می‌شود چندتایی‌ها از بردارها سریع‌تر باشند؛ بنابراین در مواردی که تغییرپذیری لازم نیست، بهتر است چندتایی‌ها را ترجیح دهید.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

یک سازنده‌ی `Tuple()` هم وجود دارد که هر مجموعه‌ی قابل‌پیمایش را به یک چندتایی تبدیل می‌کند. نکته‌ی کاربردی این است که با این کار، رشته به‌عنوان مجموعه‌ای قابل‌پیمایش از کاراکترها در نظر گرفته می‌شود.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

در هر چندتایی می‌توان با اندیس به عناصر دسترسی داشت یا روی آن‌ها حلقه زد.

هر چندتایی را که کاملاً عددی باشد نیز می‌توان در توابع ریاضی مانند `sum()` به کار برد، درست مانند آرایه‌ها.

## بازکردن

می‌توان با انتساب چندگانه، یک چندتایی را به عناصر جداگانه باز کرد. برای عناصری که نیازی به آن‌ها نیست، از زیرخط `_` به‌عنوان متغیر ساختگی استفاده کنید.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

برنامه‌نویسان پایتون با این نحوه‌ی نگارش انتساب چندگانه به‌خوبی آشنا هستند.

## چندتایی‌های نامدار

یک `Tuple` فقط مقدارها را در خود نگه می‌دارد. یک `NamedTuple` هر مقدار را با یک اسم جفت می‌کند.

سپس می‌توان با نشانه‌گذاری «نقطه» به هر فیلد جداگانه دسترسی داشت:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

اسم درون ساختار به‌صورت یک `Symbol` ذخیره می‌شود (نوعی تغییرناپذیر است و پیش از اسم یک دونقطه `:` قرار می‌گیرد)، بنابراین یک نحوه‌ی نگارش جایگزین هم وجود دارد:

```julia-repl
julia> nt[:b]
7.3
```

به‌سادگی می‌توان یا اسم‌ها (که «کلید» هم نامیده می‌شوند) یا مقدارها را جداگانه به دست آورد:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

توجه کنید که پیمایش روی یک چندتایی نامدار فقط _مقدارها_ را تولید می‌کند و _اسم‌ها_ نادیده گرفته می‌شوند.

چندتایی‌ها (نامدار یا بی‌نام) روشی بسیار رایج برای انتقال داده‌ی ساختیافته به توابع و بازگرداندن آن هستند. تغییرناپذیری در این کاربرد مفید است، چون ایمنی داده را تضمین می‌کند و امکان بهینه‌سازی‌های تهاجمی‌تر کامپایلر را می‌دهد.
