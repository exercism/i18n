# مقدمه

Common Lisp مفهومی به نام «چاپگر» دارد که همه‌ی توابع نوشتن نمایش متنی از داده‌های Lisp را در بر می‌گیرد. یکی از این توابع `format` است که به برنامه‌نویس اجازه می‌دهد داده‌ها را هرطور که می‌خواهد قالب‌بندی کند.

توانایی‌های `format` و چاپگر Lisp به‌طور کلی موضوع گسترده‌ای است؛ در اینجا مبانی استفاده از `format` توصیف می‌شود.

## تابع FORMAT

تابع `format` دست‌کم دو آرگومان می‌گیرد: یک جریان برای چاپ کردن و یک رشته‌ی کنترل که تعریف می‌کند چه چیزی و چگونه چاپ شود.

جریان‌ها مفهومی جداگانه‌اند و در جای دیگری توصیف می‌شوند. اما فعلاً تنها چیزی که باید بدانید این است که چاپ روی جریان انجام می‌شود و دو مقدار ویژه برای این آرگومان وجود دارد: `t` و `nil`. `t` یعنی چاپ به خروجی استاندارد (در واقع جریانی که متغیر `*standard-output*` به آن مقید شده است) و `nil` یعنی ساختن یک رشته و برگرداندن آن.

توجه کنید که `format` همیشه به `nil` ارزیابی می‌شود، مگر در همان حالت دوم که `nil` به‌عنوان جریان مشخص شده باشد. این روشی رایج برای درج یا ساخت ساده‌ی رشته است.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## دستورهای قالب‌بندی

رشته‌ی کنترل می‌تواند شامل «دستورهای قالب‌بندی» باشد که به `format` می‌گویند چه چیزی چاپ شود و هر پارامتر دیگر `format` چگونه تفسیر شود. به یک معنا، رشته‌ی کنترل برنامه‌ای است که `format` آن را تفسیر و اجرا می‌کند. همه‌ی دستورها با `~` شروع می‌شوند و پس از آن‌ها یک نویسه می‌آید (_برای نمونه_ `~A`، `~D`، `~&`). بزرگ یا کوچک بودن نویسه اهمیتی ندارد.

بیشتر دستورهای قالب‌بندی صرفاً یک آرگومان `format` را در خروجی درج می‌کنند. به این کار «مصرف کردن» آرگومان می‌گویند. بعضی دستورها آرگومانی مصرف نمی‌کنند یا بیش از یکی مصرف می‌کنند. حتی یک دستور به شما اجازه می‌دهد در فهرست آرگومان‌ها جابه‌جا شوید یا آرگومان‌ها را نادیده بگیرید.

## قالب‌بندی پایه

یک دستور قالب‌بندی بسیار همه‌کاره `~A` است. این دستور نسخه‌ای «خوانا برای انسان» از داده را چاپ می‌کند.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

دستور قالب‌بندی مفید دیگر `~S` است. این دستور نسخه‌ای «خوانا برای ماشین» از داده را چاپ می‌کند. اگر بخواهید بتوانید خروجی تولیدشده را به‌عنوان داده‌ی Lisp تفسیر کنید، این می‌تواند بسیار مفید باشد. برای بسیاری از داده‌ها ظاهری مانند `~A` خواهد داشت، اما توجه کنید که مثلاً برای رشته‌ها خروجی شامل علامت‌های نقل‌قول هم می‌شود (که وقتی در رشته‌ای دیگر قرار گیرد، فرار داده می‌شوند) تا بتوان مقدار را دوباره به‌عنوان پارامتر رشته خواند.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

دو دستور بسیار مفید دیگر `~%` و `~&` هستند. اولی یک نویسه‌ی خط جدید تولید می‌کند و دومی یک «خط تازه». تفاوت در این است که `~%` همیشه خط جدید تولید می‌کند، اما `~&` تنها در صورتی یکی تولید می‌کند که در ابتدای خط نباشیم. هیچ‌کدام از این دو آرگومانی مصرف نمی‌کنند.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

در پایان، `~~` دستوری ساده است که خودِ `~` را چاپ می‌کند.
