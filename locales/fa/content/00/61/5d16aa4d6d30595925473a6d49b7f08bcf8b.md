# دستورالعمل‌ها

هر کمربند ایمنی در سیرک برای باری بر حسب کیلوگرم درجه‌بندی می‌شود و هیچ‌کس تا زمانی که اعداد بررسی نشوند بالا نمی‌رود.

کلاس `SAFETY_HARNESS` به موارد زیر نیاز دارد. کد اولیه، کلاس و ویژگی آن را به شما می‌دهد؛ بقیه را اضافه کنید. هر روال زیر یک قرارداد دارد و راهنمایی‌ها می‌گویند کدام.

## 1. یک کمربند ایمنی آماده کنید

`create` باری را می‌گیرد که کمربند ایمنی برای آن درجه‌بندی شده است و یک کمربند ایمنی برمی‌گرداند.
درجه‌بندی صفر یا کمتر اصلاً کمربند ایمنی نیست، پس این یک `pre` است.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. چقدر ظرفیت خالی دارد؟

`spare_capacity` بار روی کمربند ایمنی را می‌گیرد و برمی‌گرداند که چقدر دیگر می‌تواند تحمل کند. بار نباید منفی باشد و نباید از حد مجاز بیشتر باشد؛ هر دو `pre` هستند. پاسخ هرگز منفی نیست، که یک `post` است.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. چقدر پر است؟

`percent_used` بار را می‌گیرد و آن را به‌صورت درصدی از حد مجاز برمی‌گرداند، با گرد کردن به پایین. بار نباید منفی باشد و پاسخ هرگز منفی نیست.

```sather
harness.percent_used(60)
-- => 50
```

## 4. آیا ایمن است؟

`is_safe` بار را می‌گیرد و پاسخ می‌دهد که آیا در محدوده‌ی مجاز است یا نه. می‌توان درباره‌ی هر باری پرسید، حتی یک بار مسخره، بنابراین هیچ `pre` روی بار وجود ندارد؛ اما یک `post` بنویسید که بگوید پاسخ دقیقاً زمانی درست است که بار در محدوده‌ی مجاز باشد.

```sather
harness.is_safe(200)
-- => false
```
