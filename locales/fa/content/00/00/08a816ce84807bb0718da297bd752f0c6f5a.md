# مقدمه

«عبارت باقاعده» یک الگوی کوچک است که توصیف می‌کند یک متن باید چه شکلی داشته باشد. ابزارهای عبارت باقاعده در Factor در واژگان [`regexp`][regexp] قرار دارند و یک الگو بین `R/ ` و `/` نوشته می‌شود.

بیشتر نویسه‌های یک الگو معنای خودشان را دارند. چند جزء خاص هم نشان‌دهنده‌ی نوعِ نویسه یا تعداد مورد انتظار آن هستند:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

پس `R/ [A-Z]{2}-\d{4}/` یعنی «دو حرف بزرگ، یک خط تیره، چهار رقم».

`matches?` بررسی می‌کند که آیا یک رشته‌ی *کامل* با الگو مطابقت دارد یا نه:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

واژه‌های دیگری هم *درون* یک رشته را بررسی می‌کنند: `all-matching-subseqs` همه‌ی تطابق‌ها را برمی‌گرداند، `count-matches` آن‌ها را می‌شمارد، `re-contains?` گزارش می‌دهد که آیا تطابقی وجود دارد یا نه و `re-replace` هر تطابق را با متن جدید جایگزین می‌کند:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
