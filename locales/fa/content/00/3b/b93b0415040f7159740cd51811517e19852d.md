# Tests

برای استفاده از تست‌رانر، به [نصب صحیح Godot][installation] نیاز دارید.

## اجرای تست‌ها

از [تست‌رانر][test runner] برای بارگذاری و تست راه‌حل‌ها استفاده می‌شود.
برای اجرای تست‌رانر، ابتدا آن را به‌صورت محلی دانلود کنید و سپس با `godot` تست‌رانر را اجرا کنید.
در آینده، هنگام استفاده از `exercism download`، تست‌رانر به‌طور خودکار همراه با تمرین‌ها دانلود می‌شود.

### دریافت تست‌رانر

از قطعه‌ی شل زیر می‌توانید برای دانلود تست‌رانر استفاده کنید.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### اجرای تست‌رانر

تست‌رانر با `godot` در حالت headless (بدون IDE) اجرا می‌شود.
`-s` یا `--script` به Godot می‌گوید که اسکریپت تست‌رانر را اجرا کند.
تست‌رانر دو آرگومان انتظار دارد: slug و مسیر پوشه‌ی راه‌حل.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

برای مثال،

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
