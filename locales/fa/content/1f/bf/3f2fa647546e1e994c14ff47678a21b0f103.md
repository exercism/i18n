# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است که یک [استثنا ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** هم همراه آن بگذارید تا نشان دهید منبع خطا چیست. این کار code شما را خواناتر می‌کند و به debugging کمک زیادی می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا از یک نوع مشخص است، می‌توانید یکی از [انواع خطای داخلی](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما همچنان باید پیام معناداری همراه آن بگذارید.

این تمرین به‌طور خاص از شما می‌خواهد که با استفاده از [دستور raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) یک `ValueError` را «پرتاب» کنید، وقتی مقداری که داده شده در آرایه پیدا نمی‌شود. tests تنها زمانی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بگذارید.

برای اینکه یک `ValueError` همراه با پیام ایجاد کنید، پیام را به‌عنوان آرگومان به نوع `exception` بدهید:

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
