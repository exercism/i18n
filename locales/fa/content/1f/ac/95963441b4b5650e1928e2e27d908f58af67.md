# قالب‌بندی درصدی یا «سبک قدیمی»

این راه‌حل برای رشته‌ها از `%%-formatting` یا [قالب‌بندی سبک قدیمی][old-style formatting] استفاده می‌کند.

هرچند `%%-formatting` روشی کاملاً معتبر است، می‌تواند مشکلاتی در نمایش یا خوانایی ایجاد کند. استفاده از روش [str.format()][str.format()] یا [f-strings][f-strings] (_که با نام‌های «formatted string literals» یا «interpolated strings» هم شناخته می‌شود_) می‌تواند گزینه‌هایی ارائه دهد که خوانایی را بهبود می‌بخشد و جای‌گذاری متغیرها درون رشته‌ها را شفاف‌تر می‌کند.

پست وبلاگ [String Formatting in Python][string formatting in python] نقطه‌ی شروعی خوب برای درک همه‌ی گزینه‌های قالب‌بندی رشته در Python است و [Newer Python String Format Techniques][newer python string format techniques] هم نکات و ترفندهای خوبی برای استفاده از `str.format()` و `f-strings` ارائه می‌دهد.
