# Null

`Null` یک نوع مقدار اولیه است که تنها یک مقدار دارد: `null`.
از `Null` اغلب برای نمایش هیچ‌بودن استفاده می‌شود.
آن را «کاذب» در نظر می‌گیرند، اما با `false` و سایر مقادیر کاذب تفاوت دارد.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## کار با مقادیر null

در PHP، مقادیر `null` می‌توانند علت رایجی برای خطا باشند، چون اغلب به‌جای یک وضعیت خطا یا برای نمایش هیچ‌بودن بازگردانده می‌شوند.
جلوگیری از بروز خطاها اغلب مستلزم «بررسی null» است تا پیش از انجام عملیات روی مقدار، مطمئن شویم که `null` نیست.

بررسی مکرر `null` می‌تواند مستعد خطا باشد، بنابراین PHP دو عملگر برای کار با مقادیر `null` ارائه می‌دهد: عملگر دسترسی ایمن به null، `?->`، و عملگر ادغام null، `??`.
