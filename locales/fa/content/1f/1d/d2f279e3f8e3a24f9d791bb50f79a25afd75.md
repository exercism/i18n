# درباره

PHP زبانی سمت سرور است که برای توسعه‌ی وب مناسب است. سرواژه‌ی آن بازگشتی است و مخففِ _PHP: پیش‌پردازنده‌ی ابرمتن_ است.

PHP بسیار انعطاف‌پذیرتر از اسکریپت‌نویسی CGI است و اغلب برای افزودن تعامل به HTML ساده و تقویت frameworkهای وب به کار می‌رود.

این زبان روی هر سیستم‌عاملی قابل استفاده است. PHP توسط بیشتر وب‌سرورهای رایج پشتیبانی می‌شود و اغلب از طریق یک ماژول مفسر مدیریت می‌شود. این کار کد وب ایستا را با درج‌های پویا ترکیب می‌کند.

PHP فقط یک framework وب‌سرور نیست. برای اسکریپت‌نویسی خط فرمان (تجزیه‌ی بدون نمایشگر) و توسعه‌ی GUI هم مفید است.

دلایلی که باید PHP را یاد بگیرید:

- زبانی متن‌باز است
- مستندسازی و پشتیبانی خوبی دارد
- با بیشتر وب‌سرورهای رایج سازگار است
- شروع و یادگیری آن آسان است
- مقیاس‌پذیری و توسعه‌پذیری بالایی دارد
