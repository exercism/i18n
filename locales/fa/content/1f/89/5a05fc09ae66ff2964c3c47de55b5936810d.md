# منابع

## ساخت اولین ماژول Coffee خودتان

برای ساخت ماژولی که بتوان با `Bob = require './bob'` آن را بارگذاری کرد، این کد را در `bob.coffee` قرار دهید:

```coffeescript
class Bob

module.exports = Bob
```

اطلاعات بیشتر درباره‌ی ماژول‌ها را می‌توانید در [مستندات Node](http://nodejs.org/api/modules.html#modules_module_exports) پیدا کنید.

## Visual Studio روی Windows

اگر نسخه‌ی پولی Visual Studio را دارید، می‌توانید یک solution آماده از Visual Studio را دانلود کنید که از پیش برای کار با CoffeeScript و سایر زبان‌هایی که Visual Studio پشتیبانی می‌کند، تنظیم شده است.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. قالب [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) را از GitHub دانلود کنید؛ برای این کار روی دکمه‌ی «Download Zip» در همان صفحه کلیک کنید.
2. قالب را در پوشه‌ی تمرین‌های خود از حالت فشرده خارج کنید، مثلاً در `C:\src\exercises`
2. [Exercism CLI](http://exercism.io/cli) را نصب کنید.
3. یک خط فرمان در پوشه‌ی تمرین خود باز کنید.
4. کلید API خود را به exercism اضافه کنید `exercism configure --key=YOUR_API_KEY`
5. پوشه‌ی منبع خود را در exercism تنظیم کنید `exercism configure --dir=C:\src\exercises`
6. [اولین تمرین خود را دریافت کنید](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. فایل solution مربوط به Exercism را در Visual Studio باز کنید.
8. پروژه‌ی Exercism.coffeescript را گسترش دهید.
9. در «Solution Explorer» روی **«Show All Files»** کلیک کنید (پایین را ببینید).
10. تمرینی که همین حالا دریافت کردید، خاکستری نمایش داده می‌شود. روی پوشه کلیک راست کنید و **«Include In Project»** را انتخاب کنید.
11. شروع کنید به کدنویسی...

![افزودن فایل‌ها](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

برای کار با CoffeeScript در Visual Studio، بهتر است افزونه‌ی [Web Essentials](http://vswebessentials.com/) را نصب کنید. این افزونه کار با Javascript را هم بسیار آسان‌تر می‌کند.

می‌توانید تست‌های واحد را از خط فرمان node.js و با استفاده از فایل batch در پروژه اجرا کنید.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

اگر با اجرای تست‌ها هیچ خروجی‌ای نمی‌بینید، احتمالاً در خط فرمان Node.js نیستید.
