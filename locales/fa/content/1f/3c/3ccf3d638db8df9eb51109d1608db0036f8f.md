# مقدمه

در پایتون، از `None` اغلب برای نشان دادن نبود مقدار استفاده می‌شود: جای‌نگه‌داری برای تعریف یک متغیر، شیء یا آرگومان `null` (خالی).

اگر درباره‌ی نوع `NULL` یا `nil` در زبان برنامه‌نویسی دیگری شنیده باشید یا از آن استفاده کرده باشید، این کاربرد `None` در پایتون برایتان آشنا خواهد بود.
`None` به شما کمک می‌کند متغیرها یا آرگومان‌های تابعی را تعریف کنید که هنوز مقداری برایشان ندارید.
بعداً می‌توان در صورت نیاز مقدار مشخصی به آن‌ها نسبت داد:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

`None` هنگام استفاده در یک بررسی شرطی به `False` تبدیل می‌شود، پس برای اعتبارسنجی «وجود» یا «نبود» یک مقدار (هر مقداری که باشد) مفید است؛ الگویی که وقتی یک تابع یا فرایند ممکن است یک `error`، `object` یا پیام برگرداند، بسیار به کار می‌رود.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
