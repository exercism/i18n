# مقدمه

در SQL، دستور `SELECT` به شما امکان می‌دهد داده‌ها را از یک پایگاه داده بازیابی کنید.
نتیجه‌ی یک دستور `SELECT` یک «مجموعه‌ی نتیجه» است.
مجموعه‌ی نتیجه شامل مقادیری است که در سطرها و ستون‌ها چیده شده‌اند.
هر ستون، یک ویژگی مشخص از داده‌ها است.
هر سطر برای هر ستون یک مقدار دارد.

یک راه برای اندیشیدن به این موضوع این است که مجموعه‌ای از ستون‌ها یک ساختار داده را نمایش می‌دهد: هر ستون نماینده‌ی یک فیلد از ساختار داده است و هر سطر یک نمونه از ساختار داده.

با یک دستور `SELECT` می‌توانید مشخص کنید چه داده‌ای را می‌خواهید بازیابی کنید.
همچنین به‌صورت اختیاری می‌توانید داده‌های خروجی را تبدیل کنید، فیلتر کنید یا شکل آن‌ها را تغییر دهید.

## مبانی

ساختار کلی یک دستور ساده‌ی `SELECT` به این صورت است:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
بندهای `FROM` و `WHERE` اختیاری هستند.
برای مثال، دستوری مانند `SELECT "Hello, world.";` کاملاً معتبر است.

همچنین توجه داشته باشید که شکستن خط الزامی نیست؛ هر فاصله‌ای برای جدا کردن بندهای مختلف (یعنی بخش‌های مختلف) دستور `SELECT` کافی است.
~~~~

بلافاصله پس از کلیدواژه‌ی `SELECT`، فهرستی از ستون‌هایی می‌آید که می‌خواهید در نتیجه داشته باشید.
بند `FROM` منبع داده را مشخص می‌کند که معمولاً یک جدول در پایگاه داده است.
بند `WHERE` داده‌های خروجی را بر اساس یک یا چند معیار فیلتر می‌کند.

## فیلتر کردن داده‌ها با بند WHERE

بند `WHERE` به شما امکان می‌دهد داده‌هایی را که یک دستور `SELECT` بازیابی کرده است فیلتر کنید.
برای مثال، اگر فقط داده‌های Appliances را بخواهیم، می‌توانیم این کار را انجام دهیم:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

نتیجه:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

یا شاید فقط داده‌هایی را بخواهیم که وزنشان بین 2.0 و 6.0 باشد:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

نتیجه:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

علاوه بر `=` و `BETWEEN...AND`، بند `WHERE` از طیف گسترده‌ای از عبارت‌ها پشتیبانی می‌کند، از جمله مقایسه (`<`، `<=`، `>`، `>=`)، تطبیق الگو (`LIKE`، `GLOB`، `REGEXP`، `MATCH`) و بررسی عضویت در یک فهرست (`IN`، `NOT IN`).
برای مستندات کامل، [عبارت‌های زبان SQL](sql-expr) را ببینید.
