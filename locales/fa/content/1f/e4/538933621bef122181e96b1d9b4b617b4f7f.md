# مقدمه

## دیکشنری

«دیکشنری» مجموعه‌ای از عناصر است که هر عنصر آن از یک «کلید» و یک «مقدار» تشکیل می‌شود، به‌گونه‌ای که اگر کلیدی را به یکی از «متد»های دیکشنری بدهید، مقدار متناظر با آن برگردانده می‌شود. نقش آن همان نقش «مپ» یا «آرایه‌ی انجمنی» در زبان‌های دیگر است.

یک دیکشنری را می‌توان به شکل زیر ساخت:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

یا

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

توجه کنید که نوع کلید و مقدار بخشی از تعریف دیکشنری است.

پس از ساخته شدن، می‌توان با متدهای توکار `Add` و `Remove` درایه‌هایی را به دیکشنری اضافه یا از آن حذف کرد.

خواندن یا به‌روزرسانی مقدارها در یک دیکشنری با نمایه‌گذاری آن به‌کمک یک کلید انجام می‌شود:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

می‌توانید با این کد بررسی کنید که آیا مقداری در دیکشنری وجود دارد یا نه:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

شمارش روی یک دیکشنری، جفت‌های کلید و مقدار آن را شمارش می‌کند. دیکشنری ویژگی‌هایی هم دارد که امکان شمارش روی کلیدها یا مقدارهای آن را فراهم می‌کنند.
