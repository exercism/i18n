# مقدمه

`Complex numbers` پیچیده نیستند.
فقط به اسمی نیاز دارند که کمتر نگران‌کننده باشد.

آن‌قدر مفیدند، به‌ویژه در مهندسی و علوم، که R اعداد مختلط را در کنار `integer`، `double`، `logical`، `character` و `raw` به‌عنوان انواع اتمی استاندارد در خود جای داده است.

## مبانی

یک عدد `complex` در R یک مقدار واحد است.
اما در کاربرد، می‌توان آن را جفتی از اعداد در نظر گرفت.
این دو، به دلایل تاریخی تأسف‌بار، «حقیقی» و «موهومی» نامیده می‌شوند.
باز هم بهتر است روی سادگی بنیادین تمرکز کنید، نه روی اسم‌های عجیب.

برای ساختن اعداد مختلط از دو عدد حقیقی، کافی است پسوند `i` را به بخش موهومی اضافه کنید.

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

برای ساختن یک عدد مختلط از متغیرهای حقیقی، نحوه‌ی نگارش بالا کار نمی‌کند.
نوشتن `r + imi` تجزیه‌گر را گمراه می‌کند و باعث می‌شود فکر کند `imi` اسم یک متغیر (ناموجود) است.

یا بخش موهومی را در `1i` ضرب کنید، یا از تابع [`complex()`][ref-complex] استفاده کنید:

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

شاید بپرسید چرا `i` و نه `j`؟

بیشتر مهندسان `j` را ترجیح می‌دهند.
بیشتر دانشمندان و ریاضی‌دانان نماد ریاضی `i` را برای _موهومی_ ترجیح می‌دهند، اما این نماد با کاربرد `i` به معنای _جریان_ در مهندسی برق در تضاد است.

R حرف `i` را برگزید، Python حرف `j` را و Julia با انتخاب `im` از این جنجال کنار کشید.
هنگام جابه‌جایی میان زبان‌های برنامه‌نویسی [علوم، فناوری، مهندسی و ریاضیات][wiki-STEM] احتیاط کنید.

برای دسترسی جداگانه به بخش‌های یک عدد مختلط:

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

هر یک از این دو بخش می‌تواند صفر باشد و آن‌گاه ریاضی‌دانان ممکن است از «کاملاً حقیقی» یا «کاملاً موهومی» بودن عدد سخن بگویند.
با این حال، در R همچنان یک عدد مختلط است.

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

شاید شنیده باشید که «`i` (یا `j`) ریشه‌ی دوم -۱ است».

فعلاً تنها معنایش این است که بخش موهومی، _طبق تعریف_، در تساوی زیر صدق می‌کند:

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

این ایده‌ی ساده‌ای است، اما به پیامدهای جالبی می‌انجامد.

## حساب

بیشتر عملگرهایی که با اعداد اعشاری و صحیح به کار می‌روند، با اعداد مختلط هم کار می‌کنند:

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

## توابع

بیشتر توابع ریاضی با ورودی‌های مختلط کار می‌کنند.

علاوه بر `Re()` و `Im()`، چندین تابع دیگر هم وجود دارد که به‌طور خاص برای اعداد مختلط مهم‌اند.

- `Conj()` به‌سادگی علامت بخش موهومی یک عدد مختلط را معکوس می‌کند (_از + به - یا برعکس_).
  - به دلیل نحوه‌ی کار ضرب مختلط، این کار مفیدتر از آن است که فکر می‌کنید.
- `abs(<complex number>)` تضمین‌شده یک عدد حقیقی بدون بخش موهومی («اندازه»ی آن) برمی‌گرداند و `Mod(<complex number>)` معادل آن است.
- `Arg(<complex number>)` زاویه‌ی فاز را بر حسب رادیان برمی‌گرداند.

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
