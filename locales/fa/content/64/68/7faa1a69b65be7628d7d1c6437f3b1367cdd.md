# پیوست دستورالعمل‌ها

## پیاده‌سازی

یک تابع Go به اسم `Cost` تعریف کنید که هزینه‌ی فهرست مشخصی از کتاب‌ها را بر اساس تخفیف‌های تعریف‌شده محاسبه می‌کند.

از امضای زیر برای تابع `Cost` استفاده کنید:

```go
func Cost(books []int) int
```

تابع `Cost` هزینه‌ی کل (پس از اعمال تخفیف‌ها) را به سنت برمی‌گرداند.
برای مثال، هزینه‌ی یک کتاب ۸۰۰ سنت است که برابر با ۸ دلار می‌شود.
در این تمرین فقط محاسبات عدد صحیح لازم است.
