# پیوست دستورالعمل‌ها

## قالب خروجی

دنباله‌ی پروتئین را به شکل رشته‌ای که با پوچ پایان می‌یابد خروجی بدهید، با یک نویسه‌ی خط جدید بعد از هر پروتئین.

یک نمونه خروجی چنین است: `"Methionine\nPhenylalanine\nSerine\n"`

اگر ورودی نامعتبر باشد، یک رشته‌ی خالی خروجی بدهید.

## ثبات‌ها

| ثبات     | کاربرد         | نوع     | توضیح                            |
| -------- | -------------- | ------- | -------------------------------- |
| `$a0`    | ورودی          | آدرس    | رشته‌ی ورودی پایان‌یافته با پوچ   |
| `$a1`    | ورودی/خروجی    | آدرس    | رشته‌ی خروجی پایان‌یافته با پوچ   |
| `$t0-9`  | موقت           | هر نوع  | برای ذخیره‌سازی موقت استفاده می‌شود |
