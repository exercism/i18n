# مقدمه

## زمان

مفهوم زمان در .NET با استفاده از ساختار `DateTime` بررسی می‌شود. روال‌هایی برای تبدیل بین زمان محلی و UTC وجود دارد. محاسبات را می‌توان به کمک `TimeSpan` انجام داد.

## منطقه‌ی زمانی

کلاس `TimeZoneInfo` روال‌هایی برای مدیریت تفاوت‌های میان مناطق زمانی ارائه می‌دهد. کلاس `TimeZoneInfo` همچنین متدهایی دارد که کار با ساعت تابستانی را آسان می‌کنند.

کلاس `CultureInfo` از قالب‌های تاریخ و زمان وابسته به فرهنگ پشتیبانی می‌کند.

برای پشتیبانی از کدنویسی چندسکویی، کلاس `RuntimeInformation` به شما امکان می‌دهد تشخیص دهید کد شما روی کدام سیستم‌عامل اجرا می‌شود: Linux، Windows یا OSX.
