# دستورالعمل‌ها

وظیفه‌ی شما این است که توضیحات تاریخ تحویل را بر اساس زمان شروع جلسه به تاریخ‌های تحویلِ _واقعی_ تبدیل کنید.

توضیحات تاریخ تحویل دو نوع دارند:

1. ثابت: مجموعه‌ای از واژه‌های از پیش تعیین‌شده.
2. متغیر: واژه‌هایی که بخشی متغیر دارند، اما از مجموعه‌ای از الگوهای از پیش تعیین‌شده پیروی می‌کنند.

## توضیحات تاریخ تحویل ثابت

سه توضیح تاریخ تحویل ثابت وجود دارد:

- `"NOW"`
- `"ASAP"` (در اسرع وقت)
- `"EOW"` (پایان هفته)

جدول زیر نشان می‌دهد که چگونه آن‌ها را تبدیل کنید:

| توضیح   | شروع جلسه                    | تاریخ تحویل                          |
| ------- | ---------------------------- | ----------------------------------- |
| `"NOW"` | -                            | دو ساعت پس از شروع جلسه              |
| `"ASAP"`| پیش از ساعت ۱۳:۰۰             | امروز ساعت ۱۷:۰۰                     |
| `"ASAP"`| ساعت ۱۳:۰۰ یا پس از آن        | فردا ساعت ۱۳:۰۰                      |
| `"EOW"` | دوشنبه، سه‌شنبه یا چهارشنبه   | جمعه ساعت ۱۷:۰۰                      |
| `"EOW"` | پنجشنبه یا جمعه               | یکشنبه ساعت ۲۰:۰۰                    |

## توضیحات تاریخ تحویل متغیر

دو الگوی توضیح تاریخ تحویل متغیر وجود دارد:

- `"<N>M"` (ماهِ N اُم)
- `"Q<N>"` (فصلِ N اُم)

| توضیح   | شروع جلسه                 | تاریخ تحویل                                                     |
| ------- | ------------------------- | -------------------------------------------------------------- |
| `"<N>M"`| پیش از ماهِ N اُم          | ساعت ۸:۰۰ در _اولین_ روز کاریِ ماهِ N اُم امسال                  |
| `"<N>M"`| در ماهِ N اُم یا پس از آن   | ساعت ۸:۰۰ در _اولین_ روز کاریِ ماهِ N اُم سال آینده              |
| `"Q<N>"`| در فصلِ N اُم یا پیش از آن | ساعت ۸:۰۰ در _آخرین_ روز کاریِ فصلِ N اُم امسال                   |
| `"Q<N>"`| پس از فصلِ N اُم           | ساعت ۸:۰۰ در _آخرین_ روز کاریِ فصلِ N اُم سال آینده               |

~~~~exercism/note
یک روز کاری یعنی دوشنبه، سه‌شنبه، چهارشنبه، پنجشنبه یا جمعه.

سال چهار فصل دارد که هر فصل از سه ماه تشکیل شده است:
1. ژانویه/فوریه/مارس
2. آوریل/مه/ژوئن
3. ژوئیه/اوت/سپتامبر
4. اکتبر/نوامبر/دسامبر.
~~~~
