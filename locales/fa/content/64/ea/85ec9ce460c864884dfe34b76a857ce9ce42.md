# مقدمه

## کلیدواژه‌ی `auto` در C++

در C++، کلیدواژه‌ی `auto` ویژگی قدرتمندی است که در C++۱۱ معرفی شد و برای تعریف متغیرها با نوع داده‌ی استنتاج‌شده به کار می‌رود.
کامپایلر نوع متغیر را بر اساس مقدار اولیه‌اش استنتاج می‌کند و همین می‌تواند کد را خواناتر و نگهداری‌اش را آسان‌تر کند.

## نمونه‌ی کاربرد

مثال زیر را در نظر بگیرید که در آن از `auto` برای تعریف متغیرها استفاده می‌شود:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

در هر مورد، نوع متغیر از مقداری که با آن مقداردهی اولیه شده است استنتاج می‌شود.

## استنتاج نوع

کلیدواژه‌ی `auto` با کاهش پرگویی نوع‌های صریح، به نوشتن کد مختصرتر و خواناتر کمک می‌کند.

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

در این قطعه کد، `auto` نوع `purple_wedding_pie` را به‌صورت `std::vector<std::string>` استنتاج می‌کند و نیازی به مشخص کردن دوباره‌ی صریح نوع نیست.

## سازگاری

کلیدواژه‌ی `auto` با ساختارهای مختلف C++ سازگار است و آن را به ابزاری همه‌کاره در برنامه‌نویسی مدرن C++ تبدیل می‌کند.

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

در مفاهیم بعدی اغلب کلیدواژه‌ی `auto` را همراه با عبارات لامبدا، حلقه‌های for مبتنی بر بازه و تکرارگرها خواهیم دید.
