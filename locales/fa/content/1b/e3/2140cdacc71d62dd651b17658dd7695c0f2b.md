# شرط‌ها

Crystal چیزی به نام عبارت‌های کنترلی دارد؛ این‌ها برای کنترل نحوه‌ی اجرای برنامه به کار می‌روند و یک مقدار درست یا غلط می‌گیرند.
عملگرهایی وجود دارند که می‌توان با آن‌ها مقادیر درست یا غلط ساخت؛ به این‌ها [عملگرهای برابری و مقایسه][equality-and-comparison] می‌گویند.

دو عبارت کنترلی اصلی وجود دارند که کنترل می‌کنند کدام کد اجرا شود و کدام نشود.
به بیان دیگر، کدام شاخه اجرا خواهد شد.

این دو عبارت‌اند از: `if` و عبارت `unless`.

## عملگرهای مقایسه

عملگرهای مقایسه برای مقایسه‌ی مقادیر به کار می‌روند و مقدار `true` یا `false` برمی‌گردانند.
این عملگرها برای مقایسه به دو مقدار هم‌نوع نیاز دارند.
اگر مقادیر هم‌نوع نباشند، کامپایلر خطا می‌دهد.
در ادامه فهرستی از عملگرهای مقایسه و نمونه‌ای از حالتی که مقدار `true` می‌دهند آمده است:

| متد | توضیح           | مثال |
| ------ | --------------------- | ------- |
| <      | کوچک‌تر از             | 4 < 5   |
| <=     | کوچک‌تر یا مساوی    | 4 <= 4  |
| >      | بزرگ‌تر از          | 3 > 1   |
| >=     | بزرگ‌تر یا مساوی | 2 >= 2  |

## عملگرهای برابری

عملگرهای برابری شبیه عملگرهای مقایسه‌اند، اما برای بررسی برابری دو مقدار به کار می‌روند.

عملگر `==` بررسی می‌کند که آیا دو مقدار، با در نظر گرفتن نوع‌شان، برابرند یا نه.
اگر مقادیر یکسان باشند `true` و در غیر این صورت `false` برمی‌گرداند.
عملگر `==` می‌تواند هر نوع مقداری را با هر نوع مقدار دیگری مقایسه کند.
عملگر `!=` نیز همین‌طور کار می‌کند، اما اگر مقادیر برابر نباشند `true` و اگر برابر باشند `false` برمی‌گرداند.

## عملگر سفینه‌ی فضایی

عملگر سفینه‌ی فضایی یک عملگر مقایسه‌ی منحصربه‌فرد است و نامش از ظاهرش گرفته شده است.
از این نظر منحصربه‌فرد است که به جای مقدار درست یا غلط، یک عدد برمی‌گرداند.
به صورت `<=>` نوشته می‌شود و برای مقایسه‌ی دو مقدار به کار می‌رود.
اگر مقدار سمت چپ بزرگ‌تر از مقدار سمت راست باشد `1`، اگر کوچک‌تر باشد `-1` و اگر مقادیر برابر باشند `0` برمی‌گرداند.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## دستور `if`

دستور [`if`][if] برای بررسی درست یا غلط بودن یک شرط به کار می‌رود.
اگر شرط درست باشد، کدی که داخل دستور if قرار دارد اجرا می‌شود.
دستور `if` با کلیدواژه‌ی `end` پایان می‌یابد.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## دستور `unless`

دستور [`unless`][unless] بسیار شبیه دستور `if` کار می‌کند، اما اگر شرط غلط باشد، کدی را که داخل دستور `unless` قرار دارد اجرا می‌کند.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## دستور `else`

دستور `else` می‌تواند همراه با دستورهای `if` و `unless` به کار رود.
دستور `else` زمانی اجرا می‌شود که شاخه‌ی `if` یا شاخه‌ی `unless` اجرا نشده باشد.

~~~~exercism/warning
با اینکه می‌توان از یک شاخه‌ی `else` همراه با `unless,` استفاده کرد، این کار توصیه نمی‌شود چون خوانایی را کاهش می‌دهد.
در عوض، توصیه می‌شود از `if !condition` همراه با یک شاخه‌ی `else` استفاده کنید.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## دستورهای آبشاری `if`

دستور `elsif` می‌تواند همراه با دستور if به کار رود.
دستور `elsif` زمانی اجرا می‌شود که شاخه‌ی if اجرا نشده باشد و شرط دستور `elsif` درست باشد.
دستورهای `elsif` را می‌توان به هم زنجیر کرد و نخستین شرط درست اجرا می‌شود.
همچنین می‌توان در انتهای دستور if یک دستور else قرار داد که اگر هیچ‌یک از دستورهای پیشین درست نبوده باشد، اجرا می‌شود.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## عملگر سه‌تایی

Crystal یک عملگر سه‌تایی دارد، یعنی یک دستور if-else تک‌خطی: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## `if` و `unless` به عنوان پسوند

دستور if و unless را می‌توان به عنوان [پسوند][if-as-suffix] هم به کار برد؛ این زمانی مفید است که بخواهید یک خط کد را در صورت درست بودن شرط اجرا کنید.
برای این کار، دستور if یا unless را بعد از کدی که می‌خواهید اجرا شود قرار می‌دهید.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## انواع همراه با شرط‌ها

وقتی انواع مختلفی به یک متغیر نسبت داده شود، متغیر هر دو نوع را در خود نگه می‌دارد.
دلیلش این است که کامپایلر نمی‌داند کدام شاخه اجرا خواهد شد.
این انتساب چندگانه که به «اتحاد» نیز شناخته می‌شود، در مفاهیم بعدی توضیح داده خواهد شد.
این موضوع در مثال زیر دیده می‌شود:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
