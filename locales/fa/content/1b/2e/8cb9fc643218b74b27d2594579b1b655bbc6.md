# کلاس

«کلاس» یک مفهوم محوری در برنامه‌نویسی شیءگرا است.
در Crystal همه‌چیز یک «شیء» است، هر شیء یک نوع دارد و می‌تواند به برخی «متد»ها پاسخ دهد.
کلاس‌ها نقشه‌ی ساخت اشیاء هستند و مقادیر اولیه‌ی وضعیت، مانند متغیرها، و پیاده‌سازی‌های رفتار، مانند متدها، را فراهم می‌کنند.
اشیاء نمونه‌های کلاس‌اند که همه‌ی متغیرهای نمونه‌ای و وضعیت‌ها را در خود نگه می‌دارند.

## تعریف کلاس

کلاس با کلیدواژه‌ی `class` تعریف می‌شود و پس از آن اسم کلاس می‌آید که با `UpperCamelCase` نوشته می‌شود.

```crystal
class Account
end
```

## ساخت یک نمونه

برای [ساختن یک نمونه از یک کلاس][new-initialize]، اسم کلاس را با متد `new` فراخوانی کنید.

```crystal
class Account
end

account = Account.new
```

در مثال بالا، متغیر `account` نمونه‌ای از کلاس `Account` است.

هنگام ساخت یک نمونه، متدی ویژه به اسم `initialize` نقش سازنده را ایفا می‌کند.
این متد هنگام ساخت نمونه فراخوانی می‌شود.
سازنده به شما امکان می‌دهد وضعیت اولیه‌ی نمونه را تعیین کنید.
متد `initialize` می‌تواند آرگومان بگیرد و این آرگومان‌ها هنگام ساخت نمونه پاس داده می‌شوند.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
متد `initialize` نمی‌تواند به‌صورت دستی مقداری برگرداند؛ در عوض، `new` نمونه‌ی تازه‌ساخته‌شده را برمی‌گرداند.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## متدهای نمونه‌ای

متد نمونه‌ای متدی است که در اختیار نمونه‌ی یک کلاس قرار دارد و می‌توان آن را روی همان نمونه فراخوانی کرد.
متدهای نمونه‌ای با کلیدواژه‌ی `def` و پس از آن اسم متد تعریف می‌شوند.
این متدها داخل تعریف کلاس نوشته می‌شوند.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## متغیرهای نمونه‌ای

[متغیرهای نمونه‌ای][instance-variable] متغیرهایی‌اند که در همه‌ی متدهای نمونه در دسترس‌اند.
برای دسترسی به یک متغیر نمونه‌ای باید یک متد نمونه‌ای تعریف کنید.
این متغیرها را می‌توان در متد `initialize` مقداردهی اولیه کرد.
آن‌ها با پیشوند `@` تعریف می‌شوند.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

متغیرهای نمونه‌ای را می‌توان داخل تعریف کلاس هم تعریف کرد.

```crystal
class Account
  @age = 0
end
```

### متغیرهای نمونه‌ای همراه با مقداردهی اولیه

متغیرهای نمونه‌ای را می‌توان با آرگومانی که به متد `initialize` پاس داده می‌شود مقداردهی اولیه کرد.
از آنجا که Crystal نمی‌تواند نوع آرگومان به‌کاررفته در مقداردهی اولیه را استنباط کند، باید آن را مشخص کنید.
اگر می‌خواهید بیشتر درباره‌ی این موضوع بخوانید، می‌توانید [type-inference][type-inference] را ببینید.
برای مشخص کردن نوع متغیر می‌توانید از نشانه‌ی `:` و پس از آن نوع استفاده کنید.
برای نمونه، اگر می‌خواهید متغیر نمونه‌ای به اسم `balance` از نوع `Int32` بسازید، می‌توانید این‌گونه بنویسید: `@balance : Int32`.
یا اگر می‌خواهید متغیر نمونه‌ای به اسم `raining` از نوع `Bool` بسازید، می‌توانید این‌گونه بنویسید: `@raining : Bool`.

چند راه برای پیاده‌سازی این کار وجود دارد. یکی اینکه در متد `initialize` آرگومان را همراه با نوعش اعلام کنید و بعد متغیر نمونه‌ای را به آرگومان نسبت دهید، مانند مثال زیر:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

راه دیگر این است که نوع متغیر نمونه‌ای را در تعریف کلاس به این شکل اعلام کنید: `@<variable> : <Type>`، مانند مثال زیر:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### روش کوتاه برای مقداردهی اولیه‌ی متغیرهای نمونه‌ای

روش کوتاهی برای مقداردهی اولیه‌ی متغیرهای نمونه‌ای در آرگومان‌های متد `initialize` وجود دارد که از همان نحوه‌ی نگارش `@<variable> : <Type>` استفاده می‌کند.
این روش، نسبت دادن متغیر نمونه‌ای به آرگومان و اعلام نوع متغیر نمونه‌ای را در یک جا ترکیب می‌کند.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## تغییر متغیرهای نمونه‌ای

متدها می‌توانند متغیرهای نمونه‌ای را تغییر دهند.
این متدها را می‌توان روی نمونه‌ی کلاس فراخوانی کرد.
وقتی متدی یک متغیر نمونه‌ای را تغییر می‌دهد، آن تغییر فقط در همان نمونه‌ای از کلاس که متد را روی آن فراخوانی کرده‌اید در دسترس است.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## متدهای کلاس

[متدهای کلاس][class-methods] متدهایی‌اند که برای یک کلاس تعریف می‌شوند، نه برای نمونه‌های آن.
آن‌ها راهی برای ساختن متدهایی فراهم می‌کنند که به وضعیت نمونه وابسته نیستند.
این متدها با کلیدواژه‌ی `def` و پس از آن `self.<method name>` تعریف می‌شوند.
`self` ارجاعی به فضای نامی است که از آن فراخوانی می‌شود.
در این مورد، به کلاس `Account` اشاره دارد.
همان نتیجه را می‌داد اگر `Account.` نوشته بودید، اما `self.` روش ترجیحی است.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
