# Tests

سیستم‌عامل کنونی خود را انتخاب کنید:

* [Windows](##windows)

* [Linux](##linux)

# اجرای تست‌ها

## Windows

1. یک پنجره‌ی Command Prompt باز کنید.

2. اولین تمرین را دریافت کنید:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. به پوشه‌ی تمرین بروید:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. تست‌ها را اجرا کنید:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(اگر تست‌ها را که بار اول اجرا می‌کنید شکست خوردند نگران نباشید، هر تمرین را همین‌طور شروع می‌کنید.)*

5. تمرین را حل کنید. 
    `instructions.md` را بخوانید و ببینید تمرین را چگونه حل کنید ([مشاهده در GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


موفق باشید، خوش بگذرد و به ترک COBOL خوش آمدید!

## macOS

1. یک پنجره‌ی Terminal باز کنید.

2. اولین تمرین را دریافت کنید:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. به پوشه‌ی تمرین بروید:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. تست‌ها را اجرا کنید:

    ```
     $ bash test.sh
    ```
    *(اگر تست‌ها را که بار اول اجرا می‌کنید شکست خوردند نگران نباشید، هر تمرین را همین‌طور شروع می‌کنید.)*

    نکته: اگر پیامی دریافت کردید که `basename` وجود ندارد، می‌توانید از [brew](https://brew.sh/) برای نصب coreutils استفاده کنید. (`brew install coreutils`)

5. تمرین را حل کنید. 

    `instructions.md` را بخوانید و ببینید تمرین را چگونه حل کنید ([مشاهده در GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


موفق باشید، خوش بگذرد و به ترک COBOL خوش آمدید!
