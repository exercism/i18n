# دستورالعمل‌ها

در این تمرین، برنامه‌ای می‌نویسید که به شما کمک می‌کند برای خرید خودرو آماده شوید.

دو کار پیش رو دارید: تعیین اینکه به گواهینامه نیاز دارید یا نه و تخمین قیمت قابل‌قبولی برای یک خودروی دست‌دوم.

## 1. تعیین کنید که آیا به گواهینامه نیاز دارید یا نه

برخی از انواع خودرو برای راندن به گواهینامه نیاز دارند.
فرض کنید فقط خودروهایی به گواهینامه نیاز دارند که `car` یا `truck` در نوع آن‌ها باشد؛ بقیه را می‌توان بدون گواهینامه راند.

یک جفت `pattern {action}` پیاده‌سازی کنید که وقتی فیلد اول `needs_license` است، تطبیق پیدا کند.
باید نوع خودرو را از فیلد دوم بگیرد و اگر برای آن نوع خودرو به گواهینامه نیاز دارید، «true» را چاپ کند.
اگر به گواهینامه نیاز ندارید، لازم نیست چیزی چاپ کنید.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. تخمین قیمت یک خودروی دست‌دوم

حالا که تصمیمتان را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایشگاه خودرو قیمت منصفانه‌ای می‌پردازید.
چون می‌خواهید خودروی دست‌دوم بخرید، قیمت به سن خودرو بستگی دارد.
برای یک تخمین سرانگشتی، فرض کنید اگر خودرو کمتر از ۳ سال عمر داشته باشد، ۸۰٪ قیمت اولیه‌اش را دارد.
اگر بیش از ۱۰ سال عمر داشته باشد، ۵۰٪.
اگر عمر خودرو دست‌کم ۳ سال باشد ولی از ۱۰ سال بیشتر نباشد، ۷۰٪ قیمت اولیه را دارد.

یک جفت `pattern {action}` پیاده‌سازی کنید که وقتی فیلد اول `resell_price` است، تطبیق پیدا کند.
باید قیمت اولیه‌ی خودرو را از فیلد دوم و عمر آن را از فیلد سوم بگیرد.
بخش `action` باید قیمت تخمینی را چاپ کند.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
