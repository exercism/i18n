# جانگهدار

## توابع زمان

این تمرین نیازمند استفاده از [توابع زمان][time-func] در GNU awk است.

برای توابع تجزیه و قالب‌بندی تاریخ و زمان، حتماً **پرچم UTC را تنظیم کنید**.
برای نمونه:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

خروجی:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
