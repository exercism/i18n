# ضمیمه‌ی دستورالعمل

## درباره‌ی `Enum`

دستور `enum` به شما این امکان را می‌دهد که مجموعه‌ای از برچسب‌ها را با نوع‌دهی قوی بسازید.
می‌توانید از آن نوع شمارشی در کد استفاده کنید، بدون این‌که لازم باشد آن را تجزیه کنید یا غلط املایی‌اش را بررسی کنید.

شمارشی‌ها در باطن به‌صورت اعداد صحیح نمایش داده می‌شوند و مقدار آغازین‌شان صفر است.
به‌طور پیش‌فرض، PowerShell به اولین برچسب در فهرست مقدار صفر را می‌دهد و به برچسب‌های باقی‌مانده اعداد صحیح متوالی را نسبت می‌دهد.

مثال:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

برای آشنایی بیشتر با `Enum` در PowerShell، نگاهی به [ماژول `Enum`.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum) بیندازید.
