# مقدمه

عبارات باقاعده در Elixir از مشخصات **PCRE** (عبارات باقاعده‌ی سازگار با Perl) پیروی می‌کنند، مشابه دیگر زبان‌های محبوبی مثل Java، JavaScript یا Ruby.

ماژول `Regex` توابعی برای کار با عبارات باقاعده ارائه می‌دهد. بعضی از توابع ماژول `String` هم عبارات باقاعده را به عنوان ورودی می‌پذیرند.

~~~~exercism/note
این تمرین فرض می‌کند که شما از قبل نحوه‌ی نگارش عبارات باقاعده را می‌دانید، از جمله کلاس‌های نویسه، کمیت‌سازها، گروه‌ها و گروه‌های ضبط‌شده.

اگر لازم است دانش خود را درباره‌ی عبارات باقاعده تازه کنید، یکی از این منابع را ببینید: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

## سیگیل

رایج‌ترین راه ساختن عبارات باقاعده، استفاده از «سیگیل» `~r` است.

```elixir
~r/test/
```

توجه کنید که همه‌ی سیگیل‌های Elixir از [انواع مختلف جداکننده][sigils] پشتیبانی می‌کنند، نه فقط `/`.

## تطبیق

از عملگر `=~/2` می‌توان برای انجام یک تطبیق باقاعده که نتیجه‌ای از نوع `boolean` بازمی‌گرداند استفاده کرد. از طرف دیگر، توابع `match?/2` هم در ماژول `Regex` و هم در ماژول `String` وجود دارند.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## ضبط گروه‌ها

اگر یک بررسی «منطقی» ساده کافی نیست، از تابع `Regex.run/3` استفاده کنید تا فهرستی از همه‌ی گروه‌های ضبط‌شده به دست آورید (یا `nil` اگر تطبیقی پیدا نشد). عنصر اول در فهرست بازگردانده‌شده همیشه تطبیق کل عبارت باقاعده است و عنصرهای بعدی گروه‌های تطبیق‌یافته هستند.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## تغییردهنده‌ها

رفتار یک عبارت باقاعده را می‌توان با افزودن پرچم‌های ویژه تغییر داد. وقتی از یک سیگیل برای ساختن عبارت باقاعده استفاده می‌کنید، تغییردهنده‌ها را بعد از جداکننده‌ی دوم اضافه کنید.

تغییردهنده‌های رایج عبارت‌اند از:
- `i` - تطبیق را نسبت به بزرگی و کوچکی حروف بی‌تفاوت می‌کند.
- `u` - الگوهای مخصوص Unicode مثل `\p` را فعال می‌کند و باعث می‌شود کلاس‌های نویسه مثل `\w`، `\s` و غیره هم با Unicode تطبیق پیدا کنند.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
