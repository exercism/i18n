## استفاده از عبارت‌های `use`

در Gleam معمول است که «توابع مرتبه‌ی بالاتر» بنویسیم و به کار ببریم؛ یعنی توابعی که توابع دیگر را به‌عنوان آرگومان می‌گیرند. گاهی وقتی چند تابع مرتبه‌ی بالاتر را همزمان به کار می‌بریم، کد خواندنش دشوار می‌شود، چون لایه‌های تودرتوی تورفتگی زیاد می‌شود.

برای مثال، اینجا تابعی را می‌بینیم که چندین تابع را فراخوانی می‌کند که مقدار `Result(Int, Nil)` برمی‌گردانند، و اگر هر چهار تابع موفق باشند، مقادیر را با هم جمع می‌کند.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

عبارت‌های `use` در Gleam به ما اجازه می‌دهند این کد را بدون تورفتگی بنویسیم، که اغلب خواندنش را آسان‌تر می‌کند.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

عبارت `use` همه‌ی دستورهای بعدی بلوک را جمع می‌کند و آن‌ها را به شکل یک تابع callback، به‌عنوان آخرین آرگومان، به فراخوانی تابع می‌فرستد. متغیرهای میان کلیدواژه‌ی `use` و نماد `<-` اسم آرگومان‌هایی هستند که به تابع callback فرستاده می‌شوند.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

تابع callback می‌تواند هر تعداد آرگومان بگیرد، یا هیچ آرگومانی نگیرد.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

برای ساختن تابعی که بتوان آن را با یک عبارت `use` فراخوانی کرد، هیچ شرط خاصی وجود ندارد، جز اینکه یک تابع callback را به‌عنوان آخرین آرگومان بگیرد.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

عبارت‌های `use` در Gleam قابلیت بسیار قدرتمندی هستند که می‌توان آن‌ها را برای مسائل زیادی به کار برد، اما اگر بیش از حد استفاده شوند، می‌توانند خواندن کد را دشوار کنند. به‌طور کلی بهتر است از نحوه‌ی نگارش معمول فراخوانی تابع استفاده کنید و فقط وقتی سراغ عبارت‌های `use` بروید که خواندن کد را آسان‌تر می‌کنند.
