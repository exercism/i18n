# درباره

نوع «منطقی» در Lua دو مقدار منطقی سنتی دارد: `true` و `false`. این مقادیر را می‌توان به یک متغیر نسبت داد، با عملگرهای منطقی (`and`، `or`، `not`) ترکیب کرد و در آزمون‌های شرطی (مثلاً در ساختارهای کنترلی) به کار برد.

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

آزمون‌های شرطی و عملگرهای منطقی، هم مقدار منطقی `false` و هم `nil` را «غلط» و هر مقدار دیگری را «درست» در نظر می‌گیرند.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

هر دو عملگر `and` و `or` از *ارزیابی اتصال‌کوتاه* استفاده می‌کنند، به این معنا که عملوند دوم خود را فقط در صورت لزوم ارزیابی می‌کنند. همه‌ی عملیات بر اساس [اولویت عملگرها](https://www.lua.org/manual/5.4/manual.html#3.4.8) ارزیابی می‌شوند، که در آن `not` پیش از `and` و `or` ارزیابی می‌شود.

از آنجا که تنها `false` و `nil` «غلط» در نظر گرفته می‌شوند و هر مقدار دیگری «درست» است، یک اصطلاح رایج در Lua این است:
```lua
x = x or y
```

این معادل این است:
```lua
if not x then
  x = y
end
```

استفاده از این الگو در توابع بسیار رایج است: اگر پارامتری مقداری نداشته باشد (`nil` باشد)، یک مقدار پیش‌فرض به آن نسبت داده می‌شود.
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
