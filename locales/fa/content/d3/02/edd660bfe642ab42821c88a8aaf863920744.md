# مقدمه

متدها می‌توانند یک پارامتر متغیر داشته باشند که به فراخوان اجازه می‌دهد صفر یا چند آرگومان را مانند پارامترهای عادی مشخص کند. متد این آرگومان‌ها را در یک آرایه دریافت می‌کند.

برای اینکه یک پارامتر را به پارامتر متغیر تبدیل کنید، «کلیدواژه‌ی `params` را به اعلان پارامتر اضافه کنید:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
