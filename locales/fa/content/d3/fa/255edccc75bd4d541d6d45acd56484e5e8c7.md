# نصب

## ویندوز (توصیه‌شده)

آیا از سیستم‌عامل ویندوز استفاده می‌کنید؟

کلید `Windows Key` را فشار دهید، `cmd` را تایپ کنید و `enter` را فشار دهید.

> اگر سیستم‌عامل شما ویندوز است، Batch از قبل روی سیستم شما نصب شده است.

اگر از سیستم‌عامل دیگری استفاده می‌کنید، می‌توانید Batch را با پیروی از دستورهای زیر نصب کنید.

## Mac OS

1. نباید Gatekeeper طوری تنظیم شده باشد که بسته‌های امضانشده را مسدود کند.
2. برنامه‌ی Terminal را باز کنید.
3. برای نصب Batch، دستور زیر را اجرا کنید:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. اگر سیستم شما ۶۴ بیتی است، معماری ۳۲ بیتی را فعال کنید (اگر تا کنون این کار را نکرده‌اید):

```bash
sudo dpkg --add-architecture i386
```

2. مخزن WineHQ را اضافه کنید:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. WineHQ را نصب کنید:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. مخزن Wine را فعال کنید:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. WineHQ را نصب کنید:

```bash
dnf install winehq-stable
```
