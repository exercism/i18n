# دستورالعمل‌ها

در حال آماده شدن برای پختن کلوچه برای دوستانتان، متوجه شده‌اید که باید بعضی از اندازه‌های به‌کاررفته در دستور پخت را تبدیل کنید. چون تنها با سیستم متریک آشنایید، باید راهی پیدا کنید تا اندازه‌های رایج آشپزی آمریکایی را برای راحتی خودتان به میلی‌لیتر (mL) تبدیل کنید.

برای حل خود از این جدول تبدیل استفاده کنید:

| واحد برای تبدیل | حجم | بر حسب میلی‌لیتر (mL) |
| --------------- | ------ | ------------------- |
| میلی‌لیتر | ۱ | ۱ |
| پیمانه‌ی آمریکایی | ۱ | ۲۴۰ |
| اونس مایع آمریکایی | ۱ | ۳۰ |
| قاشق چای‌خوری آمریکایی | ۱ | ۵ |
| قاشق غذاخوری آمریکایی | ۱ | ۱۵ |

چون برنامه‌نویسی مستعد و در حال آموزش هستید، تصمیم می‌گیرید میلی‌لیتر را به عنوان واحد واسط به کار ببرید تا تبدیل از هر واحد فهرست‌شده به واحد دیگر (حتی به خودش) آسان‌تر شود.

## 1. گرفتن جزء عددی از یک جفت حجم

تابع `KitchenCalculator.get_volume/1` را پیاده‌سازی کنید. این تابع با گرفتن یک تاپل جفت حجم، فقط جزء عددی را برمی‌گرداند.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. تبدیل جفت حجم به میلی‌لیتر

تابع `KitchenCalculator.to_milliliter/1` را پیاده‌سازی کنید. این تابع با گرفتن یک تاپل جفت حجم، حجم را با استفاده از جدول تبدیل به میلی‌لیتر تبدیل می‌کند.

برای ساختن تابع هر واحد، از چند بند تابع و تطبیق الگو استفاده کنید. اتم‌هایی که هر واحد را نشان می‌دهند عبارت‌اند از: `:cup`، `:fluid_ounce`، `:teaspoon`، `:tablespoon`، `:milliliter`. نتیجه‌ی تبدیل را داخل یک تاپل برگردانید.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. تبدیل جفت حجم میلی‌لیتری به واحد دیگر

تابع `KitchenCalculator.from_milliliter/2` را پیاده‌سازی کنید. این تابع با گرفتن یک تاپل جفت حجم و واحد دلخواه، حجم را با استفاده از جدول تبدیل به واحد دلخواه تبدیل می‌کند.

برای ساختن تابع هر واحد، از چند بند تابع و تطبیق الگو استفاده کنید. اتم‌هایی که هر واحد را نشان می‌دهند عبارت‌اند از: `:cup`، `:fluid_ounce`، `:teaspoon`، `:tablespoon`، `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. تبدیل از هر واحد به هر واحد

تابع `KitchenCalculator.convert/2` را پیاده‌سازی کنید. این تابع با گرفتن یک تاپل جفت حجم و واحد دلخواه، حجم داده‌شده را به واحد دلخواه تبدیل می‌کند.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
