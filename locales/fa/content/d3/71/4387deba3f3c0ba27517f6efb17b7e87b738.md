# مقدمه

Pyret دو مقدار پایه‌ی «منطقی» دارد که کاملاً از هم متمایزند: `true` و `false`.
این دو مقدار نشان می‌دهند که یک دستور یا شرط معتبر است یا نه.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret عملگرهای `and` و `or` را ارائه می‌دهد که می‌توانند مقادیر منطقی را با هم ترکیب کنند.

عملگر and اگر هر دو طرف «درست» باشند، «درست» را برمی‌گرداند و در همه‌ی ترکیب‌های دیگر «غلط».

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

عملگر or اگر دست‌کم یک طرف «درست» باشد، «درست» را برمی‌گرداند و تنها وقتی «غلط» است که هر دو طرف «غلط» باشند.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` یک تابع داخلی است که «درست» را به «غلط» و «غلط» را به «درست» تبدیل می‌کند.

```pyret
not(true) # false
not(false) # true
```
