# مقدمه

## Maybe

نوع `Maybe` راه‌حل زبان Elm برای مقادیر اختیاری است. بنابراین در امضای نوع بسیاری از توابع اصلی Elm دیده می‌شود و درک آن اهمیت زیادی دارد. نوع `Maybe` به شکل زیر تعریف شده است:

```elm
type Maybe a = Nothing | Just a
```

در اصطلاحات Elm، به این کار تعریف «نوع سفارشی» می‌گویند. این تعریف نشان می‌دهد که مقدارِ این نوع یا `Nothing` است یا `Just` یک مقدار از نوع `a`. ساختن یک مقدار `Maybe` با یکی از دو سازنده‌ی آن، `Nothing` و `Just`، انجام می‌شود. خواندن محتوای یک `Maybe` هم با تطبیق الگو انجام می‌شود.

```elm
matthieu : Maybe String
matthieu = Just "Matthieu"

anon : Maybe String
anon = Nothing

sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello matthieu
    --> "Hello, Matthieu!"

sayHello anon
    --> "Hello, World!"
```

همچنین چندین تابع مفید در ماژول `Maybe` وجود دارد که برای کار با نوع `Maybe` به کار می‌روند.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
