# درباره

ColdFusion (CFML) یک زبان اسکریپتی روی JVM است که نحوه‌ی نگارش آن شبیه C یا JavaScript است.
این زبان به‌صورت JIT به بایت‌کد کامپایل می‌شود که روی JVM اجرا می‌شود، اما پویا است و نوع‌بندی آزادی دارد؛ همین آن را سریع و آسان برای توسعه می‌کند.
CF زبانی چندپارادایمی است که از برنامه‌نویسی شیءگرای کلاسیک و برنامه‌نویسی تابعی پشتیبانی می‌کند.

CFML همچنین یک زبان قالب‌بندی مبتنی بر تگ دارد که درون خودش تعبیه شده و آن را برای اپلیکیشن‌های وب ایده‌آل می‌کند.
این زبان در یک کانتینر J2EE اجرا می‌شود و کتابخانه‌های همراه زیادی دارد که بهره‌وری را بالا می‌برند، بدون اینکه نیازی به نصب بسته‌های متعدد باشد.
CFML از فایل‌های zip، تولید PDF و Excel، ایمیل‌ها، FTP، HTTP، فایل‌سیستم‌های S3، کتابخانه‌های امنیتی ESAPI، درایورهای JDBC و APIهای JSON و REST به‌صورت بومی پشتیبانی می‌کند.

CFML همچنین می‌تواند از هر پروژه‌ی Java بهره ببرد؛ کافی است فایل‌های jar را در پروژه قرار دهید و مستقیماً اشیای Java را در کد خود نمونه‌سازی کنید.
می‌توانید درباره‌ی نحوه‌ی نگارش پایه و انواع داده‌ی درجه‌یک در این راهنما بیشتر یاد بگیرید: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
