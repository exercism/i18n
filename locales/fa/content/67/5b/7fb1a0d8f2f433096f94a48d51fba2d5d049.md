# Debug

YS یک تابع `DBG` داخلی دارد که می‌تواند برای Debug کردن کد راه‌حل شما مفید باشد.
این تابع هر تعداد آرگومان می‌گیرد و آن‌ها را روی stderr در کنسول چاپ می‌کند.
آخرین آرگومان را برمی‌گرداند، بنابراین می‌توانید آن را به‌صورت درون‌خطی در کد خودتان به کار ببرید.


می‌توانید از عملگر درون‌خطی `.>` استفاده کنید که میان‌بری برای `.DBG()` است.

این یک نمونه فایل کد است:

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

وقتی این کد را با `ys` اجرا کنید، خروجی زیر را می‌بینید:

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## کامپایل

راه رایج دیگری برای پی بردن به مشکل این است که کد Clojure را ببینید که کد YS شما به آن کامپایل می‌شود.

می‌توانید این کار را با اجرای مفسر خط فرمان `ys` همراه با گزینه‌ی `-c` انجام دهید.

فایل `program.ys` بالا وقتی کامپایل می‌شود چنین شکلی دارد:

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

به‌خوبی می‌بینید که عملگر `.>` چگونه به فراخوانی تابع `DBG` کامپایل شده است.
