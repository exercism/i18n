# چگونه از Markdown در منتورینگ استفاده کنیم

شما می‌توانید در کامنت‌های منتورینگ خود در GitHub از Markdown استفاده کنید.
این کار به شما امکان می‌دهد که قطعه‌کدها را جاسازی کنید، سرتیتر اضافه کنید، از متن پررنگ، ایتالیک، فهرست و غیره استفاده کنید و جمله‌های قبلی را نقل‌قول کنید.

ما همچنین در Exercism برخی از عناصر «Markdown با طعم GitHub» را مجاز می‌دانیم، به‌ویژه برجسته‌سازی نحوه‌ی نگارش، جدول‌ها و خط‌خورده.

اگر با Markdown یا قابلیت‌های اضافه‌ی GitHub آشنا نیستید، خواندن [راهنمای Markdown در GitHub](https://guides.github.com/features/mastering-markdown/) را توصیه می‌کنیم.
