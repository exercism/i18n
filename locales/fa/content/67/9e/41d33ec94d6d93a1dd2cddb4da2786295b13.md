# درباره

در Haxe می‌توان یک سلسله‌مراتب کلاس را با استفاده از _وراثت_ تعریف کرد؛ وراثت به کلاس مشتق (`Car`) اجازه می‌دهد تا رفتار و داده‌ی کلاس والد خود (`Vehicle`) را به ارث ببرد.

در کلاس والد می‌توانید این موارد را تعریف کنید:

- متدهایی که می‌توان بازنویسی کرد
- متدهای انتزاعی که کلاس‌های مشتق باید پیاده‌سازی کنند

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

اگر کلاس والد سازنده داشته باشد، از `super()` استفاده می‌کنیم تا آن را فراخوانی کنیم:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
