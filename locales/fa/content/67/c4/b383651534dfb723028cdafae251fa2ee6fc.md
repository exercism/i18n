# دستورالعمل‌ها

مبانی «جدول‌های داخلی» ABAP را یاد بگیرید.

کلاس شما یک جدول داخلی به اسم `initial_data` دارد. این جدول سه ستون دارد: `GROUP`، `NUMBER` و `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## گام ۱

اولین کارتان این است که متد `fill_itab` را کامل کنید و ۶ رکورد را با مقادیر زیر در این جدول قرار دهید:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## گام ۲

سپس متد `add_to_itab` را پیاده‌سازی کنید تا رکوردی را با مقدار زیر به انتهای جدول داخلی اضافه کنید:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## گام ۳

حالا لطفاً جدول داخلی را در متد `sort_itab` طوری مرتب کنید که ستون `GROUP` به ترتیب الفبایی و ستون `NUMBER` به ترتیب نزولی باشد.

## گام ۴

در متد `search_itab`، جدول مرتب‌شده را جست‌وجو کنید و اندیس رکوردی را برگردانید که مقدار ستون `NUMBER` آن 6 است.
