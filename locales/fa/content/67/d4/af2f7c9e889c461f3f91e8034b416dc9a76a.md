# مقدمه

بسیاری از انواع اعضای `struct` و `class` (که فیلدها استثنای اصلی آن هستند) می‌توانند از نحوه‌ی نگارش «عضو بدنه‌عبارتی» استفاده کنند. تعریف یک عضو با یک عبارت، اغلب کدی فشرده‌تر و خواناتر از بلوک‌ها و دستورهای سنتی به دست می‌دهد.

متدها و ویژگی‌های فقط‌خواندنی از جمله اعضایی هستند که می‌توان آن‌ها را با بدنه‌ی عبارتی تعریف کرد.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
