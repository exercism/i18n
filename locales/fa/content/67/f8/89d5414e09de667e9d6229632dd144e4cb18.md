# درباره

[توابع دودویی بیتی][bitwise-wiki] را می‌توان روی اعداد صحیح با توابع [ماژول `Bitwise`][bitwise-hexdocs] انجام داد.

- [`band/2`][bitwise-and]: AND بیتی
- [`bsl/2`][bitwise-shift-left]: SHIFT LEFT بیتی
- [`bsr/2`][bitwise-shift-right]: SHIFT RIGHT بیتی
- [`bxor/2`][bitwise-xor]: XOR بیتی
- [`bor/2`][bitwise-or]: OR بیتی
- [`bnot/1`][bitwise-not]: NOT بیتی

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
