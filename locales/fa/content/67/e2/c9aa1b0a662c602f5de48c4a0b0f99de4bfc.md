# مقدمه

نوع `rune` در Go نام دیگری برای `int32` است.
با توجه به این نوع `int32` زیربنایی، نوع `rune` یک مقدار صحیح ۳۲ بیتی علامت‌دار را نگه می‌دارد.
با این حال، برخلاف نوع `int32`، مقدار صحیح ذخیره‌شده در نوع `rune` یک کاراکتر یونیکد را نمایش می‌دهد.

## یونیکد و نقاط کد یونیکد

یونیکد یک ابرمجموعه از ASCII است که کاراکترها را با اختصاص یک عدد یکتا به هر کاراکتر نمایش می‌دهد.
به این عدد یکتا، نقطه‌ی کد یونیکد می‌گویند.
یونیکد هدف دارد که همه‌ی کاراکترهای جهان، شامل الفباهای مختلف، اعداد، نمادها و حتی ایموجی‌ها را به صورت نقاط کد یونیکد نمایش دهد.

در Go، نوع `rune` یک نقطه‌ی کد یونیکد را نمایش می‌دهد.

جدول زیر شامل کاراکترهای یونیکد نمونه به همراه نقطه‌ی کد یونیکد و مقادیر اعشاری آن‌هاست:

| کاراکتر یونیکد | نقطه‌ی کد یونیکد | مقدار اعشاری |
|-------------------|--------------------|---------------|
| 0                 | `U+0030`           | `48`          |
| A                 | `U+0041`           | `65`          |
| a                 | `U+0061`           | `97`          |
| ¿                 | `U+00BF`           | `191`         |
| π                 | `U+03C0`           | `960`         |
| 🧠                | `U+1F9E0`          | `129504`      |

## UTF-8

UTF-8 یک کدبندی کاراکتر با عرض متغیر است که برای کدبندی هر نقطه‌ی کد یونیکد به صورت ۱، ۲، ۳ یا ۴ بایت استفاده می‌شود.
از آنجایی که یک نقطه‌ی کد یونیکد می‌تواند حداکثر به ۴ بایت کدبندی شود، نوع `rune` باید بتواند تا ۴ بایت داده را نگه دارد.
به همین دلیل است که نوع `rune` نام دیگری برای `int32` است، زیرا نوع `int32` قادر است تا ۴ بایت داده را نگه دارد.

فایل‌های کد منبع Go با UTF-8 کدبندی می‌شوند.

## استفاده از runeها

متغیرهای از نوع `rune` با قرار دادن یک کاراکتر داخل تک‌کوتیشن اعلان می‌شوند:

```go
myRune := '¿'
```

از آنجایی که `rune` فقط نام دیگری برای `int32` است، چاپ نوع یک `rune` منجر به `int32` می‌شود:

```go
myRune := '¿'
fmt.Printf("myRune type: %T\n", myRune)
// Output: myRune type: int32
```

به طور مشابه، چاپ مقدار یک `rune` مقدار صحیح (اعشاری) آن را نشان می‌دهد:

```go
myRune := '¿'
fmt.Printf("myRune value: %v\n", myRune)
// Output: myRune value: 191
```

برای چاپ کاراکتر یونیکد نمایش‌داده‌شده توسط `rune`، از مشخص‌کننده‌ی قالب‌بندی `%c` استفاده کنید:

```go
myRune := '¿'
fmt.Printf("myRune Unicode character: %c\n", myRune)
// Output: myRune Unicode character: ¿
```

برای چاپ نقطه‌ی کد یونیکد نمایش‌داده‌شده توسط `rune`، از مشخص‌کننده‌ی قالب‌بندی `%U` استفاده کنید:

```go
myRune := '¿'
fmt.Printf("myRune Unicode code point: %U\n", myRune)
// Output: myRune Unicode code point: U+00BF
```

## runeها و رشته‌ها

رشته‌ها در Go با UTF-8 کدبندی می‌شوند، که به این معنی است که شامل کاراکترهای یونیکد هستند.
کاراکترها در رشته‌ها به صورت ۱، ۲، ۳ یا ۴ بایت ذخیره و کدبندی می‌شوند، بسته به کاراکتر یونیکدی که نمایش می‌دهند.

در Go، از اسلایس‌ها برای نمایش دنباله‌ها استفاده می‌شود و این اسلایس‌ها را می‌توان با استفاده از `range` پیمایش کرد.
وقتی روی یک رشته پیمایش می‌کنیم، Go رشته را به مجموعه‌ای از runeها تبدیل می‌کند که هر کدام ۴ بایت است (به یاد داشته باشید، نوع `rune` نام دیگری برای `int32` است!)

حتی اگر یک رشته فقط یک اسلایس از بایت باشد، کلیدواژه‌ی `range` روی runeهای رشته پیمایش می‌کند، نه بایت‌های آن.

در این مثال، متغیر `index` نشان‌دهنده‌ی اندیس شروع دنباله‌ی بایتی `rune` فعلی است و متغیر `char` نشان‌دهنده‌ی `rune` فعلی است:

```go
myString := "❗hello"
for index, char := range myString {
  fmt.Printf("Index: %d\tCharacter: %c\t\tCode Point: %U\n", index, char, char)
}
// Output:
// Index: 0	Character: ❗		Code Point: U+2757
// Index: 3	Character: h		Code Point: U+0068
// Index: 4	Character: e		Code Point: U+0065
// Index: 5	Character: l		Code Point: U+006C
// Index: 6	Character: l		Code Point: U+006C
// Index: 7	Character: o		Code Point: U+006F
```

از آنجایی که runeها می‌توانند به صورت ۱، ۲، ۳ یا ۴ بایت ذخیره شوند، طول یک رشته ممکن است همیشه با تعداد کاراکترهای آن برابر نباشد.
از تابع توکار `len` برای گرفتن طول یک رشته بر حسب بایت و از تابع `utf8.RuneCountInString` برای گرفتن تعداد runeهای یک رشته استفاده کنید:

```go
import "unicode/utf8"

myString := "❗hello"
stringLength := len(myString)
numberOfRunes := utf8.RuneCountInString(myString)

fmt.Printf("myString - Length: %d - Runes: %d\n", stringLength, numberOfRunes)
// Output: myString - Length: 8 - Runes: 6
```
