# درباره

Elm یک زبان کاملاً تابعی است، پس در آن دستوری وجود ندارد و همه‌چیز عبارت است؛ توابع همیشه یک عبارت واحد هستند.

این کار توابع کوچک و ساده را تشویق می‌کند و در کل خوب است، اما گاهی توابع ناگزیر پیچیده‌تر می‌شوند و به راهی نیاز داریم تا مطمئن شویم این توابع می‌توانند به شکلی زیبا نوشته شوند.

اینجاست که عبارت‌های `let` به کار می‌آیند. هرکدام دو بخش دارند: بخش `let` که در آن می‌توانید هر تعداد تعریف که لازم دارید بسازید، و سپس بخش `in` که یک عبارت واحد است و می‌تواند از این تعریف‌ها استفاده کند.

در اصطلاح رایانش، `let` یک «دامنه» ایجاد می‌کند که محدود به عبارتِ درون `in` است.

عبارت `let` در چند موقعیت به کار می‌آید:

- برای ساده کردن عبارت‌ها
- برای اسم‌گذاری روی نتیجه‌ی عبارت‌های میانی
- برای تقسیم یک عبارت به بخش‌های کوچک‌تر وقتی بزرگ می‌شود

درون یک عبارت `let` می‌توانید بیشتر کارها را انجام دهید، از جمله «تجزیه»، اما موارد زیر مجاز نیستند:

- Custom Types
- Type Alias'
- «سایه‌اندازی اسم» (نمی‌توانید اسمی را که از قبل در دامنه هست دوباره تعریف کنید یا دوباره به کار ببرید)

## ساده کردن عبارت‌ها

این عبارت مکعبِ ۳ عدد را با هم جمع می‌کند، اما خواندنش سخت است و به‌راحتی ممکن است محاسبه برای عددهای مختلف متفاوت شود.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

می‌توانیم یک تابع `cube` را درون یک عبارت `let` تعریف کنیم تا محاسبه ساده‌تر، گویاتر و ایمن‌تر شود. این تابع می‌توانست یک «حاشیه‌نویسی نوع» داشته باشد، اما در کد اصطلاحی Elm این کار نسبتاً نادر است.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## اسم‌گذاری روی نتیجه‌ی عبارت‌های میانی

این کد `sideArea` و `topArea` را تعریف می‌کند تا محاسبه ساده‌تر و گویاتر شود.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## تقسیم یک عبارت بزرگ

این کد یک الگوی اولیه برای [Game of Life](https://playgameoflife.com/) می‌سازد (یک تمرین نمونه‌ی رایج در برنامه‌نویسی).

درک دقیق نحوه‌ی کارش مهم نیست، اما امیدواریم واضح باشد که اگر به‌صورت یک عبارت واحد و بدون `let` نوشته می‌شد، بسیار بزرگ می‌شد.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
