# ثابت سطح بالا را ترجیح دهید

بهتر است عدد `GIGASECOND` را بیرون بکشید و آن را در قالب یک ثابت بنویسید:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

تنها توابع، کلاس‌ها و ثابت‌هایی که `export` شده‌اند، از بیرون قابل دیدن و دسترسی هستند. معمولاً منطقی است که به [اعداد جادویی](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29) یک اسم بدهیم، چون این کار نگهداری کد را آسان‌تر می‌کند. این ثابت‌ها می‌توانند در همان فایل قرار بگیرند، بدون اینکه در برابر کدهای دیگر آشکار شوند.
