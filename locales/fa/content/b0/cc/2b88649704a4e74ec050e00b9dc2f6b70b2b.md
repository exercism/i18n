# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات    | کاربرد      | نوع      | توضیح                                  |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | ورودی        | آدرس    | رشته‌ی سؤال پایان‌یافته با null        |
| `$v0`    | خروجی        | عدد صحیح | نتیجه، اگر سؤال معتبر نباشد ۰          |
| `$t0-9`  | موقت         | هر مقداری | برای ذخیره‌سازی موقت                   |
