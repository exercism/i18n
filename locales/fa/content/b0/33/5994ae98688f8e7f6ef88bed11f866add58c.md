# درباره

هر نمونه از یک ساختار یا کلاس، یک ویژگی ضمنی به اسم `self` دارد که به خود نمونه اشاره می‌کند.
رایج‌ترین کاربرد `self` رفع ابهام میان یک ویژگی نمونه و پارامتری است که اسم یکسانی با آن دارد:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

در Swift، کلیدواژه‌ای با حرف بزرگ به اسم `Self` هم وجود دارد که به *نوع* نمونه اشاره می‌کند، نه به خود نمونه.
