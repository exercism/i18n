# مقدمه

## حلقه‌ی while

با یک «حلقه‌ی while» می‌توانید تا زمانی که شرط خاصی برقرار باشد، کد را به‌صورت تکراری اجرا کنید.
این حلقه با «کلیدواژه»ی `while` نوشته می‌شود که پس از آن، شرطی داخل پرانتز و یک «بلوک کد» قرار می‌گیرد که «بدنه»ی حلقه را درون آکولاد در بر دارد.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript یک حلقه‌ی do-while هم دارد.
در این حلقه، شرط پس از اجرای بدنه‌ی حلقه بررسی می‌شود.
این موضوع زمانی مفید است که شرط به ارزیابی‌هایی وابسته باشد که در بدنه انجام می‌شود.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

درون بدنه‌ی حلقه، می‌توانید از کلیدواژه‌ی `break` برای توقف کامل اجرای حلقه استفاده کنید.
در مقابل، کلیدواژه‌ی `continue` فقط اجرای تکرار جاری را متوقف می‌کند و با تکرار بعدی ادامه می‌دهد.
با `continue` می‌توانید اغلب از قرار دادن بخش‌های زیادی از بدنه‌ی حلقه درون یک دستور شرطی اجتناب کنید.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## دستور switch

JavaScript علاوه بر دستور شرطی، یک دستور switch هم دارد تا منطق را به‌صورت شرطی اجرا کند.
از این دستور زمانی استفاده می‌شود که یک متغیر واحد باید با چند حالت مختلف مقایسه شود.
مقایسه با بررسی «برابری اکید» (`===`) انجام می‌شود؛ به [مفهوم مقایسه][concept-comparison] نگاه کنید.
برای متغیری مانند `x`، دستور switch در JavaScript «نحوه‌ی نگارش» زیر را دارد.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

حالت `default` اختیاری است و زمانی به کار می‌رود که بخواهید در صورتی که هیچ‌یک از گزینه‌های دیگر با متغیر مطابقت نداشت، کدی را اجرا کنید.

دستورهای `break` بالا لازم هستند، چون در JavaScript به‌طور پیش‌فرض همه‌ی حالت‌ها «ریزش» دارند.
یعنی بدون هیچ دستور `break`، همه‌ی کدی که در حالت‌های پایین‌تر از اولین گزینه‌ی منطبق قرار دارد اجرا می‌شود، حتی اگر `x` با آن حالت‌ها مطابقت نداشته باشد.
این رفتار «ریزش پیش‌فرض» دامی رایج هنگام استفاده از `switch` در JavaScript است.
درون یک تابع، می‌توان به جای `break` از `return` هم استفاده کرد تا از این مشکل جلوگیری شود.
