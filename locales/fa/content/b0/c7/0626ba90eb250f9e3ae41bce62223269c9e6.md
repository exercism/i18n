# دستورالعمل‌ها

تابعی را با استفاده از منطق گزاره‌ای پیاده‌سازی کنید تا ویژگی‌های زیر را بازسازی کند:

1. `A & B == (A' | B')'` (قانون دمورگان)
2. `[A -> (A -> B)] -> (A -> B)`
3. `A & (B' -> A') -> B`

تابع باید سه قضیه را که با نمادگذاری Z3 نوشته شده‌اند برگرداند.  
از تابع `prove()` برای تأیید درستی قضیه‌هایتان استفاده کنید.  
سه قضیه را به ترتیب، در پایان تابع برگردانید.
