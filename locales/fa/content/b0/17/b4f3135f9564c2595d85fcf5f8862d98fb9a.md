# درباره

Go دارای نوع‌های عددی پایه‌ای است که می‌توانند مجموعه‌هایی از مقادیر صحیح یا اعشاری را نمایش دهند.
بسته به اندازه‌ی مقداری که لازم دارید و معماری رایانه‌ای که برنامه روی آن اجرا می‌شود (مثلاً ۳۲بیتی و ۶۴بیتی)، نوع‌های متفاوتی وجود دارد.

این مفهوم بر دو نوع عدد تمرکز می‌کند:

- `int`: برای مثال `0`، `255`، `2147483647`.
   یک عدد صحیح علامت‌دار که حداقل ۳۲ بیت اندازه دارد (بازه‌ی مقدار: از -۲۱۴۷۴۸۳۶۴۸ تا ۲۱۴۷۴۸۳۶۴۷).
   اما این به معماری سیستم بستگی دارد.
   بیشتر رایانه‌های امروزی ۶۴بیتی هستند، بنابراین `int` اندازه‌ی ۶۴ بیت خواهد داشت (بازه‌ی مقدار: از -۹۲۲۳۳۷۲۰۳۶۸۵۴۷۷۵۸۰۸ تا ۹۲۲۳۳۷۲۰۳۶۸۵۴۷۷۵۸۰۷).

- `float64`: برای مثال `0.0`، `3.14`.
   شامل مجموعه‌ی همه‌ی اعداد اعشاری ۶۴بیتی است.

برای فهرست کامل نوع‌های عددی موجود و جزئیات بیشتر، منابع زیر را ببینید:

- [اعلان‌های نوع درون‌ساخت Go][go-builtins]
- [Digital Ocean - درک انواع داده در Go][do-understanding-types]
- [Arden Labs - درک نوع در Go][arden-understanding-types]

Go از مجموعه‌ی استاندارد عملگرهای حسابی `+`، `-`، `*`، `/` و `%` پشتیبانی می‌کند (باقی‌مانده، نه به‌پیمانه).

در Go، نسبت دادن یک مقدار میان نوع‌های متفاوت به تبدیل صریح نیاز دارد.
برای مثال، برای تبدیل یک `int` به `float64` باید به این شکل عمل کنید:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
