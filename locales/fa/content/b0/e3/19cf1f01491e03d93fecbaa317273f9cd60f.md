# راهنماها

## عمومی

- [درج رشته][string-interpolation]: آموزشی درباره‌ی نحوه‌ی استفاده از درج رشته.
- [انواع قالب‌بندی][formatting-types]: انواع قالب‌بندی در دسترس برای استفاده.
- [رشته‌های قالبی استاندارد عددی][standard-numeric-format-strings]: رشته‌های قالبی استاندارد عددی را فهرست می‌کند.
- [رشته‌های قالبی سفارشی عددی][custom-numeric-format-strings]: نحوه‌ی تعریف رشته‌های قالبی سفارشی عددی را توضیح می‌دهد.
- [رشته‌های قالبی استاندارد تاریخ و زمان][standard-date-and-time-format-strings]: رشته‌های قالبی استاندارد تاریخ و زمان را فهرست می‌کند.
- [رشته‌های قالبی سفارشی تاریخ و زمان][custom-date-and-time-format-strings]: نحوه‌ی تعریف رشته‌های قالبی سفارشی تاریخ و زمان را توضیح می‌دهد.
- [`String.Format()`][string-format]: API کتابخانه.

## 1. نمایش اسم زوج که با یک قلب از هم جدا شده است

- نگاهی به بحث [درج رشته][string-interpolation] بیندازید.

## 2. نمایش حروف اول اسم زوج درون یک قلب به سبک هنر ASCII

- این [مقاله][verbatim-strings] درباره‌ی رشته‌های متنی تحت‌اللفظی بحث می‌کند.
- این [سند][string-format] درباره‌ی `String.Format()` بحث می‌کند.

## 3. دانش‌آموزان تبادلی آلمانی باید با اعلان‌های حساس به زبان و منطقه احساس راحتی کنند.

- برای کار با رشته‌های درج‌شده، مستندات [`FormattableString`][formattable-string] را ببینید. شاید برای شروع بهتر باشد از [قالب‌بندی ترکیبی][composite-formatting] استفاده کنید.
- باید با [`CultureInfo`][culture-info] کار کنید. توجه کنید که این رابط [`IFormatProvider`][format-provider] را پیاده‌سازی می‌کند.
