# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به شما کمک می‌کند برای خرید یک وسیله‌ی نقلیه آماده شوید.

سه کار پیش رو دارید: تعیین اینکه به گواهینامه‌ی رانندگی نیاز دارید یا نه، کمک به انتخاب میان دو وسیله‌ی نقلیه و تخمین قیمت مناسب برای یک وسیله‌ی نقلیه‌ی دست‌دوم.

## 1. تعیین کنید که به گواهینامه‌ی رانندگی نیاز دارید یا نه

برخی از انواع وسایل نقلیه برای راندنشان به گواهینامه‌ی رانندگی نیاز دارند.
فرض کنید فقط انواع `'car'` و `'truck'` به گواهینامه نیاز دارند و بقیه را می‌توان بدون گواهینامه راند.

تابع `needsLicense(kind)` را پیاده‌سازی کنید که نوع وسیله‌ی نقلیه را می‌گیرد و یک مقدار «منطقی» برمی‌گرداند که نشان می‌دهد آیا برای آن نوع وسیله به گواهینامه نیاز دارید یا نه.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. انتخاب میان دو وسیله‌ی نقلیه‌ی بالقوه برای خرید

شما گزینه‌های خود را از میان وسایل نقلیه‌ی موجود بررسی می‌کنید.
موفق می‌شوید آن‌ها را به دو گزینه محدود کنید، اما برای گرفتن تصمیم نهایی به کمک نیاز دارید.
برای این کار تابع `chooseVehicle(option1, option2)` را پیاده‌سازی کنید که دو وسیله‌ی نقلیه را به عنوان آرگومان می‌گیرد و تصمیمی برمی‌گرداند که شامل گزینه‌ای است که در ترتیب الفبایی جلوتر می‌آید.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. محاسبه‌ی تخمینی برای قیمت یک وسیله‌ی نقلیه‌ی دست‌دوم

حالا که تصمیم خود را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی قیمت منصفانه‌ای می‌پردازید.
چون قصد خرید یک وسیله‌ی نقلیه‌ی دست‌دوم را دارید، قیمت به عمر آن بستگی دارد.
برای یک تخمین تقریبی، فرض کنید اگر عمر وسیله‌ی نقلیه کمتر از ۳ سال باشد، قیمت آن ۸۰ درصد قیمت اصلی‌اش در زمانی است که کاملاً نو بود.
اگر عمرش بیشتر از ۱۰ سال باشد، ۵۰ درصد.
اگر عمر وسیله‌ی نقلیه حداقل ۳ سال باشد اما بیشتر از ۱۰ سال نباشد، ۷۰ درصد قیمت اصلی است.

تابع `calculateResellPrice(originalPrice, age)` را پیاده‌سازی کنید که این منطق را با `if`، `else if` و `else` اعمال می‌کند (اگر دوست دارید تمرین کنید، روش‌های دیگری هم هست).
این تابع قیمت اصلی و عمر وسیله‌ی نقلیه را به عنوان آرگومان می‌گیرد و قیمت تخمینی را در نمایندگی برمی‌گرداند.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
