# دستورالعمل

در این تمرین، مدیریت خطا را برای یک ماشین‌حساب ساده می‌سازید.

هدف این است که یک ماشین‌حساب کارآمد داشته باشید که با گرفتن آرگومان‌های `16`، `51` و `+`، رشته‌ای با الگوی زیر برگرداند: `16 + 51 = 67`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. رسیدگی به کدی که ممکن است در متد `calculate` خطا ایجاد کند

متد اصلی برای پیاده‌سازی در این تمرین، متد کلاس `SimpleCalculator.calculate()` خواهد بود.
این متد سه آرگومان می‌گیرد.
دو آرگومان اول اعدادی هستند که قرار است عملیاتی روی آن‌ها انجام شود.
آرگومان سوم از نوع رشته است و برای این تمرین لازم است عملیات زیر پیاده‌سازی شوند:

- جمع با استفاده از رشته‌ی `+`
- ضرب با استفاده از رشته‌ی `*`
- تقسیم با استفاده از رشته‌ی `/`

## 2. رسیدگی به عملیات غیرمجاز

متد `SimpleCalculator.calculate()` را به‌روزرسانی کنید تا برای نمادهای عملیات ناشناخته، یک «استثنا»ی `UnsupportedOperation` ایجاد کند.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
در این تمرین، انتظار می‌رود استثنای `UnsupportedOperation` را برای یک محدوده‌ی مشخص تعریف کنید.
~~~~

## 3. رسیدگی به آرگومان‌های نامعتبر

متد `SimpleCalculator.calculate()` را به‌روزرسانی کنید تا برای نوع‌های نامعتبر آرگومان، یک استثنای `ArgumentError` ایجاد کند.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. رسیدگی به استثناهای DivideByZero

`SimpleCalculator.calculate()` را به‌روزرسانی کنید تا استثناهای `ZeroDivisionError` را مدیریت کند.
کد مدیریت باید رشته‌ای با محتوای `Division by zero is not allowed.` برگرداند.
هیچ استثنای دیگری نباید توسط متد `SimpleCalculator.calculate()` مدیریت شود.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
