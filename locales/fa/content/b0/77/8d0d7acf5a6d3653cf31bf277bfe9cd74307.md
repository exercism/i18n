# نکته‌ها برای تمرین Minesweeper در Bash

به نظر می‌رسد این تمرین به یک آرایه‌ی دوبعدی نیاز دارد.
Bash فقط [آرایه‌ها][array]ی تک‌بعدیِ ایندکسی یا انجمنی را ارائه می‌دهد.

می‌توان آرایه‌های چندبعدی را با استفاده از یک آرایه‌ی انجمنی شبیه‌سازی کرد: اندیس‌ها را به شکل یک رشته که با ویرگول از هم جدا شده‌اند دربیاورید و از آن به عنوان کلید آرایه استفاده کنید.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
