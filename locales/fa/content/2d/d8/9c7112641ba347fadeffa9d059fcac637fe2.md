# پیوست دستورالعمل‌ها

## پیاده‌سازی

برای نگهداری مقادیر طبقه‌بندی اعداد طبیعی،
`type Classification`
را تعریف کنید.
برای این نوع می‌توانید هر نمایشی را انتخاب کنید.

سه ثابت از نوع Classification با این اسم‌ها تعریف کنید

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

تابعی به اسم Classify پیاده‌سازی کنید که
یک ورودی int64 می‌گیرد و یک Classification و یک مقدار خطا برمی‌گرداند.

یک خطا به اسم ErrOnlyPositive بسازید
که وقتی ورودی یک عدد صحیح مثبت نیست، برگردانده می‌شود.
