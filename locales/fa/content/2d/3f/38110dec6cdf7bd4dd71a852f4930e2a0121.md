# درباره

Swift دستورهای انتقال کنترل را فراهم می‌کند تا جریان اجرای حلقه‌ها و دستورهای `switch` را تغییر دهد.
Swift علاوه بر `return`، دستورهای `continue`، `break`، برچسب حلقه و `fallthrough` را نیز دارد.

## Continue

دستور `continue` به حلقه می‌گوید که اجرای تکرار فعلی را متوقف کند و بی‌درنگ تکرار بعدی را آغاز کند.
در حلقه‌ی `while` یا `repeat-while`، مستقیماً به بررسی شرط می‌پرد.
در حلقه‌ی `for-in`، به عنصر بعدی دنباله می‌رود.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

دستور `break` یک حلقه یا دستور `switch` را بی‌درنگ و به‌طور کامل پایان می‌دهد.
اجرا از اولین خط کد پس از حلقه یا `switch` ادامه پیدا می‌کند.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## دستورهای برچسب‌دار

در حلقه‌های تودرتو، ممکن است بخواهید `break` یا `continue` روی حلقه‌ی بیرونی اثر بگذارد، نه درونی‌ترین حلقه.
برای برچسب زدن به یک حلقه، یک اسم و سپس یک دونقطه را پیش از آن قرار دهید (`labelName:`).
سپس می‌توانید آن برچسب را به `break` یا `continue` بدهید:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

در Swift، دستورهای `switch` به‌طور پیش‌فرض به `case` بعدی نمی‌روند؛ اجرا به‌طور خودکار در پایان `case` منطبق متوقف می‌شود.
اگر صریحاً بخواهید اجرا بدون بررسی الگوی `case` بعدی به آن ادامه پیدا کند، از کلیدواژه‌ی `fallthrough` استفاده کنید:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
