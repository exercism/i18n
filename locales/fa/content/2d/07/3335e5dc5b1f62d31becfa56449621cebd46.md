# مقدمه

## مبانی

ما به _زبان_ با نام **AWK** و به _برنامه‌ی اجرایی‌ای_ که برنامه‌های AWK را تفسیر می‌کند با نام **`awk`** یا **`gawk`** اشاره می‌کنیم.

### الگو و کنش

یک برنامه‌ی AWK از **جفت‌های الگو-کنش** تشکیل شده است.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

یک **الگو** می‌تواند یک عبارت باقاعده باشد که با ورودی مطابقت داده می‌شود.
همچنین می‌تواند هر عبارتی باشد که نتیجه‌اش یک مقدار «درست» یا «غلط» است.

یک **کنش** یک یا چند دستور AWK است.
آکولادهای پیرامون آن الزامی‌اند.

اگر نتیجه‌ی الگو «درست» باشد، کنش متناظر با آن ارزیابی می‌شود.

### رکورد و فیلد

AWK ورودی را به‌صورت زنجیره‌ای از **رکوردها** تجزیه می‌کند.
هر رکورد به صفر یا چند **فیلد** تقسیم می‌شود.

رفتار پیش‌فرض چنین است:

- تقسیم ورودی به رکوردها با استفاده از خط جدید به‌عنوان «جداکننده‌ی رکورد»، به‌طوری که هر _خط_ یک رکورد است.
- تقسیم رکورد به فیلدها با استفاده از فضای سفید به‌عنوان «جداکننده‌ی فیلد»، به‌طوری که هر _کلمه_ یک فیلد است.

### الگو و کنش، ادامه

می‌توان الگو را حذف کرد؛ در این صورت کنش _برای هر رکورد ورودی_ ارزیابی می‌شود.

می‌توان کنش را هم حذف کرد؛ در این صورت کنش پیش‌فرض، چاپ رکورد جاری است.

#### الگوهای خاص

دو الگوی خاص وجود دارند که اغلب استفاده می‌شوند.

- `BEGIN` کنش مرتبط را پیش از مصرف هر ورودی ارزیابی می‌کند.
- `END` کنش مرتبط را پس از مصرف تمام ورودی ارزیابی می‌کند.

### متغیرهای فیلد

به فیلدها با `$1`، `$2`، `$3` و غیره اشاره می‌کنید.

رکورد جاری `$0` است.

در ادامه چند متغیر توکار پرکاربرد دیگر را می‌بینید.

#### متغیرهای توکاری که تجزیه‌ی ورودی را کنترل می‌کنند

- `RS` جداکننده‌ی رکورد ورودی است.
  همان‌طور که گفته شد، مقدار پیش‌فرض آن خط جدید است.
- `FS` جداکننده‌ی فیلد ورودی است.

این متغیرها اغلب در بلوک کنش `BEGIN` تنظیم می‌شوند.

#### متغیرهای توکاری که اطلاعات را منتقل می‌کنند

این متغیرها در طول اجرای برنامه به‌طور خودکار توسط AWK تنظیم می‌شوند.

- `NF` تعداد فیلدهای رکورد جاری را نگه می‌دارد.
  - برای به‌دست آوردن مقدار آخرین فیلد، از `$NF` استفاده کنید.
- `NR` شماره‌ی رکورد جاری را نگه می‌دارد.
  - وقتی چند فایل ورودی پردازش می‌شوند، `NR` تعداد کل رکوردهای پردازش‌شده تا این لحظه را نگه می‌دارد.
- `FNR` شماره‌ی رکورد جاری در فایل ورودی جاری را نگه می‌دارد.
  - برای نشان دادن تفاوت میان `NR` و `FNR`، یک اصطلاح رایج AWK را می‌بینید.
    ```awk
    NR == FNR {action}
    ```
    این یعنی «اگر شماره‌ی رکورد انباشته با شماره‌ی رکورد فایل جاری برابر باشد.»
    این تنها می‌تواند برای رکوردهای _اولین فایل ورودی_ درست باشد.

### مفهوم درستی

AWK همان مفهوم درستی را مانند C به کار می‌برد.

- عدد `0` «غلط» است.
- هر عدد دیگری «درست» است.

از آنجا که AWK یک زبان پردازش متن است، مقادیر درستی به رشته‌ها هم گسترش می‌یابند.

- یک رشته‌ی خالی `""` «غلط» است.
- هر رشته‌ی ناتهی «درست» است.

### توضیح

توضیح با نویسه‌ی `#` شروع می‌شود و تا پایان خط ادامه می‌یابد.

### مثال

در سیستم‌های شبیه یونیکس، فایل `/etc/passwd` اطلاعات مربوط به کاربران را در خود دارد.
هر کاربر در یک خط جداگانه توصیف می‌شود و فیلدهای آن با دونقطه از هم جدا شده‌اند.

برای فهرست کردن اسم‌های کاربری:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

توجه کنید که کنش `{print $1}` الگویی ندارد، پس برای هر رکورد اجرا می‌شود.

اگر بخواهیم خروجی را فقط به کاربرانی محدود کنیم که از bash به‌عنوان پوسته‌ی ورود خود استفاده می‌کنند، می‌توانیم این کار را انجام دهیم:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
