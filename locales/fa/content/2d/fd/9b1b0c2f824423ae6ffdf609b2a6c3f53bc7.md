# دستورالعمل‌ها

شما روی یک بازی کار می‌کنید که برای یک سیستم توکار کم‌مصرف طراحی شده است و باید چندین تابع کمکی بنویسید که بخش‌های دیگر بازی از آن‌ها استفاده خواهند کرد.

## 1. خارج‌قسمت و باقیمانده‌ی یک تقسیم را محاسبه کنید

خارج‌قسمت، خروجی یک تقسیم است.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

مثال:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. عنصرهای واقع در موقعیت‌های زوج را از یک تکرارگر انتخاب کنید

رئیس‌تان قول می‌دهد که این کار برای فعال کردن یک بهینه‌سازی روی بافر صفحه به کارتان می‌آید.

تکرارگرها عنصرهایی هستند که متدهای تعریف‌شده توسط [trait `Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html) را در اختیار شما می‌گذارند. آن مستندات نسبتاً مفصل است، چون متدهای زیادی ارائه می‌دهند؛ در ادامه مهم‌ترین ویژگی‌هایشان را می‌بینید:

- یک تکرارگر، جریانی از عنصرها با طول دلخواه است
- متدی به نام [`enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) دارند که برای هر مقدار یک تاپل `(i, val)` برمی‌گرداند
- متدی به نام [`filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) دارند که از یک کلوژر استفاده می‌کند تا تعیین کند آیا عنصری از تکرارگر بازگردانده شود یا نه
- متدی به نام [`map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) دارند که از یک کلوژر برای تغییر دادن عنصرهای تکرارگر استفاده می‌کند

چون تابع شما می‌تواند روی هر نوع تکرارگری اجرا شود، از `impl` استفاده می‌کند تا نشان دهد این یک نمونه‌ی trait است و نه یک مورد ساده. به همین ترتیب، نحوه‌ی نگارش `<Item=T>` فقط یعنی اینکه مهم نیست تکرارگر چه نوع عنصری تولید می‌کند؛ تابع شما می‌تواند عنصرهای زوج هر تکرارگری را تولید کند.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

مثال‌ها:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. فاصله‌ی منهتن یک موقعیت از مبدأ را محاسبه کنید

برای راحتی کار با نقشه، یک struct تاپلی به اسم `Position` دارید:

```rust
struct Position(i16, i16);
```

باید متدی به نام `manhattan` روی `Position` پیاده‌سازی کنید که [فاصله‌ی منهتن](https://en.wikipedia.org/wiki/Taxicab_geometry) آن موقعیت از مبدأ (`Position(0, 0)`) را برمی‌گرداند.

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

مثال:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
