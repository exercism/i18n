# مقدمه

در سراسر مسیر Julia از شما خواسته می‌شود که با راه‌حل خود مانند کتابخانه‌های کوچک رفتار کنید، یعنی باید توابع، نوع‌ها و مواردی از این دست را تعریف کنید که سپس در برابر یک مجموعه‌ی test اجرا می‌شوند.
به همین دلیل، «توابع نامدار» را به‌عنوان نخستین مفهوم معرفی می‌کنیم.

Julia یک زبان برنامه‌نویسی پویا و به‌شدت نوع‌دار است.
سبک برنامه‌نویسی آن عمدتاً تابعی است، هرچند انعطاف بیشتری از زبان‌هایی مانند Haskell دارد.

## متغیرها و انتساب

نیازی نیست متغیری را از پیش اعلام کنید.
کافی است مقداری را به اسمی مناسب نسبت دهید:

```julia-repl
julia> myvar = 42  # an integer
42

julia> name = "Maria"  # strings are surrounded by double-quotes ""
"Maria"
```

## ثابت‌ها

اگر لازم است مقداری در سراسر برنامه در دسترس باشد اما انتظار نمی‌رود تغییر کند، بهتر است آن را به‌عنوان ثابت مشخص کنید.

قرار دادن «کلیدواژه‌ی `const`» در ابتدای یک انتساب، به کامپایلر امکان می‌دهد کدی کارآمدتر از آنچه برای یک متغیر ممکن است تولید کند.

ثابت‌ها همچنین به شما کمک می‌کنند تا از خطاهای کدنویسی در امان بمانید.
اگر به‌طور تصادفی بخواهید مقدار `const` را تغییر دهید، یک هشدار دریافت می‌کنید:

```julia-repl
julia> const answer = 42
42

julia> answer = 24
WARNING: redefinition of constant Main.answer. This may fail, cause incorrect answers, or produce other errors.
24
```

توجه کنید که `const` را فقط می‌توان *بیرون* از هر تابعی اعلام کرد.
این کار معمولاً نزدیک بالای فایل `*.jl`، پیش از تعریف توابع، انجام می‌شود.

## عملگرهای حسابی

این‌ها مانند بسیاری از زبان‌های دیگر هستند:

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division with floating-point result)
8 % 3  # 2 (remainder)
```

## توابع

دو روش رایج برای تعریف یک تابع نامدار در Julia وجود دارد:

1. با استفاده از کلیدواژه‌ی `function`

    ```julia
    function muladd(x, y, z)
        x * y + z
    end
    ```

    تورفتگی با ۴ فاصله برای خوانایی رایج است، اما کامپایلر آن را نادیده می‌گیرد.
    کلیدواژه‌ی `end` ضروری است.

    توجه کنید که می‌توانستیم `return x * y + z` را بنویسیم.
    اما توابع Julia همیشه آخرین عبارت ارزیابی‌شده را برمی‌گردانند، بنابراین کلیدواژه‌ی `return` اختیاری است.
    بسیاری از برنامه‌نویسان ترجیح می‌دهند آن را بنویسند تا منظورشان روشن‌تر باشد.

2. با استفاده از «شکل انتساب»

    ```julia
    muladd(x, y, z) = x * y + z
    ```

    این شکل بیشتر برای ساختن توابع کوتاه تک‌عبارتی به کار می‌رود.

    کلیدواژه‌ی `return` در شکل انتساب *هرگز* به کار نمی‌رود.

این دو شکل هم‌ارزند و دقیقاً به یک شیوه به کار می‌روند، پس هرکدام را که خواناتر است انتخاب کنید.

فراخوانی یک تابع با آوردن اسم آن و فرستادن آرگومان برای هر یک از پارامترهای تابع انجام می‌شود:

```julia
# invoking a function
muladd(10, 5, 1)

# and of course you can invoke a function within the body of another function:
square_plus_one(x) = muladd(x, x, 1)
```

## قواعد نام‌گذاری

مانند بسیاری از زبان‌ها، Julia لازم می‌داند که اسم‌ها (اسم متغیرها، توابع و بسیاری موارد دیگر) با یک حرف شروع شوند و پس از آن هر ترکیبی از حروف، ارقام و زیرخط بیاید.

طبق قرارداد، اسم متغیرها، ثابت‌ها و توابع *با حروف کوچک* نوشته می‌شود و زیرخط‌ها در حد معقولی کم نگه داشته می‌شوند.
