# آژانس طراحی وب

## داستان

شرکت طراحی شما تا به حال عمدتاً با تبدیل‌های CSS و برای ساختن صفحات وب کار می‌کرده است. بعد از بحث‌هایی، تصمیم گرفته می‌شود که از JavaScript برای انجام بخشی از محاسبات به‌صورت پویا استفاده شود. بعضی از هم‌تیمی‌هایتان تجربه‌ی کمتری با JavaScript دارند، بنابراین تصمیم می‌گیرید از یک «بستار» استفاده کنید تا تبدیلی قابل استفاده‌ی مجدد برای جفت مختصات `{x, y}` بسازید.

## تمرین‌ها

- تابعی بسازید که آرگومان‌هایش به‌عنوان بستار در تابع بازگردانده‌شده به کار می‌روند.

  - تابعی برای جابه‌جایی دوبعدی، که در آن تابع بیرونی مقدار جابه‌جایی را مشخص می‌کند و تابع بازگردانده‌شده یک مختصات x و y می‌گیرد و مختصات جابه‌جاشده را برمی‌گرداند.
  - تابعی برای مقیاس‌بندی دوبعدی، که در آن تابع بیرونی میزان مقیاس را مشخص می‌کند و تابع بازگردانده‌شده یک مختصات x و y می‌گیرد و مختصات جابه‌جاشده را برمی‌گرداند.
  - تابعی که تابعی را برمی‌گرداند که دو تابع را با هم ترکیب می‌کند، در عمل تابعی برای `g(f(x))`

- تابعی بسازید که یک تابع را حافظه‌دار می‌کند.
