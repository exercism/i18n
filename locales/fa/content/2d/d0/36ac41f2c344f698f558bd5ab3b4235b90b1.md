# دستورالعمل

شما به یک سرشماری پرندگان کمک می‌کنید. هر روز کسی در «پناهگاه»ی می‌نشیند و آنچه را که از کنارش پرواز می‌کند می‌شمارد، و شمارش‌های آن روز به‌صورت یک آرایه برمی‌گردند.

هر پنج وظیفه در کلاس `BIRD_SURVEY` قرار می‌گیرند.

## 1. مجموع

شمارش همه‌ی روزها را با هم جمع بزنید.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

سرشماری‌ای که هیچ روزی ندارد، صفر پرنده می‌شمارد.

## 2. بهترین روز

بزرگ‌ترین شمارش را برگردانید. اگر هیچ روزی وجود نداشته باشد، پاسخ صفر است.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. روزهای شلوغ

چند روز شمارشی بالاتر از عددی مشخص داشتند؟

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

بالاتر یعنی واقعاً بالاتر: شمارش دقیقاً ۲ به حساب نمی‌آید.

## 4. پناهگاه‌هایی که باید بررسی شوند

در روز اول سرشماری یک پناهگاه را بررسی می‌کنید، در روز دوم دو پناهگاه، و به همین ترتیب. جمعاً چند بررسی پناهگاه انجام می‌شود؟

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

یعنی ۱ + ۲ + ۳ + ۴.

## 5. اولین روز شلوغ

کدام روز اولین روزی بود که شمارشی بالاتر از عددی مشخص داشت؟ روزها از صفر شماره‌گذاری می‌شوند، همان‌طور که جایگاه‌های آرایه شماره‌گذاری می‌شوند. اگر هیچ روزی آن‌قدر شلوغ نبود، پاسخ `-1` است.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
