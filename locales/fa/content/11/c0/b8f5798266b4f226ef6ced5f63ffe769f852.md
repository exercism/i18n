# درباره

## پیمایش آرایه

حلقه‌ی `for` به شما اجازه می‌دهد روی یک آرایه پیمایش کنید و کد را برای هر عنصر تکرار کنید:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

در مثال بالا، `fruit` متغیری است که مقدار یک عنصر از آرایه‌ی `fruitList` را نگه می‌دارد. کامپایلر مطمئن می‌شود که روی `fruitList` می‌توان پیمایش کرد. در غیر این صورت، اجرا را متوقف می‌کند.

## پیمایش بازه

می‌توانید با استفاده از عملگر بازه روی اعداد پیمایش کنید. این عملگر دو عملوند از نوع `Int` می‌گیرد و به شکل `min...max` نوشته می‌شود. مقدار `min` شامل است و مقدار `max` غیرشامل (`min` <= i AND `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## پیمایش کلید-مقدار

می‌توان روی مجموعه‌هایی از جفت‌های کلید-مقدار پیمایش کرد. تنها تفاوت در نحوه‌ی نگارش این است که به‌جای یک متغیر واحد، شناسه‌ی متغیر کلید می‌آید، بعد از آن `=>` و سپس شناسه‌ی متغیر مقدار:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
