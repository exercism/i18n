# دستورالعمل‌ها

شما افسر نگهبانِ یک کشتی کوچک هستید که از تنگه‌ی برینگ می‌گذرد. سه منبع موقعیت هر یخ شناور و هر دماغه‌ای را که در دیدرس است اعلام می‌کنند:

- **میز نقشه** با جهت‌های قطب‌نما حرف می‌زند، یعنی `north`، `east`، `south` و `west`. فقط یک سمت، بدون فاصله.
- **ناوبر** با مختصات *قطبی* نسبت به آخرین موقعیت‌یابی کشتی حرف می‌زند: یک اندازه بر حسب مایل دریایی، و یک زاویه بر حسب درجه در جهت حرکت عقربه‌های ساعت از شمال (پس `0` شمال است، `90` شرق، `180` جنوب و `270` غرب).
- **دیده‌بان دکل** با مختصات *نسبی* حرف می‌زند: یک فاصله به سمت جلو، و یکی از `ahead`، `starboard`، `behind` و `port`. زاویه‌های نسبی نسبت به *سمت فعلی کشتی* سنجیده می‌شوند؛ ناخدا آن سمت را پیش از هر نگهبانی روی پل فرماندهی اعلام می‌کند.

کار شما این است که هر سه را به یک چارچوب دکارتی مشترک `(x, y)` تبدیل کنید تا نقشه قابل ترسیم باشد. زاویه‌ها بر حسب درجه‌اند؛ `(0, 1)` یک مایل دریایی به شمال و `(1, 0)` یک مایل دریایی به شرق است.

## 1. مدل داده و دکارتی برای جهت‌های اصلی

ابتدا اجزایی را که در سراسر تمرین مشترک‌اند بچینید:

- سه تاپل تعریف کنید: `cardinal` (یک خانه، `direction`)، `polar` (خانه‌های `magnitude` و `bearing`) و `relative` (خانه‌های `distance` و `bearing`).
- نمادهای سمت را با `SYMBOLS:` اعلام کنید: `north`، `east`، `south`، `west`، `ahead`، `starboard`، `behind`، `port`.
- یک متغیر پویا به اسم `heading` را با `SYMBOL:` اعلام کنید (در تکلیف سوم از آن استفاده می‌شود).
- دو واژه‌ی جنریک اعلام کنید: `GENERIC: >cartesian ( direction -- x y )` و `GENERIC: flip ( direction -- direction' )`. متدهای آن‌ها را در تکلیف‌های بعدی اضافه می‌کنید.

سپس متد `M: cardinal` از `>cartesian` را اضافه کنید که بردار یکه‌ی جهتِ نام‌برده را برمی‌گرداند.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. دکارتی برای قطبی

یک متد `M: polar` به `>cartesian` اضافه کنید که شکل قطبی را به `(x, y)` تبدیل می‌کند:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. دکارتی برای نسبی

یک متد `M: relative` به `>cartesian` اضافه کنید. اما یک نکته‌ی مهم وجود دارد: یک زاویه‌ی نسبی نسبت به *سمت فعلی کشتی* سنجیده می‌شود که جزو تاپل نیست. متغیر `heading` را (که در تکلیف اول اعلام شده) با `heading get` بخوانید، اختلاف زاویه را اضافه کنید (`ahead = 0`، `starboard = 90`، `behind = 180`، `port = 270`) و نقطه‌ی دکارتی را تولید کنید. فراخوانی‌کننده، `heading` را داخل یک بلوک `with-variable` تنظیم می‌کند.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. وارونه‌سازی

متدهای جنریک `flip` را (که در تکلیف اول اعلام شده) اضافه کنید تا جهت مخالف را برگرداند.

- برای `cardinal`: `north` ↔ `south`، `east` ↔ `west`.
- برای `polar`: ۱۸۰ درجه به زاویه اضافه کنید (به پیمانه‌ی ۳۶۰).
- برای `relative`: `ahead` ↔ `behind`، `starboard` ↔ `port`.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. جمع زدن زاویه‌ها

تابع `add-bearings ( a b -- x y )` را تعریف کنید که هر دو جهت را به دکارتی تبدیل می‌کند و مجموعشان را برمی‌گرداند. برای هر ترکیبی از `cardinal`، `polar` و `relative` کار می‌کند؛ این همان مزیتِ استفاده از یک جنریک برای `>cartesian` است.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
