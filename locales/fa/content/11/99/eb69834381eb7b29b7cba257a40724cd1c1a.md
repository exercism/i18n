# مقدمه

نوع `enum` در C# نمایانگر مجموعه‌ی ثابتی از ثابت‌های نام‌گذاری‌شده است (یک شمارش). هدف اصلی آن فراهم کردن روشی ایمن از نظر نوع برای تعامل با ثابت‌های عددی و محدود کردن مقادیر موجود به مجموعه‌ای از پیش تعریف‌شده است. یک `enum` ساده را می‌توان به شکل زیر تعریف کرد:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

اگر به صراحت تعریف نشوند، به اعضای `enum` به طور خودکار مقادیر صحیح افزایشی اختصاص داده می‌شود و اولین مقدار صفر خواهد بود. همچنین می‌توان مقادیر را به صراحت اختصاص داد:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
