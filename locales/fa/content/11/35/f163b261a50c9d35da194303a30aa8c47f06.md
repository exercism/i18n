# پیوست دستورالعمل‌ها

## راهنمایی‌ها

برای کامل کردن این تمرین، باید نوع داده‌ی `Robot` را به‌صورت یک متغیر تغییرپذیر و نوع داده‌ی `RunState` را بسازید. همچنین باید توابع زیر را پیاده‌سازی کنید:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

یک اعلان داده‌ی ساختگی و امضاهای نوع از قبل در جای خود قرار دارند، اما این شمایید که باید توابع را تعریف کنید و یک نوع داده، newtype یا type synonym معنادار بسازید. این تمرین برای مدل‌سازی وضعیت از موناد [`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State) استفاده می‌کند. به‌طور خاص‌تر، موناد `State` را با موناد `IO` و با استفاده از [مبدل‌های موناد `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html) ترکیب می‌کنیم. همه‌ی تست‌ها با `initialState` به عنوان وضعیتی که به `evalStateT` داده می‌شود اجرا می‌شوند.
