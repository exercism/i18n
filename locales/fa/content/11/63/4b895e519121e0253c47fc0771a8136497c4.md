# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است [یک استثنا ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، باید همیشه یک **پیام خطای معنادار** بگنجانید تا نشان دهید منشأ خطا چیست. این کار code شما را خواناتر می‌کند و به debug کمک چشمگیری می‌کند. در موقعیت‌هایی که می‌دانید منشأ خطا نوع مشخصی خواهد بود، می‌توانید یکی از [انواع خطای توکار](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما همچنان باید پیامی معنادار بگنجانید.

این تمرین خاص از شما می‌خواهد که از [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) استفاده کنید تا هر وقت قواعد امتیازدهی یا بازی رعایت نمی‌شوند، یک خطا «پرتاب» کنید. tests تنها در صورتی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بگنجانید.

برای ایجاد یک `ValueError` همراه با پیام، پیام را به‌عنوان آرگومان به نوع `exception` بدهید:

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
