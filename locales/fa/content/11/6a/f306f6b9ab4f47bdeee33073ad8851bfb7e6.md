# درباره

`TUPLE:` یک کلاس با «شیار»های نامدار تعریف می‌کند. Factor به‌طور خودکار یک واژه‌ی سازنده (با افزودن پسوند `new` به نام کلاس)، یک سازنده‌ی `boa` («به ترتیب آرگومان‌ها»)، یک نحوه‌ی نگارش تحت‌اللفظی `T{ class … }` و واژه‌های دسترس‌گر برای هر شیار تولید می‌کند.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

سامانه‌ی دسترس‌گرها در [`accessors`][accessors] برای هر شیار چهار گونه فراهم می‌کند: `name>>`، `>>name`، `change-name` و جفت تغییردهنده‌ی `[ … ] change-name`. `>>name` و `change-name` «تاپل» را تغییر می‌دهند؛ اگر می‌خواهید نسخه‌ی اصلی دست‌نخورده بماند، ابتدا `clone` کنید.

تاپل از `=` بر پایه‌ی تساوی ساختاری پشتیبانی می‌کند و هنگام چاپ، مقدار شیارهای غیرپیش‌فرضش نمایش داده می‌شود.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
