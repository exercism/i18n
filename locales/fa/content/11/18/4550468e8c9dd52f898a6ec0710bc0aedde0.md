# دستورالعمل‌ها

نقاط پایانی HTTP با بررسی نوع بهتر کار می‌کنند. افزودن نوع `Record` به یک درخواست `POST` تضمین می‌کند که هر بار داده‌ی درست ارسال شود.

## اهداف

- کد ارائه‌شده را تغییر دهید.
- ویژگی‌های لازم را به این `Record` اضافه کنید تا دو عملوند و یک عملگر را بپذیرد.
- یک تابع منبع HTTP اضافه کنید که درخواست `POST` را روی مسیر `/calc` بپذیرد.
- تابع باید نوع رکورد `Calculation` را به‌عنوان محتوای ورودی بپذیرد و یک شیء JSON عمومی برگرداند.

### ورودی

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### خروجی

```json
{ "expression": "4+10.2", "result": 14.2 }
```
