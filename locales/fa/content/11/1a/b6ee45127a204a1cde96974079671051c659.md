# تست‌ها

برای اجرای تست‌ها در خط فرمان، دستور زیر را از پوشه‌ی تمرین اجرا کنید:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## رابط گرافیکی

برای اجرای تست‌ها از طریق رابط گرافیکی شبیه‌ساز MARS، خط آخر را از حالت کامنت خارج کنید تا `include` پیاده‌سازی شما را در انتهای `runner.mips` قرار دهد.
