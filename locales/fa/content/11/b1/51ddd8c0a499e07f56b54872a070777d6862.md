# پیوست دستورالعمل

به توان رساندن اعداد مختلط به یک تابع نمایی، یک تابع سینوس و یک تابع کسینوس نیاز دارد. هیچ‌کدام از این توابع در WebAssembly در دسترس نیستند. خوشبختانه می‌توان برای محاسبه‌ی آن‌ها از [سری تیلور](https://en.wikipedia.org/wiki/Taylor_series) استفاده کرد. برای هم‌راستایی با مقادیر مورد انتظار، باید حداقل دقتی در حد `1/26!` داشته باشید.

## تابع نمایی

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## تابع سینوس

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## تابع کسینوس

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
