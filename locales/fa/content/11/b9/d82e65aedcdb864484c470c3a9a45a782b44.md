# دستورالعمل

اندرو، توسعه‌دهنده‌ای در شرکتش، اخیراً یک ابزار سبک برای تولید کوئری SQL برای یک ابزار مهاجرت پایگاه داده ساخته است.
اولین پیاده‌سازی ساده‌لوحانه‌اش برای مجموعه‌های کوچک داده بی‌نقص کار می‌کرد.
اما در مهاجرت‌های بزرگ در محیط عملیاتی، برنامه شروع به مصرف بیش از حد حافظه کرد و زیر بار سنگین به مشکل خورد.
اندرو پس از پروفایل کردن برنامه متوجه شد که الحاق معمولی رشته‌ها داخل حلقه‌ها باعث می‌شود Go مدام حافظه را دوباره تخصیص دهد.
حالا او به کمک شما نیاز دارد تا این ابزار را با استفاده از `strings.Builder` در Go بازنویسی کند، تا برنامه به‌خوبی مقیاس‌پذیر باشد و حجم زیادی از متن را بدون فشار آوردن به هیپ حافظه پردازش کند.

## 1. تولید کوئری‌های SELECT

تابع `BuildSelectQuery` را پیاده‌سازی کنید.
این تابع یک اسم جدول (`string`) و یک اسلایس از اسم ستون‌ها (`[]string`) می‌گیرد.
باید یک دستور `SELECT` کامل SQL را برگرداند که به نقطه‌ویرگول ختم می‌شود.
اگر اسلایس ستون‌ها خالی یا `nil` باشد، کوئری باید به‌جای آن از نویسه‌ی عام `*` برای انتخاب همه‌ی ستون‌ها استفاده کند.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. تولید دستورهای INSERT گروهی

تابع `BuildBatchInserts` را پیاده‌سازی کنید.
این تابع یک اسم جدول (`string`) و یک اسلایس دوبعدی که سطرهای پایگاه داده را نمایش می‌دهد (`[][]ColumnValue`) می‌گیرد.
هر عنصر در یک سطر، اسم یک ستون مشخص را به مقدار رشته‌ای آن پیوند می‌دهد.
تابع باید یک اسلایس از رشته‌های `INSERT` جداگانه‌ی SQL برگرداند.
قالب ساخت‌یافته‌ی اسلایس، ترتیب خروجی کوئری‌ها را قابل‌پیش‌بینی و پایدار تضمین می‌کند.
اگر اسلایس ورودی سطرها خالی باشد، یک اسلایس رشته‌ای خالی برگردانید.
اگر یکی از سطرها خالی باشد، از آن صرف‌نظر کنید.
مقادیر رشته‌ای در بخش `VALUES` باید داخل تک‌کوتیشن (`'`) قرار بگیرند.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
