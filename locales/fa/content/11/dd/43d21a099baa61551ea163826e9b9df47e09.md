# دستورالعمل‌ها

شما یک ایستگاه هواشناسی کوچک در ساحل رودخانهٔ ولتاوا در پراگ دارید و در هر شیفت، دمای خوانده‌شده را در یک لاگ متنی یادداشت می‌کنید؛ هر خط یک دما. پنج واژهٔ کوچک، کار دفترداری یک شیفت را انجام می‌دهند.

مسیر فایل لاگ به هر واژه داده می‌شود.

## 1. همهٔ دماها را بخوانید

`read-readings` را طوری تعریف کنید که همهٔ دماهای لاگ را به‌صورت آرایه‌ای از رشته‌ها برگرداند؛ هر خط، یک رشته.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. آخرین دما را پیدا کنید

`latest-reading` را طوری تعریف کنید که جدیدترین دما را برگرداند؛ یعنی آخرین خط لاگ.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. لاگ خام را بخوانید

`log-text` را طوری تعریف کنید که کل فایل لاگ را به‌صورت یک رشتهٔ واحد، دقیقاً همان‌طور که ذخیره شده است، برگرداند.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. یک دما را ثبت کنید

`record-reading` را طوری تعریف کنید که یک دمای جدید را به‌صورت خطی جداگانه به انتهای لاگ اضافه کند و دماهای قبلی را دست‌نخورده بگذارد. چیزی برنمی‌گرداند.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. لاگ را بازنویسی کنید

`rewrite-log` را طوری تعریف کنید که کل لاگ را با آرایه‌ای تازه از دماها جایگزین کند؛ هر خط یک دما.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
