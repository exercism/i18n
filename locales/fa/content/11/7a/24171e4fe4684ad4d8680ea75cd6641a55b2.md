## دستورالعمل‌ها

شما توسط یک مرکز بازیافت استخدام شده‌اید.
به‌دلیل کمبود فضا، همه‌ی محصولات روی یک نوار نقاله‌ی یکسان قرار می‌گیرند، اما این کار باعث شده مواد مختلف با هم مخلوط شوند و دیگر قابل استفاده نباشند.
برای حل این مشکل، از شما خواسته شده است توابعی بنویسید که نوع یک محصول را تشخیص دهند.

### 1. بررسی کنید که آیا یک مقدار منطقی است

تابع `isBoolean` را پیاده‌سازی کنید که بررسی می‌کند آیا یک مقدار منطقی است یا نه.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. بررسی کنید که آیا یک مقدار عدد است

تابع `isNumber` را پیاده‌سازی کنید که بررسی می‌کند آیا یک مقدار یک `number` یا `bigint` _متناهی_ است، یعنی `NaN` یا `Infinity` نیست.

گاهی دستگاه خواندن شناسه‌ها دچار خطا می‌شود و یک مقدار غیرعددی را به‌صورت `NaN` (عدد نیست) یا `Infinity` می‌خواند.
تابع شما باید بتواند این حالت را نیز به‌درستی مدیریت کند.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. بررسی کنید که آیا یک مقدار شیء است

تابع `isObject` را پیاده‌سازی کنید که باید بررسی کند آیا مقدار یک شیء است.
روی نوار نقاله، `null` به‌معنای هیچ است و شیء محسوب نمی‌شود.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. بررسی کنید که آیا یک رشته عددی است

تابع `isNumericString` را پیاده‌سازی کنید که باید بررسی کند آیا مقدار رشته‌ای است که فقط از رقم‌ها تشکیل شده یا از یک علامت منفی و پس از آن رقم‌هایی که نشان‌دهنده‌ی یک عدد منفی است.
فقط اعداد صحیح در نظر گرفته می‌شوند؛ برای این بررسی ربات بازیافت، اعداد اعشاری عددی محسوب نمی‌شوند.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. بررسی کنید که آیا یک شیء الکترونیکی است

تابع `isElectronic` را پیاده‌سازی کنید که بررسی می‌کند آیا یک شیء نمونه‌ای از کلاس `ElectronicDevice` ارائه‌شده یا یکی از کلاس‌های فرزند آن است.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. بررسی کنید که آیا یک مقدار آرایه‌ی غیرخالی است

تابع `isNonEmptyArray` را پیاده‌سازی کنید که بررسی می‌کند آیا یک مقدار آرایه‌ی غیرخالی است.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. بررسی کنید که آیا یک مقدار آرایه‌ی خالی است

تابع `isEmptyArray` را پیاده‌سازی کنید که بررسی می‌کند آیا یک مقدار آرایه‌ی خالی است.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. بررسی کنید که آیا یک شیء ویژگی یا متد `type` دارد

تابع `hasType` را پیاده‌سازی کنید که بررسی می‌کند آیا یک شیء ویژگی یا متد `type` دارد.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. اگر یک شیء ویژگی یا متد `id` ندارد، خطا پرتاب کنید

تابع `assertHasId` را پیاده‌سازی کنید که در صورت نداشتن ویژگی `id` در یک شیء، یک `Error` پرتاب می‌کند.

اگر شیء ویژگی `id` را داشته باشد، نباید هیچ مقداری برگرداند.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. بررسی کنید که آیا یک شیء ویژگی `id` دارد

تابع `hasIdProperty` را پیاده‌سازی کنید که بررسی می‌کند آیا یک شیء ویژگی `id` دارد.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. بررسی کنید که آیا یک شیء ویژگی `type` تعریف‌شده دارد

تابع `hasDefinedType` را پیاده‌سازی کنید که بررسی می‌کند آیا یک شیء ویژگی `type` دارد که `undefined` نیست.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
