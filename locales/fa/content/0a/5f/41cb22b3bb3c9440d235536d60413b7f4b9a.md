هدف این تمرین، بهبود تمرین «Password Checker» است.
از آنجا که یک گذرواژه‌ی مشخص معمولاً بیش از یک قاعده را هم‌زمان نقض می‌کند، یک بررسی‌کننده‌ی گذرواژه‌ی مفید باید همه‌ی قواعد نقض‌شده را به کاربر اطلاع دهد، نه فقط اولین قاعده‌ای را که به‌طور تصادفی کشف می‌شود.
بررسی‌کننده‌ی بهبودیافته‌ی گذرواژه باید همه‌ی قواعدی را که یک گذرواژه‌ی مشخص نقض می‌کند، یک‌جا نشان دهد.

قواعد این بررسی‌کننده‌ی گذرواژه همان قواعد تمرین پیشین «Password Checker» است:

- باید ۱۲ کاراکتر یا بیشتر داشته باشد
- باید دست‌کم یک حرف بزرگ داشته باشد
- باید دست‌کم یک حرف کوچک داشته باشد
- باید دست‌کم یک رقم داشته باشد
- باید دست‌کم یک نماد از مجموعه‌ی `!@#$%^&\*` داشته باشد

## 1. نوع «اتحادیه‌ی تفکیک‌شده»ی `PasswordError` را طوری تغییر دهید که بتوان با تک‌تک مقادیر آن مانند «پرچم» رفتار کرد

توجه کنید که تا زمانی که این مرحله‌ی ضروری کامل نشود، آزمون‌ها کامپایل نخواهند شد.

## 2. تابع `checkPassword` را پیاده‌سازی کنید

تابع `checkPassword` گذرواژه‌ی داده‌شده را بر اساس قواعد یادشده بررسی می‌کند.
این تابع باید یک مقدار `Result` برگرداند؛ زمانی که گذرواژه همه‌ی قواعد را برآورده می‌کند `Ok` برگردانده می‌شود و زمانی که یک یا چند قاعده را نقض می‌کند، یک مقدار `Error`.
اگر گذرواژه‌ی داده‌شده چند قاعده را نقض کند، مقدار `PasswordError` باید همه‌ی قواعد نقض‌شده را نشان دهد.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. تابع ``getStatusPhrases` را پیاده‌سازی کنید

تابع `getStatusPhrases` مجموعه‌ای از رشته‌ها را برمی‌گرداند که هر کدام شامل عبارتی خوانا برای انسان و متناظر با یکی از خطاهای موجود در نتیجه‌ی بازگشتی از `checkPassword` است.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
