# دستورالعمل‌ها

شما یک پیتزافروشی دارید و سه نوع پیتزا عرضه می‌کنید:

- Margherita: ۷ دلار
- Caprese: ۹ دلار
- Formaggio: ۱۰ دلار

اگر مشتری‌ها بخواهند، می‌توانند به تعداد نامحدود گزینه‌ی اضافه سفارش دهند: یا «ExtraSauce» به قیمت ۱ دلار یا «ExtraToppings» به قیمت ۲ دلار.

وظیفه‌ی شما نوشتن کدی است که به مشتری کمک می‌کند هزینه‌اش را حساب کند.

## محاسبه‌ی قیمت یک پیتزا

با دریافت اسم پیتزا به عنوان آرگومان اول و هر تعداد گزینه‌ی اضافه، قیمت پیتزا را بر حسب دلار محاسبه کنید.

```js
pizzaPrice('Margherita');
// => 7

pizzaPrice('Caprese', 'ExtraSauce', 'ExtraToppings');
// => 12

pizzaPrice(
  'Caprese',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
);
// => 17
```

## محاسبه‌ی قیمت کل یک سفارش

تابع شما با فهرستی از `PizzaOrder`ها فراخوانی می‌شود و باید قیمت کل سفارش را بر حسب دلار برگرداند.
هر `PizzaOrder` یک ویژگی `pizza` دارد، یعنی اسم پیتزا، و یک ویژگی `extras`، یعنی فهرست گزینه‌های اضافه.

```js
const margherita = new PizzaOrder('Margherita');
const caprese = new PizzaOrder('Caprese', 'ExtraToppings');
orderPrice([margherita, caprese]);
// => 18
```

متوجه می‌شوید که نمی‌توانید این را با بازگشت بنویسید، چون یک تست با تعداد بسیار زیادی سفارش، خطای `Maximum call stack size exceeded` را ایجاد می‌کند.
نگران نباشید، این عمدی است؛ این تابع را با یک حلقه‌ی دستوری پیاده‌سازی کنید!
گزینه‌های زیادی دارید، از جمله استفاده از `reduce` یا یک حلقه‌ی `for`، و نه فقط این‌ها.

وقتی مفسر JavaScript در حال اجرای کد JavaScript است، روی یک ساختار داده به اسم «پشته» ثبت می‌کند که وارد چه توابعی شده است (فراخوانی کدام توابع را شروع کرده است).
وقتی تابع برمی‌گردد (پایان می‌یابد)، از پشته حذف می‌شود.

اما این پشته اندازه‌ی محدودی دارد.
رایج‌ترین اشتباهی که رخ می‌دهد، تابع بازگشتی‌ای است که هرگز تمام نمی‌شود.
هر فراخوانی روی پشته قرار می‌گیرد، اما پیش از آنکه برگردد، فراخوانی دیگری روی پشته قرار می‌گیرد.

```javascript
function kaboom() {
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded
```

ردیابی پشته‌ی این خطا همان خط را بارها و بارها نشان می‌دهد، که منطقی است، چون تابع خودش را فراخوانی می‌کند.
گرچه در بیشتر موارد کاربرد عملی واقعی ندارد، می‌توانید بفهمید این پشته چقدر می‌تواند بلند شود.

```javascript
let calls = 0;
function kaboom() {
  calls +=1 ;
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded

console.log(calls)
// => a number, generally higher than 10.000
```

برای خطای پشته‌ی فراخوانی که یک تابع بازگشتی همگام ایجاد می‌کند، فقط دو راه‌حل عملی وجود دارد:
- مطمئن شوید توابع پیش از رسیدن به حد پشته برمی‌گردند، معمولاً با افزودن یا اصلاح یک حالت پایه.
- تابع بازگشتی را به یک حلقه‌ی دستوری بازنویسی کنید؛ این حلقه بدنه‌ی حلقه را اجرا می‌کند بدون آنکه لازم باشد وارد تابعی شود، و بنابراین پشته بزرگ‌تر نمی‌شود.
