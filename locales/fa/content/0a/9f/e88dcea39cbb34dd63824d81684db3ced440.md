# مقدمه

## مبانی ۱

### مقدار ثابت و تابع

یک مقدار ثابت با `name = expression` تعریف می‌شود؛ در Elm هر چیزی جز تعریف‌ها یک «عبارت» است.

```elm
five = 5

six = 3 + 3
```

تابع‌ها با `name parameters... = expression` تعریف می‌شوند و «پارامتر»ها تنها با فاصله از هم جدا می‌شوند.

```elm
add number1 number2 = number1 + number2
```

فراخوانی کردن یک تابع هم یک عبارت است و با نوشتن اسم تابع و دادن «آرگومان» برای هر یک از پارامترهای آن انجام می‌شود؛ آرگومان‌ها هم درست مانند تعریف تابع با فاصله از هم جدا می‌شوند.

```elm
five = add 2 3
```

از پرانتز می‌توان برای تعیین ترتیب ارزیابی یک عبارت استفاده کرد.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### تورفتگی / فاصله‌های معنادار

Elm برای تعیین مرزهای کد از نشانه‌های نگارشی مانند آکولاد، پرانتز یا نقطه‌ویرگول استفاده نمی‌کند. در عوض از فاصله‌ها و تورفتگی‌ها بهره می‌برد.

- تعریف ماژول، `import` و تابع‌های سطح بالا باید از چپ‌ترین ستون شروع شوند.
- اگر یک عبارت به چند خط تقسیم شود، کدی که بخشی از آن عبارت است باید با حداقل یک فاصله زیر آن عبارت تورفتگی داشته باشد.
- بخش‌هایی از عبارت که با هم گروه‌بندی شده‌اند باید با تعداد فاصله‌ی برابر تورفتگی داشته باشند.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### ماژول

هر فایل در Elm یک ماژول است و باید پیش از هر کد دیگری یک دستور `module` داشته باشد.
اسم ماژول باید با اسم فایلش مطابقت داشته باشد، پس ماژول `Calculator` باید در فایل Calculator.elm باشد.
هرچه داخل یک ماژول تعریف شود، به همان ماژول محدود می‌ماند و از بیرون آن قابل دسترسی نیست، مگر اینکه در `exposing` فهرست شده باشد.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### کامنت

کامنت متنی است داخل فایل Elm که به‌عنوان کد تفسیر نمی‌شود.
کامنت عمدتاً برای این است که خودتان و دیگر برنامه‌نویسان آن را بخوانید.
برای کامنت‌های تک‌خطی یک نحوه‌ی نگارش سبک بر پایه‌ی دو خط تیره وجود دارد.
کامنت‌های چندخطی هم با جفت `{-` و `-}` به‌عنوان جداکننده‌های آغاز و پایان امکان‌پذیر است.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
