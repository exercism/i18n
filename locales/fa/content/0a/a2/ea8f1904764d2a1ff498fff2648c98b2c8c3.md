# پیوست دستورالعمل‌ها

شما باید این تمرین را با استفاده از گرامر بند معین (DGC) پیاده‌سازی کنید.
از DCG می‌توان نه‌فقط برای تجزیه‌ی دنباله‌ها (لیست‌ها) استفاده کرد، بلکه برای تولید، تکمیل و بررسی همان دنباله‌ها نیز.

## کتابخانه

فایل‌های پیاده‌سازی اولیه شامل خط زیر است:

```prolog
:- use_module(library(dcg/basics)).
```

این خط تضمین می‌کند که می‌توان از کتابخانه‌ی `dcg/basics` استفاده کرد، و همین باید برای حل این تمرین کافی باشد.
