# مقدمه

## فضای نام

یکی از روش‌های مهم برای سازماندهی کد، استفاده از «فضای نام» است.
کلاس‌ها و ماژول‌ها فضای نام فراهم می‌کنند.
ممکن است اسم دو متد با هم تداخل پیدا کند که با قرار دادن آن‌ها در فضای نام‌های متفاوت برطرف می‌شود.
فضای نام‌ها می‌توانند تودرتو باشند، که می‌تواند در ساختاردهی به کدبیس‌های بزرگ کمک کند.
دسترسی به فضای نام‌ها با عملگر تفکیک دامنه، `::`، انجام می‌شود.

مثال زیر استفاده از دو متد متفاوت `foo` را نشان می‌دهد.
این دو با قرار دادن فضای نام هر کدام به‌عنوان پیشوند، در کنار هم به کار می‌روند.

```ruby
class MyNamespace
  def self.foo
    44
  end

  class MyInnerNamespace
    def self.baz
      90
    end
  end
end

class MyOtherNamespace
  def self.foo
    -2
  end
end

p MyNamespace::foo + MyOtherNamespace::foo * MyNamespace::MyInnerNamespace::baz  # => -136
```

توجه کنید که فضای نام‌ها بر اساس محل قرار گرفتن کدِ در حال اجرا تفسیر می‌شوند.
برای اشاره به چیزی در فضای نام *ریشه* (یعنی بیرون از همه‌ی فضای نام‌های تعریف‌شده)، از `::` شروع کنید.

برای مثال:

```ruby
class Example
  def self.example
    5
  end
end

class MyNamespace

  class Example
    def self.example
      10
    end
  end

  def self.call_example
    p Example::example  # => 10
    p ::Example::example  # => 5
  end
end
```
