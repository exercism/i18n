# پیوست دستورالعمل‌ها

## ثبات

| ثبات     | کاربرد  | نوع      | توضیح                     |
| -------- | ------- | -------- | ------------------------- |
| `$a0`    | ورودی   | عدد صحیح | عدد زیر رادیکال           |
| `$v0`    | خروجی   | عدد صحیح | جذر                       |
| `$t0-9`  | موقت    | هر نوع   | برای ذخیره‌سازی موقت به کار می‌رود |
