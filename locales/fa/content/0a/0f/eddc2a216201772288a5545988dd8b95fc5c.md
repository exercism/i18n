# از متد `main` استفاده نکنید

متد `main` را از کد خود حذف کنید.
تست‌های تمرین نیازی به داشتن متد `main` در راه‌حل ندارند و داشتن آن، خواندن کد را کمی سخت‌تر می‌کند.

معمولاً متد `main` را برای کمک به دیباگ کردن کد اضافه می‌کنند.
اما روش بهتر این است که کد را همراه با اجرای یک یا چند تست واحد دیباگ کنید.
این مزیت را هم دارد که می‌توانید روی دیباگ کردن یک تست مشخص تمرکز کنید.

در ادامه چند پیوند آمده که توضیح می‌دهد چطور کد Java را همراه با اجرای تست‌های واحد در محیط‌های توسعه‌ی مختلف (IDE) دیباگ کنید:

- [اجرا و دیباگ تست‌های Java در Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [دیباگ تست‌ها در IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
