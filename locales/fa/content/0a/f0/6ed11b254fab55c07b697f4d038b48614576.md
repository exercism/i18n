# مقدمه

## مقایسه

### برابری

با عملگر برابری `(==)` می‌توان انواع Elm را از نظر «یکسان بودن» بررسی کرد.
عملگر نابرابری `(/=)` است (*نه* `!=` مانند بسیاری از زبان‌ها).
عملگر برابری روی لیترال‌ها، تاپل‌ها، رکوردها و انواع سفارشی کار می‌کند.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

توجه کنید که *هرگز نباید* توابع را مقایسه کنید، چون این کار باعث می‌شود برنامه در زمان اجرا از کار بیفتد.

### مقایسه‌ها

عملگرهای مقایسه‌ی `(<)`، `(<=)`، `(>)`، `(>=)` و توابع `min`، `max` و `compare` روی انواع `comparable` کار می‌کنند.
نوع `comparable` یک نوع ویژه است که همه‌ی انواع توکاری را که قابل مقایسه‌اند در خود گرد می‌آورد: اعداد، نویسه‌ها، رشته‌ها، لیست‌هایی از مقدارهای comparable و تاپل‌هایی از مقدارهای comparable.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

مقدارهای انواع دیگر مانند رکوردها یا انواع سفارشی را نمی‌توان مستقیماً مقایسه کرد.

برخی انواع توکار نیاز دارند که محتوایشان `comparable` باشد، مانند کلیدهای `Set` یا `Dict`، چون ساختارشان به یک ترتیب درونی وابسته است.

لیست‌های مقدارهای `comparable` را می‌توان با `List.sort` مرتب کرد و لیست‌های مقدارهایی که می‌توان آن‌ها را به مقدارهای comparable نگاشت، با `List.sortBy` مرتب می‌شوند.
اگر به مرتب‌سازی سلسله‌مراتبی نیاز دارید (مرتب‌سازی بر اساس یک ویژگی و شکستن تساوی با ویژگی دیگر)، می‌توان از تاپل‌ها یا لیست‌ها هم همراه با `List.sortBy` استفاده کرد، چون تاپل‌ها و لیست‌ها به ترتیب لغت‌نامه‌ای مرتب می‌شوند.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

تابع `compare` دو مقدار `comparable` می‌گیرد و یک `Order` برمی‌گرداند.
`Order` نوعی است که در یک عملیات واحد بررسی می‌کند یک مقدار بزرگ‌تر (`GT`)، برابر (`EQ`) یا کوچک‌تر (`LT`) از دیگری است.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

می‌توان توابع مقایسه را برای انواع دلخواه ساخت و مثلاً از آن‌ها برای مرتب‌سازی با `List.sortWith` استفاده کرد:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
