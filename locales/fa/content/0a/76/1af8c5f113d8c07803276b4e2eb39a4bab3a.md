# ترتیب حاشیه‌نویسی‌های تابع

طبق قرارداد، حاشیه‌نویسی‌های `@doc` باید پیش از حاشیه‌نویسی‌های `@spec` بیایند و حاشیه‌نویسی‌های `@spec` باید بلافاصله پیش از خود تابع قرار بگیرند. اگر تابع چند بند داشته باشد، حاشیه‌نویسی‌ها باید پیش از بند اول بیایند.

مثال:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
