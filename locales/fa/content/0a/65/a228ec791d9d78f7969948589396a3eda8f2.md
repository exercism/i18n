# مقدمه

یک نوع زمانی «نوع عمومی» است که بتواند با استفاده از یک «پارامتر نوع»، مقادیر هر نوعی را در خود نگه دارد.

برای مثال، این نوع `Box` پارامتر نوع `a` را دارد (که با حروف کوچک نوشته می‌شود).

```gleam
pub type Box(a) {
  Box(a)
}
```

پارامتر نوع `a` جانگهدار هر نوعی است، بنابراین می‌توان از `Box` با رشته‌ها، اعداد صحیح یا هر نوع دیگری استفاده کرد.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

یک نوع می‌تواند چندین پارامتر نوع داشته باشد که با کاما از هم جدا می‌شوند.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## توابع عمومی

از پارامترهای نوع می‌توان در آرگومان‌های توابع هم استفاده کرد.

این تابع مقداری از نوع `a` می‌گیرد و تابعی را دو بار فراخوانی می‌کند که یک `a` می‌گیرد و یک `b` برمی‌گرداند.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
