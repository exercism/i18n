# دستورالعمل‌ها

در این تمرین، منطق مأموریت یک بازی نقش‌آفرینی جدید را پیاده‌سازی می‌کنید که یکی از دوستانتان در حال ساخت آن است. شخصیت اصلی بازی آنالین است، دختری شجاع با یک سگ خانگی سرسخت و وفادار. متأسفانه فاجعه‌ای رخ می‌دهد و بهترین دوستش در حالی که در جنگل به دنبال توت می‌گشت، دزدیده می‌شود. آنالین تلاش می‌کند بهترین دوستش را پیدا کند و آزاد کند و در این مأموریت می‌تواند سگش را هم همراه خود ببرد.

پس از مدتی که رد بهترین دوستش را دنبال می‌کند، اردوگاهی را پیدا می‌کند که بهترین دوستش در آن زندانی است. معلوم می‌شود دو آدم‌ربا وجود دارد: یک شوالیه‌ی نیرومند و یک کماندار حیله‌گر.

آنالین پس از یافتن آدم‌رباها بررسی می‌کند که کدام‌یک از کارهای زیر را می‌تواند انجام دهد:

- «حمله‌ی سریع»: اگر شوالیه خواب باشد، می‌توان حمله‌ی سریع انجام داد؛ چون پوشیدن زره برایش زمان می‌برد و در نتیجه آسیب‌پذیر خواهد بود.
- «جاسوسی»: اگر دست‌کم یکی از آنان بیدار باشد، می‌توان از گروه جاسوسی کرد. در غیر این صورت، جاسوسی اتلاف وقت است.
- «علامت دادن به زندانی»: اگر زندانی بیدار و کماندار خواب باشد، می‌توان با صدای پرندگان به زندانی علامت داد، چون کمانداران در علامت‌دهی با صدای پرندگان آموزش دیده‌اند و ممکن است پیام را رهگیری کنند.
- _«آزاد کردن زندانی»_: آنالین می‌تواند تلاش کند مخفیانه به اردوگاه نفوذ کند تا زندانی را آزاد کند.
  این کار پرخطری است و فقط به یکی از دو روش زیر می‌تواند موفق شود:
  - اگر آنالین سگ خانگی‌اش را همراه داشته باشد و کماندار خواب باشد، می‌تواند زندانی را نجات دهد.
    شوالیه از سگ می‌ترسد و کماندار فرصت نمی‌کند آماده شود، پیش از آنکه آنالین و زندانی بگریزند.
  - اگر آنالین سگش را همراه نداشته باشد، باید خودش و زندانی بسیار مخفیانه عمل کنند!
    آنالین می‌تواند زندانی را آزاد کند اگر زندانی بیدار باشد و شوالیه و کماندار هر دو خواب باشند، اما اگر زندانی خواب باشد، نمی‌توان نجاتش داد: ظاهر شدن ناگهانی آنالین زندانی را می‌ترساند و شوالیه و کماندار را بیدار می‌کند.

شما چهار کار دارید: پیاده‌سازی منطقی که بر اساس وضعیت سه شخصیت موجود در جنگل و حضور یا عدم حضور سگ خانگی آنالین تعیین کند آیا کارهای بالا در دسترس هستند یا نه.

## 1. بررسی اینکه آیا کار «حمله‌ی سریع» ممکن است

تابعی به نام `canExecuteFastAttack` پیاده‌سازی کنید که یک مقدار منطقی می‌گیرد و نشان می‌دهد آیا شوالیه بیدار است یا نه. این تابع اگر کار «حمله‌ی سریع» بر اساس وضعیت شخصیت در دسترس باشد `true` برمی‌گرداند. در غیر این صورت `false` برمی‌گرداند:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. بررسی اینکه آیا کار «جاسوسی» ممکن است

تابعی به نام `canSpy` پیاده‌سازی کنید که سه مقدار منطقی می‌گیرد و به‌ترتیب نشان می‌دهد آیا شوالیه، کماندار و زندانی بیدار هستند یا نه. این تابع اگر کار «جاسوسی» بر اساس وضعیت شخصیت‌ها در دسترس باشد `true` برمی‌گرداند. در غیر این صورت `false` برمی‌گرداند:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. بررسی اینکه آیا کار «علامت دادن به زندانی» ممکن است

تابعی به نام `canSignalPrisoner` پیاده‌سازی کنید که دو مقدار منطقی می‌گیرد و به‌ترتیب نشان می‌دهد آیا کماندار و زندانی بیدار هستند یا نه. این تابع اگر کار «علامت دادن به زندانی» بر اساس وضعیت شخصیت‌ها در دسترس باشد `true` برمی‌گرداند. در غیر این صورت `false` برمی‌گرداند:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. بررسی اینکه آیا کار «آزاد کردن زندانی» ممکن است

تابعی به نام `canFreePrisoner` پیاده‌سازی کنید که چهار مقدار منطقی می‌گیرد. سه پارامتر اول به‌ترتیب نشان می‌دهند آیا شوالیه، کماندار و زندانی بیدار هستند یا نه. پارامتر آخر نشان می‌دهد آیا سگ خانگی آنالین حاضر است یا نه. این تابع اگر کار «آزاد کردن زندانی» بر اساس وضعیت شخصیت‌ها و حضور سگ خانگی آنالین در دسترس باشد `true` برمی‌گرداند. در غیر این صورت `false` برمی‌گرداند:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
