# مقدمه

مقدار `null` در JavaScript نشان‌دهنده‌ی نبود عمدی یک مقدار شیء است. این مقدار یکی از انواع اولیه‌ی JavaScript است.

```javascript
// I do not have an apple.
var apple = null;
apple; // => null

// null is treated as falsy for boolean operations, therefore
!apple; // => true
!!apple; // => false
```
