# Tests

برای اجرای Tests این مسیر، باید DUnitX را نصب کنید. لطفاً برای اطلاعات بیشتر [دستورالعمل‌های نصب](http://www.exercism.org/docs/tracks/delphi/installation) را ببینید.

### بارگذاری تمرین در Delphi

اگر Delphi به‌درستی نصب شده باشد و انواع فایل `*.dpr` با Delphi مرتبط شده باشند، دوبار کلیک کردن روی فایل `*.dpr` ارائه‌شده، Delphi را اجرا می‌کند و تمرین/پروژه را بارگذاری می‌کند. میانبر صفحه‌کلید برای کامپایل پروژه `control + F9` است، یا فشردن `F9` پروژه را کامپایل و اجرا می‌کند.

در غیر این صورت می‌توانید Delphi را اجرا کنید و پروژه‌تان را از طریق منوی کشویی `File` بارگذاری کنید.
