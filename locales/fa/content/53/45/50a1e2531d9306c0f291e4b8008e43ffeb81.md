# پیوست دستورالعمل‌ها

## رجیسترها

| رجیستر | کاربرد        | نوع     | توضیح                              |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | ورودی        | عدد صحیح | عدد طبیعی که باید تجزیه شود     |
| `$a1`    | ورودی/خروجی | آدرس | آرایه‌ی مقصد برای عوامل اول |
| `$v0`    | خروجی       | عدد صحیح | تعداد عوامل                   |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت استفاده می‌شود          |
