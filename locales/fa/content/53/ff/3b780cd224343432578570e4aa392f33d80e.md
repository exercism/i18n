# درباره

مانند بیشتر زبان‌های برنامه‌نویسی، Gleam هم «عوارض جانبی» دارد؛ یعنی توابع می‌توانند علاوه بر برگرداندن یک مقدار، وضعیت دنیای بیرون را بخوانند و تغییر دهند.

ماژول `gleam/io` در کتابخانه‌ی استاندارد Gleam توابعی برای چاپ رشته‌ها در کنسول فراهم می‌کند.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

بسته‌های دیگر ممکن است توابع ورودی/خروجی دیگری فراهم کنند، مانند `simplifile`، بسته‌ای که توابعی برای خواندن و نوشتن فایل‌ها در اختیار می‌گذارد.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
