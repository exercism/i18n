# نصب

## نصب Clojure CLI

Clojure ابزارهای خط فرمانی برای این کارها در اختیار شما می‌گذارد: اجرای یک REPL تعاملی (حلقه‌ی خواندن، ارزیابی و چاپ)، اجرای برنامه‌های Clojure و ارزیابی عبارت‌های Clojure.
توصیه می‌کنیم در تمرین‌ها از Clojure CLI استفاده کنید. برای نصب [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
برای راهنمای نصب روی Windows به [نصب Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows) مراجعه کنید.

### Linux
برای راهنمای نصب روی بیشتر پلتفرم‌ها به [نصب Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux) مراجعه کنید.

### Homebrew برای Mac OS X
Homebrew خود را به‌روزرسانی کنید:

``` bash
$ brew update
```

Clojure CLI را نصب کنید:
``` bash
$ brew install node clojure/tools/clojure
```

برای محیط Node به `Node` نیاز است.

## آزمایش نصب

برای اطمینان از درستی نصب، دستور `clojure --help` را اجرا کنید؛ اگر همه‌چیز درست پیش رفته باشد، نسخه را به شما نشان می‌دهد.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
