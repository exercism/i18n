# نصب

## نصب .NET 10

مسیر Visual Basic از .NET 10 استفاده می‌کند.
برای ساخت و تست تمرین‌ها به‌صورت محلی، [SDK .NET 10 مناسب سیستم‌عامل خود را نصب کنید][install-sdk]:
SDK را نصب کنید، نه فقط runtime.

## بررسی نصب

یک ترمینال جدید باز کنید و اجرا کنید:

```bash
dotnet --version
```

این دستور باید `10.0.0` یا جدیدتر را نمایش دهد.

## پشتیبانی ویرایشگرها

برای تکمیل تمرین‌ها، فقط به .NET SDK و یک ویرایشگر متن ساده نیاز دارید.
برای قابلیت‌های پیشرفته‌تری مانند تکمیل خودکار کد و دیباگ کردن، یکی از این ویرایشگرها را در نظر بگیرید:

- [Visual Studio 2026][visual-studio] روی Windows
- [Visual Studio Code][visual-studio-code] روی Windows، Linux یا macOS
- [JetBrains Rider][rider] روی Windows، Linux یا macOS

[rider]: https://www.jetbrains.com/rider/
