# درباره

وقتی روی یک دنباله گام برمی‌دارید، گاهی خودِ عنصر کافی نیست: به موقعیت هم نیاز دارید. واژه‌های پیمایش *اندیس‌محور* در Factor هر دو را به «کوتیشن» هر عنصر می‌دهند، با اندیس در بالای پشته. `times` واژه‌ی مرتبط برای پیمایش شمارشی بدون یک دنباله‌ی زیربنایی است.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| واژه         | اثر                                                                  |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`، اما به پایین نگاه کنید                       |

یک نکته‌ی ظریف درباره‌ی `times`: هرچند کوتیشن آن به‌صورت `( -- )` مستند شده است، خود واژه `inline` است، بنابراین یک کوتیشن متوازن از نظر اثر مانند `( str -- str )` به‌خوبی کار می‌کند و پشته را در طول پیمایش‌ها با خود می‌برد. این به شما یک انباشتگر شمارشی می‌دهد، بدون هیچ وضعیت تغییرپذیری:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

همین ترفند برای `each-index` و `map-index` هم کار می‌کند: اثر اعلام‌شده‌ی هر عنصر یک *حداقل* است، نه یک حداکثر.
