# درباره

هر زمان که مجموعه‌ی ثابتی از مقادیر ثابت داشته باشید، می‌توانید از [انواع شمارشی][enumeration types] استفاده کنید. استفاده از `enum` روشی ایمن از نظر نوع برای کار با مقادیر ثابت در اختیارتان می‌گذارد. تعریف enum با «کلیدواژه»ی `enum` انجام می‌شود. برای اشاره به هر عضو enum، اسم enum و یک نقطه را پیش از آن می‌آورید (مثلاً `Status.Active`).

هر عضو enum، پیوندی از یک اسم و یک مقدار `int` است. اگر عضو اول مقدار صریحی نداشته باشد، مقدارش `0` در نظر گرفته می‌شود. اگر برای عضوی مقدار صریحی تعریف نشود، مقدارش به‌طور خودکار برابر با مقدار عضو قبلی به‌علاوه‌ی `1` در نظر گرفته می‌شود.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

enumها بسیار اعلانی‌اند. دو فراخوانی متد زیر را مقایسه کنید:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

برای کسی که کد را می‌خواند، نسخه‌ی دوم (با enum) آسان‌تر فهمیده می‌شود.

## enumهای نوع عددی

گرچه نوع عددی پیش‌فرض مقادیر `int` است، می‌توان آن را با مشخص کردن صریح هر نوع [عدد صحیح][integral numeric] دیگری تغییر داد.

enum زیر از نوع عددی `byte` برای مقادیرش استفاده می‌کند:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## تبدیل به یک عضو enum

هر زمان که بخواهید چیزی شبیه یک مقدار منطقی را مدل کنید، باید همیشه استفاده از enum را در نظر بگیرید. علاوه بر مزایای خوانایی که پیش‌تر گفته شد، enumها مزیت دیگری هم نسبت به مقادیر منطقی دارند: می‌توان همیشه مقادیر تازه‌ای به یک enum افزود، در حالی که یک مقدار منطقی تنها `true` یا `false` خواهد بود. پس استفاده از enum آینده‌نگرانه‌تر است.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

توجه داشته باشید که هرچند _می‌توان_ مقادیر صحیح را به یک enum تبدیل نوع کرد، این کار زمانی که مقدار صحیح به هیچ مقداری از enum نگاشت نشود می‌تواند به نتایج غیرمنتظره منجر شود:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## تجزیه‌ی یک enum

گاهی اوقات مفید است که یک رشته را بر اساس اسمش با [`Enum.Parse`][enum parse] به یک عضو enum تبدیل کنید:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

برای بررسی این که اسمی یا مقداری در enum وجود دارد یا نه، می‌توانید از [`Enum.TryParse`][enum tryparse] یا [`Enum.IsDefined`][enum isdefined] استفاده کنید؛ هر دو یک مقدار منطقی برمی‌گردانند که نشان می‌دهد عضو enum وجود دارد یا نه:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
