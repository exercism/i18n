# رشته

«رشته» مجموعه‌ای از نویسه‌ها است که داخل نشانه‌های نقل‌قول قرار می‌گیرد.
از هر دو نوع نقل‌قول تک و دوتایی پشتیبانی می‌شود.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## جای‌گذاری متغیر در رشته

در رشته‌هایی که داخل نقل‌قول دوتایی قرار دارند، اگر به متغیری که در محدوده در دسترس است ارجاع داده شود، مقدارش در رشته درج می‌شود.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## پشتیبانی از کدگذاری نویسه‌ها

در گذشته، توابع رشته در PHP فقط از نویسه‌های ASCII پشتیبانی می‌کردند و کدگذاری‌های مدرن Unicode را پشتیبانی نمی‌کردند.
هر نویسه‌ی ASCII یک بایت است، اما طول نویسه‌های Unicode می‌تواند ۱ تا ۴ بایت باشد.
اگر می‌خواهید رشته‌های Unicode را به‌صورت ایمن دست‌کاری کنید، به [نسخه‌های چندبایتی][multi-byte-fns] همان توابع قدیمی مراجعه کنید.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
