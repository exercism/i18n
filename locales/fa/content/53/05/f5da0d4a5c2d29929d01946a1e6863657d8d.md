# تست‌ها

برای تست کردن راه‌حل خود کافی است این دستور را اجرا کنید:

```bash
make test
```

این دستور فایل تست `<exercise-name>-test.ys` را اجرا می‌کند که شامل همه‌ی
تست‌هایی است که راه‌حل‌تان باید با موفقیت از آن‌ها بگذرد تا درست باشد.
بهتر است فایل تست را مطالعه کنید تا دقیقاً بفهمید راه‌حل‌تان باید چه کاری
انجام دهد.

> توجه: بار اولی که `make test` را اجرا می‌کنید، همچنین مطمئن می‌شود که
> نسخه‌ی درست مفسر `ys` YAMLScript در جای درست نصب شود.

اگر پیش از تغییر دادن هر فایلی `make test` را اجرا کنید، همه‌ی تست‌ها شکست می‌خورند.
این رفتار درست و مورد انتظار است.
روند معمول توسعه‌ی تمرین این است که راه‌حل خود را مرحله‌به‌مرحله بهتر کنید و
بعد از هر تغییر `make test` را اجرا کنید، تا زمانی که همه‌ی تست‌ها موفق شوند.

اگر می‌خواهید فقط یک تست مشخص را اجرا کنید (در حالی که روی همان بخش از راه‌حل
تمرکز دارید)، می‌توانید این جفت کلید/مقدار را به آن تست اضافه کنید:

```yaml
  ONLY: true
```

اگر می‌خواهید برخی تست‌های خاص را نادیده بگیرید (در حالی که روی بخش‌های دیگر
راه‌حل کار می‌کنید)، می‌توانید این جفت کلید/مقدار را به آن تست‌ها اضافه کنید:

```yaml
  SKIP: true
```


## پیش‌نیازهای تست

YAMLScript در حال حاضر روی MacOS و Linux اجرا می‌شود.

رایانه‌تان باید این دستورهای بسیار رایج را نصب داشته باشد:

* `bash` - می‌توانید تست‌ها را زیر هر پوسته‌ای اجرا کنید، اما `bash` باید در دسترس باشد.
* `make` - برای اجرای تست‌ها باید از GNU `make` استفاده کنید.
  در برخی محیط‌ها ممکن است نامی متفاوت از `make` داشته باشد.
  احتمالاً `gmake`.
* `prove` - این برنامه بخشی از هر نصب معمولی Perl است.
* `curl` - اگر `ys` از قبل نصب نشده باشد، برای نصب آن به کار می‌رود.

به احتمال بسیار زیاد همه‌ی این برنامه‌ها از قبل روی سیستم شما نصب هستند.
