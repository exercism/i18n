# بازه

[بازه][range] فاصله‌ای بین دو مقدار را نشان می‌دهد.
رایج‌ترین نوع‌هایی که از بازه پشتیبانی می‌کنند `Integer` و `String` هستند.
از بازه‌ها می‌توان برای کارهای زیادی استفاده کرد؛ مثل ساختن سریع یک مجموعه، برش دادن رشته‌ها، بررسی اینکه مقداری در بازه هست یا نه، و تکرار.
بازه‌ها با عملگر بازه یعنی `..` یا `...` ساخته می‌شوند (به ترتیب شامل مقدار پایانی و بدون در نظر گرفتن آن).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

دلیل وجود دو عملگر بازه این است که بتوان بازه‌هایی ساخت که مقدار پایانی را شامل شوند یا نشوند؛ این کار مثلاً هنگام کار با اندیس‌هایی که از صفر شروع می‌شوند مفید است.

بازه‌ها را می‌توان با سازنده‌ی `Range` هم ساخت.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
وقتی در Ruby با عملگرهای بازه یعنی `..` یا `...` یک بازه می‌سازید و می‌خواهید «متد»ی را روی آن بازه فراخوانی کنید، باید بازه را داخل پرانتز بگذارید.
دلیلش این است که در غیر این صورت، متد روی آرگومان دوم عملگر بازه فراخوانی می‌شود.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## به دست آوردن زیررشته‌ها

وقتی می‌خواهید رشته‌ای را برش دهید، می‌توانید با عملگر بازه یک «زیررشته» به دست آورید.
یعنی با ساختن بازه‌ای از اندیس شروع تا اندیس پایان زیررشته.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

همچنین می‌توانید از اندیس‌های منفی استفاده کنید تا زیررشته را از انتهای رشته بگیرید.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## متدهای بازه

بازه‌ها مجموعه‌ای از متدها دارند که می‌توان با آن‌ها کار کرد.
برای نمونه، با این متدها می‌توان مجموع همه‌ی مقادیر بازه را به دست آورد یا بررسی کرد که بازه مقداری را شامل می‌شود یا نه.

| متد                     | توضیح                                                                   | مثال                            |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | مجموع همه‌ی مقادیر بازه را برمی‌گرداند                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | اندازه‌ی بازه را برمی‌گرداند                                            | `(1..5).size # => 5`            |
| [`include?`][indlude]   | اگر بازه مقدار داده‌شده را شامل شود `true` و در غیر این صورت `false` را برمی‌گرداند | `(1..5).include?(3) # => true` |

## بازه‌های بی‌پایان و بی‌آغاز

یک بازه می‌تواند بی‌پایان یا بی‌آغاز باشد.
در بازه‌ی بی‌پایان یا بی‌آغاز، مقدار شروع یا پایان `nil` است، اما هنگام تعریف بازه می‌توان `nil` را حذف کرد.

استفاده از بازه‌های بی‌آغاز و بی‌پایان وقتی مفید است که مثلاً بخواهید رشته‌ای را از ابتدا یا تا انتها برش دهید.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
اگر بازه‌ی بی‌پایان با احتیاط و روی یک مجموعه استفاده نشود، می‌تواند دنباله‌ای بی‌پایان ایجاد کند.
~~~~

## بازه‌های رشته‌ای

از رشته‌ها هم می‌توان در بازه‌ها استفاده کرد و بازه‌ای از رشته‌ها بین دو رشته به دست آورد.
رفتارش با بعضی رشته‌ها می‌تواند تا حدی غیرمنتظره باشد، پس با احتیاط از آن استفاده کنید.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
