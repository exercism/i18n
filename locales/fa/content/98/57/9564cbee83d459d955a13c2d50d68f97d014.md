# راهنمایی

## 1. تعریف تأیید

- انواع سفارشی را می‌توان با استفاده از نحوه‌ی نگارش `pub type Name { Variant1 }` تعریف کرد.

## 4. تعریف فعالیت

- انواع سفارشی حاوی داده را می‌توان با استفاده از نحوه‌ی نگارش `pub type Name { Variant1(SomeType) }` تعریف کرد.

## 5. امتیاز دادن به فعالیت

- می‌توان با استفاده از عبارات case روی واریانت‌های نوع سفارشی تطبیق الگو انجام داد.
- اگر می‌خواهید شرط دیگری به یک الگو اضافه کنید، می‌توانید با استفاده از کلیدواژه‌ی `if` یک گارد به الگو اضافه کنید.
