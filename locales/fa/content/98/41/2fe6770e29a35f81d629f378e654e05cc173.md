# سازنده‌ی رشته

یک `STR` هرگز تغییر نمی‌کند. بنابراین `+` نمی‌تواند چیزی به آن اضافه کند؛ باید رشته‌ی کاملاً تازه‌ای بسازد که محتوای هر دو را داشته باشد.

این کار یک بار اشکالی ندارد. اما در یک حلقه نه:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

هر دور، هر چه تا آن لحظه ساخته شده را در یک رشته‌ی جدید کپی می‌کند و رشته‌ی قبلی را دور می‌اندازد. ۱۰ خط یعنی ۱۰ کپی، هر کدام بلندتر از کپی قبلی. ۱۰۰ خط یعنی ۱۰۰ کپی. حجم کار با *مجذور* تعداد خطوط رشد می‌کند و حلقه‌ای که بی‌ضرر به نظر می‌رسد به بخش کند برنامه تبدیل می‌شود.

## FSTR

`FSTR` رشته‌ای است که *می‌توان* تغییرش داد؛ یک **سازنده‌ی رشته**. افزودن به آن معمولاً فقط در همان فضایی می‌نویسد که از قبل دارد؛ بنابراین حلقه‌ای روی ۱۰۰ خط، حدوداً به اندازه‌ی کار ۱۰۰ خط انجام می‌دهد، نه ۱۰۰ کپی.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

به سه نکته توجه کنید.

**`#FSTR` یک سازنده‌ی خالی می‌سازد.** `#FSTR(100)` یکی می‌سازد که از پیش جای ۱۰۰ کاراکتر در آن کنار گذاشته شده؛ وقتی اندازه معلوم است، این کار ارزشش را دارد.

**باید نتیجه را دوباره به متغیر نسبت دهید.** `script := script + ...`، هرگز `script + ...` به‌تنهایی. معمولاً نتیجه همان سازنده‌ای است که وارد شده، اما وقتی فضایش تمام شده باشد، سازنده‌ی تازه و بزرگ‌تری است؛ و نادیده گرفتن نتیجه باعث می‌شود در سازنده‌ی قدیمی بنویسید.

**`.str` در پایان.** روتینی که وعده‌ی `: STR` می‌دهد باید یک `STR` برگرداند و `.str` یکی از سازنده می‌سازد.

## چه چیزهایی می‌توان اضافه کرد

`+` روی یک `FSTR` رشته، یک کاراکتر، یک عدد صحیح یا یک مقدار منطقی را می‌پذیرد؛ بنابراین معمولاً نیازی نیست از قبل تبدیل کنید:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## خط‌های جدید

`"\n"` داخل یک رشته به معنای خط جدید است؛ یک کاراکتر که با دو کاراکتر نوشته می‌شود.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
