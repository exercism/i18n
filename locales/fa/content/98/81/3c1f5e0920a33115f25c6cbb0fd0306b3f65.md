# پیوست دستورالعمل‌ها

## واژه‌ها

یک تاپل `custom-set` تعریف کنید و آن را با `INSTANCE: custom-set set` نمونه‌ای از میکسین `set` اعلام کنید.

- `<custom-set> ( -- set )`: یک مجموعه‌ی خالی می‌سازد.
- `>custom-set ( seq -- set )`: از یک دنباله یک مجموعه می‌سازد و موارد تکراری را بی‌سروصدا حذف می‌کند.

سپس متدهای `M:` (از `sets`) را برای `custom-set` روی `members`، `in?`، `adjoin` و `set-like` ارائه دهید. وقتی اعلان `INSTANCE:` و آن چهار متد در جای خود باشند، `null?`، `union`، `intersect`، `diff`، `subset?`، `set=` و `intersects?` از واژگان `sets` همه از طریق پیاده‌سازی‌های پیش‌فرض پروتکل روی مجموعه‌ی شما کار می‌کنند. تست‌ها همان واژه‌ها را مستقیماً فراخوانی می‌کنند.

`adjoin ( elt set -- )` تغییردهنده است: اگر `elt` از قبل موجود نباشد، آن را درجا به `set` اضافه می‌کند.
