# مقدمه

هش‌ها یک نوع داده در Perl هستند که مجموعه‌ای بدون ترتیب از کلیدهای رشته‌ای جفت‌شده با مقدارهای اسکالر را در خود دارند.

معمولاً یک متغیر هش را با تخصیص دادن یک فهرست به آن پر می‌کنند، برای نمونه `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

فهرست‌ها معمولاً با کاما از هم جدا می‌شوند، اما اغلب چیزی را می‌بینید که به آن «کامای چاق» `=>` می‌گویند و برای جدا کردن کلیدها و مقدارها در یک فهرست به کار می‌رود.
رفتار آن تقریباً با یک کاما یکسان است، اما این مزیت اضافه را دارد که عنصر سمت چپ را به‌صورت یک رشته تفسیر می‌کند.

هش‌ها را می‌توان با تخصیص دادن به کلیدهای تک‌تک پر کرد، برای نمونه `$scores{Alice} = 10;`.

مقدارهای یک هش را می‌توان با مشخص کردن کلیدها از طریق یک اندیس به دست آورد، برای نمونه `$scores{Bob} # 15`.

کلیدها در یک هش یکتا هستند.
اگر یک کلید چند بار داده شود، تنها آخرین مقدار داده‌شده نگه داشته می‌شود.

## توابع

توابعی که برای کار با هش‌ها به کار می‌روند شامل [keys][keys] و [values][values] هستند که برای بازیابی بخش‌های متناظر یک هش به‌صورت یک فهرست استفاده می‌شوند.
فهرست‌هایی که توابع [keys][keys] و [values][values] برمی‌گردانند می‌توانند برای توابع فهرست مانند [grep][grep]، [map][map] و [sort][sort] و همچنین حلقه‌های [for][for] مفید باشند.

از دیگر توابع هش می‌توان به [exists][exists] اشاره کرد که بررسی می‌کند آیا کلیدی در هش وجود دارد یا نه (حتی اگر مقدارش `undef` باشد)، و [delete][delete] که یک کلید را از هش حذف می‌کند.

## تفاوت سیگیل

وقتی مقدارهای یک هش را به دست می‌آورید، سیگیل به‌کاررفته نتیجه را مشخص می‌کند.
اندیس `{}` در انتهای اسم متغیر است که به Perl می‌گوید در حال دسترسی به هشی با آن اسم هستید.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

هرچند این کار مجاز است، توصیه می‌شود برای خوانایی بهتر، انواع متغیرهای مختلف اسم یکسانی نداشته باشند.
