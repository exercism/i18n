# دستورالعمل‌ها

در این تمرین قرار است کدی بنویسید که به شما کمک کند برای خرید خودرو آماده شوید.

سه وظیفه دارید: یکی تعیین اینکه به گواهینامه نیاز دارید یا نه، یکی کمک به انتخاب بین دو خودرو و یکی تخمین قیمت مناسب یک خودروی دست‌دوم.

## 1. تعیین کنید که به گواهینامه رانندگی نیاز دارید یا نه

برخی از انواع خودرو برای راندن به گواهینامه رانندگی نیاز دارند.
فرض کنید فقط انواع `"car"` و `"truck"` به گواهینامه نیاز دارند و بقیه را می‌توان بدون گواهینامه راند.

تابع `needsLicense(kind)` را پیاده‌سازی کنید که نوع خودرو را می‌گیرد و یک «مقدار منطقی» برمی‌گرداند؛ این مقدار نشان می‌دهد که آیا برای آن نوع خودرو به گواهینامه نیاز دارید یا نه.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. انتخاب بین دو خودروی بالقوه برای خرید

شما گزینه‌های خودروهای موجود را بررسی می‌کنید.
موفق می‌شوید آن‌ها را به دو گزینه محدود کنید، اما برای گرفتن تصمیم نهایی به کمک نیاز دارید.
برای این کار، تابع `chooseVehicle(option1, option2)` را پیاده‌سازی کنید که دو خودرو را به عنوان ورودی می‌گیرد و تصمیمی برمی‌گرداند که شامل گزینه‌ای است که در [ترتیب واژگانی][lexicographical-order] اول قرار می‌گیرد.

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. تخمین قیمت یک خودروی دست‌دوم

حالا که تصمیمتان را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی قیمت منصفانه‌ای می‌پردازید.
از آنجا که قصد خرید یک خودروی دست‌دوم را دارید، قیمت به سن خودرو بستگی دارد.
برای یک تخمین تقریبی، فرض کنید اگر خودرو کمتر از ۳ سال سن داشته باشد، قیمتش ۸۰٪ قیمت اصلی‌اش است، یعنی همان قیمتی که وقتی کاملاً نو بود.
اگر حداقل ۱۰ سال سن داشته باشد، قیمتش ۵۰٪ قیمت اصلی است.
اگر خودرو حداقل ۳ سال سن داشته باشد اما کمتر از ۱۰ سال، قیمتش ۷۰٪ قیمت اصلی است.

تابع `calculateResellPrice(originalPrice, age)` را پیاده‌سازی کنید که این منطق را با استفاده از `if`، `else if` و `else` اعمال می‌کند (اگر می‌خواهید تمرین کنید، راه‌های دیگری هم هست).
این تابع قیمت اصلی و سن خودرو را به عنوان ورودی می‌گیرد و قیمت تخمینی در نمایندگی را برمی‌گرداند.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```
