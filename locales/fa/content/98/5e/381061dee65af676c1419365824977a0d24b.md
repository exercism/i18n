# دستورالعمل‌ها

در این تمرین روی یک برنامه‌ریز قرار ملاقات برای یک سالن زیبایی در نیویورک کار می‌کنید که در ۱۵ سپتامبر ۲۰۱۲ افتتاح شد.

## 1. تاریخ قرار ملاقات را تجزیه کنید

متد `AppointmentScheduler.schedule()` را پیاده‌سازی کنید تا یک نمایش متنی از تاریخ قرار ملاقات را به `LocalDateTime` متناظر تبدیل کند:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. بررسی کنید که آیا قرار ملاقات گذشته است

متد `AppointmentScheduler.hasPassed()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و بررسی می‌کند آیا این قرار ملاقات در گذشته بوده است یا نه:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. بررسی کنید که آیا قرار ملاقات در بعدازظهر است

متد `AppointmentScheduler.isAfternoonAppointment()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و بررسی می‌کند آیا این قرار ملاقات در بعدازظهر است (>= ۱۲:۰۰ و < ۱۸:۰۰):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. زمان و تاریخ قرار ملاقات را توصیف کنید

متد `AppointmentScheduler.getDescription()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و توصیفی از آن تاریخ و زمان را برمی‌گرداند:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. تاریخ سالگرد را برگردانید

متد `AppointmentScheduler.getAnniversaryDate()` را پیاده‌سازی کنید که تاریخ سالگرد امسال را برمی‌گرداند؛ این تاریخ ۱۵ سپتامبر است:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
