# پیوست دستورالعمل‌ها

## واژه‌ها

`classify ( n -- str )` یکی از رشته‌های `"perfect"`، `"abundant"` یا `"deficient"` را برمی‌گرداند.

## خطاها

وقتی ورودی صفر یا منفی باشد، رشته‌ی زیر را پرتاب کنید:

```
"Classification is only possible for positive integers."
```

(عیناً، همراه با نقطه‌ی پایانی).
