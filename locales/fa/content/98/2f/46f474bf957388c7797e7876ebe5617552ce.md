# حلقه‌های While و Until

«حلقه» یک ساختار کنترلی است که به کد اجازه می‌دهد بر پایه‌ی یک شرط مشخص بارها اجرا شود.

## حلقه‌های While

حلقه‌ی While یک ساختار کنترلی است که به کد اجازه می‌دهد بر پایه‌ی یک شرط مشخص بارها اجرا شود.
کدی که داخل حلقه‌ی While قرار دارد تا زمانی که شرط درست ارزیابی شود به اجرا ادامه می‌دهد.
از حلقه‌های While معمولاً زمانی استفاده می‌شود که تعداد تکرارها از پیش مشخص نیست؛ با این حال در هر موقعیتی که به یک حلقه نیاز باشد می‌توان از آن‌ها بهره گرفت.

شرط پیش از اجرای کد داخل حلقه ارزیابی می‌شود؛ یعنی اگر شرط نادرست باشد، کد داخل حلقه هرگز اجرا نمی‌شود.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

وقتی می‌خواهید روی یک رشته پیمایش کنید، می‌توانید بر اساس طول رشته حلقه بزنید.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## حلقه‌های Until

حلقه‌های Until مانند حلقه‌های While کار می‌کنند، با این تفاوت که کد داخل حلقه تا زمانی که شرط درست ارزیابی شود به اجرا ادامه می‌دهد.
این دقیقاً همان تفاوت میان `if` و `unless` است.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### حلقه‌های بی‌پایان

یک خطای رایج در حلقه‌های While افتادن در «حلقه‌ی بی‌پایان» است، حلقهای که هرگز پایان نمی‌یابد.
حلقه‌ی بی‌پایان می‌تواند در نتیجه‌ی شرطی باشد که _هرگز_ درست یا نادرست ارزیابی نمی‌شود.
این معمولاً ناشی از خطای برنامه‌نویس است؛ برای نمونه، فراموش کردن افزایش متغیر حلقه.
اما گاهی حلقه‌ی بی‌پایان روشن‌ترین راه برای پیاده‌سازی منطق برنامه است.
یا گاهی تکرار بی‌پایان حیاتی است؛ برای نمونه، یک سرور HTTP منتظر اتصال ورودی می‌ماند، آن را پردازش می‌کند و سپس منتظر اتصال بعدی می‌ماند.

## Break

از «کلیدواژه‌ی» `break` می‌توان برای خروج زودهنگام از حلقه استفاده کرد.
این زمانی می‌تواند راحت باشد که بخواهید تحت شرایط خاصی زودتر از حلقه خارج شوید.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

از «کلیدواژه‌ی» `next` می‌توان برای پرش به تکرار بعدی حلقه استفاده کرد.
این زمانی می‌تواند راحت باشد که بخواهید برخی تکرارهای خاص یک حلقه را نادیده بگیرید.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## نوع‌ها هنگام حلقه

نوع متغیر می‌تواند در جریان حلقه تغییر کند.
در مثال زیر، نوع `a` برابر `Int32 | String` است، چون در بخش اول حلقه می‌تواند `Int32` یا `String` باشد.
متغیر `a` فقط در بخش اول حلقه نوع `Int32 | String` را حمل می‌کند، چون هنگام شروع حلقه مقدار `Int32` را دارد و در تکرار دوم یک `String` در خود نگه می‌دارد.
این سامانه‌ی چندنوعی بعداً به‌تفصیل توضیح داده می‌شود.
اما چون مطمئن هستیم که بخش دوم حلقه فقط `String` را نگه می‌دارد، نوع `a` در بخش دوم حلقه `String` است.
در زمان اجرا، هرگز به‌طور همزمان `Int32` و `String` را نگه نمی‌دارد.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
