# درباره

یک **شیء** JSON، با استفاده از اصطلاحات زبان‌های دیگر، همان «هش»، «نقشه» یا «دیکشنری» است.

JSON یک _شیء_ را این‌گونه تعریف می‌کند:

> یک شیء مجموعه‌ای نامرتب از جفت‌های **اسم**/**مقدار** است.
> یک شیء با `{` آکولاد باز شروع می‌شود و با `}` آکولاد بسته پایان می‌یابد.
> پس از هر _اسم_ یک `:` دونقطه می‌آید و جفت‌های _اسم/مقدار_ با `,` ویرگول از هم جدا می‌شوند.

_اسم_ **باید یک رشته باشد**.
واژه‌ی دیگری برای _اسم_، _کلید_ است.

_مقدار_ می‌تواند از هر نوع JSON باشد.
_مقدارهای_ مختلف در یک شیء واحد می‌توانند از انواع متفاوتی باشند، مثل این مثال.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

توجه داشته باشید که پس از _آخرین_ جفت کلید-مقدار **نباید** ویرگولی بیاید.

## ساختن شیءها

از آکولاد برای جمع‌کردن جفت‌های اسم/مقدار استفاده کنید.
با اینکه اسم‌ها باید رشته باشند، اگر **شبیه شناسه** باشند نیازی نیست داخل علامت نقل‌قول بگذاریدشان (یعنی از حروف و ارقام و زیرخط تشکیل شده باشند و با رقم شروع نشوند).

```jq
{name: "Jane", age: 42}
```

استفاده از کلیدهایی که _شبیه شناسه_ نیستند هم مجاز است.
فقط کافی است داخل علامت نقل‌قول بگذاریدشان.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

اگر اسم حاصل یک عبارت باشد، آن عبارت **باید** داخل پرانتز قرار بگیرد.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
jq: error: syntax error, unexpected '.' (Unix shell quoting issues?) at <top-level>, line 1:
{.: 42}
jq: error: May need parentheses around object key expression at <top-level>, line 1:
{.: 42}
jq: 2 compile errors

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### شکل‌های کوتاه‌نویسی

چند مورد پرتکرار در ساختن شیء شکل کوتاه‌نویسی دارند.

1. استفاده‌ی دوباره از جفت‌های کلید-مقدار یک شیء ورودی.

   ```sh
   $ jq -n '$ENV | {USER: .USER, EDITOR: .EDITOR}'
   {
     "USER": "glennj",
     "EDITOR": "vim"
   }
   ```

   `$ENV` شیئی است که جفت‌های اسم-مقدار محیط را در خود نگه می‌دارد.

   جفت‌های تکراری `key: .key` را می‌توان فقط به شکل `key` نوشت

   ```sh
   $ jq -n '$ENV | {USER, EDITOR}'
   {
     "USER": "glennj",
     "EDITOR": "vim"
   }
   ```

1. به همین شکل، هنگام استفاده از متغیرها هم یک کوتاه‌نویسی وجود دارد.

   ```sh
   $ jq -cn '"foo" as $a | "bar" as $b | {a: $a, b: $b}'
   {"a":"foo","b":"bar"}

   $ jq -cn '"foo" as $a | "bar" as $b | {$a, $b}'
   {"a":"foo","b":"bar"}
   ```

## اندیس‌گذاری

مقادیر با **نشانه‌گذاری با نقطه** از یک شیء بازیابی می‌شوند.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

اگر نمی‌توانید به کلید با یک شناسه ارجاع دهید، از **نشانه‌گذاری با کروشه** استفاده کنید.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

اگر کلید در شیء نباشد، نتیجه `null` است.

```jq
{name: "Jane", age: 42} | .sport  # => null
```

### اندیس‌گذاری مقدارهای تودرتو

خواهید دید که هنگام تجزیه‌ی نتیجه‌های پرس‌وجوهای API، این کاری است که باید بارها و بارها انجام دهید.

با داشتن شیئی که مقدارهای آرایه‌ای یا شیئی دارد، می‌توانیم عبارت‌های اندیس را به هم «زنجیر» کنیم.

```jq
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
| (
  .pets[1],       # => "fish"
  .address.city   # => "Springfield"
)
```

## افزودن یا تغییر جفت‌های کلید-مقدار

برای افزودن یک جفت کلید-مقدار تازه به یک شیء، یا به‌روزرسانی مقدار یک کلید موجود، از عملگر انتساب `=` استفاده کنید و یک عبارت اندیس در سمت چپ قرار دهید.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

عملگر `+` شیءها را _ادغام_ می‌کند.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## حذف یک کلید

برای حذف یک کلید از تابع `del` استفاده کنید.
این تابع شیء به‌روزشده را برمی‌گرداند.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

پارامتر `del` یک **عبارت اندیس** است (با نشانه‌گذاری نقطه یا کروشه) که به یک کلید در شیء اشاره می‌کند.
`jq` به آن **عبارت مسیر** می‌گوید.
صرفاً دادن یک رشته کافی نیست.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## عضویت

- برای بررسی اینکه آیا شیء یک کلید دارد، از تابع `has` استفاده کنید.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- با `in` بررسی کنید که آیا کلیدی در شیء هست.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## فهرست کردن کلیدها یا مقدارها

برای خروجی‌گرفتن فهرستی از همه‌ی کلیدها، از تابع `keys` استفاده کنید.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

توجه کنید که `keys` کلیدها را _مرتب_ می‌کند.
برای بازیابی کلیدها به ترتیب اصلی، از `keys_unsorted` استفاده کنید.

هیچ تابع معادلی برای فهرست کردن همه‌ی _مقدارها_ وجود ندارد.
اما فیلتر `.[]` مقدارهای شیء را به‌صورت یک _جریان_ خروجی می‌دهد و آن جریان را می‌توان با سازنده‌ی آرایه‌ی `[...]` ثبت کرد.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## پیمایش

- تابع `map_values(filter)` فیلتر را روی هر _مقدار_ در شیء اعمال می‌کند.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- برای پیمایش روی یک شیء، ابتدا باید آن را به آرایه‌ای از شیءهای کلید-مقدار تبدیل کنیم.
  تابع `to_entries` این کار را انجام می‌دهد.

  ```jq
  {name: "Jane", age: 42} | to_entries
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  در این مرحله می‌توانیم از توابع پیمایش آرایه، مثل `map`، استفاده کنیم.

- تابع `from_entries` برعکس این کار است: آرایه‌ای از شیءهای کلید-مقدار را به یک شیء تبدیل می‌کند.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # => {"name": "Jane", "age": 42}
  ```

- برای اعمال فیلتر روی _هر_ جفت کلید-مقدار در یک شیء، از تابع `with_entries(filter)` استفاده کنید.

  برای مثال، با داشتن شیئی که اسمی را به یک سن نگاشت می‌کند، می‌توان کلیدها و مقدارها را به این شکل جابه‌جا کرد.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  خروجی می‌دهد

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` همانند این است:

  ```jq
  to_entries | map(filter) | from_entries
  ```
