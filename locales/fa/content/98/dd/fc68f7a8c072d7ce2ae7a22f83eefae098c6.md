# راهنمایی‌ها

## 1. مشخص کنید که آیا به گواهینامه‌ی رانندگی نیاز خواهید داشت یا نه

- برای بررسی اینکه ورودی‌تان با یک رشته‌ی مشخص برابر است یا نه، از [عملگر برابری][equality-operator] استفاده کنید.
- برای ترکیب دو شرط، از یکی از دو [عملگر منطقی][logical-operators] که در مفهوم «منطقی» یاد گرفته‌اید استفاده کنید.
- برای حل این کار به دستور شرطی **نیازی** ندارید. می‌توانید عبارت منطقی‌ای را که می‌سازید مستقیماً برگردانید.

## 2. یکی از دو خودروی بالقوه را برای خرید انتخاب کنید

- برای تعیین اینکه کدام گزینه در ترتیب واژه‌نامه‌ای اول می‌آید، از [عملگر مقایسه][comparison-operators] استفاده کنید.
- برای ساختن جمله‌ی پیشنهاد، از [قالب رشته][string-templates] استفاده کنید.

## 3. قیمت تقریبی یک خودروی دست‌دوم را محاسبه کنید

- برای تعیین درصد، از [دستور شرطی if-else if-else][if-statement] استفاده کنید.
- در دو شرط if، برای مقایسه‌ی سن خودرو با مقادیر آستانه از [عملگرهای مقایسه][comparison-operators] استفاده کنید.
- برای محاسبه‌ی نتیجه، درصد را روی قیمت اصلی اعمال کنید. برای نمونه، `30% of x` را می‌توان با تقسیم `30` بر `100` و ضرب کردن در `x` محاسبه کرد.
