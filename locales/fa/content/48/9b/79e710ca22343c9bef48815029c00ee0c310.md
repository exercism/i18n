# مقدمه

## تابع پیکانی

علاوه بر اعلان‌های تابع و عبارت‌های تابع، JavaScript روش نوشتن بسیار موجز دیگری هم برای تعریف تابع دارد.
به این توابع، «تابع پیکانی» می‌گویند.

اینجا مقایسه‌ای بین یک اعلان تابع و یک تابع پیکانی می‌بینید.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

اگر بدنه‌ی تابع فقط شامل یک دستور `return` باشد، همان‌طور که در مثال بالا دیدید، می‌توان از `{}` و کلیدواژه‌ی `return` صرف‌نظر کرد.
اگر فقط یک پارامتر وجود داشته باشد، می‌توان پرانتز `()` را هم حذف کرد.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

اغلب از توابع پیکانی برای تعریف توابع کال‌بک کوتاه، مستقیماً در فراخوانی تابع، استفاده می‌شود.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## تحلیل آرایه

[آرایه][arrays-concept] متدهای توکاری برای تحلیل محتوای آرایه دارد.
بیشتر این متدها تابعی را به عنوان آرگومان می‌گیرند که «درست» یا «غلط» برمی‌گرداند.
به چنین تابعی [`predicate`][predicate_in_programming] می‌گویند.

این متدهای توکار قرار است به‌جای یک حلقه‌ی `for` یا متد توکار `forEach` به کار روند:

نمونه‌ای از تحلیل با استفاده از یک حلقه‌ی `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

نمونه‌ای از تحلیل با استفاده از یک متد توکار:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

چند متد توکار مفید دیگر که برای تحلیل یک آرایه در دسترس هستند، در ادامه نشان داده شده‌اند.
فهرست کامل متدهای آرایه را در [MDN][mdn-array-methods] ببینید.

### `includes`

متد `includes(value)` تعیین می‌کند که آیا آرایه مقدار مشخصی را در خود دارد یا نه.
اگر مقدار در آرایه باشد `true` و در غیر این صورت `false` برمی‌گرداند.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

متد `every(predicate)` تابعی را می‌گیرد که یک «محمول» است.
این متد بررسی می‌کند که آیا همه‌ی عنصرهای آرایه، وقتی به محمول داده می‌شوند، `true` برمی‌گردانند یا نه.
به بیان دیگر، بررسی می‌کند که همه‌ی عنصرهایش در آزمونی که به فراخوانی تابع داده شده، قبول می‌شوند یا نه.
اگر هر عنصر در آزمون محمول قبول شود `true` و در غیر این صورت `false` برمی‌گرداند.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

متد `some(predicate)` همانند متد `every` است، اما اگر دست‌کم یک عنصر از آرایه در آزمون محمول قبول شود، `true` برمی‌گرداند.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

متد `find(predicate)` مقدار اولین عنصری از آرایه را برمی‌گرداند که در آزمون `predicate` قبول شود.
جایی که `some()` هنگام قبول شدن `true` برمی‌گرداند، `find()` مقدار واقعی موجود در آرایه را برمی‌گرداند.
اگر هیچ‌یک از عنصرهای آرایه در آزمون محمول قبول نشوند، این متد `undefined` برمی‌گرداند.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

متد `findIndex(predicate)` همانند متد `find()` است، اما به‌جای `value`، اندیس (اولین) عنصری را برمی‌گرداند که در آزمون محمول قبول می‌شود.
اگر هیچ‌یک از عنصرهای آرایه در آزمون محمول قبول نشوند، این متد `-1` را برمی‌گرداند.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
