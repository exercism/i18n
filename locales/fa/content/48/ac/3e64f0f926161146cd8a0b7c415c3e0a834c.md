# مقدمه

[`Rational numbers`][rational] کسرهایی هستند که از تقسیم یک صورت صحیح بر یک مخرج صحیح به دست می‌آیند.

برای مثال، می‌توانیم `2//3` را به‌جای مقدار تقریبی `Float64` یعنی `0.6666...`، به‌صورت یک کسر دقیق ذخیره کنیم.

مزیت آن این است که (جز در حالت خاص [سرریز عدد صحیح][integer-overflow]) «عدد گویا» دقیق باقی می‌ماند و از خطاهای گردکردنی که با اعداد ممیز شناور اغلب اجتناب‌ناپذیرند، جلوگیری می‌کند.

جزئیات بیشتر را می‌توانید در [صفحه‌ی راهنمای][julia-rational] Julia ببینید.

اعداد گویا نوع عددی ساده‌ای هستند و هدفشان این است که کمابیش همان‌طور که انتظار دارید کار کنند.
چون از نسخه‌های اولیه، این نوع در Julia یک نوع استاندارد بوده است، بیشتر توابع آن‌ها را همانند اعداد صحیح و ممیز شناور به‌عنوان ورودی می‌پذیرند.

## ساخت اعداد گویا

ساختنشان به همین سادگی است: کافی است `//` را بین دو عدد صحیح بگذارید.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

عامل‌های مشترک به‌طور خودکار حذف می‌شوند و کسر به [«ساده‌شده‌ترین شکل»][lowest-terms] تبدیل می‌شود: کوچک‌ترین اعداد صحیحی که کسر را به‌درستی نمایش می‌دهند و مخرجی نامنفی دارند.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

نتایج بی‌نهایت پذیرفته می‌شوند، اما [`NaN`][NaN] نه.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## محاسبات با اعداد گویا

[`arithmetic operators`][operators] معمول `+ - * / ^ %` با اعداد گویا کار می‌کنند، تقریباً همان‌طور که با سایر انواع عددی کار می‌کنند.

می‌توان اعداد صحیح و `Rational`s دیگر را در عبارت گنجاند و نتیجه یک `Rational` خواهد بود.
وارد کردن یک `float` در عبارت به خروجی `float` می‌انجامد و در پی آن، دقت (به‌احتمال) کاهش می‌یابد.

اگر `float` می‌خواهید، کافی است از تابع `float()` برای تبدیل عدد گویا استفاده کنید.
کاملاً معمول است که از اعداد گویا برای حفظ دقت در طول یک محاسبه‌ی طولانی استفاده کنید و در پایان آن را به ممیز شناور تبدیل کنید.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

اعداد گویا را می‌توان با [اعداد مختلط][complex] هم ترکیب کرد.
اعداد مختلط در یک [مفهوم جداگانه][complex-concept] بحث شده‌اند.

## سایر عملیات

در Julia، اعداد گویا فقط عدد هستند.
کامپایلر معمولاً در صورت لزوم نوع‌ها را تبدیل می‌کند.

اما حواستان باشد که این مقایسه‌ها برای کسرهایی با نمایش اعشاری متناهی کار می‌کنند:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

اما در غیر این صورت، برای مقایسه باید `Rational` را به `Float` تبدیل کرد:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

توابع ریاضی اعداد گویا را به‌عنوان ورودی می‌پذیرند، اما ممکن است نتیجه‌ی ممیز شناور بدهند:

```julia-repl
julia> sqrt(9//16)
0.75
```
