# Testها

وابستگی‌ها را نصب کنید.

```sh
dart pub get
```

Testها را اجرا کنید.

```sh
dart test
```

برای خروجی دقیق‌تر به ازای هر Test، از گزارش‌دهنده‌ی «expanded» استفاده کنید.

```sh
dart test -r expanded
```

بیشتر تمرین‌ها چندین Test دارند که به‌طور پیش‌فرض همه به‌جز اولین Test رد می‌شوند.
برای اینکه Testها را یکی‌یکی جلو ببرید، همین‌طور که پیش می‌روید، در هر Test `skip: true` را به `skip: false` تغییر دهید.

در عوض، می‌توانید همه‌ی Testها را یک‌جا و بدون ویرایش فایل اجرا کنید.

```sh
dart test --run-skipped
```

همه‌ی Testها هنگام ارسال توسط test runner آنلاین اجرا می‌شوند، از جمله Testهایی که رد شده‌اند.
