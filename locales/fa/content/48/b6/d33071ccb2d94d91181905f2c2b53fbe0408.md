# مقدمه

الیکسیر با اجازه دادن به توابع برای داشتن چندین بند، به رعایت **اصل باز-بسته** کمک می‌کند؛ به این ترتیب به‌جای منطق کنترلی پراکنده و هاردکدشده، می‌توان توابعی هدفمند نوشت که افزودن یا حذف رفتار را ساده می‌کنند.

الیکسیر برای نوشتن این موارد، «بندهای چندگانه‌ی تابع» و «گارد» را در اختیارتان می‌گذارد:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

هنگام اجرا، الیکسیر از بالای فایل منبع تا پایین آن بررسی می‌کند که کدام بند تابع باید فراخوانی شود.

متغیرهایی که استفاده نمی‌شوند باید با زیرخط شروع شوند.
