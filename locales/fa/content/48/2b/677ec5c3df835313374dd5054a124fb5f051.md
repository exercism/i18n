# مبانی

برای اطلاعات دقیق‌تر درباره‌ی این موضوعات، به [صفحه‌ی مفهوم][exercism-concept] سر بزنید.

## نحوه‌ی نگارش کلی

تگ آغازین PHP یعنی `<?php` شروع کد PHP را مشخص می‌کند.
برای جدا کردن دستورها از یکدیگر، همه‌ی آن‌ها باید با یک `;` پایان یابند.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

برای خوانایی بیشتر، همه‌ی نمونه‌کدها تگ آغازین PHP یعنی `<?php` را حذف کرده‌اند.

## توضیحات

توضیحات تک‌خطی با `//` شروع می‌شوند.

```php
// Single line comment
```

## مقادیر و متغیرها

با استفاده از عملگر انتساب `=` می‌توان یک مقدار را به یک متغیر نسبت داد.
اسم متغیرها باید با علامت دلار `$` شروع شود و از [قواعد نام‌گذاری][exercism-concept-naming-conventions] پیروی کند.

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## توابع و متدها

مقادیر و متغیرها را می‌توان به توابع ارسال کرد.
آرگومان‌های تابع به متغیرهای جدیدی تبدیل می‌شوند که مقادیر ارسال‌شده را نگه می‌دارند.
توابع می‌توانند با استفاده از کلیدواژه‌ی `return` هر مقداری را برگردانند.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

به توابعی که داخل کلاس‌ها و نمونه‌های آن‌ها قرار دارند، متد می‌گوییم.
برای فراخوانی یک متد، اسم آن پس از نمونه و `->` می‌آید.
متدها به متغیر ویژه‌ی `$this` دسترسی دارند که به نمونه‌ی جاری اشاره می‌کند.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
