# دستورالعمل‌ها

در این تمرین به دلداده‌های دبیرستانی کمک می‌کنید تا عشقشان را در شبکه‌های اجتماعی ابراز کنند؛ برای این کار با حروف اول اسمشان یک جعبه‌ی ASCII می‌سازید:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. اولین حرف اسم را بگیرید

تابع `HighSchoolSweetheart.first_letter/1` را پیاده‌سازی کنید. این تابع باید یک اسم بگیرد و اولین حرف آن را برگرداند. همچنین باید هر فضای خالی اضافی را از اسم پاک کند.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. اولین حرف را به‌شکل حرف اختصاری بنویسید

تابع `HighSchoolSweetheart.initial/1` را پیاده‌سازی کنید. این تابع باید یک اسم بگیرد و اولین حرف آن را با حروف بزرگ و به‌همراه یک نقطه برگرداند. حتماً از تابع `HighSchoolSweetheart.first_letter/1` که در گام قبل تعریف کردید دوباره استفاده کنید.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. اسم کامل را به اسم کوچک و اسم خانوادگی تقسیم کنید

تابع `HighSchoolSweetheart.initials/1` را پیاده‌سازی کنید. این تابع باید یک اسم کامل، شامل اسم کوچک و اسم خانوادگی که با یک فاصله از هم جدا شده‌اند، بگیرد و حروف اول را برگرداند. حتماً از تابع `HighSchoolSweetheart.initial/1` که در گام قبل تعریف کردید دوباره استفاده کنید.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. حروف اول را داخل جعبه‌ی ASCII قرار دهید

تابع `HighSchoolSweetheart.pair/2` را پیاده‌سازی کنید. این تابع باید دو اسم کامل بگیرد و حروف اول را داخل یک جعبه‌ی ASCII برگرداند. لازم نیست خودتان جعبه را رسم کنید؛ از جعبه‌ای که در کامنت کد آمده استفاده کنید. حتماً از تابع `HighSchoolSweetheart.initials/1` که در گام قبل تعریف کردید دوباره استفاده کنید.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
