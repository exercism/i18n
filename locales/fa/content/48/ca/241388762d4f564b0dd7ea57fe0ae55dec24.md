# مقدمه

ABAP از عملگرهای حسابی برای محاسبات با مقادیر عددی پشتیبانی می‌کند.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

عملگرهای پایه عبارت‌اند از:

- `+` برای جمع.
- `-` برای تفریق.
- `*` برای ضرب.
- `/` برای تقسیم.
- `MOD` برای باقیمانده‌ی یک تقسیم صحیح.

```abap
DATA full_months TYPE i.
full_months = floor( num_days / 22 ).

DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP ضرب و تقسیم را پیش از جمع و تفریق محاسبه می‌کند. می‌توان از پرانتز استفاده کرد تا ترتیب موردنظر صریح و روشن شود.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
