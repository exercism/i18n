# دستورالعمل‌ها

تیم شما روی یک برنامه‌ی هواشناسی کار می‌کند.
آن‌ها یک API تعریف کرده‌اند که انواع و ثابت‌های گوناگونی برای نمایش داده‌های هواشناسی دارد؛ فایل `meteorology.go` را ببینید.

وظیفه‌ی شما این است که متدهای `String` مناسب را به همه‌ی انواع اضافه کنید تا «رابط» `Stringer` را پیاده‌سازی کنند.

## 1. پیاده‌سازی رابط `Stringer` برای نوع `TemperatureUnit`

بعد از کمی بحث، تیم توافق کرده است که یکای دما یا `Celsius` خواهد بود یا `Fahrenheit`.
مقادیر باید همان‌طور که در مثال‌های زیر نشان داده شده قالب‌بندی شوند.

نوع `TemperatureUnit` را طوری تغییر دهید که با افزودن یک متد `String` به آن، رابط `Stringer` را پیاده‌سازی کند.
این متد باید رشته‌ی `"°C"` را برگرداند اگر یکای دما سلسیوس است، و `"°F"` را اگر یکای دما فارنهایت است.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. پیاده‌سازی رابط `Stringer` برای نوع `Temperature`

مقادیر دما از یک عدد صحیح و یک یکای دما تشکیل شده‌اند.
باید همانند مثال‌های زیر قالب‌بندی شوند.

برای این کار، نوع `Temperature` را طوری تغییر دهید که با افزودن یک متد `String` به آن، رابط `Stringer` را پیاده‌سازی کند.
این متد باید رشته‌ای برگرداند که مقدار عددی دما و یکای دما در آن با یک فاصله از هم جدا شده‌اند: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. پیاده‌سازی رابط `Stringer` برای نوع `SpeedUnit`

بعد از بحث‌های طولانی، تیم توافق کرده است که یکای سرعت باد یا `KmPerHour` خواهد بود یا `MilesPerHour`.
مقادیر باید همانند مثال‌های زیر قالب‌بندی شوند.

برای این کار، نوع `SpeedUnit` را طوری تغییر دهید که با افزودن یک متد `String` به آن، رابط `Stringer` را پیاده‌سازی کند.
این متد باید رشته‌ی `"km/h"` را برگرداند اگر یکای سرعت کیلومتر بر ساعت است، و `"mph"` را اگر یکای سرعت مایل بر ساعت است:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. پیاده‌سازی رابط `Stringer` برای `Speed`

مقادیر سرعت باد از یک عدد صحیح و یک یکای سرعت تشکیل شده‌اند.
باید همانند مثال زیر قالب‌بندی شوند.

برای این کار، نوع `Speed` را طوری تغییر دهید که با افزودن یک متد `String` به آن، رابط `Stringer` را پیاده‌سازی کند.
این متد باید رشته‌ای برگرداند که مقدار عددی سرعت و یکای سرعت در آن با یک فاصله از هم جدا شده‌اند: `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. پیاده‌سازی رابط `Stringer` برای نوع `MeteorologyData`

داده‌های هواشناسی مکان، دما، جهت باد، سرعت باد و رطوبت را مشخص می‌کند.
باید همانند مثال زیر قالب‌بندی شود:

برای این کار، نوع `MeteorologyData` را طوری تغییر دهید که با افزودن یک متد `String` به آن، رابط `Stringer` را پیاده‌سازی کند.
این متد باید داده‌های هواشناسی را در قالب زیر برگرداند:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
