# درباره

یک `Iterator` در Gleam از این نظر به یک لیست شبیه است که مجموعه‌ای مرتب از مقادیر است و همه‌ی مقادیرش از یک نوع‌اند. تفاوتش با لیست در این است که «تنبل» است؛ یعنی همه‌ی مقادیرش را یک‌جا در حافظه ذخیره نمی‌کند و در عوض هر مقدار را هنگام نیاز محاسبه می‌کند.

این ویژگی برای کار با توالی‌هایی مفید است که اندازه‌شان بسیار بزرگ یا حتی بی‌نهایت است، چون به ما اجازه می‌دهد حتی وقتی حافظه‌ی آزاد کافی برای ذخیره‌ی همه‌ی آن‌ها به‌طور همزمان نداریم، با آن‌ها کار کنیم.

ماژول `gleam/iterator` هم نوع `Iterator` را تعریف می‌کند و هم توابعی برای کار با `Iterator` در اختیار می‌گذارد.

بسیاری از توابع لیست‌ها برای `Iterator` هم وجود دارند، مثل `map`، `filter` و `take`. این توابع یک `Iterator` برمی‌گردانند، بنابراین تا زمانی که `Iterator` مصرف نشود، هیچ کاری انجام نمی‌دهند.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

از تابع `unfold` می‌توان برای ساختن `Iterator` از تابعی استفاده کرد که بارها فراخوانی می‌شود تا مقدار بعدی توالی را تولید کند.

در اینجا از تابع `unfold` برای ساختن یک `Iterator` استفاده شده است که دنباله‌ی فیبوناچی را تولید می‌کند:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

توالی اینجا بی‌نهایت است، بنابراین پیش از جمع‌آوری مقادیر در یک لیست، از تابع `take` استفاده می‌شود تا آن را متناهی کند. اگر `to_list` را روی یک `Iterator` بی‌نهایت فراخوانی کنید، برنامه آن‌قدر اجرا می‌شود تا حافظه‌اش تمام شود و کرش کند.
