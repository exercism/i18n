# دستورالعمل‌ها

در این تمرین، مجموعه‌ای جزئی از توابع کمکی را پیاده‌سازی می‌کنید تا به یک برنامه‌نویس در پاک‌سازی اسم‌های SqueakyClean کمک کنید.

در ۴ کار، به‌تدریج متد `clean` را می‌سازید.
یک اسم معتبر SqueakyClean از صفر یا چند حرف و زیرخط تشکیل شده است.

در همه‌ی حالت‌ها تضمین شده است که رشته‌ی ورودی هرگز `null` نباشد. توجه کنید که متد `clean` باید رشته‌ی خالی را معتبر در نظر بگیرد.

## 1. هر فاصله‌ای را که دیدید با زیرخط جایگزین کنید

متد (_static_) `SqueakyClean.clean()` را طوری پیاده‌سازی کنید که هر فاصله را با زیرخط جایگزین کند. این موضوع برای فاصله‌های ابتدا و پایان رشته هم صدق می‌کند.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. تبدیل kebab-case به camelCase

متد (_static_) `SqueakyClean.clean()` را تغییر دهید تا kebab-case را به camelCase تبدیل کند.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. تبدیل leetspeak به متن معمولی

متد (_static_) `SqueakyClean.clean()` را تغییر دهید تا [leetspeak][leet-speak] را به متن معمولی تبدیل کند.

برای سادگی، فقط `4`، `3`، `0`، `1` و `7` را به‌ترتیب با `a`، `e`، `o`، `l` و `t` جایگزین می‌کنیم.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. حذف کاراکترهایی که حرف نیستند

متد (_static_) `SqueakyClean.clean()` را تغییر دهید تا هر کاراکتری را که حرف نیست حذف کند.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
