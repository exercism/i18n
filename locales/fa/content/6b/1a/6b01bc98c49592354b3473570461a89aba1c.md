# درباره

## ماژول

کد Gleam در قالب «ماژول» سازماندهی می‌شود و هر فایل یک ماژول Gleam است.

تا حالا «تابع»هایی را با «نحوه‌ی نگارش» `pub fn` نوشته‌ایم، که تابعی را تعریف می‌کند که برای ماژول‌های دیگر به‌صورت عمومی در دسترس است. توابعی که با `fn` تعریف می‌شوند برای ماژولی که در آن تعریف شده‌اند خصوصی‌اند و ماژول‌های دیگر نمی‌توانند از آن‌ها استفاده کنند.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

ماژول‌های Gleam اسم دارند و اسم‌شان بر اساس مسیر فایل‌شان در پوشه‌ی `src` یا `test` تعیین می‌شود.

برای مثال، ماژولی که در `src\geometry\rectangle.gleam` (در ویندوز) یا `src/geometry/rectangle.gleam` (در سیستم‌عامل‌های شبیه UNIX) تعریف شده باشد، اسمش `geometry/rectangle` خواهد بود.

## وارد کردن توابع از ماژول‌های دیگر

دسترسی به توابعی که در ماژول‌های دیگر تعریف شده‌اند از طریق «وارد کردن» انجام می‌شود. وقتی آن ماژول وارد می‌شود، همه‌ی توابعی که آن ماژول در دسترس قرار داده است قابل دسترسی می‌شوند. اما نحوه‌ی دسترسی به آن‌ها بسته به نحوه‌ی وارد کردن ماژول فرق می‌کند.

«وارد کردن با پیشوند» حالت پیش‌فرض است و دسترسی به تابعی در چنین ماژولی (برای مثال تابع `map` در ماژول `gleam/list`) با گذاشتن اسم ماژول به‌عنوان پیشوند (`list.map`) انجام می‌شود.

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

به‌طور پیش‌فرض اسمی که برای اشاره به ماژول استفاده می‌شود آخرین بخش اسم ماژول است، در این مورد `int`، اما این را می‌توان با استفاده از «کلیدواژه»ی `as` تغییر داد.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

«وارد کردن بدون پیشوند» دسترسی مستقیم به توابع در دسترس قرار گرفته در آن ماژول را بدون گذاشتن پیشوند ممکن می‌کند.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

وارد کردن با پیشوند ترجیح داده می‌شود چون برای خواننده روشن‌تر می‌کند که تابع از کجا می‌آید و از تداخل اسم جلوگیری می‌کند.
