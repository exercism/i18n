# درباره

برش‌ها در Go شبیه به لیست‌ها یا آرایه‌ها در زبان‌های دیگر هستند.
آن‌ها چندین عنصر از یک نوع مشخص (یا واسط) را در خود نگه می‌دارند.

برش‌ها در Go بر پایه‌ی آرایه‌ها هستند.
آرایه‌ها اندازه‌ی ثابتی دارند.
در مقابل، برش نمایی با اندازه‌ی پویا و انعطاف‌پذیر از عناصر یک آرایه است.

برش به شکل `[]T` نوشته می‌شود که `T` نوع عناصر درون برش است:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

می‌توانید عنصری را در یک اندیس مشخص که از صفر شروع می‌شود، با استفاده از نماد براکت مربع بخوانید یا مقدارش را تعیین کنید:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

می‌توانید با گرفتن یک بازه از عناصر، از روی یک برش موجود برش تازه‌ای بسازید.
باز هم با استفاده از نماد براکت مربع، اما این بار با مشخص کردن هم اندیس شروع (شامل) و هم اندیس پایان (غیرشامل).
اگر اندیس شروع را مشخص نکنید، به‌طور پیش‌فرض ۰ در نظر گرفته می‌شود.
اگر اندیس پایان را مشخص نکنید، به‌طور پیش‌فرض به اندازه‌ی طول برش در نظر گرفته می‌شود.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

می‌توانید با استفاده از تابع `append` عنصرهایی به یک برش اضافه کنید.
در ادامه `4` و `2` را به برش `a` اضافه می‌کنیم.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

تابع `append` همیشه یک برش تازه برمی‌گرداند و وقتی فقط می‌خواهیم عنصرهایی به یک برش موجود اضافه کنیم، معمول است که نتیجه را دوباره به همان متغیر برشی که به عنوان آرگومان اول پاس داده‌ایم نسبت دهیم، همان‌طور که در بالا انجام دادیم.

از `append` می‌توان برای ادغام دو برش هم استفاده کرد:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## اندیس‌ها در برش‌ها

کار با اندیس‌های برش‌ها باید همیشه به شکلی با یک بررسی محافظت شود که مطمئن شود اندیس واقعاً وجود دارد.
اگر این کار را نکنید، کل برنامه از کار می‌افتد.

## برش‌های خالی

برش‌های `nil` همان برش خالی پیش‌فرض هستند.
در مقایسه با برشی که هیچ مقداری در خود ندارد، هیچ اشکالی ندارند.
تابع `len` روی برش‌های `nil` کار می‌کند، می‌توان بدون مقداردهی اولیه عنصر اضافه کرد و به همین ترتیب.
اگر برش تازه‌ای می‌سازید، `var s []int` (برش `nil`) را به `s := []int{}` (برش خالی و غیر`nil`) ترجیح دهید.

## کارایی

وقتی برش‌هایی می‌سازید که قرار است به‌صورت تکراری پر شوند، اگر اندازه‌ی نهایی برش را بدانید، یک راه ساده برای بهبود کارایی وجود دارد.
نکته‌ی اصلی کمینه کردن تعداد دفعاتی است که باید حافظه تخصیص داده شود؛ این کار نسبتاً پرهزینه است و زمانی رخ می‌دهد که برش از فضای حافظه‌ی تخصیص‌یافته‌اش فراتر برود.
امن‌ترین راه برای این کار، مشخص کردن یک ظرفیت `cap` برای برش با `s := make([]int, 0, cap)` و سپس افزودن به برش با `append` به روش معمول است.
به این ترتیب، فضای لازم برای `cap` عنصر بلافاصله تخصیص داده می‌شود، در حالی که طول برش صفر است.
در عمل، `cap` اغلب طول یک برش دیگر است: `s := make([]int, 0, len(otherSlice))`.

## تابع `append` یک تابع خالص نیست

تابع `append` در Go برای کارایی بهینه شده است و بنابراین از برش ورودی کپی نمی‌گیرد.
این یعنی برش اصلی (پارامتر اول `append`) گاهی تغییر می‌کند.
