# پیوست دستورالعمل‌ها

## راهنمایی‌ها

باید توابع `decode` و `encode` را پیاده‌سازی کنید که یک `String` را با استفاده از رمز آفاین کدگشایی و کدگذاری می‌کنند.
اگر درباره‌ی نوع‌ها مطمئن نیستید می‌توانید از امضای ارائه‌شده استفاده کنید، اما نگذارید خلاقیت‌تان را محدود کند.

این تمرین با داده‌های متنی سروکار دارد.
به دلایل تاریخی، نوع `String` در Haskell با `[Char]`، یعنی فهرستی از کاراکترها، هم‌معناست.
برای پردازش کارآمدتر داده‌های متنی می‌توان از نوع `Text` استفاده کرد.

به عنوان یک توسعه‌ی اختیاری برای این تمرین، می‌توانید

- `- text` را به فهرست وابستگی‌هایتان در package.yaml اضافه کنید.
- `Data.Text` را [به این روش](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) وارد کنید:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- از نوع `Text` استفاده کنید، مثلاً `decode :: Text -> Text`. همچنین ترکیب‌کننده‌های `Data.Text` را با نام‌هایی مانند `T.pack` به کار ببرید.
- به مستندات [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) مراجعه کنید.
- همه‌ی موارد `String` را در Affine.hs با `Text` جایگزین کنید، یعنی:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

این بخش کاملاً اختیاری است.
