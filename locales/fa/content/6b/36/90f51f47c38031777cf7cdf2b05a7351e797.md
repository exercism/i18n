# درباره

در F#، مقادیر منطقی با نوع `bool` نشان داده می‌شوند؛ مقادیر آن می‌توانند `true` یا `false` باشند.

F# از سه [عملگر منطقی][operators] پشتیبانی می‌کند: `not` (NOT)، `&&` (AND) و `||` (OR). عملگرهای `&&` و `||` از _ارزیابی اتصال کوتاه_ استفاده می‌کنند، یعنی سمت راست عملگر فقط در صورت نیاز ارزیابی می‌شود.

```fsharp
true || false // => true
true && false // => false
```

هر یک از این سه عملگر منطقی [_اولویت عملگر_][precedence] متفاوتی دارد. در نتیجه، به این ترتیب ارزیابی می‌شوند: ابتدا `not`، سپس `&&` و در نهایت `||`. اگر می‌خواهید از این قواعد «فرار» کنید، می‌توانید یک عبارت منطقی را در پرانتز (`()`) قرار دهید، چون پرانتزها اولویت عملگر بالاتری دارند.

```fsharp
not true && false   // => false
not (true && false) // => true
```
