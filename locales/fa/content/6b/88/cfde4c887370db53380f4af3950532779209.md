# مقدمه

Unison مقادیر «درست» و «غلط» را با نوع `Boolean` نمایش می‌دهد. این نوع فقط دو مقدار دارد: `true` و `false`.

```unison
trueVariable = true
falseVariable = false
```

می‌توانیم عبارت‌های منطقی را با عملگرهای «and» که با `&&` نشان داده می‌شود، «or» که با `||` نشان داده می‌شود و «not» که با `not` نشان داده می‌شود، ارزیابی کنیم.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
