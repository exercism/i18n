# مقدمه

یک `Tuple` از بسیاری جهات شبیه `Vector` (یک `array` یک‌بعدی) است. اما چند تفاوت مهم هم وجود دارد.

- تاپل‌ها با پرانتز `( )` نوشته می‌شوند، نه با کروشه `[ ]`؛ هرچند در جاهایی که معنا روشن و بدون ابهام باشد، می‌توان پرانتزها را حذف کرد.
- تاپل‌ها لازم نیست همگن باشند: نوع هر عنصر جداگانه ذخیره می‌شود.
- تاپل‌ها تغییرناپذیرند.

تغییرناپذیری امکان بهینه‌سازی‌های بیشتری را برای کامپایلر فراهم می‌کند و باعث می‌شود تاپل‌ها کارآمدتر از `Vector` باشند، پس در جاهایی که به تغییرپذیری نیازی نیست، تاپل را ترجیح دهید.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

یک سازنده‌ی `Tuple()` هم وجود دارد که هر مجموعه‌ی قابل پیمایشی را به تاپل تبدیل می‌کند. نکته‌ی مفید اینکه این سازنده با رشته هم مثل مجموعه‌ای قابل پیمایش از کاراکترها رفتار می‌کند.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

در هر تاپلی می‌توان با استفاده از اندیس به عنصرها دسترسی داشت یا روی آن‌ها حلقه زد.

هر تاپل کاملاً عددی را هم می‌توان در توابع ریاضی مانند `sum()` به کار برد، دقیقاً مانند آرایه‌ها.

## بازگشایی

می‌توان یک تاپل را با استفاده از تخصیص چندگانه به عنصرهای جداگانه‌اش بازگشایی کرد. برای عنصرهایی که لازم نیستند، از علامت زیرخط، یعنی `_`، به عنوان متغیر ساختگی استفاده کنید.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

برنامه‌نویسان پایتون با این نحوه‌ی نگارش تخصیص چندگانه کاملاً آشنا خواهند بود.

## تاپل‌های نامدار

یک `Tuple` فقط مقدارها را در خود نگه می‌دارد. یک `NamedTuple` هر مقدار را با یک اسم جفت می‌کند.

سپس می‌توان با نشانه‌گذاری «نقطه» به هر فیلد به‌طور جداگانه دسترسی داشت:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

اسم به‌صورت داخلی به شکل یک `Symbol` ذخیره می‌شود (نوعی تغییرناپذیر که با دونقطه `:` شروع می‌شود)، بنابراین نحوه‌ی نگارش جایگزینی هم در دسترس است:

```julia-repl
julia> nt[:b]
7.3
```

به‌آسانی می‌توان اسم‌ها (که به آن‌ها «کلید» هم می‌گویند) یا مقدارها را جداگانه به دست آورد:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

توجه داشته باشید که پیمایش روی یک تاپل نامدار فقط _مقدارها_ را تولید می‌کند و _اسم‌ها_ نادیده گرفته می‌شوند.

تاپل‌ها (چه نامدار و چه بی‌نام) روشی بسیار رایج برای فرستادن داده‌های ساخت‌یافته به توابع و گرفتن آن‌ها از توابع هستند. تغییرناپذیری در این کاربرد خوب است، چون ایمنی داده را تضمین می‌کند و به کامپایلر اجازه می‌دهد بهینه‌سازی‌های قوی‌تری انجام دهد.
