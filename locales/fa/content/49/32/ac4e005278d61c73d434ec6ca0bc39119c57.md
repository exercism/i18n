# پارامترهای ورودی-خروجی

در بدنه‌ی یک تابع، با پارامترها مانند ثابت رفتار می‌شود، نه مانند متغیر؛ اگر بخواهید مقدار یک پارامتر را تغییر دهید، خطای زمان کامپایل رخ می‌دهد.
اگر تابعی بخواهد مقدار یک پارامتر را تغییر دهد، باید از یک [_پارامتر ورودی-خروجی_][in-out-parameters] استفاده کند تا به‌صراحت نشان دهد که این مقدار قابل تغییر است.

برای استفاده از پارامترهای ورودی-خروجی، برنامه‌نویس باید به سه نکته توجه کند:

1. تعریف تابع باید پارامترهای ورودی-خروجی را با نوشتن کلیدواژه‌ی `inout` بین `:` و نام نوع در تعیین نوع پارامتر، به‌صراحت مشخص کند.
2. مقداری که به پارامتر ورودی-خروجی داده می‌شود باید به‌عنوان متغیر تعریف شده باشد، نه ثابت. به همین ترتیب، نمی‌تواند یک لیترال باشد.
3. در فراخوانی تابع، باید پیش از نام متغیر علامت `&` بیاید تا به‌صراحت نشان دهد که این متغیر قابل تغییر است.

وقتی این کار انجام شود، تابع یک نسخه‌ی داخلی از پارامتر ورودی-خروجی می‌سازد، آن را همان‌طور که در بدنه‌ی تابع گفته شده تغییر می‌دهد و سپس وقتی تابع برمی‌گردد، مقدار تغییر‌یافته را دوباره در متغیری که پاس داده شده بود کپی می‌کند.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
چند قاعده‌ی اضافی هم هست که باید درباره‌ی پارامترهای ورودی-خروجی بدانید.

۱  داخل تابعی که پارامتر ورودی-خروجی دارد، اجازه ندارید به متغیری که به‌عنوان پارامتر ورودی-خروجی پاس داده شده ارجاع دهید.
۲. همان متغیر را نمی‌توان در یک تابع به‌عنوان چند پارامتر ورودی-خروجی پاس داد.
   برای نمونه، `inoutFunc(&mutVar, &mutVar)` خطای کامپایلر ایجاد می‌کند.
~~~~
