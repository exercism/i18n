# دستورالعمل‌ها

اوزان دارد برای سفر جاده‌ای پیش‌رو یک پلی‌لیست آماده می‌کند. او نمی‌خواهد یک آهنگ را بیش از یک بار بشنود، اما پلی‌لیست آن‌قدر طولانی شده که دیگر به‌سختی یادش می‌آید کدام آهنگ‌ها را قبلاً اضافه کرده است.

API پخش‌کننده‌ی موسیقی اوزان فقط با آرایه‌ها کار می‌کند، بنابراین اوزان می‌کوشد کدی بنویسد که با کمک `Array.indexOf()` پیش از افزودن یک آهنگ به پلی‌لیست، وجود آن را بررسی کند. متأسفانه اجرای برنامه‌اش بیش از حد طول می‌کشد. او به کمک شما نیاز دارد!

وقتی به یاری اوزان می‌شتابید، شگفت‌زده می‌بینید که پلی‌لیست او _نیم میلیون_ آهنگ دارد. شاید شما ساختار داده‌ی دیگری بشناسید که به کمک آن بتوانید پلی‌لیست را کارآمدتر مدیریت کنید؟

## 1. حذف آهنگ‌های تکراری

تابع `removeDuplicates` را پیاده‌سازی کنید؛ این تابع یک پلی‌لیست را به عنوان _پارامتر_ می‌گیرد و پلی‌لیست جدیدی _برمی‌گرداند_ که همه‌ی آهنگ‌هایش یکتا هستند.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. بررسی اینکه آیا یک آهنگ قبلاً اضافه شده است

تابع `hasTrack` را پیاده‌سازی کنید؛ این تابع یک پلی‌لیست و یک آهنگ را به عنوان _پارامتر_ می‌گیرد و یک مقدار «منطقی» _برمی‌گرداند_ که نشان می‌دهد آیا پلی‌لیست آن آهنگ را دارد یا نه.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. افزودن یک آهنگ

تابع `addTrack` را پیاده‌سازی کنید؛ این تابع یک پلی‌لیست و یک آهنگ را به عنوان _پارامتر_ می‌گیرد و پلی‌لیست جدیدی _برمی‌گرداند_ که آن آهنگ را در خود دارد.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. حذف یک آهنگ

تابع `deleteTrack` را پیاده‌سازی کنید؛ این تابع یک پلی‌لیست و یک آهنگ را به عنوان _پارامتر_ می‌گیرد و پلی‌لیست جدیدی _برمی‌گرداند_ که آن آهنگ را در خود ندارد.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. فهرست کردن هنرمندان یکتا

تابع `listArtists` را پیاده‌سازی کنید؛ این تابع یک پلی‌لیست را به عنوان _پارامتر_ می‌گیرد و فهرست هنرمندان یکتای آن پلی‌لیست را _برمی‌گرداند_. توجه کنید که اسم آهنگ‌ها به شکل `<SONG> - <ARTIST>` نوشته شده‌اند.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
