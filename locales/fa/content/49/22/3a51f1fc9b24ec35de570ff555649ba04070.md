# دستورالعمل‌ها

شما در حال ساخت بازی ویدیویی نقش‌آفرینی خودتان هستید. در بازی شما «شخصیت‌ها» و «آیتم‌ها» وجود دارند. یکی از کارهای متعددی که می‌توانید با یک آیتم انجام دهید این است که کاری کنید یک شخصیت آن را بخورد.

همه‌ی آیتم‌ها خوراکی نیستند و همه‌ی آیتم‌های خوراکی هم تأثیر یکسانی روی شخصیت ندارند. بعضی آیتم‌ها وقتی خورده می‌شوند به آیتم دیگری تبدیل می‌شوند (مثلاً اگر یک سیب بخورید، ته‌سیب برایتان می‌ماند).

برای اینکه همه‌ی این انعطاف ممکن شود، تصمیم گرفتید یک «پروتکل» `Edible` بسازید که بعضی از آیتم‌ها بتوانند آن را پیاده‌سازی کنند.

## 1. خوراکی بودن را تعریف کنید

پروتکل `RPG.Edible` را بسازید. این پروتکل یک تابع دارد: `eat`. تابع `eat` یک آیتم و یک شخصیت را دریافت می‌کند و یک «محصول جانبی» و یک شخصیت را برمی‌گرداند.

## 2. قرص‌های نان را خوراکی کنید

پروتکل `RPG.Edible` را برای آیتم `RPG.LoafOfBread` پیاده‌سازی کنید. وقتی خورده می‌شود، یک قرص نان ۵ امتیاز سلامتی به شخصیت می‌دهد و محصول جانبی‌ای ندارد.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. معجون‌های مانا را خوراکی کنید

پروتکل `RPG.Edible` را برای آیتم `RPG.ManaPotion` پیاده‌سازی کنید. وقتی خورده می‌شود، یک معجون مانا به اندازه‌ی قدرت معجون به شخصیت امتیاز مانا می‌دهد و یک بطری خالی تولید می‌کند.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. سم‌ها را خوراکی کنید

پروتکل `RPG.Edible` را برای آیتم `RPG.Poison` پیاده‌سازی کنید. وقتی خورده می‌شود، سم همه‌ی امتیازهای سلامتی را از شخصیت می‌گیرد و یک بطری خالی تولید می‌کند.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
