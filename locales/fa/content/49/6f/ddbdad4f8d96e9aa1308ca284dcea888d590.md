# درباره

Factor تصادف را در واژگان [`random`][random] پیرامون یک واژه‌ی عمومی واحد متمرکز می‌کند:

```
random ( obj -- elt )
```

این واژه بر اساس آرگومانش عمل می‌کند:

- یک **عدد صحیح** مانند `n` یک عدد صحیح تصادفی در `[0, n)` تولید می‌کند؛
- یک **دنباله** یک عنصر تصادفی تولید می‌کند؛
- `assocs`، `hash-sets` و چندتایی‌های `uniform-distribution` هم پشتیبانی می‌شوند.

دو تابع کمکی برای دنباله‌ها بر پایه‌ی آن ساخته شده‌اند:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` دنباله را تغییر می‌دهد و همان را برمی‌گرداند؛ پس اگر می‌خواهید ترتیب اصلی باقی بماند، اول `clone` را فراخوانی کنید.

## تصادف از کجا می‌آید

`random` مولد ذخیره‌شده در متغیر پویای `random-generator` را می‌خواند. به‌طور پیش‌فرض، این مولد یک Mersenne Twister است که مقدار اولیه‌اش از ساعت سیستم گرفته می‌شود، بنابراین هر فرایند متفاوت است. می‌توانید برای مدت اجرای یک «quotation» مولد دیگری نصب کنید:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

از آنجا که `with-random` فقط `random-generator` را برای گستره‌ی پویای quotation مقید می‌کند، واژه‌ای که آن را در بر می‌گیرد باید `inline` علامت‌گذاری شود تا quotation بتواند نتیجه‌اش را برای فراخوان روی پشته بگذارد.

افزون بر اینها، `random` برای توزیع‌های دیگر `random-bits`، `random-unit`، `uniform-random` و `normal-random` را ارائه می‌دهد و همچنین `system-random-generator` و `secure-random-generator` را برای نیازهای غیرقابل‌تکرار و رمزنگاری.
