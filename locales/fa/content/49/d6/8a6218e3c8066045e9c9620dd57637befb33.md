# راهنمایی‌ها

## عمومی

- برای تولید اعداد تصادفی، `:rand.uniform` در Erlang یا `Enum.random` نقاط شروع خوبی هستند.
- از `Integer.pow` می‌توان برای یافتن توان یک عدد استفاده کرد و `rem` برای باقیمانده.
- هیچ‌کدام از این دو برای اعداد صحیح بسیار بزرگ چندان خوب (یا سریع) کار نمی‌کند. رمزنگاری عموماً از اعداد بزرگ‌تر از ۱۰۲۴ بیت استفاده می‌کند. ماژول `:crypto` در Erlang تابع مفیدی برای یافتن باقیمانده‌ی یک توان دارد، به‌ویژه برای اعداد صحیح بسیار بزرگ، اما ممکن است برای کدگشایی آن به `:binary` نیاز داشته باشید.
