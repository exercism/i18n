# دستورالعمل‌ها

در این تمرین، دارید با یک دوست بازی حدس عدد انجام می‌دهید. قواعد بازی ساده است: شما به‌طور مخفیانه عددی بین `1` و `100` انتخاب می‌کنید و دوستتان تلاش می‌کند حدس بزند چه عددی را انتخاب کرده‌اید. برای کمک به دوستتان، بسته به اینکه حدس چقدر به عددی که انتخاب کرده‌اید (`42`) نزدیک بوده، پاسخ متفاوتی می‌دهید. قواعد پاسخ‌های مختلف این‌هاست:

- اگر حدس `42` باشد: «Correct»
- اگر حدس `41` یا `43` باشد: «So close»
- اگر حدس کمتر از `41` باشد: «Too low»
- اگر حدس بیشتر از `43` باشد: «Too high»

چهار کار دارید تا پاسخ حدس‌ها را پیاده‌سازی کنید.

## 1. پاسخ به یک حدس درست

تابع `reply` را پیاده‌سازی کنید تا به یک حدس درست پاسخ دهد:

```gleam
reply(42)
// -> "Correct"
```

## 2. پاسخ به یک حدس نزدیک

تابع `reply` را تغییر دهید تا به حدس‌های نزدیک پاسخ دهد:

```gleam
reply(41)
// -> "So close"
```

## 3. پاسخ به حدس‌های خیلی پایین

تابع `reply` را تغییر دهید تا به حدس‌های خیلی پایین پاسخ دهد:

```gleam
reply(25)
// -> "Too low"
```

## 4. پاسخ به حدس‌های خیلی بالا

تابع `reply` را تغییر دهید تا به حدس‌های خیلی بالا پاسخ دهد:

```gleam
reply(88)
// -> "Too high"
```
