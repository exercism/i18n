# دستورالعمل‌ها

در این تمرین، یک ترازو را مدل‌سازی می‌کنید.

## 1. ساخت حالت اولیه برای ترازو

ترازو هنگام مقداردهی اولیه باید تنظیمات کارخانه‌ی خود را مبنا قرار دهد، که بسته به محل فروش دستگاه متفاوت است.
بنابراین باید بتوان ترازو را با یک دقت مشخص و با تعیین اینکه متریک است یا امپریال، مقداردهی اولیه کرد.

متد `WeighingMachine#initialize` را پیاده‌سازی کنید که دو آرگومان می‌گیرد: `precision` که از نوع `Int32` است و `metric` که از نوع `Bool` است.
آرگومان `metric` وقتی `true` باشد یعنی دستگاه باید از سیستم متریک استفاده کند، در غیر این صورت باید از سیستم امپریال استفاده کند.
متد `initialize` همچنین باید متغیر نمونه‌ی `@weight` را روی `0.0` تنظیم کند.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. امکان تعیین دقت برای ترازو

برای برآورده کردن نیازهای متفاوت، به هر ترازو اجازه می‌دهیم که با یک دقت مشخص سفارشی‌سازی شود (تعداد رقم‌های بعد از جداکننده‌ی اعشار).

متد گیرنده‌ی `WeighingMachine#precision` را پیاده‌سازی کنید تا دقت ترازو را برگرداند.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. امکان تنظیم وزن روی ترازو

ویژگی `WeighingMachine#weight` را پیاده‌سازی کنید تا بتوان وزن را هم خواند _و_ هم تنظیم کرد:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. امکان تغییر واحد دستگاه بین متریک و امپریال

ویژگی `WeighingMachine#metric=` را پیاده‌سازی کنید تا بتوان واحد را تنظیم کرد.
این ویژگی باید یک مقدار «منطقی» بپذیرد.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
