# پیوست دستورالعمل‌ها

## «ثبات‌ها»

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | ورودی     | عدد صحیح | عدد ورودی               |
| `$v0`    | خروجی     | عدد صحیح | تعداد تخم‌ها             |
| `$t0-9`  | موقت | هرچه     | برای نگهداری موقت استفاده می‌شود |
