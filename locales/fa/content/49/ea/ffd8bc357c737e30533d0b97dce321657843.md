# مقدمه

دوستتان Eliud مزرعه‌ای را از مادربزرگش Tigist به ارث برده است.
مادربزرگش مخترع بود و عادت داشت وسایل را به شکلی بیش از حد پیچیده بسازد.
مرغدانی یک نمایشگر دیجیتال دارد که عددی رمزگذاری‌شده را نشان می‌دهد؛ این عدد موقعیت همه‌ی تخم‌مرغ‌هایی را نمایش می‌دهد که می‌توان آن‌ها را برداشت.

Eliud از شما می‌خواهد برنامه‌ای بنویسید که تعداد واقعی تخم‌مرغ‌های داخل مرغدانی را نشان دهد.

رمزگذاری اطلاعات مربوط به موقعیت به این شکل محاسبه می‌شود:

1. جاهای بالقوه‌ی تخم‌گذاری را بررسی کنید و برای تخم‌مرغ موجود `1` و برای جای خالی `0` را علامت بزنید.
2. عدد را از دودویی به دهدهی تبدیل کنید.
3. نتیجه را روی نمایشگر نشان دهید.

مثال ۱:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

مثال ۲:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
