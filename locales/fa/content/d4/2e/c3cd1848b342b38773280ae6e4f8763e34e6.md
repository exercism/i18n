# دستورالعمل‌ها

به دنیای *ChronoRealms* خوش آمدید، سرزمینی جادویی که در آن Timekeepers قدرتمند جریان زمان را کنترل می‌کنند.

در این قلمرو، Timekeepers «`TimeShard`ها» را مدیریت می‌کنند، واحدهای ویژه‌ای که می‌توان آن‌ها را جمع، تفریق، مقایسه و حتی از نظر برابری بررسی کرد.

وظیفه‌ی شما این است که با پیاده‌سازی عملگرهای سفارشی برای دستکاری این `TimeShard`ها به Timekeepers کمک کنید.

Timekeepers از شما می‌خواهند که یک `struct` سفارشی به نام `TimeShard` بسازید که از عملیات زیر پشتیبانی کند:

۱. **جمع و تفریق `TimeShard`ها**: Timekeepers باید بتوانند `TimeShard`ها را جمع و تفریق کنند تا خط زمانی را کنترل کنند.
۲. **مقایسه‌ی `TimeShard`ها**: گاهی باید `TimeShard`ها را مقایسه کرد تا ببینیم کدام بزرگ‌تر است یا اینکه برابرند.
۳. **بررسی برابری**: Timekeepers باید بررسی کنند که آیا دو `TimeShard` از نظر مقدار یکسان هستند.

مأموریت شما این است که `trait`های زیر را برای `struct` `TimeShard` پیاده‌سازی کنید:

۱. **جمع (`Add`)**: جمع دو نمونه `TimeShard` را ممکن کنید.
۲. **تفریق (`Sub`)**: تفریق یک `TimeShard` از `TimeShard` دیگر را ممکن کنید.
۳. **برابری (`PartialEq`)**: به Timekeepers اجازه دهید بررسی کنند که آیا دو نمونه `TimeShard` یکسان هستند.
۴. **مقایسه (`PartialOrd`)**: امکان مقایسه‌ی دو نمونه `TimeShard` را فراهم کنید تا ببینید کدام بزرگ‌تر یا کوچک‌تر است.

یک `TimeShard` با `struct`ی نمایش داده می‌شود که یک مقدار صحیح (`i32`) را نگه می‌دارد.

`trait`های لازم را پیاده‌سازی کنید تا کار Timekeepers آسان‌تر شود.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
