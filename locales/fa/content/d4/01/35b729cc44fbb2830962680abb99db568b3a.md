# راهنمایی‌ها

## عمومی
- [نوع][types] یک متغیر بر اساس مقدار آن متغیر مشخص می‌شود: *10* به‌عنوان `Int`، *'Hello'* به‌عنوان `String` یا *2.0* به‌عنوان `double`.

## 1. تعریف ثابت زمان پخت مورد انتظار بر حسب دقیقه

- باید یک متغیر ثابت تعریف کنید و یک مقدار صحیح به آن نسبت دهید.
- ثابت‌ها را می‌توان از طریق [New-Variable cmdlet][new variable] تعریف کرد.

## 2. محاسبه‌ی زمان پخت باقی‌مانده بر حسب دقیقه

- باید یک [تابع][defining functions] با یک پارامتر تعریف کنید.
- برای کم کردن مقادیر از [عملگر ریاضی تفریق][arithmetic] استفاده کنید.
- این تابع باید [یک مقدار برگرداند][return].

## 3. محاسبه‌ی زمان آماده‌سازی بر حسب دقیقه

- باید یک [تابع][defining functions] با یک پارامتر تعریف کنید.
- برای ضرب کردن مقادیر از [عملگر ریاضی ضرب][arithmetic] استفاده کنید.
- می‌توانید به‌جای استفاده از یک «عدد جادویی» در کدتان، یک _ثابت_ اضافی برای زمان بر حسب دقیقه به ازای هر لایه تعریف کنید.
- این تابع باید [یک مقدار صحیح برگرداند][return].

## 4. محاسبه‌ی مجموع زمان سپری‌شده‌ی پخت (آماده‌سازی + پخت) بر حسب دقیقه

- یک [تابع][defining functions] با دو پارامتر تعریف کنید.
- می‌توانید تابعی را که قبلاً تعریف کرده‌اید _فراخوانی_ کنید.
- می‌توانید برای جمع زدن مقادیر از [عملگر ریاضی جمع][arithmetic] استفاده کنید.
- این تابع باید [یک مقدار صحیح برگرداند][return].

## 5. به‌روزرسانی دستور پخت با یادداشت‌ها

- یک تابع بدون پارامتر تعریف کنید.
- این تابع باید یک مقدار رشته‌ای برگرداند.
