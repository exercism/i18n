# مقدمه

## عملگرهای مقایسه

عملگرهای مقایسه در Julia مانند بسیاری از زبان‌های دیگر هستند، هرچند چند گزینه‌ی اضافه هم برای علاقه‌مندان به ریاضی دارند.

برای بررسی برابری، عملگرها `==` (برابر) و `!=` یا `≠` (نابرابر) هستند.

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

علاوه بر این، عملگرهای متعددی برای کوچک‌تر و بزرگ‌تر بودن هم داریم.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

همان‌طور که اغلب در Julia می‌بینیم، یک ویرایشگر مناسب استفاده از نمادهای ریاضی را آسان می‌کند. `\ne`، `\le` یا `\ge` را تایپ کنید و سپس `TAB` را بزنید تا `≠`، `≤` یا `≥` را به دست آورید.

مثال قبلی فقط از اعداد استفاده می‌کند، اما در بخش‌های دیگر برنامه‌ی درسی خواهیم دید که انواع دیگری هم مفهوم ترتیب دارند و می‌توان کوچک‌تر یا بزرگ‌تر بودن آن‌ها را بررسی کرد.

عملگرهای مقایسه را می‌توان زنجیره‌ای به کار برد که نحوه‌ی نگارشی روشن و موجز را ممکن می‌کند:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

مثال قبلی معادل `1 ≤ n && n ≤ 5` است.

## انشعاب با `if`

این شکل کامل یک دستور شرطی `if` است:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

نیازی به پرانتز `()` یا آکولاد `{}` نیست و تورفتگی «فقط» برای بهتر شدن خوانایی است _(اما خوانایی بسیار مهم است!)_.

هم `elseif` و هم `else` اختیاری‌اند و می‌توان چند بلوک `elseif` نوشت. اما `end` الزامی است.

می‌توان دستورهای شرطی `if` را تودرتو کرد، هرچند ممکن است بخواهید با استفاده‌ی سنجیده از پرانتز، تورفتگی و کامنت، به خوانایی کمک کنید.

کوتاه‌ترین شکل یک دستور شرطی `if` به این صورت است:

```julia
if n < 0
    n = 0
end
```

یادآوری: تنها عبارت‌هایی می‌توانند به عنوان شرط به کار روند که به `true` یا `false` ارزیابی شوند.
Julia آگاهانه از هرگونه مفهوم «درست‌نمایی» پرهیز می‌کند، بنابراین مقدارهای صفر، رشته‌های خالی و آرایه‌های خالی _معادل_ `false` نیستند. 

## عملگر سه‌تایی

یک موقعیت ساده و رایج، انتخاب یکی از دو مقدار بر اساس یک شرط است.

Julia هم مانند بسیاری از زبان‌ها یک عملگر سه‌تایی دارد تا این کار را موجزتر کند.

نحوه‌ی نگارش آن `conditional ? value_if_true : value_if_false` است.

پس مثال قبلی را می‌توان این‌گونه بازنویسی کرد:

```julia
n = n < 0 ? 0 : n
```

کامپایلر پرانتز را الزامی نمی‌داند، اما پرانتزها ممکن است خوانایی را بهتر کنند.
