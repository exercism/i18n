# مقدمه

در Cairo، «سربارگذاری عملگر» به شما امکان می‌دهد تا هنگام کار با انواع سفارشی خودتان، رفتار سفارشی برای عملگرهای استانداردی مانند `+`، `-`، `==`، `<` و غیره تعریف کنید.

این کار با پیاده‌سازی `trait`های مشخص برای انواع سفارشی شما انجام می‌شود.

## `trait`های اصلی عملگرها

### `Add` و `Sub`

`trait`های `Add` و `Sub` به شما امکان می‌دهند تعریف کنید که جمع (`+`) و تفریق (`-`) با نوع شما چگونه کار می‌کنند:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`trait` `PartialEq` مقایسه‌ی برابری (`==` و `!=`) را بین نمونه‌های نوع شما ممکن می‌سازد.

این کار را می‌توان اغلب با `#[derive(PartialEq)]` به‌صورت خودکار انجام داد.

### `PartialOrd`

`trait` `PartialOrd` به شما امکان می‌دهد بین نمونه‌های نوع خودتان عملیات مقایسه (`<`، `>`، `<=`، `>=`) را انجام دهید.

این `trait` از شما می‌خواهد که حداقل متد `lt` (کوچک‌تر از) را پیاده‌سازی کنید:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
