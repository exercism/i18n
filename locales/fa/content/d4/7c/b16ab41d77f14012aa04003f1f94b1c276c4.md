# توضیحات

در این تمرین، برنامه‌ای مفید می‌سازید تا لازم نباشد مقادیر نوارها را به خاطر بسپارید.
این برنامه ۱، ۴ یا ۵ رنگ را به عنوان ورودی می‌گیرد و مقدار درست را بر حسب اهم به عنوان خروجی می‌دهد.
نوارهای رنگی به این صورت کدگذاری شده‌اند:

| رنگ       | مقدار |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

در [`Resistor Color Trio`][resistor-color-trio-exercise] سه نوار رنگی اول را رمزگشایی کردید.
برای مثال: orange-orange-brown به مقدار اصلی `330` تبدیل می‌شد.
در این تمرین باید «تلورانس» را هم به این ترکیب اضافه کنید.
تلورانس بیشترین مقداری است که یک مقدار می‌تواند بالاتر یا پایین‌تر از مقدار اصلی باشد.
برای مثال، اگر نوار آخر green باشد، بیشترین تلورانس `±0.5%` خواهد بود.

نوار تلورانس یکی از این مقادیر را خواهد داشت:

| رنگ  | تلورانس |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

مقاومت چهارنواری این‌گونه ساخته می‌شود:

| نوار ۱  | نوار ۲  | نوار ۳     | نوار ۴    |
| ------- | ------- | ---------- | --------- |
| مقدار ۱ | مقدار ۲ | ضریب | تلورانس |

مثال‌ها:

- orange-orange-brown-green برابر `330` اهم با تلورانس `±0.5%` می‌شود.
- orange-orange-red-grey برابر `3300` اهم با تلورانس `±0.05%` می‌شود.

تفاوت مقاومت چهارنواری و پنج‌نواری این است که مقاومت پنج‌نواری یک نوار اضافه دارد که مقدار دقیق‌تری را نشان می‌دهد.

| نوار ۱  | نوار ۲  | نوار ۳  | نوار ۴     | نوار ۵    |
| ------- | ------- | ------- | ---------- | --------- |
| مقدار ۱ | مقدار ۲ | مقدار ۳ | ضریب | تلورانس |

مثال‌ها:

- orange-orange-orange-black-green برابر `333` اهم با تلورانس `±0.5%` می‌شود.
- orange-red-orange-blue-violet برابر `323 million` اهم با تلورانس `±0.1%` می‌شود.

مقاومت تک‌نواری هم وجود دارد.
مقاومت تک‌نواری فقط رنگ black با مقدار 0 دارد.

برنامه‌ی شما باید یک `list` ورودی از رنگ‌های نوار مقاومت را به یک برچسب تبدیل کند:

«... ohms ±...%»

پس یک `list` ورودی از `["orange", "orange", "black", "green"]` باید این را برگرداند:

«33 ohms ±0.5%»

وقتی هزاران اهم داریم، می‌گوییم «kiloohms».
این شبیه به گفتن «کیلومتر» برای ۱۰۰۰ متر و «کیلوگرم» برای ۱۰۰۰ گرم است.

پس یک `list` ورودی از `["orange", "orange", "orange", "grey"]` باید این را برگرداند:

«33 kiloohms ±0.05%»

وقتی میلیون‌ها اهم داریم، می‌گوییم «megaohms».

پس یک `list` ورودی از `["orange", "orange", "blue", "red"]` باید این را برگرداند:

«33 megaohms ±2%»

[resistor-color-trio-exercise]: https://exercism.org/tracks/python/exercises/resistor-color-trio
