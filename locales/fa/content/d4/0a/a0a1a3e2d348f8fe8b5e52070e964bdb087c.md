# Tests

برای تست کردن راه‌حل خود، ترمینال را باز کنید و در پوشه‌ی تمرین (همان پوشه‌ای که فایل `Mason.toml` و پوشه‌های `src/` و `test/` در آن قرار دارند) این دستور را اجرا کنید:

```
mason test
```

اگر به نظرتان پیام خطا به‌اندازه‌ی کافی گویا نیست، می‌توانید برای گرفتن پیامی مفصل‌تر این کار را امتحان کنید.

```
mason test --show
```
