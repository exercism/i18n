# دستورالعمل‌ها

شما در حال ساختن یک ماشین‌حساب کوچک بر پایه‌ی نمادگذاری لهستانی معکوس (RPN) هستید.
وضعیت ماشین‌حساب یک *پشته‌ی مقدارها* است که به‌شکل یک آرایه‌ی Factor نمایش داده می‌شود. یک *عملیات* هم یک «نقل‌قول» است که چنین پشته‌ای را می‌گیرد و پشته‌ی تازه‌ای برمی‌گرداند.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. پیاده‌سازی جمع

تابع `add-op` را طوری تعریف کنید که دو مقدار بالای پشته را از پشته بیرون بیاورد، جمعشان را روی پشته بگذارد و پشته‌ی جدید را برگرداند.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. پیاده‌سازی ضرب

تابع `multiply-op` را به همین شکل، اما برای ضرب تعریف کنید.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. اعمال یک عملیات

تابع `apply-op` را طوری تعریف کنید که یک پشته و یک عملیات (یک نقل‌قول) را از پشته‌ی داده بردارد و پشته‌ی جدید ماشین‌حساب را برگرداند.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. ارزیابی یک برنامه

تابع `evaluate` را طوری تعریف کنید که یک پشته‌ی شروع و یک آرایه‌ای از عملیات‌ها را بگیرد، هر عملیات را به‌نوبت اعمال کند و پشته‌ی نهایی را برگرداند.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. ارزیابی با اسم

حالا برنامه یک فهرست از *اسم‌های عملگر* (رشته‌ها) است و ماشین‌حساب هر اسم را در یک assoc جست‌وجو می‌کند که اسم‌ها را به عملیات‌ها نگاشت می‌کند.

تابع `evaluate-named` را طوری تعریف کنید که یک پشته‌ی شروع، یک assoc از عملیات‌های نام‌دار و یک آرایه از اسم‌ها را بگیرد و پشته‌ی نهایی را برگرداند.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. تقسیم ایمن

یک ماشین‌حساب واقعی، وقتی از آن خواسته می‌شود بر صفر تقسیم کند، نباید بی‌صدا نتیجه‌ی بی‌معنی تولید کند. کلاس خطای `zero-divisor-error` از قبل برای شما تعریف شده است. تابع `divide-op` را مشابه `add-op` و `multiply-op` پیاده‌سازی کنید، با این تفاوت که اگر مقسوم‌علیه در بالای پشته `0` باشد، یک `zero-divisor-error` تازه را `throw` می‌کند.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
