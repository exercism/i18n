# راهنمایی‌ها

## 1. درج یک کارت در بالای پشته

- از تابع [`ArrayTrait::append`][append] می‌توان استفاده کرد تا به انتهای آرایه چیزی اضافه شود.

## 2. برداشتن کارت بالایی از پشته

- همیشه می‌توانید یک آرایه را به یک `span` تبدیل کنید و سپس از تابع [`SpanTrait::pop_back`][pop-back] استفاده کنید تا از انتهای آرایه حذف کنید.

## 3. درج یک کارت در پایین پشته

- راهی برای اضافه کردن یک عنصر به ابتدای آرایه وجود ندارد، اما یک راه‌حل این است که یک آرایه‌ی تازه‌ی یک‌عنصری بسازید و آرایه‌ی قدیمی را به‌صورت یک `span` با [`ArrayTrait::append_span`][append-span] به آن اضافه کنید.

## 4. برداشتن یک کارت از پایین پشته

- از تابع [`ArrayTrait::pop_front`][pop-front] می‌توان استفاده کرد تا از ابتدای آرایه حذف شود.

## 5. بررسی اندازه‌ی پشته

- از تابع [`ArrayTrait::len`][len] می‌توان استفاده کرد تا طول آرایه به دست آید.
