# مقدمه

بسته‌ی `java.time` که در Java 8 معرفی شد، چندین کلاس برای کار با تاریخ و زمان در خود دارد.

## `LocalDate`

کلاس `java.time.LocalDate` یک تاریخ را بدون منطقه‌ی زمانی در [تقویم ISO-8601][iso-8601] نمایش می‌دهد، مانند `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

تاریخ‌ها را می‌توان با تاریخ‌های دیگر مقایسه کرد:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

یک نمونه‌ی `LocalDate` متدهای getter دارد که با آن‌ها می‌توان بخش‌های زمان را از آن گرفت:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

یک نمونه‌ی `LocalDate` متدهایی دارد که واحدهای زمانی را به آن اضافه می‌کنند:

```exercism/note
این متدها یک نمونه‌ی _جدید_ `LocalDate` برمی‌گردانند و نمونه‌ی موجود را به‌روزرسانی نمی‌کنند، چون کلاس `LocalDate` تغییرناپذیر است.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

کلاس `java.time.LocalDateTime` یک تاریخ و زمان را بدون منطقه‌ی زمانی در [تقویم ISO-8601][iso-8601] نمایش می‌دهد، مانند `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

می‌توانید یک نمونه‌ی `LocalDate` را به یک `LocalDateTime` تبدیل کنید:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## قالب‌بندی تاریخ و زمان

هر دو کلاس `LocalDate` و `LocalDateTime` هنگام تبدیل از `String` و به `String` از نماد استاندارد [ISO-8601][iso-8601] استفاده می‌کنند.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

تجزیه‌ی یک `LocalDate` یا `LocalDateTime` از `String`ی مانند این با قالبی متفاوت ممکن نیست.
در عوض، برای قالب‌بندی تاریخ‌ها با قالبی سفارشی باید از `java.time.format.DateTimeFormatter` استفاده کنید:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

هنگام ساخت قالب سفارشی می‌توان یک locale هم مشخص کرد تا برای مناطق مختلف قالب‌بندی و تجزیه انجام شود:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
