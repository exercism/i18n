# مقدمه

جاوااسکریپت یک شیء توکار `Date` دارد که تاریخ و زمان را ذخیره می‌کند و روش‌هایی برای مدیریت آن‌ها فراهم می‌آورد.

<!-- prettier-ignore -->
~~~exercism/caution
این شیء بر پایه‌ی کلاس `java.util.Date` جاوا ساخته شد که در اوایل دهه‌ی ۲۰۱۰ جایگزین شد، اما به دلیل سازگاری با نسخه‌های پیشین، `Date` جاوااسکریپت همچنان پابرجاست.

چون کار کردن با تاریخ‌ها به‌طور کلی دشوار است و چون مدیریت منطقه‌ی زمانی در آن‌ها یا بسیار ضعیف است یا اصلاً وجود ندارد، کتابخانه‌های زیادی پدید آمده‌اند؛ مانند `moment.js`، `day.js`، `date-fns` و `luxon`.
هیچ‌یک از این‌ها در Exercism در دسترس نیست.

در پروژه‌های خودتان از بسته‌های منسوخ یا بدون نگهداری مانند `moment.js` استفاده نکنید و به‌جای آن به گزینه‌های مدرن‌تری مانند `luxon` یا [Temporal][mdn-temporal] که هنوز چندان رایج نشده است تکیه کنید.
تمرکز این تمرین روی `Date` است که تا پایان عمر جاوااسکریپت مرتبط باقی می‌ماند.

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## ساخت

یک شیء `Date` نمونه‌ای از کلاس `Date` است.
می‌توان آن را بدون فرستادن هیچ آرگومانی به تابع سازنده ساخت.
نتیجه یک شیء `Date` است که تاریخ و زمان کنونی را نمایش می‌دهد:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### **مهر زمانی یونیکس (عدد)**

اگر یک عدد فرستاده شود، به‌عنوان یک `timestamp` تفسیر می‌شود.
مهر زمانی یک عدد صحیح است که شمار **میلی‌ثانیه**های سپری‌شده از **۱ ژانویه ۱۹۷۰ [UTC][defn-utc]+0** را نشان می‌دهد.

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

ممکن است انتظار داشته باشید که `new Date(0)` «زودترین» شیء تاریخ را بسازد، اما جاوااسکریپت تاریخ را به منطقه‌ی زمانی محلی شما تبدیل می‌کند، یعنی فقط کسانی که در منطقه‌ی زمانی [GMT / با UTC+0][defn-gmt] هستند در واقع مقدار [مبدأ یونیکس][defn-unix-epoch] را به دست می‌آورند.

### **مهر زمانی ISO 8601 (رشته)**

می‌توانید یک مقدار رشته‌ای که نماینده‌ی یک تاریخ است به سازنده‌ی `Date` بفرستید.
**تنها** قالبی که در همه‌ی پیاده‌سازی‌ها یکسان است، [نسخه‌ی ساده‌شده][mdn-date-string-format] چیزی است که به‌صورت بین‌المللی شناخته و استاندارد شده است و به آن [رشته‌های مهر زمانی ISO 8601][defn-iso8601] می‌گویند.

یک لحظه در زمان به [UTC][defn-gmt] این‌گونه است:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

که در آن جای‌گذاری‌های زیر انجام می‌شود:

| کلید | توضیح                                   | پیش‌فرض |
| ---- | --------------------------------------------- | ------- |
| YYYY | سال تقویمی، با ۴ رقم    |         |
| MM   | ماه تقویمی، با ۲ رقم   | 01      |
| DD   | روز تقویمی، با ۲ رقم     | 01      |
| T    | حرف T به‌صورت عینی، جداکننده‌ی تاریخ از زمان |         |
| HH   | ساعت در قالب ۲۴ساعته، ۲ رقم        | 00      |
| mm   | دقیقه‌ها، ۲ رقم                         | 00      |
| ss   | ثانیه‌ها، ۲ رقم                         | 00      |
| mss  | میلی‌ثانیه‌ها، ۳ رقم                    | 000     |
| Z    | حرف Z به‌صورت عینی، یا یک انحراف `+/-HH:mm`   |         |

حرف عینی `Z` نشان‌دهنده‌ی UTC است (بدون منطقه‌ی زمانی، بدون ساعت تابستانی).

چون برای بیشتر اجزا مقدار پیش‌فرض وجود دارد، حذف بخش‌های انتهایی معتبر است:

```text
YYYY-MM-DD
```

به‌صورت پیش‌فرض زمانی برابر 00:00:00.000 در نظر گرفته می‌شود.

اگر مهر زمانی به `Z` ختم نشود و به `+HH:mm` یا `-HH:mm` هم ختم نشود (که نشان‌دهنده‌ی انحراف منطقه‌ی زمانی است)، به دلایل تاریخی، این قاعده اعمال می‌شود:

> وقتی انحراف منطقه‌ی زمانی وجود ندارد، قالب‌های فقط-تاریخ به‌عنوان زمان UTC تفسیر می‌شوند و قالب‌های تاریخ-و-زمان به‌عنوان زمان محلی.
> تفسیر به‌عنوان زمان UTC ناشی از یک خطای تاریخی در مشخصات است که با ISO 8601 سازگار نبود، اما به دلیل سازگاری با وب نمی‌توانست تغییر کند.
> به [تجزیه‌گر معیوب، یک مسئله‌ی واقعی وب][ref-broken-parser] نگاه کنید.

### **شیء Date**

یک شیء تاریخ موجود را هم می‌توان به‌عنوان آرگومان سازنده به کار برد.
این کار یک رونوشت از شیء `Date` موجود با همان تاریخ و زمان می‌سازد.

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### **فرستادن مقادیر تک‌تک اجزای تاریخ و زمان**

می‌توان با فرستادن سه عدد یک تاریخ ساخت.
و با فرستادن ۶ عدد می‌توان تاریخی همراه با زمان ساخت.

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

مقدار دوم `month` است که از `0` برای ژانویه شروع می‌شود و تا `11` برای دسامبر ادامه دارد.

## `Date.parse()`

ممکن است جاهایی به تابع تجزیه‌ی تاریخ `Date.parse` اشاره شده باشد.
چون این تابع تنها چند مورد ثابت (مسلّم) دارد و بقیه‌ی پیاده‌سازی آن مشخص نشده است (و بنابراین استاندارد نیست)، بهتر است از آن استفاده نکنید.

## دسترسی به اجزای `Date`

روش‌های گوناگونی روی شیءهای تاریخ وجود دارد که اجزای تاریخ را برمی‌گردانند:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

هر یک از این‌ها یک گونه‌ی `set` متناظر دارد (مثلاً `setFullYear`) که مقدار را به‌روزرسانی می‌کند.
هر مقدار سرریزشده به جزء بعدی منتقل می‌شود:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

برای همه‌ی روش‌ها گونه‌های UTC هم وجود دارد که منطقه‌ی زمانی محلی را نادیده می‌گیرند.

## تبدیل از تاریخ

شیءهای تاریخ روشی به نام `getTime()` دارند که مهر زمانی یونیکس را بر حسب میلی‌ثانیه برمی‌گرداند؛ یعنی شمار میلی‌ثانیه‌های سپری‌شده از نیمه‌شب آغاز ۱ ژانویه ۱۹۷۰ به وقت UTC.
همچنین روش `toISOString()` در دسترس است که یک شیء تاریخ را به رشته‌ی مهر زمانی ISO 8601 تبدیل می‌کند.

## مقایسه‌ی تاریخ‌ها

عملگرهای بزرگ‌تر از (`>`) و بزرگ‌تر یا مساوی (`>=`) و همچنین کوچک‌تر از (`<`) و کوچک‌تر یا مساوی (`<=`) را می‌توان مستقیماً بین دو تاریخ یا بین یک تاریخ و یک عدد به کار برد.
این کار می‌کند چون جاوااسکریپت می‌کوشد تاریخ را به یک مقدار اولیه تبدیل کند.
