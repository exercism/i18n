# testها

testها را با این دستور اجرا کنید:

```shell
corepack pnpm test
```

مطمئن شوید که code شما هم مانند سایر کاربران، با ESLint از بهترین شیوه‌ها و سبک‌های نگارش پیروی می‌کند. ESLint ابزاری است که تحلیل ایستا روی code شما انجام می‌دهد.
گاهی ابزارهایی مثل این می‌توانند در پیدا کردن غلط‌های تایپی یا اشتباهات ساده در code JavaScript شما، وقتتان را صرفه‌جویی کنند:

```shell
corepack pnpm lint
```

همچنین می‌توانید Jest را در حالت «watch» اجرا کنید؛ این حالت هر بار که تغییری در code یا ماژول test ذخیره کنید، testهای شما را به‌طور خودکار دوباره اجرا می‌کند:

```shell
corepack pnpm watch
```

## درک skip کردن testها

متد `skip` به مجموعه‌ی test می‌گوید که یک test را اجرا نکند. این تابع را می‌توان با نام‌های دیگری هم به کار برد: `it.skip(name, fn)` یا `xit(name, fn)` یا `xtest(name, fn)`

- چرا skip می‌شوند؟

تا کاربران بتوانند هر بار روی یک test تمرکز کنند و همزمان با پیشرفت راه‌حل، آن‌ها را یکی‌یکی فعال کنند.

- چطور آن‌ها را فعال کنیم؟

`xtest` را به `test` تغییر دهید.

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## ساخت اولین ماژول JavaScript 2015 خودتان

معمولاً testهای این مسیر یادگیری، پیاده‌سازی شما را با import کردن آن به‌عنوان یک ماژول JavaScript بارگذاری می‌کنند: `import { Bob } from './bob.js';`.
فقط کافی است پیاده‌سازی خودتان را از همان فایل ارجاع‌شده، `bob.js`، export کنید:

```javascript
export function hey(message) {}
```

می‌توانید اطلاعات بیشتر درباره‌ی ماژول‌ها را در [مستندات Babel](https://babeljs.io/docs/learn-es2015/#modules) پیدا کنید.
برای اینکه شروع کار راحت‌تر باشد، یک فایل _اسکلت_ JavaScript در این پوشه وجود دارد.
