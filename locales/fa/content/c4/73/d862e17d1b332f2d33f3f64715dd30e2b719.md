# درباره

جاهایی که نوع‌ها نمی‌توانند به‌صورت ضمنی تبدیل شوند، باید از یک عملگر تبدیل صریح [عملگر تبدیل][cast-operator] استفاده کنید. عملگر تبدیل چیزی نیست جز قرار گرفتن نوع مقصد در پرانتز، پیش از مقداری که می‌خواهید تبدیل کنید:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

استفاده از تبدیل صریح بالقوه خطرناک است. دو خطای رایج‌تر عبارت‌اند از:

- تبدیل به نوعی ناسازگار. این کار در زمان اجرا یک استثنا پرتاب می‌کند.
- تبدیل به مقدار عددی‌ای که به‌اندازه‌ی کافی «پهن» نیست. در مورد اعداد صحیح، این کار می‌تواند به تضاد علامت یا پرتاب یک استثنای سرریز منجر شود

توجه: یک عبارت از نوع `int` را می‌توان به‌صورت صریح به `char` تبدیل کرد. این کار ممکن است به یک `char` نامعتبر منجر شود.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
