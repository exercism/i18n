# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | ورودی        | عدد صحیح | تعداد ارقام ورودی                       |
| `$a1`    | ورودی        | عدد صحیح | مبنای ارقام ورودی                        |
| `$a2`    | ورودی        | عدد صحیح | مبنای ارقام خروجی                        |
| `$a3`    | ورودی/خروجی | آدرس     | آرایه‌ی قابل بازنویسی از کلمه‌های رقمی     |
| `$v0`    | خروجی        | عدد صحیح | تعداد ارقام خروجی؛ اگر ورودی نامعتبر باشد، -1 |
| `$t0-9`  | موقت         | هر نوع   | برای ذخیره‌سازی موقت استفاده می‌شود       |
