# درباره

Nim یک زبان همه‌کاره است که آندریاس رومپف آن را طراحی و توسعه داده و نخستین بار در سال ۲۰۰۸ پدیدار شد.
زبانى است که برای کارآمد، گویا و زیبا بودن طراحی شده است.
Nim به‌صورت ایستا نوع‌دهی شده و کامپایل می‌شود، اما به شما اجازه می‌دهد کد زیبایی بنویسید که بهینه اجرا شود.
Nim با کامپایل کد به C، C++، JavaScript یا Objective-C به شما امکان می‌دهد برای پلتفرم‌های متعددی برنامه بنویسید.
نحوه‌ی نگارش Nim شبیه Python است و بسیاری از ویژگی‌های Python را دارد، اما از زبان‌های متعددی مانند C، C++، C#، Lisp، Ada، Go، Oberon و دیگران الهام گرفته است.

از آنجا که Nim زبانی همه‌کاره است، می‌توان از آن در جاهای مختلفی استفاده کرد، اما در حوزه‌ی توسعه‌ی بازی و برنامه‌نویسی سیستمی، از جمله سیستم‌های نهفته، خلأ واقعی‌ای را پر کرده است.

Nim بسیاری از راحتی‌هایی را که در Python و زبان‌های دیگر پیدا می‌کنید به شما می‌دهد؛ مانند نحوه‌ی نگارش خوانا، یک سیستم مدیریت بسته برای استفاده از کتابخانه‌های جدید در پروژه‌هایتان، و traceback‌های کاربرپسند برای دیباگ خطاها.

Nim سرعت و قابلیت حمل C را به شما می‌دهد، اما با یک جمع‌کننده‌ی زباله‌ی کارآمد و نحوه‌ی نگارشی زیبا که زبان را برای تازه‌واردها بسیار قابل‌دسترس می‌کند.
Nim همچنین به شما کنترل می‌دهد؛ می‌توانید جمع‌کننده‌ی زباله را تغییر دهید یا کاملاً خاموشش کنید و این امکان را داشته باشید که حافظه را خودتان مدیریت کنید.
با Nim انواع پارادایم‌های برنامه‌نویسی و لایه‌های انتزاعی در اختیار شماست.
