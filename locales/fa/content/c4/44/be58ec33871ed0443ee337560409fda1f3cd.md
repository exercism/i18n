# مقدمه

## اعداد

ABAP چندین نوع عددی دارد. در این تمرین، از دو مورد از آن‌ها استفاده می‌کنید:

- `i` برای «عدد صحیح»، مانند تعداد روزها.
- `p` برای «مقدار اعشاری بسته»، مانند نرخ ساعتی یا تخفیف.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

عددهای اعشاری بسته، بیشترین طول و تعداد ارقام اعشار خود را تعریف می‌کنند.
عددهای اعشاری معمولاً به‌صورت مقدار متنی نوشته می‌شوند و کامپایلر یا `CONV` آن‌ها را به نوع اعشاری مقصد تبدیل می‌کند.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### گرد کردن

ABAP توابع عددی از پیش تعریف‌شده‌ای برای گرد کردن در اختیار می‌گذارد.
تابع `floor` به نزدیک‌ترین عدد صحیح کوچک‌تر گرد می‌کند و تابع `ceil` به نزدیک‌ترین عدد صحیح بزرگ‌تر.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## عملگرهای حسابی

ABAP از عملگرهای حسابی برای انجام محاسبات با مقدارهای عددی پشتیبانی می‌کند.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

عملگرهای پایه عبارت‌اند از:

- `+` برای جمع.
- `-` برای تفریق.
- `*` برای ضرب.
- `/` برای تقسیم.
- `MOD` برای باقی‌مانده‌ی تقسیم صحیح.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP ضرب و تقسیم را پیش از جمع و تفریق محاسبه می‌کند.
برای اینکه ترتیب مورد نظرتان را روشن کنید، می‌توانید از پرانتز استفاده کنید.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
