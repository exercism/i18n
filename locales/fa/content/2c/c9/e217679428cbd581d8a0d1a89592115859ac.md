# درباره

اجرای شرطی کد را می‌توان با استفاده از [عبارت‌های `if/elif/else`][conditional-expression] انجام داد. شرط‌هایی که در یک عبارت `if/elif/else` به کار می‌روند باید از نوع `bool` باشند. در F# مفهومی به نام مقادیر _truthy_ وجود ندارد.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

از آنجا که `if/elif/else` یک عبارت است، می‌توان آن را به یک اسم مقید کرد یا آن را از یک تابع برگرداند.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

همه‌ی شاخه‌ها باید یک نوع را برگردانند. در غیر این صورت، خطای کامپایلر رخ می‌دهد:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

شاخه‌های `else` و `elif` اختیاری‌اند، اما تنها در صورتی که نوع عبارت برگردانده‌شده [`unit`][unit-type] باشد.

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

عبارت `if/else` را می‌توان در یک خط هم نوشت. این کار را باید فقط برای عبارت‌های ساده‌ی `if` به کار برد.

```fsharp
let y = if x > 5 then 10 else 20
```
