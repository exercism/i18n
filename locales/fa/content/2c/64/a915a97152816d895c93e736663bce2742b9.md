# مقدمه

گسترش ایستا این امکان را می‌دهد که انواع موجود را بدون تغییر دادن کد منبعشان، به‌صورت ظاهری گسترش دهید. این کار با استفاده از دستور `using` انجام می‌شود. گسترش ایستا می‌تواند ابزاری قدرتمند باشد که امکان افزودن قابلیت به انواع را بدون تغییر واقعی آن‌ها فراهم می‌کند.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
