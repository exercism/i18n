# راهنمایی‌ها

## 1. تولید حروف صندلی

- مقدار بازگردانده‌شده باید از _نوع_ `generator` باشد.
- می‌توانید دنباله‌ای از حروف از `A` تا `D` داشته باشید و به‌صورت چرخشی از آن‌ها عبور کنید.
- برای بازگرداندن حرف بعدی از `yield` استفاده کنید.

## 2. تولید صندلی‌ها

- مقدار بازگردانده‌شده باید از _نوع_ `generator` باشد.
- ردیف `13` باید نادیده گرفته شود، پس از `12` به `14` بروید.
- به خاطر داشته باشید که مقادیر بازگردانده‌شده باید از کوچک به بزرگ مرتب باشند. `1A, 1B, 2A, ...`
- اینجا ممکن است خوب باشد که از توابعی که قبلاً تعریف کرده‌اید دوباره استفاده کنید یا آن‌ها را فراخوانی کنید.

## 3. تخصیص صندلی‌ها به مسافران

- مطمئن شوید که در شماره‌های صندلی هیچ فاصله‌ای وجود ندارد.
- اینجا ممکن است خوب باشد که از توابعی که قبلاً تعریف کرده‌اید دوباره استفاده کنید یا آن‌ها را فراخوانی کنید.

## 4. کدهای بلیت

- می‌توانید از `len()` برای گرفتن طول یک رشته استفاده کنید.
- می‌توانید از `"<string>" * <int>` برای تکرار یک رشته استفاده کنید.
