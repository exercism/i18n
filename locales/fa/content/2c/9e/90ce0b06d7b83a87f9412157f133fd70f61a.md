# دستورهای case

وقتی یک مقدار با فهرستی از حالت‌های ممکن مقایسه می‌شود، زنجیره‌ای از `elsif`ها همان حرف را بارها و بارها تکرار می‌کند:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` آن را یک بار می‌گوید:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

مقدار بعد از `case` می‌آید. هر `when` مقداری را مشخص می‌کند تا با آن مقایسه شود و اولین موردی که منطبق شود اجرا می‌شود.

## چند مقدار در یک when

یک `when` می‌تواند چند مقدار را فهرست کند که با ویرگول از هم جدا شده‌اند:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

این روی اعداد صحیح، کاراکترها و رشته‌ها کار می‌کند؛ هر چیزی که بتوان با `=` مقایسه‌اش کرد.

## The else is not optional

**یک `case` که با هیچ مقداری منطبق نشود و `else` نداشته باشد، خطایی است که هنگام رخ دادن، برنامه را متوقف می‌کند.**

این با `if` تفاوت دارد؛ در `if`، ننوشتن `else` فقط یعنی هیچ اتفاقی نمی‌افتد. با بیشتر زبان‌ها هم تفاوت دارد؛ در آن‌ها، `case`ی که هیچ تطابقی ندارد بی‌سروصدا هیچ کاری نمی‌کند.

پس هر `case` به یک `else` نیاز دارد، حتی وقتی مطمئن هستید که بخش‌های `when` همین حالا همه‌ی مقادیر را پوشش می‌دهند. بعداً یک منطقه‌ی چهارم اضافه می‌شود، `case` هم مطابق آن به‌روزرسانی نمی‌شود و برنامه روی اولین مسافری که از آن استفاده کند متوقف می‌شود.

## Only one when runs

وقتی یک `when` منطبق می‌شود، دستورهای بعد از `then` آن اجرا می‌شوند و `case` تمام می‌شود؛ برنامه بعد از `end` ادامه پیدا می‌کند. بخش‌های `when` که پایین‌تر آمده‌اند هرگز بررسی نمی‌شوند، پس لازم نیست چیزی بنویسید تا جلوی اجرای مورد بعدی را هم بگیرید.
