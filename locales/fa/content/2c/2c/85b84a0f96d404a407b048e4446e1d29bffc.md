# پیوست دستورالعمل

## راهنمایی‌ها

برای اینکه میزان چالش اینجا مناسب باشد، باید فقط از قابلیت‌هایی که در `Prelude` وجود دارد استفاده کنید. سعی کنید از `Data.List`، `Data.Char`، `Data.Bits` یا `Numeric` استفاده نکنید.

سعی کنید از `seq`، `$!` یا `BangPatterns` به‌شکل مناسب استفاده کنید تا مطمئن شوید راه‌حل کارآمد است.

نیازی به مدیریت ورودی نامعتبر نیست.
