# تسک

«تسک» ایشوهایی در GitHub است که دوست داریم افراد در انجامشان کمک کنند؛ از ویراستاری متن گرفته تا ساخت تمرین‌های مفهومی.
این تسک‌ها در وب‌سایت نمایش داده می‌شوند و به ایشوهای متناظرشان در GitHub پیوند می‌دهند.
هر تسک با یک یا چند ویژگی تگ می‌شود که این ویژگی‌ها از برچسب‌های ایشو پر می‌شوند.
سپس کاربر می‌تواند تسک‌ها را بر اساس ویژگی‌هایشان فیلتر کند.

## تگ

برای اینکه یک ایشو تسک به حساب بیاید، باید با یک یا چند برچسب مخصوص تسک برچسب‌گذاری شده باشد.
به این ترتیب، نگهدارندگان می‌توانند انتخاب کنند که فقط بعضی ایشوها به عنوان تسک نمایش داده شوند.

هر برچسب تسک به این شکل تعریف می‌شود: `x:<type>/<value>` و پنج نوع تسک پشتیبانی می‌شود:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### تگ Action

برچسب‌های `x:action/<value>` توضیح می‌دهند که مشارکت‌کننده هنگام کار روی ایشو در چه نوع کاری درگیر می‌شود.

| تگ                  | توضیح                            |
| -------------------- | -------------------------------------- |
| `x:action/create`    | انجام کاری از صفر         |
| `x:action/fix`       | رفع ایشو                           |
| `x:action/improve`   | بهبود قابلیت‌ها و محتوای موجود |
| `x:action/proofread` | ویراستاری متن                         |
| `x:action/sync`      | همگام‌سازی محتوا با آخرین نسخه‌ی آن   |

### تگ Knowledge

برچسب‌های `x:knowledge/<value>` توضیح می‌دهند که مشارکت‌کننده به چه میزان دانش Exercism نیاز دارد.

| تگ                        | توضیح                                |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | بدون نیاز به دانش Exercism    |
| `x:knowledge/elementary`   | نیاز اندک به دانش Exercism         |
| `x:knowledge/intermediate` | نیاز نسبتاً زیاد به دانش Exercism |
| `x:knowledge/advanced`     | نیاز گسترده به دانش Exercism  |

### تگ Module

برچسب‌های `x:module/<value>` نشان می‌دهند که مشارکت‌کننده روی کدام بخش از Exercism کار می‌کند.

| تگ                          | توضیح                 |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | کار روی Analyzers           |
| `x:module/concept`           | کار روی مفاهیم            |
| `x:module/concept-exercise`  | کار روی تمرین‌های مفهومی   |
| `x:module/generator`         | کار روی تولیدکننده‌های تمرین |
| `x:module/practice-exercise` | کار روی تمرین‌های عملی  |
| `x:module/representer`       | کار روی Representers        |
| `x:module/test-runner`       | کار روی Test Runners        |

### تگ Size

برچسب‌های `x:size/<value>` میزان کار مورد انتظار از یک مشارکت‌کننده را توصیف می‌کنند.

| تگ              | توضیح            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | میزان کار بسیار کم    |
| `x:size/small`   | میزان کار کم   |
| `x:size/medium`  | میزان کار متوسط  |
| `x:size/large`   | میزان کار زیاد   |
| `x:size/massive` | میزان کار بسیار زیاد |

### تگ Type

برچسب‌های `x:type/<value>` نوع کاری را توصیف می‌کنند که مشارکت‌کننده در آن درگیر می‌شود.

| تگ              | توضیح                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | کار روی یکپارچه‌سازی مستمر (مثلاً گردش‌کارهای GitHub Actions)                                                                                                                                                 |
| `x:type/coding`  | نوشتن کدی که بخشی از محتوای دانشجومحور نیست. این معمولاً تسک‌هایی است مرتبط با ابزارهای تولید (مثلاً Test Runnerها)، ابزارهای داخلی (تولیدکننده‌ها)، یا کتابخانه‌هایی که Exercism نگهداری می‌کند. |
| `x:type/content` | کار روی محتوا (مثلاً تمرین‌ها، مفاهیم)                                                                                                                                                                     |
| `x:type/docker`  | کار روی فایل‌های Dockerfile                                                                                                                                                                                            |
| `x:type/docs`    | کار روی مستندات                                                                                                                                                                                          |

## تگ‌های ادعاشده در برابر ادعانشده

برای پنهان کردن یک تسک به این دلیل که کسی از قبل روی آن کار می‌کند، یک ایشو می‌تواند برچسب `x:status/claimed` را اضافه کند.
