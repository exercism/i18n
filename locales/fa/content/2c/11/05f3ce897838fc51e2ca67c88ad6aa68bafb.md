# درباره

## «منطقی»

PowerShell نوع [`bool`][booleans] را دارد که مقادیر «درست» و «غلط» را نشان می‌دهد.
در این نوع فقط دو مقدار وجود دارد: `True` و `False`.
می‌توانید این مقادیر را با پیشوند `$` به متغیرها نسبت دهید:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

می‌توانیم از [عملگرهای منطقی][logical-operators] مانند `-and`، `-or` و `-not` برای ترکیب و ارزیابی عبارت‌های منطقی استفاده کنیم.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## تبدیل و درست‌بودن

PowerShell می‌تواند هر نوعی را به‌صورت ضمنی یک مقدار منطقی در نظر بگیرد.
با این حال می‌توانید از شتاب‌دهنده‌ی نوع منطقی `[bool]` هم برای تبدیل صریح استفاده کنید.

در ادامه چند قاعده‌ی کلی هست که PowerShell برای تبدیل دیگر نوع‌ها به مقادیر منطقی به کار می‌برد:

`$false`:
- رشته‌های خالی مانند `''` یا `""`
- مقادیر تهی مانند `$null`
- نوع عددی با مقدار صفر (۰)

`$true`:
- رشته‌های غیرخالی
- نمونه‌هایی از هر نوع دیگر که مجموعه نباشد

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

برای آشنایی با قواعد دقیق‌تر درباره‌ی تبدیل مقادیر منطقی از نوع‌های مجموعه‌ای، [اینجا][collection-conversion] را بخوانید.
