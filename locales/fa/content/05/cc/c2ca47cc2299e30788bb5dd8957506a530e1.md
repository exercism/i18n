# Tests

## اجرای tests به‌صورت تعاملی

REPL را از همان دایرکتوری‌ای که تمرین را در آن دانلود کرده‌اید اجرا کنید.

می‌توانید tests را با بارگذاری فایل test در REPL به کمک `(load "exercise-test")` اجرا کنید (واژه‌ی `exercise` را با اسم مناسب جایگزین کنید). سپس `(exercise-test:run-tests)` را ارزیابی کنید تا همه‌ی tests اجرا شوند.

اگر code را مستقیماً در REPL بنویسید، کافی است `(exercise-test:run-tests)` را ارزیابی کنید.

اگر code را در فایل lisp تمرین بنویسید، اول آن را با `(load "exercise")` بارگذاری کنید و سپس `(exercise-test:run-tests)` را ارزیابی کنید.

## اجرای tests از خط فرمان

می‌توانید tests را با این دستور خط فرمان اجرا کنید (باز هم `exercise` را در دو جا با اسم مناسب جایگزین کنید)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
