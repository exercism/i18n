# دستورالعمل‌ها

در این تمرین قرار است کدی بنویسید که کمکتان کند از کتاب آشپزی محبوبتان یک لازانیای عالی درست کنید.

چهار کار دارید که همه به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار پخت در فر را بر حسب دقیقه تعریف کنید

یک ثابت به اسم `$expected_minutes_in_oven` تعریف کنید.
طبق کتاب آشپزی، زمان مورد انتظار پخت در فر ۴۰ دقیقه است:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. زمان باقی‌مانده‌ی پخت در فر را بر حسب دقیقه محاسبه کنید

این مقدار، دقیقه‌های واقعی‌ای را که لازانیا در فر بوده است به عنوان ورودی می‌گیرد و بر اساس زمان مورد انتظار پخت در فر که در کار قبلی تعریف شد، برمی‌گرداند که لازانیا باید چند دقیقه‌ی دیگر در فر بماند.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

زمان آماده‌سازی، مدت زمانی است که طول می‌کشد تا لازانیا پیش از گذاشته‌شدن در فر آماده شود.
آماده کردن هر لایه ۲ دقیقه طول می‌کشد.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. زمان کل کار را بر حسب دقیقه محاسبه کنید

محاسبه کنید که در کل چند دقیقه برای پخت لازانیا کار کرده‌اید.
این مقدار، مجموع زمان آماده‌سازی و زمانی است که لازانیا تا این لحظه در فر گذرانده است.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
