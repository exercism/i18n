# مقدمه‌ی مبانی

[Go](https://golang.org) یک زبان برنامه‌نویسی کامپایل‌شده است که نوع‌دهی ایستا دارد.
نحوه‌ی نگارش Go شبیه به C است.
این زبان اغلب به دلیل نام دامنه‌ی پیشینش، golang.org، با اسم Golang شناخته می‌شود، اما اسم درست آن Go است.

مفهوم مبانی سه ویژگی اصلی زبان را معرفی می‌کند: «بسته»، «تابع» و «متغیر».

## بسته

برنامه‌های Go در قالب بسته‌ها سازماندهی می‌شوند.
یک بسته مجموعه‌ای از فایل‌های منبع است که در یک پوشه‌ی یکسان قرار دارند.
همه‌ی فایل‌های منبع در یک پوشه باید اسم بسته‌ی یکسانی داشته باشند.
مرسوم است که اسم بسته، آخرین پوشه در مسیر `import` باشد.
برای نمونه، فایل‌های [بسته‌ی «math/rand»](https://golang.org/src/math/rand/) با دستور `package rand` آغاز می‌شوند.
وقتی بسته‌ای `import` می‌شود، تنها می‌توان از موجودیت‌هایی (توابع، انواع، متغیرها، ثابت‌ها) که اسمشان با حرف بزرگ شروع می‌شود استفاده کرد یا به آن‌ها دسترسی داشت.
سبک توصیه‌شده‌ی نام‌گذاری در Go این است که شناسه‌ها با `camelCase` نام‌گذاری شوند، به‌جز آن‌هایی که قرار است در سراسر بسته‌ها قابل دسترسی باشند و باید `PascalCase` باشند.

```go
package lasagna
```

## متغیر

Go به‌صورت ایستا نوع‌دهی شده است، یعنی همه‌ی متغیرها [باید در زمان کامپایل نوع مشخصی داشته باشند](https://en.wikipedia.org/wiki/Type_system).

متغیرها را می‌توان با مشخص کردن صریح نوع تعریف کرد:

```go
var explicit int // Explicitly typed
```

همچنین می‌توانید از یک مقدار اولیه استفاده کنید و کامپایلر نوع متغیر را مطابق با نوع آن مقدار اولیه تعیین می‌کند.

```go
implicit := 10   // Implicitly typed as an int
```

پس از اعلان، می‌توان با عملگر `=` به متغیرها مقدار داد.
پس از اعلان، نوع یک متغیر هرگز نمی‌تواند تغییر کند.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## ثابت

«ثابت‌ها» هم مانند متغیرها یک داده را در خود نگه می‌دارند، اما مقدارشان در طول اجرای برنامه نمی‌تواند تغییر کند.

ثابت‌ها با «کلیدواژه»ی `const` تعریف می‌شوند و می‌توانند عدد، کاراکتر، رشته یا مقدار «منطقی» باشند:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## تابع

توابع Go صفر یا چند پارامتر می‌پذیرند.
پارامترها باید صریحاً دارای نوع باشند؛ استنتاج نوع وجود ندارد.

مقادیر با کلیدواژه‌ی `return` از توابع برگردانده می‌شوند.

یک تابع با مشخص کردن اسم تابع و فرستادن آرگومان برای هر یک از پارامترهای تابع فراخوانی می‌شود.

توجه داشته باشید که Go از دو نوع «کامنت» پشتیبانی می‌کند.
پیش از کامنت‌های تک‌خطی `//` می‌آید و کامنت‌های چندخطی میان `/*` و `*/` قرار می‌گیرند.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
