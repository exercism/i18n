# دستورالعمل

در این تمرین، پیام‌های لاگ نیمه‌ساختاریافته تولید خواهید کرد.

## 1. پیام‌های نیمه‌ساختاریافته تولید کنید

شما با چند تابع استاب‌شده و `enum` زیر شروع می‌کنید:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

هدف شما تولید یک پیام لاگ به‌شکل زیر است: `"[<LEVEL>]: <MESSAGE>"`.
باید توابعی را پیاده‌سازی کنید که با سطوح لاگ متناظر باشند.

برای مثال، قطعه‌کد زیر خروجی مورد انتظار برای تابع `log` را نشان می‌دهد.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

و برای `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

خوش بگذرد!

## 2. تمرین بیشتر اختیاری

یک تست دارای دروازه‌ی ویژگی در این مجموعه‌ی تست وجود دارد.
دروازه‌های ویژگی کامپایل را برای بخش‌های خاصی از برنامه‌ی شما به‌طور کامل غیرفعال می‌کنند.
بعداً به آن‌ها پرداخته می‌شود.
فعلاً فقط بدانید که تستی وجود دارد که تنها زمانی ساخته و اجرا می‌شود که از یک فراخوانی آزمایشی ویژه استفاده کنید:

```sh
cargo test --features add-a-variant
```

این تست قصد دارد نشان دهد چگونه یک گونه به `enum` خودتان اضافه کنید.
