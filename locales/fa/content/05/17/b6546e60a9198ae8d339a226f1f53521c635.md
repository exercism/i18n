# افزوده‌ی دستورالعمل‌ها

## چند نکته درباره‌ی رشته‌های Arturo

در تست‌ها نحوه‌ی نگارشی می‌بینید که ممکن است برایتان تازه باشد: رشته‌های چندخطی که داخل `{ braces }` قرار می‌گیرند.

### منابع

* نوع [`:string`][string] در مرجع زبان.
* مستندات [Basic Usage][usage] در ماژول Strings.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### لیترال‌های رشته‌ای Arturo

Arturo چند روش برای نوشتن لیترال‌های رشته‌ای دارد:

1. رشته‌های تک‌خطی که بین دو علامت نقل‌قول قرار می‌گیرند

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. رشته‌هایی که تا پایان خط ادامه دارند و از یک «گیومه‌ی هوشمند» `«` استفاده می‌کنند

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   اگر فهرستی از رشته‌های کوتاه داشته باشید، این‌ها خوانایی خوبی پیدا می‌کنند:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. رشته‌های چندخطی که داخل آکولاد قرار می‌گیرند.
   تورفتگی «مشترک» حذف می‌شود.
   خط جدیدِ ابتدا و انتها حذف می‌شود.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. رشته‌های تحت‌اللفظی مو‌به‌مو حفظ می‌شوند، از جمله فاصله‌های ابتدا و انتها

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. رشته‌های به سبک heredoc زیر خطی از ۳ خط تیره یا بیشتر و تا پایان فایل قرار می‌گیرند.
   این دقیقاً همان کاری را می‌کند که کلیدواژه‌ی `__DATA__` در Perl انجام می‌دهد.
   این سبک در یک ماژول به کار می‌آید، جایی که ممکن است مستندات یا متن مجوز را در متغیری در انتهای فایل نگه دارید.

    اگر این در فایلی به اسم «mymodule.art» باشد

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    سپس

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
