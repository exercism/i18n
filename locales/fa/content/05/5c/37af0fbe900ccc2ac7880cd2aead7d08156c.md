# درباره

معمولاً توابع فقط تعداد ثابتی آرگومان می‌پذیرند.
اما اگر پیش از نوع آخرین پارامتر `...` بگذارید، تابع می‌تواند هر تعداد آرگومان را در انتها بپذیرد.
این کار آخرین پارامتر را به یک _پارامتر متغیر_ تبدیل می‌کند.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

درون تابع، پارامتر متغیر یک `slice` است:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

یک تابع می‌تواند پیش از پارامتر متغیر، پارامترهای معمولی داشته باشد.
هر تابع حداکثر یک پارامتر متغیر می‌تواند داشته باشد و آن هم باید آخرین پارامتر باشد.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## گسترش دادن یک `slice`

برای اینکه یک `slice` را به پارامتر متغیر بدهید، بعد از آن `...` بگذارید:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...` فقط زمانی معتبر است که یک `slice` را به پارامتر متغیر بدهید.
