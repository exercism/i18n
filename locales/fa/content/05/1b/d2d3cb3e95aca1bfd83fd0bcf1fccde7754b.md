# درک بازگشت در JavaScript

«بازگشت» مفهومی قدرتمند در برنامه‌نویسی است که در آن یک تابع خودش را فراخوانی می‌کند.
ممکن است درک آن در ابتدا کمی سخت باشد، اما وقتی مبانی آن را بفهمید، به ابزاری ارزشمند برای حل مسائل پیچیده تبدیل می‌شود.
بیایید بازگشت را در JavaScript با مثال‌هایی ساده و قابل‌فهم بررسی کنیم.

## بازگشت چیست؟

بازگشت زمانی رخ می‌دهد که یک تابع خودش را فراخوانی کند، چه مستقیم و چه غیرمستقیم.
این مفهوم شبیه «حلقه» است، اما ممکن است شامل شکستن یک مسئله به زیرمسئله‌های کوچک‌تر و آسان‌تر باشد.

### مثال ۱: شمارش معکوس

بیایید با یک مثال ساده شروع کنیم: یک تابع شمارش معکوس.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

در این مثال:

- **«حالت پایه»**: وقتی `num` کوچک‌تر یا مساوی ۰ می‌شود، تابع «Blastoff!» را چاپ می‌کند و فراخوانی خودش را متوقف می‌کند.
- **«حالت بازگشتی»**: تابع مقدار فعلی `num` را چاپ می‌کند و خودش را با `num - 1` فراخوانی می‌کند.

### مثال ۲: فاکتوریل

حالا بیایید به یک مثال کلاسیک از بازگشت نگاه کنیم: محاسبه‌ی فاکتوریل یک عدد.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

در این مثال:

- **حالت پایه**: وقتی `n` برابر ۰ یا ۱ است، تابع ۱ را برمی‌گرداند.
- **حالت بازگشتی**: تابع `n` را در فاکتوریل `n - 1` ضرب می‌کند.

## مفاهیم کلیدی

### حالت پایه

هر تابع بازگشتی باید دست‌کم یک حالت پایه داشته باشد، شرطی که در آن تابع فراخوانی خودش را متوقف می‌کند.
بدون حالت پایه، بازگشت تا بی‌نهایت ادامه پیدا می‌کند و به «سرریز پشته» می‌انجامد.

### حالت بازگشتی

حالت بازگشتی تعیین می‌کند که تابع چگونه خودش را با نسخه‌ی کوچک‌تر یا ساده‌تر مسئله فراخوانی می‌کند.

## مزایا و معایب بازگشت

**مزایا:**

- راه‌حلی زیبا برای برخی مسائل.
- از مفهوم استقرای ریاضی الگو می‌گیرد.

**معایب:**

- ممکن است از راه‌حل‌های تکراری کم‌کارآمدتر باشد.
- ممکن است در بازگشت‌های عمیق به سرریز پشته منجر شود.

## نتیجه‌گیری

بازگشت تکنیکی ارزشمند است که مسائل پیچیده را با شکستن آن‌ها به زیرمسئله‌های کوچک‌تر و آسان‌تر ساده می‌کند.
درک حالت‌های پایه و حالت‌های بازگشتی برای پیاده‌سازی راه‌حل‌های بازگشتی کارآمد در JavaScript ضروری است.
