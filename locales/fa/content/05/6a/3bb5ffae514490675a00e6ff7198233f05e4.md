# راهنمایی‌ها

## 1. ساخت یک تخته‌ی امتیازهای بالا

- یک شیء جدید با آکولاد بسازید.
- کلید را به‌صورت رشته بنویسید تا کلید بتواند فاصله داشته باشد.
- کلید و مقدار را با دونقطه از هم جدا کنید.

## 2. افزودن بازیکن‌ها به تخته‌ی امتیاز

- برای افزودن کلیدی که اسمش در یک متغیر (آرگومان) ذخیره شده است، از نشانه‌گذاری کروشه استفاده کنید.
- برای تعیین مقدار برای کلید جدید، از عملگر انتساب (`=`) استفاده کنید.
- از طرف دیگر، می‌توانید از [عملگر `+`][man-plus] برای ادغام شیء ورودی با یک شیء جدید استفاده کنید.
- به یاد داشته باشید که برای کلیدهای شیء، دور عبارت باید پرانتز گذاشت.

## 3. حذف بازیکن‌ها از تخته‌ی امتیاز

- از [عبارت del][man-del] استفاده کنید.
- به همان روشی که در تمرین قبل انجام دادید، به کلید ارجاع دهید (نشانه‌گذاری کروشه).
- به یاد داشته باشید که آرگومان `del` یک _عبارت اندیس_ است، نه فقط یک رشته.

## 4. افزایش امتیاز یک بازیکن

- ابتدا فکر کنید که چگونه مقدار جدیدی را که می‌خواهید انتساب دهید بیان کنید.
- سپس مثل تمرین ۲ از عملگر انتساب استفاده کنید تا آن مقدار جدید را تعیین کنید.
- اگر هنوز این کار را نکرده‌اید، می‌توانید از [عملگر انتساب-به‌روزرسانی حسابی][man-update-assignment] `+=` استفاده کنید.

## 5. اعمال امتیازهای پاداش دوشنبه

- اینجا جای خوبی است برای استفاده از `to_entries`/`from_entries` یا `with_entries` تا روی شیء پیمایش کنید
- برای هر کلید، مقدار جدید را همان‌طور که در تمرین ۴ انجام دادید تعیین کنید.

## 6. یافتن امتیاز کل

- می‌خواهیم روی _مقدارهای_ شیء پیمایش کنیم.
  می‌توانیم از [`map_values`][man-map_values] یا [`.[]`][man-brackets] استفاده کنیم تا جریانی از مقدارها را خروجی بدهیم.
- از عبارت `add` می‌توان برای یافتن مجموع یک فهرست از عددها استفاده کرد.
