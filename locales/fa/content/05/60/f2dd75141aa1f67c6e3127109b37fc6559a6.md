# نصب

- macOS: دستور `brew install futhark` را اجرا کنید
- linux: دستور `brew install futhark` را اجرا کنید
- Windows: یا از WSL استفاده کنید یا [دستورهای مخصوص Windows][windows-specific-instructions] را دنبال کنید

روش‌های نصب جایگزین را می‌توانید در [دستورهای نصب رسمی][instructions] پیدا کنید.

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
