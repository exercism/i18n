# مقدمه

کلاس‌ها یکی از بلوک‌های سازنده‌ی بنیادین برنامه‌های Swift هستند.
با کلاس‌ها می‌توانید ویژگی‌های مرتبط (داده‌ها) و متدهای مرتبط (توابع) را در واحدهایی خودکفا از کارکرد کنار هم بگذارید.

### تعریف کلاس‌ها

برای تعریف یک کلاس، از «کلیدواژه»ی `class` و بعد از آن اسم کلاس استفاده کنید و تعریف کلاس را درون آکولاد قرار دهید:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

بدنه‌ی کلاس می‌تواند شامل ویژگی‌های ذخیره‌شده باشد؛ این ویژگی‌ها درست مثل ثابت‌های (`let`) یا متغیرهای (`var`) معمولی تعریف می‌شوند و رفتار می‌کنند.

### نمونه‌ها

تعریف کلاس به‌منزله‌ی نقشه‌ی ساخت است: نوعی تازه تعریف می‌کند و توضیح می‌دهد که مقادیرش چه شکلی‌اند، اما به‌تنهایی هیچ نمونه‌ای نمی‌سازد.

برای ساختن *نمونه* از یک کلاس، سازنده‌ی آن را فراخوانی کنید؛ کافی است اسم کلاس را بنویسید و بعد از آن پرانتز بگذارید:

```swift
let someCharacter = GameCharacter()
```

این کار نمونه‌ای تازه می‌سازد که ویژگی‌هایش با مقادیر پیش‌فرض تعیین‌شده در تعریف کلاس مقداردهی می‌شوند.
برای ویژگی‌های اختیاری که مقدار پیش‌فرض صریحی ندارند (مثل `name`)، Swift مقدارشان را به‌صورت پیش‌فرض `nil` می‌گذارد.

### دسترسی به ویژگی‌ها

برای دسترسی به ویژگی‌های یک نمونه از *نشانه‌گذاری نقطه‌ای* استفاده می‌کنید: اسم نمونه را می‌نویسید، بعد یک نقطه (`.`)، و بعد اسم ویژگی را.
نشانه‌گذاری نقطه‌ای برای ویژگی‌های تودرتو هم کار می‌کند.

می‌توانید با نشانه‌گذاری نقطه‌ای مقادیر را بخوانید و، اگر ویژگی تغییرپذیر (`var`) باشد، مقدار تازه‌ای به آن نسبت دهید:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### متدها

علاوه بر ویژگی‌ها، کلاس‌ها می‌توانند *متد* هم تعریف کنند، یعنی توابعی که به کلاس وابسته‌اند.

متدها را با نگارش استاندارد `func` درون بدنه‌ی کلاس تعریف کنید.
اگر متدی یک ویژگی را تغییر دهد، آن ویژگی باید با `var` تعریف شده باشد:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

متدها را هم درست مثل ویژگی‌ها با نشانه‌گذاری نقطه‌ای روی نمونه فراخوانی کنید:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### self

هر نمونه از یک کلاس ویژگی ضمنی‌ای به اسم `self` دارد که به خود نمونه اشاره می‌کند.
هرچند `self` را هنگام اشاره به ویژگی‌ها یا متدها اغلب نمی‌نویسند، معمولاً از آن استفاده می‌شود تا وقتی اسم یک ویژگی و اسم پارامتر یک متد یکی است، این دو را از هم جدا کند.
