# مقدمه

`bit` ریزترین مقدار در محاسبات است.
واژه‌ی `bit` مخفف «رقم دودویی» است.
`bit` یک واحد ذخیره‌سازی داده در محیط اجرا است که آن‌قدر بزرگ است که می‌تواند شیءای را در خود جای دهد که ممکن است یکی از دو مقدار را داشته باشد.
به همین دلیل، مقدار دودویی آن یا `1` است یا `0`.
همه‌ی انواع داده‌ی دیگر از چندین `bits` تشکیل می‌شوند.
برای مثال، یک `byte` معمولاً از هشت `bits` تشکیل می‌شود.

## ماسک بیت

ماسک بیت می‌تواند هر مقداری باشد که برای تنظیم بیت‌های تک‌تک به کار می‌رود.
برای نمونه، الفبای انگلیسی بیست و شش حرف دارد.
مقداری با حداقل بیست و شش بیت، مثل یک عدد صحیح بدون علامت ۳۲ بیتی، می‌تواند به عنوان ماسک بیت به کار برود تا برای هر حرف انگلیسی یک شرط `true` یا `false` تنظیم کند.
هر مقداری که بیت‌های کافی برای پوشش مجموعه‌ای از شرط‌های `true` یا `false` داشته باشد، می‌تواند به عنوان ماسک بیت عمل کند.
تنظیم و خواندن بیت‌های تک‌تک با استفاده از عملگرهای بیتی انجام می‌شود.

## عملگرهای بیتی

فرض کنید می‌خواهیم بدانیم کدام حروف در یک `string` رخ می‌دهند.
در مثال ما، فقط از بیست و شش حرف الفبای انگلیسی استفاده می‌کنیم.
ماسک بیت ما یک عدد صحیح بدون علامت ۳۲ بیتی خواهد بود.
`0` نشان می‌دهد که آن حرف رخ نمی‌دهد.
`1` نشان می‌دهد که آن حرف یک بار یا بیشتر رخ می‌دهد.
در ابتدا، نمایش بیتی ماسک بیت ما ۳۲ عدد `0s` پشت سر هم خواهد بود: `00000000000000000000000000000000`.
سمت راست‌ترین جایگاه برای `A` خواهد بود.
دومین جایگاه از سمت چپ برای `B` خواهد بود و به همین ترتیب.
فرض کنید همه‌ی حروف رشته را در یک حلقه پردازش می‌کنیم، پس می‌خواهیم یک خط کد داشته باشیم که برای تنظیم هر حرفی کار کند.

### عملگر شیفت چپ بیتی: راهی برای قرار دادن یک بیت

`<<` عملگر بیتی برای شیفت به چپ است.

اگر حرف ما `A` باشد نمی‌خواهیم به چپ شیفت بدهیم، اما اگر حرف ما `B` باشد می‌خواهیم یک جایگاه به چپ شیفت بدهیم و اگر حرف ما `C` باشد می‌خواهیم دو جایگاه به چپ شیفت بدهیم و به همین ترتیب.
هرچند می‌توانیم `chars` را حروفی مثل `A` یا `B` ببینیم، `char` در حافظه به شکل یک نوع عدد صحیح پیاده‌سازی می‌شود، پس می‌توانیم با یک `char` حساب ساده انجام دهیم.
اگر متغیری به اسم `letter` داشته باشیم که `char` در حال پردازش را نشان می‌دهد، می‌توانیم با شیفت دادن `1` به چپ به اندازه‌ی تفاضل `letter` و `char` مربوط به `A`، به تعداد جایگاه لازم به چپ شیفت بدهیم؛ به این شکل: `1 << letter - 'A'`.
`A` منهای `A` برابر `0` است، پس اگر `letter` برابر `A` باشد، صفر جایگاه به چپ شیفت می‌خورد.
`B` منهای `A` برابر `1` است، پس اگر `letter` برابر `B` باشد، یک جایگاه به چپ شیفت می‌خورد و به همین ترتیب.

### عملگر OR شمول‌گرای بیتی: راهی برای تنظیم یک بیت

وقتی بدانیم _کجا_ می‌خواهیم بیتی را تنظیم کنیم، می‌توانیم با استفاده از عملگر OR شمول‌گرای بیتی، که `|` است، آن را واقعاً تنظیم کنیم.
نتیجه‌ی عملگر `|` در هر جایگاهی که عملوند چپ یا راست بیت تنظیم‌شده‌ای داشته باشد، `1` خواهد بود.
پس نتیجه‌ی `0010 | 0001` برابر `0011` خواهد بود.
(به یاد داشته باشید که این مقدار در مبنای دو `11` است، اما در مبنای ده `3` است.)
برای نسبت دادن نتیجه به یک مقدار، می‌توان عملگر `|` را با عملگر انتساب ترکیب کرد و بیت‌ها را به این شکل تنظیم کرد: `|=`.
برای ساده ماندن مثال، نمونه‌ی زیر از حلقه استفاده نمی‌کند، اما نشان می‌دهد چطور می‌توانیم حروف `ABA` را در یک ماسک بیت پردازش کنیم.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

سمت راست‌ترین بخش ماسک را برای `A` روی `0001` تنظیم می‌کنیم و سپس ماسک را برای `B` روی `0011` تنظیم می‌کنیم.
تنظیم دوباره‌ی `A` تغییری در ماسک موجود ایجاد نمی‌کند.
می‌توانستیم با بررسی اینکه آیا `A` از قبل تنظیم شده است یا نه، از تنظیم دوباره‌ی آن بیت پرهیز کنیم.

### عملگر AND بیتی: راهی برای خواندن یک بیت

`&` عملگر AND بیتی است.
نتیجه‌ی عملگر `&` در هر جایگاهی که هم عملوند چپ و هم عملوند راست بیت تنظیم‌شده‌ای داشته باشند، `1` خواهد بود.
پس نتیجه‌ی `0011 & 0001` برابر `0001` خواهد بود.
این را می‌توانیم در نمونه‌ی زیر در عمل ببینیم.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### عملگر XOR بیتی: راهی برای وارونه کردن یک بیت

`^` عملگر OR انحصاری بیتی است.
وجود عملگر OR شمول‌گرا یعنی عملگر OR انحصاری هم با رفتاری متفاوت وجود دارد.
نتیجه‌ی عملگر `^` در هر جایگاهی که _فقط یکی_ از عملوندهای چپ یا راست بیت تنظیم‌شده‌ای داشته باشد، `1` خواهد بود.
پس نتیجه‌ی `0001 ^ 0011` برابر `0010` خواهد بود.
سمت راست‌ترین بیت تنظیم نمی‌شود، چون _هر دو_ عملوند در سمت راست‌ترین جایگاه `1` دارند.
عملگر OR انحصاری را گاهی XOR می‌نویسند.
اگر نتیجه‌ی XOR شدن یک مقدار را دوباره XOR کنیم، مقدار اصلی برمی‌گردد.
از این ویژگی می‌توان برای یک رمزنگاری بسیار ساده استفاده کرد که در آن یک کلید یکسان هم برای رمزگذاری و هم برای رمزگشایی داده به کار می‌رود.
برای مثال

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## فیلد بیت

دیدیم که می‌توان به بیت‌های جمع‌شده در یک نوع داده‌ی ساده از طریق جایگاهشان دسترسی داشت.
می‌توان به بیت‌های جمع‌شده در یک `struct` از طریق اسم دسترسی داشت.
به چنین نوع داده‌ای `bit field` می‌گویند.
یکی از موارد استفاده از `bit fields` می‌تواند زمانی باشد که به مجموعه‌ای از پرچم‌های روشن/خاموش نیاز داریم و می‌خواهیم مصرف حافظه را حداقل کنیم.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

نحوه‌ی نگارش `unsigned int variable_name : 1;` یک فیلد `1` بیتی درون یک `unsigned int` می‌سازد که در ساختار قرار گرفته است.
به‌جای `unsigned int` می‌توان از `signed int` استفاده کرد، یا از C99 به بعد می‌توان از نوع `bool` استفاده کرد.
یک ساختار که فیلد بیت دارد، می‌تواند فیلدهایی از انواع داده‌ی دیگر هم داشته باشد، مثل `number_of_lights` در مثال بالا.
