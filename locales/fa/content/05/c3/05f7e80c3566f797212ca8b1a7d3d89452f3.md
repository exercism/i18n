# مقدمه

## اعلان نوع

اعلان‌های نوع در PHP در زمان اجرا برای آرگومان‌های تابع، مقادیر بازگشتی و ویژگی‌های کلاس تضمین نوع فراهم می‌کنند.
در توابع می‌توان نوع بازگشتی `void` را اضافه کرد تا نشان دهد هیچ مقداری از تابع بازگردانده نمی‌شود.
انواع اعلان‌شده همچنین در زمان اجرا تضمین می‌کنند که توابع پاسخی با نوع نسبتاً درست برمی‌گردانند.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### نوع اتحادی

اگر آرگومان یک تابع، مقدار بازگشتی یا ویژگی یک کلاس بتواند بیش از یک نوع باشد، می‌توان نوع اتحادی را اعلان کرد.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### نوع مختلط

هنگام کار با کد، ممکن است نتوانیم نوعی را مشخص کنیم.
از PHP 8.0 به بعد، نوعی راه فرار به اسم `mixed` در اختیار قرار گرفته است.
نوع مختلط معادل یک نوع اتحادی از `object|resource|array|string|float|int|bool|null` است.
