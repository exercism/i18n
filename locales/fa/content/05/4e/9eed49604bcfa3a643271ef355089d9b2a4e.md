# مقدمه

[«عملگر شرطی سه‌گانه»][ternary-operator] شکل کوتاه و مختصری برای یک عبارت `if-else` است.
این عملگر یک شرط را ارزیابی می‌کند و بسته به اینکه آن شرط `true` باشد یا `false`، یکی از دو مقدار را برمی‌گرداند.

این عملگر از سه بخش تشکیل شده است: `condition ? trueExpression : falseExpression`.
اگر `condition` به `true` ارزیابی شود، `trueExpression` ارزیابی و برگردانده می‌شود؛ در غیر این صورت، `falseExpression` ارزیابی و برگردانده می‌شود.

عملگر سه‌گانه برای انتخاب‌های ساده و یک‌خطی ایده‌آل است:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

مثال بالا معادل فشرده‌ی زیر است:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
