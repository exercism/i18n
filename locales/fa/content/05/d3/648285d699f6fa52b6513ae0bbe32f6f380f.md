# موارد بیشتر

## GNU awk و محاسبات با دقت دلخواه

به‌طور پیش‌فرض، اعداد در `awk` به‌صورت اعداد اعشاری شناور با دقت مضاعف نمایش داده می‌شوند. این ۵۳ بیت دقت فراهم می‌کند (به [جدول ۱۶٫۳][table-16.3] در راهنما نگاه کنید). متأسفانه این برای کامل کردن این تمرین کافی نیست (هشدار لو دادن مطلب: یکی از testها به ۶۳ بیت دقت نیاز دارد).

«دقت ناکافی» چنین چیزی است:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk` این قابلیت را دارد که از اعداد با دقت دلخواه استفاده کند، به شرط آنکه کتابخانه‌های مربوطه در فایل اجرایی `awk` کامپایل شده باشند. نسخه‌ی `awk` خودتان را بررسی کنید و به دنبال «GNU MPFR» بگردید:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

اگر وجود داشته باشد، این قابلیت را با گزینه‌ی `-M` فعال کنید:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

اگر `awk` من گزینه‌ی `-M` را نداشته باشد چه؟ باید یک برنامه‌ی بیرونی را فراخوانی کنید که بتواند محاسبات با دقت دلخواه انجام دهد، مثل `bc`. برای نمونه‌ای از این کار، بخش [استفاده از `getline` برای خواندن از یک لوله در یک متغیر][getline-pipe] را ببینید.
