# انواع عدد

Crystal برای مقاصد مختلف، انواع عدد گوناگونی دارد.
برای مثال، بعضی از انواع سریع‌ترند اما بازه‌ی مقادیر ممکن‌شان از بقیه کوچک‌تر است.
بعضی دیگر بازه‌ی گسترده‌تری از مقادیر ممکن دارند اما کندترند.

در Crystal هم انواع عدد صحیح علامت‌دار وجود دارد و هم انواع عدد صحیح بدون علامت.
انواع عدد صحیح علامت‌دار می‌توانند مثبت یا منفی باشند.
انواع عدد صحیح بدون علامت فقط می‌توانند مثبت باشند.

## انواع عدد صحیح علامت‌دار

این‌ها [انواع عدد صحیح علامت‌دار][int] در Crystal هستند:

| نوع      | اندازه (بیت) | بازه                                                                                                        |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | ۸           | از -128 تا 127                                                                                               |
| `Int16`  | ۱۶          | از -32_768 تا 32_767                                                                                         |
| `Int32`  | ۳۲          | از -2_147_483_648 تا 2_147_483_647                                                                           |
| `Int64`  | ۶۴          | از -9_223_372_036_854_775_808 تا 9_223_372_036_854_775_807                                                   |
| `Int128` | ۱۲۸         | از -170_141_183_460_469_231_731_687_303_715_884_105_728 تا 170_141_183_460_469_231_731_687_303_715_884_105_727 |

انواع کوچک‌تر حافظه‌ی کمتری مصرف می‌کنند و از انواع بزرگ‌تر سریع‌ترند، اما بازه‌ی کوچک‌تری از مقادیر ممکن دارند.

اگر می‌دانید مقادیر در بازه‌ی مشخصی قرار می‌گیرند، بهتر است از کوچک‌ترین نوع ممکن استفاده کنید تا در حافظه صرفه‌جویی شود و کارایی بهبود یابد.

نوع عدد صحیح پیش‌فرض `Int32` است.
برای اعلان یک عدد صحیح با نوع مشخص، می‌توانید اسم نوع را به‌عنوان پسوند به کار ببرید؛ کافی است `<number>_I <bit>` را اضافه کنید.

```crystal
1_i8.class
# => Int8
```

می‌توانید از متد `to_i<bit>` برای تبدیل میان انواع مختلف عدد صحیح استفاده کنید.
متد `to_i` به نوع عدد صحیح پیش‌فرض، یعنی `Int32`، تبدیل می‌کند.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## انواع عدد صحیح بدون علامت

این‌ها انواع [عدد صحیح بدون علامت][uint] در Crystal هستند:

`UInt8`، `UInt16`، `UInt32`، `UInt64`، `UInt128`

تنها تفاوت میان اعداد صحیح علامت‌دار و بدون علامت این است که اعداد صحیح بدون علامت فقط می‌توانند مثبت باشند.
برای اعلان یک عدد صحیح بدون علامت با نوع مشخص، می‌توانید اسم نوع را به‌عنوان پسوند به کار ببرید؛ کافی است `<number>_u<bit>` را اضافه کنید.
می‌توانید از متد `to_u<bit>` برای تبدیل میان انواع مختلف عدد صحیح بدون علامت استفاده کنید.
متد `to_u` به نوع عدد صحیح بدون علامت پیش‌فرض، یعنی `UInt32`، تبدیل می‌کند.

```crystal
1_u8.to_u16.class
# => UInt16
```

## انواع اعشاری

این‌ها انواع اعشاری در Crystal هستند:

| نوع       | اندازه (بیت) | بازه                |
| --------- | ----------- | -------------------- |
| `Float32` | ۳۲          | از 1.2E-38 تا 3.4E+38   |
| `Float64` | ۶۴          | از 2.3E-308 تا 1.7E+308 |

دو [نوع اعشاری][float] مختلف وجود دارد که یکی از دیگری دقیق‌تر است.

نوع اعشاری پیش‌فرض `Float64` است.

می‌توانید از متد `to_f<bit>` برای تبدیل میان انواع مختلف اعشاری استفاده کنید.
متد `to_f` به نوع اعشاری پیش‌فرض، یعنی `Float64`، تبدیل می‌کند.

## نوع پس از یک عملیات

وقتی عملیاتی میان دو عدد اجرا می‌کنید، نتیجه از نوع عددی خواهد بود که بیشترین دقت را دارد.
عدد اعشاری از عدد صحیح دقیق‌تر است و عدد صحیح از عدد صحیح بدون علامت دقیق‌تر است.
سپس `Float64` از Float32 دقیق‌تر است و به همین ترتیب ادامه می‌یابد.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## عمیق‌تر کاوش کنید: اعداد صحیح بدون علامت در برابر اعداد صحیح علامت‌دار

~~~~exercism/advanced
در پشت صحنه، چیزی که اعداد صحیح بدون علامت و علامت‌دار را از هم متمایز می‌کند این است که اعداد صحیح علامت‌دار از بیت اول برای ذخیره‌ی علامت استفاده می‌کنند.
علامت یا مثبت است یا منفی.
در اعداد صحیح بدون علامت، بیت اول برای ذخیره‌ی مقدار به کار می‌رود.
بنابراین برای یک عدد صحیح ۳۲ بیتی علامت‌دار، بیشترین مقدار ۲ به توان ۳۱ منهای ۱ است.
برای یک عدد صحیح ۳۲ بیتی بدون علامت، بیشترین مقدار ۲ به توان ۳۲ منهای ۱ است.

اگر می‌خواهید درباره‌ی علامت‌دار بودن بیشتر بدانید، می‌توانید اطلاعات بیشتری را در [Wikipedia](https://en.wikipedia.org/wiki/Signedness) بخوانید.
~~~~
