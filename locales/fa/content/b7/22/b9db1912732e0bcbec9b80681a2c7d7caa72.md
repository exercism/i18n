# مقدمه

## حلقه‌ی For

دستور `for` یک بلوک کد را تکرار می‌کند.
خط اول آن کنترل می‌کند که بلوک چند بار تکرار شود:

```go
for init; condition; post {
    // loop body
}
```

- دستور **مقداردهی اولیه** یک بار پیش از نخستین تکرار اجرا می‌شود. معمولاً در آن یک متغیر شمارنده اعلام و مقداردهی می‌شود که حلقه از آن استفاده می‌کند.
- **شرط** یک «عبارت منطقی» است که پیش از هر تکرار ارزیابی می‌شود. وقتی این عبارت به `false` ارزیابی شود، حلقه متوقف می‌شود.
- دستور **پسین** پس از هر تکرار کامل اجرا می‌شود. می‌توان از آن برای به‌روزرسانی شمارنده استفاده کرد.

`init; condition; post` را داخل پرانتز قرار ندهید.
با این حال، آکولادهای `{ }` که بدنه‌ی حلقه را در بر می‌گیرند همیشه لازم هستند.

این حلقه `i` را از `1` شروع می‌کند، مقدار فعلی `i` را چاپ می‌کند، آن را برای تکرار بعدی افزایش می‌دهد و وقتی `i` به `10` می‌رسد متوقف می‌شود:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
