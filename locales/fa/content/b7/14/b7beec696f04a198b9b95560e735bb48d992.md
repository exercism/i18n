# دستورالعمل‌ها

شما یک بوتیک مد آنلاین را اداره می‌کنید. حراج بزرگ سالانه‌تان نزدیک است، پس باید موجودی خود را بررسی کنید تا مطمئن شوید آماده‌اید.

هر کالا در موجودی با یک نگاشت نشان داده می‌شود و کل موجودی فهرستی از همین نگاشت‌هاست.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. مرتب‌سازی کالاها بر اساس قیمت

تابع `sort_by_price/1` را پیاده‌سازی کنید. این تابع باید موجودی را بگیرد و آن را بر اساس قیمت کالاها به ترتیب صعودی برگرداند.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. یافتن همه‌ی کالاهای بدون قیمت

پس از مرتب‌سازی موجودی بر اساس قیمت، متوجه شدید که حتماً هنگام بررسی موجودی اشتباه کرده‌اید و فراموش کرده‌اید قیمت چند کالا را ثبت کنید.

تابع `with_missing_price/1` را پیاده‌سازی کنید. این تابع باید موجودی را بگیرد و کالاهایی را که قیمت ندارند به‌صورت فهرست برگرداند.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. به‌روزرسانی اسم کالاها

متوجه شدید که در اسم بعضی کالاها کلمه‌ای وجود دارد که دیگر نمی‌خواهید از آن استفاده کنید. حالا باید همه‌ی اسم‌های کالاها را که آن کلمه را دارند به‌روزرسانی کنید.

تابع `update_names/3` را پیاده‌سازی کنید. این تابع باید موجودی، کلمه‌ی قدیمی‌ای را که می‌خواهید حذف کنید و کلمه‌ی جدیدی را که می‌خواهید به‌جایش استفاده کنید بگیرد. باید فهرستی از کالاها را با اسم‌های به‌روزرسانی‌شده برگرداند.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. افزایش تعداد کالا

بعضی کالاها به‌طور ویژه خوب فروش می‌رفتند، برای همین در همه‌ی سایزها بیشتر سفارش دادید.

تابع `increase_quantity/2` را پیاده‌سازی کنید. این تابع باید یک کالا و یک عدد `n` بگیرد و همان کالا را برگرداند با این تفاوت که تعداد هر سایز به اندازه‌ی `n` افزایش یافته باشد.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. محاسبه‌ی تعداد کل کالا

برای اینکه بدانید در انبارتان چقدر فضا نیاز دارید، باید بدانید از هر کالا در کل چند عدد دارید.

تابع `total_quantity/1` را پیاده‌سازی کنید. این تابع باید یک کالا بگیرد و تعداد کل آن را برگرداند؛ یعنی در هر سایزی، در کل چند عدد دارید.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
