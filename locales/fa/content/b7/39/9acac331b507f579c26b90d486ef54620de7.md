# مقدمه

در Haxe، «استثناها» روشی ایمن برای مدیریت خطاهایی هستند که هنگام اجرای کد رخ می‌دهند. همه‌ی استثناها باید پیامی داشته باشند که خطا را توصیف کند. می‌توانیم استثناها را با کلیدواژه‌ی `throw` _پرتاب_ کنیم:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

وقتی استثنایی پرتاب می‌شود، کد به دنبال بخشی می‌گردد که برای مدیریت خطا تعیین شده است. اگر چنین بخشی پیدا نکند، پیام خطا را نمایش می‌دهد و در همان حال اجرای برنامه را متوقف می‌کند.

برای مدیریت استثناها در Haxe، از بلوک `try-catch` استفاده می‌کنیم. این دستور بلوکی از یک بلوک `try` و یک یا چند بلوک `catch` تشکیل شده است. بلوک `try` می‌کوشد یک بخش از کد را اجرا کند، در حالی که بلوک `catch` منتظر می‌ماند تا اگر استثنایی پرتاب شد آن را _بگیرد_، تا اجرا متوقف نشود. وقتی بلوک `catch` استثنایی را می‌گیرد، همه‌ی محتوای داخل بلوک را نیز اجرا می‌کند:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

نوع آرگومان بلوک `catch` باید حذف شود.
