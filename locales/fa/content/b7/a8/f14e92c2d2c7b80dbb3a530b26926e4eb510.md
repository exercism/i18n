# چاپ

چاپ در Cairo به شما امکان می‌دهد پیام‌ها و مقدارها را در کنسول نمایش دهید؛ این کار دیباگ کردن برنامه‌ها یا رساندن اطلاعات در حین اجرا را آسان‌تر می‌کند.

سیستم چاپ هم انعطاف‌پذیر است و هم ساده؛ ابزارهایی در اختیار شما می‌گذارد تا داده‌هایی از انواع مختلف را قالب‌بندی و خروجی بگیرید.

## مبانی چاپ

Cairo دو ماکروی اصلی برای چاپ متن در کنسول فراهم می‌کند:

- **`println!`**: خروجی را در یک خط جدید چاپ می‌کند.
- **`print!`**: خروجی را در همان خط و بدون افزودن خط جدید چاپ می‌کند.

هر دو ماکرو یک `ByteArray` را به عنوان آرگومان اصلی می‌گیرند؛ این آرگومان می‌تواند یک رشته‌ی ساده باشد یا یک رشته‌ی قالب‌بندی‌شده که جانگهدارهایی برای مقدارها دارد.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

در مثال بالا:

- جانگهدارهای `{}` با مقدارهای `x` و `y` جایگزین می‌شوند.
- `println!` باعث می‌شود خروجی با یک خط جدید تمام شود.

## قالب‌بندی رشته

گاهی ممکن است لازم باشد یک رشته‌ی قالب‌بندی‌شده بسازید، بدون اینکه بلافاصله آن را چاپ کنید.

ماکروی `format!` این امکان را به شما می‌دهد.

این ماکرو مانند `println!` کار می‌کند، اما به‌جای فرستادن خروجی به کنسول، یک `ByteArray` برمی‌گرداند.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

در این مثال:

- `format!` سه متغیر `s1`، `s2` و `s3` را در یک رشته‌ی واحد ترکیب می‌کند و آن‌ها را با خط تیره (`-`) از هم جدا می‌کند.
- رشته‌ی به‌دست‌آمده را می‌توان بعداً دوباره استفاده یا چاپ کرد.

## چاپ نوع داده‌ی سفارشی

به‌طور پیش‌فرض، Cairo فقط می‌تواند انواع پایه‌ای مانند عددهای صحیح و رشته‌ها را چاپ کند.

اگر بخواهید یک نوع سفارشی، مانند `struct`، را چاپ کنید، با یک خطا روبه‌رو می‌شوید، مگر اینکه آن نوع ویژگی‌های `Display` یا `Debug` را پیاده‌سازی کرده باشد.

### استفاده از `Display` برای قالب‌بندی سفارشی

ویژگی `Display` به شما امکان می‌دهد تعیین کنید که یک نوع سفارشی چگونه چاپ شود.

اینجا یک مثال می‌بینید:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

در این مثال:

- تابع `fmt` تعیین می‌کند که `struct`ی به اسم `Point` چگونه به یک رشته‌ی قابل چاپ تبدیل می‌شود.
- ماکروی `write!` رشته‌ی قالب‌بندی‌شده را به `Formatter` اضافه می‌کند.

### دیباگ کردن با `Debug`

Cairo برای اهداف دیباگ، ویژگی `Debug` را فراهم می‌کند.

می‌توانید آن را برای بیشتر انواع به‌طور خودکار مشتق کنید؛ این کار چاپ جزئیات درونی `struct`های شما را سریع و آسان می‌کند.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

در این مثال:

- `#[derive(Debug)]` به‌طور خودکار پیاده‌سازی ویژگی `Debug` را تولید می‌کند.
- جانگهدار `{:?}` به `println!` می‌گوید که برای قالب‌بندی از ویژگی `Debug` استفاده کند.

## چاپ در مبنای شانزده

Cairo به کمک جانگهدار `{:x}` اجازه می‌دهد عددهای صحیح را در قالب مبنای شانزده چاپ کنید.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

این کار به‌ویژه هنگام کار با نمایش‌های سطح پایین داده بسیار مفید است.
