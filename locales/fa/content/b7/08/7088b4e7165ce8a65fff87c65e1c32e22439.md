# مقدمه

Swift هنگام سروکار داشتن با «بستارها»، گونه‌ای از نحوه‌ی نگارش خود را پیشنهاد می‌کند که به آن «بستار پایانی» می‌گویند. بستار پایانی زمانی پدید می‌آید که آخرین پارامتر در فهرست پارامترهای یک تابع، نوع تابع داشته باشد. در این حالت، اگر بستاری پاس داده شود، می‌توان آن را _پس از_ پرانتز بسته نوشت و برچسب آرگومان را حذف کرد. توجه کنید که اگر تابع فقط یک پارامتر داشته باشد، می‌توان پرانتزها را کاملاً حذف کرد.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
