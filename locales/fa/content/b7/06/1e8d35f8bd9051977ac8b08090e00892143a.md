# گیرنده و تنظیم‌کننده

«گیرنده» و «تنظیم‌کننده» متدهایی هستند که به شما امکان می‌دهند مقدار ویژگی یک شیء را بخوانید و بنویسید.
Crystal «ماکرو» دارد و همین باعث می‌شود تعریف گیرنده و تنظیم‌کننده برای یک ویژگی آسان باشد.
ماکروها روشی برای تولید کد در زمان کامپایل هستند که بعداً در مفهوم ماکرو به آن می‌پردازیم.

در Ruby این متدها با استفاده از متدهای `attr_reader`، `attr_writer` و `attr_accessor` تعریف می‌شوند و در ظاهر شباهت زیادی به پیاده‌سازی Crystal دارند.
Crystal این‌ها را به صورت ماکروهای `getter`، `setter` و `property` تعریف کرده است.

## گیرنده

گیرنده ماکرویی است که متدی را تعریف می‌کند که مقدار یک «متغیر نمونه» را برمی‌گرداند.
این یعنی دیگر لازم نیست وقتی می‌خواهید به متغیر نمونه دسترسی پیدا کنید، `@` را جلوی آن بنویسید (در متدها، به‌جز `initialize`)؛ به جای آن می‌توانید متدی را که ماکروی گیرنده تعریف کرده است فراخوانی کنید.

ماکروی گیرنده می‌تواند چندین متغیر نمونه را بپذیرد؛ کافی است آن‌ها را با ویرگول از هم جدا کنید.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

همان‌طور که می‌بینید، استفاده از گیرنده حجم کدی که می‌نویسید را کم می‌کند و خواندن آن را آسان‌تر می‌کند.
همچنین Ruby و Crystal در این با هم تفاوت دارند که Crystal هم اسم متغیر و هم «نماد» را به عنوان آرگومان برای ماکروی گیرنده می‌پذیرد.
نمادها بعداً در مفهوم نماد بررسی می‌شوند.

## تنظیم‌کننده

تنظیم‌کننده ماکرویی است که متدی را تعریف می‌کند که مقدار یک متغیر نمونه را تنظیم می‌کند.
این ماکرو چندان رایج نیست و معمولاً به جای آن از ماکروی `property` استفاده می‌شود.
متدهایی که ساخته می‌شوند به شکل `name_of_method=` خواهند بود؛ این `=` است که باعث می‌شود بتوان ویژگی را تنظیم کرد.
این تعریف متد کمی خاص است، چون آرگومانی که متد دریافت می‌کند بعد از علامت `=` می‌آید.
چند متد خاص دیگر در Crystal هم از این نحوه‌ی نگارش استفاده می‌کنند، مثل متد `+`.

مانند ماکروی گیرنده، وقتی می‌خواهید مقدار یک متغیر نمونه را پس از تعریف تنظیم‌کننده به‌روزرسانی کنید، می‌توانید متدی را که ماکروی تنظیم‌کننده تعریف کرده است فراخوانی کنید.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## ویژگی

ویژگی ماکرویی است که هم گیرنده و هم تنظیم‌کننده را برای یک متغیر نمونه تعریف می‌کند.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
