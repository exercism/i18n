# پیوست
## امتیاز

«خوشه‌های گرافیمی» را حفظ کنید، یعنی:

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

احتمالاً برای این کار امتیازی، کتابخانه‌ی استاندارد `Unicode` به کارتان می‌آید.

برای فعال کردن test گرافیم‌ها، `const TEST_GRAPHEMES = true` را به دامنه‌ی سراسری فایل خودتان اضافه کنید.
