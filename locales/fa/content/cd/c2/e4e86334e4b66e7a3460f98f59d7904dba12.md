# راهنما

## 1. اطلاعات لازم برای تولید کارت‌ها را با regex استخراج کنید

- `\p{L}` با هر نوع حرفی از هر زبانی مطابقت می‌کند.
- برای استخراج اطلاعات می‌توانید از عبارت زیر استفاده کنید:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
