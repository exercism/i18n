# Debug

وقتی یک test شکست می‌خورد، پیامی نمایش داده می‌شود که توضیح می‌دهد چه چیزی اشتباه پیش رفته و ورودی چه بوده است. همچنین می‌توانید از این نکته استفاده کنید که هر چیزی که به «خروجی استاندارد» چاپ شود هم نمایش داده می‌شود. برای نوشتن در خروجی استاندارد می‌توانید از `println!` استفاده کنید:

```rust
println!("Debug message");
```

برای چاپ مقدار یک متغیر یا عبارت، از آکولاد `{}` استفاده کنید:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

توجه کنید که همه‌ی نوع‌ها را نمی‌توان این‌طور چاپ کرد؛ فقط نوع‌هایی را می‌توان چاپ کرد که بتوان آن‌ها را بدون ابهام به کاربر نشان داد.
برای مثال، وکتور (لیست) را نمی‌توان این‌طور چاپ کرد، چون مشخص نیست یک وکتور را چطور باید به کاربر نمایش داد!
برای این نوع‌های دیگر می‌توانید با `{:?}` به ماکروی `println!` بگویید که از _debug-formatting_ استفاده کند.
این نمایش فقط برای برنامه‌نویس‌ها در نظر گرفته شده است.
یک مثال:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

حتی ماکروی کاربردی `dbg!` هم وجود دارد که می‌توان از آن برای debug کردن عبارت‌های بزرگ به‌صورت درون‌خطی استفاده کرد، بدون اینکه مجبور باشید آن را به اعلان‌های متغیر جداگانه تکه‌تکه کنید.

فرض کنید عبارت زیر را داریم:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

حالا می‌خواهیم ببینیم فراخوانی `collect` چه چیزی برمی‌گرداند.
می‌توانیم این کار را بکنیم:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

اما این کار خسته‌کننده است!
نمی‌خواهیم عبارت‌های قشنگ‌مان را فقط برای اینکه بتوانیم آن‌ها را debug کنیم، از نو بنویسیم.
لطفاً از `dbg!` روی صحنه استقبال کنید:

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

فاصله‌های خالی فقط برای خوانایی بیشتر است.
می‌توانید هر عبارتی را در `dbg!()` بپیچید؛ این کار آن مقدار را (با debug-formatting) چاپ می‌کند.
بعد از آن هم می‌توانید از آن مقدار در یک عبارت بزرگ‌تر استفاده کنید، طوری که انگار `dbg!` اصلاً آن‌جا نبوده است.

debug خوبی داشته باشید!
