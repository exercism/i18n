# مقدمه

«عبارات باقاعده» در Gleam از مشخصات **PCRE** (عبارات باقاعده‌ی سازگار با Perl) پیروی می‌کند، مشابه سایر زبان‌های پرکاربرد مانند Java، JavaScript یا Ruby.

ماژول `gleam/regex` توابعی برای کار با عبارات باقاعده ارائه می‌دهد.

~~~~exercism/note
این تمرین فرض می‌کند که شما از قبل نحوه‌ی نگارش عبارات باقاعده را می‌دانید، از جمله کلاس‌های نویسه، کمیت‌سازها، گروه‌ها و گروه‌های ثبت.

اگر لازم است دانش خود را درباره‌ی عبارات باقاعده تازه کنید، یکی از این منابع را ببینید: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

رایج‌ترین راه برای ساختن عبارات باقاعده استفاده از تابع `regex.from_string` است.

```gleam
let assert Ok(re) = regex.from_string("test")
```

اگر نحوه‌ی نگارش عبارت باقاعده نامعتبر باشد، تابع `regex.from_string` یک `Error` برمی‌گرداند؛ به همین دلیل در اینجا از یک let-assertion استفاده شده تا مطمئن شویم که عبارت باقاعده معتبر است.

از تابع `regex.check` می‌توان برای بررسی اینکه آیا یک عبارت باقاعده با یک رشته مطابقت دارد یا نه استفاده کرد.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## گروه‌های ثبت

اگر می‌خواهید با یک عبارت باقاعده زیررشته‌ها را ثبت کنید، می‌توان از تابع `regex.scan` برای برگرداندن فهرستی از تطابق‌ها استفاده کرد.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## اصلاح‌کننده‌ها

رفتار یک عبارت باقاعده را می‌توان با ساختن آن به کمک تابع `regex.compile` و فرستادن گزینه‌ها تغییر داد.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
