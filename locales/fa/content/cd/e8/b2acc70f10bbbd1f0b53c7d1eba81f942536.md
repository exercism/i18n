# دستورالعمل‌ها

در این تمرین باید چند قاعده از [Pac-Man][Pac-Man]، بازی آرکید کلاسیک دهه‌ی ۱۹۸۰، را پیاده‌سازی کنید.

در کل شش کار وجود دارد که چهار موردشان قواعد مرتبط با حالت‌های بازی هستند.

> _نگران نحوه‌ی به دست آمدن آرگومان‌ها در توابع نباشید؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید._


## 0. تعریف یک حالت نیرو

متغیری به اسم `PowerOn` تعریف کنید که مقدارش نشان‌دهنده‌ی روشن بودن نیرو باشد.

```powershell
> $PowerOn
True
```

## 1. تعریف این‌که آیا Pac-Man روح می‌خورد

تابع `EatGhost` را تعریف کنید که دو پارامتر می‌گیرد (این‌که Pac-Man یک قرص نیرو فعال دارد و این‌که Pac-Man به یک روح دست زده است) و یک مقدار «منطقی» برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌تواند روح را بخورد.
تابع باید `True` را فقط در صورتی برگرداند که Pac-Man قرص نیرو فعال داشته باشد و به یک روح دست زده باشد.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. تعریف این‌که آیا Pac-Man امتیاز می‌گیرد

تابع `Score` را تعریف کنید که دو پارامتر می‌گیرد (این‌که Pac-Man به یک قرص نیرو دست زده است و این‌که Pac-Man به یک نقطه دست زده است) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man امتیاز گرفته است.
تابع باید `True` را در صورتی برگرداند که Pac-Man به یک قرص نیرو یا یک نقطه دست زده باشد.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. تعریف این‌که آیا Pac-Man می‌بازد

تابع `Lose` را تعریف کنید که دو پارامتر می‌گیرد (این‌که Pac-Man یک قرص نیرو فعال دارد و این‌که Pac-Man به یک روح دست زده است) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌بازد.
تابع باید `True` را در صورتی برگرداند که Pac-Man به یک روح دست زده باشد و قرص نیرو فعال نداشته باشد.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. تعریف این‌که آیا Pac-Man می‌برد

تابع `Win` را تعریف کنید که سه پارامتر می‌گیرد (این‌که Pac-Man همه‌ی نقطه‌ها را خورده است، این‌که Pac-Man یک قرص نیرو فعال دارد و این‌که Pac-Man به یک روح دست زده است) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌برد.
تابع باید `True` را در صورتی برگرداند که Pac-Man همه‌ی نقطه‌ها را خورده باشد و بر اساس پارامترهای تعریف‌شده در بخش ۳ نباخته باشد.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. نوشتن Synopsis برای شرط برد

به آخرین تابع برگردید و یک بخش `Synopsis` به بلوک توضیحات اضافه کنید که توصیف کوتاهی از نحوه‌ی بردن بازی باشد.
این توصیف باید حداقل ۱۰ کاراکتر طول داشته باشد.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
