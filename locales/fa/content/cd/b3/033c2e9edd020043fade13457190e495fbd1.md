# راهنمایی‌ها

## کلی

- به نحوه‌ی نگارش اشارهگرها دقت کنید.
  شما از `*` (عملگر ارجاع‌زدایی) و `->` (دسترسی به عضو از طریق اشارهگر) استفاده خواهید کرد.
- مطمئن شوید که در صورت لزوم اشارهگرهای null (`nullptr`) را بررسی می‌کنید تا از دسترسی به حافظه‌ی نامعتبر جلوگیری کنید.
- می‌توانید تست‌ها را حتی اگر کدتان کامل نیست اجرا کنید؛ یک ساختار کلی برای دیدن نتایج تست کافی است.
- همه‌ی توابعی که تست‌ها استفاده می‌کنند باید در فایل هدر اعلام شوند.
- اگر برنامه‌تان کرش کند یا رفتار غیرمنتظره‌ای داشته باشد، معمولاً به دلیل ارجاع‌زدایی از اشارهگر null است.
  دوباره بررسی کنید که `nullptr` را درست مدیریت می‌کنید.
- وقتی از محاسبات اشارهگر استفاده می‌کنید، مطمئن شوید که در محدوده‌ی آرایه‌ی حسگرها باقی می‌مانید.
  فراتر رفتن از ظرفیت آرایه می‌تواند به مشکلات حافظه منجر شود.

## 1. بررسی اتصال حسگر (`connection_check`)

- این وظیفه عمدتاً درباره‌ی بررسی این است که آیا یک اشارهگر null است یا نه.
- از عملگر مقایسه‌ی `!=` استفاده کنید تا بررسی کنید که یک اشارهگر معتبر است یا نه.
- اگر مطمئن نیستید که اشارهگر را درست بررسی می‌کنید، به این فکر کنید که `nullptr` نماینده‌ی چیست (نبود یک آدرس حافظه‌ی معتبر).


## 2. شمارش فعالیت حسگرها (`activity_counter`)

- باید روی آرایه‌ی حسگرها پیمایش کنید.
  یک آرایه در C++ را می‌توان مانند اشارهگری به اولین عنصرش در نظر گرفت.
- از محاسبات اشارهگر (`sensor_array + i`) برای دسترسی به حسگر در اندیس `i` استفاده کنید.
- عملگر `->` برای دسترسی به یک عضو struct از طریق اشارهگر به کار می‌رود.

### مثال

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. کنترل هشدار (`alarm_control`)

- ابتدا پیش از دسترسی به حسگر، بررسی کنید که اشارهگر null است یا نه.
- از عملگر `->` برای دسترسی به عضو `activity` در struct `pillar_men_sensor` استفاده کنید.
- خوب فکر کنید که اگر سطح فعالیت حسگر `0` باشد چه باید اتفاق بیفتد.
  آیا باید هشدار فعال شود؟

## 4. بررسی ناهنجاری‌ها در داده با تابع `uv_alarm`

- از عملگر `&` استفاده کنید تا یک اشارهگر به آرایه‌ی داده‌ی حسگر را به تابع `uv_light_heuristic` بدهید.
- مطمئن شوید که پیش از دسترسی به داده‌ی حسگر، اشارهگر null را درست بررسی می‌کنید.
- نتیجه‌ی `uv_light_heuristic` را با مقدار `activity` حسگر مقایسه کنید تا مشخص شود آیا باید هشدار فعال شود.
