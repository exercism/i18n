# مقدمه

در Kotlin می‌توان از کلاس‌ها برای کپسوله‌سازی داده و رفتار استفاده کرد.
کلاس با کلیدواژه‌ی `class` تعریف می‌شود.
برای مثال:

```kotlin
class Car
```

با فراخوانی کلاس، یک نمونه از آن بسازید.

```kotlin
val instance = Car()
```

## ویژگی‌ها

در مثال‌های بالا، کلاس `Car` بدون هیچ ویژگی‌ای تعریف شد.
ویژگی‌های کلاس را می‌توان در بدنه، بین `{}`، با `var` برای ویژگی‌های تغییرپذیر و با `val` برای ویژگی‌های تغییرناپذیر تعریف کرد.
برای مثال:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

روش دیگر این است که ویژگی‌ها را در سازنده‌ای تعریف کنید که آن‌ها را دریافت می‌کند.

## سازنده‌ها

Kotlin دو نوع سازنده دارد: سازنده‌ی اصلی و سازنده‌ی ثانویه.
سازنده‌ی اصلی در همان خطی تعریف می‌شود که کلاس تعریف شده است.
برای مثال:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

اگر حاشیه‌نویسی و اصلاح‌کننده‌ی دسترسی وجود نداشته باشد، می‌توان کلیدواژه‌ی `constructor` را حذف کرد:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
اگر کلاس فقط شامل ویژگی باشد، Kotlin اجازه می‌دهد آن را با بدنه تعریف کنید و نیازی به آکولاد `{}` نیست:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

هر کلاس فقط می‌تواند یک سازنده‌ی اصلی داشته باشد.
سازنده‌های ثانویه سازنده‌های دیگری هستند که با اعلام آن‌ها در بدنه‌ی کلاس به کمک کلیدواژه‌ی `constructor` اضافه می‌شوند.
برای مثال:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

سازنده‌های ثانویه باید `this` را فراخوانی کنند تا سازنده‌ی اصلی اجرا شود.

## بلوک‌های مقداردهی اولیه

سازنده‌ی اصلی ویژگی‌های کلاس را مقداردهی می‌کند.
اگر هنگام ساخت شیء کارهای بیشتری لازم باشد، می‌توان از بلوک‌های `init` برای انجام کارهای اضافی استفاده کرد.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## توابع

توابع را می‌توان در بدنه‌ی کلاس تعریف کرد.
برای مثال:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## سطح دسترسی

ویژگی‌ها و توابع می‌توانند `private`، `public`، `internal` یا `protected` باشند.

- `private` فقط از داخل کلاس قابل دسترسی است
- `protected` هم از داخل کلاس و هم از زیرکلاس‌ها قابل دسترسی است
- `internal` از داخل همان ماژول قابل دسترسی است
- `public` از سایر بخش‌هایی که از کلاس استفاده می‌کنند قابل دسترسی است

برای مثال:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
