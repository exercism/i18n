# پیوست دستورالعمل

## پیام‌های استثنا

گاهی لازم است [یک استثنا ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** هم بگنجانید تا نشان دهید منبع خطا چیست. این کار کد شما را خواناتر می‌کند و به debug کردن کمک قابل‌توجهی می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا از یک نوع خاص است، می‌توانید یکی از [انواع خطای داخلی](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما همچنان باید پیامی معنادار را هم بگنجانید.

این تمرین به‌طور خاص از شما می‌خواهد که با استفاده از [دستور raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) هنگام دریافت مختصات نامعتبر، یک `ValueError` را «پرتاب» کنید. آزمون‌ها تنها در صورتی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بگنجانید.

برای اینکه یک `ValueError` همراه با پیام ایجاد کنید، پیام را به‌صورت آرگومان برای نوع `exception` بنویسید:

```python
# when the coordinates for the piece are invalid
raise ValueError('Invalid coordinate')
```
