# دستورالعمل‌ها

در همین نزدیکی یک فروشگاه لوازم خانگی به اسم «Tech Palace» هست.
صاحب فروشگاه اخیراً یک نمایشگر بزرگ نصب کرده است تا از آن برای پیام‌های تبلیغاتی استفاده کند و وقتی مشتریان در ورودی کارت‌های وفاداری به‌اصطلاح خودشان را اسکن می‌کنند، خوش‌آمد ویژه‌ای نشان دهد.
این نمایشگر از تعداد زیادی لامپ کوچک LED تشکیل شده است و می‌تواند چندین خط متن را نشان دهد.

صاحب فروشگاه برای کدی که با آن متن نمایشگر جدید تولید می‌شود، به کمک شما نیاز دارد.

## 1. ساخت پیام خوش‌آمد

صاحب فروشگاه می‌خواهد برای بیشتر مشتریانی که کارت وفاداری‌شان را اسکن می‌کنند، `Welcome to the Tech Palace, ` و پشت سر آن اسم مشتری با حروف بزرگ روی نمایشگر نمایش داده شود.

تابع `welcome` را پیاده‌سازی کنید که اسم مشتری را می‌گیرد و پیام موردنظر را به‌صورت رشته برمی‌گرداند.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. افزودن یک حاشیه‌ی شیک

صاحب فروشگاه می‌خواهد برای مشتریان وفاداری که خرید زیادی از فروشگاه می‌کنند، با افزودن یک خط ستاره پیش و پس از پیام خوش‌آمد، نمایش خوش‌آمد را شیک‌تر کند.
او هنوز مطمئن نیست که در هر خط چند ستاره باید باشد، بنابراین می‌خواهد این تعداد قابل تنظیم باشد.

تابعی به اسم `add_border` بنویسید که پیام خوش‌آمد و تعداد ستاره‌های هر خط را به‌عنوان آرگومان می‌گیرد.
این تابع باید رشته‌ای برگرداند که از ۳ خط تشکیل شده است: یک خط با تعداد دلخواه ستاره، سپس پیام خوش‌آمد همان‌طور که ورودی گرفته شده، و بعد خط دیگری از ستاره‌ها.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. پاک‌سازی پیام‌های تبلیغاتی قدیمی

پیش از نصب این نمایشگر جدید، فروشگاه یک نمایشگر مشابه داشت که فقط می‌توانست خطوط ثابت و غیرقابل‌تنظیم را نشان دهد.
صاحب فروشگاه می‌خواهد بعضی از پیام‌های تبلیغاتی قدیمی را روی نمایشگر جدید دوباره استفاده کند.
اما این داده‌ها از قبل شامل بعضی فاصله‌های خالی نامناسب است که برای هم‌تراز کردن متن در چند نمایشگری که روی هم قرار گرفته بودند، استفاده می‌شد.
وظیفه‌ی شما پاک‌سازی این پیام‌هاست تا بتوانند دوباره استفاده شوند.

تابع `clean` را پیاده‌سازی کنید که پیام تبلیغاتی قدیمی را می‌گیرد.
این تابع باید ابتدا همه‌ی فاصله‌های خالی ابتدا و انتهای متن را حذف کند و سپس آن را برگرداند.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
