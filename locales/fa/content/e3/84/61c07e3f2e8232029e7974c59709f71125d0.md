# مقدمه

Java یک زبان با نوع‌بندی ایستا است؛ یعنی نوع یک متغیر در زمان کامپایل مشخص است.
انتساب یک مقدار به یک اسم را تعریف متغیر می‌گوییم.
یک متغیر با مشخص کردن صریح نوعش تعریف می‌شود.

```java
int explicitVar = 10;
```

مقدار یک متغیر با عملگر `=` به‌روزرسانی می‌شود.
در اینجا، `=` نشان‌دهنده‌ی برابری ریاضی نیست.
فقط یک مقدار را به یک متغیر انتساب می‌دهد.
هنگامی که یک متغیر تعریف شد، نوعش هرگز تغییر نمی‌کند.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java یک [زبان شیءگرا][object-oriented-programming] است و لازم می‌داند که همه‌ی توابع درون یک _کلاس_ تعریف شوند.
از کلیدواژه‌ی `class` برای تعریف یک کلاس استفاده می‌شود.

```java
class Calculator {
    // ...
}
```

به یک تابع درون یک کلاس، _متد_ می‌گویند.
هر متد می‌تواند صفر یا چند پارامتر داشته باشد.
نوع همه‌ی پارامترها باید صریحاً مشخص شود؛ برای پارامترها استنتاج نوع وجود ندارد.
به همین ترتیب، نوع بازگشتی هم باید صریحاً مشخص شود.
مقادیر با کلیدواژه‌ی `return` از متدها برگردانده می‌شوند.
برای اینکه یک متد بتواند توسط کلاس‌های دیگر فراخوانی شود، باید تعدیل‌کننده‌ی دسترسی `public` اضافه شود.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

فراخوانی یک متد با مشخص کردن اسم کلاس و متد آن و پاس دادن آرگومان برای هر یک از پارامترهای متد انجام می‌شود.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

محدوده در Java بین کاراکترهای `{` و `}` تعریف می‌شود.

Java از دو نوع توضیح پشتیبانی می‌کند.
توضیحات تک‌خطی با `//` آغاز می‌شوند و توضیحات چندخطی بین `/*` و `*/` قرار می‌گیرند.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
