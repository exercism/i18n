# نصب

## نسخه‌ی هدف

آزمایش برای این مسیر از ایمیج Docker با نام `alpine:3.24.1` استفاده می‌کند که در سپتامبر ۲۰۲۶ از `sqlite3 version 3.53.4` استفاده می‌کند.
ما تلاش می‌کنیم اطمینان حاصل کنیم که ابزارهای ارائه‌شده توسط این مسیر روی آخرین نسخه‌ی LTS Ubuntu کار می‌کنند.
اگرچه ممکن است کاربران نسخه‌های جدیدتری نصب کرده باشند، باید بدانند که ممکن است برخی قابلیت‌ها با تست‌رانر ما کار نکنند.
قابلیت‌ها را می‌توان در [تاریخچه‌ی نسخه‌های SQLite][version-history] مقایسه کرد.

## Windows

برای نصب SQLite روی Windows، این مراحل را دنبال کنید:

1. فایل‌های اجرایی پیش‌کامپایل‌شده‌ی Windows را از [صفحه‌ی دانلود رسمی][sqlite-download] دانلود کنید.
2. فایل ZIP دانلودشده را در پوشه‌ای به انتخاب خودتان استخراج کنید.
   برای مثال، `C:\Program Files\sqlite3`.
3. پوشه‌ای را که شامل `sqlite3.exe` است به متغیر محیطی PATH سیستم اضافه کنید.
   این روند برای هر نسخه‌ی Windows کمی متفاوت است، اما جست‌وجوی این اطلاعات باید آسان باشد.
   برای مثال [دستورالعمل‌های Windows 11][windows-11-install] و [Windows 10][windows-10-install].

## macOS

در macOS، SQLite از پیش نصب شده است.
اما اگر به نسخه‌ی جدیدتری نیاز دارید، می‌توانید از [Homebrew][homebrew] استفاده کنید:

```bash
brew install sqlite
```

## Ubuntu / Debian

برای سیستم‌های Ubuntu و مبتنی بر Debian، می‌توانید SQLite را با apt نصب کنید:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

در سیستم‌های CentOS، Fedora و مبتنی بر Red Hat، می‌توانید SQLite را با yum یا dnf نصب کنید:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

در Arch Linux، می‌توانید SQLite را با pacman نصب کنید:

```bash
sudo pacman -S sqlite
```

## روش‌های دیگر نصب و نسخه‌های قدیمی‌تر

برای اطلاعات بیشتر و روش‌های نصب جایگزین به [صفحه‌ی دانلود SQLite][sqlite-download] مراجعه کنید.
بخش `Build Product Names and Info` الگوی نام‌گذاری نسخه‌های مختلف SQLite را دارد، بنابراین باید بتوانید نسخه‌ی مورد نظرتان را با موتور جست‌وجوی محبوب خود پیدا کنید.
