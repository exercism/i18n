# مقدمه

## پروتکل

پروتکل سازوکاری برای دستیابی به «چندریختی» در Elixir است، برای زمانی که می‌خواهید رفتار بسته به نوع داده تغییر کند.

پروتکل با استفاده از `defprotocol` تعریف می‌شود و شامل یک یا چند سرآیند تابع است.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

پروتکل را می‌توان با استفاده از `defimpl` پیاده‌سازی کرد.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

پروتکل را می‌توان برای هر نوع داده‌ی موجود در Elixir یا برای یک «ساختار» پیاده‌سازی کرد.

وقتی یک تابع پروتکل فراخوانی می‌شود، پیاده‌سازی مناسب به‌طور خودکار بر اساس نوع آرگومان اول انتخاب می‌شود.
