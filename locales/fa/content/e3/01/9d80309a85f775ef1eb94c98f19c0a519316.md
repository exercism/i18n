# یادگیری

Exercism تمرین و بازخورد فراهم می‌کند، اما برای کسانی که برای اولین بار Common Lisp را یاد می‌گیرند، شروع کار با آن می‌تواند دشوار باشد.
این منابع می‌توانند به شما کمک کنند تا شروع کنید:

* [A Road to Common Lisp][road-to-cl]، نوشته‌ی وبلاگی که مسیر یک نفر به‌سوی Common Lisp را توضیح می‌دهد و نظرهای او را درباره‌ی نحوه‌ی شروع با آن بازگو می‌کند
* [Practical Common Lisp][practical-cl]، کتابی کامل برای یادگیری Common Lisp که به‌صورت رایگان آنلاین (و همچنین چاپی) در دسترس است
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  به قلم مشارکت‌کنندگان مختلف
* [Awesome Common Lisp Learning][awesome-cl]

همچنین در این مسیر Common Lisp در Exercism ببینید: [منابع مهم][track-resources].
