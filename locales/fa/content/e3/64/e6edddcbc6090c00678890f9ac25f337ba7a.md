# راهنمایی‌ها

## کلی

- [نوع اتم اینجا توضیح داده شده است][atom].

## 1. تعیین برچسب لاگ

- می‌توانید از [شکل ویژه‌ی `cond/1`][cond] استفاده کنید تا کدهای لاگ گوناگون را به‌شکلی ظریف مدیریت کنید.
- می‌توانید از [عملگرهای برابری][equality] استفاده کنید تا اعداد صحیح را از نظر برابری دقیق نوع مقایسه کنید.
- [راهی برای تعیین یک شاخه‌ی پیش‌فرض][cond] در عبارت `cond` وجود دارد که می‌توان از آن برای گرفتن موارد تعیین‌نشده استفاده کرد.

## 2. ارسال هشدار

- می‌توانید از [شکل ویژه‌ی `cond/1`][cond] استفاده کنید تا تصمیم بگیرید آیا باید هشداری فرستاده شود.
- می‌توانید از [عملگرهای برابری][equality] برای بررسی برابری اتم‌ها استفاده کنید.
