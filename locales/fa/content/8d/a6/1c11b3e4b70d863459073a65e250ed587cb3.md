# دستورالعمل‌ها

یک عدد دودویی را که به‌صورت یک رشته نمایش داده می‌شود (مثلاً «101010»)، با استفاده از اصول اولیه به معادل دهدهی‌اش تبدیل کنید.

تبدیل دودویی به دهدهی را پیاده‌سازی کنید. برنامه‌ی شما باید با گرفتن یک رشته‌ی ورودی دودویی، خروجی دهدهی تولید کند. برنامه باید ورودی‌های نامعتبر را هم مدیریت کند.

## نکته

- تبدیل را خودتان پیاده‌سازی کنید.
  از هیچ ابزار دیگری برای انجام این تبدیل به جای خودتان استفاده نکنید.

## درباره‌ی دودویی (مبنای ۲)

دهدهی یک سیستم اعداد با مبنای ۱۰ است.

عدد ۲۳ در نمایش مبنای ۱۰ را می‌توان به‌صورت ترکیب خطی توان‌های ۱۰ فهمید:

- رقم سمت راست در ۱۰^۰ = ۱ ضرب می‌شود
- عدد بعدی در ۱۰^۱ = ۱۰ ضرب می‌شود
- ...
- عدد *n*اُم در ۱۰^*(n-1)* ضرب می‌شود.
- همه‌ی این مقدارها با هم جمع می‌شوند.

پس: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

دودویی هم مشابه است، اما به جای توان‌های ۱۰ از توان‌های ۲ استفاده می‌کند.

پس: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
