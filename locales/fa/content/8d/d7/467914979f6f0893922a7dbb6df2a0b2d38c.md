# درباره

Haxe یک زبان با نوع‌دهی قوی است، اما می‌توان در صورت لزوم سیستم نوع‌دهی آن را دور زد. اختصاص دادن یک مقدار به یک اسم را تعریف «متغیر» می‌نامند. متغیر را می‌توان یا با مشخص کردن صریح نوعش تعریف کرد، یا با اجازه دادن به کامپایلر Haxe که با استفاده از [کلیدواژه‌ی `var`](var) نوع را استنتاج کند. بنابراین، دو تعریف متغیر زیر معادل هم هستند:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

به‌روزرسانی یک متغیر با عملگر `=` انجام می‌شود:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

کامپایلر هنگام تلاش برای اختصاص دادن مقداری که نوعش با متغیر متفاوت است، خطا می‌دهد:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

در Haxe، کد معمولاً داخل یک _تابع_ نوشته می‌شود که به آن [_متد_](method) هم می‌گویند. این توابع می‌توانند پارامتر (آرگومان) بگیرند و با استفاده از کلیدواژه‌ی `return` مقداری بازگردانند. توابع با نحوه‌ی نگارش `()` فراخوانی می‌شوند. همه‌ی توابع باید نوع بازگشتی داشته باشند.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

دامنه در Haxe بین کاراکترهای `{` و `}` تعریف می‌شود.

Haxe از دو نوع «کامنت» پشتیبانی می‌کند. کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.
