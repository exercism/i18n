# درباره

همانطور که می‌توان اشاره‌گری به `int` یا هر نوع داده‌ی پایه‌ی دیگری ساخت، می‌توان اشاره‌گری به یک تابع هم ساخت. از «اشاره‌گر تابع» می‌توان برای فرستادن یک تابع به تابع دیگر استفاده کرد. تابعی که به‌عنوان مقدار پارامتر به تابع دیگری فرستاده می‌شود، «تابع درجه‌یک» نام دارد. تابعی که یک یا چند تابع را به‌عنوان پارامتر می‌گیرد، یا تابعی را برمی‌گرداند، «تابع مرتبه‌بالا» نامیده می‌شود.

در مثال زیر، `is_even` و `is_odd` توابع درجه‌یک هستند. تابع مرتبه‌بالا `test_number` است.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
امضای تابع `bool (*func) (int)` برای آرگومان اول `test_number` با امضای توابعی که فرستاده می‌شوند مطابقت دارد. هم `is_even` و هم `is_odd` یک پارامتر `int` می‌گیرند و یک `bool` برمی‌گردانند. در `(*func)`، `func` نماینده‌ی اسم تابعی است که باید استفاده شود. اگر `(*fn)` به کار می‌رفت، آن‌گاه این‌گونه فراخوانی می‌شد: `printf(text, number, fn(number)? "true": "false");`. برای اینکه پارامتر اشاره‌گر تابع را برآورده کنیم، هنگام فراخوانی `test_number` اسم تابعی را می‌فرستیم که امضای مورد انتظار را دارد. پس می‌بینیم که اسم یک تابع به نشانی همان تابع نام‌گرفته اشاره می‌کند.

فراخوانی یک اشاره‌گر تابع با امضای اشتباه به رفتار تعریف‌نشده (UB) منجر می‌شود. بسته به کامپایلر، ممکن است کامپایل نشود، یا ممکن است با یا بدون هشدار کامپایل شود اما بعد در زمان اجرا از کار بیفتد.
