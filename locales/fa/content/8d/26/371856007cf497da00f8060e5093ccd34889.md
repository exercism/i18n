# دستورالعمل‌ها

شما و دوستانتان عاشق بازی‌های نقش‌آفرینی رومیزی هستید، اما متوجه شده‌اید که جذب افراد تازه به گروهتان دشوار است. آن‌ها اغلب برای ساختن شخصیت به مشکل می‌خورند و نمی‌دانند از کجا شروع کنند. برای اینکه به بازیکنان تازه کمک کنید، تصمیم گرفتید برنامه‌ی کوچکی بنویسید که آن‌ها را در این مسیر راهنمایی کند.

## 1. به بازیکن تازه خوش‌آمد بگویید

تابع `RPG.CharacterSheet.welcome/0` را پیاده‌سازی کنید. این تابع باید پیام خوش‌آمد چاپ کند و `:ok` را برگرداند.

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. اسم شخصیت را بپرسید

تابع `RPG.CharacterSheet.ask_name/0` را پیاده‌سازی کنید. این تابع باید یک پرسش چاپ کند، منتظر پاسخ بماند و پاسخ را بدون فضای خالی در ابتدا و انتها برگرداند.

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. کلاس شخصیت را بپرسید

تابع `RPG.CharacterSheet.ask_class/0` را پیاده‌سازی کنید. این تابع باید یک پرسش چاپ کند، منتظر پاسخ بماند و پاسخ را بدون فضای خالی در ابتدا و انتها برگرداند.

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. سطح شخصیت را بپرسید

تابع `RPG.CharacterSheet.ask_level/0` را پیاده‌سازی کنید. این تابع باید یک پرسش چاپ کند، منتظر پاسخ بماند و پاسخ را به‌صورت یک عدد صحیح برگرداند.

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. مراحل قبلی را در یک مرحله ادغام کنید

تابع `RPG.CharacterSheet.run/0` را پیاده‌سازی کنید. این تابع باید به بازیکن تازه خوش‌آمد بگوید، اسم، کلاس و سطح شخصیت را بپرسد و برگه‌ی شخصیت را به‌صورت یک «نقشه» برگرداند. همچنین باید نقشه را با برچسب «Your character» چاپ کند.

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
