# دستورالعمل‌ها

در این تمرین با یک ماشین کنترلی بازی می‌کنید؛ همان ماشینی که بالاخره پول کافی برای خریدش را پس‌انداز کرده‌اید.

باتری ماشین‌ها در ابتدا کاملاً پر است (۱۰۰٪). هر بار که ماشین را با کنترل از راه دور می‌رانید، ۲۰ متر جلو می‌رود و یک درصد از باتری را خالی می‌کند. لقب ماشین تا وقتی که ساخته نشده باشد، مشخص نیست.

ماشین کنترلی یک نمایشگر LED شیک دارد که دو مورد اطلاعات را نشان می‌دهد:

- مسافت کل طی‌شده، که به این شکل نمایش داده می‌شود: `"<METERS> meters"`.
- شارژ باقی‌مانده‌ی باتری، که به این شکل نمایش داده می‌شود: `"Battery at <PERCENTAGE>%"`.

اگر باتری به ۰٪ برسد، دیگر نمی‌توانید ماشین را برانید و نمایشگر باتری `"Battery empty"` را نشان می‌دهد.

## 1. یک ماشین کنترلی کاملاً نو بسازید

تابع `RemoteControlCar.new/0` را پیاده‌سازی کنید تا یک ساختار ماشین کنترلی کاملاً نو برگرداند:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

ساختار به لقب نیاز دارد؛ مطمئن شوید که مقدار آن در تابع `new` مقدار اولیه می‌گیرد، نه در خود ساختار.

## 2. یک ماشین کنترلی کاملاً نو با لقب بسازید

تابع `RemoteControlCar.new/1` را پیاده‌سازی کنید تا یک ساختار ماشین کنترلی کاملاً نو با لقبی که داده می‌شود برگرداند:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. نمایش مسافت

تابع `RemoteControlCar.display_distance/1` را پیاده‌سازی کنید تا مسافت را همان‌طور که روی نمایشگر LED نمایش داده می‌شود برگرداند:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

مطمئن شوید که تابع فقط یک ساختار `RemoteControlCar` را به عنوان آرگومان می‌پذیرد.

## 4. نمایش درصد باتری

تابع `RemoteControlCar.display_battery/1` را پیاده‌سازی کنید تا درصد باتری را همان‌طور که روی نمایشگر LED نمایش داده می‌شود برگرداند:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

مطمئن شوید که تابع فقط یک ساختار `RemoteControlCar` را به عنوان آرگومان می‌پذیرد. اگر باتری به ۰٪ رسیده باشد، نمایشگر باتری «Battery empty» را نشان می‌دهد.

## 5. رانندگی باتری و مسافت طی‌شده را تغییر می‌دهد

تابع `RemoteControlCar.drive/1` را پیاده‌سازی کنید که:

- مسافت طی‌شده را ۲۰ متر افزایش می‌دهد
- یک درصد از باتری را خالی می‌کند

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

مطمئن شوید که تابع فقط یک ساختار `RemoteControlCar` را به عنوان آرگومان می‌پذیرد.

## 6. در نظر گرفتن رانندگی با باتری خالی

تابع `RemoteControlCar.drive/1` را طوری تغییر دهید که وقتی باتری خالی است (۰٪)، نه مسافت طی‌شده را افزایش دهد و نه درصد باتری را کاهش دهد:

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
