# دستورالعمل

شما یک پرنده‌نگر مشتاق هستید که ثبت می‌کنید هر روز چند پرنده به باغتان آمده است.

تصمیم گرفته‌اید پرنده‌نگری‌تان را به سطح تازه‌ای ببرید و چند ابزار پیاده‌سازی کنید که به شما کمک می‌کنند این داده‌ها را پیگیری و پردازش کنید.

انتخاب کرده‌اید که داده‌ها را به شکل فهرستی از اعداد صحیح ذخیره کنید.
اولین عدد فهرست، شمار پرندگانی است که امروز به باغتان آمده‌اند، عدد دوم مربوط به دیروز است و به همین ترتیب.

```exercism/note
در برنامه‌های دنیای واقعی، هر جا که کاربرد داشته باشد باید همیشه از ماژول‌های پایه استفاده کنید، اما برای هدف یادگیری بازگشت، در این تمرین از هیچ‌یک از توابع `List` استفاده نکنید.
```

## 1. بررسی کنید امروز چند پرنده آمده است

تابع `today` را پیاده‌سازی کنید.
این تابع یک فهرست از شمار روزانه‌ی پرنده‌ها می‌گیرد و شمار امروز را برمی‌گرداند.
اگر فهرست خالی باشد، باید `Nothing` را برگرداند، در غیر این صورت شمار داخل یک `Just` قرار می‌گیرد.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. شمار امروز را یک واحد افزایش دهید

تابع `incrementDayCount` را پیاده‌سازی کنید.
این تابع یک فهرست از شمار روزانه‌ی پرنده‌ها می‌گیرد و شمار امروز را یک واحد افزایش می‌دهد.
اگر فهرست خالی باشد، `[1]` را برگردانید.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. بررسی کنید روزی بدون پرنده بوده است یا نه

تابع `hasDayWithoutBirds` را پیاده‌سازی کنید.
این تابع یک فهرست از شمار روزانه‌ی پرنده‌ها می‌گیرد.
اگر حداقل یک روز بوده باشد که هیچ پرنده‌ای به باغ نیامده است `True` را برمی‌گرداند و در غیر این صورت `False` را.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. شمار کل پرندگان بازدیدکننده را حساب کنید

تابع `total` را پیاده‌سازی کنید.
این تابع یک فهرست از شمار روزانه‌ی پرنده‌ها می‌گیرد و شمار کل پرندگانی را برمی‌گرداند که از زمانی که جمع‌آوری داده‌ها را شروع کرده‌اید به باغتان آمده‌اند.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. شمار روزهای پرمشغله را حساب کنید

بعضی روزها پرمشغله‌تر از بقیه‌اند.
روز پرمشغله روزی است که پنج پرنده یا بیشتر به باغتان آمده باشند.

تابع `busyDays` را پیاده‌سازی کنید.
این تابع یک فهرست از شمار روزانه‌ی پرنده‌ها می‌گیرد و شمار روزهای پرمشغله را برمی‌گرداند.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
