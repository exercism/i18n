# مشارکت‌کنندگان

مشارکت‌کنندگان Exercism افرادی هستند که به ساخت مسیرهای زبانی و ابزارهای Exercism کمک می‌کنند.

**هر کسی می‌تواند مشارکت‌کننده‌ی Exercism باشد**؛ هیچ پیش‌نیاز یا شرط ورودی وجود ندارد و ما از افراد با هر پیشینه‌ای استقبال می‌کنیم.
تا اینجا بیش از ۴٬۰۰۰ نفر به ساخت Exercism کمک کرده‌اند!

راه‌های گوناگونی برای کمک به Exercism وجود دارد:

- نوشتن تمرین‌ها
- توسعه‌ی مفاهیم یک مسیر
- بهبود مستندات
- ساخت ابزارهای جامانده (مثلاً Test Runner یا Code Analyzer)
- رفع باگ‌ها
- بهبود محتوای یک مسیر.

و بسیاری موارد دیگر.

برای دیدن همه‌ی کارهایی که اکنون به انجام‌دهنده نیاز دارند، به [بخش مشارکت](/contributing) سر بزنید.
