# یادگیری

* [The Rust Programming Language](https://doc.rust-lang.org/book/) منبعی عالی برای شروع کار با Rust و همچنین کاوش عمیق‌تر در ویژگی‌های خاص Rust است.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) نمونه‌هایی از رایج‌ترین مواردی را نشان می‌دهد که در Rust خواهید نوشت.
* [Into_rust()](http://intorust.com/) «اسکرین‌کست‌هایی برای یادگیری Rust.»
* [Rustlings](https://github.com/carols10cents/rustlings) «تمرین‌های کوچکی برای اینکه به خواندن و نوشتن کد Rust عادت کنید.»
* [Rust User Forum](http://users.rust-lang.org) به پرسش‌های همه‌ی سطوح پاسخ می‌دهد
