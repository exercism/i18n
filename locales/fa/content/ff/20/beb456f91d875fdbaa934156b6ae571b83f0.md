# مقدمه

## دستور `switch`

مانند یک دستور `if/else`، یک دستور `switch` به شما امکان می‌دهد جریان اجرای برنامه را با اجرای شرطی کد تغییر دهید.
تفاوت این است که دستور `switch` فقط می‌تواند مقدار یک عبارت از نوع داده اولیه یا رشته‌ای را با مقادیر ثابت از پیش تعریف‌شده مقایسه کند.

برخی کلیدواژه‌ها هنگام استفاده از دستور `switch` مفیدند.

- `switch`: این کلیدواژه به شما امکان می‌دهد ساختار `switch` را تعریف کنید.
  پس از آن، عبارت یا متغیری می‌آید که نتیجه را تغییر می‌دهد.
- `case`: از این کلیدواژه برای تعریف حالت‌های مختلف ممکن برای نتیجه استفاده می‌کنید.
- `break`: کلیدواژه‌ی `break` برای متوقف کردن اجرای `switch` در پایان جریان موردنظر بسیار مفید است.
  اگر آن را فراموش کنید، برنامه ادامه می‌یابد و ممکن است به نتایج غیرمنتظره‌ای منجر شود.
- `default`: همان‌طور که از اسمش پیداست، از آن به‌عنوان نتیجه‌ی پیش‌فرض زمانی استفاده کنید که هیچ `case` دیگری با نتیجه‌ی عبارت شما مطابقت ندارد.

در ساده‌ترین حالت، یک عبارت از نوع داده اولیه یا رشته‌ای را آزمایش می‌کند و بر اساس مقدار آن تصمیم می‌گیرد.
برای مثال:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
