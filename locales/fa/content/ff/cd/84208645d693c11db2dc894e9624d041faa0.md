# درباره

از `Map` برای ذخیره‌ی جفت‌های **کلید** و **مقدار** استفاده می‌شود. `Maps` درست مانند آرایه مقداردهی اولیه می‌شوند، اما برای نوشتن نقشه از عملگر `=>` استفاده می‌کنند. همچنین می‌توان نوع کلید و مقدار آن‌ها را به‌صراحت تعریف کرد، یا نوع‌ها را استنتاج کرد. کلیدها باید یکتا باشند، وگرنه خطایی پرتاب می‌شود.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

می‌توان با یک حلقه‌ی `for` روی `Map` پیمایش کرد. می‌توانید روی مقدارها یا کلیدها پیمایش کنید:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

در پشت صحنه، `Map` یک نوع انتزاعی است. در زمان کامپایل، بسته به نوع کلید، به یکی از چند نوع تخصصی زیر تبدیل می‌شود:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

نوع `Map` در زمان اجرا وجود ندارد و با یکی از اشیای بالا جایگزین شده است.
