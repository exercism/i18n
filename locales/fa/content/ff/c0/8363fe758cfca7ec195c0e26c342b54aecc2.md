# راهنمایی‌ها

## 1. یک تخته‌ی امتیاز بالا جدید بسازید

- برای ساخت یک `dict` جدید می‌توانید از توابع [`dict.new`][new] و [`dict.from_list`][from_list] استفاده کنید.

## 2. بازیکن‌ها را به تخته‌ی امتیاز اضافه کنید

- برای افزودن یک جفت کلید-مقدار جدید به یک `dict` می‌توانید از تابع [`dict.insert`][insert] استفاده کنید.

## 3. بازیکن‌ها را از تخته‌ی امتیاز حذف کنید

- برای حذف یک جفت کلید-مقدار از یک `dict` می‌توانید از تابع [`dict.delete`][delete] استفاده کنید.

## 4. امتیاز یک بازیکن را افزایش دهید

- برای گرفتن مقدار یک کلید در یک `dict` می‌توانید از تابع [`dict.get`][get] استفاده کنید.
- برای بازنویسی یک جفت کلید-مقدار موجود در یک `dict` می‌توانید از تابع [`dict.insert`][insert] استفاده کنید.

## 5. امتیاز ویژه‌ی دوشنبه را اعمال کنید

- برای تغییر همه‌ی مقدارهای یک `dict` می‌توانید از تابع [`dict.map_values`][map_values] استفاده کنید.
