# دستورالعمل‌ها

به عنوان یک علاقه‌مند به شطرنج، دوست دارید نسخه‌ی خودتان از این بازی را بنویسید.
بله، شاید همین حالا هم پیاده‌سازی‌های زیادی از شطرنج به صورت آنلاین در دسترس باشند، اما نسخه‌ی شما یگانه خواهد بود!

شما کار را با پیاده‌سازی یک سیستم حرکت پایه برای مهره‌ها شروع می‌کنید.

بازی شطرنج روی تخته‌ای انجام می‌شود که ۸ خانه عرض و ۸ خانه طول دارد.
هر خانه با یک حرف و یک عدد مشخص می‌شود.

## 1. تعریف محدوده‌ی ردیف‌ها و ستون‌ها

بازی باید ردیف‌های تخته را نگه دارد.
ردیف‌ها همان سطرهای تخته هستند و از ۱ تا ۸ شماره‌گذاری شده‌اند.

بازی همچنین باید ستون‌های تخته را نگه دارد.
ستون‌ها همان ستون‌های تخته‌اند و با حروف A تا H مشخص می‌شوند.

ثابت‌های `Chess::RANKS` و `Chess::FILES` را تعریف کنید که به ترتیب محدوده‌ی ردیف‌ها و ستون‌ها را نگه می‌دارند.

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. بررسی معتبر بودن خانه

بازی باید بررسی کند که آیا یک خانه معتبر است یا نه.
یک خانه وقتی معتبر است که ردیف و ستون آن در محدوده‌ی ردیف‌ها و ستون‌ها قرار داشته باشند.

متد `Chess.valid_square?` را تعریف کنید که آرگومان‌های `rank` و `file` را می‌گیرد؛ `rank` یک عدد صحیح از ردیف را نگه می‌دارد و `file` یک کاراکتر از ستون.
این متد باید در صورتی که ردیف و ستون در محدوده‌ی ردیف‌ها و ستون‌ها باشند `true` را برگرداند و در غیر این صورت `false` را.

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. گرفتن اسم مستعار بازیکن

بازی باید اسم مستعار بازیکن را به دست آورد.
اسم مستعار از ۲ کاراکتر اول اسم کوچک بازیکن و ۲ کاراکتر آخر اسم خانوادگی او تشکیل می‌شود.
اسم مستعار باید با حروف بزرگ نوشته شود.

متد `Chess.nickname` را تعریف کنید که آرگومان‌های `first_name` و `last_name` را می‌گیرد؛ `first_name` رشته‌ای از اسم کوچک بازیکن را نگه می‌دارد و `last_name` رشته‌ای از اسم خانوادگی او را.
این متد باید اسم مستعار بازیکن را به صورت رشته‌ای با حروف بزرگ برگرداند.

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. ساختن پیام حرکت

بازی باید برای یک حرکت پیامی بسازد که بگوید کدام بازیکن به کدام خانه حرکت کرده است.
پیام باید از اسم مستعار بازیکن و خانه‌ای که به آن حرکت کرده است استفاده کند.
بازی همچنین باید معتبر بودن حرکت را با بررسی اینکه ردیف و ستون خانه در محدوده‌ی ستون‌ها و ردیف‌ها قرار دارند یا نه تعیین کند.

اگر حرکت معتبر باشد، پیام باید این باشد: `"{nickname} moved to {square}"`
اگر حرکت معتبر نباشد، پیام باید این باشد: `"{nickname} attempted to move to {square}, but that is not a valid square"`

متد `Chess.move_message` را تعریف کنید که آرگومان‌های `first_name`، `last_name` و `square` را می‌گیرد؛ `first_name` رشته‌ای از اسم کوچک بازیکن، `last_name` رشته‌ای از اسم خانوادگی بازیکن و `square` رشته‌ای از خانه‌ای را که بازیکن به آن حرکت کرده است نگه می‌دارد.
این متد باید پیام حرکت را به صورت رشته‌ای برگرداند.

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
