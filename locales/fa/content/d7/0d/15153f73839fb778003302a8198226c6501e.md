# نصب Python

اگر Python از پیش روی سیستم شما نصب نیست، دستورالعمل‌های تفصیلی به تفکیک سیستم‌عامل را می‌توانید در بخش [Python Setup and Usage][using python] از مستندات رسمی پیدا کنید.
Real Python هم [راهنمای خوبی][helpful guide] برای نصب روی سیستم‌عامل‌های مختلف، از جمله iOS و Android، ارائه می‌دهد.

در پایان، این نوشته‌های Brett Cannon با نام [A quick-and-dirty guide][quick-and-dirty] و [Why you should use `python -m pip`][python-m-pip] توصیه‌های بسیار مفیدی درباره‌ی نحوه‌ی مدیریت نصب‌ها و بسته‌های Python در اختیارتان می‌گذارند.

**نکته برای کاربران MacOS:**  پیش از MacOS Monterey (۱۲.۳)، `Python 2.7` از پیش همراه سیستم‌عامل نصب شده بود.
استفاده از `Python 2.7` در Exercism یا بیشتر برنامه‌های دیگر پشتیبانی نمی‌شود.
در عوض، باید [Python 3][Python-three downloads] را با یکی از روش‌هایی که در ادامه آمده نصب کنید.
از MacOS Monterey (۱۲.۳) به بعد، هیچ نسخه‌ای از Python از پیش همراه MacOS نصب نمی‌شود.

چند پیوند سریع به مستندات، به تفکیک سیستم‌عامل:

-  [Windows][windows] این مقاله‌ی مایکروسافت درباره‌ی [نصب Python در ویندوز][python-on-windows] هم مفید است.
-  [Unix & Linux Systems][unix-and-linux] (_این روش‌ها تا حد زیادی برای MacOS هم کار می‌کنند_)
-  [MacOS][macos]

   همچنین توصیه می‌کنیم نگاهی به مقاله‌ی [Installing Python][installing-python] از Real Python یا نوشته‌های Brett Cannon که در بالا آمد بیندازید؛ در آن‌ها چند روش نصب معرفی شده است.


آزمون‌ها و ابزارهای Exercism در حال حاضر از `3.10` تا `3.13.5` (_آزمون‌ها_) و [`Python 3.13.5`][313-new-features] (_ابزارها_) پشتیبانی می‌کنند.
استثناهای این پشتیبانی هر جا که پیش بیایند ذکر شده‌اند.
بیشتر تمرین‌ها با `Python 3.6+` یا حتی نسخه‌های قدیمی‌تر کار می‌کنند.
اما برای نسخه‌هایی که در [Active Python Releases][active-python-releases] فهرست نشده‌اند، پشتیبانی را تضمین نمی‌کنیم.


برای اطلاع از آنچه در حال حاضر پشتیبانی می‌شود، به [مستندات Python 3.13.x][3.13 docs] مراجعه کنید.
