# پیوست دستورالعمل‌ها

## راهنمایی‌ها

این اولین تمرینی است که testهایش از شما می‌خواهند که یک [`Exception`][exception-docs] پرتاب کنید.
`Exception`ها معمولاً پرتاب می‌شوند تا نشان دهند که برنامه با یک ورودی یا وضعیت غیرمنتظره روبه‌رو شده است.

testها در سراسر مسیر بررسی می‌کنند که `Exception`هایی که پرتاب می‌کنید:

1. نمونه‌هایی از یک نوع مشخص در Java باشند؛
2. (به‌صورت اختیاری) با یک پیام مشخص مقداردهی اولیه شده باشند.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
