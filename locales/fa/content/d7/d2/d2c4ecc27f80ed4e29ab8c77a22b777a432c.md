# مقدمه

[`Time`][time] در Go نوعی است که یک لحظه در زمان را توصیف می‌کند.
اطلاعات تاریخ و زمان را می‌توان از طریق متدهایش خواند، مقایسه کرد و دست‌کاری کرد، اما چند تابع هم هست که روی خود پکیج `time` فراخوانی می‌شوند.
تاریخ و زمان کنونی را می‌توان با تابع [`time.Now`][now] به دست آورد.

تابع [`time.Parse`][parse] رشته‌ها را به مقادیری از نوع `Time` تبدیل می‌کند.
Go روش ویژه‌ای برای تعریف قالبی دارد که برای تجزیه انتظار دارید.
باید نمونه‌ای از این قالب را با استفاده از مقادیر این مهر زمانی ویژه بنویسید:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

برای مثال:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

متد [`Time.Format()`][format] نمایشی رشته‌ای از زمان برمی‌گرداند.
درست مانند تابع `Parse`، قالب مقصد هم دوباره با نمونه‌ای تعریف می‌شود که از مقادیر مهر زمانی ویژه استفاده می‌کند.

برای مثال:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## گزینه‌های قالب

برای یک قالب سفارشی، از ترکیبی از این گزینه‌ها استفاده کنید.
در Go، [ثابت‌های قالب][const] از پیش تعریف‌شده‌ای هم برای تاریخ و مهر زمانی در دسترس‌اند.

| زمان        | گزینه‌ها                                        |
| ----------- | ---------------------------------------------- |
| سال         | 2006 ; 06                                      |
| ماه         | Jan ; January ; 01 ; 1                         |
| روز         | 02 ; 2 ; \_2 (برای صفر پیشین)                  |
| روز هفته    | Mon ; Monday                                   |
| ساعت        | 15 ( قالب زمانی ۲۴ساعته ) ; 3 ; 03 (AM or PM)  |
| دقیقه       | 04 ; 4                                         |
| ثانیه       | 05 ; 5                                         |
| نشانگر AM/PM| PM                                             |
| روز سال     | 002 ; \_\_2                                    |

نوع `time.Time` متدهای گوناگونی برای دسترسی به بخشی خاص از زمان دارد؛ مثلاً ساعت: [`Time.Hour()`][hour] و ماه: [`Time.Month()`][month].
توضیح بیشتر درباره‌ی نحوه‌ی کار آن را می‌توانید در [مستندات رسمی][time] پیدا کنید.

[`time`][time] نوع دیگری هم دارد به نام [`Duration`][duration] که زمان سپری‌شده را نشان می‌دهد، به‌علاوه پشتیبانی از مکان‌ها/مناطق زمانی، تایمرها و سایر قابلیت‌های مرتبط که در مفهوم دیگری بررسی می‌شوند.
