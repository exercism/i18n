# دستورالعمل‌ها

در این تمرین باید چند قاعده از [Pac-Man][Pac-Man]، بازی آرکید کلاسیک دهه‌ی ۱۹۸۰، را پیاده‌سازی کنید.

چهار قاعده برای پیاده‌سازی دارید که همه به حالت‌های بازی مربوط می‌شوند.

> _نگران این نباشید که آرگومان‌ها چگونه به دست می‌آیند؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید._

## 1. تعریف کنید که آیا Pac-Man شبح می‌خورد

تابع `eat_ghost()` را تعریف کنید که دو پارامتر می‌گیرد (_اینکه آیا Pac-Man قرص قدرت فعال دارد_ و _اینکه آیا Pac-Man با شبح در تماس است_) و اگر Pac-Man بتواند شبح بخورد، یک مقدار «منطقی» برمی‌گرداند.
 تابع باید فقط در صورتی `True` برگرداند که Pac-Man قرص قدرت فعال داشته باشد و با شبح در تماس باشد.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. تعریف کنید که آیا Pac-Man امتیاز می‌گیرد

تابع `score()` را تعریف کنید که دو پارامتر می‌گیرد (_اینکه آیا Pac-Man با قرص قدرت در تماس است_ و _اینکه آیا Pac-Man با نقطه‌ای در تماس است_) و اگر Pac-Man امتیاز گرفته باشد، یک مقدار منطقی برمی‌گرداند.
 تابع باید در صورتی `True` برگرداند که Pac-Man با یک قرص قدرت یا یک نقطه در تماس باشد.

```python
>>> score(True, True)
...
True
```

## 3. تعریف کنید که آیا Pac-Man می‌بازد

تابع `lose()` را تعریف کنید که دو پارامتر می‌گیرد (_اینکه آیا Pac-Man قرص قدرت فعال دارد_ و _اینکه آیا Pac-Man با شبح در تماس است_) و اگر Pac-Man ببازد، یک مقدار منطقی برمی‌گرداند.
 تابع باید در صورتی `True` برگرداند که Pac-Man با شبح در تماس باشد و قرص قدرت فعالی نداشته باشد.

```python
>>> lose(False, True)
...
True
```

## 4. تعریف کنید که آیا Pac-Man می‌برد

تابع `win()` را تعریف کنید که سه پارامتر می‌گیرد (_اینکه آیا Pac-Man همه‌ی نقطه‌ها را خورده است_، _اینکه آیا Pac-Man قرص قدرت فعال دارد_ و _اینکه آیا Pac-Man با شبح در تماس است_) و اگر Pac-Man برنده شود، یک مقدار منطقی برمی‌گرداند.
 تابع باید در صورتی `True` برگرداند که Pac-Man همه‌ی نقطه‌ها را خورده باشد و بر اساس قواعد تعریف‌شده در بخش ۳ نباخته باشد.

```python
>>> win(False, True, False)
...
False
```
