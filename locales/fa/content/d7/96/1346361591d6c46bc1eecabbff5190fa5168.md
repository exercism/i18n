# مقدمه

## اکسپورت کردن توابع

اکسپورت کردن توابع در مفهوم اول پوشش داده شد؛ در ادامه یک مرور سریع داریم.

هر فایل در Elm یک ماژول است و باید پیش از هر کد دیگری شامل یک دستور `module` باشد.

نام ماژول‌ها باید با نام فایلشان یکی باشد؛ پس ماژول `Calculator` باید در فایل `Calculator.elm` باشد و ماژول `Parser.Utils` باید در فایل `Parser/Utils.elm` قرار داشته باشد.

هر چیزی که درون یک ماژول تعریف شود، به‌صورت خصوصی به همان ماژول محدود می‌شود و از بیرون این ماژول قابل دسترسی نیست، مگر آنکه در `exposing` فهرست شده باشد.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## ایمپورت کردن توابع از ماژول‌های دیگر

دسترسی به توابعی که در ماژول‌های دیگر تعریف شده‌اند، از طریق ایمپورت کردن انجام می‌شود.
وقتی ماژولی را ایمپورت می‌کنید، همه‌ی توابعی که آن ماژول آشکار کرده است، قابل دسترسی می‌شوند.
اما شیوه‌ی دسترسی به آن‌ها بسته به نحوه‌ی ایمپورت کردن ماژول فرق می‌کند.

ایمپورت کامل حالت پیش‌فرض است و برای دسترسی به تابعی در چنین ماژولی (مثلاً تابع `map` در ماژول `List`) نام ماژول را به‌عنوان پیشوند می‌آورید (`List.map`).

ایمپورت باز دسترسی مستقیم به توابع آشکارشده‌ی آن ماژول را بدون پیشوند ممکن می‌کند. این کار با کلیدواژه‌ی `exposing` انجام می‌شود، درست مثل آینه‌ای از همان کلیدواژه‌ای که در اکسپورت به کار می‌رود. می‌توانید همه‌ی توابع موجود را آشکار کنید (با `..`) یا فقط توابع خاصی را (مثلاً `map`).

همچنین می‌توانید نوع‌ها و سازنده‌هایشان را از ماژول‌های دیگر ایمپورت کنید، که موضوع یک مفهوم بعدی است.

برای وضوح بیشتر و جلوگیری از برخورد نام‌ها، ایمپورت کامل ترجیح داده می‌شود.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## حاشیه‌نویسی نوع

حاشیه‌نویسی نوع با `name : parameter types -> return type` تعریف می‌شود، که در آن نوع‌های پارامتر هم با `->` از هم جدا می‌شوند.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

می‌توان از پرانتز برای تعریف پارامترهای تابع استفاده کرد (که خودشان با همان نحوه‌ی نگارش تعریف می‌شوند و همین باعث نیاز به پرانتز می‌شود).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## عدد

دو نوع عدد در Elm وجود دارد که با نوع‌های `Int` و `Float` تعریف می‌شوند.
`Int` متناظر با مجموعه‌ی اعداد صحیح مثبت و منفی است.
`Float` متناظر با مجموعه‌ی اعداد حقیقی است که با دقت کامپیوتر محدود می‌شود.
عملیات تعریف‌شده روی اعداد معمولاً روی یکی از این دو نوع کار می‌کنند و این دو را با هم ترکیب نمی‌کنند.
توابعی برای تبدیل میان این دو وجود دارد؛ مانند `toFloat` که `Int` را به `Float` تبدیل می‌کند و `round`، `floor`، `ceiling` یا `truncate` که یک `Float` را با معانی مختلف به `Int` تبدیل می‌کنند.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## عملیات رشته

Elm برای توصیف واژه‌ها و جمله‌ها در کد، یک نوع بومی `String` دارد.
مقدارهای رشته‌ای بین دو دابل‌کوتیشن نوشته می‌شوند، مانند `"Hello World!"`.
عملگر الحاق رشته `++` و عملگر برابری `==` به‌طور پیش‌فرض در دسترس هستند.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

بیشتر توابع دیگر رشته در ماژول `String` قرار دارند که باید ایمپورت شود.

https://package.elm-lang.org/packages/elm/core/latest/String
