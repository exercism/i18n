# دستورالعمل‌ها

دوست شما کوجو طرفدار پر و پا قرص اعداد است.
او یک وبسایت کوچک به اسم «fun-with-numbers» دارد.
کوجو در برنامه‌نویسی چندان ماهر نیست، بنابراین از شما کمک خواسته است.

شما دو تابع کمکی برای بازی‌های عددی تازه در وبسایت کوجو خواهید ساخت و یک تابع سوم هم برای اعتبارسنجی ورودی‌ای که کاربر می‌تواند وارد کند.

## 1. محاسبه‌ی مجموع اعداد روی ماشین اسلات

یکی از بازی‌های وبسایت کوجو شبیه ماشین اسلاتی است که دو گروه چرخ را نشان می‌دهد و روی هر چرخ رقم‌هایی هست.
هر گروه رقم نشان‌دهنده‌ی یک عدد است.
کوجو برای مکانیک بازی باید مجموع آن دو عدد را بداند.

تابعی به اسم `twoSum` بنویسید که دو آرایه را به عنوان پارامتر می‌پذیرد.
هر آرایه از یک یا چند عدد بین ۰ و ۹ تشکیل شده است.
تابع باید هر آرایه را به عنوان یک عدد تفسیر کند و مجموع آن دو عدد را برگرداند.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. تشخیص پالیندروم بودن یک عدد

بازی دیگری در وبسایت یک آزمون کوچک به اسم «Lucky Numbers» است.
کاربر می‌تواند عددی وارد کند و بعد ببیند که آیا آن عدد به یک دنباله یا الگوی مخفی تعلق دارد یا نه.
دنباله یا الگوی «اعداد خوش‌شانس» هر ماه عوض می‌شود و هر کاربر فقط تعداد محدودی فرصت برای حدس زدن آن دارد.

اعداد خوش‌شانس این ماه باید اعدادی باشند که پالیندروم هستند.
اعداد پالیندروم با معکوس شدن رقم‌هایشان تغییری نمی‌کنند.

تابع تازه‌ی `luckyNumber` را پیاده‌سازی کنید که یک عدد را به عنوان پارامتر می‌پذیرد.
تابع باید اگر عدد پالیندروم بود `true` و در غیر این صورت `false` برگرداند.
عدد ورودی همیشه یک عدد صحیح مثبت خواهد بود.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. تولید پیام خطا برای ورودی نامعتبر کاربر

در جاهای مختلف وبسایت، فیلدهای ورودی‌ای وجود دارد که کاربران می‌توانند در آن‌ها عدد وارد کنند و با کلیک روی یک دکمه کاری را فعال کنند.
کوجو می‌خواهد تجربه‌ی کاربری سایتش را بهتر کند.
او می‌خواهد اگر کاربر روی دکمه کلیک کرد اما فیلد مقدار ورودی نامعتبری داشت، پیام خطایی نشان دهد.

در ادامه اطلاعات بیشتری درباره‌ی این که مقدار یک فیلد ورودی چگونه به دست می‌آید آمده است.

- اگر کاربر چیزی در فیلد تایپ کند، مقدار متناظر همیشه یک رشته است، حتی اگر فقط عدد تایپ کرده باشد.
- اگر کاربر چیزی تایپ کند اما دوباره پاکش کند، متغیر یک رشته‌ی خالی خواهد بود.
- پیش از آن که کاربر حتی شروع به تایپ کند، متغیر می‌تواند `undefined` یا `null` باشد.

تابعی به اسم `errorMessage` بنویسید که ورودی کاربر را به عنوان پارامتر می‌پذیرد.
اگر کاربر هیچ ورودی‌ای نداده باشد، `errorMessage` باید `'Required field'` را برگرداند.
اگر ورودی نشان‌دهنده‌ی عددی غیر از صفر نباشد (بر اساس قواعد تبدیل JavaScript)، باید `'Must be a number besides 0'` برگردانده شود.
در همه‌ی موارد دیگر می‌توانید فرض کنید ورودی معتبر است و مقدار بازگشتی باید یک رشته‌ی خالی باشد.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
