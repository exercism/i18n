# تست

## اجرای تست‌ها

برای اجرای تست‌ها، دستور زیر را اجرا کنید:

```bash
make
```

## حل تمرین

حل یک تمرین به این معناست که همه‌ی تست‌های آن پاس شوند. به‌طور پیش‌فرض، وقتی تست‌ها را اجرا می‌کنید، فقط یک تست (اولین تست) اجرا می‌شود. این کار عمدی است، چون به شما اجازه می‌دهد فقط روی پاس کردن همان یک تست تمرکز کنید. وقتی آن تست پاس شد، می‌توانید با حذف خط `TEST_IGNORE()` تست بعدی را فعال کنید. وقتی همه‌ی تست‌ها فعال شدند و پیاده‌سازی شما همه‌ی آن‌ها را پاس کرد، تمرین را حل کرده‌اید!
