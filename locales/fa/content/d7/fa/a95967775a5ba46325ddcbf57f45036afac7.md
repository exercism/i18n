# مقدمه

تبدیل نوع در Cairo به شما امکان می‌دهد داده را از یک نوع به نوع دیگر تبدیل کنید و این کار دستکاری داده را انعطاف‌پذیر و ایمن می‌کند.

## مبانی

Cairo چندین سازوکار برای تبدیل نوع ارائه می‌دهد:

### تبدیل مستقیم

برای نوع‌های عددی سازگار، می‌توانید از تبدیل مستقیم استفاده کنید:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### خصیصه‌ی Into

خصیصه‌ی `Into` امکان تبدیل از یک نوع به نوع دیگر را فراهم می‌کند:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### خصیصه‌ی TryInto

برای تبدیل‌هایی که ممکن است شکست بخورند، از `TryInto` استفاده کنید که یک `Option` برمی‌گرداند:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## تبدیل نوع سفارشی

می‌توانید `Into` را برای نوع‌های خودتان پیاده‌سازی کنید:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## ملاحظات ایمنی

- وقتی ممکن است تبدیل شکست بخورد از `TryInto` استفاده کنید (مثلاً تبدیل نوع بزرگ به کوچک)
- وقتی تبدیل همیشه موفق می‌شود از `Into` استفاده کنید
- همیشه حالت‌های `Option::None` را از `TryInto` مدیریت کنید
- هنگام تبدیل بین نوع‌های علامت‌دار و بدون علامت، سرریز و زیرریز را در نظر بگیرید
