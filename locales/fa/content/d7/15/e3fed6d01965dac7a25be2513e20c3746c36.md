# نصب

Crystal روی Linux، macOS و Windows در دسترس است.

نکته‌ی قابل توجه این است که پشتیبانی Crystal از Windows آزمایشی است. یعنی ممکن است برخی حالت‌های خاص کار نکنند و برای استفاده در محیط تولید ایده‌آل نباشد. با این حال، برای Exercism و استفاده‌های پایه، Windows بومی باید تا حد زیادی قابل استفاده باشد.

اگر به دنبال تجربه‌ای خارج از حالت پیش‌نمایش برای توسعه در Windows هستید، توصیه می‌شود از [WSL (زیرسیستم Windows برای Linux)][wsl] استفاده کنید. این قابلیتی **رایگان** در Windows 10 (1903+) و 11 است که به توسعه‌دهنده امکان می‌دهد بدون نیاز به ماشین مجازی، یک محیط Linux را اجرا کند.

برای دستورالعمل نصب Crystal، از یکی از [راهنماهای نصب][installation guides] استفاده کنید.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
