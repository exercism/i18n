# مقدمه

یک **شیء** JSON، اگر بخواهیم از اصطلاحات زبان‌های دیگر استفاده کنیم، همان «هش»، «نقشه» یا «دیکشنری» است.

JSON یک _شیء_ را این‌گونه تعریف می‌کند:

> یک شیء مجموعه‌ی نامرتبی از جفت‌های **اسم**/**مقدار** است.
> یک شیء با `{` (آکولاد چپ) آغاز می‌شود و با `}` (آکولاد راست) پایان می‌یابد.
> هر _اسم_ با `:` (دونقطه) دنبال می‌شود و جفت‌های _اسم/مقدار_ با `,` (کاما) از هم جدا می‌شوند.

_اسم_ **باید یک رشته باشد**.
واژه‌ی دیگری که برای _اسم_ به کار می‌رود، _کلید_ است.

_مقدار_ می‌تواند از هر نوع JSON باشد.
_مقدارهای_ مختلف در یک شیء یکسان می‌توانند نوع‌های متفاوتی داشته باشند، مثل این مثال.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

توجه کنید که پس از _آخرین_ جفت کلید-مقدار **نباید** کاما بیاید.

## ساختن شیءها

برای جمع کردن جفت‌های اسم/مقدار از آکولاد استفاده کنید.
هرچند اسم‌ها باید رشته باشند، اگر اسم‌ها **شبیه شناسه** باشند (از نویسه‌های الفبایی‌عددی و زیرخط تشکیل شده و با رقم شروع نشده باشند) نیازی نیست در گیومه گذاشته شوند.

```jq
{name: "Jane", age: 42}
```

استفاده از کلیدهایی که شبیه شناسه نیستند هم مجاز است.
کافی است آن‌ها را در گیومه بگذارید.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

اگر اسم نتیجه‌ی یک عبارت باشد، آن عبارت **باید** داخل پرانتز باشد.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## اندیس‌گذاری

مقدارها با **نقطه‌نگاری** از یک شیء بازیابی می‌شوند.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

اگر نمی‌توانید به کلید به‌عنوان یک شناسه ارجاع دهید، از **براکت‌نگاری** استفاده کنید.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## افزودن یا تغییر جفت‌های کلید-مقدار

برای افزودن یک جفت کلید-مقدار تازه به یک آرایه، یا برای به‌روزرسانی مقدار یک کلید موجود، از عملگر تخصیص `=` استفاده کنید و یک عبارت اندیس در سمت چپ آن بنویسید.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

عملگر `+` شیءها را _ادغام_ می‌کند.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## حذف یک کلید

برای حذف یک کلید از تابع `del` استفاده کنید.
این تابع شیء به‌روزرسانی‌شده را برمی‌گرداند.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

پارامتری که به `del` می‌دهید یک **عبارت اندیس** است (با نقطه‌نگاری یا براکت‌نگاری) که یک کلید در شیء را مشخص می‌کند.
`jq` به آن **عبارت مسیر** می‌گوید.
صرفاً دادن یک رشته کافی نیست.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## عضویت

- برای آزمایش اینکه آیا شیء یک کلید دارد، از تابع `has` استفاده کنید.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- با `in` آزمایش کنید که آیا یک کلید در یک شیء هست.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## فهرست کردن همه‌ی کلیدها

برای تولید فهرستی از همه‌ی کلیدها از تابع `keys` استفاده کنید.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

توجه کنید که `keys` کلیدها را _مرتب_ می‌کند.
برای بازیابی کلیدها به ترتیب اصلی، از `keys_unsorted` استفاده کنید.

تابع معادلی برای فهرست کردن همه‌ی _مقدارها_ وجود ندارد.
اما فیلتر `.[]` مقدارهای شیء را به‌صورت یک _جریان_ تولید می‌کند و آن جریان را می‌توان با سازنده‌ی آرایه‌ی `[...]` ثبت کرد.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## پیمایش

- تابع `map_values(filter)` فیلتر را روی هر _مقدار_ در شیء اعمال می‌کند.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- برای پیمایش یک شیء، باید ابتدا آن را به آرایه‌ای از اشیای کلید-مقدار تبدیل کنیم.
  تابع `to_entries` این کار را انجام می‌دهد.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  در این مرحله می‌توانیم از توابع پیمایش آرایه، مثل `map`، استفاده کنیم.

- تابع `from_entries` برعکس این کار است: آرایه‌ای از اشیای کلید-مقدار را به یک شیء تبدیل می‌کند.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- برای اعمال یک فیلتر روی _هر_ جفت کلید-مقدار در یک شیء، از تابع `with_entries(filter)` استفاده کنید.

  برای مثال، اگر شیئی داشته باشیم که هر اسم را به یک سن نگاشت می‌کند، می‌توان کلیدها و مقدارها را به‌صورت زیر جابه‌جا کرد.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  خروجی:

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` معادل این است:

  ```jq
  to_entries | map(filter) | from_entries
  ```
