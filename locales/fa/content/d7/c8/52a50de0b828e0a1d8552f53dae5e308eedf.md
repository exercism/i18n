# دستورالعمل‌ها

سارا روی یک بازی نقش‌آفرینی جدید کار می‌کند و برای مکانیک‌های بازیکن به کمک شما نیاز دارد.

## 1. کلاس تاپل `player` را تعریف کنید

یک کلاس تاپل `player` با چهار «جایگاه» و مقادیر پیش‌فرض تعریف کنید:

| slot     | default |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

پس از تعریف، می‌توانید یک بازیکن را به‌صورت یک مقدار تحت‌اللفظی بسازید:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. بازیکن را معرفی کنید

`introduce` را طوری تعریف کنید که اسم بازیکن را برگرداند. بازیکنان پنهان‌کار اسم خود را پنهان می‌کنند (مقدار `name` برابر `f` است) و باید به‌صورت `"Mighty Magician"` معرفی شوند.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. بازیکن افتاده را احیا کنید

`revive` را طوری تعریف کنید که یک بازیکن *جدید* برگرداند که `health` آن روی ۱۰۰ و `mana` آن روی ۱۰۰ تنظیم شده باشد، اما فقط اگر `health` بازیکن `0` باشد. اگر بازیکن هنوز زنده است، `f` را برگردانید.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. آسیب دریافت کنید

`take-damage` را طوری تعریف کنید که یک بازیکن *جدید* برگرداند که `health` آن به اندازه‌ی مقدار داده‌شده کاهش یافته باشد و هرگز به کمتر از `0` نرسد.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
