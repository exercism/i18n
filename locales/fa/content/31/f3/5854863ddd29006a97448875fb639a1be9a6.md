# دستورالعمل‌ها

شما علاقه‌ی زیادی به قطارهای مدل دارید و تصمیم گرفته‌اید اشتیاق خود را با جهان به اشتراک بگذارید و یک خبرنامه راه بیندازید. کار را با فرستادن اولین شماره‌ی خبرنامه برای دوستان و آشنایانی شروع می‌کنید که این سرگرمی را با شما مشترک دارند. یک فایل متنی دارید که فهرست نشانی‌های ایمیل آن‌ها در آن است.

## 1. خواندن نشانی‌های ایمیل از یک فایل

تابع `Newsletter.read_emails/1` را پیاده‌سازی کنید. این تابع یک مسیر فایل می‌گیرد. فایل، یک فایل متنی است که نشانی‌های ایمیل را با خط جدید از هم جدا کرده است. تابع باید فهرستی از نشانی‌های ایمیل موجود در فایل را برگرداند.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. باز کردن یک فایل گزارش برای نوشتن

فرستادن ایمیل کاری است که ممکن است به دلایل غیرقابل‌پیش‌بینی زیادی شکست بخورد، مثلاً یک غلط تایپی در نشانی ایمیل یا مشکل موقت شبکه. برای اینکه بتوانید فرستادن ایمیل‌ها به همه‌ی دوستانتان را دوباره امتحان کنید بدون آنکه ایمیل تکراری بفرستید، باید نشانی‌هایی را ثبت کنید که ایمیل را دریافت کرده‌اند. برای این کار به یک فایل گزارش نیاز دارید.

تابع `Newsletter.open_log/1` را پیاده‌سازی کنید. این تابع یک مسیر فایل می‌گیرد، فایل را برای نوشتن باز می‌کند و PID فرایندی را که فایل را مدیریت می‌کند برمی‌گرداند.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. ثبت یک ایمیل فرستاده‌شده

تابع `Newsletter.log_sent_email/2` را پیاده‌سازی کنید. این تابع PID فرایندی که فایل را مدیریت می‌کند و یک رشته شامل نشانی ایمیل را می‌گیرد. باید نشانی ایمیل را در فایل بنویسد و پس از آن یک خط جدید بگذارد.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. بستن فایل گزارش

تابع `Newsletter.close_log/1` را پیاده‌سازی کنید. این تابع PID فرایندی که فایل را مدیریت می‌کند می‌گیرد و فایل را می‌بندد.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. فرستادن خبرنامه

حالا که همه‌ی اجزای سازنده‌ی فرایند فرستادن ایمیل را دارید، باید آن‌ها را در یک تابع واحد با هم ترکیب کنید.

تابع `Newsletter.send_newsletter/3` را پیاده‌سازی کنید. این تابع مسیر فایل نشانی‌های ایمیل، مسیر یک فایل گزارش و یک تابع بی‌نام را می‌گیرد که ایمیلی را به نشانی ایمیل داده‌شده می‌فرستد. باید همه‌ی نشانی‌های ایمیل را از فایل داده‌شده بخواند و بکوشد به هر یک از آن‌ها ایمیل بفرستد. اگر تابع بی‌نامی که ایمیل را می‌فرستد مقدار `:ok` را برگرداند، نشانی ایمیل را در فایل گزارش بنویسد و پس از آن یک خط جدید بگذارد. دقت کنید این کار را به‌محض فرستادن ایمیل انجام دهید. پس از پایان همه‌ی فرستادن‌ها، فایل گزارش را ببندید.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
