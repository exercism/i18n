# عملگرهای مقایسه

PHP ده عملگر مقایسه‌ی توکار دارد:

| اسم  | مثال    | نتیجه                                             |
| ----- | ---------- | -------------------------------------------------- |
| برابر | `$a == $b` | اگر `$a` پس از تبدیل خودکار نوع برابر با `$b` باشد، «درست» است. |
| یکسان | `$a === $b` | اگر `$a` برابر با `$b` و از همان نوع باشد، «درست» است. |
| نابرابر | `$a != $b` | اگر `$a` پس از تبدیل خودکار نوع برابر با `$b` نباشد، «درست» است. |
| نابرابر | `$a <> $b` | اگر `$a` پس از تبدیل خودکار نوع برابر با `$b` نباشد، «درست» است. |
| نایکسان | `$a !== $b` | اگر `$a` برابر با `$b` نباشد یا از همان نوع نباشد، «درست» است. |
| کمتر از | `$a < $b` | اگر `$a` اکیداً کمتر از `$b` باشد، «درست» است. |
| بیشتر از | `$a > $b` | اگر `$a` اکیداً بیشتر از `$b` باشد، «درست» است. |
| کمتر یا برابر با | `$a <= $b` | اگر `$a` کمتر یا برابر با `$b` باشد، «درست» است. |
| بیشتر یا برابر با | `$a >= $b` | اگر `$a` بیشتر یا برابر با `$b` باشد، «درست» است. |
| سفینه فضایی | `$a <=> $b` | یک عدد صحیح کمتر از، برابر با، یا بیشتر از `0`i برمی‌گرداند، وقتی `$a`. |

PHP تعریف‌های متمایزی دارد که بین `equal` و `identical` تفاوت می‌گذارد. گاهی به `identical`، `strictly equal` هم گفته می‌شود.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
