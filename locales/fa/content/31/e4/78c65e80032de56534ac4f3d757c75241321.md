# مقدمه

در Go، یک برنامه در قالب پکیج‌ها سازماندهی می‌شود.
پکیج مجموعه‌ای از فایل‌های سورس است که در یک پوشه قرار دارند.
همه‌ی فایل‌های سورس در یک پوشه باید در بالای فایل نام پکیج یکسانی داشته باشند.
طبق قرارداد، پکیج‌ها هم‌نام پوشه‌ای نام‌گذاری می‌شوند که در آن قرار دارند.

```go
package greeting
```

Go کتابخانه‌ی استاندارد گسترده‌ای از پکیج‌ها ارائه می‌دهد که می‌توانید با استفاده از کلیدواژه‌ی `import` در برنامه‌تان به کار ببرید.
پکیج‌های کتابخانه‌ی استاندارد با استفاده از نام خودشان وارد می‌شوند.

```go
package greeting

import "fmt"
```

سپس به پکیج واردشده با نام پکیج ارجاع داده می‌شود:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go از طریق نحوه‌ی اعلان مشخص می‌کند که آیا کدی در پکیج‌های دیگر می‌تواند یک مورد را فراخوانی کند یا نه.
برای اینکه یک تابع، نوع، متغیر، ثابت یا فیلد ساختار از بیرون قابل مشاهده باشد (که به آن «_صادرشده_» می‌گویند)، نامش باید با حرف بزرگ شروع شود.
این موضوع مشابه زبان‌های برنامه‌نویسی دیگری مانند Java است که از تغییردهنده‌های دسترسی مثل `public` و `private` استفاده می‌کنند.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
