# مقدمه

## فیلتر کردن استثناها

کلیدواژه‌ی فیلتر کردن استثناها `when` است. این کلیدواژه بعد از دستور `catch` قرار می‌گیرد و می‌تواند یک عبارت منطقی دریافت کند که هر مقداری را که در آن لحظه در دسترس است در بر بگیرد. اگر نتیجه‌ی این عبارت «درست» باشد، بلوکی که به آن دستور `catch` مربوط است اجرا می‌شود؛ در غیر این صورت، دستور `catch` بعدی، اگر وجود داشته باشد، بررسی می‌شود.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## استثناهای تعریف‌شده توسط کاربر

استثنای تعریف‌شده توسط کاربر به هر کلاسی گفته می‌شود که در کد شما تعریف شده باشد و از `System.Exception` مشتق شده باشد. چنین کلاسی تابع همه‌ی قواعد وراثت کلاس است، اما علاوه بر آن، کامپایلر و محیط اجرای زبان با این کلاس‌ها رفتاری ویژه دارند و اجازه می‌دهند نمونه‌هایشان، همان‌طور که در تمرین `exceptions` توضیح داده شد، بیرون از جریان عادی کنترل پرتاب و گرفته شوند.

از استثناهای تعریف‌شده توسط کاربر اغلب برای حمل اطلاعات بیشتری، مانند یک پیام و سایر داده‌های مرتبط، استفاده می‌شود تا در اختیار روال‌هایی که استثنا را می‌گیرند قرار بگیرد.
