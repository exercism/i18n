# درباره

[کلاس‌ها](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) ساختار اصلی برای برنامه‌نویسی شیءگرا در F# هستند.

یک کلاس در F# از فیلدها و متدهایش تشکیل شده است. به فیلدها و متدهای یک کلاس، _اعضای_ آن می‌گویند.

کلاس‌ها در F# با کلیدواژه‌ی `type` تعریف می‌شوند. متدها با کلیدواژه‌ی `member` تعریف می‌شوند و همیشه عمومی هستند. برای تعریف فیلدهای (خصوصی) می‌توان از اتصال‌های `let` استفاده کرد.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

کلاس‌ها قالب‌هایی برای ساختن شیء هستند. برای ساختن یک نمونه از یک کلاس، نام کلاس را مانند یک تابع فراخوانی کنید. به یک نمونه از یک کلاس، _شیء_ هم می‌گویند.

با نشانه‌گذاری نقطه‌ای می‌توان به اعضای یک شیء دسترسی داشت.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
