# دستورالعمل

در این تمرین با خطوط لاگ کار می‌کنید.

هر خط لاگ رشته‌ای است که به این شکل قالب‌بندی می‌شود: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه وظیفه دارید که هرکدام یک خط لاگ می‌گیرند و از شما می‌خواهند کاری روی آن انجام دهید.

می‌توانید آزادانه از توابع قدیمی R پایه یا از کتابخانه‌ی `stringr` استفاده کنید؛ هر دو می‌توانند راه‌حل‌های کوتاه و کارآمدی ارائه دهند.

## 1. دریافت پیام از یک خط لاگ

تابع `message` را طوری پیاده‌سازی کنید که پیام یک خط لاگ را برگرداند:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

فاصله‌های سفید ابتدایی و انتهایی باید حذف شوند:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. دریافت سطح لاگ از یک خط لاگ

تابع `log_level` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. قالب‌بندی مجدد یک خط لاگ

تابع `reformat` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند، به این صورت که اول پیام را می‌آورد و بعد از آن سطح لاگ را داخل پرانتز قرار می‌دهد:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
