# نصب

## نصب Node.js

**کاربران ویندوز و OS X**: [Node.js][node] را [از طریق مدیر بسته][node-download] نصب کنید.

**کاربران لینوکس**: [Node.js][node] را طبق دستورالعمل‌هایی که برای توزیع‌تان در [مدیر بسته‌ی Node.js][linstall] آمده است نصب کنید.

## نصب `jasmine-node` و `coffeescript`

برای بیشتر کاربران، اجرای دستور زیر کافی است:

```bash
$ npm install -g jasmine-node coffeescript
```

بسته به تنظیمات شما، ممکن است برای نصب سراسری یک ماژول `npm` به دسترسی کاربر ریشه نیاز داشته باشید.
اگر از نصب‌کننده‌ی رسمی لینک‌شده در بالا استفاده کرده‌اید، همین وضعیت پیش می‌آید.
اگر NPM خطایی بدهد مبنی بر اینکه دسترسی ندارید، `sudo` را به دستور بالا اضافه کنید:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

اگر از نصب‌کننده‌ی رسمی استفاده کرده‌اید، `PATH` شما باید به‌طور خودکار تنظیم شده باشد؛ اما اگر شل شما در پیدا کردن ماژول‌های نصب‌شده‌ی سراسری مشکل دارد، یا اگر Node.js را از سورس می‌سازید، در این صورت `PATH` خود را با افزودن موارد زیر به `~/.bash_profile` یا `~/.zshrc` به‌روزرسانی کنید تا شامل باینری‌های `npm` شود:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
