# دستورالعمل‌ها

الین دارد روی یک بازی کودکانه‌ی جدید کار می‌کند که در آن حیوانات و عصاهای جادویی حضور دارند.
وقت آن رسیده که توابعی برای انداختن تاس، تولید انرژی تصادفی عصا و به‌هم‌زدن یک برش بنویسیم.

## 1. انداختن تاس

یک تابع `RollADie` پیاده‌سازی کنید.

این همان تاس سنتی بیست‌وجهی با اعداد ۱ تا ۲۰ است.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. تولید انرژی عصا

یک تابع `GenerateWandEnergy` پیاده‌سازی کنید.
انرژی عصا باید یک عدد اعشاری تصادفی بزرگ‌تر یا مساوی ۰.۰ و کوچک‌تر از ۱۲.۰ باشد.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. به‌هم‌زدن یک برش

این بازی هشت حیوان مختلف دارد:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

تابعی به اسم `ShuffleAnimals` بنویسید که برشی شامل این هشت حیوان را به ترتیب تصادفی برمی‌گرداند.
