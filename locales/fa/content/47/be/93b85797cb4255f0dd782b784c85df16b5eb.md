# استفاده از هدر تابع

[comment]: # (این خطا زمانی رخ می‌دهد که راه‌حل از هدر تابع استفاده کند)

«هدر تابع» (تعریف تابع بدون بدنه) فقط برای توابعی لازم است که آرگومان‌های پیش‌فرض دارند و چند بند دارند.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

برای توابعی که آرگومان‌های پیش‌فرض دارند و فقط یک بند دارند، می‌توان آرگومان‌های پیش‌فرض را مستقیماً در همان بند مشخص کرد.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

تابع `two_fer/1` فقط به یک بند نیاز دارد، پس به هدر تابع نیازی ندارد.
