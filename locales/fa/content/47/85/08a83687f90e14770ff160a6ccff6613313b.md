# تاپل

«تاپل» روشی سبک برای گروه‌بندی مجموعه‌ای ثابت از داده‌هایی با انواع دلخواه در کنار هم است. تاپل اسم خاصی ندارد؛ اگر برای یک ساختار داده اسم بگذارید، به یک `struct` تبدیل می‌شود. فیلدهای تاپل اسم ندارند؛ دسترسی به آن‌ها از طریق تجزیه‌ی ساختار یا بر اساس موقعیت انجام می‌شود.

## نحوه‌ی نگارش

تاپل‌ها فهرستی از فیلدها هستند که درون پرانتز قرار می‌گیرند:

- `()` همان `unit type` است که یک [حالت خاص](https://doc.rust-lang.org/std/primitive.unit.html) به شمار می‌رود
- **(** _عبارت_ **,)** یک عبارت تاپل تک‌عنصری است
- **(** _نوع_ **,)** یک نوع تاپل تک‌عنصری است
- **(** _عبارت_ **,** ... **)** یک عبارت تاپل عمومی است
- **(** _نوع_ **,** ... **)** یک نوع تاپل عمومی است

### ایجاد

تاپل‌ها همیشه با یک عبارت تاپل ایجاد می‌شوند:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

تاپل‌ها می‌توانند هر تعداد عنصری داشته باشند.

### دسترسی با تجزیه‌ی ساختار

می‌توان به عناصر یک تاپل با تجزیه‌ی ساختار دسترسی داشت. این کار فقط یعنی اختصاص دادن اسم متغیر به هر یک از عناصر تاپل، و آن را مصرف می‌کند.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### دسترسی بر اساس موقعیت

همچنین می‌توان به عناصر یک تاپل با اندیس موقعیتی عددی دسترسی داشت. اندیس‌گذاری، مثل همیشه، از ۰ شروع می‌شود.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## ساختارهای تاپلی

از شما خواسته می‌شود با ساختارهای تاپلی هم کار کنید. این‌ها مثل ساختارهای معمولی، انواع نام‌دار هستند؛ برخلاف ساختارهای معمولی، فیلدهایشان بی‌نام است. نحوه‌ی نگارش آن‌ها بسیار شبیه نحوه‌ی نگارش تاپل معمولی است. استفاده از هر دو روش تجزیه‌ی ساختار و دسترسی موقعیتی مجاز است.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### قابلیت مشاهده‌ی فیلدها

همه‌ی فیلدهای تاپل‌های بی‌نام همیشه عمومی هستند. اما فیلدهای ساختارهای تاپلی قابلیت مشاهده‌ی جداگانه دارند که به‌طور پیش‌فرض خصوصی است، درست مثل فیلدهای ساختارهای استاندارد. می‌توانید فیلدها را با اصلاح‌کننده‌ی `pub` عمومی کنید، درست مثل یک ساختار استاندارد.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
