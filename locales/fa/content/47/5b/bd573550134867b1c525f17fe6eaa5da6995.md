# پیوست دستورالعمل‌ها

## نکته‌ها

شما باید تابع زیر را پیاده‌سازی کنید

```haskell
value :: (Color, Color) -> Int
```

که فقط دو رنگ را می‌پذیرد و مؤلفه‌ی مقدار عددی مقاومت آن را تولید می‌کند.

**امتیاز - تست ویژگی:**

این تمرین فرصت خوبی است برای نوشتن [تست‌های ویژگی](https://en.wikipedia.org/wiki/Property_testing). اگر تا حالا هیچ‌کدام را ننوشته‌اید، چند منبع هم در ادامه آمده است:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

ما یک نمونه تست ویژگی QuickCheck در فایل تست قرار داده‌ایم.

مثال‌هایی از ویژگی‌هایی که می‌توان تست کرد:

- `value (x, y) >= 10` برای همه‌ی `(x, y)` که `x` برابر `Black` نیست

- فراخوانی `show` روی `value (x, y)` رشته‌ای را تولید می‌کند که از `reverse` کردن خروجی `show` روی `value (y, x)` به دست می‌آید.

- همه‌ی رنگ‌ها اسم‌های یکتا دارند. (برای هر دو رنگ، اگر رنگ‌ها متفاوت باشند، اسم‌هایشان هم متفاوت است.)
