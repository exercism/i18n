# راهنمایی‌ها

## 1. تعریف محدوده‌ی `rank` و `file`

- یک [عملگر][swift-range-docs] برای ساختن محدوده وجود دارد که هم برای رشته‌ها و هم برای اعداد صحیح به کار می‌رود.

## 2. بررسی معتبر بودن یک خانه

- یک [متد][contains-docs] وجود دارد که بررسی می‌کند آیا یک مقدار درون یک محدوده قرار دارد یا نه.

## 3. گرفتن سطر

- طول هر سطر باید ۸ باشد.
- برای هر سطر، با شروع از ۱، باید ابتدا و انتهای آن را به اندازه‌ی ۸ واحد جابه‌جا کنید.
- می‌توانید از یک محدوده برای گرفتن زیرآرایه‌ای از آرایه استفاده کنید.
