# نصب

نسخه‌ی فعلی elm، 0.19.1 است.
دستورالعمل‌های نصب با تحول زبان تغییر می‌کنند.
برای دستورالعمل‌های نصب به‌روز، به
[دستورالعمل‌های نصب راهنمای elm][elm-install] مراجعه کنید.

[elm-install]: https://guide.elm-lang.org/install/elm.html

## ابزارهای تکمیلی

**elm-test**

ابزاری که برای اجرای تست‌ها از خط فرمان استفاده می‌شود، elm-test نام دارد.
در حال حاضر elm-test به Node.js و npm نیاز دارد، پس اگر هنوز این کار را نکرده‌اید،
لطفاً ابتدا [Node.js و npm را نصب کنید][npm-install].
وقتی npm را نصب کردید، می‌توانید elm-test را با این دستور نصب کنید:

```shell
npm install --global elm-test@latest-0.19.1
```

اطلاعات بیشتر در [صفحه‌ی اصلی npm مربوط به elm-test][elm-test] موجود است.

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

بیشتر برنامه‌نویسان elm از elm-format برای قالب‌بندی کد elm خود استفاده می‌کنند.
این یک ابزار قالب‌بندی کد بدون نیاز به تنظیمات است.
اگر به ابزارهای قالب‌بندی خودکار عادت ندارید، ممکن است در ابتدا کمی کلافه‌کننده به نظر برسد،
اما وقتی به آن عادت کنید،
کم‌کم از خودتان می‌پرسید قبلاً چطور بدون آن کد می‌نوشتید.
می‌توان آن را با npm هم نصب کرد:

```shell
npm install --global elm-format@latest-0.19.1
```

اطلاعات بیشتر در [صفحه‌ی اصلی elm-format در GitHub][elm-format] موجود است.

[elm-format]: https://github.com/avh4/elm-format

**ویرایشگر متن**

پشتیبانی از Elm حداقل در [IntelliJ][intellij] خوب است و در ویرایشگرهای متنی سازگار با [سرور زبان elm][els] مانند VS Code، Sublime Text یا Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## خطاهای دسترسی با npm

ممکن است هنگام نصب elm-test یا elm-format با خطای دسترسی EACCESS مربوط به npm روبه‌رو شوید.
اگر چنین بود، لطفاً دستورالعمل‌های موجود در وب‌سایت npm را دنبال کنید.
[رفع خطاهای دسترسی EACCES هنگام نصب سراسری بسته‌ها][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
