# کمک

## نصب Rust

برای نصب Rust و منابع یادگیری، به [صفحه‌ی راهنمای Exercism][help-page] مراجعه کنید.

## ارسال راه‌حل

معمولاً باید همه‌ی فایل‌هایی را که راه‌حل خود را در آن‌ها پیاده‌سازی کرده‌اید ارسال کنید (در بیشتر موارد `src/lib.rs`). اگر از crateهای خارجی استفاده می‌کنید، بهتر است فایل `Cargo.toml` را هم ارسال کنید. این کار فرایند بررسی را سریع‌تر و شفاف‌تر می‌کند.

## بازخورد، مشکلات و Pull Request

به [فروم](https://forum.exercism.org/c/programming/rust/) بروید و پستی بنویسید تا بازخورد خود را درباره‌ی یک تمرین بدهید یا اگر می‌خواهید به پیاده‌سازی تمرین‌های جدید کمک کنید.
اعضای تیم مسیر Rust با کمال میل به شما کمک می‌کنند!

[مخزن مسیر][github] در GitHub میزبان همه‌ی تمرین‌های Rust است.

اگر می‌خواهید بیشتر درباره‌ی Exercism بدانید، نگاهی به [راهنمای مشارکت] بیندازید.

## ارسال راه‌حل‌های ناتمام
می‌توانید یک راه‌حل ناتمام ارسال کنید تا ببینید دیگران چگونه تمرین را کامل کرده‌اند.
