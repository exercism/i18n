# دستورالعمل‌ها

جِن در اتاق مرتب‌سازی یک کارخانه‌ی بزرگ کار می‌کند.
اتاق مرتب‌سازی باید هر چه را که واردش می‌شود پردازش کند و آن را با یک برچسب دسته‌بندی کند.
جِن مسئول مواردی است که از پیش به عنوان عدد دسته‌بندی شده‌اند. او به برنامه‌ای نیاز دارد که در مرتب‌سازی کمکش کند.

بیشتر مقادیر اولیه باید برچسب‌های سرراستی بگیرند.
برای اعداد، او رشته‌هایی می‌خواهد که بگویند `"This is the number 2.0"` (اگر عدد ۲ بود).
جِن برای اعداد صحیح و اعداد اعشاری همین خروجی را می‌خواهد.

چند رابط `Box` وجود دارد که باید بازگشایی شوند تا محتوایشان به دست بیاید.
برای یک `NumberBox`، او رشته‌هایی می‌خواهد که بگویند `"This is a box containing the number 3.0"` (اگر متد `Number()` مقدار ۳ را برگرداند).
برای یک `FancyNumberBox`، او رشته‌هایی می‌خواهد که بگویند `"This is a fancy box containing the number 4.0"`، اما فقط اگر نوع آن `FancyNumber` باشد.

هر مورد غیرمنتظره‌ای باید بگوید `"Return to sender"` تا جِن بتواند آن‌ها را به همان جایی که از آن آمده‌اند پس بفرستد.

## 1. توصیف اعداد ساده

جِن می‌خواهد اعداد رشته‌هایی مانند `"This is the number 2.0"` برگردانند (با یک رقم پس از ممیز):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. توصیف یک جعبه‌ی عدد

جِن می‌خواهد جعبه‌های عدد رشته‌هایی مانند `"This is a box containing the number 2.0"` برگردانند (باز هم با یک رقم پس از ممیز):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. پیاده‌سازی متدی که عدد را از یک جعبه‌ی عدد تجملی بیرون می‌کشد

جِن به یک تابع کمکی نیاز دارد که عدد را از یک `FancyNumberBox` بیرون بکشد.
اگر `FancyNumberBox` از نوع `FancyNumber` باشد، مقدارش را استخراج کنید و آن را از `string` به `int` تبدیل کنید.
هر نوع دیگری از `FancyNumberBox` باید ۰ را برگرداند.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. توصیف یک جعبه‌ی عدد تجملی

اگر `FancyNumberBox` از نوع `FancyNumber` باشد، جِن رشته‌هایی می‌خواهد که بگویند `"This is a fancy box containing the number 4.0"`.
هر نوع دیگری از `FancyNumberBox` باید بگوید `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

توجه: باید از تابع `ExtractFancyNumber` استفاده کنیم!

## 5. پیاده‌سازی `DescribeAnything` که از همه‌ی آن‌ها استفاده می‌کند

این همان تابع اصلی است که جِن نیاز دارد و هر ورودی‌ای را می‌پذیرد.
`DescribeAnything` باید بر اساس نوع مقداری که به آن داده می‌شود، کار را به توابع دیگر واگذار کند.
به طور مشخص:

- `int` و `float64` هر دو باید به `DescribeNumber` واگذار کنند
- `NumberBox` باید به `DescribeNumberBox` واگذار کند
- `FancyNumberBox` باید به `DescribeFancyNumberBox` واگذار کند
- در غیر این صورت باید `"Return to sender"` برگردانده شود

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
