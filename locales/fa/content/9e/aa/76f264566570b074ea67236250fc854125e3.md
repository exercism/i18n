# راهنما

اگر در حل مسئله به مشکل خوردید، برای گرفتن کمک می‌توانید از یکی از منابع زیر استفاده کنید:

- [ClojureScript API](http://cljs.github.io/api/) مستند رسمی API.
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet)، یک برگه‌ی تقلب رسمی.
- [/r/clojurescript](https://www.reddit.com/r/clojurescript) ساب‌ردیت C# است.
- از [StackOverflow](http://stackoverflow.com/questions/tagged/clojurescript) می‌توانید برای جست‌وجوی مشکلتان و دیدن اینکه آیا پیش‌تر به آن پاسخ داده شده است استفاده کنید. همچنین می‌توانید پرسش بپرسید و به پرسش‌ها پاسخ دهید.
