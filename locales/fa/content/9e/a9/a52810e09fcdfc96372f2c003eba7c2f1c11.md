# راهنمایی‌ها

## 1. فهرستی از اسم عنصرها را برگردانید

- از تابع [`iterator.map`][map] می‌توان برای تبدیل عنصرهای یک تکرارگر استفاده کرد.

## 2. هر عنصری را که ارزان است برگردانید

- از تابع [`iterator.filter`][filter] می‌توان برای حذف برخی از عنصرها از یک تکرارگر استفاده کرد.

## 3. هر عنصری را که ناموجود است برگردانید

- از تابع [`iterator.filter`][filter] می‌توان برای حذف برخی از عنصرها از یک تکرارگر استفاده کرد.

## 4. مجموع موجودی را برگردانید

- از تابع [`iterator.fold`][fold] می‌توان برای کاهش دادن یک تکرارگر به یک مقدار واحد استفاده کرد.

[map]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#map
[filter]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#filter
[fold]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#fold
