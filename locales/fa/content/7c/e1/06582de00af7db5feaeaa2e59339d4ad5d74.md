# مقدمه

با اینکه می‌توان از عبارت‌های `if/else` برای اجرای منطق شرطی استفاده کرد، Haskell راه قدرتمندتری هم برای این کار دارد: [«تطبیق الگو»][pattern-matching].
با تطبیق الگو می‌توان یک مقدار را در برابر یک یا چند _الگو_ آزمود.
یک نمونه از چنین الگویی _الگوی ثابت_ است که یک مقدار را با یک ثابت مطابقت می‌دهد (مثلاً `1` یا `"hello"`).

هنگام تعریف توابع می‌توانید برای الگوهای مختلف، بدنه‌های تابع جداگانه تعریف کنید.
این کار به نوشتن code تمیز، ساده و خوانا می‌انجامد.
می‌توانید روی هر نوع داده‌ای تطبیق الگو انجام دهید: اعداد، کاراکترها، لیست‌ها، تاپل‌ها و غیره.

برای مثال، یک تابع ساده که یک عدد صحیح (`Int`) می‌گیرد و آن را _۱_ واحد به _۰_ نزدیک‌تر می‌کند، می‌تواند این‌گونه بیان شود:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

تطبیق الگو وقتی همراه با الگوهای دیگر به کار می‌رود، بهتر می‌درخشد؛ برای نمونه _الگوی متغیر_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

مثال بالا همه‌ی ورودی‌های غیر از _۰_ را یکسان در نظر می‌گیرد و برای اعداد منفی نتیجه‌ی نادرست به دست می‌دهد.
این مشکل را می‌توان با الگوهای شرطی حل کرد که به _گارد_ معروف‌اند و با نماد `|` بیان می‌شوند:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

در مثال‌های بالا، همه‌ی ورودی‌های ممکن الگوی منطبق ندارند.
کامپایلر این موضوع را تشخیص می‌دهد و هشداری نمایش می‌دهد.
این یکی از ویژگی‌های بسیار مفید Haskell است که به تضمین پوشش همه‌ی مسیرهای ممکن کمک می‌کند تا از بروز خطاهای زمان اجرا جلوگیری شود.
به این کار _بررسی جامع_ می‌گویند.
برای رفع این هشدار، باید همه‌ی حالت‌ها را مدیریت کنید.
در _گارد_ها می‌توانید از عبارت `otherwise` به‌عنوان کوتاه‌نویسی برای `True` استفاده کنید تا همه‌ی الگوهای باقی‌مانده را بگیرید.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

تطبیق الگو یک مقدار را از بالا به پایین با هر الگو می‌آزماید تا الگویی منطبق پیدا کند و منطق مربوط به آن الگو را اجرا کند.
**ترتیب الگوها مهم است!**
