# درباره

«الحاق ایستا» به شما امکان می‌دهد نوع‌های موجود را بدون تغییر در منبع‌شان به‌شکل شبه‌گسترش گسترش دهید. این کار با استفاده از دستور `using` انجام می‌شود. الحاق‌های ایستا می‌توانند ابزاری قدرتمند باشند که امکان افزودن قابلیت به نوع‌ها را بدون تغییر واقعی آن‌ها فراهم می‌کنند.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
