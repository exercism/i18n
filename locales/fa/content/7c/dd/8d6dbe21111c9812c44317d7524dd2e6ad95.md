# درباره

## اختیاری

سوئیفت از [_اختیاری‌ها_][optionals] استفاده می‌کند تا برنامه‌نویسان بتوانند نبود احتمالی یک مقدار را نشان دهند.
اختیاری نوعی است که می‌تواند یا مقداری را در خود نگه دارد یا `nil` باشد؛ `nil` نشان‌دهنده‌ی نبود یک مقدار است.
استفاده از یک نوع اختیاری ایجاب می‌کند که برنامه پیش از استفاده از مقدار، پس از باز کردن آن، بررسی کند که آیا مقداری وجود دارد یا نه.

هر نوعی را می‌توان با افزودن یک `?` به انتهای اسم نوع، به یک اختیاری تبدیل کرد.
بنابراین یک عدد صحیح اختیاری نوع `Int?` خواهد داشت و یک رشته‌ی اختیاری نوع `String?`.
تعریف ثابت‌ها یا متغیرهای اختیاری و مقداردهی به آن‌ها همانند مقادیر غیراختیاری انجام می‌شود.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

شما می‌توانید با نسبت دادن مقدار ویژه‌ی `nil` به یک متغیر از نوع اختیاری، نبود یک مقدار را به آن نسبت دهید.
`nil` را می‌توان با همه‌ی انواع اختیاری به کار برد، اما `nil`هایی که به دو نوع اختیاری متفاوت نسبت داده می‌شوند نوع یکسانی ندارند و نمی‌توان آن‌ها را با هم جابه‌جا کرد یا حتی مقایسه کرد.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

همچنین توجه کنید که با آن‌که `nil` را می‌توان به هر نوع اختیاری نسبت داد، نمی‌توان آن را به یک نوع غیراختیاری نسبت داد (حتی اگر آن نوع در واقع `nil` را در خود نگه ندارد).
و متدهایی که انتظار یک نوع غیراختیاری را دارند، نمی‌توان بدون باز کردن آن، یک نوع اختیاری را به آن‌ها پاس داد.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## استفاده از اختیاری‌ها

از آنجا که انواع اختیاری همان نوع پایه‌ی خودشان نیستند، نمی‌توان از این دو نوع به یک شکل استفاده کرد.
برای مثال: `Int("123") + 1` به خطای کامپایلر «Value of optional type 'Int?' must be unwrapped to a value of type 'Int'» منجر می‌شود.
دلیل این امر آن است که `Int("123")` یک نوع اختیاری `Int?` برمی‌گرداند، نه یک نوع `Int`؛ زیرا اگر رشته نتواند به یک عدد صحیح تبدیل شود، نتیجه `nil` خواهد بود.
برای دسترسی به `Int` حاصل از تبدیل، ابتدا باید آن را «باز» کرد.

این کار معمولاً در سوئیفت با ساختارهای `if-let` و `guard-let` برای [_اتصال اختیاری_][optional-binding] انجام می‌شود، که `nil` را بررسی می‌کنند و اگر مقداری وجود داشته باشد، مسیری از کد را با مقدار بازشده که به یک اسم داده‌شده مقید شده است در پیش می‌گیرند، و اگر `nil` یافت شود، مسیر دیگری از کد را طی می‌کنند.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

شایان ذکر است که متغیر `safeNum` نوع `Int` دارد و نه `Int?`.
در مثال زیر، `num` از نوع `Int?` است و `safeNum` از نوع `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

این _اتصال اختیاری_ مهم است، زیرا نوع اختیاری را از مقدار باز (یا «حذف») می‌کند و به آن امکان می‌دهد به عنوان یک مقدار غیراختیاری به کار رود.
اگر تنها یک بررسی شرطی انجام دهید که آیا مقدار `nil` است یا نه، مقدار همچنان از نوع اختیاری خواهد بود:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

گزینه‌ی `guard-let` را نیز می‌توان در مواردی به کار برد که بازگشت زودهنگام مطلوب است:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## مقایسه‌ی اختیاری‌ها

توجه کنید که حتی اگر نوع پایه‌ی یک جفت اختیاری را بتوان با عملگرهای استاندارد مقایسه، مقایسه کرد، خود اختیاری‌ها را نمی‌توان مقایسه کرد.
آن‌ها را فقط می‌توان از نظر برابری بررسی کرد.
دو اختیاری برابرند اگر هر دو `nil` باشند یا اگر مقادیری که در خود می‌پیچند، در نوع پایه‌ی‌شان برابر باشند.

با این حال، می‌توان کدی نوشت که مقایسه‌ای سفارشی میان دو مقدار اختیاری انجام دهد.
در زیر نمونه‌ای از یک دستور `switch` آمده است که تنها در صورتی `true` را برمی‌گرداند که هر دو مقدار اختیاری `nil` نباشند و مقدار اول کمتر از دومی باشد.
برای این کار از _الگوی اختیاری_ `varName?` استفاده می‌کند که تنها با اختیاری‌هایی مطابقت می‌کند که `nil` نیستند و مقدار درون اختیاری را به اسم `varName` مقید می‌کند.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
