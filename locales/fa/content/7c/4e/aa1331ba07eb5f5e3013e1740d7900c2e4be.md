# درباره

C# یک زبان با نوع‌دهی ایستا است؛ یعنی همه‌چیز در زمان کامپایل نوع دارد. انتخاب یک اسم برای [متغیر][variable] را «تعریف متغیر» می‌گویند. وقتی یک متغیر تعریف شد، تنظیم یا به‌روزرسانی مقدار آن را «تخصیص متغیر» می‌نامند. متغیر را می‌توان یا با مشخص‌کردن صریح نوع آن تعریف کرد، یا با استفاده از [کلیدواژه‌ی `var`][var] تا کامپایلر C# نوع آن را بر اساس مقدار تخصیص‌یافته استنتاج کند. استفاده از `var` با نام _استنتاج نوع_ شناخته می‌شود.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

مقدار یک متغیر را می‌توان با [عملگر `=`][assignment] تخصیص داد و به‌روزرسانی کرد. پس از تعریف، نوع متغیر هرگز تغییر نمی‌کند.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# زبانی شیءگراست و لازم می‌داند که همه‌ی [توابع][function] در یک _کلاس_ تعریف شوند؛ کلاس‌ها با [کلیدواژه‌ی `class`][classes] تعریف می‌شوند. شیءها (یا _نمونه‌ها_) با استفاده از کلیدواژه‌ی `new` ساخته می‌شوند.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

به تابعی که داخل یک کلاس قرار دارد، _متد_ می‌گویند. هر [متد][methods] می‌تواند صفر یا چند پارامتر داشته باشد. نوع همه‌ی پارامترها باید صریحاً مشخص شود؛ برای پارامترها استنتاج نوع وجود ندارد. به همین ترتیب، نوع بازگشتی هم باید صریحاً مشخص شود. مقدارها با استفاده از [کلیدواژه‌ی `return`][return] از متد بازگردانده می‌شوند. برای اینکه کد موجود در فایل‌های دیگر بتواند یک متد را فراخوانی کند، باید اصلاح‌کننده‌ی دسترسی `public` را اضافه کرد.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

متدها با نحوه‌ی نگارش نقطه‌ای (`.`) روی یک نمونه فراخوانی می‌شوند؛ به این صورت که اسم متد موردنظر مشخص و برای هرکدام از پارامترهای متد آرگومان ارسال می‌شود. آرگومان‌ها می‌توانند به‌صورت اختیاری اسم پارامتر متناظر را مشخص کنند.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

اگر متدی که قرار است فراخوانی شود، در همان کلاسی تعریف شده باشد که متد فراخوانی‌کننده در آن قرار دارد، می‌توان اسم کلاس را حذف کرد.

اگر متدی از هیچ _وضعیتی_ از شیء استفاده نکند، می‌توان آن متد را با اصلاح‌کننده‌ی `static` به حالت _ایستا_ درآورد. متدهای ایستا هم با نحوه‌ی نگارش نقطه‌ای (`.`) فراخوانی می‌شوند، اما روی خود کلاس فراخوانی می‌شوند، نه روی نمونه‌ای از کلاس.

اگر کلاسی فقط متدهای ایستا داشته باشد، خود آن هم می‌تواند با اصلاح‌کننده‌ی `static` ایستا شود. این کار قصد و نیت کلاس را بیان می‌کند.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

دامنه در C# بین کاراکترهای `{` و `}` تعریف می‌شود.

C# از دو نوع [کامنت][comments] پشتیبانی می‌کند. کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.

مقدارهای صحیح به‌صورت یک یا چند رقم (پشت‌سرهم) تعریف می‌شوند و از [عملگرهای ریاضی پیش‌فرض][operators] پشتیبانی می‌کنند.

اسم متغیر [باید از قوانینی پیروی کند][identifier-names]؛ مثلاً با یک حرف یا زیرخط شروع شود، و [بهتر است از قواعد نام‌گذاری C# پیروی کند][naming-guidelines]. اگر اسم متغیری با یک [کلیدواژه‌ی C#][csharp-keywords] رزروشده تداخل داشته باشد، باید با `@` escape شود. استفاده از این نگارش توصیه نمی‌شود، اما در موارد استثنایی ممکن است با آن برخورد کنید؛ برای مثال: `var @this`، `var @class` یا `var @var`.

چند مفهوم آنقدر برای زبانی از خانواده‌ی C مانند C# بنیادی هستند که به‌طور طبیعی در تقریباً هر قطعه کد غیرساده‌ای پدیدار می‌شوند. این دو مفهوم، [جهش][mutation] و [دامنه][scope] هستند. جهش این ایده است که مقدار یک متغیر می‌تواند در طول عمر یک برنامه تغییر کند. دامنه این ایده است که مقدار مرتبط با یک اسم (از یک عنصر برنامه) فقط درون «ناحیه‌ی» کدی که در آن تعریف شده است قابل دسترسی است. ناحیه‌های اصلی کد در C# عبارت‌اند از _کلاس/ساختار_ و _تابع_ (معمولاً متدها)، اما می‌توانند بدنه‌ی حلقه‌ها و دیگر ساختارها را هم در بر بگیرند.
