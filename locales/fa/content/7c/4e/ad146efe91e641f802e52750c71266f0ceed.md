# برای نگه‌دارندگان

## تولید testها: `bin/generate_tests.py`

فایل‌های test از داده‌های استاندارد در [exercism/problem-specifications](https://github.com/exercism/problem-specifications) و با استفاده از قالب Jinja که در هر تمرین در `.meta/template.j2` ذخیره شده است تولید می‌شوند.

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

این اسکریپت problem-specifications را از حافظه‌ی نهان configlet می‌خواند (`~/.cache/exercism/configlet/problem-specifications` که با `bin/configlet sync` پر می‌شود)، یا از پوشه‌ی والدی با اسم `problem-specifications`.
فقط مواردی که در `.meta/tests.toml` آمده‌اند تولید می‌شوند.

رشته‌های متنی Fortran نمی‌توانند نویسه‌های فراری مانند `\n` و `\t` را در خود داشته باشند.
فیلتر قالب `escape_quote_whitespace` این‌ها را به `" // NEWLINE // "`، `" // TAB // "` و `" // CARRIAGE_RETURN // "` بازنویسی می‌کند، بنابراین قالب باید این ثابت‌ها را تعریف کند (به `exercises/practice/bob/.meta/template.j2` نگاه کنید).

### پیش‌نیازها

- CMake و کامپایلر Fortran آماده‌ی کار
- Python ۳.۱۲+ همراه با `jinja2`
- git

### روند کار برای افزودن یک تمرین تازه

با `bob` به‌عنوان مثال:

- یک شاخه‌ی جدید بسازید، مثلاً `git checkout -b exercise-bob`
- دستور `bin/add-exercise bob` را اجرا کنید (به `jq` و `curl` نیاز دارد). این دستور:
  - configlet را می‌گیرد و `configlet create` را اجرا می‌کند، که تمرین را به `config.json` اضافه می‌کند و مستندات، فراداده و `tests.toml` آن را از problem-specifications همگام می‌کند
  - `config.json` را با `bin/reorder-exercises` مرتب می‌کند
  - فایل `exercises/shared/CMakeLists.txt` را در پوشه‌ی تمرین کپی می‌کند
  - یک راه‌حل اسکلتی، یک `.meta/example.f90` اسکلتی و یک `.meta/template.j2` آغازین می‌نویسد (از `exercises/shared/template.j2`)

  مگر اینکه `-a <username>` را بدهید، اسم کاربری GitHub شما را می‌پرسد، و مگر اینکه `-d <difficulty>` را بدهید، سختی را ۱ می‌گذارد.

- فایل `.meta/template.j2` را ویرایش کنید تا هر مورد تابع درست را با ورودی‌های درست فراخوانی کند، سپس testها را تولید کنید:

  ```bash
  bin/generate_tests.py bob
  ```

- یک راه‌حل کارآمد در `.meta/example.f90` بنویسید. فایل دانش‌آموز (مثلاً `bob.f90`) را با اسکلتی از توابع یا زیرروال‌هایی که testها فراخوانی می‌کنند جایگزین کنید تا شروع کار برای دانش‌آموز آسان‌تر شود
- مطمئن شوید همه‌ی testها قبول می‌شوند و ساخت کامل را از ریشه‌ی مخزن اجرا کنید:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- دستورهای `bin/reorder-exercises` و `bin/configlet lint` را اجرا کنید
- اگر همه‌چیز قبول شد، با تغییرات خود یک pull request باز کنید

### تغییر دادن `CMakeLists.txt`

وقتی فایل cmake را تغییر می‌دهید، نسخه‌ی اصلی را در `exercises/shared/` به‌روزرسانی کنید و با `bin/update-cmake-files` آن را در همه‌ی پوشه‌های تمرین کپی کنید.
