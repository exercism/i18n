# مقدمه

می‌توان یک پارامتر متد را با دادن یک مقدار پیش‌فرض، «اختیاری» کرد. هنگام فراخوانی متدی که پارامترهای اختیاری دارد، لازم نیست فراخواننده مقداری برای آن‌ها بفرستد. اگر مقداری برای یک پارامتر اختیاری فرستاده نشود، از مقدار پیش‌فرض آن استفاده می‌شود.

پارامترهای اختیاری باید در انتهای فهرست پارامترها بیایند؛ نمی‌توان پس از آن‌ها پارامتر غیراختیاری آورد.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

می‌توان پارامتر اختیاری را با استفاده از عملگر `?` پیش از اسم متغیر، برابر `null` قرار داد:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
