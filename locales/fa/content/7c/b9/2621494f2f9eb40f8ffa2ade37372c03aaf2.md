# دستورالعمل‌ها

لزلی، بیگانه‌ی Lisp، باید خرید کند. داشتن یک لیست خرید بسیار مهم است. باید عناصری را به آن اضافه کرد و عناصری را از آن حذف کرد.

البته قلم و کاغذ ساده برای یک بیگانه‌ی Lisp کافی نیست. حتی «List» بیشتر کلمه‌ی «Lisp» است! باید چند تابع نوشته شود تا به پیگیری خرید کمک کند.

آیا می‌توانید به لزلی در پیگیری لیست خرید کمک کنید؟

## 1. ساخت یک لیست جدید

اولین کار این است که لزلی باید یک لیست خالی ایجاد کند. تابعی به نام `new-list` برای این کار عالی است.

```lisp
(new-list) ; => ()
```

اوه نه... لزلی از قبل چند مورد در ذهن دارد، بنابراین به تابعی نیاز دارد که سه عنصر بگیرد (خوشبختانه لزلی فقط لیستی از سه عنصر می‌سازد. نه بیشتر، نه کمتر!) و یک لیست خرید جدید با آن موارد ایجاد کند. تابعی به نام `list-of-things` بنویسید که سه عنصر می‌گیرد و لیستی از آن‌ها برمی‌گرداند.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. افزودن موارد به لیست

قبل از رفتن به فروشگاه، لزلی در انبار غذا را نگاه می‌کند تا ببیند چه موردی لازم دارد. با نوشتن تابع `add-to-list` به آن‌ها کمک کنید که یک عنصر را به ابتدای لیست اضافه می‌کند.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. موارد بعدی در لیست کدامند؟

هنگام خرید، لزلی می‌خواهد بداند برای بعدی به دنبال چه موردی بگردد. آن‌ها همچنین دوست دارند در لیست جلوتر را ببینند تا عنصر دوم، سوم، یا حتی بیست و سومین (عدد شانس‌شان) را ببینند.

- `first-thing` به اولین عنصر لیست ارزیابی می‌شود
- `second-thing` به عنصر دوم ارزیابی می‌شود
- `third-thing` به عنصر سوم ارزیابی می‌شود
- `twenty-third-thing` به عنصر بیست و سوم ارزیابی می‌شود

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. حذف یک مورد از لیست

لزلی می‌خواهد اولین عنصر لیست را پیدا کند و آن را از قفسه بردارد. با نوشتن تابع `remove-first-item` به آن‌ها کمک کنید. این تابع به لیستی ارزیابی می‌شود که شامل همه‌ی موارد به جز اولین عنصر لیست ورودی است.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. لیست‌های بزرگ‌تر از لیست‌های کوچک‌تر

لزلی متوجه شد که به طور تصادفی دو لیست خرید ساخته است، نه یکی! تابعی به نام `list-append` بنویسید که لیستی را برمی‌گرداند که شامل عناصر لیست اول و سپس عناصر لیست دوم است.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. چقدر طولانی‌تر؟

لزلی نگران شده است که این سفر خرید کمی طول بکشد. فقط چند مورد در این لیست وجود دارد؟ تابعی به نام `just-how-long` بنویسید تا به آن‌ها بگوید لیست‌شان چقدر طولانی است.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
