# ارتقای ویژگی در سازنده

در کلاس‌هایی که ویژگی‌های زیادی اعلام می‌کنند، اعلام جداگانه‌ی کلاس، ویژگی‌های آن و یک سازنده برای تنظیم آن ویژگی‌ها مستلزم تکرار است.
با استفاده از «ارتقای ویژگی در سازنده» می‌توانیم مقدار این تکرار را کاهش دهیم.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
