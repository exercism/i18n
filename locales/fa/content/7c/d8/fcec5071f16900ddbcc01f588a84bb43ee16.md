# دستورالعمل‌ها

در این تمرین قرار است کد بیشتری بنویسید؛ کدی درباره‌ی آماده‌کردن و پختن لازانیای فوق‌العاده‌تان از کتاب آشپزی محبوبتان.

پنج کار در پیش دارید.
کار اول به خود پختن مربوط است و چهار کار دیگر به آماده‌سازی بی‌نقص.

## 1. مشخص کنید لازانیا پخته شده است یا نه

وقتی لازانیا در فر دارید، می‌خواهید بدانید که آیا می‌توانید از همین حالا آن را بیرون بیاورید یا نه.
برای اینکه مطمئن شوید لازانیا در فر نمی‌سوزد، معمولاً تایمر می‌گذارید.
اما گاهی این کار را فراموش می‌کنید.

تابعی به اسم `cookingStatus` بنویسید که زمان باقی‌مانده‌ی تایمر را بر حسب دقیقه به عنوان پارامتر می‌پذیرد.
این تابع سه نتیجه‌ی ممکن دارد.

- اگر تایمر `0` را نشان دهد، باید `'Lasagna is done.'` را برگرداند.
- اگر تایمر هر عدد دیگری را نشان دهد، نتیجه باید `'Not done, please wait.'` باشد.
- اگر تابع بدون مقدار تایمر فراخوانی شود، نتیجه باید `'You forgot to set the timer.'` باشد.

تایمر هرگز مقداری کمتر از ۰ نشان نمی‌دهد.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. زمان آماده‌سازی را تخمین بزنید

برای لازانیای بعدی که آماده می‌کنید، می‌خواهید مطمئن شوید زمان کافی کنار گذاشته‌اید تا از پختن لذت ببرید.
قبلاً نقشه‌ای با همه‌ی لایه‌هایی که لازانیایتان خواهد داشت کشیده‌اید.
حالا می‌خواهید بر اساس آن تخمین بزنید که آماده‌سازی چقدر طول می‌کشد.

تابعی به اسم `preparationTime` پیاده‌سازی کنید که یک آرایه از لایه‌ها و میانگین زمان آماده‌سازی هر لایه را بر حسب دقیقه می‌پذیرد.
تابع باید برآورد کل زمان آماده‌سازی را بر اساس تعداد لایه‌ها برگرداند.
اگر تابع بدون ارائه‌ی میانگین زمان آماده‌سازی فراخوانی شود، به جایش باید `2` دقیقه در نظر گرفته شود.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. مقدار رشته و سس لازم را محاسبه کنید

علاوه بر کنار گذاشتن زمان، می‌خواهید مطمئن شوید سس و رشته‌ی کافی برای پختن لازانیای رؤیایی‌تان دارید.
برای هر لایه‌ی رشته در لازانیایتان به ۵۰ گرم رشته نیاز دارید.
برای هر لایه‌ی سس در لازانیایتان به ۰٫۲ لیتر سس نیاز دارید.

تابعی به اسم `quantities` تعریف کنید که یک آرایه از لایه‌ها را به عنوان پارامتر می‌گیرد.
سپس تابع مقدار رشته و سس لازم برای پختن غذایتان را تعیین می‌کند.
نتیجه باید به صورت یک شیء با کلیدهای `noodles` و `sauce` برگردانده شود.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. ماده‌ی اولیه‌ی مخفی را اضافه کنید

چندی پیش به دیدن دوستی رفتید و آنجا لازانیا خوردید.
فوق‌العاده بود و ویژگی خاصی داشت.
دوستتان فهرست مواد اولیه را برایتان فرستاد و گفت که آخرین مورد در آن فهرست، همان «ماده‌ی اولیه‌ی مخفی» است که غذا را این‌قدر خاص کرده.
حالا می‌خواهید آن ماده‌ی اولیه‌ی مخفی را به دستور پخت خودتان هم اضافه کنید.

تابعی به اسم `addSecretIngredient` بنویسید که دو آرایه از مواد اولیه را به عنوان پارامتر می‌پذیرد.
پارامتر اول فهرستی است که دوستتان برایتان فرستاده و پارامتر دوم فهرست مواد اولیه‌ی دستور پخت خودتان است.
تابع باید آخرین مورد از فهرست دوستتان را به انتهای فهرست شما اضافه کند.
آرایه‌ای که دستور پخت شما را نشان می‌دهد باید مستقیماً تغییر کند و تابع نباید چیزی برگرداند.
با این حال، آرگومان اول نباید تغییر کند.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. دستور پخت را مقیاس‌بندی کنید

مقدارهایی که در کتاب آشپزی‌تان آمده، فقط برای دو وعده لازانیا کافی است.
از آنجا که دفعه‌ی بعد می‌خواهید برای افراد بیشتری بپزید، می‌خواهید مقدارها را برای تعداد وعده‌های مختلف محاسبه کنید.

تابعی به اسم `scaleRecipe` پیاده‌سازی کنید که دو پارامتر می‌گیرد.

- یک شیء دستور پخت که مقدارهای لازم برای ۲ وعده را در خود دارد.
  قالب این شیء را در مثال زیر می‌بینید.
- تعداد وعده‌هایی که می‌خواهید بپزید.

تابع باید یک شیء دستور پخت با مقدارهای لازم برای تعداد وعده‌های مورد نظر برگرداند.
اما می‌خواهید دستور پخت اصلی دست‌نخورده بماند.
یعنی در این کار، آرگومان دستور پخت نباید تغییر کند.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
