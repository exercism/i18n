# دستورالعمل‌ها

در این تمرین، یک سیستم رایانه‌ای مبتنی بر پنجره را شبیه‌سازی می‌کنید.
چند پنجره خواهید ساخت که می‌توان آن‌ها را جابه‌جا کرد و اندازه‌شان را تغییر داد.
تصویر زیر نمونه‌ای از مقادیری است که در ادامه با آن‌ها کار می‌کنید.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. تعریف ویژگی‌های پنجره‌ی برنامه

با استفاده از اسکلت کلاسی که در اختیارتان قرار گرفته، ویژگی‌های مربوط به مقادیر `y`، `x`، `height` و `width` را تعریف کنید.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. تعریف مقادیر اولیه برای پنجره‌ی برنامه

یک تابع سازنده برای `ProgramWindow` تعریف کنید.
این تابع نباید هیچ آرگومانی بگیرد، اما هنگام اجرای سازنده باید مقادیر پیش‌فرض ویژگی‌هایش را تنظیم کند.
باید مقادیر اولیه‌ی `y` و `x` را برابر `0` قرار دهد.
باید مقادیر اولیه‌ی `height` و `width` را برابر اندازه‌ی صفحه‌ی `600x800` قرار دهد.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. تعریف تابعی برای تغییر اندازه‌ی پنجره

یک کلاس جدید در `Size.php` برای کلاس Size تعریف کنید.
این کلاس باید آرگومان‌های سازنده را برای تنظیم ویژگی‌های `height` و `width` بگیرد.
علاوه بر این، `ProgramWindow` به یک تابع تغییر اندازه نیاز دارد که نمونه‌ی شیء `Size` را می‌گیرد و ویژگی‌های خودش را به‌روزرسانی می‌کند.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. تعریف تابعی برای جابه‌جا کردن پنجره

یک کلاس جدید در `Position.php` برای کلاس Position تعریف کنید.
این کلاس باید آرگومان‌های سازنده را برای تنظیم ویژگی‌های `y` و `x` بگیرد.
علاوه بر این، `ProgramWindow` به یک تابع جابه‌جایی نیاز دارد که نمونه‌ی شیء `Position` را می‌گیرد و ویژگی‌های خودش را به‌روزرسانی می‌کند.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
