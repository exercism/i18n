# درباره

در Haxe، `class` ساختار داده‌ی اصلی است که داده (فیلدها) و رفتار (متدها) را در خود کپسوله می‌کند. به فیلدها و متدها، اعضای یک کلاس هم می‌گویند.

می‌توان دسترسی به اعضا را با استفاده از [تغییردهنده‌های دسترسی][visibility] محدود کرد، که عبارت‌اند از:

- `public`: می‌توان از هر جایی به این عضو دسترسی داشت.
- `private`: فقط از داخل همان کلاس می‌توان به این عضو دسترسی داشت.

می‌توان به کلاس‌ها به چشم قالب‌هایی برای ساختن نمونه نگاه کرد. برای ساختن یک [نمونه][class-instance]، کافی است از کلیدواژه‌ی `new` استفاده کنید:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

برای تعریف یک فیلد، از یک تغییردهنده‌ی دسترسی استفاده کنید و بعد از آن، اسم متغیر و نوع آن را بنویسید:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

می‌توانید هنگام تعریف یک فیلد، یک مقدار اولیه هم برایش تعیین کنید. اگر برای فیلدی مقدار اولیه تعیین نشود، مقدارش `null` خواهد بود. می‌توانید با نقطه‌گذاری به یک فیلد دسترسی داشته باشید:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
