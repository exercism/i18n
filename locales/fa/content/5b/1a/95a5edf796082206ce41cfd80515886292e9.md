# مقدمه

Factor یک زبان *الحاقی* است: هر واژه ورودی‌هایش را از یک **پشته‌ی داده**ی مشترک می‌خواند و خروجی‌هایش را دوباره روی همان پشته می‌گذارد. راه دیگری برای جابه‌جا کردن مقدارها وجود ندارد.

نوشتن یک مقدار ثابت، آن را روی بالای پشته می‌گذارد؛ کد از چپ به راست خوانده می‌شود:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

یک اعلان *اثر پشته*، قرارداد یک واژه را مستند می‌کند:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` می‌گوید که این واژه دو مقدار را از پشته برمی‌دارد و دو مقدار را با ترتیب دیگر بر جای می‌گذارد. این نام‌ها صرفاً جنبه‌ی مستندسازی دارند (فقط *تعداد* ورودی‌ها و خروجی‌ها است که کامپایلر بررسی می‌کند) و بالای پشته همان نام سمت راست است.

**واژه‌های جابه‌جایی**ی روزمره‌ی `kernel` ترتیب بالای پشته را عوض می‌کنند:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

واژه‌ها با `:` تعریف می‌شوند و با `;` به پایان می‌رسند؛ کامپایلر تعریفی را که بدنه‌اش با اثر اعلان‌شده همخوانی ندارد نمی‌پذیرد.
