# پیوست دستورالعمل‌ها

## راهنمایی‌ها

در این تمرین، تعریف [نوع داده‌ی جبری](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses) به اسم `Planet` را در اختیار شما گذاشته‌ایم.
شما باید تابع `ageOn` را پیاده‌سازی کنید؛ این تابع سن را بر حسب ثانیه می‌گیرد و محاسبه می‌کند که یک نفر روی یک `Planet` چند ساله می‌شود.

اگر درباره‌ی نوع‌ها مطمئن نیستید، می‌توانید از امضای داده‌شده استفاده کنید، اما نگذارید این امضا خلاقیت شما را محدود کند:

```haskell
ageOn :: Planet -> Float -> Float
```
