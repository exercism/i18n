# مقدمه

Factor تاریخها و زمانها را با واژگان [`calendar`][calendar] مدلسازی می‌کند. یک نقطه در زمان یک `timestamp` است؛ یک بازه‌ی زمانی یک `duration`.

## ساختن یک تاریخ

`<date>` (در [`calendar`][calendar]) یک `timestamp` را در نیمه‌شب روز داده‌شده می‌سازد:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` یک timestamp را دوباره به اجزایش تقسیم می‌کند:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## بررسی یک تاریخ

`day-of-week` روز هفته را به‌صورت یک عدد صحیح برمی‌گرداند، `0` برای یکشنبه تا `6` برای شنبه. `day-names` (در [`calendar.english`][english]) فهرست متناظر اسم‌هاست، بنابراین `day-names nth` عدد را به یک واژه تبدیل می‌کند:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` یک سال (یا یک timestamp) را می‌پذیرد و `days-in-month` طول ماه یک timestamp را برمی‌گرداند، که سال‌های کبیسه را هم در نظر می‌گیرد:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## محاسبات تاریخ

واژه‌هایی مانند `days`، `weeks` و `hours` یک `duration` می‌سازند و `time+` یک timestamp را به اندازه‌ی یکی از آن‌ها جابه‌جا می‌کند:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

محاسبات به‌درستی از مرزهای ماه و سال عبور می‌کند و دو timestamp که یک لحظه‌ی یکسان را نشان می‌دهند با `=` برابر در نظر گرفته می‌شوند.

## زمان‌های روز

`<timestamp>` یک timestamp کامل، تا دقت ثانیه، می‌سازد. آخرین آرگومان آن اختلاف از UTC است؛ `instant` (یک `duration` صفر) timestamp را در UTC نگه می‌دارد:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` همتای `>date<` است و یک timestamp را به ساعت، دقیقه و ثانیه‌ی آن تقسیم می‌کند:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` و `minutes` هم درست مانند `days`، `weeks` و `hours` یک `duration` می‌سازند، بنابراین هر یک از آن‌ها را می‌توان به `time+` سپرد:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

تک‌تک فیلدهای یک timestamp با دسترسی‌گیرهای `year>>`، `month>>`، `day>>`، `hour>>`، `minute>>` و `second>>` خوانده می‌شوند:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
