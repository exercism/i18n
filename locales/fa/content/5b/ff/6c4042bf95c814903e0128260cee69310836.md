# مقدمه

## ثابت‌ها و توابع

یک مقدار ثابت با `name = expression` تعریف می‌شود، با این تفاوت که در Elm همه‌چیز به‌جز تعریف‌ها «عبارت» است.

```elm
five = 5

six = 3 + 3
```

تابع‌ها با `name parameters... = expression` تعریف می‌شوند و پارامترها فقط با فاصله از هم جدا می‌شوند.

```elm
add number1 number2 = number1 + number2
```

فراخوانی یک تابع هم خودش یک عبارت است و با نوشتن اسم تابع و دادن آرگومان برای هر یک از پارامترهای آن انجام می‌شود؛ آرگومان‌ها هم درست مثل تعریف تابع، فقط با فاصله از هم جدا می‌شوند.

```elm
five = add 2 3
```

می‌توان از پرانتز برای تعیین ترتیب ارزیابی یک عبارت استفاده کرد.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## تو رفتگی / فضای خالی معنادار

Elm برای مشخص کردن مرزهای کد از نشانه‌هایی مثل آکولاد، پرانتز یا نقطه‌ویرگول استفاده نمی‌کند. در عوض از فاصله‌های خالی و تو رفتگی بهره می‌گیرد.

- تعریف ماژول، `import` و توابع سطح بالا باید از چپ‌ترین ستون شروع شوند.
- اگر یک عبارت به چند خط تقسیم شود، کدی که بخشی از آن عبارت است باید با حداقل یک فاصله زیر آن عبارت تو رفته باشد.
- بخش‌هایی از عبارت که به هم گروه‌بندی می‌شوند باید با تعداد فاصله‌های برابر تو رفته باشند.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## ماژول‌ها

هر فایل در Elm یک ماژول است و باید پیش از همه‌ی کدهای دیگر یک دستور `module` داشته باشد. اسم ماژول‌ها باید با اسم فایل‌شان یکی باشد؛ بنابراین ماژول `Calculator` باید در فایل `Calculator.elm` باشد. هر چیزی که داخل یک ماژول تعریف شود، فقط در محدوده‌ی همان ماژول قرار دارد و از بیرون این ماژول قابل دسترسی نیست، مگر اینکه در `exposing` فهرست شده باشد.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## کامنت‌ها

«کامنت» متنی درون فایل Elm است که به‌عنوان کد تفسیر نمی‌شود. کامنت عمدتاً برای این است که خودتان و برنامه‌نویسان دیگر آن را بخوانید. برای کامنت‌های تک‌خطی یک روش نوشتن ساده وجود دارد که بر پایه‌ی دو خط تیره است. کامنت‌های چندخطی هم با جفت `{-` و `-}` به‌عنوان جداکننده‌های باز و بسته امکان‌پذیر است.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
