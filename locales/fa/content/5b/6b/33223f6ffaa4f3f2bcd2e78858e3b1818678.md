# مقدمه

PowerShell یک زبان اسکریپت‌نویسی پویا و به‌طور ضمنی نوع‌دار از مایکروسافت است (_که البته از متغیرهای [قویاً نوع‌دار][strong typed] هم پشتیبانی می‌کند_) و تمرکز اصلی‌اش بر خودکارسازی کارها و مدیریت پیکربندی است.

PowerShell از سبک‌های برنامه‌نویسی امری، تابعی، شیءگرا و حتی خط لوله‌ای پشتیبانی می‌کند.

PowerShell بر بستر پلتفرم .NET ساخته شد و نخستین بار در سال ۲۰۰۶ منتشر شد.
این زبان به‌طور پیش‌فرض در همه‌ی نسخه‌های مدرن Windows گنجانده شده است و می‌توان آن را روی Mac و Linux هم نصب کرد.


## متغیرها

دو روش رایج برای تعریف متغیر در PowerShell وجود دارد.

اسم متغیرها در PowerShell باید با `$` شروع شود و از عملگر انتساب `=` برای اتصال اسم متغیر به یک مقدار استفاده می‌کند.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

همچنین می‌توانید نوع یک متغیر را به‌صورت صریح مشخص کنید، اگر می‌خواهید مقدار آن حتماً از نوع خاصی باشد.
PowerShell تا جای ممکن تلاش می‌کند مقدار را از یک نوع به نوع دیگری تبدیل کند.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### ثابت‌ها

ثابت‌ها در PowerShell متغیرهایی هستند که پس از تعریف، نه می‌توان **تغییرشان** داد و نه **حذفشان** کرد.
این ما را به دومین روش تعریف متغیر می‌رساند: استفاده از cmdlet به اسم `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

برای آشنایی با روش‌های دقیق‌تر و پیشرفته‌تر ساخت متغیر جدید، لطفاً [New-Variable][New-Variable] را بخوانید.


## توابع

[توابع][functions] در PowerShell با «کلیدواژه»ی `function` تعریف می‌شوند.
هر تابع می‌تواند صفر یا چند پارامتر رسمی در پرانتز `()` داشته باشد و پس از آن «دامنه»ی تابع می‌آید که با `{` شروع می‌شود و با `}` پایان می‌یابد.

```powershell
function Greeting {
    return "Hello!"
}
```

توابع در PowerShell می‌توانند مقادیر را به‌صورت صریح با کلیدواژه‌ی `return` برگردانند، پس از آنکه با نحوه‌ی نگارش `FuncName $Arg` فراخوانی شوند.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

نگاهی پیشرفته به نحوه‌ی نوشتن یک تعریف تابع مفصل و اینکه توابع چگونه می‌توانند به‌طور ضمنی مقدار برگردانند، در ماژول مفهومی `Functions` پوشش داده خواهد شد.


## کامنت‌ها

کامنت‌های تکی در PowerShell با `#` شروع می‌شوند و در پایان خط تمام می‌شوند.
«بلوک کامنت» در PowerShell با `<#` شروع و با `#>` تمام می‌شود.
نمایشی پیشرفته از بلوک کامنت برای ساخت Comment-Based Help در ماژول مفهومی `Functions` پوشش داده خواهد شد.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
