# پیوست دستورالعمل

## عملگرهای بیتی

در PHP [عملگرهای بیتی](https://www.php.net/manual/en/language.operators.bitwise.php) وجود دارد.

برای مثال، می‌توان از عملگر «و» بیتی (`&`) استفاده کرد تا بررسی شود که بیتی از یک عدد تعریف شده است یا نه:

```php
$number = 89; // 0b01011001
$mask16 = 16; // 0b00010000
$mask32 = 32; // 0b00100000

$isMask16 = ($number & $mask16) > 0; // 0b00010000 > 0 => TRUE
$isMask32 = ($number & $mask32) > 0; // 0b00000000 > 0 => FALSE
```
