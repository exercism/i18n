# مقدمه

در Go، یک `struct` دنباله‌ای از عناصر نام‌دار است که به آن‌ها «فیلد» می‌گویند؛ هر فیلد یک اسم و یک نوع دارد.
اسم هر فیلد باید درون `struct` یکتا باشد.
می‌توان `struct`ها را با «کلاس‌ها» در الگوی برنامه‌نویسی شیءگرا مقایسه کرد.

## تعریف `struct`

برای ساختن یک `struct` تازه، از «کلیدواژه»های `type` و `struct` استفاده می‌کنید و اسم و نوع فیلدها را به‌صراحت تعریف می‌کنید.
برای مثال، اینجا `struct`ی به اسم `Shape` تعریف می‌کنیم که اسم یک شکل و اندازه‌اش را نگه می‌دارد:

```go
type Shape struct {
    name string
    size int
}
```

اسم فیلدها در `struct`ها از قرارداد Go پیروی می‌کند: فیلدهایی که اسمشان با حرف کوچک شروع می‌شود، فقط برای کدهای همان بسته قابل مشاهده‌اند، در حالی که فیلدهایی که اسمشان با حرف بزرگ شروع می‌شود، در بسته‌های دیگر هم قابل مشاهده‌اند.

## ساختن نمونه‌هایی از یک `struct`

پس از اینکه `struct` را تعریف کردید، باید یک نمونه‌ی تازه بسازید و فیلدها را با اسم فیلدشان و به هر ترتیبی که می‌خواهید تعریف کنید:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

برای خواندن یا تغییر فیلدهای یک نمونه، از نشانه‌گذاری `.` استفاده کنید:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

فیلدهایی که مقدار اولیه‌ای به آن‌ها اختصاص داده نشود، مقدار صفر خود را خواهند داشت.
برای مثال:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

می‌توانید بدون استفاده از اسم فیلدها هم نمونه‌ای از یک `struct` بسازید، به شرطی که فیلدها را _به ترتیب_ تعریف کنید:

```go
s := Shape {
	"Oval",
	20,
}
```

با این حال، این نحوه‌ی نگارش _کد شکننده_ در نظر گرفته می‌شود، چون با اضافه شدن یک فیلد می‌تواند از کار بیفتد، به‌ویژه وقتی فیلد تازه از نوع دیگری باشد.
در مثال زیر یک فیلد اضافه به `Shape` اضافه می‌کنیم:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## توابع «New»

گاهی داشتن توابعی که به ما در ساختن نمونه‌های `struct` کمک می‌کنند می‌تواند خوشایند باشد.
طبق قرارداد، این توابع را معمولاً `New` می‌نامند یا اسمشان با `New` شروع می‌شود، اما چون فقط توابعی معمولی هستند، می‌توانید هر اسمی که می‌خواهید برایشان انتخاب کنید.
ممکن است توابع سازنده در زبان‌های دیگر را به یادتان بیاورند، اما در Go فقط توابعی معمولی هستند.

در مثال زیر، یکی از این توابع `New` برای ساختن نمونه‌ی تازه‌ای از `Shape` استفاده می‌شود و به‌طور خودکار مقدار پیش‌فرضی برای `size` شکل تنظیم می‌کند:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

استفاده از توابع `New` می‌تواند مزایای زیر را داشته باشد:

* اعتبارسنجی مقادیر داده‌شده
* مدیریت مقادیر پیش‌فرض
* چون توابع `New` اغلب در همان بسته‌ی `struct`هایی که مقداردهی اولیه می‌کنند تعریف می‌شوند، می‌توانند حتی فیلدهای خصوصی `struct` را هم مقداردهی اولیه کنند
