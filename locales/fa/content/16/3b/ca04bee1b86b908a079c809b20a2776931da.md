# دستورالعمل‌ها

سلام، مأمور Double-Null0111.

مأموریت شما، اگر بخواهید آن را بپذیرید، نوشتن دو ابزار است که به شما کمک می‌کند به مقر UMBRA (United Minions Being Really Awful) نفوذ کنید و نقشه‌های آخرین طرح واقعاً وحشتناک‌شان را به دست آورید. برای انجام این مأموریت به دو ابزار نیاز دارید.

## 1. از نقشه‌های محرمانه‌ی به دست آمده با یک رمز عبور محافظت کنید

وقتی نقشه‌های محرمانه را به دست آوردید، باید از آن‌ها محافظت کنید تا فقط کسانی که رمز عبور را می‌دانند بتوانند آن‌ها را بازیابی کنند.

برای این کار باید تابع `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String` را پیاده‌سازی کنید.
این تابع، تابع دیگری را برمی‌گرداند که رشته‌های رمز عبور ممکن را به عنوان ورودی می‌گیرد.
اگر رمز عبور واردشده درست باشد، تابع جدید راز پنهان را برمی‌گرداند، اما اگر رمز عبور نادرست باشد، تابع «Sorry. No hidden secrets here.» را برمی‌گرداند.

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. ترکیبی برای باز کردن گاوصندوق‌شان تولید کنید

ما فهمیده‌ایم که UMBRA همه‌ی ترکیب‌های گاوصندوق‌های خود را بر اساس شماره‌ی اتاقی که در آن قرار دارند تعیین می‌کند.
ترکیب‌های گاوصندوق با اعمال مکرر یک تابع ویژه روی شماره‌ی اتاق تولید می‌شوند.
پس اولین عدد ترکیب از اعمال تابع روی شماره‌ی اتاق به دست می‌آید، عدد دوم از اعمال تابع روی عدد اول و عدد سوم از اعمال تابع روی عدد دوم.

اما UMBRA تابعی را که برای تولید ترکیب‌ها استفاده می‌شود مرتباً تغییر می‌دهد، بنابراین ابزار شما باید هم شماره‌ی اتاق و هم تابع مناسب را بگیرد تا ترکیب را تولید کند.

تابع `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` را پیاده‌سازی کنید تا ترکیب مورد نیازتان را تولید کنید.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
