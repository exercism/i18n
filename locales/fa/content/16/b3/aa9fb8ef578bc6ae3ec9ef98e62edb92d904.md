# مقدمه

معمولاً توابع تنها تعداد ثابتی آرگومان می‌پذیرند.
اما اگر پیش از نوع آخرین پارامتر `...` بگذارید، تابع می‌تواند هر تعداد آرگومان در ادامه بپذیرد.
این کار آخرین پارامتر را به یک _«پارامتر variadic»_ تبدیل می‌کند.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

درون تابع، پارامتر variadic یک اسلایس است:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

تابع می‌تواند علاوه بر پارامتر variadic، پارامترهای دیگری هم داشته باشد که پیش از آن می‌آیند.
هر تابع حداکثر می‌تواند یک پارامتر variadic داشته باشد و آن هم باید آخرین پارامتر باشد.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## گسترش یک اسلایس

برای اینکه یک اسلایس را به پارامتر variadic بدهید، بعد از آن `...` بگذارید:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...` تنها زمانی معتبر است که یک اسلایس را به پارامتر variadic می‌فرستید.
