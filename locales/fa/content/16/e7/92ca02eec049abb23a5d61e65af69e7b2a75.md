# مقدمه

ماژول `gleam/order` در کتابخانه‌ی استاندارد Gleam شامل نوع `Order` است که برای مقایسه‌ی مقدارها به کار می‌رود.

تعریف `Order` به این شکل است:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

این نوع سه حالت دارد و هر کدام برای نمایش رابطه‌ی میان یک مقدار و مقداری دیگر استفاده می‌شود:

- `Gt` - این مقدار از مقدار دیگر _بزرگ‌تر_ است.
- `Eq` - این مقدار با مقدار دیگر _برابر_ است.
- `Lt` - این مقدار از مقدار دیگر _کوچک‌تر_ است.

اگر بتوان یک نوع داده را بر اساس اندازه مقایسه کرد، معمولاً ماژول یک تابع `compare` تعریف می‌کند که یک مقدار `Order` برمی‌گرداند. برای نمونه، `gleam/float` و `gleam/int` توابع `compare` تعریف می‌کنند که به‌ترتیب روی اعداد اعشاری و اعداد صحیح عمل می‌کنند.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

توابع مرتب‌سازی مانند `list.sort` معمولاً تابعی را می‌گیرند که یک مقدار `Order` برمی‌گرداند و این به فراخوانی‌کننده اجازه می‌دهد تعیین کند که فهرست چگونه مرتب شود.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
