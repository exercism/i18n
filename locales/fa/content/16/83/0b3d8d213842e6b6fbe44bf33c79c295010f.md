# مقدمه

## Switch

یک [دستور switch][switch] یک مقدار را با چندین الگوی منطبق ممکن مقایسه می‌کند.
این دستور جایگزینی پاک‌تر و خواناتر برای زنجیره‌کردن چندین دستور `if-else` فراهم می‌کند.

یک دستور switch با کلیدواژه‌ی `switch` آغاز می‌شود و پس از آن مقداری می‌آید که باید آزموده شود.
هر تطابق ممکن با کلیدواژه‌ی `case` معرفی می‌شود.
کلیدواژه‌ی `default` حالت جایگزینی را تعریف می‌کند که در صورت مطابقت نداشتن هیچ‌یک از حالت‌های صریح اجرا می‌شود.
مانند زنجیره‌های `if-else`، یک دستور switch تنها بلوک کدی را اجرا می‌کند که با نخستین حالت منطبق مرتبط است.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

زنجیره‌ی `if-else` زیر را در نظر بگیرید:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

این را می‌توان با یک دستور switch شفاف‌تر نوشت:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## حلقه‌های while

یک [حلقه‌ی while][while-loops] یک دستور جریان کنترل است که امکان می‌دهد کد تا زمانی که یک شرط خاص «درست» است اجرا شود.
Swift دو نوع حلقه‌ی while ارائه می‌دهد: حلقه‌های while و repeat-while.
شرط حلقه‌ی while پیش از اجرای بدنه‌ی حلقه ارزیابی می‌شود؛ اگر شرط «غلط» باشد، بدنه‌ی حلقه به‌کلی اجرا نخواهد شد.
حلقه‌های while در Swift ساختار زیر را دارند:

```swift
while <#condition#> {
  <#code#>
}
```

در اینجا حلقه تا زمانی که `count` بزرگ‌تر از ۰ باشد اجرا می‌شود و در نتیجه اعداد ۲، ۱ و «Liftoff!» را چاپ می‌کند.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

یک [حلقه‌ی repeat-while][while-loops] شبیه حلقه‌ی while است، اما شرط پس از اجرای بدنه‌ی حلقه ارزیابی می‌شود.
این یعنی بدنه‌ی حلقه همیشه دست‌کم یک بار اجرا می‌شود، حتی اگر شرط «غلط» باشد.
حلقه‌های repeat-while در Swift ساختار زیر را دارند:

```swift
repeat {
  <#code#>
} while <#condition#>
```

در اینجا حلقه فقط یک بار اجرا می‌شود، چون شرط «غلط» است.
چون این یک حلقه‌ی repeat-while است، بدنه‌ی حلقه پیش از ارزیابی شرط یک بار اجرا می‌شود.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## انتقال کنترل

Swift «دستورهای انتقال کنترل» را فراهم می‌کند تا جریان اجرای حلقه‌ها و دستورهای switch را تغییر دهند.
Swift علاوه بر `return`، `continue`، `break`، برچسب‌های حلقه و `fallthrough` را هم دارد.

### Continue

دستور `continue` به حلقه می‌گوید که اجرای تکرار کنونی را متوقف کند و تکرار بعدی را بی‌درنگ آغاز کند.
در حلقه‌ی `while` یا `repeat-while`، مستقیماً به بررسی شرط می‌پرد.
در حلقه‌ی `for-in`، به عنصر بعدی دنباله می‌رود.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

### Break

دستور `break` بی‌درنگ از کل حلقه یا دستور switch خارج می‌شود.
اجرا از نخستین خط کد پس از حلقه یا switch ادامه می‌یابد.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

### دستورهای برچسب‌دار

در حلقه‌های تودرتو، ممکن است بخواهید `break` یا `continue` روی یک حلقه‌ی بیرونی اثر بگذارد، نه روی درونی‌ترین حلقه.
می‌توانید با قرار دادن یک اسم و یک دونقطه (`labelName:`) در ابتدای یک حلقه، به آن برچسب بزنید.
سپس می‌توانید آن برچسب را به `break` یا `continue` بدهید:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
