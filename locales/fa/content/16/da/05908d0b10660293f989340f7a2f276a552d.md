# قالب رشته

علاوه بر متد `String#%%`، یکی از روش‌های رایج برای ساختن رشته‌ها در Ruby استفاده از [درج رشته](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) است. برای نمونه:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
