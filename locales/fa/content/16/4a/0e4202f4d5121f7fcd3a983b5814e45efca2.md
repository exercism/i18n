# مقدمه

بسیاری از برنامه‌ها برای شبیه‌سازی رویدادهای دنیای واقعی به مقادیر تصادفی (_به‌ظاهر_) نیاز دارند.

نمونه‌های رایج و آشنا عبارت‌اند از:
- پرتاب سکه: مقداری تصادفی از `('Heads', 'Tails')`.
- انداختن تاس: عددی صحیح و تصادفی از ۱ تا ۶.
- بُر زدن یک دسته کارت: ترتیبی تصادفی از فهرست کارت‌ها.
- ساخت درخت‌ها و بوته‌ها در یک شبیه‌سازی گرافیکی سه‌بعدی.

تولید مقادیر _واقعاً_ تصادفی با رایانه یک [چالش فنی به‌طرز شگفت‌آوری دشوار][truly-random] است، بنابراین ممکن است ببینید به این نتایج «شبه‌تصادفی» می‌گویند.

در عمل، کتابخانه‌ای خوش‌ساخت مانند ماژول [`random`][random] در کتابخانه‌ی استاندارد Python سریع و انعطاف‌پذیر است و نتایجی به دست می‌دهد که برای بیشتر کاربردها در مدل‌سازی، شبیه‌سازی و بازی‌ها به‌اندازه‌ی کافی خوب است.

در این مقدمه‌ی کوتاه، چهار تابع پرکاربرد این ماژول را نشان می‌دهیم.
شما را تشویق می‌کنیم که مستندات کامل [`random`][random] را بررسی کنید، چون ابزارها و گزینه‌های زیادی وجود دارد.


~~~~exercism/caution

پیش از آنکه بتوانید از ابزارهای ماژول `random` استفاده کنید، باید ابتدا آن را `import` کنید:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

برای اینکه مجبور نباشید اسم ماژول را تایپ کنید، می‌توانید توابع مشخصی را با اسمشان `import` کنید:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` و `randint()`

همان‌طور که در مثال اول بالا دیدید، تابع `randrange()` سه شکل دارد:

1. `randrange(stop)` عدد صحیح `n` را می‌دهد به‌طوری که `0 <= n < stop`
2. `randrange(start, stop)` عدد صحیح `n` را می‌دهد به‌طوری که `start <= n < stop`
3. `randrange(start, stop, step)` عدد صحیح `n` را می‌دهد به‌طوری که `start <= n < stop`
    و `n` در دنباله‌ی `start, start + step, start + 2*step...` قرار دارد

در رایج‌ترین حالتی که `step == 1` است، `randint(a, b)` ممکن است راحت‌تر و خواناتر باشد.
نتایج ممکن `randint()` کران بالا را هم _در بر می‌گیرد_، بنابراین `randint(a, b)` معادل استفاده از `randrange(a, b+1)` است.



## `choice()` و `choices()`

این دو تابع فرض می‌کنند که از یک [دنباله][sequence-types] یا ظرف دیگری شروع می‌کنید.
این معمولاً یک `list` است، یا با برخی محدودیت‌ها، یک `tuple` یا `set` (_یک `tuple` تغییرناپذیر است و `set` ترتیب ندارد_).

تابع `choice()` یک عضو را برمی‌گرداند که به‌طور تصادفی از یک دنباله‌ی داده‌شده انتخاب شده است و `choices()` تعداد مشخصی عضو (`k`) را برمی‌گرداند که به‌طور تصادفی از یک دنباله‌ی داده‌شده انتخاب شده‌اند.
در مثال‌های بالا فرض کردیم سکه‌ای سالم با احتمال برابر شیر یا خط داریم، اما می‌توان وزن‌ها را هم مشخص کرد.

برای مثال، اگر کیسه‌ای ۱۰ توپ قرمز و ۱۵ توپ سبز داشته باشد و بخواهیم یکی را به‌طور تصادفی بیرون بیاوریم:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
