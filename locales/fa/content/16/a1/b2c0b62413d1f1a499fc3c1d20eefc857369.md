# کلیات

## 1. Define the TreasureChest generic custom type

- راهنمای Elm بخشی درباره‌ی [انواع سفارشی][custom-types] دارد.
- نوع سفارشی `TreasureChest` فقط یک گونه دارد.
- در Elm، وقتی یک نوع سفارشی فقط یک گونه دارد، طبق قرارداد رایج گونه و نوع هم‌نام هستند (در اینجا اسم هر دو `TreasureChest` خواهد بود)

## 2. Define the getTreasure function

- یک [نگارش مختصر برای تجزیه‌ی انواع سفارشی تک‌گونه][single-member-custom-destructuring] وجود دارد.
- اگر لازم است مرور کنید، راهنمای Elm بخشی درباره‌ی [Maybe][maybe] دارد.
