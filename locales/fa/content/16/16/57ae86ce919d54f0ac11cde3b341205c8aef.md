# پیوست دستورالعمل‌ها

## پروسه‌ی Node

برخلاف تمرین‌های دیگر، `grep.js` داخل فایل تست `grep.spec.js` _ایمپورت نمی‌شود_. در عوض، از آن مثل یک فایل اجرایی استفاده می‌شود. برای اینکه این کار ممکن شود، فایل `grep.js` با یک «shebang» و کامنتی که توضیح می‌دهد این خط چه کاری انجام می‌دهد آماده شده است:

```javascript
#!/usr/bin/env node

// The above line is a shebang. On Unix-like operating systems, or environments,
// this will allow the script to be run by node, and thus turn this JavaScript
// file into an executable. In other words, to execute this file, you may run
// the following from your terminal:
//
// ./grep.js args
//
// If you do not have a Unix-like operating system or environment, for example
// Windows without WSL, you can use the following inside a window terminal,
// such as cmd.exe:
//
// node grep.js args
//
// Read more about shebangs here: https://en.wikipedia.org/wiki/Shebang_(Unix)
```

تست‌ها یک _پروسه‌ی_ جدید Node را راه‌اندازی می‌کنند که `grep.js` را اجرا می‌کند.

## خواندن آرگومان‌ها

برای به دست آوردن آرگومان‌هایی که _پروسه_ با آن‌ها شروع شده است، از `process.argv` استفاده کنید.

## خواندن فایل‌ها

تابع `readLines` در اختیار شما قرار گرفته است. برای استفاده از آن، نیازی به تغییر مسیر فایل نیست. تابع `readlines` مسیر را از روی پوشه‌ی کاری جاری _مشخص می‌کند_؛ این پوشه برای پروسه‌های `grep.js` روی پوشه‌ی تمرین تنظیم شده است.

## نوشتن خروجی

برای نوشتن خروجی، از موارد زیر استفاده کنید:

- `console.log` برای نوشتن در جریان خروجی استاندارد،
- `console.error` برای نوشتن در جریان خطای استاندارد.

تست‌ها اجرا را در صورتی موفق (resolved) در نظر می‌گیرند که چیزی در جریان خطای استاندارد نوشته نشود و در صورتی ناموفق (rejected) که چیزی در جریان خطای استاندارد نوشته شود.
