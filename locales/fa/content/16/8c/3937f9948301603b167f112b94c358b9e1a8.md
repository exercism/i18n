# راهنماها

## 1. تولید یک سیاره‌ی تصادفی

- Java تابعی ارائه نمی‌دهد که عنصری را به‌صورت تصادفی از یک مجموعه انتخاب کند.
- به یاد داشته باشید که می‌توانید یک عنصر را با اندیسش، که یک عدد صحیح است، از آرایه بازیابی کنید.

## 2. تولید یک شماره‌ی ثبت تصادفی برای سفینه

- کلاس `java.util.Random` متدی ارائه می‌دهد که یک `int` تصادفی بین ۰ و یک بیشینه‌ی مشخص تولید می‌کند.

## 3. تولید یک تاریخ ستاره‌ای تصادفی

- متد کلاس `java.util.Random` برای تولید یک `double` تصادفی، همیشه عددی بین `0.0` و `1.0` برمی‌گرداند.
