# نصب

ابتدا مطمئن شوید که Erlang نصب شده است؛ برای این کار، دستورهای صفحه‌ی نصب [Erlang][1] را به‌تناسب دنبال کنید.
[1]: /languages/erlang

## Homebrew برای Mac OS X

Homebrew خود را به آخرین نسخه به‌روزرسانی کنید:

```bash
$ brew update
```

LFE را نصب کنید:

```bash
$ brew install lfe
```

## نصب از کد منبع
ابزارهای توسعه‌دهنده یا بسته‌های ساخت ضروری سیستم خود را نصب کنید؛ همچنین `git` و `erl` مربوط به Erlang را.

برای نمونه، در Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

پس از آن می‌توانید LFE را با دستورهای زیر دانلود و کامپایل کنید:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

وقتی LFE را کامپایل کردید، می‌توانید با اجرای فایل دودویی ``lfe``، REPL (نشست تعاملی) را راه‌اندازی کنید:

```bash
$ ./bin/lfe
```
