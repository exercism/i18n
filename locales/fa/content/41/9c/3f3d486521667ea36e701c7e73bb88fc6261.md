# مقدمه

`Complex numbers` پیچیده نیستند.
فقط به یک اسم کمتر نگران‌کننده نیاز دارند.


آن‌قدر مفید هستند، به‌ویژه در مهندسی و علوم، که Python نوع [`complex`][complex] را به عنوان یک نوع عددی استاندارد، در کنار اعداد صحیح ([`int`s][ints]) و اعداد اعشاری ([`float`s][floats])، در خود دارد.


یک مقدار `complex` در Python در اصل یک جفت عدد اعشاری است:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

به این دو، بخش‌های «حقیقی» و «موهومی» می‌گویند.
ممکن است شنیده باشید که «`i` (یا `j`) ریشه‌ی دوم منفی ۱ است».
فعلاً تنها معنای این حرف این است که بخش موهومی _طبق تعریف_ در تساوی `1j * 1j == -1` صدق می‌کند.
این ایده‌ی ساده‌ای است، اما به نتایج ریاضی جالبی منجر می‌شود.

در Python، بخش «موهومی» با `j` نشان داده می‌شود (_نه `i` که در کتاب‌های ریاضی می‌بینید_)، و
`j` باید بلافاصله بعد از یک عدد بیاید تا Python آن را به عنوان اسم یک متغیر نبیند:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


دو روش رایج برای ساختن اعداد مختلط وجود دارد.

۱) سازنده‌ی [`complex(real, imag)`][complex] دو پارامتر `float` می‌گیرد:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    سازنده می‌تواند ورودی رشته‌ای را هم تجزیه کند.
    این محدودیت عجیب را دارد که اگر رشته فاصله داشته باشد، شکست می‌خورد.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


۲) عدد مختلط را می‌توان به شکل لیترال `<real part> + <complex part>j` نوشت، یا اگر بخش حقیقی صفر باشد فقط `<complex part>j`:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    نتیجه‌ی نهایی با استفاده از سازنده‌ی `complex()` یکسان است.


## حساب

بیشتر [`operators`][operators]ی که با اعداد اعشاری و صحیح استفاده می‌شوند، با اعداد مختلط هم کار می‌کنند.

تقسیم صحیح روی اعداد مختلط _**ممکن نیست**_، بنابراین عملگرهای `//` و `%` و تابع `divmod()` برای نوع عدد مختلط شکست می‌خورند.

توضیح قواعد ضرب و تقسیم اعداد مختلط از حیطه‌ی این مفهوم خارج است (_و به‌احتمال زیاد لازم نمی‌شود این عملیات را زیاد «دستی» انجام دهید_).

هر مقدمه‌ای بر اعداد مختلط، [ریاضی][math-complex] یا [مهندسی برق][engineering-complex]، این موقعیت‌ها را پوشش می‌دهد، اگر بخواهید در این موضوع عمیق‌تر شوید.

کتابخانه‌ی استاندارد Python یک ماژول [`math`][math-module] دارد پر از قابلیت‌های مفید برای کار با اعداد حقیقی، و ماژول [`cmath`][cmath] معادل آن برای کار با اعداد مختلط است.
