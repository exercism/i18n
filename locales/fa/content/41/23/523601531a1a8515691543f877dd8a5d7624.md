# نصب

به [NodeJS LTS](https://nodejs.org/en) نیاز دارید.

> 💡 احتمالاً این مسیر با نسخه‌های پایدار قدیمی‌تر و همچنین نسخه‌ی «current» کار می‌کند.
> اما [طبق طراحی](https://github.com/nodejs/release#release-schedule)، نسخه‌های فرد هرگز پایدار نیستند.
> همیشه دقت کنید که نسخه‌ی زوجی از NodeJS را نصب کنید.

[Yarn 4+](https://yarnpkg.com/getting-started/install) را با استفاده از `corepack` در Node.JS نصب کنید:

```shell
corepack enable yarn
```

## بررسی نصب شما

برای استفاده از برنامه‌های اجرایی‌ای که تازه نصب کرده‌اید، معمولاً باید یک ترمینال جدید باز کنید.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_نکته: احتمالاً نسخه‌های شما با این متفاوت است._

## نصب تمرین

**هر تمرین** برای اجرای تست‌ها به ابزارهایی نیاز دارد:

می‌توانید آن‌ها را با اجرای این فرمان در پوشه‌ی هر تمرین نصب کنید:

```bash
$ corepack yarn install
```

بسته به ویرایشگرتان، برای اینکه با روش نصب Plug'n'Play کار کند، باید [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) در هر تمرین نصب شود.
در زمان نوشتن این مطلب، موارد زیر پشتیبانی می‌شوند:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)

باید فرمان نصب را _داخل پوشه‌ی تمرین_ اجرا کنید تا بتوانید تست‌ها را اجرا کنید.
[Yarn 4 PnP](https://yarnpkg.com/features/pnp/) فعال است؛ نصب وابستگی‌ها در پوشه‌ی هر تمرین، یک نسخه‌ی کامل از همه‌ی وابستگی‌ها را نصب **نمی‌کند**.

اگر بعد از این کار ویرایشگرتان برای `eslint`، `prettier` یا `typescript` خطا نشان می‌دهد، پنجره را دوباره بارگذاری کنید یا ویرایشگر را دوباره باز کنید.
