# درباره

Ruby همراه با یک کتابخانه‌ی استاندارد (که اغلب به «stdlib» کوتاه می‌شود) ارائه می‌شود؛ مجموعه‌ای از کلاس‌ها برای کار با مواردی مانند تاریخ، json و شبکه. همچنین قابلیت‌های مفیدی فراهم می‌کند که کار با کدتان را آسان‌تر می‌کند.

`OpenStruct` بخشی از کتابخانه‌ی استاندارد است و به شما اجازه می‌دهد به‌راحتی از یک `Hash` یک شیء بسازید. به‌جای اینکه مجبور باشید با کلیدهای `Hash` به مقادیر دسترسی پیدا کنید، `OpenStruct` به شما امکان می‌دهد با متدها به مقادیر دسترسی داشته باشید و آن‌ها را تغییر دهید.

وقتی از کلاس‌های کتابخانه‌ی استاندارد یا هر کتابخانه‌ی دیگری استفاده می‌کنید، باید آن کلاس را با استفاده از متد `require` بارگذاری کنید.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

یک مزیت دیگر این است که وقتی از نحوه‌ی نگارش «بلوک» استفاده می‌کنید، می‌توانید از یک میانبر بهره ببرید.
در مواردی که یک بلوک فقط یک متد را فراخوانی می‌کند، می‌توانید آن بلوک را با `&:` و سپس اسم متد جایگزین کنید.
برای مثال، این دو خط معادل هم هستند:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
