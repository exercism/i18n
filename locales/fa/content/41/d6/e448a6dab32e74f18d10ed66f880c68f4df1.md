# درباره

کتابخانه‌ی استاندارد Elixir چهار ماژول مختلف برای کار با تاریخ و زمان ارائه می‌کند که هرکدام `struct` مخصوص خود را دارند.

- ماژول [`Date`][date]. یک `struct` از نوع `Date` را می‌توان با [sigilِ `~D`][sigil-d] ساخت.
    ```elixir
    ~D[2021-01-01]
    ```

- ماژول [`Time`][time]. یک `struct` از نوع `Time` را می‌توان با [sigilِ `~T`][sigil-t] ساخت.
    ```elixir
    ~T[12:00:00]
    ```

- ماژول [`NaiveDateTime`][naivedatetime] برای تاریخ-زمان‌های بدون منطقه‌ی زمانی. یک `struct` از نوع `NaiveDateTime` را می‌توان با [sigilِ `~N`][sigil-n] ساخت.
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- ماژول [`DateTime`][datetime] برای تاریخ-زمان‌های دارای منطقه‌ی زمانی. استفاده از این ماژول برای مناطقی غیر از UTC به یک وابستگی خارجی نیاز دارد، یک پایگاه‌داده‌ی منطقه‌ی زمانی. یک `struct` از نوع `DateTime` را می‌توان با [sigilِ `~U`][sigil-u] نمایش داد، اما بهتر است آن را با توابع `DateTime` ساخت.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## مقایسه

برای مقایسه‌ی تاریخ‌ها یا زمان‌ها با یکدیگر، به دنبال یک تابع `compare` یا `diff` در ماژول مربوطه بگردید. عملگرهای مقایسه مانند `==`، `>` و `<` به نظر می‌رسد کار می‌کنند، اما برای این `struct`ها مقایسه‌ی معنایی درستی انجام نمی‌دهند.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## جابه‌جایی

تاریخ‌ها، زمان‌ها و تاریخ-زمان‌ها را می‌توان با تابع `add/2` از ماژول مربوطه در زمان به جلو و عقب جابه‌جا کرد.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## تبدیل

یک `struct` از نوع `NaiveDateTime` را می‌توان با [`NaiveDateTime.to_date/1`][naivedatetime-to-date] و [`NaiveDateTime.to_time/1`][naivedatetime-to-time] به یک `struct` از نوع `Date` و یک `struct` از نوع `Time` تجزیه کرد. عکس این کار با [`NaiveDateTime.new!/2`][naivedatetime-new] انجام می‌شود.

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
