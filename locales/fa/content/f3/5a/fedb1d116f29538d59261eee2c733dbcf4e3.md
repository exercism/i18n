# درباره

Rust برای نمایش یک کاراکتر واحد، نوع [char][char type] را پیاده‌سازی می‌کند. لیترال `char` داخل کوتیشن تک قرار می‌گیرد، مثل `'a'`.
هر `char` چهار بایت است و یک [Unicode Scalar Value][unicode scalar] را نمایش می‌دهد.

با این حال، یک `char` همیشه آن چیزی نیست که ما به‌عنوان حرف می‌شناسیم. زبان‌هایی هستند، مثل هندی، که از «دیاکریتیک» استفاده می‌کنند؛
دیاکریتیک نمادهای ویژه‌ای هستند که کاراکتری را که به آن می‌چسبند تغییر می‌دهند. هرچند دیاکریتیک در Rust یک `char` جداگانه است،
آنچه ما معمولاً به‌عنوان حرف در نظر می‌گیریم، دیاکریتیک به‌همراه کاراکتری است که تغییر می‌دهد.

نام یک کاراکتر و دیاکریتیکش، «خوشه‌ی گرافیم» است. crateهای خارجی وجود دارند که می‌توان از آن‌ها برای پردازش خوشه‌های گرافیم استفاده کرد،
مثل [unicode-segmentation][unicode-segmentation].

مثال

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

این کد چاپ می‌کند:

```rust
2
'u'
'\u{308}'
```

'u{308}' روش دیگری برای نوشتن یک لیترال `char` است. `\u` نشان می‌دهد که یک `char` یونیکد است و `{308}` شماره‌ی یونیکد یکتای
همان کاراکتر یا دیاکریتیک است.
