# کلیدواژههای `static` در کلاس

یک کلاس، واحد سازماندهی کد در PHP است و اغلب نماینده‌ی نمونه‌ای از یک موجودیت، سرویس یا رویه است.
با استفاده از کلیدواژه‌های `static` و `self`، ویژگی‌ها و متدها می‌توانند در ارجاع به کلاس برای همه‌ی نمونه‌ها (یا بدون هیچ نمونه‌ای) وجود داشته باشند.

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## محدودیت

متدهای `static` کلاس فقط می‌توانند سایر ویژگی‌های `static` کلاس یا متدهای کلاس را از کلاس خودشان فراخوانی کنند.
