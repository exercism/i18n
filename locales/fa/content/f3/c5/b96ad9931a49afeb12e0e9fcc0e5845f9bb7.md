# دستورالعمل‌ها

در این تمرین، مأمور شده‌اید نرم‌افزار یک دستگاه رمزنگاری را بنویسید که با انجام تبدیل‌هایی روی داده‌ها کار می‌کند. به روشی نیاز دارید که با آن بتوانید به‌شکلی انعطاف‌پذیر، توابع پیچیده را با ترکیب توابع ساده‌تر بسازید.

برای هر کار، یک «تابع بی‌نام» برگردانید که بتوان آن را از «محدوده‌ی فراخوانی» فراخوانی کرد.

## 1. ساخت تابع جمع

`secret_add` را پیاده‌سازی کنید. باید تابعی را برگرداند که یک آرگومان می‌گیرد و آرگومانی را که به `secret_add` داده شده، به آن اضافه می‌کند.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. ساخت تابع تفریق

`secret_subtract` را پیاده‌سازی کنید. باید تابعی را برگرداند که یک آرگومان می‌گیرد و مقدار مخفی داده‌شده به `secret_subtract` را از آن آرگومان کم می‌کند.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. ساخت تابع ضرب

`secret_multiply` را پیاده‌سازی کنید. باید تابعی را برگرداند که یک آرگومان می‌گیرد و آن را در مقدار مخفی داده‌شده به `secret_multiply` ضرب می‌کند.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. ساخت تابع تقسیم

`secret_divide` را پیاده‌سازی کنید. باید تابعی را برگرداند که یک آرگومان می‌گیرد و آن را بر مقدار مخفی داده‌شده به `secret_divide` تقسیم می‌کند.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. ساخت تابع ترکیب‌کننده

`secret_combine` را پیاده‌سازی کنید. باید تابعی را برگرداند که یک آرگومان می‌گیرد و دو تابع داده‌شده به `secret_combine` را به ترتیب روی آن اعمال می‌کند.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
