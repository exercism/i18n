# دستورالعمل‌ها

دوستتان همین حالا پیامی همراه با یک راز مهم برایتان فرستاده است.
او نمی‌خواست خواندن آن برای دیگران آسان باشد، بنابراین پیام با انجام مجموعه‌ای از دستکاری‌های بیتی رمزنگاری شده است.
برای رمزگشایی پیام باید متدهایی بنویسید.

## 1. بیت‌ها را به عقب شیفت دهید

اولین گام در رمزگشایی پیام این است که شیفت انجام‌شده در فرایند رمزنگاری را با شیفت دادن بیت‌ها به سمت راست خنثی کنید.
در ادامه‌ی فرایند رمزگشایی گام‌های دیگری هم هست که فرض می‌کند صفرها از سمت چپ وارد می‌شوند.

متد `Secrets.shiftBack` را پیاده‌سازی کنید که یک مقدار و تعداد جایگاه‌های شیفت را می‌گیرد و شیفت را انجام می‌دهد.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. برخی بیت‌ها را روی ۱ تنظیم کنید

در گام بعد، بیت‌هایی هستند که باید روی ۱ تنظیم شوند.

متد `Secrets.setBits` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد و نتیجه‌ی تنظیم بیت‌های مقدار روی ۱ را برمی‌گرداند.
بیتی از مقدار که بیت متناظرش در ماسک هم ۱ است، باید روی ۱ تنظیم شود.
سایر بیت‌ها باید بدون تغییر بمانند.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. بیت‌های مشخصی را وارونه کنید

بعضی بیت‌ها در هنگام رمزنگاری وارونه می‌شوند.
برای رمزگشایی پیام باید دوباره وارونه شوند.

متد `Secrets.flipBits` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد.
ماسک مشخص می‌کند کدام بیت‌های مقدار وارونه شوند.
اگر بیتی در ماسک ۱ باشد، بیت متناظر در مقدار وارونه می‌شود.
سایر بیت‌ها بدون تغییر می‌مانند.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. بیت‌های مشخصی را پاک کنید

در پایان، بیت‌های مشخصی هم هستند که همیشه به ۰ رمزگشایی می‌شوند.

متد `Secrets.clearBits` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد.
بیت‌های `value` باید ۰ شوند، هر جا که بیت متناظر در ماسک ۱ است.
سایر بیت‌ها باید بدون تغییر بمانند.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
