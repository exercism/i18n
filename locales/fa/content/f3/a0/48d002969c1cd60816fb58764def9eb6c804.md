# دستورالعمل‌ها

کارل می‌خواهد فهرستی از زبان‌هایی را که می‌خواهد در وب‌سایت Exercism یاد بگیرد پیگیری کند.
کارل باید بتواند زبان‌های تازه اضافه کند، زبان‌های قدیمی را حذف کند و بررسی کند که آیا زبان‌های خاصی در فهرست هستند یا نه.
اگر کارل بخواهد Java یا Kotlin یاد بگیرد، خیلی هیجان‌انگیز می‌شود!

## 1. تابعی تعریف کنید که بررسی کند فهرست زبان‌ها خالی است یا نه

کارل باید بداند که آیا فهرست زبان‌هایش روزی خالی می‌شود تا بتواند برود زبان‌های بیشتری برای یادگیری پیدا کند!
متدی به اسم `isEmpty` تعریف کنید که اگر هیچ زبانی در فهرست نباشد، `true` برمی‌گرداند.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. تابعی تعریف کنید که زبانی را به فهرست اضافه کند

کارل بی‌صبرانه منتظر یادگیری Kotlin و Python است!
به کارل کمک کنید تا شروع کند و متدی به اسم `addLanguage` تعریف کنید که زبان مورد نظرش را می‌گیرد و آن را به فهرست اضافه می‌کند.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. تابعی تعریف کنید که زبانی را از فهرست حذف کند

کارل تصمیم گرفته است که فعلاً نمی‌خواهد Scala یاد بگیرد.
به کارل کمک کنید تا آن را از فهرست حذف کند؛ برای این کار متدی به اسم `removeLanguage` تعریف کنید که زبانی را که دارد حذف می‌کند می‌گیرد و آن را از فهرست برمی‌دارد.

```java
languageList.removeLanguage("Scala");
```

## 4. تابعی تعریف کنید که اولین عنصر فهرست را برگرداند

کارل می‌خواهد اولین زبانی را که به فهرست اضافه کرده (و هنوز در فهرست هست) به خاطر بسپارد.
متدی به اسم `firstLanguage` تعریف کنید که اولین زبان در فهرست را برمی‌گرداند.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. تابعی تعریف کنید که برگرداند چند زبان در فهرست هست

کارل باید بداند که چند زبان را می‌خواهد یاد بگیرد.
به کارل کمک کنید تا جواب را پیدا کند؛ برای این کار متدی به اسم `count` تعریف کنید که تعداد زبان‌های فهرست را برمی‌گرداند.

```java
int two = languageList.count(); // 2
```

## 6. تابعی تعریف کنید که تعیین کند زبانی در فهرست هست یا نه

کارل می‌خواهد یادش بیاید که می‌خواست Python یاد بگیرد یا Ruby.
متدی به اسم `containsLanguage` تعریف کنید که زبانی را که درباره‌اش می‌پرسد می‌گیرد تا کارل بتواند جواب را بفهمد!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. تابعی تعریف کنید که تعیین کند فهرست هیجان‌انگیز است یا نه

اگر کارل بخواهد Java یا Kotlin یاد بگیرد، این خیلی هیجان‌انگیز است!
متدی به اسم `isExciting` تعریف کنید که اگر کارل بخواهد Java یا Kotlin یاد بگیرد، `true` برمی‌گرداند.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
