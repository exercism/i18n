# مقدمه

## Agent

ماژول `Agent` انتزاعی برای راه‌اندازی [فرایندها و حلقه‌ی _دریافت-ارسال_][exercism-processes] فراهم می‌کند. از این پس، فرایندهایی را که با استفاده از ماژول `Agent` راه‌اندازی می‌شوند، _«فرایندهای عامل»_ می‌نامیم. ممکن است یک _فرایند عامل_ برای نمایش یک حالت اشتراکی مرکزی انتخاب شود.

برای شروع یک _فرایند عامل_، `Agent` تابع `start/2` را فراهم می‌کند. تابعی که هنگام `start` کردن _فرایند عامل_ ارائه می‌دهید، حالت اولیه‌ی فرایند را برمی‌گرداند:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

درست مانند `Map` یا `List`، `Agent` توابع زیادی برای کار با _فرایندهای عامل_ فراهم می‌کند.

مرسوم است که تمام قابلیت‌های مرتبط با `Agent` را در یک ماژول برای دامنه‌ی در حال مدل‌سازی سازماندهی و کپسوله کنند.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
