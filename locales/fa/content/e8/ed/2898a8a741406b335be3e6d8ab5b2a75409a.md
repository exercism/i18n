# مقدمه

ساختارهای شرطی Factor از میان **quotation**ها یکی را انتخاب می‌کنند؛ quotationها تکه‌کدهایی هستند که داخل کروشه نوشته می‌شوند: `[ ... ]`. نوشتن `[ ... ]` کد را به‌جای اجرا کردن، به‌عنوان یک مقدار روی پشته می‌گذارد؛ سپس ساختار شرطی تصمیم می‌گیرد کدام quotation را اجرا کند. (به quotationها در تمرینی بعدی به‌طور کامل می‌پردازیم.)

`if` (در [`kernel`][kernel]) ساختار شرطی پایه‌ی Factor است. یک مقدار منطقی و دو quotation می‌گیرد: اگر مقدار منطقی «درست» باشد اولی را اجرا می‌کند و در غیر این صورت دومی را.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` quotation خود را فقط وقتی اجرا می‌کند که مقدار منطقی «درست» باشد و `unless` فقط وقتی که «غلط» باشد. برای شاخه‌بندی چندراهه، `cond` در [`combinators`][combinators] وجود دارد:

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
