# راهنمایی‌ها

## کلی

- [مستندات Python: متدهای رشته][string-method-docs]
- [آموزش مستندات Python: متن][tutorial-strings]

## 1. حرف اول عنوان مقاله را بزرگ بنویسید

- می‌توانید برای بزرگ‌کردن درست حرف اول عنوان از [متدهای رشته][title-method-docs] استفاده کنید.

## 2. بررسی کنید که هر جمله با نقطه تمام می‌شود یا نه

- می‌توانید برای بررسی پایان یک رشته از [متدهای رشته][endswith-method-docs] استفاده کنید.

## 3. فاصله‌های اضافی را پاک‌سازی کنید

- می‌توانید برای حذف فاصله‌های خالی از [متدهای رشته][strip-method-docs] استفاده کنید.

## 4. واژه‌ها را با یک مترادف جایگزین کنید

- می‌توانید برای جایگزین‌کردن واژه‌ها از [متدهای رشته][replace-method-docs] استفاده کنید.
