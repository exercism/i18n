# درباره

یک [حلقه‌ی While][while-loops] یک دستور جریان کنترل است که اجازه می‌دهد کد تا زمانی که یک شرط مشخص «درست» باشد اجرا شود.
Swift دو نوع حلقه‌ی While ارائه می‌دهد: حلقه‌های While و Repeat-While.
شرط حلقه‌ی While پیش از اجرای بدنه‌ی حلقه ارزیابی می‌شود؛ اگر شرط «غلط» باشد، بدنه‌ی حلقه اصلاً اجرا نمی‌شود.
حلقه‌های While در Swift ساختار زیر را دارند:

```swift
while <#condition#> {
  <#code#>
}
```

اینجا حلقه تا زمانی که `count` بزرگ‌تر از ۰ باشد اجرا می‌شود و در نتیجه اعداد ۲، ۱ و «Liftoff!» را چاپ می‌کند.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

یک [حلقه‌ی Repeat-While][while-loops] مشابه حلقه‌ی While است، اما شرط پس از اجرای بدنه‌ی حلقه ارزیابی می‌شود.
یعنی بدنه‌ی حلقه همیشه دست‌کم یک‌بار اجرا می‌شود، حتی اگر شرط «غلط» باشد.
حلقه‌های Repeat-While در Swift ساختار زیر را دارند:

```swift
repeat {
  <#code#>
} while <#condition#>
```

اینجا حلقه فقط یک‌بار اجرا می‌شود، چون شرط «غلط» است.
چون این یک حلقه‌ی Repeat-While است، بدنه‌ی حلقه پیش از ارزیابی شرط یک‌بار اجرا می‌شود.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## حلقه‌های اتصال اختیاری

یکی از گونه‌های رایج حلقه‌های While در Swift، حلقه‌ی While با اتصال اختیاری است.
این حلقه‌ها تا زمانی تکرار می‌شوند که فراخوانی تابعی که یک مقدار اختیاری برمی‌گرداند، مقداری غیر از `nil` برگرداند.
سپس آن مقدار (غیراختیاری) به اسمی که خودتان انتخاب می‌کنید متصل می‌شود و می‌توانید در بدنه‌ی حلقه از آن استفاده کنید.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
