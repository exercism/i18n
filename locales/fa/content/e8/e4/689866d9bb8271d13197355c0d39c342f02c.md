# مقدمه

گاهی لازم است تکه‌ای از وضعیت میان چندین «واژه» به اشتراک گذاشته شود، بدون اینکه هر بار آن را از میان اثرهای پشته‌ی آن‌ها عبور دهید. *متغیرهای پویا*ی Factor، که با `SYMBOL:` تعریف می‌شوند، به هر واژه دسترسی به مقداری را می‌دهند که در یک فضای نام ذخیره شده است.

## `SYMBOL:` و `SYMBOLS:`

`SYMBOL: name` یک متغیر تعریف می‌کند. `SYMBOLS: a b c ;` چند متغیر را یک‌جا تعریف می‌کند:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## تنظیم و خواندن

`set-global` و `get-global` (در [`namespaces`][namespaces]) روی فضای نام سراسری کار می‌کنند:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

برای وضعیت سطح ماژول، گونه‌های `-global` همان چیزی هستند که می‌خواهید.

## اتصال‌های محدوده‌محور با `with-variable`

یک متغیر پویا گونه‌ای دوم و *محدوده‌محور* را هم پشتیبانی می‌کند. `set` / `get` / `change` (بدون پسوند `-global`) محدوده‌ی پویای *جاری* را می‌خوانند و می‌نویسند، و `with-variable` (در [`namespaces`][namespaces]) به مدت اجرای یک کوتیشن یک محدوده‌ی تازه می‌سازد:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

تا زمانی که `quot` اجرا می‌شود، متغیر به `value` متصل است؛ به‌محض اینکه برگردد، اتصال از میان می‌رود. این کار به یک فراخواننده‌ی بیرونی اجازه می‌دهد مقداری را «تزریق» کند که کد درونی بتواند آن را بخواند، بدون اینکه آن را از میان هر امضای پشته عبور دهد.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

این تمرین در سراسر خود از گونه‌ی سراسری استفاده می‌کند، اما شناختن خانواده‌ی موازی `set`/`get`/`change` وقتی کد دیگران را می‌خوانید مفید است.

## بردارهای تغییرپذیر

ازآنجاکه متغیرهای پویا یک ارجاع را نگه می‌دارند، می‌توانید مجموعه‌ای *تغییرپذیر* را درون یکی از آن‌ها نگه دارید و آن را در جای خود به‌روزرسانی کنید:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` یک بردار لیترال است. همیشه یک لیترال `V{ }` را پیش از ذخیره‌کردنش `clone` کنید: لیترال‌ها میان فراخوانی‌ها به اشتراک گذاشته می‌شوند.

## `find`: اولین تطابق

`find` (در [`sequences`][sequences]) اولین عنصری را برمی‌گرداند که گزاره برایش درست باشد، به‌همراه اندیس آن:

```
find ( seq quot -- index elt/f )
```

اگر هیچ‌چیز منطبق نشود، هر دو مقدار `f` هستند. حذف اندیس با `nip` و استفاده از `unless*` ترکیب استانداردِ «پیش‌فرض در صورت نبود مقدار» است.

## `reject`: حذف موارد منطبق

`reject` (نیز در [`sequences`][sequences]) نقطه‌ی مقابل `filter` است: عناصری را برمی‌گرداند که در گزاره *شکست می‌خورند*.
