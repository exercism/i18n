# پیوست دستورالعمل‌ها

## پیاده‌سازی

اگر آخرین عنصر فهرست به‌جای `string` یک `object` باشد، یک توصیف‌گر در خود دارد که آخرین سطر ضرب‌المثل را تغییر می‌دهد.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
