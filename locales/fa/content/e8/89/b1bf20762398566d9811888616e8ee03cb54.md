# دستورالعمل‌ها

یک API رست‌فول برای پیگیری بدهی‌ها پیاده‌سازی کنید.

چهار هم‌خانه عادت دارند مدام از یکدیگر پول قرض بگیرند و یادشان نمی‌آید چه کسی به چه کسی و چه‌قدر بدهکار است.

وظیفه‌ی شما پیاده‌سازی یک [API رست‌فول][restful-wikipedia] ساده است که [بدهی][iou]‌ها را به‌صورت درخواست‌های POST دریافت می‌کند و می‌تواند اطلاعات خلاصه‌ی مشخصی را از طریق درخواست‌های GET برگرداند.

## مشخصات API

### شیء کاربر

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### متدها

| توضیح                     | متد HTTP    | نشانی  | قالب داده‌ی ارسالی                                                        | پاسخ بدون داده                         | پاسخ همراه با داده                                                             |
| ------------------------ | ----------- | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| فهرست اطلاعات کاربران     | GET         | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| ایجاد کاربر               | POST        | /add   | `{"user":<name of new user (unique)>}`                                    | ناموجود                                | `<User object for new user>`                                                    |
| ایجاد بدهی                | POST        | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | ناموجود                                | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
