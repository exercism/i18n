# درباره

در Rust، مقادیر «منطقی» با نوع `bool` نمایش داده می‌شوند و مقدارشان می‌تواند `true` یا `false` باشد.

Rust از یک [عملگر نقیض منطقی][negation operators] پشتیبانی می‌کند: `!` (Not).

Rust از شش [عملگر مقایسه][comparison operators] پشتیبانی می‌کند: `==` (Equal)، `!=` (Not equal)، `>` (Greater than)، `<` (Less than)، `>=`
(Greater than or equal to)، `<=` (Less than or equal to). از این عملگرها می‌توان استفاده کرد تا رابطه‌ی مقادیری که منطقی نیستند ارزیابی شود و نتیجه یک مقدار منطقی باشد.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

برخلاف برخی زبان‌های دیگر، `0` به معنی `false` نیست و مقدار غیرصفر به معنی `true` نیست.

Rust از سه [عملگر دودویی منطقی][logical binary operators] پشتیبانی می‌کند: `&` (Logical And)، `|` (Logical Or)، `^` (Logical Xor).

Rust از دو [عملگر منطقی][lazy boolean operators] پشتیبانی می‌کند: `||` (Or)، `&&` (And). تفاوت آن‌ها با `|` و `&` این است که عملوند سمت راست تنها زمانی ارزیابی می‌شود که عملوند سمت چپ نتیجه‌ی عبارت را از پیش تعیین نکرده باشد. یعنی `||` عملوند سمت راست خود را تنها زمانی ارزیابی می‌کند که مقدار عملوند سمت چپ `false` باشد و `&&` تنها زمانی که مقدار آن `true` باشد.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
