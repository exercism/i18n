# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ------------------------------------- |
| `$a0`    | ورودی     | آدرس | رشته‌ی پایان‌یافته با پوچ از رقم‌های مبنای هشت |
| `$v0`    | خروجی     | عدد صحیح | مقدار مبنای ده رشته‌ی ورودی         |
| `$t0-9`  | موقت | هر     | برای ذخیره‌سازی موقت استفاده می‌شود            |
