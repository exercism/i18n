# مقدمه

## شرط‌ها: If

### عملگرهای منطقی

Java از سه عملگر منطقی `&&` (AND)، `||` (OR) و `!` (NOT) پشتیبانی می‌کند.

### دستور شرطی

نوع پایه‌ی هر عملیات شرطی، نوع `boolean` است که می‌تواند مقدار `true` یا `false` داشته باشد. ساختارهای شرطی اغلب به عنوان سازوکارهای کنترل جریان برای بررسی شرط‌های گوناگون به کار می‌روند. برای بررسی یک حالت خاص می‌توان از دستور شرطی `if` استفاده کرد که اگر شرط زیربنایی `true` باشد، کد خودش را اجرا می‌کند، به این شکل:

```java
int val;

if(val == 9) {
    // conditional code
}
```

در حالت‌هایی که بیش از یک مورد درگیر است، می‌توان دستورهای شرطی `if` متعددی را با استفاده از دستورهای `else if` و `else` به هم زنجیره کرد.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### دستور `switch`

Java همچنین برای حالت‌هایی با گزینه‌های متعدد، دستور `switch` را فراهم می‌کند.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
