# راهنمایی‌ها

## کلی

- یک [مقدار عدد صحیح (`Int`)][numbers] را می‌توان به‌صورت یک یا چند رقم پشت‌سرهم تعریف کرد.
- از متغیرها استفاده کنید تا اسم‌های خوب و خوانا برای مقدارهایتان بگذارید. یادتان باشد که خوانایی کد بسیار مهم‌تر از تعداد خطوط کد است.

## 1. محاسبه‌ی زمان باقی‌مانده‌ی پخت بر حسب دقیقه

- باید یک [تابع][functions] با یک پارامتر تعریف کنید.
- باید یک [مقدار پیش‌فرض][function-defaults] برای پارامتر تعیین کنید.
- باید به‌صورت صریح یک مقدار عدد صحیح را از یک متد برگردانید.
- پارامتر متد یک [عدد صحیح][numbers] است.
- برای تفریق مقدارها باید از عملگر ریاضی تفریق (`-`) استفاده کنید.

## 2. محاسبه‌ی زمان آماده‌سازی بر حسب دقیقه

- باید یک [تابع][functions] با یک پارامتر تعریف کنید.
- باید به‌صورت صریح یک مقدار عدد صحیح را از یک متد برگردانید.
- پارامتر متد یک [عدد صحیح][numbers] است.
- برای جمع مقدارها باید از عملگر ریاضی جمع (`+`) استفاده کنید.

## 3. محاسبه‌ی زمان سپری‌شده بر حسب دقیقه

- باید یک [تابع][functions] با دو پارامتر تعریف کنید.
- باید یک [مقدار پیش‌فرض][function-defaults] برای پارامتر دوم تعیین کنید.
- باید به‌صورت صریح یک مقدار عدد صحیح را از یک متد برگردانید.
- پارامتر متد یک [عدد صحیح][numbers] است.
- برای جمع مقدارها باید از عملگر ریاضی جمع (`+`) استفاده کنید.
- باید توابعی را که از قبل پیاده‌سازی شده‌اند فراخوانی کنید.

[numbers]: https://kotlinlang.org/docs/reference/basic-types.html#numbers
[functions]: https://kotlinlang.org/docs/reference/functions.html#function-declarations
[function-defaults]: https://kotlinlang.org/docs/reference/functions.html#default-arguments
