# مقدمه

## Try/Rescue/Else/After

استفاده از `try..rescue` ساختاری قدرتمند برای گرفتن خطاها در زمان بروز آن‌هاست. گرفتن خطاها به توابع اجازه می‌دهد در صورت لزوم مقادیر مشخصی برگردانند. ساختار `try..rescue` همچنین دو قابلیت دیگر در اختیارمان می‌گذارد که می‌توانیم از آن‌ها استفاده کنیم:

- بلوک `else`
  - وقتی بلوک `try` با موفقیت اجرا شود، نتیجه با این بلوک تطبیق داده می‌شود.
- بلوک `after`
  - چه بلوک `try` با موفقیت اجرا شود و چه خطا بدهد، کد داخل بلوک `after` همیشه اجرا می‌شود، تا زمانی که برنامه در آن نقطه در حال اجرا باشد.
  - نتیجه‌ی بلوک `after` به دامنه‌ی فراخوان برگردانده نمی‌شود.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## فراخوانی پویا

وقتی Elixir تصمیم می‌گیرد کدام تابع فراخوانی شود، از اسم ماژول برای جست‌وجو استفاده می‌کند. اگر اسم ماژول به یک متغیر مقید شده باشد، این جست‌وجو می‌تواند به‌صورت پویا انجام شود.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

از نظر داخلی، اسم یک ماژول یک اتم است. همه‌ی اتم‌های ماژول در Elixir به‌طور خودکار با `Elixir.` پیشوند می‌گیرند.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
