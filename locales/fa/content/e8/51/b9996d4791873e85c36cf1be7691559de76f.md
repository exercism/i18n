# باقیمانده

در ریاضیات، **باقیمانده** مقداری است که پس از انجام یک محاسبه «باقی می‌ماند». برای مثال، باقیمانده‌ی `5 / 3` برابر `2` است.

بسیاری از زبان‌های برنامه‌نویسی از علامت درصد (`%`) به عنوان یک عملگر برای محاسبه‌ی باقیمانده استفاده می‌کنند. برای مثال:
```javascript
5 % 3 == 2
```

باقیمانده را اغلب می‌توان هم روی اعداد صحیح و هم روی اعداد اعشاری محاسبه کرد. برای مثال،
```javascript
5.3 % 3 == 2.3
```

وقتی با اعداد منفی کار می‌کنید، نتیجه همیشه همان علامت مقسوم را دارد (عددی که در سمت چپ قرار دارد و تقسیم می‌شود). برای مثال:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

برخی زبان‌ها (مانند Python) از عملگر `%` برای محاسبه‌ی modulus استفاده می‌کنند، نه باقیمانده. این روش با اعداد منفی متفاوت رفتار می‌کند. برای اطلاعات بیشتر می‌توانید این موضوع را [در ویکی‌پدیا](https://en.wikipedia.org/wiki/Modulo) بخوانید.
