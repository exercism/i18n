# دستورالعمل‌ها

در این تمرین باید چند تابع پیاده‌سازی کنید تا فهرستی از زبان‌های برنامه‌نویسی را دست‌کاری کنند.

## 1. تابعی تعریف کنید که یک فهرست زبان خالی برگرداند

تابع `new/0` را تعریف کنید که هیچ آرگومانی نمی‌گیرد و یک فهرست خالی برمی‌گرداند.

```elixir
LanguageList.new()
# => []
```

## 2. تابعی تعریف کنید که زبانی را به فهرست اضافه کند

تابع `add/2` را تعریف کنید که ۲ آرگومان می‌گیرد (یک _فهرست زبان_ و یک رشته‌ی متنی که یک _زبان_ را نشان می‌دهد). باید زبان جدید را به ابتدای فهرست داده‌شده اضافه کند و فهرست حاصل را برگرداند.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. تابعی تعریف کنید که زبانی را از فهرست حذف کند

تابع `remove/1` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_). باید فهرستی را برگرداند که اولین عنصر آن حذف شده است. فرض کنید فهرست همیشه حداقل یک عنصر دارد.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. تابعی تعریف کنید که اولین عنصر فهرست را برگرداند

تابع `first/1` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_). باید اولین زبان فهرست را برگرداند. فرض کنید فهرست همیشه حداقل یک عنصر دارد.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. تابعی تعریف کنید که تعداد زبان‌های فهرست را برگرداند

تابع `count/1` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_). باید تعداد زبان‌های فهرست را برگرداند.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. تابعی تعریف کنید که تعیین کند آیا فهرست شامل یک زبان تابعی است یا نه

تابع `functional_list?/1` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_). باید یک «مقدار منطقی» برگرداند. اگر «_Elixir_» یکی از زبان‌های فهرست باشد، باید «درست» را برگرداند.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
