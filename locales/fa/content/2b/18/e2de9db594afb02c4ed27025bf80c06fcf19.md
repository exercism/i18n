# نصب

برای اجرای این تمرین‌ها، تنها به نصب [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) و [Java 8](https://java.com/en/download/) نیاز دارید. CommandBox CLI روی Mac، Linux و Windows پشتیبانی می‌شود و راهنمای نصب آن را می‌توانید اینجا پیدا کنید:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

اگر کاربر Homebrew روی Mac هستید، نمونه‌ای از راه‌اندازی CommandBox CLI چنین است:

```bash
brew install commandbox
```

پس از نصب CLI، می‌توانید با «REPL» کار کنید:

```bash
box repl
```

می‌توانید صفحه‌های .cfm را مستقیم اجرا کنید:

```bash
box exec myTest.cfm
```

و حتی می‌توانید یک وب‌سرور را در هر پوشه‌ای از هارد دیسک خود راه‌اندازی کنید:

```bash
box server start
```

CommandBox یک پوسته‌ی تعاملی هم دارد که می‌توانید از آن استفاده کنید؛ این پوسته تکمیل خودکار تب پیشرفته‌تری دارد و سریع‌تر اجرا می‌شود. برای ورود به آن کافی است فایل اجرایی `box` را بدون هیچ آرگومانی اجرا کنید.

```bash
box
```
