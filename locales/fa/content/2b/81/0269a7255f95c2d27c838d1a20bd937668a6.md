# درباره

Lua از دو نمایش برای اعداد استفاده می‌کند: اعداد صحیح ۶۴ بیتی و اعداد اعشاری با دقت دوگانه.

~~~exercism/note
پیش از نسخه‌ی ۵.۳، Lua همه‌ی اعداد را با قالب اعشاری دقت دوگانه نمایش می‌داد.
~~~

اعداد می‌توانند با یک بخش اعشاری اختیاری و یک توان اعشاری اختیاری نوشته شوند.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

عددی که نقطه‌ی اعشاری یا توان داشته باشد، اعشاری در نظر گرفته می‌شود و عددی که نداشته باشد، صحیح در نظر گرفته می‌شود، اما هر دو نوع «number» دارند.
```lua
type(1)         --> number
type(2.0)       --> number
```

اگر بخواهیم بین اعداد اعشاری و صحیح تفاوت قائل شویم، می‌توان از تابع `type` در ماژول `math` استفاده کرد.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## مقایسه

اعداد صحیح و اعشاری با مقدار یکسان، برابر مقایسه می‌شوند:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## حساب

Lua از مجموعه‌ی معمول عملگرهای حسابی پشتیبانی می‌کند: جمع، تفریق، ضرب، تقسیم و منفی. علاوه بر این، از تقسیم کف، باقیمانده و توان نیز پشتیبانی می‌کند.

### جمع، تفریق، ضرب و منفی

اگر هر دو عملوند عدد صحیح باشند، نتیجه‌ی عمل یک عدد صحیح است. همین برای اعداد اعشاری هم صادق است.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

اگر یک عملوند اعشاری باشد، اعداد صحیح باقی‌مانده نیز به اعشاری تبدیل می‌شوند و نتیجه‌ی عمل اعشاری خواهد بود.
```lua
1.0 + 2   --> 3.0
```

### تقسیم

تقسیم همیشه روی اعداد اعشاری عمل می‌کند و نتیجه‌ی اعشاری می‌دهد.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

تقسیم بر صفر به `inf` یا `-inf` منجر می‌شود. تقسیم صفر بر صفر به `-nan` منجر می‌شود.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### تقسیم کف

اگر نتیجه‌ی صحیح لازم باشد، می‌توان از تقسیم کف استفاده کرد. تقسیم کف همیشه خارج‌قسمت را به سمت منفی بینهایت گرد می‌کند و نتیجه‌ی صحیحی برای همه‌ی عملوندها تضمین می‌کند.

~~~exercism/note
پیش از نسخه‌ی ۵.۳، Lua هیچ عملگر حسابی برای تقسیم کف نداشت.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

تقسیم کف از همان قواعد عملگرهای جمع، تفریق، ضرب و منفی پیروی می‌کند: اگر هر دو عملوند عدد صحیح باشند، نتیجه‌ی عمل یک عدد صحیح است؛ در غیر این صورت نتیجه اعشاری است.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

هنگام تقسیم بر صفر با تقسیم کف، Lua خطا ایجاد می‌کند.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### باقیمانده

عملگر باقیمانده برای به دست آوردن باقیمانده‌ی تقسیم دو عملوند به کار می‌رود.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### توان

توان نیز مانند تقسیم روی اعداد اعشاری عمل می‌کند و نتیجه‌ی اعشاری می‌دهد.
```lua
10 ^ 2    --> 100.0
```

## اولویت

همه‌ی عملیات بر اساس [اولویت عملگرها](https://www.lua.org/manual/5.4/manual.html#3.4.8) ارزیابی می‌شوند. می‌توان از پرانتزها برای تغییر اولویت یک عبارت استفاده کرد.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## گرد کردن

ماژول `math` سه تابع گرد کردن دارد: `floor` به سمت «پایین» (به سمت منفی بینهایت) گرد می‌کند، `ceil` به سمت «بالا» (به سمت مثبت بینهایت) و `modf` به سمت صفر گرد می‌کند.

### `math.floor`

`floor` به سمت منفی بینهایت گرد می‌کند.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` به سمت مثبت بینهایت گرد می‌کند.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` به سمت صفر گرد می‌کند. این تابع مقدار گردشده و همچنین بخش کسری عدد را برمی‌گرداند که همیشه اعشاری است.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## تبدیل

اگر بخواهیم عدد صحیحی را به عدد اعشاری تبدیل کنیم، می‌توانیم `0.0` را به آن اضافه کنیم.
```lua
1 + 0.0         --> 1.0
```

اگر بخواهیم عدد اعشاری را به عدد صحیح تبدیل کنیم، می‌توانیم آن را به‌صورت بیتی با صفر OR کنیم یا از تابع `tointeger` در ماژول `math` استفاده کنیم.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

اگر عدد نتواند به عدد صحیح تبدیل شود، عملگر OR خطا می‌دهد و تابع `tointeger` مقدار `nil` را برمی‌گرداند.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## مبنای شانزده

مانند بسیاری از زبان‌های برنامه‌نویسی دیگر، Lua از اعداد مبنای شانزده با پیشوند `0x` پشتیبانی می‌کند، اما برخلاف بسیاری از زبان‌های برنامه‌نویسی دیگر، Lua از اعداد مبنای شانزدهی اعشاری نیز پشتیبانی می‌کند. آن‌ها می‌توانند بخش کسری و توان دودویی داشته باشند، با پیشوند «p» یا «P».
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
