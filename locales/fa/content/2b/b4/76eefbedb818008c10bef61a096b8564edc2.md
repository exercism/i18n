# مقدمه

## آرایه

در Common Lisp، مانند زبان‌های دیگر، «آرایه» مجموعه‌ای از عناصر است که از طریق «اندیس»های صحیح به آن‌ها دسترسی پیدا می‌کنید.
نوع عناصر می‌تواند ناهمگون باشد.
آرایه می‌تواند چندبعدی باشد (نه فقط تک‌بعدی).

### ساختن

`make-array` به شما امکان می‌دهد آرایه بسازید.
گزینه‌های زیادی دارد، اما شکل‌های ساده‌ترش به شما امکان می‌دهند آرایه‌های Nبعدی بسازید که یا همه‌ی عناصرشان با یک مقدار واحد مقداردهی اولیه شده باشند یا خود آرایه با مقادیر یک «دنباله»ی دیگر (مانند یک لیست) مقداردهی شده است. 
اولین آرگومانش لیستی از اندازه‌ی هر بعد است.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(توجه کنید که آرایه‌های Nبعدی همراه با تعداد ابعادشان چاپ می‌شوند.)

آرایه‌ها را می‌توان با همان قالبی که چاپ می‌شوند هم ساخت:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### دسترسی به عناصر

برای دسترسی به عناصر یک «بردار» از `aref` استفاده کنید؛ اندیس‌ها از صفر شروع می‌شوند. 
تعداد اندیس‌هایی که می‌دهید باید با «رتبه»ی آرایه مطابقت داشته باشد.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
