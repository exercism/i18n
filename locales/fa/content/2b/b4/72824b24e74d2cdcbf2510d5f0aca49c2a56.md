# پیوست دستورالعمل‌ها

یکی از راه‌حل‌های ممکن برای این تمرین این است که تابع توان‌رسانی پیمانه‌ای خودتان را پیاده‌سازی کنید.
برای اطلاعات بیشتر به [صفحه‌ی زیر](https://en.wikipedia.org/wiki/Modular_exponentiation) مراجعه کنید.

## برای کسب امتیاز

بسیاری از پیاده‌سازی‌ها برای همه‌ی دامنه‌ی ورودی‌ها درست کار نمی‌کنند.
آزمون‌های اختیاری دیگری هم تعریف شده‌اند که کمک می‌کنند مطمئن شوید همه‌ی ورودی‌های معتبر، نتایج معتبر تولید می‌کنند.

برای اجرای آزمون‌های امتیاز، پرچم `#[ignore]` را بردارید و آزمون‌ها را با ویژگی `big-primes` اجرا کنید، به این شکل:

```bash
$ cargo test --features big-primes
```
