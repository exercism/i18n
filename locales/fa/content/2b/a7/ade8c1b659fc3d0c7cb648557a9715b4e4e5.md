# دستورالعمل‌ها

شما روی پروژه‌ای کار می‌کنید که به کاربران اجازه می‌دهد فایل‌ها را روی سرور بارگذاری کنند تا با کاربران دیگر به اشتراک گذاشته شود. به شما سپرده شده است که تابعی بنویسید که بررسی کند یک فایل بارگذاری‌شده با [نوع رسانه][mimetype] آن مطابقت دارد یا نه. کمی تحقیق می‌کنید و متوجه می‌شوید که چند بایت اول یک فایل معمولاً مخصوص همان نوع فایل است و به آن نوعی امضا می‌دهد.

برای مرجع از جدول زیر استفاده کنید:

| نوع فایل | پسوند رایج | نوع رسانه                   | «امضای دودویی»                                   |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. با داشتن یک پسوند، نوع رسانه‌ی مورد انتظار را برگردانید

تابع `type_from_extension/1` را پیاده‌سازی کنید. این تابع باید یک پسوند فایل (رشته) بگیرد و نوع رسانه (رشته) یا `nil` را برگرداند، اگر پسوند با پسوندهای مورد انتظار مطابقت نداشته باشد.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. با داشتن یک فایل دودویی، نوع رسانه‌ی مورد انتظار را برگردانید

تابع `type_from_binary/1` را پیاده‌سازی کنید. این تابع باید یک فایل (دودویی) بگیرد و نوع رسانه (رشته) یا `nil` را برگرداند، اگر امضای فایل با امضاهای مورد انتظار مطابقت نداشته باشد.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

نگران خواندن فایل به‌صورت دودویی نباشید. فرض کنید این کار پیشاپیش برای شما انجام شده است و tests آن را به‌عنوان آرگومان در اختیار شما قرار می‌دهند.

## 3. با داشتن یک پسوند و یک فایل دودویی، بررسی کنید که فایل با نوع مورد انتظار مطابقت دارد

تابع `verify/2` را پیاده‌سازی کنید. این تابع باید یک فایل (دودویی) و یک پسوند (رشته) بگیرد و یک تاپل `:ok` یا `:error` برگرداند.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
