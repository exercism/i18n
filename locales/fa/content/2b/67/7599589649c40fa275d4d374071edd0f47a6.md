# دستورالعمل‌ها

النا، مدیر کیفیت جدید کارخانه‌ی روزنامه، از شما می‌خواهد نرم‌افزار کوچکی بنویسید که سالن تولید را پایش کند.

## 1. تعریف یک خطای سفارشی

با استفاده از واژه‌ی تجزیه‌ی `ERROR:` یک کلاس چندتایی خطا به اسم `machine-error` تعریف کنید. به هیچ اسلاتی نیاز ندارد.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. بررسی رطوبت

`check-humidity` را تعریف کنید. این واژه یک مقدار رطوبت را از پشته برمی‌دارد و وقتی این مقدار اکیداً بزرگ‌تر از `70` باشد، رشته‌ی `"humidity too high"` را `throw` می‌کند. در غیر این صورت، هیچ مقداری برنمی‌گرداند.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. بررسی دما

`check-temperature` را تعریف کنید. این واژه یک مقدار دما را از پشته برمی‌دارد و وقتی این مقدار اکیداً بزرگ‌تر از `500` باشد، رشته‌ی `"temperature too high"` را `throw` می‌کند. در غیر این صورت، هیچ مقداری برنمی‌گرداند.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. پایش دستگاه

`monitor` را طوری تعریف کنید که یک مقدار رطوبت و یک مقدار دما را از پشته بردارد و هر دو بررسی را اجرا کند. اگر هر یک از این بررسی‌ها `throw` کند، `monitor` باید در عوض یک `machine-error` تازه `throw` کند. اگر هر دو با موفقیت بگذرند، `monitor` هیچ مقداری برنمی‌گرداند.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. پایش یک دسته خوانش

`monitor-batch` را طوری تعریف کنید که آرایه‌ای از خوانش‌های `{ humidity temperature }` را بگیرد و برگرداند که چند مورد از آن‌ها شکست می‌خورند (یعنی چند مورد باعث می‌شوند که `monitor` خطا `throw` کند).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
