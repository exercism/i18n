# پیوست دستورالعمل‌ها

## پیاده‌سازی

testها به سازنده‌ای نیاز دارند که یک آرایه دریافت کند. بخش‌های درونی پیاده‌سازی مجموعه‌ی سفارشی شما می‌توانند از ساختارهای داده‌ی دیگر استفاده کنند، اما برای این که testها موفق شوند، ممکن است لازم باشد یک سازنده‌ی بیرونی پیاده‌سازی کنید که دقیقاً یک آرایه دریافت می‌کند.

برای برخی از متدها معادل عملگر یونیکد هم وجود دارد. مثلاً `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` معادل `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])` است.
