# دستورالعمل‌ها

در این تمرین، قرار است به عاشق‌های دوران دبیرستان کمک کنید تا عشق‌شان را در شبکه‌های اجتماعی با ساختن یک قلب یونی‌کد از حروف اول اسم‌شان اعلام کنند:

```
❤ J.  +  M. ❤
```

## 1. اسم را پاک‌سازی کنید

متد `cleanupname` را پیاده‌سازی کنید.
این متد یک اسم می‌گیرد و همه‌ی کاراکترهای `-` را از آن حذف می‌کند و با یک فاصله جای‌گزین می‌کند.
همچنین باید فاصله‌های اضافی را از ابتدا و انتهای اسم حذف کند.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. حرف اول اسم را به دست آورید

متد `firstletter` را پیاده‌سازی کنید.
این متد یک اسم می‌گیرد و حرف اول آن را به‌صورت یک رشته برمی‌گرداند.
حتماً از `cleanupname` که در گام قبلی تعریف کردید دوباره استفاده کنید و آن را با توابع دیگر ترکیب کنید.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. حرف اول را به‌صورت یک حرف اختصاری درآورید

متد `initial` را پیاده‌سازی کنید.
این متد یک اسم می‌گیرد و حرف اول آن را با حروف بزرگ، به‌همراه یک نقطه برمی‌گرداند.
حتماً از `firstletter` که در گام قبلی تعریف کردید دوباره استفاده کنید.

```julia-repl
initial("Robert")
"R."
```

## 4. حروف اختصاری را داخل قلب بگذارید

متد `couple` را پیاده‌سازی کنید.
این متد دو اسم می‌گیرد و حروف اختصاری را با قلب‌های ایموجی در اطراف‌شان برمی‌گرداند.
حتماً از `initial` که در گام قبلی تعریف کردید دوباره استفاده کنید.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
