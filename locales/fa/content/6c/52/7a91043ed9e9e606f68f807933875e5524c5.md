# مقدمه

## شمارشی

نوع `enum` در زبان C# مجموعه‌ای ثابت از ثابت‌های نامدار را نمایش می‌دهد (یک «شمارشی»). هدف اصلی آن فراهم کردن راهی ایمن از نظر نوع برای تعامل با ثابت‌های عددی است و مقادیر در دسترس را به مجموعه‌ای از پیش تعریف‌شده محدود می‌کند. یک شمارشی ساده را می‌توان به شکل زیر تعریف کرد:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

اگر به‌صورت صریح تعریف نشوند، به اعضای شمارشی به‌طور خودکار مقادیر صحیح افزایشی اختصاص می‌یابد که اولین مقدار آن صفر است. همچنین می‌توان مقادیر را به‌صورت صریح اختصاص داد:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
