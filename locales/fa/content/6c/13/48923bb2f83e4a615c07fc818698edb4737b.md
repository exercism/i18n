# از درهم‌آمیزی رشته استفاده کنید، نه قالب‌بندی رشته

در C# روش رایج‌تری هم هست: به‌جای استفاده از `string.Format` برای ساختن یک رشته به‌صورت پویا، از [«درهم‌آمیزی رشته»](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) استفاده کنید.

توجه داشته باشید که درهم‌آمیزی رشته فقط یک ترفند کامپایلر است که به آن «شکر نحوی» هم می‌گویند. یعنی وقتی یک عبارت درهم‌آمیزی رشته کامپایل می‌شود، کامپایلر در واقع آن را به یک فراخوانی `string.Format` تبدیل می‌کند. بنابراین، مزیت استفاده از درهم‌آمیزی رشته صرفاً ظاهری است.
