# مقدمه

## `struct`ها و `class`ها

`struct`ها و `class`ها دو مورد از بلوک‌های اصلی برنامه‌نویسی Swift هستند. هر دوی آن‌ها روشی برای گرد هم آوردن داده‌ها و توابع مرتبط در واحدهای خودبسنده‌ای از کارکرد هستند. وقتی یک `struct` یا `class` تعریف می‌کنید، در واقع یک نوع جدید تعریف می‌کنید که در Swift به کار می‌آید، دقیقاً همان‌طور که از انواعی که تا حالا با آن‌ها کار کرده‌اید استفاده می‌کنید، مانند `Int` و `String`.

`struct`ها و `class`ها در Swift شباهت‌های زیادی به هم دارند. در میان شباهت‌های دیگر، هر دو می‌توانند مقادیر را در «ویژگی»ها نگه دارند و کارکرد خود را از طریق «متد»ها فراهم کنند.

هر کدام قابلیت‌های اضافی دیگری هم دارند که خارج از محدوده‌ی این تمرین است.

### تعریف `struct` و `class`

هر دو تقریباً به یک شکل تعریف می‌شوند. با کلیدواژه‌ی مناسب شروع می‌شوند و پس از آن اسم نوعی می‌آید که تعریف می‌شود، سپس بدنه‌ی `struct` یا `class` در ادامه و بین «آکولاد»ها قرار می‌گیرد.

بدنه می‌تواند از «ویژگی»های ذخیره‌ای تشکیل شده باشد که درست مانند ثابت‌ها یا متغیرهای معمولی تعریف می‌شوند و رفتار می‌کنند.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### نمونه‌ها

همان‌طور که اشاره شد، تعریف یک `struct` یا `class` فقط تعریف یک «نوع» جدید است. این کار فقط نقشه‌ای است برای اینکه مقادیر آن نوع چه شکلی خواهند داشت، اما در واقع هیچ مقداری از آن نوع نمی‌سازد که شما با آن کار کنید.

برای ساختن یک «نمونه» از آن نوع، باید اسم نوع را بنویسید و پس از آن یک جفت پرانتز بگذارید.

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

این کار مقادیری از این نوع‌ها می‌سازد که ویژگی‌هایشان با مقدارهای پیش‌فرضِ داده‌شده در تعریف پر می‌شوند. توجه کنید که در حالت‌های اختیاری مانند ویژگی `name` در `GameCharacter`، اگر مقداری داده نشود، آن ویژگی به‌طور پیش‌فرض `nil` می‌شود، درست مانند تعریف انواع اختیاری معمولی که در آن‌ها مقدار بلافاصله داده نمی‌شود.

در مورد `struct`ها، Swift به‌طور خودکار چیزی به نام «مقدارساز عضو به عضو» فراهم می‌کند که در آن می‌توان مقادیر ویژگی‌های `struct` را داخل پرانتزها داد؛ این مقادیر جای مقدارهای پیش‌فرض تعریف را می‌گیرند.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### دسترسی به ویژگی‌ها

می‌توان با «نشانه‌گذاری نقطه‌ای» به ویژگی‌های `struct` و `class` دسترسی پیدا کرد؛ در این روش، پس از اسم مقدار یک نقطه (`.`) و بعد اسم ویژگی می‌آید. اگر یک ویژگی `struct` یا `class` خودش ویژگی‌هایی داشته باشد، با همین نشانه‌گذاری نقطه‌ای می‌توان به این ویژگی‌های تودرتو هم دسترسی پیدا کرد.

این نشانه‌گذاری هم برای خواندن مقدار ویژگی به کار می‌رود و هم، در جایی که مجاز باشد، برای تغییر آن.

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### متدها

ویژگی‌ها داده را در `struct`ها و `class`های شما نگه می‌دارند؛ در کنار آن‌ها می‌توانید «متد»هایی هم تعریف کنید که توابع را در `struct` یا `class` شما ذخیره می‌کنند.

متدها درست مانند یک تابع معمولی تعریف می‌شوند، فقط داخل بدنه‌ی `struct` یا `class`. توجه کنید که اگر تابعی مقدار یک ویژگی را در یک `struct` تغییر دهد، باید پیش از آن کلیدواژه‌ی `mutating` بیاید. به‌علاوه، اگر متدی بتواند یک ویژگی را تغییر دهد، آن ویژگی باید با `var` تعریف شود، نه `let`، درست مانند متغیرهای معمولی.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

می‌توان این متدها را درست مانند ویژگی‌ها با نشانه‌گذاری نقطه‌ای فراخوانی کرد.

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### `self`

هر نمونه‌ی یک `struct` یا `class` یک ویژگی ضمنی به اسم `self` دارد که به خود آن نمونه اشاره می‌کند.
رایج‌ترین کاربرد `self` رفع ابهام بین یک ویژگی نمونه و پارامتری است که اسم یکسانی دارند:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

انواع Swift یک کلیدواژه‌ی `Self` با حرف بزرگ هم دارند که به *نوعِ* نمونه اشاره می‌کند، نه به خود نمونه.
