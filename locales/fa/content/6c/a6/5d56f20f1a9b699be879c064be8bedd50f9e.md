# دستورالعمل‌ها

در آزمایشگاه تحقیقاتی DNA خود، روش‌های مختلفی را برای فشرده‌سازی داده‌های تحقیقیتان و صرفه‌جویی در فضای ذخیره‌سازی بررسی کرده‌اید. یکی از همکارانتان پیشنهاد می‌کند داده‌های DNA را به یک نمایش دودویی تبدیل کنید:

| اسید نوکلئیک | Code   |
| ------------ | ------ |
| یک فاصله     | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

روی این موضوع تأمل می‌کنید، چون این کار به‌طور بالقوه هزینه‌های ذخیره‌سازی داده‌های موردنیاز را نصف می‌کند، اما به قیمت کاهش خوانایی برای انسان تمام می‌شود. تصمیم می‌گیرید ماژولی بنویسید که داده‌هایتان را کدگذاری و رمزگشایی کند تا میزان صرفه‌جویی را بسنجید.

## 1. کدگذاری اسید نوکلئیک به مقدار دودویی

تابع `encode_nucleotide/1` را طوری پیاده‌سازی کنید که کدپوینت اسید نوکلئیک را بپذیرد و مقدار عدد صحیح کد کدگذاری‌شده را برگرداند.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. رمزگشایی مقدار دودویی به اسید نوکلئیک

تابع `decode_nucleotide/1` را طوری پیاده‌سازی کنید که مقدار عدد صحیح کد کدگذاری‌شده را بپذیرد و کدپوینت اسید نوکلئیک را برگرداند.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. کدگذاری یک charlist از DNA

تابع `encode/1` را طوری پیاده‌سازی کنید که یک charlist نشان‌دهنده‌ی اسیدهای نوکلئیک و فاصله‌ها را بپذیرد و یک bitstring از داده‌های کدگذاری‌شده برگرداند.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. رمزگشایی یک bitstring از DNA

تابع `decode/1` را طوری پیاده‌سازی کنید که یک bitstring نشان‌دهنده‌ی اسیدهای نوکلئیک و فاصله‌ها را بپذیرد و داده‌های رمزگشایی‌شده را به‌صورت یک charlist برگرداند.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
