# بازه

[بازه‌ها][range] فاصله‌ای بین دو مقدار را نمایش می‌دهند.
رایج‌ترین نوع‌هایی که از بازه پشتیبانی می‌کنند `Integer` و `String` هستند.
از آن‌ها می‌توان برای کاربردهای متعددی استفاده کرد؛ مانند ساختن سریع یک مجموعه، برش رشته‌ها، بررسی اینکه مقداری داخل یک بازه هست یا نه، و پیمایش.
بازه‌ها با عملگر بازه‌ی `..` یا `...` ساخته می‌شوند (به‌ترتیب شامل و غیرشامل).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

دلیل وجود دو عملگر بازه این است که بتوان بازه‌هایی ساخت که مقدار پایانی را شامل می‌شوند یا نمی‌شوند؛ این موضوع مثلاً وقتی با اندیس‌هایی کار می‌کنیم که از صفر شروع می‌شوند مفید است.

بازه‌ها را می‌توان با سازنده‌ی `Range`، یعنی `new`، هم ساخت.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
وقتی در Ruby با عملگرهای بازه‌ی `..` یا `...` یک بازه می‌سازید و می‌خواهید متدی را روی آن بازه فراخوانی کنید، باید بازه را داخل پرانتز بگذارید.
دلیلش این است که در غیر این صورت، متد روی دومین آرگومانِ عملگر بازه فراخوانی می‌شود.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## گرفتن زیررشته‌ها

وقتی می‌خواهید رشته‌ای را برش دهید، می‌توانید با عملگر بازه یک زیررشته به دست آورید.
یعنی با ساختن بازه‌ای از اندیس شروع و پایان زیررشته.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

همچنین می‌توانید با اندیس‌های منفی، زیررشته را از انتهای رشته به دست آورید.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## متدهای بازه

بازه‌ها مجموعه‌ای از متدها دارند که برای کار با آن‌ها به کار می‌روند.
برای مثال، با این متدها می‌توان مجموع همه‌ی مقادیر یک بازه را به دست آورد یا بررسی کرد که آیا بازه مقدار مشخصی را شامل می‌شود یا نه.

| متد                  | توضیح                                                             | مثال                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | مجموع همه‌ی مقادیر بازه را برمی‌گرداند                          | `(1..5).sum # => 15`            |
| [`size`][size]          | اندازه‌ی بازه را برمی‌گرداند                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | اگر بازه مقدار داده‌شده را شامل شود `true` و در غیر این صورت `false` را برمی‌گرداند | `(1..5).include?(3) # => true` |

## بازه‌های بی‌پایان و بدون آغاز

یک بازه می‌تواند بی‌پایان و بدون آغاز باشد.
در بازه‌ی بی‌پایان یا بدون آغاز، مقدار شروع یا پایان `nil` است، اما هنگام تعریف بازه می‌توان `nil` را حذف کرد.

استفاده از بازه‌های بدون آغاز و بی‌پایان وقتی مفید است که مثلاً بخواهید رشته‌ای را از ابتدا یا تا انتها برش دهید.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
اگر بازه‌ی بی‌پایان روی یک مجموعه به کار نرود، در صورت بی‌احتیاطی می‌تواند به دنباله‌ای بی‌پایان منجر شود.
~~~~

## بازه‌های رشته‌ای

از رشته‌ها نیز می‌توان در بازه‌ها استفاده کرد؛ به این ترتیب، بازه‌ای از رشته‌ها میان دو رشته به دست می‌آید.
رفتار آن با بعضی رشته‌های خاص کمی غیرمنتظره است، پس با احتیاط از آن استفاده کنید.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
