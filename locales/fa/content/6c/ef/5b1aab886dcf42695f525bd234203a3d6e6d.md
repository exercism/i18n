# مقدمه

بسیاری از زبان‌های برنامه‌نویسی انواع عددی خاصی برای نمایش انواع مختلف اعداد دارند، اما JavaScript فقط دو نوع دارد:

- `number`: یک نوع داده‌ی عددی در قالب ممیز شناور دقت دوگانه‌ی ۶۴ بیتی (IEEE 754).
  نمونه‌ها: `-6`، `-2.4`، `0`، `0.1`، `1`، `3.14`، `16.984025`، `25`، `976`، `1024.0` و `500000`.
- `bigint`: یک نوع داده‌ی عددی که می‌تواند _اعداد صحیح_ را در قالب دقت دلخواه نمایش دهد.
  نمونه‌ها: `-12n`، `0n`، `4n` و `9007199254740991n`.

اگر به [دقت دلخواه][ref-arbitrary-precision] نیاز دارید یا با اعداد بسیار بزرگ کار می‌کنید، از نوع `bigint` استفاده کنید.
در غیر این صورت، احتمالاً نوع `number` گزینه‌ی بهتر است.

## گرد کردن

یک شیء سراسری از پیش تعریف‌شده به اسم `Math` وجود دارد که [توابع گرد کردن][ref-math-object-rounding] مختلفی ارائه می‌دهد. برای مثال، می‌توانید اعداد اعشاری را به پایین (`floor`) یا به بالا (`ceil`) و به نزدیک‌ترین عدد صحیح گرد کنید.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
