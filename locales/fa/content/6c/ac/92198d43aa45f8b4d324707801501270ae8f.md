# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که نشان کارمندان کارخانه را چاپ کند.

## 1. چاپ نشان برای یک کارمند

کارمندان یک شناسه، یک اسم و یک اسم بخش دارند. برچسب‌های نشان کارمندان به این شکل قالب‌بندی می‌شوند: `"[id] - name - DEPARTMENT"`. متد (_static_) `Badge.Print()` را پیاده‌سازی کنید تا برچسب نشان یک کارمند را برگرداند:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

توجه کنید که اسم بخش روی برچسب باید با حروف بزرگ نوشته شود.

## 2. چاپ نشان برای یک کارمند تازه

به دلیل یک ایراد عجیب در سیستم رایانه‌ای، کارمندان تازه گاهی وقتی کار در کارخانه را شروع می‌کنند هنوز شناسه ندارند. چون نشان الزامی است، یک نشان موقت بدون پیشوند شناسه دریافت می‌کنند. متد (_static_) `Badge.Print()` را تغییر دهید تا از کارمندان تازه‌ای که هنوز شناسه ندارند پشتیبانی کند:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. چاپ نشان برای مالک

حتی مالک کارخانه هم باید همیشه نشان بپوشد. با این حال، مالک بخشی ندارد. در این حالت، برچسب باید به جای اسم بخش، `"OWNER"` را چاپ کند. متد (_static_) `Badge.Print()` را تغییر دهید تا برچسب مالک را چاپ کند:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

توجه کنید که ممکن است مالک هم کارمند تازه باشد:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
