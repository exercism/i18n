# Tests

بیشتر testها بررسی می‌کنند که شما با انتساب دادن به [result] یا با فرستادن یک مقدار به [exit]، مقدار مورد انتظار را برمی‌گردانید.

برخی testها بررسی می‌کنند که استثنای مورد انتظار را [raise] کنید.

## اجرای testها

برای اجرای testها به ابزار `make` نیاز دارید.

از داخل پوشه‌ی تمرین، در یک کنسول/ترمینال تایپ کنید:

```sh
make
```

اگر به فایل راه‌حل تمرین دست هم نزده باشید، پیامی شبیه این می‌بینید:

```
Please implement your solution.
```

پس پیش از شروع نوشتن راه‌حل، این خط را حذف کنید.

به صورت پیش‌فرض فقط اولین test اجرا می‌شود.

```text
TAP version 14
1..10
ok 1 - ...
```

برای اجرای همه‌ی testها، این را تایپ کنید:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

وقتی همه‌ی testها با موفقیت اجرا شدند، کار تمرین تمام شده و می‌توانید راه‌حل را ارسال کنید.

می‌توانید با دادن شماره‌ی متناظر، یک test مشخص را برای اجرا انتخاب کنید، برای مثال:

```sh
make test=2
```

فقط دومین test را اجرا می‌کند.
