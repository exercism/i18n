# راهنمایی‌ها

## عمومی

- برای این تمرین‌ها به [عبارت‌های شرطی][concept-conditionals] نیاز خواهید داشت.

## 1. مقایسه‌ی نویسه‌ها

- نویسه‌ها را می‌توان با توابعی مانند `char-greaterp`، `char-lessp` و `char=` مقایسه کرد.

## 2. تعیین «اندازه»ی نویسه

- Common Lisp دو تابع دارد که تعیین می‌کنند یک نویسه بزرگ است یا کوچک: `upper-case-p` و `lower-case-p`.
- یک نویسه می‌تواند نه بزرگ باشد و نه کوچک.

## 3. تغییر «اندازه»ی نویسه

- Common Lisp برای تغییر بزرگ یا کوچک بودن یک نویسه دو تابع دارد: `char-upcase` و `char-downcase`.

## 4. تعیین «نوع» نویسه

- Common Lisp یک تابع محمولی به اسم `alpha-char-p` دارد که تعیین می‌کند یک نویسه الفبایی است یا نه.
- Common Lisp یک تابع محمولی به اسم `digit-char-p` دارد که تعیین می‌کند یک نویسه عددی است یا نه.
- می‌توانید از `char=` استفاده کنید تا بفهمید دو نویسه با هم برابرند یا نه.
- نویسه‌ی فاصله در Common Lisp به‌صورت `#\Space` نوشته می‌شود.
- نویسه‌ی خط جدید در Common Lisp به‌صورت `#\Newline` نوشته می‌شود.
