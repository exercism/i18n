# مقدمه

## عبارت شرطی

**عبارت شرطی** در `jq` به شکل `if A then B else C end` است.

`if-then-else` مانند همه‌ی توابع توکار `jq` یک فیلتر است: یک ورودی می‌گیرد و یک خروجی تولید می‌کند.

اگر عبارت `A` مقدار «درست‌نما» تولید کند، فیلتر `if` عبارت `B` را ارزیابی می‌کند.
در غیر این صورت، عبارت `C` را ارزیابی می‌کند.
ورودی فیلتر `if` به `B` یا `C` پاس داده می‌شود.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
بند `else` **اختیاری** است؛ دو دستور زیر معادل‌اند.

```jq
if A then B else . end
if A then B end
```
~~~~

## دستورهای شرطی تودرتو

شرط‌های بیشتری را می‌توان با `elif` اضافه کرد.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

هر تعداد بند `elif` که لازم دارید، استفاده کنید.

## درست‌نمایی

تنها مقادیر «غلط» در `jq` این‌ها هستند: `false` و `null`.
هر مقدار دیگری «درست» است، حتی عدد صفر و رشته‌ی خالی، آرایه و شیء.

## عملگرهای منطقی

از **عملگرهای منطقی** `and` و `or` می‌توان برای ساخت پرس‌وجوهای پیچیده استفاده کرد.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

برای نقیض کردن، از `not` استفاده کنید. این یک **فیلتر** است، نه یک عملگر.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## عملگر جایگزین

**عملگر جایگزین** به شما امکان می‌دهد اگر یک عبارت «غلط» یا `null` باشد، یک مقدار «پیش‌فرض» را مشخص کنید.

```jq
A // B

# This is identical to
if A then A else B end
```

برای نشان دادن

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
