# آرایه

`ARRAY{T}` یک ردیف ثابت از مقدارهایی از نوع `T` است.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## آکولادها

`ARRAY{STR}` را «آرایه‌ای از `STR`» می‌خوانیم. آکولادها جای یک **«پارامتر نوع»** را نگه می‌دارند: `ARRAY` به‌تنهایی یک نوع نیست، چون آرایه باید آرایه‌ای از چیزی باشد. بخش بزرگی از کتابخانه‌ی Sather به همین شکل ساخته شده است و نوشتن چنین کلاسی را خودتان بعداً یاد می‌گیرید.

## موقعیت‌ها

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

موقعیت‌ها از `0` تا `.size - 1` هستند. آرایه اندازه‌ی خود را می‌داند و هرگز آن را عوض نمی‌کند: چیزی به نام افزودن به `ARRAY` وجود ندارد.

## ساختن آرایه بدون لیترال

`#ARRAY{INT}(n)` آرایه‌ای از `n` مقدار می‌سازد که هر کدام صفرند:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

انتساب به یک موقعیت، از همان کروشه‌های مربع در سمت چپ `:=` استفاده می‌کند.

## خارج از محدوده

خواندن یا نوشتن موقعیتی که وجود ندارد، در یک ساخت معمولی بررسی نمی‌شود. برنامه را با یک پیام راهنما متوقف نمی‌کند؛ هر چیزی را که تصادفاً در حافظه کنار آن باشد می‌خواند یا می‌نویسد. دو عادت این مشکل را برطرف می‌کنند: به‌جای عددی که با چشم شمرده‌اید از `.size - 1` استفاده کنید، و حلقه‌ها را به‌جای یک لیترال با `until!(i >= a.size)` به پایان ببرید.

## چاپ کردن آرایه

`.str` محتویات را داخل آکولاد برمی‌گرداند، که هنگام کار کردن روی یک مسئله به کار می‌آید:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
