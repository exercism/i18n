# دستورالعمل‌ها

در این تمرین شما خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با این قالب: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه کار دارید که هرکدام یک خط لاگ می‌گیرد و از شما می‌خواهد کاری با آن انجام دهید.

## 1. گرفتن پیام از یک خط لاگ

تابع `message` را طوری پیاده‌سازی کنید که پیام یک خط لاگ را برگرداند:

```julia-repl
julia> message("[ERROR]: Invalid operation")
"Invalid operation"
```

هر فاصله‌ی سفید ابتدایی یا انتهایی باید حذف شود:

```julia-repl
julia> message("[WARNING]:  Disk almost full\r\n")
"Disk almost full"
```

## 2. گرفتن سطح لاگ از یک خط لاگ

تابع `log_level` را طوری پیاده‌سازی کنید که سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```julia-repl
julia> log_level("[ERROR]: Invalid operation")
"error"
```

## 3. قالب‌بندی دوباره‌ی یک خط لاگ

تابع `reformat` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند؛ به این صورت که پیام را اول و سطح لاگ را بعد از آن داخل پرانتز قرار می‌دهد:

```julia-repl
julia> reformat("[INFO]: Operation completed")
"Operation completed (info)"
```

----

***توجه:***  همه‌ی رشته‌ها در این تمرین انگلیسی هستند و به مجموعه‌ی نویسه‌های ASCII محدود می‌شوند.
مفاهیم بعدی فرصتی فراهم می‌کنند تا با نویسه‌های یونیکد کار کنید.
