# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | ورودی     | آدرس | آرایه‌ی وزن عنصرها      |
| `$a1`    | ورودی     | آدرس | آرایه‌ی مقدار عنصرها       |
| `$a2`    | ورودی     | عدد صحیح | تعداد عنصرها            |
| `$a3`    | ورودی     | عدد صحیح | حداکثر وزن             |
| `$v0`    | خروجی    | عدد صحیح | حداکثر مقدار              |
| `$t0-9`  | موقت | هر نوع     | برای ذخیره‌سازی موقت استفاده می‌شود |
