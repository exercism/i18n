# مقدمه

منظور ما از _زبان_، **AWK** است و از _برنامه‌ی اجرایی‌ای_ که برنامه‌های AWK را تفسیر می‌کند، **`awk`** یا **`gawk`**.

## الگوها و کنش‌ها

یک برنامه‌ی AWK از **جفت‌های الگو-کنش** تشکیل شده است

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

یک **الگو** می‌تواند یک الگوی عبارت باقاعده باشد که با ورودی مطابقت داده می‌شود.
همچنین می‌تواند هر عبارتی باشد که نتیجه‌اش یک مقدار «درست» یا «غلط» است.

یک **کنش** یک یا چند دستور AWK است.
آکولادهای پیرامون آن الزامی‌اند.

اگر نتیجه‌ی الگو _درست_ باشد، کنش متناظر با آن ارزیابی می‌شود.

## رکوردها و فیلدها

AWK ورودی را به‌صورت مجموعه‌ای از **رکوردها** تجزیه می‌کند.
هر رکورد به صفر یا چند **فیلد** تقسیم می‌شود.

رفتار پیش‌فرض چنین است:

- تقسیم ورودی به رکوردها با استفاده از خط جدید به‌عنوان «جداکننده‌ی رکورد»، به این ترتیب هر _خط_ یک رکورد است.
- تقسیم رکورد به فیلدها با استفاده از فاصله‌ی خالی به‌عنوان «جداکننده‌ی فیلد»، به این ترتیب هر _واژه_ یک فیلد است.

## الگوها و کنش‌ها، ادامه

می‌توان الگو را حذف کرد؛ در این صورت کنش _برای هر رکورد ورودی_ ارزیابی می‌شود.

می‌توان کنش را حذف کرد؛ در این صورت کنش پیش‌فرض چاپ رکورد جاری است.

### الگوهای ویژه

دو الگوی ویژه وجود دارد که اغلب استفاده می‌شوند.

- `BEGIN` کنش مرتبط را پیش از مصرف هر ورودی ارزیابی می‌کند.
- `END` کنش مرتبط را پس از مصرف تمام ورودی ارزیابی می‌کند.

## متغیرهای فیلد

برای اشاره به فیلدها از `$1`، `$2`، `$3` و غیره استفاده می‌کنید.

رکورد جاری `$0` است.

در ادامه چند متغیر توکار پرکاربرد دیگر را می‌بینید.

### متغیرهای توکاری که تجزیه‌ی ورودی را کنترل می‌کنند

- `RS` جداکننده‌ی رکورد ورودی است.
  همان‌طور که اشاره شد، مقدار پیش‌فرض آن یک خط جدید است.
- `FS` جداکننده‌ی فیلد ورودی است.

این متغیرها اغلب در بلوک کنش `BEGIN` تعیین می‌شوند.

### متغیرهای توکاری که اطلاعات را منتقل می‌کنند

این متغیرها به‌طور خودکار توسط AWK در حین اجرای برنامه تعیین می‌شوند.

- `NF` تعداد فیلدهای رکورد جاری را ذخیره می‌کند.
  - برای گرفتن مقدار آخرین فیلد، از `$NF` استفاده کنید.
- `NR` شماره‌ی رکورد جاری را ذخیره می‌کند.
  - وقتی چندین فایل ورودی پردازش می‌شود، `NR` تعداد کل رکوردهای پردازش‌شده تا این لحظه را نگه می‌دارد.
- `FNR` شماره‌ی رکورد جاری در فایل ورودی جاری را ذخیره می‌کند.
  - برای نشان دادن تفاوت میان NR و FNR، در ادامه یک اصطلاح رایج AWK می‌آید.
    ```awk
    NR == FNR {action}
    ```
    این یعنی: «اگر شماره‌ی رکورد انباشته با شماره‌ی رکورد فایل جاری برابر باشد.»
    این تنها برای رکوردهای _اولین فایل ورودی_ می‌تواند درست باشد.

## درست‌بودن

AWK همان مفهوم درست‌بودن زبان C را به کار می‌برد.

- عدد `0` غلط است.
- هر عدد دیگری درست است.

از آنجا که AWK یک زبان پردازش متن است، مقادیر درستی به رشته‌ها نیز تعمیم داده می‌شوند.

- یک رشته‌ی خالی `""` غلط است.
- هر رشته‌ی ناتهی درست است.

## کامنت‌ها

کامنت‌ها با کاراکتر `#` آغاز می‌شوند و تا پایان خط ادامه می‌یابند.

## مثال‌ها

در سیستم‌های شبیه یونیکس، فایل `/etc/passwd` اطلاعات مربوط به کاربران را در خود دارد.
هر کاربر در یک خط جداگانه توصیف می‌شود و فیلدهایش با دونقطه از هم جدا می‌شوند.

برای فهرست کردن نام‌های کاربری:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

توجه کنید که کنش `{print $1}` هیچ الگویی ندارد، بنابراین برای هر رکورد اجرا می‌شود.

اگر بخواهیم خروجی را فقط به کاربرانی محدود کنیم که bash را به‌عنوان پوسته‌ی ورود خود به کار می‌برند، می‌توانیم این کار را انجام دهیم:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
