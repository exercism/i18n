# از `gofmt` استفاده نشده

`gofmt` را روی راه‌حل اجرا کنید، که به قالب‌بندی کد در Go کمک می‌کند.

قالب‌بندی کد در Go برای جامعه‌ی Go بسیار مهم است.
بیشتر IDEها را می‌توان طوری تنظیم کرد که با هر بار ذخیره، کد را به‌طور خودکار قالب‌بندی کنند. برای مثال:

- Visual Studio Code [پشتیبانی عالی از Go](https://code.visualstudio.com/docs/languages/go) دارد
- Vim هم [افزونه‌ی فوق‌العاده‌ی Go](https://github.com/fatih/vim-go) دارد
- [Jetbrains Goland](https://www.jetbrains.com/go/) یک IDE کامل برای Go است

برای اجرای دستی `gofmt`:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
