# عملگر سه‌گانه

عملگر سه‌گانه روش دیگری برای انجام یک مقایسه‌ی `if..else..` و برگرداندن یک مقدار فراهم می‌کند.

## نحوه‌ی نگارش

PHP یک دستور شرطی دارد که می‌توان با آن، یک کار را بر اساس درست بودن یک شرط ارزیابی کرد.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

از طرف دیگر، عملگر سه‌گانه می‌تواند همین عملیات را نشان دهد:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

نحوه‌ی نگارش این مقایسه کوتاه است و به صورت `(condition) ? (evaluate if true) : (evaluate if false);` نوشته می‌شود.
