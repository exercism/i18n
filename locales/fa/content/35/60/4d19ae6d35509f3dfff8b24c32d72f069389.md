# مقدمه

وقتی یک «نقل‌قول» لازم دارد مقادیری را از محیط اطرافش *به خاطر بسپارد* (چیزی که زبان‌های دیگر آن را closure می‌نامند)، Factor از دو ابزار استفاده می‌کند: واژه‌ی `curry` و روش نگارش *fry* با `'[ ]`.

## `curry`: ثبت یک مقدار

`curry` (در [`kernel`][kernel]) یک مقدار و یک نقل‌قول می‌گیرد و نقل‌قولی تازه برمی‌گرداند که آن مقدار در آن گنجانده شده است:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

`curry` را دو بار به کار ببرید تا دو مقدار ثبت کنید:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: به هم پیوستن دو نقل‌قول

`compose` (در [`kernel`][kernel]) دو نقل‌قول را به هم می‌چسباند:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## نقل‌قول‌های fry: ثبت چند مقدار

برای بیش از یکی دو مورد ثبت، فراخوانی‌های زنجیره‌ای `curry` خواندنشان سخت می‌شود. *fry* از `'[ … ]` با یک یا چند نشانه‌ی جانگهدار `_` استفاده می‌کند؛ هر `_` با مقداری که به ترتیب از پشته‌ی داده برداشته می‌شود جایگزین می‌گردد:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

هم `curry` و هم fry همان لحظه‌ای که closure ساخته می‌شود مقادیرشان را از پشته *مصرف می‌کنند*. خط بالا چیزی روی پشته باقی نمی‌گذارد و جانشینی مستقیم برای `[ + + ] curry curry` است.

جانگهدارها از چپ به راست با مقادیر پشته از پایین به بالا پر می‌شوند: `2 3 '[ _ _ ]` همان `[ 2 3 ]` است، نه `[ 3 2 ]`.

fry همچنین *به داخل* نقل‌قول‌های تودرتو نفوذ می‌کند و همین به شما امکان می‌دهد مقادیر ثبت‌شده را دقیقاً همان جایی بگذارید که می‌خواهید:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

`_` داخل `[ … ]` درونی قرار دارد، اما fry باز هم آن را پر می‌کند.

## `call` با اثری اعلام‌شده

وقتی در نهایت یک نقل‌قول ذخیره‌شده را اجرا می‌کنید، اثر پشته‌ای‌اش را روی `call` اعلام کنید تا کامپایلر بتواند نوعش را بررسی کند:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## حساب برداری

واژگان [`math.vectors`][math.vectors] دو دنباله‌ی هم‌اندازه را عضو‌به‌عضو ترکیب می‌کند. `v+` و `v*` آن‌ها را جمع یا ضرب می‌کنند؛ `vmax` و `vmin` بزرگ‌تر یا کوچک‌تر هر مؤلفه را نگه می‌دارند. هر کدام یک آرایه‌ی دوعنصری برمی‌گرداند:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
