# راهنما

## دستورالعمل‌های ویژه‌ی این مسیر

سعی کنید از تکرار کد پرهیز کنید و اگر می‌توانید، از توابع کمکی خصوصی استفاده کنید.

و برای خوانایی بهتر، شاید بهتر باشد به‌جای `if-else` از یک عبارت `Boolean` استفاده کنید.
برای اینکه ببینید این کار چطور انجام می‌شود، [اینجا](http://cs.wellesley.edu/~cs111/spring00/lectures/boolean-simplification.html) را ببینید (این پیوند مربوط به Java است، اما البته این منطق برای Scala هم معتبر است).
