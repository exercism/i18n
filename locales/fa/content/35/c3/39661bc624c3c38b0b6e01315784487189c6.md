# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به شما در آماده شدن برای خرید خودرو کمک می‌کند.

سه کار پیش رو دارید: تعیین کنید که آیا به گواهینامه نیاز دارید؛ بین دو خودرو انتخاب کنید؛ و قیمت منصفانه‌ی یک خودروی دست‌دوم را تخمین بزنید.

## 1. تعیین کنید که آیا به گواهینامه‌ی رانندگی نیاز دارید

برخی از انواع خودروها برای راندن به گواهینامه‌ی رانندگی نیاز دارند.
فرض کنید فقط انواع `"car"` و `"truck"` به گواهینامه نیاز دارند؛ بقیه را می‌توان بدون گواهینامه راند.

تابع `needs_license` را پیاده‌سازی کنید که نوع خودرو را می‌گیرد و یک مقدار «منطقی» برمی‌گرداند که نشان می‌دهد آیا برای آن نوع خودرو به گواهینامه نیاز دارید یا نه.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. انتخاب بین دو خودرویی که می‌توانید بخرید

گزینه‌های خودروهای در دسترس را بررسی کرده‌اید.
توانسته‌اید آن‌ها را به دو گزینه محدود کنید، اما برای گرفتن تصمیم نهایی به کمک نیاز دارید.
تابع `choose_vehicle` را پیاده‌سازی کنید که آرایه‌ای از دو خودرو را به‌عنوان ورودی می‌گیرد و یک تصمیم را برمی‌گرداند: گزینه‌ای که در ترتیب واژه‌نامه‌ای اول می‌آید.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. تخمین قیمت یک خودروی دست‌دوم را محاسبه کنید

حالا که تصمیم‌تان را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی خودرو را با قیمت منصفانه می‌خرید.
چون می‌خواهید یک خودروی دست‌دوم بخرید، قیمت به سن خودرو بستگی دارد.
برای یک تخمین تقریبی، فرض کنید اگر خودرو کمتر از ۳ سال سن داشته باشد، قیمتش ۸۰٪ قیمت اصلی آن هنگام نو بودن است.
اگر بیش از ۱۰ سال سن داشته باشد، ۵۰٪.
اگر خودرو حداقل ۳ سال سن داشته باشد اما بیشتر از ۱۰ سال نباشد، ۷۰٪ قیمت اصلی است.

تابع `resell_price` را پیاده‌سازی کنید که این منطق را با استفاده از `if`، `elif` و `else` اعمال می‌کند.
این تابع شیئی را می‌گیرد که قیمت اصلی و سن خودرو را در خود دارد و قیمت تخمینی در نمایندگی را برمی‌گرداند.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
