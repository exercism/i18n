## درک لیست

درک لیست ابزاری برای تبدیل «Enumerables» به شکلی آسان و اعلانی فراهم می‌کند.

برای تعریف یک درک لیست بسیار ساده، از کلیدواژه‌ی `for` استفاده می‌کنیم که پس از آن یک «مولد» و یک بلوک `do` می‌آید؛ بلوک `do` مقادیر تازه را از مقادیر شمارش‌شده می‌سازد.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

درک لیست می‌تواند «فیلتر» هم داشته باشد. مقادیری که از فیلتر عبور نمی‌کنند از لیست نهایی حذف می‌شوند:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

می‌توانیم درک لیست‌های پیچیده‌تری را در چند خط تعریف کنیم:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

با استفاده از چند مولد می‌توان یک «ضرب دکارتی» ساخت. یعنی هر مقداری که مولد اول تولید می‌کند، یک بار با هر مقداری که مولد دوم تولید می‌کند جفت می‌شود:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
