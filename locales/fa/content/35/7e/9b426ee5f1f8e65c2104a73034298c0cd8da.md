# یکپارچه‌سازی‌های ویرایشگر متن Babashka

## nREPL

### Emacs: [CIDER](https://cider.mx/)

این همان افزونه‌ای است که همه‌چیز از آن آغاز شد و اکوسیستم [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) آن به بسیاری از افزونه‌های دیگر توان می‌بخشد.

1. [Emacs](https://www.gnu.org/software/emacs/download.html) را برای سیستم‌عامل خود نصب کنید.

2. یکی از توزیع‌های موجود Emacs را انتخاب کنید ([Prelude](https://prelude.emacsredux.com/)، [Spacemacs](https://www.spacemacs.org/) و [Doom Emacs](https://github.com/hlissner/doom-emacs) هر سه عالی‌اند) یا این را به `init.el` خود اضافه کنید:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

به‌طور خلاصه از [مستندات CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

سرور nREPL را از پوشه‌ی پروژه راه‌اندازی کنید:

```bash
$ bb --nrepl-server
```

هر فایل Clojure (`.clj`) را با `C-x C-f` بسازید یا باز کنید و با `C-c C-x c j` (cider-connect-clj) به آن وصل شوید.

[کلیدهای میانبر پایه‌ی CIDER](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` یا `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` یا `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. [VSCode](https://code.visualstudio.com/) را نصب کنید.

2. [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva) را نصب کنید.

در حال حاضر، Calva کد شما را در بافت یک پوشه، یعنی یک پروژه‌ی Clojure، در نظر می‌گیرد. روش خوبی برای ساختن یکی از آن‌ها استفاده از [clj-new](https://github.com/seancorfield/clj-new) است:

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. سرور nREPL را از پوشه‌ی پروژه راه‌اندازی کنید:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

پوشه‌ی پروژه را در VSCode باز کنید (Ctrl+K Ctrl+O) یا از ترمینالی دیگر این کار را انجام دهید:

```bash
$ cd bbtest
bbtest$ code .
```

4. در VSCode، فرمان Calva یعنی `Connect to a running REPL` را اجرا کنید (ctrl+alt+c ctrl+alt+c). وقتی از شما پرسیده شد، پروژه‌ی `Generic` را انتخاب کنید و `localhost:1667` را وارد کنید.

فرمان‌های REPL:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. IntelliJ را از [اینجا](https://www.jetbrains.com/idea/download/index.html) دانلود کنید.
2. Cursive را با دنبال کردن [راهنمای کاربر](https://cursive-ide.com/userguide/) نصب کنید و [وابستگی‌ها را پیکربندی کنید](https://cursive-ide.com/userguide/deps.html).
3. برای اطلاعات بیشتر [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html) را ببینید.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/) را نصب کنید

2. بسته‌ی `chlorine` را نصب کنید

3. REPL سوکت را راه‌اندازی کنید:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. پالت فرمان Atom را باز کنید (ctrl+shift+p) و فرمان `Connect Clojure Socket REPL` را با `localhost` و `1666` اجرا کنید

5. کلیدهای میانبر را در keymap.cson از طریق منوی `Edit` -> `Keymap...` ویرایش کنید:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

برای Emacs، [inf-clojure](https://github.com/clojure-emacs/inf-clojure) را با افزودن این به `init.el` خود نصب کنید:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

REPL سوکت را مانند بالا راه‌اندازی کنید و در Emacs فرمان `M-x inf-clojure-connect` را اجرا کنید (C-c M-c).

فرم‌ها را با C-c C-e ارزیابی کنید. برای دیدن فهرست همه‌ی فرمان‌های موجود در inf-clojure-mode (که به آن REPL هم می‌گویند) و inf-clojure-minor-mode می‌توانید C-h f RET inf-clojure-mode و C-h f RET inf-clojure-minor-mode را فراخوانی کنید یا به‌سادگی منوهایشان را مرور کنید.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

[Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) را دانلود کنید و برای آن نام مستعار `vim` تعریف کنید.

* [vim-plug](https://github.com/junegunn/vim-plug) را نصب کنید:

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

فایل `~/.config/nvim/init.vim` را بسازید:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Neovim را باز کنید و فرمان `:PlugInstall` را اجرا کنید.

فرمان `iced` را به $PATH اضافه کنید:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* سرور REPL سوکت را راه‌اندازی کنید، فایل مبدأ را باز کنید و `:IcedConnectSocketRepl 1666` را اجرا کنید.

فرمان‌های پیش‌فرض REPL (مقدار پیش‌فرض `<Leader>` همان `\` است):

- `<Leader>ei` : ارزیابی عنصر درونی
- `<Leader>ee` : ارزیابی لیست بیرونی
- `<Leader>et` : ارزیابی فهرست سطح بالای بیرونی
