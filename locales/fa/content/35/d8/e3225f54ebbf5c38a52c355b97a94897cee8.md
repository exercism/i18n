# مقدمه

این تمرین به برخی جزئیات پارامترهای متد و کاربرد آن‌ها در C# می‌پردازد.

پارامترها اطلاعات را از یک متد فراخوانی‌کننده به متد فراخوانی‌شده منتقل می‌کنند.

- رفتار پارامترها را می‌توان با استفاده از «اصلاحگر»هایی مانند `ref` و `out` تغییر داد.

- پارامتری که اصلاحگر `out` دارد، مقداری را از متد فراخوانی‌شده به فراخوانی‌کننده برمی‌گرداند. این پارامتر را می‌توان بدون مقداردهی اولیه به متد فراخوانی‌شده فرستاد و در هر حالت، داخل متد فراخوانی‌شده با آن طوری رفتار می‌شود که گویی هنگام ورود مقداردهی نشده است. درک رفتار و قواعد مربوط به اصلاحگرهای پارامتر را می‌توانید به‌سادگی از طریق مثال‌ها (پایین را ببینید) و پیام‌های کامپایلر به دست آورید.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- پارامترهای `out` باید درون متد فراخوانی‌شده مقداردهی شوند.

- پارامتری که اصلاحگر `ref` دارد، مقداری را به متد فراخوانی‌شده می‌فرستد. وقتی متد بازگردد، فراخوانی‌کننده هر به‌روزرسانی‌ای را که متد فراخوانی‌شده در آن پارامتر انجام داده است، مشاهده خواهد کرد.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- پارامترهای `ref` باید متغیر باشند، چون متد فراخوانی‌شده مستقیماً روی همان پارامتری کار می‌کند که فراخوانی‌کننده می‌بیند.
- اصلاحگرهای `out` و `ref` هم در امضای متد فراخوانی‌شده و هم در محل فراخوانی لازم هستند.
