# استفاده از مشخصات نوع

[comment]: # (این هشدار زمانی داده می‌شود که راه‌حل مشخصات نوع نداشته باشد)

[مشخصات نوع](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) را هم بنویسید تا قرارداد میان ورودی‌ها و خروجی تابع مشخص شود.

- Elixir زبانی با نوع‌دهی پویا است، یعنی بررسی نوع فقط در زمان اجرا انجام می‌شود. نوشتن مشخصات نوع به لینترها و ابزارهای تحلیل ایستا مانند [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (که بر پایه‌ی [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) در Erlang ساخته شده است) اجازه می‌دهد کد را از نظر رفتارهای ناخواسته بررسی کنند.
- [فهرست کامل](https://hexdocs.pm/elixir/typespecs.html#basic-types) همه‌ی انواع توکار را می‌توانید در [مستندات زبان](https://hexdocs.pm/elixir/typespecs.html#content) ببینید.
- انواع را می‌توان با پرانتز یا بدون آن نوشت: `atom()` در برابر `atom`
  - سبک Exercism در Elixir این است که مشخصات را بدون پرانتز بنویسید.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
