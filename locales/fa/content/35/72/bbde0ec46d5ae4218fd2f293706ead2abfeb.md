# حلقه

**حلقه** یک کار را بارها و بارها انجام می‌دهد.

```sather
   loop
      ...
   end;
```

حلقه به‌تنهایی هرگز متوقف نمی‌شود، پس باید داخلش دستوری باشد که آن را پایان دهد.

## جایی برای نگه داشتن شمارش

یک حلقه تقریباً همیشه به مقداری نیاز دارد که در طول اجرا تغییر می‌کند. این مقدار یک **متغیر** است و `::=` چنین متغیری را می‌سازد:

```sather
   total ::= 0;
```

اسم این متغیر `total` است، از `0` شروع می‌شود و Sather از همان `0` می‌فهمد که نوع آن `INT` است. بعد از آن، `:=` مقدار تازه‌ای در آن می‌گذارد:

```sather
   total := total + 5;
```

این خط را از راست به چپ بخوانید: مقدار فعلی `total` را بردارید، ۵ را به آن اضافه کنید و پاسخ را دوباره در `total` بگذارید.

عمر متغیری که این‌طور ساخته شود، تا پایان «روتین» ادامه دارد.

## until!

`until!` یک پرسش می‌گیرد. هر بار که حلقه دور می‌زند، این پرسش پرسیده می‌شود و وقتی پاسخ «درست» باشد، حلقه همان‌جا متوقف می‌شود.

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

`n` به ترتیب ۱، ۲، ۳ و ... را می‌شمارد و حلقه نخستین باری که `n` از `last` بگذرد، پایان می‌یابد. اگر `n := n + 1` نبود، پاسخ این پرسش هرگز تغییر نمی‌کرد و حلقه تا ابد ادامه پیدا می‌کرد.

`until!` لازم نیست اولین خط باشد. آن را همان جایی بگذارید که پرسش معنادار است: در بالای حلقه، ممکن است حلقه اصلاً اجرا نشود؛ در پایین، همیشه دست‌کم یک بار اجرا می‌شود.

`!` بخشی از اسم است. Sather بعضی موارد را این‌طور علامت می‌زند؛ معنای این علامت را بعداً می‌بینید.

## break!

`break!` حلقه را بی‌درنگ و بدون هیچ پرسشی پایان می‌دهد. وقتی دلیل توقف در میانه‌ی کار پیدا می‌شود، به کار می‌آید.

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

`until!` و `break!` فقط درون یک `loop` معنا پیدا می‌کنند. هیچ‌کدام به‌تنهایی قابل استفاده نیستند.
