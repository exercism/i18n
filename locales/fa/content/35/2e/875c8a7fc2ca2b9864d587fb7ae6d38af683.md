# مقدمه

برای به اشتراک گذاشتن code بین ماژول‌های مختلف Elixir در همان پروژه، باید به ماژول بیرونی با اسم کاملش ارجاع دهید. اما اگر آن اسم خیلی طولانی یا گیج‌کننده باشد چه؟

«فرم خاص `alias`» به شما اجازه می‌دهد اسمی را که با آن به یک ماژول بیرونی ارجاع می‌دهید کوتاه کنید یا تغییر دهید. وقتی بدون هیچ آرگومانی استفاده شود، اسم ماژول را به آخرین بخشش کوتاه می‌کند، مثلاً `MyApp.Logger.Settings` به `Settings` تبدیل می‌شود. یک اسم سفارشی را می‌توان با گزینه‌ی `:as` مشخص کرد.

معمولاً `alias`ها در ابتدای تعریف ماژول اضافه می‌شوند.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```
