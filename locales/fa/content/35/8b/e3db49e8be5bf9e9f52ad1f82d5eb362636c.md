# درباره

کاراکترهای Factor *اعداد صحیح* هستند، یعنی کدپوینت‌های یونیکد؛ بنابراین `<`، `>` و `=` که مقایسه‌های عددی ساده‌ای هستند، از قبل ترتیب حساس به بزرگی و کوچکی حروف را به شما می‌دهند. واژگان [`unicode`][unicode] نیز محمول‌های آگاه به یونیکد و تبدیل بزرگی و کوچکی حروف برای یک کاراکتر را به آن اضافه می‌کند.

## محمول

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## تبدیل بزرگی و کوچکی حروف

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

نسخه‌های سطح رشته‌ای `>upper`، `>lower` و `>title` این تبدیل‌ها را روی همه‌ی کاراکترهای یک رشته اعمال می‌کنند.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
