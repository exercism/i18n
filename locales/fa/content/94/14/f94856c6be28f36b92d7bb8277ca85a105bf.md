# مقدمه

## حلقه‌ی For

دستور `for` یک «بلوک کد» را تکرار می‌کند.
خط اول آن کنترل می‌کند که این بلوک چند بار تکرار شود:

```go
for init; condition; post {
    // loop body
}
```

- دستور **مقداردهی اولیه** یک بار پیش از نخستین تکرار اجرا می‌شود. معمولاً یک متغیر شمارنده که حلقه از آن استفاده می‌کند، اعلان و مقداردهی اولیه می‌شود.
- **شرط** یک عبارت «منطقی» است که پیش از هر تکرار ارزیابی می‌شود. حلقه زمانی متوقف می‌شود که این عبارت به `false` ارزیابی شود.
- دستور **پسین** پس از هر تکرار کامل اجرا می‌شود. می‌توان از آن برای به‌روزرسانی شمارنده استفاده کرد.

`init; condition; post` را داخل پرانتز قرار ندهید.
با این حال، آکولادهایی که بدنه‌ی حلقه را در بر می‌گیرند همیشه لازم هستند.

این حلقه `i` را از `1` شروع می‌کند، مقدار جاری `i` را چاپ می‌کند، آن را برای تکرار بعدی افزایش می‌دهد و زمانی که `i` به `10` برسد متوقف می‌شود:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
