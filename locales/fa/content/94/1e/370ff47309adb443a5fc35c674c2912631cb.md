# هزینه‌های بزرگ پایگاه داده

## بیان مسئله

ABC Corp از شما می‌خواهد که اسم و دپارتمان کارمندانی را پیدا کنید که ورودی‌های پرداختی‌شان از یک مبلغ مشخص (مثلاً `3000.00`) بیشتر است.

برای برگرداندن داده‌های موردنیاز، رکوردی به اسم `HighPayment` بسازید. تعریف رکورد به این شکل است.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

برای گرفتن داده‌های موردنیاز از پایگاه داده، از عملیات `query` کلاینت JDBC استفاده کنید.

> توجه: نتیجه را بر اساس `payment_id` به ترتیب صعودی مرتب کنید.

## جزئیات پایگاه داده

برای این مسئله از پایگاه داده‌ی H2 ارائه‌شده استفاده کنید.

> فایل پایگاه داده‌ی نمونه `gofigure.mv.db` است و اسم پایگاه داده `gofigure` است. این فایل در پوشه‌ی `db` قرار دارد.

جدول‌های زیر از قبل با چند داده‌ی نمونه در پایگاه داده‌ی نمونه‌ی H2 وجود دارند. نام ستون‌ها و نوع داده‌ها در ادامه آمده است.

**اسم جدول** : `Employee`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحیح، کلید اصلی با افزایش خودکار       |
| `name`            | رشته        |
| `city`            | رشته        |
| `department`      | رشته        |
| `age`             | عدد صحیح        |

**اسم جدول**: `Payment`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحیح، کلید اصلی با افزایش خودکار       |
| `date`            | تاریخ        |
| `amount`          | عدد اعشاری        |
| `employee_id`     | عدد صحیح        |
| `reason`          | رشته        |

* فایل پایگاه داده `gofigure.mv.db` است. از نشانی JDBC به شکل `jdbc:h2:file:/path/to/db/file` استفاده کنید
* نام کاربری: `root`
* رمز عبور: `root`

## محدودیت‌ها

* برای اعتبارسنجی کوئری‌ها و نمونه‌ی Ballerina از فایل پایگاه داده‌ی H2 که در پوشه‌ی `db` ارائه شده استفاده کنید
* از رویکرد پارامترهای وابستگی maven استفاده کنید تا درایور پایگاه داده‌ی H2 را به‌عنوان یک وابستگی پلتفرمی در Ballerina.toml خود اضافه کنید

## محیط آزمون

* می‌توانید آزمون‌ها را با `bal test` اجرا کنید که روی پایگاه داده‌ی نمونه‌ی داده‌شده اجرا می‌شود.

## راهنماها

* برای کار با پایگاه داده از ماژول [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) استفاده کنید
* برای مراحل افزودن درایور JDBC به‌عنوان یک وابستگی، به بخش [پیشنیاز](https://lib.ballerina.io/ballerinax/java.jdbc/latest) مراجعه کنید
* برای گرفتن کوئری از پایگاه داده از متد راه دور [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) استفاده کنید
* به مثال [کوئری ساده](https://ballerina.io/learn/by-example/mysql-query-operation) مراجعه کنید
* برای دسترسی به داده‌ها از نوع [stream](https://ballerina.io/learn/by-example/stream-type) در Ballerina استفاده کنید
* برای یافتن مجموعه‌داده‌ی موردنیاز از پایگاه داده، از joinهای SQL استفاده کنید
