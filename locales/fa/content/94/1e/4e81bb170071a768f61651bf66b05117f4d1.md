# مقدمه

`str` در Python یک [توالی تغییرناپذیر][text sequence] از [نقاط کد یونیکد][unicode code points] است.
این نقاط میتوانند شامل حروف، نشانههای تلفظی، نویسههای موقعیتدهی، اعداد، نمادهای واحد پول، ایموجی، نشانهگذاری، فاصلههای مختلف، شکستن خط و موارد دیگر باشند.

رشتهها همهی [عملیات متداول توالی][common sequence operations] را پیادهسازی میکنند و میتوان با استفاده از نحوهی نگارش `for item in <str>` یا `for index, item in enumerate(<str>)` روی آنها پیمایش کرد.
میتوان آنها را با `<str> + <other str>` یا `<str>.join(<iterable>)` به هم چسباند، با `<str>.split(<separator>)` تقسیم کرد و گزینههای متعددی برای قالببندی و سرهمبندی ارائه میدهند.

برای کار بیشتر با رشتهها، Python مجموعهی غنیای از [متدهای رشته][str-methods] ارائه میدهد که میتواند در جستوجو، پاکسازی، تبدیل، ترجمه و بسیاری از عملیات دیگر کمک کند.

از آنجا که _تغییرناپذیر_ است، مقدار یک شیء `str` در حافظه تغییر نمیکند؛ متدهایی که به نظر میرسد رشته را تغییر میدهند، یک رونوشت یا نمونهی جدید از همان شیء `str` برمیگردانند.
