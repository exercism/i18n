# دستورالعمل‌ها

در این تمرین، منطق ماجراجویی یک بازی RPG جدید را پیاده‌سازی می‌کنید که دوستتان در حال ساخت آن است.

شخصیت اصلی بازی آنالین است، دختری شجاع با یک سگ خانگی بی‌باک و وفادار. متأسفانه فاجعه‌ای رخ می‌دهد: بهترین دوستش هنگام جست‌وجوی توت‌ها در جنگل دزدیده شد.

آنالین تلاش می‌کند بهترین دوستش را پیدا کند و آزادش کند، و در این ماجراجویی به اختیار خود سگش را همراه می‌برد.

پس از مدتی که رد بهترین دوستش را دنبال می‌کند، اردوگاهی را می‌یابد که دوستش در آن زندانی است. معلوم می‌شود دو آدم‌ربا وجود دارند: یک شوالیه‌ی نیرومند و یک کماندار حیله‌گر.

آنالین پس از یافتن آدم‌رباها، در نظر می‌گیرد که کدام‌یک از کارهای زیر را می‌تواند انجام دهد:

- _حمله‌ی سریع_: حمله‌ی سریع زمانی ممکن است که شوالیه خواب باشد، چون پوشیدن زره برایش وقت می‌گیرد و در نتیجه آسیب‌پذیر خواهد بود.
- _جاسوسی_: اگر دست‌کم یکی از آنان بیدار باشد می‌توان از گروه جاسوسی کرد. در غیر این صورت، جاسوسی اتلاف وقت است.
- _علامت دادن به زندانی_: اگر زندانی بیدار و کماندار خواب باشد، می‌توان با صداهای پرندگان به زندانی علامت داد، چون کمانداران در علامت‌دهی با پرندگان آموزش دیده‌اند و می‌توانند پیام را رهگیری کنند.
- _آزاد کردن زندانی_: آنالین می‌تواند تلاش کند دزدکی به اردوگاه وارد شود تا زندانی را آزاد کند.
  این کار پرخطر است و فقط به یکی از دو روش می‌تواند موفق شود:
  - اگر آنالین سگش را همراه داشته باشد، در صورتی که کماندار خواب باشد می‌تواند زندانی را نجات دهد.
    شوالیه از سگ می‌ترسد و کماندار فرصت نمی‌کند آماده شود، پیش از آنکه آنالین و زندانی بتوانند فرار کنند.
  - اگر آنالین سگش را همراه نداشته باشد، باید خودش و زندانی بسیار دزدکی عمل کنند!
    آنالین می‌تواند زندانی را آزاد کند اگر زندانی بیدار باشد و شوالیه و کماندار هر دو خواب باشند، اما اگر زندانی خواب باشد نمی‌توان نجاتش داد: ظاهر ناگهانی آنالین زندانی را غافلگیر می‌کند و شوالیه و کماندار را بیدار می‌کند.

شما چهار وظیفه دارید: پیاده‌سازی منطقی که بر پایه‌ی وضعیت سه شخصیتی که در جنگل یافت می‌شوند و اینکه سگ آنالین حاضر است یا نه، تعیین کند آیا کارهای بالا در دسترس هستند یا نه.

## 1. بررسی اینکه آیا حمله‌ی سریع ممکن است

متد `canFastAttack()` را پیاده‌سازی کنید که یک مقدار «منطقی» می‌گیرد و نشان می‌دهد آیا شوالیه بیدار است. این متد اگر بر پایه‌ی وضعیت شوالیه حمله‌ی سریع ممکن باشد، `true` برمی‌گرداند. در غیر این صورت، `false` برمی‌گرداند:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. بررسی اینکه آیا می‌توان از گروه جاسوسی کرد

متد `canSpy()` را پیاده‌سازی کنید که سه مقدار منطقی می‌گیرد و به‌ترتیب نشان می‌دهد آیا شوالیه، کماندار و زندانی بیدار هستند. این متد اگر بر پایه‌ی وضعیت سه شخصیت جاسوسی از گروه ممکن باشد، `true` برمی‌گرداند. در غیر این صورت، `false` برمی‌گرداند:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. بررسی اینکه آیا می‌توان به زندانی علامت داد

متد `canSignalPrisoner()` را پیاده‌سازی کنید که دو مقدار منطقی می‌گیرد و به‌ترتیب نشان می‌دهد آیا کماندار و زندانی بیدار هستند. این متد اگر بر پایه‌ی وضعیت آن دو شخصیت علامت دادن به زندانی ممکن باشد، `true` برمی‌گرداند. در غیر این صورت، `false` برمی‌گرداند:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. بررسی اینکه آیا می‌توان زندانی را آزاد کرد

متد `canFreePrisoner()` را پیاده‌سازی کنید که چهار مقدار منطقی می‌گیرد. سه پارامتر اول به‌ترتیب نشان می‌دهند آیا شوالیه، کماندار و زندانی بیدار هستند. پارامتر آخر نشان می‌دهد آیا سگ آنالین حاضر است. این متد اگر بر پایه‌ی وضعیت سه شخصیت و حضور سگ آنالین آزاد کردن زندانی ممکن باشد، `true` برمی‌گرداند. در غیر این صورت، `false` برمی‌گرداند:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
