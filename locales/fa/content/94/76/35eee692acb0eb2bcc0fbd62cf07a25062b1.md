# دستورالعمل‌ها

شما یک الف هستید که در بخش لجستیک بابانوئل کار می‌کنید و رئیس دو کار را برای ارتقای نرم‌افزار سیستم به شما سپرده است.

## 1. گرفتن اسم اسباب‌بازی

سیستم باید بتواند اسم یک اسباب‌بازی را از پایگاه داده بگیرد.
پایگاه داده از تاپل‌هایی از نوع `(name: String, quantity: Int)` ساخته شده است.

تابع `getName(_:)` را پیاده‌سازی کنید؛ این تابع پارامتری می‌گیرد که یک تاپل از نوع `(name: String, quantity: Int)` را در خود دارد.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. افزودن اسباب‌بازی جدید به پایگاه داده

بازار اسباب‌بازی، بازاری سریع و در حال تغییر است و اینکه چه اسباب‌بازی‌ای محبوب است، خیلی سریع عوض می‌شود.
به همین دلیل، به تابعی نیاز است که یک اسباب‌بازی جدید بسازد.

تابع `createToy(name:amount:)` را پیاده‌سازی کنید؛ این تابع دو پارامتر می‌گیرد: `name` که اسم اسباب‌بازی را نگه می‌دارد و `amount` که تعداد اسباب‌بازی را نگه می‌دارد.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. به‌روزرسانی تعداد یک اسباب‌بازی

الف‌های کارگاه بابانوئل مدام اسباب‌بازی بیشتری می‌سازند و بابانوئل باید تعداد هر اسباب‌بازی را پیگیری کند.
برای این کار، سیستم باید بتواند تعداد یک اسباب‌بازی را در پایگاه داده به‌روزرسانی کند.

تابع `updateQuantity(_:toy:Amount:)` را پیاده‌سازی کنید؛ این تابع پارامترهای زیر را می‌گیرد:
- `toys` که آرایه‌ای از تاپل‌های نوع `(name: String, quantity: Int)` را نگه می‌دارد.
- `toy` که اسم اسباب‌بازی‌ای را نگه می‌دارد که باید به‌روزرسانی شود.
- `amount` که تعداد جدید اسباب‌بازی را نگه می‌دارد.

می‌توانید فرض کنید که اسباب‌بازی از قبل در پایگاه داده وجود دارد و نیازی به بررسی آن نیست.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. افزودن کلید دسته‌بندی به یک اسباب‌بازی

بابانوئل می‌خواهد بتواند اسباب‌بازی‌های پایگاه داده را دسته‌بندی کند.
هدف این است که وقتی بابانوئل باید ارسال انجام دهد، به‌راحتی اسباب‌بازی‌ها را پیدا کند و بتواند اسباب‌بازی‌های پایگاه داده را مرتب کند.

اما وقتی سیستم برای اولین بار پیاده‌سازی شد، کلید دسته‌بندی فراموش شد.
حالا سیستم باید بتواند کلید دسته‌بندی را به یک اسباب‌بازی در پایگاه داده اضافه کند.

تابع `addCategory(_:category:)` را پیاده‌سازی کنید؛ این تابع پارامترهای زیر را می‌گیرد:
- `toys` که آرایه‌ای از تاپل‌های نوع `(name: String, quantity: Int)` را نگه می‌دارد.
- `category` که کلید دسته‌بندی‌ای را نگه می‌دارد که باید به اسباب‌بازی‌ها اضافه شود.

می‌توانید فرض کنید که اسباب‌بازی از قبل در پایگاه داده وجود دارد و نیازی به بررسی آن نیست.
همچنین می‌توانید فرض کنید که از قبل هیچ کلید دسته‌بندی‌ای در اسباب‌بازی وجود ندارد.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
