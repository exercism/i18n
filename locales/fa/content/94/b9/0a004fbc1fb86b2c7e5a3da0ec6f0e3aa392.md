# مقدمه

مقدارهای «منطقی» در Cairo با نوع منطقی از پیش تعریف‌شده‌ی `bool` نمایش داده می‌شوند که مقدارهایش می‌توانند `true` یا `false` باشند.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo از سه عملگر منطقی پشتیبانی می‌کند که می‌توانند عبارت‌ها را به مقدارهای منطقی ارزیابی کنند و `true` یا `false` برگردانند.

| عملگر    | معنی آن                                 |
| ----------- | --------------------------------------------- |
| `&&` (و)  | اگر هر دو عبارت درست باشند، نتیجه «درست» است.       |
| `\|\|` (یا) | اگر حداقل یکی از عبارت‌ها درست باشد، نتیجه «درست» است. |
| `!` (نه)   | فقط وقتی نتیجه «درست» است که عبارت «غلط» باشد.    |
