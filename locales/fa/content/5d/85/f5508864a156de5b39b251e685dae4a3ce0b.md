# مقدمه

یک پارامتر متد را می‌توان با اختصاص دادن یک «مقدار پیش‌فرض» اختیاری کرد. وقتی متدی با «پارامترهای اختیاری» فراخوانی می‌شود، لازم نیست فراخوانی‌کننده مقداری برایشان پاس بدهد. اگر مقداری برای یک پارامتر اختیاری پاس داده نشود، مقدار پیش‌فرض آن استفاده می‌شود.

پارامترهای اختیاری _باید_ در انتهای فهرست پارامترها باشند؛ پارامتر غیراختیاری نمی‌تواند بعد از آن‌ها بیاید.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
