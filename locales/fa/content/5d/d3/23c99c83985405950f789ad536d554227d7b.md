# مقدمه

در SQL، دستور `SELECT` به شما اجازه می‌دهد داده‌ها را از یک پایگاه داده بازیابی کنید.
نتیجه‌ی یک دستور `SELECT`، یک «مجموعه‌ی نتیجه» است.
مجموعه‌ی نتیجه مقدارهایی را در خود دارد که در سطرها و ستون‌ها چیده شده‌اند.
هر ستون، یک ویژگی مشخص از داده‌هاست.
هر سطر برای هر ستون یک مقدار دارد.

برای درک آن می‌توان این‌طور فکر کرد که مجموعه‌ای از ستون‌ها یک «ساختار داده» را نمایش می‌دهد؛ هر ستون یکی از فیلدهای آن ساختار داده است و هر سطر یک نمونه از آن ساختار به شمار می‌رود.

با دستور `SELECT` می‌توانید مشخص کنید چه داده‌ای را می‌خواهید بازیابی کنید.
همچنین می‌توانید به‌صورت اختیاری داده‌های خروجی را تبدیل کنید، فیلتر کنید و شکلشان را تغییر دهید.

## اصول پایه

ساختار کلی یک دستور `SELECT` ساده به این صورت است:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
بندهای `FROM` و `WHERE` اختیاری هستند.
برای مثال، دستوری مانند `SELECT "Hello, world.";` کاملاً معتبر است.

همچنین توجه داشته باشید که وجود شکست خط الزامی نیست؛ هر فاصله‌ای برای جدا کردن بندهای مختلف (یعنی بخش‌های مختلف) دستور `SELECT` کافی است.
~~~~

بلافاصله پس از «کلیدواژه»ی `SELECT`، فهرستی از ستون‌هایی می‌آید که می‌خواهید در نتیجه داشته باشید.
بند `FROM` منبع داده‌ها را مشخص می‌کند که معمولاً یک جدول در پایگاه داده است.
بند `WHERE` داده‌های خروجی را بر اساس یک یا چند معیار فیلتر می‌کند.

## فیلتر کردن داده‌ها با بند `WHERE`

بند `WHERE` به شما اجازه می‌دهد داده‌هایی را که با دستور `SELECT` بازیابی شده‌اند فیلتر کنید.
برای مثال، اگر فقط داده‌های `Appliances` را بخواهیم، می‌توانیم به این صورت عمل کنیم:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

نتیجه:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

یا شاید فقط داده‌هایی را بخواهیم که وزنشان بین 2.0 و 6.0 است:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```
