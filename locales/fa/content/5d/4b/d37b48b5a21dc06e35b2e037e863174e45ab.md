# مقدمه

نحوه‌ی «تجزیه‌ی آرایه» در JavaScript روشی مختصر است برای استخراج مقدارها از یک آرایه و اختصاص دادن آن‌ها به متغیرهای جداگانه.

در این مثال، هر مقدار در آرایه‌ی `numberOfMoons` به سیاره‌ی متناظرش اختصاص داده می‌شود:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
