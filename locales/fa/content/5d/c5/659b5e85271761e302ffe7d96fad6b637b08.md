# مقدمه

گاهی وقتی یک تابع آرگومان‌های زیادی می‌گیرد، به خاطر سپردن ترتیبی که باید آرگومان‌ها را بدهید دشوار می‌شود. برای کمک به خوانایی، Gleam اجازه می‌دهد آرگومان‌ها با یک «برچسب» مشخص شوند.

برای برچسب‌گذاری یک آرگومان، اسم برچسب را پیش از اسم آرگومان بیاورید و آن دو را با یک فاصله از هم جدا کنید.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

وقتی تابعی را با آرگومان‌های برچسب‌دار فراخوانی می‌کنید، می‌توانید آرگومان‌ها را به هر ترتیبی بدهید. هر یک از این فراخوانی‌های `replace` معادل‌اند:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

برچسب‌ها همیشه اختیاری‌اند. حتی اگر یک تابع آرگومان‌های برچسب‌دار داشته باشد، باز هم می‌توان آن را بدون برچسب فراخوانی کرد.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
