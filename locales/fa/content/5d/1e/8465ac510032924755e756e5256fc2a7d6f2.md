# مقدمه

مفاهیم «هم‌وردایی» و «پادوردایی» در PHP مهم‌اند، چون PHP هنگام ارث‌بری از کلاس‌ها یا رابط‌ها، رعایت این قواعد را الزامی می‌کند.

هم‌وردایی رابطه‌ی میان دو نوع را حفظ می‌کند، در حالی که پادوردایی آن رابطه را معکوس می‌کند. به طور خلاصه، یعنی هنگام ارث‌بری از کلاس‌ها و بازنویسی توابع، می‌توانید نوع‌هایی خاص‌تر یا کلی‌تر را برای پارامترهای متدتان مجاز کنید و از متد نوع‌هایی خاص‌تر یا کمتری برگردانید.

## مثال‌ها

کلاس زیر را در نظر بگیرید:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

اگر از کلاس ارث‌بری کنیم، می‌توانیم نوع‌های بیشتری از پارامترها را نسبت به آنچه در ابتدا اعلام شده مجاز کنیم، اما نمی‌توانیم چیزی جز نوع‌های بازگشتی اصلی را برگردانیم.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

کلاس مشتق‌شده‌ی زیر معتبر نیست، چون برگرداندن نوع‌های اضافی یا گسترده‌تر مجاز نیست:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
