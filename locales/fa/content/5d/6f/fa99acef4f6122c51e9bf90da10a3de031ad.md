# اجرای testها

## دانلود یک تمرین

برای دانلود تمرینی که می‌خواهید روی آن کار کنید، از [Exercism CLI][cli] استفاده کنید.

```sh
exercism download --track=dart --exercise=hello-world
```

سپس به پوشه‌ی تمرین بروید.

```sh
cd /path/to/exercism/dart/hello-world
```

## نصب وابستگی‌ها

پیش از اجرای testها، وابستگی‌های تمرین را دانلود کنید.

```sh
dart pub get
```

## اجرای testها

```sh
dart test
```

## درک نتایج test

`dart test` به‌صورت پیش‌فرض از گزارشگر فشرده استفاده می‌کند و شمارش پیوسته‌ی testهای پاس‌شده، ردشده و ناموفق را در یک خط نشان می‌دهد.

```sh
$ dart test
00:00 +1 -1: test/binary_search_test.dart: finds a value in the middle of an array [E]
  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
```

- `+1`: ۱ test پاس شد
- `~9`: ۹ test رد شد
- `-1`: ۱ test ناموفق بود

## پیش بردن testها

بیشتر تمرین‌ها چندین test دارند و به‌صورت پیش‌فرض همه به‌جز اولی رد شده‌اند.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

برای پیش بردن testها یکی‌یکی، هر بار `skip: true` را در هر test به `skip: false` تغییر دهید.
در عوض، می‌توانید همه‌ی testها را یک‌جا و بدون تغییر فایل اجرا کنید.

```sh
dart test --run-skipped
```

هنگام ارسال، همه‌ی testها، از جمله testهای ردشده، توسط اجراکننده‌ی test آنلاین اجرا می‌شوند.

## برخورد با خطای «Could not find a command named frontend_server.dart.snapshot»

فرض کنید تمرینی را قبلاً حل کرده و ارسال کرده‌اید و بعد از مدتی دوباره سراغ آن آمده‌اید.
ممکن است هنگام اجرای test آن با این خطا روبه‌رو شوید:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

[راه‌حل][solution] این است که فایل `pubspec.lock` را حذف کنید.
سپس دستور `dart` را دوباره اجرا کنید.

[solution]: https://stackoverflow.com/q/79247335/7552
