# مقدمه

Ruby یک [زبان شیءگرای][object-oriented-programming] پویا است.
همهچیز در Ruby یک [شیء][object] است.

در Ruby دو روش اصلی برای اختصاص دادن شیءها به اسم وجود دارد: استفاده از متغیر یا ثابت.
متغیرها همیشه با [snake case][snake-case] نوشته میشوند.
یک متغیر میتواند در طول عمرش به شیءهای مختلفی اشاره کند.
برای مثال، `my_first_variable` را میتوان با عملگر `=` چندین بار تعریف و از نو تعریف کرد:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

اما ثابتها قرار است فقط یک بار مقدار بگیرند.
آنها باید با حرف بزرگ شروع شوند و معمولاً بهصورت همهحروفبزرگ نوشته میشوند و کلمهها با زیرخط از هم جدا میشوند.

برای مثال:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby بهصورت کلاسها سازماندهی شده است.
کلاسها با کلیدواژهی `class` و سپس اسم کلاس تعریف میشوند.
شیءها معمولاً با نمونهسازی از کلاسها به کمک متد `.new` ساخته میشوند.

برای مثال:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

واحدهای کارکردی در متدها کپسوله میشوند، مشابه _توابع_ در زبانهای دیگر.
یک متد میتواند بهصورت اختیاری با آرگومانهای مکانی و/یا آرگومانهای کلیدواژهای تعریف شود؛ آرگومانهای کلیدواژهای با نحوهی نگارش `:` تعریف و فراخوانی میشوند.
متدها یا بهصورت ضمنی نتیجهی آخرین دستور ارزیابیشده را برمیگردانند، یا میتوانند بهصورت صریح یک شیء را با کلیدواژهی `return` برگردانند.
متدها با نحوهی نگارش `.` فراخوانی میشوند.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
