# دستورالعمل‌ها

یک دزد دریایی در حال طراحی مسیری روی نقشه‌ای از خلیج‌های پنهان است. این نقشه یک جدول هش است که کلیدش اسم خلیج است؛ هر مقدار آرایه‌ای از خلیج‌هایی است که می‌توانید مستقیماً از آن یکی به آن‌ها برسید.

## 1. خالی کردن صف جزر

تابع `tide-queue` را طوری تعریف کنید که آرایه‌ای از عنصرها بگیرد، هر عنصر را به ترتیب به یک `deque` تازه اضافه کند و سپس همه را دوباره بیرون بکشد و در آرایه‌ای بریزد که ترتیب اولیه را حفظ می‌کند. این همان الگوی FIFO است: افزودن به انتها، برداشتن از ابتدا.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. خلیج‌های قابل‌دسترسی

تابع `coves-reachable` را طوری تعریف کنید که یک خلیج مبدأ و یک نقشه بگیرد و یک مجموعه‌ی هش از همه‌ی خلیج‌های قابل‌دسترسی از `start` برگرداند، از جمله خودِ `start`.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

برای مرز BFS از یک `<dlist>` استفاده کنید و برای مجموعه‌ی بازدیدشده از یک `HS{ }`.

## 3. شمارش گام‌ها

تابع `hop-count` را طوری تعریف کنید که یک خلیج مبدأ، یک خلیج مقصد و یک نقشه بگیرد و کمترین تعداد گام بین آن دو را برگرداند، یا اگر دسترسی به مقصد ممکن نیست `f` را برگرداند.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

هر خلیج را همراه با فاصله‌اش از مبدأ در `deque` نگه دارید (آرایه‌ای با ۲ عنصر کار می‌کند).

## 4. شمارش طلا

در کد اولیه، `gold-count` با `:` اعلام شده است. آن را به `MEMO:` تغییر دهید (نه `:`)، تا نتیجه‌ی هر خلیج یک بار محاسبه و ذخیره شود. مقدار طلای خلیج را در ثابت `gold-distribution` که تمرین در اختیار شما می‌گذارد جست‌وجو کنید. خلیجی که در این توزیع نباشد، طلا ندارد.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. مسیر گنج

تابع `treasure-route` را طوری تعریف کنید که یک خلیج مبدأ و یک نقشه بگیرد و خلیج قابل‌دسترسی‌ای را برگرداند که بیشترین طلا را دارد. از `coves-reachable` در وظیفه‌ی ۲ و `gold-count` در وظیفه‌ی ۴ استفاده کنید.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

تابع `gold-count` که نتیجه‌اش یک بار محاسبه و ذخیره شده است، جست‌وجوهای تکراری را بدون هزینه نگه می‌دارد؛ این وقتی به کار می‌آید که چند بخش از الگوریتم به یک خلیج مراجعه کنند.
