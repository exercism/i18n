# درباره

کتابخانه‌های کلاس پایه‌ی .NET کلاس [`Regex`][regex] را برای پردازش «عبارات باقاعده» ارائه می‌دهند.

این [مقاله][regex-comparison] را برای مقایسه‌ی C# با دیگر گونه‌های عبارات باقاعده ببینید.

## گروه‌های ضبط

جنبه‌ای که باید در نظر بگیرید، «گروه‌های ضبط» است که بخش‌هایی از متن را برمی‌گردانند که با بخش‌های مختلف الگوی عبارت باقاعده منطبق‌اند. روش کار با گروه‌های ضبط نیاز به عادت کردن دارد. این [مستندات][capture] را ببینید.

توجه داشته باشید که سلسله‌مراتبی وجود دارد که گروه‌های ضبط، `(?<capture-name>pattern)`، در آن دخیل‌اند:

- که در آن مجموعه‌ای از صفر یا بیشتر «تطبیق» برگردانده می‌شود (یکی برای هر تطبیق پیداشده در متن).
- هر تطبیق شامل چند گروه ضبط است
- هر گروه شامل چند «ضبط» است.

علاوه بر این:

- `Match` از `Group` مشتق می‌شود
- `Group` از `Capture` مشتق می‌شود

نکات احتیاطی:

- امن‌ترین روش، استفاده از ضبط‌های نام‌گذاری‌شده است.
- گروه‌های ضبط معمولاً در مجموعه‌ی `Groups` و به همان ترتیبی که در متن ظاهر می‌شوند، قرار می‌گیرند.
- `Groups[0]` ظاهراً به کل تطبیق مربوط است.
- `Groups[<capture name>].Value` تقریباً قطعاً همان چیزی است که به آن علاقه‌مند هستید. ضبط‌های تکی (به‌جز `Caputures[0]`) اگر وجود داشته باشند، ظاهراً برای مقاصد تشخیصی در نظر گرفته شده‌اند.

## گزینه‌های Regex

با [`RegexOptions`][regex-options] آشنا شوید.

علاوه بر گزینه‌های معمول `IgnoreCase`، گزینه‌هایی هم برای `MultiLine` وجود دارد که برای پردازش چند خط متن به‌صورت یک‌جا مفید است. همچنین `IgnorePatternWhitespace` که وقتی با «رشته‌های ورباتیم»، درج متغیر در رشته و کامنت‌ها همراه شود، می‌تواند همان‌طور که در این نمونه نشان داده شده است، بسیار گویا باشد:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

گزینه‌ی قابل توجه دیگر، `RegexOptions.Compiled` برای عبارت‌های باقاعده‌ی [کامپایل‌شده][regex-compilation] است.
