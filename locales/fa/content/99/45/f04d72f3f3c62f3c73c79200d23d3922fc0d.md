# دستورالعمل

توجه: این تمرین ادامه‌ی تمرین `need-for-speed` است.

در این تمرین، شما مسابقه‌هایی بین انواع مختلف ماشین‌های کنترلی ترتیب می‌دهید.
هر ماشین سرعت و ویژگی‌های مصرف باتری خودش را دارد.

ماشین‌ها با باتری کاملاً پر (۱۰۰٪) شروع می‌کنند.
هر بار که ماشین را با کنترل از راه دور می‌رانید، به اندازه‌ی سرعت ماشین متر جلو می‌رود و به اندازه‌ی مصرف باتری‌اش از درصد باتری باقی‌مانده کم می‌شود.

اگر باتری ماشین کمتر از درصد مصرف باتری آن باشد، دیگر نمی‌توانید ماشین را برانید.

ماشین کنترلی یک نمایشگر LED شیک دارد که دو مورد اطلاعات را نشان می‌دهد:

- مسافت کل طی‌شده، که به این شکل نمایش داده می‌شود: `"Driven <METERS> meters"`.
- شارژ باقی‌مانده‌ی باتری، که به این شکل نمایش داده می‌شود: `"Battery at <PERCENTAGE>%"`.

هر پیست مسابقه مسافت خودش را دارد.
ماشین‌ها با بررسی اینکه آیا می‌توانند پیست را بدون تمام شدن باتری به پایان برسانند، آزمایش می‌شوند.

## 1. ماشین را برانید

متد `Drive` را روی `Car` پیاده‌سازی کنید که تعداد مترهای طی‌شده را بر اساس سرعت ماشین به‌روزرسانی می‌کند و باتری را بر اساس مصرف باتری کاهش می‌دهد:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

توجه: اگر انجام این کار باعث شود باتری ماشین زیر ۰ برود، نباید سعی کنید ماشین را برانید.

## 2. مسافت طی‌شده را نمایش دهید

یک متد `DisplayDistance` روی `Car` پیاده‌سازی کنید تا مسافت را همان‌طور که روی نمایشگر LED نمایش داده می‌شود، به‌صورت یک `string` برگرداند:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. درصد باتری را نمایش دهید

متد `DisplayBattery` را روی `Car` پیاده‌سازی کنید تا درصد باتری را همان‌طور که روی نمایشگر LED نمایش داده می‌شود، به‌صورت یک `string` برگرداند:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. بررسی کنید که آیا یک ماشین کنترلی می‌تواند مسابقه را به پایان برساند

برای تمام کردن یک مسابقه، ماشین باید بتواند مسافت مسابقه را طی کند.
یعنی نباید باتری‌اش پیش از عبور از خط پایان تمام شود.
متد `CanFinish` را پیاده‌سازی کنید که یک `trackDistance int` را به عنوان پارامتر می‌گیرد و اگر ماشین بتواند مسابقه را تمام کند `true` و در غیر این صورت `false` را برمی‌گرداند:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
