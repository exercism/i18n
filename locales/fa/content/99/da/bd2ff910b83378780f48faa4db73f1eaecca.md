# Debug

وقتی یک test شکست می‌خورد، پیامی نمایش داده می‌شود که شرح می‌دهد چه چیزی اشتباه رفته و برای کدام ورودی.
شما می‌توانید مقادیر دلخواه را در برنامه‌تان با ارسال آن‌ها به متد `debug` بررسی کنید.
این مقادیر را ثبت می‌کند و خروجی را به شما نشان می‌دهد.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
