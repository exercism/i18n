# استفاده از مقدار پیش‌فرض

برای پارامتر `%{name}` یک مقدار پیش‌فرض مشخص کنید.

برای اطلاعات بیشتر درباره‌ی نحوه‌ی مشخص کردن مقادیر پیش‌فرض برای پارامترها، که به آن‌ها پارامترهای اختیاری هم می‌گویند، [این صفحه](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#optional-arguments) را ببینید.
