# مقدمه

«لیترال‌ها» مقادیر ثابتی هستند که مستقیماً در کد به کار می‌روند.
به هیچ محاسبه‌ای در زمان اجرا نیاز ندارند.
به شکل‌های گوناگونی ظاهر می‌شوند تا انواع مختلف داده را به‌طور کارآمد بازنمایی کنند.
پرتکرارترین لیترال‌ها ماهیت عددی دارند، اما عملگرهای لیترال برای انواع تاریخ، زمان و رشته نیز وجود دارد.
مفهومی در ادامه نشان خواهد داد که چگونه می‌توان از عملگرهای لیترال تعریف‌شده توسط کاربر استفاده کرد.

## لیترال‌های عددی

لیترال‌های عددی شامل نمایش‌های دهدهی، هشتگانه، شانزدهگانه و دودویی هستند.
این مبانی پیش‌تر در [مفهوم اعداد][numbers-concept] پوشش داده شده‌اند.

همه‌ی نمایش‌هایی مثل `23`، `0x50f7ba11` و `0xba5eba11` توسط کامپایلر به‌عنوان `int` درک می‌شوند.
نوع کلی `int` علامت‌دار است و ([بسته به کامپایلر و سیستم][in-depth-integers])، اغلب بازه‌ای از `-2'147'483'648` تا `2'147'483'647` دارد.
این در بیشتر مواقع کافی است و نیازی نیست نگران نوع مشخص باشید.

برخی کاربردها به بازه‌های بزرگ‌تر یا مصرف حافظه‌ی بسیار کم برای برنامه‌ها نیاز دارند.
برای صراحت، می‌توان نوع صحیح مشخص را مستقیماً همراه با لیترال عددی نوشت.

وقتی به اعداد منفی نیازی نیست اما بازه‌ی افزوده مورد نظر است، برای اعداد صحیح _بدون علامت_ از پسوند `u` یا `U` استفاده می‌شود.
برای بازه‌های بزرگ‌تر، می‌توان از `L` یا حتی `LL` برای نوع‌های long و long long استفاده کرد.

~~~~exercism/caution
استفاده از `l` کوچک مجاز است، اما به‌راحتی با عدد `1` اشتباه گرفته می‌شود و بنابراین توصیه نمی‌شود.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

اعداد ممیز شناور معمولاً هنگام کامپایل به `double` تبدیل می‌شوند.
این پیش‌فرض خوبی است و کاربردهای نوع باریک‌تر `float` کمتر از مثال بدون علامت بالا هستند.

~~~~exercism/advanced
[استاندارد C++23][cpp23-literals] کنترل دقیق‌تری را با لیترال‌هایی مثل `f128` یا `F16` معرفی می‌کند.
برخی کامپایلرها لیترال‌های خودشان را مجاز می‌دانند.
GCC استفاده از `d` را به‌عنوان لیترال مجاز می‌داند، اما این در استاندارد در نظر گرفته نشده است و می‌تواند سازگاری بین‌پلتفرمی را مختل کند.

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## لیترال‌های کاراکتری و رشته‌ای

مفاهیم دیگر پیش‌تر از لیترال‌های کاراکتری با کوتیشن تکی مثل `'}'` یا `'@'` استفاده کرده‌اند.

در C++ نوع `char` به ۱۲۸ [کد کاراکتر ascii][ascii-code] اول محدود است.
برای استفاده از چند کاراکتر ascii یا کاراکترهای ascii توسعه‌یافته مثل `‰` یا حتی کاراکترهای یونیکد مثل `麗` و `ẞ`، به نوع‌های دیگری نیاز است.
در مفهوم پیشین، لیترال‌های رشته‌ای با _کوتیشن دوگانه_ معرفی شدند: `"一体どういう意味ですか。C++です"`.
نوع واقعی این عبارت ژاپنی `const char (&)[46]` است که رشته‌ای به سبک C است.

استفاده از لیترال‌های رشته‌ای به‌طور پیش‌فرض فعال نیست.
برای استفاده از لیترال _string_ با `""s` یا لیترال _string-view_ با `""sv`، کاربر باید با استفاده از فضای‌نام مربوطه، استفاده از آن‌ها را مشخص کند:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

یک _string_view_ را می‌توان ارجاعی به یک رشته‌ی ثابت در نظر گرفت.
