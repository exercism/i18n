# از درج رشته استفاده کنید

[comment]: # (این هشدار زمانی نمایش داده می‌شود که راه‌حل از درج رشته استفاده نکند)

برای درج پارامتر `name` در رشته‌ی خروجی از [درج رشته](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) استفاده کنید.

- در مسیر Exercism Elixir، تا حد امکان توصیه می‌شود برای خوانایی بیشتر به‌جای الحاق رشته از درج رشته استفاده کنید.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [هر عبارت Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) می‌تواند در درج رشته به کار رود.

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
