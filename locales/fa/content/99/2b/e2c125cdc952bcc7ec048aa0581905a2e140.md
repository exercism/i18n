# مقدمه

**«بستار»** یک الگوی برنامه‌نویسی [در Clojure][clojure-guide-closures] است که اجازه می‌دهد از متغیرهای یک [دامنه‌ی واژگانی][wiki-lexical-scope] بیرونی درون یک تابع استفاده شود. Clojure از بستارها به‌صورت شفاف پشتیبانی می‌کند و اغلب بدون آنکه بدانید چه هستند از آن‌ها استفاده می‌شود.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## بستار برای ذخیره‌ی وضعیت و انتقال مقادیر

با استفاده از `atom` می‌توان مقداری از وضعیت را حفظ کرد:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

هر فراخوانی پیاپی `increment` شمارنده‌اش را یک واحد افزایش می‌دهد:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
