# نصب Kotlin

علاوه بر exercism CLI و ویرایشگر متن محبوبتان، برای تمرین با تمرین‌های Exercism به زبان Kotlin به این موارد نیاز دارید:

* **Java Development Kit** (JDK): Kotlin به بایت‌کدهای Java کامپایل می‌شود؛ باید JDK را نصب کنید که هم شامل یک Java Runtime است و هم ابزارهای توسعه (به‌ویژه کامپایلر Java)؛ و
* **Gradle**: ابزاری برای ساخت که مخصوص پروژه‌های مبتنی بر JVM است و از Kotlin پشتیبانی می‌کند.

سیستم‌عامل خود را انتخاب کنید:

* [ویندوز](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... یا ...
* اگر ترجیح می‌دهید از مدیر بسته استفاده نکنید، می‌توانید [به‌صورت دستی نصب کنید](#h-install-manually).

به‌صورت اختیاری، می‌توانید از [یک IDE مخصوص Java](#h-java-ides) هم استفاده کنید.

## ویندوز

یک خط فرمان مدیریتی باز کنید.  (اگر برای باز کردن خط فرمان مدیریتی به کمک نیاز دارید، [باز کردن خط فرمان با دسترسی بالا در Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) را ببینید (یا [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. اگر Chocolatey را نصب نکرده‌اید، حالا این کار را انجام دهید:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  JDK را نصب کنید:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

توصیه می‌کنیم خط فرمان مدیریتی را ببندید و یک خط فرمان جدید باز کنید؛ برای تمرین کردن تمرین‌های Exercism به دسترسی مدیریتی نیازی ندارید.

حالا آماده‌اید تا کار با مسیر Kotlin در Exercism را شروع کنید!

برای شروع، «[اجرای Testها](https://exercism.org/docs/tracks/kotlin/tests)» را ببینید.

## macOS

در ادامه دستورالعمل‌هایی برای نصب با رایج‌ترین روش، یعنی استفاده از Homebrew، آمده است.  اگر ترجیح می‌دهید، می‌توانید [روی macOS بدون Homebrew نصب کنید](#h-installing-on-macos-without-homebrew).

### نصب

1. اگر هنوز [Homebrew](http://brew.sh) را نصب نکرده‌اید، حالا این کار را انجام دهید:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. مخزن [Homebrew Cask](https://caskroom.github.io/) را اضافه کنید؛ این کار به ما اجازه می‌دهد باینری‌های از پیش ساخته‌شده مانند JDK را نصب کنیم.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  JDK را نصب کنید:

       ```
        $ brew install --cask adoptopenjdk11
       ```

حالا آماده‌اید تا کار با مسیر Kotlin در Exercism را شروع کنید!

برای شروع، «[اجرای Testها](https://exercism.org/docs/tracks/kotlin/tests)» را ببینید.

* [Debian](#h-debian)
* [سایر توزیع‌های Linux](#h-other-linux-distributions)

### Debian

اگر از Debian یا مشتقات آن (مانند Ubuntu یا Linux Mint) استفاده می‌کنید، از APT استفاده کنید:

*(تأییدشده روی: Ubuntu 14، 16 و 18)*

1. JDK را نصب کنید:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```

### سایر توزیع‌های Linux

راه‌های زیادی برای نصب Jdk 11 وجود دارد، اما یکی از ساده‌ترین آن‌ها استفاده از SDKMAN است، 
که به شما امکان می‌دهد OpenJdk11 را به‌راحتی نصب کنید. مراحل زیر را دنبال کنید:

1. SDKMAN را نصب کنید:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (اگر این کار جواب نداد، نگاهی به دستورالعمل‌هایی که اینجا آمده بیندازید: https://sdkman.io/install )
1. openjdk11 را نصب کنید:
    ```
    $ sdk install java 11.0.2-open
    ``` 

حالا آماده‌اید تا کار با مسیر Kotlin در Exercism را شروع کنید!

برای شروع، «[اجرای Testها](https://exercism.org/docs/tracks/kotlin/tests)» را ببینید.

## IDEهای Java

IDEهای Java زیادی در دسترس‌اند.  سه مورد از محبوب‌ترین آن‌ها عبارت‌اند از:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (نسخه‌ی «Community» را دانلود کنید)
  - این IDE از سوی نویسندگان Kotlin عرضه شده و بهترین پشتیبانی از این زبان را ارائه می‌دهد.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (بسته‌ی «Java SE» را دانلود کنید)

و [موارد دیگری](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs) هم وجود دارند.
