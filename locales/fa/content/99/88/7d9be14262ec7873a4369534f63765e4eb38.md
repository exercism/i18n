# راهنمایی‌ها

## 1. چاپ یک نشان برای یک کارمند

- برای ساختن رشته‌ها در Base R، تابع [`sprintf`][ref-sprintf] مفید است.
- برای رویکرد Tidyverse، می‌توانید از [`str_glue`][ref-str_glue] از کتابخانه‌ی `stringr` استفاده کنید.

## 2. چاپ یک نشان برای یک کارمند جدید

- بر اساس [`is.na`][ref-isna] شرط بگذارید.

## 3. چاپ یک نشان برای مالک

- بر اساس [`is.null`][ref-isnull] شرط بگذارید.

## 4. محاسبه‌ی مجموع حقوق کارمندانی که شناسه ندارند

- می‌توانید ابتدا بر اساس [`is.na`][ref-isna] [فیلتر][concept-vector-filtering] کنید و سپس [`sum`][ref-sum] بگیرید.
- اگر هیچ کارمندی بدون شناسه نباشد، `salaries[is.na(ids)]` چه چیزی است؟ بررسی این موضوع در یک کنسول R مفید خواهد بود. اگر R روی رایانه‌تان نصب نیست، کنسول‌های آنلاینی مانند [rdrr.io][web-rdrr] می‌توانند کمک کنند.
