# حل تمرین‌ها به‌صورت محلی

حل تمرین‌ها روی رایانه‌ی خودتان به شما این امکان را می‌دهد که همه‌ی کدنویسی را در محیطی انجام دهید که با آن آشنا هستید.

## نصب CLI

برای حل یک تمرین روی رایانه‌ی خودتان، ابتدا باید رابط خط فرمان Exercism را با [این راهنما](https://exercism.org/cli-walkthrough) نصب و پیکربندی کنید.

### پیکربندی

باید به CLI بگویید که شما چه کسی هستید تا بتوانیم دانلودها را درست انجام دهیم.
توکن خود را در [صفحه‌ی تنظیمات](/settings/api_cli) پیدا می‌کنید.
سپس می‌توانید CLI را با دستور زیر پیکربندی کنید؛ به‌جای `<your-api-token>` مقدار موجود در صفحه‌ی تنظیمات را بگذارید:

```
exercism configure --token=<your-api-token>
```

## دانلود تمرین

پس از نصب، می‌توانید با CLI تمرین را با دستور زیر روی رایانه‌ی خودتان دانلود کنید (به‌جای `<exercise-slug>` و `<track-slug>` مقدارهای مربوطه را بگذارید:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

لازم نیست ساختار این دستور را به خاطر بسپارید، چون صفحه‌ی تمرین دستور مناسب همان تمرین را نشان می‌دهد.

پس از پایان دستور دانلود، فایل‌های تمرین روی رایانه‌ی شما دانلود می‌شوند.

## حل تمرین

هدف هر تمرین این است که پیاده‌سازی‌ای بسازید که همه‌ی تست‌ها را پاس کند.
به چنین پیاده‌سازی‌ای _راه‌حل_ می‌گویند.

برای کمک به شما در این مسیر، هر تمرین این فایل‌ها را در خود دارد:

- README.md: دستورهایی که توضیح می‌دهند چه انتظاری از شما می‌رود
- HELP.md: اطلاعاتی درباره‌ی نحوه‌ی اجرای تست‌ها و اینکه هنگام گیر کردن چطور کمک بگیرید
- HINTS.md (اختیاری): راهنمایی‌هایی برای کمک به حل تمرین
- فایل(های) تست: تست‌هایی را در خود دارند که درستی راه‌حل شما را بررسی می‌کنند
- فایل(های) اسکلت: نقطه‌ی شروعی فراهم می‌کنند تا ساخت پیاده‌سازی خود را آغاز کنید

بسته به مسیر، ممکن است فایل‌های دیگری هم باشند که ابزارهای آن مسیر برای اجرای تست‌ها به آن‌ها نیاز دارند.

## ارسال راه‌حل

وقتی راه‌حل شما همه‌ی تست‌ها را پاس کرد، می‌توانید آن را با دستور زیر ارسال کنید:

```
exercism submit <implementation_file_paths>
```

این دستور راه‌حل شما را در وب‌سایت Exercism بارگذاری می‌کند و نشانی صفحه‌ی راه‌حل را چاپ می‌کند.

باز هم لازم نیست این دستور را به خاطر بسپارید، چون فایل `HELP.md` تمرین دستور درست را نشان می‌دهد.

می‌توانید راه‌حل ناقصی هم ارسال کنید؛ این کار به شما امکان می‌دهد:

- ببینید دیگران تمرین را چطور کامل کرده‌اند
- از یک منتور کمک بخواهید

## سایر قابلیت‌های CLI

### دیدن همه‌ی دستورها

زیردستور `help` را اجرا کنید تا فهرست کامل دستورهای موجود را ببینید.

```bash
exercism help
```

### عیب‌یابی

مطمئن شوید که آخرین نسخه را دارید.

بررسی کنید کدام نسخه را دارید:

```bash
exercism version
```

آن را با آخرین انتشار مقایسه کنید و اگر نسخه‌تان جدیدترین نیست، ارتقا دهید.

پس از ارتقا، نسخه را دوباره بررسی کنید. اگر نسخه تغییر نکرده بود، مطمئن شوید که نسخه‌ی ارتقایافته را اجرا می‌کنید.

```bash
which exercism
```

اگر همچنان مشکل دارید، در `exercism/cli` روی GitHub یک issue باز کنید و خروجی دستور troubleshoot را هم بنویسید.

```bash
exercism troubleshoot
```

می‌توانید issueها را در [ردیاب issue ما](https://github.com/exercism/exercism/issues) باز کنید و جامعه‌ی ما تلاش می‌کند به شما کمک کند. **لطفاً پیش از باز کردن هر issue، [آموزش تعاملی](https://exercism.org/cli-walkthrough) را کامل انجام داده باشید.**
