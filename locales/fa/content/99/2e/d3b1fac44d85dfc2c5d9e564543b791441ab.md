# پیوست دستورالعمل‌ها

## رجیستر

| رجیستر | کاربرد | نوع | توضیح |
| ------ | ------ | --- | ----- |
| `$a0` | ورودی | عدد صحیح | `N`، مجموع اضلاع مثلث |
| `$a1` | ورودی/خروجی | آدرس | مقدارهای `a` |
| `$a2` | ورودی/خروجی | آدرس | مقدارهای `b` |
| `$a3` | ورودی/خروجی | آدرس | مقدارهای `c` |
| `$v0` | خروجی | عدد صحیح | تعداد سه‌گانه‌ها |
| `$t0-9` | موقت | هر نوع | برای ذخیره‌سازی موقت |
