# معرفی

پیش از آنکه کلاس `Promise` معرفی شود، فقط یک راه برای برخورد با کد غیرهمگام وجود داشت: «الگوی کالبک».

کالبک تابعی است که به عنوان آرگومان به تابعی دیگر داده می‌شود و زمانی فراخوانی می‌شود که کاری در آن تابع دیگر تمام شده باشد. الگوی رایج در این توابع کالبک آن است که یک «خطا» را به عنوان پارامتر اول می‌پذیرند (به مثال زیر نگاه کنید).

```javascript
function callback(error, arg2, arg3) {}
```

این موضوع چه ربطی به کد غیرهمگام دارد؟

از نظر تاریخی، از کالبک‌ها استفاده می‌شد تا بتوانیم پس از پایان یک کار غیرهمگام و بدون مسدود کردن کل برنامه، کارهایی انجام دهیم.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

در مثال بالا، تابع `fetchProduct` (که غیرهمگام است) یک کالبک را به عنوان آرگومان دوم می‌گیرد که تعیین می‌کند وقتی داده‌های محصول دریافت شد چه کاری انجام شود.
