# پیوست دستورالعمل‌ها

## نکته

تابعی که *نوع بازگشتی* دارد فقط می‌تواند داده‌ای از همان *نوع* و `null` را برگرداند.
با این حال، فراخوانی‌کننده‌ی تابع فقط انتظار یک نوع داده را دارد.

مثال:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
برای اینکه روشن‌تر شود که این تابع می‌تواند `null` یا نوع‌های داده‌ی بیشتری هم برگرداند، از `dynamic` استفاده کنید.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
