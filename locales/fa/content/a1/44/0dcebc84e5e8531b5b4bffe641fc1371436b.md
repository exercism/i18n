# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است یک استثنا [`raise` کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). هنگام انجام این کار، همیشه باید یک **پیام خطای معنادار** همراه آن بیاورید تا نشان دهید منبع خطا چیست. این کار Code شما را خواناتر می‌کند و به Debug کمک چشمگیری می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا نوع مشخصی خواهد بود، می‌توانید یکی از [انواع خطای داخلی](https://docs.python.org/3/library/exceptions.html#base-classes) را `raise` کنید، اما همچنان باید پیام معناداری همراه آن بیاورید.

این تمرین خاص از شما می‌خواهد که از [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) استفاده کنید تا در صورتی که دنباله‌ای که باید رمزگشایی یا رمزگذاری شود ناقص باشد، یک `ValueError` «پرتاب» کنید. این Testها تنها در صورتی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بیاورید.

برای `raise` کردن یک `ValueError` همراه با پیام، پیام را به‌عنوان آرگومان برای نوع `exception` بنویسید:

```python
# if the sequence is incomplete
raise ValueError("incomplete sequence")
```
