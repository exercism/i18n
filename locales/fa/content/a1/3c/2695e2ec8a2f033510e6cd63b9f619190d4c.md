# ضمیمه‌ی دستورالعمل‌ها

## ورودی نمونه

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

یعنی ورودی‌های شما عبارت‌اند از:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## برخورد با ورودی‌های نامعتبر

اگر هر یک از مقادیر ورودی نامعتبر باشد، فعل شما باید یک `empty` برگرداند (مثلاً `0$0` یا `''`).

### مثال‌ها

- اگر _مبنای ورودی_ کوچک‌تر از ۲ باشد:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- اگر _مبنای خروجی_ کوچک‌تر از ۲ باشد:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- اگر _ارقام_ مقداری بزرگ‌تر یا مساوی مبنای ورودی داشته باشند:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
