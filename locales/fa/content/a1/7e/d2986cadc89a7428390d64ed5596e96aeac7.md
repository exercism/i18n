# Tests

ما برای نوشتن تست‌هایی که راه‌حل شما را بررسی کنند، از [PonyTest](https://stdlib.ponylang.io/pony_test--index/) در stdlib استفاده می‌کنیم. برای آزمایش راه‌حل خود، کدتان را کامپایل و اجرا کنید.

برای مثال، جلسه‌ی شما برای «Hello World» ممکن است این‌گونه به نظر برسد:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
