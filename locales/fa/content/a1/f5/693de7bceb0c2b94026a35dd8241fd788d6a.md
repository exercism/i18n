# دستورالعمل‌ها

شما سیستمی دارید که از چند برنامه ساخته شده است و این برنامه‌ها لاگ‌های زیادی تولید می‌کنند. می‌خواهید برنامه‌ی کوچکی بنویسید که آن لاگ‌ها را جمع کند و بر اساس سطح شدتشان به آن‌ها برچسب بدهد. همه‌ی برنامه‌های سیستم شما از کدهای لاگ یکسانی استفاده می‌کنند، اما بعضی از برنامه‌های قدیمی از همه‌ی کدها پشتیبانی نمی‌کنند.

| کد لاگ | برچسب لاگ | پشتیبانی در برنامه‌های قدیمی؟ |
| --- | --- | --- |
| 0 | trace | خیر |
| 1 | debug | بله |
| 2 | info | بله |
| 3 | warning | بله |
| 4 | error | بله |
| 5 | fatal | خیر |
| سایر / پشتیبانی‌نشده | unknown | - |

## 1. تعیین برچسب لاگ

تابع `LogLevel.to_label/2` را پیاده‌سازی کنید. این تابع باید یک کد عددی و یک پرچم «منطقی» بگیرد که به شما می‌گوید آیا لاگ از یک برنامه‌ی قدیمی می‌آید، و برچسب یک خط لاگ را به‌صورت یک «اتم» برگرداند.

کدهای لاگی که در جدول مشخص نشده‌اند باید برچسب _unknown_ را برگردانند. کدهای لاگی هم که در جدول به‌عنوان پشتیبانی‌نشده در برنامه‌های قدیمی مشخص شده‌اند، اگر لاگ از یک برنامه‌ی قدیمی آمده باشد باید برچسب _unknown_ را برگردانند.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. ارسال هشدار

وقتی اتفاق‌های غیرمنتظره‌ای می‌افتد، باید به کسی اطلاع داده شود.

تابع `LogLevel.alert_recipient/2` را پیاده‌سازی کنید تا مشخص شود هشدار باید به چه کسی فرستاده شود. این تابع باید یک کد عددی و یک پرچم منطقی بگیرد که می‌گوید آیا لاگ از یک برنامه‌ی قدیمی می‌آید، و اسم گیرنده را به‌صورت یک اتم برگرداند.

از تابع `LogLevel.to_label/2` از بخش قبلی استفاده کنید. اگر برچسب لاگ _error_ یا _fatal_ باشد، هشدار را به تیم _ops_ بفرستید. اگر لاگی با برچسب _unknown_ از یک سیستم قدیمی دریافت کردید، هشدار را به تیم _dev1_ بفرستید، و سایر برچسب‌های _unknown_ باید به تیم _dev2_ فرستاده شوند. سایر برچسب‌های لاگ را می‌توان با برگرداندن _false_ با خیال راحت نادیده گرفت.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
