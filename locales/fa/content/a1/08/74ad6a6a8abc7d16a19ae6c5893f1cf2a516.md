# پیوست دستورالعمل‌ها

رشته‌ی شماره‌ی تلفنِ داده‌شده را بازنویسی کنید.
اگر شماره‌ی تلفن نامعتبر باشد، آن را با یک رشته‌ی خالی جایگزین کنید.

## ثبات‌ها

| ثبات     | کاربرد        | نوع     | توضیح                                        |
| -------- | ------------- | ------- | -------------------------------------------- |
| `$a0`    | ورودی/خروجی   | آدرس    | شماره‌ی تلفن به‌صورت رشته‌ای که با `null` پایان می‌یابد |
| `$t0-9`  | موقت          | هر نوع  | برای ذخیره‌سازی موقت به کار می‌رود             |
