# مقدمه

کتابخانه‌ی استاندارد Gleam نوع `Queue` را در ماژول `gleam/queue` پیاده‌سازی می‌کند. این نوع شبیه نوع `List` است، اما چند تفاوت کلیدی دارد:

- نوع `Queue` نحوه‌ی نگارش تحت‌اللفظی ندارد که بتوان با آن صف ساخت یا روی آن تطبیق الگو انجام داد.
- عنصرها را می‌توان به‌طور کارآمد به ابتدا و انتهای نوع `Queue` اضافه و از آن حذف کرد، در حالی که نوع `List` فقط می‌تواند عنصرها را از ابتدا به‌طور کارآمد اضافه و حذف کند.

بیشتر اوقات می‌خواهید از نوع `List` استفاده کنید، اما وقتی لازم است بتوانید به انتهای یک مجموعه عنصر اضافه و از آن حذف کنید، نوع `Queue` انتخاب خوبی است.

صف‌ها را می‌توان با توابع `queue.new` و `queue.from_list` ساخت:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

عنصرها را می‌توان با توابع `queue.push_front` و `queue.push_back` به صف اضافه کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

عنصرها را می‌توان با توابع `queue.pop_front` و `queue.pop_back` از صف حذف کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

می‌توان یک صف را با تابع `queue.to_list` به لیست تبدیل کرد:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## برابری صف‌ها

بسته به نحوه‌ی پیاده‌سازی صف‌ها، ممکن است دو صف با عنصرهای یکسان و در ترتیب یکسان، بر اساس عملگر `==` که مقدارها را ساختاری مقایسه می‌کند، برابر نباشند. برای نمونه:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

اگر لازم است دو صف را از نظر برابری مقایسه کنید، می‌توانید از تابع `queue.is_logically_equal` استفاده کنید.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
