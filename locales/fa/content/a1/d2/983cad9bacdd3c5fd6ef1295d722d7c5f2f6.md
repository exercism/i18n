# مقدمه

## تعریف متغیرها

تعریف متغیر یعنی اختصاص دادن یک مقدار به یک اسم. در Scala دو نوع متغیر وجود دارد: `val` و `var`.

یک `val` تغییرناپذیر است، بنابراین مقدار آن پس از اولین تخصیص دیگر قابل تغییر نیست:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

در مقابل، یک `var` را می‌توان به مقدار جدیدی از همان نوع دوباره تخصیص داد:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala یک زبان با نوع‌دهی ایستا است، یعنی همه‌چیز در زمان کامپایل نوع دارد. یک متغیر را می‌توان یا با مشخص کردن صریح نوعش تعریف کرد، یا با سپردن استنتاج نوع به کامپایلر Scala بر اساس مقدار تخصیص‌یافته (که به آن استنتاج نوع می‌گویند). بنابراین، دو تعریف متغیر زیر معادل یکدیگرند:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

پس از تعریف، نوع متغیر هرگز تغییر نمی‌کند.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## تعریف متد در کلاس

Scala یک _زبان شیءگرا_ است و لازم می‌داند که همه‌ی متدها در یک _کلاس_ تعریف شوند. برای تعریف یک کلاس از کلیدواژه‌ی `class` استفاده می‌شود.

```scala
class Calculator {
  // ...
}
```

درون یک کلاس، متدها را می‌توان با کلیدواژه‌ی `def` و سپس یک اسم تعریف کرد. هر متد می‌تواند صفر یا چند پارامتر داشته باشد که با کاما از هم جدا شده و داخل پرانتز فهرست می‌شوند. نوع همه‌ی پارامترها باید صریحاً مشخص شود؛ برای پارامترها استنتاج نوع وجود ندارد. بعد از فهرست پارامترها، نوع بازگشتی متد با یک دونقطه‌ی دیگر مشخص می‌شود.

بعد از تعریف متد یک علامت `=` می‌آید تا بدنه‌ی متد شروع شود. در مثال زیر، بدنه‌ی متد از دو دستور تشکیل شده که داخل آکولاد قرار گرفته‌اند.

متد مقدار آخرین عبارت را برمی‌گرداند؛ در این مورد، متد `add` مقدار متغیر `sum` را برمی‌گرداند:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

چند بهبود هست که می‌توان برای کوتاه کردن آن متد و بهتر شدن خوانایی اعمال کرد:

- از آنجا که متغیر `sum` فقط یک بار برای برگرداندن مقدار خوانده می‌شود، می‌توان آن را حذف کرد
- متدهایی که فقط از یک دستور تشکیل شده‌اند به آکولاد نیازی ندارند
- نوع بازگشتی متد هم مثل نوع متغیرها می‌تواند استنتاج شود

این کار به متد یک‌خطی زیر با همان کارکرد می‌انجامد:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## ساختن نمونه از کلاس و فراخوانی متد

برای فراخوانی یک متد، ابتدا نمونه‌ای از کلاس ساخته می‌شود و سپس متد با آرگومان‌ها روی آن نمونه فراخوانی می‌شود:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## کامنت‌گذاری

Scala از دو نوع کامنت پشتیبانی می‌کند: کامنت‌های تک‌خطی و کامنت‌های چندخطی:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
