# Tests

## اجرای Tests

مشخصات test را با دستور زیر اجرا کنید:

```bash
$ gradle test
```

## فعال کردن Tests بیشتر

وقتی کدتان همه‌ی testهای فعال را با موفقیت پشت سر گذاشت، می‌توانید test دیگری را فعال کنید. کافی است `@Ignore`ی را که پیش از test بعدیِ موردنظرتان آمده حذف کنید. برای این کار، خط `@Ignore` را پاک کنید یا با افزودن دو اسلش به ابتدای خط، آن را کامنت کنید.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
