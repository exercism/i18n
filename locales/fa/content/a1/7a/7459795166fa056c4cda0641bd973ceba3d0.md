# درباره

دستور `guard` در Swift برای خروج زودهنگام از توابع، حلقه‌ها یا متدها به کار می‌رود، آن هم وقتی شرط لازم برآورده نشده باشد:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

در مثال بالا، `guard` عبارتی منطقی را که پس از آن می‌آید ارزیابی می‌کند.
اگر شرط `true` باشد، اجرا با کدی ادامه می‌یابد که پس از دستور `guard` آمده است.
اگر شرط `false` باشد، کد درون بلوک `else` اجرا می‌شود.

برخلاف دستور `if`:

- دستور `guard` **باید** یک بخش `else` داشته باشد.
- بخش `else` **باید** کنترل را طوری منتقل کند که از حوزه‌ی پیرامون خارج شود (برای مثال با استفاده از `return`، `continue`، `break` یا پرتاب یک خطا).

از `guard` اغلب برای اعتبارسنجی تمیز پیش‌شرط‌ها استفاده می‌شود.
برای مثال، تابع sinc را در نظر بگیرید ($\text{sinc}(x) = \frac{\sin(x)}{x}$، که در آن $\text{sinc}(0) = 1$ تعریف شده است تا از تقسیم بر صفر جلوگیری شود):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
