# دستورالعمل‌ها

شما به عاشقان دوران دبیرستان کمک می‌کنید تا عشق خود را در شبکه‌های اجتماعی با ساختن یک قلب یونیکد از حروف اول اسمشان اعلام کنند:

```
❤ J.  +  M. ❤
```

## 1. اسم را پاکسازی کنید

تابعی به اسم `cleanupname` تعریف کنید که یک اسم را از پشته می‌گیرد. هر `-` را با یک فاصله جایگزین کنید، سپس فاصله‌های ابتدا و انتهای آن را حذف کنید.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. حرف اول اسم را به دست آورید

تابعی به اسم `firstletter` تعریف کنید که یک اسم می‌گیرد. از `cleanupname` تسک قبلی استفاده کنید، سپس اولین کاراکتر نتیجه را بردارید و آن را به‌صورت رشته‌ای یک‌کاراکتری برگردانید.

```factor
"Jane" firstletter .
! => "J"
```

## 3. حرف اول را به شکل حرف اختصاری درآورید

تابعی به اسم `initial` تعریف کنید که یک اسم می‌گیرد. از `firstletter` تسک قبلی استفاده کنید، آن را به حروف بزرگ تبدیل کنید، سپس یک `.` به انتهای آن اضافه کنید.

```factor
"Robert" initial .
! => "R."
```

## 4. حروف اختصاری را داخل قلب بگذارید

تابعی به اسم `couple` تعریف کنید که دو اسم را از پشته می‌گیرد. `initial` تسک قبلی را روی هر اسم اعمال کنید، سپس نتیجه را کنار هم بچینید:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
