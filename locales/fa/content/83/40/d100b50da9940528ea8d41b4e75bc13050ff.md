# تست‌ها

برای اجرای تست‌ها، دستور `v test .` را از داخل پوشه‌ی تمرین اجرا کنید.

اگر می‌خواهید همه‌ی تست‌هایی را که اجرا شده‌اند همراه با آمار سرعت ببینید، از `v -stats test .` استفاده کنید.

برای اطلاعات بیشتر درباره‌ی تست‌نویسی در V، [مستندات](https://github.com/vlang/v/blob/master/doc/docs.md#testing) را ببینید.
