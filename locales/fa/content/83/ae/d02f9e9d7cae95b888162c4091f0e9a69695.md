# درباره

[نمادها][symbols] شناسه‌هایی اسم‌دار هستند که می‌توان با آن‌ها به یک مقدار اشاره کرد.
نمادها با نوشتن یک نماد به‌صورت مستقیم ساخته می‌شوند، یعنی با افزودن کاراکتر `:` به ابتدای یک اسم، مثلاً `:foo`.
همچنین می‌توان آن‌ها را داخل گیومه نوشت، مثلاً `:"foo"`، که به این ترتیب، مثلاً، استفاده از فاصله در اسم را ممکن می‌کند.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

نمادها در جاهای زیادی از زبان به کار می‌روند، از جمله به عنوان کلید در هش‌ها، و برای نمایش اسم متدها و اسم متغیرها.

## شناسه

چیزی که نمادها را از رشته‌ها متمایز می‌کند این است که آن‌ها شناسه‌اند و نماینده‌ی داده یا متن نیستند.
یعنی دو نماد با اسم یکسان همیشه یک شیء یکسان‌اند.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## تغییر نمادها

نمادها تغییرناپذیرند، یعنی نمی‌توان آن‌ها را تغییر داد.
پس وقتی یک نماد را «تغییر می‌دهید»، در واقع دارید نماد تازه‌ای می‌سازید.
چند متد وجود دارد که می‌توان با آن‌ها نمادها را دستکاری کرد؛ همه‌ی آن‌ها نمادهای تازه‌ای برمی‌گردانند.
همه‌ی متدها را می‌توانید در [رابط برنامه‌نویسی Symbol][symbols-api] پیدا کنید.

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

مزیت تغییرناپذیر بودن نمادها این است که از نظر حافظه از رشته‌ها کارآمدترند، و به‌عنوان شناسه هم استفاده‌ی ایمن‌تری دارند.

## تبدیل

می‌توان نمادها را به رشته تبدیل کرد و برعکس.
این کار وقتی مفید است که بخواهید نمادی را تغییر دهید، یا بخواهید از یک نماد به‌عنوان رشته استفاده کنید.
برای تبدیل یک رشته به نماد می‌توانید از متد `String#to_sym` استفاده کنید و برای کار برعکس، از متد `Symbol#to_s`.
چون نمادها متدهای محدودی دارند، اگر به نماد تازه‌ای نیاز داشته باشید، مفید است که نماد را به رشته تبدیل کنید تا متدهای رشته را روی آن به کار ببرید.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
