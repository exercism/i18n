# مقدمه

## جنریک

یک نوع زمانی _نوع جنریک_ است که بتواند با استفاده از یک _پارامتر نوع_، مقادیر هر نوعی را در خود نگه دارد.

برای نمونه، این نوع `Box` پارامتر نوع `a` را دارد (که با حروف کوچک نوشته می‌شود).

```gleam
pub type Box(a) {
  Box(a)
}
```

پارامتر نوع `a` جانگهدار هر نوعی است، بنابراین می‌توان از `Box` با رشته‌ها، عددهای صحیح یا هر نوع دیگری استفاده کرد.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

یک نوع می‌تواند چندین پارامتر نوع داشته باشد که با ویرگول از هم جدا می‌شوند.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### توابع جنریک

پارامترهای نوع را می‌توان در آرگومان‌های توابع هم به کار برد.

این تابع یک مقدار از نوع `a` می‌گیرد و تابعی را که یک `a` می‌گیرد و یک `b` برمی‌گرداند، دو بار فراخوانی می‌کند.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
