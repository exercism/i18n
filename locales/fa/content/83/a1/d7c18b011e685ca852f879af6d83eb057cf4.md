# دستورالعمل‌ها

در این تمرین، مجموعه‌ای ناقص از روال‌های کمکی را پیاده‌سازی می‌کنید که به یک برنامه‌نویس در پاک‌سازی اسم شناسه‌ها کمک می‌کند.

در ۵ کار، به‌تدریج تابع `clean` را می‌سازید. یک شناسه‌ی معتبر از صفر یا چند حرف و زیرخط تشکیل می‌شود.

در همه‌ی موارد، تضمین شده است که رشته‌ی ورودی `nil` نباشد. اگر رشته‌ی خالی به تابع داده شود، باید رشته‌ی خالی برگردانده شود.

توجه کنید که فراخوان باید از فراخوانی تابع با یک شناسه‌ی خالی بپرهیزد، چون چنین شناسه‌هایی بی‌اثرند.

## 1. هر فاصله‌ای را که ببینید با زیرخط جایگزین کنید

تابع `clean` را طوری پیاده‌سازی کنید که هر فاصله را با زیرخط جایگزین کند. این موضوع برای فاصله‌های ابتدا و انتهای رشته هم صدق می‌کند.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. کاراکترهای کنترلی را با رشته‌ی «CTRL» با حروف بزرگ جایگزین کنید

تابع `clean` را طوری تغییر دهید که کاراکترهای کنترلی را با رشته‌ی `"CTRL"` با حروف بزرگ جایگزین کند. یک کاراکتر زمانی کاراکتر کنترلی ISO به حساب می‌آید که کدش در بازه‌ی «\u0000» تا «\u001F» یا در بازه‌ی «\u007F» تا «\u009F» باشد.

```clojure
(clean "my\u007FId")
;;=> "myCTRLId"
```

## 3. kebab-case را به camelCase تبدیل کنید

تابع `clean` را طوری تغییر دهید که kebab-case را به camelCase تبدیل کند.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. کاراکترهایی را که حرف نیستند حذف کنید

تابع `clean` را طوری تغییر دهید که هر کاراکتری را که حرف نیست حذف کند.
توجه: زیرخط‌ها باید از مرحله‌ی قبل حفظ شوند.

```clojure
(clean "1😀2😀3😀")
;; => ""
```

## 5. حروف کوچک یونانی را حذف کنید

تابع `clean` را طوری تغییر دهید که هر حرف یونانی در بازه‌ی «α» تا «ω» را حذف کند.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
