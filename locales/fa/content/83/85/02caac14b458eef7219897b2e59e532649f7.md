# مقدمه

«تابع» بلوکی از کد سازمان‌یافته و قابل استفاده‌ی مجدد است که برای انجام کاری به کار می‌رود.
روش‌های متعددی برای تعریف توابع در JavaScript وجود دارد.
در اینجا به _«اعلان تابع»_ و _«عبارت تابع»_ می‌پردازیم.
امکان‌های دیگری مانند [توابع پیکانی][concept-arrow-functions] در مفاهیم دیگر بررسی می‌شوند.

## اعلان تابع

روش استاندارد تعریف تابع در JavaScript، _«اعلان تابع»_ است که _«تعریف تابع»_ یا _«دستور تابع»_ هم نامیده می‌شود.

این ساختار شامل کلیدواژه‌ی `function`، اسم تابع و فهرستی از پارامترهاست که با کاما از هم جدا می‌شوند و داخل پرانتز می‌آیند.
پس از آن بدنه‌ی تابع می‌آید (مجموعه‌ای از دستورها که تعیین می‌کند تابع چه کاری انجام می‌دهد) که در آکولاد پیچیده شده است.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

در JavaScript، تابع را با نوشتن اسم تابع و سپس پرانتزهایی که آرگومان‌ها را در خود دارند، فراخوانی می‌کنیم (که به آن صدا زدن هم می‌گویند).

```javascript
someName(arg1, arg2, arg3);
```

## پارامتر

هنگام کار با پارامترها در بدنه‌ی تابع، مراقب عوارض جانبی احتمالی باشید.

- مقادیر [انواع داده‌ی اولیه][mdn-primitives] _تغییرناپذیر_ هستند.
  مقدار اصلی هرگز از آنچه بر سر آرگومان در بدنه‌ی تابع می‌آید تأثیر نمی‌گیرد.
- برای همه‌ی مقادیر دیگر (شیءها، آرایه‌ها، توابع)، انتساب مجدد بر مقدار اصلی اثری ندارد.
  اما اگر چنین آرگومانی را تغییر دهید (مثلاً کلیدی به یک شیء اضافه کنید)، مقدار اصلی‌ای که پاس داده شده هم تغییر می‌کند.

به‌طور پیش‌فرض، همه‌ی پارامترهایی که در اعلان تابع تعریف می‌شوند در JavaScript اختیاری هستند.
اگر تعداد آرگومان‌های کمتری از پارامترها بدهید، آرگومان‌های غایب داخل تابع `undefined` خواهند بود؛ به [Null و Undefined][concept-null-undefined] نگاه کنید.
در بسیاری از موارد منطقی است که مقدار پیش‌فرض مناسب‌تری به‌جای `undefined` در نظر بگیرید.
این کار با مشخص کردن پارامترهای پیش‌فرض مستقیماً در تعریف تابع انجام می‌شود.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## دستور `return`

دستور `return` اجرای تابع را پایان می‌دهد و مقداری را مشخص می‌کند که باید به فراخوان‌کننده‌ی تابع بازگردانده شود. یک تابع می‌تواند چندین دستور `return` داشته باشد.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

نتیجه‌ی تابعی که هیچ مقداری `return` نمی‌کند یا دستور `return` ندارد، `undefined` است.
در JavaScript هیچ `return` ضمنی‌ای وجود ندارد.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

در JavaScript فقط می‌توانید دقیقاً یک مقدار را بازگردانید.
اگر می‌خواهید اطلاعات بیشتری منتقل کنید، ابتدا باید آن‌ها را در یک موجودیت واحد ترکیب کنید، معمولاً یک [شیء][concept-objects] یا یک [آرایه][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## عبارت تابع

اعلان تابع یک دستور مستقل است.
اما گاهی تعریف یک تابع به‌عنوان بخشی از عبارتی دیگر مفید است؛ مثلاً در یک انتساب، به‌عنوان پارامتر یک تابع ([فراخوان][concept-callbacks]) یا به‌عنوان مقداری در یک [شیء][concept-objects].
این کار با عبارت تابع انجام می‌شود.
شکل نوشتن آن مانند اعلان تابع است، فقط با این تفاوت که می‌توان اسم تابع را حذف کرد تا یک _تابع بی‌نام_ ساخت.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
