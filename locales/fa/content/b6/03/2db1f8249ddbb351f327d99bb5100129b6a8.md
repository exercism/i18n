# پیوست دستورالعمل‌ها

## رجیسترها

| رجیستر  | کاربرد     | نوع     | توضیح                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | آدرس | رشته‌ی ارقام پایان‌یافته با null |
| `$a1`    | ورودی        | عدد صحیح | بازه                          |
| `$v0`    | خروجی       | عدد صحیح | بزرگ‌ترین حاصل‌ضرب سری        |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت         |
