# مقدمه

## مبانی

C# زبانی با نوع‌دهی ایستا است، یعنی هر چیز در زمان کامپایل یک نوع دارد. به اختصاص دادن یک مقدار به یک اسم، تعریف متغیر می‌گویند. یک متغیر را می‌توان یا با مشخص کردن صریح نوعش تعریف کرد، یا با اجازه دادن به کامپایلر C# که نوعش را بر اساس مقدار اختصاص‌یافته استنباط کند (که به آن استنباط نوع می‌گویند). بنابراین، دو تعریف متغیر زیر معادل هم هستند:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

مقدار یک متغیر با عملگر `=` به‌روزرسانی می‌شود. نوع یک متغیر پس از تعریف هرگز تغییر نمی‌کند.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# یک [زبان شیءگرا][object-oriented-programming] است و همه‌ی توابع باید در یک «کلاس» تعریف شوند. برای تعریف یک کلاس از کلیدواژه‌ی `class` استفاده می‌شود. شیءها (یا _نمونه‌ها_) با استفاده از کلیدواژه‌ی `new` ساخته می‌شوند.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

به تابعی که داخل یک کلاس قرار دارد، _متد_ می‌گوییم. هر متد می‌تواند صفر یا چند پارامتر داشته باشد. نوع همه‌ی پارامترها باید صریحاً مشخص شود، برای پارامترها استنباط نوع وجود ندارد. به همین ترتیب، نوع بازگشتی هم باید صریحاً مشخص شود. مقدارها با استفاده از کلیدواژه‌ی `return` از متدها برگردانده می‌شوند. برای اینکه کد موجود در فایل‌های دیگر بتواند یک متد را فراخوانی کند، باید اصلاح‌کننده‌ی دسترسی `public` را اضافه کنید.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

متدها با نحوه‌ی نگارش نقطه (`.`) روی یک نمونه فراخوانی می‌شوند؛ در این کار اسم متدی که می‌خواهید فراخوانی کنید را مشخص می‌کنید و برای هر یک از پارامترهای متد، آرگومان می‌فرستید. آرگومان‌ها می‌توانند به‌صورت اختیاری اسم پارامتر متناظرشان را هم مشخص کنند.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

محدوده در C# بین دو کاراکتر `{` و `}` تعریف می‌شود.

C# از دو نوع کامنت پشتیبانی می‌کند. قبل از کامنت‌های تک‌خطی `//` می‌آید و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
