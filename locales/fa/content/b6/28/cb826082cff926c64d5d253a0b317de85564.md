# استفاده از `+` برای به‌هم‌چسباندن رشته‌ها

در این حالت، استفاده از `+` تقریباً قطعاً انتخاب درستی است، چون کوتاه‌تر است و برای به‌هم‌چسباندن‌های ساده اغلب سریع‌تر. اگر برایتان ناآشناست، بسته‌ی قدرتمند `fmt` را ببینید. همین بسته چیزی است که معمولاً برای به‌هم‌چسباندن رشته‌های پیچیده‌تر و دیگر نیازهای قالب‌بندی رشته به کار می‌رود.
