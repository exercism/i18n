# مقدمه

متد تابعی است با یک آرگومان ویژه به نام «گیرنده».
گیرنده در فهرست آرگومان‌های خودش، بین کلیدواژه‌ی `func` و اسم متد قرار می‌گیرد.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

شما فقط می‌توانید متدی تعریف کنید که نوع گیرنده‌اش در همان بسته‌ای تعریف شده باشد که متد در آن قرار دارد.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

دو نوع گیرنده وجود دارد: گیرنده‌های مقداری و گیرنده‌های اشاره‌گر.

متدهایی که گیرنده‌ی مقداری دارند، روی یک نسخه‌ی کپی از مقداری که به آن‌ها پاس داده می‌شود کار می‌کنند؛ یعنی هر تغییری که داخل متد روی گیرنده اعمال شود، برای فراخوان‌کننده قابل مشاهده نیست.

می‌توانید متدهایی با گیرنده‌ی اشاره‌گر اعلان کنید تا مقداری را که گیرنده به آن اشاره می‌کند تغییر دهید.
این کار با افزودن یک `*` به ابتدای اسم نوع انجام می‌شود؛ برای مثال در نوع `rect`، گیرنده‌ی اشاره‌گر به‌صورت `*rect` اعلان می‌شود.
این تغییرات برای فراخوان‌کننده‌ی متد نیز قابل مشاهده‌اند.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
