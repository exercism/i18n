# درباره

می‌توان یک پارامتر متد را با اختصاص دادن یک «مقدار پیش‌فرض» به آن، اختیاری کرد. هنگام فراخوانی متدی که «پارامترهای اختیاری» دارد، فراخوانی‌کننده لازم نیست مقداری برای آن‌ها ارسال کند. اگر برای یک پارامتر اختیاری مقداری ارسال نشود، از مقدار پیش‌فرض آن استفاده می‌شود.

پارامترهای اختیاری باید در انتهای فهرست پارامترها باشند؛ بعد از آن‌ها نمی‌تواند پارامتر غیراختیاری بیاید.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

می‌توان پارامتر اختیاری را با استفاده از عملگر `?` قبل از اسم متغیر، روی `null` تنظیم کرد:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
