# نصب

این مسیر در همه‌جا بر [Wren Console][wren-console] تکیه می‌کند تا یک محیط اجرای محلی برای Wren فراهم کند. یعنی فرض ما این است که همه‌ی اجرای Wren روی رایانه‌ی شما با [Wren Console][wren-console] انجام می‌شود. لطفاً این را با <abbr title="رابط خط فرمان">CLI</abbr> رسمی Wren اشتباه نگیرید. در دنیای ایده‌آل می‌توانستید از آن محیط اجرا استفاده کنید، اما در حال حاضر [چندین](https://github.com/wren-lang/wren/pull/1006) [مشکل](https://github.com/wren-lang/wren-cli/pull/105) [مختلف](https://github.com/wren-lang/wren-cli/issues/108) [دارد](https://github.com/wren-lang/wren-cli/pull/74) که آن را به گزینه‌ای کمتر از حد مطلوب برای یادگیری Wren با Exercism تبدیل می‌کند.

Wren Console از Wren CLI منشعب شده است، این مشکلات را برطرف می‌کند و قابلیت‌هایی اضافه می‌کند که تجربه‌ی یادگیری‌تان را روان‌تر می‌کند. نگران نباشید؛ دانش و مفاهیم زبان Wren که اینجا یاد می‌گیرید، هر جا که در آینده بخواهید از Wren استفاده کنید به کارتان می‌آید.

## نمای کلی نصب

- Git را برای فرمان `git` نصب کنید
- [Wren Console][wren-console] را برای فرمان `wrenc` نصب کنید

### نصب Git

باید فایل اجرایی `git` نصب شده و در مسیر شما قرار داشته باشد. Wren Package بسته‌ها را به همین شکل نصب می‌کند (مثل مجموعه‌ی آزمونی که برای آزمودن تمرین‌هایتان لازم دارید و غیره).

- **Windows** - [دانلود رسمی Git](https://git-scm.com/download/win) نقطه‌ی شروع خوبی است.
-  **Linux** - مدیر بسته‌ی مورد علاقه‌تان کمکتان می‌کند.
- **Mac** - همه‌ی نسخه‌های تازه‌ی Mac OS، `git` را از همان ابتدا همراه دارند.

می‌توانید با `git --version` مطمئن شوید که Git نصب است:

```
$ git --version
git version 2.31.1
```

اگر شماره‌ی نسخه دقیقاً یکسان نبود نگران نشوید، این موضوع معمولاً چندان مهم نیست.


### نصب Wren Console

#### Windows

به احتمال زیاد می‌خواهید [آخرین نسخه را از GitHub دانلود کنید][releases]. بعد از آن باید فایل را از حالت فشرده خارج کنید و فایل اجرایی `wrenc` را در مسیر خود کپی کنید.

همچنین می‌توانید با Visual Studio [از سورس بسازید][build-from-source].

#### Linux

می‌توانید [آخرین نسخه را از GitHub دانلود کنید][releases] یا [از سورس بسازید][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

و مطمئن شوید که در `PATH` شما در دسترس است.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

ساده‌ترین راه نصب، استفاده از tap و formula مربوط به Exercism در [Homebrew][homebrew] است:

```
brew tap exercism/wren
brew install wren-console
```

در غیر این صورت می‌توانید [آخرین نسخه را از GitHub دانلود کنید][releases] و همان‌طور که در دستورهای Linux گفته شد، آن را دستی نصب کنید. اگر با این کارها آشنا باشید، ساختن از سورس هم نسبتاً ساده است.

### آزمودن نصب

وقتی فکر می‌کنید فایل اجرایی را درست نصب کرده‌اید، بهتر است بررسی کنید که همه‌چیز کار می‌کند.

۱. یک _ترمینال_ باز کنید (`Terminal`، `cmd`، `Powershell`، `bash`، ...)
۲. فرمان `wrenc -v` را اجرا کنید

باید هم نسخه‌ی `wrenc` و هم نسخه‌ی Wren را در فهرست ببینید:

```
wrenc v0.3.1 (wren v0.4.0)
```

**توجه**: مهم است که یک پنجره‌ی _جدید_ ترمینال باز کنید. ممکن است پنجره‌های ترمینال باز، بعد از کامل شدن نصب به‌روز نشده باشند. یعنی ترمینال‌های باز نمی‌دانند که برنامه‌ی جدیدی نصب شده است.

> _**راهنما**_: `'wrenc' is not recognised`
>
> احتمالاً `wrenc` را در PATH خود قرار نداده‌اید... در MacOS و Linux می‌توانید با افزودن موارد زیر به
> `~/.bash_profile` یا `~/.zshrc` مسیر خود را تغییر دهید:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **نمی‌دانم که آیا اینها درست است یا نه.**
> در Windows منوی Start را باز کنید و «environment variables» را جست‌وجو کنید. باید
> ورودی `PATH` را ویرایش کنید و مسیر فایل‌های اجرایی `wrenc` را اینجا _اضافه_ کنید.
> معمولاً این‌ها در `C:\Program Files\nodejs` پیدا می‌شوند. اگر با
> `File Explorer` به اینجا بروید، باید `node.exe`، `npm.bat` و `npx.bat` را پیدا کنید.
>
> هر ترمینال بازی را ببندید و یکی تازه باز کنید.

## پیش‌نیازهای تمرین

برای دانلود CLI مربوط به `exercism` برای سیستم‌عامل خود، [این دستورها][cli-walkthrough] را دنبال کنید.

وقتی CLI راه‌اندازی و پیکربندی شد، اولین تمرین، یعنی `hello-world`، را دانلود کنید:

```bash
$ exercism download --exercise=hello-world --track=wren
```

سپس هر تمرین برای اجرای آزمون‌ها به چند بسته‌ی Wren نیاز دارد. این بسته‌ها را می‌توانید با اجرای این فرمان در پوشه‌ی تمرین نصب کنید:

```bash
$ wrenc package.wren install
```
