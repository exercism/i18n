# دستورالعمل‌ها

مثل تقریباً هر کسی که شغلی دارد، Layla، فضایی Lisp، گاهی لازم دارد گزارش‌هایی تهیه کند تا دیگران را از اطلاعاتی باخبر کند. او از شما می‌پرسد که آیا می‌توانید به او کمک کنید تا داده‌هایی را که برای این گزارش‌ها در اختیار دارد قالب‌بندی کند.

## 1. قالب‌بندی مقادیر فصلی

Layla اول از همه به یک تابع نیاز دارد: `format-quarter-value` که دو پارامتر می‌گیرد، یعنی فصل تقویمی و مقدار، و آن‌ها را برای گزارش قالب‌بندی می‌کند. باید به یک رشته ارزیابی شود.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. گزارش دو فصل

Layla برای تابع `format-quarter-value` از شما تشکر می‌کند و می‌گوید که در تابع *بعدی* که لازم است، بسیار به کار خواهد آمد.

گزارش بعدی باید فصل و مقدار را برای ۲ فصل، روی دو خط نشان دهد.

همچنین خروجی باید به جریانی برود که به عنوان آرگومان اول داده شده است.

برای مثال، `(format-two-quarters t "last" 3.14 "this" 0)` نتیجه‌ی زیر را روی خروجی استاندارد تولید می‌کند:

```

The value last quarter: 3.14
The value this quarter: 0

```

به خطوط خالی اطراف آن دقت کنید.

## 3. خوانا بودن برای انسان در برابر فضایی Lisp

Layla فراموش کرد به شما بگوید که فضایی‌های Lisp دوست دارند مقادیر را به شکلی ببینند که به عنوان داده‌ی Lisp خوانا باشد. بنابراین به یک تابع جدید نیاز دارند که خروجی آن به عنوان داده‌ی Lisp قابل خواندن باشد (و باز هم به جریان مشخص‌شده فرستاده شود):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
