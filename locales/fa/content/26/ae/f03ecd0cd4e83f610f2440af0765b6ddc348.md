# پیوست دستورالعمل

## واژه‌ها

پیاده‌سازی کنید:

- `grep ( pattern flags files -- lines )`

`pattern` رشته‌ی جست‌وجو است، `flags` آرایه‌ای است از صفر یا چند رشته‌ی پرچم `"-n"`، `"-l"`، `"-i"`، `"-v"` و `"-x"`. `files` هم آرایه‌ای است از یک یا چند اسم فایل. خطوط منطبق را (همراه با هر پیشوند اسم فایل و شماره خط که خواسته شده است) به‌صورت آرایه‌ای از رشته‌ها برگردانید.

وقتی پرچم `-l` داده می‌شود، آرایه‌ای از اسم فایل‌هایی را برگردانید که دست‌کم یک تطابق دارند.

## خواندن فایل‌ها

خطوط یک فایل را با `file-lines` بخوانید و یک کدگذاری هم به آن بدهید:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

سه فایل نمونه (`iliad.txt`، `midsummer-night.txt` و `paradise-lost.txt`) همراه تمرین در پوشه‌ی کاری قرار دارند، پس خواندنشان با اسم به‌سادگی کار می‌کند.
