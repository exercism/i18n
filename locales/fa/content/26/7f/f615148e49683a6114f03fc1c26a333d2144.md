# دستورالعمل‌ها

«عدد مختلط» عددی به شکل `a + b * i` است که در آن `a` و `b` حقیقی‌اند و `i` در `i^2 = -1` صدق می‌کند.

به `a` قسمت حقیقی و به `b` قسمت موهومی `z` می‌گویند.
مزدوج عدد `a + b * i` عدد `a - b * i` است.
قدر مطلق عدد مختلط `z = a + b * i` یک عدد حقیقی است: `|z| = sqrt(a^2 + b^2)`. مربع قدر مطلق `|z|^2` حاصل ضرب `z` در مزدوجش است.

جمع یا تفریق دو عدد مختلط، با جمع یا تفریق جداگانه‌ی قسمت‌های حقیقی و موهومی آن‌ها انجام می‌شود:
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

نتیجه‌ی ضرب طبق تعریف این است:
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

معکوس یک عدد مختلط ناصفر برابر است با
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

اگر عدد مختلط `a + i * b` را بر عدد مختلط دیگری مانند `c + i * d` تقسیم کنیم، به این می‌رسیم:
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

رساندن `e` به یک توان مختلط را می‌توان به شکل `e^(a + i * b) = e^a * e^(i * b)` نوشت که جمله‌ی آخر آن با فرمول اویلر، `e^(i * b) = cos(b) + i * sin(b)`، به دست می‌آید.

این عملیات را پیاده‌سازی کنید:
 - جمع، تفریق، ضرب و تقسیم دو عدد مختلط،
 - مزدوج، قدر مطلق و توان یک عدد مختلط داده‌شده.


فرض کنید زبان برنامه‌نویسی‌ای که استفاده می‌کنید پیاده‌سازی‌ای از اعداد مختلط ندارد.
