# درباره

[عبارت‌های `throw`][throw-expressions] جایگزینی برای دستورهای `throw` هستند و به‌ویژه می‌توانند توان عبارت‌های سه‌گانه و دیگر عبارت‌های ترکیبی را افزایش دهند.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

اگر `str` در کد بالا `null` باشد، یک استثنا پرتاب می‌شود.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
