# درباره

در Go ۱.۱۸، Go پشتیبانی از **جنریک** را اضافه کرد.
جنریک به شما امکان می‌دهد تابع‌ها و ساختارهای داده‌ای بنویسید که با انواع مختلف کار می‌کنند، بدون آنکه کد را تکرار کنید.

## چرا جنریک؟

در Go، تابع‌ها و انواع معمولاً با نوع‌های مشخصی کار می‌کنند، مثل `int` یا `string`.
پیش از جنریک، برای پشتیبانی از چند نوع دو انتخاب داشتید.
اول، می‌توانستید چند تابع با اسم‌های مختلف بنویسید، مثل `SumInts` و `SumFloats`.
این رویکرد کد تکراری‌ای می‌سازد که نگهداری‌اش دشوار است.
دوم، می‌توانستید از رابط خالی `any` (`interface{}`) استفاده کنید.
اما رابط خالی بررسی نوع در زمان کامپایل را از میان می‌برد و در زمان اجرا به تأیید نوع نیاز دارد.
جنریک با فراهم کردن ایمنی نوع و پرهیز همزمان از تکرار کد، این مشکل را حل می‌کند.

## تابع‌های جنریک

شما یک تابع جنریک را با افزودن **پارامترهای نوع** داخل کروشه `[...]` بعد از اسم تابع تعریف می‌کنید.
اینجا نمونه‌ای از یک تابع جنریک است که یک اسلایس معکوس‌شده برمی‌گرداند:

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

در این مثال، `T` یک پارامتر نوع است.
می‌توانید `T` را جایگزینی برای یک نوع واقعی در نظر بگیرید.
کلیدواژه‌ی `any` داخل کروشه‌ها یک **محدودیت نوع** است.
محدودیت به کامپایلر می‌گوید چه نوع‌هایی برای `T` مجازند.
اینجا `any` یعنی `T` می‌تواند هر نوعی باشد.

### فراخوانی تابع‌های جنریک

می‌توانید یک تابع جنریک را با گذاشتن نوع واقعی داخل کروشه فراخوانی کنید.
به این نوع واقعی **آرگومان نوع** می‌گویند.

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

در بیشتر موارد، کامپایلر Go می‌تواند نوع را به‌طور خودکار از آرگومان‌های تابع تشخیص دهد.
به این ویژگی **استنتاج نوع** می‌گویند.
با استنتاج نوع، لازم نیست آرگومان نوع را داخل کروشه بنویسید.

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

در این مثال، کامپایلر می‌بیند که `words` یک اسلایس از رشته‌ها است، پس نتیجه می‌گیرد که `T` همان `string` است.

## محدودیت‌های نوع

هر پارامتر نوع باید یک محدودیت داشته باشد.
یک محدودیت مشخص می‌کند کدام نوع‌ها را می‌توانید به‌عنوان آرگومان نوع به کار ببرید.
محدودیت همچنین تعیین می‌کند چه عملیاتی روی مقادیر آن نوع مجاز است.

### محدودیت `any`

محدودیت `any` هر نوعی را مجاز می‌کند.
در Go، `any` نام دیگری برای رابط خالی `interface{}` است.
چون `any` همه‌ی نوع‌ها را مجاز می‌کند، تابع تنها می‌تواند عملیاتی انجام دهد که روی همه‌ی نوع‌های Go کار می‌کند.
برای نمونه، اگر دو مقدار `any` داشته باشید که اسلایس نگه می‌دارند، نمی‌توان آن‌ها را با `==` مقایسه کرد، چون اسلایس‌ها را نمی‌توان با `==` مقایسه کرد.

### محدودیت `comparable`

Go یک محدودیت توکار به اسم `comparable` فراهم می‌کند.
محدودیت `comparable` هر نوعی را مجاز می‌کند که از عملگرهای `==` و `!=` پشتیبانی کند.
انواع قابل مقایسه شامل نوع منطقی، عدد، رشته، اشاره‌گر، کانال و همچنین ساختار یا آرایه‌ای است که از انواع قابل مقایسه ساخته شده باشند.

اینجا نمونه‌ای از تابعی است که بررسی می‌کند آیا یک اسلایس عنصر مشخصی را در خود دارد یا نه:

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

چون `T` از محدودیت `comparable` استفاده می‌کند، به کار بردن `elem == target` معتبر است.
اگر `comparable` را با `any` عوض کنید، کامپایلر خطا گزارش می‌کند.

### محدودیت‌های سفارشی با مجموعه‌های نوع در رابط‌ها

از Go ۱.۱۸ به بعد، رابط‌ها می‌توانند علاوه بر متدها مجموعه‌ای از نوع‌ها را نیز تعریف کنند.
می‌توانید از نویسه‌ی خط عمودی `|` برای فهرست کردن نوع‌های مجاز در یک رابط استفاده کنید.

```go
type Number interface {
    int | int64 | float64
}
```

حالا می‌توانید از `Number` به‌عنوان محدودیت یک تابع استفاده کنید:

```go
func Double[T Number](value T) T {
    return value * 2
}
```

چون همه‌ی نوع‌های `Number` از عملگر `*` پشتیبانی می‌کنند، Go به کار بردن `value * 2` را داخل تابع مجاز می‌داند.

### تقریب نوع پایه با `~`

گاهی یک تعریف نوع سفارشی بر پایه‌ی یک نوع ابتدایی می‌سازید:

```go
type MyInt int
```

محدودیت `Number` که بالا تعریف شد فقط نوع‌های دقیق `int`، `int64` و `float64` را مجاز می‌کند.
اگر مقداری از نوع `MyInt` را به `Double` بدهید، کامپایلر خطا می‌دهد، چون `MyInt` با `int` مطابقت ندارد.
برای مجاز کردن هر نوعی که نوع پایه‌اش `int` است، یک تیلدا `~` پیش از نوع اضافه کنید:

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

حالا می‌توانید از `Double` با مقادیر نوع `MyInt` استفاده کنید.

### محدودیت `cmp.Ordered`

کتابخانه‌ی استاندارد محدودیت `cmp.Ordered` را در [بسته‌ی `cmp`][doc-cmp] فراهم می‌کند.
محدودیت `cmp.Ordered` هر نوعی را مجاز می‌کند که از عملگرهای مقایسه `<`، `<=`، `>` و `>=` پشتیبانی کند.

## نوع‌های جنریک

می‌توانید از پارامترهای نوع برای تعریف نوع‌های جنریک هم استفاده کنید، مثل ساختارها.
اینجا نمونه‌ای از یک ساختار داده‌ی جنریک `Stack` است:

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

وقتی متغیری از یک نوع جنریک تعریف می‌کنید، باید آرگومان نوع را داخل کروشه بدهید:

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

استنتاج نوع فقط برای تابع‌های جنریک کار می‌کند.
هنگام ساختن مقدار از یک نوع جنریک، همیشه باید آرگومان نوع را مشخص کنید.

## چه وقت از جنریک استفاده کنیم

جنریک ویژگی توانمندی است، اما لازم نیست برای هر مسئله‌ای از آن استفاده کنید.

در موقعیت‌هایی مثل این‌ها از جنریک استفاده کنید:
- ساختارهای داده‌ای می‌سازید، مثل درخت، لیست پیوندی یا کش، که با هر نوع عنصری کار می‌کنند.
- تابع‌های کمکی می‌نویسید که روی اسلایس‌ها یا مپ‌های هر نوعی کار می‌کنند، مثل فیلتر کردن، مرتب‌سازی یا جست‌وجو.
- برای چند نوع به پیاده‌سازی دقیقاً یکسانی نیاز دارید و ایمنی نوع در زمان کامپایل می‌خواهید.

در موقعیت‌هایی مثل این‌ها به‌جای آن از رابط‌ها استفاده کنید:
- رفتار و متدها برایتان مهم است، نه نوع داده‌ی زیرین.
  برای نمونه، اگر می‌خواهید داده را از منابعی با انواع گوناگون (فایل، شبکه، TTY) بخوانید و پردازش کنید، `func Process(src io.Reader)` را به `func Process[T](src T)` ترجیح می‌دهید.
- نوع‌های مختلف برای انجام کارشان به پیاده‌سازی‌های متفاوت متد نیاز دارند.
