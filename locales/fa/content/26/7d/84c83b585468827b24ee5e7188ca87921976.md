# دستورالعمل‌ها

ویولن را با گوش و در مقایسه با یک نت مرجع کوک می‌کنند. سیم‌ها از نظر زیر و بمی خیلی از هم دورند و اعداد مربوط به آن‌ها عددهای صحیح نیستند.

هر پنج تمرین در کلاس `TUNING_THE_STRINGS` قرار می‌گیرند.

## 1. یک اکتاو بالاتر

نت یک اکتاو بالاتر، دو برابر فرکانس است.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. یک اکتاو پایین‌تر

یک اکتاو پایین‌تر، نصف است.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. درست در میانه

دو فرکانس به شما داده می‌شود؛ فرکانسی را برگردانید که دقیقاً در میانه‌ی آن دو قرار دارد.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. چقدر دور از هم؟

وقتی دو نت به هم نزدیک‌اند ولی یکسان نیستند، به ازای هر سیکل اختلاف میانشان، هر ثانیه یک ضربان می‌شنوید. فاصله‌ی میان دو فرکانس را برگردانید. پاسخ هرگز منفی نیست، فارغ از اینکه کدام نت بالاتر باشد.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. تقسیم زمان تمرین

با توجه به تعداد دقیقه‌ها و تعداد نوازندگان، به هر کدام چند دقیقه می‌رسد؟ تعداد دقیقه‌ها و نوازندگان عددهای صحیح‌اند، اما پاسخ ممکن است صحیح نباشد.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
