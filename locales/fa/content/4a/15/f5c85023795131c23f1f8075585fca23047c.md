# درباره

بسیاری از عملگرها را می‌توان به‌صورت [«انتساب‌های ترکیبی»][compound-assignment] هم به کار برد. این‌ها یک شکل کوتاه‌نویسی‌اند که در آن `x = op y` را می‌توان به‌صورت `x op= y` نوشت:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
