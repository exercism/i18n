# مقدمه

## اتحادیه‌ی تفکیک‌شده

نوع «اتحادیه‌ی تفکیک‌شده» نماینده‌ی تعداد ثابتی از حالت‌های نام‌دار است. هر مقدار از یک اتحادیه‌ی تفکیک‌شده دقیقاً با یکی از حالت‌های نام‌دار متناظر است.

اتحادیه‌ی تفکیک‌شده با کلیدواژه‌ی `type` تعریف می‌شود و حالت‌هایش با کاراکترهای خط عمودی (`|`) از هم جدا می‌شوند:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

هر حالت از یک اتحادیه‌ی تفکیک‌شده می‌تواند به‌صورت اختیاری داده‌ای همراه داشته باشد و حالت‌های مختلف می‌توانند نوع‌های متفاوتی از داده داشته باشند. اگر هیچ‌کدام از حالت‌ها داده‌ی همراه نداشته باشند، اتحادیه‌ی تفکیک‌شده شبیه چیزی است که در زبان‌های دیگر معمولاً «برشماری» (یا «enum») نامیده می‌شود.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

ساختن مقدار برای یک حالت خاص با ارجاع به اسم آن انجام می‌شود (مثلاً `Success`). از آنجا که اسم‌های حالت فقط توابع سازنده‌اند، می‌توان داده‌ی همراه را مانند یک آرگومان معمولی تابع ارسال کرد. اگر اتحادیه‌ی تفکیک‌شده‌ی دیگری حالتی با همین اسم تعریف کرده باشد، باید از اسم کامل آن استفاده کنید (مثلاً `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

اتحادیه‌های تفکیک‌شده «برابری ساختاری» دارند؛ یعنی دو مقداری که برای یک حالت یکسان و با داده‌ی (اختیاری) یکسان ساخته شده‌اند، هم‌ارزند.

هرچند می‌توان برای کار با اتحادیه‌های تفکیک‌شده از عبارت‌های `if/elif/else` استفاده کرد، روش توصیه‌شده برای کار با آن‌ها «تطبیق الگو» با استفاده از «الگوی شناسه» است:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
