# مقدمه

تابع به‌طور پیش‌فرض پیوند خارجی دارد و می‌توان آن را از هر فایل دیگری در پروژه فراخوانی کرد.
برای اطلاعات بیشتر درباره‌ی پیوند، لطفاً به [مفهوم پیوند](../linkage/introduction.md#Introduction) مراجعه کنید.
تابع `static` را فقط می‌توان در همان فایل مبدأی که در آن تعریف شده است فراخوانی کرد.

برای مثال

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
