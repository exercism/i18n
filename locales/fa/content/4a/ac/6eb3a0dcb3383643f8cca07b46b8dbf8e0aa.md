# درباره

یک [`Time`][time] در Go نوعی است که یک لحظه در زمان را توصیف می‌کند.
می‌توان از طریق متدهای آن به اطلاعات تاریخ و زمان دسترسی داشت، آن‌ها را مقایسه و دستکاری کرد، اما چند تابع هم هستند که روی خود پکیج `time` فراخوانی می‌شوند.
تاریخ و زمان کنونی را می‌توان از طریق تابع [`time.Now`][now] به دست آورد.

تابع [`time.Parse`][parse] رشته‌ها را به مقادیر نوع `Time` تجزیه می‌کند.
Go روش ویژه‌ای برای تعریف قالبی دارد که برای تجزیه انتظار دارید.
باید نمونه‌ای از قالب را با استفاده از مقادیر این برچسب زمانی ویژه بنویسید:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

برای مثال:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

متد [`Time.Format()`][format] نمایش رشته‌ای زمان را برمی‌گرداند.
دقیقاً مثل تابع `Parse`، قالب هدف هم دوباره با نمونه‌ای تعریف می‌شود که از مقادیر برچسب زمانی ویژه استفاده می‌کند.

برای مثال:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## گزینه‌های قالب

برای قالب سفارشی، از ترکیبی از این گزینه‌ها استفاده کنید.
در Go، [ثابت‌های قالب‌بندی][const] تاریخ و برچسب زمانی از پیش تعریف‌شده هم در دسترس هستند.

| زمان        | گزینه‌ها                                        |
| ----------- | ---------------------------------------------- |
| سال        | 2006 ; 06                                      |
| ماه       | Jan ; January ; 01 ; 1                         |
| روز        | 02 ; 2 ; \_2 (برای ۰ ابتدایی)                 |
| روز هفته     | Mon ; Monday                                   |
| ساعت        | 15 ( قالب ۲۴ ساعته ) ; 3 ; 03 (ق.ظ یا ب.ظ) |
| دقیقه      | 04 ; 4                                         |
| ثانیه      | 05 ; 5                                         |
| نشانه‌ی ق.ظ/ب.ظ  | PM                                             |
| روز سال | 002 ; \_\_2                                    |

نوع `time.Time` متدهای گوناگونی برای دسترسی به یک زمان مشخص دارد. مثلاً ساعت: [`Time.Hour()`][hour] ، ماه: [`Time.Month()`][month].
توضیح بیشتر درباره‌ی نحوه‌ی کار آن را می‌توانید در [مستندات رسمی][time] بیابید.

[`time`][time] نوع دیگری هم دارد، [`Duration`][duration]، که زمان سپری‌شده را نمایش می‌دهد، به‌علاوه پشتیبانی از مکان‌ها/مناطق زمانی، تایمرها و سایر قابلیت‌های مرتبط که در مفهوم دیگری به آن‌ها پرداخته می‌شود.
