# مقدمه

توابع در Kotlin شهروندان درجه‌یک هستند.
این یعنی می‌توان آن‌ها را در متغیرها ذخیره کرد، به‌عنوان آرگومان پاس داد و حتی از توابع دیگر برگرداند.
برای مثال، انتساب یک تابع به متغیر `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

یک تابع می‌تواند تابع دیگری را هم برگرداند:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

پس از انتساب، می‌توان تابع را از طریق متغیر فراخوانی کرد، درست مثل یک تابع معمولی دیگر:
```kotlin
addOne(3)
// => 4
```

## اعلان نوع توابع

می‌توان نوع یک متغیر یا پارامتر را با نحوه‌ی نگارش `(parameter types) -> return type` اعلان کرد.
برای مثال، اعلان یک متغیر:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

و برای پارامتر یک تابع:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## عبارات لامبدا

عبارت لامبدا روش کوتاه‌تری برای تعریف یک تابع است.
این عبارت‌ها به شکل `{ parameters -> body }` نوشته می‌شوند.
عبارت، آخرین مقدارِ آخرین دستور در بدنه را برمی‌گرداند.
برای مثال:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

وقتی اطلاعات کافی باشد، Kotlin می‌تواند نوع‌ها را استنباط کند.
برای مثال، مثال‌های بالا را می‌توان به این شکل هم نوشت:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` برای لامبداهای تک‌پارامتری

وقتی عبارت فقط یک پارامتر داشته باشد، می‌توان آن پارامتر را حذف کرد.
در این صورت Kotlin پارامتری به اسم `it` را در بدنه در دسترس قرار می‌دهد.
برای مثال:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## پاس دادن لامبدای پایانی

وقتی آخرین آرگومان یک تابع یک لامبدا باشد، عبارت لامبدا مستقیماً _بعد از_ پرانتزها نوشته می‌شود.
برای مثال:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
