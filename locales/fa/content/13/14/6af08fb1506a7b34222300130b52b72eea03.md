# دستورالعمل‌ها

هرچه بیشتر درباره‌ی برنامه‌نویسی یاد می‌گیرید، بیشتر به این فکر می‌افتید که شاید این کار چیزی بیش از یک مُد زودگذر باشد.
شاید حتی فرصت‌های تجاری هم در آن باشد: مردم کد می‌نویسند، می‌خواهند آن را ذخیره کنند، به اشتراک بگذارند، با هم همکاری کنند و شاید حتی بازخورد بگیرند.

خیلی خب، بیایید این کار را بکنیم؛ بیایید سرویسی بسازیم که مردم را به کدنویسی تشویق کند: هی، هی، مردم، شروع کنید به استفاده از git!
بیایید اسمش را بگذاریم... GitHup.

شما ساخت یک REST JSON API را شروع می‌کنید: کاربران، درخواست‌های ادغام، نظرات؛ بک‌اند به‌سرعت تمام می‌شود.
در ادامه نمونه‌ای از داده‌ای را می‌بینید که وقتی فهرست نظرات یک درخواست ادغام را از سرور می‌خواهید، برگردانده می‌شود:

```json
[

    "id": 256,
    "pull_request_review_id": 42,
    "user": {
      "id": 101,
      "login": "octodog",

      "self": {

      },
      "pull_request": {
        "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/1"
      }

  {
    "id": 11,
    "pull_request_review_id": null,
    "user": {
      "id": 2,
      "login": "hexacat",
      "name": "Alex Kate",
      "avatar_url": "https://githup.com/images/error/hexacat_happy.gif",
      "site_admin": true

      "self": {
        "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1"
```

البته فرانت‌اند با Elm نوشته می‌شود، اما اول باید بفهمید این رمزگشاها و رمزگذارهای بدنام چه چیزی هستند.

```exercism/note
جدا از این داستان طنز، الزامات این تمرین مستقیماً از نقطه‌های پایانی REST API گیت‌هاب برای نظرات بررسی درخواست ادغام گرفته شده‌اند.
برای ساده‌تر شدن کار، برخی فیلدها از شمای JSON حذف شده‌اند، اما این تمرین تا حد ممکن به برنامه‌های دنیای واقعی نزدیک است.
```

## 1. شناسه، لطفاً!

چشم تیزبینتان متوجه شده است که هم نظرات و هم کاربران یک فیلد `id` دارند؛ جای خوبی برای شروع.

`decodeId` را طوری تعریف کنید که بتواند یک شیء JSON را با یک `id` عدد صحیح رمزگشایی کند.

```elm
Decode.decodeString decodeId """{id: 10}"""
    --> Ok 10
```

## 2. اسم من چه بود؟

در مثال بالا متوجه می‌شوید که همه‌ی کاربران اسم ندارند.

`decodeName` را طوری تعریف کنید که اگر فیلدی به اسم `name` وجود داشت، رشته‌ی درون آن را رمزگشایی کند.
اسمی نیست؟ اشکالی ندارد، کافی است `Nothing` را برگردانید.
این رمزگشا هرگز نباید شکست بخورد.

```elm
Decode.decodeString decodeName """{"id": 10, "name": "Otto"}"""
    --> Ok (Just Otto)

Decode.decodeString decodeName """null"""
    --> Ok Nothing
```

## 3. کاربر؟ او را که نمی‌شناسم!

برای رمزگشایی کاربران تقریباً تا نیمه‌ی راه رسیده‌ایم؛ بیایید تمامش کنیم.

`decodeUser` را طوری تعریف کنید که بتواند یک شیء JSON کاربر را رمزگشایی کند.
حتماً در `decodeUser` از `decodeId` و `decodeName` استفاده کنید.

```elm
Decode.decodeString decodeUser
    """
    {
      "id": 101,
      "login": "octodog",
      "avatar_url": "https://githup.com/images/error/octodog_happy.gif",
      "site_admin": false
    }
    """
    --> Ok
    -->   { id = 101
    -->   , name = Nothing
    -->   , login = "octodog"
    -->   , avatarUrl = "https://githup.com/images/error/octodog_happy.gif
    -->   , siteAdmin = False
    -->   }
```

## 4. من یک نظر مستقل و قدرتمندم

برخی نظرات در یک بررسی درخواست ادغام مستقل هستند و بنابراین `pull_request_review_id` ندارند.
اما مشخصات می‌گوید در چنین حالتی هنوز باید فیلد `pull_request_review_id` وجود داشته باشد، ولی مقدارش باید `null` باشد؛ همان `Nothing` فقیر.

`decodePullRequestReviewId` را طوری تعریف کنید که اگر فیلد `pull_request_review_id` وجود داشت، یک عدد صحیح را در آن رمزگشایی کند.
اگر عدد صحیحی وجود ندارد، باید یک `null` باشد؛ و اگر `null` وجود ندارد، رمزگشا باید شکست بخورد.

```elm
Decode.decodeString decodePullRequestReviewId """{"pull_request_review_id": 3}"""
    --> Ok (Just 3)

Decode.decodeString decodePullRequestReviewId """{"pull_request_review_id": null}"""
    --> Ok Nothing

Decode.decodeString decodePullRequestReviewId """{"id": 3}"""
    --> Err ...
```

## 5. شغل دوم

بعد نوبت این فیلد `side` است که ظاهر جالبی دارد.
در یک بررسی درخواست ادغام، می‌توانید روی کدی که حذف شده است (سمت `Left` صفحه) یا روی کدی که اضافه شده است (سمت `Right` صفحه) نظر بگذارید.

`decodeSide` را طوری تعریف کنید که بتواند `"LEFT"` یا `"RIGHT"` را در فیلد `side` رمزگشایی کند و آن را به نوع متناظرش نگاشت کند.

```elm
Decode.decodeString decodeSide """{"side": "LEFT"}"""
    --> Ok Left

Decode.decodeString decodeSide """{"side": "middle?"}"""
    --> Err ...
```

## 6. بیداری پیوندها

هر نظر مجموعه‌ای از پیوندها دارد که به نظر می‌رسد از نظری به نظر دیگر یکسان نیست.

`decodeLinks` را طوری تعریف کنید که بتواند مجموعه‌ای از URLها را در فیلد `_links` رمزگشایی کند.
اسم‌ها و تعداد پیوندها می‌تواند متفاوت باشد؛ مطمئن شوید که این موضوع را در نظر می‌گیرید.
خود پیوندها اشیاء JSON هستند و همیشه باید یک فیلد `href` داشته باشند.

```elm
Decode.decodeString decodeLinks """
    {
      "_links": {
        "self": { "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1" },
        "html": { "href": "https://githup.com/octodog/Hello-World/pull/1#discussion-diff-1" },
        "pull_request": { "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/1" }
      }
    }
    """
    --> Ok
    -->   (Dict.fromList
    -->       [ ( "self", "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1" )
    -->       , ( "html", "https://githup.com/octodog/Hello-World/pull/1#discussion-diff-1" )
    -->       , ( "pull_request", "https://api.githup.com/repos/octodog/Hello-World/pulls/1" )
    -->       ]
    -->   )
```

## 7. بله، نظرات

تقریباً رسیده‌ایم؛ بیایید تمامش کنیم.

`decodeComment` و `decodeComments` را طوری تعریف کنید که به‌ترتیب بتوانند یک شیء JSON نظر یا فهرستی از نظرات را رمزگشایی کنند.
حتماً در `decodeComment` از همه‌ی توابعی که تا اینجا تعریف کرده‌اید، به‌جز `decodeName`، استفاده کنید.
مسلماً `decodeComments` هم باید از `decodeComment` استفاده کند.

## 8. همه‌چیز به هم می‌پیوندد

در میان همه‌ی این‌ها یک قابلیت دیگر کم است: توانایی فرستادن یک نظر تازه به سرور.
برای این کار باید برعکس یک رمزگشا عمل کنید؛ باید بتوانید یک `Comment` الم را به یک `Value` از نوع JSON تبدیل کنید.

`encodeComment` را طوری تعریف کنید که بتواند هر `Comment` معتبری را رمزگذاری کند.
ترتیب فیلدها اهمیتی ندارد، تا زمانی که رمزگذار بتواند مقداری تولید کند که `decodeComment` قادر به رمزگشایی آن باشد.
