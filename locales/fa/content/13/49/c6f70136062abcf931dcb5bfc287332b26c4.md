# مقدار منطقی

Haskell نوعی دارد که به نام [`Bool`][bools] شناخته می‌شود.
این یک نوع شمارشی از `True` و `False` است.

## عملگرهای منطقی

Haskell سه عملگر «منطقی» دارد (`not`، `||` و `&&`) که مقادیر منطقی را با هم ترکیب می‌کنند و عبارت‌هایی می‌سازند که مقادیر متفاوتی تولید می‌کنند.

### و (`&&`)

[عملگر _و_][and] در Haskell با `&&` نمایش داده می‌شود و اگر هر دو مقدار `True` باشند `True` را برمی‌گرداند؛ در غیر این صورت `False` را برمی‌گرداند.
هنگام استفاده از عملگر _و_، یک مقدار منطقی در سمت راست `&&` و دیگری در سمت چپ قرار می‌گیرد.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### یا (`||`)

[عملگر _یا_][or] در Haskell با `||` نمایش داده می‌شود و اگر **حداقل یکی** از مقادیر داده‌شده `True` باشد `True` را برمی‌گرداند.
اگر هر دو مقدار `False` باشند، `False` را برمی‌گرداند.
هنگام استفاده از عملگر _یا_، یک مقدار منطقی باید در سمت راست `||` و دیگری در سمت چپ قرار گیرد.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### نقیض (`not`)

عملگر _نقیض_ در Haskell با `not` نمایش داده می‌شود؛ اگر مقدار منطقی داده‌شده `False` باشد `True` را برمی‌گرداند و اگر `True` داده شود `False` را برمی‌گرداند.
هنگام استفاده از عملگر _نقیض_، یک مقدار منطقی باید بعد از عملگر (`not`) قرار گیرد.

```haskell
not True
-- -> False

not False
-- -> True
```

## استفاده از پرانتز (`()`)

هنگام کار با مقادیر منطقی، می‌توانید از «پرانتز» استفاده کنید تا تعیین کنید کدام مقدار منطقی اول ارزیابی شود.
بسته به اینکه پرانتزها چگونه به کار روند، نتیجه می‌تواند متفاوت باشد.
در Haskell، آنچه داخل پرانتز باشد اول ارزیابی می‌شود.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

چون آنچه داخل پرانتز است اول ارزیابی می‌شود، در مثال زیر عملگر _نقیض_ روی عبارت داخل پرانتز اعمال می‌شود.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```
