# نصب

برای مسیر زبان C لازم است نرم‌افزارهای زیر روی سیستم شما نصب باشند:

* یک کامپایلر مدرن برای زبان C
* ابزار ساخت Make

محیط توسعه‌ی یکپارچه (IDE) Xcode شرکت اپل، کامپایلر و سیستم ساخت بومی را در یک برنامه‌ی واحد ادغام می‌کند.
محیط‌های Linux معمولاً کامپایلر و سیستم ساخت بومی را در قالب ابزارهای جداگانه‌ی خط فرمان در اختیار می‌گذارند.

## Linux

اگر از Linux استفاده می‌کنید، برای کامپایلر به gcc یا clang نیاز دارید و برای ساخت بومی هم به `make` نیاز خواهید داشت.
Make روی بیشتر سیستم‌های یونیکس از پیش نصب شده است، اما به احتمال زیاد از طریق مدیر بسته‌ی سیستم شما هم در دسترس است.
روی توزیع‌های مبتنی بر Debian و Ubuntu، اگر این ابزارها از قبل نصب نباشند، می‌توانید همه‌ی آنچه لازم دارید را با `sudo apt-get install build-essential` نصب کنید.

## MacOS

اگر از MacOS استفاده می‌کنید، می‌توانید gcc یا clang را با [Homebrew][] و از طریق `brew install gcc` یا `brew install llvm` نصب کنید.

## Windows

به کاربران Windows 10 توصیه می‌شود از [Windows Subsystem for Linux][] استفاده کنند و دستورالعمل Linux را که در بالا آمد، دنبال کنند.

اگر از نسخه‌ی قدیمی‌تری از Windows استفاده می‌کنید یا WSL Bash در دسترس شما نیست، می‌توانید از [MSYS][] یا [mingw-w64][] استفاده کنید.

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
