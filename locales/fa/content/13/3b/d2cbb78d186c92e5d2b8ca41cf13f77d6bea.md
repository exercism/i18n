# دستورالعمل‌ها

یک عبارت را به سرواژه‌اش تبدیل کنید.

اهل فناوری عاشق TLA (سرواژه‌های سه‌حرفی) خودشان هستند!

کمک کنید چند اصطلاح تخصصی بسازیم و برنامه‌ای بنویسید که نامی طولانی مانند Portable Network Graphics را به سرواژه‌اش (PNG) تبدیل کند.

با نشانه‌های نگارشی این‌طور رفتار می‌شود: خط تیره جداکننده‌ی واژه‌هاست (مثل فاصله)؛ بقیه‌ی نشانه‌های نگارشی را می‌توان از ورودی حذف کرد.

برای مثال:

| ورودی                     | خروجی |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
