# دستورالعمل‌ها

در ادامه‌ی مضمون بازی جادوگران و جنگجویان، حالا وقت آن است که یک متد همه‌کاره برای انداختن تاس اضافه کنیم. این تاس همان تاس سنتی ۱۸ وجهی با اعداد ۱ تا ۱۸ خواهد بود. بازیکن‌ها همچنین یک «قدرت جادو» تولید می‌کنند.

## 1. به بازیکنِ _جادوگران و جنگجویان_ امکان بدهید تاس بیندازد.

متد `RollDie()` را روی کلاس `Player` پیاده‌سازی کنید.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. بازیکن‌ها به قدرتشان نیاز دارند. راهی برای تولید قدرت جادو فراهم کنید

متد `GenerateSpellStrength()` را روی کلاس بازیکن پیاده‌سازی کنید. قدرت جادو بین 0.0 و 100.0 است، اما خود 100.0 شامل نمی‌شود.

توجه کنید که قدرت جادو باید یک عدد حقیقی باشد (نه یک عدد صحیح) تا احتمال مساوی شدن هنگام مقایسه‌ی قدرت دو حریف کمتر شود.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
