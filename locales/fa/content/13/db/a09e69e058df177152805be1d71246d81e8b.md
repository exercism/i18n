# دستورالعمل‌ها

باشگاه نت‌بال شما باید بعد از هر دور، جدول رده‌بندی‌اش را محاسبه کند.

هر چهار کار در کلاس `NETBALL_LADDER` انجام می‌شوند.

## 1. امتیازهای جدول رده‌بندی

برد ۴ امتیاز و تساوی ۲ امتیاز ارزش دارد. باخت هیچ امتیازی ندارد.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. تفاضل گل

گل‌های زده منهای گل‌های خورده. ممکن است منفی باشد.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. ربع‌های کامل بازی‌شده

هر ربع ۱۵ دقیقه است. اگر تعداد دقیقه‌ها را داشته باشیم، این چند ربع کامل می‌شود؟

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. دقیقه‌های گذشته از ربع

با همان تعداد دقیقه، چند دقیقه از ربع جاری گذشته است؟

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
