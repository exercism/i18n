# مقدمه

## دستکاری بیت

زبان Java برای دستکاری بیت‌های یک `byte`، `short`، `int`، `long` یا `char` عملگرهایی دارد.

### عملگرهای شیفت

از `<<` برای شیفت دادن بیت‌ها به چپ و از `>>` برای شیفت دادن به راست استفاده کنید.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

عملگر `<<` همیشه در سمت راست صفر درج می‌کند.
اما `>>` همان بیتی را درج می‌کند که در چپ‌ترین موقعیت قرار دارد (اگر عدد منفی باشد ۱ و اگر مثبت باشد ۰).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

وقتی هنگام شیفت دادن به راست باید صفر درج شود، به‌جای آن از `>>>` استفاده کنید.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### عملیات بیتی

#### AND بیتی

عملگر AND بیتی (`&`) دو مقدار می‌گیرد و روی هر بیت یک عمل AND انجام می‌دهد.
هر بیت از مقدار اول را با بیتی در همان موقعیت از مقدار دوم مقایسه می‌کند.
اگر هر دو ۱ باشند، بیت نتیجه ۱ می‌شود.
در غیر این صورت، بیت نتیجه ۰ است.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### OR بیتی

عملگر OR بیتی (`|`) دو مقدار می‌گیرد و روی هر بیت یک عمل OR انجام می‌دهد.
هر بیت از مقدار اول را با بیتی در همان موقعیت از مقدار دوم مقایسه می‌کند.
اگر یکی از آن دو بیت ۱ باشد، بیت نتیجه ۱ می‌شود.
در غیر این صورت، ۰ است.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### XOR بیتی

عملگر XOR بیتی (`^`) روی دو مقدار یک عمل XOR بیتی انجام می‌دهد.
مانند عملگرهای AND بیتی و OR بیتی، هر بیت از مقدار اول را با بیتی در همان موقعیت از مقدار دوم مقایسه می‌کند.
اگر تنها یکی از آن دو ۱ باشد، بیت حاصل ۱ می‌شود.
در غیر این صورت، ۰ است.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### NOT بیتی(`~`)

در پایان، عملگر NOT بیتی (`~`) هر بیت را وارونه می‌کند.
برخلاف عملگرهای قبلی، این یک «عملگر یگانی» است که تنها روی یک مقدار عمل می‌کند.

```java
~0b0110_0101;
// # => 0b1001_1010
```
