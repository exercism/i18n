# راهنما

## اجرای testها

مسیر Factor از **Factor 0.101** استفاده می‌کند. پس از
[نصب آن](https://exercism.org/docs/tracks/factor/installation)،
از پوشه‌ی همین تمرین این را اجرا کنید:

```
factor -roots=. -run=exercism-tools <exercise>
```

برای نمونه، برای `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

هر تمرین یک واژگان کوچک `exercism-tools` همراه دارد که
اجرای testها را پیش می‌برد. اجراکننده وقتی همه‌ی testها موفق
شوند با وضعیت ۰ خارج می‌شود و اگر testی شکست بخورد، با وضعیت
غیرصفر به همراه خروجی تشخیصی خارج می‌شود.

### testهای نادیده‌گرفته‌شده

به‌طور پیش‌فرض، فقط اولین test اجرا می‌شود. سازوکار آن، خط
`STOP-HERE` در فایل test است: هنگام تجزیه به تحلیلگر واژگانی
Factor می‌گوید هر چیزی را که پایین‌تر از آن است نادیده بگیرد،
بنابراین اجراکننده فقط testهای بالای آن را می‌بیند. وقتی اولین
test شما موفق شود، می‌توانید testهای بیشتری را به دو روش فعال
کنید:

- **خط `STOP-HERE` را پاک کنید** تا همه‌ی testهای باقی‌مانده
  یک‌جا فعال شوند.
- **خط `STOP-HERE` را پایین‌تر ببرید** تا testها را یکی‌یکی،
  یا هر وظیفه را جداگانه فعال کنید. تمرین‌های مفهومی
  testهای خود را زیر نشانگرهای `TASK:` گروه‌بندی می‌کنند؛
  اینکه `STOP-HERE` را دقیقاً پیش از `TASK:` بعدی ببرید،
  گامی طبیعی است.

وقتی همه‌ی testها موفق شوند، تمرین را حل کرده‌اید.

## ارسال راه‌حل شما

از پوشه‌ی تمرین:

```
exercism submit <exercise>/<exercise>.factor
```

برای نمونه:

```
exercism submit hello-world/hello-world.factor
```

اگر فایل `.meta/config.json` تمرین بیش از یک فایل راه‌حل را
فهرست کرده باشد (بعضی تمرین‌های مفهومی راه‌حل را میان یک
زیرواژگان کمکی تقسیم می‌کنند)، هر فایلی را که ویرایش کرده‌اید
به `exercism submit` بدهید.

## ارسال راه‌حل‌های ناقص

می‌توانید راه‌حلی را حتی با testهای شکست‌خورده ارسال کنید؛ این
کار به شما امکان می‌دهد ببینید دیگران چگونه به این تمرین نزدیک
شده‌اند و درباره‌ی آنچه تا کنون دارید از منتور بازخورد بخواهید.
