# پیوست دستورالعمل‌ها

## ثبات

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | ورودی     | آدرس | آرایه‌ای از کلمه‌های عامل |
| `$a1`    | ورودی     | عدد صحیح | تعداد عامل‌ها |
| `$a2`    | ورودی     | عدد صحیح | حد |
| `$v0`    | خروجی     | عدد صحیح | مجموع مضارب تا حد |
| `$t0-9`  | موقت | هر نوع | برای ذخیره‌سازی موقت به کار می‌رود |
