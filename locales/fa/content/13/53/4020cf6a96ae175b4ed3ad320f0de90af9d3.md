# مقدمه‌ای بر متغیر

## متغیر

_متغیرها_ محلی برای نگه‌داشتن داده هستند.
Bash دو نوع داده دارد: رشته و آرایه.
درباره‌ی آرایه‌ها بعداً صحبت می‌کنیم.

یک متغیر را این‌طور مقداردهی می‌کنید
```bash
name="value"
```

~~~~exercism/note
**مهم**: نباید دور علامت مساوی _هیچ فاصله‌ای_ باشد!

وقتی فاصله وجود دارد، مثل این مثال،

```bash
x = 10
```

bash قرار است **دستور** `x` را با **دو آرگومان** `=` و `10` فراخوانی کند!
~~~~

به متغیرها می‌توان _پارامتر_ هم گفت.
این دو اصطلاح در این سند به‌جای هم به کار می‌روند.

برخی پارامترهای مهم که bash از آن‌ها استفاده می‌کند یا آن‌ها را تنظیم می‌کند عبارت‌اند از:

* `PATH`: فهرستی از پوشه‌ها که با دو نقطه از هم جدا شده‌اند و برای یافتن دستورهای بیرونی استفاده می‌شود.
* `IFS`: «جداکننده‌ی میدانی درونی».
   در ادامه می‌بینیم چطور از آن استفاده می‌شود.
* `PWD`: پوشه‌ی کاری کنونی شما.
   مقدارش همان خروجی دستور `pwd` خواهد بود.
* `RANDOM`: یک عدد صحیح شبه‌تصادفی بین ۰ و ۳۲۷۶۷.
* `BASH_VERSION`: رشته‌ی نسخه‌ی نمونه‌ی در حال اجرای bash.

## گسترش پارامتر

مقدار یک پارامتر را با نحوه‌ی نگارش `$varname` به دست می‌آورید.

```bash
x=10
echo "The value of x is $x"
```

برای اینکه اسم متغیر با متن اطرافش اشتباه گرفته نشود، می‌توانید اسم متغیر را داخل آکولاد بگذارید.
برای مثال برای چاپ رشته‌ی `10x10`

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

برخی [راهنماهای سبک][google-style-guide] توصیه می‌کنند در بیشتر موارد برای خوانایی و/یا یکدستی از آکولاد استفاده کنید.

## پارامترهای موقعیتی

همان‌طور که در درس [دستورها و آرگومان‌ها][cmds-args] بحث کردیم، دستورها می‌توانند آرگومان بگیرند.
اسکریپت‌های Bash هم مستثنا نیستند.
به آرگومان‌های نمونه‌ی کنونی bash، _پارامترهای موقعیتی_ می‌گویند.
می‌توان آن‌ها را با این پارامترهای ویژه به دست آورد:

* `$1`: اولین پارامتر موقعیتی
* `$2` ... `$9`: پارامترهای بعدی
* `${10}` ...: اعداد دو رقمی به آکولاد نیاز دارند.
* `$0`: اسم اسکریپت کنونی.

آرگومان‌های یک تابع شل هم پارامترهای موقعیتی هستند و دقیقاً به همین شکل مدیریت می‌شوند.
در درسی بعدی درباره‌ی توابع بیشتر خواهیم دید.

### پارامترهای موقعیتی ویژه

چند _پارامتر ویژه_ وجود دارد که به شما کمک می‌کند با پارامترهای موقعیتی کار کنید.

* `$#` به _تعداد_ پارامترهای موقعیتی گسترش می‌یابد.
* `"$@"` به فهرست همه‌ی پارامترهای موقعیتی گسترش می‌یابد، هر کدام به‌صورت یک واژه‌ی جداگانه.
* `"$*"` به یک رشته‌ی واحد از همه‌ی پارامترهای موقعیتی که با یک نویسه به هم پیوسته‌اند گسترش می‌یابد.
  * نویسه‌ی اتصال _اولین نویسه_ از متغیر `$IFS` است که به‌طور پیش‌فرض فاصله است.

`"$@"` امن‌ترین راه برای سپردن پارامترهای موقعیتی به دستور دیگر است، در حالی که به‌صورت ایمن نقل‌قول‌شده باقی می‌مانند.
همچنین همین است که برای حلقه زدن روی پارامترهای موقعیتی از آن استفاده خواهید کرد:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

در عمل، `"$@"` بیشتر از `"$*"` استفاده می‌شود.

## جانشینی دستور

یک عملیات بسیار پرتکرار که در اسکریپت‌های bash انجام می‌دهید این است که خروجی یک دستور را بگیرید و در یک متغیر ذخیره کنید.
برای این کار از _جانشینی دستور_ استفاده خواهید کرد.

```bash
var=$(command)
```

برای مثال، برای بزرگ کردن حروف یک رشته، می‌توانید این کار را بکنید:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## بیشتر درباره‌ی گسترش پارامتر

bash امکانات درون‌ساخت زیادی برای دست‌کاری متغیرها و رشته‌ها دارد تا نیازی به فراخوانی دستورهای بیرونی نداشته باشید.

* بزرگ کردن حروف متن.
  در بخش پیشین نشان دادم که چطور با `tr` متن را بزرگ کنیم.
  برای انجام آن در bash:

  ```bash
  echo "${text^^}"
  ```

  به همین ترتیب، `${text,,}` مقدار را کوچک می‌کند.

* ارائه‌ی یک مقدار پیش‌فرض اگر متغیر خالی باشد.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* جست‌وجو و جایگزینی.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

گسترش‌های پارامتر جالب دیگری هم هست: استخراج یک زیررشته، گرفتن طول رشته، _اختصاص دادن_ یک مقدار پیش‌فرض، حذف متن از ابتدا یا انتهای مقدار و موارد بیشتر.
درباره‌ی آن‌ها [در راهنما][param-exp] بخوانید.
