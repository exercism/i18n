# راهنما

## کلیات

- نمونه‌های `struct` با نوشتن اسم `struct` و سپس مقادیر فیلدهای آن داخل آکولاد ساخته می‌شوند.
- می‌توان از `@T` برای اعلان «اسنپ‌شات»هایی از یک نوع دلخواه مانند `T` استفاده کرد؛ مثلاً `let i: @u32 = @1;` متغیری به اسم `i` اعلان می‌کند که اسنپ‌شاتی از مقدار `1` با نوع `u32` است.
- می‌توانید با استفاده از عملگر `*` (`desnap`) مقداری را از یک اسنپ‌شات استخراج کنید، مثلاً `let int = *an_int_snapshot;`.
- می‌توانید با استفاده از کلیدواژه‌ی `mut` مقداری را تغییرپذیر اعلان کنید، مانند `let mut i = 1;`.

## 1. ساخت شمارنده‌ی رأی

- باید یک اشاره‌گر به `struct`ی به اسم `VoteCounter` بسازید، به عبارت دیگر یک `@VoteCounter`.
- هنگام ساختن یک نمونه‌ی `struct` می‌توانید پارامتر `value` را مستقیم مقداردهی کنید.

## 2. گرفتن تعداد رأی‌ها از یک شمارنده

- می‌توانید از عملگر `*` روی یک اسنپ‌شات استفاده کنید تا آن را `desnap` کنید و مقدارش را به دست آورید، مثلاً `*my_snapshot`

## 3. افزایش رأی‌های یک شمارنده

- به جای تغییر دادن اسنپ‌شات `@VoteCounter`، باید نمونه‌ی جدیدی از `VoteCounter` را با رأی‌های افزایش‌یافته برگردانید.
- می‌توانید مقدار شمارنده‌ی رأی زیرین را با عملگر `*` از حالت اسنپ‌شات خارج کنید، یا تابعی را که در بخش قبلی ساختید فراخوانی کنید.

## 4. ساخت نتایج انتخابات

- یک `struct` یا متغیر جدید از نوع `ElectionResult` بسازید که فیلدهای `name` و `vote_counter` آن با مقادیر موجود در آرگومان‌های تابع پر شده باشند.
- می‌توانید با استفاده از عملگر `@` پیش از اسم متغیر یا اعلان `struct`، یک اسنپ‌شات `VoteCounter` بسازید، یا تابع `new_vote_counter` را که در یکی از بخش‌های قبلی ساختید فراخوانی کنید.

## 5. اعلام نتایج

- هرچند یک اسنپ‌شات از `ElectionResult` دریافت می‌کنید، می‌توانید با نشانه‌گذاری نقطه یعنی `.` به فیلدهای آن دسترسی داشته باشید، درست مثل این که اسنپ‌شات نیست!
- پیام را با دسترسی به فیلدهای `name` و `vote_counter` روی `struct` بسازید.
- هنگام `desnap` کردن یک اسنپ‌شات تودرتو، باید به تعداد اسنپ‌شات‌هایی که باید `desnap` شوند، عملگر `*` اعمال کنید:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. بازشماری رأی‌ها

- به دلیل [نحوه‌ی پیاده‌سازی دیکشنری‌ها][dictionaries underneath]، شرط لازم این است که آن‌ها تغییرپذیر باشند تا هم بتوان آن‌ها را تغییر داد و هم از آن‌ها خواند؛ یعنی تغییراتی که در تابع روی دیکشنری اعمال می‌کنید، بیرون از تابع هم قابل مشاهده خواهند بود.
- برای افزایش مقدار یک کلید در `let mut m: Felt252Dict<u32>`، باید توابع `get` و `insert` آن را با هم ترکیب کنید: `m.insert('mykey', m.get('mykey') + 1);`
