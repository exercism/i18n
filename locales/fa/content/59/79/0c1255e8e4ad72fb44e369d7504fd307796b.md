# پیوست دستورالعمل‌ها

## مزایا و معایب `from_quote`

تابع `Card.from_quote` یک رشته را به یک `Card` تبدیل می‌کند.
این کار امکان نوشتن چیزی مانند این را فراهم می‌کند:

```roc
card : Card
card = "Q"
```

این code به‌صورت ضمنی `Card.from_quote("Q")` را در زمان کامپایل فراخوانی می‌کند.
اجرای code در زمان کامپایل با این روش (یا روش‌های دیگری که در ادامه توضیح داده می‌شود) می‌تواند سرعت برنامه را افزایش دهد، چون نیازی نیست تجزیه و اعتبارسنجی داده‌ها را در زمان اجرا مدیریت کند.
علاوه بر این، تضمین می‌کند داده‌های نامعتبر (مثلاً قالب نادرست تاریخ) در زمان کامپایل رد شوند، نه در زمان اجرا، و این کار برنامه‌تان را مقاوم‌تر می‌کند.
در نهایت، code را خوش‌خوان و خوانا می‌کند.
برای مثال، این یکی از testهای این تمرین است:

```roc
result = simulate_game({
    player_a: ["2", "A"],
    player_b: ["3", "4", "5", "6", "K"],
})
```

با این حال، ممکن است کسی که این code را می‌خواند تصور کند تابع `simulate_game` رکوردی می‌گیرد که شامل دو `List(Str)` است، در حالی که در واقع رکوردی است شامل دو `List(Card)`.
این می‌تواند به سردرگمی و خطا منجر شود.
به همین دلیل، ممکن است شکل کمی طولانی‌تر اما صریح‌تر را ترجیح دهید: `"Q".Card` که آن هم `from_quote` را در زمان کامپایل فراخوانی می‌کند.

در برنامه‌های خودتان، ممکن است ترجیح دهید به‌جای آن از `from_str` استفاده کنید:

```roc
Card := { ... }.{
    from_str : Str -> Try(Card, [InvalidCard])
    from_str = |card_str| ...
}
```

همچنین می‌توانید `from_str` (یا هر تابع خالص دیگری) را در زمان کامپایل فراخوانی کنید، مانند این:

```roc
Ok(card) = Card.from_str("Q")
```

توجه: اگر این تعریف را در سطح بالا قرار دهید، در زمان کامپایل اجرا می‌شود (چون تابع خالص است و ورودی‌اش در زمان کامپایل معلوم است).
داخل یک تابع می‌توانید در زمان اجرا از `from_str` استفاده کنید.
