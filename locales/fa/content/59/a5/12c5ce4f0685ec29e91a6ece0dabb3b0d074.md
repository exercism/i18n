# مقدمه

یک [دستور `switch`][switch] یک مقدار را با چندین الگوی مطابق ممکن مقایسه می‌کند.
این دستور جایگزینی تمیزتر و خواناتر برای زنجیره‌کردن چندین دستور `if-else` فراهم می‌کند.

یک دستور `switch` با کلیدواژه‌ی `switch` شروع می‌شود و پس از آن مقداری می‌آید که باید بررسی شود.
هر تطابق ممکن با کلیدواژه‌ی `case` معرفی می‌شود.
کلیدواژه‌ی `default` یک حالت جایگزین تعریف می‌کند که اگر هیچ‌یک از حالت‌های صریح مطابقت نداشته باشند، اجرا می‌شود.
دستورهای `switch` هم مانند زنجیره‌های `if-else` فقط بلوک کدی را اجرا می‌کنند که به اولین حالت مطابق وابسته است.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

زنجیره‌ی `if-else` زیر را در نظر بگیرید:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

می‌توان این را با یک دستور `switch` واضح‌تر نوشت:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
