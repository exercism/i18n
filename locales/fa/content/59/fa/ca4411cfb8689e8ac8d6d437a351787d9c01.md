# حلقه

```sather
   loop
      ...
   end;
```

Sather دقیقاً یک دستور حلقه دارد. `while` و `for` وجود ندارند؛ هر دو از `loop` و چیزی ساخته می‌شوند که آن را پایان می‌دهد.

## متغیر

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` اعلام می‌کند و نوع را از مقدار داده‌شده می‌گیرد. وقتی متغیری باید پیش از وجود مقدارش موجود باشد، به‌جای مقدار، آن را با یک نوع اعلام کنید:

```sather
   total : INT;
   total := 0;
```

متغیری که بدون مقدار اعلام می‌شود، برای `INT` با صفر، برای `BOOL` با `false` و برای یک رشته یا یک شیء با void شروع می‌شود.

## پایان دادن به حلقه

| نوشته | حلقه را پایان می‌دهد |
| --- | --- |
| `until!(q)` | وقتی `q` «درست» است |
| `while!(q)` | وقتی `q` «غلط» است |
| `break!` | بلافاصله |

هر سه می‌توانند هرجای بدنه ظاهر شوند و یک حلقه می‌تواند بیش از یکی از آن‌ها را به کار ببرد.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## علامت تعجب

`until!`، `while!` و `break!` به `!` ختم می‌شوند چون **تکرارگر** هستند؛ یعنی فقط می‌توانند داخل یک حلقه ظاهر شوند و می‌توانند آن را پایان دهند. نوشتن یکی از آن‌ها بیرون از حلقه خطاست، نه هشدار. تمرین‌های بعدی از تکرارگرهای دیگر کتابخانه استفاده می‌کنند و در نهایت تکرارگرهای تازه‌ای می‌نویسند.

## حلقه‌ی بی‌پایان

حلقه‌ای که چیزی برای پایان دادنش ندارد، تا ابد اجرا می‌شود. گاهی این همان چیزی است که لازم است، اما در بیشتر موارد یعنی مقداری که شرط درباره‌اش می‌پرسد هرگز تغییر نمی‌کند. اگر برنامه‌ای معلق بماند، اولین موردی که باید بررسی شود این است که آیا چیزی داخل حلقه آن را به سمت توقف می‌برد یا نه.
