# دستورالعمل‌ها

در این تمرین شما یک بازی نقش‌آفرینی به اسم «Wizard and Warriors» بازی می‌کنید که به شما اجازه می‌دهد در نقش یک جادوگر یا یک جنگجو بازی کنید.

برای جنگجوها و جادوگرها قواعد متفاوتی وجود دارد که تعیین می‌کند چه مقدار امتیاز آسیب وارد می‌کنند.

برای یک جنگجو، قواعد به این صورت است:

- اگر شخصیتی که به آن حمله می‌کند آسیب‌پذیر نباشد، ۶ امتیاز آسیب وارد می‌کند
- اگر شخصیتی که به آن حمله می‌کند آسیب‌پذیر باشد، ۱۰ امتیاز آسیب وارد می‌کند

برای یک جادوگر، قواعد به این صورت است:

- اگر جادوگر از قبل طلسمی آماده کرده باشد، ۱۲ امتیاز آسیب وارد می‌کند
- اگر جادوگر از قبل طلسمی آماده نکرده باشد، ۳ امتیاز آسیب وارد می‌کند

به طور کلی، شخصیت‌ها هرگز آسیب‌پذیر نیستند. اما جادوگرها اگر طلسمی آماده نکرده باشند، آسیب‌پذیر _هستند_.

شما شش وظیفه دارید که با شخصیت‌های جنگجو و جادوگر کار می‌کنند.

## 1. توصیف یک شخصیت

متد `ToString()` را در کلاس `Character` بازنویسی کنید تا توصیفی از شخصیت را برگرداند، با این قالب: `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. شخصیت‌ها را به طور پیش‌فرض آسیب‌پذیر نکنید

مطمئن شوید که متد `Character.Vulnerable()` همیشه `false` برمی‌گرداند.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. به جادوگرها اجازه دهید طلسمی آماده کنند

متد `Wizard.PrepareSpell()` را پیاده‌سازی کنید تا به جادوگر اجازه دهید از قبل طلسمی آماده کند.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. جادوگرها را وقتی طلسمی آماده نکرده‌اند آسیب‌پذیر کنید

مطمئن شوید که متد `Vulnerable()` اگر جادوگر طلسمی آماده نکرده باشد `true` برمی‌گرداند؛ در غیر این صورت `false` برگرداند.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. محاسبه‌ی امتیاز آسیب برای یک جادوگر

متد `Wizard.DamagePoints()` را پیاده‌سازی کنید تا امتیاز آسیب واردشده را برگرداند: ۱۲ امتیاز آسیب وقتی طلسمی آماده شده باشد و ۳ امتیاز آسیب وقتی آماده نشده باشد.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. محاسبه‌ی امتیاز آسیب برای یک جنگجو

متد `Warrior.DamagePoints()` را پیاده‌سازی کنید تا امتیاز آسیب واردشده را برگرداند: ۱۰ امتیاز آسیب وقتی هدف آسیب‌پذیر است و ۶ امتیاز آسیب وقتی نیست.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
