# نصب

Exercism به شما این امکان را می‌دهد که کد ABAP خود را مستقیماً در مرورگرتان بنویسید و آزمایش کنید. نیازی به نصب دیگری نیست. اما اگر ترجیح می‌دهید روی سیستم خودتان کدنویسی کنید و آزمایش کنید، می‌توانید یک سیستم آزمایشی ABAP تهیه کنید.

البته ممکن است کارفرمای شما از SAP استفاده کند. لطفاً با واحد فناوری اطلاعات خود بررسی کنید که آیا می‌توانید به یک محیط توسعه‌ی آزمایشی ABAP دسترسی پیدا کنید و چگونه.

## کدام نسخه را انتخاب کنیم؟

توصیه می‌کنیم از یک نسخه‌ی فعلی از پلتفرم ABAP با پشتیبانی فعال استفاده کنید. در حال حاضر این **ABAP ۷.۵ و بالاتر** است. جزئیات مربوط به نسخه‌های کنونی و زمان‌بندی آن‌ها را می‌توانید در [مرکز توسعه‌دهندگان SAP](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise) بیابید.

## چه چیزی نصب کنیم؟

توصیه می‌کنیم از جدیدترین [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial) استفاده کنید. این نسخه بر پایه‌ی ABAP ۷.۵۸ است. می‌توانید سیستم SAP ABAP را به‌صورت یک ایمیج Docker یا به‌صورت میزبانی‌شده در SAP Cloud Appliance Library نصب کنید. علاوه بر این، بسته به سیستم‌عامل محلی‌تان باید SAP GUI را برای Windows یا برای Java نصب کنید. می‌توانید SAP GUI را از [اینجا](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui) دانلود کنید.

برای جزئیات بیشتر، این پست وبلاگ [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183) را ببینید.
