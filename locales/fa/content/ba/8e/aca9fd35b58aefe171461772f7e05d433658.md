# اجرای Test

برای اجرای Test در یک تمرین مشخص، با `cd` به پوشه‌ی آن بروید و فرمان زیر را اجرا کنید:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Testها از کتابخانه‌ای به اسم TestBox استفاده می‌کنند که از سبک‌های xUnit و BDD پشتیبانی می‌کند. همه‌ی مجموعه‌های Test در [سبک BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) نوشته می‌شوند که برای تعریف مشخصات Test از بستار استفاده می‌کند. لازم نیست نگران نصب TestBox باشید؛ اجراکننده‌ی Test در CLI خودش این کار را برایتان انجام می‌دهد. فقط کافی است بار اولی که آن را اجرا می‌کنید به اینترنت متصل باشید. برای اطلاعات بیشتر می‌توانید اینجا را بخوانید:
