# راهنمایی

## 1. چاپ نشان برای یک کارمند

- می‌توانید از [درونیابی رشته][string-interpolation] برای قالب‌بندی مختصر نشان استفاده کنید.
- یک [متد داخلی برای تبدیل رشته به حروف بزرگ][toupper] وجود دارد.

## 2. چاپ نشان برای یک کارمند جدید

- پیش از استفاده از شناسه، باید بررسی کنید که `null` نباشد.
- [این آموزش به تفصیل توضیح می‌دهد که چگونه با انواع مقدار nullable کار کنید][nullable-types-tutorial].

## 3. چاپ نشان برای مالک

- پیش از استفاده از دپارتمان، باید بررسی کنید که `null` نباشد.
- [این آموزش به تفصیل توضیح می‌دهد که چگونه با انواع ارجاعی nullable کار کنید][nullable-reference-types-tutorial].
- می‌توان از [عملگر شرطی null][null-conditional-operator] برای ساده‌کردن فراخوانی یک عضو روی یک مقدار nullable استفاده کرد.
- می‌توان از [عملگر ادغام null][null-coalescing-operator] برای ساده‌کردن برگرداندن یک مقدار متفاوت، در صورتی که یک مقدار nullable برابر `null` باشد، استفاده کرد.
