# مقدمه

در پایتون، از دستورهای [`if`][if statement]، `elif` (_کوتاه‌شده‌ی «else and if»_) و `else` برای [کنترل جریان][control flow tools] اجرای برنامه و تصمیم‌گیری در آن استفاده می‌شود.
برخلاف بسیاری از زبان‌های برنامه‌نویسی دیگر، پایتون در نسخه‌های ۳.۹ و پایین‌تر دستور case-switch رسمی ندارد و در عوض از چندین دستور `elif` برای هدفی مشابه استفاده می‌کند.

پایتون ۳.۱۰ گونه‌ای دستور case-switch به نام `pattern matching` را معرفی می‌کند که به‌طور جداگانه در مفهوم دیگری بررسی می‌شود.

دستورهای شرطی از عبارت‌هایی استفاده می‌کنند که باید به `True` یا `False` برسند، چه با برگرداندن مستقیم یک `bool` و چه با ارزیابی [«truthy» یا «falsy»][truth value testing].


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

وقتی `else` در کنار `if` بیاید، اگر شرط اصلی `if` به `False` ارزیابی شود، «بلوک کد» اختیاری `else` اجرا می‌شود:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` امکان چندین ارزیابی/شاخه را فراهم می‌کند.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

[عملیات منطقی][boolean operations] و [مقایسه‌ها][comparisons] را می‌توان با دستورهای شرطی ترکیب کرد تا آزمون‌های پیچیده‌تری انجام شود:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
