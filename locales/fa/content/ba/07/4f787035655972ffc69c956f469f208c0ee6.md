# مقدمه

به یاد بیاورید که یک برنامه‌ی `jq` یک _زنجیره‌ی عبارات_ است.
**انتساب متغیر** از این قاعده پیروی می‌کند: یک _انتساب متغیر_ عبارتی است که به این شکل است:

```jq
... | expr as $varname | ...
```

## فیلتر، ورودی را خروجی می‌دهد

مانند _عبارت همانی_ `.`، خروجی _انتساب متغیر_ هم همان ورودی آن است.
تعیین مقدار متغیر یک عارضه‌ی جانبی است.

مثال، که نشان می‌دهد `.` بعد از انتساب همان ورودی اولیه است:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## دامنه‌ی متغیر

دامنه‌ی متغیر «واژگانی» است، یعنی متغیر تا ادامه‌ی زنجیره در دامنه باقی می‌ماند.
متغیرهایی که در توابع تعریف می‌شوند (بعداً به توابع می‌رسیم) برای آن تابع «محلی» هستند.

## اسم متغیر

اسم متغیر باید با `$` شروع شود.
بقیه‌ی اسم متغیر یک **شناسه** است: با یک حرف یا زیرخط شروع می‌شود و بعد از آن حرف، عدد یا زیرخط می‌آید.

## انتساب با تجزیه‌ی ساختار

از دفترچه‌ی راهنما:

> با استفاده از یک عبارت `as` واحد می‌توان چندین متغیر را اعلان کرد، به شرط آنکه الگویی ارائه شود که _با ساختار ورودی مطابقت دارد_ (به این کار «تجزیه‌ی ساختار» می‌گویند).

مثال‌ها:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

تطبیق دادن اسم متغیر با _کلید شیء_ یک میانبر به دست می‌دهد:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## ثابت‌ها

همان‌طور که در مثال بالا دیدید، متغیرها برای نگهداری ثابت‌ها به کار می‌آیند.
بهتر است به ثابت‌ها یک اسم بدهید تا اینکه «اعداد جادویی» در کد ظاهر شوند.

## اغلب نیازی به متغیرها نیست

اغلب حذف کردن متغیرها خواناتر است.

محاسبه‌ی میانگین یک فهرست از اعداد را در نظر بگیرید

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

در مقایسه با

```jq
[2, 4, 8, 7] | add / length
```

این نکته یکی از قدرتمندترین جنبه‌های `jq` را برجسته می‌کند: ورودی یک فیلتر در اختیار _همه‌ی_ زیرعبارت‌ها قرار می‌گیرد:

- آرایه‌ی ورودی `[2,4,8,7]` به `add` سپرده می‌شود (که با اعمال عملگر `+` روی همه‌ی عناصر، اعداد را جمع می‌زند)
- _به‌طور موازی_، `[2,4,8,7]` به `length` هم سپرده می‌شود
- وقتی این زیرعبارت‌ها کامل شوند، نتیجه‌ی آن‌ها تقسیم می‌شود و میانگین اعداد آرایه‌ی ورودی به دست می‌آید.

## عملگرهای `jq` که برای تمرین یادگیری لازم دارید

### عملگر جایگزین: `//`

عبارت `a // b` اگر `a` برابر `false` یا `null` باشد خروجی‌اش `b` است، در غیر این صورت خروجی‌اش `a` است.
در بافت تعیین مقدار یک متغیر، این برای فراهم کردن یک مقدار پیش‌فرض بسیار به کار می‌آید:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### عملگرهای حساب

- `+`، `-` و `*` عملگرهای معمول جمع، تفریق و ضرب عددی هستند.
