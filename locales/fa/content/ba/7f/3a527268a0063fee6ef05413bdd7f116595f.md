# مقدمه

## کلاس

سازه‌ی اصلی شیءگرا در C#، _کلاس_ است که ترکیبی از داده (_فیلد_) و رفتار (_متد_) است. به فیلدها و متدهای یک کلاس، _اعضای_ آن می‌گویند.

دسترسی به اعضا را می‌توان از طریق اصلاح‌کننده‌های دسترسی محدود کرد که دو مورد رایج‌تر آن‌ها عبارتند از:

- `public`: هر کدی می‌تواند به این عضو دسترسی داشته باشد (بدون محدودیت).
- `private`: فقط کدی که در همان کلاس است می‌تواند به این عضو دسترسی داشته باشد.

می‌توانید به کلاس مانند قالبی برای ساختن نمونه‌هایی از آن نگاه کنید. برای ساختن نمونه‌ای از یک کلاس (که به آن _شیء_ هم می‌گویند)، از کلیدواژه‌ی `new` استفاده می‌شود:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

فیلدها یک نوع دارند و می‌توان آن‌ها را در هر جای کلاس تعریف کرد.
فیلدهای عمومی با PascalCase و فیلدهای خصوصی با camelCase و با پیشوند زیرخط `_` تعریف می‌شوند:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

می‌توان به‌صورت اختیاری یک مقدار اولیه به فیلد اختصاص داد. اگر فیلدی مقدار اولیه‌ای تعیین نکند، مقدار پیش‌فرض نوعش برای آن تنظیم می‌شود. می‌توان به مقادیر فیلدهای یک نمونه با نشانه‌گذاری نقطه‌ای دسترسی داشت و آن‌ها را به‌روزرسانی کرد.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

فیلدهای خصوصی معمولاً به‌عنوان اثر جانبی فراخوانی یک متد به‌روزرسانی می‌شوند. چنین متدهایی معمولاً مقداری برنمی‌گردانند که در این صورت نوع بازگشتی باید `void` باشد:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
