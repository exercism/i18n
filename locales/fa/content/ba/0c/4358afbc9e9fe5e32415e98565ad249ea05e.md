# مقدمه

## عملگر پایپ

به عملگر `|>` عملگر پایپ می‌گویند. می‌توان با آن فراخوانی توابع را به هم زنجیره کرد، به این شکل که مقدار برگردانده‌شده از فراخوانی تابع پیشین به فراخوانی تابع بعدی فرستاده می‌شود.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

کد بالا معادل کد زیر است:

```gleam
string.append(string.uppercase("hello"), "?!")
```

عملگر پایپ مقدار را یا به عنوان اولین آرگومان به فراخوانی تابع می‌فرستد یا به عنوان تنها آرگومان به یک فراخوانی تازه. در هر حالت، شکلی را انتخاب می‌کند که نوع درست را داشته باشد.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

گاهی می‌خواهیم مقدار را در جایگاه دیگری بفرستیم. در این حالت می‌توان از «جانگهدار» `_` استفاده کرد تا نشان دهد مقدار باید کجا قرار بگیرد.

```gleam
100
|> some_function(1, _, 2)
```
