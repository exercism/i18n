# دستورالعمل‌ها

شما برای نمایش مدرسه‌تان نشانه‌ها را اعلام می‌کنید. مدیر صحنه می‌خواهد جمله‌های استاندارد نوشته شوند تا هر کسی بتواند این میز را اداره کند.

چهار کار پیش رو دارید که همه در کلاس `STAGE_DIRECTIONS` هستند.

## 1. اعلام شروع

جمله‌ای را برگردانید که نمایش را آغاز می‌کند.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. اعلام میان‌پرده

جمله‌ای را برگردانید که در نیمه‌ی نمایش خوانده می‌شود.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. اعلام پایان

جمله‌ای را برگردانید که نمایش را به پایان می‌رساند.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. اعلام نشانه‌ی پایانی

نشانه‌ی پایانی همان جمله‌ای است که نمایش را به پایان می‌رساند. به‌جای اینکه متن را بار دوم بنویسید، روالی را که قبلاً نوشته‌اید فراخوانی کنید.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
