# Test

برای اجرای testها این مراحل را دنبال کنید:

- به پوشه‌ی مسئله بروید (مثلاً `~/Exercism/hello-world`).
- در ترمینال یک نشست `jconsole` را شروع کنید (مثلاً با تایپ کردن `jconsole` یا `ijconsole`).
- فایل راه‌حل خود را بارگذاری کنید (مثلاً `load 'hello-world.ijs'`)
- framework مربوط به unit test را با تایپ کردن `load  'general/unittest'` بارگذاری کنید
- راه‌حل خود را با تایپ کردن `unittest 'test.ijs'` test کنید.
<br></br>
- راه دیگر این است که می‌توانید testها را در یک خط به این شکل اجرا کنید: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## testهای نادیده‌گرفته‌شده

در ابتدا فقط test اول فعال خواهد بود.
این رویکرد شما را تشویق می‌کند که تمرین را قدم‌به‌قدم حل کنید.
هر test یک اسم بالای تعریفش دارد که نامش به _'\_ignore'_ ختم می‌شود.
برای اجرای test، مقدار آن را به 0 تغییر دهید.

### مثال:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
