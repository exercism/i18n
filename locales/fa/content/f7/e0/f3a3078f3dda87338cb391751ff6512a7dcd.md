# دستورالعمل‌ها

شما دستیار آموزشی هستید و برگه‌های امتحان دانشجویان را تصحیح می‌کنید.
پیگیری دستی نتایج کم‌کم خسته‌کننده و مستعد اشتباه می‌شود.
تصمیم می‌گیرید با نوشتن چند تابع برای شمارش و محاسبه‌ی نتایج کلاس، کار را کمی جذاب‌تر کنید.

## 1. گرد کردن نمره‌ها

هرچند می‌توانید برای سؤال‌های امتحان «نمره‌ی جزئی» بدهید، نمره‌ی نهایی امتحان باید از نوع `int` باشد.
بنابراین پیش از هر کار دیگری با نمره‌های کلاس، باید نمره‌ها را مرور کنید و هر نمره‌ی `float` را به `int` تبدیل کنید. خوشبختانه Python تابع درون‌ساز [`round()`][round] را دارد که می‌توانید از آن استفاده کنید.

تابع `round_scores(student_scores)` را بسازید که یک `list` از `student_scores` می‌گیرد.
این تابع باید `list` ورودی را _مصرف_ کند و `list` جدیدی `return` کند که همه‌ی نمره‌هایش به `int` تبدیل شده‌اند.
ترتیب نمره‌ها در `list` حاصل مهم نیست.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. دانشجویان قبول‌نشده

وقتی داشتید برگه‌های امتحان را تصحیح می‌کردید، متوجه شدید که عملکرد بعضی از دانشجویان آن‌قدر که انتظار داشتید خوب نبود.
اما حواستان پرت شد و فراموش کردید که دقیقاً یادداشت کنید _چند_ دانشجو.

تابع `count_failed_students(student_scores)` را بسازید که یک `list` از `student_scores` می‌گیرد.
این تابع باید تعداد دانشجویانی را که نمره‌ی قبولی نگرفته‌اند بشمارد و آن تعداد را به‌صورت یک عدد صحیح برگرداند.
دانشجو برای قبول شدن در امتحان به نمره‌ای بزرگ‌تر از **۴۰** نیاز دارد.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. «بهترین»

معلمی که به او کمک می‌کنید می‌خواهد گروهی از دانشجویان را پیدا کند که در این امتحان «بهترین» عملکرد را داشته‌اند.
اینکه چه چیزی «بهترین» به حساب می‌آید هر بار فرق می‌کند، بنابراین باید نمره‌هایی را پیدا کنید که **بزرگ‌تر یا مساوی** آستانه‌ی فعلی هستند.

تابع `above_threshold(student_scores, threshold)` را بسازید که `student_scores` (یک `list` از نمره‌ها) و `threshold` (آستانه‌ی «بالاترین نمره») را به‌عنوان پارامتر می‌گیرد.
این تابع باید `list`ی از همه‌ی نمره‌هایی را که `>=` آستانه هستند برگرداند.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. محاسبه‌ی نمره‌های حرفی

معلمی که به او کمک می‌کنید دوست دارد علاوه بر نمره‌های عددی، نمره‌های حرفی هم بدهد.
چون دانشجویان به‌ندرت در امتحان نمره‌ی ۱۰۰ می‌گیرند، آستانه‌های پایین‌تر «نمره‌ی حرفی» بر اساس بالاترین نمره‌ای که به دست آمده محاسبه می‌شوند و بین بالاترین نمره و آستانه‌ی قبول‌نشدن، یعنی **۴۰ یا کمتر**، به‌طور یکسان افزایش می‌یابند.

تابع `letter_grades(highest)` را بسازید که بالاترین نمره‌ی امتحان را به‌عنوان آرگومان می‌گیرد و `list`ی از آستانه‌های پایین‌تر نمره را برای هر بازه‌ی نمره‌ی «سبک آمریکایی» برمی‌گرداند: `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. تطبیق اسم‌ها با نمره‌ها

فهرستی از نمره‌های امتحان به ترتیب نزولی دارید و فهرست دیگری از اسم دانشجویان که آن هم بر اساس نمره‌های امتحانشان به ترتیب نزولی مرتب شده است.
می‌خواهید اسم هر دانشجو را با نمره‌ی امتحانش تطبیق دهید و رتبه‌بندی کلی کلاس را چاپ کنید.

تابع `student_ranking(student_scores, student_names)` را با پارامترهای `student_scores` و `student_names` بسازید.
اسم هر دانشجو در `list` مربوط به student_names را با نمره‌اش از `list` مربوط به student_scores تطبیق دهید.
می‌توانید فرض کنید هر `list` آرگومان از بالاترین نمره به پایین‌ترین نمره مرتب شده است.
این تابع باید `list`ی از رشته‌ها با قالب `<rank>. <student name>: <student score>` برگرداند.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. نمره‌ی «کامل»

هرچند نمره‌ی «کاملِ» ۱۰۰ در یک امتحان کم‌یاب است، جالب است بدانید آیا دست‌کم یک دانشجو آن را کسب کرده است یا نه.

تابع `perfect_score(student_info)` را با پارامتر `student_info` بسازید.
`student_info` یک `list` از لیست‌هاست که اسم و نمره‌ی هر دانشجو را در خود دارد: `[["Charles", 90], ["Tony", 80]]`.
این تابع باید _اولین_ جفت `[<name>, <score>]` مربوط به دانشجویی را برگرداند که در امتحان نمره‌ی ۱۰۰ گرفته است.

اگر هیچ نمره‌ی ۱۰۰ در `student_info` پیدا نشد، باید یک لیست خالی `[]` برگردانده شود.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
