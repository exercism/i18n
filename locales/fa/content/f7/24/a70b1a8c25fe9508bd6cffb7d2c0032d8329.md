# مقدمه

## عبارت باقاعده در JavaScript

«[عبارت باقاعده][mdn-regular-expressions]» (یا Regex) دنباله‌ای از نویسه‌هاست که می‌توانیم با استفاده از آن عناصر خاصی را در رشته‌ها هدف بگیریم و دستکاری کنیم. از این رو می‌توانیم:

- یک متن را در یک رشته **جست‌وجو** کنیم
- زیررشته‌ها را در یک رشته **جایگزین** کنیم
- اطلاعاتی را از یک رشته **استخراج** کنیم

> 💡 نوع عبارت باقاعده‌ی JavaScript بخشی از استاندارد ECMA-262 برای این زبان است. یعنی نیازی نیست نگران سازگاری مخصوص هر مرورگر باشید.

## نحوه‌ی ساخت عبارت باقاعده

در JavaScript، عبارت باقاعده بیشتر در قالب `/pattern/modifiers` نوشته می‌شود.

دو روش برای ساخت عبارت باقاعده داریم:

۱. **لیترال عبارت باقاعده**:

```javascript
const regex = /[a-z]/;
```

۲. سازنده‌ی **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

در هر دو حالت، JavaScript یک شیء از عبارت باقاعده می‌سازد. توصیه می‌شود به‌صورت پیش‌فرض از الگوهای تغییرناپذیر همراه با لیترال استفاده کنید.

از سازنده‌ی RegExp می‌توان در مواردی استفاده کرد که عبارت باقاعده تغییر می‌کند یا هنوز آن را نمی‌دانیم (مثلاً یک ورودی).

## 🏴‍☠️ فلگ‌ها

عبارت‌های باقاعده توانایی‌های اختیاری ویژه‌ای به نام [`flags`][mdn-flags] دارند که امکانات بیشتری را ممکن می‌کنند.

برخی از پرکاربردترین آن‌ها عبارت‌اند از:

- `/g` - جست‌وجوی سراسری
- `/i` - غیرحساس به بزرگی و کوچکی حروف
- `/m` - جست‌وجوی چندخطی

در ادامه یک مثال ساده می‌آوریم:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

نویسه‌ی `g` به ما امکان می‌دهد همه‌ی تطابق‌های ممکن در یک رشته را واکاوی کنیم. بدون این قابلیت، JavaScript تنها نخستین تطابق `Home` را استخراج می‌کرد.

فلگ غیرحساس به بزرگی و کوچکی حروف `/i` به ما انعطاف می‌دهد تا الگویی را پیدا کنیم. به این ترتیب مهم نیست آنچه به دنبالش هستیم با حروف `UPPERCASE` نوشته شده باشد یا `lowercase`.

وقتی از سازنده‌ی `RegExp` استفاده می‌کنید، نحوه‌ی نگارش افزودن فلگ‌ها متفاوت است.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## رایج‌ترین توابع

وقتی عبارت‌های باقاعده با توابع داخلی فعلی JavaScript ترکیب می‌شوند، روش‌های قدرتمندی برای دستکاری رشته‌ها و گرفتن داده از آن‌ها در اختیار داریم.

این‌ها برخی از رایج‌ترین توابعی هستند که همراه با عبارت باقاعده استفاده می‌شوند.

### Test

متد [test()][mdn-regex-test]] جست‌وجویی برای یافتن تطابق بین یک عبارت باقاعده و یک رشته‌ی مشخص انجام می‌دهد. مقدار «درست» یا «غلط» را برمی‌گرداند.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

با متد [match()][mdn-regex-match]، آرایه‌ای مفید به دست می‌آوریم که محتوایش به وجود یا نبود تطابق‌های پیدا‌شده بستگی دارد.

به این ترتیب، می‌توانیم هم در هر رشته‌ای **جست‌وجو** کنیم و هم اطلاعات را **استخراج** کنیم. برای مثال:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

وقتی فلگ جست‌وجوی سراسری `/g` حاضر باشد، به‌جای گرفتن تنها تطابق به‌همراه اطلاعات مفیدی مانند اندیس یا ورودی، متد همه‌ی رخدادهای نمایش‌داده‌شده در آرایه را برمی‌گرداند:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

متد [replace()][mdn-regex-replace] در JavaScript به ما امکان می‌دهد مقداری را در یک رشته‌ی داده‌شده جست‌وجو کنیم و آن را با مقدار تازه‌ی دلخواه جایگزین کنیم.

```javascript
string.replace(searchValue, newValue);
```

الگوی جست‌وجوی جایگزینی می‌تواند یک رشته‌ی تکی یا یک عبارت باقاعده باشد.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

علاوه بر این، می‌توانیم تابعی را روی جایگاه جایگزینی اعمال کنیم تا تغییرات بیشتری روی هر مقدار اعمال شود.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

متد [split()][mdn-regex-split] در JavaScript روش متفاوتی برای استفاده از رشته‌ها و دستکاری آن‌ها با عبارت‌های باقاعده ارائه می‌دهد.

به این ترتیب، از عبارت باقاعده استفاده می‌کنیم تا یک رشته‌ی داده‌شده را با تشخیص یک الگو تقسیم کنیم، مثلاً `str.split(/[,.\s]/)`. این الگو به عنوان `separator` استفاده می‌شود.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
