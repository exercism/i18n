# دستورالعمل‌ها

شما یک بوتیک مد آنلاین را اداره می‌کنید. هر عنصر در انبار شما یک آرایه‌ی دو عنصری `{ name price }` است و کل انبار آرایه‌ای از عنصرهاست.

قیمت ناموجود به‌صورت `f` ثبت می‌شود.

## 1. مرتب‌سازی انبار بر اساس قیمت

`sort-by-price` را تعریف کنید تا آرایه‌ای جدید بازگرداند که عنصرهایش بر اساس قیمت، به ترتیب صعودی مرتب شده‌اند.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. یافتن عنصرهایی که قیمتشان تعیین نشده است

`with-missing-price` را تعریف کنید تا آرایه‌ای بازگرداند که فقط شامل عنصرهایی است که قیمتشان `f` است.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. شمارش عنصرهای گران‌قیمت

`expensive-items` را تعریف کنید تا یک انبار و یک آستانه‌ی قیمت بگیرد و بازگرداند که چند عنصر قیمتی به‌طور اکید بیشتر از آستانه دارند.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. یافتن کم‌هزینه‌ترین عنصر

`cheapest-item` را تعریف کنید تا عنصری با کمترین قیمت را بازگرداند. عنصرهایی که قیمت ندارند (`f`) در ورودی ظاهر نمی‌شوند.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. جمع همه‌ی قیمت‌ها

`total-price` را تعریف کنید تا مجموع همه‌ی قیمت‌ها را بازگرداند. عنصرهایی که قیمت ندارند (`f`) در ورودی ظاهر نمی‌شوند.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. قالب‌بندی یک عنصر به‌شکل برچسب قیمت

`format-price-tag` را تعریف کنید تا برای یک عنصر رشته‌ای به شکل `"name: $price"` بازگرداند. عنصرهایی که قیمت ندارند (`f`) در اینجا ظاهر نمی‌شوند.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
