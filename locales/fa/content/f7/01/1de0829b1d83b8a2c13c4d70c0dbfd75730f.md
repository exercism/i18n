# مقدمه

## بازگشت

به توانایی تعریف شدن یک چیز بر حسب خودش، «بازگشت» می‌گویند. در F#، بازگشت بیشتر در قالب توابع بازگشتی دیده می‌شود؛ توابعی که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید حداقل یک «حالت پایه» و حداقل یک «حالت بازگشتی» داشته باشد. حالت پایه بدون فراخوانی دوباره‌ی تابع، یک مقدار برمی‌گرداند. حالت بازگشتی تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت کند.

توابع بازگشتی مانند توابع معمولی تعریف می‌شوند، اما با اصلاح‌کننده‌ی `rec`. بدون این اصلاح‌کننده، یک تابع نمی‌تواند خودش را فراخوانی کند و هر تلاشی برای این کار به یک خطای کامپایل منجر می‌شود. بنابراین بازگشت باید صریحاً انتخاب شود.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# همچنین از انواع بازگشتی از طریق اتحادهای تفکیک‌شده پشتیبانی می‌کند. در یک نوع اتحاد تفکیک‌شده‌ی بازگشتی، داده‌ی یک یا چند حالت به خود آن نوع ارجاع می‌دهد. مانند توابع بازگشتی، انواع بازگشتی هم باید یک حالت پایه داشته باشند. برخلاف توابع بازگشتی، انواع بازگشتی از کلیدواژه‌ی `rec` استفاده نمی‌کنند.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
