# نکته‌ها

## 1. تعریف کنید که آیا پک‌من می‌تواند شبحی را بخورد

* تابع باید یک مقدار «منطقی» برگرداند.
* می‌توانید از عملگر منطقی `and` استفاده کنید تا آرگومان‌ها را برای رسیدن به یک نتیجه ترکیب کنید.

## 2. تعریف کنید که آیا پک‌من امتیاز می‌گیرد

* تابع باید یک مقدار منطقی برگرداند.
* می‌توانید از عملگر منطقی `or` استفاده کنید تا آرگومان‌ها را برای رسیدن به یک نتیجه ترکیب کنید.

## 3. تعریف کنید که آیا پک‌من می‌بازد

* تابع باید یک مقدار منطقی برگرداند.
* می‌توانید از عملگرهای منطقی `and` و `not` استفاده کنید تا آرگومان‌ها را برای رسیدن به یک نتیجه ترکیب کنید.

## 4. تعریف کنید که آیا پک‌من می‌برد

* تابع باید یک مقدار منطقی برگرداند.
* می‌توانید از عملگرهای منطقی `and` و `not` استفاده کنید تا آرگومان‌ها و نتایج یکی از توابع را که پیش‌تر پیاده‌سازی شده‌اند ترکیب کنید.
