# مقدمه

نوع `enum` در سی‌شارپ نماینده‌ی مجموعه‌ی ثابتی از ثابت‌های نام‌دار است (یک برشماری).

معمولاً هر عضو `enum` فقط می‌تواند به یکی از آن ثابت‌های نام‌دار اشاره کند. اما گاهی مفید است که به بیش از یک ثابت اشاره شود. برای این کار می‌توان روی `enum` اتریبیوت [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) را گذاشت.

یک `enum` پرچمی را می‌توان به شکل زیر تعریف کرد (با نمادگذاری عدد صحیح دودویی `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

یک نمونه از `PhoneFeatures` که مقدارش `0b00000011` است، هم پرچم `Call` و هم پرچم `Text` آن تنظیم شده است.

به‌طور پیش‌فرض، برای مقادیر اعضای enum از نوع `int` استفاده می‌شود. می‌توان با مشخص کردن نوع در اعلان enum، از نوع عدد صحیح دیگری استفاده کرد:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
