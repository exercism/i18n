# راهنمایی‌ها

## کلی

- نگران نوع عددی خاصی نباشید؛ فعلاً از `Int32` و `Float64` استفاده کنید.
- `Int32` و `Float64` نوع‌های عددی پیش‌فرض در Crystal هستند، پس لازم نیست آن‌ها را مشخص کنید.

## 1. تبدیل دما از سلسیوس به کلوین

- می‌توانید از عملگر حسابی (`+`) برای جمع کردن اعداد استفاده کنید.

## 2. گرد کردن دما

- می‌توانید از متد `round` برای گرد کردن یک عدد به تعداد مشخصی رقم اعشار استفاده کنید.
- متد `round` آرگومانی به اسم `places` می‌گیرد که تعداد رقم‌های اعشار برای گرد کردن را مشخص می‌کند.

## 3. تبدیل دما از سلسیوس به فارنهایت

- می‌توانید از عملگر حسابی (`*`) برای ضرب کردن اعداد استفاده کنید.
- می‌توانید از پرانتز (`()`) برای گروه‌بندی عملیات استفاده کنید.

## 4. به دست آوردن تعداد حسگرهای گمشده

- می‌توانید از عملگر حسابی (`-`) برای تفریق اعداد استفاده کنید.
- می‌توانید از عملگر حسابی (`%`) برای گرفتن باقی‌مانده‌ی یک تقسیم استفاده کنید.
