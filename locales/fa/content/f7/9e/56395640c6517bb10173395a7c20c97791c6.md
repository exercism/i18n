# گردشکار

GitHub Actions از مفهوم _گردشکارها_ استفاده می‌کند؛ اسکریپت‌هایی که هر زمان رویداد مشخصی رخ دهد (مثلاً پوش کردن یک کامیت) به‌طور خودکار اجرا می‌شوند.

هر گردشکار GitHub Actions در یک فایل `.yml` در پوشه‌ی `.github/workflows` تعریف می‌شود.
برای کسب اطلاعات درباره‌ی گردشکارها، مستندات زیر را ببینید:

- [نحوه‌ی نگارش گردشکار](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)
- [انتخاب زمان اجرای گردشکار](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/triggering-a-workflow)
- [انتخاب محل اجرای گردشکار](https://docs.github.com/en/actions/writing-workflows/choosing-where-your-workflow-runs)
- [انتخاب اینکه گردشکار چه کاری انجام می‌دهد](https://docs.github.com/en/actions/writing-workflows/choosing-what-your-workflow-does)
- [نوشتن گردشکارها](https://docs.github.com/en/actions/writing-workflows)
- [بهترین شیوه‌ها](/docs/building/github/gha-best-practices)

## گردشکارهای مشترک

برخی گردشکارها میان مخزن‌ها مشترک هستند.

```exercism/caution
گردشکارهای مشترک به‌صورت خودکار همگام‌سازی می‌شوند (از [مخزن org-wide-files](https://github.com/exercism/org-wide-files/)).
بنابراین نباید محتوای آن‌ها را به‌صورت دستی تغییر دهید.
```

### گردشکارهای عمومی

- [همگام‌سازی برچسب‌ها](/docs/building/tracks/ci/workflows/sync-labels): برچسب‌های مخزن را از فایل همگام‌سازی می‌کند

### گردشکارهای مخصوص مسیر

- [configlet](/docs/building/tracks/ci/workflows/configlet): بررسی می‌کند که فایل‌های (پیکربندی) مسیر به‌درستی ساختار یافته‌اند، هم از نظر ساختاری و هم از نظر معنایی
- [هیچ فایل مهمی تغییر نکرده](/docs/building/tracks/ci/workflows/no-important-files-changed): روی پول‌ریکوئست‌هایی که باعث Test مجدد راه‌حل‌های موجود می‌شوند کامنت می‌گذارد
- [Test](/docs/building/tracks/new/setup-continuous-integration#h-test-workflow): تمرین‌های مسیر را بررسی می‌کند

### گردشکارهای مخصوص ابزارها

- [استقرار](/docs/building/tracks/ci/workflows/deploy): تصویر Docker ابزارهای مسیر را در Docker Hub و ECR مستقر می‌کند

### گردشکارهای اختیاری

همچنین گردشکارهایی وجود دارند که ممکن است مسیرها به آن‌ها بپیوندند:

- [توقف مشارکت‌های جامعه](/docs/building/tracks/ci/workflows/pause-community-contributions): به‌صورت خودکار روی ایشوها و پول‌ریکوئست‌های تازه‌ساخته‌شده توسط کاربرانی که عضو سازمان Exercism در GitHub نیستند کامنت می‌گذارد
