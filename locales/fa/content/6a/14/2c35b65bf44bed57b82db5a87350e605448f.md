# مبانی match

عملگر `match` یک مقدار را با زنجیره‌ای از الگوها مقایسه می‌کند و سپس بر اساس این که کدام الگو تطبیق پیدا می‌کند، کد را اجرا می‌کند.

## تطبیق مقادیر ثابت

در بنیادی‌ترین شکل خود، `match` یک مقدار را با چند تطبیق بالقوه مقایسه می‌کند و نخستین شاخه‌ای را که تطبیق پیدا کند انتخاب می‌کند. همیشه تنها یک شاخه انتخاب می‌شود و کنترل هرگز به شاخه‌ی دیگری «عبور» نمی‌کند. `match` عبارتی است که می‌تواند به یک مقدار ارزیابی شود.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## جامعیت

تطبیق همیشه جامع است: اگر ممکن باشد مقداری از لابه‌لای شاخه‌ها بگریزد، Rust برنامه را کامپایل نمی‌کند. برای کمک به این کار، `_` یک «نویسه‌ی عام» است که با هر چیزی تطبیق پیدا می‌کند.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## تطبیق به‌عنوان جریان کنترل

`match` را می‌توان به‌عنوان یک عبارت برای تولید مقدار به کار برد، اما می‌توان از آن به‌عنوان یک دستور هم استفاده کرد، صرفاً به قصد جریان کنترل.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## تطبیق بازه‌ها

لازم نیست شاخه‌های `match` به‌صورت مقدارهای تکی مشخص شوند؛ می‌توانند بازه هم باشند.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## الگوهای Or

یک شاخه‌ی `match` می‌تواند با استفاده از نشانه‌ی `|` به‌عنوان جداکننده، با یکی از چند گزینه‌ی ممکن تطبیق پیدا کند.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## تطبیق ساختاری و اتصال

تطبیق می‌تواند اتصالی تولید کند که درون یک شاخه‌ی خاص از `match` معتبر است. این ویژگی به‌ویژه برای باز کردن `enum`هایی که داده را در گونه‌های خود حمل می‌کنند بسیار مفید است.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

توضیحات بیشتر درباره‌ی این موضوع در مفهوم `match-advanced` آمده است.
