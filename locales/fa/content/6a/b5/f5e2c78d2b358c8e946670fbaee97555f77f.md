# مقدمه

## عبارات باقاعده

عبارات باقاعده در Elixir از مشخصات **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions) پیروی می‌کنند، مشابه زبان‌های محبوب دیگری مانند Java، JavaScript یا Ruby.

ماژول `Regex` توابعی برای کار کردن با عبارات باقاعده در اختیار می‌گذارد. برخی از توابع ماژول `String` هم عبارات باقاعده را به‌عنوان آرگومان می‌پذیرند.

~~~~exercism/note
این تمرین فرض می‌کند که شما از قبل نحوه‌ی نگارش عبارات باقاعده را می‌دانید، از جمله کلاس‌های نویسه، سنجه‌ها، گروه‌ها و ضبط‌ها.

اگر لازم است دانش خود را درباره‌ی عبارات باقاعده تازه کنید، یکی از این منابع را ببینید: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

### سیگیل

رایج‌ترین راه برای ساختن عبارات باقاعده استفاده از «سیگیل» `~r` است.

```elixir
~r/test/
```

توجه کنید که همه‌ی سیگیل‌های Elixir از [انواع مختلف جداکننده‌ها][sigils] پشتیبانی می‌کنند، نه فقط `/`.

### تطبیق

از عملگر `=~/2` می‌توان برای انجام یک تطبیق باقاعده استفاده کرد که نتیجه‌ی `boolean` برمی‌گرداند. در عوض، توابع `match?/2` هم در ماژول `Regex` و هم در ماژول `String` وجود دارند.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### ضبط

اگر یک بررسی ساده‌ی «منطقی» کافی نیست، از تابع `Regex.run/3` استفاده کنید تا لیستی از همه‌ی ضبط‌ها را به دست آورید (یا `nil` اگر تطبیقی وجود نداشت). اولین عنصر در لیست برگردانده‌شده همیشه تطبیق کل عبارت باقاعده است و عناصر بعدی گروه‌های منطبق‌شده هستند.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### اصلاح‌کننده‌ها

رفتار یک عبارت باقاعده را می‌توان با افزودن پرچم‌های ویژه تغییر داد. وقتی از سیگیل برای ساخت یک عبارت باقاعده استفاده می‌کنید، اصلاح‌کننده‌ها را بعد از جداکننده‌ی دوم اضافه کنید.

اصلاح‌کننده‌های رایج عبارت‌اند از:
- `i` - تطبیق را نسبت به بزرگی و کوچکی حروف بی‌تفاوت می‌کند.
- `u` - الگوهای مخصوص Unicode مانند `\p` را فعال می‌کند و باعث می‌شود کلاس‌های نویسه‌ای مانند `\w`، `\s` و غیره با Unicode هم تطبیق پیدا کنند.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
