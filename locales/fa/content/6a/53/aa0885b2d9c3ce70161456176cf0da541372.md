# مفاهیم بسامد حروف موازی

این تمرین با کمک crateهای خارجی، تنوع گسترده‌ای از راه‌حل‌های ممکن را ارائه می‌دهد. برای اینکه حجم کار قابل مدیریت بماند، این سند گزیده‌ای کوچک از این امکان‌ها را در خود دارد. راه‌حل‌های Crossbeam مجموعه‌ی مشابهی از مفاهیمی را دارند که در اینجا فهرست شده‌اند و Rayon فقط به زیرمجموعه‌ای از آن‌ها نیاز دارد.

\*<sub>مرتبط، اما در اینجا برای راه‌حل‌های معقول کاربرد ندارد</sub>

## کلیات

- رشته‌ها: به‌طور خاص، `str` همیشه در اینجا نقش دارد.
- Unicode: مصالحه‌های کارایی و امکانات میان متدهای ASCII و متدهای Unicode. نتیجه‌ی بنچمارک زمانی مخدوش می‌شود که بنچمارک از متدهای Unicode استفاده کند و راه‌حل از متدهای ASCII.
- تکرارکننده‌ها: پیمایش ورودی یا تکه‌های آن.
- مجموعه‌ها: پیمایش روی یک `HashMap` و استفاده از `Entry`. معمولاً handleها در یک `Vec` جمع می‌شوند.
- ارجاعات
- اعداد: به‌طور خاص trait مربوط به `Add`
- حلقه‌ی For: به دلیل move نمی‌توان رشته‌ها را درون یک تکرارکننده به هم پیوست.
- **اختیاری** دیدپذیری: جزئیات پیاده‌سازی را غیرعمومی نگه دارید
- **اختیاری** برش‌ها: `.chunks()` متدی است که اغلب برای تقسیم ورودی میان رشته‌های کارگر به کار می‌رود. در عوض، از زیربرش‌ها هم استفاده می‌شود.
- **اختیاری** توابع مرتبه‌بالا: می‌توان HashMapها را با یک تابع مرتبه‌بالا به همراه یک تکرارکننده ادغام کرد.
- **اختیاری** نوع‌ها: برای تقسیم ورودی می‌توان اعداد صحیح را به مقادیر اعشاری تبدیل کرد تا گرد کردن اعمال شود
- **اختیاری** crateها

## رویکرد std، با یا بدون کانال‌ها

- موازی‌سازی: زیرموضوع راه‌اندازی/پیوستن رشته‌ها.
- تکرارکننده‌ها: زیرموضوع ارزیابی تنبل؛ راه‌اندازی و پیوستن رشته‌ها با یک تکرارکننده‌ی یکسان، موازی‌سازی را از بین می‌برد.
- طول عمرها: زیرموضوع `'static lifetime` و معنای صریح `move`
- تکرارکننده‌ها/طول عمرها: زیرموضوع تکرارکننده‌های مصرف‌کننده؛ با تکرارکننده نمی‌توان رشته‌ها را به هم پیوست.
- نوع Option: بازگشایی نتیجه‌ی رشته یا کانال
- توابع: به‌طور خاص، برای راه‌اندازی رشته‌ها به توابع مرتبه‌بالا نیاز است. بستارها هم در اینجا یک گزینه‌اند.

## رویکرد std با کانال‌ها

- موازی‌سازی: زیرموضوع کانال‌ها.
- تاپل‌ها: `mpsc::channel()` یک تاپل برمی‌گرداند
- تخریب ساختار: تاپل را می‌توان هنگام انتساب تخریب ساختار کرد
- طول عمرها: `drop()`

## رویکرد جایگزین با متغیرهای مشترک

- شمارش ارجاع: به اشتراک گذاشتن داده‌ی تجمیعی میان رشته‌ها با یک مجموعه‌ی ارجاع‌شماری‌شده.
- **یادکرد ویژه**: موازی‌سازی، زیرموضوع Mutexها. برای این تمرین لازم یا مفید نیست، اما با این حال مفهومی رایج است. مرتبط: `RwLock`.

### نمونه‌ی std با کانال‌ها

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### نمونه‌ی crate با Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
