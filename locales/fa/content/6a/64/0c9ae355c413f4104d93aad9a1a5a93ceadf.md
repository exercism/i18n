# دستورالعمل‌ها

در این تمرین کمی بیشتر روی خودروهای کنترل از راه دور کار می‌کنید.

یک خودروی آزمایشی توسعه یافته است و پیست آزمون باید طوری تغییر کند که بتواند هم مدل‌های تولیدی و هم مدل‌های آزمایشی را پشتیبانی کند. هر دو نوع خودرو از قبل ساخته شده‌اند و باید راهی پیدا کنید که هر دو را در پیست آزمون مدیریت کنید.

علاوه بر این، خودروهای تولیدی کم‌کم دارند به موفقیت‌هایی دست پیدا می‌کنند. رئیس تیم مشتاق است با انتشار رتبه‌بندی خودروهای تولیدی، روح رقابت را حفظ کند.

## 1. امکان راندن خودروها در یک پیست آزمون مشترک را فراهم کنید

لطفاً متدی به رابط `IRemoteControlCar` اضافه کنید تا پیاده‌سازی‌های `Drive()` برای هر دو نوع خودرو در دسترس قرار گیرد.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. امکان مقایسه‌ی مسافت طی‌شده توسط مدل‌های مختلف در پیست آزمون را فراهم کنید

لطفاً ویژگی‌ای به رابط `IRemoteControlCar` اضافه کنید تا پیاده‌سازی‌های ویژگی `DistanceTravelled` برای هر دو نوع خودرو در دسترس قرار گیرد.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. امکان رتبه‌بندی خودروهای تولیدی را فراهم کنید

لطفاً رابط `IComparable<T>` را در کلاس `ProductionRemoteControlCar` پیاده‌سازی کنید. ترتیب مرتب‌سازی پیش‌فرض خودروها باید صعودی و بر اساس تعداد پیروزی‌ها باشد.

متد استاتیک `TestTrack.GetRankedCars()` را پیاده‌سازی کنید تا خودروهای داده‌شده را به ترتیب صعودی تعداد پیروزی‌ها برگرداند.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
