# حلقه

حلقه‌ها در Rust می‌توانند برای اجرای مکرر یک «بلوک کد» استفاده شوند، تا زمانی که به آن بگویید متوقف شود یا شرط خاصی برقرار شود.

ساده‌ترین شکل حلقه از «کلیدواژه»ی `loop` استفاده می‌کند:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

قطعه‌کد بالا یک حلقه‌ی بی‌نهایت می‌سازد. برای خروج از یک حلقه از کلیدواژه‌ی `break` استفاده کنید:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## ساخت حلقه با `for` و `while`

جز کلیدواژه‌ی `loop`، می‌توانید با `for` و `while` هم حلقه بسازید.

از حلقه‌ی `for` برای پیمایش عنصرهای یک مجموعه یا «تکرارگر» استفاده می‌شود.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

«بازه»ها هم تکرارگر هستند و همین پیمایش آن‌ها را با حلقه‌ی `for` بسیار راحت می‌کند:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

حلقه‌ی `while` اجرای کد را تا برقرار شدن یک شرط تکرار می‌کند. می‌توانیم مثال قبلی را با حلقه‌ی `while` این‌طور بازنویسی کنیم:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```
