# مقدمه

«بازگشت» روشی برای تکرار کد در یک تابع است، به این صورت که تابع خودش را فراخوانی می‌کند.
این روش دیگری برای حلقه زدن و تکرار کردن است. مثل حلقه زدن، تابع باید یک «عبارت منطقی» را بررسی کند تا بداند چه زمانی تمام شود.
برخلاف حلقه زدن، بازگشتی که هرگز تمام نمی‌شود تا بی‌نهایت اجرا نخواهد شد.
مقادیر به‌کاررفته در هر فراخوانی تابع ممکن است در قاب مخصوص خود روی پشته قرار بگیرند.
اگر تعداد فراخوانی‌های تابع فضای بیشتری از آنچه پشته دارد اشغال کند، به خطای «سرریز پشته» منجر می‌شود.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

این خروجی را چاپ می‌کند:

```
The number is 1
The number is 2
After recursion
```

ممکن است موقعیت‌هایی وجود داشته باشد که بیان آن‌ها با بازگشت، خواناتر و/یا استدلال درباره‌شان آسان‌تر از بیان آن‌ها با حلقه باشد.
