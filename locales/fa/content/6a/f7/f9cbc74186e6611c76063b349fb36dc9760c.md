# مقدمه

در JavaScript، «رشته‌های قالبی» امکان جای‌گذاری عبارت‌ها را درون رشته‌ها فراهم می‌کنند؛ به این کار درج رشته هم می‌گویند.
این قابلیت، کارکرد شیء سراسری [`String`][string-reference] را گسترش می‌دهد.

برای ساختن رشته‌های قالبی در JavaScript کافی است متن را میان دو بک‌تیک بگذارید.
این رشته‌ها نه‌تنها اجازه می‌دهند متن شامل خطوط جدید و نویسه‌های خاص دیگر باشد، بلکه می‌توانید متغیرها و عبارت‌های دیگر را هم در آن‌ها جای‌گذاری کنید.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

در مثال بالا، بک‌تیک‌ها (<code>\`\`</code>) برای نمایش یک رشته‌ی قالبی به کار می‌روند. `${...}` جای‌نگهدار است که برای جانشینی استفاده می‌شود.
هر نوع غیررشته‌ای _به‌صورت ضمنی_ به رشته تبدیل می‌شود.
این موضوع در مفهوم [تبدیل نوع][type-conversion-concept] بررسی شده است.
همه‌ی انواع عبارت‌ها را می‌توان با رشته‌های قالبی به کار برد.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

وقتی می‌خواهید رشته‌ای در چند خط قالب‌بندی شود:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

اگر می‌خواهید به‌جای استفاده از رشته‌ی قالبی (یعنی بدون بک‌تیک) یک خط جدید را درون یک رشته‌ی معمولی نمایش دهید، می‌توانید از توالی فرار خط جدید `\n` استفاده کنید:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

با قابلیت‌های جانشینی موجود، می‌توانید منطق را هم وارد این فرایند کنید تا تعیین کنید رشته‌ی خروجی چه باید باشد.
یکی از راه‌های پیاده‌سازی این منطق، استفاده از [عملگر سه‌تایی][ternary-operator] است.
این کار همان کارکرد شرطی `if/else` را در قالبی کمی متفاوت فراهم می‌کند.

برای پیاده‌سازی منطق در نحوه‌ی نگارش رشته‌ی قالبی:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
