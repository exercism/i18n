# اجرای Testها

سیستم‌عامل خود را انتخاب کنید:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. یک Command Prompt باز کنید.
2. اولین تمرین را دریافت کنید:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. به پوشه‌ی exercism بروید:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Testها را اجرا کنید:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(نگران ناموفق بودن Testها در ابتدا نباشید؛ هر تمرین را این‌طور شروع می‌کنید.)_

5. تمرین را حل کنید. راهنمای `instructions.append.md` را پیدا کنید و آن را دنبال کنید ([مشاهده در GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

موفق باشید! خوش بگذرانید!
