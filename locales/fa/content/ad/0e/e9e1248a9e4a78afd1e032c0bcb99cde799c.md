# مقدمه

مقادیر «منطقی» در C++ با نوع `bool` نمایش داده می‌شوند (در برخی منابع به این مقادیر «بولی» هم می‌گویند).
یک `bool` یا `true` است یا `false`.

## عملگرهای منطقی

C++ از سه عملگر منطقی پشتیبانی می‌کند: `!` (NOT)، `&&` (AND) و `||` (OR).
همچنین می‌توانید از نسخه‌های جایگزین `not`، `and` و `or` استفاده کنید.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## اولویت

هر یک از این سه عملگر منطقی _اولویت_ متفاوتی دارد.
در نتیجه، به این ترتیب ارزیابی می‌شوند: ابتدا `!`، سپس `&&` و در پایان `||`.
اگر می‌خواهید ترتیب دیگری را اعمال کنید، می‌توانید یک عبارت منطقی را داخل پرانتز (یعنی `()`) بگذارید، چون پرانتزها اولویت بالاتری دارند.

```cpp
!true && false   // => false
!(true and false) // => true
```

## تبدیل

اگر از `true` یا `false` در جایی استفاده کنید که یک عدد انتظار می‌رود، به ترتیب به `1` و `0` تبدیل می‌شوند.
اگر در یک عملیات منطقی از عدد استفاده کنید، هر مقدار دیگری جز `0` به‌عنوان `true` در نظر گرفته می‌شود، حتی مقادیر منفی.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
