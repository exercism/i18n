# مقدمه

وقتی به دنباله‌ای از `n` مقدار نیاز دارید که هر یک از آن‌ها به اندیس خودش وابسته باشد، Factor به شما `<iota>` را می‌دهد: یک دنباله‌ی مجازی از اعداد صحیح `0, 1, …, n-1`، به‌همراه `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` این اعداد صحیح را از پیش در حافظه تخصیص نمی‌دهد؛ `map` به ترتیب از آن‌ها عبور می‌کند و «quotation» را روی هر یک اعمال می‌کند.

اگر نتیجه‌ی هر موقعیت یک کد کاراکتر باشد، `>string` نتیجه را به یک رشته تبدیل می‌کند؛ این طبیعی‌ترین روش برای سرِهم کردن ردیفی از کاراکترها بر پایه‌ی تصمیم‌هایی است که بر اساس اندیس گرفته می‌شوند:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
