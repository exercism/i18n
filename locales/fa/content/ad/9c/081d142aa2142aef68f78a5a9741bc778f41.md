# راهنمایی‌ها

## کلی

- مستندات [gleam/set][set] را بخوانید
- مستندات [gleam/list][list] هم ممکن است به کارتان بیاید

## 1. شروع یک مجموعه

- مناسب‌ترین تابع، [تابع `set.from_list`][from_list] است

## 2. گسترش مجموعه

- از [تابع `set.insert`][insert] استفاده کنید
- از [تابع `set.contains`][contains] استفاده کنید

## 3. شروع تبادل

- از [تابع `set.contains`][contains] استفاده کنید
- از [تابع `set.insert`][insert] استفاده کنید
- از [تابع `set.delete`][delete] استفاده کنید

## 4. از هر کدام فقط یکی می‌تواند وجود داشته باشد

- ویژگی یک `Set` این است که فقط مقادیر یکتا را در خود نگه می‌دارد
- از [تابع `set.from_list`][from_list] استفاده کنید
- از [تابع `set.to_list`][to_list] استفاده کنید
- تضمینی وجود ندارد که `set.to_list` فهرستی مرتب برگرداند

## 5. کارت‌هایی که همه‌ی آن‌ها دارند

- از [تابع `set.intersection`][intersection] استفاده کنید
- از [تابع `set.to_list`][to_list] استفاده کنید

## 6. همه‌ی کارت‌ها

- از [`set.new`][new] به عنوان انباشتگر استفاده کنید
- از [تابع `set.union`][union] استفاده کنید
- از [تابع `set.size`][size] استفاده کنید

## 7. درخشان برای برد

- از [تابع `set.filter`][filter] استفاده کنید
