# مقدمه

## نوع دادهی سفارشی

نوع دادهی سفارشی روشی است که با آن نوعهای دادهی جدید در Gleam تعریف می‌شوند. هر نوع دادهی سفارشی می‌تواند چندین «گونه» داشته باشد که هر کدام اسم خودش را دارد.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

هر گونه از یک نوع دادهی سفارشی می‌تواند به‌صورت اختیاری داده‌هایی را نگه دارد، و گونه‌های مختلف می‌توانند نوع‌های مختلفی از داده داشته باشند. وقتی یک گونه داده نگه می‌دارد، به آن «رکورد» می‌گویند.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

برای ساختن یک مقدار برای یک گونه‌ی خاص، اگر داده‌ی اضافی نداشته باشد می‌توان به اسم آن اشاره کرد (`Spring`)، و اگر داشته باشد آن را به‌عنوان یک تابع فراخوانی کرد (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

نوع‌های داده‌ی سفارشی، همراه با همه‌چیز در Gleam، «برابری ساختاری» دارند، یعنی دو مقدار از یک گونه و با داده‌ی یکسان، معادل هستند.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

می‌توان با استفاده از عبارت‌های `case` روی گونه‌های نوع داده‌ی سفارشی تطبیق الگو انجام داد.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
