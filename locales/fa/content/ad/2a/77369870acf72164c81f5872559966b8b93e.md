# مقدمه

## نام مستعار نوع

در Gleam می‌توانید از «نام مستعار نوع» استفاده کنید تا برای یک نوع موجود، نامی راحت‌تر بگذارید که در غیر این صورت نوشتنش دشوار است.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

وقتی با `pub type` نوشته شود، این نام مستعار را می‌توان خارج از ماژولی که در آن تعریف شده است به کار برد. اگر `pub` حذف شود، نام مستعار خصوصی می‌شود و نمی‌توان در ماژول‌های دیگر به آن ارجاع داد.
