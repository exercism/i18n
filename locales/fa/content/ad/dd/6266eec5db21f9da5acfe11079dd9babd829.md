# مقدمه

## ساختار

«ساختارها» افزونه‌ای هستند که روی «نقشه»ها بنا شده‌اند و بررسی‌های زمان کامپایل و مقادیر پیش‌فرض را فراهم می‌کنند. هر ساختار به اسم ماژولی که در آن تعریف شده نام‌گذاری می‌شود. برای تعریف یک ساختار از سازه‌ی `defstruct` استفاده کنید. این سازه معمولاً بلافاصله پس از تعریف ماژول می‌آید. `defstruct` یا فهرستی از اتم‌ها را می‌پذیرد (برای مقادیر پیش‌فرض `nil`) یا یک لیست کلیدواژه (برای مقادیر پیش‌فرض مشخص‌شده). فیلدهای بدون مقدار پیش‌فرض باید پیش از فیلدهای دارای مقدار پیش‌فرض بیایند.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### دسترسی به فیلدها و به‌روزرسانی آن‌ها

چون ساختارها روی نقشه‌ها بنا شده‌اند، می‌توانیم از بیشتر توابع نقشه برای گرفتن و دستکاری مقادیر استفاده کنیم. رفتار _Access Behaviour_ برای ساختارها پیاده‌سازی **نشده** است. توصیه می‌شود برای دسترسی به فیلدهای ساختار به‌جای آن از «عملگر دسترسی ایستا» `.` استفاده کنید.

- گرفتن/واکشی مقادیر فیلد:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- به‌روزرسانی مقادیر فیلد

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### تطبیق الگو

از ساختارها می‌توان در تطبیق الگو، با یا بدون اسم ساختار، استفاده کرد.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

با آوردن اسم ساختار در الگو، می‌توانید مطمئن شوید که هر دو طرف، ساختارهایی از یک نوع هستند.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### الزام به مقداردهی اولیه‌ی فیلدها

می‌توانیم از ویژگی ماژول `@enforce_keys` همراه با فهرستی از کلیدهای فیلد استفاده کنیم تا مطمئن شویم هنگام ساخت ساختار، مقادیر مقداردهی اولیه می‌شوند. اگر کلیدی در فهرست نباشد، مقدارش `nil` خواهد بود، همان‌طور که در مثال بالا دیدید. اگر کلید الزام‌شده مقداردهی اولیه نشود، خطایی ایجاد می‌شود.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
