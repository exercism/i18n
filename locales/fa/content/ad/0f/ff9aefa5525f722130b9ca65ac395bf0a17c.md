# نصب

## چه چیزهایی لازم است

موارد پایه‌ی لازم برای توسعه در Common Lisp عبارت‌اند از:

- یک «پیاده‌سازی» Lisp که به شما امکان می‌دهد کد را کامپایل و اجرا کنید و همچنین یک REPL در اختیارتان بگذارد.
- یک ویرایشگر متن با امکانات لازم برای کد Lisp.
- (خوب است که داشته باشید) مرجع پرکاربرد زبان Common Lisp، یعنی ["Common Lisp Hyperspec"][hyperspec].

## Roswell

[Roswell][roswell] دستوری برای نصب و مدیریت پیاده‌سازی‌های Common Lisp است و امکانات زیادی دارد که توسعه و توزیع برنامه‌های Lisp را آسان می‌کند.
ما از آن استفاده می‌کنیم تا مراحل نصب و تست را ساده‌تر کنیم.

### نصب Roswell

راهنمای [نصب][ros-inst] را ببینید و دستورالعمل‌های مربوط به سیستم‌عامل خود را دنبال کنید.
برای بیشتر کاربران، موارد زیر کافی است:

* برای MacOS و Linux، [Homebrew][brew] این کار را ساده می‌کند:
  ```sh
  brew install roswell
  ```
* برای Windows، از [Scoop][scoop] استفاده کنید:
  ```powershell
  scoop install roswell
  ```

اولین باری که از Roswell استفاده می‌کنید، SBCL و Quicklisp را دریافت و نصب می‌کند.
فقط این را اجرا کنید:
```sh
ros help
```

با این دستور وارد REPL شوید:
```sh
ros run
```

## ویرایشگر متن خود را پیکربندی کنید

کسانی که با Common Lisp تازه آشنا شده‌اند، به‌ویژه کسانی که تجربه‌ی قبلی با Emacs دارند، می‌توانند با نصب [Portacle، محیط قابل حمل Common Lisp][portacle] سریع و آسان شروع کنند.
رایگان و پرامکانات است، روی همه‌ی پلتفرم‌های رایج کار می‌کند و از همان ابتدا، «آماده‌ی استفاده» پیکربندی شده است. این بسته موارد زیر را در اختیارتان می‌گذارد:

- یک پیاده‌سازی Lisp: SBCL، همراه با Quicklisp و ASDF.
- یک ویرایشگر متن: Emacs

... همراه با افزونه‌های فراوان برای نوشتن کد Lisp:
- SLIME، یعنی «حالت برتر تعامل با Lisp برای Emacs»، Emacs را به یک IDE برای Common Lisp تبدیل می‌کند
- ParEdit که کار با پرانتزها را آسان می‌کند.

همه‌چیز از همان ابتدا پیکربندی شده به دستتان می‌رسد. Portacle را با دانلود از [صفحه‌ی اصلی][portacle] نصب کنید.

توجه: Emacs (ویرایشگر متن) اگر به آن عادت نداشته باشید، ممکن است در ابتدا گیج‌کننده باشد. خوشبختانه آموزش‌های مقدماتی زیادی درباره‌ی Emacs و SLIME به‌صورت آنلاین در دسترس است.

## شروع سنتی

اگر ترجیح می‌دهید ابزارهای لازم را جداگانه نصب کنید، باید این موارد را نصب و راه‌اندازی کنید:

- یک ویرایشگر متن آشنا به Lisp: [Emacs][emacs] همراه با بسته‌ی [Slime][slime] یا [Sly][sly] گزینه‌ی رایجی است، اما [VIM][vim] با [SLIMV][slimv]، [Atom][atom] با [SLIMA][slima] یا [VSCode][vscode] با یک [افزونه‌ی Common Lisp][vscode-plugin] هم انتخاب‌های خوبی هستند.
- یک پیاده‌سازی Common Lisp: [SBCL][sbcl] گزینه‌ای «امن» است که روی Linux، MacOS و Windows کار می‌کند. از آنجا که این زبان بر پایه‌ی یک استاندارد بنا شده است، [پیاده‌سازی‌های منطبق][awesome-cl-implementations] دیگری هم کار خواهند کرد.
- [Quicklisp][quicklisp] برای مدیریت کتابخانه‌ها. پس از دانلود آن، [دستورالعمل‌ها][quicklisp-install] را دنبال کنید تا مطمئن شوید به‌درستی با پیاده‌سازی Common Lisp شما یکپارچه شده است.
