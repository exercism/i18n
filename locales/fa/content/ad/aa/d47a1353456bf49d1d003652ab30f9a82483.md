# پیش‌نیازها

* یک کامپایلر D نسخه‌ی ۲
* (اختیاری اما توصیه‌شده) DUB

## پیش‌نیاز: کامپایلر D نسخه‌ی ۲

در وب‌سایت زبان D، یعنی [dlang.org](https://dlang.org)، می‌توانید جدیدترین نسخه‌ی کامپایلر مرجع DMD (Digital Mars D) را برای چندین پلتفرم دانلود و نصب کنید.
برای اطلاعات بیشتر، [صفحه‌ی دانلود رسمی](https://dlang.org/download.html) را ببینید.
در Windows، یک راه‌حل جایگزین [استفاده از Chocolatey](https://chocolatey.org/packages/dmd) است.
روی Macهای مبتنی بر Intel، یک راه‌حل جایگزین [استفاده از Homebrew](https://formulae.brew.sh/formula/dmd) است.

### کامپایلرهای دیگر
علاوه بر کامپایلر مرجع DMD که از Backend خودش استفاده می‌کند، دو کامپایلر دیگر هم وجود دارد که می‌توان آن‌ها را از بخش دانلود dlang.org دریافت کرد:

* [GDC](http://gdcproject.org/downloads) که از Backend مربوط به GCC استفاده می‌کند
* [LDC](https://github.com/ldc-developers/ldc#installation) که بر پایه‌ی Backend مربوط به LLVM ساخته شده است

GDC و LDC همیشه هم‌سطح جدیدترین نسخه‌های Frontend مربوط به DMD نیستند، اما سطوح بهینه‌سازی بهتری ارائه می‌دهند و از پلتفرم‌های دیگری مانند ARM هم پشتیبانی می‌کنند.

برای [اطلاعات بیشتر](https://wiki.dlang.org/Compilers) ویکی را ببینید.

### پشتیبانی IDE

از زبان D در IDEهای گوناگون هم پشتیبانی می‌شود، مثلاً [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) برای Visual Studio و [D plugin](https://plugins.jetbrains.com/plugin/7727?pr=clion) برای CLion محصول IntelliJ.
برای [اطلاعات بیشتر](https://wiki.dlang.org/IDEs) ویکی را ببینید.

### پیش‌نیاز: DUB

[DUB](https://github.com/dlang/dub) یک ابزار مدیریت ساخت برای D است.

ما آن را به عنوان راهی برای ساده‌تر کردن فرایند اجرای Testها توصیه می‌کنیم، اما اگر نمی‌توانید یا نمی‌خواهید آن را نصب کنید، اجرای Testها بدون DUB هم ممکن است.

#### Windows

[صفحه‌ی دانلود وب‌سایت DUB](https://code.dlang.org/download) یک نصب‌کننده‌ی Windows دارد.

#### MacOS

* [صفحه‌ی دانلود وب‌سایت DUB](https://code.dlang.org/download) فایل‌های باینری macOS را دارد.
* برای Macهای مبتنی بر Intel و Apple Silicon هم [بسته‌ی Homebrew در دسترس است](https://formulae.brew.sh/formula/dub):

#### Linux

* [صفحه‌ی دانلود وب‌سایت DUB](https://code.dlang.org/download) فایل‌های باینری Linux را دارد.
* برای توزیع‌های مختلف هم بسته‌هایی ارائه شده است:
    * [ArchLinux](https://www.archlinux.org/packages/community/x86_64/dub/)
    * [Debian/Ubuntu](http://d-apt.sourceforge.net/)
    * [Gentoo](https://github.com/gentoo/dlang/tree/master/dev-util/dub)
    * [OpenSUSE](http://software.opensuse.org/download.html?project=devel%3Alanguages%3AD&package=dub)
