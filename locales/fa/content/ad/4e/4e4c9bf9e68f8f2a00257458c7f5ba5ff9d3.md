# مقدمه

## شمارش

تا اینجا بیشتر با عددها و رشته‌ها سر و کار داشته‌ایم.
برای مدل‌سازی دنیای واقعی، ممکن است بخواهیم تعداد محدودی مقدار را داشته باشیم که یک متغیر می‌تواند بپذیرد.
شاید بخواهید نوعی اختصاصی داشته باشید که چند مقدار متمایز با نام‌های متمایز دارد.
برای نمونه، در یک کارخانه‌ی اسکیت‌بردسازی، جنس دک می‌تواند فقط یکی از افرا، بامبو یا پلاستیک باشد.

می‌توانستید برای رمزگذاری این مقدارها از عددهای صحیح استفاده کنید، اما آن‌وقت لازم بود با code اضافی بررسی کنید که آیا مقداری نامعتبر از سمت سیستم برای این جنس می‌آید یا نه.
ردیابی معنای این [_اعداد جادویی_][magic numbers] در سراسر source code دشوار است و این عددها به‌آسانی با هم قاطی می‌شوند.
از `enumerations` می‌توان برای تشویق به نوشتن code گویا و برای جلوگیری از اشتباه‌های مقایسه‌ی ناخواسته استفاده کرد.

## نمونه‌ی کاربرد

اصطلاح دقیق برای این نوع شمارش، `scoped enumeration` است.
قطعه‌کد زیر نشان می‌دهد چگونه یک `enumeration` با نام `DeckMaterial` بنویسیم.
به کلیدواژه‌ی `enum class` و `;` در پایان تعریف توجه کنید:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
حالا به تابع قیمت‌گذاری در فروشگاه اسکیت نگاه کنید و به عملگر تفکیک دامنه (`::`) توجه کنید که یک `enumerator` را از `enumeration` مشخص می‌کند:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## دامنه‌بندی

تصور کنید `enumeration` دومی برای جنس چرخ دارید:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
هرچند هم چرخ‌ها و هم دک می‌توانند از _پلاستیک_ ساخته شوند، این دو با هم اشتباه گرفته نمی‌شوند.
این‌ها _نوع_های متفاوتی هستند: پلاستیک `DeckMaterial` و پلاستیک `WheelMaterial`.
هر `enumeration`، `enumerators` خودش را در دامنه‌ی خودش دارد، یعنی `namespace` خودش.
به همین دلیل است که به آن‌ها `scoped enumerations` می‌گویند.

## شمارش بدون دامنه
ممکن است فکر کنید حالا که نام `scoped` وجود دارد، شمارش‌های `unscoped` هم وجود دارند، و حق با شماست.
`Unscoped enumerations` کم‌طرفدارتر شده‌اند، چون همه‌شان در یک namespace سراسری مشترک‌اند.
به خاطر همین اشتراک، نمی‌توانستید دو `unscoped enumerations` با `enumerators` یکسان، مانند _پلاستیک_ در مثال بالا، داشته باشید.

همچنین، `unscoped enumerations` به‌طور ضمنی به عدد صحیح تبدیل می‌شوند.
برای دیدن نتیجه‌ای غافلگیرکننده به مثال زیر نگاه کنید:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

اگر می‌خواهید `scoped enumerations` را به عدد صحیح تبدیل کنید، می‌توانید از `static_cast<int>` استفاده کنید.
