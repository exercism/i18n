# دستورالعمل‌ها

وظیفه‌ی شما این است که مشخص کنید هنگام بخشیدن کوکی اضافه چه می‌گویید.

اگر اسم آن شخص را بدانید (مثلاً اسمش Do-yun باشد)، می‌گویید:

```text
One for Do-yun, one for me.
```

اگر اسم آن شخص را ندانید، به‌جایش _you_ می‌گویید.

```text
One for you, one for me.
```

چند مثال:

| اسم    | گفت‌وگو                     |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
