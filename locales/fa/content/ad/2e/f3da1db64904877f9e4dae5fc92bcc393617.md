# مقدمه

## توابع ریاضی

ریشه‌ی دوم، زاویه و منحنی‌های رشد را فقط با `+`، `-`، `*` و `/` به‌سختی می‌توان حساب کرد. واژگان [`math.functions`][math.functions] کلماتی دارد که این محاسبه‌ها را برایتان انجام می‌دهند و [`math.constants`][math.constants] هم π را دارد. هر یک از این کلمات هم مثل هر کلمه‌ی دیگری ورودی‌هایش را از پشته می‌گیرد و پاسخش را همان‌جا می‌گذارد.

## ریشه‌ی دوم

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

نردبانی به طول ۵ متر که پایه‌اش ۳ متر از دیوار فاصله دارد، ۴ متر از دیوار بالا می‌رود:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## عدد پی

`pi` (از `math.constants`) مقدار π را روی پشته می‌گذارد؛ یعنی تعداد دفعاتی که قطر یک دایره در محیطش جا می‌شود:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## زاویه‌ها بر حسب رادیان‌اند

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`، `cos` و `tan` یک زاویه می‌گیرند، اما نه بر حسب درجه. آن‌ها از **رادیان** استفاده می‌کنند؛ در رادیان نیم دور برابر π است نه ۱۸۰. دادن درجه به آن‌ها خطا محسوب نمی‌شود: بی‌سروصدا جواب غلط می‌دهد.

`deg>rad` درجه را به رادیان تبدیل می‌کند و `rad>deg` برعکسش را. این دو همان ضرب در π و تقسیم بر ۱۸۰ هستند، یا برعکس:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

پیش از فراخوانی `sin`، درجه را به رادیان تبدیل کنید:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

یک شیب‌راهه به طول ۱۰ متر با زاویه‌ی ۳۰ درجه، ۵ متر بالا می‌رود. پاسخ به صورت `4.999999999999999` چاپ می‌شود، چون توابع ریاضی نزدیک‌ترین عدد اعشاری را می‌دهند نه مقدار دقیق را. بدون تبدیل، `30 sin` عدد ۳۰ را رادیان در نظر می‌گیرد (تقریباً پنج دور کامل) و شیب‌راهه `-9.88` متر «بالا می‌رود».

## یافتن یک زاویه

`fatan2` برعکس عمل می‌کند: اگر ارتفاع و فاصله‌ی افقی را به آن بدهید، زاویه را بر حسب رادیان برمی‌گرداند. این کلمه در [`math.libm`][math.libm] قرار دارد. اول فاصله‌ی *عمودی* روی پشته می‌رود و بعد فاصله‌ی *افقی*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

زاویه از جهت مثبت *افقی* اندازه‌گیری می‌شود. `fatan2` به علامت هر دو فاصله نگاه می‌کند، پس می‌تواند هر جوابی از منفی ۱۸۰ تا ۱۸۰ درجه بدهد.

## توان‌های ده: `10^` و `log10`

`10^` عدد ۱۰ را به توانی می‌رساند:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` برعکسش را انجام می‌دهد. به این پرسش پاسخ می‌دهد: «۱۰ به توان چند، این عدد را می‌دهد؟» آن پاسخ همان **لگاریتم** عدد است:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## `e^` و `log`

`e^` و `log` همان جفت قبلی‌اند، با این تفاوت که *e* (حدود ۲٫۷۱۸) جای ۱۰ را گرفته است. `e^` عدد *e* را به توانی می‌رساند و `log` به این پرسش پاسخ می‌دهد: «*e* به توان چند، این عدد را می‌دهد؟»

```
e^  ( x -- y )
log ( x -- y )
```

ریاضی‌دان‌ها از *e* برای هر چیزی استفاده می‌کنند که در هر گام با همان کسر رشد یا کوچک می‌شود. پولی که سود می‌گیرد یک نمونه است و فنجانی چای که سرد می‌شود نمونه‌ای دیگر:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` کار `e^` را برمی‌گرداند. این‌طوری پرسش را از سمت دیگر جواب می‌دهد: چند دقیقه طول می‌کشد تا فاصله به ۴۰ درجه برسد؟

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
