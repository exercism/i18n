# مقدمه

JavaScript یک زبان پویاست که از سبک‌های شیءگرا، دستوری و اعلانی (مثلاً برنامه‌نویسی تابعی) پشتیبانی می‌کند.

## (تجدید) انتساب

چند راه اصلی برای انتساب مقدار به اسم‌های مختلف در JavaScript وجود دارد: استفاده از متغیرها یا ثابت‌ها. در Exercism، متغیرها همیشه به‌صورت [camelCase][wiki-camel-case] نوشته می‌شوند؛ ثابت‌ها به‌صورت [SCREAMING_SNAKE_CASE][wiki-snake-case]. هیچ راهنمای رسمی‌ای برای پیروی وجود ندارد و شرکت‌ها و سازمان‌های مختلف، راهنماهای سبک متفاوتی دارند. _هر طور که دوست دارید می‌توانید متغیرها را بنویسید._ مزیت نوشتن آن‌ها به همان شکلی که تمرین‌ها آماده شده‌اند این است که در رابط وب و بیشتر محیط‌های توسعه‌ی یکپارچه به شکل متفاوتی برجسته می‌شوند.

متغیرها در JavaScript را می‌توان با کلیدواژه‌ی [`const`][mdn-const]، [`let`][mdn-let] یا [`var`][mdn-var] تعریف کرد.

یک متغیر هنگام استفاده از `let` یا `var` می‌تواند در طول عمر خود به مقادیر مختلفی اشاره کند. برای مثال، `myFirstVariable` را می‌توان با عملگر انتساب `=` چندین بار تعریف و بازتعریف کرد:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

برخلاف `let` و `var`، متغیرهایی که با `const` تعریف می‌شوند فقط یک بار می‌توانند مقدار بگیرند. از این ویژگی برای تعریف ثابت‌ها در JavaScript استفاده می‌شود.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 در یک تمرین مفهومی بعدی، تفاوت میان انتساب/اتصال _ثابت_ و _مقدار_ ثابت بررسی و توضیح داده می‌شود.

## اعلان توابع

در JavaScript، واحدهای عملکردی در _توابع_ کپسوله می‌شوند و معمولاً اگر توابع به هم مربوط باشند، در یک فایل کنار هم قرار می‌گیرند. این توابع می‌توانند پارامتر (آرگومان) بگیرند و با کلیدواژه‌ی `return` مقداری را _برگردانند_. توابع با نحوه‌ی نگارش `()` فراخوانی می‌شوند.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 در JavaScript روش‌های _بسیار_ متفاوتی برای اعلان یک تابع وجود دارد. ظاهر این روش‌های دیگر با استفاده از کلیدواژه‌ی `function` متفاوت است. این مسیر تلاش می‌کند آن‌ها را به‌تدریج معرفی کند، اما اگر از قبل با آن‌ها آشنا هستید، با خیال راحت از هر کدامشان استفاده کنید. در بیشتر موارد، استفاده از یکی یا دیگری بهتر یا بدتر نیست.

## در دسترس قرار دادن برای فایل‌های دیگر

برای اینکه یک `function`، یک ثابت یا یک متغیر در _فایل‌های دیگر_ در دسترس باشد، باید با کلیدواژه‌ی `export` [صادر شود][mdn-export]. سپس فایل دیگری می‌تواند این‌ها را با کلیدواژه‌ی `import` [وارد کند][mdn-import]. به این کار سیستم ماژول هم می‌گویند. یک مثال عالی، نحوه‌ی کار همه‌ی تست‌هاست. هر تمرین دست‌کم یک فایل دارد، مثلاً `lasagna.js`، که _پیاده‌سازی_ را در خود دارد. علاوه بر این، دست‌کم یک فایل دیگر هم وجود دارد، مثلاً `lasagna.spec.js`، که _تست‌ها_ را در خود دارد. این فایل، موجودیت‌های عمومی (یعنی صادرشده) را _وارد می‌کند_ تا پیاده‌سازی را تست کند:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
