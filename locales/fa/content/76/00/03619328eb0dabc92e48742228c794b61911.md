# مقدمه

در Common Lisp، رشته‌ها [بردارها][concept-vectors]ی از [کاراکترها][concept-characters] هستند. آن‌ها به‌صورت کاراکترهایی نوشته می‌شوند که میان دو علامت نقل‌قول دوتایی قرار می‌گیرند (مثلاً "Hello World!").

«محمول» `stringp` تنها در صورتی «درست» را برمی‌گرداند که مقدار داده‌شده یک رشته باشد.

رشته‌ها را می‌توان با تابع `subseq` به زیررشته‌ها تقسیم کرد. این تابع رشته، یک اندیس شروع و به‌صورت اختیاری یک اندیس پایان می‌گیرد. اندیس‌گذاری از صفر آغاز می‌شود.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

رشته‌ها را می‌توان با `string=` از نظر برابری مقایسه کرد. اگر لازم است بزرگی و کوچکی کاراکترها نادیده گرفته شود، می‌توان از `string-equal` استفاده کرد.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

کارهایی مانند بزرگ‌کردن حروف، کوچک‌کردن حروف و بزرگ‌کردن حرف نخست واژه‌ها را می‌توان با `string-upcase`، `string-downcase` و `string-capitalize` انجام داد.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
