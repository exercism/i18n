# درباره

`reduce` تاشوی عمومی Factor است: یک دنباله را می‌پیماید و یک انباشتگر را از میان یک «quotation» دودویی می‌گذراند که انباشتگر جاری و عنصر بعدی را می‌گیرد و انباشتگر تازه را تولید می‌کند.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

یک مقدار اولیه‌ی سفارشی به `reduce` امکان می‌دهد تاشوهایی را بیان کند که `sum` یا `product` از عهده‌شان برنمی‌آیند. برای نمونه، بزرگ‌ترین مقدار یک دنباله با یک مقدار پیش‌فرض، برای وقتی که همه‌ی عنصرها در مقایسه می‌بازند:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

مقدار اولیه‌ی `0` در مقایسه شرکت می‌کند، بنابراین یک دنباله‌ی تماماً منفی به‌جای کوچک‌ترین مقدارش همچنان `0` را تولید می‌کند.

## `produce`: بازشو

قرینه‌ی `reduce` تابع `produce` است (در [`sequences`][sequences]): `reduce` یک دنباله را *مصرف* می‌کند، در حالی که `produce` یکی را *تولید* می‌کند. یک quotation محمولی حالت جاری را می‌آزماید؛ تا زمانی که یک مقدار درست برگرداند، یک quotation بدنه عنصر بعدی را تولید می‌کند.

```
produce ( pred quot -- seq )
```

`reduce` و `produce` در کنار هم جفت تاشو/بازشوی Factor را می‌سازند.

## کاهش‌های تجمعی

خانواده‌ی تجمعی در [`math.statistics`][math.statistics] دنباله‌ای به همان طول ورودی برمی‌گرداند که هر عنصرش، کاهش روی پیشوند تا آن موقعیت (و شامل خود آن) است:

| واژه          | عملیات جاری       |
|---------------|-------------------|
| `cum-sum`     | مجموع جاری        |
| `cum-product` | حاصل‌ضرب جاری     |
| `cum-min`     | کمینه‌ی جاری      |
| `cum-max`     | بیشینه‌ی جاری     |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

کاهش‌های تجمعی وقتی به کار می‌آیند که بخواهید ببینید یک کمیت *چگونه* در طول دنباله تغییر کرده است، نه فقط مقدار نهایی‌اش. زنجیره کردن آن‌ها هم مفید است: خروجی یک کاهش تجمعی خودش یک دنباله است که می‌توان آن را به دیگری داد.
