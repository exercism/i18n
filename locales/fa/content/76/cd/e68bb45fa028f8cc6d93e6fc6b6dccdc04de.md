# راهنماها

## کلیات

- یک مقدار صحیح را می‌توان به‌صورت یک یا چند رقم پشت سر هم تعریف کرد.

## 1. تعریف زمان مورد انتظار پخت در فر بر حسب دقیقه

- باید یک [متد][methods] بدون هیچ آرگومانی تعریف کنید.
- باید یک مقدار صحیح برگردانید (به [انواع توکار][built-in types] نگاه کنید).

## 2. محاسبه‌ی زمان باقی‌مانده‌ی پخت در فر بر حسب دقیقه

- باید یک [متد][methods] با یک پارامتر تعریف کنید.
- پارامتر متد یک عدد صحیح است.
- باید یک مقدار صحیح برگردانید (به [انواع توکار][built-in types] نگاه کنید).
- می‌توانید از عملگر `-` برای تفریق مقادیر استفاده کنید.

## 3. محاسبه‌ی زمان آماده‌سازی بر حسب دقیقه

- باید یک [متد][methods] با یک پارامتر تعریف کنید.
- پارامتر متد یک عدد صحیح است.
- باید یک مقدار صحیح برگردانید (به [انواع توکار][built-in types] نگاه کنید).
- می‌توانید از عملگر `*` برای ضرب مقادیر استفاده کنید.

## 4. محاسبه‌ی زمان سپری‌شده بر حسب دقیقه

- باید یک [متد][methods] با دو پارامتر تعریف کنید.
- پارامترهای متد از نوع صحیح هستند.
- باید یک مقدار صحیح برگردانید (به [انواع توکار][built-in types] نگاه کنید).
- می‌توانید یکی از متدهای دیگر را که قبلاً تعریف کرده‌اید [فراخوانی][invocation] کنید.
- می‌توانید از عملگر `+` برای جمع مقادیر استفاده کنید.

[methods]: https://docs.scala-lang.org/overviews/scala-book/methods-first-look.html
[built-in types]: https://docs.scala-lang.org/overviews/scala-book/built-in-types.html
[invocation]: https://docs.scala-lang.org/style/method-invocation.html
