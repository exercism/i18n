# درباره

برای آغاز سفر C++، با متغیرها، فراخوانی توابع و کامنت‌ها شروع می‌کنیم.

## کامنت‌ها

کامنت‌ها دو نوع‌اند: تک‌خطی و چندخطی.
هر چیزی که در همان خط بعد از `//` بیاید، کامپایلر آن را نادیده می‌گیرد.
کامنت‌های چندخطی با نام کامنت‌های سبک C هم شناخته می‌شوند.
این کامنت‌ها بین `/*` و `*/` قرار می‌گیرند.
هر چیزی که میان این دو بیاید هم نادیده گرفته می‌شود.

## متغیرها

C++ زبانی نوع‌دار است.
همه‌ی نوع‌ها باید در زمان کامپایل مشخص باشند و معمولاً باید آن‌ها را به‌صراحت اعلام کنید.
نوع یک متغیر نمی‌تواند تغییر کند.
یک متغیر از نوع عدد صحیح به اسم `years` را می‌توان این‌گونه تعریف کرد:

```cpp
int years;
```

روش خوبی است که متغیرها را هنگام تعریف، مقداردهی اولیه کنید.
C++ سازوکارهای مختلفی برای این کار ارائه می‌دهد.
نسخه‌ای که با آکولاد نوشته می‌شود با C++ مدرن هم‌خوان‌تر است، اما نسخه‌ای که با علامت مساوی نوشته می‌شود هم بسیار رایج است.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ اجازه می‌دهد از متغیرهای مقداردهی‌نشده استفاده کنید.
تا وقتی که متغیر به‌طور عمدی مقدار نگیرد، مقدارش نامعین است و ممکن است هر مقداری داشته باشد.
برای پرهیز از خطاهای استفاده پیش از مقداردهی و رفتار نامعین، توصیه می‌شود **همیشه مقداردهی اولیه کنید**.
رفتار نامعین می‌تواند در بدترین زمان ممکن برنامه‌تان را از کار بیندازد، در حالی که پیش‌تر بی‌هیچ مشکلی اجرا می‌شد.
تأکید بر این نکته هرگز کافی نیست: به هر قیمتی از رفتار نامعین بپرهیزید.

## عملگرهای حسابی

عملگرهای حسابی مانند `*`، `+` یا `-` می‌توانند بخشی از عبارتی مثل `3 * 2` یا `tomatoes + potatoes` باشند.

## به‌روزرسانی متغیرها

می‌توانید مقدار متغیرها را دوباره تعیین کنید، به شرط آنکه نوعشان حفظ شود:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## توابع

توابع یک اسم، یک نوع بازگشتی و فهرستی از پارامترها (که ممکن است خالی باشد) دارند.
نمونه‌ای از تابعی به اسم `always_fortyseven` که همیشه ۴۷ را برمی‌گرداند، این‌گونه است:

```cpp
int always_fortyseven() {
    return 47;
}
```

این هم `vip_fee` است که یک پارامتر دارد:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

یا `total_fee`، تابعی با سه پارامتر و یک فراخوانی به تابعی دیگر.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

توابع در C++ برخلاف برخی زبان‌های دیگر، مقدار آخرین دستور را برنمی‌گردانند.
برای اینکه کد کامپایل شود، کلیدواژه‌ی `return` الزامی است.

### فضای سفید

فضای سفید برای قالب‌بندی کد منبع به کار می‌رود و شامل فاصله، تب و خط جدید است.
از آنجا که کامپایلر فضای سفید غیرضروری را نادیده می‌گیرد، می‌توانید از آن برای ساختاربندی کدتان استفاده کنید.
استفاده‌ی هوشمندانه از فضای سفید می‌تواند خوانایی کد شما را بهبود ببخشد.
استانداردهای قالب‌بندی مختلفی وجود دارد، اما همه‌ی آن‌ها قراردادی‌اند و کامپایلر آن‌ها را الزامی نمی‌کند.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
