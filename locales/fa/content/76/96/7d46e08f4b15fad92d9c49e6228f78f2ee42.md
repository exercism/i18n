# راهنمایی‌ها

## 1. پیاده‌سازی اینترفیس `Stringer` برای نوع `TemperatureUnit`

- نوع `TemperatureUnit` از قبل برای شما ساخته شده است و یک یکای دما را نمایش می‌دهد
- توجه کنید که از قبل ۲ ثابت از این نوع برای شما ساخته شده است: `Celsius` و `Fahrenheit` که به‌ترتیب دما را بر حسب سلسیوس و فارنهایت نمایش می‌دهند
- یک متد `String()` به نوع `TemperatureUnit` اضافه کنید تا اینترفیس `Stringer` را برآورده کند.
  این متد باید رشته‌ی `"°C"` را برگرداند اگر یکای دما سلسیوس باشد، یا رشته‌ی `"°F"` را اگر یکای دما فارنهایت باشد

## 2. پیاده‌سازی اینترفیس `Stringer` برای نوع `Temperature`

- یک متد `String()` به نوع `Temperature` اضافه کنید تا اینترفیس `Stringer` را برآورده کند
- متد `String()` باید رشته‌ای برگرداند که مقدار عددی دما و یکای دما در آن با یک فاصله از هم جدا شده‌اند (`<temperature> <unit>`)
- ساختار `Temperature` شامل یک `TemperatureUnit` و یک `int` است.
  می‌توانید از [fmt.Sprintf][sprintf] استفاده کنید تا در قالب‌بندی این رشته به شما کمک کند
- از آنجا که `TemperatureUnit` از قبل اینترفیس `Stringer` را پیاده‌سازی کرده است (از تمرین ۱)، توابع بسته‌ی `fmt` مانند [fmt.Sprintf][sprintf] می‌دانند چگونه آن را قالب‌بندی کنند وقتی از [افعال قالب‌بندی][fmt] `%v` یا `%s` استفاده می‌کنید

## 3. پیاده‌سازی اینترفیس `Stringer` برای نوع `SpeedUnit`

- نوع `SpeedUnit` از قبل برای شما ساخته شده است و یک یکای سرعت را نمایش می‌دهد
- توجه کنید که از قبل ۲ ثابت از این نوع برای شما ساخته شده است: `KmPerHour` و `MilesPerHour` که به‌ترتیب سرعت را بر حسب کیلومتر بر ساعت و مایل بر ساعت نمایش می‌دهند
- یک متد `String()` به نوع `SpeedUnit` اضافه کنید تا اینترفیس `Stringer` را برآورده کند.
  این متد باید رشته‌ی `"km/h"` را برگرداند اگر یکای سرعت کیلومتر بر ساعت باشد، یا رشته‌ی `"mph"` را اگر یکای سرعت مایل بر ساعت باشد.

## 4. پیاده‌سازی اینترفیس `Stringer` برای `Speed`

- یک متد `String()` به نوع `Speed` اضافه کنید تا اینترفیس `Stringer` را برآورده کند
- متد `String()` باید رشته‌ای برگرداند که مقدار عددی سرعت و یکای سرعت در آن با یک فاصله از هم جدا شده‌اند (`<speed> <unit>`)
- `Speed` شامل یک `SpeedUnit` و یک `int` است.
  می‌توانید از [fmt.Sprintf][sprintf] استفاده کنید تا در قالب‌بندی این رشته به شما کمک کند
- از آنجا که ساختار `TemperatureUnit` از قبل اینترفیس `Stringer` را پیاده‌سازی کرده است (از تمرین ۳)، توابع بسته‌ی `fmt` مانند [fmt.Sprintf][sprintf] می‌دانند چگونه آن را قالب‌بندی کنند وقتی از [افعال قالب‌بندی][fmt] `%v` یا `%s` استفاده می‌کنید
- برای درج یک `%` در رشته‌ی نهایی هنگام استفاده از [fmt.Sprintf][sprintf]، از `%%` در رشته‌ی قالب‌بندی استفاده کنید.

## 5. پیاده‌سازی اینترفیس `Stringer` برای نوع `MeteorologyData`

- `Speed` شامل فیلدهای `Temperature` و `Speed` است، در کنار فیلدهای دیگر.
  می‌توانید از [fmt.Sprintf][sprintf] استفاده کنید تا در قالب‌بندی این رشته به شما کمک کند
- متد `String` باید داده‌های هواشناسی را در قالب زیر برگرداند: `"<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity"`
- از آنجا که نوع‌های `Temperature` و `Speed` از قبل اینترفیس `Stringer` را پیاده‌سازی کرده‌اند (از تمرین‌های ۲ و ۴)، توابع بسته‌ی `fmt` مانند [fmt.Sprintf][sprintf] می‌دانند چگونه آن را قالب‌بندی کنند وقتی از [افعال قالب‌بندی][fmt] `%v` یا `%s` استفاده می‌کنید

[fmt]: https://pkg.go.dev/fmt
[sprintf]: https://pkg.go.dev/fmt#Sprintf
