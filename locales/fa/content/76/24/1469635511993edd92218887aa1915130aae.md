# درباره

[فرم خاص `with`][with] راهی فراهم می‌کند تا روی «مسیر موفق» یک زنجیره از گام‌هایی که ممکن است شکست بخورند تمرکز کنید و بعداً به شکست‌ها رسیدگی کنید.

فرض کنید می‌خواهید یک نام کاربری را با چند بررسی اعتبارسنجی کنید. ممکن است سراغ `case` بروید:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

شاید الان خوانا باشد، اما اگر بررسی‌های تودرتوی بیشتری اضافه کنید، وضعیت به‌هم‌ریخته‌تر می‌شود. در این وضعیت از `with` استفاده کنید:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

در هر گام، اگر یک بند مطابقت داشته باشد، زنجیره ادامه می‌یابد تا اینکه بلوک `do` اجرا شود. اگر یک مطابقت شکست بخورد، زنجیره متوقف می‌شود و بند نامطابق برگردانده می‌شود.

می‌توانید در زنجیره از گاردها استفاده کنید، همچنین از عملگر `=` برای مطابقت‌های معمولی.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

در نهایت، می‌توانید از یک بلوک `else` استفاده کنید تا مطابقت‌های ناموفق را بگیرید و مقدار بازگشتی را تغییر دهید.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

بلوک `else` مانند یک دستور `case` برای هر مقدار نامطابق در بند `with` است. اولین مقداری که مطابقت داشته باشد استفاده می‌شود.
