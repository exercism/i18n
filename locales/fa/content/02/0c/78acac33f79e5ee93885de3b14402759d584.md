# دستکاری بیت

Crystal برای دستکاری [`Int`][ints] در سطح دودویی، عملگرهای بیتی دارد.

## عملگرهای جابه‌جایی

Crystal [عملگرهای جابه‌جایی][shift] دارد که بیت‌ها را به چپ (`<<`) یا راست (`>>`) جابه‌جا می‌کنند.

### جابه‌جایی به چپ(`<<`)

عملگر جابه‌جایی به چپ (`<<`) بیت‌ها را به چپ جابه‌جا می‌کند.
مقداری که باید جابه‌جا شود در سمت چپ و تعداد مکان‌های جابه‌جایی در سمت راست مشخص می‌شود.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

اگر عدد منفی باشد، در عوض به راست جابه‌جا می‌شود.

```crystal
0b0010 << -1
# => 0b0001
```

### جابه‌جایی به راست(`>>`)

عملگر جابه‌جایی به راست (`>>`) بیت‌ها را به راست جابه‌جا می‌کند.
مانند عملگر جابه‌جایی به چپ، مقداری که باید جابه‌جا شود در سمت چپ و تعداد مکان‌های جابه‌جایی در سمت راست مشخص می‌شود.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

و به همین ترتیب، اگر عدد منفی باشد، عملگر به چپ جابه‌جا می‌شود.

```crystal
0b0100 >> -1
# => 0b1000
```

## عملگرهای دوتایی

Crystal [سه عملگر دوتایی][binary] (`&`، `|`، `^`) و یک عملگر `~` برای انجام عملیات بیتی دارد.

### و بیتی(`&`)

عملگر دوتایی «و» (`&`) یک عملیات «و» بیتی روی دو مقدار انجام می‌دهد.
هر بیت در مقدار اول را با بیت در همان موقعیت در مقدار دوم مقایسه می‌کند.
اگر هر دو بیت ۱ باشند، بیت حاصل روی ۱ تنظیم می‌شود.
در غیر این صورت، روی ۰ تنظیم می‌شود.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### یا بیتی(`|`)

عملگر دوتایی «یا» (`|`) یک عملیات «یا» بیتی روی دو مقدار انجام می‌دهد.
همچنین هر بیت در مقدار اول را با بیت در همان موقعیت در مقدار دوم مقایسه می‌کند.
اگر هر یک از بیت‌ها ۱ باشد، بیت حاصل روی ۱ تنظیم می‌شود.
در غیر این صورت، روی ۰ تنظیم می‌شود.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### یا انحصاری(`^`)

عملگر دوتایی «یا انحصاری» (`^`) یک عملیات «یا انحصاری» بیتی انجام می‌دهد.
مانند عملگرهای بیتی «و» و «یا»، هر بیت از مقدار اول را با بیت در همان موقعیت در مقدار دوم مقایسه می‌کند.
اگر _فقط یکی_ از آن‌ها ۱ باشد، بیت حاصل ۱ است.
در غیر این صورت، ۰ است.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### نقیض بیتی(`~`)

در نهایت، عملگر نقیض بیتی (`~`) هر یک از بیت‌های مقدار را معکوس می‌کند.
برخلاف سایر عملگرهای دوتایی، این یک عملگر یکانی است که فقط روی مقدار سمت راست عمل می‌کند.

```crystal
~0b1110_0010
# => 0b0001_1101
```
