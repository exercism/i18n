# راهنمایی‌ها

## عمومی

- به هر یک از اجزای یک تاپل می‌توان با افزودن _.n_ به اسم تاپل دسترسی داشت، که در آن _n_ اندیس آن جزء است و از ۰ شروع می‌شود.

## 1. گرفتن اسم اسباب‌بازی

- می‌توانید با استفاده از نحوه‌ی نگارش `.n` به اسم اسباب‌بازی دسترسی داشته باشید.

## 2. افزودن اسباب‌بازی تازه به پایگاه داده

- می‌توانید با استفاده از نحوه‌ی نگارش تاپل `(name1: value1, name2: value2, ...)` یک تاپل تازه بسازید.

## 3. به‌روزرسانی تعداد یک اسباب‌بازی

- می‌توانید از یک [حلقه‌ی For][for-loop] برای پیمایش آرایه‌ی تاپل‌ها و به‌روزرسانی تعداد اسباب‌بازی استفاده کنید.
- می‌توانید از توابعی که پیش‌تر پیاده‌سازی شده‌اند برای به دست آوردن اسم اسباب‌بازی استفاده کنید.
- می‌توانید با یک [دستور شرطی][conditional-statement] بررسی کنید که آیا اسم اسباب‌بازی با اسمی که می‌خواهید به‌روزرسانی کنید یکسان است یا نه.
- می‌توانید با نحوه‌ی نگارش `.n` تعداد اسباب‌بازی را به‌روزرسانی کنید، مثلاً: `toys.price = 3`.

## 4. افزودن کلید دسته‌بندی به یک اسباب‌بازی

- می‌توانید از یک [حلقه‌ی For][for-loop] برای پیمایش آرایه‌ی تاپل‌ها و افزودن کلید دسته‌بندی به اسباب‌بازی استفاده کنید.
- تاپل تغییرناپذیر است، پس باید تاپل تازه‌ای بسازید که کلید دسته‌بندی به آن اضافه شده باشد.
  
[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
