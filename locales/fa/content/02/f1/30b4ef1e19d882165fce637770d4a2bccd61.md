# مقدمه

## اعداد

Lua برای اعداد از دو نمایش استفاده می‌کند: اعداد صحیح ۶۴ بیتی و اعداد اعشاری با دقت دوگانه. این زبان از مجموعه‌ی معمول عملگرهای حساب پشتیبانی می‌کند: جمع، تفریق، ضرب، تقسیم و منفی‌کردن. علاوه بر این‌ها، تقسیم کف، باقیمانده و توان را هم پشتیبانی می‌کند.

| عملگر | مثال                |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
