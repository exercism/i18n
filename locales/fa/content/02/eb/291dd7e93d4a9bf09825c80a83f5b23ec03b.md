# مفاهیم سال کبیسه

من راه‌حل مثال اول را ترجیح می‌دهم، چون ایجاز آن با آنچه از Rust اصطلاحی دیده‌ام همخوانی دارد. همچنین از افزودن مفهوم بستار در راه‌حل متعارف پرهیز می‌کند.

## مفاهیم استخراج‌شده

### کلی

- منطق بولی
  - منطقی
- عبارت
  - توابع در Rust به‌طور ضمنی عبارت بازمی‌گردانند
- حساب
  - باقی‌مانده

### نوع

- عدد صحیح بدون علامت - `u64`
- مقدار منطقی - `bool`

## مثال تمرین ۱

راه‌حل [«desi-belokonska»](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## مثال تمرین ۲

[متعارف](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
