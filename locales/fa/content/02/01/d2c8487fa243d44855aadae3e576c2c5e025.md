# دستورالعمل‌ها

در **Chrono Realms**، Time Keepers اغلب نه فقط با درخت‌های خطوط زمانی، بلکه با **Chrono Chain**ها هم سر و کار دارند، یعنی دنباله‌هایی از **TimeNode**های به‌هم‌پیوسته که هر کدام نماینده‌ی لحظه‌ای مشخص در زمان‌اند.
یک **Chrono Chain** مسیری مستقیم از لحظه‌های پشت‌سرهم است که در آن هر **TimeNode** به گره بعدی وصل می‌شود.
این **Chrono Chain**ها وقتی در حال سفر از میان مجموعه‌ای از رویدادهای مشخص هستید مفیدند، چون به Time Keepers اجازه می‌دهند یک خط زمانی واحد را دنبال کنند.

اما برای کار با این **Chrono Chain**های بالقوه بلند، Time Keepers از **اشاره‌گرهای هوشمند (`Box<T>`)** استفاده می‌کنند تا این فهرست‌های لحظه‌ها را به شکلی ایمن مدیریت و پیمایش کنند، بدون آنکه حافظه بی‌دلیل تکرار شود یا دچار سرریز شود.
هر **TimeNode** ارجاعی به گره بعدی در خود نگه می‌دارد و به این ترتیب ساختاری بازگشتی می‌سازد.

وظیفه‌ی شما به عنوان کارآموز این است که یک **Chrono Chain** را به صورت ساختاری فهرست‌مانند و بازگشتی، با استفاده از اشاره‌گرهای هوشمند پیاده‌سازی کنید.

در این تمرین، این کارها را انجام می‌دهید:

1. یک `enum` بازگشتی به نام `ChronoChain` بسازید که نماینده‌ی فهرستی از لحظه‌ها باشد.
2. از اشاره‌گر هوشمند `Box<T>` برای نگهداری گره‌های بازگشتی استفاده کنید.
3. تابعی پیاده‌سازی کنید که یک `ChronoChain` را از آرایه‌ای از مقادیر `u32` بسازد.
4. تابعی پیاده‌سازی کنید که `ChronoChain` را پیمایش کند و مقادیر ذخیره‌شده در فهرست را جمع بزند.

## 1. تعریف `enum` بازگشتی `ChronoChain`

یک `enum` بازگشتی به نام `ChronoChain` با دو گونه بسازید:

- `End`: پایان فهرست را نشان می‌دهد.
- `Link`: یک مقدار `u32` و یک ارجاع جعبه‌ای به گره بعدی زنجیره را در خود نگه می‌دارد.

## 2. نوشتن تابعی برای ساخت `ChronoChain`

تابعی به نام `ChronoChain::build` بنویسید که آرایه‌ای از مقادیر `u32` را می‌گیرد و یک `ChronoChain` برمی‌گرداند و مقادیر را به ترتیب، با اشاره‌گرهای هوشمند، به هم پیوند می‌دهد.

## 3. پیاده‌سازی تابع `sum`

تابعی به نام `ChronoChain::sum` بنویسید که `ChronoChain` را به صورت بازگشتی پیمایش کند و مقادیر همه‌ی گره‌ها را جمع بزند.

## نمونه‌ی استفاده

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
