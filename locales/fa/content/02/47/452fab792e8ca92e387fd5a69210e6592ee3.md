# مقدمه

«آرایه» و «لیست» شامل یک مجموعهی مرتب از «اسکالر»ها هستند.
جز با استفاده از «ارجاع»ها (که در یک مفهوم جداگانه پوشش داده خواهد شد)، این یعنی آرایه و لیست همیشه تخت هستند؛ یعنی نمیتوانند آرایه یا لیست دیگری در خود داشته باشند.

در بیشتر موارد، لیستها داخل پرانتز `()` قرار میگیرند و عناصرشان با کاما `,` از هم جدا میشوند.

یک متغیر آرایه معمولاً با انتساب یک لیست به آن مقداردهی میشود، مثلاً `my @names = ('Alice', 'Bob', 'Charlie');`

به عناصر یک آرایه یا لیست میتوان با مشخص کردن «اندیس»ها از طریق یک «زیرنویس» دسترسی داشت، مثلاً `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

اندیسها در Perl از `0` شروع میشوند.
اندیسهای منفی از انتهای آرایه یا لیست شمارش میشوند، مثلاً `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## توابع

توابع زیادی برای کار روی آرایهها و لیستها پیادهسازی شدهاند؛ برخی از مفیدترین آنها عبارتاند از [grep][grep] برای یک لیست جدید از عناصر فیلترشدهای که با یک شرط مطابقت دارند، [map][map] برای تبدیل عناصر به یک لیست جدید از مقادیر، و [sort][sort] برای یک لیست جدید از عناصر بازچینیشده.

توابعی برای دستکاری آرایهها شامل [push][push] برای افزودن عنصر به انتها، [pop][pop] برای حذف آخرین عنصر، [shift][shift] برای حذف اولین عنصر، [unshift][unshift] برای افزودن عنصر به ابتدا، و [splice][splice] برای تغییرات پیچیدهتر است.

پیمایش آرایهها و لیستها با دستور [for(each)][perlsynforeach] نیز از مواردی است که اغلب با آن روبهرو خواهید شد.

## تفاوت سیگیل

هنگام دسترسی به عناصر یک آرایه، «سیگیل» دادهشده نتیجه را تعیین میکند.
زیرنویس `[]` در انتهای اسم متغیر است که به Perl میگوید در حال دسترسی به آرایهای با آن اسم هستید.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

هرچند این کار مجاز است، توصیه میشود برای خوانایی، انواع متغیر مختلف اسم یکسان نداشته باشند.

## آرایه در برابر لیست

آرایه و لیست شباهتهای زیادی دارند و در بسیاری از جاها میتوانند بهجای هم استفاده شوند، اما یکی نیستند.
لیست یک مجموعهی ثابت و تغییرناپذیر از اسکالرها است.
آرایه یک مجموعهی متغیر از اسکالرها است که محتوا و اندازهی خود آرایه قابل تغییر است.

آنها در برخی «بافت»ها رفتار متفاوتی دارند.
یک آرایه که در بافت اسکالر استفاده شود، اندازهی آرایه را به شما میدهد.
یک لیست که در بافت اسکالر استفاده شود، آخرین عنصر لیست را به شما میدهد و احتمالاً چند هشدار دربارهی استفادهی بقیهی محتوایش در بافت void میدهد.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
