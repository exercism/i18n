# مقدمه

با یک حلقه‌ی While می‌توانید کد را به‌طور مکرر اجرا کنید، تا زمانی که شرط مشخصی برقرار باشد.
این حلقه با کلیدواژه‌ی `while` نوشته می‌شود، سپس شرطی داخل پرانتز و بلوکی از کد می‌آید که _بدنه‌ی_ حلقه را در بر می‌گیرد و داخل آکولاد قرار دارد.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript یک حلقه‌ی do-while هم دارد.
در این نوع حلقه، شرط پس از اجرای بدنه‌ی حلقه بررسی می‌شود.
این ویژگی زمانی مفید است که شرط به نتیجه‌ی کد داخل بدنه بستگی داشته باشد.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

در داخل بدنه‌ی حلقه می‌توانید از کلیدواژه‌ی `break` استفاده کنید تا اجرای حلقه را کاملاً متوقف کنید.
در مقابل، کلیدواژه‌ی `continue` فقط اجرای تکرار جاری را متوقف می‌کند و به تکرار بعدی می‌رود.
با `continue` اغلب می‌توانید از قرار دادن بخش‌های بزرگی از بدنه‌ی حلقه داخل یک دستور شرطی پرهیز کنید.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
