# مقدمه

`case` (در [`combinators`][combinators]) بر اساس یک مقدار تصمیم‌گیری می‌کند. این کار را با پیمایش یک لیست انجمنی از بندها انجام می‌دهد و بدنه‌ی اولین بند منطبق را اجرا می‌کند.

```
case ( obj assoc -- )
```

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

هر بند به شکل `{ value [ body ] }` است. برابری بر پایه‌ی `=` سنجیده می‌شود. بندهای منطبق در حالی اجرا می‌شوند که مقدار ورودی *از قبل* مصرف شده است. یک `[ body ]` پایانی (بدون مقدار) حالت پیش‌فرض است. این بند با ورودی‌ای اجرا می‌شود که *هنوز* روی پشته است، بنابراین بدنه معمولاً با `drop` شروع می‌شود.

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
