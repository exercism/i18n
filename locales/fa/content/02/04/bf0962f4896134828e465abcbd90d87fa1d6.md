# مقدمه

Gleam توابع درجه‌یک دارد، یعنی توابع مقادیر عادی هستند که می‌توان آن‌ها را به متغیرها نسبت داد، به عنوان آرگومان به توابع دیگر داد و از توابع دیگر بازگرداند.

به یک تابع اسم‌دار که در یک ماژول تعریف شده است، می‌توان با اسمش ارجاع داد.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam توابع ناشناس هم دارد که درون توابع دیگر تعریف می‌شوند.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

نوع یک تابع با نحوه‌ی نگارشی مشابه توابع ناشناس نوشته می‌شود. نوع تابعی که یک `Int` و یک `Float` می‌گیرد و یک `Int` برمی‌گرداند، به این شکل نوشته می‌شود:

```gleam
fn(Int, Float) -> Int
```

توابع ناشناس می‌توانند به متغیرهایی ارجاع دهند که هنگام تعریفشان در محدوده بودند و همین آن‌ها را به _«بستار»_ تبدیل می‌کند.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

نحوه‌ی نگارش _«گرفتن تابع»_ میان‌بری راحت برای ساختن توابع ناشناسی فراهم می‌کند که یک آرگومان را به یک تابع پاس می‌دهند. این دو عبارت معادل هستند:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
