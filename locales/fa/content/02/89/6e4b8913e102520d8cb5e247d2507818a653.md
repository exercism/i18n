# راهنمایی‌ها

## 1. ساختن برداری از همه‌ی واگن‌ها

- یک حلقه‌ی کلاسیک for/while همراه با `push!` روی یک `Vector` کار می‌کند.
- در غیر این صورت، تابع [`collect()`][collect] می‌تواند مختصرتر باشد.
- از طرف دیگر، splatting درون سازنده‌ی بردار هم کار می‌کند:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. اصلاح بردار واگن‌ها

- جدا کردن واگن‌های جلویی و لوکوموتیو از بقیه مفید است، تا بتوان آن‌ها را به ترتیب درست دوباره سر هم کرد.
- انتساب چندگانه همراه با splatting می‌تواند به شما کمک کند (به مقدمه نگاه کنید).

## 3. افزودن ایستگاه‌های جامانده

- یادتان باشد، این تابع ورودی را تغییر نمی‌دهد! یک `Dict` جدید بسازید.
- فقط اسم ایستگاه لازم است، نه شماره‌ی ایستگاه، پس هر جفت باید تفکیک شود.
- راه‌های مختلفی برای سر هم کردن بردار اسم‌ها وجود دارد:
  -  حلقه‌ی For/While همراه با `push!()` روی یک `Vector`.
  -  [درک آرایه‌ای][comprehensions]
  -  [`map()`][map] یک تابع روی بردار.
  -  [پخش][broadcasting] یک تابع [بی‌نام][anonymous] هم ممکن است:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. گسترش اطلاعات مسیر

- پس از slurping، `more_route_information` یک مجموعه‌ی `Pairs()` است.
- تابع [`merge()`][merge] دو یا چند `Dict` را با هم ترکیب می‌کند، اما یک مجموعه‌ی `Pairs()` را هم می‌پذیرد.
  تبدیل صریح مجموعه‌ی `Pairs()` به یک `Dict` ممکن است اما لازم نیست.
