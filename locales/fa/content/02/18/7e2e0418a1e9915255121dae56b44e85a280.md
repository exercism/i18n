# راهنمایی‌ها

## کلی

- مستندات [MapSet][mapset] را بخوانید
- مستندات [Enum][enum] هم می‌تواند مفید باشد

## 1. شروع یک مجموعه

- [این مناسب‌ترین تابع `MapSet`][new] برای انجام این کار است

## 2. مجموعه را بزرگ کنید

- برای افزودن کارت‌ها به مجموعه‌تان از [این تابع `MapSet`][put] استفاده کنید
- برای بررسی اینکه کارت مشخصی در مجموعه‌تان دارید از [آن تابع `MapSet`][member] استفاده کنید

## 3. شروع تبادل

- برای بررسی اینکه می‌توانید کارتی را تبادل کنید از [این تابع `MapSet`][member] استفاده کنید
- برای به‌روزرسانی مجموعه‌تان از [این تابع `MapSet`][delete] و [آن یکی][put] استفاده کنید

## 4. از هر کدام فقط یکی

- یک `MapSet` این ویژگی را دارد که فقط مقادیر یکتا را نگه می‌دارد
- برای ساختن یک مجموعه از [این تابع `MapSet`][new] و برای تبدیل دوباره‌ی آن به یک فهرست از [آن یکی][to_list] استفاده کنید
- `MapSet`ها مفهومی از ترتیب ندارند؛ برای مرتب‌سازی کارت‌ها باید از [این تابع `Enum`][sort] استفاده کنید، حتی اگر آزمون‌ها بدون آن هم موفق شوند

## 5. کارت‌هایی که آنان ندارند

- برای بررسی تفاوت‌های میان مجموعه‌ها از [این تابع `MapSet`][difference] استفاده کنید
- برای به‌دست آوردن تعداد کارت‌های یک مجموعه از [آن تابع `MapSet`][size] استفاده کنید

## 6. کارت‌هایی که همه‌ی آنان دارند

- [این تابع `Enum`][reduce] برای مرور همه‌ی مجموعه‌ها مفید خواهد بود
- برای تشخیص فهرست‌های خالی از ناخالی، از تطبیق الگو روی فهرست استفاده کنید
- [این تابع `MapSet`][intersection] به شما کمک می‌کند کارت‌های مشترک را نگه دارید
- [این تابع `MapSet`][to_list] می‌تواند یک فهرست بسازد
- `MapSet`ها مفهومی از ترتیب ندارند؛ برای مرتب‌سازی کارت‌ها باید از [این تابع `Enum`][sort] استفاده کنید، حتی اگر آزمون‌ها بدون آن هم موفق شوند

## 7. همه‌ی کارت‌ها

- [این تابع `Enum`][reduce] برای مرور همه‌ی مجموعه‌ها مفید خواهد بود
- از [این تابع `MapSet`][new_empty] به عنوان انباشتگر استفاده کنید
- [این تابع `MapSet`][union] به شما کمک می‌کند همه‌ی کارت‌ها را انباشته کنید
- [این تابع `MapSet`][size] تعداد کارت‌هایی را که دارید می‌شمارد

## 8. درخشان‌ها برای برد

- برای جدا کردن مجموعه‌تان از [این تابع `MapSet`][split_with] استفاده کنید
- برای تشخیص کارت‌های درخشان از [این تابع `String`][starts_with] استفاده کنید
- [این تابع `MapSet`][to_list] می‌تواند یک فهرست بسازد
- `MapSet`ها مفهومی از ترتیب ندارند؛ برای مرتب‌سازی کارت‌ها باید از [این تابع `Enum`][sort] استفاده کنید، حتی اگر آزمون‌ها بدون آن هم موفق شوند
