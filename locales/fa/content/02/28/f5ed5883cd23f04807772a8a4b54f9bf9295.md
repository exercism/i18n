# دسته‌های پرداخت در پایگاه داده

## بیان مسئله

شما باید یک دسته از داده‌های پرداخت را در جدول `Payment` درج کنید. وظیفه‌ی شما این است که داده‌های پرداخت را از فایل JSON ورودی داده‌شده بخوانید و با استفاده از عملیات `batchExecute` در JDBC Client، این داده‌ها را در جدول `Payment` درج کنید. فایل ورودی نمونه `payments.json` است.

محتوای فایل JSON ورودی بر اساس شِمای JSON زیر است.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

شما باید بدون اجرای پرس‌وجوی دیگری روی پایگاه داده، شناسه‌های پرداختی را که به‌طور خودکار برای داده‌های پرداخت درج‌شده در دسته تولید می‌شوند، به‌عنوان خروجی برگردانید.

می‌توانید فرض کنید که `employee_id`های داده‌شده در فایل `payments.json` معتبرند و از قبل در جدول `Employee` وجود دارند.

## جزئیات پایگاه داده

برای این مسئله از پایگاه داده‌ی H2 ارائه‌شده استفاده کنید.

> فایل پایگاه داده‌ی نمونه `gofigure.mv.db` است و این پایگاه داده با اسم `gofigure` شناخته می‌شود. این فایل در پوشه‌ی `db` قرار دارد.

جدول‌های زیر از قبل در پایگاه داده‌ی نمونه‌ی H2 همراه با مقداری داده‌ی نمونه وجود دارند. اسم ستون‌ها و نوع داده‌ها در ادامه آمده است.

**اسم جدول**: `Employee`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحیح، کلید اصلی خودافزا       |
| `name`            | رشته        |
| `city`            | رشته        |
| `department`      | رشته        |
| `age`             | عدد صحیح        |

**اسم جدول**: `Payment`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحیح، کلید اصلی خودافزا       |
| `date`            | تاریخ        |
| `amount`          | عدد اعشاری        |
| `employee_id`     | عدد صحیح        |
| `reason`          | رشته        |

* فایل پایگاه داده `gofigure.mv.db` است. از نشانی JDBC به‌صورت `jdbc:h2:file:/path/to/db/file` استفاده کنید.
* نام کاربری: `root`
* رمز عبور: `root`

## محدودیت‌ها

* برای اعتبارسنجی پرس‌وجوها و نمونه‌ی Ballerina از فایل پایگاه داده‌ی H2 که در پوشه‌ی `db` داده شده است استفاده کنید.
* برای افزودن درایور پایگاه داده‌ی H2 به‌عنوان یک وابستگی پلتفرم در فایل Ballerina.toml، از روش پارامترهای وابستگی maven استفاده کنید.
* باید شناسه‌های پرداخت خودکارتولیدشده را بدون اجرای پرس‌وجوی دیگری روی پایگاه داده پیدا کنید.

## محیط آزمون

* می‌توانید آزمون‌ها را با `bal test` اجرا کنید؛ آزمون‌ها روی پایگاه داده‌ی نمونه‌ی داده‌شده اجرا می‌شوند.

## مثال‌ها

### مثال ۱

**ورودی:** dbFilePath: `"/path/to/file/gofigure"`، paymentFilePath: `"/path/to/file/payments.json"`

داده‌های نمونه‌ی فایل `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**خروجی:** `[1,2,3]`

## راهنمایی‌ها

* برای کار با پایگاه داده از ماژول [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) استفاده کنید
* برای دیدن مراحل افزودن درایور JDBC به‌عنوان یک وابستگی، به بخش [پیش‌نیاز](https://lib.ballerina.io/ballerinax/java.jdbc/latest) مراجعه کنید
* برای خواندن فایل ورودی JSON از [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) استفاده کنید
* مقادیر JSON را به نوع‌های مخصوص برنامه تبدیل کنید تا به‌صورت ایمن از نظر نوع با داده‌ها کار کنید. به مثال [تبدیل به نوع تعریف‌شده توسط کاربر](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) مراجعه کنید
* برای کار با پایگاه داده از [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) و متد ریموت [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) استفاده کنید
* به مثال [اجرای دسته‌ای](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) مراجعه کنید
