# درباره

یک [دستور `switch`][switch] به شما امکان می‌دهد یک مقدار را با چند مقدار ممکنِ منطبق مقایسه کنید. با این دستور می‌توانید کدی مختصرتر از حالتی بنویسید که از چند دستور `else-if` استفاده می‌کنید. دستور `switch` با «کلیدواژه»ی `switch` شروع می‌شود و پس از آن مقداری می‌آید که باید مقایسه شود. سپس می‌توانید حالت‌ها را با کلیدواژه‌ی `case` تعریف کنید و بعد از آن مقداری می‌آید که باید با آن مقایسه شود. کلیدواژه‌ی `default` برای تعریف حالت پیش‌فرض به کار می‌رود، یعنی زمانی که هیچ‌یک از حالت‌ها منطبق نمی‌شوند. دستورهای `switch` مانند دستورهای `else-if` فقط بلوک کدی را اجرا می‌کنند که به نخستین حالت منطبق مربوط است.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

مثال زیر را در نظر بگیرید:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

در عوض، می‌توان آن را این‌گونه نوشت:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## اتصال مقادیر به اسم و دستورهای `where`

مقادیری که در دستورهای `switch` منطبق می‌شوند را می‌توان به اسم‌هایی اتصال داد که در بدنه‌ی حالت قابل استفاده‌اند. همچنین می‌توان از آن‌ها در بندهای `where` استفاده کرد؛ این بندها عبارت‌های «منطقی» افزوده‌ای هستند که برای منطبق شدن حالت باید به `true` ارزیابی شوند.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
