# مقدمه

هرچند تغییردهنده‌ی `readonly` مانع بازنویسی مقدار یا ارجاع موجود در یک فیلد می‌شود، اما هیچ محافظتی از اعضای یک نوع ارجاعی نمی‌کند.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

برای تضمین محافظت از همه‌ی اعضای یک نوع ارجاعی، می‌توان فیلدها را `readonly` کرد و ویژگی‌های خودکار را بدون دسترسی `set` تعریف کرد.

کتابخانه‌ی کلاس پایه (BCL) برخی از نسخه‌های فقط‌خواندنی مجموعه‌ها را برای مواقعی ارائه می‌دهد که نیاز است از به‌روزرسانی اعضای مجموعه‌ها جلوگیری شود. این نسخه‌ها در قالب پوشش‌دهنده‌ها ارائه می‌شوند:

- `ReadOnlyDictionary<T>` یک `Dictionary<T>` را به‌صورت فقط‌خواندنی ارائه می‌دهد.
- `ReadOnlyCollection<T>` یک `List<T>` را به‌صورت فقط‌خواندنی ارائه می‌دهد.
