# مقدمه

در F#، اختصاص دادن یک مقدار به یک اسم «اتصال» نامیده می‌شود. اتصال‌ها تغییرناپذیرند و همین آن‌ها را شبیه ثابت‌های زبان‌های دیگر می‌کند. چون F# زبانی با نوع ایستا است، هر اتصال در زمان کامپایل یک نوع دارد.

اتصال‌ها با کلیدواژه‌ی `let` تعریف می‌شوند. مشخص کردن نوع یک اتصال برای بیشتر اتصال‌ها اختیاری است، چون «استنتاج نوع» در F# معمولاً می‌تواند نوع را بر پایه‌ی مقدارشان استنتاج کند. یک اتصال چنین شکلی دارد:

```fsharp
// Automatically inferred type
let fingers = 10
```

تابع‌ها هم اتصال‌هایی معمولی‌اند، اما با یک یا چند پارامتر. تابع به‌طور خودکار آخرین عبارت خود را برمی‌گرداند. استنتاج نوع برای بیشتر تابع‌ها هم کار می‌کند: با تحلیل اینکه تابع با چه مقدارهایی فراخوانی می‌شود و چه مقداری را برمی‌گرداند.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

فراخوانی یک تابع با مشخص کردن اسم آن و فرستادن آرگومان برای هر یک از پارامترهای آن انجام می‌شود.

```fsharp
let five = add 2 3
```

اگر نوع یک اتصال قابل استنتاج نباشد، کامپایلر خطا گزارش می‌دهد. برای رفع این مشکل، یک حاشیه‌نویسی نوع صریح به اتصال اضافه کنید.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

در F#، اتصال‌ها را فقط پس از تعریف شدنشان می‌توان به کار برد. استفاده از یک اتصال پیش از تعریف شدنش به خطای کامپایل منجر می‌شود.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# از فضای سفید معنادار برای تعریف دامنه استفاده می‌کند. یعنی دامنه با تورفتگی کد به کمک فاصله‌ها، نسبت به خطی که اتصال را تعریف می‌کند، مشخص می‌شود. قرارداد پیش‌فرض این است که برای تورفتگی از چهار فاصله استفاده شود:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

اتصال‌های F# (که تابع‌ها را هم در بر می‌گیرند) معمولاً در ماژول‌ها سازمان‌دهی می‌شوند. ماژول قابلیت‌های مرتبط را گروه‌بندی می‌کند و با کلیدواژه‌ی `module` تعریف می‌شود. تعریف ماژول باید پیش از اتصال‌هایش بیاید:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# از دو نوع کامنت پشتیبانی می‌کند. کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `(*` و `*)` قرار می‌گیرند.
