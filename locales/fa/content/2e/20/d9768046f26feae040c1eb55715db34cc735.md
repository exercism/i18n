# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است [یک «استثنا» ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** بگنجانید تا نشان دهید منبع خطا چیست. این کار code شما را خواناتر می‌کند و به debug کمک قابل توجهی می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا از یک نوع مشخص است، می‌توانید یکی از [انواع خطای داخلی](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما باز هم باید پیامی معنادار بگنجانید.

این تمرین به‌طور خاص می‌خواهد که وقتی تابع `board()` ورودی نادرست دریافت می‌کند، با [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) یک `ValueError` را «پرتاب» کنید. tests فقط وقتی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بگنجانید.

برای ایجاد یک `ValueError` همراه با پیام، پیام را به‌عنوان آرگومان نوع `exception` بنویسید:

```python
# when the board receives malformed input
raise ValueError("The board is invalid with current input.")
```
