# workflow configlet

configlet از [ابزار configlet](/docs/building/configlet) استفاده می‌کند تا بررسی کند که فایل‌های (پیکربندی) یک مسیر به‌درستی ساختاربندی شده‌اند یا نه، هم از نظر نحوه‌ی نگارش و هم از نظر معنا.
این کار را با اجرای [`configlet lint`](/docs/building/configlet/lint) انجام می‌دهد.

## فعال کردن بررسی قالب‌بندی فایل‌ها

مسیر می‌تواند از [`configlet fmt`](/docs/building/configlet/format) برای قالب‌بندی فایل‌های پیکربندی گوناگون خود استفاده کند.
از همین دستور می‌توان برای بررسی این هم استفاده کرد که همه‌ی فایل‌های پیکربندی درست قالب‌بندی شده‌اند یا نه.

workflow `configlet` می‌تواند بررسی کند که فایل‌های پیکربندی درست قالب‌بندی شده‌اند یا نه، اما این کار اختیاری است و به‌طور پیش‌فرض غیرفعال است.
برای فعال کردن بررسی قالب‌بندی فایل‌های پیکربندی، این مراحل را دنبال کنید:

1. یک فایل `.github/org-wide-files-config.toml` با محتوای زیر بسازید

```toml
[configlet]
fmt = true
```

2. پس از ادغام این فایل در `main`، یک PR به‌طور خودکار باز می‌شود که workflow `configlet.yml` را به شکل زیر تغییر می‌دهد:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. به محض ادغام این PR، workflow `configlet` قالب‌بندی فایل‌های پیکربندی مسیر را هم بررسی می‌کند.

## منبع

این workflow در فایل `.github/workflows/configlet.yml` تعریف شده است.
