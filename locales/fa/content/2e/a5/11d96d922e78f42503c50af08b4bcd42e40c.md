# دستورالعمل

در این تمرین، کدی می‌نویسید که فهرستی از زبان‌های برنامه‌نویسی را که می‌خواهید در Exercism یاد بگیرید پیگیری می‌کند.

شش کار پیش رو دارید که همگی به کار کردن با فهرست‌ها مربوط می‌شوند.

## 1. یک فهرست جدید بسازید

برای پیگیری زبان‌هایی که می‌خواهید یاد بگیرید، باید یک فهرست جدید بسازید. تابع `new_list` را تعریف کنید که یک فهرست جدید و خالی برمی‌گرداند.

```gleam
new_list()
// -> []
```

## 2. یک فهرست موجود را تعریف کنید

در حال حاضر، تکه‌کاغذی دارید که زبان‌هایی را که می‌خواهید یاد بگیرید روی آن نوشته‌اید: Gleam، Go و TypeScript. تابع `existing_list` را تعریف کنید تا این فهرست را برگرداند.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. یک زبان جدید به فهرست اضافه کنید

همان‌طور که Exercism را کاوش می‌کنید و زبان‌های جالب‌تری پیدا می‌کنید، می‌خواهید آن‌ها را به فهرستتان اضافه کنید. تابع `add_language` را پیاده‌سازی کنید تا یک زبان جدید را به ابتدای فهرستتان اضافه کند.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. زبان‌های فهرست را بشمارید

شمردن زبان‌ها یکی‌یکی دردسرساز است. تابع `count_languages` را پیاده‌سازی کنید تا تعداد زبان‌های فهرستتان را بشمارد.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. فهرست را برعکس کنید

در نقطه‌ای متوجه می‌شوید که فهرستتان در واقع برعکس مرتب شده است! تابع `reverse_list` را پیاده‌سازی کنید تا فهرستتان را برعکس کند.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. بررسی کنید که فهرست هیجان‌انگیز است یا نه

هرچند همه‌ی زبان‌ها را دوست دارید، Gleam جایگاه ویژه‌ای در قلب شما دارد. بنابراین، وقتی شرایط زیر برقرار باشد، از یک فهرست زبان‌ها واقعاً هیجان‌زده می‌شوید:

- اولین عنصر فهرست Gleam باشد.
- دومین عنصر فهرست Gleam باشد و فهرست دو یا سه زبان داشته باشد.

تابع `exciting_list` را پیاده‌سازی کنید تا بررسی کند که آیا فهرست زبان‌ها هیجان‌انگیز است:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
