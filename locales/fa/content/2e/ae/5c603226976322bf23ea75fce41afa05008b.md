# پیوست دستورالعمل‌ها

## راهنمایی‌ها

شما باید توابع `decode` و `encode` را پیاده‌سازی کنید که یک `String` را با استفاده از رمز آتباش رمزگشایی و رمزگذاری می‌کنند.
اگر درباره‌ی نوع‌ها مطمئن نیستید، می‌توانید از امضایی که در اختیارتان قرار گرفته استفاده کنید، اما نگذارید خلاقیتتان را محدود کند.

این تمرین با داده‌های متنی کار می‌کند. به دلایل تاریخی، نوع `String` در Haskell با `[Char]`، یعنی لیستی از کاراکترها، هم‌معناست. برای
پردازش کارآمدتر داده‌های متنی، می‌توان از نوع `Text` استفاده کرد.

به‌عنوان یک بخش اضافی اختیاری در این تمرین، می‌توانید

- درباره‌ی [نوع‌های رشته](https://haskell-lang.org/tutorial/string-types) در
  Haskell بخوانید.
- عبارت `- text` را به لیست وابستگی‌هایتان در package.yaml اضافه کنید.
- `Data.Text` را [به روش زیر](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) `import` کنید:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- از نوع `Text` استفاده کنید، مثلاً `decode :: Text -> Text`، و به
  ترکیب‌کننده‌های `Data.Text` مثلاً به‌صورت `T.pack` ارجاع دهید.
- مستندات
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) را ببینید.
- همه‌ی موارد `String` را در Atbash.hs با `Text` جایگزین کنید، یعنی:

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

این بخش کاملاً اختیاری است.
