# مقدمه

## توضیح

علاوه بر انواع داده‌ی اولیه مانند `number` و `string`، نوع داده‌ی مهم دیگری هم در JavaScript وجود دارد که به آن `object` می‌گویند.
شیءها مجموعه‌هایی از جفت‌های کلید-مقدار هستند.
به همین دلیل می‌توان از آن‌ها همانند «نقشه» یا «دیکشنری» در زبان‌های دیگر استفاده کرد.

در زبان‌های دیگر، اغلب لازم است همه‌ی مقدارهای یک نقشه نوع داده‌ی یکسانی داشته باشند.
در JavaScript فقط نوع کلید محدود است: باید یک رشته باشد.
مقدارهای درون یک شیء می‌توانند نوع‌های متفاوتی داشته باشند.
می‌توانند نوع‌های اولیه‌ای مانند عدد باشند، اما همچنین می‌توانند آرایه، شیءهای دیگر یا حتی تابع باشند.
همین موضوع شیءها را بسیار انعطاف‌پذیر می‌کند، تا جایی که در JavaScript از ارکان اصلی [برنامه‌نویسی شیءگرا][oop] (OOP) هم به شمار می‌روند.

در ادامه بر شیءها به‌عنوان مجموعه یا نقشه تمرکز می‌کنیم. کاربردهای دیگر شیءها در مفاهیم دیگر بررسی می‌شود؛ برای نمونه [کلاس‌ها][concept-classes] را ببینید.

## ساختن یک شیء

یک شیء را با آکولاد می‌سازید.
همچنین می‌توانید چند ورودی را مستقیم داخل آن بگنجانید.
برای این کار، ابتدا کلید و سپس یک دونقطه و بعد مقدار را بنویسید.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

کامای پایانی پس از آخرین ورودی در JavaScript اختیاری است.

ممکن است برایتان سؤال پیش بیاید که چرا کلیدها داخل گیومه قرار نگرفته‌اند، هرچند قرار است رشته باشند.
این یک شکل کوتاه‌نویسی است.
اگر کلید از قواعد نام‌گذاری [شناسه][mdn-identifier] در JavaScript پیروی کند، می‌توانید گیومه‌ها را حذف کنید.
برای کلیدهایی که در نامشان کاراکترهای خاص دارند، باید از نگارش معمول رشته استفاده کنید.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## بازیابی یک مقدار

برای بازیابی مقدار یک کلید مشخص، دو روش وجود دارد: «نشانه‌گذاری نقطه‌ای» و «نشانه‌گذاری براکتی».

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

استفاده از نشانه‌گذاری نقطه‌ای به‌عنوان شکل کوتاه، همان محدودیت حذف گیومه‌ها را دارد.
این روش فقط زمانی کار می‌کند که کلید از قواعد نام‌گذاری شناسه پیروی کند.
به بیان دیگر، اگر کلید شما واژه‌ی واحدی نیست که فقط از حروف تشکیل شده باشد، باید از نشانه‌گذاری براکتی استفاده کنید.

## افزودن یا تغییر یک مقدار

می‌توانید با عملگر انتساب `=` مقداری را اضافه یا تغییر دهید.
همان‌طور که پیش‌تر گفتیم، هم نشانه‌گذاری نقطه‌ای در دسترس است و هم نشانه‌گذاری براکتی.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## حذف یک ورودی

می‌توانید یک جفت کلید-مقدار را با کلیدواژه‌ی `delete` از یک شیء حذف کنید.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## بررسی وجود یک کلید

می‌توانید با متد `hasOwnProperty` بررسی کنید که آیا کلید خاصی در یک شیء وجود دارد یا نه.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## پیمایش یک شیء با حلقه

یک حلقه‌ی ویژه‌ی `for...in` وجود دارد که روی همه‌ی کلیدهای یک شیء پیمایش می‌کند.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

برای جلوگیری از خطاهای ظریف، همیشه باید فرض کنید که حلقه‌ی `for...in` کلیدها را با ترتیبی دلخواه پیمایش می‌کند.
همچنین توجه داشته باشید که `for...in` در پیمایش خود [کلیدهای ارث‌بری‌شده][concept-inheritance] را هم شامل می‌شود.
