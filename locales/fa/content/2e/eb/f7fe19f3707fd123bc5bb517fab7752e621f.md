# راهنما

## عمومی

- برای کار با کلاس `DateTime`، باید فضای نام `System` _باز_ شود.

## 1. تجزیه‌ی تاریخ قرار ملاقات

- کلاس `DateTime` متدی برای [تجزیه][parsing] یک `string` به `DateTime` دارد.

## 2. بررسی این‌که قرار ملاقات قبلاً گذشته است یا نه

- می‌توان اشیای `DateTime` را با استفاده از [عملگرهای مقایسه][operators] پیش‌فرض مقایسه کرد.
- یک [ویژگی][properties] برای به دست آوردن تاریخ و زمان کنونی وجود دارد.

## 3. بررسی این‌که قرار ملاقات بعدازظهر است یا نه

- برای دسترسی به بخش زمان یک شیء `DateTime` می‌توان از یکی از [ویژگی‌های][properties] آن استفاده کرد.

## 4. توصیف زمان و تاریخ قرار ملاقات

- تست‌ها طوری اجرا می‌شوند که گویی روی ماشینی در ایالات متحده اجرا می‌شوند؛ یعنی هنگام تبدیل یک `DateTime` به `string`، تاریخ و زمان در قالب آمریکایی برگردانده می‌شود.
- یک [متد توکار][to-string] برای تبدیل یک نمونه‌ی `DateTime` به `string` وجود دارد. اگر از `sprintf` استفاده می‌کنید، به جای استفاده از جای‌نگهدار رشته‌ای `%s`، [جای‌نگهدار دیگری][object-placeholder] هست که به‌طور خودکار متد یادشده را فراخوانی می‌کند.

## 5. برگرداندن تاریخ سالگرد

- از یکی از [سازنده‌های][constructors] گوناگون `DateTime` برای ساختن یک نمونه‌ی جدید `DateTime` استفاده کنید.
- می‌توانید از یکی از [ویژگی‌های][properties] تاریخ و زمان کنونی برای به دست آوردن سال جاری استفاده کنید.
