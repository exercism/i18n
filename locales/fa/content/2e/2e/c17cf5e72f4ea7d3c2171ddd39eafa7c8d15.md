# Introduction

استفاده از «تطبیق الگو» در کدهای اصطلاحی و قاطعانه‌ی Elixir غالب است. شاید به خاطر داشته باشید که `=/2` را به‌جای عملگر انتساب، یک «عملگر تطبیق» توصیف می‌کنند. هنگام استفاده از عملگر تطبیق، اگر الگوی سمت چپ با سمت راست تطبیق پیدا کند، هر متغیری که در سمت چپ باشد مقید می‌شود و مقدار سمت راست بازگردانده می‌شود. اگر تطبیقی برقرار نشود، یک `MatchError` پرتاب می‌شود.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

به یاد داشته باشید که تطبیق از سمت راست به سمت چپ انجام می‌شود.

در مثال آخر، اگر به متغیری در تطبیق الگو نیاز نداشته باشیم، می‌توانیم با ارجاع به `_` آن را کنار بگذاریم.
هر متغیری که با `_` شروع شود، توسط زمان اجرا ردیابی نمی‌شود.

## تطبیق الگو در توابع نامدار

تطبیق الگو هنگام ساختن چندین «شاخه»ی تابع هم ابزار مفیدی است. می‌توان از تطبیق الگو روی آرگومان‌های تابع استفاده کرد که سپس تعیین می‌کند کدام شاخه‌ی تابع فراخوانی شود؛ از بالای فایل به پایین تا اولین تطبیق. متغیرها را می‌توان در سرِ تابع مقید کرد و در بدنه‌ی تابع به کار برد.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
