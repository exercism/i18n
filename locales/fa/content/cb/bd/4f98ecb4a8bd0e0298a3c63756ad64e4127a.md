# Luhn: استفاده از یک trait سفارشی

قبل از انجام این تمرین، بهتر است ابتدا تمرین اصلی Luhn و تمرین بعدی آن، یعنی «Luhn: استفاده از trait From»، را انجام دهید.

برای دریافت تمرین اصلی Luhn، این دستور را اجرا کنید:

```shell
exercism download --exercise=luhn --track=rust
```

برای دریافت تمرین «Luhn: استفاده از trait From»، این دستور را اجرا کنید:

```shell
exercism download --exercise=luhn-from --track=rust
```

در تمرین اصلی Luhn فقط رشته‌ها را اعتبارسنجی می‌کردید، اما الگوریتم Luhn را می‌توان روی اعداد صحیح هم اعمال کرد.

در «Luhn: استفاده از trait From» یک trait از نوع From پیاده‌سازی کردید که برای آن لازم بود یک struct به اسم Luhn هم بسازید.

به جای اینکه فقط برای انجام اعتبارسنجی یک struct بسازید، چه می‌شود اگر خود انواع اولیه (یعنی String، u8 و غیره) را اعتبارسنجی کنید؟

در این تمرین یک [trait](https://doc.rust-lang.org/book/ch10-02-traits.html) سفارشی می‌سازید و پیاده‌سازی می‌کنید که این اعتبارسنجی را انجام می‌دهد.
