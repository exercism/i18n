# سیاست کوکی

«کوکی‌ها» فایل‌های متنی کوچکی هستند که وب‌سایت‌هایی که از آن‌ها بازدید می‌کنید، روی رایانه‌تان قرار می‌دهند.

ما فقط از کوکی‌های شخص اول استفاده می‌کنیم، یعنی کوکی‌هایی که خودمان کنترلشان می‌کنیم.
ما فقط از کوکی‌های کارکردی که کاملاً ضروری هستند استفاده می‌کنیم؛ مثلاً برای مدیریت نشست ورود شما به وب‌سایت(های) ما.
ما از کوکی‌های شخص اول برای اهداف ردیابی بیرونی (مانند ابزارهای تحلیل) استفاده **نمی‌کنیم**.

ما از کوکی‌های شخص ثالث استفاده **نمی‌کنیم**.
ممکن است هنگام ورود شما از طریق یک شخص ثالث (مثلاً GitHub)، کوکی‌های دیگری تنظیم شود.
