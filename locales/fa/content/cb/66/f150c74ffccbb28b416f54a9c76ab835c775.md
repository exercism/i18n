# دستورالعمل‌ها

در این تمرین چند ثابت تعریف می‌کنید که در عملیات یک بانک به کار می‌روند.

پنج کار دارید:

## 1. نرخ بهره‌ی ثابت وام را نمایش دهید

ثابت عددی بدون نوع `FixedInterestRate` را ایجاد کنید تا مقدار ۵٪ (۵/۱۰۰) را نگه دارد، سپس تابع `GetFixedInterestRate` را پیاده‌سازی کنید تا آن را برگرداند:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. تعداد روزهای یک سال را نمایش دهید

ثابت `DaysPerYear` را با نوع `int` ایجاد کنید تا مقدار ۳۶۵ را نگه دارد، سپس تابع `GetDaysPerYear` را پیاده‌سازی کنید تا آن را برگرداند:

```go
GetDaysPerYear()
// => 365
```

## 3. ماه‌های سال را نمایش دهید

در یک «بلوک»، از شمارنده‌ی Go استفاده کنید تا دوازده ثابت عددی بدون نوع ایجاد کنید که مقادیر ۱ تا ۱۲ را برای ماه‌های سال نگه دارند. به آن‌ها اسم `Jan`، `Feb`، `Mar` و غیره بدهید، سپس تابع `GetMonth` را پیاده‌سازی کنید تا مقدار مربوط به یک ماه مشخص را برگرداند:

```go
GetMonth(Jan)
// => 1
```

## 4. شماره‌ی حساب را نمایش دهید

ثابت رشته‌ای بدون نوع `AccountNo` را ایجاد کنید تا مقدار XF348IJ را نگه دارد، سپس تابع `GetAccountNumber` را پیاده‌سازی کنید تا آن را برگرداند:

```go
GetAccountNumber()
// => "XF348IJ"
```
