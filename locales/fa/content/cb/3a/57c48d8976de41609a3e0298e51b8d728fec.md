# از بازگرداندن «مقدار منطقی» ثابت خودداری کنید

به‌جای اینکه پس از یک شرط، مقدارهای منطقی ثابت را برگردانید، می‌توانید مستقیماً خود شرط را برگردانید.

مثال:

```java
// instead of
if (someExpression) {
  return true;
} else {
  return false;
}

// ... return the expression directly
return someExpression;
```
