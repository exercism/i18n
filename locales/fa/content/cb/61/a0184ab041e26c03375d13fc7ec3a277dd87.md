# مقدمه

Python یک زبان برنامه‌نویسی [پویا و به‌شدت نوع‌دار][dynamic typing in python] است.
این زبان هم از [duck typing][duck typing] و هم از [gradual typing][gradual typing] استفاده می‌کند، آن هم از طریق [type hints][type hints].
Python تأکید زیادی بر خوانایی کد دارد و (_مشابه Haskell_) از [تورفتگی معنادار][significant indentation] برای مشخص کردن تعاریف تابع، متد و کلاس استفاده می‌کند.

Python توسط Guido van Rossum ساخته شد و نخستین بار در سال ۱۹۹۱ منتشر شد.

سبک‌های _برنامه‌نویسی_ امری، اعلانی (مثلاً تابعی) و شیءگرا همه پشتیبانی می‌شوند، اما در باطن **[همه‌چیز در Python یک شیء است][everythings an object]**.

در ادامه‌ی کار روی مفاهیم مسیر Python، بیشتر به این می‌پردازیم که همه‌ی این موارد چه معنایی دارند.

این نخستین مفهوم (`basics`) چهار ویژگی اصلی زبان Python را معرفی می‌کند:
1.  انتساب اسم (_متغیرها و ثابت‌ها_)،
2.  توابع (_کلیدواژه‌ی `def` و کلیدواژه‌ی `return`_)،
3.  توضیحات و
4.  داک‌استرینگ‌ها.

<br>

## انتساب اسم (متغیرها و ثابت‌ها)

برنامه‌نویسان می‌توانند با استفاده از عملگر انتساب `=`، [_اسم‌ها_][facts-and-myths-about-python-names] (که متغیر هم نامیده می‌شوند) را به هر نوع شیئی متصل کنند: `<name> = <value>`.
یک اسم می‌تواند در طول عمرش به مقادیر مختلف (انواع مختلف شیء) دوباره انتساب داده شود (یا دوباره متصل شود):


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### ثابت‌ها

ثابت‌ها اسم‌هایی هستند که قرار است در برنامه فقط یک بار انتساب داده شوند، هرچند Python مانع انتساب دوباره نمی‌شود.
استفاده از `SCREAMING_SNAKE_CASE` به هر کسی که کد را می‌خواند نشان می‌دهد که آن اسم **نباید** دوباره انتساب داده شود یا مقدارش تغییر کند.
ثابت‌ها باید در سطح [ماژول][module] (فایل) تعریف شوند و معمولاً برای همه‌ی توابع و کلاس‌های برنامه قابل مشاهده‌اند.



## توابع

کلیدواژه‌ی `def` یک [تعریف تابع][function definition] را آغاز می‌کند.
هر تابع می‌تواند صفر یا چند [پارامتر][parameters] صوری در پرانتزهای `()` داشته باشد، و پس از آن‌ها یک دونقطه‌ی `:` می‌آید.
دستورهای _بدنه‌ی_ تابع از خط بعد از `def` شروع می‌شوند و باید به‌صورت یک بلوک تورفته باشند.


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


توابع با کلیدواژه‌ی [`return`][return] یک مقدار یا شیء را _به‌صورت صریح_ برمی‌گردانند:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


توابعی که پس از `return` یک عبارت _صریح_ ندارند، به‌صورت _ضمنی_ شیء [`None`][none] را برمی‌گردانند.
جزئیات `None` در مفهومی بعدی پوشش داده خواهد شد.
برای هدف این تمرین و توضیح، `None` یک جانگهدار است که هیچ، یا null را نشان می‌دهد:


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

توابعی که `return` را حذف می‌کنند هم به‌صورت _ضمنی_ شیء [`None`][none] را برمی‌گردانند.
یعنی اگر در یک تابع از `return` استفاده نکنید، Python شیء `None` را به‌جای شما برمی‌گرداند.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## توضیحات

[توضیحات][comments] در Python با یک `#` شروع می‌شوند که بخشی از یک رشته نیست، و در پایان خط تمام می‌شوند.
برخلاف بسیاری از زبان‌های برنامه‌نویسی دیگر، Python از نشانه‌های توضیح چندخطی **پشتیبانی نمی‌کند**.
هر خط از یک بلوک توضیح باید با نویسه‌ی `#` شروع شود.


## داک‌استرینگ‌ها

نخستین دستور بدنه‌ی یک تابع می‌تواند به‌صورت اختیاری یک [_داک‌استرینگ_][docstring] باشد که هدف تابع یا شیء را به‌طور مختصر خلاصه می‌کند.
داک‌استرینگ‌ها را ابزارهای خودکار مستندسازی مانند [Sphinx][sphinx] می‌خوانند و با فراخوانی ویژگی ویژه‌ی `.__doc__` روی اسم تابع، متد یا کلاس برگردانده می‌شوند.
قواعد کلی داک‌استرینگ در [PEP257][pep257] آمده است، اما شکل دقیق آن بسته به پروژه و تیم متفاوت است.
داک‌استرینگ‌ها با سه گیومه‌ی دوگانه (""") اعلام می‌شوند و با همان سطح تورفتگی‌ای که بلوک کد دارد نوشته می‌شوند:
