# دستورالعمل‌ها

به عنوان یک علاقه‌مند به شطرنج، می‌خواهید نسخه‌ی خودتان از این بازی را بنویسید.
بله، شاید همین حالا هم پیاده‌سازی‌های زیادی از شطرنج به صورت آنلاین در دسترس باشد، ولی نسخه‌ی شما یگانه خواهد بود!

کار را با پیاده‌سازی یک صفحه‌ی شطرنج شروع می‌کنید.

بازی شطرنج روی صفحه‌ای به عرض هشت خانه و طول هشت خانه انجام می‌شود.
هر «خانه» با یک حرف و یک عدد مشخص می‌شود.

## 1. تعریف محدوده‌ی ردیف و ستون

بازی باید «ردیف»های صفحه را ذخیره کند.
ردیف‌ها همان سطرهای صفحه هستند و از ۱ تا ۸ شماره‌گذاری می‌شوند.

بازی همچنین باید «ستون»های صفحه را ذخیره کند.
ستون‌ها همان ستون‌های صفحه هستند و با حروف A تا H مشخص می‌شوند.

ثابت‌های `ranks` و `files` را تعریف کنید که به ترتیب محدوده‌ی ردیف‌ها و ستون‌ها را نگه می‌دارند.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. بررسی معتبر بودن یک خانه

بازی باید بررسی کند که آیا یک خانه معتبر است.
یک خانه زمانی معتبر است که ردیف و ستون آن در محدوده‌ی ردیف‌ها و ستون‌ها قرار داشته باشند.

متد `isValidSquare(rank:file:)` را تعریف کنید که آرگومان‌های `rank` و `file` را می‌گیرد؛ `rank` یک `Int` است که شماره‌ی ردیف را نگه می‌دارد و `file` یک `String` است که ستون را نگه می‌دارد.
این متد باید در صورتی که ردیف و ستون در محدوده‌ی ردیف‌ها و ستون‌ها باشند `true` و در غیر این صورت `false` را برگرداند.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. گرفتن سطر

بازی همه‌ی خانه‌های صفحه را در یک آرایه‌ی یک‌بعدی ذخیره می‌کند.
هر خانه به صورت رشته‌ای از ردیف و ستون ساخته می‌شود، مثلاً «1A»، «8B»، «4G» و غیره.
برای گرفتن سطر یک خانه، بازی باید اندیس اولین خانه‌ی آن سطر را محاسبه کند.

متد `getRow(rank:)` را تعریف کنید که آرگومان `rank` را می‌گیرد؛ `rank` یک `Int` است که شماره‌ی ردیف را نگه می‌دارد.
این متد باید آرایه‌ای از رشته‌ها را برگرداند که خانه‌های آن سطر را نشان می‌دهند.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
