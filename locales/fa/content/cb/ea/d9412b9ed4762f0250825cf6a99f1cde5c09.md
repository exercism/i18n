# قرارداد

آرگومان‌ها و نوع بازگشتی یک روتین می‌گویند چه *نوع* چیزی وارد می‌شود و چه چیزی بیرون می‌آید. اما نمی‌توانند بگویند که یک وزن باید مثبت باشد، یا اینکه یک چارچوب آزمون هرگز بیشتر از ظرفیت آزادی که دارد گزارش نمی‌دهد.

یک **قرارداد** همین موارد را در سرصفحه‌ی خودِ روتین بیان می‌کند، همان‌جا که هر کسی آن را بخواند می‌بیند.

## pre

`pre` بیان می‌کند که هنگام فراخوانی روتین چه چیزی باید برقرار باشد. این بخش بین نوع بازگشتی و `is` می‌آید.

```sather
   spare_capacity(load : INT) : INT
      pre load >= 0
   is
      return limit - load;
   end;
```

این یک خواسته از سوی **فراخوان** است: این روتین را با بار منفی فراخوانی نکنید.

## post

`post` بیان می‌کند که وقتی روتین پاسخ می‌دهد چه چیزی برقرار خواهد بود. درون آن، `result` مقداری است که بازگردانده می‌شود.

```sather
   percent_used(load : INT) : INT
      pre load >= 0
      post result >= 0
   is
      return load * 100 / limit;
   end;
```

این یک وعده به فراخوان است. روتینی که هر دو را داشته باشد یک معامله است: این را به من بدهید تا من هم آن را به شما بدهم.

چند شرط، مثل هر مقدار منطقی دیگری، با `and` به هم می‌پیوندند:

```sather
      pre load >= 0 and load <= limit
```

## قرارداد استثنا نیست

استثنایی که صادر می‌شود برای چیزی است که ممکن است رخ دهد. قراردادی که نقض شود به معنای یک **bug** است؛ کسی روتین را اشتباه فراخوانی کرده، یا روتین کاری را که گفته بود انجام نداده است.

پس قرارداد نقض‌شده چیزی صادر نمی‌کند که بتوان آن را گرفت. وقتی بررسی قرارداد روشن باشد، برنامه متوقف می‌شود و چاپ می‌کند که کدام روتین و کدام شرط بوده است. وقتی خاموش باشد، شرط حتی آزموده هم نمی‌شود و برنامه به هر بی‌معنایی که در پی می‌آید ادامه می‌دهد.

به همین دلیل قرارداد بیانیه‌ای درباره‌ی درستی است، نه راهی برای مدیریت ورودی نامعتبر. اگر ورودی نامعتبر انتظار می‌رود، آن را بررسی کنید و `raise` کنید. اگر ورودی نامعتبر به این معناست که فراخوان اشتباه کرده، این را با `pre` بگویید.

## روشن کردن بررسی

این Sather وقتی `-chk` به کامپایلر داده شود، قراردادها را بررسی می‌کند:

```
sacomp -chk mine.sa -main MAIN -o mine
```

بدون آن، `pre` و `post` فقط مستنداتی هستند که کامپایلر خوانده و پذیرفته که خوش‌ساخت‌اند، و بس. آزمون‌های این تمرین بدون `-chk` ساخته می‌شوند، بنابراین نمی‌توانند قرارداد نقض‌شده را به جای شما بگیرند؛ آن‌ها بررسی می‌کنند که روتین‌ها وقتی درست استفاده می‌شوند کار درست را انجام می‌دهند.
