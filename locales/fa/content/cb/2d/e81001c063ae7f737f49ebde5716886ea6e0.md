# پیوست دستورالعمل‌ها

## پیاده‌سازی عملیات فهرست خودتان

Rust سیستم «تکرارگر» غنی‌ای دارد و استفاده از آن‌ها برای حل این تمرین کار ساده‌ای است.
لطفاً تمرین را بدون استفاده از متدهای تکرارگر مانند `map()`، `flatten()`، `filter()`، `count()`، `fold()`، `chain()`، `rev()` و مشابه آن‌ها حل کنید.
متدهای `next()` و `next_back()` به حساب نمی‌آیند.

## پرهیز از تخصیص حافظه

این تمرین را می‌توان بدون تخصیص حافظه‌ی اضافی در راه‌حل هم حل کرد.
ببینید می‌توانید نوع تکرارگر خودتان را بسازید، به‌جای اینکه از یک مجموعه تکرارگر بسازید.
