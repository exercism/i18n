# دستورالعمل‌ها

در این تمرین با یک ماشین کنترلی بازی می‌کنید؛ ماشینی که بالاخره پول کافی برای خریدنش را پس‌انداز کرده‌اید.

ماشین‌ها با باتری کاملاً پر (۱۰۰٪) شروع می‌کنند. هر بار که ماشین را با کنترل از راه دور می‌رانید، ۲۰ متر را طی می‌کند و یک درصد از باتری را خالی می‌کند.

ماشین کنترلی یک نمایشگر LED شیک دارد که دو بخش از اطلاعات را نشان می‌دهد:

- کل مسافتی که طی کرده است، به این شکل نمایش داده می‌شود: `"Driven <METERS> meters"`.
- شارژ باقی‌مانده‌ی باتری، به این شکل نمایش داده می‌شود: `"Battery at <PERCENTAGE>%"`.

اگر باتری ۰٪ باشد، دیگر نمی‌توانید ماشین را برانید و نمایشگر باتری `"Battery empty"` را نشان می‌دهد.

شما شش کار دارید که هر کدام با نمونه‌ای از ماشین کنترلی کار می‌کند.

## 1. یک ماشین کنترلی کاملاً نو بخرید

متد (_static_) `JedliksToyCar.buy()` را پیاده‌سازی کنید تا یک نمونه‌ی کاملاً نو از ماشین کنترلی برگرداند:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. نمایش مسافت طی‌شده

متد `JedliksToyCar.distanceDisplay()` را پیاده‌سازی کنید تا مسافت را همان‌طور که روی نمایشگر LED نشان داده می‌شود برگرداند:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. نمایش درصد شارژ باتری

متد `JedliksToyCar.batteryDisplay()` را پیاده‌سازی کنید تا درصد شارژ باتری را همان‌طور که روی نمایشگر LED نشان داده می‌شود برگرداند:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. به‌روزرسانی تعداد مترهای طی‌شده هنگام رانندگی

متد `JedliksToyCar.drive()` را پیاده‌سازی کنید که تعداد مترهای طی‌شده را به‌روزرسانی می‌کند:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. به‌روزرسانی درصد شارژ باتری هنگام رانندگی

متد `JedliksToyCar.drive()` را به‌روزرسانی کنید تا درصد شارژ باتری را هم به‌روزرسانی کند:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. جلوگیری از رانندگی وقتی باتری خالی شده است

متد `JedliksToyCar.drive()` را به‌روزرسانی کنید تا وقتی باتری خالی است (۰٪)، نه مسافت طی‌شده را افزایش دهد و نه درصد شارژ باتری را کاهش دهد:

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
