# افزودنی دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | ورودی     | عدد صحیح | شماره‌ی خانه در بازه‌ی ۱ تا ۶۴ |
| `$v0`    | خروجی     | عدد صحیح | ۳۲ بیت پایینی خروجی            |
| `$v1`    | خروجی     | عدد صحیح | ۳۲ بیت بالایی خروجی            |
| `$t0-9`  | موقت      | هر       | برای ذخیره‌سازی موقت            |
