# عبارت تطبیق

یک عبارت تطبیق، یک مقدار و یک شرط را ارزیابی می‌کند تا عبارتی را برای ارزیابی بازگرداند. تقریباً مانند یک عملگر سه‌گانه، اگر شرط تطبیق پیدا نکند، عبارت بازگشتی ارزیابی نمی‌شود. برای تطبیق یک شرط، یک بررسی همانندی [برابری دقیق یا `===`] انجام می‌شود.

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

برای انجام یک بررسی برابری [`==`]، می‌توانید شرط را بازآرایی کنید:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

در یک عبارت تطبیق، اگر هیچ شرطی تطبیق پیدا نکند، یک `UnhandledMatchError` پرتاب می‌شود.
