# جانگهدار

## چگونه با bash حل کنیم

`bash` هیچ روش توکاری برای **تجزیه**ی رشته‌های تاریخ و زمان ندارد.
این تمرین می‌خواهد که سراغ یک ابزار بیرونی بروید.

* گزینه‌ی `-d` در دستور `date` گنو می‌تواند [انواع گسترده‌ای از قالب‌ها][gnu-date] را تجزیه کند.
* اگر کاربر Mac هستید، [دستور `date` در BSD][bsd-date] و گزینه‌ی `-f` آن را ببینید.
* Perl به‌طور گسترده در دسترس است و می‌توان از [ماژول `Time::Piece`][time-piece] آن برای تجزیه‌ی مهرهای زمانی استفاده کرد.

`bash` می‌تواند بدون هیچ ابزار بیرونی، تاریخ‌ها را **قالب‌بندی** کند.
اگر یک مقدار زمانی صحیح (ثانیه از مبدأ زمان) داشته باشید، [قالب‌بند `%()T` در `printf`][bash-printf] می‌تواند قالب‌بندی‌ای به سبک «strftime» اعمال کند.

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
[time-piece]: https://perldoc.pl/Time::Piece
