# دستورالعمل‌ها

آشنای شما، Erin، باید برای چندین رویداد هزاران «تراکت» چاپ کند و به کمک شما نیاز دارد! او از شما خواسته است تا چیدمان تراکتی را بسازید که شامل یک سرصفحه، یک تاریخ اختیاری و فهرستی از هنرمندان است، که هر کدام به یک _آیکون یونیکد_ مرتبط است. هدف این است که طرح تراکت جدید و جذاب خود را `print` کنید و پخش کنید، و برای موفقیت به تمام مهارت‌های قالب‌بندی رشته‌های پایتون نیاز خواهید داشت.

## 1. کلاس را با سرصفحه‌ی بزرگ‌شده بسازید

تابع `capitalize_header` باید یک اسم رویداد بگیرد و نسخه‌ی بزرگ‌شده‌ی اسم رویداد را برگرداند.

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. تاریخ را قالب‌بندی کنید

متد جدید `format_date` را بسازید که فهرستی شامل روز، ماه و سال می‌گیرد. تاریخ قالب‌بندی‌شده را با قالب `<month_name> <date>, <year>` نمایش می‌دهد.

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. کدپوینت‌های یونیکد را به‌صورت آیکون رندر کنید

وقتی متد `display_icons` فراخوانی می‌شود، فهرست کدپوینت‌های یونیکدی که پاس داده شده است باید رندر شود و به‌صورت یک `list` از _آیکون‌ها_ برگردانده شود.

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. تراکت نهایی را نمایش دهید

حالا از همه‌ی توابع بالا استفاده می‌کنید و آن‌ها را در تابع `print_leaflet` ترکیب می‌کنید.
این تابع باید یک `event_name`، یک فهرست از `icons`، یک فهرست از `authors` و یک فهرست `event_date` بگیرد.

پوستر باید از چیدمان زیر پیروی کند.

تراکت از یک چیدمان مشخص به شکل مستطیل پیروی می‌کند:

- سطر اول و آخر شامل ۲۰ ستاره است. `"*"`
- هر بخش با یک سطر خالی در بالا و پایینش از بخش‌های دیگر جدا می‌شود.
- یک سطر خالی فقط شامل یک ستاره در ابتدا و یکی در انتهاست.
- بخش اول سرصفحه‌ی تراکت است. این عنوان با حرف اول بزرگ نوشته می‌شود.
- بخش دوم تاریخ اختیاری است. اگر تاریخ پاس داده نشود، این بخش باید یک سطر خالی باشد.
- بخش سوم و آخر فهرست هنرمندان است و هر هنرمند به آیکون متناظرش مرتبط است.

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
