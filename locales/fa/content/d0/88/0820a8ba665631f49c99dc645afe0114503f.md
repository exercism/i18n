# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که به یک فریلنسر کمک می‌کند با یک مدیر پروژه ارتباط برقرار کند؛ کدتان چند ابزار کوچک در اختیارش می‌گذارد تا به‌سرعت نرخ‌های روزانه و ماهانه را، در صورت تمایل همراه با تخفیف مشخص، محاسبه کند.

ابتدا چند قاعده را بین فریلنسر و مدیر پروژه تعیین می‌کنیم:

نرخ روزانه ۸ برابر نرخ ساعتی است.
هر ماه ۲۲ روز قابل صورتحساب دارد.
فریلنسر پیشنهاد می‌دهد اگر مدیر پروژه ترجیح دهد صورت‌حساب را ماهانه دریافت کند، تخفیفی اعمال کند؛ این کار وقتی به کار می‌آید که مدیر پروژه بخواهد با بودجه‌ی مشخصی کار کند.

تخفیف‌ها در قالب اعداد اعشاری نشان‌دهنده‌ی درصد مدل می‌شوند، مثلاً 25.0 (۲۵٪).

## 1. محاسبه‌ی نرخ روزانه با داشتن نرخ ساعتی

تابعی پیاده‌سازی کنید که نرخ روزانه را با داشتن نرخ ساعتی محاسبه کند:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

نرخ روزانه‌ی برگردانده‌شده باید یک عدد اعشاری باشد.

## 2. محاسبه‌ی قیمت با تخفیف

تابعی پیاده‌سازی کنید که قیمت را پس از اعمال تخفیف محاسبه کند.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

مقدار برگردانده‌شده همیشه باید یک عدد اعشاری باشد و به هیچ شکلی رند نشود.

## 3. محاسبه‌ی نرخ ماهانه با داشتن نرخ ساعتی و تخفیف

تابعی پیاده‌سازی کنید که نرخ ماهانه را محاسبه کند و تخفیف را اعمال کند:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

نرخ ماهانه‌ی برگردانده‌شده باید به سمت بالا رند شود (سقف گرفته شود) و به نزدیک‌ترین عدد صحیح برسد.

## 4. محاسبه‌ی تعداد روزهای کاری با داشتن بودجه، نرخ ساعتی و تخفیف

تابعی پیاده‌سازی کنید که بودجه، نرخ ساعتی و تخفیف را می‌گیرد و محاسبه می‌کند که این بودجه هزینه‌ی چند روز کار را پوشش می‌دهد.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

تعداد روزهای برگردانده‌شده باید به سمت پایین، با یک رقم اعشار، رند شود (کف گرفته شود).
