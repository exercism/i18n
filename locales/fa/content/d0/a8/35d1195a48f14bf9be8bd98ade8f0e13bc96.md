# Tests

برای اجرای testها، دستور زیر را اجرا کنید:

```bash
make
```

## testهای نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی اینکه همه‌ی testهای آن قبول شوند.
به‌طور پیش‌فرض، وقتی testها را اجرا می‌کنید فقط یک test (اولین test) اجرا می‌شود.
این کار عمدی است، چون به شما اجازه می‌دهد فقط روی قبول کردن همان یک test تمرکز کنید.
وقتی آن test قبول شد، می‌توانید با حذف خط `TEST_IGNORE()` test بعدی را فعال کنید.
وقتی همه‌ی testها فعال شده باشند و پیاده‌سازی شما همه‌ی آن‌ها را قبول کند، تمرین را حل کرده‌اید!
