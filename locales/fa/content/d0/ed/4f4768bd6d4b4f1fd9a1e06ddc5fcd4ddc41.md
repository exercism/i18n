# مقدمه

[`Time`][time] در Go نوعی است که یک لحظه از زمان را توصیف می‌کند.
می‌توان از طریق متدهای آن به اطلاعات تاریخ و زمان دسترسی داشت، آن‌ها را مقایسه و دستکاری کرد، اما توابعی هم وجود دارند که روی خود پکیجِ `time` فراخوانی می‌شوند.
تاریخ و زمان کنونی را می‌توان با تابع [`time.Now`][now] به دست آورد.

تابع [`time.Parse`][parse] رشته‌ها را به مقادیری از نوع `Time` تجزیه می‌کند.
Go برای تعریفِ «چیدمان» مورد نظرتان در تجزیه، روش خاصی دارد.
باید نمونه‌ای از چیدمان را با استفاده از مقادیر این «مهر زمانی» ویژه بنویسید:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

برای مثال:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

متد [`Time.Format()`][format] یک نمایش رشته‌ای از زمان برمی‌گرداند.
درست مانند تابع `Parse`، چیدمان هدف هم دوباره با نمونه‌ای تعریف می‌شود که از مقادیر مهر زمانی ویژه استفاده می‌کند.

برای مثال:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## گزینه‌های چیدمان

برای یک چیدمان سفارشی، از ترکیب این گزینه‌ها استفاده کنید.
در Go [ثابت‌های قالب‌بندی][const] از پیش تعریف‌شده‌ای هم برای تاریخ و مهر زمانی در دسترس هستند.

| واحد زمان | گزینه‌ها |
| ----------- | ---------------------------------------------- |
| سال | 2006 ؛ 06 |
| ماه | Jan ؛ January ؛ 01 ؛ 1 |
| روز | 02 ؛ 2 ؛ \_2 (برای صفرِ ابتدایی) |
| روز هفته | Mon ؛ Monday |
| ساعت | 15 ( قالب ۲۴ساعته ) ؛ 3 ؛ 03 (قبل از ظهر یا بعد از ظهر) |
| دقیقه | 04 ؛ 4 |
| ثانیه | 05 ؛ 5 |
| نشانه‌ی قبل/بعد از ظهر | PM |
| روز سال | 002 ؛ \_\_2 |

نوع `time.Time` متدهای گوناگونی برای دسترسی به یک زمان مشخص دارد. برای مثال ساعت: [`Time.Hour()`][hour]، ماه: [`Time.Month()`][month].
توضیحات بیشتر درباره‌ی اینکه این چگونه کار می‌کند در [مستندات رسمی][time] آمده است.

پکیج [`time`][time] نوع دیگری به نام [`Duration`][duration] را هم شامل می‌شود که نشان‌دهنده‌ی زمان سپری‌شده است، و علاوه بر آن از موقعیت‌ها/مناطق زمانی، تایمرها و سایر قابلیت‌های مرتبط پشتیبانی می‌کند که در مفهوم دیگری پوشش داده خواهند شد.
