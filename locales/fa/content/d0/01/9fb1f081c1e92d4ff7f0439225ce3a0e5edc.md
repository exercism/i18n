# راهنمایی

## عمومی

- برای حل این تمرین به شکل‌های مختلف [کنترل جریان][control-flow] نیاز دارید.

## 1. بررسی وضعیت بحرانی

- برای حل این تمرین باید از دستورهای [if][if] یا [unless][unless] استفاده کنید.
- برای حل این تمرین باید از [عملگرهای مقایسه][equality-and-comparison] استفاده کنید.
- برای ترکیب چند شرط می‌توانید از [`&&`][and] و [`||`][or] استفاده کنید.

## 2. تعیین محدوده‌ی توان خروجی

- می‌توانید با استفاده از `if` و `elsif` چندین شاخه بسازید.

## 3. سازوکار ایمن در برابر خطا

- می‌توانید از `if` و `elsif` برای ساختن چندین شاخه استفاده کنید.
