# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | ورودی     | عدد صحیح | دسته‌بندی: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | ورودی     | آدرس | تاس‌ها (آرایه‌ی کلمه‌ای) |
| `$v0`    | خروجی     | عدد صحیح | امتیاز حاصل |
| `$t0-9`  | موقت | هر نوع | برای ذخیره‌سازی موقت استفاده می‌شود |
