# راهنمایی‌ها

## 1. شروع از صفر

- برای ساختن یک آرایه می‌توانید از `make-array` استفاده کنید.
- ابعاد یک آرایه به‌صورت فهرستی از `make-array` مشخص می‌شود.
- برای اینکه همه‌ی عناصر را روی یک مقدار اولیه تنظیم کنید، از پارامتر کلیدواژه‌ی `:inital-element` استفاده کنید.

## 2. شروع از یک تخته‌ی موجود

- برای تنظیم محتوای اولیه‌ی یک آرایه، از پارامتر کلیدواژه‌ی `:initial-contents` استفاده کنید.

## 3. شرط برد

- از `aref` می‌توان برای گرفتن مقدار یک خانه از آرایه استفاده کرد.
- از `eq` می‌توان برای تعیین یکسان بودن دو نماد استفاده کرد.
- از `and` می‌توان برای ترکیب دو عبارت `eq` و مقایسه‌ی سه عنصر استفاده کرد.

## 4. در یک سطر

- آرگومان‌های `aref` (برای یک آرایه‌ی دوبعدی) عبارت‌اند از «سطر» و «ستون».

## 5. در یک ستون

- آرگومان‌های `aref` (برای یک آرایه‌ی دوبعدی) عبارت‌اند از «سطر» و «ستون».
