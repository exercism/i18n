# درباره

توابع **کاربرساخته** با استفاده از کلیدواژه‌ی `function` ساخته می‌شوند. بعد از آن باید اسم تابع و فهرستی از آرگومان‌ها بیاید.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

می‌توان توابع را در یک فایل پیش از آنکه تعریف شوند فراخوانی کرد، چون به بالای حوزه‌ی خودشان منتقل می‌شوند.

## اسم‌گذاری

اسم توابع در PHP از قواعد سایر برچسب‌ها پیروی می‌کند: باید با یک زیرخط یا حرف شروع شود و پس از آن می‌تواند هر تعداد حرف، عدد یا زیرخط داشته باشد.
