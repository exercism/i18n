# مقدمه

## لیست کلیدواژه

«لیست کلیدواژه» یک ساختار داده‌ی کلید-مقدار است.

```elixir
[month: "April", year: 2018]
```

لیست کلیدواژه، لیستی از تاپل‌های `{key, value}` است و می‌توان آن را به همین شکل هم نوشت، اما نگارش کوتاه‌تر آن رایج‌تر است.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

کلیدهای یک لیست کلیدواژه باید [اتم][exercism-atoms] باشند، اما برای مقدارها هیچ محدودیتی وجود ندارد. هر کلید را می‌توان بیش از یک بار به کار برد. جفت‌های کلید-مقدار در یک لیست کلیدواژه ترتیب مشخصی دارند.

می‌توانید با لیست کلیدواژه هم درست مثل لیست‌ها کار کنید، یا از ماژول `Keyword` استفاده کنید.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
