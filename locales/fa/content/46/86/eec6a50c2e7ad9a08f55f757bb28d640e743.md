# درباره

Swift یک زبان برنامه‌نویسی کامپایل‌شده و چندالگویی است که با سه هدف اصلی طراحی شده است:

- **ایمنی**: ویژگی‌های داخلی زبان کمک می‌کنند تا پیش از اجرای کد شما در محیط عملیاتی، باگ‌ها شناسایی و از بروزشان جلوگیری شود.
- **سرعت**: کارایی بهینه‌شده، قابل مقایسه با زبان‌های مبتنی بر C.
- **بیانگری**: نحوه‌ی نگارش تمیز و مدرن که خواندن و نوشتنش لذت‌بخش و آسان است.

شرکت اپل Swift را در سال ۲۰۱۴ به عنوان جایگزینی مدرن برای Objective-C معرفی کرد؛ زبانی که پیش‌تر برای توسعه‌ی iOS و macOS به کار می‌رفت.
امروزه Swift متن‌باز است و روی پلتفرم‌های اپل، لینوکس و ویندوز اجرا می‌شود.

## شروع کار

### متغیرها

شما می‌توانید با تعریف یک [متغیر][constants-variables] مقدارها را ذخیره کنید و به آن‌ها اسم بدهید.
پس از تعریف متغیر، می‌توانید در سراسر کد از اسم آن برای اشاره به آن مقدار استفاده کنید.
متغیرها _تغییرپذیر_ هستند؛ یعنی مقدارشان می‌تواند پس از تعریف تغییر کند.

یک متغیر را با کلیدواژه‌ی `var` تعریف کنید:

```swift
var variableName = 10
```

Swift یک زبان با نوع‌گذاری ایستا است؛ یعنی هر مقدار در زمان کامپایل نوعی مشخص دارد.
می‌توانید با یک [حاشیه‌نویسی نوع][type annotations] نوع را صریحاً اعلام کنید، یا بگذارید کامپایلر Swift نوع را از مقدار تخصیص‌یافته [استنباط کند][type-inferring]:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

می‌توانید مقدار یک متغیر را با عملگر تخصیص (`=`) به‌روزرسانی کنید:

~~~~exercism/note
نوع یک متغیر پس از اعلان‌شدن نمی‌تواند تغییر کند.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

می‌توانید متغیری را بدون مقدار اولیه اعلان کنید، مشروط بر اینکه نوعش را مشخص کنید؛ اما باید پیش از استفاده از آن مقداری به آن تخصیص دهید:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### ثابت‌ها

[ثابت‌ها][constants-variables] هم یک اسم را به یک مقدار پیوند می‌دهند، اما مقدارشان پس از تخصیص قابل تغییر نیست.
ثابت‌ها _تغییرناپذیر_ هستند.
یک ثابت را با کلیدواژه‌ی `let` تعریف کنید:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### عملگرهای حسابی

Swift [عملگرهای حسابی][arithmetical-operators] استانداردی برای ریاضیات پایه ارائه می‌دهد:

- جمع: `+`
- تفریق: `-`
- ضرب: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### توابع

در Swift، [توابع][functions] بلوک‌های کدی خودکفا هستند که کار مشخصی را انجام می‌دهند.
توابع می‌توانند ورودی بگیرند، مقداری را برگردانند و خودشان به عنوان مقدار به توابع دیگر پاس داده شوند.
یک تابع را با کلیدواژه‌ی `func` تعریف کنید، سپس اسم تابع، فهرست پارامترها در پرانتز و نوع بازگشتی اختیاری می‌آید:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

توابع Swift از [برچسب‌های آرگومان][argument-labels] استفاده می‌کنند که باعث می‌شود کد مانند جمله‌های طبیعی خوانده شود:

- **برچسب آرگومان** هنگام فراخوانی تابع به کار می‌رود.
- **اسم پارامتر** درون بدنه‌ی تابع برای دسترسی به مقدار استفاده می‌شود.

اگر فقط یک اسم مشخص کنید، Swift از آن هم به عنوان برچسب آرگومان و هم به عنوان اسم پارامتر استفاده می‌کند:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

اگر نمی‌خواهید هنگام فراخوانی تابع برچسب آرگومان داشته باشید، پیش از اسم پارامتر زیرخط (`_`) بنویسید:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

همه‌ی پارامترهای تابع به طور پیش‌فرض ثابت‌اند (`let`)؛ یعنی مقدارشان درون بدنه‌ی تابع قابل تغییر نیست.

برای برگرداندن مقداری از یک تابع، نوع بازگشتی را پس از `->` مشخص کنید و از کلیدواژه‌ی `return` استفاده کنید:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

وقتی تابعی مقداری برنمی‌گرداند، نوع بازگشتی آن `Void` است (معادل یک چندتایی خالی، `()`).
در چنین توابعی می‌توانید هم نوع بازگشتی `-> Void` و هم دستور `return` را حذف کنید.

### کامنت‌ها

Swift از دو شکل [کامنت][comments] پشتیبانی می‌کند:

- **کامنت‌های تک‌خطی** با `//` شروع می‌شوند و تا پایان خط ادامه دارند.
- **کامنت‌های چندخطی** بین `/*` و `*/` قرار می‌گیرند.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
