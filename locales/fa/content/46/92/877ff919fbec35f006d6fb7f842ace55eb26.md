# دستورالعمل‌ها

موزاییک مرکز هنرهای اجتماعی ماه گذشته نصبش تمام شد و حالا Magpie Marg آن را کشف کرده است. بیشتر روزها، یکی دو کاشی را با کاشی‌های براق‌تری از **گنجینه**ی نزدیکش عوض می‌کند، یا کاشی‌ای را بیرون می‌کشد و یک ساعت ناپدید می‌شود.

شما داوطلبی هستید که هر تغییر را ثبت می‌کند. خود موزاییک یک **آرایه‌ی با اندازه‌ی ثابت** است: یک خانه برای هر موقعیت کاشی که یک رشته‌ی رنگ، یا `f` برای «گمشده» را نگه می‌دارد. گنجینه‌ی Magpie Marg هم یک **بردار** از کاشی‌های لق است که دزدیده است.

## 1. چیدن یک ردیف تازه

`fresh-mosaic` را طوری تعریف کنید که یک طول `n` بگیرد و آرایه‌ای از `n` خانه‌ی خالی (هر کدام `f`) برگرداند.

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. گذاشتن یک کاشی

`place-tile` را طوری تعریف کنید که یک ردیف، یک موقعیت و یک رنگ بگیرد و ردیف را در جای خود چنان به‌روزرسانی کند که موقعیت گفته‌شده آن رنگ را نگه دارد. این واژه چیزی برنمی‌گرداند.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. بیرون کندن یک کاشی

`chip-tile` را طوری تعریف کنید که یک ردیف و یک موقعیت بگیرد و ردیف را در جای خود چنان به‌روزرسانی کند که موقعیت گفته‌شده دوباره `f` بشود.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. تغییر رنگ یک کاشی

`recolour-tile` را طوری تعریف کنید که یک ردیف، یک موقعیت و یک `quotation` تک‌آرگومانی بگیرد و ردیف را در جای خود با اعمال آن `quotation` روی کاشیِ آن موقعیت به‌روزرسانی کند.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. گرفتن یک عکس فوری پیش از رسیدن Marg

`snapshot-mosaic` را طوری تعریف کنید که یک ردیف بگیرد و یک نسخه‌ی مستقل برگرداند که تغییرات بعدی روی نسخه‌ی اصلی روی آن اثر نگذارد.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg یک کاشی را جیب می‌کند

`stash-tile` را طوری تعریف کنید که گنجینه‌ی Marg (یک بردار) و یک رنگ بگیرد و رنگ را به گنجینه اضافه کند. چیزی برنمی‌گرداند.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg یک کاشی را برمی‌گرداند

`return-tile` را طوری تعریف کنید که گنجینه‌ی Marg را بگیرد و آخرین کاشیِ ذخیره‌شده (کاشی رویی) را بردارد و برگرداند.

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
