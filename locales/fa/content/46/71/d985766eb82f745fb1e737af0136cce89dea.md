# مقدمه

یک «دیکشنری» (`dict`) در Python یک ساختار داده است که _کلیدهای_ [هشپذیر][term-hashable] را به _مقدارها_ نسبت می‌دهد و در زبان‌های برنامه‌نویسی دیگر با نام‌های یک [جدول هش][hashtable-wikipedia] قابل تغییر اندازه، هشمپ یا [آرایه‌ی انجمنی][associative-array] شناخته می‌شود.
دیکشنری‌ها تنها [نوع نگاشت][mapping-types-dict] توکار Python هستند.


`Keys` باید هشپذیر و در سراسر دیکشنری یکتا باشند.
نوع کلیدها می‌تواند شامل `numbers`، `str` یا `tuples` (از مقدارهای _تغییرناپذیر_) باشد.
آن‌ها نمی‌توانند ساختارهای داده‌ی _تغییرپذیر_ مانند `lists`، `dict`s یا `set`s را در خود جای دهند.
از Python ۳.۷ به بعد، ترتیب کلیدهای `dict` همان ترتیبی است که عنصرها درج شده‌اند.

`values` می‌تواند از هر نوع داده یا ساختاری باشد.
 مقدارها می‌توانند به‌طور دلبخواه تو در تو شوند، بنابراین می‌توانند شامل لیست‌هایی از لیست‌ها، زیردیکشنری‌ها و دیگر ساختارهای داده‌ی سفارشی یا ترکیبی باشند.

با داشتن یک `key`، دیکشنری‌ها می‌توانند یک `value` را به‌طور میانگین در زمان ثابت بازیابی کنند (_مستقل از تعداد عنصرها_).
در مقایسه با جست‌وجوی یک مقدار در یک `list` یا `array` (_بدون دانستن موقعیت `index`)، یک `dict` حافظه‌ی بسیار بیشتری مصرف می‌کند، اما بازیابی در آن خیلی سریع است.
دیکشنری‌ها در موقعیت‌هایی که مجموعه‌ی عنصرها بزرگ است و باید مرتب به آن‌ها دسترسی داشت و به‌روزرسانی کرد، بسیار به کار می‌آیند.


## ساختن دیکشنری

دیکشنری‌ها به روش‌های زیادی ساخته می‌شوند.
دو روش سرراست‌تر، استفاده از سازنده‌ی `dict()` یا تعریف یک `dict` به شکل _لیترال_ است.

### سازنده‌ی کلاس `dict()`

`dict()` (_سازنده‌ی کلاس دیکشنری_) را می‌توان با هر شیء تکرارپذیری از جفت‌های `key`، `value` یا با مجموعه‌ای از _آرگومان‌های_ `<name>=<value>` به کار برد:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### لیترال‌های دیکشنری

یک `dict` را می‌توان مستقیماً به شکل _لیترال دیکشنری_ هم نوشت، با استفاده از آکولاد (`{}`) که جفت‌های `key : value` را در بر می‌گیرد:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## دسترسی به مقدارها در یک دیکشنری

می‌توانید با یک _کلید_ که داخل کروشه‌های مربعی (`[]`) می‌آید، به یکی از عنصرهای دیکشنری دسترسی پیدا کنید.
اگر یک `key` در `dict` وجود نداشته باشد، خطای `KeyError` پرتاب می‌شود:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

دسترسی به یک عنصر با متد `.get(<key>, <default value>)` می‌تواند از خطای `KeyError` جلوگیری کند:

```python
>>> bear.get("color", 'not found')
'not found'
```

## تغییر یا افزودن مقدارهای یک دیکشنری

می‌توانید `value` یک عنصر را با انتساب دادن به _کلید_ آن تغییر دهید:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

جفت‌های جدید `key`:`value` را هم به همین شکل می‌توان _افزود_:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## حذف کردن (پاپ کردن) عنصرهای دیکشنری

می‌توانید با متد `.pop(<key>)` یکی از عنصرهای دیکشنری را حذف کنید.
`.pop()` جفت (`key`، `value`) را حذف می‌کند و `value` را برمی‌گرداند تا از آن استفاده کنید.
مثل `.get()`، متد `.pop(<key>)` یک آرگومان دوم (_`dict.pop(<key>, <default value>)`_) هم می‌پذیرد که اگر `key` پیدا نشود، برگردانده می‌شود.
این کار جلوی پرتاب شدن خطای `KeyError` را می‌گیرد:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## حلقه زدن روی دیکشنری / پیمایش آن

وقتی با `for item in dict` یا `while item` روی یک دیکشنری حلقه می‌زنید، به‌طور پیش‌فرض فقط روی _کلیدها_ پیمایش می‌شود.
می‌توانید در همان حلقه با استفاده از _کروشه‌های مربعی_ به _مقدارها_ هم دسترسی پیدا کنید:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

همچنین می‌توانید از متد `.items()` استفاده کنید که به‌طور خودکار تاپل‌های (`key`، `value`) را برمی‌گرداند:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

به همین ترتیب، متد `.keys()` مقدارهای `keys` و متد `.values()` مقدارهای `values` را برمی‌گرداند.
