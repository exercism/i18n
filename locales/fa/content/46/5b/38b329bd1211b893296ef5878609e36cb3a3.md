# مقدمه

یک [`string`][ref-string] در Kotlin دنباله‌ای تغییرناپذیر از نویسه‌های یونیکد است.

[`Immutable`][wiki-immutable] یعنی هر عملیات روی یک رشته باید رشته‌ی جدیدی برگرداند: رشته‌ی اصلی هرگز نمی‌تواند تغییر کند.

[`Unicode`][wiki-unicode] یعنی می‌توان بیشتر سیستم‌های نوشتاری جهان را نمایش داد، اما (برخلاف زبان‌های قدیمی‌تری مانند C) نگاشت یک‌به‌یک میان نویسه‌ها و بایت‌ها وجود ندارد.

یک رشته با دو علامت نقل‌قول `" "` احاطه می‌شود.

برخی نویسه‌ها به فرار نیاز دارند: `\\`، به‌علاوه‌ی نویسه‌های غیرقابل‌چاپ معمول مانند `\t` (تب) و `\n` (خط جدید).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

رشته‌های چندخطی با ۳ علامت نقل‌قول احاطه می‌شوند و می‌توانند متن دلخواهی در خود داشته باشند (نیازی به فرار نیست).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

از [trimIndent][trimIndent-doc] استفاده کنید تا تورفتگی مشترک را از خط‌ها حذف کنید.
این برای قالب‌بندی رشته مفید است:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

به‌عنوان جایگزین، [trimMargin][trimMargin-doc] به شما امکان می‌دهد یک جداکننده مشخص کنید.
سپس هر خط در `String` پس از جداکننده آغاز می‌شود.
جداکننده به‌طور پیش‌فرض `|` است، اما می‌توانید جداکننده‌ی متفاوتی را به‌عنوان پارامتر مشخص کنید.
برای مثال:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

رشته‌ها را می‌توان با `+` به هم چسباند، اما بهتر است این کار به موارد کوتاه و ساده محدود شود.
گزینه‌های دیگر و اغلب بهتری هم وجود دارد.

## قالب‌های رشته

این به چیزی اشاره دارد که برخی زبان‌های دیگر به آن «درون‌گذاری» می‌گویند.

اگر یک رشته شامل علامت دلار `$` باشد که پس از آن یک شناسه بیاید، یا شامل آکولادهایی (`{expression}`) باشد که عبارتی را در بر می‌گیرند، آن‌ها به‌ترتیب با مقدار یا نتیجه‌ی آن عبارت جایگزین می‌شوند.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

آکولادهای `{ }` وقتی دور عبارت‌ها لازم می‌شوند که در غیر این صورت تجزیه مبهم باشد.

به‌طور کلی، استفاده از قالب‌های رشته برای ترکیب رشته‌ها روشی کارآمدتر و مرسوم‌تر از استفاده از `+` است.

## توابع رشته

Kotlin [`functions`][ref-string-functions] _بسیاری_ برای دستکاری رشته‌ها فراهم می‌کند.

بیشتر آن‌ها [`extensions functions`][ref-extensions] هستند، نه اعضای کلاس `String`؛ هرچند این تأثیر کمی بر چگونگی استفاده‌ی ما از آن‌ها دارد.

~~~~exercism/note
صفحه‌های نسبتاً پیچیده‌ی [مستندات][ref-string-functions] Kotlin، توابع افزونه را در نمای پیش‌فرض پنهان می‌کنند.
حتماً روی `Members & Extensions` کلیک کنید تا این بخش باز شود.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

نمونه‌های زیر فقط گزیده‌ی کوچکی از آنچه در دسترس است را نشان می‌دهند:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
