# دستورالعمل‌ها

شما جدول زمانی حرکت یک کشتی مسافربری کوچک جزیره‌ای را نگه می‌دارید. زمان‌های حرکت به‌صورت تاریخ ثبت می‌شوند و برای کار با آن‌ها به چند تابع کمکی نیاز دارید.

## 1. ثبت تاریخ حرکت

تابع `make-date` را تعریف کنید تا سال، ماه و روز را بگیرد و برچسب زمانی متناظر با آن را برگرداند.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. اسم روز هفته

تابع `weekday-name` را تعریف کنید تا برچسب زمانی یک حرکت را بگیرد و اسم روز هفته‌ای را برگرداند که آن حرکت در آن قرار می‌گیرد.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. سال‌های کبیسه

تابع `leap?` را تعریف کنید تا یک سال را بگیرد و برگرداند که آیا آن سال کبیسه است یا نه.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. تعداد روزهای یک ماه

تابع `month-length` را تعریف کنید تا یک سال و یک ماه را بگیرد و تعداد روزهای آن ماه را برگرداند (فوریه را به یاد داشته باشید).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. چند روز بعد

تابع `add-days` را تعریف کنید تا یک برچسب زمانی و یک تعداد روز را بگیرد و برچسب زمانیِ همان تعداد روز بعدتر را برگرداند.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
