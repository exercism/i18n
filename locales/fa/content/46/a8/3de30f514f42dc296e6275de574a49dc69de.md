# ماژول و مسیر در Cairo

Cairo برای سازمان‌دهی کد از **ماژول** استفاده می‌کند.

ماژول‌ها به ساختاردهی پروژه‌ها و کنترل سطح دسترسی به مواردی مانند توابع، structها و traitها کمک می‌کنند.

## تعریف ماژول‌ها

ماژول‌ها با `mod` تعریف می‌شوند و می‌توانند تودرتو باشند:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

توابع، structها و traitها به‌صورت پیش‌فرض **خصوصی** هستند.

برای اینکه از بیرون ماژول خودشان قابل دسترس باشند، از `pub` استفاده کنید.

## مسیرها: مطلق یا نسبی

برای ارجاع به موردی در ماژول دیگر، می‌توانید از این‌ها استفاده کنید:

- **مسیرهای مطلق** (که از `crate::` شروع می‌شوند):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **مسیرهای نسبی** (که از ماژول جاری شروع می‌شوند):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  اگر `front_of_house` در همان ماژول باشد، این روش کار می‌کند.

## آوردن ماژول‌ها به دامنه با `use`

نوشتن مکرر مسیرهای کامل دست‌وپاگیر است.

کلیدواژه‌ی `use` امکان استفاده از ارجاع‌های کوتاه‌تر را می‌دهد:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` فقط **در دامنه‌ای اعمال می‌شود که در آن آمده است**؛ اگر جای دیگری لازم باشد، باید تکرار شود.

### استفاده‌ی متداول از `use`

- **ماژول‌ها** را به دامنه بیاورید، نه توابع:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  به‌جای این:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- برای **traitها، structها و enumها**، از مسیر کامل استفاده کنید:

  ```rust
  use core::num::traits::BitSize;
  ```

### نام‌های مستعار با `as`

در صورت نیاز، نام‌ها را هنگام وارد کردن تغییر دهید:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### وارد کردن چند مورد

به‌جای چند دستور `use`، آن‌ها را یک‌جا گروه‌بندی کنید:

```rust
use shapes::{Square, Circle, Triangle};
```

## بازصادر کردن با `pub use`

برای در دسترس قرار دادن یک ماژول در ساختاری متفاوت، از `pub use` استفاده کنید:

```rust
pub use crate::front_of_house::hosting;
```

حالا کدهای بیرونی می‌توانند به‌جای `restaurant::front_of_house::hosting::add_to_waitlist()` از `restaurant::hosting::add_to_waitlist()` استفاده کنند.

## استفاده از بسته‌های بیرونی با Scarb

برای افزودن یک وابستگی، `Scarb.toml` را به‌روزرسانی کنید:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

برای افزودن وابستگی‌ها از `scarb add <package>` و برای حذف آن‌ها از `scarb rm <package>` استفاده کنید.

## عملگر Glob (`*`)

برای وارد کردن همه‌ی محتوای یک ماژول:

```rust
use core::num::traits::*;
```

باید با احتیاط از آن استفاده کرد، چون می‌تواند خواندن کد را سخت‌تر کند.
