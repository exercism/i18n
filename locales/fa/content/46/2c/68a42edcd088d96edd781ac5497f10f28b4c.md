# Instructions

در این تمرین، به عاشقان دبیرستانی کمک می‌کنید تا عشقشان را در شبکه‌های اجتماعی با ساختن یک قلب ASCII از حروف اول اسمشان ابراز کنند:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. حرف اول اسم را به دست آورید

تابع `first_letter` را پیاده‌سازی کنید. باید یک اسم بگیرد و حرف اولش را برگرداند. باید هر فاصله‌ی اضافی را از اسم پاک کند.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. حرف اول را به صورت حرف اختصاری درآورید

تابع `initial` را پیاده‌سازی کنید. باید یک اسم بگیرد و حرف اولش را بزرگ، و به دنبال آن یک نقطه، برگرداند. حتماً از `first_letter` که در گام قبل تعریف کردید دوباره استفاده کنید.

```gleam
initial("Robert")
// -> "R."
```

## 3. نام کامل را به اسم کوچک و نام خانوادگی تقسیم کنید

تابع `initials` را پیاده‌سازی کنید. باید یک نام کامل بگیرد که از یک اسم کوچک و یک نام خانوادگی جدا شده با یک فاصله تشکیل شده است، و حروف اول را برگرداند. حتماً از `initial` که در گام قبل تعریف کردید دوباره استفاده کنید.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. حروف اول را داخل قلب قرار دهید

تابع `pair` را پیاده‌سازی کنید. باید دو نام کامل بگیرد و حروف اول را داخل یک قلب ASCII برگرداند. حتماً از `initials` که در گام قبل تعریف کردید دوباره استفاده کنید.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
