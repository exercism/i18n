# مقدمه

فهرست در C# مجموعه‌ای است از مقادیر اولیه یا نمونه‌هایی از struct یا کلاس. فهرست در کتابخانه‌ی کلاس پایه به‌صورت `List<T>` پیاده‌سازی شده است که در آن `T` نوع عنصر موجود در فهرست است. API مجموعه‌ای غنی از متدها را برای ساختن و دستکاری فهرست در اختیار شما می‌گذارد.

عنصرها را می‌توان به فهرست افزود و از آن حذف کرد. فهرست به‌تناسب نیاز بزرگ و کوچک می‌شود.

```csharp
var listOfStrings = new List<string>();
```
