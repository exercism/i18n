# درباره

CoffeeScript زبانی است که به JavaScript تبدیل می‌شود و برای ساخت وب‌سایت‌های پویا (هم در مرورگر و هم روی سرور) به کار می‌رود.
پیش از اجرا، مترجم کد CoffeeScript را به JavaScript تبدیل می‌کند تا سازگاری و همان کارایی JavaScript حفظ شود و در عین حال ویژگی‌های تازه‌ی زیادی هم در اختیار شما قرار بگیرد!

CoffeeScript بر پایه‌ی آمیزه‌ای از زبان‌های Ruby و Python ساخته شد تا راهی ساده‌تر برای نوشتن JavaScript فراهم کند.
یکی از تفاوت‌های آن استفاده از «تورفتگی» و فلش‌ها به‌جای کدهای پرحجم توابع در JavaScript است و همچنین ویژگی‌های مفیدی از زبان‌های تابعی، از جمله «تطبیق الگو»، به آن افزوده شده است.

CoffeeScript یکی از زبان‌های تازه‌ی بسیاری است که به JavaScript تبدیل می‌شوند؛ از جمله TypeScript و Flow. جامعه‌ی کاربرانش در حال بزرگ‌تر شدن است و این دسته از زبان‌ها طرفداران زیادی دارند.
