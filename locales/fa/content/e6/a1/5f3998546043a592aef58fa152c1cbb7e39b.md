# دستورالعمل‌ها

آزمون‌های بازیگری نمایش مدرسه تمام شده است و کارگردان می‌خواهد تصمیم‌ها را ثبت کند.

هر چهار کار در کلاس `CASTING_CALL` قرار می‌گیرند.

## 1. حکم

هر هنرپیشه از ده نمره می‌گیرد. نمره‌ی ۸ یا بیشتر یعنی انتخاب می‌شود. ۵ تا ۷ یعنی به مرحله‌ی بعد فراخوانده می‌شود و کمتر از ۵ یعنی از او تشکر می‌شود.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. کدام گروه؟

هنرپیشه‌های زیر ۱۳ سال «Juniors» هستند، از ۱۳ تا ۱۵ سال «Middles» و از ۱۶ سال به بالا «Seniors».

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. زمان بازگشت

«Juniors» ساعت ۴ فراخوانده می‌شوند، «Middles» ساعت ۵ و بقیه ساعت ۶.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

آرگومان، اسم یک گروه است و باید دقیقاً همان‌طور که کار ۲ نوشته شده است نوشته شود.

## 4. روی برگه چه بنویسیم

کسی که ۸ یا بیشتر گرفته باشد و بتواند آواز بخواند، `"Lead"` است. ۸ یا بیشتر بدون آواز خواندن، `"Speaking part"` است. بقیه `"Chorus"` هستند.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
