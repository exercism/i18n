# مقدمه

وقتی یک «quotation» لازم دارد مقادیری را از محیط اطرافش *به خاطر بسپارد*، Factor دو ابزار در اختیارتان می‌گذارد: `curry`/`compose` از [`kernel`][kernel]، و نحوه‌ی نگارش fry که `'[ … ]` است، از [`fry`][fry].

`curry` یک مقدار را در ابتدای یک quotation می‌پزد:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` دو quotation را به هم می‌چسباند:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

وقتی بخواهید بیش از یکی دو مقدار را در quotation جا دهید، fry خیلی تمیزتر است. هر `_` به ترتیب با مقداری که از پشته برداشته می‌شود پر می‌شود:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry همچنین به درون quotationهای تودرتو راه پیدا می‌کند.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
