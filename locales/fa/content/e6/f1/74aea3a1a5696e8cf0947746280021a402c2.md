# دستورالعمل‌ها

در این تمرین، منطق مأموریت یک بازی نقش‌آفرینی جدید را پیاده‌سازی می‌کنید که دوستی در حال ساخت آن است.

شخصیت اصلی بازی آنالین است، دختری شجاع با یک سگ خانگی سرسخت و وفادار. اما متأسفانه فاجعه رخ می‌دهد: بهترین دوستش هنگام جست‌وجوی توت در جنگل ربوده می‌شود.

آنالین تلاش می‌کند بهترین دوستش را پیدا کند و آزادش کند و می‌تواند سگش را هم در این مأموریت همراه خود ببرد.

بعد از مدتی که صرف دنبال کردن رد پای بهترین دوستش می‌کند، اردوگاهی را پیدا می‌کند که دوستش در آن زندانی است. معلوم می‌شود دو آدم‌ربا وجود دارند: شوالیه‌ای قدرتمند و کمانداری حیله‌گر.

آنالین پس از یافتن آدم‌رباها بررسی می‌کند که کدام‌یک از کارهای زیر را می‌تواند انجام دهد:

- _حمله‌ی سریع_: حمله‌ی سریع زمانی می‌تواند انجام شود که شوالیه خواب باشد، چون پوشیدن زره برایش وقت می‌برد و در نتیجه آسیب‌پذیر خواهد بود.
- _جاسوسی_: اگر دست‌کم یکی از آن‌ها بیدار باشد، می‌توان از گروه جاسوسی کرد. در غیر این صورت، جاسوسی اتلاف وقت است.
- _علامت‌دادن به زندانی_: اگر زندانی بیدار و کماندار خواب باشد، می‌توان با صدای پرندگان به زندانی علامت داد، چون کماندارها در علامت‌دهی با صدای پرندگان آموزش دیده‌اند و می‌توانند پیام را رهگیری کنند.
- _آزاد کردن زندانی_: آنالین می‌تواند تلاش کند دزدکی به اردوگاه وارد شود و زندانی را آزاد کند.
  این کار پرخطر است و تنها به یکی از دو روش می‌تواند موفق شود:
  - اگر سگش همراهش باشد، در صورتی می‌تواند زندانی را نجات دهد که کماندار خواب باشد.
    شوالیه از سگ می‌ترسد و کماندار پیش از آنکه آنالین و زندانی فرار کنند، فرصت آماده شدن نخواهد داشت.
  - اگر سگش همراهش نباشد، آنالین و زندانی باید بسیار موذیانه عمل کنند!
    اگر زندانی بیدار باشد و شوالیه و کماندار هر دو خواب باشند، آنالین می‌تواند زندانی را آزاد کند؛ اما اگر زندانی خواب باشد، نمی‌توان نجاتش داد: ظاهر ناگهانی آنالین او را جا می‌زند و شوالیه و کماندار را بیدار می‌کند.

چهار کار پیش رو دارید: پیاده‌سازی منطقی که بر اساس وضعیت سه شخصیت حاضر در جنگل و اینکه سگ آنالین همراه او هست یا نه، تعیین می‌کند کارهای بالا در دسترس هستند یا نه.

## 1. بررسی امکان انجام حمله‌ی سریع

متد `can_fast_attack()` را پیاده‌سازی کنید که یک «مقدار منطقی» می‌گیرد و نشان می‌دهد شوالیه بیدار است یا نه. این متد اگر بر اساس وضعیت شوالیه بتوان حمله‌ی سریع انجام داد، `TRUE` برمی‌گرداند. در غیر این صورت، `FALSE` برمی‌گرداند:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. بررسی امکان جاسوسی از گروه

متد `can_spy()` را پیاده‌سازی کنید که سه مقدار منطقی می‌گیرد که به‌ترتیب نشان می‌دهند شوالیه، کماندار و زندانی بیدار هستند یا نه. این متد اگر بر اساس وضعیت این سه شخصیت بتوان از گروه جاسوسی کرد، `TRUE` برمی‌گرداند. در غیر این صورت، `FALSE` برمی‌گرداند:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. بررسی امکان علامت‌دادن به زندانی

متد `can_signal_prisoner()` را پیاده‌سازی کنید که دو مقدار منطقی می‌گیرد که به‌ترتیب نشان می‌دهند کماندار و زندانی بیدار هستند یا نه. این متد اگر بر اساس وضعیت این دو شخصیت بتوان به زندانی علامت داد، `TRUE` برمی‌گرداند. در غیر این صورت، `FALSE` برمی‌گرداند:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. بررسی امکان آزاد کردن زندانی

متد `can_free_prisoner()` را پیاده‌سازی کنید که چهار مقدار منطقی می‌گیرد. سه پارامتر اول به‌ترتیب نشان می‌دهند شوالیه، کماندار و زندانی بیدار هستند یا نه. پارامتر آخر نشان می‌دهد سگ آنالین حاضر است یا نه. این متد اگر بر اساس وضعیت این سه شخصیت و حضور سگ آنالین بتوان زندانی را آزاد کرد، `TRUE` برمی‌گرداند. در غیر این صورت، `FALSE` برمی‌گرداند:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
