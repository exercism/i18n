# نصب

## شروع سریع

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

به‌طور پیش‌فرض این فرمان در `/usr/local/bin` نصب می‌کند. برای تغییر آن، نام پوشه را مشخص کنید:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

فایل‌های اجرایی Linux و macOS از طریق brew ارائه می‌شوند.

نصب:

    brew install borkdude/brew/babashka

ارتقا:

    brew upgrade babashka

## Arch (Linux)

`babashka` در [مخزن کاربران Arch](https://aur.archlinux.org) [در دسترس است](https://aur.archlinux.org/packages/babashka-bin/). می‌توانید آن را با ابزارهای محبوب [AUR](https://aur.archlinux.org) مانند
[yay](https://github.com/Jguer/yay)، [yaourt](https://github.com/archlinuxfr/yaourt)، [apacman](https://github.com/oshazard/apacman) و [pacaur](https://github.com/rmarquis/pacaur) نصب کنید. در ادامه نمونه‌ای با `yay` آمده است:

    yay -S babashka-bin

## Windows

در Windows می‌توانید با [scoop](https://scoop.sh/) و مخزن
[scoop-clojure](https://github.com/littleli/scoop-clojure) نصب کنید.
