# مقدمه

[«بازه»][range] فاصله‌ی میان دو مقدار را نشان می‌دهد.
معمولاً از بازه همراه با نوع‌هایی مانند `Int`، `String` و `Character` استفاده می‌شود تا روی دنباله‌ها پیمایش شود، از مجموعه‌ها برش گرفته شود، یا بررسی شود که آیا مقداری درون محدوده‌ی آن قرار می‌گیرد یا نه.

سوئیفت دو عملگر اصلی بازه ارائه می‌دهد:

- **عملگر بازه‌ی بسته (`...`)**: هم مقدار شروع و هم مقدار پایان را شامل می‌شود (`1...5` شامل ۱، ۲، ۳، ۴ و ۵ است).
- **عملگر بازه‌ی نیمه‌باز (`..<`)**: مقدار شروع را شامل می‌شود اما مقدار پایان را نه (`1..<5` شامل ۱، ۲، ۳ و ۴ است).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
وقتی متدی را مستقیماً روی یک مقدار ثابت بازه فراخوانی می‌کنید، عبارت بازه را در پرانتز بگذارید تا کامپایلر ابتدا بازه را ارزیابی کند:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## تبدیل بازه به آرایه

می‌توانید بازه‌ای از اعداد را با سازنده‌ی `Array(_:)` به یک `Array` تبدیل کنید:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## برش یک آرایه با بازه‌ها

می‌توانید از بازه‌ها برای برش بخش‌هایی از یک آرایه استفاده کنید:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## ویژگی‌ها و متدهای بازه

عملیات رایج روی بازه‌ها عبارت‌اند از:

| عضو                  | توضیح                                                | مثال                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | تعداد عناصر بازه را برمی‌گرداند                | `(1...5).count` مقدار `5` را برمی‌گرداند          |
| [`contains(_:)`][contains] | اگر بازه مقدار مشخص‌شده را شامل شود، `true` را برمی‌گرداند | `(1...5).contains(3)` مقدار `true` را برمی‌گرداند |

## بازه‌های یک‌طرفه

سوئیفت همچنین از بازه‌های یک‌طرفه (جزئی) پشتیبانی می‌کند، بازه‌هایی که در آن‌ها یا مقدار شروع را حذف می‌کنید یا مقدار پایان را:

- `array[2...]`: از اندیس ۲ تا پایان مجموعه.
- `array[...2]`: از ابتدای مجموعه تا اندیس ۲، با احتساب آن.
- `array[..<2]`: از ابتدای مجموعه تا اندیس ۲، اما بدون احتساب آن.

## بازه‌های رشته و کاراکتر

می‌توان بازه را میان کاراکترها یا رشته‌هایی که از `Comparable` تبعیت می‌کنند هم ساخت:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
