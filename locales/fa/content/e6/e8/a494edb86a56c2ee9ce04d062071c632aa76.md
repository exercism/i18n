# مقدمه

## رشته‌ی بیتی

کار کردن با داده‌های دودویی مفهومی مهم در هر زبانی است و Elixir روشی شیک برای نوشتن، تطبیق دادن و ساختن داده‌های دودویی در اختیار شما می‌گذارد.

در Elixir به داده‌های دودویی، نوع رشته‌ی بیتی می‌گویند. _نوع_ داده‌ی دودویی (که نباید با داده‌های دودویی به معنای کلی اشتباه گرفته شود) شکل خاصی از رشته‌ی بیتی است که در تمرینی دیگر درباره‌ی آن صحبت می‌کنیم.

لیترال‌های رشته‌ی بیتی با استفاده از شکل ویژه‌ی `<<>>` تعریف می‌شوند. وقتی یک لیترال رشته‌ی بیتی تعریف می‌کنید، آن را در قالب قطعه‌هایی تعریف می‌کنید. هر قطعه یک مقدار و یک نوع دارد که با عملگر `::` از هم جدا می‌شوند. نوع مشخص می‌کند که برای کدگذاری مقدار، چند بیت استفاده می‌شود. می‌توان نوع را کاملاً حذف کرد که در این صورت به‌طور پیش‌فرض یک مقدار صحیح ۸ بیتی خواهد بود.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

نوشتن نوع به شکل `::1` شکل کوتاه‌شده‌ی `::size(1)` است. اگر اندازه‌ی بیت‌ها از یک متغیر بیاید، باید از شکل بلندتر استفاده کنید.

### دودویی

وقتی لیترال‌های صحیح دودویی را می‌نویسیم، می‌توانیم آن‌ها را مستقیماً در مبنای ۲ بنویسیم و پیشوند `0b` را به لیترال اضافه کنیم. توجه کنید که به هر حال هنگام نمایش در نتایج تست‌ها یا در iex، این اعداد به‌صورت اعداد دهدهی نشان داده می‌شوند.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

### بریدن

اگر مقدار قطعه از ظرفیت نوع آن قطعه فراتر برود، از سمت چپ بریده می‌شود.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

### افزودن به ابتدا و انتها

با استفاده از شکل ویژه می‌توانید هم به ابتدای یک رشته‌ی بیتی موجود چیزی اضافه کنید و هم به انتهای آن. اگر اندازه‌ی رشته‌ی بیتی موجود نامعلوم باشد، باید نوع `::bitstring` را برای آن به کار ببرید.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

### به هم چسباندن

می‌توانیم رشته‌های بیتی ذخیره‌شده در متغیرها را با استفاده از شکل ویژه به هم بچسبانیم. هنگام به هم چسباندن دو رشته‌ی بیتی با اندازه‌های نامعلوم باید از نوع `::bitstring` استفاده کرد.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

### تطبیق الگو

از تطبیق الگو می‌توان برای گرفتن مقدارها از شکل ویژه هم استفاده کرد. باید تعداد بیت‌های هر تکه‌ای را که می‌خواهید بگیرید بدانید، با یک استثنا: می‌توان از نوع `::bitstring` برای تطبیق الگو روی یک رشته‌ی بیتی با اندازه‌ی نامعلوم استفاده کرد، اما این کار فقط برای تکه‌ی آخر امکان‌پذیر است.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

### بررسی رشته‌های بیتی

~~~~exercism/note
ممکن است رشته‌های بیتی (توسط اجراکننده‌ی تست یا در iex) در قالبی متفاوت از قالبی که برای ساختنشان استفاده شده چاپ شوند. این موضوع هنگام یادگیری رشته‌های بیتی اغلب باعث سردرگمی می‌شود.
~~~~

به‌طور پیش‌فرض، رشته‌های بیتی در تکه‌هایی ۸ بیتی (یک بایت) نمایش داده می‌شوند، حتی اگر آن‌ها را با تکه‌هایی با اندازه‌ی متفاوت ساخته باشید.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

اگر رشته‌ی بیتی‌ای بسازید که نماینده‌ی یک رشته‌ی قابل چاپ کدگذاری‌شده با UTF-8 باشد، به‌صورت یک رشته نمایش داده می‌شود.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
