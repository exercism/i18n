# آرایه

در Cairo، آرایه یک ساختار داده است که به شما امکان می‌دهد مجموعه‌ای از عناصر هم‌نوع را ذخیره کنید.
آرایه‌ها در Cairo گزینه‌های محدودی برای تغییر دارند.
فقط می‌توانید عناصر را به انتهای آرایه اضافه کنید و آن‌ها را از ابتدای آرایه حذف کنید.
آرایه‌ها در واقع نوعی «صف» هستند که مقادیرشان قابل تغییر نیست.

## ساخت آرایه

آرایه‌ها عمدتاً با استفاده از trait به اسم `ArrayTrait` ساخته می‌شوند و برای ساختن آرایه‌ای از عناصر مانند `[1, 2]` می‌توانید از هر یک از این ۴ روش استفاده کنید:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> هر فراخوانی `append()` یک عدد تازه را به انتهای آرایه اضافه می‌کند.

## حذف عناصر آرایه

تنها راه حذف عناصر از یک آرایه در Cairo از ابتدای آن است.
این کار با متد `pop_front()` انجام می‌شود که یک `Option` برمی‌گرداند؛ این `Option` قابل بازکردن است و یا عنصر حذف‌شده را در خود دارد و یا اگر آرایه خالی باشد `Option::None` است.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## دسترسی به مقادیر یک آرایه

برای دسترسی به عناصر آرایه می‌توانید از متدهای `get()` یا `at()` استفاده کنید که نوع‌های متفاوتی برمی‌گردانند.
معادل `arr.at(index)` عملگر اندیس‌گذاری `arr[index]` است.

### استفاده از متد `get()`

متد `get()` مانند پیدا کردن یک عنصر در یک فهرست با شماره‌ی آن است.
نحوه‌ی کارش این‌گونه است:

- `arr.get(index)` به شما امکان می‌دهد عنصری را در موقعیت (اندیس) مشخصی از آرایه به دست آورید.
- اگر عنصر در اندیس داده‌شده وجود داشته باشد، `Option::Some(value)` را برمی‌گرداند و اگر اندیس خارج از محدوده باشد، `Option::None` را.

این متد زمانی ایده‌آل است که می‌خواهید مواردی را که ممکن است اندیس نامعتبر باشد، بدون از کار افتادن برنامه مدیریت کنید.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### استفاده از متد `at()`

متد `at()` مستقیماً تصویری از عنصر در یک اندیس مشخص به شما می‌دهد و از عملیات `unbox()` برای بیرون کشیدن مقدار ذخیره‌شده از جعبه استفاده می‌کند.
صورت کوتاه‌تر این متد، استفاده از عملگر اندیس‌گذاری `arr[index]` است.
اگر بخواهید به اندیسی دسترسی پیدا کنید که وجود ندارد (خارج از محدوده)، برنامه با یک خطا `panic` می‌کند.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## متدهای مربوط به اندازه

برای تعیین تعداد عناصر یک آرایه از متد `len()` استفاده کنید.
مقدار بازگشتی از نوع `usize` است.

اگر می‌خواهید بررسی کنید که آرایه خالی است یا نه، می‌توانید از متد `is_empty()` استفاده کنید که اگر آرایه خالی باشد `true` و در غیر این صورت `false` برمی‌گرداند.

## `Span`

`Span` ساختاری است که تصویری لحظه‌ای از یک `Array` را نشان می‌دهد.
این ساختار طوری طراحی شده که دسترسی ایمن و کنترل‌شده به عناصر یک آرایه را بدون تغییر دادن آرایه‌ی اصلی فراهم کند.
`Span` به‌ویژه برای تضمین یکپارچگی داده‌ها و پرهیز از مشکلات قرض‌گیری هنگام انتقال آرایه‌ها بین توابع یا انجام عملیات فقط‌خواندنی مفید است.

> همه‌ی متدهایی که `Array` فراهم می‌کند با `Span` هم قابل استفاده هستند، به‌جز متد `append()`.

برای ساختن یک `Span` از یک `Array`، متد `span()` را فراخوانی کنید:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## نوع `Array` با اندازه‌ی ثابت

مقادیر یک آرایه‌ی با اندازه‌ی ثابت را به‌صورت فهرستی جداشده با کاما داخل کروشه می‌نویسیم.
نوع آرایه با کروشه نوشته می‌شود: نوع هر عنصر، یک نقطه‌ویرگول و سپس تعداد عناصر آرایه.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> توجه: فقط آرایه‌های با اندازه‌ی ثابت را می‌توان به‌عنوان ثابت به کار برد

می‌توان به عناصر یک آرایه‌ی با اندازه‌ی ثابت یا با از هم بازکردن آرایه دسترسی داشت یا با تبدیل آن به یک `Span` که از اندیس‌گذاری پشتیبانی می‌کند.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
