# ضمیمه‌ی دستورالعمل

## عملگرهای اعداد گویا

توابع حسابی از فراخوانی معمولی تابع، ارسال ایستا (یعنی نحوه‌ی نگارش فراخوانی متد) و عملگرها پشتیبانی می‌کنند:

| فراخوانی تابع | فراخوانی متد | عملگر |
| --- | --- | --- |
| `plus(r1, r2)` | `r1.plus(r2)` | `r1 + r2` |
| `minus(r1, r2)` | `r1.minus(r2)` | `r1 - r2` |
| `times(r1, r2)` | `r1.times(r2)` | `r1 * r2` |
| `div_by(r1, r2)` | `r1.div_by(r2)` | `r1 / r2` |

تابع `reduce` را پیاده‌سازی کنید تا یک عدد گویا را به ساده‌ترین شکلش کاهش دهد، برای مثال از `6 / 8` به `3 / 4`.
