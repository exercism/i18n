# عبارت `match`

یک عبارت `match` یک مقدار را در برابر یک شرط ارزیابی می‌کند تا عبارتی را برگرداند که باید ارزیابی شود. تقریباً مانند عملگر سه‌گانه، اگر شرط مطابقت نکند، عبارت بازگشتی ارزیابی نمی‌شود. برای مطابقت دادن یک شرط، بررسی همسانی [برابری دقیق یا `===`] انجام می‌شود.

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

برای انجام بررسی برابری [`==`]، می‌توانید شرط را بازآرایی کنید:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

در یک عبارت `match`، اگر هیچ شرطی مطابقت نکند، `UnhandledMatchError` پرتاب می‌شود.
