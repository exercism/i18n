# مقدمه

`Option` یک enum است که برای بررسی معتبر بودن مقدارهای بازگشتی توابع استفاده می‌شود. به این شکل تعریف می‌شود:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

این نوع بخشی از بسته‌ی `haxe.ds` است:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
