# دستورالعمل‌ها

Conda Airlines بزرگ‌ترین شرکت هواپیمایی دنیای برنامه‌نویسی است و روزانه بیش از ۱۰٬۰۰۰ پرواز دارد!

آن‌ها در حال حاضر همه‌ی صندلی‌ها را دستی به مسافران تخصیص می‌دهند؛ این کار باید خودکار شود.

آن‌ها از _شما_ خواسته‌اند نرم‌افزاری بسازید که تخصیص صندلی مسافران را خودکار کند.
آن‌ها می‌خواهند نرم‌افزار شما هم از نظر حافظه بهینه باشد و هم سریع.

## 1. تولید حروف صندلی

Conda می‌خواهد حروف صندلی برای هواپیماهایش تولید کند.
هر هواپیما از ردیف‌هایی از صندلی تشکیل شده است.
هر ردیف _۴ صندلی_ دارد.
صندلی‌های هر ردیف همیشه با نام‌های `A`، `B`، `C` و `D` مشخص می‌شوند.
اولین صندلی ردیف `A` است، دومین صندلی ردیف `B` است و به همین ترتیب.
پس از رسیدن به `D`، باید دوباره از `A` شروع شود.

تابعی به اسم `generate_seat_letters(<number>)` پیاده‌سازی کنید که یک `int` می‌گیرد که مشخص می‌کند چند حرف صندلی باید تولید شود.
سپس تابع باید یک _تکرارپذیر_ از حروف صندلی برگرداند.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. تولید صندلی‌ها

Conda سیستمی می‌خواهد که بتواند تعداد مشخصی صندلی برای هواپیماهایش تولید کند.
هر هواپیما در هر ردیف _۴ صندلی_ دارد.
ردیف‌ها با اعداد مشخص می‌شوند، از `1` شروع می‌شوند و بالا می‌روند.
صندلی‌ها باید مرتب باشند، به این شکل: `1A`، `1B`، `1C`، `1D`، `2A`، `2B`، `2C`، `2D`، `3A`، `3B`، `3C`، `3D`، ...

این هم یک مثال:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     ردیف     |  5  | 21  |
| حرف صندلی |  A  |  D  |
|   نتیجه    | 5A  | 21D |

بسیاری از شرکت‌های هواپیمایی به خاطر خرافات میان مسافران، در پروازهایشان _ردیف_ شماره ۱۳ را ندارند.
Conda Airlines هم این رسم را رعایت می‌کند، پس مطمئن شوید که برای _ردیف_ شماره ۱۳ صندلی تولید _نکنید_.

تابعی به اسم `generate_seats(<number>)` پیاده‌سازی کنید که یک `int` می‌گیرد که مشخص می‌کند چند صندلی باید تولید شود.
سپس تابع باید یک _تکرارپذیر_ از صندلی‌های تولیدشده برگرداند.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. تخصیص صندلی‌ها به مسافران

حالا که تابعی دارید که صندلی تولید می‌کند، می‌توانید از آن برای تخصیص صندلی به مسافران استفاده کنید.

تابعی به اسم `assign_seats(<passengers>)` پیاده‌سازی کنید که یک `list` از اسم‌های مسافران می‌گیرد.
سپس تابع باید یک _دیکشنری_ برگرداند که `passenger` در آن _کلید_ و `seat_number` _مقدار_ است.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. کدهای بلیت

Conda Airlines می‌خواهد هر بلیت یک کد یکتا داشته باشد.
چون شرکت هواپیمایی بزرگی است، پروازهای زیادی دارد.
یعنی چندین پرواز با شماره‌ی صندلی یکسان وجود دارد.
آن‌ها می‌خواهند سیستمی بسازید که بلیتی یکتا بسازد که رشته‌ای _۱۲_ کاراکتری است.

این کد با `assigned_seat` شروع می‌شود و بعد از آن `flight_id` می‌آید.
بقیه‌ی کد با `0s` پر می‌شود.

تابعی به اسم `generate_codes(<seat_numbers>, <flight_id>)` پیاده‌سازی کنید که یک `list` از `seat_numbers` و یک `string` شامل شماره‌ی پرواز می‌گیرد.
سپس تابع باید یک `generator` برگرداند که `ticket_number` تولید می‌کند.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
