# دستورالعمل‌ها

دو لیست دلخواه `A` و `B` را در نظر بگیرید و مشخص کنید که:

- لیست `A` با لیست `B` برابر است؛ یا
- لیست `A` شامل لیست `B` است (یعنی `A` ابرلیست `B` است)؛ یا
- لیست `A` درون لیست `B` قرار دارد (یعنی `A` زیرلیست `B` است)؛ یا
- هیچ‌کدام از موارد بالا برقرار نیست؛ بنابراین لیست‌های `A` و `B` نابرابرند

به‌طور دقیق‌تر، لیست `A` با لیست `B` برابر است اگر هر دو لیست مقادیر یکسانی را با ترتیب یکسان داشته باشند.
لیست `A` زمانی ابرلیست `B` است که `A` زیردنباله‌ای از مقادیر برابر با `B` را در خود داشته باشد.
لیست `A` زمانی زیرلیست `B` است که `B` زیردنباله‌ای از مقادیر برابر با `A` را در خود داشته باشد.

مثال‌ها:

- اگر `A = []` و `B = []` (هر دو لیست خالی‌اند)، آنگاه `A` و `B` برابرند
- اگر `A = [1, 2, 3]` و `B = []`، آنگاه `A` ابرلیست `B` است
- اگر `A = []` و `B = [1, 2, 3]`، آنگاه `A` زیرلیست `B` است
- اگر `A = [1, 2, 3]` و `B = [1, 2, 3, 4, 5]`، آنگاه `A` زیرلیست `B` است
- اگر `A = [3, 4, 5]` و `B = [1, 2, 3, 4, 5]`، آنگاه `A` زیرلیست `B` است
- اگر `A = [3, 4]` و `B = [1, 2, 3, 4, 5]`، آنگاه `A` زیرلیست `B` است
- اگر `A = [1, 2, 3]` و `B = [1, 2, 3]`، آنگاه `A` و `B` برابرند
- اگر `A = [1, 2, 3, 4, 5]` و `B = [2, 3, 4]`، آنگاه `A` ابرلیست `B` است
- اگر `A = [1, 2, 4]` و `B = [1, 2, 3, 4, 5]`، آنگاه `A` و `B` نابرابرند
- اگر `A = [1, 2, 3]` و `B = [1, 3, 2]`، آنگاه `A` و `B` نابرابرند
