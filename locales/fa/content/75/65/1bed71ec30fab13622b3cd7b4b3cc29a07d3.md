# Entry API

API `entry` معمولاً اصطلاحی‌ترین شیوه برای دستکاری محتویات یک ساختار نقشه است. اما به شکلی غیرمعمول برای Rust، این API به صورت یک `trait` رسمیت پیدا نکرده است؛ فقط مجموعه‌ای از نوع‌ها و متدهاست که روی نوع‌های نقشه‌ی کتابخانه‌ی استاندارد پیاده‌سازی شده‌اند.

در اصل، متد `map.entry()` یک `enum` در اختیار شما می‌گذارد:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

کاربرد اصلی از متدهای دیگری می‌آید که روی همین `enum` پیاده‌سازی شده‌اند. برای مثال، اگر بخواهید مقدار متناظر با یک کلید مشخص را بگیرید و احتمالاً تغییر دهید و مقدار پیش‌فرض نوع آن هم مناسب باشد، کافی است این کار را بکنید:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

برای کاربردهایی مثل شمارنده، این کار زندگی را بسیار ساده می‌کند:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

اگر مقدار پیش‌فرض نوع برای کاربرد شما مناسب نیست، می‌توانید با `or_insert` مقدار پیش‌فرض ثابت خودتان را بدهید یا با `or_insert_with` آن را محاسبه کنید.

در برخی موارد، ممکن است بخواهید پیش از هر درج احتمالی، محاسبه‌ای روی یک مقدار موجود انجام دهید. در چنین مواردی، `and_modify` این امکان را می‌دهد. با این حال، این کاربرد تا حدی کم‌رواج است. کاربرد رایج‌تر `and_modify` جلوگیری از نیاز به ارجاع‌زدایی است:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

گاهی هم بهتر است خود `entry` را مستقیماً تطبیق دهید. این کار مجاز است:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

برای اطلاعات بیشتر، [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) و [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html) را ببینید.
