# دستورالعمل‌ها

در این تمرین، شما شماره‌های تلفن را تحلیل می‌کنید.

از شما خواسته شده است ۲ قابلیت را پیاده‌سازی کنید.

شماره‌های تلفنی که به روال‌ها داده می‌شوند، تضمین‌شده به شکل NNN-NNN-NNNN هستند، مثلاً 212-515-9876، و `null` نیستند.

## 1. تحلیل یک شماره‌ی تلفن

تحلیل شما باید ۳ بخش داده برگرداند:

1. نشانه‌ای از اینکه شماره کد تلفنی نیویورک دارد یا نه، یعنی 212 به‌عنوان ۳ رقم اول
2. نشانه‌ای از اینکه شماره جعلی است یا نه، با داشتن 555 به‌عنوان «کد پیشوند» در موقعیت‌های ۵ تا ۷ (شمارش از ۱)
3. ۴ رقم آخر شماره.

متد (ایستا) `PhoneNumber.Analyze()` را پیاده‌سازی کنید تا اطلاعات شماره‌ی تلفن را تولید کند.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. تشخیص اینکه یک شماره‌ی تلفن کد پیشوند جعلی (555) دارد یا نه

متد (ایستا) `PhoneNumber.IsFake()` را پیاده‌سازی کنید تا با استفاده از اطلاعات شماره‌ی تلفنی که در کار ۱ تولید شده است، تشخیص دهید که شماره جعلی است یا نه.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
