# مقدمه

«عملگر سه‌گانه» جایگزینی سبک و فشرده برای دستورهای ساده‌ی `if`/`else` است. معمولاً در دستورهای `return` به کار می‌رود، هرچند محدود به آن‌ها نیست؛ برای تصمیم‌گیری تنها به یک خط نیاز دارد و اگر عبارت `true` باشد مقدار سمت چپ و اگر `false` باشد مقدار سمت راست را برمی‌گرداند، به این شکل:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

بسیاری از عبارت‌های ساده‌ی `if`/`else` را می‌توان با عملگرهای سه‌گانه ساده‌تر کرد.
