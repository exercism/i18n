# دستورالعمل‌ها

فرض کنید در یک کارخانه کار می‌کنید و لازم می‌شود پیامی برای چاپ روی نشان‌های کارکنان بسازید. تصمیم می‌گیرید این تابع را در JavaScript پیاده‌سازی کنید.

هر نشان به `id` کارمند، `name` کارمند و همچنین بخشی که در آن کار می‌کند نیاز دارد.

## 1. متن نشان را بسازید

تابعی به اسم `printBadge` پیاده‌سازی کنید که متنی را که باید روی نشان چاپ شود برمی‌گرداند.

اسم کارمند همیشه داده می‌شود، اما شماره‌ی `id` کارمند و اسم بخش ممکن است `null` باشند. شماره‌ی `id` کارمند، اگر داده شده باشد، باید بین کروشه قرار بگیرد (مثلاً `[20]`).

نشان یک مالک نباید `id` یا `department` داشته باشد.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
