# پیوست دستورالعمل‌ها

هر سطر از شبکه به‌صورت یک کلمه نمایش داده می‌شود.

برای مثال،

```
    0 1 0
    1 0 0
    1 1 0
```

به‌صورت زیر نمایش داده می‌شود:

```
0x2
0x4
0x6
```

شبکه حداکثر ۳۲ ستون دارد.

## ثبات

| ثبات    | کاربرد       | نوع     | توضیحات                     |
| ------- | ------------ | ------- | --------------------------- |
| `$a0`   | ورودی        | عدد صحیح | تعداد سطرها                 |
| `$a1`   | ورودی        | عدد صحیح | تعداد ستون‌ها                |
| `$a2`   | ورودی        | آدرس    | شبکه برای نسل فعلی          |
| `$a3`   | ورودی/خروجی  | آدرس    | شبکه برای نسل بعدی          |
| `$t0-9` | موقت         | هر      | برای ذخیره‌سازی موقت استفاده می‌شود |
