# تست

همه‌ی تمرین‌ها از framework [Pester][pester] برای ماک کردن و تست کردن استفاده می‌کنند.
همه‌ی تست‌ها در فایلی به اسم `[Exercise].tests.ps1` قرار دارند، همان‌طور که استاندارد framework Pester است.
اگر در پوشه‌ی درست باشید (یعنی همان پوشه‌ای که `[Exercise].ps1` و `[Exercise].tests.ps1` در آن قرار دارند).
می‌توانید تست‌ها را از PowerShell با فراخوانی دستور زیر اجرا کنید:

``` PowerShell
Invoke-Pester
```

این دستور همه‌ی فایل‌های `.tests.ps1` را که در آن پوشه پیدا می‌کند اجرا می‌کند.

اگر از شل دیگری غیر از PowerShell استفاده می‌کنید، می‌توانید تست‌ها را با فراخوانی دستور زیر اجرا کنید:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## اجرای تست‌ها در Visual Studio Code

باید مطمئن شوید که [افزونه‌ی powershell][extension] را در Visual Studio Code نصب کرده‌اید.

می‌توانید تست‌ها را در Visual Studio Code به چند روش اجرا کنید:

- اجرای اسکریپت `.Tests.ps1` از منوی Debug. کلیدهای میانبر عبارت‌اند از: `F5` یا `Shift + F5`
- از داخل خود ویرایشگر، با کلیک روی پیوند «Run Tests» در بالای کلیدواژه‌ی `Describe` در کد تست
- پیکربندی یک Task برای اجرای framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
