# راهنما

اگر به مشکلی برخوردید، برای گرفتن کمک می‌توانید از یکی از این منابع استفاده کنید:

- [وب‌سایت CoffeeScript](http://coffeescript.org)
- [/r/coffeescript](https://www.reddit.com/r/coffeescript) ساب‌ردیت CoffeeScript است.
- از [StackOverflow](http://stackoverflow.com/questions/tagged/coffeescript) می‌توانید برای جست‌وجوی مشکلتان استفاده کنید و ببینید آیا پیش‌تر به آن پاسخ داده شده است یا نه. همچنین می‌توانید پرسش بپرسید و به پرسش‌ها پاسخ دهید.
