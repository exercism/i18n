# مقدمه

در مفهوم «جفت‌ها و دیکشنری‌ها» مبانی نوع دیکشنری در Julia بررسی شد.

از آنجا که `Dict`ها یک نوع داده‌ی مجموعه‌ای مهم و پرکاربرد هستند، توابع زیادی هم برای کار با آن‌ها وجود دارد.

## گرفتن درایه‌ها

ساده‌ترین راه برای بازیابی یک درایه، استفاده از کلید است (مثل بسیاری از زبان‌ها). اما درخواست کلیدی که وجود ندارد، منجر به `KeyError` می‌شود.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

می‌توانیم پیش از تلاش برای بازیابی، وجود کلید را بررسی کنیم (مثلاً با `haskey(d, 4)`)؛ اما گاهی مفید است که فقط یک مقدار پیش‌فرض برای کلیدهای ناموجود بگیریم.

برای این کار، تابع `get()` و گونه‌ی تغییردهنده‌ی آن یعنی `get!()` را داریم. تفاوت این دو در این است که آیا کلید «ناموجود» به `Dict` اضافه می‌شود یا نه.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

در مفهوم قبلی دیدیم که `delete!()` یک درایه را با کلیدش حذف می‌کند. این کار را می‌توان با بازیابی مقدار ترکیب کرد و از تابع `pop!()` استفاده کرد.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## پیمایش

پیمایش روی یک `Dict` به‌طور پیش‌فرض جفت‌های `key => value` را تولید می‌کند. به اجزای آن می‌توان با نام‌گذاری معمول `.first` و `.second` دسترسی داشت.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

اغلب می‌خواهیم فقط از کلیدها یا فقط از مقدارها استفاده کنیم، که کار ساده‌ای است.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## ادغام

ترکیب دو `Dict` می‌تواند مفید باشد، اما باید روشن باشد که می‌خواهیم با کلیدهایی که در بیش از یک ورودی وجود دارند چه کنیم.

توابع `merge()` و `merge!()` هر تعداد دلخواهی از `Dict`های داده‌شده را به ترتیب از چپ به راست ترکیب می‌کنند.

مقدار کلیدهای موجود به‌سادگی بازنویسی می‌شود، بنابراین `Dict` سمت راست «برنده» می‌شود.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

توابع `mergewith()` و `mergewith!()` به ما اجازه می‌دهند یک تابع را به عنوان آرگومان اول بدهیم تا مشخص کنیم کلیدهای تکراری چگونه باید ادغام شوند. جمع کردن یک مثال ساده است.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

توجه کنید که توابع `mergewith` مثال خوبی از کاربرد «توابع مرتبه‌بالا» در عمل هستند.
