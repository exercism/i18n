# درباره

در Swift نمی‌توانید با یک عدد صحیح (مثل `string[3]`) یک رشته را ایندکس کنید. چون رشته‌های Swift از کاراکترهای یونیکد با طول متغیر تشکیل شده‌اند، برای یافتن یک کاراکتر باید کاراکترهای پیش از آن را پیمایش کنید.

برای دسترسی به یک کاراکتر در موقعیت مشخص، باید ایندکسی از نوع `String.Index` محاسبه کنید. به این ایندکس‌ها «ایندکس مات» می‌گویند، چون ساختار داخلی‌شان را Swift مدیریت می‌کند و مستقیماً به‌صورت اعداد صحیح خام دستکاری نمی‌شوند:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
