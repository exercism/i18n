# کمک

اگر به مشکل خوردید، برای گرفتن کمک می‌توانید از یکی از منابع زیر استفاده کنید:

- [/r/javascript](https://www.reddit.com/r/javascript) ساب‌ردیت Javascript است.
- از [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) می‌توانید برای جست‌وجوی مشکل خودتان و دیدن این‌که آیا پیش‌تر به آن پاسخ داده شده است یا نه استفاده کنید. همچنین می‌توانید پرسش مطرح کنید و به پرسش‌ها پاسخ دهید.
- [Github issue tracker](https://github.com/exercism/javascript/issues) جایی است که توسعه و نگهداری تمرین‌های Javascript در Exercism را پیگیری می‌کنیم. اما اگر هیچ‌کدام از پیوندهای بالا به شما کمک نکرد، راحت باشید و این‌جا یک issue ثبت کنید.
