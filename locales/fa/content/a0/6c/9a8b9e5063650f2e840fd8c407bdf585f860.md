# درباره

**«بستار»** یک الگوی برنامه‌نویسی [در Clojure][clojure-guide-closures] است که امکان می‌دهد از متغیرهای یک [حوزه‌ی واژگانی][wiki-lexical-scope] بیرونی درون یک تابع استفاده شود. Clojure از بستارها به‌طور شفاف پشتیبانی می‌کند و اغلب بدون آنکه بدانیم چه هستند به کار می‌روند.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## بستارها برای حفظ وضعیت و انتقال مقادیر

استفاده از یک `atom` این امکان را می‌دهد که مقداری وضعیت حفظ شود:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

هر بار فراخوانی `increment` شمارنده‌ی آن را یک واحد افزایش می‌دهد:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
