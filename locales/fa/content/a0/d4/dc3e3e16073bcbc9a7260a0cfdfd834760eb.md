# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات     | کاربرد       | نوع     | توضیح                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | آدرس    | رشته‌ی ورودی پایان یافته با `null`  |
| `$a1`    | ورودی        | عدد صحیح | کلید جابه‌جایی                     |
| `$a2`    | ورودی/خروجی  | آدرس    | رشته‌ی نتیجه پایان یافته با `null` |
| `$t0-9`  | موقت         | هر نوع  | برای ذخیره‌سازی موقت          |
