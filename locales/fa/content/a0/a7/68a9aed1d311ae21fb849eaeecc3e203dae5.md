# راهنمایی‌ها

## 1. تقسیم یک رشته به خطوط جداگانه

- Swift یک [متد][nsstring-components-docs] برای تقسیم یک رشته به آرایه‌ای از رشته‌ها با استفاده از یک جداکننده‌ی داده‌شده دارد.

## 2. درِ جلو

- نگهبان شعری می‌خواند و شما باید شعر را به خطوط جداگانه تقسیم کنید؛ برای این کار می‌توانید از تابعی که از قبل وجود دارد استفاده کنید.
- می‌توانید از یک حلقه‌ی For برای پیمایش خطوط شعر استفاده کنید.
- می‌توانید از ویژگی `first` یک رشته برای گرفتن اولین کاراکتر یک رشته استفاده کنید.
- برای ذخیره‌ی اولین کاراکتر هر خط، می‌توانید از یک آرایه از کاراکترها یا یک رشته استفاده کنید.

## 3. درِ پشت

- نگهبان شعری می‌خواند و شما باید شعر را به خطوط جداگانه تقسیم کنید؛ برای این کار می‌توانید از تابعی که از قبل وجود دارد استفاده کنید.
- می‌توانید از یک حلقه‌ی For برای پیمایش خطوط شعر استفاده کنید.
- می‌توانید از ویژگی `last` یک رشته برای گرفتن آخرین کاراکتر یک رشته استفاده کنید.
- برای ذخیره‌ی آخرین کاراکتر هر خط، می‌توانید از یک آرایه از کاراکترها یا یک رشته استفاده کنید.

## 4. اتاق مخفی

- نگهبان شعری می‌خواند و شما باید شعر را به خطوط جداگانه تقسیم کنید؛ برای این کار می‌توانید از تابعی که از قبل وجود دارد استفاده کنید.
- می‌توانید از یک حلقه‌ی For استفاده کنید که روی طول خطوط شعر پیمایش می‌کند.
- Swift یک [متد][indexing] برای گرفتن کاراکتر در یک اندیس مشخص از یک رشته دارد.
- Swift یک [متد][uppercased] برای تبدیل یک رشته به حروف بزرگ دارد.
