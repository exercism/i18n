# درباره

`when` کلیدواژه‌ی فیلتر کردن استثناهاست. این کلیدواژه بعد از دستور `catch` قرار می‌گیرد و می‌تواند یک عبارت منطقی بگیرد که هر مقداری را که در آن لحظه در دسترس باشد در بر داشته باشد. لازم نیست این مقادیر فقط اعضای خود استثنا باشند. اگر نوع استثنا مطابقت داشته باشد و عبارت به «درست» ارزیابی شود، بلوک مربوط به همان دستور `catch` اجرا می‌شود؛ در غیر این صورت، دستور `catch` بعدی، اگر وجود داشته باشد، بررسی می‌شود.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- این مقاله‌ی [Exception filters][exception-filters] نشان می‌دهد چطور استثناها را فیلتر کنید.

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
