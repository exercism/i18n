# مقدمه

در Haxe، یک **آرایه** مجموعه‌ای از عنصرها است که (معمولاً) از یک نوع هستند. سه راه برای ساختن آرایه در Haxe وجود دارد؛ یا با سازنده یا با نحوه‌ی نگارش اعلان. در Haxe، اندیس اولین عنصر یک آرایه صفر است:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

برای ساختن آرایه با استفاده از سازنده، باید نوع عنصرهایی را که قرار است در آرایه گنجانده شوند، پاس بدهید:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

اگر بخواهیم یک آرایه چند نوع عنصر مختلف را در خود جای دهد، نوع `Dynamic` را به مشخص‌کننده‌ی نوع اضافه می‌کنیم:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
