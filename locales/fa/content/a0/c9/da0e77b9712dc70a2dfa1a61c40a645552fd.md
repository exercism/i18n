# دستورالعمل‌ها

فروشگاهی لوازم خانگی به نام «Tech Palace» در همین نزدیکی است.
صاحب فروشگاه به‌تازگی یک نمایشگر بزرگ نصب کرده است تا از آن برای پیام‌های تبلیغاتی استفاده کند و وقتی مشتریان در ورودی کارت وفاداری‌شان را اسکن می‌کنند، سلام ویژه‌ای نشان دهد.
نمایشگر از تعداد زیادی چراغ کوچک LED تشکیل شده است و می‌تواند چندین خط متن را نشان دهد.

صاحب فروشگاه برای کدی که برای تولید متن نمایشگر جدید استفاده می‌شود به کمک شما نیاز دارد.

## 1. ساخت پیام خوش‌آمد

<!-- markdownlint-disable-next-line MD038 -->
برای بیشتر مشتریانی که کارت وفاداری‌شان را اسکن می‌کنند، صاحب فروشگاه می‌خواهد روی نمایشگر `Welcome to the Tech Palace, ` و پس از آن اسم مشتری را با حروف بزرگ ببیند.

تابع `welcome_message` را پیاده‌سازی کنید که اسم مشتری را به‌عنوان یک آرگومان رشته‌ی کوتاه (`felt252`) می‌پذیرد و پیام موردنظر را به‌عنوان یک `ByteArray` برمی‌گرداند.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. افزودن یک حاشیه‌ی شیک

برای مشتریان وفاداری که خرید زیادی از فروشگاه می‌کنند، صاحب فروشگاه می‌خواهد نمایشگر پیام خوش‌آمد شیک‌تر باشد؛ به این صورت که یک خط ستاره پیش و پس از پیام خوش‌آمد اضافه شود.
او هنوز مطمئن نیست که هر خط باید چند ستاره داشته باشد، بنابراین می‌خواهد این مقدار قابل تنظیم باشد.

تابع `add_border` را بنویسید که یک پیام خوش‌آمد (از نوع `ByteArray`) و تعداد ستاره‌های هر خط (از نوع `u32`) را به‌عنوان آرگومان می‌پذیرد.
این تابع باید یک `ByteArray` برگرداند که از ۳ خط تشکیل شده است: یک خط با تعداد ستاره‌های موردنظر، سپس پیام خوش‌آمد همان‌طور که ورودی بوده، و سپس یک خط ستاره‌ی دیگر.

```rust
add_border("Welcome!", 10)
```

باید خروجی زیر را برگرداند:

```bash
**********
Welcome!
**********
```

## 3. پاک‌سازی پیام‌های تبلیغاتی قدیمی

پیش از نصب این نمایشگر جدید، فروشگاه یک نمایشگر مشابه داشت که فقط می‌توانست خط‌های ثابت و غیرقابل‌تنظیم را نشان دهد.
صاحب فروشگاه می‌خواهد برخی از پیام‌های تبلیغاتی قدیمی را روی نمایشگر جدید دوباره استفاده کند.
اما داده‌ها از قبل شامل یک حاشیه‌ی ستاره‌ای و چند فاصله‌ی ناخواسته است.
وظیفه‌ی شما این است که پیام‌ها را پاک‌سازی کنید تا بتوان دوباره از آن‌ها استفاده کرد.

تابع `clean_up_message` را پیاده‌سازی کنید که پیام تبلیغاتی قدیمی را به‌عنوان یک `ByteArray` می‌پذیرد.
این تابع باید ابتدا همه‌ی ستاره‌ها را از متن حذف کند و سپس فاصله‌های ابتدا و انتهای متن باقی‌مانده را حذف کند.
سپس تابع باید پیام پاک‌سازی‌شده را برگرداند.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
