همه‌ی فراخوانی‌های صریح `Boolean(...)` را حذف کنید.

در JavaScript، نتیجه‌ی یک عبارت نیازی به تبدیل به یک نوع خاص ندارد.
برای مثال، نتیجه‌ی یک عبارت دودویی را می‌توان همان‌طور که هست برگرداند و نیازی به فراخوانی دیگری ندارد تا آن را به یک `boolean` تبدیل کند.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
