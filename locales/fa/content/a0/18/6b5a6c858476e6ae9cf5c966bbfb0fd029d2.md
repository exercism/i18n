# منابع

منابع رایگان و عالی آنلاین زیادی برای Lua وجود دارد، از جمله:

1.  [lua.org][8]
2.  یک معرفی مفصل، معتبر و به‌شدت پیشنهادی از همه‌ی جنبه‌های برنامه‌نویسی Lua، به قلم معمار ارشد Lua: [Programming in Lua, by Roberto Ierusalimschy][6]
3.  برای تعریف رسمی زبان Lua، به [Lua 5.4 Reference Manual][7] نوشته‌ی R. Ierusalimschy، L. H. de Figueiredo، W. Celes مراجعه کنید.
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  هرچند ظاهر زیبایی ندارد، ویکی [lua-users.org][14] اطلاعات و دانش مفید زیادی در خود دارد
7.  چند گزینه برای لینت کردن کد
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  پیاده‌سازی‌های Language Server Protocol برای Lua
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
