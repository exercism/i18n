# مقدمه

## ماژول

«ماژول» روشی برای گروه‌بندی کدهای مرتبط است تا از تداخل اسم‌ها جلوگیری شود و به‌طور کلی در همه‌ی پایگاه‌های کد به‌جز پیش‌پاافتاده‌ترین آن‌ها وجود دارد.

نحوه‌ی نگارش آن به این صورت است:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

بیرون از دامنه‌ی ماژول، به انواعی که داخل ماژول قرار دارند با قرار دادن `::` به‌عنوان پیشوند قبل از اسم نوع ارجاع داده می‌شود. در عوض و معمولاً رایج‌تر، می‌توانید یک دستور `use` را در بالای فایل (یا داخل یک ماژول) قرار دهید و سپس از انواع بدون پیشوند استفاده کنید. در همان ماژول نیازی نیست اسم نوع را با مسیر کامل بنویسید.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

می‌توانید برای یک ماژول یا یک نوع با نحوه‌ی نگارش `use core::array::ArrayTrait as Arr;` یک «نام مستعار» تعریف کنید و سپس از آن نام مستعار هر جایی که می‌توان از ماژول یا نوع استفاده کرد، استفاده کنید.
