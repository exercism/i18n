# پیوست دستورالعمل‌ها

## کار با تاریخ‌ها در Prolog

پشتیبانی توکار Prolog از تاریخ‌ها [تا حدی ابتدایی][built-in-dates-support] است. روشی بسیار بهتر برای کار با تاریخ‌ها استفاده از [بسته‌ی `date_time`][date_time-package] است.

### نصب بسته‌ی `date_time`

اگر نسخه‌ی Swipl نصب‌شده‌ی شما به‌روز باشد، می‌توانید بسته را با اجرای این دستور نصب کنید:

```bash
swipl pack install date_time
```

اگر این روش جواب نداد، می‌توانید این را اجرا کنید:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
اگر از ویرایشگر آنلاین استفاده می‌کنید، نیازی نیست چیزی را به‌صورت دستی نصب کنید.
~~~~

### استفاده از بسته‌ی `date_time`

کد زیر را برای استفاده از بسته‌ی `date_time` به بالای فایل راه‌حل خود اضافه کنید:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
نکته: [منبع بسته‌ی `date_time`][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] به‌خوبی مستند شده است و می‌تواند کمک بزرگی باشد!
~~~~
