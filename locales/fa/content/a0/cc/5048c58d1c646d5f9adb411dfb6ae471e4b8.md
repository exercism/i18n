# مقدمه

زبان‌های زیادی روشی مانند `null` یا `none` دارند تا مقداری ناموجود را نشان دهند.
چون R برای کار با حجم زیادی از داده‌ها (که اغلب به‌هم‌ریخته‌اند) طراحی شده است، چند شکل مختلف «هیچ‌بودن» دارد.

هدف کلی این است که مقادیر گم‌شده یا مشکوک به‌محض برخورد، علامت‌گذاری شوند و سپس کار بدون اینکه استثنایی ایجاد شود ادامه یابد.

## NULL

اگر مقداری واقعاً وجود نداشته باشد، با `NULL` نمایش داده می‌شود. این احتمالاً به آنچه C یا Python انجام می‌دهند نزدیک‌ترین است.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

در بسیاری از زمینه‌ها، مقادیر `NULL` به‌سادگی نادیده گرفته می‌شوند:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

برای موقعیت‌هایی که مقدار وجود دارد ولی نمی‌دانیم چیست، از `NA` استفاده می‌شود. برای نمونه، هنگام شمارش خودروهایی که در جاده‌ای در حال حرکت‌اند، ممکن است ناظران انسانی بیمار شوند یا حسگرهای خودکار از کار بیفتند، اما ترافیک همچنان در جریان باشد.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

پس `NA` یک جای‌نگهدار است که به انسان‌ها هشدار می‌دهد باید تصمیم بگیرند چگونه با آن برخورد کنند.

## NaN

`NaN` که کوتاه‌شده‌ی «Not a Number» است، در موقعیت‌هایی که انتظار می‌رفت یک عدد باشد، نشان‌دهنده‌ی یک مشکل محاسباتی است.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

این تنها حالت ممکن برای محاسبات «نامعتبر» نیست.
تقسیم بر صفر، برای صورت ناصفر، `Inf` یا `-Inf` برمی‌گرداند، بدون آنکه خطایی رخ دهد.

```R
1 / 0
#> [1] Inf
```

## بردار خالی

شاید شگفت‌آور باشد که R هیچ روش استانداردی برای بررسی خالی‌بودن ندارد.

حتی ساختن یک بردار خالی هم کاملاً واضح نیست.
در بخشی پیش‌تر دیدیم که `c()` بدون آرگومان `NULL` برمی‌گرداند، نه یک بردار.

```R
is.vector(c())
#> [1] FALSE
```

توابعی مانند `logical()` یا `integer()` آرگومانی می‌گیرند که طول دلخواه را مشخص می‌کند و می‌تواند صفر باشد.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

همچنین می‌توانیم یک بردار بسازیم و سپس همه‌ی عنصرهایش را حذف کنیم، همان‌طور که در [مفهوم بردار][concept-vectors] توضیح داده شده است.
نتیجه، برداری با طول صفر از نوع مناسب است.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
