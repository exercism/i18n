# دستورالعمل‌ها

در این تمرین قرار است code بنویسید تا به شما کمک کند یک لازانیای عالی را از کتاب آشپزی محبوبتان بپزید.

چهار کار دارید که همه به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار در فر را بر حسب دقیقه تعریف کنید

«متد `expectedMinutesInOven()` را تعریف کنید که هیچ پارامتری نمی‌گیرد و برمی‌گرداند که لازانیا باید چند دقیقه در فر بماند. بر اساس کتاب آشپزی، زمان مورد انتظار در فر بر حسب دقیقه 40 است:

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. زمان باقی‌مانده در فر را بر حسب دقیقه محاسبه کنید

«متد `remainingMinutesInOven()` را تعریف کنید که تعداد دقیقه‌هایی را که لازانیا تا این لحظه در فر بوده است به عنوان پارامتر می‌گیرد و بر اساس زمان مورد انتظار در فر بر حسب دقیقه از کار قبلی، برمی‌گرداند که لازانیا باید چند دقیقه‌ی دیگر در فر بماند.

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

«متد `preparationTimeInMinutes()` را تعریف کنید که تعداد لایه‌هایی را که به لازانیا اضافه کرده‌اید به عنوان پارامتر می‌گیرد و برمی‌گرداند که چند دقیقه صرف آماده‌سازی لازانیا کرده‌اید، با این فرض که آماده‌سازی هر لایه ۲ دقیقه طول می‌کشد.

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. مجموع زمان کار را بر حسب دقیقه محاسبه کنید

«متد `totalTimeInMinutes()` را تعریف کنید که دو پارامتر می‌گیرد: پارامتر اول تعداد لایه‌هایی است که به لازانیا اضافه کرده‌اید و پارامتر دوم تعداد دقیقه‌هایی است که لازانیا در فر بوده است. این تابع باید برمی‌گرداند که در مجموع چند دقیقه روی پخت لازانیا کار کرده‌اید، که مجموع زمان آماده‌سازی بر حسب دقیقه به‌علاوه‌ی زمانی است که لازانیا تا این لحظه در فر گذرانده است.

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
