# مقدمه

در C# دو نوع متفاوت عدد وجود دارد:

- «اعداد صحیح»: اعدادی که هیچ رقمی بعد از جداکننده‌ی اعشار ندارند (اعداد کامل). مثال‌ها: `-6`، `0`، `1`، `25`، `976` و `500000`.
- «اعداد اعشاری»: اعدادی که صفر یا چند رقم بعد از جداکننده‌ی اعشار دارند. مثال‌ها: `-2.4`، `0.1`، `3.14`، `16.984025` و `1024.0`.

رایج‌ترین نوع‌های عددی در C#، `int` و `double` هستند. یک `int` عدد صحیح ۳۲بیتی است و یک `double` عدد اعشاری ۶۴بیتی.

محاسبات با عملگرهای حسابی استاندارد انجام می‌شود. مقایسه‌ی اعداد هم با عملگرهای استاندارد مقایسه‌ی عددی و عملگرهای تساوی (`==`) و نامساوی (`!=`) انجام می‌شود.

در C# دو نوع تبدیل عددی وجود دارد:

1. تبدیل‌های ضمنی: هیچ داده‌ای از دست نمی‌رود و به شکل نوشتن اضافه‌ای نیاز نیست.
2. تبدیل‌های صریح: ممکن است داده از دست برود و به شکل نوشتن اضافه‌ای، یعنی یک «کست»، نیاز است.

از آنجا که یک `int` دقت کمتری از یک `double` دارد، تبدیل از `int` به `double` ایمن است و بنابراین یک تبدیل ضمنی به شمار می‌رود. اما تبدیل از `double` به `int` می‌تواند به از دست رفتن داده منجر شود، پس به یک تبدیل صریح نیاز دارد.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
