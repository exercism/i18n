# مقدمه

C# زبانی با نوع ایستا است، یعنی همه‌چیز در زمان کامپایل نوع دارد. به اختصاص دادن یک مقدار به یک اسم، تعریف متغیر می‌گویند. متغیر را می‌توان یا با تعیین صریح نوعش تعریف کرد، یا با اجازه دادن به کامپایلر C# که نوعش را بر اساس مقدار اختصاص‌یافته استنتاج کند (که به آن _استنتاج نوع_ می‌گویند). بنابراین، دو تعریف متغیر زیر معادل هستند:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

مقدار یک متغیر با عملگر `=` به‌روزرسانی می‌شود. پس از تعریف، نوع متغیر هرگز تغییر نمی‌کند.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# یک [زبان شیءگرا][object-oriented-programming] است و لازم می‌داند که همه‌ی توابع در یک _کلاس_ تعریف شوند. برای تعریف یک کلاس از کلیدواژه‌ی `class` استفاده می‌شود. اشیاء (یا _نمونه‌ها_) با استفاده از کلیدواژه‌ی `new` ساخته می‌شوند.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

به تابعی که داخل یک کلاس قرار دارد، _متد_ می‌گویند. هر متد می‌تواند صفر یا چند پارامتر داشته باشد. نوع همه‌ی پارامترها باید صریحاً مشخص شود؛ برای پارامترها استنتاج نوع وجود ندارد. به همین ترتیب، نوع بازگشتی هم باید صریحاً مشخص شود. مقدارها با استفاده از کلیدواژه‌ی `return` از متدها برگردانده می‌شوند. برای اینکه کدی در فایل‌های دیگر بتواند یک متد را فراخوانی کند، باید اصلاح‌کننده‌ی دسترسی `public` اضافه شود.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

متدها با نحو نقطه (`.`) روی یک نمونه فراخوانی می‌شوند: اسم متدی که باید فراخوانی شود مشخص می‌شود و برای هر یک از پارامترهای متد، آرگومان مربوط به آن ارسال می‌شود. آرگومان‌ها می‌توانند به‌صورت اختیاری اسم پارامتر متناظر را هم مشخص کنند.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

محدوده در C# بین کاراکترهای `{` و `}` تعریف می‌شود.

C# از دو نوع کامنت پشتیبانی می‌کند. کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
