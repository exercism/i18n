# مقدمه

توابع بازگشتی توابعی هستند که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید حداقل یک «حالت پایه» و حداقل یک «حالت بازگشتی» داشته باشد.

حالت پایه مقداری را برمی‌گرداند بدون آنکه تابع را دوباره فراخوانی کند.
حالت بازگشتی تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که دیر یا زود با حالت پایه مطابقت کند.

در Elm، توابع بازگشتی معمولاً با تطبیق الگو به کمک عبارات `case` یا چند بند تابع تعریف می‌شوند.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## حلقه با بازگشت

به دلیل تغییرناپذیری، حلقه‌ها در Elm متفاوت از زبان‌های امری نوشته می‌شوند.
برای نمونه، حلقه‌ها معمولاً به این شکل هستند:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

در یک زبان تابعی مانند Elm، تغییر دادن متغیرها ممکن نیست.
بنابراین، حلقه‌ها را باید با بازگشت پیاده‌سازی کرد.

معادل یک حلقه‌ی `for` در Elm به این شکل خواهد بود:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

در عمل، پیمایش فهرست‌ها و سایر ساختارهای داده در Elm بیشتر وقت‌ها با توابع ماژول `List` انجام می‌شود؛ توابعی مانند `List.map`، `List.filter` و `List.foldl`.
در پشت‌صحنه، این توابع با بازگشت پیاده‌سازی شده‌اند.
