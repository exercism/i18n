# Case

[Case][case] (که در زبان‌های دیگر اغلب به آن switch می‌گویند) گونه‌ای از عبارت کنترلی است، مانند if-else.
Case امکان زنجیره‌کردن چندین دستور if-else-if را می‌دهد و در عین حال که کنترل جریان را فراهم می‌کند، می‌تواند خواناتر باشد.

یک case با کلیدواژه‌ی `case` تعریف می‌شود که پس از آن یک عبارت اختیاری می‌آید.
سپس برای هر case، از کلیدواژه‌ی `when` استفاده می‌شود که بعد از آن عبارتی می‌آید که با عبارت case مقایسه می‌شود.
کلیدواژه‌ی `when` نباید نسبت به کلیدواژه‌ی `case` تورفتگی داشته باشد.
بعد از کلیدواژه‌ی `when` کدی قرار می‌گیرد که باید در صورت تطابق عبارت case با عبارت when اجرا شود.
Case یک دستور `else` اختیاری هم می‌پذیرد که اگر هیچ case دیگری مطابقت نکند اجرا می‌شود.

ابتدا عبارت case ارزیابی می‌شود و سپس با هر یک از عبارت‌های `when` مقایسه می‌شود.
این مقایسه با عملگر تساوی case (`===`) انجام می‌شود.

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## عملگر تساوی case (`===`)

عملگر تساوی case (`===`) کمی با عملگر برابری (`==`) تفاوت دارد.
این عملگر بررسی می‌کند که آیا سمت راست عضوی از مجموعه‌ای است که سمت چپ توصیف می‌کند.
یعنی جای هر عملوند اهمیت دارد.
نحوه‌ی کار آن به نوع سمت چپ بستگی دارد؛ برای مثال، `Range` بررسی می‌کند که آیا سمت راست درون آن بازه قرار دارد و `Object` بررسی می‌کند که آیا سمت راست نمونه‌ای از `Object` است.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case با چند عبارت

Case اجازه می‌دهد در یک case چند عبارت مطابقت داده شود، به این صورت که هر مقدار ممکن با کاما از بقیه جدا می‌شود.
اگر هر کدام از عبارت‌ها مطابقت کند، کد اجرا می‌شود.
این زمانی مفید است که بخواهید یک case چند مقدار ممکن داشته باشد.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Case با بازه‌ها

Case می‌تواند بررسی کند که آیا یک مقدار در یک بازه قرار دارد.
این کار با قرار دادن یک بازه به عنوان عبارت when انجام می‌شود.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case بدون عبارت case

وقتی نیازی به عبارت case نباشد، می‌توان آن را حذف کرد.
با این کار هر عبارت case از نظر درست بودن ارزیابی می‌شود.
و باعث می‌شود مانند دستورهای if-else-if رفتار کنند.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## when تک‌خطی

Ruby امکان نوشتن دستورهای case در یک خط را فراهم می‌کند.
این زمانی به کار می‌آید که یک دستور ساده‌ی تک‌خطی دارید.
دستور when تک‌خطی به شکل `when <expression> then <statement>` نوشته می‌شود.
و اگر در دستور else به کار برود، به شکل `else <statement>` نوشته می‌شود.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Case با نوع‌ها

Case امکان مطابقت با نوع‌ها را هم می‌دهد.
این زمانی مفید است که بخواهید بسته به نوع یک متغیر رفتار متفاوتی داشته باشید.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
