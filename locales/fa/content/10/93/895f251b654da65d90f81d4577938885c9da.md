# دستورالعمل‌ها

الن دارد بازی‌ای می‌سازد که در آن بازیکن باید با بیگانه‌ها بجنگد.
او تازه با برنامه‌نویسی شیءگرا (OOP) آشنا شده و مشتاق است از آنچه استفاده از `classes` می‌تواند به برنامه‌اش اضافه کند، بهره ببرد.

الن خوشحال است که شما پیشنهاد کمک داده‌اید و برنامه‌نویسی بیگانه‌هایی را که بازیکن باید با آن‌ها بجنگد به شما سپرده است.


## 1. ساختن کلاس Alien

کلاس Alien را با یک سازنده تعریف کنید که دو پارامتر `<x_coordinate>` و `<y_coordinate>` را می‌پذیرد و آن‌ها را در متغیرهای نمونه‌ای `x_coordinate` و `y_coordinate` قرار می‌دهد.
هر بیگانه هم با سطح سلامتی ۳ شروع می‌کند، پس متغیر `health` هم باید مقداردهی اولیه شود.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

حالا هر بیگانه باید بتواند موقعیت و سلامتی خودش را به‌طور داخلی ردیابی کند.

## 2. متد `hit`

الن دوست دارد `class` بیگانه متدی به اسم `hit` داشته باشد که هنگام فراخوانی، سلامتی یک شیء بیگانه را ۱ واحد کم می‌کند.
به این ترتیب، او می‌تواند به‌سادگی `<alien>.hit()` را فراخوانی کند و مجبور نباشد سلامتی بیگانه را دستی تغییر دهد.
اینکه `hit()` امتیازهای سلامتی را _تا_ صفر کم کند یا _زیر_ صفر، به خودتان بستگی دارد.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. متد `is_alive`

متوجه می‌شوید که اگر سلامتی مدام کم شود، احتمالاً در نقطه‌ای به ۰ می‌رسد (_یا حتی کمتر!_).
ایده‌ی خوبی است که متد `is_alive` را اضافه کنید تا الن بتواند سریع آن را فراخوانی کند و بررسی کند که بیگانه... خب... زنده است یا نه. 😉
`<alien>.is_alive()` باید یک «مقدار منطقی» برگرداند.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. متد `teleport`

در بازی الن، بیگانه‌ها توانایی دورنوردی دارند!
باید متدی به اسم `teleport` بنویسید که دو مقدار تازه‌ی `x_coordinate` و `y_coordinate` می‌گیرد و مختصات بیگانه را بر همان اساس تغییر می‌دهد.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. متد `collision_detection`

واضح است که اگر بتوان به بیگانه‌ها ضربه زد، آن‌ها باید بتوانند تشخیص دهند چه زمانی چنین برخوردی رخ داده است.
با این حال، الگوریتم‌های تشخیص برخورد می‌توانند پیچیده باشند و شما هنوز نمی‌دانید چطور یکی را پیاده‌سازی کنید.
الن گفته است که بعداً خودش این کار را انجام می‌دهد، اما دوست دارد متد `collision_detection` در کلاس بماند تا یادآوری باشد برای تکمیل این قابلیت.
این متد باید نوعی متغیر بگیرد (احتمالاً یک شیء دیگر)، اما همین تنها چیزی است که می‌دانید.
باید مطمئن شوید که قرار دادن تعریف این متد در کلاس، هنگام فراخوانی هیچ خطایی ایجاد نمی‌کند:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. شمارنده‌ی بیگانه‌ها

الن با یک درخواست تازه پیش شما برگشته است.
او می‌خواهد بداند در طول عمر بازی چند بیگانه ساخته شده است.
به گفته‌ی او، این موضوع به سیستم امتیازدهی مربوط است.

برای مثال:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. ساختن لیستی از بیگانه‌ها

الن از کارهایی که تا حالا انجام داده‌اید خیلی خوشش آمده، اما یک خواهش دیگر هم دارد.
او می‌خواهد یک تابع مستقل (_بیرون از کلاس `Alien()`_) داشته باشد که با گرفتن لیستی از موقعیت‌ها (به شکل `tuples`)، یک `list` از اشیاء `Alien()` بسازد.

برای مثال:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
