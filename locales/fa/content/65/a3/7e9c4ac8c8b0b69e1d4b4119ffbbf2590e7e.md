# مقدمه

در Gleam می‌توان از عبارت `case` برای اجرای شرطی کد استفاده کرد. با یک عبارت case می‌توان یک مقدار را در برابر یک یا چند «الگو» بررسی کرد. نمونه‌ای از چنین الگویی «الگوی مقدار ثابت» است که یک مقدار را با یک مقدار ثابت (مثلاً `1` یا `"hello"`) مطابقت می‌دهد.

عبارت‌های case با کلیدواژه‌ی `case` نوشته می‌شوند:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

گرچه این ممکن است شبیه دستورهای `switch` در زبان‌های دیگر به نظر برسد، «تطبیق الگو» وقتی می‌درخشد که از الگوهای دیگر هم استفاده کنید. یکی از این الگوها «الگوی متغیر» است که اجازه می‌دهد مقداری به یک متغیر نسبت دهید. در این مثال، اگر `number` برابر `0` نباشد، مقدارش به متغیر `i` نسبت داده می‌شود:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

در برخی موارد، ممکن است بخواهید شرطی اضافی به یک الگو اضافه کنید. به این کار «گارد» (بند) می‌گویند که می‌توان آن را با کلیدواژه‌ی `if` اضافه کرد:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

به دلایل کارایی، در گاردها فقط عملگرهای پایه‌ی ریاضی و «منطقی» مجاز هستند و توابع دیگر را نمی‌توان در گاردها به کار برد.

در مثال بالا، هر ورودی ممکنی الگوی منطبق ندارد. کامپایلر این را تشخیص می‌دهد و یک خطا تولید می‌کند. به این کار «بررسی جامعیت» می‌گویند. برای رفع این هشدار باید همه‌ی حالت‌ها را پوشش دهید. برای این کار می‌توان از «الگوی نادیده‌گرفتن» استفاده کرد، الگویی که با هر مقداری مطابقت می‌کند:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

عبارت‌های case یک مقدار را از بالا به پایین در برابر هر الگو بررسی می‌کنند تا الگوی منطبق را پیدا کنند و منطق مربوط به آن الگو را اجرا کنند. ترتیب الگوها مهم است!
