# کلاس‌ها و ویژگی‌های `readonly`

کلاس‌ها و ویژگی‌های `readonly` به کلاس‌ها اجازه می‌دهند ویژگی‌های عمومی را برای دسترسی آسان تعریف کنند، اما از تغییر آن‌ها جلوگیری می‌کنند.
برای اینکه یک ویژگی را `readonly` اعلام کنید، باید `readonly` را پیش از مشخص کردن نوع آن بنویسید.
این ویژگی فقط یک بار می‌تواند مقدار بگیرد، اما هر تلاشی برای مقداردهی دوباره یا تغییر مقدار به یک `Error` منجر می‌شود.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

کلاس‌های `readonly` بر پایه‌ی همین رفتار بنا شده‌اند، به این صورت که اگر کلاسی `readonly` اعلام شود، اعلان `readonly` به هر ویژگی آن اعمال می‌شود.
علاوه بر این، از افزودن ویژگی‌های پویا جلوگیری می‌کند.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
