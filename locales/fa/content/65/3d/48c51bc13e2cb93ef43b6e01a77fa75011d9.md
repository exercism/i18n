# یادگیری

آیا علاقه‌مندید کار با Groovy را شروع کنید یا در حین کار روی تمرین‌ها بیشتر یاد بگیرید؟

Groovy را با موارد زیر امتحان کنید:

* [یک مرورگر با استفاده از مفسر آنلاین](https://www.jdoodle.com/execute-groovy-online)
* [Groovy Console](http://groovy-lang.org/groovyconsole.html) با تایپ کردن `groovyConsole` در خط فرمان
* [Groovy Shell](http://groovy-lang.org/groovyconsole.html) با تایپ کردن `groovysh` در خط فرمان

با موارد زیر یک تور سریع از Groovy بزنید:

* [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) نوشته‌ی Tim Rows برای توسعه‌دهندگان غیر جاوا هم به همان خوبی است
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) از SmartThings
* چند مورد از [online Groovy Koans](http://www.groovy-koans.org/) محصول JDriven

برای مطالعه‌ی عمیق‌تر:

* [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition)، _کتاب_ مرجع Groovy
* [Making Java Groovy](https://www.manning.com/books/making-java-groovy) از Ken Kousen
