# درباره

«تعریف نوع» یک نوع نامدار جدید می‌سازد که از هر نوع دیگری متمایز است، حتی از نوعی با همان نوع زیرین.

## تعریف نوع

یک تعریف نوع با کلیدواژه‌ی `type` شروع می‌شود و پس از آن اسم نوع جدید و نوع زیرین آن می‌آید:

```go
type File []bool
```

`File` در اینجا به یک ستون عمودی روی صفحه‌ی شطرنج اشاره دارد که معمولاً با حروف A تا H برچسب‌گذاری می‌شود.
هر خانه در این ستون با یک «مقدار منطقی» نشان داده می‌شود که مشخص می‌کند اشغال شده است یا نه.
حالا که `File` تعریف شده است، می‌توانیم از آن درون تعریف‌های دیگر استفاده کنیم:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` شناسه‌های ستون را به مقادیر `File` نگاشت می‌کند.
هر `File` یک اسلایس از مقادیر منطقی است که خانه‌های یک ستون شطرنج را نشان می‌دهد.
بدون این تعریف‌های نوع، `board` یک `map[string][]bool` می‌شد و درک اینکه چه چیزی را نمایش می‌دهیم سخت‌تر می‌شد.

## انواع تعریف‌شده متمایزند

هرچند `Score` و `int` هر دو مقدار صحیح نگه می‌دارند، تبدیل میان آن‌ها به یک تبدیل صریح نیاز دارد:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` یک ثابت بدون نوع است، پس می‌توان آن را مستقیماً به یک متغیر `Score` اختصاص داد.

انواع تعریف‌شده می‌توانند متد هم داشته باشند که در مفهوم متد به آن پرداخته می‌شود.

## انواع `struct`

تعریف‌های `struct` از همان کلیدواژه‌ی `type` استفاده می‌کنند:

```go
type Player struct {
    Name  string
    Score Score
}
```

انواع `struct` در مفهوم `struct` بررسی می‌شوند.

## نام مستعار نوع

نام مستعار نوع، به‌جای ساختن یک نوع جدید، اسم دیگری برای یک نوع موجود می‌سازد.
از آنجا که نام مستعار و نوع اصلی‌اش یکسان‌اند، می‌توان مقادیرشان را به‌جای هم به کار برد.
نام‌های مستعار با استفاده از کلیدواژه‌ی `type`، اسم نام مستعار، علامت مساوی (`=`) و نوع موجود اعلام می‌شوند.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
