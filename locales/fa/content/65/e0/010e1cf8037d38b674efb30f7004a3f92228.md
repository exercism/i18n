# مشارکت از طریق GitHub

مشارکت در کدبیس Exercism از طریق [GitHub][github] انجام می‌شود.

همان‌طور که از اسمش برمی‌آید، GitHub از [git][git] به عنوان سیستم کنترل نسخه‌ی خودش استفاده می‌کند. اگر با Git آشنایی ندارید، بهترین منبع آنلاین [Pro Git][pro-git] است.

اگر با GitHub و روند مشارکت آشنایی ندارید، این منابع می‌توانند در شروع کار به شما کمک کنند:

- [مقدمه‌ای بر GitHub، دوره‌ی تعاملی][github-course]
- [چگونه روی GitHub یک Pull Request بسازیم، آموزش][pr-tutorial]
- [چگونه یک Pull Request ساده در GitHub بسازیم، ویدیویی از anthonywritescode][anthonywritescode]

## راهنماها

می‌توانید درباره‌ی اینکه چگونه مطمئن شوید مشارکتتان مورد استقبال قرار می‌گیرد، در راهنمای [چگونه یک Pull Request عالی بسازیم][great-pr] بیشتر بخوانید.

چند راهنمای Pull Request مخصوص Exercism هم داریم:

- [چگونه یک Pull Request عالی بسازیم][how-to-make-a-great-pr]
- [راهنمای مشارکت‌کنندگان برای Pull Request][contributors-pr-guide]
- [راهنمای نگهدارندگان برای Pull Request][maintainers-pr-guide]
- [دسترسی‌های مخزن نگهدارندگان][maintainers-repo-permissions]
