# مقدمه

یک تعریف `:` می‌تواند خودش را مستقیم فراخوانی کند. کامپایلر Factor اثر پشته‌ی تعریف‌های بازگشتی را هم درست مثل هر تعریف دیگری استنباط می‌کند. برای «بازگشت» ساده به هیچ اعلان خاصی نیاز نیست.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

این دو نیمه، «حالت پایه»ی بازگشت هستند (اینجا، دنباله‌ی خالی به `0` جمع می‌شود) و «گام بازگشتی» (یک عنصر را جدا می‌کند، روی بقیه دوباره فراخوانی می‌شود و نتیجه‌ها را با هم ترکیب می‌کند).

`if-empty` و `unclip` همراهان متعارف بازگشت روی دنباله هستند. `if-empty ( seq emptyquot nonemptyquot -- )` بسته به دنباله، یکی از دو «بلوک کد» را اجرا می‌کند؛ `unclip` اولین عنصر را جدا می‌کند تا گام بازگشتی با دنباله‌ی ساده‌تری سر و کار داشته باشد.
