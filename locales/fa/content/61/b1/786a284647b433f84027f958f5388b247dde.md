# مقدمه

«نوع داده‌ی شمارشی» یک نوع داده‌ی ویژه است که اجازه می‌دهد یک متغیر یکی از ثابت‌های از پیش تعریف‌شده را در خود نگه دارد.
متغیر باید برابر با یکی از مقادیری باشد که از پیش برایش تعریف شده‌اند.
مثال‌های رایج شامل جهت‌های قطب‌نما (مقادیر `NORTH`، `SOUTH`، `EAST` و `WEST`) و روزهای هفته است.

چون ثابت هستند، اسم فیلدهای یک نوع داده‌ی شمارشی با حروف بزرگ نوشته می‌شود.

## تعریف یک نوع داده‌ی شمارشی

در زبان برنامه‌نویسی Java، یک نوع داده‌ی شمارشی را با استفاده از کلیدواژه‌ی `enum` تعریف می‌کنید.
برای مثال، یک نوع داده‌ی شمارشی برای روزهای هفته را به این صورت تعریف می‌کنید:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

هر زمان که بخواهید مجموعه‌ای معین از ثابت‌ها را نمایش دهید باید از نوع داده‌های شمارشی استفاده کنید.
این شامل نوع داده‌های شمارشی طبیعی مانند سیاره‌های منظومه‌ی شمسی و مجموعه‌داده‌هایی می‌شود که همه‌ی مقادیر ممکنشان را در زمان کامپایل می‌دانید؛ برای مثال، گزینه‌های یک منو، پرچم‌های خط فرمان و غیره.

## استفاده از یک نوع داده‌ی شمارشی

در ادامه کدی را می‌بینید که نحوه‌ی استفاده از نوع داده‌ی شمارشی `DayOfWeek` تعریف‌شده در بالا را نشان می‌دهد:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## افزودن متدها و فیلدها

نوع داده‌های شمارشی در زبان برنامه‌نویسی Java بسیار قدرتمندتر از همتایانشان در زبان‌های دیگر هستند.
اعلان `enum` یک «کلاس» تعریف می‌کند (که به آن نوع داده‌ی شمارشی می‌گویند).
بدنه‌ی کلاس شمارشی می‌تواند شامل متدها و فیلدهای دیگر باشد:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

فراخوانی متد `getNumberOfStars` روی یکی از اعضای نوع داده‌ی شمارشی `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
