# Alias

[فرم ویژهٔ `alias`][alias] به شما این امکان را می‌دهد که نامی را که با آن به یک ماژول بیرونی ارجاع می‌دهید، کوتاه‌تر کنید یا تغییر دهید. می‌توانید با گزینه‌ی `:as` یک نام دلخواه تعیین کنید.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

وقتی بدون هیچ آرگومانی به کار می‌رود، نام ماژول را به آخرین بخش آن کوتاه می‌کند؛ برای نمونه:

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

می‌توان با `{}` چندین `alias` را با هم گروه‌بندی کرد:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

معمولاً `alias`ها را در ابتدای تعریف ماژول اضافه می‌کنند، اما می‌توان آن‌ها را در هر جای دیگری هم اضافه کرد. `alias`ها دامنه‌ی واژگانی دارند، یعنی اگر داخل تعریف یک تابع `alias` اضافه کنید، آن `alias` در تابع دیگری در دسترس نخواهد بود.

`alias`های استفاده‌نشده هشدارهای کامپایلر را ایجاد می‌کنند.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
