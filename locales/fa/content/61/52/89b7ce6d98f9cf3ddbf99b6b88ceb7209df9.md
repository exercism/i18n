# مقدمه

## ویژگی‌ها

یک [ویژگی `Attribute` در C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) راهی برای تزئین یک اعلان فراهم می‌کند تا فراداده را به موارد زیر مرتبط کند: یک کلاس، یک متد، یک شمارشی، یک فیلد، یک خاصیت یا هر اعلان [دیگری که پشتیبانی می‌شود](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

می‌توانید یک ویژگی را با افزودن آن در خط پیش از اعلان، با استفاده از `ClassAttribute` و `FieldAttribute` اعمال کنید:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

این فراداده‌ی اعلانی فقط اطلاعات ساختاریافته‌ی بیشتری را به کد مرتبط می‌کند و رفتار آن را تغییر نمی‌دهد، اما بخش‌های دیگر کد از آن فراداده استفاده می‌کنند تا رفتار هدفش را تغییر دهند، یا قابلیت‌هایی به آن بیفزایند، تغییر دهند یا حذف کنند، یا برخی از قابلیت‌هایش را محدود کنند.

[ویژگی‌های از پیش تعریف‌شده و رزروشده](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) زیادی وجود دارد، برای مثال: `Flags`، `Obsolete`، `Conditional` و `Experimental`. هر یک معنای معناشناختی خاصی دارد که می‌توان آن را در مستندات C# جست‌وجو کرد. توجه داشته باشید که نام کامل یک ویژگی مانند [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) به شکل `<Name>Attribute` است (مثلاً `FlagsAttribute`).

## شمارشی‌های پرچمی

نوع [`enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) در C# مجموعه‌ای ثابت از ثابت‌های نامدار (یک برشماری) را نشان می‌دهد.

معمولاً یک عضو `enum` فقط می‌تواند به دقیقاً یکی از آن ثابت‌های نامدار اشاره کند. با این حال، گاهی مفید است که به بیش از یک ثابت اشاره شود. برای این کار، می‌توان `enum` را با [ویژگی `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) حاشیه‌نویسی کرد.

یک شمارشی پرچمی را می‌توان به‌صورت زیر تعریف کرد (با استفاده از نشانه‌گذاری عدد صحیح دودویی `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

یک نمونه‌ی `PhoneFeatures` که مقدارش `0b00000011` است، هر دو پرچم `Call` _و_ `Text` آن تنظیم شده‌اند.

به‌طور پیش‌فرض، برای مقادیر اعضای شمارشی از نوع `int` استفاده می‌شود. می‌توان با مشخص کردن نوع در اعلان شمارشی، از یک نوع عدد صحیح متفاوت استفاده کرد:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
