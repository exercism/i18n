# درباره

بسیاری از [انواع اعضای `struct` و `class`][expression-bodied-members] (که فیلدها استثنای اصلی آن هستند) می‌توانند از نحوه‌ی نگارش عضو عبارت‌محور استفاده کنند. تعریف کردن یک عضو با یک عبارت، اغلب کدی مختصرتر و خواناتر از بلوک‌ها/دستورهای سنتی تولید می‌کند.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

اعضای عبارت‌محور نمی‌توانند بلوک‌هایی با چندین دستور داشته باشند، اما باید به کسانی که پیشینه‌ی برنامه‌نویسی تابعی دارند هشدار داد که هر کاری را که یک عضو سنتی می‌تواند انجام دهد، با یکی از این اعضا هم می‌توان انجام داد. این «عبارت» می‌تواند یک عملیات انتساب باشد که عوارض جانبی ایجاد می‌کند، یا فراخوانی یک متد باشد، یعنی ممکن است هر اتفاقی بیفتد.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
