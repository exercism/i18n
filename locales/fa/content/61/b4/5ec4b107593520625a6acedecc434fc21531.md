# دستورالعمل‌ها

در این تمرین، شما با یک دوست یک بازی حدس عدد انجام می‌دهید.
قوانین ساده است: شما به‌طور مخفیانه عددی بین `1` و `100` انتخاب می‌کنید و دوستتان تلاش می‌کند حدس بزند چه عددی را انتخاب کرده‌اید.
برای اینکه به دوستتان کمک کنید، بسته به اینکه حدس چقدر به عددی که انتخاب کرده‌اید (`42`) نزدیک بوده، پاسخ متفاوتی می‌دهید.
این‌ها قوانین برای ورودی‌های مختلف ممکن است:

- اگر حدس `42` باشد: «Correct»
- اگر حدس `41` یا `43` باشد: «So close»
- اگر حدس کمتر از `41` باشد: «Too low»
- اگر حدس بیشتر از `43` باشد: «Too high»

چهار کار دارید تا پاسخ حدس‌ها را کد کنید.

## 1. پاسخ به یک حدس درست

تابع `reply` را طوری پیاده‌سازی کنید که به یک حدس درست پاسخ دهد:

```haskell
reply 42
-- -> "Correct"
```

## 2. پاسخ به یک حدس نزدیک

تابع `reply` را تغییر دهید تا به حدس‌های نزدیک پاسخ دهد:

```haskell
reply 41
-- -> "So close"
```

## 3. پاسخ به حدس‌های خیلی کم

تابع `reply` را تغییر دهید تا به حدس‌های خیلی کم پاسخ دهد:

```haskell
reply 25
-- -> "Too low"
```

## 4. پاسخ به حدس‌های خیلی زیاد

تابع `reply` را تغییر دهید تا به حدس‌های خیلی زیاد پاسخ دهد:

```haskell
reply 88
-- -> "Too high"
```
