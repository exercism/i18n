# نصب

ساده‌ترین راه برای نصب Ceylon این است که اصلاً **نصبش نکنید**.
باید بتوانید بیشتر تمرین‌ها را با استفاده از [محیط توسعه‌ی یکپارچه‌ی وب](http://try.ceylon-lang.org/) ما حل کنید.

اما اگر ترجیح می‌دهید، می‌توانید توزیع خط فرمان را نصب کنید. ساده‌ترین راه برای این کار استفاده از [SDKMAN](http://sdkman.io/) است؛ پس اگر هنوز SDKMAN را نصب نکرده‌اید، اول آن را نصب کنید و بعد کافی است در ترمینال خود دستور `sdk install ceylon` را تایپ کنید.

کاربران OSX هم می‌توانند از طریق [مدیر بسته‌ی Homebrew](http://mxcl.github.com/homebrew/) نصب کنند.

دستورالعمل‌های نصب برای سایر پلتفرم‌ها و همچنین برای Ceylon IDE، افزونه‌ای برای Eclipse، در [سایت رسمی](http://ceylon-lang.org/download/) موجود است.
