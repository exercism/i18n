# دستورالعمل‌ها

در حین کار در _Instruments of Texas_، به شما مأموریت داده شده است که روی یک ماشین‌حساب آزمایشی نوشته‌شده با C# کار کنید. شما در حال ساختن یک بستر آزمون هستید تا شماری از توابع ماشین‌حساب را، با شروع از ضرب، بررسی کنید. خواهید دید که وقتی هر دو عملوند ضرب منفی باشند، نگرانی ویژه‌ای وجود دارد.

کلاس `Calculator` برای شما فراهم شده است و نباید تغییر داده شود.

## 1. تعریف استثنای تعریف‌شده توسط کاربر `CalculationException` را کامل کنید

تعریف سازنده‌ی `CalculationException` را کامل کنید؛ این سازنده باید هر استثنایی را که ماشین‌حساب پرتاب می‌کند و همچنین عملوندهایی را که در لحظه‌ی پرتاب استثنا در حال پردازش هستند، ذخیره (بسته‌بندی) کند.

## 2. شرایط سرریز را در ماشین‌حساب مدیریت کنید و اطلاعات بیشتری در اختیار فراخواننده قرار دهید

متد `CalculatorTestHarness.Multiply()` را پیاده‌سازی کنید؛ این متد باید متد `Calculator.Multiply()` از نمونه‌ی `Calculator`ی که به سازنده پاس داده شده است را فراخوانی کند و مقادیر صحیح `x` و `y` را به آن بدهد. اگر در متد `Calculator.Multiply()` سرریزی رخ دهد، یک `OverflowException` پرتاب می‌شود. این استثنا باید در متد `CalculatorTestHarness.Multiply()` گرفته و در یک `CalculationException` بسته‌بندی شود و مقادیر `x` و `y` که پاس داده می‌شوند باید به عنوان عملوندهای استثنا ذخیره شوند. شیء `CalculationException` تازه‌ساخته‌شده باید پرتاب شود. اگر متد `Calculator.Multiply()` موفق باشد، می‌توانید مقدار بازگشتی آن را نادیده بگیرید.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. عملیات ضرب را برای ورودی‌های معتبر آزمایش کنید

متد `CalculatorTestHarness.TestMultiplication()` را پیاده‌سازی کنید که دو عدد صحیح می‌گیرد و متد `CalculatorTestHarness.Multiply()` را فراخوانی می‌کند. در این صورت `"Multiply succeeded"` بازگردانده می‌شود.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. عملیات ضرب را برای ورودی‌های منفی آزمایش کنید

متد `CalculatorTestHarness.TestMultiplication()` را طوری تغییر دهید که اگر هر دو آرگومان صحیح منفی باشند (کمتر از صفر)، `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` بازگردانده شود.

جانگهدار `<INNER_EXCEPTION_MESSAGE>` باید با پیام استثنای درونی `CalculationException` جایگزین شود.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. عملیات ضرب را برای ورودی‌های مثبت آزمایش کنید

متد `CalculatorTestHarness.TestMultiplication()` را طوری تغییر دهید که اگر حداقل یکی از آرگومان‌های صحیح منفی نباشد، `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` بازگردانده شود.

جانگهدار `<INNER_EXCEPTION_MESSAGE>` باید با پیام استثنای درونی `CalculationException` جایگزین شود.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
