# راهنماها

## کلیات

- شمارش پرندگان در هر روز در فیلدی به اسم `birdsPerDay` ذخیره می‌شود.
- شمارش پرندگان در هر روز آرایه‌ای است که دقیقاً ۷ عدد صحیح را در خود دارد.

## 1. شمارش‌های هفته‌ی گذشته را بررسی کنید

- از آنجا که هفته‌ی گذشته را نگه می‌داریم، فقط کافی است مقادیر هفته‌ی گذشته را برگردانید.

## 2. بررسی کنید امروز چند پرنده بازدید کرده‌اند

- به خاطر داشته باشید که شمارش‌ها بر اساس روز از قدیمی‌ترین به جدیدترین مرتب شده‌اند و آخرین عنصر نماینده‌ی امروز است.
- برای دسترسی به آخرین عنصر می‌توانید از اندیس (ثابت) آن استفاده کنید (یادتان باشد شمارش را از صفر شروع کنید) یا اندیس آن را با استفاده از اندازه‌ی آرایه محاسبه کنید.

## 3. یک واحد به شمارش امروز اضافه کنید

- عنصری را که نماینده‌ی شمارش امروز است، برابر با شمارش امروز به‌علاوه‌ی ۱ قرار دهید.

## 4. بررسی کنید آیا روزی بدون پرنده‌ی بازدیدکننده وجود داشته است

- می‌توان آرایه را با یک حلقه‌ی `for` پیمایش کرد.
- راه‌حل دیگر استفاده از Java Stream API است.

## 5. محاسبه‌ی تعداد پرنده‌های بازدیدکننده در چند روز نخست

- می‌توان از یک متغیر برای نگه‌داشتن تعداد پرنده‌های بازدیدکننده استفاده کرد.
- می‌توان آرایه را با یک حلقه‌ی `for` پیمایش کرد.
- متغیر را می‌توان داخل حلقه به‌روزرسانی کرد.
- یادتان باشد: اندیس آرایه‌ها از `0` شروع می‌شود.

## 6. محاسبه‌ی تعداد روزهای شلوغ

- می‌توان از یک متغیر برای نگه‌داشتن تعداد روزهای شلوغ استفاده کرد.
- می‌توان آرایه را با یک حلقه‌ی `foreach` پیمایش کرد.
- متغیر را می‌توان داخل حلقه به‌روزرسانی کرد.
- می‌توان داخل حلقه از یک دستور شرطی استفاده کرد.
