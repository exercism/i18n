# دستورالعمل‌ها

در این تمرین، اولین نوبت یک بازی [بلک‌جک][blackjack] را شبیه‌سازی می‌کنیم.

## 1. ارزش هر کارت دلخواه را محاسبه کنید.

شما دو کارت دریافت می‌کنید و می‌توانید کارت رو‌شده‌ی پخش‌کننده را ببینید.
همه‌ی کارت‌ها با یک رشته نمایش داده می‌شوند؛ مثل `ace`، `king`، `three`، `two` و غیره.
ارزش هر کارت به این صورت است:

| کارت  | ارزش |  کارت   | ارزش |
| :---: | :---: | :-----: | :---: |
|  ace  |  ۱۱   |  eight  |   ۸   |
|  two  |   ۲   |  nine   |   ۹   |
| three |   ۳   |   ten   |  ۱۰   |
| four  |   ۴   |  jack   |  ۱۰   |
| five  |   ۵   |  queen  |  ۱۰   |
|  six  |   ۶   |  king   |  ۱۰   |
| seven |   ۷   | _other_ |   ۰   |

~~~~exercism/note
معمولاً کارت‌های `ace` می‌توانند ارزش ۱ یا ۱۱ داشته باشند، اما برای سادگی فرض می‌کنیم که فقط می‌توانند ارزش ۱۱ داشته باشند.
~~~~

متد `Blackjack.parse_card` را پیاده‌سازی کنید که یک کارت را به شکل رشته به عنوان ورودی می‌گیرد.
این متد باید ارزش کارت را به‌صورت یک عدد صحیح برگرداند.

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. به بازه‌های مقادیر نام بدهید.

امتیاز بازیکن باید در بازه‌هایی از مقادیر دسته‌بندی شود.
امتیاز بازیکن از جمع ارزش دو کارت بازیکن به دست می‌آید.
بازه‌هایی که استفاده می‌شوند عبارت‌اند از:

|   بازه   |  ارزش   |
| :-------: | :------: |
|    low    | [۴، ۱۱]  |
|    mid    | [۱۲، ۱۶] |
|   high    | [۱۷، ۲۰] |
| blackjack |   [۲۱]   |

متد `Blackjack.card_range` را پیاده‌سازی کنید که دو کارت را به شکل رشته به عنوان ورودی می‌گیرد.
این متد باید اسم بازه‌ای را برگرداند که این دو کارت در آن قرار می‌گیرند.

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. منطق تصمیم‌گیری برای نوبت اول را پیاده‌سازی کنید.

بسته به دو کارت شما و کارت پخش‌کننده، برای نوبت اول بازی یک استراتژی وجود دارد که در آن گزینه‌های زیر را دارید:

- ایستادن (S)
- کارت گرفتن (H)
- تقسیم کردن جفت (P)
- برد خودکار (W)

هرچند هنوز بهینه نیست، اما از استراتژی‌ای پیروی می‌کنید که دوستتان الکس در حال توسعه‌ی آن بوده است. این استراتژی به این صورت است:

- اگر یک جفت `ace` داشته باشید، باید همیشه آن‌ها را تقسیم کنید.
- اگر بلک‌جک داشته باشید (دو کارتی که جمعشان ۲۱ می‌شود) و پخش‌کننده `ace`، کارت تصویری یا `ten` نداشته باشد، به‌طور خودکار برنده می‌شوید.
  اما اگر پخش‌کننده هر یک از این کارت‌ها را داشته باشد، باید بایستید و منتظر رو شدن کارت دیگر بمانید.
- اگر جمع کارت‌هایتان مقداری در بازه‌ی [۱۷، ۲۰] باشد، باید همیشه بایستید.
- اگر جمع کارت‌هایتان مقداری در بازه‌ی [۱۲، ۱۶] باشد، باید همیشه بایستید، مگر اینکه پخش‌کننده ۷ یا بالاتر داشته باشد که در آن صورت باید همیشه کارت بگیرید.
- اگر جمع کارت‌هایتان ۱۱ یا کمتر باشد، باید همیشه کارت بگیرید.

متد `Blackjack.first_turn` را پیاده‌سازی کنید که سه کارت را به شکل رشته به عنوان ورودی می‌گیرد.
این متد باید تصمیمی را که باید بگیرید به‌صورت یک رشته برگرداند.

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
