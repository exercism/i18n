# دستورالعمل‌ها

گروه رقص در حال آماده‌سازی نمایش پایان سال خود است: این که رقصنده‌ها به چند شکل می‌توانند چیده شوند و زمان اجرا چگونه بین پرده‌ها تقسیم می‌شود.

هر پنج کار در کلاس `FORMATION_COUNT` قرار می‌گیرند.

## 1. چند صف‌بندی؟

با `n` رقصنده، `n` فاکتوریل راه برای صف‌بندی آن‌ها وجود دارد: `n` گزینه برای نفر جلویی، سپس `n-1` گزینه برای نفر بعدی و به همین ترتیب. آن را به‌صورت یک `INTI` برگردانید. صفر رقصنده دقیقاً یک صف‌بندی دارند، یعنی همان صف‌بندی خالی.

```sather
FORMATION_COUNT::line_ups(5)
-- => 120
FORMATION_COUNT::line_ups(20)
-- => 2432902008176640000
```

## 2. آن را بنویسید

همان عدد به‌صورت یک رشته، با تک‌تک رقم‌هایش.

```sather
FORMATION_COUNT::line_ups_text(25)
-- => "15511210043330985984000000"
```

یک `INT` نمی‌تواند آن عدد را در خود جای دهد و نکته‌ی این کار هم همین است.

## 3. سهم یک پرده

نمایشی با `acts` پرده‌ی مساوی، به هر پرده `1/acts` از زمان اجرا اختصاص می‌دهد. آن را به‌صورت یک `RAT` برگردانید.

```sather
FORMATION_COUNT::share(3)
-- => 1/3
```

## 4. دو پرده با هم

دو سهم را جمع کنید و مجموع را دقیق برگردانید.

```sather
FORMATION_COUNT::combined(FORMATION_COUNT::share(2), FORMATION_COUNT::share(3))
-- => 5/6
```

## 5. آیا نمایش را پر می‌کند؟

به این پرسش پاسخ دهید که آیا یک سهم دقیقاً برابر کل نمایش است، یعنی دقیقاً برابر یک.

```sather
FORMATION_COUNT::covers_whole_show(#RAT(3, 3))
-- => true
FORMATION_COUNT::covers_whole_show(#RAT(2, 3))
-- => false
```
