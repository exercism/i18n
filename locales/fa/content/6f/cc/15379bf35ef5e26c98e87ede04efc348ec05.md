# مقدمه

یک تعریف مجموعه معمولاً شامل یک جانگهدار میان پرانتزهای زاویه‌دار است که طبق قرارداد اغلب اسمش `T` است. به چنین مجموعه‌ای «نوع جنریک» می‌گویند. این کار به کاربر مجموعه اجازه می‌دهد مشخص کند چه نوع عنصری را در مجموعه ذخیره کند. در کد نمونه‌ی بالا، یک لیست از رشته‌ها را نمونه‌سازی می‌کنیم.

یک کلاس یا تابع با استفاده از ویژگی `@:generic` **جنریک** می‌شود. این باعث می‌شود کامپایلر کلاس یا تابع را جنریک تشخیص دهد:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
