# مقدمه

در JavaScript، «آرایه» ساختاری شبیه فهرست است که طول ثابتی ندارد و می‌تواند هر نوعی از مقدارهای اولیه یا شیءها، حتی انواع مخلوط، را در خود نگه دارد.

برای ساختن آرایه، عنصرها را بین کروشه‌های `[]` قرار دهید.
برای خواندن از آرایه، اندیس را بعد از شناسه داخل کروشه‌های `[]` بگذارید.
اندیس‌های آرایه از صفر شروع می‌شوند.

برای مثال:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

برای به دست آوردن تعداد عنصرهای موجود در یک آرایه، از ویژگی `length` استفاده کنید:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

برای تغییر یک عنصر در آرایه، در آن اندیس مقداری را نسبت می‌دهید:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## متد

برخی از [متدها][mdn-array] که روی هر شیء Array در دسترس‌اند، می‌توانند برای افزودن به آرایه یا حذف از آن به کار روند.
در ادامه چند مورد را می‌بینید که هنگام کار روی این تمرین باید در نظر بگیرید:

### push

می‌توان یک `value` را با استفاده از `.push(value)` به انتهای آرایه _افزود_.
این متد طول جدید آرایه را برمی‌گرداند.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

می‌توان _آخرین_ `value` را با استفاده از `.pop()` از آرایه _حذف_ کرد.
این متد مقدار حذف‌شده را برمی‌گرداند.
با این تغییر، طول آرایه کاهش می‌یابد.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

می‌توان _اولین_ `value` را با استفاده از `.shift()` از آرایه _حذف_ کرد.
این متد مقدار حذف‌شده را برمی‌گرداند.
با این تغییر، طول آرایه کاهش می‌یابد.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

می‌توان یک `value` را با استفاده از `.unshift(value)` به ابتدای آرایه _افزود_.
این متد طول جدید آرایه را برمی‌گرداند.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

می‌توان یک `value` را در `index` مشخصی با استفاده از `.splice(index, 1)` از آرایه _حذف_ کرد.
این متد عنصر یا عنصرهای حذف‌شده را برمی‌گرداند.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
این متدها قدرتمندتر از آن‌اند که توضیح داده شد:

- هم `push` و هم `unshift` به شما اجازه می‌دهند با افزودن آرگومان‌های بیشتر، چند مقدار را یکجا push یا unshift کنید.
  برای کامل کردن این تمرین این کار لازم نیست.
- Splice می‌تواند با افزایش آرگومان دوم، چند مقدار را حذف کند.
  برای کامل کردن این تمرین این کار لازم نیست.
- Splice همچنین می‌تواند با افزودن آن‌ها به‌عنوان آرگومان بعد از `deleteCount`، چند مقدار را اضافه کند.
  از این کار می‌توان برای جایگزین کردن مقدارها یا درج مقدارها در میانه‌ی آرایه استفاده کرد (مثلاً با حذف ۰ عنصر).
  برای کامل کردن این تمرین این کار لازم نیست.
~~~
