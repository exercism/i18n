# نصب

## نصب .NET

مسیر F# روی بستر [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) ساخته شده است که روی Windows، Linux و macOS اجرا می‌شود. برای ساخت پروژه‌های .NET می‌توانید از رابط خط فرمان .NET (CLI) استفاده کنید. این CLI بخشی از .NET SDK است که می‌توانید با دنبال کردن [دستورالعمل‌های نصب](https://dotnet.microsoft.com/download) آن را نصب کنید. توجه: مسیر F# به نسخه‌ی SDK ۸.۰ یا بالاتر نیاز دارد.

پس از تمام شدن نصب، می‌توانید با اجرای این دستور در ترمینال بررسی کنید که CLI درست نصب شده است یا نه:

```bash
dotnet --version
```

اگر خروجی نسخه‌ای بزرگ‌تر یا مساوی `8.0.100` باشد، .NET SDK با موفقیت نصب شده است.

## استفاده از IDE

اگر تجربه‌ی ویرایشی کامل‌تر و پرامکانات‌تری می‌خواهید، احتمالاً بهتر است از یک محیط توسعه‌ی یکپارچه (IDE) استفاده کنید. این‌ها محبوب‌ترین IDEهایی هستند که از ساخت پروژه‌های .NET پشتیبانی می‌کنند:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) همراه با [افزونه‌ی Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

توجه: از آنجا که قالب پروژه‌ی .NET تفاوت چشمگیری با نسخه‌های پیشین دارد، IDEهای قدیمی‌تر (مانند Visual Studio 2015) پشتیبانی نمی‌شوند.
