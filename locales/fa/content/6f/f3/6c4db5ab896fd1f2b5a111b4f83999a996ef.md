# مقدمه

## مقادیر منطقی

«منطقی» در Java با نوع `boolean` نمایش داده می‌شود و مقدارش می‌تواند `true` یا `false` باشد.

Java از سه عملگر منطقی پشتیبانی می‌کند:  

- `!` (NOT): مقدار منطقی را نقیض می‌کند  
- `&&` (AND): دو مقدار منطقی می‌گیرد و اگر هر دو `true` باشند `true` برمی‌گرداند
- `||` (OR): اگر یکی از آن دو مقدار منطقی `true` باشد، `true` برمی‌گرداند

### مثال‌ها

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
