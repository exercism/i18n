# عدد ممیز شناور

`FLTD` عددی را نگه می‌دارد که ممکن است بخش اعشاری داشته باشد. یک «مقدار ثابت» به یک ممیز و یک `d` نیاز دارد:

```sather
   440.0d
   0.5d
   -2.25d
```

`FLT` همان مفهوم است، اما با نصف «دقت». این مسیر در همه جا از `FLTD` استفاده می‌کند؛ دلیلی برای رفتن سراغ `FLT` وجود ندارد، مگر اینکه حافظه کم باشد.

## محاسبات

| عملگر | معنا |
| --- | --- |
| `+` `-` `*` | مانند `INT` |
| `/` | تقسیم، با حفظ بخش اعشاری |

برای `FLTD` عملگر `%` وجود ندارد.

هر دو عملوند باید از نوع `FLTD` باشند. مخلوط کردن یک `INT` در میان، یک خطای کامپایل است، نه یک تبدیل بی‌صدا، و این خودش یک مزیت است: تنها جایی که این موضوع دردسر درست می‌کند، دقیقاً همان جایی است که افراد اشتباه می‌کنند.

## تبدیل

```sather
   7.fltd            -- 7.0, an INT made into an FLTD
   7.5d.int          -- 7, the fraction thrown away
   7.5d.round        -- 8, to the nearest whole number
   7.5d.floor        -- 7.0, down to a whole number
   7.5d.ceiling      -- 8.0, up to a whole number
```

پیش از تقسیم تبدیل کنید، نه پس از آن: `n.fltd / 2.0d` نصف را نگه می‌دارد، اما `(n / 2).fltd` آن را از قبل از دست داده است.

## روال‌های مفید

```sather
   (-2.5d).abs       -- 2.5
   2.0d.sqrt         -- 1.41421
   (2.0d).max(3.0d)  -- 3.0
```

## ممیز شناور تقریبی است

یک `FLTD` یک تقریب بسیار نزدیک را نگه می‌دارد، نه مقدار دقیق را. بیشتر کسرهای اعشاری را نمی‌توان به‌طور دقیق ذخیره کرد، همان‌طور که یک‌سوم را هم نمی‌توان به‌صورت اعشاری دقیق نوشت. بنابراین:

```sather
0.1d + 0.2d          -- very nearly 0.3, but not exactly
```

دو پیامد که ارزش به خاطر سپردن دارند:

**با `=` مقایسه نکنید.** دو محاسبه‌ای که باید پاسخ یکسان بدهند، اغلب در چند رقم آخر با هم تفاوت دارند. به جای آن بپرسید که آیا به هم نزدیک‌اند:

```sather
   (a - b).abs < 0.0001d
```

**جمع کردن بسیاری از مقادیر کوچک، از دقت می‌کاهد.** هر بار جمع کردن، کمی گِردسازی می‌کند و خطاها روی هم انباشته می‌شوند.

وقتی مقادیر باید دقیق باشند، به‌ویژه پول، به جای آن با `INT` در واحدهای کامل بشمارید (سِنت به جای دلار).

## چاپ

`.str` حدود شش رقم با‌معنا را نشان می‌دهد، که کمتر از دقتی است که در واقع نگه داشته می‌شود:

```sather
   #OUT + (1.0d / 3.0d).str;      -- 0.333333
```
