# راهنمایی‌ها

## 1. ساختن جدول امتیازهای برتر

- جدول امتیازهای برتر باید یک «جدول درهم‌سازی» باشد.
- می‌توانید با `make-hash-table` یک جدول درهم‌سازی بسازید.

## 2. افزودن بازیکن به جدول

- برای افزودن یک جفت کلید/مقدار به جدول درهم‌سازی از `(setf (gethash key table) value)` استفاده کنید.

## 3. تنظیم امتیاز بازیکن

- تنظیم امتیاز بازیکن تقریباً همانند افزودن بازیکن به جدول است.
- برای افزودن یک جفت کلید/مقدار به جدول درهم‌سازی از `(setf (gethash key table) value)` استفاده کنید.

## 4. گرفتن امتیاز از جدول

- برای گرفتن مقدار یک کلید از جدول درهم‌سازی از `gethash` استفاده کنید.
- `gethash` یک آرگومان سوم اختیاری دارد که همان مقداری است که در صورت پیدا نشدن کلید به کار می‌رود.

## 5. حذف بازیکن از جدول

- برای حذف یک کلید از جدول از `remhash` استفاده کنید.
