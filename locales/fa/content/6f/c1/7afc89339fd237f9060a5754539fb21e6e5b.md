# نصب

## پیش‌نیازها

* یک پردازنده‌ی x86 ۶۴ بیتی
* یک کامپایلر C مدرن
* ابزار ساخت Make
* اسمبلر Netwide (NASM)

لطفاً توجه داشته باشید که این بخش فقط از قرارداد فراخوانی System V AMD64 ABI پشتیبانی می‌کند. کاربران Windows باید زیرسیستم Windows برای Linux (WSL) را نصب کنند، یا یک ماشین مجازی Linux راه‌اندازی کنند.

## Linux

نرم‌افزارهای مورد نیاز را با مدیر بسته‌ی سیستمتان نصب کنید:

* Ubuntu، Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS، RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

ابزارهای خط فرمان Xcode را نصب کنید:

```bash
$ xcode-select --install
```

NASM را با [Homebrew](http://brew.sh/) نصب کنید:

```bash
$ brew install nasm
```

## Windows

برای نصب WSL، به https://docs.microsoft.com/en-us/windows/wsl/install-win10 مراجعه کنید.
