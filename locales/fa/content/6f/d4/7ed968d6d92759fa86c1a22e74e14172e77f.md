# راهنماییها

## کلی

- مستندات [مجموعه][set] را بخوانید
- مستندات [لیست][lists] هم می‌تواند به کارتان بیاید

## 1. شروع یک مجموعه

- مناسب‌ترین تابع `Set` همان [`Set.singleton`][singleton] است

## 2. بزرگ کردن مجموعه

- از [تابع `Set.insert`][insert] استفاده کنید
- از [تابع `Set.member`][member] استفاده کنید

## 3. شروع تبادل

- از [تابع `Set.member`][member] استفاده کنید
- از [تابع `Set.insert`][insert] استفاده کنید
- از [تابع `Set.remove`][remove] استفاده کنید

## 4. از هر کدام فقط یکی می‌تواند وجود داشته باشد

- یک `Set` این ویژگی را دارد که فقط مقادیر یکتا را در خود نگه می‌دارد
- از [تابع `Set.fromList`][fromList] استفاده کنید
- از [تابع `Set.toList`][toList] استفاده کنید
- تابع `Set.toList` به‌طور تضمین‌شده یک لیست مرتب برمی‌گرداند

## 5. کارت‌هایی که ندارند

- از [تابع `Set.diff`][diff] استفاده کنید
- از [تابع `Set.size`][size] استفاده کنید

## 6. کارت‌هایی که همه دارند

- از [توابع `List.foldl` یا `List.foldr`][fold] استفاده کنید
- برای تشخیص لیست‌های خالی از ناخالی، از تطبیق الگو روی لیست استفاده کنید
- از [تابع `Set.intersect`][intersect] استفاده کنید
- از [تابع `Set.toList`][toList] استفاده کنید
- تابع `Set.toList` به‌طور تضمین‌شده یک لیست مرتب برمی‌گرداند

## 7. همه‌ی کارت‌ها

- از [توابع `List.foldl` یا `List.foldr`][fold] استفاده کنید
- از [`Set.empty`][empty] به عنوان انباشتگر استفاده کنید
- از [تابع `Set.union`][union] استفاده کنید
- از [تابع `Set.size`][size] استفاده کنید

## 8. درخشان برای برد

- از [تابع `Set.partition`][partition] استفاده کنید
- از [تابع `String.startsWith`][startsWith] استفاده کنید
- از [تابع `Set.toList`][toList] استفاده کنید
- تابع `Set.toList` به‌طور تضمین‌شده یک لیست مرتب برمی‌گرداند
