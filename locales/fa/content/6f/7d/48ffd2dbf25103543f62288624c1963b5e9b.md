# مقدمه

برگرفته از [راهنما][man-types]

> jq از همان مجموعه‌ی انواع داده‌ای پشتیبانی می‌کند که JSON: عددها، رشته‌ها، مقادیر منطقی، آرایه‌ها، شیءها (که در اصطلاح JSON، هش‌هایی با تنها کلیدهای رشته‌ای هستند) و `null`.

بیایید روی **عددها** تمرکز کنیم.

## عددها و عملگرهای عددی

همه‌ی عددها، چه عدد صحیح باشند و چه غیر آن، عددهای ممیز شناور با دقت دوگانه‌ی IEEE754 هستند.
این ما را به ۵۳ بیت دقت محدود می‌کند.

عملگرهای معمول برای استفاده با عددها در دسترس هستند:

- حساب: `+`, `-`, `*`, `/`, `%`
- مقایسه: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [توابع ریاضی][man-math] استاندارد

  برای توابع تک‌ورودی، مقدار را به تابع pipe کنید

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  برای توابع دو‌ورودی، تابع ورودی را نادیده می‌گیرد و انتظار دارد که
  ورودی‌ها به‌صورت پارامتر داده شوند (به یاد بیاورید که پارامترها با
  نقطه‌ویرگول از هم جدا می‌شوند)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  نقطه‌ویرگول جداکننده‌ی آرگومان‌های تابع است، نه کاما.

## سایر عبارت‌های `jq`

برای حل تمرین، باید با عبارت‌های شرطی آشنا شوید.

### عبارت‌های شرطی

`jq` برای **عبارت‌های شرطی** از یک [عبارت `if-then-else`][if-then-else] استفاده می‌کند.
این عبارت، به‌عنوان یک _عبارت_، درون یک pipeline قرار می‌گیرد.

نحوه‌ی نگارش چنین است: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

بخش `else` اختیاری است.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

شرط‌های بیشتر از `elif` استفاده می‌کنند

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
