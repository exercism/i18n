# مقدمه

## رشته

یک `String` در Java شیئی است که متنی تغییرناپذیر را به‌صورت دنباله‌ای از کاراکترهای یونیکد (حروف، ارقام، نشانه‌های نگارشی و غیره) نمایش می‌دهد.
برای تعریف یک نمونه‌ی `String` از «نقل‌قول دوگانه» استفاده می‌شود:

```java
String fruit = "Apple";
```

رشته‌ها با فراخوانی کردن متدهای رشته دستکاری می‌شوند.
وقتی یک رشته ساخته شد، مقدار آن هرگز تغییر نمی‌کند.
هر متدی که به نظر برسد رشته را تغییر می‌دهد، در واقع رشته‌ی جدیدی برمی‌گرداند.
کلاس `String` چند متد _static_ برای تبدیل رشته‌ها فراهم می‌کند.
