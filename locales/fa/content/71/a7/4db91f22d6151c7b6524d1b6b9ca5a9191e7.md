# مقدمه

رشته‌ها در Gleam متن‌های تغییرناپذیری هستند که داخل گیومه‌ی دوتایی قرار می‌گیرند. از کاراکترهای یونیکد پشتیبانی می‌کنند و می‌توانند چندخطی باشند.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

می‌توان رشته‌ها را با استفاده از عملگر `<>` به هم متصل کرد:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

ماژول [`gleam/string`][stdlib] در کتابخانه‌ی استاندارد، توابعی برای کار با رشته‌ها فراهم می‌کند.

در عبارت‌های `case` می‌توان روی رشته‌ها مطابقت انجام داد:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

اگر می‌خواهید با ابتدای یک رشته مطابقت دهید و بقیه را به یک متغیر اختصاص دهید، می‌توانید از الگوی عملگر `<>` استفاده کنید:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
