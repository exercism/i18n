# تست

## اجرای تست‌ها

وقتی در پوشه‌ی یک تمرین هستید، باید دو زیرپوشه ببینید:

* `Sources/<Exercise>` شامل راه‌حل شما برای تمرین است
* `Tests/<Exercise>Tests` شامل تست‌هایی است که باید برای تمرین اجرا شوند

اگر در پوشه‌ی درست قرار دارید (یعنی همان پوشه‌ای که `Sources` و `Tests` را در خود دارد)، می‌توانید با اجرای `swift test` تست‌های آن تمرین را اجرا کنید:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

وقتی یک تست را پاس کردید، برای فعال کردن تست بعدی `.enabled(if: RUNALL)` را از دستور `@Test` حذف کنید؛ یا این که می‌توانید همه‌ی تست‌ها را با تنظیم متغیر محیطی `RUNALL` روی `true` در لینوکس یا macOS اجرا کنید:

```bash
$ export RUNALL=true
```

یا اگر در ویندوز از PowerShell استفاده می‌کنید:

```powershell
set RUNALL=true
```

## ارسال راه‌حل شما

برای بارگذاری یک راه‌حل در Exercism، باید در پوشه‌ای باشید که پوشه‌های `Sources` و `Tests` را در خود دارد.

```bash
$ exercism submit 
```
