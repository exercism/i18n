# دستورالعمل

الیس که می‌خواهد شعبده‌باز شود، باید اصول اولیه را تمرین کند. او یک دسته کارت دارد که می‌خواهد با آن کار کند.

برای اینکه کار کمی ساده‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

## 1. ساخت یک slice با کارت‌های مشخص

وقتی الیس با کارت‌هایش تمرین می‌کند، دوست دارد کارش را با سه کارت محبوبش از دسته شروع کند: ۲، ۶ و ۹.
تابعی به اسم `FavoriteCards` بنویسید که یک slice با همان کارت‌ها به همان ترتیب برمی‌گرداند.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. بازیابی یک کارت از دسته

کارت واقع در موقعیت `index` را از دسته‌ی داده‌شده برگردانید.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

اگر اندیس «خارج از محدوده» باشد (یعنی منفی باشد یا بعد از انتهای دسته)، می‌خواهیم `-1` را برگردانیم:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
بر اساس قرارداد در Go، به‌جای برگرداندن یک مقدار خارج از محدوده، یک خطا برگردانده می‌شود.
اینجا وقتی یک عدد صحیح مثبت انتظار می‌رود، مقدار خارج از محدوده `-1` است.
هنگام برگرداندن خطا، مرسوم است که [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) را همراه با خطا برگردانید.
برگرداندن خطا همراه با مقدار بازگشتی مناسب در تمرین آینده بررسی می‌شود.
~~~~

## 3. تعویض یک کارت در دسته

کارت واقع در موقعیت `index` را با کارت جدیدی که داده شده تعویض کنید و دسته‌ی تنظیم‌شده را برگردانید.
توجه کنید که این کار slice ورودی را تغییر می‌دهد که رفتار مورد انتظار است.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

اگر اندیس خارج از محدوده باشد (یعنی منفی باشد یا بعد از انتهای دسته)، می‌خواهیم کارت جدید را به انتهای دسته اضافه کنیم:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. افزودن کارت‌ها به بالای دسته

کارت یا کارت‌های مشخص‌شده در پارامتر `value` را به بالای دسته اضافه کنید.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

اگر برای پارامتر `value` هیچ آرگومانی داده نشود، نتیجه برابر با slice اصلی است.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. حذف یک کارت از دسته

کارت واقع در موقعیت `index` را از دسته حذف کنید و دسته را برگردانید.
توجه کنید که این کار ممکن است slice ورودی را تغییر دهد که اشکالی ندارد.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

اگر اندیس خارج از محدوده باشد (یعنی منفی باشد یا بعد از انتهای دسته)، می‌خواهیم دسته بدون تغییر بماند:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
