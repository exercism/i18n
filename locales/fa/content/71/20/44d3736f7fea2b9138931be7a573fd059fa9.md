# مقدمه

`list` در F# مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار است. همه‌ی مقدارهای یک لیست باید از یک نوع باشند. چون لیست‌ها تغییرناپذیرند، پس از این که یک لیست ساخته شد، مقدارش هرگز تغییر نمی‌کند. هر تابع یا عملگری که به نظر می‌رسد یک لیست را تغییر می‌دهد (مثل افزودن یک عنصر)، در واقع یک لیست تازه برمی‌گرداند.

لیست‌ها را می‌توان به این شکل تعریف کرد:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

رایج‌ترین راه برای افزودن یک عنصر به لیست، استفاده از عملگر `::` (cons) است:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

یک لیست F# یک _سر_ (اولین عنصر) و یک _دنباله_ (همه‌ی آنچه پس از عنصر اول می‌آید) دارد. دنباله‌ی یک لیست، خودش یک لیست است.

لیست‌ها یا با تابع‌ها و عملگرهای تعریف‌شده در ماژول `List` دستکاری می‌شوند، یا به‌صورت دستی با تطبیق الگو و به کمک الگوهای _list_ و _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

همچنین می‌توانید هنگام تطبیق الگو یک مقدار را _نادیده بگیرید_؛ وقتی در یک حالت مشخص به یک مقدار اهمیت نمی‌دهید (یعنی قصد ندارید از آن مقدار _استفاده_ کنید)، می‌توانید برای نشان دادن این موضوع از زیرخط (`'_'`) استفاده کنید:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

این `'_'` تکی باید هنگام تطبیق الگو همیشه در _آخر_ بیاید؛ هر مقداری که با هیچ‌یک از حالت‌های دیگر مطابقت _نداشته باشد_، توسط این حالت مدیریت می‌شود.
