# مقدمه

بیشتر واژه‌های دنباله در Factor *دنباله‌های جدید* را برمی‌گردانند و ورودی‌هایشان را دست‌نخورده رها می‌کنند، اما آرایه‌ها و بردارها هر دو از **تغییر درجا** پشتیبانی می‌کنند، برای زمانی که می‌خواهید حالتی را ثبت کنید که به‌مرور زمان تغییر می‌کند.

`set-nth` و `change-nth` یک خانه را درجا تغییر می‌دهند. هر دوی اینها روی آرایه یا بردار کار می‌کنند. `<array>` یک آرایه‌ی قابل‌تغییر با طول ثابت می‌سازد؛ لیترال‌های `V{ }` و همچنین `<vector>` و `push` و `pop` مجموعه‌ی مخصوص بردار هستند، چون طول آرایه‌ها نمی‌تواند تغییر کند. `clone` دنباله را تکثیر می‌کند تا تغییرهای بعدی به نسخه‌ی اصلی سرایت نکنند.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
