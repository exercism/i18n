# همگام‌سازی با GitHub

سلام به همه!

ما چند ماه گذشته را صرف کار سخت روی [Coding Fundamentals](https://exercism.org/courses/coding-fundamentals) و [Front-End Fundamentals Bootcamp](https://exercism.org/courses/front-end-fundamentals) کرده‌ایم؛ این دوره‌ها برای ما تجربه‌های فوق‌العاده‌ای بودند. حالا که تمام شده‌اند، کمی وقت می‌گذاریم تا چند قابلیت تازه به سایت اصلی Exercism اضافه کنیم!

امروز **دو قابلیت تازه** را در Exercism راه‌اندازی می‌کنیم:
1. راه‌حل‌هایتان را با GitHub همگام‌سازی کنید.
2. Favorites خود را ذخیره کنید و در آن کاوش کنید.

## همگام‌سازی راه‌حل‌هایتان با GitHub

داشتن یک نسخه‌ی پشتیبان عمومی از راه‌حل‌های خودتان، از مدت‌ها پیش خواسته‌ی کاربران بوده است.
بسیاری از افراد راه‌حل‌هایشان را به‌صورت دستی با GitHub همگام‌سازی می‌کنند یا حتی اسکریپت‌های خودشان را برای این کار نوشته‌اند، اما حالا این کار **در خود Exercism تعبیه شده است!**

به محض اینکه این قابلیت را فعال کنید، پشتیبان‌گیری خودکار از راه‌حل‌هایتان در GitHub آغاز می‌شود. می‌توانید تنظیم کنید که پشتیبان‌گیری از طریق Pull Request انجام شود یا کامیت، و همه‌ی راه‌حل‌های پیشین خود را به‌صورت یک‌جا بارگذاری کنید!

یک ماه پیش این قابلیت را بی‌سروصدا برای Insiders راه‌اندازی کردیم و تا کنون ده‌ها هزار راه‌حل را در GitHub پشتیبان‌گیری کرده‌ایم. هرچه افراد بیشتری از آن استفاده کرده‌اند، بیشتر آن را پسندیده‌اند. همان‌طور که یکی از کاربران Insiders گفت:

> وقتی این قابلیت اولین بار مطرح شد، نظر خاصی درباره‌اش نداشتم، اما حالا که آمده، بسیار خوشحالم که آن را جلو بردید! دیگر نمی‌توانم Exercism را بدون آن تصور کنم.
> 
> \- W8CYE در Discord

برای شروع، کافی است به [صفحه‌ی تنظیمات GitHub Syncer](https://exercism.org/settings/github_syncer) بروید و یک مخزن را متصل کنید!

## Favorites

امروز همچنین [Exercism Favorites](https://exercism.org/favorites) را راه‌اندازی می‌کنیم، جایی برای ذخیره و مرور بهترین راه‌حل‌هایی که در Exercism پیدا می‌کنید.

Favorites به‌عنوان راهی طراحی شده است تا هر آنچه جالب، الهام‌بخش یا چشمگیر می‌یابید را ثبت کنید: می‌توانید هنگام گشتن در سایت راه‌حل‌ها را ستاره‌دار کنید و بعد هر وقت دنبال کاوش بیشتری هستید، دوباره به آن‌ها سر بزنید.

برای افزودن یک Favorite، کافی است روی دکمه‌ی Favorite در هر یک از راه‌حل‌های کاربران کلیک کنید. می‌بینید که متن به Favorited تغییر می‌کند و ستاره طلایی می‌شود!
اگر می‌خواهید یک Favorite را حذف کنید، کافی است دوباره روی آن کلیک کنید.

<img src="https://assets.exercism.org/images/community/favorites-button.png" alt="تصویری از صفحه‌ی راه‌حل کاربران که دکمه‌ی Favorite را نشان می‌دهد" style="width:100%; max-width:600px;" width="2182" height="980" />

هر راه‌حلی که قبلاً آن را ستاره‌دار کرده‌اید، به‌طور خودکار به Favorites شما منتقل شده است. می‌توانید از طریق منوی Learn یا مستقیماً از [این لینک](https://exercism.org/favorites) به Favorites دسترسی داشته باشید.
