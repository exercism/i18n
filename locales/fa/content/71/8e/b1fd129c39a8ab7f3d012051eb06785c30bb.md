# دستورالعمل‌ها

انجمن محله‌ی شما از شما خواسته است که یک برنامه‌ی ثبت ساده برای مدیریت ثبت‌نام‌های باغ محله پیاده‌سازی کنید. ساختار `Plot` هم از قبل برایتان آماده شده است.

## 1. باغ را باز کنید

تابع `CommunityGarden.start/1` را پیاده‌سازی کنید. این تابع باید یک فهرست کلیدواژه‌ی اختیاری از گزینه‌ها دریافت کند تا به _فرایند agent_ فرستاده شود. حالت اولیه‌ی باغ باید طوری مقداردهی شود که نماینده‌ی مجموعه‌ای خالی از قطعه‌ها باشد. این تابع باید یک تاپل `:ok` همراه با `pid` باغ برگرداند.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. ثبت‌نام‌ها را فهرست کنید

تابع `CommunityGarden.list_registrations/1` را پیاده‌سازی کنید. این تابع باید `pid` باغ محله را دریافت کند. باید فهرستی از قطعه‌های ذخیره‌شده که ثبت شده‌اند برگرداند.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> در این مرحله هنوز امکان ثبت قطعه را اضافه نکرده‌ایم، پس این فهرست باید خالی باشد

## 3. قطعه‌ها را به اسم یک شخص ثبت کنید

تابع `CommunityGarden.register/2` را پیاده‌سازی کنید. این تابع باید `pid` باغ محله و یک اسم را برای ثبت قطعه دریافت کند. در صورت موفقیت باید ساختار `Plot` را همراه با شناسه‌ی قطعه و شخصی که قطعه به اسم او ثبت شده است برگرداند.

شناسه‌ها باید افزایشی و یکتا باشند. می‌توانید یک شمارنده‌ی شناسه در حالت فرایند agent نگه دارید.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. قطعه‌ها را آزاد کنید

تابع `CommunityGarden.release/2` را پیاده‌سازی کنید. این تابع باید `pid` و `id` قطعه را که باید آزاد شود دریافت کند. در صورت موفقیت باید `:ok` برگرداند. وقتی قطعه‌ای آزاد می‌شود، شناسه‌اش دوباره استفاده نمی‌شود و فقط به عنوان یک شناسه‌ی یکتا به کار می‌رود.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. یک قطعه‌ی ثبت‌شده را بگیرید

تابع `CommunityGarden.get_registration/2` را پیاده‌سازی کنید. این تابع باید `pid` و `id` قطعه را که باید بررسی شود دریافت کند. اگر قطعه ثبت شده باشد آن را برمی‌گرداند و اگر ثبت نشده باشد `:not_found` را برمی‌گرداند.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
