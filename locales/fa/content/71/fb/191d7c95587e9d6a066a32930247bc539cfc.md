# مقدمه

## مبانی

Java یک زبان با نوع ایستا است، یعنی نوع متغیر در زمان کامپایل مشخص است.
اختصاص دادن یک مقدار به یک اسم، تعریف متغیر گفته می‌شود.
متغیر با مشخص کردن صریح نوع آن تعریف می‌شود.

```java
int explicitVar = 10;
```

به‌روزرسانی مقدار متغیر از طریق عملگر `=` انجام می‌شود.
در اینجا، `=` نشان‌دهنده‌ی برابری ریاضی نیست.
فقط مقداری را به یک متغیر اختصاص می‌دهد.
پس از تعریف، نوع متغیر هرگز تغییر نمی‌کند.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java یک [زبان شیءگرا][object-oriented-programming] است و لازم است همه‌ی توابع در یک _«کلاس»_ تعریف شوند.
از کلیدواژه‌ی `class` برای تعریف یک کلاس استفاده می‌شود.

```java
class Calculator {
    // ...
}
```

به تابعی که درون یک کلاس قرار دارد، _«متد»_ می‌گویند.
هر متد می‌تواند صفر یا چند «پارامتر» داشته باشد.
نوع همه‌ی پارامترها باید صریحاً مشخص شود؛ برای پارامترها استنتاج نوع وجود ندارد.
به همین ترتیب، نوع بازگشتی نیز باید صریحاً مشخص شود.
مقدارها با استفاده از کلیدواژه‌ی `return` از متدها برگردانده می‌شوند.
برای اینکه متد بتواند توسط کلاس‌های دیگر فراخوانی شود، باید اصلاح‌کننده‌ی دسترسی `public` اضافه شود.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

فراخوانی یک متد با مشخص کردن کلاس و اسم متد و ارسال «آرگومان» برای هر یک از پارامترهای متد انجام می‌شود.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

دامنه در Java بین کاراکترهای `{` و `}` تعریف می‌شود.

Java از دو نوع «کامنت» پشتیبانی می‌کند.
کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
