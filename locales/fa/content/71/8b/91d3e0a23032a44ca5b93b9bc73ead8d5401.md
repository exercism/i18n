# دستورالعمل‌ها

در این تمرین، یک سیستم موجودی را مدیریت می‌کنید.

موجودی باید بر اساس اسم قلم مرتب شود و تعداد اقلام موجود را پیگیری کند.

باید افزودن اقلام به موجودی را مدیریت کنید. هر بار که قلمی در یک فهرست مشخص ظاهر شود، مقدار آن قلم در موجودی باید به اندازه‌ی `1` افزایش پیدا کند. همچنین باید حذف اقلام از موجودی را مدیریت کنید؛ به این شکل که هر وقت درخواست شد، مقدارها به اندازه‌ی `1` کاهش پیدا کنند.

در پایان، باید تابعی پیاده‌سازی کنید که همه‌ی جفت‌های کلید-مقدار یک موجودی را به‌صورت یک `list` از `tuples` برگرداند.


## 1. ساخت یک موجودی بر اساس یک فهرست

تابع `create_inventory(<input list>)` را پیاده‌سازی کنید که یک «موجودی» را از یک فهرست ورودی از اقلام می‌سازد. این تابع باید یک `dict` برگرداند که در آن اسم هر قلم در کنار مقدار متناظرش آمده است.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. افزودن اقلام یک فهرست به یک دیکشنری موجود

تابع `add_items(<inventory dict>, <item list>)` را پیاده‌سازی کنید که یک فهرست از اقلام را به موجودی داده‌شده اضافه می‌کند:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. کاهش اقلام موجودی

تابع `decrement_items(<inventory dict>, <items list>)` را پیاده‌سازی کنید که یک `list` از اقلام می‌گیرد. تابع شما باید برای هر بار که یک قلم در `list` ظاهر می‌شود، `1` را از تعداد آن قلم کم کند:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

تعداد اقلام موجودی نباید کمتر از 0 شود.
 اگر تعداد دفعاتی که یک قلم در `list` ورودی ظاهر می‌شود از تعداد موجود بیشتر باشد، مقدار ثبت‌شده برای آن قلم باید روی 0 باقی بماند.
 پس از آنکه تعداد به صفر رسید، درخواست‌های بعدی برای کاهش آن نادیده گرفته می‌شوند.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. حذف کامل یک ورودی از موجودی

تابع `remove_item(<inventory dict>, <item>)` را پیاده‌سازی کنید که یک قلم و تعدادش را به‌طور کامل از موجودی حذف می‌کند:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

اگر آن قلم در موجودی پیدا نشود، تابع باید موجودی اصلی را بدون تغییر برگرداند.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. بازگرداندن کل محتوای موجودی

تابع `list_inventory(<inventory dict>)` را پیاده‌سازی کنید که یک موجودی می‌گیرد و فهرستی از تاپل‌های `(item, quantity)` برمی‌گرداند.
این فهرست باید فقط شامل اقلام _موجود_ (_با مقداری بزرگ‌تر از صفر_) باشد:

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
