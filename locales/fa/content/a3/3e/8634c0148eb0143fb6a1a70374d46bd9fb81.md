# دودویی، هشت‌هشتی و شانزده‌شانزدهی

دودویی، هشت‌هشتی و شانزده‌شانزدهی (_که به آن هگز هم می‌گویند_) [دستگاه‌های اعداد][numeral-systems] گوناگونی با مبنای متفاوت‌اند.
مبنای دودویی ۲ است، مبنای هشت‌هشتی ۸ و مبنای شانزده‌شانزدهی ۱۶.
عددهای صحیح معمولی در Crystal مبنای ۱۰ دارند.
دودویی، هشت‌هشتی و شانزده‌شانزدهی همه نمایش‌هایی از عددهای صحیح هستند.
یعنی عددهای مثبت و منفی (_از جمله صفر_) را بدون کسر یا اعشار نشان می‌دهند و همه‌ی عملیاتی را که می‌توانیم با عددهای صحیح انجام دهیم پشتیبانی می‌کنند.

## دودویی

[دودویی][binary] یک دستگاه اعداد با مبنای ۲ است که فقط از رقم‌های ۰ و ۱ استفاده می‌کند.
این دستگاه معمولاً حالت‌های ۰ («خاموش») و ۱ («روشن») جریان برق گذرنده از ترانزیستورها و کلیدهای رایانه را نشان می‌دهد و نیز بارهای مثبت و منفی را در رسانه‌های ذخیره‌سازی مغناطیسی.
دودویی می‌تواند همه‌ی عددهای صحیحی را که در مبنای ۱۰ به کار می‌روند نمایش دهد.

بخشی از دستگاه مبنای ۲ چنین است، هرچند تا بی‌نهایت ادامه دارد و به ۱۲۸ ختم نمی‌شود:

| ۱۲۸      | ۶۴       | ۳۲       | ۱۶       | ۸        | ۴        | ۲        | ۱        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| ۲ \*\* ۷ | ۲ \*\* ۶ | ۲ \*\* ۵ | ۲ \*\* ۴ | ۲ \*\* ۳ | ۲ \*\* ۲ | ۲ \*\* ۱ | ۲ \*\* ۰ |

پس اگر بخواهیم عدد ۶ را نمایش دهیم، در دودویی چنین می‌شود: ۱۱۰

| ارزش مکانی    | ۴   | ۲   | ۱   |
| ------------- | --- | --- | --- |
| عدد دودویی    | ۱   | ۱   | ۰   |

و عملیات چنین می‌شود: `4 + 2 + 0 = 6`

مثال دیگر: ۱۹

| ارزش مکانی    | ۱۶  | ۸   | ۴   | ۲   | ۱   |
| ------------- | --- | --- | --- | --- | --- |
| عدد دودویی    | ۱   | ۰   | ۰   | ۱   | ۱   |

عدد دودویی چنین می‌شود: ۱۰۰۱۱
و عملیات چنین می‌شود: `16 + 0 + 0 + 2 + 1 = 19`

## دودویی در Crystal

در Crystal می‌توانیم لیترال‌های دودویی را با پیشوند `0b` بنویسیم.
اگر `0b10011` بنویسیم، Crystal آن را عددی دودویی تفسیر می‌کند و به مبنای ۱۰ تبدیل می‌کند.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

اگر عددی با پیشوند `0b` بنویسید که در دستگاه دودویی نیست، خطای کامپایل ایجاد می‌شود.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### عملیات با عددهای دودویی

چون عددهای دودویی خودشان عدد صحیح هستند، می‌توانیم همه‌ی عملیاتی را که با عددهای صحیح انجام می‌دهیم روی آن‌ها هم انجام دهیم.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### تبدیل به نمای دودویی و از آن

Crystal یک لیترال دودویی را به‌طور خودکار به `Int32` تبدیل می‌کند.
برای تبدیل یک `Int32` به نمایش دودویی، از متد [`<int>.to_s(base)`][to_s] با آرگومان base برابر ۲ استفاده کنید.
این متد یک نمایش رشته‌ای از عدد دودویی برمی‌گرداند:

```crystal
19.to_s(2)
# => "10011"
```

برای تبدیل نمایش رشته‌ای یک عدد دودویی به عدد صحیح، می‌توانیم از متد [`<int>.to_i(base)`][to_i] استفاده کنیم و مبنای (۲) را به‌عنوان آرگومان بدهیم:

```crystal
"10011".to_i(2)
# => 19
```

اگر مبنای نادرست (_یا یک نمایش دودویی نامعتبر_) بدهید، خطای `ArgumentError` ایجاد می‌شود:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### متدهای دودویی

متدهایی وجود دارند که می‌توان آن‌ها را روی عددهای صحیح به کار برد تا اطلاعاتی درباره‌ی نمایش دودویی عدد به دست آورد.

[`<int>.bit_length`][bit_length] تعداد بیت‌هایی را برمی‌گرداند که برای نمایش عدد لازم است:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] بیت موجود در اندیس داده‌شده را برمی‌گرداند، با شمارش از سمت راست (_کم‌ارزش‌ترین بیت_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## هشت‌هشتی

[هشت‌هشتی][octal] یک دستگاه اعداد با مبنای ۸ است.
از رقم‌های ۰، ۱، ۲، ۳، ۴، ۵، ۶ و ۷ استفاده می‌کند.

در Crystal می‌توانیم عددهای هشت‌هشتی را با پیشوند `0o` نمایش دهیم.
مانند دودویی، Crystal به‌طور خودکار یک نمایش هشت‌هشتی را به `Int32` تبدیل می‌کند.

```crystal
0o123
# => 83
```

اگر به عددی که در دستگاه هشت‌هشتی نیست پیشوند `0o` بدهید، خطای کامپایل ایجاد می‌شود.

### تبدیل به نمای هشت‌هشتی و از آن

مانند دودویی، می‌توانیم از متد [`<int>.to_s(base)`][to_s] برای تبدیل یک `Int32` به نمایش هشت‌هشتی استفاده کنیم.
و می‌توانیم از متد [`<int>.to_i(base)`][to_s] برای تبدیل یک نمایش هشت‌هشتی به `Int32` استفاده کنیم.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

مانند دودویی، اگر مبنای نادرست بدهید، خطای `ArgumentError` ایجاد می‌شود.

## شانزده‌شانزدهی

[شانزده‌شانزدهی][hexadecimal] یک دستگاه اعداد با مبنای ۱۶ است.
از رقم‌های ۰ تا ۹ و حروف A، B، C، D، E و F استفاده می‌کند.
A برابر ۱۰ است، B برابر ۱۱، C برابر ۱۲، D برابر ۱۳، E برابر ۱۴ و F برابر ۱۵.

می‌توانیم عددهای شانزده‌شانزدهی را در Crystal با پیشوند `0x` نمایش دهیم.
مانند دودویی و هشت‌هشتی، Crystal لیترال‌های شانزده‌شانزدهی را به‌طور خودکار به `Int32` تبدیل می‌کند.

```crystal
#=> 0x123
291
```
 
اگر به عددی که شانزده‌شانزدهی نیست پیشوند `0x` بدهید، خطای کامپایل ایجاد می‌شود.

### تبدیل به نمای شانزده‌شانزدهی و از آن

مانند دودویی، می‌توانیم از متد [`<int>.to_s(base)`][to_i] برای تبدیل یک `Int32` به نمایش شانزده‌شانزدهی استفاده کنیم.
و می‌توانیم از متد [`<int>.to_i(base)`][to_s] برای تبدیل یک نمایش شانزده‌شانزدهی به `Int32` استفاده کنیم.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

مانند دودویی و هشت‌هشتی، اگر مبنای نادرست بدهید، خطای `ArgumentError` ایجاد می‌شود.

## دقت

هنگام تبدیل یک عدد به نمایش رشته‌ای، می‌توانیم دقت عدد را مشخص کنیم.
یعنی **کمترین** تعداد رقم‌هایی که برای نمایش عدد به کار می‌رود.
اگر رقم‌های عدد از دقت کمتر باشد، صفرهای ابتدایی به نمایش رشته‌ای اضافه می‌شوند.
این کار با دادن آرگومان `precision` به متد [`<int>.to_s(<base>, precision: <value>)`][to_s] انجام می‌شود.

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
