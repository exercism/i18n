# معرفی

حلقه‌ی `for` امکان پیمایش روی یک آرایه و تکرار کد برای هر عنصر را فراهم می‌کند:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

در مثال بالا، `fruit` متغیری است که مقدار یک عنصر از آرایه‌ی `fruitList` را نگه می‌دارد. کامپایلر مطمئن می‌شود که می‌توان روی `fruitList` پیمایش کرد؛ در غیر این صورت اجرا را متوقف می‌کند.

می‌توانید با استفاده از عملگر بازه روی اعداد پیمایش کنید. این عملگر دو عملوند از نوع `Int` می‌گیرد و به‌صورت `min...max` نوشته می‌شود:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
