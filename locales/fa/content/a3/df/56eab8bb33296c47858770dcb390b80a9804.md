# درباره

[رشته‌ها][getting-started-strings] در Elixir با علامت نقل‌قول دوگانه مشخص می‌شوند و با UTF-8 کدگذاری می‌شوند:

```elixir
"Hi!"
```

رشته‌ها را می‌توان با عملگر [`<>/2`][kernel-concat] به هم چسباند:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

رشته‌ها در Elixir از [درج][string-interpolation] با شکل نوشتن `#{}` پشتیبانی می‌کنند:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

هر عبارت Elixir درون درج معتبر است. اگر یک رشته داده شود، همان رشته بدون تغییر درج می‌شود. اگر مقدار دیگری داده شود، Elixir تلاش می‌کند آن را به رشته تبدیل کند.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir توابع زیادی برای کار با رشته‌ها در ماژول `String` ارائه می‌دهد. اگر مطمئن نیستید چطور رشته‌ای را به شکلی که لازم دارید پردازش کنید، حتماً [توابع موجود در ماژول `String`][string-module-functions] را مرور کنید؛ به احتمال زیاد همان را که نیاز دارید پیدا خواهید کرد.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

هنگام استفاده از برخی از این توابع، به یاد داشته باشید که اندیس اولین کاراکتر یک رشته `0` است.

برای قرار گرفتن در یک رشته، برخی کاراکترها باید [escape شوند][escape-characters]، مثل خط جدید، علامت نقل‌قول دوگانه یا کاراکتر `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

برای کار راحت با متن‌هایی که خط جدید زیادی دارند، به‌جای آن از [روش نوشتن heredoc با سه علامت نقل‌قول دوگانه][heredoc-syntax] استفاده کنید:

```elixir
"""
1
2
3
"""
```

خیلی وقت‌ها می‌بینید که از این روش برای مستندسازی کد استفاده می‌شود:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
