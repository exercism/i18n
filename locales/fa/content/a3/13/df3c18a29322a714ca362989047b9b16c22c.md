# توابع

در JavaScript، توابع _شیءهای درجه‌یک_ هستند؛ یعنی می‌توان آن‌ها را به متغیرها و ویژگی‌ها اختصاص داد، به توابع دیگر پاس داد و از توابع بازگرداند. آن‌ها هم مانند هر _شیء_ دیگری می‌توانند ویژگی و متد داشته باشند.

## ورودی: پاس دادن آرگومان‌ها

توابع JavaScript به شما اجازه می‌دهند هنگام فراخوانی، آرگومان پاس دهید. آرگومان‌ها همیشه [با مقدار پاس داده می‌شوند](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). به عبارت دیگر، اگر تابعی پارامتری را درون خودش دوباره مقداردهی کند، آن مقدار بیرون از تابع تغییر نمی‌کند. این به آن معنا نیست که اشیای پاس‌داده‌شده را نمی‌توان تغییر داد.

> [!TIP]
> وقتی شیئی پاس داده می‌شود، ارجاع به آن شیء با مقدار پاس داده می‌شود. همین باعث می‌شود _به نظر برسد_ که پاس دادن اشیا رفتار متفاوتی دارد، اما این‌طور نیست.

نمونه‌ای از تابعی که دو آرگومان می‌گیرد و آن‌ها را در هم ضرب می‌کند:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## خروجی: مقدار بازگشتی

JavaScript می‌تواند با استفاده از کلیدواژه‌ی `return` و سپس یک عبارت، یک مقدار را از تابع بازگرداند. وقتی چیزی از تابع بازگردانده نشود، مقدار بازگشتی `undefined` است.

نمونه‌ای از تابعی که یک مقدار بازمی‌گرداند:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## تعریف توابع

در JavaScript چهار نوع تابع وجود دارد:

1. توابع معمولی که می‌توانند هر مقداری بازگردانند و همیشه تا پایان اجرا می‌شوند؛
2. توابع async که همیشه یک `Promise` بازمی‌گردانند و می‌توان آن‌ها را با عملگر `await` متوقف و دوباره ادامه داد؛
3. توابع مولد که همیشه یک شیء `Generator` بازمی‌گردانند و می‌توان آن‌ها را با عملگر `yield` متوقف و دوباره ادامه داد؛
4. توابع مولد async که همیشه یک شیء `AsyncGenerator` بازمی‌گردانند و می‌توان آن‌ها را با _هر دو_ عملگر `yield` و `await` متوقف و دوباره ادامه داد.

برای هر یک از این چهار نوع، سه روش برای تعریف وجود دارد:

1. با استفاده از یک اعلان
2. با استفاده از یک عبارت
3. با استفاده از سازنده

در پایان، روش نگارش خاصی برای تعریف _توابع پیکانی و متدها_ وجود دارد.
