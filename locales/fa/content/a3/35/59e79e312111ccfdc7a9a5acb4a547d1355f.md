# دستورالعمل‌ها

در این تمرین، مکانیک‌های یک بازی نقش‌آفرینی را پیاده‌سازی می‌کنید.
شخصیت هر بازیکن با نوع زیر نمایش داده می‌شود:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

بازیکن‌های این بازی باید به سطح ۱۰ برسند تا منبع مانا برایشان باز شود و بتوانند پرتاب طلسم را شروع کنند.
در این بازی روی دو بخش از عملکردها کار می‌کنید: مکانیک احیا و مکانیک پرتاب طلسم.

## 1. خودتان را معرفی کنید

محتوای تابع `introduce` را بنویسید.
توجه کنید که فیلد `Name` در رکورد `Player` از نوع `Option` است.
بازیکن‌های زیرک ممکن است بخواهند اسمشان را پنهان کنند و آن را روی `None` بگذارند؛ چنین بازیکن‌هایی با `"Mighty Magician"` معرفی می‌شوند.
در غیر این صورت، فقط با اسم خودتان معرفی کنید.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. مکانیک احیا را پیاده‌سازی کنید

تابع `revive` باید بررسی کند که شخصیت بازیکن واقعاً مرده است (جانش به ۰ رسیده است).
اگر مرده باشد، باید یک نمونه‌ی جدید از `Player` با ۱۰۰ جان برگرداند.
در غیر این صورت، اگر شخصیت بازیکن نمرده باشد، تابع `revive` مقدار `None` را برمی‌گرداند.

اگر سطح بازیکن ۱۰ یا بالاتر باشد، باید با ۱۰۰ مانا هم احیا شود.
اگر سطح بازیکن کمتر از ۱۰ باشد، مانای او باید `None` باشد.
تابع `revive` باید سطح بازیکن را حفظ کند.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

اگر متد `revive` روی بازیکنی فراخوانی شود که جانش ۱ یا بالاتر است، تابع باید `None` را برگرداند.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. مکانیک پرتاب طلسم را پیاده‌سازی کنید

تابع `castSpell` دو آرگومان می‌گیرد: یک `int` که نشان می‌دهد طلسم چه مقدار مانا هزینه دارد و یک `Player`.
خروجی این تابع، بازیکن به‌روزشده و مقدار آسیبی است که طلسم پرتاب‌شده وارد می‌کند.
اگر طلسمی با موفقیت پرتاب شود، آسیبی برابر با دو برابر هزینه‌ی مانای طلسم وارد می‌کند.
اما اگر بازیکن مانای کافی نداشته باشد، هیچ اتفاقی نمی‌افتد، بازیکن بی‌تغییر می‌ماند و هیچ آسیبی وارد نمی‌شود.
اگر بازیکن حتی منبع مانا هم نداشته باشد، تلاش برای پرتاب طلسم باید جانش را به اندازه‌ی هزینه‌ی مانای طلسم کاهش دهد و هیچ آسیبی وارد نمی‌کند.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
