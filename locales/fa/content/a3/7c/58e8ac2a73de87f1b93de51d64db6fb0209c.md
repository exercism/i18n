# مقدمه

## رشته

رشته‌ها در Elixir با گیومه‌های دوتایی مشخص می‌شوند و با UTF-8 کدگذاری شده‌اند:

```elixir
"Hi!"
```

رشته‌ها را می‌توان با عملگر `<>/2` به هم چسباند:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

رشته‌ها در Elixir از درج با روش نگارش `#{}` پشتیبانی می‌کنند:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

برای گذاشتن کاراکتر خط جدید در یک رشته، از دنباله‌ی فرار `\n` استفاده کنید:

```elixir
"1\n2\n3\n"
```

برای کار راحت با متن‌هایی که خط جدید زیادی دارند، در عوض از روش نوشتن heredoc با سه گیومه‌ی دوتایی استفاده کنید:

```elixir
"""
1
2
3
"""
```

Elixir توابع زیادی برای کار با رشته‌ها در ماژول `String` ارائه می‌دهد.

## عملگر پایپ

به عملگر `|>`، عملگر پایپ می‌گویند. می‌توان از آن برای زنجیره‌کردن فراخوانی توابع به شکلی استفاده کرد که مقدار برگشتی از فراخوانی تابع قبلی، به‌عنوان آرگومان اول به فراخوانی تابع بعدی داده شود.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
