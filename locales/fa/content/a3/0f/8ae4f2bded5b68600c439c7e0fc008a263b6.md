# مقدمه

## انواع `struct`

انواع `struct` را قبلاً دیده‌ایم؛ برای مرور، `struct` دنباله‌ای از عناصر است که هر کدام یک اسم و یک نوع دارند و به آن‌ها «فیلد» می‌گوییم.
اسم هر فیلد باید درون `struct` یکتا باشد.
انواع `struct` را می‌توان با «کلاس» در پارادایم برنامه‌نویسی شیءگرا مقایسه کرد.

برای ساخت یک `struct` جدید، از کلیدواژه‌های `type` و `struct` استفاده می‌کنید و سپس اسم و نوع فیلدها را همان‌طور که در مثال زیر نشان داده شده است، به‌صراحت تعریف می‌کنید.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## انواع غیر `struct`

تعریف انواع غیر `struct` نیز ممکن است؛ می‌توانید از آن‌ها به‌عنوان نام مستعار برای اعلان‌های نوع توکار استفاده کنید.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

همچنین می‌توانید انواع غیر `struct` را که از آرایه‌ها و `map`ها تشکیل شده‌اند تعریف کنید.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
