# پیوست دستورالعمل

## «صفت‌های» Rust برای `.to_string()`

همچنین باید `.to_string()` را برای ساختار `Clock` پیاده‌سازی کنید. قرار است از این برای نمایش وضعیت ساعت استفاده کنیم. می‌توانید آن را مستقیم پیاده‌سازی کنید یا از صفت [`Display`][display-trait] استفاده کنید.

اگر این کار را می‌کنید، به‌جای آن صفت `Display` را برای `Clock` پیاده‌سازی کنید.

صفت‌ها راهی مشترک برای پیاده‌سازی قابلیت‌ها برای انواع مختلف فراهم می‌کنند.

برای یادگیری بیشتر، در نظر بگیرید که چگونه می‌توانید `String::from` را برای نوع `Clock` پیاده‌سازی کنید. لازم نیست واقعاً این را پیاده‌سازی کنید (با `Display` تکراری است و وقتی نوع مقصد `String` باشد معمولاً انتخاب بهتری است)، اما داشتن چند صفت تبدیل نوع در جعبه‌ابزارتان مفید است.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
