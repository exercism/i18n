# درباره

کدی بنویسید که مثل انگلیسی ساده خوانده شود.

Visual Basic روی همان «ران‌تایم» .NET اجرا می‌شود که C# و F# روی آن اجرا می‌شوند.
شما به LINQ، generics و async/await دسترسی دارید، اما نحوه‌ی نگارش آن برای خوانده شدن ساخته شده است، نه برای رمزگشایی شدن.

اگر از قبل C# یا F# را می‌شناسید، ران‌تایم و کتابخانه‌های .NET برایتان آشنا خواهند بود.
اگر VB6، VBA یا VBScript را می‌شناسید، پشتوانه‌ی آن نحوه‌ی نگارش آشنا اکنون ران‌تایم محک‌خورده‌ی .NET است.

نه آکولادی که نگران جفت شدنش باشید، نه نقطه‌ویرگولی که دنبالش بدوید.
