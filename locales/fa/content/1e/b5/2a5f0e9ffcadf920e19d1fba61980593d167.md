# یکپارچه‌سازی ویرایشگر

بهترین روش برای توسعه‌ی Clojure استفاده از REPL متصل به ویرایشگر است. برای محبوب‌ترین ویرایشگرها و IDEها افزونه در دسترس است:

- Emacs: [CIDER](https://cider.mx)
- IntelliJ: [Cursive](https://cursive-ide.com)
- VSCode: [Calva](https://calva.io)
- Vim: [Conjure](https://github.com/Olical/conjure)

برای اطلاعات بیشتر، [مستندات رسمی](https://clojure.org/guides/editors) را ببینید.
