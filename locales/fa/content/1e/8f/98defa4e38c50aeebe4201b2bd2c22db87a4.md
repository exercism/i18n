# دستورالعمل‌ها

بخش ادعاهای Isaac's Asteroid Exploration Co. به شما مأموریت داده است که عملکرد سیستم ثبت ادعای زمین آن‌ها را بهبود دهید.

هر بار که سیارکی آماده‌ی بهره‌برداری می‌شود، از سوداگران دعوت می‌شود که ادعای خود را نسبت به یک قطعه زمین ثبت کنند.
زمین سیارک به قطعه‌های مستطیلی بدون هم‌پوشانی تقسیم می‌شود.
ابعادشان با هم فرق دارد، اما اضلاع همه موازی با محورهای مختصات است.
سوداگران با مشخص کردن مختصات، یکی از قطعه‌های زمین را به نام خود ثبت می‌کنند.

هدف شما ساخت یک سیستم کارآمد برای مدیریت هجوم ثبت زمین است؛ هجومی که در گذشته باعث از کار افتادن وب‌سایت شده بود.

واحد اندازه‌گیری ۱۰۰ متر است، اما در این تمرین‌ها می‌توان آن را نادیده گرفت.

## 1. تعریف یک نقطه

یک `struct` تعریف کنید که مختصات `x` و `y` را نگه دارد.
این مختصات اعداد صحیح نامنفی و نسبتاً کوچکی هستند، پس از نوع `UInt16` استفاده کنید.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. تعریف یک `Plot`

چون همه‌ی قطعه‌ها باید مستطیلی با اضلاع افقی و عمودی باشند، برای تعریف هر قطعه فقط به دو گوشه‌ی مقابل آن نیاز است.

ساختار `Plot` را پیاده‌سازی کنید، به‌طوری که سازنده‌اش دو ساختار `Coord` بگیرد.

`Plot` باید یک ساختار کلیدواژه‌ای با فیلدهای `bottom_left` و `top_right` باشد.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. بررسی این‌که ادعای شما پیش‌تر ثبت شده است یا نه

بر سر این ادعاها رقابت وجود دارد، بنابراین پیش از اینکه ادعای شما پذیرفته شود، آن را با ادعاهای موجود در دفتر ثبت مقایسه می‌کنند.

تابع `is_claim_staked()` را پیاده‌سازی کنید تا مشخص کنید آیا ادعایی پیش‌تر ثبت شده است یا نه.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. سوداگران می‌توانند ادعای خود را با مشخص کردن قطعه‌ای که با مختصات گوشه‌هایش تعیین می‌شود ثبت کنند

تابع تغییردهنده‌ی `stake_claim!()` را پیاده‌سازی کنید تا امکان ثبت یک ادعا فراهم شود.

اگر همان ادعا پیش‌تر ثبت شده باشد، `false` را برگردانید.

اگر ادعای تازه‌ای امکان‌پذیر باشد، آن را به دفتر ثبت اضافه کنید و `true` را برگردانید.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. یافتن طول ضلع بلندتر یک قطعه

تابع `get_longest_side()` را پیاده‌سازی کنید تا ضلع بلندتر (افقی یا عمودی) یک ادعا را به دست آورید.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. یافتن قطعه‌ای که ادعا شده است و بلندترین ضلع را دارد، برای اهداف پژوهشی

تابع `get_claim_with_longest_side()` را پیاده‌سازی کنید تا همه‌ی ادعاهای ثبت‌شده را بررسی کنید و ادعا(ها)یی را که بلندترین ضلع را دارند برگردانید.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

`Plot`(ها) را به‌صورت یک `Set` برگردانید: اگر تنها یک قطعه بلندترین ضلع را داشته باشد، یک عنصر دارد و در صورت تساوی چند عنصر.
