# مقدمه

R نوع جداگانه‌ای برای [مجموعه][wiki-set] ندارد؛ در عوض از توابع متنوعی استفاده می‌کند که عملیات مشابهی را روی بردارها انجام می‌دهند.

عملگر [`%in%`][ref-match] عضویت در مجموعه را بررسی می‌کند.
این عملگر میان‌وندی هم‌معنی تابع `is.element()` است.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

توابع مرتبط عبارت‌اند از:

- [`unique()`][ref-unique] برای حذف مقادیر تکراری.
- [`union()`][ref-sets] برای ترکیب مجموعه‌ها (از نظر ریاضی، `A ∪ B`).
- [`intersect()`][ref-sets] برای یافتن عناصری که در هر دو مجموعه مشترک‌اند (`A ∩ B`).
- [`setdiff()`][ref-sets] برای تفریق یک مجموعه از مجموعه‌ی دیگر (`A - B`).
- [`setequal`][ref-sets] برای بررسی برابری مجموعه‌ها، با نادیده گرفتن مقادیر تکراری و ترتیب.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

در هر مورد، تابع یک رونوشت برمی‌گرداند و آرگومان‌ها را بدون تغییر باقی می‌گذارد.

## جدول هش

عملیات برداری که در بالا توضیح داده شد، بخشی از R پایه است.
این عملیات برای مسائل کوچک مفیدند، اما برای مجموعه‌های بزرگ کند می‌شوند.

بسته‌های شخص ثالث مختلفی [جدول‌های هش][wiki-hash] را پیاده‌سازی می‌کنند تا در برخی زمینه‌ها کارایی را بهتر کنند.

برای مثال، بسته‌ی [`hashtable`][ref-hashtable] پیاده‌سازی‌هایی از `hashmap` و `hashset` ارائه می‌دهد که بهتر مقیاس می‌پذیرند.
مانند بیشتر بسته‌های بیرونی، این بسته در Exercism در دسترس نیست، اما ارزش بررسی برای مسائل دنیای واقعی را دارد.
