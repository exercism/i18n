# مقدمه

## سرریز

«سرریز محاسباتی» زمانی رخ می‌دهد که نتیجه‌ی یک محاسبه، مانند یک عملیات حسابی یا یک تبدیل نوع، مقداری بزرگ‌تر از ظرفیت نوع دریافت‌کننده باشد.

عبارت‌هایی از نوع `int` و `long` و معادل‌های بدون علامت‌شان در چنین شرایطی بی‌صدا دور می‌زنند.

رفتار محاسبات روی اعداد صحیح را می‌توان با استفاده از کلیدواژه‌ی `checked` تغییر داد. وقتی درون یک بلوک `checked` سرریزی رخ دهد، نمونه‌ای از `OverflowException` پرتاب می‌شود.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

عبارت‌هایی از نوع `float` و `double` مقدار خاص بینهایت را می‌گیرند.

عبارت‌هایی از نوع `decimal` نمونه‌ای از `OverflowException` را پرتاب می‌کنند.
