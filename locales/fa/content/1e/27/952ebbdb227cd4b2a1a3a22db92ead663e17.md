# ارجاع و عکس لحظه‌ای

وقتی متغیری را به یک تابع می‌دهید، معمولاً مالکیت آن منتقل می‌شود و متغیر اصلی دیگر قابل استفاده نیست. این موضوع وقتی بیش از یک بار به یک حالت دسترسی پیدا می‌کنید، کمی خسته‌کننده می‌شود.
Cairo دو قابلیت برای دادن یک مقدار بدون نابود کردن یا جابه‌جا کردن آن دارد که `references` و `snapshots` نامیده می‌شوند.

## عکس لحظه‌ای

«عکس لحظه‌ای» نمایی تغییرناپذیر از یک مقدار در یک لحظه‌ی زمانی مشخص به شما می‌دهد و به شما اجازه می‌دهد مالکیت یک متغیر را حفظ کنید و در همان حال به حالت آن دسترسی داشته باشید.
هر تغییری در متغیر یک خانه‌ی حافظه‌ی جدید می‌سازد و نمای عکس لحظه‌ای دست‌نخورده باقی می‌ماند.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## عملگر Desnap

برای تبدیل دوباره‌ی یک عکس لحظه‌ای به یک متغیر معمولی، می‌توانید از عملگر desnap یعنی `*` استفاده کنید که نقطه‌ی مقابل عملگر `@` است.
فقط انواعی که «ویژگی `Copy`» را پیاده‌سازی می‌کنند می‌توانند desnap شوند.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## ارجاع تغییرپذیر

«ارجاع تغییرپذیر» به شما اجازه می‌دهد مقادیر تغییرپذیر را به یک تابع بدهید و آن‌ها به‌طور ضمنی برگردانده شوند، در حالی که مالکیت در بافت فراخوانی‌کننده حفظ می‌ماند.
این کار با استفاده از «اصلاح‌کننده»ی `ref` انجام می‌شود، به شرطی که متغیر با «کلیدواژه»ی `mut` به‌صورت تغییرپذیر اعلام شده باشد.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
