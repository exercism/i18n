`String` و `&str` دو روش بنیادین برای کار با داده‌های متنی در Rust هستند.

`String` یک بردار مالکیت‌شده از بایت‌های `u8` است و تغییرپذیر است.
`&str` یک ارجاع قرض‌گرفته‌شده به برشی از String است و بنابراین تغییرناپذیر است.

همچنین می‌توانید `String`ها را با استفاده از یکی از متدهای متعددشان ایجاد و تغییر دهید، مانند `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

همچنین می‌توانید با تبدیل یک `&str`، یک `String` بسازید:
```rust
let a_string = "hello".to_string();
```
