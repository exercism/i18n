# مقدمه

«حلقه‌ی For» یکی از پرکاربردترین دستورها برای اجرای مکرر یک منطق است. در JavaScript، این حلقه شامل «کلیدواژه‌ی `for`»، یک _هدر_ که داخل پرانتز قرار می‌گیرد و یک «بلوک کد» است که _بدنه‌ی_ حلقه را در خود دارد و داخل آکولاد قرار می‌گیرد.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

«مقداردهی اولیه» معمولاً یک متغیر شمارنده را آماده می‌کند، «شرط» بررسی می‌کند که آیا حلقه باید ادامه یابد یا متوقف شود و «گام» شمارنده را در پایان هر تکرار یک واحد افزایش می‌دهد. بخش‌های مختلف هدر با نقطه‌ویرگول از هم جدا می‌شوند.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

تعریف گام اغلب با استفاده از عملگر افزایش یا کاهش JavaScript انجام می‌شود، همان‌طور که در مثال بالا نشان داده شده است. این عملگرها یک متغیر را در جای خود تغییر می‌دهند. `++` یک واحد به یک عدد اضافه می‌کند و `--` یک واحد از یک عدد کم می‌کند.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
