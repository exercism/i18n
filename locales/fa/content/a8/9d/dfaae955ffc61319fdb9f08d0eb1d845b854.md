# دستورالعمل‌ها

شما در حال ساخت بازی جدید و پرطرفدار «Wings Quest» هستید.
در این بازی شما یک پرنده هستید که این‌طرف و آن‌طرف حرکت می‌کند و دانه جمع می‌کند.
بازیکن با برداشتن همه‌ی دانه‌ها برنده می‌شود.
اگر بازیکن با عقابی تماس پیدا کند، همه‌ی دانه‌هایش را از دست می‌دهد و بازی را می‌بازد.
یک استثنا برای این قاعده وجود دارد: بازیکن می‌تواند یک «پاورآپ» فعال داشته باشد که باعث می‌شود بالاتر از پرنده‌های دیگر پرواز کند.

هدف شما نوشتن چند قاعده است که در بازی استفاده خواهند شد.

## 1. تعیین کنید آیا پرنده امتیاز جایزه می‌گیرد

در بازی، پرنده اگر در حالی که پاورآپ دارد با عقابی تماس پیدا کند، امتیاز جایزه می‌گیرد.

تابع `bonusPoints(powerUpActive:touchingEagle:)` را تعریف کنید که دو ورودی می‌گیرد: `powerUpActive` که نشان می‌دهد آیا پرنده پاورآپ فعال دارد یا نه، و ورودی `touchingEagle` که نشان می‌دهد آیا پرنده با عقابی در تماس است یا نه.
تابع باید فقط زمانی `true` برگرداند که پرنده پاورآپ فعال داشته باشد و با عقابی در تماس باشد، و در غیر این صورت `false` برگرداند.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. تعیین کنید آیا پرنده امتیاز می‌گیرد

در بازی، بازیکن با برداشتن یک دانه یا یک پاورآپ امتیاز می‌گیرد.

تابع `score(touchingPowerUp:touchingSeed:)` را تعریف کنید که دو ورودی می‌گیرد: `touchingPowerUp` که نشان می‌دهد آیا پرنده با پاورآپی در تماس است، و ورودی `touchingSeed` که نشان می‌دهد آیا پرنده با دانه‌ای در تماس است.
تابع باید اگر پرنده با پاورآپ یا دانه‌ای در تماس باشد `true` برگرداند، و در غیر این صورت `false` برگرداند.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. تعیین کنید آیا پرنده می‌بازد

تابع `lose(powerUpActive:touchingEagle:)` را تعریف کنید که دو ورودی می‌گیرد: `powerUpActive` که نشان می‌دهد آیا پرنده پاورآپ فعال دارد یا نه، و ورودی `touchingEagle` که نشان می‌دهد آیا پرنده با عقابی در تماس است یا نه.
تابع باید اگر شخصیت بازی با عقابی در تماس باشد و پاورآپ فعال نداشته باشد `true` برگرداند، و در غیر این صورت `false` برگرداند.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. تعیین کنید آیا پرنده برنده می‌شود

تابع `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` را تعریف کنید که این ورودی‌ها را می‌گیرد:

- `hasPickedUpAllSeeds` اگر پرنده همه‌ی دانه‌ها را برداشته باشد.
- `powerUpActive` اگر پرنده پاورآپ فعال داشته باشد.
- `touchingEagle` اگر پرنده با عقابی در تماس باشد.

تابع باید اگر پرنده همه‌ی دانه‌ها را جمع کرده باشد و بر اساس ورودی‌های تعریف‌شده در بخش ۳ بازی را نباخته باشد `true` برگرداند، و در غیر این صورت `false` برگرداند.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
