# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به یک فریلنسر کمک می‌کند با یک مدیر پروژه ارتباط برقرار کند.
وظیفه‌ی شما این است که چند ابزار کمکی ارائه دهید تا نرخ‌های روزانه و ماهانه را به‌سرعت محاسبه کنید، به‌صورت اختیاری همراه با یک تخفیف مشخص.

ابتدا چند قاعده بین فریلنسر و مدیر پروژه تعیین می‌کنیم:

- نرخ روزانه ۸ برابر نرخ ساعتی است.
- هر ماه ۲۲ روز قابل صورت‌حساب دارد.

گاهی فریلنسر پیشنهاد می‌دهد که روی نرخ روزانه‌اش تخفیف اعمال کند (برای مثال برای وفادارترین مشتریانش یا مشتریان غیرانتفاعی).

تخفیف‌ها به‌صورت اعداد اعشاری مدل‌سازی می‌شوند که درصد را نشان می‌دهند، برای مثال `25.0` (۲۵٪).

~~~~exercism/note
این‌ها پسوندهای دستورهای ممیز شناور هستند:

| پسوند | اندازه‌ی عملوند |
|--------|--------------|
| `ss`   | ۳۲ بیتی       |
| `sd`   | ۶۴ بیتی       |

این‌ها برخی از دستورهایی هستند که در این مفهوم به آن‌ها اشاره شده است:

| دستور       | توضیح                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | `b` را در `a` کپی می‌کند                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | عدد صحیح `b` را به عدد ممیز شناور `a` تبدیل می‌کند                 |
| roundss/roundsd a, b, c | عدد ممیز شناور `b` را بر اساس `c` گرد می‌کند و نتیجه را در `a` ذخیره می‌کند |
| cvtss2si/cvtsd2si a, b  | عدد ممیز شناور `b` را به عدد صحیح `a` تبدیل می‌کند                 |
| comiss/comisd a, b      | بین `a` و `b` مقایسه انجام می‌دهد؛ اگر `NaN` باشد، استثنا ایجاد می‌کند |
| ucomiss/ucomisd a, b    | بین `a` و `b` مقایسه انجام می‌دهد؛ اگر `NaN` باشد، `PF` را تنظیم می‌کند |

این‌ها اعداد کنترل گرد کردن در `roundss` و `roundsd` هستند:

| عدد | حالت         |
|:-------|:-------------|
| 0      | نزدیک‌ترین      |
| 1      | کف (پایین) |
| 2      | سقف (بالا)    |
| 3      | برش     |
~~~~

## 1. نرخ روزانه را با داشتن نرخ ساعتی محاسبه کنید

تابعی به اسم `daily_rate` پیاده‌سازی کنید تا نرخ روزانه را محاسبه کند؛ این تابع یک نرخ ساعتی را به‌عنوان پارامتر می‌گیرد که یک عدد ممیز شناور ۶۴ بیتی است.
قرارداد تعیین می‌کند که هر روز ۸ ساعت قابل صورت‌حساب دارد.

```c
daily_rate(60)
// => 480.0
```

نرخ روزانه‌ی برگردانده‌شده باید یک عدد ممیز شناور ۶۴ بیتی باشد.

## 2. قیمت تخفیف‌خورده را محاسبه کنید

تابعی به اسم `apply_discount` را پیاده‌سازی کنید تا قیمت را پس از تخفیف محاسبه کند.
این تابع باید دو پارامتر بپذیرد: قیمت اصلی و نرخ تخفیف به درصد، که هر دو به‌صورت یک عدد ممیز شناور ۶۴ بیتی هستند.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

مقدار برگردانده‌شده باید همیشه یک عدد ممیز شناور ۶۴ بیتی باشد.

## 3. نرخ ماهانه را با داشتن نرخ ساعتی و تخفیف محاسبه کنید

تابعی به اسم `monthly_rate` را پیاده‌سازی کنید تا نرخ ماهانه‌ی تخفیف‌خورده را محاسبه کند.
این تابع دو پارامتر می‌گیرد: یک نرخ ساعتی و تخفیف به درصد، که هر دو به‌صورت یک عدد ممیز شناور ۶۴ بیتی هستند.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

نرخ ماهانه‌ی برگردانده‌شده باید به نزدیک‌ترین عدد صحیح ۶۴ بیتی، به سمت بالا (سقف)، گرد شود.

## 4. تعداد روزهای کاری کامل را با داشتن بودجه، نرخ ساعتی و تخفیف محاسبه کنید

تابعی به اسم `days_in_budget` را پیاده‌سازی کنید که این پارامترها را می‌گیرد:

1. یک بودجه، به‌صورت یک عدد صحیح بدون علامت ۶۴ بیتی.
2. یک نرخ ساعتی، به‌صورت یک عدد ممیز شناور ۶۴ بیتی.
3. یک تخفیف به درصد، به‌صورت یک عدد ممیز شناور ۶۴ بیتی.

این تابع باید تعداد روزهای کاری کاملی را که بودجه پوشش می‌دهد برگرداند.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

تعداد روزهای برگردانده‌شده باید به نزدیک‌ترین عدد صحیح ۳۲ بیتی، به سمت پایین (کف)، گرد شود.
