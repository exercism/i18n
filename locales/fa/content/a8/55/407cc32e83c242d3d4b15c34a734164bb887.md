# درباره

ثابت‌ها مقادیری هستند که در زمان کامپایل تعیین می‌شوند و نمی‌توان دوباره به آن‌ها مقدار داد.
برای تعریف یک ثابت واحد از کلیدواژه‌ی `const` استفاده کنید:

```go
const greeting = "hello"
```

می‌توان چندین ثابت را در یک بلوک تعریف کرد.
در داخل یک بلوک، ثابتی که مقدار صریحی برایش تعیین نشده باشد، عبارت قبلی را تکرار می‌کند:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

ثابت‌ها معمولاً در سطح پکیج تعریف می‌شوند، هرچند می‌توان آن‌ها را درون یک تابع هم تعریف کرد.

## ثابت‌های نوع‌دار و بدون نوع

اگر ثابتی را بدون تعیین نوع تعریف کنید، بدون نوع می‌شود.
یک ثابت بدون نوع، نوع مشخصی ندارد؛ مقدارش تعیین می‌کند که با چه نوع‌هایی سازگار است.
تا زمانی که مقدار زیربنایی سازگار باشد، کامپایلر در هر بار استفاده آن را به نوع موردنیاز تبدیل می‌کند:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

ثابت نوع‌دار، نوع را در همان زمان تعریف تثبیت می‌کند:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## چه مقادیری می‌توانند ثابت باشند

ثابت‌ها فقط می‌توانند مقادیر منطقی، اعداد، رشته‌ها و `rune`ها باشند.
چون مقادیر در زمان کامپایل تعیین می‌شوند، از نتیجه‌ی فراخوانی یک تابع نمی‌توان به عنوان ثابت استفاده کرد.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

در یک بلوک از ثابت‌ها، `iota` موقعیت یک ثابت را در آن بلوک نشان می‌دهد:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

هر ثابت پس از ثابت اول، همان عبارت را به ارث می‌برد و مقدار `iota` هر بار یک واحد افزایش می‌یابد.

`iota` در عبارات هم به کار می‌رود.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
