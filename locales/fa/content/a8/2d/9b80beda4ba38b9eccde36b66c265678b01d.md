# مقدمه

## اینترفیس به‌عنوان مجموعه‌ای از متدها

در ساده‌ترین شکل خود، یک **نوع اینترفیس** مجموعه‌ای از امضاهای متد است.
در ادامه نمونه‌ای از تعریف یک اینترفیس را می‌بینید که دو متد `Add` و `Value` را در بر می‌گیرد:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

نام پارامترها مانند `increment` را می‌توان از تعریف اینترفیس حذف کرد، اما معمولاً خوانایی را بیشتر می‌کنند.

اسم اینترفیس‌ها در Go شامل کلمه‌ی `Interface` یا `I` نمی‌شود.
در عوض، معمولاً به `er` ختم می‌شوند، مثلاً `Reader` و `Stringer`.

## پیاده‌سازی یک اینترفیس

هر نوعی که متدهای اینترفیس را تعریف کند، به‌طور خودکار و به‌صورت ضمنی اینترفیس را «پیاده‌سازی» می‌کند.
کلیدواژه‌ی `implements` در Go وجود ندارد.

نوع زیر اینترفیس `Counter` را که در بالا دیدیم، پیاده‌سازی می‌کند.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

برای پیاده‌سازی اینترفیس، مهم نیست که متد گیرنده‌ی مقداری داشته باشد یا گیرنده‌ی اشاره‌گر.
(اگر در این مورد مطمئن نیستید، [مفاهیم متدها][concept-methods] را مرور کنید.)

> یک مقدار از نوع اینترفیس می‌تواند هر مقداری را که آن متدها را پیاده‌سازی می‌کند، نگه دارد. ((Go Tour: Interfaces)[go-tour-interfaces])

این یعنی حالا می‌توان از `Stats` در همه‌ی جاهایی که انتظار اینترفیس `Counter` را دارند استفاده کرد.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

چون اینترفیس‌ها به‌صورت ضمنی پیاده‌سازی می‌شوند، یک نوع به‌راحتی می‌تواند چندین اینترفیس را پیاده‌سازی کند.
فقط کافی است همه‌ی متدهای لازم را تعریف کرده باشد.

## اینترفیس خالی

یک نوع اینترفیس بسیار خاص در Go وجود دارد، **اینترفیس خالی** که هیچ متدی ندارد.
اینترفیس خالی به این شکل نوشته می‌شود: `interface{}`.
در Go 1.18 یا بالاتر، می‌توان از `any` هم استفاده کرد.
`any` به‌عنوان یک نام مستعار تعریف شده است.

چون اینترفیس خالی هیچ متدی ندارد، هر نوعی آن را به‌صورت ضمنی پیاده‌سازی می‌کند.
این برای تعریف تابعی مفید است که بتواند به‌شکلی عمومی هر مقداری را بپذیرد.
در این حالت، پارامتر تابع از نوع اینترفیس خالی استفاده می‌کند.
