# بدون `rescue`

از «استثنا» برای «کنترل جریان» استفاده نکنید.
تلاش کنید این تمرین را بدون استفاده از `rescue` حل کنید.

اگر از تابعی از کتابخانه‌ی استاندارد استفاده می‌کنید که اسمش به `!` ختم می‌شود (خطا ایجاد می‌کند)، دنبال تابع معادلی بگردید که `!` ندارد (اغلب `{:ok, result}` یا `{:error, message}` برمی‌گرداند).

توجه: اگر این پیام خودکار را روی راه‌حل خود می‌بینید، ممکن است سایر پیام‌های خودکار دقیق نباشند.
اول این مشکل را برطرف کنید!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
