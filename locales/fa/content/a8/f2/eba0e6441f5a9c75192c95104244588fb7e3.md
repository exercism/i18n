# مقدمه

یک `vector` در Clojure مجموعه‌ای ترتیبی، اندیس‌دار و تغییرناپذیر از صفر یا بیشتر مقدار است. یعنی وقتی یک `vector` ساخته شد، دیگر نمی‌توان آن را تغییر داد. توابعی که روی `vector`ها کار می‌کنند یک `vector` جدید برمی‌گردانند، در حالی که `vector` اصلی بدون تغییر باقی می‌ماند. مقادیر داخل یک `vector` می‌توانند از انواع ناهمگون باشند. `vector`ها را می‌توان به شکل زیر تعریف کرد:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

می‌توان با استفاده از یک اندیس، عناصر را از یک `vector` بازیابی کرد. `vector`های Clojure از صفر شروع می‌شوند؛ یعنی اندیس اولین عنصر همیشه صفر است:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

`vector` اصلی بدون تغییر باقی می‌ماند:

```clojure
numbers
;;=> [2 3 5]
```

برای به خاطر سپردن مقدار به‌روزشده، باید آن را همراه بفرستیم یا در یک `var` نگه داریم:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
