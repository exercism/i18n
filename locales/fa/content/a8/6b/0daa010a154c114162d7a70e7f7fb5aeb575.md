# راهنمایی‌ها

## کلی

- برای استخراج چندین آرگومان در پارامترهای تابع می‌توانید آن‌ها را با عملگر `*arguments` برای **آرایه** یا `**keyword_arguments` برای آرگومان‌های مبتنی بر کلیدواژه بسته‌بندی کنید.
- برای بسته‌بندی یا باز کردن بسته‌بندی از عملگرهای splat (`*` یا `**`) استفاده کنید.

## 1. ساختن فهرستی از همه‌ی واگن‌ها

- چندین آرگومان در پارامترهای تابع را می‌توان با عملگر `*arguments` بسته‌بندی کرد.

## 2. درست کردن فهرست واگن‌ها

- استفاده از باز کردن بسته‌بندی با عملگر splat (`*`) به شما امکان می‌دهد دو عنصر اول یک **آرایه** را استخراج کنید و بقیه را دست‌نخورده نگه دارید.
- برای افزودن یک **آرایه**ی دیگر به یک **آرایه**ی موجود، می‌توانید از عملگر splat (`*`) برای «پخش» کردن **آرایه** استفاده کنید.

## 3. افزودن ایستگاه‌های جاافتاده

- استفاده از `**keyword_arguments` به‌عنوان آرگومان یک متد، امکان ارسال هر تعداد دلخواه آرگومان کلیدواژه‌ای را فراهم می‌کند.
- استفاده از `**<hash>` به‌عنوان آرگومان، یک `Hash` را به آرگومان‌های کلیدواژه‌ای باز می‌کند.
- می‌توانید آرگومان‌های کلیدواژه‌ای را داخل `{}` قرار دهید که روش دیگری برای ساختن یک `Hash` است.
- برای بیرون کشیدن مقادیر از یک `Hash` می‌توانید از متد `Hash#values` استفاده کنید.

## 4. گسترش اطلاعات مسیریابی

- استفاده از `**{some_hash: value}` به‌عنوان آرگومان، `Hash` را به آرگومان‌های کلیدواژه‌ای باز می‌کند.
