# راهنمایی

## کلی

- برای اینکه یک اسم بتواند چند نوع مختلف داشته باشد، باید از [نوع اتحاد][union-type] استفاده کنید.
- برای اینکه بتوان از یک متغیر نمونه در یک عبارت کنترلی مانند [`if var.is_a?(Type)`][if-is-a] استفاده کرد، ابتدا باید آن را به یک متغیر محلی نسبت داد.

## 1. تنظیم گذرواژه

- باید کلاسی به اسم `PasswordLock` تعریف کنید.
- باید متدی به اسم `initialize` تعریف کنید که یکی از `String`، `Int32` یا `Float64` را به عنوان آرگومان می‌گیرد.
- باید یک [متغیر نمونه][instance-variable] به اسم `@password` تعریف کنید که مقدارش برابر آرگومان ارسال‌شده به سازنده باشد.

## 2. رمزگذاری گذرواژه

- یک متد نمونه به اسم `encrypt` تعریف کنید.
- این متد باید [متغیر نمونه][instance-variable] `@password` را طوری تغییر دهد که رمزگذاری شود.
- برای اینکه یک شاخه‌ی مشخص فقط در صورتی قابل اجرا باشد که متغیر از نوع خاصی باشد، باید از متد [`is_a?`][is-a] در یک عبارت کنترلی استفاده کنید.

## 3. بررسی درستی گذرواژه

- می‌توانید از متدهای از پیش تعریف‌شده برای رمزگذاری گذرواژه‌ی ورودی استفاده کنید.
