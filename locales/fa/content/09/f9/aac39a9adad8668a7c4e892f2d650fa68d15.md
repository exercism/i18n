# مقدمه

[Stringer][stringer-interface] یک اینترفیس برای تعیین قالب رشته‌ای مقادیر است.

این اینترفیس از یک متد واحد به اسم `String` تشکیل شده است:

```go
type Stringer interface {
    String() string
}
```

نوع‌هایی که می‌خواهند این اینترفیس را پیاده‌سازی کنند باید متدی به اسم `String()` داشته باشند که یک نمایش رشته‌ای خوانا برای انسان از آن نوع را برمی‌گرداند.
بسته‌ی [fmt][fmt-package] (و بسیاری از بسته‌های دیگر) برای قالب‌بندی و چاپ مقادیر به دنبال همین متد می‌گردد.

## مثال: فاصله‌ها

فرض کنید روی برنامه‌ای کار می‌کنیم که با فاصله‌های جغرافیایی اندازه‌گیری‌شده در واحدهای مختلف سروکار دارد.
نوع‌های `DistanceUnit` و `Distance` را به شکل زیر تعریف کرده‌ایم:

```go
type DistanceUnit int

const (
	Kilometer    DistanceUnit = 0
	Mile         DistanceUnit = 1
)

type Distance struct {
	number float64
	unit   DistanceUnit
}
```

در مثال بالا، `Kilometer` و `Mile` ثابت‌هایی از نوع `DistanceUnit` هستند.

این نوع‌ها اینترفیس `Stringer` را پیاده‌سازی نمی‌کنند، چون متد `String` را ندارند.
در نتیجه، توابع `fmt` مقادیر `Distance` را با «قالب پیش‌فرض» Go چاپ می‌کنند:

```go
mileUnit := Mile
fmt.Sprint(mileUnit)
// => 1
// The result is '1' because that is the underlying value of the 'Mile' constant (see constant declarations above)

dist := Distance{number: 790.7, unit: Kilometer}
fmt.Sprint(dist)
// => {790.7 0}
// not a very useful output!
```

برای اینکه خروجی اطلاعات بیشتری بدهد، اینترفیس `Stringer` را برای نوع‌های `DistanceUnit` و `Distance` پیاده‌سازی می‌کنیم و به هر نوع یک متد `String` اضافه می‌کنیم:

```go
func (sc DistanceUnit) String() string {
	units := []string{"km", "mi"}
	return units[sc]
}

func (d Distance) String() string {
	return fmt.Sprintf("%v %v", d.number, d.unit)
}
```

توابع بسته‌ی `fmt` هنگام قالب‌بندی مقادیر `Distance` این متدها را فراخوانی می‌کنند:

```go
kmUnit := Kilometer
kmUnit.String()
// => km

mileUnit := Mile
mileUnit.String()
// => mi

dist := Distance{
	number: 790.7,
	unit: Kilometer,
}
dist.String()
// => 790.7 km
```
