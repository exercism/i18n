# مقدمه

## بسته‌ها و ماژول‌ها

### وارد کردن

ماژول معمولاً با «کلیدواژه»ی `use` بارگذاری می‌شود.
این کار هم ماژول را بارگذاری می‌کند و هم «متد» `import` را روی آن فراخوانی می‌کند و هر نماد صادرشده‌ای را وارد می‌کند.

«نماد»های موجود در آرایه‌ی `@EXPORT` بسته به‌طور پیش‌فرض وارد می‌شوند.
نمادهای موجود در آرایه‌ی `@EXPORT_OK` بسته باید به‌صورت صریح وارد شوند.

### صادر کردن

برای اینکه نمادی وارد شود، ابتدا باید صادر شده باشد.
ماژول [Exporter][Exporter] همراه Perl ارائه می‌شود و یکی از راحت‌ترین گزینه‌ها برای صادر کردن است.

تعریف ماژول:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

استفاده از ماژول:
```perl
use Foo ('bar');

bar();
```

### ماژول‌های اصلی

در کنار [Exporter][Exporter]، Perl مجموعه‌ی گسترده‌ای از [ماژول‌های اصلی][perl-core-modules] را در اختیارتان می‌گذارد که می‌توانید از آن‌ها استفاده کنید.
چند نمونه که برای تمرین‌هایی که ممکن است اینجا با آن‌ها روبه‌رو شوید مفیدند عبارت‌اند از [List::Util][List::Util]، [Time::Piece][Time::Piece] و [Math::BigRat][Math::BigRat].

### CPAN

علاوه بر ماژول‌های اصلی، [CPAN][metacpan] هزاران ماژول دیگر هم دارد که جامعه‌ی Perl ساخته‌اند و برای نصب در دسترس‌اند.
مسیر Perl از یک [cpanfile][test-runner-cpanfile] استفاده می‌کند تا مجموعه‌ای از ماژول‌ها را نصب کند که می‌توان آن‌ها را با test runner Perl در Exercism به کار برد.
