اما همه‌چیز کمی بی‌نظم است: به نظر می‌رسد مختصات Aazra با مختصات Rui متفاوت قالب‌بندی و مرتب شده است و آنها باید مدام از این فهرست به آن فهرست نگاه کنند تا بفهمند کدام گنج‌ها به کدام مکان‌ها مربوط‌اند. از آنجا که Gleamlinهای تازه‌کاری هستند، پیش شما آمده‌اند تا به آنها در نوشتن یک برنامه‌ی کوچک (در واقع مجموعه‌ای از توابع) برای سازماندهی بهتر اطلاعات شکارشان کمک کنید.

## 1. تبدیل مکان‌ها

تابع `place_location_to_treasure_location` را پیاده‌سازی کنید که یک مکان (مانند `#("C", 1)`) می‌گیرد و آن را به مکان گنج (مانند `#(1, "C")`) تبدیل می‌کند.

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. مقایسه‌ی مکان گنج و مکان

تابع `treasure_location_matches_place_location` را پیاده‌سازی کنید که یک مکان (مانند `#("C", 1)`) می‌گیرد و اگر با مکان یک گنج (مانند `#(1, "C")`) مطابقت داشته باشد، `True` برمی‌گرداند.

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. شمارش گنج‌های یک مکان

تابع `count_place_treasures` را پیاده‌سازی کنید که یک مکان (مانند `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) و فهرست گنج‌ها را می‌گیرد و تعداد گنج‌هایی را برمی‌گرداند که می‌توان در آنجا پیدا کرد.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. مکان‌های ویژه

تابع `special_case_swap_possible` را پیاده‌سازی کنید که یک گنج (مانند `#("Amethyst Octopus", #(1, "F"))`)، یک مکان (مانند `#("Seaside Cottages", #("C", 1))`) و یک گنج دلخواه (مانند `#("Crystal Crab", #(6, "A"))`) می‌گیرد و برای ترکیب‌های زیر `True` برمی‌گرداند:

- Brass Spyglass را می‌توان در Abandoned Lighthouse با هر گنج دیگری عوض کرد.
- Amethyst Octopus را می‌توان در Stormy Breakwater با Crystal Crab یا Glass Starfish عوض کرد.
- Vintage Pirate Hat را می‌توان در Harbor Managers Office با Model Ship in Large Bottle یا Antique Glass Fishnet Float عوض کرد.
