# مقدمه

واژگانِ [`random`][random] در Factor یک واژه‌ی عمومی به نام `random` ارائه می‌دهد که خود را با ورودی‌اش تطبیق می‌دهد و علاوه بر آن، ابزارهای کمکی‌ای هم برای درهم‌ریختن و نمونه‌برداری از دنباله‌ها دارد.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

`random` وقتی روی یک عدد صحیح مثل `n` اعمال شود، مقداری در بازه‌ی `[0, n)` برمی‌گرداند و وقتی روی یک دنباله اعمال شود، یک عنصر تصادفی برمی‌گرداند. `randomize` به‌صورت درجا درهم می‌ریزد و `sample` عنصرهای متمایز را انتخاب می‌کند.

به‌طور پیش‌فرض، این‌ها مقدار را از یک مولد سراسری می‌گیرند که بذر آن از ساعت سیستم تأمین می‌شود. برای اینکه نتایج قابل بازتولید باشند، یک مولد بذردار را با `<mersenne-twister>` (از [`random.mersenne-twister`][mt]) و `with-random` نصب کنید:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
