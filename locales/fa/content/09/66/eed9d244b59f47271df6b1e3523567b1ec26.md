# راهنما

## کلی

- تاپل `plot`، نمادهای `registrations` و `next-id` و همچنین نماد `not-found` از قبل در فایل تمرین اعلام شده‌اند.
- برای حالت سطح ماژول، از `set-global`، `get-global` و `change-global` استفاده کنید.

## 1. باغ را باز کنید و ثبت‌نام‌هایش را فهرست کنید

- `V{ } clone` مقدار شروع درست برای `registrations` است (همیشه `clone` کنید تا این مقدار ثابت بین فراخوانی‌ها به اشتراک گذاشته نشود).
- `1 next-id set-global` شمارنده را تنظیم می‌کند.
- برای `list-registrations`، یک `registrations get-global` کافی است.

## 2. ثبت یک قطعه

- ابتدا `next-id` را بخوانید، سپس با `plot boa` قطعه را از `id` و `name` بسازید.
- شمارنده را با `next-id [ 1 + ] change-global` افزایش دهید.
- `push` (در [`sequences`][sequences]) در جای خودش به بردار می‌افزاید و برای `registrations get-global` عالی است.

## 3. آزاد کردن یک قطعه

- `:: release ( id -- )`، `id` را درون محمول فیلتر در دسترس قرار می‌دهد.
- `[ id>> id = ] reject` هر قطعه‌ای را که شکاف `id` آن با `id` محلی *مطابقت ندارد* نگه می‌دارد. از آن به عنوان بدنه‌ی یک `change-global` استفاده کنید.

## 4. گرفتن یک قطعه‌ی ثبت‌شده

- `find` مقدار `( index elt/f )` را برمی‌گرداند. `nip` اندیس را حذف می‌کند.
- `[ not-found ] unless*` اگر چیزی پیدا نشود، نماد را جایگزین می‌کند.
