# دستورالعمل‌ها

در این تمرین قرار است برخی از قواعد [بلک‌جک][blackjack] را پیاده‌سازی کنید؛ مثلاً اینکه بازی چگونه انجام می‌شود و چطور امتیازدهی می‌شود.

~~~~exercism/note
در این تمرین، کارت‌ها با عدد نمایش داده می‌شوند؛ هر کارت عددی با ارزش عددی خودش نمایش داده می‌شود و جک‌ها، ملکه‌ها، شاه‌ها و آس‌ها به‌ترتیب با ۱۱، ۱۲، ۱۳ و ۱۴ مشخص می‌شوند (در این بازی از جوکر استفاده نمی‌شود).

برای اینکه کار با این نمایش راحت‌تر باشد، چند ثابت در ابتدای فایل تعریف شده‌اند؛ `C2` تا `C10` برای کارت‌های عددی‌اند، `CJ` برای جک، `CQ` برای ملکه، `CK` برای شاه و `CA` برای آس.

فرض بر این است که یک [دست استاندارد ۵۲ تایی فرانسوی][standard_deck] به کار می‌رود، اما در بیشتر نسخه‌ها چند دست با هم بُر زده می‌شود و برای بازی مخلوط می‌شوند.

[standard_deck]: https://en.wikipedia.org/wiki/Standard_52-card_deck
~~~~

~~~~exercism/note
این‌ها دستورالعمل‌هایی هستند که در این مفهوم به آن‌ها اشاره شده است:

| دستورالعمل   | توضیح                                            |
|---------------|--------------------------------------------------------|
| cmp a, b      | پرچم‌ها را بر اساس `a - b` تنظیم می‌کند                          |
| jmp a         | اجرای کد اینجا متوقف می‌شود و در برچسب `a` ادامه می‌یابد     |
| jcc a         | اگر شرط موجود در `cc` برقرار باشد، کد در برچسب `a` ادامه می‌یابد  |

این‌ها شرط‌هایی هستند که در یک `jcc` پس از یک `cmp a, b` بررسی می‌شوند:

| دستورالعمل | زمانی که می‌پرد          |
|-------------|---------------------|
| je          | a == b              |
| jl          | a < b (علامت‌دار)      |
| jg          | a > b (علامت‌دار)      |
| jb          | a < b (بدون علامت)    |
| ja          | a > b (بدون علامت)    |
| jle         | a <= b (علامت‌دار)     |
| jge         | a >= b (بدون علامت)   |
| jbe         | a <= b (بدون علامت)   |
| jae         | a >= b (بدون علامت)   |
| jne         | a != b              |
| jnl         | !(a < b) (علامت‌دار)   |
| jng         | !(a > b) (علامت‌دار)   |
| jnb         | !(a < b) (بدون علامت) |
| jna         | !(a > b) (بدون علامت) |
| jnle        | !(a <= b) (علامت‌دار)  |
| jnge        | !(a >= b) (علامت‌دار)  |
| jnbe        | !(a <= b) (بدون علامت)|
| jnae        | !(a >= b) (بدون علامت)|
~~~~

## 1. محاسبه‌ی ارزش یک کارت

در **بلک‌جک**، ارزش یک `CA` بسته به دست، ۱ یا ۱۱ است (بعداً بیشتر درباره‌ی این صحبت می‌کنیم).
کارت‌های تصویری (`CJ`، `CQ` و `CK`) ۱۰ امتیاز حساب می‌شوند و هر کارت دیگری ارزش _عددی_ خودش را دارد.

تابع `value_of_card` را با پارامتر `card` تعریف کنید، عددی که نماینده‌ی یک کارت است.
این تابع باید _ارزش عددی_ کارت ورودی را برگرداند.
از آنجا که یک `CA` می‌تواند چند مقدار مختلف بگیرد (۱ **یا** ۱۱)، فعلاً ارزش `CA` را روی ۱ ثابت می‌کنیم.
بعداً تابعی پیاده‌سازی خواهید کرد که با داشتن یک دست موجود، ارزش یک `CA` را تعیین می‌کند.

```c
value_of_card(13)
// => 10

value_of_card(4)
// => 4

value_of_card(14)
// => 1
```

## 2. تعیین اینکه کدام کارت ارزش بیشتری دارد

تابع `higher_card` را با پارامترهای `card_one` و `card_two` تعریف کنید؛ دو عدد که هر کدام نماینده‌ی یک کارت است.
از نظر امتیازدهی، ارزش `CJ`، `CQ` و `CK` همگی ۱۰ است.
این تابع باید کارتی را برگرداند که برای امتیازدهی ارزش بیشتری دارد.
اگر ارزش هر دو کارت برابر باشد، هر دو را برگردانید.

یک `CA` می‌تواند چند مقدار داشته باشد، پس در این تمرین ارزش آن را ۱ در نظر می‌گیریم.

```c
higher_card(13, 11)
// => {13, 11}

higher_card(4, 6)
// => 6

>>> higher_card(13, 14)
// => 13
```

~~~~exercism/note
برای برگرداندن دو عدد صحیح از یک تابع، باید از هر دو ثبات `rax` و `rdx` استفاده کنید:

```x86asm
returning_two_values:
    mov rax, rdi
    mov rdx, rsi
    ret
```

اگر فقط یک کارت برگردانده می‌شود، باید `rdx` را روی ۰ تنظیم کنید.
~~~~

## 3. محاسبه‌ی ارزش یک آس

همان‌طور که پیش‌تر اشاره شد، یک `CA` بسته به دست _یا_ ۱ امتیاز دارد **یا** ۱۱ امتیاز.
قواعد **بلک‌جک** ایجاب می‌کند که ارزش `CA`ها طوری انتخاب شود که امتیاز دست را به بیشترین مقدار برساند، اما از ۲۱ فراتر نرود (عبور از ۲۱ در این بازی «سوختن» نامیده می‌شود).

تابع `value_of_ace` را با پارامترهای `card_one` و `card_two` تعریف کنید؛ این‌ها دو عدد هستند و نماینده‌ی جفتی از کارت‌ها که _پیش از_ گرفتن `CA` آخر در دست قرار دارند.
تابع شما باید برگرداند که به `CA` پیش رو کدام مقدار، ۱ یا ۱۱، اختصاص می‌یابد.
یادتان باشد: ارزش دست جدید (همراه با `CA`) باید تا حد ممکن بالا باشد، _بی‌آنکه_ از ۲۱ فراتر رود.

**راهنما**: اگر از قبل یک `CA` در دست داشته باشیم، آنگاه ارزش `CA` پیش رو ۱ خواهد بود.

```c
value_of_ace(6, 13)
// => 1

value_of_ace(7, 3)
// => 11
```

## 4. تعیین اینکه دست یک بلک‌جک است یا نه

اگر در اولین دو کارتی که به بازیکن داده می‌شود، یک `CA` و یک کارت ده (`C10`، `CJ`، `CQ` یا `CK`) باشد، آنگاه بازیکن امتیاز ۲۱ دارد.
به این دست **بلک‌جک** می‌گویند.

تابع `is_blackjack` را با پارامترهای `card_one` و `card_two` تعریف کنید؛ این‌ها دو عدد هستند و نماینده‌ی جفتی از کارت‌ها.
اگر دست دو کارتی یک **بلک‌جک** باشد، تابع باید ۱ برگرداند و در غیر این صورت ۰.
برای اینکه کار با مقدارها راحت‌تر شود، ثابت‌های `TRUE` و `FALSE`، به‌ترتیب معادل ۱ و ۰، در ابتدای فایل تعریف شده‌اند.

**نکته**: _محاسبه‌ی_ امتیاز به روش‌های زیادی می‌تواند انجام شود.
اما اگر ممکن است، می‌خواهیم بررسی کنید که آیا یک `CA` و یک کارت ده **_در_** دست وجود دارند، نه اینکه ارزش کارت‌ها را _جمع_ کنید.

```c
is_blackjack(14, 13)
// => 1

is_blackjack(10, 9)
// => 0
```

## 5. تقسیم جفت‌ها

اگر دو کارت اول بازیکن ارزش یکسانی داشته باشند (مثلاً دستی با دو `C6`، یا دستی با یک `CQ` و یک `CK`)، بازیکن می‌تواند آن‌ها را به‌عنوان دو دست جداگانه در نظر بگیرد.
به این کار «تقسیم جفت‌ها» می‌گویند.

تابع `can_split_pairs` را با پارامترهای `card_one` و `card_two` تعریف کنید؛ این‌ها دو عدد هستند و نماینده‌ی جفتی از کارت‌ها.
اگر دست دو کارتی را بتوان به دو دست تقسیم کرد، تابع باید ۱ برگرداند و در غیر این صورت ۰.
برای اینکه کار با مقدارها راحت‌تر شود، ثابت‌های `TRUE` و `FALSE`، به‌ترتیب معادل ۱ و ۰، در ابتدای فایل تعریف شده‌اند.

```c
can_split_pair(12, 13)
// => 1

can_split_pair(10, 14)
// => 0
```

## 6. دو برابر کردن شرط

وقتی مجموع دو کارت اولی که داده می‌شود ۹، ۱۰ یا ۱۱ امتیاز باشد، بازیکن می‌تواند شرطی اضافی برابر با شرط اولیه‌اش بگذارد.
به این کار «دو برابر کردن شرط» می‌گویند.

تابع `can_double_down` را با پارامترهای `card_one` و `card_two` تعریف کنید؛ این‌ها دو عدد هستند و نماینده‌ی جفتی از کارت‌ها.
اگر دست دو کارتی به بازیکن اجازه‌ی «دو برابر کردن شرط» را بدهد، تابع باید ۱ برگرداند و در غیر این صورت ۰.
برای اینکه کار با مقدارها راحت‌تر شود، ثابت‌های `TRUE` و `FALSE`، به‌ترتیب معادل ۱ و ۰، در ابتدای فایل تعریف شده‌اند.

```c
can_double_down(14, 9)
// => 1

can_double_down(10, 2)
// => 0
```
