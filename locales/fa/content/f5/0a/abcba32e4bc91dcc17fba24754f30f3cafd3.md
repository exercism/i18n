# پیوست دستورالعمل‌ها

## قالب شبکه

شبکه به شکل رشته‌ای نمایش داده می‌شود که با نویسه‌ی پوچ پایان می‌یابد و در انتهای هر سطر یک نویسه‌ی خط جدید دارد.

## ثبات‌ها

| ثبات     | کاربرد       | نوع     | توضیح                                                         |
| -------- | ------------ | ------- | ------------------------------------------------------------- |
| `$a0`    | ورودی        | آدرس    | رشته‌ی ورودی پایان‌یافته با نویسه‌ی پوچ                        |
| `$a1`    | ورودی/خروجی  | آدرس    | رشته‌ی نتیجه‌ی پایان‌یافته با نویسه‌ی پوچ، که اگر ابعاد شبکه نامعتبر باشد خالی است |
| `$v0`    | خروجی        | عدد صحیح | وضعیت شبکه (`0` = `ok`، `-1` = `invalid columns`، `-2` = `invalid rows`) |
| `$t0-9`  | موقت         | هر نوع  | برای ذخیره‌سازی موقت                                           |
