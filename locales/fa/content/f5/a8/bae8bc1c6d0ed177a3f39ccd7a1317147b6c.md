# دستورالعمل‌ها

در این تمرین، مجموعه‌ای جزئی از توابع کمکی را پیاده‌سازی می‌کنید تا به یک برنامه‌نویس کمک کنید نام شناسه‌ها را تمیز کند.

در این ۵ وظیفه، به‌تدریج تابع `clean` را می‌سازید.
یک شناسه‌ی معتبر شامل صفر یا چند حرف و آندرلاین است.

اگر رشته‌ی خالی به تابع `clean` داده شود، باید رشته‌ی خالی برگردانده شود.

## 1. جایگزینی فاصله‌ها با آندرلاین

تابعی به نام `clean1` پیاده‌سازی کنید که هر فاصله را با آندرلاین جایگزین کند. این موضوع برای فاصله‌های ابتدا و انتهای رشته هم صادق است.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. جایگزینی کاراکترهای کنترلی با رشته‌ی حروف بزرگ "[CTRL]"

`clean2` را پیاده‌سازی کنید تا همان کاری را انجام دهد که تابع قبلی انجام می‌داد و کاراکترهای کنترلی رایج (`\n`، `\t` و `\r`) را با رشته‌ی `"[CTRL]"` جایگزین کند.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. تبدیل kebab-case به camelCase

`clean3` را پیاده‌سازی کنید تا همان کاری را انجام دهد که تابع قبلی انجام می‌داد و kebab-case را به camelCase تبدیل کند.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. حذف رقم‌ها

`clean4` را پیاده‌سازی کنید تا همان کاری را انجام دهد که تابع قبلی انجام می‌داد و همه‌ی رقم‌ها را حذف کند.

```elm
clean4 "123"
    --> ""
```

## 5. حذف حروف کوچک یونانی

در پایان، `clean` را پیاده‌سازی کنید تا همان کاری را انجام دهد که تابع قبلی انجام می‌داد و هر حرف یونانی در بازه‌ی «α» تا «ω» را حذف کند.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
