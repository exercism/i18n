# مقدمه

## بازگشت

به توانایی این که چیزی بر اساس خودش تعریف شود، «بازگشت» می‌گویند. در Gleam، بازگشت بیشتر در توابع بازگشتی دیده می‌شود، یعنی توابعی که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید حداقل یک «حالت پایه» و حداقل یک «حالت بازگشتی» داشته باشد. حالت پایه مقداری را بدون فراخوانی دوباره‌ی تابع برمی‌گرداند. حالت بازگشتی تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت کند.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam نحوه‌ی نگارش خاصی برای حلقه‌زدن ندارد، بنابراین همه‌ی حلقه‌ها با بازگشت انجام می‌شوند.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam از نوع‌های سفارشی بازگشتی هم پشتیبانی می‌کند. یک نوع سفارشی بازگشتی یک یا چند گونه دارد که داده‌ی درونشان به خود نوع اشاره می‌کند.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
