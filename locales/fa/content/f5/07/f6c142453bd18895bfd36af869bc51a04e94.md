# درباره

«هیپ» مجموعه‌ای است که همیشه کوچک‌ترین (یا بزرگ‌ترین) عنصر خود را می‌داند و به شما اجازه می‌دهد به‌سرعت آن را حذف کنید؛ پیاده‌سازی طبیعی یک «صف اولویت» است. هیپ در واژگان [`heaps`][heaps] قرار دارد.

`<min-heap>` یک هیپ خالی می‌سازد که کوچک‌ترین کلید آن اول بیرون می‌آید؛ `<max-heap>` بزرگ‌ترین را اول تحویل می‌دهد. هر عنصر یک «مقدار» است که زیر یک «کلید» ذخیره می‌شود و کلید همان اولویتی است که Factor بر اساس آن مرتب می‌کند:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

هیپ «تغییرپذیر» است: `heap-push` و `heap-pop` آن را در جا تغییر می‌دهند.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` ابتدای هیپ را بدون حذف کردن می‌خواند؛ `heap-pop` آن را حذف و برمی‌گرداند؛ `heap-pop-all` هیپ را به یک لیست انجمنی از جفت‌های `{ key value }` به ترتیب اولویت تخلیه می‌کند.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

`heap-push` کردن از مرتبه‌ی `O(log n)` است و خواندن ابتدای هیپ `O(1)` است، بنابراین تکرار «فوری‌ترین عنصر را بردارید، بعد موارد بیشتری اضافه کنید» حتی برای یک صف بزرگ هم سریع می‌ماند. پیاده‌سازی آن یک هیپ دودویی است که در یک آرایه‌ی قابل رشد ذخیره می‌شود؛ کلید می‌تواند هر مقدار قابل مرتب‌سازی باشد (اعداد، رشته‌ها، …).
