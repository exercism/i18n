# درباره

حلقه‌های `for` پیچیده‌ترین نوع حلقه در PHP هستند. رفتارشان مانند حلقه‌های `for` در `C`، `Java` و `JavaScript` است. شکل پایه‌ی آن چنین است:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

اولین عبارت (_expr1_) پیش از شروع حلقه ارزیابی می‌شود. عبارت دوم (_expr2_) پیش از هر تکرار ارزیابی می‌شود و اگر نتیجه‌اش مقدار «درست» باشد، دستورها اجرا می‌شوند. پس از اجرای دستورها، عبارت سوم (_expr3_) ارزیابی می‌شود.
