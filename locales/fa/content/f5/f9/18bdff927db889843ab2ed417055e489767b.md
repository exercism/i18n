# دستورالعمل‌ها

تعداد مین‌ها را به یک صفحه‌ی کامل‌شده‌ی مینیاب اضافه کنید.

مینیاب یک بازی محبوب است که در آن کاربر باید مین‌ها را با کمک راهنماهای عددی پیدا کند؛ این راهنماها نشان می‌دهند چند مین به‌طور مستقیم (به‌صورت افقی، عمودی یا مورب) با یک خانه مجاورند.

در این تمرین باید code بنویسید که تعداد مین‌های مجاور یک خانه‌ی خالی مشخص را بشمارد و آن خانه را با آن عدد جایگزین کند.

صفحه یک مستطیل است که از کاراکترهای فاصله (' ') ساخته شده است.
هر مین با کاراکتر ستاره (`*`) نشان داده می‌شود.

اگر یک خانه هیچ مین مجاوری نداشته باشد، آن خانه را خالی بگذارید.

## مثال‌ها

برای مثال، ممکن است صفحه‌ای ۵ در ۴ مانند این دریافت کنید (در اینجا خانه‌های خالی برای نمایش روی صفحه با کاراکتر '·' نشان داده شده‌اند):

```text
·*·*·
··*··
··*··
·····
```

و code شما آن را به این تبدیل می‌کند:

```text
1*3*1
13*31
·2*2·
·111·
```
