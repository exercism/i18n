# خواندنی‌های پیشنهادی

از آنجا که Smalltalk کاربرد گسترده‌ای دارد، تنوع گسترده‌ای از منابع خواندنی در دسترس است.

## شروع کار

* [Pharo Main Site](https://pharo.org/documentation):
مقاله‌ها و راهنمایی‌های فراوانی دارد
* [Pharo Syntax Cheatsheet](https://files.pharo.org/media/pharoCheatSheet.pdf):
روی یک کارت پستال جا می‌شود
* [I Can Read C but not Smalltalk](https://www.eli.sdsu.edu/courses/spring01/cs635/readingSmalltalk.pdf): چند گام آسان برای درک Smalltalk
* [Pharo By Example (9.0)](https://books.pharo.org/pharo-by-example9/):
یک کتاب کامل PDF با مثال‌های گام‌به‌گام
* [Learning OOP and TDD in Pharo](https://books.pharo.org/learning-oop/):
تکنیک‌ها و مفاهیم برنامه‌نویسی بیشتری را معرفی می‌کند
* [Discord](https://discord.gg/QewZMZa) یک
انجمن گفت‌وگوی آنلاین فعال درباره‌ی Pharo دارد (از پیوند دعوت در بالای [Community Page](https://pharo.org/community) استفاده کنید)
* [Pharo Mooc](https://mooc.pharo.org/):
مجموعه‌ای از دوره‌های کامل برنامه‌نویسی و ویدیوها را ارائه می‌دهد

## پیشرفته‌تر

* [Deep Into Pharo](https://books.pharo.org/deep-into-pharo/):
شما را با موضوع‌های پیشرفته‌تری مانند گرافیک و تجزیه آشنا می‌کند
* [Pharo with style](https://github.com/SquareBracketAssociates/Booklet-PharoWithStyle):
راهنمای قالب‌بندی و طراحی به سبک Pharo است
* [Smalltalk with style](http://sdmeta.gforge.inria.fr/FreeBooks/WithStyle/SmalltalkWithStyle.pdf):
راهنمای گسترده‌تری برای قالب‌بندی و طراحی در Smalltalk است
* [Enterprise Pharo - Web Perspective](http://books.pharo.org/enterprise-pharo/):
به برنامه‌های وب، http و داده‌ها می‌پردازد
