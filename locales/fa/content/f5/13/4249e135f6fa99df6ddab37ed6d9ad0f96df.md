# مقدمه

در Common Lisp یک تابع نه فقط می‌تواند یک مقدار برگرداند، بلکه می‌تواند چندین مقدار برگرداند.
برای مثال `floor` که به سمت صفر به پایین گرد می‌کند، دو مقدار برمی‌گرداند: اولی مقدار گردشده است و دومی باقی‌مانده.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(مقادیر برگردانده‌شده را در خطوط جداگانه‌ی خروجی نشان می‌دهیم.)

## برگرداندن چندین مقدار

اگر می‌خواهید تابعی چندین مقدار برگرداند، از تابع دسترسی `values` استفاده می‌کنید:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## کار با چندین مقدار

اگر فقط مقدار اول برایتان مهم است، کار خاصی لازم نیست انجام دهید؛ زبان خودش از عهده‌ی آن برمی‌آید:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

اما اگر بخواهید به آن مقادیر دیگر دسترسی داشته باشید، چندین تابع هست که باید از آن‌ها استفاده کنید.
دو ماکروی اصلی `multiple-value-list` و `multiple-value-bind` هستند.
این دو برای بسته‌بندی چیزی به کار می‌روند که چندین مقدار برمی‌گرداند و همه‌ی آن مقادیر را در بر می‌گیرند.
اولی لیستی از همه‌ی مقادیر می‌سازد.
دومی به شما اجازه می‌دهد متغیرها را به تک‌تک مقادیر مقید کنید.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

یک تابع مفید دیگر هم `nth-value` است
