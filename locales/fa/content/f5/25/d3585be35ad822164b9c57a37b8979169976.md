# دستورالعمل‌ها

در این تمرین، قرار است برنامه‌ای بنویسید که وضعیت یک بازی [tic-tac-toe][] را تعیین کند.
(_ممکن است این بازی را با نام‌های «noughts and crosses» یا «Xs and Os» هم بشناسید._)

این بازی روی یک صفحه‌ی ۳×۳ انجام می‌شود.
بازیکنان به‌نوبت علامت‌های `X` و `O` را روی صفحه قرار می‌دهند.
بازی زمانی پایان می‌یابد که یکی از بازیکنان با قرار دادن سه علامت در یک ردیف، یک ستون یا روی یک قطرِ صفحه برنده شود، یا زمانی که کل صفحه پر شود.

در این تمرین، فرض می‌کنیم که `X` شروع می‌کند.

کار شما این است که مشخص کنید یک بازیِ داده‌شده در چه وضعیتی قرار دارد.

این بازی سه وضعیت ممکن دارد:

- بازی **در جریان** است.
- بازی با **تساوی** پایان یافته است.
- بازی با **برد** پایان یافته است.

اگر صفحه‌ی داده‌شده نامعتبر باشد، خطای مناسبی پرتاب کنید.

اگر صفحه‌ای شرایط زیر را داشته باشد، نامعتبر است:

- رسیدن به صفحه‌ی داده‌شده با انجام نوبت‌ها به ترتیب درست ممکن نیست (یادتان باشد که `X` شروع می‌کند).
- بازی پس از اینکه به پایان رسیده، ادامه داده شده است.

## مثال‌ها

### بازی در جریان

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### تساوی

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### برد

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### نامعتبر

#### ترتیب نوبت اشتباه

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### ادامه‌ی بازی پس از برد

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
