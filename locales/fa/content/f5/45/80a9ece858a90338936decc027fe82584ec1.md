# کلاس‌های جنریک

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## پارامتر چیست

`T` نشان‌دهندهٔ نوعی است که در محل استفاده ارائه می‌شود. Sather هنگام کامپایل برنامه، برای هر ترکیبی که واقعاً به کار می‌رود، یک کلاس مجزا می‌سازد. بنابراین:

- `LOST_BOX{STR}` و `LOST_BOX{INT}` دو نوع نامرتبط هستند؛
- نه بررسی زمان اجرا وجود دارد، نه جعبه‌بندی و نه تبدیل؛
- خطای داخل کلاس برای هر نوعی که با آن استفاده شود، بروز می‌کند.

این همان رویکرد قالب‌های C++ یا جنریک‌های Rust است و برخلاف جنریک‌های Java است، جایی که نوع پاک می‌شود و همه‌چیز در واقع یک شیء است.

## پارامترهای محدود

یک `T` لخت را می‌توان تخصیص داد، پاس داد و برگرداند؛ نه کار دیگری، چون اطلاعات دیگری درباره‌اش در دست نیست. برای فراخوانی روال‌ها روی آن، بگویید که باید با چه نوعی منطبق باشد:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR` الزام می‌کند که `T` با `$STR` منطبق باشد و در عوض اجازه می‌دهد `item.str` فراخوانی شود. هر کاری که `T` لخت نمی‌تواند انجام دهد، با یک محدودیت می‌توان آن را مجاز کرد.

بدون محدودیت، `item.str` کامپایل نمی‌شود و پیام به خط داخل کلاس جنریک اشاره می‌کند، نه خطی که از آن استفاده کرده است.

## روال‌های جنریک؟

هیچ روال جنریکی وجود ندارد. فقط کلاس‌ها پارامتر می‌گیرند. روالی که باید روی چند نوع کار کند، یا در یک کلاس جنریک قرار می‌گیرد، یا نوعی انتزاعی مانند `$STR` می‌گیرد.

## انتخاب بین آن دو

| | کلاس جنریک | کلاس انتزاعی |
| --- | --- | --- |
| تعیین | هنگام کامپایل | هنگام اجرا |
| نگه می‌دارد | یک نوع برای هر نمونه‌سازی | هر نوع منطبق |
| هزینه | ندارد | یک اعزام |

`ARRAY{$ACT}` از هر دو استفاده می‌کند: در نوع عنصر جنریک است و در اینکه آن عنصر چه نوعی می‌تواند باشد، انتزاعی است.

وقتی نوع در همه‌جا یکسان است و استفاده‌کنندهٔ کلاس از آن آگاه است، سراغ کلاس جنریک بروید. وقتی چند نوع باید در یک مجموعه کنار هم قرار بگیرند، سراغ کلاس انتزاعی بروید.
