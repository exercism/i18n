# مقدمه

گاهی هنگام پیمایش یک دنباله، در کنار خود عنصر به *موقعیت* آن هم نیاز دارید. خانواده‌ی `*-index` در [`sequences`][sequences] هر دوی اینها را به «quotation» هر عنصر تحویل می‌دهد. `times` هم خویشاوند نزدیک آن برای تکرار شمارشی ساده است؛ زمانی به کار می‌آید که فقط به یک شمارش نیاز داشته باشید، نه به یک دنباله.

## `each-index` و `map-index`: اندیس درون quotation

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

quotation عنصر را زیر اندیس می‌گیرد؛ `index` در **بالای** پشته قرار دارد:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index` quotation را برای عارضه‌ی جانبی‌اش اجرا می‌کند و چیزی برنمی‌گرداند. `map-index` نتیجه‌ی هر عنصر را در دنباله‌ی جدیدی از همان نوع ورودی جمع می‌کند.

## `times`: تکرار شمارشی

`times` (در [`math`][math]) quotation خود را `n` بار اجرا می‌کند.

```
times ( n quot: ( -- ) -- )
```

شکل منتشرشده‌ی `( -- )` فقط *حداقل* است؛ چون `times` از نوع `inline` است، یک quotation با اثر متوازن مانند `( str -- str )` هم به‌خوبی کار می‌کند و پشته در طول تکرارها رد می‌شود. این به شما یک انباشتگر شمارشی می‌دهد، بدون هیچ حالت قابل تغییر:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

بدنه‌ی هر تکرار رشته‌ی جاری را می‌بیند، چیزی به آن می‌افزاید و رشته‌ی جدید را برای تکرار بعدی روی پشته باقی می‌گذارد. همین ترفند برای `each-index` و `map-index` هم کار می‌کند، زمانی که بخواهید یک انباشتگر را در طول آنها رد کنید.
