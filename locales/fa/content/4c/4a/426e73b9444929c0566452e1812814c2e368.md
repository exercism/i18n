# از دستور شرطی تودرتو استفاده نکنید

دستورهای شرطی را طوری بازنویسی کنید که تودرتویی عمیق نداشته باشند، چون میتواند به کدی منجر شود که دنبال کردنش دشوارتر است. دو قطعه کد زیر را در نظر بگیرید:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

آن را با کد زیر مقایسه کنید:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

مثال دوم ساختار بسیار مشخصی دارد: همه‌ی مسیرهایی که با خطا سر و کار دارند در بلوک‌های تورفته بررسی می‌شوند، در حالی که «مسیر موفق» همیشه در سمت چپ تراز شده است. این کار خواندن کد را بسیار آسان می‌کند، چون به‌سرعت می‌توان دید که رایج‌ترین مسیر بدون خطا در کد کدام است.
