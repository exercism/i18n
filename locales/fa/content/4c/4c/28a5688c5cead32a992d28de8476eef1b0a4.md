# نصب

راه‌های زیادی برای نصب Zig وجود دارد و هر چه این زبان بالغ‌تر می‌شود، تعداد این راه‌ها هم پیوسته بیشتر می‌شود.
خوشبختانه همه‌ی روش‌های محبوب نصب در [صفحه‌ی نصب Zig][install-zig] فهرست شده‌اند.

## نسخه‌ی Zig

Exercism از Zig 0.17.0 (منتشرشده در ۲۰۲۶-۱۰-۰۱) استفاده می‌کند.

ممکن است یک تمرین با نسخه‌ی دیگری از Zig سازگار باشد، اما چنین چیزی تضمین‌شده نیست.
Zig هنوز به نسخه‌ی 1.0 نرسیده است و تغییرات ناسازگار رایج‌اند.

## ابزارهای تکمیلی

### Zig fmt: تولید کد خوش‌قالب

هنگام حل هر تمرینی، می‌توانید از هر سبک کدنویسی‌ای برای راه‌حل‌هایتان استفاده کنید.
اما بیرون از حل تمرین‌ها، مثلاً وقتی یک برنامه یا کتابخانه می‌سازید، معمولاً ایده‌ی خوبی است که کدتان را یکدست و خوانا نگه دارید.
این نکته وقتی اهمیت بیشتری پیدا می‌کند که افراد دیگری بخواهند در پروژه‌هایتان به شما کمک کنند و ناچار باشند کدتان را بخوانند.

برای حل این مشکل، کامپایلر Zig یک [لینتر][linters] سبک و توکار دارد که کدتان را به شکلی راحت قالب‌بندی می‌کند.
این قالب‌بند کد می‌کوشد [راهنمای سبک][style-guide] را که [مستندات Zig][documentation] از پیش تعیین کرده است، رعایت کند.

برای دیدن قابلیت‌های قالب‌بند بومی Zig از دستور زیر استفاده کنید:

```bash
zig fmt --help
```

### Zig zen: اصولی برای کدنویسی

گاهی هنگام انجام هر کاری، حتی نوشتن کد، کمی راهنمایی خیلی کمک می‌کند.
خوشبختانه یک دستور سرگرم‌کننده مستقیماً در کامپایلر Zig تعبیه شده است تا برخی از هدف‌هایی را که در نوشتن کد خوب Zig نقش دارند، به یادمان بیاورد.

برای دیدن این کلمات حکیمانه می‌توانید از دستور زیر استفاده کنید:

```bash
zig zen
```

### Zig Language Server: پشتیبانی جامع ویرایشگر برای Zig

این نرم‌افزار شخص ثالث، تکمیل خودکار ویرایشگر و قابلیت‌های پیشرفته‌ی پیمایش کد Zig را فراهم می‌کند که می‌توانند به شما کمک کنند زبان را سریع‌تر یاد بگیرید.

برای آخرین دستورالعمل‌ها [راهنمای نصب ZLS][install-zls] را ببینید.
