# مقدمه

## مجموعه

«مجموعه» یک ساختار داده‌ی تغییرناپذیر و بدون ترتیب است که فقط مقادیر یکتا را در خود نگه می‌دارد. همه‌ی عنصرهای یک مجموعه باید از یک نوع باشند.

ماژول `gleam/set` نوع `Set` را تعریف می‌کند و توابعی برای کار با مجموعه‌ها در اختیار می‌گذارد.

می‌توانید فهرست‌ها و مجموعه‌ها را با `set.to_list` و `set.from_list` به یکدیگر تبدیل کنید. ترتیب عنصرها در یک مجموعه تضمین نمی‌شود.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

می‌توانید با `set.new`، `set.insert` و `set.delete` مجموعه بسازید و آن را پر کنید.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

می‌توانید محتوای یک مجموعه را با توابع `set.contains` و `set.size` بررسی کنید.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

می‌توان مجموعه‌ها را با `set.union` و `set.intersection` ترکیب کرد.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

می‌توانید مجموعه‌ها را فیلتر کنید.

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
