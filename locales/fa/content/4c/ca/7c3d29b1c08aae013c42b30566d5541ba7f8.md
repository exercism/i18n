# درباره

[Conses][hyper-conses] یکی از انواع داده‌ی پایه در Common Lisp است. هر cons از یک سر و یک دنباله تشکیل می‌شود (که به [دلیل تاریخی][history] به آن‌ها `car` و `cdr` می‌گویند).
هیچ محدودیتی در نوع داده‌ی سر و دنباله‌ی یک cons وجود ندارد.

consها با تابع [`cons`][hyper-cons] ساخته می‌شوند که دو شیء می‌گیرد و به یک cons ارزیابی می‌شود (که گاهی به آن «سلول cons» هم می‌گویند).

می‌توان به بخش‌های یک cons با توابع [`car`][hyper-car] و [`cdr`][hyper-cdr] دسترسی داشت.

## مرجع

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
