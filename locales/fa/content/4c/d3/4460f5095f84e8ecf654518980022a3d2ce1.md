# مقدمه

بسیاری از برنامه‌ها به مقادیر (شبه)تصادفی نیاز دارند تا رویدادهای دنیای واقعی را شبیه‌سازی کنند.

نمونه‌های رایج و آشنای آن عبارت‌اند از:

- پرتاب سکه: یک مقدار تصادفی از ('H', 'T').
- انداختن تاس: یک عدد صحیح تصادفی از ۱ تا ۶.
- بُر زدن یک دسته کارت: یک ترتیب تصادفی از یک فهرست کارت.
- ایجاد درخت‌ها و بوته‌ها در یک شبیه‌سازی گرافیکی سه‌بعدی.

تولید مقادیر واقعاً تصادفی با کامپیوتر یک [چالش فنی به‌طرز شگفت‌انگیزی دشوار][why-randomness-is-hard] است و به همین دلیل مولدهای «شبه‌تصادفی» هم وجود دارند.

## تولید اعداد تصادفی

در JavaScript می‌توانید با تابع [`Math.random()`][Math.random] اعداد شبه‌تصادفی تولید کنید.
این تابع یک عدد اعشاری شبه‌تصادفی بین ۰ (شامل) و ۱ (غیرشامل) برمی‌گرداند.

برای به دست آوردن یک عدد تصادفی بین _min_ (شامل) و _max_ (غیرشامل) می‌توانید از تابعی مانند این استفاده کنید:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## تولید اعداد صحیح تصادفی

برای تولید یک عدد صحیح تصادفی، می‌توانید با `Math.floor()` یا `Math.ceil()` یک عدد تولیدشده‌ی تصادفی را به عدد صحیح تبدیل کنید.
