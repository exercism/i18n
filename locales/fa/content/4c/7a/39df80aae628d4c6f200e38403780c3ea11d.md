# دستورالعمل‌ها

شما تازه کار خود را در پذیرش یک باشگاه سنگ‌نوردی شروع کرده‌اید.
اعضا عضویت را برای چند ماه خریداری می‌کنند و هر بار که به باشگاه می‌آیند، ورود و خروج می‌کنند.
مدیر از شما خواسته است یک «کمک‌کننده» بنویسید که به پرسش‌هایی که اعضا بیشتر از همه می‌پرسند پاسخ دهد.

## 1. محاسبه‌ی زمان پایان عضویت

عضویتی که در تاریخی مشخص شروع می‌شود، همان تعداد ماه بعد، در همان روز از ماه به پایان می‌رسد.
اگر آن روز در ماه پایانی وجود نداشته باشد، عضویت به‌جای آن در آخرین روز آن ماه به پایان می‌رسد.

متد `FrontDesk.membershipEnd()` را پیاده‌سازی کنید که تاریخ شروع عضویت و تعداد ماه‌های آن را می‌گیرد و تاریخی را که عضویت در آن به پایان می‌رسد برمی‌گرداند:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. نمایش مدت اعتبار عضویت

باشگاه روی کارت عضویت، مدت اعتبار عضویت را به سال، ماه و روز چاپ می‌کند.

متد `FrontDesk.membershipLength()` را پیاده‌سازی کنید که تاریخ شروع و تاریخ پایان عضویت را می‌گیرد و مدت عضویت را به‌صورت یک `Period` برمی‌گرداند:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. شمارش روزهای باقی‌مانده از عضویت

اعضا اغلب می‌پرسند تا پایان عضویتشان چند روز باقی مانده است.

متد `FrontDesk.daysLeft()` را پیاده‌سازی کنید که تاریخ امروز و تاریخ پایان عضویت را می‌گیرد و تعداد کل روزها را از امروز تا تاریخ پایان برمی‌گرداند.
وقتی تاریخ پایان امروز باشد یا قبلاً گذشته باشد، روزی باقی نمانده است، بنابراین متد `0` را برمی‌گرداند:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. اندازه‌گیری یک بازدید

باشگاه شبانه‌روزی باز است و گیت ورود، تاریخ و ساعت ورود و خروج اعضا را ثبت می‌کند.

متد `FrontDesk.visitDuration()` را پیاده‌سازی کنید که تاریخ و ساعت ورود و خروج یک بازدید را می‌گیرد و مدت بازدید را به‌صورت یک `Duration` برمی‌گرداند:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. چاپ یک بازدید روی رسید

رسید، مدت بازدید را به ساعت و دقیقه نشان می‌دهد، مانند `1h 35m`.
دقیقه‌ها همیشه با دو رقم نوشته می‌شوند، ثانیه‌ها نادیده گرفته می‌شوند و ساعت‌ها به یک روز محدود نیستند.

متد `FrontDesk.formatVisit()` را پیاده‌سازی کنید که مدت یک بازدید را می‌گیرد و آن را در این قالب برمی‌گرداند:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
