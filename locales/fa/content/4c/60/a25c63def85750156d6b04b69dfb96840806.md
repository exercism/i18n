# دستورهای مخصوص SQLite

- ستون **matrix** ورودی را در خود دارد: آرایه‌ای از آرایه‌های اعداد صحیح که با JSON کدگذاری شده است.
- ستون‌های **result** باید خروجی را در خود داشته باشند، یعنی فهرست نقاط زینی.
  خروجی باید آرایه‌ای از اشیا باشد که با JSON کدگذاری شده است و هر شیء دو کلید دارد: row و column.
  برای نمونه، `[{"row": 2, "column": 1}]`.
