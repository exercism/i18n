# درباره

جاوااسکریپت علاوه بر اعلان‌های تابع و عبارت‌های تابع، روش نوشتن بسیار موجز دیگری هم برای تعریف تابع دارد.
به این توابع، «توابع پیکانی» می‌گویند.

در این مفهوم، روی روش نوشتنی تمرکز می‌کنیم که برای نوشتن تابع پیکانی به کار می‌رود.
در نحوه‌ی کار تابع پیکانی تفاوت‌هایی وجود دارد، مثل اتصال `this`، که در مفاهیم دیگر به آن‌ها می‌پردازیم.

در ادامه، مقایسه‌ای بین اعلان تابع و تابع پیکانی می‌بینید.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

در بالا می‌بینید که روش نوشتن تابع پیکانی:

1. کلیدواژه‌ی `function` را حذف می‌کند
2. شناسه‌ی `addUpTwoNumbers` را به‌عنوان یک `const` اعلام کرده است
3. یک پیکان ضخیم `=>` اضافه می‌کند

اگر بدنه‌ی تابع، مثل مثال بالا، فقط شامل یک دستور `return` باشد، می‌توان `{}` و کلیدواژه‌ی `return` را حذف کرد.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

در حالت خاصی که تابع پیکانی فقط یک شیء را برمی‌گرداند، برای اینکه بتوان دستور return را حذف کرد، باید شیء را داخل پرانتز گذاشت.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return { num1, num2 };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

استفاده از پرانتز دور پارامترها به تعداد پارامترها بستگی دارد.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
