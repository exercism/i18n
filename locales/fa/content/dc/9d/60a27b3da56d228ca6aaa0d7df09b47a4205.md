# درباره

گاهی وقتی یک تابع آرگومان‌های زیادی می‌گیرد، به خاطر سپردن ترتیبی که باید در آن‌ها رعایت شود دشوار می‌شود. برای کمک به خوانایی، Gleam اجازه می‌دهد آرگومان‌ها را با یک اسم برچسب‌گذاری کنید.

برای برچسب زدن به یک آرگومان، اسم «برچسب» را پیش از اسم آرگومان بنویسید و آن دو را با یک فاصله از هم جدا کنید.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

وقتی تابعی را با آرگومان‌های برچسب‌دار فراخوانی می‌کنید، می‌توانید آرگومان‌ها را به هر ترتیبی بدهید. هر یک از این فراخوانی‌های `replace` معادل هم هستند:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

برچسب‌ها همیشه اختیاری‌اند. حتی اگر تابعی آرگومان‌های برچسب‌دار داشته باشد، هنوز هم می‌توان آن را بدون برچسب فراخوانی کرد.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

وقتی تابعی را با آرگومان‌های برچسب‌دار تعریف می‌کنید، همه‌ی آرگومان‌های پس از اولین آرگومان برچسب‌دار هم باید برچسب داشته باشند.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
