# نصب

برخلاف بسیاری از زبان‌های دیگر، Pyret نیازی ندارد که زبان را به‌صورت سراسری نصب کنید.
در عوض، توسعه‌دهندگان Pyret کامپایلر خود را به‌صورت یک بسته‌ی npm در دسترس قرار داده‌اند.
شما Pyret را برای هر تمرین با استفاده از `npm` نصب می‌کنید:
جزئیات بیشتر در صفحه‌ی [Testing][tests] خواهد بود.

شما باید Node.js را نصب کنید که یک محیط اجرای JavaScript است.
در صفحه‌ی [دانلود Node.js][download]، حتماً `npm` را به‌عنوان مدیر بسته انتخاب کنید.

~~~~exercism/note
در حال حاضر، بسته‌ی pyret-npm فقط با Linux و MacOS سازگار است.
کاربران Windows باید pyret-npm را با استفاده از WSL یا یک ماشین مجازی نصب کنند.
~~~~

[pyret-npm]: https://www.npmjs.com/package/pyret-npm
[tests]: ./tests
[download]: https://nodejs.org/en/download
