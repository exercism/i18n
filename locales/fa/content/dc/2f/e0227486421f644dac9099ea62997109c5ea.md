# مقدمه

JSON **آرایه** را چنین تعریف می‌کند:

> آرایه مجموعه‌ای مرتب از مقدارها است.
> آرایه با `[` کروشه‌ی چپ آغاز می‌شود و با `]` کروشه‌ی راست پایان می‌یابد.
> مقدارها با `,` ویرگول از هم جدا می‌شوند.

آرایه می‌تواند صفر یا چند مقدار JSON از _هر نوعی_ در خود داشته باشد.
لازم نیست عناصر آرایه همه از یک نوع باشند.

## ساخت آرایه‌ها

برای گردآوردن عناصر در یک آرایه، از کروشه استفاده کنید.

```jq
[1, 2, 3]
```

می‌توان عناصر یک _جریان_ را با قرار دادن آن میان کروشه‌ها در یک آرایه جمع کرد.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## اندازه

تابع `length` تعداد عناصر یک آرایه را برمی‌گرداند.

## نمایه‌گذاری و برش

نمایه‌گذاری آرایه از صفر آغاز می‌شود.

با یک عبارت کروشه‌ای، عنصری را از آرایه به دست آورید:
`.[2]` عنصر سوم را برمی‌گرداند.

نمایه‌های منفی از انتهای آرایه به عقب شمرده می‌شوند:
`.[-1]` آخرین عنصر را به دست می‌آورد و `.[-2]` عنصر یکی‌مانده به آخر را.

یک **برش**، زیردنباله‌ای از آرایه است.
`.[10:15]` پنج عنصر را از نمایه‌ی ۱۰ به بعد برمی‌گرداند؛ نمایه‌ی پایانی _لحاظ نمی‌شود_.

چند تابع برای راحتی کار وجود دارد:

- `first` اولین عنصر را به دست می‌آورد.
- `last` آخرین عنصر را به دست می‌آورد.
- `nth(n)` عنصر واقع در نمایه‌ی `n` را به دست می‌آورد.

## پیمایش

`jq` توابع زیادی برای پوشش عملکردهای رایج پیمایش فراهم می‌کند:

- `map(expr)` یک آرایه‌ی جدید برمی‌گرداند که در آن `expr` به ترتیب روی هر عنصر اعمال می‌شود.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` تابعی است که `expr` را روی یک _مقدار تکی_ اعمال می‌کند؛
  اگر نتیجه‌ی عبارت «درست» باشد، آن مقدار برگردانده می‌شود؛
  اگر نتیجه «غلط» باشد، _هیچ‌چیز_ برگردانده نمی‌شود؛ نه `null`، بلکه واقعاً هیچ‌چیز.

  برای اعمال آن روی یک آرایه، آن را با `map` ترکیب کنید.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  در روشی دیگر، `select` را روی یک _جریان_ اعمال کنید و نتایج را جمع کنید.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` و `all(condition)` یک مقدار منطقی برمی‌گردانند که نشان می‌دهد آیا برخی یا همه‌ی عناصر آرایه شرط را برآورده می‌کنند یا نه.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
