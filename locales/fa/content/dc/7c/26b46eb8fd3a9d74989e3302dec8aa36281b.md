# پیوست دستورالعمل‌ها

## Testing

تست‌ها برخی عملیات را به‌صورت هم‌روند اجرا می‌کنند.
باید تلاش کنید مطمئن شوید که عملیات روی `Account` آن را در وضعیت سازگار باقی می‌گذارند.
برای مثال: چندین `goroutine` ممکن است به‌طور هم‌زمان پول واریز و برداشت کنند، دو برداشت که به‌صورت هم‌روند انجام می‌شوند نباید بتوانند موجودی را منفی کنند.

وقتی به‌صورت محلی کار می‌کنید، می‌توانید تست کنید که کدتان هم‌روندی را درست مدیریت می‌کند و رقابت داده ایجاد نمی‌کند، تست‌ها را با روشن بودن پرچم `-race` اجرا کنید.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
