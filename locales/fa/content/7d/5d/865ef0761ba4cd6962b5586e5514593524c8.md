# مقدمه‌ای بر فهرست‌ها

**فهرست‌ها** در Java مجموعه‌ای ترتیبی هستند.
برخلاف آرایه‌ها، یک [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) می‌تواند بزرگ‌تر شود تا هر تعداد عنصر را در خود جای دهد.
یک پیاده‌سازی استاندارد، `ArrayList` است که بر پایه‌ی آرایه‌ای با اندازه‌ی قابل تغییر کار می‌کند.
پیاده‌سازی استاندارد دیگر، کلاس `LinkedList` است که بر پایه‌ی یک فهرست پیوندی دوطرفه کار می‌کند.

`List`ها می‌توانند خالی باشند یا هر تعداد عنصر (از جمله عناصر تکراری) را در خود نگه دارند.
`List`ها یک **رابط جنریک** هستند که مشخص می‌کند چه نوع شیءهایی را می‌توانند در خود جای دهند.
برای مثال:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`ها متدهای مفید گوناگونی برای افزودن، حذف، دریافت و بررسی حضور یک عنصر دارند:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
