# مقدمه

به‌طور پیش‌فرض، متغیرها به همان محدوده‌ای محدود می‌شوند که در آن تعریف شده‌اند. اگر بیرون از یک تابع یا کلاس و در یک فایل تعریف شوند، به محدوده‌ی همان فایل محدود می‌شوند. اگر درون یک تابع یا کلاس تعریف شوند، به محدوده‌ی آن تابع یا کلاس محدود می‌شوند.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

همچنین می‌توان متغیرها را به‌طور خاص با محدوده‌ی `global` یا `static` اعلان کرد.
