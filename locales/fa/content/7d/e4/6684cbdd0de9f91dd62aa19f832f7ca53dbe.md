# مقدمه

## عدد

از [این راهنما][man-types]

> jq از همان مجموعه انواع داده‌ای پشتیبانی می‌کند که JSON دارد: عدد، رشته، «منطقی»، آرایه، شیء (که در زبان JSON، هش‌هایی با کلیدهای تنها رشته‌ای هستند)، و «null».

بیایید روی **عددها** تمرکز کنیم.

### عدد و عملگرهای عددی

همه‌ی عددها، چه عددهای صحیح و چه غیر آن، اعداد ممیز شناور با دقت دوگانه‌ی IEEE754 هستند.
این موضوع دقت ما را به ۵۳ بیت محدود می‌کند.

عملگرهای معمول را می‌توانید با عددها به کار ببرید:

- محاسبات: `+`، `-`، `*`، `/`، `%`
- مقایسه: `==`، `!=`، `<`، `<=`، `>=`، `>`
- [توابع ریاضی][man-math] استاندارد

  برای توابع تک‌ورودی، مقدار را با pipe به تابع بدهید

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  برای توابع دوورودی، این توابع ورودی را نادیده می‌گیرند و انتظار دارند که
  ورودی‌ها به‌عنوان پارامتر داده شوند (به یاد بیاورید که پارامترها با نقطه‌ویرگول از هم جدا می‌شوند)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  نقطه‌ویرگول جداکننده‌ی آرگومان‌های تابع است، نه ویرگول.

### سایر عبارت‌های `jq`

برای حل این تمرین، باید با عبارت‌های شرطی آشنا باشید.

#### عبارت‌های شرطی

`jq` برای **عبارت‌های شرطی** از یک [عبارت `if-then-else`][if-then-else] استفاده می‌کند.
این عبارت، به‌عنوان یک _عبارت_، در یک پایپ‌لاین قرار می‌گیرد.

نحوه‌ی نگارش آن چنین است: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

بند `else` اختیاری است.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

شرط‌های بیشتر با `elif` بیان می‌شوند

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
