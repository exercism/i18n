# مقدمه

«استثنا» شکلی از مدیریت خطا است.
به آن‌ها استثنا می‌گوییم، چون معمولاً هنگام روبه‌رو شدن با رویدادی پیش‌بینی‌نشده ظاهر می‌شوند.

در هر نقطه‌ای از کدمان می‌توانیم یک استثنا را `raise` کنیم.
این کار را با استفاده از متد `raise` انجام می‌دهیم و یک شیء به آن می‌دهیم؛ معمولاً یک شیء استثنا، هرچند می‌توانیم از رشته‌های ساده هم استفاده کنیم.
برای مثال، می‌بینید که در استاب‌های تمرین از `RuntimeError` داخلی استفاده می‌کنیم تا به Ruby بگوییم متدی پیاده‌سازی نشده است.
همچنین می‌توانید از نحوه‌ی نگارش کوتاه `raise(ExceptionObject, params)` استفاده کنید.
اگر کلاس استثنا حذف شود، به‌طور پیش‌فرض از `RuntimeError` استفاده می‌شود.
برای مثال:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

وقتی Ruby این را می‌بیند، خطا را به بالای برنامه می‌فرستد و سپس برنامه خارج می‌شود.
برای مثال، اگر عددی را بر صفر تقسیم کنید، خروجی‌ای شبیه به این می‌بینید:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
