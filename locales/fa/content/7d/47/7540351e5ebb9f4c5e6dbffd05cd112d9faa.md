# پیوست دستورالعمل‌ها

## قالب باغ

باغ به‌صورت یک رشته‌ی پایان‌یافته با `null` نمایش داده می‌شود که در پایان هر سطر یک نویسه‌ی خط جدید دارد.

یک نمونه چنین است: `"   \n * \n   \n"`

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | آدرس | رشته‌ی ورودی پایان‌یافته با `null`  |
| `$a1`    | ورودی/خروجی | آدرس | رشته‌ی خروجی پایان‌یافته با `null` |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت         |
