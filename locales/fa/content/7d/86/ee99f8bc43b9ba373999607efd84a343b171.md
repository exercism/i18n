# Tests

اگر از ChezScheme استفاده می‌کنید، کافی است `make chez` را تایپ کنید و اگر از GNU Guile استفاده می‌کنید، `make guile` را تایپ کنید.

## استفاده از REPL

- در پرامپت REPL، `test.scm` را وارد کنید.
- راه‌حل خود را در فایل راه‌حل تمرین (برای مثال، `hello-world.scm`) توسعه دهید و همان‌طور که پیش می‌روید، آن را دوباره بارگذاری کنید.
- برای بررسی راه‌حل خود، `(test)` را اجرا کنید.
