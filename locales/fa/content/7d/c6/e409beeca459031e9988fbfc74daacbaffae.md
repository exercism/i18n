# دستورالعمل‌ها

در این تمرین، باید چند قانون از بازی کلاسیک Pac-Man را به توابع Elixir ترجمه کنید.

چهار قانون برای ترجمه دارید که همه به وضعیت‌های بازی مربوط می‌شوند.

> نگران این نباشید که آرگومان‌ها چطور به دست می‌آیند؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر برگردانده شود.

## 1. تعریف کنید که آیا Pac-Man شبح را می‌خورد

تابع `Rules.eat_ghost?/2` را تعریف کنید که دو آرگومان می‌گیرد (_اینکه آیا Pac-Man قرص قدرت فعال دارد_ و _اینکه آیا Pac-Man با یک شبح در تماس است_) و «مقدار منطقی» را برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌تواند شبح را بخورد. تابع باید تنها زمانی «درست» را برگرداند که Pac-Man قرص قدرت فعال داشته باشد و با یک شبح در تماس باشد.

```elixir
Rules.eat_ghost?(false, true)
# => false
```

## 2. تعریف کنید که آیا Pac-Man امتیاز می‌گیرد

تابع `Rules.score?/2` را تعریف کنید که دو آرگومان می‌گیرد (_اینکه آیا Pac-Man با یک قرص قدرت در تماس است_ و _اینکه آیا Pac-Man با یک نقطه در تماس است_) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man امتیاز گرفته است. اگر Pac-Man با یک قرص قدرت یا یک نقطه در تماس باشد، تابع باید «درست» را برگرداند.

```elixir
Rules.score?(true, true)
# => true
```

## 3. تعریف کنید که آیا Pac-Man می‌بازد

تابع `Rules.lose?/2` را تعریف کنید که دو آرگومان می‌گیرد (_اینکه آیا Pac-Man قرص قدرت فعال دارد_ و _اینکه آیا Pac-Man با یک شبح در تماس است_) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌بازد. اگر Pac-Man با یک شبح در تماس باشد و قرص قدرت فعالی نداشته باشد، تابع باید «درست» را برگرداند.

```elixir
Rules.lose?(false, true)
# => true
```

## 4. تعریف کنید که آیا Pac-Man می‌برد

تابع `Rules.win?/3` را تعریف کنید که سه آرگومان می‌گیرد (_اینکه آیا Pac-Man همه‌ی نقطه‌ها را خورده است_، _اینکه آیا Pac-Man قرص قدرت فعال دارد_ و _اینکه آیا Pac-Man با یک شبح در تماس است_) و یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا Pac-Man می‌برد. اگر Pac-Man همه‌ی نقطه‌ها را خورده باشد و بر اساس آرگومان‌های تعریف‌شده در بخش ۳ نباخته باشد، تابع باید «درست» را برگرداند.

```elixir
Rules.win?(false, true, false)
# => false
```
