# دستورالعمل‌ها

توالی‌های RNA را به پروتئین ترجمه کنید.

می‌توان RNA را به توالی‌هایی از سه نوکلئوتید تقسیم کرد که «کدون» نامیده می‌شوند و سپس آن‌ها را به شکل زیر به یک پلی‌پپتید ترجمه کرد:

RNA: `"AUGUUUUCU"` => ترجمه می‌شود به

کدون‌ها: `"AUG", "UUU", "UCU"`
=> که به پلی‌پپتیدی با توالی زیر تبدیل می‌شوند =>

پروتئین: `"Methionine", "Phenylalanine", "Serine"`

۶۴ کدون وجود دارد که به نوبه‌ی خود با ۲۰ اسید آمینه متناظرند؛ اما در این تمرین، همه‌ی توالی‌های کدون و اسیدهای آمینه‌ی حاصل مهم نیستند.
اگر برای یک کدون کار کند، برنامه باید برای همه‌ی آن‌ها کار کند.
با این حال، اگر دوست داشتید می‌توانید فهرست را در مجموعه آزمون گسترش دهید تا همه‌ی آن‌ها را در بر بگیرد.

سه کدون پایانی هم وجود دارد (که به کدون‌های «STOP» نیز معروف‌اند)؛ اگر به هر یک از این کدون‌ها برخورد شود (توسط ریبوزوم)، ترجمه به پایان می‌رسد و پروتئین خاتمه می‌یابد.

همه‌ی کدون‌های بعدی نادیده گرفته می‌شوند، مانند این:

RNA: `"AUGUUUUCUUAAAUG"` =>

کدون‌ها: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

پروتئین: `"Methionine", "Phenylalanine", "Serine"`

توجه کنید که کدون پایانی `"UAA"` ترجمه را متوقف می‌کند و متیونین آخر به توالی پروتئین ترجمه نمی‌شود.

در ادامه، کدون‌ها و اسیدهای آمینه‌ی حاصل که برای این تمرین لازم است، آمده‌اند.

| Codon              | Protein       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

درباره‌ی [ترجمه‌ی پروتئین در ویکی‌پدیا][protein-translation] بیشتر بدانید.
