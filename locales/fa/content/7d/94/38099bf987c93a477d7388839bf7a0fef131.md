# دستورالعمل‌ها

در این تمرین باید چند متد پیاده‌سازی کنید تا یک آرایه از زبان‌های برنامه‌نویسی را دستکاری کنید.

## 1. تعریف متدی برای برگرداندن یک آرایه‌ی خالی از زبان‌ها

متد `LanguageList.list` را تعریف کنید که هیچ آرگومانی نمی‌گیرد و یک آرایه‌ی خالی از نوع `Array(String)` برمی‌گرداند.

```crystal
LanguageList.list()
# => []
```

## 2. تعریف متدی برای افزودن یک زبان به آرایه

متد `LanguageList.add` را تعریف کنید که ۲ آرگومان می‌گیرد (یک _آرایه‌ی زبان‌ها_ و یک رشته‌ی متنی از یک _زبان_).
این متد باید آرایه را همراه با زبان جدیدی که به انتهای آن اضافه شده است برگرداند.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. تعریف متدی برای حذف یک زبان از آرایه

متد `LanguageList.remove` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _آرایه‌ی زبان‌ها_).
این متد باید آرایه را بدون آخرین عنصر برگرداند.
فرض کنید آرایه همیشه حداقل یک عنصر دارد.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. تعریف متدی برای برگرداندن عنصر nاُم آرایه

تابع `LanguageList.at` را تعریف کنید که ۲ آرگومان می‌گیرد (یک _آرایه‌ی زبان‌ها_ و یک اندیس).
این متد باید زبانی را که در اندیس n آرایه قرار دارد برگرداند.
فرض کنید همیشه در آن اندیس یک زبان وجود دارد.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. تعریف متدی برای تجزیه‌ی یک رشته از زبان‌ها

متد `LanguageList.parse` را تعریف کنید که ۱ آرگومان می‌گیرد (یک رشته‌ی متنی از زبان‌ها که با کاما از هم جدا شده‌اند).
این متد باید آرایه‌ای از زبان‌ها برگرداند.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
