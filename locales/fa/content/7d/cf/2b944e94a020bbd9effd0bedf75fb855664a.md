# درباره

یک «کوتیشن»، که در `[ ]` نوشته می‌شود، معادلِ تابع بی‌نام یا بلوک کد در Factor است. مقداری درجه‌اول است که می‌توانید آن را روی پشته بفرستید، ذخیره کنید یا پاس دهید و تنها زمانی اجرا می‌شود که چیزی آن را *فراخوانی* کند.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

کوتیشن‌ها دنباله‌ای از واژه‌ها هستند و Factor هرجا که تکه‌ای از رفتار باید به تعویق بیفتد یا پارامتری شود، از آن‌ها استفاده می‌کند:

- شاخه‌های `if` / `when` / `unless` / `cond`
- شرطِ `filter`، `count`، `any?`، `all?`
- تبدیلِ `map`، `each`، `reduce`
- بدنه‌ی `times`، `while`، `loop`

معمولاً می‌توان اثر پشته‌ی یک کوتیشن را استنتاج کرد. وقتی نمی‌توان (معمولاً وقتی که ذخیره می‌شود و بعداً با `call` فراخوانی می‌شود)، اثر را صریحاً اعلام کنید: `call( a b -- c )`.

## ترکیب کوتیشن‌ها

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` دو کوتیشن را پشت سر هم به هم می‌چسباند و کوتیشن تازه‌ای می‌سازد که ابتدا کوتیشن اول را اجرا می‌کند و سپس دومی را. `curry` یک مقدار ثابت را به ابتدای کوتیشن اضافه می‌کند و کوتیشنی برمی‌گرداند که آن مقدار را پیش از فراخوانی کوتیشن اصلی روی پشته می‌گذارد. هر دو کوتیشن‌های معمولی تولید می‌کنند که می‌توانید آن‌ها را `call` کنید، ذخیره کنید یا به ترکیب‌کننده‌ها پاس دهید.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
