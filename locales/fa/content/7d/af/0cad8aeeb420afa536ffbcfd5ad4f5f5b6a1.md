# کمک

اگر به مشکل خورده‌اید، برای گرفتن کمک می‌توانید از یکی از منابع زیر استفاده کنید:

- [مستندات API دارت](https://api.dart.dev/)
- [چت Gitter دارت](https://gitter.im/dart-lang/home)
- [اطلاعات انجمن](https://www.dart.dev/community)
- [/r/dartlang](https://www.reddit.com/r/dartlang) ساب‌ردیت دارت است.
- از [StackOverflow](https://stackoverflow.com/questions/tagged/dart) می‌توانید برای جست‌وجوی مشکل‌تان و دیدن اینکه از قبل پاسخ داده شده است یا نه استفاده کنید. همچنین می‌توانید پرسش مطرح کنید و به پرسش‌های دیگران پاسخ دهید.
