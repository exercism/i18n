# راهنما

مطمئن شوید که [مستندات ویژهی مسیر C][c-track] را در سایت Exercism خوانده‌اید. این صفحه اطلاعات پایه را درباره‌ی راه‌اندازی محیط توسعه‌ی مورد انتظار تمرین‌ها پوشش می‌دهد.

## منابع

اگر به مشکل خوردید، برای دریافت کمک می‌توانید از منابع زیر استفاده کنید:

- از [StackOverflow][] می‌توانید برای جست‌وجوی مشکلتان استفاده کنید و ببینید آیا پیش‌تر پاسخ داده شده است. همچنین می‌توانید پرسش مطرح کنید و به پرسش‌ها پاسخ دهید.
- از [CPPReference][] می‌توانید برای جست‌وجوی اطلاعات درباره‌ی مفاهیم C، عملگرها، نوع‌ها، توابع کتابخانه‌ی استاندارد و موارد بیشتر استفاده کنید.
- [TutorialsPoint][] در بخش برنامه‌نویسی C خود محتوایی مشابه CPPReference دارد.
- کتاب [The C Programming][K&R] اثر K&R منبع اصلی زبان است و امروز هم همچنان مفید است.
