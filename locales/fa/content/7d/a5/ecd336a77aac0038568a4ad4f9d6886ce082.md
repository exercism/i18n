# مقدمه

## سربارگذاری عملگر

عملگرهای اصلی حسابی و مقایسه‌ای را می‌توان طوری تنظیم کرد که کلاس‌ها و ساختارهای خودتان از آن‌ها استفاده کنند. به این کار «سربارگذاری عملگر» می‌گویند.

شکل بیشتر عملگرها چنین است:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

عملگرهای تبدیل نوع چنین شکلی دارند:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

عملگرها همانند متدهای ایستا رفتار می‌کنند. نماد عملگر جای نام متد می‌نشیند و آن‌ها پارامتر و نوع بازگشتی دارند. قواعد نوع برای پارامترها و نوع بازگشتی همان انتظاری است که دارید و می‌توانید روی راهنمایی دقیق کامپایلر حساب کنید.
