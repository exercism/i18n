# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | ورودی     | آدرس | رشته‌ی ورودی پایان‌یافته با نال                      |
| `$v0`    | خروجی     | منطقی | ورودی یک ایزوگرام است (`0` = `false`، `1` = `true`) |
| `$t0-9`  | موقت | هر نوع | برای ذخیره‌سازی موقت به کار می‌رود                        |
