# مقدمه

در Rust، هر نوعی که ویژگی [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html)
را پیاده‌سازی کند، می‌تواند به‌عنوان یک «تکرارگر» در نظر گرفته شود.
[`collections`](https://doc.rust-lang.org/std/collections/index.html) توکار Rust
را می‌توان از طریق متدهای `iter`، `iter_mut` و `into_iter` به تکرارگر تبدیل کرد.
تکرارگرها طیف گسترده‌ای از [متدهای قدرتمند](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods)
مانند `collect`، `map`، `filter` و `fold` را در اختیار شما می‌گذارند تا روی داده‌هایتان عملیات انجام دهید.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
