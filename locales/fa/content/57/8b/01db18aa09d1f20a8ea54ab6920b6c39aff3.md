# دستورالعمل‌ها

Lamont یک موجود فضایی اهل Lisp است که می‌خواهد بازی ویدیویی خودش را بنویسد. یکی از کارهایی که در آن از شما کمک خواسته‌اند، نگهداری از یک فهرست امتیازهای بالا است.

## 1. ساختن جدول امتیازهای بالا

تابعی به نام `make-high-score-table` تعریف کنید که هیچ آرگومانی نمی‌گیرد و به یک جدول هش خالی جدید ارزیابی می‌شود:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. افزودن یک بازیکن به جدول

برای افزودن یک بازیکن به جدول، تابعی به نام `add-player` تعریف کنید که دو آرگومان می‌گیرد:
- جدول امتیازهای بالا
- اسم بازیکن به‌صورت یک کلیدواژه

امتیاز اولیه‌ی بازیکن را صفر قرار دهید.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. تعیین امتیاز یک بازیکن

برای تعیین امتیاز یک بازیکن، تابعی به نام `set-score` تعریف کنید که سه آرگومان می‌گیرد:
- جدول امتیازهای بالا
- اسم بازیکن به‌صورت یک کلیدواژه
- امتیاز بازیکن به‌صورت یک عدد صحیح

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. گرفتن امتیاز از جدول

برای گرفتن امتیاز یک بازیکن از جدول، تابعی به نام `get-score` تعریف کنید که دو آرگومان می‌گیرد:
- جدول امتیازهای بالا
- اسم بازیکن به‌صورت یک کلیدواژه

این تابع باید به امتیاز ذخیره‌شده برای آن بازیکن ارزیابی شود.
اگر برای آن بازیکن امتیازی ذخیره نشده باشد، یا آن بازیکن هنوز در جدول نباشد، باید به `0` ارزیابی شود.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. حذف یک بازیکن از جدول

برای حذف یک بازیکن از جدول امتیازهای بالا، تابعی به نام `remove-player` تعریف کنید که دو آرگومان می‌گیرد:
- جدول امتیازهای بالا
- اسم بازیکن به‌صورت یک کلیدواژه

این تابع باید مواردی را که بازیکن هنوز به جدول اضافه نشده است، به‌خوبی مدیریت کند.
بدیهی است که پس از حذف یک بازیکن، اگر امتیاز او از جدول گرفته شود، صفر خواهد بود.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
