# نگاشت و مجموعه

آرایه مقادیر را در موقعیت‌های شماره‌دار نگه می‌دارد. گاهی برچسبی که به کار می‌آید یک عدد نیست.

## نگاشت

**«نگاشت»** هر **«کلید»** را با یک **«هدف»** جفت می‌کند. چیزی را با کلیدش جست‌وجو کنید و نگاشت همان چیزی را به شما می‌دهد که زیر آن بایگانی شده است.

`FMAP{K,T}` نگاشتی است از کلیدهایی از نوع `K` به هدف‌هایی از نوع `T`. یک راهنما که اسم یک حیوان را با محل زندگی‌اش جفت می‌کند، از نوع `FMAP{STR,STR}` است.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## همیشه پاسخ را دوباره نسبت دهید

دوباره به آن خط میانی نگاه کنید. `insert` نگاشتی را برمی‌گرداند که جفت اضافه در آن هست، و این پاسخ باید نگه داشته شود:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

این همان قاعده‌ی `FSTR` است و به همان دلیل. پاسخ معمولاً همان نگاشتی است که وارد شده بود، که در جای خودش تغییر کرده؛ گاهی هم، وقتی نگاشت جا کم می‌آورد، نگاشتی بزرگ‌تر است. از آنجا که نمی‌توانید تشخیص دهید کدام است، **از پاسخ استفاده کنید و استفاده از اسم قدیمی را متوقف کنید.** اسمی که از پیش از یک `insert` باقی مانده ممکن است قدیمی شده باشد یا اصلاً نگاشت قابل استفاده‌ای را توصیف نکند.

این یعنی نگاشتی هم که به یک روال داده می‌شود از آن در امان نیست. اگر قرار است نسخه‌ی اصلی باقی بماند، `copy` را در صفحه‌ی مفهوم ببینید.

## آیا وجود دارد؟

`has_ind` می‌پرسد که آیا کلیدی در نگاشت هست یا نه. این اسم کوتاه‌شده‌ی «has index» است؛ index همان چیزی است که این نگاشت‌ها به آن کلید می‌گویند.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

پرسیدن کلیدی که آنجا نیست **هیچ ایرادی نمی‌گیرد**. `get` مقدار خالیِ آن نوع را برمی‌گرداند، یعنی برای یک `INT` صفر، و برای یک `STR` مقدار «void»؛ که بعداً و در جای دیگری خرابی به بار می‌آورد. پس پیش از آنکه بگیرید، نگاه کنید:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## مجموعه

**«مجموعه»** مقادیر را بدون تکرار و بدون ترتیب نگه می‌دارد. `FSET{T}` مجموعه‌ای از مقادیر نوع `T` است.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

اگر چیزی را دو بار درج کنید، فقط یک نسخه باقی می‌ماند. کاربرد مجموعه همین است: گردآوری مقادیر و فراموش کردن این نکته که هر کدام چند بار ظاهر شده‌اند.

`insert` روی یک مجموعه، مجموعه‌ای را برمی‌گرداند که از آن پس باید از آن استفاده کنید، درست همان‌طور که برای نگاشت هم همین کار را می‌کند، پس هر بار آن را دوباره نسبت دهید.

## چه تعداد

`.size` روی هر دو کار می‌کند: چند جفت در یک نگاشت هست و چند مقدار در یک مجموعه.
