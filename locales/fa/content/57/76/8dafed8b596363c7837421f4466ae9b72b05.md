# مقدمه

## تاریخ و زمان

بسته‌ی `java.time` که در Java ۸ معرفی شد، شامل چندین کلاس برای کار با تاریخ و زمان است.

### `LocalDate`

کلاس `java.time.LocalDate` تاریخی را بدون منطقه‌ی زمانی در [سیستم تقویم ISO-8601][iso-8601] نمایش می‌دهد، مانند `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

تاریخ‌ها را می‌توان با تاریخ‌های دیگر مقایسه کرد:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

یک نمونه‌ی `LocalDate` متدهای گیرنده‌ای دارد که بخش‌های زمانی را از آن بازیابی می‌کنند:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

یک نمونه‌ی `LocalDate` متدهایی برای افزودن یکاهای زمان به آن دارد:

```exercism/note
این متدها یک نمونه‌ی _جدید_ `LocalDate` برمی‌گردانند و نمونه‌ی موجود را به‌روزرسانی نمی‌کنند، چون کلاس `LocalDate` تغییرناپذیر است.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

کلاس `java.time.LocalDateTime` تاریخ و زمانی را بدون منطقه‌ی زمانی در [سیستم تقویم ISO-8601][iso-8601] نمایش می‌دهد، مانند `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

می‌توانید یک نمونه‌ی `LocalDate` را به `LocalDateTime` تبدیل کنید:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### قالب‌بندی تاریخ و زمان

هر دو کلاس `LocalDate` و `LocalDateTime` هنگام تبدیل از `String` و به آن، از نشانه‌گذاری استاندارد [ISO-8601][iso-8601] استفاده می‌کنند.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

نمی‌توان `LocalDate` یا `LocalDateTime` را با قالب متفاوتی از رشته‌ای مانند این تجزیه کرد.
در عوض، برای قالب‌بندی تاریخ‌ها با یک قالب سفارشی، باید از `java.time.format.DateTimeFormatter` استفاده کنید:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

هنگام ساختن قالب سفارشی می‌توان یک locale را نیز مشخص کرد تا قالب‌بندی و تجزیه برای مناطق مختلف انجام شود:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
