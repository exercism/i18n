# راهنمایی

## کلیات

- [سربارگذاری متد در C#][member-overloading].
- برای قالب‌بندی رشته‌های توصیف می‌توان از [درون‌گذاری رشته][string-interpolation] استفاده کرد.

## 3. توصیف روش سفر

- برای منطق شرطی می‌توان از یک [شرط ساده][if-statement] استفاده کرد.

## 4. توصیف سفر یک شخصیت به یک مقصد

- می‌توانید از قابلیت توصیف موجود دوباره استفاده کنید.
- می‌توانید از [عبارت‌ها در رشته‌های درون‌گذاری‌شده][string-interpolation-expressions] استفاده کنید، یعنی می‌توانید متدها را مستقیماً در بخش‌های درون‌گذاری‌شده‌ی یک رشته‌ی درون‌گذاری‌شده فراخوانی کنید.

## 5. توصیف سفر یک شخصیت به یک مقصد بدون مشخص کردن روش سفر

- می‌توانید از قابلیت موجودی که روش سفر را به‌صورت صریح می‌گیرد دوباره استفاده کنید.
- می‌توانید از [پارامترهای اختیاری][optional-arguments] استفاده کنید تا کدی که لازم دارید ساده‌تر شود.
