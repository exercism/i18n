# دستورالعمل‌ها

در این تمرین با حساب‌های پس‌انداز کار می‌کنید.
هر سال، موجودی حساب پس‌اندازتان بر اساس نرخ سود آن به‌روزرسانی می‌شود.
نرخ سودی که بانک به شما می‌دهد به مقدار پول موجود در حساب شما (یعنی موجودی آن) بستگی دارد:

- ۳٫۲۱۳٪ برای موجودی کمتر از `0` دلار (موجودی منفی‌تر می‌شود).
- ۰٫۵٪ برای موجودی بزرگ‌تر یا مساوی `0` دلار و کمتر از `1000` دلار.
- ۱٫۶۲۱٪ برای موجودی بزرگ‌تر یا مساوی `1000` دلار و کمتر از `5000` دلار.
- ۲٫۴۷۵٪ برای موجودی بزرگ‌تر یا مساوی `5000` دلار.

چهار وظیفه دارید که هر یک به موجودی و نرخ سود آن می‌پردازد.

## 1. محاسبه‌ی نرخ سود

تابع `interest_rate` را پیاده‌سازی کنید تا نرخ سود را بر اساس موجودی داده‌شده محاسبه کند:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. محاسبه‌ی سود

تابع `yearly_interest` را پیاده‌سازی کنید تا سود را بر اساس موجودی داده‌شده محاسبه کند:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. محاسبه‌ی به‌روزرسانی سالانه‌ی موجودی

تابع `annual_balance_update` را پیاده‌سازی کنید تا به‌روزرسانی سالانه‌ی موجودی را با در نظر گرفتن نرخ سود محاسبه کند:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. محاسبه‌ی تعداد سال‌های لازم برای رسیدن به موجودی مطلوب

تابع `years_until_desired_balance` را پیاده‌سازی کنید تا کمترین تعداد سال لازم برای رسیدن به موجودی مطلوب را محاسبه کند، با در نظر گرفتن این که هر سال سود به موجودی اضافه می‌شود.
یعنی موجودی پس از یک سال برابر است با: موجودی آغازین + سود موجودی آغازین.
موجودی پس از سال دوم برابر است با موجودی پس از یک سال + سود موجودی پس از یک سال.
و به همین ترتیب، تا وقتی که موجودی سال جاری بزرگ‌تر یا مساوی موجودی هدف شود.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

توجه کنید که مقدار برگردانده‌شده از نوع `int` است.
