# پیوست دستورالعمل‌ها

## «ثبات‌ها»

| ثبات | کاربرد | نوع | توضیحات |
| -------- | --------- | ------- | --------------------------- |
| `$a0` | ورودی | آدرس | آرایه‌ای از کلمات کتاب |
| `$a1` | ورودی | عدد صحیح | تعداد کتاب‌ها |
| `$v0` | خروجی | عدد صحیح | قیمت، به سنت |
| `$t0-9` | موقت | هر | برای ذخیره‌سازی موقت |
