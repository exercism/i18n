# دستورالعمل‌ها

Elyse، جادوگر تازه‌کار، به تمرینش ادامه می‌دهد.
او یک دسته کارت دارد که می‌خواهد با آن‌ها کار کند.

برای اینکه کارها ساده‌تر شود، او معمولاً فقط با کارت‌های شماره‌ی ۲ تا ۱۰ شروع می‌کند، هرچند بعضی از تردستی‌ها ممکن است کارت‌های (تصویری) بیشتری را هم درگیر کنند.

<!-- prettier-ignore-start -->
~~~~exercism/note
**راه‌های** زیادی برای جابه‌جا کردن کارت‌ها وجود دارد، اما برای حفظ توهم جادو، حیاتی است که *هیچ روش واحدی* استفاده نشود؛ مثلاً Elyse از `splice`، `slice`، `shift`، `unshift`، `push`، `at` استفاده نمی‌کند.
همچنین هرگز نباید از `array[index]` برای دسترسی به آرایه و از `object[key]` و `object.key` برای دسترسی به شیء استفاده کرد.
~~~~
<!-- prettier-ignore-end -->

می‌خواهید به Elyse کمک کنید جادویش را ارتقا دهد؟

<!-- prettier-ignore-start -->
~~~~exercism/advanced
هر تابع را می‌توان با استفاده از پارامترها و بدنه‌ی تابعی پیاده‌سازی کرد که تنها یک `return expression` دارد.
~~~~
<!-- prettier-ignore-end -->

## 1. اولین کارت را بگیرید

Elyse اولین کارت دسته را بدون استفاده از `array[index]`، `.at(index)` یا `.shift()` احضار می‌کند.
درست مثل جادو.

```javascript
const deck = [5, 9, 7, 1, 8];

getFirstCard(deck);
// => 5
```

## 2. دومین کارت را بگیرید

Elyse با یک تردستی دومین کارت دسته را بدون استفاده از `array[index]` یا `.shift()` احضار می‌کند.

```javascript
const deck = [3, 2, 10, 6, 7];

getSecondCard(deck);
// => 2
```

## 3. دو کارت را جابه‌جا کنید

Elyse کاری می‌کند که دو کارت دسته جایشان را با هم عوض کنند.
او نیازی به فراخوانی حتی یک تابع ندارد.

```javascript
const deck = [10, 7];

swapTwoCards(deck);
// => [7, 10]
```

## 4. سه کارت را بچرخانید

برای اینکه تردستی بیشتری انجام دهد، Elyse سه کارت برمی‌دارد و به‌سرعت کارت رویی را به پشت می‌فرستد؛ طوری که کارت میانی اولین کارت می‌شود و کارت پایینی قبلی کارت میانی.
او نیازی به فراخوانی حتی یک تابع ندارد.

```javascript
const deck = [2, 6, 10];

shiftThreeCardsAround(deck);
// => [6, 10, 2]
```

## 5. دسته‌ی نام‌گذاری‌شده را انتخاب کنید

Elyse دسته را به دو دسته تقسیم می‌کند.
سپس از تماشاگر می‌خواهد یکی از این دو دسته را انتخاب کند که ما آن را `chosen` می‌نامیم.
دسته‌ی `disregarded` دیگر اهمیتی ندارد و او آن را ناپدید می‌کند.
او نیازی به فراخوانی حتی یک تابع ندارد.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

pickNamedPile({ chosen, disregarded });
// => [5, 4]
```

## 5. دسته‌ی انتخاب‌شده را جابه‌جا کنید

متأسفانه تماشاگر مدام دسته‌ی «اشتباه» را انتخاب می‌کند، اما Elyse با یک جادوی سریع و هوشمندانه، نام دسته‌ی `chosen` را به `disregarded` و نام دسته‌ی `disregarded` را به `chosen` تغییر می‌دهد.
او نیازی به فراخوانی حتی یک تابع ندارد.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

swapNamedPile({ chosen, disregarded });
// => { chosen: [7, 10], disregarded: [5, 4] }
```
