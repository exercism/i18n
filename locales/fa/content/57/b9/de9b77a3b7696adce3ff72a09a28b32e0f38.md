# پیوست دستورالعمل‌ها

## قالب خروجی

لوزی را به‌صورت یک رشته‌ی پایان‌یافته با نال خروجی دهید که در پایان هر سطر آن یک کاراکتر خط جدید قرار دارد.

یک خروجی نمونه این می‌شود: `"  A  \n B B \nC   C\n B B \n  A  \n"`

## ثبات‌ها

| ثبات     | کاربرد           | نوع     | توضیح                             |
| -------- | ---------------- | ------- | --------------------------------- |
| `$a0`    | ورودی            | بایت    | حرف                               |
| `$a1`    | ورودی/خروجی      | آدرس    | رشته‌ی نتیجه‌ی پایان‌یافته با نال   |
| `$t0-9`  | موقت             | هر نوع  | برای ذخیره‌سازی موقت               |
