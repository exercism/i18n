# مقدمه

`OpenStruct` به شما امکان می‌دهد به‌راحتی از یک `Hash` یک شیء بسازید.
به‌جای این‌که مجبور باشید با کلیدهای `Hash` به مقادیر دسترسی داشته باشید، `OpenStruct` به ما امکان می‌دهد با متدها به مقادیر دسترسی پیدا کنیم و آن‌ها را مقداردهی کنیم.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

یک مزیت این روش این است که هنگام استفاده از «بلوک» می‌توانیم از یک میان‌بر بهره ببریم.
در موقعیت‌هایی که یک بلوک فقط یک متد را فراخوانی می‌کند، می‌توانید بلوک را با `&:` و پس از آن اسم متد جایگزین کنید.
برای نمونه، این دو خط هم‌معنی هستند:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## کتابخانه‌ی استاندارد

همه‌ی کلاس‌هایی که در تمرین‌های قبلی دیده‌اید بخشی از کتابخانه‌ی هسته‌ی Ruby بوده‌اند.

OpenStruct بخشی از کتابخانه‌ی استاندارد Ruby است (که اغلب به «stdlib» کوتاه می‌شود)، مجموعه‌ای از کلاس‌ها برای کار با مواردی مانند تاریخ‌ها، json و شبکه.
همچنین قابلیت‌های مفیدی فراهم می‌کند که کار با کدتان را آسان‌تر می‌کند.

وقتی از کلاس‌هایی استفاده می‌کنیم که از کتابخانه‌ی هسته نیستند (کد خودتان در فایل‌های دیگر، کلاس‌های stdlib، یا وابستگی‌های بیرونی)، باید پیش از استفاده آن‌ها را با متد `require` وارد کنیم.
برای نمونه:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
