# دستورالعمل‌ها

بندر پالرمو یک لنگرگاه پررفتوآمد است که کشتی‌های زیادی به آن وارد و از آن خارج می‌شوند.
مدت‌هاست که این بندر برای پیگیری کشتی‌هایی که در حال حاضر در لنگرگاه هستند، یک سامانه‌ی دستی دارد.
این سامانه بسیار خطاپذیر است و رئیس بندر تصمیم گرفته آن را با یک سامانه‌ی رایانه‌ای جایگزین کند.

رئیس بندر شما را استخدام کرده است تا سامانه‌ی جدید را پیاده‌سازی کنید.
این سامانه باید شناسه‌ها را برای کشتی‌ها و همچنین برای مقصدها مدیریت کند.

## 1. شناسه‌ی بندر را بسازید

اولین کاری که باید انجام دهید این است که شناسه‌ی بندر پالرمو را بسازید.
شناسه از چهار حرف اول اسم بندر تشکیل می‌شود، با حروف بزرگ.

ثابت `Port::IDENTIFIER` را طوری تعریف کنید که یک نماد با مقدار `:PALE` باشد.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. شناسه‌ی بندرهای دیگر را به دست آورید

برنامه باید بندرهای دیگر را هم مدیریت کند، بنابراین باید برای آن‌ها هم شناسه بسازید.
بندر می‌خواهد این سامانه خودکار باشد و چون بندرها از قراردادهای نام‌گذاری متفاوتی استفاده می‌کنند، شناسه‌ها باید از اسم بندر تولید شوند.
شناسه از چهار حرف اول اسم بندر تشکیل می‌شود، با حروف بزرگ.

متد `Port.get_identifier` را طوری تعریف کنید که یک رشته به عنوان آرگومان بگیرد و شناسه‌ی آن بندر را به صورت یک نماد برگرداند.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. تعیین کنید که یک کشتی باید در کدام ترمینال پهلو بگیرد

بندر دو ترمینال دارد و سامانه باید تعیین کند که یک کشتی باید در کدام ترمینال پهلو بگیرد.
ترمینال بر اساس شناسه‌ی کشتی مشخص می‌شود.

شناسه از ۲ بخش ساخته می‌شود؛ بخش اول از ۳ حرف بزرگ تشکیل شده است که می‌گوید کشتی چه باری حمل می‌کند و سپس ۳ عدد که شناسه‌ی یکتای کشتی است.

اگر کشتی بار **OIL** یا **GAS** را حمل کند، باید در ترمینال **A** پهلو بگیرد.
در غیر این صورت، کشتی باید در ترمینال **B** پهلو بگیرد.

متد `Port.get_terminal` را طوری تعریف کنید که یک نماد به عنوان آرگومان بگیرد که همان شناسه‌ی کشتی است.
متد باید ترمینال را به صورت یک نماد برگرداند.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
