# کلیات

[آموزش مقایسه در Python][python comparisons tutorial] و [نمونه‌های مقایسه در Python][python comparisons examples] مقدمه‌ی بسیار خوبی برای محتوای این تمرین هستند.

## 1. محاسبه‌ی مقدار یک کارت

- می‌توانید از عملگر مقایسه‌ی تساوی `==` استفاده کنید تا مشخص کنید آیا یک کارت، کارت آس است یا نه: `card == 'A'`.
- می‌توانید از عملگر عضویت `in` استفاده کنید تا مشخص کنید آیا یک زیررشته درون یک رشته قرار دارد یا نه: `'Q' in 'KJQ'`.
- می‌توانید از [سازنده‌ی `int`][int constructor] استفاده کنید تا یک `str` از یک `int` را به یک `int` تبدیل کنید: `int('13')`.

## 2. تعیین این که کدام کارت مقدار بیشتری دارد

- وقتی تابع `value_of_card` را تعریف کردید، می‌توانید آن را از توابع دیگر فراخوانی کنید.
- می‌توانید از عملگرهای مقایسه‌ی مقدار `>` و `<` استفاده کنید تا مشخص کنید آیا کارت‌های مشخصی _بزرگ‌تر از_ یا _کوچک‌تر از_ یک مقدار معلوم هستند یا نه: `3 < 12`.
- می‌توانید از عملگر مقایسه‌ی تساوی `==` استفاده کنید تا مشخص کنید آیا دو مقدار با هم برابرند یا نه.

## 3. محاسبه‌ی مقدار یک آس

- وقتی تابع `value_of_card` را تعریف کردید، می‌توانید آن را از توابع دیگر فراخوانی کنید.
- می‌توانید از عملگر مقایسه‌ی ترتیب `>` استفاده کنید تا در اینجا تصمیم بگیرید چه اقدامی مناسب است.

## 4. تشخیص بلک‌جک

- یادتان باشد که می‌توانید از [نحوه‌ی نگارش `if`/`elif`/`else`][if syntax] استفاده کنید تا ترکیب‌های مختلف کارت‌ها را مدیریت کنید.
- می‌توانید هم عملگرهای مقایسه و هم عملگرهای منطقی را _به‌صورت دلخواه_ به هم زنجیره کنید: `y < z < x` یا `(y or z) and (x or z)`
- می‌توانید از تابع `value_of_card` که پیش‌تر پیاده‌سازی شده است دوباره استفاده کنید.

## 5. جدا کردن جفت‌ها

- می‌توانید از تابع `value_of_card` که پیش‌تر پیاده‌سازی شده است دوباره استفاده کنید.
- می‌توانید حالت `A` را جداگانه مدیریت کنید (زمانی که دست‌کم یکی از کارت‌ها آس است).

## 6. دو برابر کردن

- یک `A` که ۱۱ شمرده می‌شود، اگر دو کارت در دست باشد هرگز اجازه‌ی دو برابر کردن نمی‌دهد.
- با توجه به نکته‌ی اول، _باید_ بتوانید از تابع `value_of_card` که پیش‌تر پیاده‌سازی شده است دوباره استفاده کنید.
- می‌توانید عملگرهای مقایسه را _به‌صورت دلخواه_ زنجیره کنید: `y < z < x`.
- می‌توانید از [عبارت شرطی][conditional expression] (_که گاهی «عملگر سه‌گانه» هم نامیده می‌شود_)
  برای کوتاه کردن دستورهای ساده‌ی `if`/`else` استفاده کنید: `13 if letter == 'M' else 3`.
