# مقدمه

## انواع تودرتو

انواع C# می‌توانند در محدوده‌ی یک کلاس یا ساختار تعریف شوند. نوع دربرگیرنده نوعی فضای نام فراهم می‌کند. دسترسی به نوع، از طریق نوع دربرگیرنده و با نحوه‌ی نگارش نقطه‌ای انجام می‌شود.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

می‌توانید سطوح دسترسی را برای انواع داخلی تنظیم کنید.

اعضای خصوصی نوع بیرونی در محدوده‌ی اعضای نوع داخلی قرار دارند، اما برعکس آن صادق نیست.
