# آرایه

آرایه در PHP یک نگاشت مرتب است.
نگاشت یک ساختمان داده است که یک کلید را به یک مقدار نسبت می‌دهد.
آرایه همه‌کاره است و می‌توان با آن مانند یک آرایه‌ی خطی (مثل `C` یا `Java`)، لیست [بردار]، جدول هش، دیکشنری، مجموعه، پشته یا صف رفتار کرد.

کلید اختیاری است، اما اگر مشخص شود باید یا از نوع `int` باشد یا از نوع `string`.
وقتی کلیدی ارائه نشود، PHP به‌طور پیش‌فرض کلیدهای عدد صحیح را به ترتیب صعودی و با شروع از `0` در نظر می‌گیرد.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

آرایه می‌تواند مقادیری از همه‌ی نوع‌ها را ذخیره کند.
هر مقدار می‌تواند نوع متفاوتی داشته باشد.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## استفاده از آرایه

آرایه را می‌توان به‌صورت نوشتاری تعریف کرد (همان‌طور که در بالا در کد نوشته شد) یا آن را با توابع ساخت و تغییر داد.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

با استفاده از عملگر اندیس به مقادیر دسترسی پیدا کنید، به آن‌ها مقدار بدهید یا مقادیر تازه اضافه کنید:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

با `foreach` روی آرایه پیمایش کنید:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
