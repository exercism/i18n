# مقدمه

در JavaScript، کلاس `Array` روش‌های داخلی قدرتمند زیادی برای تبدیل آرایه‌ها دارد.
این روش‌ها تبدیل یک آرایه به آرایه‌ی دیگر را بسیار ساده‌تر از آن می‌کنند که در غیر این صورت با یک حلقه‌ی For ساده یا دستکاری مستقیم‌تر ممکن بود.

برخی از این روش‌ها [_خالص_][pure-function-definition] هستند، یعنی آرایه‌ی اصلی را تغییر نمی‌دهند و به‌جای آن یک آرایه‌ی جدید برمی‌گردانند.
اما روش‌های دیگر آرایه‌ای را که روی آن فراخوانی می‌شوند دستکاری می‌کنند و آرایه‌ی تغییریافته را **برنمی‌گردانند**.

در ادامه برخی از پرکاربردترین روش‌های تبدیل آرایه‌ها معرفی می‌شوند.
فهرست کامل روش‌های موجود را می‌توانید در [مستندات MDN][array-methods] ببینید.

### map (خالص)

با تبدیل هر عنصر بر اساس تابعی که به‌عنوان آرگومان داده می‌شود، یک آرایه‌ی جدید بسازید.
این توابع callback اغلب به شکل [توابع پیکانی][concept-arrow-functions] نوشته می‌شوند.

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

شایان ذکر است که آرایه‌ی حاصل همیشه همان‌دازه با آرایه‌ی اصلی خواهد بود.

### filter (خالص)

با کمک یک تابع فیلترکننده (که اگر عنصر باید نگه داشته شود «درست» و اگر باید حذف شود «غلط» برمی‌گرداند)، آرایه‌ی جدیدی از روی آرایه‌ی فعلی می‌سازد.

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (خالص)

آرایه را با استفاده از تابعی که یک _انباشتگر_ و عنصر فعلی آرایه را به‌عنوان پارامتر می‌گیرد، به یک مقدار واحد کاهش می‌دهد.
این تابع مشخص می‌کند که عنصر فعلی چگونه باید در انباشتگر ادغام شود و انباشتگری را برمی‌گرداند که در تکرار بعدی استفاده خواهد شد.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

ترتیب عناصر یک آرایه را برعکس می‌کند.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

این روش آرایه‌ای را که روی آن فراخوانی می‌شود تغییر می‌دهد.

### slice (خالص)

با گرفتن ایندکس شروع و پایان، یک زیرآرایه از آرایه‌ی داده‌شده به‌عنوان پارامتر می‌سازد.

عنصر موجود در ایندکس پایان شامل نمی‌شود.
همچنین همه‌ی پارامترها اختیاری‌اند:
ایندکس شروع به‌طور پیش‌فرض `0` است و ایندکس پایان به‌طور پیش‌فرض طول آرایه.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

عناصری از یک آرایه را حذف می‌کند، یا جایگزین می‌کند و/یا عناصر جدیدی اضافه می‌کند.

پارامترهای زیر را می‌گیرد:

- ایندکس عنصری که تغییر آرایه از آنجا شروع می‌شود
- تعداد عناصری که باید حذف شوند
- عناصری که باید در آرایه درج شوند (اختیاری)

`splice` عناصری را که حذف شده‌اند برمی‌گرداند.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

به‌طور پیش‌فرض، `sort` عناصر یک آرایه را ابتدا با تبدیل آن‌ها به رشته و سپس با اعمال مقایسه‌ی رشته‌ای مرتب می‌کند (به [مفهوم مقایسه][concept-comparison] نگاه کنید).
مرتب‌سازی _درجا_ انجام می‌شود، یعنی آرایه‌ی اصلی تغییر می‌کند.
`sort` همچنین همان آرایه‌ی تغییریافته را برمی‌گرداند که اگر بخواهید روش‌های دیگر را به آن زنجیره کنید، راحت است.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

برای سفارشی‌سازی رفتار مرتب‌سازی، می‌توانید یک تابع مقایسه به‌عنوان آرگومان بدهید.
خود تابع مقایسه با دو آرگومان فراخوانی می‌شود که همان دو عنصر آرایه هستند.
سپس باید موارد زیر را برگرداند:

- یک عدد منفی اگر آرگومان اول باید قبل از دومی مرتب شود
- یک عدد مثبت اگر آرگومان اول باید بعد از دومی مرتب شود
- `0` اگر ترتیب عناصر باید یکسان بماند

در ادامه مثالی می‌بینید از اینکه چگونه می‌توان از یک تابع مقایسه‌ی سفارشی برای مرتب‌سازی آرایه‌ای از شیءها استفاده کرد.

```javascript
const arr = [
  { name: 'Lydia', age: 7 },
  { name: 'Anne', age: 34 },
  { name: 'Holger', age: 59 },
];

arr.sort((item1, item2) => {
  if (item1.name < item2.name) {
    return -1;
  }
  if (item1.name > item2.name) {
    return 1;
  }
  return 0;
});
// => [ { name: 'Anne', age: 34 }, { name: 'Holger', age: 59 },
// { name: 'Lydia', age: 7 } ]
```
