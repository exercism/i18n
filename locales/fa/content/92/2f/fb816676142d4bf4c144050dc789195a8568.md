# نوع منطقی

در Cairo، نوع «منطقی» برای عملیات منطقی و دستورهای شرطی ضروری است.
مقدارهای منطقی در Cairo اندازه‌ی یک `felt252` را دارند؛ این کار ضمن حفظ سادگی منطق «درست» و «غلط»، استفاده‌ی کارآمد از فضا را نیز تضمین می‌کند.

نوع منطقی در Cairo با کلیدواژه‌ی `bool` مشخص می‌شود.
این کار اعلام و دستکاری متغیرهای منطقی را در این زبان ممکن می‌کند.
برای نمونه، مثال زیر را در نظر بگیرید:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

در این مثال، دو متغیر منطقی اعلام شده است.
به متغیر `t` مقدار `true` نسبت داده شده و نوع آن به‌طور ضمنی منطقی در نظر گرفته شده است، در حالی که متغیر `f` به‌صراحت با نوع `bool` نشانه‌گذاری شده و مقدار `false` به آن نسبت داده شده است.

یک نکته‌ی مهم این است که هنگام اعلام یک متغیر منطقی در Cairo، استفاده از مقدار ثابت `true` یا `false` به‌عنوان مقدار الزامی است.
یعنی نمی‌توان از مقدارهای ثابت صحیح، مثل `0` یا `1`، به‌جای `false` یا `true` استفاده کرد.
اجرای سخت‌گیرانه‌ی این قاعده، ایمنی نوع را تضمین می‌کند و از خطاهای منطقی احتمالی در توسعه‌ی قرارداد هوشمند جلوگیری می‌کند.

## عملگرهای منطقی در Cairo

- `||` (یا منطقی): اگر دست‌کم یکی از عملوندها `true` باشد، `true` برمی‌گرداند.
- `&&` (و منطقی): اگر هر دو عملوند `true` باشند، `true` برمی‌گرداند.
- `!` (نقیض منطقی): مقدار منطقی مخالف عملوند را برمی‌گرداند.

## نمونه کد

قطعه کد زیر نشان می‌دهد که چگونه از نوع‌های منطقی در Cairo استفاده می‌شود.
در آن، اعلام متغیرهای منطقی، انتساب عبارت‌های منطقی و استفاده از دستورهای `assert` برای بررسی درستی منطق آمده است:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
