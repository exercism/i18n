# دستورالعمل

شما در کلبه‌ی رادیویی ساحل هستید و گفت‌وگوهای کانال را رصد می‌کنید: پیام‌ها روی خط می‌رسند، آن‌ها را ثبت می‌کنید و پاسخ‌ها را دوباره به بیرون می‌فرستید. پنج واژه‌ی کوچک، کار یک شیفت را انجام می‌دهند.

آزمون‌ها ورودی‌هایی از نوع `<string-reader>` به شما می‌دهند (ترافیک ورودی) و برای داده‌های خروجی از `<string-writer>` استفاده می‌کنند، اما هر واژه‌ای در اینجا با یک `<file-reader>` واقعی یا یک سوکت هم به همین شکل کار می‌کند.

## 1. همه‌اش را بشنوید

`hear-out` را تعریف کنید تا یک جریان ورودی را به یک رشته‌ی واحد تخلیه کند.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. پیام‌ها را بشمارید

`count-messages` را تعریف کنید تا هر خط را از یک جریان ورودی بخواند و برگرداند که چند خط بوده است.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. آخرین تماس را بازتاب دهید

`echo-back` را تعریف کنید تا هر خط را بخواند و **آخرین خط را با حروف بزرگ** برگرداند، همان پاسخ استاندارد رادیویی «شما X گفتید».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. یک پیام را پخش کنید

`broadcast` را تعریف کنید تا پیامی را در یک نویسنده‌ی مشخص بنویسد و جریان را تخلیه کند تا بی‌درنگ فرستاده شود. چیزی برنمی‌گرداند.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. خروجی یک بلوک کد را ثبت کنید

`capture` را تعریف کنید تا یک بلوک کد را با یک `string-writer` تازه به‌عنوان خروجی محیطی اجرا کند و هر آنچه را که آن بلوک کد چاپ کرده است، برگرداند. بلوک کد هیچ آرگومانی نمی‌گیرد، فقط مثل همیشه در جریان محیطی می‌نویسد.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
