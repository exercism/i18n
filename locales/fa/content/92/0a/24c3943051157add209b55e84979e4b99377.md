# دستورالعمل‌ها

در این تمرین به مدیریت عملیات روزانه‌ی یک نانوایی کوچک با استفاده از ساختارهای کنترل جریان Cairo کمک می‌کنید.

## 1. محاسبه‌ی مبلغ کل سفارش

`calculate_total` را پیاده‌سازی کنید که هزینه‌ی یک سفارش را بر اساس نوع شیرینی و تعداد آن محاسبه می‌کند:

- کروسان: هر کدام ۳ سکه
- مافین: هر کدام ۲ سکه
- کوکی: هر کدام ۱ سکه

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. اعمال تخفیف‌های حجمی

`apply_discount` را پیاده‌سازی کنید که بر اساس مبلغ کل سفارش تخفیف اعمال می‌کند.
درصد تخفیف را روی مبلغ کل اعمال کنید و سپس آن را به نزدیک‌ترین عدد صحیح سکه گرد کنید (گرد کردن به پایین).

- سفارش‌های ۲۰ سکه و بیشتر: ۱۰٪ تخفیف
- سفارش‌های ۱۰ سکه و بیشتر: ۵٪ تخفیف
- سفارش‌های کمتر از ۱۰ سکه: بدون تخفیف

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. ساخت برنامه‌ی پخت

`baking_schedule` را پیاده‌سازی کنید که برنامه‌ی پخت روزانه را می‌سازد.
نانوایی در دسته‌های ۵ سفارشی در هر ساعت می‌پزد:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

برای حل کارآمد هر مسئله از ساختارهای کنترل جریان مناسب (`if`/`else`، `loop`) استفاده کنید.
