# پیوست دستورالعمل‌ها

## کد اولیه

فایل `src/TreeBuilding.hs` از قبل یک راه‌حل کارا دارد که همه‌ی تست‌ها را پاس می‌کند. این راه‌حل کند و سخت‌خوان است. وظیفه‌ی شما این است که آن را بدون شکستن تست‌ها بهتر کنید.

تابع `buildTree` وقتی رکوردها یک درخت معتبر تشکیل ندهند، مقدار `Nothing` را برمی‌گرداند.

## تغییر نحوه‌ی نمایش

تست‌ها هرگز از سازنده‌های `Tree` به‌طور مستقیم استفاده نمی‌کنند. در عوض، درخت‌های مورد انتظار را با این تابع می‌سازند:

```haskell
node :: Int -> [Tree] -> Tree
```

که در آن `node i children` گره‌ای با شناسه‌ی `i` و فرزندان داده‌شده است، به ترتیب صعودی شناسه.

این یعنی شما آزادید نحوه‌ی نمایش `Tree` را تغییر دهید، برای مثال به این شکل:

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

به شرطی که `Tree` هنوز نمونه‌های `Eq` و `Show` را داشته باشد و `node` معنای خود را حفظ کند.
اگر از کتابخانه‌ای مانند `containers` استفاده می‌کنید، یادتان باشد آن را به `dependencies` در `package.yaml` اضافه کنید.
