# دستورالعمل‌ها

شما به کار روی سیستم ORM (نگاشت شیء-رابطه‌ای) که در [exercise:csharp/object-relational-mapping]() معرفی شد، بازگشته‌اید.

تحلیل ما از نحوه‌ی استفاده از ORM نشان می‌دهد که ۹۵٪ تراکنش‌ها از درون یک متد فراخوانی‌کننده اجرا می‌شوند و تصمیم گرفته شده که مناسب‌تر است یک متد ORM واحد داشته باشیم که تراکنش را باز کند، بنویسد و ثبت کند.

پایگاه‌داده متدهای نمونه‌ی زیر را دارد:

- `Database.BeginTransaction()` یک تراکنش را روی پایگاه‌داده آغاز می‌کند.
- `Database.Write(string data)` داده را در جریان تراکنش روی پایگاه‌داده می‌نویسد. اگر داده‌ی نامعتبر دریافت کند، استثنا پرتاب می‌شود. اگر این متد بدون اینکه `BeginTransaction()` فراخوانی شده باشد صدا زده شود، استثنا پرتاب می‌شود. در صورت موفقیت، وضعیت داخلی پایگاه‌داده به `DataWritten` تغییر می‌کند.
- `Database.EndTransaction()` تراکنش را روی پایگاه‌داده ثبت می‌کند. اگر نتواند تراکنش را ببندد یا اگر `Database.BeginTransaction()` فراخوانی نشده باشد، ممکن است استثنا پرتاب کند.
- فراخوانی `Database.Dispose()` اگر در جریان یک تراکنش استثنا پرتاب شود، پایگاه‌داده را پاک‌سازی می‌کند. این کار وضعیت پایگاه‌داده را به `Closed` تغییر می‌دهد.

## 1. نوشتن در پایگاه‌داده

متد `Orm.Write()` را طوری پیاده‌سازی کنید که تراکنشی روی پایگاه‌داده آغاز کند، داده‌ی ورودی را بنویسد و تراکنش را ثبت کند. همه‌ی استثناها از جمله `InvalidOperationException` باید بدون ثبت لاگ یا هرگونه دخالت دیگری به فراخوان‌کننده منتقل شوند.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. نوشتن در پایگاه‌داده و بازگرداندن نشانه‌ای به فراخوان‌کننده از موفقیت یا عدم موفقیت نوشتن

چند ماه از معرفی `Orm.Write()` می‌گذرد و در تیم اختلاف نظر پیش آمده است. بسیاری از توسعه‌دهندگان ترجیح می‌دهند _ORM_ هنگام پرتاب استثناها خودش خطاها را مدیریت کند و فقط نشانه‌ای از موفقیت را به فراخوان‌کننده بازگرداند.

لطفاً متد `Orm.WriteSafely()` را طوری پیاده‌سازی کنید که تراکنشی روی پایگاه‌داده آغاز کند، داده‌ی ورودی را بنویسد و تراکنش را ثبت کند (مثل بالا). اگر _نوشتن_ موفق باشد، باید `true` و در غیر این صورت `false` را بازگرداند. سعی نکنید استثنا را لاگ کنید.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
