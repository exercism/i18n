# دستورالعمل‌ها

در این تمرین، باید چند قانون از بازی کلاسیک Pac-Man را به توابع Gleam ترجمه کنید.

چهار قانون برای ترجمه دارید که همه به حالت‌های بازی مربوط می‌شوند.

> نگران این نباشید که آرگومان‌ها چگونه به دست می‌آیند؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید.

## 1. تعریف کنید که آیا Pac-Man یک روح را می‌خورد

تابع `eat_ghost` را تعریف کنید که دو آرگومان می‌گیرد (_آیا Pac-Man قرص قدرت فعال دارد_ و _آیا Pac-Man با یک روح در تماس است_) و اگر Pac-Man بتواند آن روح را بخورد، یک مقدار منطقی برمی‌گرداند. تابع باید فقط در صورتی `True` را برگرداند که Pac-Man قرص قدرت فعال داشته باشد و با یک روح در تماس باشد.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. تعریف کنید که آیا Pac-Man امتیاز می‌گیرد

تابع `score` را تعریف کنید که دو آرگومان می‌گیرد (_آیا Pac-Man با یک قرص قدرت در تماس است_ و _آیا Pac-Man با یک نقطه در تماس است_) و اگر Pac-Man امتیاز گرفته باشد، یک مقدار منطقی برمی‌گرداند. تابع باید اگر Pac-Man با یک قرص قدرت یا یک نقطه در تماس باشد، `True` را برگرداند.

```gleam
score(True, True)
// -> True
```

## 3. تعریف کنید که آیا Pac-Man می‌بازد

تابع `lose` را تعریف کنید که دو آرگومان می‌گیرد (_آیا Pac-Man قرص قدرت فعال دارد_ و _آیا Pac-Man با یک روح در تماس است_) و اگر Pac-Man ببازد، یک مقدار منطقی برمی‌گرداند. تابع باید اگر Pac-Man با یک روح در تماس باشد و قرص قدرت فعالی نداشته باشد، `True` را برگرداند.

```gleam
lose(False, True)
// -> True
```

## 4. تعریف کنید که آیا Pac-Man برنده می‌شود

تابع `win` را تعریف کنید که سه آرگومان می‌گیرد (_آیا Pac-Man همه‌ی نقطه‌ها را خورده است_، _آیا Pac-Man قرص قدرت فعال دارد_ و _آیا Pac-Man با یک روح در تماس است_) و اگر Pac-Man برنده شود، یک مقدار منطقی برمی‌گرداند. تابع باید اگر Pac-Man همه‌ی نقطه‌ها را خورده باشد و بر اساس آرگومان‌های تعریف‌شده در بخش ۳ نباخته باشد، `True` را برگرداند.

```gleam
win(False, True, False)
// -> False
```
