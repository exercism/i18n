# مقدمه

## مجموعه

[`Set`][set-docs] یک مجموعه‌ی بدون ترتیب است که برخلاف `List` تضمین می‌شود هیچ مقدار تکراری نداشته باشد.

پارامتر نوع جنریکِ رابط `Set` نوع عناصری را مشخص می‌کند که در `Set` قرار می‌گیرند:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

توجه کنید که متد `Set.of()` یک نمونه‌ی `Set` [_غیرقابل تغییر_][unmodifiable-set-docs] می‌سازد.
اگر بخواهید متدهایی مانند `add` و `remove` را روی این نمونه فراخوانی کنید، در زمان اجرا یک استثنا رخ می‌دهد.

برای ساختن یک `Set` قابل تغییر، باید نمونه‌ای از کلاسی بسازید که رابط `Set` را پیاده‌سازی می‌کند.
پرکاربردترین کلاس توکاری که این رابط را پیاده‌سازی می‌کند، کلاس [`HashSet`][hashset-docs] است.

```java
Set<Integer> ints = new HashSet<>();
```

رابط `Set` از رابط‌های [`Collection`][collection-docs] و [`Iterable`][iterable-docs] ارث می‌برد و بنابراین متدهای زیادی را با انواع دیگر مجموعه‌ها به اشتراک می‌گذارد.
اما یک تفاوت قابل توجه با رابط `Collection` این است که متدهایی مانند `add` و `remove` یک `boolean` برمی‌گردانند (به‌جای `void`) که نشان می‌دهد آیا عنصر در لحظه‌ی فراخوانی آن متد در مجموعه وجود داشته است یا نه:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
