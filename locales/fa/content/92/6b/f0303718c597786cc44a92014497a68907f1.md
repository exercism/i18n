# راهنمایی‌ها

## 1. بررسی معتبر بودن دستور

- برای برگرداندن یک «مقدار منطقی»، از عبارت [test][regex-test] استفاده کنید.
- به یاد داشته باشید که می‌توانیم از آرگومان [flags][flags] برای قابلیت‌های بیشتری مثل بی‌تفاوتی نسبت به بزرگی و کوچکی حروف استفاده کنیم.

## 2. حذف ایموجی‌های رمزنگاری‌شده

- به لطف رمزنگاری مشترک هر ایموجی، می‌توانیم از `[0-9]` استفاده کنیم تا هر رقمی را بعد از کلمه‌ی `emoji` جست‌وجو کنیم.
- کاراکتر `+` با یک یا چند عنصر پشت‌سرهم مطابقت می‌کند.
- از متد [gsub][regex-gsub] استفاده کنید تا هر ایموجی را با یک رشته‌ی خالی جایگزین کنید.

## 3. بررسی معتبر بودن شماره‌ی تلفن

- این [مقاله][phone-validation] در توضیح روش‌های مختلف اعتبارسنجی شماره‌ی تلفن واقعاً خوب است.
- از فیلتر `test` استفاده کنید تا بررسی کنید شماره‌ی تلفن معتبر است یا نه.
- پاسخ نهایی را با یک عبارت `if-then-else` برگردانید.

## 4. گرفتن پیوند وب‌سایت

- هدف ما کلماتی است که با یک یا چند `.` به هم متصل شده‌اند.
- می‌توان از فیلتر [match][regex-match] همراه با پرچم `g` استفاده کرد.
- استفاده از فیلتر [scan][regex-scan] ممکن است راحت‌تر باشد.

## 5. سلام کردن به کاربر

- استفاده از [گروه‌های ثبت نامدار][named-capture] برای استفاده‌ی مجدد از متن مطابقت‌شده راحت است.
- فیلتر [capture][regex-capture] برای اشاره به گروه نامدار مناسب است.

## 6. تجزیه‌ی خیلی ساده‌ی CSV

- اینجا می‌خواهیم از [split][regex-split] استفاده کنیم چون جداکننده را می‌شناسیم.
- الگو عبارت است از «ویرگول و سپس صفر یا چند فضای خالی».
- باید از فیلتر `split` با **۲ آرگومان** استفاده کنیم؛ هیچ پرچمی لازم نیست مشخص شود.
