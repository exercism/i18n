# دستورالعمل‌ها

در این تمرین، یک سیستم کامپیوتری مبتنی بر پنجره را شبیه‌سازی می‌کنید.
چند پنجره می‌سازید که می‌توانند جابه‌جا شوند، اندازه‌شان تغییر کند و محتویاتشان را نمایش دهند.
تصویر زیر نمونه‌ای از مقدارهایی است که در ادامه با آن‌ها کار می‌کنید.

```
                  <--------------------- screenSize.width --------------------->

       ^          ╔════════════════════════════════════════════════════════════╗
       |          ║                                                            ║
       |          ║          position.x,_                                      ║
       |          ║          position.y  \                                     ║
       |          ║                       \<----- size.width ----->            ║
       |          ║                 ^      *──────────────────────┐            ║
       |          ║                 |      │        title         │            ║
       |          ║                 |      ├──────────────────────┤            ║
screenSize.height ║                 |      │                      │            ║
       |          ║            size.height │                      │            ║
       |          ║                 |      │       contents       │            ║
       |          ║                 |      │                      │            ║
       |          ║                 |      │                      │            ║
       |          ║                 v      └──────────────────────┘            ║
       |          ║                                                            ║
       |          ║                                                            ║
       v          ╚════════════════════════════════════════════════════════════╝
```

## 1. تعریف یک ساختار `Size`

ساختاری به اسم `Size` تعریف کنید که دو ویژگی `Int` دارد، `width` و `height`، که به ترتیب عرض و ارتفاع فعلی پنجره را نگه می‌دارند.
عرض و ارتفاع اولیه باید به ترتیب 80 و 60 باشند.
متدی به اسم `resize(newWidth:newHeight:)` هم اضافه کنید که پارامترهای عرض و ارتفاع جدید را می‌گیرد و ویژگی‌ها را طوری تغییر می‌دهد که اندازه‌ی جدید را نشان دهند.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. تعریف یک ساختار `Position`

ساختاری به اسم `Position` تعریف کنید که دو ویژگی `Int` دارد، `x` و `y`، که به ترتیب موقعیت افقی و عمودی فعلی گوشه‌ی بالا-چپ پنجره را نگه می‌دارند.
مقدارهای اولیه‌ی `x` و `y` هر کدام باید 0 باشد. موقعیت (0, 0) گوشه‌ی بالا-چپ صفحه است؛ هر چه به سمت راست می‌روید مقدارهای `x` بزرگ‌تر می‌شوند و هر چه به سمت پایین می‌روید مقدارهای `y` بزرگ‌تر می‌شوند.

متدی به اسم `moveTo(newX:newY:)` هم اضافه کنید که پارامترهای x و y جدید را می‌گیرد و ویژگی‌ها را طوری تغییر می‌دهد که موقعیت جدید را نشان دهند.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. تعریف یک کلاس `Window`

یک کلاس پنجره تعریف کنید که ویژگی‌های زیر را دارد:

- `title` : `String`، مقدار اولیه "New Window" است
- `screenSize` : `Size`، مقداری ثابت که `width` آن 800 و `height` آن 600 است
- `size` : `Size`، مقدار اولیه‌اش مقدار پیش‌فرض ساختار `Size` است
- `position` : `Position`، مقدار اولیه‌اش مقدار پیش‌فرض ساختار `Position` است
- `contents` : `String?`، مقدار اولیه‌اش `nil` است

برای کلاس یک مقداردهنده‌ی اولیه‌ی خالی هم تعریف کنید.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. افزودن متدی برای تغییر اندازه‌ی پنجره‌ها

- `resize(to:)` : `(Size) -> ()` - این متد یک ساختار `Size` را به عنوان ورودی می‌گیرد و تلاش می‌کند اندازه‌ی پنجره را به اندازه‌ی مشخص‌شده تغییر دهد. با این حال، اندازه‌ی جدید نمی‌تواند از مرزهای مشخصی فراتر برود.
- کمترین ارتفاع یا عرض مجاز 1 است.
  ارتفاع یا عرض درخواستی کمتر از 1 به 1 محدود می‌شود.
- بیشترین ارتفاع و عرض به موقعیت فعلی پنجره بستگی دارد؛ لبه‌های پنجره نمی‌توانند از لبه‌های صفحه فراتر بروند.
  مقدارهای بزرگ‌تر از این مرزها به بزرگ‌ترین اندازه‌ای که می‌توانند داشته باشند محدود می‌شوند.
  برای نمونه، اگر موقعیت پنجره در `x` = 400، `y` = 300 باشد و درخواست تغییر اندازه به `height` = 400، `width` = 300 داده شود، پنجره به `height` = 300، `width` = 300 تغییر اندازه داده می‌شود، چون صفحه در جهت `y` به‌قدر کافی بزرگ نیست که این درخواست را کامل در خود جای دهد.

## 5. افزودن متدی برای جابه‌جایی پنجره‌ها

- `move(to:)` : `(Position) -> ()` - این متد شبیه `resize(to:)` است، اما به جای اندازه، _موقعیت_ پنجره را به مقدار درخواستی تنظیم می‌کند. مثل `resize`، موقعیت جدید هم نمی‌تواند از حدهای مشخصی فراتر برود.
- کمترین موقعیت برای هر دو `x` و `y` مقدار 0 است.
- بیشترین موقعیت در هر جهت به اندازه‌ی فعلی پنجره بستگی دارد؛ لبه‌ها نمی‌توانند از لبه‌های صفحه فراتر بروند.
       مقدارهای بزرگ‌تر از این مرزها به بزرگ‌ترین اندازه‌ای که می‌توانند داشته باشند محدود می‌شوند. برای نمونه، اگر اندازه‌ی پنجره در `x` = 250، `y` = 100 باشد و درخواست جابه‌جایی به `x` = 600، `y` = 200 داده شود، پنجره به `x` = 550، `y` = 200 جابه‌جا می‌شود، چون صفحه در جهت `x` به‌قدر کافی بزرگ نیست که این درخواست را کامل در خود جای دهد.

## 6. افزودن متدهایی برای به‌روزرسانی متن پنجره و نمایش اطلاعات پنجره

- `update(title:)` : `(String) -> ()` - این متد ویژگی `title` را به مقدار رشته‌ای که به آن پاس داده شده تنظیم می‌کند.
- `update(text:)` : `(String?) -> ()` - این متد ویژگی `contents` را به مقدار رشته‌ی اختیاری که به آن پاس داده شده تنظیم می‌کند.
- `display()` : `() -> String` - این متد رشته‌ای برمی‌گرداند که وضعیت فعلی پنجره را توصیف می‌کند. برای نمونه، اگر `title` پنجره "My First Window" باشد و `position` آن `x` = 10، `y` = 100؛ `size` آن `width` = 200، `height` = 150؛ و `contents` آن "I 😍 my window" باشد، باید رشته‌ی زیر را برگرداند: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - اگر `contents` برابر `nil` باشد، آخرین خط باید "[This window intentionally left blank]" باشد

## 7. ساخت یک مقداردهنده‌ی اولیه برای کلاس `Window`

سیستم پنجره باید یک مقداردهنده‌ی اولیه داشته باشد تا بتوان پنجره را با ورودی‌های سفارشی ساخت.
یک مقداردهنده‌ی اولیه‌ی **دیگر** برای کلاس `Window` بسازید.
این مقداردهنده‌ی اولیه باید پارامترهای زیر را بگیرد: `title`، `contents` و دو پارامتر اختیاری `size` و `position`.
پارامترهای `size` و `position` باید به‌طور پیش‌فرض برابر مقدارهای پیش‌فرض ساختارهای `Size` و `Position` باشند.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
