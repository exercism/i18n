# مقدمه

«کنترل جریان» در Cairo به شما امکان می‌دهد مسیر اجرای برنامه‌هایتان را بر اساس شرط‌ها و تکرار کنترل کنید.

## اجرای شرطی

از عبارت‌های `if` برای اجرای کد بر اساس شرط‌ها استفاده کنید:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` یک عبارت است، بنابراین می‌تواند مقدار برگرداند:

```rust
let result = if condition { 5 } else { 10 };
```

## حلقه

از `loop` برای تکرار کد استفاده کنید.
یک حلقه بی‌پایان اجرا می‌شود مگر اینکه آن را متوقف کنید؛ برای خروج از حلقه وقتی شرطی برقرار می‌شود، از `break` استفاده کنید.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

حلقه می‌تواند با استفاده از `break` مقدار برگرداند:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

از `continue` برای پرش به تکرار بعدی استفاده کنید:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
