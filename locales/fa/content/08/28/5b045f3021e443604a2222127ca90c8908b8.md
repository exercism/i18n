# درباره

در Go می‌توانیم مقادیر را با استفاده از عملگرهای تساوی و ترتیب مقایسه کنیم.
۶ تا از این عملگرها را داریم:

| مقایسه           | عملگر     |
| ------------------| --------- |
| برابر             | `==`      |
| نابرابر           | `!=`      |
| کوچک‌تر           | `<`       |
| کوچک‌تر یا برابر  | `<=`      |
| بزرگ‌تر           | `>`       |
| بزرگ‌تر یا برابر  | `>=`      |

نتیجه‌ی یک مقایسه همیشه یک مقدار «منطقی» است:

```go
a := 3

a != 4 // true
a > 5  // false
```

## عملگرهای تساوی

عملگرهای تساوی `==` و `!=` به‌ترتیب بررسی می‌کنند که آیا یک مقدار با مقدار دیگری برابر است یا نه.
می‌توانیم از عملگرهای تساوی برای بیشتر انواع داده در Go استفاده کنیم.
در ادامه چند مثال رایج را می‌بینید:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## عملگرهای ترتیب

عملگرهای ترتیب بررسی می‌کنند که یک مقدار از مقدار دیگر بزرگ‌تر است (`>`)، بزرگ‌تر یا برابر آن (`>=`)، کوچک‌تر (`<`) یا کوچک‌تر یا برابر آن (`<=`) است.
این نوع مقایسه برای اعداد، بایت‌ها، رون‌ها و رشته‌ها در دسترس است.
هنگام مقایسه‌ی رشته‌ها، ترتیب واژه‌نامه‌ای (که با نام ترتیب لغوی هم شناخته می‌شود) رعایت می‌شود.

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
