# درباره

کار با متن یکی از کارهای رایج در برنامه‌نویسی است.
Swift به همراه Foundation framework، متدهای کاربردی و ویژگی‌های بسیاری برای بررسی، تبدیل و دستکاری رشته‌ها در اختیار شما می‌گذارد.

## تقسیم رشته‌ها با `components(separatedBy:)`

برای تقسیم یک رشته به آرایه‌ای از زیررشته‌ها بر اساس یک جداکننده، از `components(separatedBy:)` استفاده کنید (برای این کار باید Foundation را `import` کنید):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## بررسی پیشوندها و پسوندها با `hasPrefix(_:)` و `hasSuffix(_:)`

برای بررسی اینکه آیا یک رشته با دنباله‌ی مشخصی از کاراکترها شروع می‌شود یا به آن ختم می‌شود، از `hasPrefix(_:)` و `hasSuffix(_:)` استفاده کنید:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## تغییر بزرگی و کوچکی حروف

می‌توانید حروف یک رشته را با این متدها و ویژگی‌های استاندارد به بزرگ یا کوچک تغییر دهید:

- `lowercased()`: نسخه‌ای از رشته با حروف کوچک برمی‌گرداند.
- `uppercased()`: نسخه‌ای از رشته با حروف بزرگ برمی‌گرداند.
- `capitalized`: نسخه‌ای برمی‌گرداند که در آن حرف اول هر کلمه بزرگ نوشته شده است (از Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## جایگزینی زیررشته‌ها با `replacingOccurrences(of:with:)`

برای جایگزینی همه‌ی رخدادهای یک زیررشته‌ی هدف با رشته‌ای دیگر، از `replacingOccurrences(of:with:)` استفاده کنید (از Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## پیوستن رشته‌ها با `joined(separator:)`

متد `joined(separator:)` به مجموعه‌هایی از رشته‌ها مثل `[String]` تعلق دارد.
این متد عنصرها را با یک جداکننده به هم می‌پیوندد و به یک رشته‌ی واحد تبدیل می‌کند:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
