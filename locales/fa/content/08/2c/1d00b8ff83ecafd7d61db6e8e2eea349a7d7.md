# دستورالعمل‌ها

دوستتان همین حالا پیامی با یک راز مهم برایتان فرستاده است.
برای اینکه خواندنش برای دیگران آسان نباشد، پیام با انجام زنجیره‌ای از دستکاری‌های بیتی رمزگذاری شده است.
شما باید توابعی بنویسید که به رمزگشایی پیام کمک کنند.

## 1. جابه‌جا کردن بیت‌ها به عقب

نخستین گام در رمزگشایی پیام این است که جابه‌جایی انجام‌شده در فرایند رمزگذاری را با جابه‌جا کردن بیت‌ها به سمت راست خنثی کنید.
در ادامه‌ی فرایند رمزگشایی گام‌های دیگری هم هست که فرض می‌کند از سمت چپ صفر درج می‌شود.

تابع `shiftBack` را پیاده‌سازی کنید که یک مقدار و تعداد خانه‌های جابه‌جایی را می‌گیرد و جابه‌جایی را انجام می‌دهد.

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. تنظیم برخی بیت‌ها

در گام بعد، چند بیت باید برابر ۱ شوند.

تابع `setBits` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد و نتیجه‌ی یک کردن بیت‌های مقدار را برمی‌گرداند.
هر بیتی از مقدار که بیت متناظرش در ماسک هم ۱ است باید ۱ شود.
بقیه‌ی بیت‌ها باید بدون تغییر بمانند.

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. وارونه کردن بیت‌های مشخص

در هنگام رمزگذاری، برخی بیت‌ها وارونه می‌شوند.
برای رمزگشایی پیام باید دوباره وارونه شوند.

تابع `flipBits` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد.
ماسک نشان می‌دهد کدام بیت‌های مقدار باید وارونه شوند.
اگر بیتی در ماسک ۱ باشد، همان بیت در مقدار وارونه می‌شود.
بقیه‌ی بیت‌ها بدون تغییر می‌مانند.

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. پاک کردن بیت‌های مشخص

در پایان هم بیت‌های مشخصی هستند که همیشه به ۰ رمزگشایی می‌شوند.

تابع `clearBits` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد.
هر بیتی در `value` که بیت متناظرش در ماسک ۱ است باید ۰ شود.
بقیه‌ی بیت‌ها باید بدون تغییر بمانند.

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
