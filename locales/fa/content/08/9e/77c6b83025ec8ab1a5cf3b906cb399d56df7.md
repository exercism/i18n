# درباره‌ی مبانی

مفهوم مبانی، [Go](https://golang.org) را به‌عنوان یک زبان برنامه‌نویسی کامپایل‌شده با نوع‌دهی ایستا معرفی کرد.
به این زبان اغلب Golang گفته می‌شود، چون دامنه‌ی پیشینش golang.org بود؛ اما اسم درستش Go است.

مفهوم مبانی سه ویژگی اصلی زبان را معرفی می‌کند: «بسته»، «تابع» و «متغیر».

## بسته

برنامه‌های Go در بسته‌ها سازمان‌دهی می‌شوند.
یک بسته مجموعه‌ای از فایل‌های منبع است که در یک پوشه قرار دارند.
همه‌ی فایل‌های منبع در یک پوشه باید اسم بسته‌ی یکسانی داشته باشند.
مرسوم است که اسم بسته، آخرین پوشه در مسیر `import` باشد.
برای مثال، فایل‌های [بسته‌ی `math/rand`](https://golang.org/src/math/rand/) با دستور `package rand` شروع می‌شوند.
وقتی بسته‌ای `import` می‌شود، فقط موجودیت‌هایی (توابع، نوع‌ها، متغیرها، ثابت‌ها) که اسمشان با حرف بزرگ شروع می‌شود، قابل استفاده یا دسترسی هستند.
سبک توصیه‌شده در Go این است که شناسه‌ها با `camelCase` نوشته شوند، جز آن‌هایی که قرار است در میان بسته‌ها قابل دسترسی باشند و باید با `PascalCase` نوشته شوند.

```go
package lasagna
```

## متغیر

Go به‌صورت ایستا نوع‌دار است، یعنی همه‌ی متغیرها باید در زمان کامپایل [نوعی تعریف‌شده داشته باشند](https://en.wikipedia.org/wiki/Type_system).

می‌توان متغیرها را با مشخص کردن صریح نوع تعریف کرد:

```go
var explicit int // Explicitly typed
```

همچنین می‌توانید از یک مقدار اولیه استفاده کنید؛ کامپایلر نوع متغیر را مطابق با نوع آن مقدار اولیه تعیین می‌کند.

```go
implicit := 10   // Implicitly typed as an int
```

پس از اعلان، می‌توان با عملگر `=` به متغیرها مقدار اختصاص داد.
پس از اعلان، نوع یک متغیر هرگز نمی‌تواند تغییر کند.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## ثابت

ثابت‌ها هم مانند متغیرها نگه‌دارنده‌ی یک داده هستند، اما مقدارشان نمی‌تواند در طول اجرای برنامه تغییر کند.

ثابت‌ها با کلیدواژه‌ی `const` تعریف می‌شوند و می‌توانند عدد، نویسه، رشته یا مقدار منطقی باشند:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## تابع

توابع Go صفر یا چند پارامتر می‌پذیرند.
پارامترها باید صریحاً نوع‌دار باشند؛ استنتاج نوع وجود ندارد.

مقدارها با کلیدواژه‌ی `return` از توابع برگردانده می‌شوند.

یک تابع با مشخص کردن اسم تابع و فرستادن آرگومان برای هر یک از پارامترهای آن فراخوانی می‌شود.

توجه کنید که Go از دو نوع کامنت پشتیبانی می‌کند.
کامنت‌های تک‌خطی با `//` شروع می‌شوند و کامنت‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
