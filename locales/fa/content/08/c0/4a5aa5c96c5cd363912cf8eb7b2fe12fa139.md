# مقدمه

سازه‌ی اصلی شیءگرا در Java، _کلاس_ است که ترکیبی از داده (_فیلد_) و رفتار (_متد_) است. به فیلدها و متدهای یک کلاس، _اعضای_ آن می‌گویند.

دسترسی به اعضا را می‌توان با اصلاح‌کننده‌های دسترسی کنترل کرد که دو مورد از رایج‌ترین آن‌ها این‌ها هستند:

- `public`: هر کدی می‌تواند به این عضو دسترسی داشته باشد (بدون محدودیت).
- `private`: فقط کدی می‌تواند به این عضو دسترسی داشته باشد که در همان کلاس است.

می‌توانید به کلاس به چشم قالبی برای ساختن نمونه‌هایی از آن نگاه کنید. برای ساختن نمونه‌ای از یک کلاس (که به آن _شیء_ هم می‌گویند)، از کلیدواژه‌ی `new` استفاده می‌شود:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

فیلدها یک نوع و یک اسم دارند (که با camelCase تعریف می‌شود) و می‌توانند هر جایی از یک کلاس تعریف شوند (طبق قرارداد با PascalCase نوشته می‌شوند):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

می‌توانید به‌صورت اختیاری یک مقدار اولیه به یک فیلد نسبت دهید. اگر فیلدی مقدار اولیه‌ای را _مشخص نکند_، به مقدار پیش‌فرض نوع خودش تنظیم می‌شود. می‌توان مقادیر فیلدهای یک نمونه را با نشانه‌گذاری نقطه‌ای خواند و به‌روزرسانی کرد.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

فیلدهای خصوصی معمولاً به‌عنوان اثر جانبی فراخوانی یک متد به‌روزرسانی می‌شوند. چنین متدهایی معمولاً مقداری برنمی‌گردانند و در این حالت نوع بازگشتی باید `void` باشد:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
