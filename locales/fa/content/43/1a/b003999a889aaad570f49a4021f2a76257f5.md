# تست

اگر فایل اجرایی 8th در `PATH` شما قرار دارد، این دستور را وارد کنید:

```bash
8th -f test.8th
```

اگر فایل اجرایی 8th در `PATH` نیست، در ویندوز وارد کنید:

```cmd
\path\to\8th -f test.8th
```

در لینوکس یا macOS:

```bash
/path/to/8th -f test.8th
```

## تست کردن در REPL

‏8th را اجرا کنید و `test-words.8th` را بارگذاری کنید:

```sh
8th -f test-words.8th
```

با این کار یک نشست CLI شروع می‌شود که در آن، پس از نوشتن مقداری کد در فایل راه‌حل خود، می‌توانید آن را در REPL بارگذاری کنید.
برای نمونه، برای تمرین «word-count» این را وارد می‌کنید:

```8th
"word-count.8th" f:include
```

و می‌توانید تست‌ها را با این دستور اجرا کنید:

```sh
"word-count-tests.8th" f:include
```

یا می‌توانید یک تست را از آن فایل کپی و پیست کنید یا تست خودتان را بنویسید.

## تست‌های نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی این که همه‌ی تست‌های آن قبول شوند.
به‌طور پیش‌فرض، وقتی تست‌ها را اجرا می‌کنید، فقط یک تست (اولین تست) اجرا می‌شود.
این کار عمدی است تا بتوانید فقط روی قبول شدن همان یک تست تمرکز کنید.
وقتی آن تست قبول شد، می‌توانید با انتقال واژه‌ی `SKIP-REST-OF-TESTS` به بعد از آن، تست بعدی را فعال کنید.

## لغو نادیده گرفتن تست‌ها

برای اجرای همه‌ی تست‌ها، از جمله تست‌های بعد از واژه‌ی `SKIP-REST-OF-TESTS`، می‌توانید متغیر محیطی `RUN_ALL_TESTS` را روی مقدار `true` تنظیم کنید.
یک راه برای تنظیم آن فقط در طول اجرای تست‌ها این است (در macOS و Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
