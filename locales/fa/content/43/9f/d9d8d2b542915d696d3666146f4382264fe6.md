# راهنمایی‌ها

## 1. ساخت یک تخته‌ی امتیاز جدید

- با استفاده از «آکولاد» یک «شیء» جدید بسازید.
- کلید را به‌صورت رشته بنویسید تا کلید بتواند فاصله داشته باشد.
- کلید و مقدار را با دو نقطه از هم جدا کنید.

## 2. افزودن بازیکن‌ها به تخته‌ی امتیاز

- از نشانه‌گذاری براکت استفاده کنید تا کلیدی اضافه کنید که اسمش در یک متغیر (آرگومان) ذخیره شده است.
- از عملگر انتساب (`=`) استفاده کنید تا مقداری برای کلید جدید تعیین کنید.
- بعد از اینکه بازیکن را اضافه کردید، پارامتر تخته‌ی امتیاز را برگردانید.

## 3. حذف بازیکن‌ها از تخته‌ی امتیاز

- از [عملگر delete][mdn-delete] استفاده کنید.
- به کلید همان‌طور که در تمرین قبلی انجام دادید ارجاع دهید (نشانه‌گذاری براکت).

## 4. افزایش امتیاز یک بازیکن

- ابتدا به این فکر کنید که مقدار جدیدی را که می‌خواهید انتساب دهید چطور بیان کنید.
- سپس مانند تمرین ۲ از عملگر انتساب استفاده کنید تا آن مقدار جدید را تعیین کنید.
- اگر تا حالا این کار را نکرده‌اید، می‌توانید از [عملگر انتساب کوتاه][mdn-shorthand-assignment] `+=` استفاده کنید.

## 5. اعمال امتیازهای دوشنبه

- از حلقه‌ی `for...in` استفاده کنید تا همه‌ی کلیدهای شیء را پیمایش کنید.
- برای هر کلید، مقدار جدید را همان‌طور که در تمرین ۴ انجام دادید تعیین کنید.
