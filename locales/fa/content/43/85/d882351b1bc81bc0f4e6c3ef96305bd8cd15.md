# مقدمه

«متدهای الحاقی» امکان می‌دهند بدون ساختن یک نوع مشتق‌شده‌ی جدید، بدون کامپایل مجدد یا تغییر دادن خود نوع اصلی، به انواع موجود متد اضافه کنید. این متدها به شکل متدهای استاتیک تعریف می‌شوند، اما با همان نحوه‌ی نگارشی فراخوانی می‌شوند که برای فراخوانی متدهای نمونه‌ای به کار می‌رود. پیش از اولین پارامتر آن، اصلاح‌کننده‌ی `this` می‌آید که مشخص می‌کند متد روی کدام نوع کار می‌کند. این متدها در سطح فضای نام به محدوده وارد می‌شوند.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
