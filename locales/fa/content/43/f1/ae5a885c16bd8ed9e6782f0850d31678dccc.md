# دستورالعمل‌ها

در این تمرین، روشی را پیاده‌سازی می‌کنید که امتیازهای بالای محبوب‌ترین بازی در سالن بازی‌های آرکید محله‌تان را ثبت کند.

شما باید ۷ تابع پیاده‌سازی کنید که همه به برگرداندن و دستکاری یک «دیکشنری» از داده‌های امتیازهای بالا مربوط می‌شوند.

## 1. یک دیکشنری جدید امتیاز بالا تعریف کنید

تابعی به نام `newScoreBoard()` ایجاد کنید که هیچ پارامتری نمی‌گیرد و یک دیکشنری جدید امتیاز بالا برمی‌گرداند که برای کلیدها از مقادیری از نوع `String` و به عنوان مقدارها از مقادیری از نوع `Int` استفاده می‌کند.

## 2. بازیکن‌ها را به دیکشنری امتیاز بالا اضافه کنید

برای افزودن بازیکن به دیکشنری امتیاز بالا، تابع `addPlayer(_:_:_:)` را تعریف کنید. این تابع ۳ پارامتر می‌گیرد:

- پارامتر اول دیکشنری امتیازها است. 
    این باید یک پارامتر ورودی-خروجی باشد.
- پارامتر دوم اسم بازیکن به صورت یک رشته است.
- پارامتر سوم امتیاز به صورت یک عدد صحیح است. 
    این پارامتر اختیاری است؛ آن را با مقدار پیش‌فرض ۰ پیاده‌سازی کنید.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. بازیکن‌ها را از دیکشنری امتیازها حذف کنید

برای حذف بازیکن از دیکشنری امتیاز بالا، `removePlayer(_:_:)` را تعریف کنید. این تابع ۲ پارامتر می‌گیرد:

- پارامتر اول دیکشنری امتیازها است. 
    این باید یک پارامتر ورودی-خروجی باشد.
- پارامتر دوم اسم بازیکن به صورت یک رشته است.

این تابع باید بازیکن را، در صورتی که در دیکشنری باشد، از آن حذف کند و در غیر این صورت کاری انجام ندهد.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. امتیاز یک بازیکن را بازنشانی کنید

برای بازنشانی امتیاز یک بازیکن، `resetPlayer(_:_:)` را تعریف کنید. این تابع ۲ پارامتر می‌گیرد:

- پارامتر اول دیکشنری امتیازها است.
    این باید یک پارامتر ورودی-خروجی باشد.
- پارامتر دوم اسم بازیکن به صورت یک رشته است که می‌خواهید امتیازش را بازنشانی کنید.

این تابع امتیاز بازیکن را روی ۰ تنظیم می‌کند. 
اگر بازیکن در دیکشنری نباشد، نباید اتفاقی بیفتد.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. امتیاز یک بازیکن را به‌روزرسانی کنید

برای به‌روزرسانی امتیاز یک بازیکن با افزودن به امتیاز قبلی، `updateScore` را تعریف کنید. این تابع ۳ پارامتر می‌گیرد:

- پارامتر اول دیکشنری امتیازها است. این باید یک پارامتر ورودی-خروجی باشد.
- پارامتر دوم اسم بازیکن به صورت یک رشته است که می‌خواهید امتیازش را به‌روزرسانی کنید.
- پارامتر سوم امتیازی است که می‌خواهید به امتیاز بالای ذخیره‌شده **اضافه** کنید.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. دریافت فهرستی از بازیکن‌ها به همراه امتیازها، مرتب‌شده بر اساس اسم بازیکن

تابع `orderByPlayers` را تعریف کنید که ۱ پارامتر می‌گیرد:

- پارامتر اول دیکشنری امتیازها است.

این تابع یک آرایه از تاپل‌های `(String, Int)` را برمی‌گرداند که همان بازیکن‌ها و امتیازهای بالایشان هستند و بر اساس اسم بازیکن به ترتیب صعودی مرتب شده‌اند.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. دریافت فهرستی از بازیکن‌ها، مرتب‌شده بر اساس امتیاز بازیکن به ترتیب نزولی

برای دریافت فهرستی از بازیکن‌ها که بر اساس امتیازها به ترتیب نزولی مرتب شده‌اند، `orderByScores` را تعریف کنید که ۱ پارامتر می‌گیرد:

- پارامتر اول دیکشنری امتیازها است.

این تابع یک آرایه از تاپل‌های `(String, Int)` را برمی‌گرداند که همان بازیکن‌ها و امتیازهای بالایشان هستند و بر اساس امتیاز بازیکن به ترتیب نزولی مرتب شده‌اند.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
