# مقدمه

[پارامترهای متغیر][variadic-parameters] به یک تابع این امکان را می‌دهند که صفر یا چند مقدار از یک نوع مشخص را برای یک پارامتر واحد بپذیرد.
شما یک پارامتر متغیر را با افزودن سه نقطه (`...`) به حاشیه‌نویسی نوع پارامتر تعریف می‌کنید.

درون بدنه‌ی تابع، Swift این مقادیر را به‌صورت یک آرایه از نوع مشخص در دسترس قرار می‌دهد:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
اگر تابعی پارامترهای دیگری بعد از یک پارامتر متغیر داشته باشد، نخستین پارامتری که پس از پارامتر متغیر می‌آید **باید** برچسب آرگومان صریح داشته باشد تا Swift بداند فهرست آرگومان‌های متغیر کجا پایان می‌یابد.
~~~~
