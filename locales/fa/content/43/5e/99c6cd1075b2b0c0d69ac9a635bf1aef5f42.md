# اشاره‌گرهای هوشمند

اشاره‌گرهای هوشمند در Cairo ابزاری قدرتمند هستند که مدیریت ایمن و کارآمد حافظه را فراهم می‌کنند.

اشاره‌گر هوشمند یک ساختمان داده است که مانند یک اشاره‌گر معمولی عمل می‌کند، اما ویژگی‌های ایمنی افزوده‌ای دارد تا از مشکلات رایج مدیریت حافظه، مثل ارجاع‌زدایی از اشاره‌گرهای `null` یا دسترسی به حافظه‌ی مقداردهی‌نشده، جلوگیری کند.

## اشاره‌گر هوشمند چیست؟

به طور کلی، اشاره‌گر یک متغیر است که یک نشانی حافظه را ذخیره می‌کند و معمولاً به مقداری اشاره دارد که در آن مکان ذخیره شده است.

اما اشاره‌گرهای خام می‌توانند خطرناک باشند: اگر اشاره‌گر به حافظه‌ی معتبری اشاره نکند یا به‌شکل نادرستی ارجاع‌زدایی شود، می‌تواند به از کار افتادن برنامه یا رفتار غیرقابل‌پیش‌بینی منجر شود.

اشاره‌گرهای هوشمند این مشکل را با اعمال قواعد سخت‌گیرانه بر مدیریت حافظه حل می‌کنند و تضمین می‌کنند که به حافظه به شکلی ایمن و کنترل‌شده دسترسی پیدا شود.

Cairo، مانند بسیاری از زبان‌های مدرن مثل Rust، از اشاره‌گرهای هوشمند استفاده می‌کند تا از دسترسی ناایمن به حافظه جلوگیری کند.

اشاره‌گر هوشمند در Cairo نه تنها یک نشانی حافظه را ذخیره می‌کند، بلکه مالکیت را هم ردیابی می‌کند و ایمنی حافظه را تضمین می‌کند.

## انواع اشاره‌گرهای هوشمند در Cairo

Cairo چندین نوع اشاره‌گر هوشمند ارائه می‌دهد، از جمله `Box<T>` و `Nullable<T>` که هر کدام هدف متفاوتی را دنبال می‌کنند.

بیایید نگاهی دقیق‌تر بیندازیم به اینکه این انواع چگونه کار می‌کنند و چه زمانی ممکن است از آن‌ها استفاده کنید.

### `Box<T>`

نوع `Box<T>` اشاره‌گر هوشمند اصلی در Cairo است.

این نوع به شما اجازه می‌دهد داده را در بخش ویژه‌ای از حافظه به اسم «بخش جعبه‌ای» ذخیره کنید. `Box<T>` اشاره‌گری است که به این بخش اشاره می‌کند و وقتی یک جعبه می‌سازید، فضایی را برای داده در این بخش تخصیص می‌دهید.

جعبه‌ها در موقعیت‌هایی ایده‌آل هستند که:

- باید مقداری از نوعی را ذخیره کنید که اندازه‌اش در زمان کامپایل قابل تعیین نیست.
- مقدار زیادی داده دارید و می‌خواهید مالکیت آن را بدون کپی کردن منتقل کنید.

با استفاده از یک جعبه، می‌توانید ساختمان‌های داده‌ی بزرگ را کارآمدتر ذخیره کنید.

وقتی یک `Box<T>` را به یک تابع می‌فرستید، فقط اشاره‌گر منتقل می‌شود و نیازی به کپی کردن همه‌ی داده نیست، که کارایی را بهبود می‌بخشد، به‌ویژه در ساختارهای بزرگ.

### `Nullable<T>`

نوع `Nullable<T>` یکی دیگر از اشاره‌گرهای هوشمند مهم در Cairo است.

می‌تواند یا به مقداری معتبر از نوع `T` اشاره کند یا اگر مقداری وجود نداشته باشد، `null` باشد.

این نوع در مواردی مفید است که باید مقادیری را ذخیره کنید که ممکن است همیشه وجود نداشته باشند، مثل یک دیکشنری که می‌تواند عناصر اختیاری داشته باشد.

در Cairo، نوع `Nullable<T>` معمولاً در دیکشنری‌ها استفاده می‌شود تا مواردی را مدیریت کند که هیچ مقدار پیش‌فرضی نمی‌توان اعمال کرد.

این نوع به شما امکان می‌دهد مقادیر را به‌صورت شرطی ذخیره کنید و مدیریت ایمن نبودِ داده را آسان‌تر می‌کند.

## ایمنی حافظه با اشاره‌گرهای هوشمند

یکی از مزایای اصلی استفاده از اشاره‌گرهای هوشمند این است که به تضمین ایمنی حافظه کمک می‌کنند.

Cairo با مدیریت مالکیت و قواعد دسترسی، از مشکلات رایجی مثل ارجاع‌زدایی از اشاره‌گرهای `null` یا معلق جلوگیری می‌کند.

اشاره‌گرهای هوشمند ردیابی می‌کنند که چه زمانی دیگر به داده نیازی نیست و می‌توانند وقتی از دامنه خارج می‌شود، حافظه را به‌طور خودکار آزاد کنند، که خطر نشت حافظه را کاهش می‌دهد.

### مثال: استفاده از `Box<T>` برای انواع بازگشتی

یک چالش رایج در بسیاری از زبان‌های برنامه‌نویسی، کار با انواع بازگشتی است.

انواع بازگشتی به انواعی اشاره دارند که ارجاع‌هایی به خودشان در بر می‌گیرند.

بدون مدیریت درست حافظه، تعریف یک نوع بازگشتی می‌تواند به مشکلاتی مثل بازگشت بی‌نهایت منجر شود.

در Cairo، `Box<T>` تعریف ایمن انواع بازگشتی را ممکن می‌کند.

برای نمونه، می‌توانید از `Box<T>` برای پیاده‌سازی یک درخت دودویی استفاده کنید، جایی که هر گره یک ارجاع به گره‌ی دیگری در بر دارد.

Cairo با ذخیره‌ی ارجاع‌ها در جعبه‌ها تضمین می‌کند که مصرف حافظه متناهی باشد و کامپایلر می‌تواند اندازه‌ی حافظه‌ی موردنیاز برای ساختار را تعیین کند.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### مزایای کارایی اشاره‌گرهای هوشمند

اشاره‌گرهای هوشمند کارایی برنامه‌های شما را هم بهبود می‌بخشند.

وقتی از `Box<T>` استفاده می‌کنید، فقط اشاره‌گر به داده جابه‌جا می‌شود، به جای اینکه کل ساختمان داده کپی شود.

این موضوع به‌ویژه هنگام کار با مجموعه‌داده‌های بزرگ مفید است، چون سربار عملیات حافظه را به‌طور چشمگیری کاهش می‌دهد.

در مثال زیر، داده با استفاده از یک `Box<T>` به‌صورت ارجاعی منتقل می‌شود تا هزینه‌ی کپی کردن کل ساختار از میان برود:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

در این مثال، `pass_pointer` به جای `Cart` یک `Box<Cart>` می‌گیرد، که مقدار حافظه‌ی کپی‌شده در طول فراخوانی تابع را کاهش می‌دهد.
