# نصب

## نصب موتور Godot

مسیر GDScript بر پایه‌ی [موتور Godot][godot-engine] ساخته شده است، که روی Windows، Linux، macOS و Android اجرا می‌شود.
فعلاً، اجراکننده‌ی تست برای [کار روی سیستم محلی][working-locally] به Linux نیاز دارد.
این مسیر به Godot نسخه‌ی ۴.۰ یا بالاتر نیاز دارد.

پس از کامل کردن نصب، می‌توانید با اجرای این دستور در یک ترمینال بررسی کنید که CLI با موفقیت نصب شده است یا نه:

```bash
godot --version
```

## نصب اجراکننده‌ی تست مسیر GDScript در Exercism

برای استفاده از اجراکننده‌ی تست، باید [Godot را به‌درستی نصب کرده باشید][installation].

برای ساخت و تست اسکریپت‌های GDScript در Exercism، Godot از طریق CLI در حالت «headless» اجرا می‌شود.
این دستورها در حال حاضر به Linux و bash نیاز دارند.

### مرحله ۱: نصب زیرساخت کلی اجراکننده‌ی تست

برای آماده‌سازی تست، [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] را کلون کنید و محتویات آن را به `/opt/test-runner/` منتقل کنید:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### مرحله ۲: دانلود اسکریپت اجراکننده‌ی تست برای یک تمرین

با فرض اینکه ابزار `exercism` را راه‌اندازی کرده‌اید و حداقل یک تمرین GDScript دانلود کرده‌اید، باید پوشه‌ای به اسم `gdscript` زیر فضای کاری شما ساخته باشد (همان‌طور که با اجرای `exercism configure` نشان داده می‌شود) که تمرین‌ها را در خود جای دهد.
[اجراکننده‌ی تست][test-local-gdscript-solution] را در این پوشه ذخیره کنید و فایل را اجراپذیر علامت بزنید.

## اجرای تست‌ها

وقتی مرحله‌های نصب انجام شد، باید بتوانید از هر پوشه‌ی تمرین (مثلاً `~/exercism/gdscript/two-fer`) شروع کنید و اسکریپت را (که یک سطح بالاتر، در `../` قرار دارد) اجرا کنید تا راه‌حل محلی خود را برای آن تمرین تست کنید:

```sh
../test-local-gdscript-solution.sh
```

## استفاده از یک IDE

برای برجسته‌سازی نحوه‌ی نگارش GDScript در ویرایشگری مانند [Visual Studio Code][vscode]، باید افزونه‌ای مثل [godot-tools][godot-tools] نصب باشد و یک سرور دیباگ هم در حال اجرا باشد.
Godot هر زمان که پروژه‌ای در ویرایشگر خودش باز باشد، این سرور دیباگ را به‌طور خودکار راه‌اندازی می‌کند و تا زمانی که پروژه یا خود Godot بسته شود، آن را در حال اجرا نگه می‌دارد.
