# دستورالعمل‌ها

یک مدرسه‌ی محلی نزدیک شما انجمن دانش‌آموزی بسیار فعالی دارد.
انجمن دانش‌آموزی توسط یک رئیس اداره می‌شود و هر ۲ سال یک‌بار برای انتخاب رئیس جدید انتخابات برگزار می‌شود.
در انتخابات امسال تصمیم گرفته شد که به یک سیستم دیجیتال جدید برای شمارش آرا نیاز است.

مدرسه برای ساخت این سیستم جدید به کمک شما نیاز دارد.

## 1. ساخت شمارنده‌ی آرا

یکی از نخستین مواردی که سیستم رأی‌گیری جدید به آن نیاز دارد، یک «شمارنده‌ی آرا» است.
این شمارنده راهی است برای پیگیری آرای یک نامزد خاص.

تابعی به اسم `new_vote_counter` بسازید که تعداد آرای اولیه‌ی یک نامزد را می‌پذیرد و تصویری از یک ساختار `VoteCounter` را برمی‌گرداند که با تعداد آرای اولیه‌ی داده‌شده مقداردهی اولیه شده است.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. گرفتن تعداد آرا از یک شمارنده

حالا راهی برای ساخت شمارنده‌های جدید دارید!
اما حالا متوجه می‌شوید که سیستم جدید به راهی هم برای گرفتن تعداد آرا از یک شمارنده نیاز خواهد داشت.

تابعی به اسم `vote_count` بسازید که یک شمارنده (`@VoteCounter`) را به عنوان ورودی می‌گیرد و تعداد آرا در شمارنده را برمی‌گرداند.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. افزایش آرای یک شمارنده

بالاخره وقت شمارش آرا رسید!
حالا به راهی برای افزایش آرای یک شمارنده نیاز دارید.

تابعی به اسم `increment_vote_count` بسازید که یک شمارنده (`@VoteCounter`) و تعدادی رأی را به عنوان ورودی می‌گیرد و شمارنده را به اندازه‌ی آن تعداد رأی افزایش می‌دهد.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. ساخت نتایج انتخابات

حالا که همه‌ی آرا شمرده شده‌اند، وقت آن است که اعلام نتیجه برای تمام مدرسه را آماده کنید.
برای این کار متوجه می‌شوید که داشتن فقط شمارنده برای آرا کافی نیست.
باید راهی باشد که تعداد آرا را به یک نامزد خاص مرتبط کند.

تابعی به اسم `new_election_result` بسازید که اسم یک نامزد و تعداد آرای او را می‌گیرد و یک نتیجه‌ی انتخابات جدید برمی‌گرداند.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

ساختار نتیجه‌ی انتخابات از قبل برای شما ساخته شده و به این صورت تعریف شده است:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. اعلام نتایج

وقت آن است که رئیس جدید را به مدرسه اعلام کنید!
رئیس جدید در تابلوهای پیام دیجیتال کوچکی که مدرسه دارد اعلام می‌شود.

پیام باید اسم رئیس جدید و آرای او را به این قالب نشان دهد: `<candidate_name> (<votes>)`.
این نمونه‌ای از چنین پیامی است: `"Peter (51)"`.

تابعی به اسم `display_result` بسازید که یک `@ElectionResult` را به عنوان ورودی می‌گیرد و یک `ByteArray` شامل پیامی که باید نمایش داده شود را برمی‌گرداند.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. بازشماری آرا

برای اطمینان از درستی نتایج نهایی، آرا بازشماری شدند.
در بازشماری مشخص شد که تعداد آرای برخی از نامزدها یک واحد اختلاف داشت.

تابعی به اسم `decrement_votes_of_candidate` بسازید که نتایج نهایی و اسم نامزدی را می‌گیرد که باید تعداد آرای او کاهش یابد.
نتایج نهایی به شکل یک `Felt252Dict<u32>` داده می‌شوند، که کلیدهای آن اسم نامزدها و مقادیر آن مجموع آرای هر نامزد است.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
