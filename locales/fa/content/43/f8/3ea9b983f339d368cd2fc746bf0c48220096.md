برای مرور چند ویژگی جالب زبان GNU awk به [دستورهای تمرین `matrix`][ex-matrix] مراجعه کنید.

### فراخوانی پویای تابع

توابع در awk شیء درجه‌یک نیستند: نمی‌توان آن‌ها را مانند برخی زبان‌های دیگر آزادانه جابه‌جا کرد.
با این حال، یک متغیر می‌تواند _اسم_ یک تابع را (به شکل رشته) در خود نگه دارد و تابع با نماد ویژه‌ی `@varname(args)` فراخوانی می‌شود.
یک مثال:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
این موضوع در [فراخوانی‌های غیرمستقیم توابع][indirect] شرح داده شده است.
این یک افزونه‌ی `gawk` است.
