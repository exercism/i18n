# درباره

کلاس‌های اصلی `java.time` مانند `LocalDate` و `LocalDateTime` متدهای پایه‌ای برای افزودن یا کم کردن واحدهای زمانی در اختیار می‌گذارند، اما تنظیم‌های پیچیده‌تر تاریخ معمولاً به منطقی پیشرفته‌تر نیاز دارند (مثلاً یافتن «دومین سه‌شنبه‌ی ماه» یا «آخرین روز سال»).

بسته‌ی `java.time.temporal` برای همین منظور، رابط تابعی [`TemporalAdjuster`][temporaladjuster-docs] را در اختیار می‌گذارد.
این رابط، راهبردی برای تنظیم یک شیء زمانی (مثل `LocalDate`) است.
کلاس کمکی [`TemporalAdjusters`][temporaladjusters-docs] (به حرف «s» جمع در انتهای اسمش توجه کنید) متدهای ایستای کارخانه‌ای دارد که بسیاری از پیاده‌سازی‌های رایج و از پیش تعریف‌شده‌ی تنظیم‌کننده را فراهم می‌کنند.

## استفاده از TemporalAdjusters

اشیای زمانی مانند `LocalDate` و `LocalDateTime` متدی به اسم `with()` دارند که یک `TemporalAdjuster` می‌پذیرد.
این متد یک شیء زمانی *جدید* با تنظیم اعمال‌شده برمی‌گرداند.

```exercism/note
استفاده از `with(TemporalAdjuster)` یک نمونه‌ی _جدید_ برمی‌گرداند و نمونه‌ی موجود را به‌روزرسانی نمی‌کند، چون همه‌ی کلاس‌های زمانی `java.time` تغییرناپذیرند.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## تنظیم‌کننده‌های از پیش تعریف‌شده‌ی رایج

کلاس `TemporalAdjusters` متدهای ایستای مفید زیادی دارد.
چند نمونه‌ی رایج را ببینید:

### یافتن روز ترتیبی هفته

تنظیم‌کننده‌ی `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` روز مشخصی از هفته را بر پایه‌ی شماره‌ی رخدادش در ماه پیدا می‌کند.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### یافتن اولین یا آخرین روز هفته در ماه

تنظیم‌کننده‌های `firstInMonth(DayOfWeek dayOfWeek)` و `lastInMonth(DayOfWeek dayOfWeek)` اولین یا آخرین رخداد یک روز از هفته را در ماه پیدا می‌کنند.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### یافتن اولین یا آخرین روز ماه یا سال

تنظیم‌کننده‌های ساده‌تر، اولین یا آخرین روز ماه یا سال جاری را پیدا می‌کنند.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### تنظیم‌های نسبی (بعدی/قبلی)

تنظیم‌کننده‌هایی مانند `next()`، `previous()`، `nextOrSame()` و `previousOrSame()` رخداد بعدی یا قبلی یک روز مشخص از هفته را نسبت به تاریخ جاری پیدا می‌کنند.

- `next()`/`previous()`: اگر تاریخ جاری با آن روز یکی باشد، آن را در نظر نمی‌گیرد.
- `nextOrSame()`/`previousOrSame()`: اگر تاریخ جاری با آن روز یکی باشد، آن را هم در نظر می‌گیرد.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## تنظیم‌کننده‌های سفارشی

از آنجا که `TemporalAdjuster` یک [`@FunctionalInterface`][functionalinterface-docs] است، می‌توانید تنظیم‌کننده‌های سفارشی خودتان را با عبارت‌های لامبدا برای منطقی که متدهای از پیش تعریف‌شده پوشش نمی‌دهند بنویسید.
این رابط فقط به پیاده‌سازی یک متد نیاز دارد: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

تنظیم‌کننده‌های سفارشی قدرتمندند، اما تنظیم‌کننده‌های از پیش تعریف‌شده در کلاس `TemporalAdjusters` طیف گسترده‌ای از موارد پرکاربرد را پوشش می‌دهند.
