# دستورالعمل‌ها

شما تخته‌ی امتیاز یک مسابقه‌ی نتبال را اداره می‌کنید. برخلاف آنچه تا اینجا داشته‌ایم، تخته‌ی امتیاز باید به خاطر بسپارد که چه اتفاقی افتاده است.

کلاس `SCOREBOARD` به موارد زیر نیاز دارد. کد اولیه، خود کلاس و دو اعلان ویژگی‌هایش را به شما می‌دهد؛ بقیه را اضافه کنید.

## 1. تخته را آماده کنید

`create` اسم تیم میزبان و اسم تیم مهمان را می‌گیرد و تخته‌ی امتیازی برمی‌گرداند که امتیاز هر دو تیم در آن صفر است.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. گل بزنید

`home_goal` یک واحد به امتیاز میزبان اضافه می‌کند و `away_goal` یک واحد به امتیاز مهمان. هیچ‌کدام مقداری برنمی‌گردانند.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. تخته را بخوانید

`summary` تخته را همان‌طور که نوشته می‌شود برمی‌گرداند: تیم میزبان، امتیازش، یک خط تیره، امتیاز مهمان و سپس تیم مهمان.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

فاصله‌ها دقیقاً همان‌طور که نشان داده شده‌اند و خط تیره یک `-` است.

## 4. کدام تیم برنده است؟

`leader` اسم تیمی را برمی‌گرداند که جلوتر است، یا وقتی امتیازها برابرند `"Draw"`.

```sather
board.leader
-- => "Vixens"
```

## 5. چقدر جلوتر؟

`margin` برمی‌گرداند که چند گل تیم‌ها را از هم جدا می‌کند. این مقدار هرگز منفی نیست، هر تیمی که جلوتر باشد.

```sather
board.margin
-- => 1
```
