# دستورالعمل‌ها

الیس که در آستانه‌ی جادوگر شدن است، باید چند مهارت پایه را تمرین کند. او پشته‌ای از کارت‌ها دارد که می‌خواهد با آن‌ها کار کند.

برای اینکه کار کمی ساده‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند، بنابراین می‌توان پشته‌ی کارت‌هایش را با یک بردار از اعداد نمایش داد.
موقعیت هر کارت مشخص با اندیس آن در بردار متناظر است.

## 1. یک کارت را از پشته بیرون بیاورید

برای برداشتن یک کارت، کارتِ اندیسِ `position` را از پشته‌ی داده‌شده برگردانید.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. یک کارت را در پشته جابه‌جا کنید

کمی تردستی کنید و کارتِ اندیسِ `position` را با کارت جایگزینی که در اختیارتان قرار گرفته عوض کنید.
پشته‌ی تغییر یافته را برگردانید.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. یک کارت را در بالای پشته درج کنید

با درج یک کارت جدید در بالای پشته، کاری کنید یک کارت ظاهر شود.
پشته‌ی تغییر یافته را برگردانید.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. یک کارت را از پشته حذف کنید

با حذف کارتِ `position` داده‌شده از پشته، کاری کنید یک کارت ناپدید شود.
پشته‌ی تغییر یافته را برگردانید.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. اندازه‌ی پشته را بررسی کنید

بررسی کنید که اندازه‌ی پشته با `stack_size` برابر است یا نه.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. کارت بالای پشته را حذف کنید

با حذف کارتِ بالای پشته، کاری کنید یک کارت ناپدید شود.
پشته‌ی تغییر یافته را برگردانید.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. یک کارت را در پایین پشته درج کنید

با درج یک کارت جدید در پایین پشته، کاری کنید یک کارت ظاهر شود.
پشته‌ی تغییر یافته را برگردانید.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. یک کارت را از پایین پشته حذف کنید

با حذف کارتِ پایین پشته، کاری کنید یک کارت ناپدید شود.
پشته‌ی تغییر یافته را برگردانید.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
