# دستورالعمل‌ها

الیس می‌خواهد شعبده‌باز شود و برای این کار باید چند مهارت پایه را تمرین کند. او یک دسته کارت دارد که می‌خواهد با آن کار کند.

برای اینکه کارش کمی راحت‌تر شود، فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

## 1. برداشتن یک کارت از دسته

تابع `getCard` را پیاده‌سازی کنید که کارت واقع در موقعیت `index` را از دسته‌ی داده‌شده برمی‌گرداند. اگر `index` در دسته نباشد، Nothing را برگردانید.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. تغییر یک کارت در دسته

تابع `setCard` را پیاده‌سازی کنید که دسته‌ای را برمی‌گرداند که در آن کارت واقع در موقعیت `index` با کارت جدیدِ داده‌شده جایگزین شده است.
اگر `index` در دسته نباشد، دسته‌ی اصلی را برگردانید.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. افزودن یک کارت به دسته

تابع `addCard` را پیاده‌سازی کنید که دسته‌ای را با کارت جدیدِ افزوده‌شده برمی‌گرداند.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. حذف یک کارت از دسته

تابع `removeCard` را پیاده‌سازی کنید که دسته‌ای را برمی‌گرداند که در آن کارت واقع در موقعیت `index` حذف شده است.
اگر `index` داده‌شده اندیس معتبری در دسته نباشد، دسته‌ی اصلی را برگردانید.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. شمارش تعداد کارت‌های زوج در دسته

تابع `evenCardCount` را پیاده‌سازی کنید که تعداد کارت‌های زوج در دسته را می‌شمارد.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
