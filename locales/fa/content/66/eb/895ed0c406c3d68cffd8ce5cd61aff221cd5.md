# دستورالعمل‌ها

دوستتان از پرداخت پول برای نرم‌افزار ویرایش عکس خسته شده و تصمیم گرفته خودش یکی بنویسد.
دوستتان تصمیم گرفته اسم نرم‌افزار جدید را Foto Fusionist بگذارد.

Foto Fusionist یک نرم‌افزار ویرایش عکس است که می‌تواند کارهای زیادی انجام دهد، اما شما تا اینجا فقط چند مورد از آن‌ها را پیاده‌سازی کرده‌اید.
با این حال، دوستتان از پیشرفت خیلی خوشحال است و از شما خواسته چند قابلیت دیگر را هم پیاده‌سازی کنید.

## 1. تبدیل نمایش دودویی به عدد صحیح

برای اولین قابلیت، دوستتان می‌خواهد بتواند نمایش دودویی یک عدد را به عدد صحیح تبدیل کند.
این کار لازم است چون نرم‌افزار باید بتواند نمایش دودویی یک کانال رنگی را بخواند و آن را به عدد صحیح تبدیل کند.

متد `FotoFusionist.binary_to_int` را پیاده‌سازی کنید که یک آرگومان به اسم `binary` از نوع `String` می‌گیرد.
این متد باید معادل عدد صحیح عدد دودویی را برگرداند.

```crystal
FotoFusionist.binary_to_int("10011")
# => 19
```

## 2. گرفتن کم‌ارزش‌ترین بیت از یک عدد صحیح

دومین قابلیتی که دوستتان می‌خواهد این است که بتواند [کم‌ارزش‌ترین بیت][least-significant-bit] را از یک عدد صحیح بگیرد.
«کم‌ارزش‌ترین بیت» بیتی است که در سمت راست‌ترین نقطه قرار دارد.
به این دلیل کم‌ارزش‌ترین بیت نامیده می‌شود که کم‌ترین ارزش را دارد.

از کم‌ارزش‌ترین بیت برای این استفاده می‌شود که ارزیابی کنیم آیا می‌توان تصویر را با کاهش تعداد بیت‌هایی که برای نمایش کانال رنگی به کار می‌رود بهینه کرد یا نه.

متد `FotoFusionist.least_significant_bit` را پیاده‌سازی کنید که یک آرگومان به اسم `number` از نوع `Int32` می‌گیرد.
این متد باید کم‌ارزش‌ترین بیت عدد را برگرداند.

```crystal
FotoFusionist.least_significant_bit(0b10011)
# => 1

FotoFusionist.least_significant_bit(0b10010)
# => 0
```

## 3. گرفتن مقدار هگزادسیمال از یک کانال رنگی

سومین قابلیتی که دوستتان می‌خواهد این است که بتواند «مقدار هگزادسیمال» را از یک کانال رنگی بگیرد.
مقدار هگزادسیمال لازم است تا بتوان کانال رنگی را به یک نمایش هگزادسیمال تبدیل کرد و این نمایش هگزادسیمال باید از دو رقم تشکیل شده باشد.

متد `FotoFusionist.hex_value` را پیاده‌سازی کنید که یک آرگومان به اسم `number` از نوع `Int32` می‌گیرد.
این متد باید مقدار هگزادسیمال عدد را به‌صورت یک `String` برگرداند.

```crystal
FotoFusionist.hex_value(19)
# => "13"
```

## 4. گرفتن مقدار هگزادسیمال از RGB

چهارمین قابلیتی که دوستتان می‌خواهد این است که بتواند مقدار هگزادسیمال را از یک رنگ RGB بگیرد.
این کار لازم است تا کاربر بتواند یک نمایش رشته‌ای واحد از یک رنگ به دست آورد.
رنگ RGB رنگی است که با سه کانال رنگی نمایش داده می‌شود: قرمز، سبز و آبی.
هر کانال رنگی با عددی بین ۰ و ۲۵۵ نمایش داده می‌شود.

مقدار هگزادسیمال یک رنگ RGB، نمایش رشته‌ای آن رنگ در مبنای شانزده است، به این ترتیب که اول کانال رنگی قرمز، بعد کانال رنگی سبز و در آخر کانال رنگی آبی می‌آید.

متد `FotoFusionist.hex_value_from_rgb` را پیاده‌سازی کنید که سه آرگومان می‌گیرد: `red`، `green` و `blue` از نوع `Int32`.
این متد باید مقدار هگزادسیمال رنگ RGB را به‌صورت یک `String` برگرداند.

```crystal
FotoFusionist.hex_value_from_rgb(255, 0, 0)
# => "ff0000"
```

[least-significant-bit]: https://en.wikipedia.org/wiki/Least_significant_bit
