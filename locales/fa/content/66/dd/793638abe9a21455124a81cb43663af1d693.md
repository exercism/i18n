# درباره

Objective-C یک لایه‌ی نازک روی C است و یک «ابرمجموعه‌ی اکید» از C است، به این معنا که می‌توان هر برنامه‌ی C را با کامپایلر Objective-C کامپایل کرد و آزادانه کد زبان C را درون یک کلاس Objective-C گنجاند.
Objective-C نحوه‌ی نگارش شیءگرای خود را از Smalltalk گرفته است.
همه‌ی نحوه‌ی نگارش عملیات غیر شیءگرا (از جمله متغیرهای ابتدایی، پیش‌پردازش، عبارت‌ها، اعلان‌های تابع و فراخوانی‌های تابع) با نحوه‌ی نگارش C یکسان است، در حالی که نحوه‌ی نگارش ویژگی‌های شیءگرا پیاده‌سازی‌ای از پیام‌رسانی به سبک Smalltalk است.

می‌توانید اطلاعات بیشتر درباره‌ی زبان و تاریخچه‌ی آن را [اینجا](https://en.wikipedia.org/wiki/Objective-C) پیدا کنید.
