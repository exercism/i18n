# تست

تست‌ها را با این دستور اجرا کنید:

```bash
$ gradlew test
```

> اگر از ویندوز استفاده می‌کنید، از `gradlew.bat` استفاده کنید

## تست‌های نادیده‌گرفته‌شده

در مجموعه‌تست‌ها، همه‌ی تست‌ها به‌جز اولین تست نادیده گرفته شده‌اند.

وقتی یک تست را با موفقیت پاس کردید، می‌توانید با حذف حاشیه‌نویسی `@Ignore` تست بعدی را فعال کنید.
