# مقدمه

JavaScript زبانی پویاست که از سبک‌های شیءگرا، دستوری و اعلانی (مثلاً برنامه‌نویسی تابعی) پشتیبانی می‌کند.

## متغیر

چند روش اصلی برای نسبت دادن مقدار به اسم در JavaScript وجود دارد: استفاده از متغیرها یا ثابت‌ها.
در Exercism، متغیرها همیشه به شکل [camelCase][wiki-camel-case] نوشته می‌شوند؛ ثابت‌ها به شکل [SCREAMING_SNAKE_CASE][wiki-snake-case].
راهنمای رسمی واحدی برای پیروی وجود ندارد و شرکت‌ها و سازمان‌های مختلف، راهنماهای سبک متفاوتی دارند.
_با خیال راحت متغیرها را هر طور که دوست دارید بنویسید_.
مزیت نوشتن آن‌ها همان‌طور که تمرین‌ها آماده شده‌اند این است که در رابط وب و بیشتر محیط‌های توسعه‌ی یکپارچه به شکل متفاوتی برجسته می‌شوند.

متغیرها در JavaScript را می‌توان با کلیدواژه‌ی [`const`][mdn-const]، [`let`][mdn-let] یا [`var`][mdn-var] تعریف کرد.

یک متغیر هنگام استفاده از `let` یا `var` می‌تواند در طول عمرش به مقدارهای مختلفی اشاره کند.
برای مثال، `myFirstVariable` را می‌توان با عملگر انتساب `=` چندین بار تعریف و بازتعریف کرد:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

برخلاف `let` و `var`، متغیرهایی که با `const` تعریف می‌شوند فقط یک بار می‌توانند مقدار بگیرند.
از این ویژگی برای تعریف ثابت‌ها در JavaScript استفاده می‌شود.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## اعلان تابع

در JavaScript، واحدهای عملکرد در _توابع_ کپسوله می‌شوند و معمولاً توابعی که به هم تعلق دارند در یک فایل کنار هم قرار می‌گیرند.
این توابع پارامتر دارند (تا بتوانند آرگومان بگیرند) و می‌توانند با استفاده از کلیدواژه‌ی `return` مقداری را _برگردانند_.
فراخوانی توابع با `()` انجام می‌شود.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

در این مثال، اسم تابع `add` است.
این تابع دو پارامتر دارد: `num1` و `num2`.
مقداری را برمی‌گرداند: نتیجه‌ی عبارت `num1 + num2`.

سپس تابع `add` با دو آرگومان _فراخوانی_ می‌شود: `1` و `3`.
نتیجه‌ی تابع، یعنی مقدار برگشتی، `4` است.

```exercism/note
💡 در JavaScript راه‌های _بسیار_ متفاوتی برای اعلان یک تابع وجود دارد.
برخی از این راه‌های دیگر با استفاده از کلیدواژه‌ی `function` فرق دارند.
این ترک سعی می‌کند آن‌ها را به‌تدریج معرفی کند، اما اگر از قبل با آن‌ها آشنا هستید، با خیال راحت از هر کدامشان استفاده کنید.
در بیشتر موارد، استفاده از یکی یا دیگری بهتر یا بدتر نیست.
```

## در دسترس قرار دادن برای فایل‌های دیگر

برای اینکه یک `function`، یک ثابت یا یک متغیر در _فایل‌های دیگر_ در دسترس باشد، باید با استفاده از کلیدواژه‌ی `export` [صادر شود][mdn-export].
سپس فایل دیگری می‌تواند آن‌ها را با استفاده از کلیدواژه‌ی `import` [وارد کند][mdn-import].
به این کار سیستم ماژول نیز می‌گویند.

نمونه‌ی خوبی از این، نحوه‌ی کار همه‌ی testهاست.
هر تمرین حداقل یک فایل دارد، برای مثال `lasagna.js`، که _پیاده‌سازی_ را در خود دارد.
_پیاده‌سازی_ از فایل `export` می‌شود تا بتوان آن را در فایل دیگری وارد کرد.
علاوه بر این، حداقل یک فایل دیگر هم وجود دارد، برای مثال `lasagna.spec.js`، که _testها_ را در خود دارد.
این فایل برای test کردن پیاده‌سازی، موجودیت‌های عمومی (یعنی `export`شده) را `import` می‌کند:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
