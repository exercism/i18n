# دستورهای مخصوص SQLite

* ستون **candidates** شامل فهرستی از رشته‌هاست که با JSON کدگذاری شده است.
  مثال:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* ستون **result** هم باید شامل فهرستی از رشته‌ها باشد که با JSON کدگذاری شده است.

## طرح‌بندی جدول

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
