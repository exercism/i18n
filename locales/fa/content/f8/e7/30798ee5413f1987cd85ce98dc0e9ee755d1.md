# مقدمه

[دیکشنری‌ها][dictionaries] یکی از انواع مجموعه‌ی اصلی Swift هستند.
یک «دیکشنری» ارتباط‌های بدون ترتیب میان کلیدهای یکتا و مقادیر متناظرشان را ذخیره می‌کند.
همه‌ی کلیدهای یک دیکشنری باید از یک نوع باشند و همه‌ی مقادیر هم باید نوع یکسانی داشته باشند.

لیترال‌های دیکشنری به شکل جفت‌های `key: value` نوشته می‌شوند که با کاما از هم جدا شده و داخل کروشه قرار می‌گیرند:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

نوع‌های دیکشنری را می‌توان به دو روش صریح نوشت: `Dictionary<Key, Value>` یا با شکل کوتاه نگارش `[Key: Value]`.

برای ساختن یک دیکشنری خالی، نوع کلید و مقدار آن را به‌صراحت مشخص کنید:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## دسترسی به مقادیر

می‌توانید با استفاده از نماد «اندیس» به مقادیر دسترسی داشته باشید: کلید را داخل کروشه، بعد از اسم دیکشنری قرار دهید.
از آنجا که ممکن است یک کلید در دیکشنری وجود نداشته باشد، دسترسی با اندیس یک مقدار *اختیاری* (`Value?`) برمی‌گرداند.
اگر کلید وجود داشته باشد، Swift مقدار پوشش‌داده‌شده را برمی‌گرداند؛ در غیر این صورت `nil` را برمی‌گرداند:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

برای اینکه مجبور نباشید با مقدارهای اختیاری کار کنید، می‌توانید با استفاده از پارامتر `default` یک مقدار پیش‌فرض بدهید:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## تغییر دادن دیکشنری‌ها

برای دیکشنری‌های قابل تغییر که با `var` تعریف شده‌اند، می‌توانید جفت‌های کلید-مقدار را با انتساب از طریق اندیس اضافه یا به‌روزرسانی کنید:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## پیمایش روی یک دیکشنری

می‌توانید با استفاده از یک حلقه‌ی `for-in` روی هر جفت کلید-مقدار یک دیکشنری پیمایش کنید.
هر عنصر به‌صورت یک «تاپل» `(key, value)` در اختیار شما قرار می‌گیرد:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## مرتب‌سازی دیکشنری‌ها

چون دیکشنری‌ها بدون ترتیب‌اند، مرتب کردن‌شان یک آرایه از جفت‌های کلید-مقدار تولید می‌کند.
می‌توانید یک «کلوژر» به متد `sorted(by:)` بدهید که دو تاپل `(key, value)` را مقایسه می‌کند و اگر تاپل اول باید قبل از دومی بیاید `true` برمی‌گرداند:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
