# مفاهیم Luhn

Luhn یک الگوریتم اعتبارسنجی است که بررسی‌های متنی و عددی را با هم ترکیب می‌کند. راه‌حل‌های Rust رویکردهای تابعی را ترجیح می‌دهند.

## کلیات

### انواع اولیه

- `&str` و `char`
  - دانش‌آموزان باید تفاوت `char` منفرد با `&str` را درک کنند تا بتوانند بخش‌هایی از ورودی داده‌شده را به‌درستی حذف کنند یا بگنجانند
- عدد صحیح
  - درک اعداد صحیح برای انجام اعتبارسنجی عددی لازم، مهم است
- مقادیر منطقی
  - برای بررسی‌های هم‌ارزی و مقایسه‌های نهایی ضروری‌اند

### ویژگی‌های تکرارگر

- زنجیره‌سازی
  - درک زنجیره‌های تکرارگر در اینجا برای حل مسئله به‌صورت مرتب مهم است.
- `map`، `filter`، turbofish و احتمالاً `fold`
  - ترکیب `map` و `filter` یک الگوی طراحی پایه برای مسائل اعتبارسنجی مثل این یکی فراهم می‌کند. راه‌حل‌های مبتنی بر `fold` هم کوتاه‌ترند.
  - در برخی راه‌حل‌ها turbofish لازم است تا به Rust بگویید چه نوعی را از یک عبارت زنجیره‌ای می‌سازید

## راه‌حل نمونه ۱

[راه‌حل](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## راه‌حل نمونه ۲

استاندارد

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
