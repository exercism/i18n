# مقدمه

## آرگومان‌های برچسب‌دار

گاهی وقتی یک تابع آرگومان‌های زیادی می‌گیرد، به خاطر سپردن ترتیبی که باید در آن داده شوند می‌تواند دشوار باشد. برای کمک به خوانایی، Gleam اجازه می‌دهد آرگومان‌ها با یک اسم برچسب‌گذاری شوند.

برای برچسب‌گذاری یک آرگومان، اسم برچسب را با یک فاصله پیش از اسم آرگومان بنویسید.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

وقتی تابعی را با آرگومان‌های برچسب‌دار فراخوانی می‌کنید، می‌توان آرگومان‌ها را به هر ترتیبی داد. هر یک از این فراخوانی‌های `replace` معادل‌اند:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

برچسب‌ها همیشه اختیاری‌اند. حتی اگر تابعی آرگومان‌های برچسب‌دار داشته باشد، همچنان می‌توان آن را بدون برچسب فراخوانی کرد.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
