# درباره

## تابع

در Gleam توابع با نحوه‌ی نگارش `pub fn` تعریف می‌شوند.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

این تابع دو آرگومان می‌گیرد که هر دو از نوع `Int` هستند و مقداری از نوع `Int` برمی‌گرداند. در Gleam کلیدواژه‌ی `return` وجود ندارد؛ مقدار آخرین عبارت در یک تابع همیشه _به‌طور ضمنی برگردانده می‌شود_.

حاشیه‌نویسی نوع برای آرگومان‌ها و نوع بازگشتی اختیاری است و Gleam همیشه کد شما را به‌طور کامل از نظر نوع بررسی می‌کند. معمولاً برنامه‌نویسان Gleam برای شفافیت به توابع خود حاشیه‌نویسی نوع می‌دهند، اما اگر بخواهید می‌توانید آن‌ها را حذف کنید.

```gleam
pub fn add(x, y) {
  x + y
}
```

یک تابع را می‌توان با نحوه‌ی نگارش `function_name(argument1, argument2)` فراخوانی کرد.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## متغیر

در Gleam متغیرها با نحوه‌ی نگارش `let name = expression` تعریف می‌شوند.

```gleam
pub fn main() {
  let count = 1
}
```

متغیرها را می‌توان با حاشیه‌نویسی نوع تعریف کرد. این حاشیه‌نویسی‌ها مانند آرگومان‌های تابع اختیاری هستند، هرچند بیشتر برنامه‌نویسان Gleam حاشیه‌نویسی نوع را برای متغیرها حذف می‌کنند.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## لیترال رشته‌ای

در Gleam رشته‌ها با علامت نقل‌قول دوگانه نوشته می‌شوند.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## کامنت کد

می‌توان از کامنت‌ها برای گذاشتن یادداشت برای سایر برنامه‌نویسانی استفاده کرد که کد منبع را می‌خوانند. کامنت‌ها در Gleam یک‌خطی‌اند و با `//` شروع می‌شوند.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
