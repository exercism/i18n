# بوتیک مد

## داستان

شما یک بوتیک مد آنلاین را اداره می‌کنید. جمعه سیاه نزدیک است، پس باید موجودی انبارتان را بررسی کنید تا مطمئن شوید آماده‌اید.

هر عنصر از موجودی انبار با یک `map`/`dictionary` نمایش داده می‌شود و کل موجودی انبار یک `list`/`array` است که از همین `map`/`dictionary`ها تشکیل شده.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## کارها

- مرتب کردن عنصرها بر اساس قیمت
- یافتن همه‌ی عنصرهایی که قیمت ندارند
- افزایش تعداد عنصر
- محاسبه‌ی تعداد کل عنصر
