# مقدمه

«کامپرهنشن» امکانی برای تبدیل _شمارش‌پذیرها_ به شکلی آسان و اعلانی فراهم می‌کند.

برای تعریف یک کامپرهنشن بسیار ساده، می‌توانیم از کلیدواژه‌ی `for` استفاده کنیم و پس از آن یک _مولد_ و یک _بلوک `do`_ بیاوریم که مقادیر جدید را از مقادیر شمارش‌شده می‌سازد.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

کامپرهنشن می‌تواند _فیلتر_ هم داشته باشد. مقادیری که از فیلتر عبور نمی‌کنند از فهرست نهایی حذف می‌شوند:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

می‌توانیم کامپرهنشن‌های پیچیده‌تری را در چند خط تعریف کنیم:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

با استفاده از چند مولد می‌توان یک _ضرب دکارتی_ ایجاد کرد. یعنی هر مقداری که مولد اول تولید می‌کند، یک‌بار با هر مقداری که مولد دوم تولید می‌کند جفت می‌شود:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
