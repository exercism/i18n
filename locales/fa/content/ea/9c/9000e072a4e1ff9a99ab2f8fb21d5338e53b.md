# مقدمه

در Python، [«enum»](https://docs.python.org/3/library/enum.html) مجموعه‌ای از نام‌هاست که به مقادیر یکتای `literal` یا `constant` مقید شده‌اند. enum با ارث‌بری از کلاس `Enum` تعریف می‌شود. انواع enum توکار در ماژول `enum` موجودند و کلاس `Enum` را می‌توان با `from enum import Enum` وارد کرد.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

توجه کنید که مقادیر اعضای enum می‌توانند هر نوع داده‌ای مانند `str`، `tuple`، `float` و غیره باشند.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

وقتی مقدار یکسانی به دو عضو در یک enum اختصاص داده می‌شود، عضوی که دیرتر اختصاص می‌یابد، نام مستعاری برای عضوی که تشکیل شده است خواهد بود. استفاده از یک نام برای دو عضو یک enum مجاز نیست.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

پیمایش اعضای enum را می‌توان با نحوه‌ی نگارش استاندارد `for member in` انجام داد:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

اعضای enum را می‌توان با [`is` (_عملگر هویت_)](https://www.w3schools.com/python/ref_keyword_is.asp) یا `is not` مقایسه کرد. `==` یا `!=` (_عملگرهای برابری_) نیز به همین شکل کار می‌کنند.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

برای دسترسی به عضوی از enum با یک مقدار مشخص، می‌توان از `EnumName(value)` استفاده کرد:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
