# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که برچسب اسم کارکنان کارخانه را چاپ می‌کند.

## 1. چاپ برچسب برای یک کارمند

هر کارمند یک ID، یک اسم و یک بخش دارد. برچسب کارکنان به این شکل قالب‌بندی می‌شود: `"[id] - name - DEPARTMENT"`.
متد `Badge.print()` را طوری پیاده‌سازی کنید که برچسب کارمند را برگرداند:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

توجه کنید که نام بخش روی برچسب باید با حروف بزرگ نوشته شود.

## 2. چاپ برچسب برای کارمند جدید

به دلیل یک نکته‌ی عجیب در سیستم کامپیوتری، کارمندان جدید گاهی هنگام شروع کار در کارخانه هنوز ID ندارند.
از آنجا که برچسب الزامی است، یک برچسب موقت بدون پیشوند ID دریافت می‌کنند. متد `Badge.print()` را تغییر دهید تا از کارمندان جدیدی که هنوز ID ندارند پشتیبانی کند:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. چاپ برچسب برای مالک

حتی مالک کارخانه هم باید همیشه برچسب بزند.
اما مالک بخشی ندارد. در این حالت، برچسب باید به جای نام بخش، `"OWNER"` را چاپ کند.
متد `Badge.print()` را تغییر دهید تا برچسب مالک را چاپ کند:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

توجه کنید که ممکن است مالک همزمان کارمند جدید هم باشد:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
