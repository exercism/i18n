# پیوست دستورالعمل‌ها

## ساختار پروژه

تمرین‌های Clojure در Exercism از دو ابزار رایج برای مدیریت وابستگی و تست پشتیبانی می‌کنند: [leiningen][leiningen] و [Clojure CLI][clojure-cli].

یک فایل تست به اسم `hello_world_test.clj` درون دایرکتوری `test` پیدا می‌کنید.
کد خود را در `src/hello_world.clj` بنویسید. باید از فضای نام `hello-world` استفاده کند تا تست‌ها بتوانند آن را پیدا کنند.

### اجرای تست‌ها با Clojure CLI

```
$ clj -X:test
```

### اجرای تست‌ها با Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

سپس تمرین را با این فرمان ارسال کنید:

```
$ exercism submit src/hello_world.clj
```

برای دستورالعمل‌های دقیق‌تر و منابع یادگیری، به [صفحه‌ی زبان Clojure در Exercism][exercism-clojure] مراجعه کنید.

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
