# مقدمه

[Go](https://golang.org) یک زبان برنامه‌نویسی ایستا نوع‌دهی‌شده و کامپایل‌شونده است.
این تمرین سه ویژگی اصلی زبان را معرفی می‌کند: بسته، تابع و متغیر.

## بسته

برنامه‌های Go در قالب بسته‌ها سازماندهی می‌شوند.
بسته مجموعه‌ای از فایل‌های منبع است که در یک پوشه قرار دارند.
همه‌ی فایل‌های منبع در یک پوشه باید نام بسته‌ی یکسانی داشته باشند.
وقتی بسته‌ای وارد می‌شود، فقط موجودیت‌هایی (توابع، انواع، متغیرها، ثابت‌ها) که نامشان با حرف بزرگ شروع می‌شود می‌توانند استفاده یا دسترسی شوند.
سبک توصیه‌شده‌ی نام‌گذاری در Go این است که شناسه‌ها با `camelCase` نام‌گذاری می‌شوند، به‌جز آن‌هایی که قرار است در سراسر بسته‌ها قابل دسترسی باشند و باید `PascalCase` باشند.

```go
package lasagna
```

## متغیر

Go به‌صورت ایستا نوع‌دهی شده است، یعنی همه‌ی متغیرها [باید در زمان کامپایل نوع مشخصی داشته باشند](https://en.wikipedia.org/wiki/Type_system).

متغیرها می‌توانند با مشخص کردن صریح نوع تعریف شوند:

```go
var explicit int // Explicitly typed
```

همچنین می‌توانید از یک مقدار اولیه استفاده کنید، و کامپایلر نوع متغیر را مطابق نوع مقدار اولیه تعیین می‌کند.

```go
implicit := 10   // Implicitly typed as an int
```

پس از اعلان، می‌توان با عملگر `=` به متغیرها مقدار اختصاص داد.
پس از اعلان، نوع متغیر هرگز نمی‌تواند تغییر کند.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## ثابت

ثابت‌ها هم مانند متغیرها نگهدارنده‌ی یک داده هستند، اما مقدارشان در طول اجرای برنامه نمی‌تواند تغییر کند.

ثابت‌ها با کلیدواژه‌ی `const` تعریف می‌شوند و می‌توانند اعداد، کاراکترها، رشته‌ها یا «مقادیر منطقی» باشند:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## تابع

توابع Go صفر یا چند پارامتر می‌پذیرند.
پارامترها باید صریحاً نوع‌دهی شوند، هیچ استنتاج نوعی وجود ندارد.

مقادیر با کلیدواژه‌ی `return` از توابع برگردانده می‌شوند.

یک تابع با مشخص کردن نام تابع و فرستادن آرگومان برای هر یک از پارامترهای تابع فراخوانی می‌شود.

توجه کنید که Go از دو نوع توضیح پشتیبانی می‌کند.
توضیحات تک‌خطی با `//` شروع می‌شوند و توضیحات چندخطی بین `/*` و `*/` قرار می‌گیرند.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
