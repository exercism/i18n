# مقدمه

یک دستور `switch` یک عبارت را ارزیابی می‌کند و اولین `case`ی را که با مقدارش مطابقت دارد اجرا می‌کند.
این دستور اغلب جایگزین تمیزتری برای زنجیره‌های طولانی `if ... else if` است.
برای مثال،

```go
operatingSystem := "windows"

if operatingSystem == "windows" {
    // do something if the operating system is windows
} else if operatingSystem == "linux" {
    // do something if the operating system is linux
} else if operatingSystem == "macos" {
    // do something if the operating system is macos
} else {
    // do something if the operating system is none of the above
}
```

را می‌توان به این شکل بازنویسی کرد:

```go
operatingSystem := "windows"

switch operatingSystem {
case "windows":
    // do something if the operating system is windows
case "linux":
    // do something if the operating system is linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

می‌توان با کاما چندین مقدار را در یک `case` واحد گروه‌بندی کرد.
اگر عبارت با هر یک از این مقادیر برابر باشد، آن case مطابقت می‌کند:

```go
switch operatingSystem {
case "windows", "linux":
    // do something if the operating system is windows or linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

عبارت بعد از `switch` را هم می‌توان کاملاً حذف کرد.
در این حالت، هر `case` یک «عبارت منطقی» در خود دارد و اولین caseی که «درست» باشد اجرا می‌شود.

```go
age := 21

switch {
case age > 20 && age < 30:
    // do something if age is between 20 and 30
case age == 10:
    // do something if age is equal to 10
default:
    // do something else for every other case
}
```
