# مقدمه

## ثابت

اصلاح‌کننده‌ی `const` را می‌توان (و عموماً باید) روی هر فیلدی اعمال کرد که مقدارش در زمان کامپایل معلوم است و در طول عمر برنامه تغییر نمی‌کند.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

اصلاح‌کننده‌ی `readonly` را می‌توان (و عموماً باید) روی هر فیلدی اعمال کرد که نمی‌توان آن را `const` کرد، به شرطی که مقدارش در طول عمر برنامه تغییر نکند و تعیین آن یا با مقداردهی اولیه‌ی درجا انجام شود یا هنگام نمونه‌سازی (توسط سازنده یا متدی که سازنده فراخوانی می‌کند).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## کپی دفاعی

در موقعیت‌های حساس به امنیت (یا حتی صرفاً در یک کدبیس بزرگ که توسعه‌دهندگان اولویت‌ها و اهداف متفاوتی دارند) نگذارید API عمومی یک کلاس با پذیرفتن و ذخیره‌کردن پارامترهای تغییرپذیر یک متد، یا با آشکار کردن یک عضو تغییرپذیر آن از طریق مقدار بازگشتی یا پارامتر `out`، دور زده شود.

## مجموعه‌ی فقط‌خواندنی

گرچه اصلاح‌کننده‌ی `readonly` جلوی بازنویسی مقدار یا ارجاع درون یک فیلد را می‌گیرد، اما از اعضای یک نوع ارجاعی محافظتی نمی‌کند.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

برای اطمینان از محافظت همه‌ی اعضای یک نوع ارجاعی، می‌توان فیلدها را `readonly` کرد و ویژگی‌های خودکار را بدون دسترسی‌دهنده‌ی `set` تعریف کرد.

کتابخانه‌ی کلاس پایه (BCL) چند نسخه‌ی فقط‌خواندنی از مجموعه‌ها را برای جاهایی فراهم می‌کند که لازم است جلوی به‌روزرسانی اعضای یک مجموعه گرفته شود. این‌ها در قالب پوشش‌هایی ارائه می‌شوند:

- `ReadOnlyDictionary<T>` یک `Dictionary<T>` را به‌صورت فقط‌خواندنی در دسترس قرار می‌دهد.
- `ReadOnlyCollection<T>` یک `List<T>` را به‌صورت فقط‌خواندنی در دسترس قرار می‌دهد.
