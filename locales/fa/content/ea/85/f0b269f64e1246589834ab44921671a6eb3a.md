# مقدمه

علاوه بر تعریف‌های تابع و عبارت‌های تابع، JavaScript یک نحوه‌ی نگارش بسیار موجز دیگر هم برای تعریف تابع دارد.
به این توابع، _تابع پیکانی_ می‌گویند.

در این مفهوم، روی نحوه‌ی نگارشی تمرکز می‌کنیم که برای نوشتن یک تابع پیکانی به کار می‌رود.
تفاوت‌هایی در نحوه‌ی کارکرد تابع پیکانی وجود دارد، مثل نحوه‌ی اتصال _this_، که در مفاهیم دیگر به آن‌ها پرداخته می‌شود.

در ادامه، مقایسه‌ای میان تعریف تابع و تابع پیکانی می‌بینید.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

در بالا می‌بینید که نحوه‌ی نگارش تابع پیکانی:

1. کلیدواژه‌ی `function` را حذف می‌کند
2. شناسه‌ی `addUpTwoNumbers` را به‌صورت `const` تعریف کرده است
3. یک پیکان ضخیم `=>` اضافه می‌کند

اگر بدنه‌ی تابع فقط شامل یک دستور return باشد، همانند مثال بالا، می‌توان `{}` و کلیدواژه‌ی `return` را حذف کرد.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

در حالت خاصی که تابع پیکانی فقط یک شیء را برمی‌گرداند، برای اینکه بتوان دستور return را حذف کرد، شیء باید داخل پرانتز قرار بگیرد.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

استفاده از پرانتز دور پارامترها به تعداد پارامترها بستگی دارد.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
