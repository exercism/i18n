# مقدمه

## دستور شرطی

دستور شرطی، دستوری برای تصمیم‌گیری است که یا «اثر جانبی» اجرا می‌کند یا جریان اجرا را در یک برنامه کنترل می‌کند.
دستور شرطی شامل `if`، `if/else`، `switch` و `ternary` می‌شود.

دستور شرطی برای پرسیدن پرسش‌هایی درباره‌ی یک مقدار یا رابطه‌ی میان چند مقدار به کار می‌رود.
این پرسش به یک پاسخ «منطقی» ارزیابی می‌شود، اما خود دستور `if` می‌تواند هر مقداری را برگرداند یا صرفاً یک اثر جانبی اجرا کند.

## دستور if

ساده‌ترین دستور `if` یک عبارت را ارزیابی می‌کند و یک خط را اجرا می‌کند.
عبارتی که آزموده می‌شود همیشه داخل پرانتز قرار می‌گیرد.

می‌تواند یک اثر جانبی اجرا کند

```c
if (count > 10)
    printf("count is greater than 10");
```

یا می‌تواند جریان اجرا را تغییر دهد


```c
if (count > 10)
    return sum;
```

اگر یک دستور `if` بیش از یک خط را اجرا کند، باید آن خط‌ها را داخل آکولاد قرار دهد

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

برخی تیم‌های برنامه‌نویسی ممکن است این را استاندارد کنند که دستورهای `if` همیشه باید از آکولاد استفاده کنند، حتی برای یک خط.


## if و else

یک دستور `if` را می‌توان با یک `else` همراه کرد

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if و else if


`else` را می‌توان با `if` دیگری همراه کرد تا چیزی ساخته شود که به آن `if-else-if ladder` می‌گویند.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


گاهی می‌توان یک `if-else-if ladder` را بهتر با یک `switch` نمایش داد.
مانند `if`، عبارتی که آزموده می‌شود همیشه داخل پرانتز قرار می‌گیرد.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

حالت `default` زمانی اجرا می‌شود که مقدار آزموده‌شده با هیچ‌یک از حالت‌های پیشین مطابقت نداشته باشد.

اگر یک حالت `switch` چیزی را برنمی‌گرداند، معمولاً برای پایان دادن به هر حالت یک `break` قرار می‌دهند، در غیر این صورت منطق به حالت بعدی «سرریز» می‌کند.
گاهی این سرریز به‌طور عمدی به کار می‌رود

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

وقتی این سرریز به‌طور ناخواسته رخ دهد، یک bug است.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

استفاده از switch زمانی می‌تواند مفید باشد که به‌جای یک محدوده از مقادیر، مقادیر مشخصی آزموده شوند.
می‌تواند از یک `if-else-if ladder` سریع‌تر باشد، چون کامپایلر ممکن است بتواند دستور `switch` را به روش‌هایی بهینه کند که با یک نردبان امکان‌پذیر نیست.
یک switch گاهی خواناتر از یک نردبان به نظر می‌رسد.

## عملگر سه‌گانه (که به آن شرطی هم می‌گویند)

عملگر سه‌گانه یک دستور شرطی سه‌بخشی است که اغلب برای تعیین یک مقدار به کار می‌رود.
عبارتی که باید آزموده شود پیش از علامت سؤال می‌آید و لازم نیست داخل پرانتز باشد.
مقداری که در صورت «درست» بودن برگردانده می‌شود پیش از دونقطه است و مقداری که در صورت «غلط» بودن برگردانده می‌شود پس از دونقطه.
می‌توان یک لیترال یا یک متغیر را برگرداند.

```c
int i = j > 5 ? 5: j;
```

عملگر سه‌گانه را می‌توان تودرتو کرد تا شلوغی نحوه‌ی نگارش کاهش یابد.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
