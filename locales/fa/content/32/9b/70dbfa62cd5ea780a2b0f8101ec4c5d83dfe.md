# مقدمه

JavaScript علاوه بر دستور شرطی، یک دستور `switch` هم دارد که منطق را به‌صورت شرطی اجرا می‌کند. از آن زمانی استفاده می‌شود که لازم است یک متغیر واحد با چند حالت مختلف مقایسه شود. این مقایسه با بررسی برابری دقیق (`===`) انجام می‌شود. به [مفهوم مقایسه][concept-comparison] نگاه کنید. برای متغیری مانند `x`، دستور `switch` در JavaScript نحوه‌ی نگارش زیر را دارد.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

حالت `default` اختیاری است و زمانی به کار می‌رود که بخواهید در صورتی که هیچ‌یک از گزینه‌های دیگر با متغیر مطابقت نداشت، کدی را اجرا کنید.

دستورهای `break` در بالا لازم‌اند، چون در JavaScript به‌طور پیش‌فرض همه‌ی حالت‌ها «به حالت بعدی می‌افتند». یعنی بدون هیچ دستور `break`، همه‌ی کدی که در حالت‌های پایین‌تر از اولین گزینه‌ی منطبق قرار دارد اجرا می‌شود، حتی اگر `x` با آن حالت‌ها منطبق نباشد. این رفتار «افتادن پیش‌فرض به حالت بعدی» یک دام رایج هنگام استفاده از `switch` در JavaScript است. داخل یک تابع هم می‌توان به‌جای `break` از `return` استفاده کرد تا از این مشکل جلوگیری شود.
