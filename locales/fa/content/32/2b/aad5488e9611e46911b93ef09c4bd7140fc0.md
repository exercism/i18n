# پیوست دستورالعمل

توان‌رسانی اعداد گویا با یک عدد حقیقی مستلزم محاسبه‌ی یک عدد به توان یک عدد غیرصحیح است؛ قابلیتی که به‌صورت بومی در WebAssembly در دسترس نیست.

با این حال، می‌توانید `x ^ y` را به‌صورت `x ^ y = exp(y * ln(x))` هم بیان کنید.

و خوشبختانه می‌توان برای محاسبه‌ی تابع نمایی و لگاریتم طبیعی از سری‌های مختلفی استفاده کرد.

## تابع نمایی

بهترین راه‌حل برای تابع نمایی، یک [سری تیلور](https://en.wikipedia.org/wiki/Taylor_series) است:

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## تابع لگاریتم (برای `x` مثبت)

روش‌های متعددی برای محاسبه‌ی کارآمد لگاریتم طبیعی وجود دارد. یکی از آن‌ها سری‌ای است بر پایه‌ی [تانژانت هذلولوی معکوس](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent):

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

یک سری تیلور دیگر هم برای محاسبه‌ی لگاریتم طبیعی وجود دارد:

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

این سری فقط برای `x` بین ۰ و ۲ دقیق است. اما می‌توان از `ln(x) = - ln(1 / x)` هم استفاده کرد.

## توان‌رسانی عدد صحیح

برای توان‌رسانی عدد صحیح، بهتر است از ضرب و یکی از دو روش «حلقه» یا بازگشت استفاده کنید، هم به دلایل کارایی و هم دقت. برای کارایی بیشتر، می‌توان از [روش هورنر](https://en.wikipedia.org/wiki/Horner%27s_method) برای کاهش تعداد ضرب‌ها استفاده کرد.
