# درباره

هنگام نوشتن توابع Haskell می‌توانیم از [تطبیق الگو][pattern-matching] استفاده کنیم.
تطبیق الگو یکی از ویژگی‌های بسیار قدرتمند Haskell است که به شما امکان می‌دهد روی سازنده‌های داده تطبیق بدهید و متغیرها را به مقادیر درون آن‌ها مقید کنید.
همان‌طور که از اسمش پیداست، کاری که می‌کنیم تطبیق دادن مقادیر با الگوهاست، و اگر مقدار با الگو تطبیق داشته باشد، می‌توانیم متغیرها را به مقادیر درون الگو مقید کنیم.
تطبیق الگو عمدتاً از این مفاهیم ساخته شده است: شناختن مقادیر، مقید کردن متغیرها و تجزیه کردن مقادیر.

~~~~exercism/note
تطبیق الگو در زبان‌هایی مانند Elixir کمی با تطبیق الگو در Haskell تفاوت دارد.
برای نمونه، Elixir اجازه می‌دهد چند اسم مقید یکسان در یک الگو داشته باشیم، در حالی که Haskell این اجازه را نمی‌دهد.
~~~~


این تابع را در نظر بگیرید:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

اینجا تابعی به اسم `lucky` داریم که یک `Int` می‌گیرد و یک `String` برمی‌گرداند.
دو الگو برای این تابع تعریف کرده‌ایم: یکی با عدد `7` تطبیق می‌دهد و دیگری با هر عدد دیگری. اسم می‌تواند هر چیزی باشد (تا زمانی که از قرارداد نام‌گذاری Haskell پیروی کند)، اما اینجا ما از `x` استفاده می‌کنیم.
اگر عدد `7` باشد، تابع `"Lucky number seven!"` را برمی‌گرداند، در غیر این صورت `"Sorry, you're out of luck, pal!"` را برمی‌گرداند.
نکته‌ی مهمی که باید در نظر بگیرید این است که الگوها از بالا به پایین بررسی می‌شوند؛ بنابراین اگر ترتیب الگوها را عوض کرده بودیم، تابع همیشه `"Lucky number seven!"` را برمی‌گرداند.

## الگوی لیست

یک الگوی بسیار رایج، تطبیق دادن روی لیست‌هاست و آن هم گرفتن سر و دنباله‌ی لیست است.
این به این دلیل است که لیست‌ها ماهیتاً یک لیست پیوندی هستند.
در اینجا نمونه‌ای از تابعی را می‌بینیم که سر و دنباله‌ی یک لیست را برمی‌گرداند:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

اینجا دو الگو داریم: یکی با یک لیست خالی تطبیق می‌دهد و یکی با لیستی که حداقل یک عنصر دارد.
این به این دلیل است که اگر لیست خالی باشد، باید حالتی برای آن داشته باشیم، وگرنه با خطای زمان اجرا روبه‌رو می‌شویم.
اگر لیست خالی نباشد، می‌توانیم سر لیست را با `x` و دنباله‌ی لیست را با `xs` تطبیق بدهیم.
این کار با عملگر `:` (کنس) انجام می‌شود، که برای افزودن یک عنصر به ابتدای لیست به کار می‌رود.
اما در تطبیق الگو به ما اجازه می‌دهد یک لیست را به سر و دنباله‌اش تجزیه کنیم، یعنی به نوعی کار برعکس را انجام می‌دهد.

`xs` اسمی رایج برای دنباله‌ی یک لیست است و نشان می‌دهد که خودش یک لیست است، اما اگر با یک لیست تودرتو کار می‌کردید، می‌توانستید از `xss` استفاده کنید تا نشان دهید لیستی از لیست‌هاست.

## الگوی چندتایی

مانند لیست‌ها، می‌توانیم روی چندتایی‌ها هم تطبیق بدهیم.
در اینجا نمونه‌ای از تابعی را می‌بینیم که یک چندتایی می‌گیرد و عنصر اول و دوم را برمی‌گرداند:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

اینجا الگویی داریم که با یک چندتایی دو عنصری تطبیق می‌دهد؛ عنصر اول به `x` و عنصر دوم به `y` مقید می‌شود.

## الگوی عام

گاهی به مقدار یک متغیر اهمیتی نمی‌دهیم و فقط می‌خواهیم روی الگو تطبیق بدهیم.
اینجاست که الگوی عام به کار می‌آید؛ با یک زیرخط `_` نشان داده می‌شود.

در اینجا نمونه‌ای از تابعی را می‌بینیم که عنصر اول یک لیست را برمی‌گرداند:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

اینجا می‌گوییم که به دنباله‌ی لیست نیازی نداریم، بنابراین از الگوی عام استفاده می‌کنیم تا آن را نادیده بگیریم.

## الگوی نوع

می‌توانیم روی نوع‌ها هم تطبیق بدهیم؛ این کار با استفاده از سازنده‌ی آن نوع انجام می‌شود.
می‌توانیم مقادیر را هم از نوع استخراج کنیم، همان‌طور که با چندتایی‌ها انجام دادیم.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

در الگوی اول روی سازنده‌ی `Guest` تطبیق می‌دهیم و در الگوی دوم روی سازنده‌ی `User` تطبیق می‌دهیم و مقدار درونش را به `name` مقید می‌کنیم.

[pattern-matching]: https://en.wikibooks.org/wiki/Haskell/Pattern_matching
