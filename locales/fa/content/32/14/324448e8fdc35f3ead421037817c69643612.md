# دستورالعمل‌ها

وقتی گروهی از دوستان در حال برنامه‌ریزی برای یک شب بازی هستند، تصمیم می‌گیرند بازی‌های محبوب کودکی‌شان را دوباره زنده کنند. دوست آلمانی‌تان بازی _Mensch ärgere Dich nicht_ (یعنی _آدم، عصبانی نشو_) را پیشنهاد می‌کند؛ بازی‌ای کلاسیک در بسیاری از کشورهای اروپایی (شبیه _Ludo_ در انگلستان یا _Parcheesi_ در آمریکای شمالی).

برای آماده شدن برای بازی، تصمیم می‌گیرید تابع انداختن تاس را در Elixir پیاده‌سازی کنید.

در _Mensch ärgere Dich nicht_ بازیکنان برای تعیین حرکت بعدی خود یک تاس شش‌وجهی می‌اندازند. اگر خوش‌شانس باشند و ۶ بیاورند، می‌توانند دوباره تاس بیندازند و حرکت کنند.

## 1. یک بار تاس شش‌وجهی بیندازید

تابع `d6/0` را پیاده‌سازی کنید که در هر فراخوانی به‌صورت تصادفی یک عدد صحیح بین ۱ و ۶ انتخاب می‌کند.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. تا وقتی ۶ می‌آورید، انداختن تاس را ادامه دهید

تابع `roll/0` را پیاده‌سازی کنید. این تابع باید یک جریان از نتایج انداختن تاس را برگرداند. این نتایج باید از قواعد بازی پیروی کنند. اگر ۶ بیاورید، می‌توانید دوباره تاس بیندازید؛ در غیر این صورت، انداختن تاس را متوقف کنید. از تابع `d6/0` که در مرحله‌ی قبلی تعریف کردید استفاده کنید.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. امکان استفاده از تاس تقلبی را فراهم کنید

برای اینکه تست کردن کدتان راحت‌تر شود، امکان استفاده از یک تاس تقلبی را فراهم کنید.

تابع `roll/0` را گسترش دهید. این تابع باید یک آرگومان اختیاری، یعنی یک تابع، بپذیرد. اگر این آرگومان داده شود، از آن برای انداختن تاس استفاده کنید؛ در غیر این صورت، به `MenschAergereDichNicht.d6/0` رجوع کنید.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
