# پیوست دستورها

## پیام‌های استثنا

گاهی لازم است [یک «استثنا» مطرح کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** بگنجانید تا نشان دهید منبع خطا چیست. این کار کد شما را خواناتر می‌کند و کمک بزرگی به دیباگ کردن می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا از یک نوع مشخص است، می‌توانید یکی از [انواع خطای توکار](https://docs.python.org/3/library/exceptions.html#base-classes) را مطرح کنید، اما باز هم باید پیام معناداری همراه آن بگنجانید.

این تمرین خاص از شما می‌خواهد که وقتی آرگومانِ داده‌شده یک لیترال دودویی معتبر نیست، با [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) یک `ValueError` را «پرتاب» کنید. تست‌ها فقط زمانی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بگنجانید.

برای پرتاب یک `ValueError` همراه با پیام، پیام را به‌عنوان آرگومان به نوع `exception` بنویسید:

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
