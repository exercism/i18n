# راهنمایی‌ها

## کلی

- قرارداد بعد از نوع بازگشتی و قبل از `is` قرار می‌گیرد:

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- درون یک قرارداد می‌توانید از آرگومان‌ها و ویژگی‌های شیء استفاده کنید، بنابراین `limit` هم در دسترس است.
- تست‌ها بدون `-chk` ساخته می‌شوند، پس یک قرارداد نادرست باعث شکست آن‌ها نمی‌شود. آن‌ها را برای خواننده بنویسید.

## 1. مهار را آماده کنید

- `pre kg > 0`، روی `create`.
- بدنه همان `new` معمول است: ویژگی را مقدار بدهید و آن را برگردانید.

## 2. چقدر ظرفیت خالی است؟

- دو شرط که با `and` به هم پیوند خورده‌اند: `pre load >= 0 and load <= limit`.
- `post result >= 0`. این از `pre` نتیجه می‌شود و همین است که گفتنش را ارزشمند می‌کند: ثبت می‌کند چرا می‌توان به پاسخ اعتماد کرد.

## 3. چقدر پر است؟

- `pre load >= 0` و `post result >= 0`.
- `load * 100 / limit`، به همین ترتیب. اگر اول تقسیم کنید، همه‌چیز از بین می‌رود، همان‌طور که در `tuning-the-strings` نیز همین‌طور است.

## 4. آیا ایمن است؟

- اصلاً `pre` وجود ندارد: تمام نکته این است که ممکن است درباره‌ی هر باری پرسیده شود.
- `post` همان پرسش را دوباره بیان می‌کند: `post result = (load <= limit)`. پرانتزها، چون `=` دو بار برای دو چیز متفاوت به کار رفته است.
