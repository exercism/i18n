# مقدمه

گاهی اوقات نیازی به سربارِ ساختن یک شیء دارای حالت ندارید.
در چنین مواردی می‌توان از `module` استفاده کرد.

یک «ماژول» بسیار شبیه به یک کلاس است (در واقع، `Module` در سلسله‌مراتب اشیاء، جدِ `Class` است). تفاوت اصلی این است که به‌جای متدهای نمونه‌ای، از متدهای کلاس استفاده می‌کنیم.
متدهای کلاس با `self.` شروع می‌شوند و مستقیماً روی یک ماژول فراخوانی می‌شوند.

برای مثال:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
