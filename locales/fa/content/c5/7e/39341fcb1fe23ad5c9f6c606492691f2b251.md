# مقدمه

حلقه‌های `for` پیچیده‌ترین نوع حلقه در PHP هستند. آن‌ها مانند حلقه‌های `for` در `C`، `Java` و `JavaScript` عمل می‌کنند. شکل پایه‌ای آن این است:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

اولین عبارت (_expr1_) قبل از شروع حلقه ارزیابی می‌شود. دومین عبارت (_expr2_) قبل از هر تکرار ارزیابی می‌شود، اگر به یک مقدار _truthy_ ارزیابی شود، دستورات اجرا می‌شوند. پس از اجرای دستورات، سومین عبارت (_expr3_) ارزیابی می‌شود.
