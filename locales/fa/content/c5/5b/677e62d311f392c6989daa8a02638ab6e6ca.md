# مقدمه

## تبدیل نوع

در Go، تبدیل بین نوع‌های مختلف باید صریح باشد.
تبدیل بین نوع‌ها (که به آن **تبدیل نوع** هم می‌گویند) از طریق تابعی انجام می‌شود که اسم نوع مقصد را دارد.
برای نمونه، برای تبدیل یک `int` به `float64` باید به این شکل عمل کنید:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## تبدیل بین نوع‌های پایه و رشته‌ها

بسته‌ای به نام `strconv` برای تبدیل بین نوع‌های پایه (مثل `int`) و `string` وجود دارد.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## تأیید نوع

رابط‌ها در Go می‌توانند درباره‌ی نوع زیرین ابهام ایجاد کنند.
تأیید نوع به ما اجازه می‌دهد تا مقدار مشخص زیرینِ مقدار رابط را با این نحوه‌ی نگارش بیرون بکشیم: `interfaceVariable.(concreteType)`.

برای نمونه:

```go
var input any = 12
number := input.(int)
```

توجه: اگر متغیر رابط مقداری از نوع مشخص را نگه ندارد، این کار باعث `panic` می‌شود.

می‌توانیم با استفاده از هر دو مقدار بازگشتی تأیید نوع بررسی کنیم که آیا مقدار رابط یک نوع مشخص خاص را نگه می‌دارد یا نه: مقدار زیرین و یک «مقدار منطقی» که گزارش می‌دهد آیا تأیید موفق بوده است یا نه.
برای نمونه:

```go
str, ok := input.(string) // no panic if input is not a string
```

اگر `input` یک `string` نگه دارد، `str` مقدار زیرین خواهد بود و `ok` برابر با «درست» خواهد بود.
اگر `input` یک `string` نگه ندارد، `str` مقدار صفر نوع `string` خواهد بود (یعنی `""`، رشته‌ی خالی) و `ok` برابر با «غلط» خواهد بود.
در هیچ حالتی `panic` رخ نمی‌دهد.

## سوئیچ نوع

یک **سوئیچ نوع** می‌تواند چندین تأیید نوع را پشت سر هم انجام دهد.
نحوه‌ی نگارش آن همانند تأیید نوع است (`interfaceVariable.(concreteType)`)، اما `concreteType` با کلیدواژه‌ی `type` جایگزین می‌شود.
برای نمونه:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
