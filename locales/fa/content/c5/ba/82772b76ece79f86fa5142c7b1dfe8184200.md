# درباره

در Haxe، یک **آرایه** مجموعه‌ای از عناصر است که (معمولاً) از یک نوع‌اند. برای ساختن آرایه در Haxe سه راه وجود دارد: یا با سازنده، یا با نحوه‌ی نگارش اعلان. در Haxe، اندیس اولین عنصر آرایه صفر است:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

برای ساختن آرایه با سازنده، باید نوع عناصری را که قرار است در آرایه قرار بگیرند مشخص کنید:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

از آنجا که دسترسی به آرایه در Haxe نامحدود است، یعنی تضمین شده که استثنایی پرتاب نمی‌کند، این موضوع بحث بیشتری می‌طلبد:

- اگر خواندن روی اندیسی انجام شود که وجود ندارد، مقداری وابسته به هدف برگردانده می‌شود.
- اگر نوشتن با اندیسی مثبت انجام شود که خارج از محدوده است، در همه‌ی موقعیت‌های میان آخرین اندیس تعریف‌شده و اندیسی که تازه نوشته شده، `null` (یا مقدار پیش‌فرض انواع پایه در هدف‌های ایستا) درج می‌شود.
- اگر نوشتن با اندیس منفی انجام شود، نتیجه نامشخص است.

اگر بخواهیم آرایه‌ای چند نوع مختلف عنصر را در خود نگه دارد، نوع `Dynamic` را به مشخص‌کننده‌ی نوع اضافه می‌کنیم:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## پیمایش

می‌توان آرایه‌ها را با یک حلقه‌ی `for` پیمایش کرد:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
