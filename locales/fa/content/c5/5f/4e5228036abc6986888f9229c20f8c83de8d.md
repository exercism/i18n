# مقدمه

Common Lisp محمول‌های برابری مختلف و زیادی دارد.
این با زبان‌های برنامه‌نویسی دیگر که ممکن است فقط یکی یا دو محمول داشته باشند تفاوت دارد (برای نمونه، شاید `==` و `===`).
برخی از این محمول‌ها در Common Lisp مخصوص نوع خاصی هستند، در حالی که برخی دیگر عمومی‌اند.
در این مطلب به همین دسته‌ی دوم می‌پردازیم.

چهار محمول برابری عمومی وجود دارد و تفاوتشان در میزان سختگیری آن‌ها درباره‌ی این است که چه چیزی را «برابر» در نظر می‌گیرند.
این چهار محمول، به ترتیب از سختگیرترین تا آسان‌گیرترین عبارت‌اند از: `eq`، `eql`، `equal` و `equalp`.

تعریف‌های کوتاه آن‌ها (با نادیده گرفتن چند جزئیات) به این شرح است:

- `eq`: برابری را به این معنا تعریف می‌کند که دو شیء یکسان‌اند.
  _برای نمونه:_

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: برابری را به این معنا تعریف می‌کند: دو عدد با نوع و مقدار یکسان، دو کاراکتر که یکسان‌اند،
  یا برای هر مورد دیگری اگر `eq` باشند.
  _برای نمونه:_

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: برابری را به این معنا تعریف می‌کند: دو لیست `equal` هستند اگر هر عنصر آن‌ها نیز `equal` باشد؛ دو رشته `equal` هستند اگر هر عنصر آن‌ها `eql` باشد؛ دو آرایه `equal` هستند اگر `eq` باشند؛ و هر مورد دیگری `equal` است اگر `eql` باشد.
  _برای نمونه:_

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: برابری را به این معنا تعریف می‌کند: رشته‌ها و کاراکترها بدون توجه به بزرگی و کوچکی حروف مقایسه می‌شوند؛ اعداد با مقداری تبدیل نوع مقایسه می‌شوند؛ لیست‌ها و آرایه‌ها `equalp` هستند اگر هر عنصر آن‌ها نیز `equalp` باشد، ساختارها اگر از نوع یکسان باشند و همه‌ی اسلات‌هایشان `equalp` باشند و جدول‌های هش اگر کلیدها و مقادیرشان `equalp` باشند
  _برای نمونه:_

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
