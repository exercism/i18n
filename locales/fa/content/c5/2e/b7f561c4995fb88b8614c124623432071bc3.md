# دستورالعمل‌ها

در این تمرین، شما پیام‌های لاگ نیمه‌ساخت‌یافته تولید می‌کنید.

## پیام‌های نیمه‌ساخت‌یافته تولید کنید

شما با چند تابع آماده و `enum` زیر شروع می‌کنید:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

هدف شما تولید یک پیام لاگ به شکل زیر است: `"[<LEVEL>]: <MESSAGE>"`.
باید توابعی را پیاده‌سازی کنید که با سطح‌های لاگ متناظرند.

برای مثال، قطعه‌کد زیر خروجی مورد انتظار برای تابع `log` را نشان می‌دهد.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

و برای `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

خوش بگذرانید!
