# دستورالعمل‌ها

یک مدرسه‌ی محلی نزدیک شما یک انجمن دانش‌آموزی بسیار فعال دارد.
انجمن دانش‌آموزی توسط یک رئیس اداره می‌شود و هر ۲ سال یک‌بار،
انتخابات برای انتخاب رئیس جدید برگزار می‌شود.

در انتخابات امسال، تصمیم گرفته شد که به یک سیستم دیجیتال جدید برای شمارش آرا نیاز است.
مدرسه برای ساختن این سیستم جدید به کمک شما نیاز دارد.

## 1. یک شمارنده‌ی آرا بسازید

یکی از اولین مواردی که سیستم رأی‌گیری جدید به آن نیاز دارد، یک شمارنده‌ی آرا است.
این شمارنده راهی است برای پیگیری آرای یک نامزد مشخص.

تابعی به اسم `NewVoteCounter` بسازید که تعداد آرای اولیه‌ی یک نامزد را می‌پذیرد و یک اشاره‌گر به یک `int` برمی‌گرداند که با تعداد آرای اولیه‌ی داده‌شده مقداردهی شده است.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. تعداد آرا را از یک شمارنده بگیرید

حالا راهی برای ساختن شمارنده‌های جدید دارید! اما اکنون متوجه می‌شوید که سیستم جدید به راهی برای گرفتن تعداد آرا از یک شمارنده هم نیاز خواهد داشت.

تابعی به اسم `VoteCount` بسازید که یک شمارنده (`*int`) را به عنوان آرگومان می‌گیرد و تعداد آرا در شمارنده را برمی‌گرداند.
اگر شمارنده `nil` باشد، باید فرض کنید که شمارنده هیچ رأیی ندارد:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. آرا را در یک شمارنده افزایش دهید

بالاخره وقت شمارش آرا رسیده است! حالا به راهی برای افزایش آرا در یک شمارنده نیاز دارید.

تابعی به اسم `IncrementVoteCount` بسازید که یک شمارنده (`*int`) و تعدادی رأی را به عنوان آرگومان می‌گیرد و شمارنده را به اندازه‌ی آن تعداد آرا افزایش می‌دهد.
می‌توانید فرض کنید اشاره‌گری که پاس داده می‌شود هرگز `nil` نخواهد بود.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. نتایج انتخابات را بسازید

حالا که همه‌ی آرا شمرده شده‌اند، وقت آن است که اعلام نتیجه برای کل مدرسه آماده شود.
برای این کار، متوجه می‌شوید که فقط داشتن شمارنده برای آرا کافی نیست.
باید راهی وجود داشته باشد که تعداد آرا را به یک نامزد مشخص مرتبط کند.

تابعی به اسم `NewElectionResult` بسازید که اسم یک نامزد و تعداد آرای او را دریافت می‌کند و یک نتیجه‌ی انتخاباتی جدید برمی‌گرداند.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

ساختار نتیجه‌ی انتخابات از قبل برایتان ساخته شده است و به این صورت تعریف می‌شود:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. نتایج را اعلام کنید

وقت آن است که رئیس جدید را به مدرسه اعلام کنید!
رئیس در تابلوهای پیام دیجیتال کوچکی که مدرسه دارد اعلام خواهد شد.
پیام باید اسم رئیس جدید و تعداد آرای او را با قالب زیر نشان دهد: `<candidate_name> (<votes>)`.
این نمونه‌ای از چنین پیامی است: `"Peter (51)"`.

تابعی به اسم `DisplayResult` بسازید که یک `*ElectionResult` را به عنوان آرگومان دریافت می‌کند و رشته‌ای با پیام قابل نمایش برمی‌گرداند.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. بازشماری آرا

برای اطمینان از درستی نتایج نهایی، آرا دوباره شمرده شدند.
در بازشماری مشخص شد که تعداد آرای برخی از نامزدها یک واحد اختلاف داشت.

تابعی به اسم `DecrementVotesOfCandidate` بسازید که نتایج نهایی و اسم نامزدی را دریافت می‌کند که باید تعداد آرای او را کاهش دهید.
نتایج نهایی به شکل یک `map[string]int` داده می‌شوند که کلیدها اسم نامزدها و مقادیر کل آرای آن‌ها هستند.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
