# مقدمه

عملگرهای اصلی حسابی و مقایسه‌ای را می‌توان برای استفاده در کلاس‌ها و ساختارهای خودتان تطبیق داد. به این کار «سربارگذاری عملگر» می‌گویند.

بیشتر عملگرها به این شکل هستند:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

عملگرهای تبدیل به این شکل هستند:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

عملگرها مانند متدهای ایستا رفتار می‌کنند. یک نماد عملگر جای شناسه‌ی متد را می‌گیرد و آن‌ها پارامتر و نوع بازگشتی دارند. قواعد نوع برای پارامترها و نوع بازگشتی با شهود شما همخوانی دارند و می‌توانید به کامپایلر تکیه کنید تا راهنمایی دقیق ارائه دهد.
