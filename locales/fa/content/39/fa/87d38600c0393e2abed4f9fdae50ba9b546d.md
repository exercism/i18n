# مقدمه

جدول هش در Common Lisp ساختاری داده‌ای برای ذخیره‌ی داده‌های انجمنی است.
آن‌ها کلیدها (که می‌توانند هر شیءای باشند) را به مقدارها (که می‌توانند هر شیءای باشند) نگاشت می‌کنند.
زبان‌های دیگر ممکن است این مفهوم را map یا dictionary یا hash بنامند.

## ساختن جدول هش

جدول هش را می‌توان با تابع `make-hash-table` ساخت.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(توجه کنید که شکل چاپ‌شده‌ی جدول هش به پیاده‌سازی وابسته است، پس ممکن است در REPL شما متفاوت به نظر برسد.)

## بازیابی مقدارها با کلیدها

برای گرفتن یک مقدار با یک کلید از جدول هش، از تابع `gethash` استفاده می‌کنید:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` [چند مقدار][concept-multiple-values] برمی‌گرداند که در مفهوم دیگری توضیح داده می‌شود.

## درج مقدارها

برای درج یک مقدار در جدول هش، `setf` را همراه با `gethash` این‌طور به کار می‌برید:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

این کار مقدار کلید `:foo` را در جدول هش `*hash-table*` به `:bar` تغییر می‌دهد.
و مقدار را برمی‌گرداند.

کاربرد `setf` در مفهوم دیگری توضیح داده خواهد شد.
