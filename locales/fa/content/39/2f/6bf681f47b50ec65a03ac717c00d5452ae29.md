# مقدمه

## Alias

برای به اشتراک گذاشتن کد بین ماژول‌های مختلف Elixir در یک پروژه، باید ماژول بیرونی را با اسم کاملش ارجاع دهید. اما اگر آن اسم خیلی طولانی یا گیج‌کننده باشد چه؟

فرم ویژه‌ی `alias` به شما اجازه می‌دهد اسمی را که با آن به یک ماژول بیرونی ارجاع می‌دهید کوتاه‌تر کنید یا تغییر دهید. وقتی بدون هیچ آرگومانی استفاده شود، اسم ماژول را به آخرین بخش آن کوتاه می‌کند؛ برای مثال `MyApp.Logger.Settings` به `Settings` تبدیل می‌شود. می‌توانید با گزینه‌ی `:as` یک اسم دلخواه تعیین کنید.

معمولاً این کار در ابتدای تعریف ماژول انجام می‌شود.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

فرم ویژه‌ی `import` به شما اجازه می‌دهد از توابع یک ماژول بیرونی بدون آوردن اسم آن ماژول استفاده کنید.

وارد کردن یک ماژول بیرونی به‌صورت کامل ممکن است با توابع محلی موجود تعارض ایجاد کند. برای جلوگیری از این کار، دو گزینه در دسترس است: `:except` و `:only`. هر دو یک لیست کلیدواژه می‌گیرند که کلید آن، اسم تابع و مقدار آن، تعداد آرگومان‌های تابع است.

معمولاً این کار هم در ابتدای تعریف ماژول انجام می‌شود.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
