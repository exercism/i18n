# دستورالعمل‌ها

یکی از دوستانتان یک فروشگاه عمده‌فروشی قدیمی به اسم **Gross Store** دارد.

این اسم از مقدار کالایی می‌آید که فروشگاه می‌فروشد: همه‌ی مقدارها بر حسب [واحد گروس][gross-unit] بیان می‌شوند.

دوستانتان از شما خواسته است که یک سیستم نقطه‌ی فروش (POS) برای فروشگاهش پیاده‌سازی کنید.

**اول، می‌خواهید برای آن یک نمونه‌ی اولیه بسازید.**

**در نمونه‌ی اولیه‌تان، سیستم شما فقط مقدار را ثبت می‌کند.**

دوستانتان برای کمک به شما فهرستی از واحدهای اندازه‌گیری داده است:

| واحد               | مقدار |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. واحد اندازه‌گیری را در برنامه‌تان ذخیره کنید

برای استفاده از اندازه‌گیری، باید آن را در برنامه‌تان ذخیره کنید.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. یک صورت حساب جدید برای مشتری بسازید

باید تابعی پیاده‌سازی کنید که یک صورت حساب جدید (خالی) برای مشتری می‌سازد.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. یک کالا به صورت حساب مشتری اضافه کنید

برای پیاده‌سازی این مورد، باید:

- اگر `unit` داده‌شده در نگاشت `units` نباشد، `false` را برگردانید.
- در غیر این صورت، کالا را با کلید اسم کالا به `bill` مشتری اضافه کنید و سپس `true` را برگردانید.
- اگر کالا از قبل در صورت حساب موجود باشد، مقدارش را به اندازه‌ی مقداری که به `unit` داده‌شده تعلق دارد افزایش دهید.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> توجه کنید که مقدار برگردانده‌شده از نوع `bool` است.

## 4. یک کالا را از صورت حساب مشتری حذف کنید

برای پیاده‌سازی این مورد، باید:

- اگر کالای داده‌شده در صورت حساب **نباشد**، `false` را برگردانید.
کالایی که مقدارش ۰ باشد، در صورت حساب موجود به حساب نمی‌آید.
- اگر `unit` داده‌شده در نگاشت `units` نباشد، `false` را برگردانید.
- اگر مقدار جدید کمتر از ۰ شود، `false` را برگردانید.
- اگر مقدار جدید ۰ باشد، کالا حذف‌شده از `bill` به حساب می‌آید، بنابراین می‌توانید `true` را برگردانید.
- در غیر این صورت، مقدار کالا را کم کنید و `true` را برگردانید.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> توجه کنید که مقدار برگردانده‌شده از نوع `bool` است.

## 5. مقدار یک کالای مشخص را که در صورت حساب مشتری است برگردانید

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> توجه کنید که مقدار برگردانده‌شده از نوع `u32` است.
