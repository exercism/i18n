# عدد

`INT` نوع ساتر برای اعداد صحیح است: `0`، `7`، `-3`. تابعی که با عدد صحیح پاسخ می‌دهد، این را بعد از دونقطه می‌نویسد. تابعی هم که با متن پاسخ می‌دهد، `STR` می‌گوید.

```sather
   goals : INT is
      return 42;
   end;
```

توابع می‌توانند **آرگومان** بگیرند، یعنی مقادیری که هنگام فراخوانی تابع به آن داده می‌شوند. برای هر آرگومان یک اسم و یک نوع تعیین می‌شود، داخل پرانتز بعد از اسم تابع:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

وقتی دو آرگومان یک نوع دارند، می‌توانید آن‌ها را با هم اسم‌گذاری کنید:

```sather
   total(first, second : INT) : INT is
```

برای فراخوانی، مقادیر را داخل پرانتز بگذارید:

```sather
SCORES::total(3, 4)     -- this is 7
```

پنج عملگر حسابی عبارت‌اند از `+`، `-`، `*`، `/` و `%`.

`/` روی دو `INT`، **تقسیم صحیح** است: به‌جای دادن کسر، باقی‌مانده را دور می‌ریزد.

```sather
7 / 2      -- 3, not 3.5
```

`%` باقی‌مانده‌ی آن تقسیم را می‌دهد.

```sather
7 % 2      -- 1
```

این دو به هم مربوط‌اند: `7` یعنی `3` بار `2` و `1` باقی‌مانده.
