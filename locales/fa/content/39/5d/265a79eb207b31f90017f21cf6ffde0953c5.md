# مقدمه

یک «لیست» در Gleam مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار است. مقادیر یک لیست باید همگی از یک نوع باشند. چون لیست‌ها تغییرناپذیرند، پس از آنکه یک لیست ساخته شد، مقدارش هرگز تغییر نمی‌کند. هر تابع یا عملگری که به نظر برسد لیست را تغییر می‌دهد (مثل افزودن یک عنصر)، در واقع یک لیست تازه برمی‌گرداند.

لیست‌ها را می‌توان به این شکل تعریف کرد:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

رایج‌ترین راه برای افزودن یک عنصر به یک لیست، استفاده از «spread» است:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

ماژول [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) در کتابخانه‌ی استاندارد Gleam توابع مفید زیادی برای کار با لیست‌ها دارد. این ماژول در کد Gleam بسیار پرکاربرد است، بنابراین خوب است که با آن آشنا باشید.

الگوهای لیست را می‌توان در عبارات `case` به کار برد تا روی لیست‌ها تطبیق انجام شود و مقادیر داخل آن‌ها به متغیرها نسبت داده شود:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

علاوه بر تطبیق روی لیست‌هایی با طول دقیق، می‌توان از «spread» برای تطبیق روی لیست‌هایی با حداقل یک طول مشخص استفاده کرد:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

همچنین می‌توان از «spread» برای نسبت دادن باقی لیست به یک متغیر استفاده کرد:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

عبارات `case` باید برای هر مقدار ممکن از نوعی که روی آن تطبیق انجام می‌شود الگویی داشته باشند، بنابراین اغلب از یک الگوی نادیده‌گرفتن (`_`) در انتها استفاده می‌شود تا هر مقدار باقی‌مانده را پوشش دهد.
