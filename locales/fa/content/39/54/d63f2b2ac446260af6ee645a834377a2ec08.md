# درباره

PHP چندین ساختار کنترلی توکار برای ساخت «حلقه» دارد، مانند `while`. شکل پایه‌ی یک دستور `while` چنین است:

```php
while (expr) {
  // statements
}
```

تا زمانی که عبارت (_expr_) به یک مقدار «درست» ارزیابی شود، دستورهای درون حلقه بارها اجرا می‌شوند. اگر عبارت (_expr_) پیش از اولین تکرار به «غلط» ارزیابی شود، دستورها هرگز اجرا نمی‌شوند.

در عوض، می‌توانید از حلقه‌ی `do-while` استفاده کنید که دستورهای درون حلقه را یک‌بار پیش از ارزیابی عبارت (_expr_) اجرا می‌کند.

```php
do {
  // statements
} while (expr);
```
