# مقدمه

«خطاها» برای گزارش دادن زمانی مفیدند که چیزی در یک برنامه یا تکه‌ای از کد اشتباه یا غیرمنتظره باشد.

آن‌ها اشیای JavaScript هستند.

ویژگی اصلی این شیء `message` است:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

با استفاده از نحوه‌ی نگارش `throw`، می‌توانید یک `Error` پرتاب کنید.

```javascript
throw new Error('Oops');
```

وقتی یک `Error` پرتاب می‌شود، اجرای فعلی متوقف می‌شود و در اولین بلوک `catch` از پشته‌ی فراخوانی ادامه می‌یابد.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

مانند هر کلاس دیگری در JavaScript، زیرکلاس‌ها می‌توانند با استفاده از کلیدواژه‌ی `extends` از `Error` ارث‌بری کنند تا خطاهای سفارشی بسازند.
نحوه‌ی نگارش `instanceof` بررسی می‌کند که خطای گرفته‌شده نمونه‌ای از یک زیرکلاس خاص `Error` هست یا نه.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
