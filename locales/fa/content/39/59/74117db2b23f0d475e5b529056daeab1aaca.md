# دستورالعمل‌ها

تمرین نتبال با دویدن چند دور شروع می‌شود. مربی هر دور را کمی طولانی‌تر از دور قبلی می‌کند: دور اول ۱۰۰ متر است، دور دوم ۱۱۰، دور سوم ۱۲۰ و به همین ترتیب، هر بار ۱۰ متر بیشتر.

هر سه تمرین در کلاس `WARM_UP_LAPS` قرار می‌گیرند.

## 1. در مجموع چقدر؟

با داشتن تعداد دورها، مسافت کل را محاسبه کنید.

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

یعنی ۱۰۰ + ۱۱۰ + ۱۲۰. صفر دور، صفر متر است.

## 2. چند دور برای طی کردن یک مسافت لازم است؟

اگر مسافتی بر حسب متر داشته باشیم، چند دور لازم است تا مجموع دست‌کم به همان اندازه برسد؟

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

مسافت صفر متر هیچ دوری لازم ندارد.

## 3. کدام دور اول از همه طولانی می‌شود؟

اگر مسافتی بر حسب متر داشته باشیم، کدام دور اولین دوری است که *خودش* از آن مسافت طولانی‌تر است؟ دور اول ۱۰۰ متر است، دور دوم ۱۱۰ و به همین ترتیب.

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

دور سوم ۱۲۰ متر است، یعنی اولین دوری که از ۱۱۵ بیشتر است.
