# پیوست دستورالعمل‌ها

## توابع و Test

یک تعریف اولیه برای تابع `SayHi` در اختیار شما قرار گرفته است.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

test runner این تابع را می‌گیرد و اجرا می‌کند و مقداری که [برمی‌گرداند][returns] را با مقداری که انتظار دارد مقایسه می‌کند.
از این تعریف اولیه‌ی تابع به عنوان پایه‌ی راه‌حل خود استفاده کنید.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
