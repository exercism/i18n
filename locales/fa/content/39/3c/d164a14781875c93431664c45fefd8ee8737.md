# تاپل

«تاپل»ها در Elm می‌توانند دو یا سه مقدار را در خود نگه دارند و هر مقدار می‌تواند هر نوعی داشته باشد.
در Elm، از تاپل‌ها بیشتر برای انواع ساده و گذرا استفاده می‌شود.
به همین دلیل، تاپل‌ها حداکثر ۳ مقدار را نگه می‌دارند و برای تشویق بیشتر، توابع کمکی فقط برای ۲ مقدار ارائه شده‌اند.
برای داده‌های پیچیده‌تر، بهتر است به «رکورد»ها روی بیاورید.
یک کاربرد رایج آن جایی است که بخواهید بیش از یک مقدار را از یک تابع برگردانید.
فیلدهای تاپل اسم ندارند و از طریق ساختارشکنی یا بر اساس موقعیت به آن‌ها دسترسی پیدا می‌کنید.

می‌توانید یک [معرفی مختصر از تاپل‌ها][tuples-concise] را بخوانید.
[معرفی جامع‌تر][tuples-in-depth] هم وجود دارد و [مستندات API ماژول Tuple][tuple-core] شامل نمونه‌های کد و مستندات مفصل است.

## اعلان

نوع‌های تاپل با پرانتز ساخته می‌شوند و نوع عناصرشان با ویرگول از هم جدا می‌شود.

```elm
type alias IntStringTuple = (Int, String)
```

### ساخت

تاپل‌ها با پرانتز ساخته می‌شوند و عناصرشان با ویرگول از هم جدا می‌شود.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

همچنین می‌توانید با `Tuple.pair` تاپلی با دو مقدار بسازید.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### دسترسی

توابعی هم برای دسترسی به مقدارهای تاپل بر اساس موقعیت وجود دارد: `Tuple.first` و `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

می‌توان تاپل‌ها را در اتصال‌ها با استفاده از تطبیق الگوی تاپل _ساختارشکنی_ کرد.
ساختارشکنی را می‌توان در عبارت‌های `let`، اعلان‌های تابع و دستورهای `case` انجام داد.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

تطبیق الگو در دستور `case` هم به شما اجازه می‌دهد روی محتوای مقادیر تطبیق انجام دهید:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
