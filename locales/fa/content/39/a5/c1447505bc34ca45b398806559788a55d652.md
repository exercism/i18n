# مقدمه

یک `list` در R مجموعه‌ای مرتب از عنصرها است که در چند مورد با `vectors` تفاوت دارد:

- عنصرها می‌توانند از انواع مختلف باشند (مثلاً ترکیب `numeric` با `character`).
- عنصرها می‌توانند ساختارهای پیچیده باشند (مثلاً بردارها، فهرست‌های دیگر و غیره).
- نحوه‌ی نگارش دسترسی به عنصرها هم کمی فرق دارد.

قیاس با زبان‌های دیگر دقیق نیست.
یک `list` در R تا حدی شبیه دیکشنری در Python است، اما `list` مرتب است و می‌توان با اندیس عددی به آن دسترسی داشت.
تا حدی هم شبیه `struct` در C است، با این تفاوت که `list` را می‌توان به‌راحتی در زمان اجرا گسترش داد.

## ساختن فهرست

دادن اسم به عنصرها (که اغلب «برچسب» نامیده می‌شود) در فهرست‌ها رایج‌تر از بردارها است:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

اما برچسب‌ها اختیاری‌اند و در آن صورت R فقط از شماره‌های اندیس استفاده می‌کند:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## دسترسی به عنصرهای فهرست

سه راه برای این کار وجود دارد که هرکدام در موقعیت‌های متفاوتی به کار می‌آید.

### ۱. با نشانه‌گذاری `$tag`

اگر اسم برچسب‌ها از پیش معلوم باشد، بسیار رایج است.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### ۲. با نشانه‌گذاری `[[tag]]`

مزیت این روش آن است که اسم برچسب را می‌توان در زمان اجرا انتخاب کرد.
به کروشه‌های دوتایی دقت کنید.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### ۳. با اندیس موقعیت

این روش چه فهرست برچسب داشته باشد و چه نداشته باشد کار می‌کند.
باز هم، کروشه‌ها دوتایی‌اند.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## افزودن و حذف عنصرها

ساده است: اگر به عنصری مقدار بدهید، در صورت وجود تغییر می‌کند و اگر تازه باشد درج می‌شود.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

برای حذف، مقدار `NULL` را به عنصر ناخواسته بدهید.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
