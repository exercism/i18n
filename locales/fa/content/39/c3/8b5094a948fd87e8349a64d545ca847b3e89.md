# دستورالعمل‌ها

تفاوت بین مربع مجموع و مجموع مربع‌های N عدد طبیعی نخست را پیدا کنید.

مربع مجموع ده عدد طبیعی نخست برابر است با
(۱ + ۲ + ... + ۱۰)² = ۵۵² = ۳۰۲۵.

مجموع مربع‌های ده عدد طبیعی نخست برابر است با
۱² + ۲² + ... + ۱۰² = ۳۸۵.

بنابراین تفاوت بین مربع مجموع ده عدد طبیعی نخست و مجموع مربع‌های ده عدد طبیعی نخست برابر است با ۳۰۲۵ - ۳۸۵ = ۲۶۴۰.

انتظار نمی‌رود که خودتان از اصول اولیه راه‌حلی کارآمد برای این مسئله کشف کنید؛ پژوهش کردن مجاز است، بلکه تشویق هم می‌شود.
یافتن بهترین الگوریتم برای این مسئله، مهارتی کلیدی در مهندسی نرم‌افزار است.
