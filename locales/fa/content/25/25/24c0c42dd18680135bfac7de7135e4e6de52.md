# اجرای testها

برای کامپایل و اجرای testها، فقط موارد زیر را در پوشه‌ی تمرینتان اجرا کنید:
```bash
$ ponyc
$ ./exercise-name
```

(`exercise-name` را با اسم پوشه‌ی تمرین جایگزین کنید)

فایل باینری کامپایل‌شده testها را در Main actor خود اجرا می‌کند، پس فقط فایل باینری را اجرا کنید و ببینید testهایتان قبول شده‌اند یا نه. Pony تمام code را در زمان کامپایل بررسی می‌کند، بنابراین ممکن است متوجه شوید که testهایتان تا زمانی که code لازم را ننوشته‌اید، کامپایل نمی‌شوند. می‌توانید testهایی را که کامپایل نمی‌شوند، با شروع کردن هر خط با `//` کامنت کنید. سپس، وقتی آماده شدید روی آن test کار کنید، می‌توانید کامنت آن را بردارید.
