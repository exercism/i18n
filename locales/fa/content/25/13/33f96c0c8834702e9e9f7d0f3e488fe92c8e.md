# دستورالعمل‌ها

در این تمرین، برای یک ایستگاه خبری محلی گزارش آب‌وهوا تولید می‌کنید.

## تولید گزارش‌های آب‌وهوا

کار را با چند تابع ناقص و `enum` زیر شروع می‌کنید:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

باید گزارشی آب‌وهوایی را به شکل `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."` قالب‌بندی کنید.
باید تابعی را پیاده‌سازی کنید که وضعیت آب‌وهوای درست را خروجی می‌دهد.

برای مثال، قطعه‌کد زیر خروجی موردانتظار تابع `get_weather_report` را برای یک روز بارانی نشان می‌دهد.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

و برای یک روز آفتابی:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
