# دستورالعمل‌ها

شما با یک تیم توسعه‌ی وب کار می‌کنید که وب‌سایتی برای یک تیم بسکتبال محلی نگهداری می‌کند. تیم توسعه‌ی وب با Elixir آشنایی کمتری دارد و می‌خواهد تابعی داشته باشد که بتواند داده‌ها را از مجموعه‌های تودرتوی «نگاشت» استخراج کند تا توسعه سریع‌تر پیش برود.

## 1. استخراج داده از یک ساختار نگاشت تودرتو

تابع `extract_from_path/2` را طوری پیاده‌سازی کنید که دو آرگومان بگیرد:

- `data`: یک ساختار نگاشت تودرتو که داده‌های مربوط به تیم بسکتبال را در خود دارد.
- `path`: رشته‌ای متشکل از کلیدهای جداشده با نقطه، برای به دست آوردن مقدار متناظر با آخرین کلید.

اگر مقدار یا کلید در هیچ نقطه‌ای از مسیر وجود نداشته باشد، باید `nil` برگردانده شود

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

هنگام پیاده‌سازی این تابع از _Access Behaviour_ استفاده کنید.

برای کار با ساختار نگاشت تودرتو از هیچ‌یک از توابع ماژول `Map` یا `Kernel` استفاده نکنید.

## 2. بازنویسی با استفاده از توابع از پیش موجود

همکارتان که در حال بازبینی کد شماست، از تابعی در ماژول `Kernel` به شما می‌گوید که کارش بسیار شبیه پیاده‌سازی شماست.

تابع `get_in_path/2` را طوری پیاده‌سازی کنید که از این تابع ماژول `Kernel` استفاده کند.

آرگومان‌های مورد انتظار همانند بخش ۱ هستند.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
