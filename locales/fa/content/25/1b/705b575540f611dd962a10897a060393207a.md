# درباره

یک [«تاپل»](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) یک گروه‌بندی _تغییرناپذیر_ از مقادیر بی‌نام اما مرتب است.
تاپل‌ها می‌توانند هر نوع داده (یا چند نوع داده) را در خود نگه دارند، از جمله تاپل‌های دیگر.

تاپل‌ها به‌صورت مقادیری تعریف می‌شوند که با کاما از هم جدا شده و بین کاراکترهای `(` و `)` قرار می‌گیرند: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

فقط تاپل‌هایی با طول یکسان و انواع یکسان (با همان ترتیب) را می‌توان مقایسه کرد.
تاپل‌ها برابری ساختاری دارند، یعنی _فقط_ زمانی برابرند که همه‌ی مقادیرشان برابر باشند.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

[سه روش برای استخراج مقادیر از یک تاپل](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) وجود دارد:

- توابع `fst` و `snd`
- «تجزیه‌ی تاپل»
- «تطبیق الگو»

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
از نظر فنی، می‌توانید به مقدار یک تاپل با استفاده از ویژگی‌های `.Item1`، `.Item2`، ... دسترسی داشته باشید، اما این کار توصیه نمی‌شود و به هشدار کامپایلر منجر می‌شود.
~~~~

## نکات کلیدی درباره‌ی تاپل

چند نکته‌ی کلیدی که باید درباره‌ی تاپل بدانید:

- یک نمونه‌ی خاص از نوع تاپل، یک شیء واحد است، مانند یک آرایه‌ی دو عنصری در C#. وقتی از آن‌ها در توابع استفاده می‌کنید، به‌عنوان یک پارامتر واحد به حساب می‌آیند. تنها استثنا زمانی است که کد غیر F# را با چندین پارامتر فراخوانی می‌کنید؛ در این حالت یک تاپل می‌فرستید و مقادیر آن به‌طور خودکار به مقدار پارامترهای متناظر نسبت داده می‌شوند.
- به انواع تاپل نمی‌توان نام صریح داد. «نام» نوع تاپل از ترکیب نوع‌هایی که در هم ضرب می‌شوند مشخص می‌شود.
- کاما نماد حیاتی‌ای است که تاپل را تعریف می‌کند، نه پرانتز. می‌توانید تاپل را بدون پرانتز تعریف کنید، هرچند این کار گاهی می‌تواند گیج‌کننده باشد. در F#، اگر کامایی ببینید، احتمالاً بخشی از یک تاپل است.
- از تاپل‌ها می‌توان به‌عنوان آرگومان تابع و مقدار بازگشتی تابع استفاده کرد.
