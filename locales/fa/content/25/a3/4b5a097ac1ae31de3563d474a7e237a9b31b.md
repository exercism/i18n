## اجرای Test‌ها

1. به ریشه‌ی پوشه‌ی تمرین PHP خود بروید، یعنی `<EXERCISM_WORKSPACE>/php`.
   برای پیدا کردن فضای کاری Exercism این دستور را اجرا کنید

   ```shell
   exercism workspace
   ```

2. اگر [PHPUnit] را هنوز نصب نکرده‌اید، آن را نصب کنید.
3. Test‌ها را با این دستور اجرا کنید:

   ```shell
   phpunit test_file.php
   ```

   برای نمونه، برای اجرای Test‌های تمرین Hello World، این دستور را اجرا می‌کنید:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
