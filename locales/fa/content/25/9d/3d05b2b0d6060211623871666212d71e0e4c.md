# دستورالعمل‌ها

شما هر روز شمار پرندگانی را که به باغتان می‌آیند ثبت می‌کنید. داده‌ها
به‌صورت یک آرایه از اعداد صحیح ذخیره می‌شوند، با **شمار امروز در ابتدای آن**.

## 1. شمار امروز

`today` را طوری تعریف کنید که یک آرایه از شمارهای روزانه را از پشته بردارد و
شمار امروز را برگرداند، یا اگر آرایه خالی بود `f` را برگرداند.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. افزایش شمار امروز

`increment-day-count` را طوری تعریف کنید که آرایه‌ای تازه برگرداند که شمار
امروز در آن یک واحد افزایش یافته باشد. اگر ورودی خالی بود، `{ 1 }` را
برگردانید.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. آیا روزی بدون پرنده وجود داشته است؟

`has-day-without-birds?` را طوری تعریف کنید که اگر دست‌کم در یک روز صفر
پرنده ثبت شده باشد `t` و در غیر این صورت `f` را برگرداند.

**از بازگشت استفاده کنید**، نه از `any?` یا سایر واژه‌های دنباله‌ی
مرتبه‌بالاتر.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. شمار کل پرندگان از زمانی که شروع کرده‌اید

`total` را طوری تعریف کنید که مجموع همه‌ی شمارها را برگرداند.

**از بازگشت استفاده کنید**، نه از `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. روزهای پرمشغله

روز پرمشغله روزی است که در آن ۵ پرنده یا بیشتر باشد. `busy-days` را طوری
تعریف کنید که تعداد روزهای پرمشغله را برگرداند.

**از بازگشت استفاده کنید**، نه از `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
