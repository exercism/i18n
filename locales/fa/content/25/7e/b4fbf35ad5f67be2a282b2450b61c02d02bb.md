# دستورالعمل‌ها

وقتی موجودات فضایی Lisp نخستین بار به زمین آمدند، با بی‌شمار پدیده‌ی عجیب و شگفت‌انگیز روبه‌رو شدند، اما یکی از محبوب‌ترین کشف‌هایشان «حیوان خانگی» بود. انصافاً کدام موجود فضایی است که با دیدن یک توله‌سگ یا بچه‌گربه ذوق نکند؟

لودویگ، بعد از سفر تفریحی اخیرش به زمین، تصمیم گرفته است که حیوان خانگی خودش را داشته باشد! تنها مشکل چیست؟ حق انتخاب بیش از حد! شاید بتوانید برنامه‌ای بنویسید که به لودویگ کمک کند دوست پشمالوی بعدی‌اش را پیدا کند و از او نگهداری کند؟

## 1. انتخاب یک همدم

لودویگ هرچند مصمم است که حیوان خانگی بگیرد، اما فکرش تا همین‌جا بیشتر نرفته است. پس اولین قدم این است که تصمیم بگیرد چه نوع حیوان خانگی‌ای بگیرد!

لودویگ می‌خواهد همدمی پیدا کند که شخصیتش مکمل شخصیت خودش باشد. می‌توانید برای لودویگ تابعی به اسم `pal-picker` بنویسید که یک ویژگی شخصیتی (یک کلیدواژه) می‌گیرد و نوع حیوان خانگی (یک رشته) با آن ویژگی را برمی‌گرداند؟

در این مورد خاص:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

برای سایر شخصیت‌های ناشناخته، تابع شما باید به این مقدار ارزیابی شود: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. در زیستگاه طبیعی خودش

حالا که لودویگ یک دوست جدید دارد، به جایی برای زندگی نیاز دارد! می‌توانید به لودویگ کمک کنید اندازه‌ی درست تخت / آکواریوم / قفس را برای حیوان خانگی‌اش انتخاب کند؟

اینجا لودویگ به تابعی به اسم `habitat-fitter` نیاز دارد که اندازه‌ی مناسب زیستگاه (یک کلیدواژه) را از روی وزن حیوان خانگی‌اش بر حسب کیلوگرم (یک عدد صحیح) انتخاب کند.

زیستگاه‌های لازم برای هر اندازه حیوان خانگی چنین‌اند:

- بیشتر یا مساوی ۴۰ کیلوگرم -> `:massive`
- از ۲۰ کیلوگرم تا ۳۹ کیلوگرم (شامل) -> `:large`
- از ۱۰ کیلوگرم تا ۱۹ کیلوگرم (شامل) -> `:medium`
- از ۱ کیلوگرم تا ۹ کیلوگرم (شامل) -> `:small`
- کمتر یا مساوی ۰ کیلوگرم -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. و حالا، وقت غذاست

همه‌ی حیوانات خانگی زمینی یک ویژگی مشترک دارند: نیاز به غذا! اما این مفهوم برای لودویگ تا حدی بیگانه است، چون زود یادش می‌رود کاسه‌ی غذای حیوان خانگی‌اش را دوباره پر کند.

لودویگ به تابعی ساده به اسم `feeding-time` نیاز دارد که وقتی کاسه باید دوباره پر شود به او هشدار دهد. این تابع درصد پر بودن (یک عدد صحیح) را می‌گیرد و پیامی به شکل یک رشته برمی‌گرداند.

اگر سطح غذا چنین باشد:

- بالای ۲۰٪ -> `"All is well."`
- ۲۰٪ یا کمتر -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. آیین رفتار

حالا که همه‌ی مقدمات مرتب شده‌اند، لودویگ مشتاق است چند کار هیجان‌انگیز را امتحان کند، مثل «نوازش کردن» و بازی «آوردن». با این حال، هر حیوان خانگی‌ای برای این کارها مناسب نیست.

لودویگ دو تابع می‌خواهد، `pet` و `play-fetch`، که نوع حیوان خانگی را (به شکل یک رشته) می‌گیرند و اگر آن کار مناسب نباشد، یا چیزی برنمی‌گردانند یا پیامی مانند `"Maybe not with this pet..."` برمی‌گردانند.

فرض کنید فقط `"Dog"`ها بازی آوردن را انجام می‌دهند و همه‌ی حیوانات خانگی به‌جز `"Fish"` را می‌توان نوازش کرد.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
