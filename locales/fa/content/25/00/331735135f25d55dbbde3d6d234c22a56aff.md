# درباره

مهم‌ترین نکته‌ای که باید درباره‌ی رشته‌های C# به خاطر بسپارید این است که آن‌ها اشیائی تغییرناپذیرند که متن را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، علائم نگارشی و غیره) نمایش می‌دهند. برای تعریف یک نمونه‌ی `string` از گیومه‌های دوگانه استفاده می‌شود:

```csharp
string fruit = "Apple";
```

دستکاری یک رشته با فراخوانی یکی از [متدها][methods] یا [ویژگی‌ها][properties] آن انجام می‌شود. از آنجا که مقادیر رشته هرگز پس از تعریف تغییر نمی‌کنند، همه‌ی متدهای دستکاری رشته یک رشته‌ی جدید برمی‌گردانند.

یک رشته با نویسه‌های گیومه‌ی دوگانه (`"`) محدود می‌شود. برخی از نویسه‌های خاص نیاز به [escape][escaping] دارند که با نویسه‌ی بک‌اسلش (`\`) انجام می‌شود. همچنین می‌توان پیش از رشته علامت at (`@`) را قرار داد که آن را به یک [رشته‌ی verbatim][verbatim] تبدیل می‌کند و هر نویسه‌ای را که escape شده است نادیده می‌گیرد.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

اگر فقط به بخشی از یک رشته نیاز دارید، می‌توانید از [متد `Substring()`][substring] استفاده کنید تا فقط همان بخش را استخراج کنید:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

از [متد `IndexOf`][indexof] می‌توان برای یافتن اندیس نخستین وقوع یک `string` درون یک `string` استفاده کرد، و اگر مقدار مشخص‌شده پیدا نشود `-1` برمی‌گرداند:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

در پایان، [راه‌های زیادی برای به هم چسباندن رشته‌ها][concatenation] وجود دارد. ساده‌ترین راه استفاده از [عملگر `+`][plus-operator] است.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

برای هر قالب‌بندی رشته‌ای که پیچیده‌تر از به هم چسباندن ساده باشد، [درج رشته][interpolation] ترجیح داده می‌شود. برای اینکه درج رشته در یک رشته فعال شود، پیش از آن علامت دلار (`$`) را قرار دهید.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
