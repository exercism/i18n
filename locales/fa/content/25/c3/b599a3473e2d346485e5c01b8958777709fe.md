# مقدمه‌ای بر نقل‌قول‌گذاری

یک توصیه که برنامه‌نویسان تازه‌کار bash بارها و بارها می‌شنوند:

> متغیرهایتان را داخل گیومه بگذارید!

چرا؟

وقتی متغیری (مثل `$name`) را بسط می‌دهید، تقریباً همیشه می‌خواهید _مقدار_ آن متغیر را به‌صورت یک رشته‌ی واحد (یا یک عدد) به کار ببرید.
نمی‌خواهید با مقدار به‌طور غیرمنتظره‌ای مثل دو یا چند رشته‌ی جداگانه رفتار شود.

## نقل‌قول‌گذاری

نقل‌قول‌گذاری اصلی‌ترین سازوکار برای تضمین این است که یک تکه متن به‌صورت یک کلمه‌ی واحد در نظر گرفته شود.
دو نوع اصلی گیومه وجود دارد.

### گیومه‌های دوگانه

گیومه‌های دوگانه اجازه می‌دهند بسط پارامتر، بسط حسابی و جانشینی دستور در داخلشان انجام شود.

```bash
echo "This is bash version $BASH_VERSION"
```

می‌توانید یک گیومه‌ی دوگانه‌ی تحت‌اللفظی را داخل رشته‌ای که در گیومه‌ی دوگانه است، با گذاشتن یک بک‌اسلش پیش از آن بگنجانید.

```bash
echo "She said \"Let me teach you about bash.\""
```

### گیومه‌های تک

گیومه‌های تک _هیچ بسطی را درون خود مجاز نمی‌دانند_.

```bash
echo 'This is bash version $BASH_VERSION'
# ...^..................................^
# prints exactly: This is bash version $BASH_VERSION
```

_امکان ندارد_ یک گیومه‌ی تک را داخل رشته‌ای که در گیومه‌ی تک است بگنجانید.

## اهمیت نقل‌قول‌گذاری

دقیقاً چه اشکالی دارد که `echo $name` بنویسیم؟

وقتی شل یک خط کد را تجزیه می‌کند، [چند نوع بسط][expansions] را به‌ترتیب انجام می‌دهد.
دو مورد از آخرین بسط‌ها _تقسیم کلمه_ و _بسط نام فایل_ هستند.

### تقسیم کلمه

هر نتیجه‌ای از بسط پارامتر، جانشینی دستور یا بسط حسابی _که داخل گیومه‌های دوگانه رخ نداده باشد_، مستعد «تقسیم کلمه» است.
شل نتیجه‌ی بسط‌داده‌شده را می‌گیرد و آن را بر اساس هر دنباله‌ای از کاراکترها که در مقدار `$IFS` وجود دارد تقسیم می‌کند.
به‌طور پیش‌فرض، این‌ها فاصله، تب و خط جدید هستند.

می‌توانیم این را با یک حلقه‌ی شل در عمل ببینیم:

```bash
sentence="The quick brown fox jumps."
i=0
for word in "$sentence"; do echo "$((++i)) $word"; done
# ..........^.........^
```
خروجی می‌دهد
```none
1 The quick brown fox jumps.
```

اما بدون گیومه:

```bash
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
خروجی می‌دهد
```none
1 The
2 quick
3 brown
4 fox
5 jumps.
```

بیایید آن را با مقدار متفاوتی از `$IFS` ببینیم:

```bash
csv="first,second,third"
IFS=","
for word in $csv; do echo "$word"; done
```
خروجی می‌دهد
```none
first
second
third
```

#### غیرفعال کردن تقسیم کلمه

یک تکنیک برای غیرفعال کردن تقسیم کلمه این است که `$IFS` را روی یک رشته‌ی خالی تنظیم کنید

```bash
sentence="The quick brown fox jumps."
IFS=    # or explicitly, IFS=""
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
خروجی می‌دهد
```none
1 The quick brown fox jumps.
```

با این حال، توصیه نمی‌شود متغیرها را بدون گیومه رها کنید، مگر اینکه بسط نام فایل را هم غیرفعال کنید.
در ادامه خواهیم دید چطور این کار را انجام دهیم.

### بسط نام فایل

از الگوهای «Glob» برای بیان یک الگوی مختصر جهت تطبیق با مجموعه‌ای از فایل‌ها استفاده می‌شود.
برای مثال، می‌توانید همه‌ی فایل‌های Markdown یک پوشه را با `*.md` تطبیق دهید.
[الگوهای Glob][glob] از زمان اختراع Unix وجود داشته‌اند.

کاراکترهای عام در Glob عبارت‌اند از:

* `*` با صفر یا چند کاراکتر دلخواه تطبیق می‌کند،
* `?` دقیقاً با یک کاراکتر دلخواه تطبیق می‌کند،
* `[...]` دقیقاً با یک کاراکتر از مجموعه‌ی کاراکترهای فهرست‌شده در داخل کروشه‌ها تطبیق می‌کند.

   ~~~~exercism/advanced
   <details><summary>
   جزئیات زیادی درباره‌ی مجموعه‌های کاراکتر وجود دارد.
   برای نمایش آن‌ها اینجا را کلیک کنید.
   </summary>

    * `[abc]` دقیقاً با یک کاراکتر تطبیق می‌کند که یا `a` است یا `b` یا `c`.
        * برای گنجاندن یک کروشه‌ی بسته‌ی تحت‌اللفظی در عبارت، آن را اولین کاراکتر بعد از کروشه‌ی باز قرار دهید (بعد از یک `^` اختیاری)
            * `[][]` یک مجموعه‌ی کاراکتر است که هم با کروشه‌ی بسته و هم با کروشه‌ی باز تطبیق می‌کند.
            * یا جلوی آن یک بک‌اسلش بگذارید: `[[\]]`
    * `[x-y]` دقیقاً با یک کاراکتر تطبیق می‌کند که در _بازه‌ی_ `x` تا `y` باشد
        * برای گنجاندن یک کاراکتر خط تیره‌ی تحت‌اللفظی در یک مجموعه‌ی کاراکتر، آن کاراکتر باید یا اولین کاراکتر بعد از کروشه‌ی باز باشد (بعد از یک `^` اختیاری) یا آخرین کاراکتر قبل از کروشه‌ی بسته.
            * `[-xy]` و `[xy-]` هر کدام دقیقاً با یک کاراکتر تطبیق می‌کنند که `-` است یا `x` یا `y`
            * یا جلوی آن یک بک‌اسلش بگذارید: `[x\-y]`
        * می‌توان چند بازه را مشخص کرد، برای مثال `[0-9A-Fa-f]` با یک رقم هگزادسیمال تطبیق می‌کند
    * `[^abc]` دقیقاً با یک کاراکتری تطبیق می‌کند که **نه** `a` است و نه `b` و نه `c`،
    * `[^x-y]` دقیقاً با یک کاراکتری تطبیق می‌کند که در بازه‌ی `x` تا `y` **نباشد**
    * `[[:character_class:]]` با یک کاراکتر تطبیق می‌کند که در «character_class» نام‌داده‌شده باشد
        * کلاس‌های کاراکتر موجود عبارت‌اند از:
            * `lower` -- حروف کوچک
            * `upper` -- حروف بزرگ
            * `alpha` -- حروف
            * `digit` -- ارقام
            * `alnum` -- حروف و ارقام
            * `space` -- فاصله‌ی سفید
            * `blank` -- فاصله‌ی سفید افقی (فاصله و تب)
            * `xdigit` -- ارقام هگزادسیمال
            * `word` -- کاراکترهای مجاز در یک شناسه (حروف، اعداد، زیرخط)
            * `punct` -- نقطه‌گذاری
            * `cntrl` -- کاراکترهای کنترلی
            * `graph` -- کاراکترهای «قابل‌مشاهده»
            * `print` -- کاراکترهای قابل‌مشاهده به‌علاوه‌ی فاصله
        * می‌توان آن‌ها را ترکیب کرد:
            * کلاس `[[:alpha:]]` از `[[:lower:][:upper:]]` تشکیل شده است
            * کلاس `[[:alnum:]]` از `[[:alpha:][:digit:]]` تشکیل شده است
            * کلاس `[[:word:]]` از `[[:alnum:]_]` تشکیل شده است
            * زیرخط (هشت‌هشتی ۱۳۷) هم `[[:word:]]` است و هم `[[:punct:]]`
            * کلاس `[[:graph:]]` از `[[:alnum:][:punct:]]` تشکیل شده است
            * کلاس `[[:print:]]` از `[[:graph:] ]` تشکیل شده است -- فقط فاصله (هشت‌هشتی ۰۴۰) و نه هیچ فاصله‌ی سفید دیگری.
   </details>   
   ~~~~

#### پیمایش روی فهرستی از فایل‌ها

می‌توانید با یک حلقه‌ی `for` روی فهرستی از فایل‌ها پیمایش کنید

```bash
for file in *.csv; do
    do_something_with "$file"
done
```

توجه کنید که متغیر `"$file"` در گیومه قرار گرفته است.
الگوی Glob می‌تواند فایل‌هایی را برگرداند که در اسمشان فاصله دارند.
باید متغیر را در گیومه بگذاریم تا دستور `do_something_with` دقیقاً یک آرگومان، یعنی اسم فایل، دریافت کند.

#### الگوهای Glob عبارت‌های باقاعده نیستند

الگوهای Glob **عبارت‌های باقاعده نیستند**.

* تطبیق دقیق با یک کاراکتر
   * عبارت باقاعده: `.`
   * Glob: `?`
* تطبیق با صفر یا چند کاراکتر
   * عبارت باقاعده: `.*`
   * Glob: `*`
        * الگوی Glob `.*` یعنی «با اسم فایلی تطبیق می‌کند که اولین کاراکترش یک نقطه‌ی تحت‌اللفظی است و پس از آن صفر یا چند کاراکتر دلخواه می‌آید».
* تطبیق با یک یا چند کاراکتر
   * عبارت باقاعده: `.+`
   * Glob: `?*`
* مجموعه‌های کاراکتر در عبارت‌های باقاعده و در Glob به یک شکل عمل می‌کنند.

~~~~exercism/advanced
Bash [الگوهای توسعه‌یافته][extended-patterns] را فراهم می‌کند که به عبارت‌های باقاعده نزدیک‌ترند.

[extended-patterns]: https://www.gnu.org/software/bash/manual/bash.html#Pattern-Matching
~~~~

#### نقل‌قول‌گذاری و بسط نام فایل

مواقعی پیش می‌آید که نمی‌خواهید بسط نام فایل انجام شود.
پردازش ورودی کاربر یکی از همین مواقع است.
این قطعه‌کد را در نظر بگیرید

```bash
read -p "Enter something: " user_input
echo $user_input
```

اگر کاربر یک ستاره (`*`) وارد کند، خروجی چه خواهد بود؟
فهرست فایل‌های پوشه‌ی جاری.
احتمالاً این چیزی نیست که می‌خواهید انجام دهید.

مثال دیگر، دادن الگوها به‌عنوان آرگومان به برنامه‌هایی است که انتظار الگو دارند.
برنامه‌ی `tr` اغلب برای دست‌کاری متن به کار می‌رود. برای کوچک کردن مقدار یک متغیر، می‌توانید این کار را انجام دهید

```bash
var="My Puppet"
echo "$var" | tr '[:upper:]' '[:lower:]'
```
خروجی می‌دهد
```none
my puppet
```

یک اشتباه رایج این است که آرگومان‌های `tr` را در گیومه نگذاریم: `tr [:upper:] [:lower:]`

~~~~exercism/caution
چرا این مسئله‌ساز است؟
الگوهای Glob بدون گیومه به فهرست فایل‌های منطبق بسط داده می‌شوند.
فرض کنید فردی که از اسکریپت شما استفاده می‌کند، فایل‌هایی با اسم `p` و `u` و `w` در پوشه‌ی جاری داشته باشد:

```bash
touch p u w
var="My Puppet"
echo "$var" | tr [:upper:] [:lower:]
```

این کار به خطا منجر می‌شود!

الگوی `[:upper:]` بدون گیومه با هر یک از `:`، `u`، `p`، `e` یا `r` تطبیق می‌کند.
الگوی `[:lower:]` بدون گیومه با هر یک از `:`، `l`، `o`، `w`، `e` یا `r` تطبیق می‌کند.
Bash برای الگوی اول با فایل‌های `p` و `u` و برای الگوی دوم با فایل `w` تطبیق می‌کند و `tr` به این شکل فراخوانی می‌شود

```bash
echo "$var" | tr p u w
```

و این تعداد آرگومان اشتباهی برای `tr` است.
~~~~

#### غیرفعال کردن بسط نام فایل

می‌توانید از دستور [`set`][set] برای غیرفعال کردن بسط نام فایل استفاده کنید.

```bash
echo *      # prints a list of files
set -f      # disable filename expansion
echo *      # prints a literal asterisk
set +f      # enable filename expansion
```

#### کنترل بسط نام فایل

چندین تنظیم برای دستور توکار [`shopt`][shopt] وجود دارد که نحوه‌ی کار بسط نام فایل را کنترل می‌کنند.
چند مورد جالب‌شان عبارت‌اند از:

* `shopt -s nocaseglob` -- تطبیق بدون توجه به بزرگی و کوچکی حروف
* `shopt -s extglob` -- فعال کردن الگوهای توسعه‌یافته
* `shopt -s nullglob` -- اگر هیچ فایلی تطبیق نکند، الگو را با هیچ‌چیز جایگزین می‌کند.
   رفتار پیش‌فرض این است که الگو را به‌صورت یک رشته‌ی تحت‌اللفظی سر جایش بگذارد.
