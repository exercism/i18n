# مقدمه

## متغیر نمونه

شیءها می‌توانند با تعیین _متغیرهای نمونه_، وضعیت خودشان را نگه دارند.
این متغیرها درون یک شیء قرار دارند و معمولاً برای ذخیره‌ی مقداری وضعیت درونی به کار می‌روند.

متغیرهای نمونه همیشه با `@` شروع می‌شوند.
می‌توانید با تعیین متغیری که با یک `@` شروع می‌شود، یک متغیر نمونه‌ی تازه بسازید.
برای مثال:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

شیءها معمولاً وضعیت اولیه‌ی خود را در متدی به نام `initialize` تعیین می‌کنند که هنگام فراخوانی `new` روی یک کلاس به‌طور خودکار فراخوانی می‌شود.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

متد `initialize` می‌تواند آرگومان هم بگیرد تا هر نمونه بتواند با وضعیتی سفارشی شروع کند:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

کار خوبی است که متغیرهای _نمونه_ را از خواندن و نوشتنِ بیرونی خصوصی در نظر بگیریم.
در عوض، متدهایی تعریف می‌کنیم که مقدارشان را بگیرند و تعیین کنند.
برای مثال:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## nil

[Nil][nil-dictionary] واژه‌ای انگلیسی به معنای «هیچ» یا «صفر» است.
در Ruby، از `nil` برای بیان نبودِ یک شیء استفاده می‌شود.
در زبان‌های برنامه‌نویسی دیگر، مقادیر `null` یا `none` ممکن است نقش مشابهی ایفا کنند.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby به هر متغیر نمونه، وقتی برای نخستین بار با آن روبه‌رو می‌شود، مقدار پیش‌فرض `nil` را می‌دهد، تا زمانی که مقدار دیگری به آن داده شود.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
