# مقدمه

## آرایه

آرایه‌ها در PHP نگاشت‌های مرتب هستند.
«نگاشت» یک ساختار داده است که یک «کلید» را به یک «مقدار» مرتبط می‌کند.
آرایه‌ها انعطاف‌پذیرند و می‌توان آن‌ها را مانند یک آرایه‌ی خطی (مثل `C` یا `Java`)، فهرست [بردار]، جدول درهم‌سازی، دیکشنری، مجموعه، پشته یا صف در نظر گرفت.

کلید اختیاری است، اما اگر تعیین شود، باید یا `int` باشد یا `string`.
وقتی کلیدی ارائه نشود، PHP به‌طور پیش‌فرض کلیدهای عدد صحیح را به ترتیب صعودی و با شروع از `0` در نظر می‌گیرد.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

یک آرایه می‌تواند مقادیری از همه‌ی نوع‌ها را ذخیره کند.
هر مقدار می‌تواند نوع متفاوتی داشته باشد.

### استفاده از آرایه‌ها

آرایه‌ها را می‌توان به‌صورت یک لیترال تعریف کرد (که در کد نوشته می‌شود، همان‌طور که در بالا انجام شد) یا آن‌ها را با توابع ایجاد و دست‌کاری کرد.
برای دسترسی، مقداردهی و افزودن مقادیر از عملگر اندیس استفاده کنید:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## آرگومان‌های با طول متغیر

آرگومان‌های یک تابع را می‌توان طوری تعیین کرد که هر تعداد آرگومان بپذیرد:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
