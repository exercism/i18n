# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات    | کاربرد | نوع       | توضیح                        |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | ورودی     | عدد صحیح | x                          |
| `$a1`    | ورودی     | عدد صحیح | y                          |
| `$v0`    | خروجی     | عدد صحیح | امتیاز کسب‌شده              |
| `$t0-9`  | موقت      | هر نوع   | برای ذخیره‌سازی موقت استفاده می‌شود |
