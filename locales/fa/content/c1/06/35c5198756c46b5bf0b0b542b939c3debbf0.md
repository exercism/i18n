# پیوست دستورالعمل

## بسته‌ی مرتب‌سازی

این تمرین از شما می‌خواهد که یک آرایه را مرتب کنید، اما این کار در کتابخانه‌ی استاندارد وجود ندارد. می‌توانید کتابخانه‌ی مرتب‌سازی خودتان را بنویسید، اما راه بهتر استفاده از [بسته‌ی sorts](https://github.com/diku-dk/sorts) است.

می‌توانید با اجرای دستور زیر در پوشه‌ی راه‌حل، از این بسته در راه‌حل خود استفاده کنید:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

سپس [الگوریتم‌های مرتب‌سازی موردنظرتان](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) را به این صورت وارد کنید:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
