# درباره

[«تابع مرتبه‌بالا»](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) تابعی است که یکی از این دو کار را انجام می‌دهد:

- یک تابع را به‌عنوان آرگومان می‌گیرد
- یک تابع را برمی‌گرداند

آرگومان تابع فقط یک آرگومان معمولی است، با این تفاوت که می‌توانید آن را فراخوانی کنید.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
