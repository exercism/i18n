# پیوست دستورالعمل‌ها

## پیاده‌سازی

در این تمرین رویه‌ای را پیاده‌سازی می‌کنید که قرار است رشته‌ای را که برمی‌گرداند، تخصیص دهد. آزادسازی رشته بر عهده‌ی فراخوانی‌کننده‌ی آن رویه است.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
