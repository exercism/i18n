# مقدمه

در Common Lisp زمان به چهار روش نمایش داده می‌شود که در اینجا به دو مورد از آن‌ها می‌پردازیم.

- زمان جهانی یک زمان مطلق است، عددی صحیح که تعداد ثانیه‌های سپری‌شده از `1900-01-01T00:00:00Z` را نشان می‌دهد (یعنی نیمه‌شب ۱ ژانویه ۱۹۰۰ به وقت UTC).
- زمان رمزگشایی‌شده یک تاپل از ۹ مقدار است که با هم یک زمان تقویمی مشخص را نشان می‌دهند: ثانیه، دقیقه، ساعت، روزِ ماه، ماه، سال، روزِ هفته، پرچم ساعت تابستانی، منطقه‌ی زمانی.
(در ادامه به‌تفصیل بررسی می‌شود.)

## زمان جهانی

برای گرفتن زمان جهانی کنونی از `get-universal-time` یا `get-decoded-time` استفاده می‌شود.
اولی تعداد ثانیه‌های کنونی از `1900-01-01T00:00Z` را برمی‌گرداند و دومی همان داده را در قالب رمزگشایی‌شده برمی‌گرداند.

## زمان رمزگشایی‌شده

`decode-universal-time` و `encode-universal-time` توابع اصلی برای کار با زمان هستند.
اولی یک زمان جهانی می‌گیرد و یک زمان رمزگشایی‌شده را به‌صورت [مقادیر چندگانه][concept-multiple-values] برمی‌گرداند و دومی مقادیر زمان رمزگشایی‌شده را به‌عنوان آرگومان می‌گیرد و یک زمان جهانی برمی‌گرداند.

هر دو یک آرگومان اختیاری منطقه‌ی زمانی می‌گیرند.
قالب منطقه‌ی زمانی را در ادامه ببینید.

زمان رمزگشایی‌شده مجموعه‌ای از مقادیر است:

- *ثانیه*: عددی صحیح بین ۰ و ۵۹
- *دقیقه*: عددی صحیح بین ۰ و ۵۹
- *ساعت*: عددی صحیح بین ۰ و ۲۳
- *روزِ ماه*: عددی صحیح بین ۱ و ۳۱ (که مسلماً حد بالا به ماه و سال بستگی دارد)
- *ماه*: عددی صحیح بین ۱ و ۱۲
- *سال*: عددی صحیح که سال را نشان می‌دهد.
- *روزِ هفته*: عددی صحیح بین ۰ و ۶. ۰ یعنی دوشنبه، ۱ یعنی سه‌شنبه و به همین ترتیب ... ۶ یعنی یکشنبه.
- *پرچم ساعت تابستانی*: مقدار «درست» نشان می‌دهد که ساعت تابستانی اعمال شده است.
- *منطقه‌ی زمانی*: تعدادی ساعت بین -۲۴ و ۲۴ که اختلاف با UTC را نشان می‌دهد.
این عدد گویا است و باید مضربی از `1/3600` باشد.

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
