# درباره

[«تاپل»ها][tuples] چندین مقدار را در قالب یک مقدار ترکیبی واحد کنار هم می‌گذارند.
برخلاف آرایه‌ها، مقادیر یک تاپل لازم نیست هم‌نوع باشند و اندازه‌ی تاپل پس از ساخته شدن ثابت است.

برای ساختن یک تاپل، مقادیر جداشده با کاما را داخل پرانتز قرار دهید:

```swift
let order = ("biscuits", 2.99, 3)
```

همچنین می‌توانید نوع‌ها را به‌صورت صریح مشخص کنید:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

برای استخراج تک‌تک عنصرهای یک تاپل بی‌نام، از اندیس‌گذاری از صفر استفاده کنید (`.0`، `.1` و غیره):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## تاپل‌های نام‌دار

می‌توانید هنگام تعریف تاپل، به تک‌تک عنصرهای آن اسم بدهید:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

نام‌گذاری عنصرها کد را خواناتر می‌کند و به شما اجازه می‌دهد با نقطه‌گذاری همراه با برچسب‌ها به عنصرها دسترسی داشته باشید:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

همچنین می‌توانید اسم عنصرها را هم در مشخص کردن نوع بیاورید:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## تغییر دادن تاپل‌ها

اگر یک تاپل به‌صورت متغیر (`var`) تعریف شده باشد، می‌توانید عنصرهایش را به‌روزرسانی کنید:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## برگرداندن چند مقدار

هرچند توابع Swift فقط می‌توانند یک مقدار برگردانند، برگرداندن یک تاپل به شما اجازه می‌دهد چند مقدار را بسته‌بندی کنید و [از یک تابع برگردانید][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## تجزیه‌ی تاپل

می‌توانید مقادیر یک تاپل را تجزیه کنید (یعنی باز کنید) و آن‌ها را در ثابت‌ها یا متغیرهای جداگانه بریزید:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

تجزیه‌ی تاپل به‌طور مستقیم در حلقه‌های `for-in` هم کار می‌کند:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
