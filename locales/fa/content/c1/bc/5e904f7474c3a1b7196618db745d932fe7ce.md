# درباره

## انواع تابع

پیش‌تر دیدیم که امضای تابع با یک اسم تابع تعریف می‌شود که پس از آن فهرستی از برچسب‌های پارامتر جداشده با ویرگول به همراه نوع‌هایشان می‌آید، و سپس `->` و نوع مقادیری که تابع برمی‌گرداند.

اگر همه‌ی اسم‌ها و برچسب‌ها را از این امضا حذف کنیم، آنچه باقی می‌ماند [نوع تابع][function-types] است.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

توجه کنید که نوع دو تابع اول یکسان است، `(String, Int) -> String`، هرچند این دو تابع به‌شیوه‌ای بسیار متفاوت کار می‌کنند. هر دو یک `String` و یک `Int` را به عنوان ورودی می‌گیرند و یک `String` برمی‌گردانند. و همان‌طور که از نوع تابع سوم پیداست، هرچند این تابع به نظر می‌رسد چیزی برنمی‌گرداند، در واقع `()` را برمی‌گرداند، تنها مقدار از نوع `Void`. توجه کنید که `()` و `Void` به عنوان اسم نوع قابل جابه‌جایی‌اند، بنابراین نوع `printString` را می‌توان به‌صورت `String) -> Void` هم نوشت.

این نوع‌ها را می‌توان مانند هر نوع دیگر در Swift به کار برد؛ برای مثال، می‌توان از آن‌ها در اعلان متغیرها یا ثابت‌ها استفاده کرد. و چون توابع در Swift مقدار هستند، می‌توان توابع موجود را به این ثابت‌ها/متغیرها نسبت داد:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

مانند سایر متغیرها/ثابت‌ها، مقداری که به آن نسبت می‌دهید باید از نوع درست باشد:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## انواع تابع به عنوان نوع پارامتر

چون نوع تابع را می‌توان هر جایی که نوع‌های دیگر به کار می‌روند استفاده کرد، نتیجه می‌شود که [می‌توان از آن‌ها به عنوان نوع پارامتر استفاده کرد][functions-as-parameters] و آن‌ها را به توابع دیگر پاس داد و از داخل آن توابع فراخوانی کرد.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## انواع تابع به عنوان نوع بازگشتی

به‌طور مشابه، [می‌توان از نوع تابع به عنوان نوع بازگشتی][functions-as-returns] توابع استفاده کرد. به عبارت دیگر، می‌توان توابعی نوشت که توابع دیگر را می‌سازند و برمی‌گردانند. هنگام ساخت این توابع، تابعی که برگردانده می‌شود می‌تواند از سایر پارامترهای پاس‌داده‌شده به تابع یا متغیرهای محلی ساخته‌شده درون تابع والد استفاده کند.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## گرفتن مقدارها

همان‌طور که در تابع `makeAdder(base:)` در بالا دیدیم، توابع تودرتو می‌توانند به پارامترها و متغیرهای توابع پیرامون خود دسترسی داشته باشند. به‌علاوه، می‌توانند دسترسی خود به این مقدارها را پس از پایان یافتن تابع دربرگیرنده حفظ کنند. این عمل به‌دست‌آوردن و حفظ دسترسی، [_گرفتن_][capturing-values] نامیده می‌شود.

## توابع مرتبه‌بالا

توابعی که توابع را به عنوان پارامتر می‌گیرند و/یا توابعی را برمی‌گردانند، توابع مرتبه‌بالا نامیده می‌شوند. Swift در کتابخانه‌های گوناگون خود توابع مرتبه‌بالای زیادی دارد. برای مثال، متد `sorted(by:)` که روی مجموعه‌های Swift مانند `Array` در دسترس است و برای آرایه‌ای با عنصرهایی از نوع `T`، تابعی از نوع `(T, T) -> Bool` می‌گیرد که تعیین می‌کند کدام یک از دو مقدار باید در آرایه‌ی مرتب‌شده پیش از دیگری بیاید؛ اگر مقدار سمت چپ باید اول بیاید `true` و اگر مقدار سمت راست باید اول بیاید `false` را برمی‌گرداند.

مثال دیگر، متد `contains(where:)` روی مجموعه‌هاست که برای مجموعه‌ای با عنصرهایی از نوع `T`، تابعی از نوع `(T) -> Bool` می‌گیرد که اگر عنصر ویژگی‌ای را برآورده کند `true` و در غیر این صورت `false` را برمی‌گرداند. سپس `contains(where:)` اگر عنصری در مجموعه این ویژگی را برآورده کند `true` را برمی‌گرداند.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
