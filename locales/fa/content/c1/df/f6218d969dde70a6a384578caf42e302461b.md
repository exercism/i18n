# دستورالعمل‌ها

در این تمرین، خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با این قالب: `"[<LVL>]: <MESSAGE>"`.

سطوح لاگ مختلف عبارت‌اند از:

- `TRC` (ردیابی)
- `DBG` (debug)
- `INF` (اطلاعات)
- `WRN` (هشدار)
- `ERR` (خطا)
- `FTL` (بحرانی)

سه وظیفه دارید.

## 1. تجزیه‌ی سطح لاگ

یک `enum` به اسم `LogLevel` تعریف کنید که شش عنصر متناظر با سطوح لاگ بالا دارد.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

سپس متد `LogLine.getLogLevel()` را پیاده‌سازی کنید که سطح لاگ تجزیه‌شده‌ی یک خط لاگ را برمی‌گرداند:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. پشتیبانی از سطح لاگ ناشناخته

متأسفانه گاهی بعضی خطوط لاگ یک سطح لاگ ناشناخته دارند.
برای اینکه با این خطوط لاگ به‌شکل مناسبی رفتار کنید، یک عنصر `UNKNOWN` به `enum` `LogLevel` اضافه کنید که هنگام تجزیه‌ی یک سطح لاگ ناشناخته باید برگردانده شود:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. تبدیل خط لاگ به قالب کوتاه

سطح لاگ یک خط لاگ خیلی طولانی است.
برای کاهش فضای دیسک لازم برای ذخیره‌ی خطوط لاگ، قالب کوتاهی طراحی شده است: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

سطح لاگ رمزگذاری‌شده نگاشت ساده‌ای از یک سطح لاگ به یک عدد است:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

متد `LogLine.getOutputForShortLog()` را پیاده‌سازی کنید که می‌تواند قالب کوتاه‌شده‌ی خط لاگ را خروجی بدهد:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
