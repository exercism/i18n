# مقدمه

در Elixir، «رشته‌ها» با گیومه‌ی دوتایی محدود می‌شوند و با UTF-8 کدگذاری می‌شوند:

```elixir
"Hi!"
```

می‌توان رشته‌ها را با عملگر `<>/2` به هم پیوست کرد:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

در Elixir می‌توان با نحوه‌ی نگارش `#{}` مقادیر را در رشته‌ها درج کرد:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

برای قرار دادن کاراکتر خط جدید در یک رشته، از کد فرار `\n` استفاده کنید:

```elixir
"1\n2\n3\n"
```

برای اینکه کار با متن‌هایی که خط جدید زیادی دارند راحت باشد، به‌جای آن از نحوه‌ی نگارش heredoc با سه گیومه‌ی دوتایی استفاده کنید:

```elixir
"""
1
2
3
"""
```

Elixir توابع زیادی برای کار با رشته‌ها در ماژول `String` ارائه می‌دهد.
