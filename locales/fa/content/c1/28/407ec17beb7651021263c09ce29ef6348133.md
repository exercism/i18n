# مقدمه

نوع «اتحاد تفکیک‌شده» نماینده‌ی تعداد ثابتی از «حالت»های دارای اسم است. هر مقدار از اتحاد تفکیک‌شده دقیقاً با یکی از این حالت‌ها متناظر است.

اتحاد تفکیک‌شده با «کلیدواژه»ی `type` تعریف می‌شود و حالت‌ها با کاراکترهای لوله (`|`) از هم جدا می‌شوند:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

هر حالت از اتحاد تفکیک‌شده می‌تواند به‌صورت اختیاری داده‌ای همراه داشته باشد و حالت‌های مختلف می‌توانند انواع متفاوتی از داده داشته باشند. اگر هیچ‌کدام از حالت‌ها داده‌ای همراه نداشته باشند، اتحاد تفکیک‌شده شبیه مفهومی است که زبان‌های دیگر معمولاً آن را «شمارش» (یا «enum») می‌نامند.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

برای ساختن مقدار برای یک حالت مشخص، می‌توانید به اسم آن ارجاع دهید (مثلاً `Success`). چون اسم‌های حالت‌ها فقط «توابع سازنده» هستند، داده‌ی همراه را می‌توان به‌عنوان آرگومان معمولی یک تابع پاس داد. اگر اتحاد تفکیک‌شده‌ی دیگری حالتی با همین اسم تعریف کرده باشد، باید از اسم کامل آن استفاده کنید (مثلاً `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

اتحادهای تفکیک‌شده «برابری ساختاری» دارند؛ یعنی دو مقدار برای یک حالت و با داده‌ی (اختیاری) یکسان، هم‌ارز هستند.

هرچند می‌توان برای کار با اتحادهای تفکیک‌شده از عبارت‌های `if/elif/else` استفاده کرد، روش توصیه‌شده «تطبیق الگو» با استفاده از «الگوی شناسه» است:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
