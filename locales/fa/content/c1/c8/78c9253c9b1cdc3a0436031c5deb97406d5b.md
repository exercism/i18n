# مقدمه

«پیوند» توصیف می‌کند که از کجا در کد می‌توان به یک «شناسه» دسترسی داشت.
مقادیری که دامنه‌ی بلوک، تابع، یا پیش‌نمایش تابع دارند، هیچ پیوندی ندارند.
یعنی نمی‌توان از خارج از دامنه‌شان به آن‌ها دسترسی داشت.
برای اطلاعات بیشتر درباره‌ی دامنه، به [مفهوم دامنه](../scope/introduction.md#Introduction) مراجعه کنید.

## پیوند خارجی

شناسه‌هایی که دامنه‌ی فایل دارند، به‌طور پیش‌فرض پیوند خارجی دارند.
یک شناسه با پیوند خارجی را می‌توان از هر فایلی در برنامه فراخوانی کرد.

## پیوند داخلی

می‌توان یک شناسه با دامنه‌ی فایل را با استفاده از مشخص‌کننده‌ی `static` دارای پیوند داخلی کرد.
از یک شناسه با پیوند داخلی فقط در فایل خودش می‌توان استفاده کرد.

برای مثال

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

پیوند ایستا را نباید با مدت ذخیره‌سازی ایستا اشتباه گرفت.
برای اطلاعات بیشتر درباره‌ی مدت ذخیره‌سازی ایستا، به [مفهوم مدت ذخیره‌سازی](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type) مراجعه کنید.
