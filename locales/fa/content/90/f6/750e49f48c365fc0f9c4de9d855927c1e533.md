# دستورالعمل‌ها

برای زیرمجموعه‌ی بسیار ساده‌ای از Forth، یک ارزیاب را پیاده‌سازی کنید.

[Forth][forth]
یک زبان برنامه‌نویسی مبتنی بر «پشته» است.
یک ارزیاب بسیار ابتدایی را برای زیرمجموعه‌ی کوچکی از Forth پیاده‌سازی کنید.

ارزیاب شما باید از واژه‌های زیر پشتیبانی کند:

- `+`، `-`، `*`، `/` (محاسبات اعداد صحیح)
- `DUP`، `DROP`، `SWAP`، `OVER` (دستکاری پشته)

می‌توانید از تاپل به‌عنوان پشته استفاده کنید تا از کدهای عملیاتی مرتبط با پشته در fift و asm پرهیز کنید.

برای ساده نگه داشتن کار، تنها نوع داده‌ای که باید پشتیبانی کنید اعداد صحیح علامت‌دار با اندازه‌ی حداقل ۱۶ بیت است.

برای نحوه‌ی نگارش باید از قواعد زیر استفاده کنید: یک عدد دنباله‌ای از یک یا چند رقم (ASCII) است، یک واژه دنباله‌ای از یک یا چند حرف، رقم، نماد یا علامت نگارشی است که عدد نباشد.
(Forth احتمالاً قواعد کمی متفاوتی دارد، اما این به‌اندازه‌ی کافی نزدیک است.)
