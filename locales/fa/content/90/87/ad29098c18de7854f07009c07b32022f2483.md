# مقدمه

## عملگر سه‌تایی

«عملگر سه‌تایی» جایگزینی سبک و فشرده برای دستورهای ساده‌ی `if/else` است.
معمولاً در دستورهای `return` استفاده می‌شود (اما محدود به آن‌ها نیست) و فقط یک خط برای تصمیم‌گیری لازم دارد: اگر عبارت `true` باشد مقدار سمت چپ و اگر `false` باشد مقدار سمت راست را برمی‌گرداند، به‌صورت زیر:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

بسیاری از عبارت‌های ساده‌ی `if/else` را می‌توان با عملگر سه‌تایی ساده کرد.
