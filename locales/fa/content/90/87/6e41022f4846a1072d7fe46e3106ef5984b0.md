# راهنمایی‌ها

## 1. انسان‌ها را به دنیای تروآ بیاورید

- هسته‌ی این تمرین استفاده از `unique_ptr` و `shared_ptr` است. برای هر یک از متغیرهای `human` از کدام نوع «اشاره‌گر هوشمند» باید استفاده کرد؟
- `artifacts` مشترک نیستند، اما برای ردیابی افرادی که تحت تأثیر قرار گرفته‌اند به `powers` نیاز دارید.
- اشاره‌گر `possession` باید یکتا باشد و اشاره‌گرهای قدرت باید مشترک باشند.

## 2. آرتیفکت‌ها را به تروآ بیاورید

- باید یک اشاره‌گر هوشمند بسازید و آن را به متغیر `possession` نسبت دهید.
- برای تغییر شیء بیرون از تابع از _ارجاع‌ها_ استفاده کنید.
- برای گرفتن چند راهنما نگاهی به [`std::make_unique`][make_unique] بیندازید.
- نوع شیءِ هدفِ اشاره‌گر باید درون براکت‌های زاویه‌دار و دوباره درون پرانتزها قرار بگیرد تا شیء تعریف شود.
- این یک نمونه‌ی کامل است: `variable = std::make_unique<int>(int{23});`

## 3. اقلام را قابل مبادله کنید

- می‌توانید [مرجع `unique_ptr`][unique_ptr] را بررسی کنید تا تابع مناسبی پیدا کنید.
- به نظر شما آیا `std::swap` می‌تواند کمکتان کند؟

## 4. به مردم قدرت بدهید

- باید یک اشاره‌گر هوشمند بسازید و آن را به متغیر `own_power` نسبت دهید.
- برای تغییر شیء بیرون از تابع از _ارجاع‌ها_ استفاده کنید.
- برای گرفتن چند راهنما نگاهی به [`std::make_shared`][make_shared] بیندازید.
- نوع شیءِ هدفِ اشاره‌گر باید درون براکت‌های زاویه‌دار و دوباره درون پرانتزها قرار بگیرد تا شیء تعریف شود.
- این یک نمونه‌ی کامل است: `variable = std::make_shared<int>(int{23});`

## 5. از قدرت استفاده کنید

- برای تغییر شیء بیرون از تابع از _ارجاع‌ها_ استفاده کنید.

## 6. مراقب شدت قدرت باشید

- می‌توانید [مرجع `shared_ptr`][shared_ptr] را بررسی کنید تا تابع مناسبی پیدا کنید.
- به نظر شما آیا `use_count` می‌تواند کمکتان کند؟
