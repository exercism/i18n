# مقدمه

## مبانی

### متغیر

الیکسیر یک زبان با نوع‌دهی پویاست؛ یعنی نوع یک متغیر فقط در زمان اجرا بررسی می‌شود. با عملگر تطبیق `=` می‌توانیم مقداری از هر نوع را به اسم یک متغیر متصل کنیم:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### ماژول

الیکسیر یک [زبان برنامه‌نویسی تابعی][functional-programming] است و ایجاب می‌کند که همه‌ی توابع نامدار در یک _ماژول_ تعریف شوند. کلیدواژه‌ی `defmodule` برای تعریف یک ماژول به کار می‌رود. همه‌ی ماژول‌ها در زمان اجرا برای سایر ماژول‌ها در دسترس‌اند و برای اینکه بقیه‌ی بخش‌های برنامه آن‌ها را ببینند به _اصلاح‌کننده‌ی دسترسی_ نیازی ندارند. یک _ماژول_ همانند یک _کلاس_ در سایر زبان‌های برنامه‌نویسی است.

```elixir
defmodule Calculator do
  # ...
end
```

### توابع نامدار

_توابع نامدار_ باید در یک ماژول تعریف شوند. کلیدواژه‌ی `def` برای تعریف یک تابع نامدار _عمومی_ به کار می‌رود.

هر تابع می‌تواند صفر یا چند آرگومان داشته باشد. مقدار آخرین عبارت در یک تابع همیشه _به‌صورت ضمنی برگردانده می‌شود_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

فراخوانی یک تابع با مشخص کردن ماژول و اسم آن و دادن آرگومانی برای هر یک از آرگومان‌های تابع انجام می‌شود.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

می‌توان به‌جای `def` از کلیدواژه‌ی `defp` برای تعریف یک تابع _خصوصی_ استفاده کرد. توابع خصوصی فقط از داخل همان ماژولی که آن‌ها را تعریف کرده است قابل استفاده‌اند.

هنگام فراخوانی یک تابع در همان ماژولی که تعریف شده است، می‌توان اسم ماژول را حذف کرد.

همچنین می‌توانید توابع کوتاه را با نحوه‌ی نگارش یک‌خطی بنویسید (به کاما `,` و دونقطه `:` در دو طرف کلیدواژه‌ی `do` توجه کنید).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### آریتی توابع

رایج است که توابع را با _آریتی_شان بنامیم. _آریتی_ یک تابع، تعداد آرگومان‌هایی است که می‌پذیرد.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### قرارداد نام‌گذاری

اسم ماژول‌ها باید از `PascalCase` استفاده کند. اسم یک ماژول باید با یک حرف بزرگ `A-Z` شروع شود و می‌تواند شامل حروف `a-zA-Z`، اعداد `0-9` و زیرخط `_` باشد.

اسم متغیرها و توابع باید از `snake_case` استفاده کند. اسم یک متغیر یا تابع باید با یک حرف کوچک `a-z` یا زیرخط `_` شروع شود، می‌تواند شامل حروف `a-zA-Z`، اعداد `0-9` و زیرخط `_` باشد و ممکن است با علامت سؤال `?` یا علامت تعجب `!` پایان یابد.

### کتابخانه‌ی استاندارد

کتابخانه‌ی استاندارد الیکسیر بسیار غنی است و مستندات خوبی دارد. مستندات آن به‌صورت آنلاین در [hexdocs.pm/elixir][docs] در دسترس است. این لینک را جایی ذخیره کنید؛ خیلی از آن استفاده خواهید کرد!

بیشتر انواع داده‌ی توکار ماژولی متناظر دارند که توابعی برای کار با آن نوع داده ارائه می‌دهد؛ برای نمونه، ماژول `Integer` برای اعداد صحیح، ماژول `String` برای رشته‌ها، ماژول `List` برای فهرست‌ها و به همین ترتیب.

یک ماژول قابل توجه، ماژول `Kernel` است. این ماژول توانمندی‌های پایه‌ای را فراهم می‌کند که بقیه‌ی کتابخانه‌ی استاندارد بر پایه‌ی آن‌ها ساخته شده است؛ مواردی مانند عملگرهای حسابی، ماکروهای کنترل جریان و بسیاری موارد دیگر. توابع ماژول `Kernel` به‌طور خودکار وارد می‌شوند، بنابراین می‌توانید آن‌ها را بدون پیشوند `Kernel.` به کار ببرید.
