# دستورالعمل‌ها

آژانس فضایی Exercism (ESA) با تمام سرعت در حال برنامه‌ریزی برای مأموریتی تازه به [فوبوس][phobos] است، قمری از مریخ.
هدف این مأموریت نشاندن یک کاوشگر بر سطح فوبوس و فرستادن داده‌هایی درباره‌ی سطح آن است.
ESA از شما خواسته است که در ساخت رایانه‌ی ناوبری کاوشگر به آن کمک کنید.
حافظه‌ی رایانه‌ی ناوبری محدود است، پس باید مصرف حافظه را تا حد امکان پایین نگه داریم.
به همین دلیل باید از انواع داده‌ی مناسب استفاده کنیم.

## 1. ثابت‌های ناوبری

رایانه‌ی ناوبری برای انجام محاسبات درست باید فاصله‌ی میان بعضی از اجرام فضایی را بداند؛ این فاصله بر حسب کیلومتر اندازه‌گیری می‌شود.

ثابت‌های زیر را تعریف کنید:

- `NEPTUNE_DISTANCE` با مقدار `4_400_000_000` که باید به‌صورت یک `Int64` ذخیره شود
- `MARS_DISTANCE` با مقدار `227_940_000` که باید به‌صورت یک `Int32` ذخیره شود
- `ATMOSPHERE_DISTANCE` با مقدار `10_000` که باید به‌صورت یک `Int16` ذخیره شود

## 2. اصلاح تحلیل مساحت

رایانه‌ی ناوبری برای انجام محاسبات درست باید مساحت بعضی از اجرام فضایی را بداند.
مساحت **نمی‌تواند** منفی باشد.
مهندسان برنامه‌ریزی کرده بودند که برنامه هنگام منفی بودن مساحت، خطای سرریز تولید کند.
اما مهندسان فراموش کردند عدد صحیح علامت‌دار را به عدد صحیح بدون علامت تغییر دهند.

بنابراین، مهندسان برنامه‌ای می‌خواهند که یک عدد صحیح علامت‌دار را به یک عدد صحیح بدون علامت تبدیل کند.

متد `Navigation#correct_area_analysis` را پیاده‌سازی کنید که یک `measurement` را به عنوان آرگومان می‌گیرد و مساحت را به‌صورت یک عدد صحیح بدون علامت ۳۲ بیتی برمی‌گرداند.

~~~~exercism/note
مساحت داده‌شده همیشه در یک عدد صحیح بدون علامت ۳۲ بیتی جا می‌شود.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. محاسبه‌ی سرعت

رایانه‌ی ناوبری باید سرعت کاوشگر را بداند.
سرعت بر حسب متر بر ثانیه اندازه‌گیری می‌شود.

برای محاسبه‌ی سرعت باید مسافت پیموده‌شده و زمانی را که برای پیمودن آن مسافت صرف شده است بدانیم.
سپس مسافت را بر زمان تقسیم کنید.

سرعت می‌تواند کمی نادقیق باشد و هرگز عدد بزرگی نخواهد بود.
بنابراین می‌توانیم از یک `Float32` استفاده کنیم.

متد `Navigation#calculate_velocity` را پیاده‌سازی کنید که `distance` و `time` را به عنوان آرگومان می‌گیرد و سرعت را به‌صورت یک `Float` ۳۲ بیتی برمی‌گرداند.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
