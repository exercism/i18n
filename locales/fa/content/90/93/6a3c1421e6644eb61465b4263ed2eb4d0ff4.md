# درباره

[رکورد][records] مجموعه‌ای از فیلدهاست (که می‌توانند از انواع متفاوتی باشند) که به هم تعلق دارند. برای [تعریف رکورد][define] از کلیدواژه‌ی `type` استفاده می‌شود. فیلدهای یک رکورد بین دو کاراکتر `{` و `}` تعریف می‌شوند و هر فیلد یک اسم _و_ یک نوع دارد.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

برای [ساختن رکورد][create]، اسم فیلدها را مشخص کنید و بین دو کاراکتر `{` و `}` به آن‌ها مقدار بدهید. هنگام ساختن یک رکورد، باید به همه‌ی فیلدهای آن مقدار داده شود. فیلدها را می‌توان به هر ترتیبی مشخص کرد؛ لازم نیست با ترتیب تعریف نوع رکورد یکسان باشند. برای دسترسی به مقادیر فیلدهای یک نمونه رکورد، از نشانه‌گذاری نقطه استفاده می‌شود.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

هنگام تعریف یا ساختن یک رکورد، هر فیلد باید یا در خطی جداگانه باشد یا، وقتی همه در یک خط قرار دارند، با نقطه‌ویرگول (`;`) از هم جدا شود:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

اگر اسم‌های فیلدهای یک رکورد یکتا باشند، حاشیه‌نویسی نوع اختیاری است، چون کامپایلر می‌تواند نوع را به‌طور خودکار استنتاج کند. اگر ترکیب اسم فیلدها _یکتا نباشد_، می‌توانید به کامپایلر در انتخاب رکورد درست کمک کنید: یا نوعی صریح برای اتصال رکورد مشخص کنید، یا نام نوع رکورد را به‌عنوان پیشوند به یک یا چند فیلد اضافه کنید:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

از آنجا که رکوردها تغییرناپذیرند، پس از ساخته‌شدن یک رکورد، مقادیر فیلدهایش هرگز تغییر نمی‌کنند. اگر می‌خواهید مقادیر یک رکورد را تغییر دهید، کلیدواژه‌ی `with` به شما امکان می‌دهد [نسخه‌ای از یک رکورد موجود بسازید، اما با مقادیر تازه برای یک یا چند فیلد][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

رکوردها [_برابری ساختاری_][equality] دارند، یعنی دو نمونه از یک رکورد با مقادیر یکسان، هم‌ارز هستند:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

علاوه بر اینکه می‌توانید با نشانه‌گذاری نقطه به فیلدهای یک رکورد دسترسی داشته باشید، رکوردها را می‌توان در اتصال‌ها و در تطبیق الگو با استفاده از [الگوی رکورد][record-patterns] نیز _ازهم‌گشایی_ کرد:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
