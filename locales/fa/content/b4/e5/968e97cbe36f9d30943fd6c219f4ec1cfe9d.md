# درباره‌ی عملگرهای حسابی

## عملگرها

Go از عملگرهای حسابی زیر پشتیبانی می‌کند:

| عملگر | مثال           |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

در تقسیم صحیح، باقیمانده حذف می‌شود (مثلاً `5 / 2 == 2`).

عملگر `+` رشته‌ها را هم به هم می‌چسباند: `"foo" + "bar" == "foobar"`.

## عملیات حسابی با انواع متفاوت

Go اجازه نمی‌دهد عملیات حسابی میان انواع عددی مختلف انجام شود:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

عملوندها باید از یک نوع باشند و گاهی به تبدیل صریح نیاز دارند:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## انتساب‌های کوتاه‌شده

هر عملگر یک شکل کوتاه‌شده‌ی انتساب دارد که متغیر را در جای خودش به‌روزرسانی می‌کند:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## افزایش و کاهش

دستورهای افزایش (`++`) و کاهش (`--`) وقتی بعد از یک متغیر قرار بگیرند، مقدار عددی ذخیره‌شده در آن را به اندازه ۱ افزایش یا کاهش می‌دهند.
قرار دادن آن‌ها پیش از متغیر یک خطای نگارشی است.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

چون دستور هستند، مقداری برنمی‌گردانند.
