# مقدمه

AWK زبان بسیار کوچکی است و فقط چند نوع داده‌ی پایه دارد.
در این درس به اعداد و رشته‌ها می‌پردازیم.

## اعداد

اعداد در AWK به‌صورت اعداد اعشاری شناور با دقت مضاعف پیاده‌سازی شده‌اند.
هیچ تمایزی بین اعداد صحیح، اعشاری و دقت مضاعف وجود ندارد.

AWK ثابت‌های عددی در مبنای هشت (که با `0` شروع می‌شوند) و ثابت‌های عددی در مبنای شانزده (که با `0x` یا `0X` شروع می‌شوند) را می‌شناسد.

### عملیات عددی

می‌توانید از [عملگرهای حسابی استاندارد][ops-arith] `+`، `-`، `*`، `/` و `%` استفاده کنید.
عملگر توان `^` است (که POSIX آن را تعریف کرده است)، هرچند می‌توان از `**` هم استفاده کرد.
چند [تابع عددی توکار][funcs-numeric] وجود دارد، از جمله توابع مثلثاتی، تولید عدد تصادفی و `int(x)` که یک عدد را تا نزدیک‌ترین عدد صحیح بین _x_ و صفر کوتاه می‌کند.

عملگرهای _بیتی_ وجود ندارند.
gawk آن‌ها را به‌صورت تابع پیاده‌سازی می‌کند.
آرگومان‌ها باید اعداد نامنفی باشند.

| تابع                | عملیات                                         |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | AND بیتی آرگومان‌ها                            |
| `or(a, b [, ...])`  | OR بیتی آرگومان‌ها                             |
| `xor(a, b [, ...])` | XOR بیتی آرگومان‌ها                            |
| `lshift(v, count)`  | مقدار _v_ شیفت‌یافته به چپ به اندازه‌ی _count_ بیت  |
| `rshift(v, count)`  | مقدار _v_ شیفت‌یافته به راست به اندازه‌ی _count_ بیت |
| `compl(v, count)`   | متمم بیتی _v_                                  |

## رشته‌ها

رشته‌های AWK دنباله‌ای از کاراکترها هستند.
یک ثابت رشته‌ای را با گیومه‌های دوگانه مشخص کنید.

~~~~exercism/caution
GNU awk کاراکترهای یونیکد را در رشته‌ها مجاز می‌داند، اما سایر پیاده‌سازی‌های awk ممکن است چنین نکنند.
`gawk` را با `mawk`، یکی دیگر از پیاده‌سازی‌های محبوب AWK، مقایسه کنید:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### عملیات رشته‌ای

فقط یک عملیات رشته‌ای وجود دارد: اتصال.
اتصال عملگر ویژه‌ای ندارد؛
کافی است دو رشته را کنار هم بگذارید تا به هم متصل شوند:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` یک **دستور** است، نه یک تابع.
`print` به پرانتز نیازی ندارد.
~~~~

AWK مجموعه‌ی غنی‌ای از [توابع کار با رشته][funcs-string] دارد.
در ادامه‌ی مسیر، به‌طور عمیق با آن‌ها آشنا خواهیم شد.

## تبدیل بین اعداد و رشته‌ها

عملگر صریحی برای تبدیل بین اعداد و رشته‌ها وجود ندارد.
AWK این کار را به‌صورت ضمنی و بر اساس بافت برنامه انجام می‌دهد.
همین موضوع، کار با مقدار فیلدهای ورودی را بسیار ساده می‌کند: AWK معمولاً همان کاری را می‌کند که شما می‌خواهید.

* `print x + y` به لطف عملگر عددی `+`، مقدار متغیرهای `x` و `y` را به عدد تبدیل می‌کند.
* `print x y` به لطف عملیات اتصال، مقدار متغیرهای `x` و `y` را به رشته تبدیل می‌کند.

اگر بخواهید صریح عمل کنید، `0 + x` نمایش عددی _x_ و `"" x` نمایش رشته‌ای _x_ را به دست می‌دهد.

### تبدیل از رشته به عدد

شیوه‌ای که AWK یک رشته را به عدد تبدیل می‌کند می‌تواند گیج‌کننده باشد.
یک راه ساده برای درک آن این است که AWK از ابتدای رشته «کاراکترهای عددی» را می‌خواند تا به یک کاراکتر «غیرعددی» برسد.
چند مثال:

* `"2.5"` به عدد `2.5` تبدیل می‌شود؛
* `"1e3"` به عدد `1000` تبدیل می‌شود (نمایش علمی)؛
* `"456abc"` به عدد `456` تبدیل می‌شود (چون `a` یک «رقم» نیست، تبدیل همان‌جا متوقف می‌شود).
* `"abc789"` به عدد `0` تبدیل می‌شود (هیچ رقمی در **ابتدا**ی رشته وجود ندارد).

جزئیات کامل [در راهنما][str-to-num] آمده است.

## تعیین نوع متغیر

[تابع `typeof(var)`][func-typeof] نوع را به‌صورت یک رشته برمی‌گرداند.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
خروجی زیر را می‌دهد:
```none
42 string
43 number
```
