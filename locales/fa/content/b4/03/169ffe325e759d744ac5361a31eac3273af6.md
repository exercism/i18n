# درباره

ثابت‌ها در Gleam روشی برای اسم‌گذاری روی مقدارها هستند. آن‌ها با کلیدواژه‌ی `const` تعریف می‌شوند.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

وقتی ثابت‌های یک ماژول با کلیدواژه‌ی `pub` تعریف می‌شوند، ماژول‌های دیگر می‌توانند به آن‌ها دسترسی داشته باشند؛ در غیر این صورت، فقط از داخل همان ماژولی که ثابت‌ها در آن تعریف شده‌اند می‌توان به آن‌ها دسترسی داشت.
