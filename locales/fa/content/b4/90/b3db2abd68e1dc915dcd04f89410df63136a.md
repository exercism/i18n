# مقدمه

## ویژگی

یک «ویژگی» در C# عضوی از یک کلاس است که دسترسی به داده‌های داخل آن کلاس را فراهم می‌کند. کدهای فراخوانی‌کننده می‌توانند داده را تنظیم یا بازیابی (خواندن) کنند. ویژگی‌ها می‌توانند خودکارپیاده‌سازی‌شده باشند یا یک «فیلد پشتیبان» داشته باشند. ویژگی‌ها شامل یک «دسترسگر» `set` و/یا یک دسترسگر `get` هستند. در برخی زبان‌های دیگر، یک «تغییردهنده» تقریباً معادل یک دسترسگر `set` است و یک «دسترسگر» تقریباً معادل یک دسترسگر `get`، هرچند ساختار نحوه‌ی نگارش کاملاً متفاوت است.

هنگام تنظیم یک ویژگی، می‌توان مقدار ورودی را اعتبارسنجی کرد، قالب‌بندی کرد یا به شکل دیگری دستکاری کرد. در واقع، هر عملیات برنامه‌ای که برای کد داخل کلاس قابل دسترسی باشد، می‌تواند اجرا شود.

به همین ترتیب، هنگام بازیابی یک ویژگی می‌توان داده را محاسبه یا قالب‌بندی کرد و باز هم هر عملیات برنامه‌ای که در دسترس کلاس باشد، می‌تواند اجرا شود.

ویژگی‌ها مانند سایر اعضای کلاس «اصلاح‌کننده‌های دسترسی» (`public`، `private` و غیره) دارند، اما دسترسگر `set` می‌تواند سطح دسترسی‌ای مستقل از دسترسگر `get` داشته باشد و برعکس. یک ویژگی لازم نیست هر دو دسترسگر را داشته باشد؛ می‌تواند فقط یکی را داشته باشد (یا `get` یا `set`).

نحوه‌ی نگارش پایه برای بیان ویژگی‌ها دو شکل دارد:

### ویژگی مبتنی بر فیلد/عبارت:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### ویژگی خودکارپیاده‌سازی‌شده

```
public int MyProperty { get; private set; } = 42;
```
