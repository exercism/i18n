## متغیر

متغیرها اسم‌هایی نمادین‌اند که یا به مقدارها ارجاع می‌دهند یا به «مخزن»ها. اسم متغیر می‌تواند با نویسه‌ی خاصی به اسم [sigil][sigils] شروع شود یا بدون آن؛ در هر دو حالت پس از آن یک شناسه می‌آید. همچنین پس از این نویسه‌ی خاص می‌تواند یک [twigil][twigils] بیاید.

متغیرهایی که نویسه‌ی خاص متفاوتی دارند، انواع متفاوتی از ساختارهای داده را در خود نگه می‌دارند.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

twigilهایی که معمولاً زیاد می‌بینید `^` و `:` هستند؛ این دو میانبری برای امضای بلوک کد به شمار می‌آیند. `^` برای پارامترهای موقعیتی است. `:` برای پارامترهای نامدار است.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## مخزن

مخزن همان چیزی است که امکان تغییر یک متغیر را فراهم می‌کند.

متغیرهایی که با `constant` تعریف می‌شوند و همچنین متغیرهای بدون نویسه‌ی خاص (که با یک `\` پیش از شناسه تعریف می‌شوند)، مخزن ندارند و در عوض مستقیماً به مقدارها ارجاع می‌دهند.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## نوع

متغیرها می‌توانند با یک محدودیت نوع تعریف شوند. محدودیت نوع می‌تواند تبدیل نوع هم داشته باشد؛ کافی است یک نوع پذیرفته‌شده را به عنوان آرگومان به نوع موردنظر بدهید.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

استفاده از محدودیت‌های نوع، راهی برای بهره‌گیری از روال‌های چندفرستی است.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

نوع‌ها در Raku فقط نوع دیگری از شیء هستند. تعریف `class`، `role` یا `enum` روش‌هایی برای ساختن شیءهای نوع خودتان است. برای مثال، نوع توکار `Bool` با یک `enum` ساخته می‌شود: `enum Bool <False True>`.

همچنین می‌توانید با کلیدواژه‌ی `subset` محدودیت‌های نوع ساده‌ای بر پایه‌ی نوع‌های دیگر بسازید. می‌توانید این نوع تازه را با استفاده از یک شرط `where` بیشتر محدود کنید. یک شرط `where` را می‌توان در امضا هم به کار برد.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
