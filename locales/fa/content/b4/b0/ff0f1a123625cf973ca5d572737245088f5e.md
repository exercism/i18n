# مقدمه

«اعداد اعشاری» اعدادی هستند که یک یا چند رقم بعد از جداکننده‌ی اعشار دارند.

```gleam
let float = 3.45
// -> 3.45
```

اعداد اعشاری عملگرهای مخصوص به خود را هم دارند.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```
