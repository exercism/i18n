# دستورالعمل‌ها

شما مسئول تدارکات کشتی هستید و موجودی انبار آذوقه را مدیریت می‌کنید. موجودی یک «هش‌تیبل» است که در آن هر کلید اسم یک قلم کالا و هر مقدار تعداد آن در انبار است.

## 1. ساختن موجودی از یک فهرست

`create-inventory` را طوری تعریف کنید که دنباله‌ای از اسم اقلام را بگیرد و یک هش‌تیبل برگرداند که هر اسم یکتا را با تعدادش جفت می‌کند.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. افزودن اقلام بیشتر

`add-items` را طوری تعریف کنید که یک موجودی و دنباله‌ای از اقلام را بگیرد و موجودی تازه‌ای برگرداند که در آن تعداد هر قلمی که در فهرست آمده، افزایش یافته است. موجودی اصلی نباید تغییر کند.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. کاهش تعدادها

`decrement-items` را طوری تعریف کنید که یک موجودی و دنباله‌ای از اقلام را بگیرد و موجودی تازه‌ای برگرداند که در آن تعداد هر قلمی که در فهرست آمده، یک واحد کاهش یافته است. تعدادها هرگز نباید به زیر صفر برسند و اقلامی که از قبل در موجودی نیستند باید نادیده گرفته شوند (هیچ ورودی منفی‌ای درج نمی‌شود).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. حذف کامل یک قلم

`remove-item` را طوری تعریف کنید که یک موجودی و یک قلم را بگیرد و موجودی تازه‌ای برگرداند که آن قلم از آن حذف شده است. اگر آن قلم در موجودی نباشد، یک نسخه‌ی بدون تغییر برگردانید.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. فهرست کردن اقلام موجود

`list-inventory` را طوری تعریف کنید که یک موجودی را بگیرد و آرایه‌ای از جفت‌های `{ name quantity }` برگرداند که فقط اقلامی را شامل می‌شود که مقدارشان بیشتر از صفر است و این جفت‌ها بر اساس اسم به ترتیب الفبا مرتب شده‌اند.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
