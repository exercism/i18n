# راهنماها

## کلی

- نگران نباشید که آرگومان‌ها چطور به دست می‌آیند؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید.

## 1. تعریف کنید که آیا pac-man می‌تواند یک روح را بخورد

- تابع باید یک «مقدار [منطقی][boolean]» را برگرداند.
- می‌توانید برای ترکیب آرگومان‌ها و رسیدن به نتیجه، از عملگر [منطقی][boolean] [`and/2`][boolean-and] استفاده کنید.

## 2. تعریف کنید که آیا pac-man امتیاز می‌گیرد

- تابع باید یک مقدار [منطقی][boolean] را برگرداند.
- می‌توانید برای ترکیب آرگومان‌ها و رسیدن به نتیجه، از عملگر [منطقی][boolean] [`or/2`][boolean-or] استفاده کنید.

## 3. تعریف کنید که آیا pac-man می‌بازد

- تابع باید یک مقدار [منطقی][boolean] را برگرداند.
- می‌توانید برای ترکیب آرگومان‌ها و رسیدن به نتیجه، از عملگرهای [منطقی][boolean] [`and/2`][boolean-and] و [`not/1`][boolean-not] استفاده کنید.

## 4. تعریف کنید که آیا pac-man می‌برد

- تابع باید یک مقدار [منطقی][boolean] را برگرداند.
- می‌توانید برای ترکیب آرگومان‌ها و نتایج یکی از توابعی که قبلاً پیاده‌سازی کرده‌اید، از عملگرهای [منطقی][boolean] [`and/2`][boolean-and] و [`not/1`][boolean-not] استفاده کنید.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
