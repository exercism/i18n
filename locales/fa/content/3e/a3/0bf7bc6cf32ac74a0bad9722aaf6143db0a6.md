# مقدمه‌ای بر آرایه

Bash دو نوع پارامتر فراهم می‌کند: مقادیر «اسکالر» و آرایه‌ها.
یک مقدار اسکالر می‌تواند یک رشته یا یک عدد باشد و نماینده‌ی یک واحد مستقل است.

بیشتر اوقات، مقادیر اسکالر برای نگه‌داشتن داده‌های شما کافی‌اند.
اما گاهی لازم است فهرستی از مقادیر اسکالر را ذخیره کنید.
در این حالت از یک _آرایه_ استفاده می‌کنید.

دو نوع آرایه وجود دارد:

* آرایه‌های با اندیس عددی، یک کلید صحیح را به یک مقدار رشته‌ای نگاشت می‌کنند.
  (زبان‌های دیگر ممکن است به این «لیست» یا «دنباله» بگویند.)
* آرایه‌های انجمنی، یک کلید رشته‌ای را به یک مقدار رشته‌ای نگاشت می‌کنند.
  (زبان‌های دیگر ممکن است به این «نقشه» یا «دیکشنری» بگویند.)

چند بخش نخست این نوشتار به آرایه‌های با اندیس عددی می‌پردازد (که از این پس به‌سادگی «آرایه» نامیده می‌شوند).
جزئیات مربوط به آرایه‌های انجمنی در پایان می‌آید.

~~~~exercism/caution
آرایه‌های Bash _فقط_ می‌توانند مقادیر اسکالر ذخیره کنند.
امکان ساختن یک آرایه‌ی دوبعدی (آرایه‌ی آرایه‌ها) وجود ندارد.
~~~~

## اعلام و مقداردهی اولیه‌ی یک متغیر آرایه

می‌توانید یک آرایه را با انتساب فهرستی از عناصر که داخل پرانتز قرار دارد (و می‌تواند خالی باشد) به یک متغیر، مقداردهی اولیه کنید.

```bash
myarray=("one" "two" "three")
```

همان‌طور که در هر انتساب متغیر رخ می‌دهد، نباید اطراف علامت مساوی فاصله‌ای باشد.

توجه کنید که میان عناصر جداکننده‌ی ویرگول وجود ندارد؛ این فهرستی از رشته‌هاست که با فضای خالی از هم جدا شده‌اند.

در واقع، میزان فضای خالی داخل پرانتزها کاملاً دلبخواه است.
خط جدید هم مجاز است؛ هر تعداد که برای خوانایی بهتر می‌خواهید به کار ببرید.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

انتساب فهرستی از رشته‌ها به یک متغیر آرایه به این شیوه، رشته‌ی اول را در اندیس ۰، رشته‌ی بعدی را در اندیس ۱، و بعدی را در اندیس ۲ و به همین ترتیب ذخیره می‌کند.

می‌توان با مشخص کردن اندیس‌های موردنیاز، یک «آرایه‌ی تُنُک» را مقداردهی اولیه کرد.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
برای تأکید دوباره: اندیس‌های آرایه از صفر شروع می‌شوند.
این قطعه‌کد «true» را چاپ می‌کند:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

می‌توانید از دستور `declare` (یا `local` درون یک تابع) استفاده کنید تا مشخص کنید که یک متغیر یک آرایه نگه می‌دارد.

```bash
declare -a myarray
```

طبیعی‌تر است که برای مقداردهی اولیه‌ی متغیر، صرفاً یک فهرست داخل پرانتز (شاید خالی) را انتساب دهید.

## دسترسی به عناصر یک آرایه

همان‌طور که در نکته‌ی بالا دیدید، نحوه‌ی نگارش دسترسی به یک عنصر آرایه `${myarray[$index]}` است.
اندیس داخل کروشه نوشته می‌شود.
آکولادها الزامی‌اند.

~~~~exercism/note
برای آرایه‌های با اندیس عددی، اندیس یک عبارت حسابی است.
راهنمای Bash [می‌گوید][arithmetic]:

> درون یک عبارت حسابی، متغیرهای شل را می‌توان با اسمشان نیز ارجاع داد، بدون آنکه از نحوه‌ی نگارش بسط پارامتر استفاده شود.

این یعنی برای بسط «ساده‌ی» متغیر، وجود `$` لازم نیست.
می‌توانید عناصر را به این شکل دسترسی بگیرید که کمی خواناتر است:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

اگر اندیس داده‌شده در آرایه وجود نداشته باشد، نتیجه‌ی بسط یک رشته‌ی خالی است.

## انتساب به یک آرایه

برای انتساب به یک درایه‌ی مشخص از آرایه، از این نحوه‌ی نگارش استفاده کنید:

```bash
myarray[10]="hello"
```

برای _الحاق_ به یک آرایه، از عملگر انتساب-الحاق `+=` استفاده کنید و پرانتزها را هم به کار ببرید:

```bash
myarray+=("new element 1" "new element 2")
```

## پیمایش یک آرایه

معمولاً لازم است روی _مقادیر_ یک آرایه پیمایش کنید.
از یک حلقه‌ی For استفاده کنید (همان که در مفهوم [حلقه][looping] دیدید):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

به نحوه‌ی نگارش ویژه‌ی بسط آرایه توجه کنید: `"${myarray[@]}"`
این شکل از بسط پارامتر، مقادیر آرایه را به‌صورت واژه‌های جداگانه جایگزین می‌کند.
تا حدی معادل این است:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

شکل `"${myarray[@]}"` با آرایه‌های تُنُک هم کار می‌کند و تنها به مقادیر تعریف‌شده بسط می‌یابد.

این بسط ویژه، که در آن اندیس یک آمپرسند (`@`) است، تنها درون گیومه‌ی دوگانه ویژه به شمار می‌آید.

#### بسط‌های پارامتر ویژه‌ی دیگر

چند نمونه‌ی دیگر از نحوه‌ی نگارش ویژه هم هست که برای پیمایش یک آرایه به آن‌ها نیاز داریم.
این‌ها در راهنما زیر [بسط پارامتر شل][man-expn] توضیح داده شده‌اند.

برای یافتن _طول_ یک آرایه، از `${#myarray[@]}` استفاده کنید که یک `#` پیش از اسم می‌آید.
«طول» یک آرایه یعنی تعداد عناصر آن.

برای استخراج فهرست _اندیس‌های_ یک آرایه، از `"${!myarray[@]}"` استفاده کنید که یک `!` پیش از اسم می‌آید و بسط درون گیومه‌ی دوگانه قرار دارد.
برای آرایه‌های با اندیس عددی، اندیس‌ها به ترتیب عددی بسط می‌یابند.

### پیمایش روی اندیس‌های آرایه

گاهی هم به اندیس نیاز دارید و هم به مقدار.
چند راه برای این کار وجود دارد.

1. وقتی می‌دانید که اندیس‌ها دنباله‌ای بی‌وقفه تشکیل می‌دهند، می‌توانید از یک حلقه‌ی For _حسابی_ استفاده کنید.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   به نحوه‌ی نگارش `${#myarray[@]}` توجه کنید که نویسه‌ی `#` پیش از اسم آرایه می‌آید.
   چون آرایه‌ها از اندیس‌گذاری مبتنی بر صفر استفاده می‌کنند، آخرین اندیس آرایه یکی کمتر از طول آرایه است.

2. وقتی آرایه تُنُک است، می‌توانید از این شکل استفاده کنید:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   به نحوه‌ی نگارش `${!myarray[@]}` توجه کنید که نویسه‌ی `!` پیش از اسم آرایه می‌آید.

## بررسی یک آرایه

اگر می‌خواهید محتوای یک آرایه را ببینید، از دستور `declare` با گزینه‌ی `-p` استفاده کنید:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

این محتوا را با نقل‌قول استاندارد شل چاپ می‌کند.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## آرایه‌های انجمنی

برای تأکید دوباره، آرایه‌های انجمنی از رشته‌ها به‌عنوان اندیس استفاده می‌کنند، نه از اعداد.
هر آنچه در بالا نوشته شد برای آرایه‌های انجمنی هم صادق است، اما با تفاوت‌های کوچکی.
به‌طور کلی، ما اصطلاح «کلید» را به کار می‌بریم و نه «اندیس»: آرایه‌های انجمنی کلیدها را به مقدارها نگاشت می‌کنند.

### اعلام یک آرایه‌ی انجمنی

برخلاف آرایه‌ها، آرایه‌های انجمنی **باید** اعلام شوند.
از گزینه‌ی `-A` برای `declare` (یا `local` درون یک تابع) استفاده کنید:

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### مقداردهی اولیه‌ی یک آرایه‌ی انجمنی

جفت‌های کلید-مقدار درون فهرست داخل پرانتز مشخص می‌شوند:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

خروجی این است:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
توجه داشته باشید که آرایه‌های انجمنی **بی‌ترتیب** هستند.
~~~~

اعلام و مقداردهی اولیه می‌توانند در یک خط انجام شوند.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

در نسخه‌های اخیر Bash، مقداردهی اولیه می‌تواند از فهرست `(key value key value ...)` استفاده کند.

```bash
declare -A mymap=(first foo second bar third baz)
```

### دسترسی به مقدارها

برای دسترسی به عناصر همان نحوه‌ی نگارش پیشین به کار می‌رود: `${mymap[$key]}`.

کلیدهای آرایه‌ی انجمنی در بافت حسابی ارزیابی نمی‌شوند.
نحوه‌ی نگارش معمول بسط پارامتر لازم است.

### انتساب به یک آرایه‌ی انجمنی

انتساب از همان نحوه‌ی نگارش پیشین استفاده می‌کند:

```bash
mymap[$key]="$value"
```

### پیمایش

می‌توانید از یک حلقه‌ی `for value in "${mymap[@]}"` برای پیمایش استفاده کنید.
اما معمولاً می‌خواهید کلید هم همراه مقدار بیاید.

از همان نحوه‌ی نگارش `"${!mymap[@]}"` که در بالا دیدیم استفاده کنید.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

خروجی این است

```
second -> bar
first -> foo
third -> baz
```

برای تأکید دوباره، هیچ ترتیبی میان کلیدها وجود ندارد.
