# دستورالعمل‌ها

الیس، جادوگر تازه‌کار، تمرین‌هایش را ادامه می‌دهد. چندین دسته کارت به او داده می‌شود که برای اجرای ترفندهایش به آن‌ها نیاز دارد.
برای اینکه کارها کمی آسان‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

در این تمرین، برای تحلیل محتوای یک آرایه از متدهای داخلی استفاده کنید.

## 1. موقعیت یک کارت را پیدا کنید

الیس می‌خواهد موقعیت (ایندکس) یک کارت در دسته را بداند.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. مشخص کنید که آیا کارتی وجود دارد

الیس می‌خواهد مشخص کند که آیا کارتی در دسته وجود دارد؛ به عبارت دیگر، آیا دسته شامل یک `number` مشخص است یا نه.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. مشخص کنید که آیا هر کارت زوج است

الیس می‌خواهد بداند که آیا هر کارت زوج است؛ به عبارت دیگر، آیا هر عدد در دسته یک `number` زوج است یا نه.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. بررسی کنید که آیا دسته کارتی با مقدار فرد دارد

الیس می‌خواهد بداند که آیا عددی فرد در دسته وجود دارد.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. اولین کارت فرد را از دسته بگیرید

الیس می‌خواهد مقدار اولین کارت فرد را بداند.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. موقعیت اولین کارت زوج را مشخص کنید

الیس می‌خواهد موقعیت اولین کارت زوج را بداند.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
