# دستورالعمل‌ها

یک عدد در مبنای شانزده را که به‌صورت یک رشته نمایش داده شده است (مثلاً «10af8c») با استفاده از اصول اولیه به معادل مبنای ده آن تبدیل کنید (یعنی نه، اجازه ندارید برای انجام این تبدیل از کتابخانه‌های داخلی یا بیرونی استفاده کنید).

در وب برای نمایش رنگ‌ها از مبنای شانزده استفاده می‌کنیم؛ مثلاً سبز: 008000، فیروزه‌ای: 008080، سرمه‌ای: 000080).

برنامه باید رشته‌های نامعتبر مبنای شانزده را هم مدیریت کند.
