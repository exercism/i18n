# پیوست دستورالعمل‌ها

## ثبات

| ثبات    | کاربرد | نوع       | توضیح                                                                                  |
| ------- | ------ | --------- | -------------------------------------------------------------------------------------- |
| `$a0`   | ورودی  | عدد صحیح  | ضلع a                                                                                  |
| `$a1`   | ورودی  | عدد صحیح  | ضلع b                                                                                  |
| `$a2`   | ورودی  | عدد صحیح  | ضلع c                                                                                  |
| `$v0`   | خروجی  | عدد صحیح  | نوع مثلث (`0` = مختلف‌الاضلاع، `1` = متساوی‌الساقین، `2` = متساوی‌الاضلاع، `3` = نامعتبر) |
| `$t0-9` | موقت   | هر نوع    | برای ذخیره‌سازی موقت به کار می‌رود                                                       |
