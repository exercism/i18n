# مقدمه

یک رابط را می‌توان به‌عنوان امضای یک کلاس درک کرد، زیرا فیلدهای عمومی یک کلاس را توصیف می‌کند. یک کلاس یک `interface` را با کلیدواژه‌ی `implments` _پیاده‌سازی می‌کند_.

نحوه‌ی نگارش آن بسیار شبیه به یک کلاس است، با این تفاوت که متدها به صورت امضاهایی بدون بدنه ظاهر می‌شوند:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

فیلدهایی که از یک رابط پیاده‌سازی می‌شوند **باید** همیشه از یک تعدیل‌کننده‌ی دسترسی یکسان استفاده کنند. برای مثال، اگر متغیر `a` در یک رابط `public` باشد، پیاده‌سازی آن نیز باید `public` باشد.
