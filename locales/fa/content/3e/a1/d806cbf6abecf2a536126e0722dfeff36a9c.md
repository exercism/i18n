# مقدمه

یک `string` در C# شیئی است که متنی تغییرناپذیر را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، نشانه‌های نگارشی و غیره) نمایش می‌دهد. برای تعریف یک نمونه‌ی `string` از گیومه‌های دوگانه استفاده می‌شود:

```csharp
string fruit = "Apple";
```

کار با `string`ها از طریق فراخوانی متدهای آن انجام می‌شود. وقتی یک `string` ساخته شد، مقدارش هرگز تغییر نمی‌کند. هر متدی که به نظر برسد `string` را تغییر می‌دهد، در واقع یک `string` جدید برمی‌گرداند.

چند `string` را می‌توان به هم الحاق کرد (جمع کرد). ساده‌ترین راه برای این کار استفاده از عملگر `+` است.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

برای هر قالب‌بندی `string` که پیچیده‌تر از الحاق ساده باشد، درج مقادیر درون `string` ترجیح داده می‌شود. برای استفاده از درج درون یک `string`، نماد دلار (`$`) را به ابتدای آن اضافه کنید. سپس می‌توانید با آکولاد (`{}`) به هر متغیری درون `string` خودتان دسترسی داشته باشید.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
