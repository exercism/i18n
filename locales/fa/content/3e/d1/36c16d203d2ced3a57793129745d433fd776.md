# دستورالعمل‌ها

در این تمرین روی یک برنامه‌ریز قرار ملاقات برای یک سالن زیبایی کار می‌کنید.

سه وظیفه دارید که همه‌ی آن‌ها به تاریخ‌های قرار ملاقات مربوط می‌شوند.

## 1. بررسی کنید که آیا قرار ملاقات پیش‌تر گذشته است

تابع `appointment_has_passed` را پیاده‌سازی کنید که یک رشته‌ی تاریخ می‌گیرد و بررسی می‌کند که آیا قرار ملاقات جایی در گذشته بوده است:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

رشته‌های تاریخ در قالب تاریخ و زمان ISO 8601 پاس داده می‌شوند: `YYYY-mm-ddTHH:MM:SS`

باید تابع خصوصی `_parse_datetime` را پیاده‌سازی کنید.
چند ماژول هم برایتان پیشنهاد می‌شود:

- [Time::Piece][time-piece] یکی از ماژول‌های اصلی Perl است.
- [DateTime::Tiny][datetime-tiny] از CPAN در دسترس است.

## 2. بررسی کنید که آیا قرار ملاقات بعدازظهر است

تابع `is_afternoon_appointment` را پیاده‌سازی کنید که یک رشته‌ی تاریخ می‌گیرد و بررسی می‌کند که آیا قرار ملاقات بعدازظهر است (>= ۱۲:۰۰ و < ۱۸:۰۰):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. زمان و تاریخ قرار ملاقات را توصیف کنید

تابع `describe_appointment` را پیاده‌سازی کنید که یک رشته‌ی تاریخ می‌گیرد و توصیفی از آن تاریخ و زمان برمی‌گرداند:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

توجه کنید که ساعت در بازه‌ی ۰ تا ۱۲ قرار دارد و صفر یا فاصله‌ای در ابتدای آن نمی‌آید.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
