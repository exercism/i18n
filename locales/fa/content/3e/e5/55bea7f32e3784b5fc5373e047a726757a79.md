# دستورالعمل

در شهرتان چندین فروشگاه برش پیتزا دارید و می‌خواهید یک اپلیکیشن وب بنویسید که به شما امکان دهد دو پیکربندی مختلف پیتزا را مقایسه کنید تا بفهمید کدام‌یک برش بزرگ‌تری به شما می‌دهد.

## 1. یک تابع بنویسید که اندازه‌ی برش‌ها را محاسبه کند و برای ورودی نامعتبر `nil` برگرداند.

تابع `sliceSize(diameter: Double?, slices: Int?) -> Double?` را پیاده‌سازی کنید که با گرفتن قطر پیتزا و تعداد برش‌های هر پیتزا، مساحت یک برش را برمی‌گرداند.
برای قطرهای منفی و تعداد برش‌های کمتر از ۱، `nil` برگردانید، چون پیتزایی با قطر منفی وجود ندارد و نمی‌توان پیتزا را به کمتر از ۱ برش تقسیم کرد.
اگر هر یک از پارامترها `nil` باشد، `nil` برگردانید.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. ورودی اپلیکیشن وب خود را پردازش کنید تا برش بزرگ‌تر را مشخص کنید.

اپلیکیشن وب شما چهار رشته به تابع `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String` ارسال می‌کند.
رشته‌ی اول و دوم به‌ترتیب قطر و تعداد برش‌های پیتزای اول هستند و رشته‌ی سوم و چهارم به‌ترتیب قطر و تعداد برش‌های پیتزای دوم.

`biggestSlice` را طوری پیاده‌سازی کنید که تلاش کند قطر و تعداد برش‌های هر پیتزا را به‌ترتیب به یک `Double` و یک `Int` تبدیل کند.
اگر بتوان هر دوی این مقادیر را از رشته‌ها به دست آورد، از تابع اول خود برای محاسبه‌ی مساحت استفاده کنید، در غیر این صورت مساحت آن برش `nil` است.
وقتی مساحت هر دو برش به دست آمد، دو مساحت را با قواعد زیر مقایسه کنید:

1. اگر مساحت برش A یک `Double` باشد و مساحت برش B `nil` باشد، «Slice A is bigger» را برگردانید. اگر برعکس بود، «Slice B is bigger» را برگردانید.
2. اگر هر دو مساحت `Double`ها باشند، بر اساس اینکه کدام برش مساحت بزرگ‌تری دارد، «Slice A is bigger» یا «Slice B is bigger» را برگردانید.
3. اگر هر دو مساحت `nil` باشند، یا اگر هر دو `Double` و برابر باشند، «Neither slice is bigger» را برگردانید.

~~~~exercism/note
حتی اگر ورودی منجر به مساحت برش ۰ شود، آن برش همچنان معتبر در نظر گرفته می‌شود و باید بزرگ‌تر از برشی با مساحت `nil` دیده شود.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
