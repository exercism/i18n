# مقدمه

**«کلمه»** نامی است که Factor برای تابع گذاشته است. این مفهوم که بر پشته‌ی داده از `basics` بنا شده، درباره‌ی تعریف کلمه‌های خودتان است: انجام محاسبات حسابی، نام‌گذاری مقادیر ثابت و ساختن کلمه‌ها از کلمه‌های دیگر.

هر تعریف با `:` آغاز می‌شود، بعد اثر پشته می‌آید، سپس بدنه و در پایان `;`. کامپایلر بررسی می‌کند که بدنه با اثر اعلام‌شده مطابقت داشته باشد:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

کلمه‌های حساب اعداد صحیح، یعنی `+`، `-` و `*`، هر یک دو عدد را از پشته برمی‌دارد و نتیجه را روی پشته می‌گذارد. این کلمه‌ها در واژگان `math` قرار دارند، پس فایلی که از آن‌ها استفاده می‌کند باید `math` را در خط `USING:` خود داشته باشد. بالای پشته، عملوند سمت راست است:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` یک مقدار ثابت را نام‌گذاری می‌کند. خودِ ثابت هم یک کلمه است؛ فراخوانی آن مقدار را روی پشته می‌گذارد:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

بدنه‌ی یک کلمه می‌تواند هر کلمه‌ای را که در دامنه قرار دارد فراخوانی کند، از جمله کلمه‌هایی که قبلاً در همان فایل تعریف کرده‌اید:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

`?` در انتهای خروجی‌ها، قراردادِ «مقدار منطقی» است. هم کلمه‌ها و هم ثابت‌ها از `lowercase-kebab-case` استفاده می‌کنند.
