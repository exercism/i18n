# Tests

اگر تمرینی را با ابزار CLI دانلود کرده باشید، باید یک فایل Uiua با اسم تمرین و یک فایل `tests.ua` ببینید.
این فایل شامل همه‌ی موارد تست است؛ همان مواردی که وقتی راه‌حل خود را بارگذاری می‌کنید، ابزار اجرای تست اجرا می‌کند.
برای آزمایش، به‌راحتی می‌توانید موارد تست بیشتری اضافه کنید.
اما تغییر دادن تست‌ها تأثیری بر فرایند اجرای تست آنلاین ندارد.

## تست محلی

برای اجرای تست‌های یک تمرین، یک ترمینال در پوشه‌ی تمرین باز کنید و فرمان `uiua test tests.ua` را اجرا کنید.

برای نمونه، خروجی یک تمرین `hello-world` ویرایش‌نشده ممکن است چنین باشد:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

خط `Error` خروجی واقعی کد شما را نشان می‌دهد.
شماره‌ی خط، محل نتیجه‌ی مورد انتظار در `tests.ua` را مشخص می‌کند.
یک راه‌حل درست چنین چیزی تولید می‌کند:

```bash
$ uiua test tests.ua
Test passed
```
