# مقدمه

یک فایل چیزی نیست جز یک جریان که اسمی روی دیسک دارد. واژگان [`io.files`][io.files] دو روش برای کار با آن پیش پای شما می‌گذارد: واژه‌های راحتی که کل فایل را در یک فراخوانی می‌خوانند یا می‌نویسند، و واژه‌های بازکردن جریان برای وقتی که می‌خواهید تکه‌تکه بخوانید یا بنویسید.

هر واژه‌ای که با فایل سر و کار دارد یک **کدگذاری** می‌گیرد، یعنی روشی که بایت‌ها را به کاراکتر و برعکس تبدیل می‌کند. برای متن، این تقریباً همیشه [`utf8`][utf8] از `io.encodings.utf8` است.

## خواندن کل یک فایل

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` تمام فایل را به‌صورت یک رشته برمی‌گرداند. `file-lines` هم آرایه‌ای از خطوط آن را برمی‌گرداند، که خط‌های جدیدش حذف شده است.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## نوشتن کل یک فایل

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

هر دو محتوای فایل را **جایگزین** می‌کنند (و در صورت نیاز آن را می‌سازند). `set-file-contents` یک رشته را عیناً می‌نویسد؛ `set-file-lines` هر عنصر از یک دنباله را در خط خودش می‌نویسد و خط‌های جدید را خودش اضافه می‌کند.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## افزودن به یک فایل

برای افزودن به یک فایل بدون پاک‌کردن آنچه از قبل در آن هست، آن را با یک ترکیب‌کننده‌ی `with-…` باز کنید و داخل بلوک کد به جریان محیطی بنویسید:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

این‌ها هم مثل هر ترکیب‌کننده‌ی `with-…` دیگری دامنه‌های آزادسازی منابع‌اند: وقتی اجرای بلوک کد تمام شود، دسته‌ی فایل بسته می‌شود، حتی اگر خطایی پرتاب شود.
