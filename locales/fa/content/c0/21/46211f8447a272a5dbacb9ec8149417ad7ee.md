# مقدمه

Cairo دیکشنری‌ها را به‌عنوان بخشی از کتابخانه‌های اصلی خود ارائه می‌دهد که با نوع `Felt252Dict<T>` نمایش داده می‌شوند.

نوع کلید دیکشنری در Cairo به `felt252` محدود شده است، برخلاف زبان‌های دیگر که در آن‌ها می‌توان نوع کلید را تعریف کرد.

برای ساختن یک دیکشنری، می‌توانید از متد `default` در trait `Default` استفاده کنید، به این صورت:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

عملیات‌های اصلی که بیشتر از همه استفاده می‌شوند عبارت‌اند از:

1. `insert(felt252, T) -> ()` برای نوشتن مقدارها در یک نمونه دیکشنری و
2. `get(felt252) -> T` برای خواندن مقدارها از آن.

و این هم نحوه‌ی استفاده از این عملیات‌ها:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

اگر مقدار یک کلید را بازیابی کنید که در دیکشنری وجود ندارد، دیکشنری مقدار صفرِ نوع مقدار را برمی‌گرداند.

این می‌تواند شما را گیج کند، به‌ویژه اگر مقدار پیش‌فرض نوع مقدار شما (برای مثال، ۰ برای یک عدد صحیح) یک مقدار معتبر باشد.

این همچنین به این معناست که راهی برای حذف داده‌ها از یک دیکشنری وجود ندارد.

نکته‌ای که هنگام گنجاندن این ساختار در کد خود باید در نظر بگیرید.
