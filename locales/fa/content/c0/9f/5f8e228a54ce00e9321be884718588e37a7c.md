# دستورالعمل‌ها

کار روی پروژه‌ی ماشین کنترل از راه دور ادامه دارد. پهنای باند در سامانه‌ی تله‌متری بسیار محدود است و از شما خواسته شده است که یک پروتکل پیام برای انتقال داده‌های تله‌متری پیاده‌سازی کنید.

داده‌ها در یک بافر (آرایه‌ی بایت) منتقل می‌شوند. هنگام ارسال اعداد صحیح، با به‌کارگیری پروتکلی که در ادامه توضیح داده شده است، اندازه‌ی بافر کاهش می‌یابد.

هر مقدار باید در کوچک‌ترین نوع صحیح ممکن نمایش داده شود (انواع `byte` و `sbyte` لحاظ نشده‌اند، چون صرفه‌جویی ناچیز خواهد بود):

| از                         | تا                        | نوع      |
| -------------------------- | ------------------------- | -------- |
| ۴٬۲۹۴٬۹۶۷٬۲۹۶              | ۹٬۲۲۳٬۳۷۲٬۰۳۶٬۸۵۴٬۷۷۵٬۸۰۷ | `long`   |
| ۲٬۱۴۷٬۴۸۳٬۶۴۸              | ۴٬۲۹۴٬۹۶۷٬۲۹۵             | `uint`   |
| ۶۵٬۵۳۶                     | ۲٬۱۴۷٬۴۸۳٬۶۴۷             | `int`    |
| ۰                          | ۶۵٬۵۳۵                    | `ushort` |
| منفی ۳۲٬۷۶۸                | منفی ۱                    | `short`  |
| منفی ۲٬۱۴۷٬۴۸۳٬۶۴۸         | منفی ۳۲٬۷۶۹               | `int`    |
| منفی ۹٬۲۲۳٬۳۷۲٬۰۳۶٬۸۵۴٬۷۷۵٬۸۰۸ | منفی ۲٬۱۴۷٬۴۸۳٬۶۴۹      | `long`   |

مقدار باید به تعداد بایت مناسب برای نوع تخصیص‌یافته‌اش تبدیل شود. بافر کامل شامل یک بایت است که شمار بایت‌های اضافی در بافر را نشان می‌دهد (_بایت پیشوند_) و پس از آن بایت‌هایی قرار می‌گیرند که عدد صحیح را در خود دارند (_بایت‌های داده_).

برخی از انواع از تعداد بایت یکسانی استفاده می‌کنند (مثلاً انواع `uint` و `int`). به‌طور معمول، آن‌ها _بایت پیشوند_ یکسانی می‌داشتند، اما این کار رمزگشایی را دشوار می‌کرد. برای مقابله با این مشکل، پروتکل ترفند کوچکی به کار می‌برد: برای انواع علامت‌دار، مقدار _بایت پیشوند_ برابر است با `256` منهای شمار بایت‌های اضافی در بافر.

در ارتباط، فقط بایت پیشوند و شمار بایت‌های بعدی که با پیشوند مشخص می‌شوند فرستاده می‌شوند. در داخل، هم روال‌های ارسال و هم روال‌های دریافت از یک بافر ۹ بایتی استفاده می‌کنند (در صورت لزوم با صفرهای انتهایی).

## 1. یک مقدار صحیح آماده‌ی ارسال را رمزگذاری کنید

لطفاً متد استاتیک `TelemetryBuffer.ToBuffer()` را پیاده‌سازی کنید تا با گرفتن پارامتری که به متد پاس داده می‌شود، یک بافر را رمزگذاری کند.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. یک بافر دریافتی را رمزگشایی کنید

لطفاً متد استاتیک `TelemetryBuffer.FromBuffer()` را پیاده‌سازی کنید تا بافر دریافتی را رمزگشایی کند و مقدار را به شکل یک `long` برگرداند.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

اگر مقدار بایت پیشوند غیرمنتظره باشد، باید `0` برگردانده شود.
