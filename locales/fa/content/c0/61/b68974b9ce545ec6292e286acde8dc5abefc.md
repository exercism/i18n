# معرفی

هر نمونه از یک `struct` یا `class`، ویژگی ضمنی‌ای به اسم `self` دارد که به خود نمونه اشاره می‌کند.
رایج‌ترین کاربرد `self`، رفع ابهام میان یک ویژگی نمونه و یک پارامتر است که اسم یکسانی دارند:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

در Swift، نوع‌ها کلیدواژه‌ی `Self` را هم دارند که با حرف بزرگ نوشته می‌شود و به *نوع* نمونه اشاره می‌کند، نه به خود نمونه.
