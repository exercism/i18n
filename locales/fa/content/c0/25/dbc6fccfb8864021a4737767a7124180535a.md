# Tests

## Clojure CLI

تمرین‌های Clojure در Exercism همراه با یک فایل `deps.edn` ارائه می‌شوند که یک alias به اسم `:test` دارد و با آن [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) را فراخوانی می‌کنید:

``` bash
$ clj -X:test
```

این فرمان پوشه‌ی `test` پروژه‌ی شما را می‌گردد، هر tests را که با `clojure.test` تعریف شده باشد پیدا می‌کند و آن‌ها را اجرا می‌کند.

## Leiningen

برای اجرای tests یک تمرین با Leiningen، کافی است این فرمان را اجرا کنید:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
