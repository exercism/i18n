# مقدمه

از دستور `guard` در Swift برای خروج زودهنگام از توابع، حلقه‌ها یا متدها استفاده می‌شود، آن هم زمانی که شرط لازم برآورده نشده باشد:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

در مثال بالا، `guard` عبارت منطقی را که پس از آن می‌آید ارزیابی می‌کند.
اگر شرط `true` باشد، اجرا با کدی که پس از دستور `guard` می‌آید ادامه پیدا می‌کند.
اگر شرط `false` باشد، کد درون بلوک `else` اجرا می‌شود.

برخلاف دستور `if`:

- دستور `guard` **باید** یک بخش `else` داشته باشد.
- بخش `else` **باید** کنترل را طوری منتقل کند که از دامنه‌ی اطراف خارج شود (برای نمونه، با استفاده از `return`، `continue`، `break` یا پرتاب یک خطا).

از `guard` اغلب برای اعتبارسنجی پیش‌شرط‌ها به‌صورت تمیز استفاده می‌شود.
برای نمونه، تابع sinc را در نظر بگیرید ($\text{sinc}(x) = \frac{\sin(x)}{x}$، که در آن $\text{sinc}(0) = 1$ است تا از تقسیم بر صفر جلوگیری شود):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
