# راهنمایی‌ها

## کلی

- این چالش درباره‌ی ساختن یک [_پشته_][Baeldung: The Stack Data Structure] با استفاده از یک [لیست پیوندی][singly linked list] است.
- برخلاف پشته‌هایی که بر پایه‌ی `lists` یا `collections.deque` یا `queue.LifoQueue` ساخته شده‌اند، از شما می‌خواهیم کلاس‌های سفارشی `Node` و `LinkedList` [`classes`][classes tutorial] را بسازید تا عنصرها را ذخیره کنید و به هم پیوند دهید.

![نموداری که یک پشته‌ی پیاده‌سازی‌شده با یک لیست پیوندی را نشان می‌دهد. دایره‌ای با حاشیه‌ی خط‌چین به نام New_Node در دورترین نقطه‌ی سمت چپ قرار دارد و دو خط فلش نقطه‌چین به سمت راست از آن بیرون آمده‌اند. روی New_Node نوشته شده: «(به سر تبدیل می‌شود) - New_Node - next = node_6». خط فلش نقطه‌چین بالایی برچسب «push» دارد و به Node_6 اشاره می‌کند که در بالا و سمت راست قرار دارد. روی Node_6 نوشته شده: «سر (فعلی) - Node_6 - next = node_5». خط فلش نقطه‌چین پایینی برچسب «pop» دارد و به جعبه‌ای اشاره می‌کند که روی آن نوشته شده: «هنگام pop() حذف می‌شود». Node_6 یک فلش توپر دارد که به سمت راست به Node_5 اشاره می‌کند، و روی Node_5 نوشته شده: «Node_5 - next = node_4». Node_5 یک فلش توپر دارد که به سمت راست به Node_4 اشاره می‌کند، و روی Node_4 نوشته شده: «Node_4 - next = node_3». این الگو تا Node_1 ادامه می‌یابد که روی آن نوشته شده: «ته (فعلی) - Node_1 - next = None». Node_1 یک فلش نقطه‌چین دارد که به سمت راست به گره‌ای اشاره می‌کند که روی آن نوشته شده: «None».](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- [Real Python: Linked Lists][Real Python Linked Lists]، [Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] و [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python] می‌توانند برای مرور جزئیات پیاده‌سازی مفید باشند.
- `LinkedList` شما باید یک آرگومان `list` را در _سازنده‌ی_ خود بپذیرد، اما نباید از یک `list` برای ذخیره‌ی گره‌ها یا عنصرها استفاده کند.
- `len()` یک تابع توکار برای بیشتر اشیای Python است.
برای اینکه _اشیای سفارشی_ از `len()` پشتیبانی کنند، باید متد ویژه‌ی [`__len__`][__len__] تعریف شود.
- پیمایش در Python برای بیشتر اشیای از نوع دنباله، ظرف یا مجموعه پشتیبانی می‌شود.
برای اینکه یک شیء _سفارشی_ از حلقه زدن یا تغییر ترتیب پشتیبانی کند، باید متد ویژه‌ی `__iter__` تعریف شود.
[Implementing an iterator for a class][implementing iterators] می‌تواند به شما کمک کند تا ببینید این کار چگونه انجام می‌شود.
