# درباره

Ceylon یک زبان برنامه‌نویسی همه‌کاره است که نحوه‌ی نگارش آن شبیه Java و C# است. این زبان امری، ایستاگونه‌دار، بلوک‌ساختاری، شیءگرا و مرتبه‌بالا است. منظور از _ایستاگونه‌دار_ این است که کامپایلر با کمک حاشیه‌نویسی‌های نوعی که در کد ظاهر می‌شوند، بررسی گسترده‌ی نوع را انجام می‌دهد. منظور از _شیءگرا_ این است که زبان از نوع‌های تعریف‌شده توسط کاربر پشتیبانی می‌کند و دارای نظام نوع نام‌بنیاد است که در آن یک نوع مجموعه‌ای از ویژگی‌ها و عملیات نام‌دار است، و نیز از وراثت و چندریختی زیرنوعی پشتیبانی می‌کند. منظور از _مرتبه‌بالا_ این است که هر عنصر ارجاع‌پذیر برنامه (هر ویژگی، هر عملیات و هر نوع) خودش نیز یک مقدار است. منظور از _بلوک‌ساختاری_ این است که زبان دارای حوزه‌ی دید واژگانی و نحوه‌ی نگارش بازگشتی بسیار منظمی برای اعلان‌ها و دستورها است.

Ceylon زبان و نظام نوع Java را بهبود می‌بخشد تا در مقایسه با Java و C#، پرگویی را کاهش دهد و ایمنی نوع را افزایش دهد. Ceylon سبک تابعی‌تر و تا حدی کم‌امری‌تری از برنامه‌نویسی را تشویق می‌کند و در نتیجه کدی به دست می‌آید که استدلال درباره‌ی آن آسان‌تر و بازآرایی آن راحت‌تر است.
