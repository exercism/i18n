# راهنمایی‌هایی برای تمرین میدان گل در Bash

به نظر می‌رسد این تمرین به یک آرایه‌ی دوبعدی نیاز دارد.
Bash فقط [آرایه‌های][array] یک‌بعدیِ ایندکس‌محور یا انجمنی را ارائه می‌دهد.

می‌توان آرایه‌های چندبعدی را با آرایه‌های انجمنی شبیه‌سازی کرد: اندیس‌ها را به شکل رشته‌ای جداشده با ویرگول کدگذاری کنید تا به عنوان کلید آرایه به کار رود.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
