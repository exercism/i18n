# کاراکتر

`CHAR` یک کاراکتر است که بین دو نقل‌قول تک نوشته می‌شود.

```sather
   c : CHAR := 'M';
```

## کاراکترهای ویژه

بعضی کاراکترها را نمی‌توان مستقیم تایپ کرد و با یک بک‌اسلش نوشته می‌شوند:

| نوشته | یعنی |
| --- | --- |
| `'\n'` | یک خط جدید |
| `'\t'` | یک تب |
| `'\''` | یک نقل‌قول تک |
| `'\\'` | یک بک‌اسلش |

## پرسش‌ها

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## بزرگی و کوچکی حروف

`.upper` و `.lower` بزرگی و کوچکی یک حرف را تغییر می‌دهند و بقیه را دست‌نخورده رها می‌کنند، بنابراین می‌توان بی‌دغدغه آن‌ها را روی کاراکتری که بررسی نکرده‌اید هم اعمال کرد.

## اعداد

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` و `.char` دقیقاً معکوس هم هستند. نکته‌های مفید درباره‌ی شماره‌گذاری این است که `'a'` تا `'z'` پشت سر هم می‌آیند، `'A'` تا `'Z'` پشت سر هم می‌آیند و `'0'` تا `'9'` هم پشت سر هم می‌آیند، پس:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## دور زدن

چرخ رمز از `z` می‌گذرد و به `a` برمی‌گردد. `%` دقیقاً همین کار را می‌کند:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

عملگر `%` در سیستر وقتی سمت راست مثبت است هرگز پاسخ منفی نمی‌دهد، بنابراین این عبارت هم برای چرخاندن چرخ به عقب کار می‌کند و هم به جلو.

## کاراکترها و رشته‌ها

یک `STR` ردیفی از بایت‌هاست و یک `CHAR` یک بایت است. در متن انگلیسی، هر بایت یک حرف است، بنابراین `"Marlowe".size` برابر ۷ است و `"Marlowe"[0]` برابر `'M'`. در متنی که علامت تلفظ یا الفبای دیگری دارد، ممکن است یک حرف چند بایت اشغال کند و هیچ‌کدام از آن دو برقرار نباشد.
