# مقدمه

`Rational numbers` کسرهایی هستند که صورت آن‌ها یک عدد صحیح و مخرجشان یک عدد صحیح است.

برای مثال، می‌توانیم `2//3` را به‌صورت یک کسر دقیق ذخیره کنیم، به‌جای مقدار تقریبی `Float64` که `0.6666...` است.

مزیت این کار آن است که (جز در حالت حاد *سرریز عدد صحیح*) یک عدد گویا دقیق باقی می‌ماند و از خطاهای گردکردنی که در اعداد ممیز شناور اغلب گریزناپذیرند جلوگیری می‌کند.

اعداد گویا نوع عددی نسبتاً ساده‌ای هستند و قرار است تقریباً همان‌طور که انتظار دارید عمل کنند.
چون از نخستین نسخه‌ها یک نوع استاندارد در Julia بوده‌اند، بیشتر توابع آن‌ها را همانند اعداد صحیح و ممیز شناور به‌عنوان ورودی می‌پذیرند.

## ساخت اعداد گویا

ساختن آن‌ها به همین سادگی است که `//` را بین دو عدد صحیح قرار دهید.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

عامل‌های مشترک به‌طور خودکار حذف می‌شوند و کسر به «ساده‌ترین شکل» خود تبدیل می‌شود: کوچک‌ترین اعداد صحیحی که کسر را به‌درستی نمایش می‌دهند و مخرجی نامنفی دارند.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## محاسبات با اعداد گویا

`arithmetic operators` معمول، یعنی `+ - * / ^ %`، با اعداد گویا کار می‌کنند، تقریباً همان‌طور که با دیگر انواع عددی کار می‌کنند.

اعداد صحیح و دیگر `Rational`ها را می‌توان در عبارت گنجاند و نتیجه یک `Rational` به دست می‌آید.
گنجاندن یک `float` در عبارت، خروجی `float` می‌دهد و در پی آن (احتمالاً) دقت از دست می‌رود.

اگر `float` می‌خواهید، کافی است از تابع `float()` برای تبدیل یک عدد گویا استفاده کنید.
کاملاً معمول است که از اعداد گویا برای حفظ دقت در یک محاسبه‌ی طولانی استفاده کنید و در پایان، نتیجه را به `float` تبدیل کنید.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## عملیات دیگر

در Julia، اعداد گویا فقط عدد هستند.
کامپایلر معمولاً در صورت نیاز نوع‌ها را تبدیل می‌کند.

با این حال، حواستان باشد که مقایسه‌ها برای کسرهایی کار می‌کنند که نمایش اعشاری متناهی دارند:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

اما در غیر این صورت، برای مقایسه‌ها باید یک `Rational` را به `Float` تبدیل کرد:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

توابع ریاضی اعداد گویا را به‌عنوان ورودی می‌پذیرند، اما ممکن است نتیجه‌ای ممیز شناور بدهند:

```julia-repl
julia> sqrt(9//16)
0.75
```
