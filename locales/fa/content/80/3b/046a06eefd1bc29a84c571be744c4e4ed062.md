# پیوست دستورالعمل‌ها

## نکات پیاده‌سازی

تعریف اینترفیس `Cipher` در `cipher.go` قرار دارد.

پیاده‌سازی‌های شما باید با اینترفیس `Cipher` سازگار باشند.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

انتظار می‌رود `Encode` همه‌ی مقادیری را که در بازه‌ی A-Za-z نیستند نادیده بگیرد؛ این مقادیر در خروجی نمایش داده نمی‌شوند.
خروجی همچنین به حروف کوچک تبدیل می‌شود.

توابعی که برای ساختن رمزها استفاده می‌شوند عبارت‌اند از:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

آرگومان `NewShift` باید در بازه‌ی ۱ تا ۲۵ یا منفی ۱ تا منفی ۲۵ باشد.
صفر مجاز نیست.
برای آرگومان‌های نامعتبر، `NewShift` مقدار `nil` را برمی‌گرداند.

آرگومان `NewVigenere` باید فقط شامل حروف کوچک `a` تا `z` باشد.
مقدارهایی که کاملاً از حرف `a` تشکیل شده‌اند مجاز نیستند.
برای آرگومان‌های نامعتبر، `NewVigenere` مقدار `nil` را برمی‌گرداند.
