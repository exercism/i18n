# مقدمه

## نوع «منطقی» در R

مقادیر «درست» یا «غلط» با نوع `logical` نمایش داده می‌شوند.
این نوع فقط دو مقدار دارد: `TRUE` و `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## عملگرهای منطقی

در R پنج عملگر منطقی وجود دارد، اما در این مرحله از برنامه‌ی درسی فقط سه عملگر آن‌ها مرتبط است.
دو عملگر دیگر هنگام کار با بردارها مهم خواهند بود که در چند مفهوم بعدی به آن‌ها پرداخته می‌شود.

`&&` عملگر منطقی «و» است.
اگر عبارت‌های دو طرف `&&` *هر دو* `TRUE` باشند، مقدار آن `TRUE` می‌شود.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` عملگر منطقی «یا» است.
اگر عبارتی در *هر یک* از دو طرف `||` `TRUE` باشد، مقدار آن `TRUE` می‌شود.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` عملگر منطقی «نقیض» است.
مقادیر `TRUE` و `FALSE` را با هم جابه‌جا می‌کند.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

برای عبارت‌های طولانی‌تر و پیچیده‌تر، بهتر است از پرانتز استفاده کنید تا منظورتان روشن باشد.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
