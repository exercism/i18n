# مقدمه

«String buffer» روشی کارآمد برای ساختن یک رشته‌ی بزرگ از راه افزودن عناصر کوچک به یکدیگر است. برخلاف String، یک نمونه‌ی StringBuf تغییرناپذیر نیست؛ یعنی می‌توان آن را به‌عنوان آرگومان به توابعی داد که با افزودن مقدارهای بیشتر، آن را تغییر می‌دهند.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
