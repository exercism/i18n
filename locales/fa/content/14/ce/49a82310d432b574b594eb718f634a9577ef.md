# کمک‌هزینه‌ی سوخت

## صورت مسئله

هر کارمند شرکت ABC Corp کمک‌هزینه‌ی سوخت نامحدود دریافت می‌کند. کارمندان موظف‌اند هر بار که خودروی خود را سوخت‌گیری می‌کنند، یک رکورد ارسال کنند. این رکوردها به همان فایل CSV اضافه می‌شوند و در پایان ماه پردازش می‌شوند.

به‌عنوان یکی از اعضای تیم عملیات دیجیتال، وظیفه‌ی شما این است که این فایل CSV را بخوانید و نتایج را در فایل CSV دیگری بنویسید. فایل خروجی باید برای هر کارمند یک ورودی داشته باشد که این اطلاعات را در بر می‌گیرد:

- شماره‌ی کارمند
- تعداد سوخت‌گیری‌ها
- هزینه‌ی کل سوخت
- مجموع گالن‌ها
- مجموع مایل‌های پیموده‌شده

دو آرگومان از نوع `string` به شما داده می‌شود.

1. مسیر فایل CSV ورودی
1. مسیر فایل CSV خروجی

فایل CSV ورودی `n` خط دارد و هر خط به شکل زیر است.

| نام ستون      | نوع در Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

فایل خروجی باید برای هر کارمند یک ورودی داشته باشد که بر اساس `employee_id` به ترتیب صعودی مرتب شده است. هر خط به شکل زیر است:

| نام ستون      | نوع در Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## محدودیت‌ها

- تعداد خطوط `n` در فایل CSV ورودی: ۲ <= n <= ۱۰۰۰
- تعداد کارمندان شرکت: ۹۷
- قیمت سوخت به ازای هر گالن است
- هیچ رکورد سوخت‌گیری‌ای جا نیفتاده است

## مثال ۱

- ورودی: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- خروجی: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
