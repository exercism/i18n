# دستورالعمل‌ها

ایزی پرنده‌نگری پرشور است که پیگیری می‌کند چند پرنده در هر روز به باغش آمده‌اند.

او از شما خواسته است که کمک کنید پرنده‌نگری‌اش را به سطحی تازه برسانید و چند ابزار پیاده‌سازی کنید که به او در پیگیری و پردازش داده‌ها کمک کند.

شما تصمیم گرفته‌اید داده‌ها را به‌صورت فهرستی از اعداد صحیح ذخیره کنید. عدد اول در فهرست، تعداد پرنده‌هایی است که امروز به باغ شما آمده‌اند، عدد دوم مربوط به دیروز است و به همین ترتیب.

## 1. بررسی کنید چند پرنده امروز آمده‌اند

تابع `today` را پیاده‌سازی کنید. باید فهرستی از شمارش روزانه‌ی پرنده‌ها بگیرد و شمارش امروز را برگرداند. اگر فهرست خالی باشد، باید `0` را برگرداند.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. شمارش امروز را افزایش دهید

تابع `increment_day_count` را پیاده‌سازی کنید. باید فهرستی از شمارش روزانه‌ی پرنده‌ها بگیرد و شمارش امروز را ۱ واحد افزایش دهد. اگر فهرست خالی باشد، `[1]` را برگردانید.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. بررسی کنید آیا روزی بدون پرنده‌ی آمده وجود داشته است یا نه

تابع `has_day_without_birds` را پیاده‌سازی کنید. باید فهرستی از شمارش روزانه‌ی پرنده‌ها بگیرد. اگر دست‌کم یک روز بوده باشد که هیچ پرنده‌ای به باغ نیامده است، باید `True` را برگرداند و در غیر این صورت `False` را. اگر فهرست خالی باشد، این به معنای آن است که _هنوز_ هیچ پرنده‌ای ثبت نشده؛ `False` را برگردانید.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. محاسبه‌ی تعداد کل پرنده‌های آمده

تابع `total` را پیاده‌سازی کنید. باید فهرستی از شمارش روزانه‌ی پرنده‌ها بگیرد و تعداد کل پرنده‌هایی را برگرداند که از زمانی که جمع‌آوری داده‌ها را شروع کرده‌اید به باغ شما آمده‌اند.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. محاسبه‌ی تعداد روزهای پرمشغله

بعضی روزها پرمشغله‌تر از بقیه‌اند. روز پرمشغله روزی است که پنج پرنده یا بیشتر به باغ شما آمده باشند.

تابع `busy_days` را پیاده‌سازی کنید. باید فهرستی از شمارش روزانه‌ی پرنده‌ها بگیرد و تعداد روزهای پرمشغله را برگرداند.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
