# مقدمه

یک اعلان `MACRO:` شبیه `:` است، با این تفاوت که بدنه‌ی آن در *زمان کامپایل* اجرا می‌شود و باید یک «quotation» برگرداند. کامپایلر همان quotation برگردانده‌شده را جای فراخوانی ماکرو می‌گذارد. چون بدنه کد معمولیِ Factor است، ساختن quotation نتیجه فقط دستکاری دنباله‌هایی از واژه‌هاست.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

ورودی‌های یک ماکرو *مقادیر ثابت در محل فراخوانی* هستند. اگر مقداری غیرثابت بدهید، کامپایلر از تخصصی‌سازی سر باز می‌زند، چون بدنه‌ی ماکرو به آن مقدار در زمان کامپایل نیاز دارد، نه در زمان اجرا.

خویشاوند نزدیک آن، بلوک ارزیابی زمان تجزیه‌ی `<< … >>` است که کد Factor دلخواه را در زمان کامپایل اجرا می‌کند، بدون قراردادِ برگرداندن quotation. هر دو زیر سازوکار [`macros`][macros] در Factor قرار می‌گیرند.

[macros]: https://docs.factorcode.org/content/vocab-macros.html
