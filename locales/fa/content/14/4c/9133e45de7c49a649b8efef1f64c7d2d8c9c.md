# دستورالعمل‌ها

بر اساس طرح طبقه‌بندی نیکوماخوس (۶۰ تا ۱۲۰ میلادی) برای اعداد صحیح مثبت مشخص کنید که یک عدد **perfect** است، **abundant** یا **deficient**.

ریاضی‌دان یونانی [نیکوماخوس](https://en.wikipedia.org/wiki/Nicomachus) طرحی برای طبقه‌بندی اعداد صحیح مثبت ابداع کرد که هر عدد را بر اساس [مجموع مقسوم‌علیه‌های سره](https://en.wikipedia.org/wiki/Aliquot_sum) هر عدد، به‌طور یکتا در یکی از دسته‌های **perfect**، **abundant** یا **deficient** قرار می‌دهد. منظور از مجموع مقسوم‌علیه‌های سره، مجموع مقسوم‌علیه‌های یک عدد است، بدون در نظر گرفتن خود آن عدد. برای نمونه، مجموع مقسوم‌علیه‌های سره‌ی ۱۵ برابر است با (۱ + ۳ + ۵) = ۹

- **Perfect**: مجموع مقسوم‌علیه‌های سره = عدد
  - ۶ یک عدد perfect است، چون (۱ + ۲ + ۳) = ۶
  - ۲۸ یک عدد perfect است، چون (۱ + ۲ + ۴ + ۷ + ۱۴) = ۲۸
- **Abundant**: مجموع مقسوم‌علیه‌های سره > عدد
  - ۱۲ یک عدد abundant است، چون (۱ + ۲ + ۳ + ۴ + ۶) = ۱۶
  - ۲۴ یک عدد abundant است، چون (۱ + ۲ + ۳ + ۴ + ۶ + ۸ + ۱۲) = ۳۶
- **Deficient**: مجموع مقسوم‌علیه‌های سره < عدد
  - ۸ یک عدد deficient است، چون (۱ + ۲ + ۴) = ۷
  - اعداد اول deficient هستند

راهی پیاده‌سازی کنید که مشخص کند یک عدد داده‌شده **perfect** است یا نه. بسته به مسیر زبانتان، ممکن است لازم باشد راهی هم پیاده‌سازی کنید که مشخص کند یک عدد داده‌شده **abundant** است یا **deficient**.
