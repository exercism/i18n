# درباره

یک «رشته» نماینده‌ی داده‌ی متنی است.
در Swift، [`String`][strings-and-characters] یک مجموعه‌ی مرتب از مقادیر `Character` است و هر «نویسه» در آن نماینده‌ی یک نویسه‌ی یونیکد است.

رشته را با یک «لیترال رشته‌ای» می‌سازید؛ لیترال رشته‌ای دنباله‌ای از نویسه‌ها است که بین دو علامت نقل‌قول دوگانه (`"`) قرار می‌گیرد.
برای رشته‌های چندخطی، از سه علامت نقل‌قول دوگانه (`"""`) استفاده کنید:

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

رشته‌های Swift به‌شکل یکپارچه با کلاس [`NSString`][nsstring-docs] در فریمورک Foundation پیوند می‌خورند و امکان دسترسی به قابلیت‌های گسترده‌ی پردازش متن را فراهم می‌کنند.

## نویسه

یک `Character` نماینده‌ی یک «خوشه‌ی گرافیمی گسترده» است، یعنی یک نویسه‌ی خوانا برای انسان که از یک یا چند [مقدار اسکالر یونیکد][unicode-scalar-values] ساخته می‌شود.
یک مقدار اسکالر یونیکد، یک نقطه‌ی کد ۲۱بیتی در بازه‌ی `U+0000` تا `U+D7FF` (شامل خودشان) یا `U+E000` تا `U+10FFFF` (شامل خودشان) است.

```swift
let aChar: Character = "A"
```

## استنتاج نوع

وقتی یک لیترال رشته‌ای می‌نویسید، Swift نوع آن را به‌طور خودکار `String` استنتاج می‌کند.
برای ذخیره‌ی یک نویسه به‌صورت `Character`، باید یک حاشیه‌نویسی نوع صریح بنویسید:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## الحاق

می‌توانید رشته‌ها را با عملگر جمع (`+`) به هم بپیوندید:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

نمی‌توانید یک `Character` را بدون اینکه ابتدا آن را به رشته تبدیل کنید، مستقیماً با `+` به یک `String` الحاق کنید.
اما می‌توانید از متد [`append(_:)`][append] استفاده کنید تا یک رشته یا یک نویسه را مستقیماً به یک رشته‌ی قابل‌تغییر اضافه کنید:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## درون‌یابی رشته

[درون‌یابی رشته][string-interpolation] به شما امکان می‌دهد با جای‌گذاری ثابت‌ها، متغیرها، لیترال‌ها و عبارت‌هایی درون لیترال‌های رشته‌ای، یک رشته بسازید.
هر عبارت را داخل پرانتزهایی بگذارید که پیش از آن‌ها یک بک‌اسلش آمده است (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## ویژگی‌های رشته و نویسه

رشته‌ها و نویسه‌ها چندین ویژگی دارند که با آن‌ها می‌توانید محتوایشان را بررسی کنید.

### ویژگی‌های رشته

ویژگی‌های رایج رشته عبارت‌اند از:

| ویژگی     | توضیح                                          | مثال                             |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | اگر رشته هیچ نویسه‌ای نداشته باشد، `true` برمی‌گرداند | مقدار `"Hello".isEmpty` برابر با `false` است |
| `count`   | تعداد نویسه‌های رشته را برمی‌گرداند                 | مقدار `"Hello".count` برابر با `5` است       |

برای فهرست کامل ویژگی‌ها، به [مستندات `String` در Apple][string-docs] مراجعه کنید.

### ویژگی‌های نویسه

ویژگی‌های رایج نویسه عبارت‌اند از:

| ویژگی          | توضیح                                       | مثال                                 |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | اگر نویسه کوچک باشد، `true` برمی‌گرداند          | مقدار `"a".isLowercase` برابر با `true` است |
| `isUppercase`  | اگر نویسه بزرگ باشد، `true` برمی‌گرداند          | مقدار `"A".isUppercase` برابر با `true` است |
| `isNumber`     | اگر نویسه یک رقم باشد، `true` برمی‌گرداند         | مقدار `"1".isNumber` برابر با `true` است    |
| `isWhitespace` | اگر نویسه فضای خالی باشد، `true` برمی‌گرداند      | مقدار `" ".isWhitespace` برابر با `true` است|

برای فهرست کامل ویژگی‌ها، به [مستندات `Character` در Apple][character-docs] مراجعه کنید.

## تبدیل نوع

می‌توانید انواع دیگر را با استفاده از سازنده‌ی `String(_:)` به رشته تبدیل کنید؛ این سازنده از انواع استانداردی مانند `Int`، `Double` و `Character` پشتیبانی می‌کند:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## نویسه‌های خاص

لیترال‌های رشته‌ای Swift چندین [دنباله‌ی گریز][special-characters] را برای نویسه‌های خاص پشتیبانی می‌کنند:

| دنباله    | توضیح                        |
| --------- | ---------------------------- |
| `\0`      | نویسه‌ی تهی                  |
| `\\`      | بک‌اسلش                      |
| `\t`      | تب افقی                      |
| `\n`      | فید خط (خط جدید)             |
| `\r`      | بازگشت به ابتدای خط          |
| `\'`      | علامت نقل‌قول تک             |
| `\"`      | علامت نقل‌قول دوگانه         |
| `\u{n}`   | مقدار اسکالر یونیکد دلخواه (شانزده‌شانزدهی) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
