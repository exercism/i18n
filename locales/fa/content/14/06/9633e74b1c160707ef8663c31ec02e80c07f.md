# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات     | کاربرد        | نوع     | توضیح                              |
| -------- | ------------- | ------- | ---------------------------------- |
| `$a0`    | ورودی         | آدرس    | رشته‌ی ورودی با پایانِ نال          |
| `$a1`    | ورودی/خروجی   | آدرس    | رشته‌ی نتیجه با پایانِ نال          |
| `$t0-9`  | موقت          | هر نوع  | برای ذخیره‌سازی موقت                |
