# نصب

این مسیر از ReScript ۱۲ استفاده می‌کند و به [Node.js][nodejs] نسخه‌ی ۲۲ یا بالاتر نیاز دارد.
بسیاری از سیستم‌ها این را از پیش نصب دارند، یا ممکن است قبلاً آن را برای مسیر دیگری نصب کرده باشید.

یک ترمینال باز کنید و اجرا کنید:

```sh
node -v
```

اگر Node نصب نیست یا نسخه‌ی قدیمی‌تری نمایش داده می‌شود، لطفاً دستورهای [نصب رسمی Node.js][nodejs-install] را برای سیستم‌عامل خود دنبال کنید.

## نصب وابستگی‌ها

هر تمرین ReScript یک پروژه‌ی npm خودبسنده است.
پس از دانلود یک تمرین با [Exercism CLI][exercism-cli]، وابستگی‌های پروژه را همراه با ReScript نصب کنید تا آماده‌ی شروع باشید:

```sh
cd /path/to/exercise
npm install
```

## پشتیبانی ویرایشگر
