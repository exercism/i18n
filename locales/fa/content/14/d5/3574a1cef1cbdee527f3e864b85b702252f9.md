# مقدمه

## لیست

لیست‌ها در زبان Elixir توکار هستند. آن‌ها یک نوع پایه در نظر گرفته می‌شوند که با کروشه نشان داده می‌شوند. لیست‌ها می‌توانند خالی باشند یا هر تعداد عنصری از هر نوعی را در خود نگه دارند. برای مثال:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir لیست‌ها را به صورت یک لیست پیوندی پیاده‌سازی می‌کند که هر گره در آن دو مقدار را ذخیره می‌کند: اولین عنصر و لیست دیگری که همه‌ی عناصر باقی‌مانده را در خود دارد. به اولین عنصر لیست، «سر» و به لیست باقی‌مانده‌ی عناصر، «دم» می‌گویند. می‌توانیم از این نماد در کد استفاده کنیم:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

می‌توانیم با نماد _`[head | tail]`_ عنصرها را به ابتدای لیست اضافه کنیم:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

در ماژول `Kernel` چندین تابع برای کار با لیست‌ها وجود دارد، و همچنین کل ماژول `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
