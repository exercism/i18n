# مقدمه

در Haxe، یک `class` ساختار داده‌ی اصلی است که داده‌ها (فیلدها) و رفتار (متدها) را در خود جای می‌دهد. به فیلدها و متدها، اعضای یک کلاس هم می‌گویند.

دسترسی به اعضا را می‌توان با «اصلاح‌کننده‌های دسترسی» محدود کرد. این اصلاح‌کننده‌ها عبارت‌اند از:

- `public`: عضو از هر جایی قابل دسترسی است.
- `private`: عضو فقط از داخل همان کلاس قابل دسترسی است.

می‌توان کلاس‌ها را قالب‌هایی برای ساختن «نمونه» در نظر گرفت. برای ساختن یک نمونه، کافی است از «کلیدواژه»ی `new` استفاده کنید:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

برای تعریف یک فیلد، از یک اصلاح‌کننده‌ی دسترسی و پس از آن اسم و نوع متغیر استفاده کنید:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

هنگام تعریف یک فیلد می‌توانید یک مقدار اولیه هم تعیین کنید. اگر فیلدی مقدار اولیه نداشته باشد، مقدار `null` را می‌گیرد. برای دسترسی به یک فیلد از «نشانه‌گذاری نقطه‌ای» استفاده کنید:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
