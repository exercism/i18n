# پیوست دستورالعمل

## موضوعات

برخی از موضوعات Rust که ممکن است بخواهید در حین حل این تمرین درباره‌شان بخوانید:

- `trait`ها، هم `trait` مربوط به `From` و هم [پیاده‌سازی `trait`های خودتان](https://doc.rust-lang.org/book/ch10-02-traits.html)
- [پیاده‌سازی‌های پیش‌فرض متد](https://doc.rust-lang.org/book/ch10-02-traits.html#default-implementations) برای `trait`ها
- `macro`ها، استفاده از یک `macro` می‌تواند کدهای تکراری را کاهش دهد و خوانایی این تمرین را افزایش دهد. برای نمونه، [یک `macro` می‌تواند `trait` را برای چند نوع به‌طور همزمان پیاده‌سازی کند](https://stackoverflow.com/questions/39150216/implementing-a-trait-for-multiple-types-at-once)، هرچند اشکالی ندارد که `years_during` را در خود `trait` مربوط به `Planet` پیاده‌سازی کنید. یک `macro` می‌تواند هم `struct`ها و هم پیاده‌سازی‌هایشان را تعریف کند. برای شروع کار با `macro`ها می‌توانید از این منابع استفاده کنید:

  - [فصل `macro`ها در کتاب The Rust Programming Language](https://doc.rust-lang.org/stable/book/ch19-06-macros.html)
  - [نسخه‌ی قدیمی‌تری از فصل `macro`ها همراه با جزئیات مفید](https://doc.rust-lang.org/1.30.0/book/first-edition/macros.html)
  - [Rust By Example](https://doc.rust-lang.org/stable/rust-by-example/macros.html)
