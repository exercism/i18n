# دستورالعمل‌ها

چرخ رمز دو دیسک است، یکی درون دیگری، که الفبا را می‌چرخاند: آن را روی ۳ تنظیم کنید و هر حرف، حرفی می‌شود که سه جایگاه جلوتر است، و `z` دوباره به `a` برمی‌گردد. کارآگاهان قرن‌ها از آن استفاده کرده‌اند. شما در حال ساختن یکی از آن‌ها هستید.

هر پنج کار در کلاس `CIPHER_WHEEL` قرار می‌گیرند.

## 1. آیا حرف است؟

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. فریادش بزنید

شکل بزرگ یک کاراکتر را برگردانید. اگر کاراکتر حرف نباشد، بدون تغییر برمی‌گردد.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. چه عددی است؟

عددی را که نشان‌دهنده‌ی یک کاراکتر است، برگردانید.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. اولین کاراکتر

اولین کاراکتر یک رشته را برگردانید.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. چرخ را بچرخانید

اگر یک حرف کوچک و تعداد جایگاه‌ها داده شود، حرفی را برگردانید که به همان تعداد جایگاه در الفبا جلوتر است. بعد از `z` دوباره به `a` برمی‌گردد.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

چرخش به عقب هم با تعداد منفی جایگاه‌ها کار می‌کند.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

می‌توانید فرض کنید کاراکتری که داده می‌شود، یک حرف کوچک است.
