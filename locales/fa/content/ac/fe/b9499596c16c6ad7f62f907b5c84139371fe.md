# دستورالعمل‌ها

شما در حال پیاده‌سازی یک سیستم پایش سلامت هستید.
به عنوان بخشی از آن، باید آمار سلامت کاربران را پیگیری کنید.

شما کار خود را با چند تابع ناتمام در یک بلوک `impl` و همچنین تعریف `struct` زیر آغاز می‌کنید:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

هدف شما این است که متدهای ناتمام را روی `struct`ی به اسم `User` که در بلوک `impl` تعریف شده است پیاده‌سازی کنید.

برای مثال، متد `new` باید نمونه‌ای از `struct` `User` را با مقادیر مشخص‌شده برای اسم، سن و وزن برگرداند.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

متد `weight` باید وزن `User` را برگرداند.

```rust
bob.weight();
// Returns: 72
```

متد `set_age` باید سن `User` را تنظیم کند.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

خوش بگذرانید!
