# دستورالعمل‌ها

باب مشاور مالی است و به افراد کمک می‌کند هزینه‌هایشان را مدیریت کنند.
مشتریان باب سوابق هزینه‌های خود را می‌فرستند تا او آن‌ها را تحلیل کند.
باب سوابق دوره‌های پیشین را هم دارد تا بتواند تغییرات هزینه‌ها را ببیند.
باب تقویم را دوست ندارد و به‌جای تاریخ از «مبدأ باب» استفاده می‌کند.
مبدأ باب تعداد روزهایی است که از زمان شروع فعالیت مشتری باب گذشته است.

در این تمرین، برنامه‌ای می‌سازید که به باب کمک می‌کند هزینه‌های مشتریانش را مدیریت و تحلیل کند.

باب با `Record`ها و `DaysPeriod`ها کار می‌کند.

یک `Record` نماینده‌ی یک سابقه‌ی هزینه است که روز انجام هزینه، مبلغ خرج‌شده و دسته‌ی هزینه را در خود دارد.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

یک `DaysPeriod` بازه‌ای از روزها را نشان می‌دهد و همه‌ی روزها را از روز `From` تا روز `To` در بر می‌گیرد.
هر دو سر بازه هم شامل می‌شوند.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. پیاده‌سازی یک فیلتر عمومی برای سوابق

باب هر روز با سوابق زیادی سر و کار دارد، اما بسته به تحلیلی که انجام می‌دهد، همه‌ی آن‌ها برایش جالب نیستند.
بیایید به باب کمک کنیم تا یک فیلترگذاری پایه روی سوابق انجام دهد.

تابع عمومی `Filter` را پیاده‌سازی کنید تا سوابق را بر اساس معیاری که یک تابع تعیین می‌کند فیلتر کند.
این تابع فیلتر، مجموعه‌ای از سوابق و یک تابع شرطی می‌گیرد و تنها سوابق موجود در مجموعه را برمی‌گرداند که این شرط را برآورده می‌کنند.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. فیلتر کردن سوابق در یک بازه‌ی زمانی

باب اغلب لازم دارد سوابقی را فیلتر کند که در یک بازه‌ی زمانی مشخص قرار دارند.

تابع `ByDaysPeriod` را پیاده‌سازی کنید که به باب کمک می‌کند چنین فیلترهایی بسازد.
این تابع یک `DaysPeriod` می‌گیرد و تابعی برمی‌گرداند که یک سابقه می‌گیرد و مشخص می‌کند آیا آن سابقه در بازه‌ی زمانی تعیین‌شده با `DaysPeriod`ی که به عنوان آرگومان داده شده قرار دارد یا نه.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. فیلتر کردن سوابق بر اساس دسته

باب علاوه بر فیلتر کردن سوابق بر اساس بازه‌ی زمانی، لازم دارد سوابق را بر اساس دسته‌ی آن‌ها هم فیلتر کند.

تابع `ByCategory` را پیاده‌سازی کنید که به باب کمک می‌کند چنین فیلترهایی بسازد.
این تابع یک دسته می‌گیرد و تابعی برمی‌گرداند که یک سابقه می‌گیرد و مشخص می‌کند آیا دسته‌ی این سابقه با دسته‌ای که به عنوان آرگومان داده شده یکسان است یا نه.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. محاسبه‌ی مجموع هزینه‌ها در یک بازه

باب همچنین می‌خواهد مجموع هزینه‌ها را در یک بازه‌ی زمانی بداند.

تابع `TotalByPeriod` را پیاده‌سازی کنید تا مجموع هزینه‌ها را در بازه‌ی روزها برگرداند.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. محاسبه‌ی مجموع هزینه‌های سوابق یک دسته در یک بازه

باب برای پیچیده‌ترین گزارش‌هایی که به مشتریانش ارائه می‌دهد، لازم دارد سوابق را هم‌زمان بر اساس دسته و بازه‌ی زمانی فیلتر کند.
یعنی باب می‌خواهد مجموع هزینه‌های سوابق یک دسته را در یک بازه‌ی زمانی مشخص بداند.

تابع `CategoryExpenses` را پیاده‌سازی کنید که مجموع هزینه‌های یک دسته را در یک بازه‌ی مشخص از روزها برمی‌گرداند.
این تابع باید حالتی را که دسته‌ی داده‌شده در سوابق هزینه وجود ندارد، از حالتی که هزینه‌های آن دسته در بازه‌ی داده‌شده وجود ندارد، تفکیک کند.
وقتی دسته، دسته‌ی هیچ‌یک از سوابق نباشد (بدون توجه به بازه‌ی زمانی)، تابع باید یک خطا برگرداند.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
