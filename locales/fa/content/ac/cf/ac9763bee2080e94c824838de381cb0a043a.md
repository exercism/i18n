# مقدمه

درک مرجع‌ها یکی از پایه‌های استفاده‌ی مؤثر از Perl است.
چون مرجع‌ها خودشان اسکالر هستند و آرایه‌ها و هش‌ها فقط می‌توانند اسکالر در خود جای دهند، مرجع‌ها کلید تودرتوسازی این ساختارهای داده هستند.

می‌توانید برای متغیرها و زیرروال‌های موجود با استفاده از عملگر بک‌اسلش `\` مرجع بسازید:

* `\$scalar` برای ساختن یک مرجع اسکالر (این می‌تواند هر اسکالری باشد، مثلاً `\1`، نه فقط یک متغیر).
* `\@array` برای ساختن یک مرجع آرایه.
* `\%hash` برای ساختن یک مرجع هش.
* `\&sub` برای ساختن یک مرجع کد.

همچنین می‌توانید برای آرایه‌ها، هش‌ها و زیرروال‌ها چیزی بسازید که به آن مرجع بینام می‌گویند:

* `['Alice', 'Bob', 'Charlie']` برای ساختن یک مرجع آرایه‌ی بینام.
* `{foo => 'a', bar => 'b', baz => 'c'}` برای ساختن یک مرجع هش بینام.
* `sub { return 1 }` برای ساختن یک مرجع کد بینام.

هشدار: آکولادها در Perl می‌توانند در برخی بافت‌ها مبهم باشند. اگر مرجع هشی که انتظار دارید را به دست نمی‌آورید، یک علامت بعلاوه در ابتدای آن اضافه کنید تا ابهام برطرف شود، مثلاً `+{}`. برای اطلاعات بیشتر [آکولادها][perlrefcurlybrackets] را ببینید.

می‌توان با استفاده از عملگر فلش `->` به مرجع‌ها دسترسی پیدا کرد:

* `$ref->[0]` برای دسترسی به یک عنصر داخل یک مرجع آرایه.
* `$ref->{foo}` برای دسترسی به یک مقدار داخل یک مرجع هش.
* `$ref->($arg)` برای فراخوانی یک زیرروال از طریق یک مرجع کد.

می‌توان به داده‌های داخل ساختارهای داده‌ی پیچیده، مانند آرایه‌های چندبعدی و هش‌های تودرتو، با زنجیره‌کردن اندیس‌ها دسترسی پیدا کرد، مثلاً `$ref->{foo}[0]{bar}` (معادل `$ref->{foo}->[0]->{bar}`).

اگر می‌خواهید یک آرایه یا هش را به‌طور کامل مرجع‌گشایی کنید، می‌توانید از عملگر فلش استفاده کنید و بعد از آن به‌ترتیب `@*` یا `%*` را بیاورید، مثلاً `$ref->@*` یا `$ref->%*`.
همچنین می‌توانید با جایگزین کردن `*` با یک اندیس، برش‌هایی از یک مرجع آرایه یا هش به دست آورید، مثلاً `$ref->@[0..2]` یا `$ref->@{'Foo', 'Bar'}`.
درباره‌ی برش‌ها، نوسان سیگیل اینجا هم همان‌طور که برای متغیرهای آرایه و هش اعمال می‌شود، اعمال می‌شود.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
