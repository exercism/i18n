# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات    | کاربرد         | نوع        | توضیح                                    |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | عدد صحیح | عدد داده‌شده                  |
| `$a1`    | ورودی/خروجی | آدرس | رشته‌ی نتیجه که با null پایان می‌یابد |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت         |
