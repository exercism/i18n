# حل تمرین

مهم‌ترین راهی که Exercism به شما در یادگیری کمک می‌کند، حل کردن تمرین است.

برای حل تمرین در Exercism دو روش وجود دارد:

1. [آنلاین، با ویرایشگر درون‌مرورگر وب‌سایت](/docs/using/solving-exercises/using-the-online-editor)
2. [روی رایانه‌ی محلی خودتان با CLI](/docs/using/solving-exercises/working-locally)

## کدام گزینه را انتخاب کنم؟

استفاده از ویرایشگر آنلاین یا CLI هر کدام مزایا و معایب خودش را دارد:

|            | ویرایشگر آنلاین                        | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| نصب        | خیر                                    | بله (مثلاً SDK)                              |
| ویرایش     | مرورگر                                 | ویرایشگر دلخواه شما                          |
| Test       | اجرای Testها روی وب‌سایت               | اجرای Testها به‌صورت محلی                     |
| Debug      | پشتیبانی محدود (فقط برای بعضی مسیرها)  | پشتیبانی کامل (بسته به محیط شما)             |

به‌طور کلی، ویرایشگر آنلاین برای شروع مسیرهای تازه ایده‌آل است، در حالی که روش مبتنی بر CLI برای زمانی عالی است که بخواهید از محیط برنامه‌نویسی شخصی خودتان استفاده کنید.
