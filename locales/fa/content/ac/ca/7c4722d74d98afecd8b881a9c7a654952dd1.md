# مقدمه

توانایی تعریف شدن یک چیز بر اساس خودش را «بازگشتی» می‌گویند. در Gleam، بازگشتی را بیشتر در قالب توابع بازگشتی می‌بینیم؛ توابعی که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید دست‌کم یک «حالت پایه» و دست‌کم یک «حالت بازگشتی» داشته باشد. حالت پایه مقداری را برمی‌گرداند بدون اینکه تابع را دوباره فراخوانی کند. حالت بازگشتی تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت کند.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam نحوه‌ی نگارش ویژه‌ای برای حلقه زدن ندارد؛ به همین دلیل همه‌ی حلقه‌ها با بازگشتی انجام می‌شوند.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam از نوع‌های سفارشی بازگشتی هم پشتیبانی می‌کند. در یک نوع سفارشی بازگشتی، یک یا چند گونه از آن در داده‌ی درونشان به خود نوع ارجاع می‌دهند.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
