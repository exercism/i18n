# دستورالعمل‌ها

در این تمرین، خط‌های لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با قالب زیر: `"[<LVL>]: <MESSAGE>"`.

این‌ها سطوح مختلف لاگ هستند:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

سه وظیفه دارید و باید هر سه را انجام دهید تا قابلیت لازم فراهم شود.

## 1. ساخت `enum` به اسم `LogLevel`

یک `enum` به اسم `LogLevel` تعریف کنید که شش حالت متناظر با سطوح لاگ بالا دارد، به همراه یک حالت `unknown` برای سطح‌هایی که ناموجود یا غیراستاندارد هستند.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. تجزیه‌ی سطح لاگ

سپس، سازنده‌ی `LogLevel` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را تجزیه کند:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. تبدیل خط لاگ به قالب کوتاه

سطح لاگ یک خط لاگ بسیار طولانی است.
برای کاهش فضای دیسک لازم برای ذخیره‌ی خط‌های لاگ، یک قالب کوتاه طراحی شده است: `"<ENCODED_LEVEL>:<MESSAGE>"`.

سطح لاگ رمزگذاری‌شده نگاشتی ساده از سطح لاگ به یک عدد است:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

متد `shortFormat(message: String) -> String` را پیاده‌سازی کنید که می‌تواند قالب کوتاه‌شده‌ی خط لاگ را به‌صورت یک `String` خروجی بدهد:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
