# `defmacro` با `_is` و علامت سؤال

Elixir برای انتخاب اسم قراردادهای خاصی دارد که شامل نحوه‌ی انتخاب اسم [توابعی که «مقدار منطقی» برمی‌گردانند](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) و [بررسی‌هایی که مقدار منطقی برمی‌گردانند و در بندهای «گارد» مجاز هستند](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo) می‌شود:

> توابعی که مقدار منطقی برمی‌گردانند، در انتهای اسمشان یک علامت سؤال دارند.

> بررسی‌های نوع و دیگر بررسی‌های منطقی که در بندهای گارد مجاز هستند، پیشوند `is_` دارند.

ماکروها را می‌توان در هر دو بافت به کار برد، بنابراین شکل نوشتن به موقعیت بستگی دارد، اما این دو قرارداد را نباید با هم مخلوط کرد.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
