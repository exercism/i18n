# دستورالعمل‌ها

دوستتان همین حالا پیامی همراه با یک راز مهم برایتان فرستاده است.
چون نمی‌خواهد خواندنش برای دیگران آسان باشد، پیام با یک رشته دستکاری بیتی رمزنگاری شده است.
باید برنامه‌ای بنویسید که به رمزگشایی پیام کمک کند.

## 1. بیت‌ها را به عقب جابه‌جا کنید

اولین گام در رمزگشایی پیام این است که جابه‌جایی انجام‌شده در فرایند رمزنگاری را با جابه‌جا کردن بیت‌ها به سمت چپ خنثی کنیم.
تعداد جاهایی که باید جابه‌جا شوند، از پیامی به پیام دیگر می‌تواند متفاوت باشد.

متد `Secrets.shift_back` را پیاده‌سازی کنید که یک مقدار و تعداد جاهای جابه‌جایی به سمت چپ را می‌گیرد.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. یک ماسک بیتی را اعمال کنید

گام بعدی، اعمال یک ماسک بیتی برای استخراج مقدار بیت‌های مشخصی است.
ماسک با انجام یک AND بیتی میان مقدار و ماسک اعمال می‌شود.

متد `Secrets.apply_mask` را پیاده‌سازی کنید که یک مقدار می‌گیرد و ماسکی را اعمال می‌کند.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. برخی از بیت‌ها را تنظیم کنید

جابه‌جا کردن بیت‌ها به سمت چپ، چند بیت ۰ تازه اضافه کرده است.
بعضی از این بیت‌های تازه باید به ۱ تبدیل شوند.
OR بیتی برای تبدیل بیت‌های خاصی به ۱ و در همان حال حفظ بقیه به کار می‌آید.

متد `Secrets.set_bits` را پیاده‌سازی کنید که دو مقدار می‌گیرد و یک OR بیتی انجام می‌دهد.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. وارون کردن XOR

بخشی از فرایند رمزنگاری، یک XOR با یک مقدار توافق‌شده اعمال می‌کند.
برای بازگشت به مقدار اصلی، کافی است مقدار رمزنگاری‌شده را دوباره با همان مقدار توافق‌شده XOR کنیم.
اما به دلیل یک سوءتفاهم، دوستتان پیش از اعمال XOR بیت‌های مقدار توافق‌شده را وارونه کرده است (یعنی یک NOT بیتی روی مقدار توافق‌شده اعمال کرده است). 

متد `Secrets.reverse_xor` را پیاده‌سازی کنید که مقدار رمزنگاری‌شده و مقدار توافق‌شده را می‌گیرد و مقدار اصلی را محاسبه می‌کند.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
