# مولد

`generator` یک تابع یا عبارت است که نوع خاصی از [تکرارگر][iterator] را برمی‌گرداند که به آن [`generator iterator`][generator-iterator] می‌گویند.
`Generator-iterator`ها [تنبل][lazy iterator] هستند: `values` خود را در حافظه ذخیره نمی‌کنند، بلکه مقادیرشان را هنگام نیاز _تولید_ می‌کنند.

یک تابع مولد شبیه هر تابع دیگری است، اما شامل یک یا چند [عبارت `yield`][yield expression] است.
هر `yield` اجرای کد را معلق می‌کند و وضعیت اجرای جاری را ذخیره می‌کند (_شامل همه‌ی متغیرهای محلی و دستورهای `try`_).
وقتی مولد ادامه پیدا می‌کند، وضعیت را از همان نقطه‌ی تعلیق برمی‌دارد، برخلاف توابع معمولی که با هر بار فراخوانی از نو آغاز می‌شوند.


## ساخت یک مولد

مولدها تقریباً مانند دیگر توابع حلقه‌ای یا بازگشتی ساخته می‌شوند، اما به یک [عبارت `yield`](#the-yield-expression) نیاز دارند که کمی بعد با جزئیات بیشتری به آن می‌پردازیم.

یک نمونه، تابعی است که _مربع‌های_ اعداد یک فهرست مشخص را برمی‌گرداند.
همان‌طور که اکنون نوشته شده است، باید همه‌ی ورودی پردازش شود تا بتوان هر مقداری را برگرداند:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

می‌توانید آن تابع را به این شکل به یک مولد تبدیل کنید:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

دلیلش این است که از مولد زمانی استفاده می‌کنید که نیازی ندارید همه‌ی مقادیر را _یک‌جا_ تولید کنید.
این کار حافظه و توان پردازشی را ذخیره می‌کند، چون فقط مقداری محاسبه می‌شود که _در همان لحظه روی آن کار می‌کنید_.


## استفاده از یک مولد

در Python می‌توان از مولدها به‌جای بیشتر `iterables` استفاده کرد.
این شامل _تابع‌ها_ یا _شیءهایی_ می‌شود که یک `iterable`/`iterator` را به‌عنوان آرگومان می‌خواهند.

برای استفاده از مولد `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

مقادیر داخل یک `generator` را هم می‌توان با تابع `next()` تولید کرد یا به آن‌ها دسترسی داشت.
`next()` متد `__next__()` یک شیء مولد-تکرارگر را فراخوانی می‌کند، کد را تا عبارت `yield` آن «به جلو می‌برد» یا ارزیابی می‌کند و بعد آن مقدار را «بازمی‌گرداند» یا برمی‌گرداند:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

وقتی یک `generator-iterator` کاملاً مصرف شود و دیگر مقداری برای برگرداندن نداشته باشد، یک خطای `StopIteration` پرتاب می‌کند.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

مولد-تکرارگرها زیرمجموعه‌ای خاص از [تکرارگرها][iterator] هستند.
`Iterators` سازوکار/پروتکلی هستند که حلقه‌زدن روی _تکرارپذیرها_ را ممکن می‌کنند.
مولد-تکرارگرها و تکرارگرهایی که [`iterables`][iterables] رایج Python برمی‌گردانند رفتار بسیار مشابهی دارند، اما چند تفاوت مهم وجود دارد که باید در نظر بگیرید:

- آن‌ها _[به‌صورت تنبل ارزیابی می‌شوند][lazy evaluation]_؛ تکرار _یک‌طرفه_ است و «عقب‌گرد» به مقدار قبلی وجود ندارد.
- با تکرار روی مقادیر برگردانده‌شده _مصرف می‌شوند_؛ هیچ بازنشانی یا ذخیره‌ای در حافظه وجود ندارد.
- قابل مرتب‌سازی نیستند و نمی‌توان آن‌ها را معکوس کرد.
- آن‌ها از انواع دنباله نیستند و `indexes` ندارند. 
  نمی‌توانید به مقدار قبلی یا بعدی با جمع یا تفریق ارجاع دهید و نمی‌توانید از نگارش کروشه (`[]`) یا برش استفاده کنید.
- نمی‌توان آن‌ها را با تابع `len()` به کار برد، چون طولی ندارند.
- می‌توانند _متناهی_ یا _نامتناهی_ باشند. هنگام جمع‌آوری همه‌ی مقادیر از یک `generator-iterator` _نامتناهی_ احتیاط کنید!

## عبارت `yield`

[عبارت `yield`][yield expression] بسیار شبیه عبارت `return` است.
_برخلاف_ عبارت `return`، دستور `yield` مقادیر را در یک _نقطه‌ی مشخص_ به فراخوان‌کننده واگذار می‌کند و ارزیابی یا برگرداندن مقادیر بیشتر را تا زمانی که درخواست شوند معلق نگه می‌دارد.
وقتی `yield` ارزیابی می‌شود، اجرای تابع دربرگیرنده را موقتاً متوقف می‌کند و مقادیر تابع را _در همان نقطه‌ی زمانی_ برمی‌گرداند.
پس از آن، تابع _در حوزه‌ی خود باقی می‌ماند_ و وقتی `__next__()` فراخوانی شود، اجرا تا رسیدن دوباره به `yield` ادامه پیدا می‌کند.


~~~~exercism/note
استفاده از عبارت‌های `yield` بیرون از توابع ممنوع است.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## چرا مولد بسازیم؟

مولدها در بسیاری از کاربردها مفیدند.

وقتی با مجموعه‌ی بالقوه‌ای بزرگ از مقادیر کار می‌کنید، ممکن است نخواهید همه‌ی آن‌ها را در حافظه قرار دهید.
می‌توان از یک مولد برای کار تکه‌تکه روی داده‌های بزرگ‌تر استفاده کرد، که حافظه را ذخیره می‌کند و کارایی را بهبود می‌بخشد.

مولدها همچنین وقتی یک فرایند یا محاسبه _پیچیده_، _پرهزینه_ یا _نامتناهی_ باشد بسیار کمک‌کننده‌اند:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

حالا هر بار که `__next__()` روی شیء `infinite_sequence` فراخوانی شود، _عدد قبلی_ را به‌علاوه‌ی ۱ برمی‌گرداند.
