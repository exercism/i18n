# Tests

برای اجرای tests با Objective-C دو روش متفاوت برای آماده‌سازی وجود دارد:

- یک پروژه‌ی Xcode با یک test target بسازید که tests را اجرا می‌کند.
- از gem مربوط به ruby با نام `objc` به عنوان ابزاری برای اجرای tests استفاده کنید.

هر دو مورد با جزئیات بیشتر اینجا توضیح داده شده‌اند: https://exercism.org/tracks/objective-c/tests
