# مقدمه

## Charlists

Charlists با استفاده از سیگیل `~c` ساخته می‌شوند.

```elixir
~c"hello"
```

~~~~exercism/note
توجه کنید که در نسخه‌های قدیمی‌تر Elixir، charlistها با کوتیشن تکی به‌صورت `'hello'` نمایش داده می‌شوند.
~~~~

با اینکه ظاهرشان بسیار شبیه رشته‌هاست، این دو نوع داده تفاوت زیادی با هم دارند. یک charlist فهرستی از اعداد صحیح است. این اعداد صحیح، مقدار یونیکد یک نویسه را نشان می‌دهند؛ به این مقدار، «نقطه‌ی کد» هم می‌گویند.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

می‌توانید قبل از یک نویسه علامت `?` بگذارید تا نقطه‌ی کد آن را به دست آورید.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

از آنجا که charlist یک فهرست است، می‌توانید درست مانند هر فهرست دیگری با آن کار کنید، مثلاً با بازگشت و تطبیق الگو.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

می‌توانید دو فهرست را با `++` به هم بچسبانید.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

هرچه فهرست اول طولانی‌تر باشد، چسباندن کندتر انجام می‌شود؛ پس از افزودن پیاپی به فهرست‌هایی با طول دلخواه خودداری کنید.

## case

`case` یک ساختار کنترل جریان است که به ما امکان می‌دهد یک مقدار مشخص را با الگوهای زیادی مقایسه کنیم. بندهای یک عبارت `case` از بالا به پایین ارزیابی می‌شوند تا اینکه تطبیقی پیدا شود.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
