# سطح دسترسی

وقتی از کلاس‌ها برای سازمان‌دهی کد استفاده می‌کنید، سطح دسترسی ویژگی‌ها، متدها و ثابت‌ها می‌تواند انتزاع‌ها و مسئولیت‌های درست را تشویق کند.
سطح دسترسی ویژگی‌ها، متدها و ثابت‌ها با استفاده از کلیدواژه‌های `public`، `private` یا `protected` در زمان اعلانشان تعریف می‌شود.
سطح دسترسی همیشه نسبت به استفاده‌ی بیرونی از ویژگی، متد یا ثابت کلاس سنجیده می‌شود.
یعنی اگر ویژگی‌ای `public` اعلان شود، برای فراخوانی‌های بیرونی قابل مشاهده و استفاده است.
ویژگی‌ها، متدها و ثابت‌های `private` برای فراخوانی‌های بیرونی قابل مشاهده یا استفاده نیستند.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

ویژگی‌ها، متدها و ثابت‌های `protected` فقط برای خودشان و کلاس‌های فرزند (از طریق وراثت) قابل مشاهده هستند.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
