# مقدمه

«اعداد اعشاری» اعدادی هستند که یک یا چند رقم بعد از جداکننده‌ی اعشار دارند. این اعداد از قالب ممیز شناور با دقت مضاعف ۶۴ بیتی استفاده می‌کنند.

```elixir
float = 3.45
# => 3.45
```

## کار با اعداد

در ماژول‌های [`Integer`][integer-functions] و [`Float`][float-functions] می‌توانید چند تابع مفید برای کار با این نوع‌ها پیدا کنید. عملگرهای حساب پایه در ماژول [`Kernel`][kernel-arithmetic-operators] تعریف شده‌اند.

## تبدیل

«اعداد صحیح» و اعداد اعشاری را می‌توان در یک عبارت حسابی با هم ترکیب کرد. به کار بردن یک عدد اعشاری در یک عبارت تضمین می‌کند که نتیجه هم اعشاری باشد.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

اما هنگام تقسیم، نتیجه همیشه اعشاری خواهد بود، حتی اگر فقط از اعداد صحیح استفاده شود.

```elixir
6 / 2
# => 3.0
```

برای تبدیل یک عدد اعشاری به عدد صحیح، می‌توانید بخش اعشاری را با [`trunc/1`][trunc-1] حذف کنید.
