# مقدمه

## مقایسه

Python از عملگرهای مقایسه‌ی پایه‌ی زیر پشتیبانی می‌کند:

| عملگر | عمل                  | توضیح                                                               |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | «بزرگ‌تر از»             | `a > b` برابر با `True` است اگر مقدار `a` **به‌طور اکید** بزرگ‌تر از `b` باشد        |
| `<`      | «کوچک‌تر از»                | `a < b` برابر با `True` است اگر مقدار `a` **به‌طور اکید** کوچک‌تر از `b` باشد           |
| `==`     | «برابر با»                 | `a == b` برابر با `True` است اگر مقدار `a` **به‌طور اکید** برابر با `b` باشد           |
| `>=`     | «بزرگ‌تر یا مساوی» | `a >= b` برابر با `True` است اگر مقدار `a > b` یا `a == b` باشد                        |
| `<=`     | «کوچک‌تر یا مساوی»    | `a <= b` برابر با `True` است اگر مقدار `a < b` یا `a == b` باشد                        |
| `!=`     | «برابر نبودن»             | `a != b` برابر با `True` است اگر `a == b` برابر با `False` باشد                                 |
| `is`     | «هویت»               | `a is b` برابر با `True` است اگر **_و تنها اگر_** `a` و `b` همان _شیء_ یکسان باشند |
| `is not` | «نقیض هویت»         | `a is not b` برابر با `True` است اگر `a` و `b` همان _شیء_ **نباشند**       |
| `in`     | «آزمون عضویت»         | `a in b` برابر با `True` است اگر `a` عضو، زیرمجموعه یا عنصری از `b` باشد            |
| `not in` | «آزمون نقیض عضویت» | `a not in b` برابر با `True` است اگر `a` عضو، زیرمجموعه یا عنصری از `b` نباشد  |

همه‌ی آن‌ها اولویت یکسانی دارند (_که از اولویت [عملیات منطقی][boolean operations] بالاتر، ولی از اولویت عملیات حسابی یا بیتی پایین‌تر است_).

## مقایسه بین انواع داده‌ی مختلف

اشیائی که از انواع متفاوتی هستند (_به‌جز انواع عددی_) به‌طور پیش‌فرض هرگز برابر مقایسه نمی‌شوند.
نمونه‌های غیریکسان یک `class` هم _**برابر**_ مقایسه نمی‌شوند، مگر آنکه `class` متدهای ویژه‌ی [مقایسه‌ی غنی][rich comparisons] را تعریف کند که رفتار پیش‌فرض مقایسه‌ی `object` را سفارشی‌سازی می‌کنند.
سفارشی‌سازی از طریق `rich comparisons` در یک تمرین بعدی پوشش داده می‌شود.
برای جزئیات (بسیار) بیشتر در این مورد، به [مقایسه‌ی مقادیر][value comparisons] در مستندات Python مراجعه کنید.

انواع عددی (بیشتر اوقات) استثنایی بر این قاعده‌ی تطبیق نوع هستند.
یک `integer` **می‌تواند** برابر با یک `float` در نظر گرفته شود (_یا یک [`octal`][octal] برابر با یک [`hexadecimal`][hex]_)، به شرطی که این انواع بتوانند به‌صورت ضمنی برای مقایسه تبدیل شوند.

برای دیگر انواع عددی در کتابخانه‌ی استاندارد Python ([complex][complex numbers]، [decimal][decimal numbers]، [fractions][rational numbers])، عملگرهای مقایسه در جایی تعریف می‌شوند که «معنا دارند» (_جایی که تبدیل ضمنی نتیجه را تغییر نمی‌دهد_)، ولی اگر اشیاء زیربنایی نتوانند به‌درستی برای مقایسه تبدیل شوند، یک `TypeError` پرتاب می‌کنند.
برای اطلاعات بیشتر درباره‌ی قواعدی که Python برای _تبدیل عددی_ به کار می‌برد، به [تبدیل‌های حسابی][arithmetic conversions] در مستندات Python مراجعه کنید.

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

هر مقایسه‌ی ترتیبی یک عدد با یک نوع `NaN` (_نه یک عدد_) برابر با `False` است.
یک عارضه‌ی گیج‌کننده‌ی تعریف `NaN` در Python این است که `NaN` هرگز برابر با `NaN` مقایسه نمی‌شود.

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## مقایسه‌ی رشته‌ها

برخلاف اعداد، رشته‌ها (`str`) به‌صورت [_واژه‌نامه‌ای_][lexographic order] مقایسه می‌شوند، با استفاده از نقاط کد یونیکد تک‌تک آن‌ها (_یعنی نتیجه‌ی سپردن هر نقطه‌ی کد در `str` به تابع توکار [`ord()`][ord]، که یک `int` برمی‌گرداند_).
اگر همه‌ی نقاط کد در هر دو رشته مطابقت داشته باشند و _**به یک ترتیب**_ باشند، آن دو رشته برابر در نظر گرفته می‌شوند.
این مقایسه به‌شکل «جفت‌به‌جفت» انجام می‌شود، اولی‌بااولی، دومی‌بادومی و به همین ترتیب.
در Python 3.x، `str` و `bytes` را نمی‌توان مستقیماً هم‌تبدیل یا مقایسه کرد.

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## زنجیره‌سازی مقایسه

عملگرهای مقایسه را می‌توان _به‌صورت دلبخواه_ زنجیره کرد، یعنی می‌توان آن‌ها را در هر ترکیبی با هر طولی به کار برد.
توجه داشته باشید که ارزیابی یک عبارت از `left` به `right` انجام می‌شود.

به‌عنوان مثال، `x < y <= z` معادل `x < y` `and` `y <= z` است، با این تفاوت که `y` **فقط یک‌بار** ارزیابی می‌شود.
در هر دو حالت، وقتی `x < y` برابر با `False` تشخیص داده شود، `z` **اصلاً** ارزیابی _نمی‌شود_.
به این کار اغلب `short-circuit evaluation` می‌گویند: اگر ارزش درستیِ عبارت پیش‌تر مشخص شده باشد، ارزیابی متوقف می‌شود.

`Short circuiting` توسط عملگرهای منطقی و توابع مختلف، و همچنین توسط زنجیره‌سازی مقایسه در Python پشتیبانی می‌شود.
برخلاف بسیاری از زبان‌های برنامه‌نویسی دیگر، از جمله `C`، `C++`، `C#` و `Java`، عبارت‌های زنجیره‌ای مانند `a < b < c` در Python یک [تفسیر ریاضی][three way boolean comparison] و اولویت متعارف دارند.

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## مقایسه‌ی هویت شیء

عملگرهای `is` و `is not` [_هویت_][object identity] شیء را می‌آزمایند، در مقابل _مقدار_ شیء.
هویت یک شیء پس از ساخته‌شدن هرگز تغییر نمی‌کند و می‌توان آن را با استفاده از تابع [`id()`][id function] یافت.

`<apple> is <orange>` اگر _**و تنها اگر**_ `id(<apple>)` == `id(<orange>)` باشد، برابر با `True` ارزیابی می‌شود.
`<apple> is not <orange>` نتیجه‌ی معکوس را می‌دهد.

به دلیل وضعیت تک‌نمونه‌ای‌شان، `None` و `NotImplemented` باید همیشه با استفاده از `is` و `is not` با عناصر مقایسه شوند.
برای جزئیات بیشتر درباره‌ی این قرارداد، مستندات مرجع Python درباره‌ی [مقایسه‌ی مقادیر][value comparisons none] و [PEP8][pep8 programming recommendations] را ببینید.

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## مقایسه‌های عضویت

عملگرهای `in` و `not in` _عضویت_ را می‌آزمایند.
`<fish> in <soup>` اگر `<fish>` عضوی از `<soup>` باشد (_اگر `<fish>` زیرمجموعه‌ای از `<soup>` باشد یا درون آن قرار گیرد_)، برابر با `True` ارزیابی می‌شود و در غیر این صورت `False` ارزیابی می‌شود.
`<fish> not in <soup>` نقیض، یا _معکوسِ_ `<fish> in <soup>` را برمی‌گرداند.

برای انواع رشته و بایت، `<name> in <fullname>` _**اگر و تنها اگر**_ `<name>` زیررشته‌ای از `<fullname>` باشد، برابر با `True` است.

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
