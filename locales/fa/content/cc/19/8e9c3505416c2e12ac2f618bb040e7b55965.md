# دستورالعمل‌ها

در این تمرین روی چند تابع کار می‌کنید تا نوبت‌ها را مدیریت کنید.
سیستم همه‌ی اطلاعات را در رشته‌هایی با قالب ISO 8601 ذخیره می‌کند، اما مردم تقویم را این‌طور به کار نمی‌برند.
برای تبدیل میان این قالب‌های مختلف، توابع گوناگونی لازم است.

## 1. یک نوبت ایجاد کنید

یک نوبت برای `n` روز بعد از الان و در زمان کنونی ایجاد کنید.
این تابع `n` روز را می‌گیرد و زمان نوبت را برای `n` روز بعد از الان برمی‌گرداند.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

اگر پارامتر دوم یعنی `now` استفاده نشود، باید از زمان کنونی استفاده شود.

## 2. تبدیل یک تاریخ به برچسب زمان

ابزارهای گوناگون فقط با قالب ISO 8601 که استاندارد بین‌المللی است کار می‌کنند.
تابع `getAppointmentTimestamp` را بنویسید تا یک تاریخ بگیرد و رشته‌ای در همان قالب برگرداند.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. جزئیات یک نوبت را دریافت کنید

خواندن برچسب‌های زمان سخت است؛ تابعی که جزئیات نوبت را بگیرد می‌تواند در این کار کمک کند.
تابع `getAppointmentDetails` یک برچسب زمان در قالب ISO 8601 می‌گیرد و سال، ماه، تاریخ، ساعت و دقیقه را برمی‌گرداند.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. به‌روزرسانی یک نوبت با گزینه‌های داده‌شده

این تابع، آرگومان اول را به‌عنوان زمان نوبت و آرگومان دوم را به‌عنوان شیئی از چند گزینه دریافت می‌کند.
باید نوبت را بر اساس گزینه‌های موجود در آن شیء به‌روزرسانی کنید و تاریخ نوبت جدید را برگردانید.
شیء گزینه‌ها می‌تواند چندین گزینه داشته باشد.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. دریافت زمان موجود بین دو نوبت

این تابع، دو نوبت (برچسب زمان) را به‌عنوان آرگومان دریافت می‌کند.
باید اختلاف آن دو زمان را بر حسب ثانیه برگردانید.

چون نیم ثانیه تقریباً بی‌معناست، عدد را پیش از برگرداندن گرد کنید.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. بررسی اینکه آیا نوبت اکنون معتبر است یا نه

در پایان، وقتی نوبتی ثبت می‌شود، سیستم باید بررسی کند که معتبر است یا نه.
به بیان دیگر، نوبت باید در آینده باشد، نه در گذشته.

تابع `isValid` را بنویسید که دو آرگومان می‌گیرد: یک برچسب زمان نوبت (رشته) و زمان کنونی به‌صورت برچسب زمان (رشته)؛ و اگر نوبت با توجه به زمان کنونی در آینده باشد، `true` را برمی‌گرداند.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
