# پیوست دستورالعمل

## ثبات

| ثبات     | کاربرد        | نوع    | توضیح                                  |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | ورودی        | نشانی | رشته‌ی ورودی که با `null` پایان می‌یابد            |
| `$a1`    | ورودی/خروجی | نشانی | آرایه‌ی کلمه‌ای که شمارش نهایی نوکلئوتیدها را نگه می‌دارد |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت                   |
