# درباره

مقادیر منطقی در C++ با نوع `bool` نمایش داده می‌شوند.
مقدار `bool` یا `true` است یا `false`.

## عملگرهای منطقی

C++ از سه عملگر منطقی پشتیبانی می‌کند: `!` (NOT)، `&&` (AND) و `||` (OR).
همچنین می‌توانید از نسخه‌های جایگزین `not`، `and` و `or` استفاده کنید.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## اولویت

این سه عملگر منطقی هرکدام _«اولویت عملگر»_ متفاوتی دارند.
در نتیجه، به این ترتیب ارزیابی می‌شوند: ابتدا `!`، سپس `&&` و در نهایت `||`.
اگر می‌خواهید ترتیب متفاوتی را اجباری کنید، می‌توانید یک عبارت منطقی را در پرانتز (یعنی `()`) قرار دهید، زیرا پرانتزها حتی اولویت عملگر بالاتری دارند.

```cpp
!true && false   // => false
!(true and false) // => true
```

## تبدیل

اگر از `true` یا `false` در جایی استفاده کنید که یک عدد انتظار می‌رود، به‌ترتیب به `1` و `0` تبدیل می‌شوند.
اگر از یک عدد در یک عملیات منطقی استفاده کنید، هر مقدار دیگری به‌جز `0` به‌عنوان `true` در نظر گرفته می‌شود، حتی مقادیر منفی.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
