# درباره

«[گاردها][guards]» به‌عنوان مکملی برای «[تطبیق الگو][exercism-pattern-matching]» به کار می‌روند. این‌ها امکان بررسی‌های پیچیده‌تری را فراهم می‌کنند. می‌توان از آن‌ها در [برخی موقعیت‌ها، اما نه همه][where-guards-can-be-used]، که تطبیق الگو در آن‌ها به کار می‌رود، استفاده کرد؛ برای مثال در بندهای تابع یا بندهای `case`.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- گاردها با کلیدواژه‌ی `when` شروع می‌شوند و پس از آن یک عبارت «منطقی» می‌آید.
- عبارت‌های گارد، توابع خاصی هستند که:
  - باید [خالص][pure-function] باشند و هیچ حالت سراسری‌ای را تغییر ندهند.
  - باید مقادیر دقیقاً `true` یا `false` را برگردانند.
- فهرستی از گاردهای رایج در [مستندات Elixir][kernel-guards] آمده است. از جمله:
  - بررسی‌های نوع: [`is_integer/1`][guard-is-integer]، [`is_list/1`][guard-is-list]، [`is_nil/1`][guard-is-nil] و غیره.
  - عملگرهای حسابی: [`+/2`][guard-plus]، [`-/2`][guard-minus] و غیره.
  - مقایسه‌ها: [`==/2`][guard-equals]، [`>/2`][guard-greater]، [`</2`][guard-less] و غیره.
  - عملگرهای منطقی: [`and/2`][guard-and]، [`or/2`][guard-or]، [`not/1`][guard-not]
  - عملگر عضویت: [`in/2`][guard-in]
- می‌توانید گارد خودتان را با [`defguard`][defguard] تعریف کنید.

  - بر اساس [قرارداد نام‌گذاری][naming] Elixir، اسم گاردها باید با `is_` شروع شود.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
