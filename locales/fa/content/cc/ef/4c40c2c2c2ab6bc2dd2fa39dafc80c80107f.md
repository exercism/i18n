# مفاهیم اعداد آرمسترانگ

> [عدد آرمسترانگ](https://en.wikipedia.org/wiki/Narcissistic_number) عددی است که با مجموع رقم‌های خودش برابر است، به شرطی که هر رقم به توان تعداد رقم‌ها رسیده باشد.

## نمونه راه‌حل

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## مفاهیم

- توابع: برای تأیید راه‌حل و تعریف منطق ضروری‌اند
- مجموعه‌های Test: برای تأیید راه‌حل لازم‌اند
- اعداد صحیح: `u32` برای آرگومان و بررسی‌های یکسانی
- `&str`: برای شمردن طول عدد لازم است، چون Rust به نوع‌ها سخت‌گیرانه پایبند است
- `Option<T>`: برای دسترسی به مقدار واقعی `char::to_digit` لازم است
- تبدیل نوع: برای اعمال عملیات حسابی لازم است
- ویژگی‌های تکرارگر:
  - turbofish برای ممکن کردن راه‌حل تک‌عبارتی
  - `map` و `sum` برای کاهش راحت عبارت به چیزی که باید تأیید کنیم
