# مقدمه

PowerShell یک زبان اسکریپت‌نویسی با نوع‌دهی ضمنی پویا (که از متغیرهای با نوع صریح هم پشتیبانی می‌کند) از Microsoft است که بیشتر بر خودکارسازی کارها و مدیریت پیکربندی تمرکز دارد.

PowerShell از برنامه‌نویسی امری، تابعی، شیءگرا و حتی سبک پایپ‌لاین پشتیبانی می‌کند.

PowerShell بر بستر پلتفرم .NET ساخته شد و نخستین بار در سال ۲۰۰۶ منتشر شد.
این زبان به‌صورت پیش‌فرض در همه‌ی نسخه‌های مدرن Windows گنجانده شده است و می‌توان آن را روی Mac و Linux نصب کرد.


## متغیر

دو روش رایج برای تعریف متغیر در PowerShell وجود دارد.

اسم متغیر در PowerShell باید با `$` شروع شود و از عملگر انتساب `=` برای اتصال اسم متغیر به یک مقدار استفاده می‌کند.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

همچنین می‌توانید نوع یک متغیر را به‌صورت صریح مشخص کنید، اگر می‌خواهید [نوع][strong typed] خاصی را اعمال کنید.
PowerShell تمام تلاش خود را می‌کند تا در صورت امکان مقدار را از یک نوع به نوع دیگر تبدیل کند.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### ثابت

ثابت‌ها در PowerShell متغیرهای فقط‌خواندنی هستند که پس از تعریف نمی‌توان آن‌ها را **حذف** کرد.
این ما را به روش دوم تعریف متغیرها با استفاده از کامندلت `New-Variable` می‌رساند.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

برای آشنایی با روشی دقیق‌تر و پیشرفته‌تر برای ساخت متغیر جدید با گزینه‌های مختلف، لطفاً کامندلت [New-Variable][New-Variable] را ببینید.


## تابع

[توابع][functions] در PowerShell با کلیدواژه‌ی `function` تعریف می‌شوند.
هر تابع می‌تواند صفر یا چند [پارامتر][parameters] صوری در پرانتز `()` داشته باشد که پس از آن [محدوده][scope] خودش با `{` شروع و با `}` پایان می‌یابد.

```powershell
function Greeting {
    return "Hello!"
}
```

توابع در PowerShell می‌توانند مقادیر را به‌صورت صریح از طریق کلیدواژه‌ی `return` برگردانند، پس از آن‌که با نحوه‌ی نگارش `FuncName $Arg` فراخوانی شوند.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

نگاه پیشرفته‌تر به نحوه‌ی نوشتن تعریف دقیق تابع و اینکه توابع چگونه می‌توانند مقادیر را به‌صورت ضمنی برگردانند، در ماژول مفهومی `Functions` پوشش داده خواهد شد.


## کامنت

کامنت تک‌خطی در PowerShell با `#` شروع می‌شود و در پایان خط تمام می‌شود.
بلوک کامنت در PowerShell با `<#` شروع و با `#>` پایان می‌یابد.
نمایش پیشرفته‌ی بلوک کامنت برای ساخت راهنمای مبتنی بر کامنت در ماژول مفهومی `Functions` پوشش داده خواهد شد.

```powershell
function Main() {
    #This is a comment
}
```
