# دستورالعمل‌ها

در این تمرین با حساب‌های پس‌انداز کار می‌کنید.
هر سال، موجودی حساب پس‌انداز شما بر اساس نرخ سود آن به‌روزرسانی می‌شود.
نرخ سودی که بانک به شما می‌دهد به مقدار پول در حساب شما (یعنی موجودی آن) بستگی دارد:

- 3.213٪ برای موجودی منفی (موجودی منفی‌تر می‌شود).
- 0.5٪ برای موجودی مثبت کمتر از `1000` دلار.
- 1.621٪ برای موجودی مثبت بزرگ‌تر یا مساوی `1000` دلار و کمتر از `5000` دلار.
- 2.475٪ برای موجودی مثبت بزرگ‌تر یا مساوی `5000` دلار.

چهار کار پیش رو دارید که هر کدام به موجودی و نرخ سود آن می‌پردازد.

## 1. محاسبه‌ی نرخ سود

متد `SavingsAccount.interest_rate()` را پیاده‌سازی کنید که یک موجودی را به عنوان آرگومان می‌گیرد.
این متد باید نرخ سود را برای موجودی داده‌شده برگرداند.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. محاسبه‌ی سود

متد `SavingsAccount.interest()` را پیاده‌سازی کنید که یک موجودی را به عنوان آرگومان می‌گیرد.
این متد باید سود مربوط به موجودی داده‌شده را برگرداند.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. محاسبه‌ی به‌روزرسانی سالانه‌ی موجودی

متد `SavingsAccount.annual_balance_update()` را پیاده‌سازی کنید که یک موجودی را به عنوان آرگومان می‌گیرد.
این متد باید موجودی را پس از یک سال برگرداند.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. محاسبه‌ی تعداد سال‌های لازم برای رسیدن به موجودی هدف

متد `SavingsAccount.years_before_desired_balance()` را پیاده‌سازی کنید که یک موجودی و یک موجودی هدف را به عنوان آرگومان می‌گیرد.
این متد باید تعداد سال‌هایی را که برای رسیدن به موجودی هدف لازم است، برگرداند.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
وقتی سود ساده به موجودی اصل اعمال می‌شود، موجودی در نرخ سود ضرب می‌شود و حاصل‌ضرب این دو، مقدار سود است.

از طرف دیگر، سود مرکب با اعمال سود به صورت دوره‌ای محاسبه می‌شود.
در هر بار اعمال، مقدار سود محاسبه و به موجودی اصل اضافه می‌شود، به طوری که محاسبات سود بعدی روی موجودی اصل بزرگ‌تری انجام می‌شوند.
~~~~
