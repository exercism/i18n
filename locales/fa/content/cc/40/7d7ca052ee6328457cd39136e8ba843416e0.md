# مقدمه

کار با دادههای دودویی میتواند دشوار باشد، به همین دلیل Gleam یک نوع `BitArray` و نحوه‌ی نگارش همراه آن را برای ساختن و تطبیق الگو روی داده‌های دودویی فراهم می‌کند.

لیترال‌های آرایه‌ی بیتی با استفاده از نحوه‌ی نگارش `<<>>` تعریف می‌شوند. وقتی یک لیترال آرایه‌ی بیتی تعریف می‌کنید، به‌صورت قطعه‌قطعه تعریف می‌شود. هر قطعه یک مقدار و یک حاشیه‌نویسی دارد که با `:` از هم جدا می‌شوند. حاشیه‌نویسی مشخص می‌کند که چند بیت برای رمزگذاری مقدار استفاده می‌شود و اگر کاملاً حذف شود، به‌طور پیش‌فرض یک مقدار صحیح ۸ بیتی در نظر گرفته می‌شود.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

مشخص کردن نوع به‌صورت `:1` کوته‌نوشتی برای نوشتن `:size(1)` است. اگر اندازه‌ی بیت از یک متغیر بیاید، باید از نحوه‌ی نگارش بلندتر استفاده کنید.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## دودویی

هنگام نوشتن لیترال‌های صحیح دودویی، می‌توانید آن‌ها را مستقیماً با نمایش مبنای ۲ بنویسید، با قرار دادن `0b` در ابتدای لیترال. توجه داشته باشید که هنگام چاپ در تست‌ها یا در برنامه‌تان به‌صورت اعداد دهدهی نمایش داده می‌شوند.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## کوتاه کردن

اگر مقدار قطعه از ظرفیت نوع قطعه سرریز کند، از سمت چپ کوتاه می‌شود.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## افزودن به ابتدا و انتها

می‌توانید با استفاده از نحوه‌ی نگارش آرایه‌ی بیتی، هم به ابتدای یک آرایه‌ی بیتی موجود اضافه کنید و هم به انتهای آن. برای آرایه‌ی بیتی موجود باید از حاشیه‌نویسی `:bits` استفاده شود.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## به‌هم‌چسباندن

می‌توانید آرایه‌های بیتی ذخیره‌شده در متغیرها را با استفاده از این نحوه‌ی نگارش به هم بچسبانید. هنگام به‌هم‌چسباندن دو آرایه‌ی بیتی با اندازه‌های متغیر باید از حاشیه‌نویسی `:bits` استفاده شود.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## تطبیق الگو

می‌توان از تطبیق الگو هم برای به دست آوردن مقادیر از آرایه‌ی بیتی استفاده کرد. باید تعداد بیت‌های هر بخشی را که می‌خواهید ثبت کنید بدانید، با یک استثنا: می‌توان از حاشیه‌نویسی `:bits` برای تطبیق الگو روی آرایه‌ی بیتی با اندازه‌ی نامعلوم استفاده کرد، اما این کار فقط برای آخرین بخش قابل استفاده است.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## بررسی آرایه‌های بیتی

~~~~exercism/note
آرایه‌های بیتی ممکن است در قالبی متفاوت از قالبی که برای ساختنشان استفاده شده چاپ شوند. این موضوع هنگام یادگیری آرایه‌های بیتی اغلب باعث سردرگمی می‌شود.
~~~~

به‌طور پیش‌فرض، آرایه‌های بیتی در بخش‌هایی از ۸ بیت (یک بایت) نمایش داده می‌شوند، حتی اگر آن‌ها را با بخش‌هایی با اندازه‌ی متفاوت ساخته باشید.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

اگر آرایه‌ی بیتی‌ای بسازید که نماینده‌ی یک رشته‌ی قابل چاپ با کدگذاری UTF-8 باشد، ممکن است توسط توابعی مانند `io.debug` به‌صورت یک رشته نمایش داده شود. این به دلیل جزئیات پیاده‌سازی نحوه‌ی نمایش داخلی رشته‌ها در Gleam است.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
