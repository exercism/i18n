# پیوست دستورالعمل‌ها

## واژه‌ها

یک تاپل `game` و یک سازنده‌ی `<game> ( -- game )` را تعریف کنید که یک بازی تازه بدون هیچ پرتابی برمی‌گرداند.

واژه‌های زیر را که روی یک بازی عمل می‌کنند ارائه دهید:

- `roll ( pins game -- )`: ثبت می‌کند که `pins` میله افتاده است. وقتی پرتاب نامعتبر باشد، خطا بدهید:
  - `"Negative roll is invalid"` برای تعداد منفی میله‌ها.
  - `"Cannot roll after game is over"` وقتی همه‌ی ده فریم (و هر توپ تکمیلی) پرتاب شده باشند.
  - `"Pin count exceeds pins on the lane"` وقتی تعداد میله‌های افتاده از میله‌های ایستاده روی لاین بیشتر باشد.
- `score ( game -- n )`: امتیاز کل بازی. وقتی بازی هنوز کامل نشده است، خطای `"Score cannot be taken until the end of the game"` را بدهید.

توجه کنید که `roll` واژه‌ی جابه‌جایی `roll` را از واژگان `kernel` سایه می‌اندازد. مجموعه‌آزمون با `FROM: bowling => roll ;` ابهام‌زدایی می‌کند.
