# مقدمه

در JavaScript، «رشته‌ی قالبی» امکان درج عبارت‌ها را درون رشته‌ها فراهم می‌کند؛ به این کار درج درون‌رشته‌ای هم می‌گویند.
این قابلیت، کارکرد شیء سراسری [`String`][string-reference] را گسترش می‌دهد.

برای ساختن رشته‌ی قالبی در JavaScript، کافی است متن را میان دو بک‌تیک بگذارید.
رشته‌ی قالبی نه‌تنها اجازه می‌دهد متن شامل خطوط جدید و نویسه‌های خاص دیگر باشد، بلکه می‌توانید متغیرها و عبارت‌های دیگر را هم در آن جای دهید.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

در مثال بالا، بک‌تیک‌ها (<code>\`\`</code>) برای نمایش رشته‌ی قالبی به کار می‌روند. `${...}` جانگه‌داری است که برای جانشینی استفاده می‌شود.
هر نوع غیر رشته‌ای، _به‌صورت ضمنی_ به رشته تبدیل می‌شود.
این موضوع در مفهوم [تبدیل نوع][type-conversion-concept] بررسی می‌شود.
همه‌ی انواع عبارت را می‌توان با رشته‌ی قالبی به کار برد.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

وقتی می‌خواهید رشته در چند خط قالب‌بندی شود:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

با توانایی‌های جانشینی که در اختیار دارید، می‌توانید منطق را هم وارد این فرایند کنید تا مشخص کنید رشته‌ی خروجی چه باید باشد.

یک نمونه از این کار، درج [عملگر سه‌تایی][ternary-operator] است.
این عملگر شکل کوتاه نوشتن دستور `if/else` است.
نحوه‌ی نگارش آن `condition ? consequent-expression : alternative-expression` است.
اگر شرط درست باشد، عملوند سمت چپ دونقطه برگردانده می‌شود.
در غیر این صورت، نتیجه‌ی عبارت سه‌تایی، عملوند سمت راست دونقطه است.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
