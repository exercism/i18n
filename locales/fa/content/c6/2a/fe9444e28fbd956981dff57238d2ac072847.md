# مقدمه

## متدهای الحاقی

متدهای الحاقی به شما امکان می‌دهند بدون ایجاد یک نوع مشتق‌شده‌ی جدید، کامپایل مجدد، یا تغییر نوع اصلی به شکل دیگری، به انواع موجود متد اضافه کنید. این متدها به‌صورت متدهای ایستا تعریف می‌شوند، اما فراخوانی آن‌ها با نحوه‌ی نگارش فراخوانی متد نمونه انجام می‌شود. پیش از پارامتر اول آن‌ها اصلاح‌کننده‌ی `this` می‌آید؛ این پارامتر مشخص می‌کند که متد روی کدام نوع عمل می‌کند. این متدها در سطح فضای نام در دسترس قرار می‌گیرند.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
