# درباره

«لیست کلیدواژه» لیستی از [تاپل‌های][exercism-tuples] `{key, value}` است. دو روش برای نوشتن یک لیست کلیدواژه وجود دارد:

```elixir
# concise
[month: "April", year: 2018]

# explicit
[{:month, "April"}, {:year, 2018}]
```

## کلیدها باید اتم باشند

هر لیستی از تاپل‌های دوتایی، لیست کلیدواژه نیست. کلیدها باید اتم باشند:

```elixir
Keyword.keyword?([{"month", "April"}])
# => false
```

اگر می‌خواهید در کلید از نویسه‌هایی غیر از حروف، اعداد و `_` استفاده کنید، باید آن را داخل کوتیشن بگذارید. اما این کار آن را به رشته تبدیل نمی‌کند؛ همچنان یک اتم است.

[//]: # (elixir-formatter-disable-next-block)

```elixir
Keyword.keyword?(["day of week": "Monday"])
# => true
```

## کلیدها می‌توانند تکرار شوند

کلیدها در یک لیست کلیدواژه می‌توانند تکرار شوند و [جفت‌های کلید-مقدار مرتب هستند][keyword-duplicate-keys-and-ordering]. وقتی بخواهید یک مقدار مشخص را از یک کلید به دست آورید، اولین مقدار را دریافت می‌کنید و سایر مقادیر زیر همان کلید بی‌سروصدا نادیده گرفته می‌شوند.

```elixir
list = [month: "April", month: "May"]

Keyword.get_values(list, :month)
# => ["April", "May"]

Keyword.get(list, :month)
# => "April"
```

لیست‌های کلیدواژه همچنین از [_رفتار Access_][access-behaviour] پشتیبانی می‌کنند.

```elixir
list[:month]
# => "April"
```

## لیست‌های کلیدواژه به عنوان گزینه‌ها

ویژگی‌های لیست‌های کلیدواژه، آن‌ها را به مکانیزم پیش‌فرض برای ارسال گزینه‌ها به توابع در Elixir تبدیل کرد.

وقتی درباره‌ی `if` یاد می‌گرفتید، یک نحوه‌ی نگارش کوتاه‌تر و خاص دیدید:

```elixir
if age >= 16, do: "beer", else: "no beer"
```

ممکن است به نظر برسد که `if` دو آرگومان می‌پذیرد، اما جفت `do:` و `else:` در واقع یک آرگومان واحد است: یک لیست کلیدواژه. همین کد را می‌توان این‌گونه نوشت:

[//]: # (elixir-formatter-disable-next-block)

```elixir
if age >= 16, [do: "beer", else: "no beer"]
# or
if age >= 16, [{:do, "beer"}, {:else, "no beer"}]
```

استفاده از لیست‌های کلیدواژه به عنوان گزینه‌های تابع آن‌قدر رایج است که Elixir به شما اجازه می‌دهد [وقتی لیست کلیدواژه آخرین آرگومان ارسالی به تابع است، براکت‌های مربعی را حذف کنید][keyword-call-syntax].

از آنجا که تاپل‌ها، لیست‌ها، مپ‌ها و موارد دیگر در نحوه‌ی نگارش Elixir مانند فراخوانی تابع رفتار می‌شوند، این ویژگی برای آن‌ها هم در دسترس است.

```elixir
[1, 2, three: 3]
# => [1, 2, {:three, 3}]
```

## تطبیق الگو

برای اینکه با استفاده از نحوه‌ی نگارش مختصر، تطبیق الگو را روی یک لیست کلیدواژه با موفقیت انجام دهید، باید همه‌ی کلیدها را به ترتیب درست مشخص کنید. همین باعث می‌شود تطبیق الگو انتخاب بعیدی برای کار با لیست‌های کلیدواژه باشد. در عوض از ماژول [`Keyword`][keyword] یا [_رفتار Access_][access-behaviour] استفاده کنید.

```elixir
[month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]

[year: year, month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]
```

## لیست‌های کلیدواژه در برابر مپ‌ها

|                  | لیست کلیدواژه                 | مپ                                  |
| ---------------- | ----------------------------- | ----------------------------------- |
| نوع کلید         | اتم                           | هر نوعی، می‌توانند در یک مپ ترکیب شوند |
| کلیدهای تکراری   | بله                           | خیر                                 |
| ترتیب کلیدها     | بله                           | خیر                                 |
| دسترسی           | `list[:key]`, `Keyword.get/2` | `map.key`, `map[:key]`, `Map.get/2` |
| زمان دسترسی      | خطی                           | لگاریتمی                            |
| تطبیق الگو       | چندان مفید نیست               | مفید                                |

زمان دسترسی سریع‌تر، نوع کلید انعطاف‌پذیر و تطبیق الگوی مفید، مپ‌ها را در بیشتر موارد به انتخاب پیش‌فرض تبدیل می‌کند.

وقتی داده‌ی زیادی ندارید اما به کلیدهای تکراری یا کلیدهایی با ترتیب مشخص نیاز دارید، از لیست‌های کلیدواژه استفاده کنید.
