# دستورالعمل

شرکتی که در آن کار می‌کنید در آستانه‌ی عرضه‌ی گوشی هوشمند تازه‌اش به نام **Smarty 5** است؛ این گوشی به یک سیستم دوربین تازه، یک طراحی جدید و یک پردازنده‌ی انقلابی مجهز است که روی سیستم‌عامل جدیدی به نام **smartyOS** اجرا می‌شود.

پردازنده‌ی جدید این توان را دارد که رمزهای عبور امن‌تری از همیشه را پردازش کند و شرکت تصمیم گرفته از این مزیت به نفع خودش استفاده کند. آن‌ها از شما خواسته‌اند که یک سیستم قفل رمز عبور برای این گوشی پیاده‌سازی کنید تا کاربر بتواند رمزی تعیین کند و سپس بررسی کند که رمز داده‌شده درست است یا نه.

~~~~exercism/caution
سیستم رمز عبوری که در این تمرین با آن کار می‌کنید امن نیست و فقط با هدف آموزشی به کار می‌رود. این سیستم **نباید** در هیچ برنامه‌ی واقعی به کار رود.
~~~~

## 1. تعیین رمز عبور

گوشی به کاربران اجازه می‌دهد از چند نوع مختلف رمز عبور استفاده کنند، از یک رمز عبور عددی ساده تا یک رمز عبور حرف‌وعددی امن‌تر و حتی رمزی که اثر انگشتشان را ذخیره می‌کند.

این انواع مختلف رمز عبور از نوع‌های متفاوتی استفاده می‌کنند: رمز عبور عددی از `Int32` استفاده می‌کند، رمز عبور حرف‌وعددی از `String` و رمز عبور اثر انگشت از `Float64`.

کلاس `PasswordLock` را با یک سازنده پیاده‌سازی کنید که هر یک از این سه نوع رمز عبور را به عنوان آرگومان می‌گیرد و آن را در یک متغیر نمونه‌ای به نام `@password` ذخیره می‌کند.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. رمزگذاری رمز عبور

شرکت تصمیم گرفته رمز عبور را رمزگذاری کند تا به‌صورت متن ساده ذخیره نشود و از شما خواسته است متدی برای رمزگذاری آن پیاده‌سازی کنید.

هر نوع رمز عبور، روش یکتای خودش را برای رمزگذاری دارد:

- رمز عبور `Int32`: رمز عبور بر دو تقسیم می‌شود و به نزدیک‌ترین عدد صحیح گرد می‌شود.
- رمز عبور `String`: رمز عبور برعکس می‌شود.
- رمز عبور `Float64`: رمز عبور در چهار ضرب می‌شود.

یک متد نمونه‌ای به نام `encrypt` پیاده‌سازی کنید که هیچ آرگومانی نمی‌گیرد و متغیر نمونه‌ای `@password` را طوری تغییر می‌دهد که رمزگذاری شود.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. بررسی درست بودن رمز عبور

شرکت همچنین از شما خواسته است متدی پیاده‌سازی کنید که بررسی می‌کند آیا رمز عبور داده‌شده درست است یا نه.

آن‌ها می‌خواهند این متد اگر رمز عبور نادرست بود `nil` و اگر رمز عبور درست بود `"Unlocked"` برگرداند.

یک متد نمونه‌ای به نام `unlock?` پیاده‌سازی کنید که رمز عبور مورد بررسی را به عنوان آرگومان می‌گیرد.
این متد باید اگر رمز عبور نادرست بود `nil` و اگر رمز عبور درست بود `"Unlocked"` برگرداند.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
