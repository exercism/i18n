# مقدمه

## عملگرهای حسابی

JavaScript شش عملگر مختلف را برای انجام عملیات حسابی پایه روی اعداد در اختیار شما قرار می‌دهد.

- `+`: عملگر جمع برای یافتن مجموع اعداد به کار می‌رود.
- `-`: عملگر تفریق برای یافتن اختلاف دو عدد به کار می‌رود.
- `*`: عملگر ضرب برای یافتن حاصل‌ضرب دو عدد به کار می‌رود.
- `/`: عملگر تقسیم برای تقسیم دو عدد به کار می‌رود.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: عملگر باقیمانده برای یافتن باقیمانده‌ی یک تقسیم به کار می‌رود.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: عملگر توان برای رساندن یک عدد به توان به کار می‌رود.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## ترتیب عملیات

وقتی چند عملگر در یک خط به کار می‌رود، JavaScript ترتیب تقدمی را دنبال می‌کند که در [این جدول تقدم][mdn-operator-precedence] نشان داده شده است.
برای ساده کردنش در بستر ما، JavaScript از قاعده‌ی PEDMAS (پرانتز، توان، تقسیم/ضرب، جمع/تفریق) استفاده می‌کند که در کلاس‌های ریاضی مقدماتی یاد گرفته‌ایم.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## عملگرهای انتساب کوتاه‌نویسی

عملگرهای انتساب کوتاه‌نویسی روش کوتاه‌تری برای نوشتن کدی هستند که عملیات حسابی را روی یک متغیر انجام می‌دهد و مقدار جدید را به همان متغیر نسبت می‌دهد.
برای مثال، دو متغیر `x` و `y` را در نظر بگیرید.
در این صورت، `x += y` همان `x = x + y` است.
غالباً این کار با یک عدد به جای متغیر `y` انجام می‌شود.
پنج عملیات دیگر هم می‌توانند به روشی مشابه انجام شوند.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
