# دستورالعمل‌ها

شما اپراتور بی‌سیم تلگراف روی یک کشتی باری هستید. سیگنال از خطی پرنویز می‌رسد؛ صدای ماشین‌آلات کشتی، پارازیت جوّ، گاهی هم صحبت‌های بیگانه، همه درهم‌آمیخته با همان مورسی که در انتظارش هستید. برای گرفتن پیام، سیم را از دستگاهی به نام «نوار» عبور می‌دهید که هر چیزی جز نمادهای معتبر مورس (`.`، `-` و فاصله‌ای که حروف را از هم جدا می‌کند) را حذف می‌کند.

کار شما این است که نوار را به عنوان یک جریان ورودی سفارشی Factor بسازید.

## 1. نوار را تعریف کنید

یک تاپل `tape` تعریف کنید که از `disposable` ارث‌بری می‌کند و یک اسلات به نام `wire` برای جریان ورودی زیربنایی در خود نگه می‌دارد.

```factor
TUPLE: tape < disposable wire ;
```

سپس سازنده‌ی `<tape> ( wire -- tape )` را بنویسید. از `new-disposable` (نه `new`) استفاده کنید تا چارچوب تخریب‌گر نوار را ثبت کند، و جریان زیربنایی را در اسلات `wire` ذخیره کنید.

## 2. به میکسین input-stream بپیوندید

`tape` را به عنوان یک `input-stream` اعلام کنید:

```factor
INSTANCE: tape input-stream
```

این کار باعث می‌شود ترکیب‌گرهای پیش‌فرض پروتکل به کلاس شما فرستاده شوند.

## 3. یک نماد مورس را بخوانید

`M: tape stream-read1 ( tape -- elt/f )` را پیاده‌سازی کنید. بایت‌هایی را از سیم زیربنایی بخوانید تا به یکی از `CHAR: .`، `CHAR: -` یا `CHAR: \s` (فاصله) برسید. همان بایت را برگردانید. اگر سیم `f` را برگرداند (پایان جریان)، شما هم `f` را برگردانید؛ کار نوار تمام است.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. نوع عنصر را واگذار کنید

`M: tape stream-element-type ( tape -- type )` را با واگذاری به سیم پیاده‌سازی کنید؛ نوار نوع عناصری که خوانده می‌شوند را تغییر نمی‌دهد.

## 5. پاک‌سازی کنید

`M: tape dispose* ( tape -- )` را پیاده‌سازی کنید. چارچوب متد شما را دقیقاً یک بار به ازای هر `dispose` فراخوانی می‌کند؛ فقط سیم زیربنایی را آزادسازی کنید.

با آماده بودن این پنج قطعه، نوار مانند یک جریان ورودی معمولی کار می‌کند؛ `with-input-stream`، `stream-read` و دیگر واژه‌های پروتکل همگی به‌طور خودکار به متدهای شما فرستاده می‌شوند.
