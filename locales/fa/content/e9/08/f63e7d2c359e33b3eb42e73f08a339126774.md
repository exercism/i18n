# درباره

- نوع [باینری][binary] گونه‌ای تخصصی از نوع [بیت‌استرینگ][bitstring] است.
- باینری از [بایت‌ها][wiki-byte] تشکیل شده است.
  - بایت از ۸ [بیت][wiki-bit] تشکیل شده است.
  - بایت می‌تواند اعدادی از `0` تا `255` را نمایش دهد
  - مقادیر صحیح [هگزادسیمال][wiki-hexadecimal] هنگام کار با بایت رایج‌اند: از `0x00` تا `0xFF`.
- لیترال‌های باینری با استفاده از [فرم ویژه‌ی `<<>>`][special-form] تعریف می‌شوند.
  - اگر برای یک بایت از عددی بزرگ‌تر از `255` استفاده کنید، فقط ۸ بیت آخر به کار می‌رود، مگر اینکه [واحد و/یا اندازه‌ی مورد استفاده][bin-size] را با عملگر [`::`][type-operator] مشخص کنید.
- از [`<>/2`][bin-concat] می‌توان برای الحاق بیت‌استرینگ‌ها، باینری‌ها و رشته‌ها استفاده کرد.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

_بایت تهی_ نام دیگری برای `<<0>>` است.

## رشته‌ها داده‌ی باینری کدگذاری‌شده‌اند

- رشته‌ها داده‌ی باینری کدگذاری‌شده در قالب [UTF-8][wiki-utf8] هستند.
  - آن‌ها در قطعه‌های ۸ بیتی (یک‌بایتی) کدگذاری می‌شوند و برای نمایش بیش از ۲۵۵ نویسه، تا ۴ بایت به کار می‌برند.
  - [طول یک رشته][string-length] ممکن است با [اندازه‌ی بایتی][byte-size] آن یکسان نباشد.

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## تطبیق الگو روی داده‌ی باینری

- باینری را می‌توان [به‌صورت یک کل یا با استفاده از فرم ویژه تطبیق داد][special-form] تا فقط یک بخش مطابقت داده شود.
  - فقط بخش آخر در یک تطبیق الگو می‌تواند اندازه‌ی متغیر داشته باشد.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

این کار برای رشته‌ها هم انجام می‌شود:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
