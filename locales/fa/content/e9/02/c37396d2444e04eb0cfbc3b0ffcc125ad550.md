# راهنمایی‌ها

## 1. تعریف انواع `Usd`، `Eur` و `Jpy`

- انواع `Usd`، `Eur` و `Jpy` را می‌توان بدون سازنده‌ها و با نحوه‌ی نگارش `pub type TypeName` تعریف کرد.

## 2. تعریف نوع `Money`

- نوع `Money` باید یک پارامتر نوع فانتوم برای واحد پول داشته باشد.

## 3. تعریف توابع `dollar`، `euro` و `yen`

- حاشیه‌نویسی نوع بازگشتی توابع `dollar`، `euro` و `yen` باید `Money(currency)` باشد، که در آن `currency` پارامتر نوع مناسب نوع `Money` است.

## 4. تعریف تابع `total`

- حاشیه‌نویسی نوع بازگشتی تابع `total` باید از همان پارامتر نوعی استفاده کند که آرگومان دارد.
