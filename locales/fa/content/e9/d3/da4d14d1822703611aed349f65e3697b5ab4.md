# مقدمه

برای آشنایی با مبانی آرگومان‌های تابع، به [مفهوم تابع][function concept] مراجعه کنید.

## اسم پارامتر

[اسم پارامتر][parameters]، مثل اسم متغیر، باید با یک حرف یا زیرخط شروع شود و می‌تواند شامل حروف، زیرخط یا اعداد باشد.
اسم پارامتر نباید شامل فاصله یا علامت نگارشی باشد.


## آرگومان‌های موقعیتی

آرگومان‌های موقعیتی مقادیری هستند که به تابع فرستاده می‌شوند، به همان ترتیبی که پارامترهای متناظر با آن‌ها آمده‌اند.
می‌توان آن‌ها را به‌صورت اختیاری با استفاده از اسم پارامترشان هم فرستاد:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

فراخوانی اول `concat` آرگومان‌ها را بر اساس موقعیت می‌فرستد.
فراخوانی دوم `concat` آرگومان‌ها را بر اساس _اسم_ می‌فرستد و این امکان را می‌دهد که موقعیت آن‌ها تغییر کند.

توجه کنید که آرگومان‌های موقعیتی نمی‌توانند بعد از آرگومان‌هایی بیایند که با اسم فرستاده شده‌اند (_که به آن‌ها [آرگومان‌های کلیدواژه‌ای][keyword-arguments] هم می‌گویند. **نه** اینکه با پارامترهای موقعیتی متغیر یا [**kwargs][kwargs]** اشتباه گرفته شوند_).

این مجموعه از آرگومان‌ها:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

منجر به این خطا می‌شود:

```
SyntaxError: positional argument follows keyword argument
```

## مقادیر پیش‌فرض آرگومان

[مقادیر پیش‌فرض][default arguments] برای یک یا چند آرگومان را می‌توان در فهرست پارامترها تعیین کرد.
این کار اجازه می‌دهد در صورت نیاز تابع را با آرگومان‌های _کمتری_ فراخوانی کنید.
می‌توان مقادیر پیش‌فرض را با فراخوانی تابع با آرگومان‌های جدید به‌جای مقادیر پیش‌فرض بازنویسی کرد:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## آرگومان‌های کلیدواژه‌ای

آرگومان‌های کلیدواژه‌ای هنگام فرستادن آرگومان‌ها به تابع از اسم پارامتر استفاده می‌کنند.
می‌توان به‌صورت اختیاری آن‌ها را بر اساس موقعیت هم مشخص کرد:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
