این تمرین ترد را معرفی می‌کند تا بررسی شود که حساب بانکی شما در برابر عملیات همزمان چقدر مقاوم است. چند منبع برای مطالعه درباره‌ی ترد در Tcl:

* [مدل ترد در Tcl](https://www.tcl.tk/doc/howto/thread_model.html)
* [ترد به شکل درست… با Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [اسکریپت‌های چندتردی Tcl](http://www.beedub.com/book/4th/Threads.pdf)،
  فصلی از کتاب _Practical Programming in Tcl and Tk, 4th Ed._،
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)

* [دستورهای بسته‌ی Thread](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) از مستندات Tcl.

## نصب

برخی توزیع‌های Tcl به‌طور پیش‌فرض بسته‌ی Thread را همراه ندارند: ممکن است لازم باشد جداگانه نصب شود.
برای بررسی، دستور زیر را اجرا کنید:
```bash
$ echo 'package require Thread' | tclsh
```
اگر این دستور _هیچ خروجی‌ای_ تولید نکند، یعنی بسته‌ی Thread از قبل نصب شده است.

در صورت نیاز، دستور `apt install tcl-thread` (یا `dnf install tcl-thread`) را اجرا کنید.
