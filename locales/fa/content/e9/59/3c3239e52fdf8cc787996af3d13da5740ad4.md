# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | ورودی     | عدد صحیح | اندیس عدد اول                |
| `$v0`    | خروجی     | عدد صحیح | مقدار عدد اولِ nاُم            |
| `$t0-9`  | موقت | هر نوع     | برای ذخیره‌سازی موقت استفاده می‌شود |
