# Tests

برای اجرای تست‌های ارائه‌شده، به gem Minitest نیاز دارید. یک پنجره‌ی ترمینال باز کنید و برای نصب Minitest دستور زیر را اجرا کنید:

```
gem install minitest
```


تست‌ها را از پوشه‌ی تمرین با دستور زیر اجرا کنید:

```
ruby <snake-case-exercise>_test.rb
```

لطفاً `<snake-case-exercise>` را با اسم تمرین خودتان در قالب snake_case جایگزین کنید.

## خروجی رنگی

می‌توانید `require 'minitest/pride'` را اجرا کنید یا برای گرفتن خروجی رنگی دستور زیر را اجرا کنید:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
