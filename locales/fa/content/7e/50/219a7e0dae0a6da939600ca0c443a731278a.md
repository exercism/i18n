# دستورالعمل‌ها

شما یک پرنده‌نگر پرشور هستید که پیگیری می‌کنید در هفت روز گذشته چند پرنده به باغ شما سر زده‌اند.

شش وظیفه دارید که همه‌شان به تعداد پرندگانی مربوط می‌شوند که به باغ شما سر زده‌اند.

## 1. بررسی کنید امروز چند پرنده سر زده‌اند

تابع `today()` را پیاده‌سازی کنید تا برگرداند چند پرنده امروز به باغ شما سر زده‌اند. شمارش پرندگان بر اساس روز مرتب شده است؛ اولین عنصر شمارش قدیمی‌ترین روز است و آخرین عنصر شمارش امروز.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. شمارش امروز را یک واحد افزایش دهید

تابع `increment_todays_count()` را پیاده‌سازی کنید تا شمارش امروز را یک واحد افزایش دهد:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. بررسی کنید آیا روزی بوده که هیچ پرنده‌ای سر نزده باشد

تابع `has_day_without_birds()` را پیاده‌سازی کنید که اگر روزی بوده که هیچ پرنده‌ای به باغ سر نزده باشد مقدار `TRUE` را برمی‌گرداند؛ در غیر این صورت مقدار `FALSE` را برگردانید:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. تعداد پرندگان بازدیدکننده را برای چند روز اول محاسبه کنید

تابع `count_for_first_days()` را پیاده‌سازی کنید که تعداد پرندگانی را برمی‌گرداند که از ابتدای هفته به باغ شما سر زده‌اند، اما شمارش را به تعداد روزهای مشخص‌شده از ابتدای هفته محدود می‌کند.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. تعداد روزهای پرمشغله را محاسبه کنید

بعضی روزها پرمشغله‌تر از بقیه‌اند. روز پرمشغله روزی است که پنج پرنده یا بیشتر به باغ شما سر زده باشند.
تابع `busy_days()` را پیاده‌سازی کنید تا تعداد روزهای پرمشغله را برگرداند:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. مجموع تجمعی بازدید پرندگان در هفته‌ی گذشته را محاسبه کنید

کنجکاو هستید که بدانید در مجموع چند پرنده تا اینجای هفته سر زده‌اند.
برای هر روز مجموع تجمعی را محاسبه کنید.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. نام روزها را بر اساس میزان پرمشغله بودنشان مرتب کنید

شما گمان می‌کنید بازدید پرندگان تحت تأثیر الگوهای ترافیک جاده‌های نزدیک است، بنابراین آخر هفته با روزهای کاری فرق می‌کند.

مخفف نام روزها را بر اساس تعداد پرندگانی که بازدید کرده‌اند، به ترتیب _نزولی_ مرتب کنید.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
