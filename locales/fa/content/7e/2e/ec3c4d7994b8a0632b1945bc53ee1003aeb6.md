# مقدمه‌ای بر حلقه‌ی For-Each

[حلقه‌ی For-Each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) سازوکاری فراهم می‌کند که برای هر عنصر در یک «مجموعه»، یک «بلوک کد» را اجرا کند.
برخی مستندات (مثلاً مستندات Oracle) این‌ها را «حلقه‌های For تقویت‌شده» می‌نامند.

نحوه‌ی نگارش کلی به این صورت است:

```java
for(declaration: collection) {
    body;
}
```

‏`declaration` متغیری را اعلان می‌کند که مقدارهای تخصیص‌یافته از مجموعه را در خود نگه می‌دارد.

‏`collection` یک آرایه یا مجموعه است که مقدارهایی را در خود نگه می‌دارد که به متغیر حلقه تخصیص داده می‌شوند.

‏`body` شامل دستوراتی است که برای هر مقدار در مجموعه یک بار اجرا می‌شوند.

برای مثال:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

که خروجی زیر را می‌دهد:

```text
a
e
i
o
u
```

به‌طور کلی، حلقه‌ی `for-each` به دلایل زیر بر حلقه‌ی `for` ترجیح دارد:

- حلقه‌ی `for-each` تضمین می‌کند که روی _همه‌ی_ مقادیر پیمایش شود.
- حلقه‌ی `for-each` _اعلانی‌تر_ است، یعنی کد بیان می‌کند که _چه کاری_ انجام می‌دهد، نه _چگونه_ آن را انجام می‌دهد.
- حلقه‌ی `for-each` جا برای خطا نمی‌گذارد، در حالی که در حلقه‌های `for` به‌راحتی ممکن است خطای یک واحد رخ دهد (به استفاده از `<` در مقابل `<=` فکر کنید).
- حلقه‌ی `for-each` روی همه‌ی انواع مجموعه کار می‌کند، از جمله انواعی که دسترسی به عناصر با اندیس را پشتیبانی نمی‌کنند (مثلاً `Set`).
