# مقدمه

در JavaScript، «رشته‌های قالبی» به شما امکان می‌دهند عبارت‌هایی را درون رشته‌ها جای دهید؛ به این کار درون‌گذاری رشته هم می‌گویند.
این قابلیت، کارکرد شیء سراسری توکار [`String`][string-reference] را گسترش می‌دهد.

برای ساختن رشته‌های قالبی در JavaScript کافی است متن را بین دو بک‌تیک قرار دهید.
این رشته‌ها نه تنها اجازه می‌دهند متن خطوط جدید و کاراکترهای خاص دیگری داشته باشد، بلکه می‌توانید متغیرها و عبارت‌های دیگر را هم درونشان درج کنید.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

در مثال بالا، از بک‌تیک‌ها (<code>\`\`</code>) برای نمایش یک رشته‌ی قالبی استفاده شده است. `${...}` جانگه‌داری است که برای جایگذاری به کار می‌رود.
هر نوع غیر رشته‌ای _به‌صورت ضمنی_ به رشته تبدیل می‌شود.
این موضوع در مفهوم [تبدیل نوع][type-conversion-concept] بررسی شده است.
از همه‌ی انواع عبارت می‌توان در رشته‌های قالبی استفاده کرد.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

وقتی می‌خواهید رشته‌ها در چند خط قالب‌بندی شوند:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

با توانایی‌های جایگذاری موجود، می‌توانید منطق را هم وارد این فرایند کنید تا مشخص شود رشته‌ی خروجی چه باید باشد.
یکی از راه‌های پیاده‌سازی این منطق، استفاده از [عملگر سه‌تایی][ternary-operator] است.
این کار همان کارکرد شرطی `if/else` را در قالبی کمی متفاوت در اختیارتان می‌گذارد.

برای وارد کردن منطق در نحوه‌ی نگارش رشته‌های قالبی:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
