# دستورالعمل‌ها

الیس، جادوگرِ آینده، به تمرین‌هایش ادامه می‌دهد. چند دسته کارت به او داده می‌شود که برای اجرای تردستی‌هایش به آن‌ها نیاز دارد.
برای اینکه کار کمی ساده‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

در این تمرین، از متدهای توکار برای تحلیل محتوای یک بردار استفاده کنید.

## 1. تعیین کنید که آیا کارتی وجود دارد

الیس می‌خواهد تعیین کند که آیا کارتی در دسته وجود دارد؛ به عبارت دیگر، آیا دسته شامل یک عدد مشخص است یا نه.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. موقعیت یک کارت را پیدا کنید

الیس می‌خواهد موقعیت (اندیس) یک کارت در دسته را بداند. 
اگر کارت در دسته نباشد، `-1` را برگردانید.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. تعیین کنید که آیا هر کارت زوج است

الیس می‌خواهد بداند که آیا همه‌ی کارت‌ها زوج هستند؛ به عبارت دیگر، آیا هر عدد در دسته یک عدد زوج است.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. بررسی کنید که آیا دسته کارتی با مقدار فرد دارد

الیس می‌خواهد بداند که آیا عددی فرد در دسته وجود دارد.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. اولین کارت فرد را از دسته بگیرید

الیس می‌خواهد مقدار اولین کارت فرد را بداند.  
اگر کارت فردی در دسته نباشد، `-1` را برگردانید.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. موقعیت اولین کارت زوج را تعیین کنید

الیس می‌خواهد موقعیت اولین کارت زوج را بداند.
اگر کارت زوجی در دسته نباشد، `-1` را برگردانید.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
