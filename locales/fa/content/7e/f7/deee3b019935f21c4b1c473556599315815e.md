# تابع در `jq`

می‌توانید در `jq` **توابع سفارشی** خودتان را تعریف کنید تا هر منطقی که لازم دارید را در آن بگنجانید.
_تابع‌ها_ دقیقاً مثل توابع توکار عمل می‌کنند: یک ورودی می‌گیرند و صفر، یک یا چند خروجی تولید می‌کنند.

## تعریف یک تابع

می‌توانید یک _تابع_ `jq` را با نحوه‌ی نگارش زیر تعریف کنید:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- با کلیدواژه‌ی `def` شروع می‌شود،
- پیش از بدنه‌ی تابع یک دونقطه می‌آید،
- بدنه از یک عبارت واحد تشکیل شده است،
- با یک نقطه‌ویرگول پایان می‌یابد،
- مانند بقیه‌ی نحوه‌ی نگارش `jq`، می‌توانید برای خوانایی از فاصله‌های دلخواه استفاده کنید.

## توابع را کجا قرار دهیم

_تابع‌ها_ باید پیش از استفاده تعریف شوند؛ این یک خطا است:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

این یعنی باید _تابع‌ها_ را در بالای کد `jq` خود، پیش از عبارت «اصلی»، قرار دهید.

### توابع تودرتو

_تابع‌ها_ می‌توانند تودرتو باشند:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

در اینجا، _تابع_ `B` فقط در بدنه‌ی `A` قابل مشاهده است.

## محدوده

یک _تابع_ یک **محدوده**ی جدید برای متغیرها و توابع تودرتو ایجاد می‌کند.

## آرگومان

**آرگومان‌های** _تابع_ با _نقطه‌ویرگول_ از هم جدا می‌شوند، نه با کاما.
برای نمونه، _تابعی_ که یک عدد می‌گیرد و بعد عددی به آن می‌افزاید و در عددی ضرب می‌کند:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

### آرگومان‌ها _عبارت_ هستند

_آرگومان‌های_ تابع، فیلتر هستند، نه مقدار.
از این نظر، مثل چیزی عمل می‌کنند که زبان‌های دیگر آن را «کالبک» می‌نامند:

با استفاده از تابع `add_mul` به‌عنوان نمونه:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

اینجا چه اتفاقی می‌افتد؟

- آرگومان `adder` _عبارت_ `. + 5` را دریافت می‌کند
  - وقتی تابع `. + adder` را انجام می‌دهد، به `. + . + 5` تبدیل می‌شود
  - و چون `. == 10`، نتیجه ۲۵ می‌شود
- به همین ترتیب، آرگومان `multiplier` عبارت `. - 2` است
  - که نتیجه‌اش ۸ می‌شود
  - و بعد نتیجه `25 * 8 == 200` است

### آرگومان به‌عنوان مقدار

گاهی می‌خواهید یک _آرگومان_ را به یک متغیر «تبدیل» کنید:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

یک میانبر برای این کار وجود دارد:

```jq
def my_func($arg):
    other stuff ...
;
```

توجه کنید که این صرفاً یک میانبر نگارشی است: نام `arg` بدون `$` همچنان درون _تابع_ در محدوده است.

## تعداد آرگومان

_تابع‌ها_ یک **تعداد آرگومان** دارند، یعنی شمار _آرگومان‌هایی_ که می‌گیرند.

_تابع‌ها_ می‌توانند با تعداد آرگومان‌های متفاوت، نام یکسان داشته باشند.
تابع توکار [`range`][man-range] این را نشان می‌دهد: `range/1`، `range/2` و `range/3` همگی کنار هم وجود دارند.

این می‌تواند برای تعریف توابع بازگشتی که وضعیت را از طریق آرگومان‌ها با خود حمل می‌کنند مفید باشد.
برای نمونه، `map` _می‌تواند_ این‌طور پیاده‌سازی شود:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## بازگشت

`jq` بهینه‌سازی فراخوانی پایانی را انجام می‌دهد، اما فقط برای توابعی با تعداد آرگومان صفر.

## ماژول

«ماژول» `jq` فایلی است که فقط شامل توابع است.
ماژول‌ها با دستورهای [`include`][man-include] یا [`import`][man-import] به یک برنامه‌ی jq وارد می‌شوند.
