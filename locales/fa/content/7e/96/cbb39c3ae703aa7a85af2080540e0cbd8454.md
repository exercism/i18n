# مقدمه

## آرایه و وکتور

C++ برای ذخیره‌ی عنصرهایی از یک نوع به شکلی مرتب، ظرف‌های مختلفی ارائه می‌دهد.
`std::array` برای ظرف‌هایی با اندازه‌ی ثابت وجود دارد و `std::vector` هم قابلیت تغییر اندازه‌ی پویا را به همراه دارد.

### ساخت

وقتی آرایه یا وکتوری اعلان می‌کنید، باید نوع عنصرهایی را که آن ظرف نگه می‌دارد مشخص کنید.
آرایه‌ها به اندازه هم نیاز دارند.
به این مثال‌ها نگاه کنید تا مقداردهی اولیه‌ی این دو نوع ظرف را ببینید:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

وکتورها معمولاً به فضای بیشتری نیاز دارند، چون برای رشد بیشتر حافظه تخصیص می‌دهند.
لازم نیست اندازه را مشخص کنید:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> توجه: لازم نیست هنوز سازوکار دقیق پشت مفهوم `template` را بدانید؛ این مفهوم در ادامه‌ی درخت برنامه‌ی درسی، مفهوم مستقل خودش را خواهد داشت.

### دسترسی به عنصر

وکتورها و آرایه‌ها برای دسترسی به عناصرشان از توابع یکسانی استفاده می‌کنند.
می‌توانید از توابع عضو `front` و `back` برای گرفتن اولین و آخرین عنصر ظرف استفاده کنید.
همچنین `at` و عملگر `[]` برای دسترسی به عنصرهای مشخص وجود دارد.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> توجه: اگر موقعیتی را انتخاب کنید که در محدوده‌ی ظرف شما نباشد، `[]` ممکن است به رفتار تعریف‌نشده منجر شود.
> تابع `at` یک استثنا ایجاد می‌کند که در بلندمدت ممکن است کارتان را راحت‌تر کند.

### تغییردهنده‌های وکتور

از آنجا که اندازه‌ی یک `vector` ثابت نیست، می‌توان عنصر اضافه یا حذف کرد.
دو تابع رایج برای این کار `emplace_back` و `pop_back` هستند.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### ظرفیت

می‌توانید خالی بودن ظرف‌ها را با تابع عضو `empty` بررسی کنید.
اگر می‌خواهید تعداد عنصرها را بدانید، می‌توانید از `size` استفاده کنید.
