# مقدمه

Ruby همراه با یک کتابخانه‌ی استاندارد (که اغلب به «stdlib» کوتاه می‌شود) ارائه می‌شود؛ مجموعه‌ای از کلاس‌ها برای کار با مواردی مانند تاریخ‌ها، JSON و شبکه.
همچنین قابلیت‌های مفیدی فراهم می‌کند که کار با کد شما را آسان‌تر می‌کند.

`OpenStruct` بخشی از کتابخانه‌ی استاندارد است و به شما اجازه می‌دهد به راحتی از یک `Hash` یک شیء بسازید.
به جای اینکه مجبور باشید با کلیدهای `Hash` به مقادیر دسترسی داشته باشید، `OpenStruct` به شما اجازه می‌دهد برای دسترسی و تنظیم مقادیر از متدها استفاده کنید.

وقتی از کلاس‌های کتابخانه‌ی استاندارد، یا هر کتابخانه‌ی دیگری استفاده می‌کنید، باید آن کلاس را با استفاده از متد `require` بارگذاری کنید.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

یک مزیت اضافی این است که می‌توانید هنگام استفاده از نحوه‌ی نگارش بلوک از یک میانبر بهره ببرید.
در موقعیت‌هایی که یک بلوک فقط یک متد را فراخوانی می‌کند، می‌توانید بلوک را با `&:` که پس از آن اسم متد می‌آید جایگزین کنید.
برای مثال، این دو خط هم‌معنی هستند:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
