# مقدمه

R نوع داده‌ای جداگانه به اسم «مجموعه» ندارد و به‌جای آن، از توابع گوناگونی برای انجام عملیات مشابه روی بردارها استفاده می‌کند.

عملگر `%in%` عضویت در مجموعه را بررسی می‌کند.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

توابع مرتبط عبارت‌اند از `unique` (برای حذف مقادیر تکراری)، به‌علاوه‌ی `union()`، `intersect()`، `setdiff()` و `setequal()` که روی جفت‌های مجموعه کار می‌کنند.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

در هر حالت، `set_1` و `set_2` بدون تغییر می‌مانند.
