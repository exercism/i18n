# `def` با `is_`

[comment]: # (به دو پارامتر نیاز دارد:)
[comment]: # (- expected: نام اصلاح‌شده)
[comment]: # (- actual: نام نادرستی که دانشجو به کار برده است)

Elixir قراردادهای نام‌گذاری مشخصی دارد که شامل نحوه‌ی نام‌گذاری [توابعی که مقدار منطقی برمی‌گردانند](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) است:

> توابعی که مقدار منطقی برمی‌گردانند، با یک علامت سؤال در انتهای نامشان نام‌گذاری می‌شوند.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

توجه کنید که گاردها، برخی توابع و ماکروهای توکار که مقدار منطقی برمی‌گردانند و در گاردها معتبرند، از قرارداد دیگری پیروی می‌کنند و با پیشوند `is_` نام‌گذاری می‌شوند (`def is_integer`، `defguard is_foo`، `defmacro is_foo`). این دو قرارداد نباید با هم مخلوط شوند.
