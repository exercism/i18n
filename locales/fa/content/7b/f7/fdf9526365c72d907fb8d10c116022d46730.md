# پیوست دستورالعمل‌ها

## راهنمایی‌ها

باید تابع `recite` را پیاده‌سازی کنید که متن ترانه‌ی «The Twelve Days of Christmas» را تولید می‌کند. اگر درباره‌ی نوع‌ها مطمئن نیستید می‌توانید از امضای ارائه‌شده استفاده کنید، اما نگذارید خلاقیت شما را محدود کند.

این تمرین با داده‌های متنی کار می‌کند. به دلایل تاریخی، نوع `String` در Haskell با `[Char]`، یعنی فهرستی از نویسه‌ها، هم‌معناست. برای پردازش کارآمدتر داده‌های متنی می‌توان از نوع `Text` استفاده کرد.

به‌عنوان یک گسترش اختیاری برای این تمرین، می‌توانید

- درباره‌ی [نوع‌های رشته](https://haskell-lang.org/tutorial/string-types) در Haskell بخوانید.
- عبارت `- text` را به فهرست وابستگی‌هایتان در package.yaml اضافه کنید.
- `Data.Text` را [به این شکل](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) وارد کنید:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- مثلاً `recite :: Int -> Int -> [Text]` را بنویسید و مثلاً با `T.pack` به ترکیب‌کننده‌های `Data.Text` ارجاع دهید.
- مستندات [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) را ببینید.
- همه‌ی موارد `String` را در TwelveDays.hs با `Text` جایگزین کنید، یعنی:

```haskell
recite :: Int -> Int -> [Text]
```

این بخش کاملاً اختیاری است.
