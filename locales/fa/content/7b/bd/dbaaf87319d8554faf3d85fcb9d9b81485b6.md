# مقدمه

Cairo نوع بومی‌ای برای رشته‌ها ندارد، اما دو راه برای کار با آن‌ها در اختیار می‌گذارد: رشته‌های کوتاه با کوتیشن‌های ساده و `ByteArray` با کوتیشن‌های دوگانه.

یک رشته‌ی کوتاه، رشته‌ای ASCII است که هر کاراکترش روی یک بایت کدگذاری می‌شود.

نوعی که Cairo به‌طور پیش‌فرض برای رشته‌های کوتاه استفاده می‌کند `felt252` است و همین باعث می‌شود حداکثر طول آن‌ها فقط ۳۱ کاراکتر باشد.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

از نظر فنی، هر نوع عدد صحیحی که کوچک‌تر از `felt252` باشد را می‌توان با قالب رشته‌ی کوتاه نمایش داد.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

برای رشته‌های بلندتر از ۳۱ کاراکتر، Cairo نوع `ByteArray` را فراهم می‌کند که طولی نامحدود دارد.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

`ByteArray`ها را می‌توان با عملگر `+` به هم چسباند:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

بعضی کاراکترهای خاص باید با یک بک‌اسلش در ابتدا escape شوند؛ مثل `\t` برای تب و `\n` برای خط جدید در رشته‌ها.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

حتی می‌توانید با استفاده از ایندکس، به تک‌تک بایت‌های یک `ByteArray` دسترسی داشته باشید.

اما حواستان باشد، نوع بایت برگردانده‌شده `u8` است، نه `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

کتابخانه‌ی اصلی متدها و عملگرهای مفید زیادی برای کار با `ByteArray`ها در اختیار می‌گذارد.

برای اطلاعات بیشتر درباره‌ی متدهای `ByteArray`، مستندات [`ByteArrayTrait`][docs] را ببینید.

چند نمونه در ادامه می‌آید:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
