# پیوست دستورالعمل‌ها

## پیام‌های استثنا

گاهی لازم است [استثنایی ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، باید همیشه یک **پیام خطای معنادار** بنویسید که منبع خطا را نشان دهد. این کار code شما را خواناتر می‌کند و به میزان چشمگیری به debug کردن کمک می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا از نوع مشخصی خواهد بود، می‌توانید یکی از [انواع خطای توکار](https://docs.python.org/3/library/exceptions.html#base-classes) را `raise` کنید، اما همچنان باید پیام معناداری هم همراه آن بیاورید.

این تمرین به‌طور خاص از شما می‌خواهد که از [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) استفاده کنید تا اگر به کلاس `Tree()` درختی داده شود که نمی‌توان دوباره جهت‌دهی‌اش کرد، یا مسیری بین یک `start node` و یک `end node` پیدا نشود، چندین `ValueErrors` را «پرتاب» کنید.
tests تنها در صورتی قبول می‌شوند که هم نوع `exception` مورد انتظار را `raise` کنید و هم پیام مورد انتظار را همراه آن بیاورید.

لطفاً tests و نتایج مورد انتظارشان را با دقت بررسی کنید.
