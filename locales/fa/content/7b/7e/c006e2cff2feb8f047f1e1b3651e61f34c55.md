# دستورالعمل

با داشتن فهرستی از عامل‌ها و یک حد، همه‌ی مضرب‌های یکتای آن عامل‌ها را که کمتر از حد هستند با هم جمع کنید.
همه‌ی ورودی‌ها بزرگ‌تر یا مساوی صفر خواهند بود.

## مثال

فرض کنید حد برابر ۲۰ است و فهرست عامل‌ها [۳، ۵] است.
باید مجموع همه‌ی مضرب‌های یکتای ۳ و ۵ را که کمتر از ۲۰ هستند پیدا کنیم.

مضرب‌های ۳ که کمتر از ۲۰ هستند: ۳، ۶، ۹، ۱۲، ۱۵، ۱۸
مضرب‌های ۵ که کمتر از ۲۰ هستند: ۵، ۱۰، ۱۵

مضرب‌های یکتا عبارت‌اند از: ۳، ۵، ۶، ۹، ۱۰، ۱۲، ۱۵، ۱۸

مجموع مضرب‌های یکتا برابر است با: ۳ + ۵ + ۶ + ۹ + ۱۰ + ۱۲ + ۱۵ + ۱۸ = ۷۸

بنابراین، پاسخ ۷۸ است.
