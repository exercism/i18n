# مقدمه

«انواع سفارشی» در Gleam روشی است برای تعریف نوع‌های داده‌ی جدید. هر نوع سفارشی می‌تواند چندین _گونه_ داشته باشد که هر کدام اسم خودشان را دارند.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

هر گونه از یک نوع سفارشی می‌تواند به‌صورت اختیاری مقداری داده نگه دارد، و گونه‌های مختلف می‌توانند انواع مختلفی از داده را نگه دارند. وقتی یک گونه داده نگه می‌دارد، به آن _رکورد_ می‌گویند.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

ساختن یک مقدار برای یک گونه‌ی خاص، اگر آن گونه داده‌ی اضافی نداشته باشد، با ارجاع به اسم آن انجام می‌شود (`Spring`)، و اگر داشته باشد، با فراخوانی آن به عنوان یک تابع (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

انواع سفارشی، مانند همه‌ی موارد دیگر در Gleam، «برابری ساختاری» دارند، یعنی دو مقدار از یک گونه‌ی یکسان و با داده‌ی یکسان، معادل هستند.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

گونه‌های نوع سفارشی را می‌توان با استفاده از عبارت‌های `case` تطبیق الگو کرد.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
