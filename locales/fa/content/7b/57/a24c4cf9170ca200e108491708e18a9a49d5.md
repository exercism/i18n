# دستورالعمل‌ها

اعلیحضرت میزبان یک ضیافت شام در پایتخت [اتحادیه‌ی کالمار][kalmar_union]، کپنهاگ هستند.
این بزرگ‌ترین مهمانی سال است و همه‌ی اشراف دعوت شده‌اند.
اما شایعاتی در سراسر کشور پخش می‌شود که توطئه‌ای برای مسموم کردن اعلیحضرت وجود دارد.

اعلیحضرت از شما، یابنده‌ی زهر سلطنتی، خواسته‌اند تا بفهمید آیا غذایی یا نوشیدنی‌ای مسموم است.
اعلیحضرت قصد دارند فقط **Mushroom pasties** را به‌عنوان غذا سرو کنند، اما برای نوشیدنی‌ها، انواع مختلفی وجود دارد.

## 1. بررسی درست بودن غذا

اگر غذا همان چیزی نباشد که اعلیحضرت سفارش داده‌اند، احتمال زیادی هست که مسموم باشد.
اگر غذا همان چیزی نباشد که اعلیحضرت سفارش داده‌اند، باید دور انداخته شود.

متد `check_food?` را پیاده‌سازی کنید، که آرگومان `food` را می‌گیرد و اسم غذا را به‌صورت یک `String` نگه می‌دارد.
متد باید اگر غذا `Mushroom pasties` بود، غذا را برگرداند؛ در غیر این صورت، باید `nil` را برگرداند.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. بررسی مسموم بودن نوشیدنی

ممکن است نوشیدنی مسموم باشد، اما تشخیص آن کمی دشوارتر است.
نوشیدنی مسموم است اگر اسم آن حرف `i` را **نداشته باشد**؛ بزرگ یا کوچک بودن حرف مهم نیست.
اگر نوشیدنی مسموم باشد، باید دور انداخته شود.

متد `check_drink?` را پیاده‌سازی کنید، که آرگومان `drink` را می‌گیرد و اسم نوشیدنی را به‌صورت یک `String` نگه می‌دارد.
متد باید اگر نوشیدنی مسموم نبود، نوشیدنی را برگرداند؛ در غیر این صورت، باید `nil` را برگرداند.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. جایگزینی نوشیدنی

اعلیحضرت نمی‌خواهند مهمان‌هایشان را درباره‌ی زهر در غذایشان نگران کنند.
بنابراین، اگر نوشیدنی مسموم باشد، باید با یک نوشیدنی جدید، به‌طور مشخص **Apple juice**، جایگزین شود.

متد `replace_drink` را پیاده‌سازی کنید، که آرگومان `drink` را می‌گیرد و اسم نوشیدنی را به‌صورت یک `String` نگه می‌دارد.
متد باید اگر نوشیدنی مسموم نبود، نوشیدنی را برگرداند؛ در غیر این صورت، باید `"Apple juice"` را برگرداند.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
