# درباره

آرایه‌ها نوع دنباله‌ی طول‌ثابت در Factor هستند: می‌توانید عناصر را تغییر دهید اما نمی‌توانید طول را تغییر دهید.
لیترال‌ها از `{ … }` با فاصله‌ی سفید میان عناصر استفاده می‌کنند؛ «واژگان» `arrays` سازنده‌های کوچکی اضافه می‌کند که مقدارها را از پشته بیرون می‌کشد:

| واژه     | اثر                                 |
|----------|-------------------------------------|
| `1array` | `( a     -- { a } )`                |
| `2array` | `( a b   -- { a b } )`              |
| `3array` | `( a b c -- { a b c } )`            |
| `<array>`| `( n elt -- array )`، `n` نسخه از `elt` |
| `array?` | `( obj   -- ? )`، گزاره‌ی نوع       |

چند واژه‌ی [«پروتکل»][sequence-protocol] از `sequences` آن‌قدر زیاد همراه آرایه‌ها پیش می‌آید که ارزش دارد آن‌ها را به‌صورت یک مجموعه یاد بگیرید:

| واژه      | اثر                                                |
|-----------|-------------------------------------------------------|
| `concat`  | `( seqs -- seq )`، دنباله‌ای از دنباله‌ها را تخت می‌کند   |
| `join`    | `( seqs glue -- seq )`، با یک جداکننده تخت می‌کند     |
| `reverse` | `( seq -- newseq )`                                   |
| `index`   | `( elt seq -- i/f )`، اندیس عنصر، یا `f`              |
| `member?` | `( elt seq -- ? )`، بررسی عضویت                   |

```factor
USING: arrays sequences ;

3 4 2array .                       ! => { 3 4 }
{ { 1 2 } { 3 4 } } concat .       ! => { 1 2 3 4 }
{ 1 2 3 4 } reverse .              ! => { 4 3 2 1 }
"b" { "a" "b" "c" } index .        ! => 1
"b" { "a" "b" "c" } member? .      ! => t
```

`all-unique?` و `members` از [`sets`][sets] هم هر دنباله‌ای را می‌پذیرند؛ این زمانی به کار می‌آید که بخواهید تکراری‌های عناصر یک آرایه را حذف کنید یا وجود تکراری را بررسی کنید، بدون این‌که اول آن را به یک `hash-set` تبدیل کنید.

[sets]: https://docs.factorcode.org/content/vocab-sets.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
