# درباره

[لیست][list] یک نوع داده‌ی پایه در Haskell برای نگهداری مجموعه‌ای از مقادیر است.
لیست _تغییرناپذیر_ است، یعنی نمی‌توان آن را تغییر داد.
هر عملیاتی که یک لیست را تغییر دهد، لیست جدیدی برمی‌گرداند.
چندین تابع در prelude وجود دارد که به شما امکان کار با لیست‌ها را می‌دهد.

لیست‌ها در Haskell به‌صورت [لیست پیوندی][linked-list-wiki] پیاده‌سازی می‌شوند، نه به‌صورت آرایه‌هایی از مکان‌های پیوسته‌ی حافظه.
بنابراین، دسترسی به یک عنصر از لیست زمان خطی می‌برد و به طول لیست بستگی دارد.

لیست را می‌توان به شکل مستقیم، در نشانه‌گذاری سر-دم (که از عملگر `cons` یعنی `:` استفاده می‌کند)، یا ترکیبی از هر دو نوشت:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

از نشانه‌گذاری سر-دم می‌توان برای افزودن عنصرها به یک لیست استفاده کرد.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

افزودن عنصرها به یک لیست در حین تکرار، یک «الگوی نامناسب» به شمار می‌رود.
افزودن یک عنصر نیازمند پیمودن کل لیست و افزودن عنصر در انتهای آن است؛ بنابراین افزودن یک عنصر جدید در هر تکرار، پیمودن کل لیست را در هر تکرار لازم می‌کند.

می‌توانیم به همین نتیجه برسیم با افزودن عنصر به ابتدای لیست معکوس‌شده و سپس معکوس کردن نتیجه. افزودن به ابتدا عملیاتی سریع است و زمان ثابت می‌برد.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

چندین تابع رایج در Prelude برای لیست‌ها وجود دارد:

- تابع [`head`][head] سرِ لیست را برمی‌گرداند، یعنی اولین عنصر لیست.
- تابع [`tail`][tail] دم لیست را برمی‌گرداند، یعنی لیست _بدون_ اولین عنصر.
- تابع [`length`][length] تعداد عنصرهای لیست را برمی‌گرداند.
- تابع [`elem`][elem] یک مقدار منطقی برمی‌گرداند که نشان می‌دهد آیا آن عنصر در لیست هست یا نه.

همچنین [ماژول `Data.List`][list] نیز وجود دارد.

## انواع لیست

در Haskell، لیست‌ها **همگن** هستند.
این یعنی همه‌ی عناصر یک لیست یک نوع دارند.
اگر بخواهید عنصرهایی با نوع‌های متفاوت را در یک لیست قرار دهید، خطای نوع می‌گیرید.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

حاشیه‌نویسی نوع یک لیست `[a]` است، که در آن a نوعی است که لیست نگه می‌دارد، مثلاً `String` یا `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
