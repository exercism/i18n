# درباره

در Haxe، «استثناها» روشی ایمن برای مدیریت خطاهایی هستند که هنگام اجرای کد رخ می‌دهند. همه‌ی استثناها باید پیامی داشته باشند که خطا را توصیف می‌کند. می‌توانیم استثناها را با کلیدواژه‌ی `throw` _پرتاب_ کنیم:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

وقتی استثنایی پرتاب می‌شود، کد به دنبال بخشی می‌گردد که برای مدیریت خطا در نظر گرفته شده است. اگر چنین بخشی پیدا نشود، پیام خطا نمایش داده می‌شود و اجرای برنامه نیز متوقف می‌شود.

برای مدیریت استثناها در Haxe، از بلوک `try-catch` استفاده می‌کنیم. این دستور بلوکی از یک بلوک `try` و یک یا چند بلوک `catch` تشکیل شده است. بلوک `try` _تلاش می‌کند_ بخشی از کد را اجرا کند، در حالی که بلوک `catch` منتظر می‌ماند تا اگر استثنایی پرتاب شد آن را _بگیرد_، تا اجرا متوقف نشود. وقتی بلوک‌های `catch` استثنایی را می‌گیرند، تمام محتوای بلوک را نیز اجرا می‌کنند:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

نوع آرگومان بلوک `catch` باید حذف شود.

توجه به این نکته مهم است که استثناها باید در مواردی استفاده شوند که اتفاقی استثنایی رخ می‌دهد، خطایی که به مدیریت ویژه نیاز دارد. نباید از آن‌ها برای کنترل جریان برنامه استفاده کرد، زیرا این کار طراحی بدی تلقی می‌شود که اغلب به عملکرد ضعیف و قابلیت نگهداری پایین منجر می‌شود.
