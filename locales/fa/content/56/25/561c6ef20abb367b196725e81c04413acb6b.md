# نصب

برای دریافت دستورالعمل‌های نصب پیشنهادی برای پلتفرم خود، به [وب‌سایت رسمی Rust] مراجعه کنید.

نصب بودن زنجیره‌ی ابزار همه‌چیز نیست! پشتیبانی از محیط توسعه‌ی یکپارچه افزایش چشمگیر بهره‌وری است که بیشتر برنامه‌نویسان امروز به آن عادت کرده‌اند. اگر از Visual Studio Code استفاده می‌کنید، نگاهی به [مستندات پشتیبانی از Rust][vscode] آن بیندازید. همچنین با تمام وجود توصیه می‌کنیم که [لینت کردن با clippy][vscode-linting] را فعال کنید!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
