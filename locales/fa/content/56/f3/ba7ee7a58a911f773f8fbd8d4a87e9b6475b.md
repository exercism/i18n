# مقدمه

Common Lisp به برنامه‌نویس اجازه می‌دهد «کامنت» بنویسد، یعنی متن‌هایی که کامپیوتر نادیده‌شان می‌گیرد.

کامنت‌های تک‌خطی با یک یا چند نقطه‌ویرگول (`;`) شروع می‌شوند و گاهی ممکن است موارد زیر را ببینید:

```lisp
(code...) ; => value
```

در این حالت، کامنت برای نشان دادن مقداری به کار می‌رود که Common Lisp پس از اجرای کد آن خط برمی‌گرداند.

مرسوم است که برای کامنت کوتاه در پایان یک خط از یک نقطه‌ویرگول استفاده شود، برای کامنت بلندتر در بالای بخشی از کد از دو نقطه‌ویرگول، برای کامنت بلندی که چیزی مانند یک تابع را توصیف می‌کند از سه نقطه‌ویرگول و برای کامنتی مانند سرصفحه در بالای یک فایل منبع از چهار نقطه‌ویرگول استفاده می‌شود.
