# دستورالعمل‌ها

در این تمرین، [قواعد بازی Go](https://matmoore.github.io/learngo/) را اعمال می‌کنید. خود قواعد از قبل نوشته شده‌اند؛ شما فقط باید آن‌ها را اعمال کنید تا Game را به‌روزرسانی کنید و خطاها یا نقض قواعد را مدیریت کنید.

بازی به این صورت نمایش داده می‌شود:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

این بازی ۴ قاعده دارد:

- هر نقطه فقط می‌تواند یک سنگ داشته باشد.
- می‌توان سنگ‌های حریف را اسیر کرد.
- نمی‌توانید سنگی را در جایی بگذارید که خودش را اسیر کند.
- نمی‌توانید از یک نقطه دو بار استفاده کنید.

## 1. اعمال قواعد

محتوای تابع `apply_rules` را بنویسید؛ این تابع یک `Game` اولیه و مجموعه‌ای از قواعد را می‌گیرد و پس از اعمال قواعد، `Game` جدید را برمی‌گرداند.

سه مورد از این قواعد، نقض قواعد را بررسی می‌کنند و ممکن است خطا برگردانند، بنابراین نوع بازگشتی آن‌ها `Result(Game, String)` است. اگر هر یک از این قواعد شکست بخورد، باید بازی اصلی برگردانده شود، اما با فیلد `error` که با خطای مربوطه به‌روزرسانی شده است.

قاعده‌ی دیگر نقضی را بررسی نمی‌کند و بنابراین نمی‌تواند شکست بخورد (هرچند می‌تواند یک `Game` تغییر‌یافته برگرداند) و در نتیجه نوع بازگشتی آن `Game` است.

اگر همه‌ی قواعد موفق شوند، هر تغییری که قواعد در `Game` ایجاد کرده‌اند باید حفظ شود و بازیکن باید عوض شود.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
