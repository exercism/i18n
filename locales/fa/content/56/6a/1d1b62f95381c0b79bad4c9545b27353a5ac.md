# درباره

«عبارت‌های باقاعده» ابزاری قدرتمند برای کار با رشته‌ها در Elixir هستند. عبارت‌های باقاعده در Elixir از مشخصات **PCRE** (عبارت‌های باقاعده‌ی سازگار با Perl) پیروی می‌کنند. الگوهای رشته‌ای که معنای عبارت باقاعده را نشان می‌دهند، ابتدا کامپایل می‌شوند و سپس برای تطبیق همه یا بخشی از یک رشته استفاده می‌شوند.

در Elixir، رایج‌ترین روش برای ساخت عبارت‌های باقاعده استفاده از [سیجیل `~r`][sigils-regex] است. سیجیل‌ها میانبرهایی به سبک _شکر نحوی_ برای کارهای رایج در Elixir فراهم می‌کنند. در این مورد، `~r` میانبری برای استفاده از [`Regex.compile!/2`][regex-compile] است.

```elixir
Regex.compile!("test") == ~r/test/
# => true
```

عملگر [`=~/2`][regex-match-operator] برای انجام تطبیق یک عبارت باقاعده روی یک رشته و برگرداندن نتیجه‌ی `boolean` مفید است.

```elixir
"this is a test" =~ ~r/test/
# => true
```

## مرور نحوه‌ی نگارش عبارت‌های باقاعده

- برخی از نویسه‌ها در الگوی عبارت باقاعده معنای خاصی دارند؛ برای استفاده‌ی معمولی از نویسه باید با `\` اسکیپ شود، مثلاً `~r/\?/`.
- _کلاس‌های نویسه_ (مثلاً `\d`، `\w`) به الگوها اجازه می‌دهند با طیفی از نویسه‌ها تطبیق پیدا کنند
- _جانشین‌ها_ (`|`) به الگوها اجازه می‌دهند با یکی از چند الگو تطبیق پیدا کنند
- _کمیت‌سازها_ (`{N, M}`، `*`، `?`) به الگوها اجازه می‌دهند تعداد مشخصی از الگوهای تکرارشده را تطبیق دهند
- _گروه‌ها_ (`()`) به بخش‌هایی از الگوها اجازه می‌دهند به‌صورت یک واحد عمل کنند

## گرفتن‌ها

عبارت‌های باقاعده همچنین برای استخراج بخشی از یک رشته مفیدند. به این کار _گرفتن_ می‌گویند. برای _گرفتن_ بخشی از یک رشته، برای بخشی که می‌خواهید بگیرید یک گروه (`()`) بسازید و از [`Regex.run`][regex-run] استفاده کنید.

```elixir
Regex.run(~r/Weight: (\d*)g/, "Weight: 150g")
# => ["Weight: 150g", "150"]
```

گرفتن‌ها شماره‌گذاری می‌شوند (از ۱ شروع می‌شود) و می‌توانند در نتیجه نیز هنگام جایگزینی بخش‌هایی از یک رشته با عبارت باقاعده استفاده شوند:

```elixir
Regex.replace(~r/Weight: (\d*)g/, "Weight: 150g", "Gewicht: \\1g")
# => "Gewicht: 150g"
```

گرفتن‌ها را می‌توان با افزودن `?<name>` بعد از پرانتز باز نیز اسم‌گذاری کرد. برای گرفتن یک map با گرفتن‌هایی که اسم دارند از [`Regex.named_captures/3`][regex-named-captures] استفاده کنید.

```elixir
Regex.named_captures(~r/Weight: (?<weight>\d*)g/, "Weight: 150g")
# => %{"weight" => "150"}
```

## اصلاح‌کننده‌ها

رفتار یک عبارت باقاعده را می‌توان با افزودن پرچم‌های خاص در انتهای عبارت باقاعده تغییر داد، مثلاً `~r/test/i`.

- `caseless` `i` - حساس نبودن به بزرگی و کوچکی حروف
  ```elixir
  "A" =~ ~r/a/
  # => false
  "A" =~ ~r/a/i
  # => true
  ```
- `unicode` `u` - الگوهای مخصوص Unicode مانند `\p` را فعال می‌کند و باعث می‌شود کلاس‌های نویسه مانند `\w` و غیره نیز با Unicode تطبیق پیدا کنند
  ```elixir
  "ö" =~ ~r/^\w$/
  # => false
  "ö" =~ ~r/^\w$/u
  # => true
  ```
- [و موارد بیشتر: `dotall`، `multiline`، `extended`، `firstline`، `ungreedy`][regex-modifiers]

## ساخت پویای عبارت‌های باقاعده

از آنجا که سیجیل `~r` میانبری برای `"pattern" |> Regex.escape() |> Regex.compile!()` است، می‌توانید از درج رشته نیز برای ساخت پویای الگوی عبارت باقاعده استفاده کنید:

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```

## عبارت‌های باقاعده در برابر ماژول `String`

اگرچه عبارت‌های باقاعده قدرتمند هستند، همیشه استفاده از آن‌ها عاقلانه نیست:

- باید پیش از استفاده کامپایل شوند؛ این کار زمان و حافظه‌ی محاسباتی می‌گیرد.
- ممکن است از توابع ساده‌ی رشته کندتر باشند.

به‌عنوان یک قاعده‌ی سرانگشتی، بهتر است هر زمان که ممکن است از [توابع ماژول `String`][string-functions] استفاده کنید.

```elixir
# Don't use regular expressions to check a suffix:
if "YELLING!" =~ ~r/!$/, do: "Whoa, chill out!"

# Use a string function:
if String.ends_with?("YELLING!", "!"), do: "Whoa, chill out!"
```
