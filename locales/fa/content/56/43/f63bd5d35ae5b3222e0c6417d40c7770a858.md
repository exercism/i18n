# مقدمه

## رشته

«رشته» دنباله‌ای از کاراکترها است که داخل کوتیشن‌ها قرار می‌گیرد.
هم کوتیشن تکی و هم کوتیشن دوگانه پشتیبانی می‌شوند.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### درج متغیر در رشته

در رشته‌های داخل کوتیشن دوگانه، اگر متغیری در محدوده باشد و به آن ارجاع داده شود، مقدارش داخل رشته درج می‌شود.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### پشتیبانی از کدگذاری کاراکتر

از نظر تاریخی، توابع رشته در PHP فقط از کاراکترهای ASCII پشتیبانی می‌کردند و از کدگذاری‌های مدرن یونیکد پشتیبانی نمی‌کردند.
هر کاراکتر ASCII یک بایت است، در حالی که طول کاراکترهای یونیکد می‌تواند ۱ تا ۴ بایت باشد.
اگر می‌خواهید رشته‌های یونیکد را به‌شکل ایمن دست‌کاری کنید، به [نسخه‌های چندبایتی][multi-byte-fns] توابع قدیمی مراجعه کنید.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
