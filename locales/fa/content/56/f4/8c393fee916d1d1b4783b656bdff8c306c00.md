# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که برای کارمندان کارخانه نشان اسم چاپ می‌کند. هر کارمند یک شناسه، یک اسم و یک اسم دپارتمان دارد. برچسب نشان کارمندان به این شکل قالب‌بندی می‌شود: `"[id] - name - DEPARTMENT"`.

## 1. چاپ نشان برای یک کارمند

تابع `NameBadge.print/3` را پیاده‌سازی کنید. این تابع باید یک `id`، یک `name` و یک `department` بگیرد و برچسب نشان را با اسم دپارتمان به‌صورت حروف بزرگ برگرداند.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. چاپ نشان برای یک کارمند جدید

به دلیل یک ایراد عجیب در سیستم رایانه‌ای، گاهی کارمندان جدید هنگام شروع کار در کارخانه هنوز شناسه ندارند. چون همراه داشتن نشان الزامی است، یک نشان موقت بدون پیشوند شناسه دریافت می‌کنند.

تابع `NameBadge.print/3` را گسترش دهید. وقتی `id` وجود ندارد، باید نشانی بدون آن چاپ کند.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. چاپ نشان برای صاحب کارخانه

حتی صاحب کارخانه هم باید همیشه یک نشان همراه داشته باشد. اما صاحب کارخانه دپارتمان ندارد. در این حالت، برچسب باید به‌جای اسم دپارتمان `"OWNER"` را چاپ کند.

تابع `NameBadge.print/3` را گسترش دهید. وقتی `department` وجود ندارد، فرض کنید که نشان به صاحب کارخانه تعلق دارد.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

توجه کنید که ممکن است صاحب کارخانه هم کارمند جدیدی باشد.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
