# مقدمه

زبان Go نوع‌دهی ایستا دارد؛ پس نوع هر «متغیر» در زمان کامپایل مشخص است.
پس از تعریف، نوع متغیر دیگر تغییر نمی‌کند.

## ساختن متغیر

دستور `var` می‌تواند نوع متغیر جدید را تعریف کند، مقدار آن را تعیین کند، یا هر دو را همزمان انجام دهد:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

درون یک تابع، می‌توانید از دستور انتساب کوتاه `:=` هم استفاده کنید.

```go
count := 1 // Type implictly declared, value explicitly set
```

متغیر در Go همیشه یک مقدار دارد.
اگر هنگام تعریف مقداری برایش تعیین نشود، Go بر اساس نوع متغیر مقداری را برای آن فراهم می‌کند که [مقدار صفر][zero-values] نام دارد.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## به‌روزرسانی متغیر

درون یک تابع، عملگر انتساب `=` می‌تواند مقدار جدیدی را برای متغیر موجود تعیین کند:

```go
count := 1
count = 2
```

نوع مقدار جدید باید همان نوع متغیر باشد:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
