# پیوست دستورالعمل‌ها

## `Print` مقادیر رشته‌ای را داخل گیومه نمی‌گذارد

این تمرین شامل دستکاری امتیازهای عددی است.
#[a: 1]` and `#[a: "1"]` یکسان نیستند:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

یک روش رایج در Debug این است که مقادیر را `print` کنید.
اما خروجی، دور رشته‌ها علامت گیومه اضافه نمی‌کند.
بنابراین، یک رشته‌ی عددی مانند `"1"` هنگام چاپ همانند عدد صحیح `1` به نظر می‌رسد.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
در خروجی تست این تمرین، ممکن است نتیجه‌ای مانند `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]` ببینید.
این دو «دیکشنری» که با هم مقایسه می‌شوند، هنگام چاپ یکسان به نظر می‌رسند.
اما دیکشنری اول مقادیر رشته‌ای عددی دارد و دومی مقادیر عدد صحیح، بنابراین یکسان نیستند. 
هنگام Debug، می‌توانید از `inspect` برای بررسی محتویات دیکشنری خودتان استفاده کنید.

## `Express` مقادیر رشته‌ای را داخل گیومه می‌گذارد

`express` یک مقدار را به کد Arturo تبدیل می‌کند و رشته‌ای را برمی‌گرداند که همان نمایش کد را نشان می‌دهد.
در آن نتیجه، همه‌ی مقادیر رشته‌ای داخل گیومه قرار می‌گیرند.
در نتیجه، `express "1"` مقدار `"1"` را برمی‌گرداند، نه `1` را.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
