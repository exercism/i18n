# مقدمه

یک عبارت «منطقی» پرسشی است که از یک یا چند مقدار پرسیده می‌شود و می‌توان با `true` یا `false` به آن پاسخ داد.
یک عبارت «درست» مقدار `1` را برمی‌گرداند و یک عبارت «غلط» مقدار `0` را.
همچنین عددها هم مقدار «درست» یا «غلط» دارند. صفر `false` است و هر عدد ناصفر `true`.

کدهای قدیمی C یا مستقیماً از نوع `int` برای مقادیر منطقی استفاده می‌کردند، یا ممکن است برنامه‌نویس ثابت‌هایی مثل `TRUE` و `FALSE` تعریف کرده باشد تا `1` و `0` را به یک نمایش منطقی نگاشت کند.

در نسخه‌ی C99 نوع `_Bool` اضافه شد.
فایل هدر `stdbool.h` سه نماد منطقی جدید تعریف می‌کند: `bool`، `true` و `false`.
`true` به `1` نگاشت می‌شود، `false` به `0` و `bool` به `_Bool`.
پس حالا برنامه‌نویس‌ها می‌توانند به‌جای استفاده‌ی مستقیم از `int` یا ساختن نگاشت‌های منطقی خودشان، `stdbool.h` را اضافه کنند و به‌طور خودکار نمادهای منطقی را در کدشان داشته باشند.

## عملگرهای مقایسه

C از شش عملگر مقایسه پشتیبانی می‌کند: `==` (برابر)، `!=` (نابرابر)، `>` (بزرگ‌تر از)، `<` (کوچک‌تر از)، `>=` (بزرگ‌تر یا برابر) و `<=` (کوچک‌تر یا برابر).
این عملگرها رابطه‌ی بین مقدارها را مقایسه می‌کنند و نتیجه را به یک مقدار منطقی تبدیل می‌کنند.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## عملگرهای منطقی

C از سه عملگر منطقی پشتیبانی می‌کند: `||` (یا)، `&&` (و) و `!` (نقیض).

`!` با یک عملوند استفاده می‌شود.
مقدار منطقی عملوند را برعکس می‌کند.
برای نمونه، `0` همان `false` است، اما `!0` همان `true` است.

`||` و `&&` با دو عملوند استفاده می‌شوند.
عملوند سمت راست تنها زمانی ارزیابی می‌شود که عملوند سمت چپ نتیجه‌ی عبارت را از قبل تعیین نکرده باشد.
یعنی `||` عملوند سمت راستش را تنها زمانی ارزیابی می‌کند که عملوند سمت چپش به `false` ارزیابی شود.
`&&` عملوند سمت راستش را تنها زمانی ارزیابی می‌کند که عملوند سمت چپش به `true` ارزیابی شود.
