# پارامترهای متغیر

[_پارامترهای متغیر_][variadic-parameters] در Swift اجازه می‌دهند صفر یا چند مقدار از یک نوع، به یک پارامتر واحد در یک تابع فرستاده شوند. این ویژگی با افزودن `...` به اعلان نوع پارامتر مشخص می‌شود.

این مقادیر به‌طور خودکار در یک «آرایه» گروه‌بندی می‌شوند که عناصر آن از همان نوع پارامتر متغیر هستند.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

توجه داشته باشید که Swift هنگام استفاده از پارامترهای متغیر یک محدودیت دارد.
اگر تابعی در تعریف خود پارامترهایی بعد از پارامتر متغیر داشته باشد، اولین پارامتری که بعد از پارامتر متغیر می‌آید، _باید_ یک «برچسب آرگومان» داشته باشد.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
