# مقدمه

در Go، `map` یک نوع داده‌ی توکار است که کلیدها را به مقدارها نگاشت می‌کند.
در زبان‌های برنامه‌نویسی دیگر، ممکن است با مفهوم `map` به عنوان دیکشنری، جدول درهم‌سازی، مخزن کلید/مقدار یا آرایه‌ی انجمنی آشنا باشید.

از نظر نحوه‌ی نگارش، `map` به این شکل است:

```go
map[KeyType]ElementType
```

همچنین مهم است بدانید که هر کلید یکتاست، یعنی اگر یک کلید را دو بار مقداردهی کنید، مقدار کلید متناظر بازنویسی می‌شود.

برای ساختن `map`، می‌توانید این کار را انجام دهید:

```go
  // With map literal
  foo := map[string]int{}
```

یا

```go
  // or with make function
  foo := make(map[string]int)
```

در ادامه چند عملیات که می‌توانید با `map` انجام دهید آورده شده است

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

اگر بخواهید مقدار یک کلید را که در `map` وجود ندارد بازیابی کنید، مقدار صفر نوع مقدار را برمی‌گرداند.
این می‌تواند شما را سردرگم کند، به‌ویژه اگر مقدار پیش‌فرض `ElementType` شما (برای مثال، ۰ برای یک `int`) یک مقدار معتبر باشد.
برای بررسی اینکه آیا کلیدی در `map` شما وجود دارد، می‌توانید از این استفاده کنید:

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
