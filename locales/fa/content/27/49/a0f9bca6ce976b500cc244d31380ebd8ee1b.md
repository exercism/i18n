# دستورالعمل‌ها

در این تمرین، «خطوط لاگ» را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با قالب زیر: `"[<LVL>]: <MESSAGE>"`.

سطوح مختلف لاگ عبارت‌اند از:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

سه وظیفه دارید.

## 1. تجزیه‌ی سطح لاگ

یک `enum` به اسم `LogLevel` تعریف کنید که شش عضو متناظر با سطوح لاگ بالا دارد.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

در ادامه، متد (_static_) `LogLine.ParseLogLevel()` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را تجزیه کند:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. پشتیبانی از سطح لاگ ناشناخته

متأسفانه گاهی برخی خطوط لاگ سطح لاگ ناشناخته دارند. برای اینکه این خطوط لاگ را به‌خوبی مدیریت کنید، به `enum` `LogLevel` عضوی به اسم `Unknown` اضافه کنید که هنگام تجزیه‌ی یک سطح لاگ ناشناخته باید برگردانده شود:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. تبدیل خط لاگ به قالب کوتاه

سطح لاگ یک خط لاگ نسبتاً پرحجم است. برای کاهش فضای دیسکی که برای ذخیره‌ی خطوط لاگ لازم است، قالب کوتاهی طراحی شده است: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

سطح لاگ رمزگذاری‌شده نگاشتی ساده از سطح لاگ به یک عدد است:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

متد (_static_) `LogLine.OutputForShortLog()` را پیاده‌سازی کنید که می‌تواند قالب کوتاه‌شده‌ی خط لاگ را تولید کند:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
