# مقدمه

«تاپل» یک ظرف مرتب از مقادیر است. تاپل مانند همه‌ی انواع داده‌ی Gleam تغییرناپذیر است. هر عنصر یک تاپل می‌تواند از نوعی متفاوت باشد، حتی می‌تواند خودش تاپل دیگری باشد.

تاپل‌ها به‌صورت مقادیر جداشده با ویرگول بین `#(` و `)` تعریف می‌شوند: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

تاپل‌هایی با طول یکسان و انواع یکسان (به همان ترتیب) را می‌توان از نظر برابری مقایسه کرد.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

سه روش برای بیرون آوردن مقادیر موجود در یک تاپل وجود دارد:

- ایندکس کردن.
- تطبیق الگو با `let`.
- تطبیق الگو با `case`.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

از ایندکس کردن تاپل می‌توان در نگهبان‌های عبارت `case` استفاده کرد.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
