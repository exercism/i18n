# مقدمه

به توانایی اینکه چیزی بر اساس خودش تعریف شود، «بازگشت» می‌گویند. در F#، بازگشت بیشتر در توابع بازگشتی دیده می‌شود، یعنی توابعی که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید دست‌کم یک «_حالت پایه_» و دست‌کم یک «_حالت بازگشتی_» داشته باشد. _حالت پایه_ بدون فراخوانی دوباره‌ی تابع مقداری را برمی‌گرداند. _حالت بازگشتی_ تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در نقطه‌ای با حالت پایه مطابقت کند.

توابع بازگشتی مانند توابع معمولی تعریف می‌شوند، اما با اصلاح‌کننده‌ی `rec`. بدون این اصلاح‌کننده، یک تابع _نمی‌تواند_ خودش را فراخوانی کند و هر تلاشی برای این کار به خطای کامپایل منجر می‌شود. بنابراین بازگشت باید به‌صراحت انتخاب شود.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# همچنین از انواع بازگشتی از طریق انواع اتحادیه‌ی متمایز پشتیبانی می‌کند. یک نوع اتحادیه‌ی متمایز بازگشتی یک یا چند حالت دارد که در داده‌ی خودشان به خودِ نوع اتحادیه‌ی متمایز ارجاع می‌دهند. مانند توابع بازگشتی، انواع بازگشتی هم باید حالت پایه داشته باشند. برخلاف توابع بازگشتی، انواع بازگشتی از کلیدواژه‌ی `rec` استفاده نمی‌کنند.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
