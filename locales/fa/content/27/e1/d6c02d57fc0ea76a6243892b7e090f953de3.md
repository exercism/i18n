# مقدمه

`string` در F# شیئی است که متنی تغییرناپذیر را به‌صورت دنباله‌ای از کاراکترهای یونیکد (حروف، ارقام، علائم نگارشی و غیره) نمایش می‌دهد و به شکل زیر تعریف می‌شود:

```fsharp
let fruit = "Apple"
```

برای کار با `string`ها می‌توانید متدهای آن را فراخوانی کنید یا از توابع ماژول `String` استفاده کنید. پس از آنکه یک `string` ساخته شد، مقدارش دیگر هرگز تغییر نمی‌کند. هر متد یا تابعی که به نظر برسد `string` را تغییر می‌دهد، در واقع `string` جدیدی برمی‌گرداند.

می‌توان `string`ها را به چند روش مختلف به هم پیوست یا قالب‌بندی کرد.
* می‌توانید از عملگر `+` برای به هم پیوستن استفاده کنید:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* می‌توانید از تابع `sprintf` برای قالب‌بندی متن استفاده کنید؛ در این حالت در متن قالب جای‌نگهدار دارید (`%s` برای یک `string`) و مقادیر را به‌عنوان آرگومان می‌دهید:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
