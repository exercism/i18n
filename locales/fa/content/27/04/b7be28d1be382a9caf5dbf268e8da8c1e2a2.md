# مقدمه

به‌طور کلی دو نوع «حلقه» وجود دارد:

۱. حلقه تا زمانی که یک شرط برآورده شود.
۲. حلقه زدن روی عناصر یک مجموعه.

هر دو در Julia ممکن‌اند، هرچند نوع دوم ممکن است رایج‌تر باشد.

## حلقه‌ی `while`

برای مسائل بازی که تعداد گردش‌های حلقه از پیش معلوم نیست، Julia حلقه‌ی `while` را دارد.

شکل پایه‌ای آن نسبتاً ساده است:

```julia
while condition
    do_something()
end
```

در این حالت، برنامه آن‌قدر دور حلقه می‌چرخد تا `condition` دیگر `true` نباشد.

دو راه برای خروج زودهنگام از حلقه وجود دارد:

- `break` باعث خروج از حلقه می‌شود و اجرا از خط بعدی پس از `end` حلقه ادامه پیدا می‌کند.
- `return x` اجرای تابع جاری را متوقف می‌کند و مقدار بازگشتی `x` را به فراخوان بازمی‌گرداند.

با وجود این گزینه‌ها، گاهی راحت است که یک حلقه‌ی «بی‌نهایت» با `while true ... end` بسازید و سپس به یافتن شرط توقف در بدنه‌ی حلقه تکیه کنید تا `break` یا `return` فعال شود.

## حلقه زدن روی یک مجموعه

ساده‌ترین مثال، حلقه زدن روی یک بازه است.

اگر بخواهیم کاری را ۱۰ بار انجام دهیم:

```julia
for n in 1:10
    do_something(n)
end
```

اگر تکرار جاری شرطی را برآورده نکند، می‌توان با `continue` بی‌درنگ به تکرار بعدی رفت:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

در شکلی کوتاه‌تر، می‌توان بلوک `if` را با `is_useless(n) && continue` جایگزین کرد.

می‌توان روی بسیاری از انواع مجموعه‌ی دیگر هم حلقه زد: عناصر یک آرایه، کاراکترهای یک رشته، کلیدهای یک دیکشنری...

مثال‌های تا اینجا روی بازه‌ی `1:10` حلقه می‌زنند، که در آن مقدار همان اندیس حلقه هم هست.

به‌طور کلی‌تر، ممکن است به اندیس نیاز باشد و نه فقط به مقدار.
برای این کار از تابع `eachindex()` استفاده می‌شود، مثلاً `for i in eachindex(my_array) ... end`.

## درک فهرست

نوشتن حلقه‌های صریح در Julia معمولاً کمتر از بسیاری از زبان‌های سنتی رایج است، چون گزینه‌های مختصرتر گوناگونی وجود دارد.

یک موقعیت به‌ویژه رایج زمانی است که باید بردار جدیدی از عناصر مجموعه‌ی دیگری بسازیم (بردار، رشته، مجموعه ... احتمالات بسیاری وجود دارد).

هر کس که «درک فهرست» را در Python دوست دارد، خوشحال می‌شود بداند Julia می‌تواند از نحوه‌ی نگارش مشابهی استفاده کند.

ماهیت این کار، برپا کردن حلقه‌ای بسیار فشرده درون یک بردار است.

ساده‌ترین نحوه‌ی نگارش به شکل `result = [f(x) for x in some_collection]` است.

با یک حلقه‌ی سنتی، می‌توان آن را چنین نوشت:

```julia
result = []
for x in some_collection
    push!(result, f(x))
end
```

به‌صورت اختیاری، می‌توان در پایان یک شرط افزود تا فقط عناصر منطبق در مجموعه انتخاب شوند:

```julia-repl
# multiples of 3
julia> [n^2 for n in 1:10 if n%3 == 0]
3-element Vector{Int64}:
  9
 36
 81
```
