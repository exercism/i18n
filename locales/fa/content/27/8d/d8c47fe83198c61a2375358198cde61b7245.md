# دستورالعمل‌ها

شما در حال ساختن یک پورتال آنلاین تازه هستید تا مشتریانتان بتوانند میوه‌ی تازه‌ی خود را از میوه‌فروش سفارش دهند. میوه‌فروش یک API دارد که می‌توانید با آن بررسی کنید آیا موجودی موردنظر مشتریانتان را دارد یا نه. باید کتابخانه‌ای کوچک از توابع بسازید تا با API میوه‌فروش تعامل کنید.

## 1. وقتی سفارش مشتری‌تان موفق بود، به او اطلاع دهید

پورتال باید در صورت موفق بودن سفارش، به مشتری اطلاع دهد. تابع `callback` به اسم `onSuccess` را تعریف کنید؛ این تابع اگر سفارش به دلیل داشتن میوه‌ی کافی در انبار میوه‌فروش موفق شود، فراخوانی می‌شود. این تابع باید تابع `notify` واردشده را فراخوانی کند و `{ message: 'SUCCESS' }` را به آن بدهد تا به مشتری اطلاع دهد که سفارشش موفق بوده است.

```javascript
onSuccess();
// => `notify` called with `{ message: 'SUCCESS' }`
```

## 2. وقتی سفارش مشتری‌تان ناموفق بود، به او اطلاع دهید

پورتال باید در صورت ناموفق بودن سفارش، به مشتری اطلاع دهد. تابع `callback` به اسم `onError` را تعریف کنید؛ این تابع اگر سفارش ناموفق شود، چون میوه‌فروش میوه را _در انبار ندارد_ یا خطایی رخ داده است، فراخوانی می‌شود. این تابع باید تابع `notify` واردشده را فراخوانی کند و `{ message: 'ERROR' }` را به آن بدهد تا به مشتری اطلاع دهد که سفارشش ناموفق بوده است.

```javascript
onError();
// => `notify` called with `{ message: 'ERROR' }`
```

## 3. یک پوسته‌ی API بسازید تا تابع سفارش API میوه‌فروش را در بر بگیرد

سفارش‌های میوه از طریق API میوه‌فروش و با تابع `order` که در اختیارتان قرار گرفته ثبت می‌شوند. این تابع سه آرگومان می‌گیرد: یک _query_ که `variety` و `quantity` میوه‌ی درخواستی را در خود دارد، یک تابع `callback` که وقتی سفارش موفق می‌شود فراخوانی می‌شود، و یک تابع `callback` که وقتی سفارش به خطا می‌خورد فراخوانی می‌شود.

می‌خواهید کدتان را از تغییرات احتمالی بیرونی ایمن نگه دارید و تصمیم می‌گیرید فراخوانی تابع `order` را درون تابع تازه‌ای به اسم `orderFromGrocer` قرار دهید. تابع `orderFromGrocer` را پیاده‌سازی کنید که می‌کوشد با فراخوانی تابع `order` در API میوه‌فروش سفارشی ثبت کند و مطمئن می‌شود آرگومان‌های داده‌شده به `orderFromGrocer` را به فراخوانی API می‌فرستد.

این _query_ به شکل یک _object_ است:

```typescript
const query = {
  variety: string,
  quantity: number,
};
```

```javascript
orderFromGrocer(
  { variety: 'pear', quantity: 12 },
  exampleSuccessCallback,
  exampleErrorCallback,
);
// => `order` was called with the query and the callbacks
```

## 4. رسیدگی به سفارش‌های ثبت‌شده را ساده کنید

مشتریان شما حالا می‌توانند از طریق پورتال شما سفارش میوه بدهند، اما متوجه می‌شوید که تابع `orderFromGrocer` را در جاهای مختلفی از کدتان فراخوانی می‌کنید و هر بار باید یک `query` و دو تابع `callback` را به عنوان آرگومان بدهید. فرصتی برای بازآرایی کدتان می‌بینید و فکر می‌کنید اگر بتوانید فقط با دادن `variety` و `quantity` میوه‌ی لازم سفارش ثبت کنید، ساده‌تر می‌شود. تابع کمکی `postOrder` را تعریف کنید که `variety` و `quantity` را به عنوان آرگومان می‌گیرد و می‌کوشد نزد میوه‌فروش سفارشی ثبت کند.

```javascript
postOrder('peach', 100);
// => order placed for 100 peaches
```
