# مقدمه

Map در Elixir ساختار داده‌ای برای ذخیره‌ی اطلاعات به‌صورت جفت‌های کلید-مقدار است. در زبان‌های دیگر، این ساختار با نام‌های آرایه‌ی انجمنی (PHP)، هش (Perl 5 و Raku) یا دیکشنری (Python) هم شناخته می‌شود.

کلیدها و مقدارها می‌توانند از هر نوع داده‌ای باشند، اما اگر کلید یک اتم باشد، می‌توانیم از یک نحوه‌ی نگارش کوتاه استفاده کنیم. Map ترتیب ورودی‌هایش را هنگام دسترسی یا بازگرداندن تضمین نمی‌کند.

## شکل‌های نوشتن مستقیم

یک Map خالی به‌سادگی با `%{}` تعریف می‌شود. اگر بخواهیم عنصری را مستقیماً در یک Map بنویسیم، از دو شکل می‌توانیم استفاده کنیم:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

هرچند قالب استانداردی وجود ندارد، اما برای نمایش جفت‌های کلید-مقدار یک روش یکدست انتخاب کنید.

## توابع ماژول Map

Elixir توابع زیادی برای کار با Map در _ماژول Map_ فراهم می‌کند. بعضی از توابع _ماژول Map_ نیاز دارند تابعی _بینام_ به آن‌ها داده شود تا در تبدیل Map کمک کند.
