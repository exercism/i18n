# نرمال‌سازی‌های representer

[representer جاوااسکریپت][github-javascript-representer] نرمال‌سازی‌های زیر را اعمال می‌کند:

## حذف کامنت‌ها

همه‌ی کامنت‌ها حذف می‌شوند.
مثال‌های زیر معادل‌اند:

### مثالی با کامنت

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### مثالی بدون کامنت

```javascript
function hello() {
  return 'hi there';
}
```

## نرمال‌سازی فضای خالی

وقتی کد بازنمایی می‌شود، _ترتیب_ آن مهم است، اما موقعیت فیزیکی‌اش اهمیت ندارد.
یعنی فضای خالی نرمال‌سازی می‌شود.
مثال‌های زیر معادل‌اند:

### مثالی با تورفتگی دو فاصله

```javascript
function hello() {
  return 'hello world';
}
```

### مثالی با تورفتگی چهار فاصله

```javascript
function hello() {
  return 'hello world';
}
```

### مثالی با تورفتگی جالب

```javascript
function hello() {
  return 'hello world';
}
```

## نرمال‌سازی شناسه‌ها

شناسه‌ها به یک مقدار جانگهدار نرمال‌سازی می‌شوند.

### قبل

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### بعد

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
