# مقدمه

به یاد بیاورید که در مفهوم «مبانی»، یک برنامه‌ی AWK از **جفت‌های الگو-کنش** تشکیل شده است.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## منظور ما از «الگو» چیست؟

«الگو» هر عبارت AWK است.
اینکه نتیجه‌ی عبارت «درست» باشد یا «غلط»، تعیین می‌کند که کنش اجرا شود یا نه.

## الگوی خالی

می‌توان الگو را حذف کرد.
در این حالت، کنش برای هر رکورد انجام می‌شود.

می‌توانیم همه‌ی اسم‌های کاربری را در فایل passwd چاپ کنیم.

```sh
awk -F: '{print $1}' /etc/passwd
```

## عبارت‌های باقاعده

AWK می‌تواند رشته‌ها را با عبارت‌های باقاعده مقایسه کند و نتیجه‌ای «منطقی» به دست آورد.

برای تطبیق یک فیلد مشخص، از عملگر تطبیق عبارت باقاعده، یعنی `~`، استفاده کنید.
این عملگر یک رشته را به عنوان عملوند سمت چپ و یک عبارت باقاعده را به عنوان عملوند سمت راست می‌گیرد.
عبارت باقاعده را میان دو اسلش `/` می‌نویسید.

برای یافتن کاربرانی در فایل passwd که با bash وارد می‌شوند:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` عملگر «عبارت باقاعده **تطبیق نمی‌دهد**» است.

برای تطبیق یک عبارت باقاعده با رکورد جاری، می‌توانید از `$0 ~ /regex/` استفاده کنید.
این کار آن‌قدر رایج است که یک شکل کوتاه‌نویسی هم دارد: می‌توانید `$0` و `~` را حذف کنید و به سادگی `/regex/` بنویسید

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
آن یک‌خطی AWK را با دستور معادل grep مقایسه کنید

```sh
grep 'regex' data.txt
```

AWK یک زبان برنامه‌نویسی کامل در اختیارتان می‌گذارد، بی‌آنکه از ایجازش چیزی کم شود.
~~~~

در یکی از مفاهیم بعدی، بیشتر به سبک عبارت‌های باقاعده‌ی GNU AWK می‌پردازیم.

## عبارت‌ها

عبارت‌های AWK (حسابی، منطقی یا هر نوع دیگر) می‌توانند به عنوان الگو به کار روند.

برای استخراج همه‌ی کاربرانی با UID برابر ۱۰۰۰ یا بیشتر:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

به یاد بیاورید که مقادیر «غلط» در AWK عدد صفر و رشته‌ی خالی هستند و همه‌ی اعداد و رشته‌های دیگر «درست» به شمار می‌آیند.
هر عبارتی که به عدد یا رشته‌ای ارزیابی شود، می‌تواند به عنوان الگو استفاده شود.

## توابع

هر تابع [درونی][builtins] یا [تعریف‌شده توسط کاربر][user-defined] را می‌توان در یک عبارت، و از این رو در الگو، به کار برد.
چند نمونه:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## الگوهای ثابت

یک اصطلاح رایج در AWK این است:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` الگویی است که درست ارزیابی می‌شود و هیچ کنش همراهی ندارد.
این یعنی «رکورد جاری را چاپ کن.»
