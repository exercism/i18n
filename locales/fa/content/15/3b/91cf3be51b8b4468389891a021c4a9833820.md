# مقدمه

پایتون سه نوع مختلف از اعداد توکار دارد: اعداد صحیح ([`int`][int])، اعداد اعشاری ([`float`][float]) و اعداد مختلط ([`complex`][complex]).
کسرها ([`fractions.Fraction`][fractions]) و دسیمال‌ها ([`decimal.Decimal`][decimals]) نیز از طریق `import` از کتابخانه‌ی استاندارد در دسترس‌اند.

اعداد صحیح، از جمله اعداد هگزادسیمال ([_`hex()`_][hex])، هشت‌گانه ([_`oct()`_][oct]) و دودویی ([_`bin()`_][bin]) که **بدون** رقم اعشارند، نیز از نوع `ints` شناخته می‌شوند:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

اعدادی که شامل نقطه‌ی اعشار باشند (با جزء اعشاری یا بدون آن) از نوع `floats` شناخته می‌شوند:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## عملیات حسابی

پایتون به‌طور کامل از عملیات حسابی میان این نوع‌های مختلف عددی پشتیبانی می‌کند و وقتی از عملگرهای حسابی دودویی (`+`، `-`، `*`، `/`، `//` و `%`) استفاده شود، اعداد باریک‌تر را به نوع پهن‌تر متناظرشان تبدیل می‌کند.

### جمع و تفریق

عملگرهای جمع و تفریق مانند ریاضیات معمولی عمل می‌کنند.
اگر یک یا چند عملوند از نوع `float` باشند، بقیه‌ی `int`ها هم به `float` تبدیل می‌شوند:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### ضرب

مانند جمع و تفریق، ضرب نیز اعداد باریک‌تر را به نوع پهن‌تر متناظرشان تبدیل می‌کند:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### تقسیم

تقسیم همیشه یک `float` برمی‌گرداند، حتی اگر نتیجه عددی صحیح باشد:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### تقسیم کف

اگر به نتیجه‌ای از نوع `int` نیاز دارید، می‌توانید از تقسیم کف برای بریدن نتیجه استفاده کنید.
تقسیم کف با عملگر `//` انجام می‌شود:

```python
>>> 6//5
1

>>> 6//2
3
```

### باقیمانده

عملگر باقیمانده (`%`) باقیمانده‌ی تقسیم دو عملوند را برمی‌گرداند:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

روش دیگری برای نگاه کردن به ۵ % ۳:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## گرد کردن

پایتون یک تابع توکار [`round(number, <decimal_places>)`][round] فراهم می‌کند تا یک عدد اعشاری را به تعداد مشخصی رقم اعشار گرد کند.
اگر تعداد ارقام اعشار مشخص نشود، عدد به نزدیک‌ترین عدد صحیح گرد می‌شود و یک `int` برمی‌گرداند:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## اولویت و پرانتز

پایتون به شما اجازه می‌دهد از پرانتز برای گروه‌بندی عبارت‌ها استفاده کنید.
این زمانی مفید است که بخواهید ترتیب پیش‌فرض عملیات را نادیده بگیرید.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

پایتون برای تقدم عملگرها از قاعده‌ی [PEMDAS][pemdas] پیروی می‌کند.
یعنی محاسبات داخل `()` بالاترین اولویت را دارند و پس از آن `**`، سپس `*`، `/`، `//`، `%`، `+` و `-` قرار می‌گیرند:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## دقت و نمایش

اعداد صحیح در پایتون [دقت دلخواه][arbitrary-precision] دارند؛ تعداد ارقام تنها با حافظه‌ی در دسترس سیستم میزبان محدود می‌شود.

اعداد اعشاری معمولاً در C با `double` پیاده‌سازی می‌شوند (_۱۵ رقم دقت_)، اما نمایششان بسته به سیستم میزبان متفاوت است.
اعداد مختلط یک بخش `real` و یک بخش `imaginary` دارند که هر دو با اعداد اعشاری نمایش داده می‌شوند.

برای بحث‌های مفصل‌تر درباره‌ی مشکلات و محدودیت‌های حساب اعشاری در زبان‌های برنامه‌نویسی مختلف، نگاهی به [0.30000000000000004.com][0.30000000000000004.com] و [The Python Tutorial][floating point math] بیندازید.
