# متدهای آرایه

آرایه‌ها از ساختارهای داده‌ی رایج‌اند که با آن‌ها کار می‌کنیم.
به همین دلیل، مجموعه‌ای از متدها وجود دارند که می‌توان برای کار با آرایه‌ها از آن‌ها استفاده کرد.
این مجموعه شامل مرتب‌سازی، معکوس‌سازی، درج و بسیاری موارد دیگر است.

برخی از این متدها مخرب هستند، یعنی آرایه‌ی اصلی را تغییر می‌دهند.
برخی دیگر غیرمخرب‌اند؛ یعنی یک آرایه‌ی جدید برمی‌گردانند و آرایه‌ی اصلی را تغییر نمی‌دهند.

در ادامه چند مورد از رایج‌ترین متدهایی را می‌بینید که می‌توان هنگام کار با آرایه‌ها از آن‌ها استفاده کرد:

## insert

هنگام درج یک عنصر در آرایه، می‌توانید از متد [`insert`][insert] استفاده کنید که یک اندیس و یک عنصر را به عنوان آرگومان می‌گیرد.
عنصر در اندیس مشخص‌شده درج می‌شود و باقی آرایه به سمت راست جابه‌جا می‌شود.
اگر اندیس خارج از محدوده باشد، یک `IndexError` ایجاد می‌شود.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

وقتی می‌خواهید عنصر مشخصی را از آرایه حذف کنید، می‌توانید از متد [`delete`][delete] استفاده کنید که یک عنصر را به عنوان آرگومان می‌گیرد.
این متد عنصر حذف‌شده را برمی‌گرداند.
اگر عنصر در آرایه وجود نداشته باشد، `nil` برگردانده می‌شود.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

وقتی می‌خواهید اولین یا آخرین عنصر یک آرایه را به دست آورید، می‌توانید از متدهای [`first`][first] و [`last`][last] استفاده کنید.
این متدها یک آرگومان اختیاری می‌گیرند که مشخص می‌کند چند عنصر برگردانده شود.
این کار در مقایسه با استفاده از اندیس `0` یا `-1`، یا استفاده از یک بازه، خوانایی را بهبود می‌دهد.
اگر آرایه خالی باشد، یک `Enumerable::EmptyError` ایجاد می‌شود.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

وقتی می‌خواهید یک آرایه را معکوس کنید، می‌توانید از متد [`reverse`][reverse] استفاده کنید که آرایه‌ی جدیدی با عناصر در ترتیب معکوس برمی‌گرداند.
توجه به این نکته مهم است که `reverse` یک آرایه‌ی جدید برمی‌گرداند و آرایه‌ی اصلی را تغییر نمی‌دهد.
اگر می‌خواهید آرایه‌ی اصلی را تغییر دهید، یک `!` به انتهای اسم متد اضافه کنید.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

متدهای زیر هنگام انجام کارهایی مانند تک‌بعدی کردن آرایه، حذف عناصر `nil`، حذف مقادیر تکراری یا جابه‌جا کردن سطرها و ستون‌های آرایه‌ای از آرایه‌ها مفید هستند.
مانند `reverse`، این متدها یک آرایه‌ی جدید برمی‌گردانند و آرایه‌ی اصلی را تغییر نمی‌دهند.

| متد | توضیح | مثال |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | آرایه‌ی جدیدی برمی‌گرداند که تخت‌شدن تک‌بعدی این آرایه (به‌صورت بازگشتی) است. یعنی برای هر عنصر آرایه، عناصر آن را در آرایه‌ی جدید استخراج می‌کند. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | یک نسخه‌ی از self برمی‌گرداند که همه‌ی عناصر nil از آن حذف شده‌اند. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | فرض می‌کند که self آرایه‌ای از آرایه‌ها است و سطرها و ستون‌ها را [جابه‌جا می‌کند][transpose]. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | با حذف مقادیر تکراری در self، آرایه‌ی جدیدی برمی‌گرداند. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

متد الحاق (`<<`) هنگامی که می‌خواهید اشیایی به آرایه اضافه کنید مفید است.
با این حال، هنگام ترکیب دو آرایه می‌توانید از عملگر [`+`][concat] استفاده کنید که آرایه‌ی جدیدی با عناصر هر دو آرایه برمی‌گرداند.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

اگر آرایه‌ای را به آرایه‌ی دیگری الحاق کنید، آن آرایه به صورت یک عنصر واحد اضافه می‌شود.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

برای بررسی خالی بودن یک آرایه می‌توانید از متد [`empty?`][empty?] استفاده کنید که اگر آرایه خالی باشد `true` و در غیر این صورت `false` برمی‌گرداند.
این کار در مقایسه با مقایسه‌ی طول آرایه با `0`، خوانایی را بهبود می‌دهد.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

وقتی می‌خواهید اندیس یک عنصر در آرایه را به دست آورید، می‌توانید از متد [`index`][index] استفاده کنید که یک عنصر را به عنوان آرگومان می‌گیرد.
اگر عنصر در آرایه وجود نداشته باشد، `nil` برگردانده می‌شود.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

وقتی می‌خواهید تعداد عناصر یک آرایه را بدانید، می‌توانید از متد [`size`][size] استفاده کنید.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

وقتی می‌خواهید بشمارید که یک عنصر چند بار در آرایه وجود دارد، می‌توانید از متد [`count`][count] استفاده کنید.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

وقتی می‌خواهید یک آرایه را مرتب کنید، می‌توانید از متد [`sort`][sort] استفاده کنید که آرایه‌ی جدیدی با عناصر مرتب‌شده برمی‌گرداند.
مانند `reverse`، این متد یک آرایه‌ی جدید برمی‌گرداند و آرایه‌ی اصلی را تغییر نمی‌دهد.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
