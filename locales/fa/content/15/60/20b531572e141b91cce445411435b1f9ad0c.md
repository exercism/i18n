# مقدمه

«پیمایش» یعنی گام‌به‌گام از یک مجموعه (`Array`، `Hash` و غیره) گذر کردن و روی هر عضو آن کاری انجام دادن.

پیمایش یکی از مفاهیم کلیدی در Ruby است و برای مرتب‌سازی (`sort_by`)، گروه‌بندی (`group_by`)، نگاشت (`map`)، کاهش (`reduce`) و بسیاری موارد دیگر به کار می‌رود.
بیشتر اوقات پیمایش را به‌عنوان روش اصطلاحیِ گشتن در مجموعه‌ها می‌بینید، نه استفاده از حلقه‌ها.

یک پیمایش ساده که از `map` و `with_index` استفاده می‌کند، به این شکل است:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
