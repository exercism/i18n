# مقدمه

ماژول [`fractions`][fractions] به ما امکان می‌دهد تا با [`rational numbers`][rational] کار کنیم و آن‌ها را بسازیم: کسرهایی که صورتشان یک عدد صحیح است و بر مخرجی صحیح تقسیم می‌شود.
برای مثال، می‌توانیم `2/3` را به‌صورت یک کسر دقیق ذخیره کنیم، به‌جای مقدار تقریبی `float` که `0.6666...` است.

برخلاف اعداد `int`، `float` و `complex`، کسرها شکل تحت‌اللفظی ندارند.
با این حال، سازنده‌ی کسر کاملاً انعطاف‌پذیر است.

واضح‌ترین حالت این است که می‌تواند دو عدد صحیح را به‌عنوان آرگومان بگیرد.
عامل‌های مشترک به‌طور خودکار حذف می‌شوند و کسر به «ساده‌ترین شکل» خود تبدیل می‌شود (_کوچک‌ترین اعداد صحیحی که کسر را به‌درستی نشان می‌دهند_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

سازنده‌ی کسر همچنین می‌تواند یک نمایش رشته‌ای را تجزیه کند:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

کسرها می‌توانند با پارامترهای `float` هم کار کنند، اما این کار ممکن است به‌خاطر ماهیت تقریبی نمایش داخلی مقدار اعشاری به‌صورت دودویی دردسرساز شود.
برای اطلاعات بیشتر درباره‌ی این مسئله‌ی نمایش، وب‌سایت [0.30000000000000004][0.30000000000000004] و بخش [حساب ممیز شناور: مسائل و محدودیت‌ها ][fp-issues] در مستندات Python را ببینید.

برای گرفتن نتیجه‌ای قابل‌اطمینان‌تر هنگام استفاده از اعداد اعشاری همراه با کسرها، متد `<fraction>.limit_denominator()` وجود دارد.


## حساب با کسرها

عملگرهای [`arithmetic operators`][operators] معمول `+ - * / **` با کسرها هم، درست مثل سایر انواع عددی، کار می‌کنند.

عددهای صحیح و `Fraction`های دیگر می‌توانند در محاسبه شرکت کنند و نتیجه‌شان یک `Fraction` باشد.
اگر یک `float` در عبارت بیاید، خروجی `float` می‌شود و در نتیجه دقت ممکن است کاهش پیدا کند:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

توابع عددی استاندارد مختلف Python هم همان نتیجه‌ای را می‌دهند که از کار با انواع `int` و `float` انتظار دارید:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
