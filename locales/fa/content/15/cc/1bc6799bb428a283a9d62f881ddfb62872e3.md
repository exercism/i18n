# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که کدهای تلفن بین‌المللی را در قالب یک دیکشنری کد تلفن بین‌المللی نگه دارد.

این دیکشنری برای کلیدهایش از عدد صحیح (کد تلفن) و برای مقدارهایش از رشته (نام کشور) استفاده می‌کند.

۹ تسک دارید که همه به کلاس استاتیک `DialingCodes` مربوط می‌شوند.

## 1. ساخت یک دیکشنری جدید

متد (استاتیک) `DialingCodes.GetEmptyDictionary()` را پیاده‌سازی کنید که یک دیکشنری خالی برمی‌گرداند.

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. ساخت یک دیکشنری از پیش پر شده

یک دیکشنری از پیش پر شده وجود دارد که این ۳ کد تلفن را در خود دارد: "United States of America" با کد ۱، "Brazil" با کد ۵۵ و "India" با کد ۹۱. متد (استاتیک) `DialingCodes.GetExistingDictionary()` را پیاده‌سازی کنید تا این دیکشنری از پیش پر شده را برگرداند:

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. افزودن یک کشور به دیکشنری خالی

متد (استاتیک) `DialingCodes.AddCountryToEmptyDictionary()` را پیاده‌سازی کنید که یک دیکشنری می‌سازد و یک کد تلفن و نام کشور مرتبط با آن را به آن اضافه می‌کند.

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. افزودن یک کشور به دیکشنری موجود

متد (استاتیک) `DialingCodes.AddCountryToExistingDictionary()` را پیاده‌سازی کنید که یک کد تلفن و نام کشور مرتبط با آن را به یک دیکشنری غیرخالی اضافه می‌کند.

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. گرفتن نام کشوری که با یک کد تلفن مطابقت دارد

متد (استاتیک) `DialingCodes.GetCountryNameFromDictionary()` را پیاده‌سازی کنید که یک کد تلفن می‌گیرد و نام کشور متناظر را برمی‌گرداند. اگر کد تلفن در دیکشنری نباشد، رشته‌ی خالی برگردانده می‌شود.

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. بررسی وجود یک کشور در دیکشنری

متد (استاتیک) `DialingCodes.CheckCodeExists()` را پیاده‌سازی کنید تا بررسی کنید آیا یک کد تلفن در دیکشنری وجود دارد یا نه.

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. به‌روزرسانی نام یک کشور

متد (استاتیک) `DialingCodes.UpdateDictionary()` را پیاده‌سازی کنید که یک کد تلفن می‌گیرد و نام کشور متناظر در دیکشنری را با نام کشوری که به عنوان پارامتر پاس داده شده جایگزین می‌کند. اگر کد تلفن در دیکشنری وجود نداشته باشد، دیکشنری بدون تغییر می‌ماند.

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. حذف یک کشور از دیکشنری

متد (استاتیک) `DialingCodes.RemoveCountryFromDictionary()` را پیاده‌سازی کنید که یک کد تلفن می‌گیرد و رکورد متناظر، یعنی کد تلفن به همراه نام کشور، را از دیکشنری حذف می‌کند.

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. یافتن کشوری با بلندترین نام

متد (استاتیک) `DialingCodes.FindLongestCountryName()` را پیاده‌سازی کنید که نام کشوری با بلندترین نام را از میان نام‌های ذخیره‌شده در دیکشنری برمی‌گرداند.

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
