# راهنمایی‌ها

## کلی

- برای دسترسی به «متغیر نمونه» و تعریف آن، `@` را می‌نویسید و بعد از آن اسم متغیر را می‌آورید.

## 1. مقداردهی اولیه‌ی `TaskHandler`

- برای ساختن یک `Proc` از نحوه‌ی نگارش `-> (args) { block }` استفاده کنید.
- وقتی یک `Proc` برای متغیر نمونه تعریف می‌شود، باید نوعش به‌صراحت مشخص شود.
  این کار با افزودن `: Proc(<arg_type>, <return_type>)` بعد از اسم متغیر انجام می‌شود.
  یا می‌توان همین کار را با نحوه‌ی نگارش `-> (arg_1 : <arg_type>) : <return_type> { block }` انجام داد.
- `Proc` باید بررسی کند که آیا آرگومان بزرگ‌تر یا مساوی ۰ است.

## 2. به‌روزرسانی منطق شرط وظیفه

- متد باید یک «بلوک» را به عنوان آرگومان بگیرد و آن را به متغیر نمونه‌ی `@task_condition_logic` اختصاص دهد.

## 3. اجرای وظیفه‌ی بعدی

- برای اجرای یک `Proc` می‌توانید از متد `call` استفاده کنید که آرگومان‌های مربوط به `Proc` را می‌پذیرد.
