# درباره‌ی حلقه‌ی For

[حلقه‌ی for](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) سازوکاری فراهم می‌کند تا گروهی از دستورها را به‌طور مکرر و تا زمانی که شرطی برآورده شود اجرا کند.
حلقه از چهار بخش تشکیل شده است:

```java
for (initialization; test; update) {
    body;
}
```

بخش `initialization` یک حالت اولیه برای حلقه تنظیم می‌کند و دقیقاً یک بار در آغاز حلقه اجرا می‌شود.
معمولاً متغیری را اعلام و مقداردهی می‌کند که در عبارت آزمون و دستور به‌روزرسانی استفاده می‌شود.
برای مثال:

```java
int i = 1
```

عبارت `test` بررسی می‌کند که آیا حلقه باید پایان یابد.
اگر مقدار آن «درست» باشد، ابتدا بدنه و سپس عبارت به‌روزرسانی اجرا می‌شوند.
اگر مقدار آن «غلط» باشد، نه بدنه اجرا می‌شود و نه دستور به‌روزرسانی. اجرا پس از آکولاد بسته‌ی حلقه ادامه پیدا می‌کند.
معمولاً متغیری را که در بلوک `initialization` مقدار گرفته است بررسی می‌کند.
برای مثال:

```java
i <= 10
```

پس از اجرای بدنه‌ی حلقه، عبارت `update` اجرا می‌شود.
معمولاً متغیر حلقه را به اندازه‌ی مقداری افزایش یا کاهش می‌دهد.
برای مثال:

```java
i++
```

یک حلقه‌ی For که چهار مربع اول را چاپ می‌کند، به این صورت است:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

اگر قصد پیمایش همه‌ی عناصر یک مجموعه را دارید، حلقه‌ی `for-each` ترجیح داده می‌شود، اما می‌توانید همین کار را با یک حلقه‌ی `for` هم به این شکل انجام دهید:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

حلقه‌ی `for` در مقایسه با حلقه‌ی `for-each` چند مزیت دارد:

- می‌توانید از هر اندیسی که می‌خواهید شروع کنید یا متوقف شوید.
- می‌توانید هر شرط پایانی «منطقی» را که می‌خواهید به کار ببرید.
- می‌توانید با سفارشی‌سازی نحوه‌ی افزایش متغیر حلقه، از روی بعضی عناصر بگذرید.
- می‌توانید مجموعه‌ها را با شمارش نزولی از آخر به اول پردازش کنید.
- می‌توانید از حلقه‌های `for` در موقعیت‌هایی استفاده کنید که به مجموعه‌ها مربوط نیستند.
