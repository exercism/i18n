# مقدمه

## فضای نام

یک روش مهم برای سازمان‌دهی کد، استفاده از «فضای نام» است.
ممکن است اسم دو تابع با هم تداخل داشته باشد، که این مشکل را می‌توان با قرار دادن آن‌ها در فضاهای نام متفاوت حل کرد.
فضاهای نام می‌توانند تودرتو باشند، و این ممکن است به ساختاردهی پایگاه‌های کد بزرگ کمک کند.
دسترسی به فضاهای نام با عملگر تفکیک دامنه‌ی `::` انجام می‌شود.

مثال زیر استفاده از دو تابع متفاوت `foo` را نشان می‌دهد.
این دو تابع با پیشوند کردن فضای نام مربوط به هرکدام، با هم به کار می‌روند.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
