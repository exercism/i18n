# دستورالعمل‌ها

در این تمرین، خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است که به این شکل قالب‌بندی شده است: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه وظیفه دارید؛ هر وظیفه یک خط لاگ می‌گیرد و از شما می‌خواهد کاری روی آن انجام دهید.

## 1. دریافت پیام از یک خط لاگ

تابع `message` را طوری پیاده‌سازی کنید که پیام یک خط لاگ را برگرداند:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

هر فاصله‌ی خالی ابتدا یا انتهای رشته باید حذف شود:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. دریافت سطح لاگ از یک خط لاگ

تابع `log_level` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. قالب‌بندی مجدد یک خط لاگ

تابع `reformat` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند، به این صورت که پیام اول می‌آید و سطح لاگ بعد از آن داخل پرانتز قرار می‌گیرد:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
