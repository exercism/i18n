# پیوست دستورالعمل‌ها

## واژه‌ها

- `<bst> ( data-seq -- tree )`: درختی می‌سازد و هر عنصر `data-seq` را به ترتیب در آن درج می‌کند.
- `sorted-data ( tree -- seq )`: عنصرهای درخت را به ترتیب صعودی برمی‌گرداند (پیمایش میان‌ترتیبی).

## سلسله‌مراتب تاپل

یک گره در درخت جست‌وجوی دودویی یا *خالی* است یا *داده به همراه دو زیردرخت دارد*. این را به صورت یک سلسله‌مراتب ارث‌بری کوچک مدل‌سازی کنید:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` والد انتزاعی است. `leaf` حالت درخت خالی است. `branch` یک مقدار و دو فرزند `bst` دارد (که هر کدام از آن‌ها یا `leaf` است یا `branch`).

## ترتیب‌دهی

داده را با `before=?` (از `math.order`) مقایسه کنید؛ این مقایسه هم روی رشته‌ها کار می‌کند و هم روی اعداد. تست‌ها از داده‌های رشته‌ای مانند `"1"`، `"2"`، `"3"` استفاده می‌کنند.
