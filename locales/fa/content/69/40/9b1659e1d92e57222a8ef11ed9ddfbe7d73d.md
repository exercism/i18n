# مقدمه

همانند ویژگی‌ها که داده‌ها را در `struct`ها و `class`های شما ذخیره می‌کنند، می‌توانید «روش»ها را هم تعریف کنید. روش‌ها توابع را در `struct` یا `class` شما ذخیره می‌کنند.

روش‌ها درست به همان شیوه‌ی یک تابع معمولی تعریف می‌شوند؛ تنها تفاوت این است که داخل بدنه‌ی `struct` یا `class` قرار می‌گیرند. توجه کنید که اگر یک تابع مقدار یک ویژگی را در یک `struct` تغییر دهد، باید پیش از آن «کلیدواژه‌ی `mutating`» بیاید. به‌علاوه، اگر یک روش بتواند یک ویژگی را تغییر دهد، آن ویژگی باید مانند متغیرهای معمولی با `var` تعریف شود، نه با `let`.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

این روش‌ها را هم می‌توان مانند ویژگی‌ها با نقطه‌گذاری فراخوانی کرد.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
