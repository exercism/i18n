## نصب Z3

### دانلود Python (اگر هنوز نصب نشده است)

آخرین نسخه‌ی Python را می‌توانید از [اینجا](https://python.org) دانلود کنید.

* هنگام نصب، حتماً کادری را انتخاب کنید که Python را به PATH اضافه می‌کند

### دانلود Visual Studio (اگر هنوز نصب نشده است)

آخرین نسخه‌ی Visual Studio را می‌توانید از [اینجا](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019) دانلود کنید.

* هنگام نصب، بار کاری **«Python Development»** را انتخاب کنید
* در سمت راست، همه‌ی کادرهای انتخاب بسته‌های توسعه‌ی اختیاری Python را تیک بزنید

پس از نصب، Visual Studio را باز کنید و تنظیمات اولیه‌ی خود را انجام دهید.

### نصب دستورهای Git

دستورالعمل‌های نصب Git را می‌توانید [اینجا](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) پیدا کنید.

* باید [Git را به متغیرهای سیستم خود اضافه کنید](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### کلون کردن Z3

برای مشاهده‌ی پروژه، به [مخزن GitHub پروژه‌ی Z3](https://github.com/Z3Prover/z3) بروید.

یک ترمینال روی رایانه‌ی خود باز کنید و به مسیری بروید که می‌خواهید مخزن Z3 را در آن کلون کنید (مثال: C:\Z3).

از همان مسیر، این دستور را اجرا کنید:

```bash
git clone https://github.com/z3Prover/z3.git
```

### ساخت Z3 در ویندوز با استفاده از Visual Studio Command Prompt

از منوی Start، **Developer Command Prompt for VS 2019** را باز کنید.

به پوشه‌ای بروید که مخزن Z3 را در آن کلون کرده‌اید (مثال: C:\Z3).

برای ساخت ۳۲بیتی، این دستور را اجرا کنید:

```bash
python scripts/mk_make.py
```

برای ساخت ۶۴بیتی، این دستور را اجرا کنید:

```bash
python scripts/mk_make.py -x
```

سپس این دستور را اجرا کنید:

```bash
cd build
pip install z3-solver
```



اکنون باید بتوانید Visual Studio را باز کنید و Z3 را با اتصال Python آن اجرا کنید.


برای آزمایش، می‌توانید این کد را اجرا کنید:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

دو خط آخر باید `sat` و `[y = 4, x = 2]` را تولید کنند.
