# نصب

برای نصب Reason به Node Package Manager (npm) نیاز دارید. دستورالعمل‌ها را [اینجا](https://www.npmjs.com/get-npm) دنبال کنید.

پس از آنکه npm را نصب کردید، Reason را به این صورت نصب کنید:
```
npm install -g bs-platform
```

Reason با شماری از ویرایشگرها یکپارچه می‌شود؛ [اینجا](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors) را ببینید.

شماری از ابزارهای خط فرمان (از جمله یک REPL که به شما امکان می‌دهد عبارت‌های Reason را در یک پوسته ارزیابی کنید) را می‌توانید [اینجا](https://github.com/reasonml/reason-cli) پیدا کنید.
