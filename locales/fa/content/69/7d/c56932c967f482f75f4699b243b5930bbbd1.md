# کنترل جریان

عبارت‌های `if` و حلقه‌ها جریان اجرا را در Cairo کنترل می‌کنند:
`

- **عبارت `if`** بسته به اینکه یک شرط به `true` ارزیابی شود، کد را به‌صورت شرطی اجرا می‌کند.
- **حلقه** (مانند `loop`، `while` و `for`) تا زمانی که یک شرط مشخص «درست» بماند یا تا وقتی شرط توقف برآورده شود، کد را بارها اجرا می‌کند.

این ساختارها برای پیاده‌سازی منطق و تکرار در Cairo بنیادی‌اند.

## عبارت `if`

عبارت‌های `if` در Cairo به شما امکان می‌دهند جریان اجرا را بر اساس منطق شرطی کنترل کنید.
ساختار آن‌ها به این صورت است که کد بسته به اینکه یک شرط منطقی به `true` یا `false` ارزیابی شود، اجرا می‌شود.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

این مثال یک بلوک `if` ساده را در Cairo نشان می‌دهد.
پیام `"It's hot outside!"` تنها در صورتی چاپ می‌شود که شرط `temperature > 25` به `true` ارزیابی شود.
اگر شرط `false` باشد، هیچ کدی اجرا نمی‌شود و برنامه ادامه می‌یابد.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

اجرای این کد `"The number is less than 10."` را در کنسول چاپ می‌کند.

### مدیریت چند شرط با `else if`

می‌توانید با ترکیب `if` و `else` در یک عبارت `else if` از چند شرط استفاده کنید.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

اجرای این کد `"Grade: B"` را در کنسول چاپ می‌کند.

### استفاده از `if` در دستور `let`

از عبارت `if` در Cairo می‌توان در سمت راست یک دستور `let` استفاده کرد تا نتیجه به یک متغیر اختصاص یابد.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## حلقه

حلقه یک ساختار بنیادی است که امکان تکرار بلوک‌های کد را فراهم می‌کند و اجرای کارآمد و کنترل‌شده‌ی کارها را ممکن می‌سازد.
حلقه می‌تواند روی یک دنباله تکرار کند یا بر اساس یک شرط، کد را بارها اجرا کند.
Cairo سه گونه‌ی اصلی از حلقه ارائه می‌دهد:

- **loop**: حلقه‌ای پایه که تا زمانی که با یک دستور `break` به‌صراحت متوقف نشود، بی‌پایان اجرا می‌شود.
- **while**: تا زمانی که یک شرط مشخص `true` بماند، به اجرا ادامه می‌دهد.
  وقتی شرط `false` شود، متوقف می‌شود.
- **for**: روی عنصرهای یک مجموعه، مانند آرایه‌ها، تکرار می‌کند و برای هر عنصر کد را اجرا می‌کند.

### تکرار کد با `loop`

کلیدواژه‌ی `loop` به Cairo می‌گوید که یک بلوک کد را بارها و بارها تا ابد اجرا کند، یا تا زمانی که شما به‌صراحت به آن دستور توقف بدهید.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

اجرای این کد `"again!"` را به‌طور نامحدود در کنسول چاپ می‌کند، تا اینکه یا گاز برنامه تمام شود یا خودمان آن را متوقف کنیم.

> توجه: Cairo با گنجاندن یک گازسنج، جلوی اجرای برنامه‌ای با حلقه‌های بی‌نهایت را می‌گیرد.
> گازسنج سازوکاری است که میزان محاسبه‌ای را که می‌توان در یک برنامه انجام داد محدود می‌کند.
> گاز یکای اندازه‌گیری است که هزینه‌ی محاسباتی یک دستور را بیان می‌کند.
> وقتی گازسنج تمام شود، برنامه متوقف می‌شود.

برای خارج شدن از یک حلقه، کلیدواژه‌ی `break` را درون حلقه قرار دهید تا به برنامه بگویید چه زمانی اجرای آن را متوقف کند.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

کلیدواژه‌ی `continue` به برنامه می‌گوید که به تکرار بعدی حلقه برود و بقیه‌ی کد این تکرار را نادیده بگیرد.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

اجرای این برنامه مقدار `i` را وقتی برابر با `5` است چاپ نمی‌کند.

#### بازگرداندن مقدار از `loop`

می‌توانید با استفاده از کلیدواژه‌ی `break` که پس از آن مقداری می‌آید که می‌خواهید بازگردانید، مقداری را از یک `loop` بازگردانید.
این کار به شما امکان می‌دهد از `loop` خارج شوید و نتیجه‌ای را به بقیه‌ی کد خود بدهید.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### حلقه‌های شرطی با `while`

`while` تا زمانی که یک شرط `true` است کد را اجرا می‌کند و وقتی شرط `false` شود، خارج می‌شود.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### پیمایش یک مجموعه با `for`

`for` روی هر عنصر یک مجموعه تکرار می‌کند و برای هر عنصر کد را اجرا می‌کند.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
