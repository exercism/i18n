# دستورالعمل‌ها

در این تمرین، خط‌هایی از یک گزارش ثبت‌شده را پردازش می‌کنید.
هر خط لاگ، رشته‌ای است که به این شکل قالب‌بندی شده است: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ مختلف وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه وظیفه دارید که هر کدام یک خط لاگ می‌گیرد و از شما می‌خواهد کاری روی آن انجام دهید.

## 1. گرفتن پیام از یک خط لاگ

متد `log_line::message` را پیاده‌سازی کنید تا پیام یک خط لاگ را برگرداند:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. گرفتن سطح لاگ از یک خط لاگ

متد `log_line::log_level` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف بزرگ برگردانده شود:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. قالب‌بندی دوباره‌ی یک خط لاگ

متد `log_line::reformat` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند، به این صورت که پیام اول می‌آید و سطح لاگ بعد از آن داخل پرانتز قرار می‌گیرد:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
