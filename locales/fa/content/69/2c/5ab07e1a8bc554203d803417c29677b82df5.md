# مقدمه

## تاپل

در Elixir، تاپل یک ساختار داده است که داده‌ها را سازمان‌دهی می‌کند و تعداد ثابتی عنصر از هر نوعی را در خود نگه می‌دارد، اما هیچ نام مشخصی برای تک‌تک عناصر آن وجود ندارد. از تاپل‌ها در Elixir اغلب برای عملیات پرمصرف از نظر خواندن حافظه استفاده می‌شود، چون دسترسی خواندنی به یک عنصر یک عملیات با زمان ثابت است. معمولاً وقتی که ممکن است عناصر به‌صورت پویا اضافه یا حذف شوند از آن‌ها استفاده نمی‌شود، چون به‌جای تغییر تاپل موجود، یک تاپل تازه ساخته می‌شود که نیازمند تخصیص حافظه از پیش است.

در عمل، تاپل‌ها در Elixir با آکولاد ساخته می‌شوند. می‌توان با تابع `elem/2` و با ایندکس‌گذاری از صفر، جداگانه به هر عنصر یک تاپل دسترسی داشت:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### تاپل به‌عنوان اطلاعات گروه‌بندی‌شده

در عمل اغلب از تاپل‌ها برای نمایش اطلاعات گروه‌بندی‌شده استفاده می‌شود.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## تطبیق الگو

استفاده از تطبیق الگو در کد اصیل و قطعیت‌گرای Elixir غالب است. شاید به یاد بیاورید که `=/2` را به‌جای یک عملگر انتساب، «عملگر تطبیق» می‌دانند. وقتی از عملگر تطبیق استفاده می‌کنید، اگر الگوی سمت چپ با سمت راست منطبق باشد، هر متغیری که در سمت چپ باشد مقید می‌شود و مقدار سمت راست بازگردانده می‌شود. اگر تطابقی برقرار نباشد، `MatchError` رخ می‌دهد.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

به یاد داشته باشید که تطبیق‌ها از سمت راست به سمت چپ انجام می‌شوند.

در مثال آخر، اگر در یک تطبیق الگو به متغیری نیاز نداشته باشیم، می‌توانیم با ارجاع به `_` از آن صرف‌نظر کنیم. هیچ متغیری که با `_` شروع شود، توسط زمان اجرا ردیابی نمی‌شود.

### تطبیق الگو در توابع نامدار

تطبیق الگو ابزار مفیدی هم برای ساختن چندین بند تابع است. می‌توان از تطبیق الگو روی آرگومان‌های تابع استفاده کرد و همین مشخص می‌کند که کدام بند تابع فراخوانی شود، از بالای فایل به سمت پایین تا نخستین تطبیق. متغیرها ممکن است در سر تابع مقید شوند و در بدنه‌ی تابع به کار روند.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
