# درباره

متغیرهایی که با «کلیدواژه»ی `final` به‌جای `var` تعریف می‌شوند، فقط یک بار می‌توان به آن‌ها مقدار داد.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

توجه به این نکته مهم است که `final` ممکن است روی انواعی که تغییرناپذیر نیستند، مثل آرایه‌ها یا اشیاء، اثر مورد نظر را نداشته باشد:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
