# درباره

متغیرهای محلی جای کد پشته‌ای را نمی‌گیرند، بلکه در کنار آن قرار دارند. در این موقعیت‌ها به سراغشان بروید:

- ورودی یکسانی بیش از یک بار ارجاع داده می‌شود.
- ترتیب طبیعی عملیات با ترتیب پشته هماهنگ نیست.
- داخل یک تابع مرتبه‌بالاتر هستید که چند مقدار را همزمان به لامبدا می‌دهد (`( key value -- newkey newvalue )` در `assoc-map`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` اتصال‌های محلی را داخل یک نقل‌قول یا در listener معرفی می‌کند، جایی که `:>` در غیر این صورت هیچ حوزه‌ی واژگانی‌ای برای اتصال ندارد:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

پسوند تغییر `:>` به شما امکان می‌دهد یک متغیر محلی را دوباره اتصال دهید؛ در حلقه‌هایی با حال‌وهوای دستوری مفید است:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
