# درباره

C++ هم مانند زبان‌های دیگر دستور `switch` را ارائه می‌دهد.
دستورهای `switch` روشی کوتاه‌تر برای نوشتن دستورهای طولانی `if ... else if` هستند.
برای ساختن یک `switch`، ابتدا از «کلیدواژه»ی `switch` استفاده می‌کنیم و پس از آن یک عدد صحیح می‌نویسیم.
سپس هر یک از شرط‌ها را با کلیدواژه‌ی `case` تعریف می‌کنیم.
همچنین می‌توانیم حالت `default` را تعریف کنیم که وقتی هیچ‌یک از شرط‌های `case` قبلی مطابقت نداشت، اجرا می‌شود.
هر حالت باید با یک دستور `break` (یا `return`) پایان یابد.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## عبور به حالت بعدی

یک نکته‌ی مهم درباره‌ی ساختار `switch` این است که کد تا زمانی که با یک دستور `break` (یا `return`) متوقف نشود، به اجرا ادامه می‌دهد.
این موضوع می‌تواند به رفتاری غیرمنتظره منجر شود.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

کاربرد اصلی این ویژگیِ ادامه‌ی اجرا، دستوری است که چندین «برچسب» دارد.
می‌توان چندین نتیجه‌ی `switch` را به یک قطعه‌کد یکسان برای اجرا نسبت داد.
به این ترتیب، مثلاً در یک برنامه‌ی رزرو، تابعی که برای اندازه‌ی گروه ۲ و ۳ فراخوانی می‌شود می‌تواند یکی باشد:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
همان‌طور که دیدید، دستور `switch` در C++ در مقایسه با زبان‌های دیگر بسیار محدود است.
بسیاری از زبان‌ها می‌توانند `switch` را بر پایه‌ی عبارت‌های «منطقی» یا حتی عبارت‌های باقاعده انجام دهند.
می‌توانید نسخه‌ی C++ را یک ساختار گسترده‌ی goto/switch در نظر بگیرید.
تنها دستور `switch` می‌تواند به یک برچسب بپرد.
پس از آن، همه‌ی برچسب‌های دیگر نادیده گرفته می‌شوند و برای خارج شدن از «بلوک کد» باید از دستور `break` استفاده کنید.
~~~~
