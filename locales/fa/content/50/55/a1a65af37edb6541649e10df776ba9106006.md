# Tests

برای اجرای testها، دستور زیر را اجرا کنید:

```bash
make
```

## testهای نادیده‌گرفته‌شده

حل کردن یک تمرین یعنی کاری کنید که همه‌ی testهای آن پاس شوند.
به‌طور پیش‌فرض، هنگام اجرای testها فقط یک test (اولین test) اجرا می‌شود.
این کار عمدی است تا بتوانید فقط روی پاس کردن همان یک test تمرکز کنید.
وقتی پاس شد، می‌توانید خط `TEST_IGNORE()` را حذف کنید و test بعدی را فعال کنید.
وقتی همه‌ی testها فعال شدند و پیاده‌سازی شما همه‌ی آن‌ها را پاس کند، تمرین را حل کرده‌اید!

## Debugging

برای کمک به Debug کردن، ماکروهای گوناگونی در فایل `debug.mac` تعریف شده‌اند.
می‌توان آن‌ها را با یک یا چند آرگومان با اندازه‌ی مناسب فراخوانی کرد.
برای مثال:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

برای استفاده از هر یک از این ماکروها، باید `debug.mac` در بالای فایل راه‌حل گنجانده شود:

```x86asm
%include "debug.mac"
```
