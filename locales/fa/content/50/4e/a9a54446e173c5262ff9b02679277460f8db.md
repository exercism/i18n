# دستورالعمل‌ها

در این تمرین، شما با بهترین دوستانتان مشغول بازی کردن یک بازی نقش‌آفرینی به نام «جادوگر و جنگجویان» هستید. شما «استاد بازی» هستید، همان کسی که وظیفه دارد دنیای بازی را برای بازیکنان زنده کند. یک جنبه‌ی کلیدی این کار، توصیف بازی برای بازیکنان است: وضعیت یک شخصیت چیست، شهری که به آن سر می‌زنند چه شکلی است و غیره.

پنج وظیفه دارید که در آن‌ها بخش‌هایی از بازی را برای بازیکنان توصیف می‌کنید.

## 1. یک شخصیت را توصیف کنید

هر شخصیت یک کلاس، یک سطح و تعدادی نقاط جان دارد و به این شکل توصیف می‌شود: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. متد (استاتیک) `GameMaster.Describe` را پیاده‌سازی کنید که یک `Character` را به عنوان تنها پارامترش می‌گیرد و توصیف آن را برمی‌گرداند.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. یک مقصد را توصیف کنید

هر مقصد یک اسم و تعدادی ساکن دارد و به این شکل توصیف می‌شود: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. متد (استاتیک) `GameMaster.Describe` را پیاده‌سازی کنید که یک `Destination` را به عنوان تنها پارامترش می‌گیرد و توصیف آن را برمی‌گرداند.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. روش سفر را توصیف کنید

شخصیت‌ها می‌توانند با یکی از دو گزینه به مقصد سفر کنند:

- پیاده، که این‌گونه توصیف می‌شود: `"You're traveling to your destination by walking."`
- سواره، که این‌گونه توصیف می‌شود: `"You're traveling to your destination on horseback."`

متد (استاتیک) `GameMaster.Describe` را پیاده‌سازی کنید که یک `TravelMethod` را به عنوان تنها پارامترش می‌گیرد و توصیف آن را برمی‌گرداند.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. شخصیتی را توصیف کنید که به مقصدی سفر می‌کند

وقتی شخصیتی به مقصدی سفر می‌کند، این وضعیت به شکل ترکیبی از توصیف‌های جداگانه بیان می‌شود: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. متد (استاتیک) `GameMaster.Describe` را پیاده‌سازی کنید که یک `Character`، یک `Destination` و یک `TravelMethod` را به عنوان پارامترهایش می‌گیرد و توصیف آن را برمی‌گرداند.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. توصیف شخصیتی که بدون تعیین روش سفر به مقصدی سفر می‌کند

در بیشتر موارد، شخصیت‌ها پیاده به مقصد سفر می‌کنند. برای راحتی، بازیکنان می‌توانند ذکر روش سفرشان را حذف کنند؛ در این صورت فرض می‌شود که روش سفر پیاده است. متد (استاتیک) `GameMaster.Describe` را پیاده‌سازی کنید که یک `Character` و یک `Destination` را به عنوان پارامترهایش می‌گیرد و توصیف آن را برمی‌گرداند.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
