# درباره

از عبارت‌های شرطی برای اجرای کد بر اساس این استفاده می‌شود که یک شرط **«درست»** است یا **«غلط»**. این عبارت‌ها به این شکل نوشته می‌شوند:

```haxe
if (condition) {
  expressions
};
```

خروجی شرط از نوع `Bool` است؛ بنابراین وقتی خروجی `true` باشد، عبارت‌ها اجرا می‌شوند.

گاهی اوقات، وقتی شرط در واقع `false` است، می‌خواهیم بخش دیگری از کد اجرا شود. اینجاست که عبارت `else` به کار می‌آید. `else` وقتی عبارت‌ها را اجرا می‌کند که شرط اولیه `false` باشد. اما اگر بخواهیم شرط را برای چند حالت مختلف بررسی کنیم چه؟ در این صورت از `else if (condition)` استفاده می‌کنیم. در ادامه یک نمونه‌ی کامل می‌آید:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
