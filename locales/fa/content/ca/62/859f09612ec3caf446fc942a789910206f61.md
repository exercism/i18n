# اجرای Testها

می‌توانید SWI Prolog را به‌صورت تعاملی به کار ببرید یا آن را مستقیماً از خط فرمان اجرا کنید.

## خط فرمان

برای اجرای Testها از خط فرمان، می‌توانید از دستور زیر استفاده کنید:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>` را با اسم تمرینی که در حال پیاده‌سازی آن هستید جایگزین کنید.

## تعاملی

برای اجرای prolog به‌صورت تعاملی، ابتدا این دستور را اجرا کنید:

```bash
swipl
```

پس از اینکه کنسول prolog بالا آمد، پیاده‌سازی خود را بارگذاری کنید و Testها را با دستور زیر اجرا کنید:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>` را با اسم تمرینی که در حال پیاده‌سازی آن هستید جایگزین کنید.

### بارگذاری مجدد تغییرات

پس از آنکه فایل‌های بالا بارگذاری شدند، می‌توانید تغییرهایی را که داده‌اید با اجرای دستور زیر اعمال کنید:

```
?- make.
```

## Testهای نادیده‌گرفته‌شده

وقتی اولین بار یک تمرین را شروع می‌کنید، فقط اولین Test اجرا می‌شود. بقیه با افزودن `condition(pending)` به هدف `test` نادیده گرفته شده‌اند.
وقتی اولین Test موفق شد، Test بعدی را با تغییر دادن `pending` در `condition(pending)` به `true` از حالت نادیده‌گرفته‌شده درآورید.
این کار را برای هر Test تکرار کنید تا همه‌شان اجرا شوند و موفق شوند.

### خط فرمان

برای اینکه Testهای در انتظار هم اجرا شوند، آرگومان `-- --all` را به انتهای دستور اضافه کنید:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
