# مقدمه

توابع و متدهای Go می‌توانند چندین مقدار بازگردانند:

```go
func GetCard() (Card, error) { ... }
```

هر مقدار بازگشتی باید به ترتیب تخصیص داده شود و با کاما از هم جدا شود:

```go
card, err := GetCard()
```

هر جایگاه در این تخصیص، یک متغیر تعریف می‌کند.
اگر متغیر تعریف‌شده‌ای هیچ‌جا استفاده نشود، Go کامپایل نمی‌کند.
شناسه‌ی خالی `_` جای اسم متغیر را می‌گیرد تا از آن مقدار بازگشتی صرف‌نظر کند:

```go
card, _ := GetCard()
```

`error` یک واسط توکار است.
خطای `nil` یعنی خطایی رخ نداده است؛ هر مقداری که `nil` نباشد یعنی مشکلی پیش آمده است.
طبق قرارداد، توابعی که ممکن است شکست بخورند باید `error` را به عنوان آخرین مقدار خود بازگردانند.
فراخوان باید پیش از استفاده از سایر مقادیر بازگشتی، آن را بررسی کند:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
