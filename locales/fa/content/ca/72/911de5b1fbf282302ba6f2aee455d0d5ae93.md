# مقدمه

## «شمارشی»

تا اینجا بیشتر با اعداد و رشته‌ها سروکار داشته‌ایم.
برای مدل‌سازی دنیای واقعی، ممکن است بخواهیم تعداد محدودی مقدار را در اختیار داشته باشیم که یک متغیر می‌تواند بپذیرد.
ممکن است بخواهید نوعی اختصاصی با چند مقدار متمایز و نام‌های متمایز داشته باشید.
برای نمونه، در یک کارخانه‌ی اسکیت‌سازی، جنس تخته فقط یکی از سه گزینه‌ی maple، bamboo یا plastic باشد.

می‌توانستید برای کدگذاری این مقادیر از اعداد صحیح استفاده کنید، اما باید کد اضافی‌ای می‌نوشتید تا بررسی کنید آیا مقدار نامعتبری برای جنس از سمت سیستم می‌آید یا نه.
ردیابی معنای این [_اعداد جادویی_][magic numbers] در سراسر کد منبع دشوار است و این اعداد به‌آسانی با هم اشتباه گرفته می‌شوند.
از `enumerations` می‌توان برای تشویق به نوشتن کدی گویاتر و جلوگیری از اشتباهات مقایسه‌ای ناخواسته استفاده کرد.

## نمونه‌ی استفاده

اصطلاح دقیق برای این نوع شمارشی، `scoped enumeration` است.
قطعه‌کد زیر نشان می‌دهد چگونه یک `enumeration` با نام `DeckMaterial` بنویسیم.
به کلیدواژه‌ی `enum class` و `;` در پایان تعریف توجه کنید:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```

حالا به یک تابع قیمت‌گذاری در فروشگاه اسکیت نگاه کنید و به عملگر تفکیک دامنه (`::`) توجه کنید که یک `enumerator` را از `enumeration` مشخص می‌کند:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## دامنه

تصور کنید یک `enumeration` دوم برای جنس چرخ دارید:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```

هرچند هم چرخ‌ها و هم تخته می‌توانند از _plastic_ ساخته شوند، این دو را نمی‌توان با هم اشتباه گرفت.
آن‌ها دو _نوع_ متفاوت‌اند: plastic از نوع `DeckMaterial` و plastic از نوع `WheelMaterial`.
هر `enumeration`، `enumerators` خود را در دامنه‌ی خودش دارد؛ یعنی `namespace` خودش.
به همین دلیل است که به آن‌ها `scoped enumerations` می‌گویند.

## شمارشی بدون دامنه

ممکن است فکر کنید وقتی نامی مثل `scoped` وجود دارد، پس شمارشی‌های _`unscoped`_ هم وجود دارند، و حق با شماست.
`Unscoped enumerations` کم‌کم محبوبیت خود را از دست می‌دهند، چون همگی یک فضای نام سراسری مشترک دارند.
به خاطر همین اشتراک، نمی‌توانستید دو `unscoped enumerations` داشته باشید که `enumerators` یکسانی مثل _plastic_ در مثال بالا داشته باشند.

همچنین `unscoped enumerations` به‌طور ضمنی به اعداد صحیح تبدیل می‌شوند.
برای دیدن یک نتیجه‌ی غافلگیرکننده به مثال زیر نگاه کنید:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

اگر می‌خواهید `scoped enumerations` را به اعداد صحیح تبدیل کنید، می‌توانید از `static_cast<int>` استفاده کنید.

## دستور `switch`

C++ هم مانند زبان‌های دیگر، دستور `switch` را در اختیار می‌گذارد.
دستورهای `switch` روش کوتاه‌تری برای نوشتن دستورهای طولانی `if ... else if` هستند.
برای ساختن یک `switch`، با کلیدواژه‌ی `switch` شروع می‌کنیم و بعد از آن یک عدد صحیح می‌آید.
سپس هر یک از شرط‌ها را با کلیدواژه‌ی `case` اعلام می‌کنیم.
همچنین می‌توانیم یک حالت `default` تعریف کنیم که وقتی هیچ‌یک از شرط‌های `case` قبلی برقرار نبودند اجرا می‌شود.
هر حالت باید با یک دستور `break` (یا `return`) پایان یابد.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## عبور به مورد بعدی

یک نکته‌ی مهم درباره‌ی ساختار switch این است که کد به اجرای خود ادامه می‌دهد تا اینکه با یک دستور `break` (یا `return`) متوقف شود.
این می‌تواند به رفتار غیرمنتظره‌ای منجر شود.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

کاربرد اصلی این ویژگی ادامه‌ی اجرا، دستوری است که چند برچسب دارد.
می‌توان چند نتیجه‌ی switch را به یک قطعه‌کد یکسان برای اجرا نگاشت کرد.
به این ترتیب، مثلاً در یک اپلیکیشن رزرو، تابع فراخوانی‌شده برای اندازه‌های گروه ۲ و ۳ می‌تواند یکی باشد:

```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
