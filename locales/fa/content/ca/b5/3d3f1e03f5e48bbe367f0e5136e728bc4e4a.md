# مقدمه

## آرایه و بردار

C++ برای ذخیره‌ی «عنصر»های هم‌نوع به صورت مرتب، «ظرف»های مختلفی ارائه می‌دهد. `std::array` برای ظرف‌هایی با اندازه‌ی ثابت وجود دارد و `std::vector` که قابلیت تغییر اندازه‌ی پویا دارد.

### ساخت

وقتی یک «آرایه» یا «بردار» تعریف می‌کنید، باید نوع عناصری را مشخص کنید که آن ظرف نگه می‌دارد. آرایه هم به یک اندازه نیاز دارد. برای دیدن نحوه‌ی مقداردهی اولیه‌ی این دو نوع ظرف، به این مثال‌ها نگاه کنید:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

بردار معمولاً به فضای بیشتری نیاز دارد، چون برای رشد بیشتر حافظه اختصاص می‌دهد. لازم نیست اندازه را مشخص کنید:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> نکته: لازم نیست مکانیزم دقیق پشت مفهوم `template` را از الان بدانید؛ این مفهوم پایین‌تر در درخت برنامه‌ی درسی، بخش خودش را خواهد داشت.

### دسترسی به عناصر

بردار و آرایه توابع یکسانی برای دسترسی به عناصرشان دارند. می‌توانید از توابع عضو `front` و `back` برای به دست آوردن اولین و آخرین عنصر ظرف استفاده کنید. همچنین `at` و عملگر `[]` برای دسترسی به عناصر مشخص وجود دارند.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> نکته: اگر موقعیتی را انتخاب کنید که در محدوده‌ی ظرف شما نباشد، `[]` ممکن است به رفتار تعریف‌نشده منجر شود. تابع `at` یک استثنا ایجاد می‌کند که در درازمدت می‌تواند کار شما را راحت‌تر کند.

### تغییردهنده‌های بردار

از آنجا که اندازه‌ی `vector` ثابت نیست، می‌توان عنصر اضافه یا حذف کرد. دو تابع رایج برای این کار `emplace_back` و `pop_back` هستند.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### ظرفیت

می‌توانید خالی بودن ظرف‌ها را با تابع عضو `empty` بررسی کنید. اگر می‌خواهید تعداد عناصر را بدانید، می‌توانید از `size` استفاده کنید.
