# درباره

هکس از «عبارت‌های باقاعده» به‌صورت توکار پشتیبانی می‌کند. از آن‌ها می‌توان برای بررسی قالب یک رشته، تبدیل یک رشته، یا استخراج داده‌های مشخصی از یک متن داده‌شده استفاده کرد.

برای ساختن یک عبارت باقاعده، بین `~/` و `/` تایپ کنید:

```haxe
var r = ~/haxe/i;
```

روش دیگری برای انجام این کار، استفاده از نمونه‌ی `EReg()` است:

```haxe
var r = new EReg("haxe", "i");
```

در اینجا `i` یک «پرچم» است که باعث می‌شود الگو به بزرگی و کوچکی حروف حساس نباشد. پرچم‌های دیگری هم هست، از جمله:

- `g`: جایگزینی سراسری.
- `m`: تطبیق چندخطی

بین `~/` و `/`، الگوهای عبارت باقاعده را تایپ می‌کنید. برای مثال، می‌خواهید رشته‌ای را پیدا کنید که حروفی از A تا Z داشته باشد. اینجا می‌توانیم از الگوی بازه‌ی `[A-Z]` استفاده کنیم. الگوهای عبارتی زیادی وجود دارد، از جمله:

- `.`: هر کاراکتری
- `*`: تکرار صفر بار یا بیشتر
- `+`: تکرار یک بار یا بیشتر
- `[A-Z0-9]`: بازه‌های کاراکتر
