# مقدمه

## منطقی

در Elixir، مقادیر «درست» و «غلط» با نوع داده‌ی «منطقی» نمایش داده می‌شوند. فقط دو مقدار وجود دارد: `true` و `false`. می‌توان این مقادیر را به یک متغیر نسبت داد:

```elixir
true_variable = true
false_variable = false
```

می‌توانیم عبارت‌های منطقی سخت‌گیرانه را با عملگرهای `and/2`، `or/2` و `not/1` ارزیابی کنیم.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

وقتی تابعی می‌نویسید که یک مقدار منطقی برمی‌گرداند، مرسوم است که اسم تابع را با `?` تمام کنید. همین قرارداد را می‌توان برای متغیرهایی به کار برد که مقادیر منطقی را نگه می‌دارند.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
