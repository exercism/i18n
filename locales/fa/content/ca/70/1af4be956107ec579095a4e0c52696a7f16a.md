# دستورالعمل‌ها

شما در یک شهربازی کار می‌کنید و مشخصاتی به شما داده شده است تا سامانه‌ای را برای مدیریت ورود بازدیدکنندگان و وسایل بازی طراحی کنید. وظیفه‌ی شما مدل‌سازی بازدیدکننده (شخصی که از پارک بازدید می‌کند) است.

## 1. بازدیدکننده‌های جدید بسازید

متد `Attendee#initialize` از کلاس `Attendee` را پیاده‌سازی کنید؛ این متد باید یک قد (به سانتی‌متر) بگیرد و آن را در یک «متغیر نمونه» ذخیره کند.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. قد بازدیدکننده چقدر است

متد گیرنده‌ی `Attendee#height` از کلاس `Attendee` را پیاده‌سازی کنید؛ این متد باید قد نمونه را برگرداند.

```ruby
Attendee.new(106).height
# => 106
```

## 3. شناسه‌ی بلیت سواری چیست

همه‌ی بازدیدکننده‌ها بلیت سواری نخریده‌اند، اما باید بدانیم بلیت دارند یا نه. متد گیرنده‌ی `Attendee#pass_id` را برای کلاس `Attendee` پیاده‌سازی کنید؛ این متد باید `pass_id` نمونه را برگرداند، یا اگر بازدیدکننده بلیت ندارد، `nil` را برگرداند.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. به افراد اجازه دهید بلیت بخرند

متد `Attendee#issue_pass!` را پیاده‌سازی کنید تا وضعیت نمونه را تغییر دهد و متغیر نمونه‌ی شناسه‌ی بلیت را برابر آرگومان قرار دهد. این متد باید شناسه‌ی بلیت را برگرداند.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. بلیت را باطل کنید

برخی مهمان‌ها با رفتار ناایمن قوانین را زیر پا می‌گذارند، بنابراین پارک می‌خواهد بتواند بلیت‌ها را باطل کند. متد `Attendee#revoke_pass!` را پیاده‌سازی کنید تا وضعیت نمونه را تغییر دهد و شناسه‌ی بلیت را برابر `nil` قرار دهد.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
