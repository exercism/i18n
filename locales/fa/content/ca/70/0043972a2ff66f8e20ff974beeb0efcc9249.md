# پیوست دستورالعمل‌ها

## کار با تاریخ‌ها در Prolog

پشتیبانی توکار Prolog از تاریخ‌ها [نسبتاً ابتدایی است][built-in-dates-support].
هرچند می‌توانید این تمرین را فقط با همان امکانات توکار Prolog حل کنید، روش بسیار بهتری برای کار با تاریخ‌ها استفاده از [بسته‌ی date_time][date-time-package] است.

### نصب بسته‌ی date_time

اگر نسخه‌ی نصب‌شده‌ی Swipl شما به‌اندازه‌ی کافی به‌روز باشد، می‌توانید این بسته را با اجرای دستور زیر نصب کنید:

```bash
swipl pack install date_time
```

اگر این کار جواب نداد، می‌توانید این دستور را اجرا کنید:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
اگر از ویرایشگر آنلاین استفاده می‌کنید، نیازی نیست چیزی را به‌صورت دستی نصب کنید.
~~~~

### استفاده از بسته‌ی date_time

برای استفاده از بسته‌ی `date_time`، کد زیر را به ابتدای فایل راه‌حل خود اضافه کنید:

```prolog
:- use_module(library(date_time)).
```
