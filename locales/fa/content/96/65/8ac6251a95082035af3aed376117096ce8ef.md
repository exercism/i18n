# دستورالعمل‌ها

در این تمرین قرار است کدی بنویسید که به شما در آماده‌شدن برای خرید یک وسیله‌ی نقلیه کمک کند.

سه کار پیش رو دارید: یکی تعیین اینکه به گواهینامه نیاز دارید یا نه، یکی کمک به انتخاب بین دو وسیله‌ی نقلیه و یکی تخمین زدن قیمت قابل‌قبولی که برای یک وسیله‌ی نقلیه‌ی دست‌دوم منصفانه است.

## 1. تعیین کنید که به گواهینامه‌ی رانندگی نیاز خواهید داشت یا نه

رانندگی با برخی از انواع وسیله‌ی نقلیه به گواهینامه‌ی رانندگی نیاز دارد.
فرض کنید فقط انواع `"car"` و `"truck"` به گواهینامه نیاز دارند و از بقیه می‌توان بدون گواهینامه استفاده کرد.

تابع `NeedsLicense(kind)` را پیاده‌سازی کنید که نوع وسیله‌ی نقلیه را می‌گیرد و یک مقدار «منطقی» برمی‌گرداند که نشان می‌دهد آیا برای همان نوع وسیله به گواهینامه نیاز دارید یا نه.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. انتخاب بین دو وسیله‌ی نقلیه‌ی بالقوه برای خرید

شما گزینه‌های وسیله‌های نقلیه‌ی موجود را بررسی می‌کنید.
موفق می‌شوید آن‌ها را به دو گزینه محدود کنید، اما برای گرفتن تصمیم نهایی به کمک نیاز دارید.
برای این کار، تابع `ChooseVehicle(option1, option2)` را پیاده‌سازی کنید که دو وسیله‌ی نقلیه را به عنوان آرگومان می‌گیرد و تصمیمی برمی‌گرداند که شامل گزینه‌ای است که در ترتیب واژه‌نامه‌ای اول می‌آید.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. محاسبه‌ی تخمینی برای قیمت یک وسیله‌ی نقلیه‌ی دست‌دوم

حالا که تصمیم‌تان را گرفته‌اید، می‌خواهید مطمئن شوید که در نمایندگی قیمت منصفانه‌ای می‌پردازید.
چون می‌خواهید یک وسیله‌ی نقلیه‌ی دست‌دوم بخرید، قیمت به عمر وسیله بستگی دارد.
برای یک تخمین تقریبی، فرض کنید اگر عمر وسیله کمتر از ۳ سال باشد، ۸۰٪ قیمت اصلی‌اش را دارد، یعنی همان قیمتی که وقتی کاملاً نو بود.
اگر حداقل ۱۰ سال عمر داشته باشد، ۵۰٪ قیمت اصلی را دارد.
اگر عمر وسیله حداقل ۳ سال ولی کمتر از ۱۰ سال باشد، ۷۰٪ قیمت اصلی را دارد.

تابع `CalculateResellPrice(originalPrice, age)` را پیاده‌سازی کنید که این منطق را با استفاده از `if`، `else if` و `else` اعمال می‌کند (اگر می‌خواهید تمرین کنید، راه‌های دیگری هم هست).
این تابع قیمت اصلی و عمر وسیله‌ی نقلیه را به عنوان آرگومان می‌گیرد و قیمت تخمینی در نمایندگی را برمی‌گرداند.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**توجه** مقدار بازگشتی یک `float64` است.
