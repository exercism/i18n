# درباره

در C#، از [لیترال `null`][null-keyword] برای نشان دادن نبود یک مقدار استفاده می‌شود. نوع _«نالپذیر»_ نوعی است که مقادیر `null` را می‌پذیرد.

پیش از C# ۸.۰، نوع‌های ارجاعی همیشه نالپذیر بودند، اما نوع‌های مقداری این‌طور نبودند. با این حال، با افزودن علامت سؤال (`?`) به آن، [می‌توان یک نوع مقداری را نالپذیر کرد][nullable-value-types].

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

دسترسی به عضوی از متغیری که مقدارش `null` است، بدون مشکل کامپایل می‌شود، اما در زمان اجرا به پرتاب شدن یک `NullReferenceException` می‌انجامد:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

برای مقابله با این نوع خطای رایج، C# ۸ به شما امکان می‌دهد تا [ویژگی‌ای را فعال کنید][nullable-csharp-8] که [نوع‌های ارجاعی را به‌صورت پیش‌فرض غیرنالپذیر می‌کند][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

برای [کار کردن ایمن با مقادیر نالپذیر][nullable-types-tutorial]، بهتر است پیش از کار با آن‌ها بررسی کنید که `null` هستند یا نه:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

عملگر [`??`][null-coalescing-operator] این امکان را می‌دهد که وقتی مقدار `null` است، یک مقدار پیش‌فرض برگردانید:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

عملگر [`?.`][null-conditional-operator] امکان فراخوانی ایمن اعضا را روی مقداری که ممکن است `null` باشد می‌دهد:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

اگر کامپایلر فکر می‌کند که ممکن است یک مقدار `null` باشد، ولی شما مطمئن هستید که نیست، می‌توانید از عملگر [`!.`][null-forgiving-operator] استفاده کنید تا اخطار نمایش داده نشود. با این حال، این عملگر را فقط به‌عنوان آخرین راه‌حل به کار ببرید.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
