# مقدمه

## متغیر

الیکسیر یک زبان با نوع پویا است؛ یعنی نوع متغیر فقط در زمان اجرا بررسی می‌شود. با استفاده از عملگر تطبیق `=` می‌توانیم مقداری از هر نوع را به یک نام متغیر متصل کنیم:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## ماژول

الیکسیر یک [زبان برنامه‌نویسی تابعی][functional-programming] است و لازم است همه‌ی «توابع نامدار» در یک «ماژول» تعریف شوند. از کلیدواژه‌ی `defmodule` برای تعریف ماژول استفاده می‌شود. همه‌ی ماژول‌ها در زمان اجرا برای سایر ماژول‌ها در دسترس هستند و برای قابل مشاهده بودن برای سایر بخش‌های برنامه به «تعدیل‌کننده‌ی دسترسی» نیاز ندارند. یک «ماژول» معادل یک «کلاس» در سایر زبان‌های برنامه‌نویسی است.

```elixir
defmodule Calculator do
  # ...
end
```

## تابع نامدار

«توابع نامدار» باید در یک ماژول تعریف شوند. از کلیدواژه‌ی `def` برای تعریف یک تابع نامدار «عمومی» استفاده می‌شود.

هر تابع می‌تواند صفر یا چند «آرگومان» داشته باشد. مقدار آخرین عبارت در یک تابع همیشه «به‌صورت ضمنی برگردانده می‌شود».

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

برای فراخوانی یک تابع، ماژول و نام تابع آن را مشخص می‌کنید و برای هر یک از آرگومان‌های تابع، آرگومان می‌فرستید.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

از کلیدواژه‌ی `defp` می‌توان به‌جای `def` برای تعریف یک تابع «خصوصی» استفاده کرد. توابع خصوصی فقط از داخل همان ماژولی که آن‌ها را تعریف کرده است قابل استفاده‌اند.

وقتی تابعی را در داخل همان ماژولی که تعریف شده است فراخوانی می‌کنید، می‌توانید نام ماژول را حذف کنید.

همچنین می‌توانید توابع کوتاه را با نگارش یک‌خطی بنویسید (به کاما `,` و دونقطه `:` در اطراف کلیدواژه‌ی `do` توجه کنید).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## تعداد آرگومان تابع

رایج است که توابع را با «تعداد آرگومان»شان بنامیم. «تعداد آرگومان» یک تابع، تعداد آرگومان‌هایی است که می‌پذیرد.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## قرارداد نام‌گذاری

نام ماژول‌ها باید از `PascalCase` استفاده کند. نام ماژول باید با یک حرف بزرگ `A-Z` شروع شود و می‌تواند شامل حروف `a-zA-Z`، اعداد `0-9` و زیرخط `_` باشد.

نام متغیرها و توابع باید از `snake_case` استفاده کند. نام متغیر یا تابع باید با یک حرف کوچک `a-z` یا زیرخط `_` شروع شود، می‌تواند شامل حروف `a-zA-Z`، اعداد `0-9` و زیرخط `_` باشد و ممکن است با علامت سؤال `?` یا علامت تعجب `!` پایان یابد.

## کتابخانه‌ی استاندارد

الیکسیر یک «کتابخانه‌ی استاندارد» بسیار غنی و با مستندات خوب دارد. مستندات آن به‌صورت آنلاین در [hexdocs.pm/elixir][docs] در دسترس است. این پیوند را جایی ذخیره کنید؛ از آن زیاد استفاده خواهید کرد!

بیشتر انواع داده‌ی درونی یک ماژول متناظر دارند که توابعی برای کار با آن نوع داده ارائه می‌دهد، مثلاً ماژول `Integer` برای اعداد صحیح، ماژول `String` برای رشته‌ها، ماژول `List` برای فهرست‌ها و غیره.

یک ماژول قابل توجه، ماژول `Kernel` است. این ماژول توانایی‌های پایه‌ای را فراهم می‌کند که بقیه‌ی کتابخانه‌ی استاندارد روی آن‌ها ساخته شده است، مانند عملگرهای حسابی، ماکروهای کنترل جریان و موارد بسیار دیگر. توابع ماژول `Kernel` به‌طور خودکار وارد می‌شوند، بنابراین می‌توانید بدون پیشوند `Kernel.` از آن‌ها استفاده کنید.
