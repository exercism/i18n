# درباره

هنگام مدل‌سازی داده‌هایی که تنها می‌توانند مجموعه‌ای مشخص از حالت‌های ممکن را بپذیرند، مانند روزهای هفته، جهت‌های قطب‌نما یا دکمه‌های یک دسته‌ی بازی، انواع پایه‌ای مثل `Int` یا `String` اشکالات اساسی دارند.
با اعداد صحیح یا رشته‌ها، کد شما باید مدام مقادیر نامعتبر را بررسی کند (مثل کد وضعیت `999` یا غلط تایپی مثل `"leftt"`)، و خواننده‌های انسانی هم به‌سختی می‌توانند بفهمند این اعداد چه چیزی را نشان می‌دهند.

سوئیفت این مشکل را با [_شمارشی‌ها_][enumerations] (که غالباً به «enum» کوتاه می‌شود) حل می‌کند.
شمارشی نوعی مشترک برای گروهی از مقادیر مرتبط و نامدار تعریف می‌کند. چون کامپایلر همه‌ی حالت‌های ممکن را از پیش می‌داند، می‌تواند کد شما را در زمان کامپایل از نظر درستی و کامل بودن بررسی کند.
شمارشی‌ها می‌توانند متد، سازنده و ویژگی‌های محاسبه‌شده هم داشته باشند.

## تعریف شمارشی‌ها

یک شمارشی را با کلیدواژه‌ی `enum` و پس از آن اسم نوع تعریف کنید و حالت‌هایش را داخل آکولاد بنویسید.
بر اساس قرارداد سوئیفت، اسم نوع با `UpperCamelCase` و هر حالت با `lowerCamelCase` نوشته می‌شود:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

همچنین می‌توانید چندین حالت را در یک خط و جدا شده با کاما تعریف کنید:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

برای اشاره به یک حالت شمارشی، اسم نوع شمارشی، یک نقطه (`.`)، و اسم حالت را بنویسید. وقتی نوع مشخص باشد یا کامپایلر بتواند آن را استنتاج کند، می‌توانید اسم نوع را حذف کنید و از نحوه‌ی نگارش نقطه‌ای کوتاه‌تر استفاده کنید:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## شمارشی‌ها و دستورهای `switch`

شمارشی‌ها به‌شکلی روان با [دستورهای `switch`][enums-and-switches] کار می‌کنند.
چون `switch` در سوئیفت باید جامع باشد، کامپایلر تضمین می‌کند که همه‌ی حالت‌های ممکن را پوشش دهید:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

اگر حالتی را جا بیندازید و شاخه‌ی `default` هم ندهید، کامپایلر خطا گزارش می‌دهد:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

فهرست کردن صریح همه‌ی حالت‌ها غالباً بهتر از استفاده از `default` است. به این ترتیب، اگر در آینده حالت تازه‌ای اضافه کنید، کامپایلر بی‌درنگ به شما هشدار می‌دهد تا هر دستور `switch` که آن شمارشی را مدیریت می‌کند به‌روزرسانی کنید.

## متدها و سازنده‌ها

شمارشی‌ها هم درست مثل کلاس‌ها و ساختارها می‌توانند متد و سازنده‌های سفارشی تعریف کنند. داخل یک متد شمارشی، `self` به مقدار حالت جاری اشاره می‌کند:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## مقادیر خام

حالت‌های شمارشی را می‌توان از پیش با مقادیر پیش‌فرضی به نام [_مقادیر خام_][raw-values] پر کرد.
همه‌ی مقادیر خام در یک شمارشی باید از یک نوع باشند (مثل `Int`، `String` یا `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

می‌توانید یک شمارشی را با `init(rawValue:)` از یک مقدار خام بسازید. چون ممکن است مقدار خام نامعتبری داده شود، این سازنده یک مقدار اختیاری برمی‌گرداند:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

سوئیفت می‌تواند برای شمارشی‌های `String` و `Int` به‌طور خودکار مقدار خام تعیین کند:

- در شمارشی‌های `String`، مقدار خام هر حالت به‌طور پیش‌فرض اسم همان حالت است.
- در شمارشی‌های `Int`، مقادیر خام از `0` شروع می‌شوند و تا زمانی که خلافش گفته نشود، هر بار ۱ واحد زیاد می‌شوند.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## مقادیر همراه

حالت‌های شمارشی می‌توانند در کنار هر حالت، مقادیر سفارشی از انواع مختلف را هم نگه دارند که به آن‌ها [_مقادیر همراه_][associated-values] می‌گویند:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

یک شمارشی می‌تواند از مقادیر خام یا مقادیر همراه استفاده کند، اما نه از هر دو.

## شمارشی‌های بازگشتی

یک [شمارشی بازگشتی][recursive-enumerations] شمارشی است که برای یک یا چند حالت، نمونه‌ی دیگری از همان شمارشی را به‌عنوان مقدار همراه دارد.
برای فعال کردن بازگشت، حالت (یا کل شمارشی) را با کلیدواژه‌ی `indirect` علامت بزنید:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
