# مقدمه

نوع `Result` در زبان Elm راه‌حل گزارش خطا است و امکان بازیابی از خطا را فراهم می‌کند. تا حدی شبیه نوع `Maybe` است، اما هرچند `Maybe` می‌تواند توسط توابعی که ممکن است شکست بخورند برگردانده شود، هیچ چیزی درباره‌ی دلیل شکست به شما نمی‌گوید. `Result` همین زمینه را درباره‌ی علت شکست در خود دارد.

نوع `Result` به شکل زیر تعریف شده است:

```elm
type Result error value
  = Ok value
  | Err error
```

در اصطلاحات Elm، به این کار «تعریف نوع سفارشی» می‌گویند.
`error` و `value` در `OK value` و `Error error` نماینده‌ی یک متغیر نوع هستند، یعنی می‌تواند هر نوعی باشد، مانند `Int`، `Bool` یا `String`.
بنابراین، `Result String Int` متغیری است که انتظار می‌رود یک `Int` در خود داشته باشد و اگر خطایی رخ دهد، به‌صورت یک `String` نمایش داده می‌شود.
یک [ماژول `Result`](https://package.elm-lang.org/packages/elm/core/latest/Result) با تعداد زیادی تابع کمکی مفید برای `Result` وجود دارد.
