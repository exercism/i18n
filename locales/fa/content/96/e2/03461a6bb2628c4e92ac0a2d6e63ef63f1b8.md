# پیوست دستورالعمل‌ها

## درباره‌ی ability `Stream`

`Stream` یک ability در Unison است که برای انتشار مقادیر به کار می‌رود.

اگر تابعی دارید که باید هنگام فراخوانی، مقادیر را به‌عنوان یک اثر جانبی تولید کند، ممکن است از ability `Stream` استفاده کنید. برای مثال، این تابع آخرین مقدار فهرست را برمی‌گرداند، اما با دیدن هر عنصر، جمع جاری را منتشر می‌کند:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

می‌توانیم با یک ability handler، `Stream` را به‌صورت یک `List` و همراه با مقدار بازگشتی تابعی که آن را تولید می‌کند، درآوریم:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
