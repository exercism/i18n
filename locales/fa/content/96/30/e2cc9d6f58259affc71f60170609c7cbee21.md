# دستورالعمل‌ها

به‌عنوان یک علاقه‌مند به شطرنج، دوست دارید نسخه‌ی خودتان از این بازی را بنویسید. بله، شاید همین حالا هم پیاده‌سازی‌های زیادی از شطرنج به‌صورت آنلاین در دسترس باشد، اما نسخه‌ی شما منحصربه‌فرد خواهد بود!

اما پیش از آن‌که تخیلتان را آزاد بگذارید، باید به اصول اولیه بپردازید. بیایید با تولید صفحه شروع کنیم.

هر خانه از صفحه‌ی شطرنج با یک جفت حرف-عدد شناسایی می‌شود. ستون‌های عمودی خانه‌ها، که «فایل» نامیده می‌شوند، با حروف A تا H برچسب‌گذاری شده‌اند. ردیف‌های افقی خانه‌ها، که «رتبه» نامیده می‌شوند، از ۱ تا ۸ شماره‌گذاری شده‌اند.

## 1. تعریف بازه‌ی رتبه

تابع `rank_range/0` را پیاده‌سازی کنید. این تابع باید یک بازه از اعداد صحیح را برگرداند، از ۱ تا ۸.

```elixir
Chessboard.rank_range()
```

## 2. تعریف بازه‌ی فایل

تابع `file_range/0` را پیاده‌سازی کنید. این تابع باید یک بازه از اعداد صحیح را برگرداند، از کدپوینت حرف بزرگ A تا کدپوینت حرف بزرگ H.

```elixir
Chessboard.file_range()
```

## 3. تبدیل بازه‌ی رتبه به فهرست رتبه‌ها

تابع `ranks/0` را پیاده‌سازی کنید. این تابع باید فهرستی از اعداد صحیح را برگرداند، از ۱ تا ۸. این فهرست را دستی ننویسید؛ آن را از بازه‌ای که تابع `rank_range/0` برمی‌گرداند تولید کنید.

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. تبدیل بازه‌ی فایل به فهرست فایل‌ها

تابع `files/0` را پیاده‌سازی کنید. این تابع باید فهرستی از حروف (رشته‌ها) را برگرداند، از "A" تا "H". این فهرست را دستی ننویسید؛ آن را از بازه‌ای که تابع `file_range/0` برمی‌گرداند تولید کنید.

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
