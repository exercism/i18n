# دستورالعمل‌ها

سرناوی هر روز روی عرشه جلسه‌ی توجیهی نگهبانی برگزار می‌کند: یک سلام ثابت، نام‌خوانی خدمه‌ی کشیک و در پایان مرخص کردن خدمه. شما توجیه را به چند خط کوچکِ نام‌دار تقسیم می‌کنید و آن‌ها را کنار هم می‌چینید.

در این تمرین **دو فایل** را ویرایش می‌کنید:

- `bosuns-briefing/helpers/helpers.factor`: تکه‌های کوچک و قابل استفاده‌ی مجدد. واژگان: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: فایل اصلی که توابع کمکی را کنار هم می‌چیند. واژگان: `bosuns-briefing`.

## 1. سلام

در `helpers.factor`، `greeting` را طوری تعریف کنید که رشته‌ی ثابت آغازین `"All hands, attention!"` را برگرداند.

```factor
greeting .
! => "All hands, attention!"
```

## 2. خط خدمه

در `helpers.factor`، `crew-line` را طوری تعریف کنید که یک رشته‌ی اسم بگیرد و همان اسم را با پیشوند `"  - "` (دو فاصله، یک خط تیره، یک فاصله) برگرداند.

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. پایان‌بندی

در `helpers.factor`، `closing` را طوری تعریف کنید که رشته‌ی ثابت پایان‌بندی `"Carry on."` را برگرداند.

```factor
closing .
! => "Carry on."
```

## 4. فهرست خدمه

در `bosuns-briefing.factor`، `roster` را طوری تعریف کنید که یک «آرایه» از اسم‌های خدمه بگیرد و یک رشته‌ی چندخطی برگرداند که هر اسم در آن با `crew-line` قالب‌بندی شده و اسم‌ها با خط جدید به هم وصل شده‌اند.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. توجیه

در `bosuns-briefing.factor`، `briefing` را طوری تعریف کنید که یک آرایه از اسم‌های خدمه بگیرد و توجیه کامل را به‌صورت یک رشته برگرداند: سلام در خط اول، فهرست خدمه در خطوط بعدی و پایان‌بندی در خط آخر. از توابع کمکی و `roster` استفاده کنید.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
