# مقدمه

## ثابت و تابع

برنامه‌های Haskell از تعریف‌ها و عبارت‌ها تشکیل شده‌اند.

یک مقدار ثابت با `name = expression` تعریف می‌شود.

```haskell
five = 5

six = 3 + 3
```

توابع با `name parameters... = expression` تعریف می‌شوند؛ پارامترها فقط با فاصله از هم جدا می‌شوند.

```haskell
add number1 number2 = number1 + number2
```

فراخوانی یک تابع هم یک عبارت است و با نوشتن اسم آن و فرستادن آرگومان‌ها برای هر یک از پارامترهای تابع انجام می‌شود، درست مثل تعریف تابع؛ آرگومان‌ها با فاصله از هم جدا می‌شوند.

```haskell
five = add 2 3
```

از پرانتز می‌توان برای مشخص کردن ترتیب ارزیابی یک عبارت استفاده کرد.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## تورفتگی / فاصله‌های معنادار

Haskell از فاصله‌ها و تورفتگی برای مشخص کردن مرزهای کد استفاده می‌کند.

***کدی که بخشی از یک عبارت است باید با تورفتگی بیشتری نسبت به ابتدای آن عبارت نوشته شود.***

- ماژول، import و تعریف‌های تابع سطح بالا باید از چپ‌ترین ستون شروع شوند.
- اگر یک عبارت به چند خط تقسیم شود، کدی که بخشی از آن عبارت است باید با حداقل یک فاصله زیر آن عبارت تورفته باشد.
- بخش‌هایی از عبارت که با هم گروه‌بندی شده‌اند باید با تعداد یکسانی فاصله تورفته باشند.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## ماژول

ماژول‌ها توابع را صادر می‌کنند.
یعنی می‌توانید از توابعی استفاده کنید که ماژول در دستور export خود در دسترس قرار می‌دهد.
یک ماژول می‌تواند توابعی را هم فقط برای استفاده‌ی داخلی تعریف کند.
به‌طور پیش‌فرض، توابعی که صریحاً صادر نشده‌اند نمی‌توانند از بیرون ماژول استفاده شوند.

در ابتدای یک ماژول، اسم ماژول را مشخص می‌کنیم.
اگر فایلی به اسم Calculator.hs داشته باشیم، باید اسم ماژولمان را Calculator بگذاریم.
بعد، توابعی را که صادر می‌کند مشخص می‌کنیم و پس از آن می‌توانیم نوشتن توابع را شروع کنیم.
حالا با این شروع می‌کنیم.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## کامنت

کامنت متنی است درون فایل Haskell که به‌عنوان کد تفسیر نمی‌شود.
عمدتاً برای این در نظر گرفته شده که خودتان و برنامه‌نویس‌های دیگر آن را بخوانید.
یک نحوه‌ی نگارش سبک برای کامنت‌های تک‌خطی وجود دارد که بر پایه‌ی دو خط تیره است.
کامنت‌های چندخطی هم با جفت `{-` و `-}` به‌عنوان جداکننده‌های باز و بسته ممکن هستند.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
