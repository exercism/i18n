# ترکیب تکرارگرها

یک حلقه می‌تواند بیش از یک تکرارگر را فراخوانی کند. در هر دور، یک بار مقدار بعدیِ هرکدام درخواست می‌شود و همه با هم جلو می‌روند.

```sather
   loop
      first ::= violin_one.elt!;
      second ::= violin_two.elt!;
      #OUT + first + " against " + second + "\n";
   end;
```

این کار هر دو آرایه را کنار هم پیش می‌برد: عنصر اول با عنصر اول، عنصر دوم با عنصر دوم.

## قانونی که همه را غافلگیر می‌کند

**حلقه به‌محض اینکه *اولین* تکرارگرش تمام شود، پایان می‌یابد.**

نه وقتی آخرین تکرارگر تمام می‌شود. نه وقتی همه تمام شده‌اند. اولین تکرارگر.

پس اگر `violin_one` چهار میزان داشته باشد و `violin_two` دو میزان، حلقه‌ی بالا **دو بار** اجرا می‌شود. میزان‌های سوم و چهارم بخش اول هرگز بررسی نمی‌شوند، چون تا آن موقع بخش دوم دیگر چیزی برای ارائه ندارد.

معمولاً دقیقاً همین چیزی است که می‌خواهیم (جفت‌جفت کردن فقط تا وقتی معنا دارد که جفت‌هایی وجود داشته باشد)، اما این را باید دانست، نه اینکه خودمان کشفش کنیم.

## شمارش هم‌زمان

یک تکرارگر که هرگز تمام نمی‌شود، دقیقاً به خاطر همان قانون مفید است. `up!` تا ابد می‌شمارد:

```sather
1.up!        -- 1, 2, 3, 4, ... and never ends
```

به‌تنهایی، حلقه تا ابد ادامه پیدا می‌کند. اما در کنار تکرارگری که تمام می‌شود، مقادیر را شماره‌گذاری می‌کند بدون اینکه هرگز تصمیم بگیرد تا کجا بشمارد:

```sather
   loop
      number ::= 1.up!;
      bar ::= part.elt!;
      #OUT + "Bar " + number + ": " + bar + "\n";
   end;
```

`part.elt!` حلقه را تمام می‌کند؛ `1.up!` شماره‌گذاری را تأمین می‌کند. هیچ‌کدام لازم نیست بدانند بخش چقدر طولانی است.

## ترتیب اهمیتی ندارد

از همه‌ی تکرارگرها در هر دور یک بار درخواست می‌شود، پس فرقی نمی‌کند کدام اول نوشته شود. آنچه مهم است این است که از هرکدام دقیقاً یک بار درخواست شود. نوشتن `part.elt!` دو بار در یک دور، دو مقدار می‌گیرد، نه یکی.
