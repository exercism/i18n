# درباره

مهم‌ترین نکته درباره‌ی رشته‌های Java این است که اشیایی تغییرناپذیرند که متن را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، نشانه‌گذاری و غیره) نمایش می‌دهند.
برای تعریف یک نمونه از `String` از علامت‌های نقل‌قول دوگانه استفاده می‌شود:

```java
String fruit = "Apple";
```

دستکاری یک رشته را می‌توان با استفاده از متدهای کلاس [`String`][string-class] انجام داد.
از آنجا که مقادیر رشته پس از تعریف هرگز تغییر نمی‌کنند، همه‌ی متدهای دستکاری رشته یک رشته‌ی جدید برمی‌گردانند.

هر رشته با نویسه‌های نقل‌قول دوگانه (`"`) محصور می‌شود.
برای نوشتن برخی نویسه‌های خاص باید از نویسه‌ی بک‌اسلش (`\`) استفاده کنید.
نویسه‌هایی که در Java نیاز به بک‌اسلش دارند:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

در پایان، راه‌های زیادی برای به‌هم‌چسباندن رشته‌ها وجود دارد.
ساده‌ترینشان عملگر `+` است:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

برای هر قالب‌بندی رشته‌ای پیچیده‌تر از چسباندن ساده، متد `String.format` ترجیح داده می‌شود.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

گزینه‌های دیگری هم وجود دارد:

- استفاده از کلاس [`StringBuilder`][string-builder]
- استفاده از متد [`String.concat`][string-concat]
