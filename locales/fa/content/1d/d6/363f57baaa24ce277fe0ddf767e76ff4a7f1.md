# راهنمایی‌ها

## 1. خواندن نشانی‌های ایمیل از یک فایل

- از تابع [`simplifile.read`][file-read] می‌توانید برای خواندن محتوای یک فایل استفاده کنید.

## 2. ساختن فایل گزارش برای نوشتن

- از تابع [`simplifile.create_file`][file-create] می‌توانید برای ساختن یک فایل خالی استفاده کنید.

## 3. ثبت ایمیل ارسال‌شده

- از تابع [`simplifile.append`][file-append] می‌توانید برای افزودن متن به یک فایل استفاده کنید.

## 5. ارسال خبرنامه

- همه‌ی عملیات لازم روی فایل‌ها در مراحل قبلی پیاده‌سازی شده‌اند.
- از تابع [`result.try`][result-try] و تابع [`list.try_each`][list-try-each] می‌توانید برای کار با نوع `Result` استفاده کنید.

[file-create]: https://hexdocs.pm/simplifile/simplifile.html#create_file
[file-append]: https://hexdocs.pm/simplifile/simplifile.html#append
[result-try]: https://hexdocs.pm/gleam_stdlib/gleam/result.html#try
[list-try-each]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#try_each
