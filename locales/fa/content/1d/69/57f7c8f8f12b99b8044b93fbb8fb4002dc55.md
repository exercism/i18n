# درباره

تطبیق الگو فرایند شاخه‌بندی بر اساس تطبیق یک مقدار با الگوهای مشخص است؛ الگوهایی که ممکن است عمیق باشند. در Haxe، **تطبیق الگو** با استفاده از عبارت `switch` و عبارت‌های `case` جداگانه انجام می‌شود.

ساختار داده‌ی زیر را در نظر بگیرید:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- الگوها همیشه از بالا به پایین تطبیق داده می‌شوند.
- بالاترین الگویی که با مقدار ورودی تطبیق پیدا می‌کند، عبارت آن اجرا می‌شود.
- الگوی `_` با هر چیزی تطبیق پیدا می‌کند، بنابراین `case _:` معادل `default:` است.

## تطبیق `enum`

انواع `enum` را می‌توان به‌طور طبیعی با سازنده‌شان تطبیق داد:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
