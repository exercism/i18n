# کمک

اگر برای حل مشکلی به کمک نیاز دارید، می‌توانید از یکی از منابع زیر استفاده کنید:

- [مستندات کتابخانه‌ی استاندارد](http://caml.inria.fr/pub/docs/manual-ocaml/libref/index.html)
- [/r/ocaml](https://www.reddit.com/r/ocaml) سابردیت OCaml است.
- از [StackOverflow](http://stackoverflow.com/questions/tagged/ocaml) می‌توانید برای جست‌وجوی مشکلتان استفاده کنید و ببینید آیا پیش‌تر به آن پاسخ داده شده است یا نه. همچنین می‌توانید پرسش بپرسید و به پرسش‌ها پاسخ دهید.
