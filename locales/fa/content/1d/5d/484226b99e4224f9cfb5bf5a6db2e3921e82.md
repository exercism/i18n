# درباره

یک `string` در C++ یک «رشته» است: شیئی تغییرپذیر که متن را به‌صورت دنباله‌ای از کاراکترها (حروف، ارقام، علائم نگارشی و غیره) نمایش می‌دهد.
رشته‌ها با فراخوانی متدهایشان دستکاری می‌شوند.

## کتابخانه‌ی رشته

در C++، نوع رشته و توابع مرتبط با آن باید پیش از استفاده، از کتابخانه‌ی رشته include شوند.
این کار را با افزودن `#include <string>` به بالای فایل خودتان انجام می‌دهید.
پس از این کار، در فضای نام `std` قرار می‌گیرند.
لیترال رشته از کاراکتر دابل‌کوتیشن استفاده می‌کند: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## عملیات رایج روی رشته

می‌توانید با عملگر `+` رشته‌ها را به هم الحاق کنید:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

برای استفاده از کتابخانه‌ی رشته، باید بدانید که می‌توان تابعی را که به یک شیء تعلق دارد فراخوانی کرد.
به این‌ها توابع عضو می‌گویند.
بعداً در برنامه‌ی درسی، درباره‌ی توابع عضو و مفهوم کلاس که با آن‌ها پیوند دارد بیشتر یاد می‌گیرید.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


تابع `find` هم بسیار مفید است.
این تابع به‌صورت یک تابع عضو روی رشته فراخوانی می‌شود و یک رشته را به‌عنوان آرگومان می‌گیرد.
تابع `find` موقعیت نخستین رخداد در رشته را برمی‌گرداند، با اندیسی که از صفر شروع می‌شود.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

تابع `to_string` هم وجود دارد که می‌توان با آن اعداد صحیح و مقادیر float/double را به رشته تبدیل کرد.
تابع `to_string` یک رشته برمی‌گرداند.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
