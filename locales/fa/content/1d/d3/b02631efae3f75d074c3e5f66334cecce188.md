# مقدمه

«انواع فانتوم» پارامترهای نوعیِ یک نوع سفارشی هستند که در هیچ‌یک از سازنده‌های مقدارِ آن نوع به کار نمی‌روند.

این توضیح کمی انتزاعی است، پس با یک مثال آن را روشن می‌کنیم:

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

در این مثال، پارامتر نوعِ `unit` در سازنده‌ی مقدار `Length` استفاده نشده است، بنابراین `unit` یک نوع فانتوم است.

این پارامتر نوعِ بی‌استفاده ممکن است بی‌فایده به نظر برسد، اما می‌توان از آن برای اعمال محدودیت‌های بیشتر بر نحوه‌ی استفاده از مقادیر `Length` بهره گرفت.

برای مثال، می‌توانیم تابعی به اسم `double` داشته باشیم که طول را ضرب می‌کند. این تابع با طول‌هایی با هر واحدی کار می‌کند، بنابراین پارامتر نوع یک متغیر نوعِ جنریک است.

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

همچنین می‌توانیم تابعی به اسم `add_inch` داشته باشیم که فقط وقتی کار می‌کند که طول بر حسب اینچ باشد.

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

تابع `add_inch` طول‌هایی با هیچ پارامتر واحد دیگری را نمی‌پذیرد؛ از نوع فانتوم استفاده شده تا مطمئن شویم فقط واحد درست به کار می‌رود.

همچنین می‌توان تابعی نوشت که تضمین کند دو مقدار طول از یک واحدند، به این ترتیب که برای هر دو از یک متغیر نوع استفاده شود.

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

انواع فانتوم می‌توانند با «انواع مات» به خوبی کار کنند. اگر ماژول‌های دیگر نتوانند مقادیر `Length` را بسازند، می‌توانیم مطمئن شویم که این مقادیر با یک نوع واحد نامعتبر ساخته نمی‌شوند و فقط توابع تعریف‌شده در بالا می‌توانند با آن‌ها به کار روند.
