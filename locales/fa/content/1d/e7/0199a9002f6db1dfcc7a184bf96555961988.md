# درباره

## دستورهای شرطی

دستورهای شرطی، دستورهایی برای تصمیم‌گیری هستند که یا عوارض جانبی اجرا می‌کنند یا جریان اجرا در یک برنامه را کنترل می‌کنند.
دستورهای شرطی شامل `if`، `if/else`، `switch` و `ternary` می‌شوند.

از دستورهای شرطی برای پرسیدن سؤال درباره‌ی یک مقدار یا رابطه‌ی میان مقدارها استفاده می‌شود.
این پرسش به یک پاسخ «منطقی» ارزیابی می‌شود، اما دستور `if` خودش می‌تواند هر مقداری را برگرداند یا صرفاً یک عارضه‌ی جانبی اجرا کند.

## دستورهای `if`

ساده‌ترین دستور `if` یک عبارت را ارزیابی می‌کند و یک خط را اجرا می‌کند.
عبارتی که آزمایش می‌شود همیشه داخل پرانتز قرار می‌گیرد.

می‌تواند یک عارضه‌ی جانبی اجرا کند

```c
if (count > 10)
    printf("count is greater than 10");
```

یا می‌تواند جریان اجرا را تغییر دهد


```c
if (count > 10)
    return sum;
```

اگر دستور `if` بیش از یک خط را اجرا کند، باید آن خط‌ها را داخل آکولاد قرار دهد

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

برخی تیم‌های برنامه‌نویسی ممکن است این استاندارد را وضع کنند که دستورهای `if` همیشه باید از آکولاد استفاده کنند، حتی برای یک خط.


## `if` و `else`

می‌توان دستور `if` را با یک `else` جفت کرد

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`، `else` و `if`


می‌توان `else` را با یک `if` دیگر جفت کرد تا چیزی ساخته شود که به آن `if-else-if ladder` می‌گویند.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


گاهی می‌توان `if-else-if ladder` را بهتر با یک `switch` نمایش داد.
مانند `if`، عبارتی که آزمایش می‌شود همیشه داخل پرانتز قرار می‌گیرد.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

حالت `default` زمانی اجرا می‌شود که مقدار آزمایش‌شده با هیچ‌یک از حالت‌های قبلی مطابقت نداشته باشد.

اگر یک حالت `switch` چیزی برنگرداند، معمولاً یک `break` برای پایان دادن به هر حالت درج می‌شود؛ در غیر این صورت منطق به حالت بعدی «عبور می‌کند».
گاهی از عبور به‌صورت عمدی استفاده می‌شود

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

وقتی عبور ناخواسته رخ دهد، یک باگ است.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

استفاده از `switch` می‌تواند زمانی مفید باشد که به‌جای محدوده‌ای از مقدارها، با مقدارهای مشخصی مقایسه می‌کنیم.
می‌تواند از `if-else-if ladder` سریع‌تر باشد، زیرا کامپایلر ممکن است بتواند دستور `switch` را به روش‌هایی بهینه کند که با یک نردبان امکان‌پذیر نیست.
گاهی `switch` خواناتر از یک نردبان به نظر می‌رسد.

## عملگر سه‌گانه (که به آن عملگر شرطی هم می‌گویند)

عملگر سه‌گانه یک دستور شرطی سه‌بخشی است که اغلب برای تعیین یک مقدار به کار می‌رود.
عبارتی که باید آزمایش شود پیش از علامت سؤال می‌آید و لازم نیست داخل پرانتز باشد.
مقداری که در صورت «درست» بودن برگردانده می‌شود پیش از دونقطه است و مقداری که در صورت «غلط» بودن برگردانده می‌شود پس از دونقطه قرار می‌گیرد.
می‌توان یک مقدار ثابت یا یک متغیر را برگرداند.

```c
int i = j > 5 ? 5: j;
```

عملگرهای سه‌گانه را می‌توان تودرتو کرد تا شلوغی نحوه‌ی نگارش کاهش یابد.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## مقایسه‌های شرطی برای مقدارهای اعشاری

به دلیل نحوه‌ی پیاده‌سازی اعداد اعشاری، یک عملیات ریاضی ساده ممکن است به خطای گردکردن منجر شود که می‌تواند باعث شود آزمایش برابری نتیجه‌ی مورد انتظار را برنگرداند.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

می‌توان از یک مقدار رواداری که به آن `epsilon` می‌گویند برای تعیین بازه‌ای استفاده کرد که یک مقدار اگر در آن قرار بگیرد، در مقایسه با مقدار دیگر همچنان برابر در نظر گرفته می‌شود.
برخی پلتفرم‌ها ثابت‌های درون‌ساخته‌ای برای اپسیلون `float` و `double` دارند.
برای اطلاعات بیشتر به مستندات کامپایلر خود مراجعه کنید.
محاسبه‌ی اپسیلون می‌تواند پیچیده باشد و ممکن است از پلتفرمی به پلتفرم دیگر متفاوت باشد، حتی از یک ماشین به ماشین دیگر.
در ادامه یک برنامه‌ی نمونه با یک مقایسه‌ی ساده آمده است.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

هنگام مقایسه‌ی `float`ها یا `double`ها برای برابری احتیاط کنید!
