# ضمیمه‌ی دستورالعمل

## قالب خروجی

متن ترانه را به‌صورت رشته‌ای خروجی بدهید که با پوچ پایان می‌یابد.

## ثبات‌ها

| ثبات     | کاربرد        | نوع     | توضیحات                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | عدد صحیح | بطری‌های شروع                  |
| `$a1`    | ورودی        | عدد صحیح | برداشتن                       |
| `$a2`    | ورودی/خروجی  | آدرس    | رشته‌ی خروجی که با پوچ پایان می‌یابد |
| `$t0-9`  | موقت         | هر نوع  | برای ذخیره‌سازی موقت            |
