# راهنمایی‌ها

## 1. دریافت مجوزهای پیش‌فرض برای یک نوع حساب

- `Permission` را به‌صورت یک `enum` تعریف کنید که مقادیری برای این نوع‌های مجوز داشته باشد: `None`، `Read`، `Write` و `Delete`.
- استفاده از فلگ‌های `enum` این امکان را می‌دهد که بدون کار اضافه از عملگرهای بیتی برای `Permission` استفاده کنید، [`enum` `Flags` را ببینید][docs-enum-flags].
- عضو `All` در این `enum` را می‌توان به‌صورت ترکیبی از اعضای `Read`، `Write` و `Delete` تعریف کرد.
- `AccountType` را به‌صورت یک `enum` تعریف کنید که مقادیری برای این نوع‌های حساب داشته باشد: `Guest`، `User` و `Moderator`.
- برای رسیدگی به هر نوع حساب می‌توان از دستور `if` استفاده کرد، اما [دستور `switch`][docs.microsoft.com-switch-keyword] جایگزین بسیار خوبی است.
- ترکیب فلگ‌ها یعنی تنظیم یک بیت مشخص روی `1` با استفاده از یکی از [عملگرهای بیتی][docs.microsoft.com-bitwise-and-shift-operators].

## 2. اعطای مجوز

- ترکیب فلگ‌ها یعنی تنظیم یک بیت مشخص روی `1` با استفاده از یکی از [عملگرهای بیتی][docs.microsoft.com-bitwise-and-shift-operators].

## 3. لغو مجوز

- حذف یک فلگ یعنی تنظیم یک بیت مشخص روی `0` با ترکیبی از دو [عملگر بیتی][docs.microsoft.com-bitwise-and-shift-operators].

## 4. بررسی مجوز

- برای بررسی مجوز می‌توان نتیجه‌ی اعمال یکی از [عملگرهای بیتی][docs.microsoft.com-bitwise-and-shift-operators] را بررسی کرد.
