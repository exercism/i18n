# نصب Emacs

از آنجا که Emacs Lisp (elisp) زبان توسعه‌ی Emacs است، اول باید [GNU Emacs](http://www.gnu.org/software/emacs/) را نصب کنید.

توصیه می‌شود آخرین نسخه‌ی Emacs را نصب کنید، اما پیاده‌سازی هدف برای تمرین‌ها باید 28.1 یا بالاتر باشد.
اگر Emacs را از قبل نصب کرده‌اید، می‌توانید نسخه‌ی آن را با `M-x emacs-version RET` ببینید.

## در OS X
ساده‌ترین راه این است که به [Emacs For Mac OS X](http://emacsformacosx.com/) سر بزنید و فایل dmg را دانلود کنید، که GNU Emacs را به‌صورت یک برنامه‌ی بسته‌بندی‌شده‌ی OS X نصب می‌کند.

راه‌های دیگری هم هست، مثل Aquamacs (توصیه نمی‌شود) یا نصب از طریق [Homebrew](https://formulae.brew.sh/formula/emacs)، اگر ترجیح می‌دهید.

## در Linux
در بعضی توزیع‌ها Emacs از قبل نصب است، چون بخشی از GNU است.

### Ubuntu
راه توصیه‌شده‌ی فعلی برای نصب جدیدترین نسخه‌ی Emacs استفاده از [snap](https://snapcraft.io/emacs) است:

```
sudo snap install emacs --classic
```

اگر نمی‌خواهید از snap استفاده کنید، می‌توانید Emacs را از طریق snap نصب کنید، اما نسخه‌ای که در مخازن Ubuntu موجود است اغلب قدیمی است.
اگر می‌خواهید نسخه‌ی جدیدتری از Emacs را با apt نصب کنید، باید از یک [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) استفاده کنید یا [آن را از سورس بسازید](https://www.emacswiki.org/emacs/BuildingEmacs).

اگر برایتان مهم نیست که آخرین نسخه را نصب کنید، کار باید به همین سادگی باشد:

```
sudo apt-get install emacs
```

### Arch
Arch معمولاً آخرین نسخه‌ی Emacs را همراه دارد، پس این را اجرا کنید:

```
sudo pacman -S emacs
```

و کارتان راه می‌افتد.

### توزیع‌های دیگر
با توزیع خود بررسی کنید که کدام نسخه فعلی است و به‌تناسب از مدیر بسته‌ی خود استفاده کنید یا از سورس بسازید.

### Windows
برای نصب Emacs روی Windows به نزدیک‌ترین [آینه‌ی آرشیو FTP](https://ftpmirror.gnu.org/emacs/windows) بروید، نصب‌کننده (=emacs-XX.X-installer.exe=) را بگیرید و آن را اجرا کنید.
اگر نمی‌خواهید Emacs را بدون نصب کردن آن استفاده کنید، می‌توانید فایل با الگوی =emacs-XX.x.zip= را بگیرید، آن را از حالت فشرده خارج کنید و `bin\runemacs.exe` را اجرا کنید.

اگر از [MSYS2](https://www.msys2.org/) استفاده می‌کنید، می‌توانید نسخه‌ی ۶۴بیتی Emacs را با این نصب کنید:

```
pacman -S mingw-w64-x86_64-emacs
```

یا نسخه‌ی ۳۲بیتی را با:

```
pacman -S mingw-w64-i686-emacs
```
