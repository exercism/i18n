# پیوست دستورالعمل

## خروجی

در این تمرین، یک «verb» پیاده‌سازی می‌کنید که مثلث پاسکال را تا تعداد معینی سطر تولید می‌کند. خروجی آن می‌تواند به یکی از دو صورت قالب‌بندی شود:

  1. به‌صورت آرایه‌ای از فهرست‌های جعبه‌ای، که هر فهرست یک سطر از مثلث پاسکال را نشان می‌دهد.
  1. به‌صورت یک جدول، که اعداد در آن به سمت راست تراز شده‌اند و از صفرها برای پر کردن فضاهای خالی سمت چپ استفاده می‌شود.

### خروجی نمونه

دو خروجی معتبر برای `pascal 3` در ادامه آمده است:

  - به‌صورت آرایه‌ای از فهرست‌های جعبه‌ای:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - به‌صورت یک جدول با پرکردن:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
