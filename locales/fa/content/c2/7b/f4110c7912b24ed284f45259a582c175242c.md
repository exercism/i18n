# مقدمه

## اعداد

دو نوع رایج‌ترین عدد در Ruby عبارت‌اند از:

- **اعداد صحیح:** اعدادی که هیچ رقمی بعد از جداکننده‌ی اعشار ندارند (اعداد کامل). مثال‌ها عبارت‌اند از `-6`، `0`، `1`، `25`، `976` و `500000`.
- **اعداد اعشاری:** اعدادی که یک یا چند رقم بعد از جداکننده‌ی اعشار دارند. مثال‌ها عبارت‌اند از `-2.4`، `0.1`، `3.14`، `16.984025` و `1024.0`.

این اعداد از طریق کلاس‌های `Integer` و `Float` پیاده‌سازی می‌شوند.

این کلاس‌ها متدهایی دارند که مقادیر را از یکی به دیگری تبدیل می‌کنند. اعداد `Integer` به یک واحد کامل دقیق‌اند، در حالی که دقت `Float` کسری نسبت به یک عدد کامل است:

- `Integer#to_f`: تبدیل به یک عدد اعشاری جدید
- `Float#ceil`: گرد کردن به بالا تا نزدیک‌ترین عدد صحیح
- `Float#floor`: گرد کردن به پایین تا نزدیک‌ترین عدد صحیح
- `Float#round`: گرد کردن به نزدیک‌ترین عدد صحیح
- `Float#to_i`: بریدن تا نزدیک‌ترین عدد صحیح

## دستورهای شرطی

Ruby چیزهایی دارد که به آن‌ها عبارات کنترل جریان می‌گویند؛ این‌ها برای کنترل نحوه‌ی اجرای برنامه به کار می‌روند و یک مقدار درست‌نما یا غلط‌نما می‌گیرند.
عملگرهایی هم وجود دارند که می‌توان با آن‌ها مقادیر درست‌نما یا غلط‌نما ساخت؛ به این‌ها [عملگرهای مقایسه][comparison-operators] می‌گویند.

دو عبارت کنترلی اصلی وجود دارند که تعیین می‌کنند کدام کد اجرا شود و کدام نشود؛ به بیان دیگر، کدام شاخه‌ی داده‌شده اجرا شود.

این دو عبارت‌اند از: `if` و عبارت `unless`.

## عملگرهای مقایسه

از [عملگرهای مقایسه][comparison-operators] برای مقایسه‌ی مقادیر و برگرداندن مقدار `true` یا `false` استفاده می‌شود.
عملگرهای زیر نیاز دارند دو مقداری که با هم مقایسه می‌شوند از یک نوع باشند.
اگر مقادیر از یک نوع نباشند، کامپایلر خطا می‌دهد.
در ادامه فهرستی از این عملگرها و مثالی از زمانی که مقدار `true` می‌دهند آمده است:

| متد | توضیح           | مثال |
| ------ | --------------------- | ------- |
| <      | کوچک‌تر از             | 4 < 5   |
| <=     | کوچک‌تر یا مساوی    | 4 <= 4  |
| >      | بزرگ‌تر از          | 3 > 1   |
| >=     | بزرگ‌تر یا مساوی | 2 >= 2  |

برخلاف عملگرهایی که پیش‌تر گفته شد، از عملگرهای مساوی و نامساوی می‌توان برای مقایسه‌ی هر نوع مقداری استفاده کرد.
عملگر `==` برای بررسی برابری دو مقدار به کار می‌رود و نوع مقدار را هم بررسی می‌کند.
عملگر `!=` هم به همین شکل کار می‌کند، اما اگر مقادیر نامساوی باشند `true` و اگر مساوی باشند `false` برمی‌گرداند.
در ادامه فهرستی از عملگرهای مساوی و نامساوی و مثالی از زمانی که مقدار `true` می‌دهند آمده است:

| متد | توضیح  | مثال |
| ------ | ------------ | ------- |
| ==     | مساوی        | 4 == 4  |
| !=     | نامساوی    | 5 != 4  |

## دستور if

دستور [`if`][if] برای بررسی این به کار می‌رود که یک شرط داده‌شده «درست‌نما» است یا «غلط‌نما».
اگر شرط درست‌نما باشد، کد داخل دستور if اجرا می‌شود.
یک دستور `if` با کلیدواژه‌ی `end` پایان می‌یابد.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## دستور unless

دستور `unless` بسیار شبیه دستور `if` کار می‌کند، اما کد داخل دستور `unless` را زمانی اجرا می‌کند که شرط غلط‌نما باشد.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## دستور else

دستور `else` می‌تواند همراه با دستور `if` به کار رود.
دستور `else` اگر شاخه‌ی `if` اجرا نشود، اجرا می‌شود.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## دستورهای «if آبشاری»

دستور `elsif` می‌تواند همراه با دستور if به کار رود.
دستور `elsif` زمانی اجرا می‌شود که شاخه‌ی if اجرا نشود و شرط دستور elsif درست‌نما باشد.
دستورهای elsif را می‌توان به هم زنجیره کرد و نخستین شرط درست‌نما اجرا می‌شود.
همچنین می‌توان یک دستور else در انتهای دستور if قرار داد که اگر هیچ‌یک از دستورهای پیشین درست نبوده باشد، اجرا می‌شود.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
