# مقدمه

یک [`string`][ref-string] در Kotlin دنباله‌ای تغییرناپذیر از کاراکترهای یونیکد است.

[`Immutable`][wiki-immutable] یعنی هر عملیاتی روی یک رشته باید رشته‌ی جدیدی برگرداند: رشته‌ی اصلی هرگز نمی‌تواند تغییر کند.

[`Unicode`][wiki-unicode] یعنی می‌توان بیشتر سامانه‌های نوشتاری جهان را نمایش داد، اما (برخلاف زبان‌های قدیمی‌تری مانند C) نگاشت یک‌به‌یک بین کاراکترها و بایت‌ها وجود ندارد.

یک رشته معمولاً بین دو گیومه‌ی دوتایی `" "` قرار می‌گیرد.

بعضی کاراکترها را باید escape کرد: `\'`، `\\` و همچنین کاراکترهای غیرچاپی معمول مانند `\t` (تب) و `\n` (خط جدید).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

رشته‌های چندخطی بین ۳ گیومه‌ی دوتایی قرار می‌گیرند و می‌توانند متن دلخواهی در خود داشته باشند (نیازی به escape نیست).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

از [trimIndent][trimIndent-doc] استفاده کنید تا تورفتگی مشترک را از خطوط حذف کنید.
این کار برای قالب‌بندی رشته مفید است:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

در عوض، [trimMargin][trimMargin-doc] به شما امکان می‌دهد یک جداکننده مشخص کنید.
سپس هر خط در `String` بعد از جداکننده شروع می‌شود.
جداکننده به‌طور پیش‌فرض `|` است، اما می‌توانید جداکننده‌ی دیگری را به‌عنوان پارامتر مشخص کنید.
برای مثال:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

رشته‌ها را می‌توان با `+` به هم چسباند، اما بهتر است این کار را به موارد کوتاه و ساده محدود کنید.
گزینه‌های دیگری هم هست که اغلب بهترند.

## قالب‌های رشته

این به چیزی اشاره دارد که برخی زبان‌های دیگر به آن «درون‌یابی» می‌گویند.

اگر رشته‌ای شامل علامت دلار `$` باشد که پس از آن یک شناسه بیاید، یا شامل آکولادهایی (`{expression}`) دور یک عبارت باشد، این‌ها به‌ترتیب با مقدار یا نتیجه‌ی آن عبارت جایگزین می‌شوند.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

آکولادهای `{ }` وقتی دور عبارت‌ها لازم می‌شوند که در غیر این صورت تجزیه مبهم باشد.

به‌طور کلی، استفاده از قالب‌های رشته روشی کارآمدتر و طبیعی‌تر برای ترکیب رشته‌ها در مقایسه با استفاده از `+` است.

## توابع رشته

Kotlin توابع [`functions`][ref-string-functions] _بسیاری_ برای کار با رشته‌ها فراهم می‌کند.

بیشتر این‌ها به‌جای اعضای کلاس `String`، توابع [`extensions functions`][ref-extensions] هستند، هرچند تأثیر چندانی بر نحوه‌ی استفاده‌ی ما از آن‌ها ندارد.

~~~~exercism/note
صفحه‌های [documentation][ref-string-functions] Kotlin که نسبتاً پیچیده‌اند، توابع extension را در نمای پیش‌فرض پنهان می‌کنند.
حتماً روی `Members & Extensions` کلیک کنید تا این بخش را باز کنید.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

مثال‌های زیر فقط نمونه‌ی کوچکی از آنچه در دسترس است را نشان می‌دهند:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
