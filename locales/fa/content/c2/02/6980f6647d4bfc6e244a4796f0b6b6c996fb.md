# نصب

ما از *PolyML* به عنوان پیاده‌سازی Standard ML خود استفاده می‌کنیم.

اگر از Windows استفاده می‌کنید، می‌توانید نصب‌کننده را از [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases) دانلود کنید.
دستورالعمل‌های کلی برای Linux/OS X/Free BSD را می‌توانید در [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme) پیدا کنید.

اگر می‌خواهید از سورس نصب کنید، فرایند آن خیلی ساده است:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

اگر می‌خواهید آن را در مسیر دلخواهی، مثلاً `$HOME/.local`، نصب کنید:

```sh
$ ./configure --prefix=$HOME/.local
```

آخرین گام:

```sh
$ make compiler
$ make install
```

بررسی کنید که درست نصب شده است:

```sh
$ poly
```

اگر مفسر را می‌بینید، آماده‌اید!
اگر این‌طور نیست، احتمالاً باید `$HOME/.local/bin` (یا `<you prefix>/bin`) را به `$PATH` خود اضافه کنید.
