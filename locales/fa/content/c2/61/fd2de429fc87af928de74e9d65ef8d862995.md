# Test

با پیروی از [سه قانون توسعه‌ی مبتنی بر test][3-tdd-rules]، کاری کنید که اولین test کامپایل شود، لینک شود و پاس شود.

می‌توانید با استفاده از فایل makefile همراه و وظیفه‌ی `test`، testها را بسازید و اجرا کنید.

```console
$ make test
```

فقط همان توابعی را بسازید که برای برطرف کردن خطاهای کامپایلر لازم دارید و کاری کنید که test شکست بخورد.
سپس فقط به‌اندازه‌ی کافی code بنویسید تا test پاس شود.
وقتی این کار را انجام دادید، به سراغ test بعدی بروید.

همین‌طور که در testها پیش می‌روید، وقت بگذارید و پیاده‌سازی‌تان را برای خوانایی و رسایی ریفکتور کنید و بعد به سراغ test بعدی بروید.

سعی کنید به‌جای نوشتن دستی الگوریتم‌ها یا ابزارهای سطح‌پایین، از امکانات استاندارد C99 استفاده کنید.

## بررسی نشت حافظه

فایل makefile یک نسخه‌ی ساخت هم دارد که برخی اشتباه‌های رایج مربوط به نشت حافظه و دسترسی خارج از محدوده به آرایه‌ها را بررسی می‌کند.
برای اجرای این بررسی‌ها، از فرمان زیر در خط فرمان استفاده کنید:

```console
$ make memcheck
```
