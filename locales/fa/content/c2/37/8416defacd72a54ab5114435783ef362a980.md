# نصب

## نصب tclsh

تنها ابزاری که لازم دارید «مفسر» TCL، یعنی `tclsh`، است.

برای ویندوز، بهترین جایی که می‌توانید Tcl را از آن تهیه کنید [نصب‌کننده‌ی Tcl از Magicsplat][magicsplat] است.

روی MacOS و سیستم‌عامل‌های شبیه یونیکس، `tclsh` از قبل نصب شده است.
معمولاً نسخه‌ای که نصب شده 8.6.*چیزی* خواهد بود.
برای نصب نسخه‌ی پایدار کنونی، یعنی 9.1:
 - روی MacOS از [Homebrew][brew] استفاده کنید.
 - در لینوکس، مدیر بسته‌های خودتان را بررسی کنید.
 - یا [منبع را دانلود کنید][download] و [آن را بسازید][build].

اگر بخواهید تمرین‌ها را با رابط وب Exercism حل کنید، اجراکننده‌ی آزمون (تا فوریه ۲۰۲۳) از Tcl نسخه‌ی 8.7a4 استفاده می‌کند.

## استفاده از «پوسته‌ی» تعاملی tclsh

مرسوم است که هنگام کدنویسی یک نشست تعاملی [`tclsh`][tclsh] اجرا کنید تا دستورها را امتحان کنید.
اما tclsh فقط یک مفسر REPL بسیار ساده فراهم می‌کند که نه ویرایش خط فرمان دارد و نه تاریخچه‌ی دستورها.
برای تجربه‌ای بهتر، برنامه‌ای به اسم `rlwrap` وجود دارد که قابلیت readline را اضافه می‌کند:

```bash
rlwrap tclsh
```

برای نصب rlwrap:
 - روی MacOS از [Homebrew][brew] استفاده کنید.
 - در لینوکس‌ها، مدیر بسته‌های خودتان را بررسی کنید.
 - یا [منبع را دانلود کنید][rlwrap-download] و [آن را بسازید][rlwrap-build].

آن‌قدر کارآمد است که همیشه می‌خواهید از آن استفاده کنید: این را به ~/.bashrc خود اضافه کنید

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## از کدام نسخه استفاده کنیم؟

نسخه‌ی پایدار کنونی 9.1 است.
همان‌طور که در بالا اشاره شد، نسخه‌ی 8.6 هنوز به‌طور گسترده در حال استفاده است.

می‌توانید با اجرای دستور زیر بررسی کنید که کدام نسخه از `tclsh` را نصب کرده‌اید:

```bash
echo 'puts [info patchlevel]' | tclsh
```
