# مقدمه

## رشته

به یاد آورید که `jq` همان انواع دادهی JSON را پشتیبانی می‌کند.
JSON **«رشته»** را این‌گونه توصیف می‌کند:

> رشته دنباله‌ای است از صفر یا چند نویسه‌ی یونیکد که در گیومه‌ی دوتایی پیچیده شده و از دنباله‌های فرار بک‌اسلش استفاده می‌کند.

### دنباله‌ی فرار

درون یک رشته، از نویسه‌ی بک‌اسلش برای جا دادن نویسه‌های «خاص» استفاده کنید:

- `\"` یک علامت نقل‌قول دوتایی واقعی،
- `\\` یک بک‌اسلش واقعی،
- نویسه‌های فضای خالی `\n`، `\t`، `\r`، `\f`، `\b`
- نویسه‌های یونیکد `\uAAAA` که در آن `A` یک رقم مبنای ۱۶ است

### طول رشته

برای یافتن تعداد نویسه‌ها، از تابع `length` استفاده کنید.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### زیررشته

از نگارش **برش** می‌توان برای استخراج زیررشته‌ها استفاده کرد.
نحوه‌ی نگارش آن `.[i:j]` است.
زیررشته‌ای که برگردانده می‌شود طولش `j - i` است و نویسه‌ها را از اندیس `i` (شامل) تا اندیس `j` (غیرشامل) برمی‌گرداند.
هر کدام از اندیس‌ها می‌تواند منفی باشد، که در این صورت از انتهای رشته به عقب شمرده می‌شود.
هر کدام از اندیس‌ها را می‌توان حذف کرد، که در این صورت به ابتدا یا انتهای رشته اشاره می‌کند.
اندیس‌ها از صفر شروع می‌شوند.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### الحاق

برای به هم پیوستن رشته‌ها از `+` استفاده کنید:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

وقتی آرایه‌ای از رشته‌ها در اختیار دارید، از `add` استفاده کنید:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### تقسیم و پیوستن

تقسیم از تابع `split/1` یا عملگر `/` استفاده می‌کند:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

معکوس `split/1`، تابع `join/1` است.

تبدیل یک رشته به آرایه‌ای از نویسه‌ها اغلب لازم است.
دو راه برای این کار وجود دارد:

1. تقسیم روی یک رشته‌ی خالی

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` به آرایه‌ای از _کدپوینت‌ها_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` معکوس `explode` است.

### یافتن اندیس یک زیررشته

از تابع `index/1` استفاده کنید؛ اندیس از صفر شروع می‌شود.

```jq
"hello" | index("el")'   # => 1
```

اگر زیررشته در رشته نباشد، نتیجه `null` است

```jq
"hello" | index("elk")   # => null
```

### درج رشته

درون یک رشته، دنباله‌ی `\(expression)` _نتیجه‌ی_ آن عبارت را [درون رشته جای می‌دهد][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### تبدیل حروف بزرگ و کوچک

از توابع `ascii_downcase` و `ascii_upcase` استفاده کنید.

### عبارت باقاعده

`jq` از عبارت‌های باقاعده پشتیبانی گسترده‌ای دارد. این موضوع یک درس بعدی خواهد بود.

[interpolate]: https://jqlang.org/manual/#string-interpolation
