# گنجاندن کد

```sather
   include WARM_UP;
   include WARM_UP count -> warm_up_count;
   include WARM_UP describe -> ;
   include WARM_UP count -> beats, describe -> ;
```

یک `include` کد یک کلاس دیگر را در این کلاس کپی می‌کند. این یک عملیات زمان کامپایل است که نه هزینه‌ای در زمان اجرا دارد و نه رابطه‌ای در زمان اجرا: دو کلاس پس از آن به هم متصل نیستند.

## بند

```
   include CLASS  old_name -> new_name , old_name -> ;
```

هر ورودی یک قابلیت را تغییر نام می‌دهد. `-> ;` بدون نام جدید آن را حذف می‌کند. هر چیزی که ذکر نشود، بدون تغییر وارد می‌شود.

تغییر نام بر آنچه *بیرون* می‌بیند اثر می‌گذارد. فراخوانی‌ها میان روال‌های گنجانده‌شده همچنان کار می‌کنند: اگر `describe`، `count` را فراخوانی کند و `count` به `beats` تغییر نام یابد، `describe`، `beats` را فراخوانی می‌کند.

## گنجاندن چند کلاس

```sather
   include WARM_UP;
   include COOL_DOWN;
```

مجاز است و همان روشی است که Sather چیزی را به دست می‌آورد که زبان‌های دیگر آن را «وراثت چندگانه» می‌نامند، بدون دردسر همیشگی، چون برخورد یک خطای کامپایل است و راه‌حلش تغییر نام دادن یا حذف یکی از آن‌هاست. هیچ چیزی با یک ترتیب تقدم که مجبور باشید از بر کنید حل نمی‌شود.

## private include

```sather
   private include WARM_UP;
```

کد را برای استفاده‌ی خود همین کلاس وارد می‌کند بدون اینکه آن را آشکار کند. زمانی مفید است که پیاده‌سازی را بخواهید و نه واسط را.

## این دو در کنار هم

شکل معمول برای یک خانواده از کلاس‌ها:

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class ACT_BASICS is
   minutes : INT is return 5; end;
end;

class JUGGLING < $ACT is
   include ACT_BASICS;
   name : STR is return "Juggling"; end;
end;
```

`< $ACT` می‌گوید که چه کاری می‌تواند انجام دهد؛ `include ACT_BASICS` بخشی از چگونگی را فراهم می‌کند. اگر نظرتان درباره‌ی چگونگی عوض شود، `<` جابه‌جا نمی‌شود.

## چرا این‌طور انجام می‌شود

یک کلاس انتزاعی هیچ کدی ندارد، پس نمی‌توان به‌طور تصادفی از آن ارث برد، و چیزی به نام ابرکلاس که رفتارش زیر پای شما تغییر کند وجود ندارد. استفاده‌ی مجدد یک کپی است که در زمان کامپایل برداشته می‌شود، از کلاسی که خودتان نام برده‌اید، در حالی که هر تغییر نام نوشته شده است.

هزینه‌اش این است که استفاده‌ی مجدد باید در هر کلاس به‌صراحت درخواست شود. این همان معاوضه است: تایپ بیشتر، هیچ چیز ضمنی.
