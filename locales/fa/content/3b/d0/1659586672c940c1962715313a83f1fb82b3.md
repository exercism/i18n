# دستورالعمل‌ها

دوستتان همین حالا پیامی برایتان فرستاده است که رازی مهم در آن است.
او نمی‌خواست خواندن آن برای دیگران آسان باشد، پس پیام را با انجام مجموعه‌ای از دستکاری‌های بیتی رمزنگاری کرده است.
برای کمک به رمزگشایی پیام، باید توابعی بنویسید.

## 1. شیفت دادن بیت‌ها به عقب

نخستین گام در رمزگشایی پیام این است که شیفت انجام‌شده در فرایند رمزنگاری را با شیفت دادن بیت‌ها به سمت راست خنثی کنید.
در ادامه‌ی فرایند رمزگشایی گام‌های دیگری هم هست که فرض می‌کند صفرها از سمت چپ وارد می‌شوند.

تابع `shift_back()` را پیاده‌سازی کنید که یک مقدار و تعداد جای شیفت را می‌گیرد و شیفت را انجام می‌دهد.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. تنظیم چند بیت

در گام بعد، چند بیت هست که باید روی ۱ تنظیم شوند.

تابع `set_bits()` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد و نتیجه‌ی تنظیم بیت‌های مقدار روی ۱ را برمی‌گرداند.
هر بیتی از `value` که بیت متناظر در `mask` هم ۱ باشد، باید روی ۱ تنظیم شود.
بقیه‌ی بیت‌ها باید بدون تغییر بمانند.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. وارونه کردن بیت‌های مشخص

برخی بیت‌ها هنگام رمزنگاری وارونه می‌شوند.
برای رمزگشایی پیام باید این بیت‌ها دوباره وارونه شوند.

تابع `flip_bits()` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد.
ماسک مشخص می‌کند کدام بیت‌های مقدار باید وارونه شوند.
اگر بیتی در `mask` برابر ۱ باشد، آن بیت در `value` وارونه می‌شود.
بقیه‌ی بیت‌ها بدون تغییر می‌مانند.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. صفر کردن بیت‌های مشخص

و در آخر، بیت‌های مشخصی هم هستند که همیشه به ۰ رمزگشایی می‌شوند.

تابع `clear_bits()` را پیاده‌سازی کنید که یک مقدار و یک ماسک می‌گیرد.
هر بیتی در `value` که بیت متناظر در ماسک برابر ۱ باشد، باید روی ۰ تنظیم شود.
بقیه‌ی بیت‌ها باید بدون تغییر بمانند.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
