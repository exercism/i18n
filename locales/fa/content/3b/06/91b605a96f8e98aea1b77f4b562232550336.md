# دستور `case`

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## نحوه‌ی تطبیق

مقدار بعد از `case` از بالا به پایین با هر مقدار `when` با استفاده از `=` مقایسه می‌شود. اولین تطبیق اجرا می‌شود و فقط همان یکی. بقیه‌ی بخش‌های `when` نادیده گرفته می‌شوند و اجرا بعد از `end` ادامه پیدا می‌کند.

هر نوعی که از `=` پشتیبانی کند می‌تواند به کار برود: `INT`، `CHAR`، `STR`، `BOOL`.

## بخش `else`

یک `case` بدون تطبیق که `else` نداشته باشد، هنگام اجرا یک خطای مهلک ایجاد می‌کند. همیشه یکی بنویسید. وقتی واقعاً نباید بقیه‌ی حالت‌ها اتفاق بیفتند، همان‌جا این موضوع را بگویید، نه اینکه آن را حذف کنید:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` بعداً می‌آید؛ تا آن زمان، برگرداندن یک مقدار پیش‌فرض معقول اشکالی ندارد.

## چه زمانی `if` را ترجیح دهیم

`case` یک مقدار را با ثابت‌ها مقایسه می‌کند. هر کار دیگری به `if` نیاز دارد:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

اگر بخواهید یک بازه را به زور در `case` بگنجانید، نتیجه‌ای طولانی‌تر و بدتر از `if`ی به دست می‌آید که جای آن را گرفته است.

## `case` به عنوان یک عبارت

`case` یک دستور است، نه یک عبارت؛ پس این کد Sather نیست:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

از داخل هر شاخه `return` کنید، یا داخل هر شاخه به یک متغیر مقدار بدهید.
