# تغییرپذیری

Cairo با طراحی مبتنی بر بلاکچین خود، به‌طور پیش‌فرض یک مدل حافظه‌ی تغییرناپذیر پیاده‌سازی می‌کند.
این یعنی وقتی مقداری در حافظه نوشته می‌شود، دیگر نمی‌توان آن را بازنویسی کرد و فقط می‌توان آن را خواند.
با این حال، Cairo سازوکاری برای ساختن متغیرهای تغییرپذیر با استفاده از کلیدواژه‌ی `mut` فراهم می‌کند.
وقتی متغیری تغییرپذیر تعریف می‌شود و مقدارش تغییر می‌کند، مقدار تازه در خانه‌ی حافظه‌ی جدیدی نوشته می‌شود و متغیر طوری به‌روزرسانی می‌شود که به خانه‌ی جدید اشاره کند.
این سازوکان ضمن حفظ مزایای تغییرناپذیری، انعطاف‌پذیری را ممکن می‌کند.

در مثال زیر، `x` به‌عنوان یک متغیر تغییرناپذیر تعریف می‌شود.
اگر مقدار `x` تغییر کند، کامپایلر خطا می‌دهد.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

می‌توانیم `x` را با استفاده از کلیدواژه‌ی `mut` به‌عنوان متغیری تغییرپذیر تعریف کنیم.
این کار اجازه می‌دهد مقدار `x` پس از تعریفش تغییر کند.

```rust
let mut x = 5;
x = 10;
```

در نهایت، تصمیم درباره‌ی اینکه از تغییرپذیری استفاده کنید یا نه به خودتان بستگی دارد و به اینکه در آن موقعیت خاص چه چیزی را روشن‌تر می‌دانید.

## ثابت

ثابت‌ها، مانند متغیرهای تغییرناپذیر، مقادیری هستند که به یک اسم مقید می‌شوند و اجازه‌ی تغییر ندارند، اما چند تفاوت میان ثابت‌ها و متغیرها وجود دارد:

- ثابت‌ها با کلیدواژه‌ی `const` تعریف می‌شوند
- نمی‌توانید از `mut` همراه ثابت‌ها استفاده کنید
- نوع مقدار باید همیشه به‌صورت صریح مشخص شود
- ثابت‌ها فقط در حوزه‌ی سراسری می‌توانند تعریف شوند
- ثابت‌ها فقط می‌توانند به عبارات ثابت مقداردهی شوند، نه به نتیجه‌ی مقداری که در زمان اجرا محاسبه می‌شود

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

می‌توان از ماکروی `consteval_int!` استفاده کرد تا متغیری `const` بسازیم که نتیجه‌ی محاسبه‌ای است.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## سایه‌اندازی

ممکن است، و اغلب هم روشی متداول است، که وقتی یک مقدار خاص دگرگون می‌شود، اسم یک متغیر را با تعریف دوباره‌ی آن از طریق چند فراخوانی `let` بازاستفاده کنید.
به این کار _سایه‌اندازی_ می‌گویند.
در واقع، متغیر دوم روی متغیر اول سایه می‌اندازد و هر استفاده از اسم متغیر را تا زمانی که یا خودش سایه شود یا حوزه به پایان برسد، به خود اختصاص می‌دهد.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

با استفاده از سایه‌اندازی، حتی می‌توانیم نوع متغیر را تغییر دهیم و در همان حال از همان اسم متغیر استفاده کنیم.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
