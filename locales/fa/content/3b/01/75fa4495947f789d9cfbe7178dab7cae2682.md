# دستورالعمل‌ها

دافنه روی سیستمی برای اجرا و ثبت نتایج آزمایش‌هایش کار می‌کرده است. بخشی از کد کمی طولانی و تکراری شده است، بنابراین از شما خواسته است چند عبارت `use` بنویسید تا به تمیزتر شدن آن کمک کنید.

## 1. تعریف تابع `with_retry`

گاهی آزمایش‌ها ممکن است به دلیل یک اشتباه یک‌باره شکست بخورند؛ بنابراین اگر آزمایشی شکست بخورد، دافنه می‌خواهد دوباره آن را امتحان کند تا ببیند بار دوم کار می‌کند یا نه.

تابع `with_retry` را تعریف کنید. این تابع، تابعی را به عنوان آرگومان می‌گیرد که نتیجه برمی‌گرداند.

اگر تابع مقدار `Ok` را برگرداند، `with_retry` باید همان مقدار را برگرداند.

اگر تابع مقدار `Error` را برگرداند، `with_retry` باید دوباره تابع را فراخوانی کند و نتیجه‌ی آن فراخوانی را برگرداند.

دافنه از این تابع به این شکل استفاده می‌کند:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. تعریف تابع `record_timing`

دافنه مدت زمان اجرای هر آزمایش را با فراخوانی یک تابع ثبت زمان، قبل و بعد از هر آزمایش، ثبت می‌کند.

تابع `record_timing` را تعریف کنید که دو آرگومان می‌گیرد:
- تابع ثبت زمان که هیچ آرگومانی نمی‌گیرد و `Nil` را برمی‌گرداند.
- تابع آزمایش که هیچ آرگومانی نمی‌گیرد و نتیجه‌ای برمی‌گرداند.

`record_timing` باید تابع ثبت زمان را فراخوانی کند، سپس تابع آزمایش را فراخوانی کند، بعد دوباره تابع ثبت زمان را فراخوانی کند و در پایان نتیجه‌ی تابع آزمایش را برگرداند.

دافنه از این تابع به این شکل استفاده می‌کند:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. تعریف تابع `run_experiment`

آزمایش‌ها از سه مرحله تشکیل می‌شوند: آماده‌سازی، اقدام و ثبت. هر سه مرحله نتیجه برمی‌گردانند و هر مرحله برای اجرا به نتیجه‌ی موفق مرحله‌ی قبلی نیاز دارد.

تابع `run_experiment` را تعریف کنید که چهار آرگومان می‌گیرد:
- اسم آزمایش به‌صورت یک `String`.
- تابع آماده‌سازی که هیچ آرگومانی نمی‌گیرد و نتیجه‌ای برمی‌گرداند.
- تابع اقدام که مقدار `Ok` تابع آماده‌سازی را به عنوان آرگومان می‌گیرد و نتیجه‌ای برمی‌گرداند.
- تابع ثبت که مقدار `Ok` توابع آماده‌سازی و اقدام را به عنوان آرگومان می‌گیرد و نتیجه‌ای برمی‌گرداند.

اگر هر سه تابع موفق شوند، `run_experiment` باید `Ok(#(experiment_name, recording_data))` را برگرداند.

اگر هر یک از توابع مقدار `Error` را برگرداند، `run_experiment` باید همان مقدار را برگرداند.

دافنه از این تابع به این شکل استفاده می‌کند:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
