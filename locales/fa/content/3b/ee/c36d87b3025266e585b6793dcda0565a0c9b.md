# دستورالعمل‌ها

الیس که می‌خواهد شعبده‌باز شود، باید چند مبنای ساده را تمرین کند.

او یک دسته کارت دارد که می‌خواهد با آن‌ها کار کند.

برای اینکه کار کمی ساده‌تر شود، او فقط از کارت‌های ۱ تا ۱۰ استفاده می‌کند.

دسته‌ی کارت‌ها با یک `Array` نمایش داده می‌شود؛ پایین دسته در ابتدای آرایه و بالای دسته در انتهای آرایه قرار دارد.

## 1. یک کارت به بالای دسته اضافه کنید

تابع `insert_top` را پیاده‌سازی کنید؛ این تابع رونوشتی از دسته را برمی‌گرداند که کارت جدید داده‌شده به بالای آن اضافه شده است.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. کارت بالایی را از دسته بردارید

تابع `remove_top_card` را پیاده‌سازی کنید؛ این تابع رونوشتی از دسته را برمی‌گرداند که کارت بالایی‌اش برداشته شده است.

اگر دسته‌ی داده‌شده خالی باشد، باید همان دسته‌ی اصلی بدون تغییر برگردانده شود.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. یک کارت به پایین دسته اضافه کنید

تابع `insert_bottom` را پیاده‌سازی کنید؛ این تابع رونوشتی از دسته را برمی‌گرداند که کارت جدید داده‌شده به پایین آن اضافه شده است.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. یک کارت را از پایین دسته بردارید

تابع `remove_bottom_card` را پیاده‌سازی کنید؛ این تابع رونوشتی از دسته را برمی‌گرداند که کارت پایینی‌اش برداشته شده است.

اگر دسته‌ی داده‌شده خالی باشد، باید همان دسته‌ی اصلی بدون تغییر برگردانده شود.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. اندازه‌ی دسته را بررسی کنید

تابع `check_size_of_stack` را پیاده‌سازی کنید؛ این تابع بررسی می‌کند که آیا اندازه‌ی دسته با `stack_size` داده‌شده برابر است یا نه.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
