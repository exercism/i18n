# درباره

`call` عنصر پایه‌ی فراگیری است که معنایش «همین حالا این نقل‌قول را اجرا کن» است. وقتی کامپایلر نقل‌قول را به‌صورت مستقیم ببیند، می‌تواند «اثر» آن را استنتاج کند؛ اما وقتی نقل‌قول از یک متغیر، یک آرایه یا یک پارامتر بیاید، باید اثر را خودتان اعلام کنید:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

اعلان `call( a b -- c )` به یک بررسی در زمان اجرا کامپایل می‌شود که تأیید می‌کند نقل‌قول واقعاً همان اثر اعلام‌شده را دارد. ناهمخوانی هم به‌جای وضعیت خراب پشته، به یک خطای روشن تبدیل می‌شود.

برخورد با نقل‌قول‌ها به‌عنوان داده، یعنی گذاشتنشان روی پشته، قرار دادنشان در آرایه‌ها و برگرداندنشان از واژه‌ها، یکی از عواملی است که کد الحاقی را تا این حد فشرده می‌کند. یک «برنامه» می‌تواند یک دنباله‌ی ساده باشد و `each` همراه با `call` برای تفسیر کردن آن کافی است.
