# Tests

روی MacOS/Linux، لطفاً اجرا کنید:

```sh
$ chmod +x gradlew
```

Tests را با دستور زیر اجرا کنید:

```sh
$ ./gradlew test
```

> اگر روی Windows هستید، از `gradlew.bat` استفاده کنید

## Tests نادیده‌گرفته‌شده

پس از اینکه اولین test(s) قبول شدند، ادامه دهید و حاشیه‌نویسی‌های `@Ignore` را که پیش از سایر tests قرار دارند، کامنت کنید یا حذف کنید.
