# مقدمه

`enum`ها در Cairo به شما امکان می‌دهند نوعی تعریف کنید که می‌تواند یکی از چندین گونه‌ی نام‌دار باشد.

## مبانی

`enum` که کوتاه‌شده‌ی enumerations است، همه‌ی مقادیر ممکن یک داده را به مجموعه‌ای از پیش تعریف‌شده محدود می‌کند. به مقادیر ممکن یک `enum`، «گونه» می‌گوییم:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

مقدارهای `enum` را با مشخص کردن گونه ایجاد کنید:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## تطبیق الگو

برای رسیدگی به گونه‌های مختلف `enum` از `match` استفاده کنید:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

هر شاخه از `match` به یک گونه از `enum` رسیدگی می‌کند.

## `enum`های دارای داده

گونه‌های `enum` می‌توانند داده‌ی بیشتری در خود نگه دارند:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

برای استخراج داده، الگو را تطبیق دهید:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
