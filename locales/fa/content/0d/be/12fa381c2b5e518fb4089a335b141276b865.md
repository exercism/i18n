# مقدمه

توابع می‌توانند برای یک یا چند آرگومان مقدار پیش‌فرض تعریف کنند. بیایید این تابع را در نظر بگیریم:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

هنگام کامپایل، Elixir یک تعریف تابع برای `number/0` (بدون آرگومان) و `number/1` (یک آرگومان) می‌سازد.

اگر بیش از یک آرگومان مقدار پیش‌فرض داشته باشد، مقادیر پیش‌فرض از چپ به راست روی تابع اعمال می‌شوند تا آرگومان‌های جاافتاده را پر کنند.

اگر تابع بیش از یک «بند» داشته باشد، آرگومان‌های پیش‌فرض باید در سرآیند تابع (تابعی بدون بدنه) و پیش از بندهای تابع تعریف شوند:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
