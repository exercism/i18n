# درباره

«کلاس»ها یکی از بلوک‌های سازنده‌ی بنیادین برنامه‌های Swift هستند.
آنها به شما امکان می‌دهند «ویژگی»های مرتبط (داده) و «متد»های مرتبط (توابع) را در واحدهای کارکردی خودکفا کنار هم قرار دهید.

### تعریف کلاس

برای تعریف یک کلاس، از کلیدواژه‌ی `class` استفاده کنید و بعد از آن اسم کلاس را بنویسید، به‌طوری که تعریف کلاس داخل آکولاد قرار بگیرد:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

بدنه‌ی یک کلاس می‌تواند ویژگی‌های ذخیره‌شده را در خود داشته باشد؛ این ویژگی‌ها مانند ثابت‌های معمولی (`let`) یا متغیرهای معمولی (`var`) تعریف می‌شوند و رفتار می‌کنند.

### نمونه

تعریف یک کلاس مانند یک نقشه عمل می‌کند: نوعی تازه تعریف می‌کند و توضیح می‌دهد مقادیر آن چه شکلی دارند، اما خودش به‌تنهایی هیچ «نمونه»ای نمی‌سازد.

برای ساختن یک نمونه از یک کلاس، «سازنده»ی آن را با نوشتن اسم کلاس و بعد از آن پرانتز فراخوانی کنید:

```swift
let someCharacter = GameCharacter()
```

این کار یک نمونه‌ی تازه می‌سازد که ویژگی‌هایش با مقادیر پیش‌فرضِ مشخص‌شده در تعریف کلاس مقداردهی اولیه می‌شوند.
برای ویژگی‌های «اختیاری» که مقدار پیش‌فرض صریحی ندارند (مثل `name`)، Swift آن‌ها را به‌صورت پیش‌فرض `nil` قرار می‌دهد.

### دسترسی به ویژگی

شما با استفاده از «نقطه‌گذاری» به ویژگی‌های یک نمونه دسترسی پیدا می‌کنید: اسم نمونه، یک نقطه (`.`)، و اسم ویژگی را بنویسید.
نقطه‌گذاری برای ویژگی‌های تودرتو هم کار می‌کند.

می‌توانید از نقطه‌گذاری برای خواندن مقادیر استفاده کنید و اگر ویژگی «تغییرپذیر» (`var`) باشد، مقدارهای تازه به آن اختصاص دهید:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### متد

علاوه بر ویژگی‌ها، کلاس‌ها می‌توانند متد تعریف کنند، یعنی توابعی که به کلاس وابسته‌اند.

متدها را داخل بدنه‌ی کلاس با استفاده از نحوه‌ی نگارش استاندارد `func` تعریف کنید.
اگر یک متد ویژگی‌ای را تغییر دهد، آن ویژگی باید با `var` اعلام شود:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

متدها را روی یک نمونه، درست مثل ویژگی‌ها، با نقطه‌گذاری فراخوانی کنید:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### `self`

هر نمونه از یک کلاس یک ویژگی ضمنی به اسم `self` دارد که به خود نمونه اشاره می‌کند.
با اینکه هنگام اشاره به ویژگی‌ها یا متدها معمولاً حذف می‌شود، `self` معمولاً برای تفکیک اسم ویژگی‌ها از اسم پارامترهای متد به کار می‌رود، وقتی که هم‌نام باشند.
