# مقدمه

## آرایه

در C#، به ساختارهای داده‌ای که می‌توانند صفر یا چند عنصر را در خود نگه دارند، «مجموعه» می‌گویند. یک **آرایه** مجموعه‌ای است که اندازه/طول ثابتی دارد و عناصر آن همگی باید از یک نوع باشند. می‌توان با استفاده از اندیس، مقداری به عناصر آرایه نسبت داد یا مقداری را از آن بازیابی کرد. آرایه‌های C# صفرپایه هستند، یعنی اندیس نخستین عنصر همیشه ۰ است:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

آرایه‌ها را می‌توان با نوعی نگارش کوتاه هم تعریف کرد که به شما امکان می‌دهد هم آرایه را بسازید و هم مقدارش را تعیین کنید. حالا که کامپایلر می‌تواند بگوید آرایه چند عنصر خواهد داشت، می‌توان طول را حذف کرد:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

می‌توان آرایه‌ها را با فراخوانی متدها یا پراپرتی‌های یک نمونه‌ی آرایه، یا با استفاده از متدهای استاتیک تعریف‌شده در کلاس `Array` دستکاری کرد.

## حلقه‌ی For

یک حلقه‌ی `for` به شما امکان می‌دهد کدی را در یک حلقه بارها اجرا کنید تا اینکه یک شرط برقرار شود.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

یک حلقه‌ی `for` از چهار بخش تشکیل شده است:

1. مقداردهی اولیه: یک‌بار پیش از ورود به حلقه اجرا می‌شود. معمولاً برای تعریف متغیرهایی به کار می‌رود که درون حلقه استفاده می‌شوند.
2. شرط: پیش از هر بار اجرای حلقه ارزیابی می‌شود. حلقه تا زمانی که این شرط `true` ارزیابی شود، به اجرا ادامه می‌دهد.
3. شمارنده: پس از هر بار اجرای حلقه اجرا می‌شود. معمولاً برای تغییر (اغلب: افزایش/کاهش) متغیرهای حلقه به کار می‌رود.
4. بدنه: کدی که در هر بار اجرای حلقه اجرا می‌شود.

## حلقه‌ی Foreach

اینکه یک آرایه در واقع یک «مجموعه» هم هست یعنی علاوه بر دسترسی به مقادیر از طریق اندیس، می‌توانید با یک حلقه‌ی `foreach` روی همه‌ی مقادیر آن پیمایش کنید:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
