# دستورالعمل‌ها

مدیر صحنه می‌خواهد متن تمرین تایپ شود و چند بخش از آن با تکرار کردن یا به هم چسباندن موارد ساخته می‌شود.

هر چهار وظیفه را در کلاس `REHEARSAL_SCRIPT` پیاده‌سازی می‌کنید.

## 1. یک نشانه را تکرار کنید

با گرفتن یک نشانه و یک عدد، آن نشانه را به همان تعداد پشت سر هم برگردانید، بدون اینکه چیزی بین‌شان قرار بگیرد.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

اگر یک مورد را صفر بار تکرار کنید، رشته‌ی خالی به دست می‌آید.

## 2. حروف اول بازیگران

با گرفتن فهرست بازیگران، حرف اول هر اسم را پشت سر هم برگردانید.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. سطرها را شماره‌گذاری کنید

با گرفتن سطرهای یک صحنه، آن‌ها را از یک شروع شماره‌گذاری کنید، هر کدام در سطر خودش.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

یک خط جدید *بین* سطرها وجود دارد و بعد از سطر آخر هیچ خط جدیدی نیست. صحنه‌ای که سطر ندارد، رشته‌ی خالی است.

## 4. یک سطر را فریاد بزنید

یک سطر را طوری برگردانید که هر حرف آن به حرف بزرگ تبدیل شده باشد.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
