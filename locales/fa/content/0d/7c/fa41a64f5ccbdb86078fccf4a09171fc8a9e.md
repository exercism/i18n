# درباره

هر مقداری می‌تواند یک خطا باشد. `throw` (در `kernel`) علامت می‌دهد؛ اثر پشته‌ای واژه‌ی جاری رها می‌شود و کنترل تا نزدیک‌ترین `recover` دربرگیرنده باز می‌گردد.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` یک واژه‌ی تجزیه است که یک‌جا هم یک کلاس تاپل خطا *و* هم یک واژه‌ی سازنده تعریف می‌کند:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

این کار به هر خطای سفارشی یک کلاس یکتا، یک سازنده‌ی دوستانه برای پرتاب و یک محمول کلاس (`name?`) می‌دهد تا خطاهای گرفته‌شده را با آن بسنجید:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

برای پاک‌سازی به سبک finally، `cleanup` را در `continuations` ببینید. برای شرط‌های قابل راه‌اندازی مجدد، `condition` را ببینید.
