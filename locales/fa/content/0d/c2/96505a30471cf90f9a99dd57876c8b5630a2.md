# دستورالعمل‌ها

هنگام آماده‌شدن برای پختن کلوچه برای دوستانتان، متوجه می‌شوید که باید برخی از اندازه‌های به‌کاررفته در دستور پخت را تبدیل کنید.
چون فقط با دستگاه متریک آشنایید، باید راهی پیدا کنید تا اندازه‌های رایج آشپزی آمریکایی را برای راحتی خودتان به میلی‌لیتر (mL) تبدیل کنید.

برای حل مسئله از این جدول تبدیل استفاده کنید:

| واحد برای تبدیل | حجم | بر حسب میلی‌لیتر (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| US cup          | 1      | 240                 |
| US fluid ounce  | 1      | 30                  |
| US teaspoon     | 1      | 5                   |
| US tablespoon   | 1      | 15                  |

چون برنامه‌نویسی مستعد و در حال یادگیری هستید، تصمیم می‌گیرید میلی‌لیتر را به‌عنوان «واحد واسط» به کار ببرید تا تبدیل از هر واحد فهرست‌شده به واحد دیگر (حتی به خودش) آسان شود.

## 1. گرفتن مؤلفه‌ی عددی از یک جفت حجم

متد `KitchenCalculator.get_volume` را پیاده‌سازی کنید.
این متد با گرفتن یک جفت حجم، فقط مؤلفه‌ی عددی را برمی‌گرداند.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. تبدیل جفت حجم به میلی‌لیتر

متد `KitchenCalculator.to_milliliter` را پیاده‌سازی کنید.
این متد با گرفتن یک جفت حجم، حجم را با استفاده از جدول تبدیل به میلی‌لیتر تبدیل می‌کند.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. تبدیل جفت حجم میلی‌لیتری به واحد دیگر

متد `KitchenCalculator.from_milliliter` را پیاده‌سازی کنید.
این متد با گرفتن یک جفت حجم و واحد موردنظر، حجم را با استفاده از جدول تبدیل به واحد موردنظر تبدیل می‌کند.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. تبدیل از هر واحد به هر واحد

متد `KitchenCalculator.convert` را پیاده‌سازی کنید.
این متد با گرفتن یک جفت حجم و واحد موردنظر، حجم داده‌شده را به واحد موردنظر تبدیل می‌کند.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
