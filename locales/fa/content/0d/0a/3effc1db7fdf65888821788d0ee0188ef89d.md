# منابع

* کانال IRC ‎#haskell در Libera Chat که هدفش «تشویق یادگیری و بحث درباره‌ی Haskell، برنامه‌نویسی تابعی و برنامه‌نویسی به‌طور کلی» است. اطلاعات بیشتر درباره‌ی کانال IRC را می‌توانید در [صفحه‌ی ویکی Haskell برای این کانال](https://wiki.haskell.org/IRC_channel) پیدا کنید.
* [Hoogle](https://www.haskell.org/hoogle/) یک موتور جستجوی API Haskell است. این امکان را به شما می‌دهد که اگر فقط اسم تابع را می‌دانید، ببینید چه کاری انجام می‌دهد. شاید جالب‌تر اینکه، از جستجو بر اساس امضای نوع هم پشتیبانی می‌کند: اگر می‌خواهید بدانید چه توابعی امضای نوع [(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b]) را دارند، Hoogle کمک می‌کند تا بفهمید!
* [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell) را می‌توانید برای جستجوی مشکلتان استفاده کنید و ببینید آیا قبلاً به آن پاسخ داده شده است. همچنین می‌توانید سؤال بپرسید و به سؤال‌ها پاسخ دهید.
* [/r/haskell](https://www.reddit.com/r/haskell) سابردیت Haskell است.
* [صفحه‌ی جامعه‌ی Haskell](https://www.haskell.org/community/) به تعدادی از جوامعی پیوند می‌دهد که برنامه‌نویسان Haskell در آن‌ها گرد هم می‌آیند و تعامل می‌کنند؛ از اینجا می‌توانید رسانه‌ی ارتباطی ترجیحی خودتان را انتخاب کنید.
