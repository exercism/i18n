# دستورالعمل‌ها

چند توسعه‌دهنده‌ی «دیگر» روی پروژه‌ی خودروی کنترل از راه دور [exercise:csharp/remote-control-competition]() کار می‌کرده‌اند. شما را فراخوانده‌اند تا کد را مرتب کنید.

## 1. جدا کردن دغدغه‌ها بین خود خودرو و سامانه‌ی تله‌متری

کلاس `RemoteControlCar` را بازآرایی کنید تا متدها و ویژگی‌های تله‌متری جدا شوند و از طریق یک ویژگی `Telemetry` به آن‌ها دسترسی داشته باشید.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. جلوگیری از وابستگی بیش از حد کدهای دیگر به نوع `Telemetry`

مطمئن شوید که نمونه‌ی `Telemetry` نتواند خارج از دامنه‌ی خودرو ایجاد شود.

## 3. جلوگیری از وابستگی کدهای دیگر به `struct` `Speed`

مطمئن شوید که `struct` `Speed` نتواند خارج از دامنه‌ی کلاس `RemoteControlCar` استفاده شود.

## 4. جلوگیری از وابستگی کدهای دیگر به `enum` `SpeedUnits`

مطمئن شوید که `enum` `SpeedUnits` نتواند خارج از دامنه‌ی کلاس `RemoteControlCar` استفاده شود.
