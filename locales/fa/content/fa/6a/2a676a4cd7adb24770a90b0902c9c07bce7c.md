# نصب

ساده‌ترین راه نصب PureScript از طریق Node.js و NPM است.

اگر Node.js روی رایانه‌تان نصب نیست، می‌توانید آن را از [وب‌سایت Node.js](https://nodejs.org/) دانلود کنید. وقتی Node.js نصب و اجرا شد، این فرمان را در ترمینال وارد کنید تا کامپایلر PureScript و ابزار ساخت Spago نصب شوند:

    npm install --global purescript spago

اطلاعات بیشتر را می‌توانید در [مخزن PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md) پیدا کنید.
