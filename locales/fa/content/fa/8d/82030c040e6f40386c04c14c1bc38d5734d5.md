# دستورالعمل‌ها

در این تمرین، قوانینی برای وب‌سایت یک سینما می‌سازید.

## 1. بررسی کنید که آیا تماشاگر فیلم مشمول تخفیف سالمندان است

این سینما برای «بازنشستگان» تخفیف ارائه می‌دهد.
هر کسی که ۶۰ سال یا بیشتر داشته باشد، برای بلیت ۱۰٫۰۰ می‌پردازد.
هر کسی که جوان‌تر باشد، کل ۱۵٫۰۰ را می‌پردازد.

متد `Moviegoer#ticket_price` را با استفاده از یک عبارت شرطی سه‌گانه بنویسید.

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. بررسی کنید که آیا تماشاگر فیلم مجاز به تماشای فیلم‌های ترسناک است

این سینما یک سیستم ساده‌شده‌ی تأیید سن دارد.
اگر ۱۸ سال یا بیشتر داشته باشید، می‌توانید فیلم‌های ترسناک تماشا کنید.
اگر جوان‌تر باشید، نمی‌توانید.

متد `Moviegoer#watch_scary_movie?` را پیاده‌سازی کنید.
این متد باید برگرداند که آیا فرد مجاز به تماشای فیلم هست یا نه.

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. بررسی کنید که آیا تماشاگر فیلم مشمول پاپ‌کورن رایگان است

این سینما یک برنامه‌ی باشگاه فیلم دارد.
اعضا هنگام تماشای هر فیلمی پاپ‌کورن رایگان می‌گیرند.

متد `Moviegoer.claim_free_popcorn!` را پیاده‌سازی کنید.
اگر بیننده عضو باشگاه فیلم باشد، باید پاپ‌کورن رایگانش را دریافت کند.
اگر عضو نباشد، متد باید استثنای `UnsupportedOperation` را که در بالای کد تعریف شده است، پرتاب کند.

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
در این تمرین، انتظار می‌رود که استثنای `UnsupportedOperation` را برای یک محدوده‌ی مشخص تعریف کنید.
~~~~
