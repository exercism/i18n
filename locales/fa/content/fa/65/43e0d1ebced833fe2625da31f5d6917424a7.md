# برای نگه‌دارندگان

## اسکریپت کمکی برای ساختن testهای Fortran: create_fortran_test.py

راه آسانی برای ساختن test یک تمرین این است که از اسکریپت `bin/create\_fortran\_test.py` استفاده کنید.

با این اسکریپت یک فایل اولیه‌ی <exercise>_test.f90 بسازید که می‌تواند به‌عنوان قالب test شما به کار برود.
معمولاً باید تابع `response` را در فایل تولیدشده با فراخوانی درست تابع جایگزین کنید.

همچنین توجه داشته باشید که Fortran با نویسه‌های خاصی مانند `\n` و `\t` مشکل دارد، پس در کار با آن‌ها دقت ویژه‌ای به خرج دهید.

### پیش‌نیازها

- CMake و کامپایلر Fortran آماده‌ی کار
- Python ۳.x (شاید بتوانید آن را با Python ۲ هم به کار بیندازید، اما من برای سازگاری با نسخه‌های قدیمی‌تر تلاشی نکرده‌ام)
- آخرین نسخه‌ی https://github.com/exercism/problem-specifications.git
- git

### روند کار برای ساختن یک test جدید

- آخرین تغییرات را از `exercism/problem-specifications` بگیرید، مثلاً `git clone git@github.com:exercism/problem-specifications.git`
- یک شاخه‌ی جدید برای ساختن تمرین تازه بسازید، مثلاً `git checkout -b exercise-bob`
- این اسکریپت را برای مثالی که می‌خواهید بسازید اجرا کنید
- فایل `config/CMakeLists.txt` را در پوشه‌ی تمرین کپی کنید (برای این کار می‌توانید از `bin/update-cmake-files` استفاده کنید)
- تمرین را طوری پیاده‌سازی کنید که کار کند
- testهای مشکل‌دار احتمالی را اصلاح کنید (مثلاً به «Test 20» و «Test 24» در `exercise/bob` نگاه کنید)
- مطمئن شوید که دستور `ctest` بدون خطا تأیید می‌شود
- راه‌حل خود را در `.meta/example.f90` کپی کنید و پیاده‌سازی واقعی را از فایل تمرین حذف کنید، مثلاً `bob.f90`
- پوشه‌های `.docs` و `.meta` را به‌روزرسانی کنید
  - `cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md`
    - عبارت «# Description» را با «# Instructions» جایگزین کنید
  - فایل `.meta/tests.toml` را دستی پر کنید (تا زمانی که یک راه خودکار وجود داشته باشد)
  - فایل `.meta/config.json` را دستی پر کنید (تا زمانی که یک راه خودکار وجود داشته باشد)
    - از `../problem-specifications/exercises/bob/metadata.yml` استفاده کنید
- با تغییرات خود یک pull request باز کنید

برای مثال bob:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### تغییر دادن `CMakeLists.txt`

وقتی فایل cmake را تغییر می‌دهید، نسخه‌ی اصلی را در `config/` به‌روزرسانی کنید و با `bin/update-cmake-files` آن را در همه‌ی پوشه‌های تمرین کپی کنید.

## راه‌حل

وقتی راه‌حلی آماده شد، آن را در پوشه‌ی `.meta` با اسم `example.f90` کپی کنید.

شاید بخواهید یک پیاده‌سازی اسکلتی از تابع یا زیرروال را نگه دارید که به دانش‌آموز کمک می‌کند، و فایلی با اسم تمرین را در پوشه‌ی تمرین بگذارید.
