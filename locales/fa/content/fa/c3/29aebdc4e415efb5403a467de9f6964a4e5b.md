# کلاس

کلاس‌ها مفهوم محوری در [برنامه‌نویسی شیءگرا][object-oriented-programming] هستند.
[در Crystal همه‌چیز یک شیء است][everything-is-an-object]، هر شیء یک نوع دارد و می‌تواند به برخی متدها پاسخ دهد.
کلاس‌ها نقشه‌ی ساخت اشیاء هستند و مقادیر اولیه‌ی وضعیت، مانند متغیرها، و پیاده‌سازی‌های رفتار، مانند متدها، را فراهم می‌کنند.
اشیاء نمونه‌های کلاس‌اند که همه‌ی متغیرهای نمونه و وضعیت‌ها را نگه می‌دارند.

## تعریف کلاس

کلاس با کلیدواژه‌ی `class` تعریف می‌شود و پس از آن، اسم کلاس به شکل `UpperCamelCase` نوشته می‌شود.

```crystal
class Account
end
```

## ساختن یک نمونه

برای [ساختن یک نمونه از یک کلاس][new-initialize]، اسم کلاس را با متد `new` فراخوانی کنید.

```crystal
class Account
end

account = Account.new
```

در مثال بالا، متغیر `account` یک نمونه از کلاس `Account` است.

هنگام ساختن یک نمونه، یک متد ویژه به اسم `initialize` نقش سازنده را ایفا می‌کند.
این متد زمانی فراخوانی می‌شود که یک نمونه ساخته می‌شود.
سازنده به شما اجازه می‌دهد وضعیت اولیه‌ی نمونه را تعیین کنید.
متد `initialize` می‌تواند آرگومان بگیرد؛ آرگومان‌ها هنگام ساختن نمونه پاس داده می‌شوند.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
متد `initialize` نمی‌تواند به‌صورت دستی مقداری برگرداند؛ در عوض، `new` نمونه‌ی تازه‌ساخته‌شده را برمی‌گرداند.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## متدهای نمونه

متد نمونه متدی است که در دسترس یک نمونه از کلاس قرار دارد و می‌توان آن را روی آن نمونه فراخوانی کرد.
متدهای نمونه با کلیدواژه‌ی `def` و پس از آن اسم متد تعریف می‌شوند.
این متدها داخل تعریف کلاس تعریف می‌شوند.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## متغیرهای نمونه

[متغیرهای نمونه][instance-variable] متغیرهایی هستند که در همه‌ی متدهای نمونه در دسترس‌اند.
برای دسترسی به یک متغیر نمونه باید یک متد نمونه تعریف کنید.
می‌توان آن‌ها را در متد `initialize` مقداردهی اولیه کرد.
این متغیرها با پیشوند `@` تعریف می‌شوند.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

متغیرهای نمونه را می‌توان داخل تعریف کلاس هم تعریف کرد.

```crystal
class Account
  @age = 0
end
```

### متغیرهای نمونه همراه با مقداردهی اولیه

متغیرهای نمونه را می‌توان با آرگومانی که به متد `initialize` پاس داده می‌شود مقداردهی اولیه کرد.
از آنجا که Crystal نمی‌تواند نوع آرگومان به‌کاررفته هنگام مقداردهی اولیه را استنتاج کند، باید مشخص شود.
اگر می‌خواهید درباره‌ی این موضوع بیشتر بخوانید، می‌توانید این را بخوانید: [type-inference][type-inference].
برای مشخص کردن نوع متغیر می‌توانید از نماد `:` و پس از آن نوع استفاده کنید.
برای نمونه، اگر می‌خواهید یک متغیر نمونه به اسم `balance` از نوع `Int32` بسازید، می‌توانید این کار را بکنید: `@balance : Int32`.
یا اگر می‌خواهید یک متغیر نمونه به اسم `raining` از نوع `Bool` بسازید، می‌توانید این کار را بکنید: `@raining : Bool`.

برای پیاده‌سازی این کار چند راه وجود دارد؛ یکی اینکه در متد `initialize` آرگومان را همراه با نوعش اعلام کنید و سپس متغیر نمونه را به آرگومان نسبت دهید، مانند مثال زیر:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

راه دیگر این است که نوع متغیر نمونه را در تعریف کلاس، به شکل `@<variable> : <Type>` اعلام کنید، مانند مثال زیر:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## تغییر متغیرهای نمونه

متدها می‌توانند متغیرهای نمونه را تغییر دهند.
این متدها را می‌توان روی نمونه‌ی کلاس فراخوانی کرد.
وقتی متدی یک متغیر نمونه را تغییر می‌دهد، آن تغییر فقط در همان نمونه از کلاسی که متد را روی آن فراخوانی کرده‌اید در دسترس است.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## متدهای کلاس

[متدهای کلاس][class-methods] متدهایی هستند که برای یک کلاس تعریف می‌شوند، نه برای نمونه‌های آن.
این متدها راهی برای ساختن متدهایی فراهم می‌کنند که به وضعیت نمونه وابسته نیستند.
متدهای کلاس با کلیدواژه‌ی `def` و پس از آن `self.<method name>` تعریف می‌شوند.
`self` ارجاعی است به فضای نامی که `self` از آن فراخوانی می‌شود.
در این مورد، به کلاس `Account` اشاره دارد.
این دقیقاً همان چیزی است که اگر `Account.` را می‌نوشتید، اما `self.` روش ترجیحی است.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
