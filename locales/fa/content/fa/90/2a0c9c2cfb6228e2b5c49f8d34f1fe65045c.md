# مقدمه

«رکورد» مجموعه‌ای از «فیلد»هاست (که می‌توانند انواع مختلفی داشته باشند) که به هم مربوط‌اند. برای تعریف یک رکورد از کلیدواژه‌ی `type` استفاده می‌شود. فیلدهای یک رکورد بین کاراکترهای `{` و `}` تعریف می‌شوند و هر فیلد یک اسم _و_ یک نوع دارد. برای ساختن یک رکورد، اسم فیلدها را مشخص کنید و بین کاراکترهای `{` و `}` به آن‌ها مقداری نسبت دهید. هنگام ساختن یک رکورد، باید به همه‌ی فیلدها مقدار داده شود. به مقادیر فیلدهای یک نمونه‌ی رکورد می‌توان با نقطه‌گذاری دسترسی داشت.

هنگام تعریف یا ساختن یک رکورد، هر فیلد باید یا در خطی جداگانه نوشته شود یا، اگر در یک خط قرار دارد، با نقطه‌ویرگول (`;`) از هم جدا شود.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

از آنجا که رکوردها تغییرناپذیرند، پس از ساخته شدن یک رکورد، مقادیر فیلدهایش هرگز تغییر نمی‌کنند. اگر می‌خواهید مقادیر یک رکورد را تغییر دهید، کلیدواژه‌ی `with` به شما امکان می‌دهد نسخه‌ای از یک رکورد موجود بسازید، اما با مقادیر تازه برای یک یا چند فیلد.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

رکوردها _برابری ساختاری_ دارند، یعنی دو نمونه از یک رکورد با مقادیر یکسان، معادل‌اند.

علاوه بر اینکه می‌توان با نقطه‌گذاری به فیلدهای یک رکورد دسترسی داشت، رکوردها را می‌توان در اتصال‌ها و در تطبیق الگو نیز _تجزیه_ کرد:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
