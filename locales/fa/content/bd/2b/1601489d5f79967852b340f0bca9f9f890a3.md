# مقدمه

نوع `Result` این امکان را به یک تابع می‌دهد که یک مقدار واحد برگرداند که همه‌ی موارد زیر را نشان دهد:

- اینکه عملیات موفق شده یا شکست خورده است
- در صورت موفقیت، مقدار حاصل از عملیات
- در صورت شکست، دلیل شکست

## کاربرد

`Result` یک نوع عمومی است که دو نوع زیربنایی در خود دارد:

- نوع مقدار حاصل در یک عملیات موفق
- نوعی که دلیل شکست را در صورت شکست نشان می‌دهد

نوع `Result` همچنین یک [اتحاد تفکیک‌شده][discriminated-union] است با حالت‌های ممکن زیر:

- `Ok <value>` که یک نتیجه‌ی موفق را نشان می‌دهد
- `Error <reason>` که یک شکست را نشان می‌دهد

تابع زیر نشان می‌دهد که چطور می‌توان یک مقدار `Result` ساخت:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

در این مثال، مقدار `Ok` یک رشته است (اسم داده‌شده) و مقدار `Error` هم یک رشته است (علت خطا، به شکلی که برای انسان خوانا باشد).

## خواندن محتوای یک مقدار `Result`

تعریف نوع و امضای تابع زیر را در نظر بگیرید:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

کدی که تابع `openFile` را فراخوانی می‌کند می‌تواند برای مدیریت حالت‌های موفقیت و شکست از «تطبیق الگو» استفاده کند، مانند مثال زیر:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```

[discriminated-union]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/discriminated-unions
