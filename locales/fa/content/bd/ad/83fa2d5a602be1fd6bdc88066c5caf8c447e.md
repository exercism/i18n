# مقدمه

## طول عمر منابع

[concept:csharp/resource-cleanup]() از رابط `IDispose` استفاده می‌کند تا نشان دهد که وقتی دیگر به یک شیء نیازی نیست، منبع آن یا وضعیت دیگری از برنامه باید آزاد یا بازنشانی شود (و تکیه بر جمع‌کننده‌ی زباله این نتیجه را نمی‌دهد یا سطح لازم از کنترل را فراهم نمی‌کند) و این‌که متد `IDisposable.Dispose()` جای طبیعی چنین عملیات پاک‌سازی است.

سازه‌ی دیگری هم وجود دارد به نام بلوک `using` که از دید فراخوانی‌کننده اجازه می‌دهد تمام مدیریت طول عمر منابع در یک دستور واحد جمع شود.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

در مثال بالا، منابع سیستم فایل مرتبط با `file` وقتی از بلوک `using` خارج می‌شویم به سیستم‌عامل بازگردانده می‌شوند.

برای این‌که این الگو کار کند، متغیر در دستور `using` باید از نوع ارجاعی باشد که رابط `IDisposable` را پیاده‌سازی می‌کند و باید در متد `Dispose()` خود منابع را آزاد کند یا وضعیت برنامه را بازنشانی کند.

C# 8 بهبودی به این الگو اضافه می‌کند. دستور `using` می‌تواند در ابتدای یک بلوک قرار بگیرد.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

توسعه‌دهندگان Java ممکن است این را معادلی برای مکانیزم _مدیریت خودکار منابع_ بدانند که در Java 7 معرفی شد.
