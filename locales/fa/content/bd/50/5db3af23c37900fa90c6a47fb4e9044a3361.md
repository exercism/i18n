# پیوست دستورالعمل‌ها

## DSL خودتان را بسازید

در این تمرین، کاملاً آزاد هستید که DSL گرافِ دلخواه خودتان را طراحی کنید.

Testها فقط می‌خواهند چند گراف مشخص بسازید؛ اینکه چطور آن‌ها را بسازید کاملاً به خودتان بستگی دارد.

برای اینکه سرگرمی دو برابر شود، می‌توانید به‌صورت اختیاری تابع `to_dot` را پیاده‌سازی کنید که گراف شما را به قالب DOT تبدیل می‌کند!

## نمایش گراف

DSL خودتان را در `Graph.roc` تعریف کنید و بعد از آن برای ساختن گراف‌هایی استفاده کنید که stub درخواست می‌کند.
دو شناسه‌ی گره در هر `EdgeId` باید به ترتیب حروف الفبا مرتب شده باشند.

| تعریف | گرافی که باید ساخته شود |
| --- | --- |
| `empty_graph` | یک گراف خالی |
| `graph_with_one_node` | یک گره |
| `graph_with_one_node_with_attribute` | یک گره با یک ویژگی |
| `graph_with_one_edge` | یک یال |
| `graph_with_one_attribute` | یک ویژگی گراف |
| `graph_with_nodes_edges_and_attributes` | گره‌ها، یال‌ها و ویژگی‌ها |
| `multiple_edges_on_one_line` | چند یال که در یک خط بیان شده‌اند |
| `only_1_edge_between_nodes` | فقط یک یال بین هر جفت گره |
