# Debug

وقتی یک test شکست می‌خورد، پیامی نمایش داده می‌شود که توضیح می‌دهد چه چیزی اشتباه شده و مربوط به کدام ورودی است.
می‌توانید مقادیر دلخواه را در برنامه‌تان با ارسالشان به متد `debug` بررسی کنید (که در `exercism/test_runner` در دسترس است).
این کار مقادیر را ثبت می‌کند و خروجی را به شما نشان می‌دهد.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
