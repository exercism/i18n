# مقدمه

«رشته» نوع داده‌ی JavaScript برای ذخیره‌ی داده‌های متنی است.

## ساختن یک رشته

یک رشته را با قرار دادن متن داخل «گیومه‌ی تک» یا «گیومه‌ی جفت» می‌سازید.
در Exercism از گیومه‌ی تک استفاده می‌شود.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## رشته به‌عنوان فهرستی از کاراکترها

می‌توان با یک رشته مانند فهرستی از «کاراکترها» رفتار کرد که اولین کاراکتر اندیس `0` دارد.
می‌توانید با استفاده از «کروشه» و اندیس حرفی که می‌خواهید بردارید، به یک کاراکتر مشخص از رشته دسترسی پیدا کنید.

```javascript
'cat'[1];
// => 'a'
```

می‌توانید با دسترسی به ویژگی `length` تعداد کاراکترهای یک رشته را تعیین کنید.

```javascript
'cat'.length;
// => 3
```

## به هم چسباندن و متدها

ساده‌ترین راه برای به هم چسباندن رشته‌ها، استفاده از عملگر جمع `+` است.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

رشته‌ها «متدهای کمکی» زیادی در اختیارتان می‌گذارند؛ برای دیدن فهرست کامل، [مستندات MDN درباره‌ی متدهای رشته][mdn-string-methods] را ببینید.
فهرست زیر چند متد کمکی پرکاربرد را نشان می‌دهد.

- [`toUpperCase`][mdn-to-upper-case] و [`toLowerCase`][mdn-to-lower-case]: تبدیل همه‌ی کاراکترها به حروف بزرگ یا کوچک
- [`trim`][mdn-trim]: حذف فاصله‌های خالی از ابتدا و انتهای رشته
- [`includes`][mdn-includes]، [`startsWith`][mdn-starts-with] و [`endsWith`][mdn-ends-with]: تعیین اینکه رشته‌ی دیگری بخشی از رشته‌ی داده‌شده هست یا نه
- [`slice`][mdn-slice]: جدا کردن بخشی از رشته

رشته‌ها در JavaScript تغییرناپذیرند. بنابراین یک «تغییر»، مثلاً به کمک برخی از متدهای بالا، همیشه به‌جای تغییر رشته‌ی اصلی، یک رشته‌ی جدید می‌سازد.
