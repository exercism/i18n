# مقدمه

## شروع کار

### متغیر

شما می‌توانید با تعریف یک [متغیر][constants-variables] مقادیری را ذخیره کنید و به آن‌ها اسم بدهید. بعد از تعریف یک متغیر، می‌توانید از اسم آن برای اشاره به آن مقدار در سراسر کدتان استفاده کنید. متغیرها _قابل تغییر_ هستند، یعنی مقدارشان می‌تواند بعد از تعریف تغییر کند.

یک متغیر را با «کلیدواژه»ی `var` تعریف کنید:

```swift
var variableName = 10
```

Swift یک زبان با نوع‌بندی ایستا است؛ یعنی نوع هر مقدار در زمان کامپایل معلوم است. می‌توانید یک نوع را به‌صورت صریح با [حاشیه‌نویسی‌های نوع][type annotations] اعلان کنید، یا بگذارید کامپایلر Swift [نوع را از مقدار تخصیص‌یافته استنتاج کند][type-inferring]:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

می‌توانید مقدار یک متغیر را با عملگر انتساب (`=`) به‌روزرسانی کنید:

~~~~exercism/note
نوع یک متغیر بعد از اعلان‌شدن نمی‌تواند تغییر کند.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

می‌توانید یک متغیر را بدون مقدار اولیه و با مشخص کردن نوعش اعلان کنید، اما باید قبل از استفاده از آن به آن مقدار بدهید:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### ثابت

[ثابت‌ها][constants-variables] هم یک اسم را به یک مقدار پیوند می‌دهند، اما مقدارشان بعد از انتساب قابل تغییر نیست. این‌ها _تغییرناپذیر_ هستند. یک ثابت را با کلیدواژه‌ی `let` تعریف کنید:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### عملگر حسابی

Swift [عملگرهای حسابی][arithmetical-operators] استانداردی برای محاسبات پایه فراهم می‌کند:

- جمع: `+`
- تفریق: `-`
- ضرب: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### تابع

در Swift، [توابع][functions] «بلوک‌های کد» مستقلی هستند که یک کار مشخص را انجام می‌دهند. توابع می‌توانند ورودی بگیرند، یک مقدار برگردانند و به‌عنوان مقدار به توابع دیگر پاس داده شوند. یک تابع را با کلیدواژه‌ی `func` تعریف می‌کنید که بعد از آن اسم تابع، فهرست پارامترها داخل پرانتز و یک نوع بازگشتی اختیاری می‌آید:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

توابع Swift از [برچسب‌های آرگومان][argument-labels] استفاده می‌کنند که باعث می‌شود کد مثل جمله‌های طبیعی خوانده شود:

- **برچسب آرگومان** هنگام فراخوانی تابع استفاده می‌شود.
- **اسم پارامتر** داخل بدنه‌ی تابع برای دسترسی به مقدار استفاده می‌شود.

اگر فقط یک اسم مشخص کنید، Swift از آن هم به‌عنوان برچسب آرگومان و هم به‌عنوان اسم پارامتر استفاده می‌کند:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

اگر هنگام فراخوانی تابع برچسب آرگومان نمی‌خواهید، قبل از اسم پارامتر یک زیرخط (`_`) بنویسید:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

همه‌ی پارامترهای تابع به‌صورت پیش‌فرض ثابت (`let`) هستند؛ یعنی مقدارشان داخل بدنه‌ی تابع قابل تغییر نیست.

برای برگرداندن یک مقدار از یک تابع، نوع بازگشتی را بعد از `->` مشخص کنید و از کلیدواژه‌ی `return` استفاده کنید:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

وقتی یک تابع مقداری برنمی‌گرداند، نوع بازگشتی آن `Void` است (معادل یک تاپل خالی، `()`). در چنین توابعی می‌توانید هم نوع بازگشتی `-> Void` و هم دستور `return` را حذف کنید.

### کامنت

Swift از دو شکل [کامنت][comments] پشتیبانی می‌کند:

- **کامنت‌های تک‌خطی** با `//` شروع می‌شوند و تا انتهای خط ادامه پیدا می‌کنند.
- **کامنت‌های چندخطی** بین `/*` و `*/` قرار می‌گیرند.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
