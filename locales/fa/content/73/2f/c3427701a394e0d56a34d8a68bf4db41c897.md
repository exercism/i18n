# درباره

[عبارت‌های switch][switch-expressions] رفتاری مشابه [دستورهای switch][switch-statements] دارند که در [concept:csharp/switch-statements]() بررسی شده‌اند. این عبارت‌ها از نوعی جدول تصمیم پشتیبانی می‌کنند که شرط‌های ورودی را به کنش‌ها یا مقدارها نگاشت می‌کند.

در هسته‌ی عبارت switch، _تطبیق الگو_ قرار دارد. در تمرین کدنویسی، مقدارها را با الگوهای `const` تطبیق دادیم. در این حالت، ورودی‌های `switch` یک _عبارت بازه‌ای_ است که با مقدارهای `const` و مقدارهایی که _گاردهای case_ به کار می‌برند تطبیق داده می‌شود.

حالت‌ها (که با نام _بازوهای switch_ هم شناخته می‌شوند) به ترتیب متن ارزیابی می‌شوند و به‌محض یافتن تطبیق، فرایند متوقف می‌شود و مقدار متناظر برگردانده می‌شود.

حالت `_` که آخرین مورد در فهرست است، برای اطمینان از اینکه تطبیق جامع است و برای پرهیز از خطاهای احتمالی زمان اجرا مفید است.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

یک «بازو» از `switch` زمانی انتخاب می‌شود که الگو با متغیر بازه‌ای تطبیق داشته باشد و نتیجه‌ی هر گارد case «درست» باشد.

عبارت‌های switch همچنین از [الگوهای نوع][pattern-matching] و تطبیق بازگشتی پشتیبانی می‌کنند.
