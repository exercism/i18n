# درباره

[Lua](https://lua.org) یک زبان اسکریپتی ساده اما قدرتمند، کارآمد، سبک و قابل جاسازی است. این زبان از سال ۱۹۹۳ در [PUC-RIO](https://www.puc-rio.br/) در برزیل توسط تیم روبرتو ایِرُزالیمشکی، والدمار سِلس و لوئیز هنریکه دی فیگیریدو طراحی، پیاده‌سازی و نگهداری می‌شود.

## توضیحات

توضیحات تک‌خطی در Lua با `--` شروع می‌شوند و توضیحات چندخطی با `--[[` شروع و با `]]` پایان می‌یابند.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## متغیرها

در Lua سه نوع متغیر وجود دارد: متغیرهای سراسری، متغیرهای محلی و فیلدهای جدول. برای ساده نگه داشتن ماجرا، اینجا فقط متغیرهای محلی توضیح داده می‌شوند. به‌طور پیش‌فرض همه‌ی متغیرها سراسری هستند، پس باید متغیرهای محلی را با کلیدواژه‌ی `local` به‌عنوان محلی اعلام کنیم.
```lua
local x
```

می‌توان با استفاده از عملگر `=` مقداری را به یک متغیر نسبت داد.
```lua
local x = 1
```

دامنه‌ی یک متغیر `local` محدود به بلوکی است که در آن اعلام شده است. یک بلوک می‌تواند بدنه‌ی یک ساختار کنترلی، بدنه‌ی یک تابع، یا فایل یا رشته‌ای باشد که متغیر در آن اعلام شده است.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## توابع

یک تابع با کلیدواژه‌ی `function` اعلام می‌شود و مانند متغیرها به‌طور پیش‌فرض سراسری است. تعریف یک تابع یک اسم، فهرستی از پارامترها و یک بدنه دارد. تابع وقتی به کلیدواژه‌ی `return` برسد خارج می‌شود و همه‌ی مقادیری را که پس از آن فهرست شده‌اند برمی‌گرداند. بدون یک `return` مشخص، تابع `nil` را برمی‌گرداند.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## جدول‌ها

جدول‌ها تنها سازوکار ساختاربندی داده در Lua هستند و بسیار قدرتمندند. از آن‌ها برای نمایش آرایه‌ها، مجموعه‌ها، شیءها، ماژول‌ها و بسیاری موارد دیگر استفاده می‌شود. در اصل، یک جدول در Lua یک آرایه‌ی انجمنی است.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

این فقط نگاهی کوچک است که برای بخش بعدی لازم است. بعداً با جزئیات به این موضوع برمی‌گردیم.

## ماژول‌ها

یک ماژول مجموعه‌ای از کد است که در یک فایل مبدأ `.lua` ذخیره می‌شود. هر چیزی که ماژول صادر می‌کند در یک جدول ذخیره می‌شود و این جدول در پایان فایل برگردانده می‌شود. پس جدول اساساً نقش نوعی فضای نام را ایفا می‌کند.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

سپس می‌توان آن ماژول را از طریق تابع `require` که آن جدول را برمی‌گرداند، در فایل دیگری بارگذاری کرد.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

وقتی `say.hello` را می‌بینیم، به یاد می‌آوریم که یعنی «تابع `hello` از ماژول `say`». اما وقتی بدانیم `say-hello.lua` ما یک جدول برمی‌گرداند و به بخش جدول‌ها برگردیم، متوجه می‌شویم که در Lua این عبارت به معنای «ایندکس کردن جدول `say` با استفاده از رشته‌ی `hello` به‌عنوان کلید» است.  

هرچند خوب است که یک ماژول جدول برگرداند، اما برگرداندن هر نوع دیگری مانند یک تابع هم به همان اندازه ممکن است.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
