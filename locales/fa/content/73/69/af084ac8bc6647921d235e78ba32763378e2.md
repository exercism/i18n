# دستورالعمل‌ها

شما به عنوان مدیر سیستم در یک شرکت بزرگ در مونیخ آلمان کار می‌کنید. یکی از مسئولیت‌های شما مدیریت حساب‌های ایمیل است.

شکایت‌هایی را از افراد شنیده‌اید که می‌گویند نمی‌توانند به آقای Müller ایمیل بفرستند. خیلی زود متوجه می‌شوید که بیشتر شرکت از یک کلاینت ایمیل قدیمی استفاده می‌کند که `müller@firma.de` را به دلیل کاراکتر غیر ASCII به عنوان یک نشانی ایمیل معتبر نمی‌شناسد.

گفتن به مردم که کلاینت ایمیل قدیمی محبوب‌شان را کنار بگذارند، نبردی شکست‌خورده است. پس تصمیم می‌گیرید برای همه‌ی حساب‌های ایمیل، نام‌های مستعار پاک‌سازی‌شده بسازید.

## 1. نام‌های کاربری موجود را با حذف همه‌ی کاراکترها جز حروف کوچک پاک‌سازی کنید

تابع `sanitize/1` را پیاده‌سازی کنید. این تابع باید یک نام کاربری را به صورت `charlist` دریافت کند و نام کاربری‌ای را برگرداند که همه‌ی کاراکترهایش جز حروف کوچک حذف شده باشند.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. زیرخط‌ها را مجاز کنید

تابع `sanitize/1` را گسترش دهید. این تابع نباید زیرخط‌ها را از نام کاربری حذف کند.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. حروف آلمانی را جایگزین کنید

۴ کاراکتر غیر ASCII در الفبای آلمانی وجود دارد و همه‌ی آن‌ها جانشین‌های ASCII شناخته‌شده‌ای دارند.

| حرف آلمانی | جانشین ASCII |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

تابع `sanitize/1` را گسترش دهید. این تابع باید حروف آلمانی را طبق جدول جایگزین کند. می‌توانید با خیال راحت فرض کنید که همه‌ی نام‌های کاربری از قبل با حروف کوچک نوشته شده‌اند.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
