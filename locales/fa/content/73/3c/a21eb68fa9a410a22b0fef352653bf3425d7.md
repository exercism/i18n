# Tests

می‌توانید از ویرایشگر آنلاین در وب‌سایت Exercism برای حل تمرین‌ها استفاده کنید.
یا تمرین‌ها را روی کامپیوتر خود دانلود کنید، آن‌ها را به‌صورت محلی حل کنید و سپس آن‌ها را در Exercism ارسال کنید.
بقیه‌ی این سند درباره‌ی کار کردن به‌صورت محلی است.

## Exercism CLI

برای دانلود و ارسال تمرین‌ها به ابزار خط فرمان `exercism` نیاز دارید.
برای دستورالعمل‌های دانلود و پیکربندی آن، [مستندات exercism cli][exercism-cli] را ببینید.

برای دانلود یک تمرین، این کار را انجام دهید:

```bash
exercism download --track 8th --exercise hello-world
```

و به پوشه‌ی تمرین بروید:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

یا اگر از Windows استفاده می‌کنید:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

توجه کنید که می‌توانید فضای کاری exercism خودتان را با دستور `exercism configure` به دست آورید.

## اجرای تست‌ها به‌صورت محلی

برای اجرای تست‌های یک تمرین، باید در پوشه‌ی درست تمرین باشید.
سپس تست‌ها را با این دستور اجرا کنید:

```bash
8th -f test.8th
```

## تست‌های غیرفعال

حل کردن یک تمرین یعنی کاری کنید که همه‌ی تست‌هایش موفق شوند.
به‌طور پیش‌فرض، وقتی تست‌ها را اجرا می‌کنید، فقط یک تست (اولین تست) اجرا می‌شود.
این کار عمدی است، چون به شما امکان می‌دهد فقط روی موفق شدن همان یک تست تمرکز کنید.
وقتی آن تست موفق شد، می‌توانید خط `SKIP-REST-OF-TESTS` را به زیر آن منتقل کنید و تست بعدی را فعال کنید.

### لغو غیرفعال بودن تست‌ها

برای اجرای همه‌ی تست‌ها، از جمله تست‌هایی که بعد از واژه‌ی `SKIP-REST-OF-TESTS` می‌آیند، می‌توانید متغیر محیطی `RUN_ALL_TESTS` را روی مقدار `true` تنظیم کنید.
یک راه برای تنظیم آن فقط برای مدت اجرای تست‌ها این است (macOS و Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## ارسال راه‌حل شما

برای بارگذاری راه‌حل خود در وب‌سایت Exercism با استفاده از ابزار exercism:

```bash
exercism submit
```

توجه کنید که می‌توانید کد خود را حتی اگر همه‌ی تست‌ها را موفق نشده باشد، بارگذاری کنید.
این کار زمانی مفید است که گیر کرده‌اید و به کمک یک مربی نیاز دارید.
