# مقدمه

به‌طور کلی دو نوع حلقه وجود دارد:

1. حلقه بزنید تا یک شرط برآورده شود.
2. روی عنصرهای یک مجموعه حلقه بزنید.

هر دو در R ممکن‌اند، هرچند نوع اول ممکن است رایج‌تر باشد.

## `while` و `repeat`

برای مسائل بی‌پایانی که از پیش نمی‌دانیم چند بار باید دور حلقه بچرخیم، R حلقه‌ی `while` با یک شرط دارد و حلقه‌ی `repeat` بدون شرط (معادل `while (TRUE)`).

شکل پایه‌ای آن نسبتاً ساده است:

```R
while (condition) {
  do_something()
}
```

در این حالت، برنامه آن‌قدر دور حلقه می‌چرخد تا دیگر `condition` برابر `TRUE` نباشد.

دو راه برای خروج زودهنگام از حلقه وجود دارد:

- `break` باعث خروج از حلقه می‌شود و اجرا از خط بعدی پس از آکولاد بسته‌ی حلقه `}` ادامه می‌یابد.
- `return(x)` اجرای تابع جاری را متوقف می‌کند و مقدار بازگشتی `x` را به فراخواننده برمی‌گرداند.

با در دسترس بودن این گزینه‌ها، گاهی راحت است که با `repeat { ... }` یک حلقه‌ی «بی‌نهایت» بسازیم و بعد با یافتن یک شرط توقف در بدنه‌ی حلقه، `break` یا `return` را فعال کنیم.

این ۳ گونه معادل‌اند و همه با `x == 0.4444...` پایان می‌یابند

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## پیمایش یک بردار

این کار در R اغلب لازم نیست.
همان‌طور که در مفاهیم دیگر بحث شد، بسیاری از توابع روی کل بردار کار می‌کنند.

با این حال، گاهی نمی‌توان از حلقه‌های صریح پرهیز کرد.
این موضوع به‌ویژه در این موارد درست است:

- بدنه‌ی حلقه عوارض جانبی داشته باشد، مثل چاپ کردن یا ورودی/خروجی فایل.
- حلقه آن‌قدر ادامه یابد تا معیاری مشخص برآورده شود، پس از تعداد نامعلومی تکرار.

شرط حلقه باید داخل پرانتز باشد.
مثل بدنه‌ی توابع، برای بدنه‌های حلقه‌ی یک‌خطی، آکولادها اختیاری‌اند (اما اغلب نوشته می‌شوند).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

اگر تکرار جاری شرطی را برآورده نکند، می‌توان با `next` بی‌درنگ به تکرار بعدی پرید:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

اگر به اندیس عددی نیاز دارید، از `seq_along()` استفاده کنید.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

استفاده از `i in 1:length(v)` توصیه _نمی‌شود_، چون وقتی `length(v)` صفر باشد می‌تواند مشکل ایجاد کند.
بازه‌ی `1:0` معادل `c(1, 0)` است، پس بدنه‌ی حلقه اجرا می‌شود و احتمالاً شکست می‌خورد.
تابع `seq_along()` طوری طراحی شده که این حالت را درست مدیریت کند.
