# مقدمه

## وراثت

«وراثت» یکی از مفاهیم اصلی «برنامه‌نویسی شیءگرا» است.
این مفهوم نشان‌دهنده‌ی یک رابطه‌ی «هست-یک» است.
معنای آن در برنامه‌نویسی دقیقاً همان معنایی است که در انگلیسی دارد: به ارث بردن ویژگی‌ها از «والد» (در برنامه‌نویسی، ویژگی‌ها معمولاً «توابع» و «متغیرها» هستند).

یک «کلاس» به نام `Animal` را در نظر بگیرید، همان‌طور که نشان داده شده است:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` یک کلاس والد است، چون ویژگی‌های این کلاس می‌توانند به همه‌ی حیوانات تعمیم یابند.

حیوانی به نام `Lion` را در نظر بگیرید که کلاسی به این شکل دارد:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
از «حاشیه‌نویسی» `Override` برای این استفاده می‌شود که نشان دهد «متد»ی در یک «زیرکلاس»، «متد»ی از «ابرکلاس» را بازنویسی می‌کند.
استفاده از آن اکیداً ضروری نیست، اما یک رویه‌ی خوب است.
~~~~

حالا هر زمان که این کار را انجام می‌دهیم:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

توجه: کلاس `Animal` را با `Lion` نمونه‌سازی می‌کنیم.
خروجی به این شکل خواهد بود:

```java
Lion here!!
```

بر اساس برنامه‌نویسی شیءگرا، انواع مختلفی از وراثت وجود دارد، اما Java فقط از برخی از آن‌ها پشتیبانی می‌کند («چندسطحی» و «سلسله‌مراتبی»).
برای مطالعه‌ی بیشتر درباره‌ی آن، لطفاً [این مطلب][java-inheritance] را بخوانید.
