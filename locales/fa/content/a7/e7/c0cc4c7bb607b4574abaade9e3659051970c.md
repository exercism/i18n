# دستورالعمل‌ها

شما تازه به تیمی پیوسته‌اید که یک خط لوله‌ی داده‌ی مبتنی بر jq را نگهداری می‌کند.
در اولین جلسه‌ی برنامه‌نویسی دونفره‌تان، همکار جدیدتان کنجکاو می‌شود:
*«آیا می‌دانید `add`، `reverse` و `map` در پشت صحنه چگونه کار می‌کنند؟ بیایید بررسی کنیم؛ امتحان کنید و خودتان آن‌ها را با استفاده از بازگشت پیاده‌سازی کنید، بدون استفاده از توابع درون‌ساخت.»*

## 1. یک تابع برای جمع زدن اعداد یک آرایه پیاده‌سازی کنید

فیلتر درون‌ساخت `add` را دوباره پیاده‌سازی می‌کنیم تا بازگشت را تمرین کنیم.
_حالت پایه_ این است که مجموع یک آرایه‌ی خالی **صفر** است.

خودتان آن را با یک تابع بازگشتی پیاده‌سازی کنید؛ از `add` درون‌ساخت استفاده نکنید.

```jq
[5, 4, 6, 10] | array_add     # => 25
```

## 2. یک آرایه را برعکس کنید

فیلتر درون‌ساخت `reverse` را دوباره پیاده‌سازی می‌کنیم.
_حالت پایه_ این است که برعکس کردن یک آرایه‌ی خالی، یک آرایه‌ی خالی است.

خودتان آن را با یک تابع بازگشتی پیاده‌سازی کنید؛ از `reverse` درون‌ساخت استفاده نکنید.

```sh
[5, 4, 6, 10] | array_reverse   # => [10, 6, 4, 5]
```

## 3. اعمال `map` روی یک آرایه

فیلتر درون‌ساخت `map` را دوباره پیاده‌سازی می‌کنیم.
این تابع یک فیلتر را به‌عنوان پارامتر می‌گیرد، آن فیلتر را برای هر عنصر از آرایه‌ی ورودی اجرا می‌کند و خروجی‌ها را در یک آرایه‌ی جدید برمی‌گرداند.
_حالت پایه_ این است که آرایه‌ی خالی به آرایه‌ی خالی نگاشت می‌شود.

خودتان آن را با یک تابع بازگشتی پیاده‌سازی کنید؛ از `map` درون‌ساخت استفاده نکنید.

```sh
[5, 4, 6, 10] | array_map(. + 10)   # => [15, 14, 16, 20]
```
