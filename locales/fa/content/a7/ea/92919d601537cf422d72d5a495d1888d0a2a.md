# دستورالعمل‌ها

در این تمرین، خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است که به این شکل قالب‌بندی شده است: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

شما سه کار دارید. هر کار یک خط لاگ می‌گیرد و از شما می‌خواهد کاری با آن انجام دهید.

## 1. گرفتن پیام از یک خط لاگ

تابع `message` را طوری پیاده‌سازی کنید که پیام یک خط لاگ را برگرداند:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

هر فاصله‌ی خالی ابتدا یا انتهای رشته باید حذف شود:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. گرفتن سطح لاگ از یک خط لاگ

تابع `logLevel` را طوری پیاده‌سازی کنید که سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. قالب‌بندی مجدد یک خط لاگ

تابع `reformat` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند و پیام را اول و سطح لاگ را بعد از آن داخل پرانتز قرار می‌دهد:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
