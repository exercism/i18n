# درباره

JavaScript یک «عملگر افزایش» و یک «عملگر کاهش» دارد.
این عملگرها یک متغیر را در جای خودش تغییر می‌دهند.
عملگر `++` یک واحد به یک عدد اضافه می‌کند و عملگر `--` یک واحد از یک عدد کم می‌کند.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

مثال بالا عملگر افزایش/کاهش پسوندی را نشان می‌دهد.
در این حالت، عملگر بعد از متغیر قرار می‌گیرد و مقدار برگشتی عبارت، مقدار متغیر _پیش از_ افزایش/کاهش است.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

گونه‌ی پیشوندی هم وجود دارد که در آن عملگر پیش از متغیر قرار می‌گیرد.
در این حالت، مقدار برگشتی، مقدار متغیر _پس از_ افزایش/کاهش است.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
