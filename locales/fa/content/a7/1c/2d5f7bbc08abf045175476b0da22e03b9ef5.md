# دستورالعمل‌ها

لوسی، موجود فضایی Lisp، عددها را دوست دارد و به نظرشان بعضی از آن‌ها «باشکوه» هستند.

از شما می‌خواهند کمکشان کنید تا توابعی بنویسند که عددها را باشکوه‌تر کنند.

اینکه از نظر لوسی چه چیزی یک عدد را باشکوه می‌کند می‌تواند تغییر کند، بنابراین توابع باید انعطاف‌پذیر باشند.

## 1. باشکوه بسازید

برای تبدیل یک فهرست از عددها به فهرستی از عددهای باشکوه‌تر، باید تابعی به اسم `make-magnificent-maybe` بنویسید که یک تابع برای اعمال روی عددها و یک فهرست از عددها می‌گیرد.
نتیجه‌ی آن باید فهرستی از عددها باشد که (بر اساس تابعی که داده شده) باشکوه‌تر هستند.

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. فقط بهترین

پس از اینکه (به امید موفقیت) عددها را باشکوه‌تر کردید، لوسی می‌خواهد فقط عددهایی را ببیند که واقعاً باشکوه‌اند.

آن‌ها مطمئناً می‌دانند که 1 *هرگز* باشکوه نیست، بنابراین باید آن را حذف کنید.

اما جز این، لوسی گاهی نظرش را عوض می‌کند، بنابراین دوباره تابعی به شما می‌دهند که می‌گوید یک عدد باشکوه است یا نه.

باید تابعی به اسم `only-the-best` بنویسید که یک تابع و یک فهرست از عددها می‌گیرد و فقط بهترین عددها را برمی‌گرداند (نه `1` و نه عددهایی که تابع برای آن‌ها به «درست» ارزیابی می‌شود).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
