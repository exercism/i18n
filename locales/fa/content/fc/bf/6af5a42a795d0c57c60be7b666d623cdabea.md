# Char

`Char` یک نوع داده در Crystal است که یک [نقطه‌ی کد یونیکد][unicode] ۳۲ بیتی را نمایش می‌دهد.
اندازه‌ی آن‌ها باعث می‌شود از نظر حافظه به‌صرفه باشند و ویژگی‌های خاصی داشته باشند که رشته‌ها ندارند.
آن‌ها با گیومه‌ی تک (`'`) ساخته می‌شوند و فقط اجازه می‌دهند یک نقطه‌ی کد یونیکد درونشان قرار بگیرد.

```crystal
'a' # => 'a'
'a'.class # => Char
```

در Crystal، وقتی با رشته‌ها کار می‌کنید، کار کردن با `Char` بسیار رایج است، چون تعداد قابل‌توجهی از متدهای کلاس `String` یا `Char` برمی‌گردانند یا `Char` را به عنوان آرگومان می‌گیرند.
برای مثال، متد [`String#[]`][index] یک `Char` برمی‌گرداند، یا متد [`String#chars`][chars] مجموعه‌ای از `Char` را برمی‌گرداند.

## افزایش و کاهش

چون `Char` یک نقطه‌ی کد یونیکد ۳۲ بیتی است، از افزایش و کاهش پشتیبانی می‌کند؛ به این ترتیب اگر `'a'` داشته باشید، با اضافه کردن یک، `'b'` به دست می‌آید.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

همچنین متدی به اسم [`Char#succ`][succ] وجود دارد که کاراکتر بعدی در جدول یونیکد را برمی‌گرداند و [`Char#pred`][pred] که کاراکتر قبلی در جدول یونیکد را برمی‌گرداند.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## الحاق

چون `Char` فقط برای نمایش یک نقطه‌ی کد یونیکد ۳۲ بیتی به کار می‌رود، دو کاراکتر را نمی‌توان به هم الحاق کرد.
بنابراین `Char` را فقط می‌توان به رشته الحاق کرد.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## متدهای ویژگی

Crystal چند متد برای گرفتن اطلاعات درباره‌ی یک کاراکتر دارد؛ مثلاً اینکه عدد است یا حرف، یا اینکه حرف بزرگ است یا کوچک.
در ادامه فهرستی از برخی از این متدها آمده است؛ برای فهرست کامل، [API مربوط به Char][char-api] را ببینید:

| متد                              | توضیح                                                |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | اگر `Char` عدد باشد `true` برمی‌گرداند               |
| [`Char#letter?`][letter]         | اگر `Char` حرف باشد `true` برمی‌گرداند               |
| [`Char#lowercase?`][lowercase]   | اگر `Char` حرف کوچک باشد `true` برمی‌گرداند          |
| [`Char#uppercase?`][uppercase]   | اگر `Char` حرف بزرگ باشد `true` برمی‌گرداند          |
| [`Char#ascii?`][ascii]           | اگر `Char` یک کاراکتر ASCII باشد `true` برمی‌گرداند  |
| [`Char#whitespace?`][whitespace] | اگر `Char` یک کاراکتر فضای سفید باشد `true` برمی‌گرداند |

## تبدیل

### تبدیل بین نقطه‌های کد و `Char`

چون `Char` یک نقطه‌ی کد یونیکد ۳۲ بیتی است، می‌توانید بین `Char` و نقطه‌های کد (`Int`) تبدیل انجام دهید.
این کار با استفاده از متد [`Char#ord`][ord] انجام می‌شود که نقطه‌ی کد `Char` را برمی‌گرداند، یا متد [`Int#chr`][chr] که `Char` متناظر با آن نقطه‌ی کد را برمی‌گرداند.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### تبدیل میان انواع

مانند سایر انواع داده، `Char` هم چند متد برای تبدیل میان انواع دارد.
رایج‌ترین آن‌ها متد `Char#to_s` است که `Char` را به رشته تبدیل می‌کند. علاوه بر آن، متد `Char#to_i` هم وجود دارد که `Char` را به `Int` تبدیل می‌کند و متد `Char#to_f` که `Char` را به `Float` تبدیل می‌کند.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
