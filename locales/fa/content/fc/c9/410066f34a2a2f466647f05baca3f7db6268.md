# Debug

وقتی یک test شکست می‌خورد، پیامی نمایش داده می‌شود که توضیح می‌دهد چه چیزی اشتباه شده و مربوط به کدام ورودی بوده است.

چاپ کردن مقادیر و محتوای متغیرها هم می‌تواند به درک آنچه اتفاق می‌افتد کمک کند.
PHP می‌تواند مقادیر را به این روش‌ها چاپ کند:

- `echo 'Debug message';` برای چاپ یک رشته به انتخاب خودتان
- `var_dump($variable);` برای درک بهتر یک مقدار، مثلاً نوعی که PHP آن را می‌بیند
