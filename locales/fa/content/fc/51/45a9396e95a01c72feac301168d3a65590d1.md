# راهنماها

## کلی

- برای استخراج چند آرگومان از پارامترهای تابع، می‌توانید آن‌ها را با `...<args>` بسته‌بندی کنید.
- برای استفاده از rest و spread از عملگر `...` استفاده کنید.

## 1. ساخت فهرستی از همه‌ی واگن‌ها

- چند آرگومان در پارامترهای تابع را می‌توان با [ساختار `...<args>` (spread)][spread-syntax] بسته‌بندی کرد.

## 2. انتقال دو عنصر اول به انتهای آرایه

- می‌توانید با [انتساب تجزیه (`...`)][destructuring-assignment] مجموعه‌ای از پارامترها را از هم باز کنید.
  این کار به شما امکان می‌دهد دو عنصر اول یک `array` را جدا کنید و بقیه را دست‌نخورده نگه دارید.
- برای افزودن یک `array` دیگر به یک `array` موجود، می‌توانید از عملگر `...` برای «spread» کردن `array` استفاده کنید.

## 3. افزودن مقادیر جاافتاده

- با باز کردن همراه با عملگر rest (`...`)، می‌توانید عنصر اول یک `array` را جدا کنید و بقیه را دست‌نخورده نگه دارید.
- برای افزودن یک `array` دیگر به یک `array` موجود، می‌توانید از عملگر `...` برای «spread» کردن `array` استفاده کنید.

## 4. گسترش اطلاعات مسیریابی

- برای افزودن یک `object` دیگر به یک `object` موجود، می‌توانید از عملگر `...` برای «spread» کردن `object` استفاده کنید.

## 5. جدا کردن زمان رسیدن از اطلاعات مسیریابی

- برای استخراج یک مقدار از یک `object` و دست‌نخورده نگه داشتن بقیه، می‌توانید از عملگر rest (`...`) استفاده کنید.

[spread-syntax]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax
[destructuring-assignment]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment
