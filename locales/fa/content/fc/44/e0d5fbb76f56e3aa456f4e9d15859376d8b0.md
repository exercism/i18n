# درباره

[Groovy](http://www.groovy-lang.org/) زبان پویا، قدرتمند و با تایپ اختیاری بنیاد Apache است که قابلیت‌های تایپ ایستا و کامپایل ایستا را هم دارد.

Groovy به لطف نحوه‌ی نگارش مختصر و آسان برای یادگیری، در پی بالا بردن بهره‌وری برنامه‌نویسان است.
این زبان نوشتن اسکریپت، ساختن زبان خاص دامنه، فرابرنامه‌نویسی در زمان اجرا و زمان کامپایل، و برنامه‌نویسی تابعی را ساده می‌کند.

به کل اکوسیستم کتابخانه‌های Java دسترسی می‌دهد و به‌طور یکپارچه با برنامه‌های Java ادغام می‌شود.

می‌توان از آن به‌عنوان یک زبان اسکریپت‌نویسی ساده استفاده کرد یا آن را به چارچوب‌های پیچیده‌ی Java افزود.

پشت فناوری‌هایی مانند این‌هاست:
* Gradle،
* Spock،
* Ratpack،
* Grails
* و اسکریپت‌نویسی در Jenkins.

همچنین کار با آن سرگرم‌کننده است.
