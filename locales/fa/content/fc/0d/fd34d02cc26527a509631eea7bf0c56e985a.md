# کاراکتر

یک **کاراکتر** یک حرف، رقم، فاصله یا نشانه است. نوع کاراکتر در Sather برابر `CHAR` است و کاراکتر را بین نقل‌قول‌های تکی می‌نویسند.

```sather
   initial : CHAR is
      return 'M';
   end;
```

نقل‌قول تکی برای یک کاراکتر است و نقل‌قول دوتایی برای یک رشته. `'M'` و `"M"` دو نوع متفاوت‌اند و جای همدیگر به کار نمی‌روند.

## بیرون کشیدن کاراکتر از یک رشته

یک رشته ردیفی از کاراکترها است و کروشه‌ها با شماره‌ی موقعیت به یکی از آن‌ها دسترسی می‌دهند؛ شمارش از صفر شروع می‌شود، درست مثل یک آرایه.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## بررسی یک کاراکتر

| فراخوانی | پاسخ |
| --- | --- |
| `c.is_alpha` | آیا حرف است؟ |
| `c.is_digit` | آیا یکی از `0` تا `9` است؟ |
| `c.is_upper` | آیا حرف بزرگ است؟ |
| `c.is_lower` | آیا حرف کوچک است؟ |

هرکدام `true` یا `false` برمی‌گردانند.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## تغییر بزرگی و کوچکی حروف

`.upper` حرف بزرگ یک حرف را برمی‌گرداند و `.lower` حرف کوچک آن را. هر چیزی که حرف نباشد، بدون تغییر برگردانده می‌شود.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## کاراکترها به شکل عدد

هر کاراکتر یک عدد دارد. `.int` آن عدد را می‌دهد و `.char` یک عدد را دوباره به کاراکتر تبدیل می‌کند.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

خود این عددها به‌ندرت مهم‌اند. آنچه مهم است این است که حروف `a` تا `z` به ترتیب و کنار هم قرار دارند، بنابراین `'c'.int - 'a'.int` برابر ۲ است، یعنی `c` چقدر در الفبا جلوتر است. همین است که یک چرخ رمز را کار می‌اندازد.
