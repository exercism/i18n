# دستورالعمل‌ها

ما در حال راه‌اندازی یک باشگاه پنیر هستیم که از ML استفاده می‌کند تا بر اساس سابقه و سلیقه‌ی مشتریان پنیردوستمان، پنیرهای تازه‌ای را برای عرضه انتخاب کند.

اعضای جدید باید یک نظرسنجی اولیه را پر کنند تا ما بتوانیم داده‌های پایه‌ای را برای شروع جمع‌آوری کنیم.
از این طریق مشخص شده است که زیرمجموعه‌ای از مشتریان پرشور وجود دارند که در نقدهایشان ظرافت کمی دارند.
چون این کار می‌تواند به‌طور جبران‌ناپذیری باعث سوگیری یک الگوریتم دقیق‌تر شود، الگوریتم جداگانه‌ای برای رسیدگی به نیازهای آنان در نظر گرفته شده است.
از شما خواسته شده است چند تابع کمکی بنویسید تا داده‌های آنان را سر و سامان دهید.

~~~~exercism/note
هرچند ممکن است راه‌های مختلفی برای حل تمرین‌های زیر وجود داشته باشد، هرکدام را می‌توان با حداکثر دو تابع مرتبه‌بالا حل کرد.
~~~~

## 1. دسته‌بندی مشتریان

سیستم امتیازدهی بر پایه‌ی پنج ستاره است که به‌سادگی از اعداد صحیح `1:5` تشکیل شده است.
مشتریان پرشور فقط امتیاز `1` یا `5` می‌دهند و می‌خواهیم بدانیم آیا یک مشتری چنین رفتاری دارد یا نه.

تابع `all_15()` را پیاده‌سازی کنید که یک بردار از امتیازها می‌گیرد و اگر همه‌ی امتیازها `1` یا `5` باشند `true` و در غیر این صورت false برمی‌گرداند.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. اسم‌گذاری مشتریان

باید اسم مشتری (یا شناسه‌ی او) را به امتیازهایش نسبت دهیم.

تابع `name_customers()` را پیاده‌سازی کنید که یک بردار از اسم‌ها و یک لیست از امتیازها می‌گیرد و آن‌ها را در یک لیست از لیست‌ها «زیپ» می‌کند.

عناصر لیست درونی باید اسم‌های `name` و `rating` را داشته باشند.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. جدا کردن مشتریان پرشور

باید مشتریان پرشورتر را از بقیه جدا کنیم.

تابع `emphatics()` را پیاده‌سازی کنید که مشتریان و امتیازها را می‌گیرد.
لیستی برمی‌گرداند که فقط به کسانی محدود است که تنها امتیازهای ستاره‌ای `1` یا `5` می‌دهند.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. تبدیل امتیازها به دودویی

از آنجا که مشتریان پرشور فقط از امتیازهای `1` و `5` استفاده می‌کنند، از نظر محاسباتی راحت‌تر است که این‌ها به `0` و `1` تغییر داده شوند.

تابع `to_binary()` را پیاده‌سازی کنید که یک بردار از امتیازهای پرشور می‌گیرد.
امتیازهای دودویی را برمی‌گرداند، که در آن `1` به `0` و `5` به `1` تغییر یافته است.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. محاسبه‌ی میانگین امتیازها در طول زمان

شما می‌خواهید با گذشت زمان و هرچه سلیقه‌ی مشتریان را بهتر می‌شناسید، توصیه‌ها را برای تک‌تک مشتریان (نه فقط پرشورها) بهتر و بهتر کنید.

تابع `satisfactions()` را پیاده‌سازی کنید که یک بردار از امتیازها می‌گیرد.
یک بردار از میانگین‌های تجمعی امتیازها تا این نقطه را برمی‌گرداند.
نتایج را به ۲ رقم اعشار گرد کنید.

امیدواریم این اعداد برای مشتریان خوشحال، همچنان رشد کنند!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
