# مقدمه

از دستور `guard` در Swift برای بازگشت‌های زودهنگام از توابع استفاده می‌شود، آن هم زمانی که شرطی که برای ادامه‌ی پردازش لازم است برآورده نشده باشد. برای نمونه:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

در اینجا، `guard` بررسی می‌کند که آیا عبارت منطقی پس از کلیدواژه‌ی `guard` به «درست» ارزیابی می‌شود یا نه. اگر چنین باشد، پردازش با کدی که پس از دستور `guard` می‌آید ادامه پیدا می‌کند (در اینجا `let root = myValue.squareRoot()`). در غیر این صورت، کد موجود در بخش `else` اجرا می‌شود. برخلاف دستور `if`، دستور `guard` _باید_ یک بخش `else` داشته باشد و برخلاف بخش `else` در یک `if-else`، بخش `else` در یک `guard` _باید_ از دامنه‌ی دستور `guard` خارج شود؛ یعنی باید از یک «دستور انتقال کنترل» مانند `return`، `continue` یا `break` استفاده کند، یا خطایی پرتاب کند یا برنامه را خاتمه دهد.
