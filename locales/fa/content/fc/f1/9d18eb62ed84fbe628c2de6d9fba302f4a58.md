# دستورالعمل‌ها

هر برنامه‌ی رقصی که گروه رقص اجرا می‌کند، بر پایه‌ی یک گرم‌کردن یکسان بنا شده است و بعد راه خودش را می‌رود.

کد اولیه `WARM_UP` را به شما می‌دهد. سه کلاس دیگر زیر آن بنویسید.

## 1. برنامه‌ی رقص جاز

`JAZZ_ROUTINE` همه‌چیز را بدون تغییر از `WARM_UP` می‌گیرد و موردی به آن اضافه نمی‌کند.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. برنامه‌ی رقص تپ

`TAP_ROUTINE` مقدار `counts` را از `WARM_UP` می‌گیرد، اما خودش را به شیوه‌ی خودش توصیف می‌کند. `describe` را از `include` بیرون بگذارید و یکی تازه بنویسید.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. فینال

`FINALE`، `counts` را با اسم `warm_up_counts` از `WARM_UP` می‌گیرد و `describe` را بیرون می‌گذارد. سپس `counts` خودش را دارد که دو برابر گرم‌کردن است، و `describe` خودش را.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

نکته‌ای که اینجا روشن می‌شود: `FINALE::counts` همان `WARM_UP::counts` نیست و هر دو با اسم‌های متفاوت در همان کلاس در دسترس‌اند.
