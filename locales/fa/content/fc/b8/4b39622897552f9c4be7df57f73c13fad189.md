# مقدمه

## مبانی

### تابع

در Gleam «توابع» با نحوه‌ی نگارش `pub fn` تعریف می‌شوند.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

این تابع دو آرگومان می‌گیرد که هر دو از نوع `Int` هستند و مقداری از نوع `Int` برمی‌گرداند. در Gleam کلیدواژه‌ی `return` وجود ندارد؛ مقدار آخرین عبارت در یک تابع همیشه _به‌صورت ضمنی برگردانده می‌شود_.

حاشیه‌نویسی نوع برای آرگومان‌ها و نوع بازگشتی اختیاری‌اند و Gleam همیشه کد شما را به‌طور کامل از نظر نوع بررسی می‌کند. معمولاً برنامه‌نویسان Gleam برای شفافیت به توابع خود حاشیه‌نویسی نوع می‌دهند، اما اگر بخواهید می‌توانید آن‌ها را حذف کنید.

```gleam
pub fn add(x, y) {
  x + y
}
```

یک تابع را می‌توان با نحوه‌ی نگارش `function_name(argument1, argument2)` فراخوانی کرد.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### متغیر

در Gleam «متغیرها» با نحوه‌ی نگارش `let name = expression` تعریف می‌شوند.

```gleam
pub fn main() {
  let count = 1
}
```

می‌توان متغیرها را همراه با حاشیه‌نویسی نوع تعریف کرد. این‌ها مانند آرگومان‌های تابع اختیاری‌اند، هرچند بیشتر برنامه‌نویسان Gleam برای کوتاه‌نویسی حاشیه‌نویسی نوع متغیرها را حذف می‌کنند.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### رشته‌ی متنی

در Gleam «رشته‌ها» با کوتیشن دوگانه نوشته می‌شوند.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### کامنت کد

از کامنت‌ها می‌توان برای گذاشتن یادداشت برای سایر توسعه‌دهندگانی که کد منبع را می‌خوانند استفاده کرد. کامنت‌ها در Gleam تک‌خطی‌اند و با `//` شروع می‌شوند.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
