# دستورالعمل‌ها

مکا مانچ™، شرکتی در حوزه‌ی خودکارسازی خرید مواد غذایی، همین حالا شما را برای کار روی اپلیکیشن سفارش‌گیری‌اش استخدام کرده است.
وظیفه‌ی تیم شما ساخت یک MVP (_[حداقل محصول پذیرفتنی][mvp]_) است که همه‌ی فعالیت‌های پایه‌ی سبد خرید را مدیریت کند و به کاربران امکان دهد سفارش‌های مواد غذایی‌شان را اضافه، حذف و مرتب کنند.
خوشبختانه، تیم دیگری مسئول همه‌ی کارهای مربوط به پول و تسویه‌حساب است!

## 1. افزودن عنصر(ها) به سبد خرید کاربر

این MVP باید به کاربر اجازه دهد عنصرهایی به سبد خریدش اضافه کند.
این می‌تواند یک عنصر یا چند عنصر به‌صورت هم‌زمان باشد.
از آنجا که این یک MVP است، مقدار هر عنصر با _تکرار_ نشان داده می‌شود.
اگر کاربر بخواهد ۲ پرتقال اضافه کند، «Oranges» دو بار در تکرارپذیر ورودی ظاهر می‌شود.
اگر کاربر از قبل آن عنصر را در سبدش داشته باشد، مقدار آن در سبد باید ۱ واحد افزایش یابد.
اگر عنصر _تازه_ در سبد باشد، باید با مقدار ۱ اضافه شود.

تابع `add_item(<current_cart>, <items_to_add>)` را بسازید که یک دیکشنری سبد خرید و هر تکرارپذیر شبیه فهرست از عنصرهای موردنظر برای افزودن را به عنوان آرگومان می‌گیرد.
این تابع باید یک دیکشنری سبد خرید جدید/به‌روزشده برای کاربر برگرداند.

```python
>>> add_item({'Banana': 3, 'Apple': 2, 'Orange': 1},
              ('Apple', 'Apple', 'Orange', 'Apple', 'Banana'))
{'Banana': 4, 'Apple': 5, 'Orange': 2}

>>> add_item({'Banana': 3, 'Apple': 2, 'Orange': 1},
              ['Banana', 'Orange', 'Blueberries', 'Banana'])
{'Banana': 5, 'Apple': 2, 'Orange': 2, 'Blueberries': 1}
```

## 2. خواندن عنصرهای فهرست‌شده در برنامه‌ی یادداشت کاربر

اوه.
به نظر می‌رسد تیم محصول دست به [افزایش بی‌رویه‌ی قابلیت‌ها][feature creep] زده است.
آن‌ها می‌خواهند قابلیت‌های بیشتری به MVP اضافه کنند.
اپلیکیشن حالا باید با خواندن عنصرها از برنامه‌ی یادداشت کاربر، یک سبد خرید بسازد.
این برای کاربران راحت است، اما کمی کار بیشتر برای تیم.

تابع `read_notes(<notes>)` را بسازید که می‌تواند هر تکرارپذیری شبیه فهرست را به عنوان آرگومان بگیرد.
این تابع باید عنصرها را تجزیه کند و یک سبد خرید/دیکشنری برای کاربر بسازد.
هر عنصر باید با مقدار ۱ اضافه شود.
سپس سبد خرید جدید کاربر باید برگردانده شود.

```python
>>> read_notes(('Banana','Apple', 'Orange'))
{'Banana': 1, 'Apple': 1, 'Orange': 1}

>>> read_notes(['Blueberries', 'Pear', 'Orange', 'Banana', 'Apple'])
{'Blueberries' : 1, 'Pear' : 1, 'Orange' : 1, 'Banana' : 1, 'Apple' : 1}
```

## 3. به‌روزرسانی بخش «ایده‌ها»ی دستورهای پخت

این اپلیکیشن بخشی با نام «ایده‌ها» دارد که پر است از دستورهای پخت آماده از سبک‌های آشپزی گوناگون.
کاربر می‌تواند هر یک از این دستورهای پخت را انتخاب کند و همه‌ی مواد آن به‌صورت خودکار به سبد خریدش اضافه شود.
مدیر پروژه از شما خواسته راهی برای ویرایش این دستورهای پخت «ایده‌ها» بسازید، چون تیم محتوا مدام مواد و مقدارها را تغییر می‌دهد.

تابع `update_recipes(<ideas>, <recipe_updates>)` را بسازید که یک دیکشنری «ایده‌ها» و یک تکرارپذیر از به‌روزرسانی‌های دستور پخت را به عنوان آرگومان می‌گیرد.
این تابع باید دیکشنری «ایده‌ها»ی جدید/به‌روزشده را برگرداند.

```python
>>>update_recipes(
    {'Banana Bread' : {'Banana': 1, 'Apple': 1, 'Walnuts': 1, 'Flour': 1, 'Eggs': 2, 'Butter': 1},
     'Raspberry Pie' : {'Raspberry': 1, 'Orange': 1, 'Pie Crust': 1, 'Cream Custard': 1}},
    (('Banana Bread', {'Banana': 4,  'Walnuts': 2, 'Flour': 1, 'Butter': 1, 'Milk': 2, 'Eggs': 3}),)
    )
...

{'Banana Bread': {'Banana': 4, 'Walnuts': 2, 'Flour': 1, 'Butter': 1, 'Milk': 2, 'Eggs': 3}, 
 'Raspberry Pie': {'Raspberry': 1, 'Orange': 1, 'Pie Crust': 1, 'Cream Custard': 1}}

>>> update_recipes(
    {'Banana Bread' : {'Banana': 1, 'Apple': 1, 'Walnuts': 1, 'Flour': 1, 'Eggs': 2, 'Butter': 1},
    'Raspberry Pie' : {'Raspberry': 1, 'Orange': 1, 'Pie Crust': 1, 'Cream Custard': 1},
    'Pasta Primavera': {'Eggs': 1, 'Carrots': 1, 'Spinach': 2, 'Tomatoes': 3, 'Parmesan': 2, 'Milk': 1, 'Onion': 1}},
    [('Raspberry Pie', {'Raspberry': 3, 'Orange': 1, 'Pie Crust': 1, 'Cream Custard': 1, 'Whipped Cream': 2}),
    ('Pasta Primavera', {'Eggs': 1, 'Mixed Veggies': 2, 'Parmesan': 2, 'Milk': 1, 'Spinach': 1, 'Bread Crumbs': 1}),

```

## 4. مرتب‌سازی عنصرهای سبد خرید کاربر

وقتی کاربری سبدی را آغاز کرده باشد، اپلیکیشن به او اجازه می‌دهد عنصرهایش را به ترتیب الفبا مرتب کند.
این کار پیدا کردن عنصرها را آسان‌تر می‌کند و وقتی خطاهای ثبت داده رخ می‌دهد، مثل داشتن «potatoes» و «Potato» در پایگاه داده، کمک می‌کند.

تابع `sort_entries(<cart>)` را بسازید که یک سبد خرید/دیکشنری را به عنوان آرگومان می‌گیرد و یک سبد جدید و مرتب‌شده بر اساس الفبا برمی‌گرداند.

```python
>>> sort_entries({'Banana': 3, 'Apple': 2, 'Orange': 1})
{'Apple': 2, 'Banana':3, 'Orange': 1}
```

## 5. ارسال سبد خرید کاربر به فروشگاه برای آماده‌سازی سفارش

اپلیکیشن باید سبد خرید یک کاربر مشخص را برای آماده‌سازی به فروشگاه بفرستد.
اما کارکنان فروشگاه باید بدانند هر عنصر در کدام راهروی فروشگاه قرار دارد و آیا به یخچال نیاز دارد یا نه.
بنابراین (_تا حدی دلبخواه_) سبد «آماده‌سازی» باید به ترتیب معکوس الفبا مرتب شود و مقدار هر عنصر با اطلاعات مکان و یخچال ترکیب شود.

تابع `send_to_store(<cart>, <aisle_mapping>)` را بسازید که یک سبد خرید کاربر و یک دیکشنری می‌گیرد که برای هر عنصر، شماره‌ی راهروی فروشگاه و یک `True`/`False` برای نیاز به یخچال را دارد.
این تابع باید یک سبد «آماده‌سازی» ترکیبی را `return` کند که برای هر عنصری که مشتری سفارش می‌دهد، (مقدار، راهرو و یخچال) را دارد.
عنصرها باید به ترتیب _معکوس_ الفبا بیایند.

```python
>>> send_to_store({'Banana': 3, 'Apple': 2, 'Orange': 1, 'Milk': 2},
                  {'Banana': ['Aisle 5', False], 'Apple': ['Aisle 4', False], 'Orange': ['Aisle 4', False], 'Milk': ['Aisle 2', True]})
{'Orange': [1, 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True], 'Banana': [3, 'Aisle 5', False], 'Apple': [2, 'Aisle 4', False]}
```

## 6. به‌روزرسانی موجودی فروشگاه بر اساس آنچه کاربر سفارش داده است

اپلیکیشن نمی‌تواند بی‌پایان سفارش مشتری‌ها را ثبت کند.
دیر یا زود، موجودی محصول‌های مختلف فروشگاه تمام می‌شود.
پس MVP شما باید هر بار که کاربری سفارشش را به فروشگاه می‌فرستد، موجودی فروشگاه را به‌روزرسانی کند.
وگرنه مشتری‌ها محصول‌هایی را سفارش می‌دهند که واقعاً موجود نیستند.

تابع `update_store_inventory(<fulfillment_cart>, <store_inventory>)` را بسازید که یک سبد «آماده‌سازی» و یک موجودی فروشگاه می‌گیرد.
این تابع باید مقدارهای موجودی فروشگاه را به اندازه‌ی عدد «سفارش‌داده‌شده» در سبد «آماده‌سازی» کاهش دهد و سپس موجودی به‌روزشده‌ی فروشگاه را برگرداند.
هر جا تعداد یک محصول در فروشگاه به ۰ برسد، آن عدد باید با پیام «Out of Stock» جایگزین شود.

```python
>>> update_store_inventory({'Orange': [1, 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True], 'Banana': [3, 'Aisle 5', False], 'Apple': [2, 'Aisle 4', False]},
{'Banana': [15, 'Aisle 5', False], 'Apple': [12, 'Aisle 4', False], 'Orange': [1, 'Aisle 4', False], 'Milk': [4, 'Aisle 2', True]})

{'Banana': [12, 'Aisle 5', False], 'Apple': [10, 'Aisle 4', False], 'Orange': ['Out of Stock', 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True]}
```
