# مقدمه

## خطاها

گزارش کردن خطاها زمانی مفید است که چیزی در یک برنامه یا بخشی از کد اشتباه یا غیرمنتظره باشد.

آن‌ها شیءهای جاوااسکریپت هستند.

ویژگی اصلی این شیء `message` است:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

با استفاده از نحوه‌ی نگارش `throw` می‌توانید یک خطا پرتاب کنید.

```javascript
throw new Error('Oops');
```

وقتی یک خطا پرتاب می‌شود، اجرای فعلی متوقف می‌شود و در اولین بلوک `catch` از پشته‌ی فراخوانی ادامه می‌یابد.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## وراثت

وراثت روشی برای ایجاد رابطه‌ی والد-فرزند بین کلاس‌ها است.
کلاس فرزند (که گاهی _زیرکلاس_ نامیده می‌شود) به رفتار و داده‌ای که کلاس والد (که گاهی _ابرکلاس_ نامیده می‌شود) تعریف کرده است دسترسی دارد.

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

کلیدواژه‌ی `extends` در تعریف کلاس فرزند، از طریق [زنجیره‌ی پروتوتایپ][prototype-chain] رابطه‌ای با کلاس والد برقرار می‌کند.

اشیائی که سازنده‌ی فرزند ایجاد می‌کند، پروتوتایپ کلاس والد را در زنجیره‌ی پروتوتایپ خود خواهند داشت و این، دسترسی به هر متد یا داده‌ای که والد تعریف کرده است را فراهم می‌کند.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

مانند هر کلاس دیگری در جاوااسکریپت، زیرکلاس‌ها می‌توانند با استفاده از کلیدواژه‌ی `extends` از `Error` ارث‌بری کنند تا خطاهای سفارشی بسازند.
نحوه‌ی نگارش `instanceof` بررسی می‌کند که آیا خطای گرفته‌شده نمونه‌ی یک زیرکلاس خاص از `Error` است یا نه.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
