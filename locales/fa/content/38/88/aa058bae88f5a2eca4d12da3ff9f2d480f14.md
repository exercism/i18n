# درباره

زبان Swift یک نوع داده‌ی درون‌ساخت به نام [`Bool`][bools] دارد که «مقادیر منطقی» را نشان می‌دهد: `true` و `false`.

## عملگرهای منطقی

Swift سه [عملگر منطقی][logical-operators] (`!`، `&&` و `||`) دارد که با آن‌ها می‌توان عبارات منطقی را ترکیب و ارزیابی کرد.

### عملگر منطقی AND (`&&`)

[عملگر _and_][and] (`&&`) تنها زمانی `true` برمی‌گرداند که هر دو عملوند `true` باشند.
اگر یکی از عملوندها `false` باشد، `false` برمی‌گرداند.
در هر طرف نماد `&&` یک عبارت یا مقدار منطقی قرار دهید:

```swift
true && true  // true
true && false // false
```

### عملگر منطقی OR (`||`)

[عملگر _or_][or] (`||`) اگر **حداقل یکی** از عملوندها `true` باشد، `true` برمی‌گرداند.
تنها زمانی `false` برمی‌گرداند که هر دو عملوند `false` باشند.
در هر طرف نماد `||` یک عبارت یا مقدار منطقی قرار دهید:

```swift
true || true   // true
true || false  // true
false || false // false
```

### عملگر منطقی NOT (`!`)

[عملگر _not_][not] (`!`) یک مقدار منطقی را وارونه می‌کند.
اگر مقدار `false` باشد `true` برمی‌گرداند و اگر `true` باشد `false`.
عملگر `!` را بی‌درنگ پیش از مقدار یا عبارت قرار دهید:

```swift
!true  // false
!false // true
```

## استفاده از پرانتز (`()`)

می‌توانید از [پرانتز][explicit-parentheses] برای گروه‌بندی عبارات و کنترل ترتیب ارزیابی استفاده کنید.
در Swift، عبارت‌های داخل پرانتز اول ارزیابی می‌شوند:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

گروه‌بندی با پرانتز همچنین تعیین می‌کند که عملگر NOT چگونه روی عبارت‌های پیچیده اعمال می‌شود:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
هرگاه لازم است ترتیب ارزیابی را روشن کنید یا خواندن شرط‌های پیچیده را ساده‌تر کنید، از پرانتز استفاده کنید.
وقتی اولویت پیش‌فرض از پیش روشن است، از افزودن پرانتزهای بی‌نیاز بپرهیزید.
~~~~
