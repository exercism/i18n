# کمک

- [The Zig Programming Language Documentation][documentation] مرور کلی بسیار خوبی است بر همه‌ی امکانات زبانی که Zig در اختیار کسانی که از آن استفاده می‌کنند قرار می‌دهد.
- [Zig Guide][zig-guide] یک راهنمای مقدماتی عالی است که امکانات زبانی Zig را توضیح می‌دهد.
- [Ziglings][ziglings] را به‌شدت توصیه می‌کنیم.
  Zig را با درست‌کردن برنامه‌های کوچک خراب یاد بگیرید.
- [The Zig Programming Language Discord][discord-zig] دیسکورد اصلی است.
  راه بسیار خوبی است برای ارتباط با جامعه‌ی گسترده‌ی Zig و دریافت کمک سریع و مستقیم برای هر مشکل مرتبط با Zig.
- [#zig][irc] در irc.freenode.net کانال اصلی IRC مربوط به Zig است.
- [/r/Zig][reddit] سابردیت اصلی Zig است.
- از [Stack Overflow][stack-overflow] می‌توان برای پیدا کردن قطعه‌کدها و راه‌حل مشکلاتی استفاده کرد که شاید دیگران قبلاً پرسیده و حتی حل کرده باشند.
