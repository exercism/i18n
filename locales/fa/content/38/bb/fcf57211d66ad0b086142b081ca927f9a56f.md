# مقدمه

## سربارگذاری متد

در جاوا، «سربارگذاری متد» قابلیتی است که به یک کلاس اجازه می‌دهد بیش از یک متد با اسم یکسان داشته باشد، به شرطی که فهرست پارامترهایشان متفاوت باشد.
این مفهوم با «چندریختی» زمان کامپایل (یا چندریختی ایستا) مرتبط است.
این مفهوم برای ساختن متدهایی حیاتی است که کارهای مشابهی را با ورودی‌های متفاوت انجام می‌دهند.

### چرا متدها را سربارگذاری کنیم؟

سربارگذاری متد خوانایی برنامه را افزایش می‌دهد.
به متدهای متفاوت می‌توان اسم یکسان داد، اما با پارامترهای متفاوت.
بسته به تعداد پارامترها یا نوع پارامترها، متد متناظر فراخوانی می‌شود.

### چگونه متدها را سربارگذاری کنیم؟

کلید سربارگذاری متد، «امضای متد» است.
اگر دو متد امضاهای متفاوتی داشته باشند، متفاوت در نظر گرفته می‌شوند.
دو روش برای سربارگذاری یک متد وجود دارد:

1. **تعداد متفاوت پارامترها**: متدها می‌توانند اسم یکسان اما تعداد پارامترهای متفاوت داشته باشند.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **انواع متفاوت پارامترها**: متدها می‌توانند اسم یکسان و تعداد پارامترهای یکسان داشته باشند، اما نوع پارامترهایشان متفاوت باشد.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### نکاتی که باید به خاطر بسپارید

- متدهای سربارگذاری‌شده باید فهرست آرگومان‌ها را تغییر دهند.
- متدهای سربارگذاری‌شده می‌توانند نوع بازگشتی را هم تغییر دهند، اما تغییر صرفِ نوع بازگشتی سربارگذاری متد به حساب نمی‌آید.
- متدها را می‌توان در همان کلاس یا در یک زیرکلاس سربارگذاری کرد.

در این مفهوم، نمونه‌ها و ظرافت‌های گوناگون سربارگذاری متد در جاوا را بررسی خواهیم کرد.
