# مقدمه

## کاراکتر

### کاراکتر

نوع اولیه‌ی `char` در جاوا نمایشی ۱۶ بیتی از یک کاراکتر واحد است.
چندین `char` می‌توانند یک رشته را تشکیل دهند، مثل `"word"`، یا می‌توان `char`ها را به صورت مستقل پردازش کرد.
یک `char` لیترال بین دو علامت نقل‌قول تک قرار می‌گیرد (مثلاً `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### به دست آوردن کاراکترهای یک `String`

متد `String.toCharArray` کاراکترهای یک `String` را به‌صورت یک آرایه برمی‌گرداند.
همان‌طور که در آرایه اشاره شد، می‌توانید از یک حلقه‌ی `for` برای پیمایش روی آرایه استفاده کنید.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### کلاس `Character`

متدهای کتابخانه‌ای آماده‌ی زیادی برای بررسی و دستکاری `char`ها وجود دارد.
این‌ها را می‌توان به‌صورت متدهای استاتیک کلاس `java.lang.Character` پیدا کرد.
چند نمونه:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### افزودن یک `char` به یک `String`

می‌توان از عملگر `+` برای افزودن یک `char` به یک `String` استفاده کرد.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
مراقب باشید که از `+` برای چسباندن دو `char` به هم و ساختن یک `String` استفاده _نکنید_!
جمع کردن دو `char` به این شکل یک `int` به دست می‌دهد، _نه_ یک `String`!
برای مثال:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

دلیلش این است که جاوا `char` را به `int` ارتقا می‌دهد (بخش [۴.۲ انواع اولیه و مقادیر ][jls-primitives] از [مشخصات زبان جاوا][jls-main] را ببینید).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

اما وقتی کاراکترهای زیادی برای افزودن وجود دارد، استفاده از `StringBuilder` می‌تواند کارآمدتر باشد:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
