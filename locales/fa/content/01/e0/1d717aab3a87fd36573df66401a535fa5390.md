# پیوست دستورالعمل‌ها

## قالب خروجی

متن ترانه را به‌صورت یک رشته‌ی مختوم به `null` خروجی بدهید.

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ورودی        | عدد صحیح | بند شروع                   |
| `$a1`    | ورودی        | عدد صحیح | بند پایان                     |
| `$a2`    | ورودی/خروجی | نشانی | رشته‌ی خروجی مختوم به `null` |
| `$t0-9`  | موقت    | هر نوع     | برای ذخیره‌سازی موقت         |
