# Debug

می‌توانید از [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) استفاده کنید تا پیام‌ها را به تست‌های ناموفق پیوست کنید، به این شکل:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

هنگام اجرای یک تست ناموفق، لاگ پیوست‌شده این خواهد بود: `secondsInOneHour: 3600`.

یک نکته‌ی مهم هم هست: ثابت‌های سطح بالا فقط یک بار و پیش از شروع اجرای تست‌ها ارزیابی می‌شوند، بنابراین تست‌ها نمی‌توانند پیام‌های لاگ آن‌ها را ثبت کنند. برای نمونه:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

در طول اجرای تست‌ها هیچ چیزی را لاگ نمی‌کند، چون متغیر JavaScript متناظر با `secondsInOneHour` پیش‌تر با مقدار ۳۶۰۰ ارزیابی شده است.
