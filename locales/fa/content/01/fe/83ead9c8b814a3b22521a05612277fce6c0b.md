# توابع

توابع در Cairo پایه‌ای هستند.

بر اساس یک قرارداد، Cairo برای اسم توابع و متغیرها از **«snake case»** استفاده می‌کند؛ در این سبک، واژه‌ها با حروف کوچک نوشته می‌شوند و با زیرخط از هم جدا می‌شوند.

مثالی را ببینید:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

توابع با `fn` تعریف می‌شوند؛ پس از آن یک اسم، پرانتزهایی برای پارامترها (در صورت وجود) و بدنه‌ای قرار می‌گیرد که در آکولاد محصور شده است.

می‌توانید یک تابع را با نوشتن اسم آن و سپس پرانتزها فراخوانی کنید.

ترتیب توابع مهم نیست، تا زمانی که در محدوده‌ی دید باشند.

## پارامترها

توابع می‌توانند **پارامتر** بگیرند؛ پارامترها متغیرهایی هستند که در امضای تابع تعریف می‌شوند.

هنگام فراخوانی تابع، **آرگومان** می‌دهید؛ یعنی مقادیری که به این پارامترها پاس داده می‌شوند.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

در اینجا `x` پارامتری از نوع `felt252` است.

وقتی با `5` فراخوانی شود، تابع «The value of x is: 5» را چاپ می‌کند.

پارامترهای متعدد با ویرگول از هم جدا می‌شوند:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

این خروجی را چاپ می‌کند: `The measurement is: 5h`.

## دستورها و عبارت‌ها

توابع Cairo از **دستورها** و **عبارت‌ها** تشکیل می‌شوند:

- **دستورها** کارهایی انجام می‌دهند، اما مقداری برنمی‌گردانند.
برای مثال، `let x = 3;` یک دستور است.
- **عبارت‌ها** به یک مقدار ارزیابی می‌شوند.
برای مثال، `5 + 6` به `11` ارزیابی می‌شود.

بلوک‌هایی که در آکولاد قرار می‌گیرند هم عبارت هستند و مقدار نهایی‌شان برگردانده می‌شود:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

در اینجا مقدار `4` به `y` اختصاص داده می‌شود.

## مقادیر بازگشتی

توابع می‌توانند با استفاده از نحوه‌ی نگارش `->` مقدار برگردانند و نوع بازگشتی را مشخص کنند.

به‌طور پیش‌فرض، یک تابع مقدار عبارت نهایی خود را برمی‌گرداند:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

این خروجی را نشان می‌دهد: `The value of x is: 5`.

برای موارد پیچیده‌تر:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

این چاپ می‌کند: `The value of x is: 6`.

دقت کنید که در پایان عبارت نهایی سمی‌کالن نگذارید؛ چون عبارت را به یک دستور تبدیل می‌کند و باعث می‌شود تابع به‌جای مقدار مورد انتظار، `()` (نوع واحد) را برگرداند.
