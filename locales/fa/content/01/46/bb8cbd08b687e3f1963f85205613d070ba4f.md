# مقدمه

شرط‌ها دستورهایی هستند که بسته به اینکه یک شرط `true` باشد یا `false`، کد متفاوتی را اجرا می‌کنند.

یک دستور `if` تنها زمانی بدنه‌اش را اجرا می‌کند که شرطش `true` باشد.
زبان Go هیچ مفهومی از مقادیر truthy یا falsy ندارد، پس شرط باید از نوع `bool` باشد.
عبارت‌هایی مثل `if mySlice { ... }` یا `if 1 { ... }` خطای کامپایل هستند.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

از `else if` برای بررسی شرط‌های بیشتر و از `else` به عنوان حالت پشتیبان استفاده کنید، برای وقتی که هیچ‌کدام مطابقت نداشتند.
شرط‌ها از بالا به پایین ارزیابی می‌شوند و تنها نخستین شاخه‌ای که شرطش «درست» است اجرا می‌شود.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

یک دستور `if` می‌تواند یک دستور مقداردهی اولیه‌ی کوتاه هم داشته باشد.
متغیرهایی که به این شکل تعریف می‌شوند فقط در محدوده‌ی کل زنجیره‌ی `if`/`else` در دسترس‌اند.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
