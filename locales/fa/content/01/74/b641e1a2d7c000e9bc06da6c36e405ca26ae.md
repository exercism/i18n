# استفاده از بازگشت دنباله‌ای

هدف این تمرین، آموزش بازگشت دنباله‌ای است. آن را بدون استفاده از توابع بازگشتی‌ای که دنباله‌ای نیستند حل کنید.

توابع بازگشتی دنباله‌ای که در راه‌حل شما پیدا شدند: %{tail_call_recursive_functions}. سایر توابع بازگشتی که در راه‌حل شما پیدا شدند: %{non_tail_call_recursive_functions}.

به یاد داشته باشید که بازگشت دنباله‌ای زمانی رخ می‌دهد که _آخرین_ عبارتی که تابع ارزیابی می‌کند، فراخوانی خودش باشد.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
