# منابع

## دریافت کمک

1. [ویکی Emacs](http://emacswiki.org/) بسیار ارزشمند است. وقت زیادی را اینجا بگذرانید.
2. [ویرایشگر Emacs](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) دفترچه‌ی راهنمای رسمی GNU Emacs است.
3. IRC: در [Libera.Chat](https://libera.chat/) کانال‌هایی برای `#emacs`، `#org-mode` و بسیاری از بسته‌های Emacs وجود دارد و افراد کمک‌کننده‌ی زیادی هم آنجا هستند. و در Emacs، فاصله‌ی شما تا IRC فقط یک `M-x erc` است.
4. Matrix: در [Matrix](https://matrix.org/) اتاق‌هایی برای [emacs](https://matrix.to/#/#emacs:matrix.org)، [org-mode](https://matrix.to/#/#org-mode:matrix.org) و دیگر بسته‌های Emacs وجود دارد. می‌توانید [به فضای Emacs در Matrix بپیوندید](https://matrix.to/#/#emacs-space:matrix.org) تا نمایی کلی از کانال‌های موجود به دست آورید. برای پیوستن به Matrix از داخل Emacs می‌توانید از بسته‌ی [Ement.el](https://github.com/alphapapa/ement.el) استفاده کنید.
5. از [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) و [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) می‌توانید برای جست‌وجوی مشکل خودتان و دیدن اینکه آیا پیش‌تر پاسخ داده شده است یا نه استفاده کنید. همچنین می‌توانید سؤال بپرسید و به پرسش‌ها پاسخ دهید.
