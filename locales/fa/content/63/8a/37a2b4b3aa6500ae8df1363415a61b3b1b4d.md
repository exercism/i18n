# دستورالعمل‌ها

ترامواهای ملبورن بر اساس ناحیه کرایه می‌گیرند و مرکز شهر رایگان است. شما در حال نوشتن قواعد کرایه برای دستگاه بلیت‌فروشی هستید. همه‌ی کرایه‌ها بر حسب سنت هستند.

هر چهار تمرین در کلاس `TRAM_FARES` قرار می‌گیرند.

## 1. کرایه‌ی یک ناحیه

ناحیه‌ی 0 همان ناحیه‌ی تراموای رایگان است و هزینه‌ای ندارد. ناحیه‌ی 1 برابر 550 است. ناحیه‌ی 2 برابر 370 است. هر عدد دیگری اصلاً ناحیه‌ی تراموا نیست و هزینه‌ای ندارد.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. چه نوع بلیتی؟

روی بلیت‌ها یک حرف نوشته شده است. `'f'` کرایه‌ی کامل است. هر دو `'c'` و `'s'` تخفیف‌دار هستند، یکی برای کودکان و یکی برای دانشجویان. `'x'` بلیت رایگان است. هر مورد دیگری ناشناخته است.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

چهار پاسخ عبارت‌اند از `"Full fare"`، `"Concession"`، `"Free pass"` و `"Unknown"`.

## 3. چه نوع روزی؟

`"Sat"` و `"Sun"` آخر هفته هستند. `"Mon"` تا `"Fri"` روز کاری هستند. هر مورد دیگری ناشناخته است.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

سه پاسخ عبارت‌اند از `"Weekend"`، `"Weekday"` و `"Unknown"`.

## 4. سقف روزانه

هر تعداد تراموا که سوار شوید، هرگز بیشتر از سقف آن روز پرداخت نمی‌کنید: 1100 در روزهای کاری و 700 در آخر هفته. روزی که کسی آن را نمی‌شناسد سقفی ندارد، یعنی صفر.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
