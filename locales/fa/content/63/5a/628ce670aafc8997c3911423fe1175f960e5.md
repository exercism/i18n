# دستورالعمل‌ها

دوست‌دختر لوسین در راه خانه است و او هنوز شام سالگردشان را نپخته است!

در این تمرین، قرار است کدی بنویسید تا به لوسین کمک کنید از کتاب آشپزی محبوبش یک لازانیای عالی بپزد.

چهار کار دارید که همه‌شان به زمان صرف‌شده برای پخت لازانیا مربوط می‌شوند.

## 1. زمان مورد انتظار پخت در فر را بر حسب دقیقه تعریف کنید

متد `Lasagna.ExpectedMinutesInOven()` را تعریف کنید که هیچ پارامتری نمی‌گیرد و برمی‌گرداند که لازانیا باید چند دقیقه در فر بماند. بر اساس کتاب آشپزی، زمان مورد انتظار پخت در فر 40 دقیقه است:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. زمان باقی‌مانده‌ی پخت در فر را بر حسب دقیقه محاسبه کنید

متد `Lasagna.RemainingMinutesInOven()` را تعریف کنید که تعداد دقیقه‌هایی را که لازانیا تاکنون در فر بوده است به عنوان پارامتر می‌گیرد و بر اساس زمان مورد انتظار پخت در فر از کار قبلی، برمی‌گرداند که لازانیا باید چند دقیقه‌ی دیگر در فر بماند.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. زمان آماده‌سازی را بر حسب دقیقه محاسبه کنید

متد `Lasagna.PreparationTimeInMinutes()` را تعریف کنید که تعداد لایه‌هایی را که به لازانیا اضافه کرده‌اید به عنوان پارامتر می‌گیرد و برمی‌گرداند که چند دقیقه صرف آماده‌سازی لازانیا کرده‌اید، با این فرض که آماده‌سازی هر لایه 2 دقیقه طول می‌کشد.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. زمان سپری‌شده را بر حسب دقیقه محاسبه کنید

متد `Lasagna.ElapsedTimeInMinutes()` را تعریف کنید که دو پارامتر می‌گیرد: پارامتر اول تعداد لایه‌هایی است که به لازانیا اضافه کرده‌اید و پارامتر دوم تعداد دقیقه‌هایی است که لازانیا در فر بوده است. این تابع باید برمی‌گرداند که چند دقیقه روی پخت لازانیا کار کرده‌اید، که مجموع زمان آماده‌سازی بر حسب دقیقه و زمانی است که لازانیا در این لحظه در فر گذرانده است.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
