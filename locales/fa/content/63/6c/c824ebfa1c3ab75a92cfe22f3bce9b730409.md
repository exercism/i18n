# مقدار منطقی

بعضی پرسش‌ها فقط دو جواب دارند: بله یا خیر. نوع داده‌ای که Sather برای چنین جوابی دارد، «منطقی» است. این نوع `BOOL` نامیده می‌شود و دو جوابش `true` و `false` نوشته می‌شوند. در منابع دیگر به این نوع داده «بولی» هم می‌گویند.

```sather
   ready : BOOL is
      return true;
   end;
```

## مقایسه

حاصل مقایسه‌ی دو عدد یک `BOOL` است.

| عملگر | پرسش |
| --- | --- |
| `=` | آیا برابرند؟ |
| `/=` | آیا متفاوت‌اند؟ |
| `<` | آیا عدد سمت چپ کوچک‌تر است؟ |
| `<=` | کوچک‌تر است، یا برابر؟ |
| `>` | آیا عدد سمت چپ بزرگ‌تر است؟ |
| `>=` | بزرگ‌تر است، یا برابر؟ |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

توجه کنید که `=` یک پرسش می‌پرسد. قرار دادن یک مقدار *درونِ* چیزی با `:=` انجام می‌شود که پیش‌تر آن را دیده‌اید و این دو یکی نیستند.

## ترکیب

سه عملگر از پرسش‌های کوچک‌تر، پرسش‌های بزرگ‌تر می‌سازند.

`and` وقتی «درست» است که **هر دو** طرف «درست» باشند.

```sather
harness_on and rope_checked
```

`or` وقتی «درست» است که **هر یک** از دو طرف «درست» باشد، یا هر دو.

```sather
mat_below or net_below
```

`~` یک جواب را معکوس می‌کند: «درست» را به «غلط» تبدیل می‌کند و «غلط» را به «درست».

```sather
~ready       -- true exactly when ready is false
```

`and` و `or` بین دو جواب قرار می‌گیرند؛ `~` جلوی یکی از آن‌ها می‌آید.
