# راهنمایی‌ها

## کلی

- واژگان `locals` نشانه‌های `::` و `[| | ]` را فراهم می‌کند.
- متغیرهای محلی جایگزین کد پشته نمی‌شوند؛ از آن‌ها هر جا که به خوانایی کد کمک می‌کنند استفاده کنید.

## 1. تعیین وضعیت پخت

- `cond` از [`combinators`][combinators] ساختار درستی است: یک شاخه `dup not` را بررسی می‌کند (تایمر `f` است)، شاخه‌ی دیگری `dup zero?` را بررسی می‌کند و یک حالت پیش‌فرض بقیه را مدیریت می‌کند. هر شاخه باید پیش از آنکه رشته را روی پشته بگذارد، تایمر را `drop` کند.

## 2. برآورد زمان آماده‌سازی

- `:: preparation-time ( layers minutes-per-layer -- total )` با `layers length minutes-per-layer *`.

## 3. محاسبه‌ی رشته‌فرنگی و سس موردنیاز

- متغیرهای محلی به شما امکان می‌دهند بدون `dup` دو بار به `layers` ارجاع دهید. `count` با محمول `[ "noodles" = ]` (یا `"sauce" =`) تعداد هر لایه را به شما می‌دهد.
- `1/5` یک لیترال گویا در Factor است.

## 4. افزودن ماده‌ی اولیه‌ی مخفی

- `last` (در [`sequences`][sequences]) آخرین عنصر را می‌خواند؛ `suffix` یکی را به انتهای آن می‌افزاید.

## 5. مقیاس‌کردن دستور پخت

- ضریب مقیاس `portions / 2` است. متغیرهای محلی به شما امکان می‌دهند درون لامبدا به `portions` ارجاع دهید.
- `assoc-map` از [`assocs`][assocs] یک بلوک کد به شکل `( key value -- newkey newvalue )` می‌گیرد. درون `[| key value | … ]` هر دو مقدار را برگردانید تا کلید یکسان بماند و مقدار تازه‌ای تولید کنید.
