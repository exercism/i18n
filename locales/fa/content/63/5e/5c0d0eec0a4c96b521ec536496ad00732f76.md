# دستورالعمل‌ها

شما یک راهنمای میدانی نگه می‌دارید: نگاشتی از اسم یک حیوان به زیستگاهی که در آن زندگی می‌کند.

هر پنج تمرین در کلاس `FIELD_GUIDE` قرار می‌گیرند.

## 1. آیا در راهنما هست؟

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. کجا زندگی می‌کند؟

زیستگاه ثبت‌شده برای یک حیوان را برگردانید. اگر راهنما هرگز اسم آن را نشنیده باشد، مقدار `"Unknown"` را برگردانید.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. یک ورودی اضافه کنید

راهنمایی را برگردانید که یک حیوان دیگر به آن اضافه شده است. زیستگاه حیوانی که از قبل در فهرست آمده است، جایگزین می‌شود.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

هر چه این برگرداند، از آن پس باید از همان راهنما استفاده کنید. افزودن به راهنمایی که کاملاً خالی است کار می‌کند و راهنمایی به دست می‌دهد که یک حیوان در آن است.

## 4. چند حیوان؟

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. کدام زیستگاه‌ها؟

زیستگاه‌هایی را که راهنما ذکر می‌کند، به شکل یک مجموعه برگردانید. ممکن است چند حیوان یک زیستگاه مشترک داشته باشند و آن زیستگاه باید فقط یک بار ظاهر شود.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
