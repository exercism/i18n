# دستورالعمل‌ها

در این تمرین، باید چند قانون از بازی کلاسیک Pac-Man را به توابع Haskell ترجمه کنید.

چهار قانون برای ترجمه دارید که همه مربوط به وضعیت‌های بازی هستند.

> نگران نباشید که آرگومان‌ها چگونه به دست می‌آیند؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید.

## 1. تعریف کنید که آیا Pac-Man شبح می‌خورد

تابع `eatsGhost` را تعریف کنید که دو آرگومان می‌گیرد (_این‌که Pac-Man گلوله‌ی قدرت فعال دارد_ و _Pac-Man با یک شبح تماس دارد_) و وقتی Pac-Man می‌تواند شبح را بخورد، یک مقدار `Bool` برمی‌گرداند.
تابع باید فقط وقتی `True` برگرداند که Pac-Man گلوله‌ی قدرت فعال دارد و با یک شبح تماس دارد.

```haskell
eatsGhost False True
-- -> False
```

## 2. تعریف کنید که آیا Pac-Man امتیاز می‌گیرد

تابع `scores` را تعریف کنید که دو آرگومان می‌گیرد (_این‌که Pac-Man با یک گلوله‌ی قدرت تماس دارد_ و _Pac-Man با یک نقطه تماس دارد_) و اگر Pac-Man امتیاز گرفته باشد، یک مقدار `Bool` برمی‌گرداند.
تابع باید وقتی `True` برگرداند که Pac-Man با یک گلوله‌ی قدرت یا یک نقطه تماس دارد.

```haskell
scores True True
-- -> True
```

## 3. تعریف کنید که آیا Pac-Man می‌بازد

تابع `loses` را تعریف کنید که دو آرگومان می‌گیرد (_این‌که Pac-Man گلوله‌ی قدرت فعال دارد_ و _Pac-Man با یک شبح تماس دارد_) و اگر Pac-Man ببازد، یک مقدار `Bool` برمی‌گرداند.
تابع باید وقتی `True` برگرداند که Pac-Man با یک شبح تماس دارد و گلوله‌ی قدرت فعالی ندارد.

```haskell
loses False True
-- -> True
```

## 4. تعریف کنید که آیا Pac-Man می‌برد

تابع `wins` را تعریف کنید که سه آرگومان می‌گیرد (_این‌که Pac-Man همه‌ی نقطه‌ها را خورده است_، _Pac-Man گلوله‌ی قدرت فعال دارد_ و _Pac-Man با یک شبح تماس دارد_) و اگر Pac-Man ببرد، یک مقدار `Bool` برمی‌گرداند.
تابع باید وقتی `True` برگرداند که Pac-Man همه‌ی نقطه‌ها را خورده باشد _و_ بر اساس آرگومان‌های تعریف‌شده در بخش ۳ نباخته باشد.

```haskell
wins False True False
-- -> False
```
