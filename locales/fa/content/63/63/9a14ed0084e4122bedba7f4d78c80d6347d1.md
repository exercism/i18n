# مبانی نحوه‌ی نگارش Elm ۲

## صادر کردن توابع

صادر کردن توابع در اولین مفهوم توضیح داده شد؛ اینجا یک یادآوری سریع می‌کنیم.

هر فایل در Elm یک ماژول است و باید پیش از هر کد دیگری یک دستور `module` داشته باشد.

اسم ماژول‌ها باید با اسم فایل‌شان یکی باشد؛ پس ماژول `Calculator` باید در فایل Calculator.elm باشد و ماژول `Parser.Utils` باید در فایل Parser/Utils.elm قرار بگیرد.

هرچه درون یک ماژول تعریف شود، فقط در محدوده‌ی همان ماژول قابل دسترسی است و از بیرون آن نمی‌توان به آن دسترسی داشت، مگر اینکه در `exposing` فهرست شده باشد.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## وارد کردن توابع از ماژول‌های دیگر

دسترسی به توابعی که در ماژول‌های دیگر تعریف شده‌اند، از طریق وارد کردن انجام می‌شود.
وقتی ماژولی را وارد می‌کنید، همه‌ی توابعی که آن ماژول صادر کرده است در دسترس قرار می‌گیرند.
اما شیوه‌ی دسترسی به آن‌ها بسته به اینکه ماژول چطور وارد شده باشد متفاوت است.

وارد کردن با نام کامل ماژول حالت پیش‌فرض است و برای دسترسی به تابعی در چنین ماژولی (مثلاً تابع `map` در ماژول `List`) اسم ماژول را به عنوان پیشوند می‌نویسید (`List.map`).

وارد کردن باز دسترسی مستقیم به توابع صادرشده‌ی آن ماژول را ممکن می‌کند، بدون نوشتن پیشوند. این کار با کلیدواژه‌ی `exposing` انجام می‌شود، درست مانند قرینه‌ی همان کلیدواژه‌ای که در صادر کردن به کار می‌رود. می‌توانید همه‌ی توابع موجود را صادر کنید (با `..`) یا فقط توابع مشخصی را (مثلاً `map`).

همچنین می‌توانید نوع‌ها و سازنده‌هایشان را از ماژول‌های دیگر وارد کنید، که در مفهوم‌های بعدی به آن می‌پردازیم.

وارد کردن با نام کامل ماژول ترجیح داده می‌شود تا خوانایی بیشتر شود و از تداخل اسم‌ها جلوگیری شود.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## حاشیه‌نویسی نوع

حاشیه‌نویسی نوع با `name : parameter types -> return type` تعریف می‌شود؛ نوع پارامترها هم با `->` از هم جدا می‌شوند.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

از پرانتز می‌توان برای تعریف پارامترهای تابع استفاده کرد (که خودشان با همین نحوه‌ی نگارش تعریف می‌شوند، و به همین دلیل به پرانتز نیاز است).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## عدد

دو نوع عدد در Elm وجود دارد که با نوع‌های `Int` و `Float` تعریف می‌شوند.
`Int` متناظر با مجموعه‌ی عددهای صحیح مثبت و منفی است.
`Float` متناظر با مجموعه‌ی عددهای حقیقی است که با دقت رایانه محدود می‌شود.
عمل‌هایی که برای عددها تعریف شده‌اند معمولاً فقط روی یکی از این دو نوع کار می‌کنند، نه روی ترکیبی از آن‌ها.
تابع‌هایی برای تبدیل این دو به هم وجود دارد؛ مانند `toFloat` که `Int` را به `Float` تبدیل می‌کند و `round`، `floor`، `ceiling` یا `truncate` که یک `Float` را با معناهای متفاوت به `Int` تبدیل می‌کنند.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## عمل‌های رشته

برای توصیف کلمه‌ها و جمله‌ها در کد، Elm یک نوع بومی `String` دارد.
لیترال‌های رشته بین دو علامت نقل‌قول دوتایی نوشته می‌شوند، مثل `"Hello World!"`.
عملگر اتصال رشته‌ها `++` و عملگر برابری `==` به‌طور پیش‌فرض در دسترس هستند.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

بیشتر تابع‌های دیگر رشته در ماژول `String` قرار دارند که باید وارد شود.

https://package.elm-lang.org/packages/elm/core/latest/String
