# مقدمه

**«اعلان‌های نوع اتحادی»** از `PHP 8.0.0` به بعد در دسترس هستند و مقادیری از چند نوع متفاوت را می‌پذیرند، نه از یک نوع واحد. تعریف‌های نوع اتحادی با استفاده از علامت پایپ (`|`) برای جدا کردن نوع‌ها ساخته می‌شوند.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

اگر پارامترهای ورودی نه `float` باشند و نه `int`، PHP در «حالت سخت‌گیرانه» یک `TypeError` پرتاب می‌کند. در «حالت غیر سخت‌گیرانه»، اگر پارامترهای ورودی را نتوان به `float` یا `int` تبدیل کرد، یک خطای نوع پرتاب می‌شود.

به همین ترتیب، اگر تابع یکی از انواع اعلام‌شده را برنگرداند، PHP در زمان اجرا یک `TypeError` پرتاب می‌کند.
