# توضیحات

«سه‌گانه‌ی فیثاغورسی» مجموعه‌ای از سه عدد طبیعی است، {a, b, c}، که در آن:

```text
a² + b² = c²
```

و به‌گونه‌ای که:

```text
a < b < c
```

برای مثال:

```text
3² + 4² = 5².
```

اگر یک عدد صحیح ورودی N داده شود، همه‌ی سه‌گانه‌های فیثاغورسی را بیابید که برایشان `a + b + c = N` برقرار است.

مثلاً با N = ۱۰۰۰، دقیقاً یک سه‌گانه‌ی فیثاغورسی وجود دارد که برای آن `a + b + c = 1000` است: `{200, 375, 425}`.
