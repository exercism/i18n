# درباره‌ی توابع مرتبه‌بالا

توابع در کاتلین شهروندان درجه‌ی یک به حساب می‌آیند.
این یعنی می‌توان آن‌ها را در متغیرها ذخیره کرد، به عنوان آرگومان پاس داد و حتی توابع دیگر هم می‌توانند آن‌ها را برگردانند.
برای نمونه، اختصاص دادن یک تابع به متغیر `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

یک تابع همچنین می‌تواند تابع دیگری را برگرداند:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

پس از اختصاص، می‌توان تابع را از طریق متغیر فراخوانی کرد، مثل این‌که یک تابع معمولی دیگر است:
```kotlin
addOne(3)
// => 4
```

## اعلان نوع تابع

می‌توان نوع یک متغیر یا پارامتر را با نحوه‌ی نگارش `(parameter types) -> return type` اعلان کرد.
برای نمونه، اعلان یک متغیر:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

و برای پارامتر یک تابع:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## عبارت لامبدا

عبارت لامبدا روشی کوتاه‌تر برای تعریف یک تابع است.
این عبارت‌ها به شکل `{ parameters -> body }` نوشته می‌شوند.
این عبارت آخرین مقدار را از آخرین دستور در بدنه برمی‌گرداند.
برای نمونه:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

کاتلین وقتی اطلاعات کافی وجود داشته باشد، می‌تواند نوع‌ها را استنتاج کند.
برای نمونه، مثال‌های بالا را می‌توان به این شکل هم نوشت:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` برای لامبداهای تک‌پارامتری

وقتی عبارت فقط یک پارامتر دارد، می‌توان آن پارامتر را حذف کرد.
در این صورت کاتلین پارامتری به اسم `it` را در بدنه در دسترس قرار می‌دهد.
برای نمونه:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## پاس دادن لامبدای پایانی

وقتی آخرین آرگومان یک تابع لامبدا باشد، عبارت لامبدا مستقیماً _بعد از_ پرانتزها نوشته می‌شود.
برای نمونه:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
