# مقدمه

برای واژه‌های کوتاه، دستکاری پشته کافی است. وقتی یک واژه چندین ورودی دارد و لازم است با اسم به آن‌ها اشاره کنید، Factor امکانی به نام `locals` در اختیارتان می‌گذارد: «اتصال‌های نام‌دار» که با `::` (برای تعریف واژه‌ها) یا `[| | ]` (برای لامبداهای درون‌خطی) معرفی می‌شوند و هر دو از [`locals`][locals] می‌آیند.

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

درون یک «quotation»، عبارت `[| inputs | body ]` یک لامبدا با ورودی‌های نام‌دار است:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
