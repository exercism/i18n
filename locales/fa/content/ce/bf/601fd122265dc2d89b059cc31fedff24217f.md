# مقدمه

`String` در Haxe یک شیء است که متنی تغییرناپذیر را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، نشانه‌های نگارشی و غیره) نمایش می‌دهد. برای تعریف یک نمونه‌ی `String` از گیومه‌ی دوتایی استفاده می‌شود:

```haxe
var fruit:String = "Apple";
```

رشته‌ها را می‌توان با فراخوانی متدهایشان دست‌کاری کرد. پس از ساخته شدن یک رشته، مقدارش هرگز تغییر نمی‌کند. هر متدی که به نظر می‌رسد رشته را تغییر می‌دهد، در واقع یک رشته‌ی جدید برمی‌گرداند.

می‌توان چندین رشته را به هم الحاق کرد (جمع کرد). ساده‌ترین راه برای این کار استفاده از عملگر `+` است.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

برای هر قالب‌بندی رشته‌ای پیچیده‌تر از الحاق ساده، درون‌یابی رشته ترجیح داده می‌شود. برای استفاده از درون‌یابی در یک رشته، آن را با نویسه‌ی تک‌گیومه (`'`) در بر بگیرید. سپس می‌توانید از علامت دلار (`$`) برای فعال کردن درون‌یابی استفاده کنید:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
