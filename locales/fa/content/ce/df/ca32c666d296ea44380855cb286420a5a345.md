# Exercism API

## توضیحات

بیشتر مسیرهای زبان Exercism برای دریافت و ارسال تمرین‌ها از ابزار خط فرمان `exercism` استفاده می‌کنند که از طریق یک API REST با `exercism.io` در تعامل است. مسیر زبان Pharo Smalltalk به‌جای آن از همان API REST استفاده می‌کند تا تمرین‌ها را بدون هیچ ابزار واسطه‌ای به تصویر Pharo وارد کند و از آن بیرون بیاورد. این سند APIِ Exercism را با تمرکز بر شیوه‌ی استفاده‌ی مسیر زبان Pharo Smalltalk از آن شرح می‌دهد. مخاطب آن نگهدارندگان ابزارهای Pharo Smalltalk هستند.

## هدرها

در همه‌ی اندپوینت‌ها باید هدرهای درخواست روی مقادیر زیر تنظیم شوند:

```
Authorization: Bearer <token>
```

مقدار `<token>` توکن احراز هویت CLI کاربر است که در `https://exercism.io/my/settings` در دسترس قرار دارد.

## دریافت تمرین‌ها

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

در URL بالا، `<slug>` اسم تمرین است، مثلاً `hello-world`، و `<language>` اسم مسیر زبان است، مثلاً `pharo-smalltalk`.

### پاسخ

#### 200

یک درخواست موفق پاسخی برمی‌گرداند که دربردارنده‌ی یک داده‌ی JSON است. درون این JSON اطلاعاتی درباره‌ی تمرین و URLی هست که فایل‌های تمرین از آن دانلود می‌شوند.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

اسم مسیر زبان مبهم است، یا فایل‌های تمرین ارسالی تغییری نکرده‌اند.

#### 403

راه‌حل برای کاربر باز نشده است، یا کاربر به مسیر زبان نپیوسته است.

#### 404

مسیر زبان یا تمرین پیدا نشد.

## ارسال تمرین‌ها

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### پاسخ

#### 201

یک ارسال موفقیت‌آمیز.

#### 400

یکی از فایل‌های ارسالی بیش از حد بزرگ است (بیشتر از یک مگابایت)، یا راه‌حل تکراری است.

#### 403

کاربر به راه‌حل دسترسی ندارد. شناسه‌ی کاربر راه‌حل با شناسه‌ی کاربر فعلی یکسان نیست.

#### 404

شناسه‌ی راه‌حل پیدا نشد.
