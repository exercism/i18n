# مقدمه

سیستم خطای Factor سه بخش دارد: `throw` (در [`kernel`][kernel]) یک خطا پرتاب می‌کند، `recover` (در [`continuations`][continuations]) آن را می‌گیرد و `ERROR:` یک کلاس خطا از نوع تاپل تعریف می‌کند.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` کوتیشن *try* را اجرا می‌کند؛ اگر خطا پرتاب کند، خطا روی پشته قرار می‌گیرد و کوتیشن *recovery* اجرا می‌شود.

`ERROR:` هم کلاس را تعریف می‌کند و هم واژه‌ای سازنده که یک نمونه‌ی تازه پرتاب می‌کند:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```
