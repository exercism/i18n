# راهنمایی‌ها

## 1. تاریخ قرار ملاقات را تجزیه کنید

- کلاس `LocalDateTime` روشی دارد که یک `String` را به `LocalDateTime` [تجزیه می‌کند][localdatetime-parse].
- از یک [`DateTimeFormatter`][datetimeformatter-docs] با الگویی سفارشی استفاده کنید تا قالبی غیراستاندارد از تاریخ و زمان را تجزیه کنید.

## 2. بررسی کنید که آیا قرار ملاقات گذشته است

- نمونه‌های `LocalDateTime` [روش‌هایی][localdatetime-methods] برای مقایسه‌شان با `LocalDateTime`های دیگر دارند.
- [روشی][localdatetime-methods] برای به‌دست‌آوردن تاریخ و زمان کنونی وجود دارد.

## 3. بررسی کنید که آیا قرار ملاقات بعدازظهر است

- برای دسترسی به بخش زمانِ یک نمونه‌ی `LocalDateTime` می‌توانید از یکی از [روش‌هایش][localdatetime-methods] استفاده کنید.

## 4. تاریخ و زمان قرار ملاقات را توصیف کنید

- از یک [`DateTimeFormatter`][datetimeformatter-docs] با الگویی سفارشی برای قالب‌بندی `LocalDateTime` استفاده کنید.
- آزمون‌ها طوری اجرا می‌شوند که انگار روی ماشینی در ایالات متحده اجرا می‌شوند، پس مطمئن شوید که قالب‌بند [از تنظیمات منطقه‌ی درست استفاده می‌کند][datetimeformatter-ofpattern-with-locale].

## 5. تاریخ سالگرد را برگردانید

- کلاس `LocalDate` [روشی][localdate-methods] برای به‌دست‌آوردن تاریخ کنونی دارد.
- برای دسترسی به سالِ یک نمونه‌ی `LocalDate` می‌توانید از یکی از [روش‌هایش][localdate-methods] استفاده کنید.
