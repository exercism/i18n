# استفاده از گاردها

[comment]: # (این خطا زمانی نمایش داده می‌شود که راه‌حل اصلاً از گاردها استفاده نکند)

از [«گاردها»](https://hexdocs.pm/elixir/master/guards.html) استفاده کنید تا `two_fer/1` کد را با ورودی‌های غیرباینری اجرا نکند.

> به یاد داشته باشید که در Elixir، [رشته‌ها](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) نوعی [داده‌ی باینری](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) به حساب می‌آیند.

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> این گارد را می‌توانید در `iex` آزمایش کنید.

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
