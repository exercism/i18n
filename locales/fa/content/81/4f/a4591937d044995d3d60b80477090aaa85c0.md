# مقدمه

## اعداد صحیح

در Elixir دو نوع مختلف عدد وجود دارد: «اعداد صحیح» و «اعداد اعشاری».

اعداد صحیح، اعدادی بدون جزء اعشاری هستند.

```elixir
integer = 3
# => 3
```

## اعداد اعشاری

اعداد اعشاری، اعدادی هستند که یک یا چند رقم پس از جداکننده‌ی اعشار دارند. این اعداد از قالب اعشاری دقت مضاعف ۶۴ بیتی استفاده می‌کنند.

```elixir
float = 3.45
# => 3.45
```

### کار با اعداد

در ماژول‌های [`Integer`][integer-functions] و [`Float`][float-functions] می‌توانید چند تابع مفید برای کار با این نوع‌ها پیدا کنید. عملگرهای حسابی پایه در ماژول [`Kernel`][kernel-arithmetic-operators] تعریف شده‌اند.

### تبدیل

اعداد صحیح و اعشاری را می‌توان در یک عبارت حسابی با هم ترکیب کرد. استفاده از یک عدد اعشاری در عبارت باعث می‌شود نتیجه هم اعشاری باشد.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

اما وقتی تقسیم می‌کنید، نتیجه همیشه یک عدد اعشاری خواهد بود، حتی اگر فقط از اعداد صحیح استفاده کنید.

```elixir
6 / 2
# => 3.0
```

برای تبدیل یک عدد اعشاری به عدد صحیح، می‌توانید جزء اعشاری را با [`trunc/1`][trunc-1] حذف کنید.
