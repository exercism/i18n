# ضمیمه‌ی دستورالعمل‌ها

## رجیسترها

| رجیستر | کاربرد | نوع | توضیح |
| -------- | ------------ | ------- | ----------------------- |
| `$a0`    | ورودی | عدد صحیح | تعداد سطرهای مثلث |
| `$a1`    | ورودی/خروجی | آدرس | آرایه‌ای از کلمه‌ها |
| `$v0`    | خروجی | عدد صحیح | تعداد کلمه‌های خروجی |
| `$t0-9`  | موقت | هر نوعی | برای ذخیره‌سازی موقت |
