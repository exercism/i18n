# درباره

حلقه‌ی `do-while` جایگزینی برای حلقه‌ی `while` است و تنها تفاوت این است که حلقه‌ی `do-while` حداقل یک بار اجرا می‌شود:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

موارد استفاده از حلقه‌ی `do-while` بسیار نادر است، بنابراین به‌جای آن از حلقه‌ی معمولی `while` استفاده می‌شود.
