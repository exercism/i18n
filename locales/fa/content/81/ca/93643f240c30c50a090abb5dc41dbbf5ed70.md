# درباره

نوع `Bool` یکی از اجزای سازنده‌ی زبان است.
هدف آن توصیف این است که چیزی «درست» است یا «غلط»، با مقادیر متناظر `True` و `False`.
اسم `Bool` مخفف Boolean است، که شاخه‌ای از ریاضیات مرتبط با تفکر منطقی است و اسمش از کار جورج بول گرفته شده است.

## عملگرهای منطقی

دو تابع و دو عملگر برای دستکاری مقادیر نوع `Bool` وجود دارد.

- `not : Bool -> Bool`
  این تابع `True` را به `False` و `False` را به `True` تبدیل می‌کند.
- `(&&) : Bool -> Bool -> Bool`
  این عملگر که «AND» نام دارد، دو مقدار منطقی می‌گیرد و اگر هر دو `True` باشند `True` برمی‌گرداند.
  برای مثال، `True && True` مقدار `True` را برمی‌گرداند اما `True && False` مقدار `False` را برمی‌گرداند.
- `(||) : Bool -> Bool -> Bool`
  این عملگر که «OR» نام دارد، دو مقدار منطقی می‌گیرد و اگر دست‌کم یکی از آن‌ها `True` باشد `True` برمی‌گرداند.
  برای مثال، `False || False` مقدار `False` را برمی‌گرداند اما `True || False` مقدار `True` را برمی‌گرداند.
- `xor : Bool -> Bool -> Bool`
  این تابع (نه عملگر) که «XOR» نام دارد، دو مقدار منطقی می‌گیرد و اگر و تنها اگر یکی `True` و دیگری `False` باشد `True` برمی‌گرداند.

عملگرهای `&&` و `||` اولویت یکسانی ندارند.
اولویت `&&` از اولویت `||` بالاتر است، درست مانند ضرب `*` و جمع `+`.
در نتیجه، عبارت `True || False && False` معادل `True || (False && False)` است و با `(True || False) && False` تفاوت دارد.
اولی `True` را برمی‌گرداند و دومی `False` را.

## انشعاب شرطی

مقادیر منطقی برای ساختن شاخه‌هایی در کد بسیار مفید هستند؛ شاخه‌هایی که فقط در صورت برقرار بودن شرط‌های خاصی اجرا می‌شوند.
در Elm این کار با یک عبارت `if-then-else` انجام می‌شود که به شکل زیر استفاده می‌شود.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

مقدار `someCondition` می‌تواند هر عبارتی باشد که یک `Bool` برمی‌گرداند.
اگر آن مقدار منطقی `True` باشد، کد `doSomething` را اجرا می‌کند.
در غیر این صورت `False` است و کد `doSomethingElse` را اجرا می‌کند.
برخلاف برخی زبان‌های برنامه‌نویسی دیگر، شاخه‌ی `else` اجباری است.

اگر لازم است شرط‌ها را به هم زنجیر کنید، کافی است عبارت‌های `if-then-else` را به هم زنجیر کنید.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
