# درباره

از آنجا که همه‌ی نوع‌های داده‌ی استاندارد Clojure تغییرناپذیرند، این زبان *نوع‌های ارجاعی* را ارائه می‌دهد که تغییر کنترل‌شده را ممکن می‌کنند. ساده‌ترین و پرکاربردترین آن‌ها «Atom» نام دارد.

Atomها با تابع `atom` ساخته می‌شوند که یک مقدار اولیه می‌گیرد:

```clojure
(def players (atom ()))
```

مقدار جاری Atom را می‌توان با `deref` یا صورت کوتاه `@` واکشی کرد:

```clojure
@players
;;=> ()
```

مقدار جاری Atom `players` را می‌توان با `swap!` تغییر داد؛ این تابع مقدار را با اعمال یک تابع به‌روزرسانی می‌کند:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

تابع `reset!` مقدار یک Atom را بدون توجه به مقدار جاری‌اش جایگزین می‌کند:

```clojure
(reset! players ())
```
