# دستورالعمل‌ها

شما پرنده‌نگری مشتاق هستید که پیگیری می‌کنید در هفت روز گذشته چند پرنده به باغتان آمده‌اند.

شش تمرین پیش رو دارید که همه به تعداد پرندگانی مربوط می‌شوند که به باغتان آمده‌اند.

## 1. بررسی کنید شمارش‌های هفته‌ی گذشته چه بوده‌اند

برای مقایسه، همیشه نسخه‌ای از شمارش‌های هفته‌ی گذشته را کنار دستتان نگه می‌دارید که عبارت‌اند از: 0، 2، 5، 3، 7، 8 و 4. متد (_static_) `BirdCount.LastWeek()` را پیاده‌سازی کنید که شمارش‌های هفته‌ی گذشته را برمی‌گرداند:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. بررسی کنید امروز چند پرنده آمده‌اند

متد `BirdCount.Today()` را پیاده‌سازی کنید تا برگرداند امروز چند پرنده به باغ شما آمده‌اند. شمارش پرندگان به ترتیب روز مرتب شده است، به این صورت که اولین عنصر شمارش قدیمی‌ترین روز است و آخرین عنصر شمارش امروز.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. شمارش امروز را افزایش دهید

متد `BirdCount.IncrementTodaysCount()` را پیاده‌سازی کنید تا شمارش امروز را افزایش دهد:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. بررسی کنید روزی بدون پرنده‌ی بازدیدکننده وجود داشته است یا نه

متد `BirdCount.HasDayWithoutBirds()` را پیاده‌سازی کنید که اگر روزی وجود داشته باشد که در آن هیچ پرنده‌ای به باغ نیامده باشد، `true` را برمی‌گرداند؛ در غیر این صورت، `false` را برگردانید:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. محاسبه‌ی تعداد پرندگان بازدیدکننده در چند روز نخست

متد `BirdCount.CountForFirstDays()` را پیاده‌سازی کنید که تعداد پرندگانی را برمی‌گرداند که از ابتدای هفته به باغ شما آمده‌اند، اما شمارش را به تعداد روزهای مشخص‌شده از ابتدای هفته محدود کنید.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. محاسبه‌ی تعداد روزهای پرمشغله

برخی روزها پرمشغله‌تر از بقیه هستند. روز پرمشغله روزی است که پنج پرنده یا بیشتر به باغ شما آمده باشند.
متد `BirdCount.BusyDays()` را پیاده‌سازی کنید تا تعداد روزهای پرمشغله را برگرداند:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
