# مقدمه

گاهی لازم است یک تکه کد بیش از یک بار استفاده شود. در این صورت، ممکن است راحت‌تر باشد که آن کد را داخل یک تابع بگذارید. یک «تابع» معمولاً فقط یک کار مشخص را انجام می‌دهد. در Rust برای تعریف توابع از کلیدواژه‌ی ```fn``` استفاده می‌شود. کدی که به تابع تعلق دارد همیشه بین آکولادها قرار می‌گیرد (یعنی `{}`). تابعی به اسم `main` ویژه است، چون نقطه‌ی ورود برنامه‌هاست. از همان تابع می‌توانید توابع دیگر را فراخوانی کنید.

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

توابع می‌توانند پارامتر هم بگیرند، مثل ```name: &str``` در ```say_my_name()```. توابع می‌توانند مقدار هم برگردانند، مثل `-> &str` در بالا.
