# استفاده از `strings.Compare`

استفاده از `strings.Compare` را حذف کنید. در [مستندات رسمی](https://golang.org/pkg/strings/#Compare) آن آمده است:

> `Compare` فقط برای تقارن با پکیج `bytes` گنجانده شده است.
> معمولاً استفاده از عملگرهای مقایسه‌ی رشته‌ی داخلی مانند `==`، `<`، `>` و غیره خواناتر و همیشه سریع‌تر است.
