# مقدمه

## عبارت‌های باقاعده

عبارت‌های باقاعده در Gleam، مشابه زبان‌های محبوب دیگری مانند Java، JavaScript یا Ruby، از مشخصات **PCRE** («عبارت‌های باقاعده‌ی سازگار با Perl») پیروی می‌کنند.

ماژول `gleam/regexp` از بسته‌ی `gleam_regexp` توابعی برای کار با عبارت‌های باقاعده ارائه می‌دهد.

~~~~exercism/note
این تمرین فرض می‌کند که شما از قبل نحوه‌ی نگارش عبارت‌های باقاعده را می‌دانید، از جمله کلاس‌های نویسه، کمیت‌سازها، گروه‌ها و گروه‌های گرفته‌شده.

اگر لازم است دانش خود را درباره‌ی عبارت‌های باقاعده تازه کنید، یکی از این منابع را ببینید: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

رایج‌ترین راه برای ساختن عبارت‌های باقاعده، استفاده از تابع `regexp.from_string` است.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

توابع ساخت عبارت باقاعده در صورتی که نحوه‌ی نگارش عبارت نامعتبر باشد خطا برمی‌گردانند، به همین دلیل اینجا از یک `let-assertion` استفاده شده تا مطمئن شویم عبارت باقاعده معتبر است.

با تابع `regexp.check` می‌توان بررسی کرد که آیا یک عبارت باقاعده با یک رشته مطابقت دارد یا نه.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### گروه‌های گرفته‌شده

اگر می‌خواهید با یک عبارت باقاعده زیررشته‌ها را بگیرید، می‌توان از تابع `regexp.scan` استفاده کرد تا فهرستی از تطابق‌ها برگردانده شود.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### اصلاح‌کننده‌ها

می‌توان رفتار یک عبارت باقاعده را با ساختن آن به کمک تابع `regexp.compile` و دادن گزینه‌ها تغییر داد.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
