# عدد

کریستال نوعی دارد به اسم `Number` که نوع پایه‌ی همه‌ی انواع عددی است.
درون نوع `Number` دو زیرنوع اصلی وجود دارد: [`Int`][int] و [`Float`][float].

`Int` مخفف integer است و نماینده‌ی اعداد صحیح است.
`Int` می‌تواند هم منفی باشد و هم مثبت، بدون نقطه‌ی اعشار.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` نماینده‌ی اعدادی با نقطه‌ی اعشار است.
مقادیر `Float` می‌توانند هم منفی باشند و هم مثبت.

```crystal
10.5.class
# => Float64
```

## تبدیل بین `Int` و `Float`

با متدهای `to_i` و `to_f` می‌توانید بین `Int` و `Float` تبدیل انجام دهید.
هنگام تبدیل از `Float` به `Int`، عدد به پایین گرد می‌شود.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## عملگرهای حسابی

می‌توانید از [عملگرهای حسابی پایه][math] روی `Int` و `Float` استفاده کنید.
این عملگرها عبارت‌اند از `+`، `-`، `*`، `/` و `%`.
هنگام استفاده از این عملگرها می‌توانید `Int` و `Float` را با هم ترکیب کنید.

### جمع و تفریق و ضرب

عملگر `+` برای جمع، عملگر `-` برای تفریق و عملگر `*` برای ضرب به کار می‌رود.

| عملگر | مثال        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### تقسیم

از تقسیم برای بخش کردن اعداد استفاده می‌شود.
عملگر `/` برای تقسیم به کار می‌رود.
نتیجه همیشه یک `Float` خواهد بود.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
در بعضی زبان‌های برنامه‌نویسی، وقتی بر صفر تقسیم می‌کنید، نتیجه یک خطا خواهد بود.

در کریستال، وقتی بر صفر تقسیم می‌کنید، نتیجه `Infinity` یا `-Infinity` است.
تنها استثنا تقسیم صفر بر صفر است که به `NaN` (نه یک عدد) منجر می‌شود.
`Infinity` و `NaN` مقادیر ویژه‌ای در نوع `Float` هستند.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### باقیمانده

از باقیمانده برای به دست آوردن باقیمانده‌ی یک تقسیم استفاده می‌شود.
برای این کار از عملگر `%` استفاده می‌شود.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
تقسیم بر صفر هنگام استفاده از باقیمانده به `DivisionByZeroError` منجر می‌شود.
این با تقسیم معمولی فرق دارد.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## گرد کردن

متد `round` یک آرگومان اختیاری می‌گیرد: تعداد رقم‌های اعشاری که باید گرد شوند.
تعداد پیش‌فرض رقم‌های اعشاری ۰ است.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## اولویت و پرانتزها

کریستال پرانتز (`()`) را مجاز می‌داند و می‌توان از آن برای گروه‌بندی عبارت‌ها استفاده کرد.
این کار وقتی مفید است که بخواهید ترتیب عملیات را تغییر دهید.

وقتی از چند عملگر حسابی استفاده می‌کنید، ترتیب عملیات همانند ریاضیات است که به [PEMDAS][pemdas] معروف است.
این ترتیب از پرانتز (`()`)، توان (`**`)، ضرب (`*`) و تقسیم (`/`) و سپس جمع (`+`) و تفریق (`-`) پیروی می‌کند.

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
