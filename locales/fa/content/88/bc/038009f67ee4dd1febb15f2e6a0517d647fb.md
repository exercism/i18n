# مرتب‌سازی

مرتب کردن موارد آن‌قدر رایج است که کتابخانه خودش این کار را برایتان انجام می‌دهد.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` روی هر موردی کار می‌کند که از قبل بداند چطور خودش را با دیگران مقایسه کند. اعداد و رشته‌ها این کار را بلدند، چون `is_lt` دارند.

## مرتب‌سازی با قاعده‌ی خودتان

بیشتر ترتیب‌ها همان ترتیب درون‌ساخت نیستند. جدول رده‌بندی نتبال نه بر اساس حروف الفباست و نه بر اساس طول اسم: بر اساس امتیاز است و بعد برای تیم‌هایی که امتیازشان برابر است، بر اساس تفاضل گل. `ARRAY` هیچ راهی ندارد که این را حدس بزند.

پس ترتیب را به شکل یک رویه‌ی مقید ارائه می‌دهید:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` یک `ROUT{T,T}:BOOL` می‌گیرد؛ یعنی رویه‌ای که دو مورد از موارد در حال مرتب‌سازی را می‌گیرد و پاسخ می‌دهد که آیا اولی باید پیش از دومی بیاید یا نه. این رویه را هر چند بار که لازم باشد فراخوانی می‌کند و آرایه را به همان ترتیبی می‌چیند که پاسخ‌ها ایجاب می‌کنند.

`understudy` برای همین بود. کتابخانه می‌داند چطور مرتب کند و از تصور شما از ترتیب بی‌خبر است؛ رویه‌ی مقید همان‌جایی است که این دو به هم می‌رسند.

## نوشتن مقایسه

رویه **«درست» را پاسخ می‌دهد وقتی که آرگومان اول جلوتر باشد**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

برای قاعده‌ای که بیش از یک بخش دارد، بخش‌ها را به ترتیب اهمیت بررسی کنید:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

اولین `if` هر جا که امتیازها متفاوت باشند، تصمیم نهایی را می‌گیرد. فقط وقتی برابر باشند نوبت به خط دوم می‌رسد. اگر تعیین‌کننده‌ی تساوی را اول می‌نوشتیم، امتیازها هیچ‌وقت مهم نبودند.

## مرتب‌سازی آرایه را تغییر می‌دهد

`insertion_sort_by` خود آرایه را مرتب می‌کند و چیزی برنمی‌گرداند:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

اگر ترتیب اولیه مهم است، یک رونوشت را مرتب کنید:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
