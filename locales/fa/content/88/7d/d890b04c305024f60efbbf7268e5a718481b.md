# دستورالعمل

دوست شما، هنرمندی نوپا، با ایده‌ی یک پروژه به سراغتان آمد. بیایید خلاقیت بصری او را با تخصص فنی شما ترکیب کنیم. وقت آن رسیده که در [هنر مولد][generative-art] دستی ببرید!

محدودیت‌ها به خلاقیت کمک می‌کنند و مهلت پروژه را کوتاه‌تر می‌کنند، پس هر دو توافق کرده‌اید شاهکارتان را به یک شکل محدود کنید: دایره. اما قرار است دایره‌های زیادی داشته باشیم. و می‌توانند جابه‌جا شوند! اسمش را می‌گذارید... نقطه‌های رقصان.

دوست شما قطعاً می‌خواهد حرکت‌های تازه و پیچیده‌ای برای نقطه‌ها ابداع کند، پس کدنویسی را با ساختن معماری‌ای شروع می‌کنید که بعداً به شما اجازه می‌دهد انیمیشن‌های جدید را به‌راحتی تعریف کنید.

## 1. رفتار انیمیشن را تعریف کنید

هر ماژول انیمیشن باید دو callback را پیاده‌سازی کند: `init/1` و `handle_frame/3`. آن‌ها را در ماژول `Animation` تعریف کنید.

callback یعنی `init/1`. باید یک آرگومان از نوع `opts` بگیرد و یک تاپل `{:ok, opts}` یا تاپل `{:error, error}` بازگرداند. پیاده‌سازی‌های این callback بررسی می‌کنند که آیا گزینه‌های داده‌شده برای این نوع خاص از انیمیشن معتبرند یا نه.

callback یعنی `handle_frame/3` را تعریف کنید. باید سه آرگومان بگیرد: نقطه، شماره‌ی فریم و گزینه‌ها. باید همیشه یک نقطه بازگرداند. پیاده‌سازی‌های این callback ویژگی‌های نقطه را بر اساس شماره‌ی فریم جاری و گزینه‌های انیمیشن تغییر می‌دهند.

## 2. یک پیاده‌سازی پیش‌فرض برای callback یعنی `init/1` فراهم کنید

رفتار `Animation` باید طوری باشد که با فراخوانی `use DancingDots.Animation` به‌راحتی در ماژول‌های دیگر جای بگیرد.

برای این کار، ماکروی `__using__` را در ماژول `Animation` پیاده‌سازی کنید تا ماژول `Animation` را به‌عنوان رفتار ماژول دیگر تعیین کند. همچنین باید یک پیاده‌سازی پیش‌فرض از callback یعنی `init/1` فراهم کند. پیاده‌سازی پیش‌فرض `init/1` باید گزینه‌های داده‌شده را بدون تغییر بازگرداند.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. انیمیشن `Flicker` را پیاده‌سازی کنید

با استفاده از رفتار `Animation` یک انیمیشن چشمک‌زن پیاده‌سازی کنید.

باید از callback پیش‌فرض `init/1` استفاده کند، چون هیچ گزینه‌ای نمی‌گیرد.

callback یعنی `handle_frame/3` را پیاده‌سازی کنید که یک فریم را مدیریت می‌کند. اگر شماره‌ی فریم مضربی از چهار باشد، تابع باید نقطه را با نصف کدری اولیه‌اش بازگرداند. در فریم‌های دیگر باید نقطه را بدون تغییر بازگرداند.

فریم‌ها از `1` شمرده می‌شوند. نقطه‌ای که به `handle_frame/3` داده می‌شود همیشه نقطه در حالت اولیه‌ی خودش است، نه در حالتی که از فریم قبلی به جا مانده.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. انیمیشن `Zoom` را پیاده‌سازی کنید

با استفاده از رفتار `Animation` یک انیمیشن زوم پیاده‌سازی کنید.

این انیمیشن یک گزینه می‌گیرد: سرعت. سرعت می‌تواند هر عددی باشد. اگر منفی باشد، نقطه به‌جای بزرگ‌تر شدن، کوچک‌تر می‌شود.

callback یعنی `init/1` را پیاده‌سازی کنید. باید بررسی کند که گزینه‌های داده‌شده یک لیست کلیدواژه‌ای با کلید `:velocity` هستند. مقدار سرعت باید یک عدد باشد. اگر عدد نباشد، خطای `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"` را بازگردانید.

callback یعنی `handle_frame/3` را پیاده‌سازی کنید. باید نقطه را با شعاعی بازگرداند که به اندازه‌ی شماره‌ی فریم جاری منهای یک، ضربدر سرعت، افزایش یافته است.

فریم‌ها از `1` شمرده می‌شوند. نقطه‌ای که به `handle_frame/3` داده می‌شود همیشه نقطه در حالت اولیه‌ی خودش است، نه در حالتی که از فریم قبلی به جا مانده.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
