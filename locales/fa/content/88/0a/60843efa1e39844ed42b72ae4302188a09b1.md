# مقدمه

«اشاره‌گرهای هوشمند» در Cairo ساختارهای داده‌ی پیشرفته‌ای هستند که با افزودن ویژگی‌های ایمنی به اشاره‌گرهای معمولی، مدیریت حافظه‌ی ایمن و کارآمد را تضمین می‌کنند و از بروز مشکلات رایجی مثل ارجاع‌زدایی از اشاره‌گر تهی یا دسترسی به حافظه‌ی مقداردهی‌نشده جلوگیری می‌کنند.

## اشاره‌گر هوشمند چیست؟

اشاره‌گر هوشمند مثل یک اشاره‌گر معمولی رفتار می‌کند، اما مالکیت را ردیابی می‌کند و دسترسی ایمن به حافظه را تضمین می‌کند و جلوی مشکلاتی مثل ارجاع‌زدایی از اشاره‌گر تهی یا اشاره‌گر معلق را می‌گیرد.

## انواع اشاره‌گرهای هوشمند

Cairo چند نوع اشاره‌گر هوشمند در اختیار شما می‌گذارد، مثل `Box<T>` و `Nullable<T>`:

- **`Box<T>`**: داده را در یک بخش حافظه‌ی ویژه ذخیره می‌کند و برای داده‌های بزرگ یا با اندازه‌ی پویا ایدئال است.
                امکان انتقال مالکیت را بدون کپی کردن داده فراهم می‌کند.
- **`Nullable<T>`**: به یک مقدار معتبر از نوع `T` یا به `null` اشاره می‌کند و برای کار با مقادیر اختیاری به کار می‌آید.

## ایمنی حافظه

اشاره‌گرهای هوشمند به جلوگیری از دسترسی ناایمن به حافظه کمک می‌کنند و تضمین می‌کنند که حافظه وقتی دیگر لازم نیست، به‌طور خودکار آزاد شود؛ این‌گونه خطر نشت حافظه کاهش می‌یابد.

### مثال: استفاده از `Box<T>` برای انواع بازگشتی

اشاره‌گرهای هوشمندی مثل `Box<T>` با تخصیص کارآمد حافظه و پرهیز از بازگشت بی‌پایان، امکان کار ایمن با انواع بازگشتی را فراهم می‌کنند؛ مثلاً در یک درخت دودویی.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## مزایای کارایی

اشاره‌گرهای هوشمند با ارسال ارجاع به داده به‌جای کپی کردن ساختارهای بزرگ، کارایی را بهبود می‌دهند و سرباز حافظه را کم می‌کنند.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
