# مقدمه

ساختار اصلی شیءگرا در C#، «کلاس» است که ترکیبی از داده («فیلد») و رفتار («متد») است. به فیلدها و متدهای یک کلاس، «اعضا» می‌گویند.

دسترسی به اعضا را می‌توان با «اصلاح‌کننده‌های دسترسی» محدود کرد. دو مورد از رایج‌ترین آن‌ها عبارت‌اند از:

- `public`: هر کدی می‌تواند به این عضو دسترسی داشته باشد (بدون محدودیت).
- `private`: فقط کدی در همان کلاس می‌تواند به این عضو دسترسی داشته باشد.

می‌توانید کلاس را به‌عنوان قالبی برای ساختن نمونه‌هایی از آن در نظر بگیرید. برای ساختن نمونه‌ای از یک کلاس (که به آن «شیء» هم می‌گویند)، از کلیدواژه‌ی `new` استفاده می‌شود:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

فیلدها یک نوع دارند و می‌توانند در هر جای کلاس تعریف شوند.
فیلدهای عمومی با PascalCase و فیلدهای خصوصی با camelCase تعریف می‌شوند و با زیرخط `_` شروع می‌شوند:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

می‌توان به‌صورت اختیاری یک مقدار اولیه به فیلد اختصاص داد. اگر فیلدی مقدار اولیه مشخص نکند، مقدار پیش‌فرض نوعش برای آن تنظیم می‌شود. مقادیر فیلدهای یک نمونه را می‌توان با «نقطه‌گذاری» خواند و به‌روزرسانی کرد.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

فیلدهای خصوصی معمولاً در نتیجه‌ی فراخوانی یک متد به‌روزرسانی می‌شوند. چنین متدهایی معمولاً مقداری برنمی‌گردانند و در این صورت نوع بازگشتی باید `void` باشد:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
