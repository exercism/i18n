# دستورالعمل‌ها

در این تمرین با حساب‌های پس‌انداز کار می‌کنید. هر سال، موجودی حساب پس‌انداز شما بر اساس نرخ سود آن به‌روزرسانی می‌شود. نرخ سودی که بانک به شما می‌دهد به مقدار پول موجود در حساب شما (موجودی آن) بستگی دارد:

- ۳٫۲۱۳٪ برای موجودی منفی (به سود منفی منجر می‌شود).
- ۰٫۵٪ برای موجودی مثبتِ کمتر از `1000` دلار.
- ۱٫۶۲۱٪ برای موجودی مثبتِ بزرگ‌تر یا مساوی `1000` دلار و کمتر از `5000` دلار.
- ۲٫۴۷۵٪ برای موجودی مثبتِ بزرگ‌تر یا مساوی `5000` دلار.

هر سال دولت به شما اجازه می‌دهد درصدی از پولتان را به‌صورت معاف از مالیات به امور خیریه اهدا کنید. چون آدم خوبی هستید، اگر موجودی شما در پایان سال مثبت باشد، درصد معاف از مالیات را برمی‌دارید و آن را دو برابر می‌کنید و به نزدیک‌ترین دلار کامل به پایین گرد می‌کنید. پرداخت مالیات روی نیمه‌ی دوم این اهدا برایتان مهم نیست.

سه وظیفه دارید که هرکدام به موجودی شما و نرخ سود آن می‌پردازد.

## 1. محاسبه‌ی نرخ سود

تابع `interestRate` را پیاده‌سازی کنید تا نرخ سود را بر اساس موجودی داده‌شده محاسبه کند:

```fsharp
interestRate 200.75m
// => 0.5f
```

توجه کنید که مقدار برگشتی یک `single` است.

## 2. محاسبه‌ی سود

متد `interest` را پیاده‌سازی کنید تا سود را بر اساس موجودی داده‌شده محاسبه کند:

```fsharp
interest 200.75m
// => 1.00375m
```

توجه کنید که مقدار برگشتی یک `decimal` است.

## 3. محاسبه‌ی به‌روزرسانی سالانه‌ی موجودی

تابع `annualBalanceUpdate` را پیاده‌سازی کنید تا به‌روزرسانی سالانه‌ی موجودی را با در نظر گرفتن نرخ سود محاسبه کند:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

توجه کنید که مقدار برگشتی یک `decimal` است.

## 4. محاسبه‌ی مقدار پولی که باید اهدا شود

تابع `amountToDonate` را پیاده‌سازی کنید تا بر اساس موجودی و درصد معاف از مالیاتی که دولت مجاز می‌داند، محاسبه کند چه مقدار پول باید به امور خیریه اهدا شود:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

توجه کنید که مقدار برگشتی یک `int` است.
