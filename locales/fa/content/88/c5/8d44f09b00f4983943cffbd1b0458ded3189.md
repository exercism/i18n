# مقدمه

کاراکترهای Factor اعداد صحیح‌اند؛ یعنی نقاط کد یونیکد. بنابراین عملگرهای عددی `<`، `>` و `=` مستقیماً یک ترتیب حساس به بزرگی و کوچکی حروف به شما می‌دهند. واژگان [`unicode`][unicode] توابع بررسی‌کننده‌ی آگاه از یونیکد و تبدیل حالت حروف برای یک کاراکتر را اضافه می‌کند.

## توابع بررسی کاراکتر

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## تبدیل حالت حروف

`ch>upper` و `ch>lower` حالت یک کاراکتر را برمی‌گردانند. `>upper` و `>lower` در سطح رشته، آن‌ها را روی همه‌ی کاراکترهای یک رشته اعمال می‌کنند.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
