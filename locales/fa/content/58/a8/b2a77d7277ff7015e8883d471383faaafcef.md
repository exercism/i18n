# مقدمه

از «انواع خارجی» می‌توان برای اشاره به انواع داده‌ای که در زبان‌های دیگر تعریف شده‌اند، مانند Erlang یا JavaScript، استفاده کرد.

برای تعریف یک «تابع خارجی»، یک نوع را اعلان کنید اما هیچ سازنده‌ای ارائه ندهید. سپس می‌توان از آن مانند هر نوع دیگری استفاده کرد.

```gleam
pub type OrderedDictionary(element)
```
