# مقدمه

اسلایس‌ها در Go شبیه به لیست‌ها یا آرایه‌ها در زبان‌های دیگر هستند.
هر اسلایس چندین عنصر از یک نوع مشخص (یا یک رابط) را در خود نگه می‌دارد.

اسلایس‌ها در Go بر پایه‌ی آرایه‌ها ساخته شده‌اند.
آرایه‌ها اندازه‌ی ثابتی دارند.
اسلایس اما نمایی انعطاف‌پذیر و با اندازه‌ی پویا از عناصر یک آرایه است.

اسلایس به شکل `[]T` نوشته می‌شود که در آن `T` نوع عناصر داخل اسلایس است:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

با نشانه‌گذاری کروشه می‌توانید عنصری را در یک اندیس مشخص که از صفر شماره‌گذاری می‌شود بخوانید یا مقدار جدیدی برایش تعیین کنید:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

می‌توانید با گرفتن یک بازه از عناصر، از روی یک اسلایس موجود اسلایس جدیدی بسازید.
این بار هم با نشانه‌گذاری کروشه، اما با مشخص کردن هم اندیس شروع (که خودش هم شامل می‌شود) و هم اندیس پایان (که شامل نمی‌شود).
اگر اندیس شروع را مشخص نکنید، مقدار پیش‌فرض آن ۰ است.
اگر اندیس پایان را مشخص نکنید، مقدار پیش‌فرض آن طول اسلایس است.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

می‌توانید با استفاده از تابع `append` عنصرهایی به یک اسلایس اضافه کنید.
در ادامه `4` و `2` را به اسلایس `a` اضافه می‌کنیم.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

تابع `append` همیشه یک اسلایس جدید برمی‌گرداند. وقتی هم که فقط می‌خواهیم عنصرهایی به یک اسلایس موجود اضافه کنیم، معمول است نتیجه را دوباره به همان متغیر اسلایسی نسبت دهیم که به عنوان آرگومان اول پاس داده‌ایم؛ همان کاری که در بالا کردیم.

از `append` می‌توان برای ادغام دو اسلایس هم استفاده کرد:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## اندیس‌ها در اسلایس‌ها

کار با اندیس‌های اسلایس‌ها را باید همیشه به نحوی با یک بررسی محافظت کرد که مطمئن شود آن اندیس واقعاً وجود دارد.
اگر این کار را نکنید، کل برنامه کرش می‌کند.

## اسلایس‌های خالی

اسلایس‌های `nil` همان اسلایس خالی پیش‌فرض هستند.
در مقایسه با یک اسلایس بدون مقدار، هیچ اشکالی ندارند.
تابع `len` روی اسلایس‌های `nil` کار می‌کند و می‌توان بدون مقداردهی اولیه به آن عنصر اضافه کرد و از این قبیل کارها.
اگر می‌خواهید اسلایس جدیدی بسازید، `var s []int` (اسلایس `nil`) را به `s := []int{}` (اسلایس خالی و غیر`nil`) ترجیح دهید.

## کارایی

وقتی اسلایس‌هایی می‌سازید که قرار است به‌صورت تکراری پر شوند، اگر اندازه‌ی نهایی اسلایس مشخص باشد، کار سادهای برای بهبود کارایی وجود دارد.
نکته‌ی اصلی کم کردن تعداد دفعاتی است که باید حافظه تخصیص داده شود؛ کاری نسبتاً پرهزینه که وقتی اسلایس از فضای حافظه‌ی تخصیص‌یافته‌اش بزرگ‌تر شود رخ می‌دهد.
امن‌ترین راه این کار، مشخص کردن یک ظرفیت `cap` برای اسلایس به شکل `s := make([]int, 0, cap)` و سپس استفاده از `append` روی اسلایس به روش معمول است.
به این ترتیب، فضای لازم برای `cap` عنصر بلافاصله تخصیص داده می‌شود، در حالی که طول اسلایس صفر است.
در عمل، `cap` اغلب طول یک اسلایس دیگر است: `s := make([]int, 0, len(otherSlice))`.

## `append` تابعی خالص نیست

تابع `append` در Go برای کارایی بهینه شده است و به همین دلیل از اسلایس ورودی کپی نمی‌گیرد.
این یعنی اسلایس اصلی (پارامتر اول `append`) گاهی تغییر می‌کند.
