# راهنماها

## 1. بررسی کنید آیا یک مقدار منطقی است

- می‌توانید از `typeof` برای یافتن نوع یک مقدار استفاده کنید.
- `typeof` یک رشته برمی‌گرداند.

## 2. بررسی کنید آیا یک مقدار عدد است.

- می‌توانید از `typeof` برای یافتن نوع یک مقدار استفاده کنید.
- `typeof` یک رشته برمی‌گرداند.
- باید `Infinity` و `NaN` را هم بررسی کنید.
- `NaN` هرگز با خودش برابر نیست، اما یک [تابع داخلی][isNaN] هست که با آن می‌توانید بررسی کنید آیا یک مقدار `NaN` است.

## 3. بررسی کنید آیا یک مقدار شیء است

- می‌توانید از `typeof` برای یافتن نوع یک مقدار استفاده کنید.
- `typeof` یک رشته برمی‌گرداند.
- باید `null` را هم بررسی کنید.

## 4. بررسی کنید آیا یک رشته عددی است

- می‌توانید از `typeof` برای یافتن نوع یک مقدار استفاده کنید.
- `typeof` یک رشته برمی‌گرداند.
- می‌توانید یک رشته را پیمایش کنید تا بررسی کنید که همه‌ی کاراکترهایش رقم هستند.

## 5. بررسی کنید آیا یک شیء الکترونیکی است

- می‌توانید از `instanceof` استفاده کنید تا بررسی کنید آیا یک شیء نمونه‌ای از یک کلاس یا یکی از فرزندانش است.

## 6. بررسی کنید آیا یک مقدار آرایه‌ی ناتهی است

- می‌توانید از `typeof` برای یافتن نوع یک مقدار استفاده کنید.
- `typeof` یک رشته برمی‌گرداند.
- می‌توانید طول یک آرایه را بررسی کنید تا بفهمید چند عنصر دارد.

## 7. بررسی کنید آیا یک مقدار آرایه‌ی خالی است

- می‌توانید از `typeof` برای یافتن نوع یک مقدار استفاده کنید.
- `typeof` یک رشته برمی‌گرداند.
- می‌توانید طول یک آرایه را بررسی کنید تا بفهمید چند عنصر دارد.

## 8. بررسی کنید آیا یک شیء ویژگی یا متد `type` دارد

- می‌توانید از عملگر `in` استفاده کنید تا بررسی کنید آیا یک شیء ویژگی یا متدی دارد.

## 9. اگر یک شیء ویژگی یا متد `id` را ندارد، خطا پرتاب کنید

- می‌توانید از عملگر `in` استفاده کنید تا بررسی کنید آیا یک شیء ویژگی یا متدی دارد.
- اگر ویژگی یا متد `id` وجود نداشته باشد، تابع شما باید یک `Error` پرتاب کند.

## 10. بررسی کنید آیا یک شیء ویژگی `id` دارد

- برای بررسی اینکه یک شیء ویژگی‌ای دارد (نه متد)، می‌توانید از تابع `Object.hasOwn()` استفاده کنید.

## 11. بررسی کنید آیا یک شیء ویژگی `type` تعریف‌شده دارد

- برای بررسی اینکه یک شیء ویژگی‌ای دارد (نه متد)، می‌توانید از تابع `Object.hasOwn()` استفاده کنید.
- باید به ویژگی `type` دسترسی پیدا کنید و بررسی کنید که تعریف شده است.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
