# مقدمه

به‌طور کلی، هنگام برنامه‌نویسی نمی‌خواهید چرخ را دوباره اختراع کنید.
برای بسیاری از الگوریتم‌های استاندارد، کسی هست که ممکن است کار شما را پیش‌تر انجام داده باشد.

## دستورهای `include`

برای گنجاندن محتوای فایل‌های دیگر، C++ از دستور `include` استفاده می‌کند.
این دستورهای `include` باید در بالای فایل نوشته شوند.
در هنگام کامپایل، خطی که دستور در آن قرار دارد با محتوای فایل مربوطه جایگزین می‌شود.
فضاهای نام پس از `include`ها همان‌طور که در فایل اصلی هستند باقی می‌مانند.

## کتابخانه‌ی استاندارد

کتابخانه‌ی استاندارد توابع، الگوریتم‌ها و ساختارهای داده‌ی رایج بسیاری را ارائه می‌دهد.
کتابخانه‌ی استاندارد از فضای نام `std` استفاده می‌کند.

یک نمونه، کتابخانه‌ی محاسبات عددی C یعنی `cmath` است.
این کتابخانه عملیات ریاضی رایج بسیاری را فراهم می‌کند.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
کتابخانه‌های استاندارد با براکت‌های زاویه‌دار `<>` گنجانده می‌شوند، نه با گیومه‌ی دوگانه `"`.
تفاوت در مکانی است که کامپایلر فایل‌های مربوطه را در آن جست‌وجو می‌کند.
در نسخه‌ی براکت‌های زاویه‌دار، جست‌وجو در پروژه‌ی فعلی نادیده گرفته می‌شود و مستقیماً از پوشه‌های `include` سیستم آغاز می‌شود.
اگر بخواهید فایل‌های محلی را include کنید، از گیومه‌ی دوگانه استفاده می‌کنید: `#include "myfile"`
~~~~
