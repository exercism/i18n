# درباره

[«گارد»][guards] به عنوان مکملی برای [«تطبیق الگو»][exercism-pattern-matching] به کار می‌رود. که در یکی از مفاهیم بعدی به آن می‌پردازیم. گاردها به ما امکان می‌دهند بسته به مقدار ورودی، پیاده‌سازی‌های متفاوتی از یک تابع داشته باشیم. همچنین بررسی‌های پیچیده‌تری را ممکن می‌کنند.

یک دستور گارد با یک خط عمودی `|` تعریف می‌شود که پس از آن یک عبارت منطقی می‌آید و به علامت تساوی `=` و بدنه‌ی تابع ختم می‌شود. برای یک تابع می‌توان چندین دستور گارد داشت. دستورهای گارد از بالا به پایین ارزیابی می‌شوند و نخستین دستوری که به `True` ارزیابی شود، اجرا می‌شود. یک دستور گارد می‌تواند یک حالت `otherwise` هم داشته باشد که هر مقداری را که با دستورهای گارد پیشین مطابقت ندارد، پوشش می‌دهد.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

همچنین می‌توانیم تابع خودمان را تعریف کنیم و آن را درون دستور گارد به کار ببریم.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
