# مقدمه

_«تاریخ و زمان از چیزهایی است که به بچه‌های کوچک هم یاد می‌دهیم. مگر چقدر می‌تواند سخت باشد؟»_

بسیاری از برنامه‌نویسان مرتکب همین اشتباه شده‌اند و تجربه‌ی بعد از آن معمولاً تأثیر بدی بر سلامت و شادی‌شان می‌گذارد.

هر کسی که برنامه‌نویسی غیرساده با تاریخ و زمان انجام می‌دهد، دست‌کم باید آماده باشد مشکلات احتمالی را درک کند و از آن‌ها بکاهد.

این سند می‌کوشد نمای کلی‌ای از نحوه‌ی کار جولیا با تاریخ و زمان ارائه دهد، اما برای جزئیات بیشتر باید به [راهنما][Dates] مراجعه کنید.
همچنین یک [ویکی‌کتاب][Wikibook] هم هست که توضیحاتش ممکن است برای برخی خوانندگان روشن‌تر باشد و شامل یک [نمودار][type-hierarchy] مفید از سلسله‌مراتب نوع‌ها است.

## ماژول `Dates`

بیشتر قابلیت‌های پایه در `Dates` قرار دارد، ماژولی که در نصب پیش‌فرض گنجانده شده اما بخشی از کتابخانه‌ی استاندارد نیست.

برای استفاده از این ماژول، دو گزینه وجود دارد:

1. `import Dates` را اضافه کنید، سپس پیش از همه‌ی فراخوانی‌های تابع `Dates.` را بگذارید.
2. `using Dates` را اضافه کنید، که کل ماژول را به فضای‌نام جاری می‌آورد (_به‌جز چند نام مشکل‌دار_).

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

ماژول `Dates` بزرگ و پیچیده است، اما چهار نوع اصلی قابلیت فراهم می‌کند:

- `Dates.Date` که شامل روز-ماه-سال است اما زمان روز را ندارد.
- `Dates.Time` که شامل زمان روز است اما تاریخ را ندارد.
- `Dates.DateTime` که تاریخ و زمان را ترکیب می‌کند.
- `Dates.Period` که بازه‌های زمان/تاریخ را مدیریت می‌کند.

لطفاً توجه کنید که یک `DateTime` به‌طور کلی اطلاعات منطقه‌ی زمانی را شامل _نمی‌شود_ (پایتون به این نوع، تاریخ‌وزمان «ساده» می‌گوید).
یک استثنا `now()` است که زمان محلی را از ساعت سیستم شما می‌گیرد و در صورت نیاز می‌تواند آن را به UTC تبدیل کند.

شاید رایج‌ترین نیازها این‌ها باشند:

- تجزیه‌ی یک قالب ورودی مناسب برای ساختن یک نوع `Dates`.
- گرفتن قالب عددی یا متنی موردنیاز از یک نوع `Dates`.
- اعمال یک جابه‌جایی روی مقدار `Date`، `Time` یا `DateTime`.
- محاسبه‌ی بازه‌ی میان دو مقدار از این دست.
- گرفتن تاریخ جاری (با `today()`) و/یا زمان (با `now()`).

~~~~exercism/note
برای کاهش حواس‌پرتی بصری، بیشتر کدهای نمونه در ادامه‌ی این سند فرض می‌کنند `using Dates` اجرا شده است و از آوردن نام ماژول `Dates.` در فراخوانی‌های تابع پرهیز می‌کنند.
~~~~

### قالب‌های تاریخ و زمان

روش‌های زیادی برای نوشتن تاریخ و زمان وجود دارد که معمولاً وابسته به فرهنگ‌اند.
تاریخ‌های تمام‌عددی مانند «7/6/23» مبهم و گیج‌کننده‌اند و به اشتباهات پرهزینه‌ی زیادی در سازمان‌های چندملیتی منجر شده‌اند (_نویسنده این را از تجربه‌ی تلخ شخصی می‌گوید_).

استاندارد بین‌المللی در `ISO 8601` تعریف شده است و دو مزیت اصلی دارد:

- تجزیه سریع و بدون ابهام است.
- مرتب‌سازی آسان است، چون تاریخ‌وزمان را می‌توان مثل متن معمولی در نظر گرفت و به ترتیب الفبایی مرتب کرد.

در مثال قبلی دیدیم که `Date.now()` مقدار `2025-06-21T16:03:04.161` را برگرداند.

این مقدار از بخش‌های گوناگونی ساخته می‌شود:

- `YYYY-MM-DD` برای بخش تاریخ.
- `hh:mm:ss` برای بخش زمان.
- به‌صورت اختیاری، میلی‌ثانیه (یا واحدی حتی کوچک‌تر) پس از نقطه‌ی اعشار.

قالب‌های متنی دیگر در بخش بعدی بررسی می‌شوند.

## تاریخ‌ها

`Dates.Date` نوعی نسبتاً ساده و فقط‌مربوط‌به‌تاریخ است که هیچ درکی از زمان یا منطقه‌ی زمانی ندارد.

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

برای بخش‌های جداگانه‌ی تاریخ، توابع دسترسی وجود دارد و این توابع جفت‌جفت‌اند که با بزرگی و کوچکی حروف از هم تشخیص داده می‌شوند.

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### توابع پرس‌وجو

توابع گوناگونی وجود دارد که تا حدی از تقویم سر در می‌آورند.
مثال بعدی فقط چند تا از آن‌ها را نشان می‌دهد.

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## زمان‌ها

`Dates.Time` نوع پایه و فقط‌مربوط‌به‌زمان است.
هیچ درکی از تاریخ ندارد: زمان‌ها در نیمه‌شب به‌طور خودکار به `Time(0, 0, 0)` می‌چرخند.

قالب کامل سازنده `Time(hour, min, sec, millisec, microsec)` یا معادل ISO 8601 آن است.

همه‌ی پارامترها اختیاری‌اند و به‌طور پیش‌فرض `0` می‌شوند.

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

مانند `Date`، بخش‌های جداگانه با توابع دسترسی در دسترس‌اند:

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## تاریخ‌وزمان‌ها

`Dates.DateTime` بیشتر ویژگی‌های نوع‌های `Date` و `Time` را ترکیب می‌کند.

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

پارامترهای سال، ماه و روز به‌طور پیش‌فرض `1` و پارامترهای زمان همه به‌طور پیش‌فرض `0` هستند.

نگه‌داشتن ترتیب درست همه‌ی این پارامترها می‌تواند چالش‌برانگیز باشد، بنابراین برای ورودی، قالب ISO ممکن است ترجیح داده شود.

به‌طور جایگزین، می‌توان یک `DateTime` را از یک `Date` و یک `Time` ساخت، همان‌طور که در مثال بالا دیدیم.

## بازه‌ها

هر یک از اجزای تاریخ/زمان نوع `Period` خودش را دارد، از `Year` تا `Nanosecond`، که نماینده‌ی یک بازه‌ی زمانی است.
این نوع‌ها به‌ویژه برای حساب مفیدند.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

هنگام کار با نوع‌های `Period`، جولیا می‌کوشد در برابر نامنظمی‌های تقویم مانند طول ماه هوشمند باشد و در صورت لزوم گرد کند.

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## نمایش‌های متنی

پیش‌تر به استاندارد ISO 8601 اشاره کردیم که نمایش پیش‌فرض تاریخ/زمان در جولیا هنگام قالب‌بندی یا تجزیه‌ی متن‌ها است.

بدیهی است که قالب‌های بسیار دیگری هم زیاد به کار می‌روند، اغلب به شیوه‌های وابسته به فرهنگ.
برای مدیریت این‌ها، جولیا نوع `DateFormat` را دارد که می‌توان آن را از یک متن قالب با هر پیچیدگی ساخت.

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

مثال بالا بسیار ساده است، فقط یک تاریخ در قالب روز/ماه/سال که در اروپا رایج است.
دو گونه از این نحوه‌ی نگارش نشان داده شده است، اما نتیجه یکسان است.

سپس می‌توان از یک `DateFormat` برای تجزیه‌ی هر متن مناسبی استفاده کرد:

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

ساختن یک `DateFormat` سربار قابل‌توجهی دارد، بنابراین انجام این مرحله فقط یک بار (همان‌طور که اینجا با `dtfmt` انجام شد) هنگام حلقه‌زدن روی متن‌های زیاد تاریخ/زمان به کارایی کمک می‌کند.

قالب‌ها می‌توانند بسیار پیچیده‌تر از این باشند، بنابراین برای جزئیات به [راهنما][dateformat] مراجعه کنید.

از همان `DateFormat` می‌توان برای خروجی گرفتن تاریخ/زمان در هر قالب متنی دلخواه استفاده کرد، با استفاده از تابع [`Dates.format()`][format].

متأسفانه به نظر می‌رسد تضادی در فضای‌نام با `format` وجود دارد (دست‌کم تا جولیا 1.11.5)، بنابراین بهتر است حتی پس از `using Dates` پیشوند `Dates.` را هم بگذارید.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

همان‌طور که [مستند شده است][wiki-format]، `"e, u d"` نمایش متنی مختصر روز هفته و ماه را می‌دهد.

نمایش متنی به‌طور پیش‌فرض انگلیسی است.
زبان‌های دیگر هم می‌توانند افزوده شوند، هرچند پشتیبانی از این کار در حال حاضر چندان مطلوب نیست.
