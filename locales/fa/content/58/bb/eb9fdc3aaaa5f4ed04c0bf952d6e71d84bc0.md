# مقدمه

پکیج `math/rand` از تولید اعداد شبه‌تصادفی پشتیبانی می‌کند.

در ادامه می‌بینید چطور می‌توان یک عدد صحیح تصادفی بین `0` و `99` تولید کرد:

```go
import "math/rand"

n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

تابع `rand.Float64` یک عدد اعشاری تصادفی بین `0.0` و `1.0` برمی‌گرداند:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

همچنین از درهم‌آمیختن یک اسلایس (یا ساختارهای داده‌ی دیگر) هم پشتیبانی می‌شود:

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## بذر

دنباله‌های اعدادی که پکیج `math/rand` تولید می‌کند، واقعاً تصادفی نیستند.
اگر یک مقدار «بذر» مشخص داده شود، نتایج کاملاً قطعی خواهند بود.

در Go ۱.۲۰ و بالاتر، بذر به‌صورت خودکار و تصادفی انتخاب می‌شود، بنابراین هر بار که برنامه‌تان را اجرا کنید دنباله‌ی متفاوتی از اعداد تصادفی خواهید دید.

در نسخه‌های پیشین Go، بذر به‌صورت پیش‌فرض `1` بود.
پس برای اینکه در اجراهای مختلف برنامه دنباله‌های متفاوتی به دست آورید، باید پیش از دریافت هر عدد تصادفی، بذر مولد اعداد تصادفی را به‌صورت دستی تعیین می‌کردید، مثلاً با زمان کنونی.

```go
rand.Seed(time.Now().UnixNano())
```
