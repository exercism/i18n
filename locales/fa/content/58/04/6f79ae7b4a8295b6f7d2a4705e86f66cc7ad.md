# دستورالعمل‌ها

مأموریت شما نوشتن سرویسی است که رویدادها را دریافت می‌کند. هر رویداد تاریخی دارد، اما متوجه می‌شوید که ۳ قالب مختلف به اندپوینت سرویس شما فرستاده می‌شود:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

می‌بینید که میان آن‌ها شباهت‌هایی وجود دارد و تصمیم می‌گیرید چند الگوی عبارت باقاعده‌ی ترکیب‌پذیر بنویسید.

## 1. روز، ماه و سال را از یک تاریخ تطبیق دهید

`day/0`، `month/0` و `year/0` را طوری پیاده‌سازی کنید که یک الگوی رشته‌ای برگردانند که با کامپایل شدن، اجزای عددی `"01/01/1970"` را تطبیق دهد (قالب `dd/mm/yyyy`). روز و ماه ممکن است به شکل `1` یا `01` بیایند (با صفر در سمت چپ پر شده باشند).

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. روز هفته و ماه سال را تطبیق دهید

`day_names/0` و `month_names/0` را طوری پیاده‌سازی کنید که یک الگوی رشته‌ای برگردانند که با کامپایل شدن، به‌ترتیب نام روز هفته و نام ماه سال را تطبیق دهد.

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. روز، ماه و سال را ضبط کنید

`capture_day/0`، `capture_month/0`، `capture_year/0`، `capture_day_name/0` و `capture_month_name/0` را طوری پیاده‌سازی کنید که یک الگوی رشته‌ای برگردانند که اجزای مربوطه را با این نام‌ها ضبط کند: `"day"`، `"month"`، `"year"`، `"day_name"`، `"month_name"`

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. ضبط‌ها را ترکیب کنید تا کل تاریخ را ضبط کنید

`capture_numeric_date/0`، `capture_month_name_date()` و `capture_day_month_name_date/0` را طوری پیاده‌سازی کنید که یک الگوی رشته‌ای برگردانند که اجزای بخش ۳ را با قالب تاریخ مربوطه ضبط کند:

- تاریخ عددی - `"01/01/1970"`
- تاریخ با نام ماه - `"January 1, 1970"`
- تاریخ با نام روز و ماه - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. ضبط را محدود کنید تا فقط با تاریخ تطبیق داده شود

`match_numeric_date/0`، `match_month_name_date/0` و `match_day_month_name_date/0` را طوری پیاده‌سازی کنید که یک عبارت باقاعده‌ی کامپایل‌شده برگردانند که فقط با تاریخ تطبیق داده شود و بتواند اجزا را هم ضبط کند.

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
