# پارامتر اجباری پیش‌بینی‌نشده

پارامتر `${'parameter.name'}` در tests هم با یک مقدار و هم بدون مقدار فراخوانی می‌شود، اما _به‌عنوان اختیاری علامت‌گذاری نشده است_، یعنی tests پاس نمی‌شوند. می‌توان یک پارامتر TypeScript را با پسوند `?` به‌صورت صریح اختیاری کرد:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

یا به روشی دیگر، با اختصاص دادن یک مقدار پیش‌فرض به آن:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
