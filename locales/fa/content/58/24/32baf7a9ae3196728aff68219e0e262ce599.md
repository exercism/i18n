# `String`

نوع داده‌ی `String` یک سری خطی از نویسه‌ها است که با UTF-8 کدگذاری شده‌اند. برای ذخیره‌ی داده‌های متنی مفید است.

## ساخت یک `String`

یک `String` را می‌توان با توابع مرتبط `String::new()` یا `String::from()` ساخت. بسیاری از انواع، متدی به اسم `to_string` دارند که یک رشته تولید می‌کند، مثلاً از یک عدد.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### ماکروی `format!`

از آنجا که تولید یک رشته‌ی بزرگ از ترکیب چند نوع داده‌ی کوچک‌تر کاری رایج است، Rust یک شکل مختصر هم دارد که جزئیات فراخوانی `to_string` را حذف می‌کند: ماکروی `format!`. برای مثال، می‌توانیم ساخت رشته‌ی ترکیبی بالا را به شکل زیر ساده کنیم:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## برش رشته

رشته‌ها رابطه‌ی نزدیکی با برش‌های رشته دارند. برش‌های رشته ارجاع‌هایی تغییرناپذیر به ناحیه‌ای از حافظه با اندازه‌ی مشخص‌اند که شامل یک سری خطی از نویسه‌های کدگذاری‌شده با UTF-8 هستند. هر رشته‌ای را می‌توان با قرض گرفتن به‌وسیله‌ی عملگر ارجاع (`&`) به یک برش رشته تبدیل کرد. برای تبدیل یک برش رشته به یک رشته، هم متد `to_string()` و هم `String::from` مناسب‌اند.

در کد Rust، یک رشته‌ی متنی میان گیومه‌های دوتایی قرار می‌گیرد. این رشته‌های متنی همیشه برش رشته‌اند، چون به ناحیه‌ای تغییرناپذیر از حافظه در فایل اجرایی برنامه اشاره می‌کنند.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## تغییر دادن یک `String`

برای الحاق یک نویسه‌ی تکی به یک رشته، از متد `push` استفاده کنید. برای الحاق یک برش رشته به یک رشته، از متد `push_str` یا عملگر `+` استفاده کنید.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## دسترسی به نویسه‌های یک `String`

از آنجا که رشته‌های Rust با UTF-8 کدگذاری می‌شوند، نویسه‌های تک‌تک همگی اندازه‌ی یکسانی ندارند. بنابراین نوع داده‌ی `String` عملگر اندیس‌گذاری (`[]`) ارائه نمی‌دهد. برای دسترسی به همه‌ی نویسه‌های یک رشته یا یک نویسه‌ی مشخص در آن، می‌توان از متد `chars()` استفاده کرد. این متد روی هر نویسه‌ی رشته، به ترتیب، پیمایش می‌کند.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

## بیشتر

`String` یک نوع داده‌ی غنی است که چندین متد و ماکرو حول آن ساخته شده‌اند. برای دیدن همه‌ی متدهای عضو و قابلیت‌هایی که `String` ارائه می‌دهد، [مستندات کتابخانه‌ی استاندارد](https://doc.rust-lang.org/std/string/struct.String.html) را ببینید.
